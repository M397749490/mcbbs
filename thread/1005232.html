作者的话  Author's words
This Skript allows you to create warps with a per-warp permission!
WARNING: This plugin requires Skript to work!
SUPPORT: https://discord.gg/NYu4VST
这个 Skript 允许你去创建一个每次传送需要传送权限的传送点
警告： 这个插件需要 Skript 进行运行
支持（联系作者）
： https://discord.gg/NYu4VST
简介/特点  Introduction / features
- Create warps!
- Teleport to warps!
- Delete warps!
- See all the warps!
- Per-warp permission!
- Per-command permission!
- Reload command!
- Easy to understand!
  • 创建一个传送点
  • 删除一个传送点
  • 传送到传送点
  • 可以看见所有的传送点
  • 每个传送点需要权限
  • 每个命令需要权限
  • 拥有重载命令
  • 简单又方便
设置  Set up
1: Download Skript here
2: Place Skript in your plugins folder
3: Restart the server
4: Download EasyWarps.sk
5: Go to your plugins folder and select skript, select scripts and place EasyWarps.sk in this folder
6: Restart your server and you are all done!
1： 在此处下载skcript
2： 将skript放入插件文件夹
3： 重新启动服务器
4： 下载EasyWarps.sk
5： 转到插件文件夹并打开skript，再打开scripts并将EasyWarps.sk放在此文件夹中
6： 重新启动服务器，您就完成了！
命令&权限  COMMANDS & PERMISSIONS
/setwarp <warp> - Create a warp!
easywarps.setwarp

/warp <warp> - Teleport to a warp!
easywarps.warp.<warp>
easywarps.warp.*

/delwarp <warp> - Delete a warp!
easywarps.delwarp

/warplist - See all the warps!
easywarps.warplist

/EasyWarps info - Shows the Skript information!
easywarps.admin.info
easywarps.admin.*

/EasyWarps reload - Reload EasyWarps!
easywarps.admin.reload
easywarps.admin.*

/EasyWarps help - Shows all the commands!
easywarps.admin.help
easywarps.admin.*
/setwarp <warp> - 创建一个传送点
easywarps.setwarp

/delwarp <warp> - 删除一个传送点
