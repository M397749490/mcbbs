这是宠物插件所有指令

/mypet
显示所有可用的 MyPet 指令。
/petinfo [玩家名]
显示宠物的 HP 和经验值。输入玩家名后会显示该玩家宠物信息。
别名:
/pinfo
/petname [宠物新名字]
设置宠物的名字
/petrelease [宠物名]
释放宠物。没有宠物后，可重新捕捉。
/petcall
将你的宠物传送到你身边。
别名:
/pc
/petc
/petsendaway
遣散你的宠物。
可通过指令 /petcall 召回宠物
别名:
/psa
/petsa
/petskill <玩家>
显示自己 宠物 的技能树信息
管理可通过该指令查看其他玩家的 宠物 的技能树信息
/petadmin <选项> [参数…]
只有拥有 MyPet.admin 权限的玩家可使用
选项:
name
为指定玩家的 宠物 设置新名字
参数:
<拥有者>
<新名字>
exp
为指定玩家的 宠物 设置经验值
参数:
<拥有者>
<数值>
[add/set/remove]
注：add为增加 set为设置指定数值 remove为扣除

respawn
为指定玩家的 宠物 设置重生时间
只能改变死亡中的 宠物 使用
参数:
<拥有者>
[新的重生时间] 或 [show]
reload
重载配置文件 (config.yml)
build
显示 MyPet 版本
/petstop
使宠物停止攻击目标
别名:
/ps
/pets
/petskilltree <mobtype> [技能树名]
查看指定物种的可用技能树
查看指定物种的技能树包含的技能和等级
只能在服务器控制台使用
/petchooseskilltree [技能树名]
显示所有可用技能树
为 宠物 选择一个技能树
别名:
/pcst
/petcst
技能指令

/petinventory
打开宠物物品栏。
别名:
/pi
/peti
/petpickup
切换宠物 是否自动拾取。
别名:
/pp
/petp
/petbehavior <模式>
切换宠物状态
模式:
友好（friendly） → 不会攻击，即使自己被攻击
friend
普通(normal) → 像普通狼一样
好战（aggressive） → 攻击玩家15格范围内所有的生物
aggro
打野（farm） → 攻击玩家15格范围内所有的怪物
突击（raid） → 如同普通模式，但宠物不会攻击玩家和其他宠物
duel → Pets will only attack other pets in duel mode.
别名:
/pb
/petb
/petbeacon
打开 宠物 的信标技能窗口.
别名:
/pbeacon
/petbeacon
