【链接信息】Link Info
版本：【1.7.2】-【1.7.10】
官网：http://www.minecraftforum.net/forums/mapping-and-modding/minecraft-mods/1294637-link-info-0-4-see-basic-info-about-webpages-before
-可以显示你收到的链接的信息
-包括网站标题等
-如果是一个Youtube影片，则会显示UP主，播放量等
-如果是一张图片，则可以直接查看


官方更新日志：

0.4

  • Youtube: Changed to use oEmbed. This fixes The recent breakage.
  • Youtube: Removed duration, views, rating, and comment count. Will be back soon.
  • 加入Imgur信息
  • Images: Support for animated gifs
  • Several under the hood changes
  • 其他内容作者忘了

0.3.1

  • 修复点击链接后崩溃

0.3

  • 升级到1.7.10
  • 修复点击链接后卡死
  • Access the network less【不知道怎么翻译了】
  • 修复Youtube视频为0评论时崩溃
  • Change how the youtube rating ratio is gotten.
  • Rewrite image scaling. Fixes images being larger than the window or discolored.
  • 删除没用的东西
  • Removed jsoup. (Was used tor html parsing of title. Now uses regex)

0.2

  • 如果一个网站有域名重定向，则显示新的域名
  • 自动截取页面标题
  • 修复SSL证书无效时崩溃
  • 当图片没有加载时不显示图片按钮
  • 修复一些网站提示403错误

0.1

  • 正式发布
之后会添加的功能：
  • 显示推特信息
  • 显示Reddit推送信息
  • 显示Imgur相册
