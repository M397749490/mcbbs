使用方法
1、人形合成后右键可实体化

2、实体化后按右键切换状态

站立状态(Standby)
人形静止不动

活跃状态(patrol)
在这个状态下人形可以可以自由移动，并且发挥各自的特殊能力。为了防止迷路，她们如果离玩家太远，会报告离玩家的距离，方便找到。右击人偶核心可召回。

随从状态(follow)
她们会跟着玩家，并保持一段距离，太远时会自动传送
骑乘状态(ride)
不是你骑着人形，是她们骑着你……她们会呆在你的头顶上，右键可以让他们下来

3、立体化的人形也是有血的，如果把她们的血打没，她们会变成物品状态(Item)，可以拾起她们，右键仍可立体化。

4、持人偶核心右击人偶可以关闭人偶功能，再次右击可恢复

5、持书右击人偶可改变挖掘等级

6、持人偶核心左击人偶可使其变为物品状态

设置更改

%appdata%\config.mod_Touhou_Alice_Dolls.cfg，用记事本打开它，这个文件是Mod的设置，可更改，方法如下

0、 dollEntityID人偶的实体ID
dollEntityID = 81;

1、dollCoreID,dollShanghaiID,dollHoraiID,dollOoedoID,dollRussiaID
物品的ID
dollCoreID = 392;
      dollShanghaiID = 393;
      dollHoraiID = 394;
      dollOoedoID = 395;
      dollRussiaID = 396;
      dollGermanyID = 397;
      dollLondonID = 398;
      dollBareID = -1;
      dollMarisaID = -1;


2、searchEntity
可以探测的动物、怪物ID，可以添加别的MOD的动物、怪物的ID。
searchEntity = "\\A(?!Alice's Doll).*";

3、targetBlock
人形可探测的方块ID同上，可以添加别的MOD的方块ID。
digBlockList = "ore.+";

4、taregtEntity
人形可探测的敌人、动物ID，可以添加别的MOD的动物、怪物的ID。
targetEntity = "Zombie|Skeleton|Creeper|Spider|Slime|Enderman|Silverfish|Blaze";

5、entitySearchHeight
人形可探测的垂直距离
entitySearchHeight = 4.0;

6、searchRange
貌似是可探测的水平距离
entitySearchRange = 16.0;

7、attackStrength
上海的攻击力
attackStrength = 2;

8、explodeStrength
人形的爆炸威力
  explodeStrength = 3.0

9、ItemAttractRange
可收回物品的范围
canCollectRange=3.0;

10、loggingLevel
聊天框记录的等级
0:不记录
1:只显示有关探测的信息
2:全部显示
3:Debug模式
初始值：
loggingLevel = 2;

11、modelBiped
如果为true，Doll使用玩家的模型
modelBiped = false;

12、mineRange
人形可挖矿的距离
mineRange = 3;

13、mineSpeed
人形挖矿的速度
mineSpeed = 2.5;

14、 logBlock
人形伐木的方块
ogBlockList = "log|mushroom";

15、 leavesBlock
设定的叶子方块
leavesBlock = "leaves|mushroom|vine";

16、cutRange
伐木的距离
cutRange = 5;

17、cutSpeed
伐木速度
cutSpeed = 2.5;
