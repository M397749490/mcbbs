IPTest
通过简单的配置，限制指定国家的玩家可登录服务器，可切换白名单，黑名单模式，可以设置忽略的玩家和IP地址。
说明
周末无聊，在学校寝室写了个插件，学习一下Java，也顺便学习一下Minecraft插件开发。插件基于ip2region来判断国家位置，然后通过判断返回的国家信息是否让玩家登录，插件理论全版本可用，个人使用1.12.2，完全可使用。
命令和权限
无
配置文件
  1. # 配置版本号，请勿修改
  2. version: 1.0

  4. # true 白名单模式 false 黑名单模式
  5. mode: true
  6. # 跳过检查的IP
  7. bypass-ip:
  8.   - "127.0.0.1"
  9. # 跳过检查的用户名
  10. bypass-user:
  11.   - ""
  12. # 白名单模式下允许的国家
  13. allow-region:
  14.   - "美国"
  15. # 黑名单模式下不允许的国家
  16. disallow-region:
  17.   - "中国"
