插件介绍
Limit total amount of entities in chunks or from huge spawner farms to prevent from unnecessary server load. It can limit entity amount in each chunk by set limit. In example by default there can be only 20 pigs in one chunk and 100 animals (pigs, cows, horses, rabbits, chickens). Set your own limits and avoid lags from unnecessary mob grinders ir huge animal farms.

本插件可以限制区块内的实体总量，防止玩家的大规模牧场导致不必要的服务器资源占用，可以按照设置的限制来管束每个区块的实体数量，例如每个区块只允许20只猪或者100只被动生物（猪，牛，马，兔子，鸡）你可以自己设置限制来避免玩家的大型牧场造成的卡服。 ——原帖


插件特性
  • 全实体种类支持（包含所有MC版本中的所有生物实体）
  • 可设置玩家一次最多多少只狼跟随
  • 通过指令直接查看实体最多的区块列表，精准清理，防止误清
  • 限制每个区块内盔甲架和物品展示框的数量
  • 可设置当盔甲架或者物品展示框上有物品时不会清理
  • 可设置不会清理驯服的动物和已命名的动物
  • 可设置不会清理幼年期的动物
  • 可设置不会清理带鞍的动物
  • 可设置不会清理的世界
  • 可设置每过一定时间自动清理
  • 针对所有怪物生成原因精准限制，可设置怪物不会因为某种原因生成（比如刷怪笼）
  • 清理组限制，可把一类实体归为一组，数量限制针对该组全体数量而设定
  • 可限制玩家自己制作凋灵，铁傀儡，雪傀儡





安装与使用
无前置

指令与权限
  • /mfm clean <区块半径> - 直接按照数量限制清理一定区块半径内的实体
  • /mfm list <区块半径> - 输出前20个实体最多的区块，可点击传送
  • /mfm reload - 重载插件
  • /mfm chunks - 输出前20个使用中漏斗最多的区块，可点击传送

本插件由于直接限制了玩家创建某些生物的权限，因此：
酌情给玩家的权限
mfm.build.wither - 搭建凋灵
mfm.build.irongolem - 搭建铁傀儡
mfm.build.snowman - 搭建雪傀儡
mfm.bypasslimit.armorstand - 不受数量限制放置盔甲架
mfm.bypasslimit.itemframe - 不受数量限制放置物品展示框
