前言

可以自定义多久保存一次存档
以及自定义是否公告和公告的内容

使用教程

在装好forge的服务端中
放入mods文件夹即可
(客户端不用装这个mod)

唯一指令
/as save #手动保存存档,并且发送公告

配置文件
# Configuration file

general {
    # 设置保存时公告的消息
    S:announceMessage=World Saved!    #--- 消息内容

    # 是否开启公告
    B:disableBroadcast=false   #--- 设置为 true 为关闭公告

    # 保存的间隔
    I:saveInterval=5    #--- 间隔单位是分钟

    # 公告消息前缀
    S:serverName=AutoSave   #--- 公告的消息前面括号中的内容
}
