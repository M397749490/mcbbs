标题: 服务器玩家没有一点ESS权限
我把那个权限组的文件夹删了 重启服务器后 把普通玩家的tpa、back、hat、nick、mc、输入彩色字体 这些权限去掉了 结果玩家连home的权限都没了 怎么回事？
作者: 凯文丶    时间: 2016-4-22 19:37
这是最简单的方法
1、关服
2、把GroupManager文件夹删了
3、开服，等等重新生成GroupManager文件夹、关服
4、打开GroupManager内的globalgroups.yml文件，找到文件内的这个地方g:essentials_builder:的下面。删除你想不给玩家的权限，如
    - essentials.tpa
    - essentials.back
    - essentials.hat
等权限，在次开服即可

GroupManger会将default设置默认组
可以再配置文件(groups.yml) 这样写
  Builder:
    default: true
    permissions:
    - BossShop.open.sign
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      build: true
      prefix: '&2'
      suffix: ''
然后将default组的 default 改为 flase
