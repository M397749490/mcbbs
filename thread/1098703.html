可以给僵尸命名或者使用指令召唤一只有标签的僵尸
然后检测目标区域是否存在此僵尸
例如
/summon minecraft:zombie ~ ~1 ~ {Tags:["233"]}
/execute unless entity @e[type=zombie,Tag=233]  run +指令

如果你能修改存档，或者说使用数据包，可以给怪物掉落添加一个额外的战利品表，当怪物死亡时必定掉落一个自定义的、隐形的、不可拾取的物品，随后高频探测是否有该物品出现，若出现则 /setblock（可能需要用 /execute positioned as 转换执行坐标）并清除该掉落物。
另一种方法，先杀死指定怪物，再在相同位置生成一个载（Passengers）有一个隐形盔甲架的同种怪物，随后高频探测这个盔甲架下是否还有所乘怪物，若已消失则 /setblock 并清除该盔甲架。
当然如果只检测一个特定的怪物，只需 /tag 给予该怪物一个标签即可，随后高频探测是否存在该标签。

# 先召唤一只 tag=foo 的僵尸
summon zombie ~ ~ ~ {Tags:["foo"]}
# 如果没有 tag=foo 的实体则运行 setblock
execute unless entity @e[tag=foo] run setblock
