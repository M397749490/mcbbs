此插件暂时不支持最新的1.15.2的authme开发板
站内原本有搬运帖子，但是由于年代久远并且没有介绍所有的功能~
所以我决定重搬
（此帖子将会介绍此插件大多数功能。如果你有些功能看不懂，那么你可以去本站的旧搬运帖子看看，或许对你有帮助~）

插件概述：
让你的服务器正版玩家不用登录和注册了吧~
离线服务器正版玩家自动登录和自动注册~

其实我觉得把这个插件可以保护正版账号的账户安全，一般玩家会把authme密码设置为mojang正版一样的密码，，，万一服务器没有用SSL加密 一不小心被爆破了 黑客在一撞库~  qq wx zfb等等账号密码不保啊~
主要特性：
此插件支持Cauldron
此插件支持蹦极，在BC端和服务端同时安装即可（使用BC的话不可以使用sqlite本地数据库，必须要用mysql）
要求前置为ProtocolLib和后面介绍中提到的任意一款登陆插件。
此插件需要JAVA8或更高的版本来运行。
  1. 开源的 (Github)
  2. 检测正版账户
  3. 使正版用户自动注册
  4. 使正版用户自动登陆
  5. 支持多种登陆插件
  6. 支持Cauldron
  7. 支持Forge/Sponge后端（BC端）
  8. 支持正版用户UUID（正版用户更换用户名照常玩耍）
  9. 转发正版皮肤/头像(在没有皮肤插件的离线服务器可以显示正版玩家的皮肤和TAB头像)
  10. 支持BungeeCord
  11. 支持ProtocolSupport，可用作ProtocolLib的替代方案
  12. 不需要对客户端进行修改
  13. 使用异步进行了性能优化
  14. 免费(开源且免费)
复制代码
支持的登录插件：
·        AuthMe Reloaded
·        AdvancedLogin
·        UltraAuth
·        BungeeAuth
·        CrazyLogin

指令：
/premium //直接标记自己为正版玩家(/prem 为简化指令)
/premium [playername] //标记一个玩家为正版玩家
/cracked [playername] //取消标记一个玩家为正版玩家

权限：
fastlogin.bukkit.command.premium  //标注自己为正版玩家
fastlogin.bukkit.command.cracked  //标注自己为盗版玩家
fastlogin.bukkit.command.premium.other  //标注他人为正版玩家
fastlogin.bukkit.command.cracked.other  //标注他人为盗版玩家

服务器端必要设置：
1. 在server.properties文件中找到online-mode设置为false
2. 安装必要的前置插件 ProtocolLib
3. 将插件放进plugins目录
4. 重启服务器即可

# 此项配置需要spigot；Cauldron或者PaperSpigot
premiumUuid: false

# 此项配置请慎重开启
# 此项配置功能是检测正版玩家id的变化~
# 请看下面的例子说明 （实在不知道怎么翻译。。。所以一半机翻 一半手动翻译）
# 例子：
# ####案例1
# nameChangeCheck = false ----- autoRegister = false
#
# 不开启验证和自动登录
#
# ####案例2
#
# nameChangeCheck = true ----- autoRegister = FALSE
#
# 连接Mojang API并检查玩家具有的UUID（UUID存在=>正版Minecraft帐户）。如果那个UUID在
# 数据库它是现有玩家而FastLogin可以假设玩家是正版并且更改了id。
# 如果它不在数据库中，它是一个新玩家，也有可能是一个破解的玩家。所以我们只使用离线模式认证此玩家。
#
# **限制**：使用正版账户的新用户名的离线玩家如果不在数据库则无法加入服务器
# 包含旧名称。（示例：付费帐户的所有者不再在服务器上播放，但更改了用户名
# 同时）。
#
# ####案例3
#
# nameChangeCheck = false ----- autoRegister = true
#
# 如果我们不知道用户名，我们将始终要求开启正版验证，但付费的Minecraft正在使用
# 帐户。这意味着它是一种更积极的检查，如nameChangeCheck = true和autoRegister = false，因为
# 它请求一个对我们来说全新的正版认证，即使是正版用户UUID也不在我们的数据库中。
#
# ####案例4
#
# nameChangeCheck=true ----- autoRegister的=true
#
# 基于autoRegister，它检查播放器名称是否为premium并使用高级身份验证登录。之后
# fastlogin收到保费UUID和可更新的数据库记录。
#
# ** autoRegister的限制**：使用现有Minecraft用户名的新离线玩家无法加入服务器
nameChangeCheck: false

# 此功能随意开启

forwardSkin: true
