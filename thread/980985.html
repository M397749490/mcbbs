前言
1.针对副本不会下载MC的玩家，我先简单介绍一下MC的PC版本
2.PC版本[意思电脑版本]分为现在流行的[1.7.10].[1.8.8].[1.9.4].[1.12.2].[1.13.x].[1.14.x].[1.15.x]
3.针对选择需玩单人玩法的萌新，可以选择高版本的玩法.玩法多。
下面是介绍玩法的。
4.针对选择玩多人联机玩法的萌新，需要到MCBBS的多人联机中的服务器中选择玩什么服。
下载对应的客户端，几乎吧，他们都有自己的客户端可以下载他们的客户端。
这样子就告别自己不知道怎么搞的问题了
5.但是前提你需要下载一个叫Java的东西
下载Java8.32位 或者 Java8.64位
我以及给大家找好了 点击这里 点击我~
选择下载对应的位数。
6.此时萌新会问如何选择位数，不知道怎么回事？
进入控制面板，点击系统与安全，双击系统就可以查看电脑是32位还是64位


32位操作系统最多支持4G内存，如果你的电脑内存大于4G就要用64位的系统了，64位操作系统支持4G，8G，16G，32G，64G，128G，256G内存

如果你系统是双核以上肯定支持64位操作系统，64位操作系统，计算主要由两大优点，可以进行更大范围的整数运算可以支持更大的内存。
64位系统运行起来比32位的系统，理论上快2倍，32位的操作系统民用化软件基本全部兼容，而64位的要差些。




初入MC教程
1.玩家式的基础指令
1.初次进入服务器你需要输入/register 密码 密码         [用于注册你的号，需要你牢记密码]
[指令还可以这样子输入也是注册 /reg 密码 密码]
然后输入回车[Enter]
2.第二次进入服务器你需要输入/login 密码 密码                  [用于登录你的号]
[指令还可以这样子输入也是登录 /l 密码 密码]
然后输入回车[Enter]
以后进入就可以都这样输入了
[前提是同一个服务器，如果换了你就还要输入/register 这样子注册]
3.基础指令
/sethome
这个是在你脚下生成一个名为"家"的一个东西
以后你可以输入/home 就都可以回到这个地点了
/delhome #删除家

/spawn
这个是用于回城 也就回到主城
/tpa 名字
这个指令可以将你传送到"名字"那个人的位置哦~
[前提他要同意你的传送]
也就是/tpaccept
相反别人传送你，你也需要这样子输入
/back
这个指令可以回到你的上一次传送后的地方或者是死亡的地方
嘿嘿[如果是岩浆的话 或者危险地带 就别传送了哦~可能又会死]
/suicide 这个指令可以给自己杀死哦~
/help #查看命令帮助
/list #查看当前在线玩家
/msg 玩家 文字 #私密玩家
/pay 玩家 数量 #给玩家金币
/tpahere 玩家 #请求玩家传送到你的身边

此外进阶玩法如果你是OP[也就是管理员]必须自己开的服或者别人服给你的管理员
指令/OP 你的名字
创造模式 /gamemode 1，生存模式 /gamemode 2，冒险模式 /gamemode 3。
想获得物品可以输入 give 你的用户名+物品代码（通常是物品的英文名），这是玩家最常使用的指令之一，并且如果玩家对物品代码较熟，可以很轻松地获得想要的物品。
下面也都是只能OP使用的指令
/tp id传送到谁那
/tp @e 玩家 将附近实体传送到玩家
/gamerule keepinventory true 死亡不掉落
/gamerule mobgriefing false 防爆
/kill **
]/kill @e 清除附近实体
/kill 玩家 杀死某玩家
/gamemode 0/1设定游戏为生存/创造
/op 玩家 给予某玩家主机权限
/deop op 清除某玩家权限
/clear 清空背包
/difficulty 调整难度(0:和平 1:简单 2：普通 3：困难)
/effect 获得效果(1速度 2缓慢 3急迫 4挖掘疲劳 5力量 6瞬间治疗 7瞬间伤害 8跳跃提升 9反胃 10生命恢复 11抗性提升 12防火 13水下呼吸 14隐身 15失明 16夜视 17饥饿 18虚弱 19中毒)
/enchant 手中的装备会被附魔(目前不清楚附魔ID)
/say <文本信息>会让命令台发送广播消息



领地插件
几乎每个服务器都有的哦
输入“/res ?”查看全部sub命令简要说明;
        　　输入“/res info”可以查看当前领地详细信息;
        　　输入“/res list”列出自己所拥有的领地;
        　　输入“/res listall”列出所有领地。
        　　一、设置领地：
        　　先用一个木头斧子【部分服务器可能是木棒 也可能是木铲子 多试试】左键敲击一方块设置点A，右键敲击一方块设置点B(输入“/res select size”查看所选区域的大小);
        　　之后输入“/res create 123”(例)这样设置后，就形成了[以AB连线为体对角线的长方体或正方体(包括A、B所在边)，每一块砖要花费3元。
        
               
        　　二、移除领地：
        　　输入“/res remove 123”(例)移除名为123的领地，注意，移除领地无法从服务器获得金钱!
        　　三、领地内权限设置：
        　　输入“/res set 123 flags true/false”(例)来设置权限，其中：
        　　①123是领地名，不填则默认为当前所处领地;
        　　②flags代表权限
　四、子空间设置：
        　　如同设置领地一样选择区域，不同的是之后输入“/res subzone 123 abc”(例)设置母领地为123的名为abc的子空间，该区域的权限设置和移除则需要将领地名变为123.abc，
        　　无则默认为当前所处领地(在子空间则为子空间)。
        　　五、领地信息设置：
        　　可以设置进出领地时的提示信息，输入“/res message 123 enter(leave) ABC”(例)设置领地123的进入(离开)时的提示信息为ABC，
        　　123处不填，则默认为当前所处领地;
        　　特别地，在提示信息中可以添加：
        　　%player - 在提示信息中显示进出领地的玩家名
        　　%owner - 在提示信息中显示领主
        　　%residence - 在提示信息中显示该领地

/qs玩家商店基础插件介绍
见过木牌子的箱子商店吗？ 这里给你介绍一下怎么用！
例子：
     我要卖一把金剑，那么我拿着这把金剑，然后对着箱子点击鼠标左键，出现"按T"打开对话框之后，输入1000，把金剑的价钱设置为1000，然后按enter确定。出现下图，成功摆摊！
如果有人看上这把金剑，然后要买怎么办？
     那么对着这个出售中的箱子点击鼠标左键，出现提示“请按T输入你想要购买的数量，并以enter键确定购买”。
   那么就按T后输入想买的数量进行购买吧！如果你的金币数量够木牌上显示的价格，那么就能成功购买。
如果你想收购你手上拿着的那件物品
      当你的商店开启成功后，十字 光标对着这个正在出售的箱子，输入命令
【/qs buy】然后按enter键确定。
  如果要改回出售的状态，那么命令改为【/qs sell】按enter即可
创建一个无限物品的商店
  对着出售/收购的商店按T输入命令【   /qs unlimited  】即可。
      如果要取消无限物品，那么再对着已经设置成出售/收购无限商品的箱子输入上面命令即可。
修改价格
       如果你想要修改你箱子商店出售的物品价格，那么对着箱子输入命令
【/qs price 价格】，其中价格是数字，不要输入汉字I或者符号了哦！
   我要把100/把改成100/把，那么就输入【/qs price 1000】然后按enter键确定。
其它的一些命令
     比如清空十字光标对着的商店里面出售的所有货物【/qs empty】
     给十字光标对着的箱子商店添加出售中的商品，【/qs refill 出售在的物品数量】
      给箱子商店换卖家，指令是【/qs setowner 玩家名字】
