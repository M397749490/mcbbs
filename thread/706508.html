作者: LRual    时间: 2017-7-15 06:55
目前没有直接的方法
但可以通过其他mod来辅助
比如Too Much Loot：
https://minecraft.curseforge.com/projects/toomuchloot

如果楼主是1710的服务器还请继续看下去
如果不是的话可以无视我

首先安装上这个mod
然后运行一次服务器

之后找到这个路径：
  1. config\TooMuchLoot\loot\generated
复制代码

并打开dungeonChest.json文件
可通过搜索找到如果下内容：
  1. {
  2.       "item": "IC2:itemOreIridium",
  3.       "damage": 0,
  4.       "weight": 20,
  5.       "count_min": 1,
  6.       "count_max": 2
  7.     },
  8.     {
  9.       "item": "IC2:itemShardIridium",
  10.       "damage": 0,
  11.       "weight": 100,
  12.       "count_min": 6,
  13.       "count_max": 14
  14.     },
复制代码


IC2:itemOreIridium指的是依矿
IC2:itemShardIridium是小依矿
可将不想生成的物品的最多最少值都改为0
例如：
  1. "item": "IC2:itemShardIridium",
  2.       "damage": 0,
  3.       "weight": 100,
  4.       "count_min": 0,
  5.       "count_max": 0
复制代码


之后保存并重启服务器
