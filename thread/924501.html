你是否觉得原版的合成太过简单乏味？
这个mod可以让你感受来自世界的力量。
流体、火焰、爆炸，世界的一举一动，皆有其意义。

本mod为CraftTweaker集成了用流体、火焰或爆炸进行合成的功能。
  • 当液体接触到特定物品时将其变为另一种液体。
  • 当物品接触到特定液体时将其变为另一种物品。
  • 点燃物品时将其变为另一种物品。
  • 引爆物品时将其变为另一种物品。
  • 炸毁方块时将会生成某一种物品。
  • 可以设定合成中是否会消耗物品或液体、所需燃烧时间、爆炸后合成成功的概率等。

本mod内置JEI支持，你可以使用JEI快速学习使用本mod的整合包添加的自定义配方。
也可以试着自己制做整合包，用它做出更多独具创意的配方，另其他人吃一惊！

已知bug：在使用了改变掉落物品类型的mod时可能导致点燃物品的合成方式失效。

对整合包魔改有兴趣的可以在坛里搜索类似“魔改”、“CraftTweaker”，教程应该不少，这里就不写CraftTweaker的教程了。本mod添加的语法如下：
  1. 物品接触液体转换成其他物品（得到的物品，介质液体，材料物品，是否消耗介质）：mods.inworldcrafting.FluidToItem.transform(IItemStack,ILiquidStack,IIngredient[],boolean);
  2. 液体接触物品转换成其他液体（得到的液体，材料液体，介质物品，是否消耗介质）：mods.inworldcrafting.FluidToItem.transform(ILiquidStack,ILiquidStack,IIngredient[],boolean);
  3. 点燃物品时将其变为其他物品（得到的物品，材料物品，等待时间）：mods.inworldcrafting.FireCrafting.addRecipe(IItemStack,IIngredient[],int);
  4. 引爆物品时将其变为其他物品（得到的物品，材料物品，等待时间）：mods.inworldcrafting.ExplosionCrafting.explodeItemRecipe(IItemStack,IIngredient,int);
  5. 炸毁方块时将会生成其他物品（得到的物品，材料物品，等待时间）：mods.inworldcrafting.ExplosionCrafting.explodeBlockRecipe(IItemStack,IItemStack,int);

inworldcrafting-1.12.2-1.0.0-universal-beta
  • Removed the item blacklist, changed approach to crafting so we don't cannibalized custom EntityItem classes. (Might be a bit more expensive on the cpu, so marking this version as a beta)

  • Removed config as the Blacklist is no longer a thing, the config file can be removed without breaking anything.
