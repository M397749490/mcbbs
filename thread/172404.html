20人的服务器一般用VPS就足够了，推荐有1GB RAM（内存），硬盘看你自己的需要，CPU不要太渣都可以，网速推荐5mbps以上，如果有20人同时在线那么5mpbs其实未必够用的
服务器系统推荐用Linux服务器，如果实在离不开图形操作界面的话那么就用Windows吧...

如果原版推荐用bukkit端（因为官方的扩展性也实在太弱了...bukkit也能装些保护插件之类的
MOD我就不清楚. .


开一个bukkit服. .你需要java. .（超级废话
很简单. .搜索一下都能找到的了


bukkit可以在这里下载（目前只有1.5.2的稳定版，但也有1.6.2（中文的我不知道有没有

然后Linux就在和jar同目录的地方新建一个run.sh
然后nano run.sh
然后输入以下内容：
  1. #!/bin/sh
  2. BINDIR=$(dirname "$(readlink -fn "$0")")
  3. cd "$BINDIR"
  4. java -Xmx1024M -jar craftbukkit.jar -o false
复制代码
-Xmx1024M是最大分配1024MB RAM，建议留下一点给系统（不要用满. .
然后craftbukkit.jar替换成你的jar的名字
-o false代表在线模式为关闭（可用盗版）

Windows就新建run.bat输入
  1. java -Xmx1024M -jar craftbukkit.jar -o false
  2. PAUSE
复制代码
插件可以在http://dev.bukkit.org/bukkit-plugins搜索和下载（注意用Filters来搜索...
下载完了如果是jar结尾的可以直接塞进/plugins里面，如果是zip就解压


详情阅读http://wiki.bukkit.org/Setting_up_a_server即可. .
