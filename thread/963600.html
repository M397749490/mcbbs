FAQ(摘自前贴)
Q:我该怎么报告错误？
A:你可以在 Github 或者 Mantis 上报告错误。
请注意，如果要报告错误，请包括  游戏版本号、MOD版本号 以及 所出现的问题。

Q:我该怎么联系作者？
A:你可以在Esper Irc Network的#EnchantingPlus上找作者私聊 以便寻求帮助。

Q:我可以使用这个mod在我modpack里面吗？
A:如果你坚持这么做的话，可以，不过你要做到以下要求
给予一个链接地址连接到 原帖。
Give proper credits to all the contributes of this mod: currently mssodin28, GnRSlash.
Give proper credits to the original authors: Qizzok, xkyouchoux.
保持非盈利。(如果你想做一个盈利的modpack，包括广告，你需要来与作者协商相关条例.)
给予一个链接地址连接到源代码储放处，指 Github。

Q:请问有多少个关于该mod的网址呢？
A:
GitHub 第三代之前包括第三代：https://github.com/Epoxide-MC/EnchantingPlus
