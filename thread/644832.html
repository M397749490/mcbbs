已经是我第4次bbs上见到这问题了....
你的版本是1.9以上吧，就是那个左右手的那个版本??对吧?
以金剑为例，于材质包进行修改。(前3个人都问我如何直接在文件内核改，原因我都已经不想说了.....)
于材质包assets\minecraft\models\item内新建golden_sword.json
golden_sword.json用记事本打开输入以下并保存

  1. {
  2.     "parent": "builtin/generated",
  3.     "textures": {
  4.         "layer0": "items/golden_sword"
  5.     },
  6.     "display": {
  7.         "thirdperson_righthand": {
  8.             "rotation": [ 15, 90, 0 ],
  9.             "translation": [ 0, 7.5, -3 ],
  10.             "scale": [ 1.8, 1.8, 1.8 ]
  11.         },
  12.         "thirdperson_lefthand": {
  13.             "rotation": [ 90, 0, 170 ],
  14.             "translation": [ -3.5, -5.5, 7 ],
  15.             "scale": [ 1.8, 1.8, 1.8 ]
  16.         }
  17.     }
  18. }
复制代码
以上只改了第三人称时左右手上时的大小显示和角位调整。个人喜好可自行调整。
最后你那个贴图命名为golden_sword.png且保存于assets\minecraft\textures\items目录下


旋转角度(rotation)
移位(translation)
大小(scale)(这个就是你最需要改的，取值0~2)
