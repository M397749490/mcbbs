标题: [管理]PluginManager-很好的插件管理工具[1.4.7-R1.0]
一个小巧并强大的插件管理工具，能够显示插件各类信息、对插件进行加载卸载启用禁用等操作

并且可以注销掉插件的某条命令（赞~）

在windows系统&JAVA 7下，能够删除插件

  1. # 显示菜单
  2. # 权限：无
  3. /pm
  4. # 启用插件
  5. # 权限：pluginmanager.enable
  6. /pm enable <插件>
  7. # 禁用插件
  8. # 权限：pluginmanager.disable
  9. /pm disable <插件>
  10. # 加载插件
  11. # 权限：pluginmanager.load
  12. /pm load <文件名>
  13. # 卸载并移除插件
  14. # 权限：pluginmanager.unload
  15. /pm unload <插件>
  16. # 重载插件
  17. # 权限：pluginmanager.reload
  18. /pm reload <插件>
  19. # 禁用，然后再启用插件
  20. # 权限：pluginmanager.softreload
  21. /pm sreload <插件>
  22. # 显示插件的详细信息
  23. # 权限：pluginmanager.show
  24. /pm show <插件>
  25. # 列出插件
  26. # 权限：pluginmanager.list
  27. /pm list [选项]
  28. # 注销一条命令!
  29. # 权限：pluginmanager.cmd.unregister
  30. /pm cmd unregister <插件> <命令>
  31. # 给插件一条命令的优先级设置为最高
  32. # 权限：pluginmanager.cmd.priority
  33. /pm cmd priority <插件> <命令>


  36. 最后两个权限：
  37. pluginmanager.*
  38. pluginmanager.cmd.*


  41. [选项]的参数：

  43. -v - 显示所有插件版本信息
  44. -o - 显示所有选项
  45. -a - 按字母顺序排列插件
  46. -s:[名称] - 显示名称中带有[名称]的插件，等同于搜索
