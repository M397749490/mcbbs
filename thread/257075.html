原理是运用正弦公式。
文件名为sincos.java
源码如下：
  1. public class sincos{
  2.         public static void main(String arg[])
  3.         {
  4.                 double sin1 = Math.sin(Math.PI/180);
  5.                 double cos1 = Math.sqrt(1-Math.pow(sin1,2));
  6.                 double sin = sin1;
  7.                 double cos = cos1;
  8.                 for (int i = 2;i <91 ;i++ )
  9.                 {
  10.                         sin = sin*cos1+cos*sin1;
  11.                         cos = Math.sqrt(1-Math.pow(sin,2));
  12.                         System.out.println("度数："+ i +"度 【sin = "+ sin +"】-【cos = "+ cos +"】");
  13.                 }
  14.         }
  15. }
