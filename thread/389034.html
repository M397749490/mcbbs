高频后面跟着的装置其中一个在空腔setblock一个红石块，然后另一个被激活的命令方块为setblock air的。

代码部分装置是蓝色角右边的区域，右边的是Warmup代码，高频旁边从上至下执行循环代码。
这是代码

  2. //伪代码说明：

  7. //loop是高频循环，open是开始，close是结束，continue是循环代码结尾
  8. scoreboard objectives add times dummy //初始化变量 htims是换行数，times操作数
  9. scoreboard objectives add htims dummy

  11. ;Warmup. //自定义代码，在下面

  13. ;loop open: //开始高频循环，多次使用直接从这里开始
  14. testfor @e[name=Scan,score_htims_min=5] //换行数等于行数结束循环
  15. {
  16.         tp @e[name=Scan] ~ -1 ~  //杀掉定位器
  17.         ;Warmup. //重置
  18.         ;loop close.  //关闭高频
  19. }
  20. testfor @e[name=Scan,score_times_min=7] //操作数等于行中格数执行
  21. {
  22.         tp @e[name=Scan] -112 ~ ~1 //带回行头，绝对坐标保证高频率下不丢方块
  23.         scoreboard players set @e[name=Scan] times 0 //重置操作数
  24.         scoreboard players add @e[name=Scan] htims 1 //换行数+1
  25. }

  27. scoreboard players add @e[name=Scan] times 1 //操作数+1
  28. execute @e[name=Scan] ~ ~ ~ clone ~ ~-1 ~ ~ ~-1 ~ ~ ~-1 ~8 //复印，也就是操作一次
  29. ;loop continue
