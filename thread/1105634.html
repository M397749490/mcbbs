首先 格式是 BeamTarget:{X:<x>,Y:<y>,Z:<z>}其次 坐标是int
  1. execute store result entity @e[tag=123,limit=1] BeamTarget.X int 0.001 run data get entity @p Pos[0] 1000

  3. execute store result entity @e[tag=123,limit=1] BeamTarget.Y int 0.001 run data get entity @p Pos[1] 1000

  5. execute store result entity @e[tag=123,limit=1] BeamTarget.Z int 0.001 run data get entity @p Pos[2] 1000
