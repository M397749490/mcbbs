ServerManager
强大的功能，简单的配置，服务器尽在你手中
不扯闲话先上图



具体功能请自行体验，无法一一截图
1.说明书
根据作者的说明，翻译成中文
该插件具有以下功能
- 停止服务器
- 重载服务器
- 在线更改白名单状态
- 踢出所有玩家
- 清除所有实体
- 难度更改
- 更改白天黑夜
- 更改下雨状态
- 对每个玩家进行配置
- 然而，这一切全部通过可视化界面操作（GUI）
让你轻松控制服务器
2.安装说明
本插件经过本人汉化！（我真的该去睡觉了）
直接放进plugins即可使用，（不想汉化GUI标题了,不影响使用，强迫症请见谅）
3.命令及权限
/menu       权限 sm.menu
仅此一个，简单粗暴
4.配置文件
  1. #是否允许关闭服务器
  2. Stop Server: true
  3. #是否允许重载服务器
  4. Reload Server: true
  5. #是否允许更改白名单
  6. Toggle Whitelist: true
  7. #是否允许调整玩家
  8. Adjust Players: true
  9. #是否允许踢出所有玩家
  10. Kick All Players: true
  11. #是否允许删除所有实体
  12. Remove All Entities: true
  13. #是否允许设置游戏难度
  14. Set Difficulty: true
  15. #是否允许更改日夜
  16. Toggle Day: true
  17. #是否允许更改降水
  18. Toggle Weather: true
复制代码
这都是开关性的配置，辅助不愿意给OP过多功能就关掉一部分吧
5.版本
理论支持1.7.x-1.8.x  本次同样在1.8.7环境下测试，兼容性良好
