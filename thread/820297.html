功能
99%兼容 任何模组/插件/原版 造成的伤害
比如Flan枪械,拔刀发出的幻影剑
100%兼容 任何模组/插件/原版 生物中文名字

三种显示方法 权限控制 任你选 100%可自定义配置

显示方法1:
玩家 攻击/受到 伤害 物品栏上方(action_bar) 提示战斗信息 可自定义文本


显示方法2:
玩家攻击实体时 在实体身上弹出战斗信息 可自定义位置或随机位置 和材质包材质
注意:   方法2 需要材质包才可使用
下载材质包   提取码: g72t


显示方法3:
玩家 攻击/受到 伤害 在 聊天栏 显示战斗信息 可自定义文本


命令
ds reload

1.7.10使用方法

·使用 uranium 服务端至少Dev构建205版本
·使用 uraniumplus Mod最新版


配置文件
  1. # 插件名字
  2. prefix: "§8[§6系统§8] §F> "

  4. # 显示方法 1 的文本
  5. # 对应权限 damageShow.one 默认
  6. # %sh 代表伤害
  7. # %hp 代表血量
  8. # %name 代表名字
  9. damageMes_one_Att: "§a你攻击§C %name §a造成了§C %sh §a伤害§7---§a目标剩余血量§c %hp"
  10. damageMes_one_Atted: "§c你受到了§a %name §c造成的§a %sh §c伤害§7---§c自身剩余血量§a %hp"

  13. # 对应权限 damageShow.two
  14. # 数字一 对应的材质字体 以此类推
  15. 0: "?"
  16. 1: "?"
  17. 2: "?"
  18. 3: "?"
  19. 4: "?"
  20. 5: "?"
  21. 6: "?"
  22. 7: "?"
  23. 8: "?"
  24. 9: "?"

  26. # 跳字的偏移位置
  27. # 就是在被攻击实体的位置上 偏移坐标
  28. X: 1.0
  29. Y: 2.4
  30. Z: 0.0
  31. # 是否启用随机数值
  32. Enable_Random: false
  33. #最大值
  34. MaxX: 2
  35. #最小值
  36. MinX: 1

  38. MaxY: 2
  39. MinY: 1

  41. MaxZ: 2
  42. MinZ: 1

  46. RemoveTime: 300

  50. # 在玩家聊天栏显示
  51. # 对应权限 damageShow.three

  53. # %hp 代表血量
