标题: 怎么删除字符串列表里的指定元素
不知道下标,但是知道字符串
例如xxx:['a','b','c']删除其中的'a'

作者: brooke_zb    时间: 2020-3-3 10:30
本帖最后由 brooke_zb 于 2020-3-3 11:17 编辑

遍历列表。假设往命名空间为test的storage的里List数据值里塞入了["a","b","c"]这个列表
  1. /data modify storage test List set value ["a","b","c"]
复制代码
想要判断列表有没有"c"这个元素，我们可以先创建一个dummy型计分板 num 用于储存列表内元素个数（创建计分板指令就不写了）：
  1. /execute store result score @e[tag=marker] num run data get storage test List
复制代码
然后运行下面的函数获取List列表第一个元素到First，判断First是否为"c"，若是则执行后续指令，若不是则将元素从列表头移动到列表末，并再次执行函数（最多执行次数为列表元素数，相当于变相遍历列表）：
  1. data modify storage test First set from storage test List[0]
  2. execute if data storage test {First:"c"} run 后续指令
  3. execute unless data storage test {First:"c"} run data modify storage test List append from storage test List[0]
  4. execute unless data storage test {First:"c"} run data remove storage test List[0]
  5. scoreboard players remove @e[tag=marker] num 1
  6. execute unless data storage test {First:"c"} if score @e[tag=marker,limit=1] num matches 1.. run function 再次执行这个函数
