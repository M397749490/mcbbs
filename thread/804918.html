[ Exchangers - 方块交换器 ]
MOD作用（特性）（原文）
  • Configurable durability / RF capacity for all exchangers (except the special variants)
  • Configurable RF usage per block for all RF-based exchangers
  • All RF-based exchangers supports Forge Energy (FE)
  • All vanilla-based exchangers (except Wooden Exchanger) can be repaired with the correct materials in Anvil
  • Regular Exchangers can exchange up to a 15x15 area, depending on the tier. Creative Exchanger can exchange up to 25x25 area (Configurable via config as of 1.8.3 for 1.10 / 1.11 or 1.7.3 for 1.12)
  • Config options to tweak recipe difficulties, there are 3 difficulties: easy, normal and hard, normal is the default option, modpack makers can choose whatever preset they want or use CraftTweaker to make their own recipes
  • Indicators for the current exchanger area next to crosshair
  • In-game config GUI, without the need of going to find and edit the config file manually (certain things require you to restart the game for the new values to be applied)
  • Easy to increase / decrease exchange range (Pressing the mode key increases range and holding sneak + pressing mode key decreases range, mode key is bound to "Comma" by default)
  • Force Drop Items mode, which forces items to drop on the floor even if there's inventory space
  • Harvest level gating system, harvest level on Exchangers goes up whenever you upgrade
  • Item containers support (only for item containers with IItemHandler capability implemented, such as /dank/null and Bag of Holding), Exchangers are able to pull blocks from item containers if there's no blocks in players' main inventory
  • Config option for Silk Touch mode, enabled by default
  • Enchantments support, if Silk Touch mode is disabled, players may enchant the Exchangers with Silk Touch to achieve Silk Touching on Exchangers or Fortune to get additional drops. There's also support for Holding enchant (increases RF capacity) and Unbreaking enchant (reduces chance of consuming RF per block) for RF-based exchangers
  • If you're a Patreon or Twitch subscriber of mine, you may have your own special cape in-game with Exchangers installed
译文
  • 各个交换器的耐久或RF的容量可以在config里面调整
  • 转移一个方块所消耗的RF可调整
  • 使用支持RF的交换器均支持FE
  • 所有原版交换器可以在铁毡里修复
  • 原版交换器最多能一次换13x13的方块，创造交换器一次可以换25x25的方块
  • 物品合成有三个等级：easy，normal，hard。默认normal，可以在config里面调整
  • 交换器可以显示交换的范围
  • 你可以在游戏中修改config而不是打开config文件夹用记事本修改
  • 你可以拿着交换器，按住“，”键，再右键来修改交换区域大小
  • 你可以拿着交换器，按住“。”键，再右键来修改是否强制掉落，强制掉落回物品栏里
  • 交换器有挖掘等级
  • 交换器支持含有背包的mod，物品栏空间不够时会放背包里
  • 你可以在config里面调整是否开启精准采集，默认开启
  • 你可以给交换器附魔，除了精准采集
  • 你可以在patern或者twitch上面成为作者的粉丝并分享游戏中的趣事给作者
