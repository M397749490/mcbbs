CuStom GOJoinPrice
自定义队列组队附属JoinPrice

CuStomeGo附属,东西都没有你也想进入副本？

附属简绍

CuStomeGo-JoinPrice是CuStomGo的相关附属插件,本次附属插件扩展了CuStomeGo的对于加入副本的条件判断,本插件可以做到对加入需求进行限制,和加入消耗进行限制两个部分。每天一次的藏宝图,不来试试吗？
CuStomeGo-JoinPrice是基于CuStomeGo的扩展,如果你想食用本插件请安装CustomeGo本体插件

||>>>CuStomeGo<<<||
||--------------------------||

食用方法
配置
#在这里编辑加入需求。
#Need下的设置意味着只有玩家有足够的要求物才可以进入游戏。但是并不消耗要求物。
JoinPrice:
  Need:
    Money: 0
#这里设置金钱。
    Points: 0
#这里设置点券。
    Level: 50
#这里设置等级。
    Items: 幻境之钥_1,梦碎片_20
#这里设置物品。
#在这里编辑加入消耗。
#Consume下的设置意味着加入消耗相应物品。所有消耗物一旦多于要求物的设置，自动调为要求物。
  Consume:
    Money: 0
#这里设置金钱。
    Points: 0
#这里设置点券。
    Level: 0
#这里设置等级。
    Items: 梦碎片_20
#这里设置物品。
#注：物品编辑格式:"物品名1_数量,物品名2_数量...."。数量必须小于最大叠加。
#其中,物品名只需要关键字，但不支持处理含同关键字的不同物品。


#以上加入需求设置表示：

#玩家要50等级和一把幻境之钥作为加入要求，消耗20梦碎片，才能够加入这场游戏
