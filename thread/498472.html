ServerShop-GUI是一个购物系统。它允许玩家购买自定义的商品列表。它使用一个GUI库存显示商店。这个插件需要Vault插件
特性
可以在商店里放任何你想要的物品
可配置数量和价格
轻量、简单使用的插件
打开商店用右键单击定义项或命令
支持多个商店
商店大小可定制
可出售权限
可花钱执行命令
可花钱执行控制台命令
可自定义商品描述
支持附魔
自定义显示名称
自带点券系统


使用界面
单击一个项目去购买它即可。
Config(配置文件解读)
config.yml
# ---------------------------------------------- #
#                常规配置                            #
# ---------------------------------------------- #
main:
  # 主面板大小选择(27则是3行，一行9格) PS:主面板就是输入/shop的面板，打开以后还有商店选择！不要搞混了！
  slots: 27
  # 是否启用指令，如果启用则可以使用/shop打开商店
  enableCommand: true
  # 是否可以使用物品打开商店
  enableItem: false
  # 使用物品打开商店,COMPASS=指南针(上面的必须是true)
  shopOpenWithItem: COMPASS
  # 如果设置为true，将会阻止这些命令
  # 例子:
  # 如果你出售命令：/money 它将只能在商店买到(无法在聊天窗口输入这个命令)
  # 玩家将会无法使用 /money 但是如果你把这个指令放在PlayerCommand，就可以使用了
  blockbuyablecommands: false
  
  #是否启用日志 (日志目录:/plugins/ServerShop-GUI/logs)
  EnableLogs: false
  
  # 是否启用声音(点击购买的时候响起声音)
  EnableClickSound: true
  
  # 是否启用Metrics(作者：如果你启用他，我将会很感激你)
  EnableMetrics: true
  
  # 是否在后台输出更多信息
  Debug: false
  
  #启用它的话将会重置你的配置！
  #千万不要手贱！！！
  firststart: false
  
  #The Item you wish to use for the Item Currency (Pay with Items as price) PS：这里不会翻译...
  Item_Currency: EMERALD
#商店列表  
  list:
#这个“0”是你这个项目在GUI中的位置
  '0':
    # 商店库存大小 相关文件:"Items.yml"
    size: 27
    #这是你的商店名字，它将会自动创建一个yml文件(填写为Items，创建出来的文件就叫做Items.yml)
    name: Items
    #商店图标(Wood是木头，当然你还可以弄成Wood:3)
    icon: Wood
    #商店描述 PS:支持颜色代码
    description:
    - '&6This is the new default'
    - description for your shop
    - '&6Have fun.'
    #是否显示返回按钮(点击按钮可以回到主面板)
    returnbutton: true

指令权限
/shop
说明: 打开商店主面板
所需权限: 无需权限

/shop <name>
说明: 打开某一个商店
所需权限: shop.open.<商店名字>

/shop reload
说明: 重载插件
所需权限: shop.reload

/shop createnpc <NPC名字> <商店名字>
说明: 创建一个NPC用于打开某一个商店
所需权限: shop.npc.create

/shop help
说明: 查看指令帮助
所需权限: 无需权限

/shop info
说明: 查看商店信息
所需权限: 无需权限

/shop version
说明: 查看插件版本
所需权限: 无需权限

蹲下+右击一个NPC来删除
说明: 删除掉右击的NPC
权限需求: shop.npc.remove

打开商店需要的权限:
说明: 玩家需要这个权限来打开商店
权限需求: shop.open.<商店名字>

通过NPC打开商店所需要的权限:
说明: 玩家需要这个权限来通过NPC打开商店
权限需求: shop.npc.interact

无视商店关闭
说明: 如果你在配置文件里面关闭了某个商店,这个权限可以无视关闭
权限需求: shop.command.bypass

单个物品栏
说明: 如果你在配置文件打开了每一个物品栏都需要一个权限, 你可以用这个权限来给予玩家相应的物品栏
权限需求: shop.<商店名字>.<物品栏数字>
例子: shop.simon3000.5 -> 这个权限允许玩家购买名为simon3000的商店第五个物品栏的物品

点券命令
/tokens
说明: 查看你的点券余额
权限需求： 无

/tokens balance <player>
说明：查看其它玩家的点券余额
权限需求: tokens.balance.others

/tokens add <player> <amount>
说明: 给某个玩家添加一定数量的点券
权限需求: tokens.add
栗子：/tokens add Lonelier 100 就说明给Lonelier添加了100点券

/tokens take <player> <amount>
说明：扣除某个玩家一定数量的点券
权限需求: tokens.take
栗子：/tokens take Lonelier 100 就说明扣除了Lonelier的100点券

/tokens send <player> <amount>
说明: 从自己的点券中给某个玩家一定数量的点券
权限需求: tokens.send
栗子：/tokens send Lonelier 100 给某个玩家100点券，并扣除了自己的100点券

/tokens set <player> <amount>
说明：设置某个玩家的点券数量
权限需求: tokens.set
栗子：/tokens set Lonelier 1000 设置Lonelier的点券数量为1000
