要求服务器允许波兰服务器访问
要求外网可以访问的服务器
也许以后会换成中国服务器


查询方式有两种：
1、需要服务器Query端口开启
2、任何Minecraft服务器（能正常进入的服务器）
PE服务器需要打开Query端口查询，第二种方法不可用


进入正题
返回json

Server_info_new（第一种查询方式）

请求地址：http://gdenga.evai.pl/Server_info_new.php

请求参数：
参数 方式 描述 示例
ip Post/Get 要查询服务器的ip play.rhymc.cn
port Post/Get 要查询服务器的端口 可空，默认25565


请求示例
  1. http://gdenga.evai.pl/Server_info_new.php?ip=127.0.0.1&port=25566
复制代码


响应参数:

参数类型 描述 示例
Time String 服务器请求时间 A Minecraft Server
Info Serverinfo 服务器信息
   └ HostName String 服务器描述 A Minecraft Server
   └ GameType String 服务器游戏模式SMP
   └ GameName String 游戏名字 MINECRAFT
   └ Version String 游戏版本 1.7.10
   └ Plugins String 服务器插件 Essentials 2.12.2

   └ Players Number 服务器在线人数 10
   └ MaxPlayers Number 服务器最大人数 2018
   └ HostPort Number 服务器端口 25566
   └ HostIp String 服务器地址 127.0.0.1
   └ RawPlugins String 原始插件 tpLogin 1.5.1
   └ Software String 核心信息 KCauldron 1.7.10
Player String 在线玩家信息
