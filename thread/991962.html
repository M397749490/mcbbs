指令

  1. 我相信有很多玩家在服务器里建房子被拆掉吧  有了它 你就不用怕了^ ^
  2. 领地设置方法 ：斧头（有的不是斧头，有的是木棒 木锄之类的）点击左键设为坐标1,点击右键设为坐标2.两坐标形成对角线形成长方形领地.
  3. 领地指令有：/res create [领地名] - 选择好区域后创建一个叫做[领地名]的领地
  4. 　　             /res remove [领地名] - 移除一个叫[领地名]的领地 /res removeall - 移除所有领地
  5. 　　             /res subzone <领地名> [子区域名] - 在领地内创建一块子区域，你必须是所有者才行。
  6. 　　             /res info [领地名] - 查询领地权
  7.                                    以下为权限设置(true为开启，false为关闭)
  8. 　　             /res set 【领地**具体权限】 true/false 将你的领地设定权限是否开启
  9. 　　             /res pset 【领地**玩家名字**具体权限】 true/false 将你的领地开放或关闭给某玩家一个具体的权限（适用于小伙伴）
  10. 具体权限有：admin：领地的全权管理权限，仅能给与某玩家
  11. 　　             container：是否能使用箱子，发射器等
  12. 　　            bucket：设置是否能使用桶
  13. 　　            ignite：点火的权限
  14. 　　            piston：活塞是否能使用
  15.                    build：建造权限(包括destroy和place)
  16. 　　            destroy：毁坏权限
  17. 　　            place：放置权限e
  18. 　　            move：进入权限
  19. 　　            tp：传送权限
  20. 　　            use：使用权限(工作台，炉子等)
  21. 　　            subzone：是否能设置子空间
  22. 　　            tnt：设置tnt是否有效
  23. 　　            creeper：设置JJ怪是否有效(设置F的话JJ怪就废了)
  24. 　　            damage：设置领地内是否能造成伤害(不能防止被挤死)
  25. 　　            monsters：设置是否刷新怪物
  26. 　　            animals：设置是否刷新动物
  27. 　　            firespread：火是否能蔓延
  28. 　　            flow：液体流动，包括waterflow和lavaflow
  29. 　　            waterflow：水的流动
  30. 　　            lavaflow：岩浆流动
  31. 　　            healing：设置是否能恢复生命
  32. 　　            pvp：设置是否能pvp
  33. 设置子空间：
  34. 　　如同设置领地一样选择区域，不同的是之后输入“/res subzone 123 abc”(例)设置母领地为123的名为abc的子空间，
  35. 　　该区域的权限设置和移除则需要将领地名变为123.abc，无则默认为当前所处领地(在子空间则为子空间)。

  37. No.3（3）指令篇之——不常用命令
  38. 有一些不常用命令 了解就行

  40. 信息命令
  41. /res area list [领地名] - 列出某领地的所有区域
  42. /res area listall [领地名] - 列出某领地的所有区域以及他们的坐标
  43. /res current - 显示你所在的领地
  44. /res info <领地名> - 得到某领地的信息
  45. /res list - 显示你拥有的领地
  46. /res listall - 显示所有领地
  47. /res limits - 显示重要的权限
  48. /res sublist - 显示你所在领地的所有子区域
  49. /res version - 显示插件版本

  51. 选择命令：
  52. /res select [x] [y] [z] - 选择领地的长方体区域，X Y 和Z 都是从你当前位置为中心的距离，你也可以用一个工具（默认是蛛丝）来选择地块。
  53. /res select chunk - 选取一整个chunk。
  54. /res select expand [格数] - 向你的前方延伸选区。
  55. /res select size - 显示已选择区域的尺寸。
  56. /res select shift [格数] - 向你的前方移动选区。
  57. /res select vert - 把选区延伸到从天顶到地底。

  59. 权限命令
  60. /res gset <领地名> [群组名] [权限] [true/false/remove] - 设置某领地对于某群组的权限
  61. /res lset <领地名> [黑名单/忽略名单] [材质] - 从某领地的黑名单/忽略名单中增加/移除某材质
  62. /res lset <领地名> info - 显示某领地的黑名单/忽略名单设置
  63. /res pset <领地名> [玩家名] [权限] [true/false/remove] - 设置某领地对于某玩家的权限
  64. /res set <领地名> [权限] [true/false/remove] - 设置某领地的权限

  66. 交易命令
  67. /res lease [renew/cost] [领地名] - 更新/显示 更新一个领地的费用（？意义不明）
  68. /res market list - 显示在售的所有领地
  69. /res market info [领地名] - 显示在售的某领地的信息
  70. /res market sell [领地名] [价格] - 将某领地出售
  71. /res market unsell [领地名] - 将某领地下架
  72. /res market buy [领地名] 购买某领地
  73. /res market rentable [领地名] [价格] [天数] <repeat:t/f> - 将某领地以[价格]/[天数]出租并设置可否自动续期
  74. /res market rent [领地名] <repeat:t/f> - 设置某领地出租手否可自动续期
  75. /res market release [领地名] - 解除某领地的出租

  77. 管理命令
  78. /resadmin lease set [领地名] [#天数/infinite] - 设置领地的时间限制或不限时
  79. /resadmin removeall [玩家名] - 移除某玩家的所有领地
  80. /resadmin setowner [领地名] [玩家名] - 将某领地以交给某玩家
  81. /resadmin server [领地名] - 将某领地设置为服务器领地
  82. /resload - 载入领地插件. *注* 在res.yml的任何改变都不会被还原. 你可以再更改过res.yml后想立即将新设置生效的时候使用此命令
  83. /rereload - 重载领地插件. *注* 将会还原res.yml为初始状态. 如果你在res.yml更改过设置请不要使用此命令

变量
  • ％residence_user_current_owner％ -返回当前的居民所有者名称
  • ％residence_user_current_rentends ％ -返回租金结束的时间
  • ％ Residence_user_current_rentdays ％ -返回您可以租用区域的天数
  • ％ resident_user_current_rentedby ％ -返回正在出租区域的玩家名称
  • ％ Residence_user_current_rentprice ％ -返回其租金的地区价格
  • ％ Residence_user_current_forrent ％ -如果该区域要出租，则返回true或false
  • ％ Residence_user_current_saleprice ％ -退货价格
  • ％ Residence_user_current_forsale ％ -如果要出售的区域，则返回true或false
  • ％ Residence_user_current_ssize ％ -返回以平方（x * z）为单位的居住面积
  • ％ Residence_user_current_qsize ％ -以立方（x * z * y）返回居住面积
  • ％ resident_user_current_bank ％ -返回居民银行的金额
  • ％ resident_user_current_res ％ -返回当前居住地的名称
  • ％ Residence_user_blocksell ％ -退还玩家的大卖出金额
  • ％ Residence_user_blockcost ％ -返回玩家的块购买费用
  • ％ Residence_user_maxrentdays ％ -返回玩家的最高租金天数
  • ％ Residence_user_maxrents ％ -返回玩家可拥有的最大可出租住宅数量
  • ％ Residence_user_maxsubdepth ％ -返回允许的最大分区深度
  • ％ Residence_user_maxsub ％ -返回玩家可以拥有的最大分区数量
  • ％ Residence_user_maxud ％ -返回最大高度
  • ％ Residence_user_maxew ％ -返回最大长度（以长度为单位）
  • ％ Residence_user_maxres ％ -返回最大宽度
  • ％ resident_user_cancreate ％ -如果玩家可以创建居住地，则返回true或false
  • ％ Residence_user_amount ％ -返回玩家当前拥有的居住数量
  • ％ Residence_user_admin ％ -返回true或false，这取决于播放器是否为res admin
  • ％ resident_user_group ％ -返回玩家居住组
