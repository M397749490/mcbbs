创建个txt文本文档
然后输入：
@ECHO OFF
java -Xms1g -Xmx1g -jar <此处换成你下载到的文件的文件名>.jar
pause
保存，重命名为xxx.bat   一定要后缀的bat
文件名一般是 craftbukkit-几点几之类的
