這個世界,被人們稱為創世神,
而這裡有個村莊...
在離村莊不遠的地方有著一群殭屍,
當太陽逐漸西下,
黑夜來臨時,
白天躲在陰暗處的殭屍們,
總是會來攻擊村莊,
使得村民們飽受生命威脅。
這次! 村民們再也忍無可忍了,
村裡年輕的少年,為了擊退這股惡勢力,
紛紛自告奮勇成立村民聯合軍。
就這樣,殭屍與村民各自成立了大陣營,
這場一觸即發的大戰爭即將開打！



版本 : 1.9
建議人數 : 3 vs 3 以上 (6人以上) ~ 8 vs 8 (16人)
遊戲簡介說明 :
玩家 分為兩個陣營 ( 紅、綠 )
雙方陣營都有一個陣營主塔
當陣營內陣營核心 被破壞則會扣除 陣營生命值
