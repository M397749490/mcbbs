介绍和前言：
  • 该插件翻译质量取决于各自翻译平台，与插件无关。
  • 支持多种翻译渠道，默认首选谷歌翻译，但不能频繁请求（请求翻译间隔不能短）。
  • 翻译过程是异步的，不影响主线程的运行，几乎不影响服务器性能！
  • 配置文件需要为 UTF-8 的编码，如果配置文件内只有英文，那么常见编码也能够读取！
  • 配置文件中的翻译间隔( interval )请不要设置过小，否则容易被谷歌翻译或有道翻译临时性封禁 IP 以禁止请求翻译。
  • 如果有条件，请尽量使用百度翻译(默认不可用，需要根据上方教程进行配置才可用)。
  • 禁止发布使用本插件汉化的配置文件不做处理就发布至 MCBBS，违者后果自负！
  • 本插件为洛神团队编写，完全免费，严禁倒卖、未经允许转载至其他地方（例如其他网站或者论坛）

使用百度翻译进行翻译：
优点：
  • 可翻译次数无限。
  • 质量相对较高、国内响应速度快。

缺点：
  • 由于百度翻译API免费版的限制
  • 每秒只能接受一次翻译(可以通过购买高级版解除限制)
  • 并且需要指定 IP 地址


第一步：
前往 这里 注册申请开发者，如果没有百度账号请先注册

第二步：
  • 查看自己的开发者信息，点击查看
  • 根据申请信息里的 APP ID 和 密钥
  • 填写 TranslateTool 的 配置文件：config.yml，如下：
  红字部分为需要修改的地方
# 可选：Google, Baidu, Tencent, Youdao
# 目前稳定可用的只有 Google, Youdao
# Baidu 几乎无法使用
type: 'Baidu'
# 每次查询的间隔 毫秒，如果间隔过短, 容易出现长期拒绝访问!
interval: 2000

source:
  baidu:
    # 为了更稳定
    # 是否启用自己的百度翻译接口
    enabled: true
    # appid 和 security_key,
    # 需要去百度官方获取, 地址: https://api.fanyi.baidu.com/ , 申请成为开发者
    # 在个人信息页面查看
    app_id: '这里填写你的 APP ID'
    security_key: '这里填写你的 密钥'

第三步：
  • 在控制台输入 tt reload 或者重新启动服务器
  • 输入 tt config <你的配置文件路径> 来体验百度翻译



配置文件：
  1. # 可选：Google, Baidu, Tencent, Youdao
  2. # 目前稳定可用的只有 Google, Youdao
  3. # Tencent 几乎无法使用
  4. type: 'Google'

  6. interval: 2000

  15.     # 在个人信息页面查看

  17.     security_key: ''
