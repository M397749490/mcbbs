⚙ 如何安装

  • 确保服务器未运行
  • 将插件放在插件文件夹中
  • 启动服务器以生成所需的文件和配置
  • 设置插件作为服务器的世界生成器：

    1. 原版添加: 到 bukkit.yml 中添加下列代码
    1. worlds:
    2.   <世界的名字>:
    3.     generator: Realistic_World
    复制代码
    2. 如果使用多世界 Multiworld: 使用下列命令创建一个RWG世界
    1. /mw create <世界的名字> plugin:Realistic_World
    复制代码
    3. 如果使用多世界 Multiverse: 使用下列命令创建一个RWG世界
    1. /mv create <世界的名字> NORMAL -g Realistic_World
    复制代码

🙅‍ 使用须知

实际上，这里有一些东西你应该先了解一下：
  • 这个插件使用反盗版系统。您可以在八个不同的 IP 上使用相同许可证运行插件。如果在三个以上不同的 IP 上同时使用插件，许可证会被ban掉。但是可以通过向插件成员发送私聊来解锁！
  • 此插件使用匿名统计系统来改进我们的服务。您可以在插件中禁用它。(每15分钟给服务器发HTTP请求, 别用YUM否则后台会炸)
  • 无法使用原版的末影之眼找到地牢的特性，插件团队正在为此努力。
  • 可以通过 PSC 购买，需要 discord 私聊作者 (感谢 #3 补充, 是PaySafe Card的意思)

🙏 我的碎碎念

高版本(1.14+) 服务器，如果想流畅运行 RWG 需要强劲的服务器性能高版本建议预生成一定大小的世界防止跑图崩溃：预生成世界可以通过 WorldBorder 实现：
  • 安装插件 WorldBorder
  • 首先确保世界能够正常通过RWG生成
  • 开服
  • 输入 /wb <世界名> set <预生成范围X> <预生成范围Z>
  • 输入 /wb <世界名> fill 3 208 false
  • 跟着 WorldBorder 的提示走，就可以了
另外，RWG 它首次使用需要到服务器下载地形信息，要确保你能访问他们的服务器，否则建议你先在国外服务器上下载，然后复制数据到国内服务器
