作者: lzs1234    时间: 2016-3-19 14:53
1L的指令会导致全地图所有鸡都有效果
前置计分板：
/scoreboard objectives add a dummy

/summon Chicken ~ ~1 ~ {Invulnerable:1b,NoAI:1b}
高频连接：
/scoreboard players set @e[type=Chicken] a 1 {Invulnerable:1b,NoAI:1b}
/execute @e[score_a_min=1] ~ ~ ~ particle enchantmenttable ~ ~ ~ 0 0 0 1
系统结束
Invulnerable是无敌NBT，NoAI会固定生物
