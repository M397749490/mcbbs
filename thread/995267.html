MarketPlace [mp,maple]

  • /mp create <name>  创建一个摊位
  • /mp name <name>  重命名你的摊位名字
  • /mp open  打开你的摊位
  • /mp price <cost>  上架你手上的物品
  • mp priceall <cost>  将正在售卖的物品统一定价
  • /mp reload  重载插件
  • /mp help  插件帮助


World Region [mpr,mapler]

  • /mpr create <name>  创建一个可摆摊的区域
  • /mpr delete <name>  删除一个可摆摊的区域
  • /mpr A|B  
  • /mpr status <name>  区域信息
  • /mpr list  列出目前规划的区域
  • /mpr check <name>  检车某个区域
  • /mpr help  插件帮助
