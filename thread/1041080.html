看错问题了，请忽略
====


你把yml里面 Enchantment_Drop_Rates 里面每一项Tier的数值都改成0应该就可以了。

原文是这样的：
  1. Enchantment_Drop_Rates:
  2.     Tier_1:
  3.         COMMON: 5.00
  4.         UNCOMMON: 1.00
  5.         RARE: 0.10
  6.         EPIC: 0.01
  7.         LEGENDARY: 0.01
复制代码


每一个改成：
  1. Enchantment_Drop_Rates:
  2.     Tier_1:
  3.         COMMON: 0
  4.         UNCOMMON: 0
  5.         RARE: 0
  6.         EPIC: 0
  7.         LEGENDARY: 0
复制代码




====

或者把Enchantments_Rarity里面的所有附魔书都删除掉，变成
  1. Enchantments_Rarity:
  2.     COMMON:
  3.     UNCOMMON:
  4.     RARE:
  5.     EPIC:
  6.     LEGENDARY:
复制代码


两个之中其中一个做了应该就可以了
