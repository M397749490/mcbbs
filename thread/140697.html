Minecraft中文论坛友情提示：

由于Minecraft 1.7.4加入了Twitch直播功能，故本启动器无法完全兼容Minecraft 1.7.4以及之后版本。
若作者更新启动器，请自行删除本提示，并联系版主去除“过期”标记。


    由于官方的1.6更新，多款启动器已经无法启动1.6版本，故自开发的一个新的启动器，Akarin Launcher，自己使用。现在也将其发布，供各位Minecraft玩家使用，启动器问题较多，请指教。

  • 特点
  • 全面设置 —— 用户可自由设置游戏窗口大小、游戏文件路径、启动参数等。
  • 全版本支持 —— 不管是Minecraft 1.5.2 也好，1.2.5也好，最新的1.6.2包括其Forge版本都可以支持！
  • 多版本管理 —— 类似官方新启动器，可以配置多个版本，每个版本的位置都可以在不同的路径里。
  • 模组加载 —— 对于1.6以上的Forge客户端，可以使用外挂的模组加载。（Mod支持的版本必须与当前版本一致）
  • Json文件读取 —— 通过读取Json，可以提高Forge成功启动的机率。
  • 游戏下载 —— 从官方的服务器下载快照和发布版本。
  • 正版登陆　——　方便正版玩家使用，也可以使用不认证的离线模式。
  • 正版助手　——　方便正版玩家转换官方启动器的配置文件到Akarin Launcher可以使用的版本文件。
  • 标题信息 —— 在游戏窗口的标题处显示 FPS 、运行时间这些信息。
  • 新鲜血液 —— 即使没有人使用，作者我也会继续更新的。（能持续到年末就不错了）
  • C#.Net 打造 —— .Net 框架在Windows良好高效的使用体验。
  • 较繁琐的操作 —— 可能需要一些时间才能入门，不符合KISS理念。
  • 难看的界面 ——　作者的美工不好，难以做出美观的启动器。(现在可以自定义图片背景，但是惨不忍睹)

    （1.5等版本默认在工作路径下自动创建.minecraft文件夹。而1.6版本不会，所以1.6版本可以选择任意路径，存档也保存在那个路径）。

  • 使用事项
    须将zip压缩包中的全部文件都解压至同一目录下。
    启动器可以放在任意目录下，不一定要和 .minecraft 放在一起。
    如果和 .minecraft 放在一起，第一次启动后会提示是否导入 .minecraft 文件夹里的游戏。

  • 系统需求
    安装有 Microsoft .NET Framework 2.0 SP1 的系统 SP1 推荐直接安装SP2：
        理论可支持的系统：Windows XP SP2、SP3 32bit、Windows Vista SP1、SP2 32/64bit 、Windows 7 (SP1) 32/64bit 、Windows8 32/64bit、Windows 8.1
        未测试的系统： Windows 2000
    Java 6 (推荐使用 Java 7)

  • 安全
    通过VirSCAN.org的检查，全部无报毒。
    如果使用360安全软件提示报毒，请完全关闭360软件。
