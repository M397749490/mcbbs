[Mod简介]

这个轻量级的Mod添加了一些实用的指令

比如/day 设定成白天，/night 设定成晚上

目前作者在持续更新，详细指令请看指令表


[指令表]



  • /killall - 杀死所有人，当然，包括你自己
  • /kys -杀死你自己
  • /explode - 让你自己爆炸
  • /gms - 更换为生存模式
  • /gmc - 更换为创造模式
  • /gma - 更换为冒险模式
  • /gmsp - 更换为观察者模式
  • /day - 将时间调整至白天，效果等同于/time set day
  • /night - 将时间调整至晚上，效果等同于/time set night
  • /heal - 治疗自己并恢复饱食度
  • /speed1~speed10 - 获得永久速度Buff，比如/speed1获得速度II效果，/speed2获得速度III效果
