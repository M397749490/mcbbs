二：字符显示支持不同字体
按照官方的说法，字符显示增加了font属性，用于控制字符字体，Minecraft默认字体是minecraft:default，而其他字体则需要通过资源包添加，顺带一提，mojang借此优化了字体切换，设置→语言→强制使用Unicode字体将不再需要等待重载（一小会卡顿

如下：资源包内font文件夹创建了test.json，使用了一个TTF字体，游戏内并不会影响原有字体，而在聊天组件中使用"font":"test"后则可以改变为指定字体

三：attribute指令
mojang允许修改玩家属性了你敢信？相信不少Cber会感叹一句“MJNB！”
attribute指令允许修改/获取实体的属性值，包括最大生命值、盔甲值、速度值等。
那和使用data有什么区别？该指令允许以玩家为目标！（经测试修改移动速度base值以及玩家并不拥有的属性无效）
趁血条不注意一拳打死凋零？
修饰语使用例
  1. attribute @s minecraft:generic.attack_damage modifier add 1-1-1-1-1 test 100 add

该指令用法为
  • attribute <target> <attribute> get [<scale>] - 获取目标对应属性总数值
  • attribute <target> <attribute> base set <value> - 设置基础数值
  • attribute <target> <attribute> base get [<scale>] - 获取基础数值
  • attribute <target> <attribute> modifier add <uuid> <name> <value> add|multiply|multiply_base - 添加修饰语
  • attribute <target> <attribute> modifier remove <uuid> - 移除修饰语
  • attribute <target> <attribute> modifier value get <uuid> [<scale>] - 获取修饰语数值
  • target - 目标实体
  • attribute - 属性名称 (类似 minecraft:generic.attack_damage)
  • name - 描述修饰语的字符串
  • value - 浮点值
