标题: Residence领地插件如何默认OP拥有所有权限。查水表用
如题。玩家圈地了OP没有使用权限。用/resadmin指令又会留下痕迹。如何才能查水表而不被发现。求大神
作者: xRPQx    时间: 2015-12-24 18:44
打开config
修改

  # 是否仅允许 OP 和拥有 'residence.admin' 权限的玩家 无视领地flag 和修改领地.
    AdminOnlyCommands: true
    # 设置为'true'让OP具有领地管理员权限.
    AdminOPs: true

修改为true即可
