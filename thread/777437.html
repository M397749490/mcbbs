建议手动安装：
1）在bbs先下载.minecraft纯净版的文件下来
2）也是在bbs下载hmcl等启动器，放在和.minecraft文件夹同级目录下并启动游戏。（1.7版本之后hmcl会自动补全游戏缺失文件）
3）从forge官网下载对应版本的forge安装包，安装时候选择client并填好.minecraft绝对路径
4）成功安装并启动一次之后.minecraft文件夹内version文件夹会多出一个forge的版本文件夹并且.minecraft文件夹多出mods文件夹，mod丢进去就好了。
ps:别人的整合包没几个好用的...大多数都是为了经验然后扣别人整合好的整合包再把mod丢进去
forge官网：https://files.minecraftforge.net

这种解决办法应对是的核显老显卡在win10下的问题。
是不是这种问题可以通过游戏目录C:\MCLDownload\Game\账号名\MCGame\游戏名\.minecraft\crash-reports里边的文件查看：
包含如下错误信息：
org.lwjgl.LWJGLException: Pixel format not accelerated
OpenGL: ~~ERROR~~ RuntimeException: No OpenGL context found in the current thread.

这种问题论坛官方给出的任何办法都无法解决，
这种问题主因是Intel没有为HD3000/HD2000/HD Graphics这些一代及二代的老核显为Win10更新驱动，OpenGL的DLL就无法被加载。
所以有大神给这种核显驱动的OpenGL写了patch。
问题解决办法参考：https://github.com/LWJGL/lwjgl/issues/119
使用补丁：https://github.com/LWJGL/lwjgl/f ... -bit.Fix.by.MST.zip
安装即可。
但是有可能ig4icd64.dll会Error。需要把c:\windows\system32中的ig4icd64.dll复制到c:\windows\syswow64，然后再patch，patch之后再把syswow64下的ig4icd64.dll剪切回system32下
