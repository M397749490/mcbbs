传送弓——TeleportBow

现在，小游戏服务器腐竹的福音到了！
如果，你的服务器大厅够大够炫酷
但是缺点来了
玩家在跑图的情况下需要跑很久呢！
这个插件完美解决这一问题！
让你在炫酷的传送中迅速到达你想到的位置！
生存服务器也可以用，但是注意使用方法！

当你看到别的服务器的传送弓的时候，眼里会迸发嫉妒火花吗？

不用再看了！！这里就有！！




英文版本（还没汉化，汉化完后会第一时间更新！）

这个插件可以做什么?

其实很简单，就是拉这把弓，你会瞬移到箭射到的位置

权限在哪里?

  • 只有一个呢！:teleportbow.use
我如何设置这个插件呢?

  • 去插件的文件夹/ TeleportBow config.yml

  • 来选择世界，这将决定那个世界将运行这个插件

  • （MW应该可以）
配置文件：修改这个就行# this  World

world:

# can Work?

enable:true

# this World

world_nether:

# can Work?

enable:true

# this  World

world_the_end:

# can  Work?enable:true
