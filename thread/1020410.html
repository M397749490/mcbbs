指令只适用于单人，需要打开死亡不掉落（如果不想保存经验就关掉）
1.12：
创建两个记分板
/scoreboard objectives add jfbdc deathCount
/scoreboard objectives add jfbd dummy
三个循环命令方块
/execute @a[score_jfdbc_min=1] ~ ~ ~ scoreboard players set @a jfbd 1
/execute @a[score_jfbd_min=1] ~ ~ ~ scoreboard players set @a jfbdc 0
/execute @a[score_jfbd_min=1] ~ ~ ~ clear @a
在最后一个循环命令方块后面接五个有条件连锁命令方块
/replaceitem entity @a armor.chest  <胸甲ID>
/replaceitem entity @a armor.feet <靴子ID>
/replaceitem entity @a armor.head <头盔ID>
/replaceitem entity @a armor.legs <护腿ID>
/scoreboard players set @a jfbd 0

原理：玩家死亡时清除除经验外所有物品，然后用命令将装备装到头上
缺点：
1、耐久会补满
2、每次换盔甲就需要修改命令
