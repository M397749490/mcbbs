CraftNotify
--------------------------------
卡服崩服邮件通知。

发送邮件
--------------------------------
  • 当服务器崩溃之后
  • 当服务器有点卡顿
  • 当服务器状况未知

配置文件
--------------------------------
server:
    # 可以随便填服务器名
    name: The minecraft server name
    notify:
        lagged:
            # TPS低于多少时发邮件
            threshold: 15
notify:
    # 填你的邮箱地址
    from: 'mengcraft@qq.com'
    smtp:
        # 填你的邮箱SMTP主机
        # 用QQ邮箱的童鞋要开通SMTP才行
        host: smtp.qq.com
        port: 25
        user: mengcraft
        # 用QQ邮箱的童鞋填邮箱独立密码
        pass: anyPassword
        # 是否使用SSL加密通信
        # 取决于SMTP主机是否要
        sign: false
    send:
    # 邮件收件人列表
    # 留空则发给自己
    - 'hahaha@qq.com'

使用协议
--------------------------------
本插件依GPLv2发布，请使用者遵守该协议。
