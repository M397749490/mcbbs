怎么禁止玩家使用nick 昵称
作者: Smaoll    时间: 2015-4-11 18:18
用notepad++打开 \plugins\Essentials\config.yml

找到全局设置
  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |                Essentials 全局设置                   | #
  4. # +------------------------------------------------------+ #
  5. ############################################################
复制代码


在其以下有一个配置项
  1. # 命令黑名单,冻结的命令在服务器将完全不可使用.
  2. # 当命令冲突时,在此禁用将无效果
  3. disabled-commands:
  4. #  - nick
  5. #  - clear
复制代码

然后将nick前面的"#"去掉保存，如下
  1. # 命令黑名单,冻结的命令在服务器将完全不可使用.
  2. # 当命令冲突时,在此禁用将无效果
  3. disabled-commands:
  4.   - nick
  5. #  - clear
复制代码


最后重启服务器，完成。望采纳！

有些服务器的权限组插件会有些问题
解决方法
打开权限组插件的config文件
把里面的nick去掉
并把essconfig里面的nick权限去掉
