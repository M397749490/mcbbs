作者: mitianyi0914    时间: 2019-6-16 14:46
如果不愿意新增新的插件的话，可以更改ess自带的groupmangger插件里的config文件
  1. mirrors:
  2.         world:
  3.           world_nether:
  4.           - users
  5.           - groups
  6.           world_the_end:
  7.           - users
  8.           - groups
  9.           all_unnamed_worlds:
  10.           - users
  11.           - groups
复制代码
在下面新增你需要的世界名，让某个世界权限独立，例如
  1.   world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           all_unnamed_worlds:
  9.           - users
  10.           - groups
  11.           zy:
  12.           - users
复制代码
这里的zy世界就只集成user.yml文件的配置而不集成group.yml的配置
刷新后台，你就会看到GM插件文件夹内的world文件下新生成了zy文件夹，里面就是zy的独立权限配置文件
对照ess更改即可，在group中给你需要的组一个ess的飞行权限节点
manload之后权限配置完成
