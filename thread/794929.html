多世界
指令:
/mw help 帮助
/mw load 加载现有世界
/mw unload 卸载世界

/mw delete 删除整个世界的文件夹及其所有数据
/mw tp [player] 将玩家传送到目标世界
/mw list 世界列表
/mw spawn 传送到这个世界的复活点
/mw setspawn 设置这个世界的复活点

权限:
默认OP拥有
mw.command.load 使用/mw load
mw.command.unload 使用/mw unload
mw.command.create 使用/mw create
mw.command.delete 使用/mw delete
mw.command.list 使用/mw list
mw.command.teleport 使用/mw tp
mw.command.spawn 使用/mw spawn
mw.command.setspawn 使用/mw setspawn
