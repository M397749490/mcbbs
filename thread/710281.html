    Mod特色
  GeoMastery在不同方面改变了游戏的许多机制。

    库存：你的初始库存大幅度减少，堆叠数量也大幅度减少。但随着你的发展，你可以装备一些储存物品增加你的库存规模，但这样会增加你的负担，减慢你的速度！

   食物：你现在有三个饥饿条：蛋白质、碳水化合物、水果/蔬菜。这三个饥饿条都是独立的，他们每条都可以饿死你或者治愈你。许多食品都会腐烂，所以储存很多食物还不如有一个作物场好。睡一觉会要花费你一个饥饿，但也给你一个健康的新陈代谢！

   温度：这个新的因素将会不断地影响你，如果温度过于**会扣血。寒冷的地方、高海拔或者水会使你清爽；而火,热的生物群系或是增加衣物会使你温暖。在物品栏的右方的快捷图标会让你知道你现在的温度。
   
   科技：这儿有很多不同类型且各具特色的基于现实工业早期技术发展的炉膛装置。你需要使用正确的设备来完成你的目的，因为合成表到处都找不到！一些手工制作的设备很容易风化，如果把它暴露在外界空气中，它就很容易被摧毁！

  农业：这个Mod添加了许多新类型的农作物，它们的生长需要特定的生物群系，比如有的就只在水里生长。你也可以找到一些果树，果实在叶子里。耕作收获会很慢！从动物身上获取食物也不是那么容易，一个被杀的动物只会掉落尸体，你需要用小刀割开它才能获得它掉落的物品。

  建筑：大多数原版方块不能按照你习惯的方式放置，因为它们都受重力影响！我们增加了很多新的方块建筑和使用，但是它们也受重力影响！你需要考虑你使用的材料的重量，在空中建造需要考虑考虑再考虑！

  战斗：合成装甲和武器的材料已经改变，以适应其他技术的发展。我们增加了一个新的武器——矛，它会造成不轻的近战伤害，但也可以作为强力但短程的可重复使用的炮弹投掷。

这个Mod入门很难，所以福利来了：征服大地新手必备指南！ 感谢 @天域 的汉化！

         开发计划&已知Bug    
开发计划：
  • 我们准备对树进行一次大修改，包括树的产生、生长、收获。
  • 我们打算改变或更换许多原版怪物，包括改变怪物的生成和战斗。以及友好动物的饲养和猎捕方式。
  • 我们正在规划创建一个魔法树！
已知Bug：
  • 木桩石桩等物品无法显示。 解决办法：删除Optifine（高清修复）Mod即可。

2.0.0版本更新记录
Update, version 2.0.0!

This version is not backwards-compatible. Old worlds will break if loaded in this version!

Changes
  • Building blocks are now all harvested by hand.
  • Fluids now behave properly.
  • Building items have tooltips summarising their building requirements.
  • Food items have tooltips with their food type.
  • Crop seeds have tooltips listing their valid biomes.
  • Useful messages are sent to the player when trying to place a building block in an invalid position.
  • Ability to re-add the vanilla crafting table with all vanilla recipes removed - for crude modpack compatibility.
  • Ability to hide unused and inaccessible vanilla items from JEI.
  • Improved placement of building blocks with facing.
  • zh_tw translation (Thanks, mymagadsl!)
  • Config settings!
    • Toggle food type tooltips.
    • Toggle crop biome tooltips.
    • Toggle building item tooltips.
    • Toggle building failure messages.
    • Toggle vanilla crafting table recipe.
    • Toggle hiding vanilla items from JEI.
    • Toggle using durability bar length for food decay.
