大家都知道一个指令：
就是playsound指令（详细）

那么，这怎么弄呢？

{:10_513:}

————————材料————————



电脑一台（......）

音乐文件（推荐Itunes、酷狗等搜索）

（可选）格式工厂

一个存档



———————！创建材质包！———————

第一个，就是音乐文件

把你要播放的音乐文件用格式工厂转化为OGG格式

（如果你的音乐文件本身就是OGG可省略）


第二，新建文件夹（任意名称（后面***代表）） 在里面再新建文件夹：assets，再在里面添加文件夹：minecraft，再添加文件夹：sound

大致这样的
  1. ***\assets\minecraft\sound
复制代码

把音乐文件丢到sound里面，如果可以的话，改成一个好记的英文名称


第三，新建文件在
  1. ***\assets\minecraft
复制代码
文件名为：sound.json


使用记事本的方式打开它（扫盲：右键，属性，打开方式，记事本，或者改变名称为sound.txt）

然后输入下面的文字：
  1.   "内部名称": {
  2.      "sounds":  [
  3.          "文件"
  4.       ]
  5.   }
复制代码

我的文件为mu5，那么我就

  1.   "mu.mu.5": {
  2.      "sounds":  [
  3.          "mu5"
  4.       ]
  5.   }
复制代码
{请以上面为准}





输入到最后就再加入一个
  1. }
复制代码
在最下面



然后当做材质包放进材质包文件（请注意材质包的基本要点）

——————————————————————！材质完成！—————————————————————————————



最后，进入存档，使用give指令打出命令方块（ID:137），然后放在地上，对里面输入
playsound <内部名称> <玩家> (x) (y) (z) (音量) (音效效果) (最小音量)

<>是一定要填写的

如果xyz不填，那么就是命令方块本身发出声音（这里也就是播放声音的地方）



到这里，配上按钮，设计地图，你的音乐地图就完成了！
