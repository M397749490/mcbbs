该问题已确认是dz的Bug，现在公布一下修复方案以方便其他站点解决
进入source\include\space\space_thread.php，然后在第13行左右（即
if(!defined('IN_DISCUZ')) {
        exit('Access Denied');
}
的下面）加上下面一段代码
  1. require_once libfile('function/friend');
  2. $isfriend = friend_check($space['uid'], 1);
复制代码


问题分析：在该模板页dz将会通过一个叫 $isfriend 的变量来判断是否为好友，然后再显示不同的按钮。
但是在主题页面的时候，space_thread.php没有这个变量，导致无法判断是否为好友，故产生了该Bug
目前正在修复和上传修改后的文件
