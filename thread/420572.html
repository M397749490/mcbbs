如何探测某个物品掉落在地上并且执行某个命令：
首先，设立一个计分板目标
scoreboard objectives add （比如:itemType） dummy
看看他的种类
scoreboard objectives add （比如:onGround） dummy
看看他是否在地上

scoreboard players set @e[type=Item] itemType 1 {id:"(你要的物品的id)",Damage:（你要的物品的数据值，可以不用）}

scoreboard players set @e[type=Item] onGround 1 {OnGround:1}

execute @e[score_itemType=1,score_itemType_min=1,score_onGround=1,score_onGround_min=1] ~ ~ ~ /你要的命令


————————————————————————————————————————
如何做到把记分板内所有玩家增加特定点的分数，用*号？
/scoreboard players add * (计分板目标名） add （数值）
* 就是代表所有被该计分板追踪的玩家/实体/假玩家名（只用作储存数据）
