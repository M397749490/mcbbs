插件介绍
相当简单且实用的插件，可以让你在游戏内创建一些新的工作台合成配方/熔炉熔炼配方/铁砧合成配方，可用于RPG服务器的锻造，宝石熔炼等

所有创建/修改/删除合成 -> 游戏内编辑
输入/cr create <合成名> 即可打开合成创建菜单，简单方便，不需要动配置
可在GUI中选择合成方式：有序合成，无序合成，熔炉，铁砧

指令&权限
  • /cr create <合成名> - 创建合成
  • /cr edit <合成名> - 编辑合成
  • /cr view <合成名> - 查看合成配方
  • /cr remove <合成名> - 删除合成
  • /cr disable <合成名> - 暂时禁用该合成
  • /cr enable <合成名> - 重新启用该合成
  • /cr list - 查看已存在的合成配方列表
  • /cr clear - 清除全部已存在合成
  • /cr reload - 重载插件

权限
customrecipe.craft.<合成名> - 允许进行此合成
customrecipe.craft.* - 允许进行所有合成

配置文件
请将此文件放入plugins/CustomRecipe文件夹
