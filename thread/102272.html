描述
当玩家进入PVP的区域的时候，被攻击玩家会进入隐身状态且攻击玩家名字变成红色
当玩家死亡的时候，会将掉落的物品装入一个箱子内
玩家 死亡后，可以进行TP回到自己死亡地点进行拾取物品 （我没测试出来）{:10_494:}
可以自己定制安全时间，默认为30秒
可以自己定制攻击后玩家的名字颜色
权限
没有
命令
基本没用
配置文件
  1. Tagging:
  2.   Enabled: true  --是否启用
  3.   NameTag Color: c  --PVP时玩家头顶颜色
  4.   Remove Invisible: true  --是否启用隐身保护
  5.   Disable Enderpearls: true
  6.   Anti Pilejump: false
  7.   Disable Flying: true  
  8.   Safe Time: 30  --安全时间单位：秒
  9.   Disabled Worlds: example1,example2   --禁用PVPTAG的世界
  10.   Use TagAPI: true  --是否器用TAGAPI
  11.   Disabled Commands: warp,heal
  12. Death:
  13.   DeathTP Enabled: false --死亡后是否可以进TP
  14.   DeathTP Time: 30  --死亡后进行TP的时间
  15.   DeathChest Enabled: false  ---死亡后是否将掉落物品装入箱子
  16.   Chest Time: 45  --箱子存在的时间
  17. PvPLogger Zombie:
  18.   Enabled: false
  19.   Health: 50
  20. Auto update: false

安装说明
需要一个TAGAPI 这个其实就是将玩家名字变红的一个前置插件，必须装，不装玩家名字不会变色
TAGAPI下载地址
http://pan.baidu.com/share/link?shareid=401295&uk=3106394892

然后将TAGAPI 和PVPTAG 同时复制到plugins下面 启动服务生成配置文件，然后可已经修改
修改OK 然后进行重启即可生效。
