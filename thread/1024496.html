如何将uuid附到owner标签上？ 使用execute store配合data?

以1.15.2为例

/execute as @e[type=minecraft:item] at @s run data modify entity @s Owner.L set from entity @p[tag=test] UUIDLeast
/execute as @e[type=minecraft:item] at @s run data modify entity @s Owner.M set from entity @p[tag=test] UUIDMost
