第二次季度活动



本次活动主题为：地牢怪物！

当你第一次在Minecraft的地牢中穿梭时，每一个转角是否都让你心惊胆战？
然而那些三头六臂令人胆寒的怪物终究只停留在了想象中，并没有出现在阴影里
来发挥你的奇思妙想吧！一探究竟脑海中的转角后的阴影，无论是多么稀奇古怪！


活动详情：
本活动由黑洞计划举办并维持
举办时间：帖子发布至帖子关闭
本活动旨在提升国内MC玩家的创造力，以及指令全民化
在原版mc的基础上创造一个尽量奇异的怪物（必须为敌对），方式有模型/原版指令两种

  模型：
  • 必须能被Minecraft读取
  • 展示图片不少于2张，用心者有额外评分（如拥有场景或是渲染图）
  • 需要附上简短介绍，建议提及它的来由、能力，小则故事可以加分~
  原版指令：
  • 不得从他人地图上照搬怪物（本人确信自己玩过的地图足够多）
  • 版本不限，但请附上版本号
  • 必须提供1~2张展示图，并附上指令，指令必须是能执行的
  • 可以给自己的怪物做上技能，不做的话一定要在介绍中说明
  • 过于简单的怪物（比如单单是一只骑在猪上的僵尸）会扣分，最终奖励不超过1人气25金粒
  • 指令萌新？这里可供参考：各种生物/实体的数据值，推荐使用的数据值：Passengers（骑乘实体）、ArmorItems（盔甲）、HandItems（手持武器）、CustomName（名称）、CustomNameVisible（在实体上方显示其名称）、Attributes（实体属性，如生命值、速度等，生命值需配合Health数据值）、ActiveEffects（状态效果）……
  • 特别提醒：一个怪物≠一个实体，这个怪物可以通过多个实体组合而成，或者拥有召唤的能力

例子：



怪物名：噩梦小分队（1.13）
简介：它们携带着邪恶的符咒在充满梦的气息的夜空中游荡，并将符文化为梦魇
生成指令：
  1. summon minecraft:phantom ~ ~5 ~ {Passengers:[{id:"minecraft:spawner_minecart",SpawnData:{id:"minecraft:armor_stand",ArmorItems:[{},{},{},{id:"minecraft:purple_carpet",Count:1b}],NoGravity:1b,Invisible:1b,Tags:[go],Passengers:[{id:"minecraft:item",Tags:[goo],PickupDelay:32767,Age:-32768,Item:{id:"minecraft:knowledge_book",Count:1b}}]},SpawnCount:3,SpawnRange:6,RequiredPlayerRange:128,Delay:100,MinSpawnDelay:10,MaxSpawnDelay:100,MaxNearbyEntities:8,Passengers:[{id:"minecraft:bat",Passengers:[{id:"minecraft:stray",Tags:[st],HandItems:[{id:"minecraft:bow",Count:1b},{id:"minecraft:trident",Count:1b}],CustomName:"{"text":"噩梦小分队","color":"dark_purple","bold":"true"}",CustomNameVisible:1b}]}]}],Glowing:1b,NoAI:1,Size:13,Tags:[ph]}
复制代码
以下指令循环执行（rcb）：
  1. execute as @e[tag=go] at @s rotated as @e[type=minecraft:phantom,tag=ph] run tp @s ^ ^ ^0.05
  2. execute at @e[tag=go] run particle minecraft:crit ~ ~1 ~ 0 0 0 0 2 force
  3. execute at @e[tag=st] run kill @e[tag=goo,distance=7..]
  4. execute at @e[tag=st] run kill @e[tag=go,distance=7..]
