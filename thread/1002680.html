作者: nidb    时间: 2020-3-31 14:45
自己的服务器的话推荐使用nginx进行代理，可以实现https+自定义错误页
https://demo.dynmap.cn:8888 (没备案不80了，但是HTTPS是完美实现的）
关于dynmap的任何问题可以到BBS转载贴  https://www.mcbbs.net/thread-990539-1-1.html 提问
nginx代理的方法：
编辑nginx配置文件，加入

  2.         server{#demo dynmap
  3.                 listen 8888 ssl;#端口
  4.                 ssl_certificate /data/ssl/demo.dynmap.cn.pem;#SSL证书位置
  5.                 ssl_certificate_key /data/ssl/demo.dynmap.cn.key;#SSL密钥位置
  6.                 ssl_protocols TLSv1 TLSv1.1 TLSv1.2;
  7.                 ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:ECDHE:ECDH:AES:HIGH:!NULL:!aNULL:!MD5:!ADH:!RC4;

  9.                 index index.html;
  10.                 error_page 502 /dynmap502.html;#设置502页（在dynmap关闭时候显示的）
  11.                 server_name demo.dynmap.cn;#你的域名
  12.                 location / {
  13.                         proxy_pass  http://45.2**.**.***:8123;#你的IP:8123，本机可以填127.0.0.1:8123
  14.                 }
  15.                         location = /dynmap502.html{
  16.                         root /data/errpages;#自定义502页面位置
  17.                 }

  19.         }
