其实 你可以自己下载CraftBukkit 必须是跟你那个Minecraft版本一致 否则 进不了服务器

1。翻墙 下载火狐浏览器 在附加组件 在网上搜索AutoProxy 安装之后 点重启 然后 你会看见有个福字 说明你装进去了

在AutoProxy设置上 添加订阅 有一个词 ：对付GFW 选择一个gfwList （P.R.China） 然后升级 你就可以连接外国的网络！！！！！

2。建立服务端 下载一个一模一样版本的 。jar文件 上网搜去 大小吗。。。至少地10兆字节以上
    弄一个 Bat文件

color 0a


@ECHO OFF

cls
SET BINDIR=%~dp0
CD /D "%BINDIR%"
"%ProgramFiles%\Java\jre6\bin\java.exe" -Xincgc -Xmx1G -jar （跟你一致的水桶服）.jar
PAUSE

复制那一段 到txt文件 然后改成Bat

还别忘了 打开 Server.properits 编辑Online-mode（正版专用）改成False！！！！ 除非你是正版玩家！！！！否则必改
