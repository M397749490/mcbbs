Zombies in the daytime! Zombies are everywhere, be careful. Sort of an adventure mod. The zombies will attack players, chickens and pigs. There are options in the config file to control spawning of skeletons, creepers, spiders, slime, and endermen. The default minecraft zombies are disabled. There is a GUI configuration screen under the main screen mods button. Select the crackedZombie mod and then the config button. You can enable/disable other mob spawns such as the creepers, skeletons, etc. When spawning the player will be given a random type sword for protection. That option can be disabled in the config if you're really hard core.                                                                                                                                                                                                                                                                          ————————来自官方原文

第一次测试时，NEI居然挂了（显示不出任何信息），再加上官方的介绍，让我以为他是原版改正的类型，事实上模组有添加了新的生物，代替了原版生物的生成（感觉好尴尬啊）。罢了，只好再编排一次了，望各位原谅我的粗心

效果：
1.白天僵尸不会燃烧（新的僵尸）
2.所有怪物的生成现在可以定制
3.僵尸猪人都是带仇恨的（新的僵尸猪人）
4.僵尸可以在任何生物群系生成（？）
5.僵尸现在会攻击动物（牛啊，猪啊，鸡啊什么的，奇怪的是他居然对羊没反应）6.模组中的cracked zombie和cracked pigzombie会替代原版怪物生成（蜘蛛，女巫及地狱的各种怪物除外）
