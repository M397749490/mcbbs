游玩须知
难度/流畅度
如果卡或者难度太大的话可以把.minecraft/versions/1.12.2/config中的DeadlyMonsters.cfg文件调一下
具体怎么调可以把全部复制粘贴到有道翻译中，然后照着翻译调
其中
类似于
    # Health multiplier for all mod mobs [range: 0.01 ~ 999.0, default: 1.0]
    S:healthMultiplier=10.0
    # Speed multiplier for the mod mobs [range: 0.01 ~ 999.0, default: 1.0]
    S:speedMultiplier=10.0
    # Strength multiplier the all mod mobs [range: 0.01 ~ 999.0, default: 1.0]
    S:strengthMultiplier=10.0
的配置
后面的默认值是1.0
我扩大了10倍[滑稽]
这种
    # Bloody Maiden spawn rate. Default for Zombie is 8. [range: 0 ~ 999, default: 4]
    I:bloodyMaidenSawnRate=8
默认值是4
还好
只有2倍[滑稽]

内存
如果要调整内存的话不仅要在启动器的游戏设置中调整最大内存
还要把下面的java参数中的-Xms一项后面的值设为和最大内存相等的值
这样是为了防止分配的内存一直跳动
占用CPU
调整后会有一定优化效果
注意：我测试的话最大内存是5120MB
实际使用1500MB左右，
建议内存2048MB~4096MB或更高
