BauerCam & Minema 视频录制教程

请点击上方目录条目进行阅读






I. 前言

你可能一直在想，没有高端的电脑，没法开光影，没法录视频，作品展示方面就输在了起跑线上。不用担心，有了下面这两款Mod，渣机也能录出高质量的视频。



Minema可以将游戏转换为一个离线渲染器，强制降低游戏运行速度来保证录制出稳定帧率的视频。
而BauerCam是专为Minema量身打造的一款镜头路径Mod，可以控制镜头在特定的帧数内完成指定的路径，配合Minema的机制，保证每一帧的质量。
不管是抗锯齿，高配光影还是高清材质，随你使用，只要你有大把的时间等待录制完成，炫酷的展示视频触手可及。

注意：本文的方法仅针对作品展示类视频（Cinematic），实况类视频请考虑使用PixelCam, Camstasia等录制方式。

本文使用资源：
  • BauerCam v1.13 by Gregosteros
  • Minema ShaderSync v3.3.1 by Gregosteros*
  • KUDA Shaders v6.4.80
  • FFmpeg v3.3.2


  • Minecraft版本：1.12
  • Forge版本：14.21.1.2443
  • 地图：http://www.mcbbs.net/thread-724722-1-1.html

III. 录制

若根据前文内容安装了Minema, BauerCam 以及FFmpeg，使用默认配置即可进行录制，若希望对Minema进行自定义配置，请首先参阅Minema配置部分，本部分将使用默认配置进行讲解。


  • 使用P键（默认）可将当前位置与角度（以及倾斜度与角视场，后文详解）储存为路径的一个点。



    图中可见在按下P键后，聊天栏中提示成功设定第一个点。
  • 当选择了至少两个点之后，BauerCam会使用三次样条插值建立一条曲线路径连接这些点，该路径显示为红色。选择点时应尽量使用最少的点数量划定路径，可以避免各种奇怪的插值造成的路径转弯。



    接下来用同样的方式设定第二个点，注意按下P键时被保存的除了位置还有视角朝向。
  • 路径创建完成后，按下F4可开启Minema录制系统（此时应有一声蓝鸡产卵音效），此时应稍等几秒等待区块完全加载。
  • 使用 /cam start x 即可开始沿设定的路径移动，x为采样数，根据Minema设定的帧率及需要的视频长度设定，为 帧率 x 秒数（如60fps的3秒视频为180，默认配置帧率为60）。



    输入指令，这里为/cam start 2400，即60fps，40秒。
  • 开始后玩家将会在设定的采样数内走完路径，同时每个点的各个视角参数也会被带入计算进行补间处理达到镜头旋转效果，此时应当注意不应手动改变视角（建议把鼠标拔了），或改变窗口大小（会导致Minema编码失败强制停止录制）。



    聊天栏中提示Travelling started代表开始沿轨迹运动，当达到轨迹终点时视角将不会继续自动改变，此时应停止录制。
  • 路径运行完成之后再次按下F4（会有同样的音效），会停止录制，此时在输出文件夹将会看到输出的文件，以录制时间命名。
  • 由于录制中包括了输入指令的部分，建议自行对成品进行剪辑。


录制建议
  • 录制时建议使用旁观者模式（/gamemode spectator），并使用F1隐藏GUI。
  • 使用/cam clear 可清除当前路径，退出当前世界也会清除路径。
  • 通过相关指令可导入导出路径，请参阅第四章。


[实例0-简单录制]
如何轻松吃到鸡录视频

Minema配置：默认

  • 进入地图，前往需要录制的区域，找到适合的起始位置，按下P键记录第一个点，可以看到左下角提示记录完成。
  • 前往设想路径中的下一个点，将视角调整至需要的方向（会从上一个点方向旋转至下一点方向），再次按下P建记录第二个点，同样可以看到记录完成。
  • 前往最后一个点，使用同样的方式记录（本次实例使用三个点）。
  • 按下F4开始录制，并马上输入/cam start 180开始沿设定路径移动。
  • 移动完成后，再次按下F4停止录制，此时在 .minecraft/movies文件夹中将可以找到录制的源视频。

这里开一个小的讲解，不愿深究者可跳过。

与一般录制路径系统不同的是，其他路径系统一般会产生一条运动时长为x秒的运行轨迹，如果在录制时帧率不稳定，会造成一部分视频的速度过快或过慢。但是如果我们为需要的每一帧都提供渲染录制的机会，即一个采样点，在每一帧录制完成后再录制下一帧，保证整条轨迹会在x帧中走完，此时当我们以一个固定帧率进行编码时，得到的便是帧率稳定过渡平滑的视频。BauerCam的机制便是如此，结合Minema的异步处理系统，我们可以保证每一帧都能得到充分的渲染时间。




IV. BauerCam 镜头控制与相关指令

此外BauerCam也提供了镜头相关的操作

  • 使用 J,K,L 键可分别向左，重置，向右设置镜头旋转方向。
  • 使用 U,I,O 键可分别降低，重置，增加镜头视角宽度，甚至可以超出Minecraft本身的限制。


设定录制点时同样也会记录目前的镜头角度与视角宽度，善用这些功能可为你的视频增加沉浸感。

指令列表：
/cam start <x>开始运行路径，在x步内完成
/cam stop强制停止运动
/cam goto <x>前往路径中设置的第x个点
/cam insert <x>在x点之前添加一个点（会对点重新编号）
/cam remove <x>移除第x个点
/cam replace <x>使用当前位置与视角替换第x个点的已有参数
/cam undo撤销上一次修改
/cam clear清除整个路径与所有已设定的点
/cam save <文件名>将当前路径保存为文件，储存于根目录下的bauercam文件夹中
/cam load <文件名>载入一个已保存的路径，会覆盖当前设置的路径
/cam target set将当前位置设定为焦点，运动过程中镜头会锁定该点
/cam target off移除焦点
/cam circle <r> <c> <left/right> 以当前位置为圆心，创建一个半径为r的路径，第三参数left代表向左运动，right代表向右运动，此功能建议配合焦点使用
/cam preview隐藏或显示路径线


以下实例为镜头与路径相关操作演示

[实例1-镜头旋转]


Minema 配置：默认
  • 前往需要录制的区域，本文中为一个简单的走廊，左右使用红蓝两色以便辨别方向，按下P键记录第一个点，目前镜头角度为正常角度。
  • 沿走廊前进，到达设想的第二个点时，使用J键旋转镜头，旋转完成后保持当前状态按下P键，此时将会记录第二个点，同时记录当前镜头的旋转角度。
  • 继续前进至下一位置，再次使用J键向同一方向旋转镜头，并使用P键记录第三个点。
  • 来到走廊尽头，继续旋转镜头，并记录最后一个点。
  • 路径设定结束后，按下F4并使用/cam start指令即可开始录制。（此处使用/cam start 240）
  • 完成预定线路后，再次按下F4结束录制。

    由于多个点之间距离与旋转角度比不同，视频中可以发现旋转速度发生变化，若希望旋转速度均衡，仅设定起始与结束点，并保证两点之间存在镜头角度差即可。



[实例2-镜头缩放]


  • 前往需要录制的区域，目前镜头缩放为正常缩放。
  • 在同一位置，按住U键扩大角视距，可以看到通过BauerCam可以达到远超原版广角的效果。此时按下P键记录位置与视角，以及角视场数据。
  • 首先使用I键恢复正常视角，前往走廊尽头，并按住O键缩小角视场，可以看到同样可以达到极高的放大效果，此时同样使用P键进行记录，便创建了一条过两点的轨迹，在其上角视场值逐渐缩小。
  • 同样，此时按下F4，并使用/cam start指令开始录制。（这里使用的为/cam start 240）
  • 完成预定线路后，再次按下F4结束录制。

V. Minema 相关配置

最后，Minema也提供了许多配置功能，让我们可以有效控制录制相关规则（希望直接使用默认配置或者不愿深入了解可直接跳过本段），打开配置的方法为点击主菜单Mod，选择Minema接着点击左下方的Config。



此时界面中会有三个选项



  • Encoding - 用于配置编码相关设置
  • Capturing - 用于配置录制相关设置
  • Engine Override - 用于配置引擎相关设置


Encoding - 编码相关配置中




Use Video Encoder
是否使用编码器（true=启用，false=禁用），一般为启用，可以在录制过程中同时编码直接输出视频，不使用的后果见上（直接输出图片序列）。
Encoder Path
编码器路径，默认为ffmpeg，即指向Minecraft根目录中的ffmpeg.exe，若已跟随上面的部分进行了安装，这一条不需修改，若编码器放置位置不同或使用了不同的编码器，请自行设定编码器程序路径。
Encoder Arguments
编码器运行参数，即运行解码器时使用的参数，默认为
  1. -f rawvideo -pix_fmt bgr24 -s %WIDTH%x%HEIGHT% -r %FPS% -i - -vf vflip -c:v libx264 -preset ultrafast -tune zerolatency -qp 18 -pix_fmt yuv420p %NAME%.mp4
复制代码

这个参数是ffmpeg相关的参数，若使用其他编码器请更改为对应的参数。
其中参数中
  • %WIDTH% 为录制范围宽度占位符
  • %HEIGHT% 为录制范围高度占位符
  • %NAME% 为文件名占位符

这里值得注意的是 -qp 18 部分，这个数字代表压缩率，-qp 0 代表无损，同时文件也更大，数值越大损耗率越大，默认的18是一个可以接受的折中数值。
Snap Resolution
分辨率自动修正，即根据设置将玩家设定的录制分辨率大小进行调整，以便与编码器兼容（亲测ffmpeg若关闭此项会无法编码），默认为mod2（ffmpeg需要的最小值为mod2，其他编码器可能需要更高的值），即调整为最近的2的倍数，其他选项有mod4, mod8, mod16与disable（关闭），一般此项为降低影响设置为mod2即可。

Capturing - 录制相关设置



Capture Path
录制存储路径，从根目录开始计算，默认为movies
Frame Width/Frame Height
录制分辨率长宽，默认为0，即使用游戏窗口大小，可设置为需要的大小（录制时会受到Snap Resolution设置的调整）。注意，这不是基于窗口大小的分辨率插值拉伸，而是直接把游戏界面设置为对应的大小，通过使用这个选项，也可以使用超出本身屏幕分辨率大小的分辨率进行高清录制。
Frame Rate
录制帧率，默认为60，若不需要如此高帧率可设定为30（其实个人推荐60fps，便于后期制作速度变换效果且帧率不会损失严重，而且看着爽【）
Frame Limit
最大帧数量，默认为-1，即无限制，若设置上限则录制时达到此帧数时录制会自动停止。
Show Overlay
是否显示叠加层，默认为disable（关闭），开启后录制时在F3界面会显示录制相关信息（会显示到视频中），一般为debug用。



如右下角所示，其中：
  • Frame - 当前帧序号
  • Rate - 当前实际帧率
  • Avg. - 录制过程平均帧率
  • Time R. - 实际录制用时
  • Time V. - 已录制长度（输出时长）


Use PBOs
是否使用缓冲区（pixel buffer objects），开启可进行异步像素处理，比关闭时处理速度快，默认为开启。此选项在过旧的显卡上可能不能使用，若出现问题应关闭此项。

Engine Overrides - 引擎相关设置



这部分中的设定会直接影响Minecraft引擎的某些运行方式，所以仅在单人游戏中才能生效（另外请注意，Minema只适合单机使用）

Engine Speed
引擎速度，Minecraft的游戏运行速度，默认为1.0，即原版的每秒20游戏刻，调整此数值会直接影响游戏运行速度，更高或更低的数值会将其加快或减慢。
Preload Chunks
预加载区块，开启此项后Minema在进行录制时会强制加快区块加载速度，将渲染距离内的区块全部加载。默认为开启（true）。
Force Preload Chunks
强制预加载区块，与上一项类似，但开启后会随时对区块进行预加载。
默认为关闭（false）。
Synchronize
同步化，若开启，会将游戏引擎运行速度同步至录制速度，对于有生物的场景以及与游戏刻挂钩的系统（虽然我觉得你不应该拿这个录红石）的录制十分有效。同时，ShaderSync版（即本文展示使用的非官方Fork版）还可以将光影运行速度同步化（如树叶抖动，水波纹，体积云速度），可兼容光影核心Mod与Optifine。

[实例4-高分辨率截图]

如何获得高分辨率截图


  • 首先进入Capturing设定，将分辨率设定为需要的分辨率（可以超出屏幕分辨率，此处为1920x1080），并将最大帧数（Frame Limit）设为1，这样可保证仅输出一张图片。
  • 接下来进入Encoding设定，因为需要的为静图，不需要视频编码，所以应关闭编码器（Use Video Encoder项目设定为false）。
  • 此时进入地图，开启光影等等，找到合适的角度，按下F4，即可拍下一张高分辨率的截图（根据配置可能会卡顿数秒），图片会输出为TARGA文件，位于输出文件夹中以拍摄时间命名的文件夹中。
  • 使用主流图片处理软件（如PS）便可打开TARGA文件，可以看到输出的文件分辨率为设定的1920x1080。



使用类似的技法，但开启编码器并取消最大帧数限制（正常拍摄配置，但修改分辨率），结合BauerCam便可拍出高分辨率视频。


小提示：
在设定页面右下角勾选“应用到全局”并点击“重设为默认值”便可将所有数值恢复为默认设定，在调试时用处颇大。
