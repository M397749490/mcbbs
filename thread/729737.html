写给开发者的插件介绍：
你需要一个字符串数组，告诉插件你的GUI图像，这个字符串的要求为：
  • 不能为null
  • 字符串数组大小不超过6
  • 每个字符串的长度不小于9
然后你还需要一个转换器，将字符串里的字符转换成对应的ItemStack
他需要是一个继承了Swapper类的对象或者是实现了Swapper接口的对象
在Swapper接口下，有一个public ItemStack getItemStackByChar(Character character);方法
需要你覆写这个方法：当接收一个字符时，返回对应字符的对应itemstack
然后你就可以调用方法GUIMakerAPI.getInventory();了

示例代码：
创建字符串代替GUI模型：
  1. String[] s = {
  2. "*@@@@@@@*",
  3. "*@%%%%%@*",
  4. "*@%###%@*",
  5. "*@%###%@*",
  6. "*@%%%%%@*",
  7. "*@@@@@@@*"};

  1. class Swap implements Swapper {
  2.     @Override
  3.     public ItemStack getItemStackByChar(Character character) {
  4.         //为字符'*'设置一个对应的ItemStack
  5.         if(character == '*') {
  6.             ItemStack itemStack = new ItemStack(Material.STAINED_GLASS_PANE,1,(short)8);
  7.             ItemMeta itemMeta = itemStack.getItemMeta();
  8.             itemMeta.setDisplayName("§c边栏");
  9.             itemStack.setItemMeta(itemMeta);
  10.             return itemStack;

  21.         if(character == '%') {

  32.             itemMeta.setDisplayName("§b§l核心");
  33.             itemStack.setItemMeta(itemMeta);
  34.             return itemStack;
  35.         }
  36.         //默认情况下返回的ItemStack
  37.         return new ItemStack(Material.AIR);
  38.     }
  39. }
