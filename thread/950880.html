主要设置已经给出中文释义，下面具体讲讲砍伐模式

FullChop:经典的砍树模式，一次性伐倒一整棵树！

SingleChop:对着一棵树最下端的原木方块进行伐树，原木会依次往下掉落

VanillaChop:无特殊效果，等同于关闭砍树插件


在FullChop模式下的耐久度计算：

Break_Mid_Chop:在砍树的同时进行耐久度计算

Break_After_Chop:在砍树后进行耐久度计算

Config File
The config file is located at .minecraft/config/fabric-tree-chopper.toml.

Available options:

fastLeafDecay
true or false
treeChopMode
FULL_CHOP, SINGLE_CHOP, or VANILLA_CHOP
fullChopDurabilityUsage
NO_DURABILITY_LOSS, BREAK_AFTER_CHOP, or BREAK_MID_CHOP
sneakToDisable
true or false
requireLeavesToChop
true or false
