AntiBadChat
更好的禁止脏话
别看我，看左边

介绍
  • AntiBadChat可以做哪些事情?
  • 使用正则表达式限制聊天
  • 限制聊天的开头关键词
  • 限制聊天的结尾关键词
  • 限制聊天的包含关键词
  • 在玩家违规时发出多条指令
  • 可以选择的是否取消输出
  • 可以选择的更多变量
  • 可以选择的脏话替换
  • 可以选择的控制台监听
  • 可以选择的支持彩色符号的警告
指令和权限
指令
/abc help 插件帮助
/abc reload  重载插件配置
/abc on  开启插件
/abc off  关闭插件
/abc about 关于插件
权限
abc.noabc 可以说脏话
abc.cmd 可以使用指令
abc.* 本插件全部权限
配置文件
  1. #正则表达式
  2. Regular:
  3.   - "(C|c).*(N|n).*(M|m)"
  4. #禁止开头如下词汇的聊天
  5. AntiStart:
  6.   - "蕾姆蕾姆"
  7. #禁止结尾如下词汇的聊天
  8. AntiEnd:
  9.   - "了啦"
  10.   - "poi"
  11.   - "~~~"
  12. #禁止包含如下词汇的聊天
  13. AntiHave:
  14.   - "SB"
  15.   - "傻逼"
  16.   - "操你妈"
  17.   - "瞎骂"
  18.   - "OP"
  19.   - "管理员"
  20.   - "服务器"
  21.   - "操逼"
  22.   - "麻痹"
  23.   - "儿子"
  24.   - "IP"
  25.   - "地址"
  26.   - "网址"
  27.   - "http"
  28.   - "www"
  29.   - ".com"
  30.   - "垃圾"
  31.   - "智障"
  32.   - "狗篮子"
  33. #如果违反执行以下指令 不需要/
  34. Command:
  35.   - "tell %player% 请不要说脏话，你被惩罚禁言五秒"
  36.   - "shock %player%"
  37. #如果违反是否取消显示
  38. Cancel: false
  39. #脏话替换配置
  40. Replace: "%player%是SB"
  41. #是否给玩家发送警告
  42. Warn: true
  43. #警告信息设置 支持颜色符号
  44. WarnMsg: "&c(%chat%)&e是脏话&b，&c你不能说脏话！"
  45. #控制台监听
  46. Console: true
