首先，如果是全组都有的称号（就是一进入用户组就拥有的称号）是不需要权限的。
首先请楼主看一下我的这篇文章http://www.mcbbs.net/thread-517227-1-1.html
举个例子：
  1.   Builder:
  2.     default: true
  3.     permissions: []
  4.     inheritance:
  5.     - default
  6.     - g:essentials_builder
  7.     - g:towny_builder
  8.     info:
  9.       prefix: ''
  10.       build: true
  11.       suffix: ''
复制代码

在上面这个用户组中，要在“prefix”后面写上称号，这个称号就会被显示。
注意，如果你这么写：
  1. prefix: '&b[这是称号]'
复制代码

那么拥有这个称号的玩家说的话也是跟称号同样的颜色。
要这么写
prefix: '&b[称号]&e'
称号后的那个颜色代码实际上就是玩家说话的颜色
