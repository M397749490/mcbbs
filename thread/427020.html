还在因为没有办法锁定某些世界的时间而困扰吗？
还在因为使用命令方块的方式锁定时间而卡服或者感到效果不好吗？
那就用TimeLock吧。
(其实这个插件很多服主都知道的……我只是看MCBBS上没有才搬的……)








插件简介：
这个插件可以通过简单的指令来实现对指定或所有世界的时间锁定。比使用命令方块锁定方式的时间效果更好并且减少资源消耗。








插件特点：

  • 可以设定时间为早上、晚上、正常时间
  • 可以利用此插件来建造特定的环境。
  • 低资源消耗。
  • 比使用命令方块更有效，不怕区块卸载导致失效。
  • 自定义时间









插件指令以及权限：

   -timelock.admin               只有这一个权限，给予后获得所有调配权限。
/tl day 锁定时间为白天
/tl night 锁定时间夜晚
/tl normal 调回正常时间
/tl (0-24000) 锁定时间为(0-24000)ticks
/tl set [世界名] [时间(day/night/normal/ticks) 锁定指定世界的时间为白天/夜晚/正常时间/ticks
/tl refresh [时间(秒)] 设置TimeLock的时间刷新频率
/tl reload 重新加载confirm.yml配置文件
/timelock 关于插件






更新日志：

  • 0.6 Updated to 1.7.2
  • 0.5b New command (/tl refresh). Plugin no longer runs in async thread.
  • 0.4 New command (/tl set), with console support.
  • 0.3 Added tick support (/tl 18000 will lock time at 0:00)
  • 0.2 Initial Release
