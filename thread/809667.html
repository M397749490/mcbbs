标题: 怎么不指定文件而是读取一个目录下的所有文件
在做竞技场等时候用到
每个竞技场创建的时候名字都不一样
那就不能用 YamlConfiguration.loadConfiguration(file) 来读取文件了
怎么才能做到读取 plugin/Alpha/arean/ 目录下的所有yml文件呢
是不是要用snakeyaml什么的
作者: 602723113    时间: 2018-7-28 13:59
该问题属于java基础问题
我假设你的插件名为Alpha，那么该路径可以为 ../plugins/Alpha/arean
File file = new File(getDataFolder(), "\\arean");

之后利用File#listFile函数 http://tool.oschina.net/uploads/ ... File.html#listFiles(java.io.FilenameFilter)
这里我选择用带FilenameFilter参数类型的那个重载

那么可以写成
File[] files = file.listFile((dir, name) -> name.endWith(".yml"))

即可得到该目录下所有以.yml结尾的文件的File对象，然后你遍历什么的就行了
