使用clear 0的方法，获取背包内各物品的数量总和
execute as @a run function foo:bar

#foo:bar
scoreboard players set $count_1 board 0
scoreboard players set $count_2 board 0
execute store result score $count_1 board run clear @s stick 0
execute store result score $count_2 board run clear @s iron_ingot 0

之后检测数量，至于是指定多少，还是至少为多少，你自己才清楚。
execute if score $count_1 board matches 5.. if score $count_2 board matches 3.. run function foo:bar2(清除物品，给与经验)
