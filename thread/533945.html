PerWorldTablist


     大家好我是一个新人，第一次搬运插件，如果有什么不对的地方请大家多多指教。  


========================================================================================

用途介绍：
      可以在不同的世界里加载不同的Tab列表，再配合背包隔离等几个插件，就真的可以达到一个服务器当成多个服务器使用！建议配合插件:  1.PerWorldPlugins 不同的世界加载不同的插件 2.PerWorldMotds 不同的世界有不同的提示信息
3.MultiInv 不同的世界有不同的背包
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------命令与权限：
注：以下命令中的的perworldtablist均可用pwtl代替！ 紫色为建议给管理员的权限
指令用途权限
/perworldtablist reload重启插件的config pwtl.reload
/perworldtablist list/glist 查看服务器所有玩家 pwtl.list/pwtl.glist
                  /按Tab可以查看所有玩家 pwtl.exempt
我猜测glist是所有玩家，list是当前世界玩家
========================================================================================
配置文件：
  1. Configuration:
  2. # 拥有权限'pwtl.exempt'的玩家是否可以看见所有玩家true为可以看见
  3.   EnableExemptPermission: true
  4. # 插件是否开始组，如果开启，将不会在那个世界隐藏玩家的组
  5.   EnableGroups: true
  6. # 插件的/list指令是否要取代其他插件(如Ess基础插件的 /list)
  7.   ReplaceOtherLists:
  8.     Enable: false
  9.     # 如果为true，请设置以下的取代指令，请使用小写
  10.     Replace:
  11.     - list
  12.     - elist
  13.     - who
  14.     - online
  15.     # 替换
  16.     Run: wlist
  17.   # 这个插件应该显示玩家没有pwtl.glist权限在世界列表里吗？
  18.   ShowWorldlistIfNoGloballistPermissions: false
  19.   # 所有世界应该没有玩家隐藏在全局列表吗?
  20.   HideWorldsWithoutPlayers: true
  21.   # 世界全局列表中不显示
  22.   # 区分大小写
  23.   HiddenWorldsInGloballist:
  24.   - exampleWorld
  25.   - anotherExample
  26.   # 这个插件应该使用displayname(从Ess或其他插件)而不是playername吗?
  27.   # 推荐如果你使用EssentialsChat(很棒的前缀!)
  28.   UseDisplaynameInsteadOfPlayername: false
  29.   # 这个插件应该前缀PermissionsEx之前玩家的名字吗?(需要PermissionsEx)
  30.   DisplayPermissionsExPrefixes: false
  31. # 注意!以下不要改动!
  32. ConfigVersion: 02
复制代码

# PerWorldTablist v1.1.0 - Configuration
# 汉化：Ghost_LoneWalker[台湾孤判]
Configuration:
# 拥有'pwtl.exempt'权限的人是否可以在列表看到其他权限组/世界的玩家?
  EnableExemptPermission: false
# 是否开启让同一权限组玩家看到所有同组玩家？
  EnableGroups: true
# 是否替换其他插件的列表[ESS/LIST]？
  ReplaceOtherLists:
    Enable: false
    # 要替换的命令[小写]
    Replace:
    - list
    - elist
    - who
    - online
    # 替换的信息
    Run: wlist
  # 没有玩家在的时间是否隐藏列表？
  HideWorldsWithoutPlayers: true
  # 将不想要开启插件的世界填写在这里
  # 注意大小写！
  HiddenWorldsInGlobalList:
  - exampleWorld
  - anotherExample
  # 是否使用其他插件名称[ESS/NAMETAG] 而不是玩家的ID？
  # 如果你使用ESS前缀 请开启选项[true]
  UseDisplayNameInsteadOfPlayerName: false
  # 是否开启玩家的[PermissionsEx]插件前缀？需要安装[PermissionsEx]插件
  DisplayPermissionsExPrefixes: false
