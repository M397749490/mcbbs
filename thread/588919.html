────────────────────────────────────────────

[= 图片 =]

[= 动态图片 =]

[= 特点 =]
1.完全可自定义
2.轻量级，非常容易使用
3.可以设置传送延迟
4.启用/禁用粒子效果
5.防止物品同时传送
6.Title的使用
7.使用传送卷轴时的粒子效果
[= 指令 =]
/scrolls - 基础命令
/scrolls help - 所有命令
/scrolls create <代码> <卷轴的名字> <延迟> <1-10> - 创建卷轴
/scrolls give <代码> <玩家名> - 给玩家一个设定好的卷轴
/scrolls set <选项> <代码> <价格> - 设置传送选项
/scrolls reload - 重载插件配置
[= 权限 =]
tpscrolls.use - 允许使用卷轴(默认拥有该权限)
tpscrolls.bypass - 跳过所有限制
tpscrolls.command - 查看所有命令
提示: 配置文件中设置卷轴更方便哦!
