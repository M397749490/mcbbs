前言

简介
CMM是一个可用于自定义主界面的MOD，通过配置json文件来达到效果，其配置文件的位置位于.minecraft/config/CustomMainMenu中，名为mainmenu.json

配置文件探讨
配置文件一共包含四个大类，分别是：images（图片）,buttons（按钮）,texts（文本）,other（其它）
[attach]1147214[/attach]
images在初始情况下只拥有一个小类，就是title（标题），很简单，就是游戏中的标题
buttons在初始情况下拥有singleplayer（单人游戏），multiplayer（多人游戏），mods（mod），options（设置），quit（退出游戏），language（语言）和它自带的refresh（刷新）。按钮相较于图片最大的不同就是可以有可执行动作。
texts在初始情况下拥有mojang（右下角的版权信息）和fml（左下角的forge，mod什么的信息）
other在初始情况下拥有splash-text（标题右边的小黄字）和panorama（背景）
这里详细讲一下panorama和singleplayer的支选项
panorama

        "panorama":
        {
            "images" : "minecraft:textures/gui/title/background/panorama_%c.png",
            "animate" : true,
            "animationSpeed" : 1,
            "blur" : true,
            "gradient" : true
        }
images：背景图片的路径
animate：是否旋转，如果false的话就只有一张图片的效果
animationSpeed：旋转速度，越大越快（悄悄告诉你 调成100的话特别喜感）
blur：是否模糊，false就是不模糊
gradient：没搞懂


singleplayer

        "singleplayer":
        {
            "text" : "menu.singleplayer",
            "posX" : -100,
            "posY" : 48,
            "width" : 200,
            "height" : 20,
            "action" :
            {
                "type" : "openGui",
                "gui" : "singleplayer"
            }
        }

text：显示出来的文本，之所以这里是menu.singleplayer你可以理解为这里调用的是游戏中显示的字
posX，posY：这就是坐标，和游戏内同理，你只要随便搞搞就知道怎么用了
width：宽度
height：高度
action：动作
type-openGui：指类型是打开Gui的动作
gui-singleplayer：告诉它你要打开的是一个单人游戏的Gui
如果你想要自定义图标，你需要加一个
"texture" : "custommainmenu:textures/gui/xxx.png"
这就是你图标的路径，你也可以将图标放在别的路径里，如果你不是很懂就不要搞了
还有，如果这个项后面还有项，必须要加后面加,（英文逗号！）

那么同理，CMM除了可以修改原有的以外，还可以支持新增自定义的各种内容，格式完全可以照着自带的来
这里说一种特殊的东西：background（2D背景），这个其实和panorama的子选项animate调成false的效果是一样的，代码在原教程帖有
那么再提一点吧，如果你要修改字为中文或者使用§，你必须要将编码转为ANSI，否则会乱码
[attach]1147220[/attach]

修改按钮内容补充
如果你要做一个200*100的按钮，那么你在ps里面就要创建一个200*200的画布，在配置文件的width调为200，height调为100，因为它类似于会将你的按钮等分成上下两部分，上一半是没有鼠标悬浮的状态，下一半是鼠标悬浮的状态
