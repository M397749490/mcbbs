正式版是Minecraft经过一段时间的预览版测试之后得到的稳定版本，也是众多材质、MOD与CraftBukkit插件会逐渐跟进的版本。官方正版登陆器也会第一时间进行推送。
建议玩家与开服的朋友关注其相关Mod及其所需的API、CraftBukkit与其插件的更新，迎接新的正式版吧！
专注于单人原版游戏的玩家可立即更新，多人玩家请关注您所在的服务器的通知。

请勿将版本号中不加任何前缀的1.8.X与一年多前的Minecraft Beta 1.8混淆。

转载本贴时须要注明原作者以及本帖地址。
We have released a new version of Minecraft 1.8, called 1.8.6, which is now available for download in your launcher. This release fixes a few reported security issues, in addition to some other bug fixes. This update fixes an issue that was not fixed completely in 1.8.5.
我们已经发布了一个新版本的Minecraft：1.8.6，现在已经可以在启动器里下载了，该版本修正了几个已报告的安全问题，修复了一些bug，此次更新解决了未能在1.8.5完全修复的问题。

This version is fully compatible with all previous 1.8 versions, but it is still highly recommend to update to 1.8.6 as soon as possible.
这次更新和所有1.8兼容，但还是建议尽快更新1.8.6。

对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。启动器在上文已经提供。适用于全PC平台。

非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。如有仍疑惑请到原版问答板块提问。
