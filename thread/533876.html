我认为这个插件好就好在有边框

更加的美观!
  1. Interval: #多长时间发布一次公告
  2.   Minutes: 5 #分钟
  3.   Seconds: 0  #秒
  4. No Players: true
  5. Default Message Color: '&7' #颜色代码 请看下面
  6. Announcements:
  7.   AnnouncementGroup1:
  8.     header: '&1-----------[BarksSimple&bAnnouncer]-----------'  #边框1 下面有提示
  9.     footer: '&1----------------------&b----------------------'  #边框2
  10.     messages:
  11.     - '&oWelcome to Bukkit'  #公告
  12.     - '&lExample of an announce%nWith another line' #公告
复制代码


  1. name: "\xa78[\xa73NXA\xa78]\xa77"  #名字
  2. Messages:
  3.   COMMAND_USAGE: '&e不正确的格式! 请使用:&o %s'
  4.   HELP: '&b帮助&7: '
  5.   HELP_COMMANDS: '&l/%s &r&7%s -&b %s'
  6.   LIST_COMMAND: '&3&l公告: '
  7.   LIST_ANNOUNCEMENT: '&8[&3%s&8]:&7 %s'
  8.   RANGE_EXCEPTION: '&e数字必须在 %s 到 %s 范围内'
  9.   VIEW_INFO: 公告 &8[&3%s&8]
  10.   NUMBER_EXCEPTION: 参数 &8[&3%s&8] 必须是数字!
  11.   ANNOUNCEMENT_SET: 下一个公告设置为 &8[&3%s&8]s
