AutoMessage
简单的设置你的服务器公告
By thearyon
指令|Command
  • /automessage - 查看帮助
  • /automessage status - 开启定时公告
  • /automessage add <内容> - 添加一条公告
  • /automessage remove <公告id> - 删除一条公告
  • /automessage edit <公告id> <内容> - 修改一条现有的公告内容
  • /automessage list - 查看所有公告
  • 以上指令需要 automessage.staff 权限才能使用[OP默认拥有]
  • automessage可缩写为amsg 如:/amsg list
配置|Configure
请不要直接复制代码
