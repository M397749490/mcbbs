1.需要多世界插件，配置文件里设置世界和平模式即可，不过动物还是会刷
2.打开plugins\Residence\config.yml
  1. # The maximum number of blocks a Residence can be, East to West (X).
  2.            MaxEastWest: 256     ←领地的长度，可以设置大一点
  3.            # The maximum number of blocks a Residence can be, North to South (Z).
  4.            MaxNorthSouth: 256  ←领地的宽度，可以设置大一点
  5.            # The maximum number of blocks a Residence can be, High to Low (Y).
  6.            MaxUpDown: 256     ←领地的高度，最高256
