蓝色字体，就是刚刚红圈中的字。
至于要自己制作。。。就复制下面这段话，保存到txt文件中，再将扩展名改为：mcmeta。名字改为：pack
也就是：mcmeta.pack
懒人代码：
  1. {
  2.   "pack": {
  3.     "pack_format": 1,
  4.     "description": "【资源包的名字】"
  5.   }
  6. }
