新版更新记录

Code cleanup.

如题所说这个插件杀死怪物后可以得


下载后安装进服务器插件文件夹重启就可以使用了。


有个权限给了玩家才能得钱

mobmoney.receive

重载指令

/mobmoney reload


配置文件说明

转载自之前的转载帖


main: # 设置为True时，怪物会掉落金钱   
AllowSpawnEggs: true #设置为True时，怪物箱生成怪物也会掉钱!   
AllowMonsterSpawner: true # 设置为True时，被创造模式的玩家击杀也会获得金钱  
AllowCreativeMode: true #这个是捡钱时的声效   
pickupsound: ITEM_PICKUP #声音大小  
pickupsound-volume: 5 #声音间隔   
pickupsound-pitch: 1 #该设置项用作于怪物掉钱的物品   
droppedItem: Gold_Ingot # 设置为True时，插件会发送玩家捡起钱的数量
   sendpickupmessage: true # 设置为True时，怪物会双倍掉落！
   double_event: false # 掉落的倍率   
ChanceToDropMoney: 20 language: # 汉化，插件提示玩家捡起钱的数量
  pickup: '&e你捡到了%money'
