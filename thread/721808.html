作者: sweet与糖    时间: 2017-8-17 16:35
创建一个一秒触发一次的红石脉冲，先关着
创建一个计分板，名字自定，比如创建一个叫CD(只能英文)的计分板:
  1. /scoreboard objectives add CD dummy
复制代码
生成一个实体，标记上一个标签，比如创建一个有233(只能英文)标签的盔甲架
  1. /summon minecraft:armor_stand ~ ~ ~
复制代码
  1. /scoreboard players tag 刚刚生成的实体 add 233
复制代码
将标签为233的生物CD记分板上的分数设置为你想要的冷却时间
  1. /scoreboard players set @e[tag=233] CD 10(想要设置的冷却时间)
复制代码
在生成boss的命令前添加(注意空格)
  1. /execute @e[score_CD_min=想要设置的冷却时间] ~ ~ ~
复制代码
然后连接一个连锁命令方块，写上指令
  1. /execute @e[score_CD_min=想要设置的冷却时间] ~ ~ ~ /scoreboard players set @e[tag=233] CD 0
复制代码
在连接一个连锁命令方块，激活脉冲(只能激活不能熄灭)，
将脉冲连接至一个命令方块，写上指令

  1. scoreboard players add @e[tag=233] CD 1
复制代码
不要忘了/gamerule commandBlockOutput false，如果嫌吵的话
(可选)
将脉冲连接至另一个命令方块，写上指令
  1. execute @e[score_CD_min=要设置的冷却时间+1] ~ ~ ~ /scoreboard players set @e[tag=233] CD 要设置的冷却时间
复制代码
(反正加上之后我觉得更舒服)

要用积分板计时吧
不知道你的版本
我这里是1.12
而且也不知道你的召唤机制
首先创建一个名为X的积分板
/scoreboard objectives add X dummy
/scoreboard objectives add JS dummy
然后我们需要一个盔甲架来计时
/summon armor_stand ~ ~ ~ {Tags:["A"]}
比方说我们有个有着X标签的僵尸
summon zombie ~ ~ ~ {Tags:["X"]}
他一出现就给他的积分板X加分
以下指令高频执行
scoreboard players add @e[tag=X] X 1
然后,当僵尸的X的分数为1时,给盔甲架一个名为"JS"的标签
execute @e[score_X_min=1,score_X=1] ~ ~ ~ scoreboard players tag @e[tag=A] add JS
scoreboard players tag @e[score_X_min=1,score_X=1] remove X
然后,当盔甲架有JS标签时,他的积分板JS开始加分,到了80也就是4秒时设置为0并移除JS标签
/scoreboard players add @e[tag=JS] JS 1
scoreboard players tag @e[score_JS_min=80] remove JS
scoreboard players set @e[score_JS_min=80] JS 0
然后,召唤这个僵尸就必须用这个指令
/execute @e[tag=JS,score_JS_min=0,score_JS=0] ~ ~ ~ summon zombie ~ ~ ~ {Tags:["X"]}
也就是当4秒过了之后才能召唤
