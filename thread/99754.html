这是一个可以用龙作为交通工具的插件

能够像火车站一样（= =暂时就这么描述吧），让玩家进行付费（免费）的旅行

分为普通旅行和航线两种方式

普通旅行是直达车，可以设置站台，并能够设置站牌，玩家可以输入命令或者通过站牌开始搭车

航线类似于公交车，或者说观光车，一条航线可以有多个航路点，也就是说，行进路线可以是蜿蜒曲折，能够作为服务器的观光旅游工具

旅行中支持播放音乐（见config.yml配置文件）

支持以指定玩家为终点

支持随机旅行(见配置文件)

支持免费的回家之旅(见命令)

支持创建静止的装饰龙(可以用来作为城门或者车站标志)

可以指定骑乘时哪些命令禁止执行

支持以信物的方式乘车(即身上没有指定物品的话拒绝搭乘)

支持GUI界面(如果你安装了Spout/SpoutCraft插件)

可选前置插件：vault(如果不收费则不需要)

骑乘时可以随时下来(使用命令/dt dismount或其它带有传送的指令，如果它们没在配置文件中禁用的话)

木牌使用说明

关于目的地



当你成功创建一个目的地(比如destination)后，脚下会出现一块萤石，在萤石附近(默认是5个方块内)放置一块木牌


第一行：[dragontravel]


确定后木牌第一行会变成金黄色，第二行会出现目的地名称：


第一行：[dragontravel]
第二行：destination



关于普通站牌



成功创建一个站点(比如station)后，脚下会出现一块萤石，在萤石附近(默认5个方块内)放置一块木牌


第一行：[dragontravel]
第二行：留空
第三行：目的地名称(比如destination)
第四行：价格（免费则留空）


确定后木牌第一行会变成金黄色


第一行：[dragontravel]
第二行：station
第三行：抵达：destination
第四行：价格（免费则空）



关于航线站牌



创建航线(比如test)，可以和目的地名称重名，具体看命令，这里不做说明


在站点附近放置木牌


第一行：[dragontravel]
第二行：flight
第三行：test
第四行：价格（免费则留空）


确定后除了第一行变黄色，其它不变



航线站牌和普通站牌可以共用一个站点，也就是说一个站点可以出现数十个站牌（只要在范围内）

命令:
  1. #  骑上一头龙
  2. /dt mount
  3. # 从龙上下来
  4. /dt dismount
  5. # 设置家
  6. /dt sethome
  7. # 开始一场回城旅行
  8. /dt home
  9. # 开始指定航班
  10. /dt flight <航班名称>
  11. # 显示所有航班列表
  12. /dt flightlist
  13. # 停止旅行中的音乐
  14. /dt stopmusic
  15. # 让你旅行到指定目的地
  16. /dt travel <目的地>
  17. # 显示所有目的地列表
  18. /dt destlist
  19. # 显示所有站点列表
  20. /dt statlist
  21. # 允许/禁止别人以你为目的地
  22. /dt ptoggle
  23. # 旅行到指定坐标
  24. /dt ctravel <x> <y> <z>
  25. # 旅行到指定玩家
  26. /dt ptravel <玩家名称>
  27. # 设置一个目的地
  28. /dt setdest <名称>
  29. # 设置一个站点
  30. /dt setstat <名称>
  31. # 移除一个目的地
  32. /dt remdest <名称>
  33. # 移除一个站点
  34. /dt remstat <名称>
  35. # 创建一个新航班
  36. /dt createflight <名称>
  37. # 移除一个已完成的航班
  38. /dt remflight <名称>
  39. # 设置一个航路点
  40. /dt setwp
  41. # 保存航班
  42. /dt saveflight
  43. # 移除最后一个设置的航路点
  44. /dt remlastwp
  45. # 生成一条静止的龙
  46. /dt statdragon
  47. # 移除所有龙
  48. /dt remdragons

配置：


  2. # 版本信息
  3. ConfigVersion: 1.6

  5. # 收费旅行
  6. Economy: true

  8. # 普通旅行价格
  9. PayTravel: 5.0
  10. # 飞行航班价格
  11. PayFlight: 5.0
  12. # 定向旅行价格
  13. PayCoords: 10.0
  14. # 回家旅行价格
  15. PayHome: 0.0
  16. # 设置家的价格
  17. HomeSetCost: 0.0
  18. # 抵达玩家价格
  19. PaytoPlayer: 7.0

  21. # 骑乘离地高度. 允许高过天空
  22. TravelHeight: 100

  24. # 骑乘需要拿着指定物品
  25. RequireItemForTravel: false
  26. # 物品ID. 122 = 龙蛋
  27. RequiredItemForTravel: 122

  29. # 只能从站点骑乘
  30. UseStation: false
  31. # 站点或目的地生成时是否创建标记
  32. UseStatDestMarker: true

  34. # 站点半径
  35. DistancetoStation: 5.0

  37. # 是否只能通过木牌进行目的地旅行
  38. # 会禁用命令/dt travel
  39. UseOnlySigns: false

  41. # 是否无视方块
  42. IgnoreAntiMobspawnAreas: true

  44. # 哪种龙不能破坏方块
  45. AntiGriefallDragons: false
  46. AntiGriefDragonTravelDragons: true

  48. # 龙飞行速度
  49. # 大于 1 服务器可能崩溃
  50. DragonSpeed: 0.5

  52. # 骑乘在龙身上时什么命令不能被执行
  53. CommandPrevent:
  54. - /spawn
  55. - /f
  56. - /kill
  57. - /home
  58. - /tp

  60. # 随机目的地的名称. 默认 _random_
  61. RandomDest-Name: '_random_'
  62. # 随机目的地的范围
  63. X-Axis:
  64.     MinX: -100
  65.     MaxX: 100
  66. Z-Axis:
  67.     MinZ: -100
  68.     MaxZ: 100
  69.    

  71. # 旅行时演奏的音乐文件地址
  72. # 支持ogg/wav/mp3格式
  73. MusicURL: 'http://dl.dropbox.com/u/37237580/DragonTravelDemo.ogg'
  74. MessageOnPlay: true

  76. # 开启GUI按键
  77. # 仅适用安装Spout/SpoutCraft用户
  78. GUIopenKey: 'KEY_L'
