吐槽部分：

官方wiki讲解详尽，这些问题全部都能在wiki找到，汉译wiki在这样：https://pluginscdtribe.github.io/wiki/griefprevention/希望你能够逐渐提高自己解决问题的能力，变得越来越强。


参考答案：
问题一：
    玩家组只需要一个权限节点  griefprevention.user
不要给自己 * 或者 griefprevention.* 权限，这可能会使插件出故障

管理员只应该拥有 griefprevention.admin 以及 griefprevention.user 权限

如果你修改了管理员权限 请务必输入 /gpreload 来重载插件

问题二&三：
    GP提供了以meta值的形式限制玩家相关参数，关键词的中文对照表在这里  https://pluginscdtribe.github.io ... vanced-Options.html

使用方法：
例①：
      以修改初始领地块数量为例，将玩家初始两地块设置为256个方块：
      关键字：“griefprevention.initial-claim-blocks ”
      指令：/lp user [玩家ID] meta set griefprevention.initial-claim-blocks 256
例②：
      以最大获得在线领地块奖励数量的上限为例，将玩家最多获得方块数量设置为1：
      关键字：griefprevention.max-accrued-claim-blocks
      指令：/lp user [玩家ID] meta set griefprevention.max-accrued-claim-blocks 1

注意：请不要将meta关键字对应的值设置为0
