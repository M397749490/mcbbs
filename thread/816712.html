EagleVision 鹰眼视觉
第一次发布插件，如果什么写错漏写的东西请各位大神留下回复！
这个插件是我学习发包的小成果，如果对各位有用就再好不过了！
本插件尚未完善，欢迎大家提交BUG，计划会慢慢添加功能的啦！
简介
这个插件能让你像刺客信条一样使用鹰眼标记敌人，且可以与朋友共享标记！
功能
  • 当玩家打开鹰眼模式时，使用Shift+左/右键能标记（发光）你所指的生物！
  • 如果想与朋友共享标记，一起手持末影之眼 然后Shift+右键朋友就可以啦！
  • 全部功能都在GUI菜单里啦，范围标记是标记周围十格内所有实体的！支持MySQL数据库存储数据！
命令&权限
指令                                         权限                                     介绍
/EagleVision   或   /ev            ev.useEagleVision              打开主菜单
/ev color   或   /ev c               同上                                     自定义发光颜色
/ev list                                     同上                                    查询共享标记的玩家
/ev near                                  同上                                    标记周围十格内的所有生物
配置文件
  • 配置Config：
    1. #能标记多少格远的生物
    2. tag range: 20

    4. #实体被标记后能发光多长时间（单位秒）/ 9999以上为永久标记
    5. glowing time: 30

    7. #能透过什么方块标记实体（默认：草、蔓藤、叶子、玻璃）
    8. ignored block:
    9.     - LONG_GRASS
    10.     - DOUBLE_PLANT
    11.     - VINE
    12.     - LEAVES
    13.     - GLASS

    15. #mysql数据库连接
    16. mysql:
    17.   enable: true
    18.   databasename: EagleVision
    19.   username: user
    20.   password: pw
    21.   port: 3306
    22.   ip: localhost
    复制代码
  • 语言Language：
    1. #开启鹰眼模式
    2. onVision: "&9&l[EagleVision] &a开启鹰眼！"

    4. #关闭鹰眼模式
    5. offVision: "&9&l[EagleVision] &a关闭鹰眼！"

    7. #共享时缺少道具
    8. lackItemOnShare: "§9§l[EagleVision] §c对方缺少链接道具！"

    10. #重复共享
    11. repeatShare: "§9§l[EagleVision] §c已经§e%player§c共享标记了！"

    13. #共享成功提示（给自己）
    14. successShareForSelf: "§9§l[EagleVision] §a成功与§e%player§a共享标记！"

    16. #共享成功提示（给被共享的玩家）
    17. successShareForOther: "§9§l[EagleVision] §a成功与§e%player§a共享标记！"

    19. #取消共享提示（给自己）
    20. successUnshareForSelf: "§9§l[EagleVision] §a已断开与§e%player§a的标记共享"

    22. #取消共享提示（给被共享的玩家）
    23. successUnshareForOther: "§9§l[EagleVision] §e%player§a与你断开了链接"

    25. #权限不足
    26. noPermission: "§9§l[EagleVision] §c权限不足"
