我收到一封信，对方让我去车站，带我，逃离这个世界
收拾我所有东西，赴这夏日之约
第二天醒来，我就在这里了，石碑上刻着Lovenia洛夫尼亚——Njord的领地
噢，夏之神的领地
我在海岸上和巨大花田附近游荡，我找到了夏之神的密宝，夏日美酒
草莓樱桃加上一个天使的香吻包含了夏天热烈的气息，我的夏日美酒飘散着这些美好事物的醇香
走了几天，我发现了不寻常的地方，夏之神的领地怎么会有枯黄的枫树和高耸的雪峰？
没办法解释我只好往高原走，那里树木比较稀少，稍作休息，我又向东北方向走
途中遇到一艘破船，我简单修了，顺着河流划着小船
我闯入了一片柳林，那里有一棵巨大的柳树，我爬不上去，只好作罢
我看见了巨大的六边形石柱！
天哪，如果不是我亲眼见证，我根本不可能相信
我深入石柱群我看见了巨大的法阵和喷发过的火山
我爬上火山，看着周围的一切，也把我最后一点酒喝掉了
喝光夏日酒的那一天，一切都变了
世界观
这里是夏之神Njord的领地，本来这里一年四季炎热不堪，但等到Njord与冬之神女巨人skadi结婚，大陆上才渐渐出现了积雪
巨型花朵被放置在空地上，慢慢地在附近土地上长出了花
Lovenia河因为地势改变，一时间洪水泛滥，海之神激起水花往高处流入海洋
回到中部花田，丰饶之神偷偷将玫瑰换成了农作物
索洛文尼亚高原上土壤稀薄，少植物，但地底下却埋藏了一个大秘密
北上安格西火山，强大的魔法阵维持着领地的秩序，四周的六边形柱，好像**着什么
Lovenia一片生机......

|||    [ Install - 地图安装 ]

Save存档(正版用户):
1、关闭Minecraft，
2、在Windows资源管理器的路径中输入 %appdata%/.minecraft 。
3、把下载的地图存档解压缩放到. minecraft\saves 文件夹里面。

Schematics存档：
这类型需要MCEdit。
1、下载完成后解压，
2、关闭Minecraft，
3、打开MCEdit.exe，点击下方import按钮，选择你下载的文件，
     最后点import，按Ctrl+s保存，Ctrl+w关掉存档，点Quit退出。
