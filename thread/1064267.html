作者: xwjcool123    时间: 2020-6-20 08:05
store result score @s x9就是将后面run的结果(result)储存到@s的记分板目标x0下。
data get entity @s Pos[0] 4000000会获取@s的Pos的第0项，即为@s的x轴坐标，并将它乘上4000000作为结果返回
后面的y0与Pos[1]，z0与Pos[2]同理

后面的store result entity是执行相反操作，把run读取记分板，把结果储存到实体的数据标签上。double表示存储为双精度浮点0.000001也是缩放倍率。

很久没玩指令了，现在按我的感觉来讲一下
data get entity @e[limit=1,sort=nearest,tag=fireball]，返回NBT。里面的Pos是一个数组，所以Pos[0]代表数组中的第一项，即x。同理，[1]代表y，[2]代表z。
execute store result score @s x run，其中的execute store result代表将指令运行结果存入记分板，后面的你应该看得懂。
