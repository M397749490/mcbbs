  • 介绍

这是一款众广周知的热门奔跑小游戏
很多游戏玩家选手在游戏开始后，必须不断奔跑，防止掉下去，跑过的方块都会消失
直到只剩下最后一个玩家选手即获得胜利

  • 特点

  • 支持Bungeecord蹦极模式
  • 支持MySQL数据库统计
  • 支持自动回滚回档地图
  • 自定义闪烁计分板
  • 自定义无限竞技场
  • 自带快捷物品菜单（仅限Bungeecord）
  • 自定义奖励（金钱、命令）

  • 注意

  • 必须安装 WorldEdit 插件
  • 如果你当前TNTRun插件版本大于Beta1.0.7时，请删除arenas.yml并重新创建竞技场
  • 如果使用经济赠送金钱（与Vault相关经济插件）的，请安装 Vault 插件
  • 点击牌子加入游戏的玩家需要权限：tntrun.join.signs


教程

  • 创建竞技场
1. /tntrun create 游戏名 #创建一个竞技场，支持中文名

2. /tntrun set spawn 游戏名 #设置游戏准备和开始的出生点

3. /tntrun set spectate 游戏名 #设置观察者/失败者的出生点

4. /tntrun set bounds 游戏名 #必须用创世神的木斧像圈地一样左点右点圈起来，这是设置竞技场范围

5. /tntrun set loselevel 游戏名 #必须用创世神的木斧像圈地一样左点右点圈起来，这是设置死亡范围（当然是在竞技场下面设置啦，让玩家掉在这个死亡范围就会淘汰）

6. /tntrun set time 游戏名 #设置一个游戏需要等待X秒开始

7. /tntrun set minplayers 游戏名 #设置竞技场最少玩家数量（必须超过1个）

8. /tntrun set maxplayers 游戏名 #设置竞技场最大玩家数量

9. /tntrun finish 游戏名

10. 然后会有东西提示让你输入：//copy

11. 再输入/tntrun finish 游戏名

12.最后大功告成！快开Bungeecord然后直接加入游戏吧
（单端的用牌子加入的请继续看帖子，命令也可以的）

  • 命令
命令 描述 权限
/tntrun 主命令
/tntrun help 命令帮助
/tntrun create 游戏名 创建竞技场
/tntrun set spawn 游戏名 设置竞技场的准备和开始的出生点
/tutrun set spectate 游戏名 设置竞技场观察者/失败者的出生点
/tntrun set bounds 游戏名 设置竞技场范围（创世神一样使用木斧选择区域）
/tntrun set loselevel 游戏名设置掉在某高度位置则游戏失败（在你位置所在的高度）
/tntrun set time 游戏名 时间 设置竞技场需要等待X秒开始
/tntrun set minplayers 游戏名 数量 设置竞技场最小玩家数
/tntrun set maxplayers 游戏名 数量 设置竞技场最大玩家数
/tntrun finish 游戏名 完成并保存竞技场
/tntrun reload 重载config.yml和message.yml配置
/tntrun join 游戏名 加入游戏
/tntrun leave 离开游戏
/tntrun stats 显示统计
/tntrun force 游戏名 强制开始 tntrun.force
