简介
    Scavenger插件是由作者最初写的SirHedgehog插件的续写。这个插件能帮助死去的玩家自动恢复死去之前背包内的物品。

特点

死亡后自动恢复物品
Automatic item recovery at death.
根据所拥有的权限恢复权限内容
Individual item recovery based on permissions if enabled.
自动恢复死前经验
Automatic level and experience recovery at death.
支持超级用户
Supports SuperPerms
支持基于Vault经济插件的服务端
Supports Vault based economies.
持续恢复，假如玩家死亡后没复活服务器关闭了，那么物品的恢复将会变成清单保存到下一次服务器启动恢复。
Persistent recoveries. If the server is stopped before a player can recover inventory the inventory is saved to disk.
基础XXX的恢复[不懂]
Slot based recovery

支持的插件


  • Multiverse-Inventories
  • MultiInv
  • Mob Arena
  • PVP Arean
  • Ultimate Arena
  • Battle Arena
  • WorldInventories
  • Minigames
  • xInventories[炸了]
指令和权限以及说明

  • scavenger.scavenge - 启用项目恢复
  • scavenger.scavenge。damage_cause
  • scavenger.level - 启用等级恢复
  • scavenger.exp - 启用经验点恢复
  • scavenger.free - 免费项目恢复
  • scavenger.reload - 重新加载配置
  • scavenger.drop。[ITEM] - 如果SingleItemDrops为true，则不恢复这些项目。
  • scavenger.keep。[ITEM] - 如果SingleItemKeeps为true，则只恢复这些项目。
  • scavenger.self.on - 允许玩家自己启用项目恢复。
  • scavenger.self.off - 允许玩家自己禁用项目恢复。
  • scavenger.disable - 允许玩家完全禁用拾荒者。
  • scavenger.enable - 允许玩家完全启用拾荒者。
  • scavenger.list - 允许插件列出所有待处理的恢复。（纯信息）
  • / scvr - 重新加载配置
  • / scvron - 自己启用拾荒者
  • / scvroff - 自己禁用拾荒者
  • / scvrlist - 列出所有待处理的恢复

常问问题
Q）如何明确保留项目？
A）将SingleItemKeeps设置 为 true。然后使用scavenger.keep。[ITEM]保留ITEM。
Q）如何显式删除项目？
A）将SingleItemDrops设置 为 true。然后使用scavenger.drop。[ITEM]删除ITEM。

  • 盔甲：
    • scavenger.armour.X - 护甲槽，其中X为0,1,2或3。
      • 护甲：0 =靴子，1 =裤子，2 =胸甲，3 =头盔

  • Inventory
    • scavenger.inv.X - Inventory广告位，其中X为0到35。
      • 库存栏：0 - 8
      • 库存行1：9 - 17
      • 库存行2：18 - 26
      • 库存行3：27 - 35

  • 手绘（盾牌等）
    • 清道夫
