这是截至目前为止我在bukkit站上找到的最简单方便，最轻量化，操作最傻瓜的编辑mc原版怪物的插件。简单介绍:
这是一款专门用于编辑mc原版怪物属性的插件。
作者:
booggy
主要功能:
编辑怪物血量，编辑怪物伤害，编辑怪物掉落，编辑怪物经验
插件版本:
V.1.0.2 （作者已有更新，鉴于时间有限我决定先转载我已经使用熟练并且翻译完毕的版本，新版本将在日后继续转载)
权限:
easymobs.reload 拥有重新载入easymobs的权限，默认只有op拥有
命令：
/easymob reload 重新载入插件
改动日志:
1.0.2 - 解决一些bug，加入了重载命令
1.0.1 - 解决部分掉落bug
1.0.0 - 最初发行版本



配置文件:

由于配置实在太过简单并且我也已经做了翻译的缘故，这里就不做什么解释了。大家可以自己看。的确非常傻瓜式。
  1. # 注意事项:
  2. # 所有的怪物名称必须使用英文大写!

  4. # 可以使用的怪物名称(括号内的是该怪物的中文翻译，设置配置文件时请务必使用英文):
  5. # BLAZE（火焰怪）, CAVE_SPIDER（洞穴蜘蛛）, CREEPER（爬行者） (不要使用 DMG_CREEPER, 请使用下面的modifier),
  6. # ENDER_DRAGON(末影龙), ENDERMAN(末影人), GHAST(恶魂）, GIANT（巨人), IRON_GOLEM(铁傀儡), MAGMA_CUBE(岩浆史莱姆), PIG_ZOMBIE(猪人),
  7. # SILVERFISH(囊虫), SKELETON(骷髅), SLIME)(史莱姆), SPIDER(蜘蛛), WITCH(女巫), WITHER(凋零), ZOMBIE(僵尸)
  8. # BAT(蝙蝠), CHICKEN(鸡), COW(牛), PIG(猪), SHEEP(羊), SNOWMAN(雪人), SQUID(乌贼）, VILLAGER（村民), WOLF(狼)

  10. # 任何不在这个单子里的怪物将不会被该插件影响

  12. ###########################
  13. ###### 伤害设置      ###### 使用方法:
  14. ########################### "DMG_怪物名字: 数量"
  15. #设置僵尸的伤害
  16. DMG_ZOMBIE: 6
  17. #设置骷髅的伤害
  18. DMG_SKELETON: 5

  20. # 注:改变爬行者的伤害需要用下面的模式
  21. # For this you can use the modifier (default creeper dmg * modifier)
  22. # 1是原本的伤害，0.5是一半的伤害，2是2倍伤害，以此类推
  23. CREEP_MODIFIER: 1.5

  25. ###########################
  26. ### 血量设置            ### 使用方法:
  27. ########################### "HP_怪物名字: 血量"
  28. #设置僵尸血量
  29. HP_ZOMBIE: 35
  30. #设置骷髅血量
  31. HP_SKELETON: 30
  32. #设置爬行者血量
  33. HP_CREEPER: 20

  35. ###########################
  36. #### 经验值设置        #### 使用方法:
  37. ########################### "EXP_怪物名字: 经验"
  38. #设置僵尸经验
  39. EXP_ZOMBIE: 12
  40. #设置骷髅经验
  41. EXP_SKELETON: 10
  42. #设置爬行者经验
  43. EXP_CREEPER: 14

  45. ###########################
  46. ##### 头掉落率        ##### 使用方法:
  47. ########################### 设置"0" 为0掉落率, "100" 为 100% 掉落率
  48. #玩家头掉落
  49. SKULL_DROP_PLAYER: 20
  50. #僵尸头掉落
  51. SKULL_DROP_ZOMBIE: 5
  52. #骷髅头掉落
  53. SKULL_DROP_SKELETON: 5
  54. #爬行者头掉落
  55. SKULL_DROP_CREEPER: 5

  57. ###########################
  58. ######## 怪物掉落  ########
  59. ###########################
  60. # 注:头和以下掉落只有在玩家杀死怪物后才会掉落

  62. DISABLE_DEFAULTS: false
  63. # 设为false: 原版的掉落依然会存在，你编辑的掉落只是作为附加品
  64. # 设为true: 原版掉落被禁止，怪物只会掉落你编辑的掉落品

  66. # 使用方法:
  67. # DROP_怪物名称:
  68. # - 材料名称, 最大掉落数量, 掉落率, 附加值(比方说羊毛35:15,15就是附加值)

  70. # 材料名称必须要用大写英文字母，一个材料名称的单子可以在下面网址找到
  71. # http://jd.bukkit.org/rb/doxygen/d6/d0e/enumorg_1_1bukkit_1_1Material.html
  72. # 请使用名称，请勿使用ID

  74. # percentage of drop refers to maximal amount, so on the example below there is a
  75. # 15 % chance of dropping 3 books, or a 30 % chance of dropping 2 red wool!

  77. # datavalue: is only needed for certain materials (like wool), if not needed: leave it blank!
  78. # list of data values: http://minecraft.gamepedia.com/Data_value
  79. # Use the decimal value only!

  81. DROP_ZOMBIE:
  82. #Ex: 掉落书，最多3本，几率15%
  83. #     掉落红色羊毛(35:14)，最多2个，几率30%
  84. - BOOK, 3, 15
  85. - WOOL, 2, 30, 14
复制代码
使用方法：

1.下载jar文件
2.放入服务器端plugins文件夹内
3.启动服务器
4.修改plugins/easymobs文件夹里的config.yml (如果想使用我的翻译版本就请把这里下载的config.yml覆盖进去)
5.输入/easymob reload重新载入插件
6.享受吧
