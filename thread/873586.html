插件特点:
  • 死亡计数器，记分牌，头衔
  • 具有未锁定成就的玩家统计数据（存储在配置文件中）
  • 现场标志（可加入标志的游戏状态）
  • 配置文件+自定义消息+自定义标题+自定义菜单
  • 粒子商店（需要EffectLib 5.1和Vault，Effectlib仅适用于1.8 - 1.10）
  • 玩家统计菜单（死亡或胜利计数器）
  • “酸水”（玩家进入水中时会被杀死）
  • 弹跳板（粘液块 + 铁制压力板）
  • 传送垫（竖纹紫珀块 + 压力板）
如何设置：
  • /elytrarace setmainlobby //在你的位置设置游戏大厅
  • /elytrarace create <竞技场名称> //创建竞技场
  • /elytrarace setlobby <竞技场名称> //在您的位置设置大等待大厅，玩家将在这里等待游戏开始。
  • /elytrarace addspawn <竞技场名称> //添加重生点。
  • 创建一个木牌：写ElytraRace在第一行，和竞技场名称在第二行。

不要忘记在比赛结束的地方放置一块岩浆块（玩家必须打破它才能获胜）。

更多命令：
-/elytrarace help //帮助
-/elytrarace version //插件版本
-/elytrace list //竞技场列表
-/elytrarace join <Name> //加入竞技场
-/elytrarace delete <Name> //删除竞技场
-/elytrarace stop <Name> //强制停止
-/elytrarace star <Name> //强制开始
-/elytrarace lobby //离开游戏


权限：

- elytrarace.admin //管理员权限
- elytrarace.help //帮助权限
- elytrarace.sign //允许创建加入木牌权限
- elytrarace.* //所有权限
