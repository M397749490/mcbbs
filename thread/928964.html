 服务器新建的vip组继承了builder组之后 没有warp和spawn权限，切换到builder组有权限

作者: sunting    时间: 2019-11-27 20:26
本帖最后由 sunting 于 2019-11-28 05:38 编辑

给你参考下 VIP1 用户组继承 builder 用户组权限
  1.   VIP1:
  2.     default: true
  3.     permissions: []
  4.     inheritance:
  5.     - builder
  6.     info:
  7.       build: true
  8.       prefix: ''
  9.       suffix: ''
复制代码

或者你可以直接用指令干这些事
  1. /mangadd VIP1     创建 VIP1 用户组
  2. /mangaddv VIP1 build true     给予 VIP1 用户组基础权限
  3. /mangaddi VIP1 builder   VIP1 用户组继承 builder 用户组权限
