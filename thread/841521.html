你这个服务器核心只支持插件【plugins文件夹】不支持MOD【没有MODS文件夹】
开启服务器的话：
1、新建一个txt文本文档，打开并输入：
  1. @ECHO OFF
  2. java -Xms1g -Xmx1g -jar <此处换成你下载到的文件的文件名>.jar
  3. pause
复制代码

2、保存该文档，并将文档重命名为bat后缀（文件名任意）；
3、双击该bat文件即可运行服务器；
4、输入stop正常关闭服务器。
