挖得很慢而已吧
你需要一把强力的稿子或者暴力拆除
实在不行你下载电脑MOD
花费一玻璃板一红石7石头造个电脑
再加上7铁1箱子造个机器人
机器人在和钻石镐合成
然后放在地上
输入label set XXXX
XXXX为名字
设定好之后
输入edit XXX
XXX为文件名
待会启动的时候打这个，比如我打的1，待会启动就得打1
输入之后会创建一个文件
打turtle.dig()
然后按键盘左边Ctrl按回车保存
在Ctrl按→回车退出
最后打文件名（之前的XXX）运行
机器人就会挖掉前面的方块
秒破，什么都可以挖（基岩算了）
然后打unequip left（注意方向，如果稿子在右边就用right代替left）
然后稿子就拆下来了，自己藏着用吧

顺便送个机器人代码，原创，自动检测背包是否满回家储存来不及写了
右下角一个放火把
然后加燃料，放一些东西，能在熔炉做燃料 的都可以
然后打refuel all
下面是代码
LONG = read()
TIME = read()
for X = 1,TIME do
   print("start")
   turtle.turnRight()
   turtle.dig()
   function forward()
      while not turtle.forward() do
         turtle.dig()
      end
   end
   forward()
   for long = 1,LONG do
      function forward()
         while not turtle.forward() do
            turtle.dig()
         end
      end
      turtle.dig()
      turtle.digUp()
      forward()
   end
   print("back")
   turtle.turnLeft()
   turtle.turnLeft()
   for Z = 1,LONG do
      function forward()
         while not turtle.forward() do
            turtle.dig()
         end
      end
      forward()
      if Z % 8 == 0 then
         print("Placed")
         turtle.select(16)
         turtle.placeUp()
         turtle.select(1)
      end
   end
   forward()
   turtle.turnRight()
   forward()
   forward()
   forward()
   forward()
end
保存之后启动
然后打长度（比如20，每条矿道就是20格长）
回车之后打次数（比如3就是挖3条矿道）
回车，然后就可以了
然后就等着收货矿物吧（这货不会自己挑矿物挖掉哦！但是不会受砂砾影响）
