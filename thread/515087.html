标题: BukkitApi中使用ClassLoader动态加载类
主要用途:
插件的向下兼容(开发子插件系统)以增强(编程向)用户体验.

需要掌握:
Java基础
Java-反射机制

提前学习:
ClassLoader

我写这篇教程时正在开发一个怪物修改类的插件,写到技能方面后为了增强插件的扩展性开始研究如何在插件中进行动态加载...嘛,遇到了很多困难,最后也都被解决了.

思路:
利用Java本身的反射机制的ClassLoader加载其他的jar,然后就可以做一些怪怪(?)的事情啦！


注意点：
过程中需要指定bukkitAPI本身自带的ClassLoader加载器为父加载器.


需要将通过JarFile读取的jar文件中枚举的元素路径由"/"替换成"."成为包格式.


具体事例还是需要具体分析,详见代码:
  1. //该方法会抛出IO异常,类不存在异常.
  2.         public List<Class<?>> getJarAllClass(String jarFile,Class superClass) throws IOException, ClassNotFoundException  {
  3.                 //新建一个List用于储存获得的Class
  4.                 ArrayList<Class<?>> l = new ArrayList<Class<?>>();
  5.                 //将输入的文件路径转换成URL路径
  6.                 URL url = new URL("file:"+jarFile);
  7.                 //将文件加载成URLClassLoader,注意这里的this代表是继承JavaPlugin的类,使用BukkitApi本身提供的ClassLoader作为父加载器.
  8.                  URLClassLoader cl  = new URLClassLoader(new URL[] { url },this.getClassLoader());
  9.         //将文件用JarFile类载入
  10.         JarFile jar = new JarFile(jarFile);
  11.         //使用迭代器遍历jar内所有元素
  12.         Enumeration<JarEntry> e = jar.entries();
  13.         while(e.hasMoreElements()){
  14.         //加载元素路径为Java包路径格式
  15. String name = isPathToClass(e.nextElement().getName());
  16. //如果name==null则不是class元素路径,进入下个遍历
  17. if(name==null)
  18.         continue;

  20. //用之前创建的URLClassLoader加载确认的元素获得其Class
  21.         Class<?> cla = cl.loadClass(name);
  22. //如果ClassLoader没有取到类,跳到下个遍历(基本是Jar包内包含.class后戳的其他编码文件)
  23.         if(cla==null)
  24.                 continue;

  26. //判断这个Class是否继承该超类为父类,如果是或没有指定父类则加入列表.
  27.         if(superClass==null||cla.getSuperclass()==superClass)
  28.                 l.add(cla);
  29.                
  30.         }
  31.         return l;
  32.     }



  36.        
  37.         private static String isPathToClass(String n) {

  39. //如果长度大于6符合class文件路径标准
  40.         if(n.length()>6)
  41.         if(n.substring(n.length()-6, n.length()).equalsIgnoreCase(".class"))
  42.                 //如果文件末端也为.class确定为class文件
  43.                 {
  44. //返回时将.class去掉并将"/"替换为"."变成类似com.baidu.util.Math的包路径格式
  45.         return n.substring(0, n.length()-6).replaceAll("/", ".");
  46.                
  47.                 }

  51. //不是class文件路径,返回NULL
  52.         return null;

  54.         }
