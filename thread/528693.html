作者: 鸭蛋只吃黄    时间: 2015-12-6 15:51
在ESS的配置文件里有这么一行：
  1. # 当启用后, 具有对应权限的玩家加入、离开游戏将不会在公屏上显示消息
  2. allow-silent-join-quit: true

  4. # 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
  5. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  6. custom-join-message: ""

  8. # 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
  9. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  10. custom-quit-message: ""
复制代码
