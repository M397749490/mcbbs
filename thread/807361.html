万华殿

== 作品介绍 ==
建筑是由_Nekopara 建造的全结构唐代宫殿建筑群
耗时三个月肝出来的成果，结构除了斜廊其他全都有
渲染：Klace_Haue | 建筑：_Nekopara_
本建筑是在C-winword开放创造服建筑的  代发：Haue
转载请私聊申请 服务器为代发 最终解释权归作者所有

== 光影截图 ==









== 下载地址 ==
提供的建筑文件为schematics,该建筑存档不同于一般的存档,不能直接放到saves文件中
需要通过mcedit等工具加载到存档里,好处是,该建筑存档可以随意加入放置到你的地图中(使用mcedit工具)
如果你想参观该建筑,或者获取建筑的存档,请加入服务器
