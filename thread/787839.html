skript可以通过自定义脚本，让你的服务器体现不同的光彩。
无需学习编程，只需稍稍了解，就可以写许多强大的脚本。
但是，有时候还是会遇到问题的，这里就来讲一下要怎么自定义命令。
首先插入代码：
  1. command /Custom command:
复制代码
这段代码的意思是说，“当玩家使用命令/Custom command时，就触发事件”
就像是一个监视者，在旁边看着玩家，然后服务器中有无数个这样的监视者，一旦玩家使用命令/Custom command时，监视者会立刻知道，然后告诉skript，skript知道了，就执行下面的命令。
然后再插入代码：
比如说我们想做一个输入“/Custom command”时就向玩家发一条消息：“你使用了自定义命令”
  1. command /Custom command:

这段代码的意思是：
当使用命令 /Custom command时：
    对使用的玩家发出消息"你使用了自定义命令"
大家在使用skript时一定要注意，每使用一个冒号(":"),就要在下面的脚本前打4个或8个空格，或1个缩进。
上面讲了简单的自定义命令，下面来讲带参数的，很多插件中都有带参数的命令
比如RPGitem:
  1. /rpgitem <物品名称> create          -创建一个RPG物品
复制代码
这里面的"<物品名称>"就是一个参数，就是可以让玩家自己设置的东西。
下面来看一段代码。
  1. command /hello <player>:
复制代码
这段代码的意思是，当玩家输入命令"/hello <player>"时，如果使用者有skript.hello权限，就向<player>发送"hello"，这里的<player>代表一个玩家。
比如
/hello wuuuw
向wuuuw发送"hello"
那如何调用<player>这个参数呢，就是玩家使用时填的<player>，要这样才能获取到呢。
大家看到上面代码中的argument了吗？
这个代表的就是参数。还可以用"arg"代替"argument"
群众：如果要好几个参数怎么办？那argument代表哪一个？
回答：很简单，只需要用"arg <第几个参数>"或"argument <第几个参数>"就行了
大家可能会问，为什么我按照你说的写了，可是输入命令没用？是不是骗人的？
其实，仔细的人，会发现上面的代码中有一个trigger:
这是什么意思呢？
其实就是说，在使用命令后，要执行的脚本。
必须要加trigger:
否则执行后没有效果。
自定义命令的主格式：
command /command <arguments>:
    description: A description of what this command does
    usage: How to use the command, e.g. /command <arguments>
    permission: skript.command
    permission message: You don't have permission
    executable by: players/console/players and console
    aliases: /cmd, /command.
    trigger:
        put conditions and effects here that will be checked/executed when the command is used.
