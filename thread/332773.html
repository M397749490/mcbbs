放自定义指令的指令方块↓
  1. setblock ~ ~1 ~ command_block 0 replace {Command:"指令"}
复制代码



放贴在墙的告示牌↓

  1. setblock ~ ~1 ~ wall_sign 0 replace {Text1:要写的字}
复制代码


放在地上的告示牌↓

  1. setblock ~ ~1 ~ standing_sign 0 replace {Text2:要写的字}
复制代码


上面两个指令中的0，是数据值，比如：第二条指令把0调成1或2或3都可以，你自己试试就懂了。

Text1：告示牌的第一行字，以此类推，也可以Text2或Text3或Text4

Command Block:
/setblock <x> <y> <z> command_block 0 replace {Command:"command"}

Sign:
/setblock <x> <y> <z> minecraft:wall_sign 0 place  {Text1:text,Text2:text,Text3:text,Text4:text}
/setblock <x> <y> <z> minecraft:standing_sign 0 place  {Text1:text,Text2:text,Text3:text,Text4:text}
