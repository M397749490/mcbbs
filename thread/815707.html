安装方法及基础配置：



在配置好的sponge服务端下，拖入mod文件夹即可，随后重启服务器，web-api会自动加载，但是如果要想使用，还需分两种情况进行区别配置



1.该服务端运行在本地电脑上（即非云主机或者其他电脑上）：无需其他配置，在终端输入终端给出的网址（即AdminPanel后面的网址）即可访问，此种方式只能在开启服务端的这台电脑上进行访问。



2.服务端运行在云主机时需要修改位于config文件夹下的配置文件，即/config/webapi/config.conf ，找到host一项将其改为0.0.0.0（如图）

此时开启服务端，并确保所在端口默认为8081和8080是开启状况（开启方法各服务商不尽相同请自行百度，通常都很简单），即可在任意联网设备，任意地点上访问管理面板，注意localhost部分要替换为你自己的ip，例如我的ip是123.123.123.123，那么我在开启端口并开启服务端的情况下，用任意设备的浏览器输入http://123.123.123.123:8080/admin即可访问！（如果使用https，谷歌浏览器可能会提示证书无效等信息，忽略即可，解决办法又是另外一个故事了，与插件无关在此不做详述，用http访问就好）





插件指令及使用说明：


指令权限描述
users listwebapi.user.list显示所有webapi用户
users add <user> [password]webapi.user.add添加一个用户
users pw <user>webapi.user.changepw修改用户密码
users remove <user>webapi.user.remove移除用户

白名单指令权限描述
whitelist add <ip>webapi.whitelist.add添加特定ip到白名单
whitelist remove <ip>webapi.whitelist.remove移除白名单的特定ip
whitelist enablewebapi.whitelist.enable开启ip白名单
whitelist disablewebapi.whitelist.disable关闭ip白名单

blockoprations指令权限描述
ops listwebapi.op.list列出所有正常进行的blockopration
ops pause <uuid>webapi.op.pause暂停/继续 特定的 block operation
ops stop <uuid>webapi.op.stop停止特定的 block operation


notify指令权限描述
notify <name> [params...]webapi.notify.<name>大概是可以给登陆面板的特定用户留下一个提示信息

不明白如何登陆请看下方操作示例，介绍主要的命令使用

黑名单指令及权限将whitelist改成blacklist即可

第三步，设置白名单（仅针对非本地主机用户，例如**云）

默认开启白名单，如果没有设置将无法远程登陆！

白名单指令（此处的白名单是针对ip的！必须在白名单添加ip，这个ip的用户才可以登陆！）

开启白名单 /webapi whitelist enable（默认开启）

关闭白名单 /webapi whitelist disable

添加ip到白名单/webapi whitelist add 你的ip

删除ip从白名单/webapi whitelist remove 你的ip



对应的也有黑名单指令，只是whitelist改成blacklist即可，如有不明白请在后台输入/webapi 即可出现提示


方法一：添加ip到白名单

例如我要从我的手机浏览器访问，假如我知道我的手机ip地址为123.123.123.123，那么在后台输入/webapi whitelist add 123.123.123.123后，我才能通过手机访问登陆页面，否则是打不开的。

方法二：关闭白名单

输入/webapi whitelist disable即可，任何设备都可以访问登陆页面



完成上述操作后，即可愉快的登陆了
