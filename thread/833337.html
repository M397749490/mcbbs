TRY THE NEW MINECRAFT LAUNCHER BETA
试试新的 Minecraft Beta 启动器
Available on PC, Mac and Linux!
在电脑、Mac 与 Linux 上可用


We’re releasing a new Minecraft Launcher beta that we want you to try out! So what changes can you expect in this beta? Hopefully none!
我们发布了一个新的 Minecraft beta 启动器，快来试试吧！那么在这个 beta 中你能看到那些改动呢？但愿没有！

At least none yet. The Launcher app is currently a starting point for playing Minecraft: Java Edition, but we envision a future where it will become so much more! It’ll be the home for our future games within the Minecraft universe, and therefore we’ve started the journey of rethinking how the Launcher will work and look.
至少目前还没有。游戏启动器现在只是作为 Minecraft Java 版的入口点，但我们设想它将来会有更多的作用！它将成为我们将来的 Minecraft 衍生游戏的家园，因此我们也重新开始了对启动器未来工作方式和外观的思考。

In this beta release we have looked under the hood of the Launcher to tidy up and structure the code so it can support bigger changes in the future. This means we’ve made a lot of changes that you can’t see, and hopefully you shouldn’t notice any difference in the functionality either – for now!
在这个 beta 发布中，我们整理了启动器的底层代码，方便将来进行大的改动。这意味着我们做了很多你看不到的修改，但愿你不会注意到功能上有什么不同——当然，只是现在如此！

However, we would love for you to try it out and give us feedback if anything is not working. You can report any bugs you find here, please make sure to choose the ‘Beta (1.2.#-beta)’ version in the drop down when creating the bug report. You are also welcome to share your thoughts on our Feedback site.
不过呢，如果你发现有任何东西不正常工作了，请在这里反馈漏洞，记得在创建漏洞反馈的时候选中「Beta (1.2.#-beta)」版本。你还可以在反馈网站上分享你的想法。

With the Launcher Beta you will automatically receive and experience the latest juicy Launcher updates we are planning to make during the coming year.
使用 beta 启动器，你将会自动接收并体验到我们计划在来年制作的丰富的启动器更新。

平台描述下载
Windows（推荐）双击并安装，非常简单！MinecraftInstaller-beta.msi
Windows（备选）不使用我们方便的安装器来获取 Minecraft。如果你真的想那么做的话。Minecraft-beta.exe
Mac打开，然后把 Minecraft 拖到你的应用里Minecraft-beta.dmg
Debian / Ubuntu安装并运行，不用瞎忙活！Minecraft-beta.deb
Arch Linux从 AUR 安装 Minecraft 启动器minecraft-launcher-beta
其他 Linux需要提前安装 Java 8Minecraft-beta.tar.gz
