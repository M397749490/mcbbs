<>指令说明
/bplay add [房间名] ------ 创建新房间
/bplay set [房间名] ------ 设置房间
/bplay del [房间名] ------ 删除房间
<>创建一个游戏的步骤
  1. 首先输入/bplay add xxx
  2. 之后再输入/bplay set xxx
  3. 然后按照提示破坏方块即可
复制代码

<>游戏区域设置要求
  1. -边框自行设置且不能使用羊毛自行建造模板
  2. -请使用竖立平面且最左上角必须设为点1，最右下角必须设为点2
  3. -破坏方块设置点1，然后破坏一个3x3大小的竖直平面的方块设置点2
复制代码

<>配置文件说明
  1. state: 'true'
  2. room_world: basketball
  3. start_time: '5'
  4. pos1: -521+7+-916
  5. pos2: -521+5+-914
  6. direction: z+
  7. area: 9
  8. length: 3
  9. width: 3
  10. button_pos: -522+5+-917
复制代码
配置文件除start_time外请不要擅自修改
start_time的作用是开始游戏的时间
