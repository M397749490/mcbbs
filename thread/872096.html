NoCommands
完全禁用指令


前言

    MCBBS上已有其他禁用指令的插件，但这些插件都有一个共同的缺点，那就是禁用的指令可以被绕过，如/xxx:xxx，还有的指令无法被禁用，指令一样能执行。

    NoCommands使用了拦截数据包的方式禁用指令，这样可以做到完全禁用指令，并且对/xxx:xxx的绕过方式作出了解决方案。



游戏截图





指令、权限

指令:
指令 用途
/noc 帮助菜单
/noc help 帮助菜单
/noc bypass toggle 切换绕过启用状态
/noc bypass whitelist list 显示白名单列表
/noc bypass whitelist add <玩家> 添加白名单玩家
/noc bypass whitelist remove <玩家> 移除白名单玩家
/noc commands list 禁用指令列表
/noc commands add <指令> 添加禁用指令
/noc commands remove <指令> 移除禁用指令

权限:
权限 用途
nocommands.admin 允许使用管理指令
nocommands.bypass 允许使用被禁用的指令
nocommands.reload 允许重载配置文件

作者: 流离人    时间: 2019-11-12 18:10
这款插件对于我来说非常好，感谢楼主。
好处在于：禁止的指令，玩家可以通过菜单打开，无需额外权限或者OP执行
举个例子，CMI基础插件包含大量的指令，大概有280条指令
如果玩家试这些指令，会弹出“权限不足”或者是“该功能未开启”，虽然没有影响，但是玩家可以摸索出服务器关闭了CMI的哪些功能，开启了哪些功能。
传统的屏蔽指令插件，禁止指令后，在菜单里也会禁止（比如一个菜单选项是/help），除非用OP身份执行。
但众所周知，deluxe菜单没有OP执行项。
但是nocommands可以做到：在CMI所有指令禁止的情况下，玩家可以点击deluxe菜单里的[player] cmi ctext rules（查看服务器规则） 执行指令，无需额外权限或者OP执行
