作者: intesr    时间: 2015-5-27 22:39
否定玩家世界权限
essentials.build.destroy.*     破坏
essentials.build.drop.*         丢弃
essentials.build.interact.*     交互
essentials.build.pickup.*       捡拾
essentials.build.place.*         放置
essentials.build.use.*           使用

mv modify set animals false 动物生成
mv modify set monsters false 怪物生成
打完之后用/killall mobs杀死现有的所有生物


固定时间
/gamerule doDaylightCycle false

作者: Near0    时间: 2015-5-29 10:56
打开server.properties文件
1.把这项
   spawn-protection=     ''=''后面改为10000就可以保护主城世界了
2.这项
   spawn-monsters=true    true改为false，可以禁止生成怪物
3.先输入
/gamerule doDaylightCycle false  
然后设置时间
/time set 5000
这样就可以永远白天了
