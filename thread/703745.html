经验翻倍

这个插件能够让你在服务器中使经验翻倍
可以在举办活动时使用，控制经验倍数

举个栗子
平时你杀一只牛获得十点经验，你输入指令/multiplyxp event set 你自己 3 ,那么你杀一只牛会获得10*3的经验

权限
experiencemultiplier.mx  -  玩家将可以使用插件一切指令（不建议给予玩家）
指令
/multiplyxp event <start|stop> [multiplier]
描述: 开启或关闭一个翻倍。
< start|stop > 开启或关闭一个经验翻倍.< multiplier > 所有玩家经验翻的倍数.

/multiplyxp set <player> <amount>
描述: 设置一个玩家的经验加成倍数。
< player > 玩家名字，注意！玩家必须连接了！< amount > 这个玩家经验翻的倍数.

/multiplyxp add <player> <amount>  
描述: 增加一个玩家的经验倍数。
<player >玩家.< amount > 增加玩家翻倍的倍数。

安装

1.将下载的插件放入你服务器的plugins文件夹
2.重启服务器
3.尽情享受经验加成的快感~
