这款插件对于战争服估计很有用的~
玩家发动线下遁(没血就下线,防止自己被打死掉一地装备)的那种玩家无处可逃！

插件会记录玩家在低血量退出一些开启线下遁防御机制的世界次数
如果次数超过了配置文件里的最大容许次数 就会帮助这名'线下遁'逃窜玩家背包掉落一地在下线坐标,可以自定义设置全服提醒与否以及内容哦~

玩家如果没达到最大限度 重新登入时有温馨提醒 让该玩家不要再犯罪掉线了 掉线的后果很严重hh。
当玩家抵达最大容纳次数时,会对该玩家进行自定义处罚,比如:**/清空背包,并且可以自行提醒该玩家为何给处罚了(可自定义).

配置文本:

  1. #拥有OP权限/QuitPunish.Ignore权限的,有着线下遁保护机制.
  2. Set:
  3.   #血量小于等于这个值退出服务器进行线下遁判断次数+1.
  4.   Health: 4
  5.   #开启的世界.
  6.   Worlds:
  7.     - DAYZ
  8.   #线下遁次数,超过就判断为线下遁.
  9.   Count: 2
  10.   #全服公告开关
  11.   MessageSwitch: true
  12.   #全服公告
  13.   Message: '§c[§d线下遁检测§c]§b:玩家<player>因为血量过低退出了服务器,被系统默认判断为线下遁,现已被惩罚掉落背包所有物品在下线地点周围.'
  14.   #玩家进服的提醒.
  15.   PlayerJoinSwitch: true
  16.   #玩家进服的提醒内容.
  17.   PlayerJoinMessage: '§c[§d线下遁检测§c]§b:由于您退出次数过多,被判定为线下遁操作,已处罚.'
  18.   #玩家退出次数未达到线下遁怀疑时的温馨提醒.
  19.   ProtectMessage: '§c[§d线下遁检测§c]§b:您再退出<num>次将被系统判断为线下遁操作!'
  20.   #清空背包.
  21.   Clear: true
  22.   #**.
  23.   Suicide: true
  24.   #掉落背包全部物品在下线地点.
  25.   DropItems: true
  26.   #OP/或者有 QuitPunish.Ignore 权限的人无视线下遁机制.
  27.   AdminProtect: true
复制代码


插件权限:
OP或者拥有QuitPunish.Ignore权限的人无视线下遁机制.

插件重载指令:
