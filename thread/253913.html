附录：Cauldron启动bat代码
  1. @echo OFF
  2. java -Xmx1024M -Xms1024M -jar cauldron.jar
  3. PAUSE
复制代码
注：cauldron.jar是你下载的服务器端文件名，文件后缀名.jar前是-server而不是-installer。请根据你下载到文件的修改。否则无法运行。
-Xmx1024M与-Xms1024M为服务器最大可用内存 1G=1024M 修改时请根据配置酌情修改。32位JAVA最大支持1024M。
