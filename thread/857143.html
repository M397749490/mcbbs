楼主你好，依照你的问题我给出了下面的方法：
需求插件：Mythicmobs
使用方法：
(这里我就不写如何写一个怪物了，如果需要我可以再写。)
1.首先朝着一个方块（空气也行，推荐方块）输入/mm s create [刷怪点名字] [怪物名字] 这样会在鼠标处生成一个刷怪点
2.输入/mm s set [刷怪点名字] cooldown [时间，单位：秒]
这样子就可以完成楼主所说的设置指定怪物，指定地点，指定刷新时间的刷怪点了。
这里给出一个例子=-=
例子：
/mm s create mc mcbbs                   #创建一个刷怪点叫mc，生成mcbbs这个怪物
/mm s set mc cooldown 666            #设置mc这个刷怪点666秒的cd

最后给出2个地址楼主可以参考借鉴。汉化教程：https://pluginscdtribe.github.io/wiki/mythicmobs/
Minecraft插件百科（已链接到Mythicmobs的刷怪点）：http://mineplugin.org/MythicMobs#.E6.99.AE.E9.80.9A.E5.88.B7.E6.80.AA.E7.82.B9
