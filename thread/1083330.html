WorldGuard


      插件介绍
  • 此插件为Nukkit版的安全区插件
  • 通过划定区域来设置安全区
  • 自定义安全区标签
  • 多种安全区标签类型

      指令&权限
获取帮助 /wg help
列出所有标签 /rg flag
创建安全区 /rg create myregion
添加标签 /rg flag <regionName> <flag> deny
删除标签 /rg flag <regionName> <flag> allow

      使用方法
如何创建安全区？
  • 输入//wand（选择SWorldEdit）
  • 左键第一个方块选择第一个位置
  • 右键另一个方块选择另一个位置
  • 输入/rg create myregion创建


如何给安全区添加标签
  • 添加标签 /rg flag <regionName> <flag> deny
  • 删除标签 /rg flag <regionName> <flag> allow

标签类型
  • block-break：玩家无法破坏
  • block-place：玩家不能放置方块
  • mob-spawning：僵尸无法生成
  • pvp：玩家无法攻击其他玩家
  • damage-animals：玩家无法攻击怪物
  • explosions：取消TNT、苦力怕等爆炸
