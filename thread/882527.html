您可以尝试安装World Edit 模组，安装完后→打开游戏→进入存档→打指令//wand【注意是两个//不是一个/】

或者拿出木斧→使用左键跟右键选取方块【注意木斧拿在手上】→打指令//distr【注意是两个//不是一个/】。


然后就可以了。

以下则是world edit常用指令【注意是两个//不是一个/】
//wand　　　　　　　 取得編輯工具(預設是木斧)
//set ID　　　　　　　填滿方塊
//undo　　　　　　　 復原
//redo　　　　　　　  再製
//hpos　　　　　　　  以準心選取
//replace A B　　　　  把A取代為B
//replacenear d A B　把玩家d格內的A換成B
//pos　　　　　　　以玩家位置選取
//walls ID　　　　　　建立圍牆
//outline ID　　　　　建立輪廓
//overlay ID　　　　　覆蓋
//copy　　　　　　　　　複製
//paste　　　　　　　　　貼上
//rotate Y [X] [Z]　　　旋轉
//stack 數量 [方向]　　堆疊
//move 數量 [方向]　 移動　　
//expand 數量 [方向]　　延伸
//contract 數量 [方向]　收縮
//outset 數量　　　　　外擴
//inset 數量　　　　　內縮
//shift 數量　　　　　移動
//chunk　　　　　　　選取整個chunk(區塊)
//count ID　　　　　計算方塊數量
//distr　　　　　　　顯示所有方塊
//size　　　　　　　顯示選取區的size/資訊


好了如果还有什么问题可以说出来只要在下可以解决！
