* 前言说明：
————————————————————————————
本插件是国外一位插件制作者所写的一个小型插件
此插件虽然小，但是我认为是一个不错的插件，个人认为还是比较有趣的，所以搬运过来
这个插件可以让玩家相互看到对方的末影箱内物品，还是很有趣的
并且，此插件的操作简单，对小白服主非常体贴
————————————————————————————

一.插件命令以及权限节点

ShareChest的官方命令是/ sharechest，但是您可以使用别名/ shch来节省时间。

  • / shch-显示 ShareChest的帮助菜单
  • / shch allow [Player]-允许玩家查看您的无尽之箱
  • / shch不允许[玩家]- 删除玩家的访问权限以查看您的
  • / shch请参阅[玩家]-查看允许您查看其的玩家的
  • 权限点 sharechest.cmd 默认情况下，所有玩家都拥有

三.插件使用教程
  • 输入/ shch 先查看帮助菜单
  • 输入/ shch allow [player] 允许[player]查看我的末影箱
  • 输入/ shch see [player] 输入指令后可以查看[player] 的末影箱了


五.插件配置文件

这个插件并没有配置文件，只需要指令即可（非常容易上手）
这个插件只有一个playerdata的文本用于记录使用查看的玩家
  • player_data:
  •    序列：[]
  • #这里是当前正在存储有关谁可以看到谁的EnderChest的数据。
