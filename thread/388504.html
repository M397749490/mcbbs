作者: Smaoll    时间: 2015-1-23 16:32
打开 \plugins\Essentials 里的 config.yml 文件
找到如下代码并修改（怎么改就不用我教了吧），
  1. # 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
  2. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  3. custom-join-message: "none"

  5. # 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
  6. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  7. custom-quit-message: "none"
复制代码
  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |         Essentials 出生设置 / 新玩家设置             | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7. newbies:
  8.   # 是否显示某玩家第一次进服时的欢迎信息
  9.   # 若开启,编辑内容,{DISPLAYNAME}将自动转换为玩家名字.
  10.   # 若取消,改为''
  11.   #announce-format: ''
  12.   announce-format: '&d欢迎新玩家{DISPLAYNAME}&d来到服务器!'
复制代码
