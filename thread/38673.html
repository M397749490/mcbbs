标题: Minecraft 1.3.1正式版 发布
正式版是Minecraft经过一段时间的预览版测试之后得到的稳定版本，也是众多材质、MOD与CraftBukkit插件会逐渐跟进的版本。官方正版登陆器也会第一时间进行推送。
建议玩家与开服的朋友关注其相关MOD、CraftBukkit与其插件的更新，迎接新的正式版吧！
专注于单人游戏的玩家可立即更新。多人玩家请关注您所在的服务器的通知。
请勿将版本号中不加任何前缀的1.3.1与一年多前的Minecraft Beta 1.3混淆。

经验证，正版启动器已经开始推送。MinecraftSP启动器强制更新也OK

+ 单人模式也会内部运行服务器
+ 单人模式可对局域网开放
+ 多人服务器界面自动搜寻局域网服务器
+ 单人模式加入“作弊”功能（允许使用命令）
+ 新创造的世界加入可选的奖励箱
+ 加入冒险模式（未完善）
+ 加入村民
+ 加入绿宝石及其块、矿石
+ 为丛林加入可可果
+ 加入末影箱
+ 加入绊线
+ 加入带搜索功能的新的创造模式物品栏
+ 采矿与熔炼可能得到经验球
+ 加入可编辑的书
+ 加入“巨型生物群系”世界类型
+ 加入丛林神庙与沙漠神殿
+ 加入聊天设置
+ 加入可开关与监控的反馈信息
+ 为Debug窗口加入更多信息
+ 为非正版用户的启动器加入“演示游戏”按钮
+ /seed命令查看地图种子
+ /defaultgamemode命令设置新加入的玩家的游戏模式=
+ /debug命令
+ SRV记录查询支持
* 降低最高附魔等级：从50到30
* /tp命令可传送到具体的坐标
* 生物可在平坦表面生成=
* 更新语言界面
* 生物更不容易因为漏洞而穿过方块
* 服务器列表可以排序
* 相邻的物品会自动堆叠
* 星星更小更亮
* 末路之地的天空颜色被改变
* 提高“选择方块”键的体验
* 一些以前不可堆叠的物品可以堆叠了
* 山脉生物群系稍稍高了一点
* 木头可以侧放
* 木质半砖表现为木质的性质
* 雨天的树叶会渗水
* 矿车与船可以被发射器放置
* 沙石材质改变
* 拉杆可以在方块底部放置
* 爬行者爆炸会因难度而改变
* 性能改善
* 其它漏洞修正
- 移除 Herobrine
