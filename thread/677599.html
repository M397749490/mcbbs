1.6.4的nbtedit和什么mod冲突？为什么我的整合包一加载nbtedit就闪退
作者: yuudachi    时间: 2017-3-1 11:43
当你的MC同时安装了中文输入补丁和In Game NBTEdit时，In Game NBTEdit将会无法使用。下面是一个简单的解决方案。
1.安装ServerCommandsGUI。注意：下载到的是RAR文件，需要先解压，然后将其中“coremods”文件夹下的东西放到 “.minecraft\coremods”下，将其中“config”文件夹下的东西放到“.minecraft\config”下。
2.配置ServerCommandsGUI。先进入“.minecraft\config”，将scg_vanilla.xml用记事本打开，在最后两行
</category>
与
</commandlist>
之间输入：
<command name="启动 In Game NBTEdit" help="启动 In Game NBTEdit">/nbtedit</command>
然后保存，当进入游戏后按C键打开界面化命令菜单，在最后一行即可看到“启动 In Game NBTEdit”。先用鼠标准星对准要编辑NBT的东西，再按C，用键盘方向键选中"启动 In Game NBTEdit"，按回车键，即可启动In Game NBTEdit。（在上述代码中的"启动 In Game NBTEdit"可以替换为自己喜欢的文字。）
3（可选）. 当你进入游戏后，这个MOD需要很久才能载入。为了快速载入，我们先运行一次游戏，当它载入后（游戏左下角出现提示信息），将“.minecraft\coremods”下的SCG.cfg中的
B:Enable_ModVersionChecker=true
改为
B:Enable_ModVersionChecker=false
以关闭自动更新，即可。
