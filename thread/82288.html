又是一个生存世界，虽然同样有High类设定，不过不打算做相反的世界，同时这回的世界改变了Surface/Nether/End。

整体改变：
┼虚空。
  └主体为空岛。
    └所以改变世界的时候您有可能看到一片虚空。
      └空岛边缘不规则虚空。
Tip:善用Debug，这个世界中的很多东西都不是您所看到的那样。


Surface改变：
┌矿脉。
│└以下为现在的生成设定。
│   ├无洞穴；50%裂谷，将会在Y38（准确的说是Y37.8）及以下填充水，可能延伸到地面。
│   ├矿脉总体生成值：100%
│   ├金：1%-Y0-Y31；
│   ├铁：6%-Y0-Y63；
│   ├煤：10%-Y0-Y255；
│   ├青金石：1%-Y0-Y31；
│   ├钻石：1%-Y0-Y15；
│   ├绿宝石：1%-Y0-Y31；
│   ├水：1%-Y0-Y255；
│   ├岩浆：2%-Y0-Y15；
│   ├泥土：57%-Y0-Y255；
│   ├沙砾：28%-Y0-Y255；
│   ├红石：8%-Y0-Y15。
│   ├树木：取消原本生成，一律50%概率。
│   └雪：整个世界，更多NBT。
├包含一层雪块。
└地平面与海平面更高，起伏更大。


Nether改变：
┌矿脉。
│└以下为现在的生成设定。
│  ├200%洞穴，将会在Y16（准确的说是Y15.8）及以下填充水，可能延伸到地面；无裂谷。
│  ├矿脉总体生成值：100%
│  ├金：0%-Y0-Y31；
│  ├铁：26%-Y0-Y63；
│  ├煤：30%-Y0-Y255；
│  ├青金石：5%-Y0-Y31；
│  ├钻石：1%-Y0-Y15；
│  ├绿宝石：2%-Y0-Y31；
│  ├水：0%-Y0-Y255；
│  ├岩浆：2%-Y0-Y15；
│  ├泥土：0%-Y0-Y255；
│  ├沙砾：18%-Y0-Y255；
│  ├红石：1%-Y0-Y15。
│  └无任何树木。
└地平面与海平面更低，起伏更小。


End改变：
┌矿脉。
│└以下为现在的生成设定。
│  ├40%洞穴，可能延伸到地面；40%裂谷，可能延伸到地面。
│  ├矿脉总体生成值：100%
│  ├金：80%-Y0-Y31；
│  ├铁：1%-Y0-Y63；
│  ├煤：11%-Y0-Y255；
│  ├青金石：0%-Y0-Y31；
│  ├钻石：10%-Y0-Y15；
│  ├绿宝石：0%-Y0-Y31；
│  ├水：2%-Y0-Y255；
│  ├岩浆：2%-Y0-Y15；
│  ├泥土：1%-Y0-Y255；
│  ├沙砾：0%-Y0-Y255；
│  ├红石：18%-Y0-Y15。
│  └无任何树木。
├不规则的岩浆与水。
└地平面与海平面更低，起伏更小。
