怎么设置，或禁止玩家在某个世界圈地
作者: Stupidbanana666    时间: 2016-8-19 00:03
打开GroupManager
打开config
添加你要弄的世界,如下

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          plotworld:
          - users
          all_unnamed_worlds:
          - users
          - groups
          world1:
          - users (红色的就是要添加的,world1可以变换成你想要的世界名，注意下面只要- user~~)
然后游戏里输入/manload
你会发现,worlds里面多了一个文件夹
复制一份原来就有的世界文件夹里的group拷贝过去
进入修改即可

按你的要求，只要在builder组添加

- -residence.create



(前面的两个-必须有！)
若果不行就- -residence.*

求最佳
