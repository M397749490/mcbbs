Github page (https://github.com/NLthijs48/AreaShop)
Spigot page (https://www.spigotmc.org/resources/areashop.2991/)


*插件支持的版本1.7.9+, 1.8, 1.9, 1.10, 1.11 和 1.12

这个插件是为玩家提供租用或购买地区的插件。 它可以用来让玩家在你的监狱服务器里面租用/购买监狱或者在生存服务器里租用/购买一块区域建立商店或任何自己喜欢的建筑，同样适合战争服务器，RPG服务器，等等使用了WorldGuard插件的服务器。安全保障又不用管理。玩家可以与木牌互动，简单快捷方便使用。 它还有很多命令来检查所有区域的状态，管理一个地区的租用和购买以及管理员的功能。除 此之外，插件能够保存区域并在租用到期后恢复到原来的样子，这是非常灵活的功能，可以设置默认适用于每个区域，查看配置显示更多相关信息。


所有功能列表:
  • 向玩家租用和出售地区商店，玩家可以将其购买的地区转售给其他玩家。
  • 区域商店的木牌，方便互动和对话框中显示当前状态。

  • 更改插件的语言或使用已经提供的语言文件（请查看这里支持的语言，里面已经包含了插件本体，只需更改配置文件中的中的语言设置即可）。
  • 自动让插件恢复区域。
  • 设置玩家可以使用哪些命令与权限。
  • 更改配置来自定义插件，更符合自己的服务器使用。
  • 如果将木牌放在区域内就可以自动添加在木牌上。
  • 传送到租用/购买地区商店，还可以选择设置传送点（在该地区内的传送安全点）。

  • 添加朋友到地区商店（TA也有权限传送）。
  • 自动租用/出售很久没上线玩家的区域商店。
  • 如果玩家的租金快用完时（当他们登录时或者他们在线的时候）会自动提示给他们相关信息。
  • 权限组系统可以为几个区域而不是所有区域设置选项。

  • 所有繁重的任务随着时间的推移而分散（每个刻录的一部分被执行直到完成），所以插件不应该造成任何滞后。
  • 租用/购买的数量每个权限节点(玩家权限组)都不一样，在不同模式下的世界（生存/创造）或一个区域权限组（例如：普通玩家可以在生存模式下可以购买1个区域商店+1个建筑区域；创造模式下就可以购买/租用2个区域，而VIP可以拥有双倍的数量）。
  • 因为UUID保存玩家的信息，所有支持玩家更改ID，有关详细信息，请查看FAQ条目：玩家改名后会发生什么？



要求和安装：
  • 支持服务器版本：Bukkit 1.7.9或更高版本，Spigot 1.7.9或更高版本。
  • Java 7或更高版本（推荐最新）。
  • WorldGuard 5.9或更高版本（推荐6.0+）。
  • WorldEdit5.6.3或更高版本（推荐6.0+）。
  • Vault 1.4.1或更高版本。
  • 一个由Vault支持的经济插件（检查Vault页面是否支持）。

当你安装了AreaShop后，先调试好了服务器和所有必需的插件（以及正确的版本），就可以启动服务器了。 你可以根据自己的喜好编辑AreaShop的config.yml和default.yml文件，之后使用“/as reload”重新加载配置。 然后，你可以先创建区域并将其添加到AreaShop中。

指令的详细介绍已经在语言文件里面写很清楚了，

  1. 以下是所有命令及其权限列表。
  2. 权限的默认状态在后面的括号中，“true”表示默认情况下的所有玩家拥有，“false”表示默认情况下玩家没有，
  3. “op”仅表示OP，“non op”的意思是只有非OP才拥有。 如果没有提供可选的[region]参数，
  4. 那么插件将使用自己所在的区域来执行玩家命令（默认状态为true），并且你的worldEdit选择为'op'commmands。

  6. AreaShop的主要命令是'/areashop'，因为这是相当长时间使用的指令了，通常使用别名'/ as'，如果你有一个和这个插件冲突的指令，
  7. 你可以使用主命令或定义你要的指令别名，可以通过Bukkit的Commands.yml文件去修改，请检查此wiki页面。

  9. /as help
  10. 对应权限：
