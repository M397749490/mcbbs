介绍



嫌Towny城镇指令太麻烦,记不住指令?城镇指令太多导致劝退萌新?
那么这款插件就整合了城镇插件的所有指令到菜单内来方便玩家了解城镇.
有了这款插件你就可以让你的玩家只需通过点击菜单就能执行复杂的城镇指令.



指令&权限
指令 权限 作用
- townygui.*插件的 所有权限
/tgui 默认拥有 打开主菜单

/tgui <菜单名>

 townygui.command.* 打开所有菜单的权限
/tgui main   townygui.command.mainmenu OP - 打开主菜单.
/tgui town   townygui.command.townmenu OP - 打开城镇菜单
/tgui towny   townygui.command.townymenu OP - 打开Towny菜单
/tgui plot townygui.command.plotmenu OP - 打开土地菜单.
/tgui resident    townygui.command.residentmenu OP - 打开居民菜单.
/tgui nation townygui.command.nationmenu OP - 打开国家菜单.
/tgui townyworld  townygui.command.townyworldmenu OP - 打开城镇世界菜单.
/tgui reload   townygui.admin.reload OP - 重载配置.
/tgui version
  townygui.admin.version OP - 检测插件版本.

townygui.signs.townyworld 创建城镇世界菜单牌子
townygui.signs.*创建所有牌子
townygui.signs.main 创建主菜单牌子
townygui.signs.town 创建城镇菜单牌子
townygui.signs.towny
创建Towny菜单牌子
townygui.signs.plot 创建土地菜单牌子
townygui.signs.resident 创建居民菜单牌子
townygui.signs.nation 创建国家菜单牌子
牌子格式:

第一行: [townygui]

第二行: {留空}

第三行: <{GUI} Menu> Menu

第四行: {留空}
