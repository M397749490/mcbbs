第一章——线程基础(上)

第一部分——啥是线程
1.1什么是线程？
线程，你可以看做是一个轻量化的进程，是程序执行程序流的最小的单元。一个线程可以有一个ID(名字)
1.2为什么我们要用线程？(同步与异步的概念)
我们举这样一个梨子，假设你去买一台电脑，如果不使用线程(同步进行)的话，你就得在那里看着电脑装在箱子里，再运到你家。
但是如果你使用线程(异步进行)的话，你就可以买完电脑之后就可以出去吃顿饭啥的，这些配送的事情也丝毫不会花费你的时间。这就是异步调用。

第二部分——线程的创建与一些线程常用方法
2.1创建一个线程
有以下几种方法，第一种:
Thread thread = new Thread(new Runnable() {
@Override
public void run() {
//这里是你要运行的代码
});

然后使用thread.start()启动线程，但切记不要用thread.run()方法进行启动，这个方法仅仅是对run方法的调用，调用run方法不能实现异步，必须调用start方法。

第二种:

public class XXX implements Runnable {
public void run() {
//运行的代码
}
}


然后要启动这个线程就可以这样子来玩
XXX instance = new XXX();
Thread thread = new Thread(instance);
thread.start();

第三种:

public class XXX extends Thread {
public void run() {
//运行的代码
}
}



运行方法:
XXX instance = new XXX();
instance.start();
