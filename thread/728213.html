SpigotLib
各种易用的API都在这里


SpigotLib集成了各种有用的库和API，方便插件开发。这个插件不仅可以帮助开发者，也可以让服主使用API来测试命令，非常方便

源码  Javadocs

不兼容的服务器版本
  • 1.8.0
完全兼容的服务器版本
  • 1.8.8
  • 1.9
  • 1.9.4
  • 1.10.2
  • 1.11
  • 1.11.2
  • 1.12
  • 1.12.1
没有列出的版本(更新的或者相似的版本)也应该是完全兼容的，更老的版本部分兼容，所以你也可以在1.6和1.7使用此插件的部分特性。


特性如下
  • AnimationAPI - 轻松创建动态效果
  • Anti Book Hack - 防止玩家在书本里添加过长的json文本来蹦服，或者添加点击执行的 /op 命令等
  • Anti Sigh hack - 同上，不过是牌子
  • BungeeAPI - 非常方便的和其他连接到同一Bungee服务器的服务器传输数据
  • ChatAPI - 非常方便的给聊天添加json消息，也可以使用我的非常方便的自定义格式
  • CommandAPI - 非常方便的使用命令，每个命令都是通过 VariableAPI 执行，所以你可以使用变量
  • ConfigurationAPI - 简化你的配置文件管理，不要再在读取配置浪费时间了。现在还可以使用MySQL
  • EconomyAPI - 非常方便的经济API，支持Vault，支持多种货币，支持其他经济管理插件
  • ItemGuiAPI - 非常轻松的创建自定义的gui，支持背包布局管理
  • JSON API - 你是否厌倦了 Gson，是时候换一个新的API了，和配置管理类似，不过是使用json
  • Language management API - 支持用户选择你的插件的语言文件
  • Map API - 轻松管理自定义地图，使用发包所以非常快
  • Mojang API - 轻松处理你的服务器与MojangAPI之间的通信
  • MySQL API - 不用再担心MySQL的连接了，只需要发送命令得到结果，或者只是做一些后台/异步的update
  • NBT API - 轻松给生物/物品添加自定义nbt
  • TPS meter and crashreporter - 当tps果滴时创建一个含有每个线程的dump信息的崩溃报告
  • Title API - 不用担心版本兼容，向玩家发送标题/子标题
  • PacketAPI - 我创建了一个全新的包API，轻松管理每个包，支持不同的spigot版本
  • PlayerFile - 创建一个用于存储玩家的各种信息的文件，支持文件和MySQL
  • RomanNumsAPI - 支持罗马数字和阿拉伯数字的互相转换
  • ScoreboardAPI - 无闪的计分板API，管理每个玩家的侧边栏/tab栏/名称栏
  • VariableAPI - 支持无限的跨插件的变量API，使用非常简单
  • TimeAPI - 方便地在聊天中显示时间

命令
  • /sl cmd
  • /sl debug
  • /sl item
  • /sl lang
  • /sl migratetodb
  • /sl perm
  • /sl reload
  • /sl save
  • /sl vars
  • /sl velocity


目前支持英语/荷兰语/匈牙利语/德语
