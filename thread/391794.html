他能做些什么？

  • 增加趣味性（废话）
  • RPG服务器可以用来做BOSS的掉落物
  • 因为可以通过权限控制玩家可开的箱子，所以用来做职业礼包之类的也是极好的
  • 也是因为可通过权限控制，所以拿来弄VIP礼包可以防止没权限的玩家开启


听说有人需要效果图什么的，大概就是这个样

注：此处附魔瓶代表经验，在箱子中展示的东西可以随意设置
指令与权限：
  • /givebox <玩家> <箱子ID> ：生成一个箱子给玩家
  • /openbox ：打开手中的箱子
  • /randombox,/rb ：显示插件版本及插件作者信息
  • /randombox reload  ：重载插件配置文件，添加了箱子信息后记得重载哦
  • /randombox list ：列出所有可用的宝箱ID，包括内含的所有奖品信息也显示的出来哦
  • /randomblock create <宝箱ID> <消耗金钱>  ：输入指令后右键方块，它就会变成一个开箱方块，右键就会花钱开指定箱子
  • /randomblock remove  <宝箱ID> ： 移除一个开箱的方块（同上，仅2.4版本可用）
=====================以上为指令部分，下方为权限=====================
  • randombox.* ：RandomBox所有权限
  • randombox.main ：使用/randombox的权限
  • randombox.openbox ：允许你用/openbox开启宝箱（这个给玩家）
  • randombox.givebox ：允许你给予他人宝箱
  • randombox.infinitebox ：宝箱开启后也不会消失，需要在Plugin.yml中将randombox.infinitebox设定为true
  • randombox.open.<宝箱ID> ：允许开启指定的宝箱，比如你将randombox.open.9000权限给了普通玩家，那么他们就可以开启ID为9000的宝箱（注意：需要将配置文件中宝箱的checkPermission设定为true）
  • randombox.open.* ：允许开启所有的宝箱，注意事项同上
  • randombox.randomblock ：允许使用/randomblock指令（当然包括指令下的create和remove）

配置文件
config.yml
  1. # Use metrics. http://mcstats.org/plugin/RandomBox  插件自带统计，无需更改
  2. metrics: true

  4. # Enables randombox.infinitebox permission   启用无限开箱的权限，一般不需要开启
  5. useInfinitePermission: false

  7. # Default locales: en (English), ru (Русский), zhtw (Traditional Chinese), zhcn (Simplified Chinese)  插件本地化选项，改为zhcn即可汉化
  8. locale: zhcn
复制代码
boxes文件夹下（因作者更新后每个奖励箱子独立为一个文件，此处仅讲解自带的例子）9901.yml
论坛貌似因为我发的太长直接给砍了……写了快1小时直接没了，稍后放上yml文件

locale文件夹下的都是一些本地化的语言文件，若对插件内置的汉化有需要改动的，可以更改对应文件


一些需要注意的：

  • 本插件与mod的兼容性暂未测试，请谨慎使用
  • 箱子ID不能为0开头，否则会有箱子无法打开的BUG
  • 版本（2.3版本前）更新后，旧版配置文件可以转换为新配置文件，但奖励箱编辑需要单独新建一个文件
  • 其实不用等完GUI的结果，按E关闭GUI可以立刻结算（这好像不算什么需要注意的吧）
