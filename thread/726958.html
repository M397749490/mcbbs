介绍
该插件是一款基础插件，相比spigot的essentials功能要更强大
并且支持从EssentialCmds一键迁移到本插件，无需重新配置
本插件最新版已支持到API7的1.12.1

★本插件的特点有以下几点★
  • 几乎拥有EssentialCmds的所有特点，并且支持最新的API
  • 以及比EssentialCmds的功能要更多更强大
  • 允许用户自定义管理模块化系统
  • 可禁用指定的命令
  • 可设定延时、冷却以及设定指令收费
  • 允许其他插件接入Nucleus的API

Gluon的作用：
用于给Nucleus支持PAPI的占位符
使用Placeholders的占位符在Nucleus里
Nucleus里面名字的占位符是{{name}}
若要使用PAPI的占位符，格式应该是这样的{%[变量]%}
并不是%%，因此若要使用%player%
就应该要输入{%player%}
使用Nucleus的占位符在Placeholders里
任何Nucleus的占位符前面有需要加个nucleus_作为前缀
例如Nucleus里有{{displayname}}占位符
你可以用PlaceholderAPI的%nucleus_displayname%
你也可以用其他占位符插件，然后使用Nucleus的API
样子就是这样的%nucleus_pl:pluginid:id%

Mixins的作用：
Mixins是用来增强世界生成以及/invsee指令的
由于该插件功能已集成到了1.11以及1.12版本当中
因此只有1.10.X的才需要用到这个插件
可自由开关本插件的功能
  1. # Enables /invsee to work across all players.
  2. invsee=true
  3. # Enhanced world generation
  4. world-generation=true

权限的问题
1000条权限，想必你也不会去一一配置
如果你想方便点，可按照我说的去做
如果你不想进入离开模式，那么就给予nucleus.afk.exempt.toggle权限
如果你想让进出服务器不显示消息，那么就给予nucleus.connectionmessages.disable权限
很多插件会无法达到预期的功能，比如GriefPrevention，因此，请不要使用通配符
建议你添加其他的权限插件，如果没有，你可以在控制台给你自己
nucleus.nucleus.setupperms.base权限，然后就可以在游戏里给权限了
如果你想一次性给完权限
那么请使用该指令/nucleus setupperms [USER|MOD|ADMIN] <groupname>
USER为玩家所用，MOD为管理员所用，ADMIN为服主所用
USER将拥有以下使用权
使用 /afk 进退离开模式
使用 /me 发言
使用 /time 查看服务器时间
创建以及传送到家
查看MOTD
屏蔽其他玩家的聊天
与其他玩家发邮件
使用 /helpop 向OP求救
与其他玩家私聊
使用 /suicide 自杀
使用 /realname 查看一个玩家的真实名字
使用 /list 列出玩家
使用 /rules 看规则
使用服务器商店 (/itembuy 和 /itemsell)
传送到 /spawn 以及 /firstspawn
使用 /tpa 同意和拒绝以及使用 /tptoggle 省的去拒绝
使用 /warp 传送到地标
使用 /getpos 获取自己的坐标
默认玩家权限中没有back指令的使用权
请手动给予nucleus.back.base权限
以及随机传送权限nucleus.rtp.base

想关闭一些功能可进/config/nucleus/main.conf文件
然后找到modules，输入DISABLED即可关闭不想要的功能
