前言

首先我早期发布此插件，距离现在已经很久远了，我发现热度不减，觉定重新编辑此插件帖
作者于2015/7/2更新到1.2版本，至今依旧停留在此版本

此插件作用很简单，输入/namecolor它会打开一个有组织的GUI（也就是箱子菜单），有一大堆的彩色
玻璃窗，当你点击一个（每一个都需要权限）设置用户标签名字颜色对应的颜色。

特性
作者原话：
It currently has a small config as I was running low on time and wanted to type this description out. The option is a prefix for the messages which you can change to be whatever you want. When you click an item it sets the users nametag color to clicked pane color It even supports nicknames!
简单的来说就是此插件很简单，当然也可以配置配置文件已获得更多功能
通过打开GUI界面实现文字颜色的切换，好像也可支持昵称的颜色切换（英语不好）
命令/权限
命令：
/namecolor：打开GUI界面
权限：
namegui.*:给予所有权限
namegui.open: 允许使用/namecolor打开菜单
namegui.gold 给予使用黄色名字权限
namegui.lgreen 给予使用绿色名字权限
namegui.lgray 给予使用灰色名字权限
namegui.dgray 给予使用灰色名字权限
namegui.cyan 给予使用青色名字权限
namegui.dpurple 给予使用紫色名字权限
namegui.dblue 给予使用蓝色名字权限
namegui.dgreen 给予使用绿色名字权限
namegui.red 给予使用红色名字权限
namegui.nickname: 允许用户设置自己的标签名字当作他们当前的昵称
