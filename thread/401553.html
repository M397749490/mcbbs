害怕熊孩子捣毁家园怎么办？ 不用怕！！！！您可以设置领地与购买地皮[推荐购买地皮]！
领地设置方法：
本服圈地工具为”箭“，每格领地0.5元
方法：先用左键选择一个点，再用右键选择一个点，两点所组成的三维空间就是你的领地尺寸
领地指令：选择好两个点后
输入/res select size查看领地尺寸和所需money
再输入/res create 领地名[注意是英文] 来创建领地
创建领地后，熊孩子就搞不了破坏啦！！！
------------------------------
①设置所有人权限
/res set 领地名 权限 t/f
输入t代表同意，f代表否认
②设置玩家权限
/res pset 玩家名 权限 t/f
输入t代表同意，f代表否认
③权限：
use:[使用:仅限于门]，container[容器，如箱子熔炉]，destroy[破坏]，build[建筑
move[移动]，animakilling[动物杀戳，系统默认t，请设置f，此权限为玩家所爱的]。更多权限请加群查看群文件
下列权限只适用于设置所有人权限
piston[活塞运作，默认f，flow[流体流动，默认水f，系统禁止熔岩流动]，healing[治疗]更多权限请加群查看群文件
