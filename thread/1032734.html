我的世界快照20W17A
[size=1.13]我的世界Java快照




本周快照为您带来了一些调整，错误修复和技术更改！
我们也进行了一项调查，以便您可以告诉我们您对下界更新的看法。您可以通过单击[color=rgb(37, 120, 33) !important]此处找到它。如果您能抽出宝贵时间填写表格，我们将不胜感激。
20W17A的新功能
  • 添加了实体距离比例选项，范围从50％到500％
  • 现在可以从“创建世界”屏幕更改难度和游戏规则
20W17A的变化
  • 改进的史密斯表用户界面
  • 现在被破坏的传送门生成频率降低
  • 将“ Soul Fire Torch”和“ Soul Fire Lantern”更名为“ Soul Torch”和“ Soul Lantern”
  • 调整后的堡垒剩余战利品
  • 现在，墙可以在更多物体（例如压板和横幅）下创建帖子
  • 如果没有可供选择的世界，“单人”按钮将直接跳至“创建世界”屏幕
20W17A中的技术更改
  • 聊天组件样式现在可以选择字体
  • 略微更改块中的块存储格式，以加快各种任务（渲染，寻路，生成世界等）
  • 支持全部Unicode字符（有些人可能知道know的含义）
  • 添加了[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]attribute命令
世界保存格式
  • 现在保存level.dat使用随机命名的临时文件（而不是每次使用level.dat_new）
  • 现在以类似于level.dat的方式保存player / *。dat（包括保留.dat_old文件）
块存储
BlockStates  在节  元件不再包含值拉伸在多个64位字段。如果每个块的位数不是2的幂（即，单个64位值不能填满整个块状态），则将不使用某些位。
例如，如果单个块状态占用5位，则将不使用每个64位字段的最高4位。这也意味着存储大小会略有增加（在5位的情况下，从320个到342个64位字段）。
指令[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]属性
在单个实体上添加修改属性。可能的语法：
参数：
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]属性<target> <attribute>获取[<scale>]  -获取属性的总值
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]属性<target> <attribute>基础集<value>  -设置基础值
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]属性<target> <attribute>基本获取[<scale>]  -获取基本值
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]属性<target> <attribute>修饰符add <uuid> <name> <value> add | multiply | multiply_base-  添加修饰符（如果已经存在修饰符则失败）
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]属性<target> <attribute>修饰符remove <uuid>  -移除修饰符
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]属性<target> <attribute>修饰符值get <uuid> [<scale>]  -获取修饰符的值
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]目标  -单个实体（注意：只有玩家，装甲站和小怪才有属性）
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]attribute-属性  名称（例如[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]minecraft：generic.max_health）
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]名字  -字符串（在可选引号）描述修改的人类可读名称
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]value-  浮点值（注意：某些属性对最终值有限制，因此您的更改可能不会引起注意）
聊天组件悬停事件参数
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]style.hoverEvent  参数现在有参数[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]的内容，以根据内容类型：
  • 对于[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]show_text-聊天组件
  • 对于[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]show_item-项目id或具有字段[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]id，[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]count和[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]tag的对象（最后一个序列化为NBT）
  • 对于[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]show_entity-具有以下字段的对象：[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]id（UUID），[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]名称（聊天组件）和[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]类型（实体类型资源位置）
  • 旧样式[color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]值参数现在已弃用（但仍受支持）
色彩
color属性现在可以包含以＃开头的RGB值。例如，＃55ff55  将产生与绿色相同的颜色。
自定义字体
聊天组件样式现在支持字体属性，这是资源包中字体的资源位置。没有条目等效于minecraft：default。
字型
  • [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important] 现在，“ [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]强制Unicode”选项可在普通字体和备用字体（称为“ [color=rgb(120, 36, 197) !important][backcolor=rgb(241, 237, 236) !important]uniform.json”）之间切换-无需重新加载
