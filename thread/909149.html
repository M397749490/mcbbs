注意

前置插件:

- VexView -v2.4以上

由于：VexView2.4的已知BUG(图片自转BUG)，所以推荐VexView2.4.2再打开图片开关

功能

必须使用VexView2.4及以上版本
主要提供玩家消息在头顶显示功能
config.yml可以修改文字的位置和图片的位置
文字提供分行支持
图片提供自适应高度以便对应文字分行

配置文件

  1. text:
  2.   use: true #使用开关
  3.   id: '文字'
  4.   x: 0
  5.   y: 2.7 #最好不要低于2.7
  6.   z: 0
  7.   prefix: '§a' #字体前缀，主要用来自定义颜色。
  8.   length: 10 #单行的最大字数，请勿为0
  9.   black: true #背景是否无黑框
  10.   tag:
  11.     x: 0
  12.     y: 0
  13.     z: 0
  14.     for: true #跟随玩家（跟随显示该Tag的玩家转向而转向）,否则跟随视野（如同玩家名称，始终朝向另一个玩家看他的视野）
  15.     see: true #拥有这个Tag玩家是否可以自己的Tag（就是除了自己以外其他所有人都看得到）
  16. image:
  17.   use: false #2.4有转BUG  图片不推荐使用 （BUG已反馈，下个版本2.4.2应该就可以使用这个了） 如果要使用 推荐下面的for属性改成false
  18.   id: '背景'
  19.   x: 0
  20.   y: 3 #已提供自适应  此数值比text的y推荐高1-5 (根据背景来调)
  21.   z: 0.01 #比文字多0.01  就能把图片贴在文字背后
  22.   url: '[local]item.png'
  23.   w: 80
  24.   h: 30
  25.   xshow: 3
  26.   yshow: 0.4 #这个显示高度已经自适应  推荐边框高度  然后中间是内容
  27.   tag:
  28.     x: 0
  29.     y: 0
  30.     z: 0
  31.     for: true #跟随玩家（跟随显示该Tag的玩家转向而转向）,否则跟随视野（如同玩家名称，始终朝向另一个玩家看他的视野） （BUG已反馈，下个版本2.4.2应该就可以使用这个了）
  32.     see: true #拥有这个Tag玩家是否可以自己的Tag（就是除了自己以外其他所有人都看得到）
  33. time: 5 #聊天显示的持续时间
