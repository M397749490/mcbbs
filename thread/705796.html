这个可以做到 某个世界可以不限制破坏也就是随意破坏。。然后特定某个世界 只能圈地才可以破坏吗？ ...

可以做到
  Flags:
        Global: #下面这些为世界总体默认flag设置, 这会覆盖各个组的设置
            use: true
            build: true
            ignite: true
            firespread: true
            damage: true
            creeper: true
            tnt: true
            pvp: true
       WorldNameHere: #这里你可以设定个人的世界，这些覆盖总体的flag
            #build: true
配置里面上面的flags就是默认所有世界的权限，这里显示的意思是不圈地的情况所有世界的权限都是true，也就是可以破坏，可以PVP，可以使用等等等等。如果你把某项改为false那么所有世界这一项的权限就关闭了，如果你把build后面改为false那么所有世界不圈地就不可破坏。
再说你想做到某个世界可以破坏某些世界不可破坏，那就是下面的 WorldNameHere，这个项的名字你改成你想要单独设置的世界名，打个比方ZC世界吧。ZC世界下面选项你可以自己添加，这里的权限是优先于上面的flags的权限。你可以在下面继续按照格式添加每个世界单独的权限。我写个例子。
  Flags:
        Global: #下面这些为世界总体默认flag设置, 这会覆盖各个组的设置
            use: true
            build: true
            ignite: true
            firespread: true
            damage: true
            creeper: true
            tnt: true
            pvp: true
       sc: #这里你可以设定个人的世界，这些覆盖总体的flag
            build: false
       zc:
            build: false

这个例子的意思就是SC世界和ZC世界不圈地那么就不能破坏方块，而其他世界随意破坏
SC和ZC优先于上面的flags

亲，领地插件本身就可以设置，圈地后才可以破坏，不圈地无法破坏，不需要其他插件。
# 这个是世界flag,不在领地中时
    Flags:
        Global: #下面这些为世界总体默认flag设置, 这会覆盖各个组的设置
            use: true
            build: true
            ignite: true
            firespread: true
            damage: true
            creeper: true
            tnt: true
            pvp: true
       WorldNameHere: #这里你可以设定个人的世界，这些覆盖总体的flag
            #build: true
这个配置就是修改不圈地时候世界的权限，你把Build改为false，那么如果不圈地就无法破坏了。
如果其他改为false那么不圈地也没有那个权限。
至于下面的WorldNameHere是可以更改各个世界不同的权限，例如有的世界可以直接破坏，
有的世界圈地后才可以破坏。
