先简单的介绍一下这个插件吧！{:10_512:}
  这个插件就是十分好用的市场插件！名曰：环球市场。就是传说中的GlobalMarket。

引用之前搬运者介绍！：
玩家可以使用一个简单的命令使用游戏中的GUI系统把任何物品待价而沽
    使用Bukkit的内置存储项目，所以没有元数据被剥离，这意味着它可以与大多数其他插件兼容
    单纯通过Bukkit的API，它不会有过时，除非API变化
    真正的界面，所有交易立即显示出来，而无需“刷新”或关闭GUI
    邮箱系统，让您能够建立市场区域或拍卖行
    指导价是从之前的交易计算的平均价格

环球市场是一个服务器性的市场体系。它可以让玩家通过一个方便的方式使用界面购买和出售物品。它类似于魔兽世界的拍卖行或的Runescape的大交易所。

借助之前搬运者的指令与权限！
  权限·指令
  • globalmarket.admin -最高权限
  • globalmarket.util - 创建邮箱
  • globalmarket.quicklist - 使用 /market listings 打开商品列表
  • globalmarket.quickmail - 使用 /market mail 打开邮箱
  • globalmarket.create - 使用 /market create上架商品
  • globalmarket.send - 使用 /market send发送邮件
  • globalmarket.history - 使用 /market history
  • globalmarket.pricecheck - 使用 /market pricecheck
  • globalmarket.nolimit.* - 越过价格和上架数量限制
  • globalmarket.nolimit.maxprice - 越过价格限制
  • globalmarket.nolimit.maxlistings - 越过上架数量限制
  • globalmarket.noqueue - 越过等待时间
  • globalmarket.infinitelistings - 拥有创建无限商品权限

因为之前搬运者的汉化不行，所以我就找了尘曲的汉化文件补了上去。在此，谢谢之前搬运者的搬运，与尘曲的汉化！衷心感谢{:10_512:}
汉化十分详细具体。我只是负责把汉化的上传。
指令在此：
/market create 价格 数量    把手上的物品上架到市场
/market send 玩家名 数量    把手上的物品发送至另一玩家邮箱
/market mail            打开自己的邮箱
/market listings        打开市场

以上是基本指令
下面的指令不常用或者是op指令。
/market reload 重载插件
/market  history (>数量<) 查看交易历史
/market pricecheck 查看你手里物品的价格（不知道有啥用）
以上~


配置：（引用）
server:
    enable: false
现在请忽略这项,这是为未来的更新
automatic_payments: false
如果设置为 true, 当玩家购买物品后直接付款给卖家,而不是发送到卖家的信箱
enable_cut: true
如果设置为 false, 市场不会采取税收交易
cut_amount: 0.05
税收的百分比
enable_metrics: true
是否禁用 PluginMetrics
