鸡蛋多的没处用？ 机友长途搬运动物太麻烦？ 那么，用这个插件来坑掉机友多（suo）余（you）的鸡蛋吧！~

当前特性
  • 可设置捕捉怪物血量限制
  • 支持保护插件如： GriefPrevention 来保护动物不被捉
  • 兼容所有交易类插件
  • 使用简单，往怪物身上砸个鸡蛋使之变成刷怪蛋
  • 权限支持
  • 可设置捕捉几率
  • 可设置捕捉消耗 (vault 经济支持, 或消耗其他物品).
  • 捕捉时有爆炸效果（只是效果）

前置插件
如果使用金钱消耗，必须安装 Vault

指令
无

  1. UsePermissions: true —— 是否使用权限，true为是，false为否，以下不做赘述
  2. UseCatchChance: true —— 是否启用几率捕捉
  3. LooseEggOnFail: true —— 捕捉失败时是否丢失鸡蛋
  4. UseVaultCost: false —— 是否启用经济花费
  5. UseItemCost: false —— 是否启用物品消耗
  6. UseHealthPercentage: false —— 是否生命百分比捕捉
  7. ExplosionEffect: true —— 是否启用爆炸效果
  8. SmokeEffect: false —— 是否启用烟雾效果

  11. PreventCatchingTamedAnimals: true —— 是否阻止捕捉驯服的动物
  12. PreventCatchingShearedSheeps: true —— 是否阻止捕捉被薅羊毛的羊
  13. SpawnChickenOnSuccess: false —— 捕捉成功时是否刷新一只小鸡（有几率）
  14. SpawnChickenOnFail: true —— 捕捉失败时是否刷新一只小鸡（有几率）
