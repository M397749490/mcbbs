Please Chat
请多聊天，不要自闭


插件简介
你的玩家是否经常自娱 ♂ 自乐，闷声挖矿发大财？
他们都不怎么聊天，服务器显得死气沉沉的，缺乏活力。那怎么让他们多聊天呢？
这个插件就可以帮到你，强制让玩家参与聊天，不然就 —— 嘿嘿嘿
这个插件呢，其实是我在群里看到有人在卖，而且开价 500 块钱，我想着这么简单个插件居然还卖这么贵，实在是说不过去，于是我就试着自己模仿着造了一个，本来只是想写着玩，没想到还真写出来了。



插件的主要功能
这个插件主要的功能和特性有：
  • 让玩家都参与聊天，提高游戏活跃度
  • 给最活跃的玩家发放奖励，以及惩罚那些不愿意参与的玩家
  • 可选不检测 AFK 状态下的玩家
  • 支持自定义聊天发言次数的检测间隔时间
  • 支持自定义每个间隔最少要说多少句话，以及达到发放奖励要求的指定消息数量
  • 支持自定义 AFK 检测超时时间
  • 支持自定义的奖励和惩罚命令，支持多个命令
  • 支持自定义的消息文本以及支持 Title 显示
  • 支持检测重复发送的消息（防止一直按 T ↑ Enter 刷消息数量的玩家）
  • 支持设置消息的最短长度要求


插件的安装和使用
好了我们上面介绍完了各种花里胡哨的功能，那么这个插件怎么安装怎么用呢？非常简单。
  • 首先下载本插件： PleaseChat.jar (10.54 KB, 下载次数: 28)
    2019-8-23 04:17 上传
    点击文件名下载附件
  • 丢进服务端 plugins 目录，重启服务器，重启后会自动生成配置文件。
  • 编辑 config.yml 根据里面的提示配置，然后输入 /psc reload 重载配置文件
  • Enjoy！


插件的命令与权限
插件只需要一个权限：psc.admin
命令列表：
  • /psc enable 开启本插件的功能，你也可以在配置文件中指定 enable: true 自动启动
  • /psc disable 禁用本插件的功能
  • /psc status 查看统计信息
  • /psc reload 重载插件的配置文件


配置文件
以下是一份示例配置文件，请根据自己的需要修改：
  1. # PleaseChat 配置文件
  2. # 是否默认启用插件（你也可以使用 /psc enable 启用）
  3. enable: true

  5. # 检查时间间隔，单位分钟
  6. interval: 10

  8. # 玩家每分钟最少要说多少句话？
  9. minmessages: 1

  11. # 玩家每分钟说多少句话就可以获得奖励？
  12. maxmessages: 10

  14. # 玩家未达到要求时执行的命令，支持多条，用 ; 隔开，用 %player% 代替玩家名，如果命令中带有 ; 请用 %3b 替换
  15. unfinished: "money take %player% 10"

  17. # 玩家达到要求时执行的命令，支持多条，用 ; 隔开，用 %player% 代替玩家名，如果命令中带有 ; 请用 %3b 替换
  18. finished: "money give %player% 10"

  20. # 是否强制检查 Afk 状态的玩家，如果设置为 true，那就相当于禁用掉了本插件内置的 afk 检测功能
  21. checkafk: false

  23. # Afk 超时时间，单位分钟
  24. # 注意这里的 Afk 检测并不是根据 Essentials 插件的，而是本插件自己实现的一个 Afk 检测功能
  25. afkinterval: 3

  27. # 自定义显示消息
  28. lang:
  29.   nextcheck:
  30.     displaytitle: true
  31.     firstline: "&6[&c防自闭系统&6]"
  32.     secondline: "&b系统会统计你在 %time% 分钟内的发言数量，请保持活跃！"
  33.     text: "&6[&c防自闭系统&6] &b请在接下来的 %time% 分钟内发送至少 %min% 条有意义的消息，否则会被惩罚，发送超过 %max% 条将会获得奖励。"

  35.   unfinished:
  36.     displaytitle: true
  37.     firstline: "&6[&c防自闭系统&6]"
  38.     secondline: "&c你因为没有在 %time% 分钟内发送 %min% 条消息而受到惩罚。"
  39.     text: "&6[&c防自闭系统&6] &c你因为没有在 %time% 分钟内发送 %min% 条消息而受到惩罚，请保持活跃，不要自闭！"

  41.   finished:
  42.     displaytitle: true
  43.     firstline: "&6[&c防自闭系统&6]"
  44.     secondline: "&a恭喜你完成了发言目标，你已经获得了奖励，请查收。"
  45.     text: "&6[&c防自闭系统&6] &a你已完成发言目标，系统已经将奖励发送至你的账号。"

  47.   normal:
  48.     displaytitle: true
  49.     firstline: "&6[&c防自闭系统&6]"
  50.     secondline: "&a你完成了最低发言目标，请继续保持活跃。"
  51.     text: "&6[&c防自闭系统&6] &a你已完成最低发言目标，再活跃一点就可以获得系统奖励。"

  53.   broadcast:
  54.     enable: true
  55.     text: "&6[&c防自闭系统&6] &b过去 %time% 分钟里，有 %unfinished% 位玩家因为没有达到最低发言目标被惩罚，有 %finished% 位玩家完成了最高目标获得了奖励，以及 %normal% 位玩家达到了最低发言目标。"

  57. # 消息内容判定
  58. # 内容至少需要多少个字
  59. minlength: 5
  60. # 是否检测重复的消息
  61. checkrepeat: true
  62. # 是否屏蔽重复的消息
  63. blockrepeat: true
  64. # 屏蔽时的提示信息
  65. blocktext: "&6[&c防自闭系统&6] &c请不要连续发送同样的内容。"
