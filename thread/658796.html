开源地址：https://github.com/MIdCoard/DropItem


格外欢快地转来转去仿佛随时都会开始左右横跳的充满嘲讽意味的掉落物

使用后可以将mc原版的掉落物替换为更加真实的静止掉落物，使用新的捡拾方法

本插件只支持1.8及其以上版本


[捡拾掉落物]:
右键或者shift匍匐移动


[指令] :
dropitem clean or /di clean 清理已知的掉落物
dropitem cleanall or /di cleanall 清理类似于掉落物的所有掉落物（不安全，仅在物品加载错误时使用）
dropitem disable or /di disable 安全无遗留卸载DropItem插件
dropitem update or /di update 检查更新
dropitem download or /di download 下载更新，并在插件重载时更新
dropitem updatenow or /di updatenow 立即更新
dropitem reload or /di reload 重载DropItem插件

[权限] :

dropitem.use                                     拥有此权限的玩家掉落物品会立体化
dropitem.command                             拥有此权限的玩家可以使用dropitem指令

[config.yml配置文件]
  1. Version: '9.0'
  2. #用于版本更新时自动更新配置文件，该项请不要修改.
  3. VersionCheck: true
  4. #是否开启版本更新检查。默认为true。为true时VersionDownload默认将无效。
  5. VersionCheckCycle: 10800
  6. #设置版本更新检查时间。如果只在服务器启动时检查，则为false。默认为10800（单位为秒）。
  7. VersionDownload: true
  8. #是否开启新版本自动下载。默认为true。
  9. DropForm: normal
  10. #设置物品掉落形式。normal: 掉落在地上后立体化。w-spawn: 掉落立即立体化。默认为normal。
  11. PickForm: normal
  12. #设置物品拾起形式。normal: 右键或者shift+移动拾取。w-move: 玩家靠近拾取。right-click：只能右键拾取。默认为normal。
  13. PitchX: 100
  14. PitchY: 135
  15. PitchZ: 100
  16. #设置物品持有角度。默认为100，135，100（范围为0-360之间）。
  17. EnableCoverBlock: false
  18. #是否启用覆盖方块（修复不能再掉落物上面放方块的bug）。默认为false。
  19. EnableAliases: true
  20. #是否启用子指令。默认为true。
  21. EnableStats: true
  22. #是否启动数据统计（只用于总体数据统计，不会单独储存任何数据）。默认为true。
  23. ShowItemInfo: true
  24. #是否显示物品信息。默认为true。
  25. DropItemAI: true
  26. #是否开启性能优化AI。默认为true。
  27. WaitingTime: 20
  28. #设置物品掉落拾起冷却时间。默认为20（单位为tick，0为无冷却时间）。
  29. Language: zh_CN
  30. #设置生成物品显示名字语言。zh_CN：显示名字为中文简体。zh_TW：显示为中文繁体。其他代码均显示英文。默认为zh_CN。
  31. NaturalSpawn: true
  32. #是否自然生成（即所有掉落方式）的物品立体化。默认为true。为true时后面一项（即AllowedPlayer）默认将无效且允许所有玩家使用该插件。
  33. AllowedPlayer: true
  34. #是否允许所有玩家拥有使用该插件的权限。默认为true。为true时后面一项（即AllowedPlayers）默认将无效。
  35. AllowedPlayers: MidCoard
  36. #设置当AllowedPlayer为false时的白名单玩家。默认为MidCoard（作者Minecraft玩家名）。多个玩家请用“,”（即英文状态下的逗号）隔开。
  37. BanItem: AIR
  38. #设置生成时不需立体化的物品。默认为AIR（请使用大写，可以使用数字）。多个物品请用“,”（即英文状态下的逗号）隔开。
  39. RefreshTime: 300
  40. #设置物品掉落消失时间。如果物品不消失，则为false。默认为300（单位为秒）。
  41. Height: 0.3
  42. #设置物品悬空高度。默认为0.3（范围为0-1之间）。
  43. Angles:
  44.   - AIR 100 135 100
  45. #设置某种物品持有角度。默认为 AIR（请使用大写，可以使用数字） 100 135 100。多个物品请分行并以“-”隔开。
