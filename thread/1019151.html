如何使用 Python 的 NBT 库？

我按照我的方法操作，报错。

以下是我的做法：

  • 下载 NBT 库
    • 来到：https://github.com/twoolie/NBT
    • 点击右上角的 Clone or download
    • 选择 Download ZIP
  • 解压压缩包
    • 将压缩包提取到当前位置
    • 进入文件夹 NBT-master
    • Shift+右键 —> 在此处打开命令窗口
  • 导入 NBT 库
    • 运行命令：python setup.py install
  • 测试
    • 将原版的 data\minecraft\structures\end_city\base_floor.nbt 复制到桌面
    • 在桌面上新建 test.py
    • 打开并添加：
      1. import nbt
      2. nbtfile = nbt.NBTFile("base_floor.nbt",'rb')
      复制代码

      • 运行和调试
      • 报错：
        发生异常: AttributeError
        module 'nbt' has no attribute 'NBTFile'


Python 版本：
Python 3.7.7 (tags/v3.7.7:d7c567b08f, Mar 10 2020, 09:44:33) [MSC v.1900 32 bit (Intel)] on win32
