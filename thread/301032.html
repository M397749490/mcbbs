问:

GroupManager权限插件中的group.yml文件是设置组权限的，对吗？

答:是的，groups.yml是组权限,users.yml是个人权限.

问:
为什么有些权限前面加“- -”，有些权限前面只加“-”？
权限前的“- -”和“-”分别代表什么？

答:Bukkit 的YamlConfiguration 中 读取list(列表)的正确格式是这样的：
  1. Section1:
  2.   - a
  3.   - b
  4.   - c
复制代码

而你说的 '- -'是相当于它的名字(谁说权限里不能包含 '-' 呢？)
  1. Section1:
  2.   - -a
  3.   - -b
  4.   - c
复制代码


问:
什么是“继承”呀？

答:继承相当于组1继承组2的所有权限,例如:
  1. groupA:
  2.   permissions:
  3.     - a
  4.     - b
  5.     - c
