怎么设置所有人默认权限组是builder组？怎么设置所有世界的权限是连通的？为什么我在server.properties里面改了spawn-protection=999999但是却没有作用？

作者: 729007894    时间: 2016-6-5 11:38
一.所有世界权限连通在\plugins\GroupManager\config.yml下设置
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           all_unnamed_worlds:
  9.           - users
  10.           - groups
复制代码

二。默认权限组
将Default下面的default：true改为false，将Builder下的default：false改为true
  1. groups:
  2.   Default:
  3.     default: false
  4.     permissions:
  5.     - -bukkit.command.kill
  6.     inheritance:
  7.     - g:groupmanager_default
  8.     - g:bukkit_default
  9.     - g:essentials_default
  10.     - g:towny_default
  11.     info:
  12.       prefix: '&e'
  13.       build: false
  14.       suffix: ''
  15.   Builder:
  16.     default: true
  17.     permissions: []
  18.     inheritance:
  19.     - default
  20.     - g:essentials_builder
  21.     - g:towny_builder
  22.     info:
  23.       prefix: '&2'
  24.       build: true
  25.       suffix: ''
复制代码

之后/manload重载，如果还是没有权限请使用/manuadd 玩家名 builder切换权限组！
