如何驾驭服务端？

玩家常用的指令我都写在/help里了，在游戏内输入指令即可！

某腐竹问：地图没被加载怎么办？
答：输入/mv reload 即可！

某腐竹问：怎么换崩坏世界存档？
答：先输入 /mv delete SkyWorld 删除世界
再输入 /mv create SkyWorld normal -g SkyStoneGen 创建一个

某腐竹问：默认的权限组是什么啊？
答：默认权限组：Builder 输入/mangaddp Builder <权限名> 添加权限即可！

某腐竹问：我要给VIP多个地皮要怎么给？
答：输入/mangaddp <VIP权限组> plots.plot.3 这个指令就是给3块地皮

某腐竹问：我随意创了个世界但是玩家没有破坏权限怎么办？
答：输入/mangaddp Builder NoBuild.<世界名> 允许玩家在那个世界建筑

某腐竹问：服务器内的信息怎么改成我想要的怎么改？
答：在plugins文件夹的 BasicTab JoinTitle MOTDColor 文件夹的config修改即可

某腐竹问：怎么端口映射？怎么开服？
答：点我

某腐竹问：怎么给OP？
答：点我

某腐竹问：怎么开启死亡不掉落？
答：传送到你要开启的世界输入 /gamerule keepInventory true 即可！


清理服务器做出优化的部分指令！
插件网址：LaggRemoverPlus
/lrp tps           查看你服务器的tps
/lrp ram                 查看你服务器的内存信息
/lrp gc                                                    进行内存清理，这个命令可以释放你50%的内存占用
/lrp clear items -w清除世界丢弃的物品。
