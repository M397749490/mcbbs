标题: 黏土士兵教程
黏土士兵可以带装备大家应该知道，可是能带些什么装备呢？我会一一讲述我的发现。

要玩黏土士兵，要JAVA7和Forge。


物品          外貌                  功能

    玻璃板        带了眼镜              反隐形
    鸡蛋          半透明                隐形
    木棍          手持木棍              加攻击 +
    皮革          穿了皮甲              加防御 +
    烈焰棒        手持烈焰棒            加攻击，使敌人着火
    烈焰弹        手有黑点              扔烈焰弹攻击
    雪球          手有白点              扔雪球攻击，使敌人迟缓
    绿宝石        手有绿点              雷电攻击，有使用限制
    碗            手持圆盾              加防御 +
    箭            手持箭                加攻击 ++，加攻距 +
    骨头          手持骨头              加攻击 +++
    铁锭          变大了                应该是更能扛，更能打
    金粒          头戴王冠              变成国王，其他人会跟着它
    钻石          头戴蓝王冠和蓝披风    行动加快，其他人跟随
    糖            无                    行动加快
    火药          身上有灰点            死亡时自爆
    萤石粉        身上有黄点            发光
    红石          无                    导致混乱
    粘液球        无                    攻击带禁锢效果
    纸            有披风                无
    砖块          无                    站立不动
    地狱砖        无                    火焰皮肤
    末影珍珠      肤色偏黑，双手举起    变得六亲不认
    所有食物      无                    必要时会血
    黏土          无                    复活同伴
    石英          无                    学会战争踩踏，有技能冷却
    烈焰粉        无                    秒杀遇到的第一个敌人
    岩浆膏        身上有绿点            让击杀你的敌人自爆而亡

请不要相信加号，那都是预估
    其中，他们还会拿仙人掌和线，但劳资昨晚弄了好久都不知道有什么用



装备都分为：
1.近战装备（右手）     2.远程装备（左手）    3.护甲    4.头    5.皮肤装（皮肤上看得出）   6.隐藏装(别人看不出）
所有同种装备只能带其一

1.右手
    木棍     烈焰棍     箭       半片剪刀（本人不太喜欢）
2.左手
    绿宝石/绿宝石块（多几发）       烈焰弹         雪球
3.护甲
   皮革
4.头
   玻璃板（反隐形）         皇冠
5.皮肤
   铁锭（变大了）         岩浆膏       火药         萤石粉
6.隐藏
    其他没列出的就是



最后，大家分配兵种时最好有栏杆围住
