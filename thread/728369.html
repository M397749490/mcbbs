特点 | Feature


  • 让你选择你自己的鹦鹉宠物在你的肩膀！
  • 自定义颜色
  • 面板
  • 自定义配置



指令&权限 | Cmd And Permissions



命令
/Parrots : 打开面板!
/Parrots Reload : 重载插件!
/Parrots Version : 显示插件信息!
/Parrots set (玩家) (位置) (颜色) : 设置

权限

对应鹦鹉的颜色
灰色 - Parrots.GRAY
蓝色 - Parrots.BLUE
青色 - Parrots.CYAN
绿色 - Parrots.GREEN
红色 - Parrots.RED
