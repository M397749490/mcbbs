标题: 怎么做一个快捷的盔甲包
例如手上拿着一根木棍，右击后身上自动装备一套铁甲。
作者: HangBack_    时间: 2019-8-2 15:27

如果版本是 1.8及以上，1.12.2及以下
那么首先得生成一个循环并且无敌隐形和无兑换内容的村民（傻子村民）命令如下：
  1. /summon villagers ~ ~ ~ {Tags:["right.click"],ActiveEffects:[{Id:14,Amplifier:255,Duration:99999}],Invulnerable:1b,NoAI:1b,Offers:{Recipes:[]}}
复制代码
但是注意，我们必须保证每个玩家身边有一个村民，所以我们得改造一下命令，以下在1.12+可以用函数执行（直接创建一个函数，创建方法如下，进入存档文件找到data，再找到functions，如果没有找到请自行创建，然后在里面创建一个文件夹，并且取一个你喜欢的英文名字（只能带英文，防止出错），然后进入这个文件夹，再创建一个txt文档，并且全部（包括格式）都重命名为：一窜英文.mcfunction，一窜英文请改成你喜欢的英文名称，也不要带有除了-_.等以外的其它符号，然后用notepad打开该文档，将编码格式改为UTF-8 且无Bom格式），放进函数后请循环运行这个函数，1.12-需要按照#后的提示用命令方块运行
  1. #用循环命令方块执行（暂时不要保持开启）
  2. execute @a[tag=!player,c=1] ~ ~ ~ summon villagers ~ ~ ~ {Tags:["right.click"],ActiveEffects:[{Id:14,Amplifier:255,Duration:99999}],Invulnerable:1b,NoAI:1b,Offers:{Recipes:[]}}
  3. #用连锁命令方块并与上一个循环命令方块连接（且保持开启）
  4. execute @a[tag=!player,c=1] ~ ~ ~ scoreboard players tag @s add player
复制代码


这样就可以生成一个没有交易项的“真”傻子村民
其次，我们得让这个村民一直跟着玩家，那么此时我们就需要用到tp
命令如下
  1. execute @e[type=villager,c=1] ~ ~ ~ tp @p
复制代码
然后我们得想办法检测玩家正在与村民互动
于是我们就得创建一个计分板
命令如下
  1. /scoreboard objectives add 英文 stat.talkedToVillager
复制代码
英文请改成你喜欢的英文，不要带符号（防止出意外）
然后我们循环检测这个计分板上分数的变化
命令如下（同样参照之前说的那样，可以放进函数，也可以按照提示放置命令方块）
  1. #放置一个循环命令方块（暂时不要保持开启）输入以下命令
  2. scoreboard players tag @s add stick {SelectedItem:{id:"minecraft:stick"},Count:木棍的数量（-128~127）没有则去掉包括前面的半角逗号,tag:{木棍的一些标签，没有则不填}}
  3. #连锁命令方块，连接上一个循环命令方块，保持开启
  4. execute @a[score_刚才创建计分板用的英文_min=1] ~ ~ ~ give @s[tag=stick] 你需要给的装备id
  5. #连锁命令方块，连接上一个连锁命令方块，保持开启，如果需要多增加几个装备就多增加几个如上这个连锁命令方块，并以此填好你需要给的装备id，为了防止重复给，我们得清除玩家的分数
  6. execute @a[score_刚才创建计分板用的英文_min=1] ~ ~ ~ scoreboard players reset @s 刚才创建的计分板用的英文
复制代码
以上就是全部，如果有问题再找我，接下来是1.13+的解决方法
首先创建一个计分板
  1. /scoreboard objectives add 英文 minecraft.custom:minecraft.talked_to_villager
复制代码
其次，按照提示，或者创建数据包（自己看教程），ruhuasiyu的教程
  1. #循环命令方块
  2. execute as @a at @s if entity @s[nbt={SelectedItem:{id:"minecraft:stick",Count:数量（-128~127）不需要则去掉本段,tag:{其它标签，没有则不填}}},scores={刚才创建计分板使用的英文=1..}] run give @s 装备id
  3. #连锁命令方块（如果有其它装备请多增加如上，但改成连锁命令方块，并连接）
  4. execute as @a at @s if entity @s[scores={刚才创建计分板使用的英文=1..}] run scoreboard players reset @s 刚才创建计分板使用的英文

作者: xmdhs    时间: 2019-8-2 20:11
看了下，似乎检测木棍很麻烦的样子，检测胡萝卜杆不仅简单，而且有现成的。

https://www.mcbbs.net/thread-817939-1-1.html

具体是这样 ，先按照上面的帖子设置一些命令方块。
先创建两个记分板
/scoreboard objectives add used_coas stat.useItem.minecraft.carrot_on_a_stick
/scoreboard objectives add goataway dummy

获取一个特别的胡萝卜杆 /give @p minecraft:minecraft:carrot_on_a_stick 1 0 {effects:["goataway"]}

然后高频下面几个命令
  1. /scoreboard players tag @a remove goataway
  2. /scoreboard players tag @a add goataway {SelectedItem:{tag:{effects:["goataway"]}}}
  3. /scoreboard players set @a[tag=!goataway] used_coas 0
  4. /scoreboard players add @a[score_used_coas_min=1] goataway 1
  5. /scoreboard players set @a used_coas 0
  6. /scoreboard players reset @a[score_goataway_min=1] goataway
  7. /execute @a[score_goataway_min=1] ~ ~ ~ replaceitem entity @s slot.armor.legs minecraft:iron_leggings
  8. /execute @a[score_goataway_min=1] ~ ~ ~ replaceitem entity @s slot.armor.head minecraft:iron_helmet
  9. /execute @a[score_goataway_min=1] ~ ~ ~ replaceitem entity @s slot.armor.feet minecraft:iron_boots
  10. /execute @a[score_goataway_min=1] ~ ~ ~ replaceitem entity @s slot.armor.chest minecraft:iron_chestplate
