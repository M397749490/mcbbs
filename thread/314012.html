标题: RPGITEM美观问题
我在服务器里制作了一个RPGITEM的武器，但是武器展示名下面的one handed,20-40damage,sword之类的东西怎么删，如果不能删的话怎么改颜色，求助{:10_497:}
作者: 堕星辰    时间: 2014-8-3 13:56
能删能改
/rpgitem ID hand 改成你想要的
/rpgitem ID type 改成你想要的
至于20-40damage这个是攻击力如果你要去掉就/rpgitem ID damage 0
如果要改成中文或者别的要自己到RPGitem的文件夹里找到config
打开你会看到
defaults:
  hand: hand
  sword: sword
  damage: damage
  armour: armour
把格式改成ANSI
然后你就可以打中文，下面的是我的服务器里的给你参考
defaults:
  hand: 级别：
  sword: 类型：
  damage: 点攻击力
  armour: 的防御
