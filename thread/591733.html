是否还有些人用@ECHO OFFjava路径 -Xmx最小内存 -Xms最大内存 -jar "核心文件名".jarPAUSE来开服呢？这种开服的方式比较老土(ˉ▽￣～) 切~~这种开服方法的坏处就是：
服主，服务器崩啦，快来开一下！
                           好的，我这就来
服主，服务器又崩啦~！

                               好的，我来了
服主，服主。。。。。

                               。。。。。。
服务器连连崩，自己没办法守在服务器旁。。。看到别人购买的服务器可以崩服自动重启好羡慕啊！
我来教大家弄个优化式bat开服器=v=
崩服自动重启、自优化内存、隐藏自身窗口(开服器的cmd窗口感觉好难看，因此我选择隐藏)再也不用守在服务器旁啦~！

下面开始亮出我的bat代码：
@ECHO OFF
if "%1" == "h" goto begin
mshta vbscript:createobject("wscript.shell").run("""%~nx0"" h",0)(window.close)&&exit
:begin
REM
#白色字体的代码是隐藏自身窗口，大家可不＞(￣ε￣ = ￣3￣)<要
:start
"E:\config\java\bin\java.exe" -server -Xincgc -Xms768m -Xmx768m -XX:+AggressiveOpts -XX:+UseCompressedOops -jar Start.jar -nojline
goto start
#红色字体是自优化内存的代码，（这句代码站内有介绍：http://www.mcbbs.net/thread-478126-1-1.html）可以删掉，其余部分为崩服自动重启代码
