插件介绍

Rank Upper插件可以给你的Sponge服务器加入等级系统

可以根据玩家的等级、金钱、经验来自动提升玩家等级

工作原理

英文介绍

This plugin compares the primary group the player is, normally the first of PEX (if the player is in more groups) and if this group is set on configuration, check all requeriments and if done with all, execute the comand to promote the player, and optionally you can configure as many commands you want to give money, messages, etc.

简单翻译

这款插件首先获取玩家的初始组（一般是default组，如果玩家处在多个组，则默认为父组），如果初始组在插件配置中存在，则判断玩家是否满足升级要求，如果满足，则执行相应的指令，如等级提升指令、奖励指令等等，这些指令都需要自行配置。

全部指令

  1. /ru check - 检视已游玩时间以及升级条件.
  2. /ru check [player] - 检视其他玩家.
  3. /ru top - 显示游玩最长时间的前十个玩家.
  4. /ru player-info <player> - 显示玩家信息.
  5. /ru set <player> <minutes> - 设置玩家游玩的时间.
  6. /ru add <player> <minutes> - 给玩家添加游玩时间.
  7. /ru save-all - 保存所有玩家的状态.
  8. /ru load-all - 加载所有玩家的状态.
  9. /ru reload - 重载插件.
  10. /ru addgroup <group> <nextGroup> <time> <level> <money>- 添加等级组.
  11. /ru setgroup <group> <nextGroup> <time> <level> <money>- 设置等级组升级要求.

配置文件（你需要自学♂成才）
  1. # 日期格式.
  2. date-format="dd/MM/yyyy"

  4. # 调试信息
  5. debug-messages=false

  7. # 玩家信息存储时间间隔
  8. flat-file-save-interval=20

  10. # 语言
  11. language=EN-US

  13. # All configurations for promote players based on requeriments.
  14. ranked-groups {
  15. #按照下面的格式添加权限组和指令
  16. default {

  18.         # 玩家升级时执行的指令
  19.         execute-commands=[
  20.             "pex user {player} parent delete group {oldgroup}",
  21.             "pex user {player} parent add group {newgroup}",                       
  22.             "xp 50L {player}",
  23.             "adminpay {player} 2000",
  24.             "pex reload"
  25.         ]

  27.         # 升级所需等级，
  28.         levels-needed=50

  30.         # 升级后广播信息
  31.         message-broadcast="&a>> The player &6{player} &ahas played for &6{time} &aand now is rank {newgroup} of server."

  33.         # 在线时长要求
  34.         minutes-needed=120

  36.         # 金♂钱要求
  37.         money-needed=1000

  39.         #下一级权限组名称，区分大小写
  40.         next-group=Member
  41.     }
  42. }

  44. # 玩家在线时长更新间隔
  45. update-player-time-minutes=5

  47. # 是否使用UUID存储玩家信息
  48. use-uuids-instead-names=true
