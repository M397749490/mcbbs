指令和权限
Commands/Perms
CommandDescriptionPermission
/sc这个插件的主指令
/sc setspawn <竞技场名字>设置复活点mgsnake.setup
/sc setlobby <竞技场名字>设置大厅(在你站的地方)mgsnake.setup
/sc setmainlobby设置主大厅(你站的地方)mgsnake.setup
/sc savearena <竞技场名字>保存这个竞技场mgsnake.setup
/sc setmaxplayers <竞技场名字> <人数>设置可以加入这个竞技场的最大玩家mgsnake.setup
/sc setminplayers <竞技场名字> <人数>设置可以加入这个竞技场的最少玩家mgsnake.setup
/sc setarenavip <竞技场名字> <true(是)/false(否)>设置竞技场是否需要权限进入mgsnake.setup
/sc removearena <竞技场名字>配置中删掉一个竞技场mgsnake.setup
/sc removespawn <竞技场名字> 从配置中删除一个竞技场的复活点mgsnake.setup
/sc join <竞技场名字>加入一个竞技场
/sc leave退出这个竞技场
/sc start <竞技场名字>开启一个停止了的竞技场mgsnake.start
/sc stop <竞技场名字>停止一个已经开始了的竞技场mgsnake.stop
/sc list显示出所有的竞技场
/sc reload重新启动config.yml


Setup 教程
You need to install MinigamesLib for the plugin to work
这个插件需要MinigamesLib这个插件才工作
Also, you'll need Vault for economy rewards to work.
当然你也要装经济插件来让插件工作
/sc setmainlobby set the main lobby where all join signs will be
/sc setmainlobby 设置所有竞技场的主大厅
/sc setlobby [arena] set the waiting lobby
/sc setlobby [竞技场] 设置一个竞技场的大厅(与上面不一样)
setmainlobby是设置所有竞技场退出游戏后的大厅,setlobby是设置每一个竞技场的次大厅(你有多少个竞技场就可以设置多少个次大厅[建议不要在主大厅设置])


/sc setspawn [arena] sets the player spawn, repeat for
/sc setspawn [竞技场] 设置玩家的出生点可以重复
               multiple spawns (but keep them near the first one)
       可以多个复活点(但是还是以第一个为准)
/sc savearena [arena] You can now set a join sign (optionally). Lines
/sc savearena [竞技场] 你现在可以保存了,现在是加入牌子

配置
Config 配置
There are a few config files (config.yml, classes.yml, arenas.yml, messages.yml, stats.yml) which are mostly self explanatory. Be aware that guns.yml is not used in this minigame!
有一些配置文件(config.yml, classes.yml, arenas.yml, messages.yml, stats.yml)会有些问题，要知道guns.yml(大概说的是枪械文件啥的)
config:  default_max_players: 4 # default amount of maximum players that are allowed to join an arena  默认最大的玩家数: 4 这是默认的最大玩家数量  default_min_players: 2 # default amount of minimum players that can join an arena  默认最小的的玩家: 2 这是默认的最小玩家数量  lobby_countdown: 30 # amount of time in seconds to countdown in lobby  大厅的倒数时间: 30 在次大厅开始游戏的时间(秒)   ingame_countdown: 10 # amount of time in seconds to countdown ingame before the final start  在游戏中倒数时间: 10 在时间的最后几秒开始冲刺  rewards:    奖励    economy: true    是否奖励金钱: 是    economy_reward: 10 # You'll need Vault for economy to work    给的钱数: 10 这个必须要装经济插件才工作    item_reward: false    是否奖励物品: 否    item_reward_ids: 264*1;11*1 # 264 being the id, you can specify an amount (the '*1') and enchantments (e.g. 264#DAMAGE_ALL:2*64 would be sharpness 2 on a stack of diamonds)    给的物品: 264*1;11*1 给一个ID为264的物品一个;给ID为11的物品一个还有倍数(264#DAMAGE_ALL钻石全部[一组]:2*64 给2*64个钻石两组)    command_reward: false    输入指令: 否    command: pex user <player> add SKILLZ.*    指令: 添加一个玩家到一个权限组(啥玩儿)  global_arenas_size: 30 # not used in this minigame  地图大小: 30(此为边长30格) 这是最小的地图大小  
You can also specify data on an item reward. If you would want 32 enchanted red wool blocks, you'd adjust the config to: 35:14#DAMAGE_ALL:1*32, where :14 is the data for red, 35 the id for wool, and the rest as explained above.
你还能指定其他项目奖励的数据。如果你想32块红色羊毛，你会调整配置：35:14 # damage_all：1×32，其中：14是红色羊毛的附加数，35的ID为羊毛，其余的依靠上面。

Kits/Classes 礼包/类别
There are 2 classes, a speed and a jump class. As always, you can adjust them in classes.yml.
有两个一个为速度和跳跃,这些你都可以在classes.yml中修改
