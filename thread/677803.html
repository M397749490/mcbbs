起床命令
  • 在这里你可以看到所有的命令以及命令的说明，您可以看到每个命令可能或需要的参数。斜体的参数是可选的，其他的参数需要设置。
  • 懒癌发作，暂时翻译到这里，将会翻译后续命令

/bw help {page}
  • 这个命令可以显示插件所有命令的信息，OP或者拥有 bw.setup 权限的玩家将会显示管理帮助，其他玩家将会看到权限 bw.base 的任何命令。
  • 权限: bw.base
  • 参数:
  • page 可选数字: 添加page参数来切换页数。

/bw addgame {name} {minplayers}
  • 使用这个命令你可以创建一个新的起床游戏。
  • 权限: bw.base
  • 参数:
  • name 文本: 此参数指定游戏的名称，将用于其他任何与游戏相关的命令。
  • minplayers 数字: 在大厅开始游戏的最小的玩家数量. 只有配置文件的 lobbycountdown-rule 项设置为 1 时，这个项才会生效。

/bw removegame {game}
  • 这个命令将会卸载并删除关于指定起床游戏的所有储存数据。
  • 权限: bw.setup
  • 参数:
  • game 文本: 将被删除的游戏。

/bw setspawner {game} {type}
  • 允许管理员或者拥有 bw.setup 权限的玩家来设置资源刷新点。
  • 权限: bw.setup
  • 参数:
  • game 文本: 将要添加资源刷新点的游戏。
  • type 文本: 资源刷新的类型，类型可以在配置文件里设置。

/bw addteam {game} {name} {color} {players}
  • 给游戏添加队伍
  • 权限: bw.setup
  • 参数:
  • game 文本: 添加队伍的游戏。
  • name 文本: 将在计分板和队伍选择上显示的队伍名字。
  • color 队伍颜色: 队伍的颜色，你可以在 Teamcolor wiki page 页面看到所有可选的队伍颜色，颜色不区分大小写。

/bw save {game}
  • 保存游戏数据，当你对游戏做出任何更改时都需要使用此命令保存!
  • 权限: bw.setup
  • 参数:
  • game 文本: 将要保存的游戏.

/bw setregion {game} {id}
  • 执行此命令设置区域角。两个角 (loc1 and loc2)需要设置保存区域，飞到游戏地图的右上角使用 /bw setregion {game} loc1 来设置第一个位置 ，飞到游戏地图的的左下角使用 /bw setregion {game} loc2 来设置第二个位置.
  • 权限: bw.setup
  • 参数:
  • game 文本: 将要设置地区的游戏名字
  • id 文本(loc1;loc2):  "loc1" 或 "loc2".

/bw join {game}
  • 当执行此命令的时候，你（当前玩家）将会加入命令给出的游戏，如果游戏正在进行中或者处于关闭状态，你将无法加入。否则当游戏正在运行的时候你将作为一个旁观者加入，如果游戏处于等待状态，你将加入到大厅。
  • 权限: bw.base
  • 参数:
  • game 文本: 要加入的游戏

/bw setspawn {game} {team}
  • 给指定的游戏和队伍设置复活点（位置和方向）
  • 权限: bw.setup
  • 参数:
  • game 文本: 将要设置复活点的游戏
  • team 文本: 将要设置出生点的队伍名字（不是队伍颜色）

/bw setlobby {game}
  • 设置给定游戏的大厅，大厅必须和游戏处于不同的世界，大厅位置将会设置在你（命令执行玩家）的站立位置。
  • 权限: bw.setup
  • 参数:
  • game 文本: 将要设置大厅的游戏

/bw settarget {game} {team}
  • 此命令允许为团队设置核心方块（一般是床，我这里就这样说了）。这是每个团队都需要的。要设置一个核心方块，你必须站在配置里所设置的核心方块上。
  • 权限: bw.setup
  • 参数:
  • game 文本: 将要设置核心方块的游戏.
  • team 文本: 将要设置核心方块的队伍.

/bw leave
  • 离开当前的游戏
  • 权限 bw.base

起床权限
  • 假装这里有些文字。

bw.base
  • 允许玩家加入并游玩起床游戏。
  • 默认: 开启

bw.setup
  • 允许设置或者维护起床游戏（应该是管理员或者op所应有的权限）
  • 默认: OP

bw.vip.*
  • 允许玩家使用vip特性（详见子权限）
  • 默认: OP
  • 子权限
  • bw.vip.forcestart
  • 允许玩家在大厅等待的时候在背包里有一个强行开始的钻石按钮
  • bw.vip.joinfull
  • 允许玩家加入一个满人的游戏/大厅，将会踢出一个普通玩家。

bw.cmd
  • 允许玩家在游戏起床中使用与起床不相干的命令（例如/lobby或者/gamemode）
  • 默认: OP

bw.otherstats
  • 允许玩家使用命令 /bw stats {player} 插件其他玩家的统计信息
  • 默认: OP

bw.kick
允许玩家使用 /bw kick {player} 命令将另一个玩家
默认: OP
