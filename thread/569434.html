[fishing_rod]插件说明

☆你可以通过这个插件来控制玩家或者生物☆

☆你可以通过用做出来的道具来进行控制玩家、生物，被控制的玩家、生物将不能攻击、移动、跳跃等☆

食用方法

☆下载插件然后添加到你的plugin文件夹开启服务器即可☆

指令

输入/cap查询所有命令

/cap get 获得一个捕获鱼竿

/cap give 玩家名字 给这个玩家捕获鱼竿

/cap reload 重载配置文件

[diamond_gem]权限

capturerod.command 默认分配给每个人

capturerod.get 使用/cap get 的权限    默认op拥有

capturerod.give 使用/cap give 的权限    默认op拥有

capturerod.reload 使用/cap reload   重载配置文件    默认op拥有

capturerod.action 默认每个人拥有

capturerod.* 此插件的最高权限

[paper]配置

# CaptureRod v1.0.2
# @author     ucchy
# @license    LGPLv3
# @copyright  Copyright ucchy 2014

# 距离范围
# 你可以参考的数值 1 - 30.
captureRange: 8

# 是否启用物品合成？默认：是
enableCraft: true

# CaptureRod 的长度
wireLength: 3.0

# CaptureRod 的张力
# 如果你设置更小的值拉力将更强.
wireTension: 5.0

# 用这个物品一次消耗的耐久
durabilityCost: 2
