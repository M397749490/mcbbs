clan是一个简单公会插件
他拥有公会插件该有的功能
并且没有其他不需要的功能



指令:
/Clans
查看所有指令
/Clans Delete
解散公会
/Clans Rename <Name>
为公会重复名
/Clans SetHome
设置公会基地
/Clans DelHome
删除公会基地
/Clans Invite <Player>
邀请一个人到你的公会
/Clans Kick <Player>
T人
/Clans PvP
切换公会团员的PVP
/Clans Create <Name>
创建一个公会
/Clans Leave
离开一个公会
/Clans Accept
接受公会邀请
/Clans Deny
拒绝公会邀请
/Clans Home
传送到公会基地
/Clans Chat <Message>
公会聊天
/Clans Info [Clan]
显示公会的信息
/Clans List
显示所有公会
/Clans Help
显示插件信息
前面的clans可以换成c和clan
红色为公会会长才可以使用
橙色为公会成员就可以使用


权限:
Clans.use 玩家给这个权限就好了
http://www.mcbbs.net/thread-429826-1-1.html此帖的权限错了



配置文件:
auto-update: true  是否自动更新
chat-format-prefix: '&7<&6%clan%&7>'  聊天时的公会前缀,与Ess的前缀不冲突 %clan%代表公会名
clan-home-delay: 5  传送到公会基地需要的时间 单位为秒
clan-pvp-default: false  公会默认PVP是否开启
clan-chat:
  prefix: '*'    在聊天前加上*自动公会聊天
  format-owner: '&7[&3公会聊天&7](&4会长&7) &c%player%&7: &6%message%'    会长公会聊天显示的内容
  format-member: '&7[&3公会聊天&7](&2成员&7) &6%player%&7: &6%message%'   成员公会聊天显示的内容
similar-cmd-suggestions: true  是否开启补全指令  例如:输入/clan hom 会自动变成/clan home
