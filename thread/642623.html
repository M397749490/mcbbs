新件golden_sword.json(金剑)，并保存于材质包assets\minecraft\models\item内
golden_sword.json内输入以下并保存

  1. {
  2.     "parent": "builtin/generated",
  3.     "textures": {
  4.         "layer0": "items/gold_sword"
  5.     },
  6.     "display": {
  7.         "thirdperson_righthand": {
  8.             "rotation": [ 15, 90, 0 ],
  9.             "translation": [ 0, 7.5, -3 ],
  10.             "scale": [ 1.8, 1.8, 1.8 ]
  11.         },
  12.         "thirdperson_lefthand": {
  13.             "rotation": [ 90, 0, 170 ],
  14.             "translation": [ -3.5, -5.5, 7 ],
  15.             "scale": [ 1.8, 1.8, 1.8 ]
  16.         }
  17.     }
  18. }

assets里面没有你说的那些路径啊

用材质包
路径为
.minecraft\resourcepacks\材质包名字\assets\minecraft\models\item
.minecraft\resourcepacks\材质包名字\assets\minecraft\textures\items
(没有那些文件夹的话就新建一个)
还有我上次脑抽，1.8开始材质包才支持模型的修改。
所以你问的1.7.10是不行的。
------------------------
你那个是直接开游戏文件吧，如果你打算直接修改内核的话，也不是不可以。
旧版本直接有asset文件夹，而现在....还是不废话了
.minecraft\versions\版本号.jar
那个版本号.jar用压缩文件打开查看，assets文件夹就在里面。


毕竟你这个是直接改内核文件，除非特殊原因，不建议这么做。
