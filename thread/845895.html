功能

- 多种菜单物品获取方式
- 支持全局变量(PlaceholderAPI)
- 可配置菜单操作声效
- 可配置多套菜单
- 树形结构菜单,可包含任意多级
- 多种显示条位置可选择
- 菜单显示格式配置
- 提供完善的开发API

命令

(提示: <变量>代表必须变量, [变量]代表可选变量)
/mcmenu reload: 重载菜单插件
/mcmenu get <菜单名>: 将手中的物品变为指定菜单

一般情况下你不需要手动使用以下命令:

/mcmenu join <菜单名> [菜单格子]: 加入菜单,菜单格子如果未指定,则会使用当前打开的菜单的格子,如果当前没有打开的菜单,则使用当前格子
/mcmenu left: 左移
/mcmenu right: 右移
/mcmenu confirm: 确认
/mcmenu back: 返回
/mcmenu exit: 退出

权限

/mcmenu reload: 需要后台或OP玩家才能发出
其他命令不需要权限

如何获取菜单?

- 管理通过命令获取菜单后,通过商店或其他方式发放给玩家(推荐)
- 普通玩家直接通过命令来获取菜单
- 如果你有开发能力,可以通过以下方式获取菜单物品: McMenuApi.getItemManager().saveMenuInfo(item, menuName)
- 甚至如果你需要自定义菜单物品,则只需知道以下情况下物品会判定为菜单物品: 物品lore第一行为配置里的lore.check值,物品lore最后行为配置里的lore.menu值

如何使用菜单?

- 将菜单物品放在快捷栏任意位置
- 进入菜单/确认: 点击菜单物品
- 返回: 点击快捷栏第八格(也就是倒数第二格)
- 退出: 移动即可退出菜单(走两步就退出了)
- 左移: 点击快捷栏第一格
- 右移: 点击快捷栏第九格(也就是倒数第一格)
(提示: 菜单物品不要放在快捷栏第一,二,八,九格,否则会冲突,这个很容易发现)

配置文件

实际使用的是config.yml与lang.yml,比如你需要使用中文语言,可以将lang.yml备份一下,再将lang-cn.yml改名为lang.yml

  1. #菜单获取方式
  2. get:
  3.   #是否允许普通玩家通过命令(/mcmenu get <菜单名>)获取菜单
  4.   #(OP始终允许)
  5.   cmd: true

  7. #菜单退出方式
  8. exit:
  9.   #移动退出
  10.   move:
  11.     #是否开启
  12.     enable: true
  13.     #移动距离,实数,>=0
  14.     distance: 0.5
  15.   #打开容器界面退出
  16.   openInventory:
  17.     enable: false

  19. #菜单物品信息显示
  20. lore:
  21.   #菜单物品标识,可使用颜色字符&
  22.   check: "&e+&a菜单&e+"
  23.   #物品标题,可使用颜色字符&,'{0}'代表菜单名
  24.   title: "&a{0}"
  25.   #描述列表,可使用颜色字符&
  26.   descriptions:
  27.     - "&e将菜单物品放在快捷栏"
  28.     - "&e进入菜单/确认: &7点击菜单物品"
  29.     - "&e返回: &7点击快捷栏第八格"
  30.     - "&e退出: &7移动即可退出菜单"
  31.     - "&e左移: &7点击快捷栏第一格"
  32.     - "&e右移: &7点击快捷栏第九格"
  33.   #菜单名行,可使用颜色字符&,问好?是菜单名占位符
  34.   menu: "&7(?)"

  36. #显示
  37. #可用显示条:
  38. #  title: 屏幕中央Title
  39. #  subTitle: 屏幕中央副Title
  40. #  tip: 在subTitle下
  41. #  actionbar: 在tip下
  42. #  popup: 在actionbar下
  43. #  chat: 聊天窗口
  44. display:
  45.   #字数限制,格式'显示条 限制',默认无限制
  46.   limit:
  47.     - "title 16"
  48.     - "subTitle 32"
  49.     - "tip 64"
  50.     - "actionbar 64"
  51.     - "popup 64"
  52.   #刷新,格式'显示条 刷新间隔(单位tick)',默认不刷新
  53.   #有些显示会淡化,所以需要刷新
  54.   refresh:
  55.     - "tip 30"
  56.     - "actionbar 30"
  57.     - "popup 30"
  58.   bar:
  59.     #主条,用来显示菜单
  60.     main: "subTitle"
  61.     #次条,用来显示描述
  62.     sub: "actionbar"
  63.   #显示格式
  64.   format:
  65.     #开头,可使用颜色字符&
  66.     start: ""
  67.     #结尾,可使用颜色字符&
  68.     end: ""
  69.     #中间(分隔符),可使用颜色字符&
  70.     separator: " &c| "
  71.     #当前菜单项,其中'{0}'代表项内容,可使用颜色字符&
  72.     current: "&a{0}"
  73.     #非当前菜单项,其中'{0}'代表项内容,可使用颜色字符&
  74.     notCurrent: "&7{0}"
  75.     #描述的格式,其中'{0}'代表描述内容,可使用颜色字符&
  76.     description: "&e{0}"

  78. #声音(操作反馈,只在用快捷栏操作时发出)
  79. sound:
  80.   #声音大小,实数
  81.   volume: 1.0
  82.   #声音的pitch,实数
  83.   pitch: 1.0
  84.   #加入,可选
  85.   join: "RANDOM_ORB"
  86.   #左移,可选
  87.   left: "RANDOM_POP"
  88.   #右移,可选
  89.   right: "RANDOM_POP"
  90.   #确认,可选
  91.   confirm: "RANDOM_POP"
  92.   #返回,可选
  93.   back: "RANDOM_POP"
