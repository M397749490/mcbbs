本帖最后由 荣辱观 于 2020-3-3 19:40 编辑
功能
可以让玩家使用GUI自由选择聊天的色彩
支持各种权限配置!
无需汉化 无需图片
可以做成氪金项目
指令&权限
  1. /chatcolor - 打开GUI
  2. /chatcolor help - 查看帮助
  3. /chatcolor reset <player>-重置玩家的聊天颜色
  4. /chatcolor set <player> <color code> - 为玩家设置一个聊天颜色
  5. 使用颜色代码,如:&a, &b, etc.
  6. /chatcolor reload - 重载插件
复制代码
  1. chatcolorgui.use - 允许使用/chatcolor
  2. chatcolorgui.help - 允许使用/chatcolor help
  3. chatcolorgui.reset - 允许使用 /chatcolor reset <player>
  4. chatcolorgui.set - 允许使用 /chatcolor set <player> <color code>
  5. chatcolorgui.reload - 允许使用 /chatcolor reload
  6. chatcolorgui.color.* - 允许使用所有颜色
