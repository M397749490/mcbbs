标题: 领地插件查看玩家所有领地的权限
求解服务器怎么关闭领地插件玩家/res listall的权限 也就是玩家查看所有领地的列表的权限
作者: 极光酋长    时间: 2017-8-18 02:00
  res的插件信息 plugin.yml 文件下有如下条目：
  1.   residence.command.listall:
  2.     description: Allows to access particular command
  3.     default: true
复制代码

在权限组禁用即可：
   residence.command.listall
【额外建议】
·命令/list(s) ，默认玩家拥有
    residence.command.lists
    residence.command.list
·查看其它玩家领地
    residence.command.list.others
作者: cc7w    时间: 2017-8-18 15:19
mangaddp builder -residence.command.list.others
