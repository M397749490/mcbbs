关于巫术游戏

巫术游戏一款受《英雄联盟》启发开发的我的世界小游戏插件。巫术游戏包括了很多功能、玩法和特殊物品！游戏的目标是摧毁其他玩家的BOSS(BOSS你可以理解为《英雄联盟》中的水晶),在前往BOSS的路上有小兵来保护BOSS和防御塔免受破坏。每当你击败一个保护者你就可以获得金币，金币可以提升你的巫术（技能），法力和HP。在我们的API包里包括完全定制设计的巫术和被动技能以及可选英雄，因此巫术游戏是高度定制的，你甚至可以创建自己的英雄和升级树。

API

我为那些想要添加自定义英雄或者升级的服主们创建了一个API，以下是API目前可用的功能:

想要创建一个自定义英雄（或者升级）：
1、创建一个英雄class（类）来扩展英雄
Ps.你仍然需要在'addltems"中来给予护甲
2、为你的英雄创建巫术和class来扩展巫术
3、在你的onEnable项中，将冠军加入到冠军名单中
例子:Witched.getKits().addKit(KitItemitem) 工具包项目获得冠军class等...
关于一些事件(Event)：
  • GameEndEvent: 当游戏结束的时
  • GameJoinEvent: 当玩家加入时
  • GameLeaveEvent: 当玩家离开时
  • GameResetEvent: 对局结束后
  • GameStartEvent: 当游戏开始时
[size=14.6667px]更多的API将会很快发布！

指令与权限
  • witched.player：给予所有玩家可用指令的权限
  • witched.admin：给予所有管理员可用指令的权限
  • witched.champions.<名字 或者 * 指代所有>：单个或者每个英雄权限
  • witched.upgrades.<名字 或者 * 指代所有>：单个或者每个升级树的权限[/td]

指令
  • /witched about - 查看插件版本
  • /witched kit - 打开工具菜单
  • /witched join/leave - 加入或者离开游戏
  • /witched setLobby - 设置一个大厅出生点
  • /witched setup/delete <地图名> - 创建或者删除一张地图
  • /witched start - 强制开始一局游戏
  • /witched mana/gold <玩家名> <数值> - 给玩家设置一定数值的法力值（mana）或者金币（gold）
