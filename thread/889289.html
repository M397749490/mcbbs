你权限文件的配置文件给世界分类，
world:             #主世界
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
          - DIM-42
          - DIM-19
          - DIM69
          - DIM1
          - DIM-1          #这些世界都是继承主世界的权限
          - DIM7
          - dp
          - zy
        DIM3:            #这个世界单独生成一个权限文件
          - DIM4           #这个世界继承DIM3的权限文件
        zc:                    #这个世界也单独生成一个权限文件
          - fb                   #这些世界继承zc世界权限文件
          - pvp
然后关闭某个世界建筑权限
