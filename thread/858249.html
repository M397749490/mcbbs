提醒: 插件代码更新到了1.13，应该支持其他版本

插件不会在你第一次安装插件且mojang服务器离线时生效。在mojang服务器正常时安装插件才能生效!

下载该插件可能需要‘特殊手段’ 未测试插件是否有效
介绍
插件设置了一个定时重复任务来检测正版验证服务器是否离线. 如果严重服务器离线，插件将进入mojang离线模式.
在这个模式下，服务器会允许匹配上次登录ip的玩家进入服务器. 如果ip不匹配则拒绝登录. 如果新玩家在mojang服务器离线时加入服务器也会被拒绝.

特点 · Features

  • 将上一次已验证的数据存储到 FlatFile 或 MySQL 数据库内
  • UUIDs 不会被破解. 玩家的UUIDs 总是一致的.
  • 不需要第三方软件
  • 兼容大多数bungee、spigot和bukkit 插件
  • 轻量、高效
  • 无需前置插件库
  • 兼容 Bungeecord版本
  • 兼容 spigot 版本
  • 完全免费!


指令 & 权限
  • /alwaysonline toggle - 手动切换离线模式.
  • /alwaysonline enable - 检测mojang验证服务器是否发芽.
  • /alwaysonline disable - 停止检测.
  • /alwaysonline reload - 重载配置.

所有指令的权限为：alwaysonline.usage


汉化配置 · Configuration
  1. #欢迎来到 AlwaysOnline 主配置文件!
  2. #检测验证服务器是否离线的间隔.单位为秒
  3. check-interval=60
  4. #在验证服务器离线时显示在MOTD上的消息. 设置为 'null' 来关闭.
  5. message-motd-offline=&eMojang土豆服务器发芽了,\n&e但是你仍能正常登录!
  6. #发送给在验证服务器离线时尝试登录但IP不匹配的玩家的消息.
  7. message-kick-ip=由于你登录的IP不同所以你暂时无法进入服务器!
  8. #发送给在验证服务器离线时登录的新玩家的消息.
  9. message-kick-new=由于mojang验证服务器离线你无法登录!
  10. #发送给用无效用户名登录的玩家的消息.
  11. message-kick-invalid=无效的用户名.
  12. #服务器离线时显示的消息. 设置为 null 来关闭.
  13. message-mojang-offline=&5[&2AlwaysOnline&5]&a Mojang土豆服务器现已发芽!
  14. #服务器在线时显示的消息. 设置为 null 来关闭.
  15. message-mojang-online=&5[&2AlwaysOnline&5]&a Mojang服务器在线!
  16. #以下为三种检测mojang验证服务器是否离线的方式.
  17. #比如, 如果 http-head-session-server 为 true 且 mojang-server-status 也为 true,
  18. #插件会使用这两张方式来验证服务器是否离线.
  19. #从该网站获取服务器状态： https://sessionserver.mojang.com/
  20. http-head-session-server=true
  21. #使用 https://help.mojang.com/ 获取Mojang服务器状态
  22. mojang-server-status=false
  23. #使用 http://xpaw.ru/mcstatus/
  24. #不推荐使用xpaw , 因为这缺少合适的API支持
  25. xpaw-status=false
  26. ##########################################
  27. #    Mysql 数据库信息
  28. #    只在使用 mysql 时需修改
  29. ##########################################
  30. use_mysql=false
  31. host=127.0.0.1
  32. port=3306
  33. database-name=minecraft
  34. database-username=root
  35. database-password=password
  36. #不要改这个!
  37. config_version=5
