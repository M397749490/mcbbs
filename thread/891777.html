          这是一个可以自定义世界矿物生成机制的插件，可以设置生物群系中的特定矿物生成机制，且完全可以用GUI进行所有的操作。


                       指令
/orecontrol                                 打开GUI编辑面板                        
/orecontrolreload reload           重新加载messages.yml文件      
/orecontrol set                           设置矿石生成                              
/orecontrol setbiome                 设置生物群系的矿石生成            
/orecontrol create                      创建一个矿物生成模板                 
/orecontrol help                         打开命令列表
/orecontrol help set/create/help/reload/setbiome         获取该命令的详细信息
