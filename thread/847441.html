下载地址
介绍 · Introduction
Canyon World Generator可以让你创建由巨型峡谷和溪流构成的世界.可用于RPG或荒野大镖客：救赎风格的服务器

目前世界不会生成矿洞等原版结构，不推荐用于生存

v1.1版本的插件只兼容1.14.4
图片


特点
  • - 生成溪流、山坡、灌木和植物.
  • - 支持地图种子
  • - 生成峡谷世界


使用方法
下载插件并放到插件文件夹内.

使用Multiverse-Core


/mv create [世界名] normal -g CanyonWorldGenerator

使用Multiworld:


/mw create 你的世界名 plugin:CanyonWorldGenerator

或在 bukkit.yml 内加入以下内容:

  1. worlds:
  2.   world:
  3.     generator: CanyonWorldGenerator
