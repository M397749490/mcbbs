简介

这个数据包增加了两种药水：回忆药水和增强版回忆药水


大部分的功能机制跟泰拉瑞亚中的同名物品一样

回忆药水在使用时传送回玩家出生点（床旁边或重生锚旁）

增强版回忆药水在其基础上增加一个用于返回的传送门

至于为什么我想做出这两个东西

因为我发现在我的服务器中玩家有传送回家的需求，可是我不想让/home泛滥，而又不想要搞冷却时间恶心人

所以就想到了这个东西




药水介绍

回忆药水

使用后将玩家传送到设置的出生点旁，如果未设置出生点或者出生点被不可穿过的方块堵住则会传送到世界出生点

增强版回忆药水

功能与普通版回忆药水一样，只不过在传送回家之后会在原地创造一个传送门，站在传送门上按住Shift可传送回最开始使用药水的地方

传送门由粒子组成，且只有传送门的创造者才能看见和使用传送门，多个玩家的传送门可以重叠在同一个位置

关于材质

默认情况下两种药水是原版的喷溅型药水，对应的自定义材质下载地址与数据包的放在了一块

这两个材质均是从泰拉瑞亚中提取出来的，如果需要其他材质可以自己换

自定义材质采用CustomModelData ID占用在200~205 （喷溅型药水）


获取

由于在原版中合成表不能有nbt，且这个数据包不测重获取部分，所以这个数据包中的两种药水并无法通过生存获取

想要获取两种药水请使用指令
/function recall_potion:potions/give_potion

如果你想把这两种药水用于联机或者多人生存，请使用村民或者自定义战利品表来增加获取药水的途径

如果需要控制传送药水是否可用，可使用
/scoreboard players set enable_tp_potion calcscore 0 禁用传送药水
/scoreboard players set enable_tp_potion calcscore 1 启用传送药水
可使用命令方块或者其他指令进行控制，开关对整个世界（全服）有效


原理

两种药水的原理极其简单

玩家在舔过床之后会在nbt中设置自己重生位置，分别是SleepX，SleepY和SleepZ

使用药水时盔甲架执行execute store将三个nbt存进三个不同的记分板中，再将盔甲架位置修改为记分板中的位置，最后将玩家tp过去

而增强版回忆药水就是在其基础上记录玩家起始位置和维度并在玩家靠近传送门潜行时将玩家传送回去即可

整个功能实现最难的部分是区块加载的问题，例如你强行将一个非玩家实体tp到未加载区块后，这个实体将无法再被实体选择器找到

在PlanetMinecraft上也有人做过回忆药水的数据包，他用的办法是将玩家出生点周围五个区块强加载

但这样在多人游戏中，尤其是服务器中可能会导致实体过多甚至导致服务器崩掉

那么避免由于在未加载区块导致实体选择不上怎么办？

很简单，由于@s可以一直追溯实体

我们就可以让盔甲架在tp到未加载区块之前以自己为执行者执行一个function，在function中tp过去即可


多人游戏兼容性

那么既然药水要支持多人游戏，怎么才能用目标选择器找到使用药水的玩家呢？

虽然理论上讲我们可以记录玩家UUID找到玩家，但由于UUID数字过大，无论如何存不进记分板

我所使用的方法是用一个算法生成一个玩家标签（相当于数据包内部ID）

我使用了一个相当简单的算法生成玩家ID，新玩家没有ID的自动分配一个，ID又小至大，如果两个玩家ID重复则随机其中一名玩家将其ID数字+1


如果有人想把这个数据包加入到服务器中，你需要确保没有Ess等会毁坏原版指令和记分板的插件（Team无所谓）
