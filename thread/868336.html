看到目前行尸走肉火已经退掉了，且安全区插件也差不多都知道了，为了防止行尸走肉大佬们封锁且对新人腐竹施加压力，特在此发出行尸走肉的官方安全区插件，且手把手教你使用！
首先，下载好前置（WGRegionEvents我自己都没找到合适的QAQ），如果你的前置找对了，他后台就正常运行，否则会无限报错，挤爆你的log文件。然后接下来，就是教程了：
1.WorldGuard教程就不在这里赘述了，自己百度去查吧。
2.这个拓展插件分为这几个权限：
  1. Flag（权限点）: can-break-legs（能摔断骨头）
  2. Default（默认ALLOW为开启DENY为关闭）: ALLOW
  3. Description（描述）: Determines if a player can break a leg in the region（决定你的玩家能否在这个区域摔断骨头）

  5. Flag: can-waterlevels-update（会掉水分）
  6. Default: ALLOW
  7. Description: Setting to DENY will force the players in the region to max water level（设置关闭会让你的玩家水分值保持最高）

  9. Flag: can-view-tags（能访问头条...不是那个头条）
  10. Default: ALLOW
  11. Description: Will players in the region be able to view player tags above eachothers heads?（你想让你的玩家在此区域内看到头上的名字条？）

  13. Flag: can-take-bullet-damage（能受到子弹伤害）（重点来了！）
  14. Default: ALLOW
  15. Description: In a region with this set to DENY, players wont take bullet damage（如果调成关闭，玩家将不会在此区域受到子弹攻击伤害）

  17. Flag: can-take-blood-damage（流血受伤）
  18. Default: ALLOW
  19. Description: In a region with this set to DENY, players wont take bleeding damage（如果调成关闭，玩家将在此区域不会受到流血伤害）

  21. Flag: can-take-infection-damage（感染伤害）
  22. Default: ALLOW
  23. Description: In a region with this set to DENY, players wont take infection damage（如果调成关闭，玩家将在此区域不会受到感染伤害）

  25. Flag: can-throw-grenade（扔手榴弹）
  26. Default: ALLOW
  27. Description: Determines if a player in the region can throw grenades or not（决定你的玩家在此区域内能否扔手雷）(终结扔毒气弹杀人的熊孩子)

  29. Flag: cd-build（建筑基地）
  30. Default: DENY
  31. Description: Acts as a custom 'build DENY' flag but lets custom Crafting Dead events pass. If you set this to ALLOW you must set the build flag for the region to ALLOW.（调为关闭玩家在此区域内无法建造基地）
