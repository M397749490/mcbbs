介绍 · Introduction
这款插件可以让玩家一次性放置多个方块.
插件共有3个等级可供使用.
潜行水平放置方块，不潜行则垂直放置方块.
指令 & 权限
指令:
/Fastplace set <方块数量> - 一次性放置自定义数量的方块
/Fastplace disable - 关闭快速放置模式
/Fastplace help - 显示帮助
/Fastplace reload - 重载插件

权限:
Fastplace.use - 允许玩家使用 /Fastplace help 和 /Fastplace disable

Fastplace.reload - 允许使用/fastplace reload

Fastplace.custom - 允许使用 /Fastplace set <方块数量> 来一次性放置多个方块

快速放置等级权限位于配置内，你可以自行修改.

使用方法
给予玩家fastplace.level.1 权限即可获得一级快速放置

默认
一级放置3个方块
二级放置6个方块
三级放置9个方块
放置的方块数和权限可在配置内修改 你也可以按照配置创建四级五级······

玩家输入/fp 1 即可启用一级快速放置 以此类推
