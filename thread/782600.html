Zombie Awareness
僵尸意识
现在，怪物们得到了进化，他们会闻到你散发出的血腥味
甚至可以通过你发出的声响来找到你。
采矿将会更加危险，记得规划一条逃生路线，
尽量避免发出不必要的声音。
演示视频
https://static.hdslb.com/miniloader.swf?aid=19703578&page=1
MOD特点
- 更智能的怪物们，它们通过血腥味，噪音和光源来找你
- 血腥味：如果你受伤，你会散发出血腥味
- 噪音：你发出的噪音会吸引怪物来找你
- 光源：远处的人工光源会吸引怪物
- 夜晚：夜晚会刷出更多的怪物
- 更快的怪物：有些怪物们跑到会更快
配置文件（原文）
  1. "zombie awareness: features" {
  2. # Monsters see light near player and move towards it
  3. B:awareness_Light=true

  5. # Spawn scent/blood sense sources for monsters to track
  6. B:awareness_Scent=true

  8. # Spawn sound sense sources for monsters to track
  9. B:awareness_Sound=true

  11. # Spawn extra zombies in caves where other zombies already are if dark and away from player until Spawning.extraSpawningMaxCount is reached
  12. B:extraSpawningCave=false

  14. # Spawn extra zombies randomly on the surface at night if dark and away from player until Spawning.extraSpawningMaxCount is reached
  15. B:extraSpawningSurface=false

  17. # Pistons cause sound sense sources attracting monsters
  18. B:noisyPistons=true

  20. # Growling zombies attracts other zombies
  21. B:noisyZombies=true

  23. # Causes monsters to horde up and wander the surface together to random points
  24. B:wanderingHordes=true

  26. # MC/Forge default is 0.05, this overrides that default, set to -1 to cause no override then restore forges default in their config
  27. D:zombieBabyChance=0.0

  29. # MC/Forge default is 0.1, this overrides that default, set to -1 to cause no override then restore forges default in their config
  30. D:zombieSummonHelpBaseChance=0.0
  31. }

  33. "zombie awareness: general" {
  34. # Prevent non zombies from being attracted to light
  35. B:awareness_Light_OnlyZombies=true
  36. B:client_debugRenderSounds=true
  37. B:client_renderBlood=true
  38. B:debugConsole=false
  39. B:debugConsoleOmnipotent=false
  40. B:debugConsoleSpawns=false
  41. B:debugConsoleSuperDetailed=false

  43. # Minimum distance required between active sense sources, prevents spamming sources [performance sensitive]
  44. D:extraScentCutoffRange=1.0

  46. # max rate of spawning sound sources in milliseconds
  47. I:frequentSoundThreshold=1000

  49. # Max pathfind range for zombies [performance sensitive]
  50. I:maxPFRange=64

  52. # Max awareness range for zombies
  53. I:maxPFRangeSense=64

  55. # Always target closest player [performance sensitive]
  56. B:omnipotent=false

  58. # Effects how far monsters will sense scents from
  59. I:scentStrength=60

  61. # skips line of sight check on targetting [performance sensitive]
  62. B:seeThroughWalls=false
  63. I:sightRange=16

  65. # Random X Z variation of sound source placement
  66. I:soundScentSpawnPosRandom=1

  68. # Effects how far monsters will sense sound sources from
  69. I:soundStrength=60

  71. # how frequently the mod iterates all entities, effects rates, less is more frequent [performance sensitive]
  72. I:tickRateAILoop=5

  74. # how frequently the mod iterates all players, effects rates, less is more frequent
  75. I:tickRatePlayerLoop=1

  77. # currently unused
  78. I:zombieRandSpeedBoost=5
  79. }

  81. "zombie awareness: spawning" {
  82. # Automatically target closest player on spawn for mods extra spawning features
  83. B:extraSpawningAutoTarget=false

  85. # Max distance required from closest player to spawn extra random position zombie
  86. I:extraSpawningDistMax=100

  88. # Min distance required from closest player to spawn extra random position zombie
  89. I:extraSpawningDistMin=50

  91. # The max count of zombies active in loaded chunks for extra random surface spawning, or extra cave spawning
  92. I:extraSpawningMaxCount=50

  94. # Odds to 1 of spawning extra random zombies
  95. I:extraSpawningRandomPool=100

  97. # The max count of zombies active in loaded chunks for duplicating zombie at a location
  98. I:maxZombiesNight=50

  100. # Odds to 1 of duplicating extra zombies
  101. I:maxZombiesNightBaseRarity=100

  103. # Delay rate of spawning extra zombies
  104. I:zombieSpawnTickDelay=5
  105. }

  107. "zombie awareness: player rules & lists" {
  108. # List of mobs to prevent enhanced AI on
  109. S:blacklistAITick=Creeper, Enderman, Wolf

  111. # Uses list of mobs to prevent enhanced AI on
  112. B:blacklistUsedAITick=true

  114. # swaps blacklistUsedAITick/blacklistAITick into a whitelist
  115. B:forceListUsedAITickAsWhitelist=false

  117. # Uses list of people to have spawning of zombies for
  118. B:whiteListUsedExtraSpawning=false

  120. # Uses list of people to have omnipotent targetting effect
  121. B:whiteListUsedOmnipotent=false

  123. # Uses list of people to have senses spawned for
  124. B:whiteListUsedSenses=false

  126. # List of people to have spawning of zombies for
  127. S:whitelistExtraSpawning=Corosus

  129. # List of people to have omnipotent targetting effect
  130. S:whitelistOmnipotentTargettedPlayers=Corosus, SomeDude

  132. # List of people to have senses spawned for
  133. S:whitelistSenses=Corosus, SomeDude
  134. }
