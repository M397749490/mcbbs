作者: xmdhs    时间: 2020-3-10 21:14
打开 .minecraft\assets\indexes\1.12.json

搜索 minecraft/sounds/note

然后复制后面的字符串，比如 1afefaa39a53606d2737bab9cb3409350cb2dc9f

然后在.minecraft\assets\objects 中使用 windows 的搜索功能搜索这个字符串，搜到的文件改名成 xx.ogg 然后就是音符盒的音频文件了。

作者: 勇者之鹰    时间: 2020-3-10 21:46
.minecraft\assets\virtual\legacy\sounds 这个格式是1.7.10以下的版本。 1.7.10以上的版本的assets文件夹被修改了，现在只有两个文件夹。一个是indexes，还有一个是objects。游戏音效和音乐代码都在在indexes里。用写字板打开会出现一堆数字和字母，不要随意修改！如果不小心修改了，不要按保存！如果你是正版，会自动下载覆盖你原来修改的。否则要断网才能修改成功。 objects里面放的是游戏音效并去除了后缀。名称都是音效的代码。有很多文件夹，而文件夹则是音效代码的前两个字母或数字。 像这个就是用写字板打开indexes里的json文件后出现的一种字幕，所有字幕格式都一样。 "sounds/music/menu/menu1.ogg": { "hash": "c157c56846f0e50620f808fecd9d069423dd6c41", "size": 1744657 },   而c157c56846f0e50620f808fecd9d069423dd6c41则是音效的代码，在1.7.10以上的版本可以把这个代码复制粘贴到一个ogg音频格式里然后替换指定文件夹里的音效（比如替换唱片音乐，网上都有）
