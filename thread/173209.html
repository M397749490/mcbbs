首先去租一只服务器或者租一只VPS. .

然后安装个java（如果PC上面开服如果你能玩Minecraft就说明你已经有java了，如果没有搜索一下就好，没啥难度
然后去http://dl.bukkit.org/downloads/craftbukkit/list/rb/下载一只服务器端（那么你就选择1.5.2

然后如果是Windows就在与服务器端jar同一个目录新建一个run.bat然后里面输入（用记事本即可）
  1. java -Xmx1024M -jar craftbukkit.jar -o false
  2. PAUSE
复制代码
-Xmx1024M是最大内存
craftbukkit.jar改为你的那个bukkit端的jar的名称
-o flase是关闭online-mode（允许盗版

如果是Linux就nano run.sh
里面输入
  1. #!/bin/sh
  2. BINDIR=$(dirname "$(readlink -fn "$0")")
  3. cd "$BINDIR"
  4. java -Xmx1024M -jar craftbukkit.jar -o false
复制代码
如无意外.w.
你的bukkit服就已经启动了.w.

由于我只有Linux的服务器，所以发图片也是废的...（Linux Server没有图形界面，纯文字的. .
于是就写步骤好了.w.

首先输入
  1. mkdir /home/minecraft
复制代码
（路径也可以自己选一个，我这次示范就用/home/minecraft）来新建一个目录
然后到目录里面，输入
  1. cd /home/minecraft
复制代码
然后到http://dl.bukkit.org/找到服务器端的下载地址（右键-复制链接地址）
我选择的是稳定版，所以输入
  1. wget http://dl.bukkit.org/latest-rb/craftbukkit.jar
复制代码
2013-09-14 19:26:58 (354 KB/s) - “craftbukkit-1.6.2-R1.0.jar” saved [15278482/15278482]
下载完毕~
于是在这个目录下输入
  1. nano run.sh
复制代码
然后往里面输入
  1. #!/bin/sh
  2. BINDIR=$(dirname "$(readlink -fn "$0")")
  3. cd "$BINDIR"
  4. java -Xmx512M -jar craftbukkit-1.6.2-R1.0.jar -o false
复制代码
这段代码是开一个不需要正版验证，使用512MB内存，使用craftbukkit-1.6.2-R1.0.jar服务端的
自己看情况修改.w.
ctrl+o保存，crtl+X退出~
然后现在只需要输入./run.sh即可开服
以后再其他目录下输入/home/minecraft/run.sh就可以开服了
