全局游戏规则 介绍

本插件可以很方便的设置和查询全局游戏规则。

只有当世界载入时，插件会同步一次游戏规则，对性能影响非常小。

除了设置全局游戏规则，还可以一键查询某个游戏规则在所有世界的设置！

使用非常简单，所有指令都可以通过TAB自动补全，

通过指令可以一键管理游戏规则、修改不同步的世界！

全版本适用！

对于某些模组生成的世界（如星系）无法保存游戏规则，
这个插件可以很好地解决。







指令&权限

指令 - 介绍 - 权限
/ggr set <游戏规则> <设置值>   -   设置全局游戏规则  - globalgamerules.set

/ggr remove <游戏规则>  -  移除已经设置的全局游戏规则 - globalgamerules.remove

/ggr check    -  查询已经设置的全局游戏规则 - globalgamerules.check

/ggr check <游戏规则>  -  查询某个游戏规则在所有世界的情况 - 权限同上

/ggr reload      -    重新加载配置文件 - globalgamerules.reload
/ggr sync      -    立即同步游戏规则 - globalgamerules.sync
/ggr world      -    管理不同步游戏规则的世界 - globalgamerules.world
/ggr world add <世界> - 添加一个不同步的世界
/ggr world remove <世界> - 删除一个不同步的世界
/ggr world info - 查询已经设置的不同步世界

管理员权限（默认 OP 拥有）：globalgamerules.admin
拥有该权限可以使用所有指令



使用方法

1.直接使用指令配置（最简单）
输入/ggr set ，输入需要设置的游戏规则，期间全部可以按TAB自动补全
输入/ggr world add 输入需要添加的不同步游戏规则的世界，一样可以按TAB补全
设置完成，输入/ggr check 查询已经设置的规则
接着输入/ggr sync即可同步。

后面加载的世界游戏规则将会自动设置。



2.修改config.yml
在config.yml中的gamerules一项改成像以下格式一样即可（注意大小写）：
  1. gamerules:
  2.   keepInventory: 'true'
  3.   doFireTick: 'false'
复制代码
修改完成后输入/ggr reload即可重载配置并且同步游戏规则。
