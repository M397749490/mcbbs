介绍：
【MC十周年限定】玩家在挖掘方块时随机产生幸运方块，以op权限运行指定命令。如给予物品、经济加/扣钱等

使用：
将本插件扔进服务端plugins文件夹里，重新启动服务器即可。没有任何命令。

权限：
权限
说明
默认拥有
luckyblock.trigger允许触发幸运方块所有

配置：
config.yml
  1. # 是否发送提示
  2. send-msg: true
  3. # 提示消息
  4. msg: "&6您真幸运！"
  5. # 方块配置
  6. blocks:
  7.   # 方块名称ID
  8.   emerald_ore:
  9.     -
  10.       # 命令（@p = 玩家）
  11.       cmd: "give @p 382 2"
  12.       # 概率 [0,1]
  13.       pr: 0.0005
  14.     -
  15.       cmd: "give @p 450 1"
  16.       pr: 0.0002
复制代码
注：方块名称ID可在官方百科查询
