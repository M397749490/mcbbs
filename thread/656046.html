插件介绍
  • 抛弃essentials的GC指令页面
  • 能看到完整的内存使用率
  • 能看到TPS值与TPS的平均值
  • 能看到前五个耗时最多的插件 (要看到更多请期待完整版)
  • 一些有用的指令，比如 /top permissions, /top uploadconfig
      注意：发布的这个插件不是完整版，完整版能够看到每个玩家加入服务器的延迟和世界时间或更多
原文：NOTE: This is not the full version. Full version has access to player latency, world timings , sharing and much more

指令

/top                             - 显示服务器信息
/top reload                 - 重新加载插件
/top help                    - 显示指令帮助
/top uploadlog           - 上传日记
/top about                  - 列出所有插件
/top permissions       - 列出所有权限
/top resetconfig        - 重新加载配置
/top changelog          - 列出插件日记
/top reset                   -  重新获取服务器信息
top可使用ss,serverstatus,status,sstatus代替


使用方法
  • 把插件丢入Plugins文件夹
  • 开启服务器，输入Top显示服务器信息
  • 注意：插件无法在1.7.1环境下工作！同时貌似不支持模组！
