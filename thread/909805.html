插件介绍
简介
                                             Ultimate Statistics是一个基于UUID 的高级统计插件
可以收集，分类和智能地保存有关玩家服务器活动的信息
它几乎适用于任何类型的服务器，尽管体积小，但提供了许多配置选项！

功能
                                        优化/轻量级 - 插件利用RAM缓存数据，而不是重复访问服务器的磁盘。  
                                  精美定制 - 每个GUI库存物品都是单独定制的，看起来很精致，允许更深入的数据定制。
                          精心分类 - 统计数据根据其相似性进行精心分类，访问和储存数据都变得非常容易
高级配置 - 别看插件体积小，它拥有控制插件功能所需的一切。
                  丰富的信息 - 无论插件的分类如何，它还可以为每个分类事件保存多个数据。
                  无需前置 - 该插件不需要依赖项，购买即用，进程通过事件和调度程序运行。
                                      MySQL统计数据 - 仅通过SQL数据库在BungeeCord服务器网络上存储和更新全局统计数据。

命令
/ ustats <player> ——打开玩家统计数据GUI
/ ustats reset <player> [数据类型] ——重新设置玩家的某项数据
/ ustats reload ——插件重载
/ stats <player> ——查看该玩家所有数据
