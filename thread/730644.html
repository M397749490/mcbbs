插件使用注意事项&说明
  • /honor和/honor help 都可以查看帮助指令
  • /honor use null 是不使用头衔【也就是不显示
  • 显示目前所有头衔和提示信息修改等以后会做:D
  • \\&代表§ &就是& [比如/honor add Rinne \\&m垃圾凛音]
  • 另外我加了个§z是清除字体+颜色[比如加粗等] 因为特性所以请字体转码优先然后是颜色
    1. /honor add Rinne \\&m\\&1凛音:)
    复制代码

  • 如果你删除了一个已经给予别的玩家的头衔，那么那个玩家聊天或者list自己头衔的时候会自动移除那个头衔并提示
  • 帮助↓

  1. -------------头衔指令帮助-------------
  2. /honor help 查询帮助
  3. /honor use [Player] <前缀id> 更改前缀
  4. /honor list [PlayerID] 查询玩家所拥有的头衔
  5. /honor add <前缀id> <前缀> 添加前缀
  6. /honor delete <前缀id> 移除前缀
  7. /honor give <玩家id> <前缀id> 给予玩家前缀
  8. /honor take <玩家id> <前缀id> 拿走玩家前缀
  9. --------------------------------------
复制代码

正确创建一个头衔并让玩家使用流程
  1. /honor add Rinne \\&m垃圾凛音
  2. /honor give 玩家 Rinne
  3. /honor use Rinne
  4. #如果更改别人使用的头衔就是
  5. /honor use 玩家 Rinne
复制代码
这样每次聊天前面就会有4个划掉的字了
PS:没有自动给头衔加上[]或者【】或者<>等 如有需要请人工给头衔加上
/honor add 头衔id [§xxxxxxx§xxxxx头衔§z]
比如↑ :D #如果你括号要有颜色或者加粗什么的也是可以的
