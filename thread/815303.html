插件介绍
这个插件可以给你的服务器添加一种新的合成方式——通过炼药锅来合成特定的物品

特点
  • 用炼药锅合成自动物品
  • 可配置合成成功几率
  • 可用物品合成触发指令
  • 用聊天框进行操作，方便快捷


使用方法
输入 /caulcrafting create 然后跟寻屏幕给出的帮助操作即可.(可点击聊天框)

详细步骤:
  • 输入以上指令
  • 对准炼药锅按Q(或手持材料在聊天框输入add)添加合成所需材料 (重复此步骤来添加其他物品作为所需材料)
  • 显示消息后点击【下一步】(或输入next)
  • 对准炼药锅按Q(或手持合成所需材料在聊天框输入add)添加合成获得的物品
  • 点击【掉落率】设置成功几率(翻译错误，应为成功率) 之后会在聊天框出现指令/ccc setdropchance 0 <0.01-100>
  • <>内为取值范围 单位为%. 例如100则成功率为100% 指令: /ccc setdropchance 0 100
  • 点击【下一步】即可保存配方
  • 配置完配方后通过把对应物品扔入有水的炼药锅内即可合成
以这个配方为例:
木棍x1+橙色染料x1→烈焰棒x1

指令
  • /cc /ccc /c3  —— 主指令
  • /caulcrafting create 创建新的合成配方  (可输入主指令后点击聊天框来打开)
  • /caulcrafting list 列出已有的合成配方 (点击X图标可以删除配方)


权限
  • caulcrafting.use
    • 允许你使用合成系统
    • 默认所有玩家拥有
  • caulcrafting.nowaterconsume
    • 允许玩家合成不消耗炼药锅的水 (VIP权限)
    • 默认无此权限
  • caulcrafting.admin.*
    • 管理员权限
    • 默认OP拥有此权限
  • caulcrafting.admin.list
    • 运行你打开配方列表
    • 默认OP拥有此权限
  • caulcrafting.admin.create
    • 允许你创建配方
    • 默认OP拥有此权限
  • caulcrafting.admin.remove
    • 允许你移除配方
    • 默认OP拥有此权限

已知问题
/cc 指令与Chestcommands指令冲突
解决方法:
用解压软件打开插件jar里的plugin.yml
第8行
aliases: [cc,cauldroncrafting]
删除cc,即可
如:
aliases: [cauldroncrafting]
