每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。

然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。

Minecraft 1.14 仍未发布，19w06a 为其第 20 个预览版。

转载本贴时须要注明原作者以及本帖地址。

This week's snapshot is a small one, but it brings a fancy new splash screen! Start up the snapshot and you'll find out right away.
本周快照内容不多，不过有一个很赞的新的启动界面！启动快照自己去看看吧。

CHANGES IN 19W06A
19W06A 的改动

  • Added a new splash screen and slightly improved startup time
  • 添加了新的启动界面，并略微加快了启动时间。
  • Updated LWJGL to 3.2.1
  • 更新 LWJGL 至 3.2.1
  • Particles are now broken up into individual textures rather than being in particles.png
  • 粒子材质被分割为了独立的文件，而不是全部放在 particles.png 当中
  • This breaks resource packs right now but we're working on a way to still be able to load old resource packs
  • - 这使得所有涉及到粒子的旧资源包都不能用了。不过我们正在尝试让游戏能够正常加载那些旧的资源包。
  • Adjustments to the Wandering Trader
  • 调整云游商人
  • New optional tag for block items: BlockStateTag
  • 为方块物品新增可选标签：BlockStateTag
  • Contains map of block state properties to be overwritten after block is placed (note: item model is not affected).
  • - 当放置方块后，会用该标签内的值覆盖方块状态（备注：不会改变物品的模型）
  • Fixed bugs
  • 修复漏洞

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要魔法上网。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
