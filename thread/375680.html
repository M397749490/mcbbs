标题: 服务器spawn设置问题
服务器有多世界插件和背包切换插件 以下问题：生存世界 地皮世界 资源世界 游戏世界 各个世界的spawn怎么设置 ？
玩家在生存世界 spawn就会到生存世界设置的主城 死亡也会在 生存世界主城  
在资源世界 spawn会到生存世界设置的主城  死亡也会在生存世界主城重生，
在地皮世界用spawn 会到地皮世界主城。死亡会在地皮世界重生

游戏世界用spawn会到生存世界 死亡会在生存世界重生
虽然问题有点多，但说一下设置原理,就行了
作者: 琥珀剑心    时间: 2014-12-18 01:13
传送的话用/mv setspawn 即可
重生的话打开ess的配置文件，找到
  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |         Essentials 出生设置 / 新玩家设置             | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7. newbies:
  8.   # 是否显示某玩家第一次进服时的欢迎信息
  9.   # 若开启,编辑内容,{DISPLAYNAME}将自动转换为玩家名字.
  10.   # 若取消,改为''
  11.   #announce-format: ''
  12.   announce-format: '&d欢迎新玩家{DISPLAYNAME}来到梦幻星空服务器!'

  14.   # 当我们第一次出生时,出现在哪个出生点？
  15.   # 如果你想要使用世界自带的出生点,则设置为"none".
  16.   spawnpoint: newbies

  18.   # 是否想要玩家第一次进入服务器时赠送新手礼物? 设置为 ''禁用此功能.
  19.   # 这个赠送不会花费金钱,也可以给予权限.
  20.   #kit: ''
  21.   kit: tools

  23. # 设置为 lowest, 如果你想使用 Multiverse 处理重生.
  24. # 设置为 high, 如果你想使用 EssentialsSpawn插件 处理重生.
  25. # 设置为 highest, 如果你想强制使用 EssentialsSpawn插件 处理重生.
  26. respawn-listener-priority: lowest      这边这样设置即可，用多世界的重生，死亡会在多世界的传送点复活
