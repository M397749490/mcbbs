你可以使用 RespawnWorld.jar (5.71 KB, 下载次数: 57)
2016-10-13 19:10 上传
点击文件名下载附件

/rw set [世界名] | 把你脚下的地点设置为输入世界名的重生世界
如站在123世界的时候，输入/rw set world
那么，在world世界死亡的时候，就会复活在123世界的所战的位置，
设置也很简单
