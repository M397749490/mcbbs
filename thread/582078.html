RPG Drop 1.4(6.16.16更新)
简介：
这款插件可以让你完美仿造网游的BOSS掉落模式，即谁给BOSS最后一击则谁可以优先拾取BOSS掉落的物品。
换句话来说就是 谁最后一招杀死了怪物，怪物掉落后的物品会由他先拾取，其余玩家需要等待延迟过了才可拾取。

特点：
  • 自定义拾取延迟时间。
  • 掉落保护。
  • 支持 MythicMobs。
  • 支持 RPGPartySystem。
  • 唯一权限：rpgdrop.protect。
  • 增加更多的延迟功能，支持限制掉落，如：只允许怪物掉落有延迟等。
  • 支持1.10。
#只有给予rpgdrop.protect权限的才能享受此掉落延迟。

Config：
  1. Time: 10 #保护时间。单位20=1s
  2. PlayerDropProtect: true #玩家掉落保护
  3. MobDropProtect: true #怪物掉落保护
  4. MythicDropProtect: true #MythicMobs怪物掉落保护(需MythicMobs插件作为前置)
  5. PartySystemDropSupport: true #组队掉落保护(需RPGPartySystem插件作为前置)
