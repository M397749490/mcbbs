Melon Golem[西瓜傀儡]


[似曾认识一个白色的西瓜傀儡...]

介绍

西瓜傀儡

其性质如同它的名字和形状，跟铁傀儡和雪傀儡一样是一种友好生物.

它能丢出西瓜进行攻击

与雪傀儡不同的是，它的攻速是较慢的，但它的攻击具有一定的伤害！

[四颗心，可在配置文件修改]

血量仅仅只有八滴血...被骷髅两箭就能射死[但你可以修改配置文件!]

从此种地只种西瓜！


召唤西瓜傀儡

想召唤这神奇的生物?,你只需要三个西瓜块垂直摆在方块上【类似于雪傀儡召唤】
然后大喊一声"德玛西亚"
左手[盾牌手]一根木棍,右手一根木棍
右键它中间的一块西瓜
woc...传说中的西瓜傀儡就这样诞生了！


配置文件

真是没想到我今天居然良心大发
写配置文件
  1. # Configuration file

  3. general {
  4.     D:"Base Golem Health"=8.0  #西瓜傀儡生命值
  5.     B:"Enable Golem Block Heads"=true   #能否创建西瓜傀儡
  6.     B:"Golem Eats Melons"=true   #能否喂食西瓜
  7.     D:"Melon Heal Amount"=1.0    #一片西瓜增加的血量
  8.     D:"Melon Slice Damage"=4.0   #西瓜傀儡的伤害
  9.     B:"Shears Spawn Block"=true  #让西瓜人戴上方块
  10.     B:"TTS Signs"=true           #并不重要
  11.     B:"TehNut Mode"=false        #并不重要
  12. }
复制代码

配置文件位置:\.minecraft\config\melongolem.cfg

更多信息

诶...我的西瓜傀儡咋长这样?
没南瓜?
实际上南瓜是可以套上去的
不仅是南瓜，还有各种方块！
拿出你手上的方块，右键西瓜太郎吧！
用剪刀可以剔除方块.
用西瓜可以喂西瓜傀儡加血

THE END
