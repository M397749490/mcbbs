制作一种新液体

本文为大家讲述如何在Minecraft中制作一种新的液体，本教程暂不支持modloader。
  • 打开material.java
  • 在material.java中添加如下内容
  1. public static final Material XXX =  new MaterialLiquid();
复制代码
其中（XXX代表液体）
  • 复制block.fluid，block.flowing，block.stationary，并重命名为您所希望的名字（如：block.fluidx，block.flowingx以及block.stationaryx）。并在block.fluidx中查找如下语句：

  1. public static double func_293_a(IBlockAccess iblockaccess, int i, int j, int k, Material material)
复制代码
在向下翻阅少许之后就会发下如下语句：
  1. if(material == Material.water)
  2.         {
  3.             vec3d = ((BlockFluid)Block.waterMoving).getFlowVector(iblockaccess, i, j, k);
  4.         }

  6. rename it to this:
  7. if(material == Material.YourMaterial)
  8.         {
  9.             vec3d = ((BlockFluidx)Block.xxxMoving).getFlowVector(iblockaccess, i, j, k);
  10.         }
复制代码
此时：
  • 确保您的block.XXXmoving 和Block.xxxstationary在block.fluidx得以扩展。
  • 复制 TextureWaterFlowFx以及TextureWaterFx并重命名。
  • 在您的block.fluidx中您会发现:

  1. super(i, (material != Material.lava ? 12 : 14) * 16 + 13, material);
复制代码
将此语句重命名为：
  1. super(i, (material != Material.lava && material != Material.water ? 13 : 14) * 12 + 17, material);
复制代码
此时将会更改您的液体的材质，其样子如terrain.png所示，使用"13 : 14) * 12 + 17"可以使其获得水的材质。您也可以将其替换为您希望获得的材质的样子。
  • 打开minecraft.java，查询如下语句：

  1. textureWaterFX = new TextureWaterFX();
  2.         textureLavaFX = new TextureLavaFX();
复制代码
并添加：
  1.   textureXXXFX = new TextureXXXFX();  
复制代码
查询：
  1. renderEngine.registerTextureFX(new TextureWaterFlowFX());
复制代码
添加：
  1. renderEngine.registerTextureFX(new TextureXXXFlowFX());
复制代码
此时，XXX即为您所创建的新液体的名字了，查询：
  1.     private TextureLavaFX textureLavaFX;
复制代码
添加：
  1. private TextureXXXFX textureXXXFX;
复制代码

  • 在block.fluidx中查询：

  1. public int tickRate()
  2.     {
  3.         if(blockMaterial == Material.water)
  4.         {
  5.             return 5;
  6.         }
  7.         return blockMaterial != Material.lava ? 0 : 30;
  8.     }
复制代码
将Material.water重名为material.xxx。其数值表示液体的流速，流速为0则表示其流速最快。
