音乐电台（v1.9）
——————————————————————————

【最后一次更新 2018-2-8】


前言
相信大家都认识这款插件, 站内已由搬运帖, 所以不做过多介绍
插件最高只能 1.8 的版本使用, 导致很多高版本服务器放弃这个功能
这款插件我在半年前就尝试过重置, 因为原代码有很多意义不明的算法和模块, 再加上当时技术有限, 最后以失败告终
直到今天再次捡起这款插件, 我也希望各位能尊重我的劳动成果, 顺手打个评分就是对我最大的鼓励
高产似.. ??


开源
https://github.com/Bkm016/BAMradio


重置内容
- 插件以 GNU General Public License v3.0 协议开源
- 接近 60% 的代码重构
- 命令模块完全重写
- 语言模块完全重写
- 更加直观的插件框架
- 移除了不必要的指令、模块、工具
- 允许选择多个世界和区域播放音乐
- 修复原插件不会自动创建配置文件的问题
- 等等...


命令
  1. /bamradio —— 插件命令
复制代码


配置
  1. # BAMradio -- Author: FR34KYN01535, 坏黑
  2. # For more information visit http://dev.bukkit.org/server-mods/bamradio/

  4. # 是否在服务器启动后自动播放
  5. auto-play: true

  7. # 初始音量 (可以是负数)
  8. volume: 15

  10. # 自动播放下一首
  11. auto-play-next: true

  13. # 强制使用软件播放器
  14. force-software-sequencer: false

  16. # 显示曲目名称
  17. show-current-track: true

  19. # 只有以下区域播放音乐, 使用 'all_region' 代表全部区域
  20. enable_region:
  21. - 'all_region'

  23. # 只有以下世界播放音乐, 使用 'all_world' 代表全部世界
  24. enable_world:
  25. - 'all_world'

  27. # 语言文件
  28. # 请勿填写不存在的语言文件
  29. language: "en_US"
