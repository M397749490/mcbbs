作者: qq794195711    时间: 2019-1-20 14:35
gm权限插件设置一下，我默认为你用的是gm插件。
config.yml这里
  1.   mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds:
  16.           - users
  17.           - groups
复制代码

主要是这个all_unnamed_worlds，加进去，如果没有的话。
如果这样还不行，就把这个节点写成你地皮世界的名字。
世界名字再mv list里面找。
