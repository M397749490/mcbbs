配置文件:#NPC窗口在这里写上
#这个不能变
NPCWindow:
  #NPCid  
  0:
    #窗口们~~
    Windows:
      #窗口id  
      # 为CustomWindow目录下的id
      window1:
        #点开最小等级
        LevelMin: 0
        #点开最大等级
        # 注意:  此值为0则无限制
        LevelMax: 0
#附加的按钮
Additional:
  #书本任务
  BookQuest:
    #是否启用关联,
    #为 true 并且安装了 BookQuest 插件才会生效
    #       BookQuest 为我自制的另一个书本任务插件
    #                 有需要的可以联系我视频介绍:优酷地址
    #
    #默认为 false
    Enable: false
    Text: '&0【&0&n任务&0】'
    Tip:
    - '&7任务列表'
    - '&7在该NPC处接受的任务'
#附加的文本
AdditionalText:
  #附加按钮前面的文本列表
  Prefix:
  #附加按钮后面的文本列表
  Suffix:
  - '§7-----------------------------'




如果需要配置一个窗口
请在PxBookWindow/CustomWindow中创建一个文件或者在原有的CustomWindow.yml中继续添加
#窗口id
#调用窗口时使用
#不能重复
window1:
  #支持 PlaceholderAPI
  Text:
  - '&d&l我是Px'
  - '&d这个插件的作者'
  - '&d很感谢您支持这个插件'
  - '&d如果您的服务器'
  - '&d还装了&0&lPlaceholderAPI&d插件'
  - '&d还可以使用(player_name)'
  - '&0效果: &7<&d&l%player_name%&7>'
  - '&0这是&4<NPC.NAME>&3NPC'
  - '&0如果需要定制插件请联系'
  - '&0&lQQ: XX'
  #这一句是变量的使用
  # 变量使用格式: <VAR.变量id>
  # 变量ID是 CustomVar文件夹下面的文件里面每个自定义变量的id
  - '<VAR.test>'




然后说说变量
变量是存在PxBookWindow/CustomVAR文件夹下面的
创建方法与窗口一致
#变量id
#同窗口id的性质
#但是不与窗口id冲突
test:
  #变量显示名
  Text: '&3&n单击我吧&a%player_name%'
  #变量的提示文本列表
  Msg:
  - '&7我是提示的文本'
  - '&7当然我是可以单击的'
  - '&b可以多行'
  - '%player_name%'
  # 变量执行命令
  # <NPC.ID> 会替换成 NPC 的id
  # <NPC.NAME> 会替换成 NPC 的名字
  # <PLAYER.NAME> 会替换成 玩家 的名字
  Run: '/say %player_name%'






这个插件支持PlaceholderAPI的





指令:
/bookwindow(bw) reload 需要OP权限
/bookwindow(bw) open <id> 打开一个窗口,需要pxbookwindow.open权限 玩家默认没有


权限:
   bookwindow.open
   玩家默认啥都没有
