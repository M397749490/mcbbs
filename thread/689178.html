插件介绍

    这是一款可以展示玩家物品在展示柜上的插件，他可以让玩家自定义展示他要的物品！
     其他玩家可以看见他的展示柜！！


游戏截图

     












指令&权限
/showcase | 打开自己的展示柜(可编辑) |
showcase.open

/showcase <玩家> | 打开某玩家的展示柜 |
showcase.open.others


配置文件

配置文件1.5Config-仅供参考

  1. # Showcase by N3kas
  2. # 插件原作者 N3kas
  3. # 汉化|搬运 Auange
  4. showcase:
  5.   # 选择后是否不保留物品 true为不保留 flase为保留
  6.   retrieve-items: true
  7.   # 音效特效
  8.   sounds:
  9.     inventory-opened: BAT_TAKEOFF
  10.     item-clicked: VILLAGER_IDLE
  11. # 花费项目,前置Vault
  12.   costs:
  13.    # 金钱不足提示语言
  14.     message:
  15.       - '你无法支付起'
  16.    # 打开这个展示柜需花费的游戏币,设置0则为关闭这项收费
  17.     money: 0
  18. # 自定义设置指令
  19.   command:
  20.     # 指令
  21.     command: '/showcase'
  22.     # 权限
  23.     permission: showcase.open
  24.     # 无权限提示的语言
  25.     no-permission-message:
  26.       - '&c你没有权限打开这个展示柜'
  27.       - '&c你没有权限解锁这个展示柜'
  28. # GUI设置选项
  29. inventory:
  30. # 添加物品到展示柜的按钮修改
  31.   confirm-add:
  32.     accept:
  33.       item: STAINED_GLASS_PANE
  34.       id: 5
  35.       name: "&f<&7¤&a&l确定展示&7¤&f>"

  37.     deny:
  38.       item: STAINED_GLASS_PANE
  39.       id: 14
  40.       name: "&f<&7¤&c&l取消选择&7¤&f>"
  41.       lore: "&a&l&m-++__=>|_=+     +=_|<=__++-\n&7>&c取消你的选择\n&7>&c选择的物品将会重新放置在你的背包\n&a&l&m-++__=>|_=+     +=_|<=__++-"
