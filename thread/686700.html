==封装胶带==
此模组只添加了一个物品——封装胶带
拿着胶带右键或者Shift+右键需要封装的方块使用
当物品栏中有纸时，胶带可以将任何内带有TileEntity子标签的方块封装
（包括大部分模组的机器、箱子和功能方块）
封装后的方块可以直接用手挖掘下了，并转移到任何地方
直接右键解封
==封装黑名单==
从模组版本v0.3.5开始，默认情况下，以下方块列入黑名单，无法封装
命令方块：安全问题：移动命令方块可能会触发bug。
末地传送门方块：安全/游戏平衡相关：移动末地传送门方块可能会导致问题。
刷怪笼：游戏平衡相关：刷怪笼应当保留难以获得的特性。
玩家头颅：它们没有一个ItemBlock标签，可以轻松地挖掉重新放置，
以及：旗帜，比较器，阳光传感器，活塞，音符盒，告示牌
无论如何，封装上面这些物品没有任何意义。
（除了告示牌，也是安全问题）。
==配置文件==
上方为每个胶带的使用次数（默认为8）
下方为封装刷怪笼的黑白名单，
将刷怪笼的实体标签添加到whitelist（白名单）上，就可以封装刷怪笼了，如下
  1. tileentities {
  2.     S:blacklist <
  3.      >
  4.     S:whitelist <
  5.         net.minecraft.tileentity.TileEntityMobSpawner
  6.      >
  7. }
复制代码
此段配置文件经实测不适用于1.8以上的版本
