第二步
编辑服务器基础配置
由于新生成的server.properties是默认配置，所以要做些改动才能使客户端接入allow-nether=true                是否可以传送到地狱，true为可以，false为不可以level-name=world                世界名字server-port=25565                服务器端口，此项建议不需要做更改，如果改了请记住！请检查下载的懒人包内是否已经将此端口改变！server-ip=                       此项留空即可，填入ip地址可能无法开服！！！！！！！max-build-height=256             最大建筑高度spawn-npcs=true                 生成npcwhite-list=false                   是否启用白名单spawn-animals=true               生成动物online-mode=false                在线验证（正版验证）此处需为falsepvp=true                        是否允许pkdifficulty=1                      游戏难度0和平，1简单，2正常，3困难gamemode=0                    游戏模式0生存，1创造max-players=20                  最大玩家数view-distance=10                 视距，数值越大，传输带宽要求越高motd=A Minecraft Server           服务器名【一句话介绍，默认仅限英语】





第三步
编辑启动脚本
@ECHO OFFSET BINDIR=%~dp0"C:\ProgramFiles\Java\jre7\bin\java.exe" -Xms1024M -Xmx1024M -jar"%BINDIR%\mcpc-plus-1.5.2-R1.1-forge738-B589.jar"PAUSE 这是脚本的内容，下面逐行解释
@ECHO OFF关闭命令显示，批处理的用语，不用在意
SET BINDIR=%~dp0设置bindir为当前路径
"C:\ProgramFiles\Java\jre7\bin\java.exe"java.exe的路径
-Xms1024M最小内存
-Xmx1024M最大内存【32为java不应超过1024M】
"%BINDIR%\mcpc-plus-1.5.2-R1.1-forge738-B589.jar"游戏核心文件的位置
pause暂停、等待键盘动作后继续【用于出现错误而没有正常启动时，可以看见返回的错误报告】
如果开服发现批处理一闪而过，那就在最后加上这句话，你就可以看见错误的具体内容了 启动脚本编辑好后保存即可若没有的话，新建一个文本文档，把上面的代码粘帖进去，保存，后缀名改为.bat




第四步
启动服务器
双击刚刚编辑过的bat文件，便开始启动了，耐心等一会，发现文字不再跳动了，差不多就可以确定不是启动完了就是出错了。。。此时敲击回车若出现11:59:40 [INFO] Unknown command. Type"help" for help.这类的文字，或者中文“未知命令，使用help开启帮助”就说明开启成功了 如果出现什么stoping server、save world之类的，恭喜你，服务器没成功开启。。。这时你要考虑插件是否对应版本，mod是否兼容，是否多余，因为有些mod客户端装就好了，装到服务端会报错

第三步
测试内网连接、外网连接

还是打开游戏，输入你的内网地址，就是192.168开头的确认这个可以链接再输入外网ip外网ip可以通过www.ip138.com查询【一般情况下是准确的】如果也能成功连上，那就说明之前的操作都成功了【地址保留需要重启后验证，先不管】  如果内网连不上，先确认你的本机ip没有错其次确认你没有输错 外网连不上则在此确认你的外网ip正常、端口映射正常

服务端：
1。系统找不到指定文件确认启动文件bat中关于java的路径设置正确无误
2。Error occurred during initialization of vmcould not reserve enough space for objectheapError: Could not create the Java Virtual MachineError: A fatal exception has occurred.Program will exit. 一般情况下此错误为32位java在内存设置上超过了1024M后的提示
3.xxxxxxxxxxxxxxx\ crash-reports\crash-xxxx-xx-xx_xx.xx.xxx-server.txt mod冲突，大问题！





客户端：
无法连接到服务器1。连接失败：bad login 查看server.properties中关于online-mode=true改成online-mode=false
2。time out连接超时 确认网络通畅
