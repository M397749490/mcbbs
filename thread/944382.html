标题: Java 版附赠的 Windows 10 版兑换码即将失效
本帖最后由 KakagouLT 于 2020-1-22 14:57 编辑

在 2018 年 10 月 19 日前购买 Java 版游戏的老玩家，都拥有一份免费的 Windows 10 版游戏的兑换码。但是，这个兑换码即将于 2020 年 4 月 20 日过期，请尚未兑换的老玩家们尽快兑换。

这个兑换码本用于为 Java 版玩家提供 Win10 版的测试版抢先体验，而目前 Win10 版早已正式发布，在 minecraft.net 和其他渠道均有销售。

4 月 20 日也是 Tom Stone 的生日，虽然本信息与本文主题无关。

兑换方法(转自MCBBS官微)：
① 进入Mojang官网的登陆界面，account.mojang.com/login
② 登陆自己的正版账号，此步骤需要连接至reCAPTCHA进行人机验证
③ 找到Minecraft for Windows 10处的Gift Code即可
④ 在Win10Store或者兑换网址 redeem.microsoft.com 进行兑换
