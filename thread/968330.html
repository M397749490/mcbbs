请注意
插件现在不支持1.13及以下了
仅仅支持1.14-1.16.1
不支持1.16.2
插件现在3.70版本有BUG无法食用，现在已向作者反馈等待回复


插件授权图片


介绍
通过简单的GUI制作你自己的食物和药水!
自定义合成配方，添加药水效果，执行命令，播放声音，散播粒子，从怪物身上掉落
以及自定义食物能力和更多的东西!?
插件不支持 1.13及其以下!
只支持 1.14 - 1.16

√自定义的能力:
>> 可以像MM插件一样，自定义语法执行其他新的操作
>> 支持MM怪物掉落
√超强的自定义性:
>> 你可以修改插件配置.
>> 你可以更改插件的任何提示消息 (聊天, 物品栏, 标题).
√体积小:
>> 插件体积小，优化好.
>> 不会因为延迟和内存原因导致内存泄露？
√GUI编辑器:
>> 用简单的GUI编辑器创建和管理食物配方!
√创建配方:
>> 每种自定义食物都有自定义的配方!
>> 适用于: 工作台和熔炉.
>> 自动将新增配方添加到玩家配方表中，并且会及时移除被禁用的食物配方.
>> 配方支持自定义物品和其他插件的食物物品!?
√自定义食物:
>> 支持名字，介绍，物品标志和附魔属性
>> 支持自定义头颅皮肤!
>> 支持药水颜色!
√特点:
>> 创建无限数量的自定义食物.
>> 禁用/启用在满血量情况下对食物的消耗.
>> 禁用/启用在满饱食度情况下对食物的消耗
>> 自定义血量恢复的数量.
>> 自定义饱食度恢复的数量.
>> 自定义每种食物的冷却时间.
>> 自定义每种食物的音效.
>> 自定义每种食物的粒子效果.
>> 自定义每种食物的药水效果.
>> 当玩家吃掉食物后可以自定义执行的指令[后台，OP，玩家](只能由服主配置)!
√掉落系统:
>> 有特定机会从特定怪物中掉落某些食物.
>> 禁用在某些世界中某些食物掉落.
>> 禁用某些自然生成食物的掉落,例如自然生成的动物, 鸡蛋, 等等.
>> 支持 MythicMobs.

如何使用
使用指令/food editor 或者/food create 来制作食物配方!
如果想要设置食物掉落概率，在config.yml中修改


指令
/food give <玩家> <食物ID> [数量] - 给予玩家食物.
/food editor - 打开GUI编辑器.
/food reload - 重载插件.


权限
advancedfood.eat.<食物ID> - 允许食用某种食物.
advancedfood.craft.<食物ID> - 允许制作某种食物.
advancedfood.eat.* - 允许使用所有食物.<默认已授予此权限>
advancedfood.craft.* - 允许制作所有食物. <默认已授予此权限>
advancedfood.admin - 管理员权限.
