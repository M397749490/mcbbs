使用基础插件即可

plugin/essentials/config.yml文件中下下拉,拉到自定义进入退出信息(大概在第360行左右)，可以自定义玩家的加入或退出消息

再往下拉就可以设置新玩家登陆信息.


自定义加入/退出信息
  1. # 是否关闭加入、退出游戏的提示消息
  2. # 当启用后, 具有对应权限的玩家加入、离开游戏将不会在公屏上显示消息
  3. allow-silent-join-quit: false

  5. # 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
  6. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  7. custom-join-message: "自定义的加入消息"

  9. # 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
  10. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  11. custom-quit-message: "自定义的退出消息"
复制代码


(上面的配置大概在第360行左右)

自定义新玩家加入信息

  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |         Essentials 出生设置 / 新玩家设置             | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7. newbies:
  8.   # 是否显示某玩家第一次进服时的欢迎信息
  9.   # 若开启,编辑内容,{DISPLAYNAME}将自动转换为玩家名字.
  10.   # 若取消,改为''
  11.   #announce-format: ''
  12.   announce-format: '自定义新玩家加入信息'
