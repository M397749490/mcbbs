Holographic Shop
一、插件简介

作者原话:
HolographicShop
A fancy shop plugin that uses holographic displays


what it does?
did you have hard time displaying bunch of selling/buying items in your previous shop plugin? do you want something unique in your server? this is what it is.
HolographicShop provides fancy looking shop, can add multiple items, and very easy installation. Personal shop is added in 0.0.3 too this plugin will work only in 1.8~1.8.8 or above since Holographic Displays plugin support those versions.?



个人理解：
本插件就是一款只能用于1.8版本里不错的官方商店插件，类似于QS的漂浮物展示，通过全息影像的方式将所有的操作方式漂浮在箱子上面，简单明了易于上手，编辑也还算简单，基本有过开服经验的腐竹都能使用。看起来真的逼格满满有木有~
二、安装方法
①.下载插件本体
②.下载前置插件(服务器已有的话请忽略)
③.将本体和前置插件放入服务器Plugins文件夹内
④.重启服务器
三、使用方法
①.你需要相应的权限
②.在你想要的地方放一个箱子
③.在箱子上面放一个牌子
④.在牌子上如下所示写上
系统商店:

第一行[adminshop]

第二行商店的名字

第三行:购买或出售


玩家商店:

第一行[shop]

第二行:商店名字

?

⑤. 如果你操作没有错误,箱子上应该有一副全系图片漂浮了
6。 用/shop < shopname > additem <价格>命令
添加你的物品
你应该持有一个物品
玩家商店必须往箱子里放入相应的物品
商店里如果没有更多的物品将不再出售
不过adminshop有无限的物品

玩家可以通过点击全系图片的加减符号选择购买数量,左右符号翻页

四、权限节点与指令
holographicshop.admin  -  管理员权限,不建议给与玩家
holographicshop.user  -  玩家可以访问和创建商店
