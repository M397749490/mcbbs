MCLauncherBN插件API
    Public Function Init(Launcher As String, Addon As Object, AddonLoadingVersion As String, LauncherVersion As Version ,Optional Lang As String = "zh-cn") As String()
Launcher ：MCBN
Addon ：Addon Object，用于调用启动器功能
AddonLoadingVersion ：目前第二代，为2
LauncherVersion ：启动器版本
Lang ：语言，目前仅zh-cn,zh-tw,en-us
注意：此函数为启动器加载DLL时调用的函数
以下为返回。
Return {"version:1", "type:Context:[useragent]", "update:zhhsvr", "name:JSON编辑器", "description:不用介绍了吧。。。" & vbCrLf & "故名思意嘛~", "author:zhh0000zhh"}
version为插件版本，type可分为Context，Tabpage
Context为主界面版本列表右键菜单添加项
Tabpage语法：type:Tabpage:[down|addon|main]:[useragent]
sub为在加载项中心打开，此时第三个分割为sub名称，仅支持定义1个sub，如果定义多个，最后一个sub会覆盖之前的定义
第三个分割内容为用户自定义标识
用于需要声明多个接口时使用

update为检查升级接口，注意：启动器不会自动检查插件更新。
zhhsvr为使用启动器自带检查更新，只有在服务器端添加的插件才能使用此功能
url为使用http/https检查更新，格式为第一行为最新版本号，第二行为最新版下载地址，使用crlf分割下载地址可为zip或dll后缀
如update:url:http://checkupdate.mcbnaddon.net/addon1.htm
function为使用插件自带程序检查更新
如update:function:checkupdate
返回值为string，使用crlf分割，第一行为最新版本号，第二行为最新版下载地址

当启动器插件加载器分析返回值时
如果需要添加右键菜单或者选项卡时
会调用DLL中的Add_Object
Public Function Add_Object(Obj As Object, UserState As Object) As Boolean
返回值为成功与失败
UserState是刚刚定义的自定义标识。
Obj为所请求的控件，如ToolStripMenuItem，TabPage
示例：
        Obj.GetType.GetProperty("Text").SetValue(Obj, “右键菜单”, Nothing)'设置text属性
        Dim e As System.Reflection.EventInfo
        e = Obj.GetType.GetEvent("Click")
        e.AddEventHandler(Obj, [Delegate].CreateDelegate(e.EventHandlerType, Me, "_Click"))'添加click过程处理

外部调用程序：
Args:
Version*UserName*MemorySize*Pwd*LoginType*VM_Args
Version:MC版本
UserName:玩家名
MemorySize:内存大小
Pwd:密码
如MCLauncherBN.exe 1.6.2-Forge9.10.1.871*用户名*1024*4*密码*-Dfml.ignoreInvalidMinecraftCertificates=true -Dfml.ignorePatchDiscrepancies=true
