PerBiomePVP
这个插件可以修改可以/不能PVP的提示语
这个插件可以让你在某个生物群系里可以和玩家PVP [wood_sword]
这个插件可以让你在某个生物群系里不能与玩家PVP[saddle]



这个插件没有命令和权限
这里不提供生物群系名,请自行WIKI
标题写[全版本][1.8]原因：我不知道以后还会不会加群系
我也不会关注这个插件以后的更新，因为我不打算在自己服里使用
推荐 [ WorldEdit ]，是因为 [ WorldEdit ]可修改群系



Config

Disable - 禁止
Enable - 启用
All Biomes - 所有群系
All Biomes Except for - 除了哪些群系
Messages - 信息


PVP:                                                     #PVP
  Disable All Biomes: true                        #禁止所有群系的PVP：激活
  Disable All Biomes Except for:                #除了下面的世界可以PVP外，其他都不可以
  - COLD_TAIGA                                       #群系
  - FROZEN_OCEAN                                 #群系
  - PLAINS                                              #群系
  Enable All Biomes: false                        #可以再所有群系PVP:禁用
  Enable All Biomes Except for:                #除了下面的世界不可以PVP外，其他都可以
  - PLAINS
Messages:                                              #提示语
  PVP Biome Entry: '&ePVP is allowed in this biome!'                            #在这个生物群系里可以进行PVP
  PVP Disabled Biome: '&cYou are not allowed to PVP in this biome!'       #在这个生物群系里不可以进行PVP
