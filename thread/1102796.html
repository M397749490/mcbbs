  2.         "type": "minecraft:crafting_shaped",
  3.         "pattern": [
  4.                 "#",
  5.                 "S"
  6.        ],
  7.        "key": {
  8.                 "#": {
  9.                         "item": "minecraft:turtle_helmet"
  10.                },
  11.                 "S": {
  12.                         "item": "minecraft:snow_block"
  13.                }
  14.        },
  15.        "result": {
  16.                 "item": "minecraft:red_dye",
  17.                 "count": 1
  18.        }
  19. }
复制代码
（以上为代码）（懂得都懂，这又是迫 害）
（以下为讲解）
"pattern"下的 "#","S"的排列方式决定了有序合成时的配方（ "#","S"可替换成别的字符，这里替换了下面的也要跟着替换）
"key"下的"#","S"后接的"item"中填上对应物品的命名空间ID（这里物品的命名空间ID分别是turtle_helmet和snow_block）
"result"下的"item"中填上被合成物品的命名空间ID（这里物品的命名空间ID是red_dye）
"count"后填数量（不大于64，例如520就不行）
怎么样，你学废了吗？
