标题: 怎么设置每一个世界的前缀和pvp
我想把地皮世界和资源世界的pvp关掉  和  在地皮世界的人 会显示[地皮]XXX  资源的就显示[资源]XXX
作者: 网络摆渡客    时间: 2014-11-1 09:39
你用的是什么多世界插件?
如果是Multiworld，禁止pvp的指令为/mw setflag 世界名 pvp false

MV的指令记不住了。

修改前缀的话这个需要使这两个世界使用独立的权限表，找到/Groupmanager/config.yml使用notepad++或者其他文本编辑工具打开并编辑：
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           替换为地皮世界的名字:
  9.           - users     //只继承主世界的users.yml，不继承groups.yml
  10.           替换为资源世界的名字:
  11.           - users     //只继承主世界的users.yml，不继承groups.yml
  12.           all_unnamed_worlds:
  13.           - users
  14.           - groups
复制代码
之后重新加载权限组插件/manload
然后在/Groupmanager/worlds/目录会生成名字有地皮和资源两个世界世界名命名的目录，里面各自有一个groups.yml。
将同目录下world中的groups.yml复制到上述两个新目录并覆盖自动生成的上述两个groups.yml。
打开上述地皮世界目录下的groups.yml，找到默认组的下列代码：
  1.     inheritance: []
  2.     info:
  3.       prefix: ''
  4.       build: true
  5.       suffix: ''
复制代码
修改为
  1.     inheritance: []
  2.     info:
  3.       prefix: '[地皮] '
  4.       build: true
  5.       suffix: ''
复制代码

同理修改资源世界的groups.yml
修改完后重新加载权限组插件/manload
