作者: jack_a1SCS    时间: 2020-7-13 17:54
mm怪物插件进行原版修改就行了
SKELETON:（原版怪物名称）
  Display: '显示名称'
  Health: 50
  Damage: 20
  Equipment:
  - LEATHER_HELMET:4
  Options:
    AlwaysShowName: true
    KnockbackResistance: 1
    MovementSpeed: 0.2
    FollowRange: 15
    MaxCombatDistance: 50
    PreventOtherDrops: true
    PreventItemPickup: true
  AITargetSelectors:
  - 0 clear
  Drops:
  - sexp 3 1
掉落物改为0就行了
