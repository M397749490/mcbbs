RealisticWorldGenerator
生成更贴近现实的地形,让玩家体验冒险的乐趣~
功能
类似于生成器的插件,主要功能用于生成地形,可以自行控制矿物密度等
安装
1.[下载安装]下载插件本体后放入服务器plugins文件夹后重启即可
生成方式①[不同的世界生成插件指令请一一对照]
[MultiWorld]/mw create <新世界名称> plugin:Realistic_World
[Multiverse-Core]/mv create <新世界名称> NORMAL -g Realistic_World
生成方式②[用于主世界]
  1. worlds:
  2.   world: #生成该地形的世界,一般服务器内world都为主世界
  3.     generator: Realistic_World #地形名称
复制代码
配置
  1. Biome: #群系控制
  2.    Vulcano: false #是否开启火山地形,true开启,false关闭,下同
  3.    DesertPlus: false #是否开启沙漠地形
  4. Coal: #煤矿
  5.     Info: Set Coal.Chance to a int between 0 and 1000， Set Coal.HightMin and Coal.HightMax between 1 and 256
  6.     Chance: 25 #煤矿的生成几率,在0-1000之间选择,请自行把握
  7.     HightMin: 1 #最低的生成高度
  8.     HightMax: 128 #最高的生成高度,该项数字最大可填256
复制代码
权限
无
