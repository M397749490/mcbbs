不需要导入世界... 额其实我昨天是懒的详细介绍，可是那样也能懂了吧

  • 输入/swr create <地图名称> 会创造一个空的地图. 你需要改造这个地图, 别忘记摆放信标代表生成点也箱子的位置.
  • 改造完后输入 /swr save <地图名称> 会保存这个地图到saves文件夹内.
  • 其次你需要注册这个地图才可以在插件内使用, 输入 /swr register <地图名称>.
  • 如果想编辑这个地图请输入 /swr edit <地图名称> 就会加载这个地图你继续编辑.
