Takeout
外卖插件 by-Vlhpe

足不出户，美食送到面前，这是在现实生活中的一大享受
但你有想过在虚拟的游戏世界中实现这一享受吗？
恭喜你！你找对帖子了！
本插件可在让玩家在MC中也能订外卖
做一只快乐的肥宅~
【本帖不再展现过久的历史更新日志】
【2.4更新内容（2019/8/3）】
【+】调整面板的样式，输入/to open后弹出主页面，主页面含【我的收藏】【点餐】【个人信息】三个选项
【+】新增收藏功能和【我的收藏】面板，玩家可对自己心仪的商品进行收藏操作，收藏的商品将呈现在【我的收藏】面板中，【我的收藏】面板与外卖商店大致相似，点击商品即可查看相关信息，且支持翻页
【+】新增的主页面依然保留了快捷返回功能，按【Esc】键时可以快速返回GUI上一级

插件特色：
[1] 创新性：将现实生活中的外卖搬进了我的世界，做一只快乐的肥宅吧
[2] 大容量的外卖商店GUI，能完全展现商品的原貌，且支持翻页
[3] 评论功能，玩家在确认收货后，可以对商品进行评价，评价分为【评星】和【评语】两个部分，商品会展现最新的三条评论
[4] 优惠券功能，在下单时玩家可以选择优惠券，确认下单时可以获得“满减”的优惠效果
[5] 会员功能，拥有会员的玩家在购买时可以获得默认20%减价效果（减免程度可自定义）
[6] 便捷的GUI操作系统，按下【Esc】键可以快速返回上一级面板，提高操作效率
[7] 收藏功能，玩家可以对喜欢的商品进行收藏，收藏的商品可以在【我的收藏】面板中看到，商品内容一目了然。
[8] 商品信息展现，点击商品可以查看其完整信息，包括【简介】【评论】【销量】等等，秒杀所有信息



游戏截图&用法

- 指令 -
<指令中的takeout可以用to代替>

/takeout open 打开外卖商城
/takeout commet <评星(1-5)> <评语> 对已买商品进行评价
/takeout c 查看已有优惠券
/takeout set <编辑名> <价格> 上架手中的商品【管理员】
/takeout remove <编辑名> 下架某个商品【管理员】
/takeout adddescription <编辑名> <内容>为某商品添加描述【管理员】
/takeout cc <编辑名> <消费金额> <减免金额> 创建优惠券【管理员】
/takeout rc <编辑名> 删除优惠券【管理员】
/takeout rc <玩家名><编辑名> 给予某优惠券【管理员】
/takeout gapc <编辑名> 给予全服玩家某优惠券【管理员】
/takeout gv <玩家名> 给予VIP【管理员】
/takeout rv <玩家名> 取消VIP【管理员】
/takeout reload 重载config.yml【管理员】

- 权限 -
takeout.admin 【管理员】权限

Step.1
上架手中的物品并为其标注简介

/takeout set <编辑名> <价格>
/takeout adddescription <编辑名> <内容>
小提示：要将上架的物品拿在手上才行哟~
编辑名相当于编号，但只能用以英文开头的英文+阿拉巴数字的组合
简介支持&颜色代码

比如/takeout set a1 20



Step.2
打开外卖商城主界面
外卖商城主界面分为【我的收藏】【点餐】【个人信息】三个按键
进入其中一个面板后输入【Esc】键可以快速返回上一级

/takeout open

这就是你刚才上架的商品
支持翻页功能，左键下一页，右键上一页




Step.3
挑选外卖，左键点击查看其信息
包括价格，简介，销量，评价等信息，点击可以购买
按Esc可以快速返回商城主界面
（2.1版本后新增优惠券功能，详情见帖子前面的部分）
优惠券用法：
在新版本中下单按钮旁有一个【优惠券】按钮，点击后可以选择优惠券
在点击后，聊天框会自动提示出你所拥有的且符合条件的优惠券的编号及信息
在15秒内直接在聊天框中输入你要使用的优惠券编号即可，然后自动跳转回下单界面
（2.2版本后改为第二行第八个格子）
VIP会员系统：
VIP可通过管理员给予（指令见上），VIP用户可以享受到一定百分比的优惠
默认是20%，腐竹可以自己在config.yml中的【Reduce】项更改
【Reduce】项以小数形式展现，如你填写0.2就是20% 0.5就是50%
若使用了优惠券，则在券后价的基础上进行减免
总之无论用不用券，都能得到优惠
收藏功能：
点击第二行第二个格子可以进行【收藏】或【取消收藏】操作
收藏后的商品，可以在【我的收藏】中看到，并且可以像商城一样点击购买
点击中间的按钮下单：
（展现商品简介，评价，销量，售价等）



在下单后，外卖将在8秒后送达
届时空手左键点击空气即可获取

Step.-
在确定收货后，可以对外卖进行评价
在外卖信息中，评价只显示最新的三条
一个订单只能评价一次
腐竹可以在config.yml禁词表中设置评语禁词

/takeout comment <评星> <评语>评星为阿拉伯数字1-5
1-失望 2-较差 3-一般 4-还行 5-很好
- 配置文件 -
插件被加载到服务器后，会生成config.yml
一个config.yml(可以在里面修改评语禁词，部分提示语等等)
