作者: Rhythm    时间: 2017-10-1 19:09
非常简单,可参考mc-proxy的说明

Minecraft-Proxy

相当于BungeeCord的精简版，完整支持Forge，暂不支持正版登录。若后端服务器是Spigot或者Cauldron，可以通过spigot.yml启用bungee模式来获取正确的客户端IP


这玩意就相当于一个精简版的Bungeecord 用于作为多个服务器共同使用同一端口的代理
Bungeecord用/server切换服务器 而这个则用匹配规则切换服务器

程序区分服务器的优先级为：

  • 查询端口和域名都符合的服务器
  • 查询域名符合的服务器
  • 查询端口符合的服务器

若上述三步均未找到服务器，则查找default字段指定的服务器，若default字段指定的服务器不存在，则会断开和客户端的连接


如果想使用Mc-proxy作为防御 那么只需要将Mc-proxy连接到BC BC再连接各个子服即可
步骤:
1.首先 将Bungeecord的端口设置为25566
2.然后 将MC-Proxy的端口设置为25565
  1. {
  2.   "port": [25566],   //程序监听的端口，可以监听任意多个端口
  3.   "host": "0.0.0.0",  //程序监听的IP，暂不支持监听多个，0.0.0.0代表所有入口ip
  4.   "default": "localhost",
  5.   "ipLimit": {    //IP并发限制
  6.     "default": 0,   //默认限制，-1代表不限制
  7.     "127.0.0.1": 0
  8.   },
  9.   "ban": {"ip": []},  //封禁ip
  10.   "servers":{  //服务器们
  11.     "25566": {    //连接的服务器的端口，即上面的端口
  12.       "host": "localhost",   //BC地址
  13.       "port": 25566,          //BC端口
  14.       "handlePing": {     //使用proxy处理ping请求，如不需要则删除该项或者设为false
  15.         "version": "1.7.10",   //服务版本
  16.         "maxPlayers": 93,     //玩家上限
  17.         "description": "minecraft-proxy",    //motd
  18.         "favicon": "path/to/file.png"       //图片
  19.       }
复制代码
这样 你便可以用 ip:25565 通过 mc-proxy 来连接 25566端口的Bungeecord服务器而Bungeecord服务器则负责把其他子服串联起来

缺点:经过多层代理 丢失IP 所有玩家IP都会是127.0.0.1
