用阿里云开的BDS服务器，想问一下怎么设置op？

作者: xmdhs    时间: 2020-2-7 12:36
后台输入 op 用户名id

或者编辑 permissions.json

参照这个格式
[
   {
      "permission" : "operator",
      "xuid" : "2535471941728363"
   }
]


xuid 可在玩家进服时看到
