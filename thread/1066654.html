      addons，全称叫add-ons for minecraft，是我的世界基岩版功能十分强大的插件

      1准备工作   一个好用的文本编辑器（推荐notepad＋＋）
                       一个浏览器（直接用ie）
                                        开始制作
首先大开任意浏览器搜索  我的世界附加包点击第一个


然后
下载原版资源包文件&原版行为包文件   


……
……（等待下载中
下载完后我们先做行为包
先创建一个文件夹可写任意名字
在再里面创建一个叫items的文件，再在里面创建一个记事本将txt改为json
然后写入
{
  "format_version": "1.10",
  "minecraft:item": {
    "description": {
      "identifier": "minecraft:shuai"    --------id，可以瞎打
    },

    "components": {
      "minecraft:use_duration": 32,
      "minecraft:food": {
        "nutrition": 4,                            ------补给值，下期再讲
        "saturation_modifier": "low"
      }
    }
  }
}     写好后将文件名命名为id的名字，
之后将下载好的Vanilla_Behavior_Pack_1.16.0.zip解压
将manifest.json剪贴到你自己做的行为包文件里

将manifest.json文件打开{
    "format_version": 2,
    "header": {
        "description": "Example vanilla behavior pack",-----简介可以瞎打
        "name": "Vanilla Behavior Pack",-----名字可以瞎打
        "uuid": "ee649bcf-256c-4013-9068-6a802b89d756",
        "version": [ 0, 0, 1 ],
        "min_engine_version": [ 1, 14, 0 ]
    },
    "modules": [
        {
            "description": "Example vanilla behavior pack",-----打你刚才输的那个简介
            "type": "data",
            "uuid": "fa6e90c8-c925-460f-8155-c8a60b753caa",
            "version": [0, 0, 1]
        }
    ],
    "dependencies": [
        {
            "uuid": "66c6e9a8-3093-462a-9c36-dbb052165822",
            "version": [0, 0, 1]
        }
    ]
}
材质包制作
首先创建一个文件夹textures然后进入创建一个名为item_texture记事本将txt改为json并输入
{
  "resource_pack_name": "vanilla",
  "texture_name": "atlas.items",
  "texture_data": {
    "shuai": {-----物品的id
      "textures": "textures/items/shuai"----物品的材质路径，注：仅能为.png，填写贴图路径时不需要加.png
    }
  }
}

将Vanilla_Resource_Pack_1.16.0.zip移植到任意文件夹只要不跟Vanilla_Behavior_Pack_1.16.0.zip解压后重名即可
将解压后的manifest.json移植到你材质包的目录并比对其更改{
    "format_version": 2,
    "header": {
        "description": "Example vanilla resource pack",,-----打你刚才输的那个简介
        "name": "Vanilla Resource Pack",,-----打你刚才输的那个名称
        "uuid": "66c6e9a8-3093-462a-9c36-dbb052165822",
        "version": [0, 0, 1],
        "min_engine_version": [ 1, 14, 0 ]
    },
    "modules": [
        {
            "description": "Example vanilla resource pack",,-----打你刚才输的那个简介
            "type": "resources",
            "uuid": "743f6949-53be-44b6-b326-398005028819",
            "version": [0, 0, 1]
        }
    ]
}
保存即可
当然，你现在没有给物品分类，所以在物品栏是找不到的，只能通过指令获取，
