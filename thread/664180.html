PermissionManager
权限管理员是一个有特色的权限插件，他可以让管理员轻松地控制服务器的权限和权限组
PermissionManageris a permission plugin with a lot of features to let the administratorscontrols the
permissions and the groups on their server.

功能特色
  • Support all the subjects(Players, groups, etc)
  • 支持所有的功能（玩家、权限组等等……）
  • Full integration of the PermissionService ofSponge API.
  • 给海绵端整合完整的权限服务
  • Multiple contexts supported
  • 支持多种语境
  • Multi world support.
  • 支持多世界
  • File format yaml
  • 文件格式为yaml
  • Tab completion.
  • 自动补全
  • Rule system416, to add some conditions to the use of apermission.
  • 可用规则系统来给权限添加一些条件
  • Promotion system.
  • 换职系统
  • Save and load each user, group or promotionwhile the server is running.
  • 可让服务器运行时加载、保存、换职（无需重启服务器）
  • Interactif menu
  • 交互菜单

Sponge API
  • 6.X
  • 5.X
  • 4.2.0
