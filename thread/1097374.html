如果你不是想要让两个世界的背包独立出来，而是切实想要让玩家去到某个世界直接清空玩家的背包的话（无法恢复）。
可以编写插件
这里是核心代码：
  1. public class YourPlugin extends JavaPlugin implements org.bukkit.event.Listener {
  2.     @Override
  3.     public void onEnable(){
  4.         getServer().getPluginManager().registerEvents(this, this); //注册监听器
  5.         getLogger().info("清空背包的插件已加载");
  6.     }
  7.     @EventHandler
  8.     public void playerPreJoinWorld(PlayerPortalEvent e)//使用传送门到这个世界的监听器
  9.     {
  10.             if ((e.getTo().getWorld().getName().equals("世界名") && !e.getPlayer().isOp()))
  11.             {
  12.                 e.getPlayer().getInventory().clear();//清空玩家背包
  13.             }
  14.     }
  15.     @EventHandler
  16.     public void playerPreJoinWorld(PlayerTeleportEvent e)//传送到这个世界的监听器
  17.     {
  18.         if ((e.getTo().getWorld().getName().equals("世界名") && !e.getPlayer().isOp()))
  19.         {
  20.             e.getPlayer().getInventory().clear();//清空玩家背包
  21.         }
  22.     }

  24. }
