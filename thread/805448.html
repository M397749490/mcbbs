找到解决方案了，在kc服务端里，找到一个叫<kcauldron.yml>的文件，用notepad++打开，然后找到updatechecker，再找到enable:true,把true改成false，就可以解决啦~
如果不知道的，我把代码放在下面，可以参考一下~
  1. common:
  2.   allowNetherPortalBesidesOverworld: false
  3.   fastLeavesDecay:
  4.     enable: false
  5.     maxTickTime: 10
  6.     minTickTime: 5
  7. updatechecker:
  8.   quiet: false
  9.   symlinks: KCauldron.jar
  10.   enable: false
  11.   autorestart: false
  12.   autoinstall: false
  13.   quite: false
  14. logging:
  15.   materialInjection: false
  16.   clientModList: true
  17. experimental:
  18.   tileEntityListRecreation: false
  19. command:
  20.   enable: true
