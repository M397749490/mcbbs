方法一

在项目的gradle.properties文件中添加一行，设置jvm的MaxHeapSize值

org.gradle.jvmargs=-XX\:MaxHeapSize\=256m -Xmx256m
方法二

打开Android studio，然后关闭所有的项目（File-> Close Project）,进入了欢迎的窗口

Configure > Settings->Build, Execution, Deployment > Compiler

修改Build process heap size (Mbytes) 值为 1024
修改 Additional build process to VM Options 值为 -Xmx512m.
方法一有时不会奏效，就可以使用方法二。
