在AuthMe作为前置的情况下，你可以使用自定义登录界面。

你可以在插件配置文件夹下的login.yml中进行编辑：

#是否使用自定义的登录界面

#需要AuthMe或是其他登录插件作为前置

login: true

#自定义登录界面的背景图片URL

url: '[local]login.png'

#自定义背景图片显示的X坐标

x: 0

#自定义背景图片显示的Y坐标

y: 0

#背景图片的实际宽度

xSize: 694

#背景图片的实际高度

ySize: 434

#背景图片的显示宽度

xShow: 694

#背景图片的显示高度

yShow: 434

#输入框颜色选择(BLUE/PURPLE/RED/YELLOW/WHITE/BLACK/GREEN|共七种)

textfieldcolor: PURPLE

#输入框是否呈半透明状

textfieldalpha: true
