可以啦，怎么简便怎么来

/bossbar/execute/scoreboard就可以了
/bossbar add <id1> <文本（JSON）> #创建
/bossbar set <id1> players @a #展示给所有玩家
/bossbar set <id1> max 9 #设置总进度为9
/scoreboard objectives add <id2> dummy
/scoreboard players set <一个名字> <id2> 0
那么按钮点击时运行
/scoreboard players add <一个名字> <id2> 1
/execute store result bossbar <id1> value run scoreboard players get <一个名字> <id2>
