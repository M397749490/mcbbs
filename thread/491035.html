[map]介绍：
      此工具是专门给mcbbs上的新闻发布者准备的，会定时检测Mojang官方的更新，发现更新后会第一时间弹出窗口提醒，于是就可以第一时间抢到新闻23333……如果不信，可以看我勋章栏里那闪闪发亮的新闻官勋章~

[red_music_disc]运行截图&界面说明&使用方法：

    由于某某某些原因，我写的时候用的是英文...不过这不重要，相信能翻译Mojang的奇葩更新日志的人都能看懂233

    第一次运行时，程序会生成一个config.json和一个versions.json。那个versions.json储存的是旧版本列表，不用理它，删了就没法区分旧版本和新版本了。
     config.json里面顾名思义是配置文件，内容如下：
  1. {
  2.     "Interval":10,
  3.     "CheckURL":"http://s3.amazonaws.com/Minecraft.Download/versions/versions.json"
  4. }
复制代码
    Interval是定时检测时间，默认为10秒。
     CheckURL为版本列表的网址，请不要修改成比如说BMCLAPI的网址，因为BMCLAPI虽然快，但是并不是实时更新的，跟官方的有时间差。
     修改了配置文件后，重新启动，程序就会读取配置文件。然后你就不需要管那个黑黑的cmd窗口啦，等它检测到新版本时，会自动弹出提示窗口(见图内)，告诉你有新版本啦。窗口内信息以及其意思如下：
英文
意义
例子
Version  ID
  新版本的版本号
15w37a
Release  Time
  发布的时间，格式为
  本地时间  (GMT: GMT时间)
2015/9/10 22:22:31 (GMT: 2015/9/10 14:22:31)
  
Type
  		  新版本的类型,
“snapshot”代表新版本是个快照,
”release”代表新版本是正式版
snapshot
  
Found Time
  		  程序弹出窗口提示你有新快照的时间，
也就是发现这个更新的时间。
2015/9/11 22:17:31
Update Log
  更新日志的网址,
打开后里面是此版本的更新日志*
https://mojang.com/2015/9/
[View Update Log]
  点击打开更新日志
-
[Close]
  关闭这个窗口(不会关闭程序运行)
-
*那个更新日志的网址并不是点进去就可以看见的...那只是本月的所有更新的列表，因为不同版本的日志的链接没有固定的格式(甚至还会出错，比如链接里是15w32a，点进去是15w32b)，程序无法判断到底哪个是正确的，只好麻烦你多点一下喽QAQ
控制台里的信息基本不需要管，所以在此就不解释了。相信你看得懂……
此程序运行消耗的资源非常少，因此如果你愿意，甚至可以整晚开着电脑，第二天早上早起去看。
