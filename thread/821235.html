GM-sktotal

GM 的多功能脚本合集

安裝方法:
首先安装skript与其他前置插件 并将脚本放入伺服器文件（脚本副档名都是sk）plugins/Skript/scripts 并输入/ sk reload all即可完成读取所有脚本

脚本介紹:
Heart bottle 心臟罐
功能介紹:
玩家可以透过心脏罐提升自身血量上限并且可限制玩家使用心脏罐的使用次数，另外此脚本不适合与其他有关血量插件并用

指令:
/h指令列表
/h give [玩家]给予玩家一个心脏罐
/h clear [玩家]重置一个玩家的生命值上限
/h set [玩家] [血量]设置玩家的生命值上限
/h check [玩家/空]查看该玩家的生命值上限，空为查看自己

權限:
heart.use查看目前的血量資訊
heart.admin使用所有指令的權限


設定檔:
        # 使用次數限制
        max: 20

    # 物品id
        item_type: rose red
        # 物品名稱
        item_name: &c心臟罐
        # 物品敘述 || 為分行
        item_lore: &c點擊右鍵即可使用||&e每次使用可擴充一格生命值||&a最多能夠使用 &f20 &a次

        # 提示設定
        heart_msg1: &c你的心臟罐使用次數已達到上限

        heart_msg2: &a成功添加 &f1 &a格生命上限,目前血量上限: &e%{_num2}*2% &4剩餘使用次數: &f%{_msg}% &4次

        get_item: &a獲得了一個心臟罐!

        # 指令提示設定

        cmd_msg1: &f你的目前 &a生命值上限: &e%{_numbera}*2%

        cmd_msg2: &c你已使用了 &f%{_numberb}% &c次心臟罐,還剩 &f%{_msg}% &c次

TitleItem 廣播物品
功能介紹:
玩家可以使用自定义广播物品对全服发送大大的标题广播，手持广播物品点击右键即可广播“/”符号为分行用，每次则会消耗一个喇叭（预设）。另外，普通玩家只可 使用副标题广播,需要有权限 ti.vip 才可使用完整的广播，如果不想有此功能将普通玩家添加权限即可

RenameTag 武器改名卡
功能介紹:
玩家可以透过改名卡让武器的名子能有更多色彩，是个非常轻量的脚本

指令&權限:
/rt give <player> 給玩家改名卡

rt.admin 指令權限


設定檔:
        #物品設定
        itemtype: name tag
        itemname: &e武器改名卡
        itemlore: &b點擊&a右鍵&b即可開始改名

        
  #提示設定
        msg1: &a請將手上移到想改名的武器,並輸入名子! &c點擊 &fshift &c取消
        
        msg2: &a成功將武器命名為 &r%message%
        
        msg3: &c你必須擁有改名卡!
        
        cancel: &c成功取消命名

ShowChest  展示箱
简介：
这是轻量到不行的迷你脚本，相信很多伺服器都会需要展示箱这种东西，玩家需要有权限才能编辑箱子内的物品

使用方法：
先使用指令/ showchest get 得到获得的箱子即是展示箱了，接下来就可以将物品放进去展示了！

指令&權限:
/showchest get 獲得展示箱
/shc list 查看所有展示箱座标

sc.admin 編輯箱子許可權

ItemLoreClear  删除带有指定Lore的物品
简介：
可在玩家登入时检查玩家的背包，若玩家背包中物品lore带有指定lore，将直接删除该物品，并通报管理员
使用方法:
先使用指令/ ilc add [储存的代号] [侦测的叙述] 添加完成后，使用指令/ ilc start 即可将目前线上玩家的背包物品带有 [侦测的叙述]的物品清除了

指令&權限:
ilc.admin - 使用指令的權限
/ilc add [代号] [字串] 将一段叙述储存进资料库
/ilc list 查看所有已储存的叙述
/ilc del [代号] 删除一个已储存的叙述
/ilc clear 清除所有储存的叙述
/ilc start   清除所有玩家身上带有 <已储存叙述> 的物品

设定档：
  #是否开启玩家登入检查背包物品 false 为关闭
        登入: true

   #讯息编辑
        msg_to_player: &c你背包含不合法物品,已被清除!

   #发送给op的讯息
        msg_to_op: &f%player% 的 %{_name}% &a成功删除
