怎么开服呀？不用开服器
作者: jiuerd    时间: 2014-6-20 22:42
下载核心文件mcpc、craftbukkit等等；
然后在核心文件同目录下新建一个txt；
修改txt内容如下：
@echo OFF
echo run server now ,  you can't close
SET BINDIR=%~dp0
"C:\Program Files\Java\jre7\bin\java.exe" -Xms16m -Xmx1g -jar "%BINDIR%\mcpc-plus-1.6.4-R2.1-forge965-B251.jar
java路径改为你的java安装路径；
绿色部分改为你的核心文件名字；
把txt重命名为run.bat；
双击运行run.bat文件；
等待一段时间后命令提示符窗口出现help or ？之后就说明开服成功；
