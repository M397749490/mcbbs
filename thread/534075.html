【解决办法 - 对于插件开发者】
  1. public void reloadCustomConfig() throws Throwable {
  2.         if (!dataFolder.exists()) {
  3.             dataFolder.mkdirs();
  4.         }
  5.         File configFile = new File(dataFolder, "config.yml");
  6.         if (!configFile.exists()) {
  7.             configFile.createNewFile();
  8.         }
  9.         config = YamlConfiguration.loadConfiguration(configFile);  //加载配置文件
  10.         DumperOptions yamlOptions = null;
  11.         try{
  12.             Field f = YamlConfiguration.class.getDeclaredField("yamlOptions");   //获取类YamlConfiguration里的匿名yamlOptions字段
  13.             f.setAccessible(true);
  14.             
  15.             yamlOptions = new DumperOptions(){  //将yamlOptions字段替换为一个DumperOptions的匿名内部类，里面替换了setAllowUnicode方法让其永远无法设置为true
  16.                 @Override
  17.                 public void setAllowUnicode(boolean allowUnicode) {
  18.                     super.setAllowUnicode(false);
  19.                 }

  21.                 @Override
  22.                 public void setLineBreak(DumperOptions.LineBreak lineBreak) {
  23.                     super.setLineBreak(DumperOptions.LineBreak.getPlatformLineBreak());
  24.                 }
  25.             };
  26.             
  27.             yamlOptions.setLineBreak(DumperOptions.LineBreak.getPlatformLineBreak());
  28.             f.set(config, yamlOptions); //把新的yamlOptions偷梁换柱回去
  29.         }catch(ReflectiveOperationException ex){
  30.         }
  31.     }
复制代码

这是我的ColorMOTD插件内配置文件夹加载器中的一个方法
平常插件加载配置文件都是使用
  1. saveDefaultConfig();
  2. reloadConfig();
复制代码

然后通过getConfig()访问
我这个方法代替了saveDefaultConfig()、reloadConfig()和getConfig()的功能，
其中使用了2个全局变量需要说明：
  1. File dataFolder;  //也就是主类中getDataFolder()的返回值
  2. FileConfiguration config;  //替代getConfig()，读取配置文件时就操作它好了
复制代码

这个方法关键是把YamlConfiguration里的yaml设置DumperOptions里面的setAllowUnicode方法覆盖掉，使其无法被设为true
然后就解决了╮(╯▽╰)╭
