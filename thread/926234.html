每周快照是Minecraft Java版的测试机制，主要用于下一个正式版的特性预览。

   
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。在快照中打开存档前请务必进行备份。适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。

   
Minecraft 1.15 仍未发布，19w46b为其第15个预览版。

Minecraft Snapshot 19w46b
Minecraft 快照 19w46b

  Changes in 19w46b
    改动

  • Fixed a crash when bees forgot about a flower position
  • 修复了蜜蜂忘记花朵位置时的崩溃
  • Fixed a crash when an invalid biome was specified for a superflat world
  • 修复了为超平坦世界指定一个无效的生物群系时的崩溃
  • Fixed a crash when tab completing names in the chat
  • 修复了在聊天栏中用Tab补全名称时的崩溃
  • Contrast tweaks for text colors
  • 文本颜色的对比度调整
  • Command suggestions are now narrated if the narrator is turned to system or all
  • 命令建议现在会在复述功能开启为复述所有或复述系统消息时复述。

    Fixed bug in 19w46b
    修复漏洞


  • MC-161874 - Scoreboard sidebar text is partially transparent
  • MC-161874 - 记分板侧栏文本会部分透明

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。Java版的启动器下载地址在上文已经提供。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
