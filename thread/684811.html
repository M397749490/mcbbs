插件介绍
你还在用Essentials自带的hat功能？你想给你的VIP玩家一些稀有方块当做帽子，又担心他们拿着方块乱来？那么你一定要试试这款插件！这款插件允许你设置让玩家用任何方块戴在头上，但是，只要是生存模式和冒险模式的玩家，他们直接拿是拿！不！下！来！的！玩家可通过输入指令打开GUI菜单操作，十分安全

GUI菜单选择头戴方块


为什么要在意细节？


安装与使用
下载本插件，放入plugins文件夹，重启服务器

和Essentials自带的/hat的兼容性

之前我做了实验，用ess自带的hat往头上戴了一个草方块，如下图



可以确认这个方块也是拿不下来的，而且菜单中“移除帽子”那一栏也有显示，可以说是能兼容



但是，安装了这个插件后请不要再给玩家essentials.hat权限，因为使用ess的/hat指令，玩家先前戴的方块会返回背包，可能会造成不小的困扰
关于和Essentials或者其他帽子插件的兼容我已经向作者询问，作者建议使用了本插件以后不要再使用其它帽子插件，否则可能会出现一系列问题



感谢PCD大佬XJue_DaDa提出的问题


指令与权限
  • - /hats - 打开帽子GUI菜单
  • - /hats set [玩家] <物品> [物品名称] - 设置一个玩家的帽子，当[玩家]值缺省的时候默认是你自己
  • - /hats remove [玩家] - 移除一个玩家的帽子
  • - /hats add [物品名称] - 把你手持的这件方块加入GUI菜单中
  • - /hats reload - 重载插件
  • - /hats help - 插件帮助.

酌情给玩家的权限
betterhats.use - 打开GUI菜单
betterhats.all - 使用所有帽子种类的权限
betterhats.<帽子种类> - 使用指定帽子种类的权限

安装方法

下载jar文件,扔进plugins文件夹里，重启服务器……我感觉大家都会吧……


指令
- /hats - 打开帽子GUI菜单
- /hats set [玩家] <物品> [物品名称] - 设置一个玩家的帽子，当[玩家]值缺省的时候默认是你自己
- /hats remove [玩家] - 移除一个玩家的帽子
- /hats add [物品名称] - 把你手持的这件方块加入GUI菜单中
- /hats reload - 重载插件
- /hats help - 插件帮助.

权限
- betterhats.use - 打开GUI菜单-先把这个权限给VIP玩家
- betterhats.all - 允许使用全部种类的帽子 - 给了这个权限以后玩家可以使用所有帽子（特殊设置的除外）
- betterhats.特殊设置 - 单独设置某种帽子是否可选-这个权限会覆盖上一个权限
----------后面的权限不用看了----------
- betterhats.set - 使用设置帽子 "/hats set" 命令
- betterhats.set.other - 设置别人的帽子的命令 "/hats set"
- betterhats.remove - 移除自己的帽子
- betterhats.remove.other - 移除别人的帽子"/hats remove"
- betterhats.add - 使用指令 "/hats add [物品名称]" 添加帽子种类
- betterhats.delete - 删除帽子种类
- betterhats.reload - 重载插件
