标题: Time Is Money ATM 1.8原版单人模拟服务器插件
好久没有发帖了！所以我决定冒一下泡！
我无聊时制作的作品
这是一个模拟服务器的"Time Is Money"插件的地图（相似度:100%）
纯使用1.8.8原版的东西制作的，没有任何的mod和服务器的插件制作，无需mod和插件运行
主要运用计分板以及牌子的json和漏斗计时器

建筑材料：10个命令方块、13根红石线、5个中继器、2个粘性活塞、2个漏斗、2个比较器、2个按钮、2压力板、1红石块和1告示牌（好多2哦）
截图:


计分板：请自己输入/scoreboard objectives list来查看计分板（已经注释）
  1. /scoreboard objectives list
复制代码
命令方块的命令：
牌子后面的第一个命令方块（把最近玩家的在线时间设置为缓存的钱）
  1. /scoreboard players operation @p DummyMoney = @p OnlineTime
复制代码
牌子后面的第二个命令方块（把最近玩家的在线时间设置为0）
  1. /scoreboard players set @p OnlineTime 0
复制代码
牌子后面的第三个命令方块（把最近玩家缓存的钱乘以System的Double的值）
  1. /scoreboard players operation @p DummyMoney *= System Double
复制代码
牌子后面的第四个命令方块（把最近玩家缓存的钱加进实际的钱）
  1. /scoreboard players operation @p Money += @p DummyMoney
复制代码
牌子后面的第五个命令方块(设置最近玩家缓存的钱设置为0)
  1. /scoreboard players set @p DummyMoney 0
复制代码
牌子后面的第六个命令方块（显示玩家的钱）
  1. /setblock -199 71 -183 minecraft:wall_sign 5 replace {
  2. Text1:"{text:"谢谢!",color:dark_blue}",
  3. Text2:"{text:"现在你有 :",color:dark_blue}",
  4. Text3:"{text:"",color:green,extra:[{score:{name:"@p",objective:"Money"}},{text:"元"}]}"
  5. }
复制代码
——————————————————————————————————————————分割线
牌子前面的第一个命令方块(Json不解释)
  1. /setblock -199 71 -183 minecraft:wall_sign 5 replace {
  2. Text1:"{text:"你好 ",color:dark_blue,extra:[{selector:"@p"}]}",
  3. Text2:"{text:"在线时间 :",color:dark_blue}",
  4. Text3:"{text:"",color:green,extra:[{score:{name:"@p",objective:"OnlineTime"}},{text:" min."}]}",
  5. Text4:"{text:"<-给予的钱->",color:dark_blue}"}
复制代码
牌子前面的第二个命令方块（清空牌子的文字）
  1. /setblock -199 71 -183 minecraft:wall_sign 5
复制代码
最后是漏斗计时器，两个漏斗一共有150个红石，不断地进行流动，每当一个漏斗满了，则另外一个漏斗是空的，比较器就不输出，活塞就把红石块推过去触发命令方块，活塞推一次为1分钟，且增加在线玩家计分板OnlineTime的值为1
