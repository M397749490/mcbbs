作者: lgou2w    时间: 2019-8-13 22:03
Asynchronous block remove! 方块、实体这些的都不能在异步线程中操作的，因为服务端底层实现问题。你可以在异步线程中调度一个服务器同步任务来处理方块修改操作。
  1. Bukkit.getScheduler().runTask(YourPlugin, () -> {
  2.   Block block = ...;
  3.   block.setType(xxx);
  4. });
