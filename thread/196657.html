限制了大小  

找到领地插件生成的文件：Residence

找到配置文件config.yml

用记事本打开

找到
  1. CanCreate: true
  2.            # The maximum number of Residences a player can have.
  3.            MaxResidences: 3
  4.            # The maximum number of physical areas a residence can have.
  5.            MaxAreasPerResidence: 2
  6.            # The maximum number of blocks a Residence can be, East to West (X).
  7.            MaxEastWest: 256
  8.            # The maximum number of blocks a Residence can be, North to South (Z).
  9.            MaxNorthSouth: 256
  10.            # The maximum number of blocks a Residence can be, High to Low (Y).
  11.            MaxUpDown: 256
