5.名字：LoginSecurity ——登录插件

作用：用于防止他人登录别的玩家帐号进行拿去东西，简单来说就是一个登录验证一下你是否是这个帐号的主人

指令：/login <密码> 登录 | /register <密码> 注册  ，这个插件无法简略的输入，例如：/L <密码> 这种方式登录

权限：默认分配完毕

Config文本设置： true = 是 ； false = 否

settings:
  password-required: false
#是否强制所有玩家注册密码？ 默认:否
  encryption: MD5
#用户密码加密储存方式，可选择MD5, SHA, SHA-1, SHA-256, SHA-512 和 PHPBB3
  encoder: UTF-8
#编码模式，可选择UTF-8 和 UTF-16
  PHP_VERSION: 4
  messager-api: true
  blindness: true
#降低未登录玩家的视野？默认：是
  session:
    use: true
    timeout (sec): 60
#玩家退出后是否保留登录状态。默认：是    时间：60（秒）
  timeout:
    use: true
    timeout (sec): 60
#玩家超过一定时间未登录将退出服务器。默认：是    时间：60（秒）
  table prefix: ls_
#聊天前缀 （作用不明）
MySQL:
  use: false
#使用MySQL    默认：否
  host: localhost
  port: 3306

教程：
首先准备两样东西（必须要下载好java），第一样是服务端文件，第二样是新建一个文本。
第一步：把上面两样东西都放在一个新建的文件夹里，文件夹可以取名为【我的服务器】
第二步：打开文本，在里面输入以下代码
"C:\Program Files\Java\jre7\bin\java.exe" -Xincgc -Xmx4G -jar mcpc-plus-1.6.4-R2.1-forge965-B251.jar"
解释：
黄色的这一段是你"自己的java目录" 绿色的这一段是你的最大物理内存 蓝色这一段是你服务端文件名"
顺便考验一下你是否有色盲—————————————————————————————————
第三步： 把文本后缀改为.bat格式，之后双击进行启动。等待后台加载成功。
第四步：加载完毕之后，输入stop进行关闭服务器，以后都要这样关闭服务器，不行直接×
第五步：关闭后台之后，文件夹内会自动新建一个文本型的文件，名字为<server properties>，右键他进行编辑
第六步：找到<online-mode=true>这行文字，把true改为false
第7步：你的服务器建立完毕！
服务器小常识： 如果服务端文件是craftbukkit ，则无法安装MOD，是MCPC则可以安装MOD。
给不知道什么类型的服务端可以安装MOD小白。

服务器文本<server properties>翻译{只翻译重点｝


server-ip=                                                             此项不要设置，他是逻辑性的，如果没设置，则取本电脑的外网IP
max-build-height=256                                            最高层度，玩家可以建筑到最高256                                            
white-list=false                                                       白名单 是否启用
online-mode=false                                                  是否开启正版验证，默认为true 必须要改为false
pvp=true                                                                是否开启PVP
