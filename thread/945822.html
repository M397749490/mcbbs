标题: 发一下搭建vip的全过程指令
比如我要弄vip和svip这两个，用的权限组插件是[权限]LuckPerms-Bukkit-4.4.1
第一步要先发什么指令？第二步呢，一步一步按顺序麻烦了
作者: GiNYAi    时间: 2020-1-24 19:20
本帖最后由 GiNYAi 于 2020-1-24 20:07 编辑

新建一个权限组(vip)
  1. /lp creategroup vip
复制代码

给vip组添加要给的特殊权限
  1. /lp group vip permission set xxxx.xxx
复制代码

或者
  1. /lp group vip editor
复制代码


然后vip组就做好了
给玩家添加vip权限的话是
  1. /lp user <player> parent add vip
复制代码

如果要控制时间的话是(30天)
  1. /lp user <player> parent addtemp vip 30d accumulate
复制代码


新建一个权限组(svip)
  1. /lp creategroup svip
复制代码

通常svip会包含vip的全部权限
那么可以添加svip继承vip
  1. /lp group svip parent add vip
复制代码


给svip组添加要给的特殊权限
  1. /lp group svip permission set xxxx.xxx
复制代码

或者
  1. /lp group svip editor
复制代码
