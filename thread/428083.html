首先要使这个世界使用独立的权限表，打开Groupmanager/config.yml并找到下面的代码，并按照样子修改：
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          替换为这个世界的名字:
          - users     //只继承主世界的users.yml，不继承groups.yml
          all_unnamed_worlds:
          - users
          - groups
复制代码
之后重新加载权限组插件/manload
然后在/Groupmanager/worlds/目录会生成名字为“替换为这个世界的名字”的目录，里面有一个groups.yml。
将同目录下world中的groups.yml复制到改目录并覆盖自动生成的上述groups.yml。
打开并编辑：
找到默认组，将build: true改为build: false

然后添加下列权限：
    - essentials.build.drop.*         //丢弃
    - essentials.build.interact.*     //交互
    - essentials.build.pickup.*       //捡拾
    - essentials.build.use.*          //使用
复制代码
以上代码中的*代指所有物品。
如果将*替换为物品id则代表只允许该物品的以上权限。
这样玩家只能在这个世界活动，但是不能放置和破坏方块了。

还要注意一下Essentials配置里的这个
############################################################
# +------------------------------------------------------+ #
# |               Essentials 建筑控制                    | #
# +------------------------------------------------------+ #
############################################################

  # Disable various default physics and behaviors
  # 查看更多信息,请访问 http://wiki.ess3.net/wiki/AntiBuild

    # 玩家是否可以建造:
    # 设置为 true 可以禁用那些没有权限玩家的建造
    # 设置为 false 将使 EssentialsAntiBuild 从不阻止玩家建造
    build: true

    # 玩家是否可以使用物品:
    # 设置为 true 可以禁用那些没有权限玩家的使用物品
    # 设置为 false 将使 EssentialsAntiBuild 从不阻止玩家使用物品
    use: true
                            就上面这个要注意
    # 玩家无法建造时是否提示玩家
    warn-on-build-disallow: true
