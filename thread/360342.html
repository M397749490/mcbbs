如何设置服务器单个世界权限
比如在地狱设置普通玩家不可破坏  【例子是地狱！！】
还有其他权限 无法back{:10_512:}
作者: 网络摆渡客    时间: 2014-11-2 09:18
以地狱为例：
首先要是这个世界使用独立的权限表：
  1.         world:
  2.           world_nether:
  3.           - users    //只继承主世界的users.yml，不继承groups.yml
  4.           world_the_end:
  5.           - users
  6.           - groups
  7.           all_unnamed_worlds:
  8.           - users
  9.           - groups
复制代码
之后重新加载权限组插件/manload
然后在/Groupmanager/worlds/目录会生成名字为“world_nether”的目录，里面有一个groups.yml。
将同目录下world中的groups.yml复制到改目录并覆盖自动生成的上述groups.yml。
打开并编辑：
找到默认组，将build: true改为build: false
然后添加下列权限：
  1.     - essentials.build.drop.*         //丢弃
  2.     - essentials.build.interact.*     //交互
  3.     - essentials.build.pickup.*       //捡拾
  4.     - essentials.build.use.*          //使用
复制代码
以上代码中的*代指所有物品。
如果将*替换为物品id则代表只允许该物品的以上权限。
这样玩家只能在这个世界活动，但是不能放置和破坏方块了。
如果取消back，需要去掉下面的权限：
  1.     - essentials.back
  2.     - essentials.back..ondeath
