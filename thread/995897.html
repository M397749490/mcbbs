作者: 青芦叶    时间: 2020-3-25 20:10
整合包怎么说也应该是改config文件啊。。整合包就玩一个存档吗

config文件里面明明就有设置每晚都是血月的方法：

bloodmoon.cfg：
   schedule {
        # The chance of a bloodmoon occuring at the beginning of a night (0=Never;1=Every night;0.05=5% of all nights)
              血月在夜晚开始时发生的概率：（0=不发生；1=每晚都是血月；0.05=夜晚中的5%）
        D:Chance=0.05


        # Whether there should be a bloodmoon whenever there is a full moon
        满月时是否一定发生血月
        B:Fullmoon=false


        # Every nth night there will be a bloodmoon (0 disables this, 1 would be every night, 2 every second night)
         第几个晚上发生血月（0表示禁用，1表示每晚，2表示每第二个晚上）
        I:NthNight=0
    }

注意：
血月只在time=12000开始,你必须把时间设置在11999之前，让它自动到12000触发
否则直接跳时间到晚上（甚至直接time set 12000 都不会触发血月）
/bloodmoon force:明晚将是血月来临之时
这时候你跳时间time set 18000还不是血月，你还可以睡觉。醒来以后当天晚上才是血月。不信你可以试试。


我敢说上面这些人都没有玩过这个mod，甚至没有自己试一试。


于是你应该：
先建立一个存档
/bloodmoon force（出现提示——明晚将是血月来临之时）
然后 /time set 11999 (出现提示——血月升起了...）
然后（等一会），关闭日夜循环 /gamerule doDaylightCycle false
