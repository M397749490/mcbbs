教程开始：
大家应该也知道trigger吧，我只知道1.8有 1.9+的话我都不知道....
大家也知道trigger指令用法：/trigger 记分牌 add或set 数字
你输入了之后会显示什么什么未启用对吧
所以要先添加一个记分牌名字为spawn
  1. /scoreboard objectives add spawn trigger
复制代码

之后你需要用红石高频连接这个命令
  1. scoreboard players enable @a spawn
复制代码
上面这个命令就是激活所有玩家

然后继续用高频激活下面两条指
  1. tp @a[score_spawn_min=2,score_spawn=2] x y  z
复制代码


  1. scoreboard players set @a[score_spawn_min=1] spawn 0
复制代码
上面的tp @a[score_spawn_min=2,score_spawn=2] x y z 代表：tp所有spawn分数为2的人到某个地方，记得xyz要改成你想要的坐标哦
上面的scoreboard players set @a[score_spawn_min=1] spawn 0 代表：设置所有spawn分数大于1的人设置为0

然后你输入/trigger spawn set 2我比较习惯用set- -，然后你就会被tp到你所设置的xyz
很简单吧，你还能继续设置，只要在添加一个tp @a[score_spawn_min=3,score_spawn=3] x y z 就是trigger设置为3的时候tp到xyz
你可以无限设置
当然输入指令麻烦的可以使用书 指令：
  1. give @p minecraft:written_book 1 0 {title:"传送书",author:小晴制作禁止盗版,pages:["{text:"          传送列表",color:green,extra:[{text:"\n□■□■□■□■□■□■□■□■□■□■□■□■□",color:gold},{text:"\n       点我传送回城",color:blue,bold:true,clickEvent:{action:run_command,value:"/trigger spawn set 2"}},{text:"\n----------------------------",color:blue},{text:"\n传送到其他地方",color:blue,bold:true,clickEvent:{action:run_command,value:"/trigger spawn set 3"}},{text:"\n□■□■□■□■□■□■□■□■□■□■□■□■□",color:gold},{text:"\n       下面是op的指令",color:green},{text:"\n         点击变创造",color:gold,clickEvent:{action:run_command,value:"/gamemode 1"}},{text:"\n          点我自杀",color:gold,clickEvent:{action:run_command,value:"/kill"}}]}"]}
