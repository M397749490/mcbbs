今日知识

  • 关于java语言当中的整数型
数据类型     占用空间大小      默认值         取值范围
------------------------------------------------------------
byte              1             0           [-128~127]
short             2             0           [-32768 ~ 32767]
int                 4             0           [-2147483648 ~ 2147483647]
long              8             0L

  • java语言当中的"整数型字面值"被默认当做int类型来处理。要让这个"整数型字面值"被当做
    long类型来处理的话，需要在"整数型字面值"后面添加1/L,建议使用大写的L

  • java语言当中的整数型字面值有三种表示方式
第一种方式：十进制【是一种缺省默认的方式】
第二种方式：八进制【在编写八进制整数型字面值的时候需要以0开始】
第三种方式：十六进制【在编写十六进制整数型字面值的时候需要以0x开始】
