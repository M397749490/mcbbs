CustomNPCFix
BGM:

前言:
使用开源项目:https://github.com/stleary/JSON-java

这是一个简单的mod 他优化了CustomNPC的不足之处
注意:
1.他的任何优化项都是默认关闭的
2.他是补丁 不能独立运行 需要NPC本体作前置
3.可仅仅服务器使用 但不一定所有优化项生效
4.因为修改了NPC本体 请慎用
5.本MOD1.7.10和1.12.2并非完全相同 且主要升级1.12.2
6.秋梨膏 不要无脑全部打成true
配置文件 config/customnpcsfix.cfg 再问**

配置文件参考:
仅供参考 并非推荐配置(主要是我懒得改回默认)
1.7.10:

  2. # Configuration file

  4. client {
  5.     # 死亡自动把NPC补充到区块
  6.     # 这通常用来修复死后不可互交BUG
  7.     B:AutoReaddNPCToChunk=true

  9.     # 会为无材质的NPC使用透明材质,这防止了此错误信息在客户端日志里刷屏
  10.     # 这通常服务强迫症和开发者
  11.     B:SafeRenderNoTexNPC=false
  12. }


  15. general {
  16.     # 更快的JSON反序列化 虽然不是特别快 但是比NPC自带的快的多
  17.     # 这通常用来修复开启玩家档案卡顿
  18.     B:FastJsonDeserialize=false

  20.     # 修复%信息崩溃bug
  21.     # 这通常用于修复:
  22.     # 1.NPC台词里使用%导致错误
  23.     # 2.NPC脚本里NPC的say方法和玩家的message发送%导致错误
  24.     B:NoMsgPercentSymbolBug=false

  26.     # 慎用! Gson实现json(反)序列化 特大复杂数据比FastJsonDeserialize快
  27.     # 注:
  28.     # 1.需先启用FastJsonDeserialize
  29.     # 2.Gson序列化的文件原版NPC不可反序列化
  30.     B:UseNBTJson=false
  31. }



复制代码

1.12.2:

  2. # Configuration file

  4. client {
  5.     # 不发送无脚本内容的保存请求。
  6.     # 这通常用于解决有时候出现的脚本保存丢失
  7.     B:DontSendDubiousScript=false

  9.     # 当脚本为11页时,隐藏添加按钮
  10.     # 这通常服务强迫症和开发者
  11.     B:LimitedScriptGuiAddButton=false

  13.     # 渲染任务导航点图标的偏移量
  14.     # 第一个是X坐标偏移 第二个是Y坐标偏移
  15.     I:OffestQuestWaypoint <
  16.         8
  17.         8
  18.      >

  20.     # 任务导航点使用JourneyMap
  21.     B:QuestWaypointJMapMode=false

  23.     # 任务导航点使用VoxelMap
  24.     B:QuestWaypointVMapMode=true

  26.     # 会为无材质的NPC使用透明材质,这防止了此错误信息在客户端日志里刷屏
  27.     # 这通常服务强迫症和开发者
  28.     B:SafeRenderNoTexNPC=false
  29. }


  32. general {
  33.     # 在玩家受到来源npc的伤害自动将其类型转为NPCDamageSource
  34.     # 这通常是方便开发者用的
  35.     B:AutoUseNPCDamageSource=false

  37.     # 更精准的物品搜集任务判定
  38.     # 优化物品搜集任务的不精准判断
  39.     B:EffectiveCollectItemQuest=true

  41.     # 启动任务导航点功能
  42.     # 这允许你在玩家进行任务时在地图上标点为玩家导航
  43.     # 这需要在客户端安装CustomNPCsFix和Xaeros Minimap(或JourneyMap)
  44.     # 推荐开启小地图选项"以上距离路近点显示名称"
  45.     B:EnabledQuestWaypoint=true

  47.     # 更快的JSON(反)序列化 虽然不是特别快 但是比NPC自带的快的多
  48.     # JSON(反)序列化常被npc用于 保存玩家数据 任务数据 对话数据等
  49.     # NPC的IO和网络通讯使用同一线程
  50.     # 因此,如果JSON(反)序列化速度慢的话 可能会导致像交互延迟等现象
  51.     B:FastJsonDeserialize=false

  53.     # 修复%信息崩溃bug
  54.     # 这通常用于修复:
  55.     # 1.NPC台词里使用%导致错误
  56.     # 2.NPC脚本里NPC的say方法和玩家的message发送%导致错误
  57.     B:NoMsgPercentSymbolBug=false

  59.     # 通过世界名判断任务导航点
  60.     # 如果你使用多世界插件 最好启用这个选项
  61.     B:QuestWaypointFromWorldName=false

  63.     # 传送师使用世界名判断世界而不是ID
  64.     # 注:
  65.     # 1.启动此项后 会在设定传送点时保存其世界名
  66.     # 2.启动此项后 新建一个传送点 就会自动为先前没有WorldName的传送点补全WorldName(不一定正确)
  67.     # 这通常用于修复MV插件与NPC传送师的数据不同步等异常
  68.     B:TPLocUseWorldName=false

  70.     # 传送师使用BukkitAPI进行传送
  71.     # 这通常用于修复某些插件显示的世界和玩家所在的世界不同
  72.     # 需TPLocUseWorldName
  73.     B:TPUseBukkitAPI=false

  75.     # 修复同伴的进食BUG
  76.     B:WIPNoFoodBUG=false
  77. }
