介绍
还在老套地使用手写方式修改配置?
还在仅仅限于用默认的几个老到掉牙的等级和权限?

使用 WGuild, 您可以通过 GUI 方便地修改任何东西.
管理员可以完全自定义公会的等级组与权限组.




                                   目前功能特性:

                                   √ 全GUI
                                   √ 全自定义权限组
                                   √ 全自定义等级组
                                   √ 公会贡献
                                   √ 称号显示
                                   √ 公会签到
                                  (仿EC特效/不卡顿)
                                   √ 公会成员列表
                                   √ 公会聊天频道 (默认使用英文感叹号 ! ,
                                   您可以在 plugins/EasyAPI/integrateConfig.yml中修改
                                   WGuild.guildChatStarWith: '!' )
                                   √ 聊天公会称号
                                   √ NameTag显示
                                   √ 基础组件
                                   (踢出, 邀请, 解散, 同意 etc.)





GUI
您可以通过/wguild gui (简写/wgd g) 以打开GUI.













                                                     全自定义权限&等级权限

                                                     一个权限组可以有500个权限
                                                     您可以设置:
                                                     - 权限的显示名 支持 颜色符(&§)
                                                     - 是否为会长
                                                     - 可以踢人
                                                     - 可以 邀请
                                                    - 可以允许邀请
                                                     - 可以改配置
                                                     - 可以解散
                                                     - 可以管理资金
                                                     - 是否为默认权限
                                                     等级
                                                     一个等级组可以有500个等级
                                                     您可以设置:
                                                     - 最大成员数
                                                     - 允许有编辑权限的成员
                                                     自定义权限组
                                                     - 可以改公会名
                                                     - 可以使用颜色符
                                                     - 公开性
                                                     - 公会内PVP
                                                     - 升级所需价格

                        %wguild_player% - 玩家所在公会
