最近开创造服务器,发现玩家玩鞘翅.
1.11用户玩鞘翅飞到几万米高空,卡服.
于是去其他服务器测试了一下,基本没有几个服务器有使用限制飞行高度的.....
mcbbs也貌似没有.
于是自己写了一个简单的.
也想提醒一下腐竹飞行高度的问题.
插件很简单,就是飞到Y:350以上的时候,自动传送到Y:345.

应该是支持全版本的

权限:无
指令:无

关于mod导致的有没有用问题.
插件检测原理是玩家位置,所以当玩家传送到350以上,只要移动一下.
就会传送到350.所以应该支持mod服务器

源码,PS:用取消事件会卡住.
  1. package bop1;

  3. import org.bukkit.Bukkit;
  4. import org.bukkit.ChatColor;
  5. import org.bukkit.event.EventHandler;
  6. import org.bukkit.event.Listener;
  7. import org.bukkit.event.player.PlayerMoveEvent;
  8. import org.bukkit.plugin.java.JavaPlugin;

  10. public class q1243475331 extends JavaPlugin implements Listener

  12. {
  13.         public void onEnable()
  14.         {
  15.                 Bukkit.getPluginManager().registerEvents(this, this);
  16.         }
  17.         @EventHandler
  18.         public void PlayerMove(PlayerMoveEvent evt){
  19.          if( evt.getTo().getY() > 350 )
  20.          {
  21.                  evt.getPlayer().sendMessage "你超过飞行高度. 限制高度[350]");
  22.                  evt.getTo().setY(345);
  23.          }
  24.                  
  25.         }

  27. }
