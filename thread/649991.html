【介绍】

这个MOD能播放URL的音乐，支持网页MP3 URL链接。

【合成】


空白唱片

可以在刻录机中纪录音乐，然后由播放器播放

多重唱片
这个东西由多个唱片合成，可以播放多个音乐


刻录机
用于刻录空光盘


播放器
用于播放刻录后的唱片

频率水晶
这个东西原文是说，可以调节广播电台，和无线电配合使用，不过天朝好像用不了这玩应


音频调节器
用于调节频率水晶的频道

无线电
用于播放频率水晶

音响



闪光灯




镭射


音箱线

用于连接各个原件



音箱线剪刀
用于剪掉音响线

Version 1.2.0
Update credit: Borlea

  • Increase lazer length by right clicking, decrease by shift right clicking.
  • Fixed repeating records losing their volume level
  • Added Shuffling

Version 1.1.9
Hotfix for a few minor bugs, and a major bug.

  • Fixed desync between wire connections
  • Fixed server allowing connections over EXTREME distances
  • Moved the location of dependencies and the default library
  • Added a few more allowed encoding types for MP3s

Version 1.1.8

  • Fix for audio files playing incorrectly

Version 1.1.6

  • Added update checker
  • Added radios
  • Added frequency tuner
  • Added lazers
  • Added experimental lazer clusters
  • Added local library
  • (Hopefully) Fixed the wire bug
  • Added disclaimer xD
  • Changed the options screen
  • Added multirecords
  • Added repeatability to records

(Expect the high possibility of bugs. I tried to get this pushed out quickly, so it didn't undergo as rigorous testing as I usually do.)

Version 1.1.2

  • - If snooper is enabled, it'll send me error reports so that I can fix issues quicker

Version 1.1.0

  • Updated to 1.7.10
  • Added config dialog by pressing "N"
  • Added ability to play songs while downloading (Disabled by default)
  • Added library to the etcher
  • Added song size to records
  • Added support for more types of mp3 files
  • Added initial placement tips to blocks
  • Added dev mode (You can toggle in the config file)
  • Multiple bug fixes
  • (I would have had it out earlier, but I was adding the radio. Needless to say, I thought you guys would be getting restless, so I commented out those additions for now.)

Version 1.0.3.23

  • Made the URL validation code support more url types and made it more secure.

Version 1.0.2.22

  • Added ability to toggle auto-download of songs when playing in multiplayer
  • Made url-validation better
