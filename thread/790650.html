After more than six years it's time to say goodbye! I've had a lot fun integrating my own features into Minecraft and creating a mod that reached so many more people than I have ever anticipated - but now I'm going to move on. Thank you for an amazing time.
Feel free to modify, update and add new features (I heard you like free capes :P) to the mod.

六年多了，是时候说再见了！我将我想要的功能加进了 Minecraft 中，编写了一个使用人数超乎预料的 mod  - 但现在我要继续前进了。感谢这美好的时光。
你可以随意修改，更新或加入新功能到 mod（我听说你们喜欢免费披风：P）。

（作者要离开不干了啊）






一个Mod，提升您单机和联机的游戏体验。




简洁&现代

我一直致力于创造一个极度简洁而且现代的设计，它以一种令人惊叹的方式在简单的GUI中显示大量信息。


灵活

5zig Mod的灵活性已经接近极致。您可以调整数据显示的位置，几乎所有功能都是可以在Mod里调整的。


创新

实现了大量的全新功能和理念，使它成为一个独一无二的Mod。请参阅：自定义服务器API，坐标剪贴板以及在功能列表中的更多功能。

社交

添加好友并与之联系。5zig Mod允许您通过客户端里一个简单的聊天GUI与您的朋友实时交流。




功能特性（里面有一些官方的图）
https://www.5zig.net/features
- 舒适而简洁的玩家信息

  可以显示显示：

  • 一种更加精确的帧数显示，每秒更新50次。
  • 可选的坐标精度
  • 您的方向
  • 您的药水效果
  • 您的盔甲状态
  • 您所在的生物群系
  • 您到服务器的ping值
  • 您所在的服务器的玩家人数
  • 您的当前时间
  • 实体计数
- 可以调整Mod的颜色和样式

- 支持一些小游戏服务器，当你在服务器中时能显示各种数据。
- 可扩展性从50%到150%

- 玩家信息显示的位置是可以调整的，可以在Mod选项中调整服务器属性，护甲状态和药剂效果的显示

- 好友系统！
  • 加入了一个新的好友系统
  • 可以添加无限多的好友，和他们聊天、一起享受Minecraft
  • 可以在一个列表中查看所有的好友
  • 每个好友都有自己的主页，在那里您可以看到他们的当前信息——在线状态，正在玩的服务器，上一次在线时间和皮肤头像（由cravatar.eu提供的玩家头像）
  • 添加特别关心，他们会出现在列表的顶部，他们旁边会有个闪闪的黄色星星，您可以更快找到他们
  • 使用 Java NIO 来超快地发送消息
  • 聊天时只占用很少的网络资源
  • 可以发送离线消息，您的好友友将会在他们上线的时候看到您的消息
  • 为每一个对话设置通知行为
  • 消息状态！您可以查看您的信息是否已被发送到服务器或已被您的好友查看
  • 消息的时间会显示在旁边
  • 消息的日期会显示在聊天窗口的中间
  • 聊天记录是离线保存的，即使没有连网，您依然可以查看它们
  • 您可以更改聊天窗口的背景，甚至把它设置为透明的
  • 如果Minecraft没有被聚焦，您会收到一个托盘通知
  • 您可以让它在收到消息时发出声音提示
      您还可以改变这些声音！只需要创建一个简单的资源包，包含这样的一个目录
  1. assets/the5zigmod/sounds/chat/
复制代码
     和里面的两个声音文件
  1. message_receive.ogg
复制代码
  1. message_send.ogg
复制代码
      或者说，您可以修改位于下面目录的声音文件
  1. .minecraft/libraries/eu/the5zig/The5zigMod/1.8.4_3.0/The5zigMod-1.8.4_3.0.jar/assets/the5zigmod/sounds/chat/
复制代码
    可以在这里找到一个示范的声音包（搬运的人的话：我是打不开这个链接）

  • 看见您的好友是否正在输入
  • 可自定义的隐私选项，您可以选择是否想要连网，是否想在网上显示您的好友，是否想显示您的服务器，是否想让其他玩家看到您读了他们的消息，是否想要收到朋友的请求，是否想要接收聊天和群组聊天通知，是否想看到您的朋友上线的通知。
  • 可以在聊天窗口中点击超链接
  • 用方向键来选择上一次发送的信息（就和Minecraft中一样）
  • 在线状态
       选择“在线”，“离开“和”离线“
       您将在十分钟后自动被设置为“离开”，您还可以修改这一时间
  • 若果您捐助过我，您的名字将会有一个Green Prefix（绿色前缀）（如果您捐助获得了默认披风），或者有一个Gold Prefix（金色前缀）（如果你捐助获得了自定义披风）。您还可以通过“&”字符和Minecraft颜色代码在聊天中使用彩色文字。您甚至可以挤进一个满人的服务器
- 群组聊天！
  • 创建不限量多的的每个最多50人的群组
  • 可以同时与多个好友聊天
  • 群组聊天记录会离线保存
  • 如果您不在线时有群组消息，您会在上线的时候收到它们
  • 作为创建者，您可以在创建群组之后管理您的群组和群组成员
       增加新的成员
       将某个成员移出群组
       重命名您的群组
       转让群组的所有权
       将成员设置为管理员
       解散您的群组
  • 给予成员管理员权限，以允许他们管理群组成员和编辑群名称
  • 两种现实坐标的方式：横着或竖着排列
  • 一个可以保存坐标的Gui，这样你就不用再记住它们了。（搬运的人的话：输入一个坐标，在屏幕上就会有个箭头，指向坐标点）
  • 提供不同的语言版本（有中文）， 语言文件位于
  1. .minecraft/the5zigmod/lang
复制代码
  • 这个Mod几乎所有东西都是可以开关的

      可以随意调整这些东西：
  • -显示您的坐标
  • -显示您的FPS
  • -显示您的方向
  • -显示您的ping
  • -显示连接到的服务器的IP地址
  • -显示有多少玩家连接到你正在游玩的服务器上
  • -显示您的药水效果
  • -显示您的装甲状态
  • -Show a large invincibility time
  • -显示连杀
  • -显示服务器属性
  • -显示所有标签（除了左上角的标签）
  • -显示你的生物群系
  • -显示到正在偶玩的服务器的ping值
  • -显示当前时间
  • -还有很多很多
- 消息过滤器
  • 将消息添加到过滤器，然后就可以掉忽略它们
  • 使用通配符如“*”或“?”轻松匹配消息。你可以用" \ "来转义字符
  • Messages that eg. Spam your chat on specific servers can be easily ignored
  • Messages can be also server specific ignored.
  • 在一个华丽丽的界面管理你的消息
  • 教程：https://youtu.be/g5OOfjKMTIA
-  用于Bukkit/Spigot的可定制的服务器API
  • 全新的客户端和服务端的通信方式
  • 用“键-值 系统 Key-Value-System”来设置记分项
  • Change the Display Name of the Stat
  • You can create up to 10 different stats
  • Introducing IMAGE SENDING via a Server Plugin!
  • Send Multi-line Titles which are automatically splitted onto a new line and with the “\n” char
  • 更多信息，源代码，javadocs和下载:https://github.com/5zig/5zig-mod -2.0/
