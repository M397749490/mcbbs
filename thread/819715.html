介绍一下 · Introduce to you (又臭又长...)
服务器除了一些基础插件外其余皆是腐竹一人编写.所以在这里你会看见一些与市面上不一样的内容
\
·平衡方面 / 在这里不充钱照样可以成为大佬,只不过需要时间罢了.氪金可获得的东西平民基本也能获得
除此之外,服务器各种任务奖励,等级奖励,签到奖励,怪物血量攻击力经验等都是经过计算,不多不少刚刚好
\
·服务器核心玩法 / 精工强化（相似于淬炼）这个是玩家变强的核心,强化各个等级成功几率也是经过
精心计算多次测量,以及各种精工强化宝石的获取也是如此.精工成功升星,失败则随机掉1-2星,既保证了该玩法
的可玩性，也保证了玩家不会发展太快而感到迷茫.
\
·说到迷茫 /  服务器完美的任务体系不会让你感到迷茫，原创的剧情。任务奖励不随便应付。在打怪升级
中不忘生存。主线任务外还有支线任务，每日任务。
\
·自写怪物系统 /  服务器内资源世界中刷新的怪物不再是原版那样弱小,他们将获得强化，击败后
可获得经验，银两，宝石碎片等。怪物一共分100级，距离出生点越远等级就越高。所以挖矿的时候小心你的
背后喔~当然，你们需要量力而行,新手最好在出生点附近挖矿采取资源。资源世界每周更新一次。当然，你也可以
当个狩猎者。寻找在你击杀能力范围内的等级怪物击杀他们，获取经验，升级，成为服务器霸主！又或是与好友
一起组队砍怪物，或是...逃跑..
\
·完美的经济体系 / 服务器内有4大经济货币: 银两,绑银,黄金,绑金
银两: 可以购买一些绑银买不到的,且可转换为绑银——获得途径:击杀怪物,每日任务,活动奖励
绑银: 最基础的货币,无法转为银两——获得途径: 杂货商店出售生存物品,签到,各种活动
黄金: 可用于购买珍贵的物品 —— 获得途径: 氪金,活动
绑金: 可购买部分黄金可购买的物品 —— 获得途径: 氪金赠送,活动,任务奖励等.
还有个小经济货币: 武勋
击杀敌方宗族玩家可获得,被击杀的玩家在宗族的地位越高获得的越多.武勋可购买物品
\
·宗族体系 / 服务器内有2大宗族，玩家到5级时候可加入一个宗族
宗族内有官职,宗族地位越高可使用的官职权限越大，宗主只有本宗族的任意帮派帮主才可参与竞选
后续将开发国战系统。


\
更多的等日后开服体验吧.怕打太多你们看不下去了.
