Rs系列插件，原RVIP插件。现在，RVIP各个功能已经被我独立出来了
—————————————————————————————————————————
它被划分为五个插件，留下了足够扩展空间和函数
ps.如果你想配套RVIP，并使用它的函数，你可以在插件包中的RsFunction函数使用文档中查阅

RsFunction 前置插件
RVIP RVIP主体
RsProtect 保护功能
RsPrefix 称号功能
RsPoint 点卷功能

这个五个插件中，RsFunction为全部插件的前置。
RVIP为插件主体，主要负责VIP的添加，删除，储存等。
RsProtect负责保护，比如创造放置的方块，防止op刷op，op刷创造等。
RsPrefix负责vip称号部分，比如vip1显示什么什么称号，都可以改，（ps.RsPrefix目前不提供
配置文件，你可以在RVIP的config配置文件更改)
RsPoint负责点卷功能，RVIP里的/vip buy如果没有它则无法使用

—————————————————————————————————————————
各个插件的指
—————————————————————————————————————————
RVIP:
/vip add 玩家 等级 天数              添加一个vip
/vip remove 玩家                        移除一个vip
/vip buy 天数 等级                      玩家购买vip
/vip gm 1/0                                vip玩家变为创造
/vip tp 玩家名字                         vip玩家tp一个玩家
/vip tphere 玩家名字                  vip玩家tphere一个玩家

RsProtect:
/rop add 玩家名字                      添加一个真op，（ps.RsProtecet中限制了op使用一些指令，只有为op添加这个真op才能正常使用
/rop remove                               移除一个真op
/rmod add                                  添加一个可以变为创造的玩家(ps.由于时间问题，我只写了vip创造玩家和这个可以变，下个版本添加op
/rmod remove                            移除一个
/rban add                                   禁止一个人进入服务器，这个为全方面的
/rban remove                             允许一个被禁止的人进入服务器

RsPrefix:
/prefix add 玩家 称号　　　　　为玩家添加一个称号
/prefix list 玩家                            查看玩家拥有的称号和称号id
/prefix remove 玩家 称号id         删除玩家的称号
普通玩家可以使用
/prefix 称号id                              来选择称号
/prefix                                         来查看称号id

RsPoint:
/point add 玩家 点卷                   为玩家添加点卷
/point remove 玩家点卷              为玩家移除点卷
/point 玩家                                  查看玩家的点卷
/point set 玩家点卷                      设置玩家的点卷
扩展：
/point point 数量                         兑换帝国之战的积分,兑换比例可在配置文件更改
/point money                              兑换EAPI的货币，同上
普通玩家可以使用
/point                                          来查看自己的点卷

RsFunction:
其中的config.yml配置文件可以修改其余四款插件的指令前缀

—————————————————————————————————————————
最后，RVIP花了我几个月的时间，从1.0到3.0，都是免费发布
这里我会说，这里的五款插件，永久免费更新，并会不断的推出附属插件
