大家都知道start 的bat只需要一行就可以使用
  1. java 内存 -jar 核心名.jar

虽然简单，可是这样很没有逼格！所以我们加个颜色吧！
color 09 ，0是背景颜色，9是字体颜色，
  1. color 09
  2. java 内存 -jar 核心名.jar
复制代码



崩服不显示报错，直接闪掉，而且是bc群组的话，子服很容易混淆，所以我们要加个标题并加一行pause！
  1. @echo OFF
  2. title 登陆服
  3. color 09
  4. java -Xms4g -Xmx8g -jar spigot-1.8.8-R0.1-SNAPSHOT.jar
  5. pause

但是点一下就开服,感觉还是不够逼格怎么办!所以我们要加个密码锁啥的
  1. @ECHO OFF
  2. title 登陆服
  3. color 09
  4. :s
  5. echo *****************************************************************
  6. @echo.                        请问我帅不帅？         
  7. @echo.*****************************************************************
  8. set /p des=
  9. if "%des%"=="帅" goto a
  10. echo *****************************************************************
  11. @echo.                回答错误，再来一次，提示回答[帅]
  12. @echo.*****************************************************************
  13. goto s
  14. :a
  15. echo *****************************************************************
  16. @echo.                   诚实的孩子，服务器正在开启中
  17. @echo.*****************************************************************
  18. java -Xms4g -Xmx8g -jar spigot-1.8.8-R0.1-SNAPSHOT.jar
  19. paus

什么？服务器蹦了，懒的重启，那我们让他自动重启吧
  1. @ECHO OFF
  2. title 登陆服
  3. color 09
  4. :s
  5. echo *****************************************************************
  6. @echo.                         请问我帅不帅？         
  7. @echo.*****************************************************************
  8. set /p des=
  9. if "%des%"=="帅" goto a
  10. echo *****************************************************************
  11. @echo.                回答错误，再来一次，提示回答[帅]
  12. @echo.*****************************************************************
  13. goto s
  14. :a
  15. echo *****************************************************************
  16. @echo.                   诚实的孩子，服务器正在开启中
  17. @echo.*****************************************************************
  18. java -Xms4g -Xmx8g -jar spigot-1.8.8-R0.1-SNAPSHOT.jar
  19. goto b
  20. :b
  21. echo *****************************************************************
  22. @echo.                         服务器重启中
  23. @echo.*****************************************************************
  24. java -Xms4g -Xmx8g -jar spigot-1.8.8-R0.1-SNAPSHOT.jar
  25. pause
