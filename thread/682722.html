功能
创建一个区域 玩家破坏方块或放置后
在一定时间后恢复
  • 多区域不同设置
  • 允许某个已设置区域禁止放置方块
  • 禁止水桶和岩浆桶在已设置区域内使用
  • 支持水和岩浆的恢复
  • 支持放置方块的恢复
  • 支持破坏方块的恢复
  • 优先删除放置方块后再恢复破坏方块
  • 允许设置区域重载时禁止进入
  • 重载时服务器关闭数据不会丢失
  • 世界删除时矿区数据会自动删除
  • 区域内方块被更改才开始计时刷新
  • 异步恢复方块 不会影响服务器运行
  • 已知BUG： 有方向的方块恢复时会出错 梯子，火把等



本插件需要 WorldGuard 才可运行

配置文件
region:
- 'test@world@展示名@true@30 seconds'
# 第一个变量为 区域名
# 第二个变量为 区域所在世界名
# 第三个变量为 区域展示给玩家的名字
# 第四个变量为 是否允许玩家在区域内放置方块 true 允许 false 不允许
# 第五个变量为 该区域的刷新时间 seconds 秒 hour 时 days 天
message:
  prefix: '&c[&4&lMineRegion&c] &r'
  nobreak: '&c你不能在这里放置方块'
  nowater: '&c你不能在这里放置水或岩浆'
  title: '&a区域 {region} 还有 {time} 秒后刷新'
  subtitle: '&7区域 {region} 还有 {time} 秒后刷新'
# 全屏提示配置 {region} 为区域展示名 {time} 为下方倒计时数字
  timeerror: '&c刷新时间错误 区域无法使用 请联系在线管理员'
  updateerror: '&c当前区域无法刷新'
  worldnull: '&c目标世界不存在 已删除所有有关变量'
  update_start: '&7开始刷新'
  update_success: '&a刷新成功'
  updatekick: '&c该区域正在重载 无法进入'
config:
  count: 10
# 刷新倒计时 单位秒
  updatekick: true
# 区域刷新时是否允许进入

设置帮助
目标
在 world 世界创建 ore 区域 刷新时间 30 分钟
名为 一级矿区 且不允许放置方块

第一步
使用 WorldGuard 插件在 world 世界 创建一个名为 ore 的区域

第二步
在配置文件的 region 下写入
- 'ore@world@一级矿区@false@30 minutes'

第三步
输入指令 /mrg reload 重载即可生效

预计更新
设置指定 Lore 才可破坏指定区域

指令帮助
  • item save [Name]  --- 保存手中物品
  • item edit [Name] --- 覆盖同名物品
  • item give [Name] [P] [A] --- 给予玩家 P 数量 A 的物品 不填给自己
  • item drop [Name] [P] [A] --- 同上，把物品丢在玩家 P 脚下
  • item remove [Name] --- 删除物品
  • item list <Page> --- 列出物品 不填默认第一页 每页 25 个物品
  • item loaditem <Value>@<File> --- 载入物品，下面讲


API 使用帮助
前提你懂 Skript 基本使用规则
itemAPI_GiveItem(player, string, int)

itemAPI_DropItem(player, string, int)

功能
将已储存的物品丢到玩家或生物脚下

触发帮助
上面也说了 插件总共 8 个触发器

click - 点击 (左右键)
这个触发器只能设置主手生效 不能设置背包位置

right-click - 右键点击
同上

left-click - 左键点击
同上

sneak-toggle - 潜行触发
也就是当玩家按下 shift 的时候触发一次

damage-att - 攻击触发
当玩家攻击任何实体的时候触发
以后可能会更新实体类型

damage-vic - 受伤触发
当玩家受到任何伤害时触发
以后可能更新受伤类型和攻击者类型

break - 破坏触发
当玩家挖掘方块的时候触发
可设定破坏方块类型 需要用@隔开每个方块 all 代表全部
break{s=tool;i=stone@dirt@grass}

chat - 聊天触发
当玩家聊天的时候触发


背包格子
部分触发器可用 s=[] 变量来设置物品
在背包内的某个位置触发

  • [0-8] 快捷栏从左到右
  • [9-35] 背包左上角开始
  • [40] 副手栏 (1.9+)
  • [36-39] 脚到头
  • [tool] 手持物品


指令变量
{p} - 触发玩家, {e} - 返回值
