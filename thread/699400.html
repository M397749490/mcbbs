插件介绍
——————————————————————————————————————————————————

AuthMeBridge 是一个在你的Bukkit服务器与BungeeCord间搭建Authme登录插件的桥梁
简单来说，该插件在你的Bukkit服务器检测登录信息并发送给BC的 AuthMeBridge 插件
如果BC未收到该玩家登录成功的消息，该玩家将无法进行聊天或使用命令等任何服务器操作
如果有多个登录服，您可以启用自动注册选项，允许您在服务器之间切换而不必再进行登录


举个例子，玩家A进入服务器，他还没有登录就想通过/server进入其他子服
那么该插件就会阻止他的操作并要求他进行登录

该插件可以有效防止玩家使用OP号未登录时就使用/server或/stp传送到其他子服
进而进行一系列破坏等熊孩子操作


配置文件详解
——————————————————————————————————————————————————

  1. # 在此填写你需要桥接的服务器
  2. serversList:
  3.   - lobby
  4. # 这个是允许玩家使用注册或者登陆命令
  5. commandsRequiresAuth: true
  6. #这个是允许玩家未登录可以执行的命令
  7. commandsWhitelist:
  8.   - /glist
  9. # 是否允许玩家未登录聊天
  10. chatRequiresAuth: true
  11. # 踢出没有登录就行执行命令的玩家
  12. # 请不要设置为true，这样会使服务器增加负担
  13. serverSwitchRequiresAuth: false
复制代码



如何使用？
——————————————————————————————————————————————————

下载该插件后，会发现他是一个压缩包
打开它，里面有两个文件夹，分别是BungeeCord与Bukkit
将BungeeCord文件夹内的jar插件装入你的BC的plugins文件夹下
将Bukkit文件夹内的Authme文件夹内的jar插件装入你的登录服的plugins文件夹下
然后重载它们，即可正常工作
