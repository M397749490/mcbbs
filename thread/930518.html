Craftbukkit 1.14.4
写插件的时候发现 用 block.breakNaturally(item) 破坏的矿物(煤矿啊啥的)不会掉落经验。尝试call BlockBreakEvent也不会掉落经验。

各位dalao，有没有办法可以解决这个问题啊。

ps: 目前想得到的办法就是自己设置掉落的经验，除了这个方法还有别的解决方案嘛。

本帖最后由 jebme 于 2019-12-8 18:37 编辑

1. Event这个东西是给插件用的，服务端内部并不监听事件，所以你call event没效果
2. 掉落经验是的判断是在PlayerInteractManager里的breakBlock方法内，先计算出掉落的经验，然后掉落出来:(1. 计算bonusLevel, 这个bonusLevel就是手中物品的"LOOTING"附魔等级，没有则为0)


(2. 计算经验， BlockOre类重写了getExpDrop方法，父类是直接返回0的)

注意: 不同的方块有不同的实现类，也就是说不同的方块，他的getExpDrop方法可能不同，因此，如果你想准确知道每个方块应该掉多少经验，要么直接调用NMS代码，要么就自己慢慢把所有方块实现类翻一遍，抄到插件代码中...
(3. 调用 Block#dropExperience() 掉落经验)





* 注意: 以上代码均来自NMS，并非Bukkit API

还有，这是1.8的NMS代码，1.14的代码实现请自行反编译，看了下，1.14的掉落经验实现略有改动，具体自行查看，大体一致

建议:
给出两个解决方法的选择：
1. 简单点直接模拟他的计算方法，生成经验实体
2. 要么调用NMS，调用又分为直接调用或者反射，这个就略微麻烦点了
