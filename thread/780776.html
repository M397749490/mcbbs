EnhancedSnowman增强雪人♂
你是不是曾经有过这样的经历，自己辛辛苦苦造了一堆雪人结果一下雨雪人全部over,然后好不容易造了个雨棚安置雪人结果那雪人一看到下雨就到处乱跑再次over.然后你想聪明了造了个栏杆结果被骷髅狠狠射死.
这时候你就会发现雪人真的没有卵用丢个雪球打不死击退又少还伤其友军.
但这个MOD不同，它能够增强♂雪人，使它更具有威胁♂力!
虽然它还是会到处乱跑击退又少还伤友军然后下雨会over,但这个MOD为雪人增加缓慢效果攻击以及攻击带伤害!

这个MOD能为我们带来什么?
如上面所说，这个MOD为雪人增加了一种攻击效果:snow[缓慢]以及附带伤害!
但它丢出一定的雪球的时候，会死亡。这是MOD的特性效果.这一切均可以由配置决定.
MOD细节
当你用这个MOD精心设计了一个大规模的雪球袭击，你会发现一个惊奇的事情"天啦我的雪人死的真快!""还是别玩这MOD了"NO!收回你的话，这个MOD不仅仅是这样这个MOD在当雪人发出的雪球打死怪物的时候会将怪物替换成雪人[这啥鬼逻辑?]这种特性可以在MOD配置上设置.另外，玩家的雪球默认是没有伤害的但这种特性还是可以在配置上设置.默认伤害为0.25心.减速2s
MOD配置

实际上我是挺不想写的...
可以在游戏内 mod 列表 GUI (MC1.11 或更高) 中完成

\.minecraft\config\enhanced_snowman.cfg为配置文件，用记事本打开
  1. <strong># Configuration file

  3. general {
  4.    
  5. # 当雪人的雪球杀死了生物时该生物是否转变为雪人
  6.    
  7. B:convert=false

  9.     # 只对怪物造成伤害
  10.    
  11. B:onlyHostile=true

  13.    
  14. # 玩家的雪球是否能够造成伤害
  15.    
  16. B:playersDealDamage=false

  18.    
  19. # 雪人的雪球是否会有缓慢效果
  20.    
  21. B:slowness=true

  23.     # 当达到什么情况后雪人会死亡
  24. snowballDamage为雪人伤害
  25.     # Min: 0.0
  26.     #
  27. Max: 100.0
  28.     D:snowballDamage=0.5
  29. }</strong>
