1、2两点，Essentials或者WorldGuard的黑名单功能都可以。

3. 这是一个汉化需求。plugins\Essentials.jar\messages_en.properties这个可以给予汉化，然后 plugins\Essentials\config.yml里面找到以下部分
  1. # Set the locale for all messages
  2. # If you don't set this, the default locale of the server will be used.
  3. # For example, to set language to English, set locale to en, to use the file "messages_en.properties"
  4. # Don't forget to remove the # in front of the line
  5. # For more information, visit http://wiki.ess3.net/wiki/Locale
  6. #locale: en
复制代码
删除locale: en前面的#

4. 这需要重新编译mod哟

5. 打开暮光森林的配置文件，找到
  1. ####################
  2. # dimension
  3. ####################

  5. dimension {
  6.     # What ID number to assign to the Twilight Forest dimension.  Change if you are having conflicts with another mod.
  7.     I:dimensionID=7
  8. }
复制代码
这是未手动更改的默认情况，dimensionID=7
所以去找.minecraft\saves\存档名\DIM7

6. 需要多世界插件的，问答区有很多多世界相关问题，搜索吧骚年
