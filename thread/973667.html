我这里给个1.12.2的教程吧(并不是很明白楼主看到的"别人"是怎么做到的，如果有链接可以私我一下我研究研究。)
首先生成一个隐形村民
  1. <span style="background-color: silver;">summon minecraft:villager ~ ~ ~ {NoAI:1,Invulnerable:1,Silent:1b,Tags:["rightcv"],Offers:{Recipes:[]},ActiveEffects:[{Id:14 ,Amplifier:0,Duration:1999999,ShowParticles:0b}],DeathLootTable:"empty"}</span>
复制代码
创建计分板检测右键
  1. <font color="#000000" style="background-color: silver;">scoreboard objectives add rightclvil stat.talkedToVillager 右键侦测(村民版)
  2. scoreboard players set @p rightclvil 0</font>
复制代码
高频tp村民至玩家
  1. <div><font style="background-color: silver;" color="#000000">tp @e[tag=rightcv] @p</font></div><div><font color="#000000" style="background-color: silver;">scoreboard players tag @p remove withdiamondsword
  2. <font style="">scoreboard players tag @a add withdiamondsword {SelectedItem:{tag:{Tags:["diamond_sword"]}}}</font>
  3. <font style="">execute @p[score_rightclvil_min=1] ~ ~ ~ scoreboard players set @p[tag=!withdiamondsword] rightclvil 0</font></font></div>
复制代码
检测当玩家右键后给予效果
  1. <div><span style="background-color: silver;">高频testfor <span id="kM0.7680842569711985">@a[score_rightclivl_min=1]</span></span></div><div><span style="background-color: silver;">后接比较器 effort <span id="kM0.14622027023082684">@a[score_rightclivl_min=1] xx xx</span></span></div><div><span style="background-color: silver;">再接一个连锁 scoreboard players set <span id="kM0.5766780611322344">@a[score_rightclivl_min=1] rightclivl 0</span></span></div>
复制代码
