关于java编程中运算符之：算数运算符
  1. +   求和
  2. -   相减
  3. *   乘积
  4. /   商
  5. %   求余数【取模】

  7. ++  自加1
  8. --  自减1
复制代码
注意：
一个表达式当中有多个运算符，运算符有优先级，不确定的加小括号，优先级得到提升
没有必要去专门记忆运算符的优先级。

例题：
  1. int i = 10;
  2. int j = 3;

  4. System.out.println( i + j ); //13
  5. System.out.println( i - j ); //7
  6. System.out.println( i * j ); //30
  7. System.out.println( i / j ); //3
  8. System.out.println( i % j ); //1
复制代码
  1. //以下为++为例，--运算符自学！
  2. //关于++运算符【自加1】
  3. int k = 10;

  5. //++运算符可以出现在变量后面【单目运算符】
  6. k ++;

  8. System.out.println(k); //11

  10. int y = 10;
  11. //++运算符可以出现在变量前面【单目运算符】
  12. ++ y;
  13. System.out.println(y); //11

  15. //--运算符
  16. int z = 9;
  17. z --;
  18. System.out.println(z);
复制代码
以上小结：
++运算符可以出现在变量前，也可以出现在变量后，无论是变量还是变量后
只要++运算结束，该变量中的值一定自加1
  1. //++ 出现在变量后
  2. //规则：先做赋值运算，再对变量中保存的值进行自加1.
  3. int a = 100;
  4. int b = a ++;
  5. System.out.println(a); //101
  6. System.out.println(b); //100

  8. //++ 出现在变量前
  9. //规则：进行自加1运算，然后再进行赋值操作。
  10. int m = 20;
  11. int n = ++ m;
  12. System.out.println(m); //21
  13. System.out.println(n); //21
复制代码
  1. int xx = 500;
  2. System.out.println(xx);

  4. int e = 100;
  5. System.out.println(e ++); //100
  6. System.out.println(e); //101

  8. int s = 100;
  9. System.out.println(++ s); //101
  10. System.out.println(s); //101
