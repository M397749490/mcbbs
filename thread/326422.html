Hey everyone!
各位大家好！

I’ve been getting a lot of questions about MINECON lately, because before this time last year everyone knew the date and location and ticket info for MINECON 2013. While we don’t have a set date for the next MINECON just yet, I wanted to let everyone know that it won’t be until some time in 2015. I’m shooting to have it in the spring in London!
我收到了很多关于未来举办Minecon的一些提问，因为去年在这段时间，大家都会知道Minecon 2013的日期、地点和门票资讯。虽然我们没有为下一届的Minecon定下举办日期，我想让大家知道，直到2015为止，我们都不会举办新一届的Minecon。我打算新一届在春天的伦敦举行！

While we’d love to do MINECON every year and it’s the only event we do as a company, we want to make sure we can give it the attention it needs, and that means that springtime next year will work best!
我们热衷于每年举办Minecon，毕竟这是我们公司唯一的活动。我们希望我们能给予这个活动足够的关注度，这也就代表，明年春天举办Minecon可能是最佳时机！

As soon as I have confirmed information it’ll be out there. We always announce as soon as we confirm with the venue and have a signed contract, but never before, because we want to make sure we can follow through with the event and we never want people to start planning to attend something that might not happen. So watch out for information in the coming months!一旦有关Minecon的具体信息全部确立下来，我就会立马通知你们。签署有关合同之后，我们将把具体信息在第一时间告诉大家；但是我们从来不会提前发布这些信息，因为我们想保证计划的万无一失，同时我们也不想让各位为一件并不确定的事情做提前计划。所以请各位在接下来的几个月内多多关注我们公布的最新消息！

Vu – @vubui
Vu – @vubui
