作者: 白灯    时间: 2018-7-29 02:16
先获取Entity判断是不是玩家 如果是 再强转成玩家
Player有一个getName()的方法可以获取玩家名字

相关代码:
@EventHandler
public void onEntityDamage(EntityDamageEvent e){
    if(e.getEntity() instanceof Player){
        Player p = (Player) e.getEntity();
        p.sendMessage("PlayerName: " + p.getName());
    }
}
