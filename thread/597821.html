你们都说错了，问题出在领地插件上，你用的是Residence4.1.4.4以上版本吧。
这个领地插件里面有一个领地的设置，配置文件位置：plugins\Residence\config.yml
  1.     Flow:
  2.       # Level from witch one to start lava and water flow blocking
  3.       # This dont have effect in residence area
  4.       Level: 63
  5.       # With this set to true, lava flow outside residence is blocked
  6.       NoLavaFlow: true
  7.       # With this set to true, water flow outside residence is blocked
  8.       NoWaterFlow: true
  9.       Worlds:
  10.       - world

作者: 406844919    时间: 2016-7-3 19:07
是不是安装了[限制流水]BanHighWater

是的话可以删了

或

安装插件并重启服务器后输入/sethigh [高度]来设置高空流水的限制高度，然后再重启服务器生效或者输入/reload 指令生效。




/banhw 查看插件帮助指南
/sethigh [高度] 设置高空流水的限制高度
例子：
    /sethigh 75
    意思是当坐标的y轴大于75的时候就会限制放水。
权限：
    BanHighWater.admin    查看指南和设置限制高度的权限。
    BanHighWater.bypass   突破这个插件限制可以随意放水
