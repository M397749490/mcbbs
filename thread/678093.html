大家好，本人今天为大家带来一个数据库对接的教程。

目前可防御：假人、恶意注册、加密模式更安全、数据不容易丢失。

服务器建议加一个域名，开启一个百度云加速，就可以防御CC和比较低级的DDoS

------------分割线------------

需要用到的东西：

1.MineCraft服务器一台并使用authme插件，站内的插件下载：点我

2.虚拟主机一台并带数据库（推荐大小500M-2G左右），不知道虚拟主机是什么的，点我

3.discuz论坛一枚，你不知道discuz论坛是啥？点我

PS.如果你还不知道上面的步骤是什么。那请看下面的视频教程或者联系我。

没有虚拟主机和数据库的也可以联系我（免费）

[qq]546247977[/qq]

------------分割线------------

步骤操作：


1.把discuz论坛的upload文件里面的源码上传到虚拟主机，然后安装，这里就不多介绍安装步骤

特别提醒：数据库安装步骤中的pre_前缀建议不要修改！

安装好论坛后先不要修改论坛内容，这些以后在修改！



2.打开FTP软件连接MineCraft服务器找到authme插件的文件夹（一般都是/plugins/authme）

3.进入authme配置文件夹，用Notepad++打开config.yml文件

定位到一下内容：

  1. DataSource:
  2. # 用于存储或检查玩家昵称
  3. mySQLColumnName: username
  4. # 数据库的资料表名称
  5. mySQLTablename: authme
  6. # 连接数据库的用户名
  7. mySQLUsername: authme
  8. # 可以设置的文件类型: file, sqlite, mysql
  9. backend: file
  10. # 用于存储玩家上一次登陆
  11. mySQLColumnLastLogin: lastlogin
  12. # 数据库名称, 使用转换器或者SQLITE数据库
  13. mySQLDatabase: authme
  14. # 数据库端口
  15. mySQLPort: '3306'
  16. # 用于存储玩家ip
  17. mySQLColumnIp: ip
  18. # 数据库地址
  19. mySQLHost: 127.0.0.1
  20. # 用于存储玩家密码
  21. mySQLColumnPassword: password
  22. # 数据库连接密码
  23. mySQLPassword: '12345'
  24. # 是否需要缓存所有查询？
  25. caching: true
  26. # 用于存储退出位置 - X
  27. mySQLlastlocX: x
  28. # 用于存储退出位置 - Y
  29. mySQLlastlocY: y
  30. # 用于存储退出位置 - Z
  31. mySQLlastlocZ: z
  32. # 用于存储退出位置 - World name
  33. mySQLlastlocWorld: world
  34. # 用于存储玩家邮箱
  35. mySQLColumnEmail: email
  36. # 用于存储ID
  37. mySQLColumnId: id
  38. # 用于存储一个玩家是否登陆
  39. mySQLColumnLogged: isLogged
复制代码
强烈建议使用X3.2，因为X3.3修改了太多东西！！！！
下载地址：http://www.comsenz.com/downloads/install/discuzx
修改mySQLTablename项为
pre_ucenter_members
（默认数据库表，安装dz时若有修改请自行处理）。
修改mySQLUsername项为MySQL的最高权限用户名，即拥有所有操作数据库的权限。
修改backend项为mysql。
修改mySQLDatabase项为数据库名称。
修改mySQLPort为数据库端口号，默认为3306，部分网站服务器有所不同。
修改mySQLColumnIp项为regip。（这是dz论坛默认项）
修改mySQLHost项为数据库地址，不带端口号。
修改mySQLPassword项为数据库最高权限用户的密码，与mySQLUsername项相对应。
修改mySQLColumnId项为uid。
接下来定位到以下位置：

  1. security:
  2. # 密码最小长度
  3. minPasswordLength: 4
  4. # 这是个非常重要的选项,
  5. # 每次玩家加入到服务器,
  6. # 如果他们注册, AuthMe 将会吧他移动到未登录组
  7. # 这可以防止所有主要利用注册的作弊
  8. # 所以，你可以在你的权限插件里设置一个这样的特殊的无权限权限组
  9. # 玩家正确登陆后会被移动到正常组
  10. # 注意，组名是区分大小写的
  11. # 如果大小写搞错，玩家会被移动到默认组
  12. # 例如: NotLogged
  13. unLoggedinGroup: unLoggedinGroup
  14. # 可以设置的值: MD5, SHA1, SHA256, WHIRLPOOL, XAUTH,
  15. MD5VB, PHPBB,
  16. # PLAINTEXT ( 非散列密码),
  17. # MYBB, IPB3, PHPFUSION, SMF, XENFORO, SALTED2MD5,
  18. JOOMLA, BCRYPT, WBB3, SHA512,
  19. # DOUBLEMD5, PBKDF2, WORDPRESS, ROYALAUTH,
  20. CUSTOM(只对开发者)
  21. passwordHash: SHA256
  22. # SALTED2MD5 MD5盐度(MD5(password)+salt)
  23. doubleMD5SaltLength: 8
  24. # 如果检测到密码返回为false, 是否需要检测所有其他密码
  25. # 来检测一个老的密码？Autheme将更新一个新的Hash密码！
  26. supportOldPasswordHash: false
  27. # 禁止使用的不安全的密码, 使用小写！
  28. #unsafePasswords:
  29. #- '123456'
  30. #- 'password'
  31. unsafePasswords: []
复制代码
将passwordHash项改为SALTED2MD5。（discuz论坛专用加密算法）
将doubleMD5SaltLength项改为6。
接下来找到以下内容：
  1. ExternalBoardOptions:
  2. # MySQL 加盐列 , needed for some forum/cms support
  3. mySQLColumnSalt: ''
  4. # MySQL 组的列, needed for some forum/cms support
  5. mySQLColumnGroup: ''
  6. # -1 表示禁用. 如果你想只有激活的玩家能进入你的服务器，在这里设置激活的组的玩家数，默认-1
  7. # needed for some forum/cms support
  8. nonActivedUserGroup: -1
  9. # 其他的 MySQL 用户名列 (区分大小写)
  10. mySQLOtherUsernameColumns: []
  11. # 要在 BCrypt 记录多少记录(如果你不知道它是做什么的不要改变它)
  12. bCryptLog2Round: 10
  13. # phpBB 安装过程中的自定义前缀
  14. phpbbTablePrefix: 'phpbb_'
  15. # phpBB 激活组id, 2 是 phpbb 的默认设置
  16. phpbbActivatedGroupId: 2
  17. # WordPress 安装过程中的自定义前缀
  18. wordpressTablePrefix: 'wp_'
复制代码
将mySQLColumSalt项改为salt。
保存文件，上传覆盖。
重启服务器，观察启动过程中是否报错，若没有报错说明配置正确。
完成操作

有了这项功能，你完全可以把AuthMe自带的注册功能关闭。限制玩家只能在论坛上进行注册，并且使用论坛的账号作为ID，论坛的密码用于登陆才能成功游玩。
