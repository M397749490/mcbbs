时间都是以ticks为单位。20ticks = 1秒

命令：
  1. /bm - 命令列表
  2. /bm info - 显示流血是否启用，最大粒子数量和活跃的世界
  3. /bm reload - 重载配置文件
  4. /bm toggle - 开/关流血
  5. /bm toggle-world [世界名称] - 启用/禁用指定世界的流血
  6. /bm set maxparticles [最大数量] - 设置粒子的最大数量
  7. /bm set attackpercentage [百分比] - 攻击粒子数量
  8. /bm set fallpercentage [百分比]] - 掉落伤害的粒子数量
  9. /bm set deathpercentage [百分比] - 死亡粒子百分比
  10. /bm set projectilepercentage [百分比] - 弹射伤害粒子数量
  11. /bm set bloodstreampercentage [百分比] - 攻击后的粒子数量
  12. /bm set bloodstreaminterval [间隔时间] - 设置攻击之后流血粒子的显示间隔
  13. /bm set bloodstreamtime [持续时间] - 流血持续时间
  14. /bm set bleedwhencanceled - 开/关当伤害被禁止的时候流血(也就是只要攻击到就流血)
  15. /bm set [类型] ...
复制代码


类型：
  1. woolchance [数字] - 羊毛掉落几率
  2. bonechance [数字] - 尸骨掉落几率
  3. woolcolor [颜色] - 羊毛颜色
  4. stainsfloor (true|false) - 地板是否会被染色
  5. bonelife [数字] - 尸骨存在时间
  6. particlematerial (材料|hand|lookat) - 粒子材料。材料可以使用英文名称或ID。hand指手上物品，lookat指正对着的物品
  7. saturatedmats clear - 清除痕迹
  8. particlelife [最小范围] [最大范围] - 粒子存在时间
  9. stainlife [最小范围] [最大范围] - 血液存在时间
  10. amount [最小范围] [最大范围] - 攻击会掉落多少粒子
  11. saturatedmats add (材料|hand|lookat) - 添加材料到血迹材料列表中，将会替换掉血迹
  12. saturatedmats remove (材料|hand|lookat) - 添加材料从血迹材料列表中，将会替换掉血迹
复制代码


羊毛颜色：
  1. white, orange, magenta, light-blue, yellow, lime, pink, gray, silver, cyan, purple, blue, brown, green, red, black
复制代码


权限：
  1. bleedingmobs.admin - 全部权限
  2. bleedingmobs.update - 可以看到更新信息
  3. bleedingmobs.bloodstrike - 当配置启用时，只有拥有此权限才能使用出血效果
  4. bleedingmobs.noblood - 不启用出血效果
复制代码
