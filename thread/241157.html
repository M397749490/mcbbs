首先,先在http://dl.bukkit.org/下载一个Bukkit 服务端(请下载需要的版本,Bukkit最新版本为1.7.2 也可以用在1.7.4) 然后不要直接运行 请新建一个Bat档案:档案内容:
  1. java -Xmx1024M -jar craftbukkit-XXXX.jar -o false
  2. PAUSE
复制代码
然后打开就会开始加载服的文件,等他显示(Done!)信息之后可以输入:stop 来关闭服务器 (注意:千万不要通过强制关闭Java,不然可能会导致数据丢失
)

关闭之后,可以打开server.properties 文件 进行修改配置等等 可以使用记事本打开 然后修改服务器配置

修改后之后保存，下一步 安装插件

插件可以在http://mcbbs.net或者 dev.bukkit.org下载
下载完想要的插件之后，放到plugins文件夹然后再运行服务器,便会进行加载插件和更新的配置

大部分的插件安装完之后，都需要进行配置，不然不能好好的运用插件
例如Essentials插件 他的配置文件就在plugin→Essentials里面
插件配置请自行参考论坛文章

配置好后，一个基本的水桶服就差不多了，当然你说要像大型服务器那么好,很需要去用心建筑，修改等等、
