标题: 关于格式化MOD的设想
想做个MOD，把CommandBlock和Command格式化，能有更多功能……
例如逻辑运算：
  1. logic 条件 命令
复制代码
条件为true时执行命令
例如：
  1. logic @p.heart<20 effect @p minecraft:instant_health
  2. //@p.heart代表玩家生命（@p代指玩家对象，这个对象下有多个参数（可以更换为玩家名））
复制代码
然后让命令方块保持开启，即可检测。
我打算设计以下参数（针对@p）

参数 用途
@p.heart 获取玩家的当前生命
@p.exp 获取玩家的当前经验
@p.hunger 获取玩家的当前饥饿值
@p.name 获取玩家名字
@p.ip 针对服务器：玩家IP
@p.inventory_<id> 返回背包上指定ID格子的物品（可见WIKI）
@p.armorval 返回护甲值
@p.location_<x/y/z> 返回<x/y/z>的坐标值
@p.buildblockcount_<id>
 从统计信息里获取指定ID方块的搭建总数量


包括对事件的设置：
  1. event 事件 对象 命令
复制代码
例如：
  1. event useCommand @p tell @p 你使用了@event.name命令
  2. //@event是事件，.name代表命令名称
  3. //useCommand是使用命令事件，此外还有其他事件
复制代码
事件我打算设计这些：
事件 用途
useCommand 玩家使用命令
placeBlock 玩家放置方块
breakBlock 玩家破坏方块
damageBlock 玩家损坏方块（就是撸（点）方块）
interactBlock 与方块交互（例如箱子木牌）
useChestOut 从箱子中取出东西
useChestIn 放东西到箱子里
useCarrier 使用载具
move 移动
eat 吃东西
drink 喝药水、牛奶
drop 丢掉东西
fly 飞行
walkOnBlock 在方块上移动
getEffect 获取到效果时
loseEffect 效果消失
death 死亡
swim 游泳
burn 点火

我还打算设计连环嵌套结构，例如：
  1. event breakBlock @p if @event.id==minecraft:stone tell @p 你好！你破坏了@event.id
