HeadSpawner是一个让你通过指令或者PVP获得玩家头的插件
安装方法

1 下载jar
2 丢入服务端/plugins
3 重启服务器


命令列表及权限

权限
指令
快捷指令
功能
headspawner.give.self
/head <player>
/hd <玩家>
把<玩家>的头给你
headspawner.give.other
/head <player1> <player2>
/hd <玩家1> <玩家2>
把<玩家2>的头给<玩家1>


PVP掉落设置

特点:  headdrop:   
      #功能:更改True或False来选择玩家PVP死亡后是否掉落头颅.
   #值: true / false   
   #默认: false
    enabled: false
       #功能:输入玩家PVP死亡后获得玩家头颅的几率 单位:%
    #值: 1 - 100 (inclusive)
    #默认: 10
   chance: 10 (相当于10%的几率死亡掉落玩家头颅)
        #功能:让在列表里的世界启用pvp掉落头颅
    #值:输入世界名称或在whitelist里填'*'(分号不要)来使每个世界都开启PVP掉落头颅
   #默认世界: world
    whitelist:
     - world
          #功能:如果列表包含允许或不允许的世界(不明何意)
    #值: true / false
   #默认: false
   use-as-blacklist: false
       #功能:将头拿在手上右击后可以看见是头的主人的名字
   #值: true / false
   #默认: true
   show-owner: true



下载地址
http://dev.bukkit.org/bukkit-plugins/headspawner/ 自行选择合适版本
