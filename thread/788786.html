标题: 插件指令冲突怎么办？
装了mcbbs全家桶，指令是/b开头的，跟笔刷的指令/b冲突了，导致mcbbs不能用……有大佬知道有什么办法更改某一个插件的默认指令么？两个都不想卸载啊
作者: AAAA哥    时间: 2018-3-30 11:23
有个最简单的办法。
可以参考之前的playerpoints和plotme的命令冲突解决办法。
打开playerpoints插件本体（使用解压软件，比如winrar、好压）插件本体中有个叫plugin.yml的文件,打开后可以看到全是英文，再看到这一栏。
  1. commands:
  2.   points:
  3.    description: Root command for PlayerPoints
  4.    usage: /points <param>
  5.   p:
  6.    description: the same as /points
  7.    usage: /p <param>
复制代码

把p:下的内容删除，重启服务器即可。基本上是不会出错的。
这个方法也可以算是最简单、最笨的办法了。

当然还有别的类型，打开后没发现像playerpoints这样的。那么可以看commands下的aliases中附带的命令，这里一般都写有的，删除掉基本没什么大碍、如果都没发现存在的话，那只有去改源码了。
