[watch]什么是BossShop?
他是一个可以用来方便玩家和腐竹的快捷GUI
你的脑洞越大他的功能也就越多，只有想不到
本插件不适合小白，懒人使用

已知功能(RewardType)
给予玩家物品: item
只要是客户端里面有的物品，都可以让玩家获得

权限与命令
#输入/bs - 打开主店
/bs - Opens the main shop
#输入/bs 商店名称 - 打开一个叫XX的商店
/bs <shop> - Opens the named shop
#输入/bs open 商店名称 玩家ID - 为玩家XX打开一个叫XX的商店
/bs open <shop> <name> - Opens named shop for the named player
#输入/bs close 玩家ID - 为玩家XX关闭商店，可以放到配置里，关闭BS
/bs close <name> - Closes the inventory of the named player
#输入/bs reload -重载配置，如果有附属插件，会一起重载
/bs reload - Reloads the plugin, shops, configs and all installed addons
#输入/bs check- 查看BossSop的信息
/bs check - Shows detailed information about loaded shops/items etc.
#你可以把/bs 换成/shop或者/BossShop
Aliases:
/shop
/BossShop
#你还可以删除你不要的指令，虽然我不会
You can remove the commands you don't want
此处用老帖子介绍，不推荐给玩家权限，请用附属插件
BossShop.open - 允许通过牌子/命令打开所有的商店
BossShop.open.sign - 只允许通过牌子来打开所有的商店
BossShop.open.command - 只允许通过命令来打开所有的商店
BossShop.open.command <商店名称> - 允许通过命令打开指定的商店
BossShop.open.other - 允许打开其他玩家的商店（其他玩家能设置商店？）
BossShop.close - 允许通过命令将一个玩家当前打开的商店关闭
BossShop.createSign - 允许创建 BossShop 牌子(即，可以自己帖个牌子，上面写着店名就能进去)
BossShop.reload - 允许重新加载插件
BossShop.check - 允许使用check命令

小提示与变量
1. /bs reload 可以重载插件配置，不用重启后台(当初我小白的时候，不知道，光重启服务器)
2. 你可以利用GuiShopMangager和隐藏无权限功能。配置不同权限组的不同菜单
3. 你可以利用BS-SingleUse配置升级权限组
4. %player% 为玩家变量，我所配的主菜单有这例子
5.%balance%为显示玩家总游戏币数量
6. %balancepoints%为显示玩家总点券数量汉化地址，借用其他地址
7. %itemname%为显示商店名称，不是name或lore
8. %price% 如果消耗权限，就会显示具体权限，需要消耗物品，
会显示物品名称，如果需要消耗等级/游戏币/点券，会显示具体数量
9.%pricetype% 为消耗类型 Pricetype所显示的
10.  %reward%为奖励的显示，如奖励权限，就会显示具体权限。
如为等级/游戏币/点券，就会具体数量，需要消耗物品，会显示物品名称
11. %rewardtype% 奖励的名称，RewardType所显示的
12. 蓝色与绿色的区别只是因为我想让用Not+++的朋友更清晰的看懂
