@wjwrh

           你看一下  是不是paper端问题 还是？

问题的原因是插件在调用 setResourcePack(java.lang.String url, byte[] hash) 向玩家发送资源包的时候, hash 哈希值为空。

哈希值通常是为了确认下载之后的资源包是没有损坏的, 插件被混淆了我也看不出来233, 但是我猜是因为插件还没有生成资源包的哈希, 或者是网络问题(是否能访问配置文件中的资源包URL?)。

在 github 上我搜到了相关的一个 issue Issue #222, 但是这提交者确实够2的自己给关了, 也没有得到任何答复. 所以建议你自己去插件Github上面提一个Issue询问这个问题, 当然可以先试试我上面的方法。
