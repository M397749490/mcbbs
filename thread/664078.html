1、调试Eclipse中的插件


当你在调试插件时，有时候Eclipse没有报错，官方Wiki地址：戳我戳我
但是Minecraft里出不来，那么该怎么办呢？

1、设置开服bat

把原来开服的bat文件用记事本打开
修改成这样：
  1. @echo off

  3. java -Xdebug -Xnoagent -Djava.compiler=NONE -Xrunjdwp:transport=dt_socket,server=y,suspend=n,address=51321 -Xms512M -Xmx1024M -XX:MaxPermSize=128M -jar 你的服务端核心文件名.jar
  4. pause
复制代码

示范
  1. @echo off

  3. java -Xdebug -Xnoagent -Djava.compiler=NONE -Xrunjdwp:transport=dt_socket,server=y,suspend=n,address=51321 -Xms512M -Xmx1024M -XX:MaxPermSize=128M -jar spigot-1.10.jar
  4. pause
复制代码



2、Eclipse开启调试

点击“调试 类名（因人而异）>调试 配置(B)...”

然后点击“远程 java 应用程序>新建启动配置”

之后你看到的是这样的，
按照下图输入内容

然后按“应用”


3、bat开启调试

你在上面的过程中，如果按了“调试”，Eclipse会报错。
你必须先重启你的服务器，然后在按调试。
当你看到这个的时候，就说明你成功了！

你可以在你的代码中设置断点，查看代码的错误
也可以进入服务器开始试验插件了
