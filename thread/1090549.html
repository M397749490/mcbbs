使用方法：找到游戏中的log文件，拖到程序里，回车即可。
提取后的聊天记录将被保存在程序运行目录下的CHAT.log文件内。
每个服务器的关键词可能不大一样，具体有需求可以改一下。

源代码：

filePath = input("log文件（.txt or .log）")
chat = []
for line in open(filePath):
    if "[CHAT]" in line:
        line = line.replace('[net.minecraft.client.gui.GuiNewChat]: ', '')
        line = line.replace('[Client thread/INFO] ', '')
        line = line.replace('[CHAT] ', '')
        line = line.replace('\n', '')
        chat.append(line)
OutputPath = './CHAT.log'
with open(OutputPath, 'w', encoding='utf-8') as file_object:
    for i in chat:
        file_object.write(i)
        file_object.write('\n')



与程序无关的内容：

写这个的原因，其实是服务器里起了冲突，联系管理员仲裁的时候，提供聊天记录，
担心管理员看log看花眼，所以给单独挑出来聊天记录，去掉了无关的内容。。。
如果有哪个服务器也需要log作为判定依据的话，建议索要双方log的源文件，然后自己手动的获取聊天记录，
再然后对比一下聊天记录是否有缺失删改，这样才能确定log的准确性。
当然，我猜大部分腐竹都会从服务器下载log来看。。
