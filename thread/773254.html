entity的伤害、血量：
- bukkit版本1.9以后可以使用Attribute实现：
  1. Entity entity = balabala...;
  2. Attribute 属性类型_最大生命 = Attribute.GENERIC_MAX_HEALTH;
  3. //攻击伤害：GENERIC_ATTACK_DAMAGE
  4. AttributeInstance entity的最大生命属性 = entity.getAttribute(属性类型_最大生命);
  5. double 要增加的属性数值 = 10;
  6. //减少的属性数值 = -10;
  7. AttributeModifier 属性数值修改器 = new AttributeModifier("Stronger!", 要增加的属性数值, Operation.ADD_NUMBER);
  8. entity的最大生命属性.addModifier(属性数值修改器);

  10. ===压缩===
  11. entity.getAttribute(Attribute.GENERIC_MAX_HEALTH).addModifier(new AttributeModifier("Harder!", 10, Operation.ADD_NUMBER));
