ModelManager



模型管理
下载

面对服主:
这仅仅是一个前置插件，可以帮您方便管理
服务器的4D模型，前提是服务器里得有基于
本插件的插件

面对开发者:
插件提供了各种列表(例如human_Model)，您通过一个模型名称(模型文件夹名称)获得Skin对象直接使用
可以调用开放api使模型json直接反序列化成ModelBean对象，方便操作
也可以通过一个ModelBean对象直接序列化成json字符串，直接拿来使用

API:
  • getModel(String jsonPath) 可以得到一个ModelBean对象
  • getJson(ModelBean bean) 通过ModelBean对象反序列化成json字符串
  • getHuman_Model() 返回HashMap<String, Skin>
  • getMonster_Model() 如上
  • getPet_Model() 如上
  • getObject_Model() 如上

一个解析json的Demo
  1. String json = ""geo.name": {...}" // 这里写入json模型字符串
  2. ModelBean bean = ModelManage.getModel(json);
  3. Models models = bean.getModels();
  4. List<Bones> bones = models.bones;
  5. for(Bones bone : bones) {
  6.   List<Cubes> cubes = bone.cubes;
  7.   for(Cubes cube : cubes) {
  8.     List<Double> origin = cube.origin;  //[x, y, z] 方块起点
  9.     List<Double> size = cube.size;  //[x, y, z]  方块大小
  10.     List<Integer> uv = cube.uv;  //[x, y]  贴图uv
  11.   }
  12. }
