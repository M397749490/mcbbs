  大家好,我是哈陆lu,昨天我一上我的QQ就发现有7个人加我好友,都是问我怎么开服的,今天我就教小白们如何开服.

  教程是在windows系统上开服的,其他系统如何开服请去问百度

开服的条件
  首先,你必须有java(废话)，你还要知道你电脑的内存(设置人数)，如果是内网开服就要映射或者蛤蟆吃或者花生壳,然后你需要想一想你的服务器要不要装mod，如果不装就看"水桶"，如果装就看"MCPC+"


水桶


首先,你需要一个水桶服务端,水桶官方下载地是http://dl.bukkit.org
,下载完以后,你需要新建一个开始.txt文件(文本文档)然后输入一下代码
  1. @ECHO OFF
  2. java -Xms1g -Xmx1g -jar <水桶服务端的文件名>.jar
  3. pause
复制代码
文件名就是你下载的水桶服务端的文件名，之后把开始.txt改成开始.bat，然后运行，直到出现Done <x.xx>!就开服完了，不过你还需要改一些东西,打开server.properties 里面有一个online-mode=true 你需要把true 改成 false
这样，你的服务器就开完了，每次开服只要点一下 开始.bat 就能开服了


MCPC+
和水桶一样，你先要有一个MCPC+的服务端，MCPC+论坛内搬运运http://www.mcbbs.net/thread-145866-1-1.html
你要下载一个MCPC+的服务端，下载完以后,你需要新建一个开始.txt文件(文本文档)然后输入一下代码

  1. @ECHO OFF
  2. java -Xms1g -Xmx1g -jar <MCPC+的文件名>.jar
  3. pause
复制代码
文件名就是你下载的MCPC+服务端的文件名，之后把开始.txt改成开始.bat，然后运行，直到出现Done <x.xx>!就开服完了，不过你还需要改一些东西,打开server.properties 里面有一个online-mode=true 你需要把true 改成 false 这样，你的服务器就开完了，每次开服只要点一下 开始.bat 就能开服了

插件

  事先说明：水桶的大部分插件兼容MCPC+
  打开你开服的那个文件夹，你会发现里面有一个叫"plugins"的文件夹，这个文件夹就是放插件的，你只要把插件放进这个文件夹里就行了


如何让别人进入你的服务器

  首先，如果你不想用外网，你就要蛤蟆吃或者花生壳，蛤蟆吃与花生壳的用法


蛤蟆吃

蛤蟆吃是局域网软件,你只要创建新网络,再让别人加加进来就行了


花生壳


首先要注册,然后下载一个花生壳6.5,映射一下你的端口,别人只要输入你的免费域名:端口号就能上你的服务器了

                      映射
请看http://www.mcbbs.net/thread-8261-1-1.html
