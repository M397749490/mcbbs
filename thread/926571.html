简介 Description
一款不错的电梯插件
很类似现实中的电梯
所以我就搬来拉~

特点 Characteristics
1.支持多楼层
2.可定制移动平台材料
3.呼叫电梯按钮
4.自动开门关门
5.使用GUI来选择楼层

权限和指令 Permission & command
/ep help - 查看帮助. (eplus.help - 默认权限: 所有人)
/ep create [名称] - 创建新电梯. (eplus.create - 默认权限: op)
/ep remove [名称] - 删除电梯. (eplus.remove - 默认权限: op)
/ep list (页码) - 显示电梯列表. (eplus.list - 默认权限: op)
/ep set [名称] [参数] [数值] - 修改电梯参数.
(eplus.set - 默认权限: op)
  参数有:
  levelsCount(楼层总数) [添加呼叫按钮自动增加,不需要动]
  levelDistance(楼层间距)
  floorMaterial(移动平台ID) [不需要动]
  floorData(移动平台子ID) [不需要动]
  currentLevel(当前停靠楼层) [不需要动]
  (作者自己都没写2333)
/ep info [名称] - 显示有关电梯的信息. (eplus.info - 默认权限: op)
/ep setsign [名称] - 设置GUI牌子. (eplus.setsign - 默认权限: op)
/ep reload - 重新加载此插件. (eplus.reload - 默认权限: op)
/ep addbutton [名称] [楼层] - 添加呼叫按钮到电梯. (eplus.addbutton  - 默认权限: op)
/ep removebutton [名称] [楼层] - 删除电梯的呼叫按钮. (eplus.removebutton - 默认权限: op)
/ep listbutton [名称] (页码) - 显示呼叫按钮列表.
(eplus.listbutton - 默认权限: op)
/ep addblock [名称] - 添加移动平台到电梯.
(eplus.addblock - 默认权限: op)
/ep removeblock [名称] [ID] - 删除电梯的移动平台. (eplus.removeblock - 默认权限: op)
/ep listblock [名称] (页码) - 显示移动平台的列表.
(eplus.listblock - 默认权限: op)
/ep powertool [子指令] - 使用 PowerTool.
(eplus.powertool - 默认权限: op)

食用方法 Instructions
文本介绍
使用 /ep help 来查看命令的用法
1)使用 /ep create 创建电梯.
2)使用 /ep addblock 添加移动平台.
3)使用 /ep addbutton 为每个楼层添加呼叫按钮.
4)为电梯增加GUI, 使用 /ep setsign 对目标牌子.
