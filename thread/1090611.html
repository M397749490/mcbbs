配置
  1. #SQL参数(高一点的版本需要在url加上'?useSSL=false')
  2. Sql: false
  3. Url: 'jdbc:mysql://localhost:3306/web_study?useSSL=false'
  4. User: 'root'
  5. Password: '123456'

  7. #物品几天后自动下架
  8. LimitTime: 1

  10. #启用分类
  11. ItemClassify: true

  13. #上架限制
  14. LimitLore: true
  15. LimitLoreList:
  16.   - 私有
  17.   - vip
  18.   - 绑定

  20. #数量限制
  21. LimitAmount: true
  22. LimitAmountNum: 30

  24. #上架最大金额(默认9999999)
  25. MaxPrice: 9999999

  27. #上架提示
  28. SellBroadcast: true

  30. #邮箱限制(超过限制上线自动签收)
  31. LimitMail: true
  32. LimitMailNum: 30

指令
/market                                  - 环球市场
/market help                           - 指令帮助
/market mine                          - 个人市场
/market mail                           - 个人邮箱
/market data                               - 个人信息
/market clean                          - 全部签收     market.clean
/market sell [m] <a>               - 出售物品      market.sell
/market auction [m] <a>         - 拍卖物品      market.auction
/market discount [id] [a]          -  商品打折     market.discount
/market send [p] <a>              - 发送邮件     market.send
/market statistic <p|id>           - 统计数据      market.statistic
/market other [p]                    - 他人商店      market.other
/market classify <type>           - 商品分类   
其中p表玩家，a表数量，m表价格，<>表示可选，[]表示必填 权限红色要手动给
