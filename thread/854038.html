如题，我是腐竹，请问服务器给了玩家的称号如何删除？用这个指令给的 /manuaddv ID prefix 称号想假装看不见改成 （空格）也没办法使称号变成 （空格）、、

作者: 帕帕武    时间: 2019-3-30 23:32
你有两种办法
一是
/manuaddv ID prefix &f

这样玩家称号就会消失了

二是
直接输入
/manudelv 玩家名字 prefix

直接删除掉玩家称号
不用空格

groupmanager似乎没办法很好的管理玩家称号，推荐升级为luckperm，支持1.7-1.13所有版本，并且共支持100个权重也就是最高可设置100个称号http://www.mcbbs.net/thread-676818-1-1.html是最为先进的权限、权限组与称号管理插件哦~
  1. 我怎么为玩家设置前缀或后缀
  2. 举个例子，如果我想让admin权限组的玩家拥有 "&c[Admin] " 前缀，在mod权限组的玩家拥有 "&d[Mod] " 前缀的话，我需要运行：
  3. /lp creategroup admin
  4. /lp creategroup mod
  5. /lp group admin parent add mod
  6. /lp group admin meta addprefix 100 "&c[Admin] "
  7. /lp group mod meta addprefix 90 "&d[Mod] "
  8. 然后如果我决定想要将admin用户组的称号改为使用 "&4" 这个颜色代码的话，要想删除之前设定的值，我需要运行：
  9. /lp group admin meta removeprefix 100
  10. 这会将所有设定给admin权限组的，优先级为100的前缀全部移除，然后我就能重新设置新的前缀值了。
  11. 对于临时设定用户前缀或后缀的方法和增加临时权限或临时权限组的方法差不多。
  12. 所有的权限使用方法可以在权限使用页面找到。增加和移除元数据的方法也列在了那里。
