请问如何判断一个生物上方是否有方块？答案:
                if(entity.getLocation().getBlockY() + 2 < world.getHighestBlockYAt(entity.getLocation())) {
                        player.sendMessage("有障碍");
                }else {
                        player.sendMessage("无障碍");
                }
