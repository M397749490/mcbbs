作者: 网络摆渡客    时间: 2014-7-22 08:47
解决了：
需要给default（或者其他用户所在的组）添加相关权限：
  1. #领地建立权限
  2. /mangaddp default residence.create
  3. #worldedit所有权限
  4. /mangaddp default worldedit.*
复制代码

这个操作是游戏内指令。
