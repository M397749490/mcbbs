插件图片:


特点:
  • World Map Loading System(地图加载系统)
  • Ability to use signs to join maps(牌子加入)
  • Very customizable(自定义)
  • In-game and Spectator Shops(游戏商店和观察者商店)
  • Kits(装备)
  • Basic, Regular and OP Chest files including player voting for OP Chests(多种箱子)
  • Time Voting(时间投票)
  • Weather Voting(天气投票)
  • Jump Boost Voting(跳转提升投票)
  • Permanent Kits Shop(永久装备商店)
  • Glass Color Shop(彩色玻璃[size=14.6667px]商店)
  • Particle Effects Shop(粒子特效[size=14.6667px]商店)
  • Projectile Trail Effects Shop(弹径特效[size=14.6667px]商店)
  • BungeeMode (In development)

命令:
  • /swr join - 加入游戏
  • /swr quit - 退出游戏
  • /swr start - 强制开始
  • /swr kit - 打开装备菜单
  • /swr menu - 打开大厅菜单
  • /swr shop - 打开游戏商店
  • /swr glassshop - 打开玻璃商店
  • /swr permkitshop - 打开装备商店
  • /swr particleshop - 粒子商店
  • /swr trialshop - 打开弹径特效[size=14.6667px]商店
  • /swr stats - 获取战绩
  • /swr setspawn - 设置大厅出生地
  • /swr spectate - 观察者菜单
  • /swr reload - 重载配置
  • /swr list - 获取地图列表
  • /swr create <mapname> - 创建地图
  • /swr save <mapname> - 保存地图
  • /swr edit <mapname> - 编辑地图
  • /swr delete <mapname> - 删除地图
  • /swr register <mapname> - 挂载(开启)地图
  • /swr unregister <mapname> - 关闭地图
  • /swr games - 获取正在开始的比赛
  • /swr endgame <gamenumber> - 结束一场游戏
  • /swr addpoints <playername> <points> - 添加money
  • /swr removepoints <playername> <points> - 扣除money
  • /swr setglass <playername> <color> - 设置玻璃
  • /swr seteffect <playername> <effect> - 设置粒子
  • /swr setprojeffect <playername> <effect> - 设置弹径特效
  • /g - 全局聊天

权限:(英文)
  • swr.play - Allows use of join, quit, kit, and stats command.
  • swr.spectate - Allows a player to use the spectate command.
  • swr.opchest – Allows the player to vote for OP chests in the game options.
  • swr.timevote – Allows the player to vote for time of day in the game options.
  • swr.jumpvote – Allows the player to vote for time of day in the game options.
  • swr.weathervote - Allows the player to vote for weather in the game optons.
  • swr.usecolor - Allows players to change their glass color in the game options.
  • swr.useeffect - Allows playesr to change their particle effects in the game options.
  • swr.useprojeffect - Allows a player to change the projectile trial effects in the game options.
  • swr.signs – Allows the player to create and destroy swr signs.
  • swr.global - Allows the player to use global chat.
  • swr.start - Allows the players to use the /swr start command.
  • swr.shop - Allows a player to use the shop command.
  • swr.spectateshop - Allows a player to use the spectator shop.
  • swr.admin - Allows use of setspawn, games, endgame, reload, addpoints, removepoints, setglass, seteffect, and setprojeffect commands.
  • swr.ignoreLobbyGuard - Allows the player to ignore the lobby guard (make changes to the lobby world)
  • swr.vip -gives the player the VIP Multiplier
  • swr.maps - Allows use of all map commands.
  • swr.kit.<kitname> - Allows a player to use a kit.
  • swr.kit.free.<kitname> - Allows a player to get a kit for free even if it costs balance
  • swr.permkits -allows a player to buy permanent kits (permanent kit price can be set in the <kitname>.yml.
  • swr.color - Allows a player to use color chat.
  • swr.colorshop - Allows the player to buy glass colors.
  • swr.colorglass.<glasscolor> - Allows a player to use a certain glass color. This permission is given to the player when they buy a color. (all the colors are listed and the prices can be changed in the glasscolors.yml).
  • swr.effectshop - Allows players to buy particle effects.
  • swr.effect.<effectname> - Allows a player to use a certain particle effect. This permission is given to the player when they buy a particle effect. (all the effects are listed and the prices can be changed in the particleeffects.yml).
  • swr.projeffectshop - Allows a player to buy Projectile Trail effects.
  • swr.projeffect.<effectname> - Allows a player to use a certain trail effect. This permission is given to the player when they buy a trail effect. (all the effects are listed and the prices can be changed in the projectileeffects.yml).

地图创建方法:
  • /swr create <mapname> 创建一个世界(一个世界一个地图，不支持多世界插件)
  • [size=14.6667px]/swr save <mapname> 保存存档（保存世界）
  • [size=14.6667px]/swr register <mapname>.启动世界(至少需要两个出生点(信标，开始时会自动生成玻璃))
    如果这步出现问题，后台会报出原因，一般是没放信标（版本不兼容会导致找不到信标）
  • [size=14.6667px]/swr edit <mapname>编辑世界（编辑已经好了的场地，需重新/unregister /register 生效）
  • 如果需要导入地图，可以把[size=14.6667px]plugins\SkyWarsReloaded\maps的存档替换
详细教程@volta薯片~:

1.丢进plugins= =
2.重启服务器
3.生成了叫Skywarsreloaded的文件夹，打开，看config.yml随便用记事本或者Notepad++打开。
4.可以看到上方有一些带#号的内容，下方又重复了一遍不带#号的，改那些不带#号的，大部分保持默认，但是SignJoinMode要改成True，不然登录牌子用不了。（补充:不改是另一个模式，只需要放踏板，踩踏板可以随机匹配一个）
5.如果你想作死去汉化就去改message.yml吧= =表示汉化以后自动变回英文，发了语言文件我正让楼主帮我改编码= =
6.进游戏，楼主有一点没说清楚，/swr那些指令是要自己建地图才用的，楼主说的自己生成的那个地图是原来就有的，不用新建，直接/swr register caves(那个地图本来叫caves），然后再按楼主说的设置登录牌子（记住名字叫caves）
7.注意，应该先用多世界插件（管你用MW还是MV）生成一个新的世界，在新的世界先/swr setlobby，然后再进行第六步= =最好弄新的世界，因为弄好就绑定了这个世界，近来自动给你商店啥的，我之前设在了主城边上，结果就QAQ了
8.最后要保证玩家玩的爽，要把权限都给玩家= =

帮楼主补充教程：
1.丢进plugins= =
2.重启服务器
3.生成了叫Skywarsreloaded的文件夹，打开，看config.yml随便用记事本或者Notepad++打开。
4.可以看到上方有一些带#号的内容，下方又重复了一遍不带#号的，改那些不带#号的，大部分保持默认，但是SignJoinMode要改成True，不然登录牌子用不了。
5.如果你想作死去汉化就去改message.yml吧= =表示汉化以后自动变回英文，让楼楼改了编码不知道能不能用= =
6.进游戏，楼主有一点没说清楚，/swr那些指令是要自己建地图才用的，楼主说的自己生成的那个地图是原来就有的，不用新建，直接/swr register caves(那个地图本来叫caves），然后再按楼主说的设置登录牌子（记住名字叫caves）
7.注意，应该先用多世界插件（管你用MW还是MV）生成一个新的世界，在新的世界先/swr setlobby，然后再进行第六步= =最好弄新的世界，因为弄好就绑定了这个世界，近来自动给你商店啥的，我之前设在了主城边上，结果就QAQ了
8.最后要保证玩家玩的爽，要把权限都给玩家= =
起码要给：
swr.play
swr.spectate
swr.timevote
swr.jumpvote
swr.weathervote
swr.usecolor
swr.useeffect
swr.useprojeffect
swr.global（注意，不给的话玩家不能说话= =）
swr.start（可给可不给，反正都有牌子加入了）
swr.shop
swr.spectateshop
swr.kit.<kitname>（后面的kitname要自己输，设置装备后面讲，默认有个叫example的）
swr.permkits
swr.colorshop
swr.effectshop
swr.projeffectshop
说一下，@chenjiwei的翻译有些问题= =
swr.opchest的意思是给箱子投票，还是别给好= =
swr.timevote是给时间投票没错，但swr.jumpvote怎么也写的是时间投票= =真正的意思是给跳跃的类型投票
后面的那个射击实验效果和抛物线效果一看就是机翻= =实际意义是你发射物品时（如射箭）伴有的粒子效果。

其他没什么好说的了= =哦对，给权限的指令是/mangaddp builder 权限
后面设置装备名称的，有时间在更= =
