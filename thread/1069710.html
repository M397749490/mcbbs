作者: tnqzh123    时间: 2020-6-29 23:28
SkinsRestorer 的话，除非是使用有披风的正版的 ID 的皮肤，否则是没有办法支持披风的。

在多人联机中，玩家信息（包括皮肤和披风）是由服务端下发给客户端的。Minecraft 客户端本身有限制允许加载的材质的域名（mojang.com 和 minecraft.net），并会验证服务端下发的玩家信息的签名。

SkinsRestorer 的原理是直接返回指定的正版 ID 的玩家信息中的皮肤和披风以及签名，包括自定义皮肤也是这样（他们使用了一个叫 MineSkin 的 API，原理是用他们自己的正版账号上传皮肤，拿到 URL 和签名之后再返回给客户端）。但是正版没办法自己上传披风，所以做不到你的需求。

如果有这方面的需求，建议使用皮肤站（比如 LittleSkin）配合皮肤 Mod（比如 CustomSkinLoader）实现。CustomSkinLoader
