介绍
这个插件可以让你做出来一个竞技场、还能自定义工具和物品在竞技场里使用并生存下来。
命令arena.reload
命令描述权限
/arena create 竞技场名字创建出一个竞技场arena.create
/arena setpos 竞技场名字把竞技场位置设置到你脚下的地方arena.create
/arena reload重载插件
/arena help查看和竞技场有关的所有指令无
权限
权限描述
arena.create创建竞技场
arenas.join允许加入竞技场
arenas.kit允许使用工具
arena.reload重载插件
arena.*以上所有的权限


注意事项：这个竞技场插件的前置插件最好使用Multiverse-Core插件，请勿使用其他多世界插件。还有，下方告示牌里的内容只有OP可以设置
         如何创建一个竞技场
   
      
  • 输入 /arena create 竞技场名字
  • 到你想创建竞技场的地方输入/arena setpos 你刚才输入的竞技场名字，确认地点
  • 如果要进入竞技场，你必须使用一个展示牌写的文字如下↓（<>可打可不打Arena name处为你所创建的竞技场名字）
还有自定义工具的竞技场（<>也是可打不打Kit name处输入你想使用工具的代码）
