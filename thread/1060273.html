作者: 天辉胡萝卜    时间: 2020-6-12 01:37
是用的papi吗？是的话可以直接用placeholder JavaScript取整

/papi ecloud download JavaScript
之后进入plugins/PlaceholderAPI/javascript_placeholders.yml，加入以下内容
  1. my_valut:
  2.   file: my_valut.js
复制代码


之后在plugins/PlaceholderAPI/javascripts/创建my_valut.js，内容为
  1. function my_valut() {
  2.     return Math.round(parseInt('%游戏币占位符%');
  3. }

  5. my_valut();
复制代码


最后/papi reload
然后你就可以用占位符%javascript_my_vault%来代替原有的游戏币显示
可以/papi parse me %javascript_my_vault%来测试
