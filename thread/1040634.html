个人使用paper1.12.2，可以正常运行此插件

插件特色
√随意定时间发放工资
√可设置玩家离线时发放的工资
√多语言支持
（暂时有德语、英语，中文我已上传给作者，等待添加，下方有汉化文件）

插件指令/所需权限

/salary <权限组名称或玩家名称> <数量> [-g 或 -p 或 -o]
设置权限组或玩家的工资数量
注：-g为权限组，-p为玩家，-o为离线玩家
权限：
salarymanager.set
salarymanager.set.offline

/salaryfrom <玩家名称或UUID或none>
将<玩家名称或UUID或none>设置为取款机
每次发放工资将会从<玩家名称或UUID或none>内扣取
默认是none
权限：
salarymanager.notify  ---该权限为被取款通知，没有该权限将不会显示被取款的消息

插件配置

config.yml
请勿直接复制粘贴
default-delay: 1200 #发薪水的时间，以秒为单位
get-most-profitable: true  #合理的获取薪水，建议开启这项，下面两项可以不用管
get-player-salary-when-possible: false  #如果设置了玩家薪水，是否获取玩家薪水
get-all: false  #是否获取所有权限组合起来的薪水
ignore-afk: true  #是否忽略挂机玩家（需要Essentials插件）
message-player: true  #发薪水时是否发送消息
log-payments: true  #是否将数据记录到history.yml
log-payments-to-console: true  #是否开启控制台接收玩家收款消息
notify-staff: true  #是否将玩家收款消息发送给op
use-language: default  #设置语言
reschedule-on-reload: true  #重新加载时是否重置发薪水时间
allow-finding-offline-players: false  #是否开启salary指令和salaryfrom指令的离线玩家，开启后可以设置离线玩家，而不仅仅只能设置在线玩家
simpler-money-format: false  #未知，建议不要乱动
use-bstats: true  #是否使用bstats
offline-salaries-paid-when-online: true  #开启后将会照样支付离线玩家薪水
