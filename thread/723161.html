该项目面对人群：

有C# 面对对象基础的开发者
学习Minecraft网络数据包结构的开发者
软件嵌入式显示服务器信息开发者
等对该功能有需要的开发者

该项目语言：
.NET Framework 4.0 C#

该项目能获取：
服务器MOTD（可能带颜色代码）
服务器最大玩家数量/服务器在线人数
服务器在线玩家名称列表（如果可行）（可能带颜色代码，已自动删除颜色代码）
服务器Protocol版本
服务器MOD列表（如果可行）（带其版本号）
服务器延迟（毫秒）
服务器ICON图标（如果可行）（Bitmap）
颜色代码转换16进制颜色代码

使用教程：
  1. //下载并引用库MinecraftOutClient.Modules
  2. using MinecraftOutClient.Modules;
复制代码
  1. //新实例化一个ServerInfo，并使用带参数的构造函数设置IP以及端口
  2. ServerInfo info = new ServerInfo("127.0.0.1", 25565);
复制代码
  1. //使用StartGetServerInfo方法开始获取服务器信息
  2. info.StartGetServerInfo();
复制代码
  1. //接下来GET info的各种属性即可获取服务器各种信息，例如获取MOTD：
  2. string motd = info.Motd;
复制代码
*注意：无法获取或获取失败的属性为null，请在操作前检测是否为空指针。
*获取的服务器ICON（如果可用）为bitmap。使用save即可保存为文件。
*MOTD以及其他属性可能会带有Minecraft颜色代码。ServerInfo.MinecraftColors可以帮助你转换成16进制颜色代码*被查询的服务器版本号应高于1.7.2 既protocol版本号应大于4
*BungeeCord可能无法查询到MOTD
