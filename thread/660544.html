SaveIt~
——]-前言-[——
是否还在为地图保存效率不高而担忧?
是否已经厌倦了bukkit那抽风的保存?
是否整天因为道具丢失的关系被玩家投诉?
那么,这个插件就是你的救星!



——]-介绍-[——
本插件是作者的处女作
插件不大,只有40多KB
但是功能非常多,性能也十分不错



——]-功能-[——
World Saving -保存世界
AutoSave in minutes -每分钟自动保存
Multi-World Support -支持多世界
Supports All Permission Plugin -支持所有权限插件
You can Disable the Default Bukkit Auto Save
-可以停用bukkit自带的辣鸡保存系统!!!
Saves all Players -保存玩家
Per World Save Configuration -保存每个世界的config
Enable/Disable Saving Messages -启用/禁用发送保存信息
Custom Messages -自定义保存信息
Anti-Config Error -自动修改错误
In-Game Help -有/help[有个*用啊!]
Supports Colors in the Config -支持颜色代码
Save On Disable -节省空间
Save All Worlds Option -选择需要保存的世界
In-Game Config Editor -可以在游戏内改config文件
Works on Every Bukkit Build
-在bukkit及其衍生的服务端中都可以使用,BC也可以
Forge Support! -支持Forge
Now with Backup Support! -保存玩家退出时的位置
Special Features:
- Saves On X Quit -不懂
- Saves On X Login -不懂
- Saves On X Block Place (Any kind of Block) -不懂
- Saves On X Block Break (Any kind of Block) -不懂
- Save Your Own Data With a Command -可以用指令保存你的信息
- Debug -修复错误
Power Save Mode -节能模式
Tweaked Performance Source is available again on Github -开源



——]-指令&权限-[——
/saveit -列出指令(default)
/saveit save -立刻保存世界(saveit.save)
/saveit reload -重载配置文件(saveit.reload)
/saveit selfsave -节省数据(saveit.selfsave)
/saveit add WORLDNAME -添加/世界配置(saveit.manage)
/saveit remove WORLDNAME -删除/世界配置(saveit.manage)
/saveit list -已经配置的世界(saveit.manage)
/saveit backup -创建一个ZIP备份服务器[不懂](saveit.backup)
/saveit update -从dev上下载最新版本(OP)
