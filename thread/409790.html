  1. 附加参数
  2. 在定义目标之后，你也可以决定是否使用附加参数。  使用方法为：  @<selector>[<argument>=<value>,<argument>=<value>]
  3. 参数        功能
  4. x        搜索中心的X坐标。
  5. y        搜索中心的Y坐标。
  6. z        搜索中心的Z坐标。
  7. r        最大搜索半径
  8. rm        最小搜索半径
  9. m        玩家的游戏模式。0=生存，1=创造，2=冒险
  10. c        玩家数量。如果数值为负，将优先选定列表的末尾。
  11. l        目标玩家可拥有的最大等级
  12. lm        目标玩家可拥有的最小等级
  13. score_name        在记分板目标"name"中，玩家可拥有的最大分数
  14. score_name_min        在记分板目标"name"中，玩家可拥有的最小分数
  15. team        测试此玩家是否存在于所指定的队伍内，在队伍名前添加"!"将只测试不在此队里的玩家。提供空的队伍名将测试所有没有队伍的玩家。
  16. name        指定只有这个名字的玩家。在name前添加"!"将只测试没有此名字的玩家。
  17. dx        搜索范围的x平移量。
  18. dy        搜索范围的y平移量。
  19. dz        搜索范围的z平移量。
  20. rx        最大x轴搜索半径
  21. rxm        最小x轴搜索半径
  22. ry        最大y轴搜索半径
  23. rym        最小x轴搜索半径
  24. type        搜索此类型的实体
  25. id        搜索拥有此UUID的实体（NBT相关）
  26. 例：@p[x=1,y=30,z=26,r=10,rm=2,m=1,c=3,l=25,lm=3,score_Kills_min=1,score_Deaths=2,team=Red]可以被用来精确定义符合下列条件的3个玩家（c=3）（c>0优先从列表上面选,c<0优先从列表下面选）1.在X=1,Y=30,Z=26周围2~10格（1，30，26，10，rm=2）
  27. 2.创造模式
  28. 3.3~25级
  29. 4.最小score_Kills 数为1，最大score_Deaths为2
  30. 5.红队（team=red）
