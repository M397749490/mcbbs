Block Redstone Event Analyse and Diagnose
方块红石事件分析及诊断

功能
本插件用于分析服务器内的红石数据。通过这个插件，您可以使用一个简单的命令检测服务器一段时间内绝大多数的红石更新，并得到一个可读的分析报告。

命令
  • /bread - 根命令。
  • /bread start - 启动一轮BREAD。
  • /bread semi-fast - 启动一轮半快速BREAD。
  • /bread fast - 启动一轮快速BREAD。
  • /bread stop - 停止正在运行的BREAD。
  • /bread status - 查看BREAD状态，以及上一轮BREAD结果（若存在）。

权限
  • bread.admin - 允许管理员使用BREAD。默认OP拥有。
