你只需要这样调
Residence:
           # 玩家是否可以创建领地.
           CanCreate: true
           # 玩家允许拥有最大领地数.
           MaxResidences: 3
           # 一个领地的最大物理区域数目.
           MaxAreasPerResidence: 3
           # 一个领地在东西方向最大距离 (X坐标).
           MaxEastWest: 9999
           # 一个领地在东西方向最小距离 (X坐标).
           MinEastWest: 0
           # 一个领地在南北方向最大距离 (Z坐标).
           MaxNorthSouth: 9999
           # 一个领地在南北方向最小距离 (Z坐标).
           MinNorthSouth: 0
           # 一个领地在上下方向最大高度 (Y坐标).
           MaxUpDown: 256
           # 一个领地在上下方向最小高度 (Y坐标).
           MinUpDown: 0
           # 允许创建领地的最低高度.
           MinHeight: 0
           # 允许创建领地的最高高度.
           MaxHeight: 255

然后resadmin reload groups,之后再mangaddp builder residence.max.res.数量 (数量填较大值)

你好楼主请打开res的文件夹,groups.yml里找到
       Residence:
           # 玩家是否可以创建领地.
           CanCreate: true

           MaxAreasPerResidence: 3

           MaxEastWest: 64
           # 一个领地在东西方向最小距离 (X坐标).
           MinEastWest: 3
           # 一个领地在南北方向最大距离 (Z坐标).
           MaxNorthSouth: 64
           # 一个领地在南北方向最小距离 (Z坐标).
           MinNorthSouth: 3
           # 一个领地在上下方向最大高度 (Y坐标).
           MaxUpDown: 256
           # 一个领地在上下方向最小高度 (Y坐标).
