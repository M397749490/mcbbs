作者: llc1    时间: 2020-4-12 15:09
创建死亡榜：/scoreboard objectives add a deathCount ["死亡"]
重复执行 无条件 始终执行：/execute @a[score_a=1,score_a_min=1] ~ ~ ~ gamemode 3 @p
连锁（和上面）条件 始终执行：/execute @a[score_a=1,score_a_min=1] ~ ~ ~ scoreboard players set @p a 0
原理：检测到玩家的死亡数为1，那么把玩家的游戏模式换成旁观者，然后将死亡分数换回0
