采摘作物触发命令 Steal_Food
交流群: 1023365448
功能:
1.玩家右键作物时 如果作物处于 成熟阶段 即 触发命令和掉落物品 并恢复到即将成熟阶段
2.可以设置是否无视权限 (可以达到偷菜功能)


命令:
/sf reload  -重新加载配置


配置:


  2. # 是否开启调试模式
  3. # 开启后 右键作物会显示其 方块Id
  4. Debug: true

  6. # 是否可以采摘没有权限的作物
  7. IsPer: false

  9. # 偷菜设置
  10. StealFood:
  11.   # 填写Debug的 方块Id
  12.   # 这里是小麦
  13.   "59":
  14.     # 成熟时的Data 大小 不设置默认是7
  15.     Data: 7
  16.     # 恢复到即将 成熟的Data (必须设置)
  17.     ReData: 5
  18.     # 触发命令设置
  19.     Command:
  20.       - "say %p你采摘了小麦"
  21.     # 触发命令是否以管理员权限运行
  22.     CommandIsAdmin: true
  23.     # 掉落物设置
  24.     # 格式 Id 最小数量~最大数量 几率 子Id
  25.     DropItem:
  26.       - "351 1~3 100 0"
  27.   # 这里是甜菜根
  28.   "244":
  29.     # 成熟的Data 大小 不设置默认是7
  30.     Data: 7
  31.     # 恢复到即将 成熟的Data (必须设置)
  32.     ReData: 5
  33.     # 触发命令设置
  34.     Command:
  35.       - "say %p你采摘了甜菜根"
  36.     # 触发命令是否以管理员权限运行
  37.     CommandIsAdmin: true
  38.     # 掉落物设置
  39.     # 格式 Id 最小数量~最大数量 几率 子Id
  40.     DropItem:
  41.       - "351 1~5 50 0"

  43. # 提示
  44. Mes:
  45.   Immature: "§c还没有成熟"
  46.   Succ: "§a成功采取"
