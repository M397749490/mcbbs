MiniAnni Recoded
简介
2015年，群雄争霸面世了，它引发了一波群雄争霸的热潮。这次的群雄争霸与以往的不一样，它是迷你版，意味着你只需要花费更加的资源就可以体验到群雄争霸！接下来跟随我的步伐，深入探索群雄争霸迷你版的重置版吧！

安装与使用
此插件比较依赖前置，在安装此插件到你的服务端之前，请确保你的服务端已安装下列插件：
  • Vault
  • Lobby & Maps （慢慢加载）
  • LuckPerms 或 PermissionsEx （自行寻找）

特点与机制
  • 坐拥四支队伍
  • 拥有四个阶段
  • 支持 ActionBar
  • 每个队伍的核心有 75 血
  • 个人的末影箱
  • 个人的随身熔炉
  • 通过金锭购买物品的武器商店
  • 可再生的矿物和树木等等
  • Boss 将在第三阶段生成
  • 在大厅内选取游戏地图
  • 职业 - 在大厅或者游戏内通过一些预先设定好的方式选择
  • 通过背包（E）内的物品选择职业
  • 通过背包（E）内的物品投票选取地图
  • 输入 /stats 统计你的游戏数据
  • 输入 /distance 查看你与你队伍核心的距离
  • 在第三阶段开始时在地图的中心生成钻石
  • 在第三阶段开始时在地图的中心生成 Boss
  • 有通过金锭购买物品的酿造商店
  • 击杀 Boss 会掉落强力药水
  • 从第五阶段开始核心受到的伤害会加倍
  • 加入队伍通过输入 /red /yellow /green /blue 或使用告示牌
  • NPC 僵尸拥有反战斗功能
  • 支持斯洛伐克语、捷克语和英语（由于午申的存在，多了一个中文）
  • 可以自定义语言
  • 支持 MySQL 储存信息
  • 支持 Craftbukkit (1.8.x, 1.9.x, 1.10.x, 1.11.x, 1.12.x, 1.13.x, 1.14.x, 1.15.x)
  • 支持 Spigot (1.8.x, 1.9.x, 1.10.x, 1.11.x, 1.12.x, 1.13.x, 1.14.x, 1.15.x)
  • 支持 PaperSpigot (1.8.x, 1.9.x, 1.10.x, 1.11.x, 1.12.x, 1.13.x, 1.14.x)

机制详解
一局游戏包括五个阶段：
  • 阶段 I：
核心为不可破坏的状态直到该阶段结束
  • 阶段 II：
核心不再维持不可破坏的状态
  • 阶段 III：
钻石将会在地图中间生成
Boss 将会生成
  • 阶段 IV：

  • 阶段 V：
核心将受双倍伤害

命令与权限
命令
  • /manni - 帮助指令
  • /manni start - 开始游戏（默认管理员拥有）
  • /team - 显示游戏信息
  • /team red 或 /red - 加入 RED 队
  • /team yellow 或 /yellow - 加入 YELLOW 队
  • /team blue 或 /blue - 加入 BLUE 队
  • /team green 或 /green - 加入 GREEN 队
  • /vote <id/map> - 使用地图对应的ID或地图名字为下一个地图投票，ID在右边的计分板上
  • /stats - 查看你的数据，包括杀人数、核心摧毁数和死亡数等
  • /distance - 查看你离 RED 或 YELLOW 或 GREEN 或 BLUE 队核心的距离
  • /class - 打开职业菜单选择或改变一个你的职业（默认管理员或有权限的人拥有）
  • /map <edit/save> <map_name> - 这个指令是为管理员提供的，你可以用这个指令编辑地图
权限
职业：
  • minianni.class.archer : 射手
  • minianni.class.miner : 矿工
  • minianni.class.fighter : 战士
  • minianni.class.healer : 牧师
  • minianni.class.jumper : 技师
  • minianni.class.pyro : 操焰者
命令：
  • minianni.command.start : 允许使用 /anni start
  • minianni.command.class : 允许使用 /class
  • minianni.map.edit : 允许使用 /map edit <map name>
  • minianni.map.save : 允许使用 /map save <map name>
其他：
  • minianni.bypass.teamlimitor : 允许你在大厅或正在运行的游戏中改变队伍
  • minianni.bypass.teamlimit : 允许你加入一个满员的队伍
  • minianni.bypass.phaselimiter : 允许你在一个不允许加入游戏的阶段中加入游戏

教程
如何重置地图？
步骤 I：
在开头处下载 MiniAnni 地图，下载后打开文件并全部解压，将解压出来的 Trees 文件拖动到 plugins/MiniAnni/backup
步骤 II：
到 plugins/MiniAnni 中打开 config.yml 文件找到 WorldReset 条目并修改为下面的样式。
  1. #
  2. # 世界重置
  3. WorldReset:
  4.   Maps:
  5.   - "Trees"
  6. #
  7. # Boss 战利品设置

  9. # Boss 战利品设置
