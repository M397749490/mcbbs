可以用EntityOptions做什么？
首先，此插件允许您使用GUI 创建实体，包括怪物，动物和其他这样的NPC。
插件的想法是使它更容易修改这个实体，改变属性，如他们的名字、装备等。
您可以在下面找到您可以更改的所有实体属性。

特点 | Feature
  • - 用于实体创建和编辑的GUI
  • - 实体编辑器工具包禁用和启用实体
  • - 保存实体
  • - 删除实体
  • - 修改实体属性：
  • 设置自定义名称
  • 设置装备
  • 设置生命
  • 设定产生的实体数量
  • 设置外观（适用于 >　羊，村民，马，鹦鹉）
  • 需要持久性
  • 没有声音
  • 免受攻击伤害
  • 自定义名称可见
  • 可以拾取物品
  • 支持1.8-1.12版本




指令&权限 | Cmd And Permissions
命令

-/eo -> 命令开始创建一个实体
-/eo editor -> 给你用来编辑实体编辑器工具包
-/eo savedlist -> 显示已经保存的实体
-/eo info -> 插件信息
-/eo help -> 插件帮助

权限
- entityoptions.use 管理员权限





使用方法 | Instructions
[ 基础-One ]



创建实体 ->>


要创建一个实体你需要使用命令/eo 打开面板，您可以在其中选择所需实体的类型。
有四种类型：MONSTERS, ANIMALS, OTHERS 和 CUSTOM.。

除非先前在配置中保存了一个实体，否则CUSTOM类别将不会显示。

现在,选择实体来生成 然后,“Entity Editing”打开编辑界面 ,现在可以根据需要更改设置。
< 基础第二步-TWO >



[ 基础-TWO ]



编辑实体 ->>

要编辑一个实体,你需要使用命令/eo editor 然后你会收到一套编辑器。
玻璃控制实体AI 如果您右键单击一个实体与您的手中的项目 激活/停用
用于停止实体的移动和攻击。

界面总览


设置自定义名称 >>         (查看图片)

点击 Nametag 设置实体的名称,当你选择之后界面将会关闭,你只需要在聊天窗口输入自定义名称即可


设置生命值 >>  

与自定义名称相同, 需要在聊天框输入实体的生命值

生成实体的数量 >>         (查看图片)

在这里您可以设置想要产生的实体数量,仅在创建实体的时候有效


额外选项 >>

目前有7个额外的选项，只需要点击这些选项来激活或停用. < 绿色 = 激活, 红色 = 停用 >

设置外观 >>       (查看图片)

目前，此选项仅适用于羊、马、村民.
它设置实体的外观和类型，例如: 羊的颜色

装备设置 >>

设置非常简单,只要把你想要的装备放在各自的位置.您可以点击装备或武器,设置相应项目的掉落几率.
如果设置为100实体只会掉落那一个物品

保存实体 >>      (查看图片)

保存之后所有的配置会储存在 config.yml 方便更改,当然也方便你重新生成 不需要在配置
