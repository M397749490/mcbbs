自定义跳板 Custom Jumppads
小游戏服必备！高度自定义跳板插件！

简介

  • 小游戏必备跳板插件！
  • 支持高版本！
  • 可高度自定义，包括：飞行距离，角度，特效粒子 等
  • 完全免费！
  • 无需任何前置插件！

原文简介：
Custom JumpPads is a super smart JumpPads plugin featuring independent JumpPads. Each JumpPad is assigned its own power level, angle value, pressure plate type (or slime block) in-game, particle type, launch effect, and more which means there is almost no setup at all! Drag & Drop the plugin and start creating all the JumpPads you need!

指令

  • /jumppads（以下所有开头指令皆可使用简写 /jp）  帮助指令
  • /jumppads create <力量> [角度]  创建跳板（可对跳板和粘液块使用）
  • /jumppads delete  删除跳板
  • /jumppads set <属性> [值]  给跳板设置属性
  • /jumppads info  查看瞄准的跳板的相关信息
  • /jumppads list [页码]  列出所有跳板
  • /jumppads reload  重新加载配置文件

权限

  • jumppads.help
允许玩家查看帮助

  • jumppads.create
允许玩家创建跳板

  • jumppads.delete
允许玩家删除/破坏跳板

  • jumppads.set
允许玩家使用Set指令

  • jumppads.use
允许玩家使用跳板

  • jumppads.reload
允许玩家重载配置文件

  • jumppads.maxpower.bypass
允许玩家创建超过最大力量限制的跳板

  • jumppads.info
允许玩家查看跳板信息

  • jumppads.list
允许玩家列出所有跳板

  • jumppads.list.teleport
允许玩家传送至跳板列表内的跳板

  • jumppads.update
允许玩家收到插件更新信息
