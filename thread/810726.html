插件介绍
你有没有想过去带一个刷怪笼回家？
silkspawners让你可以带走刷怪笼（甚至支持mod）
现在你可以用带有精准采集的镐子采集刷怪笼
普通的稿子则会掉落相应的刷怪蛋
当然也允许刷怪笼的合成
你可以控制每一刷怪笼掉的刷怪蛋的数量，让配置更加容易！
注意：这个插件需要JAVA8支持!!!!!!!!!!!!!!!!!!

插件截图




特征
1.添加BarAPI支持（仅支持1.9 +：支持Vanilla成就）

2.支持编辑每种刷怪笼的名字和是否会爆炸！

3.支持游戏版本：1.5-1.12.2

4.可以设置在爆炸中刷怪笼掉落的概率

5.刷怪笼会存储被刷的生物类型

6.支持所有刷怪笼

7.支持所有刷怪笼的制作（如果需要的话每个生物都有自己的配方）

8.当刷怪笼被放置、破坏或在背包时显示被刷的生物类型

命令
/ss help -  显示帮助菜单
/ss list|all - 显示所有的合成
/ss view - 显示所预览的刷怪笼信息
/ss reload|rl - 重新加载配置文件
/ss change|set <新生物类型> - 更改所拿着的或所看的刷怪笼的生物类型
/ss give|add <玩家> <生物类型> [数量] - 给与玩家所选生物类型的刷怪笼或刷怪蛋（数量是可选的）
/spawner - 查看刷怪笼信息
/spawner [生物类型] - 修改刷怪笼的生物类型
/spawner [生物名] - 获得指定的刷怪笼
/egg [生物名] - 获得指定的刷怪蛋
如果未找到权限插件，则所有命令仅适用于OP！

权限
silkspawners.*  - 给予所有权限（非默认权限）
silkspawners.info - 允许玩家在放置或破坏刷怪笼时获得刷怪笼的信息（默认权限）
silkspawners.viewtype  - 允许使用 /spawner 来查看刷怪笼信息（默认权限）
silkspawners.reload - 允许使用/ss reload 来重新加载配置文件（op权限）
silkspawners.place.* 或 silkspawners.place.<生物类型> - 允许玩家放置刷怪笼（默认权限）
silkspawners.craft.* 或 silkspawners.craft.<生物类型> - 允许玩家合成刷怪笼（默认权限）
silkspawners.silkdrop.* 或 silkspawners.silkdrop.<生物类型> - 允许玩家使用精准采集获取刷怪笼（默认权限）
silkspawners.destroydrop.* 或 silkspawners.destroydrop.<生物类型> - 允许玩家破坏刷怪笼时可获得配置过的掉落物（默认权限）
silkspawners.explodedrop - 允许玩家可以获得爆炸后的刷怪笼所配置过的掉落物（默认权限）
silkspawners.changetype.* 或 silkspawners.changetype.<生物类型>  - 允许玩家修改刷怪笼的种类 /spawner [生物名] （op权限）
silkspawners.changetypewithegg.* - 允许玩家通过手持刷怪蛋左键点击刷怪笼来修改刷怪笼的生物类型（op权限）
silkspawners.freeitem.* -  允许玩家使用/spawner [生物名] （op权限）
silkspawners.freeitemegg.* 或 silkspawners.freeitemegg.<生物类型> - 允许玩家使用 /egg [creature]（op权限）
仅支持bukkit！
如果未找到权限插件，则所有命令仅适用于OP！
