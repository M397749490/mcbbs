我不认为文件名会影响你的正常使用,除非作者吃饱没事加了个没有什么用还坑用户的文件名验证.这很智**.
所以你只需要活学活用就可以了.

#1 为啥他的使用指南要你改名为nide8auth.jar
这样可以方便你直接复制下面的参数粘贴,如果你的文件名不一样那会导致复制的代码无效.

#2 那咋办嘛
很简单.
在原有的命令行上添加以下红色部分参数，其他不要更改，以下只是范例：
java -javaagent:nide8auth.jar=12345678912345678912 -Xmx1024M -Xms1024M -jar minecraft_server.jar nogui

原文是这样.
所以你只需要这样:
  1. java -javaagent:{nide8auth.jar修改后的文件名}={他送给你的一串诡异token} -Xmx1024M -Xms1024M -jar minecraft_server.jar nogui
复制代码
