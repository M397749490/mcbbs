服务器里用npc自带的音乐感觉好low
便四处去找添加npc音乐的方法
找来找去也没找到
(吐槽:npc 1.6.4版本后就不能直接加音乐了 好坑)
后来自己摸索还摸索出来了

接下来我就分享一下我的方法 如有帮助请回一下贴

开始正文:

12步骤都必须完成


1.歌曲转格式:

首先你得下载一个要装进去的歌曲
一般是.mp3格式的
但是我的世界只支持.ogg格式
此时你就要转换格式了
我这里有一个转格式的工具
下载地址: https://pan.baidu.com/s/1dFCBMmd

加入npc mod教程:
找到你的npc mod
右键用压缩文件打开如图所示:

依次打开assets\customnpcs\sounds

在这里面创建一个文件夹 最好不要是中文
可能会乱码 我这里创建了个A的文件夹
将你要的转格式后的音乐放进去
改个名字 最好是英文

我这里弄得abc.ogg



2.实现在游戏里使用该音乐的方法
在压缩文件目录assets\customnpcs下找到sound.json
最好用Notepad++打开 注意了这里重要(对于编程小白，当然大神可以直接按照下面的配置文件弄)
不出错的情况下把文件打开后拉到底如图所示:

然后点这里

回车空一行

并删除这个空格变成这样

接下来放出代码


  1. },
  2. "abc": {
  3. "category": "player",
  4. "sounds": ["A/abc"]
复制代码

如果是比较长的音乐
请用这个代码 不然会卡很久
  1. },
  2. "abc": {
  3. "category": "player",
  4. "sounds": [{"name": "A/abc", "stream": true}]
复制代码


复制这个代码直接粘贴在上面红圈那里
abc是名字可以随便输
A/abc就是目录啦


3.成功





最后保存使用完工
