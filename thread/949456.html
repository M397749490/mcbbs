要点：安装指令
echo "deb [trusted=yes] https://yadominjinta.github.io/files/ termux extras" >> $PREFIX/etc/apt/sources.list && pkg in atilo-cn

使用范例：atilo pull ubuntu （安装ubuntu）（不要复制括号里的）

                 atilo run ubuntu（启动ubuntu）

在这里我的教程已经结束了，其余部分参考第一个链接即可（其实开过服的都知道了），你可以通过wget获取jar包，更简单
最后给一个一键安装java环境＋必须工具的命令
apt install unzip openjdk-11-jre-headless wget nano screenfetch -y


如果觉得速度慢到**请更换镜像源

cd /etc/apt
sed -i "s/ports.ubuntu.com/mirrors.aliyun.com/g" /etc/apt/sources.list
