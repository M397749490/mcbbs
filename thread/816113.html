  • 插件更新通知

命令
/lapisbans [player|import|rollback|help]:
  • 没有任何参数时将会展示插件信息
  • Player:执行此命令需要输入玩家用户名，例如: "/lapisbans player dart2112". 这将显示该玩家的惩罚信息
  • Import: 此命令可以将其他插件封禁信息导入到本插件，例如： "/lapisbans import advancedban".这将会导入advancedban插件的信息，他还支持导入以下插件 : advancedban, Essentials, vanilla,Maxbans, MaxBansPlus.
  • Rollback: 该命令需要指定玩家并可以选择[before|after] [time]例如： "/lapisbans rollback dart2112" 将会清除dart2112玩家的封禁记录. 但是使用 "/lapisbans rollback dart2112 after 1 hour 30 minutes" 指令就会清除之前1小时30分的封禁记录(保留1小时30分之内的)
  • Help: this command will display the help text for every lapisbans command, be warned that there are more messages then can fit on the screen so you will need to scroll（简单一句：显示插件帮助）
/ban [username] [time] [reason|-silent|-shadow]:
  • username：玩家必须进入过服务器
  • time: 时间由正整数与时间单位组成,例如："1 hour 30 minutes 5 seconds"，请不要在时间内输入其他文字，否则不会正常检测并会到理由中，如果没有设置时间，那么就是永久封禁
  • reason: 封禁原因
       -silent : 沉默标签，使用此标签玩家被封禁后不会公告通知
       -shadow : 影子标签，使用此标签后操作的玩家不会进行任何操作（像essentials的监狱）
/history [username|IP address]:
  • 命令别名： /lapisbanshistory 用于已经有 /history 命令的服务器
  • 必须是经服务器的玩家或IP, IP地址必须是自插件安装以来已经加入的玩家。
  • 这个命令将返回一个已经应用于给定用户名或 IP 地址的所有惩罚的清单，其中包括任何已经过期或已经取消的惩罚
/ipban [username|IP address] [time] [reason|-silent|-shadow]:
  • IP必须是自本插件安装以来内的玩家的IP，因为我们使用用户名查找玩家ip
  • 有关时间，理由，标签请查看/ban [username] [time] [reason|-silent|-shadow]以下的信息
/iplookup [username|IP address]:
  • 玩家与IP必须是自插件安装以来的
  • 如果给出用户名，将会返回该用户的IP地址，反之给出用户名
/kick [username] [reason|-silent]:
  • 必须进入过服务器
  • 有关时间，理由，标签请查看/ban [username] [time] [reason|-silent|-shadow]以下的信息(-shadow标签只能用于禁止命令)
/mute [username] [time] [reason|-silent]:
  • 必须进入过服务器
  • 有关时间，理由，标签请查看/ban [username] [time] [reason|-silent|-shadow]以下的信息(-shadow标签只能用于禁止命令)
  • 禁止玩家聊天以及输入指令，聊天命令可在config.yml文件里配置
/staffhistory [username]:
  • 命令别名 :  /lapisbansstaffhistory 用于已经有 /staffhistory 的服务器
  • 该命令将显示由玩家或控制台给出的惩罚，使用console将显示控制台以及自动警告系统给出的惩罚
/unban [username|IP address]:
  • 该玩家/IP必须被封禁
  • 解封玩家/IP
  • 如果你使用IP地址，那么只有IP ban才能取消(?)(雾)
/unmute [username]:
  • 解除禁言
/unwarn [username] [before|after] [time]
  • 前后的时间与/lapisbans的回滚命令(Rollback)大致相同, 请参考回滚命令的时间格式
  • 如果没有设置时间将会删除所有警告记录
/warn [username] [reason|-silent]:
  • 这个命令与/ban命令用法大致相同。不能使用影子标签
  • 在 config.yml 中，您将会找到一个警告命令列表，如果玩家已经收到了在该行开始时声明的警告数量，则该命令将被运行。 这些命令不一定是 Lapis Bans 命令，但是它们需要在控制台上使用，因为它们是通过控制台执行的。 在列表上方的注释中，有一些变量可以在任何命令中自由使用。 如果没有对当前警告数目的命令，就不会运行命令。 试着添加一些命令，这些命令可以在玩家离线时使用，因为不管玩家是否在线，这些命令都会运行
  • 如果你给了离线玩家一个警告，那么该玩家将在他上线时收到警告
