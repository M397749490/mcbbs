cmifix —— 基于CMI与BentoBox的BUG修复

插件特性
  • 轻量级
  • 无需配置
  • 如果觉得好用的话~点赞评分一下下呗~

插件前置
  • CMI
  • BentoBox

BUG介绍
  • 当CMI的的地标<包括[home,warp,悬浮字,spawn]>坐标为空岛地图时
  • 服务器首次开启或重启后
  • CMI会丢失这些地标直到管理cmi reload

插件原理
  • 当服务器首次开启或重启后第一个玩家进入服务器时
  • 插件将自动重载CMI插件

插件权限
  • 无

插件源码






    @EventHandler
        public void onJoin(PlayerJoinEvent event) {
            if (Bukkit.getOnlinePlayers().size() <= 1 && CmiFixConfig.getInstance().getCheck().equals("false")) {
                Bukkit.dispatchCommand(Bukkit.getConsoleSender(),"cmi reload");
                CmiFixConfig.getInstance().setCheck("true");
            }
        }


特殊姿势
  • 该BUG在我的服务器内存在，我并不清楚是否只为偶然性

这个bug产生的原因是因为在服务器重启时候加载插件的前后顺序导致的，你会发现 bentobox 相关插件都在最后加载，从而导致前面cmi里某些设置失效，正因为这个原因，不单单cmi和bentobox，很多插件(比如：CrateReloaded的抽奖箱位置)也因此要在重启后再进行重载，讲道理这插件很不错，就是解决方面不够彻底，不过还是要支持一下原创插件。。
