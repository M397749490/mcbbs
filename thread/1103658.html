女仆数量上限的调整方法：
打开 <服务端根目录>\config\TouhouLittleMaid.cfg，
  1.         # The maximum number of maids the player own.
  2.         # Min: 0
  3.         # Max: 2147483647
  4.         I:OwnerMaxMaidNum=2147483647
复制代码

将 2147483647 改为你需要的数字即可。

记得重启服务端，如果不重启是不会生效的。
