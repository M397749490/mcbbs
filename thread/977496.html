作者: 481624466    时间: 2020-3-5 17:15
textures 文件夹：存放材质
blocks 文件夹：方块材质
entity 文件夹：实体材质
environment 文件夹：自然环境材质
gui 文件夹：GUI界面材质
items 文件夹：物品材质
map 文件夹：地图材质
models 文件夹：装备模型材质
painting 文件夹：画材质
particle 文件夹：粒子特效材质
ui 文件夹：未分类的UI材质
wallpaper 文件夹：游戏界面材质
flame_atlas.png 火焰燃烧材质
forcefield_atlas.png 力场材质
ui 文件夹：UI 及其说明文件
manifest.json 说明 信息文件

pack_icon.png 材质包 图标
