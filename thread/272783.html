安装：



Installation GuideForge
  • Before you install you need to have ran the Minecraft version atleast once (you can select your version in the game profile from the minecraft launcher)
  • Download the recommended forge installer for the verions you need
  • Select that you want to install the client
  • Press ok
  • Run minecraft once to check if it correctly installed (make sure there are no outdated mods in the mods folder)
  • Locate the .minecraft/mods folder
    • Open minecraft
    • Go to Options -> Resource Packs
    • Press the open resource pack folder button
    • This should bring you to the .minecraft/resourcepacks folder
    • Go up one folder and go into the mods folder
  • Now simply drag the .jar or .zip into the mods folder
  • You can now start minecraft and the mods should be installed
