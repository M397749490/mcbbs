总览

ChessCraft让你在MC的世界里也能下国际象棋了！

它可以支持多棋盘，可以同时开始多个棋局，你可以和玩家对战或是同各种难度的电脑一决高下。


特性
  • 你可以在多世界里创造无限多的棋盘, 玩家们同时开始好几个棋局也不是问题
  • 有多种棋盘和旗子样式可选 (已经预置了几种)
  • 权限插件：支持  (通过 Bukkit superperms)
  • 所有经济插件都支持 - 可对棋局下注
  • 可与人类玩家或是AI对战 (使用jChecs AI engine)
  • WorldEdit 支持 - 当棋盘被删除时可以恢复地形
  • ScrollingMenuSign插件：支持 - 可以创建关于棋局/棋盘的便捷命令牌子
  • Leaderboard插件：支持 显示服务器里的最高分玩家
  • 集成了 棋子设计功能
  • 翻译 - ChessCraft的文本消息可以被翻译为其他语言 中文汉化：白宝石汉化组
  • 可将棋局导出为PGN格式的棋谱

安装
  • 将ChessCraft.jar复制到你Bukkit服务端下的plugins目录中.
  • 可选项: 如果你想要使用Economy经济插件, 你需要安装一个Vault插件.
  • 可选项: 如果你安装了WorldEdit, 当棋盘被创建时原地形会被自动备份 (移除棋盘时会自动恢复). 需要WorldEdit的版本至少在v5.3以上 - WorldEdit-5.3-SNAPSHOT或者更早版本无效.
  • 可选项: 如果你安装了ScrollingMenuSign插件, ChessCraft会自动为棋盘/棋局管理创建控制面板，详情请点击这里.
  • 重启或者reload你的服务端.

安装须知
  • 千万不要使用PEX 1.18: PEX 1.18 会忽视plugin.yml文件中定义的默认值，因此基本没法用。PEX 1.19, 1.17还有 1.16 都没这毛病.
  • Vault需要的版本为v0.5以上.

插件命令
管理员命令

如果你使用了某个权限插件, 你需要拥有op身份, 或是拥有chesscraft.admin 和/或 chesscraft.commands.command 权限节点来使用这些命令。如果没用权限插件，你需要是op.

创建棋盘/chess create board 棋盘名称 [-style 棋盘样式名称] [-pstyle 棋子样式名称]
删除棋盘
/chess delete board 棋盘名称
删除棋局/chess delete game 棋局名称
设置/获取配置
/chess setcfg 属性 值
/chess getcfg [属性]
重新读取棋局状态/chess reload {ai|config|persist}
改变棋盘样式
/chess board set <属性> <值>
保存棋盘样式
/chess board save [<新样式名称>]
创建棋局/chess create game [棋局名称] [棋盘名称
显示棋盘信息
/chess list board [棋盘名称
显示棋局列表
/chess list game [棋局名称
设置或显示棋局
/chess game [棋局名称]
设置棋局赌注
/chess stake
邀请玩家
/chess invite [玩家名称
加入棋局
/chess join [棋局名称
开始棋局
/chess start
用命令移子
/chess move 来源方格 目标方格
请求和棋
/chess offer draw 对方用/chess yes或/chess no来回应
请求换子
/chess offer swap对方用/chess yes或/chess no来回应
设置士兵下底升变的类型
/chess promote 棋子名称   (用N, B, R, Q表示骑士, 主角, 战车, 王后，只对当前棋局有效,默认王后)
认输
/chess resign
瞬移来到/离开棋局
/chess tp [棋局名称]
瞬移到棋盘
/chess tp 棋盘名称 -b
写入PGN棋谱文件
/chess archive
查看Leaderboard
/chess list top [<项数>] [<查看类型>]

权限节点设置
简单设置方法可以快速应用
  • 给予管理员chesscraft.admin节点
  • 给予你想允许他下棋的玩家chesscraft.basic节点

详细设置方法如果上面的简单设置方法不能满足你的需要，你可以使用以下这些节点赋予玩家使用独立的命令的权利。每个节点都直接对应一个ChessCraft命令, 例如想让玩家使用/chess create board命令，你需要分配给他chesscraft.commands.create.board这一节点.管理员用:
  • chesscraft.commands.create.board
  • chesscraft.commands.delete.board
  • chesscraft.commands.delete.game
  • chesscraft.commands.redraw
  • chesscraft.commands.getcfg
  • chesscraft.commands.setcfg
  • chesscraft.commands.save
  • chesscraft.commands.reload
  • chesscraft.commands.board.set
  • chesscraft.commands.board.save
  • chesscraft.commands.design

普通玩家用:
  • chesscraft.commands.create.game
  • chesscraft.commands.invite
  • chesscraft.commands.join
  • chesscraft.commands.move
  • chesscraft.commands.offer.draw
  • chesscraft.commands.offer.swap
  • chesscraft.commands.resign
  • chesscraft.commands.archive
  • chesscraft.commands.tp
  • chesscraft.commands.win
