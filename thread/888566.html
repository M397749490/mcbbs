/summon villager ~ ~1 ~ {VillagerData:{profession:2,type:1,lvl:2},
Offers:{
Recipes:[
{maxUses:2100000000,buy:{id:wheat,Count:18},sell:{id:emerald,Count:1},priceMultiplier:1,demand:1}
]
}
}

  • 版本：1.14
  • 这是我的自定义村民代码，由早期版本（1.11）改过来的，为了观看方便，我删去了一部分交易内容
  • 召唤出来的村民是一个无职业村民，右键会一闪而过交易列表然后关闭，截图显示交易是对的
  • 在他的身边放置堆肥桶之类的方块（赋予职业）会直接重置交易为原版交易
  • ====问题阐述：====

我的问题是：
请问这段代码怎么改才能做出一个自定义交易的村民？或者请给我教程的链接。

先放置出村民，并赋予职业，后使用data命令修改其Offers标签。

或者先放置该职业对应的方块，后在村民的nbt中添加如下内容
  1. Brain:{memories:{"minecraft:job_site":{Pos:[<x>,<y>,<z>],dimension:"miiinevraft:overworld"}}}
复制代码
其中Pos内填该工作站的坐标

或者直接将村民设置为NoAI
