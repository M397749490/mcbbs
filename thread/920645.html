打开你papi的插件文件夹
在javascripts文件夹里新建一个health.js的文件并编辑写入并保存
function hp() {
    return Math.round(parseInt('%player_health%') * 100) / 100;
}
hp();
然后编辑 javascript_placeholders.yml  文件  按格式写入
health:
   file: health.js
然后重启
