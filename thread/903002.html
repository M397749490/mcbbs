权限互交？？
没有破坏权限？
这个简单。Builder权限组拥有普通玩家全部基本权限指令，1.7.10改版以后玩家默认权限组改成Default。
1.GroupManager\worlds\world文件下打开groups.yml文件，从1.7.10版本以后玩家默认权限组都是Default的了所以才没有权限互交。
groups:
  Default:
    default: false
    permissions:
    - -bukkit.command.kill
    inheritance:    - Builder      在这里添加Builder继承权限组
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    info:
      prefix: '&e'
      build: true
      suffix: ''
  Builder:
    default: false
    permissions: []
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      prefix: '&2'
      build: true
      suffix: ''这个……文件修改我忘了，应该是这样该的，不记得了。这个是给玩家进入游戏默认就是Builder权限组，如果玩家还是Default权限组的话也不荒。在Default下的inheritance:添加：- Builder继承权限。


这个方法我不怎么记得了，你可以试者改一下。
方法二：
在permissions:下添加essentials.build、essentials.build.break.*两个权限即可，但有个严重问题。这个问题就是没有tp，回家，设置家等的权限。
这个解决方法就是一条一条的添加，适合搭配就行了。这个是基础插件的权限链接：http://mineplugin.org/Essentials ... 0.E8.8A.82.E7.82.B9
Default:
    default: false
    permissions:    - essentials.build
    - essentials.build.break.*
    - -bukkit.command.kill
    inheritance:
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    info:
      prefix: '&e'
      build: true
      suffix: ''


权限组的命令：
/mangadd 名称        创建权限组          例如：/mangadd VIP
/mangaddp  权限组名称     给权限组添加权限          例如：/mangaddp Default essentials.build
/mangaddi   权限组名称     权限组名称    继承权限组        例如：/mangaddi Default Builder


推荐另外一款权限组：LuckPerms，有兴趣可以研究一下！
