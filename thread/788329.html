用的Project Worlds多世界插件和Luckperms权限插件，权限我都看过了好像也没有相关的
作者: 838652229    时间: 2018-4-3 13:48
tanzhang3897 发表于 2018-3-27 12:00
用的Project Worlds多世界插件和Luckperms权限插件，权限我都看过了好像也没有相关的 ...

Essentials插件里：
# 设置该项为true为每个地标启用单独的传送权限.
per-warp-permission: false

# 设置为true,启用每个世界传送单独的权限.
# 支持 /world, /back, /tp[a|o][here|all],但是不支持 warps.
# 给予玩家某个世界的传送权限 essentials.world.<worldname>
# 不包括 /home 命令, 下面有单独的设定.
world-teleport-permissions: true

要么你就在权限插件里加上：
- essentials.worlds.*
