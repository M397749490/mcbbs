Control All Complete

Control All complete(CAC)是一款管理用的

插件，它能提供一些简单的功能，使得服务器的OP能同时对所有玩家进行操作。

(PS：该插件刚刚发布不久至少搬运的时候只发了一天，功能与适用版本比较少，耐心等待作者更新)

功能:
管理员能设置所有玩家的游戏模式
管理员能开关玩家的fly模式(开启能飞，同时无视掉落伤害)
管理员能清空玩家的所有物品
管理员能向所有玩家发送消息(能吸引玩家注意力，还能通过多频道发送)

命令&权限:
  • /cac                                           查看所有指令                    cac.command.cac
  • /cac setgm <游戏模式>         改变全局游戏模式                 cac.command.setgm
  • /cac setfly <on|off>           同时开关玩家的飞行模式          cac.command.setfly
  • /cac clear                       清空所有玩家背包内所有物品      cac.command.clear
  • /cac msgall <消息>              给所有玩家发送消息               cac.command.msgall
  • 以上所有指令                       以上所有指令的权限               cac.command.*
  • 无                 拥有该权限玩家不会被/cac clear清除背包     cac.exempt.clear
  • 无          拥有该权限玩家不会被/cac setfly改变飞行状态    cac.exempt.setfly
  • 无                              该权限包含了以上两条权限的功能    cac.exempt.*
  • 无                                                       该插件的全部权限    cac.*
