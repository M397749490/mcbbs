当你的服务器更新MOD的时候

,是否会有一堆玩家来问怎么更新MOD

，是否要为上传超级大的客户端而烦恼

，是否为玩家下载客户端的速度超级慢而烦恼。

本软件可以让您快速解决这个烦恼

，只需配置一次，即可一劳永逸

，并且本软件自带在线更新

，(没有后门),您只需要在您的服务器上传MOD后在储存服务器上上传并编辑JSON即可

，玩家只需点击按钮，即可自动同步MOD



配置教程



关于使用第一步

您需要有一个阿里云OSS储存

并创建一个bucket 并设置为读写权限公共读

里面创建一个文件夹名字为ServerMod(可以自己起名)

第二步在文件夹里创建一个文件夹MOD(可以自己起名)

并上传自己的MOD（客户端MOD）

第三步在自己的电脑上创建一个JSON 并命名为Servermod

并写入以下东西


{
  "Version":"1.0.0.0",
  "ServerVersion":"1.0.0.0",
  "Updateurl":"",
  "LastUpdateTime":"",
  "ModListName":[],
  "ModListDownLoad":[]
}
第四步 下载配置软件并打开

选择文件目录选择你的MOD目录

下载文件前置 在OSS储存里 随便上传个文件 找到下载地址

http://Test.oss-cn-beijing.aliyuncs.com/MineCraftServerV1/mod/Gun.jar

例如上面的连接 我们只需要

http://Test.oss-cn-beijing.aliyuncs.com/OSS储存里的MOD文件夹

填入在前置连接里 点击确认

然后点击左下角 载入并刷新文件 左右文件框就会出现配置文件

左面的名称输出框里的东西 全部选择 CTRL+A CTRL+C

然后找到你的Servermod.json文件并写入

{
  "Version":"1.0.0.0",
  "ServerVersion":"1.0.0.0",
  "Updateurl":"",
  "LastUpdateTime":"",
  "ModListName":[左面输出的东西 删掉最后的逗号],
  "ModListDownLoad":[右面输出的东西 删掉最后的逗号]
}

示例
{

{
  "Version":"1.0.0.0",
  "ServerVersion":"1.0.0.0",
  "Updateurl":"",
  "LastUpdateTime":"",
  "ModListName":["Test1.jar","Test2.jar","Test3.jar"],
  "ModListDownLoad":["https://下载地址前缀/"Test1.jar","https://下载地址前缀/"Test2.jar","https://下载地址前缀/"Test3.jar"]
}

保存即可并上传到OSS 复制下载链接

然后打开软件 会提示缺少配置文件

点击软件左上角的软件 设置

第一个设置文件夹目录 建议吧这个软件放在和启动器同一个目录

所以默认就可以这么写

./.minecraft/mods

这个路径是相对路径

下面的更新配置文件下载URL就是你写好并上传的JSON下载地址

启动器选择

你就可以直接写你启动器的名字(必须相同目录)

例如我用的是PCL 那么我就可以写 PCL.exe 一定要带后缀

如果我要把这个程序改名为开始游戏

那么上面主程序名称一定要改为开始游戏

因为不进行更改是不可以在线更新软件的(不更新软件不可以同步MOD)

点击保存

然后隐藏以下文件即可
