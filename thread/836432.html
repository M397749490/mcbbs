  • 我需要详细的教程教我如何关闭龙之的爆炸
  • 能不能修改爆炸的范围

作者: hua2hua    时间: 2019-1-3 18:45
打开服务器的 config/DraconicEvolution.cfg

# Configuration file

"draconic reactor" {
    # Setting this to false will reduce the reactor explosion to little more then a tnt blast
    B:EnableBigExplosion=true

# 配置文件

"神龙反应堆" {
    # 设置为 false 将反应堆修改为 TNT的爆炸程度
    B:启用反应堆爆炸=true
