该贴主要为一些cs4支持的某些奇奇怪怪的功能整合贴，该贴可能更新缓慢(发掘新内容挺慢的嘛)
下面是这些功能的一些介绍与教程

一：同一流体之间是否生成新的流体（无限水）


    {
      "type": "fluidModifier",
      "entries": [
        {
          "block": "minecraft:flowing_water",
          "canCreateSource": true
        },
        {
          "block": "minecraft:flowing_lava",
          "canCreateSource": true
        }
      ]
    },

"block"=流体的英文ID
"canCreateSource"=是否可以创建新的流体方块

就是可不可以生成无限水

代码也是很简单的，有添加文本，改变按钮的文本，删除按钮


        {
      "type": "guiModifier",
      "entries": [
        {
          "gui": "ingameMenu",    #按钮位于界面的ID
          "labels": [
            {      #添加位于xxxxx的esc文本
              "offsetX": 2,    #文本的x轴
              "offsetY": -2,  #文本的y轴
              "alignX": "left",  #文本xy轴的相对位置
              "alignY": "bottom",   #文本xy轴的相对位置
              "text": "某玖_Damon"   #文本内容
            }
          ],
                  "editButtons": [    #改变按钮的文本
            {
              "buttonId": 4,    #按钮ID
              "text": "关闭菜单",   #文本内容
              "offsetY": ["25%", 8]   #文本的大小以及字体
            }
          ]/*,
          "removeButtons": [   #删除按钮
            7    #按钮ID
          ]*/
        }
      ]
    },
