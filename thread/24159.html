每周快照是Minecraft的测试机制，里面的新内容会被包含到下一个正式版里去。
请勿抱怨“更新太快”，这仅仅是预览版，BUG很多，仅做测试尝鲜用，不建议用于长期游戏。

http://www.mojang.com/2012/05/minecraft-snapshot-week-21/

Time for a new snapshot! One big difference this time is that you don’t need the server jar to play single-player. Also,
是时候发表新的快照了！这次最大的变化是你不需要服务端的jar来运行单人游戏了。而且：

  • Villagers will trade items (they are cheap bastards, though!)  村民能够交易物品（虽然他们是便宜的混蛋！）
  • Added a “currency item”        加入一个“货币物品”
  • A few minor terrain changes       一点点地形更新
  • A new useful block/item (requires obsidian)   一个新的实用方块/物品 （需要黑曜石合成）
  • Added a /seed command for showing the map seed  加入/seed命令显示地图种子
  • Added sandstone stairs     加入方块“砂岩楼梯”
  • A lot of smaller changes and fixes    很多小的改变与修正




  • 客户端： http://assets.minecraft.net/12w21a/minecraft.jar
  • 服务端： http://assets.minecraft.net/12w21a/minecraft_server.jar (或 EXE)

确认的情报：
新的方块Ender Chest“末路之箱”，可以远程访问箱子内存储的东西



沙砾Gravel的材质被改了



每一个村民会买/卖特定的某物品，用绿宝石/翡翠交换，翡翠也拥有自己的矿石。
1 emerald -> 6 melon slices
1 emerald -> 3 (sometimes 4) bread
14 books -> 1 emerald
1 emerald -> 8 cooked chicken
