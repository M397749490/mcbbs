Disguise 伪装

Duration 持续时间
Type 种类 Mob是怪物，Player是玩家，Misc是混合..应该是实体 方块吧
如果你选了Mob：
Mob - 怪物种类
Adult - 是否成年
如果你选了Player：
Player - 玩家名字
如果你选了Misc：
Misc - 实体名字
Date - 附加值

Explosion 爆炸

Power 爆炸等级
Damage block 是否炸坏方块
Fire 爆炸是否起火

Forget targets 忘记目标

类似于消除仇恨

Heal 生命恢复

Type 类型 Health数值恢复，Percent 百分比回复
Value 回复的值，如果是Percent就是回复的百分比

Held item 拿着物品..

Item 物品给予

好像是给玩家/目标一个物品
Material 物品名字
Amount 数量
Durability 耐久
Date 物品附加值
Custom 不清楚

Item projectile 物品弹射 （贼鸡儿多）

就是发出某个物品射别人
Item 发出的物品名字
Item date 附加值
Group 会被射的人的组....Enemy是敌人，Ally是盟友
Spread 范围 Cone是圆锥，Rain是大量的，Horizontal是水平圆锥
Amount 射出的数量
Velocity 射出的速度
Angle 范围的角度大小，就是圆的那个角，你懂的
Position 位置，不懂怎么用

Check name 是否检查物品名字
Regex 是否用正则表达式..

Launch 发射

F... 向前的速度
U... 向上的速度
R... 向右的速度

Lightning 雷电

在前方打出一个雷电
Damge 雷电伤害
F... 向前偏移
R... 向右偏移

Mana 魔法恢复

Type 类型 Mana是数值回复，Percent是百分比回复
Value 回复数值，如果是Percent就是回复百分比

Attribute 属性强化

Attribute 填属性名称
Amount 填属性数量，也就是加多少属性
Second 属性增长持续的时间

Block 生成方块

Shape 形状 Sphere是球形，cuboid是长方形
Type 种类 Air是气体，any是任何(?)，solid是固体
Block 方块 意思是生成哪种方块
Block date 是附加值 你应该懂
Seconds 持续时间
Forward offset 向前多少格生成
Up ... 向上多少格
Right ... 向右多少格
Radius 方块半径

Cancel 取消

不清楚

Channel 通道(?)

Channel使用期间玩家不能移动，攻击或使用其他的什么什么东西
其它不是很懂

Cleanse 净化

类似于牛奶
Potion 清除哪种DEBUFF
Status 应该是状态，但不清楚用法

Cooldown 冷却缩减

为自己的技能减少冷却时间
Skill 填减少冷却的技能名字
Type 类型 Seconds是减少秒数，另一个不懂
Value 减少的值


Damage 造成伤害
Type 类型 Damage是伤害，Mu什么的是乘，Percent Left 百分比减少??，Percent Missing 百分比闪避??
Value 伤害值
True Damage 应该是是否造成真实伤害 无法被防御力抵消的那种

Damage Buff 攻击BUFF

就是获得一段时间的攻击加成
Type 类型 Flat是平的，不懂意思，Mu什么的一样不懂
Skill Damage 是否造成技能伤害
Value 攻击加成的值
Seconds 持续时间

Damage Lore 攻击标签

为自己手上的东西加上   攻击: XX的lore(标签)
Hand 主副手 Main是主手，Offhand是副手，1.9才能用
Regex 标签的格式
Multiplier 又是这玩意 不懂！
True Damage 是否造成真实伤害 (前面提到了)

Defence Buff 防御BUFF

和攻击BUFF类似
翻译一样

Delay 延迟

这个可以理解为一个中介
让技能延迟释放，怎么用就不详解了
