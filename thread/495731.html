ess权限组插件怎么分世界管理？我的就只有一个world管理的
作者: xRPQx    时间: 2015-8-29 11:29

打开GroupManager
打开config
添加你要弄的世界,如下

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          plotworld:
          - users
          all_unnamed_worlds:
          - users
          - groups
          world1:
          - users
(红色的就是要添加的,world1可以变换成你想要的世界名，注意下面只要- user~~)
然后游戏里输入/manload
你会发现,worlds里面多了一个文件夹，进去修改group权限即可~

作者: 红菜头糕    时间: 2015-8-29 12:10
权限组插件config有这样一项
world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
按格式在下面编辑
          某分世界
          - users
编辑好后输入manload重载，这样就可以让某世界有自己独立的groups.yml文件，最后你去worlds里找到对应世界名字的文件夹打开编辑里面的yml文件即可
