——Elevator 炫酷的电梯——
简介(译文)：There are a lot of elevator plugins out there, and this is yet another version of them. Elevator is a simple lightweight elevator plugin that is inspired by more than one, and it is formed to be as easy as possible..（有很多电梯插件，而这个电梯插件是一个简单轻量的插件，它的灵感来自于不止一个插件）
功能：
  • 自定义电梯方块
  • 自定义粒子和下降上升的音效
  • 权限控制玩家是否能使用电梯
  • 自定义消息

使用方法:
在配置文件设置电梯方块，拿着你自定义的电梯方块搭建电梯就像上面的图片一样。
权限与命令:
elevator.use——使用电梯的权限
elevator.admin——重载插件配置文件权限
/elevator reload——重载配置文件
配置文件:
BlockType: IRON_BLOCK
EnableParticle: true
ParticleType: SPELL_WITCH
ParticleCount: 20
UsageSound: entity.enderman.teleport
ActivateSound: entity.player.levelup
Hooks:
  GriefPrevention: true
ElevatorUp: "&a上升"
ElevatorDown: "&a下降"
ElevatorDanger: "&4你不能用电梯到这个地方"
ElevatorActivated: "&a电梯成功启动"
