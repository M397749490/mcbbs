默认是这样的，意思就是（没想到最后还是得重新介绍一次）
world: ←world世界权限组
          world_nether: ←地狱世界
          - users ←保存单个玩家权限组信息的文件
          - groups ← 权限组设置文件
          world_the_end: ←末地世界
          - users
          - groups
          all_unnamed_worlds: ← 所有其余世界
          - users
          - groups
地狱世界和末地世界都在world世界组的列表内，意思就是这两个世界的users和groups都将会和world（默认主世界名称）同步，如果你在world或者地狱又或者末地加入/修改/删除权限的话会影响这些世界
我刚刚是叫你创造一个新的世界权限组，例如叫做mcbbs
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.         mcbbs:
  9.           将你要取消权限世界的名称写到这里:
  10.           - users
  11.           - groups
复制代码

          all_unnamed_worlds: ←你需要将这个选项删除
          - users
          - groups
设置完后在那个世界设置权限不会影响到第一个世界权限组，但是新创造的世界组权限都是插件默认配置也就是说你需要重新设置这个世界的权限。
最后你到这个世界输入我沙发那楼给的指令就行，不会同步其他世界。
