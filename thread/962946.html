NoBedExplosions

夭寿啦！MC可以在地狱睡觉啦！



  
插件功能:
  
  
- 禁用床的爆炸
  

  
插件特点:
  
  
- 非常轻量
- 可自定义一些语言文件的输出
  


  
插件指令与权限:
  
  
- /reloadnobedexplosions或/reloadnbs
- 对应权限为nobedexplosions.reload
- 默认OP拥有

插件设置:
  
  

  # +-------------------+ +--------------------------------------------------+
  # |                    | |                                                     |
  # |  NoBedExplosions  | |  https://github.com/ItsTehBrian/NoBedExplosions  |

  # |                    | |    /-------------------------/
  # +-------------------+ +---/
  
  # 是否启用此插件
  enabled: true
  
  
  # 设置为true则允许玩家睡觉并设置重生点
  # 设置为false则会阻止玩家睡觉并发送一条提醒
  allow_sleep: true
  
  
  # 上面一项设置为false则该条设置启用
  # 留空为不提醒，禁止床爆炸并代替为一条提醒
  denied_msg: "&7你不能在这儿睡觉.."
  
  
  # 重载插件的消息
  # 留空为不提醒
  reload_msg: "&7[&cNBE&7] &f插件成功重载!"
