配置文件中可以修改-但搬运贴内没写出传送到里面的相关配置-并提议不用改
worlds:
  世界名字:
    plot:
      height: 64 #高度 一般不用动它
      size: 50 #地皮大小
      filling: #地皮表面以下的方块ID
      - '3:0' #泥土一般不用管
      floor:
      - '2:0' #地皮表面的方块 一般都是草方块 别动
      bedrock: true #是否有基岩
      biome: FOREST #地皮上的自然群系
      auto_merge: true #玩家有多块地皮是否自动合体
      create_signs: true #自动创造牌子
    wall:
      block: '44:0' #没认领前围墙的方块
      block_claimed: '44:1' #认领后围墙的方块
      filling: '1:0' #围墙下面的方块
      height: 64 #高度 一般不用动
    road:
      width: 7 #马路的宽
      height: 64 #马路的高 一般不用动
      block: '155:0' #马路方块
    home:
      default: side #传送到家时在地皮外面 好像是这样翻译 不用改就是了

这里我翻机了一下 可能是 inside 所以你把side 改成 inside 试试
