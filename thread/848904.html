一些较纯净生存服的管理员们可能会提供史莱姆区块的查询服务。
本插件被设计用于在不泄露服务器种子的前提下解放他们的双手。
功能
本插件可以使玩家（有偿或无偿）通过输入命令打开史莱姆区块地图，查询以自己为中心5x5区块范围内的史莱姆区块。

（SlimeChunkMap，Minecraft版本1.12.2）
指令
  • /scm：打开史莱姆区块地图。
  • /scm reload：重载插件。
权限
  • slimechunkmap.use：打开史莱姆区块地图的权限。默认玩家拥有。
  • slimechunkmap.free：在配置中need-cost项打开时免费使用史莱姆区块地图的权限。默认OP拥有。
  • slimechunkmap.reload：重载插件的权限。默认OP拥有。
配置
  1. # 该选项默认为false，若设置为true，则插件需要Vault作为前置
  2. need-cost: false
  3. # 若need-cost项设置为true，则请务必设置cost项，否则插件会报错
  4. # cost: 50.0
