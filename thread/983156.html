PreventThrow

防止使用快捷键丢出带有自定义lore的物品




前言

mcbbs也有很多防丢的插件了,但是我自己也写了一个比较简单的分享给那些需要的人

主要用于RPG防止不小心把武器用快捷键直接给丢出去,有不要的垃圾和物品可以打开背包手丢出去

功能
  • 带有自定义的lore 禁止快捷键丢出
  • 物品上如果有lore 禁止快捷键丢出
  • 自定义某个原版物品禁止快捷键丢出
  • 物品上带附魔的禁止快捷键丢出
  • 共计 四 个检测禁止快捷键丢出（都可以在配置里面设置开或者关）
  • 自定义 Message 输出的消息


配置文件

Config

  1. ############################################################
  2. # -------------------------------------------------------- #
  3. # |                       Config                         | #
  4. # -------------------------------------------------------- #
  5. ############################################################
  6. #配置文件版本
  7. Configversion: 1.1.0

  9. #设置
  10. Setting:
  11.   #自定义lore检测防丢(是否开启)
  12.   Customloreitem: true
  13.   #带有随便的lore检测防丢(是否开启)
  14.   Loreitem: false
  15.   #自定义物品检测防丢(是否开启)
  16.   Customitems: false
  17.   #附魔物品检测防丢(是否开启)
  18.   Enchantingitem: false
  19.   #你希望玩家每次进来的防丢模式
  20.   PlayerjoinStatus: true

  22. #Lore 检测
  23. No-lore:
  24.   - "禁止"

  26. #自定义物品检测
  27. Customitems:
  28.   - "STONE"

复制代码




命令&权限

/pdrop on - 开启快捷键防丢模式
/pdrop off - 关闭快捷键防丢模式
/pdrop reload - 重新加载配置文件

权限: PreventThrow.on
权限: PreventThrow.off
权限: PreventThrow.reload
