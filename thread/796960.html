插件详情

一、前言
ShopKeepers 2换1太少？试试看这个插件吧。
支持十种材料兑换物品，且支持Vault和PlayerPoints。

二、特性
  • 支持Vault + PlayerPoints兑换
  • 全GUI进行操作, 简单方便
  • 支持绑定NPC来打开商店
  • 100%的文本支持修改(提示, GUI标题, 物品名/描述)
  • 已测试版本: Spigot1.8, Spigot1.9, Spigot1.10.2, PaperSpigot1.12.2

三、命令
管理-命令
/rpgshop create <编号> <标题> <大小> #创建一个RPG商店
/rpgshop add <编号> #给一个RPG商店增加物品
/rpgshop list #查看商店列表
/rpgshop edit <编号> #编辑所选RPG商店
/rpgshop delete <编号> #删除所选RPG商店
/rpgshop removeItem <编号> <物品位置> #删除所选RPG商店内某个位置的物品
/rpgshop reload #重载插件配置
权限: rpgshop.命令节点 例如: rpgshop.create / rpgshop.reload
