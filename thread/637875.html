Halloween World 1.6

万圣节世界是一个很有趣的插件，它可以让你进入一个令人毛骨悚然的世界...

该插件测试版本是：1.10（更多版本请各位腐竹尝试，可以的请留言谢谢.）



插件特点：
?万圣节世界入口?

3*3的地狱岩为底，四周是灵魂沙，然后倒水就大功告成了！



一、如果你手上有名字为‘Jump and Run’的玻璃（跳的更高或跑更快）、南瓜或南瓜灯，然后你左键/右键你就会得到一顶帽子（这些都要在万圣节世界的箱子内有）


二、你可以创建Herobrine祭坛。
用黄金块包围着一个苔石，接下来是在苔石上面放一个地狱岩，然后地狱岩四个面的黄金块上放四个红石火把，最后在地狱岩上面点火就可以了！




三、特殊道具：一个可以传送的弓，死亡金苹果（吃的时候会炸死附近怪物）和一把有电的剑（试了很久找不到...），‘Jump and Run’玻璃、这些都可以在坟墓里或在烟箱找到...


四、跑的时候有几率出现：蝙蝠的出现，玩家被缠住，爆炸效果，天上掉下南瓜头僵尸，奇怪的声音，闪电和Shuffle Inventory Items（我真不会翻译这个，知道的请留言谢谢.）


◆这个插件有趣的东西很多，比如有死神出没，没有白天，僵尸马，坟墓下面有好东西哦嘿嘿，刷怪笼都会有很多特别的小黑等等生存见不到的，更多发现待各位腐竹去探索啦！

  1. 超级烦，编辑好的汉化指令，论坛老出错，要哭了.

  3. command: /halloween
  4. description: 插件帮助

  6. command: /halloween whitelist <on|off>

  9. command: /halloween whitelist list

  12. command: /halloween build <on|off>
  13. description: 建筑权限开启/关闭

  15. command: /halloween whitelist <add|remove> <player>

  18. command: /halloween info
  19. description: 万圣节世界信息

  21. command: /halloween seed <num>
  22. description: 替换万圣节的地图种子

  24. command: /halloween new
  25. description: 更新世界

  27. command: /halloween reload
  28. description: 重置插件

  30. command: /halloween tp [player]

  33. command: /halloween enable <on|off>
  34. description: 开启/关闭插件

  36. command: /halloween explode chest <on|off>
  37. description: 开启/关闭 箱子爆炸

  39. command: /halloween explode creeper <on|off>

  63. command: /halloween zombie <on|off>
  64. description: 开启/关闭 僵尸出生

  66. command: /halloween health <num>
