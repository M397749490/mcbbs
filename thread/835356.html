如果楼主要全局设置：
/config/sponge/global.conf 文件可以全局设置

如果楼主要单独世界设置：

设置某个世界直接翻这个文件夹下对应世界的dimension.conf文件
打开文件找到这些设置项目：
  1. spawner {
  2.         #环境生物最大数量
  3.         spawn-limit-ambient=5
  4.         # 动物最大数量
  5.         spawn-limit-animal=15
  6.         #水生生物最大数量
  7.         spawn-limit-aquatic=5
  8.         # 怪物最大数量
  9.         spawn-limit-monster=40
  10.         # 环境生物生成速率（即每多少tick尝试生成一次）
  11.         tick-rate-ambient=400
  12.         # 动物生成速率（即每多少tick尝试生成一次）
  13.         tick-rate-animal=400
  14.         # 水生生物生成速率（即每多少tick尝试生成一次）
  15.         tick-rate-aquatic=400
  16.         # 怪物生物生成速率（即每多少tick尝试生成一次），这个值可以调高一些
  17.         tick-rate-monster=1
  18.     }
复制代码
