你这代码应该是从什么教程贴内复制的吧...那么这个教程贴应该有说去去Forge官方获取获取Forge的源码（SRC）吧，注意版本！
你这代码的第一行意思是你这个Mod所在的路径：com/example/examplemod
后面的四行，也就是你的问题所在
import net.minecraft.init.Blocks;
import net.minecraftforge.fml.common.Mod;
import net.minecraftforge.fml.common.Mod.EventHandler;
import net.minecraftforge.fml.common.event.FMLInitializationEvent;
import的意思你上面也说了是导入，因为它需要从“资源”的地方找到这些文件并且导入到这个Mod内
理论上你这里只是想取读草方块而已，检查下导入的文件
