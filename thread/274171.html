SavageDeathCompass v1.1.1

{:10_496:}我又来搬插件了,这次带来一个不错的插件,用这个可以弥补一些RPG服 死亡重生的问题 或者是死亡留下箱子插件

简单的介绍： 本插件会在玩家死后给玩家一个死亡罗盘,罗盘会指向玩家死亡的位置
插件特点：
  可以自定义死亡罗盘名称
  可以自定义死亡罗盘介绍
  可以自定义死亡消息
  可以取消死亡消息
  支持UUID
  支持多世界
  重启也有效果
  可以禁止掉落
权限
  deathcompass.use  在玩家死后给她死亡罗盘
  deathcompass.reload  允许重启这个插件
  deathcompass.admin 管理员权限
命令  
  /deathcompass reload 重新载入插件
配置文件：# DeathCompass Configuration

# 物品名称设置
ItemName: 'Death Compass'

# 物品介绍设置
ItemLore:
  - '&ePoints to Your Last'
  - '&eDeath Location'

# 是否禁止掉落
DestroyOnDrop: true

# 禁止启用的世界
EnabledWorlds:
  - world
  - another_world

# 用UUID代替玩家名字
use-uuid: false

# 自定义消息
# Variable substitutions:
# %itemname%           插件名称
# %playername%         玩家名称
# %playernickname%     玩家的nick名称
# %playerdisplayname%  玩家的称号
# %worldname%           世界名称
messages:
  respawn:
    enabled: true
    string: '%itemname% &cpoints to %playernickname%''s &cdeath location in %worldname%.'
  destroy:
    enabled: true
    string: '%itemname% &cdestroyed.
