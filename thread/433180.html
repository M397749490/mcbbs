极光类战舰-蒸汽朋克伊什飞艇
A steampunk-ish airship

[paper]作者原话[paper]
Okay so ... where do I start with this...
2 weeks of heavy construction, 2 weeks of planning prior to that and lots and lots of mistakes - THIS is the result of my work.
I have never been prouder to present a project than today!
I did not use metadata (custom) blocks on this build as it was entirely build by myself in singleplayer using the 1.7.4 version of the game.

The entire ship is exactly 699 blocks long (including the wings) and requires a large, flat area to be put at in order to store its massive size.

为了尊重作者，我还是不机翻了，毕竟这个只是作者的一些话而已，没有什么重要的内容
