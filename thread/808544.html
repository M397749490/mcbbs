SpeedChanger
————————————————————————————————————
可以用命令改变自己或别人的飞行速度与步行速度
~w_w~


用法：将下载的SpeedChanger插件本体放入服务器的plugins文件夹里，重启服务器。

指令
作用描述
权限
/wspeed <数值或reset>
改变你的步行速度
changespeed.walk
/wspeed <数值或reset> [用户ID]
改变其他人的步行速度
changespeed.walkothers
/fspeed <数值或reset>
改变你的飞行速度
changespeed.fly
/fspeed <数值或reset> [用户ID]
更改其他的飞行速度
changespeed.flyothers
<数值>范围只能是1~10，可以使用小数，填写reset为重置速度（就是调整回1）
游戏默认步行速度为2，飞行速度为1

命令别名：
/wspeed  别名  /ws
/fspeed  别名  /fs



下载地址：

百度网盘
原帖下载



配置文件
  1. enabled: true      # 是否启用插件功能
  2. reset-on-join: true
  3. no-permission-message: '&cNo permission to run this command'      # 没有权限发出的消息
