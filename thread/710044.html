  • 配置这些文件，值得注意的是每个世界的再生设置，在这里设置当城镇区块被城镇 unclaim/lost 的时候，这些区块是否会恢复到原始状态，关于“世界的再生”，会在后面详细介绍

  • 新城镇的默认设置

复制代码

详细介绍
等级制度
流浪者
流浪者是不属于任何城镇的玩家，他们没有土地，他们的权限可以在TownyPerms.yml中进行设置，流浪者可以在拥有towny.command.plot.claim权限的情况下购买其他城镇的大使馆区块

市民
每个加入了你服务器的玩家都可以成为市民（Nomads下拥有towny.town.resident权限），市民拥有自己的指令/resident（缩写为/res，注意此项和Residence领地插件冲突）来展示自己的市民概览页面，包含有金钱，所属城镇，所拥有的土地和朋友信息
市民可以加入或者选择自己创建一个城镇，市民也可以自动在第一次加入服务器时被放入默认城镇，比如新手村（设置方法：在config.yml中找到 default_town_name: '' 在引号中填入默认城镇的名称，重载即可）
加入了城镇的市民可以购买市长正在出售的土地，当市民拥有一块及以上的土地时，他们会看到自己的市民概览页面多了一行“Plot”，展示他们拥有的土地和他所自己拥有的所有土地的权限信息
市民也拥有自己的权限组，在TownyPerms.yml中进行配置

城镇
一个城镇就是一群以一个人为市长的市民的集合（当然也可以是一个市民），一个城镇也拥有一个银行，所有人可以往里存钱，但只有市长可以取钱。一个市长也可以为自己设置一个和他拥有同等权限的助理。如果服务器设置了城镇维护费，维护费每天都会在城镇银行中扣除，如果没有钱来扣除，则城镇会被解散。
城镇通常会不断扩张，市长在创建城镇时站立的位置就是这个城镇默认的HomeBlock（中心区块），扩张时所有区块间必须接壤，除非创建outpost区块（一个和城镇不接壤的区块，默认创建费用比创建一个新的城镇还要高）

市长
市长在他的助理的帮助下维护着一个城镇，管理着这个城镇和市民，市长在TownyPerms.yml中拥有自己的权限组
市长可以决定市民的等级，但等级必须事先由服务器管理员在TownyPerms.yml中配置好，市长可以使用命令 /town ranklist来查看可用等级，玩家可以通过命令/town rank {add|remove} {playername} {rankname}分配到不同等级，一个玩家可以被分配到多个等级，管理员可以利用这个功能创建很多的城镇角色，例如银行工作人员，建设者，使者，让市长的管理工作更加轻松有序。
除非你是管理员，否则不能创建多个城镇。一个管理员可以按照如下方法建立多个城镇：
例如：管理员 Bob
管理员Bob想拥有一个服务器用的新手村和自己的私人城镇。Bob需要创建一个新城镇，然后完善各项设置
完成以上步骤之后，Bob需要使用命令/townyadmin set mayor {townname} npc来放置一个假的 NPC 来担任本市市长，然后Bob就可以离开这个城镇，然后单独建立自己的城镇了，再次使用这个命令可以将市长身份切回。
Bob在没有担任市长之后可以使用命令/townyadmin town {townname} add {playername}来给城镇添加玩家，或者按照上方介绍的设置默认新手村的方式来让玩家加入这个城镇
Bob还可以使用命令/ta nation {nation} add {town}来让城镇加入国家（/ta为/townyadmin的缩写）
国家
一个国家就是以一个城镇为首都，以首都城镇市长为国王的城镇的集合（也可以只有一个城镇）。一个国家可以加入与敌对国家的战争，并于自己的联盟并肩作战。一个国家同样拥有自己的国家银行，运作方式与城镇类似。
两个国家可以选择加入一个联盟，避免他们之间发生误伤事件，并且互相帮助开发土地（如果允许联盟国家操作本国土地），并在战争中并肩作战。
在0.91.0.0版本中，你可以限制国家联盟必须是双向的，比如A国家不能在B不把A视作盟友的情况下将B国家视作盟友。在这里进行配置：config: war.disallow_one_way_alliance  默认为false，推荐设置为true
当然，在0.91.0.0版本中，你还可以限制创建\加入\维持一个连门所需要的最少人口数量，详见config.yml中的Global Town Settings

国王
国王领导着一个国家并且是首都的市长，国王在TonyPerms.yml中拥有自己的权限配置
国王可以决定他的市民的等级。这可以是一个国王助理或者其他任意的管理员在TownyPerms.yml里配置好的角色。国王可以使用指令‘/nation ranklist’ 来查看可用等级，并通过命令‘/nation rank {add|remove} {playername} {rankname}’来分配玩家到不同等级。一个玩家可以被分配到一个或多个等几种。允许管理员创建多种多样的国家角色，例如银行管理员，大使。
国王拥有设置玩家的称号和后缀的能力，命令
  • /nation set title {name} titlegoeshere
  • /nation set surname {name} surnamegoeshere


如果命令中{name}参数后没有任何内容，则将玩家的称号或后缀设置为空白

配置TownyPerms.yml和其中的角色
Towny0.82.0.0以上版本都拥有此文件
位置：towny\settings 文件夹内

此系统将会把权限直接推送到Bukkit，并可以与其他权限插件一同使用。它让你可以基于玩家的等级（流浪者/市民/市长/国王）来进行权限配置。你也可以任意指定城镇/国家角色，来调整他们的权限（例如：助手/Vip）。这个系统中的权限配置不仅限于Towny中的权限，甚至还可以操控其他插件的权限。

这个文件允许管理员决定不同地位的玩家能够做什么。一些角色在插件第一次运行时就已经被自动配置了：
  • 没有加入任何城镇的玩家为流浪者
  • 加入了城镇的玩家为市民
  • 城镇的拥有者为市长
  • 国家的拥有者为国王

一些角色由市长/国王进行分配，以下是已经自动配置的角色：
  • 市长可以设置市长助理
  • 国王可以设置国王助理
  • 市长和国王可以分配由管理员配置好的角色给市民
  • - 一个玩家可以从他们的市长或者国王那里获取到许多不同的角色
  • - 例如：城镇银行管理员 城镇建设者（管理银行系统）（拥有整个城镇的建设权限） 城镇大使（负责邀请玩家加入）

一个城镇的市民可以通过指令‘/town ranklist’来查看可用的角色。市长可以使用命令‘/town rank {add|remove} {playername} {rankname}’来给予玩家一个在他们城镇范围内有效的角色，国王可以使用命令‘/nation rank {add|remove} {playername} {rankname}’来给玩家在国家范围内有效的角色。

城镇发展指南
创建一个城镇
市长使用指令/town new {城镇名称} 来创建一个城镇，输入指令时所站的区块为城镇的中心区块，城镇主城只能设置在中心区块
更多的城镇区块需要通过指令  /town claim 来购买，所有后面claim（购买）的土地均必须与城镇的某一块土地接壤

加入一个城镇
由拥有权限的城镇管理员，使用命令 /town add {playername} 来添加玩家到城镇，如果使用了Questioner.jar，玩家会收到邀请，并有权决定是否加入，如果没有使用Questioner.jar，则会直接加入。
如果市长使用指令  /town toggle open 来将城镇设置为开放状态，则玩家无需收到邀请，只需要使用命令  /town join {townname} 即可加入一个城镇
更多的市民加入城镇，在默认设置下意味着城镇会拥有更多的土地上限（默认玩家数量*6）

区块系统 和 土地所有权

注：本帖中的“区块”和“土地”可以视作一种东西

城镇区块
Towny提供了管理员可以当甩手掌柜的区块保护系统，保护系统将土地分成区块，称为TownBlock（城镇区块），默认大小为16*16*128（128为基岩到云层，也就是“整个世界”），城镇区块被市长Claim（声明，但本帖翻译为 购买），并且可以挂牌出售来卖给市民（大使馆区块可以卖给城镇外的人）。

城镇区块大小
你可以在config.yml中的 town_block_size: 16 对区块大小进行设置
请只在第一次安装Towny时修改本文件，否则会导致严重问题
设置为一个更小的数值来提高精准度，但会增加服务器能耗，让服务器缓存变得无用
默认16*16*128就很合理，如果非调整不可，建议为16的倍数，以方便玩家通过F3+G来查看区块，更加方便玩家管理城镇

设置城镇的城镇区块上限
你可以设置一个城镇所能购买的区块上限。这可以在两个地方进行配置。Towny会首先检查config.yml 中的 town_block_ratio: 8 并默认给予一个城镇 市民数量 * 8 的区块上限。
你也可以更改此项为 town_block_ratio: 0 来启用 townLevel （上方介绍的城镇等级）中的设置（即到达一定数量才增加而不是加入一人就增加）

购买城镇区块上限
市长可以使用命令 /town buy bonus {amount} 来购买区块上限，注意只是购买区块上限，购买后仍然需要通过 /t claim 来购买区块。管理员可以设置一个城镇最多可以购买多少额外的区块，位置是 config.yml max_purchased_blocks: '0' 价格设置在 price_purchased_bonus_townblock: '25.0'  你还可以设置购买第二块额外领地上限时，价格是第一块的多少倍，这样可以让购买额外区块变得越来越昂贵。

城镇区块类型

Towny post-0.75 及以上版本添加了区块类型，市长可以通过将区块设置为不同的区块类型来更加合理、方便的管理区块

默认型
这种区块类型是在被购买时默认的类型
可以通过指令 /plot forsale {价格}  来挂牌出售
一个其他类型的区块可以通过命令 /plot set reset  来重置为默认型

商店型
商店区块可以通过命令 /plot set shop 来设置
市长可以使用  /town set shopprice {价格}  来设置商店区块的价格（首先还是通过 /plot forsale {价格}  来挂牌出售）
一个市长还可以通过指令  /town set shoptax {价格}  来设置商店区块主人每天需要为每一块商店区块支付的税费

竞技场
竞技场区块可以通过命令  /plot set arena 来设置
在这个区域，无论城镇是否开启了PVP，这里都可以PVP，并且如果城镇内设置了回血效果，在这里也会无效

大使馆
大使馆区块可以通过命令 /plot set Embassy 来设置
市长可以使用  /town set embassyprice {价格}  来设置大使馆区块的价格（首先还是通过 /plot forsale {价格}  来挂牌出售）
一个市长还可以通过指令  /town set embassyprice {价格}  来设置商店区块主人每天需要为每一块大使馆区块支付的税费
一个大使馆区块可以被任何人购买，不论他们是否在城镇内，市长也可以在任何时候要回此区块的所有权

野外型
大使馆区块可以通过命令 /plot set wild 来设置
野外型区块不同于荒郊野外，这类似于城市郊区，允许市民破坏和防止在荒郊野外允许放置和破坏的方块，在默认设置下，这些方块包括矿石，树木，花和蘑菇等。在默认设置下，它不包含石头，泥土，草和其他与地形有关的方块
这对你创建一个林场很有用，并且可以保护你城镇周边的自然地形，同时也允许市民去砍树和探索洞穴
设置野外型区块会稍微复杂一些，说明如下：
位置：towny\data\worlds\WORLDNAME.txt
进行设置
  • unclaimedZoneBuild=false
  • unclaimedZoneDestroy=false


设置 unclaimedZoneIgnoreIds 这一行来设置你的玩具在野外型区块能够 破坏/建造 哪些方块
去到你想设定为野外型区块的地方，然后使用指令 /plot set wilds
使用指令 ‘/plot set perm resident build on’ and ‘/plot set perm resident destroy on’ 来让市民只能 破坏/建造 ignoreIDs  列表中有对应ID的方块

旅馆型
旅馆型区块可以通过命令 /plot set inn  来设置
旅馆型区块允许任何人使用床来设置自己的出生点，然后可以通过 "/res spawn" 回到出生点以及在死亡时在此处复活。旅馆型区块依然会阻止敌对国家的市民入住。相当于是一个除了敌对国家外，对所有人开放的地区
可以在config.yml中的eny_bed_use: ‘true’项目处设置是否允许使用旅馆性区块的床

监狱型
监狱型区块可以通过命令 /plot set jail  来设置
玩家会在以下事件发生时进入监狱
  • 市长/警长（城镇角色）将他们送入监狱时
  • 敌对国家的袭击者在本市领地范围内死亡，他将会被送入监狱区块（如果本市有的话）




被监禁的玩家在以下事件发生时将会脱离监狱
  • 他们使用命令离开了这个城镇，成为一名流浪者
  • 市长/警长 释放了他
  • 他支付了保释金 指令： /resident jail paybail
  • 他们越过了监狱，进入到了荒郊野外区块




被监禁的玩家将会发生以下改变
  • 不能传送
  • 不能使用末影珍珠（除非在config.yml中开启）
  • 在死亡后依然会在监狱复活
  • 在被杀害时不会被扣钱（如果开启了死亡扣钱）
  • 使用命令/res [玩家ID] 查看信息概览面板时，会显示他们的监禁状态




建议你在TownyPerms.yml中新建一个名为“警长”的角色，然后给予此角色  towny.command.town.toggle.jail 节点，最新版的TownyPerms.yml文件中已经默认包含有此角色

农场型
农场型区块可以通过命令 /plot set farm  来设置
在一个农场区块内，市民只能 破坏/建造 config.yml 文件中 global_town_settings.farm_plot_allow_blocks.中列出的ID所对应的方块，你可以进行修改，默认是 各类花草以及各类农作物
谁可以建造/破坏 这些方块，依然会显示在/plot perm 页面上。这意味着如果 B=rao ,所有人都可以在这里进行建造/破坏，而如果B=r-，那只有市民可以。
如果服务器管理员喜欢，他们还可以添加 SOIL 到config.yml 中的设置里，这可以让玩家锄地。默认设置中是不可以的，只有 管理员/市长/助理 可以锄地。当然，Towny插件也已经自带防护，可以防止耕地被踩踏而变回草方块，但是耕地仍然会在土地没有被灌溉的时候变回泥土。
农场型区块同样也允许市民击杀动物，具体也可以在 config.yml 中的  global_town_settings.farm_animals  进行设置。默认包含猪、牛、鸡、羊以及哞菇

前哨
前面已经说到过，城镇扩张时，不论是何种类型的区块，每一块土地都必须和城镇中的某一块土地接壤，而Outposts（前哨型）则不必接壤。
为了让玩家可以购买前哨区块，config.yml 中的allow_outposts必须设置为true，并且需要在他们的权限列表中有towny.town.claim.outpost  节点
管理员可以设置玩家最多可以购买多少个前哨区块，这需要在你的权限插件中的info/option/meta 使用Towny_maxoutposts: {数量} 节点
前哨型区块不能太靠近HomeBlock（中心区块），就像一个市长新建一个新城镇不能太靠近其他城镇一样。具体设置在config中的min_distance_from_town_homeblock: 5.（默认设置为5个区块，也就是5*16=80格）
前哨区块具体设置见config
  • allow_outposts  设置为false来彻底关闭前哨区块的购买
  • price_outpost  来设置前哨区块的价格（推荐略高于城镇创建费）



前哨型区块可以直接传送前往，传送点为市长使用命令‘/town set outpost’时的站位。玩家可以通过命令‘/town outpost x’来传送到自己城镇的一个前哨型区块（X代表如果本城镇有多个前哨，要前往的是第几个）

出售土地
土地只能由市长购买后出售给玩家，要实现扣费，你必须在config中将using_iconomy设置为true，市长可以通过指令来将土地挂牌出售
/town set plotprice {价格}
  • 这将设置一个区块为出售状态，玩家走进这个区块的时候聊天框会显示“[for sale:价格]”，如果你没有注明价格，则默认为0



然后玩家可以通过命令/plot claim来买下这个区块，然后就可以任意操作了

使用城镇地图
城镇地图将会显示你们城镇的土地概况，你可以通过指令来切换到地图模式，从而在进入一个区块的时候会自动显示地图，方便你使用地图。
  • 使用命令 /resident set mode map 来开启这个模式
  • 使用命令 /resident set mode reset 来关闭这个模式



查看城镇大地图可以使用命令/towny map big

土地再生 ＆ 放弃土地
以下有四种情况会对土地产生巨大影响
恢复到原始状态
当一个城镇区块被放弃（由于一个玩家使用命令/t unclaim或者由于无法缴纳维护费）时，这些土地会慢慢的恢复到被声明前的快照，如果还未完全恢复到原始状态再次被购买，则在再次购买时还会创建新的快照（总之就是土地被购买时会创建一个快照用于恢复，并且这个快照会覆盖以前的快照）。

有以下几种方式可以关闭此功能：
  • 关闭此模式，位置 towny\data\worlds\worldname.txt @ usingPlotManagementRevert=false
  • 在你希望关闭此功能的世界使用命令 ‘/tw toggle revertunclaim’
  • 为以后新创建的时间默认关闭此功能 new_world_settings.plot_management.revert_on_unclaim.enabled



如果你希望配置某些特定的方块不被复原，来防止玩家利用这个特性刷贵重物品，你可以这样来实现：

  • 修改data/worlds/worldname.txt下的worlds txt中的block_ignore列表
  • 为以后的新世界进行设置：config 中的new_world_settings.plot_management.revert_on_unclaim.block_ignore:


删除某些方块
当一个城镇区块被放弃（由于一个玩家使用命令/t unclaim或者由于无法缴纳维护费）时，设置好的方块ID所对应的方块会被删除，这对删除城镇内的公告牌很有用，并且可以保证所有的被牌子锁锁上的箱子被解锁，避免玩家通过此功能卡仓库
有以下几种方式可以关闭此功能：
  • 关闭此模式 towny\data\worlds\worldname.txt @ usingPlotManagementdelete=false
  • 为以后新创建的时间默认关闭此功能 new_world_settings.plot_management.block_delete.enabled



如果你希望配置某些特定的方块不被删除，你可以这样来实现：

  • 修改data/worlds/worldname.txt下的worlds txt中的plotManagementDeleteIds=列表
  • 为以后的新世界进行设置：config 中的 new_world_settings.plot_management.block_delete.unclaim_delete


土地主人/市长 使用命/plot clear
市长可以对土地使用命令/plot clear，这个命令将会删除掉这个区块中置顶的物品，迫使市民搬移到另一个区块或者是离开城镇。默认设置下，这个命令只会清理牌子，用于接触牌子锁。
有以下几种方式可以关闭此功能：
  • 关闭此模式 towny\data\worlds\worldname.txt @ usingPlotManagementdelete=false
  • 为以后新创建的时间默认关闭此功能 new_world_settings.plot_management.block_delete.enabled


如果你希望配置某些特定的方块不被删除，你可以这样来实现：
  • 修改data/worlds/worldname.txt下的worlds txt中的plotManagementDeleteIds=列表
  • 为以后的新世界进行设置：config 中的 new_world_settings.plot_management.mayor_plotblock_delete.mayor_plot_delete

设置 wild_revert_on_mob_explosion 来防护爬行者等的爆炸导致的破坏

城镇方块保护机制
Towny的一项特别的才能是它能够让玩家自己对自己的区块进行保护，而无需管理员的大量工作，并且玩家也不能在不劳动的情况下疯狂的拓展土地。
你首先需要了解的是4种权限和3个组

Towny土地权限
Towny中一共有四种土地权限类型，对个人和对城镇都适用（市民进行设置则对个人土地生效，市长进行设置则对整个城镇除私人土地外的所有土地生效），基础命令是/res set perm 或者 /t set perm
在Towny0.77.0.0以及之后的版本中，不论是城镇新购买的区块，还是市民从市长那购买的区块，土地都将会在被创建时从config中读取默认设置，同时土地拥有者也能够自己对权限进行调整，也可以全局调整，也可以对单独的一个地块进行调整。
可以通过命令/plot perm来查看所处土地的权限信息，命令/plot set perm来设置权限
默认的个人土地权限可以通过/res 来查看，默认的城镇土地权限可以通过命令/t 来查看

权限类型
一共有四种权限类型 Build Destroy Switch 和 Itemuse
Build允许玩家进行建造
Destroy允许玩家进行破坏
Switch权限包括使用以下物品
  • 酿造台
  • 音符盒
  • 箱子
  • 熔炉
  • 铁门和木门
  • 拉杆
  • 各种压力板
  • 按钮
  • 活板门
  • 唱片机
  • 红石中继器
  • 红是比较器
  • 末影门
  • 末影箱
  • 信标
  • 漏斗
  • 发射器
  • 各种类型的矿车



Itemuse包括在土地内使用以下物品
  • 熔岩桶，水桶
  • 空桶
  • 打火石
  • 骨粉，各种染料
  • 末影珍珠
  • 各种类型的矿车
  • 火焰弹
  • 瓶子






权限组
对居民来说，一共有三种权限组，他们是FAO（Friend Ally Outsider） 朋友 盟友 外人
市城镇来说，一共有三种权限组，他们是RAO（Resident Ally  Outsider）市民 盟友 外人
朋友
市民完全信任的人，朋友可以随意操作你的土地，默认设置下，允许单向好友
市民
加入了本市的居民
盟友
  • 来自你城镇的玩家
  • 你国家其他城镇的玩家
  • 盟国城镇的玩家

外人
不在你盟国和本国城镇内的玩家
在游戏内使用命令来更改设置

PVP控制
[spoiler]Towny会对PVP进行控制

误伤
默认情况下，城镇会防止城镇居民、国家国民之间的误伤，可以将 config.yml friendly_fire: 'true' 设置为false来开启PVP，这项设置将会直接应用到所有的城镇
土地，城镇和世界PVP设定
土地，城镇和世界都拥有自己的PVP设置，下面详细介绍配置方式

世界PVP设置
世界PVP设置可以使用游戏命令来控制
  • /townyworld toggle pvp 对全世界的PVP进行控制，使用命令/tw查看世界面板，如果有红色的{PVP}字样则说明已经开启
  • /tw toggle forcepvp 对全世界的PVP进行控制，且城镇无权改变，同时管理员依然可以通过对配置文件进行修改来进行设置 位置：Towny\Data\Towns\城镇名称.txt ， adminDisabledPvP=true


城镇PVP设置
  • /t toggle pvp 对全镇的PVP进行设置

土地PVP设置
  • /plot toggle pvp 对该区块的PVP进行设置

Money
税和维护费
税和维护费是城镇经济非常重要的两个部分，在进行阅读前，请务必保证你的 config.yml中的  using_iconomy 设置为了true
城镇的税和维护费都是以“日”为单位来进行收取，而每“日”的时间是可以自定义的，设置在config.yml中的 day_interval: 1d ，默认为1d即24小时，你可以使用命令/ta newday来开启新的一天（立即收税），或者通过命令/t time来查看今天还剩下多长时间

税务
在config.yml 中的 daily_taxes 设置是否收税
市民可以通过指令/res tax 来查看需要缴纳的税款

命令：
/t set taxes {价格}
这可以为你的城镇设置居民税，他可以按照固定值收取，也可以按比例收取
  • 开启/关闭 按比例收取模式 /town toggle taxpercent
  • 玩家将在每“日”开始的时候缴税
  • 无钱缴税的玩家将会被自动踢出城镇，请提醒玩家务必在私人账户留有足够存款

/t set plottax {价格}
这可以为你的居民设置土地税
  • 只能按照固定值收取
  • 无钱缴税的玩家将会失去土地

/nathion set taxes {价格}
设置国家的城镇税款
  • 按固定值缴税，从城镇银行扣除
  • 无钱缴税的城镇将会被踢出国家

管理员可以在config中的max_tax_percent设置税收上限，避免过高收税，第一个是固定值的上限，第二个是比例值上限。默认是1000和25%
商店、大使馆还可以拥有自己单独的税收政策，前面已经讲到过了

多世界
Towny拥有多世界支持，每个世界都可以完全单独的进行设置
位置： /plugins/towny/data/worlds/世界名称.txt
所有的世界也都在/towny/data/worlds.txt文件中列出

世界开关
Towny可以在游戏内对每个世界进行调整，方法是站在那个世界中，使用命令 /townyworld toggle
开关内容
  • claimable 是否可以购买土地
  • pvp 是否开启PVP
  • forcepvp 是否开启PVP并禁止镇长进行单独设置
  • fire 是否开启火焰蔓延
  • townmobs 是否开启怪物生成，可以只限制部分生物，设置位置为config.yml
  • worldmobs 是否开启世界怪物生成，可以只限制部分生物，设置位置为config.yml
  • usingtowny 是否在本世界使用towny
  • revertunclaim 是否在删除土地后将土地恢复原状
  • revertexpl 是否在荒郊野外恢复被生物炸毁的地形

城镇战争
服务器中如果有战争正在发生，则插件暂时不会接受更新

/ta toggle war ( 开关战争 )
服务器管理员可以使用此命令开开启战争，使用命令后会有30秒冷却时间，然后战争爆发
Config.yml中的Using_economy必须在战争开始之前被设置为true
在国家之间相互战斗的时候，没有加入国家的城镇将会被排除在战争之外
国家也可以每天额外支出一定的中立费用来保持中立，从而避免战争，中立费用可以在Config.yml中的price_nation_neutrality设置
/towny war hud命令可以查看战争积分，战争积分由双方各自占领的对方领土数量决定
城镇区块在战争期间会拥有HP，普通区块有60HP，中心区块有120HP，这些都是可以在Config中修改的
一个城镇区块会在敌人站在这个区块上时被扣除HP，HP被扣除到0则表示已经占领

在城镇区块正在遭受袭击的时候，烟花会出现在上空，红色代表伤害，红色的苦力怕形状表示获胜，原谅绿表示城镇区块被收复

默认设置下，只有靠近荒郊野外的边境区块才能在战争初期遭受契机，这也是可以在Config中进行设置的

城镇和国家都会在HomeBlock（中心区块）或者 市长/国王 被杀害时被淘汰

战争积分获得方式
  • 击杀敌人 1
  • 占领土地 1
  • 淘汰一个城镇 10
  • 淘汰一个国家 100



城镇战争将会在只有一个国家的HomeBlock没有被占领，或者管理员使用命令时结束
所有的城镇区块都会在战争结束时被恢复

使用SQL
在Towny 0.80.0.0以上，已经支持SQL ,可以在Config.yml中进行相关设置

配置SQL
支持3种数据类型
MySQL
  • 打开\towny\settings\config.yml然后找到Plugin Interfacing这一节
  • 找到sql
  • 配置hostname/port/username 和 password
  • 保存Config
H2
  • 下载h2.jar并载入服务器
sqlite

  • 和H2相同


将文件转换为SQL
  • 关闭服务器
  • 打开打开\towny\settings\config.yml然后找到Plugin Interfacing这一节
  • 找到 database_load 确保它是设置为 flatfile的
  • 找到 database_save 设置为 MySQL SQLite 或者 h2
  • 保存config然后启动你的服务器
  • 在你的服务器正在运行时，将 database_load 设置为 mysql sqlite 或者 h2，然后在游戏中使用命令  /ta reload
  • 打开 Towny\Data\folder 然后删掉除了 plot-block-data 文件夹的所有文件（这个文件夹用于记录快照来在删除城镇地块时将地块恢复到初始状态，如果你不使用此功能，可以将其一并删除）
  • 值得注意的是，Towny并不会对使用数据库备份的数据进行备份，你需要自己来做这个事情


将SQL转换到文件
  • 关闭服务器
  • 打开打开\towny\settings\config.yml然后找到Plugin Interfacing这一节
  • 找到 database_load 确保它是设置为 MySQL SQLite 或者 h2
  • 找到 database_save 设置为 flatfile
  • 保存config然后启动你的服务器
  • 在你的服务器正在运行时，将 database_load 设置为 flatfile，然后在游戏中使用命令  /ta reload
