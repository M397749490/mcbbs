插件介绍

本插件可以让玩家的合成直接在工作台表面全息显示，如下图


工作台表面显示的物品会按照工作台内的物品变化而变化
可用于展示物品合成配方等

下载附件

显示有全息物品的工作台可被活塞推动


可随时切换回原版工作台功能


指令与权限
  • /craftingtable reload - 重载插件 - publiccrafts.reload
  • /craftingtable toggle - 切换回原版工作台功能 - publiccrafts.private

配置文件
config.yml

  1. # Public Crafters Config - Created by BananaPuncher714 Translated by AndyYu from PCD

  3. # 全息悬浮物品距离工作台表面多高
  4. # 0.7 代表稍微比工作台表面高一点点, 0.61 代表与工作台表面平齐
  5. item-height: .7

  7. # 将盔甲架设置为marker（意义不明），如果设置为true,全息物品会变得稍微暗一些
  8. marker: false

  10. # 工作台表面的全息物品多少tick更新一次？
  11. # 当使用活塞推动工作台导致卡顿时，建议设置为2
  12. update-delay: 0
