主要功能：
&#8226;链锁任务
&#8226;登录的支持
&#8226;彩色信息
&#8226;奖励/费用配置
&#8226;支持所有主要经济体
&#8226;权限
&#8226;可选的自动更新
&#8226;添加任务通过任务配置文件
&#8226;任务统计
更多功能：http://dev.bukkit.org/server-mods/project-34294/

指令：
/ Q give [questName]
给你一个随机任务，除非指定，并扣除/根据具体的任务，在追求配置指定的奖励费。
/q info
让您对您的当前任务的详细信息
/ q tasks
为您提供您的当前任务的任务
/ q drop
删除您当前的任务，扣除/给/根据具体的任务，在追求配置指定的奖励费。
/ Q done

任务类型：
收集 - 收集指定数量的金额
破坏 - 破坏指定的方块
损伤 - 损伤指定用品的数量
放置 - 放置一个指定的方块
杀 -杀死指定数量的暴民
Kill_Player- 杀死杀死指定数量的玩家
附魔 - 附魔指定的装备
驯服 - 驯服指定的动物
give [URL=]复原编辑[/ URL]
