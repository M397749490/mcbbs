为什么一遇到这样的问题就老想着事件？这样的需求根本不需要监听任何事件。

方案一：

  1. // 你的作物种子类覆写 onItemUse 方法
  2. @Override
  3. public EnumActionResult onItemUse(EntityPlayer player, World world, BlockPos pos, EnumHand hand, EnumFacing facing, float hitX, float hitY, float hitZ) {
  4.   ItemStack held = player.getHeldItem(hand);
  5.   IBlockState targetState = world.getBlockState(pos);
  6.   // 用 targetState.getBlock() == RegisterBlock.crystal 强制检查被右击的方块是不是你的“土壤”方块，以及上方是不是空气
  7.   // 如此一来只有你的“土壤”方块能合理地种植此作物
  8.   if (facing == EnumFacing.UP && player.canPlayerEdit(pos.offset(facing), facing, held) && targetState.getBlock() == RegisterBlock.crystal && worldIn.isAirBlock(pos.up())) {
  9.     world.setBlockState(pos.up(), this.crops.getDefaultState());
  10.     if (player instanceof EntityPlayerMP) { // 原版进度触发器
  11.       CriteriaTriggers.PLACED_BLOCK.trigger((EntityPlayerMP)player, pos.up(), held);
  12.     }
  13.     held.shrink(1); // 种植成功，种子数量减一
  14.     return EnumActionResult.SUCCESS;
  15.   } else {
  16.     return EnumActionResult.FAIL;
  17.   }
  18. }

方案二：

虽然是个 Hack，但对其他 Mod 的兼容性稍微好一点。
利用 Forge 的 EnumPlantType 这套系统即可。
首先你的作物种子类 SeedGreenCrystalFlower 需要有如下声明：
  1. public static final EnumPlantType GREEN_CRYSTAL_FLOWER_PLANT_TYPE = EnumPlantType.getPlantType("green_crystal_flower");
  2. @Override
  3. public EnumPlantType getPlantType(IBlockAccess world, BlockPos pos) {
  4.   return GREEN_CRYSTAL_FLOWER;
  5. }
复制代码

然后在你的“土壤”方块类中，覆写 canSustainPlant：
  1. @Override
  2. public boolean canSustainPlant(IBlockState state, IBlockAccess world, BlockPos pos, EnumFacing direction, IPlantable plantable) {
  3.   return plantable.getPlantType(world, pos.offset(direction)) == SeedGreenCrystalFlower.GREEN_CRYSTAL_FLOWER_PLANT_TYPE;
  4. }
