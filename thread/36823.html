作者: strawmaine    时间: 2012-7-29 00:20
文本编辑器（不推荐记事本）打开plugins\GroupManager\config.yml
  1. mirrors:
  2.         # Worlds listed here have their settings mirrored in their children.
  3.         # The first element 'world' is the main worlds name
  4.         # subsequent elements 'world_nether' and 'world_the_end' are worlds which will use
  5.         # the same user/groups files as the parent.
  6.         # Each child world can be configured to mirror the 'groups', 'users' or both files from it's parent.
  7.         world:
  8.           world_nether:
  9.           - users
  10.           - groups
  11.           world_the_end:
  12.           - users
  13.           - groups
  14.           world2                       重点加这三行（你的world2在这儿呢哟）
  15.           - users                       重点加这三行
  16.           - groups                     重点加这三行
复制代码
