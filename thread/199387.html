Lucky Droppers


一个简单有趣、可以坑玩家的小插件~

用法
创建（参考上图）
  • 放置一个发射器(任意朝向)
  • 在它下面安置一个按钮，木制 石制皆可
  • (可选操作: 放个牌子到发射器上显示它的相关信息
使用
  • 手持使用该发射器需要的东西
  • 按钮！
  • 看看出来的是啥~
删除
  • 敲碎
  • 或使用 /ld delete

指令
目视该发射器以“选定”它
  • /luckydropper (简写: ld, luckyd, luckydrops, droppers, drops)
  • /luckydropper reload (重载配置)
  • /luckydropper create [分组] (将选定的普通发射器设定为特定掉落分组的幸运发射器)
  • /luckydropper set [分组] (改变该幸运发射器的掉落分组)
  • /luckydropper delete (移除幸运发射器效果，还原为普通发射器)
  • /luckydropper type (列出所有掉落分组以及选定的幸运发射器的掉落分组)
  • /luckydropper info [分组] (列出该发射器的掉落分组)

权限
LuckyDropper.admin ——包含以下权限，自行对应上面的指令，这里没有set的权限，要么是作者忘了，要么是包含在某个权限里
      LuckyDropper.create
      LuckyDropper.delete
      LuckyDropper.type
      LuckyDropper.info
      LuckyDropper.reload
LuckyDropper.alltypes —— 允许使用所有掉落分组的发射器
LuckyDropper.分组，如poor组，那么该组权限就是LuckyDropper.poor

LuckyDropper.* —— 包含该插件的所有权限

配置文件
  1. version: 1.0
  2. types:
  3.   rich: # 掉落分组名
  4.     cost: 'diamond,2' # 玩♂一次的花费 (物品, 数量)
  5.     drops: # 掉落清单
  6.       - diamond_block,5 # 掉落物 (物品, X%的几率) 这条就是5%掉落钻石块
  7.       - air,50 # 什么都不掉~
  8.       - emerald,10
  9.       - gold_ingot,30
  10.   poor:
  11.     cost: gold_nugget,1
  12.     drops:
  13.       - dirt,10
  14.       - stone,10
  15.       - iron_block,50
  16.       - gold_block,30
复制代码
注意，掉落物必须是英文代码（抱歉，那个对照表网站俺忘了~，好像是这个http://minecraft-ids.grahamedgecombe.com/ ，空格处别忘了加下划线），不能填数字ID（目前不支持）。
