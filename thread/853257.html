标题: Minecraft 基岩版 Beta 1.11.0.8 发布
本帖最后由 zyjking 于 2019-3-28 19:51 编辑

测试版是Minecraft 基岩版的测试机制，主要用于下一个正式版的特性预览。

然而，测试版主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。适用于正式版的领域服务器不兼容，不提供支持。

如果在测试版中遇到旧版存档无法使用的问题，测试版将允许你将存档上传以供开发团队查找问题。

Minecraft 基岩版 1.11 仍未发布，1.11.0.8为其第6个测试版。

转载本贴时须要注明原作者以及本帖地址。



Bug修复
修复了39个bug
（此版本没有任何内容更新，仅修复bug）

Crashes/Performance
崩溃/性能
  • Improved the performance when opening the player inventory with the crafting recipes open (MCPE-41772, MCPE-41166, MCPE-27167)
  • 改善玩家打开背包界面并打开合成配方界面时的性能
    • Please note - we have made some progress on this and the related bugs, but we are also working on further crafting and inventory optimisations that will be included in a future update
    • 请注意 - 我们已对此以及相关bug取得了一些进展，但我们还在进一步改善合成和物品栏的优化，这些优化将包含在未来的更新中
  • Fixed several crashes that could occur during gameplay
  • 修复了游玩时可能发生的崩溃问题
  • Fixed a crash that could occur when entities like XP orbs touch bell blocks (MCPE-43224)
  • 修复了当掉落经验矿物等实体触碰钟方块时可能发生的崩溃
  • Fixed a crash that could occur when using a crafting table in creative mode
  • 修复了创造模式使用工作台时可能会发生崩溃的问题
  • Fixed a crash that could occur when spawning a Vile Spider from the MINECON add-on pack
  • 修复了使用来自MINECON的附加包生成“VileSpider”怪物可能会发生崩溃的问题
  • Sneezing Pandas no longer crash the game
  • 打喷嚏的熊猫不再会使游戏崩溃
  • Fixed a crash that could occur when suspending the game on Gear VR
  • 修复了在Gear VR上暂停游戏时可能会发生的崩溃问题
  • Fixed a bug that could cause the game to freeze when selecting Save & Quit
  • 修复了选择保存并退出时可能导致游戏冻结的错误
  • Fixed a crash that could occur on Bedrock Dedicated Server
  • 修复了基岩版专用服务器可能会发生的崩溃问题
  • Fixed a crash that could occur when viewing owned skin packs
  • 修复了查看自已拥有的皮肤包时可能发生的崩溃问题
  • Fixed a crash that could occur when the text to speech feature tried to read a special character
  • 修复了当文字转语音功能尝试读取特殊字符时可能发生的崩溃问题
  • General performance improvements
  • 整体游戏的性能优化
  • Improved performance by adjusting the 'RandomStroll' mob behaviour
  • 通过调整'RandomStroll'怪物行为来提高性能

General
整体
  • Text to Speech now only operates when focus is on Minecraft
  • 现在只有在Minecraft运行时才会启用文字转语音
  • Text to speech no longer stops working if too many punctuation marks are used
  • 有太多标点符号时，文字转语音不会再停止运行
  • Choosing the "Allow Games to Speak to Me" option on Xbox now works correctly with Minecraft
  • Xbox上的“允许游戏与我对话”选项现在可以正常在Minecraft上使用
  • Updated text to speech popup text
  • 更新文字转语音的弹出文本
  • Text to Speech now correctly reads the generating world dialog boxes
  • 文字转语音现在可以正常读取生成世界对话框
  • Text to speech will now only auto-enable when the client is set to English
  • 只有当客户端设为英语时，文字转语音才会自动启用
  • Text to speech for touch now uses single tap for focus and double tap for press
  • 文字转语音现在单击进行高亮，双击进行按下
  • Fixed a bug where the text to speech narrator would read world names twice
  • 修复了文字转语音讲述人读取两次世界名称的错误
  • Made further improvements to world saving, to prevent worlds becoming disappearing from the world list
  • 进一步改善世界保存，防止世界从世界名单中消失
  • Worlds should no longer get stuck on the 'generating world' screen when the player is in the end dimension (MCPE-41513)
  • 当玩家处于末地时，进入世界不再卡在“生成世界中”界面上
  • Free preview skins now roam across devices when signed in to Xbox Live
  • 登录到Xbox Live后，免费的可预览皮肤现在可以在不同使用基岩版的设备中漫游

Gameplay
游玩
  • If a player exits and re-enters a world during a Raid, the Boss Bar no longer disappears, and the 'Hero of the Village' effect can still be obtained
  • 如果一个玩家在袭击事件中退出并重进一个世界，事件进度条依然不会消失，并且仍然可以获得“乡村英雄”效果
  • Raids no longer fail to spawn waves while player is flying
  • 当玩家飞行时，袭击事件不会再无法生成波数
  • Reverted the fix for players falling through blocks around blocks 65k from spawn - more work is needed to fully fix this bug! (MCPE-39299)
  • 恢复了离出生点65000格方块会穿透方块掉虚空的特性 - 需要更多的工作来完全修复这个bug！

Mobs
怪物
  • Skeleton horses spawned in from earlier versions can be ridden once again (MCPE-40857)
  • 从早期版本中生成的骷髅马可以再骑一次
  • Removed the distance restriction for phantom spawning, meaning they should spawn more readily now (MCPE-43736)
  • 删除了幻翼生成的距离限制，这意味着它们现在应该更容易生成
  • Villagers can now properly access the entire village outskirts, without showing frustrated particles because it's too far
  • 村民们现在可以正确地进入整个村庄区域，而不会出现沮丧粒子效果，因为它太远了
  • Spawned villagers who are levelled up now start with preferred profession and won't change when introduced to a new village
  • 现在已升级的村民从优先职业开始，并且在加入新的村庄时不会改变

  • Blocks
  • 方块
    • End portal blocks can no longer drop as items (MCPE-42991)
    • 末影珍珠不能再作为普通物品丢弃

  • Items
  • 物品
    • Crafted items will once again stack correctly with partial stacks already in the player's inventory (MCPE-42719)
    • 已制作的物品将再次与玩家背包中已存在的一部分正确堆叠

  • Graphical
  • 图形界面
    • Clouds are 100% more fluffy again (MCPE-43505)
    • 云体积现在再次有100％的蓬松体积
    • On screen animation no longer plays for all mob effects (MCPE-43502)
    • 界面动画不再播放所有怪物效果

  • User Interface
  • 用户界面
    • Ratings button for server consumables now shows 'Rate this pack!' instead of the purchase button
    • 服务器上的消费按钮现在会正确显示“评价这个包！” 而不是购买按钮

  • Add-Ons / Script Engine
  • 附加包/脚本引擎
    • Added component references for new villagers
    • 为新的村民增加了参考组件
    • Original Villager and Zombie variant spawn eggs can still be obtained and used in Marketplace content that utilised them
    • 原始的村民和僵尸变种怪物蛋仍然可以在使用它们的市场内容中获得和使用
