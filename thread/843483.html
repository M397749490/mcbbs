此项目为mcCoder的一个功能。
  • mcCoder
  • mcCoder GitHub
使用说明
  • 下载mcCoder-withmixin
  • 加入项目依赖
  • 在资源文件夹新建文件mccoder.properties，写上modid。
  • 进入游戏。
  • 此时lang/en_us.lang中已经出现该词条。
注意
  • 此mod是为mod开发者准备，非mod开发者请不要下载。
  • 可以被自动生成的词条需满足非本地化名字中带有modid:。
  • 当该词条需要被显示（本地化）时才会自动生成。
  • 更多信息请查看GitHub
