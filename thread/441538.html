  Hello!

If you're interested in testing out this upcoming update head on over to the Preview branch! You can gain access by right clicking on Unturned in your Steam library, selecting properties, navigating to the Betas tab and entering the secret passcode "OPERATIONMAPLELEAF".

Additions:
  • Added perspective command.
  • Added perspective server filter.
  • Added ability to attach in 3rd person.
Improvements:
  • Improved smoothness of all networked objects on the client.
  • Improved vehicles to exit further away when traveling fast.
Tweaks:
  • Tweaked interact distance a bit higher in third person.
Fixes:
  • Fixed highlighting yourself in 3rd person.
  • Fixed player info tags not coloring correctly.
  • Fixed character slot items getting setup in multiplayer.
  • Fixed achievement test code leftover.
  • Fixed zombie related crash when spawning.
  • Fixed colliding with dead zombies on clients.
  • Fixed loading into third person not disabling viewmodel.
  • Fixed password and security filters.
  • Fixed speed reseting on client.
  • Fixed vehicles to use current information when driving.
By default servers are first person only and singleplayer allows both. Use the perspective command in your commands file to set the default first/third/both.
