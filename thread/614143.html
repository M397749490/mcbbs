怎么绑定

只要你不怕服务器的木头泛滥成灾，你把这个自定义后复制到cji的item.yml里
插件请搜索customjoinitem

  1.   
  2. [b][color=Red]#这是第一个设置绑定的命令，那个1可以更换成任何字母或单词[/color][/b]
  3. 1:
  4.   name: '&f树的英文名'
  5. #这里填写树苗的id
  6.   id: xxx     
  7. #这里是要绑定的命令  *表示你要进行生长的树木类型，有3个可选：[tree] [redwood] [jungle],你可以分别给这3种类型分别设置一个这样的绑定
  8.   command: bigtree *'
  9. #这是冷却时间，最好设置一下，除非你想让服务器崩掉，建议你设置为20秒
  10.   cooldown-seconds: 20
  11. #玩家需要的权限，请把种树的权限给予玩家
  12.   permission: 'essentials.bigtree.*'
  13. #是否允许掉落,你这个情况请设置true
  14.   allow-drop: true
  15. #是否允许在背包里移动,你这个情况请设置true
  16.   block-movement: true
  17. #是否在加入游戏后给予,你这个情况请设置false
  18.   give-at-respawn: false
  19. #是否在切换世界后给予,你这个情况请设置false
  20.   give-on-world-change: false
  21. #在哪些世界不可用使用这个功能？不同世界名称之间请用逗号隔开，逗号后面记着打一个空格。像这样：
  22.   disabled-worlds: world, world_nether, world_the_end
  23. [color=Red][b]#这是第二个设置绑定的命令[/b][/color]
  24. 2:
  25. #中英文都设置上防止命令无效。。文字颜色必须是白色《&f》否则无效
  26.   name: '&f树的中文名'
  27.   id: xxx     
  28.   command: 'bigtree *'
  29.   cooldown-seconds: 20
  30.   permission: 'essentials.bigtree.*'
  31.   allow-drop: true
  32.   block-movement: true
  33.   give-at-respawn: false
  34.   give-on-world-change: false
  35.   disabled-worlds: world, world_nether, world_the_end
