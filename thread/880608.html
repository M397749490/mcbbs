创建新物品实体实例，设置位置，然后world.spawnEntity
如果要像平常一样掉落记得setDefaultPickupDelay
如果你让实体掉落的话实体类里面有方法可以快捷掉落物品，还有自带喷溅(像一般实体爆物品一样的效果)

  2. // 伪随机数发生器，用于随机决定掉落物速度，模拟“掉落”的物理效果
  3. private static final Random RAND = new Random();

  5. public static void dropItemStackAsEntity(World world, BlockPos pos, @Nonnull ItemStack toDrop) {
  6.   // 掉落物是实体，所以首先要先有一个实体
  7.   EntityItem entityItem = new EntityItem(world, pos.getX(), pos.getY() + 0.5D, pos.getZ(), toDrop);
  8.   // 速度向量，nextGaussian 返回一正态分布的伪随机双精浮点数，范围 [0.0, 1.0)
  9.   // * 0.05D 避免物品直接嗖一下飞出去。Y 方向多 0.2D 保证它先往上飞一会然后再掉下去。
  10.   entityItem.motionX = RAND.nextGaussian() * 0.05D;
  11.   entityItem.motionY = RAND.nextGaussian() * 0.05D + 0.2D;
  12.   entityItem.motionZ = RAND.nextGaussian() * 0.05D;
  13.   // 最终生成实体
  14.   world.spawnEntity(entityItem);
  15. }
