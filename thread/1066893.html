是 JSON 本身格式有问题, 在 "dependencies": [jei] 那里, JSON 是不允许这种写法的, 必须带上双引号。
我用了一个比较硬核的正则解决这个问题, 加上直接硬拼接字符串, 只敢保证你的这个用例不会报错, 其它的我不敢保证233

import re

# 这里 json_string 是你的 JSON 字符串

json_string = "xxxx"



json_inner = json_string.split("[{")[1].split("}]")[0]

pattern_string = r'"dependencies"\: \[.*?]'

patt = re.compile(pattern_string)

new_json = re.sub(patt, "\"dependencies\": []", json_inner)

new_json = "[{"+new_json+"}]"


实际作用是它会把所有 "dependencies": [xxxxx] 替换成 "dependencies": [], 这种方法 会导致你读不到mod依赖。但是因为你是要去重嘛, 估计这个字段在你的用例里没啥用。
最后输出的标准JSON是 new_json
