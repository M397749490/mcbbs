前言

开发此功能的原因和JText Studio还确实不一样，从名字就可以看出，JText Studio是因为个人使用原因开发的（具体可以看此链接），OOC呢？其实现在基本都是数据包的时代了，几乎不会有人使用这了，但也不外乎一些特殊情况吧。不罗嗦了，看东西.

OOC的生成是使用了pca玩家的pcb核心，个人将其升级到兼容1.13-1.16，软件语法也有一定的借鉴，所以pcb的用户入手会容易点

备注：功能已移植到了vscode，在插件中搜索ooc即可（也可以在下方链接下载），推荐使用vscode插件版，体验更好！





软件特点

入手有一定难度，需要熟悉语法，部分功能仅插件版有，已备注

  • 在线软件，免安装，免费的
  • 游戏兼容性好，1.9-1.16
  • 使用注释注解完成设置，因此兼容mcfunction文件
  • 实时解析当前配置，鼠标移入注解时提供当前配置提醒功能（仅插件版）
  • 实时范围高亮，提供移入注解时当前配置影响的范围（仅插件版）
  • 友好的配置页面，移除了文件开始配置信息的功能，使用vscode设置页面统一配置（仅插件版）
  • 提供注解方面的代码补全功能（仅插件版）
  • conditioned模式的检测（仅插件版）

备注：生成超过32500字符长度时不支持分段，后续会添加

使用

1. 按语法规范编写

2. 网页版：ctrl + G生成代码（P.S. 方块的conditioned模式出现在拐角会失效，暂不支持对conditioned模式的检测，所有设置size时请注意）
    插件版：使用ctrl + k ctrl + g，并且支持conditioned模式的检测





语法

主要思路是采用注解来配置的，这样的好处是兼容高版本的mcfunction文件

  1. # 演示用例
  2. # 名称OOOC，过时的OOC，功能一键命令方块生成器，软件免费
  3. # 使用注解的形式设置参数，因此兼容mcfuncion
  4. # by hans0000
  5. # ctrl + g 生成ooc

  7. # [config]
  8. #
  9. # 设置游戏版本，-version <版本号>（默认新版本）
  10. # OOC共三个版本差异1.9-1.10 1.11-1.12 1.13-1.6
  11. # -version 1.10

  13. # 设置生成OOC的尺寸，-size <x> <z>
  14. # -size 1 1

  16. # -offset
  17. # 设置生成OOC距离触发方块的偏移值，-offset <x> <y> <z>

  19. # init 预处理的指令，一般是积分版之类的
  20. # [init]
  21. scoreboard objectives add timer dummy
  22. scoreboard objectives setdisplay sidebar timer
  23. scoreboard players add @p timer 1

  25. # > 代表命令方块的条件执行（默认无条件限制）
  26. # * 代表命令方块的红石触发（默认保持开启）
  27. # rcb 循环、ccb 连锁、icb 脉冲（默认连锁命令方块）
  28. # 数字 代表当前设置影响的行数，默认到下一个设置

  30. # [rcb 1] 有数字代表仅影响1行
  31. execute as @p[scores={timer=..10}] run say 1
  32. execute as @p[scores={timer=..10}] run give @p stone

  34. # [>ccb] 有>代表是conditioned模式
  35. scoreboard players add @p timer 1
  36. give @p diamond_sword

  38. # [icb*1] 有*代表红石激活，有数字代表仅影响一行，也就是第二行clear指令是默认配置
  39. scoreboard objectives remove timer
  40. clear @a
  41. #
  42. # end OOC生成后处理的指令
  43. # [end]
  44. say thx!
