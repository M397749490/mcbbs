JSON示例

config.json文件

请勿修改":"前的部分，作者一概不为此问题负责！

"name"为菜单的文件名称（以json为后缀名）

"command"内为打开菜单的命令，无需"/"

若还需添加菜单的话请复制"menu"内的内容，并粘贴至大括号下

记得在前面的大括号后加上一个","

  1. {
  2.     "version": "v1.1.2",
  3.     "open": 345,
  4.     "menu": [
  5.         {
  6.             "name": "default",
  7.             "title": "主菜单",
  8.             "command": "menu"
  9.         }
  10.     ]
  11. }
复制代码

default.json文件

请勿修改":"前的部分，作者一概不为此问题负责！

可修改部分："data"，"content"，"text"，"title"，"command"

"content"为菜单的内容

"data"为图片的路径

"text"为按钮的文字

"title"为菜单的标题

"pointX"为是否启用点券扣费功能

"moneyX"为是否启用金钱扣费功能

"point"为点券扣费的数额

"money"为金钱扣费的数额

"command"为按钮点击时执行的命令

注："command"内的指令不需+"/"，且可以执行任何指令

注：在需执行的指令的开头+"{temprary}"即可执行OP可执行的命令

注：在需执行的指令的开头+"{op}"即可使该命令需OP可才执行

注：在需执行的指令的开头+"{cmd}"即可以后台的方式执行该命令

注：在需执行的指令的开头+"{menu}"即可以菜单的方式打开该菜单的文件名

（{temprary}有一个问题，就是执行完该命令后若该玩家突然去世，则会成为永久OP，因此我在{cmd}中补足了一下，也就是说 @s @p 均可在{cmd}中使用，调用原版命令时最好使用{cmd}）
