(2) 添加外部JAR（即Bukkit核心文件）
这就像是一座图书馆，有了它你才能依照Bukkit给的方法来开发插件
> 右键一个项目，点击Build Path(构建路径) >> Configure Build Path(配置构建路径)
> 找到第三个子夹(Libraries)，点击右侧 Add External JARs...，选中你下载的核心文件，点击右下方的Apply and Close(确认并关闭)
然后你就成功令核心文件生效了

(3) 创建包
就像你的书包里的分层
> 展开项目(点击项目左侧三角或双击)
> 右键src文件夹，点击New >> Package，填写Name内容
Name(包名) 不建议写成下面的形式：
a.b.c、ahahahhahahahaha、jon.myplugin.com
建议写成：
域名.任意.还可以加点...

(4) 创建类
如同书包里的一本书
> 右键刚刚的包，点击New >> Class
键入类名，建议首字母大写，例如：Main、MPMain等

(5) 【重要】创建plugin.yml文件
如同你在书包上用马克笔写的名字，方便你我他辨认
这个plugin.yml文件就是告诉Bukkit，这个插件的信息的，没有它，Bukkit就视而不见咯~
> 右键你这个Java项目或者src文件夹(两种做法都行)
> 点击New >> File(文件) e^Asi9GQ
> 在下方输入框内输入plugin.yml，回车或者点确定按钮
然后你会跳转到一个编辑框里面，这时候可以写plugin.yml的内容了，以后想补充，展开项目，双击文件就行啦

plugin.yml内容：
  1. name: 插件名, 不建议中文, 空格会被自动替换成_
  2. main: 主类, 格式为包名.类名
  3. version: 插件版本, 随便写, 不建议中文
  4. author: 作者
  5. # 后面其实还有很多东西，但是目前用不着，就不写了，到后面再讲
  6. # 每行前面带个#就是注释哦
复制代码

例如：
  1. name: MyPlugin
  2. main: com.sombody.Main
  3. version: 1.0
  4. author: Somebody
复制代码
