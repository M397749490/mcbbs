F1：请问Owner Default 和 Builder有区别？分别什么意思？

这是三个权限的分组   
Default是基础分组，一般用来做监狱，谁犯了错就把他拖到这个分组Owner是腐竹分组，这个不可以给玩家，只能给自己，在这个分组的人权利相当大，可已设置OP
Builder分组就是玩家进游戏的默认可以游戏的分组，这是正常的的

F2：请问怎么设置单独世界的权限？区别了默认世界的权限（选择继承了world的users.yml但是独立的groups.yml）

在新版本的ESS插件中可以做到，给你一个连接，最新版的 GroupManager 下载地址 事实上这个插件是ESS插件的附属插件
不可以单独使用的

F3：请问怎么设置一个新的权限组仿照默认的权限？

你应该已经知道用什么办法创建分组了，那我就不再多说了
创建分组之后的第一步需  让新的分组继承 Builder 分组的权限，这么说你可能不理解
换个方法说就是  你创建了一个分组之后，这个分组是没有任何权限的，你需要把Builder分组的权限全部复制过来，这样在新的分组内的玩家才能正常游戏。
那么 复制权限的指令我就给你贴出来
/mangaddi 组1 组2               （让分组1拥有分组2的权限）

下一步就是打开 对应世界的文件夹的Group文件（使用Notepad++打开）  找到你新建的分组的那一行
这里打个比方
  如下，比如我创建了一个VIP分组，
并且已经让他继承了Builder的权限
然后我就要开启他的建筑权限
  1.   vip:
  2.     default: false
  3.     permissions: []
  4.     inheritance:
  5.     - builder
  6.     info:
  7.       prefix: '&a[&cVip&a]&2'
  8.       build: true
  9.       suffix: ''
复制代码
然后保存文件，重启服务器就好了
