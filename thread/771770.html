作者: qq2646088422    时间: 2017-12-14 14:56
权限
deluxemenus.admin :
    说明: 使用管理员指令.
    默认: OP
  deluxemenus.open :
    说明: 可以使用/dm open <菜单名> 来打开菜单.
    默认: OP
  deluxemenus.open.others :
    说明: 可以使用/dm open <菜单名> <玩家名> 给一个玩家打开菜单.
    默认: OP
  deluxemenus.open.bypass :
    说明: 打开一个菜单时,无视打开该菜单需要的权限.
    默认: OP
  deluxemenus.menu.* :
    说明: 所有菜单的权限.
    默认: OP
  deluxemenus.openrequirement.bypass.* :
    说明: 打开菜单时无视所有打开菜单需要达到的条件.
    默认: OP
指令
/dm open <菜单名> <玩家> #给某个玩家打开某个菜单
/dm list  #列出所有菜单
/dm reload #重载插件，(做菜单时常用)

把菜单保存。config文件下更改为这样。
  1. check_updates: false
  2. gui_menus:
  3.   main:
  4.     file: main.yml
复制代码

main改为你需要的菜单名。可任意添加。
之后在deluxemenus文件夹中会有个gui_menus文件夹，里面放的是在config中添加的菜单文件。菜单在其中更改就可以了。一般的菜单大概这样就可以了。
  1. menu_title: 'title'
  2. open_command: main
  3. size: 54
  4. items:
  5.   '0':
  6.     material: 1
  7.     data: 0
  8.     slot: 0
  9.     display_name: 'name'
  10.     lore:
  11.     - 'lore'
  12.     left_click_commands:
  13.     - '[close]'
  14.     right_click_commands:
  15.     - '[close]'
复制代码

直接就按照这个改就可以了。config文件下弄的菜单可能会出现一点问题。
