以下命令执行一次
建立计分板，其中一个用于判断僵尸击杀，另一个用于检测僵尸数量。（其实只用一个也可以）
  1. scoreboard objectives add kills_zomie minecraft.killed:minecraft.zombie
  2. scoreboard objectives add count dummy
复制代码
然后检测僵尸数量并保存至计分板
  1. execute store result score normal_ count if entity @e[type=zombie,name=僵尸]
  2. execute store result score senior_ count if entity @e[type=zombie,name=高级僵尸]
复制代码



以下命令循环执行
检测场上各种僵尸的数量
  1. execute store result score normal count if entity @e[type=zombie,name=僵尸]
  2. execute store result score senior count if entity @e[type=zombie,name=高级僵尸]
复制代码
与之前检测的结果做比较，如果数量减少了，就说明僵尸被击杀，此时可认为在kills_zombie上拥有1分的玩家即为击杀者
  1. execute if score normal count < normal_ count run scoreboard players add @a[scores={kills_zombie=1..}] gold 1
  2. execute if score senior count < senior_ count run scoreboard players add @a[scores={kills_zombie=1..}] gold 5
复制代码
然后更新僵尸数量，并重置kills_zombie计分板
  1. execute store result score normal_ count if entity @e[type=zombie,name=僵尸]
  2. execute store result score senior_ count if entity @e[type=zombie,name=高级僵尸]
  3. scoreboard players reset @a kills_zombie
复制代码

创建金币计分板
创建检测击杀僵尸的计分板
然后高频执行以下命令
execute as @a[scores={检测计分板=1}] at @s if entity @e[type=zombie,name=僵尸,limit=1,sort=nearest] run scoreboard player add @s 金币计分板 1
execute as @a[scores={检测计分板=1}] at @s if entity @e[type=zombie,name=高级僵尸,limit=1,sort=nearest] run scoreboard player add @s 金币计分板 5
execute as @a[scores={检测计分板=1}] run scoreboard player set @s 检测计分板 0
因为生物死亡不会立刻消失，所以可以检测玩家击杀僵尸时附近的僵尸类型，以此来增加金币
另外指令纯手打可能会有错误，自己修正一下，选择器name如果不能用中文，就用nbt检测display中的name

另外还有种方法，就是击杀僵尸让僵尸掉落金币，两种僵尸的金币不一样，检测该金币进入了背包，就增加金币计分板的分数，并移除背包中的该金币
