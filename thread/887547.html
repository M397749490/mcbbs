CitizensShop
公民商店
用NPC创建GUI商店吧！





使用步骤：
(1)前往原帖下载插件(1个) -> 地址
(2)下载前置插件(2个) -> Vault Citzens2
(3)将以上3个插件扔入服务器plugins文件夹
(4)启动服务器，并根据根据下列指令与权限进行配置



指令：
  1. #创建一个NPC -> /createnpcshop <名字>
  2. (别忘了先使用一个棍子选择NPC)

  4. #在选择好的商店(NPC)添加一项商品 -> /citizensshop add <地方> <价格>
  5. #在选择好的的商店(NPC)删除一项商品 -> /citizensshop remove <地方>

  7. #删除商店可以使用指令 -> /npc remove
复制代码


权限：
  1. #创建商店 -> citizensShop.admin
