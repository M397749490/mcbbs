获取一个东西

检测副手是否有这个东西
  1. execute as @a if data entity @s Inventory[{Slot:-106b}].tag.custom run say foo
复制代码




向前射出一支箭
  1. #execute as @a at @s run...
  2. tag @s add player
  3. summon minecraft:area_effect_cloud ~ ~ ~ {Tags:["marker"]}
  4. summon minecraft:arrow ~ ~ ~ {Tags:["aw"]}
  5. execute as @e[type=area_effect_cloud,tag=marker,distance=..0.1] at @s run function foo:bar
  6. execute anchored eyes run teleport @e[type=minecraft:arrow,tag=aw] ^ ^ ^2.5
  7. tag @s remove player
  8. tag @e remove aw
复制代码

  1. #foo:bar
  2. execute positioned 0.0 0.0 0.0 rotated as @a[tag=player] run teleport @s ^ ^ ^1
  3. data modify entity @e[type=arrow,tag=aw,distance=..0.1,limit=1] Motion set from entity @s Pos
  4. kill @s
