标题: 修改 BlockStateTag 和 BlockEntityTag
问题一：是否有方法（穷举除外）可以修改 BlockStateTag？
例如把 ~ ~ ~ 的箱子的 facing 变成 south。
问题二：是否有方法（穷举除外，clone 除外）可以修改 BlockEntityTag？
例如把 0 0 0 的箱子的 所有 BlockEntityTag 复制到 ~ ~ ~ 的箱子。
作者: Chelover_C60    时间: 2020-2-20 20:08
1、可以考虑先把nbt复制一份，然后替换目标方块为指定方块状态的方块，再把nbt加回去？
data modify storage test {} merge from block ~ ~ ~ {}
setblock ~ ~ ~ minecraft:chest[facing=south]
data modify block ~ ~ ~ {} merge from storage test {}
