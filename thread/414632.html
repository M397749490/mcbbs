介绍：
       本插件允许您用中文的指令别名代替英文指令。比如，输入"主城传送"就可以传送到主城，或者使用"/圈地 123"就能创建一个叫123的领地等。(支持MCPC+全版本、Bukkit全版本，Spigot未测试)
【v1.1及以上版本支持使用例如"/主城传送"来到达主城的功能】
【v1.2版本支持使用例如"自杀:OP-kill %player%"来杀死使用命令的玩家的功能】
【v1.4及以上版本支持使用变量,例如"/圈地 123"等于"/res create 123"】
      本插件识别文字时忽略两边的空格和颜色代码，如
"  &a  测试   &b      "跟"测试"是同一个效果。
如果发送的聊天是设置好的指令则不会显示在聊天列表上，但后台会显示
XXX issued chinese command: /xxx
如果执行的命令是控制台命令(v1.2新功能)则会提示
XXX issued console command: /xxx

命令：
/cncmd reload      重载配置(OP指令)


权限：无

注意！v1.4的配置文件跟以前的版本不一样！下面讲的是v1.4的配置，如果只升级jar不更新配置会导致某些功能无法使用!
配置文件(设置指令别名教程，必看)：
本插件的配置文件不是config.yml而是setting.yml
编码：GBK或GB2312
  1. #-----setting.yml-----
  2. # 命令列表
  3. # 添加命令的格式为：
  4. # 第一种：不带'/'的别名(中文别名)
  5. # 别名:命令  (注意是英文冒号)     e.g:   回家:/home
  6. # 第二种：带'/'的别名(中文命令)
  7. # /别名:命令 (注意是英文冒号)  e.g:  /主城传送:/spawn
  8. # 别名无论带不带'/'都可以加入变量
  9. # ---------------------
  10. # 命令可以带'/'也可以不带
  11. # 命令是以玩家自己的权限执行的
  12. # 如果没有按格式添加将会被忽略
  13. CommandList:      #命令别名列表(就是带'/'的别名)
  14. - '/圈地:/res create'       #让玩家使用"/圈地 领地名"的格式来圈地(v1.4或以上)
  15. - '/回家:/home'          #让玩家使用"/回家"就等于使用"/home"
  16. ChatList:              #不带'/'的别名列表   注意:在v1.4前，不带'/'的别名列表跟命令别名列表都是在CommandList里的
  17. - '例子:/spawn'
  18. - '自杀:OP-kill %player%'      #杀死使用“自杀”别名的玩家(v1.2或以上)
  19. # 还可以使用"%player%"来代替使用该命令的玩家名称。(v1.2或以上)
  20. # 如果在要执行的命令前面加上"OP-"，这个命令就会由控制台执行。(v1.2或以上)
  21. # 比如，"自杀:OP-kill %player%"即可杀死使用“自杀”命令别名的玩家。
  22. #-----------------------
复制代码
注意：使用带'/'的别名将会覆盖已经存在的指令（假如有的话）。
比如设置'/spawn:/home'将会覆盖原先的/spawn指令的功能！
P.S:别名不一定要中文，所有GBK编码支持的字符都可以
P.S.P.S:如果还不清楚怎么设置可以来回帖问我
