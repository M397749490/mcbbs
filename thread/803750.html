<li>启动器参数</li>
@echo OFF
Menu   
echo        现在时间为%time%   今天是%date%  
java  -Dfile.encoding=UTF-8 -Xincgc -Xmx1700M -XXMaxPermSize=1000M -jar PaperSpigot-1.12.2.jar      可修改内存大小、核心
@echo 服务器已关闭，将于xxx后重启  控制台提示输出
@ping -n xxx 127.0.0.1nul  xxx可替换为自定义时长，单位秒
@goto Menu
pause



<p>举例：如果xxx为   60，则在服务器关闭60s后自动重启服务器。</p>




<h3>教程</h3>
下载插件，修改配置文件（插件贴有教程）(创建一个定时计划，输出指令为stop)
配合启动器脚本 可实现定时关服  定时启动。


<h3>演示</h3>
config.yml内容
events
     stop
       timing
       occasion every day
       time 0000
listener
      stop
      commands
     - stop


启动器脚本内容
@echo OFF
test
java  -Dfile.encoding=UTF-8 -Xincgc -Xmx1700M -XXMaxPermSize=1000M -jar PaperSpigot-1.12.2-b1471.jar
@echo 服务器关闭，6小时后重启
<url=home.phpmod=space&uid=260039>@ping<url> -n 21600 127.0.0.1nul
<url=home.phpmod=space&uid=1121364>@goto<url> test
pause
