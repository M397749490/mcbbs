简介

没错就是你想象中的那样。这个插件能提供两个或多个传送平台之间的传送功能，就像是武侠小说里面的传送阵法。

它的用途甚广：用于PVP(邪恶的微笑)、挖矿传送、小游戏、大厅的传送（包括主城）、建筑传送……

食用方法

1.把插件jar文件插♂入plugins文件夹中并重启你的服务器

2.根据你的需要更改配置文件（懒人无视），随后重启或重载配置 命令：/enderpads reload

↑↑↑↑↑以上全都是废话↑↑↑↑↑

3.创建传送台：

前提：你要有创建的权限（见后面）

首先，放置一块黑曜石（可在配置文件中换为其他方块，下同）作为传送台的底座。

注：本插件会在外边四个方块组合相同的传送台之间建立一个“组合连接(link combo)”，因此你可以创建很多组对应的传送台而不会互相干扰

若有三个或以上的传送台是同一组合，那么就会在这些传送台间随机传送只要破坏传送台的任意一个方块，传送台就会被销毁

配置文件config.yml

已翻译

  1. General:
  2. ColorfulLogging: true #后台的消息使用颜色代码
  3. DebugMessages: false #输出调试信息 如果你喜欢调试或后台刷屏请开启此功能
  4. LogUse: true #每一个传送台被创建/销毁/使用时在后台输出信息
  5. Cooldown: 6 #玩家使用传送台的冷却时间(秒)
  6. SkipBlockedPads: true #如果是false,玩家可能掉入陷阱
  7. DefaultMax: 2 #默认的创建传送台的数量上限
  8. # # #警告：如果你改变了中心材料所有使用旧材料的的传送台将会在服务器加载此项配置后失效
  9. CenterMaterial: OBSIDIAN~0 #设置传送台的中心材料(默认黑曜石)
  10. # # #警告：如果你改变了中心材料所有使用旧材料的的传送台将会在服务器加载此项配置后失效
  11. Blacklist:
  12. Materials:
  13. -GRASS
  14. - .. #黑名单: 此项中的材料将不允许用于建造传送台
  15. Effects:
  16. Lightning:
  17. OnCreate: true #在传送台被创建时使用闪电
  18. OnDestroy: true #在传送台被销毁时使用闪电
  19. OnUse: true #在传送台被使用时使用闪电

API

本搬运帖不面向开(da)发(lao)者(men)，原文内容如下


At this point in time, there is not an official API. However, there are three events you can use in your own plugin. They can all return the EnderPad and Player object responsible.


  • EnderPadUseEvent | Fired after a successful use of an EnderPad. Cancelling this will cancel the teleportation.
  • EnderPadCreateEvent | Fired when an EnderPad is successfully constructed. Cancelling this will stop the EnderPad from being saved.
  • EnderPadDestroyEvent | Fired when an EnderPad is successfully destroyed. Cancelling this is not recommended. Also, Player can be null, if it wasn't a player breaking the EnderPad to begin with.
