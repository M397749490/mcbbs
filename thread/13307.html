作者: green丶bastard    时间: 2011-11-24 06:29
  Admin Commands 管理员指令
[] - Mandatory必须
() - Optional 可有可无

Command - command's syntax 指令
Permission - command's permission node权限
Description - short description of the command 介绍

Command 指令
 Permission这个是个文件可以无视的 Description
/citizens citizens.admin.info View general Citizens information
看citizen插件的资料
/citizens debug citizens.admin.debug Toggle debug mode, if debug is on, debug messages will print to the console
切换debug mode看看有啥漏洞
/citizens reload citizens.admin.reload Reload Citizens configuration files
重新加载插件的设置文件
/citizens save citizens.admin.save Save Citizens files
保存插件的文件
/citizens clean citizens.admin.clean Removes all "ghost" entities in your world
将所有“幽灵”怪物从地图中拿走

  General Commands一般的[] - Mandatory必须
() - Optional 可有

Command - command's syntax指令
Args Description - description of the command's arguments 指令附加
Require Selected - whether the command requires an NPC to be selected指令需求
Require Ownership - whether the commands requires you to be the owner of the NPC对npc的所有权
Permission - command's permission node权限
Description - short description of the command介绍
Command Args Description Require Selected Require Ownership Permission Description
/citizens help (page) page - page to view
page是输入help页数例如1，2
 false
无 下面不在翻译
 false citizens.basic.use.help 看帮助
/npc help (page)同上 false false citizens.basic.use.help View the help page for Citizens
/npc None 是 false citizens.basic.use.info View information on the selected NPC
看选取npc资料
/npc create [name] (text) name - npc名字
text - t右击npc他说的话		 false false citizens.basic.create 创建npc
/npc move None true true citizens.basic.modify.move 移动mpc
/npc moveTo [x y z] (world pitch yaw) x y z - 坐标轴
world - 想把npc已往的世界
pitch - 方向
yaw - 这俩我觉得没啥用的。。		 true true citizens.basic.modify.moveto 移动npc
/npc copy None true true citizens.basic.modify.copy 复制npc 要权限的
/npc remove (all) all - Removes all NPCs true (only for /npc remove) true (only for /npc remove) citizens.basic.modify.remove or citizens.basic.modify.remove.all for /npc remove all 弄走所有npc
/npc rename None true true citizens.basic.modify.rename 重命名npc
/npc color &[code] code - 颜色的代码 ps的都知道（color你妹的渣美佬英语）
 true true citizens.basic.modify.color 换npc颜色
/npc set [text] text - 给npc说的话 true true citizens.basic.modify.settext 设置npc的话
/npc add [text] text - Text to add to an NPC, split lines with
tag		 true true citizens.basic.modify.addtext 给npc再加话
/npc reset None true true citizens.basic.modify.resettext 弄走npc说的话
/npc equip None true true citizens.basic.modify.equip 编辑npc持有物
/npc tp None true true citizens.basic.use.teleport 传送到npc那
/npc talkclose None true true citizens.basic.modify.talkclose 设置npc在你接近说不说话
/npc lookat None true true citizens.basic.modify.lookat 设置npc在你接近转不转身看你
/npc select [id] id - npc的id false false citizens.basic.use.select 设置npc装备
/npc setowner [player-name] player-name - 玩家名 true true citizens.basic.modify.setowner 设置npc主人
/npc list (name) (page) name - 玩家或者自己名
page - 页数		 false false citizens.basic.use.list 看自己或他人拥有的npc
