一般像这类mod自带世界的都会继承到主世界的权限。
这个显然是这个世界没有配置权限的一系列问题。
看你用什么全显著插件了，比如如果是GroupManager插件。
你就打开这个权限组的配置文件，config.yml，找到mirrors节点。
在下面把这个豆腐的世界添加进去，你看看这个
  1.   mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds:
  16.           - users
  17.           - groups
