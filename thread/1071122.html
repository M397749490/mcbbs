知识之书（Knowledge Book）是一种使用后可以让玩家获得指定合成配方的实用物品。

/gamerule doLimitedCrafting设置为true时，你只能用已经解锁了的合成配方来合成物品，而知识之书正是用来解锁合成配方的。


知识之书目前只能通过使用命令获得。

比如说，要给予玩家a可以解锁桶和花盆的合成配方的知识之书，请输入这条命令：/give @a minecraft:knowledge_book{Recipes:["minecraft:bucket", "minecraft:flower_pot"]}。

知识之书可以解锁配方，但是需要通过/give指令获得。

所以首先设置/gamerule doLimitedCrafting true然后/give @a Minecraft:knowledge_book{Recipes:["minecraft: carrot_on_a_stick"]}

胡萝卜钓竿的wiki链接：https://minecraft-zh.gamepedia.com/胡萝卜钓竿

知识之书的wiki链接：https://minecraft-zh.gamepedia.com/知识之书

啊，我突然想到好像记分板也行。
先聊天栏输入命令
  1. /scoreboard objectives add crafted_carrot minecraft.crafted:minecraft.carrot_on_a_stick
复制代码

放一个保持开启，里面写
  1. execute as @a[scores={crafted_carrot=1..}] run clear @s minecraft:carrot_on_a_stick
复制代码

再放一个保持开启，里面写
  1. execute as @a[scores={crafted_carrot=1..}] run scoreboard players remove @s crafted_carrot 1
复制代码

这样好像可以检测所有类型的合成胡萝卜钓竿，用钓鱼竿+胡萝卜和两根胡萝卜钓竿的合成都行。
