ItemRename —— 物品改名



插件介绍
Description — 简介

顾名思义就是指使用命令来更改物品的叙述（Lore）与名字（Name）
Required — 需求

  • JAVA 8
  • Spigot 1.8+


图片展示


配置说明
  1. #默認權限，可以更改

复制代码


命令与权限说明
Commands — 命令


  • /item - 查看帮助
  • /item setname <name> - 设置物品名字
  • /item setlore <lore> - 设置物品叙述 - (使用%nl%来换行)

Permissions — 权限

  • item.rename - 允许使用插件命令

默认的权限，可以从config.yml里去更改
