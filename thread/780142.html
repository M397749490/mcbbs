NTools是一个轻量级的插件，旨在为建设者和服务器管理员提供一些常见的烦人，复杂或耗时的任务的快速且简单的解决方案。

NTools目前提供了两个解决方案：

堵塞有障碍的区域并在非正方形的区域去除区块。

这两项任务都可以用WorldEdit完成，但是NTools提供了一种更快更简单的解决方案。

只需放置一个块即可完成（而不是每次选择两个位置并使用一堆命令）。


1.QBC（快速屏障栏）：立即在特殊块的Y轴向上创建可配置的障碍物！有用的快速区域阻止！

2.QDD（快速摧毁）：在Y轴上立即销毁一个可配置数量的障碍，特殊块被放置（向下）。有用的快速删除难以获得（与世界编辑）地区！

这两项都是你放下方块后的特殊效果！



效果图








特点
1.超简单的设置和使用！
2.有效并且省时！
3.插件的每个方案都是可配置的！
4.拥有安全系统，以确保只有管理能使用特殊块！
5.直接从游戏中改变值！
6.没有复杂的命令或位置！
7.所有1.9以上版本的方块！
8.非常轻量级，不会落后于任何服务器！
9.如果有要求功能在评论部分或与作者讨论！[转于原贴讨论谢谢，或在此帖@我来转达]






指令
/ nt - 主要命令！
/ nt get - 获取特殊方块的命令！
/ nt config - 配置方块的行为和值！
/ nt版本 - 查看插件的版本
/ nt重新加载 - 重新加载config.yml（手动编辑配置时需要）
举个栗子：
/nt get QBC
/nt get QDD
/nt config skip true
/nt config height 120
/nt config destroyamount 30





权限
ntools.use -使用NTOOLS所有命令的权限
