RandomHashTags

1.8-1.13


介绍 · Introduction
玩家可直接获得经验瓶、怪物或破坏方块掉落的经验而无需捡起满地的经验球!
- 兼容经验修补附魔

配置
  1. # 插件开发者: RandomHashTags
  2. #
  3. # 权限
  4. #
  5. ## RandomOrbsorber.block
  6. ### 允许玩家直接获得破坏方块的经验
  7. #
  8. ## RandomOrbsorber.entity
  9. ### 允许玩家直接获得击杀生物的经验
  10. #
  11. ## RandomOrbsorber.mending
  12. ### 允许玩家直接获得的经验用于经验修补
  13. #
  14. ## RandomOrbsorber.xpbottle
  15. ### 允许玩家直接获得经验瓶的经验

  17. # true = 启用 | false = 关闭
  18. ## 如果关闭则上述权限无效
  19. block: true
  20. entity: true
  21. mending: false
  22. xpbottle: true
