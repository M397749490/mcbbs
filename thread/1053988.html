需要说的核心就是两个东西，一是鼠标准星，二是盔甲架的动作

盔甲架动作：
以亚索为例，关于亚索盔甲架的动作用的函数就在行为gesture的文件夹内，核心是gesture11.mcfunction
在这个函数里我们一共用了37个计分板，其中一个是rate，控制盔甲架动作的速度

剩下36个分别代表：头 左手 右手 身体 左腿 右腿 6个部位的X Y Z轴。一个部位有X Y Z三个轴，这看起来似乎18个计分板就够了呀？
确实，18个计分板就可以很好的控制，但是，我们要的是能够让盔甲架像动画一样让每一个部位的动作都有一个运动的过程。
简单来说，盔甲架每一个部位的所在的每一根轴，都有两个计分板来对应，一个计分板是该部位当前动作所处的值，另一个计分板是你想要让这个盔甲架的这个部位移动到某个位置的值

举个例子：我们来控制盔甲架的头在y轴的动作  现在我们有计分板heady和head2，指令如下
  1. execute as @e[tag=gesture] at @s if score @s heady < @s head2 run scoreboard players add @s heady 1
  2. execute as @e[tag=gesture] at @s if score @s heady > @s head2 run scoreboard players remove @s heady 1
  3. execute as @e[tag=gesture] at @s store result entity @s Pose.Head[1] float 1 run scoreboard players get @s heady
  4. execute as @e[tag=gesture] at @s store result score @s heady run data get entity @s Pose.Head[1]
复制代码
有tag=gesture的，就是我们需要控制的这个盔甲架。
显然第三行指令是用于更改盔甲架head在y轴的位置。第四行就是获取更改之后的位置的值。
再看第一二行，如果heady的值大于（或小于）head2的值，那么heady就加（或减）1，这就可以体现盔甲架某个部位从一个位置运动到另一个位置的过程。


比如，当前heady的值为0，你想要转动90度，你就可以scoreboard players set @e[tag=gesture] head2 90  那么它的头就会在y轴一度一度的运动到90度位置。
但是这个过程需要4.5秒，一秒20度，太慢了，所以我们做进一步的修改：
  1. #heady
  2. execute as @e[tag=gesture,scores={rate=1..}] at @s if score @s heady < @s head2 run scoreboard players add @s heady 1
  3. execute as @e[tag=gesture,scores={rate=2..}] at @s if score @s heady < @s head2 run scoreboard players add @s heady 2
  4. execute as @e[tag=gesture,scores={rate=3..}] at @s if score @s heady < @s head2 run scoreboard players add @s heady 3
  5. execute as @e[tag=gesture,scores={rate=4..}] at @s if score @s heady < @s head2 run scoreboard players add @s heady 4
  6. execute as @e[tag=gesture,scores={rate=5..}] at @s if score @s heady < @s head2 run scoreboard players add @s heady 5
  7. execute as @e[tag=gesture,scores={rate=6..}] at @s if score @s heady < @s head2 run scoreboard players add @s heady 10

  9. execute as @e[tag=gesture,scores={rate=1..}] at @s if score @s heady > @s head2 run scoreboard players remove @s heady 1
  10. execute as @e[tag=gesture,scores={rate=2..}] at @s if score @s heady > @s head2 run scoreboard players remove @s heady 2
  11. execute as @e[tag=gesture,scores={rate=3..}] at @s if score @s heady > @s head2 run scoreboard players remove @s heady 3
  12. execute as @e[tag=gesture,scores={rate=4..}] at @s if score @s heady > @s head2 run scoreboard players remove @s heady 4
  13. execute as @e[tag=gesture,scores={rate=5..}] at @s if score @s heady > @s head2 run scoreboard players remove @s heady 5
  14. execute as @e[tag=gesture,scores={rate=6..}] at @s if score @s heady > @s head2 run scoreboard players remove @s heady 10

  16. execute as @e[tag=gesture] at @s store result entity @s Pose.Head[1] float 1 run scoreboard players get @s heady
  17. execute as @e[tag=gesture] at @s store result score @s heady run data get entity @s Pose.Head[1]
复制代码

这里我们就使用了rate计分板，用来控制部位的转动速度
当rate=1，每tick可以转动1度，
当rate=2，每tick可以转动1+2度
为什么我没有直接写转动3度而是写的转动2度然后保留转动1度？
因为这样可以保证盔甲架运动到你设置的位置是精确的
用指令控制盔甲架其他的部位就同理了，这样写的好处是什么？
这样你就可以很方便的控制盔甲架，对于一个部位你想对他做什么操作你只需要将计分板设置到一个值就可以了，从而实现了盔甲架的动画过程

鼠标准星判定：
判定鼠标准星的问题简单的做一个就行了，原理就是用一个实体以你自己的朝向往前tp，然后递归就完事了，不需要太精确，能用就行。实体一般可以选择使用药水云，或者盔甲架，如果是盔甲架的话，记得给这个盔甲架加上marker:1使这个盔甲架的碰撞体积变小
在该数据包里面，我们使用的实体是tag=gouzi的药水云：
summon minecraft:area_effect_cloud ~ ~1 ~ {Tags:["gouzi"],Pose:{Head:[0F,0F,0F]},CustomName:"2333",Potion:CBC,Age:0,Duration:3000,Color:0,Radius:0,RadiusOnUse:0,RadiusPerTick:0}
因为这个部分不难，所以不多说，如有不懂的参考该数据包的mousepos.mcfunction 和test.mcfunction

至于里面有一个glowing.mcfunction则是玩家鼠标对准了某个指定的实体之后因为会给该实体一个发光的效果，当鼠标移开这个实体时，该实体任然会发光一会儿
glowing.mcfunction的作用就是鼠标移开实体后，这个实体的发光效果会立马清除（其实这个问题在给发光的时候直接data就解决了，只不过我用了effect，算是多此一举吧）

英雄的移动，行走、停止动作：
通过前面展示的亚索的行走我们可以知道，我们是像英雄联盟一样，鼠标右键（用萝卜钓竿来判定）点击地面，然后英雄会移动到鼠标点击处，这个实现起来很简单，因为我们已经有了鼠标准星的判定，所以我们只需要检测以下两种情况：
1、玩家右键且药水云碰撞到了方块
2、玩家右键且药水云碰撞到了实体
当玩家右键且药水云检测到了方块（或实体），那就在这个位置或者这个实体做个标志，然后让亚索盔甲架移动到这个标志即可
（此处参考click.mcfunction和follow.mcfunction）

以点击地面为例：
（click.mcfunction）
  1. execute as @e[type=minecraft:area_effect_cloud,tag=gouzi1] at @s if block ~ ~ ~ #minecraft:ground if entity @a[tag=player2,scores={click1=1..}] run kill @e[tag=click1,tag=ground1]
  2. execute as @e[type=minecraft:area_effect_cloud,tag=gouzi1] at @s if block ~ ~ ~ #minecraft:ground if entity @a[tag=player2,scores={click1=1..}] run summon minecraft:armor_stand ~ ~0.2 ~ {Tags:["click1","ground1"],NoGravity:1b,Invisible:1b}
  3. execute as @e[type=minecraft:area_effect_cloud,tag=gouzi1] at @s if block ~ ~ ~ #minecraft:ground if entity @a[tag=player2,scores={click1=1..}] run particle minecraft:portal ~ ~ ~ 0.1 0.2 0.1 0.1 200
  4. execute as @e[type=minecraft:area_effect_cloud,tag=gouzi1] at @s if block ~ ~ ~ #minecraft:ground if entity @a[tag=player2,scores={click1=1..}] run scoreboard players set @a click1 0
复制代码

当玩家对着地面（#minecraft:ground）右键时，先清除已经存在的tag=click，tag=ground的盔甲架，然后再在点击的位置，即玩家右键时药水云所在的位置再召唤一个tag=click，tag=ground的盔甲架，为了确定点击的位置，可以再在这一瞬间加一个粒子效果确认你是否点击了，最后清除玩家右键萝卜钓竿的计分板

此时我们有了一个tag=click，tag=ground的盔甲架，我们就让亚索向这个盔甲架移动：
（follow.mcfunction）
  1. execute as @e[type=armor_stand,tag=yasuo,tag=!attack] at @s facing entity @e[distance=0..,tag=click,tag=ground,scores={time2=..1}] feet run tp ^ ^ ^0.5
  2. execute as @e[type=armor_stand,tag=yasuo,tag=!attack] at @s facing entity @e[distance=0..,tag=click,tag=ground,scores={time2=4..}] feet run tp ^ ^ ^0.3
  3. execute as @e[type=armor_stand,tag=yasuo,tag=!attack] at @s if entity @e[tag=click,tag=ground,distance=..0.5] run kill @e[tag=click,tag=ground]
复制代码

当亚索移动到tag=click，tag=ground的盔甲架时，就清除这个盔甲架。
此外，在这里移动的时候我用了两条，差别在于里面的计分板判定，scores={time2=..1}和scores={time2=4..}，作用就是给亚索一点时间来转身而不是立马就移动，如果点击之后立马移动会导致亚索这个盔甲架表现出来的朝向与你点击的位置不一致


关于亚索行走和停止的动作就很简单了，行走的时候当然是 左脚前左手后右脚前右手后  左脚后左手前右脚后右手前，设置计分板分数让盔甲架能实现这一动作即可
  1. # 左手前右手后 右脚前左脚后  左
  2. execute as @e[tag=yasuo,tag=walking,scores={leftarmx=45}] at @s run scoreboard players set @s leftarm1 -45
  3. execute as @e[tag=yasuo,tag=walking,tag=!attacking,scores={rightarmx=-45}] at @s run scoreboard players set @s rightarm1 45
  4. execute as @e[tag=yasuo,tag=walking,scores={rightlegx=45}] at @s run scoreboard players set @s rightleg1 -45
  5. execute as @e[tag=yasuo,tag=walking,scores={leftlegx=-45}] at @s run scoreboard players set @s leftleg1 45

  7. # 左手后右手前 右脚后左脚前  右
  8. execute as @e[tag=yasuo,tag=walking,scores={leftarmx=-45}] at @s run scoreboard players set @s leftarm1 45
  9. execute as @e[tag=yasuo,tag=walking,tag=!attacking,scores={rightarmx=45}] at @s run scoreboard players set @s rightarm1 -45
  10. execute as @e[tag=yasuo,tag=walking,scores={rightlegx=-45}] at @s run scoreboard players set @s rightleg1 45
  11. execute as @e[tag=yasuo,tag=walking,scores={leftlegx=45}] at @s run scoreboard players set @s leftleg1 -45

然后就是判定亚索是在行走还是在站立不动的问题，用一样东西来作为参考就行了，比如盔甲架（在这里就是tag=gensui的盔甲架），分别获取亚索和tag=gensui 在x和z轴的坐标
  1. #x轴
  2. execute as @e[tag=yasuo] at @s store result score @s positionx run data get entity @s Pos[0] 10
  3. execute as @e[tag=gensui] at @s store result score @s positionx run data get entity @s Pos[0] 10
  4. #z轴
  5. execute as @e[tag=yasuo] at @s store result score @s positionz run data get entity @s Pos[2] 10
  6. execute as @e[tag=gensui] at @s store result score @s positionz run data get entity @s Pos[2] 10
复制代码


用这个盔甲架作为参考来判断亚索到底是行走还是停着的
  1. # 走跑
  2. execute unless score @e[tag=gensui,limit=1] positionx = @e[tag=yasuo,limit=1] positionx unless score @e[tag=gensui,limit=1] positionz = @e[tag=yasuo,limit=1] positionz run tag @e[tag=yasuo] add walking
  3. execute unless score @e[tag=gensui,limit=1] positionx = @e[tag=yasuo,limit=1] positionx unless score @e[tag=gensui,limit=1] positionz = @e[tag=yasuo,limit=1] positionz run tag @e[tag=yasuo] remove standing
  4. # 站立
  5. execute if score @e[tag=gensui,limit=1] positionx = @e[tag=yasuo,limit=1] positionx if score @e[tag=gensui,limit=1] positionz = @e[tag=yasuo,limit=1] positionz run tag @e[tag=yasuo] add standing
  6. execute if score @e[tag=gensui,limit=1] positionx = @e[tag=yasuo,limit=1] positionx if score @e[tag=gensui,limit=1] positionz = @e[tag=yasuo,limit=1] positionz run tag @e[tag=yasuo] remove walking
复制代码
这就实现了当亚索的xz坐标与tag=gebsui的盔甲架xz轴不一致时，表明亚索在移动，当他们的xz轴一致时，表明亚索在站立不动，
以上指令还无法实现该效果，因为还需要我们开始参考的判定：
  1. # 让盔甲架慢于玩家的判断
  2. scoreboard players set @e[tag=yasuo,scores={time=10..}] time 0
  3. scoreboard players add @e[tag=yasuo] time 1
  4. execute as @e[tag=yasuo,scores={time=0..1}] at @s run tp @e[tag=gensui] ~ ~18 ~
复制代码

这样做就是每0.5s中会有0.1s会对亚索的位置进行判断，简单来讲就是参考延迟，因为如果
execute as @e[tag=yasuo,scores={time=0..1}] at @s run tp @e[tag=gensui] ~ ~18 ~这条指令中不加入scores={time=0..1}，那么亚索永远都是处于站立不动的状态，加了scores={time=0..1}之后，亚索一移动，就有一段时间会让该盔甲架与亚索位置不一致，从而判定亚索在行走。

关于地图英雄的控制：
控制亚索：/scoreboard players set @s hero 1
控制劫：/scoreboard players set @s hero 2
自由移动：/scoreboard players set @s hero 0
关于亚索如何操作：
选中热键栏1时：Q键释放Q技能，F键释放E技能，右键为移动
选中热键栏2时：右键释放W技能
选中热键栏3时：技能亮起时，右键释放R技能
关于劫如何操作：
选中热键栏1时：右键移动
选中热键栏2时：释放Q技能，右键移动
选中热键栏3时：右键释放W，再次右键可与W分身互换位置
选中热键栏4时：释放E技能
选中热键栏5时：释放R技能，右键可与R分身互换位置
