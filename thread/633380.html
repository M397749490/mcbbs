前言：
3天没有发MOD了，另外，这个MOD汉化的内容好多！（话说这个MOD竟然没有wiki）

简介：
这个MOD为Minecraft增加了RPG元素。

首先，增加了玩家等级系统。玩家可以花费你Minecraft里的经验来升级。

MOD有以下玩家属性：最高生命值、法力（是自己的哦）、生命值、恢复法力、力量（提高物理抗性）、敏捷（提高攻击速度）、智力（提高魔法伤害）、不同运动属性（移动速度、跳跃等等）和其他。

第二，MOD为Minecraft所有生物也增加了等级系统。生物越生成在离玩家重生点更远的地方，等级会更高。生物每50米增加1级每一等级会增加生命和伤害。

第三，还增加了：
许多不同的武器、工具、盔甲和剑。
工具材料增加了黑曜石、基岩、黑质、白质。
一些武器和盔甲种类，例如小刀、武士刀、镰刀等等。
魔法权杖、造成魔法伤害、消耗玩家的法力。
5x5大小工作台
玩家菜单 - 提高玩家属性和查看装备。

所有武器、工具和盔甲都可升级。在未来的更新中每级会提高一些物品属性。现在只能提高耐久（15级为无限耐久）

未来特性：
新的玩家属性
新的物品和物品属性
新的高等级生物的战利品
宝石系统（嵌入宝石提高属性）
魔法
自己的生物（遥远的将来）
地牢系统（遥远的将来）

作者原文：

Whats's about this mod?
This mod will add an element of RPG in your Minecraft.

At first, mod adds system of player's level. Player can spend some your minecraft's level to raise your stats.
At this moment, mod has the following player stats: max health, mana (yes, this mod adds its own mana), health and mana regenerations, strength (increases phisical damage), agility (increases attack speed), intelligence (increases magic damage), different motion attributes (move speed, jump, etc), passive phisical and magic immunity and other.

Secondly, mod adds level system for all mobs in minecraft. The farther mob spawns from player's spawn point, the higher level it gets. Mob gets one lvl point for each 50 metres from player's spawn. Each lvl point adds to mob some stats (health, damage).

Thirdly, mod adds:
  • A lot of many different weapons, tools, armors and bows.
  • Tool materials such as obsidian, bedrock, black matter, white matter.
  • Some weapon and armor types such as knife, katana, scythe, hammer, magic armor and other. Each type has its own item stats. For example, damage, speed, swing range, magic resistance, phisical resistance.
  • Magic staffs, which deals magic damage and spends player's mana.
  • Workbench 5x5.
  • Player's menu - place, when you can increase player stats or see an equipment.
All weapons, tools and armors are levelable too. In the future each level will increase some item stats. Now it increases only max durablity (at 15 lvl adds infinite durability).
In future
  • new player stats;
  • new items and item stats;
  • new loot from high lvl mobs;
  • system of gems (you can insert a gem in any item and get a passive features of some kind);
  • magic;
  • its own mobs (in distance future);
  • system of dungeons (in distance future).

Notes
Mod adds level system for all mobs (and from other mods too) notes in config file. You can activate level system for all mobs, or for your own list (look in config file, by default all mobs are activated). The same applies for items. You can activate item stats in config (by default activated only default Minecraft items and DangerRPG items).

Installing the mod
1. Make sure Forge is installed.
2. Put the jar in your mods folder.

FAQ
- I have a bug to report/suggestion to make!
If you find a bug or have an idea to improve this mod, contribute to the issue list!

- I want DangerRPG in my mod pack!
DangerRPG, being under the MIT License, is frequently used in modpacks. Feel free to redistribute it! My only request is to provide a link to this thread.

- I want to contribute!
If you feel like doing some modding, the source code of this mod is freely availablehere. Feel free to improve it by adding new features or fixing bugs! Some ideas are already listed in the "issues" section.
