概述：

Server Command GUI (SCG) 是设计给那些服务器管理的mod，让管理变得更加简单。当然对于那些已经习惯了输入指令的人，啥都一样。不过其实这东西对于需要输入指令的人，效果都一样。
本mod提供了一个简洁的菜单界面来使用服务器指令。指令被分组管理，使得玩家跟容易找到他们，同样这个mod也有一些自动化的地方，比如可从列表中选择玩家姓名作为输入


详细：

Version 2
Version 2.0 基本上是重写了mod，提高了此mod的各个方面.
  • 玩家互动界面更简洁
    • 合适的为外观，并不是纯文字Proper looking menus, not just text.
    • 选择中的选项，会有特殊的显示效果（背景变亮，字体变暗）.
    • 读取时的读取条.
    • 图标.
  • 支持原版（单人或者多人）和bukkit指令
  • 新的命令检测系统New command detection system checks which commands the server will let you run.
  • UI界面支持鼠标和键盘UI now supports mouse as well as keyboard
  • 增加了帮助界面（按H）Built in help. Point to icon or press H.
  • 改进了数字，玩家，物品的数据输入Improved data entry for numbers, players, items, etc.
  • 支持其他mod，可以装在其他mod增加的指令，并且他们拥有一个独立的指令列表.
    • 支持林业指令列表.
    • 未来会有更多.


控制:
C - 打开指令界面 (可以在设置菜单中更改changable from settings menu).
方向键或者鼠标 - 控制菜单.
回车或者鼠标 - 选择已选中选项Select the item or execute the command.
Esc - 关闭菜单Close the menu.
H - 显示帮助.
