2.插件编辑





插件下载后装入了服务器，但是有很多功能都是可以自定义的。
那么如何自定义实现自己满意的插件配置呢？要通过配置文件夹.
通常配置文件夹在插件载入后自动生成。以插件名字的文件夹形式存在。
这时要通过传输文件夹到自己电脑进行修改，一般新人都会使用记事本修改。
但是记事本看起来很乱，而且很容易出现问题导致插件无法读取。
我推荐使用notepad++进行编码，修改插件配置。下载地址：点我
编辑时注意选用格式，win系统的服务器使用ANSI编码，linux系统使用UTF-8编码。
至于你的服务器是什么系统，这个要问你的服务商了。

4.推荐增加插件

1.地皮插件 这个插件大家也耳熟能详了，用于创建一个格子世界，供玩家领取，用于建筑生存，下载地址：点我

         2.看了地皮插件你们肯定想问他们那种点击木牌领取地皮的插件是什么，这玩意叫脚本方块，下载地址：点我
脚本插件我就讲讲基本用法，像那种右键执行一个指令的方法为，输入/sbinteract create @comman /(命令)指令
（命令）可以写任何玩家有权限执行的指令，比如你绑定/spawn 那么玩家右键绑定了指令的方块就会回到主城
假如你想弄点击领取地皮的就输/sbinteract create @comman /p aut就行
如果你要绑定一个传送点就绑定/warp (坐标名字) 就能实现简单的传送
同理，你把sbinteract换成sbwalk即可设置为踩踏触发式
如果想让玩家无视权限实现指令就用/sbinteract create @bypass /(指令)来实现
这个我常用的就是，领取快捷菜单，领取新手礼包，等等等~
其他食用方法我就不一一列举了，只想说这个插件用处太大太广，你想法到了他就能给你实现~

5.全息显示 这个插件也是很有用的一个插件，用于创那种浮空的字体，能展示一些信息，也支持一些变量
创建教程：首先输入/hd create <编号> 创建一个权限字体
然后输入/hd addline <编号> <内容>添加信息，支持彩色字体，&u为变颜色
删除多余的或者错误的内容输入/hd removeline <编号> <行数>进行删除
其他更详细的指令和变量我就偷下懒了，去原[url=]Flash[/url]帖看看把，喵~  下载地址：点我


6.公告插件 这个插件用于服务器自动发生一些信息，大家肯定也都知道是个什么玩意，这里我就教教大家怎么配置就行了
我把我服务器的配置直接发出来，你们生成了插件配置文件直接复制粘贴就行，然后再改
settings:
  enabled: true
  min-players: 0
  log-to-console: false
message-lists:
  default:
    enabled: true
# 下面的200 是公告发送间隔，单位是秒复制的时候把我这行删掉，其他都不要改
    interval: 200
    expiry: -1
    random: false
    prefix: "公告前缀"
    suffix: ''
    messages:
    - "公告内容": []
    - "可以多行，也支持颜色代码": []
直接把上面的全部复制就行，插件下载地址：点我
