配置

= = = = = = = = = =[聊天格式]= = = = = = = = = =

  • nukechat.chat ——聊天的许可。true为可聊天，其他为不可聊天
  • nukechat.chat.color ——允许字体用颜色

= = = = = = = = = =【自定义频道】= = = = = = = = = =

  • nukechat.customcommand.join——允许加入所有频道。
  • nukechat.customcommand.leave.all ——允许玩家将所有频道。

= = = = = = = = = =【加入/退出消息】= = = = = = = = = =

  • nukechat.message.all——允许有加入/退出游戏的消息。
