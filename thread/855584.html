你好依照你的问题，这里我给出了几个解决这些问题的办法。

worlds:
  世界名字:
    plot:
      height: 64 #高度 一般不用动它
      size: 50 #地皮大小(这里无法做到如同楼主所说的非正方形的50*40大小的)
      filling: #地皮表面以下的方块ID
      - '3:0' #泥土一般不用管
      floor:
      - '2:0' #地皮表面的方块 一般都是草方块 别动
      bedrock: true #是否有基岩
      biome: FOREST #地皮上的自然群系
      auto_merge: true #玩家有多块地皮是否自动合体
      create_signs: true #自动创造牌子
    wall:
      block: '44:0' #没认领前围墙的方块
      block_claimed: '44:1' #认领后围墙的方块
      filling: '1:0' #围墙下面的方块
      height: 64 #高度 一般不用动
    road:
      width: 7 #马路的宽
      height: 64 #马路的高 一般不用动
      block: '155:0' #马路方块
    home:
      default: side #传送到家时在地皮外面 好像是这样翻译 不用改就是了
      allow-nonmembers: false #允许没有地皮建筑权限的人也可以破坏 也不用改就是了
    schematic: #这个属于后期的高级教程 以后慢慢说
      specify_on_claim: false
      on_claim: false
      file: 'null'
      schematics: []
    economy:
      prices:（合并费用和出售费用看楼主要不要，不要就改成0即可）
        merge: 100.0 #合并费用
        sell: 100.0 #出售费用
        claim: 5000.0 #认领费用
      use: true #是否开启
    chat:
      enabled: false #地皮是否默认开启聊天模式
    limits:
      max-members: 128
    world:
      max_height: 256
      gamemode: creative
      min_height: 1
      border: false
    event:
      spawn:
        egg: false #允许丢鸡蛋生成动物
        breeding: false #允许动物交配
        custom: true
    natural_mob_spawning: false #怪物生成?
    flags: {}


然后配合多世界管理插件，我这里先给出MV的因为用的比较多么
/mv modify set pvp false                #这里在地皮世界输入即可作用是禁止PVP（不过好像本来地皮没有建筑权限就没有PVP的吧。。）

还有一种就是地皮设置flag
