           我的世界新手开服教程.发帖一次也是最后一次了昂~   其实么  每个开服器都能用的~别说开服器烂~只是你连的网烂~   你要么是自己家的网线.要么就是连别人的.   但是你们没有发现.连到路由器上  根本开不了  公共服~只能用蛤蟆吃对不对.要是你插到矛上试试~   怎么样.  应该把开服器打开 就可以了吧~         下面是教程        点击开始  就是电脑左下角的  东东     看见有个运行了么      你们肯定说 是的      把那个打开  就是这个样子                 上面写 请键入程序丶文件夹丶文档或Internet 资源的名      在打开 那里输入 cmd  记住一定要连到矛上~    点击确定OK  比方 上面写 Microsoft Windows XP [版本 XXXXXXXXX]       C  版权suoy   0000-0000 Microsoft Corp     C:\Documents and Settings\Administrator>在这后面 输入 ipconfig   记住 是ipconfig      输入后   就显示出 3种IP  一个是 Hamachi 的  一个是本地连接          随后一个   是 PPP adapter 宽带连接    在  IP Address .......：这个后面就是你服务器IP    恩    不管哪个开服起都可以的  记住哦    ！！！！~~~~~        下载插件那些就自己琢磨把 . 打字好累的              如果觉得地图不行  好 就打开 开服器点入后  找world    那里面就是地图了     你只要把里面的东西覆盖了就OK    还有个小文件  就是 server.proper ties  的#Minecraft server properties
#Fri Apr 05 17:10:05 CST 2013
generator-settings=
allow-nether=true
level-name=world
enable-query=false
allow-flight=false
server-port=25565
level-type=DEFAULT
enable-rcon=false
level-seed=
server-ip=
max-build-height=256
spawn-npcs=true
white-list=false
spawn-animals=true
snooper-enabled=true
hardcore=false
texture-pack=
online-mode=false
pvp=true
difficulty=1
server-name=Unknown Server
gamemode=0
max-players=20000
spawn-monsters=true
generate-structures=true
view-distance=5
spawn-protection=0
motd=1.4.7MCPC mod+plugins
你会看见这样  慢着 找到  max-players=  后面写数字 就是进你服务器的人数 我  弄的是 20000  你们 如果家里网速好  也就20000就差不多了  反正也是装逼    进步了那么多             好累    就 这样了   泽泽                  第一个帖子 也是最后一个的说~                         就到这里了 拜拜~
