说来这个问题真有点没料到。

我这里手上的Minecraft1.14.x基本都是在旧电脑上下载，然后迁移到新电脑上的，当时玩1.14.3原版时Panorama是村庄掠夺的。然后开学，大致半年没有搓游戏，最近放假才重新开始搓，结果 开 幕 雷 击
（其实是今天才开始重视，毕竟无意间发现jar的CRC32和官方源完全一致）



于是发现主菜单Panorama变成海洋更新的了？？？？？？？

个人对该问题的研究
1.首先我测试1.14~1.14.4（除了1.14.1，嫌负优化不稳定）以及截图中的Forge Mod包，全部遇上Panorama停留在海洋更新问题，都是上方截图那样的问题。
2.我首先怀疑是启动器问题，然后更换其他第三方启动器，Panorama还是错的
3.然后怀疑是Vanilla jar（香子兰罐头）被谁动过了，于是使用官启重新下载了1.14.4原版（保存在另一个文件夹），比对CRC32如下：
--官方源：
    jar    330d2184
    json  df030eb4
--第三方启动器声称的官方源：
    jar    330d2184
    json  7575c1ac

4.根据json的CRC32不同这个线索，用官启启动官方源的1.14.4原版，未出现问题。
5.将官方源json覆盖掉第三方启动器给出的json，然后启动修改过的1.14.4原版，问题依然存在。
6.改用第三方启动器启动1.14.4原版，未出现问题。

现状
1.Panorama问题仅出现在“第三方启动器声称的官方源”中。
2.修改过1.14.4.json后，Forge依然正常启动，没有提示MD5不匹配。
3.官启和第三方启动器这两个.minecraft文件夹中的assets文件夹差别巨大，官启的有从1.10.2到1.15.1的若干版本，第三方启动器的仅有1.14.x的若干快照/预览版（以及愚人节更新）以及正式发布版1.14/.2/.3/.4。（个人习惯将版本号为1.a.b的Minecraft按1.a分类）

提问
1.该问题原理，是否和assets文件夹有关
2.该如何解决
