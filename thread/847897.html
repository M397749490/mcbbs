标题: 如何让服务端生成含有mod内容的地图
我按着一些教程弄了个服务器，运行于某云，centos7，就3-4个好友玩
去弄了个bukkit 1.12.2，plugin因为太复杂所以一个都没装（人少都是好友也没必要弄
弄了个客户端，丢了一些mod进去
开服用的是这条指令
#!/bin/sh
screen -dmS mc java -Xms1G -Xmx2G -XX:+AggressiveOpts -XX:+UseCompressedOops -jar /root/craftbukkit/craftbukkit-1.12.2.jar


问题是：我的mod包含神秘时代6，以及一些其他应该会在地图上生成的mod要素
但是在开服后逛了逛并没有发现

个人初步判断是因为mod安装在客户端，服务端在生成地图时按照原版生成了出生区块周围的地图，所以找不到mod矿物
可能走远一点继续生成地图后会有矿物，但是没有验证
顺便问一下，在没有安装插件的情况下如何弄简单的权限？我目前想gamemode0来快速向外探索验证问题，但是没有权限。好像之前看到说bukkit有简单的权限配置文件
看了地图后发现初始生成区域挺大的，要往外探索很烦。
同时我担心即使玩家向外走继续生成地图也无法刷出mod矿物（因为切不了创造故无法验证）而且已经探索的地表部分没有发现mod内容
我有查到一些说mcpc+可以做服务端mod，但都是1.7的很久远的文章
也有看到有人说本地生成地图然后导入服务器，但是在所有开服教程文章中都没有提及这件事，而且我也担心上述的“向外走继续生成地图也无法刷出mod矿物”

所以就是如何初始生成地图时包含mod内容？如何玩家探索时生成的区块包含mod内容？如何利用bukkit自带的文件简单的弄弄权限？

1.craftbukkit，spigot，paper这些bukkit服务端只能安装插件，无法安装Mod，因此不可能包含任何Mod内容。如果楼主想进行Mod联机，必须要使用包含forge的服务端。鉴于楼主只是和朋友一起玩，推荐安装forge到1.12.2官方服务端中开服。
2.原版服务端只有简单的权限系统，即op身份验证，包括/gamemode在内的大部分命令只有op才能使用。在服务端后台输入 /op 玩家ID 就可以任命玩家为op。鉴于楼主只是和朋友一起玩，就不需要更复杂的权限系统。
