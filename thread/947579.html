My Plot ( 家园系统  )

属于 PocketMine 的高性能地皮家园系统

命令列表：
  • /p addhelper - 给予玩家权限
  • /p auto - 随机认领地皮
  • /p biome - 改变地皮生物群系
  • /p claim - 认领脚下地皮
  • /p clear - 清除地皮
  • /p denyplayer - 拒绝玩家访问
  • /p dispose - 出售地皮
  • /p generate - 创建地皮世界
  • /p give - 将地皮给予其他玩家
  • /p help - 列表帮助菜单
  • /p home - 返回地皮
  • /p homes - 列出可返回地皮
  • /p info - 列出地皮信息
  • /p list - 列出地皮列表
  • /p middle - 传送至地皮中心
  • /p name - 重命名地皮
  • /p pvp - 切换PVP模式
  • /p removehelper - 删除玩家权限
  • /p reset - 重置地皮
  • /p setowner - 重新设置地皮主人
  • /p warp - 传送至地皮
