怎么给戴皮革帽子的人加分 不用/stats
必须要支持多人
作者: ⊙v⊙    时间: 2017-7-29 20:31
  1. /scoreboard objectives add namehere dummy
  2. /scoreboard players set @a namehere 0
  3. /scoreboard players set @a namehere 1 {Inventory:[{Slot:103,id:"leather_helmet", tag:{display:{Name:"helmetname"}}}]}
复制代码
建立namehere计分板 dummy类设置所有玩家namehere分数为0
设置所有103位为皮帽且皮帽名字为helmetname的玩家分数为1
