PlaytimeReward

PlaytimeReward是基于PlaytimePlus的一款附属插件，因为目前看来，PlaytimePlus的功能仅仅是游戏时间排行榜，和游戏时间的查询，并无奖励类型设定，这款插件便提供了PlaytimePlus奖励机制。
配置文件 Config

  1. #Rewards

  3. reward1:
  4.    hours: 0
  5.    minutes: 10
  6.    seconds: 0
  7.    reward:
  8.       - 'say §c玩家 §3%player% §c在线奖励发送完毕！'
  9.       - 'give %player% minecraft:diamond 5'
  10.       
  11. reward2:
  12.    hours: 0
  13.    minutes: 2
  14.    seconds: 0
  15.    reward:
  16.       - 'say §c玩家 §3%player% §c在线奖励发送完毕！'
  17.       - 'give %player% minecraft:diamond 5'
  18.       - 'effect %player% minecraft:speed 120'
  19.       
  20. reward3:
  21.    hours: 0
  22.    minutes: 13
  23.    seconds: 30
  24.    reward:
  25.       - 'say §c玩家 §3%player% §c在线奖励发送完毕！'
  26.       - 'give %player% minecraft:diamond 5'
  27.       
  28. #You can add more rewards!
复制代码
（注：个人发现，配置中没有附带奖励提醒，个人建议使用全服通告奖励，颜色代码为原版符号§，奖励不仅仅是给予物品，可以使用指令，玩家变量：%player%，信息发送后显示是 [Server] say的内容，目前个人不知道前缀[Server]如何修改，若有dalao知道，还望告知。）
