作者: SkyCatcher    时间: 2013-9-14 17:05
automessage插件
config里面
  1. settings:
  2.   enabled: true
  3.   min-players: 0
  4.   log-to-console: false
  5. message-lists:
  6.   default:
  7.     enabled: true
  8.     random: false
  9.     interval: 600
  10.     expiry: -1
  11.     prefix: '&e[公告] '
  12.     suffix: ''
  13.     messages:
  14.     - '&b你们别好别乱搞破坏! ！'
  15.     - '&b第二条信息！'
复制代码
请注意如果要加标点，先切换至英文模式，否则可能会报错
interval: xxx是间隔，以秒计算
