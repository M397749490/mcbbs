非常简单的一个小模组，仅供单人客户端
当你加载并进入MC主界面后，或者是进入世界以及进入服务器后会发出声音
这个声音是可以在配置文件中修改的


把它叫做“Ding”模组是因为这声音就好像是你捡到经验球一样


不需要iChunUtil
（本Mod作者是iChun）


配置文件：
  1. # Configuration file

  3. ding {
  4.     # Minecraft name of sound file to play
  5.     # EG: "gui.button.press" or "random.orb"
  6.     #
  7.     # This can also be a mod sound if the mod is installed.
  8.     # EG: modname:modsound.boing
  9.     S:name=random.orb

  11.     # Pitch of the sound to play
  12.     D:pitch=1.0
  13. }
