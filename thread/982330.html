插件介绍
Interaction Lock is a light weight, operator only plugin, it is used to lock/unlock ALMOST anything in the game! (List of supported blocks below)
互动锁是一个很小（5.22KB）的插件.他可以用来锁定所有可交互的东西.
如：门，工作台，桌子，铁砧，桌子，炉子，漏斗，门，信标，按钮，杠杆等
插件权限
无
插件指令
/LOCK-(此处的消息是可以自定义的)    例如：此箱子已锁定
/unlock
/lockcancel
/unlockcanel - /lockcanel的别名.
