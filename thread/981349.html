BirthPoint
出生点管理与多功能设置家


目前功能


    1.是否拉回主城

    2.是否在死亡的地图的出生点复活

    3.自定义设置家的数量

    4.自定义设置家的冷却

    5.自定义安家费（需有EconomyAPI）

    6.自定义禁止设置家的世界

    7.返回上次死亡的地点

    8.玩家花钱自由设置公共传送点

    9.OP设置官方传送点

配置文件


是否拉回主城: false
是否在死亡的地图复活: true
设置家的数量: 3
设置家的冷却: 60
安家收费: 0
# 费用为0则是关闭
禁止设置家的世界:
  - zc
玩家设置传送点的费用: 10000
# -1则是玩家不可以自由设置传送点
# 请注意 传送点一旦设置之后是公共的 全服玩家可见的
最多可设置的传送点数量: 1000
# 相对于全服玩家
禁止设置传送点的世界:
  - zc



  指令


   /back                              回到上次死亡的地点

         /设置家 名称                    设置一个家

   /回家 名称                       回到一个家

   /删除家 名称                    删除一个家

  /家列表                            已经设置的家的列表

/allcmd                              用法示例： allcmd givemoney%@a%1000   @a代表在线的所有人

/设置传送点                        打开设置传送点的GUI界面
