你把block/cube加上"shade":false，再给block/block加上"ambientocclusion":false，游戏内绝大多数方块都会被处理。
下面就是修改过的两个文件（记得把注释去了）

方块模型加上"shade":false和"ambientocclusion":flase，并禁用父模型，例如这样（修改自1.15的草径原版模型）：

  2. {
  3.         "ambientocclusion":false,
  4.         "textures":{
  5.                 "particle":"block/dirt",
  6.                 "top":"block/grass_path_top",
  7.                 "side":"block/grass_path_side",
  8.                 "bottom":"block/dirt"
  9.         },
  10.         "elements":[
  11.                 {
  12.                         "from":[0,0,0],
  13.                         "to":[16,15,16],
  14.                         "shade":false,
  15.                         "faces":{
  16.                                 "down":{"uv":[0,0,16,16],"texture":"#bottom","cullface":"down"},
  17.                                 "up":{"uv":[0,0,16,16],"texture":"#top"},
  18.                                 "north":{"uv":[0,1,16,16],"texture":"#side","cullface":"north"},
  19.                                 "south":{"uv":[0,1,16,16],"texture":"#side","cullface":"south"},
  20.                                 "west":{"uv":[0,1,16,16],"texture":"#side","cullface":"west"},
  21.                                 "east":{"uv":[0,1,16,16],"texture":"#side","cullface":"east"}
  22.                         }
  23.                 }
  24.         ]
  25. }
复制代码

当然这样会因为没有display数据从而导致物品拿在手上的样子很不正常，但是如果只是需要抠图的话可以临时凑合一用
