这个插件就行，可以把命令绑定到任何一个方块上去
比如：如果想右键一个牌子得到称号
  1. /sbinteract create @bypass /manuaddv <player> prefix 称号
复制代码

输入完后右键牌子就能把这个命令绑定上去，这是无视权限的给予，任何人都能用
  1. /sbinteract create @bypass 指令
复制代码

如果想给予物品
  1. /sbinteract create @bypass /give <player> 方块ID 数量
复制代码

能绑定任何指令
/sbinteract 改为 /sbwalk 能变成踩到一个方块执行指令，比如传送地标什么的
  1. /sbwalk create @bypass /warp 地标名
复制代码
