功能

功能:
         主要是对玩家一些事件的操控，可以用于群组的登陆服来实现一些保护。比如设置登陆服不能丢弃跨服菜单=w=
           所有控制均可以在配置文件里面开启或者关闭QwQ

暂时写了：

+聊天控制
+丢弃物品控制
+摔落控制
+游戏模式自动设置         
+物品栏保护(玩家无法移动物品栏物品的位置)

计划更新的功能
* 踩踏耕地控制
*PVP控制

*破坏控制

~GUI菜单设置

命令与权限

命令:
/pmreload  重载配置文件                          对应权限: pm.admin
其他: pm.chat          无视聊天禁用，比如你在配置文件里禁用了聊天，但如果你有这个权限，你依然可以聊天。




配置文件


  1. # ++++++++++++++++++++++++++
  2. # + PlayerManager-玩家管理 +
  3. # ++++++++++++++++++++++++++
  4. #作者QQ: 1609403959
  5. #MCBBS ID: jebme
  6. #强制设置玩家游戏模式
  7. #0是生存，1是创造，2是冒险模式，3是观察者模式
  8. gamemode: 0
  9. #是否取消玩家掉落伤害(true就是取消伤害，false就是不取消)
  10. antifalldamage: false
  11. #是否禁止玩家聊天(true就是禁止,false就是允许玩家聊天)
  12. #拥有pm.chat权限的玩家无视该设置可以聊天
  13. playerchat: false
  14. #是否禁用玩家丢弃东西(true就是禁止,false就是取消)
  15. playerdropitem: false
  16. #是否禁用玩家移动背包内物品位置(false就是不禁用,true就是禁用)
  17. clickitem: false
复制代码
乱码自行转码！
配置文件在plugins/PlayerManager文件夹里config.yml
建议使用notepad++编辑
