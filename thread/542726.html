4.死亡的人实体自动在死亡地点生成一个实体
求解

作者: 爱心魔王FHC    时间: 2016-1-18 19:59
/scoreboard players set @a  计分板名称 1 {SelectedItem:{id:minecraft:物品名称, Damage:数据值/损伤值,Count:数量}}
effect @a[score_计分板名称_min=1,score_计分板名称=1] 效果 秒数 倍率 隐藏粒子

给谁造成伤害？

testfor @e[name=Boss名字] {HealF:指定剩余血量f}
用比较器连接释放技能

/scoreboard players set @a  计分板名称 2 {HealF:0}
/execute @a[score_计分板名称_min=2,score_计分板名称=2] ~ ~ ~ summon 实体
