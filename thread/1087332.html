食用方法:

使用Java11启动服务端(这样才能保证使搭路插件完美运行)
启动指令
java -jar -Xmx1024mb -Xms1024mb PaperSpigot-1.8.8-433.jar

# 前头java 指向的是C盘里的(不一定) 需要Java11启动

#-Xmx1024mb 为最大内存

#-Xms1024mb 为最小内存

#如 "D:\JDK\bin\java.exe" -jar -Xmx1gb -Xms1gb PaperSpigot-1.8.8-433.jar
