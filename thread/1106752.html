NekoGuard

一款开源的使用 InfluxDB 进行记录数据的综合查询回档插件
本插件支持以下事件的记录和查询:
  • 方块防置和破坏(包括玩家和其他实体)
  • 容器操作(物品放入拿取)
  • 实体生成和死亡
  • 玩家聊天和命令
  • 玩家上线下线位置和IP
  • 物品掉落和拾起
  • 实体和方块爆炸
  • 作物生长、冰雪产生和消融(默认不记录)

本插件支持以下操作的回档:

  • 方块放置和破坏
  • 容器操作
  • 实体击杀和生成


本插件与其他类似插件(如 CoreProtect)相比具有的特性
  • 支持自动定时删除数据
  • 更直观的数据显示模式, 并且是全中文
  • 支持全局查询、全局回档模式
  • 容器和物品操作查询支持直接拿取物品到背包中
  • 查询玩家登陆信息时无权限者可隐藏IP
  • 支持撤销多个回档操作
  • 支持点击方块、容器或实体直接查询相关信息
  • 提供了丰富的 API 供使用 (Gradle和Maven依赖请看项目 README)
  • 支持自定义查询时间间隔
  • 支持自动合并物品操作(如漏斗漏出相同的一个物品会合并成一堆物品再记录)
  • 更高的写入性能(由 InfluxDB 提供)
  • 支持爆炸溯源(如谁点燃了TNT或苦力怕以及恶魂火球因攻击何人而射出)
  • 代码完整开源
