—— 指令 ——
                                         /pman - 打开GUI菜单 管理所有已安装插件
                      /pman help - 显示插件管理器的帮助信息
                      /pman enable <plugin|all> - 启动单个或所有插件                                    
                     /pman disable <plugin|all> - 禁用指定或所有插件                                    
   /pman restart <plugin|all> - 重启指定或所有插件                 
                   /pman load <plugin|all> - 安装加载指定或所有插件                       
                  /pman unload <plugin|all> - 卸载指定或所有插件                                 
       /pman reload <plugin|all> - 重新加载指定或所有插件               
                  /pman info <plugin> - 显示插件管理器的版权信息和版本号
                   /pman commands <plugin> - 显示指定插件的所有指令                              
       /pman cmdlookup <command> - 显示某指令属于哪个插件的                     
                   /pm list - 显示所有的插件列表
