4.开始搭建
①首先掌握几条常用命令
Ls  显示所有文件夹以及文件
Cd  进入文件夹
Vi   修改文件（只能修改文本文档类型）
！qw 保存并退出修改文件
！q 不保存，直接退出
./   执行某文件

yum  install automake
yum  install libtool
yum  install autoconf
yum  install m4

⑤安装PE版0.11.X服务端
输入命令
wget -q -O -http://get.pocketmine.net/ | bash -s - -v development

五 开服去玩吧。。
运行命令
Screen –S 名字   创建一个会话
Screen –x 名字    打开一个会话
（上面2个命令经常用到，也很重要。具体我不多解释，不会请百度。）然后在运行命令
./start.sh开服
然后就可以关闭软件。
PS：如果你的IP是共享的请在后面对接上端口号
比如： 123.123.123.123：端口
映射的端口都是随便你填的 一般都是5位数以上 6位数一下。

PC：
1.下载server.jar
2.把server.jar放入一个空文件夹
3.运行一下server.jar
4.打开server.properties，把文件内容替换成如下格式
#Minecraft server properties
#Mon Mar 02 12:58:40 CST 2020
spawn-protection=16
max-tick-time=60000
query.port=25565
generator-settings=
force-gamemode=false
allow-nether=true
enforce-whitelist=false
gamemode=
broadcast-console-to-ops=true
enable-query=false
player-idle-timeout=0
difficulty=easy
spawn-monsters=true
broadcast-rcon-to-ops=true
op-permission-level=4
pvp=true
snooper-enabled=true
level-type=default
hardcore=false
enable-command-block=false
max-players=20
network-compression-threshold=256
resource-pack-sha1=
max-world-size=29999984
function-permission-level=2
rcon.port=25575
server-port=45190
server-ip=0.0.0.0
spawn-npcs=true
allow-flight=false
level-name=world
view-distance=10
resource-pack=
spawn-animals=true
white-list=false
rcon.password=
generate-structures=true
max-build-height=256
online-mode=false
level-seed=107038380838084
prevent-proxy-connections=false
use-native-transport=true
enable-rcon=false
motd=A Minecraft Server
（小声BB：如果没有看见server.properties的话，请重复步骤2）
4.打开终端，进入当前目录，输入如下指令即可启动服务器
java -Xmx2048M -Xms1024M -jar server.jar -nogui
