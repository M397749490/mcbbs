  18.     @Override

  28.     }
  29. }
复制代码


不过提醒一下，猪人进入地狱门是极少出现的
大型地狱门刷怪塔的原理是地狱门会生成僵尸猪人，你可以在spigot.yml中
将enable-zombie-pigmen-portal-spawns的值设置为false来禁用地狱门生成僵尸猪人：
  1. enable-zombie-pigmen-portal-spawns: false
