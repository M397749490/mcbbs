介绍：
【愚人节限定】OMG方块们既然都复活啦！调皮可爱的方块宝宝们活蹦乱跳的，快来领养一只吧~
改造自PetteriM1的宠物插件，方块宠物会随玩家上下线。
注意：部分透明方块（如火、钟等）会显示为隐形宠物

使用：
将本插件丢进服务端plugins文件夹内，重新启动服务器即可。

命令&权限：
命令
权限
默认拥有者
说明
/bpet add <玩家名> <方块ID> [方块数据值]blockpets.manageOP为玩家添加方块宠物
/bpet remove <玩家名>移除玩家的方块宠物

配置：
config.yml
  1. # 配置版本，请勿编辑
  2. configVersion: 2
  3. #宠物显示名颜色
  4. nameTagColor: "§b"
  5. # 是否在主人传送时传送宠物
  6. teleportPets: true
  7. # 玩家数据，请勿编辑
  8. players:
