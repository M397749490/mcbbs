Hector的科技生存整合
(Hector's Tech of MC)






版本：1.12.2 Forge-14.23.5.2847



                   前 言                      

      感谢各路对MC模组开发或转载的人士。我在几年前发过一个的整合包，整合的是困难生存，可惜当时1.9.4还算比较新的版本，能给出的可用模组并不多。即使是这样，我到如今还是看到有人在下载。直至今日上一个整合包已有大量的下载量，让我很震惊。实际上上一个整合包质量并不是很好，比较偏向纯生存，内容相对也不算多。发新的整合包的想法其实也有很久了，只是因为我一直鸽，只顾着自己玩，一直没分享出来(就是因为嫌弃码字太麻烦)，如今我就把我觉得比较好的整合包发出来，整合包在不断更新，欢迎你提出意见或者建议。



[整合包根据反馈已进行调整更新，下载收藏的朋友请考虑升级]



————————整合包介绍————————
         该整合包以机械和魔法为主，魔法指的是神秘6，作为魔法模组大帝，神秘时代一直是每场优秀的模组，我很喜欢探索的过程，尤其是在神秘时代内引入自我研究和让人觉得神奇的要素以及神秘的世界观......整合的过程中，我在想如果仅仅有这两种元素其实也不是很好。
        我之后又引入了对MC生存机制改变的模组，比如你需要营养均衡，你需要用工具做食物而不是直接在工作台中合成，你需要有更多的动作，你会遇到各种令人抓狂的生物比如蚊子老鼠和食人鱼，你会遇到各路奇怪而可怕的生物，你有非常可爱的女仆，你有实现大型工厂自动化一键管理的能力，你能用科技改变自己的生存方式，最后你甚至能企及太空，探索无边无际的世界真理，你还能利用更多装饰性模组，达成科技与艺术的完美结合。最后你发现世界并不只是表面那么简单，再一次触碰水晶之后，你发现了一个前所未见的魔法世界，你学会了解构自然，发现了异域世界的惊悚，创造了甚至能掌控自然的道具。世界正处于你的脚下.....

——我喜欢未知，这能给我带来心理上的满足感。那种为了快乐而产生的求知欲，才是我创造动力的源泉。



——模组介绍（主要部分）——


1.[AE2]appliedenergistics2-rv6-stable-7
应用能源2 家喻户晓的自动化模组，通过该模组能做到各种自动化一键操作，模组的兼容性也一直很好，相比一代引入的频道概念也容易被人接受。通过该模组，你可以使周围一切都变得自动化，冶炼操作合成收集等烦人的操作都可以化简，烦人的物品管理和箱子也被该模组所取代。也许这个模组没有什么确切的目的，但只要当你了解该模组之后，你会发现这个模组才是作为自动化真正不可或缺的部分，如果你不会玩该模组，强烈建议观看B站大佬教程https://www.bilibili.com/video/av36739266其中讲述的非常明确，易学易懂。
~
2.[AE2扩展]ae2stuff-0.7.0.4-mc1.12.2
应用能源2的扩展模组，加入了几个非常实用的工具如网络可视化工具、晶体催生仓的进化版本，以及压印器的改进版，科一次性加工一组产物等，其他实用工具请体验。
~
3.[AE2 更多存储单元]ExtraCells-1.12.2-2.6.5
应用能源2的扩展模组，加入了更多存储设备，支持气体、和流体的接口或者终端等。由于流体在正式模组中已有，实际上只是引入了气体部分，但却依然非常实用。
~
4.[蹬墙跳]walljump-1.12.2-1.2.3
这是一个改善机制的模组，这允许你最高一次性跳到3格高地地方，很多时候在挖矿的时候就不需要总是搭方块在自己脚下。面对墙体按下Shift不放抓住墙体后松开Shift即可再次跳跃，限制是不可以在同一平面上连续跳跃两次，所以在面对两面墙时你就可以回转跳反复上升。实际测试发现就算你使用真男人挖矿法想再回到地表只要不断蹬墙跳就行了
，此外模组修改了摔落伤害的判定，若不是很高的地方跳下去是不会掉血的。

~
5.[车万女仆]touhoulittlemaid-1.12.2-1.1.9-release
酒石酸大佬经常更新的船新女仆模组，非常非常非常非常可爱的女仆（幻想乡我来了）。该模组女仆目前可以做到喂食、守卫、光源、攻击、收获、漫游等功能。引入了多方块祭坛，非常有东方韵味，非常强大的声优模组，让人赞不绝口，这将是在你生存过程中必不可少的伙伴。模组还加入了许多装饰性物品，打破方块限制，甚至还有压路机和新宝岛(玩梗NB)，模组在持续更新中。

~
6.[盖亚魔典3]GrimoireOfGaia3-1.12.2-1.6.9.3
该模组的作者加入了非常多的生物，作者的初衷是提供一个较为困难的环境，以供玩家挑战自己，建议面对这些生物在前期要逃走，不要无脑硬钢。

~
7.[潘马斯农场]Pam's+HarvestCraft+1.12.2zf
丰收工艺和潘马斯的结合体，提供了一系列新的食物和收获方式，扩展了渔业、林业，带来更多的养老休闲方式。

8.[额外食物]XL-Food-Mod-1.12.2-1.9.2
超多额外食物，潘马斯农场的附属，提供了近200+种食物，你还怕营养不均衡？！

加入了史蒂夫的营养均衡体系，你需要摄入不同种类的食物以确保自己的身体均衡，在均衡程度高时，你会获得相应的增益的buff，反之当你某种营养确实不良时，会引起某些debuff，保持健康的身体，不要工作过度也是一种非常必要的过程。

12.热力膨胀5

——环境要求——

以因特尔处理器为例，我在做出大型工厂建设的过程中发现，机器唤醒的区块过多（超过9个区块）还是会一定程度上考验CPU的能力，因此请至少使用intel7代及以上处理保证高集成机器下依然能流畅运行。另外我整合了星空材质包和个别光影，我的电脑太渣，截图的时候就没打开了。 内存设置 至少2000MB，推荐使用java8，而不推荐使用openj9。





——已知BUG——

1.[轻量]在第一次打开游戏加载世界时有低几率未响应卡死，这时需要重启整合包，这是由于在进入世界时大量世界缓存数据加载导致的假死，你可以选择等待或者重启重试。1.12.2版本该问题在许多整合包中出现几率比较频繁，应该是和官方优化有关。建议在BetterFPS选项卡中设置算法为原版可以有效解决该问题。

2.[严重--已解决]出于未知原因，我看过好几次崩溃报告，目前无解。在某些时候使用背包内的手动合成时，有极小几率退到主界面。在合成台则不会出现。
（手动合成指的是直接使用材料在背包内搭建合成方式，若想100%避免该情况，请使用原版自带的合成书直接点击要合成的物品，不用去搭建合成方式）

3.[轻量]通用机械里有一个非常耐人寻味的BUG，水是一种液体，水蒸气是一种气体，而“蒸汽”却是一种液体。意思就是通用机械认为水有三种形态：液态、水蒸气态、和蒸汽态？？？水蒸气和水的蒸汽竟然不是同一种东西。所以在热力锅炉或者核反应堆中取出蒸汽时，请使用机械管道。

问：哇，伙计，你的这个整合包进度也太慢了吧，我玩了这么久什么时候才能上太空啊？

答：我整合的整合包就是专门用来联机或者作为一个长期游玩的整合包，发展进度会比较慢，正常的地图种子下想快速发展到打死末影龙也是比较中后期的事，我们追求的是体验游玩的探索过程，而不是直接发展到无敌。
~

问：这整合包怎么像别人说的一样不刷怪啊？我需要大量粘液球怎么办？
答：不刷怪的原因在BUG区我已给出，更多说明请看历史更新日志，新版本已无此问题。至于粘液球，以这种材料为例，除了从史莱姆身上获得，也可以从鼻涕虫身上获得。有些东西则可以取代粘液球，比如合成粘性活塞的时候，沥青则可以代替粘液球合成粘性活塞。更多合成方式请看JEI。
~
问：这些模组我都不会玩怎么办啊？

答：不要担心，探索和学习是一个非常有意思的过程，B站有各式各样的教程；MC百科（强烈推荐）站记录了几乎所有模组的信息，按照给出的物品介绍顺藤摸瓜即可。部分模组游戏内自带游玩手册(如车万女仆的指导书)，多学习，多探索，你会从中获得求知带来的快乐。

~
问：常常有人和我反馈说JEI的合成查找关系不会？
答：默认情况是这样的，物品合成有”该物品的合成方式“和”该物品能参与的合成方式“。如果你的鼠标有鼠标3和鼠标4按键，我默认设置了鼠标3是查看参与合成、鼠标4是查看如何合成该物品。查找的方式非常简单，在JEI列表里对着你想查找的物品点击相应的鼠标按键即可，并且对背包内的物品也同样有效。如果你的鼠标没有鼠标按键3和鼠标按键4，请到设置里选项中调整相应的按键，设置成方便你操作的样子。

不刷怪的原因
野外的蜜蜂是一种敌对生物，他会攻击附近所有的生物，很多中立生物会被其消灭，多留意。
如果想让黄蜂这种生物猎杀者消失，请到整合包根目录下confing中找到“hatedmobs.cfg”，编辑其中的
        # Set to false to disable wasps
        B:wasp=true

改为
        # Set to false to disable wasps
        B:wasp=false

即可。

新版本中该问题已解决，使用新版本即可。

Open GL 1281 错误
你遇到的应该是OpenGL错误1281，极有可能是因为你使用了其他材质包导致的。

新版本已经解决该问题，使用新版本即可。
