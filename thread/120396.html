其实1.5.2 MCPC+几乎兼容了所有bukkit插件，当然你可能要牺牲掉一些MOD。
具体什么参数和意义需要去官方网站查，需要修改bukkity.yml文件配置。我贴一段供大家参考。
  1. plugin-settings:
  2.     default:
  3.       debug: false
  4.       custom-class-loader: true
  5.       use-guava10: true
  6.       remap-nms-v1_5_R2: true
  7.       remap-nms-v1_5_R1: true
  8.       remap-nms-v1_4_R1: true
  9.       remap-nms-v1_4_6: true
  10.       remap-obc-v1_5_R1: true
  11.       remap-obc-v1_4_R1: false
  12.       remap-obc-v1_4_6: false
  13.       remap-obc-pre: false
  14.       remap-nms-pre: 'false'
  15.       global-inheritance: true
  16.       plugin-inheritance: true
  17.       remap-reflect-field: true
复制代码
这些设定最好看wiki网站自己调整下。
供上网站：http://mcportcentral.co.za/wiki/ ... Compatibility_Guide
