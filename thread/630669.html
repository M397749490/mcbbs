三个方法；插件/GM权限组配置文件
插件的话，直接装http://www.mcbbs.net/thread-580585-1-1.html这个即可，不但能禁止某个世界被破坏，还能禁止放置！
GM权限组配置文件：
  1.   Builder:
  2.     default: true
  3.     permissions:
  4.     - -essentials.chat.color
  5.     - essentials.kits.Color
  6.     - essentials.kits.dipishouze
  7.     - essentials.kits.dipizhiling
  8.     - essentials.kits.jianghun
  9.     - essentials.kits.VIP
  10.     - essentials.kits.yt
  11.     - essentials.kits.zu
  12.     - serversigns.use.*
  13.     inheritance:
  14.     - default
  15.     - g:essentials_builder
  16.     - g:towny_builder
  17.     info:
  18.       build: true   ###这里修改成“false” 即可，注意，需要玩家默认组才行！不推荐此方法，建议用上面的插件！
  19.       prefix: '&a[居民]&2'
  20.       suffix: '&a[未常驻]'
