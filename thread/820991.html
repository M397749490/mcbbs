★Citizens Server Selector★
跨服公民

大家好..我又来搬运插件了



插件介绍
作者：andrei1058
必备前置：Citizens2
插件功能：
可以创建一个跨服/世界的公民，名字下方会显示单服/世界的在线人数


指令与权限
/css create  创建一个新的NPC
/css rename  修改现有NPC的名字
/css setDesc  添加或者更改计数栏全息显示
/css setskin  更改NPC的皮肤
/css setCounter  查看这个子服的玩家数量
/css setType 设置计数栏类型(服务器/世界)
/css setcmd 为目标设置指令
/css remove  删除NPC
/css join 翻译无能

本插件没有任何权限需要给玩家

配置文件

无
