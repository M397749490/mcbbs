作者: itsuhane    时间: 2011-8-19 16:12
如果你用的 MinecraftSP 在 .minecraft 目录里面有一个 MinecraftSP.jar 的文件的话，可以试试看自己建立一个 bat 文件（比如叫 MinecraftSP.bat）内容如下：
  1. @echo off
  2. SET BINDIR=%~dp0
  3. CD /D "%BINDIR%"
  4. java -Xmx1G -jar MinecraftSP.jar
复制代码
上面的那个 java 替换成你的机器里安装的 Java 运行时，比如如果你把 Java 安装在了 D:\Program Files\Java\jre6 的话，应该会有一个 D:\Program Files\Java\jre6\bin\java.exe 的，于是把那一行替换成（注意加引号）
  1. "D:\Program Files\Java\jre6\bin\java.exe" -Xmx1G -jar MinecraftSP.jar
复制代码
放在 .minecraft 目录下面，双击运行试试看，如果可以正常运行的话改用这个代替启动器就可以了

不过这个方法启动起来之后后面会有一个黑黑的命令行窗口，可以去掉不过这里就先不讲了，先看看能不能帮助 LZ 解决问题再说。
