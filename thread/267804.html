create @bypassPERM:权限节点 /带斜杠的命令这个自定义选项将为玩家临时添加权限节点以执行其后的相应命令，并在命令执行后移除该权限节点。
对你问题的实例方案∶
  首先禁用普通玩家的warp 这点你已经解决
  之后
  1. /sbinteract create @bypass_PERM:essentials.warp /warp XX
复制代码
来给予玩家临时权限，触发命令后自动移除权限，XX就是你的warp名

作者: mmmmmmmm丶浅瞳    时间: 2014-4-25 10:57
给玩家添加上
scriptblock.interact.use
scriptblock.walk.use
这两条权限

具体指令是下面两条
/mangaddp Default scriptblock.interact.use
/mangaddp Default scriptblock.walk.use

输入这两个指令后就 在输入/manload   然后就行了

求最佳。
