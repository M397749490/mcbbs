介绍 · Introduction
WorldEditGlobalizer 可用于Bungee/Bukkit服务器, 可以让你的服务器同步子服的worldedit的剪贴板.
如何使用
  • 当你输入 "//copy" 时,这个插件会上传worldedit的剪贴板到BungeeCord内并储存.
  • 当你输入 "/weg upload" 会上传你当前worldedit的剪贴板到BungeeCord内.
  • 输入 "/weg download" 这个插件会把BC内储存的schematic文件粘帖到你所在子服的worldedit的剪贴板.之后输入//paste即可粘帖建筑


安装
  • 点击下载插件
  • 把插件放到bc和所需子服的插件文件夹(Spigot服务器)
  • 重启你的 BungeeCord服务器及其所有子服

特点

  • 语言支持: 你可以修改message文件来改变信息
  • 高效: 这个插件应该不会卡服!
  • 大多数信息可以配置
  • 限制剪贴板大小: 你可以限制剪贴板大小(可配置)
  • 剪贴板会在服务器重启后保存或 Player-Relog
  • 这个插件也兼容 FastAsyncWorldEdit(1.13版本不兼容)
  • 加载/存储/删除/列出 所有的schematic文件: 完全支持WorldEdit的schematics文件!

配置
  1. # WorldEditGlobalizer 配置文件

  3. # 你可以在这里更改插件的语言.
  4. # 默认可用语言为 'en'(英语) 或 'de'(德语).
  5. # 中文由qsefthuopq翻译!
  6. # 插件默认配置文件为英语.
  7. language: cn

  9. # 你可以在这里更改更改上传粘贴板的最大字节.
  10. # 你可以使用如 '1024*1024*30' 的数学表达式.
  11. maxClipboardSize: 1024*1024*30

  13. # 是否在玩家退出服务器或服务器重启后保留玩家的粘贴板
  14. keepClipboard: true

  16. # 插件前缀
  17. prefix: '&3WEG &7&l>> &r'
复制代码


前置
一台BungeeCord服务器 至少一个spigot子服并且安装有worldedit

用法

  • 选区
  • //copy
  • /weg upload
  • 前往其他子服
  • /weg download
  • //paste



指令 & 权限
  • worldeditglobalizer.command.weg - /weg        使用/weg主指令
  • worldeditglobalizer.use.global.clipboard - 开启自动上传剪贴板
  • worldeditglobalizer.command.info - /weg info -获得剪贴板的信息
  • worldeditglobalizer.command.info.other - /weg info [player] 获得你给予玩家的剪贴板的信息
  • worldeditglobalizer.command.download - /weg download        下载剪贴板到你所在的服务器
  • worldeditglobalizer.command.upload - /weg upload 上传你的剪贴板到网上
  • worldeditglobalizer.command.reload - /weg reload 重载配置
  • worldeditglobalizer.command.stats - /weg stats 显示插件数据
  • worldeditglobalizer.command.schematic - /weg schematic 使用 "/weg schematic" 指令
  • worldeditglobalizer.command.schematic.save - /weg schematic save 保存你的剪贴板为schematic文件
  • worldeditglobalizer.command.schematic.load - /weg schematic load 加载一个schematic文件到你的剪贴板
  • worldeditglobalizer.command.schematic.delete - /weg schematic delete删除一个schematic文件
  • worldeditglobalizer.command.schematic.list - /weg schematic list 显示已保存的schematic文件
