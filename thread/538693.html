ItemTags 物品标签 v1.4

中文名字是随便起的，不过应该问题不大。本插件并不需要多少描述，其利用了1.8的特性，可以开启掉落物顶部名称显示，并非使用Hologram，对服务器没有任何影响。
本插件仅限1.8+的服务器才可使用

插件配置：
安装插件后，你的plugins文件夹会生成一个ItemTags文件夹，里面含有以下文件：
config.yml:
  1. global_pre: '所有物品的前缀，记住不要移除单引号'
  2. global_suf: '所有物品的后缀，记住不要移除单引号'
  3. # 物品名称格式，以下为&b颜色代码+前缀#pre#+名称#name#+后缀#suf
  4. item_name: '&b#pre##name##suf#'
  5. # 物品如果超过一个，则会以下列形式出现，其中#count#是数量
  6. item_name_stacked: '&b#pre##name##suf# *#count#'
  7. # 所有所有的物品，都显示标签
  8. display_all: true
  9. # 被铁砧改名的物品会显示标签
  10. display_withname: true
  11. # 有自定义描述的物品会显示标签
  12. display_withlore: true
  13. # 附魔过的物品会显示标签
  14. display_withenchant: true
  15. # 即使custom.txt物品有其他名字，也显示物品用铁砧改过的名字
  16. trust_item_name: true
复制代码
custom_name.txt: 此处可以改变默认物品名称，格式为"物品:名称"，不带双引号，如果改为了井号"#"则代表不显示。中文包见下载区。
  1. STONE:石头
  2. LOG:木头
