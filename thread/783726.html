SaneEconomy明智的经济系统

  • 选择原因（推荐阅读）
作者的话
I was looking for an economy plugin for a server I administrate, and I noticed something quite strange.
All of the plugins are years outdated, built against Bukkit API versions as old as Minecraft 1.2.4, and often have loads of bug reports, both in the comments on BukkitDev/SpigotMC, and on GitHub, all with no response from the developer!

I decided that it was time for a change. I wanted a working, updated economy plugin for Bukkit, built against the latest API. So I wrote one myself, and have committed to maintaining it as long as I'm able.

翻译
我在为管理服务器而找经济系统插件的时候，我注意到一些问题
目前全部大多数经济系统插件都过时了很久，他们使用的代码有点古老，比如用到了Minecraft 1.2.4的BukkitAPI，而且这些插件在 BukkitDev/SpigotMC 和 GitHub 上有大量Bug包裹，那些开发者都没回应！

于是我决定改变了，开发使用于Bukkit工作、更新的经济系统插件，本插件使用于新的BukkitAPI而开发，并且承诺一直维护更新它

  • 介绍
       SaneEconomy是1.8-1.12的轻量级经济插件，而且采用新BukkitAPI而开发，是安全的

  • 特点
       支持文本、数据库MySQL存储方式
       支持多服务器蹦极同步经济
       自定义货币名称和符号
       显示经济排行
       初始余额
       玩家交易

  • 命令权限


  • 检查玩家余额
       用法：
       /balance 或 /balance 玩家ID
       别名：
       /bal 或 /bal 玩家ID
       权限：
       - saneeconomy.balance   查看自己余额
       - saneeconomy.balance.other   查看另一个玩家余额
  • 支付钱给另一个玩家
       用法：
       /play 玩家ID 数量
       别名：
       /transfer
       权限：
       - saneeconomy.pay
  • 经济管理
       用法：
       /ecoadmin give 玩家ID 数量   新增玩家的钱
       /ecoadmin take 玩家ID 数量   扣除玩家的钱
       /ecoadmin set 玩家ID 数量   重新设置玩家的钱
       别名：
       /eco
       权限：
       saneeconomy.ecoadmin
  • 管理命令
       用法：
       /saneeconomy reload-database   重新加载经济数据库
       别名：
       /saneeco
       权限：
       saneeconomy.admin
  • 显示金钱排行
       用法：
       /balancetop
       别名：
       /baltop
       权限：
       saneeconomy.balancetop

常见问题
  • 为何jar这么大
       因为打包了HikariCP库而获得很好的MySQL连接池，并且还打包了HikariCP的依赖注SLF4J
  • 控制台中有关于SLF4J的警告
       这是安全的，可以忽略的，这是来自HikariCP的问题，暂时无法禁用
  • 为什么超过1000时，金钱被重置为0
       作者表示不知道，但有解决方案https://github.com/AppleDash/SaneEconomy/issues/34
       不过，这个只发生在西班牙地区
