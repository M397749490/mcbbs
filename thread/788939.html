return 之后不能再有东西了。 比如：

  1. public ItemStack getTabIconItem() {
  2.     return new ItemStack(EnergyItem.itemBestSword);
  3. }
复制代码

或者：

  1. public ItemStack getTabIconItem() {
  2.     if (blabla) {
  3.         return new ItemStack(EnergyItem.itemBestSword);
  4.     } else {
  5.         return new ItemStack(EnergyItem.itemBestSword);
  6.     }
  7. }
复制代码

但 return 代表方法执行的结束，下列代码自然是不可能的：

  1. public ItemStack getTabIconItem() {
  2.     return new ItemStack(EnergyItem.itemBestSword);
  3.     System.out.println("Heyo"); // Compliation Error
  4. }
