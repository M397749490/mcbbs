作者: 森林蝙蝠    时间: 2018-10-6 16:42
net.minecraft.world.gen.feature.WorldGenerator下的generate（）方法负责方块的生成。
你可以参考net.minecraft.world.gen.feature下的其他类来知道如何编写方块生成。

一个简单的例子：
  1. public class OreGen implements IWorldGenerator {

  3.     private final WorldGenerator glowstoneGenerator = new WorldGenMinable(Blocks.glowstone, 16); // 创建一个萤石生成器，其矿脉最大大小为16
  4.     private final WorldGenerator diamondBlockGenerator = new WorldGenMinable(Blocks.diamond_block, 4); // 创建一个钻石块生成器，其矿脉最大大小为4

  6.     @Override
  7.     public void generate(Random random, int chunkX, int chunkZ, World world, IChunkProvider chunkGenerator, IChunkProvider chunkProvider) {
  8.         int x = chunkX * 16, z = chunkZ * 16;

  10.         if(world.provider.dimensionId == 0) { // 判断是否是普通世界
  11.             // 萤石生成
  12.             for (int i = 0; i < 4; ++i) { // 每个区块内生成4次萤石
  13.                 int posX = x + random.nextInt(16); // 请勿修改，随机生成X坐标
  14.                 int posY = 32 + random.nextInt(16); // 在32~48格之间随机高度生成
  15.                 int posZ = z + random.nextInt(16); // 请勿修改，随机生成Z坐标
  16.                 glowstoneGenerator.generate(world, random, posX, posY, posZ); // 生成萤石
  17.             }

  19.             // 钻石块生成
  20.             for (int i = 0; i < 2; ++i) { // 每个区块内生成2次钻石块

  22.                 int posX = x + random.nextInt(16); // 请勿修改，随机生成X坐标
  23.                 int posY = 16 + random.nextInt(32); // 在16~48格之间随机高度生成
  24.                 int posZ = z + random.nextInt(16); // 请勿修改，随机生成Z坐标
  25.                 diamondBlockGenerator.generate(world, random, posX, posY, posZ); // 生成钻石块
  26.             }
  27.         }
  28.     }
  29. }

然后再FMLInitializationEvent注册这个生成器：
  1.    @EventHandler
  2.     public void init(FMLInitializationEvent event)
  3.     {
  4.         GameRegistry.registerWorldGenerator(new OreGen(), 0);
  5.     }
