介绍
一些BC常见问题：

  • 启动 BC 前必须转 UTF-8 编码，否则报错.

  • 未开启 force_default_server 功能 ，导致可以绕过登录服

  • BC 配置文件看不懂，胡乱配置.

  • 未开启 ip_forward 功能，导致可以绕过登录服

  • 不知道 BC 端能使用的指令.

  • 不会添加子服

  • 跨服均是 127.0.0.1 无法获取玩家真实 IP 地址


  • Start.bat 不会弄成自动重启，开开关关实在麻烦

  • 未删除 bungeecord.command.server 权限，导致可以绕过登录服

  • md_5 账号绕过登录服

  • 暂未发现更多问题，如有请通知我加上去

注意！标记为红色的是极其危险的问题！！！

问题根源&解决方法

  • BC 的配置文件不允许出现中文，否则会自动转换为 ANSI 编码 下次启动 BC 就会报错，因为 BC 只认 UTF-8 编码.

  • BungeeCord 会记录你上次下线的子服，然后重新上线直接到达该子服而不是登录服.

  • 本帖内有cnfig.yml的中文翻译版.

  • force_default_server 功能未打开，导致所有人进入服务器都是127.0.0.1 假如你的登录插件设置了保持会话（ip不变自动登录）那么就完全可以绕过密码.

  • 本帖内有 BC 端能使用的所有指令.

  • 添加子服方法在本帖内.

  • 想要让子服获取玩家真实IP地址，必须将 spigot 服务端中的 spigot.yml 里面的 bungeeCord 功能打开.

  • 本帖内有自动重启 Start.bat 下载即可.

  • /server 指令绕过登录服，将 BC 权限组内的 bungeecord.command.server 权限删除即可.

  • 原因是 BC 权限组内 md_5 账号，默认是 BC 的管理员，将 BC 管理员权限组的权限留空即可

Config.yml


  1. # 玩家权限组设置
  2. groups: null

  4. # ip 地址共享

  6. # 请在子服 spigot.yml 设置 【 bungee=true 】 ,才能与 BC 共享玩家 ip 地址
  7. ip_forward: true

  9. # 压缩等级
  10. network_compression_threshold: 128

  12. # 标识码
  13. stats: 96facdac-025e-4919-ac0d-f048d2492c2f

  15. # 权限配置
  16. permissions:

  18. # 玩家权限,已经删除  bungeecord.command.server 权限
  19.   default:
  20.   - bungeecord.command.list
  21.   
  22. # 管理员权限,留空了管理员了权限.
  23.   admin: []

  25. # 正版验证，建议打开.
  26. online_mode: false

  28. # 服务器列表
  29. servers:

  31. # 子服务器名称
  32.   lobby:

  34. # 子服务器公告
  35.     motd: '&1Just another BungeeCord - Forced Host'

  37. # 子服务器地址
  38.     address: localhost:25565

  40. # 受限，指除管理员其他玩家不能进入
  41.     restricted: false

  43. # 连接超时设置
  44. timeout: 60000
  45. listeners:

  47. # 端口设置
  48. - query_port: 25565

  50. # 公告
  51.   motd: '&1Another Bungee server'

  53. # 标签列表
  54.   tab_list: GLOBAL_PING

  56. # 是否启用代理
  57.   query_enabled: false

  59. # 是否启用代理协议
  60.   proxy_protocol: false

  62. # 作者的广告
  63.   forced_hosts:
  64.     pvp.md-5.net: pvp
  65.    
  66. # 如果变为 true。那么motd什么的就全部变为default服务器（lobby登录大厅）
  67.   ping_passthrough: false

  69. # 子服进入优先级
  70.   priorities:
  71.   - lobby

  73. # 绑定本地地址
  74.   bind_local_address: true

  76. # BungeeCord 开放的端口
  77.   host: 0.0.0.0:25565

  79. # 显示最大在线人数
  80.   max_players: 20

  82. # tab列表大小，每多20格增加一列
  83.   tab_size: 60

  85. # 这里是强制第进入为默认服务器
  86.   force_default_server: true

  88. # 防止代理连接
  89. prevent_proxy_connections: false

  91. # 最大在线人数
  92. player_limit: 20

  94. # 禁止使用的命令
  95. disabled_commands:
  96. - server

  98. # log 纪录使用的指令
  99. log_commands: false

  101. # 不知道什么功能，麻烦 dalao 告诉下
  102. connection_throttle: 4000

自动重启BAT


  1. @ ECHO OFF
  2. title [标题]
  3. :Start
  4. java -Xmx[最大内存]M -Xms[最小内存]M -jar BungeeCord.jar
  5. goto Start
