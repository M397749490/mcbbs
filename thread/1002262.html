  开始


     快速入门
  * 这是快速入门，快速掌握技巧
  


  1. 创建领土
    /lands create <王国名字>

  2. 设置模式
    /lands selection

  3. 领地范围的选择
    请使用空手左键右键来选择，不要使用工具!

  4. 创建区域
    /lands claim

  5. 打开王国菜单
    /lands menu

  6. 使用命令来编辑不同的土地，例如 /lands edit <土地名>
    即所有命令将用于您指定的土地



指定王国进行编辑


请使用 /lands edit <王国名> 来编辑


给予玩家权限


请使用 /lands trust <玩家ID> 来给予玩家权限
此举会打开一个GUI，让你移除玩家.


移除玩家权限


请使用 /lands untrust <玩家ID> 来取消玩家在领地内的权限
此举会打开一个GUI，让你移除玩家.


开启公共权限



  1. 打开你的王国菜单 /lands

  2. 点击 角色配置

  3. 打开设置菜单

  4. 开始配置吧!


升职/降职



  1. 打开王国菜单 /lands

  2. 点击 玩家 设置

  3. 左键升职 | 右键降职

领土区域


什么时候领土区域


诶，你领土就领土呗，还有个区域？
领土区域是领土内的子区域，这意味着，它们并不是一片完整的领土，而是领土内的领土，您可以赋予一个玩家领土，就像西欧庄园一样


创建一个区域



  1. 首先，您得有领土，然后输入 /lands menu ，在而后点击 区域 选项，每个服务器如果没配置过GUI，一般都是这样的
    " alt="Areas" />

  2. 现在来添加区域吧！
    " alt="CreateAreas" />

  3. 然后便会出现一个新的GUI，你可以在这里设置
    " alt="SetSize" />

  4. 设置好了之后，我们将会看到如图所示的样子，然后开始配置吧
    " alt="Test" />
