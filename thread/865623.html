比如输入一个指令可以获得当前插件文件夹的路径，然后往他的上一层目录新建一个文件夹或文件，应该用api哪个方法？
作者: gooding300    时间: 2019-5-15 12:38
getDataFolder()
作者: lgou2w    时间: 2019-5-15 13:00
  1. File.getParentFile(); // 获取当前文件目录的父目录
复制代码

假设你的插件名为 YourPlugin，那么插件获取到的 getDataFolder() 就是: 服务端目录/plugins/YourPlugin/
所以你想获取到插件目录的父目录就是：
  1. File pluginsDir = YourPlugin.getDataFolder().getParentFile(); // 服务端目录/plugins/
  2. File serverDir = pluginsDir.getParentFile(); // 服务端目录/
