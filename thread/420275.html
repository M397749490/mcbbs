Better Shops（简称bs）是一个有GUI界面的商店插件，玩家可以定制专属的商店。改变价格、出售购买等的操作都是非常简便的。废话不多说，开始介绍插件了。

特点：

  • 完全自动化的商店系统
  • GUI界面
  • 交易记录
  • 自定义
  • 游戏中配置插件
  • 支持附魔、头颅、自定义名称等
  • 无限商店
  • NPC商店，各种动物、怪物都可以
  • 没有指令
  • 多人共同管理商店
  • 全息商店

用法：
注意：此步骤仅适用于1.8及以上版本。1.8以下版本，创建商店要输入[shop]（第一行），同时命名商店会在聊天栏提示，在聊天栏输入即可。同时要注意的是，如果您的服务器上使用了lockette锁箱插件，会有冲突，导致不能创建商店。可以使用另一个锁箱插件http://dev.bukkit.org/bukkit-plugins/lwc/感谢@奶油酱 的反馈
1、放一个箱子，把牌子贴在箱子上（按住shift），第一行写上[商店]（要英文输入法的[]，不是【】），其他行不用写。


2、命名商店名字，不能为中文，仅可以数字与字母。   点右边的纸完成。   



3、设置购买或者销售状态



4、商店开关




指令与权限：

玩家权限

权限 描述 默认
bettershops.shop.create 允许创建商店
  default
bettershops.shop.buy 允许购买  default
bettershops.shop.sell
 允许出售  default

op权限
权限 描述 默认
bettershops.shop.* 全部权限 OP
bettershops.shop.limit 创建商店不限 OP
bettershops.shop.infinite 创建无限商店（库存） OP
bettershops.shop.owneruse 允许创建服务器类型商店 OP
bettershops.shop.NPC 允许创建NPC类型商店 OP
bettershops.shop.creationcost 允许创建商店不支付金钱 OP
bettershops.shop.config 允许用配置界面 OP

指令
指令 描述 权限
/bs 帮助信息 default
/bs open 商店名 打开指定商店 OP
/sremove 商店名 移除商店（破坏牌子或箱子也可以） default
/bs language 打开语言设置界面 op
/bs config 打开插件配置界面 op




界面介绍：
1、主界面



绿宝石那个是商店历史管理
2、config设置界面   命令：/bs config

3、语言设置界面  命令：/bs language
可以自定义插件的显示文字

4、设置NPC模式
右键点击主界面的末影箱，打开商店设置界面，就像这样

可以设置商店描述，商店类型（NPC或者箱子）
NPC设置可以使任何生物，这点就觉得比较吊了                                                                                                                                               
5、服务器商店模式
貌似可以批量管理的，就是把服务器商店模式打开（在上一个介绍倒数第二个箱子里）
然后主界面第一行就会多一个箱子，点开就可以管理了
