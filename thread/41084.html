BattleNight是怎样的插件？

BattleNight 一个可以进行玩家和玩家之间竞技的Bukkit插件，因为增加了类似RPG游戏的职业选择以及竞技场使得本插件超越了一般的PvP体验从而更令玩家享受。此插件是由一款极佳的叫做Fight的插件启发而制作的，但是此插件现已经停止开发。

此插件和别的类似插件都有什么区别？

我希望此插件易于使用, 易于设置并且在增加大量特性的时候保持没有Bug。我花费了很长时间来阅读你们的评论、意见和错误反馈来保证本插件适合大众并且在服务器上平稳的运行。

特性:
  • 易于设置
  • 建造你自己的竞技场！
  • 创建独特的职业！
  • 两支队伍（红队和蓝队）
  • 玩家只需要输入极少的命令
  • 支持权限插件 (SuperPerms) 或者只让OP使用
  • 几乎做好了反作弊功能
  • 如果双击了jar文件则会弹出小对话框提醒菜鸟服主这个其实是一个插件（译者注：真的是非常贴心的开发者啊）
  • 保存装备

权限：/bn help        User/Admin        显示帮助
/bn waypoints        Admin        显示设置和未设置的路点
/bn join        User        自动选择队伍并加入对应大厅
/bn watch        User        传送至观察区
/bn leave        User        离开比赛或观察区
/bn kick {Player}        Admin        踢出玩家
/bn kickall        Admin        踢出所有人，结束游戏
/bn endgame        Admin        同上
/bn redlounge        Admin        设置红队大厅
/bn redspawn        Admin        设置红队出生点
/bn bluelounge        Admin        设置蓝队大厅
/bn bluespawn        Admin        设置蓝队出生点
/bn spectator        Admin        设置观察者传送点
/bn exit        Admin        设置离开时的传送点
/bn version        User        显示目前插件版本号
/bn relaod        Admin        重新载入配置

权限：
此插件深得简易之要领，权限只有如下三种：
battlenight.user 玩家权限
battlenight.admin 管理员权限
battlenight.* 所有权限
