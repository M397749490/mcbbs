设置生成点
/mm s create 刷怪点名字 怪物
设置怪物复活时间  单位秒
/mm s set 刷怪点名 cooldown 300
例如你的就是
/mm s create 僵尸1 僵尸
/mm s set 僵尸1 cooldown 300
任何设置多个可以直接复制
/mm s copy 僵尸1 僵尸2
/mm s copy 僵尸1 僵尸3  
以此类推
