◆介绍◆
This plugin allows you to enable your players to open a trash can enable them to throw objects they do not want in their inventory.
这个插件可以让你的玩家打开垃圾桶，把不想要的东西扔进去。


Features:
Allow you to open an empty inventory when player can drop their item!
Fully customizable!
Sign trash
特点：
允许当你打开空的背包时，玩家可以扔掉物品。
完全可以自定义。
标记垃圾桶。
命令/权限
命令:
/bin - 打开垃圾桶
/bin reload - 重新加载配置

权限:
superbin.sign - 允许创建一个垃圾桶
superbin.drop - 允许你扔垃圾在noDrop开启时
superbin.admin - 允许你使用/bin reload
配置文件
  1. itemName: Default
  2. itemLore:
  3.   - I'm the default lore
  4.   - You can add many line if
  5.   - you want!!
  6. menuName: Default bin name
  7. canDrop: true
  8. noDropMessage: You can't drop here
  9. signName: SuperBin
  10. signText: Open
  11. worldDisable:
  12.   - ExempleWorld1
  13.   - ExempleWorld2
  14. soundsAllow: true
