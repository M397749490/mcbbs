Mcmeta文件在blocks文件夹下是运行动态材质的基础，可用记事本打开

随便找到一个Mcmeta文件，用记事本打开
water_flow.png.[流动的水]
  1. {
  2.   "animation": {}
  3. }
复制代码

这是最基本的mcmeta文件内部，没有任何的标签，即所有属性读取默认值。animation表示动画

water_still.png.mcmeta[静止的水]
  1. {
  2.   "animation": {
  3.     "frametime": 2
  4.   }
  5. }
复制代码

可以看到，在animation这个基础对象内多了一frametime属性

这个属性规定了“帧数”，也就是每秒读取图片的个数，如果没有这个标签，默认帧数为1

复制代码
animation内多了一个frames数组
作用为，按照一定的顺序读取图片
在这里，顺序就是：1,2,3,4,5···18,19,18,17···2,1
简单来说，就是以每秒读取2张的速度，从上走到下，再从下走到上
repeating_command_block_back.png.mcmeta
  1. {
  2.   "animation": {
  3.     "interpolate": true,
  4.     "frametime": 10
  5.   }
  6. }
复制代码
可以看到多了一个interpolate属性
如果这个属性的值为true，那么在每两张图片之间插入一帧的延迟
默认为false


Blocks文件夹下的Mcmeta文件就这三大类，下面说下基本格式
红色必须有，蓝色可有可无
{"animation": {"frametime":数值,"frames":[顺序]}}

1.frametime标签的数值必须为整数
2.frames标签的顺序之间用英文逗号[,]隔开，最大数值必须等于图片数值
3.在不定义frames标签标签的情况下，默认是从上往下，再从第一个从上往下读取
