        Unique Prefix
                   GUI称号系统 II



                  前言 简介
            UniquePrefix II是以前版本的重置版,食用方法比以前优雅许多,也优化了很多算法.
                    （特别感谢梨子大大给出了一个非常优雅的算法）
                     新的版本加入了：
                         ·  支持不同的称号组,并可以选择是否需要权限才能购买组内称号.
                         ·  支持指令 生成/修改 贩卖称号.
                         ·  超高度自定义称号位置.
                         ·  可自定义语音文本,提示信息随意修改并支持变量.
                         ·  不需要GroupManager前置插件(第二页旧版依然需要
                  食用 方法
            指令篇：
                    
      
指令
介绍
权限
/uprefix group [称号组名称]
打开指定称号组的GUI界面
(管理员可以设置打开权限)
UniquePrefix.use
/uprefix custom [称号]
为自己量身定做称号
(普通玩家有敏感词过滤)
UniquePrefix.vip
/uprefix admin addgroup [称号组名称] [界面大小]
创建一个称号组
(界面大小范围: 9~54且为9的倍数)
UniquePrefix.admin
/uprefix admin addprefix [称号组名称] [称号] [价格]
为指定称号组
添加一个称号并设置价格
(称号支持&颜色字符)
UniquePrefix.admin
/uprefix admin addlore [分类] [称号] [lore]
为指定称号组的某个称号
添加一个Lore
(Lore支持&颜色字符)
UniquePrefix.admin
/uprefix admin dellore [分类] [称号]
为指定称号组的某个称号
删除某个Lore
UniquePrefix.admin
/uprefix admin openper [称号组名称]
为指定指定称号组开启需要权限
开启后玩家打开该称号组需要
(UniquePrefix.称号组名称的权限)
UniquePrefix.admin
/uprefix admin closeper [称号组名称]
为指定指定称号组关闭需要权限
UniquePrefix.admin
                  

                    Config.yml篇：
                  

  1. display: '%prefix%<%name%> %message%' #玩家说话后调整/添加称号的地方
  2. 变量说明: %prefix% 称号 ; %name% 玩家名 ; %message% 玩家说的话
  3. language: 'CN' #使用的语言文件
  4. auto-save: true #是否开启自动保存
  5. 注意: 开启自动保存后在开服状态下请勿修改Player.yml Prefix.yml 否则重启或关服将会被还原
  6. save-time: 5 #自动保存的间隔,单位: 分钟
复制代码
                  

                    Player.yml篇：
                  

                   请使用Notepad++编辑!
                   Player.yml是记录所有玩家称号的地方请慎重修改!
  1. '123': #玩家名
  2.     prefix: '[唔]' #玩家当前的称号
  3.     has: #玩家购买过的称号
  4.         - 'test.yo' #格式: '称号组.称号'
复制代码
                  

                    Prefix.yml篇：
                  

                   请使用Notepad++编辑!
                   Prefix.yml是记录所有出售称号的地方请慎重修改!
                   如果您在设置称号的lore时,想要修改或加入非最后一行的lore时可以打开Prefix.yml
                   来修改,其他情况不建议您修改Prefix.yml
  1. test: #称号组名称  parameter:
  2.     box-size: 9 #该称号组显示界面
  3.     permission: true #是否开启需要权限
  4.     权限格式: UniquePrefix.称号组名称 比如这个称号组的权限就是UniquePrefix.test
  5.   "&c啧啧啧": #称号
  6.     price: 222 #称号价格
  7.     ID: #称号在GUI中的展示材质
  8.       ==: org.bukkit.inventory.ItemStack
  9.       type: BOW
  10.     IDdata: 3 #展示材质副ID或耗损值
复制代码
                  

                    Prefix.yml篇：
                  

  1. shield: #自定义称号中的屏蔽词(拥有UniquePrefix.admin权限可以无视)
  2.     - '服主'
  3.     - '管理员'
复制代码
                  

                    文图使用教程篇： (未写完,正在努力补全)
                  

                   创建称号组篇:
                       首先确定好称号组名称和界面大小
                       输入: /uprefix admin addgroup [称号组名称] [界面大小]
                       例如: /uprefix admin addgroup test 54
                       提示添加成功即可
                       如果想查看称号组输入/uprefix group [称号组名称]即可
                       例如: /uprefix admin group test
                       创建称号组篇(完)

                    添加称号篇:
                       注意! 需先创建称号组
                       首先拿着准备好的任意物品当做次称号在GUI界面里的显示材质
                       输入: /uprefix admin addprefix [称号组名称] [称号] [价格]
                       提示添加成功即可
                       例如: /uprefix admin addprefix test &c啧啧啧 167
                       如果想查看称号输入/uprefix group [称号组名称]即可
                       例如: /uprefix admin group test
                       添加称号篇(完)
