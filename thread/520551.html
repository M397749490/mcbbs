作者: yixiazi    时间: 2015-11-8 16:24
第一：weather:
      storm: true                          # 禁用雨天,寒冷生态环境为雪天
      thunder: false                       # 禁用雷电
      lightning: false                     # 禁用闪电
在ESS插件文件夹里面修改config 可以解决你的问题
第2：/mv modify set difficulty 0 世界名设置一个世界没有怪物
要是你的多世界插件不是
MV的话可以用下面这个禁止怪物生成
/mw setflag <世界名> SpawnMonster false

禁止动物生成
/mw setflag <世界名> SpawnAnimal false
你可以试试看
