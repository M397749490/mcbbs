问下 趣味道具 使用变身会崩客户端
这个怎么解决
或者怎么用权限 禁止玩家使用变身

作者: Dawn_NULL    时间: 2019-8-1 12:20
本帖最后由 825894968 于 2019-8-1 15:26 编辑

Disabled-Cosmetics:
  Hats: false
  Animated Hats: false
  Particles: false
  Suits: false
  Gadgets: false
  Pets: false
  Miniatures: false
  Morphs: true #禁用变身
  Banners: false
  Emotes: false
  Cloaks: false
在plugins\GadgetsMenu下的config.yml找到如上所示并进行修改即可

下面这个是是否允许玩家购买/解锁指定道具 true是允许
  # 是否允许玩家购买/解锁指定道具
  Enabled-Cosmetics:
    Hats: true
    Animated Hats: true
    Particles: true
    Suits: true
    Gadgets: true
    Pets: true
    Miniatures: true
    Morphs: true
    Banners: true
    Emotes: true
    Cloaks: true
