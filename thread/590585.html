权限组：
  • ZombieLogin.Administrator(默认OP拥有,掌控插件生杀大权)


指令【省略斜杠】：
  • zblog stop             ;停止正在运行的尸潮进程
  • zblog run                 ;开启一段尸潮  
  • zblog debug             ;读取到的语言配置文件
  • zblog debug [true/false]   ;是否启动debug模式(如果为true 则启用尸潮不延迟 但是会有提示【debug mode启用】)
  • zblog debug show     ;显示在启动DEBUG后各个变量具体值[1.0.6.5版本有效]
  • zblog level               ;显示当前的难度
  • zblog reload             ;重载配置


已知BUG：
  • 当指令刷出尸潮的时候可能插件会抽，您可以先用指令关闭尸潮暂时设置为白天 30s后再启动尸潮
  • 如果您的服务端对于命令要求异步（如paper服务端），或者尸潮出现多个进程，请使用修复版（感谢 @幻想のLU <-这是他Q名 提供的建议）
  • 如果您的服务器中不存在world世界，请暂时不要用所有版本（包括原插件），下一版本修复
  • 如果遇到没有提及的BUG Please mailto:zdl0804@qq.com
