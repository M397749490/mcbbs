安装方法
在开始安装过程中, 你需要完全访问MySQL数据库的权限.可以是一个现有的数据库, 也可以创建一个新的.
你还必须有一个Web服务器来托管网站.
插件安装:
  • 打开下载下来的压缩包,您应该能看到一个Statistic.jar和一个Statistic.zip.
  • 将Statistics.jar复制到服务端根目录的plugins文件夹内. 然后reload或者重启服务器. 插件会因为连接不到数据库而报错 - 这是正常的.
  • 打开/plugins/Statistics/config.yml 然后填写数据库信息. 接着重启或者reload服务器.
  • 插件会完成数据表的初始设置. 您将看到通知 - 请耐心等待, 直到插件说数据库更新完毕.
  • 插件安装完成.
网页安装:
  • 将Statistics.zip解压到Web服务器上所需的目录,例如/home/public_html/stats
  • 确保cache和include/config目录可写(chmod 777)
  • 如果你需要汉化文件或者皮肤之类的魔改,请把相应文件夹内的文件覆盖进网站目录
  • 进入相对目录,例如http://127.0.0.1/stats/然后按照屏幕上的提示操作
  • 网站安装完毕

获取服务器统计数据
Statistics有各种不同的服务器相关变量, 这些都是通过com.wolvencraft.yasp.StatisticsAPI访问的. 下面是一些例子:
  1. //获得服务器启动时间
  2. long lastStartup = (Long) StatisticsAPI.getValue(ServerVariable.LAST_STARTUP);

  4. //获取服务器总死亡数
  5. int deaths = (Integer) StatisticsAPI.getValue(ServerVariable.DEATHS);

  7. //获取当前TPS
  8. int ticksPerSecond = (Integer) StatisticsAPI.getValue(ServerVariable.TICKS_PER_SECOND);

获取玩家数据
获取一个玩家的会话
Statistics提供两种取得玩家会话的方式,分别是com.wolvencraft.yasp.session.OnlineSession和com.wolvencraft.yasp.session.OfflineSession. 区别很明显: OnlineSession用于在线玩家, 而OfflineSession则是从数据库中提取数据, 主要用于离线玩家.

得到一个玩家的会话是很容易的(我怎么不觉得). 这是个例子:
  1. //获得一个在线玩家会话(其中player代表玩家名字)
  2. OnlineSession onlineSession = StatisticsAPI.getSession(player);

  4. //获取一个离线玩家会话 (其中username是玩家名字的字符串)
  5. OfflineSession offlineSession = StatisticsAPI.getSession(username);
复制代码

所有会话都会缓存. 这代表如果你使用getSession()来获得玩家会话, 其数据会自动和数据同步. 如果你想要一个不缓存的会话, 你可以使用下面的方法:
  1. //获取一个离线的玩家会话 (其中username是玩家名字的字符串)
  2. OfflineSession offlineSession = StatisticsAPI.getSession(username, false);
复制代码

需要注意的是, 从数据库中获取会话是有些卡服的, 如果你在服务器主线程中运行的话, 可能会卡一下. 玩家会话是安全的, 可以在异步任务随意使用.

有些服务器可能会禁止一些玩家会话记录. 如果玩家没有会话记录, 试图得到他的OnlineSession会返回一个null.
获取玩家数据
从一个会话获取玩家统计数据很像获取服务器统计数据. 下面是一些例子:
  1. //获取方块总破坏
  2. int blocksBroken = (Integer) session.getPlayerTotals().getValue(PlayerVariable.BLOCKS_BROKEN);

  4. //获取玩家在线时间总计
  5. long playtime = (Long) session.getPlayerTotals().getValue(PlayerVariable.TOTAL_PLAYTIME_RAW);

  7. //获取K/D比
  8. double kdr = (Double) session.getPlayerTotals().getValue(PlayerVariable.KILL_DEATH_RATIO);
复制代码

至于变量类型, 这是常识. 方块数是整数, 移动距离是双精度浮点型, 时间就是时间戳, 等等.

链接到Statistics的配置
有时候, 你可能会想获取主插件的配置值. 例如, 你可能要检查插件是不是在调试模式下运行, Statistics是不是钩子到了某些别的插件, 查找数据库的时间表, 等等.

是的, 你可以使用该方法获取包括服务器所有者的信息, 包括但不限于数据库主机名和端口, 数据库用户名和密码, 数据库的表和前缀. 不过, 你并不需要这些信息, 此外, 试图查看一个保密的数据可以被BukkitDev认为是恶意代码.

有些迹象表明你可以访问, 即com.wolvencraft.yasp.settings.LocalConfiguration, com.wolvencraft.yasp.settings.RemoteConfiguration,和com.wolvencraft.yasp.settings.Modules. 所有数据都缓存一确保不会卡服, 你不必担心这个.
LocalConfiguration
LocalConfiguration包含Statistics的config.yml. 例如:
  1. //检查插件是不是在调试模式
  2. boolean debug = LocalConfiguration.Debug.asBoolean();
复制代码

RemoteConfiguration
RemoteConfiguration包含数据库中的设置表. 不是所有设置表的数据都储存于RemoteConfiguration, 模块项目位于模块枚举, 而一些网站的特定值 (如管理员的电子邮件) 是没有的. 下面是一些例子:
  1. //获取同步周期
  2. long ping = RemoteConfiguration.Ping.asLong();

  4. //获取数据库版本
  5. int version = RemoteConfiguration.DatabaseVersion.asInteger();
复制代码

Module
模块枚举表示Statistics插件对不同的插件的钩子和模块. 这部分并不是很重要, 除非你准备用Statistics钩到另一个插件 (请不要这样做, 这是很可笑的). 下面是一些例子:
  1. //检查插件搜集的玩家背包数据
  2. boolean active = Module.Inventory.isActive();

  4. //检查Statistics是不是勾到了WorldGuard插件
  5. boolean worldGuard = Module.WorldGuard.isActive();
复制代码

你可能注意到了, 有两个类似的方法在Module - isEnabled()和isActive(). 短的: 始终使用isActive(). 长的: isEnabled() 代表这个模块已经在管理面板打开了, 而isActive()代表Statistics可以启用这个模块.

如何打开GD2库
打开php的配置文件php.ini, 搜索extension=php_gd2.dll, 去掉前面的分号, 保存后重启apache/IIS

如何打开cURL库
找到php.ini里面的extension=php_curl.dll, 删掉前面的分号, 保存后重启apache/IIS

如何打开fsockopen

打开php.ini文件, 查找allow_url_fopen = 看看后面是 off  还是on, 如果是on, 直接看下一步, 如果是off 那就修改成on, 需要注意完整的是allow_url_fopen = on等号的左右有空格.
第二步
继续在php.ini文件中,查找extension=php_openssl.dll,删掉这段代码前面的 ; 号, 然后保存.
第三步
重启apache/IIS

如何打开MySQL的InnoDB引擎支持
关闭MySQL服务
打开my.ini
将default-storage-engine=INNODB前的注释(#)去掉
将skip-innodb这行注释(加上#)
保存后重启mysql服务
