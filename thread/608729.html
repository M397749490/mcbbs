上次已经教完大家如何启动BungeeCord了，这次教大家配置Config

我们能看见，上次启动完的BungeeCord.jar生成了一个config.yml，我们用notepad++将其打开

ip_forward: true

#这里和spigot.yml中的bungee=true一起打开就能做到入子服玩家的ip与b进入bc的ip相同，不打开就会变为127.0.0.1

network_compression_threshold: 256

#这里是压缩，建议改为128

stats: 689d078a-8c67-4b65-bcb9-b6ef225bf1ce

#这里没必要改

permissions:

  default:

  - bungeecord.command.server

  - bungeecord.command.list

#这里是普通玩家权限，。建议删除- bungeecord.command.server，不然可以绕过登录服下一章详细讲

  admin:

  - bungeecord.command.alert

  - bungeecord.command.end

  - bungeecord.command.ip

  - bungeecord.command.reload

#这里是管理员权限。建议删除

groups:

  md_5:

  - admin

#这里建议设置为null，不然md_5账号可以绕过登录服

servers:

  lobby:

#服务器名称

    motd: '&1Just another BungeeCord - Forced Host'

#服务器motd，没啥用   

address: 192.168.1.6:10001

#子服务器地址

    restricted: false

#受限，默认false，改true无法进入

timeout: 30000

#连接超时

listeners:

- query_port: 25577

#query端口

  motd: '&1Another Bungee server'

#这个motd真的特别丑，建议使用colormotd

  priorities:

#这里是优先级，第一个进不去就自动转入第二个

  - lobby

  - lobby

  - lobby

  bind_local_address: true

#这个没必要改

  tab_list: GLOBAL_PING

  query_enabled: false

#不会用query就直接false

  host: 0.0.0.0:25577

#这里是进入bungeecord调度/代理的端口

  forced_hosts:

    pvp.md-5.net: pvp

#这个是作者的广告

  max_players: 1

#显示的最大在线人数

  tab_size: 60

#tab列表大小，每多20格增加一列，建议另装BungeeTabListPlus（bbs有，发帖人把bungee拼成了Bungge）

  ping_passthrough: false

#如果变为true。那么motd什么的就全部变为default服务器（lobby登录大厅）

  force_default_server: false

#这里是强制第进入为默认服务器，建议开true，不然玩家可以直接用他人账号不进入登录服就进入其他子服

player_limit: -1

#玩家数量限制

online_mode: false

#正版验证

log_commands: false

disabled_commands:

- disabledcommandhere


connection_throttle: 4000

#其他就没必要改了
然后是指令：

/alert <信息>

权限：bungeecord.command.alert

全服信息

/alertraw <json格式的信息>

权限：bungeecord.command.alert

使用json的全服信息

/bungee

显示BungeeCord的版本信息，就像普通服务端的/version

/end

权限：bungeecord.command.end

关闭BungeeCord服务端，就像普通服务端的stop

/find <玩家名>

权限：bungeecord.command.find

查询某玩家所在的位置

/glist

权限：bungeecord.command.list

显示各子服在线人数

/greload

权限：bungeecord.command.reload

重载BungeeCord服务端的配置文件，不重载插件

/ip <玩家名>

权限：bungeecord.command.ip

查找玩家真实ip

/perms

显示你所在的权限组及拥有的权限

/send <玩家名/current/all> <目标子服务器名>

权限节点：bungeecord.command.send

把xxx强制传送到xxx服务器


默认使用者：群组管理员

/server [子服务器名]

节点：bungeecord.command.server

按理说这个权限不应该给玩家，之前已经说过能绕密码
