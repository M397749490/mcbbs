等级血量

[支持1.7.2-1.11.2]

插件介绍：

<内容已修改>

这个插件让玩家有能力通过获得升级来增加他们的最大生命值。每升几级玩家都会获得增加血量的效果，他最大生命值也会增加。levelhearts非常高端的配置，还可以使用命令可改变生命和任何玩家最大的生命！无需客户端mod！

指令：


/maxhealth [player]
显示一个玩家目前最大的生命值，和升级血量需要的经验
/maxhealth help
查看最大生命值帮助
/maxhealth get [player]
给你/一个玩家最大血量和最大等级并显示在什么情况下会增加最大血量(我也不懂，测试了效果跟第一个指令一样)
/maxhealth set [player] <amount>
设置一个玩家的最大生命值/  <amount>=数值，比如5点血，就写5。效果:比如他本来是3的，你设置了5就变5了
/maxhealth give [player] <amount>
增加一个玩家的最大生命值/ 。效果:比如他本来是3的，你<amount>填了5就变8了
/maxhealth take [player] <amount>
减少一个玩家的最大生命值/ 。效果:比如他本来是8的，你<amount>填了5就变3了
/maxhealth reset [player]
初始化。效果:如果你之前设置或者增加减少了他的血量，这个是让他返回插件本身效果。

生命值命令

/health [player]
显示一个玩家目前最大的生命值，和升级血量需要的经验
/health help
查看生命值帮助
/health get [player]
给你/一个玩家血量和等级并显示在什么情况下会增加最大血量(我也不懂，测试了效果跟第一个指令一样)
/health set [player] <amount>
设置一个玩家的生命值/  <amount>=数值，比如5点血，就写5。效果:比如他本来是3的，你设置了5就变5了
/health give [player] <amount>
增加一个玩家的生命值/ 。效果:比如他本来是3的，你<amount>填了5就变8了
/health take [player] <amount>
减少一个玩家的生命值/ 。效果:比如他本来是8的，你<amount>填了5就变3了
/health restore [player]
初始化。效果:如果你之前设置或者增加减少了他的血量，这个是让他返回插件本身效果。
另一个指令: /hearts

管理员命令

/lvlhearts
显示插件信息
/lvlhearts help
查看插件帮助
/lvlhearts reload
重启插件
