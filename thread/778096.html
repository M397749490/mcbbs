标题: [管理]Custom Whitelist——自定义缺少白名单提示[API7][1.12]
Custom Whitelist
Sponge服务器可以使用的自定义白名单插件.
自定义消息
这个插件可以让你在配置文件中修改默认的缺少白名单的提示。
自动生成
关于如何配置，请参考"配置文件"部分
这个插件同时可以根据一个SQL数据库自动生成whitelist.json文件。这个功能会在某些情况下十分有用，例如：你有一个Minecraft服务器，同时还有一个网站管理注册和白名单。
可以使用指令"/cwl whitelist"，自动生成。插件同时支持在后台根据特定的时间间隔自动同步。
重载插件
你可以使用指令"/cwl reload"来重载配置，并且重新开始自动同步。
配置文件
  1. main {
  2.   whitelist="Send a whitelist request firstly!"
  3.   db_connection="jdbc:mysql://localhost/lc?user=YOUR_USERNAME&password=YOUR_PASSWORD"
  4.   db_query="SELECT `username`, `uuid` from `players` WHERE `access` = 2;"
  5.   sync_delay=600
  6. }
复制代码
  • whitelist 部分设置没有白名单的玩家进入服务器时的提示。
  • db_connection 部分设置JDBC URL。你也可以使用在Sponge配置中设置好的JDBC URL的别名。
  • db_query 部分设置SQL查询语句，要求返回两列:username 和 uuid。
  • sync_delay 部分设置自动同步白名单的时间间隔，设置为0则关闭自动同步。
