  不想让玩家通过/help看到服务器都装了什么插件？想随心所欲改写/help里的内容？想通过/help更直观的让新人了解本服务器？
  这款轻量插件可以做到以上的功能。对于/help里的内容进行屏蔽甚至改写。
  版本：1.7.10、1.8、1.8.8、1.9.4、1.10.2、1.11.2。
  权限：无
  指令：无
通过后台插件config里修改help消息。
配置：
  1. <font size="4">config:
  2.   activated: true
  3.   prefix: '&cCustomHelp by funky33'
  4.   line1: '&4Use ColorCodes'
  5.   line2: '&8Edit this in Config.yml'
  6.   line3: '&aYou can go up to 10 Lines.'
  7.   line4: '&5So use them'
  8.   line5: '&2Every Message needs to be in Strings'
  9.   line6: '&0But only if you use ColorCodes.'
  10.   line7: Otherwise it will look like this
  11.   line8: '&6So have fun whith the Plugin'
  12.   line9: '&6If there are any Problems contact me'
  13.   line10: '&6on dev.bukkit.org/members/funky33 und my Plugin or private'</font>
复制代码

汉化以及使用：后台config里直接把line 行数:'xxxxxxxx'里面这段xxx改成你想要让玩家看到的文字就ok。如果只想让玩家看到两三行直接把lin4以及后面的删掉就行。同理如果需要更多的行数可以在line 10的下一行写上line 11:'xxxxx'以此推列。
