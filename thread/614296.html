更多的合成 Crafting++ v1.6.1
Minecraft 原版模组


主要内容与使用方法
本模组(官方网站)支持的 Minecraft 版本为1.12 pre2，作者 ruhuasiyu@mcbbs。

内容包括
(1) 背包合成：将材料放入背包右上角对应的3×3的格子里，即可自动得到产物。不参与合成的格子内物品不受影响，有的合成表有包含关系，注意放置的次序以免合成了不需要的物品。包括
(1-1) 回收剑镐斧锹锄、盔甲、马铠、鞍、矿车、花岗岩、闪长岩、安山岩、石英块、木炭。


(1-2) 压制钻石、鞍、蜘蛛网、马铠、粘土、浮冰。


(1-3) 38种刷怪蛋的合成(幻术师暂不可用)。



(1-4) 精制矿物，包括精制煤炭、精制铁锭、精制金锭、精制钻石、精制下界之星，用于制作剑镐斧锹、盔甲、强力时钟，以及
  • 传送球：手持传送球右击地面会将玩家传送相应方向200米。
  • 矿物探测器：手持矿物探测器右击地面会将附近10米内的矿物高亮显示5秒。
  • 强力磁铁：手持强力磁铁可将掉落物全部吸引过来。
  • 渔网：将渔网扔入水中，每隔20秒可以获得一件物品。



(1-5)  附魔金苹果和13种高级药水的合成。


(1-6) 6种树种的合成，树种用于植树：沿竖直方向依次放置主色方块、副色方块、树种即可自动种下。主副色方块需为羊毛或树叶。



(1-7) 16种高级画的合成。


(2) 修改了部分生物的掉落物、钓鱼的物品、少量文字内容、以及高压爬行者的生成。


(3) 新增24种模组专有进度，完成进度会给予经验、物品、状态效果奖励。

背包合成
由于前述方法不能合成带nbt的物品，所以有大量物品是由这种方式合成的。
首先_init已记录所需要的计分板清单。
在存档文件夹的data新建functions/cpp/_main.txt用于主循环，其中根据配方的不同给予计分板的不同分数和合成的物品，例如
  1. scoreboard players set @a craft 1 {Inventory:[{Slot:15b,id:"minecraft:wool",Count:1b},{Slot:16b,id:"minecraft:wool",Count:1b},{Slot:17b,id:"minecraft:wool",Count:1b},{Slot:24b,id:"minecraft:wool",Count:1b},{Slot:25b,id:"minecraft:egg",Count:1b},{Slot:26b,id:"minecraft:wool",Count:1b},{Slot:33b,id:"minecraft:wool",Count:1b},{Slot:34b,id:"minecraft:wool",Count:1b},{Slot:35b,id:"minecraft:wool",Count:1b}]}
  2. replaceitem entity @a[score_craft_min=1,score_craft=1] slot.inventory.16 minecraft:spawn_egg 1 0 {EntityTag:{id:"minecraft:sheep"}}
复制代码

然后根据合成的形状给予不同的clearslot分数，例如
  1. scoreboard players set @a[score_craft_min=1,score_craft=999] clearslot 111101111

传送
给予玩家一个带标签的刷怪蛋，在上述循环中检测是否存在该生物，然后执行functions/cpp:tpall，清除并执行相应命令即可。

捕鱼
钓鱼时，利用计分板每隔一段时间，在相应的蜘蛛网处召唤DeathLootTable为fishing的蠹虫并杀死之。

强力磁铁
为手中有指定物品的玩家计时，然后传送物品到最近的计时完成的玩家手中。

矿物探测
先将附近物品传送至高处，随后将附近的矿物替换成对应的半个木门。clone move 附近的方块使其更新，木门掉落。将在木门处生成指定分组潜影贝，给予指定分组的发光效果。清除附近的木门，并将高处物品传送回来。等待一段时间后，杀死潜影贝即可。

植树
给予玩家一个带标签的刷怪蛋，循环探测之。然后利用detect在对应位置放置相应的羊毛/树叶结构方块，并对次要的设置完整性为0.4f，最后fill树干。

高压苦力怕
每个循环中依次对4个苦力怕标记，并将最后一个改为高压苦力怕。

画
利用地图保存相应画的信息，最后给予玩家对应的地图即可。

合成（清除部分）
添加计分板
  1. scoreboard objectives add clearSlot dummy
复制代码


玩家背包右上角3×3格子内分别对应数值1,2,4,8,16,32,64,128,256。例如玩家clearSlot分数为259时，就会清除1,2,256对应的格子。
  1. replaceitem entity @a[score_clearSlot_min=256] slot.inventory.26 minecraft:air
  2. scoreboard players remove @a[score_clearSlot_min=256] clearSlot 256
  3. replaceitem entity @a[score_clearSlot_min=128] slot.inventory.25 minecraft:air
  4. scoreboard players remove @a[score_clearSlot_min=128] clearSlot 128
  5. ……
  6. replaceitem entity @a[score_clearSlot_min=2] slot.inventory.7 minecraft:air
  7. scoreboard players remove @a[score_clearSlot_min=2] clearSlot 2
  8. replaceitem entity @a[score_clearSlot_min=1] slot.inventory.6 minecraft:air
  9. scoreboard players remove @a[score_clearSlot_min=1] clearSlot 1
复制代码


合成


rcb 给予背包指定位置有指定内容（例如8个羊毛1个鸡蛋）的玩家标签sheep
  1. scoreboard players tag @a add sheep {Inventory:[{Slot:15b,id:minecraft:wool,Count:1b},{Slot:16b,id:minecraft:wool,Count:1b},{Slot:17b,id:minecraft:wool,Count:1b},{Slot:24b,id:minecraft:wool,Count:1b},{Slot:25b,id:minecraft:egg,Count:1b},{Slot:26b,id:minecraft:wool,Count:1b},{Slot:33b,id:minecraft:wool,Count:1b},{Slot:34b,id:minecraft:wool,Count:1b},{Slot:35b,id:minecraft:wool,Count:1b}]}
复制代码
ccb 给予有标签sheep的玩家计分板clearSlot数值495，用于清除指定位置的物品。

  1. scoreboard players set @a[tag=sheep] clearSlot 495
复制代码
ccb 替换指定位置

  1. replaceitem entity @a[tag=sheep] slot.inventory.16 minecraft:spawn_egg 1 0 {EntityTag:{id:minecraft:sheep}}
  2. scoreboard players tag @a remove sheep
复制代码



特殊物品
特殊的物品如精制矿物为添加有空的附魔的物品

盔甲的合成
由于盔甲的合成表有包含关系，因此其对应的cb链需要按裤子、胸甲、头盔、靴子的顺序来连成长cb链。


传送、磁力、钓鱼、矿物探测等功能
给予玩家一个带标签的刷怪蛋，用rcb检测是否存在该生物，然后清除并执行相应制定即可。

钓鱼时，利用计分板每隔一段时间，在相应的蜘蛛网处召唤DeathLootTable为fishing的蠹虫并杀死之。

矿物探测时，先将附近物品传送至高处，随后将附近的矿物替换成对应的半个木门。clone move 附近的方块使其更新，木门掉落。将在木门处生成指定分组潜影贝，给予指定分组的发光效果。清除附近的木门，并将高处物品传送回来。等待一段时间后，杀死潜影贝即可。

结构
附件中的文件已经包含了相应的结构和地图数据。
生成结构时，先放置结构方块，然后放置红石块激活。

更多的画均是地图文件，打包在一个箱子内。

v1.6 更新内容一览
  • 游戏本体版本升级为1.12，不再支持1.12之前的版本。
  • 不再支持使用粘性活塞回收；新增回收斧锹锄；回收产物均调整为1；修改压制钻石配方；新增压制鞍、蜘蛛网、马铠、粘土、浮冰。
  • 删除鸟刷怪蛋，增加鹦鹉、卫道士、幻术师刷怪蛋的合成。
  • 精制矿物合成材料恢复到需要使用低一级的精制矿物；修复了精制煤炭的名称；锹的合成形状恢复正常；修复了剑和护腿不在对应槽位也有属性加成；修复了护腿的盔甲错误；精制矿物合成的剑添加横扫之刃魔咒；调整传送的距离为200米；强力磁铁将有5秒的冷却时间；修复矿物探测器和传送球的漏洞。
  • 新增附魔金苹果的合成。
  • 删除了建筑和植物的合成；新增树种的合成，放置在羊毛/树叶可以得到不同的树；修改画的合成配方；删除了画：春夏秋冬；增加了画：岩间圣母、创造亚当、伏尔加河上的纤夫、开国大典、无名女郎。
  • 增加24种进度。
  • 有几率天然生成高压爬行者。
  • 掉落物变动：增加僵尸猪0-1猪肉；僵尸村民(被玩家杀死)0-1绿宝石，不受抢夺附魔影响；村民0-4绿宝石；驴、骡、马、羊驼1-3生驴、骡、马、羊驼肉（属性同羊肉）、鹦鹉1-2生鹦鹉肉（属性同鸡肉）、北极熊1-4生熊肉（属性同牛肉），着火时掉落对应熟肉；哞菇3-5红蘑菇。修改：鸡、鹦鹉着火时死亡将不掉落羽毛；唤魔者掉落物不死图腾修改为金色。
  • 钓鱼：新增宝藏湿海绵；新增垃圾火药，和腐肉等权重。
  • 完全去除了命令方块；修改了材质的文字部分；修复了GUI材质透明错误。
