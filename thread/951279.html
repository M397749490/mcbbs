（功能简介 )


  • 手持未绑定物品 shift + 左击 打开绑定界面

  • 自定义修改绑定界面的material name lore  

  • 钓鱼竿未绑定无法钓鱼

  • 武器未绑定无法攻击

  • 工具未绑定无法挖掘

  • 已绑定物品禁止手持输入指令（防上架到全球市场）

  • 已绑定物品禁止丢（可在配置设置开关）

  • 已绑定物品别人禁止捡起来

  • 自定义开关未解封状态动作

  • 使用Gui界面解绑物品（更方便）




( 命令/权限 )

/Gubind bind add - 添加待绑定状态

/Gubind bind setbind 《玩家名》 - 设置手持物品绑定为某个玩家

/Gubind bind open - 使用命令打开绑定界面

/Gubind Untie unbind - 使用命令解除手持绑定

/Gubind Untie open 打开解绑界面

/Gubind Untie give <玩家> <数量> 给解绑石

/Gubind about 查看插件信息

/Gubind reload 重新加载配置


Guibind.add - 添加待绑定权限 （默认权限OP）

Guibind.setbind - 设置某个玩家绑定权限 （默认权限OP）

Guibind.unbind - 解除绑定权限 （默认权限OP）

Guibind.reload - 重新加载配置 (默认权限OP)

Guibind.Untie.open - 打开解绑界面权限

Guibind.Untie.give - 给解绑石权限
