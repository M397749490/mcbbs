★指令★
感谢frea的提醒，指令/rc可能和领地内聊天指令冲突
如果发生类似情况，请把指令中所有/rc换成/rtp，效果相同

指令太多了，挑几个重要的先介绍，后面再加
请注意，本插件所指“地标”非ess的warp地标，而是本插件的地标
标有[]代表可选变量


——————【基础指令】——————
/rc 随机传送
/rc player [玩家名] [目标世界名] [最大半径] [最小半径]   随机传送其他玩家
/rc all [目标世界名] [最大半径] [最小半径]   随机传送全部玩家
/rc reload   重载插件

——————【地标指令】——————
再重复一遍，本插件所指“地标”不是ess的warp地标
/rc warp set <地标名>   设置你脚下为地标
/rc warp [目标世界名] [玩家名]   让某玩家随机选择某世界某个地标传送
/rc warp delete <地标名>  删除某个地标

所有指令还可加一个变量[from:来源世界名]，即只有在这个世界的人会被传送

更多指令请参下方教程

★权限★
——————【玩家权限】——————
random.basic   玩家基础权限，即玩家可使用指令/牌子/传送门传送
↑↑↑给玩家这个准没错，下面的别看了↑↑↑

random.command   使用/rc指令随机传送
random.warps   使用/rc warp指令随机选择地标传送
random.onjoin   允许玩家第一次进服的时候随机传送
random.portaluse   使用传送门传送的权限
random.signuse   使用木牌传送的权限
random.cooldown.bypass   无视冷却时间直接传送
random.TBT.bypass   无视传送前延迟直接传送

——————【WorldGuard权限】——————
random.region.others   使用/rc region [玩家名]指令随机传送玩家进区域
random.region.command  使用/rc region指令
random.region.[WG区域名]   允许使用/rc region [区域名]来传送进特定区域

——————【管理员权限】——————
random.admin.*   全部管理员权限
random.admin.all   允许使用/rc all传送所有人
random.admin.settings   允许使用/rc set指令
random.admin.others   允许使用/rc player传送其他玩家
random.admin.portals   允许使用/rc portal创建传送门
random.admin.reload   允许使用/rc reload重载插件
random.admin.warp   允许使用/rc warp创建地标
random.admin.sign   允许创建传送木牌
random.limiter.bypass  是否无视config限制的总传送次数


下面是教程部分，我觉得有必要召唤一波小组排版了，All Hail PCD！
教程一★如何设置随机地标传送
本功能适合枪战等服务器的随机特定地点传送

一，使用指令/rc warp set <地标名>设置多个地标
二，让玩家执行指令/rc warp即可随机传送，强烈建议该指令绑定脚本方块，指令牌子等辅助插件，不建议让玩家直接执行
三，如何设置只在本世界的地标随机传送？打开config.yml找到
  1. WarpCrossWorld: true
复制代码
true改为false，这么一改玩家就只能在本世界的随机地标里传送啦！

教程二★如何设置WG区域内随机传送
本功能适合PVP竞技场，小游戏竞技场随机地点加入

一，创建WorldGuard区域大家都会吧，先用小木斧选出区域，然后/rg define <区域名>创建区域
二，让玩家执行/rc region <区域名>即可，和上面一样，建议使用绑定指令，不建议直接执行

教程三★如何设置木牌随机传送

一，最简单的传送木牌：木牌第一行写上[RandomCoords] 玩家点击木牌如同执行指令/rc
二，指定世界随机传送的木牌：木牌第一行写上[RandomCoords] 第二行写上世界名即可
三，能付费传送的木牌：木牌第一行写上[RandomCoords] 第三行写上金钱数量即可
四，又能指定世界又能付费的木牌：……你就不能把第二、三种木牌合起来吗

教程四★如何设置传送门随机传送

一，输入指令/rc wand 获得创建传送门的巴拉拉小魔棒
二，使用该魔棒左键传送门一个点，右键对角线一个点，选出传送门区域
三，输入/rc portal create <传送门名称> [目标世界名]即可创建完成！[目标世界名]可选
你还可以加更多可选变量，所以完整的指令应该是这样的：
/rc portal create <传送门名称> [半径最大值] [半径最小值] [目标世界名]
四，想要删除传送门，输入/rc portal delete <传送门名称>即可
五，列出所有传送门列表，输入/rc portal list

教程五★新人随机传送|初始道具箱配置

某些原版生存的服务器可能需要这个功能

一，打开config.yml找到 OnJoin 并将其改为true，找到 OnJoinWorlds 并设定随机传送的世界，然后再给玩家权限组上权限random.onjoin，即可开启新人玩家进服随机传送功能
本功能可能会和某些固定上线的插件起冲突，请斟酌使用
二，初始道具箱，指的是玩家第一次进服，随机传送后会在其身边生成一个道具箱
打开config.yml，找到
  1. BonusChest: false
  2. BonusChestItems:
  3. - WOOD_SWORD
复制代码
先把BonusChest启用，随后即可在下面配置将会生成的奖励物品，物品必须是英文名
可直接使用Essentials的kit礼包作为道具箱物品，在物品名称处写上Essentials,礼包名称即可
如Essentials,tools
…………可能直接放到背包里更好吧

教程六★空岛传送模式配置|其它

本功能适合虚空世界随机传送（比如空岛）
可在传送到虚空时脚下生成一个方块，当你离开这个方块3格远以后方块自动消失
该配置在SkyBlockSave.yml中
  1. # 传送到虚空位置时脚下生成的方块种类 BEDROCK是基岩
  2. SkyBlock: BEDROCK
  3. # 当你离开这个方块3格远后，该方块是否移除？
  4. AutoRemove: true
  5. # 默认传送到的高度
  6. DefaultY: 60
  7. # 启用这种空岛传送机制的世界
  8. SkyBlockWorlds:
  9. - RandomExample
