     介绍

* 注: 摘自原文与维基百科
* 注: 原搬运贴长久未更新，故二搬

OpenTerrainGenerator是一款致力于类似于史诗地形的插件，同类插件还有EpicWorldGenerator，虽然EWG也是功能强大，但是EWG是付费插件，让国内许多用爱发电的服主望而却步，而现在！OTG，这款免费的插件！就是你最好的选择！而且，OTG还支持forge服务器和spigot，不支持CatServer！


二楼为兼容性和使用方法


MultiverseCore 创建方法:

/mv create [预置地形包名字] normal -g OpenTerrainGenerator

     特点

+ 全新的生物群系，可自定义的地形起伏
+ 可创建新的生物群系！
+ 可导入自定义树木或者BO3
+ 自定义建筑，新的村庄，新宝岛
+ 洞穴与峡谷都可以自定义呢
+ 可自定义树叶还有天空(需要客户端也装OTG模组)
+ 多维度支持，不单只是主世界
+ 自定义生物都可以呢！
+ 还有预置世界供你选择！

How to use it  Mohist如何使用
+ 把这个下载好的插件放入 mods 文件夹内
+ 把地形包以.jar的形式放入 mods 文件夹内
+ 然后把下载好的插件放入你的客户端的 mods 文件夹内
+ 然后进入服务器，按O
+ 点一个一个地形包，点 ADD 来创建世界
