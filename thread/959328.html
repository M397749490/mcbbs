Sell
快速出售物品

功能介绍:
  • 快速出售物品
  • 自定义gui内容（大小.标题.介绍）
  • 开关判断lore回收
  • 判断lore回收价格（例如:回收价格:100）
  • 可自定义添加原版物品出售(前提得关闭判断LORE)
  • GUI是模仿Sx的, 可以吐槽
配置文件与使用方法:
配置文件
#可在配置文件中添加可回收的原版物品
#可以手持物品输入/Sell add <价格> 快速添加
  1. SellItem:
  2.   DIAMOND: 50
复制代码

  1. #出售界面的标题
  2. SellGUIName: '&e出售系统'
  3. #出售界面的格数(不可以低于18，必须为9的倍数)
  4. SellGUISlot: 27
  5. #如果以Lore判断回收价格，那么下面就是判断的Lore
  6. SellLore: '回收价格'
  7. #是否以Lore判断回收价格(false则只判断原版ID)
  8. LoreDetermine: false
  9. #语言
  10. Message:
  11.   SaleSuccess: '&f[&e出售&f] 你出售物品获得了 &e%price% &f金币!'
  12.   NotforSale: '&f[&e出售&f] 你放入的物品不可以 &e出售 &f哦!'
  13.   Noitems: '&f[&e出售&f] 请放入你需要 &e出售 &f的物品!'
  14.   NoHandItems: '&f[&e出售&f] 请手持你需要添加的物品!'
  15.   ErrorSellPrice: '&f[&e出售&f] 请填写正确的出售价格!'
  16.   AddSellItem: '&f[&e出售&f] 已将物品 &e%ItemType% &f添加到出售列表中, 售价为 &e%price% &f金币'
  17.   NoPermission: '&f[&e出售&f] 你没有使用当前指令的权限!'
  18. #以下为创建收购物品的地方，格式为(物品ID: 价格)
  19. #物品ID可手持物品输入指令 /Sell id 查询
  20. SellItem:
  21.   DIAMOND: 50
复制代码


命令&权限:
/sell——打开回收界面                                             权限sell.use
/sell id——查询手中物品的原版ID                          权限sell.id
/sell add <价格> 添加手中物品到出售列表            权限sell.add
/sell reload 重载插件配置                                      权限sell.reload
