插件介绍:
在关服重启的时候会自动刷新指定世界(支持种子)
以达到自动刷新世界的效果,需要 Multiverse-Core 插件作为前置插件
非常轻量级且不会卡服(毕竟是在关服的时候刷新),大概可以方便一些懒癌腐竹吧

配置文件：
  1. # 自动刷新世界,在开服的时候会判断是否过期,如过期则进行刷新
  2. # 需要 Multiverse-Core 插件作为前置插件,支持自己添加多个需要刷新的世界

  4. # 不想要的功能可以直接在配置文件中删掉
  5. # 如果您删掉配置文件之后,该功能会自动禁用

  7. 自动刷新世界:

  9. # 自动刷新 ziyuan 世界
  10. #   ziyuan 即为要刷新的世界名称
  11. #   如果不清楚世界名称可以到多世界插件的 world 文件查询

  13. # 刷新间隔
  14. #   单位为天 多少天刷新一次
  15. #   设为 0 则每次关服都会进行刷新

  17. # 上次刷新时间
  18. #   记录上次刷新地图时间
  19. #   请不要尝试改动,如想重置刷新时间请设为 0

  21. # 游戏规则设置
  22. #   每次刷新世界时自动设置游戏规则
  23. #   不需要您再次手动重新设置游戏规则

  25.   ziyuan:
  26.     刷新间隔: 7
  27.     上次刷新时间: 0
  28.     游戏规则设置:
  29.     - 'keepInventory,true'

  31.   world_the_end:
  32.     刷新间隔: 7
  33.     上次刷新时间: 0
  34.     游戏规则设置:
  35.     - 'keepInventory,true'
