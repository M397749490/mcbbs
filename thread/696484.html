The plugin is not perfect, do not hesitate to report the bugs
I create this free and open source plugin because I do not know very well Java and I count on you to help me to improve EpicPets


该插件还不是很完美，遇到BUG请不要犹豫，请汇报给作者吧！

作者创建了这个免费的开源插件.

因为他还没能完全运用Java，

所以依靠我们大家来帮助他改进EpicPets








1.你可以创建自己的宠物纹理和动画；有关更多信息，请参阅文档.

2.可以伪装和修改宠物外观,可以使用GUI来修改宠物相关内容,也可以根据需要修改整个插件,配置文件相当完整.

4.本插件不会干扰pvp,放心去战斗吧.

5.你的视角右上方可以看到固定的宠物.

6.你的宠物会拥有特殊的动画陪伴你.

7.使用蹲下按'Shift'让宠物ID隐形;当潜行时宠物名称将会消失.

8.本插件不需要任何资源包.

9.你可以自定义宠物的名字.

10.该插件支持Worldguard插件.

文档包括权限和命令


权限

  1. 召唤宠物: epicpets.pet.spawn
  2. 移除宠物: epicpets.pet.remove
  3. 为宠物改名: epicpets.pet.rename

  5. 打开菜单: epicpets.gui.open.main
  6. 打开宠物动画菜单: epicpets.gui.open.animations
  7. 打开宠物偏好效果菜单: epicpets.gui.open.preferences
  8. 打开宠物头盔菜单: epicpets.gui.open.helmet
  9. 打开宠物胸甲菜单: epicpets.gui.open.chestplate
  10. 打开宠物裤子菜单: epicpets.gui.open.leggings
  11. 打开宠物鞋子菜单: epicpets.gui.open.boots

  13. 让宠物缩小/放大: epicpets.gui.action.preferences.setsmall
  14. 重命名宠物: epicpets.gui.action.preferences.showname
  15. 设置宠物盔甲架是否可见: epicpets.gui.action.preferences.setvisible
  16. 显示/关闭宠物的手臂: epicpets.gui.action.preferences.showarms
  17. 启用/禁用 潜行(Shift键) 隐藏宠物ID: epicpets.gui.action.preferences.sneakprotect
复制代码




指令：

  1. /epicpets spawn 召唤宠物
  2. /epicpets remove 移除宠物
  3. /epicpets gui 打开宠物主菜单
