前言：
我第一次玩监狱风云是在2015年的某盒子的一个群组服内
当时对这款游戏很上瘾。个人感觉在极限中挖矿挺有意思的
只是服务器到了后面越来越卡，觉得玩着没意思。
当时那服务器玩的人虽然多，也只有那一个监狱风云
可以拿出手来。其它的都是简单的迷你游戏。
——————————————————————————————————————————




简短介绍
此端是国内一款完美的监狱生存类型的整合包
近期将对核心进行优化，敬请期待。
<本服务端插件只适用于VPS，家用电脑等Windows系统。Linux和面板服就不要使用了。>


游戏玩法
游戏开局会发一套装备和工具，玩家通过在A,B,C,D,PVP矿区挖矿
赚钱升级罪犯等级，C矿区开始就有罪犯等级限制(详细请开服游戏)
部分矿区没有PVP限制或者死亡不掉落。玩家可能一夜暴富
或身无分文。

游戏指令
/drop 切换丢弃状态
/manuaddv 玩家id prefix 给某玩家一个前缀称号
/eco [give/take/reset] id 数量  调整玩家的经济状态
/points give id 数量   给予点卷
/worth [ID] 查看系统价格,不写物品id默认为查看手上的物品价格
/itemdb 查询你手上拿着的物品的名称和ID
/whois 查看玩家IP地址
/setworth [物品名字/物品id] [数值]  设置物品的系统价格
/invsee id  查看玩家背包
/enderchest id 查看玩家末影箱
/Shopkeepers 召唤村民
/Shopkeepers sing 激活一个牌子作为商店

矿场相关-高级命令:
权限节点：prison.mines.manage
/mines create <名称> [创建一个矿场]
/mines addblock <矿场名> <方块ID> <几率> [设置方块在矿场刷新比率]
/mines reset [刷新该矿场]
/mines info <矿场名> [查看该矿场的信息]
/mines list [查看所有矿场]
/mines removeblock <矿场名> <方块ID> [删除方块在矿场刷成]
/mines delete <矿场名> [删除一个矿场]
/mines redefine <矿场名> [重新划定矿场的区域（需要先用创世神选取两个点）]

/npc remove
/npc resetcmds 删除选定NPC所有指令
/npc addcmd false noperm 指令    给NPC绑定指令
