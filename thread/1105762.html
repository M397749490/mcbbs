作者: ❤️🍓    时间: 2020-8-20 09:09
解压文件，用记事本打开pack.mcmeta文件，将里面的
{
   "pack":{
      "pack_format":5,
      "description":"这是资源包的简介"
   }
}
把里面的
"pack_format":3

改为
"pack_format":1

保存，然后放进游戏
（压不压缩都没问题）
就可以使用了
（但不知道多出来的那些贴图🈶🈚问题会影响游戏）
