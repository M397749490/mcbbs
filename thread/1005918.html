在核心的目录下新建一个txt文档
名字看你喜好
然后打开这个文件
输入
@color 0b
java -Xms1024M -jar 你核心的名字 nogui
PAUSE
然后保存
退出后把这个文件的后缀改成.bat
再点开就可以了

作者: liaoxu2003    时间: 2020-4-2 21:40
您好 新建一个.txt文件 在里面编辑并保存为.bat
@echo
OFFjava -Xms512m -Xmx最大内存m -jar 核心名.jar
pause
然后放在服务端根目录运行即可
进入游戏输入ip 127.0.0.1:所分配端口
即可登录服务器
