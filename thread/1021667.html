邀请管理器插件

简介：

      这个插件除了能自动派发奖品，还可以帮助你追踪玩家邀请的其他玩家（禁止套娃）版本从1.8支持到1.15.2，安装也十分简单，

特点：

  • 简易的指令
  • 快速存储
  • 自定义奖励指令
  • json格式存储
配置文件:


  1. # 默认配置文件
  2. # 原作者: maxbridgland <mabridgland (at) protonmail.com>

  4. # 启用插件
  5. enabled: true
  6. # 奖励机制
  7. levels:
  8. # 奖励等级
  9.   5:
  10.    # 当玩家达到5个邀请数
  11.     # {player} 会替换为邀请者
  12.     - "say {player} 邀请了5人啦！"
  13.     - "give {player} diamond_sword"
  14.   # 下面这个和上面这个格式一样
  15.   10:
  16.    - "say {player} has reached 10 invites!"
  17. misc_settings:
  18. # 防止用机器人刷邀请的屑（非100%准确）
  19.   bot_protection: true
复制代码

指令：

/im

    - /im i <玩家名>把玩家注册为输入者的邀请者

    - /im top 邀请者排名，邀请的人越多就越靠前

    - /im stats 查看自己的邀请情况
