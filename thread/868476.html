要单独拿出来说的

1.显示形式
  1. # Style Health 显示形式
  2. #生命值显示为?（官方默认配色）
  3. #Full Health Icon: "&4\u2764"
  4. #Half Health Icon: "&c\u2764"
  5. #Empty Health Icon: "&7\u2764"
  6. #生命值显示为方块（官方默认配色）
  7. #Full Health Icon: "&a&l\u2588"
  8. #Half Health Icon: "&a\u258c"
  9. #Empty Health Icon: ""
  10. #生命值显示为线状（官方默认配色）
  11. #Health Message: '{name} - &c[{usestyle}&c]'
  12. #Full Health Icon: "&c\u007C"
  13. #Half Health Icon: "&c\u007C"
  14. #Empty Health Icon: "&4\u007C"
  15. #显示为 当前生命值/最大生命值（官方默认配色）
  16. #Health Message: '&6&l{name}: &a&l{health} / {maxhealth}'
  17. Full Health Icon: "&4\u2764"
  18. Half Health Icon: "&c\u2764"
  19. Empty Health Icon: "&7\u2764"
复制代码

心形字符：\u2764
方块字符：\u2588
半方块字符：\u258c
线状字符：\u007C
用您想要的显示形式的字符替换下面配置中的字符，保存并重载即可。
如果您想使用 [当前生命/最大生命] 的显示方式，
只需要设置文件开头的“Health Message”为“{name}:{health} / {maxhealth}”即可。

示例：

  1. # If enabled players with the permission 'ActionHealth.Health' will only see the action health message.是否只对有拥有“ActionHealth.Health”权限的玩家显示血量 默认false
  2. Use Permissions: false

  2. # The message the player is sent.血量显示格式

  71. - randomworld

  74. - testing_region

  76. # Disable ActionHealth in regions where PvP is denied.在禁止PVP的区域禁用该插件 默认true
  77. Region PvP: true

  79. # Limits the health style to a certain amount of symbols.前三种生命显示格式的字符（?、方块、线）上限 默认10
