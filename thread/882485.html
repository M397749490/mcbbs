BowTweaker v1.0



简介



这是一个简单的轻量级的插件，在玩家使用弓时发射除了箭矢以外的实体

所发射实体的种类，位置，初速度都可以通过配置文件高度自定义





使用方法

基础使用方法：





输入/bt list列出所有可用的弹药类型

手持弓 输入    /bt set 弹药类型 弹药数目

若成功 物品的lore会有改变

然后就可以用弓箭发射此弹药啦



进阶使用方法——自定义实体：




需要一定java基础

将插件放入plugins文件夹后启动一次
就会在plugins\BowTweaker\BTScripts文件夹下生成
与弹药类型同名的配置文件
新建NEW.txt并输入
  1. 发射猪
  2. new net.minecraft.entity.passive.EntityPig(world);//new+空格+forge全限定名(用逗号分隔的参数);
复制代码



猪会在坐标0,0,0生成，所以修改它的坐标
  1. 发射猪
  2. new net.minecraft.entity.passive.EntityPig(world);//脚本支持双斜杠注释
  3. setPosition(x,y,z);
复制代码


我们要发射猪，所以给它一个初速度

  1. 发射猪
  2. new net.minecraft.entity.passive.EntityPig(world)；
  3. setPosition(x,y,z);
  4. setMotion(fx,fy,fz);
复制代码




修改初速度使其与力度成正比

  1. 发射猪
  2. new net.minecraft.entity.passive.EntityPig(world)；
  3. setPosition(x,y,z);
  4. setMotion(fx*charge/20,fy*charge/20,fz*charge/20);//支持四则运算
复制代码



也可以使用临时变量简化脚本


  1. 发射猪
  2. power=charge/20；//charge太大了，不除以20猪会直接飞没
  3. net.minecraft.entity.passive.EntityPig(world);
  4. setPosition(x,y,z);
  5. setMotion(fx*power,fy*power,fz*power);
复制代码


这与上个脚本是等价的
之后输入/bt reload 或重启服务端，然后使用/bt set 指令
就能够用弓愉快地发射猪猪啦！
更多自定义脚本的教程可以在下载的压缩文件中找到，不在此赘述
插件初次启动会在plugins\BowTweaker\BTScripts文件夹下生成脚本样例，可以作为参考或直接使用



配置文件

##lore中的前缀
TypePrefix: "§6弹药类型:"
RemainingPrefix: "§6剩余次数:"
## 当有无限I附魔不消耗箭矢"true""false"请带引号
ReactToInfinite: "true"
##设为true不在后台输出脚本错误信息
MuteScript: "false"
##true:forge事件系统  false:bukkit事件系统 这也是插件不兼容除了KCauldron以外服务端的原因之一
EventSystem: "true"





命令

/bowtweaker /bowt /bt     获取帮助
/bt list                             列出所有可用的弹药类型
/bt set <type> <amount>将手持弓的弹药类型设为<type>,弹药数目为<amount>,如果<amount>为负数则视为无限
/bt charge   <amount>     将手中弓弹药数据增加 <amount>
/bt clear                          将手中弓恢复为普通弓
/bt reload                        重新加载弹药配置文件







权限节点

bowtweaker.admin 使用所有指令的权限
bowtweaker.use 发射特殊弹药的权限
在KC版本admin 权限默认op拥有 use权限默认所有人拥有
在sponge版本中需要使用权限管理插件手动给予权限











注意事项&已知问题



1.本插件已在KCauldron-1.7.10-1614.201服务端测试可用，应该能支持所有1.7.10的KCauldron版本与其优化版本

由于插件本身的一部分原因（使用了forge api），绝对无法兼容CB/Spigot端

说这是一个forge mod也不为过

2./bt set 会覆盖弓的lore，可能会影响其他插件

3.弓射击中止(某些脚本会导致这个问题)后不会消耗箭矢，但客户端会不同步，需要点击一下箭的槽位才能更新

建议为每张弓附魔无限I避免这个问题

4.在使用部分登陆插件时，未登录时时仍然可以使用弓，建议开启隐藏物品栏解决问题

5.现已支持Sponge1.12.2 （测试版本 spongeforge-1.12.2-2705-7.1.0-BETA-3151 forge-1.12.2-14.23.4.2705-universal）

请使用SpongeForge而不是SpongeVanilla

配置文件会在plugins\BowTweaker生成 由于编码问题，修改配置需要转为Unicode编码（脚本不受影响）
