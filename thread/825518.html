测试版是Minecraft 基岩版的测试机制，主要用于下一个正式版的特性预览。

然而，测试版主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。适用于正式版的领域服务器不兼容，不提供支持。

如果在测试版中遇到旧版存档无法使用的问题，测试版将允许你将存档上传以供开发团队查找问题。

Minecraft 基岩版 1.8 仍未发布，1.8.0.11为其第3个测试版。

转载本贴时须要注明原作者以及本帖地址。



改动：
  熊猫的变化与改动：
  • 所有默认大熊猫现在都会在它们受到攻击时咬一次
  • 攻击性熊猫会保护其它熊猫
  • 为攻击性熊猫添加新皮肤
  • 熊猫现在会把愤怒发泄到攻击性熊猫身上
  • 攻击性熊猫现在会保护被攻击的熊猫宝宝

BUG修复：
  • Fixed several crashes that occurred during gameplay
  • 修复了游戏期间可能出现的崩溃问题
  • Fixed a crash that occurred when joining multiplayer games
  • 修复了在加入多人游戏时崩溃
  • The player's arm now moves at the correct speed when breaking blocks (MCPE-38041)
  • 破坏方块时，现在玩家的手臂会以正确的速度移动
  • Custom entities can now correctly use the 'minecraft:shooter' component (MCPE-38263)
  • 自定义实体现在可以正确使用“MiCeFrave:Sunoter”组件
  • Players can now correctly use scaffolding that is in or near water (MCPE-38054)
  • 玩家现在可以正确地使用水上附近的脚手架
  • Flight controls on mobile devices now work correctly after climbing scaffolding (MCPE-38059)
  • 手机设备在攀爬脚手架之后能够正确地控制飞行
  • Fixed a bug that caused horses (and variants) to show flashing colors on certain devices (no more disco horses!) (MCPE-31726)
  • 修正了一个导致马（以及变种）在某些设备上显示闪烁颜色的错误（没有更多的迪斯科马！）
  • Fixed a bug that caused a significant performance drop when rendering chunks (MCPE-37192)
  • 修正了在渲染区块时导致性能显著下降的bug
  • Gamerule slash commands can now only be changed by operators
  • /gamerule 指令现在只能由操作员更改
  • Falling blocks (such as sand) will no longer cause scaffolding extensions to fall (MCPE-38098)
  • 落下的方块（比如沙子）将不再导致脚手架延伸下降
  • Fixed a bug that could result in the a player's spawn point being changed inadvertently
  • 修正了一个可能导致玩家的重生点被无意中改变的bug
  • Pressing the "Go Back" button in "Turn Off Achievements" window no longer changes the game mode in World Settings (MCPE-38278)
  • 在“关闭成就”窗口中按下“返回”按钮后不再改变世界设置的游戏模式
  • Pandas no longer become stuck in a sitting position after reloading the world
  • 重新载入世界后，熊猫不会被卡住坐姿
  • Newly equipped player skins now apply correctly to the paper-doll model
  • 新装备的玩家皮肤现在正确地适用于纸娃娃模型
  • Endermen no longer have a missing jaw when attacking
  • 末影人在攻击时不会缺失下巴
  • Blocks now disappear more quickly when broken quickly in creative
  • 在创造模式更快地破坏方块时，方块会更快地消失
  • Search results in the Marketplace are now more consistent when searching through all content
  • 在搜索所有内容时，搜索结果会更加的一致
  • Only templates are suggested in the "Get More Templates" menu now
  • 现在只能在“获取更多模版”菜单中建议模版
  • Using a bucket of fish in a dispenser no longer crashes the game (MCPE-38194)
  • 在炼药锅中使用一桶鱼不再会导致崩溃
  • Dyed beds now have the correct crafting recipe
  • 染色床现在有正确的合成配方
  • Fixed the bug where the player would unexpectedly turn in a random direction (MCPE-35910)
  • 修复了玩家在任意方向上意外转向的bug
  • Double slabs will now create the correct type of block (MCPE-38107)
  • 双层台阶现在将创建正确的方块类型
  • Fixed a bug where the world could crash if the player exited the world whilst using a nether portal
  • 修复了玩家退出世界的同时使用地狱传送门会崩溃的bug
  • Selecting an unowned skin now directs you to the expanded skin picker menu
  • 选择一个未拥有的皮肤现在会定向到扩展皮肤选择菜单中
