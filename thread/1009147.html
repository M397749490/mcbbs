简介:
使用经验来飞行
目前只用1.12.2测试能使用
其他版本请自行测试





指令:
/expfly on  [开启经验飞行]
/expfly off  [关闭经验飞行]
/expfly reload [重载经验飞行]

配置文件:


    general:
      # 每秒消耗的经验值
      consume: 2.5
      # 开启经验飞行的最小经验值
      start-exp-min: 300.0
      # 为他人开启经验飞行所需的权限
      admin-perm: "expfly.admin"

    # 禁用经验飞行的世界
    noFlyWorlds:
      - nofly
      - disallow

    message:
      reload: "§a插件重载成功"
      no-perm: "§c你没有权限这么做"
      no-player: "§c这个玩家不存在或不在线"
      player-only: "§c这个命令只能由玩家执行，后台使用请指定目标名称"
      no-enough-exp: "§c你的经验不足，飞行关闭"
      start-fly: "§e你开始经验飞行了"
      end-fly: "§e你停止了经验飞行"
