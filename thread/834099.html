介绍  · Introduction




Robbery 可以让你设置可以让玩家抢钱或物品的商店。
这款插件完全可自定义，你可以配置多个不同的可掠夺的商店以及掠夺所需时间、掠夺冷却时间。

前置  · Dependencies
必要前置:
  • Vault
  • Citizens
  • WorldEdit / WorldGuard

非必要前置:
  • CrackShot
  • HolographicDisplays


特点

  • 两种抢劫方式:
抢劫银行:
[size=14.6667px]玩家必须创组队才能开始银行抢劫，抢劫开始后，玩家需要在一定的时间突破银行的防线，从保险箱里偷钱，偷完东西后，玩家需要逃出生天才能收到被盗的现金.

目前，有两种可以放在银行里的结构，一种是保险库门，用来保护保险箱，另一种是保险箱，用于存储金钱。

普通抢劫:
玩家可以直接抢劫商店，等待劫掠时间结束后即可完成抢劫. 用Crackshot的枪支指着NPC的头部可以加速劫掠时间.?




  • 可通过指令轻松地关联如police等其他插件来进行劫掠
  • 完全可自定义
  • 可创建多个可掠夺商店
  • 可用金钱后和指令作为掠夺物 (未来将支持变量)
  • 可配置每个地方的掠夺冷却
  • 支持用CrackShot的枪械指着NPC的头来加速抢劫
  • 基于GUI来开始掠夺(潜行+右键 NPC)
  • 如果玩家在掠夺过程中被杀死或离开会导致劫掠失败
  • 用action bar消息条显示掠夺所需时间

Commands · 指令 & 权限  · Permissions

指令
  • /robbery help
  • /robbery reload
  • /robbery place add <地点ID> <地点名> <WG区域ID> <劫掠时间> <劫掠冷却>
  • /robbery place remove <place id>
  • /robbery crew  - 用于组队抢劫
  • /robbery join <队伍名> - 受到邀请后加入抢劫队伍
  • /robbery structures -用于生成银行结构 (保险库门和保险箱)











权限

  • robbery.help - /robbery 或 /robbery help 指令的权限.
  • robbery.reload - 重载插件.
  • robbery.place - 管理可掠夺地点所需权限(添加和删除).
  • robbery.gui - 打开劫掠GUI的权限.
  • robbery.crew - /robbery crew 指令权限
  • robbery.join - /robbery join 指令权限
  • robbery.structures -  /robbery structures 指令权限
