2.安装JDK(Java开发工具包)

如果你还没用下载请到上面的链接中下载，推荐下载Java7。

为了开发Mod你必须安装有JDK，如果你已安装请跳过
如果你没有安装请看一下步骤
Windows：
1.打开JDK的安装程序进行安装，我们可以使用默认的安装目录，请记下安装目录因为我们在后续需要用到

2.安装完成后我们需要设置“系统变量”。打开 “我的电脑-右键-属性-高级系统设置”（XP：我的电脑-右键-属性）

3.切换标签到高级

4.点击下面系统变量。

5.点击系统变量分组框里面的新建按钮
（如果已经JAVA_HOME变量请点击编辑）

6.输入变量名为 "JAVA_HOME"，
变量值为JDK的主目录。
然后确定即可。

7.参照以上方法新建CLASSPATH变量
变量名：CLASSPATH
变量值：“.;%Java_Home%\bin;%Java_Home%\lib\dt.jar;%Java_Home%\lib\tools.jar”

8.找到Path变量，如不存在请新建。
点击编辑

9.在变量值最后面添加“%Java_Home%\bin;%Java_Home%\jre\bin;”
注意！：如果变量值最后面没有“；”请务必加上！
Linux：
可以先通过终端输入javac -version以确认是否已经安装
创建一个目录，并把下载到的Bin文件复制到该文件夹中
# mkdir /usr/java
然后根据自己的文件选择以下其中一种方法
1.jdk-8u51-linux-i586.bin文件安装
例如我下载的文件，名字是：jdk-8u51-linux-i586.bin
# chmod a+x jdk-8u51-linux-i586.bin     ←修改为可执行
# ./jdk-8u51-linux-i586.bin     ← 选择yes直到安装完毕
2.jdk-8u51-linux-i586-rpm.bin文件安装
# chmod 777 jdk-8u51-linux-i586-rpm.bin    ← 修改为可执行
# ./jdk-8u51-linux-i586-rpm.bin        ← 选择yes同意上面的协议
# rpm -ivh jdk-8u51-linux-i586.rpm       ← 选择yes直到安装完毕

配置环境变量
# vi /etc/profile     ← 使用编辑器打开文件

在最后加入以下几行：
export JAVA_HOME=/usr/java/jdk1.8.0_51
export CLASSPATH=.:$JAVA_HOME/jre/lib/rt.jar:$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
export PATH=$PATH:$JAVA_HOME/bin

# source /etc/profile    ← 执行后生效

3.环境的搭配
这一步非常麻烦，需要有耐心折腾。但请不要因为这一步放弃。


1.首先把下载好的Forge Src解压到一个目录下，例如:"D:\forgesrc\"
此时你看到的目录是这个样子的



2.“Win+R”打开运行，输入CMD，回车
在命令提示符或者终端下切换到你的Forge Src目录下。（例如:Win下输入命令 "cd D:\forgesrc\" 和 "D:"）


3.在该目录下执行以下命令:（在命令后面加上-i可以查看详细内容）
Windows下执行:gradlew.bat setupDecompWorkspace
OS X下执行:bash gradle setupDecompWorkspace
Linux下执行:                  略
执行完成后不要关闭窗口。
成功后才可进行下一步，怎么才算是成功呢：出现Build Success。
失败即Build Failed，失败请参考步骤3.1

如果需要完全重新配置环境请执行：gradlew --refresh-dependencies eclipse

4.2.Eclipse配置出错

1.使用已配置的ForgeSrc搭建中时间异常长久：在-i模式下如果不断的检验文件
貌似只能等如果有什么方法的可以回复我。之前这一步我一直提示检验文件，结果等了1个小时。

2.配置完成后，用IDE打开提示项目文件不存在：重新配置环境

如何手动配置：建议参考白玉楼之梦 - szszss' blog


5.配置成功后常见错误及解决方案。

1.运行时出现以下错误：Java HotSpot(TM) 64-Bit Server VM warning: Using incremental CMS is deprecated and will likely be removed in a future release
请使用JDK7，而不是JDK8.

2.导入时出现以下错误：Error:(X, X) java: package XXX
尝试执行gradlew idea，然后直接打开项目。  /    尝试重新执行。

3.IDEA在启动游戏时提示缺少SDK（Can't find out SDK ......）
手动添加SDK指向JDK主目录。

4.Eclipse配置成功后：打开项目时提示项目文件不存在
尝试重新配置

5.Eclipse配置成功并切换工作空间后：只有项目minecraft但是没有任何内容
双击项目即可加载内容

6.搭建过程中： “-i” 看到有不停的输出，但是非常久都不行
可能是因为Gradle在不停的检验文件，暂未找到具体方法只能等(尝试VPN或者FGOW或者国内源)。

7.配置好IDEA后没有运行项
在ForgeSrc目录运行gradlew gIR

8.IDEA运行错误，提示无法找到主类
打开“Project Structure => Modules => 选择名字为你的Minecraft版本的项”
