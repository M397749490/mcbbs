保存时，把玩家物品栏中的物品复制到潜影盒里，
例如：data modify block ~ 255 ~ 数据标签 set from entity 玩家 数据标签

再用把数据保存在盔甲架中
例如：data modify entity 盔甲架 ArmorItems[3].tag.Items set from block 潜影盒的坐标 Items


读取时反过来，先把物品放回潜影盒
例如：data modify block 潜影盒坐标 Items set from entity 盔甲架 ArmorItems[3].tag.Items

在配合修改的战利品表，并把潜影盒的内容物放回玩家物品栏
例如：loot replace entity 玩家 inventory.0 mine 潜影盒坐标 带有特殊tag的工具

潜影盒战利品表需要加上例如
"children": [
                {
                        "type": "minecraft:dynamic",
                        "name": "minecraft:contents",
                        "conditions": [
                                        {
                                                "condition": "minecraft:match_tool",
                                                "predicate": {
                                                                "nbt":"{工具的tag}"
                                                                }
                                        }
                                        ]
                }
