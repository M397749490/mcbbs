简介
简单来讲，这插件用于记录玩家收到的警告，每次收到警告时可自定义一些惩罚措施，比如监禁，当警告数量达到上限，将执行更加严厉的惩罚，比如ban掉！ 对于人数比较多的服，一定程度上能减轻管理压力，挡住一些屡屡犯错、心存侥幸的家伙~
基友服不推荐安装本插件。
另：本插件支持 MySQL

权限
&#8226; sw.warn - 能发出警告
&#8226; sw.check - 检查自己的警告记录
&#8226; sw.check.other - 检查别人的警告记录
&#8226; sw.delete - 删除其他玩家指定一条警告
&#8226; sw.mod - 拥有使用 SimpleWarnings 的管理指令权限
&#8226; sw.reload - 重载设置
&#8226; sw.fix - 更新老版警告记录数据到 0.8+ 的格式 —— 基本没用，无视

配置文件
  1. OnWarn: —— 收到警告时
  2.   Broadcast: true —— 广播否？
  3.   KickOnWarning: false —— 警告时是否T掉
  4.   CustomCommandOnWarning: false —— 警告时是否执行惩罚指令
  5.   CustomCommand: jail %player% 5m —— 指令
  6.   CustomCommandOnEachWarning: true —— 每次警告给予不同的惩罚
  7.   Penalties:
  8.     Warning1: none —— 一次
  9.     Warning2: none —— 二次 依此类推添加项
  10. OnJoin: ——加入游戏时
  11.   BroadcastWarningTotal: true —— 是否广播警告总数
  12.   NotifyUserOfWarningTotal: false —— 提示玩家否？
  13.   NotifyAdminOfUserWarningTotal: false —— 提示管理否？
  14.   NotifyAdminOfWarningExpire: true —— 是否提示管理已达上限
  15. MaxWarnings: —— 达到上限时
  16.   WarningLimit: 3 —— 次数上限
  17.   AutoBan: true —— 是否自动ban
  18.   DefineFinalBanMsg: false —— 是否显示被ban的信息
  19.   BanMsg: Warning Limit Reached! %player% Banned! —— 信息
  20.   CustomCommandOnMaxWarning: false —— 是否广播
  21.   CustomCommand: broadcast Goodbye %player% —— 广播内容
  22. WarningExpiration: 0
  23. MySQL:  —— MYSQL设置，以下不做介绍了~
  24.   USE_MYSQL: false
  25.   hostname: localhost
  26.   hostport: 3306
  27.   database: warnings
  28.   user: MYSQLUSER
  29.   password: MYSQLPASS
