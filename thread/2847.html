【服务器教程】Craftbukkit ！用Craftbukkit 架设自己的beta 1.3特色服务器！
http://www.mcbbs.net/thread-2798-1-1.html

本帖主要为那些想要建服的人提供便利（本资源来源于帖顶网址，饮水思源）

版本：git-bukkit-0.0.0-493-g8b5496e-b493jnks <MC: 1.3>
整合插件：essentialsHome插件，支持/sethome和/home指令；
　　　　　BackupPlugin自动备份；
　　　　　GroupManager权限系统；
　　　　　AnjoSecurity用户注册及登录插件


白名单：空；OP名单：空；ban玩家名单：空；banIP名单：空；

用户组名单：空；地图：无（开启服务器自动生成）；

建立服务器需要做如下修改：
server.properties文件内容
#Minecraft server properties
#Sat Mar 05 22:05:43 CST 2011
level-name=world （这个为地图文件夹的名称，若想换地图可给地图文件夹重命名或直接删除）
hellworld=false （地狱是否开启）
spawn-monsters=false （怪物是否出生）
online-mode=false （这个不是false，盗版就没法进行IP直连）
spawn-animals=true （动物是否出生）
max-players=20 （最大同时在线玩家数，建议修改，每一个玩家在线都会占用服务器所在电脑内存）
server-ip=（此处填上你的IP）
pvp=false （玩家间是否可以互相攻击，PK……）
server-port=（若为内网请填上端口（hamachi虚拟内网就填不填都可以了））
white-list=false （白名单是否开启）
spawn-protection=16 （出生保护）

下面是命令的更改与设置：

plugins\Essentials\config.yml文件部分内容:
# Disabled commands will be completellyunavailable on the server.
disabled-commands:（不可使用的命令，OP也不能用的）
- nick （给某人一个虚拟昵称（不影响原账号））
- whois （去除某人的虚拟昵称）


# Restricted commands will only beavailable to ops.
# These will have NO EFFECT if you havePermissions installed!
# These are here only if you wantsomething simpler than Permissions.
restricted-commands:（可以使用的命令）
- tree （造普通树）
- bigtree （造大树，除了桦树）
- item （给本人物品，形式：/give 物品id 数量，注意空格）
- give （给任意玩家物品，形式：/give 玩家昵称 物品id 数量，注意空格）
- plugin （添加修改或删除插件，可以无视）
- time （更改时间，就白天和黑天，直接加day或night）
- top （向上传送，地下挖矿时迷路用的）
- tp （传送，地球人都知道）
- antioch （未知，求知识分子搞定）
- back （使用/home后，方便返回原先位置，包满了放东西用的）
- broadcast （广播）
- clearinventory （背包物品清除，比如当你调物品调成一堆门，扔出去了又拣回来，这命令就有用了）
- compass （显示正对的方位及距离）
- depth （显示海拔，注意是海拔，跟小地图的不一样的）
- essentials （重载插件）
- getpos （显示坐标，有小地图也没啥用了）
- gc （内存及地图情况）
- helpop （向OP求助，只有OP可见）
- jump （跳跃到准心所在的方块）
- kit （显示组件）
- kill （杀人）
- killme （自杀）
- ping （Pong！）

plugins\GroupManager\worlds\world\users.yml文件内容:
users: {}
注意空格，如果文本内容不为这种形式服务器将无法修改玩家的用户组

单机版的MOD是给自己用的，跟单机一样
服务器的MOD是在服务器上可以用的，用来更改用户权限或增加命令等的
材质只能是自己用
“放到服务器上，然后大家进入时就更改材质”这是不可能的，你可以告诉大家用某个材质，因为服务器只是建服而已
