利用权限来控制玩家伤害倍数,支持多位数小数(1.111223之类的).请务必看到最后的如何使用！否则会出错！
插件还在Beta测试版本,出现任何BUG请及时跟帖回复.

注意：
1>本插件需要权限的支持,请任意选择安装权限插件,或使用bukkit/spigot自带permission.yml
2>切记要设置spigot.yml里的伤害Max值,以免伤害超过上限!

使用范例:
1> RPG服务器用来控制VIP的伤害行为,多种VIP不同伤害倍率.
2> 普通生存服务器,降低玩家伤害. 增加生存难度.
3> 模拟职业转职,给予权限伤害翻倍!
4> 变态RPG服控制伤害的基础插件!

功能:
-有对应权限的玩家伤害翻对应的倍数,.
-设置伤害组,拥有对应组权限的人伤害翻指定倍数.(0-N);
-有对应组权限的玩家登陆欢迎信息（每组可单独设置).
-无限的组,你可以自定义N个组
-游戏内一键查看所有分组信息.
-2种伤害结算模式,mode1与mode2
-优化的算法,不过多遍历检查用户权限,减轻数据库压力.
-便捷的命令,让您极快上手使用!
-命令全条件覆盖,完美指引提示您的任意一步命令错误.
-2个版本,linux与windows.

权限
-vipdamage.组名      对应组权限,拥有该权限即可享受该组伤害翻倍.
-vipdamage.admin    管理权限。所有命令使用权限


命令
-/vd addgroup 组名 伤害倍数 登陆信息..
-/vd list  查看所有组
-/vd mode 1|2  选择模式1或模式2
/vd reload  重载插件
#模式1为默认模式,直接修改伤害值
#如果模式1无效,请修改模式2.模式2强制造成伤害.可能与其他保护插件不兼容!

安装方式:
1>下载对应您服务器系统的版本
2>把插件放到plugin目录里,开服,关服.
3> 进游戏，使用命令添加新的组.
范例:/vd addgroup vip1 1.5 "&b欢迎加入我的服务器!您攻击倍数为1.5倍！"
这样拥有vipdamage.vip1权限的玩家
->登陆就会看到"欢迎加入我的服务器!您攻击倍数为1.5倍！"
->攻击享受1.5倍加成

并给予对应玩家/对应权限组权限.
例: 给所有玩家vip1翻倍的权限
gm : /mangaddp builder add vipdamage.vip1
pex : /pex group default add vipdamage.vip1

4> 完工！
