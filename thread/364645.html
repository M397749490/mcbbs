懂了，就是一个 TAG_Compound NBT。

用法很简单，应该就是~~~~~~~为了我还能继续讲已经屏蔽~~~~~~~~
不需要加入Slot，因为游戏会自动探测。

官方解释
Contains the item data of the item currently held in the player's hand

玩家正在拿着一个包含该物品数据的物品
Added to compact the process of testing if a player is holding a specific item

将使测试玩家手持一个特定的物品的过程更简单
Previous method required nine commands in command blocks; now requires only one command

以前的方法需要九个在命令方块里的命令；现在只需要一个命令（请无视翻译）

功能与优缺点
功能：探测玩家手持物品
优点：一个命令就相当于九个testfor @a {SelectedItemSlot:格子,Inventory:[{id:物品,Slot:物品所在储存格b,Count:数量b,,Damage:附加值s,tag:{---}}]}
缺点：只能探测手持物品，无法智能感应- -，无法探测选中格子更正：可以探测物品所在储存格
储存格号码

主要用法：
testfor探测玩家手持物品基本格式
  1. testfor @a {SelectedItem:{id:方块ID(格式minecraft:---),Slot:物品所在储存格(数字后要加b),Damage:附加值(数字后要加s),Count:数量(数字后要加b),tag:{---}}}
复制代码
实例：探测所有玩家中手持石头的
  1. testfor @a {SelectedItem:{id:minecraft:stone}}
复制代码


探测叫test的玩家是否手持5个石头
  1. testfor @a[name=test] {SelectedItem:{id:minecraft:stone,Count:5b}}
复制代码
探测5格内是否有记分板Test分数最小为5的玩家手持1个名字叫Test，说明为Test的石头
  1. testfor @a[r=5,score_Test_min=5] {SelectedItem:{id:minecraft:stone,Count:1b,tag:{display:{Name:"Test",Lore:["Test"]}}}}
复制代码
探测玩家手持书本，内容为Test
图片：
  1. testfor @a {SelectedItem:{id:minecraft:written_book,tag:{pages:["Test"]}}}
复制代码
