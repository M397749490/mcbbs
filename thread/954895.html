Season Lite

轻量级的季节插件



插件付费版本: Season Pro






A




插件介绍

Plugin Introduction

这个插件加入了春夏秋冬四个季节，并引入了大量有趣的机制。

让你的Minecraft服务器更加出色与真实！


B




插件特性

Plugin Features

- AFK System 挂机系统

- Bathing System 游泳系统

- Calendar System 日历系统

- Live Updating 活跃更新(指此插件)

- Pulse System 脉搏系统

- Real Breathing System 真实呼吸系统

- Sound System 声音系统

- Temperature System 温度系统

- Weather System 天气系统

温度过高/过低的提醒

脉搏过高的提醒

冬天在水里游泳的提醒

玩家加入服务器提醒日期和季节、第二天来临时的提醒

会改变生物群系以配合冬天下雪的特性(Config内可设置)


- 挂机 -


挂机系统每 1000 游戏刻 (=20秒)会检测玩家是否没有移动(处于挂机状态)，若有则会请出玩家


- 温度与脉搏 -


跑步会快速提升你的温度与脉搏

在冬天，温度的提升速度会变慢，脉搏提升速度会变快


原地挂机也会降低你的温度和脉搏

在冬天温度降低的下限会变低


走路与原地站着一样，也会降低你的脉搏

同样，冬天也会加快脉搏降低的速度


玩家的理想温度是介于32-38度之间

过高(高于41.9度)或过低(低于25度)都会导致玩家的死亡

理想脉搏同上(真的可以这么放松吗)

同样，过高(高于160)或过低(低于20)也会导致玩家死亡。


- 淋浴系统 -

冬天游泳会以每2000游戏刻(=40秒)-0.5度的速度减少体温，其他季节不会

每一个小时你必须至少洗一次澡，超过3小时不洗澡你会变臭(不是张口闭眼的那种臭)

这个机制通过检测玩家附近的方块来运行，可能会造成卡顿(未来会改进)


- 脉搏系统 -

除冬天外脉搏高于120都会使你气喘吁吁

但在冬天超过120你的呼吸速度会x2


- 日历系统 -

仿照群峦的日历机制，每一个月都和真实世界的12个月对应


- 声音系统 -

每一个季节都有它独特的声音！

例如在冬天你能听到风声

声音发出的频率是完全随机的，因此你几乎随时都可以听到它们


- 季节系统 -

插件被分为春夏秋冬四季，其中春夏固定三个月

秋季和冬季时长取决于秋末是否下雨

若秋末不下雨，则有80%的几率入冬

此项功能将会在未来改进


此插件暂时不支持多世界

未来将会加入衣服的保温系统

生病系统以及药物系统、更多的食物系统

背包盔甲等的重量系统


C




插件安装

Plugin Install

把它像一般插件一样丢进服务器

并且让它吐出(误)生成Config.yml

在Config里面找到这一行:

main-world: 'world'

将'world'内英文改成你想要使此插件生效的主世界(季节时钟标准的世界)

插件指令与权限
Plugin Command and Permission

/seasonlite 显示插件信息
seasonlite.bypass - (OP默认)拥有此权限将不会受到上述机制的影响
seasonlite.getpulse - 允许显示脉搏的权限
seasonlite.gettempurature - 允许显示温度的权限

插件变量
Plugin Placeholders
- %seasonslite_temperature% - 返回玩家的温度值 -
- %seasonslite_pulse% - 返回玩家的脉搏值 -
- %seasonslite_day% - 返回当前日期 -
- %seasonslite_month% - 返回当前月份 -
- %seasonslite_year% - 返回当前年份 -
