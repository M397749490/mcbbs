作者: 1962853568    时间: 2016-8-3 01:01
/mv import  plotworld normal
这个可以回复你破烂的地皮世界
如果你不满意  使用下面俩个指令
/mv delete  plotworld  
这个可以删除你的地皮世界

/mv create plotworld normal -g PlotMe
这个可以再次生成你的地皮世界

你要先去你的服务器目录，找到你原来的plotworld世界
