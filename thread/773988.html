介绍

　　DungeonsXL是一款支持免排队的竞技场，它用处不仅仅限于RPG冒险的使用
　　它还可以用于组队加入PVE竞技场、游戏竞技场等
　　还提供了自定义游戏机制，让竞技场更有趣
　　免排队是利用多世界互不干扰相同场景的副本，当然不一定免排队（可以设置一个副本最多产生世界）

特征

  • 创建更多副本
  • 允许玩家同一队在一个副本
  • 允许玩家同时使用一个副本（免排队）
  • 自动删除地图文件（副本依然存在）
  • 可邀请玩家加入编辑副本模式
  • 在编辑模式下设置检查点、触发点、破坏块、消息等
  • 独立副本配置
  • 玩家可以使用自己物品或副本的物品（共库/独库）
  • 门户传送门
  • PVP
  • 时间限制
  • 支持怪物（自带怪物系统/Mythicmobs）
  • 生物波
  • 强大API
  • 异步加载世界创建世界
  • 副本资源包
  • 还有更多...

兼容性
版本

　　DungeonsXL适用于1.7.8及以上版本服务端
　　由于Spigot API，所以优先对1.9.X/1.10.X/1.11.X服务端支持
　　如果你使用低于1.9版本，那么有些特征用不到的
　　因此建议用于1.9及以上版本服务端
　　请用于Spigot服务端不支持在CraftBukkit服务端使用

　　不想看废话的请看这里
　　要求
  • Java7及以上
  • Spigot服务端（不能在CraftBukkit服务端使用）
  • 1.9及以上版本服务端
  • 可选兼容插件请继续看帖子

支持

  • CommandsXL   高级命令执行插件
  • Citizens   自定义公民NPC插件
  • MythicMobs   自定义生物插件
  • InsaneMobs   另类自定义生物插件
  • ItemsXL   自定义物品和生物
  • 任何支持Vault的权限插件
  • 任何支持Vault的经济插件

不兼容

　　不兼容插件
  • Towny
  • Corpses

　　如果你实在需要
  • 请使用PerWorldPlugins（用于1.8+）
  • 将不兼容插件用于需要使用的世界，不要与DungeonsXL插件的世界冲突

常见问题
  • [ExternalMob]标志失效了怎么办？
由于最新版本更新了，[ExternalMob]与[Mob]合并了
请用[Mob]代之

  • 玩家进入副本库存不同步怎么办？
请在插件文件的config.yml的底部
改为/添加
default:
  keepInventoryOnEnter: true

  • 如何设置击杀mythicmobs怪物指定数量就结束副本？
在副本放置牌子
第一行：[end]
第二行：空
第三行：空
第四行：M xxx

xxx为Mythicmobs怪物ID
数量还没确定，正在问作者

  • 如何设置离开副本后保留库存物品？
请在插件文件的config.yml的底部
改为/添加
default:
  #完成副本后是否保留
  keepInventoryOnFinish: true
  #中途离开副本后是否保留
  keepInventoryOnEscape: true
