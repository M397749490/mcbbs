所谓“水上漂”，自然是要漂浮在水面上。（废话）
那么既然要漂浮在水上，就可以用飘浮的状态效果来让自己“飘”起来：
  1. effect @p minecraft:levitation 1 255
复制代码

255倍率也就是256等级，会被识别为0级，就能让玩家悬挂在那儿。

然后，我们要选择水上的玩家。于是得出命令：
  1. execute as @a at @s if block ~ ~-0.5 ~ minecraft:water if block ~ ~ ~ minecraft:air run effect @p minecraft:levitation 1 255
复制代码

当然要放在保持开启的循环命令方块里执行。
