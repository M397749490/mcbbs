怎么能关闭伤害了
作者: Sakura小樱花    时间: 2014-10-23 21:22
更改领地权限
如果你是OP
直接使用
/resadmin create 领地名 即可无花费不受限制创建领地
设置禁止PVP即可取消伤害
/res set 领地名 pvp false
如果是OP权限
/resadmin set 领地名 heal true
可以使进入领地的人自动治疗
