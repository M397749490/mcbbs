MOD介绍
此MOD很简单，就是当你死亡后不会马上进入重生和进入标题界面的菜单里面，而是提供一个濒临死亡状态，等待同伴的救援。
类似吃鸡里面拉队友复活。具体的救援时间和距离都可以配置，并且濒临死亡状态的玩家会有一个发光状态，特别适合PVP服务器。

MOD兼容附属（本MOD可独立使用）
这款MOD兼容其他两个MOD，在此贴里一并介绍，因为跟本MOD的配置有关。
TEAM UP MOD
Team up站内帖（更新到1.10.2）原贴 1.10-1.12
这个MOD结合就是死亡后还可以使用队伍频道
指令：
/teamup CreateTeam "队名"创建一个队
/teamup SetColor "颜色英文名"
设置队的颜色
/teamup AddPlayer "玩家名"
添加一个成员
/teamup RemovePlayer "玩家名"
删除一个成员
/teamup LeaveTeam "队名"
离开一个队
/teamup DeleteTeam "队名"
删除一个队
这是一款建立组队的MOD，组队后可以分组聊天，不会发送到队外公屏。
这款MOD原搬运者说没有玩家没有权限使用指令，我没有具体测试过，我也没有找到关于权限节点和配置文件中可以调节的地方。
有兴趣的话可以帮我测试下以下权限节点
-teamup.createteam
-teamup.setcolor
-teamup.addplayer
-teamup.removeplayer
-teamup.leaveteam
-teamup.deleteteam
-teamup.*
还有一个办法，就是用ChestCommands插件，给与一些OP指令使用的按钮。
COMMAND: 'op: teamup CreateTeam 1
建立1队，因为Chestcommands无法个性化后面的队名，只能这样了。
PING MOD
Ping原贴链接 （1.12-1.14）  这个是发送信息的MOD 就是把一个方块高亮显示，用红色效果框起来
然后发送给身边的玩家，比如挖到一个钻石，打开菜单（默认V键）选择看，
基友就会看到：哇，好大一块钻石。

  3. general {
  4.     # 如果设置为true，濒临死亡的玩家会发光，通过积木可以看到他们。
  5.     B:"Glow on Death"=true

  7.     # 玩家仍然可以从濒临死亡中获救的时间。20Ticks=1秒。
  8.     I:"Max Death Ticks"=2400

  13.     # 这会在死亡屏幕上添加一个“发送Ping”按钮。
  14.     B:"Ping Compatibility"=true

  16.     # 救援基佬所需的时间。20Ticks=1秒。
  17.     I:"Rescue Ticks"=40

  19.     # 需要启用Ping兼容性。 你死后自动发送ping。
  20.     B:"Send Ping on Death"=true

  22.     # 这使得Team Up的聊天功能也可以在死亡屏幕上运行。
  23.     B:"Team Up Compatibility"=true
  24. }
