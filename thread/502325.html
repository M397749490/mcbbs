MineDoor
Java 编写的一个配置简单、运行高效的 Minecraft: Pocket Edition 玩家分发(入口)服务器
适用于各种类型的分布式小游戏服务器、生存服务器等
一贯的使用 GPL 协议，代码开源并由 Github 托管


MineDoor 是什么？
在 2012年的时候，一个 MinecraftPE 服务器能同时在线 40 个玩家就已经算是很大的服务器了。现在的 MinecraftPE 服务器所承载的玩家数量已经远远多于以前，70 人、100 人同时在线已经是家常便饭，甚至上千人同时在线在大型的服务器上也是很常见的，比如今天早上我起来的时候就看到 LifeBoat 有 7897 人在线，而这么大的用户量如果全部堆在一个服务端上，肯定是承受不住的。所以现在一般的大型服务器都会采用分布式服务器，将玩家分流到各个子服务器上，并以一定的算法平衡各个服务端的负载量。在这套系统内，玩家首先会连接到入口服务器，然后由该服务器经过计算将用户转发到最适合的一个节点服务器上。MineDoor 就是这样一个作为入口的服务器，内置一套使各个节点服务器负载均匀的算法，通过获取各个节点的负载量、延迟等，计算出最适合的服务器节点。


配置 MineDoor
要使用 MineDoor，请先安装 Java Runtime Environment (JRE) 及 Maven 工具，二进制可执行文件及安装包可以在 Java 官网: java.com，Maven 下载

若要编译并安装安装 MineDoor，在 Bash Shell 中使用命令
  1. curl https://raw.githubusercontent.com/SuperMarcus/MineDoor/master/build.sh | bash
复制代码
或者可以前往 Github 下载已经编译完成的二进制文件: https://github.com/SuperMarcus/MineDoor/releases
安装完成后，根据提示使用命令运行服务器
  1. ./start.sh
复制代码
MineDoor 是 CLI 接口的 Java 应用，故在运行中不会有任何窗口弹出
第一次启动服务器之后，运行目录下会生成两个文件("server.properties", "servers.txt") 请对其进行配置。
添加节点服务器请按格式追加到"servers.txt"内:
  1. 地址:端口
复制代码
如: play.lbsg.net:19132
