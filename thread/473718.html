作者: 枫色天国    时间: 2015-7-23 18:50
这个MOD只有假矿了
还有另外一个方法就是人防
用ESS开启方块破坏提醒
  1.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  2.   # 你加载了一次Essentials后,就可以在plugins/Essentials/items.csv中找到物品ID列表.
  3.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  4.   alert:
  5.     on-placement:  #放置该ID物品
  6.     on-use: 327   #使用该ID物品
  7.     on-break: 56,129  #破坏该ID物品 56就是钻石矿 129就是绿宝石矿
复制代码


在服务器里面选择几个信任的玩家给予接收破坏消息的权限节点
当又玩家频繁出现监控ID方块的破坏时记录下了查水表

接收消息权限节点是
essentials.protect.alerts
