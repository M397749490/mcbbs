极限附魔插件EnchantExtreme
是一个可以自定义附魔效果、附魔等级、物品名称、物品描述的插件

  1. 指令：
  2. # 列出附魔列表
  3. /eex list
  4. # 附魔别名列表
  5. /eex alias
  6. # 帮助菜单
  7. /eex help
  8. # 给指定玩家一个附魔物品.
  9. /eex give <玩家> <物品ID> <附魔名称> <附魔等级>
  10. # 给指定玩家一个自命名的附魔物品.
  11. /eex give <玩家> <物品ID> <附魔名称> <附魔等级> <新名称>
  12. # 添加一个附魔物品到你背包中.
  13. /eex <物品ID> <附魔名称> <附魔等级>
  14. # 添加一个自命名的附魔物品到你背包中.
  15. /eex <物品ID> <附魔名称> <附魔等级> <新名称>
  16. # 为手中物品增加附魔.
  17. /eex hand <附魔名称> <附魔等级>
  18. # 为手中物品增加附魔并重命名.
  19. /eex hand <附魔名称> <附魔等级> <新名称>
  20. # 为手中物品重命名.
  21. /setname <新名称>
  22. # 为手中物品写入描述文字
  23. /setlore <描述文字>
  24. # 查看手中物品ID.
  25. /itemid
复制代码
  1. 权限：

  3. enchantextreme.eex
  4. enchantextreme.setname
  5. enchantextreme.setlore
  6. enchantextreme.itemid

  4. maxLevel: 200
