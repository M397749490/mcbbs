你是安装了iconomy插件吧？ 就是金钱插件 你打开iconomy的config（就是设定文件）
  1. System:
  2.     Default:
  3.         Currency:
  4.             Major: [ 'Dollar', 'Dollars' ]   <--把dollars删了改成你想要的，下面也一样             # Major ([Major].Minor) 1.00 Dollar (With Seperate 1 Dollar)
  5.             Minor: [ 'Coin', 'Coins' ]       《--这个也是不过是几分             # Minor (Major.[Minor]) 0.23 Coins  (With Seperate 0 Dollars, 23 Coins)
  6.         Account:
  7.             Holdings: 30.0                            # Default holdings on hand upon join / creation.
  8.         Bank:
  9.             Name: iConomy                             # Default Bank Name
  10.             Currency:
  11.                 Major: [ 'Dollar', 'Dollars' ]
  12.                 Minor: [ 'Coin', 'Coins' ]
