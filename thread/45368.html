首先1. 不能挖应该是ESS禁掉了挖矿机 具体解除方法打开ESS的配置文件config 找到placement 和usage 一项 后面的数字就是禁掉的物品id 找到并去掉你需要的就行了 顺便上面的on—placement 和on-use 也去掉
2.装了这个？ 你说的应该是权限插件吧 如果不擅长写权限插件 删掉EssentialsGroupManager 插件
3.友军伤害 你就是想pvp呗 打开服务器文件夹找到server(PRORERTIES格式的)找到pvp=  等号后面填true就是打开false就是关闭 TNT禁掉方法跟问题1我回答的一样 同理 加上tnt的id就是禁掉了

作者: strawmaine    时间: 2012-8-20 13:44
1. 参考http://www.mcbbs.net/thread-34587-1-1.html 命令是在服务端命令提示符窗口打的

2. 你可以选择学习权限插件配置方法，或者直接删了它。EssentialsGroupManager.jar和EssentialsGroupBridge.jar

3. essentials的config.yml里有这一段配置：
  1. # Users with the essentials.protect.pvp permission will still be able to attack each other if this is set to true.
  2.     # They will be unable to attack users without that same permission node.
  3.     pvp: false               false改为true就可以开启友军伤害
复制代码
另外请在服务端的server.properties里保证pvp=true

essentials的config.yml里还有这一段配置是禁用物品的：
  1. blacklist:

  3.     # Which blocks should people be prevented from placing
  4.     placement: 10,11,46,327                       46就是TNT，默认这种配置下禁用放置TNT

  6.     # Which items should people be prevented from using
  7.     usage: 327

  9.     # Which blocks should people be prevented from breaking
  10.     break:

  12.     # Which blocks should not be pushed by pistons
  13.     piston:
