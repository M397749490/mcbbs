作者: 秋风残叶    时间: 2017-6-4 10:42
您把领地组和权限组的概念搞混了 default是默认的领地组
/res gset是针对领地组的指令
您可以打开领地文件夹的groups.yml，在这个文件夹里你可以创建，修改领地组的相关属性
比如您新建了一个叫test的领地组，给玩家residence.group.test 就可以让玩家进入这个领地组
如果还有不懂的地方欢迎追问，希望对您有所帮助

首先您得在配置文件groups.yml中创建新的领地组才可以，例如我新建一个领地组test
我举个例子吧，把这些内容复制进groups.yml
  1.     test:
  2.        Residence:
  3.            # 这个组可以创建领地？
  4.            CanCreate: true
  5.            # 这个组的最大领地数量
  6.            MaxResidences: 4
  7.            # 这个组领地内最大区域数量
  8.            MaxAreasPerResidence: 2
  9.            # 最大领地长 宽 高
  10.            MaxEastWest: 100
  11.            MaxNorthSouth: 100
  12.            MaxUpDown: 256
  13.            # 创建领地最小 最大高度
  14.            MinHeight: 0
  15.            MaxHeight: 255
  16.            # 子区域深度
  17.            SubzoneDepth: 3
  18.            # 可以传送至该领地
  19.            CanTeleport: true
  20.            # 可以踢出领地
  21.            Unstuck: true
  22.            Kick: true
  23.            SelectCommandAccess: true
  24.            ItemListAccess: true
  25.        # 这个组的领地提示语
  26.        Messaging:
  27.            CanChange: true
  28.            DefaultEnter: 欢迎玩家 %player 来到领地 %residence, 该领地拥有者是 %owner.
  29.            DefaultLeave: 您离开了领地 %residence.
  30.        Lease:
  31.           MaxDays: 16
  32.           RenewIncrement: 14
  33.        Rent:
  34.            MaxRents: 3
  35.            MaxRentables: 3
  36.            MaxRentDays: 31
  37.        Economy:
  38.           CanBuy: true
  39.           CanSell: false
  40.           IgnoreLimits: false
  41.           BuyCost: 0.7
  42.           SellCost: 0.3
  43.           RenewCost: 0.3
复制代码
