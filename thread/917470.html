KickIdlePlayers

踢出服务器人多/卡顿时还在挂机的玩家吧



前言:

服务器本来配置并不好，因此人多时就会卡顿，此时一些挂机的玩家会白白浪费服务器珍贵的资源，因此我做了这个插件来将他们踢掉。



功能:

  • 踢出前玩家必须进入Essentials的AFK模式XX时长
  • 服务器TPS必须低于XX.XX
  • 人数必须多于XX
这样就可以达到在服务器不卡顿或者人少时，保留挂机的玩家，既不影响玩家自己挂机，还可以在线人数+1而同时在服务器卡顿时将这些玩家移除，将珍贵的资源留给更加活跃的玩家。


默认配置文件:
  1. #More than [players] players, plugin will start kick the player
  2. players: 8
  3. #PLayer must afk more than [max-idle-time] secs, and him will can get kick
  4. max-idle-time: 3600
  5. #The server must low than this value and plugin will start kick player
  6. kick-tps: 18.50
  7. #The message for kick player
  8. kick-message: "&c您由于1小时没有活动且当前服务器繁忙，为了减轻服务器负载，您已被从服务器中移出"
