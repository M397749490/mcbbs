                                       AboutTea                        

提醒：此mod还处于一个早期版本，甚至材质都没加全，bug必然很多，有bug可以提交到github的issues

这是TeaCon作品之一，在丛林中找到茶树，开始制茶的冒险
感谢 @浊酒散人lsg.  为我做美工，十分感谢


目前没有什么合成，不过支持整合包自己添加物品

整合包相关：

支持CraftTweaker

  2. addDryRecipe(IItemStack input,IItemStack output,int time)//添加干燥器配方
  3. removeDryRecipe(IItemStack output)//移除干燥器配方
  4. addMixRecipe(IIngredient[] input, IItemStack output, int time)//添加混合器配方
  5. removeMixRecipe(IItemStack output)//移除混合器配方
  6. addTeaStoneWorkstationRecipe(IIngredient[][] inputs, IItemStack output, int tick)//添加茶叶石工作台配方
  7. removeTeaStoneWorkstationRecipe(IItemStack output)//移除茶叶石工作台配方
复制代码
支持自行添加茶叶
在teas文件夹下teas.json

例子
  1. {
  2.   "test_tea": { //名字
  3.     "tier": 1, //等级
  4.     "color": 1100730, //颜色 16进制颜色代码转10进制
  5.     "effects": { //效果，可以有多个
  6.       "minecraft:speed": { //效果名
  7.         "duration": 300, //时间，单位tick
  8.         "amplifier": 2 //等级
  9.       }
  10.     }
  11.   }
复制代码
zh_cn.json可以添加茶叶语言文件
具体格式

  2. {
  3.   "item.abouttea.golden_tea": "黄金茶叶" //翻译key: 内容
  4. }
复制代码


关于茶杯使用：
需要将茶杯与茶叶合成，可获得装了茶叶的茶杯
然后需要右键水，即可装满水
右键即可饮用（冷泡茶）
