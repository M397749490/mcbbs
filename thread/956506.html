[管理|安全]SkyPerms轻巧的权限插件

为什么选择SkyPerms?
当我刚开始学习Java和Spigot API时,我决定了我的最终目标将是我自己的权限插件.
一个基本的权限管理系统只需大约十分钟即可实现,也许只需二十行代码.
当然,一个完美的插件还不止于此,但是它比我预期的简单得多.
SkyPerms是在一个7天内完成的[Universe花费了大约一个半月的时间]
太好了,但是SkyPerms是什么?我为什么要使用它?
SkyPerms是一个轻量级的权限插件
但是,很多权限插件的不同之处在于,它不依赖Vault,并且可以更改名称标签.
没错,玩家的排名将显示在聊天中,标签列表中以及他们的游戏头上.当然,此功能并不适合所有人,因此可以将其禁用.
让我们深入研究一下.
权限管理
就像其他权限插件一样,SkyPerms有Permissions.yml文件
您无需了解一些古怪的设置
插件首次加载时,它将向文件中吐出一个可爱的默认组(ps:作者好可爱啊awa)
以便快速了解权限组的格式.该文件还将包含一个标有user的部分.
UUID列出的是服务器上的所有玩家
一行显示玩家的等级
另一行显示玩家的姓名
命令
/wp
主命令.这将显示帮助菜单.
/wp group <name> <add:remove> <permission>
使用此命令可从指定组添加或删除权限.请注意,每次执行该命令仅适用于一个权限.(尽管如此,我确实计划允许同时执行多个权限).
/wp group <name> prefix <prefix>
使用此命令可在任何地方更改组的前缀.
/wp group <name> create
这将创建一个新的组.
/wp group <name> delete
这将删除一个组..该组中的所有成员都将加入您标记为默认组的任何组.
/wp user <name> <add:remove> <permission>
这将使您可以添加或删除特定用户的权限.
/wp user <name> set <group>
将玩家分配到一个组.
/sp user <name> prefix <prefix>
这将使您可以为用户提供前缀.要删除前缀,请运行此命令并为用户分配* clear(带有星号的是),它将清除它.只是为了使这些内容更明显
/sp user <name> prefix *clear
这将删除用户的前缀.
/sp reload
如果您对文件进行了更改,请运行此命令,所有内容(包括配置)都将被重新加载,刷新和应用.
