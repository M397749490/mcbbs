[ a=物品ID 93=闪电ID ] PS：闪电也属于实体
function useItem(x,y,z,a){
if(a==1){
Level.spawnMob(x,y,z,93);
}
}上面整段是当用id为1物品点击方块（useItem）时生成闪电（Level.spawnMob(x,y,z,93);）
