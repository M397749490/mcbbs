What is textparticle?
This is a very small, good coded skript. This skript allows you to create "Text Particles"
什么是粒子文本？
这是一个小巧但是很好用的脚本！它允许你创建 “文字特效”
——————————————————————————————
Command[指令] | Perms [权限]:

- /ptext [ptext.admin]
- /pstopall [ptext.stopall]
- /premove [ptext.remove]
- /plist [ptext.list]

Particle Effects[支持的粒子]:

- Flame
- Snow
- Lava
- Crit
- Bubble
- Redstone

How to create or reomve a particle[怎么玩]?
/ptext flame 1 Text
在你所在的位置创建一个文本
"Flame" 是上方支持的粒子特效之一
"1"就是这个文本的ID就像全息显示一样
"Test"就是创建出来所显示的文本
/premove 1
移除ID为1的文本

Needed Plugins[需要的前置插件]:
需注意本插件问sk脚本下载后放入Skiript的配置文件中！
SkQuery: http://dev.bukkit.org/bukkit-plugins/skquery/
Skript: http://dev.bukkit.org/bukkit-plugins/skript/
SkRayFal: http://dev.bukkit.org/bukkit-plugins/skrayfall/
