前提概要:
本插件需要Skript 和 SkRayFall做前置
如果不考虑加Skript 请直接关闭该页即可

插件介绍:
站内很多签到是基于24H冷却来做的签到系统
导致实际上基本需要3天才能签到2次 完全不合理而本插件根据玩家签到日进行判断
你现在可以第一天23:59签到后第二天0:00进行第二次签到
制作这个插件共修改了4次 基本上没有BUG的存在
现在将该插件分享给大家

插件代码详解:(核心)
        set {_i1} to "%now%"
#读取当前时间 并将 时间这个变量 赋予 {_i1}
        set {_i2::*} to {_i1} split by " "
#PS:这里详细说一下
#%now% 这个变量的格式是 xx-xx-xx ...(省略后面)
#split by这个语法 将会吧 {_i1} 用 " " 分成 xx-xx-xx 和 ... 两个部#并赋值给 {_i2::*} 变量组
#{_i2::*} 是一个变量组(学过编程的就是数组)
#其中 {_i2::1} 为 xx-xx-xx , {_i2::2} 为 ...
        set {_i3::*} to {_i2::1} split by "-"
#相同 split by这个语法 将会把 {_i2::1} 用字符 "-" 分成 xx 和 xx 和 xx 三个部分
#并存储于 {_i3::*} 变量组中
#其中 {_i3::1} 为第一个xx(年) {_i3::2} 为第二个xx(月) {_i3::3} 为第三个xx(日)
        set {_m} to {_i3::2} parsed as integer
#将 {_i3::2} (月) 赋值给 {_m}
        set {_d} to {_i3::3} parsed as integer
#将 {_i3::3} (月) 赋值给 {_d}
