看来你并没看懂，你需要设置分世界权限，但是继承同一个用户配置文件。然后可以单独设置不同世界不同权限。
作者: 水煮清娃    时间: 2017-5-16 21:19
给你举个例子，找到权限组的配置文件config.yml
mirrors:
        # 多世界设置,世界列表中子世界将参照父世界的设置.
        # 第一个世界 'world' 是主世界名称
        # 子世界 'world_nether' 和 'world_the_end' 将会
        # 与父世界使用相同的玩家/用户组文件.
        # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
        # all_unnamed_worlds将会使用所有未定义的世界
        world:
          all_unnamed_worlds:
          - users
          - groups
          tg:
          - users
          zy:
          - users   
          world_nether:
          - users
          world_the_end:
          - users
然后在worlds会生产独立的五个权限文件夹，对应不同的世界，你只要在你需要设置特别权限的那个文件夹里修改配置文件即可，不影响其它的世界，由于用的是一样的用户配置users.yml，所以设置好全部权限之后不影响会员之类的权限
