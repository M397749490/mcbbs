这样看起来美观一点。
其实像 javascript 那种把参数写成 object, 这样参数名和value都写在脸上的, 如果你用 IDEA 的话也能做到, 它会在每个参数前面显示一个角标, 说明这个参数对应方法中的哪个变量名.
如果想要易用性的话可以试试这个:

String item_name = "abc";
int amount = 12;
String display_name = ((something)? "a":"b");
boolean breakable = true;
do_something( item_name, amount, display_name, breakable );
