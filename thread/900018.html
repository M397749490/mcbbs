eGlow —— 五光十色的发光效果~

授权证明

特点
  • 五光十色的发光轮廓,氪金点+1
  • 艳丽红,中国红,闪耀金,疑车无据黄,原谅绿,资深原谅绿,碧霄蓝,苍穹蓝,紫罗兰,少女粉,纯净白,深空灰,深邃灰,神秘黑等16种颜色任君选择
  • 什么? 还可以闪烁? 还可以彩虹? 还可以调节速度? (慢/快）
  • 支持MySQL的喔~
  • 还支持PAPI的哦~
  • Tab列表玩家名的基本自定义~(玩家名的颜色是目前的发光颜色什么的...)（要Vault）
  • 世界黑名单~ 不准在起床战争里给别队作弊!
  • 自定义慢/快延迟哒!
  • (正在开发) 自定义效果~ 你是天边独一无二的云彩
  • ……

命令&权限
给玩家的命令&权限:
  • /eGlow (eglow.gui) - 打开GUI
  • /eGlow help (eglow.help) - 查阅帮助
  • /eGlow list (eglow.list) - 查看所有颜色&效果
  • /eGlow toggle (eglow.toggle) - 开关颜色或效果
  • eglow.glow - 你在有下面的颜色权限的情况下可以发光了,但是没有颜色权限还是不行
  • /eGlow <颜色> - 让自己发光
  • /eGlow <效果> <fast(快)/slow(慢)> - 给自己点效果
  • /eGlow <颜色> blink <fast(快)/slow(慢)> - 让自己闪烁起来,bling bling起来
  • eglow.user.* - 所有用户权限（仍需要颜色权限）

给管理的命令&权限:
  • /eGlow set <玩家> <颜色> (eglow.glow.others) - 给别的玩家点颜色看看
  • /eGlow set <玩家> <颜色> <blink> <fast(快)/slow(慢)> (eglow.glow.others) 给别的玩家点闪烁看看
  • /eGlow set <玩家> <效果> <fast(快)/slow(慢)> (eglow.glow.others) 给别的玩家点效果看看
  • /eGlow reload (eglow.reload) - 重载配置文件
  • eglow.* - 尽情搞事的权限

颜色权限: (闪烁效果需要两个权限:eglow.<颜色>和eglow.<颜色>.blink)
  • eglow.red(.blink) - 艳丽红(闪烁)
  • eglow.darkred(.blink) - 中国红(闪烁)
  • eglow.gold(.blink) - 闪耀金(闪烁)
  • eglow.yellow(.blink) - 疑车无据黄(闪烁)
  • eglow.green(.blink) - 原谅绿(闪烁)
  • eglow.darkgreen(.blink) - 资深原谅绿(闪烁)
  • eglow.aqua(.blink) - 碧霄蓝(闪烁)
  • eglow.darkaqua(.blink) - 苍穹蓝(闪烁)
  • eglow.blue(.blink) - 红色(闪烁)
  • eglow.darkblue(.blink) - 红色(闪烁)
  • eglow.purple(.blink) - 紫罗兰(闪烁)
  • eglow.pink(.blink) - 少女粉(闪烁)
  • eglow.white(.blink) - 纯净白(闪烁)
  • eglow.gray(.blink) - 深空灰(闪烁)
  • eglow.darkgray(.blink) - 深邃灰(闪烁)
  • eglow.black(.blink) - 神秘黑(闪烁)
  • eglow.rainbow - 彩虹效果
  • eglow.blink - 所有颜色的闪烁效果
  • eglow.color.* - 所有颜色(包括闪烁)的权限
