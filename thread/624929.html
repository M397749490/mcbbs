非常简单，ScriptBlock插件
这插件有个功能，就是限制特定的权限组才能使用被绑定的方块执行命令
@group:group    当脚本只想到此条时,就会触发他检查玩家是不是他所限定的用户组,如果不是的话就没有权限往后运行了。    例子:/sbinteract create [@group:default][@bypass /manuadd  builder]    这个脚本运行时会检索玩家是否为default组成员,如果是的话就可以进入builder组,也就是说,当他运行此脚本之后就不能再运    行第二次了,因为他已经不是default组的成员了。


举个栗子：只有VIP组才能去名为"1"的领地，那么我们这样设置命令：
/sbinteract create [@group:VIP][@bypass /res tp 1]  即可 【注意：领地是谁都可以过去的，建议用坐标tp过去】


再举个栗子：只有VIP组的玩家才能去- x:123 y:45 Z:789 这个坐标那么指令就会如下所示:
/sbinteract create [@group:VIP][@bypass /tp <player> 123 45 789]


注意，在坐标周围圈地，以免被熊，然后输入/res set tp false 即可
