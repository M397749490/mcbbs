插件介绍
这是一款需要使用金币来解锁的仓库插件，可分成个人仓库和共享仓库2种。
个人仓库：玩家可以消费金币解锁个人仓库，在解锁仓库的容量，也可以通过输入快捷指令打开该仓库。玩家也可以通过指令修改指定仓库的名字。未来版本将会支持修改指定仓库的物品材质。
共享仓库：玩家可以消费金币解锁共享仓库，在解锁仓库的容量，该玩家可以通过指令邀请其他玩家和自己共同使用同一个仓库。

插件指令
/whp openp [玩家] >> 打开某个玩家的仓库（OP查水表专用权限）/whp open >> 打开仓库
/whp open [id] >> 打开指定仓库
/whp accept >> 查看当前对自己的所有邀请
/whp accept [name] >> 接受某个邀请
/whp rename [id] [name] >> 修改某个仓库的名字
/whp coop [name] >> 创建一个名为name的共享仓库
/whp with [name] [player] >> 发送共享请求给某人
/whp without [name] >> 将某个仓库从自己的列表中移除
/whp without [name] [player] >> 将某人从共享仓库中移除
