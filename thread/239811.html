[p=256, null, left][size=256px]成绩下降检讨书


[p=169, null, left][size=169px]尊敬的老师们：


[p=169, null, left][size=169px]您们好！现在我怀着愧疚的心情

[p=169, null, left],

[p=169, null, left][size=169px]写下这份检查

[p=169, null, left].

[p=169, null, left][size=169px]以向您表示我的决心和悔改之意，只希

[p=169, null, left][size=169px]望老师能够给我一个改正错误的机会。


[p=169, null, left][size=169px]以前我没有意识到自己的散漫和无知，上课总是不认真听讲

[p=169, null, left],

[p=169, null, left][size=169px]导致我成绩下降。


[p=169, null, left][size=169px]我认为，这成绩下降还有两个大的原因。


[p=169, null, left][size=169px]一是学习不用功。

[p=169, null, left][size=169px]这么说有些笼统，

[p=169, null, left][size=169px]其实它可以分为很多小原因。

[p=169, null, left][size=169px]也许您知道也许您不

[p=169, null, left][size=169px]知道。

[p=169, null, left][size=169px]前段时间不是因为月考成绩看得过去有所松懈，

[p=169, null, left][size=169px]而是一直就不紧张：

[p=169, null, left][size=169px]早读有一半的时

[p=169, null, left][size=169px]间用来犯困，另一半时间中的效率也不高，有时还哼首歌什么的（由此决定以后少听歌）

[p=169, null, left][size=169px]。

[p=169, null, left][size=169px]上课时，尤其是数学和英语，一有听不懂的情况就犯困，

[p=169, null, left][size=169px]越困越听不懂

[p=169, null, left][size=169px]（最近课前开始仔细

[p=169, null, left][size=169px]预习了，上课听懂了就不犯困了，这方面有了改善）

[p=169, null, left][size=169px]。


[p=169, null, left][size=169px]二是我不知道什么时候有了个大毛病

[p=169, null, left]----

[p=169, null, left][size=169px]发呆。这的确浪费了很多时间。只要一闲下来

[p=169, null, left][size=169px]就发呆。所以，以后打算把日程排满，充实自己，改掉这个自杀式的烂毛病。还有，我有个

[p=169, null, left][size=169px]不爱写作业的毛病。

[p=169, null, left][size=169px]尤其是上了二年级后作业多了起来。

[p=169, null, left][size=169px]以后要勤快些。

[p=169, null, left][size=169px]其实这也是学习态

[p=169, null, left][size=169px]度的问题。然而有时候又控制不住自己，总想着上网。如今，大错既成，我深深懊悔不已。


[p=169, null, left][size=169px]据上，我决定有如下个人整改措施：


[p=182, null, left]1

[p=182, null, left][size=169px]、对自己思想上的错误根源进行深挖细找的整理，并认清其可能造成的严重后果。


[p=182, null, left]2

[p=182, null, left][size=169px]、制定学习计划，认真克服生活懒散、粗心大意的缺点，在下次考试中考好，以好成

[p=169, null, left][size=169px]绩来弥补我的过错。


[p=182, null, left]3

[p=182, null, left][size=169px]、和同学们加强沟通。保证不再出现上述错误请关心爱护我的老师同学继续监督、帮

[p=169, null, left][size=169px]助我改正缺点，取得更大的进步！同时，我也会尽量的少上网的！
