要给普通玩家建筑？
很简单放心我教你

  Default:                           《这是普通玩家意
    default: true
    permissions:                  《普通的玩家权利
    - -bukkit.command.kill
    - back
    - kits.tools
    - quickshop.create.buy
    - quickshop.create.sell
    - quickshop.use
    inheritance:
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    info:
      prefix: '&a'
      build: false                       《《把这个建筑权利改为true
      suffix: ''
其他的 build:也要改为true

指令方法是使用/mangaddv Default build true

设置权限组吧骚年{:10_492:}
作者: zhong19981221    时间: 2014-1-25 17:17

/mangadd [名字]   
创立一个用户组
/mangaddp [名字] [权限]     
给组添加某某权限
/manglistp [名字]   
列出某个组的权限
/mangdelp [名字] 权限   
删除某组的某权限
/mangaddv [名字]  prefix [数值]（比如&f是一种颜色）   
给组添加值的前缀
举例/mangaddv LBWORD prefix &f 熊族
给LBWORD用户组添加了[熊族]的前缀，并且这个前缀是带[&f]这个数值的颜色的
/mangaddi [名字1]  [名字2]      让组1担当租2的权限，能够为权限设置剩下不少费事
/manuadd [玩家ID] [名字]      
将用户添加到组
如果你是腐竹你就
/manuaddp    [玩家ID]   [名字]      
给用户权限
/manudelp [玩家ID]   [名字]      
删除用户权限
/manuaddp 玩家 prefix [参数]给玩家添加XXX的前缀
/manuaddv 用户名 prefix &[]  
给玩家添加XXXX的称号
