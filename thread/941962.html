什么是MineChess？
《MineChess》就是在《Minecraft》中重建的国际象棋游戏，你可以和你的朋友一起玩，并可以创建多个竞技场，并测试你的逻辑思维

第一个抓到对手的国王的玩家就是本次游戏的获胜者，如果游戏时间已到，并且两方的国王还活着，则得分最多的玩家取得胜利！

如果你不知道怎么玩，可以去wiki查一下：https://en.wikipedia.org/wiki/Chess

创建竞技场教程：
在创建竞技场之前，使用/chess setmainlobby设置主大厅，记住了！
  • 先使用/chess create [竞技场名字] 创建一个竞技场
  • 再使用/chess build [竞技场名字]
  • *注意了，使用这个命令会将方块放置在你的旁边并替换周围所有的方块，这就是为什么你需要在弄它之前建造它.
  • 再使用/chess setspawn [竞技场名字] 设置竞技场的出生点，你可以将出生点设置空中，因为玩家可以在游戏过程中飞行这样方便棋手推动
  • 再使用/chess enable [竞技场名字] 允许玩家加入竞技场
  • 最后你可以创建一个牌子让玩家加入竞技场

格式：
[Chess]
arena_name

指令：
  • /chess delete [竞技场] 删除竞技场
  • /chess join [竞技场] 加入竞技场
  • /chs 退出竞技场
  • /chess setmainlobby 设置国际象棋游戏大厅
  • /chess enable [竞技场] 启用竞技场
  • /chess disable [竞技场] 禁用竞技场
  • /chess build [竞技场] 在当前位置制作竞技场
  • /chess setspawn [竞技场] 设置竞技场出生点
  • /chess reload 重新加载配置文件

权限：
  • Chess.admin


变量：
  • %minechess_loses%
  • %minechess_ties%
  • %minechess_played_time%
  • %minechess_arenaplayers_count_<竞技场>%
  • %minechess_arena_status_<竞技场>%
