你可以把玩家移动至 admin 组
修改名字颜色在mc/plugins/GroupManager/worlds/world/groups.yml
里面的
  1.   Admin:
  2.     default: false
  3.     permissions:
  4.     - essentials.chat.color
  5.     - essentials.chat.format
  6.     inheritance:
  7.     - moderator
  8.     - g:groupmanager_admin
  9.     - g:bukkit_admin
  10.     - g:essentials_admin
  11.     - g:towny_admin
  12.     - g:vanish_admin
  13.     info:
  14.       build: false
  15.       prefix: ''                               #<<<<<<这里是在后面的名字
  16.       suffix: '&b&l[Admin]'             #<<<<<<这里是在前面的名字

最好的办法是给管理员ID固定一个前缀和颜色，不需要折腾其它那么多的插件。在权限组插件里找到users.yml 然后编辑它

  1.   UUID序列码:
  2.     lastname: 管理员ID
  3.     info:
  4.       prefix: '&7&l[&3&n&l管理员&7&l] &e&l'
复制代码

这里的prefix就是前缀和ID颜色的设置位置，&e&l就是大写金黄色的ID
