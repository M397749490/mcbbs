一下是领地插件的方法
如果你想给一个权限组 领地的 权限组（说的什么J8玩意！）    后面介绍~

DefaultSettings:
   #默认 进出领地显示的消息
  DefaultEnterMessage: You have entered %area%
   DefaultLeaveMessage: You have left %area%
   #领地所有者的权限标记
  OwnerFlags:
     admin: true
     build: true
     use: true
   # 这应该是其他人的标记
  AreaFlags:
     build: false
     use: false
   #最大高度
  MaxHeight: 255
   #最低高度
  MinHeight: 0
   #最大长度
  MaxLength: 200
   #最小长度
  MinLength: 0
   #最大宽度
  MaxWidth: 200
   #最小宽度
  MinWidth: 0
   #最小Y值
  MinY: 0
   #最大Y值
  MaxY: 255
   #最大领地数量
  MaxResidences: 10
   #需要花费的金币 ，  0.15 是每个方块的价格 ，默认是0
   CostEquation: (YSize * XSize * ZSize) * 0.15
   #重量？  不知道什么意思。
  Weight: 0

如果你写的组名字叫 Admin , OP玩家默认就会变成那个组，  如果你自己新增一个叫 vip 的组  
你需要给叫 vip 的权限组  一个叫 residence.groups.vip   的权限 ，然后他就有领地的权限分组了~
