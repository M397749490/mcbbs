作者: 1720942566    时间: 2015-8-3 19:36
找到Essentials目录下的config.yml找到这几行
  1. # 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
  2. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  3. custom-join-message: "none"

  5. # 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
  6. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  7. custom-quit-message: "none"
复制代码

可以将"none"分别替换成"{USERNAME} 进入了游戏" 和 "{USERNAME} 退出了游戏"
注意不要把双引号删掉了，漏了也不行
