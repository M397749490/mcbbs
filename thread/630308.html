手拿需要ban掉的合成材料。输入/banitem add 理由
理由：随便填，如果你想警示玩家的话，可以把理由改成：禁止合成此物品，如要成品，请前往商店/NPC处购买兑换

然后你想通过NPC兑换来获得成品？例如工业2的镭射枪，工具盒等这样用来合成的材料，却有N个BUG。然后不得不用banitem来禁止持有，但是你又想让玩家自己合成出成品来，如果真是这样。那么建议用ESS基础插件自带的ban
  1.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  2.   # 你加载了一次Essentials后,就可以在plugins/EssentialsX/items.csv中找到物品ID列表.
  3.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  4.   alert:
  5.     on-placement: 10,11,46
  6.     on-use:
  7.     on-break:

  9.   blacklist:

  11.     # 阻止玩家放置以下方块
  12.     placement: 10,11,46,4833,368,4844

  14.     # 阻止玩家使用以下物品
  15.     usage: 4833,368,4844

  17.     # 阻止玩家破坏以下方块
  18.     break:

  20.     # 阻止活塞推动以下方块
  21.     piston:

  23.     # 阻止发射器发射以下物品
  24.     dispenser:
复制代码
如：4833是工业2里的工具盒的物品ID，4844则是镭射枪，如果你按照这样的格式写入服务器。
那么在游戏内的普通玩家，将无法打开【工具盒】以及使用【镭射枪】从而只能用来当合成材料来使用。当然，如果怕玩家做出0电的镭射枪，你可以考虑将0耐久的镭射枪给ban了。就行了
