作者: NoName德里奇    时间: 2018-9-7 06:36
你的崩溃报告开头，崩溃描述（Description）是这样的：
  1. Description: Exception getting block type in world
复制代码

此外，像这样的提示在你的崩溃报告中出现了几次：
  1. -- Requested block coordinates --
  2. Details:
  3.         Found chunk: true
  4.         Location: World: (-624,47,-340), Chunk: (at 0,2,12 in -39,-22; contains blocks -624,0,-352 to -609,255,-337), Region: (-2,-1; contains chunks -64,-32 to -33,-1, blocks -1024,0,-512 to -513,255,-1)
复制代码

说明有一些方块出错了，可以考虑通过 MCEdit 等工具移除错误的方块。
而方块出错的原因，怀疑是 Fastcraft 和 wtfcore 与通用机械模组导致的，
而前两个模组的可能性更大些。
我的建议是这样的：
先尝试将 Fastcraft 移除，如果问题没有解决，
将 wtfcore 和以它为前置的模组移除（如果这些模组没有添加方块之类的，那就比较安全）
如果仍未解决，删除崩溃报告中提到的这些区块。之所以没有建议移除通用机械模组，是因为这个模组相对稳定，
而且添加了不少方块，移除它可能产生别的问题。
