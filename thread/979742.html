1.8.9和1.12.2差别主要体现在哪里

1.8的注册参数基本上是得全重写了。
就比如说utsc-zzzz的
  1. public ItemLoader(FMLPreInitializationEvent event)
  2.     {
  3.         register(goldenEgg, "golden_egg");
  4.     }

  6.     private static void register(Item item, String name)
  7.     {
  8.         GameRegistry.registerItem(item.setRegistryName(name));
  9.     }
复制代码
这段代码，你在1.12就得全改。
可以改为
  1. @SubscribeEvent
  2.     public static void registerItems(RegistryEvent.Register<Item> event) {
  3.         event.getRegistry().registerAll(
  4.                 BUBBLE
  5.     );
  6. }
复制代码
这段，且不必再主类进行注册。
当然你也可以继续使用GameRegistry.registerItem方法，只不过这非常麻烦，推荐用Forge的方法。
