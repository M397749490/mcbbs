手套

  • cross键传球
  • Circle键射门

网球

棒球


棒球棒


棒球手套


玩法：
  • 鼠标右键用手套接球
  • Circle键扔球
  • shift+鼠标右键用棒球棒击球

客户端：
  • 安装Forge，Player API 支持Forge版本，Render Player API 支持Forge版本
  • 将下载好的客户端运动MOD放入MODS文件夹
  • Enjoy sports！

  • 安装Forge，Player API 支持Forge版本
  • 将下载好的服务端运动MOD放入MODS文件夹
