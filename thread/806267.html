在ICommand接口中有如下方法
  1. int executeCommand(ICommandSender sender, String rawCommand);
复制代码
执行成功返回非零。
代码样例如下：
  1. MinecraftServer instance = player.getServer();
  2. if(instance!=null)
  3.     instance.commandManager.executeCommand(player,"/say Hello.");
复制代码
例子：
比如我有一个继承于ItemArrow类的CustomItemArrow类。
覆盖了父类的isInfinite方法。
这个方法传入了一个EntityPlayer 对象。
由于Entity对象实现了接口 ICommandSender
MinecraftServer对象有一个ICommandManager实例。
可调用MinecraftServer对象中的commandManager 实例的executeCommand()方法
以下为代码（在生存模式中射箭是会调用）
  1. @Override
  2. public boolean isInfinite(ItemStack stack, ItemStack bow, EntityPlayer player)
  3. {
  4.     MinecraftServer instance = player.getServer();
  5.     if(instance!=null)
  6.         instance.commandManager.executeCommand(player,"/say Hello.");
  7.     int enchant = net.minecraft.enchantment.EnchantmentHelper.getEnchantmentLevel(net.minecraft.init.Enchantments.INFINITY, bow);
  8.     return enchant > 0;
  9. }
