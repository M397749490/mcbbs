功能特性

同时发送/接收不止一个传送请求
支持权限分配
基本的tpa和tphere功能
经测试，支持二个及以上玩家

使用方法


1.查看玩家列表
2.获取玩家ID
3.发送传送请求/邀请
4.目标玩家接受请求
5.传送

tips：
请求在发出30s后会过期，届时无法同意这个请求
在每次初始化时所有请求会立即过期
所有“「」”中的内容均可以点击自动输入命令主干，只需键入ID之类的按回车即可
每次传送前不会检查传送目标所在地的安全性

指令及权限

玩家默认拥有所有使用权限

指令
 简介 权限*
/trigger tpa set -1
 查看所有玩家ID与帮助 -
/trigger tpa set <玩家ID>
 请求传送到该ID对应的玩家 permission.HBtpa.tpa_forbid
/trigger tphere set <玩家ID>
 邀请该ID对应的玩家传送到这里 permission.HBtpa.tphere_forbid
/trigger taccept <请求ID>**
 同意ID对应的请求 permission.HBtpa.tpaccept_forbid
/trigger tpreject set <请求ID>
 拒绝ID对应的请求
 permission.HBtpa.tpreject_forbid
*有这下列tag的玩家不可使用这个指令
**在创建请求后，被请求的玩家可以在聊天栏中看到请求ID
