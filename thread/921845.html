RideMe +
经典好玩的骑人插件重制版


插件简介 · Introduction

这是经典插件 RideMe 的重制版，在原插件的基础上加了一些功能和改进。
原来的版本没有配置文件，功能很少，因为我自己要用，所以就重制了一下。
插件的原作者应该是这个：https://www.mcbbs.net/thread-207816-1-1.html
插件已发布到 SpigotMC：https://www.spigotmc.org/resources/rideme-plus.72228/

插件特性 · Features
上任何的生物，或让任何生物上你！

标有 [+] 的功能为重制后的新功能，加粗字体的是我个人需要的功能，以及我觉得重制后最大的亮点。

  • 骑在其他玩家和生物头上
  • 让其他玩家和生物骑在你头上
  • [+] 可设置禁止别的玩家骑在你头上或者把你顶在头上
  • [+] 可以把骑在你头上的玩家或生物踢下去
  • [+] 可以设置禁止骑在某种生物上（防止 bug 蹦服）
  • [+] 可以将骑在你头上的人弹射出去，可设置弹射高度和角度
  • [+] 可以让一个玩家/生物骑在另一个玩家/生物头上
  • [+] 可以控制你骑着的玩家或者生物移动，可以设置速度
  • [+] 可配置的语言翻译
  • [+] 兼容 1.14.4 版本

安装方法 · Install

  • 首先下载本插件（见下方），放入 plugins 目录
  • 重新启动服务器或者 reload
  • 进入游戏输入 /ride 命令开始玩

命令和权限 · Commands & Permissions

命令列表

  • /ride 骑在其他玩家或者生物头上
  • /ride me 让其他玩家或者生物骑在你头上
  • /ride on 允许其他玩家骑在你头上或者让你骑在对方头上
  • /ride off 禁止其他玩家骑在你头上或者让你骑在对方头上
  • /ride kick 把你头上的玩家或者生物踢下去
  • /ride launch 把你头上的玩家或者生物弹射出去（可能会摔死）
  • /ride move 控制你骑着的玩家或者生物，再输入一次停下来
  • /ride connect 开启连接两个实体的功能，右键选中一个实体，然后再点另外一个来连接
  • /ride reload 重新载入配置文件

权限列表

一般直接给玩家 ridemeplus.use 这个权限就行了。
它同时包含 me、on、off、kick、launch、move、connect 这几个子命令权限。

如果你想细分每个权限或者禁用某些功能请手动设置以下权限：

  • ridemeplus.me 允许玩家把另一个玩家顶在头上
  • ridemeplus.on 允许玩家启用 Ride/RideMe 功能
  • ridemeplus.off 允许玩家关闭 Ride/RideMe 功能
  • ridemeplus.kick 允许玩家把头顶的生物踢下去

以下权限谨慎给玩家，因为可以用来恶搞另一个玩家，如果你不想启用的话请不要给这几个权限：

  • ridemeplus.launch 允许玩家把头顶的生物弹出去
  • ridemeplus.move 允许玩家控制骑着的生物
  • ridemeplus.connect 允许玩家把两个生物叠起来

这个权限建议给管理员：

  • ridemeplus.reload 允许执行重载命令

配置文件介绍 · Config

配置文件并不复杂，基本上就几个选项，这里简单介绍一下：

  • disable-list: 设置哪些生物禁止骑上去以及顶在头上，列表可以在 https://bukkit.windit.net/javado ... ity/EntityType.html 这里看到
  • launch: 还有 x y z 三个子节点，分别表示将玩家弹射出去之后的向量，如果你不清楚什么是向量，请保持默认
  • move_speed: 被控制的玩家移动的速度，不建议太快，默认 0.5，嫌慢可以加到 0.6 左右。
