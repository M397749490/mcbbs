如果可以的话，望楼主采纳。
建议先了解有关命令的知识再来学习。

https://minecraft-zh.gamepedia.com/记分板
https://minecraft-zh.gamepedia.com/命令
https://minecraft-zh.gamepedia.com/命令方块

先在聊天栏里输入：

  1. /scoreboard objectives add craft_diamond minecraft.crafted:minecraft.diamond_pickaxe
复制代码

放置循环命令方块（不受制约，保持开启），输入
  1. execute as @a[scores={craft_diamond=1..}] run give @s minecraft:diamond 1
复制代码

输出端接出一个连锁命令方块（不受制约，保持开启），输入
  1. execute as @a[scores={craft_diamond=1..}] run scoreboard players remove @s craft_diamond 1
复制代码
作者: 破损的鞘翅    时间: 2020-6-13 23:42
首先在聊天栏输入两条指令：
  1. /scoreboard objectives add craft minecraft.crafted:minecraft.diamond_pickaxe
复制代码
  1. /scoreboard players add f craft 1
复制代码

然后使用两个循环命令方块，分别装入以下两条指令：
  1. execute as @a if score @s craft matches 1.. run give @s minecraft:diamond
复制代码
  1. execute as @a if score @s craft matches 1.. run scoreboard players operation @s craft -= f craft
复制代码

可以保证在一次性大量合成钻石镐的情况下也不会少给钻石，前提是tps不低
