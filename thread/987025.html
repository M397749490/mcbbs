简介[官方]
原版的怪物太简单了 - 特别是近战的. 他们的攻击伤害又低又慢. 如果在游戏初期你就有一箱子的木质工具，你肯定不会被怪物打到哭.
如果安装了 LevelledMobs 插件, 它将会给原版中怪物一些血量、攻击和伤害提升，让玩家迎接更大的挑战，让PVE服变得更有趣.


LevelledMobs 是一个 Spigot端插件，其设计于刷新生物时给予他们一个等级. 其等级将会赋予不同血量攻击和伤害.
例如, Lv.0 仅有原版的血量伤害和速度, 挺无聊的数值对吧, 但是Lv.10 将会提供高血量高伤害和很快的移动速度.


不久前, 我和别人一样寻找着与其相似的插件, 但是找不到. 所以我写了这款插件!
我希望它能带来乐趣。因为有少数人告诉我，他们已经感受到插件给他们服务器带来的不同，无论是公开还是私下 (包括私信).

想要在其他版本上运行吗？
插件似乎可以支持1.13和1.14，但是要自己测试.
如果你真想运行在其他版本上，请一定要在测试服务器中进行测试.
除1.15.x之外的其他版本可能会存在兼容性问题
并且将不为除构架服务端版本以外的服务端提供支持

1.27-Changes:
[#56] Added 'ranged damage multiplier' with a default value of 1.1
Projectiles, such as arrows from skeletons, did too much damage. Requested by SpigotMC user @Velerium.
[#44] Added 'blacklisted types override', which forces mobs to be levelled, regardless of their status in 'blacklisted types' and if 'level passive' is false.
'SHULKER' is added by default, as for some reason they aren't considered a hostile mob.
