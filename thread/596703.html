作者: a1294790523    时间: 2016-6-29 22:18
只是Kcauldron的检查更新无法连接到更新服务器而已
请在kcauldron.yml内找到
  1. updatechecker:
  2.   quiet: false
  3.   symlinks: KCauldron.jar
  4.   enable: true
  5.   autorestart: false
  6.   autoinstall: false
  7.   quite: false
复制代码

将
  1. enable: true
复制代码
改为
  1. enable: false
复制代码
即可
