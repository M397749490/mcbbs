简介 Introduction

使用 Bukkit / Spigot 服务端时，可能玩家的账户会被黑客破解 (正版玩家也不例外) ，为此，我们尝试去寻找解决方法，最终在 SpigotMC 发现了 MineSecure ，可以使用 Google 开发的二步验证 (Two Factor Authentication) 对玩家的账户进行保护 ，插件本身完美，但是定价高昂，所以我们尝试自制类似于 MineSecure 的插件，并且免费开源，作为服务器管理者使用的插件、插件编写者借鉴的资料


语言 Language
  • 简体中文 Original
  • English 100%

功能 Features
  • 使用 Google 二步验证保护玩家的账户
  • 管理员可直接强制性控制玩家二步验证激活状态
  • 可使用多种数据库 (JsonDB / ymlDB / MySQL / SQLite) 进行二步验证数据管理 (MySQL / SQLite / ymlDB 正在开发)
  • 可使用 Google Authenticator 或 Authy 等同类 APP 绑定二步验证
  • config.yml 可自定义

安装 Install
前往 SpigotMC 或 Github Releases 下载对应版本，将其放入 / plugins 文件夹

命令 Commands
eap
  • / eap safepoint 记录玩家安全点
  • / eap create 创建二步验证
  • / eap delete 删除自己的二步验证
  • / eap verify <code> 初始化验证
  • / eap exit 退出创建步骤
2fa
  • / 2fa <code> 进服二步验证
eapre
需要管理员权限
  • / eapre <玩家名> 强制删除任意玩家二步验证

权限 Permissions

  • EusAccountPro.general 本插件的普通权限 (默认情况下已授予)
  • EusAccountPro.admin 本插件的管理员权限，可以强制删除任意玩家二步验证


配置文件 Config.yml
Storage:
  type: JSON # JSON, SQLite, MySQL, yml
Account:
  Display: EusMC # 字符串，包含在二维码内服务器的名称，可自定义，APP扫描后会显示该名称
Plugins:
  GeoIP:
    switch: false # 布尔值，开启GeoIP地址检测，根据地址变动自动启用进服验证
    online: false # 布尔值，使用在线模式进行GeoIP地址检测，若为false，则必须提供lib，若为true，则必须提供token
    lib: /GeoIP/GeoIP2-City.mmdb # 若使用本地GeoIP，填入GeoIP的数据库地址，此为示例
    token: 35c3d3e57d879403a3f3f51517fbffcf0ee11f6e34541e028d4c259ababc46c9 # ipinfodb.com 提供的token

数据库 Database

  • JsonDB 使用 Json 文件进行玩家数据存储 (默认选择，文件格式主流，跨平台，在 FastJson 的辅助下读写快速)
  • ymlDB 使用 yml 文件进行玩家数据存储 (敬请期待)
  • MySQL 使用 MySQL 数据库进行玩家数据存储 (敬请期待)
  • SQLite 使用 SQLite 数据库进行玩家数据存储 (敬请期待)
