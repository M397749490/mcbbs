想在空中进行2次推进吗？


想在MC里和超人一样吗

这个插件为你实现~~~~


这是一个什么样的插件?
就是跳一下可以在空中再跳一下（前提是你有权限） 权限在哪里？请看下面

特点：
可调节掉落伤害
可开启或关闭跳跃声音
可设置权限
可设置跳跃高度


命令： 无 设置权限即可


权限：
doublejumper.use 跳跃权限
允许玩家双跳


config：


sound: true 声音开启
nofall: true  不下落开启 （貌似就是不扣血）
forward: 0.8 前进参数0.8
up: 1.0 上升参数1.0
usepermission: true 插件权限限制已开启
