指令和权限以及说明
  • / CE
    • 说明： 打开GUI。
    • 权限： CrazyEnchantments.Access
  • /BlackSmith
    • 说明： 打开Black Smith
    • 权限： CrazyEnchantments.BlackSmith
  • / Tinker（Alt / Tinkerer）
    • 说明： 打开Crazy Tinkerer 的GUI。
    • 权限： CrazyEnchantments.Tinker
  • / GKitz [Kit] [Player]
    • 说明： 打开GUI或给您或播放器。
    • 权限： CrazyEnchantments.GKitz。<Kit>
  • /CE Info [附魔/类型]
    • 说明： 打开信息GUI。或快速搜索附魔。
    • 权限： CrazyEnchantments.Info
  • /CE Reload
    • 说明： 重新加载Config.yml。
    • 权限： CrazyEnchantments.Admin
  • /CE Add <Enchantments> [Lvl]
    • 描述： 在手中的物品上添加和附魔。
    • 权限： CrazyEnchantments.Admin
  • / CE Spawn <Enchantment> [等级：＃/世界：<世界> / X：＃/ Y：＃/ Z：＃]
    • 描述： 生成一本附魔书
    • 权限： CrazyEnchantments.Admin
  • / CE Scroll <Player> <Scroll> <Amount>
    • 说明： 给玩家一些Scrolls。
    • 权限： CrazyEnchantments.Admin
  • /CE Dust <Success/Destroy> [Amount] [Player] [Percent]
    • 说明： 给玩家魔法尘埃。
    • 权限： CrazyEnchantments.Admin
  • / CE Book <Enchantment> [Lvl] [Amount] [Player]
    • 说明： 给玩家一个特定的附魔书。
    • 权限： CrazyEnchantments.Admin
  • / CE LostBook <类别> [金额] [玩家]
    • 说明： 给玩家一本封尘的书。
    • 权限： CrazyEnchantments.Admin
  • /CE Crystal [金额] [玩家]
    • 说明：给玩家一个神奇水晶。
    • 权限： CrazyEnchantments.Admin
  • / CE Scrambler [Amount] [Player]
    • 说明：给玩家一个爬行者。[额....实在不懂]
    • 权限： CrazyEnchantments.Admin
CrazyEnchantments.Sign - 允许用户对商店进行签名。
CrazyEnchantments .Limit。＃ - 设置最大的附魔极限。
CrazyEnchantments.aurabypass - 禁用光环附魔防止影响你。有益于工作人员。
CrazyEnchantments.Gkitz。<GKit> - 给玩家一个特定的gkit的权限。
