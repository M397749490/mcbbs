DiamondGuarantee


介绍
这款插件是用来修复稀缺资源在服务器被掏空的问题.在原版多人服务器里，这些资源可能很快就会被肝帝掏空，从而使得萌新发展艰难，可能挖矿一天矿一颗钻石都没有. 如果你生成一个资源世界且不控制矿物生成率的话可能矿物又会太多.
而这款插件会让十分努力的玩家尽可能获得稀缺资源作为回报 .
例如,插件在正在挖矿的玩家附近生成钻石矿, 使地狱生物掉落地狱疣和萤石粉 (带有一些反刷怪机制), 并使末影龙有几率掉落鞘翅.

插件测试兼容1.8、1.12 理论上兼容1.8-1.13


指令
  • - /dgreload (重载配置)
  • - /diamondscore <player> (获得一名玩家获得的钻石分数)
  • - /setdiamondscore <player> (设置一名玩家的钻石分数)
钻石分数为在玩家附近生成钻石矿所需分数，当玩家达到这个分数后分数会清零并生成钻石矿

默认分数为1000




指令&权限
  • - diamondguarantee.reload (重载插件)
  • - diamondguarantee.getscore (获取玩家钻石分数)
  • - diamondguarantee.setscore (设置玩家钻石分数)

配置文件介绍
这里只是介绍配置文件内容，配置文件汉化后加载插件会被覆盖 请勿覆盖原配置文件
  1. # 配置包括不同时间的配置.  没有世界名称的方块设置用于在加载这个插件之后创建/加载的世界，例如由其他插件生成的世界
  2. #world: 主世界设置
  3. #  Diamond Zone: 钻石区域
  4. #    Minimum Y Value: 0 最小Y坐标
  5. #    Maximum Y Value: 16 最大Y坐标
  6. #  Diamond Generation: 生成钻石
  7. #    Enabled: true  是否启用
  8. #    Diamond Value: 1000 生成所需分数
  9. #    Stone Value:  石头得分
  10. #      Outside Diamond Zone: 1 钻石区域外
  11. #      Inside Diamond Zone: 3  钻石区域内
  12. #    Log Details: false  记录细节
  13. #world_nether: 地狱设置
  14. #  Ghasts Drop This Many Glowstone Dust: 20  恶魂掉落萤石粉几率
  15. #  Percent Chance Fortress Pig Zombies Will Drop Nether Wart: 20  地狱堡垒的僵尸猪人掉落地狱疣的几率
  16. #world_the_end:  末地设置
  17. #  Ender Dragon:  末影龙 (掉率都为100%，不建议开启)
  18. #    Drops Dragon Eggs: true  是否掉落龙蛋
  19. #    Drops Elytras: true   是否掉落鞘翅（1.8没有鞘翅不会有掉落）
  20. #    Drops Dragon Heads: true  是否掉落龙头 （1.8没有龙头不会有掉落）（低版本存在BUG）
  21. #以下为其他世界的配置，同上
