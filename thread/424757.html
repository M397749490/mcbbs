服务端整合包版规

此版规由 服务端懒人包Beta 0.8、服务端懒人包 Beta 0.6、服务端懒人包版规

Beta 0.4、多人联机大区规定 改编而来。

(如果版规有所不足，请积极以私聊的方式反应给版主)

目前可以申请高亮/优秀。详见服务端懒人包综合申请帖

发帖格式
格式：
[服务端版本][服务端类型]标题介绍服务端特色、风格、主内容、简介
例如：
[1.8.8][Spigot]东方神教服务端
[1.7.2-1.7.10][CB]欧洲提督不可进的自动识别服务端
注：
craftbukkit —— CB
MCPC+ —— MCPC+
Minecraft_Server (即官方服务端) —— 官服
Spoutcraft —— SC
Spigot  —— Spigot
Libigot —— Libigot
Cauldron —— CD
Thermos —— Thermos


一、关于标题
1-1: 主题标题格式必须严格按照发帖格式编辑，如果不合格我们会将进行强制修改，当然会扣除掉10金粒以作手续费。

*：若可以判定为不止一次不按版规发帖的，版主拥有引导，删帖，扣分，发卡，直至最高封禁7天的权力。
1-2: 如果放任不管被关闭的主题，我们会在14天之内做认作过期并且移进已过期服务端整合包中；
1-3: 标题或正文内如果出现服务器宣传、商业性质广告、个人主页广告、其他论坛广告、QQ群等盈利性内容，我们会直接删帖 + 发卡；
1-4: 关于想在标题内标注作者，请标注在标题的最末，如：
[1.7-1.8][MCPC+]LoveLive大法好服务端[LL教徒整合]

*: 作者可以按照自己的意愿选择标注或者不标注，但是如果选择标注必须按照格式。
*: 注意是 "[" 与 "]" 不是 "【" 与 "】"，版本之间的符号是“-”而不是“~”

二、关于内容
2-1: 必须严格按照模板发布服务端；
2-2: 帖子内必须包含服务端内所有插件截图、所有MOD截图（MOD端，纯净端例外）、服务端控制台开启截图；若缺少截图或者图挂，我们会在下面回复提醒在24小时内及时补上，若超出24小时，我们将会锁帖+移动至过期。

*: 如果使用开服器也必须附上截图并加上使用说明。
2-3: 如果转载他人整合包请征得原作者同意，如果从国外搬运也必须征得同意，并且请自行汉化内容，附上原帖地址，不管是转载还是搬运，如果没有原帖地址我们将会视为剽窃，发卡 + 删帖 + 扣除1贡献；

*: 如果是机翻我们会直接删除。
2-4: 主题内容必须介绍详细，与内容无关的一串字、一个表情、一串乱码都会受到版主警告，不整改的会直接删除；

*: 叙述中可以根据个人习惯适当使用表情。
2-5: 禁止以任何形式的向他人索取回复，你可以求人气求金粒，但是不允许索要回复。一经发现，清除评分 + 扣除2人气 + 发卡警告，屡教不改直接删帖 + 扣除1贡献；
2-6: 禁止多开小号顶贴，如有发现撤销回复 + 扣除2人气 + 发卡*禁言一周；
2-7: 帖子内必须附上服务端下载链接，且禁止使用类似115网盘这种需要注册才能下载的网盘；
2-8: 服务端压缩包禁止附带密码；否则将会被移动至过期(4/4)
2-9: 整合包内禁止私自修改插件或配置文件达到宣传服务器、QQ群或者盈利而非捐助的目的。如果是原创插件包含在包内则允许附上捐助链接，但仍旧不允许宣传服务器和QQ群。如有发现，作删帖 + 发卡 + 扣除1贡献处理；
2-10: 允许主题内进行个人推广，但不允许包含盈利性内容，如收费XXX制作XXX等，视情况作封禁7天 / 扣除(贡献 / 人气) ~ 永久封禁的处理；
2-11: 服务端中如果使用了非自动生成地图请注明。如果不是原创的则需要征得地图原作者的同意，否则视为剽窃，直接删帖+发卡；
2-12: 如果在服务端中含有任何形式的后门，我们会立刻删帖 + 发卡 + 扣除2贡献；
2-13: 如果权限组插件你进行了权限组和权限的配置，必须附上所有相关内容的列表！否则视为后门处理；
2-14: 为了大多数会员的阅读习惯着想，帖子内不得有字体大于五号；
2-15: 由于整合包的特殊性，禁止下放一切具有盈利性质的下载链接（如 adf.ly）！违者直接永久禁言；
2-16: 服务端版本更新不允许新开主题，请在现有的主题上编辑。如果新开主题的话旧主题会被直接删除；
2-17: 1.7.2 之前的所有服务端都会被移动到已过期服务端懒人包；
2-18: 请文明发帖，主题内不允许有偏激性语句/脏话/针对某个会员/版主/管理员的嘲讽/攻击，如有发现我们会警告处理，如若放任不管则会被删帖；
2-19: 发表完更新后允许自顶一次，其余情况不允许自己顶贴；

*:若自顶被处理后将被下沉处理，第二次及更多自顶-2人气-20金粒处理上不封顶(11/1)
2-20: 如果一个主题内容遭到大部分会员的有理憎恨/厌恶/反感，我们会根据具体情况讨论后作出处理；
2-21: 服务端内所有MOD和插件必须为已经在站内发布过的，如果你想使用站内没有发布过的，请转载到站内，而如果你是原创插件或者MOD先加入整合包中，请先发布通过后再整合！违规一律直接删帖；若服务端内含有大量(超过3个及以上)付费插件，违者一律发卡删帖；若服务端内仅含有1-2个付费插件，我们将会移动至过期，也请及时删除后联系版主移回。
2-22: 禁止任何诅咒内容，如不回复没有XXX。
2-23: 本版禁止仅楼主可见，一经发现直接删除。
2-24: 本版禁止一切软件类端口映射发布，有推广外链的一经发现直接删除，外链推荐产生任何收益的附加封禁7天，其余按坛规处理。
2-25:以任何魔改、非原版Pixelmon MOD为服务器玩法、元素的服务端即日起将直接被删除并警告。
关于主题的奖励
当你的主题获得大多数会员的认可和版主的认可时，你可以申请加分。
火I:+1人气+10金粒
火II:+2人气+15金粒
火III:+3人气+20金粒

(#1 [附录]) 服务端类型缩写
CraftBukkit -> CB
MCPC+ -> MCPC+
SpoutCraft -> SC
Spigot -> Spigot
Libigot -> Libigot
Minecraft Server (即官方服务端) -> 官服
* 其他类型可将完整名称写入，如果帖内含有多种服务端则用 “/” 分隔。

回复&评分规定

一、违规行为
3-1:脸滚键盘打出来的内容，如"ksdfhjkasdfasdj"阿斯顿复活节偶怕史蒂夫"478415s546"kkkkkkk"等。
3-2:纯表情图片而没有任何文字内容。
3-3:单纯的赞美楼主，如"支持一下""666""好好好，拿走了"等。
3-4:已经发布了下载地址的主题内询问下载地址是什么、
3-5:询问解压密码多少。[2-8中已经明确规定不允许使用任何压缩包密码。]
3-6:无意义的回复。如"准备和基友开个小服""能不能加个XX插件、XXmod啊"
3-7:"为什么服务器开不了"也算为水回复。如果想询问楼主为什么无法打开服务端请附上具体情况或者截图。
3-8:连楼都算水[作者本人回答他人问题不算][论坛卡导致的不算]。
3-9:与主题无关的回复，如"钻石如何获得""wwwwwwwwwww"
3-10:在回复/主题宣传服务器的，直接发卡+扣除2人气+10金粒+封禁5天。
3-11:在回复宣传其他论坛/盈利性内容/个人推广的直接发卡+扣除2人气+10金粒+1贡献。
3-12:禁止使用万用回复回复和屠版。如"这个整合包做得很好很和我的胃口，希望作者再接再厉。"等。
3-13:禁止除了回答问题以外的任何无意义版聊。超过2帖/人或4帖/总的，予以警告+扣除 1人气 5金粒(下限) ~ 2人气 20金粒(上限)的处罚。但是允许评论服务端，提出不足或者需要改进的地方，如果有什么地方好可以给予评价，但是请注意不要触犯3-3、喜欢版聊请去矿工茶馆，谢谢。
3-14:恶意抹黑服务端[给恶评]的，直接警告+扣除2人气20金粒。如果服务端真的存在问题，请不要暗讽或者引战，如果是后门请举报，如果是楼主的失误可以正常回复，引战或者暗讽一律按恶评处理。
3-15:在没有下载服务端的情况下，直接吐槽帖子内容也算作灌水

*"已举报"等回复同样视为灌水。
3-16:版战*超过2帖/人或4帖/总的，每人予以封停3-7天，视情况附加扣除 -1人气 -5金粒 ~ -2人气 -20金粒 -1贡献 -5绿宝石的处理。

*"版战"包括且不仅限于偏激语言，暗讽或其他坛规规定的内容。若有冲突以总坛规为准。
3-17:在无意义帖*内的评分，予以无条件撤销，若过多则调用坛规进行刷分处理。

*"无意义贴"不仅限于服务器宣传，完全无图，标题偏差严重等。若您主观判断楼主已阅读本版规，且尊重本版的主题，欢迎您在不违反3-15的情况下向楼主提出违规内容并劝导其改正，我们会适当予以加分。

因为新版规和旧版规就回复而言严格了许多倍，在这里做一些解释以免引起不必要的误解。
正常提出问题不会被算在违规范围内，但请给作者一个能听清楚你想表达什么的措辞或者截图。
因为不允许索要QQ，所以建议私聊。
如果想表达对楼主的支持，你可以附上使用感想。
*如果你根本就没用过楼主制作的服务端你想支持什么？

发帖者未浏览版规而被处理，后果自负
