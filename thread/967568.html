Groups.yml内 修改普通权限组Default的
  1.        Economy:
  2.           # 是否可以购买待购的领地
  3.           CanBuy: true
  4.           # 是否可以出售领地
  5.           CanSell: false
  6.           # 购买领地时，是否忽略领地面积/数量的限制
  7.           IgnoreLimits: false
  8.           # 创建一个新领地或添加物理区域时的每个方块大小花费.
  9.           BuyCost: 0.5
  10.           #  移除一个领地时返还每个方块大小价格.
  11.           SellCost: 0.25
  12.           # Lease领地时每个方块大小花·费 (如果Lease系统开启).
  13.           RenewCost: 0.2
复制代码
  1. RenewCost: 0.2
复制代码
便是每个方块的价格
修改为你需要的价格即可
