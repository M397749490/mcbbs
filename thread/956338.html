综合申请贴


申请晋升

当您成功加入小组后,一般都需要经过实习期 (2个月)

在2个月内完成实习任务即可成为正式组员

而如果您是正式组员,那么以下任意一种情况可以申请晋升荣誉组员


  • 为小组做出过突出贡献,
  • 拥有≥3~4个优秀图章帖子,且注明来自于本组
  • 拥有≥1~2个精华图章帖子,且注明来自于本组
    也可以结合多个条件(例如2优秀,1精华)

抱歉,现阶段暂不接受荣誉组员晋升的主动申请

申请格式
  1. 申请项目: 晋升 正式组员
  2. 实习任务:
  3. - Task
  4. - Task
  5. 相关帖子:
  6. - URL
  7. - URL
  8. AT组长: （请在此处at现任组长）
复制代码



申请勋章

在这里申请获得小组的专属勋章

请注意,以下情况申请不会通过

  • 处于实习阶段,且未曾对小组有过较大贡献
  • 正式组员,但在近期（3个月内)中,被处以组内警告过

请注意,一旦申请,则视为同意撤销本有的别组勋章
在申请成功后至拿到勋章中间的一段时间内，请勿改名

申请格式
  1. 申请项目: 小组勋章
  2. 申请理由:
  3. - Reason
  4. - Reason
  5. AT组长: （请在此处at现任组长）
复制代码



注意

我们将通过QQ等联系方式与您联系

而不是通过评分来告知您
