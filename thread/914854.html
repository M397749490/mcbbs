chestfix —— 一个轻量的潜影盒修复插件

简介
  • 最近服务器内玩家提交了一个由潜影盒配合特殊姿势刷物品的BUG
  • 测试了许多ban物品的插件效果不尽人意
  • 所以就自己写了一个
  • 插件没有任何权限与指令
  • 插件理论是1.12+如果不适配或是报错请PM我
  • 如果觉得好用的话~点赞评分一下下呗~

特点
  • 无需封禁潜影盒与展示框即可防止玩家使用特殊姿势刷物品
  • 经测试支持CAT端=w=

插件源码
@EventHandler
    public void PlayerInteractEntityEvent(PlayerInteractEntityEvent event) {
        if (!event.getPlayer().isOp()) {
            if (event.getRightClicked().getType().name().equalsIgnoreCase(String.valueOf(Material.ITEM_FRAME))) {
                if (event.getPlayer().getInventory().getItemInMainHand().getType().name().endsWith("SHULKER_BOX")) {
                    event.getPlayer().sendMessage("你没有权限这么做");
                    event.setCancelled(true);
                }

            }

        }

    }
