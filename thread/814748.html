插件介绍

实体死亡后，它将产生一个迷你箱子（可配置），其中包含所有实体掉落。它有一个倒计时，玩家可以在倒计时结束之前进行掠夺。

官方预览
插件特色
轻量级
完全自定义！
为玩家保护掉落
自主掠夺
允许/禁止打破宝箱战利品
自定义宝箱纹理
粒子效果
宝箱上方的全息图
MythicMobs支持
插件指令
/ rpgloot info - 插件信息
/ rpgloot reload - 重新加载配置

插件配置
  1. #配置文件由烧鸡汉化(bbsid：Leucothea)。请不要随意盗窃.
  2. General:
  3. #掉落保护，关闭了掉落物会直接爆出来
  4. ProtectDrop: true
  5. #允许破坏，开启则可以敲掉宝箱，关闭后倒计时结束自动消失
  6. AllowBreak: false
  7. #倒计时时间
  8. TimeToLoot: 360
  9. #RegularMobs联动
  10. ApplyToRegularMobs: true
  11. #MythicMobs联动，只有开启了，MythicMobsBlackList配置才会生效
  12. ApplyToMythicMobs: true
  13. #实体黑名单，被加进去的实体死亡不会生成宝箱
  14. EntityBlackList:
  15. - ARMOR_STAND
  16. #MythicMobs怪物名单，把怪物ID加进去，怪物死亡后就会掉出宝箱
  17. MythicMobsBlackList:
  18. - SkeletonKing123
  19. Item:
  20. #宝箱头颅材质，一般不需要改
  21. SkullHash:'eyJ0ZXh0dXJlcyI6eyJTS0lOIjp7InVybCI6Imh0dHA6Ly90ZXh0dXJlcy5taW5lY3JhZnQubmV0L3RleHR1cmUvYWFhMzY4MzY1YjYwMzM3NWQ1Y2RkYTlkYWE5MjRiOTY0YjFmMTE4YTcyNTAxODdhNjk2YTA3ZmYxOGNmMDIifX19\'
  22. #粒子设定
  23. Particles:
  24. #是否启用
  25. Enabled: true
  26. #粒子类型
  27. Type: 'SPELL_WITCH'
  28. #宝箱上HD配置
  29. Holograms:
  30. #是否启用
  31. Enabled: false
  32. List:
  33. - '&7[&eLoot of &c%e%&7]'
  34. - '&6> &eTime: &f%time%'
  35. - '&6> &eOwner: &f%owner%'
