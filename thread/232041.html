可否使用Itemizer 设定命令使不同组的玩家分别穿戴装备？我们用的是banitem

比如我想要给某个分组的人使用弓的权利，可否在弓内用Itemizer写入

mangaddp default banitem.bypass.261:0

如果不行的话有没有其他插件能做到的

/rpgitem XXX description add

或者用这个行不行
