                                   下面重磅教程开始！

下面讲解一下时间轴...时间轴呢它里面的每个图片对应/显示一个图层，所以
这也是动画的关键，时间轴里面我们只需要用到：复制图层&播放这两个按钮即可。
如下图所示： ↓

下面我们点击:"复制帧"(你要显示多少个动画就复制多少个，你复制的帧显示的都是和第一个帧一样的，因为我们还没有给他分配显示的图层，我前面说过，每个帧都只显示/对应一个图层) [注:每个图层画好后记得按Ctrl+Alt+Shift+E键盖印]
我这里画5个帧(即5个不同的展示图层)小技巧：Shift+z -撤销/Shift+Alt+z一直撤销。图层前面的眼睛是代表：显示/不显示该图层的意思。

仔细对比图层与帧位置，你会发现他们都是对应的，做到这里，差不多到一半了
好，接下来我们再次新建一个新标题，大小为：宽64高320像素，背景内容为：透明，下面我们将这5个图层全部选中(按住Shift键不放，鼠标点击第一个图层与最后一个图层既是全部选中)然后右键任意一个图层点击复制图层然后选择复制到我们刚刚新建的另一个标题，具体步骤如下图所示： ↓

之后也就是最关键的一步！即：对齐图层
这个时候我们需要一个"模板"来确定各个图层的位置，这时候我们可以再次新建一个64×64大小背景内容为透明的标题，进入后按Ctrl+Delete键/Alt+Delete键填充颜色，在选择侧边工具栏中的：矩形选框架(即工具栏第二个工具)，然后框选整个颜色覆盖区域，按Ctrl+C键复制样式图层，然后转回我们的第二个标题(即第二次创建的标题)中按Ctrl+V键复制，然后用鼠标选择此图层拖到图层栏的倒数第二个位置，再用侧边栏第一个工具：移动工具将刚刚复制过来的图层移动到最上面与背景图层对其，然后再次Ctrl+V键复制，这次给模板换个颜色(步骤：先对着第一个模板图层右键点击复制图层/Ctrl+J然后按住Ctrl键不放点击第二个模板图层的小方块，这时会出现一个虚线选框，那么我们再次按Ctrl+Delete键/Alt+Delete键填充另一个颜色，如果上次是Ctrl+Delette那么这次就要按Alt+Delette键然后选择侧边栏的:矩形框选工具随意单击图层舞台中任意位置，最后用侧边栏第一个工具：移动工具将刚刚复制过来的图层移动到上一个模板图层后与第一个模板图层拼接)即如下图所示:↓

全部拼接好了就会是这样的，随后我们看到图层栏，点击最上面的第一个模板图层
按Ctrl+E键合并所有的模板图层为一个如下图所示：↓
合并
模板图层上面的就是我们的动画帧图层了，现在我们每个模板位置对应一个图层，
使用移动工具，将第二个图层(即图层5，以此类推)移动到第二个模板所在位置，
第三个图层移动到第三个模板的位置...然后以此类推，效果图如下：↓

当然我们在移动的时候要把图层前面的"小眼睛"点出来...我前面说过小眼睛是干嘛的
如果怕对不齐可以使用放大镜工具来辅助对齐！
                                     倒数第二步骤
把倒数第一个图层(背景层)与倒数第二个图层(合并后的模板层)前面的"小眼睛"点没
否则就会出现GG的效果..点没后...进入下一个步骤..
                                最后的一个步骤！！！
按Shift+Ctrl+Alt+S键会出现一个对话框，下面你们跟着我的设置改一下..下图所示

然后点击储存....

前步骤完成
然后有人问我..这就可以了？？

当然没有
最后的步骤
我们在开始窗口内输入：记事本然后敲击回车键[桌面创建的记事本不好用]然后在记事本内输入以下内容：
  1. {
  2.   "animation": {
  3.   "frametime":2
  4.   }
  5. }
复制代码
然后保存，注意！这里的文件名格式是：×××.png.mcmeta
然后保存类型是：所有文件
这个文件是让贴图动起来的...文件的前面必须和我们刚刚做的贴图名字一样..
我举个栗子（例子）..：我刚刚做的贴图名字叫：damage.png，那么这个文件名就应该是：damage.png.mcmeta，然后把它俩一起丢进贴图文件夹里面替换即可..
