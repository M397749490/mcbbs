据点



据点显示方式已更新，拉到下面的特效系统可查看效果，可在配置文件修改位置及内容
  • 配置教程
    极其简单，跟着下面的步骤走

    • step.1 首先在插件目录下找到points.yml文件并用Notepad++（或其他文本）打开
    • step.2 可以看到如下代码片段
    #据点配置
    1. #据点配置
    2. points:
    3. a1:
    4. name: '碧海核心'
    5. world: 'world'
    6. x: 892
    7. y: 67
    8. z: -163
    9. guild: ''
    10. level: 1
    复制代码

  • 据点地址与名称
    据点之间的名字一定不能重名否则会发生错误，世界名不能填写错误，如果错误也会发生异常情况，配置好过后，开服将在这个坐标生成一个信标，而这个信标就是核心，是攻击占领时的标志物。
    所属公会
    guild配置项是数据，表面当前占领这个据点的公会是哪一个公会，不可轻易修改！
    占领限制
    每个公会的等级决定了这个公会对据点的最多占有数量，可在config.yml中配置，资源加成效果可以叠加
    据点等级
    据点有三种等级（可以自己新增但要按照格式，但不推荐新增），可以分别在points.yml设置据点等级每分钟的产量资源

    • level: 1 小型据点
    • level: 2 中型据点
    • level: 3 大型据点
  • 使用教程

    • 占领教程
    只要破坏一次信标就可以扣除20点值，而每个等级的据点有不同的最大血量，血量扣除完毕该据点将会被对本核心造成伤害最大的公会占领
    开放的时间是服主自己设置的！

    #################################
    buff: 0                         #

公共BUFF列表(通用于所有服务器)：
  • 指令型BUFF
    介绍:  每一分钟为所有占领本据点的公会的在线成员执行一遍自定义的指令
    id: 0
    可叠加
    参数: args中填写要执行的指令，其中{player}是玩家的变量，不加"/"
    ################################# 每分钟为该公会所有玩家执行一次指令
    buff: 0                         #
    args: 'eco give {player} 100'   #
    #################################
  • 移动速度BUFF
    介绍:  占领公会的玩家将会获得速度加成或抑制，全看你的设置
    id: 1
    不可叠加
    参数: args中填[-1.00 ~ 1.00]这个区间
    ################################# 占领的公会的玩家移动速度为0.3
    buff: 1                         # 默认的移动速度为: 0.2
    args: '0.3'                     #
    #################################
  • 经验倍增
    介绍: 占领该据点的公会玩家将会获得经验的倍率加成
    id: 2
    可叠加
    参数: args中填小数倍率[0 - ?]
    ################################# 假如原本玩家会获得10经验，那如果该BUFF生效则玩家
    buff: 2                         # 获得10 * 1.5 = 15 经验，而如果该公会同时占领两
    args: '1.5'                     # 个这种据点， 则是10 * 1.5 * 1.5 = 22经验
    #################################
  • 据点金钱生产量BUFF
    介绍: 本据点生产金币的数量会随设置增加
    id: 4
    可叠加
    参数: args中填整数[0 - 10000]
    ################################# 额外增加400金币生产量/分钟
    buff: 4                         #
    args: '400'                     #
    #################################
  • 据点伤害叠加BUFF
    介绍: 占领本据点的公会玩家在攻击其他据点时会获得伤害加成
    id: 3
    可叠加
    参数: args中填整数[0 - 1000]
    ################################# 额外增加100据点伤害量
    buff: 3                         #
    args: '100'                     #
    #################################
  • 公会荣誉增加BUFF（编写中）
    介绍: 占领本据点的公会玩家在获得BUFF的时候会获得BUFF加成
    id: 5
    可叠加
    参数: args中填整数[0 - 10000] #**才填多
    ################################# 当玩家获得荣誉时会额外增加50点贡献
    buff: 5                         #
    args: '50'                      #
    #################################

    buff: 8003                                # BUFF的据点,几率为100%转换为背包里的神奇
