LocaleLanguageAPI
本地化语言API


介绍
本插件为前置API，用于获取物品本地化名字
插件内提供了一个通过NMS获取物品名字的方法，自定义名字优先
插件可启用自定义语言文件，启用并将文件放入插件的lang文件夹即可
当自定义语言文件不存在对应物品时，会自动读取原语言文件
1.12及以下自定义语言会影响到其他通过NMS获取物品名的插件
（服主可以单独安装用来汉化其他只能获取物品英文名的插件）
1.12及以下语言文件后缀为.lang
1.13及以上语言文件后缀为.json
支持mod物品，同样放入lang文件夹
理论支持含有NMS的Spigot服务端

指令 & 权限 & 配置
指令
/ll reload 重载插件
/localang reload 重载插件

权限
localang.reload 重载权限

配置
#是否启用自定义语言文件
enable: false
#重载信息
reload: '§a[%name%]: OK!'


API
类:  com.tripleying.qwq.LocaleLanguageAPI.LocaleLanguageAPI
方法:  获取物品名
public static String getItemName(org.bukkit.inventory.ItemStack is);
方法:  转换本地化字符串 (v1.1.0新增)
public static String get(String str);
