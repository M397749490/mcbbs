标题: flan内容包枪和盔甲的特殊效果一览表
flan是目前最自由的枪械mod，可以自定义枪械和子弹的属性，但是访问它的官网没有有关于内容包开发的教程和文档。前一段时间回答了两个关于此的问题后，我决定将我反编译flan得到的属性列表作为教程发上来：
我反编译的flan版本为4.1.10 for mc 1.7.10
一行有两个的是在源码中被视为等价的
枪:(位于 com.flansmod-guns-GunType.class)

Damage//单发弹药单个弹片伤害
MeleeDamage//物理伤害
CanForceReload//是否允许强制重装子弹
ReloadTime//重装子弹时间
Recoil//后坐力
Knockback//击退
Accuracy == Spread//精度，或者说弹药散布，为0则指哪打哪
NumBullets//数量 用于散弹枪，单发弹片数量(每次依然只消耗一发子弹，单个弹片攻击力由Damage决定)
ConsumeGunOnUse//**时是否消耗枪支本身(用于手雷)
DropItemOnShoot//打中后是否使物品掉落，推测对于物品展示矿
NumBurstRounds//扣一次扳机射出的子弹数量
MinigunStartSpeed//(用于机枪)射击初始速度
ShootDelay//射击间隔，单位tick
SoundLength//
DistortSound
ShootSound
ReloadSound
IdleSound
IdleSoundLength//这些属性都是声音相关
MeleeSound
WarmupSound
WarmupSoundLength
LoopedSound == SpinSound
LoopedSoundLength == SpinSoundLength
CooldownSound//
Mode//自动还是半自动
Scope//是否可开镜
ZoomLevel//放大等级
FOVZoomLevel//广角放大等级
Deployable//是否可放置到地上
ModelScale//模型大小
Texture//枪械材质
DeployedTexture//放置后枪械模型材质
StandBackDistance//猜测是放置的枪械的最小间隔
TopViewLimit//最大射击仰角
BottomViewLimit//最大射击俯角
SideViewLimit//最大射击侧角
PivotHeight//中心点高度
Ammo//可以使用的子弹
NumAmmoSlots == NumAmmoItemsInGun == LoadIntoGun//一次上弹消耗子弹数量
BulletSpeed//子弹速度
CanShootUnderwater//允许水下射击
OneHanded//允许双持武器
SecondaryFunction//不知道
UsableByPlayers//玩家可用
UsableByMechas//机械，再聚可用
UseCustomMelee//使用自定的伤害轨迹
MeleeTime//伤害轨迹时长
AddNode//增加伤害轨迹判定点
MeleeDamagePoint == MeleeDamageOffset//物理伤害点
MoveSpeedModifier == Slowness//拿枪时速度调整(具体量纲不详)
KnockbackReduction == KnockbackModifier//拿枪时击退抗性调整(具体量纲不详)
AllowAllAttachments//允许所有的附加部件
AllowAttachments//允许附加部件
AllowBarrelAttachments
AllowScopeAttachments
AllowStockAttachments
AllowGripAttachments//允许具体的附加部件
NumGenericAttachmentSlots//允许具体的附加部件
paintjob//颜色相关
shield//持枪时伤害吸收

子弹:(位于 com.flansmod-guns-BulletType.class)

FlakParticles
FlakParticleType//粒子效果
SetEntitiesOnFire//让击中的实体着火
HitSound//击中的声音
Penetrates
Penetration == PenetratingPower//子弹穿透，具体量纲不详
Bomb//是炸弹
Shell//炮弹
Missile//导弹
WeaponType//武器类型
HasLight//发光
LockOnToDriveables
LockOnToVehicles
LockOnToPlanes
LockOnToMechas
LockOnToPlayers
MaxLockOnAngle
LockOnForce == TurningForce//锁定相关，具体量纲不详


护甲:
DamageReduction  Defence  增加防御，具体多少因为对MC的API不熟系所以不敢确定
MoveSpeedModifier  Slowness  增加速度，具体多少因为对MC的API不熟系所以不敢确定
JumpModifier 增加跳跃，具体多少因为对MC的API不熟系所以不敢确定
KnockbackReduction   KnockbackModifier 增加击退抗性，具体多少因为对MC的API不熟系所以不敢确定
NightVision 是否夜视
NegateFallDamage 是否免除摔落伤害(确定是免除而不是减少，因为源码中是布尔型)
Overlay 这个不懂，单词原意是覆盖，具体什么作用我没试
SmokeProtection 是否不受枪械烟雾效果的影响(确定是免除而不是减少，因为源码中也是布尔型)
ArmourTexture   ArmorTexture 护甲材质
