今天这个帖子就是为大家介绍怎么在家用电脑上进行开服，而且尽可能的使用能够让大家直接受益的内容。

首先广义上的“开服”一共有两种说法：
第一种则是使用服务端
第二种则是简单的联机

在这里我们先进行介绍使用服务端的方法，想使用家用电脑进行开服的人们可以从这里开始阅读：

1、首先，我们需要一个完整的服务端，我们可以到MCBBS的服务端整合包板块进行下载。
（打开折叠内容可以看到来自minecraft官网提供的开服方式，当然了，在MCBBS中下载整合包更快更简洁，适合新手使用，自主化略低，且部分内容需要后期修改。）
下载 minecraft_server.1.12.2.jar 并运行以下命令：
  1. Java -Xmx1024M -Xms1024M -jar minecraft_server.12.2.jar nogui
复制代码
如果你需要GUI界面，就把命令行最后的“nogui”去掉，去掉“nogui”时不要忘记去掉其前面的空格

2、然后，针对内网玩家，我们需要一个内网穿透方案。
我们有以下方案可供选择：
（一）路由器自带的内网穿透协议（此处指的是虚拟服务器，慎用DMZ功能！）
（二）第三方内网穿透服务
（三）自行搭建的内网穿透服务
其中第三条的困难性较大，在此帖不会进行介绍，但是这里有着详细的教程并且提供完全免费的服务器，安全性适中，此行文本指向的博客文章页面仅是对FRP搭建进行了介绍，并没有对其他的开源项目进行介绍，百度后可以获得其他内容。_(:з」∠)_
我们先从第一条内容进行介绍，我这里是用的是磊科发行的360 p1路由器。一般的路由器的管理界面是 192.168.0.1 或 192.168.1.1 。
下面是按照我的路由器进行的内网穿透操作：
不少路由器，比如Tenda、TP-Link、360、极路由、MI路由等等都可以做到内网穿透（虚拟服务器），具体相应内容请按照型号进行上网查找或者按照购买时的说明书进行使用。
此处在进行声明：慎用DMZ功能！！

接下来讲讲第二条，第三方有很多很好用的免费服务，我们在寻找这种服务是，不应局限于免费这个字眼，更多的应该关注流量、连接个数和是否限制速度。
我前期使用的是Oray花生壳，不过花生壳在花费5元购买完壳域名后，还要花8元进行验证，这也仅仅是获得每月1G流量限制上下行的免费级服务，不得不说这13块花费的一点也不知，1G流量根本不够服务器使用！
nat123也需要支付宝付费认证，最少8元，速度也是没有保障。
我使用的是星云互联和魔法隧道，不过魔法隧道在昨天的测试中注册服务崩了，无法接收验证码，已联系客服，但现在暂时没有受到任何通知...

3、访问
内网用户访问你的服务器的方法：
ipconfig后的ip + : + 端口号
如果你不知道怎么进行ipconfig，可以打开隐藏内容进行查看：
按下 Win键+R键 打开运行，在打开后面的可编辑下拉框中输入cmd，然后点击确定。
在弹出的窗口中输入命令：ipconfig
在含有：以太网、互联网、因特网等字样的项目中找到ipv4地址，这就是你的内网ip。
外网用户访问你的服务器的方法：
内网穿透后的域名或IP + : + 公网端口号
（路由器穿透后的外网IP即为你的公网IP，在这里可以进行查看。）

附加内容：如何把自己的域名作为连接IP进行连接
我这里使用的是freenom的域名，所以以freenom的DNS解析服务为例，国内还有许多优秀的DNS解析服务，例如DNSPod。

进入My Domains后点击箭头所指处，进入DNS解析页面


一般的第三方内网穿透都可以使用自己的域名，你可以使用他们所提供的特定地址进行CNAME记录。值得注意的是，CNAME记录可以记录ip和域名。


【当然，你的TTL值没必要像我的一样这么大，一般900或者600就够了...】


在某个帖子中我曾看到过外网IP可以进行A记录，我有点不太明白。假如我需要把一个域名绑定到我的虚拟主机处，我需要在我的域名DNS解析处进行A记录，然后还需要在虚拟主机处进行别名指向，难道按照帖子中说的只在DNS解析处为外网ip进行A记录解析就可以正常使用了吗？欢迎有懂的朋友对这个问题进行解析。
我的想法是把外网IP在第三方转发服务处进行转发，再将域名做CNAME记录指向转发服务的CNAME服务器。不知是否可行，欢迎补充！

其实家用电脑开服在网络方面还是有三大点受限：1、动态IP或无公网IP（针对使用路由器穿透的玩家）
2、上行受限（家庭网络的下行若达到1M/s 那么上行也仅仅只有100k - 200k/s左右）
3、连接数受限（就算连接数不受限 D3 1600 8G的内存为了保证电脑正常运行也只能设置30-50人左右）
而且开服还会加速硬件损耗 尽管损耗微弱 _(:з」∠)_
