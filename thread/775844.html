应该是这两个插件 不知道怎么设置 ...

第一个没有配置文件的
第二个配置为
  1. # 每10秒钟限制一个IP能发送MOTD请求数，超过这个数则判定为MOTD压测，加入黑名单（防MOTD压测）pingPacketIn10SecPerIP: 20
  2. # 每10秒钟限制一个IP的玩家能加入服务器多少次，超过这个数则判定为加入压测，加入黑名单（防假人压测）joinRequestIn10SecPerIP: 5
  3. # 当一个IP发送过多的MOTD请求后，屏蔽多少秒banTimeOnOverclockingPing: 20
  4. # 当一个IP请求加入服务器次数过多后，屏蔽多少秒banTimeOnOverclockingJoin: 30
  5. # 当检测到任何类型的压测时是否通知后台warningConsole: true
  6. # 当检测到任何类型的压测时是否通知在线的OPwarningOPs: true
  7. # 白名单列表，建议不要手动编辑，而使用添加白名单命令whitelist: []
复制代码

建议把joinRequestIn10SecPerIP适当调大点和banTimeOnOverclockingPing适当调小点
