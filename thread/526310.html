前几天我写了个贴，审核通过了不知道为啥别人都看不见，就我自己能看见，我复制下来给你看：
一、CPU
       CPU是服务器最核心的部分没有之一，分为计算器和控制器...(扯远了)，CPU的性能直接影响到了开服后游戏的流畅程度。以下内容引用自这篇帖子：
  • 如果 真核数 <= 8 则 基数 = CPU 真核数 x 最高睿频
  • 如果 真核数 > 8 则 基数 = CPU 真核数 x 默认主频
  • 如果手动超频则 基数 = CPU 真核数 x 全核心最高同步主频（不过超频的玩家基本都不会需要看这一节吧）
  • 如果为 Intel CPU 则 基数 x 1.7
  • 如果支持并开启超线程则 基数 x 1.5
  • 如果默认主频 < 2GHz 则 基数 x 0.9
  • 自己CPU的各种参数，百度一下便有，不用问我。如果最终结果 > 18 的话，开一个二十人以下小型服务器问题不大； > 30 的开六十人以下的中型服务器无压力。大型服务器？你确定你有在认真读？

附：最高睿频就是CPU超频后的最大主频。具体查看方法就是下载一个CPU-Z，下载地址百度有很多，当然这个网盘也有(论伸手党的胜利。密码：f2h3)，按照上面的公式(就好像初中学的分段函数)计算完成后比对第七条，计算自己的服务器的CPU能带多少玩家。
另外总觉得CPU实际的承载力始终比计算值要低一些，可能是MC服务端本身对多核心CPU的利用就不好，但是群组服却能很好地利用多核心。
二、带宽
       带宽是租用服务器(或VPS)最贵的项目之一。一般来说都是以5M、10M或者是20M为主(上次还看见有50M的，不过贵的要死)，VPS        VPS可以自己分配带宽。注意，不要因为带宽很贵就降低标准。
       在服务器中上传带宽更重要，而家用机正好相反(这也是不提倡用家用机开服的原因之一)
       在这里讲一下MBps和Mbps的区别：我们平时说的“20M宽带”中的“M”是“Mbps”。不要忽略了这个大小写，Mbps和MBps是两个不同的单位，比率是【8bps = 1Bps】也就是说，20M宽带的理论速度只有20 / 8 = 2.5M每秒。服务器中的每个玩家需要大概12KBps的上行带宽。按照单位换算一下，20M带宽能带动 ((20÷8)*1024)/12 = 213 个玩家(关于你服务器带宽承载力的算法：（[(X / 8) * 1024] / 12，将X换为你的购买的带宽就行。当然如果你计算器都懒得开，就用这个小程序吧,37KB。密码：i8pw，输入带宽就能计算人数。C++编写，安全无毒
       ps：看到这里大家就能发现某宝上的只用内存大小决定人数的方法是不负责任的。况且很多供应商的接入带宽只有可怜的5M，但是只因为分配高内存就把人数定为100人，实际上这样还是会很卡。
三、内存
（本节部分文本由 @zlzchuyue 协助编写）
       关于内存的所用在前面已经说明，这里就不再赘述。
       关于服务器内存大小的建议：一般来说，在纯净服为每8到9个玩家分配1G内存可以不卡。MOD服中安装的各种MOD（特别是像暮色或者是神奇宝贝这类的MOD）要吃掉不少内存，MOD服内存自己估计着分配，安装的MOD不同额外消耗的内存也不同。
       安装内存和分配内存的区别：安装内存是指服务器实际安装的内存，在上面那个CPU-Z软件可以查看，各种检测软件也可以查看，在“我的电脑”上右击点开“属性”也可以查看。分配内存就是你分配给你的服务端的内存。分配内存需要在比如我的服务器安装内存是32G，假如我分配1G内存就意味着服务端只能利用1G的安装内存，对这个服来说剩下的31G就是浪费掉了(因为没有被利用)。所以一般来说在只有一个服务端的情况下分配内存占用整个系统的安装内存96%比较合适，当安装内存很大时可以设置为98%左右(原因是java本身还有其他的一些电脑的系统应用还要消耗一部分内存)
       关于分配内存的设置在启动脚本那里也不会写到，因为大家都知道怎么设置
(有的服务器安装内存能达到128G，快赶上我电脑上的一块硬盘了...真吓人...)
四、外存
       这里的外存是指服务器搭载的硬盘的容量。如果一台服务器上只搭载一个服务端，那就除了系统盘之外再有一个盘就够。如果是搭载多个服务端的话最好是每个盘放一个服务端(当然这只是为了方便管理方便)
       外存的大小其实无所谓。外存容量很便宜，1块钱能买好多好多的容量。就照多了买吧(少吃一包辣条就能买十几个G)。但是我认为对外存空间的利用却是一个服能长久运行下去的保障
       井井有条的风格可以使开服更加顺畅，当出了问题也容易找到问题文件的地址。如果是自己存的东西自己都找不到，那开服就比较难受了。当然，有大神喜欢乱糟糟那就当我没说。另外楼主的强迫症八成治不好了.....233
