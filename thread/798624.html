我想让插件实现这样的：
sender发出了一条命令。
然后全局发送几条信息

如果玩家点了参加就怎样怎样的
有什么方法可以实现？

**首先能点的那个东西叫Tellraw, 1.7的新东西**

### 具体思路:
  - 首先我假设你会写指令，那么首先要构建出我们需要的tellraw json数据，然后进行遍历所有玩家的操作

### 那么写json数据的操作可以有以下几种我只给出教程
1. 使用md_5的ChatComponentAPI写json数据并发给玩家 [教程 赞美耗子]
2. 自己写json数据 [教程]
3. 调用类库 [我的垃圾类库]

#### 以下适用于 2 3 两种形式  (使用了Java8的一些语法)
// json数据
String json = "省略...";

Bukkit.getOnlinePlayers().forEach(player -> {  // 其实质就是给在线玩家都发送 /tellraw <玩家名> [json数据] 这个指令，如果你觉得不优雅的话可以试着用发包
  Bukkit.dispatchCommand(Bukkit.getConsoleSender(), "tellraw " + player.getName() + " " + json);
});
