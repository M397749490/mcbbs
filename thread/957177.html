AntiAC is a plugin which should prevent / avoid the use of Auto Clicker.

Config


原理
插件会记录玩家的点击次数，当达到所允许的范围内会做出一些禁止他们点击的次数。比如说kick/ban等等等等


效果图


指令
               
  


权限
应该就只有这个了..
-antiac.clicks

效果展示
踢出服务器
封禁玩家
被踢出的玩家还有聊天栏的警告
还有个“冻结”玩家
这个功能我没搞懂
如果有知道的可以告诉我一下

特♂殊的功能
可以生成Log,并且你可以设置多少天删除Log
