让玩家坐在椅子上(更新至1.9)

【注意】本插件需要protocollib前置插件
下载地址http://dev.bukkit.org/bukkit-plugins/protocollib/files/

安装方法
-将文件放入服务器plugins文件夹
-设置玩家的权限

如何正确食用
-仅需右键椅子方块(台阶)即可坐在椅子上
-配置文件中可以设置互动距离、椅子形状(两边有木牌)、椅子最大宽度
-按潜行(shift)键站起来

命令和权限
chairs.reload /chairs reload 重载配置文件
chairs.sit - 能坐在椅子上
chairs.sit.health - 坐着能够回血

原文内容
  1. About Chairs Reloaded

  3. This is a reload of the original Chairs mod by Spoothie. That plugin was no longer being updated so I have continued it here.

  5. This plugin allows players to sit in chairs (steps).

  7. Chairs-Screenshot

  9. Installation

  11. Drop the Chairs jar file in your plugins directory.
  12. Setup permissions accordingly.
  13. How To

  15. To sit down on a chair, you simply have to right click on the stairs-block.

  17. If you have set the "distance"-option to a value higher than 0, you have to be close enough to the chair to be able to sit down.
  18. If you have the "sign-check"-option enabled, there have to be signs at the end of the chair/row of chairs to be able to sit down.
  19. If you have set the "max-chair-width"-option to a value higher than 0, the chair/row of chairs must not be longer than this value.
  20. To stand up from a chair press sneak.
  21. Commands & Permissions

  23. chairs.reload

  25. /chairs reload - Reload the Chairs configuration file.
  26. chairs.sit

  28. Sit down on chairs.
  29. chairs.sit.health

  31. If the health sitting effects are enabled then players with this permission node are healed while siting.
  32. Change Log

  34. Source

  36. Github

  38. Development builds

  40. Development builds of this project can be acquired at the provided continuous integration server. These builds have not been approved by the BukkitDev staff. Use them at your own risk.
