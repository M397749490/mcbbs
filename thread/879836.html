开源地址
https://github.com/Reckfullies/View-Only-Chests


作者认为他只能让插件支持1.14+(因为用到的是 data API)


插件内容非常简单 让你创建一个只能被打开但是不能从里面拿东西的只读箱子
你也可以作为展示各种kit的箱子

权限
  • vochests - 使用help指令
  • vochests.create - 允许创建只读箱子
  • vochests.delete - 允许删除只读箱子
  • vochests.edit - 允许修改只读箱子(当然是给op的)
  • vochests.view -允许打开只读箱子


指令
  • / vochests - 帮助信息
  • / vochests create - 把你准星指向的箱子变成只读箱子
  • / vochests delete - 把你准星指向的只读箱子变成普通箱子
