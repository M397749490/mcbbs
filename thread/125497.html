标题: 轉發【密技】4bit亂數產生器+類比解析器
今天要發的是4bit的亂數產生器
這有什麼功用呢?

可以拿來做抽獎機之類的東西。
這個的主體是用比較器的減法原理


由下往上分別是-1,-2,-4,-8
-0 => 15
-1 => 14
-2 => 13
-1,-2 => 12
-4 => 11
-1,-4 => 10
-2,-4 => 9
-1,-2,-4 => 8
-8 => 7
-1,-8 => 6
-2,-8 => 5
-1,-2,-8 => 4
-4,-8 => 3
-1,-4,-8 => 2
-2,-4,-8 => 1
-1,-2,-4,-8 => 0
然後這是1bit亂數產生器的本體




第一張圖是投擲器投出不可堆疊的物品，會發出3格信號，讓火把熄滅
第二張圖是投擲器投出可堆疊的物品，會發出1格信號，火把就不會熄滅了。
