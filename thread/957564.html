掉落表[Drop tables]

自定义掉落常常是人们容易忽略的东西，其提供的功能比mythicmobs里的Drops更强，自定义属性不弱于机制，如果你想为你服务器添加一些好玩的东西，这也许是个好选择
Droptables基本格式如下
  1. 掉落表名称:
  2.   TotalItems: <amount>
  3.   MinItems: <amount>
  4.   MaxItems: <amount>
  5.   BonusLuckItems: <multiplier>
  6.   BonusLevelItems: <multiplier>
  7.   Conditions:      
  8.   - 条件
  9.   TriggerConditions:
  10.   - 条件
  11.   Drops:
  12.   - <物品/经验/掉落表> <数量> <几率>
  13.   - cmd{c="Kill 烙铁"}
  14.   - cmd{c="tell <trigger.name> 我是烙铁，我喜欢你"}

Variables

Variables变量模块
MM自身拥有一个单独变量模块，他无法使用Papi的变量，就很麻烦麻烦
于是他位于4.6版本推出了自定义变量模块，可以把Papi变量转化成MM自己的变量
变量模块提供了  
三个类型
INTEGER              整数(栗子：5)
FLOAT                   浮点数(栗子: 5.44545645879)
STRING                句子(烙铁烙铁爱大米)

五个目标
SKILL               技能组内，使用后消失
CASTER            怪物自身
TARGET            攻击目标
WORLD            世界
GLOBAL            服务器
五位一体化，三类合一用

首先来看看，如何设置一个变量
初始设置变量时使用的是 setvariable
他有如下选项
variable    变量名字
value         变量数值
scope        五个目标
type           三个类别
save          是否储存(不适用于Skill目标)(默认false)
duration   是否限时(默认不限时)

设置目标时我们有两种设置方法
  1. setvariable{var=目标.变量名字;....}
  2. setvariable{var=变量名字;scope=目标;...}
  3. 实例：
  4. setvariable{var=caster.test;type=STRING;value="瓜皮烙铁"}
  5. setvariable{var=test;scope=caster;type=STRING;value="瓜皮烙铁"}
复制代码
两个效果一样，自己喜欢哪种就选择哪种，如果叠加使用会报错

设置数值时我们可以设置Papi变量进入，但是Papi变量反馈出来的
必须是对应的类别(整数，浮点数，句子)
  1. setvariable{var=caster.test;type=STRING;value="%OrangeGood%"}
  2. setvariable{var=test;scope=caster;type=INTEGER;value="%SolderingIron_Low%"}

Aura不是一个技能，是技能内的一个大模块
Aura是什么？
他是一个 状态
你拥有这个状态，你可以触发什么
有什么条件你可以触发什么技能
你可以用他来设置生物攻击拥有这个状态的人

[MM常见问题集合]

我设置的怪物血量很大
但是召唤出来只有20血量
Spigot默认设置最大血量为2000，超过两千则怪物血量为20，可以通过修改服务端里面的spigot文件夹来进行修改最大血量

Projectile技能打不到怪物
Projectile技能默认不击打实体，需要添加hnp=true选项，这样才可以攻击到实体

粒子类技能使用后踢出玩家
并显示一大串字符
是因为你写的粒子种类出现了Bug，请仔细查询Mcwiki的粒子表

Artifact附属如何添加技能？
就像写怪物一样，在下方添加Skills就行，记得对正哦

第二步，检查怪物的技能触发是否正常
第三步，检查技能是否有wiki没有的，不对版本的，自己凭空想的

做成一个个块状，然后拼接，这样错误好排查
