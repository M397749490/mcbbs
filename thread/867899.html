Config.yml  ——  配置文件


搭配这个设置指定世界圈地功能
  
Optimizations:
    # 这个是领地插件默认的世界. 默认的世界是 'World'. 这个选项最好与 essential 的设置相匹配
    DefaultWorld: world
    DisabledWorlds:
      # 禁用插件的世界列表
      #下面是我的几个例子，
      #你可以把不要圈地的世界名写在下面
      List:
      - plotworld
      - world_nether
      - world_the_end
      - PVP
      # 在禁用的世界中,是否禁用世界的监听器(监听器:插件运行需要的东西，禁用后在此世界无法使用领地)  
      DisableListeners: true
      # 在禁用的世界中,是否禁用所有的领地指令
      DisableCommands: true
