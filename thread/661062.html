Action Bar Health

本插件依赖JAVA8+

插件简介
此插件可以实现在物品栏上方显示你所攻击生物的血量，完全自定义！
并且兼容多种插件，可在指定世界禁止

区域支持:
WorldEdit
WorldGuard

变量支持:
PlaceHolderAPI
MVdMPlaceHolderAPI

怪物支持:
Mythcimobs

语言支持:
LanguageUtils

命令&权限
/ActionHealth reload —— 重载插件
/ActionHealth toggle —— 开关血量显示
ActionHealth.Reload —— 重载插件权限
ActionHealth.Reload —— 重载配置文件
ActionHealth.Toggle —— 开关血量显示
ActionHealth.Health —— 只有在配置文件启用 Use Permissions 才有效
插件变量
{name} —— 你所攻击的生物的名字
{health} ——你所攻击的生物的血量
{maxhealth} —— 你所攻击的生物的最大血量
{usestyle} —— 血条的风格(请在配置文件中改)

配置文件
# 发送给玩家的血量信息
# {name} 目标的名称.
# {health} 目标的血量.
# {maxhealth} 目标最大血量.
# {usestyle} 显示风格.
# {displayname} 显示自定义名称(例如Mythicmobs自定义名字).
# {opponentlastdamage} 显示最后一次收到的伤害.
# 支持 PlaceholderAPI 和 MVdWPlaceholderAPI.
Health Message: '&7&l{name}: {usestyle}'

# 如果设置为空则显示上面的信息.
# 此信息发送给非玩家的实体.
# {name} 玩家的名称.
# 支持PAPI.
Non Player Message: ''

# 禁止血量时发送给玩家的消息.
# {name} 玩家的名称.
Toggle Message: ''

# 开启血量显示时发送的信息
# {name} 玩家的名称.
On Enable: '&7血量显示已 &c开启&7.'

# 关闭血量显示发送的信息
# {name} 玩家的名称.
On Disable: '&7血量显示已 &c关闭&7.'

# 移除名称.
Strip Name: true

# 如果启用则需要此权限 ActionHealth.Health 才能显示
Use Permissions: false

# 显示怪物的血量
Show Mob: true

# 显示玩家的血量
Show Player: true

# 显示NPC的血量
Show NPC: true

# 开启后将延迟发送给玩家血量状态，有利于精准获取血量信息(RPG武器额外增加的伤害获取更精准).
Delay Message: false
# 时间(秒)
Delay Tick: 1

# 血量风格
Full Health Icon: "&4\u2764" 心
Half Health Icon: "&c\u2764" 心
Empty Health Icon: "&7\u2764" 心

# 在指定的世界禁止血量显示
Disabled worlds:
  - randomworld

#在指定区域禁止血量显示(WorldGuard)
Disabled regions:
  - testing_region

# 在禁止PVP的区域禁止血量显示
Region PvP: true

# 显示血量风格的最大限制 ?
Limit Health: 10

# 保存玩家切换血量显示的数据
# 使用文件存储，如果对SQL感兴趣可以向作者反馈哦
Remember Toggle: false

# 名称黑名单
#添加后指定的名称不会显示在血量信息中
# 支持 Mythicmobs 的自定义名称！！！
Blacklist:
  - 'CCPD Officer'

# 指针显示目标血量的距离
Show On Look: true
Look Distance: 10

# 显示血量状态前检测玩家指针是否对准目标
Can See: true

# 如果实体处于隐身状态则隐藏血量显示
Invisible Potion: true

# 实体处于观察者状态则隐藏
Spectator Mode: true

# 是否显示 MiniaturePets 宠物的血量状态
ShowMiniaturePets: true

# 翻译名称，区分大小写！
# 如果您计划使用的语言已存在翻译，请检查ActuonHealth界面.
#
# 如果使用自定义翻译的服务器将它们与我们共享，我将不胜感激!
# 对于这样做的用户，我将在Spigotmc贴内标记他们并且显示他们的IP.
Name Change: false
Name:
  - Snow Golem = New name

# 使用客户端语言翻译名称，需要安装LanguageUtils
# https://www.spigotmc.org/resourc ... anguage-utils.8859/
Use Client Language: false

# 如果启用，当玩家进入战斗时，他们将在可配置的时间内被标记.
# 当敌人出发操作时，将发送配置的消息.
# 支持PlaceholderAPI.
# 支持的事件: CONSUME, RIGHTCLICK, LEFTCLICK, SWAP
# 消耗，右键点击，左键点击，切换
Action:
  Enabled: false
  # 时间(秒)
  TagLength: 20
  # 玩家在战斗中可以标记玩家的数量，-1表示无限制
  TagAmount: 2
  Events:
    CONSUME:
      GOLDEN_APPLE: '&7&l{name} 消耗 &c金苹果&7&l!'
      REGENERATION_POTION: '&7&l{name} 消耗 &c再生药水&7&l!'
    RIGHTCLICK:
      ENDER_PEARL: '&7&l{name} 使用 &c末影珍珠&7&l!'
    SWAP:
      ENDER_PEARL: '&7&l{name} 切换至 &c末影珍珠&7&l. {usestyle}&7&l'
      POTION: '&7&l{name} 切换至 &c药水&7&l. {usestyle}&7&l'

血量风格

心形:

[tr]Health Message: '&6&l{name}: {usestyle}'

[tr]Full Health Icon: "&4\u2764"

[tr]Half Health Icon: "&c\u2764"

[tr]Empty Health Icon: "&7\u2764"


方块形:

[tr]Health Message: '&6&l{name}: {usestyle}'

[tr]Full Health Icon: "&a&l\u2588"

[tr]Half Health Icon: "&a\u258c"

[tr]Empty Health Icon: ""


竖杠形:

[tr]Health Message: '{name} - &c[{usestyle}&c]'

[tr]Full Health Icon: "&c\u007C"

[tr]Empty Health Icon: "&4\u007C"
