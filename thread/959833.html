如何正确的在高版本使用LWC

在你配置插件之前请先安装插件
1.12.2请用2.0.7版本（否则有可能不会触发落地锁）
1.13及以上版本请用最新版本
MCBBS的插件搬运帖:https://www.mcbbs.net/forum.php?mod=viewthread&tid=892322
喵哒的教程帖：https://www.mcbbs.net/thread-937835-1-1.html
关于安装插件就不再说明了

配置文件core.yml(仅供参考

  1. #核心内容
  2. core:
  3.     #语言文件 填cn就是中文语言
  4.     locale: cn
  5.     #数据更新频率(单位：s) 请勿设置为大于10
  6.     flushInterval: 10
  7.     #LWC自带的定期的本地缓存保护，防止插件频繁访问数据库，默认是10000
  8.     cacheSize: 10000
  9.     #启动插件时预缓存多少本地缓存保护保护，-1是使用cachesize的值并尽可能预缓存
  10.     precache: -1
  11.     #显示LWC创建保护的相关信息
  12.     showNotices: true
  13.     #显示对于我的相关信息（例如打开一个被自己设置保护的箱子，它会发送通知。设置false则关闭）
  14.     showMyNotices: false
  15.     opIsLWCAdmin: true
  16.     disableHistory: false
  17.     townyBorders: false
  18.     groupPrefix: group.
  19.     #更新提示
  20.     updateNotifier: false
  21. #可选参数
  22. optional:
  23.     #是否开启“保护仅在玩家在线时生效”
  24.     onlyProtectWhenOwnerIsOnline: false
  25.     #是否开启“保护仅在玩家离线时生效”
  26.     onlyProtectWhenOwnerIsOffline: false
  27.     #设置阻止被LWC管理员清除的物品id
  28.     exemptBlocks: []
  29.     optOut: false
  30.     #禁止玩家在受到保护的方块附近放置下列黑名单方块
  31.     blacklistedBlocks:
  32.     - '166'
  33.     - HOPPER
  34.     blacklistedPlayers:
  35.     - player
  36.     #是否开启使用保护限制(推荐开启)
  37.     useProtectionLimits: true
  38. #数据储存 可以选sqlite或者mysql
  39. database:
  40.     adapter: sqlite
  41.     path: plugins/LWC/lwc.db
  42.     host: localhost
  43.     database: lwc
  44.     username: ''
  45.     password: ''
  46.     prefix: lwc_
  47.     ping_interval: 300
  48. #保护设置
  49. protections:
  50.     #防止红石启用的门和其他相关的方块
  51.     denyRedstone: false
  52.     #在默认情况下禁止使用漏斗，请使用/lwc flag hopper on在游戏内使用漏斗
  53.     denyHoppers: true
  54.     #是否在放置方块后立刻锁定方块
  55.     autoRegister: false
  56.     #Whether block breaks will be processed. Do not enable this unless you know what you're doing.
  57.     ignoreBlockDestruction: false
  58.     #忽略对受保护方块的左键事件
  59.     ignoreLeftClick: false
  60.     #忽略对受保护方块的右键事件
  61.     ignoreRightClick: false
  62.     #是否允许爆炸破坏受保护的方块
  63.     ignoreExplosions: false
  64.     #是否允许实体破坏门（指僵尸之类的）
  65.     allowEntityBreakDoor: false
  66.     #是否允许其他实体与受保护的方块交互
  67.     allowEntityInteract: false
  68.     #
  69.     quiet: false
  70.     #如果设置为true，将禁止玩家修改他们设置的保护，只有LWC管理员才能修改
  71.     readonly-modify: false
  72.     #如果设置为true，将禁止玩家破坏他们设置的保护，只有LWC管理员才能破坏
  73.     readonly-remove: false
  74. #自动上锁配置
  75.     blocks:
  76.         chest:
  77.             enabled: true #是否启用保护
  78.             autoRegister: private  #保护类型
  79.         furnace:
  80.             enabled: true
  81.             autoRegister: private
  82.         sign:
  83.             enabled: true
  84.             autoRegister: private   
  85. #模式（没看懂原文什么意思）
  86. modes:
  87.     #是否开启掉落的物品会被自动放在附件的箱子里
  88.     droptransfer:
  89.         #是否开启
  90.         enabled: true
  91.         #横跨世界？
  92.         crossWorld: false
  93.     persist:
  94.         enabled: true
复制代码

                                          指令部分
  (转载自MCBBS搬运帖 ，微改)
  • /cpublic - 创建一个公共箱子，任何人都能打开它。
  • /cprivate (/lock)- 创建一个私人箱子，只有你（还有你添加的人）才能打开它。
  • /cpassword - 创建一个密码箱，只有知道密码的人才能打开它。
  • /cmodify - 修改受LWC保护容器的配置，你可以用它添加你信任的玩家或者权限组。
  • /cunlock - 解锁受密码保护的容器。
  • /cremove (/unlock)- 解锁受LWC保护的容器。
  • /cinfo - 查看一个受LWC保护的容器的信息。
  • /climits - 查看你已经锁过的容器数量。
  • /lwc flag <flag名字> <on/off>
    所有可供使用的flag名字: (相关配置选项请看core.yml)
    redstone - 如果打开, 红石将能够影响这个受保护的容器。
    magnet - 打开后，容器会自动吸取附近的掉落物。
    autoclose - 如果受保护的方块是门, 在打开后会帮你自动关上。
    AllowExplosions - 打开后, 爆炸会摧毁受保护的箱子。
    hopper - 打开后, 漏斗可以放入/取出箱子内的物品。
  • 管理员命令:
    /lwc admin view - 查看一个受保护的箱子,admin要在受保护的箱子旁边(其实并无卵用)
    /lwc admin find - 列出一个玩家所有锁上的容器
    /lwc admin forceowner - 强制修改一个锁住的容器的拥有者
    /lwc admin remove - 移除一个受保护容器的保护
    /lwc admin purge - 删除玩家所有锁上的容器
    /lwc admin cleanup - 清理 LWC 的数据库
    /lwc admin version - 查看服务器使用的 LWC 版本
    /lwc admin update - 更新至最新版的 LWC
    /lwc admin report - 查看 LWC 的性能报告
    /lwc admin convert - 转换其他保护插件的数据库
    /lwc admin clear - 从受保护的容器中删除所有保护或所有权限
