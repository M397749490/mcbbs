Instruction
介绍
一个Fabric mod，在屏幕上显示按下的按键(W,S,A,D,左右键等)，并支持显示CPS

Features
特性
支持显示除按键以外的其他信息（比如潜行等）
自定义位置，自定义颜色，自定义字体

Commands
指令
/keystrokes 打开设置界面
/keystrokes reload 重载设置界面
/keystrokes save 保存设置

展示


Installation
安装
确保你安装了最新版本的Fabric Loader，Fabric API，modmenu。另外，在1.14.4和1.15.2版本中, 你需要安装Cotton Client Commands作为前置

Reporting Issues
汇报漏洞
