作者: 我的世界城市服    时间: 2015-5-14 22:05
指令篇:
/op id 给予某玩家op
/deop id 取消某玩家op
/gamemode 0/1 id 给予某玩家生存/创造模式
/ban id/ip 封禁不解释
/difficulty 0/1/2/3 分别是和平/简单/一般/困难
/give id 物品代码 给予某玩家某物品
/sethome 设置家
/home 回家
/kick id 踢出某玩家
/kill id 杀死某玩家
/time set 数字 改变时间
/spawnpoint id x y x 设置某玩家重生点
.
tp 指令
/tp id 传送到某玩家处
/tp id1 id2 将玩家1传送到玩家2处
/tp id x y z 将某玩家传送到某坐标处
.
其他的插件指令就不发了
