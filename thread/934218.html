TickTime
下载
MC以秒为单位的时间计算可能会导致不公平的劣势
此插件能帮助你写的插件和游戏内的Trick统一
任何方式计算时间的插件中，都必须具有此轻量级的API
虽然通常使用System.nanotime()是可行的解决方法
但由于滞后，插件，玩家，实体，盔甲架等原因
像MC中那样计算时间可能会导致一些不一致
使用TickTime，你可以计算Minecraft的时间间隔，因此测量值将与世界，实体，玩家等保持一致
TickTime没有命令，没有权限，也没有事件，因此只需将其拖放到你的plugins文件夹中即可

使用TickTime

  1. long time0 = TickTime.currentTickTime();

  3. letsMakeSomeCode();

  5. long time1 = TickTime.currentTickTime();

  7. // calculate time between ticks!
  8. long time_taken = time1 - time0;

  10. // 1 second = 20 mc ticks
  11. long seconds = time_taken / 20;

开源

  1. package dev.ckitty.mc.ticktime;

  3. import org.bukkit.plugin.java.JavaPlugin;
  4. import org.bukkit.scheduler.BukkitRunnable;

  6. public class TickTime extends JavaPlugin {

  8.     private static long TICK_TIME;

  10.     public static long currentTickTime() {
  11.         return TICK_TIME;
  12.     }

  14.     private Timer timer;

  16.     @Override
  17.     public void onEnable() {
  18.         timer = new Timer();
  19.         timer.runTaskTimerAsynchronously(this, 0, 1);
  20.     }

  22.     @Override
  23.     public void onDisable() {
  24.         timer.cancel();
  25.         timer = null;
  26.     }

  28.     private class Timer extends BukkitRunnable {

  30.         @Override
  31.         public void run() {
  32.             TICK_TIME++;
  33.         }
  34.    
  35.     }

  37. }
复制代码

TickTime.currentTickTime()给出的值在服务器关闭后不一致，但在使用/reload命令之后
你不必担心TICK_TIME变量可能会溢出
即便如此System.nanotime()在服务器运行使用中也会造成一些溢出
因此，请每隔几天重新启动服务器
