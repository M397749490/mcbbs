让别人不能在我的领地内放方块？

一个领地初步建立后就已经禁止拥有者之外的玩家在领地内放置或破坏方块了。
默认的领地权限是：
  1. ResidenceDefault:
  2.         build: false
  3.         use: false
  4.         container: false
  5.         pvp: false
  6.         tnt: false
  7.         creeper: false
  8.         flow: false
  9.         piston: false
  10.         ignite: false
  11.         firespread: false
  12.         piston: false
复制代码
而默认的领地拥有者则具有以下权限：
  1. CreatorDefault:
  2.         build: true
  3.         move: true
  4.         use: true
  5.         ignite: true
  6.         container: true

禁止某些人进入我的领地？

对于名为 player1 的玩家 ，禁止他进入的方法是：
你站在领地内，打如下命令
/res pset player1 move false
回车
