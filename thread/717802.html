前言（可以不用看）

可能有人会说这个插件比较鸡肋
但是！我之前找了半天，都没有找到一个支持多行消息的BC公告插件！
所以我自己写了一个并顺手发到了这里
所以觉得插件渣的别喷了，浏览器右上角点一个叉，就清静了



介绍
这是一个比较目前厉(la)害(ji)的BC公告插件
定时发送指定消息（不是废话吗）
轻量
支持一次发送多行消息（如果不懂请继续往下看）


这大概就是这个插件目前的功能，不过，后续我也会添加更多的功能，比如tellraw的消息等等


使用方法
  • 下载该插件并放到bc的plugins文件夹
  • 重启bc端
  • 找到plugins/BungeeAnnouncer/config.yml，配置相关的信息
  • 配置完成后重启bc端，完成！

默认配置下的使用截图:



配置文件(UTF-8编码)

  1. timer: 120
  2. #发消息的间隔，单位为秒
  3. Order:
  4.   - 'example'
  5.   - 'example2'
  6.   - 'example3'
  7. #消息的顺序，插件将根据间隔从上往下播报
  8. Messages:
  9.   example:
  10.     - '&a&l&m========================'
  11.     - '&b欢迎使用BungeeAnnouncer!'
  12.     - '&a&l&m========================'
  13.   example2:
  14.     - 'Welcome to use BungeeAnnouncer!'
  15.     - 'This is a second-row message!'
  16.   example3:
  17.     - '作者博客: http://www.zhanshi123.me 欢迎参观'
  18.     #如果需要添加网页链接 请尽量在网址两边空格 以免程序识别错误
  19. #配置消息:
  20. # 消息名:
  21. #   - '内容 第一行'
  22. #   - '内容 第二行'
  23. #编辑完后记得在order中添加顺序，否则不会启用
复制代码
注意，网址必须以http或https开头


插件命令


/ba 查看帮助
/ba reload 重载插件
/ba send <消息名> 发送消息


命令均需要bc权限 ba.admin
(如果在游戏中输入/ba查看帮助，把鼠标移到你想要使用的命令上右击，是可以直接把命令复制到聊天栏的哦)
