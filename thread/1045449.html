谁知道1点14怎么利用胡萝卜钓竿来检测玩家是否右键，并以此来增加记分榜
作者: 晴路卡    时间: 2020-5-14 15:42
首先创建一个记分板，该记分板的判据会使得玩家每次右键胡萝卜钓竿就自增1
  1. /scoreboard objectives add test minecraft.used:minecraft.carrot_on_a_stick
复制代码

然后按顺序高频执行下面这些命令检测玩家右键
当test的分数高于0时，检测玩家手中的物品是否为名字为a
符合条件则执行命令，并且把test的分数重置为0
  1. execute as @a[scores={test=1..}] if data entity @s {SelectedItem:{id:"minecraft:carrot_on_a_stick",Count:1b,tag:{display:{Name:'{"text":"a"}'}}}} run say 233
  2. scoreboard players set @a[scores={test=1..}] test 0
复制代码
