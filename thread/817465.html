嘿大家好，上一次给大家带来，破解面板服务器端口限制的插件这次，给大家介绍一款新插件，使用QQ群来验证
这个插件上手的程度并不难，可以说是一些服主的福利吧

提醒：
这个插件花了几个小时开发，功能不是很全面，所以会出现不少的bug，后期慢慢的修复的，毕竟暑假结束了qwq
声明一下，酷Q和游戏服务端暂时得在一个服务器里面，当时脑抽忘记把自定义连接服务器写出来
效果图：




使用方法：
声明一下
该插件属于开发阶段，有很多的地方不完善，如果有问题可以加交流群：468745984 艾特群主提问

准备材料：
    游戏， 服务端，酷Q机器人(可以使用Air版 (ps:免费的))

1.  文件“win.mc10.login.cpk”是放在酷Q机器人里面的
2.  文件“[酷Q登陆]SimpleExternalLogin.jar”是放在服务端下的

SimpleExternalLogin插件配置：
插件放完后先启动服务器，之后等待服务器加载完成后关闭服务器，在控制台输入stop，在插件的目录下会生成SimpleExternalLogin文件夹，点进去
用记事本打开config.yml文件，在QGroupNumber：后面输入你的群号，例如QGroupNumber: 468745984，这里的468745984是我的群号
之后保存关闭，启动服务器

酷Q插件配置：
把win.mc10.login.cpk插件放在酷Q目录下的app文件夹里面，打开酷Q，右键托盘下的酷Q图标
应用 -> 应用管理打开找到Simple外置登陆，启用
之后点回控制台看看控制台有没有出现：

[酷Q登陆]认证客户端登陆到服务器！

这样一串字，如果有的话恭喜你搭建成功了！，如果没有那么继续一样右键托盘下的酷Q图标
应用 -> Simple外置登陆 -> 重新连接服务器
点一下回到控制台看看即可【注意这招日后机器人没反应的时候也能用qwq】

【最后一点注意了：千万不要忘记把机器人拉进群里qwq】
【请留意一下帖子 http://www.mcbbs.net/thread-817465-1-1.html 可能随时更新新东西】

基本命令
1. 在群内发送 #绑定账号 游戏名称，例如 #绑定账号 Rain_Ning
2. 玩家进入服务器后，在群内发送 #确认授权 游戏名称 来登陆，例如 #确认授权 Rain_Ning
3. 在群内发送 #连接服务器 即可重新连接到验证服务器，当机器人没反应的时候可以使用

更新日志：
【1.0.4】
1. 增加指令“/setloginspawn”设置登陆出生点 (在指定位置出生，登陆成功后返回上一次退出游戏时的位置)
2. 可以在config配置文件里面设置是否允许使用设置登陆出生点的地方登陆“isSpawn: true”
3. 优化全屏提醒，现在可以开和关了“FullDisplay: true
4. 优化登陆位置，设置出生点后可以在出生点登陆后传送回原来的位置
5. 修复使用qqupdata命令无法检测更新

【1.0.3】
1. 增加全屏提示
2. 增加控制台新命令setqgroup，可以使用命令来绑定Q群
3. 增加了没登陆的时候失明效果
4. 优化了提示，防止被刷屏刷掉
5. 修复了机器人不理人的问题，等部分bug

【1.0.2】
1. 增加了变量，在配置中可以使用%player%来获取玩家名字
2. 增加登陆命令，当玩家登陆成功后会执行配置文件里配置的插件
3. 将配置文件里的§改为&，可以使用&来改变字体颜色
4. 修改了配置的创建方式，之前是玩家进入才会创建配置
5. 修复了玩家未登录的情况下会受到伤害，以及部分bug
6. 可以在控制台输入qqupdata，来检测插件是否有更新

【1.0.1】
1. 酷Q插件新增自定义连接服务器地址（在配置文件里修改）
2. 新增命令，管理员或群主在群内发送 #连接服务器 即可连接到验证服务器（群内机器人没反应的时候可以使用）
3. 新增限制玩家绑定账号数量，在服务端插件配置里修改（可以防止熊孩子绑定多个游戏ID，熊服务器）
4. 新增插件更新版本提醒功能，插件有新版本在控制台里有提示
5. 修改了登陆成功后提示的方式，之前只能显示现在可以多行了（之前版本的将config.yml里面的LandingSuccess:删掉即可）
6. 优化了验证服务器和Q酷之间的稳定性

本插件所用所有代码均为原创,不存在借用/抄袭等行为
