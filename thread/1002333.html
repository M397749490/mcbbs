标题: 想写一个附魔消耗金币的插件 但是 还是消耗经验
@EventHandler
public void onEn(EnchantItemEvent e){
    Player p = e.getEnchanter();
    if (!economy.has(p,10000)){
        e.setCancelled(true);
        p.sendMessage("你需要"+ 10000 + "金币");
        return;
    }
    e.setExpLevelCost(0);
    economy.withdrawPlayer(p,10000);
    p.sendMessage("金币-"+10000);
}



有问题吗？

确定有注册到该监听事件吗？e.setExpLevelCost(0);就能将本次附魔扣的等级设置为0，但如果你监听事件没有注册的话那无法生效
