小地球   

46米立方的小地球,
嗯~~也沒啥好說的, 照平面圖搞就是了...
要是覺得地形有啥奇怪, 不合現狀的, 就請無視吧...
話說... 先前看過國外有人搞超百米級的大地球, 解析度可高了,
但太累人, 不想做那麼大顆的...
就此打住, 上圖了...

( 照慣例, 純展示, 勿求檔, 皮膚也一樣... )

飄浮在半空中的地球... 剛好底下牛羊豬雞全到齊... 好個四海一家...


火星人登陸地球...


遠眺歐亞大陸...


近觀神州大地...


繞著地球跑... 跟著世界轉...


來到歐洲及非洲...


再過去就是美洲...


北美...


南美... 南北都很美...


差點忘了, 還有個澳洲...


一片漆黑, 南極洲全在陰影裡... ( 太陽及人物是自製貼圖測試 )
