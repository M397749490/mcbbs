每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。
适用于正式版的MOD不兼容预览版，而且大多数MOD都不提供对每周快照的支持。
Minecraft 1.7.3仍未发布，13w47e为其第16个预览版。
注意！旧版启动器已经无法启动Minecraft 1.6以及1.7快照，请看下面的说明。
本版新闻除非特别说明，否则均允许转载，但转载必须注明本帖地址。


在Minecon中，我们宣布了我们与Twitch的合作计划，将为Minecraft添加一键直播功能。经过短暂等待后，我们终于能将这个新功能付诸公测了！这是首个能一键直播的快照，所以漏洞是不可避免的，而且一键直播功能还不够完善。不过现在勉强够用，希望你能提供及时的反馈！

在直播前，您必须访问您的Mojang账户设置页面，将Twitch账户与Mojang账户绑定。然后在游戏中你可以在选项->直播选项里进行设置。默认的一键直播按键为F6。

目前直播功能仅支持Windows（XP以上不包括XP）以及Max OS X Lion（10.7以上不包括10.7）。如果你无法开始直播，去看看选项屏幕，那里会告你该怎么做的。
随着新的Twitch的直播功能的加入，总会有一坨的BUG要修复。如果你发现了BUG，请到BUG反馈页面报告！(渣翻译勿喷)

早都说了，加入了Twitch直播的功能后，更新速度是丧心病狂的！

对于正版用户，可以直接接收到新版官方启动器的快照推送。前提是：
  • Profile中的Version Selection勾选Enable experimental development versions ("snapshots")一项
  • Use version选择Use latest version
对于非正版用户，前提是：
  • 你使用的启动器能够在线读取官方的版本列表，并具备下载功能。
