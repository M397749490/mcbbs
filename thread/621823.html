Essentials插件功能
开启方法：
/plugin/essentials/config.yml
寻找以下配置
  1. # Auto-AFK
  2. # After this timeout in seconds, the user will be set as afk.
  3. # This feature requires the player to have essentials.afk.auto node.
  4. # Set to -1 for no timeout.
  5. auto-afk: 300
复制代码

300应该是5分钟内没有动就进入AFK模式（也就你说的xxx离开了）
如果玩家动了就退出AFK模式（也就是你说的xxx回来了）
如果是-1为关闭
（/afk指令可以手动切换xxx回来、离开）
