对朋友开通权限,请站在领地内,输入/res pset 朋友ID 权限 true
对朋友移除权限,请站在领地内,输入/res pset 朋友ID 权限 false
设置你的领地的主要权限,请站在领地内,输入/res set 权限 true

权限表：
admin：领地的全部权限
container：是否能用箱子，发射器等
bucket：是否能用桶
ignite：点火的权限
piston：活塞是否能用
build：建造权限（包括destroy和place）
destroy：毁坏权限
place：放置权限
move：进入权限
tp：传送权限
use：使用权限（工作台，炉子等）
subzone：是否能设置子空间
tnt：tnt是否有效
creeper：JJ怪是否能爆炸
damage：领地内是否能造成伤害（不能防止被挤死）
monsters：是否刷新怪物
animals：是否刷新动物
firespread：火是否能蔓延
flow：液体流动，包括waterflow和lavaflow
waterflow：水的流动
lavaflow：岩浆流动
healing：是否能恢复生命
pvp：是否能pvp

楼上正解，领地插件有很多权限，要看你要给什么，move是指进出领地的权限，use是指使用权限，build，建筑，破坏的权限，container打开箱子的权限
作者: 梦雨雨雨雨    时间: 2013-12-25 00:48
正如三楼所说，权限有很多，先用线左击有领地的地面要想给所有玩家权限就输入/res set 权限 t即可例如/res set use t (t为是f为否),就可以让所有玩家在领地使用门和踏板,要想对某个玩家的话你就输入/res pset 玩家名字 use t 即可，例如要给名为123的玩家权限那你输入/res pset 123 use t 那么就只有这一个玩家可以在领地内使用门和踏板，其他玩家则不能使用，要是还不会留下你的QQ或者服务器IP我去你的服教你.
