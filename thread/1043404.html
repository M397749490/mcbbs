BungeeList


     插件介绍
  这个插件可以查询bungeecord所有在线的玩家，他的身份及所在的服务器
  高度自定义信息，若出现其他报错/问题可以再discord提问

  授权图：

   


  
     插件功能

  查询全部在线玩家
  基于bungeecord
  可自定义的信息
  玩家隐身
  身份层次，层次高的可以看到层次低的隐身的玩家
  显示所在服务器
  服务器分组，例如大厅在一组，生存在一组
  配置文件中子服名称不区分大小写

  
     安装
  
  关闭bungeecord服务器
  打开bungeecord-plugins文件夹
  将Bungeelist.jar放到这个文件夹
  开启bungeecord服务器

  
     命令及权限
  
  /staff
  显示所有在线的玩家
  /staff vanish
  切换隐身模式
  所需权限：bungeelist.vanish
  /staff reload
  重载插件的配置文件
  所需权限：bungeelist.reload

     配置文件  

  1. ranks:
  2. # 如果一个玩家拥有多个权限，则在玩家列表中显示的身份为更高权限的身份
  3.   owner:
  4.     permission: 'bungeelist.owner'
  5.     format: '&8[&2服主&8]&r'
  6.   developer:
  7.     permission: 'bungeelist.developer'
  8.     format: '&8[&6技术&8]&r'
  9.   moderator:
  10.     permission: 'bungeelist.moderator'
  11.     format: '&8[&3城管&8]&r'
  12.   helper:
  13.     permission: 'bungeelist.helper'
  14.     format: '&8[&e助手&8]&r'

  16. groups:#服务器分组
  17.   arenas:
  18.    - 'Arena1'
  19.     - 'Arena2'
  20.     - 'Arena3'
  21.   lobbies:
  22.    - 'lobby1'
  23.     - 'lobby2'
  24.     - 'lobby3'

  26. blacklist:
  27. - 'secretserver'

  29. command:
  30.   permission: 'bungeelist.staff'
  31.   aliases:
  32.     - glist
  33.     - list
  34.     - onlinestaff

  36. formats:
  37.   header: "&6&m---------&e&l 玩家在线列表 &6&m---------"
  38.   footer: "&6&m-----------------------------------"
  39.   # %name% 表示玩家所在的服务器名称
  40.   # %rank% 表示玩家的身份
  41.   # %player% 表示玩家ID

  43.   # 服务器组或服务器的标题
  44.   # %total_online% - 全服在线玩家总数
  45.   # %total_online_staff% - 拥有身份权限的玩家在线总数
  46.   # %total_online_group% - 服务器组或服务器的在线玩家总数
  47.   title: "  &e&l%name% (%total_online_group%/%total_online_staff%)\n"
  48.   # 玩家所在的服务器没有在服务器组
  49.   server: "    %rank% &f%player%\n"
  50.   # 玩家所在的服务器在服务器组
  51.   group: "    %rank% &f %player% &e(%name%)\n"
  52.   # 如果你不想让服务器组与服务器之间分割，请设置为 ""
  53.   divider: "\n"

  55. messages:
  56.   no-staff: '&c&l太糟糕了! &c没有在线管理'
  57.   invalid-argument: '&c这个命令不可用，请使用 &l/staff (vanish/reload)'
  58.   no-console: '&c控制台不可以使用这个命令哦，只有玩家才可以使用。'
  59.   no-permission: '&c你没有权限使用这个指令。'
  60.   reload: '&a重载配置文件成功'
  61.   vanish:
  62.     enabled: '&a你已成功隐身，将不会出现在玩家列表中（身份比你等级高的可以看到）'
  63.     disabled: '&a你已成功解除隐身，将会出现在玩家列表中。'
