我已经搞定了，我分享一下,start_server.command里面的 #!/bin/bash
cd "$( dirname "$0" )"
java -Xmx1024M -Xms1024M -jar craftbukkit.jar
这是修改过后的，然后这是以前的
#!/bin/bash
cd "$( dirname "$0" )"
java -Xmx1024M -Xms1024M -jar craftbukkit.jar－o true

也就是说这是多了一个-o true,然后就这样了
