Linux发行版（选看，感兴趣的服主可以了解一下，看不懂没有关系）
  对于“发行版”这个词可能很多小伙伴头一次听到是一脸懵逼，其实Linux并不是某一个操作系统的名称而是一类操作系统的统称，而发行版就是基于Linux的开源内核再加以各自偏向的方向再加以开发得来，如何理解呢？最简单的方式就是对标windows的不同版本，虽然不太恰当，但是这么理解比较容易。
  一些流行的发行版的详细介绍我就不过多阐述，找了一个不错的文章给大家看看 2019年最流行的Linux发行版
  被大量用来作为服务器系统的发行版其实就几种：Redhat CentOS Ubuntu Fedora Debian
  我这里就简单描述一下CentOS和Ubuntu的区别，因为目前国内企业服务器基本都是这两种系统之一或者混用。
  CentOS和Ubuntu其实是属于不同派系发行版（fedora和debian），都用过的小伙伴应该有发现两种系统的包管理器（就是自动安装软件的程序）是不一样的，CentOS的是yum，Ubuntu的是apt-get，这是其中一个区别，包管理的体系不一样，相应的软件源也不一样。区别其二是CentOS主张极高的稳定性，Ubuntu主张较新的功能，所以在稳定性上Ubuntu要稍差一些，但是依然非常稳定，毕竟CentOS出自Redhat。由于追求极高的稳定性，CentOS不管是在内核（kernel）版本，yum的base源的软件版本都是比较低的（久经考验），所以在CentOS上如果想用比较新的软件的话需要自行编译安装或者直接安装已编译好的二进制包又或者新版本的软件有相应的yum源。
  所以，综上所述，作为服务器我个人推荐CentOS，[:hide:]其实还有一个原因也是因为CentOS我用得最熟，现在公司用的Ubuntu其实有点不适应。

为什么选择Linux？
  这里我不会阐述什么配置能带起来多少玩家并且TPS达到多少，我这里主要是简单讲一下为什么选择Linux，Linux和windows到底有哪些区别，并且我会避开比较难以理解的内容，放心食用。
  1，服务器硬件配置低的情况下选择Linux更加合适。其实大多数服主在刚开服的时候都不是一来就有什么8核16G，8核32G甚至更高的配置的服务器，一般都是1核2G的腾讯云学生机或者1核1G的阿里云或者其他云服务器商的机器（这里我不阐述面板服相关的东西），在这种情况下如果装Windows的话会因为Windows的图形界面以及Windows较多的自启程序而导致内存占用差不多一半或者更高，也就是几百MB的样子，而Linux在没有图形界面情况下开机的时候以CentOS7.6为例只有大概80MB左右的内存占用，这对于对内存比较敏感的MC服务端来说无疑节省了不少的内存开支
  2，优秀的内存管理。关于内存管理的部分其实理解起来又挺大难度，具体细节要研究内核的内存管理逻辑，这里不做细讲，而且我也讲不好这个东西，感兴趣的小伙伴还得自行百度或者谷歌。相信大家都经历过windows蓝屏的绝望，windows蓝屏其实较多时候是由内存问题引起，而Linux上几乎不会出现因为内存问题出现的系统崩溃现象
  3，极高的稳定性。众所周知到处都在说Linux比windows稳定，但是稳定多少，怎么个稳定法，为什么稳定很少有人能说得明明白白，当然我也不能，但是我会抽一些点来描述一下。
    (1)，在处理高并发任务的时候由于任务数量和进程+线程总数是远大于CPU核心数的，那么CPU为了让所有的任务”同时”运行，那么CPU就需要不停地切换线程进行处理，这个动作称之为“上下文切换”（这里CPU的工作逻辑详细概念想了解需要自行搜索），而CPU上下文切换这个操作是由操作系统内核来完成的，那么这里又牵扯出另外一个概念，那就是CPU的内核时间。CPU在工作的时候其实不是单纯的占用率，是分为usertime（用户空间时间）、system time（内核空间时间）、iowait（IO等待时间）以及上下文切换和中断等，这里不再展开讲，简单说就是一般情况下用户运行程序是主要占用用户空间时间，而内核空间时间的占用率和系统内核性能有非常大的关系，而且内核空间时间占用大小直接影响CPU能发挥的性能也直接影响系统稳定性。那么说回为什么在高并发下Linux比windows优秀，上面已经说过在处理多任务的时候CPU需要不停切换上下文，而切换上下文需要内核来操作，那么这部分操作就是内核空间时间，而Linux内核在处理这类任务的时候是无比高效的，换句话说内核空间时间越少系统能发挥的CPU性能就越高也越稳定，特别是在多路CPU的情况下。如果感兴趣的话可以找两台机，一台windows一台linux然后跑一些差不多的程序然后观察内核空间时间，你会发现windows内核空间时间占用率非常高。下面附上看各系统内核空间时间占用率的办法：
    windows: 如下图，把“显示内核时间”（win10、win server 2016以上）对勾点上，然后你就会发现CPU占用率会分成两层，一层颜色深一层颜色浅，深色的就是内核占用时间
   
    Linux：如下图执行top命令然后在%Cpu一行的sy就是system time占用百分比，id是空闲百分比
   
  (2)，Linux较windows更稳定还有一个特点就是Linux的内核可配置性和内核更改无须重启的特性。Linux在更改内核参数或者其他系统级的更改操作后并不需要重新启动系统才生效，这一点对于稳定性要求极高的企业场景无疑是非常大的优势。说一句题外话，Linux因为是开源系统，所以在Linux上几乎可以做任何你想做的事，只要你会做，甚至你都可以简单调整一下内核参数然后配置一下转发路由就可以把一台Linux服务器做路由器用。
  (3)，Linux病毒威胁较少。由于Linux的用户管理模式是由root作为最高权限用户能和内核直接交互以外所有用户都不能和内核直接交互，所以在这种模式下对于病毒多了一道防火墙，入侵Linux系统“提权”就成了最重要也是比较有难度的事了。
  4，“避免令人困惑的用户界面”。这句话其实是“Linux五大哲学思想”之一，这句话的意思其实就是说避免了图形界面给用户带来的困惑，在进行某些设置或者配置的时候迷茫。其实这句话在我刚开始学Linux的时候我无法理解，也不赞同，对于当时已经比较熟悉的windows的我来说，全是命令行才让我迷茫好吗，我相信在看本文的你说不定也是这么想的，但是这句话能成为Linux五大哲学思想之一是有道理的，等你真正熟悉并且融会贯通了Linux之后再来看这一句话你就能理解了。

三，常用命令以及MC开服会用到的命令详解
  1，screen    screen命令在MC开服中很重要，原因是MC的服务端是一个交互性服务端，所谓交互性就是说MC的服务端起来了之后是一个可以输入指令的控制台，用户可以通过输入指令和服务端交互，这个时候服务端就需要占用一个终端，相信用Linux开过服的同学都知道，如果不用screen命令直接启动服务端等关掉终端的时候服务端也被关掉了，这就是因为服务端是依赖用户所登陆的那个终端的。
那么screen是怎么解决这个问题的呢？screen在创建一个新会话的时候其实是启动了另外一个终端然后将服务端启动在这个终端里面然后将会话挂起，这么一来的话服务端使用的终端和用户登陆的终端就不是一个终端了，那么用户退出终端的时候就不会影响在其他终端运行的服务端，就实现了在“后台”运行的效果，并且还可以返回到控制台和服务端进行交互  如图是我服务器的服务端进程，ps命令是查看进程的命令，后面会讲到：
   
  其中红色的pts/1就是服务端启动的终端号，与登陆的终端号是不同的    screen在MC开服中会用到的命令参数：
    -d <会话名称> 将指定的screen会话挂起（理解为放到后台）
    -m 即使设置的新会话名称已存在同名会话也强制创建会话
    -S <会话名称> 指定创建的会话名称，可用于返回会话的时候使用
    -r <会话名称> 用于返回已有的screen会话
  举例：启动命令 screen -d -m -S "minecraft" java -Xms4G -Xmx4G -XX:+UseG1GC -jar spigot-1.14.4.jar
  如上面所示的启动命令所带的参数的意思就是强制启动一个名为minecraft的会话，并在这个会话终端中启动java...-jar spigot-1.14.4.jar这段命令
  执行了之后表面是看不出来发生了什么的，因为带上了-d参数，系统会在后台来启动这个会话，那么这个时候只要执行screen -r minecraft就能返回这个会话，也就是回到服务端的控制台。当执行完指令要退出的时候千万不要执行ctrl+c或者ctrl+d，需要先挂起会话才能安全退出登录，需要按下组合键ctrl+a然后松开组合键再按一次d就能挂起screen会话，什么时候还需要回到会话的时候再次执行screen -r minecraft即可  2，history   用于查看命令行的历史记录 这个我不再细讲因为了解就好，感兴趣的话可以看我的博客，之前写过history命令用法详解
  2，ls  ls命令是Linux中最常用的命令之一了，这个命令简单说就是展示目录下的文件和目录。该命令和文件系统知识有关系，在文件系统课时细讲

  3，cd cd命令也是最常用的命令之一，cd的功能非常简单，就是切换当前所在目录。该命令和文件系统知识有关系，在文件系统课时会有应用举例
  4，yum yum命令在之前也提到过，yum是centos的包管理器（概念可以百度，简单说就是自动装软件的）。包管理器存在的意义是因为Linux上很多软件开发都会用到很多同样的系统调用功能，比如文件IO，内存调用，那么这种重复的东西就没有必要重复开发，所以就存在了通用库，但是不是所有的库都是默认存在在系统中的，不同的软件可能要用到不同的库文件，这就叫做软件依赖关系，而yum就是用来解决这个问题的，使用yum安装软件的话会自动帮助用户处理依赖问题，自动安装上软件所需要的各种依赖，这样的话就给用户省了很多麻烦。
    yum install <应用名> 安装应用
    yum list <应用名> 列出应用，这里可以使用通配符来搜索应用，比如 yun list java* 这样可以搜索出以java开头的所有应用
    yum remove <应用名> 删除应用
    yum reinstall <应用名> 重装应用

一些固定目录的作用：
/boot:引导文件存放目录，内核文件(vmlinuz)、引导加载器 (bootloader, grub)都存放于此目录
/bin:供所有用户使用的基本命令;不能关联至独立分区， OS启动即会用到的程序
/sbin:管理类的基本命令;不能关联至独立分区，OS启动即 会用到的程序
/lib:启动时程序依赖的基本共享库文件以及内核模块文件 (/lib/modules)
/lib64:专用于x86_64系统上的辅助共享库文件存放位置
/etc:配置文件目录
/home/USERNAME:普通用户家目录
/root:管理员的家目录
/media:便携式移动设备挂载点
/mnt:临时文件系统挂载点
/dev:设备文件及特殊文件存储位置
/opt:第三方应用程序的安装位置
/srv:系统上运行的服务用到的数据
/tmp:临时文件存储位置/proc: 用于输出内核与进程信息相关的虚拟文件系统/sys:用于输出当前系统上硬件设备相关信息虚拟文件系统
/selinux: security enhanced Linux，selinux相关的安全策 略等信息的存储位置
usr: universal shared, read-only data
bin: 保证系统拥有完整功能而提供的应用程序
sbin: 同上
lib:32位使用
lib64:只存在64位系统
include: C程序的头文件(header files) share:结构化独立的数据，例如doc, man等 local:第三方应用程序的安装位置
/var: variable data files
cache: 应用程序缓存数据目录
lib: 应用程序状态信息数据 local:专用于为/usr/local下的应用程序存储可变数据; lock: 锁文件
log: 日志目录及文件
opt: 专用于为/opt下的应用程序存储可变数据;
run: 运行中的进程相关数据,通常用于存储进程pid文件 spool: 应用程序数据池
tmp: 保存系统两次重启之间产生的临时数据

什么叫文件类型呢？在服务器上执行 ls -l或者ll会列出当前目录的文件详情，如下图演示：

可以看到详细信息的最左边的第一个字符有些是“-”有些是“d”，那么这个标识就是文件类型，对照上面的文件类型提示，“-”就是普通文件，“d"就表示文件夹或者叫做目录。
图中的cd 命令在第二课有提到过，但是相信大家在看到第二课的时候对路径不是很理解，现在了解了一下Linux的文件系统后应该会有一个大致的概念。我这里解析一下我刚才执行的cd /mcserver/minecraft是什么意思
cd命令是切换目录的意思，然后/mcserver/minecraft的意思是在”/“下，有一个名为mcserver的目录在这个mcserver目录中又有一个叫minecraft的目录，那么cd /mcserver/minecraft的意思就是切换到”/“下的mcserver下的minecraft中。
顺带一提：在路径中如果是以”/“开头的路径叫做绝对路径，就是一个完整路径，那么有绝对路径就有相对路径。
相对路径：

如图的一系列操作：首先，pwd命令的作用是查看当前所在路径也可以通过查看变量得知，命令：echo $PWD
cd ../和cd minecraft/logs/都是相对路径的操作办法，其中 cd ../的意思是回到上级目录，cd minecraft/logs/的意思是切换到当前目录下的minecraft下的logs下，这就是相对路径的用法
途中还有顺带一提的cd -和cd ~，cd -这个命令在实际使用中会很常用，cd -的意思是回到上一次所在的路径，如图上的内容，我在执行cd -之前是处于/mcserver/minecraft/logs目录中，当我执行了cd -之后就回到了我在切换到/mcserver/minecraft/logs之前的目录，也就是/mcserver。
然后cd ~的意思很简单，就是回到当前用户的家目录，~符号代表的就是家目录的意思

常用的通配符：
通配符通俗易懂地说就是一种匹配目录/文件名的匹配规则，通配符有比较多种写法，这里我列举几个最常用的：
* 匹配零个或多个字符
? 匹配任何单个字符
[0-9] 匹配数字范围
[a-z]:字母
[A-Z]:字母


如何用呢？我如下面演示：

如图，第一步我用mkdir命令在当前目录下创建了一个tmp目录；
第二步，我cd到tmp目录下；
第三步，我用touch命令（该命令的作用是用于创建空的文件）创建了如图所示的文件；
第四步，我执行ls看一下当前目录下的所有文件；
第五步，我执行ls *，这里请对照上面我列举的通配符，*是匹配零个或者多个字符，那么可以理解为“任意字符”，所以ls *的作用和ls在当前环境是一样的，如图上所示，两次命令结果确实一样；
第六步，我执行了ls a*，大家已经知道了*可以代表任意字符，那么a*的意思就是以a开头不管什么结尾也不管中间有多少个字符的任意文件，那么结果当然就是aaa和aab了因为当前目录只有这两个文件是以a开头；
第七步，我执行了ls aa?，?代表的任意单个字符，其实?和*的功能很像，唯一不一样的是?只能代表一个字符，比如我执行ls a?这样的话就不会显示任何文件，因为没有以a开头然后再加任意一个字符结尾的文件，但是ls a?a能匹配出来，原因是当前目录有以a开头中间任意一个字符然后以a结尾的文件，正是aaa；
第八步，我执行了ls [0-9]，结果是没有那个文件和目录，其实这里的[0-9]的意思是从0-9的单个字符的文件，在当前目录下文件名是数字的只有111 222 333，都是3个数字组成，所以执行[0-9]是不会有任何结果的，但是如果结合*来匹配的话意思就是以[0-9]开头任意个数任意字符结尾的文件，那么这样的话都能匹配上了，后面的ls [a-z]*也是同理
