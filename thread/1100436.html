如题

我在使用CustomMainMenu-自定义GUI Mod的时候遇到的问题

创建一个按钮

背景选择填充

当我以1920*1080窗口大小Ctrl+R时按钮位置是正常的

当我缩小窗口时按钮发生错位直至错位到显示窗口外

有没有办法可以让按钮像文字项一样跟随窗口大小进行移动

谢答


作者: 诺言T    时间: 2020-8-13 09:55

自定义对齐属性来调节好就能保持全屏和缩小窗口的位置一致
"alignments":
    {
        "c1":
        {
            "factorWidth" : 0.5,
            "factorHeight" : 0.7
        },

        "c2":
        {
            "factorWidth" : 0.2,
            "factorHeight" : 0.2
        }
    }
