作者: SPGoding    时间: 2019-7-6 15:56

出生点有两种。

一、世界出生点区块位置
函数默认执行位置（由 #load 或 #tick 执行的函数所在的位置）在出生点区块，所以直接在函数里写
summon minecraft:armor_stand ~ ~  ~ {Tags:["marker"]}
然后获取它的坐标存在记分板就可以了：
execute store result score $x foo run data get entity @e[limit=1,tag=marker] Pos[0]
execute store result score $y foo run data get entity @e[limit=1,tag=marker] Pos[1]
execute store result score $z foo run data get entity @e[limit=1,tag=marker] Pos[2]
别忘了杀死临时实体
kill @e[tag=marker]


二、玩家出生点位置
玩家个人的出生点储存在 NBT 中。请务必注意，出生点和世界出生点一致的玩家很可能没有这些标签，这时玩家的出生点就是「一」中提到的位置。
这个的获取就很简单了：
execute store result score $x foo run data get entity @p SpawnX
execute store result score $y foo run data get entity @p SpawnY
execute store result score $z foo run data get entity @p SpawnZ
