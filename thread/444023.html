ProtocolLib 4.2.0  ProtocolLib为部分插件的必要前置插件。       最新版本已更新！！！
  
  功能:
  • 配置:重新加载配置文件。
  • 检查:检查对BukkitDev新版本。
  • 更新:检查新版本并自动下载的JAR
  • 计时:切换测量每个插件的CPU时间。
  • 监视:显示插件使用ProtocolLib在做什么,他们截获的数据包类型。
  指令:
/protocol [参数值]
  1. ·config 重新加载配置文件
复制代码



     权限:
- protocol.admin
  其他:监视器具体使用方:
  1. <font size="2">Packet

  3. Add or remove a debug packet listener. This is useful for plugin authors who just wants to see when a packet is sent, and with what content.

  5. Sub commands:

  7. add: Add a packet listener with a given packet ID.
  8. remove: Remove one or every packet listener with the given packet IDs.
  9. names: Print the name of every given packet ID.
  10. Parameters (in order):

  12. Connection side: Either client or server.
  13. Multiple ID ranges: Can be a single packet ID like 14, or a range like 10 - 15. Defaults to 0 - 255 if not specified.
  14. Detailed: If TRUE, prints the full packet content.
  15. Example:

  17. /packet add client 10-13 true
  18. For 3.0.0 and above, you should specify the protocol, sender and name instead:

  20. /packet add play server chat true
  21. In 3.4.0-SNAPSHOT and above, you can also display the packet before its modified by any packet listeners:

  23. /packet add play server chat compare
  24. Remove all listeners:

  26. /packet remove client
  27. /packet remove server
  28. Note that this command should rarely be used on a production server. Listening to too many packets may crash the server.</font>
