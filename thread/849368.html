标题: Minecraft 主机版 1.89 发布
主机版即PlayStation 4版和Switch版，由4J Studios为Mojang开发。

迎接新的正式版吧！

转载本贴时须要注明原作者以及本帖地址。



来源：https://www.minecraftforum.net/forums/minecraft...change

更新日志 - 2019年3月7日

  • Fix for a Zombie texture issue in Steven Universe Mash-Up Pack.
  • 修复了Steven Universe混搭包中的僵尸材质问题
  • Fix for Chests splitting apart on Chunk Boundaries - Split Chests will need to be broken and placed.
  • 修复了箱子在区块边界分离的问题。分离的箱子需要破坏后重新放置。
  • Fixed Old Shulker Boxes Blocks loading as Purple Shulker Blocks instead of undyed.
  • 修复了旧的潜影盒方块被加载为紫色潜影盒而不是未染色的。
  • Fix for Dispensers not placing Shulker Boxes.
  • 修复了发射器不会放置潜影盒的问题。
  • Fix for MCCE #8829 - Nether Brick Fences required the Nether Brick Wall Recipe to be crafted.
  • 修复了MCCE-8829：地狱砖栅栏需要地狱砖块墙配方来合成。
  • Fix for MCCE #8832 - Stone Slabs can be used to craft Purpur Pillars.
  • 修复了MCCE-8832：石砖可以被用于竖纹紫珀块。
