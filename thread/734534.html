OreReplacer--- Powered by LogoCat
一个几乎不占性能的反作弊插件
矿物追踪？X-Ray？透视材质？
这个插件让熊孩子的作弊手段统统失效！
·杜绝100%所有类型的X-Ray作弊挖矿手段
·几乎不占用服务器的网络和性能
·绝对不会影响普通的玩家
- 工作原理 -
这个插件会自动动态的更换被破坏的方块(?)
所以作弊的玩家会想他正在接近矿物而他挖掉矿物前面的一块石头的时候他会发现矿物消失了
[引自原帖 勿喷]
无 OP默认拥有全部权限
/OreReplacer reload - 重载插件
无 详细情况请自行使用
(按照上面写的工作原理自行脑补)
1.下载插件 然后将插件丢入/plugin/文件夹内
2.重启服务器 生成config.yml
3.关闭服务器 配置config.yml 即可
Config 配置文件
  1. ENABLED_WORLD: world,world_nether,world_the_end
  2. PROBABILITY_DIAMOND: 0.001
  3. # 0.001 means that when a player mine 1000 blocks, the player would "probably" get 1 diamond. (Expected value.)
  4. MAX_DIAMOND: 4
  5. #What is the maximum number blocks of the ore veins.
  6. PROBABILITY_INCREASING_CONSTANT: 1.0
  7. #You could change this value and hold a mining bonus time!.
  8. #This number will multiply the probability of ore generation.
  9. REPLACING_DIAMOND: true
  10. # true equals replacing such ores.
  11. # false equals leaving such ores as their original position.
  12. #Other ore blocks have default setting. Just follow the logic above.
  13. #若您不会配置 请使用这里的配置
