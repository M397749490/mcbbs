properties文件读取的时候，存入到String，trim去空格，然后转换为Double类型。
JAVA实现：
  1. String str = properties.getProperties("price");
  2. if(str == null)
  3.   return;
  4. Double price = Double.parse(str.trim());
  5. price = price*0.5;
