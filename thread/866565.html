全息信息
插件特色
1.全息图可无限行数加入PAPI变量
2.可以设置全息图的高度
3.自定义PAPI变量
4.指令控制，只有开了该指令的才可以看见玩家变量
5.支持1.14(明明holo才到1.13)
注意，此插件一定要使用HolographicDisplays全息插件，否则该插件无法功能
部分服务端使用测试玩家Ping值后可能出现报错，不显示即可
由于此插件原贴改过英文名字，所以老版本的指令可能为/av
相关变量点这里

指令和权限
/adminesp 简写/aesp  - 开启/关闭全息信息显示
权限:adminesp.use - 使用指令/aesp

配置文件
                                                                              
                                                                           
  1. #插件是否开启
  2. enable: true

  4. #刷新玩家全息信息的时间(以tick为单位)
  5. # 20 ticks = 1秒
  6. update-interval: 20

  8. #之后多少秒删除原来位置的全息(以刻为单位)，建议与上面相同
  9. delete-interval: 20

  11. #全息信息的高度
  12. height: 2
  13.   
  14. #全息信息配置
  15. #常用变量
  16. # %player% - 显示玩家的名字
  17. # %hp% - 显示玩家的血量
  18. # %food% - 显示玩家的饱食度
  19. # %holding% - 显示玩家手上的物品
  20. # %ping% - 显示玩家的ping
  21. # %distance% - 管理员与该玩家的距离
  22. info:
  23.   - '&e%player%'
  24.   - '&e血量: &a%hp% &8| &e饱食度: &6%food%'
  25.   - '&dPing: &a%ping%'
  26.   
  27.   

  29. # 聊天信息配置
  30. messages:
  31.   adminview-enabled: '&8[&eAdminEsp&8] &a&lON!'
  32.   adminview-disabled: '&8[&eAdminEsp&8] &c&lOFF!'[/spoiler]
