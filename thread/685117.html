TTA 3.6
很小但很精用的开源插件

一、简介 Description
TTA是一个轻量级开源插件，他的功能有很多，比如: Tab之类的，有好多个比较出名的插件都需要这款插件作为前置                                                 Java菜鸟请勿入

二、功能 Features
·支持所有版本从1.7-1.11！
·简单而且轻量
·玩家发光开源[1.9&1.11]
·Boss血量条支持所有功能开源[1.9]
·Ping值开源[所有版本]
·自动服务器检测版本开源
