config下的ic2.ini，里面有这一段

  1. ; Additional initial uu values, a value of 1 equals cobblestone.
  2. ; Recipes may cause the final value be lower than ** specified here.
  3. ; Format: <name>[@metadata] = <value>
  4. [balance / uu-values / predefined]
  5. IC2:misc_resource#iridium_ore = 12000
  6. IC2:misc_resource#iridium_shard = 1333
复制代码


格式是名称 = uu值
比如IC2:misc_resource#iridium_ore = 12000，也就是ic2的铱矿=12000 uu

你可以手持物品，输入/ic2 currentItem，屏幕上就会显示物品的名称，加入上面段即可
