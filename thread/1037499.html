-医疗包

设置了毒圈，你可以开始游戏，跳伞

首先，指令为/game help 获取指令帮助

/game mode （按tab补全b开头的）

/game map x y z （最后一个不知道，有知道的告诉我，好像是坐标z的终点）

/game l什么的（tab补全） x y z 1 设置出生地

/game start 开始游戏

注意

AI

会自动出生在玩家旁边

会攻击玩家

会攻击AI

会捡起枪


指令
/airdrop 生成一个空投在你的头顶
关于刷新
首先，输入/loot help，出现英文界面
再找到物品中的战利品生成器
放置在地下
指令列表:/loot generate  生成刷新品
/loot  clear 清除生成器
/loot show 显示生成器
/loot info关于物品生成器的信息
/loot reset  重置配置
按键说明
B:改变开火模式
P:打开配件菜单
N:打开夜视仪
