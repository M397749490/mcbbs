随意的话不行吧，不然没准走着走着就没了（
进入到了NPC路径移动介绍！可以让你的NPC按照一定的路径重复移动，首先输入命令，然后左键单击方块选择多个路径点，NPC就会自动围绕这些点移动了，如果要删除点，可以右键单击删除已经存在的路径点，命令为:
/npc path
复制代码
首先，我们创建了一个红色名为好黑的猪，然后我们放置了四个钻石块，让好黑围绕这四个路径点移动。
然后我们输入了命令 /npc path ,然后左键点击了四个钻石块，坏黑已经围着转了，我们再输入 toggle path ，显示四个路径点，注意没有 / ,现在是这样的:
好黑已经在移动了，如果输入 clear , 就可以清除所有路径点，如果不小心设置错了路径点可以右键删除掉，最后设置好了再次输入 /npc path 退出设置路径的模式，路径就设置好了。
接上一个路径移动，下面介绍一个命令，设置NPC移动的速度，命令为
/npc speed <速度>
复制代码
我将好黑的移动速度设置为5，可以看到好黑的移动速度明显加快，甚至漂移了。
