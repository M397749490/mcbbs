非常简单的一个插件

在你死了以后显示一个 GUI 界面，让你选择是在出生点复活还是返回死亡地点附近

具有的功能：
  • 自动重生（可选）
  • 自动返回死亡地点（可选）
  • 显示 GUI 来选择复活方式（可选）
  • 返回死亡地点（可选）
  • 返回死亡地点附近（可选）
  • 显示死亡地点（可选）
  • 避免在水上（可选）
  • 尝试在树叶下（可选）
  • 使用 /back 返回死亡地点（可选）
  • 存储死亡地点，重进游戏也可以返回（可选）
  • zhi sha /killself 命令（可选）
  • 支持类似地狱的洞穴世界的随机传送
  • 支持生成均匀环形随机点

配置文件
  1. # 语言; English: en, 简体普通话: cmn_Hans, 简体文言文: lzh_Hans
  2. lang: cmn_Hans

  4. # 开启后将不会显示死亡界面
  5. auto_respawn: true
  6. # 开启后会自动返回死亡地点
  7. auto_back: false

  9. # 返回死亡地点附近
  10. back_random:
  11.   enable: true
  12.   # 必须 > 0
  13.   min: 8
  14.   # 必须 > min
  15.   max: 32
  16.   # 生成随机点的最大尝试次数
  17.   # 必须 >= 10
  18.   max_try: 100
  19.   # 玩家在传送失败后可以重试的次数
  20.   # 必须 >= 1
  21.   max_retry: 3
  22.   # 生成均匀的随机点
  23.   uniform: true
  24.   # 尽量生成在陆地上的点
  25.   try_to_land: true
  26.   # 永远不会生成在水里点
  27.   never_water: false
  28.   # 尝试生成在树叶下
  29.   try_not_leaves: true

  31. # 开启后任何时候都能使用 /back 来返回
  32. back_command: true
  33. # 显示 '你能使用 /back' 的消息
  34. # 需要 {back_command:true}
  35. show_back_command_msg: false
  36. # 开启后将不会显示复活 GUI
  37. # 需要 {back_command: true}
  38. no_gui: false

  40. # 显示死亡地点，通天粒子柱
  41. show_death_loc: false

  43. # 存储死亡地点
  44. store_location: true

  46. # 使用 /killself 来 zhi sha
  47. kill_self_command: true
复制代码
