作者: 耗子    时间: 2018-10-6 19:53
单纯的添加材质非常简单，例子如下：
  1. public class ItemExample extends Item {

  3.     private IIcon icon;

  5.     @Override
  6.     public IIcon getIconFromDamage(int damage) {
  7.         return icon;
  8.     }

  10.     @Override
  11.     @SideOnly(Side.CLIENT)
  12.     public void registerIcons(IIconRegister register) {
  13.         icon = register.registerIcon(getIconString());
  14.     }
  15. }
复制代码

然后便可以在创建一个物品的时候，设置它的材质名：
  1. new ItemExample().setTextureName("example");
复制代码

之后将贴图文件放置在assets/<modid>/textures/items/example.png下就可以使用了。
