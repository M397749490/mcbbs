Rush 攻防之战 VER0.7.1
一款快节奏小游戏BattleFeild[战地]著名游戏

一、简介 Description
Rush是一款战地中很著名的游戏，我就把Rush命名为突击模式，游戏中分两队，分别是蓝队和红队，蓝队是防守方，红队是进攻方。红队目标是摧毁Mcom[本人翻译为:目标点]，而蓝队目标就是保护目标点。

二、功能 Features
·玩家地图投票系统              √
·自定义职业  √
·自定义Mcom[目标点]√
·拥有计分板√

四、指令 COMMAND
/r & /rush                                      | 主指令
/r join <战场号>                            | 加入较小的队伍<战场号>
/r spectate <战场号>                     | 加入<战场> 作为观战者
/r leave                                         | 退出当前游戏
/r list                                            | 查看所有战场 / 所有在玩的玩家
/r start                                          | 开启游戏  [OP权限]
/r stop                                          | 停止游戏  [OP权限]

五、设置游戏 Setup Game
初始设置
·下载Rush.jar
·将Rush.jar拖到plugins文件
·重启服务器
·打开Config.yml
设置多房间 [重要Important
·Config文件内查找Game0:
·Game0底下的字都归于一个游戏
·复制黏贴Game0部分内容 并将黏贴部分Game0改成Game1
·如果你在游戏中继续创建游戏就需要继续黏贴

六、配置 Configuration [非正式,将各选项汉化]

---------------------------------------------------------------------------------------------------------
基本设置区
Games: 游戏数量
showWelcome: True/False 开/关 欢迎信息
WelcomeMsg: 欢迎信息自定义,想写啥写啥
---------------------------------------------------------------------------------------------------------
自定义基本设置区
timeTilExplode: 目标点爆炸时间
tickets: 红队起始的游戏币
FriendlyFire: true/false 开/关 队友开火
PlayerForAutostart: 开始游戏的玩家数量
maxPlayer: 游戏最多玩家数
timeUntilRespawn: 玩家死亡后复活时间
timeUntilStart: 当到达开始游戏的玩家数量后，需要等待的时间[秒]
SpawnLobby: 玩家游戏结束后的传送地点 世界名#X#Y#Z  
(例子 world#-77#114#130)
Maps: 地图数
---------------------------------------------------------------------------------------------------------
自定义地图设置区
Name: 地图名字
SpawnLobby: 玩家等待大厅点 世界名#X#Y#Z (例子 world#-77#114#130)

Phases: 回合数[选择一共进行多少局]
ActivatorBlock: 红石块出现点,开起大门[一头雾水,表示自己对战地不懂QAQ]
世界名#X#Y#Z (例子 world#-77#114#130)
SpawnRed: 红队出生点 世界名#X#Y#Z (例子 world#-77#114#130)
SpawnBlue: 蓝队出生点 世界名#X#Y#Z (例子 world#-77#114#130)
McomA: 抢夺目标点A点 世界名#X#Y#Z (例子 world#-77#114#130)
McomB: 抢夺目标点B点 世界名#X#Y#Z (例子 world#-77#114#130)
---------------------------------------------------------------------------------------------------------
