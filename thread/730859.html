用记事本打开.minecraft\config\IguanaTinkerTweaks\main.cfg，找到这段文字
  1.     # Makes all non-TConstruct swords useless. Like whacking enemies with a stick. [default: false]
  2.     B:disableRegularSwords=false
复制代码
把false改成true
再在这段文字中添加>和Railcraft:tool.steel.sword这两行之间加上Minecraft:*，当然也把一些模组的武器也给ban了。
  1. # Swords that are excluded if the option to nerf non-tinkers swords is enabled. [default: [Botania:manasteelSword], [Steamcraft:swordGildedGold], [Steamcraft:swordBrass], [ThermalExpansion:tool.battleWrenchInvar], [IC2:itemToolBronzeSword], [Railcraft:tool.steel.sword]]
  2.     S:swords <
  3.         Botania:manasteelSword
  4.         Steamcraft:swordGildedGold
  5.         Steamcraft:swordBrass
  6.         ThermalExpansion:tool.battleWrenchInvar

匠魂强化默认不许使用原版工具，想关闭的话在游戏目录下mods同级文件夹中寻找名为config文件夹。在里面寻找与匠魂强化同名的文件。打开更改。
