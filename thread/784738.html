行尸走肉模组是禁止多余模组以及多余材质包的，也就是说你的模组文件只能有crafting dead core和crafting dead主体文件，其他的不能有。（这是默认设置） 如果你需要修改请打开服务器里面的 craftingdead/aftermath/craftingdead_server.properties
找到以下代码

  1. //Allow the client modpack to be edited on this server? #是否允许其他模组
  2. allow-mods=false
  3. //Allow the client modpack to run texturepacks on this server? #是否允许材质包
  4. allow-texturepacks=false
复制代码
这两项改为true即可
