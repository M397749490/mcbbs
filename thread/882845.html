基于 Minecraft 女仆模组思路
结合东方 Project 的二次创作

因为经典的日站女仆模组在 1.12.2 不再更新而且问题百出，同时对其一些设定并不是很喜欢，所以做出来这个名为“车万女仆”的模组。

该模组支持自定义女仆皮肤，通过资源包可以快捷加载女仆皮肤。

女仆也具有非常丰富多样的功能，能够快捷的协助玩家进行各种游戏内的工作。

围绕其本身也添加了多种内容，包括饰品系统、合成系统等。


如何开始

虽然不是必须的，但是我们仍然极为推荐安装 Patchouli 模组，这样你就能在游戏内合成得到本模组的一本手册，手册内对游戏的玩法提供了非常详细的介绍。

首先你需要合成一个御币，而后依据手册内提示的结构，修建多方块祭坛。

通过查询 JEI 找到祭坛中女仆的合成表，在六个御柱上摆上对应物品（无序合成）即可获取得到女仆。默认使用蛋糕驯服女仆，即可进行后续各种操作。

女仆并不会在世界中自然生成，这一点要明确！

那个攻击你的是女仆妖精，她也不可以驯服！

常见问题解答

1. 模组崩溃问题
  • 你是否装了自定义 NPC 模组？我注意到很多人仍旧在使用 09jul18 版本的自定义 NPC 模组，而这个版本的模组早在半年前就被作者从发布帖移除了。
  • 是不是其他模组导致的问题？你删掉 Touhou Little Maid 模组以后，相关问题是否仍旧存在？

2. 怎么弹出缺失必要的模组啊？
  • 本模组默认不需要任何前置模组！你那个弹出界面说的是你 forge 版本太低了，请用 2768 及其以后版本的 forge。（备注：2768 都已经是两年前的版本了，你这个 forge 版本是有够老的）

3. 女仆无法打开 GUI 问题
  • 女仆在打开 GUI 时会识别您是否为它的主人。我注意到部分人因为使用的启动器问题，导致每次启动都会生成不一样的游戏名，进而导致无法打开女仆 GUI。如果出现上述问题时，请测试下先前驯服的狼、猫等原版宠物是否也无法进行操作，情况属实请更换启动器。

4. 物品栏部分物品不显示问题
  • 你是否装了 OptiFine 模组？这个模组某些版本可能会存在渲染问题，建议删掉模组进行测试，可以查看类似情况是否还会出现。如果实在需要 OptiFine 模组，可以尝试更换 OptiFine 的版本。

5. 其他模组武器、工具、护甲对女仆不起作用
  • 可能和很多人想象的不一样。所谓女仆，实际上和原版的猫、狗、僵尸、骷髅等生物在血缘上更加接近，与玩家的血缘其实比较的疏远。而部分模组作者设计的武器、工具护甲等却又恰好是专为玩家设计的（比如植物魔法、龙之进化、匠魂、无尽贪婪等等）。
    检测这些模组是否专为玩家设计的方法很简单，用原版指令给僵尸、骷髅等也装备上对应的武器、工具和护甲，看看这些东西是否也对它们起效。
    如果不起效？还等什么，赶紧给这些作者反馈 bug 啊！
    哇，xxx 模组作者，你设计的武器、工具、护甲怎么僵尸、骷髅用不了啊！我不管你有什么自己的设计理念，请务必！务必！务必！更改下！
    你看原版的武器、工具和护甲，僵尸小白什么的都能穿，都能起作用，你的为啥就不行。

6. Java 版本过低？可是我用的就是最新版的 Java 啊？
  • 你用的模组版本老了，更新到最新版就行。

7. 咋回事，女仆怎么都没有动画效果，也没法待命坐下啊，之前版本明明还可以的
  • 你用的模组版本老了，更新到最新版就行。

8. 一些匪夷所思的问题
  • 你对原版游戏内容足够熟悉么？（以下案例均为真实案例）

    • 命名牌无法命名女仆：实际上是对方不会用命名牌。原版命名牌需要在铁砧中改名后才能对生物改名，而对方直接拿创造模式取出的命名牌右击女仆进行命名。（经过详细询问后，了解到对方认为这样会打开一个 GUI，可以输入名称进行命名……）
    • 女仆和玩家同时坐在船上，玩家射箭会伤到女仆：你可以试试和其他生物也同时坐上船上，也会触发类似问题。
      还等什么啊，赶紧轰炸 Mojang 反馈 bug 啊
    • 女仆寻路无法跨过铁轨：同上，你可以试试原版的僵尸、骷髅、狗、猫等生物的寻路，也无法跨过铁轨
      还等什么啊，赶紧轰炸 Mojang 反馈 bug 啊
    • 在洞穴中骑扫帚，碰着顶部有可能会卡进方块受到伤害：同上，你可以试试在洞穴中骑马，你看碰着顶部时候会不会受到卡进方块的窒息伤害。
      还等什么啊，赶紧轰炸 Mojang 反馈 bug 啊

  • 你对模组本身有一定了解么？（以下案例均为真实案例）

    • 女仆发射弹幕会伤害到玩家：请使用旗指物
    • 女仆发射的弹幕伤到了玩家的狗，然后狗就开始攻击女仆了：请使用旗指物
    • 女仆发射的弹幕伤害到了其他玩家，结果对方玩家的女仆开始攻击我的女仆了：请使用旗指物
    • 我不小心打死了我的女仆：请使用旗指物
