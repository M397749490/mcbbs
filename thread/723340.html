根据你提供的日志部分，显示服务端执行了/backup命令。
同时你将"CONSOLE"替换成了"提示"，意义不明。
/backup是Essentials的备份命令，它的配置如下(config.yml)：
  1. # Backup runs a batch/bash command while saving is disabled.
  2. backup:
  3.   # Interval in minutes.
  4.   interval: 30
  5.   # Unless you add a valid backup command or script here, this feature will be useless.
  6.   # Use 'save-all' to simply force regular world saving without backup.
  7.   #command: 'rdiff-backup World1 backups/World1'

  9. # Set this true to enable permission per warp.
  10. per-warp-permission: false
复制代码
根据注释可以得知，Essentials本身不实现备份功能，通过调用系统命令来进行备份操作。
命令为command参数，默认command参数被注释(#)，默认的命令是调用rdiff-backup程序。
根据以上信息，我判断这可能是指令冲突导致的。
你可能安装了其他备份插件，指令和Essentials冲突，快捷的解决这个问题你可以使用"/插件名:指令"，比如/essentials:tp，参数不变。
如果由于其他原因，请详细说明，建议下次提问时注意描述自己的目的。
