经验翻倍插件

这个插件能够让你在服务器中使经验翻倍

可以在举办活动时使用，控制经验倍数
指令：
/multiplyxp event <start|stop> [multiplier]
别名: [mx]  描述: 开启或关闭一个翻倍。# start|stop > 开启或关闭一个经验翻倍.# multiplier > 所有玩家经验翻的倍数.
/multiplyxp set <player> <amount>#
# player > 玩家名字，注意！玩家必须连接了！# amount > 这个玩家经验翻的倍数.
/multiplyxp add <player> <amount>                                                                                      
# player >玩家                                                                                                          
# amount > 增加玩家翻倍的倍数..


比如你杀一只牛获得十点经验，你输入指令/multiplyxp event set 你自己 3 ,那么你杀一只牛会获得10*3的经验
