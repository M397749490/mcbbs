多态方法

在Scala中匿名函数不可以是多态的，也就是说[ruby=Polymorphic Method]多态方法[/ruby]不能直接作为值出现，需要作为成员定义在类的模板里，语法如下例所示：
  1. def id[T](value: T): T = value
  2. def const[T, U](value: T, discard: U): T = value
  3. def compose[A, B, C](g: B => C, f: A => B): A => C = a => g(f(a))

多态方法的类型参数同样可以定义协变、逆变、上界、下界，其语法跟类型构造器的语法相同。如果说类型构造器是从类型到类型的函数，多态方法就可以说是从类型到值的函数。例如：
  • id的类型是：id: (T: *) -> (value: T) => T
  • const的类型是：const: (T: *, U: *) => (value: T, discard: U) => T
  • compose的类型是：compose: (A: *, B: *, C: *) -> (g: B => C, f: A => B) => A => C
Scala中值到值的函数的类型使用双箭头（=>），而类型到值或类型的函数的类型使用单箭头（->）。

参数化多态

[ruby=Polymorphism]多态[/ruby]使单个值可以有多个类型，Scala的多态方法正式的名称叫做[ruby=Parametric Polymorphism]参数化多态[/ruby]。参数化多态与[ruby=Ad-hoc Polymorphism]特例化多态[/ruby]也就是函数重载的最大区别是，特例化多态可以有多个不同的实现，而参数化多态只有一个实现，换句话说不能对类型参数的实际类型进行判断从而选择不同的实现。Scala的参数化多态只能是[ruby=First Rank]一阶[/ruby]的，也就是只能在方法定义时进行参数化多态，而不能把一个多态的值传入作为参数传入函数内。例如以下类型由于不是一阶的，所以是非法的：
  1. (F: * -> *) -> ((T: *) -> T => F[T]) => (F[Int], F[String])
