一、准备插件
1. Citizens  插件
2. NpcCommand  插件

二、操作(例子)
1. /npc create spawn   - 创建一个名为'spawn'的npc

2. /npccommand set /spawn - 设置 /spawn 命令获取命令方块

3. 拿着命令方块左键单击一下



让普通玩家有权限使用:
npccommand.use
