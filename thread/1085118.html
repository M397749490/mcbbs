用 display 这个 NBT：
... {display:{Name:"<JSON 文本>"}}
JSON 文本中表示删除线：
...{"text":"测试文本","strikethrough":true}
JSON 文本中表示混淆文本：
...{"text":"测试文本","obfuscated":true}
具体可见：https://wiki.biligame.com/mc/%E5%8E%9F%E5%A7%8BJSON%E6%96%87%E6%9C%AC%E6%A0%BC%E5%BC%8F

使用函数
首先打开游戏存档目录，打开data/functions文件夹
建立一个名字由小写字母、数字、下划线组成的文件夹，或者使用“minecraft”作为文件夹的名字。这个是命名空间。打开
建立一个mcfunction格式的文件，名字由小写字母、数字、下划线组成。这个是函数名。打开
编码格式记得改为UTF8(无BOM)格式
输入
  1. give @s diamond 1 0 {display:{Name:"§r非斜体"}}
  2. give @s diamond 1 0 {display:{Name:"§r§m删除线"}}
  3. give @s diamond 1 0 {display:{Name:"§r§k luanma"}}
复制代码
进入游戏，输入reload后，再输入
  1. /function <命名空间>:<函数名>
复制代码

或者也可以直接使用tab补全，即可
