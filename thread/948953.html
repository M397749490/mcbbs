先查看玩家所在的权限组 /lp user 玩家名 info

然后
/lp group 权限组 permission set chestcommands.open.*
/lp group 权限组 permission set chestcommands.command.open       

作者: 夕离丶    时间: 2020-1-31 11:49
/mangaddp 玩家组名 chestcommands.item.生存服.yml
/mangaddp 玩家组名 chestcommands.open.生存服.yml
如果权限组是builder的话就
/mangaddp builder chestcommands.item.生存服.yml
/mangaddp builder chestcommands.open.生存服.yml
如果想知道怎么给到玩家组的话
你在控制上输入指令gc查看一下玩家组
