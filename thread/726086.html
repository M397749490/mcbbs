作者原话
This is an all in one trolling/punishing plugin which is still under development and will have many features to come. LeTroll, a project started back in 2014. Rewritten numerous times but never really felt like this project was the best it could be. So 3 years later when I stumbled upon this project again, I decided to rewrite it once more. A new major feature was added. A GUI to issue trolls / punishments to players. This provides a user-friendly experience to any staff that are wanting to troll / punish their players. It's extremely light-weight and easy to install.
