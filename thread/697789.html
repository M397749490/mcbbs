│前言Preface


   
The current version of this plugin may require different string values for sounds depending on your version due to the changes to bukkit effect names between each update - the default config strings are configured to 1.10+ by default, make sure every string in the config.yml is valid with your version of bukkit before using the plugin.
此插件的当前版本可能需要不同的字符串值，这取决于您的版本，因为每次更新之间的bukkit效果名称的更改 - 默认配置字符串默认配置为1.10+，请确保config.yml中的每个字符串在使用该插件之前，您的bukkit版本是有效的。



│概述Overview


  "Daily Rewards"是一个非常轻便和简单的插件，只需运行命令即可奖励您的玩家。这个插件是非常可配置的，能够运行您的服务器的任何命令。

"Daily rewards" is a very lightweight and simple plugin that rewards your players daily by simply running a command. This plugin is extremely configurable and is capable of running any command your server has.



│功能Features


  • 可定义的奖励和奖励类型
  • 可定义的权限
  • 可自定义的消息
  • 可自定义的冷却时间
  • 随机奖励
  • UUID支持
  • IP支持
  • 本地储存玩家数据
  • 专为spigot/craftbukkit 1.12, 并支持supports 1.7 - 1.12?


│命令&权限Commands&Permissions


/Claim- Default-权限: dr.claim
/Dailyrewards - 权限: dr.admin
当您将奖励许可确认为true时，玩家必须具有以下权限:dr.（奖励名称）

When you put a reward's permission to true, the player must have the permission: dr.(reward's name here)

该插件必须是在是Java8前提下使用(Requires Java 8 when used in a home hosted server)



│配置Features


Config.yml
  1. #冷却时间
  2. cooldown: 86400000
  3. savetoip: false
  4. loginclaim:
  5.   enabled: false
  6.   delay: 3
  7. #声音
  8. claim:
  9.   sound:
  10.   #是否启用(默认启用，请手动关闭)
  11.     enabled: false
  12.     #声音类型
  13.     type: ENTITY_PLAYER_LEVELUP
  14.     volume: 1
  15.     pitch: 1
  16. noreward:
  17.   sound:
  18.   #是否启用(默认启用，请手动关闭)
  19.     enabled: false
  20.     #声音类型
  21.     type: BLOCK_ANVIL_LAND
  22.     volume: 1
  23.     pitch: 1
  24.     #每日奖励设置
  25. rewards:
  26. #这个随便起英文..
  27.   basic:
  28.   #礼包名字(给权限给的是这个dr.奖励名字)
  29.     name: Basic
  30.     #权限
  31.     permission: false
  32.     #随机
  33.     random: false
  34.     #提醒/可修改成中文，我这就没改了
  35.     claim-message: '&aRewards&f: You claimed the &7Basic&f Daily Reward!'
  36.     #广播
  37.     broadcast: ''
  38.     #执行命令(控制台执行)
  39.     commands:
  40.     - give %player minecraft:diamond 1
  41.     #下面和上面的大同小异
  42.   advanced:
  43.     name: Advanced
  44.     permission: true
  45.     random: true
  46.     claim-message: ''
  47.     broadcast: '&aRewards&f: %player claimed the &eAdvanced&f Daily Reward!'
  48.     commands:
  49.     - give %player minecraft:diamond 1
  50.     - give %player minecraft:emerald 1
