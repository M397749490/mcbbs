bStats
Plugin Metrics made with Heart
bStats是一款强大、免费且开源的插件数据统计系统。它可以统计当前正在使用插件的服务器、使用插件的人数、地区等信息。著名的EssentialsX、WorldEdit插件使用的就是bStats。这款统计系统对插件的性能及服务器的网络影响几乎可以忽略不计。它支持Bukkit/Spigot/Sponge/Bungeecord。本教程将演示如何给Bukkit/Spigot插件添加bStats

在下载完后，请将Metrics.java复制到自己的项目里【如果你连如何复制到项目都不会，请好好巩固Java基础】
注意：如果你的插件类型为Sponge，请点击”Using Maven to shade bStats“，并根据提示进行配置。若看不懂英文，请使用百度翻译
第四步
如果你的插件类型是Bukkit/Spigot/Bungeecord
请在onEnable方法中添加以下代码：
  1. metrics = metricsFactory.make(刚刚你记住的数字，比如我的是7700);
复制代码
如果你的插件类型是Sponge，
请按照以下示例进行添加
  1. import com.google.inject.Inject;
  2. import org.bstats.sponge.Metrics2;
  3. import org.spongepowered.api.event.Listener;
  4. import org.spongepowered.api.event.game.state.GameStartedServerEvent;
  5. import org.spongepowered.api.plugin.Plugin;

  7. @Plugin(id = "exampleplugin", name = "ExamplePlugin", version = "1.0")
  8. public class ExamplePlugin {

  10.     private final Metrics2 metrics;

  12.     // The metricsFactory parameter gets injected using @Inject :)
  13.     // Check out https://docs.spongepowered.org/master/en/plugin/injection.html if you don't know what @Inject does
  14.     @Inject
  15.     public ExamplePlugin(Metrics2.Factory metricsFactory) {
  16.         // You can find the plugin ids of your plugins on the page https://bstats.org/what-is-my-plugin-id
  17.         int pluginId = 7700; // <-- 这里填写你记住的那串数字！
  18.         metrics = metricsFactory.make(pluginId);
  19.     }

  21.     // Optional: Add custom charts
  22.     @Listener
  23.     public void onServerStart(GameStartedServerEvent event) {
  24.         metrics.addCustomChart(new Metrics2.SimplePie("chart_id", () -> "My value"));
  25.     }

  27. }
复制代码
到这里，教程就结束了。注意：bStats的统计有延迟，一般为半小时左右。如果你觉得我的教程有用，欢迎给我评分！
