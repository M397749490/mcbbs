作者: 鹿小语    时间: 2019-5-16 10:11
提示旧版本，其实是材质包内pack.mcmeta文件设置问题

  1. {
  2.   "pack": {
  3.     "pack_format": 4,
  4.     "description": ""
  5.   }
  6. }
复制代码
1.8-1.12 pack_format=3            1.13-1.14 pack_format=4


其实你可以尝试修改这个数字来实现新版材质包，但是你要注意，1.12的材质包并不适用于1.13，因为会出现错误材质
