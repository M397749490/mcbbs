那么不多废话了，作为热身的第一章我们就直接进入正文吧——
在本教程中，将使用 Forge1.7.2-10.12.2.1121 作为整个开发环境的底层，请注意你的版本号哟~

作为演示的基础，我们需要一个结构完整的空mod，在这章中，我们就将把最基本的东西打好，并在之后的章节中为这个目前空空如也的mod添砖加瓦。
*包名统一使用cn.graphrevo.xxx,在文章中省略了"cn.graphrevo"。
*对于渲染和图形以外的mod问题，不在此教程的讨论范围内。我会努力的提供最详尽的注释，如果你无法理解的话，请先阅读modding相关的基础教程（问我也可以=w=）。

/graphrevo.java:
这个文件是整个Mod的核心。通过@Mod和@Network注解，Forge了解到这是一个Mod的主类，并在加载时自动载入并调用它，进行mod内部的各种加载。

  2. /**
  3. * 这是整个Mod的主类，负责进行各种注册的调用，提供Mod的基本信息。
  4. */
  5. @Mod(modid = "graph-revo", name = "Graphics Revolution", version = GraphRevo.VERSION) //Mod的基本信息
  6. public class GraphRevo {

  8.     /**
  9.      * 版本号。
  10.      */
  11.     public static final String VERSION = "0.0.1";
  12.    
  13.     /**
  14.      * 日志
  15.      */
  16.     public static Logger log = Logger.getLogger("GraphRevo");
  17.    
  18.     /**
  19.      * 创造模式栏。
  20.      */
  21.     public static CreativeTabs cct = new CCTGraphRevo("graph-revo");
  22.    
  23.     /**
  24.      * 网络包处理。
  25.      */
  26.     public static SimpleNetworkWrapper netHandler =  NetworkRegistry.INSTANCE.newSimpleChannel("net-graphrevo");
  27.    
  28.     /**
  29.      * mod实例。
  30.      */
  31.     @Instance("graph-revo")
  32.     public static GraphRevo instance;
  33.    
  34.     /**
  35.      * 加载代理，由forge来辅助管理。
  36.      */
  37.     @SidedProxy(
  38.             clientSide = "cn.graphrevo.proxy.GRClientProxy",
  39.             serverSide = "cn.graphrevo.proxy.GRCommonProxy"
  40.     )
  41.     public static GRCommonProxy proxy;
  42.    

  44.     /**
  45.      * 加载第一阶段。
  46.      */
  47.     @EventHandler()
  48.     public void preInit(FMLPreInitializationEvent event) {
  49.         log.info("Starting GraphRevo " + GraphRevo.VERSION); //启动信息
  50.         log.info("Copyright (c) Lambda Innovation, 2013-2014");
  51.         
  52.         GRItems.init();
  53.         
  54.         proxy.preInit();
  55.     }
  56.    
  57.     /**
  58.      * 加载第二阶段。
  59.      */
  60.     @EventHandler()
  61.     public void init(FMLInitializationEvent event) {
  62.         proxy.init();
  63.         registerEntity(EntityFreezing.class, "entity_frozen");
  64.     }
  65.    
  66.     static int nextEntityID = 0;
  67.     private void registerEntity(Class<? extends Entity> entityClass, String name) {
  68.         EntityRegistry.registerModEntity(entityClass, name, ++nextEntityID, GraphRevo.instance, 32, 3, true);
  69.     }
  70.    
  71.     /**
  72.      * 加载第三阶段。
  73.      */
  74.     @EventHandler()
  75.     public void postInit(FMLPostInitializationEvent event) {
  76.         proxy.postInit();
  77.     }
  78.    
  79.     /**
  80.      * 服务器加载（注册指令）
  81.      */
  82.     @EventHandler()
  83.     public void serverStarting(FMLServerStartingEvent event) {
  84.         
  85.     }

  87. }

/proxy/GRCommonProxy.java:
这个类是加载代理, 在mod的主类的preInit、init、postInit函数中被分别调用，进行一些内部的加载过程。

  2. /**
  3. * 加载代理（Server端）
  4. */
  5. public class GRCommonProxy {

  7.     /**
  8.      * 执行第1阶段的加载行为。
  9.      */
  10.     public void preInit() {}
  11.    
  12.     /**
  13.      * 执行第2阶段的加载行为。
  14.      */
  15.     public void init() {
  16.         LanguageRegistry.instance().addStringLocalization("ItemGroup.graph-revo", "Graphics Revolution"); //创造模式栏的名称
  17.     }
  18.    
  19.     /**
  20.      * 执行第3阶段的加载行为。
  21.      */
  22.     public void postInit() {}

  24. }

  4. */

  7.     /**

  11.         super(label);
  12.     }
  13.    
  14.     @Override
  15.     public int getTabIconItemIndex() {
  16.         return Block.enchantmentTable.blockID;
  17.     }

  19. }
