AutoPickup

介绍
AutoPickup 是一个简单的插件，可以让玩家直接获得物品和经验，而不是在破坏方块或干掉实体后去拾取地上的掉落物和经验球。
AutoPickup 还可以禁用非玩家玩家击杀的实体掉落物品和经验，例如当太阳升起时烧死的僵尸。

权限
autopickup.entity.experience  允许击杀实体后自动拾取经验球
autopickup.entity.item  允许击杀实体后自动拾取掉落物
autopickup.block.experience  允许破坏方块后自动拾取经验球
autopickup.block.item  允许破坏方块后自动拾取掉落物

配置
AutoPickup 为每个世界生成配置。可以修改这些配置来开启或关闭方块和实体的特定功能。
配置文件可以在 config/autopickup/worlds/ 文件夹中找到，文件结构非常简单但是有关更多信息请查看配置：
  1. Config {
  2.     Enabled=true
  3.     Block {
  4.         AutoPickup-Experience=true
  5.         AutoPickup-Item=true
  6.         FullInventory-Message="(action_bar)&4你的背包已经满了。"
  7.     }
  8.     Entity {
  9.         AutoPickup-Experience=true
  10.         AutoPickup-Item=true
  11.         NoDrop-Experience=false
  12.         NoDrop-Item=false
  13.         FullInventory-Message="(action_bar)&4你的背包已经满了。"
  14.     }
  15. }
  16. Version=1
复制代码

  • AutoPickup-Experience 自动拾取掉落经验
  • AutoPickup-Item 自动拾取掉落物品
  • NoDrop-Experience 自然死亡不会掉落经验
  • NoDrop-Item 自然死亡不会掉落物品
