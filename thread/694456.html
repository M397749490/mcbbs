安装方法
购买本插件，扔进plugins文件夹，重启服务器，把帖内汉化好的语言文件放入相应文件夹，重启服务器

本插件需要3个前置


  • 前置插件1：Vault
基础经济系统，和幸运方块购买有关 站内下载

  • 前置插件2：WorldEdit
和某些生成建筑有关 站内下载

  • 前置插件3：ParticleAPI
和获得物品时的粒子特效有关 外网下载

指令&权限
玩家指令
/lb help 查看指令帮助
/lb buy <数量>  购买幸运方块
/lb shop 打开幸运方块商店


玩家权限

luckyblocksuper.use.break 挖掉幸运方块并获得奖励
luckyblocksuper.use.place 放置幸运方块
luckyblocksuper.use.BuySign 使用木牌购买幸运方块
luckyblocksuper.use.BuyCmd 使用指令购买幸运方块
luckyblocksuper.use.shop 打开幸运方块商店
luckyblocksuper.use.partyblock 使用派对方块
luckyblocksuper.use.ebow 使用爆炸弓
luckyblocksuper.use.redeemcoins 使用幸运硬币兑换钱
luckyblocksuper.use.placeHorse 使用RayHorse方块放置马


luckyblocksuper.use.wand.<魔杖名> 使用魔杖
luckyblocksuper.use.ammo.<可投掷名> 使用可投掷物品
TNT 史莱姆slime 岩浆怪lavaslime 苦力怕creeper 雷电thor 火焰fire 岩浆lava 治愈heal 防御shield 隐身invisible 凋零头wither
这作者搞那么多权限……


管理员指令

/lb admin 查看管理员指令帮助
/lb admin menu 查看管理员物品菜单，管理员可随意获得魔杖等物品
/lb admin give <数量> [玩家] 给予幸运方块，玩家名缺省默认自己
/lb admin givecoins <数量> 给予幸运硬币
/lb admin stopparty 强制停止所有幸运方块派对
/lb admin list <页码> 查看200多种可能性的状态，启用与否
/lb admin reload 重载插件

【圣诞礼物】

可通过商店购买/放置圣诞节方块获得，放置生效，随机获得一个物品


【派对方块】

可通过商店购买获得，放置生效，在60秒内放置点周围会如雨点般掉落普通幸运方块


木牌系统
本插件提供3种木牌，以供方块购买/兑换金钱


【购买幸运方块木牌】

木牌第二行写上!LuckyShop 第三行写上一次出售的数量，即可，玩家点击即可购买


【打开方块商店木牌】

木牌第二行写上!LuckyShop，第三行写上shop，即可，玩家点击即可打开商店


【兑换幸运金币木牌】

方块奖品中有一种奖品是幸运金币，玩家手持金币右键点击该木牌即可兑换随机金钱
木牌第二行写上!LuckyCoin即可创建
