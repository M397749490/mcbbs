前言：


这是原作者制作的第一个mod，有bug可以去curseforge上面进行反馈
本模组需要同时装载Fabric API Mod使用
本模组支持20w07a



这款模组新添了5套基于原版内容的装备

分别是绿宝石、石头（其实是圆石）、安山岩、闪长岩、花岗岩

此模组装备属性只是过渡，实际效果还是钻石套和下界合金套好
