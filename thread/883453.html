插件名
Crawling

作者
Arthed

兼容版本
1.14

介绍
在1.14版本你可以使用活版门或活塞来进入爬行状态，安装了这款插件你只需在洞前按潜行键即可进入爬行状态





洞至少要有两格的长度.


汉化配置
  1. #################
  2. #    Crawling   #
  3. #################

  5. #是否启用查功能
  6. Enabled: true

  8. #玩家是否需权限才能使用该插件功能? (crawl.player)
  9. UsePermissions: false

  11. #消息

  13. AutoCrawlOn: '&6自行爬行&a&l开启'
  14. AutoCrawlOff: '&6自动爬行&c&l关闭'

  16. CrawlAlreadyOn: '&6自动爬行已&a&l开启'
  17. CrawlAlreadyOff: '&6自动爬行&c&l关闭'

  19. NoPermission: '&c你没有权限这么做'

  21. CommandsHelp: '&7-_-_- &6Crawl 指令 &7-_-_- ; ; &6/crawl help &8- &7查看指令 ; &6/crawl &8- &7开关自动爬行模式 ; &6/crawl on &8- &7开启自动爬行 ; &6/crawl off &8- &7关闭自动爬行 ; ; &6/crawl reload &8- &7重载配置'
