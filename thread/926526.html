你没说你用的是什么登录插件。

这里用 authme 为例。
  1. Email:
  2.     # SMTP服务器IP
  3.     mailSMTP: 'smtp.gmail.com'
  4.     # SMTP服务端口
  5.     mailPort: 465
  6.     # 仅适用于25端口,是否启用 TLS/STARTTLS 功能
  7.     useTls: true
  8.     # 发信邮箱账号例如 abc
  9.     mailAccount: ''
  10.     # 发信邮箱密码
  11.     mailPassword: ''
  12.     # 发信邮箱账户,例如 abc@abc.cn
  13.     mailAddress: ''
复制代码

以上的内容均可从你的邮箱提供商处获得， 以 qq 邮箱为例。

填写内容为
  1. Email:
  2.     # SMTP服务器IP
  3.     mailSMTP: 'smtp.qq.com'
  4.     # SMTP服务端口
  5.     mailPort: 465
  6.     # 仅适用于25端口,是否启用 TLS/STARTTLS 功能
  7.     useTls: true
  8.     # 发信邮箱账号例如 abc
  9.     mailAccount: '你的qq号'
  10.     # 发信邮箱密码
  11.     mailPassword: '见我下面的说明'
  12.     # 发信邮箱账户,例如 abc@abc.cn
  13.     mailAddress: 你的qq号@qq.com''
