功能  ↓↓↓

   ①.使用熔炉强化防具和武器
   ②.打怪物/动物有几率掉落强化石(可配置)
   ③.可以设置手上的物品为修复石——修复石名字，描述介绍
         材质全部自定义(可配置) -支持颜色  
   ④.可以设置修复成功公告提示内容-支持颜色  @p代表玩家
   ⑤.本插件还添加了一个指令，可以设置手上物品的名字以及描述介绍哦！-支持颜色
修复石指令


    /xfs get ——【给自己一个修复石】
    /xfs set ——【设置手上的物品为修复石】
    /xfs lore 《名字》《描述》——【修改手上的物品的名字以及描述介绍】
    /xfs message 《信息》——【设置修复成功公告提示的内容，@p代表玩家】
