谢邀，可以使用Sponge核心自带的TileEntity-Activation功能：
方法如下：
1、找到../config/Sponge/global.conf文件；
2、在Modules下找到关键字：“tileentity-activation”，将其值设置为“tileentity-activation=true”
3、在tileentity-activation下找到关键字“auto-populate”，将其值设置为：“auto-populate=true”
4、重启服务器；
5、重启后，Global.conf会更新，在在tileentity-activation下找到关键字“mob_spawner”（参考如下）
  1. tileentity-activation {
  2.         # If 'true', newly discovered tileentities will be added to this config with default settings.
  3.         auto-populate=true
  4.         # Default activation block range used for all tileentities unless overridden.
  5.         default-block-range=64
  6.         # Default tick rate used for all tileentities unless overridden.
  7.         default-tick-rate=1
  8.         # Per-mod overrides. Refer to the minecraft default mod for example.
  9.         mods {
  10.             minecraft {
  11.                 block-range {
  12.                     chest=64
  13.                     "mob_spawner"=64
  14.                 }
  15.                 # If 'false', tileentity activation rules for this mod will be ignored and always tick.
  16.                 enabled=true
  17.                 tick-rate {
  18.                     chest=1
  19.                     "mob_spawner"=1
  20.                 }
  21.             }
  22.         }
  23.     }
复制代码

6、其中在这里：
  1. tick-rate {
  2.                     chest=1
  3.                     "mob_spawner"=1
  4.                 }
复制代码

将1设置为大于1的数。
解释：
        "mob_spawner"=1的意思为1/1的Tick获取效率（即原始刷新速度）
        "mob_spawner"=2的意思为1/2的Tick获取效率（即一半的刷新速度）
        "mob_spawner"=10的意思为1/10的Tick获取效率（即十分之一的刷新速度）
