MineCraft上的神庙逃亡是怎样的呢?


[grid_gold_nugget]这个插件的设定与安卓/iOS平台上的游戏基本相同，只有一点不同——它是一个minecraft上的插件。它会使你的服务器变得更加有趣。

[grid_gold_nugget]有跑酷地图的服务器都可以使用这个插件，在原有地图上的基础上可以带来更好的游戏体验——玩家不损失经验物品、可以快捷地重新开始，跑酷过程中搜集金币增加乐趣……

【注意】问了下作者xapfeltortexp，他表示有人购买了这个插件的所有权。所以呐，Templerun这个插件就不再在Bukkit网站上提供了……我这个帖子还保留了下1.6.2、1.5.2版本的下载地址，其他版本的就不能用了，以后很长一段时间内也不会有新的。 另外推荐一个不用自己造地图的templerun插件：Real TempleRun ，使用起来也是很简单的。

->如何安装和使用
1.下载本插件
2.关闭服务器
3.将TempleRun.jar放入Plugins文件夹
4.打开服务器
5.制作道路，开始游戏
（要自己建游戏场地，设定是玩家掉到水或岩浆就GAMEOVER）

->指令
在游戏中输入 /tr 就可以看到游戏相关指令，指令不多，包括参加结束游戏、设置起始点、显示前十名等.
以下是详细指令和权限：【玩家不能加入的话试试用templerun.play】
指令和描述权限
/tr join [场地名称] = 参加神庙逃亡竞技 [场地名称]templerun.play
/tr leave = 离开游戏templerun.play
/tr creat [场地名称] = 设置起始点templerun.creat
/tr kick [玩家] =使该玩家离开比赛templerun.kick
/tr stop = 停止游戏templerun.stop
/tr start =开始游戏templerun.start
/tr give [数量] = 得到游戏中的金币templerun.give
/tr info =显示你的分数
/tr topten = 显示前十名玩家
/tr pickup = 决定能否收集金币templerun.pickup
/tr delete [场地名称] = 删除[场地名称]场地templerun.delete
其他：
  • /tr winitem add [场地名称] <用户名:数据:数量>=在场地里增加winitem    templerun.winitemadd  （winitem是什么？我这里没法实验一下）
  • /tr ep=是否允许拾起金币 templerun.pickup       
  • /tr arenas =列出所有场地                  
  • /tr update = 检查更新  templerun.update
  • 输入 /Tr give [数量] 就可以得到游戏中的金币（金粒...）。  然后将洒在地上，就跟Templerun一样！

       也可以用金块代替金粒，参见下面的“方块功能”
  • 有关于金粒的BUG:如果你输入/stoplag，worldedit会移除所有的金币
  • 创造一个开始标志（利用[board]告示牌，权限为templerun.create）

->方块功能
  • 钻石块：让玩家跳得更高（玩家会一下子蹦起来，基本就GAMEOVER了）
  • 绿宝石块：让玩家拥有南瓜头盔（这样玩家就看不清路了）
  • 金块：给予玩家金币
