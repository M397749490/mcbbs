求最全的粒子指令教程，么有的话告诉我在玩家a和玩家b之间产生一条粒子线
作者: Chelover_C60    时间: 2019-4-20 13:01

命令只有一个particle，用法也只有一个，要达到更复杂的目的只能用不同命令搭配。
1.12只能穷举玩家之间的方位，再想办法生成粒子
1.13需要生成大量盔甲架，然后用execute调整方向，然后tp，再生成粒子(可能需要过多的实体，可行性不高)。或者借助function写循环结构。

以下介绍1.13借助function生成粒子的方法
首先激活以下命令，一次即可
  1. /tag <玩家A> add start
  2. /tag <玩家B> add end
复制代码
然后按一定频率并按顺序激活以下命令。频率可以自己控制
  1. /execute at @a[tag=start] run summon armor_stand ~ ~ ~ {Invisible:1,Tags:["particle"]}
  2. /execute as @e[tag=particle] at @s facing entity @a[tag=end] eyes run tp ^ ^ ^1
  3. /execute as @e[tag=particle] at @s run function exa:line
  4. /kill @e[tag=particle]
复制代码
以下为函数exa:line的内容：
  1. particle happy_villager ~ ~1 ~
  2. tp ^ ^ ^1
  3. execute unless entity @a[tag=end,distance=..1] run function exa:line
复制代码

关于函数，可以参考【1.13-1.14】数据包(原版模组)入门教程
