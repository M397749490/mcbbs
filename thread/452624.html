§1.4 编写我的第一个Java程序
本节学习：编写我的第一个Java程序(输出HelloWorld!)
首先在一个文件夹（我直接在桌面）新建一个Java源文件：HelloWorld.java

然后用记事本 或者Notepad++打开，我推荐用Notepad++。


右击源文件，点击"Edit with Notepad++"

然后敲入以下代码：
  1. <div>public class HelloWorld</div><div>{</div><div>
  2. </div><div>}</div>
复制代码
再写一个方法，是一个公用(public)、静态(static)、返回值为空(void)、名字叫main、有个String（字符串）的数组参数，叫args。
至于那些public,static,void什么的，我们以后再讲。
输出内容的代码：
  1. System.out.print("输出的内容");
复制代码

我们要输出HelloWorld! 那么就把输出的内容替换成HelloWorld!吧。

注意：
· Java中对大小写敏感，也就是说ABC和abc是不一样的
· 每一个语句在结束时都要有一个半角分号

写完了代码，我们轻敲Ctrl+S保存代码，然后按下Win+R，在运行窗口中的“打开”编辑框输入cmd，按确定。
弹出了命令行窗口，输入：cd 源文件的路径。
我的源文件在桌面，所以只需要cd desktop即可。
再输入javac HelloWorld.java(编译HelloWorld.java)
过了一会，cmd窗口什么也没发生，我们再输入：
  1. java HelloWorld
复制代码
大约1秒后，输出了HelloWorld!。
至此，你成功编写了你的第一个Java程序。
