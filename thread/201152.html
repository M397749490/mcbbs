目测Lz不是小白- -    送金币？

      打开服务端内的：启动服务器.bat文件

      如果没有，Lz需要建立一个txt   

然后输入以下内容：
  1. @ECHO OFF

  3. color c
  4. title
  5. SET BINDIR=%~dp0
  6. CD /D "%BINDIR%"

  8. "%ProgramFiles%\Java\jre7\bin\java.exe"【这个是默认路径--（我可以删掉）】 -Xmx1024M -Xms512M -jar 这里输入你服务端.jar的名字
  9. PAUSE
