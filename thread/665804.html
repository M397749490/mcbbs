这不能设置的，用计分板可以的,手动输入
  1. /scoreboard objectives add 任意名字 dummy
复制代码

任意名字自己填写，不要重复
然后弄个高频连接命令方块
  1. /scoreboard players add 任意名字2 计分板名字  1
复制代码

※同时连接又连接一个命令方块
  1. /testfor @r[score_计分板名字=2]
复制代码

标有※命令方块后面加上比较器，比较器连接一个红石，红石连接一个命令方块输入
  1. /scoreboard players set 任意名字2 计分板名字 0
复制代码

任意名字2随便写，但是任意名字2必须全部相同，计分板名字=手动输入的那个任意名字
然后在放方块的地方分别连接命令方块，注意是分别连接
  1. /testfor 任意名字2[score_计分板名字=0]
  2. /testfor 任意名字2[score_计分板名字=1]
  3. /testfor 任意名字2[score_计分板名字=2]
复制代码
然后三个分别对应一个setblock命令方块
  1. /setblock x y z 137 0 keep NBT
复制代码
  1. /setblock x y z 137 0 keep NBT
复制代码
  1. /setblock x y z 137 0 keep NBT
复制代码
注意三个x,y,z不一样哦！NBT自己写，后面不是叫你输入NBT
