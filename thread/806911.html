口渴插件

想要给服务器增加难度？这个插件可以让你在服务器增加口渴的状态，利用水瓶在里面体验更真实的感觉。
介绍
    口随着时间而减少，需要玩家喝东西
    口渴会无视玩家的创造（就是说创造也要喝水）
   就算下雨口渴也不会增加，只会暂停口渴[但也不会增加]
    在某些口渴级别会有一些表现
    玩家越口渴，效果越明显
    如果口渴度为0时会掉血
    通过游泳或饮用东西来补充干渴
还能和 ArmorWeight worldguard 插件互相配合使用？
工艺
可堆叠的水瓶(数量可配置)
能够在寒冷地区制造/融化雪球成水瓶
能在炉子中产生开水(目前还没有用)
添加您自己的自定义药水配方
GUI
BARAPI支持
BossBarAPI支持
在1.8中通过操作栏获取口渴信息的能力
口渴记分板启用，可查看口渴程度
计分板能够支持，变量 = %thirst%
指令
/thirst help - 查看指令帮助
/thirst check - 检查你的口渴程度
/thirst refresh me - 让自己不口渴 (需要权限)
/thirst refresh <玩家> - 让其他玩家不口渴 (需要权限)
/thirst set <玩家> <程度> - 设定一个玩家的口渴度 (1就是1%)
/thirst ignite - 被插件逼疯 烧死自己
/thirst debug- 调试控制台？
权限
thirst.refresh - 刷新自己口渴
thirst.refresh.others - 刷新其他玩家口渴
thirst.set.others - 设置口渴的权限
thirst.immune - 烧死自己

thirst.debug- 调试控制台权限
