标题: 怎么修改领地上限？
作者: dxcfbb    时间: 2014-4-20 09:18
如果你是OP,可以无限创建：
/resadmin create <领地名称>           ——无限创建领地

/resadmin remove <领地名称>          ——强制删除别人的领地或者自己的


作者: dxcfbb    时间: 2014-4-20 09:21
打开领地插件文件夹的config找到以下：
Residence:
           # Determins if this group can create residences or not.  This option can be overriden with the permissions node 'residence.create'
           CanCreate: true           
           # The maximum number of Residences a player can have.
           MaxResidences: 5                             ——设置最多能创建多少领地
