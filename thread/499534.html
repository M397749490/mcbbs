ess的config里可以设置。
  1. # 定义玩家每次使用命令时所要花的钱,空格由"-"代替,带有"example"的是例子.
  2. #一些命令例如/repair拥有独立的花费,可以在essentials wiki查看更多信息
  3. command-costs:
  4.   # /example costs $1000 PER USE
  5.   #example: 1000
  6.   # /kit tools costs $1500 PER USE
  7.   #kit-tools: 1500
