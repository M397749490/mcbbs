作者: yao_yao_QQQ    时间: 2020-8-21 18:26
1.7建议穷举，我觉得你如果不是做生存的话不会用到那么多等级
即 /scoreboard players set @a[l=a,lm=a] A a   A是你计分板的名字，记得用类型为dummy
这里的a是每一个等级,如果你要写最大到5级的话，就写十个这样的命令然后用指令循环执行,如
/scoreboard players set @a[l=1,lm=1] A 1
/scoreboard players set @a[l=2,lm=2] A 2
/scoreboard players set @a[l=3,lm=3] A 3
/scoreboard players set @a[l=4,lm=4] A 4
/scoreboard players set @a[l=5,lm=5] A 5
[可能会比较卡，但是只能这样了]
当然建议升级，1.7指令太少了
