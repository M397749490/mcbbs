新人翻译，若有错误的地方，欢迎修改。(由于NPC村庄的地址崩了，请大家自己寻找）

build 1 加入村庄，它们由砾石，木板和沙石的桥梁生成。
build 2 沙漠村庄现在由沙石组成。
0.9.0 build 4 使村民更稀有。
build 7 使村民更普遍。
0.11.0 build 1 草径 在村庄中替代了砾石。
0.12.1 build 1 更大的村庄现在生成 铁傀儡来保护村民。
build 8 农田现在包括甜菜根 作物。
0.14.0 build 3 增加门与村民的比（以前是1:1）。
0.15.0 build 1 加入热带草原村庄和针叶林村庄。
为了翻译，我连续做了2次检查。第一次，我把所有的句号都补上了；第二次，我把“稀树草原”改为”热带草原“。
