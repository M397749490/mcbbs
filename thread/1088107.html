实现的功能：
  • 自定义创建跑酷简便，免去指令小白玩家建造跑酷地图时的困扰。
  • 玩家跑酷时自动为其记时，使跑酷更有趣味性。
  • 使用者可以在一个地图中无限生成跑酷，一个跑酷中可以有无限个途径点。


使用方法：
创建地图时：
第一步：输入/function parkour:init以初始化。
第二步：输入/function parkour:new以创建新跑酷。

第三步：站在您的跑酷起点，右键点击绿色玻璃板以在当前位置创建起点，其他途径点（黄色玻璃板）、终点（红色玻璃板）以此类推。
第四步：在所有起点、途径点、终点全部设置完成后，点击门以结束。
如果要创建第二个跑酷，按照2到4步进行即可。
如果结束时起点途径点终点中任何一个没有设置，则会将该跑酷全部删除（不会破坏地形）。
如果您放错了途径点，可以通过右键左数第二个屏障删除上一个途径点。
如果您想要放弃这个跑酷，可以通过右键左数第一个屏障删除该跑酷（不会破坏地形）。
如果您要删除一个跑酷，请输入/scoreboard players set #remove parkour_remove <要删除的跑酷id> ,删除后会自动补全id
例子：如要删除4号跑酷，则应当输入/scoreboard players set #remove parkour_remove 4


玩家跑酷时：
第一步：到起点  未在创建中的大厅玩家到起点后会自动开始计时
第二步：依次通过途径点  玩家不可以跳过任何一个途径点，否则到其他途径点/终点时不会被检查。
第三步：到终点  
在通过途径点和终点时，会显示从开始时到当前的计时（分：秒：毫秒）

注意事项：
  • 在生成起点和终点时，如果更改他们，会在原位留下一个金压力板，别忘把它删除哦！
  • 由于本数据包使用的是村民糊脸检测右键，所以在跑酷或创建跑酷时尽量不要因为其他原因使用右键，同时，速度过快也会导致无法检测右键。
  • 不要将起点终点途径点放在不完全方块上（如栅栏，箱子，下半部分半砖），否则他们会被吞掉的。


如果您要删除本原版模组，请先在聊天框中输入/function parkour:remove ，然后删除原版模组本身。
