作者: 白琥    时间: 2015-11-13 23:58
①先用多世界创建一个VIP世界
②将文件中./plugins/GroupManager/config.yml中
  1. mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.      world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds:
  16.           - users
  17.           - groups
  18.           VIP:    #这里向我这样添加
  19.       - users
  20.           - groups
复制代码

做完以上事情后重启服务器

③将./plugins/worlds/VIP/groups.yml里面的
  1. Builder: #这里修改成VIP
  2.     default: true
  3.     permissions: []
  4.     inheritance:
  5.     - default
  6.     - g:essentials_builder
  7.     - g:towny_builder
  8.     info:
  9.       prefix: '&2[玩家]'
  10.       build: true
  11.       suffix: ''
复制代码

并且新建一个新组命令为Builder，不给予任何权限

④之后进入VIP世界，然后将VIP玩家拉入VIP权限组里面
这样，普通玩家进入该世界将无权限破坏任何物品
VIP玩家却可以正常游戏

如果有帮助到你，望采纳~
