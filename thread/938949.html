作者: SPGoding    时间: 2020-1-7 18:14
你自己生成的末影龙是不会自带血条的，所以要自己加一个。

首先设置 bossbar（每个世界只需要执行一次）：
  1. bossbar add xxx {"translate": "entity.minecraft.ender_dragon", "color": "reset"}
  2. bossbar set xxx players @a
  3. bossbar set xxx color pink
  4. bossbar set xxx max 200
复制代码


生成末影龙：
  1. summon ender_dragon ~ ~ ~ {DragonPhase: 0, Tags: ["ooo"]}
复制代码


每刻高频执行（用循环命令方块，或有 #tick 标签的函数）：
  1. execute if entity @e[type=minecraft:ender_dragon,tag=ooo] run bossbar set xxx visible true
  2. execute unless entity @e[type=minecraft:ender_dragon,tag=ooo] run bossbar set xxx visible false
  3. execute store result bossbar xxx value run data get entity @e[limit=1,type=minecraft:ender_dragon,tag=ooo] Health
复制代码


以上命令中的 xxx 表示 bossbar 的 ID，ooo 表示该特定末影龙的标签，可以自己换，也可以不换。
