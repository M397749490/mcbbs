大家好我是小喵
这是我搬运的第一个插件
SlimeMobs -- 粘液生物

这个插件可以使玩家杀死生物后掉落SlimeFun的物品
前置插件SlimeFun(1.9的汉化插件也在下载链接里),CS-CoreLib(SlimeFun会自动下载)插件截图
使用方法:扔进Plugins文件夹重启服务器
插件配置：
  1. options:
  2.   auto-update: true //自动更新，如报错可以关闭
  3. dropchance: 15 //百分比，掉落物品的几率
  4. enabledEntities: //开启掉落物品的生物
  5.   CREEPER: true
  6.   SKELETON: true
  7.   SPIDER: true
  8.   GIANT: true
  9.   ZOMBIE: true
  10.   SLIME: true
  11.   GHAST: true
  12.   PIG_ZOMBIE: true
  13.   ENDERMAN: true
  14.   CAVE_SPIDER: true
  15.   SILVERFISH: true
  16.   BLAZE: true
  17.   MAGMA_CUBE: true
  18.   WITHER: true
  19.   BAT: true
  20.   WITCH: true
  21.   ENDERMITE: true
  22.   GUARDIAN: true
  23.   PIG: true
  24.   SHEEP: true
  25.   COW: true
  26.   CHICKEN: true
  27.   SQUID: true
  28.   WOLF: true
  29.   MUSHROOM_COW: true
  30.   SNOWMAN: true
  31.   OCELOT: true
  32.   IRON_GOLEM: true
  33.   HORSE: true
  34.   RABBIT: true
  35.   VILLAGER: true
  36. items: //该选项包含的所有slimefun物品。所有的物品都是默认启用。
  37.   EXAMPLE_ITEM: true //如果你不想让这个物品掉落，请设置为false
复制代码
指令/权限
  1. /batchset <true|false>
  2. 此命令允许您设置“物品”节点下的所有项目为false
  3. 权限:slimemobs.batchset
