好了言归正传，开始写经验心得了。本次心得是Ta制作【出来吧，比卡丘】这个MOD总结出来的一些经验，主要包括物品制造机和炸弹这两个东西的相关制作，我会分开来进行讲解。不足和不对之处敬请谅解和指正。

投掷炸弹的制作。
       一、结构：武器相对于装备来说所关联的文件多了很多，缺少任何一环都会造成出错或者无限Loading，所以搞清楚其关联的文件是我们第一步要做的。因为为了让制作的MOD的含义和结构更清晰，所以我一般会为MOD文件都准备一个文件夹，除非是单文件。好了，现在我把结构图展示出来，其中会标明每个目录的文件的作用：
不知道你有没有被这个文件结构吓到，我反正是做到一半的时候都快放弃了。不过大家不要被这个貌似庞大的体系所吓倒，我下面所说的内容会让你发现其实这个结构很好理解：
      1、  首先，我们需要设计一个炸弹的道具，也就是item，这里面包括炸弹的属性：.thrownitem，比如多大威力啊啥的，当然也需要这个炸弹在我们手中和在道具栏中的样子的图片：.png。
     2、  然后，我们需要这个炸弹飞行和爆炸时候的造型，也就是projectiles。在这里面分为三部分，爆炸的样子：explosions，飞行时的样子：throwable，物理引擎：physics.config。a)     爆炸的样子是必须的，也是华丽丽效果的主体，我们需要一张图片：.png，然后需要将这个图片分解成几部分，让这几部分进行循环播放成为动画：.frames，接着就是爆炸效果的参数：.projectile，最后我们还要为这个动画设置他播放动画的参数，甚至给他加上辅助动画，让他更加的华丽：.config。b)     当然我们还需要炸弹扔出去后在空中飞行的样子，这样才能让我们了解炸弹的飞行轨迹，才能掌握好Fire in thehole的精髓，我们依然需要一张图片：.png，然后对这个图片进行分解：.frames，然后依然是飞行效果的参数：.projectile。c)     最后我们还需要给我们的炸弹设置一下他所用的物理引擎：physics.config。
      3、  正如2-a中所说我们可能需要为爆炸的动画添加更华丽的特效，那么我们就需要一个animations，里面是我们为爆炸特效设计的更多的辅助效果，当然也还是包括图片.png，分解：.frames，最后依然是动画参数：.animation。
      4、  除了华丽的爆炸外，怎能缺少震撼的音效？？于是我们需要再sfx文件夹里添加一个荡气回肠的.wav。
      5、  到此，一个完整的炸弹就设计好了，当然我们还需要设置一个制造炸弹的材料清单：.recipe。
      6、  最后，给我们这个MOD加上一个描述文件.modinfo，否则游戏不会读取这个MOD的。基本上，炸弹的基本结构描述就是如此，是不是发现理顺思路后，其实挺简单的？那么接下来我就会告诉你制作一个炸弹的步骤了：

      一、       步骤：我们设计一个炸弹，首先从道具属性入手，然后再是样式（这里包括主体动画、辅助动画、声音），最后才是制作清单和MOD描述。一步步来，思路才能清晰。1、  道具属性：item：如果认真阅读过我的第一篇经验谈，应该知道item文件的大部分属性参数的含义了，为了方便制作，我还是把所有属性参数的含义列出来：
  itemName 道具ID名称（英文）
rarity 稀有程度
inventoryIcon 物品栏里和简介里的图形（这里不知道为何，不能像身上装备一样给他设置单独的简介里的图形造型，也就是说largeImage这个属性是无效的）
image 拿在手上的样子
shortdescription 游戏中显示的道具名称（中文要转码）
description 游戏中显示的道具简介（中文要转码）
maxStack 最大堆叠数
ammoUsage 每次使用的消耗量，设置为0则为不消耗
edgeTrigger 是否在触碰到怪物后立即触发爆炸
windupTime 触发爆炸的延迟时间
cooldown CD冷却时间，每次扔炸弹的间隔时间
projectileType 炸弹爆炸和飞行时的动画样式，这里的文件关联着projectiles文件夹
projectileConfig 炸弹飞行的速度speed和爆炸威力power  
1、  道具动画：projectiles：道具动画分为三部分：爆炸的样子：explosions，飞行时的样子：throwable，物理引擎：physics.config。我们分别进行说明：a)  爆炸的动画：explosions.png是你为动画设计的每个帧的造型。如下图：

你可以设计为更多或更少的帧，也可以通过.farmes来控制只显示哪些帧。
.frames是图片分割的设置，文件里的属性参数含义为：
  size  
显示在游戏中的图片尺寸，一般为每帧的尺寸大小
dimensions
图片分割，第一个参数是列，第二个参数是行。比如例子里的图就可以分为8列1行，共8帧
names
为你的每帧动画标识ID号，设置了多少帧就要命名多少个
.config文件是为你的动画设置各种参数，比如动画主体、辅助动画、声音、是否能破坏环境等等，文件里的属性参数含义为：
  action：projectile  
是主体动画

inheritDamageFactor
这个参数的含义不是太明白
type
爆炸类型，这里关联同目录下的.projectile文件，设置为该文件的文件名即可
action：loop
是辅助动画的属性，不需要的话可以不写。loop 是环状特效，会把动画文件绕一个圈好几个循环同时一遍

count
动画循环次数
body
这是辅助动画显示的内容，在这之下可以放入多个动画效果

action：option
辅助动画文件就放在这里面

action：particle
粒子属性，这里为粒子效果
specification
具体的参数都在这个属性之下

animation
使用的辅助动画的文件，关联到animations目录
size
效果的放大倍率
initial
这个不清楚
rotation
旋转，但是设置了没有明显的什么效果
timeToLive
存在时间，一般和主动画存在时间一致就行
action：spark
这个会给你的爆炸添加火花溅射的效果
action：sound
是声音文件，也就是爆炸时候的声音特效，关联到sfx目录
action：light
是炸弹飞行时会发光
.projectile文件是爆炸主体动画的属性参数，具体参数含义如下：
  projectileName  
爆炸主体动画ID名称（英文）
frames
爆炸主体的动画图片
animationCycle
多少秒循环一次动画，比如你设置的是1秒，总共5帧，那么每帧显示的时间是0.2秒
level
这个含义不明
frameNumber
动画帧数，这个跟你的图片一致就行了
speed
速度
fallSpeed
下降速度，跟上面那个速度一样，没去修改测试，不知道有何影响
damagePoly
这个不明白是什么参数
animationLoops
动画是否循环，ture的话会播放很多次
piercing
是否穿刺，这个不明白是指伤害还是指图片的显示，没测试
flippable
是否可以翻转，这个设置会影响动画的形式
universalDamage
机翻是：普遍伤害。我的理解是图片覆盖范围以内都能造成伤害
damageKind
伤害类型，没研究，一般为default
     飞行的动画：throwable这个文件夹控制的是炸弹扔出去后在空中飞行时的动画效果。图片.png和分割.frame的问题就不累述了。.projectile是飞行动画的各种参数的设置，具体参数含义如下：
  projectileName  
飞行动画ID名称（英文）
frames
动画图片的文件
animationCycle
多少秒循环一次动画，比如你设置的是1秒，总共5帧，那么每帧显示的时间是0.2秒
level
这个含义不明
timeToLive
这个存在时间其实是炸弹从扔出后到自然爆炸之间的最长存在时间
physics
使用的物理引擎，这里关联到了物理引擎文件physics.config
frameNumber
动画帧数，这个跟你的图片一致就行了
lightColor
飞行时发的光的RGB参数
bounces
反弹次数，这里是说在存在时间内，炸弹最多反弹几次。如果设置为0，就不会反弹，碰到阻碍物就直接爆炸
actionOnReap
爆炸动画的样式，这里关联到了爆炸动画样式所在文件夹projectiles
power
爆炸的威力
damageType
伤害类型，这个没深究，就用的默认的值
damageKind
也是伤害类型，也没去深究了，一般为default
damagePoly
这个不明白是什么参数，不知道是不是伤害浮动值？还是暴击浮动值？默认就行了，影响不大
emitters
这个也不太明白是什么属性
      物理引擎：physics.config这个文件里有各种道具的物理引擎，为了避免和系统文件冲突，我们将炸弹的物理引擎复制一份并设置一个新名称，这样就能减少报错的几率，即便修改了参数也不会影响其他道具。这些参数我都没去测试具体影响哪些属性，所以大家看看就可以了，没有特殊要求的就没必要去特意修改，有时间自己可以做做测试。
      1辅助动画：animations：辅助动画其实有没有都无所谓的，如果不需要辅助动画的话，这个文件可以不需要去管。我在这里说明一下，只是给大家一个概念，这样有利于大家丰富和完善自己的MOD特效。辅助动画其实没有什么特殊的内容，跟其他动画设计是一样的，图片.png，分割.frame都不再累述了，.animation文件里的参数含义如下：
  frames  
动画ID名称（英文）
variants
这个意义不太明白，修改了后没有发现明显的变化
frameNumber
帧数，和你的.frame设置的值一样就行
animationCycle
多少秒循环一次动画
offset
这个参数不明
1、         声音特效：sfx：声音特效的问题没有别的什么特别的，只要注意两点：a)   必须是.wav格式，否则游戏会强退b)   要转换为44100Hz，16Bits，PCM的wav格式，测试了一些其他格式都不行，但这个肯定行。可能还有其他格式，但有一个能用的就够了 2、         制作清单：recipe：这个其实也不用再说啥了。input，放入的材料output，做出的东西但是有一点要说明的。groups：    如果是让这个道具出现在MOD道具制造机里，就在里面添加 “mod”，如果是让道具出现在我们自制的物品制造机里，那么就要给他加上我们给这个制造机命名的物品制造机平台ID。这在后面设计物品制造机中会提到。 3、         MOD描述：modinfo：描述文件就不用再说了吧，少了这个游戏就不会读取这个MOD ==================================================好了，炸弹的设计就告一段落了。
