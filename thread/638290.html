作者厨房原文
Main Reference image:
Build Size: 354 x 344 x 256
This build was mainly for me to practice my ability to scale things in proportion with each other properly with the main reference image, but also to work withing the build height limit (#raisebuildheight2016) and make everything look as realistic as possible. I am super proud of how realistic and dope it turned out and i hope you all like it as well :) most cabinet work was from the reference pic and then i took a little liberty with it in the end to add in some color.

主要参考图片：
建造尺寸：354×344×256
这个建筑主要是锻炼我把参考图片的建筑比例缩到游戏比例的能力。
并且练习在建筑最高高度(2016最高建筑高度)这样的条件下，使建筑看起来更加真实。


我最得意的一点在于我能让它变得更逼真并且给他涂上合适的颜色，希望你们喜欢:)
大多数的柜橱作品都是严格照搬参考图片上，而我建造时有点放开，我会在柜橱建造完毕时给它上点儿颜色。

-remind-下载与安装
Save存档(正版用户):关闭Minecraft，在Windows开始菜单的搜索框中输入%appdata%/.minecraft，然后按下Enter（回车）按键。把从百度网盘下载回来的地图存档解压缩放到.minecraft\saves文件夹里面。
Schematics存档：这类型需要MCEdit。下载完成后解压到桌面，关闭Minecraft，双击mcedit.exe，点击下方import按钮，打开你下载的文件到你需要放的地方，最后点import，按Ctrl+s保存，Ctrl+w关掉存档，点Quit退出。
