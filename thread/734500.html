你是否还在为服务器的配置和价格发愁？你是否还在为没有公网IP而忧心？
搭建穿透来在本地运行服务器吧！


首先，你得有个VPS和一个域名（没备案的也行）。
1.创建centos6系统（不推荐7）




2.使用Xshell连接

这样就算连接好了。


3.为你的域名添加泛解析。
打开你的域名管理页面，

在主机名位置添加*号，把对应值指向你的服务器IP。


4.安装git、go、ngrok。
这里参考了sunny的博客，地址：http://www.sunnyos.com/article-show-48.html
使用命令：下载git所需要的依赖包
  1. yum -y install zlib-devel openssl-devel perl hg cpio expat-devel gettext-devel curl curl-devel perl-ExtUtils-MakeMaker hg wget gcc gcc-c++
复制代码


再下载git
  1. wget https://www.kernel.org/pub/software/scm/git/git-2.6.0.tar.gz
复制代码


再使用命令解压git
  1. tar zxvf git-2.6.0.tar.gz
复制代码

再使用命令编译git。
  1. cd git-2.6.0
  2. ./configure --prefix=/usr/local/git
  3. make
  4. make install
复制代码

最后输入来创建git的软链接
  1. ln -s /usr/local/git/bin/* /usr/bin/
复制代码

安装go
下载go环境包
由于编译go需要1.4的版本（最新版本会编译失败），但是go中国网站并没有这个资源，所以我这里提供一个下载
https://share.weiyun.com/5e10ab460e27da7bf637f2bd3bef8a7f
再使用flashFXP进行连接
点击站点》站点管理器》新建站点》输入名称》连接类型选择SFTP over SSH》输入用户名和密码

把go放到root目录下

解压go环境包
  1. tar -zxvf go1.4.2.linux-amd64.tar.gz #64位
  2. tar -zxvf go1.4.2.linux-386.tar.gz #32位
复制代码

指定位置
  1. mv go /usr/local/
复制代码

添加GO的软链接
  1. ln -s /usr/local/go/bin/* /usr/bin/
复制代码

编译NGROK
  1. cd /usr/local/
  2. git clone https://github.com/inconshreveable/ngrok.git
  3. export GOPATH=/usr/local/ngrok/
  4. export NGROK_DOMAIN="ngrok.mcpyjiaoyi.top" #注意这里改成自己的域名
  5. cd ngrok
复制代码

生成证书
  1. openssl genrsa -out rootCA.key 2048
  2. openssl req -x509 -new -nodes -key rootCA.key -subj "/CN=$NGROK_DOMAIN" -days 5000 -out rootCA.pem
  3. openssl genrsa -out server.key 2048
  4. openssl req -new -key server.key -subj "/CN=$NGROK_DOMAIN" -out server.csr
  5. openssl x509 -req -in server.csr -CA rootCA.pem -CAkey rootCA.key -CAcreateserial -out server.crt -days 5000
复制代码

复制证书到指定位置
  1. cp rootCA.pem assets/client/tls/ngrokroot.crt
  2. cp server.crt assets/server/tls/snakeoil.crt
  3. cp server.key assets/server/tls/snakeoil.key
复制代码
询问你是否覆盖的时候 输入Y加回车

4.编译服务端
32位：
  1. cd /usr/local/go/src
  2. GOOS=linux GOARCH=386 ./make.bash
  3. cd /usr/local/ngrok/
  4. GOOS=linux GOARCH=386 make release-server
复制代码


64位
  1. cd /usr/local/go/src
  2. GOOS=linux GOARCH=amd64 ./make.bash
  3. cd /usr/local/ngrok/
  4. GOOS=linux GOARCH=amd64 make release-server
复制代码
5.编译windons客户端
  1. cd /usr/local/go/src
  2. GOOS=windows GOARCH=amd64 ./make.bash
  3. cd /usr/local/ngrok/
  4. GOOS=windows GOARCH=amd64 make release-client
复制代码

6.启动服务端
  1. /usr/local/ngrok/bin/ngrokd -domain="$NGROK_DOMAIN" -httpAddr=":80"
复制代码

7.配置客户端
打开flashFXP连接到VPS，在目录usr/local/ngrok/bin/windons_amd64下面有个ngrok.exe就是客户端了
把它下载到本地电脑。
新建一个TXT，复制以下内容
  1. server_addr: "ngrok.mcpyjiaoyi.top:4443" #你自己的域名，端口输入4443
  2. trust_host_root_certs: false
复制代码
另存为 ngrok.cfg

打开文本文档，复制以下内容
  1. ngrok -config="ngrok.cfg" start mstsc
复制代码
另存为 启动.bat
客户端配置完成后有这三个文件

保存完毕点开启动.bat，这样显示就说明穿透成功

打开服务器测试一下

成功





备注：连接失败问题：严格检查配置文件中域名是否和设置一样
                              检测服务器时间是否正确
                              查看端口是否开放，可以使用以下命令来开启端口
  1. /sbin/iptables -I INPUT -p tcp --dport 8080 -j ACCEPT #开启8080端口  
  2. /etc/rc.d/init.d/iptables save #保存配置  
  3. /etc/rc.d/init.d/iptables restart #重启服务  
复制代码


          Xshell断开连接后，端口映射也会断开问题，可以安装screen来保持连接。详情请看：
          http://blog.csdn.net/eagle5063/article/details/53843211
