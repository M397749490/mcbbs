常量
OK，如题，咱们一一对应，先来讲常量吧！
常量这个玩意儿啊，你要知道，这玩意儿在程序运行中是不能变的。
上过初中数学的应该都知道，常量就是在一个变化过程中不变的量，
你说，“我就是想变怎么办？”
能咋办？panic劝退，Panic：走走走，一边去
咳咳，下面就来看看其一般表现形式吧！
  1. const name type //定义一个常量
复制代码

此例中，const是声明常量的关键字，name则为常量字面量（其实就是名字）
type 就是类型啦！
常量也可以一次定义多个
就比如下面这个
  1. const (
  2. a,b,c,d
  3. )
复制代码

咱们还能从里面看出一个东西，常量是可以隐式声明的，也就是省去类型(你甚至可以使用中文定义常量名)，编译器直接给你搞定
（多棒的设计）
咱们还要知道一个东西，Go里面是没有枚举(enum)类型的，别忘了，咱还有常量呢！
如下面的例子哈！
  1. const (
  2. Connected = 0
  3. Disconnected = 1
  4. Unknown = 2
  5. )
复制代码

咱在上述例子中定义了一组枚举类型，分别表示连接的状态
那么，我们要记录一周七天怎么弄呢？
  1. const(
  2. Monday = 1
  3. Tuesday = 2
  4. Wednesday = 3
  5. Thursday = 4
  6. Friday = 5
  7. Saturday = 6
  8. Sunday = 7
  9. )
复制代码

这样写吗？不不不，这样太麻烦了，也没有一点技术含量
那么，怎么解决呢？
简单，只需要让第一个变量的值为 iota 就好啦！
咱们来修改一下

  1. const (
  2. Monday = iota
  3. Tuesday
  4. Wednesday
  5. Thursday
  6. Friday
  7. Saturday
  8. Sunday
  9. )
复制代码

对，只需要这么简单
那么，什么是 iota 的功能呢？
它啊， 你只要在一个常量赋值为他，后边的都会自动的+1，相当隐式的声明后边的啦！当然 iota 是从0开始数的

OK，接下来咱们来介绍变量

变量
变量是个好东西，能帮我们做很多，比如做一个表达式就需要变量来。
那么什么是变量呢？顾名思义，就是 可以变的量
怎么样？没想到吧？以为我要说什么很长的听不懂的？
不存在的（滑稽）
咳咳，变量的一般形式为
  1. var name type
  2. name := value
复制代码

第一个是使用 var 关键字来声明一个变量  name  和  type 的含义同上
第二个，哼哼，非常简便是不是？
这就是golang的另一种声明变量的方法啦！
使用 := 直接赋值，但是只能在函数中用诶
