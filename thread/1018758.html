       这次还原的作品是1997年上映，由冯小刚导演，葛优、冯小刚、刘蓓等主演的喜剧电影《甲方乙方》，选择了电影开头一个卖书商扮演巴顿将军，在作战室开会的场景，其“地图找不着”的名句流传甚广。个人觉得这电影充满了京味的幽默，现在看也十分有趣。

【南_京地图的制作】

本想用挂画做，但不允许替换材质，所以改用地图+展示框制作而成


首先将视频截图，缩放到3：2的大小


然后做地图的方法有两种；
一是用像素画生成器生成，然后拿着地图走出来，不过要计算好地图大小，然后从每块地图的中间开始，比较麻烦


我是选择用MCMapGenerator直接生成地图，比较方便


用方法一走出来的地图可以直接挂在展示框上，用方法二的话先在游戏里做出使用的地图，然后将MCMapGenerator生成的地图覆盖存档里data文件夹下相应编号的map_“数字”.dat文件即可。

在做图过程中发现：
这哪里是南_京地图啊！！！



将军：姚司令，你解释一下
姚司令：将军，时间紧，您先凑合部署，行动时我们再看着办




【将军与部下】

本来是画了皮肤，想找人站位来拍照，但无奈找不到人，只好将村民当做材料，做成建筑的一部分了。（文末附皮肤下载）
自己研究了下，使用代码生成村民。
为符合电影场景，村民的职业选择了一身绿的“傻子”，将军为普通村民，部下选择了头顶有像军帽一样东西的沼泽生物群系的村民。
下面介绍代码

将军
  1. /summon minecraft:villager ~ ~0.5 ~
  2. {
  3. NoAI:1b,
  4. VillagerData:{profession:"minecraft:nitwit"},
  5. Rotation:[-30.0f,-10.0f,],
  6. HandItems:[{id:"minecraft:stick",Count:1b,Damage:0s}]
  7. }
复制代码

/summon minecraft:villager ~ ~0.5 ~ 生成一个村民，位置为我所在位置上方0.5格(因为站地上不够高)
{开头
NoAI:1b, 禁止移动
VillagerData:{profession:"minecraft:nitwit"}, 村民数据，profession是职业，minecraft:nitwit是指定职业为傻子
Rotation:[-30.0f,-10.0f,], -30是村民朝向，-10是头的角度
HandItems:[{id:"minecraft:stick",Count:1b,Damage:0s}] 手持物品，电影中将军拿着个台球棍，所以让村民也拿着个棍子，Count为数量，Damage为耐久
} 结束


部下
  1. /summon minecraft:villager ~ ~0.5 ~
  2. {
  3. NoAI:1b,
  4. VillagerData:{type:"minecraft:swamp",profession:"minecraft:nitwit"},
  5. Rotation:[90.0f,-10.0f,],
  6. }
复制代码
/summon minecraft:villager ~ ~0.5 ~
生成一个村民，位置为我所在位置上方0.5格(因为站地上不够高)
{
开头
NoAI:1b,
禁止移动
VillagerData:{type:"minecraft:swamp",profession:"minecraft:nitwit"},
村民数据：type为村民种类，minecraft:swamp为数值，指沼泽群系村民
Rotation:[90.0f,-10.0f,]
90是村民朝向，-10是村民头的角度，生成时按照电影中每个人的头角度设置，左右两边朝向分别为90与-90
}
结束
除最后一段外，每段指令后加逗号做结束




【其它细节】

  • 桌上的电话用凋零骷髅头做，头盔、茶杯、烟灰缸就扔了钻石头盔、水桶（空/装水）、碗在桌上


  • 除了电影截图的画面外，为了整体建筑完整，稍微扩充做了下周边（详细可以看视频或下存档）




地图放在右边的箱子里了


  • 在游戏截图时为了还原电影中的光线效果，把“战略图”上方及右方的墙拆了，不然地图太黑。本想加火把，但开光影后颜色太黄，所以还是用自然光

     另外为了方便，在太阳最佳角度时，固定了游戏里的时间，代码为
  1. /gamerule doDaylightCycle false
复制代码


  • 最后截图时，角视场为30，图片用ps裁切后降低下色温就完成了
     在截图时开了光影，但录视频时就没有了，因为开了光影后，游戏基本卡成PPT了
