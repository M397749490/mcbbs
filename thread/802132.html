如果你想让玩家拥有建筑权，修改默认权限组后重载插件即可：
在 plugins\GroupManager\worlds\世界名 下寻找 groups.yml,编辑：
  1.   Builder:
  2.     default: false
  3.     permissions: []
  4.     inheritance:
  5.     - default
  6.     - g:essentials_builder
  7.     - g:towny_builder
  8.     info:
  9.       prefix: '&2'
  10.       build: true
  11.       suffix: ''
复制代码

  把 default: false 改成 default: true 即可
ps.记得把 Default 组的对应项改成false，可以理解为“一山不容二虎”

tpa这些权限是插件预备好了的，你也可以这样封印（在权限面前加减号）：
  1.   Builder:
  2.     default: true
  3.     permissions:
  4.     - -essentials.tpa
  5.     - -essentials.tpaccept
  6.     - -essentials.tpahere
  7.     - -essentials.tpdeny
  8.     inheritance:
  9.     - default
  10.     - g:essentials_builder
  11.     - g:towny_builder
  12.     info:
  13.       prefix: '&2'
  14.       build: true
  15.       suffix: ''

                /mangaddp 组名 权限     ——添加权限，如essentials.tpa
