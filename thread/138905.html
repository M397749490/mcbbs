第三章，开发工具Eclipse的安装和使用。
首先，除了Ec外，我还推荐一个开发工具NetBeans.可以到www.netbeans.org进行下载，但本帖主要讲述Ec。
下载地址：www.eclipse.org。
大家也可以自行在百度上搜索汉化版。
我用的是http://www.uzzf.com/soft/20214.html
下载完后直接解压。
如果不是在官网上下载的可能工作空间已经设置完成，可以在
进行修改。
完成后，让我们来通过Ec建立第一个JAVA项目。
点击文件，新建，项目弹出对话框。
选择Java项目。点击下一步。
输入项目名，我这是因为我之前已经创建过同样名称的项目，不要在意细节=。=
点击下一步，点击完成。参数占时全用默认的。
可能会出现“要打开相关连的透视图吗？”的窗口，点击是。
完成后。
点击文件，新建，类。
勾选public static void main(String[] args)
输入名称，点击完成。
接下来就开始完成大绝大多数程序猿的第一个程序。Helloworld~
打开程序编辑区。
我问会看到如下代码

  2. public class hello {
  3.         
  4.         public static void main(String[] args){                                
  5.         
  6. }

  8. }
复制代码
可能会有注释行，不用管它，我们输入

  2. public class hello {
  3.         
  4.         public static void main(String[] args){
  5.                 System.out.println("helloworld");
  6.                
  7.         }
  8. }
复制代码
点击运行，就会看到。

完
