作者: linnaea    时间: 2014-9-18 15:18
如果你有Notepad++的话，可以这么做：

1.把服务器的日志全部下载回来
2.用Notepad++打开日志
3.点击搜索-->查找
4.点击Mark选项卡
5.在“查找目标”中输入 玩家名字 issued server command: /
6.勾选“标记所在行”
7.点击“查找全部”
8.关闭对话框
9.点击 搜索-->书签-->删除未标记行
