玩家能在服务器破坏方块，我就想问，怎么关掉Builder权限组的破坏方块？
作者: Mcats    时间: 2017-2-20 19:11
不用那么麻烦，修改一个数据即可。
打开GroupManager文件夹下的worlds文件夹，里面默认应该只有一个world文件夹（如果你没分世界权限的话）
打开这个文件夹，打开里面groups.yml这个文件找到长这样的一段代码：
  1. Builder:
  2.     default: false
  3.     permissions: []
  4.     inheritance:
  5.     - default
  6.     - g:essentials_builder
  7.     - g:towny_builder
  8.     info:
  9.       prefix: '&2'
  10.       build: true
  11.       suffix: ''
复制代码
把build: true改成build: false即可。

essentials.build.drop.*
essentials.build.interact.*
essentials.build.pickup.*
删除这3条权限
/mangdelp Builder essentials.build.drop.*
/mangdelp Builder essentials.build.interact.*
/mangdelp Builder essentials.build.pickup.*
