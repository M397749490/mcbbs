RT，这是一个红石距离感应装置，靠近可以点亮(熄灭红石火把)

范围可完全自定

正向距离传感器(名称都汉化了，只是沿用作者原图)


反向距离传感器


只能通过合成的方式获得

对着传感器右击可以设置感应范围

使用魔棒可以自定义感应区域(目前1.5.1不支持这功能，1.4.7完美)


命令：

  1. /rps defaultrange <格数> - 设置默认感应范围
  2. /rps maxrange <格数> - 设置最大感应范围
  3. /rps onlyowner <true/false> - 开启/关闭只有所有者能够更改范围
  4. /rps reload - 重载配置
  5. /rps wand - 获得魔棒
  6. /rps setrange - 确定范围
复制代码

权限：

  1. redstonesensor.use - 能够使用传感器
  2. redstonesensor.create - 能够制作传感器
  3. redstonesensor.customrange - 能够使用RPS魔棒并自定范围
复制代码

配置：

  1. Config:
  2.   # 最大范围
  3.   max-range: 10
  4.   # 检查更新
  5.   update-checker: false
  6.   # 默认范围
  7.   default-range: 3
  8.   # 是否只有所有者能够更改范围
  9.   owner-only-change-range: true
  10.   # 感应器名称
  11.   proximity-sensor-name: 正向传感器
  12.   not-proximity-sensor-name: 反向传感器
  13.   proximity-range-notify-text: 感应范围
  14. # 感应器列表
  15. Redstones: {}
