Poll

提醒
！务必注意 ！！如果您在低于1.14的版本上使用它，您将自行承担风险。

描述

                                    
  • 用插件提供的公告功能向服务器中的玩家提问！
  • 完全自定义
  • 支持可点击消息
  • 支持无限的问题和无限的答案！

bstats

命令与权限
/ poll reload - poll.reload - 重新加载插件
/poll vote <问题> <问题答案> - 无权限 - 对特定问题进行民意调查。
/ pollvotes <问题> - 无权限 - 查看特定问题的投票
/ pollsend <玩家名称|全部> <问题> - poll.send - 向玩家或所有玩家发送投票
问题可以在下面的配置部分查看。

Config
  1. #######################
  2. #         Poll        #
  3. #     by MrIvanPlays  #
  4. #######################

  6. # All polls
  7. questions:
  8.   difficulty: # This is the question identifier. Make it simple
  9.     question: "&eServer: &aWhat is the difficulty that the server should be?"
  10.     answers:
  11.      - "&cHard"
  12.       - "&eNormal"
  13.       - "&aEasy"
  14.   plugin:
  15.     question: "&eServer: &aWhich plugin should the server implement?"
  16.     answers:
  17.      - "&aMcMMO"
  18.       - "&b&lJobs"


  21. # Question announcer
  22. # Announces the questions to the player between the interval specified
  23. # If the player have voted already on the question, the question wont
  24. # get sent to the player
  25. # !! IMPORTANT !! Interval is measured in seconds
  26. question-announcer:
  27.   enable: true
  28.   random-order: true
  29.   interval: 300

  31. # Should the plugin perform a check for update or no
  32. # !! IT IS RECOMMENDED TO LEAVE THIS TRUE !!
  33. update-check: true

  35. # All messages
  36. messages:
  37.   hover-message: "&aClick to vote"
  38.   usage: "&cUsage: /poll <reload|vote> [question identifier] [question answer]"
  39.   no-permission: "&cYou don't have permission to perform this command. Please contact administrator if you believe this is wrong."
  40.   reload-message: "&aReload success"
  41.   no-console: "&cThe console can't vote"
  42.   question-not-found: "&cThe specified question cannot be found"
  43.   already-voted: "&cYou have already voted for this question!"
  44.   invalid-answer: "&cInvalid answer. Valid options: %answers%"
  45.   vote-success: "&aYou have voted successfully"
  46.   pollvotes-usage: "&cUsage: /pollvotes <question identifier>"
  47.   votes-for: "&eVotes for %question%"
  48.   votes-message: "%answer% &rhas &e%votes% vote(s)"
  49.   pollsend-usage: "&cUsage: /pollsend <player name|all> <question identifier>"
  50.   player-not-found: "&cThat player cannot be found"
  51.   sent-success: "&aSuccess sent!"
