检测玩家投掷出经验瓶
将目标锁定至经验瓶实体(可用药水云无限传送)
当药水云检测到经验球实体将经验数据改变举个使用例子

首先拿个具有特殊标签的经验瓶:
/give @s minecraft:experience_bottle{SIEB:1b}
检测经验瓶掷出状态并生成药水云:
/execute as @e[type=minecraft:experience_bottle] at @s if data entity @s {Item:{tag:{SIEB:1b}}} run summon minecraft:area_effect_cloud ~ ~ ~ {Duration:3,Tags:["SAEBAST"]}
在药水云检测到经验球时修改其数据(药水云会自行消失)
/execute as @e[type=minecraft:area_effect_cloud,tag=SAEBAST] at @s as @e[type=minecraft:experience_orb] at @s as @e[type=minecraft:experience_orb,distance=..5] at @s run data merge entity @s {Value:10}
Value可以改成你需要的经验数值


这个的缺点就是如果附近有经验球会把旁边的经验球的数据也改了
添加limit可能会出问题(当然这只是个例子,你可以根据思路自己搞一个系统)
药水云无限传送的话，那还不如用循环生成有一定时间的药水云
反正目标经验瓶实体消失了,那就不会继续生成药水云了
