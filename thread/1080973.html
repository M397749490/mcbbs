前言
本插件用于修补玩家与怪物之间的平衡
并非通过无脑提高怪物血量、花里胡哨的技能来平衡
可以提高隐蔽性，让玩家产生一种“我为什么打不过它”的感觉


特点
语言文本自定，可以选择让玩家根本不知情的情况下进行修补
不仅可以让怪物更难挑战，也可以相反，让怪物更容易挑战（文本配置改一下）
对拔刀剑有特殊机制，无脑SA收割不可取
插件轻量，兼容性非常高


指令、权限组和配置文件
指令
  1. /br set  开关消息提示
  2. /br mode  切换交互实体显示信息模式
  3. /br reload  重载配置文件
复制代码
权限
  1. br.set 使用/br set指令权限 默认玩家拥有
  2. br.op 拥有此权限的人不会被本插件影响 OP默认
  3. br.unlimiteddamage  无限疲劳值权限
