  • 支持 JS 计算经验升级公式
  • 支持 数据库&本地 储存数据
  • 替代 原版等级 更好的兼容市面上的插件 (像AttributePlus的装备等级限制)


插件说明 & 插件配置
2020/7/19

  • 该插件会替代原版等级的计算,原版经验会转为插件经验,所以能兼容市面上大部分的插件
  • MythicMobs 的掉落经验 & AttributePlus 的装备等级要求 等...

  11.   #玩家首次登录是否更新玩家等级
  12.   #开启后玩家已获得的经验转为插件经验
  13.   initPlayerLevel: true

  16.   #异步实时保存

  18.   realTimeSave: true

  21.   calculation:
  22.     enable: false

  26.       - "21-30:30*(1+%al_level%)"
  27.   #固值
  28.   fixed:
  29.     enable: true

  31.     #如果用了 0-10 范围建议开启
  32.     #公式: 经验*等级=升至下级所需经验
  33.     #例如: 0-10:100 然后玩家5级(100*(5*1.0)=500)
  34.     #那么玩家必须再获得 500 经验才升级!
  35.     level:
  36.       enable: true

  54. #PlaceholderAPI 变量
  55. #%al_olevel% — 旧等级
  56. #%al_level% — 新等级
