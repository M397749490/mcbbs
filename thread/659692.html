一款能让自己的服务器支持更高版本的插件

一、简介 Description
大家都想知道别的服务器为什么可以支持很多版本？新出的1.11为什么一下子就支持了？我之前看到了老帖，不过我是先在SPIGOTMC发现才在MCBBS发现的，但是那个版本只支持1.8-1.10，现在新出了1.11！此插件和ProtocolSupport不一样，不会到处都是BUG！                                                                                                           原搬运贴点击传送

二、功能 Features
·让1.8服务器支持1.8-1.11最新版本
·让1.9服务器支持1.9-1.11
·让1.10服务器支持1.10-1.11
·让1.11服务器支持1.11[并没有什么卵用]
