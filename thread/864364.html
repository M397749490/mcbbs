如果你有加装Essentials插件，请在插件配置目录（plugins/essentials/config.yml）中
  1. # 若在使用/give或/item命令时如果没有填写数量.
  2. # 如果这个数值设置小于1,那么给予最大叠加数量的物品
  3. # 如果超大堆叠没有开启,那么数量大于正常堆叠数量(64)时,将给予1组以上物品.
  4. default-stack-size: -1

  6. # 超大堆叠允许玩家堆叠物品超过正常最大堆叠.
  7. # 如果玩家拥有essentials.oversizedstacks权限,当使用 /give 或 /item时可以获得超大堆叠物品.
  8. # 超大堆叠物品的上限是多少?
  9. oversized-stacksize: 64
复制代码

请把这两个项分别改为

  2. default-stack-size: 128
  3. oversized-stacksize: 128
复制代码

然后输入/give 物品ID 128
即可获取超大堆叠的物品，然后再使用/svs priceitem hand
