SignLogin —— 木牌登录
这个插件可以让你使用木牌来登录和注册账号，登录自动遮挡密码，这可能是唯一一个兼容了1.13+(然而只测试了1.14.3)版本的木牌登录插件吧。

⊙ 配置文件 ⊙
配置文件:
  1. #是否开启随机告示牌(应该只有1.14能用吧) 1.13以下版本请勿开启
  2. random: false
  3. #兼容模式 1.12.2以上版本请勿开启 1.12.2以及以下版本可以开启
  4. compatible: true
  5. sign:
  6.   #注册
  7.   register:
  8.     #密码在哪一行输入(0是第一行)
  9.     password-line: 0
  10.     #确认密码的行数
  11.     confirm-password-line: 1
  12.     #牌子的内容
  13.     lines:
  14.       - ""
  15.       - ""
  16.       - "§f欢迎你 §9%Player%"
  17.       - "§f请输入密码并确认"
  18.   login:
  19.     password-line: 0
  20.     lines:
  21.       - ""
  22.       - "§f欢迎回来 §9%Player%"
  23.       - "§f请输入你的密码"
  24.       - "§4§l如第一次进服请更名"
复制代码

★ 使用方法 ★
  • 下载本插件
  • 将插件放入服务端的plugins文件夹
  • 启动服务器
  • 根据你的版本以及需求修改config.yml
  • 重启服务器(或重载插件)
  • 进入服务器即可看到木牌登录界面
