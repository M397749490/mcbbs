Shulker Backpacks 1.5.2
你的随身潜影箱
作者|Author：DarkMonolith
可用版本：1.13-1.16 Spigot、PaperMC（尚未在CraftBukkit上测试）
你是否觉得想要把潜影箱里的东西拿出来前，需要先放下来这个步骤太麻烦了？有的时候我们只是想拿一块牛排，却不得不找一个没有被圈地的区域，放下潜影箱，取出物品，再挖掉潜影箱；有的时候我们的潜影箱放错了位置，打不开了，需要挖掉重新放一次；有的时候潜影箱被摆到了危险的地方（岩浆湖边上），一不小心你的心血就会付诸东流......
现在，有了这个插件，我们可以在背包界面/箱子界面右键打开潜影盒（或者拿在手上对着空气右键），还可以阻止玩家放置潜影盒，以防有玩家粗心大意对着岩浆湖右键潜影盒。

功能与配置

可以配置：
  • 能否对着空气右键打开
  • 能否箱子界面右键打开
  • 能否末影箱界面右键打开
  • 潜影箱能否放置到地上
  • 右键打开潜影箱时是否需要按住shift

  1. blacklistedinventories: ["&4&lMineXChange", "test inventory"]
  2. #黑名单物品

  4. canopeninair: true #设为 false 就不能对着空气右键打开潜影箱
  5. canopenininventory: true #设为 false 就不能打开背包里的潜影箱
  6. canopeninchests: true #设为 false 就不能打开箱子界面的潜影箱（无论是否在背包里）
  7. canopeninenderchest: true #设为 false 就不能打开末影箱界面的潜影箱（无论是否在背包里）
  8. canopeninbarrels: true #设为 false 就不能打开木桶界面的潜影箱（无论是否在背包里）
  9. canplaceshulker: true #设为 false 将防止玩家把潜影箱放到地上

  11. defaultname: "&9潜影箱"
  12. shiftclicktoopen: false
  13. #右键打开潜影箱时是否需要按住shift
  14. shulkervolume: 1 #0.1很轻, 1最响
