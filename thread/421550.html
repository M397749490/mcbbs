简介
本插件为物品绑定插件,可以在RPG用于设定绑定武器.被绑定的武器玩家无法给别的玩家,无法放入箱子或者其他任何容器.死亡后绑定物品也不会掉落而是依旧在玩家背包内.本插件可以兼容大部分RPG武器插件,经测试的有item lore stats 以及 RPGitem


用法
1.如果你想要使一个武器变成绑定武器只需要拿着输入 /ib bind 即可.


2.此外你还可以直接通过在物品lore中添加 绑定 两字,同样可以使物品拥有绑定效果.(支持在绑定两字前添加任意颜色代码)

如果你觉得这个绑定物品没用了,想丢掉.当然没问题直接拿着物品丢弃就会出现如下提示
这时你只要按提示输入指令,手中的绑定物品就会被删除.
如果你开启了解绑功能则会出现如下提示.


配置文件
  1. bind:
  2. #是否开启绑定功能,开启后玩家无需任何权限即可使用绑定指令.
  3.   enable: false
  4. #绑定花费.
  5.   cost: 0
  6. unbind:
  7. #是否开启解绑功能,开启后玩家无需任何权限即可使用解绑功能.
  8.   enable: false
  9. #解绑花费.
  10.   cost: 0
  11. #是否开启白名单
  12. #当玩家手持绑定物品时只允许执行列表内的指令.
  13. #如不启用白名单则启用黑名单,只禁止黑名单内指令
  14. useWhiteList: true
  15. cmdWhiteList:
  16.   - '/ibind'
  17.   - '/ib'
  18. cmdBlackList:
  19.   - '/shop'
  20. #列表内容器可以移动绑定物品
  21. containerWhiteList:
  22.   - 'container.crafting'
  23.   - 'container.enderchest'
  24. #当玩家把绑定物品放入不被允许的容器中时,玩家关闭容器界面时
  25. #是否将容器内绑定物品返还至玩家背包
  26. returnContainerItem: false
复制代码


权限
Itembound.bind —— 使用/ib bind绑定物品权限
Itembound.unbind—— 使用/ib unbind解绑物品权限.
Itembound.bypass —— 无视绑定限制,随意丢弃物品权限.


下载地址: 百度网盘


本插件必须在Java8环境下运行
