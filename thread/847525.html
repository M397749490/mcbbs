介绍 · Introduction
这款插件可以禁止玩家在掉落时输入特定的指令。
插件检测玩家下方的方块来判定摔落状态. 如果玩家所在方块为空气方块即为掉落状态.
"allow if flying" 这个选项可以让拥有权限的飞行状态的玩家输入指令.

可用于但不限于：在开启死亡掉落的服务器内防止玩家在摔死前输入无冷却的传送指令转移掉落物这可以使得掉落虚空、岩浆更加致命
指令
  • /fallavert reload - 重载插件

汉化配置
  1. # 设置为true则为白名单
  2. # 设置为false则为黑名单
  3. whitelist mode: false

  5. # 禁止或允许的指令, 取决于 "whitelist mode"
  6. # 不要忘记加上 "/"
  7. commands:
  8. - /tp
  9. - /fly
  10. - /tpa
  11. - /warp
  12. - /island

  14. # 是否允许玩家飞行时输入指令
  15. # 默认: true
  16. allow if flying: true

  18. message: "&c&o你不能在摔落时输入 &a{command}&c&o!"
  19. reload: "&a成功重载FallAvert的配置."

  21. punishments:
  22.   #是否启用惩罚在空中退出游戏的玩家
  23.   # 默认: 关闭
  24.   enable: false

  26.   # 执行作为惩罚的命令
  27.   # 由控制台发出
  28.   # 不需要在指令前添加'/'
  29.   #
  30.   # 可用变量:
  31.   #   {player}: 退出游戏的玩家名
  32.   commands:
  33.   - "kill {player}"
