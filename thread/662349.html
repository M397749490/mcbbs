搬运Mod
Neat
Mod介绍
此Mod增加了一个简洁的血条，这个血条可以在某种生物的顶部显示出它的当前的血量值，及当前的血量值占总血量值的百分比，还有总血量值、生物属性和护甲。
另外，这个Mod只可以显示你周围一定范围内的生物血条，如果某种生物离你太远的话，即使它在你的可视距离内，你也看不到它的血条。
注意：如果更改了配置文件，以上介绍部分内容作废。
Mod特点
1.完全支持客户端
2.如果没有方块等物体阻挡的话，会在生物顶部显示出Neat血条
3.血条的颜色变化取决于生物当前血量占总血量百分比的高低（绿色、黄色、红色）
4.显示生物属性（比如蜘蛛显示蜘蛛眼，而僵尸显示腐肉）和它们的护甲
5.如果是组合生物将会把两个生物的血条一起显示出来（如鸡骑士会在上面显示出僵尸的血条和鸡的血条，蜘蛛骑士会在上面显示出骷髅的血条和蜘蛛的血条）
6.在Minecraft的记分牌上，生物和玩家会有不同颜色的名字
7.可以配置（无论你是否在游戏中）
8.修改配置文件后，以上部分内容作废
9.潜影贝的血条不会被显示出来！

配置文件
此Mod的配置文件为neat.cfg

  1. # Configuration file

  3. general {
  4.     I:"Background Height"=6  #血条半透明背景高度大小
  5.     I:"Background Padding"=2  #血条半透明背景填充面积大小

  7.     # Blacklist uses entity IDs, not their display names. Use F3 to see them in the Neat bar.
  8.     # 黑名单使用实体ID, 而不是显示的名字。按下F3来在Neat血条中看到他们。
  9.     S:Blacklist <
  10.         Shulker
  11.         ArmorStand
  12.      >
  13.     B:"Color Health Bar by Type (instead of health percentage)"=false  #是否根据敌对关系确定血条颜色（开启的话中立生物的血条将会变成黄色，敌对生物的血条将会变成红色、友好生物的血条将会变成绿色、Boss的血条将会变成紫色）
  14.     B:"Display on Bosses"=true  #是否显示生物血条
  15.     B:"Display on Players"=true  #是否显示玩家血条
  16.     B:"Draw Background"=true  #是否启用血条黑色半透明背景
  17.     B:"Group Armor (condense 5 iron icons into 1 diamond icon)"=true  #是否启用护甲集成（五铁护甲将会集成为一钻石护甲）
  18.     I:"HP Text Height"=14  #当前血量占总血量的百分比、总血量、当前血量等数据显示的高度（数值越大就越往下）
  19.     I:"Health Bar Height"=4  #血条高度大小
  20.     D:"Height Above Mob"=0.6  #生物血条比生物高多少
  21.     I:"Max Distance"=24  #最大距离你多远的生物会被显示出来血条
  22.     B:"Only show the health bar for the entity looked at"=false  #是否只有把游戏准标移动到生物身上才可以看到血条
  23.     I:"Plate Size"=25  #血条尺寸（这里是宽度）
  24.     I:"Plate Size (Boss)"=50  #Boss（比如末影龙、凋零）的血条尺寸（这里是宽度）
  25.     B:"Render with Interface Disabled (F1)"=true  #按F1时是否隐藏血条
  26.     B:"Show Armor"=true  #是否显示血条上的生物护甲
  27.     B:"Show Attributes"=true  #是否显示血条上的生物属性
  28.     B:"Show Current HP"=true  #是否显示血条左侧的当前血量值
  29.     B:"Show Debug Info with F3"=true  #按F3是否进入Debug模式
  30.     B:"Show HP Percentage"=true  #是否显示血条上当前血量占总血量值的百分比
  31.     B:"Show Max HP"=true  #是否显示血条右侧的总血量值
  32. }
