标题: 领地插件和木牌锁权限OP没有
有些玩家 设置了领地权限和箱子锁  OP查水表很不方便 都打不开箱子和 领地内 破坏放置   怎么让OP有这两个插件的所有权限
作者: 琥珀剑心    时间: 2014-3-4 20:03
1.领地的话，打开领地的配置文件，找到
# Setting this to true makes server OPs admins.
    AdminOPs: true
把AdminOPs改为true即可
2.牌子锁的话，打开牌子锁的配置文件，找到
allow-admin-snoop: false
把false改为true即可
