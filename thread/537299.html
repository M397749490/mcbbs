>>> 前言 <<<
相信开Bungeecord 的腐竹都想要个插件 可以让玩家自行隐藏其他玩家
那么这个插件就是你的救星！
小小的插件只要 几KB 就能满足你的欲望
很多人就说 这插件不是搬运过吗？
我只能说！ 这个插件不仅是隐藏全部玩家 可以选择隐藏某个权限组的玩家
更方便快捷！

>>> 语言文件 <<<
  1. # In this file you can edit some messages!
  2. prefix: '&8[&5HidePlayers&8] '
  3. players:
  4.   successfuly:
  5.     hidden: '&cThe group [COLOR] [GROUP] &cis now hidden!'
  6.     visable: '&aThe group [COLOR] [GROUP] &ais now visable!'
  7. item:
  8.   name: '&6Item to hide and show players'
  9. inventory:
  10.   name: '&6Hide/Show Players'
  11.   visable: '&aPlayers are visable'
  12.   hidden: '&cPlayers are hidden'
  13.   group:  <<<<<这个就是设置权限组的地方啦~
  14.     member: '&aMembers'
  15.     vip: '&6VIPs'
  16.     youtuber: '&5Youtubers'
  17.     architect: '&2Architects'
  18.     presenter: '&cPresenters'
  19.     developer: '&bDevelopers'
