那就来我们服务器试试吧！
无付费变态武器/护甲，无灵魂绑定.
死亡概率百分比掉落!
多种玩法，MOD供你选择！

服务器特色
Server So Color
可破坏战区

传统战争服战区不可破坏？我们不一样！
整个战区均可破坏!并且会自动复原！
给你不一样的PVP体验!

更加人性化多样化的领地
服务器的领地均可自定义天气与日夜！如下雨，晴天，黑天，白天等。
让您的领地更加人性化！根据您的需求进行调整建设！


定制战区地图

斥资近千打造专属定制地图！
各种地形各色建筑可以提高你的PVP体验！

更多的武器和食物
服务器加有潘马斯，更多武器等mod，丰富生存玩法

武器等级
武器/护甲制作之后会有随机的等级！如普通,罕见,史诗等。
不同的稀有度会有不同的伤害加成！击杀怪物/承受伤害可提高等级。
提高等级获得技能点即可定制你专属的武器技能！

平衡的武器系统
所有枪械都各有所长，各有所短。不会出现过于变态的武器！
(当然活动可能会发放一些属性较强的武器不会出售)

枪械改装
服务器可自行改装武器，更换武器皮肤。您可根据您的需求改装！

死亡概率掉落

服务器的主题是战争/生存,如果死亡对玩家没
有一点影响的话为什么要叫生存呢?但是为了
降低一定难度，我们设置了有概率死亡不掉落
即便死亡掉落也是随机的百分比掉落.
