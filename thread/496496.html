想在服务器添加更多的合成配方吗？

那么就使用这个插件吧！

安装方式：拖到plugins文件夹里

命令：


/morecraft reload 重新加载配置


权限：


morecraft.* 所权限


morecraft.reload 重新加载配置命令的权限


添加合成公式方法：

打开plugins/morecraft/recipes.yml文件，可以看到内置的几种合成公式与烧制公式，



在Crafts:后面是合成公式配置：

其中output:后面填写输出的物品的ID，可以在后面加个空格然后写 name:自定义名称

shapelessRepice:   是否为不定型公式，即是否可以随意摆放

usePermission:   是否需要权限才能合成

noPermission:    没权限时提示文字(可以使用颜色代码，记得加'')

repice:   合成公式，下面每行开头有-，用字母代替物品

ingredients:    上面合成公式中的字母代表什么



在Smelts:后面的为烧制公式：

output:    输出什么

ingredient:    输入什么

下面为普通合成Notch的头的公式(粘贴到Crafts:后面，要另起一行)：

  1.   Notch:
  2.     output: 397:3 1 player:Notch
  3.     shapelessRecipe: false
  4.     usePermission: false
  5.     recipe:
  6.     - aaa
  7.     - abc
  8.     - ddd
  9.     ingredients:
  10.       a: '35:12'
  11.       b: '159:0'
  12.       c: '35:11'
  13.       d: '87'
复制代码
下面为合成草方块的配置：(粘贴到Crafts:后面)

  1.   grass:
  2.     output: '2'
  3.     shapelessRecipe: true
  4.     usePermission: true
  5.     noPermission: '&c你不能合成一个草方块'
  6.     ingredients:
  7.     - '3'
  8.     - '295'
复制代码
下面为烧制草方块成红沙的配置(粘贴到Smelts:下面，记得另起一行)

  1.   leather:
  2.     output: '2'
  3.     ingredient: '12:1'
