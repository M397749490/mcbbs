星空Mod添加了很多行星和卫星来修改Galacticraft，插件需要Galacticraft来运行。
我们不追求其他插件的创造者，我们正在努力提高品质。
插件是为Minecraft 1.7.10和1.12.2版本制作的，早期版本不会被转移。
而GalaxyAdditions则加入了木星、土星、天王星、海王星，并优化了体验。

1. Added config to disable advanced crafting rocket tier 2 and 3.

3. Changed input side in the Planetary Shield.
4. New Mars WorldGen [test]
5. Upgrade to GC4 version above 237 build.
6. Dynamic temperature system [experimental].
7. Triton.
8. Improved sky on Ceres and Pluto.
9. Added the ability to get stone and cobblestone on Mars.
10. Added new variations of ice with gases.
11. Fixed atmospheric station on Venus.
12. Added small trees on Barnarda C.
13. Fixed rendering of the Jetpack on the player.
14. Spacesuit can no longer be enchanted.
15. Ion engine for rocket tier 4 and 5.
16. The maximum radius of the Gravity Module = 16.
17. Added ja_JP localization.
18. The gravitational effect is now applied to mobs.
19. Added thermal padding tier 3 and 4.

【AsmodeusCore】0.0.12 更新日志：
1.Replace (byte) meta -> IBlockState in WE biomes.
2.Some changed method for register celestial bodies.
3.Added dynamic thermal level methods.
4.Some fixs

【1.7.10】1.2.13 更新日志：
1. Fixed number of drop of diamonds from Venus ore.
2. Fixed crash due to incorrect recipe in Liquid Separator.
3. Improved sky on Earth is now off by standard in the new config.
4. Reworked logic of Portable Nuclear Reactor.
5. Uranium ingots removed. Uranium rods added.
6. The modules for the spacesuit are rewritten. New modules added.
7. Modified GUI Modification table (backport from 1.12.2)
8. Added config to disable images in the sky.
9. Fixed EPP oxygen canister.
10. Enriched fuel canister added.

【Additions】1.0.1 更新日志：
1.GA now works without Thaumcraft and Botania.
2.Fixed some textures.

2、1.12.2：下载星空Mod及AsmodeusCore。

3  将所有Mod拖入 .minecraft/mods 文件夹。
