请移步PermissionsEx帮助：
仔细查看可知：可以设置不同世界不同权限。

  1. Usage:
  2. /pex - Display help
  3. /pex reload - Reload environment
  4. /pex report - Report an issue with PEX
  5. /pex config <node> [value] - Print or set <node> [value]
  6. /pex backend - Print currently used backend
  7. /pex backend <backend> - Change permission backend on the fly (Use with caution!)
  8. /pex hierarchy [world] - Print complete user/group hierarchy
  9. /pex import <backend> - Import data from <backend> into currently selected backend
  10. /pex convert uuid - Bulk convert user data to UUID-based storage
  11. /pex toggle debug - Enable/disable debug mode
  12. /pex help[count] - PermissionsEx commands help
  13. /pex users list - List all registered users
  14. /pex users - List all registered users (alias)
  15. /pex user - List all registered users (alias)
  16. /pex user <user> - List user permissions (list alias)
  17. /pex user <user> list [world] - List user permissions
  18. /pex user <user> superperms - List user actual superperms
  19. /pex user <user> prefix [newprefix] [world] - Get or set <user> prefix
  20. /pex user <user> suffix [newsuffix] [world] - Get or set <user> suffix
  21. /pex user <user> toggle debug - Toggle debug only for <user>
  22. /pex user <user> check <permission> [world] - Checks player for <permission>
  23. /pex user <user> get <option> [world] - Toggle debug only for <user>
  24. /pex user <user> delete - Remove <user>
  25. /pex user <user> add <permission> [world] - Add <permission> to <user> in [world]
  26. /pex user <user> remove <permission> [world] - Remove permission from <user> in [world]
  27. /pex user <user> swap <permission> <targetPermission> [world] - Swap <permission> and <targetPermission> in permission list. Could be number or permission itself
  28. /pex user <user> timed add <permission> [lifetime] [world] - Add timed <permissions> to <user> for [lifetime] seconds in [world]
  29. /pex user <user> timed remove <permission> [world] - Remove timed <permission> from <user> in [world]
  30. /pex user <user> set <option> <value> [world] - Set <option> to <value> in [world]
  31. /pex user <user> group list [world] - List all <user> groups
  32. /pex user <user> group add <group> [world] [lifetime] - Add <user> to <group>
  33. /pex user <user> group set <group> [world] - Set <group> for <user>
  34. /pex user <user> group remove <group> [world] - Remove <user> from <group>
  35. /pex users cleanup <group> [threshold] - Clean users of specified group, which last login was before threshold (in days). By default threshold is 30 days.
  36. /pex group <group> swap <permission> <targetPermission> [world] - Swap <permission> and <targetPermission> in permission list. Could be number or permission itself
  37. /pex groups list [world] - List all registered groups
  38. /pex groups - List all registered groups (alias)
  39. /pex group - List all registered groups (alias)
  40. /pex group <group> weight [weight] - Print or set group weight
  41. /pex group <group> toggle debug - Toggle debug mode for group
  42. /pex group <group> prefix [newprefix] [world] - Get or set <group> prefix.
  43. /pex group <group> suffix [newsuffix] [world] - Get or set <group> suffix
  44. /pex group <group> create [parents] - Create <group> and/or set [parents]
  45. /pex group <group> delete - Remove <group>
  46. /pex group <group> parents [world] - List parents for <group> (alias)
  47. /pex group <group> parents list [world] - List parents for <group>
  48. /pex group <group> parents set <parents> [world] - Set parent(s) for <group> (single or comma-separated list)
  49. /pex group <group> parents add <parents> [world] - Set parent(s) for <group> (single or comma-separated list)
  50. /pex group <group> parents remove <parents> [world] - Set parent(s) for <group> (single or comma-separated list)
  51. /pex group <group> - List all <group> permissions (alias)
  52. /pex group <group> list [world] - List all <group> permissions in [world]
  53. /pex group <group> add <permission> [world] - Add <permission> to <group> in [world]
  54. /pex group <group> set <option> <value> [world] - Set <option> <value> for <group> in [world]
  55. /pex group <group> remove <permission> [world] - Remove <permission> from <group> in [world]
  56. /pex group <group> timed add <permission> [lifetime] [world] - Add timed <permission> to <group> with [lifetime] in [world]
  57. /pex group <group> timed remove <permission> [world] - Remove timed <permissions> for <group> in [world]
  58. /pex group <group> users - List all users in <group>
  59. /pex group <group> user add <user> [world] - Add <user> (single or comma-separated list) to <group>
  60. /pex group <group> user remove <user> [world] - Add <user> (single or comma-separated list) to <group>
  61. /pex default group [world] - Print default groups for specified world
  62. /pex set default group <group> <value> [world] - Set whether a group is default for specified worlds
  63. /pex group <group> rank [rank] [ladder] - Get or set <group> [rank] [ladder]
  64. /pex promote <user> [ladder] - Promotes <user> to next group on [ladder]
  65. /pex demote <user> [ladder] - Demotes <user> to previous group or [ladder]
  66. /pex worlds - Print loaded worlds
  67. /pex world <world> - Print <world> inheritance info
  68. /pex world <world> inherit <parentWorlds> - Set <parentWorlds> for <world>
