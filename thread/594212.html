链式：
  1. scoreboard players tag @a add BoomBow {SelectedItemSlot:0,Inventory:[{Slot:0b,id:"minecraft:bow",Count:1b,tag:{display:{Name:"boombow"}}}]}  // 自行补充，不知为何nbtexplorer就是不出现wiki所说的SelectedItem
  2. execute @a[tag=BoomBow] ~ ~ ~ scoreboard players tag @e[type=Arrow,r=2] add BoomArrow
  3. scoreboard players tag @e[type=Arrow,tag=BoomArrow] add Explode {inGround:1b}
  4. clear @a[tag=BoomBow,m=!1] tnt -1 1  // 那啥，这个设上条件限制
  5. execute @e[tag=Explode] ~ ~ ~ summon PrimedTnt
  6. kill @e[tag=Explode]  // 那啥，这个设上条件限制
复制代码
