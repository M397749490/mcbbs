标题: linux用脚本会导致开服加载不出mod
启动参数是这个
java -server -Xincgc -Xmx3400M -Xms64M -Xss512K -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseCMSCompactAtFullCollection -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=2 -XX:+UseConcMarkSweepGC -XX:CMSFullGCsBeforeCompaction=2 -XX:CMSInitiatingOccupancyFraction=70 -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar /root/minecraft/CatServer.jar

手动在命令行输入这个可以正常运行。于是我把它做成了一个bash脚本内容是这样的,名字是launch.sh
#!/bin/sh
screen -dmS mc java -server -Xincgc -Xmx3400M -Xms64M -Xss512K -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseCMSCompactAtFullCollection -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=2 -XX:+UseConcMarkSweepGC -XX:CMSFullGCsBeforeCompaction=2 -XX:CMSInitiatingOccupancyFraction=70 -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar /root/minecraft/CatServer.jar

我运行bash launch.sh，它也会正常的启动。但是似乎加载不出任何MOD。 变成一个纯净服。比如在线人数变成默认的20，后台输入如gc之类的命令都提示没有找到命令。
