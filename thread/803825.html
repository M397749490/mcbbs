使用Bukkit的Scheduler可以实现你的想法。
  1. Bukkit.getScheduler().scheduleSyncRepeatingTask(this, ()->{
  2. /* 你的代码 */
  3. }, 1, 1);
复制代码

根据https://hub.spigotmc.org/javadoc ... -long-long-]Javadoc[/url]，该方法的参数如下:
plugin - 执行任务的插件实例
task - 任务
delay - 等待多久之后首次执行（tick）
period - 延迟（tick）
