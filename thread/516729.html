关键词：2人  崩服  服务端  插件

问题分析：
崩服是MinecraftServer类内的静态变量currentTick初始化时<0造成的，如下：

  • public static int currentTick = (int)(System.currentTimeMillis() / 50L);


把时间long型转为int型，导致小于0，这个方法一直把这个当正数来调用，所以导致异常。


处理方法：
   方法1（不推荐）：更换服务端----代价太大！
  方法2（推荐）：使用修复插件（目测你的服务器是1.7.X/1.8.x）
