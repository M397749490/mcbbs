作者: 爱心魔王FHC    时间: 2015-5-1 21:19
请先输入指令：/gamerule keepInventory true
作用：启用死亡后对物品栏的保存
探测玩家死亡
/testfor @a {HealF:0f}
用冲脉激活，命令方块旁边放个比较器，如果玩家死了就会输出信号
然后清空玩家背包即可
clear @a
这样物品不会掉出来，也会没掉

您好,请输入命令/gamerule keepInventory true与命令/scoreboard objectives add 变量名 deathCount,之后使用高频红石信号激活输入了命令/clear @a[score_变量名_min=1]的命令方块,使用红石比较器将其连接至输入了命令/scoreboard players set @a 变量名 0的命令方块即可达到您的目的。其中为避免bug,"变量名"请使用同一串英文字符串。若您还有任何疑问请向我发送消息,我会尽量为您解答。
