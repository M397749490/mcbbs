  1. 金剑:
  2.   Id: GOLD_SWORD
复制代码

写在Mobs里的
  1. 金剑:
  2.   Type: armor_stand
  3.   Options:
  4.     HasArms: true
  5.     Marker: true
  6.     Invisible: true
  7.     HasGravity: false
  8.     ItemHand: 金剑
  9.   Pose:
  10.     RightArm: -103,5,180
复制代码

写在Skills里的
  1. 金剑[1]:
  2.   Skills:
  3.   - mythicprojectile{pobject=金剑;v=15;i=1;hR=1}
