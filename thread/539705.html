前言：
这是给刚接触pixemon的腐竹或者管理们看的。
大神就可以无视这个帖子~~
------------------------------------------------------
准备工具：
RPGitem（一般都是服务器自带的）
一枚小号或者一名基友
-----------------------------------------------------

这个教程好处也就是右键一个物品或者消耗品即可获得精灵和道具。
很适合制作赞助礼包，不过操作可能比较繁琐。（别说vipzero什么的,口袋妖怪基本都是小服）

当然并不是只有口袋服能用！所有新服的腐竹都能学习下！
----------------------------------------------
好！

废话少说教程开始！


--------------------------------------------------------------
首先输入指令“/RPGitem 1 create”，一个代号为“1”的模板创建好了。




--------------------------------------------------------------
输入指令“/RPGitem 1 give”,把这个物品给予给自己。
[img]http://i4.tietuku.com/810a6509734a8fb2.png[/img
--------------------------------------------------------------
好，然后输入输入指令“/RPGitem 1 display 名字

这里的颜色可以更改成你喜欢的颜色，这里我神兽自然我就用史诗橙来用与名字的颜色。
--------------------------------------------------------------
输入指令“/RPGitem 0 item 材质id”为物品设置材质




这里我就用和裂空坐颜色差不多的甲虫徽章。
材质ID就是后面的数字。
注意：输入ID时比如某个物品的ID为#0014这样的ID。就只用输入14就可以了。
-------------------------------------------------------------------------

--------------------------------------------------------------
好了。接下进入正题。

我们目前就先设置这么多。剩下的我会发优化物品的教程。
-------------------------------------------------------------------------

设置完毕后输入
/rpgitem 1 power command 0 right 描述 `指令` 权限
-----------------------------------------------------------------------
我要右键获得裂空坐我就这样输入~

/rpgitem 1 power command 0 right 右键获得裂空坐 `pokegive {player} Rayquaza` *
----------------------------------------------------------------------------------------------------------------
如果你想只能使用一次就输入这个指令
/RPGitem 1 power consume"(设置物品为消耗品，使用一次消失)
--------------------------------------------------------------
好了，差不多成型了。

-------------------------------------------------------------------------
来试试效果

--------------------------------------------------------------------------------------------------------------
当然如果你觉得自己是管理有权限获得。
现在你需要的小号的用处就出来了。
我们先把设置好的裂空坐放在野外，当然放必须要找的到。
我现在就开个小号去实验。

--------------------------------------------------------------
可见没有权限的小号也开启了这个裂空坐兑换卷~所以实验成功。

--------------------------------------------------------------
当然你也可以自定义获得精灵的属性和等级。
----------------------------------------------------------
假如我要获得一只100级6V的精灵

/rpgitem 1 power command 0 right 描述 `pokegive {player} 精灵英文名 lvl100 o ivhp:31 o ivatk:31 o ivdef:31 o ivsatk:31 o ivsdef:31 o ivspd:31` *
----------------------------------------------------------
如果你觉得一只不够。
就可以输入两遍，比如
/rpgitem ID power command 0 right 右键此礼包获得精灵 `pokegive {player} Bulbasaur` *（这是妙蛙种子）
/rpgitem ID power command 0 right 右键此礼包获得精灵 `pokegive {player} Charmander` *（这是小火龙）
---------------------------------------------------------
--------------------------------------------------------------
假如你想制作一个VIP礼包
礼包里面包含了
急冻鸟*1、大师球*3、奇异甜食*32、钻石*64、高级球*64、

急冻鸟：/rpgitem ID power command 0 right 右键使用礼包 `pokegive {player} Bulbasaur` *
大师球：/rpgitem ID power command 0 right 右键使用礼包 `give {player} 4137 3` *
升级糖：/rpgitem ID power command 0 right 右键使用礼包 `give {player} 4487 32` *
高级球：/rpgitem ID power command 0 right 右键使用礼包 `give {player} 4136 64` *
钻石：/rpgitem ID power command 0 right 右键使用礼包 `give {player} 264 64` *
