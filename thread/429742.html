怎么设置当前世界无法被玩家破坏！！！
作者: robbit    时间: 2015-4-5 03:30
你需要找到权限组配置文件，D:\ECSServer\plugins\GroupManager\config把下面红色的东西调成相应形式
比如你有A B C D 三个世界，然而你想调成D世界不会被破坏，那就把下边的世界列表中的D世界去掉(记得空格)
       world:
          - A                           
          - B                              
          - C                             
          - D
变成下边的这样
       world:
          - A                           
          -B                              
          -C                             



然后打开权限组中的另一配置文件D:\ECSServer\plugins\GroupManager\worlds\D\groups


找到这样一行:
Builder:
    default: true
    permissions:
    - automessage.receive.default
    - chestcommands.command.open
    - chestcommands.item.spawn.yml
    - mypet.custom.skilltree
    - mypet.user.leash.chicken
    - nautomessage.receive.builder
    - serversigns.use.*
    - serversigns.use.promote
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      prefix: '&a[公民]&2'                      玩家名称前缀
      build: false                                    当前世界的建造权限(true就是有/false就是没有)你只要把D世界的建造权限设置为false就可以了
      suffix: ''
