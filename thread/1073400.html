机器的设置

储罐的设置

方块的设置如下

        {
      "type": "block:simple",
      "entries": [
        {
          "id": "Infinity_Tank",
          "creativeTab": "creationitem-blocks",
          "model": "creation_item:infinity_tank", #方块模型
          "tileEntity": "creation_item:infinity_tank", #储罐TileEntity
          "gui": "creation_item:infinity_tank" #储罐GUI
        }
    },


而后，这是储罐的GUI的TileEntity设置

        {
      "type": "tileentity:simple",
      "entries": [
        {
          "id": "infinity_tank", #TileEntity内部ID
          "modules": [
            {
              "type": "tank", #TileEntity类型
              "name": "infinity_tank", #TileEntity的名字
              "capacity": 100000000, #储罐可以储存多少流体的数
              "canDrain": true, #是否可以排空储罐
              "canFill": true, #是否可以填满储罐
              "sides": ["north", "south", "east", "west", "up", "down"] #输入面
            }
        }
    },

后话
机器的话，仅支持熔炉类型的机器，其他要电或者其他的话要等cubex更新后才能(?)支持
而机器的栏位支持1+1+1，而不是上面实例的2+2+2.
而储罐的话，敲掉不会保留流体，按Ctrl+中键也不会保留，但支持熊抱mod.
