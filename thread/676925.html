BungeePing

               
简介
    SpigotPing是一个BungeeCord插件，它允许玩家使用一个简单的命令/ ping来检查他们的游戏中ping。显示消息可通过config自定义前缀和颜色。除此之外，您可以开启称号显示，并在标签列表（前缀/后缀）中显示玩家的ping。

将延迟显示在列表上面

汉化的配置文件，如果有需要请拿去提示：诺做的不好请见谅
使用教程：关闭BC打开BC文件目录找到BungeePing文件夹复制文本内容到插件的config.yml文本里面，保存打开BC

  1. #########################################################################
  2. # BungeePing 配置文件
  3. # https://www.spigotmc.org/resources/bungeeping.16840/
  4. # 请检查更新，如果需要，记得更新配置!
  5. #汉化 by xsbb Q1904421864
  6. #########################################################################

  8. # 与相关的部分 /ping 命令.
  9. ping-command:
  10.   # 自定义命令的输出，使用 % ping % 来指示玩家的延迟.
  11.   ping-message: "&a[Ping] &7你的ping是: &a%ping%ms"
  12.   #自定义命令的输出以检查另一个玩家的 ping (如果启用).
  13.   # 使用 % target % 表示目标玩家的名称，使用 % ping % 表示玩家的延迟.
  14.   ping-target-message: "&a[Ping] &7  &a%target% 的ping &7是: &a%ping%ms"

  16. # 与每个命令权限系统相关的部分.
  17. permission-system:
  18.   # 如果要启用权限系统，请将此设置为 true.
  19.   enabled: false
  20.   # 自定义发送给玩家的消息，如果他们没有必需的权限.
  21.   no-perm-message: "&c您没有执行此命令的权限."

  23. #与/ping <玩家> 命令相关的部分
  24. others-ping:
  25.   # 如果您想禁止用户检查另一个玩家的 ping，请将此设置为 false.
  26.   show-other-players-ping: true
  27.   # 自定义发送给玩家的消息，如果他们没有必需的权限.
  28.   not-allowed-message: "&c你没有权限检查其他玩家的 ping."
  29.   # 如果找不到指定的玩家，请自定义发送给玩家的消息.
  30.   player-not-found: "&c指定的玩家未在线."
复制代码


如果出现乱码或错误请试着切换编码或继续使用英文版config.yml里面
