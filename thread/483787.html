能不能实现挖一个方块输出一次数据呢?

可以，还是按照第一个指令创建一个判据为挖掘制定方块的计分板，再另外创建一个计分板
  1. /scoreboard objectives add b dummy
复制代码

然后用高频依次连接以下指令
  1. /testfor @a[score_计分板名_min=1,score_计分板名=1]
复制代码

这样会输出信号
后接比较器，连接命令方块（如果你想要多个输出就连个中继器接红石线），里面输入
  1. /scoreboard players set @a[score_计分板名_min=1,score_计分板名=1] b 1
复制代码

然后
  1. /scoreboard players set @a[score_b_min=1] 计分板名 0
复制代码

最后
  1. /scoreboard players set @a[score_b_min=1] b 0
复制代码
作者: lzs1234    时间: 2015-8-9 18:55
计分板有一个stat.mineBlock判据
用法/scoreboard objectives add 计分板名 stat.mineBlock.方块ID
可以探测玩家破坏了某种方块的数量
然后用/testfor @a[score_计分板名_min=最少分数,score_计分板名=最大分数]来探测分数在最少分数和最大分数之间的玩家，输进命令方块里用高频激活，后面跟红石比较器，会有信号输出（有几个玩家就会有几格信号，当然最高15）
