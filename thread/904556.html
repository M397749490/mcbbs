CNTrans 是站内外首个，也是目前唯一一款支持自动翻译整个中文服务器内容的插件,
方便我国港澳台地区的玩家在你的简体中文服务器内游戏、交流！

FEATURES 特色
  • 跨版本支持 1.9-1.14 *(暂不支持 1.8)
  • 修改数据包，你无需改变服务器的任何一点内容
  • 不需要 ProtocolLib
  • 自动提醒玩家切换 *(监听玩家客户端语言更改)
  • 翻译 GUI/物品/聊天/记分板/TITLE/TabList* 等等
  • 支持让繁体中文的服务器支持简体中文
  • 极好的兼容性, 可开关的翻译功能
  • 自动消歧翻译
  • 支持自定义翻译关键词替换 *NEW
  • 极简设计，快速上手，无繁琐配置
  • 自动更新检测
  • 代码开源






本插件所用所有代码均为原创,不存在借用/抄袭等行为, 本插件在 Github 上开源
