可以使用static关键字来修饰静态方法,这样在其他类就可以以 类名.方法名 来调用               也可以通过获取该类的实例来调用非静态方法

  1. class C1{
  2.         public static void aaa(){
  3.                 //调用非静态方法
  4.                 new C2().bbb();
  5.         }
  6. }
  7. class C2{
  8.         public void bbb(){
  9.                 //调用静态方法
  10.                 C1.aaa();
  11.         }
  12. }
