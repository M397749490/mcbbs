特别水的引言昨天，有人留言说做一把凋零弓，然后我就把命令参数改了一下，做出来了，
直接上命令
特别水的虚伪的烂透了的函数

  1. tag @e[type=arrow,limit=1] add wither_arrow
  2. #生成凋零之首
  3. execute at @e[tag=wither_arrow] run summon minecraft:wither_skull ~ ~ ~ {Motion:[0d,0d,0d],direction:[0d,0d,0d],power:[0d,0d,0d],Tags:["wither_skull"]}
  4. #转移tags
  5. execute store result score test test run data get entity @e[tag=wither_arrow,limit=1] Motion[0] 100
  6. execute store result entity @e[tag=wither_skull,limit=1] Motion[0] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[0] 1000
  7. execute store result entity @e[tag=wither_skull,limit=1] direction[0] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[0] 1000
  8. execute store result entity @e[tag=wither_skull,limit=1] power[0] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[0] 1000

  10. execute store result entity @e[tag=wither_skull,limit=1] Motion[1] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[1] 1000
  11. execute store result entity @e[tag=wither_skull,limit=1] direction[1] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[1] 1000
  12. execute store result entity @e[tag=wither_skull,limit=1] power[1] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[1] 1000

  14. execute store result entity @e[tag=wither_skull,limit=1] Motion[2] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[2] 1000
  15. execute store result entity @e[tag=wither_skull,limit=1] direction[2] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[2] 1000
  16. execute store result entity @e[tag=wither_skull,limit=1] power[2] double 0.001 run data get entity @e[tag=wither_arrow,limit=1] Motion[2] 1000

  18. execute store result entity @e[tag=wither_skull,limit=1] Rotation[0] float 0.01 run data get entity @e[tag=wither_arrow,limit=1] Rotation[1] 100
  19. execute store result entity @e[tag=wither_skull,limit=1] Rotation[1] float 0.01 run data get entity @e[tag=wither_arrow,limit=1] Rotation[1] 100

  21. #清除箭
  22. kill @e[tag=wither_arrow]
  23. tag @e[tag=wither_skull] remove wither_skull

特别水的虚伪的烂透了的命令分析
先看凋零之首的nbt格式（上文为英文维基原文，下文为我的理解）


Entity data
┣Tags common to all entities
┃    实体通用格式
┣direction: List of 3 doubles. Should be identical to Motion.
┃    direciton/方向：三个双精确浮点数与Motion相同
┣life: Increments each tick when the projectile is not moving; resets to 0 if it moves. Has no effect, though is still saved/read
┃    life/生命：在没有移动的每一刻递增，移动了就重置为0，没有效果，尽管还在读写（可能翻译有误）
┗power: List of 3 doubles that acts like direction but without resistance

      power/力量：与direciton的3个值相同，但没有阻力（可能翻译有误）


也就是说，要把弓箭的Motion复制到3个数组上面，所以命令会多很多，函数结束时在把Tags去掉就可以了
