白宝石小组最新汉化成果: LogBlock v1.61汉化=w=

LogBlock是一个强大的方块更改的记录插件. 他可以记录方块的破坏, 防止, 被水流/岩浆流/火焰破坏的方块, 甚至连树叶的消失都可以被记录! 当然, 除了这些, 还可以记录拉杆开关的使用情况, 门的开启情况, 牌子放置时的内容, 以及箱子的取出和存入记录. 在发现破坏之后, 管理员还可以通过LogBlock进行撤销操作, 误撤销操作也可以恢复. 查询不再只是一个方块所有记录那么简单, LogBlock可以自定义范围, 自定义方块列表, 自定义玩家名字, 自定义更改时间……LogBlock可以非常方便的找出破坏的凶手, 让管理不再头疼!

本汉化基于github源码重新构造汉化, 更改插件名称为LogBlockCN, 但是没有改变包名. 所以使用中文版LogBlock时, 请禁用原版的LogBlock. 本次汉化较为全面, 但由于基于源码汉化, 可能有部分内容没有成功汉化或者汉化的内容或顺序不通, 如果您有任何意见或建议, 均可发送邮件到root@jackyyf.com, 我会在第一时间内修复.

LogBlock 命令列表:
    /lb commands 列出命令列表
    /lb params 列出参数列表    /lb permissions 列出你所拥有的权限
    /lb tool 给你一个LogBlock查询工具
    /lb tool [on|off] 启用或者禁用LogBlock查询工具
    /lb tool [params] 设置工具查询的请求
    /lb tool default 设置工具查询请求为默认值
    /lb toolblock 等同于/lb tool, 不过是配置文件中的一个方块, 可以对放置位置进行查询
    /lb hide 将你从日志中隐藏
    /lb rollback [params] 撤销
    /lb redo [params] 恢复
    /lb tp [params] 将你传送到偷窃发生的地点
    /lb writelogfile [params] 写入到一个日志文件
    /lb lookup [params] 查询
    /lb prev|next 翻阅查询结果, prev为前一页, next为后一页
    /lb page 显示特定页码的查询结果
    /lb me 显示你自己的状态
http://github.com/LogBlock/LogBlock/wiki/Commands 有完整的命令介绍

LogBlock参数列表:
    使用双引号来转义一个关键词比如: world \"world\"
    player [name1] <name2> <name3> 玩家列表
    block [type1] <type2> <type3> 方块类型列表
    created, destroyed 仅显示被放置的/被破坏的方块
    chestaccess 仅显示物品箱的信息
    area <radius> 周围以radius为半径的范围内
    selection, sel 在当前WorldEdit选定的区域内
    world [worldname] 改变查询的世界为worldname
    time [number] [minutes|hours|days] 在最近指定的时间内
    since <dd.MM.yyyy> <HH:mm:ss> 从指定时间点到现在之间
    before <dd.MM.yyyy> <HH:mm:ss> 在指定时间点之前
    limit <row count> 限制返回结果的行数
    sum [none|blocks|players] 计算结果的总和
    asc, desc 更改返回结果的排序顺序
    coords 显示每个方块的坐标
    silent 更清爽的显示(减少冗余信息)
