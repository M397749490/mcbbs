向日葵

这个插件：

这个插件可以创建向日葵农场。你可以种植向日葵，向日葵的种子会成长。和其他农作物一样！

特性：
1.向日葵种子是需要种下来的。
2.向日葵的茎成熟后变成向日葵。
3.你必须把葵花籽放进土中，它会生长。
4 你可以吃向日葵的种子


指令：
只有一个
/sunflower reload      重新加载配置


配置： seed-name: '&7&6&8&6Sunflower seed' # Name of sunflower seed 向日葵花的名字 stem-max-age: 5 # Age of stem when it will turn into sunflower 多少天后会从茎变为向日葵
seed-craft-enable: true # Enable (true) sunflower seed recipe  葵花籽配方(?)  
allow-manual-place: false # Allows (true) to place sunflowers as a block  是否将向日葵归为一个方块
nibble:    food-level-per-seed: 1 # HP amount restored by one consumed sunflower seed  吃葵花籽可以恢复多少的饥饿度   
max-food-level-restore: 10 # Max HP-level that could be restored by nibbling sunflower seeds  吃葵花籽最多可以恢复多少饥饿度
  1. sunflower:
  2.   seed-name: '&7&6&8&6Sunflower seed' # Name of sunflower seed
  3.   stem-max-age: 5 # Age of stem when it will turn into sunflower
  4.   seed-craft-enable: true # Enable (true) sunflower seed recipe
  5.   allow-manual-place: false # Allows (true) to place sunflowers as a block
  6.   nibble:
  7.     food-level-per-seed: 1 # HP amount restored by one consumed sunflower seed
  8.     max-food-level-restore: 10 # Max HP-level that could be restored by nibbling sunflower seeds
