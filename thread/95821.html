和WebServer相比,这个多了 V10 scripting language 支持,以及自定义404页面之类的
关于V10可以在启用插件后在浏览器输入 http://127.0.0.1:8107/test.v10 查看演示
虽然设置里有php,但是不知道怎么弄

配置文件,见plugins下BukkitHTTPD.yml文件
  1. AutoUpdate: true  #自动更新插件
  2. HidePort: false  #隐藏端口(不清楚用处)
  3. Port: 8107  #网页端口(http://127.0.0.1:8107)
  4. Directory: F:\MineCraft\1.4.7\123\plugins\BukkitHTTPD  #网页文件地址,绝对路径,可以自动生成
  5. Banner: true  #横幅(BukkitHTTPD\banner.png)
  6. ShowPlugins: true  #显示插件(横幅中间)
  7. Color: '000000'  #颜色(横幅的文字)
  8. BannerRefresh: 30  #横幅刷新时间
  9. MinecraftBans: true
  10. error:  #自定义错误网页
  11.   '404': error/404.html  #自定义404网页
  12.   '403': error/403.html
  13. PHP:
  14.   exe: /usr/bin/php
  15.   Enabled: false
复制代码
其他的没什么了.
