https://papermc.io/legacy
在这里下载1.12.2的核心

然后建个文件夹 把核心丢进去
再在文件夹中建一个txt文本 内容写
  1. title 服务器名字
  2. java -Xmx250M -XX:MaxPermSize=128M -jar 核心名字.jar
  3. @echo 5秒后重启
  4. @ping -n 7 127.0.0.1>n
  5. @set a a=%a%+1
  6. @goto Menu
  7. pause
复制代码


然后再把后缀.txt改成.bat 双击启动
