①游戏基本信息介绍：

Minecraft是一款建立在Java系统上的一款像素高自由度游戏。

所以说游戏需要在安装JAVA的条件下进行运行。

如果想尝试自己编程也可以去Wiki搜索一下。

我接下来九详细说一下游戏的基本设置吧。

②Java安装

垃圾广告软件。当然不介意的话也可以】

然后进入安装程序

响的】


安装程序-

③登录器使用

目前比较方便的就是旋律登录器了-

首先我来介绍一下登录器的概念：

现在市面上所有的登录器大多数只使用于盗版。

正版登录器和账号需要通过在官网上购买，支付一定的金额才能获得。【貌似是200RMB左右】

当然正版账号淘宝上也是有的代购。-不过只要盗版还没被微软封杀，基本也不会去碰正版。

正版与盗版的区别：

正版：可以直接添加模组和皮肤。

盗版：需要安装一定的插件来进行更多样性的游戏。

--

我的世界目前比较适用的版本：【PC版】

①1.5.1、1.5.2-主要是为了一些好玩的模组以及水桶的开服。

②1.6.2           -目前最主流的游戏版本，一些基本的设置都已经齐全，较于之前的版本更加的完善。模组也比较多。

大多数生存模组服务器都是用1.6.2版本。

③1.6.4           -主要是一些中小型模组服务器使用的。可以安装暮色神秘之类的大型解密新大陆性模组。也是比较多的。

④1.7.2           -这个版本是比较新的，在1.6X的基础上添加了彩色玻璃新的这几个方块。在指令和设置方面更加完

善。一些大型服务器一般都是1.7.2的。

⑤1.7.10     -主要是一些小模组，在设置和方块上貌似没有太多的改变。

⑥1.8.1          -Minecarft最新的版本，目前没有多少的模组，增加方块，AI生物。

③游戏基础玩法


    按照我的方法进入游戏之后，就可以开始你的游戏。

具体的攻略可以参考怀念的生存三部曲，我只在下面对各种模式进行初步的介绍。

No.1

创造模式-：

创造模式又可以称之为上帝模式。

通过这个模式玩家可以高自由度的破坏以及放置方块，以及创造AI生物，这一切都是由自己决定的。并通过一定的指

令进行作弊行为。

基础操作-：

双击空格键-飞行

WSAD:上下左右

Q：丢弃

G：安装了合成表的可以查看。

F1：物品栏消失

F2：保存照片

F3：显示配置信息

No.2

生存模式

玩家要通过各种途径进行生存，通过采取各种资源进行游戏。

可以在游戏设置里调节世界的生成，开启作弊。

基础操作：

WSAD:上下左右

Q：丢弃

G：安装了合成表的可以查看。

F1：物品栏消失

F2：保存照片

F3：显示配置信息
No.3


极限模式

较于生存模式更加有难度。

在极限模式中，游戏将强制将难度设置为困难，同时您无法修改这个世界的难度。

并且每个玩家只有一条生命，死亡后会显示得分不能复活。

基础操作：

WSAD:上下左右
Q：丢弃
G：安装了合成表的可以查看。
F1：物品栏消失
F2：保存照片
F3：显示配置信息


④基础指令

首先玩家需要在设置中开启作弊。若没有开启作弊模式，你会发现回车不能打开输入框     。

首先请安回车。

有一些版本或登录器是T。

【一些服务器的命令在单人是不可用的】

1.设置出生点/setspawn

2.关闭死亡掉落/gamerule keepInventory true

3.切换模式/gmd 0-生存模式 1-创造模式 2-极限模式

4.停雨/rain off

5.调整时间-一般这个TMI修改器可以直接跳-/time set [xx:xx]

6.回到死亡地点 /back

7.给自己一定的物品/give 物品序号 数量

8.自杀病娇专用！-/kil

⑤总结

总的来说，这款游戏还是很容易上手的。

生存技巧和一些建筑技巧可以在探索中慢慢领悟。
