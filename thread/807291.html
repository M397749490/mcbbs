1.8.9安装方法（以V3.2.9为例）

-----分割线-----

官方下载地址：https://www.labymod.net/download
下载了格式为.jar的安装文件后

在桌面或其他能找到的文件夹中新建一个.txt文本文件（与下载的.jar文件同目录！），输入以下代码
  1. java -jar LabyMod3_Installer.jar
  2. pause
复制代码
注意，代码中的LabyMod3_Installer.jar这一段指令请按照实际情况使用
"另存为"中转变格式为.bat文件，一切妥当后双击这个.bat文件开始安装！
（如果你下载了上面的启动器直接将启动器放进同目录双击启动）


↑请按照实际情况选择版本↑
第二栏选择Forge，选择完成后选择Next


↑选择额外增加的项目↑
列出文字的翻译
MotinBlurmod-动态模糊
CWBW GommeHDnet-LabyStudio团队的旗下Mod（辅助类）
CustomCrosshair-自定义准心
MoreParticles-更多粒子效果
DamageIndicator-血量显示
Keystrokes v3-按键显示
Resourcepack24-更多的材质包
GommeHDnet-外国的一个小游戏服务器
DirectionHUD-显示装备、武器的耐久以及药水效果
ToggleSneak-自动冲刺
WorldEdit CUI-创世神插件用户界面（显示圈住方块）
Settings Profile Mod-显示CPS
ItemPhysics-掉落物品物理化（比如在水中的掉落物品会浮起来，在地上的物品会因为这个mod而不会像以往悬空旋转了）
OptFine-高清修复

请注意！在安装时它会自动勾选OptFine，请根据自己安装的客户端是否含OptFine取决是否安装！

选择完成后按下Install键等待安装完成
安装时可能弹出要求安装Forge，选择No
（这里选择了No以后，想要安装这个mod的客户端需要安装Forge）
（如果你没有安装Forge，选择yes以后手动安装的Forge必须为正版客户端，否则Forge将无法检测到你的客户端！）
安装可能需要五到十分钟，请耐心等待
安装完成后，安装文件的位置：
  1. C:\Users\Administrator\AppData\Roaming\.minecraft
复制代码
这里将有两个文件夹，一个名为LabyMod（是LabyMod的文件），另一个为mods（自定义下载的mods）
将两个文件夹中的mods全部复制，粘贴进对应版本的mods文件夹
然后运行启动器，启动游戏
进入游戏后你就可以看到这个mod啦！
