华丽丽的分割线~~




首先把一台电脑网在发射器旁边，使用
  • peripheral.wrap(side)


来把发射器包裹进来
使用craftFireworkStar(number color(s), number shape, number effect)来创建一个烟花的样式，返回值是一个叫starID的数值

其中shape的代码为：
代号　　形状　　　材料
0 　　标准圆球　　无
1　　　大圆球　　火焰弹
2　　　星形　　　金粒
3　　苦力怕形　　任何的头
4　　　爆炸形　　羽毛

effect的代码为
代号　效果　　　　　　　　材料
0  　　无　　　　　　　　　无
1　　　闪烁　　　　　　　　萤石粉末
2　　　燃烧痕迹　　　　　　钻石
3　　　闪烁＋燃烧痕迹　　　萤石粉末＋钻石

如果使用创造模式的烟花发射器(橘红色的那个)，则不需要材料。一般都用于创造模式吧，谁无聊在生存中造烟花

使用craftFireworkRocket(number launchHeight[1-3],table starIDTable)来创建一个烟花的火箭，返回值是这个火箭的ID

使用inspectFireworkRocket(rocketID)激活火箭
使用launch()来发射。

最简单的发射一枚火箭的例子

  • FL = peripheral.wrap("back")
  • function LaunchFireBall(color,shape,effect,launchHeight)
  • local starID = {}
  • isSuccess,starID[0] = FL.craftFireworkStar(color,shape,effect)
  • isSuccess,rocketID = FL.craftFireworkRocket(launchHeight,starID)
  • FL.inspectFireworkRocket(rocketID)
  • FL.launch()
  • end



作者还在MP里内置了其他玩家(Dog and TheOriginalBIT)制作的一个图形化的焰火发射界面

在装了mp的电脑里输入StarCaster即可使用
