最近服务器里捣乱的小孩特别多

于是闲来无事写了个状态插件
从这些信息和聊天可以大概推断出他具体再干嘛

这是plugin.yml
  1. name: GetPlayerInfo
  2. main: cn.minecraftunion.plugin.Entry
  3. author: InfinlityBlack
  4. version: 1.0.0

  6. commands:
  7.   gpi:
  8.     description: Version
  9.     usage: /gpi
  10.     permission: GetPlayerInfo.Version
  11.     permission-message: Unknown Command .
  12.   get:
  13.     description: Get Player Info
  14.     usage: /get ID
  15.     permission: GetPlayerInfo.info
  16.     permission-message: Unknown Command .

  18. permission:
  19.   GetPlayerInfo.Version:
  20.     description:
  21.     default: true
  22.   GetPlayerInfo.Info:
  23.     description:
  24.     default: op
复制代码


插件功能指令是/get ID
显示玩家各种状态
包括生命，食物，手持物品，坐标，等等
