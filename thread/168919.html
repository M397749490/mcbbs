这只是建议不是教程 TukMC是一个界面美化mod
1.除了GuiIngame.java以外的其他类都用hhclass汉化文本
2.GuiIngame.java使用源代码进行文本修改
3.最后测试时你会发现地形并没有汉化
无论用hhclass还是源代码都找不到这个文本根据作者的源代码显示如下
  1. private void drawTopBar(final FontRenderer fr, final RenderItem ir,
  2.             final int width, final int height, final String biomeName)
复制代码
这说明地形是作为参数提交进来的
4.你可以在源代码中添加以下代码
  1. String biome;
  2. biomeName=biomeName.toLowerCase();
  3. switch(biomeName){
  4.          case 'jungle':
  5.          biome="丛林";
  6.          break;
  7.          case 'forest':
  8.          biome="森林";
  9.          break;
  10.          case 'desert':
  11.          biome="沙漠";
  12.          break;
  13.          case 'swampland':
  14.          biome="沼泽";
  15.          break;
  16.          case 'plains':
  17.          biome="平原";
  18.          break;
  19.          case "tundra";
  20.          case "ice plains":
  21.          biome="雪地";
  22.          break;
  23.          case "taiga":
  24.          biome="泰加林";
  25.          break;
  26.          case "extreme hills";
  27.          case "mountains":
  28.          biome="山地";
  29.          break;
  30.          case "ocean":
  31.          biome="海洋";
  32.          break;
  33.          case "mushroom island";
  34.          case "mushroom":
  35.          biome="蘑菇岛";
  36.          break;
  37.          case "neither";
  38.          case "hell":
  39.          biome="地狱";
  40.          break;
  41.          case "sky";
  42.          case "the end":
  43.          biome="末地";
  44.          break;
  45.          default:
  46.          biome=biomeName;
  47.          break;
  48. }
  49. biomeName=biome;//这段代码加在那个方法中
复制代码
这样以后TukMC汉化就完整了
