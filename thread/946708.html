SuperHolidayGift

天降大礼



前言：以前的很多宝藏插件，很多随机度不够，扩展性不够，很多需要繁杂的配置并且缺乏新意，而今天，漂浮带着SuperHolidayGift来敲响你的大门

插件服空降任意贴图的梦想已经实现！无论你是RPG还是各种各样的服务器，都可以使用他


亮点介绍
- VexView支持

|- 自由配置宝物的贴图地址、贴图大小及其偏转和偏移

|- 自由配置宝物的下降速度(位移差)和刷新速率

|- 可以根据物品开关是否显示展示名以及自由配置展示名的高度和相对偏移


- 丰富的系统及自由组合

|- 自由配置宝物的展示名和多条触发的指令及获得概率

|- 自由配置每个宝物不同的获取成功和失败的提示信息

|- 自由配置每个宝物生成的Title信息

|- 自由配置的范围系统

|- 自由选择的降落逻辑

|- 礼包与范围的独立保证每一个礼包都可以在每一个区域内快速生成

|- 通过指令生成任意数量的任意礼包在任意的配置范围

|- 高级的代码优化力保证执行效率

|- 可以通过指令/VexGui界面来获取藏宝图

|- 藏宝图可自定义半径等多种参数智能生成

|- 一键回收指令保证服务器的正常运作以及残余礼包的回收

使用初步

使用本插件之前，了解原理对你配置礼包起了很好的帮助作用

本插件原理主要集中在这一句指令

/holiday spawn [生成的区域] [生成的礼包] [数量]

所以我们只需要配置好区域和礼包即可直接使用指令来生成礼包

复制代码
生成范围详解
在config.yml 配置文件下，有一个dropWay节点，配置文件中有详细的介绍，将井号和冒号中间的英文粘贴替换即可

  1. #下降方式
  2. # BOTH_BLOCK_FW: 在范围内最顶端随机生成礼包，依次往下掉落，直到碰到方块或者到达范围底部停止
  3. # BOTH_BLOCK_XK: 在范围内最顶端随机生成礼包，依次往下掉落，直到碰到方块或者触碰到虚空停止
  4. # BOTH_ALL_RANDOM: 生成时每一个礼包的X、Y、Z轴全部随机，可能会卡在方块里，直到碰到方块或者到达范围底部停止
  5. dropWay: 'BOTH_BLOCK_XK'
复制代码
指令及权限
指令必须权限: SuperHolidayGift.use

/holiday spawn 在某个区域空降某个礼包
权限: SuperHolidayGift.spawn     
/holiday guide send 为某个玩家输出藏宝图
权限: SuperHolidayGift.guide.send
/holiday guide sendall 为全部在线玩家输出藏宝图
权限: SuperHolidayGift.guide.sendall
/holiday reload 重载配置文件
权限: SuperHolidayGift.reload
/holiday guide open 打开Vex藏宝图界面
权限: SuperHolidayGift.open
/holiday guide get 获得聊天框输出的藏宝图
权限: SuperHolidayGift.guide.get
