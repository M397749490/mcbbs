Hello，大家好，我是Soft，今天给大家带来我的最新成果。

效果

如图，这里就是全部的电路，十分简单。



我们来到右边，看到一个按钮。


点击了之后，下方迅速出现一串无规律的九位数。


再按一次，产生的数也不同了。
怎样，是否很神奇呢？在旧时代，用红石做一个随机数器，位数很低，且生成的的时间也不短。
而且实现起来很麻烦，现在可以轻松地快捷的生成一串随机数。

原理翻页

原理

原理大家也看到了，十分简单。首先，按下按钮，绿色线路会触发9个发射器。


那么发射器里是什么呢？是九个命令方块。众所周知，1.8目前可以通过发射器放置方块。

随机数的每一位都对应一个命令方块。这里以亿位的为例子。
从第一个到第九个命令分别是：
  1. /scoreboard players add @a 1 100000000
复制代码
  1. /scoreboard players add @a 1 200000000
复制代码
以此类推，最后是
  1. /scoreboard players add @a 1 900000000
复制代码


大家可以看到，末端还有3个命令方块。



第一个：清除9个命令方块
clone 0 68 4 0 68 -4 0 65 -4
第二个：说出分数
/tellraw @a {text:"Random Number: ",extra:[{color:green,score:{name:"*",objective:"1"}}]
第三个：补充发射器(把上方的发射器克隆下来）
clone 0 68 4 0 68 -4 0 65 -4

当再次生成随机数时，系统会把上次的分数清零

  1. /scoreboard players set @a 1 0
复制代码


怎样，是不是很简单呢？同样这个可以无限扩展，生成无限的随机数。
