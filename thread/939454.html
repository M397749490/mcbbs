我想检测玩家背包没有某个东西时候就执行命令
作者: Chelover_C60    时间: 2020-1-9 16:24
利用tag检测玩家nbt，当玩家没有某个nbt时，给玩家加上标签，然后让有标签的玩家执行命令即可。这样可以避免使用中继器，也可以避免延迟。
示例:给所有没有石头的玩家一颗钻石
/scoreboard players tag @a add stone
/scoreboard players tag @a remove stone {Inventory:[{id:"minecraft:stone"}]}
/give @a[tag=stone] diamond
/scoreboard players tag @a remove stone

首先这个某个东西，比如石头
给予
一个附加值为0，nbt为foo值为1b的石头
/give @s stone 1 0 {foo:1b}

检测，放进命令方块里，后面接比较器做输出检测
清除附加值为0，nbt为foo:1b的石头零个
/clear @a stone 0 0 {foo:1b}

比较器亮了则表明玩家背包有此物品，
反之没有(强烈暗示接个非门...)

*foo:1b用于区分特殊物品，要检测一般物品把nbt那段去掉即可
作者: xiang_xge    时间: 2020-1-9 16:45
首先，取一循环性命令方块，调为保持开启，输入/clear @a minecraft:[你要检测物品的英文名] 0 0
然后取一红石比较器，将输入端对准循环性命令方块
在输出端放一不透明方块，不透明方块另一侧插一红石火把
将红石火把旁放上一脉冲命令方块，输入要执行的指令即可
