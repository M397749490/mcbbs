提供获取服务器信息的API:
1.7及1.8版本用:
                         http://api.blminecraft.com/api/getServer.php?Server=你的服务器地址(如localhost或者localhost:25566.端口默认25565)
                         如果成功则返回一串json格式信息:                                            
  1. {
  2.     "status": true,
  3.     "players": {
  4.         "online": 9,
  5.         "max": 1000
  6.     },
  7.     "motd": "\u6df7\u6c8c\u65f6\u7a7a-\u7ea2\u77f3\u6218\u4e89\u4e91\u7ec4",
  8.     "version": "BungeeCord 1.8",
  9.     "latency": "0.016"
  10. }
复制代码
                         status即是否成功(一般都是true.不成功也不会显示这边了.你可以通过判断是否有这个来获取是否成功)
                         players分为online和max
                         motd即每日信息.Unicode格式
                         version即服务器端版本
                         latency返回的是延迟
                         所有数据有30s的缓存
                         失败则返回：
  1. {
  2.     "error": "Failed to connect to test:25565"
  3. }
复制代码
1.7以下版本请使用:
                             http://api.blminecraft.com/api/getOldServer.php?Server=你的服务器地址(如localhost或者localhost:25566.端口默认25565)
                             所有返回信息同上
