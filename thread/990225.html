如何使用 ...

首先init玩家,参数是玩家和tab有几列(1,2,3,4)
假设你的list有30个,你需要init两列
int index=0;
for(Player player:list)
{
    TabManager.update(player,index,index>20 ? 1 : 0,"这是tab显示的内容",0);
}
此外建议一直4列,其他列数根据分辨率不一定是三列或者每列20个
