为什么要学C#
C#虽然只在编程语言排名中排第5
但C#的功能却十分强大
主要包括
桌面应用开发
游戏开发(Unity3D等)
Web应用
其次，它还可以完成人工智能，网络爬虫等任务
并且很重要一点，C# 还非常容易入门

因此，C# 就非常适合  非工作用途(业余)   的学习
（ 当然，作为工作用途也是不错的选择 ）
随手就能做出一些有趣的桌面应用，或者简单的游戏
比其他语言都要方便很多
当然各个语言都有它自己的专长
因此就有过一个笑话：
只有新手程序员才会比谁的语言更好
之后就都在比谁有女朋友了

再说，C# 是微软爸爸的，它能不香吗？（雾）
什么是C#
C#（读作“See Sharp”）是一种新式编程语言，不仅面向对象，还类型安全。 C# 源于 C 语言系列，C、C++、Java 和 JavaScript 程序员很快就可以上手使用。


C# 是一门编程语言，它属于.NET平台
那.NET又是什么呢？？
.NET的官网 是这么说的
.NET is a developer platform with tools and libraries for building any type of app

.NET是一个开发平台，它具有用于构建任何类型的应用程序的工具和库
