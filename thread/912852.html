积雪
Snowpack
原版下雪天的雪片只有一层，本模组去掉了这种限制，雪片可以无限堆，堆到8层会得到雪块并可以继续往上堆。默认速度很慢，不用担心被雪淹没不知所措。
同时，下雨天将会在河面/海面产生积水，随着时间推移积水会越来越多，小心被水淹没不知所措。
配置
使用命令
  1. /scoreboard players set #doSnowPack spvalue 0或1
复制代码
来关闭/开启积雪功能，默认为1(开启)。
使用命令
  1. /scoreboard players set #doSeeper spvalue 0或1
复制代码
来关闭/开启积水功能，默认为1(开启)。
使用命令
  1. /scoreboard players set #SnowPackPeriod spvalue [数值]
复制代码
来修改积雪生成速度，数值越高速度越慢，默认为4。
使用命令
  1. /scoreboard players set #SeeperPeriod spvalue [数值]
复制代码
来修改积水生成速度，数值越高速度越慢，默认为600。

原理简析
周期在玩家附近生成标记，标记处生成判断天气的战利品表。若为下雨天则生成判断群系和下雪所需高度的战利品表，然后和当前高度做比较。若满足条件则将下方的雪层堆叠一层。
