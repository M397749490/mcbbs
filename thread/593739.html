用residence领地插件就可以做到
打开配置文件/plugins/Residence/config.yml， 然后找到设置领地外默认权限的选项，改成像下面这样
    Flags:
        Global:
            use: false
            build: false
            ignite: false
            firespread: false
            damage: false
            creeper: false
            tnt: false
            pvp: false
        ziyuan:
            build: true
            damage: true
            use: true

其中Global是设置所有世界的默认选项的， build就是设置玩家建造破坏权限，true就是允许，false就是禁止，底下的ziyuan是如果你想设置资源世界用不同设置，除了建筑权限外依次是怪物伤害和使用按钮踏板等的权限。
希望能帮到你。

怎么实现主世界只有领地才能建筑的功能？

你可以把Global底下的build后面改成true，然后单独设置主世界的build权限为false，
比如主世界的名字是world，那么领地配置文件的Flags底下看起来就是这样：
    # 这个是世界flag,不在领地中时
    Flags:
        Global: #下面这些为世界总体默认flag设置, 这会覆盖各个组的设置
            use: true
            build: true
            ignite: false
            firespread: false
            damage: true
            creeper: false
            tnt: false
            pvp: false
        world: #这里你可以设定个人的世界，这些覆盖总体的flag
            build: false
