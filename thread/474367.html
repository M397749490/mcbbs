用Citizens插件的服主是不是遇到过不支持Cauldron的情况？

那么，Cauldron官方论坛推出的Citizens 2 for Cauldron能解决!


简单说明：Citizens是一个NPC插件，可以让NPC做很多与真实玩家一样的事，通过安装其他插件可以使它做更多的事。

安装方法：放进Plugins文件夹。

命令(我不懂的就没说，只说主要的)：首先要创造一个NPC，/npc create 名称 ，如果要更高级的，可以这样：/npc create 名称 --at x:y:z --type 动物类型(见下) --trait (如果装了类似Sentry的插件，输入名称，如Sentry，没有就不要输入--trait)。


名称
在Citizens里面的名称
史蒂夫(其实就是玩家)
player
动物
它的英文名称(见wiki)(大小写随便)


现在有了NPC了吧，多创造几个之后，是不是要选择一个？选择最近的：/npc select，如果要选择指定的NPC，怎么办？/npc select 名称(id也行)。

名字手残打错了怎么办？/npc rename 名称。

如何找到NPC的id？/npc list，如果查看当前选择的NPC的id，/npc id即可。

现在想让NPC游泳吗？/npc swim --set true 是设定能游泳，把true改成false就是不能游泳。

NPC重生时间(比如装了Sentry后被杀死了重生时间，还有掉进虚空)/npc respawn 时间(单位为ticks)。

选中了NPC想看它的详细信息，那么就输入/npc。

NPC死沉沉地站着不好看，那么就输入/npc path来吧！输入之后，左键添加一个点，右键删除一个点，添加好之后，NPC会在这几个点之间走，如果设置好了，输入/npc path即可保存。

那么，将NPC设置成了僵尸，如何让它变成小僵尸或僵尸村民呢？/npc zombiemod -b 这样就能变成小僵尸，把b换成v可以变成僵尸村民。

来试试反重力的NPC吧！/npc gravity 显示enabled代表开启重力，disabled代表反重力。

想骑NPC吗？/npc control 显示“名称 can no longer be controlled”代表骑不了，“名称 can now be controlled”代表能骑。

改变NPC类型：/npc type。

当NPC是苦力怕时，输入/npc power即可变成闪电苦力怕，再次输入取消。

NPC看附近玩家：/npc look。

让NPC到你那里：/npc tphere。到NPC那里：/npc tp。

让NPC飞：/npc flyable true 把true改成false即可取消。

让NPC消失但不删除配置：/npc despawn。恢复输入/npc spawn。

想让NPC的名字不显示吗？/npc name。

让NPC说话：/npc text进入编辑模式，此时输入add(不加/)进入添加模式，然后输入NPC要说的话，再加的话输入add后再输入。remove是删除文本，输入之后可以看到文本编号，然后输入编号即可删除，删除其他的文本操作一样。然后配置好后输入random来设置说出随机语句，close设置靠近玩家说话，然后输入exit退出。

更改NPC年龄：/npc age 年龄。

更改NPC所有者：/npc owner 玩家名称。

更改NPC手上拿的东西：/npc equip 然后拿物品右击NPC即可。再次输入即可保存。不过，NPC拿的Mod物品会导致物品变为默认状态，比如ComputerCraft的掌上电脑会关机。

/citizens reload citizens.admin
/citizens save citizens.admin
