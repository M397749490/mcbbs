标题: [综合|安全|经济|传送|管理]多功能集成插件v1.2.2 —— 必备插件合集！[1.4.6-R0.1]
本插件的最初诉求为一体成形、简易设定、方便管理以及可以轻松进行个人化的调整。
主要的插件功能都具有独立开关。目前暂无权限方面的设定，较适用于小型服务器。
此外插件初始目的之一就是当教学用材料，所以欢迎自行取用源始码进行个人需求的修改。

插件的设定全都集合在config.yml单一档案上。另外会自动产生data.yml用来记录相关资料。
新版本追加value.yml档案，用来转换怪物名称、物品名称。
建议使用Notepad++ 做为编辑YAML 档案的软件。
Notepad++官方页：http://notepad-plus-plus.org


ExpansionManager目前有三个主要功能：
　      IPAuth：可将玩家的名称与IP位置做绑定处理。
　 　 此功能仅适于玩家皆为固定IP或者透过如同LogMeIn Hamachi的方式连线时使用。
　 　 预设为关闭状态。
　 　 ● 功能初始参照插件为同名的IPAuth插件。
　      KeepInventory：可设定死亡时是否保留身上物品，并可做机率性保留处理及掉落时的公告设定。
　 　 ● 功能初始参照插件为KeepItems插件。
　      Protection：可设置各种游戏保护的功能。
　 　 除一般的爆炸类保护外，额外有设定僵尸是否能破坏门、
　 　 是否可破坏挂画及物品展示框以及玩家离线时进行宠物保护等功能。
　 　 ● 功能初始参照插件为NoEntityGrief 、 SafeExplosions 、 LockProtection等插件。


CommandManager主要为指令方面的追加功能：
　      CommandRestrict：开启时将会使玩家除了设定内的指令外，其余指令皆无效 &#8203;&#8203;。
　 　 ● 功能初始参照插件为UnknownCommand插件。
　      CommandCooldown：可设定指令的再次使用时间。
　      Back：指令/back可返回先前的死亡地点。
　      Hat：指令/hat可将手中物品戴至头上。
　 　 ● 功能初始参照插件为SimpleHat插件。
　      Home：指令/homeset可设置当前地点为家。而/home可返回到设置的家。
　 　 ● 功能初始参照插件为Homestead插件。
　      Ping：指令/ping可查询与伺服器的延迟时间。
　      Spawn：指令/spawnset可设置当前位置为该世界的重生点。而/spawn可返回到重生点。
　 　 ● 功能初始参照插件为PlgSetspawn插件。


MessageManager
　 主要为讯息方面的功能设定。
　 可设置玩家聊天讯息的格式、玩家加入游戏、离开游戏及死亡讯息、重生讯息。
　 此外还可自订Help 帮助清单跟设置循环提示讯息的功能。
　 ● 预设的游戏讯息格式设定方面，功能初始参照插件为nChat + dhmcDeath插件。
　 ● 自制帮助清单的功能初始参照插件为iHelp插件。
　 ● 循环提示讯息的功能初始参照插件为ZNounce插件。


BonusSystem
　 奖励系统，可在玩家累积在线时间达到设定时给予玩家奖励。
　 ● 功能初始参照插件为DailyBonus插件。


MoneySystem
　 独立的金钱系统，可在玩家杀死生物时给予玩家金钱。
　 目前附有指令的直接交易功能做为衍生应用。
　 ● 功能初始参照插件为MobBountyReloaded插件。

　  插 件 设 定  　　

。 ExpansionManager
　 。 Setting
　 　 。 IPAuth
　 　　  。 MaxAccounts 设置一个IP最多可注册的名称数量。
　 　 。 KeepInventory
　 　　  。 DropPercent 设定玩家死亡时掉落物品的机率百分比。请直接输入0 ~ 100的整数。
　 　　  。 DropBroadcast 设定玩家死亡并掉落物品时是否进行公告。
　 　 。 Protection
　 　　  。 WorldName 设定要进行以下保护功能的世界名称。
　 　　  。 BlockIgniteByLightning 保护被闪电击中的方块不着火。
　 　　  　 设定0 为关闭此保护。
　 　　  　 设定1 为开启此保护。
　 　　  　 设定2 为开启此保护，但仅限在重生点范围内。
　 　　  　 以下保护功能皆是如此设定。
　 　　  。 EntityBreakDoor 保护门不被生物破坏。
　 　　  。 EntityChangeBlockByEnderman 保护方块不被Enderman终界使者搬动。
　 　　  。 EntityChangeBlockByWither 保护方块不被Wither凋零怪撞毁。
　 　　  。 EntityDamage 保护生物不被伤害。除OP的普通攻击类可进行强制伤害。
　 　　  。 EntityDamageByPetWhenOwnerOffline 保护狗跟猫在饲主离线时不受伤害。
　 　　  。 EntityExplodeByCreeper 保护方块不被Creeper苦力怕破坏。
　 　　  。 EntityExplodeByFireball 保护方块不被火球类的爆炸（如Ghost地狱幽灵）给破坏。
　 　　  。 EntityExplodeByTNT 保护方块不被TNT 破坏。
　 　　  。 EntityExplodeByWitherSpawn 保护方块不被Wither凋零怪生成时的爆炸给破坏。
　 　　  。 EntityExplodeByWitherSkull 保护方块不被Wither凋零怪的凋零骷髅头所产生的爆炸给破坏。
　 　　  。 HangingBreak 保护画及物品展示框不被破坏。但若依附的方块被破坏仍会掉落。
　 　　  。 HangingPlace 使画及物品展示框无法放置。
　 　　  。 PigZap 保护猪不会因为被闪电击中而变成僵尸猪人。
　 　　  。 PlayerInteractTrampleSoil 保护农地不会因玩家践踏而变回土块。
　 　　  。 PlayerInteractBreakBlock 使玩家无法与下面PlayerInteractBreakBlockIDList所设定的方块互动。
　 　　  。 PlayerInteractBreakBlockIDList 同上，在此列方块ID清单中的方块将无法进行互动。
　 　　  　 关于方块ID请参照 Minecraft Wiki : Data values
。 CommandManager
　 。 Setting
　 　 。 CommandRestrict
　 　　  。 Allow 当启用时，除了在这边设定的指令外，其余指令皆将无法使用。
　 　 。 CommandCooldown
　 　　  。 List 设定指令的冷却时间。以「:」冒号为分隔，前为指令名称，后为冷却时间。以秒为单位。
　 　　  。 Format 可设定给玩家的讯息中的时间格式。以「,」逗号为分隔，依序为秒钟、分钟、小时。
　 　 。 Back
　 　　  。 SpendFood 可设定使用指令时所消耗的饱食度。
　 　　  　 若要设定为消耗一格饱食度则设定2 ，半格饱食度则设定为1 。
　 　　  　 当值为0 时则关闭消耗饱食度的设定。
　 　　  　 下方Home 、Spawn 都有相同功能。
　 　 。 Ping
　 　　  。 Value 对应下面Color中的数值颜色。
　 　　  　 例如预设值的100,300 则代表：
　 　　  　 当延迟时间为0 ~ 100 时显示Color 的第一个颜色。
　 　　  　 当延迟时间为101 ~ 300 时显示Color 的第二个颜色。
　 　　  　 当延迟时间为300 以上时则显示Color 的第三个颜色。
　 　 。 Spawn
　 　　  。 FirstJoinInSpawn 设定玩家初次进入时是否诞生在重生点。否则如预设的会随机生在重生范围内。
　 　　  。 FirstJoinStrikeLighting 设定玩家初次进入时是否在该处降下落雷。
。 MessageManager
　 。 Setting
　 　 。 Chat 是否自订玩家对话格式。
　 　 。 Join 是否自订玩家加入游戏时的讯息。
　 　 。 Quit 是否自订玩家离开游戏时的讯息。
　 　 。 First 是否使用玩家第一次加入游戏时的讯息。
　 　 。 Respawn 是否使用玩家重生时的讯息。
　 　 。 Death 是否自订玩家死亡时的讯息。
　 　 。 Help 是否使用自订的/help帮助清单。
　 　 。 Tip
　 　　  。 Interval 设置循环游戏提示的间隔时间，以秒为单位。
　 　　  。 Random 设置游戏提示的方式，true为随机，false为依照顺序。
　 。 Message
　 　 。 Help
　 　　  。 Player 这边将设定一般玩家使用/help所得到的帮助清单。
　 　　  。 Operator 这边则为OP才看得到的部分。
。 BonusSystem
　 。 Setting
　 　 。 TimerInterval 设定玩家在线时间的记录间隔。以秒为单位。
　 　　  数值越小则记录间隔越短，而玩家的在线时间也就记录得越精准，但相对的会使资料档写入较频繁。
　 　 。 BonusInterval 当玩家累积的在线时间达到此数量时即给予奖励。以秒为单位。
　 。 Group
　 　 。 0 给予奖励的组别，限数字，从0开始。
　 　　  。 Item 给予的奖励物品，以「x」为分隔，前方为物品ID ，后方为数量。
　 　　  。 Percent 得到该组奖励的机率百分比。
　 　　  　 系统一定会选出一组奖励，所以只有在有2组以上的奖励组别时，此机率设定才有实际功效。
　 　　  　 选择方式为：先随机选择组别（公平机率），之后再依照组别的机率判定是否获得该组奖励。
　 　　  　 若在机率外则会重新选择组别。
　 　　  。 Broadcast 当得到本组奖励时是否进行公告。
　 　　  。 BroadcastMessage 当使用公告时的公告讯息设定。
。 MoneySystem
　 。 Setting
　 　 。 Blaze ~ Zombie
　 　　  为杀死怪物获得的金钱设定，以「,」逗号为分隔，
　 　　  依序为掉落的最大金钱量、最小金钱量、掉落机率。
　 　　  PS 预设中杀死终界龙是所有线上玩家一起获得金钱。
　 　 。 TradeTime
　 　　  设定交易的逾时时间，以秒为单位。


所有讯息设定中，若要使用颜色设定则都使用游戏预设的「§」符号。如§f之后的文字便是白色。
相关颜色代码请参照 Minecraft Wiki : Formatting codes
