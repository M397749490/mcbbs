作者: lgou2w    时间: 2019-4-9 17:39
适用于 1.13 之前的版本。
  1. EntityType type = EntityType.fromName("zombie");
  2. ItemStack stack = new ItemStack(Material.MOSTER_EGG, 1);
  3. SpawnEggMeta meta = (SpawnEggMeta) stack.getItemMeta();
  4. meta.setSpawnedType(type);
  5. stack.setItemMeta(meta);
复制代码

如果是 1.13 之后版本的话使用对应物品材料类型就行。
  1. ItemStack stack = new ItemStack(Material.COW_SPAWN_EGG, 1);
  2. ItemStack stack = new ItemStack(Material.ZOMBIE_SPAWN_EGG, 1);
复制代码
