标题: [PC/Mac]Minecraft官方启动器 使用说明[20150729更新]
本教程针对老款正版启动器，现已过期，请勿参考







本文是为PC/Mac版官方启动器准备的。希望为被Profile和version搞得晕头转向的玩家提供一点帮助。
由于官方启动器只有英文版，热切希望你阅读本文前能有一定的英语基础。

写本文的原因：
首先，官方启动器目前还在开发中，功能可能随着官方MOD API的开发进度会随时增增减减。
其次，官方启动器与Minecraft客户端本身有最紧密的、得天独厚的联系，也是众多非官方启动器设计的蓝本。
再者，支持正版用户也是每一个Minecraft社区的责任
最后，也许本文能够促进一些人入正？那就更好了

官方正版启动器无法刷新新版本列表/无法下载解决方案
[教程][正版相关]Minecraft PC正版介绍与购买渠道

界面说明
以Minecraft Launcher 1.6.11为例

首次启动，会出现登录界面：

上面一行为用户名（Mojang账户，通常是Email形式），下面一行是密码。输入完毕按Log In即可。

主界面如下所示

① 标签页选择。依次为：
  • Update Notes（更新信息）：获取自Tumblr的官方版本更新信息
  • Launcher Log（启动器日志）：显示启动器后台返回信息的相关内容，里面包含的信息对于mod开发者、整合包制作者、启动器作者等人等较为有用。
  • Profile Editor（配置编辑器）：对不同配置（Profile）的编辑以及查看。详见下文。
② 配置（Profile）选择，用于选择实现定义好的配置。还有新建配置(New Profile)与编辑配置(Edit Profile)的快捷键。
③ 那个大大的Play按钮，不用我多说吧……
  • 如果是Play Offline，说明你的网络连接不畅，或者是此时Mojang登录服务器挂了……此时也是可以玩的，只不过是离线模式，无法进入开启正版验证的服务器（是的，离线模式就是盗版的实现原理）
  • 如果是Play Demo，说明你尚未购买正版。
④ Switch User（切换用户），返回刚才的登录界面


下面集中解释一下Profile和Version的概念

Profile，可以理解为“配置”。每个Profile都能配置如下的信息。也就是说，Profile的概念更抽象，单个的Profile可以设置为使用自己的游戏目录、游戏文件、分辨率与java启动参数。
Version，“版本”，这个版本不同于一般理解的Minecraft版本，理解为“一套游戏文件”更合适。比如你给1.8装了forge，多出的一个1.8-forge11.14.1.1341也是一个“版本”。

下图的弹出窗口为Profile Editor（配置编辑器），Edit Profile（编辑配置）或是New Profile（新建配置）都会触发该窗口。大部分配置行之前都有复选框，如果不勾选这一行的复选框，那这一行对应的配置就是默认值。


① Profile Info（配置信息）
  • Profile Name（配置名称）：可以重命名配置，起一个你自己觉得好记，容易区分的就可以了
  • Game Directory（游戏目录）：即游戏文件目录
  • Resolution（分辨率）：游戏窗口的分辨率
  • Automatically ask Mojang for assistance with fixing crashes（自动请求Mojang参与协助修复崩溃）：会将你游戏崩溃的详细数据提交Mojang分析
  • Launcher Visibility（启动器可见性）：可选启动游戏后是Hide launcher and re-open when game closes（隐藏启动器并在游戏关闭后重现）、Close launcher when game starts（游戏启动后关闭启动器）还是Keep the launcher open（保持启动器开启）
②Version Selection（版本选择）
  • Enable experimental development versions（启用试验开发版本）：如果你要在这个Profile（配置）中体验快照版本，此选项必须启用
  • Allow use of old "Beta" Minecraft versions（允许使用Minecraft Beta老版本）：如果你要在这个Profile（配置）中体验2010-2011年的Beta系列版本，此选项必须启用
  • Allow use of old "Alpha" Minecraft versions（允许使用Minecraft Alpha老版本）：如果你要在这个Profile（配置）中体验2009-2010年的pre-Clasic、Classic、Indev、Infdev、Alpha系列版本，此选项必须启用
  • Use version（使用版本）：可以选择能够在线更新的所有原版Minecraft版本以及你当前电脑中存放的所有版本配置
Java Settings（Java选项，不建议电脑新手手动设置）
  • Executable（可执行程序）：Java运行环境核心Java.exe的位置，可手动指定
  • JVM Arguments（Java虚拟机参数）：可手动指定Java虚拟机参数，如内存分配等

选项卡中的Profile Editior可以一目了然地查看所有保存的配置以及对应的版本。这些版本都可以在.minecraft/versions文件夹下全部找到，也可以方便地自行修改。值得注意的是现在不少的Mod API或Mod都以安装器的形式公布，这些安装器能够自动修改原版jar，向.minecraft/versions文件夹写入新的“版本”并在官方启动器中添加新的配置（Profile）。一般此类自动配置的Profile不建议新手朋友们修改，直接运行就好。
