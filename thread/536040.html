我发这个帖子的原因:  别人的帖子 介绍指令少了几个 而我 现在发布最新版本+汉化
介绍:
这个插件允许玩家改变他们的聊天颜色不同的颜色，以及粗体，斜体等定期更新.


特征:







  • 更改服务器聊天的颜色!
  • 创建您想要的颜色和样式！现在支持四个修饰语，拓宽你的聊天定制!
  • 改变你的聊天为 蓝色 和 粗体字 或暗红色, 斜体 和 下划线! 你甚至可以只弄 斜体字,粗体字 , 下划线 和浅紫色!
  • 一个简单的命令，你可以用一个的点击与一个新的GUI更改颜色!
  • 改变大家的聊天，或者只是你自己!
  • 更改单个玩家的聊天颜色!
  • 让人们使用某些颜色!
  • 检查自己的聊天颜色，或检查别人!
  • 每一个功能都有权限，所以你可以给各位玩家希望他们有权限到底是什么!
  • 支持所有 Bukkit / Minecraft 的颜色代码, 包括 粗体字, 下划线, 和 其他人!
  • 彩色控制台消息 :) (这不是问题 :P )
  • 一个活跃的作者 - 我几乎总是在这里回答问题或添加新功能! <一 这个要去原帖和作者说



权限:
权限描述
chatcolor.use允许使用 仍需要其他权限.
chatcolor.change.self允许使用'/chatcolor <color>' 改变自己的聊天颜色.
chatcolor.change.others允许使用 '/chatcolor <player> <color>' 改变其他玩家的聊天颜色.
chatcolor.change.global允许使用 '/chatcolor global <color>' 改变每个在线玩家的聊天颜色.
chatcolor.change.modifiers允许使用可选的 [modifier] . 例如 '/chatcolor <color> [modifier]'
chatcolor.change.modifiers.multiple允许使用全部 [modifier] 更改自己的聊天颜色的修饰代码.
chatcolor.checkcolor.self允许使用 '/chatcolor check' 检查自己的聊天颜色.
chatcolor.checkcolor.others允许使用 '/chatcolor check <player>' 查看其他玩家的聊天颜色.
chatcolor.colors.<color>允许使用指定的颜色.
chatcolor.colors.*允许使用各种的颜色.
chatcolor.modifiers.<modifier>允许使用指定的修饰代码.
chatcolor.modifiers.*允许使用所有修饰代码.
chatcolor.checkupdates允许使用 '/chatcolor updates' 查看最新版本并更新.
chatcolor.gui允许使用 '/chatcolor gui' 通过GUI菜单来设置自己的聊天颜色.

命令:







  • 关键: <param> - Required Parameter. [param] - 可选参数请参下面的说明.








  • /chatcolor [player/global] <color> [modifier] [modifier] [modifier] [modifier] - 改变玩家聊天的颜色;其他玩家，或全局聊天颜色，四个可选的修饰符!
  • /chatcolor check [player] - 通知发送者的当前的聊天的颜色，或者其他玩家的聊天颜色.
  • /chatcolor updates - 更新插件.
  • /chatcolor gui - 打开颜色选择GUI菜单.








  • 注意: 使用 [modifier] 或 [player] 参数，以及GUI和更新日志，你必须有所需的权限，请参阅上述有关权限的详细信息.

说明:







  • [global] Optional Parameter: - 用于设置每个人的聊天颜色在服务器上.
  • [player] Optional Parameter: - 用于设定一个特定 玩家. [player] 的聊天颜色可通过一个玩家的名字被替换.
  • [modifier] Optional Parameter: - 用于添加到一种颜色，例如粗体（l），斜体（o）或有下划线（n）的
  • <color> Required Parameter: - 指定到相应的聊天秒设置为颜色.



Bukkit 颜色代码:
颜色代码:







  • a - 浅绿色
  • b - 浅蓝
  • c - 红
  • d - 浅紫
  • e - 浅黄
  • f - 白
  • 0 - 黑
  • 1 - 深蓝
  • 2 - 深绿
  • 3 - 青
  • 4 - 深红
  • 5 - 紫
  • 6 - 金
  • 7 - 灰
  • 8 - 深灰
  • 9 - 蓝

修饰代码:







  • k - 随机
  • l - 加粗
  • m - 删除线
  • n - 下划线
  • o - 斜体


命令实例:







  • /chatcolor a l m n o - 将改变你 聊天颜色为浅绿色、粗体、斜体、删除线和带下划线!  <一可以不用弄太多修饰代码
  • /chatcolor global c l - 将改变每个人的 聊天颜色 每个人都在服务器上红色粗体字!







  • 这些只是几个不同组合的!


权限实例:







  • chatcolor.colors.c - 允许使用 c 颜色代码.
  • chatcolor.modifiers.o - 允许使用 o 修饰代码.
