SimpleBoard
简单易用的计分板插件,就是这么简洁~
功能
1.实时显示服务器、玩家的数据
2.自定义格式,每一行你都可以自己设置
3.自动更新数据
4.拥有变量显示和PlaceholderAPI
5.支持颜色代码
6.支持多行显示
安装
1.[下载安装]下载插件本体后放入服务器plugins文件夹后重启即可
变量[更多变量请前往PlaceholderAPI帖子查看]
{player-name} - 玩家名称
{player-ping} - 玩家延迟
{online-amount} - 在线人数
配置
  1. title: '&b&lSimple&bBoard' #计分板标题
  2. PlaceholderAPI: false #是否开启PlaceholderAPI,建议开启,true开启,false关闭
  3. lines: #下面的内容可以自定义
  4. - '&m--------------'
  5. - '&bName:'
  6. - '{player-name}'
  7. - ' '
  8. - '&bPing:'
  9. - '{player-ping} ms'
  10. - ' '
  11. - '&bWebsite:'
  12. - '&fwww.google.com'
  13. - ' '
  14. - '&bOnline:'
  15. - '{online-amount}'
  16. - '&m--------------'
复制代码
命令
/sb - 显示主命令
权限
无
