插件名
BattleMusic

作者
LouShunt

兼容版本
1.12-1.15

介绍 · Intro
这款插件可以在你与怪物搏斗时响起战歌，使你充满抛瓦，使你觉得在你的BGM里没有人能够打得过你。你可以使用Minecraft原版的音效、资源包的音效或是MCJukebox插件的音乐，你还可以在配置内设置对抗不同类型的怪物响起不同的战歌。

指令 & 权限
Command & Permission
/battlemusicreload 或 /bmr - 重载配置 - battlemusic.reload


配置 · Config
  1. ignore-creative: true #创造模式的玩家是否可以听到战歌
  2. run-away-time: 15 #在结束战斗后多少秒停止播放战歌
  3. disable-music: #与这些生物战斗时不会响起战歌。在你杀鸡时不需要战歌！
  4.     - villager
  5.     - chicken
  6.     - cow
  7.     - squid
  8.     - sheep
  9.     - rabbit
  10.     - pig
  11.     - parrot
  12.     - ocelot
  13.     - bat
  14.     - horse

  16. mcjukebox:
  17.     fade-time: 3 #使用MCJukeBox的音乐时在结束战斗多久后停止播放战歌
  18.     channel: "default" #使用哪一个频道的音乐 ? 如果你不知道频道请保留默认配置
  19.     volume: 100 #音量 (最大 100)


  22. ignore-playervsplayer: false #是否不在玩家PVP时播放战歌

  24. default-battlesound:
  25.   - "https://audio.jukehost.co.uk/p/e1ed6c25e972c60066f8d81e2533b75cdf6261e7/2c55e818227" #音效地址，如果你使用Minecraft的音效则可以设置为custom.creeper

  27. mob:

如何使用 · How to use
资源包音效：
第一步你要做的就是这个音效能够正常播放，使用这个指令来测试：
  1. /playsound <音效名> block @p
复制代码
如果无误的话，下一步和你将音效放入sounds.json一样，示例配置：
  1. default-battlesound:
  2. - "custom.ohno"
复制代码
之后重载插件后你就能听见战歌了！
MCJukeBox
MCJukeBox是我最喜欢的插件之一，安装这款插件并正确配置插件。
如果你的MCJukeBox插件能够正常播放音乐，那么你就可以在配置内填入音乐地址。示例：
  1. default-battlesound:
  2. - "https://audio.jukehost.co.uk/p/e1ed6c25e972c60066f8d81e2533b75cdf6261e7/2c55e818227"
复制代码
之后重载插件后你就能听见战歌了！
Noteblock（红石音乐）
使用红石音乐的好处是玩家不需要下载任何资源包或打开浏览器来播放音乐，你只需要下载前置NoteBlockAPI并安装到你的服务器内，然后将音乐文件放入plugins/battlemusic/music内即可。你找不到红石音乐？看看这个帖子吧：
[娱乐]JukeBox——在Minecraft里播放nbs红石音乐|附100首红石音乐[1.11-1.14]

示例配置：
  1. default-battlesound:
  2. - "noteblock:All Star"
