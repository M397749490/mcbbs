TigerReport —— 优秀的GUI举报插件

简介
TigerReports是一个高度可配置且详细的插件，用于管理玩家报告。
它与一个简单的命令/report 一起工作，使用命令/report 即可举报玩家
他会记录举报信息在工作人员GUI（箱子界面）中
在GUI（箱子界面）中会显示的更多详细数据。

授权证明


特点
玩家可以通过冷却时间和最少数量的角色来举报在线和离线玩家（取决于配置）。
如果他们未指定任何原因，则将打开GUI（箱子界面）以选择默认（可配置）原因之一。
发送报告后，打开菜单的可点击消息会提醒在线的管理成员。

此菜单允许：
  • 1.传送到被举报者的当前和较旧位置（举报过程中）。
  • 2.如果该报告是带有配置时间冷却时间的滥用报告，则应予以惩罚（使用此惩罚时，需要在GUI中将该报告被标记为“false”）。
  • 3.查看更详细的数据，例如游戏模式，运行状况，效果以及举报的玩家等信息。
  • 4.将举报状态标记为：正在等待，进行中，重要或完成。
  • 5.存档举报（已从主菜单中删除，但保留在数据库中）。
  • 6.明确删除举报
  • 7.在报告上写下并查看管理人员的备注

安装&使用
TigerReports的安装如下的：
1.关闭服务器。
2.到作者的 Spigot 页面下载 TigerReports.jar 文件并将其放在服务器的 plugins 文件夹中。
3.启动您的服务器。就是这样，您现在可以在 /plugins/TigerReports 文件夹中编辑所需的所有内容，保存更改并通过使用 /reports reload 命令重新加载将更改应用到服务器上。
某些功能/消息需要重新启动服务器才能进行更新。

如果使用 MySQL 数据库，建议使用 phpMyAdmin 的 SQL 选项卡执行以下查询：
ALTER TABLE tigerreports_reports 转换为字符集 utf8mb4 ； ALTER TABLE tigerreports_comments转换为 CHARACTER SET utf8mb4，并在 config.yml 中配置了 MySQL 后重新启动服务器。

如果您是 BungeeCord 服务器：
您必须在每个 Spigot 服务器上的 config.yml 文件（在底部）中配置 MySQL 数据库连接，并使BungeeCord 选项保持启用状态。
（您不必将 TigerReports.jar 放在 BungeeCord 服务器的 plugins 文件夹中。只需要安装在子服内）

我建议您：
根据需要编辑 messages.yml 和 config.yml 文件。
在一台服务器上检查一切正常。
选择 TigerReports 文件夹（在服务器的plugins文件夹中），然后按住CTRL键并选择 TigerReports.jar。
现在，您可以复制两个文件并将它们粘贴到每个Spigot服务器上。

[skelecton]命令&权限
命令:
  • 举报指令 - /report
  • 查看GUI - /reports
  • 重载 - /reports reload
权限:
(默认无需给予)
这是所有可用权限的列表。
管理人员请给予tigerreports.staff.teleport 与 tigerreports.staff权限。
tigerreports.report        允许使用/report报告玩家（如果PermissionRequired在config.yml中被禁用，则不需要）。
tigerreports.report.exempt                   免疫举报。
tigerreports.staff                                   允许查看和处理报告。
tigerreports.staff.teleport                         允许传送到报告的参与者。
tigerreports.staff.archive                           允许存档报告。
tigerreports.staff.archive.auto           允许在处理报告时自动将其存档。
tigerreports.staff.delete                           允许删除报告。
tigerreports.staff.advanced                       允许管理执行 重要 和 完成 选项报告，并查看报告的高级数据。
tigerreports.staff.*                                   授予与报表处理相关的所有权限。
tigerreports.manage                           允许重新加载插件并更改玩家的统计信息。
tigerreports.*                                           授予所有权限。
