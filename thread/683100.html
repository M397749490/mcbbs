一、简介 Description
这款插件可以自定义盾牌, 很像SuperTrails一样的选择设定! 这款插件是一个国人制作的插件, 但是没有发布到MCBBS里.

二、功能 Features



    ·添加图形到你的盾牌里
    ·公开盾牌制作
    ·30个预设盾牌
    ·保存盾牌设置
    ·简易操作

六、图片 Image


六、权限 Permission
shield: 使用此插件
shield.add: 添加盾牌到自己的列表
shield.addtoPublic: 添加盾牌到公开列表
shield.editPublic: 编辑公开盾牌列表
shield.addtoPlayer: 将手中的盾牌添加到指定玩家的盾牌设置

七、指令 Command
/shield - 打开自定义盾牌菜单 [拿着盾牌使用指令进行设置]
/shield add: 将手中的盾牌添加到自己的盾牌设置
/shield add <玩家>: 将手中的盾牌添加到指定玩家的盾牌设置
/shield addtoPublic: 将手中的盾牌添加到公开盾牌列表
/shield reload: 重载公开盾牌列表
/shield save: 保存公开盾牌列表
/shield reloadConfig: 重载插件
