事实证明，Linux作为服务器更好。但是官方那个有点问题，于是我今天优化一下（Thinker服就是这么干的）

如何在VPS上配置Minecraft

本文将以CentOS系统为例，实际上Debian以及Ubuntu用户基本也不会遇到什么问题，因为Minecraft这款游戏实际上是基于Java平台的（还记得Java的高度可移植性吗？）

1）使用Putty或其他SSH管理软件登录VPS控制端（这步是废话~）

2）安装Java（JDK），貌似JRE（Java runtime environment）也可以

CentOS下

yum install java-1.6.0-openjdk  （回帖反应有其他版本）

Debian下

sudo apt-get install python-software-propertiessudo add-apt-repository ppa:ferramroberto/javasudo apt-get updatesudo apt-get install sun-java6-jdk看看Java版本？请用java -version命令

3）下载Minecraft

mkdir /home/Minecraftcd /home/Minecraft
wget <此处为服务器Jar下载地址>以水桶1.5.1 BEta为例wget http://cbukk.it/craftbukkit-beta.jar
等他下载完成  

安装个Screen吧（让你不用一直连接服务器）

CentOS下

yum install screen

Debian下

apt-get install screen

配置Minecraft

命令中的Xmx和Xms后面的数字分别代表最大和最小占用内存的量，具体的按照大家VPS的实际情况调节吧，我见有人用512M的也可以，再小估计用户一多就吃力鸟~）

vi ok.sh然后输入 java -Xmx1024M -Xms1024M -jar minecraft_server.jar   感谢aa210063654
esc+wq回车 保存

输入：screen -S minecraft 回车
然后sh ./ok.sh
然后游戏开始啦！IP：25565开玩！（记得把盗版那个在线验证改了！）
