RuleEditor
用物品GUI的方式快速对某个世界规则（gamerule）进行修改
支持版本： 1.13 - 1.16.4
构建环境：java 8、spigot 1.16.4
GUI的操作方式
SHIFT + 鼠标左键（SHIFT+LEFT）： 切换布尔值(boolean)或增加整数值(integer)（+1）  
SHIFT + 鼠标右键（SHIFT+RIGHT）： 不影响布尔值(boolean)，减少整数值(integer)（-1）  
鼠标中间（MIDDLE）： 关闭GUI并启动自定义值会话，聊天框设置指定值（15秒内输入）  
Q键（丢出物品）： 恢复值为默认值  
GUI物品信息可根据规则自定义

命令
  1. 命令插入到原版的命令中，权限依赖于原版权限
  2. /gamerule editor 打开编辑当前世界规则的GUI
  3. /gamerule editor reload 重新加载配置文件
  4. /gamerule editor disable (v1.1) 卸载本插件，只能被非玩家执行
  5. /gamerule editor help 显示命令和GUI操作方式
  6. /gamerule editor [world] 打开编辑指定世界规则的GUI，[world] 为世界名称

更新
v1.1
  • 新增配置文件属性 rules-timeout 变更使用 中键 自定义数值时的等待时间，默认15秒
  • 新增配置文件属性 rules-show-all 是否显示未配置的规则，可自定义物品
  • 新增配置文件属性 rules-out-item 未配置规则的物品
  • 新增命令 /gamerule editor disable 卸载本插件，卸载后未退出的玩家仍然持有命令提示，但没有命令执行
    *只能非玩家执行
  • 修复使用命令重载配置时，没有配置文件时不会重新生成配置文件
  • 修复如果玩家不在所编辑的地图时，无法正确移除GUI数据
  • 修复未配置（有效）的规则会读取默认配置显示
  • 补全2个 1.16.4 规则配置
