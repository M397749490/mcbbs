游戏规则：
对战双方分为两个阵营 ( 红、绿 )
双方阵营都有一个阵营主塔
当阵营內阵营核心被破坏则会扣除阵营生命值
注意，阵营塔内会被切换成冒险模式，也就是说无法在此地区建筑
阵营內两个阵营的领土、矿物分布皆相同
游戏中可以采集各种资源来生存
可以砍木、挖矿提升战斗力
或是盖城墙防止敌人偷袭入侵


在地图內的矿物每过一段时间会自动再生！（铁、金、红石10s，绿宝石15s，青金石60s）
可以挖掘矿物做成更好的装备或附魔


战争阶段 :
战争总共分为五个阶段
第一阶段(10分钟):核心无敌保护 采集物资准备
第二阶段(10分钟):核心保护失效 交易所开放
第三阶段(10分钟):开始出现随机任务系统
第四阶段(10分钟):矿物获取量增加 死亡扣阵营生命值
第五阶段(10分钟):核心被破坏时受双倍伤害


召集令使用 :

侦查兵召集令 : (10 绿宝石)
在我方阵营塔上召唤出一只侦查兵，
敌人跨越领土时会私密通知我方这样。
侦查兵死亡時失效。

天眼兵召集令 :  (50 绿宝石)
在我方这样塔上召唤出一只天眼兵，
给予敌人发光效果，随时标示敌人位置(包含隐形)。
天眼兵死亡时失效。


盜贼召集令 :  (30 绿宝石)
随机清空一位敌人身上的物品

矿物封锁令 :  (25 绿宝石)
敌方的矿物将会变成基岩90秒无法再获取更多资源

阵营无敌令 :  (30 绿宝石)
我方的核心将会无敌60秒，不能被破坏


其他资讯 :  
【经验泉】

阵营內的小水池出水口，会不断涌出经验

就算堵住出水口 还是会冒出经验

【附魔台】

在阵营塔旁边有个小洞，会有附魔台可以使用
注意 : 附魔台是可以被破坏的！
