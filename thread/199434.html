插件指令和权限：
PVP插件：
  • /tpvp [player name] 开启指定玩家的PVP
  • /pvp 打开自己的PVP
  • /fpvp [player name or * or all] 强制开启指定玩家或所有人的PVP
  • /pvp toggles pvp on self (by request)
  • /tpvp [player name] will toggle the player's PvP (on -> off, off -> on)调整别人的PVP模式
  • /fpvp [player name] will toggle the player's PvP and not allow them to turn it off until you use the command on them again.
  • /fpvp * (or all) will toggle EVERYONE's PvP and not allow them to turn it off until you use /fpvp *off (or alloff).
  • /fpvp *off (or alloff) will remove the force toggle. It will not turn their PvP off, but will let them turn it off manually.关闭强制PVP
  • /bloodmoonpvp, /bmpvp enables Bloodmoon PvP mode.血月PVP

权限：
  • pvpswitch - /tpvp
  • none -/pvp This command acts as a replacement for manually clicking the swords to enable PvP... Done on request
  • pvpforce -/fpvp
  • pvpbmoon -/bmpvp

锁箱子插件：
        输入指令后右击箱子生效
  • /ccset - Cancels selecting a chest to protect/refill/etc.取消选择箱子保护/填充/等。
  • /cinfo - Shows info on a chest when opened.箱子信息
  • /clock <password> - Locks a chest using the password. Use "remove" as the password to remove it.用密码锁箱子
  • /convchests - Converts all currently existing chests to use the new database format. USE THIS AS SOON AS YOU START A WORLD. ONLY USE THIS ONCE!安装后用一次这个！
  • /cpset - Toggles the publicity of a chest.转换公共状态
  • /crefill [<time>] - Toggles a chest's refill status, adds a refill delay if applicable.无限填充箱子
  • /crset - Toggles a chest's region share status.区域分享状态
  • /cset - Protects a chest when opened.保护箱子，锁箱子（超管放置的箱子是自动上锁的）
  • /cunlock - Unlocks a chest using the password.密码开锁
  • /cunset - Un-protects a chest when opened.解除保护

权限：
  • infchests.admin.convert - Allows /convchests.
  • infchests.admin.editall - Allows editing any chests.
  • infchests.admin.info - Allows /cinfo.
  • infchests.admin.refill - Allows /crefill.
  • infchests.chest.deselect - Allows /ccset.
  • infchests.chest.lock - Allows /clock.
  • infchests.chest.public - Allows /cpset.
  • infchests.chest.region - Allows /crset.
  • infchests.chest.protect - Allows /cset.
  • infchests.chest.unlock - Allows /cunlock.
  • infchests.chest.unprotect - Allows /cunset.

WE创世神插件：
  • //all - Selects the entire world.选择整个世界
  • //biome <biome1> <biome2> - Converts all of the tiles in the selection that correspond to the first biome to the tiles that correspond with the second biome.生态环境
  • //contract <amount> <direction> - Contracts the selection.
  • //copy - Copies the selection to the clipboard.
  • //cut - Cuts the selection into the clipboard.剪切
  • //drain [radius] - Drains liquids from the selection or in a radius around you.抽干液体
  • //expand <amount> <direction> - Expands the selection.
  • //fixgrass [radius] - Fixes suffocated grass in the selection or in a radius around you.
  • //fixhalves [radius] - Fixes covered half blocks in the selection or in a radius around you.
  • //fixslopes [radius] - Fixes covered slopes in the selection or in a radius around you.
  • //flip <direction> - Flips the contents of the clipboard. <direction> can contain any amount of X's and Y's; each occurrence will flip the direction. E.g., XXYY would leave the clipboard unchanged.
  • //flood <liquid> <radius> - Floods the nearby area with lava, honey, or water.填充液体
  • //inset <amount> - Contracts the selection in every direction.
  • //mow [radius] - Mows grass, thorns, and vines in the selection or in a radius around you.
  • //outset <amount> - Expands the selection in every direction.
  • //paint <color> [where conditions...] - Paints all of the tiles in the selection. You can use "blank" to remove paint.油漆
  • //paintwall <color> [where conditions...] - Paints all of the walls in the selection. You can use "blank" to remove paint.漆墙
  • //paste [alignment] - Pastes the clipboard to the first point. The alignment specifies the paste "direction" -- it can be l, r, t, b, or a combination of those letters. For example,//paste rb would paste as if the first point were the right-bottom.
  • //point <1|2> - Sets the points of the selection.选择区域
  • //point1 <x> <y> - Sets the first point of the selection.选择区域点1的坐标
  • //point2 <x> <y> - Sets the second point of the selection.选择区域点2的坐标
  • //redo [account] <steps> - Redoes that many actions for the account, if possible.
  • //region [name] OR //region [x] [y] - Selects a region to perform actions on.
  • //rotate <degrees> - Rotates the clipboard's contents by the specified angle, in degrees. Only multiples of 90 are accepted.
  • //schematic - Schematic commands:
    • //schematic delete <name> - Deletes the specified schematic if possible.
    • //schematic help - Lists all schematic commands.
    • //schematic list - Lists the available schematics.
    • //schematic load <name> - Loads the specified schematic to the clipboard if it exists.
    • //schematic save <name> - Saves the contents of the clipboard to the specified schematic.
  • //select <selection type> - Sets the way that tiles are selected. Valid arguments include: altcheckers, checkers, ellipse, normal, and outline.
  • //set <tile> [where conditions...] - Sets all of the tiles in the selection to <tile>.把区域填充物块
  • //setwall <wall> [where conditions...]- Sets all of the walls in the selection to <wall>.填充墙壁
  • //setwire <wire 1 state> <wire 2 state> <wire 3 state> [where conditions...] - Sets all of the wire states in the section.放电线
  • //shift <amount> <direction> - Moves the position of the selection.
  • //size - Prints the dimensions of the selection.
  • //undo [account] <steps> - Undoes that many actions for the account, if possible.

  复制区域：先框区域，然后输入//copy,到复制目的地的左上角//point 1然后//paste 复制后牌子和箱子不可读
