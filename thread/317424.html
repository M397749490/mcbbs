接下来，就是烦人但是必须有的projectiles配置！！！当当当！！！
要先在“item”里面加一个“projectiles”文件夹
就是武器的特效，如果你不知道请仔细看贴
这个文件夹里面要有5个文件（为一个武器做特效）
别怕♂慢慢来
首先做
  1. 【特效名称】.frames
复制代码
  1. 【特效名称】.frames.bak
复制代码
第二个应该是备份用的
我们先看第一个的内容：
  1. {
  2.   "frameGrid" : {
  3.     "size【大小】" : [106, 126],
  4.     "dimensions【帧数】" : [3, 1],

  6.     "names" : [
  7.       [ 【"0" ,"1" , ......(这个是帧的顺序） ]
  8.     ]
  9.   }
  10. }
复制代码
第二个跟第一个应该是一样的，可很多MOD在“size”上（纵坐标）比第一个小
接下来就是：
  1. 【特效名称】.projectile
复制代码
代码有点长：
  1. {
  2.   "projectileName" : "【特效名称】",
  3.   "frames" : "【特效图片】.png",
  4.   "animationCycle" : 【【特效图片】.png里面的图片数/10】,
  5.   "frameNumber" : 【同上,只不过不用/10】,
  6.   "damageKindImage" : "【特效小图标，还不清楚在哪里用得上】",
  7.   "level" : 【等级】,
  8.   "speed" : 【速度，填0】,
  9.   "orientationLocked" : 【特效动画是否固定在一个地方，布尔值】,
  10.   "damagePoly" : [[-28, 24.5], [7.5, 24.5], [22.5, 21.5], [38.5, 15.5], [48.5, 7.5], [53.5, -1.5], [53.5, -12.5], [43.5, -24.5], [-28, -24.5] 【一堆坐标，我给的是默认的】],
