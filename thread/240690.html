  关服状态下   进入路径/plugins/GroupManager/worlds/世界名/groups.yml,右键编辑它  找到代码
  1. groups:
  2.   Default:
  3.     default: true
复制代码
改为
  1. groups:
  2.   Default:
  3.     default: false
复制代码
接着再找到代码
  1.   Builder:
  2.     default: false
复制代码
改为
  1.   Builder:
  2.     default: true
复制代码
之后保存并重启服务器即可，每个世界都如此更改即可。
