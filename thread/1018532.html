Bukkit插件的加载机制是在服务器启动时，使用JavaPluginLoader加载插件的类，可以写个插件获取这个插件对应的JavaPluginLoader，这一类中提供了close方法，会关闭掉一直被占用着的jar文件流。

实例一：自己做的插件，插件被加载后可以允许用户删掉该插件的jar文件。


@Override

        public void onEnable() {

                Bukkit.getPluginManager().registerEvents(this, this);

                PluginClassLoader classLoader = ((PluginClassLoader)this.getClassLoader());

                try {

                        classLoader.close();

                } catch (Exception e) {

                        // TODO Auto-generated catch block

                        e.printStackTrace();

                }

        }

实例二：卸载其他插件，并让其他插件再被卸载后jar文件不被占用。


private void removePlugin(String pluginName) {

                JavaPlugin pluginBase = (JavaPlugin)Bukkit.getPluginManager().getPlugin(pluginName);

                Bukkit.getPluginManager().disablePlugin(pluginBase);



                try {

            PluginClassLoader classLoader = (PluginClassLoader) pluginBase.getClass().getClassLoader();

            classLoader.close();

                        System.out.println("Success to disable plugin: "+pluginName);

                }catch(Exception e) {

                        System.out.println("Failed to disable plugin: "+pluginName);

                        e.printStackTrace();

                }

        }



这里做了一个实例插件 PluginQuickRemover，使用指令/disableplugin 插件名 或 /rp 插件名 即可卸载插件（插件名区分大小写）。
