作者: jued_huangjim    时间: 2019-7-19 15:24
对于这个问题，你可以选择下载js变量
/papi ecloud download JavaScript
重载之后会多出一个 javascript_placeholders.yml 和 javascripts 文件
然后在javascripts里面新建一个txt，然后后缀改成.js
然后用文本方式打开这个js文件
写入
var Marriage = "%marriage_gender%";

function Male() {

   if (Marriage == "male") {
       return "男";
   }

   else {
       return "";
   }
}
Male();

保存时记得ANSI编码，要不然乱码

然后打开javascript_placeholders.yml文件
里面写入
MarriageFemale:
  file: MarriageFemale.js
  engine: nashorn

MarriageFemale:就是变量名
如%javascript_MarriageFemale%
file: MarriageFemale.js 是新建的js名

然后按照这操作连续3次，
同时聊天上写入js的3个变量
然后变量输入Male的时候，2个显示是完全没字符，只有男 变量显示的男
