显现盔甲架
1.12以下：
  1. entitydata @e[type=armor_stand] {Invisible:0b}
复制代码

1.14以上:
  1. execute as @e[type=armor_stand] run data modify entity @s Invisible set value 0b
复制代码

1.12以下清除距离在5格之内的盔甲架：
  1. kill @e[type=armor_stand,rm=5]
复制代码

1.14以上清除最近的盔甲架：
  1. kill @e[type=armor_stand,limit=1,sort=nearest]
复制代码
