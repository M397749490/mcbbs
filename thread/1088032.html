Valkyrie 一个面向中文社区的 Bukkit / Spigot 插件开发教程


Valkyrie 是什么

简单来讲，Valkyrie 就是一本尽量降低门槛的 Bukkit / Spigot 插件开发教程，现在仍然处于开发阶段，Valkyrie 尽量简化了非常难以理解的内容，并且低基础的 Mcer 也能看得懂，Valkyrie 包含了 IntelliJ IDEA 的简单使用方式、Java 基础内容、插件入门内容、插件进阶内容以及数据库工具等实用内容，但由于文本量较多，Valkyrie 现已托管在 Github 代码仓库，以 Docsify 作为写作框架，并以 CC-BY-NC-SA 4.0 进行开源


在哪里可以查阅 Valkyrie

你可以前往代码仓库 https://github.com/ElaBosak233/Valkyrie.git 再点击右侧的链接进入 Valkyrie，或者你可以直接使用 https://valkyrie.ela.ac.cn 进行查阅，当然，别忘了给仓库一颗 star ⭐，感谢你选择 Valkyrie，我很希望你能将阅读文档后的感受反馈给 @ElaBosak，如果文档中有难以解决的问题，也可以直接在本页面下评论，或者你可能遇到文档有错误的地方，那么我更加希望你能在仓库的 issues 中反馈一下，这样更有利于我改正文档中的错误，谢谢~
注：由于 Ela 本人有繁忙的学业在身，以及 Valkyrie 刚发布的时候经常出现误导新手的状况（现大部分已修复），Valkyrie 将暂时暂停更新，等待下一次机会再进行公开宣传

  6.    ...> e.printStackTrace();
  7.    ...> }

  9. |  已捕获到异常错误java.io.IOException
