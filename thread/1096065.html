列表操作工具
By vcs
此原版模组主要用于对于列表的操作，可用的操作方式见下表
函数名输入对象输出对象表达
list_tool:getNBT路径：Item.tag.input[list_input]聊天框将Item.tag.input第list_input项输出到聊天框
list_tool:setNBT路径：Item.tag.input[list_input]NBT路径：Item.tag.result将Item.tag.input第list_input项输出Item.tag.result
list_tool:insertNBT路径：Item.tag.resultNBT路径：Item.tag.result将Item.tag.result插入到Item.tag.input第list_input项并输出到Item.tag.result，Item.tag.input不变
list_tool:removeNBT路径：Item.tag.input[list_input]NBT路径：Item.tag.result将Item.tag.input第list_input项删除并将删除后的表输出到Item.tag.result，Item.tag.input不变
list_tool:changeNBT路径：Item.tag.inputNBT路径：Item.tag.result[list_input]将Item.tag.result第list_input项替换为Item.tag.input

记分板对象：你将要操作其Item.tag.input路径的实体（必须有此路径且有效）
记分板目标：list_input

注意：你在单次操作中，仅仅只能在记分板对象中的实体这一个实体中进行输入和输出的操作，如需对其它实体操作，请自行研究方法
示例：
      这个世界的某个已加载区块有一掉落物且仅有此掉落物其Item.tag的值为{input:[1,2,3,4,5,6],result:{}}，在游戏中按以下步骤输入命令
  1. #输入项数
  2. execute as [url=home.php?mod=space&uid=1702895]@e[type=item][/url] run scoreboard players set @s list_input 1
  3. #输出Item.tag.input第list_input项内容到Item.tag.result
  4. execute as @e[type=item] run function list_tool:set
  5. #完成后，让我们data get一下
  6. data get entity @e[type=item,limit=1] Item.tag.result
  7. #此时，聊天框会显示2
  8. #继续操作，输入项数
  9. execute as @e[type=item] run scoreboard players set @s list_input -8
  10. #将Item.tag.result输出到Item.tag.input第list_input项
  11. execute as @e[type=item] run function list_tool:insert
  12. #完成后，让我们data get一下
  13. data get entity @e[type=item,limit=1] Item.tag.result
  14. #此时，聊天框会显示[1,2,3,4,5,2,6]，可以看到原先的result中的2已经跑到该列表倒数第二个（5）的后面
  15. #同理，其操作方式几乎等同于原版手动输入命令，但是取消了硬编码的限制

在某些计算机语言中有这样操作列表的语法，假如定义了一个变量叫做a，值为0，一个列表为α，内容为[1,2,3]那么α[a]就得的输出结果就是1，效果等同于α[0]，但是由于a是变量，我们可以做计算，于是我们便可以根据特定的（比如随机数）数字来获取表中第a项内容，而我的世界原本是不支持这种操作的，所以制作了这个数据包，虽然这类工具制作很简单，但为了方便大家快速制作可导入该数据包（里面除了数据包信息外没有包含声明作者的东西），我是该数据包的作者，发布的账号是工坊账号（楼主）
