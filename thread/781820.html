标题: 关于groupmanager权限组插件
怎么让一个世界继承主世界的权限，就是使用同一个groups.yml文件

作者: Luckily_Baby    时间: 2018-2-14 16:04
在Groupmanager/config.yml中找到并修改：
mirrors:
   world：
    world_nether:
           - users
           - groups
       world_the_end:
           - users
           - groups
       XXX：（你新创建的世界的文件夹名字）
          -users  （使用world的玩家组数据，但是不使用group.yml）
添加完世界后，
使用/manload
在Groupmanager/worlds文件夹下会生成你刚才所添加的世界的配置文件夹
在XXX文件夹下，将group.yml文件替换成world文件夹下的Groupmanger/worlds/world/group.yml
作者: 一条鱼乾    时间: 2018-2-14 16:35
mirrors:
        # 多世界设置,世界列表中子世界将参照父世界的设置.
        # 第一个世界 'world' 是主世界名称
        # 子世界 'world_nether' 和 'world_the_end' 将会
        # 与父世界使用相同的玩家/用户组文件.
        # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
        # all_unnamed_worlds将会使用所有未定义的世界
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
