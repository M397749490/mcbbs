——第0章

资源准备

前言：
本教程的前提是你已经有一定的C#基础，并且会使用Visual Studio 2015或以上版本，本教程将会用Visual Studio 2019进行演示，也就意味着不支持xp用户
重要的内容：
其实你不会C#也没关系，本帖的代码也是比较详细的

需要的所有程序或库（最后这些库都将嵌入到你的程序中）：

1. Newtonsoft.Json.dll

-解析JSON

2. 7z.exe & 7z.dll

-解压natives

3. 任何网络库（可选）

-正版登录

4. 安装.NET FrameWork4.6.1 SDK 的 Visual Studio

C#编程你想不用.NET？

5. 一台不会启动Visual Studio就蓝屏的安装 Java JDK 或者 JRE 的计算机

MC不用Java？怎么可能

附：
newtonsoft.json.dll的下载地址：
https://edgw.github.io/CMCL/Newtonsoft.Json.dll

如果你的启动器允许半途弹出一个命令窗口来解压natives文件的话，你可以把7z.exe&7z.dll 替换为 7za.exe
