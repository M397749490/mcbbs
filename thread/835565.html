这是我做的第四个MOD了(全部都是服务端专用233)

注意：现已与我一个未发布的MOD合并，不在更新

网盘2个文件:
mires-source.zip -> 1.3.8的源码
[ 领地 ]MIResidence - r1.3.8.jar -> 1.3.8版的模组


领地mod
实现领地插件的部分功能
支持权限控制和trust等
提供了一个没有合成的"位置选择工具"(可以用MT加或者/give送等)

提取码: gab9

图片:




指令:
/mires:
  1. /mires create <name> 创建
  2. /mires delete <name> [confirm] 删除
  3. /mires list [p  a  g  e] 列出自己的领地
  4. /mires info [name] 显示当前领地数据
  5. /mires trust/untrust [name] <playerName> 信任/取消
  6. /mires send <name> <playerName> 赠送领地
  7. /mires op <name> <权限名> [值] 管理权限
  8. 可用权限:

  10. Break=破坏
  11. Place=放置
  12. Interact=交互
  13. Use=使用(右键)
  14. Container=打开容器 *还有BUG
  15. Pickup=捡起物品
  16. Bucket=使用桶
  17. Attack=攻击
  18. Move=移动
  19. Teleport=传送 *未实现
  20. Water=无限水
  21. Flow=液体流动 *未实现
  22. Animal=动物生成
  23. Monster=怪物生成
  24. Explode=爆炸

  26. 值true/false
复制代码

/mires_admin (权限等级:3)
  1. /mires_admin create <name> 无视限制的创建和删除
  2. /mires_admin delete <name> [confirm]
  3. /mires_admin listAll <page> 列出所有领地
  4. /mires_admin setOwner <name> <playerName> 更改所有者
  5. /mires_admin info <name> 不管是不是你的领地都可以查看信息
复制代码


/mires_storage (权限等级:4)
  1. /mires_save
  2. 立即保存 * 默认1000tick自动保存一次
复制代码

配置文件:
  1. maxBlockCount 每个领地允许的最大方块个数 默认25600
  2. maxResCount 每个玩家允许拥有的最大领地个数 默认3
  3. moveCheckInterval 移动检查间隔(tick) 默认15
复制代码
