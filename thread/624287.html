例如在 0 60 0 处有一个投掷器。按钮连接命令方块们：
  1. testforblock 0 60 0 dropper 0 {Items:[{Slot:0b,id:leather_helmet,Damage:0s},{Slot:1b,id:leather_chestplate,Damage:0s},{Slot:3b,id:leather_leggings,Damage:0s},{Slot:4b,id:leather_boots,Damage:0s}]}
复制代码
至于无序，那就只能把所有可能的有序配方全部输入到命令中，让它们都来检测。


其实无序最好用探测地面上的物品，而不是容器来合成。当然也可以用村民交易。
