·前置
mod版本1.6.x往后需要 Fabric API version 0.3.1
mod版本1.8.0-1.13.1需要Vanilla Hammers
mod版本1.11.0-1.13.1需要Vanilla Excavators
注：目前mod版本为1.14.1以上，所以新版本不需要前置。

Tool Builder可以让玩家使用不同的材料制作工具。

★ 所有工具特点 Each tool
  • 在原版工作台制作。
  • 工具数值随着材料的变化而变化。
  • 对应原版的用途。

★ 新增加的工具 New tool types
  • 锤子：可以当做武器的稿子变种。
  • 小刀：攻击速度快的武器。
  • 大剑：攻击速度慢，伤害高的武器。

★ 材料影响的属性 Impacted ways
  • 耐久度。
  • 可附魔性。

★ 支持的工具 Supported tools
  • 斧子
  • 锤子
  • 锄头
  • 小刀
  • 稿子
  • 铲子
  • 剑
  • 大剑
  • 弓
  • 剪刀

★ 可用于工具身的材料 Materials for the head
  • 木头
  • 石头
  • 铁
  • 金
  • 钻石
  • 钢
  • 铜
  • 银
  • 铅
  • 黑曜石
  • 钴
  • 铝
  • 地狱砖
  • 钨

★ 可用于工具柄的材料  Materials for the handle
  • 木头
  • 金
  • 石头
  • 骨头
  • 钻石
注：你可以在手柄上添加皮革来增快工具的挖掘速度/攻击速度。
