minecraft-launcher 启动模块

  

  介绍
1. Native解压支持
2. 快速启动MC (首次启动: ~300ms 二次启动: ~60ms)
3. 支持最新启动协议 (MC版本 >= 17w43a)
4. 缺少库提示
5. 命令行支持
6. 支持TypeScript
7. 基于Nodejs

  使用方式
安装模块:
  1. $ npm install --save minecraft-launcher
复制代码
快速启动:
  1. import MCLauncher from 'minecraft-launcher'

  3. const core = new MCLauncher()
  4. core.launch('1.12.0')
复制代码
监听器及更多配置请前往项目地址查看

  1. core.launch({
  2.   version: '1.10.2', // 需要启动的版本名
  3.   // 以下均为可选参数
  4.   authenticator: MCLauncher.offline('Steve'), // 离线登录
  5.   authenticator: MCLauncher.yggdrasil('10000@qq.com', '123456'), // 正版登陆
  6.   authenticator: { displayName: '游戏名', uuid: 'UUID' },
  7.   versionType: 'minecraft-launcher', // MC主界面游戏版本右边的文字
  8.   maxMemory: 1024, // 最大内存
  9.   minMemory: 512, // 最小内存
  10.   server: { // 自动连接的服务器
  11.     address: 'www.360.cn', // 服务器IP
  12.     port: 25565 // 服务器端口，默认25565
  13.   },
  14.   size: { // 游戏窗口大小
  15.     fullScreen: true, // 全屏，可选
  16.     height: 768, // 宽
  17.     width: 1280 // 高
  18.   },
  19.   launcherName: 'MCLauncher', // 启动器名
  20.   launcherVersion: '3.1.0', // 启动器版本
  21.   advencedArguments: [], // Java虚拟机参数
  22.   cgcEnabled: true, // 开启GC，默认/推荐开启
  23.   agentPath: 'agent.jar', // Java代理
  24.   features: { // 开启的特殊参数
  25.     is_demo_user: true
  26.   }
  27. })
复制代码

  命令行
全局安装模块:
  1. $ npm install -g minecraft-launcher
复制代码
快速启动游戏:
  1. $ mclauncher 1.12.0
复制代码
全部命令:
  1.   $ mclauncher -h

  3.   Usage: mclauncher <游戏版本> [参数]

  5.   Options:

  7.     -h, --help            显示相关帮助，即当前界面
  8.     -V, --version         显示当前安装的minecraft-launcher版本
  9.     -r, --root            游戏根目录
  10.     -u, --username <str>  你的游戏名
  11.     -p, --password <str>  你的正版密码
  12.     -e, --email <str>     你的正版邮箱
  13.     -m, --memory <int>    游戏最大内存
  14.     -s, --save            保存游戏账户信息
  15.     -c, --clean           清除游戏账户信息
  16.     -j, --java <str>      JAVA路径
  17.     -a, --address <str>   游戏进入后自动进入的服务器IP
  18.     -o, --port <int>      游戏进入后自动进入的服务器端口
  19.     -f, --full            全屏游戏
  20.     -l, --log             不显示log
