1.4.0版本之后就改成essential.要给命令权限的命令全称
现在有八种类型的牌子
[Gamemode] 改变游戏模式
[Free] 免费牌子
[Disposal] 辣鸡桶
[Time] 改时间
[Heal] 治疗牌子
[Weather] 改天气
[Buy] 购买牌子
[Sell] 出售牌子
只需在第一行写上就行了

配置文件config的汉化
请勿复制，仅供参考

  1. # 输入clearchat时连续“刷屏”多少行（默认75行）
  2. Clear-Chat-Lines: 75
  3. # 在这里输入玩家不能使用的命令.
  4. Blocked-commands: [op, version]
  5. # 玩家进入监狱时不能使用的命令
  6. Jail-Blocked-Commands:
  7. - spawn
  8. - warp
  9. - home
  10. - tp
  11. # 自动公告的时间（单位为秒），如果要禁用该功能，请改为0
  12. Auto-Message-Time: 60
  13. # 自动公告信息
  14. Auto-Messages:
  15. - "&6Hope you enjoy this server!"
  16. - "&cThis is an auto message"
  17. - "&6If you enjoy the plugin you can find it here:\n&chttps://www.spigotmc.org/resources/betterssentials-1-8-1-13.58074/"
  18. # 这些是自定义的加入/离开时的消息，输入"none"即为禁用
  19. Join-Message: "&4%player% &6entered the server."
  20. Leave-Message: "&4%player% &6left the server."
  21. # 是否启用聊天格式
  22. Chat-Format-Enable: true
  23. # 聊天格式：
  24. # %prefix% 为前缀
  25. # %player% 玩家名字
  26. # %suffix% 为后缀
  27. # %message% 为发出的信息
  28. # 支持 Placeholder 变量
  29. Chat-Format: "<%prefix% %player% %suffix%> %message%"
  30. # OP的名字应该是什么颜色的
  31. # 按照Minecraft颜色表来
  32. Op-Color: "4"
  33. # 礼包是否应该拥有自定义权限，譬如某礼包叫做nmsl，然后要给的权限是betterssential.kit.nmsl
  34. # Per-Kit-Permissions: false(为true的话就开启上述描写的信息)
  35. # 金钱符号应该是什么
  36. Money-Sign: "[        DISCUZ_CODE_1        ]quot;
  37. Per-Kit-Permissions: false
  38. # 玩家第一次加入时的信息，设置为none即为不启用
  39. First-Join-Message: "&4%player% &6joined for the first time!"
  40. # 玩家第一次加入时执行的命令
  41. First-Join-Commands:
  42. - "say &6Everyone welcome them!"
  43. # 哪些命令有冷却时间
  44. Cooldown-Commands:
  45. - kick
  46. - ban
  47. # 冷却时长
  48. Cooldown-Time: 5
  49. # 传送命令的冷却时长
  50. Cooldown-Move-Time: 3
  51. # 本插件应该是用哪些语言
  52. # 已支持的语言：en（英文），ro，es，pl，fr，de，ru，zh
