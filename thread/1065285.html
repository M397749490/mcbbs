占用确实不高, 只是 Windows 在你内存充裕情况下, 会把缓存存储到内存中, 服务器真正占用其实只有 50%。所以你可以无视。
如何克服这个障碍呢? 你可以试用一下Linux, 分分钟 buff/cache 把你内存吃满
尤其是对于高版本来说, 占用内存是很大的, 如果在你内存充裕(非群组/不在服务器用Chrome) 的情况下这也许不是一件坏事, 可以让玩家的体验更好。频繁的GC/减少区块加载到内存是要以CPU和频繁的硬盘读写为代价的。

如果还是想优化内存可以照着下面的方法做:
1. 视距调小到 4-6
2. clearlag:
ram-meter:

  enabled: true

  interval: 20

  ram-limit: 3000

  commands:

    - 'lagg killmobs'

    - 'lagg clear'

    - 'lagg gc'

3. bukkit.yml
chunk-gc:

  period-in-ticks: 300

4. paper.yml
# 会让出生点区块不再常驻

keep-spawn-loaded: false

5. 使用 openj9(兼容性会差)
6. 即使不把它当作正常清理插件用, 我依旧推荐安装 Laggremover, 它可以智能优化内存/网络等性能, 对低内存优化还是可以
