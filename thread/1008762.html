监听合成事件 然后 获取合成出来的拔刀剑 弄成ItemStack 然后转
net.minecraft.server.v1_12_R1.ItemStack CraftItem = CraftItemStack.asNMSCopy(Item);
int Killer = CraftItem.getTag().getInt("Killer"); (Killer我不确定是否为拔刀剑杀敌数NBT标签)
NBTTagCompound tag = new NBTTagCompound();
tag = CraftItem.getTag();
tag.setInt(Killer", 0);
CraftItem.setTag(tag);
ItemStack NowItem = CraftItemStack.asBukkitCopy(CraftItem);
这样既可把合成出来的拔刀剑的杀敌数清空.
