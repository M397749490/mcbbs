作者: 1208180423    时间: 2017-7-28 18:01
服务端链接不上更新服务器，报错很正常
关闭办法：
1.打开服务器目录下的kcauldron.yml文件
2.找到如下的文字
updatechecker:
  quiet: true
  symlinks: KCauldron.jar
  enable: false
  autorestart: false
  autoinstall: false
3.把这些文字里的enable: true改成enable: false
4.保存，重启服务器即可
