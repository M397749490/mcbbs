紧急修复

Cshop目前有两个已知bug，我已经反馈给官方开发者，但是由于此插件处于半弃坑状态，两个bug均未被官方修复！
  • 当Carrotshop和GriefPrevention一起使用的时候，一个bug会在方块售卖完成后补偿回去！
  • Cshop无法识别带有小数的价格，例如，1.6会被处理为16！


However，以上两个bug均被米二非官方修复：

  • 现在手持道具将无法进行交易，必须主副手全部为空才能交互。
  • 修正版的Cshop现在能够识别小数价格了
  • 此重置版仅在Api7中进行测试，可能不兼容1.10.2-1.11.2

（题外话，此修复版被定义为“非官方版”，这个问题米二很久以前就修复了，但是鉴于伸手党非常多，米二一直没有分享，近日米二良心发现决定发布出来，希望大家不要再继续潜水和伸手了！）

指令
以下“/cs”指令可被/carrotshop、/cshop、/shop等指令替代，再问自*

  • /cs help                  ——    打开CarrotShop的官方wiki（英文）
  • /cs hide                  ——    隐藏你的销售提醒
  • /cs report               ——    显示自己的销售报告
  • /cs report [player]   ——    显示指定玩家的销售报告
  • /cs servreport         ——    显示整个服务器范围内的全部销售报告
  • /cs config               ——    修改通行货币（不建议修改）
教程
(1)货币交易型
1.放置一个箱子和一个牌子（两者任意远）
2.向箱子里放上待交易的商品（一个）
*注：这里需要放置的商品数量是对应牌子价格的单价，如果你放满商品，购买者会以牌子上的单价一次性卖光所以商品
3.将牌子修改为指定格式（这里使用了一款很棒的牌子编辑插件）
4.手持红石粉末左键箱子
4.（手持红石粉末）再点击设置好的木牌
5.如果是**类型的商店，请在创建完成后打开箱子补货
(2)以物易物型
示例交易方式：
用[卡洛兰菜单]换[打火石]
1.放置两个箱子（C1和C2）和一个牌子
3.在牌子第一行写[Trade](大小写不敏感)
4.将卡洛兰菜单放入C1
5.将打火石放入C2
6.手持红石粉末 先左键C1（注意先后顺序）
7.手持红石粉末 再左键C2（注意先后顺序）
6.手持红石粉末 最后左键牌子（注意先后顺序）
注：
第一次左键的箱子将会是你想要的商品
第二次左键的箱子将会是你提供的商品
(3)牌子格式参考
第一行：商店类型
第二行：任意文字
第三行：任意文字
第四行：单价

常见问题（必看）
为什么我的玩家不能使用我的商店？
  • 出生点附近16格被服务器保护，玩家只能左键交互，无法右键交互
  • 如果使用GriefPrevention领地保护插件，请确保商店所在领地已经将wall_sign和standing_sign的交互权限设置为true
  •        /cf interact-block-primary minecraft:wall_sign true
  •        /cf interact-block-primary minecraft:standing_sign true
  •        /cf interact-block-secondary minecraft:wall_sign true
  •        /cf interact-block-secondary minecraft:standing_sign true

目前本商店只支持整数价格
已在修复版中修复
