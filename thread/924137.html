可惜苦力怕的Fuse数值是固定的，不然可以通过检测Fuse数值来探测是否快要爆炸
也可以换一种想法，苦力怕是靠近玩家4格以内才会爆炸
那么可以给4格以内的苦力怕持续加分数，30几分的时候爆炸，那就检测15的时候执行命令什么的
而苦力怕脱离玩家4格的范围内，分数就重置为0

手动输入
/gamerule commandBlockOutput false
/scoreboard objectives add creeper dummy
第一条高频，后面两条连锁
/execute as @e[type=creeper] at @s if entity @p[distance=..4] run scoreboard players add @s creeper 1
/execute as @e[type=creeper] at @s if entity @p[distance=4..] run scoreboard players set @s creeper 0
/execute as @e[type=creeper,scores={creeper=15}] at @s run title @a[distance=..5] title "附近有苦力怕快爆炸了"
