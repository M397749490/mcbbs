[回形针工作室]
<让正在服务器游玩的小伙伴在不退出游戏的情况下看到Q群里的消息>
[需要Java8]
该插件可以把在Q群里说话的玩家说的话发到服务器里面就像是他在游戏里说一样,如图:
[插件配置信息]
该插件的配置文件以及数据文件储存在/plugins/CQP文件夹里，而且不可直接编辑，只能通过命令配置。
将插件拖到plugins文件夹里后，需要手动新建CQP文件夹，否则会报错。
该插件依靠酷Q获取Q群的消息，所以需要先配置酷Q~

酷Q配置方法：
①在酷Q官网下载 酷Q Air 标准版。
②在酷Q论坛下载 酷Q SocketAPI插件 ，这个酷Q插件用于让本插件和酷Q通讯
③运行酷Q、按照酷Q的说明登录（一般需要注册小号用于酷Q）
④将下载到的cpk文件复制进酷Q根目录下的app文件夹
⑤重启酷Q，在酷Q右键→应用→应用管理→CoolQ Socket API→启用，然后就可以点击关闭按钮。
⑥至此酷Q部分配置完成

服务器插件配置方法：
酷Q成功运行后，即可正式开始配置本插件。
①下载本插件
②将本插件放置于服务器plugins文件夹中,并在plugins文件夹中手动新建CQP文件夹
③启动服务器
④进入游戏(需要是OP),执行指令:
/CQP OP setGroupID [GroupID]

该命令用于设置需要转发的Q群群号
（请将命令中[GroupID]替换为你的Q群的ID，如： /CQP OP setGroupID 304279325）
⑤至此插件部分配置完成，若你每分钟都看到“ServerHello”，那么说明插件成功与酷Q建立连接

绑定成员名称：
本插件支持将玩家绑定QQ，绑定后该QQ在群内发言，转发至服务器时将会使用该玩家的游戏名，否则将显示该QQ号。
绑定方法：
需要玩家本人进入游戏执行命令“/CQP bind”,随后系统将显示验证码。
玩家直接在Q群内发送该验证码，这样就可以将发送验证码的这个QQ绑定到该玩家名下。

关于该插件全部命令的说明

以下是所有可用的命令{大括号内的为命令的说明}：
  • /CQP bind {用于将QQ绑定到玩家名下，直接输入此命令，然后在Q群内发送验证码即可绑定成功}
  • /CQP delete [QQ号] {用于将QQ从本人名下删除。}
  • /CQP list {列出本人名下所有的QQ}
  • /CQP OP
  • {
  • 本命令需要OP权限
  •   使用方法：
  • /CQP OP setGroupID [Q群号] {设置服务器的群，请注意登录酷Q的QQ当然一定至少要是群成员}
  •   /CQP OP OP_M_delete [Q号] {从任意玩家名下解绑此QQ，用于Q号被盗绑时的找回}
  • }


[安全信息]
服务器请开启11235udp端口的防火墙，以免外来udp包接入、控制酷Q SocketAPI
