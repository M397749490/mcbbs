怎么修改。

插件生成的文件夹里面有一个config.yml打开修改即可 下面是介绍

  1. settings:
  2.   enabled: true  ——启用否。true是 false否，以下不再赘述。
  3.   min-players: 0  ——不知道！（喂
  4.   log-to-console: false  ——是否显示到控制台
  5.   auto-update: false  ——自动升级否？
  6. message-lists: ——以下是广播列表
  7.   default:  ——default列表
  8.     enabled: true  ——是否启用
  9.     random: false  ——是否随机
  10.     interval: 45  ——间隔45 秒
  11.     prefix: '&r[&bAutoMsg&r] '  ——这是前缀
  12.     messages:  ——以下是本组内的消息，\n 可用来换行，拥有automessage.receive.default 权限的玩家/组会接收到本组内所有的消息
  13.     - '&1First&r message \nin the default list!'
  14.     - '&2Second&r message \nin the default list!'
  15.     - '&3Third&r message \nin the default list!'
  16.     - 'These messages will be displayed to users with \nautomessage.receive.default!'
  17.   vip:  ——这是VIP组，以下同上
  18.     enabled: true
  19.     random: false
  20.     interval: 45
  21.     prefix: '&r[&bAutoMsg&r] '
  22.     messages:  ——拥有automessage.receive.vip权限的玩家/组可以接收到本组所有信息
  23.     - 'This message will be displayed to users with \nautomessage.receive.vip!'
  24. 注：可以继续添加消息组，按照以上格式添加，对应的，权限就是automessage.receive.<列表名>
