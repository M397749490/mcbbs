仅服务端

仅服务端的话建议走插件+脚本路线,而不是仅靠脚本,因为脚本只能通过强制杀死服务端的方法重启.
这里以bukkit系服务器做例子.
脚本:
  1. while true
  2. do
  3. 你原先的启动命令,如java -jar xxx.jar
  4. #加入延时
  5. sleep 1
  6. done
复制代码

然后用一个定时执行指令的插件,这里推荐的是TimerExecute.
[管理]TimerExecute——给你的服务器加一些定时指令吧![1.8-1.12]
https://www.mcbbs.net/thread-815854-1-1.html
然后参考帖子里的内容,可以非常轻易的写一个定时任务,比如我要求每天晚上11点重启:

  2. TimerReboot:
  3.   enable: true
  4.   
  5.   year: -1
  6.   month: -1
  7.   day: -1
  8.   
  9.   timer_timeset:
  10.    - '23:00:00'
  11.   

  13.   command_set:
  14.     commands:
  15.      - 'broadcast 将于5秒后重启服务器!'
  16.      - 'delay 5000'
  17.      - 'broadcast 正在重启…'
  18.      - 'stop'
复制代码

这样服务器就会在23点自动stop,然后脚本又会让服务器再次启动.

这个方法看起来很麻烦，但实际应用范围很广，且不需要安装额外的服务端插件
依赖（ubuntu可能自带）:crontab php


首先在脚本里设置循环，就是在服务端里/stop之后又会自己启动。这里参照楼上
  1. while true
  2. do
  3. 你原先的启动命令,如java -jar xxx.jar
  4. #加入延时
  5. sleep 1
  6. done
复制代码


接着在服务端同目录创建一个叫Rcon.php的文件，里面的内容参照https://wiki.vg/RCON https://lo-li.cn/361 https://cqp.cc/t/27121
接下来在同目录创建一个stop.php的文件，作用是调用Rcon.php来发送/stop命令
  1. <?php
  2. #!/usr/bin/php -q
  3. include 'Rcon.php';
  4. $rcon = new Rcon("localhost", 你设置的Rcon端口, 你设置的Rcon密钥', 3);
  5. if ($rcon->connect()){
  6.         $rcon->sendCommand('broadcast 将于120秒后重启，请及时完成手上的工作。');
  7.         sleep(120);
  8.         $rcon->sendCommand('kickall 适度游戏益脑，过度游戏伤身。(服务器重启，预计3分钟)');
  9.         $rcon->sendCommand('stop');
  10. }
  11. else{
  12.         echo 'Rcon连接失败';
  13. }
复制代码


最后在shell输入crontab -e，加入一行参数，意思为每天凌晨4点自动重启
  1. 0 4 * * * /usr/bin/php 你的服务端路径/stop.php
复制代码


需要注意的是要在配置文件里设置开启rcon的密钥和端口(enable-rcon rcon.password  rcon.port）
很多地方讲述的不够清楚，如果有疑问可继续追问，但建议遇到问题先搜索并阅读相关文档
