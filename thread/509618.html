All are default OP

  • smileychat.* all permissions.
  • smileychat.update update notification on player join.
  • smileychat.info acces to /smileychat command.
  • smileychat.reload acces to /smileychat reload command.
  • smileychat.list acces to /smileychat smileys command.
  • smileychat.chat.*
    • smileychat.chat.smileys use smileys in chat.
    • smileychat.chat.custom use custom smileys in chat.
    • smileychat.chat.art use ascii-art in chat.
  • smileychat.sign.*
    • smileychat.sign.smileys use smileys on signs.
    • smileychat.sign.custom use custom smileys on signs.
    • smileychat.sign.art use ascii-art on signs.
  • smileychat.command.*
    • smileychat.command.smileys use smileys in commands.
    • smileychat.command.custom use custom smileys command.
    • smileychat.command.art use ascii-art in commands.
  • smileychat.book.*
    • smileychat.book.smileys use smileys in books
    • smileychat.book.custom use custom smileys in books
    • smileychat.book.art use art in books
