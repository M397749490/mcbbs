本帖最后由 1582952890 于 2017-9-17 08:45 编辑

介绍：如果一个玩家发现自己被困在一个地狱门时,NPR将传送他们离开此处！


插件特性：
①当一位玩家一直在地狱门，10秒后将传送他离开。
②当一位玩家刚上线时，如果在地狱门将传送他离开。

安装：
①下载NetherPortalRescue.jar
②将NetherPortalRescue.jar拖入plugins文件夹内
③启动服务器
④完成！

插件指令：
对8起，插件太简便，无需指令

插件权限：
对8起，插件太简便，没有权限


插件配置：
properties
  • use-metrics: Let mcstats.org know you're running the plugin.
  • debug-messages: Send some debug messages to console.
  • login-check: Check on the player on login.
  • auto-rescue: Check on players after they've used a portal.
  • wait-timer: After portal used, wait in seconds before checking on them.
messages
  • ReturnedToSpawn: Message sent if they're teleported to spawn.
  • ReturnToPrevLoc: Message sent if they're still in a portal block after using a portal.

支持MCPC+
已在1.7.10 KCauldron 完美运行，向下兼容支持MCPC+
