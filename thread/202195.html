之前在mcbbs发布过一篇关于使用java/javaw启动Minecraft的帖子： MC 干净简洁的启动方式
时至今日，帖子早已过时，相应脚本也只适用于版本小于1.6的mc，很久没玩，才发现都更新到1.7.2了， 于是在mc官方论坛上转了转，找到了适用于最新版(1.7.2)的启动命令。

核心代码：
  1. java -Xmx512M -Djava.library.path="%MCDIR%\versions\1.7.2\1.7.2-natives" -cp "%MCDIR%\libraries\org\apache\logging\log4j\log4j-api\2.0-beta9\log4j-api-2.0-beta9.jar;%MCDIR%\libraries\org\apache\logging\log4j\log4j-core\2.0-beta9\log4j-core-2.0-beta9.jar;%MCDIR%\libraries\com\ibm\icu\icu4j-core-mojang\51.2\icu4j-core-mojang-51.2.jar;%MCDIR%\libraries\com\mojang\authlib\1.3\authlib-1.3.jar;%MCDIR%\libraries\io\netty\netty-all\4.0.10.Final\netty-all-4.0.10.Final.jar;%MCDIR%\libraries\java3d\vecmath\1.3.1\vecmath-1.3.1.jar;%MCDIR%\libraries\net\sf\trove4j\trove4j\3.0.3\trove4j-3.0.3.jar;%MCDIR%\libraries\net\sf\jopt-simple\jopt-simple\4.5\jopt-simple-4.5.jar;%MCDIR%\libraries\com\paulscode\codecjorbis\20101023\codecjorbis-20101023.jar;%MCDIR%\libraries\com\paulscode\codecwav\20101023\codecwav-20101023.jar;%MCDIR%\libraries\com\paulscode\librarylwjglopenal\20100824\librarylwjglopenal-20100824.jar;%MCDIR%\libraries\com\paulscode\libraryjavasound\20101123\libraryjavasound-20101123.jar;%MCDIR%\libraries\com\paulscode\soundsystem\20120107\soundsystem-20120107.jar;%MCDIR%\libraries\com\google\guava\guava\15.0\guava-15.0.jar;%MCDIR%\libraries\org\apache\commons\commons-lang3\3.1\commons-lang3-3.1.jar;%MCDIR%\libraries\commons-io\commons-io\2.4\commons-io-2.4.jar;%MCDIR%\libraries\net\java\jinput\jinput\2.0.5\jinput-2.0.5.jar;%MCDIR%\libraries\net\java\jinput\jinput-platform\2.0.5\jinput-platform-2.0.5-natives-windows.jar;%MCDIR%\libraries\net\java\jutils\jutils\1.0.0\jutils-1.0.0.jar;%MCDIR%\libraries\com\google\code\gson\gson\2.2.4\gson-2.2.4.jar;%MCDIR%\libraries\org\lwjgl\lwjgl\lwjgl\2.9.0\lwjgl-2.9.0.jar;%MCDIR%\libraries\org\lwjgl\lwjgl\lwjgl_util\2.9.0\lwjgl_util-2.9.0.jar;%MCDIR%\versions\1.7.2\1.7.2.jar" net.minecraft.client.main.Main --username [player name] --version 1.7.2 --gameDir %MCDIR% --assetsDir %MCDIR%\assets --accessToken [obtain from launcher_profiles.json in MC directory] --uuid (Default)

这就是启动mc最本质的东西了，所有启动器都应该遵守这个规则吧，虽然和众多拥有大量复杂功能的启动器相比， 这个简直弱爆了，但我觉得比较适合有洁癖， 玩纯净版或者动手能力较强的同学吧~

脚本：
这里写了两个简单的自动运行的脚本（文章后面提供下载）， launch.bat 和 launch.js，适用于windows系统：

launch.bat
bat是windows批处理文件，简单说明： set设置变量，%var%引用变量，命名换行相隔，@echo off指不打印bat中的命令到控制台只是运行，java 指当前系统中的java虚拟机，javaw功能和java一样但不显示输出...
  1. :: 变量mcdir表示mc根目录，默认"./"代表mc根目录和脚本在同一个目录
  2. :: 变量assetsDir指assets目录，默认位于mc根目录下
  3. :: mc根目录及结构见：http://www.mcbbs.net/thread-38297-1-1.html
  4. set mcdir=./set assetsDir=%mcdir%/assets

  6. :: 变量username就是游戏里玩家名字啦，默认mcfan
  7. set username=mcfan

  9. :: 变量accessToken和uuid组合形成一个session id，格式为accessToke:uuid, 有何用途不太清楚
  10. :: 这里默认设置0:0:0，可正常启动mc，后果未知。。
  11. set accessToken=0:0
  12. set uuid=0

  14. :: 这个maxMemory变量当然就是java虚拟机能够使用的最大内存啦， 省略单位M（兆字节）， 默认1024
  15. set maxMemory=1024
复制代码


使用bat脚本系统会打开一个控制台，如果使用java启动mc你会看到控制台会打印出mc日志（对于程序员们这个貌似很带感lol），关闭mc控制台自动关闭，也可在mc启动后直接关闭不影响游戏运行。

launch.js
没错，这是一个javascript的脚本，由于windows系统自带Microsoft的Jscript引擎，js能在windows系统中直接运行，双击便是，使用bat脚本启动mc会有显示一个控制台（黑色命名窗口），有些同学可能会感觉到古怪，影响游戏心情那可不好，于是写了一个js脚本，js脚本使用了windows的WScript.Shell接口，可以后台运行一些程序，使用方法：
  1. // 修改传入launch(mcdir, assetsDir, username, accessToken, uuid, maxMemory)函数的参数来更改相应配置
  2. launch("./", "./assets", "mcfan", "0:0", "0", 1024);

  4. // 直接调用不传入任何参数，使用默认参数，默认参数和bat脚本默认参数一致
  5. launch();
复制代码
使用vbs脚本也这么干，同样调用WScript.Shell接口，脚本功能都一样，这里就不写了。

使用linux系统和mac系统的同学，感兴趣，有一定计算机基础的的同学可自己编写sh脚本，核心代码见文章第二部分，以上两个脚本在win7中测试通过，xp/vista/win8理论也是没问题了，请自行测试，同时欢迎反馈 :)

使用方法：
1. 下载：  windows系统用户下载任意一个脚本，保存文件名随意, 但请保留后缀(.bat/.js)
2. 修改：  修改bat脚本中变量，更改相应设置（mc目录, assets目录，玩家名字，内存，Session...）
3. 运行：  双击脚本运行，如果无法启动mc，请仔细检查修改脚本是否正确，请确保你安装了jre， 并且已经包含jre/bin路径到系统PATH常量
4. Sorry：  不懂代码的同学请耐心坐等大神更新吧：Minecraft宇宙最快启动器
