游戏方法

翻译人员： miguo，djx

○□△×
可以通过按键时间的长短决定射门和传球的力度大小。
球类在不同地面的运动方式不同。
在接触球时按□键可以捡起球。
按住△键可以冲刺。

游戏设定
通过在选项中控制面板可以自定义按键（○、□、△、×）
通过在选项中“Sport MOD”面板可以自定球类ID

==篮球==




——按键说明——
单击篮球可以运球。
按×可以持球。
按○可以投篮。
按住潜行+×可以旋转。
——合成表——
篮球


篮球框



==足球==





——按键说明——
通过移动推动足球前进
按×可以传球。
按○可以射门，此时视角越高，球射的越高。
右击手套可以握住球。
——合成表——

足球

守门员手套



==网球==

——按键说明——
按×拿起球来。
按○把球扔出去。
右击球拍击球，此时视角越高，球射的越高。
网球发射器的难度取决于你的游戏难度（和平、简单、普通、困难）
球会被发射到随机方向。
——合成表——
网球

网球拍

网球发射器


==棒球==





——按键说明——
右击手套接球。
按○投球。
潜行+右击球棒可以进行击球。
——合成表——
  
棒球

棒球棒

棒球手套

——安装说明——
客户端
在minecraft.jar中删除META-INF.
下载MinecraftForge Client，解压后把文件放入minecraft.jar。
下载Render 1.4，解压后把文件放入minecraft.jar。
下载SportsMod for Client，解压后把文件放入minecraft.jar。
服务器
下载MinecraftForge Server
下载PlayerAPI
下载SportsMod for server
Bukkit
下载latest craftBukkit MCPC
下载PlayerAPI 1.2 for bukkit
下载mod_Sports for Bukkit
