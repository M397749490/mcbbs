CitizensBooks
公民之书
简介
  这是一个极其简单的插件，你可以在Citizens的NPC处编辑一本书。一旦点击了这个NPC，就会打开你设置的书
  此外，借助这个书本编辑器，你可以创建世界上最美丽的书本！
  http://minecraft.tools/en/book.php
图片
在你编辑完书本后点击NPC

指令和权限
  • /npcbook help - [npcbook.command.help] 打开插件帮助界面
  • /npcbook about - [无权限]
  • /npcbook set - [npcbook.command.set] 设置一本书
  • /npcbook remove - [npcbook.command.remove] 移除一本书
  • /npcbook getbook - [npcbook.command.getbook] 获得一本书
  • /npcbook openbook - [npcbook.command.openbook] 打开一本书
  • /npcbook reload - [npcbook.command.reload] 重载插件
  • /npcbook setcmd - [npcbook.command.setcmd] 设置命令
  • /npcbook remcmd - [npcbook.command.remcmd] 重新设置命令
  • /npcbook filter <子命令> <筛选器名称> - [npcbook.command.filter.<sub-command>]
  • [size=14.6667px]*子命令有: set, remove, getbook
