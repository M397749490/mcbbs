指令:
/is权限:
askyblock.island.*     ----所有基础权限
askyblock.team.*    ---队伍的所有权限
askyblock.coop  ---使用/is coop 权限 允许一个玩家暂时访问你的岛
nobreak.build.ASkyBlock_nether  ------地狱岛破坏以及建筑权限
nobreak.build.ASkyBlock  ------普通世界岛破坏以及建筑权限


  • 房子的数量 - askyblock.island.maxhomes.<number>
  • 岛屿成员的上限 - askyblock.team.maxsize.<number>
  • 初始地皮保护大小 - askyblock.island.range.<number>
  • askyblock.island.controlpanel 控制面板的权限 我也不知道是什么
管理员权限就没必要发了

岛屿传送点的建立
放一个牌子,然后第一行写上[传送点] 234随便写,然后会变绿,变绿就成功,变红就重新弄
然后别人可以输入/is warp 你的ID 来传送到你的岛！

聊天时候显示岛屿等级方法:
打开ess的config,在聊天设置那里(514行左右)
默认是这个: format: '<{DISPLAYNAME}> {MESSAGE}',在{DISPLAYNAME}前面加入{ISLAND_LEVEL} 即可
然后输入/ess 任意键 重载插件即可显示
例子:
format: '<{ISLAND_LEVEL}{DISPLAYNAME}> {MESSAGE}'

FAQ: 意欲汉化所有FAQ
①:如何把空岛设置为主世界
推荐新服这样做
准备的插件Essentials, WorldEdit, 权限组插件, 以及 Vault 1.5+
生成 主世界、地狱、末地后(不包括空岛的世界),关服
把空岛插件以及上述插件丢进插件文件夹后
编辑server.properties文件
level-name=world 把world改成ASkyBlock
然后打开bukkit.yml文件,复制下面的内容,新起一行并删除前面的空格然后复制 非常重要的一步
worlds:
  ASkyBlock:
    generator: ASkyBlock
  ASkyBlock_nether:
    generator: ASkyBlock

如果你在插件config里面改了世界名字,那么记着sever文件和bukkit里面要修改名字
然后删除world, world_nether, world_the_end文件夹,然后开服
然后服务器进入个OP,你会在天空中飘啊飘,输入/is来获得一座岛
然后注销自己,指令/asadmin unregister <your name>(也就是岛屿不是你的了,属于服务器的出生点)
然后输入/asadmin setspawn来设置出生点/setspawn也可以 如果有ess插件的话
然后输入 /asadmin setrange <数字>设置岛屿保护范围
然后没你事
②:为什么我能拿走GUI页面的东西(除网卡外,这种情况较少)
这一般是由别的插件影响的,查找 显示GUI页面的和查看箱子物品的插件,然后一个个删除直到找到影响的插件
建议删除他,因为他写的很烂
网卡例外

③:玩家可以用活塞把方块推到岛外
插件默认允许这样的行为,如果你不想这样做,打开config文件把allowpistonpush设为false
然后重启服务器.建议多看config以便了解什么是允许或者不允许的
看不懂的就算了

④:去别人空岛不能用quickshop
没研究 不知道-。-不过可以试试环球商店 我这有国外无bug版的环球 加Q找我 代购.

建议你把空岛服单独开,单端要开的话 配合该插件使用

更新vault到156

⑧:为什么我换了核心后插件还是无法使用
删除服务端根目录原配置文件以及重新按边askyblock

图挂,懒得补.
自定义空岛形状(蓝图教程) 需要WE插件 高级教程 没有一定基础的服主不要看
先自己设计/盖好岛后,开创造模式,飞到岛上面的一个角落去 如图所示


然后在把垫着的方块打掉 浮在空中 输入//pos1
然后再从岛屿的另一角落下去 如图

然后一直下降 直到虚空 高度0 在高度0左右的时候输入/up 1

注意看我的高度为1 然后输入//pos2
然后输入//copy 然后会出现 XXXX block(s) were copied
然后输入//schematic save 任意文件名 我输入的是//schematic save 1 也就是文件名为1
然后会出现 1 saved
然后在worldedit文件夹里会生成schematics文件夹 里面有个名字为1的文件
然后把这个文件转移到ASkyBlock\schematics里去 然后打开config文件 拉到最下面
然后复制下面这些东西 新起一行 把前面的空格排空 然后粘贴 我用最简单的一个做例子
    default: #这个名字改掉 不能重复
      # 这个是在输入/is的时候出现的图标 F3 H一起按住 然后自己去看物品的英文名称
      icon: DIRT #泥土
      #在GUI页面中排的顺序 这个是默认的 所以是第一个
      order: 1
      # 物品的名字
      name: "The Original"
      # 物品的lore |来分行
      description: "Challenging|starter|island!"
      # 使用的蓝图名字 比如我的是1 就把island改成1
      filename: island.schematic
      # 使用默认的箱子 没啥要求就别改
      useDefaultChest: true
      # 如果newnether是开启的 这个世界的地狱可以自己设置 也是改下面蓝图的名字来换个地狱   
      # 太高级了- -又扯出新的地狱 反正我不会
      partnerSchematic: nether
      #Level handicap zeros the initial island level. 等级**什么初始等级 看不懂 有人翻译下么..
      levelHandicap: 3
上面这个是最简单的一个 没啥别的要求就复制我上面的 比如自定义箱子里的东西和群系
然后输入重载指令/asadmin reload然后输入/is就可以正常使用了
