插件介绍/功能
介绍
25种不同寻常的弓，为您服务器提供更多的弓~
（以下弓的名称、括号内介绍与原贴差不多一致）
● 银弓（增加40%的伤害）
● 爆炸弓（产生区域爆炸效果）
● 震动弓（射中后屏幕会持续震动一段时间）
● 腐蚀弓（射中方块/实体，触发区域）
● 猎人弓（动物将额外增加75%的伤害）
● 标记弓（暂时标记玩家，攻击后产生额外40%伤害）
● 闪电弓（射中后召唤闪电！）
● 传送弓（射中后将你传送到射中的地方）
● 冰爆弓（射中后产生小范围的冰爆）
● 火弓（射中后产生小范围的火爆以及区域燃烧）
● 三重弓（射出三支箭）
● 复合弓（直线射击的箭）
● 重力弓（将射中的实体吸到你的位置）
● 丘比特之弓（治疗目标三颗心）
● 线性弓（直线射击，射中后爆炸）
● 铁路炮弓（射出将直接爆炸，需坐在矿车上才有效）
● 雪球弓（射出几个雪球）
● 凋零弓（射出凋零发射的凋零头颅）
● 连射弓（射出许多支箭）
● 鸡蛋弓（快速射出鸡蛋）
● 火焰弓（射中后持续火焰伤害，有较炫酷的粒子效果）
● 暗影弓（与火焰弓类似，但没有持续火焰伤害）
● 黑洞弓（召唤一段时间的黑洞，会吸玩家！）
● 流星弓（召唤拥有爆炸效果的流星！）
● 斯巴达弓（召唤天空箭，会在较高的地方持续射箭一段时间）
● 地震弓（释放冲击波！）
● 激光弓（用激光击穿目标！）
功能：
(弓的功能已经附加在各个弓的右侧括号中了)
(或许这才是介绍？！)
弓箭都有自己的冷却时间，防止严重卡服！
所有弓箭可用于小白怪物！！！
每个弓拥有自己的粒子和声音效果！
自定义名字、伤害、冷却时间、颜色、粒子效果、合成表等
可以用mb-bows、worldguar flag来禁止指定区域内的某个弓
除非获得权限，否则不能重命名弓！
拥有简单操作的命令，输入/mb即可查询所有命令
拥有gui界面！可方便的查看各个弓的属性以及名称，点击即可直接获取！！！
可添加更多的弓！
插件指令/权限
指令
查询所有命令:  /mb
将某个弓给予给玩家:  /mb get <弓的名字> (玩家)
获取所有弓:  /mb getall
打开gui界面，所有弓都在里面:  /mb gui
列出所有弓:  /mb list
重载配置:  /mb reload
权限
moarbows.admin  使用全部命令的权限
moarbows.gui  打开gui界面的权限
moarbows.anvil  在铁砧中重命名普通弓为插件弓的权限
moarbows.repair  修复插件弓的权限
moarbows.enchant  附魔弓的权限
moarbows.update-notify  接受插件新版本通知的权限
moarbows.use.*  使用所有弓的权限
例如爆炸弓的使用权限，就是moarbows.use.explosive-bow权限
下划线更换为-即可
[教程]如何添加更多的弓
首先先打开bows.yml
这里是所有弓的存放地
EARTHQUAKE_BOW:
name: '&f爆炸弓'
lore:
- '&e&m------------------------------'
- 击中后发生爆炸
- 猛烈的爆炸伤害！！
- 5个方块内所有敌人会受到爆炸伤害
- '&e&m------------------------------'
cooldown: 10.0
durability: 0
craft-enabled: true
craft:
- DIRT,DIRT,DIRT
- DIRT,BOW,DIRT
- DIRT,DIRT,DIRT
eff: redstone:128,0,0
knockup: 1
radius: 5
例如爆炸弓EARTHQUAKE_BOW
EARTHQUAKE_BOW为名字，可自定义
name为弓显示的名字，可自定义名称！
lore为弓的描述
cooldown是冷却时间，例如这里的10.0，就是10秒冷却
durability是耐久值，0为无限耐久
craft-enabled  是否启用合成表
craft为合成方式
eff是药水效果
knockup是击退的等级
radius为影响范围半径
