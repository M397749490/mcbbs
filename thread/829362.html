标签设置的 攻击力: 10-20
但是打出来如果蓄力了那就是10-20
如果连续打就会是低于10

1.9以上 就会有攻速限制的 必须蓄力才能打出全部伤害

这个插件就可以实现高版本就跟低版本一样的攻速
http://www.mcbbs.net/thread-793362-1-1.html

#是否启用血条压缩功能
  • #是否启用血条压缩功能
  • HealthScaled:
  •   Enabled: true
  •   #血量压缩锁定值 每2个Value算一颗心
  •   #例如我当前最大生命值是1000，他只会显示两排
  •   #最大血量低于Value数值的情况下，自动不压缩
  •   Value: 40

  • #是否开启1.9战斗模式（十分推荐）
  • DamageGauges: true




  • #是否清除物品原版标签（例如默认的攻击力、护甲，会导致伤害不准确）
  • ClearDefaultAttribute:
  •   #本插件产生的物品
  •   ThisPlugin: true
  •   #所有 工具类 的物品 （开启此项后 村民交易的工具物品 可能会出问题 需要手动更新）
  •   All: false
  •   #出现上述问题，关闭以上选项，开启此项，即可恢复原版标签。
  •   Reset: false

上面这三段 是原贴复制的


如果你不想用这个插件 又想解决问题 那只能定制插件了
