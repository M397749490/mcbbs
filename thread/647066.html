注意事项

虽然我们希望更多的人能够帮助我们翻译，但我们更希望每个负责翻译的人都有一定程度的Java开发基础。因为SpongeDocs中出现了大量和Java有关的术语，对Java不熟悉的参与者很容易错翻漏翻，这也是我们不希望看到的。不过，如果不熟悉Java，可以去帮我们投票（往下看）。

SpongeDocs里有大量崭新的概念，请在遇到不熟悉的概念时，先点击位于在线翻译界面正下方的“Search TM”栏，并输入不清楚的词句。因为可能已经有人提供过相关的翻译了，所以为了保证翻译的一致性，请使用之前曾经出现过的翻译，如有必要，请括号标注对应的英文名称。

SpongeDocs使用reStructuredText进行文档排版，如果参与者之前对Markdown等格式比较熟悉那么应该较容易上手，但翻译时仍需谨慎。例如用于标记格式的标点必须使用英文标点，一些特殊格式中的英文不能翻译，特殊格式两端必须留有空格等。本帖后面有关于该格式的说明。

项目简介

Sponge是一个富有活力的、社区驱动的、开源并且全是BUG的Minecraft插件平台。其设计了一套崭新的API用于1.8以上版本的Minecraft服务端的插件开发，而SpongeDocs便是这套API等相关的开发文档。

这里是本人拿到Sponge开发团队官方许可的证明，同时本人也是该项目的校对员。

SpongeDocs英文原文（官方版本）：https://docs.spongepowered.org/master/en/
SpongeDocs中文翻译（正在审查）：https://docs.spongepowered.org/master/zh-CN/

本项目参与Minecraft相关项目本土化协助计划。

重要提醒

SpongeDocs使用reStructuredText书写，这里是关于翻译中大量用到的部分格式介绍：

  • 使用 *一对星号括起来* 的文本为斜体文本，
    可以翻译。
  • 使用 **两对星号括起来** 的文本为粗体文本，
    可以翻译。
  • 使用 ``两对反引号括起来`` 的文本为代码文本，
    其中的内容不应翻译。
  • 使用 `一对反引号括起来，后面跟着下划线`_ 的文本为链接，
    其中的内容不应翻译，因为被一个反引号括起来的内容起到了索引的作用。
  • 使用 `和上面的结构类似，只不过后面有一个被尖括号括起来的链接 <http://www.example.com/>`_ 的文本为自定义显示内容的链接，
    尖括号外的内容可以翻译，而尖括号内大多为一个URL，不应翻译。
  • 使用 :ref:`两个冒号及其中的ref打头，后面跟着一对反引号括起来` 的文本为页内章节引用链接，
    其中的内容不应翻译。
  • 使用 :doc:`两个冒号及其中的doc打头，后面跟着一对反引号括起来` 的文本为文档内其他页面引用链接，
    其中的内容大多为一个URL，不应翻译。
  • 使用 :doc:`和上面的结构类似，只不过链接被尖括号括了起来 <http://www.example.com/>` 的文本为自定义显示内容的引用链接，
    尖括号外的内容可以翻译，而尖括号内大多为一个URL，不应翻译。
  • 使用 :javadoc:`和上面的结构类似，只不过是javadoc` 的文本为JavaDoc，
    其中的内容为类名，不应翻译。
  • 请注意反引号（`）和单引号（'）的区别。
  • 上面提及的所有格式中用到的反引号、冒号、尖括号、星号等特殊字符，均不能翻译为对应的中文字符，同时所有的特殊格式必须在两边加空格，例如下面一段英文原文：
    1. A tutorial how the data is accessed can be found `here <https://minecraft.gamepedia.com/Tutorials/Command_stats>`_.
    复制代码

    这是本人的翻译：
    1. 如果想要了解这些数据是如何访问的，可以参见 `这里 <https://minecraft.gamepedia.com/Tutorials/Command_stats>`_ 。
    复制代码

    注意形如“`xxx<xxx>`_”的内容是表示一段链接的特殊格式。所以必须在其前后加上空格，尤其注意中文句号前的空格！如果该空格不存在，Sponge使用的Markdown引擎将会无法将其解析成一个链接。
  • 如果见到类似于“\\s”一样的内容，这只是文档想要表达英文复数形式，也就是后面加上了字母s，中文并不存在复数形式，直接忽略就可以了。


除了上面提到的特殊格式，其他所有位于字里行间的英文标点，请全部转换为中文标点，同时，为统一中英统一排版的风格，在中文与英文之间需加上空格。位于标点符号附近的英文可以不和标点符号之间添加空格，拥有特殊格式的除外。

如出现专业术语，以出现过的翻译为准，如果没有人翻译过，那就大胆地自己造词吧2333不过记得在这里说明哦～

不要去翻译3.1.0、4.1.0、或5.2.0目录下的部分，因为这些部分对应的是SpongeAPI的旧版本，也就是说几乎不会有人去看的。这些部分也已经翻译完了。
