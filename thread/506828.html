介绍：本插件适合原始社会的生存服、封建时期的农业服、现代工业服等。实现资源地图的自动更换，告别挖不到矿、砍不到树、找不到动物吃不到肉的尴尬。设置了自动更换的地图上不适合建造永久建筑（民房、主城、商店、副本等），适合作为资源地图、冒险地图、随机boss地图使用。

功能：
     1.支持普通、地狱、末地三种环境的地图每隔指定时间后自动换图
     2.重新生成后保留gamerule设置，保留mv/mw插件中的此地图配置信息
     3.重新生成地图时可清理此图中所有LWC锁（测试功能）
     4.可自定义是否更换地图种子
     5.仅在服务器性能良好时执行换图功能，在线玩家多/服务器性能差时不执行

支持插件：
   
     1.无任何地图插件也可自动换图功能（主世界不能换）
    2.支持Multiverse-Core和MultiWorld（最好有这个）
    3.支持清除LWC锁

插件配置说明：
   
    ReTime: 0 #计时器，请勿修改
    ChangeSeed: true #换图时是否更换种子 true更换 false不更换 推荐更换，以防矿石刷新位置不变
    MinHours: 48  #地图最短存在时间，只有超过48小时才会换图
    RefleshWorld: #自动重置世界的名称列表，大小写敏感
    - tempworld
    - rebuildworld_nether
     CleanLWC: false #开启新图LWC锁清理
    setUnDrop: true #开启新图设置gamerule中keepInventory=true
