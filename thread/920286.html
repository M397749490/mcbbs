关于引用





  • ModuleLauncher启动引擎

ModuleLauncher模块由易语言开发的支持全版本、全拓展启动，支持多渠道服务器验证的Minecraft启动引擎。



  • BMCL API

BMCLAPI是@bangbang93开发的BMCL的一部分，

用于解决国内线路对Forge和Minecraft官方使用的Amazon S3 速度缓慢的问题。

BMCLAPI是对外开放的，所有需要Minecraft资源的启动器均可调用。

服务器的开销是有费用的，若你觉得BMCLAPI对你有帮助，欢迎捐助，支付宝：bangbang93@bangbang93.com



  • TSS Mirror


面对日益缓慢的BMCLAPI，虽然我很支持bangbang93的积极的扩建速度，但是这仍然不够快，

并且经常不稳定，我希望能有一个不同解决思路的镜像来作为它的补充。

服务器的开销是有费用的，若你觉得TSS Mirror对你有帮助，欢迎捐助爱发电或B站充电



  • Minecraft统一通行证

无需在游戏中输入/login，直接在启动器登录。

一个账号通行所有服务器，无需重复注册，不存在游戏ID占用。

支持所有服务端、客户端。兼容BC群组服。



  • Authlib-Injector

authlib-injector是一个游戏外登录规范，使用CC BY-SA 4.0授权。

它描述了一套类Mojang Yggdrasil的API，并且对Yggdrasil服务端及启动器的实现作出了规范。

authlib-injector也包含了一个mod，使用GPL-3.0授权。

它能够注入到MC客户端和服务端，使之使用指定的Yggdrasil服务端进行验证相关操作。
