插件特点 Features
本插件主要是针对中小型服务器开发的
适用于单体的生存、小游戏娱乐服务器
如果你需要BungeeCord使用，可以移步PermissionsEX或LuckPerms，或与之同用。


  • 普通的权限组功能
  • 定时权限功能（即操作后一定时间内生效，时限到达后失效）
  • 权限列表功能（可以快速添加指定权限）
  • 前后缀系统
  • 可以针对个人或者其他人进行权限增删
  • 可以添加指定的世界权限（在指定世界生效）
  • 权限组密码锁
  • 权限类级系统



指令 Commands

TIPS: 指令较多，建议使用Ctrl+F4查找
关于时限的填写方法：将<时限>改为s:m:h，其中s为秒、m为分、h为小时
例如：/permgroup MyGroup addperm test.test timed 0:0:1
即为向MyGroup组添加时限为1小时的test.test权限


普通权限组增删 Group handle：
  • /permgroup create <组> | 创建组
  • /permgroup delete <组> | 删除组
  • /permgroup setdefault <组> | 设置一个组为默认组
  • /permgroup <组> addperm <权限/权限表> | 向组添加权限或一次性添加某个权限列表内的权限
  • /permgroup <组> addperm <权限/权限表> timed <时限> | 向组添加权限或一次性添加某个权限列表内的权限（有时限）
  • /permgroup <组> addperm <权限/权限表> <世界>| 向组添加权限或一次性添加某个权限列表内的权限（有世界限制）
  • /permgroup <组> removeperm <权限/权限表> | 向组删除权限或一次性删除某个权限列表内的权限
  • /permgroup <组> removeperm <权限/权限表> timed <时限> | 向组删除权限或一次性删除某个权限列表内的权限（有时限）
  • /permgroup <组> addperm <权限/权限表> <世界> | 向组添加权限或一次性添加某个权限列表内的权限（有世界限制）
  • /permgroup <组> addperm <权限/权限表> <世界> | 向组删除权限或一次性删除某个权限列表内的权限（有世界限制）
  • /permgroup <组> prefix <前缀> | 给一组设置前缀
  • /permgroup <组> suffix <后缀> | 给一组设置后缀

权限列表 Permissions list：
  • /perm createlist <列表名称> | 创建一个权限列表
  • /perm removelist <列表名称> | 删除一个权限列表
  • /perm <列表名称> addperm <权限> | 向权限列表添加一个权限
  • /perm <列表名称> removeperm <权限> | 从权限表中删除权限

 个人操作 User handle：
  • /permuser <用户> | 获得这个用户的权限信息
  • /permuser <用户> addgroup <组> | 把一个用户移入一个组
  • /permuser <用户> removegroup <组> | 把一个用户从一个组中移除
  • /permuser <用户> addgroup <组> timed <时限> | 把一个用户移入一个组（有时间限制）
  • /permuser <用户> addperm <权限/权限表> | 向用户添加一个权限
  • /permuser <用户> addperm <权限/权限表> timed <时限> | 向用户添加一个权限或权限列表（有时间限制）
  • /permuser <用户> addperm <权限/权限表> <世界> | 向用户添加一个权限或权限列表（有世界限制）
  • /permuser <用户> removeperm <权限/权限表> | 向用户添加一个权限
  • /permuser <用户> removeperm <权限/权限表> timed <时限> | 向用户添加一个权限或权限列表（有时间限制）
  • /permuser <用户> addperm <权限/权限表> <世界> | 向用户添加一个权限或权限列表（有世界限制）
  • /permuser <用户> prefix <前缀> | 给用户设置前缀
  • /permuser <用户> suffix <后缀> | 给用户设置后缀
  • /permuser <用户> find <regex> | 根据正则表达式为用户查找权限（意义不明）
  • /permu promote <用户> | 设置用户的下一级（意义不明）
  • /permu demote <用户> | 设置用户的上一级（意义不明）

其他 Others：
  • /permrank create <类级名称> <组> | 添加一个权限类级（即权限组上一级的权限组群，由多个权限组串联而成）
  • /permrank delete <类级名称> <组> | 删除一个权限类级
  • /permrank addgroup <类级> <组1，组2，组3> | 向权限类级添加一定组
  • /permrank removegroup <类级> <组1，组2，组3> | 向权限类级删除一定组
  • /perm finder | 开启/关闭权限查找器（意义不明）
  • /permlock  <密码> | 设置权限组的锁（设置后，你在登陆时会要求你登录权限组以获得权限，使你的账户更加安全）
  • /permlock on <密码> | 开启权限组锁
  • /permlock off | 关闭/注销权限组锁
  • /perm reload | 重启系统

如何从PEX导入数据 Import data from PermissionsEX
在此之前，你先要确认服务器在之前使用了PEX并有数据
确认完毕后使玩家全部离线（但服务器要开启），并拖入PermissionsPlus（这样做是为了防止数据出错）
随后在控制台输入/Perm export
执行成功后/perm reload 重启
现在你可以删除PermissionsEx并重启服务器了！
现在PermissionsPlus已经完成了数据过渡！放心使用吧！

疑难解答 FAQ

Q:为什么OP没有更改插件的权限
A:默认OP没有更改PermissionsPlus权限，需要在config中找到
  1. # set this to true if you want that only op player can use all PermissionsPlus commands
  2. onlyOp-usePerm: false  
复制代码
改为true即可.

Q:为什么没有通配符
A:通配符是由插件分配的，没有通配符我也没办法

Q:如何手动更改插件权限表
A:很简单，找到permissions.yml
  1. Groups:
  2.   default:
  3.     default: true
  4.     permissions:
  5.       - modifyworld.*
  6. Users: {}
复制代码
这是对节点的讲解：
  • Groups：组列表打头，不要更改
  • default：这是默认组的打头名称
  • permissions：单个组权限列表打头，不要更改
  • permissions下属你可以添加上自己需要的权限
例子
  1. vip:
  2.     default: false
  3.     permissions:
  4.      - vip.iamvip
