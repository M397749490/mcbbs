GParticles


介绍
这款插件可以给你的服务器添加增加有趣的功能。如粒子效果、足迹和趣味道具.
这款插件原为pParticles,现在这一项目刚刚重启,如果你有好的建议可以和插件作者在Discord交流

同类插件我个人推荐使用PlayerParticles (已内置汉化)

特点
  • 20+ 不同的粒子效果
  • 10+ 趣味道具
  • 10+ 不同的足迹
  • 在玩家离线后自动关闭粒子、足迹和趣味道具，并在玩家登录服务器后重新启用
  • 兼容 VanishNoPacket





截图



指令&权限


  • pp.command.gadget : 使用 /pp gadget [name]
  • pp.command.gadget.list : 使用 /pp gadget list
  • pp.command.particle : 使用 /pp particle [name]
  • pp.command.particle.list : 使用 /pp particle list
  • pp.command.particle.remove : 使用 /pp particle remove
  • pp.command.trail : 使用 /pp trail [name]
  • pp.command.trail.list : 使用 /pp trail list
  • pp.command.trail.remove : 使用 /pp trail remove
  • pp.particle.* : 使用所有粒子
  • pp.particle.[name] : 使用特定粒子
  • pp.trail.* : 使用所有足迹
  • pp.trail.[name] : 使用特定足迹
  • pp.gadget.* : 使用所有装置
  • pp.gadget.[name] : 使用特定装置
