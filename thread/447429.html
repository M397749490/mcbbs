介绍

csm可以定义Bukkit / Minecraft-server的默认消息，例如：白名单消息，加入服务器消息，转换聊天命令格式，修改死亡消息，修改服务器介绍标语Motd。
With csm you can redefine the default Bukkit/Minecraft-server messsages.
(For example: whitelist message, join message, block /plugins message, and much more）

插件特点
  • 编辑加入和离开的消息
  • 编辑转换/say 和 /me 命令格式(需要加入csm.say和csm.me权限)
  • 限制/plugins, /version 和 /seed 命令(需要加入csm.plugins, csm.version 和 csm.seed 权限)
  • 通过输入Message: ' ' 禁用消息
  • 编辑死亡提示信息
  • 如果你有其他想法,把它写在评论里

支持彩色代码
&0-9
&a-f
&k - Random
&l - Bold
&m - Striked
&n - Underlined
&o - Italics
&r - Reset
&nl - new line

%Player 获取玩家名称
%Message 获取命令消息 (say/me 命令)
