可以，通过修改配置文件：
打开/config/armourers_workshop/common.cfg
找到
  1. holiday-events {
  2.     # Setting to true will disable all holiday events. What's wrong with you! [default: false]
  3.     B:disableAllHolidayEvents=false
复制代码

把disableAllHolidayEvents的false改成true，就不会触发任何节日效果，而时装工坊发放礼品袋就是节日触发的（我的是在第78行）
