介绍 · Introduction


相较于Mythicmobs而言 我个人觉得还是Mythicmobs的功能更强大
只不过这款插件可能入门比较简单，但我不推荐使用这款插件，原因：
  • 菜单无法汉化
  • 插件作者经常更新插件，但没有什么实质性的更新内容
点击查看原图
图片被压缩了只能将就着看

这款插件适合我吗?

  • 你是否认为原版的怪物太无聊了?
  • 你是否厌倦于击杀重复的怪物?
  • 你是否安装了怪物竞技场插件并想要加入更多怪物?
  • 你是否想要怪物掉落钥匙来解锁一些东西?
  • 是否有些"看穿一切"的玩家放弃了生存？
  • 或是你的服务器玩家流失,这款插件也许可以帮到你.
但这不是万能药. 最好的方法是关心你的服务器.不论你是否购买这款插件你也应该看看以下建议:
  • 注意你的服务器结构和游戏模式. 一些东西并不是多多益善(less is more).
  • 安装小游戏插件来让玩家放松.
  • 安装如Multiverse-Core的多世界插件
  • 安装如DynMap的地图插件来记录玩家.
  • 经常查看Spigot的更新日志.
兼容性 · Compatibility
  • Java 8 或9
  • Spigot 1.7.10 +

* 你需要安装 BungeeChatAPI 才能在1.7.10运行该插件.
