----探测日夜----

探测日夜其实之前已经发了出来了，这次看着差不多就顺手再发了一次。


我看见有些探测日夜的都是修改gamerule，然后模拟/time增加时间做出来的，但其实有个更简单的方法。

MC的游戏时间是0~24000，既然可以睡觉的时间是12541-23458
那么就设定为：0~12540=白天 12541~23458=夜晚

首先需要一个计分板
  1. /scoreboard objectives add time dummy
复制代码

RCB：
  1. /time query daytime
复制代码

CCB ：
  1. /stats block ~ ~ ~1 set QueryResult @a time
复制代码
这个相对坐标，连接到上一个RCB 的坐标就可以啦。

当然，你也可以加上一个信息。

探测白天
  1. /execute @a[score_time_min=23458,score_time=23458] ~ ~ ~ /tellraw @a {"text":"天亮了。","color":"yellow"}
复制代码




探测夜晚
  1. /execute @a[score_time_min=12541,score_time=12541] ~ ~ ~ /tellraw @a {"text":"天黑了。","color":"yellow"}
复制代码

探测天气这个是在做擂台赛作品的时候才做出来的，灵感其实来自于某纯净原版生存服务器。







(我就在下雨的时候拿着弓射了一支箭，然后箭就熄灭了。)








然后我把这个小改了一下，把箭换成了盔甲架。


加一个计分板：
  1. /scoreboard objectives add wtime dummy
复制代码
  1. /scoreboard objectives add stime dummy
复制代码
  1. /scoreboard objectives add rtime dummy
复制代码
wtime，用于CB延时
stime，用于存储天晴时间
rtime，用于存储下雨时间


召唤一个盔甲架，注意这个盔甲架必须露天：
  1. /summon ArmorStand ~ ~1 ~ {Tags:["weather"],Invulnerable:1b}
复制代码



下文中出现的Fire:**， 其中的**是负1s，我不知道为什么每次都会变成**
有毒吧，负1s会变成**，我到现在才发现。
好吧，基于这个，复制的时候记得把负改成-。





高频：

/scoreboard players add @e[tag=weather] wtime 1

/entitydata @e[tag=weather,score_wtime_min=20] {Fire:999s}

/scoreboard players add @e[tag=weather] stime 1 {Fire:998s}

/execute @e[tag=weather,score_stime_min=1,score_stime=1] ~ ~ ~ /execute @e[score_rtime_min=1] ~ ~ ~/tellraw @a {"text":"天晴了。\n这次的下雨时间：","color":"yellow","extra":[{"score":{"name":"@e[tag=weather]","objective":"rtime"}},{"text":"秒"}]}

/scoreboard players set @e[tag=weather,score_stime_min=1,score_stime=1] rtime 0

/scoreboard players add @e[tag=weather,score_wtime=1] rtime 1 {Fire:负1s}

/execute @e[tag=weather,score_rtime_min=1,score_rtime=1] ~ ~ ~ /execute @e[score_stime_min=1] ~ ~ ~ /tellraw @a {"text":"下雨了。\n这次的天晴时间：","color":"gray","extra":[{"score":{"name":"@e[tag=weather]","objective":"stime"}},{"text":"秒"}]}

/scoreboard players set @e[tag=weather,score_rtime_min=1,score_rtime=1] stime 0

/scoreboard players set @e[tag=weather,score_wtime_min=20] wtime 0

这样，下雨的时候就会下分，而天晴的时候分数就会停止增长。

如果你再加入一个雨水计分板，就可以完成雨水收集装置了。

这个的话，完全可以用于实现雨水收集机这个装置。
(因为炼药锅的收集速度实在是不敢恭维)


如果你只想探测是否下雨的话，那么rtime、stime这个计分板就没用了，因为不需要探测下雨/天晴时间，那么可以简化一下：

/scoreboard players add @e[tag=weather] wtime 1

/entitydata @e[tag=weather,score_wtime_min=2] {Fire:999s}

/scoreboard players set @e[tag=weather,score_wtime_min=2] wtime 0

/scoreboard players tag @e[tag=weather] add sunny {Fire:998s}

/scoreboard players tag @e[tag=sunny] remove rainy

/scoreboard players tag @e[tag=weather] add rainy {Fire:负1s}

/scoreboard players tag @e[tag=rainy] remove sunny
