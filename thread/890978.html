前言


这款插件是做给自己的生存服用的
因为感觉市面上的其他宝石、锻造类插件玩法都比较复杂
虽然可以提升可玩性但影响纯净服的纯净度
给人感觉更像是RPG服
出于对自己六年前玩的1.7纯净服类似机制的怀念
就动手写了这款插件
玩法虽然简单，但包含四个GUI，功能的实现都非常细致
支持Mysql，可跨服使用！




功能


玩家可以通过挖矿获得战斗点数
用战斗点数兑换获得的战斗宝石在装备后可获得一定的伤害加成
通过采集作物可获得生命点数
用生命点数兑换获得的生命宝石在装备后可获得一定的伤害减免
（最初的设计是增加伤害值、增加最大生命，
但有点难以控制，且增加最大生命会被其他插件修复）
两颗宝石可合成为更高一级的宝石，每级有一定的成功率

1.8-1.12版本请在安装并运行一次后
从插件Jar文件中解压出config-legacy.yml
覆盖插件文件夹中的config.yml并重载插件
（因为偷懒自动释放尚未实现）

插件未用到新版本中的特性API，理论上1.8-1.14通用。
欢迎回复更多功能建议、BUG反馈




命令与权限以及配置文件


玩家命令:
/se                                    打开GUI主菜单
/se equip                         打开宝石装备GUI菜单
/se upgrade                     打开宝石升级GUI菜单
/se ranking                      打开点数排名GUI菜单
/se enum                         打开矿物/作物枚举GUI菜单
OP命令:
/se give <player> <type> <level> [number]   给予指定玩家指定类型、等级和数量的宝石
/se point <player> <type> <points>                调整玩家的战斗或生命点数（+/-）
/se reload                                                               重载插件配置文件
权限:   
无
Placeholders:
%expert_battle_gem%        战斗宝石等级
%expert_life_gem%            生命宝石等级
%expert_battle_total%       总获得的战斗点数
%expert_life_total%            总获得的生命点数
%expert_battle_usable%    可用战斗点数
%expert_life_usable%         可用生命点数
