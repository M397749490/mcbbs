标题: 地狱不刷怪
服务器其他世界都刷怪，只有地狱不刷怪，多世界插件那边也是允许生成，怪物难度也是困难，但是地狱就是不刷怪。。。求解。。
作者: 浅念哥    时间: 2017-4-23 15:36
首先传送到地狱
/mvm set animals true
/mvm set monsters true
/mvm set difficulty 3
/gamerule doMobSpawning true
/difficulty 3
重启服务器，再不刷怪你赢了
