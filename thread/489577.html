你改的路径是玩家目录，不是核心文件，不是.Minecraft文件夹

新建一个bat文件，写入以下内容，路径自己修改，写入以下内容即可，我就是这么玩的，亲测可用。

  1. [url=home.php?mod=space&uid=39305]@echo[/url] off
  2. Title Minecraft Launcher
  3. set APPDATA=%E:\Personal\minecraft%\
  4. start %E:\Personal\minecraft%\Minecraft.exe
