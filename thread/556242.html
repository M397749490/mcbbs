作者: dc_xin    时间: 2016-2-14 14:20
在GroupManager配置文件中改成
       world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
        world2:
          新建世界名:
          - users
          - groups
重启服务器之后进入不要权限的世界进行删除权限就可以了     不过建议在操作前先保存GroupManager文件

kivv 发表于 2016-2-14 14:24
比如新世界是SC

       world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
        world2:
          SC:
          - users
          - groups

world就是创建一个独立的权限， 而SC就是拥有这个独立权限的世界   你在重启服务器之后world文件会生成一个新的文件world2    这个就是一个新的独立权限。    而里面的文件你可以从world复制覆盖过去。。     那么两个世界的权限就是一样的了    你只要在想要删除权限的世界删除要权限就可以了
