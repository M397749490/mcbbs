零.准备

1.开服前提
会制作所有物品，了解所有生物，去过三界，死过N次，联机一段时间

建服要求至英语的语言能力，以及一定的JAVA理解能力，独立自助自学的能力也是需要的

小型服（1~20人）——家用机就可以满足，2GB内存，10MB光纤相信对游戏玩家不是问题；
中型服（20~100人）——这就需要服务器了，无收入人士还是建小型服或者去玩别人的服吧；
大型服（100人+）——需要专业服务器，大流量光纤，非常烧钱

你需要有充足的时间，如果是毕业考什么在即的，还是不要开服吧

2.开服准备
JRE（Java Runtime Environment - Java运行环境）
如你所知，客户端是JAVA程序，服务器也是JAVA程序。

第一章，开服
1，服务端建立
打开网址 http://dl.bukkit.org/
下载最后一个正式版服务端

或者最后一个测试版服务端
或者点击这个链接查看全部服务端（不推荐）
下载好后请不要解压
然后在相同的文件夹下创建一个文本文档

内容为
@echo off
java -Xms1024M -Xmx1024M -jar craftbukkit.jar -o falsepause
接下来是解释
第一行是关闭输出 既不会输出C:\Users\Administrator>
第二行启动java 1g是分配的内存 注意-o false 这里控制了时候使用在线模式 即正版验证
craftbukkit-1.4.7-R1.0.jar 是你刚才下载了的jar的文件名
第三行，需要在控制台中按空格才关闭
最后，将这个文本文档重命名为run.bat
到此为止，一个服务端已经建立完成
双击这个bat服务器就已经启动了，控制台窗口中出现了“Done!”的字样，则说明你服务器已建立完毕。
你可以打开同版本的mc 客户端，在服务器ip里叔叔127.0.0.1或者0就可以先预览自己的服务器了
然后，每次记得打指令stop关服，等到控制台显示 请按任意键……时方可关闭

2.2服务器结构服务器运行关闭后，将会出现以下文件和文件夹
server.log 服务器日志，所有在控制台中显示的内容里面都会保存 具体内容在2.3说明
server.properties 服务器设置 具体内容在2.4说明
plugins 插件文件夹 第二章详解
world 世界
world_nether地狱
world_the_end末地
banned-ips.txt被封禁的ip
banned-players.txt被封禁的玩家
bukkit.yml这是Bukkit的主配置文件。具体内容在2.4说明
permissions.yml 无需理会，用插件groupmanager代替（http://www.mcbbs.net/thread-52522-1-1.html）
help.yml 默认系统指令
ops.txt op列表
white-list.txt 白名单 未开启白名单无需理会

2.4服务端配置

  • #Minecraft 服务器设置文件 此类型文件不支持中文，本内容仅供作为说明，true代表执行，false代表不执行
  • #Sun Mar 11 18:24:34 CST 2012 此为文件生成时间
  • # 是否开启地狱，不开启话地狱门将无效
  • allow-nether=true
  • # 地图文件夹名称，下界与末路之地将会自动以nether,ender加上并用下划线隔开，推荐world
  • level-name=world
  • # 是否开启GameSpy4协议服务器监听器，用于获取服务器信息。目测国内用不上。
  • enable-query=false
  • # 是否允许飞行，于指令/fly无关
  • allow-flight=false
  • # 远程访问服务器的密码，此项可以留空或删除
  • rcon.password=
  • # 服务器端口（25565为默认端口，联机时无需输入）
  • server-port=25565
  • # 地图类型，Default=默认，FLAT=超平坦，LARGEBIOMES=巨型生物群系
  • level-type=DEFAULT
  • # 是否开启远程访问服务器控制台。技术人员可选。
  • enable-rcon=false
  • # 地图种子，在生成地图文件夹之前填入此项，可生成特定的地图，不填写随机
  • level-seed=
  • # 服务器IP，不输入则为默认IP，内网用户的话请填内网IP，hamachi用户填写hamachi-ip
  • server-ip=
  • # 最大建筑高度，上限是256，因为Chunk的高度最大值是256
  • max-build-height=256
  • # 是否生成NPC
  • spawn-npcs=true
  • # 是否开启白名单，没有白名单的玩家尝试进入服务器会被自动拒绝
  • white-list=false
  • # 是否生成动物
  • spawn-animals=true
  • # 此处填写服务器默认材质下载链接，链接必须以.zip结尾
  • texture-pack=
  • # 用于给http://snoop.minecraft.net网站发送服务器数据，这样玩家可以从客户端上获取服务器信息，目测也没人看，推荐关闭
  • snooper-enabled=false
  • # 是否开启极限模式，玩家死亡将自动被ban
  • hardcore=false
  • # 是否开启联网模式，盗版改false否则会出现bad login，不过，记得修改bat
  • online-mode=false
  • # 是否开启PVP
  • pvp=true
  • # 游戏难度，与单机相同1-10
  • difficulty=1
  • # 玩家第一次进入游戏时的游戏模式 0生存，1创造，2冒险
  • gamemode=0
  • # 同时在线的最大玩家数，提升玩家数时请到bat中修改相应内存
  • max-players=20
  • # 远程访问服务器的端口号，此项可以留空或删除，25565是默认端口
  • rcon.port=25575
  • # 是否生成怪物
  • spawn-monsters=true
  • # 是否生成建筑物（包括村庄和地牢）
  • generate-structures=true
  • # 可见距离，最大值为10
  • view-distance=10
  • # 服务器欢迎信息（显示在玩家联机页面），中文需中文补丁支持和转码，或者使用插件 推荐yulemotd（http://www.mcbbs.net/thread-73399-1-1.html）
  • motd=A Minecraft Server
