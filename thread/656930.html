这个插件在@1350837713的帖子里最高只有1.7.9-1.8.1的版本,已经老的不行了。为了我们愉快的玩耍，今天我去国外原帖看了看，发现更新到了1.11版本于是我就赶紧搬了过来......
1.12版本已更新，连接补上

指令和权限指令和权限（因为差不大多，所以借用下他的）：

玩家：

/pb help
显示帮助页面
– paintball.general
/pb lobby
加入大厅

/pb blue
加入蓝队

/pb red
加入红队

/pb random
随机加入队伍

/pb spec
加入观察者

/pb leave
离开队伍，如果不在队伍内离开游戏

/pb toggle
是否启用小游戏内的提示信息

/pb shop [id]
购买加强以及额外补给物品等
– paintball.shop.not<id>
/pb stats
显示你的数据

/pb rank
显示你的排名

/pb top
根据分数显示前十位玩家

/pb cash
显示小游戏内的资金

管理员：

/pb admin
显示管理员帮助指令
– paintball.admin
/pb admin reload
重新载入插件并将所有玩家从游戏和大厅内移出

/pb admin softreload
等待所有游戏结束之后重新载入插件

/pb disable
设置是否允许新游戏进行

/pb admin lobby spawn
设置一个大厅出生点

/pb admin lobby remove
移除大厅出生点

/pb admin next <arena>
强制进入下一个竞技场

/pb admin cash <player> [amount]
显示玩家金钱，加上后续参数即为给他那么多金钱


/pb admin rank <player> [amount]
显示玩家排名，加上后续参数即为给他点数

/pb admin reset <all/player> [value]
重置所有玩家或特定玩家的所有数据或特定数据

/pb admin helmet <blue/red/spec>
将队伍的帽子改为你手中正在拿着的物品

竞技场：

/pb arena
显示竞技场帮助页
– paintball.arena
/pb arena <name>
创建一个新的竞技场

/pb arena <name> blue
创建蓝队出生点

/pb arena <name> red
创建红队出生点

/pb arena <name> spec
创建观察者出生点

/pb arena <name> remove
删除竞技场

/pb arena <name> delblue
删除蓝队出生点

/pb arena <name> delred
删除红队出生点

/pb arena <name> delspec
删除观察者出生点

/pb arena <name> size <number>
定义竞技场的大小（暂时无用）

/pb arena info <name>
获取竞技场的信息

/pb arena list
获取竞技场的列表
