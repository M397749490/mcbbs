如题，LuckPerms如何给予玩家临时权限/权限组
作者: xmdhs    时间: 2019-7-17 18:54
本帖最后由 xmdhs 于 2019-7-17 18:57 编辑

/lp user xmdhs permission settemp * true 1d

* 填你想给的权限

xmdhs 填玩家名

1d 填时间

/lp user 玩家名 parent addtemp 权限组 10d

这个是给临时组
