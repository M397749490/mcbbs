Chat Guard---聊天警卫
Chat Guard插件简介
   Chat Guard可以使玩家在聊天中无法刷屏，无法说脏话，无法发送垃圾邮件包括{/msg /mail等等}，无法说出敏感词，非法指令等等
   我们可以配置相对应的惩罚and警告，配置非法的语言。玩家到一定量时就会受到惩罚[如/kick /kill /mute等等]
     新效果 全员禁言，清理聊天面板，禁言加理由。
图示:
          {管理员}我下线
           {玩家A}哈哈 管理员终于走了
           {玩家B}哪又怎么样
           {玩家A}垃圾 有种来PK  [垃圾为敏感词]
          {系统}警告玩家A 出现非法字体 请注意
           {玩家A}额 我去草你蛋 ...  [等等非法字体]
          {系统}/kick 玩家A 非法字体过多 [我们可以设置惩罚 ban一定的时间也可以设置]


特性:
  • 刷屏警告预防
  • 敏感词的预防
  • 不良字的预防
  • 非法广告预防
  • 对警告者通知管理员
  • 聊天清洁
  • 全员禁言
  • 清理聊天面板
  • 您可以用任何指令来惩罚
  • 玩家得到警告
  • 删除无效的词
  • 增加白名单
  • 检查更新(在配置可以禁用)



指令[含2种]

                     指令                                                        作用

  • /cg ban 文字          /cg add 文字                         设置文字为不良词
  • /cg unban 文字     /cg remove 文字                   删除文字为不良词
  •               /cg whiterlist 文字                                 设置文字为白名单
  • /cg info 玩家          /cg warns 玩家         查看这个玩家被警告的信息
  •               /cg cc 玩家                                清理这个玩家的聊天面板
  •               /cg cc all                                    清理所有玩家的聊天面板
  •               /cg globalmute                                    全员禁言[2次为关闭]
  •       /cg mute 玩家 禁言时间 理由                          禁言玩家有理由
  •       /cg unmute 玩家                                           解除对玩家的禁言
  •       /cg warn 玩家 警告类型                                  警告一个玩家
  •      /cg  clear 警告理由 玩家                              明确警告一个玩家
  •       /cg addwarn 玩家                                         增加玩家警告次数
  •      /cg removewarn 玩家                                    删除玩家警告次数
  •      /cg list                                                 查看所有玩家警告信息
  •      /cg reload                                                     重新启动插件
  •     注意：蓝色字为1.8.1和1.7.2版本使用
  •               绿色字为其他版本使用
  •               红色字为通用     


权限
chatguard。*        完全访问!
chatguard.banword                添加文字权限
chatguard.unbanword            删除文字权限
chatguard.warn                      警告指令权限
chatguard.mute                      禁言权限
chatguard.unmute                  关闭禁言权限
chatguard.whitelist                  白名单的权限
chatguard.clearwarnings         明确的警告权限
chatguard.info                        查看信息权限
chatguard.info.others             看其他玩家的信息权限
chatguard.inform。                 (刷屏、垃圾邮件、脏话) 接收警报
chatguard.clearchat               / cg cc commad chatguard.
clearchat.all                            清理所有玩家聊天的面板权限
chatguard.clearchat.others             使用清洁的聊天权限
chatguard.globalmute                      全员禁言权限
chatguard.reload                             重新加载权限
chatguard.ignore。*                        忽略所有的保护
chatguard.ignore。                    忽略(刷屏、垃圾邮件、脏话)的保护
chatguard.ignore.globalmute             忽视全员禁言权限
chatguard.ignore.cooldown               忽略冷却时间
chatguard.ignore.cc                          忽略被清理面板权限
