第三章 – 为你的方块和物品加上材质
大家好，今天我给大家带来基于Forge 1.8.0的Mod 开发教程。鉴于目前基础教程过多，本教程不会从Java基础讲起，也不会讲解Forge环境搭建。如果没有Java基础，请先看看别的大触的基础教程，再来学习这个。

首先，我们打开上节课写的代码。上节课我们讲了方块和物品的添加方法，这节课，我将会教物品和方块的模型&材质的添加方法。

熟为人知，1.8的材质方面改动极大，原本的一行代码变成了许许多多的代码！(不是在吓人..其实弄懂就觉得不难的了)

我们进入主题, 这节课我们在代码部分会讲的少, 模型文件的代码(.json)会讲的多一些.

首先我们先为物品加上材质, 我们创建一个json. 1.8以后的材质&模型必须得写json! 这就是1.8mod制作的繁琐之一.  我们在src/main/resources中建立assets.rubycraft.models.item包, 创建一个 json名为“ruby.json”.
写下面的内容:

  1. {
  2.     "parent": "builtin/generated",
  3.     "textures": {
  4.         "layer0": "rubycraft:items/ruby"
  5.     },
  6.     "display": {
  7.         "thirdperson": {
  8.             "rotation": [ -90, 0, 0 ],
  9.             "translation": [ 0, 1, -3 ],
  10.             "scale": [ 0.55, 0.55, 0.55 ]
  11.          },
  12.          "firstperson": {
  13.             "rotation": [ 0, -135, 25 ],
  14.             "translation": [ 0, 4, 2 ],
  15.             "scale": [ 1.7, 1.7, 1.7 ]
  16.          }
  17.     }
  18. }
复制代码


layer0": "rubycraft:items/ruby"  的填写规则是:
layer0": "[modid]:items/[itemname]"

其他没有什么好多说的, 就是调整位置.
接下来我们在FMLInitializationEvent(load处,与之前不同,注意!!)处添加以下代码:

  1. if(event.getSide().isClient()){//是客户端在执行吗?
  2.                 Minecraft.getMinecraft().getRenderItem().getItemModelMesher().register(ruby, 0,
  3.                 new ModelResourceLocation("rubycraft:ruby", "inventory"));
  4.                 ModelBakery.addVariantName(ruby, "rubycraft:ruby");
  5.         }
复制代码
需要导入的类:

  1. net.minecraft.client.Minecraft;
  2. net.minecraft.client.resources.model.ModelBakery;
  3. net.minecraft.client.resources.model.ModelResourceLocation;
复制代码


       1.8的模型注册是只能客户端执行的, 服务器执行就会报错, 所以我们需要判断是否客户端在执行这段代码. 判断方法: 一是上方

  1. if(event.getSide().isClient()){
  2. }
复制代码

不过这个方法很笨,我们一般使用proxy来进行客户端服务端判断, 不过关于proxy的我会在后文讲解,现在读者只需要使用上方的方法进行判断.
中间2行是注册模型的代码. 第2行 中的
  1. Minecraft.getMinecraft().getRenderItem().getItemModelMesher().register(ruby, 0,
  2. new ModelResourceLocation("rubycraft:ruby", "inventory"));
复制代码

ruby是一个Item类, 0不变更
"rubycraft:ruby" 填写规则为 "[modid]:[itemname]"  ,"inventory" 不变更.
第三行:

  1. ModelBakery.addVariantName(ruby, "rubycraft:ruby");
复制代码
ruby是一个Item类, "rubycraft:ruby" 填写规则为 "[modid]:[itemname]"

接着, 创建assets.rubycraft.textures.items包, 把材质ruby.png放进其中即可.

现在我们来添加方块的材质.
我们在src/main/resources中建立assets.rubycraft.blockstates包, 创建一个 json名为 “ruby_ore.json”.
写以下内容:

  1. {
  2.     "variants": {
  3.         "normal": {
  4.             "model": "rubycraft:ruby_ore"
  5.         }
  6.     }
  7. }
复制代码

"model": "rubycraft:ruby_ore"书写规则是"[modid]:[blockname] "
       1.8中出现了BlockState ，这个BlockState可以抽象地解释为"方块状态"。
例子：我们知道土豆生长有4个阶段
这4个阶段就是一个BlockState
可以把许多个Property插入BlockState，Property分为若干种 方块朝向/植物生成阶段等.
这个Block是个普通的Block ，没有任何BlockState，我们直接在variants中写normal就可以了
接着建立assets.rubycraft.models.block包，创建一个 json名为“ruby_ore.json”.
写以下内容:

  1. {
  2.     "parent": "block/cube_all",
  3.     "textures": {
  4.         "all": "rubycraft:blocks/ruby_ore"
  5.     }
  6. }
复制代码

"all": "ruby:blocks/ruby_ore"书写规则是"[modid]:blocks/[blockname] "
再在assets.rubycraft.models.item包内创建一个 json名为“ruby_ore.json”.
写以下内容:

  1. {
  2.     "parent": "rubycraft:block/ruby_ore",
  3.     "display": {
  4.         "thirdperson": {
  5.             "rotation": [ 10, -45, 170 ],
  6.             "translation": [ 0, 1.5, -2.75 ],
  7.             "scale": [ 0.375, 0.375, 0.375 ]
  8.         }
  9.     }
  10. }
复制代码


"parent": "rubycraft:block/ruby_ore",书写规则是"[modid]:[blockname] "
然后我们在FMLInitializationEvent(load处,与之前不同,注意!!但是与物品材质注册相同位置)处的if(event.getSide().isClient()){ 添加以下代码:
      
  1.       Minecraft.getMinecraft().getRenderItem().getItemModelMesher().register(Item.getItemFromBlock(ruby_ore), 0,
  2. new ModelResourceLocation("rubycraft:ruby_ore", "inventory"));
复制代码

ruby_ore是Item，"rubycraft:ruby_ore",书写规则是"[modid]:[blockname] "
其他数据不变更.
然后创建assets.rubycraft.textures.blocks包, 把材质ruby_ore.png放进其中即可.
