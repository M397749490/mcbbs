不要插件！不要MOD！
只使用原版指令！
版本：1.13以上和1.13以下的两种版本
如题，我需要制作一个伐木工的成就
挖100个木头系统会提示：恭喜你完成成就伐木工[1]
奖励1把铁斧并直接放在背包
制作思路是有的，首先用计分板里面的变量使玩家破坏橡木等木头加分，然后用计分板里的operation相加其他种类木头分数至破坏橡木分数里
最后检测并给予铁斧
但主要是破坏方块的变量我不知道，百度查不出来
或者用一种类似的变量替代
跪求大佬解答！(解答附全指令)

这玩意要弄文件

但这是原版的唯一方法

如果不弄文件，估计只能用计分板检测判断分数，然后用tellraw仿一个聊天框的输出了，再加tag做标记

tellraw示例：
  1. /tellraw @a {"translate":"chat.type.advancement.task","with":[{"selector":"@p"},{"text":"[伐木工]","color":"green","hoverEvent":{"action":"show_text","value":{"text":"伐木工\n破坏100个原木方块","color":"green"}}}]}
  2. /tellraw @a {"translate":"chat.type.advancement.challenge","with":[{"selector":"@p"},{"text":"[伐木工]","color":"green","hoverEvent":{"action":"show_text","value":{"text":"伐木工\n破坏100个原木方块","color":"green"}}}]}
  3. /tellraw @a {"translate":"chat.type.advancement.goal","with":[{"selector":"@p"},{"text":"[伐木工]","color":"dark_purple","hoverEvent":{"action":"show_text","value":{"text":"伐木工\n破坏100个原木方块","color":"dark_purple"}}}]}

复制代码
以上命令1.11及以前版本有效

以你要求的进度为例的全命令（版本：1.13）
  1. scoreboard objectives add oaklog minecraft.mined:minecraft.oak_log
  2. scoreboard objectives add sprucelog minecraft.mined:minecraft.spruce_log
  3. scoreboard objectives add birchlog minecraft.mined:minecraft.birch_log
  4. scoreboard objectives add junglelog minecraft.mined:minecraft.jungle_log
  5. scoreboard objectives add acacialog minecraft.mined:minecraft.acacia_log
  6. scoreboard objectives add darkoaklog minecraft.mined:minecraft.dark_oak_log
复制代码
以上命令执行一次
  1. #分数计算
  2. execute as @a[scores={sprucelog=1..}] run scoreboard players operation @s oaklog += @s sprucelog
  3. execute as @a[scores={sprucelog=1..}] run scoreboard players reset @s sprucelog
  4. execute as @a[scores={birchlog=1..}] run scoreboard players operation @s oaklog += @s birchlog
  5. execute as @a[scores={birchlog=1..}] run scoreboard players reset @s birchlog
  6. execute as @a[scores={junglelog=1..}] run scoreboard players operation @s oaklog += @s junglelog
  7. execute as @a[scores={junglelog=1..}] run scoreboard players reset @s junglelog
  8. execute as @a[scores={acacialog=1..}] run scoreboard players operation @s oaklog += @s acacialog
  9. execute as @a[scores={acacialog=1..}] run scoreboard players reset @s acacialog
  10. execute as @a[scores={darkoaklog=1..}] run scoreboard players operation @s oaklog += @s darkoaklog
  11. execute as @a[scores={darkoaklog=1..}] run scoreboard players reset @s darkoaklog
  12. #达成判定
  13. execute as @a[tag=!loggers,scores={oaklog=100..}] run tellraw @a {"translate":"chat.type.advancement.task","with":[{"selector":"@s"},{"text":"[伐木工]","color":"green","hoverEvent":{"action":"show_text","value":{"text":"伐木工\n破坏100个原木方块","color":"green"}}}]}
  14. give @a[tag=!loggers,scores={oaklog=100..}] iron_axe
  15. tag @a[tag=!loggers,scores={oaklog=100..}] add loggers
复制代码
这些命令循环激活
