LuckyBlock






幸运方块插件！


这款插件可以设置的掉落物品：





- LuckyBlock item/block       幸运物品

- Amount                                    数量

- Private message                  私人消息提示


- Broadcast message              全服通告               


- Command                                指令

- Enchant                                    附魔

- Potion effect                          药水效果

- Entity spawn                          生物

- Sound                                      音效

- Extra thinks (TNT, THE_KILLER_BUNNY) 额外详细：如TNT啥的

- Particle effect                     粒子效果

- Configurable percentual chance

掉落几率

- Enable/Disable in creative mode  

掉落模式（生存和创造）



命令：

- /lblock reload - 重新加载插件

- /lblock author - Display a author of LuckyBlock plugin.
- /lblock version - Display version of plugin.
