如何配置不计算y轴
作者: 浅念哥    时间: 2017-10-19 15:10
打开领地插件的config.yml，搜索"Selection:"
  1.   Selection:
  2.     # 如果设置为true，则高度是从基岩到天空(即忽略Y坐标大小)
  3.     IgnoreY: false
  4.     # 如果设置为true，则玩家只需要支付X/Z方块的价钱，无视高度
  5.     # 这会使领地价格降低至256倍多，因此在设置选项时要调整价格
  6.     NoCostForYBlocks: false
