By default, Marriage will check for updates from bukkitdev every 3 hours.
This feature can be disabled by setting "updater.enabled" to "false"
Anyone with the permission node marry.update will be notified of updates, and it also able to download them via /marry update.
Which again can be disabled by disabling the update-checker

命令:
  1. /marry gift -送礼物给妻子lol
  2. /marry gender -指定性别
  3. /marry <player> -向玩家求婚
  4. /marry pvp -开启或者关闭PVP(夫妻之间)
  5. /marry list [页数] -列出所有结婚了的人
  6. /marry seen -查看另一半什么时候下线的
  7. /marry home -传送到你们的家庭
  8. /marry sethome -设置你们的家庭
  9. /marry chat -启用夫妻聊天模式
  10. /marry divorce -离婚（baga）
  11. /marry tp -传送到另一半身边
  12. /marry reload -重载配置文件

  1. marry.* -插件所有权限
  2. marry.tp -强制tp到另一半权限
  3. marry.sethome -设置家庭权限
  4. marry.home -传送到家庭权限
  5. marry.gift -送礼物权限
  6. marry.seen -查看另一半什么时候下线权限
  7. marry.marry -向其他玩家求婚权限
  8. marry.admin -管理员权限
  9. marry.chat -夫妻聊天权限(好像别人看不见吧)
  10. marry.default -和marry.* 一样
  11. marry.chatspy -监视夫妻聊天权限
  12. marry.divorce -让玩家离婚权限
