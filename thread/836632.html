标题: 如何使用GroupManager来设置不同世界不同权限
如题
使用GroupManager这款插件
在不一样的世界
设置不一样的权限
作者: qsefthuopq    时间: 2019-1-5 15:15
如果没有该世界的配置文件的话在GroupManager\worlds内 新建名为该世界名的文件夹
将world主世界的group.yml复制进去并修改权限
然后修改config.yml
  1.   mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds:
  16.           - users
  17.           - groups
  18.         世界名:      (与world对齐)
  19.           - users   
  20.           - groups
