目前没有直接探测使用指令的，你是单人还是多人？

怎么没有了,适用于1.8以后。先创建一个计分板
  1. /scoreboard objectives add command dummy
复制代码

然后放一个rcb高频，将使用指令次数转移到计分板上
  1. /stats entity @a set SuccessCount @a command
复制代码

然后要先把玩家的command计分板清零
  1. /scoreboard players set @a command 0
复制代码

然后只要玩家成功执行指令，command计分板的分数就会变成1
接下来要干什么就随你啦
