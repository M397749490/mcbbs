最近正在到处流浪找防矿追的东西,无意中就找到了

什么是X-Ray
  • 防X射线(Anti X-Ray)相信大家多少知道一点关于“X-Ray”的事情吧
  • 这是一个透视外挂，中文译为“X射线”
  • 不少服主已经很早就已经开始蛋疼因为太多人开透视自己都不知道(如果你服不让开透视挖矿的话)
  • 这个插件也许就能帮到你


作用
  • 监视玩家挖矿
  • 限制挖矿数量
  • 限制挖矿速度过快暂时不能，并通知OP


配置文件AntiXRay:
  1.   EnableMetricsTracking: true
  2.   NewPlayerStartingPoints: -400
  3.   PointsEarnedPerHourPlayed: 800
  4.   MaximumPoints: 1600
  5.   IgnoreMaxPointsForBlockRatio: true
  6.   ExemptCreativeModePlayers: true
  7.   NotifyOnMiningLimitReached: false
  8.   DefaultMaxHeight: 63
  9.   ProtectedBlockValues:
  10.     EMERALD_ORE:
  11.       Value: 50
  12.       MaxHeight: 35
  13.     DIAMOND_ORE:
  14.       Value: 100
  15.       MaxHeight: 20
  16.   Worlds:
  17.     world: ''
  18.     world_nether:
  19.       DefaultMaxHeight: 256
  20.     world_the_end:
  21.       DefaultMaxHeight: 256
复制代码



指令
/antixray help 显示所有指令
/antixray reload 重新加载插件
/antixray check [player] 检查他们目前挖矿的数量已达到限制他们的目的
/antixray set <player> <points|counter> <valuer> 设置他们挖矿的数量



权限
antixray.monitorxrayers（默认：OP）玩家将得到通知，当一个玩家已经达到了他的挖矿的数量，并通知。
antixray.bypass（默认：关闭）允许玩家自由开采任何块不被反X射线检查。
antixray.help（默认：关闭）允许玩家查看帮助页面，其中包含有关命令
antixray.reload（默认值：OP）允许一个玩家重新加载antix-ray的的配置和消息文件。
antixray.check.self（默认：OP）允许玩家查看他的剩余挖矿的数量。
antixray.check.others（默认：OP）允许玩家查看其他玩家剩余挖矿的数量。
