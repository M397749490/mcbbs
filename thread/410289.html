作者: RaycusMX    时间: 2015-2-16 14:17
你可以在禁止pvp枪战的地方圈上领地，设置 /res set pvp f 以及 /res set damage f 这样领地内玩家不受任何伤害。地图爆炸可以用 AntiCreeper 插件来防止，配置后可以防止Flan爆炸、武器mod爆炸、竹mod爆炸、插件爆炸等等各种爆炸，而且保留爆炸的动画效果和伤害。
