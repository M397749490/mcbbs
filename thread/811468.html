+——Lobby Reloaded——+

让你的大厅五彩缤纷





简介

LobbyReloaded是我在spigot上发现的一个插件

这是一个十分强大的大厅管理插件

能为你的大厅增添许多色彩





特点(高能谨慎展开)


  • 大厅自动公告
  • 大厅重生点设置
  • 大厅区域保护
  • 大厅TAB系统
  • 大厅欢迎标题
  • 大厅趣味道具
  • 大厅宠物
  • 大厅每日礼包
  • 大厅粒子特效
  • 大厅进♂出公告
  • SQL支持(可能会有BUG)
  • 大厅血条(可能需要BAR API)
  • 大厅计分板
  • 大厅传送器
  • 大厅玩家可见/不可见设置
  • 飞行控制
  • 建筑控制
  • 私人大厅(类似于hypixel长期静止不动时自动移动到一个小房间的功能)
  • ping随时查询
  • 隐身
  • ....累到我都不想写了






指令&权限


  • /lobby|主命令
  • /lobby setspawn|设置大厅出生点
  • /lobby setloc1|设置大厅区域点1
  • /lobby setloc2|设置大厅区域点2
  • /lobby wand|获取选区工具
  • /lobby inv|打开配置仓库
  • /lobby sorttp|Opens an Inventory to sort the tp inventory(WTF？)
  • /lobby addtp <名称>|在你的位置上新建一个TP地标
  • /lobby removetp <名称>|删除一个指定的TP地标
  • /lobby reload|重启插件
  • /lobby setdailyrewards|设置一个每日奖励村民
  • /lobby removeDailyreward|删除每日奖励村民
  • 以上命令权限:lobby.admin

  • /pet|打开宠物菜单
  • /armor|打开装备菜单
  • /fly|飞行~
  • /silentHub|进入私人大厅
  • /msg <玩家> <消息>|发送私人消息
  • /motd set <motd>
