监狱风云の玩法

估计也有很多人玩过监狱风云，这个介绍仅给刚入门的腐竹/没玩过的小白看
有人说这个是小游戏，其实严格意义上来讲不算是，因为占有的生存元素很多
这个也在国外是一个很火的PVP类生存型服务器
监狱风云，顾名思义就是把你扔到监狱去劳改，经历长时间的挖矿来赚钱
初次进入游戏会发给你一套劳改工具与装备，让你去挖矿，然后再将矿物卖钱
慢慢攒钱，直至升级，从最初的"普通囚犯"最后成为"罪大恶极"
原作者特别声明

在您下载/使用本服务端之前需要同意以下几点：
伸手党不知道的:
监狱基础指令讲解：
/res info 查看领地信息
/resadmin message enter(进入),leave(离开),remove( 移除) 设置当前所在领地的进入/离开或移除消息提示
resadmin setowner 领地英文名名字 id  将一个领地强制给一个人
/resadmin create 领地名字  无视领地大小限制直接用管理权限创建领地
/Shopkeepers 生成自定义村民
                /manudel id 把一个玩家恢复为默认权限组
/mines list 矿场列表
                                   /mines addblock 矿场名 方块id 几率     设置方块在矿区刷出比例
      /mines create 名字   创建一个矿场 【需要木斧选点】
/mines delete 矿场名 删除一个矿场
/mines redefine 矿场名 重新划定矿场区域
/mines reset 刷新矿场的矿物
/mines removeblock 矿场名 方块id  删除方块在矿场的生成\
/npc create 名字 创建一个npc
/npc select 序号 进入选定npc
/npc addcmd false noperm 指令    给NPC绑定指令
/npc resetcmds 删除选定NPC所有指令
/baoshi 宝石id 宝石等级 玩家id 给予玩家x级宝石宝石id：1=青磷石 2=落风石 3=水夕石 4=烟云石 5=宝石粘合剂
/lore name 自定义名称  修改手中物品的名字
/lore undo 撤销更改
/lore owner 使用对象  更改物品的所有者
/lore add 文本/属性名字   给手中的物品添加文本/属性
/lore set 行数 行数内容 更改目标行数的描述/属性
/lore delete 行数 删除目标行数的内容
/lore clear 清除手中物品的所有描述和属性
/markitem 获得一个绑定花
/nj hand -1  设置为无限耐久
/pw <密码> 打开仓库
          /pw set <密码> 设置密码
          /pw change <旧密码> <新密码> 更改密码
          /pw upgrade 升级仓库容量
          /pw view <玩家名> 强制查看他人背包
          /pw reload 重载config.yml
/fx 维修装备
/garbagebin 打开垃圾桶
/Trails  打开特效菜单
