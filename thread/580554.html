[board]【The Introduction 简单介绍】[board]

  • 前言

此地图的产生源于我做的一个梦，这个梦在我脑海里逗留了整整一年。今天，这个梦终于要实现了。我很高兴为大家介绍Phain 菲恩- 古人的六边形棋盘游戏，耗时一年时间，约摸400多个小时！其中的地形是被一个称为《无尽传奇》的战略游戏所启发的。来，让我们一起来欣赏吧！

欢迎来到菲恩！





在“拉文”的四季圣灵的指引下，独行者游历到菲恩，发现这儿的大陆是由远古巨人为娱乐而创造的。在这里，他将求索以返回失去的家园“忒伊亚”。

  • 故事

亿万年前，菲恩只是一片普通的大陆。与此同时，在遥远的另一片大地上巨人正悄然崛起。这些强大的怪物不仅奴役人类，还践踏所有无法保护自己的生物。

巨人渴望有什么东西供它们娱乐，他们带着这个目标来到菲恩，在这里进行创造以满足他们的残虐。在这里，他们雕刻湖泊，挪移山川，直到整片土地成为了他们的游戏棋盘，供他们进行那些暴力的游戏。

所有创造完成后，巨人命人类在菲恩定居。几十年过去了，美丽的城镇，村庄，矿山和小路也渐渐出现在荒郊野外。

在菲恩的生活是美好，和平的，好景不长，巨人再次归来，开始玩他们自己的血腥游戏。在所有王国自认为闪耀光荣的战争中，人类在巨人的棋牌游戏上赫然成为了一兵一卒。这是没有幸存者的比赛。留下的只有死亡。

又是亿万年过去了。 菲恩现在已经面目全非，也不晓得有人知道，没有人居住于此，更没有人记得那些过去的日子。只剩下风萧轻轻耳语，那早已被人遗忘的充满惨叫的战争。


  • 概述

菲恩被古巨人建于亿万年前。它包含了4个区域，没有人知道这些区域的真实名字，所以我们可以简单地称他们为蓝冰，红日，黄麦和绿叶。

蓝冰是面积最大的，被厚厚的冰雪所覆盖。它为蓝坡。

红日是位于沙漠，热带草原，丛林和远古峡谷的潮湿地区。它为红坡。

绿叶里是各种各样森林和沼泽。它为绿坡。

黄麦是一个满是田野，花园和迷宫的地方，这一切都要归功于魔法。它为黄坡，而且是唯一毗邻所有其他区域的中心地带。

  • 地形指引

菲恩的地形与你之前所看到的其它地形大有不同，它主要是由六边形组成的。六边形区域的树木，岩石，草丛或山坡上相互分离。斜坡都装饰有特定的树木以分辨区域。麦黄和绿叶的为落叶林，红日的为棕榈树，蓝冰为雪松。

此地图共有4层高度。第一层永远都是海滩。层是由32方块高的斜坡分开。在层数间移动，你可以看到它们的梯度或连接顶端的巨梯。下面的图片可以更好地帮助你理解。

  • 制作看似不可能的地图：


1. Python

我脑海中的第一个问题就是，这个地图是否有建造出来的可能？答案是肯定的——但是与大多数自定义地形建筑师使用的工具所不同。菲恩的地形为六边形，无论是World Painter亦或是World Machine都不支持。那么怎么办呢？如果没有合适的软件，那我就必须自己做出软件来。

因为地图的信息都存储在高度图里，所以我不得不去创建一个生成器来生成六边形的高度图。听起来很简单对吧？但要做到这一点，我要使用Python编程语言，PIL库管理构图。我创建的程序会读取任何输入进去的高度图，并生成沿六边形的被岩石所覆盖的斜坡。做完后，就可以输入有趣的程序，生成六边形的高度图，并移动到下一个阶梯。程序生成的不同阶梯会用最大值函数相结合到一起，如下GIF图片所示。



2.World Machine

我程序生成高度图是很无聊的。所有的地形就只是山坡和平原。而我们还需要苔原，沙漠，田野，丘陵，岩石等。World Machine则可以实现这一目的。利用它我可以增加任何我想要的到之前生成的地形中去。但很不幸的是，WM地形适应到我的高度图中是个巨大的技术挑战，在经历了数小时的尝试和规划后才完成。它共有421个节点，利用了Python中我的程序，最后才在高度图的顶部成功生成地形。



3. World Painter

所以难点都已经突破了？不是，这才刚刚开始。此地图有923个六边形。 923块土地，这必须用某种工具来处理（你猜对了！），我无法在一定时间内独自一人建造。在建造数个小时后，我完成了超过200种不同的阶梯的WP文件。在那之后我得去检查每一棵树，东西，地形层是否位于正确的地方。

4. In-Game Editing 在游戏中编辑

前面的步骤也产生了一些形状不美观的地形漏洞，所以我要在我的世界里手动来解决这些问题。增加方尖碑之间的传送点则是我在这一阶段完成的另一件事情了。

5. Planet Minecraft 星球世界

而现在的这个地图被呈现到Planetminecraft上面。历时400小时的研究和建造后，终于将它完成。它是至今我所建造的最宏伟的艺术地图，也经历了最艰难的技术挑战。它可能耗费的时间很长，但成果永在。


  • 主要特点

生存地图，含洞穴，要塞，村庄和资源。

都是你在我的世界中从未见过的独特地形。

[powered_minecart]【The Installation 存档安装】[powered_minecart]
Save存档(正版用户):关闭Minecraft，在Windows开始菜单的搜索框中输入%appdata%/.minecraft，然后按下Enter（回车）按键。把从百度网盘下载回来的地图存档解压缩放到.minecraft\saves文件夹里面。
Schematics存档：这类型需要MCEdit。下载完成后解压到桌面，关闭Minecraft，双击mcedit.exe，点击下方import按钮，打开你下载的文件到你需要放的地方，最后点import，按Ctrl+s保存，Ctrl+w关掉存档，点Quit退出。
