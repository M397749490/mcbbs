  Minecraft绿叶家园服务器是一个纯净的插件服务器，服务器全服不掉落！绿叶家园服务器经过我们多次完善之后，增加了MD5验证系统，杜绝多数熊孩作弊。只有指定的客户端才能进入，一旦加入别的Mod，将不能够进入服务器。(需要加入别的Mod可以私聊腐竹进行增加)。
绿叶家园至今依然坚持纯净插件服，为的就是让玩家更方便地进入服务器进行游戏，享受最原版的MC。我们加入了大量的插件，有地皮、电梯、砍树、公会、结婚等插件，玩家可自行创建公会(前提是金币要够)，与公会成员一起游戏，一起挖矿，一起生存，(老司机还可以一起开车,啧啧)。其中砍树插件全体玩家都可以使用(命令/choptree <on/off>)，再也不用像单机一样要一个一个木头地撸了。
服务器不设Vip制度，大多数权限玩家都可以拥有，我们不出售飞行、创造，请勿私聊腐竹或者管理员进行购买权限，发现非法飞行的玩家我们一律采用永久封号。我们服务器的赞助来源为出售称号和各种付费道具，玩家可以购买多个自定义称号。[我们使用的是PrefixManager插件，可拥有多个称号]

の结婚插件の
/marry list - 显示所有结婚的人
/marry accept - 接受求婚
/marry <玩家> - 和他/她 求婚
/marry <玩家> <玩家> - 结合两个人 (只限牧师)
/marry deny - 拒绝求婚
/marry divorce <玩家> - 离婚
/marry sethome 设置你们的家
/marry tp 可以直接传送到自己伴侣的旁边 无需接受 (前提对方在线)
/marry home 传送到你们设置的家
/marry delhome 删除你们设置家的传送点
/marry chat 聊天内容 可以和你的伴侣进行私密聊天
/marry chat toggle进入伴侣私聊模式 输入之后下面输入的聊天内容都为伴侣私聊 再次输入切换回来
/marry gift 把你手中的物品送给你的伴侣 (伴侣背包要有空间 防止物品被挤刷)
/marry kiss 和你的伴侣亲亲?(? ???ω??? ?)? (两人站在离对方5格以内)

の登陆插件の
进入游戏后，按回车键输入/reg <密码> <密码>    进行注册
比如我要注册密码为12345，那么我就输入/reg 123456 123456   进行注册
登陆时输入/login 密码  进行登陆

の市场插件の

/market create 价格 数量    把手上的物品上架到市场
/market send 玩家名 数量    把手上的物品发送至另一玩家邮箱
/market mail            打开自己的邮箱
/market listings        打开市场
/market  history <数量> 查看交易历史

の地皮插件の

/plotme claim <player> 为别人认领你脚下的地皮
/plotme auto 自动认领顺序下一个地皮
/plotme home[:#] 设置家，如果你有多个
/plotme home:1会带你去1号地皮.
/plotme home:2 会带你去2号地皮.
/plotme list 列出你的地皮
/plotme list <player> 列出别人的地皮
/plotme info 列出你站在的地皮的信息(包括地皮id, 主人,地形, 日期, 结束 帮助).
/plotme comment <text> 评论一下（留言）到当前的地皮
/plotme comments 查看各种留言
/plotme biome 查看目前地形
/plotme biome <biome> 改变当前地皮的地形
/plotme biomelist 列出可设置地形
/plotme tp <id> 传送到某个地皮
/plotme id 查看当前地皮的id和坐标
/plotme clear 将地皮初始化到认领时候的样子（地形哦~慎用）
/plotme reset 还原地皮（慎用，解除占领的）
/plotme add <player> 给某个玩家在你地皮建造的权限
/plotme remove <player> 移除某个玩家在你地皮建造的权限
