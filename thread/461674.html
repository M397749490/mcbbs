一、条件语句 —— if
从字面上理解就是如果的意思，应该知道这个语句是做什么用的了吧？
条件判断相信大家都理解得到吧，假如说现在八点了，你得起床，条件就是当前时间是八点，要做的事就是起床。
我们先来看看if的用法：
  1. if(表达式) { 方法体 } else if(表达式) { 方法体 } else { 方法体 }
复制代码

方法体怎样才会被执行呢？当表达式的值为true是，就会执行方法体。
这里的else
if有3种用法:
  • if ...
  • if ... else ...
  • if ... else if ... else ...

拿实例说明一切～
我们先码一个if ..
  1. public class omg {
  2.     public static void main(String args[]) {
  3.         int i =233333;
  4.         if(i == 233333) {
  5.             System.out.println("23333333333333333333");
  6.         }
  7.     }
  8. }
复制代码

这里有个表达式是i == 233333，很显然此条件匹配，就会输出“23333333333333333333”，如果把变量i的值改动的话，这个程序就没有输出。
if ... else ...:
  1. public class omg {
  2.     public static void main(String args[]) {
  3.         int i =233336;
  4.         if(i == 233333) {
  5.             System.out.println("23333333333333333333");
  6.         } else {
  7.             System.out.println("变量i不等于233333.");
  8.         }
  9.     }
  10. }
复制代码

这里的表达式与上面是相同的，但是此表达式不匹配，就会执行else语句块。
来个有难度的:
  1. public class omg {
  2.     public static void main(String args[]) {
  3.         int i = 0;
  4.         if(i == 233333) {
  5.             System.out.println("23333333333333333333");
  6.         } else if(i < 0) {
  7.             System.out.println("变量i小于0.");
  8.         } else if(i > 0) {
  9.             System.out.println("变量i大于0.");
  10.         } else {
  11.             System.out.println("变量i等于0.");
  12.         }
  13.     }
  14. }
复制代码

二、分支语句 —— switch
switch语句和if语句是相似的，但是switch语句比if语句更优越，因为switch可以根据表达式的值判断要执行的代码块，不过switch语句比if语句复杂，但是有时switch比if可以减少掉许多代码。
switch语句的语法如下:
  1. switch(表达式) {
  2.     case 表达式的值1:
  3.         //方法体
  4.         break;
  5.     case 表达式的值2:
  6.         //方法体
  7.         break;
  8.     ......
  9.     default:
  10.    // 如果表达式与上述的值均不匹配，所执行的方法体
  11.    break;
  12. }
复制代码

注意：switch语句在执行时，即使遇到符合要求的case语句块，也会往下执行，所以一定要在每个case语句的末尾加上break以免浪费时间和资源。大家可以试试去掉break会怎么样。在本章的后部分会详解break等语句的作用。
直接上实例:
  1. public class omg {
  2.     public static void main(String args[]) {
  3.         String week = "星期二";
  4.         switch(week) {
  5.             case "星期一" :
  6.                 System.out.println("今天是星期一，新的一周开始了");
  7.                 break;
  8.             case "星期二" :
  9.                 System.out.println("今天是星期二，沉着冷静面对工作～");
  10.                 break;
  11.             case "星期三" :
  12.                 System.out.println("今天是星期三，迎接着朝阳，继续努力吧");
  13.                 break;
  14.             case "星期四" :
  15.                 System.out.println("今天是星期四，勤奋创造成绩哟");
  16.                 break;
  17.             case "星期五" :
  18.                 System.out.println("今天是星期五，给本周工作画上一个圆满的句号");
  19.                 break;
  20.             case "星期六" :
  21.                 System.out.println("今天是星期六，一觉睡到自然醒");
  22.                 break;
  23.             default :
  24.                 System.out.println("今天是" + week + "，好好得享受这一天～");
  25.                 break;
  26.         }
  27.     }
  28. }
复制代码

解析：week变量的值为“星期二”，匹配“case "星期二"”分支，执行此分支的代码.
