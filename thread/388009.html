简介

原网页的介绍啰啰嗦嗦写了好大一堆，下面的介绍是我自己重新编辑的，原内容请到原网址查看。

此插件已经发布新版本pre3.0，但是这个版本连作者本人都没有过多测试，而且还是一个pre版本，所以我没有更新，这里还是2.1版本

国内服务器大多数都是盗版服务器，为了账号安全都要安装Authme之类的账号管理插件，让玩家用/register、/login 之类的命令来登录，对正版玩家可能会造成一些麻烦。这个插件可以让正版玩家直接进入开启了各种登录插件的盗版服务器，无需/login 登录。适合半正版服务器使用。


  • 支持LogIt、Authme、xAuth作为登录插件
  • 支持ProtocolLib
  • 支持Bungee
  • 正版用户使用原有的UUID，而不是生成的UUID
  • 可以开启盗版用户黑/白名单
  • 可以要求正版玩家注册，但无需登录（当Mojang验证服务出问题时，玩家仍可以用/login 登录）
  • 可以根据IP地址在Mojang服务器异常时判断已登录过的正版玩家
  • 提供切换模式，此模式不接受新的盗版玩家（用于盗版服务器转正版）
  • 消息文本可配置
  • 提供插件开发API


注：实际测试，使用该插件会延长加入服务器时间，因为需要验证正版账号。玩家有可能会卡在“登入中”界面直至超时掉线。网络环境不好的服务器请酌情使用此插件。

命令

  1. /autoinlists 管理黑白名单
  2. /autoinstatus 查看玩家状态
  3. /autoinmanage 管理排除检查的玩家
  4. /autoinreload 重载插件

配置文件

重要提醒：如果你使用的是Spigot，那么请在spigot.yml里将late-bind设置为true，否则玩家有可能会在此插件运行之前进入游戏

个人表示，因为同样的原因，不要用/reload 命令或者/plugman reload 来重载此插件

插件实际的TryNumbers选项与官网的描述不符，因为这是2.1-fix.2版本的一个改动，官网描述没有改，所以应以此处为准

  1. Enabled: true #是否启用插件功能
  2. AutoLogin: true #正版玩家是否自动登录
  3. ProtocolLib: true #是否开启ProtocolLib支持
  4. FixedUUID: false #设为true则正版玩家仍然使用盗版UUID
  5. SkriptAPI: true #是否开启SkriptAPI
  6. OnlineModeFix: true #如果服务器在Offline模式，则这个需要设置为true
  7. MustRegister: true #正版玩家是否需要注册（以便验证出错时能登录）
  8. ServersDown_Protect: true #验证服务器出错时禁止新玩家加入
  9. ServersDown_IPCache: true #验证服务器出错时用以前的IP来验证正版
  10. LogItForceFix: true #修复LogIt在1.8的TabList问题
  11. TryNumbers: [1, 1, 1, 1, 0, 0] # 重试配置，这是一个含有0或1的列表，每一项都表示重试一次，0表示在minecraft.net验证，1表示在mojang.com验证
  12. OfflineWhiteListEnabled: false # 是否开启盗版白名单
  13. SwitchMode: false #是否开启切换模式
  14. Exceptions: [] # 排除检查的玩家
  15. EnabledLogin: [] # 强制登录的玩家
  16. Lists: # 黑白名单，以下两个是例子
  17.   player1: WHITE_LISTED
  18.   player2: BLACK_LISTED
  19. Messages: # 消息文本
  20.   AutoLogin: '&a检测到你为正版玩家，无需登录'
  21.   NoAutoLogin: ''
  22.   ForceRegister: '&c请注册！\n虽然检测到你是正版玩家，但当无法验证时\n你需要一个账号来加入游戏'
  23.   ServersDownProtect: '&c无法检测你是否为正版玩家\n请登录！'
  24.   ServersDownIPCached: '&a你曾经登录过该正版账号，无需登录'
  25.   ServersDownProtectNewPlayer: '&4验证服务器异常，暂不接受新玩家'
  26.   SwitchModeKick: '&4服务器已经转换为正版服务器，不接受新的非正版用户'
  27.   SwitchModeJoin: '&c服务器已经转换为正版服务器，老玩家请尽快购买正版账号'
  28.   PluginNotLoaded: '&4服务器启动未完成，请稍后重新登录'
  29. # 这三个是事件优先级设置，一般保持默认
  30. PlayerLoginEvent: LOWEST
  31. PlayerJoinEvent: LOWEST
  32. PlayerQuitEvent: MONITOR

针对盗版玩家的白名单使用方式：
打开“configguration”文件，第101行“CrackedWhiteListEnabled:”设置为true
此时任何盗版玩家还无法进入服务器，需要控制台输入以下【3条】指令：
（XXX为玩家ID，按顺序输入）
AutoIn setException XXX true
AutoIn setWhitelistStatus XXX white
AutoIn setEnabledLogin XXX true
输完后这个名为XXX的玩家就可以正常进入服务器了XD这个过程就是添加白名单，服务器自带的白名单和这个是不一样的，无法通用，未通过这个方式添加的盗版玩家无法进入服务器，可能提示【登入失败】
次白名单对正版玩家没有影响
