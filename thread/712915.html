标题: [安全]custombungee——限制连接服务器的版本[1.7-1.12]
本帖最后由 1582952890 于 2017-9-16 09:07 编辑




特征:
可以阻止不同版本的玩家连接
可以自定义踢出玩家的信息
可以通过修改配置文件配置命令


配置文件：
  1. # 显示无效版本
  2. NAME: "&5CustomBungee &cv1.8"
  3. # 版本不符合显示内容
  4. KICK: "&8[&5CustomBungee&8]\n\n&7Your &cversion&7 isn't allowed. \n&7Please use &c1.8"
  5. DESCRIPTION: "&7Server using &5CustomBungee&7.\n&7Your &cversion isn't allowed&7."
  6. #版本符合显示内容
  7. ALLOWED_DESCRIPTION: "&7Server using &5CustomBungee&7.\n&7Your &aversion is allowed&7."
  8. VERSIONS:
  9. - 47
  10. # 重载命令，没设置则无法加载插件
  11. COMMAND:
  12. # 重载名称
  13. NAME: custombungeereload
  14. # 重新加载权限
  15. PERMISSION: bungee.admin
  16. # 其他命令
  17. ALIASES:
  18.   - cbrl
  19.   - custombungeerl
  20. #重载提示内容
  21. SUCCESS: "&7CustomBungee's configuration &asuccessfuly &7reloaded"
复制代码
命令：自己配置默认/custombungeerl 重载
显示内容，可配置
权限：可配置，默认bungee.admin
