Description
Install this plugin if you want that you can hide under beds in minecraft. Place a hideable bed, sneak and rightclick on it to hide under it.
The question is not WHY. It is WHY NOT!Features
  • Set all beds hideable or only selected beds.
  • Sneak and Rightclick on the bed end to hide under it.
  • You are not visible for the other players.
  • You can get crushed when someone jumps on the bed.


                                                                                      Commands
  • /huab give <amount> - Gives a hideable bed.   给你一张可以盖上被子睡得床！

                                                                                      Permissions
  • HideUnderABed.placeBeds               Allows to use plugin commands and bed placing      
  •                                 允许你使用指令/huab give <amount>
  •     HideUnderABed.use                Allows to hide under beds.                                 
  •        允许你盖上被子睡觉

Config
special-Beds: true
是否开启专用的床（也就是上面的指令<` -`>）
blindness: true
#When this is true, hidden players will get blinded on hide.
是否开启睡后闭眼（也就是黑屏<'w '>）
crush-Jumps: true
#When this is true, players who hide under a bed get crushed when someone jumps or lys on the bed
当有人在床上跳时会进入睡觉状态<z . z>
