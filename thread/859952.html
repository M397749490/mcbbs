MultiRespawn
可以使玩家复活至最近复活点

命令
  • /spawn
  • /spawn set
  • /spawn remove
  • /spawn list
  • 在游戏中使用/sponge help spawn查看更多信息

权限
  • spawn.command.set
  • spawn.command.remove
  • spawn.command.list
  • spawn.command.use
  • spawn.set // 方块权限
  • spawn.remove

特性
  • 与指定方块的放置/破坏同步
  • 与Waystone同步
  • 与Nucleus地标同步
  • 会关闭Nucleus的复活模块

已知漏洞
  • 当你移动时放置传送石碑（Waystone），会导致复活点名称错误
