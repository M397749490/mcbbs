好吧，我这里需要的是默认权限nucleus setupperms user default。我找到了。然后增加某些权限是lp group default permission set 权限节点 ，指令的权限节点可以参考此链接http://www.mcbbs.net/thread-732446-1-1.html。然后/nucleus setupperms <Nucleus Role> <Permission Group>意思是添加某个权限组的权限给某些人群，这个指令<Nucleus Role>是指人群，而人群有user mod 和admin让普通玩家获得权限填user就好了。注意的是权限节点是被权限组包含在内的。需要创建权限组将权限节点放入【如nucleus.suicide.exempt.cooldown就是权限节点】。意即为nucleus setupperms user只是添加权限组，可你并没有权限组，你需要创建权限组，然后将权限节点用lp group default permission set 【权限节点】放入。建议lp group default permission set 【权限节点】default为默认权限组，所以不需要创建
