■历史前言(留个纪念)■

2015年7月9日 更新v1.3 工业科技整合包发布
不管期间经历了如何如何，就像是看着田里的的一片片谷物都黄澄澄的，一个多星期为了一个整合包，翻帖子看攻略翻译汉化做测试，到现在终于可以松一口气写一下感言了。
其实也没有什么感言了，能看到你在玩过整合包之后觉得这包不错的回复（当然还有评分啦），楼主就觉得非常开心了，也就因为这样，希望能在有限的时间里把整合包做得更好，楼主就这样的一个人。
其实在做整合包的时候看到一个个mod别出心裁的精彩创意，也是一种乐趣，当然同时希望能把这种乐趣传递给屏幕前的你。
简单说明一下，本帖依旧是主阵地，不久之后还会在这里更新1.8的整合包为跳出旧版整合包之深渊而奋斗，遥遥整合1.x版本（异度之遥）和2.x版本（工业城市）只是基础模组部分相同，会同步更新。
最后再说一下更名。名不正则言不顺，现在有逐渐发展成为系列整合趋向，防止造成混乱，因此更名异度之遥。这个名字是楼主的好朋友733（萌货一只，是个很强的画师哦）刚好在听异度之刃的歌曲（楼主没听过），然后就说了这样的一个名字，刚好楼主整合包里是有一把异度之刃[卡通武器]的，加上“异度”本身有异次元/维度的意思，“遥”是楼主的昵称，又有遥远之意，一语双关，天作之合。
最后，请愉快的食用“遥遥整合-异度之遥v1.3”吧，如果你是v1.2.2版本的用户，可以直接下载升级包进行升级，升级前记得备份存档哦~

2015年6月24日 整合包全面追随最新版本API MOD 完全汉化
更新了v1.2.2，这个版本号是怎么来的呢？本来是和@a759205573 这位同学回复帖子的时候刚好发现女仆mod更新了，而且试了一下更新的版本，竟然修复了与光影的冲突（楼主心里一直默认这些mod的bug一辈子都不会修复），之后第二天又发现了一个什么mod更新了来着（我也忘了），这算两个0.0.1版本 _(:3 」∠)_
随后，楼主慢慢的发现之前直接从咱们论坛搬来的mod很多都是旧版本的，索性做了一张表格，把所有mod列出来然后逐个“挖祖坟”，结果连着forge一共更新了17、8个mod，豆腐工艺还是昨天更新的2.1.5，有些mod更新的版本比较近，大概是修复了一些bug之类的，有些版本就差得有点大，能汉化的也都顺便汉化了，但是有几个mod是没有lang文件的，class文件我研究很久还是不知道怎么把文本找出来，所以血量显示、自动钓鱼没有汉化，不过影响不算大，配置菜单没有几个单词。还有精英怪这个也没有汉化（就在写到这里的时候，楼主去找了一下精英怪的文件，发现竟然是有lang文本的w(?Д?)w，我竟然给忽略掉了w(?Д?)w。。。不过，反正就是些乱七八糟的属性，大家将就着摸黑打吧 (→_→)）。
印象深刻的还是汉化糖果世界，这个mod原来的版本是alpha1.2.3，现在是beta1.3，虽然不是正式版（楼主一直以为是），不过内容也很完整了，1.2.3版本的文件5MB大小，1.3的竟然将近12MB，“其实第一次听说要汉化这么大的模组楼主是拒绝的。。。”，最后楼主还是汉化了，整整一通宵八个半小时啊，我一开始在心里大言不惭的想（flag即视感）两小时（晚上10点到12点）搞定，因为有旧版的汉化撑（作）腰（参考），但真正开始后楼主才发现旧版的汉化直逼机翻，于是只好开始一行一行从头重新翻译。。。楼主晚饭没吃，一边谷哥度娘翻译双开一边百度各种糖果甜点，口水差点流一键盘。
第一次看到这个mod的时候，真的以为这是日本人做的（老美哪有这种情调），边汉化着边查阅着资料，恍惚间回到童年一般，也许每个人小时候都有一个幸福的生活在糖果世界的梦，楼主真的有过这个梦，也只能感叹mc这个神奇的游戏了。
最后，因为各种原因楼主坚持汉化完了才睡下（“第二天”起来又校对修改了一遍），这一觉，一直在做梦，梦里可不是什么糖果蛋糕巧克力之类的，而是在不停的汉化文本，不停的，不停的。。。 w(?Д?)w很符合日有所思，夜有所梦啊。。。
这就是那0.1个版本号的来历 (/"≡ _ ≡)/~┴┴
这次的整合包算是基本上独立自主的产物了，模组来源清晰，搬运的版本和汉化也有很多是独家的（以后还会继续跟进更新，喜欢想抱走的话记得回下帖子哦 (￣▽￣")）
最后请愉快的食用“遥遥整合v1.2.2”吧，然后这次并没有升级包 ( >﹏<。)，直接下载整合包把存档放进去就可以了 <(￣︶￣)>

2015年6月16日 整合之初的一些话
第一次制作整合包，简单讲述一下作案动机吧{:10_524:}
玩mc也有一两年了，一直是和朋友们玩的原版，最初的时候还有小地图加中文输入，现在是纯原版了，我经常自己一个人独处一段时间（好吧，说成闭关、神隐什么的也行{:10_516:}）感觉和朋友们在一起很开心，不过做事难以集中精力，其实，独处也有很多时间在找游戏玩，非常喜欢mc这种开放式的游戏，后来我又玩了少女卷轴5（手动斜眼），直到前些日子，又下载了辐射3（贴吧一位大大制作的包，真是精致）
不过，还是mc好玩啊@-@
然后就来到了那个“登陆账号密码一直错误，很奇迹般的第五次也就是最后一次输入密码，我竟然试对了！”的论坛{:10_492:}。
作案动机从这开始，啊不是，是制作整合包的动机。
于是我来到了mcbbs的mod发布区和懒人包发布区，打算体验一下不同的mc世界，真的是一千个整合包一千个世界。
不是最新版怎么能忍！1.8！1.8！1.8！
于是点开了一位大大的帖子@junxian0608 神秘之旅
这是我短暂的生存成果了（标准的建筑渣），无奈1.8的modbug太多，很多大型mod还是不完整版（对于我这种强迫症简直是灾难），于是开始寻找上一个版本1.7.10的整合包，看了不少也没有满意的。之后无意间看到了安迪大大的整合教程，想想自己动手丰衣足食，自己来整合吧！
整合包的基础是安迪大大的简单整合v3.8 for1.7.10，参照了上面提到的神秘之旅中的mod。
一星期前的那天我在心里大言不惭的想：一天就做好整合包！
本来以为轻轻松松的加入mod就好了，不过既然开始做了，就做的认真点吧。
整整对头周二到周二一星期。
一开始研究简单整合中每一个基础mod的文件和功能、出处（全部删掉，然后一个个文件重新往里加，我这里的网络不能用启动器直接下原版，所以不能从下载原版游戏开始了）
之后是翻遍MC中文模组百科然后就是在mcbbs的mod发布版里一页一页的找（英文渣没敢去国外网站{:10_514:}），找到需要的就是添加到游戏里测试，这一星期不知道开了多少次mc游戏。。。。。。
最后把找到的mod修正汉化配置，我用记事本汉化lang文件你怕不怕，先是乱码后是乱位，好歹是坚持了下来慢慢摸索找到原因解决。
既然做了，就尽可能做到最好。虽然耗费了一个星期的时间，不过学会了MC整合包的制作和一点基础编程知识，甚至英文和其他一些方面也有些许进步。总算是有点收获啦。

■模组介绍■
  • API
forge：版本10.13.4.1448
  • 补丁类
1.输入修正：在游戏中输入中文的补丁(作者ZLainSama)
2.皮肤移植：将1.8的新人物模型移植到1.7.10的补丁(作者ZLainSama)
  • 游戏性能
1.快速工艺：优化游戏帧数
2.更好的FPS：优化游戏帧数
3.内存清理：每隔180秒会自动清理一次游戏内存，此时游戏会稍卡一下
  • 显示类
1.高清修复：优化游戏帧数，扩展了视频设置中的可调整的项目
2.光影核心：安装光影核心后会严重影响游戏性能
3.F4光照提示：按下F4直观显示每个方块的光照等级(作者oldjunyi)
4.动态光源：手中的火把、掉落的火把等都可以发光，金头盔也可以发光
5.游戏内信息显示：在.minecraft\config的InGameInfo.xml中可配置显示内容(原帖有教程)，默认无快捷键(整合包设定I)，游戏内左上角显示天数时间经验等信息，左下角显示所持物品的耐久，右下角显示药水效果
6.血量显示：显示生物的血量、敌对状态等
7.高亮显示：显示物品和生物的名字状态等，小键盘的0键打开菜单可以进行设置，附带扩展Wawla，可以查看更多详细信息
8.更好的叶子：更好的显示效果，改变了树叶草地，水中还会出现芦苇水草等，配置请按下F8随喜好设定
9.音效过滤：更真实的音效，墙壁、水有减弱声音的效果，山洞有回声等
  • 功能类
1.物品管理器：O键显示/隐藏，R键查看合成，U键查看用途，附带一个通用插件NotEnoughResources支持查看一些物品在地牢等宝箱内出现的几率等信息
2.内置合成表：默认G键打开合成表，查看[拔刀剑]合成表时需要用到，支持中文搜索(作者sunny00123)
3.R键整理：按下R键自动整理物品
4.旅行地图：右上角小地图，默认J键打开设置
5.鼠标手势：添加了一些鼠标手势动作
6.创世神：在作弊模式下快速替换方块，教程请看原帖
7.砍树：用斧破坏树木根部方块，可以把整棵树变成掉落物
8.刷怪笼精准采集：可以使用附魔精准采集的工具采集刷怪笼
  • 小型杂项类
1.末影指南针：指向离你最近的主世界要塞
2.精灵球：精灵球左键可抓取/释放生物，抓取敌对生物貌似需要残血，高级精灵球则可以直接抓取敌对生物
3.更多箱子：添加了更多材料制成的箱子，增大存储空间等
4.背包：添加了16色的大小号扩展背包(中背包暂未开发)，手持背包右击可以打开
5.储物抽屉：添加美观实用的抽屉柜，详细介绍请看原帖
6.怪物萌化：在游戏主界面的“Minecraft领域”右侧的“mods”按钮打开的模组列表中选中“Cute Mob Models”项，点击左下角的“Config”按钮可以配置外形和碰撞箱等
7.更多武器：添加更多种类实用武器
8.生物模型：杀死原版已经大多数mod中的生物会以2%几率掉落一个模型，可使用道具缩放，装饰用
9.RPG升级：Y键打开界面，消耗经验升级技能，死亡后技能等级清零
10.卡通武器：添加一系列动漫中出现的武器，自带特定附魔，美观实用
11.黑曜石船：添加了坚固的黑曜石船，可在水和岩浆中航行，上船自动加持抗火buff
12.龙坐骑：右击龙蛋孵化龙，长大后用生鱼驯服后套上鞍可以骑乘，在水/冰雪/沙漠/下界等条件下会孵化出不同的种类，详细介绍请看原帖

■整合包食用说明■
1.强烈建议安装使用JAVA 8，游戏预设内存建议大于1G
2.整合包内附有说明书，开始游戏前请认真阅读
3.如果开启游戏闪退或者卡住，请删除[女仆]mod及其扩展[女仆哨子]和[小龙女](少数电脑可能会出现这个问题)
4.如果需要使用非正版皮肤的话，请删除[皮肤移植]mod
5.如果你偏向建筑党可以考虑使用更改游戏规则的指令
/gamerule keepInventory true(死亡不掉落)
/gamerule mobGriefing false(关闭苦力怕和小黑对地形的破坏)
6.本整合包的说明也可以参照楼主另一个帖子——工业城市整合包的说明，两个整合包的API和基础mod基本完全相同
