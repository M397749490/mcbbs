使用方法
必须需要PlaceholderAPI
下载地址: https://www.spigotmc.org/resources/placeholderapi.6245/
输入下列命令 安装PAPI的扩展组件
papi ecloud download player
papi ecloud download vault
papi ecloud download server
papi ecloud download javascript
papi reload
[聊天|信息]MiaoBoard —— 喵式记分板 自定义动态记分板[1.7+全版本]
http://www.mcbbs.net/thread-631482-1-1.html
(出处: Minecraft(我的世界)中文论坛
用这个插件
金币%vault_eco_balance%
点券:%playerpoints_points%
称号前缀后缀
%vault_suffix%
%vault_prefix%
或者%player_displayname%
当前世界
%player_x%
%player_y%
%player_z%
%player_world%
