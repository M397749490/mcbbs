Plugin-Annotations[原帖]
Plugin Annotations is a tool created to help developers who find it tedious to make and fill out a plugin.yml file every time they create a new project.

这个插件可以省去我们创建Plugin.yml，通过注解的形式，来设置。

在此之前请先了解好Plugin
>Spigot Plugin<


Maven导入
创建一个Maven后，在pom.xml中的project标签内插入如下
<dependencies>
  <dependency>
    <groupId>org.spigotmc</groupId>
    <artifactId>plugin-annotations</artifactId>
    <version>1.2.0-SNAPSHOT</version>
  </dependency>
</dependencies>

<repositories>
  <repository>
    <id>spigot-repo</id>
    <url>https://hub.spigotmc.org/nexus/content/repositories/snapshots/</url>
  </repository>
</repositories>

写完之后在IDEA左下角就会出现这么一个提示框

Maven projects ned to be imported
>Import Changes<   Enable Auto-Import

选择Import Changes后-将鼠标移至左下角选择其中的Maven，当你插件编写完毕之后，双击其中的install构建即可。


Plugin-Annotations[注解]
注解插入在类之前【其实原帖对注解的栗子已经很详细了，开这个感觉稍微的多此一举了】
Required Annotations[必要注释]
   @Plugin(name String,Version String)    两个形参，对应原来的Plugin.yml中的name,与version，注解放的位置就是main包的位置。这个注释是不可少的。Optional Annotations[可选注释]


Optional Annotations[可选注释]
@Description
@LoadOn
@Author
@Website
@LogPrefix
@Dependency
@LoadBefore@SoftDependency
@Command
@ChildPermission
