零：添加前置


先按这个网站的方法，把PAPI作为前置插件

https://github.com/PlaceholderAPI/PlaceholderAPI/wiki/Hook-into-PlaceholderAPI#adding-placeholders-to-placeholderapi

比如说Maven，那就在POM.xml里面加上

  1. <repositories>
  2. <repository>
  3.     <id>placeholderapi</id>
  4.     <url>https://repo.extendedclip.com/content/repositories/placeholderapi/</url>
  5. </repository>
  6.     </repositories>
  7.     <dependencies>
  8.         <dependency>
  9.          <groupId>me.clip</groupId>
  10.           <artifactId>placeholderapi</artifactId>
  11.           <version>{VERSION}</version>
  12.          <scope>provided</scope>
  13.         </dependency>
  14.     </dependencies>
复制代码

其中{version}替换成自己使用的版本（目前的最新版是2.10.6）

--2020.5.5修订
如果不使用maven而是普通javaproject，你可以按照导入自己bukkit核心的方法导入

抑或是gradle，那就在gradle.build里面加上


  1. repositories {
  2.     maven {
  3.         url = 'https://repo.extendedclip.com/content/repositories/placeholderapi/'
  4.     }
  5. }dependencies {
  6.     compileOnly 'me.clip:placeholderapi:{VERSION}'
  7. }

如何添加dependency不再多做说明了
接下来就是在plugin.yml当中添加依赖
比如说

depend: [PlaceholderAPI]

此处中括号在YAML里面表示的是列表，你也可以

depend: [xxxxxx, PlaceholderAPI]

来为自己的插件添加多个依赖（扯远了）

如果你的插件必须有它作为前置就使用前者

如果是可有可无的就使用软依赖

注意Placeholder不是PlaceHolder，大小写区分开





一、插件内使用PAPI变量

先看原文：

To use placeholders from other plugins in our own plugin, we simply have to use the setPlaceholders method.
  1. public void onEnable() {
  2.     if (Bukkit.getPluginManager().getPlugin("PlaceholderAPI") != null) {
  3.          /*
  4.           * We register the EventListeneres here, when PlaceholderAPI is installed.            
  5.           * Since all events are in the main class (this class), we simply use "this"
  6.           * 说的是在主类注册的事件监听，因此使用了this
  7.           * 如何注册事件监听不做讲解
  8.           */
  9.          Bukkit.getPluginManager().registerEvents(this, this);
  10.      } else {            
  11.          /*
  12.           * 如果没有找到papi这个插件就直接报错
  13.           */
  14.          throw new RuntimeException("Could not find PlaceholderAPI!! Plugin can not work without it!");
  15.      }
  16. }   
  17.    
  18. @EventHandler(priority = EventPriority.HIGHEST)   
  19. public void onJoin(PlayerJoinEvent event) {        
  20.     String joinText = "%player_name% &ajoined the server! He/she is rank &f%vault_rank%";        
  21.     // We parse the placeholders using "setPlaceholders"
  22.     // 使用setPlaceholders方法
  23.     joinText = PlaceholderAPI.setPlaceholders(event.getPlayer(), joinText);
  24.     event.setJoinMessage(withPlaceholdersSet);
  25. }
复制代码

接下来仔细研究一下这一段代码
说的是你已经有了一段字符串，并且其中已经有PlaceHolder
比如 “你好，我是%player_name%”
那么此时就使用setPlaceholders方法，把%player_name%换成玩家的名字
至于哪一些placeholder能被替换就取决于服务器有没有安装对应的papi扩展
这里不一定非要传入Player对象，同样也可以使用OfflinePlayer对象




二、插件内注册PAPI变量

需要在插件中使用一个独立的类来注册papi变量
看原文的实例
这段实例注册的是%someplugin_placeholder1%和%someplugin_placeholder2%

请注意！2.10.4版本及以后的PAPI已经不再支持旧的EZPlaceholderHook！

  1. /**
  2. * This class will be registered through the register-method in the plugins
  3. * onEnable-method.
  4. */
  5. public class SomeExpansion extends PlaceholderExpansion {

  7.     private Test plugin;

  9.     /**
  10.      * Since we register the expansion inside our own plugin, we can simply use
  11.      * this method here to get an instance of our plugin.
  12.      *
  13.      * @param plugin The instance of our plugin.
  14.      */
  15.     public SomeExpansion(Test plugin) {
  16.         this.plugin = plugin;
  17.     }

  19.     /*
  20.          *上面是使用构造函数传入插件主类实例
  21.          *主类实例的传入方法很多
  22.          *这里不多作讲解了
  23.      */
  24.     /**
  25.      * Because this is an internal class, you must override this method to let
  26.      * PlaceholderAPI know to not unregister your expansion class when
  27.      * PlaceholderAPI is reloaded
  28.      *
  29.          * 这里指是不是要让papi扩展持久化
  30.          * 不持久化则使用reload指令之后你的变量就没了
  31.          *
  32.      * [url=home.php?mod=space&uid=491268]@Return[/url] true to persist through reloads
  33.      */
  34.     @Override
  35.     public boolean persist() {
  36.         return true;
  37.     }

  39.     /**
  40.      * Because this is a internal class, this check is not needed and we can
  41.      * simply return {[url=home.php?mod=space&uid=28815]@code[/url] true}
  42.      *
  43.          * 不用管这个，直接return true就可以了
  44.          *
  45.      * @return Always true since it's an internal class.
  46.      */
  47.     @Override
  48.     public boolean canRegister() {
  49.         return true;
  50.     }

  52.     /**
  53.      * The name of the person who created this expansion should go here.
  54.      * <br>For convienience do we return the author from the plugin.yml
  55.      *
  56.          * papi扩展的作者，这里使用的是插件的作者
  57.          *
  58.      * @return The name of the author as a String.
  59.      */
  60.     @Override
  61.     public String getAuthor() {
  62.         return plugin.getDescription().getAuthors().toString();
  63.     }

  65.     /**
  66.      * The placeholder identifier should go here.
  67.      * <br>This is what tells PlaceholderAPI to call our onRequest method to
  68.      * obtain a value if a placeholder starts with our identifier.
  69.      * <br>This must be unique and can not contain % or _
  70.      *
  71.          * 对于%someplugin_placeholder1%，这里需要返回someplugin
  72.          *
  73.      * @return The identifier in {@code %<identifier>_<value>%} as String.
  74.      */
  75.     @Override
  76.     public String getIdentifier() {
  77.         return "someplugin";
  78.     }

  80.     /**
  81.      * This is the version of the expansion.
  82.      * <br>You don't have to use numbers, since it is set as a String.
  83.      *
  84.      * For convienience do we return the version from the plugin.yml
  85.      *
  86.          * papi扩展的版本，和plugin.yml当中版本的版本号规范是一样的
  87.          * 这边方便一点使用插件作者
  88.          *
  89.      * @return The version as a String.
  90.      */
  91.     @Override
  92.     public String getVersion() {
  93.         return plugin.getDescription().getVersion();
  94.     }

  96.     /**
  97.      * This is the method called when a placeholder with our identifier is found
  98.      * and needs a value.
  99.      * <br>We specify the value identifier in this method.
  100.      * <br>Since version 2.9.1 can you use OfflinePlayers in your requests.
  101.      *
  102.          * 真正实现papi变量返回值的地方
  103.          *
  104.      * @param player A {[url=home.php?mod=space&uid=41191]@link[/url] org.bukkit.Player Player}.
  105.      * @param identifier A String containing the identifier/value.
  106.      *
  107.      * @return possibly-null String of the requested identifier.
  108.      */
  109.     @Override
  110.     public String onPlaceholderRequest(Player player, String identifier) {
  111.         
  112.         if (player == null) {
  113.             return "";
  114.         }

  116.         // %someplugin_placeholder1%
  117.                 // 如果是%someplugin_placeholder1%，这里需要检测placeholder1
  118.         if (identifier.equals("placeholder1")) {
  119.             return plugin.getConfig().getString("placeholder1", "value doesnt exist");
  120.         }

  122.         // %someplugin_placeholder2%
  123.         if (identifier.equals("placeholder2")) {
  124.             return plugin.getConfig().getString("placeholder2", "value doesnt exist");
  125.         }

  127.         // We return null if an invalid placeholder (f.e. %someplugin_placeholder3%)
  128.         // was provided
  129.                 // 错误的papi后缀，比如说someplugin_placeholder666，并没有被我们所定义
  130.         return null;
  131.     }
  132. }
复制代码

注：onRequest方法不一定使用Player对象作为参数，同样可以OfflinePlayer
然后还需要在主类onEnable方法注册

  1. public void onEnable(){      
  2. // Small check to make sure that PlaceholderAPI is installed</font>
  3.    if(Bukkit.getPluginManager().getPlugin("PlaceholderAPI") != null){
  4.         new SomeExpansion(this).register();
  5.    }
  6. }
复制代码

使用register方法来注册papi变量


需要注意的是比如我写了两个变量

%mtxz_state% %mtxz_attainments%

第一个标示符返回mtxz

第二个标示符则是你自己的后缀判断，比如state

这里不要重复加上mtxz_的前缀

还有papi变量尽量使用xxxx_xxxx的形式，不要随意改动




三、单独的PAPI扩展
（没有继承JavaPlugin的类，只有papi变量这一个功能）
这种变量不需要一些你自己插件所记录的独有内容
而只是返回一些玩家统计数据或是进行一些计算什么的
此时你可以直接写一个和上文一样的注册的类继承PlaceholderExpansion

然后构建成一个jar
放进papi的文件夹，即服务端的/plugins/PlaceholderAPI/expansions




四、云扩展
腐竹直接在服务器使用/papi ecloud download指令来下载

请看这里https://github.com/PlaceholderAPI/PlaceholderAPI/wiki/Expansion-cloud

本质上和三是一样的

只不过不需要腐竹自己下载jar再扔进目录

输入指令之后papi会搞定一切

注意这种方法对于版本号等参数的要求很严格

如果你要写这种扩展请仔细阅读原文
