1. 认识 Custom NPC
这次我拿1.7.10c的版本来作为测试（具我初步了解，1.7.10c和1.7.10d本质上没有问题，但是1.7.10d在服务器运行的时候，对话框会出现一字多字的情况，英文不影响）
此MOD工具分为10个：
图片
说明

Npc 魔杖
主要用于编辑，删除，添加NPC等操作

Npc 复制魔杖
主要用于复制以设置好的NPC
（可设置生成NPC的刷怪笼）

Npc 脚本魔杖
主要用于编写NPC或者脚本方块
（此教程不会讲这么深奥的问题）

Npc 骑乘魔杖		 可以骑大多数生物，甚至可以骑玩家
可以让NPC骑NPC
（比如NPC骑NPC马）

Npc 传送魔杖		可以传送到绝大多数世界

Npc 路径魔杖		主要用于编辑NPC路径

定点快 		主要用于任务设置需要寻找某些地方
而设定

结界		主要用于玩家在某些【对话】【任务】
【阵营】【时间】不能通过/能通过

红石块		 主要用于玩家接近方块多少范围
而触发红石信号

空灵魂石（可叠加）		低配版的【Npc 复制魔杖】
无UI界面
直接使用会获得其复制的NPC的物品
【满灵魂石（不可叠加）】
可在config.yml里禁用灵魂石
PS:有些图片是在MC百科上扒的，有些是NPC里面找到，在通过PS弄成128x128的



2.  Custom NPC 外形设置
界面展示



名称：
当你右键生成Npc时，他会自动给你生成一个英文名字，你可以修改它，也可以设置隐藏或不隐藏

标题：
默认：无
标题是依附在名称下方，通常是用于对玩家可见的职业，如：商人

模型：
默认生成是steve，可在编辑模型，可以设置MOD中的生物模型
（PS：这里自己去研究，比如头大，腿细，腰长，各种胡子等等）

尺寸：
默认设置为：5
可根据类型类设置尺寸，如BOSS类型，大小可以调高

材质：
默认：Steve
你可以用本地所有的材质，以及正版玩家的皮肤，以及网络图片地址的皮肤（俗称图床）

披风：
默认：无
披风只能用于本地的材质

附加材质：
默认：无
在原本皮肤上在覆盖此皮肤的功能

是否有活力的：
模式：有活力
善不明确（如果你发现了什么可以在下面评论）

是否可见：
默认：可见
如果消失了却不好编辑怎么办？
拿着Npc 魔杖对着天空就是一怼

Boss血条：
默认：隐藏
设置为有，和凋零的血量是一样的

界面展示

生命：
默认：20
这个就不用讲了吧！QAQ

默认：16
在此NPC的敌对阵营里面是玩家所处的阵营就会触发
生物类型：
默认：普通
所有类型：普通 / 不死 / 节肢动物
和亡灵杀手以及节肢杀手相对应
不死 = 亡灵

重生：
界面展示

是否设置为重生：
默认：是
这个也不用讲了吧QAQ
  
时间：
默认：20
重生时间
隐藏尸体：
默认：不隐藏
是否隐藏Npc死亡后的尸体
自然消失：
默认：不自然消失
以我的理解应该是，随时间消失而消失，就像物品有5分钟的时间一样
近战选项：
界面展示

近战伤害：
默认：5
设置Npc近战伤害
  
近战攻击距离：
默认：2
这些都感觉没什么好介绍的啊QAQ
近战攻击速度：
默认：20
理论上越低攻速越快，这里的20指20tick = 1s = 1秒
如果设置为10,10tick = 0.5s = 0.5秒攻击一下
击退：
默认：0
和附魔属性【击退】一样
攻击效果（秒）：
默认：无
所有效果：
【火】默认时间：5
【中毒】默认时间：5   无增益
【饥饿】默认时间：5   无增益
【虚弱】默认时间：5   无增益
【缓慢】默认时间：5   无增益
【反胃】默认时间：5   无增益
【失明】默认时间：5   无增益
【凋零】默认时间：5   无增益
这里面的增益，我认为是在原基础剩余的时间在加上现在的时间
用公式表达：
设默认时间为x，总时间为y
（x - 玩家承受过的buff时间） + x  =  y

默认：否
（PS：我建议在使用弓箭的时候开启）
弹药类型：
界面展示

力量：
默认：4
冲击：
默认：0
2D/3D：
默认：2D
3D：
旋转：否   穿透目标：否
尺寸：
默认：5（1-10）

速度：
默认：10
飞行速度
受重力影响：
默认：是
是：抛物线
否：直线
爆炸：
默认：否
当你调整到【是】的时候，会有【无，小型，中等，大型】共选择
其中【无】不会破坏地形
【小型，中等，大型】均可破坏地形，除非你设置了
/gamerule mobGriefing false
这个属性
效果：
默认：无
和【近战选项】中的【攻击效果】一样
跟踪轨迹：
默认：无  / 不发光
这里自行测试（我懒，要图）
抗性提升：
界面展示

以上所有效果设置为小于0%则 增加伤害
大于0%则 增加抗性
大约是这样的：
设置为：箭-50%，近战50%
玩家近战伤害10，弓箭伤害10
NPC会受到近战伤害10 - (10 * 50%) = 5
弓箭伤害为10 - （10 * - 50%） = 10 - -5 = 10+5 = 15
PS：我怎么教你们这些QAQ

4.  Custom NPC AI设置
页面展示

发现敌人时：
反击 / 恐慌 / 撤退 / 无反应
反击：在主动攻击范围内进行反击
恐慌：在主动攻击范围内发现敌人，一定范围走动
撤退：在主动攻击范围内发现敌人后逃跑
无反应：无反应
与门交互
是否能移动到门在打开门等等东西
可以游泳
是：浮在水面
否：称在水底
寻求庇护：
关闭 / 黑暗 / 日光
在使用【游荡】【路径移动】特定条件下才有用

必须看到目标：
否 = 以范围X格内感知到
是 = 以范围X格内无障碍物看到才行
战术变换：
突袭  = 直接过来
闪避 = 闪避远程攻击
包围 = 寻找友军包围敌军
打了就跑 = 受到攻击了X秒后逃跑
伏击 = 寻找有力的障碍物，发现敌军后伏击
偷袭 = 等于上
无
移动：

动物种类：
站立 / 游荡 / 路径移动
站立 = 原地不动
游荡 = 范围移动
路径移动 = 根据Npc 路径魔杖指定移动
位移：
在原位置移动xyz范围（0-10）
活泼：
普通 / 坐下  / 躺下 / 潜行 /  跳舞 / 盯着 / 爬行 / 拥抱
旋转：
默认 = 身体
操练 = 使NPC指定一个地方（0,90,180,270）
跟踪 = 以360°无死角看着玩家
头 = 以头为中心，旋转身体
停止互动：
善不明确
