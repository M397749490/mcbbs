BC端Config解析

     只解析一些重要的！
groups
他的下面会有个md-5，请把他改为你的游戏ID，因为这是玩家名，如果有玩家叫md-5那么他将有bc端的所有权限
player_limit
最大人数上限，-1则无限
max_players
显示的最大人数上线，真正的是在上面。这个仅为看的
default_server
默认服、第一次进游戏所在的服。又叫登陆服
fallback_server
默认服未开启、不可用将移动到这个服务器
host
IP和端口，默认0.0.0.0:25565 0.0.0.0表示接收所有IP

tab_size

TAB总容量 默认60 总三列 80时四列 以此类推

force_default_server

开启时玩家每次进游戏时都会进到默认设置的服

若关闭，加入服务器则为上次进入的服

servers



  lobby:                                                                       服务器名

    address: localhost:25565                                          服务器IP以及端口   

    restricted: false                                                       若开启，没 bungeecord.server.服名 的玩家将无法进入游戏

    motd: '&1Just another BungeeCord - Forced Host'       不说了 MOTD大家都懂

ip_forward

是否启用真实IP和UUID转发功能。本功能需要后端的子服务器为spigot服务端或者cauldron（MCPC+）服务端，并且在其“spigot.yml”中设置“bungeecord: true”。两边都开启后，后端服务器可以获得玩家的真实IP和UUID，两边任何一边没开启，将导致后端服务器获取的IP全部是127.0.0.1，UUID是离线模式下的UUID

online_mode

正版游戏验证，开启时有正版的玩家才能进服







BC子服搭建方法
在BC端内新建文件夹假设命名为生存

打开生存文件夹，把服务器核心文件以及bat文件放进去
bat文件和下文介绍的bat一样的设置，只需要把核心文件改你需要的！

下一步打开bat文件，直到他出现这个


下一步打开eula文件
找到eula=false把false改为true保存

下一步再次打开bat文件，即可开服成功！
子服设置好后，需要到BC端的Config的servers下增加


  sc:                                           你的子服名字
    motd: '&1生存服'                     你的MOTD
    address: localhost:23456           你的子服IP:端口
    restricted: false                         无需修改

进入游戏即可连接成功！
建议使用Stp插件跨服！

  2. title [凯文整合-生存端纯净]
  3. pause
  4. :MAIN
  5. cls
  6. java -Xms512M -Xmx512M -jar spigot-1.7.2-R0.4-SNAPSHOT.jar

  10. #当你需要改内存的时候请两个一起改

  12. #-jar后面的是核心文件，如果要开其他服可以把后面那改其他核心文件

  14. if exist "plugins\RestartEvolution\restart.mcs" goto MAIN
  15. if not exist "plugins\RestartEvolution\restart.mcs" goto END
  16. :END
  17. echo.

回答问题时间

问：我要怎么开服？
答：打开服务端的bat文件。


问：为什么我开服了，但进不去？
答：下好端后需要到server.properties文件修改IP为自己VPS、电脑、IP再打开游戏连接。


问：我刚下服务端，要怎么获得第一个OP？
答：在bat后台输入op 你的游戏名或在服务端文件里的ops文件增加你的游戏名字就可以了！
