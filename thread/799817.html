SuperVanish

描述：
这是一个先进的隐身插件，使其他玩家认为你不根本不在服务器上。
如果想要使用服务器列表，标题栏等请首先添加Protocollib
1.14、1.15: 非常重要 -安装最新版的Protocollib dev-build !
如果想要支持作者的话，可以看看作者的另外一个插件PremiumVanish（更彻底更完全的隐身,从数据包级别完成究极隐身，以后一起搬运）


特征

玩家使得隐形完全
隐藏在[TAB]中列表的玩家
调整服务器列表中线上玩家的总数量（需要ProtocolLib）
作弊客户端的无法看到完全隐身的玩家
网求允许更详细的权限管理权限
向隐身玩家显示名称（需要ProtocolLib）
您可以在messages.yml中从插件中改变每条提示消息
隐身玩家在加入/退出后仍然不可见
隐身玩家在服务器reload/重启后仍然有效
隐身玩家不能捡起掉落物
禁用隐身玩家的加入/离开服务器的消息
对隐身玩家禁用玩家伤害
手中的物品将会被隐藏
隐藏隐身玩家的装备
可在游戏中重载插件配置
隐身玩家可以静默打开箱子（需要ProtocolLib）
隐身玩家无法触发压力板
隐身玩家即使处于生存模式也可以飞行
隐身玩家不会阻挡其他玩家放置方块
隐身玩家不会阻挡其它玩家/方块发射的箭(但隐身的玩家会传送到箭上方两格)----无法理解,有知道的话可以跟我说
隐身玩家不能被玩家选中(就是有攻击准心)
在服务器列表中隐藏隐身玩家（需要ProtocolLib）



命令和权限:
[...] = 必填; <...> = 可选
/sv help - 打开帮助
/sv [on|off] - 开启/关闭隐身 - sv.use [.levelX]
/sv [on|off] <player> - 开启/关闭其他玩家的隐身 - sv.others
/sv reload - 重载配置 - sv.reload
/sv list - 列出隐身玩家 - sv.list
/sv login - 显示登陆消息 - sv.login
/sv logout - 显示离开消息 - sv.logout
/sv recreatefiles [confirm|force] - 重创配置文件 - sv.recreatefiles
/sv tipu - 切换每个玩家的物品 - sv.toggleitems
/sv stacktrace - 记录报告问题的信息
其他值得注意的权限:
sv.see [.levelX] - 具有此权限的玩家可以看到不可见的玩家（如果已在配置中启用）
sv.keepfly - 没有此权限的玩家将在重新登陆后失去在生存模式飞行的能力
sv.notoggle -  拥有此权限的玩家不会被他人更改隐身状态
sv.see的用法[未汉化]
