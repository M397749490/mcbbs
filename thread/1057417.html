作者: 梦星桐    时间: 2020-6-6 23:47
ap有原版伤害机制，时间间隔打出最大伤害
可在attributes.yml配置中将default关闭
  1. #伤害设置
  2. Damage:
  3.   #是否提示伤害消息
  4.   message:
  5.     #攻击提醒
  6.     damage: true
  7.     #受伤提醒
  8.     injured: true
  9.   #是否开启原版伤害
  10.   default: true
  11.   #插件特色,建议尝试使用 (来自作者的强力推荐)
  12.   #是否开启蓄力伤害机制,1.9以上版本支持,真实伤害不受影响
  13.   #弓拉满即可打出满额伤害,未拉满则按目前拉的力道造成伤害(弩相同)
  14.   #近战蓄力触发横扫可打出满额伤害,攻击过快将按蓄力强度造成伤害
  15.   damageMechanism: false
