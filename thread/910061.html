一、WAC插件优势
● 积极更新——WAC定期更新，通常每周多次更新。如果您发现错误、插件检测被绕过、误报正常玩家，请告知我，我会尽快的修复。
● 多元化的作弊检查——WAC可对多种作弊行为进行检查判定，例如有关玩家动作的（非法的飞行，不正常的加速），有关战斗的（杀戮光环，扩大攻击范围）或其他一些类型（瞬移，改变时间），更多具体内容您可以查看下面的可检测列表。插件支持检测的作弊项目将会越来越多，以便应对更多样化、更新的作弊方案。
● 配置便捷——WAC允许您设置应该检测哪些作弊项，是否以及何时通知管理员玩家的作弊行为，是否以及何时应该阻止玩家作弊等等。然而，与许多其他的反作弊插件相比，这个插件不会给出很多关于个别的、模棱两可的作弊配置选项。至于原因，在我看来这些配置选项大多没什么卵用。如果在检测作弊中出现问题，不应该通过更改配置来解决，因为这不是真正的解决，而只是一种折中的暂时性解决方法。正确的做法应该是向作者报告这个问题，作者通过调整代码使这个问题得到永久彻底的解决。
● 易于使用——在使用WAC之前，您无需花费数小时来配置WAC。虽然有一个配置文件，但您不需要修改它，您只需将WAC安装到您的服务器上，插件便会自动处理其他的工作。
● 无需任何前置——WAC使用TinyProtocol处理数据包，这意味着您不必担心找不到正确的ProtocolLib版本。插件也没有其他依赖的前置，您可以将其直接放入plugins文件夹，重新启动你的服务器，它就会自己工作。
● 开发者API——WAC提供了一个API，允许您将其与其他插件集成。您可以在下面阅读有关API的更多信息。

二、可检测的作弊项列表

  • Angle——错误的角度
  • BHop Speed——快速连跳
  • Blink——瞬移
  • Boat Fly——船上飞行
  • Climb (aka Spider)——爬墙
  • Fly——飞行
  • Jetpack——喷气背包
  • KillAura——杀戮光环
  • NoFall——掉落无伤害
  • OnGround Speed——快速行走
  • Ping Spoof——伪高延迟
  • Reach——扩大攻击范围
  • Step——无需跳跃直接走上一格高的方块
  • Timer——变速
  • Vanilla Speed——加速
  • Water Walk (aka Jesus)——水上行走

请注意，此列表并不完整。有一些检查项甚至可以检测到没有加入此列表的作弊行为。
例如：虽然我没有为它添加任何特殊代码，但飞行检查阻止了Jetpack这项作弊，这仅仅是因为飞行和Jetpack的作弊行为很相似。（注：jetpack是另一种类似飞行作弊的作弊行为）
还有，同一个作弊玩家在作弊客户端中可以有许多不同的用户名，所以作弊玩家使用的作弊项即使不在这个列表中也极有可能被插件检测到并阻止。

三、插件指令&权限节点
指令：
/wac
用途：显示WAC的工作状态和正在使用的版本
/wacnotify [on|off] 或简化指令 /wacn [on|off]
用途：开关插件检测通知
/wacreload 或简化指令 /wacr
用途：重载插件配置

权限：
wac.notify——允许查看插件监测通知并使用/wacnotify命令（默认OP拥有）
wac.reload——允许使用/wacreload指令（默认OP拥有）
wac.bypass——允许绕过所有检测
wac.bypass.[checkName]——允许绕过设定的检测（以上两项默认无，需手动添加）

  6.   # 是否发送检测通知

  8.   # 玩家作弊次数超过此限制插件才会发送通知，设置为5，则前四次作弊均不会有任何提示
  9.   notify-threshold: 5
  10.   # 插件通知的间隔时间，小于此时间的通知将不会被发送，此项用于避免刷屏（单位：秒）

  13.   # 是否开启阻止作弊

  16.   block-threshold: 10

  18.   # 是否开启作弊踢出服务器
  19.   kick: false
  20.   # 插件踢出作弊玩家的间隔时间，小于此时间的作弊将不会被踢出
  21.   kick-threshold: 25
  22.   # 如果一个玩家作弊被踢出，并立即重新加入，他的作弊行为通常还没有结束
  23.   # 这意味着他仍然超过了踢出间隔时间，并且在下一次违规时将立即再次被踢出
  24.   # 为了防止这种情况发生，这个选项添加了一个最小数量的违规行为，计算时间从玩家最近一次被踢后到下次被踢之前
  25.   # 这并不能取代上一项间隔设置，它是一个额外的功能。它可以在不改变作弊次数的情况下防止上述问题的发生。
  26.   rekick-threshold: 10

  28.   # 在插件检测玩家的ping值时，将会忽略ping值高于此设置的玩家
  29.   # 将数值设置为-1将会始终检测所有玩家的ping值

  32.   # 在插件检测服务器的TPS时，如果服务器的TPS低于此设置，检查将被禁用

五、开发者API
每次WAC检测到玩家作弊时，会出现以下事件，您可以使用它将其集成到您自己的插件中
  1. class com.gmail.olexorus.witherac.api.ViolationEvent extends org.bukkit.event.Event implements org.bukkit.event.Cancellable {
  2.     // returns the type of hack that was detected
  3.     com.gmail.olexorus.witherac.api.CheckType getType()
  4.     // returns the player who was detected
  5.     org.bukkit.entity.Player getPlayer()
  6.     // return the amount of previous violations (not counting the current event)
  7.     int getPreviousViolations()
  8.     // a runnable which blocks the detected hack when executed
  9.     Runnable getBlockAction()
  10.     // returns if the event is cancelled
  11.     boolean isCancelled()
  12.     // change if the event is cancelled
  13.     void setCancelled(boolean)
  14. }

  16. enum com.gmail.olexorus.witherac.api.CheckType {
  17.     // returns the internal name of the Check
  18.     String getCheckName()
  19.     // returns the description of the Check
  20.     String getCheckDescription()
  21. }
