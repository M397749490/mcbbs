OverCraft

守望先锋


■本贴由StarMC来处理■



■介绍■

守望先锋是一款多人竞技游戏，一般来说要电脑配置很好的才能玩
而现在，不用担心，你将可以在Minecraft中体验到这款游戏。




■安装■

1.下载[守望先锋OverCraft]插件
2.将[守望先锋OverCraft]丢进plugins文件里
3.开启服务器
4.没有了




■指令■

/oc create [竞技场名字] [最小玩家数] [最大玩家数] [观察number_of_capture_points]
/oc wand  给你一个带指令的棒点击块来保存位置和右击块来移除位置
/oc remove [竞技场名字]
/oc list [所有竞技场]
/oc autojoin 自动加入一个竞技场
/oc join 加入一个竞技场
/oc leave 退出一个竞技场
/oc class 选择一个英雄
/oc hero 打开英雄gui


■创建竞技场■
/oc create [竞技场名字] [最小玩家数] [最大玩家数] [观察number_of_capture_points]
/oc wand  给你一个带指令的棒点击块来保存位置和右击块来移除位置
左键点击移除位置，右击以添加位置
然后设置较低的蓝色团队生成区域
并设置蓝色团队的上层区域
然后设置红色的团队
然后设置较低的红**团队生成区域
并设置红**团队的上层区域
然后设置游戏大厅，玩家可以在那里等待
设置返回点，玩家在游戏结束后会传送
然后设置下竞技场区域

说的不是很清楚，请谅解
