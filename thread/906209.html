介绍

主播认证步骤太繁琐？没时间处理主播认证？一个插件自助认证！
它可以验证主播的粉丝数以及播放量，如果达到标准，则进行下一步
通过改个人介绍的方式确认是否是本人
视频: https://www.bilibili.com/video/av64846329/

目前仅支持BiliBili（看这个名字也看出来了，不过之后也许会加其他平台的）




特性:

完全自定义奖励内容，消息几乎全可定制

安全的异步请求，保证服务器不卡顿

个人签名验证，防止冒充主播申请

解放服主，无需一个个审批！
支持Mysql！

更新:

8.22 更新：
支持Mysql数据库，新增加权限判断，以及一些优化功能，插件启动前会自动删掉老版本配置文件，请注意
9.6 更新:

修复了/bili reload指令无法重载配置的bug，因为没有配置文件的更新所以不会删除老版本配置文件



权限:

bili.admin 插件重载权限



指令:

/bili B站mid（打开自己空间 http://space.bilibili.com/xxx xxx就是）
/bili reload 重载插件

配置文件:

  1. #感谢您使用BiliChecker，如果喜欢这个插件
  2. #你可以来B站给我点个关注，地址:https://space.bilibili.com/5832391
  3. #你也可以来mcbbs给我评分，谢谢
  4. #任何Bug反馈或者建议请在Mcbbs上提出，感谢您的使用！www

  6. #版本号，请勿修改！
  7. Version: 1.1

  9. #申请粉丝数要求
  10. Fans: 1000

  12. #播放数量要求
  13. Views: 100000

  15. #尝试验证自己的粉丝数，并且成功通过验证的，此时将引导玩家通过B站签名认证，<Sign>为随机码
  16. Verifying: '&a恭喜你成功通过验证！现在为了确认您是账号本人，我们需要您将签名改为&e<Sign>&a，当你更改之后，请回到游戏输入/bili或者/bilichecker'

  18. #当尝试验证粉丝数之后，失败通过验证的
  19. FailedToPass: '&c你没有通过验证，本服务器主播验证需求:<Fans>粉丝数和<Views>播放量'

  21. #当玩家成功完成签名验证时的提示
  22. Success: '&a恭喜你，通过验证，礼包已经自动发放，请查收'

  24. #当玩家成功验证之后，服务器自动执行的指令，<Player>将会自动替换为该名玩家的玩家名
  25. #以下只是示范，你可以自行配置
  26. Commands:
  27.   - say <Player>成功完成主播验证
  28.   - say 服务器又新增一名主播！
  29.   - pex user <Player> group set ZhuBo
  30.   - money give <Player> 10000000000

  32. #防止玩家过度验证，设置的指令间隔，单位为秒
  33. Limit: 30

  35. #玩家参数错误，或者跳过验证步骤提示的消息
  36. NotInt: '&c您输入的指令有误，请输入/bilichecker <你的Mid>'

  38. #当玩家处于冷却时输入指令提示
  39. In-CoolDown: '&c请过一会儿再尝试验证'

  41. #签名验证的前缀，比如填写'服务器验证码-'，生成的随机验证为服务器验证码-Sk2Jk2a10P
  42. Verify: '主播验证'

  44. #当该B站账号已被验证过后的提示
  45. Verified: '&c该账号已经被认证'

  47. #当签名认证失败时提示的消息
  48. NotVerified: '&c验证失败，请重试，注意不要包含大小写，以及空格等'

  50. #Mysql相关设置，用于存储该uid是否被验证过
  51. Mysql:
  52.   enable: true
  53.   address: localhost:3306
  54.   user: root
  55.   database: mysql
  56.   passwd: 1234

  58. #是否验证玩家权限，如果有该权限则无法领取，可以防止玩家多次领取礼包
  59. PermissionCheck:
  60.   enable: false
  61.   #需要Vault前置，当玩家领取后自动给这个权限
  62.   auto: false
  63.   #已拥有权限时输入指令的提示
  64.   message: '&c你已经认证过主播啦！'
  65.   #权限名
  66.   permission: 'bili.yt'
