About


NoResidenceQuickShop(以下简写为NRQS) 可以规定忘记应该(只能)在什么地方创建商店, 在未安装此插件前,玩家们可以在领地的container权限开启时(比如小黑塔等需要开放箱子的)在其他人的领地里创建商店,就像下面这样.

NoResidenceQuickShop 的功能


  • 阻止玩家在存在于黑名单里的世界里创建商店
  • 允许玩家在存在于白名单里的世界里创建商店(没有任何限制，即使这个世界也同时存在于黑名单里)
  • 可以控制玩家是否可以不在领地里创建商店(是否可以在领地外面创建商店)
  • 可以控制玩家是否可以在领地里创建商店
  • 可以让玩家修改 领地权限
  • 允许领地管理员在其他人的领地里创建商店(无视领地flag)
  • 阻止没有领地权限的人在领地里创建商店
  • 可以自定义截断消息, 你也可以填上 "" 来阻止系统显示提示
  • 可以自定义截断消息[领地内], 你也可以填上 "" 来阻止系统显示提示. 或者填上 "<default>" 来使用领地插件的信息




权限
  • nrqs.admin - (OP) 给予你 nrqs.reload权限以及无视限制的权限
  • nrqs.update - (OP) 拥有此权限的人在进入服务器是会获得这个插件的更新信息(Spigot MC)
  • nrqs.reload - (OP) 允许使用 /nrqs reload
  • nrqs.command - 允许使用 /nrqs (但不能执行 /nrqs reload)
  • nrqs.create-out-residence - 允许玩家不在领地里创建商店[默认给予]
  • nrqs.create-in-residence - 允许玩家在领地里创建商店[领地flag可以阻止她创建商店][没有这个权限的玩家，及时她拥有一个领地的 create 权限, 也无法创建商店]
  • nrqs.create-[world] - 允许玩家在某个世界创建商店, 但是如果这个世界在黑名单里的话，这个权限是无效的
config.yml
  1. # 启动 debug 模式可以获得更多信息
  2. debug: false
  3. # 更新检查
  4. update: false
  5. # 领地flag编辑
  6. # 其实只有名字编辑是有用的
  7. # 因为 /plugins/Residence/flag.yml 也可以修改,不对吗?
  8. flag:
  9.     #flag名字
  10.     name: quickshopcreate
  11.     #是否只允许管理员设置(修改)
  12.     admin-set-only: false
  13.     #权限介绍(例如领地自带的admin flag的值是 "玩家可以更改权限")
  14.     description: Allow or deny players to create a QuickShop in your residence.
  15.     #真假值, 设置领地没有设置的时候采用的默认值(true/false)
  16.     default: false
  17.     #领地gui显示物品用的物品id(这里是箱子)
  18.     id: 54
  19.     #附加值
  20.     data: 0
  21. # 没啥用的
  22. listeners:
  23.     plotme: true
  24.     residence: true

  26. # 权限的检测顺序 (优先级)
  27. #
  28. # 如果 有 'nrqs.admin' 权限 -> 允许
  29. # 如果 当前世界在白名单里 -> 允许
  30. # 如果 当前世界在黑名单里 -> 禁止
  31. # 如果 没有 'nrqs.create-[world]' 权限 -> 禁止
  32. # 当玩家不在领地里面 -> 如果 没有 'nrqs.create-out-residence' 权限 -> 禁止
  33. # 当玩家在领地里面 -> 如果没有 'nrqs.create-in-residence' 权限 -> 禁止
  34. # 如果玩家是领地管理员 -> 允许
  35. # 如果没有领地flag -> 禁止

  37. #黑名单
  38. blackworlds: []

  40. # 白名单
  41. # 根据检测优先级得出 如果 世界x 同时存在与 黑名单 和 白名单 里, 玩家还是可以在这个世界里创建商店
  42. whiteworlds: []

  44. # 自定义信息
  45. messages:
  46.     #服务器领地的名字
  47.     server-land: "Server"
  48.     #黑名单禁止
  49.     blackworld: "&cYou can't create a quick shop in this world."
  50.     #没有世界权限
  51.     no-world-permission: "&cYou don't have the permission to create a quick shop in this world."
  52.     #不在领地里被禁止
  53.     out-of-residence: "&cYou can't create a quick shop when you are not in a residence."
  54.     #在领地里被禁止
  55.     in-residence: "&cYou can't create a quick shop when you are in a residence."

  57.     # 填入 "<default>" 来使用res的配置信息
  58.     # 你也可以自定义这个信息
  59.     # 可以使用的变量: {flag_name} {player} {loc:x} {loc:y} {loc:z} {loc:world} {res:owner} {res:name}
  60.     #
  61.     # 在这个领地的主人名字是 "Server_Land" 的时候(这个领地属于服务器的领地的时候)
  62.     # 变量 "res:owner" 会是 "<messages.server-land>" 的值
  63.     # 复制以下代码并塞入信息框来查看mc颜色代码
  64.     # &11&22&33&44&55&66&77&88&99&00&aa&bb&cc&dd&ee&ff
  65.     #no-residence-flag: "&cYou don't have &b{res:name}&6:&e{flag_name}&c permission.\n&3{loc:world} &6{loc:x}&b, &6{loc:y}&b, &6{loc:z}&b res owner: &d{res:owner}"
  66.     no-residence-flag: "<default>"
  67.     no-plot-alowed: "&cYou can't create a quick shop in this plot."
