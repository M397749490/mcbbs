作者: 592764254    时间: 2020-3-27 11:41
set {_random122} to random integer between 1 and 35（这里可以设置你想要的数）
                                                if {_random122} is 1:
                                                        执行物品给予指令
                                                if {_random122} is 2:
                                                        执行物品给予指令
。。。
                                                if {_random122} is 35:
                                                        执行物品给予指令
这样一直复制到最大数，你就能实现随机，甚至可以控制几率
