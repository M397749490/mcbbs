AnimatedTeleport
动画特效传送


功能介绍:
  • 类似GTA的传送风格动画特效
  • 可限制那些传送指令才有这动画效果
  • 可开关进入服务器特效（类似GTA线上进入的效果）
  • 可设置传送总时间和传送效果时玩家的上升高度
配置文件与使用方法:
配置文件

  1. # 每次上升/下降的方塊距離
  2. # the teleport Y interval
  3. Interval-Y: 50
  4. # 傳送總耗時
  5. # tp total time
  6. time: 5
  7. # 允許把此傳送方式用在加入伺服器的時候。並且需要有 gtateleport.join 的權限
  8. # enable whether to apply this teleport on join, the player must have gtateleport.join to do it
  9. enable-on-join: true
  10. # 啟用失明效果
  11. # enable the blindness effect between teleport
  12. blindness-enable: true
  13. # 允許使用此傳送方式的指令列表。若果你所輸入的並非傳送指令，將無法運行。
  14. # the tp command in this list will auto apply this teleport style
  15. allow-command:
  16.   - /loc
  17.   - /tp
  18.   - /home
  19.   - /spawn
  20. # 传送音效 (默认 1.14.4 音效名称，若是其他版本版本，請自行更改)
  21. # teleport sound (default using 1.14.4 sound name, change the sound name to match your server version yourself.)
  22. teleport-sound: ENTITY_ENDERMAN_TELEPORT
  23. messages:
  24.   tp-title: "&e正在传送..."
  25.   no-perm: "&c沒有权限"
  26.   set-success: "&a测试位置设置成功! 可输入 /loc 来测试GTA传送效果"
  27.   no-loc: "&c尚未设置测试位置!"
  28.   invalid-loc: "&c位置无效"
  29.   teleporting: "&c传送中，无法执行其他指令!"
  30.   reload-success: "&a插件重載成功"
复制代码

命令&权限:
/setloc ——设置测试传送的位置
/loc ——用插件动画效果传送到测试位置
    ·ar.tester
/ar-reload——重载配置文件
    ·ar.reload
ar.join——进服时使用插件动画效果传送
