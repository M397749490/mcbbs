你好LZ 这个进服的提示消息是可以改的 请到服务端根目录 plugins\Essentials\config.yml 找到
  1. # 是否关闭加入、退出游戏的提示消息
  2. # 当启用后, 具有对应权限的玩家加入、离开游戏将不会在公屏上显示消息
  3. allow-silent-join-quit: false

  5. # 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
  6. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  7. custom-join-message: "none"

  9. # 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
  10. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  11. custom-quit-message: "none"

ess插件配置
# 是否关闭加入、退出游戏的提示消息
# 当启用后, 具有对应权限的玩家加入、离开游戏将不会在公屏上显示消息
allow-silent-join-quit: false

# 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
# 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
custom-join-message: "&6[+] &b{USERNAME}&a进入游戏"

# 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
# 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
custom-quit-message: "&7[-]  &b{USERNAME}&c离开游戏"
