标题: 急需1.15.2可以在服务器使用的原版实体数量限制系统
版本：1.15.2forge官服，无法使用插件，如果是mod的话也可以接受。
如题，不能是简单的定时统一清理，效果太差，只能是实体的数量到达一个可设置的值才触发清理。
举个例子，所有实体到达了200，则清理怪物，没有达到这个值就不清理
补充：站内的相关数据包已经都试过了，没有效果

啊这那我来安利一波


首先添加一个什么也不干的前置数据包
https://www.mcbbs.net/thread-775667-1-1.html


然后创建板
scoreboard objectives add dummy dummy


游戏内高频这两条
execute store result score $count dummy if entity @e[type=#uin:tech/mobs]
execute if score $count dummy matches 200.. run kill @e[type=#uin:tech/hostile,sort=random,limit=100]

记录所有生物(排除了盔甲架，掉落物，挂画等非生物和玩家)的数量，若大于等于200个，则随机清除100个被动行生物*如果要包括掉落物则改为
execute store result score $count dummy if entity @e[type=#uin:tech/mobs]
execute store result score $count2 dummy if entity @e[type=item]
scoreboard players operation $count dummy += $count2 dummy
execute if score $count dummy matches 200.. run kill @e[type=#uin:tech/hostile,sort=random,limit=100]


另外不清楚会不会对原版命令有影响，如果以上命令不能识别的话尝试在命令前加上minecraft:

如
minecraft:execute store result score $count dummy if entity @e[type=#uin:tech/all]

先在出生点主城生成一个工具盔甲架。
summon minecraft:armor_stand ~ ~ ~ {Invisible:1b,Tags:["SMFX040"]}
再创建一个计分板
scoreboard objectives add SMFX041 dummy
再高频执行
execute as @e[type=!player] run scoreboard players add @e[type=armor_stand,tag=SMFX040] SMFX041 1
execute as @e[type=armor_stand,scores={SMFX041=200..}] run kill @e[type=!player,tag=!SMFX040]
scoreboard players set @e[type=armor_stand,tag=SMFX040] SMFX041 0
即可（可能连掉落物也会清除）
