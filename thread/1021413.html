插件简介
使用指令添加Lore实现保护你服务器的贵重物品
保护物品无法放置,丢弃!
插件原名LYAntiPlace

插件演示
https://www.bilibili.com/video/BV1bK4y1b7nz/

指令权限
/添加保护 - 为你手上的物品添加保护
/删除保护 - 为你手上的物品删除保护
/lyip help - 查看帮助
/lyip reload - 重载配置文件
lyip.use - 使用基础指令的权限(不包含reload)



配置文件
  1. anti:
  2.   #物品保护的Lore
  3.   lore: "&a[&b+&a] &f该物品被保护"
  4. tip:
  5.   #选择无法放置提示消息类型
  6.   # message - 消息提示
  7.   # bossbar - 血条提示
  8.   # title - 标题提示
  9.   # actionbar - 物品栏上方提示 (需要前置插件ActionBarAPI)
  10.   # none - 不提示
  11.   set: "message"
  12.   one: "&a[LYItemProtect] - &c当前物品你无法放置!"
  13.   two: "Nothing"
