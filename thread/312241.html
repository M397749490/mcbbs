大家好！我是Exforld001！ 这次我带来（转载）了一套 Minecraft PE 0.7.2版本的一些实用mod（还有些是不推荐使用的，），这简直是生存党的福音啊！
虽然0.7.2版本有点老，但是这个版本毕竟mod还是比较多，所以请各位将就一下！！！

这些Mod是从台湾安卓论坛上转载下来的，如果你想自己去，那也可以，不过要登录和扣分数下载。原帖地址：http://apk.tw/thread-332787-1-1.html

首先，介绍一下安装mod的方法（一步一步操作），（很简单）检查你的手机中是否真的有Mincraft PE 0.7.2版，没有的，附件里有.
1、把文件夹放到手机存储中，
2、安装方块启动器到手机中，
3、打开方块启动器。
4、方块启动器启动到Minecraft的界面之后点击屏幕上面中间的那个图标进入“游戏内打补丁”按钮。
5、按“输入”按钮
6、打开手机中刚才放文件夹的地方打开它，
7、看下面的介绍来安装自己喜爱的mod吧！！！

1.Bigger chests
更大的箱子
顾名思义，就是箱子容量变大

2.Explosive arrows
炸药箭
射出的箭会爆炸

3.Explosive arrows(over kill)
炸药箭(超过杀？！)

4.Faster player 32
玩家速度x32

5.Fly in survival
生存模式飞行
生存模式可以飞了

6.Indestructible tool
莫名其妙的工具
工具不会有使用损耗

7.Infinite arrows
射不完的箭
射箭不会有数量限制，但是前提是至少要有一支箭在背包中
个人觉得还是序号10的mod比这个好用...

8.Inventory save
物品保存

9.Night vision 夜视
消除所有的影子，黑夜和白天一样明亮，但依然会生成怪物

10.No arrow charge 不用弓箭填箭
背包中没有箭也能发射弓箭！（这个挺实用）

11.No fog
去雾，但是使用这个mod之后容易崩溃，不推荐...

12.No stack limit
没有库存限制
说是没有，其实应该还是有的，至于是多大，自己去试

13. Open containers in creative
创造模式打开箱子
不止能打开箱子，还能打开工作台，熔炉，石头切割机，甚至还能启动反应堆

14.Player nametag 玩家显名
联机时能看到玩家的用户名

15. Remove throwing gravity
投掷或射出的箭物品不会受重力影响而掉落。

16.Spawn eggs hostile
敌对生物产卵

17.Walk faster
走得更快

18.100 for one item
一个掉落物品变成100个掉落物品

19.Double cacuts
成倍的仙人掌

20.Double chest
成倍的箱子

21.Eat for full heath
吃一口食物满血

22.Fast break+one hitter
禁止破坏方块+一击毙命

23.Fast break
禁止破坏方块(解谜用)

24.High jump
跳得更高
跳跃能力增强，其实就是加一格

25.Immobile mobs
不会动的生物
除史蒂夫外的所有生物、怪物都不会移动


26.Immortal
不死
除非你掉下虚空不然你永远不会死

27.Item duplicator
物品复制
没测试过，具体怎么用自己测试吧

28.Mega jump
跳跃魔法
用了这个以后你就是跳蚤了
这个用起来很（坑爹），如果你不装序号28的mod（不会受到伤害）的话一按跳跃就会跳的老高然后摔死...
很有趣，你会看见游戏里的动物一跳起来就会跳得好高然后摔下来摔死...（貌似是躲僵尸必备）

29.No harm
不会受到伤害

30.One hitter
一击毙命

31. Render distance increase
渲染距离增加
不要对它抱有太大的期望，其实没增加多少的

32. Skeleton arrow pick up
捡起骷髅的箭
箭甚麼的重来没愁过

33. Snowball machine gun
雪球机枪
跑步时可以快速扔雪球、鸡蛋，还可以连续放置方块

34. Super jump
超级跳
跳跃能力增加2格，还没有前面的跳跃魔法跳得高

35. Too many eggs
鸡蛋太多了
鸡下蛋的效率大幅度增加，卡爆了

36. Zombies drop diamond blocks
僵尸掉落钻石块

37. Mighty tool系列 （这个mod不推荐装）
坚硬的工具
不用被它的名字骗了，用了它之后工具就不能用了
Axe＝斧头
Digger＝铲子
Pickaxe＝镐子
Shear＝剪刀
Tools＝所有工具

Cobweb＝蜘蛛网

Iron ore＝铁矿
Lapis liuzui block＝青金石块
Lapis liuzui ore＝青金石矿
Lava＝岩浆
Lava-stat＝静态岩浆
Melon＝西瓜
Obsdian＝黑曜石
TNT＝炸药包
Water＝水
Water-stat＝静态水
Yellow flowers＝黄色花

39. 255 server slots
服务器上限255人
不过我估计10个人就已经卡爆了

40. Caves patch
洞穴补丁
创造新世界时生成洞穴

41. Climbing
攀爬
有了它你就是蜘蛛侠了

42. Fast flames
快速燃烧
燃烧方块的速度加快

43. IP blind
IP地址隐藏
单机党必备

44. No animated texture
没有动画的材质
即高清修复补丁，使用之后高清材质的方块贴图不会有错误了，但是水、岩浆、火焰的动画会消失，建议在16x以上的材质使用(不包括16x)

45. No crafting table
没有工作台
其实是把工作台的菜单合并到背包当中去

46. No stone cutter
没有石头切割机
和上面那个一样，把石头切割机的菜单转移到背包中去

47. Night in creative
创造模式加入黑夜环境

48. No water dynamic
没有水动画
这个好像自带

49. Super inferno
超级地狱
下界生成的物品增多

50. Tall grass
高高的草
创造新世界时会长草


51. More slots
更多物品槽
请按顺序安装

52. Pick me
捡起我
准星范围128格，也就是说只要是你能看到的地方，都可以用准星在上面放置方块，还可以远程耕地、点火，最逆天的mod
注意，仅限准星模式

53. More item in creative
创造模式更多物品
增加了基岩，火焰，蜘蛛网，隐形基岩，还有静态水和静态火

54. Free crafting
免费制造
在生存模式制作物品不花费任何材料

55. No GUI blocks
不用GUI的方块
不使用材质包的材质

56. Anaglyph Unlock
立体解锁
戴上红蓝3D眼镜会有立体效果，但是并不是很好

57. Bigger spider
更大的蜘蛛
蜘蛛变大了，但是触点貌似没有改变

58. Insta-destroy
快速破坏
史蒂夫的右手成为神器，神一般地存在著



59. More ore
更多矿石
创造新地图时会生成很多矿石

60. Redstone drops glowing Obsidian
红石矿石掉落发光的黑曜石

62. Snowboll grenade
