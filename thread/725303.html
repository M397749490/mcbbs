AntiContainer

简介：
这是一款可以禁用某些容器的插件，支持自定义容器名称，支持自定义警告信息，支持指令获取物品type
config:
  1. #本配置文件为GB2312编码，UTF-8请自行转码
  2. #作者：Healthable
  3. #是否开启
  4. enable: true
  5. #提示信息
  6. message: §e对不起您不能打开该物品
  7. #物品名称,如果不知道怎么获取，本插件提供命令，拿着物品输入/AntiContainer type   获取，请严格遵守大小写
  8. item:
  9. - "CHEST"
复制代码
命令：
/ac type 获取手上物品的type
权限：
Anticontainer.use   默认OP拥有
