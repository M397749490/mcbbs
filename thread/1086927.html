在进服后进行点击验证，能阻挡多数作弊端，可配置验证失败执行的指令
无反作弊服务端目前非常建议添加。当然有反作弊加不加都无所谓咯

更多图片请见原帖


已测试作弊端:
成功阻挡(带.指令)：Wur*, Sigm*, Aristo*...(2020/7/26)
阻挡失败(无或可更改作弊端的命令前置.)：...


命令及权限:
/verify 获取你的验证信息 - verify.use
/verify reload 重新加载配置文件 -verify.reload
需验证 - verify.bypass


配置:

  1. # By Heron4gf
  2. length: 3 # 安全码长度，3足以
  3. verifyButton: "&a&l[ CLICK TO VERIFY ]" # 信息，可更改为"[左键这里验证]"
  4. hoverButton: "&3&lCLICK HERE!" # 把你鼠标停留在上边的信息时会浮现的信息
  5. dotCommand: ".say" # 你懂的，不懂就别改咯
  6. commandOnVerify: "msg %player% you have verified yourself"
  7. commandOnWrongCode: "say %player% was kicked"
  8. #
  9. # 验证失败执行的指令，小游戏服建议直接ban-ip
  10. # 使用 %player% 代表被kick的玩家
复制代码

已知问题:
- 部分服务器玩家发送信息控制台抛异常
