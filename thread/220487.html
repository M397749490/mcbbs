1.6.2的MCPC服务端    已安装forge

建立一个启动服务器的bat后打开    服务器建立完全后会有mods文件夹

MCPC同时兼容MOD以及插件
  1. @ECHO OFF

  3. color c
  4. title
  5. SET BINDIR=%~dp0
  6. CD /D "%BINDIR%"

  8. "%ProgramFiles%\Java\jre7\bin\java.exe" -Xmx1024M -Xms512M -jar mcpc-plus-1.6.2-R1.1-forge871-B97.jar -nojline
  9. PAUSE
复制代码
如果Java路径Lz没修改过    一致的话   复制以上文字   建立一个txt    粘贴到txt   然后把txt重命名为：点我启动服务器.bat   即可
