FlySpend是一个花钱就能飞行的插件！


1.插件必要前置 vault 金钱，还可以配合指令牌子

2.使用方法和主要特点

①需要给允许飞行的权限，权限：FlySpend.fly
②需要装上滑翔翼（下面有合成表）才能进入飞行状态，中途拿掉滑翔翼将会坠落
③ 扣钱按周期检查，每周期60秒在配置文件里设置，没扣一次钱就能进入飞行状态
④ 如果玩家在一个周期内没有飞行（要落地哦），飞行状态自动取消，不再继续扣钱！


3.配置文件
  1. # FlySpend v1.0.1 Config
  2. # 启用飞行状态消耗金钱，缺省每分钟100
  3. # 'cost per period'启用一个飞行周期消耗的金钱，缺省每分钟100
  4. # 'fly period'每次消耗飞行的周期长度，缺省60秒
  5. # '2016.3.31 By Liangzhu.
  6. cost per period: '100'
  7. fly period: '60'
  8. disable on death: true
  9. banned players: []
  10. allow while flying:
  11.   pvp: true
  12.   bow: true
  13.   throwing potions: false
