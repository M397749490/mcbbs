一、插件功能

此插件不再更新，请移步GrScriptBlock
此插件不是什么高大上的回城插件，而是一款类似于脚本方块的插件。

一条指令

执行多条指令

指令间支持延迟

PlaceHolderAPI支持

多种参数，全服信息，Title，ActionBar，声音，任你发送





此插件提供了一个可以自由修改的配置文件，在里面你可以配置好一些指令脚本，用于在游戏中，使用此插件的一条指令来调用这些脚本，使其从不同的地方运行指令，并且这些脚本支持延迟，支持冷却，让你用各种你想要的体位执行指令，或者对玩家发送一些特殊消息，包括声音，Title。

此插件用于与其他只支持单指令(如CommandCode)，或作为指令发起的脚本插件使用


二、插件特性
配置文件简洁明了

脚本支持全局冷却，个人冷却

支持延迟执行，强，无敌

支持PlaceHolderAPI，更多拓展

能发送各种类提示信息，甚至是播放声音

四、插件指令及权限

指令功能权限
/ggc reload重载插件配置文件只有OP能够使用
/gcc run <指令组名> <玩家名>对指定玩家运行配置好的指令组只有OP能够使用

五、插件配置文件与使用说明
1、安装插件
2、打开config.yml，配置好自己想要的指令组，包括指令组名，玩家指令，后台指令
3、重载插件
4、在需要的时候使用指令/ggc run <指令组名> <玩家名>

建议下载配置文件后使用notepad++阅读，内含插件功能详细注释

玩家指令组支持的特殊配置：
  1、  %player% 替换为指定玩家的名字
  2、  单行若格式为  @delay  数字  则指令组会延迟数字所表示的时间后再执行下一条指令，单位为游戏tick
  3、  以 [op]:             开头的指令行将会以最高权限执行
  4、  以 [msg]:          开头的指令行将会对指定玩家发送其后面的信息
  5、  以 [title]:        开头的指令行将会对指定玩家发送其后面的标题信息，仅支持1.8及以上版本的服务器
  6、  以 [actionbar]: 开头的指令行将会对指定玩家发送一条后面的字符组成的actionbar信息，仅支持1.8及以上版本的服务器
  7、  以 [sound]:       开头的指令行将会对指定玩家播放其后面的声音

后台指令组支持的特殊配置：
  1、%player% 替换为指定玩家的名字
  2、单行若格式为  @delay 数字  则指令组会延迟数字所表示的时间后再执行下一条指令，单位为游戏tick
  3、以 [msg_all]:       开头的指令行将会对所有人发送其后面的信息
  4、以 [title_all]:     开头的指令行将会对所有人发送其后面的标题信息，仅支持1.8及以上版本的服务器
  5、以 [actionbar_all]: 开头的指令行将会对所有人发送一条后面的字符组成的actionbar信息，仅支持1.8及以上版本的服务器
  6、以 [sound_all]:     开头的指令行将会对所有人播放其后面的声音
