首先建立一个计分板
  1. /scoreboard objectives add feather dummy
复制代码
然后循环并按顺序执行以下命令
  1. /execute as @a[nbt={Inventory:[{Slot:-106b,id:"minecraft:feather"}]}] store result score @s feather run clear @s feather 0
  2. /effect give @a[scores={feather=1..}] jump_boost 30 1
  3. /clear @a[scores={feather=1..}] feather
  4. /scoreboard players remove @a[scores={feather=1..}] feather 1
  5. /execute at @a[scores={feather=1..}] run summon item ~ ~ ~ {Item:{id:feather,Count:1}}
  6. /execute as @a[scores={feather=1..}] store result entity @e[sort=nearest,limit=1,type=item,nbt={Item:{id:"minecraft:feather",Count:1b}}] Item.Count byte 1 run scoreboard players get @s feather
  7. /scoreboard players reset @a[scores={feather=1..}]
复制代码
即可做到手持羽毛按下F后给予跳跃提升并消耗一个羽毛（已知bug:当羽毛数量超过两组时，羽毛会被全部清除。但是我觉得小游戏地图里很少有道具超过两组的情况吧~~~要修复这个bug，可能需要借助function写一个循环结构）

关于破坏方块后执行命令
计分板有一个判据是破坏方块数量（minecraft.mined:minecraft.方块名），比如minecraft.mined:minecraft.diamond_block破坏钻石块的数量。检测到数量增加后执行命令，并将分数清零即可

关于tag
1.13后tag命令被单独分离出作为一个命令，不再通过计分板命令添加。格式为
  1. /tag <实体> add/remove <标签名>    #添加或移除标签
  2. /tag <实体> list               #查看目标实体的标签
