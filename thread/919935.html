标题: [void island control]自定义一个空岛类型教程
void island control 是一款神奇且能够生成多种空岛类型的mod，尽管原版就已包含了很多空岛类型，但这些空岛类型和 sky resource 2 配合实用更佳。


在制作整合包的过程中，有莫有某种方式能让 void island control 自己定义一个全新的空岛类型来实现用其他mod开局空岛呢？答案肯定是有的，不然也不会有这篇帖子咯。



在翻阅void island control的curseforge主页后，确定void island control使用structure block（结构方块）生成的nbt数据进行岛屿类型管理。详细的structure block方块内容请直接移步至：https://www.mcbbs.net/thread-479527-1-1.html



那么接下来正式开启本次教程了哦~


一、获取到structure block（结构方块）

      【注意】structure block无法通过除了/setblock或/give指令以外的途径获得

           指令：/give <玩家名> minecraft:structure_block <数量>

                                        /setblock <x坐标> <y坐标> <z坐标> minecraft:structure_block

四、编辑void island control的config

将\.minecraft\save\<编辑时的存档名> 里structure文件夹下的 <结构名称>.nbt文件移动进\.minecraft\config\voidislandcontrolstructures里。

回到\.minecraft\config文件夹里，找到 ‘voidislandcontrol.cfg’ 文件进行编辑.

找到 “S:customIslands <>” （我的在75行），并在尖括号内填上刚刚自定义的<结构名称>，保存生效。

五、重启minecraft游戏

重新建立一个存档，然后就可以使用指令  /island  create <结构名称>  实现自定义岛屿类型的创建。

六、结束语

通过使用自定义空岛类型，能够让整合包作者使用更多更有趣的开局mod制作出更加好玩的整合包，而不仅仅是局限于必须使用 sky resource2 配合  voild island control开局。这样，无论是单人空岛生存还是服务器空岛生存，都能够使用这个mod达到自定义空岛的效果
