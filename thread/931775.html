如果你的钻石剑模型是以"builtin/generated"为父模型的话，把粒子贴图的贴图参数调整为layer0；如果没有父模型的话，单独设置一个贴图参数为"particle"的项。
例如原版的钻石剑模型：

  2. {
  3.     "parent": "item/handheld",
  4.     "textures": {
  5.         "layer0": "item/diamond_sword"
  6.     }
  7. }
复制代码

中的那个layer0会在builtin/generated中作为粒子贴图使用，但是如果没有这个父模型的话，就要加上一个"particle"贴图，就像这样

  2. {
  3.         "textures":{
  4.                 "layer0":"item/diamond_sword",
  5.                 "particle":"item/diamond_sword"
  6.         },
  7.         elements:[
  8.                 ...

以下是diamond_sword.json的代码，应该使用了父模型：
{
    "parent": "item/handheld",
  "textures": {
    "layer0": "items/diamond_sword"
  },

  "overrides": [

    {
      "predicate": {
        "damaged": 0
      },
      "model": "item/diamond_sword_original"
    },

    {
      "predicate": {
        "damaged": 1
      },
      "model": "item/diamond_sword_original"
    },

    {
      "predicate": {
        "damaged": 0,
        "damage": 1
      },
      "model": "item/ethaxium_sword_d"
    }
  ]
}
随后我又根据以上代码添加了diamond_sword_original.json和ethaxium_sword_d.json：
{
    "parent": "item/handheld",
    "textures": {
        "layer0": "items/diamond_sword_original"
    }
}
