           指令&权限     使用教程           
将插件放入plugins文件夹后重启服务器即可

          指令：
          /jcs enable 开启网页端验证
            /jcs disable 关闭网页端验证（脚本服务器故障时建议）

          权限：
          jcs.enable, jcs.disable


使用教程

§1.建议直接使用虚拟主机搭建，下载脚本(见最下方下载部分)ZIP文件，上传到主机，解压
然后打开Config/config.php进行数据库信息配置
在phpMyAdmin等管理程序中执行以下SQL语句建立数据表：
CREATE TABLE jcs_players (
name VARCHAR(64) NOT NULL,
password VARCHAR(64) NOT NULL,
email VARCHAR(128) NOT NULL,
logged INT(1) NOT NULL
)

【执行上面语句后，执行下面语句】
INSERT INTO `jcs_players`(`name`, `password`, `email`, `logged`) VALUES ('@ERROR', 'error' ,'error', 0)

(INSERT插入 防止SQL注入)

§2.配置config.yml的Server部分，见配置文件说明，这将直接影响插件网络访问的地址
§3.重启服务器
§4.强烈建议OP们先注册账号，以免被率先注册，密码支持中文
§5.网页端注册后，请登录，登录后即可直接进入服务器，若未登录，则被踢出服务器

已经在使用最初版本的PHP脚本的服主请：
记得删除数据表（DROP TABLE jcs_players）
然后重新创建
