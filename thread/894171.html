看了很多dalao的地图了。
蛮好奇他们地图里面的脚本方块怎么实现的？
比如说踩上一个金块就能播放一个粒子效果并且执行一条指令。

作者: Ph-苯    时间: 2019-7-30 22:09
1.8-1.12:
executs @a ~ ~ ~ detect ~ ~-0.1 ~ gold_block 0 指令
1.13+ :
execute as @a at @s if block ~ ~-0.1 ~ gold_block run 指令
渲染粒子效果:
particle ……(这玩意儿的用法到网上随便搜，但推荐去维基)
