插件介绍


WishingWells插件可以给你的服务器添加许愿池，玩家只要向许愿池里丢物品，就有可能“愿望成真”，获得奖励

插件指令

  1. /well create <name>: 创建许愿池
  2. /Well delete <name>: 删除许愿池
  3. /Well list: 查看所有许愿池
复制代码
插件权限

  1. well.command ：创建许愿池
  2. well.use ：使用许愿池

插件使用

玩家可以往许愿池里面丢东西“许愿”，就有可能获得奖励

插件配置

  1. #许愿间隔，多久可以许愿一次，单位秒
  2. Delay: 60

  4. #用来许愿的祭品
  5. Accepted:
  6. - <itemnumber>                #数量
  7. - 264                                 #物品ID

  9. #愿望成真后奖励的物品
  10. Returned:
  11. # 格式如下
  12. # 名称(必须是英文):
  13. # - <物品ID> <数量> <属性>
  14. test:
  15. - 266 1
  16. Example:
  17. - 278 1 efficiency:1 durability:1 fortune:1 name:&4Gigadrill lore:The_drill_that_&npierces|the_heavens

  19. #愿望成真的概率，百分制
  20. ReturnedChance:
  21. # 名称和上面对于，格式如下
  22. # 名称: 概率
  23. Example: 50
  24. test: 50

  26. #提示，我顺便翻译了
  27. CongratsMessage: '&a恭喜你，愿望成真了，你从许愿池获得了奖励!'

  29. TooBadMessage: '&c哎，你的愿望没有实现，你的祭品消失了!'

  31. ItemNotAccepted: '&4你扔的东西不是祭品，不能许愿哦!'

  33. Delay message: '&c啊，你两次许愿的间隔太短了，请在 %s 秒后再许愿!'
  34. #自动更新
  35. auto-update: true
