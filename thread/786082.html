PaperSpigot 服务端生成文件详解

以下文件基于 PaperSpigot 1.12.2 最新版进行讲解
版本不同有可能导致参数,设置,文件不同,请自行对号入座

成功开启 PperSpigot 服务端时会生成以下文件夹与文件
有些没列出来的说明意义不大,一般不需要用到,你们可以自己去了解一下

logs -> 存放服务器运行日志
plugins -> 存放服务器插件
world -> 主世界文件夹
world_nether -> 地狱世界文件夹
world_the_end -> 末地世界文件夹

banned-ips.json -> 被封禁的IP地址列表
banned-players.json -> 被封禁的玩家列表
bukkit.yml -> bukkit 相关设置
ops.json -> 服务器管理员列表
paper.yml -> paper 相关设置
server.properties -> server 相关设置
spigot.yml -> spigot 相关设置
usercache.json -> 玩家缓存文件
whitelist.json -> 玩家白名单列表

接下来我来讲解一些重要文件的设置推荐以下所有文件都使用 notepad++ 打开
