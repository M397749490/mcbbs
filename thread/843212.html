感谢诸多热心玩家的付出。


基岩版1.9是一个于2019年2月6日发布的重大更新。此次更新将加入一些于1.8内没有加入的村庄和掠夺特性。


新内容
方块
木桶、钟、高炉、制图台和烟熏炉
  • 当前没有功能。
制箭台
  • 可用工作台和箭合成。
  • 当前没有功能。
花
  • 加入了矢车菊。
    • 能合成蓝色染料。
    • 出现在平原生物群系。
  • 加入了铃兰。
    • 能合成白色染料。
    • 出现在森林生物群系。
砂轮
  • 当前没有功能。
  • 版本独有：使用Java版18w44a快照里的旧材质。
灯笼
  • 充当新光源。
告示牌
  • 加入了云杉木告示牌、白桦木告示牌、丛林木告示牌和深色橡木告示牌。
锻造台
  • 可用工作台和圆石合成。
  • 当前没有功能。
  • 版本独有：使用Java版18w44a快照里的旧材质。
平滑方块
  • 加入了平滑石头、平滑砂岩、平滑红砂岩和平滑石英块。
台阶
  • 加入了石台阶、安山岩台阶、磨制安山岩台阶、闪长岩台阶、磨制闪长岩台阶、花岗岩台阶、磨制花岗岩台阶、苔石砖台阶、苔石台阶、平滑砂岩台阶、切制砂岩台阶、平滑红砂岩台阶、切制红砂岩台阶、平滑石英台阶、红色地狱砖台阶和末地石砖台阶。
  • 版本独有：加入了切制砂岩台阶和切制红砂岩台阶。
楼梯
  • 加入了石楼梯、安山岩楼梯、磨制安山岩楼梯、闪长岩楼梯、磨制闪长岩楼梯、花岗岩楼梯、磨制花岗岩楼梯、苔石砖楼梯、苔石楼梯、平滑砂岩楼梯、平滑红砂岩楼梯、平滑石英楼梯、红色地狱砖楼梯和末地石砖楼梯。
墙
  • 加入了砖块墙、安山岩墙、闪长岩墙、花岗岩墙、海晶石墙、石砖墙、苔石砖墙、砂岩墙、红砂岩墙、地狱砖墙、红色地狱砖墙和末地石砖墙。
其他方块
  • 制图台、制箭台、砂轮、钟、木桶、锻造台、烟熏炉、高炉、灯笼
    • 只有在启用“实验性选项”时才可用。

生物
掠夺者
  • 敌对生物，是灾厄村民的一部分。
  • 有24点生命值。
  • 手持弩。
  • 被杀死时机率掉落随机耐久的弩（受抢夺魔咒影响）。
  • 会袭击或占领村庄，并杀死村民。
  • 不能穿戴任何种类的盔甲。
被动生物
  • 现在会随机进入求偶模式。

世界生成
竹林
  • 丛林的新变种。
  • 包含竹子，灰化土和熊猫。

命令
showDeathMessages
  • 允许玩家在玩家或驯服的生物死亡时选择是否在聊天中出现消息。
  • 有新的“立即重生”的选项。
/tellraw
  • 允许使用原始文本格式用JSON发送可翻译文本到聊天。
/titleraw
  • 允许使用原始文本格式用JSON发送可翻译文本到标题。
  • 现在/kill命令可以杀死创造模式下的玩家了。
/particle
  • 加入新的颗粒：
    • minecraft:test_flipbook
    • minecraft:test_vertexrandom
    • minecraft:balloon_gas_particle
    • minecraft:mobspell_emitter
    • minecraft:basic_crit_particle
    • minecraft:portal_directional
    • minecraft:bubble_column_down_particle
    • minecraft:portal_east_west
    • minecraft:portal_north_south
    • minecraft:bubble_column_up_particle
    • minecraft:crit_emitter
    • minecraft:splash_spell_emitter
    • minecraft:end_chest
    • minecraft:totem_particle
    • minecraft:evocation_fang_particle
    • minecraft:water_splash_particle
    • minecraft:evoker_spell
    • minecraft:water_wake_particle
    • minecraft:magnesium_salts_emitter
    • minecraft:wither_boss_invulnerable
    • minecraft:mob_portal

游戏规则
  • 通过新游戏规则（默认为10,000）可以限制通过函数运行的命令数量，以限制性能问题。
函数
  • 现在可以在运行每刻时新建一个更新循环。
标签
  • 自定义标签可以应用于实体和玩家，以创建更灵活的选择器分组。
  • 在成分中加入has_tag过滤器来允许检查实体是否有标签。
  • 可选的标签的自动填充功能
  • 现在/kill命令可以杀死创造模式中的玩家。

常规
暂停菜单
  • 加入新的“反馈”按钮
    • 显示Minecraft的反馈页面、漏洞追踪器、和Mojang帮助页面的链接。
  • “如何游玩”按钮现在在游戏中的设置菜单中可见。

更改
方块
  • 苔石被重命名为“苔圆石（Mossy Cobblestone）”。
  • 地狱砖栅栏的合成配方从4块地狱砖变成2块。
    • 曾经的合成配方现在用于合成下界石砖墙。
  • 平滑沙石和平滑红沙石分别被改名成“切制沙石”和“切制红沙石”。
  • 告示牌被改名成“橡木告示牌”。
    • 一个橡木告示牌只能用橡木来合成，而不是其他各种木材。
  • 石质台阶被改名为平滑石头台阶，现在需要平滑石头来合成，而不是原来的普通石头。
    • 曾经的合成配方现在用于合成新出的石头台阶。
  • 沙石和红沙石楼梯和台阶的合成不能使用任何除了普通沙石和红沙石以外的沙石种类。
炼药锅
  • 现在可以盛熔岩。
    • 现在会把在内的实体点燃，并且发光。
绊线钩
  • 现在在破坏时被激活，除非使用剪刀。
羊毛
  • 白颜色羊毛（White colored wool）被改名成白色羊毛（white wool）

游戏内容
  • 在加载屏幕中加入几个新的社区提出的提示。
  • 当被驯服的生物死后，玩家会在聊天记录里收到一条信息。(MCPE-35138)
  • 提高了使用函数命令时的性能，它们现在在世界加载时预编译。

常规
Minecraft Script Engine
  • 使用JavaScript。
  • 脚本可以被编写并与行为包绑定，以便监听和响应游戏事件、获取和修改实体组件、影响游戏行为。
  • 只能通过Windows 10并从实验性选项中获得。
多人游戏
  • 玩家现在可以加入并游玩小版本不匹配的游戏（MCPE-38945）

修复
修复了30个漏洞
