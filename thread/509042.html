如图建设树场，图中使用的原木是你要种什么树，用什么原木，其他摆放的材料没有限制

我们先写砍伐1颗树的代码

需要提前在turtle的物品栏第一格放树苗，第二个放要种的树的原木。
  • function cutAtree()
  •     turtle.select(2)
  •         while turtle.compare() do
  •            turtle.dig()
  •            turtle.digUp()
  •            turtle.up()
  •         end
  •            while turtle.down() do
  •         end
  • end



代码很简单，就是对比前面是原木，就砍。最后再下来。
试试效果

人造树不要在意

然后让turtle按预定的轨迹走，就是碰到障碍物就右拐，这就是为什么道路两头放木板的原因
  • while true do
  •     if not turtle.forward() then --转弯
  •         turtle.turnRight()
  •         end
  • end




然后发现即使碰到人，turtle也会右拐，就会跑出外面。这样如果是怪物跑过来，就会试turtle错了，turtle很可能会跑得远远的(最伤心了)

所以必须加个条件，让turtle对比前面的方块是原木才能右拐。

相应代码改为
  • while true do
  •     if not turtle.forward() and turtle.compare() then --转弯
  •         turtle.turnRight()
  •         end
  • end




然后让turtle在植树点判断树长大没有，然后砍树
  • while true do
  •     turtle.select(2)
  •     if turtle.compareDown() then --检查是否是植树点
  •            turtle.turnLeft()
  •            if turtle.compare() then --检查树有没有长大
  •               cutAtree()
  •            end
  •                 turtle.turnRight()
  •         end
  •     if not turtle.forward() and turtle.compare() then --转弯
  •         turtle.turnRight()
  •         end
  • end



现在已经能完成任务了，但还有几个问题
1.turtle不会自动植树
2.turtle不会自己捡起树苗，造成浪费
3.刚启动时，turtle可能会出错

所以我又改了下代码，下面放出完整的代码，可以直接复制使用。然后新建个程序名叫startup,内容是shell.run("砍树程序的程序名")
就可以全自动砍树了。生存再也不缺木头了。

  • function cutAtree()
  •     turtle.select(2)
  •         while turtle.compare() do
  •        turtle.dig()
  •            turtle.digUp()
  •            turtle.up()
  •         end
  •            while turtle.down() do
  •         end
  •         turtle.select(1)
  •         turtle.place()
  •         turtle.select(2)
  • end
  • function pickUp()
  •     turtle.select(1)
  •     turtle.suck()
  •         turtle.select(2)
  • end
  • function startCheck()
  •     turtle.select(2)
  •      if not turtle.detectDown() then --检查turtle是否在空中
  •                 cutAtree()
  •                 turtle.turnRight()
  •          else
  •             if turtle.compareDown() then --检查是否在植树点
  •                     if turtle.detect() then --检查turtle的方向是否朝前
  •                         turtle.turnRight()
  •             end
  •                 end
  •          end
  • end
