常见问题:

1.如何下载/获取NukkitAPI？
你可以在 Nukkit的帖子 里面找到Nukkit下载地址，然后直接把Nukkit的jar作为类库导入项目

2.我在开发中遇到Bug或者对API有什么建议如何反馈？
你可以在Github上发布你的issues，或者在Nukkit官方论坛Post

3.如何编译插件源码为Jar？
如果你在使用IDE，编译方法将会变得非常简单：
Eclipse：右键项目 → 导出 → jar （记得选中你的代码以及plugin.yml等资源文件）
IDEA： 新建Artifacts → 拖入你的plugin.yml等资源文件及右侧的complie output
其他： 编译所有Java文件，然后打包


4.如何在安卓运行Nukkit？( 需要Root )
不支持Java8的安卓系统：http://www.mcbbs.net/thread-549811-1-1.html(Snake1999)
支持Java8的安卓系统：http://tieba.baidu.com/p/4174201008(Finally_lie)

5.和开发团队相关人员及时通信？
+企鹅Group：515521405

6.如何在IDEA、Eclipse调试Nukkit？
IDEA、Eclipse(有待补充)

7.怎么开发插件、插件开发教程？ (中文)
UnknownDomain、fromgate

8.编译或运行报错: UnsupportedClassVersionError
Nukkit使用了Java 8，请使用JDK/JRE 8.
Java 8的特性可以使Nukkit的运行效率更加高
