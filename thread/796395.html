插件介绍
DynamicBungeeAuth 是一个较为先进的一个正版玩家登录系统，它可以为盗版玩家来伪造一个正版的“通行证”让他们注册以及登录的一个账户。
DBA 只能在 BungeeCord 里面或用作于 Spigot 里面作为 Addons 使用，是一个安全而又简单的玩家注册/登录系统。
DBA 必须依靠 MySQL 进行存储玩家的账户以及各个数据。
本插件提供了一些东西，比如 Server Balancer, Multiple BungeeCord 的支持，Multiple Lobby-Auth 服务器的支持和较为简单的config.yml。
PS:DBA 是一个“合二为一”的插件，他可以在BungeeCord或Spigot上运行。
PS:不可以只在Spigot上运行而不安装BungeeCord

插件功能
  • 防破解/攻击 —— 当服务器一个时间点内有大量玩家登录时，本插件将会阻止部分玩家进行登录，让插件做完清理缓存的工作。
  • 多个版本支持 —— 本插件支持服务端版本 1.7.X--1.12.X 的 BungeeCord 以及 Spigot 运行
  • Community Driven —— Enter your idea for them to be build into the next updates （不知道如何翻译它，请dalao指教）
  • 黑名单密码 —— 可以自行配置服务器内要禁止的密码比如 “123”、“asd”、“test” 这些
  • 同IP下设置最多可注册、登录多少个账户 —— 可以设置单个IP下能拥有几个正版/盗版账户
  • 可以在 BungeeCord 和 Spigot 下同时运行 —— 它们可以安装在各个子服和 BungeeCord 核心内但他们的工作原理是不同的
  • 正版玩家登录系统 —— 正版玩家不需要进行注册以及登录，他们将会免密自动登录随后传送到大厅服或你自己配置的传送的服务器
  • ID 保护系统 —— 非正版玩家无法使用正版玩家的 ID 进行注册。举个例子，当一个盗版玩家注册了一个 ID 为 “md_5” ，一个正版玩家同时更改 ID 为 “md_5” ，然后进入了服务器，该 ID 将不会被自动登录，还是需要输入密码的，从而达到防止正版用户窃取盗版用户ID的行为（这可以在配置中禁用）
  • 登录服务器 —— 可以设置登录服当然也可以不设置它
  • Multi BungeeCord 支持 —— 你可以在多个 BungeeCord 环境下使用该插件
  • Multi Lobby/Server 支持 —— 在 Spigot/Bukkit 上可以安装在任意一个服务器上，然后可以配置一个大厅的配置文件
  • BungeeCord 的 Online_Mode 和 Offline_Mode 支持 —— 无需将 BungeeCord 设置为 Offline_Mode 来运行这个插件，本插件将模拟一个 Offline_Mode 运作，但实际上他就是一个 Online_Mode 模式。（且是受保护的）同时，这个插件支持 Offline_Mode 但是作者推荐在 Online_Mode 模式下使用
  • 药水效果 —— 当玩家还没有登录的时候，可以使用药水效果比如失明来限制玩家的移动
  • 缓存 —— 这将降低发送到 Mojang API 的请求数量，这使得登录速度更快。缓存还将缓存非正版玩家信息以加快登录速度。
  • 正版玩家皮肤显示 —— 正版玩家将会显示他们的皮肤而不是 Steve 或 Alex （需要 Online_mode
    为 true）
  • 密码加密存储 —— 默认加密数据为 "Hash and Salt" ，还可以支持 SHA 或 SHA512
  • 禁止使用指令 —— 玩家将在登录服务器之前不能使用任何指令
  • Sessions —— 当非正版玩家第一次进入服务器会自动记录数据，他们将在第二次登录后永久生效
