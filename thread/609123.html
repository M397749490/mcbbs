这个插件可以通过箱子GUI向玩家展示KIT的内容。
  • 简单的设置. 你需要一个Essentials插件 推荐EssentialsX. 然后下载最新的KitPreview放到plugins装载插件!?
  • 高效. 新版本的KitPreview经过优化,并不会过多的占用服务器资源.?
  • 支持全息. 指令 /kp holo
  • 支持粒子效果: 指令 /kp particle
  • Vault: KitPreview插件支持Vault.  指令 /kp buy eco <kit> <price>.
  • 指令: 你可以为你的Kit增加指令 /kp buy addcommand <kit> <command> 或 /kp buy removecommand <kit> <command>?
  • 支持所有方块! 你可以设置所有类型的方块用来打开GUI 指令 /kp set <kit>.?
  • 购买. 玩家可以购买 /kp buy setlink <kit> <link>.?
  • 牌子. 任何有权限的玩家都可以使用和创建一个Kit牌子:
    - previewkit.sign.create
    - previewkit.sign.use    ?
  • Keys. 你可以给一个玩家特定的Kit 指令 /kp key <kit> <player>.?
另外内容请移至SpigotMc自行查阅
