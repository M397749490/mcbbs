功能

  • 强化玩家生命上限
  • 可以配置多种不同效果的强化物品
  • 不会与其它修改生命上限插件冲突

如何强化

玩家`食用`强化过的物品后,会有几率增加生命上限.(注意设置强化到无法食用的物品上是无效的)

如何设置强化物品

OP可使用命令:

  • `/stre set <强化id>`来设置手中物品强化
  • `/stre del` 删除手中物品强化

配置config.yml



  2. #utf-8格式

  4. #指令:
  5. #/stre set <强化id> 设置强化
  6. #/stre del 删除强化

  8. #此插件最多增加的生命上限,>=0.0,-1表示无限制
  9. max: 100.0

  11. #强化列表
  12. strengths:
  13. - id: "lv1"                       #在管理指令那会用到
  14.   name: "&6+初级无尽强化丹+"       #名字,同时也是判断物品是强化丹的唯一标记
  15.   chance: 0.05                    #成功几率,0.0001-1,如0.05表示5%
  16.   add: 0.5                        #增加的生命上限,>=0.0
  17. - id: "lv2"
  18.   name: "&6+中级无尽强化丹+"
  19.   chance: 0.05
  20.   add: 1.5
  21. - id: "lv3"
  22.   name: "&6+高级无尽强化丹+"
  23.   chance: 0.03
  24.   add: 3

  26. #语言
  27. lang:
  28.   - "10 &c无法再增加了."
  29.   - "20 &a使用{0}&a成功,增加{1}生命上限."
  30.   - "30 &c使用{0}&c失败."
  31.   - "40 &c无权限."
  32.   - "50 &c此命令只能由玩家发出."
  33.   - "60 &c请将物品拿在手上."
  34.   - "70 &c此物品无强化信息."
  35.   - "80 &c删除强化成功."
  36.   - "90 &c指定ID的强化信息不存在."
  37.   - "100 &a设置强化成功."
