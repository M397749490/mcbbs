Q1：Lore 支持颜色吗？
Lore 不支持 Json 文本，但是你可以在函数里用样式代码 § 来显示颜色。

Q2：如何生成一个无底座、不会被破坏、有双手、东西不可以拿下来但可以放上去、小个的盔甲架？
推荐wiki 区块格式页面（中文，不推荐），在 armor_stand（盔甲架）下面详细列出了每一个标签的名字及其作用。
我把你问的都写出来了。
NoBasePlate:1b 无底座
Invulnerable:1b 无敌（创造模式仍可破坏）
ShowArms:1b 有手
Small:1b 小个
DisabledSlots:1108169199616 只能放不能拿

Q3：如何检测脚下有某个方块或者头上有某个方块时运行指令
execute as @a at @s if block ~ ~-1 ~ minecraft:stone run say 我的脚下有石头！
execute as @a at @s if block ~ ~2 ~ minecraft:stone run say 我的头顶上有石头！

Q4：最后，有什么装比（坑人）的指令么，嘿嘿嘿
没有，gun

Q5：自定义药水
推荐 wiki 这个页面（中文，不推荐），列出了有关自定义药水的所有 NBT。举个例子：
/give @s minecraft:potion{CustomPotionEffects:[{Id:1b,Duration:100}]}
给予命令执行者五秒的速度效果的药水
