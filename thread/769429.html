插件命令
重要的命令已用红色标记









  • /sg 帮助

  • /sg list 列出说有的战场

  • /sg join <战场> 加入战场

  • /sg leave 离开游戏
  • /sg kits 选择职业
  • /sg shop 打开商店
  • /sg stats 个人信息
  • /sg lobby 传送至大厅/sg info 游戏版本信息
  • /sg wand 进入选择模式/sg create <战场名> <最少人数> <最大人数> 创建一个战场
  • /sg wand 来开启选择模式
  • sg delete <战场名> 删除一个战场
  • /sg Enable | disable 启用或禁用一个战场
  • /sg Addspawn | Removespawn 增加 | 移除 一个出生点
  • /sgadddeathmatch | removedeathmatch 增加 | 移除 一个死斗点
  • /sg reload 重载插件
  • /sg Coins add | remove | set <玩家> <数值>  增加 | 删除 | 设置 玩家的硬币
  • /sg setholostats 设置战绩统计位置
  • /sg updatechests <战场> 更新箱子位置
  • /sg setglobalobby 设置游戏大厅

现在我们来制作一个战场吧！
举个栗子：
  • /sg wand 开启选择模式，然后选择两点（与领地相同)
  • /sg create <战场名> <最少人数> <最大人数> 来创建一个新的战场
  • /sg addspawn （一共要重复上面设置的最大人数)
  • /sg adddeathmatch 增加一个死斗出生点
  • /sg setgloballobby 最后我们在设置游戏大厅
  • /sg updatechests <战场> 更新箱子位置
  • /sg Enable <战场名> 启用战场
  • 好了，你现在设置完了，使用命令/sg join <战场> 加入游戏吧!
高能警报
前方职业设置
首先，我们打开插进文件夹中的kits.yml文件
然后我们来开始创建一个职业吧
配置插件时这个不要一起输入[]
   "[职业名称]"：
    permission: false | true  //是否需要购买 false否 true 是
    price: <数值> //购买需要的代币
    command-excuted-on-purchase: "manuaddp %player% sg.kits.[职业名称]" //需要的权限
    item: '<id>' //职业显示的id
    armor: //装备
      helmet: '<id>' //头盔id
      chestplate: '<id>' //胸甲id
      leggings: '<id>' //靴子id
    description: //职业介绍
    - "[文字]" //(可多行)
    items: //职业的物品
    - '<id> : <数量> ：<name/enchant/lore……>'
    potion-effects:  //职业附带药水效果（如果无效果请替换
  potion-effects: [])

    - '<药水英文id> : <时间 秒> : <等级>'

记得看空格
可用u码，配置转码科打开这个网址：
