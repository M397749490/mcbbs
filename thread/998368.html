不行，在1.12.2里，所以方块被放置后都会重置，name，nbt，lore，tag
但是有办法替换箱子1里的物品，后面接个比较器或者下面接个同种物品的漏斗通过比较器或许可以达到效果

/replaceitem block 0 0 0 slot.container.0 minecraft:mob_spawner 1 0
