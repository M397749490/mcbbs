探测玩家手中是否存在羽毛，如果存在就给予1秒指定buff


execute if entity @a[nbt={SelectedItem:{id:"minecraft:feather"}}] run effect give @p speed 1


参考帖子：1.14去掉了testfor,不能检测玩家手持物了。
