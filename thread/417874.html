        得到MC的源代码后，MCP提供了一个Start类模拟启动器，作用是调用MC真正的主类Main：
  1. public static void main(String[] args)
  2. {
  3. Main.main(concat(new String[] {"--version", "mcp", "--accessToken", "0", "--gameDir", "jars"}, args));
  4. }
复制代码
       这个代码的意义相当于在命令行下把启动参数传给了Main，那这些参数有什么意义呢，我们进入到Main的代码来看一看     
  1. OptionParser op = new OptionParser();
  2.         op.allowsUnrecognizedOptions();
  3.         op.accepts("demo");
  4.         op.accepts("fullscreen");
  5.         ArgumentAcceptingOptionSpec<String> serverOp = op.accepts("server").withRequiredArg();
  6.         ArgumentAcceptingOptionSpec<Integer> portOp = op.accepts("port").withRequiredArg().ofType(Integer.class).defaultsTo(Integer.valueOf(25565), new Integer[0]);
  7.         ArgumentAcceptingOptionSpec<File> gameDirOp = op.accepts("gameDir").withRequiredArg().ofType(File.class).defaultsTo(new File("."), new File[0]);
  8.         ArgumentAcceptingOptionSpec<File> assetsDirOp = op.accepts("assetsDir").withRequiredArg().ofType(File.class);
  9.         ArgumentAcceptingOptionSpec<File> resourcePackDirOp = op.accepts("resourcePackDir").withRequiredArg().ofType(File.class);
  10.         ArgumentAcceptingOptionSpec<String> proxyHostOp = op.accepts("proxyHost").withRequiredArg();
  11.         ArgumentAcceptingOptionSpec<Integer> proxyPortOp = op.accepts("proxyPort").withRequiredArg().defaultsTo("8080", new String[0]).ofType(Integer.class);
  12.         ArgumentAcceptingOptionSpec<String> proxyUserOp = op.accepts("proxyUser").withRequiredArg();
  13.         ArgumentAcceptingOptionSpec<String> proxyPassOp = op.accepts("proxyPass").withRequiredArg();
  14.         ArgumentAcceptingOptionSpec<String> usernameOp = op.accepts("username").withRequiredArg().defaultsTo("Player" + Minecraft.getSystemTime() % 1000L, new String[0]);
  15.         ArgumentAcceptingOptionSpec<String> uuidOp = op.accepts("uuid").withRequiredArg();
  16.         ArgumentAcceptingOptionSpec<String> accessTokenOp = op.accepts("accessToken").withRequiredArg().required();
  17.         ArgumentAcceptingOptionSpec<String> versionOp = op.accepts("version").withRequiredArg().required();
  18.         ArgumentAcceptingOptionSpec<Integer> widthOp = op.accepts("width").withRequiredArg().ofType(Integer.class).defaultsTo(Integer.valueOf(854), new Integer[0]);
  19.         ArgumentAcceptingOptionSpec<Integer> heightOp = op.accepts("height").withRequiredArg().ofType(Integer.class).defaultsTo(Integer.valueOf(480), new Integer[0]);
  20.         NonOptionArgumentSpec localNonOptionArgumentSpec = op.nonOptions();
  21.         OptionSet localOptionSet = op.parse(par0ArrayOfStr);
复制代码
       MC使用了OptionParser来解析启动参数，这个类是JOptSimple提供的。关于这个工具大家可以自行百度/谷歌。
        这么多参数为什么Start类只写了三个？我们在Start的代码中把"--version", "mcp", 删掉，然后执行，控制台输出：
        Missing required option(s) ['version']
        这说明version这个参数是必须的，在解析参数的代码中仔细看就会发现，只有version和accessToken加了required()，这就表示它们是必须的。而gameDir是游戏路径，默认是当前路径（在eclipse中是项目的根目录）。其实最小的启动项只需要两个，但是因为一般从MCP反编译过来的游戏路径是Jars文件夹，所以这个也不能省略{:10_523:}。
        回到Main类，解析好参数后，就是获取参数值，然后初始游戏设置。首先做的是设置代理
  1. Proxy proxy = Proxy.NO_PROXY;

  3.         if (proxyHost != null){
  4.             try{
  5.                 proxy = new Proxy(Type.SOCKS, new InetSocketAddress(proxyHost, ((Integer)localOptionSet.valueOf(proxyPortOp)).intValue()));
  6.             }
  7.             catch (Exception e){
  8.             }
  9.         }

  11.         final String proxyUser = (String)localOptionSet.valueOf(proxyUserOp);
  12.         final String proxyPass = (String)localOptionSet.valueOf(proxyPassOp);

  14.         if (!proxy.equals(Proxy.NO_PROXY) && isNotEmpty(proxyUser) && isNotEmpty(proxyPass))
  15.         {
  16.             Authenticator.setDefault(new Authenticator()
  17.             {
  18.                 private static final String __OBFID = "CL_00000828";
  19.                 protected PasswordAuthentication getPasswordAuthentication()
  20.                 {
  21.                     return new PasswordAuthentication(proxyUser, proxyPass.toCharArray());
  22.                 }
  23.             });
  24.         }
复制代码
       上面的代码为Java的网络连接设置好代理服务器，当然了没有配置代理的话这里就会直接跳过。
        接下来是分别获取窗口宽、高，全屏，游戏路径等等。再下面的代码就是最关键的两句
  1. Session session = new Session((String)usernameOp.value(localOptionSet), uuid, (String)accessTokenOp.value(localOptionSet));
  2.         Minecraft mc = new Minecraft(session, width, height, isFullScreen, isDemo, gameDir, assetsDir, resourcepacksDir, proxy, version);
复制代码
       分别实例化了Session对象和Minecraft对象，Session对象用于保存用户信息，而Minecraft对象就是游戏的主体对象，负责加载资源、启动和管理游戏线程。我们可以看到最后一行是
  1. mc.run();
