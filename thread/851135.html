插件的话 目前应该是没这个功能的
FileConfiguration 有getItemStack的方法
你直接遍历背包, 获取到每个格子的ItemStack 然后设置FileConfiguration 用到的时候再读取即可

这是个例子:
  1. ItemStack item = new ItemStack(Material.STONE);
  2. File f = new File(getDataFolder(), "test.yml");
  3. FileConfiguration data = YamlConfiguration.loadConfiguration(f);
  4. data.set("Item1", item);
  5. data.save(f); //这有一个 try 我没写出来
复制代码


读取物品:
  1. File f = new File(getDataFolder(), "test.yml");
  2. FileConfiguration data = YamlConfiguration.loadConfiguration(f);
  3. ItemStack item = data.getItemStack("Item1");
