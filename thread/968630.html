MobAspects

获得怪物们的被动能力



[插件介绍]

类似于一些天赋插件，这个插件可以让玩家获得生物的一些被动能力



[插件特点]

高质量的被动能力介绍及排版

[插件指令与权限]


绿色为玩家默认拥有，红色为默认OP拥有
拥有重载此插件的权限
aspects.reload

/aspects unlock <player> <aspect>
对指定玩家解锁特定的能力.
对应权限aspects.unlock
<player> = 示例: "Notch"
<aspect> = 示例: "BatAspect"

/aspects lock <player> <aspect>
与上一个指令效果相反.
对应权限aspects.lock

/aspects select <id>
改变玩家当前选择的能力.
对应权限aspects.select
<id> = 能力名称 (示例: "CatAspect")
