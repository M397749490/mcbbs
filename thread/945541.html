Coin System + API
简介：
这个插件集成了一个货币系统到你的服务器中，且API在大多数情况下都采用异步处理的方法。
当然，你也可以额外自定义一些命令与消息。
另外，不要忘了添加我插件的 depend 到你的Plugin.yml 中。
  1. name: 你的插件名字
  2. main: 路径
  3. version: 版本号
  4. description: 消息
  5. depend: [CoinSystem]
复制代码
建议不会使用 Vault 或刚入手编程的人使用。

指令与权限：

  • /addcoins <玩家名|UUID> <数量> | system.commands.coins.add
  • /removecoins <玩家名|UUID> <数量> | system.commands.coins.remove
  • /setcoins <玩家名|UUID> <数量> | system.commands.coins.set
  • /pay <玩家名> <数量> | system.commands.coins.pay
  • /coins <玩家名> | system.commands.coins.display

亮点：
  • 异步处理
  • 支持 MySQL
  • JSON 文件配置
  • 多样性
  • 2个独立的事件
- PlayerPayPlayerEvent
- PlayerCoinsChangeEvent
  • 所有命令都可随时停用或激活
  • 没有任何的命令在 PluginYML 中注册
  • 包含 Msg 类
