          它可以给予服务器上的玩家，提供自动公告信息，是服务器必备的插件它比其他自动公告插件设置的更容易一些，更丰富一些。
命令：（也可以一键后台设置，也支持彩色文字）

/ram start - 启动消息
/ram stop - 停止消息
/ram reload - 重新载入这个插件
/ram msg - 消息帮助
/ram msg show - 显示所有的消息
/ram msg add [输入消息] - 增加一条消息
/ram msg del [消息ID]- 删除一条消息
/ram msg edit [消息ID] [消息] - 编辑一条消息
/ram prefix - 消息前缀帮助
/ram prefix show - 显示所有前缀
/ram prefix set [prefix] - 设置消息的前缀
/ram suffix - 消息后缀帮助
/ram suffix show - 显示所有消息后缀
/ram suffix set [suffix] - 设置后缀
/ram interval - 帮助说明
/ram interval show - 显示每个消息的间隔
/ram interval set  - 设置每个消息的间隔
/ram starttime - 帮助说明
/ram starttime show - 显示消息开始的时间
/ram starttime set  - 设置开始的时间
/ram startuptime - 帮助说明
/ram startuptime show - 显示启动时间
/ram startuptime set  - 设置启动时间
/ram ran - 帮助说明
/ram ran show - 显示设置的随机消息
/ram ran set  - 设置随机消息
/ram info - 显示此插件的相关信息
/ram version - 显示插件的版本
/ram help - 显示所有帮助

使用方法：
1.下载插件，把插件放入 plugins中，然后重启服务器，会生成一个RichAutoMessage文件夹
2.打开message（这里可以修改，但可能会格式不对，建议在后台或者服务器里用指令修改)
3.打开 config 开始设置
normal:
  prefix: '&c[RichAutoMessage]'    前缀
  suffix: ''                 后缀
  interval: 20            每个消息的间隔（S）
  random: false         是否按照消息的设置顺序，随机发送消息
pro:
  startuptime: 20      这个是服务器开启后，过多长时间开始发送消息
  starttime: 2            多长时间启动此插件，建议不要修改
