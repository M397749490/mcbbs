标题: 我的世界spawn和warp tpa 等传送没权限
如题，我的服务器除了op，玩家组都没权限，注意传送权限能用，就是tpa别人接受后传送不过去，显示没权限，输入回城spawn然后显示正在传送，然后传送不过去显示没权限，我设置的传送时间得等3秒，TPA WARP SPAWN 输入了，等了三秒他说没权限，怎么解决啊
作者: 小烦    时间: 2017-1-24 22:52
那个玩家所在的位置/位置有一个领地，领地没有打开传送权限。

这个提醒是领地插件的
如果home/spawn/tpa的区域的领地没有开启tp（传送）权限 就无法传送过去

/res set 领地名 tp t 或 站在领地内/res set tp t 就是了
