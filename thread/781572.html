前言 Preface
相信大家都知道月亮岛事件，那我先不提了，不学他是第一步。这也算是教程吧
简介 Description
今天就给大家带来Minecraft开服心得，不定期更新~
第 ①
首先得开服=-=
查看自己炸鸡配置，2G左右的话5-10人就好了，不然把你电脑搞爆awa
第 ②
映射端口，这里需要你自己设置了，我路由器根本进不去
当然利用软件也是ok的，比如Ngrok，花生壳什么的我就不提供了
第 ③
设置好服务端，比如在MCBBS下载的也行。
如果你想用核心，不想用他们配置好的我爱折腾XD
那么下载核心请移步酷车手BB弹的帖子
第 ③的番外——只有核心的童鞋必看
唉？下载了核心我不会用怎么办？
照着那些端缺一个Bat文件，那是啥？
在这里我提供给你,这个可以自动重启

@echo OFF
set a=1
set b=1
set c=-1
:restart
set /a c+=1
title [自定义][端口号留着怕忘记你自己改][你的核心的名字其实没必要]最大内存[%a%G]最小内存[%b%G]重启次数[%c%次]
echo 正在启动服务器...
java -Xmx%a%G -Xms%b%G -jar 改成你核心的名字.jar
echo 重启倒计时 5 秒
ping -n 2 -w 500 0.0.0.1>nul
echo 重启倒计时 4 秒
ping -n 2 -w 500 0.0.0.1>nul
echo 重启倒计时 3 秒
ping -n 2 -w 500 0.0.0.1>nul
echo 重启倒计时 2 秒
ping -n 2 -w 500 0.0.0.1>nul
echo 重启倒计时 1 秒
ping -n 2 -w 500 0.0.0.1>nul
goto restart

第 ④
运行一次服务器(就是双击Bat文件)等到cmd彻底不动关闭它
这时会出现一大堆文件找到那个server开头的使用Notepad++打开
查看自己的端口(就是server-port=等于号右边的，推荐不使用默认的25566/25565)
第 ⑤
用软件/路由器映射，TCP服务
比如Ngrok啊，server-port=端口号
比如端口号是3695
那么你就映射3695
然后你再次启动开服脚本。
(打开浏览器，百度IP查看自己IP然后添加端口比如我是127.0.0.1那就在后面加上端口.栗子:127.0.0.1:3695)←路由器用户
(如果你是软件你就....复制你映射的IP)←软件
打开游戏，添加服务器试试看有没有绿色的东东awa
