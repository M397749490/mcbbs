作者: fyfly    时间: 2015-8-7 15:33
食物应该是所有物品里面最简单的一个了吧
如果你只需要一个很简单的食物，只能够回复饱食度，那么请看代码

  1. public class ItemBanana extends ItemFood {

  3.     public ItemBanana() {
  4.         super(10, false); // 第一个参数是添加的饱食度，第二个是是否能作为狼的食物
  5.     }
  6. }
复制代码

如果你想让这个食物无视满饱食度继续吃可以添加一句setAlwaysEdible();药水效果可以setPotionEffect(id, duration, amplifier, probability);

如果你想做出来更多功能的食物可以试着Override这个方法
  • onFoodEaten()
  • onItemUseFinish()
  • onItemRightClick()
  • getMaxItemUseDuration()
  • onItemUse()



更多代码请到GitHub上去寻找，推荐去看Botania的代码
