LilyPad跨服群组搭建教程

前言
LilyPad是与BungeeCord相似的跨服群组端,旨在提高服务器硬件利用率,通过LilyPad可以搭建大型的跨服群组。
其实LilyPad早在2014年就已经开始发布了,但在论坛中却没有人发布相关的教程帖子。
因个人水平有限,本帖可能出现翻译方面的错误,欢迎大家指正!


安装指南
LilyPad端分为三部分，分别是 代理端、通讯端、服务器端
代理端就相当于BungeeCord,是所有玩家进入服务器的入口端,服务器端则是我们的每个子服,而通讯端则是代理端与服务器端的桥梁,通过通讯端使代理端和服务器端能够互联互通。
要安装LilyPad，我们就需要下载以上三个端!

通讯端:http://ci.lilypadmc.org/job/Go-Server-Connect/
代理端:http://ci.lilypadmc.org/job/Go-Server-Proxy/
服务器端:http://ci.lilypadmc.org/job/Bukkit-Connect/

首先我们下载对应于服务器系统的通讯端与代理端，服务器操作系统对应的软件端名字如下
windows 64位 --> amd64.exe
windows 32位 --> 386.exe
Linux 64位 --> linux-amd64
Linux 32位 --> linux-386

下载后我们需要运行一下代理端与通讯端,使他们生成配置文件。
connect.yml(通讯端配置文件)内容如下
  1. bind: :5091#通讯端的端口号,用于内部通讯,一遍不需要更改
  2. logins:#以下是各代理端、服务器端的账号密码配置
  3. - username: proxy1#代理端1账号
  4. password: password#代理端1密码
  5. - username: proxy2#代理端2账号
  6. password: password#代理端2密码
  7. - username: server1#服务器端1账号
  8. password: password#服务器端1密码
复制代码

proxy.yml(代理端配置文件)内容如下


  1. connect:
  2.   address: 127.0.0.1:5091#通讯端的ip及端口
  3.   credentials:
  4.     username: proxy1#通讯端配置里的账号
  5.     password: password#通讯端配置里的密码
  6. proxy:
  7.   bind: :25565#本代理端对外监视的端口
  8.   routes:
  9.   - domain: example.com#当连接域名为example.com时 连接以下服务器端
  10.     servers:
  11.     - hub1
  12.     - hub2
  13. icon: icon.png
  14. locale:
  15.     full: The server seems to be currently full. Try again later!
  16.     offline: The requested server is currently offline. Try again later!
  17.     loggedIn: You seem to be logged in already. Try again later!
  18.     lostConn: Lost connection... Please try to reconnect
  19.     shutdown: The server is being restarted. Please try to reconnect
  20.   motd: A LilyPad Server
  21.   maxPlayers: 1#最大玩家数量
  22.   syncMaxPlayers: false#同步最大玩家数量
  23.   authenticate: true#是否开启正版验证
