Yasui 是一个轻量级的性能优化和区块清理工具。

在你的服务器TPS十分稳定的时候，Yasui只有一种简单的逻辑，就是在一定需要的时候取消部分区块生物的读取，用来容纳更多的玩家，更多的生存地图等等。
功能
  • 暂停生物-在须要的时候暂停生物活动
  • 红石控制-必要时停止红石
  • 实体删除-删除加载区块中的实体并停止新的物品生成
  • 随机区块刷新时间速度-调整区块刷新速度
  • 自定义命令-按需求执行任何命令
  • Performance Counter / Profiler-一个简单的计数器和探查器，可帮助您找到使服务器卡顿的区块
  • 区域覆盖-自定义区域以绕过特定的功能
使用图片[来源于官方]










食用方法
插件依赖的文件都是服务器自带的-只会使用一点点服务器服务器内存，并不会浪费服务器性能
  • 下载 Yasui  
  • 下载 NyaaCore 和 Langutils   ←[两个服务器端均已自带]
  • 将NyaaCore与Langutils放入插件文件夹
  • 重启服务器
Config
  • 编辑插件配置 yasui/operations/
  • 打开或者关闭规则请位于 yasui/rules 配置
  • 重载插件/yasui reload

  • 将文件设置为只读模式[不然会被还原]
  • 重启

命令
  • /yasui chunkentities - 按照区块内存占用清理占用内存最大的区块
  • /yasui chunkevents - 检测红石类占用内存最大的区块
  • /yasui counter entity - 列出占用内存的区块
  • /yasui counter tileentity - 列出占用服务器内存的活塞与漏斗
  • /yasui operation [engage|release] [operation name] [world name] - 在特定世界现在/稍后执行清理内存
