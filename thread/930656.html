预发布版是Minecraft Java版的测试机制，如果该版本作为正式版发布，那么预发布版的游戏文件将与启动器推送的正式版完全相同。

然而，预发布版主要用于服主和Mod制作者的预先体验，如果发现重大漏洞，该预发布版会被新的预发布版代替。因此建议普通玩家持观望态度。

Minecraft 1.15 仍未发布，1.15-pre5 为其第 5 个预发布版，第 19 个预览版。

转载本贴时须要注明原作者以及本帖地址。

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。Java版的启动器下载地址在上文已经提供。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。

MC-117449 - options.txt is read and written with default OS encoding
MC-117449 - 名称包含非ASCII字符的资源包有时会加载错误

我来解释bug了（
这个是因为代码写得不严谨的缘故，其实这个bug的原文是有问题的
在1.12中，MC读取options.txt使用的是系统的默认编码：
  1. #net.minecraft.client.settings.GameSettings.loadOptions()V
  2. List<String> list = IOUtils.readLines(new FileInputStream(this.optionsFile));
复制代码

方法如下：
  1. #org.apache.commons.io.IOUtils
  2. public static List<String> readLines(final InputStream input) throws IOException {
  3.         return readLines(input, Charset.defaultCharset());
  4.     }
复制代码

也就说是使用的是默认的编码，如果如bug标题所说使用默认编码读写的话是没有问题的，但是...
  1. #net.minecraft.client.settings.GameSettings.saveOptions()V
  2. printwriter = new PrintWriter(new OutputStreamWriter(new FileOutputStream(this.optionsFile), StandardCharsets.UTF_8));
复制代码

如你所见，指定使用UTF8编码保存，这就233了
所以说在默认编码格式为ANSI的windows系统不能在options.txt里面使用非ASCII字符（ASCII字符编码格式一样，所以不受影响）
