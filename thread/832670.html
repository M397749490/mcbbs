创建菜单
所有菜单节点均可省略。
所有菜单节点均忽略大小写判断。（NAME 同等于 name）

菜单目录
在路径 /plugins/TabooMenu/menu/ 内创建任意以 yml 结尾编码为 UTF-8 的文件。

菜单节点
  1. # 总节点
  2. menu-settings:
  3.   # 菜单标题
  4.   name: '测试菜单'
  5.   # 菜单行数
  6.   rows: 1
  7.   # 菜单打开所需要的命令（不同指令之间使用 ";" 区分）
  8.   command: 'menu;help;cd'
  9.   # 菜单自动刷新时间（单位：秒）
  10.   auto-refresh: 1
  11.   # 菜单打开执行动作（可以使用大部分物品动作）
  12.   open-action: 'sound: BLOCK_CHEST_OPEN-1-1'
  13.   # 菜单关闭执行动作（可以使用大部分物品动作）
  14.   close-action: 'sound: BLOCK_CHEST_CLOSE-1-1'
  15.   # 菜单打开是否跳过权限判断
  16.   permission-bypass: true
  17.   # 菜单关闭时自动打开的菜单
  18.   previous: 'previous.yml'

菜单模板
该功能需要 TabooMenu v1.7+ 以上

命令相关
命令作用示范
/tmenu template create创建模板/tmenu template create 测试模板
/tmenu template name更改模板名称/tmenu template name 测试模板 模板名称
/tmenu template rows更改模板行数/tmenu template rows 测试模板 3
/tmenu template open打开模板/tmenu open 测试模板

创建模板
通过使用命令 /tmenu template create 创建一份新的模板。
你可以在目录 plugins/TabooMenu/template/ 中找到你之前创建的模板配置。

编辑模板
通过使用命令 /tmenu template open 打开你之前创建的模板。
将物品直接放入菜单中后关闭界面即可保存。


使用模板
将生成好的模板文件复制到 plugins/TabooMenu/menu 文件内即可正常使用。
物品展示节点以外的动作节点则需要您手动配置。

注意事项
  • 请勿直接编辑 plugins/TabooMenu/template 模板文件夹中的源文件。
  • 模板行数减少时请提前收回即将越界的物品，否则将会被删除。
  • 该功能仅保存能够使用配置实现的数据。（不保存：烟花配方、物品属性等）

创建物品

所有物品节点均忽略大小写判断。（NAME 同等于 name）


TabooMenu拥有一个独特的联想判断功能(又称抽象化判断)，这个功能会使节点判断更加的简单。用过Skript的用户应该都知道，通常一串代码可以用多种方式来表达，比如 "[the] health of %living entities%" 和 "%living entities%' health" 是一样的意思，但是不同的表达方式。而TabooMenu也实现了这个功能， 比如物品ID同时可以用"ID"或者"Material"来表达。在每个子版块中都会在最前面添加一段类似于这样的节点用法:
POSITION_X ("(Position-|Location-)x")
POSITION_Y ("(Position-|Location-)y")

这样的节点用法，就和前面所说的抽象化判断相关。
理解格式为 节点名称("(可有可无的)用法|用法二")
在括号中的第二个括号代表了第二个括号中的内容是可有可无的，在先前的例子中，你可以使用:
  • Position-x
  • Location-x
  • X（直接使用X作为节点）
在其中还有一个竖线“|”，代表了可以选择两个之间的一个，比如：
在"id|material"中，你可以选择id作为节点或者material作为节点

注: 如果实在理解不了，你可以直接使用例子中的用法



序号及坐标
POSITION_X ("(Position-|Location-)x")
POSITION_Y ("(Position-|Location-)y")

  2. 0:
  3.   id: diamond
  4. # 坐标方式
  5. item:
  6.   id: diamond
  7.   position-x: 0
  8.   position-y: 0

命令与权限
TabooMenu 允许使用 ChestCommands 的 cc 指令别名。

命令
命令作用
/taboomenu open [菜单] <玩家>打开菜单
/taboomenu list列出菜单
/taboomenu reload重载插件
如果文件名为 menu - bedwars.yml 那么则需要使用 /tmenu open menu__-__bedwars.yml 来打开。
允许使用 TAB 来自动补全 open 指令后的菜单名称。
权限
权限作用
taboomenu.command.help查看命令帮助
taboomenu.command.open使用打开菜单命令
taboomenu.command.open.other使用打开菜单命令（向其他玩家）
taboomenu.command.list使用列出菜单命令
taboomenu.commsnd.reload使用重载插件命令
taboomenu.open.文件名.yml打开菜单
