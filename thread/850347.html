什么是MythicLib?
Mythiclib是一个跨平台的库插件，它为Mythicmobs作者的一些插件提供了功能扩展，MythicLib是这些功能的前置。
What is MythicLibs? MythicLib is a cross-platform library plugin that provides numerous useful methods for my plugins. It is a required dependency for them!
If you are a developer, you are welcome to use it if you'd like.


使用前请注意
  • 此插件支持的版本是1.8-1.10,以上版本的服务器无需安装
  • 此插件是Mythicmobs作者为自己的插件编写准备的,不使用以下插件则不要安装
  • 目前的Mythicmobs 4.x版本已不需要这个插件(准确来说是自从 Mm插件2.5.11以后都不需要)
  • 这个插件居然支持海绵端Sponge(it will all eventually be cross-compatible with Sponge)

MythicLib所支持的插件
  • Graveyards(墓地插件，提供死亡掉落箱、灵魂绑定等功能，本人已搬运)
  • Champions(疑似是MMO玩法的职业技能竞技插件,在Bukkit上显示尚且处于试验阶段,站内无搬运)
  • Mythicmobs(支持1.10-1.8版本的,本人已搬运)

作用
  • 为上方的插件提供前置
  • 此插件作为一个开发者的API,作者的介绍很少,但是提到了这个插件提供了轻量的命令解析器(ightweight command parser)、物品栏菜单(inventory menus)、函数解析器(mathematical parser)和一些随机性的功能(random stuff) 由于搬运者对开发插件了解的少之甚少,这里尽我最大努力介绍下(虽然我感觉完全没有必要,因为作者原帖的介绍也是寥寥无几)
  • Graveyards和Champions的作者都不是MM的作者,他们想必是用了MythicLib作为前置的插件开发者,其中Graveyards是个小型插件，Champions疑似是个较大型的插件,待考究Champions(我觉得以后可能会是个知名插件)
