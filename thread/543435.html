标题: 领地权限问题
怎么让不同权限组
圈地数量，大小，价格不同
还有求领地插件的权限组权限(不是领地内建造权限什么的)
作者: 格林    时间: 2016-1-20 20:20
1例如：我想让Default组最多圈10块地，Builder组最多圈20块地。
2打开配置文件： plugins\residence\config.yml
3然后打修改：

Groups:
    Default:  #默认配置
       # Information about the Residence zone that the player can define.
       #Uncomment the lines below to mirror this config to other groups.
       #Mirror:
         #- 'group1'
         #- 'group2'
       Residence:
           # Determins if this group can create residences or not.  This option can be overriden with the permissions node 'residence.create'
           CanCreate: true
           # The maximum number of Residences a player can have.
          MaxResidences: 10
           .........
   Builder: #自己添加新组
       # Information about the Residence zone that the player can define.
       #Uncomment the lines below to mirror this config to other groups.
       #Mirror:
         #- 'group1'
         #- 'group2'
       Residence:
           # Determins if this group can create residences or not.  This option can be overriden with the permissions node 'residence.create'
           CanCreate: true
           # The maximum number of Residences a player can have.
           MaxResidences: 20
            .........
........
