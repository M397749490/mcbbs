CombatLogX
更炫酷的战斗信息
授权证明

功能
·战斗中的玩家退出游戏将会自动死亡
·自定义信息
·计分板实时显示
·动态信息显示
·Boss血条信息显示
·PvP时强制进入生存模式,并关闭飞行
·禁止药水
·阻止玩家PVP时使用指令
·自定义关闭/开启的世界
安装
1.[下载安装]下载插件本体后放入服务器plugins文件夹后重启即可
命令
/clreload - 重载配置文件
权限
combatlog.reload - 重载配置的权限
配置
  1. timer: 30
  2. ender pearl cooldown: -1
  3. update checker: true #是否开启自动更新
  4. action bar: true #开启动态显示
  5. boss bar: true #开启Boss血条显示
  6. self combat: true #与玩家PVP时显示
  7. mobs combat: true #与生物PVP时显示
  8. remove potions: true #移除药水效果
  9. prevent flight: true #关闭PVP飞行
  10. change gamemode: true #强制更改为生存模式
  11. punish loggers: true #退出游戏的惩罚
  12. scoreboard: true #计分板
  13. disabled worlds: #不启用该插件的世界
  14. - Creative
  15. - WoRlD
  16. blocked commands: #PVP时禁止的指令
  17. - home
  18. - tpa
  19. - spawn
  20. banned potions: #禁止使用的药水
  21. - INVISIBILITY
  22. - UNLUCK
  23. punish commands: #玩家PVP时强制退出的惩罚
  24. - ban {player} You left during combat
  25. prevent inventory: true #清空背包
  26. kill player: false #PVP时退出后杀死玩家
