简介
插件主要功能是设置世界为受控世界。设置后，如果玩家拥有权限 nworldpermissions.forfreeto.<世界名> ，则会被传送，并收到消息：

如果没有权限，则传送会被拒绝：

image.png (26.49 KB, 下载次数: 0)

下载附件

2020-7-29 14:07 上传
所有消息都支持自定义。
此插件也支持将指定世界的玩家传送出世界（包括离线玩家）。

使用此插件，您可以解决以下问题：
  • 世界被重置后，我希望管理员先进入建造一些东西，此时如何防止玩家进入？
  • 世界将被重置，如果将玩家传送出去？
  • 如何创建一个 VIP 世界？
  • 以及更多……

语言支持
插件通过 crowdin 提供多语言支持。
简体中文版属官方翻译，可至 https://crwd.in/nworldpermissions 下载，随后使用之替换 messages.yml 。

最新测试版 3.1.2_Pre3 属于大更新，有新功能出现，指令和权限与上个版本完全不同。代码经过了重构。可以进行如下的测试，来确定可否使用：
  • 获取 OP ；
  • 通过编辑文本，修改 messages.yml ；
  • 使用指令 /wp reload messages ，观察其是否可用；
  • 使用指令 /nworldpermissions ，观察其是否正常提示；
  • 使用指令 /wp ，观察其是否正常提示；（如果与其他插件有重复则换用 /nwp 、 /nwdp 或 /worldpermissions，下同）
  • 使用指令 /wp config ，观察其是否正常提示；（如果与其他插件有重复则换用 /nwp 、 /nwdp 或 /worldpermissions，下同）
  • 通过编辑文本，在 config.yml 中添加一个受限世界，并将 offline-players-tracker.enable 设置为 true ， offline-players-tracker.record-only 设置为 false ；
  • 使用指令 /wp reload config ；
  • 如果您目前就处于受限世界，请传送走；
  • 取消自己的 OP 和 nworldpermissions.forfreeto.<受限世界> 权限；
  • 尝试传送至受限世界，检查其是否阻止了传送并产生提示；
  • 给予自己 nworldpermissions.forfreeto.<受限世界> 权限，再次尝试传送，检查其是否允许了传送并产生了提示。
  • 获取 OP ；
  • 多次使用 /wp config add 和 /wp config remove 对受限世界进行设置，通过 config.yml 的变化，检查其是否可用；
  • 使用 /wp marks add 和 /wp marks remove ，通过 marks.yml 的变化，检查其是否可用；
  • 添加若干 mark 点；
  • 通过编辑 marks.yml ，删除多余的 mark ，最终保留一个 mark ，并改变其名称；
  • 使用 /wp reload marks ，检查其是否可用；
  • 使用 /wp tp online <你所在的世界> <保留的 mark 的名称> ，检查自己是否被传送；
  • 退出游戏；
  • 检查是否有 playersData 目录，以及是否有 <你的UUID>.yml 文件，及其中是否记录了一个 position ；
  • 修改 position 记录的位置（稍微改变地多一点，建议直接把 world 换掉，注意不要与先前 mark 的位置相同），并保存；
  • 进入游戏，观察位置是否改变（注意，请关闭其他插件的相似功能，比如 authme 的上线时传送到固定位置）；
  • 进行一些移动，如果可能，直接换个世界；
  • 使用 /wp tp offline <你所在世界的名字> <先前 mark 的名称>，检查 playersData/<你的UUID>.yml 中的 position 是否发生了变化，且改变到了 mark 的位置；
  • 取消 OP ；
  • 取消 OP ，尝试使用 /wp config ， /wp marks ， /wp tp 和 /wp reload 检测其是否均没有反应；
  • 根据 /wp 的提示，获取相关权限，再次尝试使用上述指令，检测其是否有反应；
  • 如果以上结果有“否”，那么部分功能可能不可用，若有错误提示，可以把内容发给我，我会尝试修改插件进行兼容；而若都为“是”，那么恭喜你，这个插件完全支持此版本，也请一定要告诉我鸭！

目前已知的问题：
  • /wp reload 权限异常（已修复）
  • messages使用了\r\n换行，这会在linux上产生问题（已修复）
  • offline-players-tracker无法使用（不能重现）

能不能判断玩家是否身处于世界的时候直接把他传送回主城

首先为你的主城设置一个 mark。如果使用 MarksAPI，用任意支持的插件添加即可；如果不用 MarksAPI，站在主城，使用 /wp marks add <取个名字> 来添加。

接着使用 /tp online <世界名> <mark名> <次数> 即可将指定世界的在线玩家传送到该 mark，次数可选，默认为 1。
接着使用 /tp offline <世界名> <mark名> 即可将指定世界的离线玩家传送到该 mark，需要提前开启 offline players tracker。

等等……你的意思是上线的时候一定传送出来吗？目前没有这个功能，需要的话可以添加。
