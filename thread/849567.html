作者: liach    时间: 2019-3-10 07:31
蝙蝠别误导人了。这位仁兄用的是自定义 json 处理库，和 Minecraft 源码没有关系。

你需要将你用的库配置在你的mod里面发布。

推荐使用 gradle shadow 插件并以 shadowJar 作为成品 mod 包发布。
shadowJar 里面 include 的 dependency 只要你的 json 处理库就行了。
  1. shadowJar {
  2.     // 只把指定的依赖打入到fat jar中
  3.     dependencies {
  4.         // 这个依赖不一定是compile阶段的依赖
  5.         include(dependency('net.sf.json-lib:classifer:版本')) // classifier 和版本看你自己用什么
  6.     }
  7.     relocate 'net.sf.json', 'com.mymod.shadow.net.sf.json' //随便转移到一个不同的不会冲突的包下，最好是你的mod用的包下的包
  8. }
复制代码

这里有教程：https://www.zybuluo.com/xtccc/note/317832
