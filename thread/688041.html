这款插件可以保护你的物品展示框，挂着的画，盔甲架甚至还能保护你的栓绳！
使用起来非常简单，几乎不用你配置什么。


那就是 Frameprotect 2.8.7！


        >> 相比2.8有什么新的特性？

                        - 添加 1.12+ 支持
                        - 添加 end crystal 支持
                        - 添加 新语言 支持
                           (韩文)
                        - 由于异步保存技术，性能有明显的提升！
                        - 改善重生机制
                              - 暂时生成块，以确保物品展示框，挂着的画，盔甲架和栓绳能在正常的地方重生
                              - 最小化控制台输出信息
                                 (在控制台不会再有 (Unable to respawn disappeared *)这类的垃圾提示消息了)
                        - 添加选项以开关错误的日志记录 (保存日志文件)
                        - 添加选项以开关重新生成的消失对象相关消息的日志记录 (默认启用)
                        - 以及一些其他的修复


        >> 相比 以往版本 有什么新的特性？

        >> 相比2.7有什么新的特性？

                        - 增加 1.12 支持
                        - 新增 新语言 支持
                           (日语 , 简体中文(就是LZ汉化的))
                        - 使用了 bStats (bstats.org) 来作为插件的统计
                        - 使用了 spiget (spiget.org) 来更新插件
                           (在控制台不会再有未知主机异常(UnknownHostException)这类的垃圾提示消息了)
                        - 以及一些其他的修复
  

        >> 相比2.6有什么新的特性？

                        - 添加选项 “protectfromprojectile” 来开关
                          “当射中被保护的展示框时，展示框内的物品会掉落” 的选项
                        - 添加 1.7.10 支持
                        - 添加 1.8+ 支持
                        - 添加 栓绳 保护
                        - 添加 盔甲架 自动保护
                        - 添加 “/fp import” 命令，可以手动导入2.5和2.6版本的数据
                        - 添加 “/fp we takeown” 和 “/fp we remove” 命令
                        - 添加 “/fp transfer” 命令 给 非OP 的玩家，将他们保护的物品转移给其他玩家
                          （权限为 "frameProtect.transfer" ）
                        - 新增 "/fp near" 命令，能让你找到附近已保护的物品
                        - 允许 命令 定制（更改/fp 为任何你想要的指令）
                        - 允许 前缀 定制
                        - 使用 UUID 来保存世界的被保护物
                        - 以及一些其他的修复

             插件特色：
  
                        + 可以保护物品展示框，画，盔甲架和栓绳
                        + 每个玩家都有独立的保护
                        + 保护重新刷出来的物品
                        + 保护在被破坏后方方块的物品(例如：挂在空中的画)
                        + 保护被怪物袭击的物品（例如：苦力怕，小白）
                        + 保护被活塞推动的物品
                        + 支持UUID
                        + 支持MySQL
                        + 支持权限插件
                        + 可定制的消息提示
                        + 可定制的命令
                        + 可定制的前缀命令
                        + 许多配置选项



             关于权限：

指令
权限
功能
[无]
frameProtect.place.*[建议给玩家] 放置/摧毁一个保护(仅限自己的)
/fp transfer <ID>frameProtect.transfer[建议给玩家] 更改被保护物品的所有者(仅限自己的)
[无]
frameProtect.autoprotect.*[建议给玩家] 自动添加保护
Shift+左键frameProtect.protect.*[建议给玩家] 保护/取消保护(仅限自己的)
Shift+右键frameProtect.info.*[可以给玩家] 查看保护物的主人
/fp owner <ID>frameProtect.admin{OP用} 设置保护物主人
/fp near <半径>frameProtect.admin{OP用} 寻找附近的保护物
/fp importframeProtect.admin{OP用} 查看数据
/fp weframeProtect.admin{OP用} 在使用WE的时候破坏保护物
/fp saveframeProtect.admin{OP用} 保存
/fp reloadframeProtect.admin{OP用} 重新载入

             配置文件：

                             适用于 v2.5 版本：

  1. language: EN
  2. #语言：EN
  3. disable_consoleMessages: false
  4. #是否关闭后台信息提示：true为是，false为否
  5. disable_create_and_destroy_messages: false
  6. #是否关闭当你放置/破坏你的展示框&画时的消息提示：true为是，false为否
  7. disable_not_yours_messages: false
  8. #是否关闭当你破坏不是你的展示框&画时的消息提示：true为是，false为否
  9. disable_natural_breaking: false
  10. #禁止自然天气等破坏展示框&画：true为禁止，false为不禁止
  11. disable_breaking_by_mobs: true
  12. #禁止怪物破坏展示框&画：true为禁止，false为不禁止
  13. protect_blocks: true
  14. #保护展示框&画后方的方块（2.5版本下使用活塞依旧可以推动）：true为保护，false为不保护
  15. stop_block_placing_over_frames: true
  16. #禁止在展示框&画附近放置方块：true为禁止，false为不禁止
  17. use_MySql: false
  18. #是否使用MySQL数据库：true为使用，false为不使用
  19. mysql_host: localhost
  20. mysql_port: '3306'
  21. mysql_database: database
  22. mysql_username: username
  23. mysql_password: password
  24. #以上均为MySQL数据库设置项目
  25. do_not_change_this: false
  26. #别！更！改！这个！
  27. resetDataBase: false
  28. #数据库清零：true为是，false为否
复制代码
