JONO的启动文件是：
  1. @ECHO OFF
  2. color b
  3. title 【MC】1.2.5 服务器整合包  by_Jono
  4. SET BINDIR=%~dp0
  5. CD /D "%BINDIR%"
  6. "%ProgramFiles%\Java\jre7\bin\java.exe" -Xincgc -Xmx1G -jar craftbukkit-1.2.5-R1.2-MCPC-SNAPSHOT-76.jar
  7. PAUSE
复制代码
%ProgramFiles%\Java\jre7\bin\java.exe

所以启动条件是： 1.      有安装java
                           2.      装的是java 7
                           3.      java 7安装在默认的系统盘Program Files文件夹下

若不满足这些条件，请自行用记事本打开bat文件更改java路径为实际java路径即可
