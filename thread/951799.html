完全不用找，你可以自己写一个。
举个例子：trident.json
  1. {
  2.   "type": "minecraft:crafting_shaped",
  3.   "pattern": [
  4.     "XXX",
  5.     " I ",
  6.     " I "
  7.   ],
  8.   "key": {
  9.     "X": {
  10.       "item": "minecraft:iron_sword"
  11.     },
  12.     "I": {
  13.       "item": "minecraft:diamond"
  14.     }
  15.   },
  16.   "result": {
  17.     "item": "minecraft:trident",
  18.     "count": 1
  19.   }
  20. }
复制代码

对于伸手党玩家，你可以把这个文件复制粘贴然后保存到你的存档文件夹/datapacks/pack/data/minecraft/recipes里面，再在datapacks/pack文件夹里保存一个文件：


pack.mcmeta
  1. {
  2.     "pack":{
  3.     "pack_format":5,
  4.     "description":"伸手党专用\n反正你也不看教程"
  5.     }
  6. }
复制代码

就可以在工作台使用三把铁剑和两个钻石合成一把三叉戟了。
这两个文件啥意思？能不能自定义别的？有耐心的玩家可以往下看：


后面那个pack.mcmeta不用管，用来识别数据包的。我们的重心放在前面那个json文件。让我们来一行一行分析：
  1. "type": "minecraft:crafting_shaped",
复制代码
这一句是用来说明合成类型的，minecraft:crafting_shaped表示有序合成，即物品要按照规定的位置摆放。
  1. "pattern": [
  2.     "XXX",
  3.     " I ",
  4.     " I "
  5.   ],
复制代码

这一句是用来说明合成配方的形状的，你可以在这个3*3字符的地方用字符摆放合成配方的位置。同一个材料使用同一个字符，空位用空格代替。
  1. "key": {
  2.     "X": {
  3.       "item": "minecraft:iron_sword"
  4.     },
  5.     "I": {
  6.       "item": "minecraft:diamond"
  7.     }
  8.   },
复制代码

这一大屯话是用来定义合成材料的。我们在上面说明材料形状的地方用到了'X'和'I'两个字符，那么这一段可以定义'X'和'I'分别对应什么材料。像这里，X表示minecraft:iron_sword（铁剑），I表示minecraft:diamond（钻石）。你也可以修改成别的，只要修改对应的物品名称就可以了。比如X对应的物品修改为minecraft:bedrock，那么就需要铁剑的位置就会变成基岩。
  1. "result": {
  2.     "item": "minecraft:trident",
  3.     "count": 1
  4.   }
  5. }
复制代码

这里就是配方会输出的成品了。还是一样，item表示输出的物品，minecraft:trident也就是三叉戟。count表示输出成品的数量，当然三叉戟不能堆叠超过1个，设为1就好。

因此，如果你看懂了上面的内容，你就可以像套公式一样写一些十分实用的配方。比如：

  1. {
  2.   "type": "minecraft:crafting_shaped",
  3.   "pattern": [
  4.     "X  ",
  5.     " X ",
  6.     "   "
  7.   ],
  8.   "key": {
  9.     "X": {
  10.       "item": "minecraft:dirt"
  11.     }
  12.   "result": {
  13.     "item": "minecraft:diamond_block",
  14.     "count": 64
  15.   }
  16. }
复制代码




嗯 的确十分实用呢
