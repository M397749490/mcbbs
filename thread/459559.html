安装有任意一个可以生成虚空世界的多世界插件
并且知道如何使用该插件生成虚空地图

单机生成虚空世界的教程论坛有不少了，嗯，今天有网友询问服务器生成虚空主世界的方法，实际上我不太清楚比较正规的方法如何操作，但是有一种自己想到的一种方法，下面简单说一下。

① 生成一个普通的虚空世界

使用多世界插件（MW或者MV等），生成一个普通的虚空世界，load之后进入，up指令一个基点（无所谓，主要是检查是不是生成正确）。

② 修改主世界设定

关闭服务器，修改server.properties配置文件中这一项：
  1. level-name=上一步中生成的世界的名字

③ 修改与世界名有关的插件的个别设定

以GroupManager为例，默认主世界是world，现在要更名为你第一步中生成的世界的名字，打开groupmanager的config.yml：
  1.   mirrors:
  2.         # Worlds listed here have their settings mirrored in their children.
  3.         # The first element 'world' is the main worlds name, and is the parent world.
  4.         # subsequent elements 'world_nether' and 'world_the_end' are worlds which will use
  5.         # the same user/groups files as the parent.
  6.         # the element 'all_unnamed_worlds' specifies all worlds that aren't listed, and automatically mirrors them to it's parent.
  7.         # Each child world can be configured to mirror the 'groups', 'users' or both files from its parent.
  8.         第一步中生成的世界的名字:
  9.           第一步中生成的世界的名字_nether:      #注意，主世界名的改变会引起下界和末地名的改变
  10.           - users
  11.           - groups
  12.           第一步中生成的世界的名字_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds:
  16.           - users
  17.           - groups

保存。

groupmanager/worlds/中的主世界的名字也要修改。

其他插件类似（比如多世界背包/PerWorldPlugin/Mypet世界分组等）。
