一些杂话-------------------------------------------------------

什么？你只想和朋友局域网联机？看看这个教程... 传送门
什么？你不知道哪里有服务器核心？去看看 @酷车手BB弹 的帖子吧！传送门
或许我找到了更好的，更全的！但是下载地址是限速云的，你们自己找找办法吧pwp 传送门
要做的准备：
1.把服务器核心命名为“core.jar”（什么？没有扩展名？那就是“core”）
2.开服器放在和核心同一目录
开服吧！

什么？你是小白？不知道哪里有服务器核心？自己到“服务器整合包”板块上找呀，下载后可以选择把主目录的jar文件（比如是原版：minecraft_server.jar）改名成 core.jar
没有扩展名就是“core”
你只想和好基友玩原版？在http://mcversions.net下载一个原版服务器核心！（找到对应版本，然后找到旁边的"Download"点击，再点击"Download Server JAR"就可以下载了）

我回来惹！但是看到1.15.X更新了，我也不说什么，理论上是可以正常开服滴！
（什么？原版？那抱歉，用我的这个开服器，会显示出GUI交互界面
  什么？不想看到GUI？请单独写一个bat
  内容为
  1. @echo off
  2. echo 正在开服...
  3. java -server -Xincgc -Xmx1024M -Xms1024M -Xss512K -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseCMSCompactAtFullCollection -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=4 -XX:+UseConcMarkSweepGC -XX:CMSFullGCsBeforeCompaction=2 -XX:CMSInitiatingOccupancyFraction=70 -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar core.jar nogui
  4. echo 服务器已关闭...
  5. pause
复制代码
  “-Xms”和“-Xmx”后面的数字是可以改滴！“M”不要改！除非最低内存大于1G（等于1G可以写成1024M），则把上面代码第三行改成（例如最小1G，最大2G）：
  1. java -server -Xincgc -Xmx2G -Xms1G -Xss512K -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseCMSCompactAtFullCollection -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=4 -XX:+UseConcMarkSweepGC -XX:CMSFullGCsBeforeCompaction=2 -XX:CMSInitiatingOccupancyFraction=70 -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar core.jar nogui
复制代码
模组服的话最好把 -Xmx 和 -Xms 都改成一样，不然对服务器不好！！！！
解释：
-Xmx 是最大内存
-Xms 是最小内存
）
