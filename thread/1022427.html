权限&命令&使用方法

           /ewg bugreport. 反馈BUG
           /ewg tp <生物区块名字> (<半径>). 快速传送至某个地形
           /ewg edit (<世界>). 修改某个世界的地形配置
           /ewg install <id>. 下载其他地形配置
           /ewg create <X左边> <Y坐标> <Z坐标> <名字>. 创建一个'结构'(用于生成自然建筑)（需要WE前置支持）
           /ewg paste <结构名字> 黏贴一个'结构'（类似WE中的paste黏贴）

           使用方法:  装进plugins文件夹然后生成世界即可，如果是已经生成了的世界，那么会在未加载区块的边界出现区块断层

Q&A
官方wiki

1.EWG生成的树的树叶并不会自然消失，你需要使用砍树插件
点击跳转EWG附属TreeFaller砍树插件

2. 默认配置里的橡树苗并不会长成橡木（部分版本）
请看上文中的配置部分

3.出现区块断层
请注意不要在已经生成的世界使用EWG或者修改EWG的生成配置！

4.EWG无法正常使用
请注意的你的服务器版本是否和EWG版本匹配
1.14.4-1.15.2  ——  8.1.13（仅供参考）
1.13.2  ——  8.0.0（仅供参考）

5.为什么我无法创建结构？
首先确认你是否已经安装了WorldEdit插件
其次一些更新较早的版本，为了更快适应新版本阉割了该功能
请换用最新的版本

6.为什么我粘帖了结构却看不到？
只是一些渲染BUG，只要传送到其他地方再传送回来就好
重进游戏也是可以的

7.地形的配置文件呢？
地形的配置文件还在编辑，部分内容专业性太强
还在与作者交流

8.矿物密度能否控制呢？
首先打开地形配置文件:'world/settings/biomes/default’
然后打开你想修改的地形
"ores": [
#为了方便查看只举一个例子
    {
#矿物内容
      "type": "DIRT",
#每份矿物多少方块
      "size": 33,
#生成几率，数字越大几率越高
      "count": 10,
#最低高度
      "minHeight": 0,
#最高高度
      "maxHeight": 256
    }

9.如何让指定世界不使用EWG生成呢？
打开插件下的settings.json文件

{
  "info": "Looking for the config files? The configuration files is located in the world folder under the settings folder",
  "worldsWithDefaultWG": [
#在这里添加不想使用EWG生成的世界
    "myvanillaworld"
  ],
  "minecraft_1_7_Map": false,
  "controlWaterFlow": true,
  "enableGeneratorSwap": false
}
