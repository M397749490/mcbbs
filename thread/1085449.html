前言:Linux为GNU项目下的一个开源操作系统内核(属于自由软件)本篇仅讨论在Debian发行版及其衍生发行版下的JRE安装，Redhat等其他非Debian衍生发行版请移步·这些系统的官方论坛。本篇教程是基于Ubuntu20.04LTS制作,其他Debian衍生发行版不会有过大差异。

本篇教程基于AMD64架构,i386(32位)请在相关的地方选择i386版(32位版)谢谢这篇文章的作者


1.下载JRE
下载64位压缩文件到/usr/lib/java
下(java文件夹需自行创建)并解压缩

可以直接右键-解压到当前目录
(不行请见Q.1)


2.添加系统路径
需要使用到终端
右键-在此位置打开终端
然后
  1. sudo passwd
复制代码
输入你的密码
输入你要给超级账户设置的密码(输入2遍)(提示要之前的密码的话就跳过这一步)
然后
  1. su root
复制代码
并输入你的密码
然后
  1. gedit etc/environment
复制代码
然后输入
  1. AVA_HOME="/usr/lib/java/jre1.8.0_65"
  2. CLASSPATH="$JAVA_HOME/lib"
  3. PATH＝"$JAVA_HOME/bin"
复制代码
然后保存就可以测试了然后
  1. java
复制代码
如果不提示没有这个命令,就成功了，如果提示，就一遍遍检查，实在不行私信我

3.下载启动器
有官网账号的下载官方启动器(推荐)没有的下载HMCL(不推荐)
然后下载完后，官方启动器输入
  1. dpkg -i "下载下来的启动器安装包"
复制代码
HMCL输入
  1. java "你下载下来的HMCL的jar文件及路径"
复制代码
然后和Windows一样就可以了


问&答
Q1:没有或无法选择解压缩
A:输入:tar -xvf "你下载下来的压缩文件"Q2:1楼有一个好像更好的方式,可以用么
A:待我实验一下
Q3:还有别的方法么？
A:可以考虑一下wine跑BMCL/BakaXL等其他启动器(可能闪退,但是更简单)
Q4:我是xxx发行版,请问xxx操作怎么办?
A:对不起，不知道，找别人去(一键三联)Q5:装了还好好的,怎么过几天又不行了?
A:请输入以下命令检查并选择。
  1. sudo update-alternatives --config java
复制代码
然后选择
  1. /usr/lib/java/jre1.8.0_65
复制代码
的版本编号并选择
Q6:没有更多问题了么
A:以后会有的
