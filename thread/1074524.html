handy-minecraft
一款有点好用的Minecraft开发Maven镜像
爱发电     仓库内容     文档说明
功能介绍
  • 源地址: http://maven.ljxmc.top/repository/handy-minecraft/
  • 包含: spigot和paper的1.8.8-1.16.1的主流核心...
  • 包含: AttributePlus,SXAttribute,Dantiao,TrHologram,TabooLib,VexView...
  • 包含: vault,placeholderapi,playerPoints,holographicdisplays,ProtocolLib,MythicMobs,SkillAPI...
  • 更多的支持请看文档说明,如果没有你想要的,请回帖说明,最好带上原路径,我会添加到本maven仓库中
  • 如果你想直接复制粘贴就使用,我强烈建议你看上面的文档说明!!!
  • 如果本镜像帮助到了您,希望给个评分,建议收藏本帖,您的收藏和评分对我维护本镜像站非常重要~
maven仓库简单使用介绍
第一步: 打开pom.xml ，在<repositories>...</repositories>代码块中加入：
  1. <repository>
  2.       <id>handy-minecraft</id>
  3.       <url>http://maven.ljxmc.top/repository/handy-minecraft/</url>
  4. </repository>
复制代码
第二步:引入你想要的jar。
AttributePlus:
  1. <dependency>
  2.       <groupId>org.serverct.ersha.jd</groupId>
  3.       <artifactId>AttributePlus</artifactId>
  4.       <version>2.1.9</version>
  5.       <scope>provided</scope>
  6. </dependency>
复制代码
TrHologram:

  2. <dependency>
  3.   <groupId>me.arasple.mc.trhologram</groupId>
  4.   <artifactId>TrHologram</artifactId>
  5.   <version>1.11</version>
  6.   <scope>provided</scope>
  7. </dependency>
复制代码
holographicdisplays:
  1. <dependency>
  2.     <groupId>com.gmail.filoghost.holographicdisplays</groupId>
  3.     <artifactId>holographicdisplays-api</artifactId>
  4.     <version>2.3.2</version>
  5.     <scope>provided</scope>
  6. </dependency>
