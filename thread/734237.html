插件名：

Fp（ForcePlayer）

本插件需在JAVA8的环境下运行

他的功能非常的强大
可以控制玩家以玩家的身份执行命令和发送消息
还可以控制玩家以OP身份执行命令

必须的前置
Citizens插件
若不安装将无法运行


指令
/fp chat ID 消息  让玩家以玩家的身份发送消息
/fp command ID 消息  让玩家以玩家的身份执行命令
/fp cop ID 消息  让玩家以OP的身份执行命令

权限
无
[只有OP可以执行这个命令]


小技巧
你想让玩家以OP的身份发送消息？
很简单
输入/fp cop ID fp chat ID 消息
是不是很简单？


就是这么多了最后就是期待的下载地址了
但是这个插件很特别
分为JS JAR
JS的安装方法和JAR不同
需要安装至
服务端/pvpin/plugin/player
内 重启服务器就好了
若您已经使用pvpin_js_rt插件
只需安装JS即可
JAR只需安装至
服务端/plugin
然后重启服务器就完成了
