首先用这条命令创建计分板scoreboard objectives add zsk minecraft.mined:minecraft.diamond_ore
循环执行execute if entity @a[scores={zsk=1..}] run summon minecraft:zombie 坐标
后面接一个条件限制的连锁命令方块输入scoreboard players reset @a zsk

  1. # 初始化
  2. ## 挖掘钻石矿 记分版
  3. scoreboard objectives add foo minecraft.mined:minecraft.diamond_ore

  5. # minecraft:tick
  6. execute as @a[scores={foo=1..}] at @s run function foo:zombie

  8. # 函数 foo:zombie
  9. ## 在当前位置召唤僵尸
  10. summon zombie ~ ~ ~
  11. scoreboard players remove @s foo 1
