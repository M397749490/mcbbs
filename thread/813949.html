作者: 秋灯Lantern    时间: 2018-8-13 10:39
一、你下了op依然可以破坏别人的领地
情况1 你的权限组比别人更高级 拥有破坏领地的权限 这是类似OP的情况
你可以输入/manudel 自己的ID
这样就恢复到了跟玩家一样的默认组。

情况2 那个人的领地开启了建筑权限/给了你建筑权限
让他在领地输入/res set 领地名 build false 设置所有人不可建筑
让他在领地输入/res pset 领地名 你的ID build false 设置你不可建筑。

情况3 领地插件默认开启了建筑权限
打开领地插件的主配置文件 /plugins/Residence/confing.yml
很多文本编辑器都带有搜索功能[search] 搜索 ResidenceDefault
然后你会看到 类似
  1.     ResidenceDefault:
  2.         build: false
  3.         use: false
  4.         container: false
  5.         pvp: false
  6.         tnt: false
  7.         creeper: false
  8.         flow: false
  9.         piston: false
  10.         ignite: false
  11.         firespread: false
复制代码

这样的
把其中build改成false 这样就可以设置每个领地默认关闭build权限

不过那个领地的主人还是得输入一遍/res set 领地名 build false

二、tpa权限
打开/plugins/GroupManager/worlds/world/groups.yml
搜索default: true 这样你就可以找到默认组
一般默认组是Builder或者Default
当你搜索到了之后会看到类似以下的东西
  1.   Default:
  2.     default: true
  3.     permissions:
  4.     - -bukkit.command.kill
  5.     inheritance:
  6.     - g:groupmanager_default
  7.     - g:bukkit_default
  8.     - g:essentials_default
  9.     - g:towny_default
  10.     info:
  11.       build: false
  12.       prefix: '&e'
  13.       suffix: ''
复制代码

或者会看到类似这样的
  1.   Builder:
  2.     default: true
  3.     permissions:
  4.     - essentials.build
  5.     inheritance:
  6.     - default
  7.     - g:essentials_builder
  8.     - g:towny_builder
  9.     info:
  10.       build: true
  11.       prefix: '&2'
  12.       suffix: ''

- essentials.tpa

添加之后应该大致是这个样子

    - essentials.tpa
[前面的横杠跟permissions对齐]
[横杠后空格不能丢 只能有一个空格]
