作者: 神の手    时间: 2016-1-26 17:23
去plugins\GroupManager\worlds\groups.yml
比如你想设置Builder为默认权限组
那么在builder这里面把default改成true
如下
  1.   Builder:
  2.     default: true
  3.     permissions:
  4.     info:
  5.       build: true
  6.       prefix: ''
  7.       suffix: ''
