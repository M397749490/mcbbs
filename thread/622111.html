前言
我其实早对这款插件朝思暮想好久了

刚刚好，我有个朋友会做

我就让他做了这款插件，然后我来给大家做福利A.A[不好请勿吐槽]

指令
/GJ - 查看插件帮助
/GJ setprice 指令 价格 设置某个动作的价格,默认十元[列如尿尿是/GJ NN，那就是NN]
/GJ NN - 在原地撒泡尿
/GJ LS - 在原地啦坨屎
/GJ GJ id - 和某某搞基
/GJ PPP id - 和某某啪啪啪
/GJ JB - 露出自己的繁殖器
/GJ PY - 露出自己的屁眼
/GJ DD - 露出自己的洞洞
/GJ PP - 露出自己的屁屁


效果我就不放出来，也就一俩个小点的奇葩粒子效果[没有权限节点，已经设置好辣]
服务器还会有通知-[用了就知道辣]
