FeatherJump

一个轻量级的登陆服快速运动插件

First.简介

   在跳起时右键指定道具 可进行快速二段跳

Second.指令
  • /fjump                列出全部命令
  • /fjump tuto        FeatherJump的使用教程
  • /fjump reload        重载

Third.权限
  • fjump.*                     全部指令权限
  • jump.user                  给玩家的权限（包含jump.tuto及fjump.jump）
  • jump.tuto                  允许玩家使用/fjump指令
  • fjump.jump               允许玩家使用技能物品进行二段跳

Fourth.配置文件
  1. # Default multiplier: 2.0 跳跃距离
  2. # Default item: FEATHER,更多物品名称参考： http://kiwike.se/wiki/index.php/Item_Names (用 "Bukkit Block/Item name) 更换技能物品
  3. # Default sound: true 是否启用声音
  4. # Default sound-type: ENTITY_BAT_TAKEOFF, 更多声音参考https://www.spigotmc.org/wiki/cc-sounds-list/ 使用技能时的声音
  5. # Default delay: 2 等待时间
  6. # Default delay-message: "&c你必须等待 &e&l{COUNT} &c秒后才可继续使用.",{COUNT} 为剩余冷却时间变量
  7. # Default delay-message-end: "&c冷却完成!"
  8. # Default no-perm: &4你没有权限"没有权限时的提示
  9. multiplier: 1.5
  10. height-jump: 1.0
  11. item: FEATHER
  12. sound: true
  13. sound-type: ENTITY_BAT_TAKEOFF
  14. delay: 2
  15. enable-delay-message: true
  16. delay-message: &c你必须等待 &e&l{COUNT} &c秒后才可继续使用"
  17. delay-message-end: &c冷却完成"
  18. no-perm: "&4你没有权限"
