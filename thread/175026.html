更多音效

这个插件允许你在服务器事件上添加音效:登陆，离开，攻击，聊天，等等等等……并且其他更多支持事件会在将来添加！添加的音效是可以自定义的,但是必须是MC音效之一.你会在这个插件运行后找到一个公开音效表：list-of-sounds.yml.

命令和权限
命令权限介绍
/sounds helpmoresounds.help列出可用命令
/sounds reloadmoresounds.reload重载配置文件
/sounds listmoresounds.list列出所有可用命令
/sounds play <sound>moresounds.play测试音效表中某个音效
-moresounds.update登录时会收到插件升级提醒

配置文件config.yml文件是很简洁的：
配置文件十分简单便捷:

sounds:
  '禁用一个声效请设置成none'
  '声音格式: soundname,[音调],[响度]         [] = 可配置的'
  '例子: note-pling,2,0.2'
  join: note-pling
  # 玩家登录时 - 所有人都会听见
  leave: note-bass
  # 玩家离开时 - 同上
  chat: item-pickup
  # 聊天时 - 同上
  command: item-pickup
  # 执行一个命令 - 执行者才能听到
  hit: hurt-flesh,1.2
  # 一个怪物或玩家攻击时 - 所有人听见
  hit-sword: zombie-metal,1.5
  # 当一个怪物或玩家在用剑攻击时 (铁或钻) - 所有人听见
  hit-arrow: orb-pickup,0.8
  # 成功弓箭攻击 - 个人听见
  teleport: portal-travel,2
  # 玩家用指令传送时 - 个人听见
  on-death: wither-spawn
  # 玩家死后 - 个人听见
update-notifications: true
# 当服务器开启时检查更新
teleport-particles: true
# 传送时的粒子效果 - 所有人可见
