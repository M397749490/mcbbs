服务器插件介绍
1.自由PVP插件,可以越战Yo~~~

2.砍树插件，砍掉树干一节就啪嗒啪嗒的砍好了
注意：只有(原版斧头才生效)

3.称号系统
/prm list [prefix/surfix]
prefix 为前缀 surfix为后缀 (二选一)
查看当前拥有的称号(列表)
/prm set [prefix/surfix] [序号]
prefix 为前缀 surfix为后缀 (二选一)
使用称号
/prm check
将使用中的称号放入列表
4.商店系统
拿好要出售的物品左键单击
以聊天的形式输入价格
用指令更改商店类型
对着商店/see
可以看到商店内的物品
5.@系统
以聊天的形式
@玩家id
@全体玩家
6.锁箱系统
摆上箱子后自动上锁
7.领地系统
圈地工具为 纸
选取两个点后
/res select size 查看价格
/res create 领地名 创建领地
更多见群
