标题: MythicMobs插件生物出生点的问题
造了一些副本，但是我弄一个出生点/mm s create XXXX 到处都会生成这个出生点预设的生物，就算用leashrange变量设置也不行 有什么办法可以弄好吗

作者: a2605393469    时间: 2016-2-4 04:18
/mm s set 刷怪点 cooldown 10  怪物死后3秒刷怪
/mm s set 刷怪点 maxmobs 1 限制这个刷怪点最多可以刷一个怪
/mm s set 刷怪点 mobsperspawn 1 刷怪点一次刷一个怪

设置完这些，在也不怕副本到处都是这个怪拉
