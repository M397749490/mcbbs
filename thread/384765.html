作者: wjxhahaha    时间: 2015-1-11 23:58
用essentials的config.yml里面的聊天设置来改，有一个样本给你看看
  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |              EssentialsChat 聊天设置                 | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7. chat:

  9. # 设置聊天半径,如果安装了EssentialsChat,这将设置玩家喊话的可见范围,以格为单位.设置为0则允许全图聊天.
  10. # 注意开启了间谍模式(权限:essentials.chat.spy)的玩家将看到所有聊天内容,无视该设置.
  11. # 拥有"essentials.chat.shout"权限的玩家可以忽视该设置,只要在聊天内容前面加上"!"符号即可(小写感叹号)；
  12. # 或者拥有"essentials.chat.question"权限的玩家可以忽视该设置,只要在聊天内容前面加上"?"符号即可(小写问号)；
  13. # 你可以添加使用上两行方法的花销,在上经济设置中的"command-costs"下添加"chat-shout"和"chat-question"的设置即可.
  14.   radius: 0

  16.   # 聊天格式,可以有两种,你可以定义所有聊天为标准格式.
  17.   # 或者你可以给一个用户组特定的聊天格式,提供一些额外的变化.
  18.   # 是否设置为默认聊天格式,需要与ichat插件兼容.
  19.   # 想了解更多的默认聊天格式的信息,请查看wiki: http://wiki.ess3.net/wiki/Chat_Formatting

  21.   #format: '<{DISPLAYNAME}> {MESSAGE}'
  22.   format: '&e[{WORLDNAME}]&a[{GROUP}]&r{DISPLAYNAME}&f: {MESSAGE}'

  24.   group-formats:
  25.   #  Default: '{WORLDNAME} {DISPLAYNAME}&7:&r {MESSAGE}'
  26.      黑幕: '&0[{GROUP}]&f{DISPLAYNAME}&f:{MESSAGE}'
  27.      弹幕游戏: '&e[{WORLDNAME}]&6[{GROUP}]&2{DISPLAYNAME}&f: {MESSAGE}'
  28.      乡民: '&e[{WORLDNAME}]&6[{GROUP}]&2{DISPLAYNAME}:&f {MESSAGE}'
  29.      活动中: '&e[{WORLDNAME}]&5[{GROUP}]&5{DISPLAYNAME}&f: {MESSAGE}'
复制代码

这里的worldname就是世界名，displayname是玩家名，groupname是用户组名。你还可以在group-formats里设置不同用户组的不同聊天格式。比方说我就设置了 黑幕组，弹幕游戏组，乡民组，活动组 4种不同的聊天格式，这4组之外的其他所有组都用format里默认的聊天格式
