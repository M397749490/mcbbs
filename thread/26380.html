从0学起（会弄的可以跳过了）
什么是权限插件？权限插件是一个管理你的服务器的玩家权利的插件，他可以控制玩家可以用的插件，使用的指令，可以干的事情等等。在你下载每个插件的时候，网站上都会有一个permission note，一般你就把这个note放进你的服务器里就可以控制大家的行为了！所以，你现在要做的就是把那些note找出来为待会做准备。但是，你要是想然大家都能用这个东西，在“.”后面加上“*”。所以以下我都以permission代替，注意格式和字母。祝愿你成功！
安装PermissionEX

首先，去上面的网站下一个最新版本的permissionEX，里面会有3个jar，其实是三个插件，其他两个要是你想用的话就可以用。但是我们今天主角是pemissionEX,当然，jar上面写着名字了。

怎样子安装插件就不解释了吧

确定你有生成文件！！！

好，现在你有2种方法修改：
1.游戏里设置（新手推荐！！！）
2.修改yml
游戏里设置

打开你的服务器，好你已经准备好了
确保你的permission完整生成好了

我用的是服务器，游戏内用法一样，加个“/”
上面的世界是要是你有多世界
你已经完成了....剩下的就是输指令，根据下面的指令设置你的服务器权限：（常规修改指令，所有指令在下面）<>必须[]可选
group:
pex group <组> create [关系] 创建小组，关系意思是他是从那个组升上来的
pex group <组> delete 删除小组
pex group <组> add <permission> [世界] 给小组加permission
pex group <组> remove <permission> [世界]给小组减permission
pex group <组> timed add <permission> [lifetime] [世界]给小组限时（秒）给permission
pex group <组> timed remove <permission> [世界] 把小组限时的permission去掉
user:
pex user <玩家> add <permission> [世界] 给玩家增加permission
pex user <玩家> remove <permission> [世界]给玩家移除permission
pex user <玩家> timed add/remove <permission> <lifetime in seconds> [世界] 给玩家在时间内（秒）添加/移除permission
pex user <玩家> group set/remove <group> [世界]  把玩家放进/移除<group>
给小组加人：
pex group <组> user add <玩家>给组加上玩家
pex group <group> user remove <user>给组减去玩家
要是想给玩家/组名字和说的话加颜色的话：（均已颜色代码表明）
pex user <玩家> prefix [开头] 设置玩家开头（名字）颜色
pex user <玩家> suffix [结尾] 设置玩家结尾（说的话）颜色
pex group <组> prefix [开头] 设置组开头（名字）颜色
pex group <组> prefix [结尾] 设置组结尾（说的话）颜色

颜色列表
好了用这些东西应该就可以应付设置了

修改yml
我们要修改的是pemission.yml，另外一个config.不管他
首先，文件里他会给你一个像这个的东西：


  2. groups:
  3.   default:
  4.     default: true
  5.     permissions:
  6.     - modifyworld.chat
复制代码
所以我们就可以改这个文件，建议你下个notepad++(点击到下载页面！）
解释一下：
  1. groups:
  2.   default:                           《=====小组名字
  3.     default: true                  《+++++是不是默认（true or false)
  4.     permissions:                  《=====permission notes
  5.     - modifyworld.chat        《+++++一个permission note
复制代码
你们就可以在这个基础上修改，像这样（示范）加有一些新东西：



  4. groups:
  5.   default:                                《=====一个组，名字自拟
  6.     default: true
  7.     permissions:
  8.     - modifyworld.chat
  9.   user:                                    《=====又一个，名字自拟
  10.     default: false
  11.     permissions:
  12.     - iConomy.*
  13.     inheritance:
  14.     - default                              《=====他的下属，也就是说他包含了《default》的所有东西
  15.   Admin:                           《=====管理员名字自拟（但是不非得需要这三个，你可以有一个或者10个）
  16.     default: false                             ↑越线了
  17.     permissions:
  18.     - '*'                                     《=====所有权限以“*”表示
  19.     prefix: '&4[admin FTW]'      《=====开头颜色（上面有讲）[]圈住要说的
  20.     suffix: '&1'                           《=====结尾颜色
  21.     worlds:                                《=====世界（可以控制多世界）
  22.       nether:                              《=====地狱
  23.         permissions:                     
  24.         - '*'
复制代码
注意，不能抄上面的（加的评论通不过）
很简单吧？现在我列出来一个组里面可以用的选项：
default: 是不是默认
permissions: 填permission note 的地方
inheritance: 继承他的下属（下属有的他都有）没有默认无、
prefix:
suffix:  讲了很多遍了...
worlds:多世界选项，世界名，permission
其实还有更多，但是一般我们用不到


在这里，我提醒大家：小心前面的空格！！！
由于notepade++每次跳线时，都会自己跳格（就只有一个空格！），但是我们的插件需要格子！！！要是没有会导致permission错误！！！我列出需要的格子



  2. group:               <===0
  3.   Admin:             <===2
  4.     default: false  <===4
  5.     permissions:  <===4
  6.     - '*'               <===4
  7.     prefix: '&4[admin FTW]'  <====4
  8.     suffix: '&1'     <====4
  9.     worlds:          <====4
  10.       nether:        <====6
  11.         permissions: <===8
  12.         - '*'            <====8
复制代码

可以看出，每降一级，多2个格
注意，defaut,pemission还有- 都是同一级别的
