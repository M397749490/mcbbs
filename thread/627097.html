找到这个位置，
  1.   mirrors:
  2.         # Worlds listed here have their settings mirrored in their children.
  3.         # The first element 'world' is the main worlds name, and is the parent world.
  4.         # subsequent elements 'world_nether' and 'world_the_end' are worlds which will use
  5.         # the same user/groups files as the parent.
  6.         # the element 'all_unnamed_worlds' specifies all worlds that aren't listed, and automatically mirrors them to it's parent.
  7.         # Each child world can be configured to mirror the 'groups', 'users' or both files from its parent.
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
复制代码



然后复制粘贴就是了，再然后在游戏内用OP权限，输入/manload 重载GM权限组，再然后，你就会发现【worlds】文件夹里就多了几个以你的世界命名的文件夹了。打个比方，你有四个世界分别是【world】【dipi】【DIM1】【DIM-1】，那么你【worlds】文件夹里就会生成四个世界的权限文件夹。然后找到你的特定世界，在返回游戏（这样最好，更直接，当然你也可以在配置文件里添加权限）
输入
/mangaddp  builder -essentials.back
/mangaddp  builder -essentials.sethome.* 就行了，如果还想禁其他的权限，请看http://www.mcbbs.net/forum.php?m ... d=523122&extra=
我曾经提过这个问题，你参考参考即可

作者: 苏颜    时间: 2016-8-26 11:41
要先把不同世界的权限分开。需要groupmanager插件[1.7.2]版本
①：装好插件重启服务器生成插件文件夹，打开/plugins/GroupManager/config.yml。
② :
  1.   mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           sc:
  16.           - users
  17.           - groups
  18.           pt:
  19.           - users
  20.           - groups
  21.         World2:      (World2 将会拥有自己的独立设置)
  22.         同上:
  23.     #    world3:
  24.     #    - users    (World3 使用 world2 的 users.yml,但是使用自己独立的 groups.yml)
  25.     #    world4:
  26.     #    - groups   (World4 使用 world2 的 groups.yml,但是使用自己独立的 users.yml)
  27.     #  world5:
  28.     #    - world6   (这个世界使用从world5镜像过来的设置文件)
复制代码

把World2和同上改成自己要设定世界的名字（是地图文件夹的名字）
③：进入该世界输入/mangaddp Builder(要关闭的组名) -essentials.sethome以及-essentials.back
在权限前面加  -    就等于除去了这个权限
④然后就没有然后咯~
