DimReseter

作用：自动重置指定的世界，例如资源世界（可以自动删除GP的领地）

用法：丢到mods文件夹内重启服务端生成配置文件

配置文件：

  1. CustomGenerators {
  2.     # 如果启用，列表中的所有世界都在重置时使用新的世界生成器
  3.     Enabled=false
  4.     # 列表中的所有世界都将使用指定的生成器生成
  5.     List=[
  6.         "DIM1|WorldGenerator"
  7.     ]
  8. }
  9. # 每个月都重置的列表
  10. EveryMonthReset=[
  11.     world
  12. ]
  13. # 每次重启服务器都重置的列表
  14. EveryRestartReset=[]
  15. # 重置日期 - 每月的某日 - 0 为关闭
  16. ResetDay=1
  17. # 是否在下次服务器重启时重置
  18. ResetToday=false
