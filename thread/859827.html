介绍:PlayerShopsRPG , 作者:Zerthick
是一个可视化还不错(类似mud)的商店插件,相比较于同类插件(如carrotshop或villagershop)的好处在于,配置轻松,且不需要实体来启用商店,我是指不需要摆个箱子

特性:
  • Region-defined Player Shops! 【基于区域的玩家商店】
  • Easy to use Chat Interface! 【使用聊天栏交互】
  • Ability to define Admin/Server Shops! 【可以设置管理员/服务器商店】
  • Ability to define different Shop Types (Ex: Blacksmith) that can only sell certain items! 【可以定义不同商店种类,(例如铁匠铺)这会让商店只能出售对应类型道具(需要编写config)】
  • Support for Shop Managers in addition to Owners! 【支持同一商店多个管理者】
  • Full Support for Custom Items (MetaData)! 【完全支持metadata(这点我没测试是否兼容其他依赖nbt的插件,比如nt-rpg)】
  • Support for Multiple Currencies! 【多种货币支持】
  • More! 【更多】



教程部分:
QuickStart - How to create your first shop
  • /shop select to select the region to create the shop
  • /shop create My Wonderful QuickStart Shop to create a shop named My Wonderful QuickStart Shop
  • Hold an item you want the shop to buy or sell in your hand and execute /shop item create
  • To stock your created item hold it in your hand and execute /shop item add
  • /shop browse to view the contents of your shop
  • Click on Manager to access the management page
  • Click on the first and second -- to set the sell and buy price respectively.
  • Profit!
来自官方ore的wiki

7-点击 -- 来设置价格(上面会提示sell和buy)
8-咔嘭!
