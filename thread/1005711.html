ME接口 (ME Interface)
  • 编辑
  • 加合成表

物品命令：/give @p appliedenergistics2:interface 64 0

可以从从ME网络中输出物品到其自身或向ME网络输入物品，也可以通过样板在ME终端控制机器进行生产。

右击打开GUI可以看到配置栏和样板栏：



配置栏第一行用于配置物品，光标拿着要标记的物品，左击第一行任意一格将手中的全部该物品配置进这一格，右击则是配置一个该物品。

配置栏第二行用于输入输出物品，第一行若标记了物品且网络中存在这种物品时，将会在第二行同一位置输出该物品，若网络中该物品不足标记的数量，则会继续输出直到数量相同。也可以手动将物品放入第二行，当放入的这一格的头上并没有标记时他会被输入网络，如果第一行有这种物品的标记但是你没放在标记的下面，也会先被输入进网络再在标记的下面输出。如果第一行没有标记放入的一切物品都会被输入网络。

样板栏用于放置编码样板，当放置了编码样板且贴着该样板对应的机器时，可以用ME终端调用该处理，实现自动化。


ME接口占用一个频道。




物品导管 (Item Conduit)
  • 编辑
  • 加合成表

物品命令：/give @p enderio:item_item_conduit 64 0

物品导管是一个传导物品的管道，并且可以应用多种升级。

它会自动连接相邻的带有物品存储的方块（如果一个机器的IO模式被设为“禁用”，仍会连接），并在所连接的方块的表面形成一个导管接口，导管接口是方块进入物品导管网络的标志。如果这个被连接的方块被移除，相应的，连接会被自动切断。

每一次抽取一“组”，一“组”数量为4个物品，这个值可以被导管升级调整。


右击导管接口可以打开它的GUI，对这个导管接口进行设置。下图是默认的设置


GUI (1.12.2)

  • 加入/抽取（Insert/Extract）：勾选生效相应的功能。如果都不勾选，连接将被切断。玩家能够通过导管接口处的箭头的方向来辨别它的IO状态。

  • 频道（Channel）：物品导管网络中，相同频道的导管接口才能互通，共有16种颜色的频道可供选择。玩家能够通过导管接口处的箭头的颜色来辨别它的频道。

  • 优先级（Priority）：这决定了同一网络中多个“加入”导管接口的输入顺序。只有优先级更高的“加入”导管接口不再能被输入时，优先级次之的“加入”导管接口才会被输入。

  • 循环模式（Round Robin）：网络中存在多个“加入”导管接口时，会以“组”为单位，依次向每个“加入”导管接口输送物品，优先级高的优先，距离近的优先，优先级的判定优先于距离判定。

  • 自供给模式（Self Feed）：将抽取的物品再加入被抽取的容器，前提是加入和抽取同时打开，加入和抽取处于同一频道。优先级的判定优先于自供给模式，所以打开这个模式时，优先级一定要大于物品管道网络中任意一个导管接口的优先级。

  • 红石模式（Redstone Mode）：控制导管对红石信号的反应，默认为从不工作。左击顺序改变模式，右击倒序改变模式。顺序为：始终工作、收到信号工作、收到信号不工作、从不工作。如果调整为收到信号工作或收到信号不工作，这个图标右侧会出现信号颜色（Signal Color）按钮，用于调节红石模式响应什么颜色的红石信号（见红石导管），默认为红色。玩家能够通过导管接口处的箭头前端的颜色来辨别它的颜色。

  • 过滤器升级（Filter Upgrade）：放入过滤器限制抽取和加入的物品。

  • 功能升级（Function Upgrade）：放入速度升级/降级以控制抽取速度。


可用的过滤器：

  • 基础物品过滤器

  • 高级物品过滤器

  • 灵魂过滤器[5.0.38及以后]

  • 大型物品过滤器[5.0.38及以后]

  • 高级大型物品过滤器[1.12以及后]

  • 高级灵魂过滤器[5.0.38及以后]

  • 充能物品过滤器

  • 模组物品过滤器

  • 现有物品过滤器

  • 限制物品过滤器[1.12及以后]

  • 计数物品过滤器[仅1.10]


可用的功能升级：

  • 导管速度升级[1.12及以后]

  • 导管速度降级[1.12及以后]

  • 物品导管速度升级[1.10及以前]

  • 物品导管速度降级[1.10及以前]

  • 远程接入升级[1.10及以前]
