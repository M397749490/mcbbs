插件的问题，已经有很多人向作者反映了
[PlaceholderAPI] BS-Teams is currently using a deprecated method to hook into PlaceholderAPI. Placeholders for that plugin no longer work. Please consult [Bkm016, Saukiya] and urge them to update it ASAP.
BS-Teams目前使用一种不推荐的方法来挂钩到PlaceholderAPI。该插件的占位符不再工作。请咨询[Bkm016, Saukiya]并催促他们尽快更新

可以在配置文件Language2里zh_CN.yml中text的文本加入颜色代码（解决字体发亮）
commandtemp改成command
例如↓↓↓
  1. TEMA-HELP:
  2. - '[book]'
  3. - '       &c< &4&nBS-Teams&c >'
  4. - ''
  5. - '&8&m                           '
  6. - '       &k|&r &l<@1>&r &k|&r'
  7. - ''
  8. - '       &k|&r &l<@2>&r &k|&r'
  9. - ''
  10. - '       &k|&r &l<@3>&r &k|&r'
  11. - ''
  12. - '       &k|&r &l<@4>&r &k|&r'
  13. - '&8&m                           '
  14. - '@option:1'
  15. - '    text: &a&l创建队伍'
  16. - '    command: /bsteams create'
  17. - '    showtext: &7点击创建队伍'
  18. - '@option:2'
  19. - '    text: &a&l队伍邀请'
  20. - '    command: /bsteams accept'
  21. - '    showtext: &7点击查看邀请列表'
  22. - '@option:3'
  23. - '    text: &a&l队伍列表'
  24. - '    command: /bsteams list'
  25. - '    showtext: &7点击查看队伍列表'
  26. - '@option:4'
  27. - '    text: &a&l加入队伍'
  28. - '    command: /bsteams join'
  29. - '    showtext: &7点击加入指定队伍'
