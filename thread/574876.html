随机传送我们都知道,这个是1.9版

简介:

   这是一款随机传送插件。这个插件使玩家们可以使用命令/tpr,传送到一个随机的位置。 你可以设置传送范围，多远可以传送。 这个简单的插件，可以帮助服务器里的玩家利用起地图的每个地方！

指令:
(/randomteleport=/rtp=/rteleport=/randomtp)
/rtp <add | remove> <name> 添加或者删除一个传送点
/rtp <list> 列出所有的传送点

权限:
  • "rtp.command.rtp" : 可以使用/rtp
  • "rtp.command.addtp : 允许使用添加传送点的指令
  • "rtp.command.removetp" : 允许使用删除传送点的指令
  • "rtp.command.listtp" : 允许使用列出所有传送点的指令
  • "rtp.cooldown.bypass" : Unlocks hard set limit for teleporting 懂的留言.....
