on place:
    world is 世界名
    block is not 方块ID
    cancel event
on break:
    world is 世界名
    block is not 方块ID
    cancel event
把以上代码写入一个txt文档，然后把文档改名成 XXXX（任意英文）.sk
安装skript插件,然后把该文件放到skript的script文件夹中，然后游戏中输入/sk reload XXXX即可
