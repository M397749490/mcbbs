AuroraBackup-极光自动备份

极光自动备份是一款为Sponge端而编写的自动备份插件，该插件可以定时的进行备份世界。且指令及设置简单易懂，适合小白服主上手使用









功能:
  • 手动/自动 备份世界（目前仅支持默认世界）


待更新功能：
  • 接入FTP/OSS/COS等云端存储服务
  • 备份指定数据库
  • 备份插件数据
  • 备份数量达到一定数量自动删除
  • 待续...




配置文件


  1. AuroraBackup{
  2.     # 插件版本号，请勿修改否则可能会丢失设置
  3.     Version = 1.0.0
  4.     # 插件语言，目前支持：zh-CN/en-US
  5.     Lang = "zh-CN"
  6.     # 备份时间间隔,单位是秒
  7.     Time = 900
  8.     # 自动备份
  9.     AutoBackup = true
  10. }

指令及权限


权限 指令描述
aurorabackup.base
/aurorabackup 或 /backup
 主命令
aurorabackup.base.create
/aurorabackup create/new
创建一个新的备份文件
aurorabackup.base.reload
/aurorabackup reload
重新载入配置文件
aurorabackup.base.manager
/aurorabackup time
设置自动备份的时间间隔，单位是秒
aurorabackup.base.enable
/aurorabackup enable/on
启用自动备份
aurorabackup.base.disable/aurorabackup disable/off 禁用自动备份
