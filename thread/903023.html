基于各阿里云解析API编写
请遵守协议使用！


为什么要开发GeDDNS:
    本人也是一名腐竹，同时也是一名计算机爱好者，搭建了许多的服务器，IPV6网络已经到来，5G网络也是非常注重IPV6，但是此时此刻，我跑遍了Github和Gitee，也找不到对IPV4与IPV6同时能够进行简单易懂的支持的软件，故我就基于阿里云的DNS服务API开发了这样一款DDNS软件。
GeDDNS开发目标：
1.使用Python开发，代码精简，注释详细，易于修改
2.结构简单，使用简单，易于上手
3.使用JSON进行配置储存，易于与其他程序交互，调用简单
4.支持IPV4与IPV6，可以自由开关
5.跨平台，多平台支持
GeDDNS使用注意事项：
本软件没有自动循环执行功能，
如果需要实时同步，建议使用相关
定时执行的程序，按照需求执行[如宝塔bt.cn面板]
#--------------------------------------------#
本程序基于AliDNS，
请先将自己的域名托管到阿里云平台
#--------------------------------------------#
本程序遵守LGPLv3开源，请遵守协议
GeDDNS安装教程：
Windows：
1.安装Python(建议3.7.4）【安装时注意勾选“添加到环境变量”】
2.下载PIP(https://pypi.org/project/pip/)
3.解压到任意文件夹
4.进入到文件夹，按住Shift右键鼠标，点击进入Powershell（或命令行）
5.输入“py setup.py install”,等待安装完成
6.随后进入Python安装目录，进入Script文件夹，重复第四步步骤
7.按顺序输入以下命令（待前一个执行完成再输入下一个）
pip install requests
pip install aliyun-python-sdk-core
pip install aliyun-python-sdk-alidns
8.下载GeDDNS，解压到任意目录
9.按照README或者本帖要求填写配置文件
10.运行ddns.py，即可自动同步【py ddns.py】
Linux(Mac OS)
1.安装Python(建议3.7.4）【参考文献：https://www.cnblogs.com/yhongji/p/9383857.html】
2.下载PIP(https://pypi.org/project/pip/)【wget】
3.解压到任意文件夹【tar】
4.进入到文件夹【cd】
5.输入“py setup.py install”,等待安装完成
6.随后进入Python安装目录，进入Script文件夹
7.按顺序输入以下命令（待前一个执行完成再输入下一个）
pip install requests
pip install aliyun-python-sdk-core
pip install aliyun-python-sdk-alidns
8.下载GeDDNS,解压到任意目录【wget】
9.按照README或者本帖要求填写配置文件
10.运行ddns.py,即可自动同步【py ddns.py】
GeDDNS配置教程：
{
    "RR": "",
    "Domain": "",
    "IPV4": "",
    "IPV6": "",
    "accessKeyId": "",
    "accessSecret": ""
}
1.RR指解析的二级域名
【如我要解析test.example.com,则填写test】
2.Domain指主域名
【如我要解析test.example.com，则填写example.com】
3.IPV4与IPV6指是否启用IPV4/IPV6的DDNS(启用填true，关闭填写False)
4.accessKeyId与accessSecret是阿里云API鉴权口令，可以从阿里云控制台获取
例子：
{
    "RR": "test",
    "Domain": "domain.com",
    "IPV4": "true",
    "IPV6": "false",
    "accessKeyId": "Tom",
    "accessSecret": "Mike"
}
效果：
解析的域名：test.domain.com
IPV4成功解析
IPV6未开启
