使用方法
Multiverse多世界生成方法[常用]
需要下载Multiverse-Core多世界前置
  • 输入指令
/mv create <世界名> normal -g VoidGenerator

便可以生成一个普通的虚空世界，然后使用/mv tp <世界名>即可来到该世界
  • 输入指令
/mv create <世界名> normal -g VoidGenerator -t FLAT

也可以生成一个虚空世界，与上面那个不一样的是，这种世界的海平面是0，不是63
（上面那种世界下降到高度63以下周围就黑了，这种世界下降到高度0以下才黑）

主世界world生成方法
先删除系统生成的world文件夹，打开bukkit.yml并添加以下内容
  1. worlds:
  2.   world:
  3.     generator: VoidGenerator
复制代码
如果你没有做改动的话，world是默认的主世界名
然后启动服务器即可
