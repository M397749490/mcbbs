标题: MCPE PocketMine-MP服务器 更新到1.3稳定版 更新多项功能 未来有望复制口袋领域API
本帖最后由 TylrDrdn 于 2013-5-29 11:23 编辑

发在PE多人联机版貌似没什么人看。。。


PocketMine-MP是针对MCPE开发的第三方服务端软件，由于编写语言是PHP，自由度非常高，可在多种系统环境下运行并支持第三方插件，目前支持：Windows、Linux、Mac、Android、RPi（1.3版更新后支持移动设备），可以在个人电脑、手机、虚拟服务器等设备上运行，轻松实现24小时开服。


具体开服教程参考这个帖子：【更新】最新完整1.3版 PocketMine-MP 开服、进服及地图导入图文教程


1.3版之前由于服务端还有许多缺陷，功能鸡肋，并不看好它，但是在新版出来后觉得发展前景非常可观！


1.3版更新内容：
原文链接：https://github.com/PocketMine/PocketMine-MP/wiki/Stable-Version-History翻译：
  • Selectors 聊天对象选择（例如：Hello! Everyone @all）
  • Multiworld system 多世界系统（没试过，貌似是可以在多个世界互相切换？）
  • RCON protocol 远程控制协议（远程管理服务器）
  • Query protocol 远程查询协议（远程查询服务器属性）
  • ACK/NACK packet recovery system 掉包修复系统
  • Ping/Pong system （这个有点难解释，和上面一样是加强网络通信稳定性的）
  • Items attack damage 道具攻击伤害
  • PMF Levels PMF格式的存档
  • Better map Importing 优化地图导入
  • Fixed Chests, crashes and more bugs 修复箱子、系统崩溃等bug
  • Hack protection 防作弊
  • Added new commands 添加新命令
  • Lots of small changes 许多小改动
  • Buckets, Cakes 预先为0.7.0加入桶和蛋糕的支持
  • Blocks as torches drops when broken its support block 当火把（或者其他同类的方块）底下的方块被打破之后火把掉落
  • In-game spawn protection 出生点保护
  • Ability to modify the Creative player's inventory via plugins 能够使用插件修改创造模式内玩家的道具
  • Armor damage reduction 护甲降低伤害（就是护甲可以起作用了）
  • Optional Item enforcement (without crafting) （防止玩家使用mod添加道具的选项）（生存模式开启选项会令玩家无法合成）
  • Cached block changes （缓存的方块变化，缓冲并发送大量方块修改的封包。。大概是对大量方块修改的稳定性支持吧）
  • Autodetection of internal ticker （不懂！）
  • Command history support in Linux (Linux支持命令历史记录)
  • Big packet sending （大型封包的发送）
  • Smelting （支持熔炉）


作者透漏在MCPE 0.7.0版发布后会很快添加对0.7.0版的支持再更新一次
另外作者还说在获取 “口袋领域” API之后会研究合并开发的可行性，值得期待，毕竟目前需要对MCPE的客户端进行破解（修改服务器IP）才能加入PocketMine服务器，合并开发后也许就不需要了。
