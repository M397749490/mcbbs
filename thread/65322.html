# 纯属黑DinnerBone
# 记住，这是玩笑！
2013年，Minecraft 9.1.9发布，本游戏发布了许多新奇的玩意儿。（我可以先告诉你，Notch已经着手搞0x10c，Jeb卧倒不起，所以这些玩意都是由可恶的Dinnerbone创作的）
列表如下：
修复或增强
  • 门
  • 门也会被水和岩浆破坏了（铁门除外）
  • 新增了可以打开的铁门。
  • 金苹果
  • 新增高能金苹果，食用后会在旁边生成TNT爆炸。（不会对食用者造成伤害）
  • 提高附魔金苹果的效果。
  • 蠹虫
  • 现在蠹虫会破坏羊毛和书架了。
  • 村民
  • 现在村民会远离人多的地方了。
  • 绿色村民现在可用，将会在教堂的顶层生成，交易不变。
  • 村民可以人工繁殖，使用钻石即可。
  • NPC村庄
  • 增大了铁匠铺的空间，并且放置了门。
  • 现在每位村民的家都有一个箱子。
  • 增大了教堂的空间，被误解为“瞭望塔”的时代已经结束。
  • 新增坟墓。
  • 冻原
  • 冻原将会生成雪地小屋。
  • 如果不穿盔甲或穿着链甲将会受伤。
  • 皮革盔甲
  • （你懂得，见上面）
  • 新增之前的合成方法。（即使用羊毛合成）
  • 要塞、地牢和废弃矿洞
  • 这三个建筑结构将不会因为同时出现而破坏。
  • 蝙蝠
  • 蝙蝠只能使用刷怪蛋或作弊获得，不能自然生成。

新增
  • 让Minecraft更卡，1GB内存+高级多核CPU+高级显卡也就只有30FPS。
  • 预装Optifine（即通吃某提高性能+高清修复Mod）
  • 新增生物男巫——女巫的男性版本。
  • 新增光源方块“夜太阳”。
  • 新增彩色玻璃等其它装饰性方块。
删减
  • 移除Herobrine（官方玩笑）
