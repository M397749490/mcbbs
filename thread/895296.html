Skript解决了我一系列制作RPG服务端时的难题,下面切入正题

必要的一些前戏操作
首先你得有一台能用的电脑,Skript需要1.8到1.14的服务端(1.7.10曾经尝试似乎可以但好像会有点点BUG)
然后在MCBBS或者直接去原地址下一个适合当前服务端的Skript
同时想要学习一波Skript完成更多操作的可以收藏一波下面的插件百科Skript链接
http://mineplugin.org/Skript

Skript的基础操作
当把Skript塞进Server/Plugins以后重启一下服务器就可以在Plugins/Skript/scripts看到你的脚本(插件)们了
此时里面有一些奇怪的 形如"-brock head.sk"的插件自带的脚本
前面加了这个符号所以就是默认没有加载的状态,不用管他,我们直接复制一个自带的脚本
然后改成你想要的名字比如说"use skript build a world of warcraft.sk"
再把里面所有字符删完,就完成了一个新的脚本(插件)的创建,这样可以保证编码不出错(可能)
当然也可以直接创建一个xxx.sk
Skript便于调试,只需要用你的Notepad甚至记事本改完了保存就可以输入下面这个指令重载脚本(插件)
"/sk reload shut up and take my money"
然后就加载了你的"shut up and take my money.sk"

大致了解Skript咋锤出一个完整的插件
Skript脚本大致可以理解为由 触发器,表达式,行为 组成
触发器很好理解,例如有"On Break" / "On Place" / "On Damage"
在前两者中放置方块关系到 玩家Player,方块Block 这两者就是表达式
而第三者则关系到 攻击者Attacker,受击者Victim 这俩也是表达式
行为比如说 Heal the %express%,Damage the %express% by 3 hearts
在这里我们介绍一个 cancel event 顾名思义,意为取消事件,阻止Break/Place/Damage的发生
了解以后我们可以直接来解析下面这个脚本(插件)
  1. on break:
  2.     if player is op:
  3.         stop
  4.     cancel event
  5.     stop
复制代码
没错,Skript的格式就是这样子
当出现 Break 这个事情的时候,里面的内容从上往下执行
使用 if player is op: 来检验是不是OP,如果是的话就执行下面的内容,即 stop
stop的意思是直接结束脚本,后面的东西就不用管了
那么这么一搞,如果你是OP,破坏方块的时候检验你是不是OP,是的话就停止
后面的 cancel event 就不会涉及到了,因为 stop 了,反之如果破坏的人不是OP
那么检测不通过直接跳过 if 里面的内容,cancel event 然后 stop

Skript原版的功能很多,可以完成很多操作
只要稍加学习就可以充分发挥想象力达到很多效果
通过查阅成品脚本(插件),学习更多语句可以使手中的Sk更加强大
下面介绍几种方法着重完成RPG服务器中的几个脚本例子,可以代替一些插件

右键打开一个名为"treasure chest"的宝箱
  1. on right click with a chest:
  2.     if player's tool's name is "treasure chest":
  3.         chance of 50%:
  4.             give player a diamond
  5.         execute console command "/mm i give %player% SkeletonKingSword"
  6.         message "you opened a treasure chest!"
  7.     stop

  1. on chat:
  2.     if player is in world "chicken":
  3.         if player have permission "changtiaoraplanqiu":
  4.             cancel event
  5.             broadcast "&7&l&m                                           "
  6.             broadcast " &f%player's display name% &f&l: &e%message%"
