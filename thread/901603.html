标题: Skript插件死亡保护符
求写一下配置文件，死亡不掉落，消耗背包中的死亡保护符，挖掘圆石，有20%的几率掉落死亡保护符
作者: lmyalmy    时间: 2019-8-13 09:59
本帖最后由 lmyalmy 于 2019-8-26 07:35 编辑

挖掘圆石：
on mine of cobblestone:
    if chance of 0.2:
        drop a paper named "&r死亡保护符"

on death of player:
    if player have a paper named "&r死亡保护符":
        take a paper named "&r死亡保护符" from player
        set {inv%player%} to player's inventory        clear player's inventory（ps:这里一开始写的时候忘了，后期编辑加进来的格式不对了）

on respawn:
    if {inv%player%} is set:
        if {inv%player%} is not 1:
            set player's inventory to {inv%player%}
            set {inv%player%} to 1



注：不一定保证有效，我电脑打不开1.9.X或更高版，而低版本不支持很多功能，因此无法实测
