介绍 · Introduction

这款插件只用于BungeeCords且需要安装 ChatControl Pro到Bukkit服务器内.
这款插件是用于ChatControl专业版跨服聊天的桥梁.为了节省内存,没有玩家的服务器会被忽略.
安装 · Installation

  • 关闭你的Bungee服务器.
  • 拓展插件到bungee服务器的文件夹内(不是 bukkit!).


特点 · Features
- 跨服显示 加入, 离开 和 切换服务器消息.
- 另外,插件重定向子服间传输的数据. 详情查看ChatControl页面.
新特点: 部分匹配
如果一条来自ChatControl的私聊消息的接收者的名称未能成功匹配,插件就会进行部分匹配. 也就是说如果你在子服输入"/tell arko Hello" ， 插件将自动发送给 "kangarko" 或其他匹配名称的玩家. 匹配按照玩家名的相似度来匹配.
相似度越高,插件发错私聊的概率也就越低. 这个数值可以设置 0.0 到 1.0 (0% 到 100%) 或0来关闭.
名为 pm-partial-match的配置选项的默认数值为 0.40.


权限 · Permissions
chatcontrol.silence.join - 隐藏玩家加入消息.
chatcontrol.silence.leave - 隐藏玩家离开消息.
chatcontrol.silence.switch - 隐藏玩家切换服务器消息.
chatcontrol.bypass.silence.join - 使你可以看到隐藏的加入消息.
chatcontrol.bypass.silence.leave - 使你可以看到隐藏的离开消息.
chatcontrol.bypass.silence.switch - 使你可以看到隐藏的切换服务器消息.
前置 · Requirement
BungeeCords, Java 8 和 ChatControl Pro.
