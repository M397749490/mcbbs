[S]如遇箱子复制物品问题，请暂时禁用箱子生成吧~[/S]

作者出现了！！ 静静等待插件逐步完善吧~
如图所示，玩家死后会在该点自动生成一个墓碑，墓碑上记录着玩家名字，死亡日期，以及生存的时间！ 不仅如此，死后的遗产将以宝箱的形式保存在玩家的墓碑下（可通过config设置修改，默认是这样的），如果禁掉essential的back功能，这样跑尸是不是有几分山口山的感觉~  通过这个插件，玩家能更好的了解自己在游戏里的探（sǐ）险（wáng）经历~

注意！！ 本插件与死亡箱子、拾荒者等一类的插件冲突！
箱子方面还是有点问题
建议暂时关闭 create-buried-inventory-chest 项

现在可通过添加白名单或黑名单来限制对指定玩家的墓碑生成！



配置文件
项目        默认        类型        描述
only-build-grave-on-natural-material        true        boolean        墓碑材料只会覆盖到 "天然" 方块上，比如泥土 沙子 草地 砂砾 地狱石等. 设置为 false 墓碑将覆盖到任何方块上。 感谢 荧惑 纠错！！
enable-fancy-grave        true        boolean        开启 "华丽的墓碑" 后会在墓碑附近添加玫瑰和泥土. 设置为 false 后生成 "普通" 墓碑，只有一个墓碑和牌子
create-buried-inventory-chest        true        boolean        启用后在墓碑下埋葬你的宝箱.如果不想要这功能，设置为 false
display-date-time-of-death        true        boolean        显示玩家死亡时间
fancy-grave-material        dirt        string        华丽墓碑用的材料 默认是泥土
enable-fancy-grave-side-decor        true        boolean        是否添加华丽墓碑两侧的东西
fancy-grave-side-decor        red rose        string        设置华丽墓碑两侧放置的东西
allow-grave-in-normal-world        true        boolean        是否在普通世界启用本功能
allow-grave-in-nether        true        boolean        是否在地狱启用本功能
allow-grave-in-end        true        boolean        是否在终界启用本功能
