e1、如何设置领地？e
/scs help
输入“/res ?”查看全部命令简要说明；
       输入“/res info”可以查看当前领地详细信息；
       输入“/res list”列出自己所拥有的领地；
       输入“/res listall”列出所有领地。
       一、设置领地：
       先用一块木头斧子左键敲击一方块设置点A，右键敲击一方块设置点B（可以输入“/res select size”查看所选区域的大小，注意，你要选的区域是立体的，所以你要左键上角的方块和右键右下角的方块，这样形成一条对角线就能圈住整块区域了）；
       之后输入“/res create 123”（例）这样设置后，就形成了[以AB连线为体对角线的长方体的][名为123的领地（包括A、B所在边），设置一块砖要花费1元。
       二、移除领地：
       输入“/res remove 123”（例）移除名为123的领地，注意，移除领地无法从服务器获得金钱！
       三、领地内权限设置：
       输入“/res set 123 xx true”  （例） 在领地123上打开xx权限  “/res set 123 xx false” （例） 在领地123上关闭xx权限
       权限有：
       　move（移动）；build（改变地形）；place（放置物品）；destroy（破坏）；use（使用）；
       　container（打开箱子）；pvp（玩家伤害）；tp（传送到该领地）；ignite（点火）；
       　firespread（火的传播）；bucket（桶的使用）；flow（后面两个总括）；lavaflow（岩浆流动）；piston 活塞
       　waterflow（水的流动）；creeper（JJ怪爆炸）；tnt（tnt爆炸）；monsters（怪物出生）；
       　animals（动物出生）；subzone（子空间）；healing（治疗）。
       ③true和false是权限状态，若输入true则为开启，false则为关闭。
         
        /res tpset 设定这个领地的传送位置 （前提是权限里面的tp是true的）
      
        四。如何给其他玩家权限
         输入“/res pset 123 xx” （例）在领地123上给 xx玩家权限
       五、子空间设置：
       如同设置领地一样选择区域，不同的是之后输入“/res subzone 123 abc”（例）设置母领地为123的名为abc的子空间，该区域的权限设置和移除则需要将领地名变为123.abc，
       无则默认为当前所处领地（在子空间则为子空间）。
       六、领地信息设置：
       可以设置进出领地时的提示信息，输入“ 123 enter(leave) ABC”（例）设置领地123的进入（离开）时的提示信息为ABC，
       123处不填，则默认为当前所处领地；
       特别地，在提示信息中可以添加：
       %player - 在提示信息中显示进出领地的玩家名
       %owner - 在提示信息中显示领主
       %residence - 在提示信息中显示该领地

2、如何锁箱子？
装了后你放在地上的箱子都会默认锁定为你的，别人打不开
输入任何命令后都要左键一下箱子
/cremove
然后左键点击箱子。
这个命令是取消锁箱子，这样设置后别人可以给你的这个箱子上锁，或者是打烂
使箱子变成共用。之后才能进行下一步设定。
比如，设置私人箱子先/cremove 然后再设定/cprivate [ID1] [ID2]...
/cprivate [ID]
为你自己或多名玩家设置私有箱子
/cmodify[ID1]  [ID2] [ID3] .....
和别的玩家共享这个箱子（记住都要输入命令后左键一下）
/cpublic
设置公共箱子，这样做你的箱子别人无法破坏，也无法设定为自己私有的
/cpassword [密码]
设置密码箱子
解锁时，输入/unlock 你的密码。直到你下线之前，你都不用再输入密码
