会飞的爆炸物

顾名思义，当TNTorCreeper等爆炸后不是将爆炸物给炸消失，而是将爆炸物弄飞至天上！

等于将其飞入天上，并且停留。

图片：



很适合于战争服，小游戏和派系战争！

但是前提开启爆炸！

作者原话:

====== Minecraft plugin version is currently 1.8 ======
====== Works with 1.8 - 1.8.8 ======
Description
When an explosion occurs on your server, instead of having the blocks disappear they will go flying everywhere!
Purpose
This plugin can be used on server ranging from Survival/Factions to Minigames and everything in between. I created this plugin because I think the default explosion in Minecraft is a little on the plain side, and quite frankly boring. Not to mention how every explosion looks alike and have nothing to make itself unique.
