第一章  - 建立一个空白的Mod
大家好，今天我给大家带来基于Forge 1.8.0的 Mod 开发教程。鉴于目前基础教程过多，本教程不会从Java基础讲起，也不会讲解Forge环境搭建。如果没有Java基础，请先看看别的大触的基础教程，再来学习这个。
首先，我们使用的JavaIDE是Eclipe。让我们右击src/main/java —>新建 -->包  创建一个包。

点击 完成 就创建完毕.怎么让Forge识别这个主类？要让Forge识别，需要一段Annotation(注释)。
在
  1. public class RubyMain {
复制代码
上方添加以下代码:
  1. @Mod(modid="rubycraft", name="rubycraft", version="1.0")
复制代码
需要import的类:
  1. net.minecraftforge.fml.common.Mod;
复制代码

@Mod只能存在于类的上方。他的作用就是告诉Forge这是一个Mod的主类。第一个modid是Mod的ID。他将用于材质注册、模型注册等，请保证modid内无特殊符号。name是给玩家看的Mod名字 (不能用中文)，version指本Mod的版本。
之后，我们需要添加Forge的初始化代码：
  1. @EventHandler
  2.         public void preLoad(FMLPreInitializationEvent event)
  3.         {
  4.         }
  5.          
  6.         @EventHandler
  7.         public void load(FMLInitializationEvent event)
  8.         {
  9.         }
  10.          
  11.         @EventHandler
  12.         public void postLoad(FMLPostInitializationEvent event)
  13.         {
  14.         }
复制代码


需要import的类:
  1. net.minecraftforge.fml.common.Mod.EventHandler;
  2. net.minecraftforge.fml.common.event.FMLInitializationEvent;
  3. net.minecraftforge.fml.common.event.FMLPostInitializationEvent;
  4. net.minecraftforge.fml.common.event.FMLPreInitializationEvent;
复制代码
@EventHandler的含义是告诉Forge所有的Mod初始化工作的方法。根据他们的参数类型，Forge会在不同的时间段上调用他们。
FMLPreInitializationEvent 预初始化：
       这个阶段用于进行创建方块、物品，注册等的初始化。
FMLInitializationEvent 初始化：
       这个阶段用于与其他Mod通信。
FMLPostInitializationEvent 初始化以后：
       这个时候因为所有的Mod都载入了，所以这个阶段可以用于对其他Mod的交互准备操作。

  这时，如果没有任何报错的话，那就运行试试吧！

此处atioglxx.dll即AMD系显卡驱动。

参考了一下MCForum和Java.com相关问题，解决方法如下：
1.更新你的显卡驱动
2.缩小运行MC分配的内存（比如分配1024M缩到512M）

注：
2缩小内存需要编辑Eclipse调试的运行变量
