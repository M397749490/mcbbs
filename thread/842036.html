第一条：
命令方块类型：循环 不受制约 保持开启
/execute as @a[name=eloole] run tag @e[type=arrow,nbt={inGround:1b}] add LD
这个是检测玩家然后给所有没落地的箭LD标签


第二条：
命令方块类型：循环 不受制约 保持开启

这个是给所有没有LD标签的箭粒子效果

第一条，前面execute的意义何在。
你的思路比较歪。应该是这样的

pickup 1b的箭可以被玩家捡到，小白的箭为pickup 0b。
那么只要选取所有非落地且有pickup的箭就完事了。

  1. execute as @e[type=minecraft:arrow,nbt={inGround:0b,pickup:1b}] at @s run particle minecraft:angry_villager ~ ~ ~ 0 0 0 1 100 force
复制代码


习惯性的as at连用，其实这样应该也可以。
  1. execute at @e[type=minecraft:arrow,nbt={inGround:0b,pickup:1b}] run particle minecraft:angry_villager ~ ~ ~ 0 0 0 1 100 force
