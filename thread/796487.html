准备：
1.Notepad++（编辑文本），或者其他能编辑文本的工具

2.如图所示的文件夹和文件：（其中的texts文件夹用于装语言文件）

开始：

0.不要忘了添加你的皮肤！
1.用Notepad++打开manifest.json,你将会看到如下所示的文字：
{
    "header":
        {
            "version":[1,0,0],
            "description":"456",
            "name":"2333",
            "uuid":"12345678-90ab-cdef-1234-567890abcdef"
        },
    "modules":
        [
            {
                "version":[1,0,0],
                "description":"456",
                "type":"skin_pack",
                "uuid":"12345678-90ab-cdef-1234-567890abcdef"
                }
            ],
    "format_version":1
}

其中:
version(蓝色字体)后面的参数对应版本号，可以随便改。
desccription(绿色字体)后面的参数对应这个皮肤包的介绍文字，可以随便改。
name(橙色字体)后面的参数对应皮肤包的名称，可以随便改。
type(紫色字体)后面的参数对应该包的类型，比如skin_pack代表皮肤包，所以不能改。
uuid(红色字体)后面的参数对应皮肤包的ID，必须改，否则游戏有可能认不出皮肤包(和其他皮肤包重复)，具体修改的方法是：到这个在线UUID生成器上复制一个船新版本的uuid替换原有的uuid(或者自己编一个)。
修改完毕后记得保存！

2.用Notepad++打开skins.json，你将会看到如下图所示的文字：
{
   "localization_name": "皮肤包",
   "serialize_name": "233",
   "skins":
   [
      {
         "geometry": "geometry.humanoid.custom",
         "localization_name": "steve",
         "texture": "steve.png",
         "type": "free"
      },
      {
         "geometry": "geometry.humanoid.customSlim",
         "localization_name": "alex",
         "texture": "alex.png",
         "type": "free"
      }
   ]
}

其中:
localization_name(红色字体)后面的参数对应该皮肤包的本地名称，很重要，在后面语言文件的编辑中会用到。
serialize_name(橙色字体)后面的参数对应该皮肤包的序列化名称，没啥用，随便改改就好了。
gemoetry(绿色字体)后面的参数对应该皮肤的模型，很重要(对于强迫症)，决定了该皮肤是粗手臂还是细手臂，如果是粗手臂，填写"geometry.humanoid.custom"，如果是细手臂，则填写"geometry.humanoid.customSlim"。注意两者的差别。
localization_name(蓝色字体)后面的参数对应该皮肤的本地名称，很重要，在后面语言文件的编辑中会用到。注意和前面红色字体的差别。
texture(紫色字体)后面的参数对应该皮肤的路径，以skins.json所在的文件夹为基准点。但是由于某种未知原因，将皮肤放在其他文件夹会出错(应该是斜杠没有转义，当时是真的小白)，所以实际上只要填写该皮肤的文件名就好了(必须要带上.png的后缀名)。支持旧版单层皮肤，新版双层皮肤，以及高清（128x128）皮肤。
如何往皮肤包里塞更多的皮肤？只要复制上面黄-底部分的文字并进行粘贴，再修改其中的参数就好了。复制过程中要注意json文件的语法，所以我为不懂的小白做了一个mp4演示(其实我也不是很了解)：点我下载小视频
修改完毕后记得保存！

3.打开Notepad++，新建文件，并在其中输入如图片所示的文字：
skinpack.皮肤包=我的皮肤包
skin.皮肤包.steve=史蒂夫233
skin.皮肤包.alex=艾利克斯233


其中，皮肤包(红色字体)修改为skins.json文件中localization_name（红色）所对应的参数，蓝色字体处修改为skins.json文件中localization_name（蓝色）所对应的参数，第一行必须是
skinpack.localization_name=显示的皮肤包名称

的形式，第二行起是
skin.localization_name.localization_name=显示的皮肤名称

的形式。注意不同的“localization_name”所代表的不同含义！在第一行后，有多少个皮肤就添加多少行，前提是skins.json中有与之对应的项目。确认输入无误后，保存为”.lang“文件。
完成

1.安卓用户将皮肤包放在“根目录\games\com.mojang\skin_packs”内
win10用户请于C盘内搜索“skin_packs”
或者全选文件夹内的文件，压缩成xxx.zip，再把后缀名改为".mcpack"，双击打开(win10)，或者选用minecraft打开(其他平台)

2.打开游戏
