作者: Mars_xiaokai    时间: 2013-6-9 22:48
/res pset XXX move t
res pset XXX build t
res pset XXX use t
res pset XXX container t
或者
/res set move t
res set build t
res set use t
res set container t

set是给全部人权限，pset是给个人权限！
