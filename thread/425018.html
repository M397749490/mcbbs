我翻看了材质包内的一个文件（材质包内     \assets\minecraft\models\block      的文件），发现一段字
{

            "to": [ 32, 32, 32 ],

重点在这一段
"from": [ 0, 0, 0 ],
"to": [ 32, 32, 32 ],

大概意思就是这个方块，他从坐标x0 y0 z0一直延伸到x2 y2 z2（疑似每16为一格）
那么这个方块“的大小”就是2*2（为什么要用双引号？后面会说）
那么我们将这个粉色羊毛（这个文件的名字是粉色羊毛，就是它记录着这个方块）放置在地上
