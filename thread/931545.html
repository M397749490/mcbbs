SellMarket
玩家之间的交易市场

加群了解更多动态: 点我加入QQ群-------------------------------------------------------------------------------------------------------------
功能
-------------------------------------------------------------------------------------------------------------
1.  实现玩家之间物品的出售
2.  实现官方出售商店
3.  支持NBT物品出售


-------------------------------------------------------------------------------------------------------------
使用方法
-------------------------------------------------------------------------------------------------------------
指令 权限 帮助
/sm help 玩家 显示交易市场帮助信息
/sm black OP 将手持物品添加进交易市场黑名单 (玩家将无法上架此物品)
/sm add 玩家 将手持物品上架交易市场
/sm admin <玩家名> OP 将玩家添加为 交易市场管理员 (上架的物品不被消耗)
/sm bill玩家 显示玩家交易记录 (重启清空)
/sm inv 玩家   将玩家背包物品显示在GUI 点击按钮可上架交易市场
/sm ban <玩家名> OP 将玩家加入黑名单 (无法上架，修改商品信息)

如何制作官方出售商店:1. 将你添加进管理名单 /sm admin 你的名字
2.   config.yml:
自定义分类:
  方块: "textures/blocks/brick"
  工具: "textures/items/diamond_pickaxe"
  食物: "textures/items/bread"
  其他: "textures/ui/inventory_icon"
  自定义分类名称: "图片路径"

3. 在adminMenu.yml 里添加分类 添加后，普通玩家无法在此分类上架物品
