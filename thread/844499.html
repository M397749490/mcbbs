作者: hua2hua    时间: 2019-2-17 07:07
你下载的插件有些估计是默认没有权限，
比如打开插件的plugin.yml文件比如下面这个就是地皮的插件默认配置
  1. permissions:
  2.   plots.use:
  3.     default: true
  4.   plots.permpack.basicflags:
  5.     default: op
  6.     children:
  7.       plots.set.flag: true
  8.       plots.flag: true
  9.       plots.flag.add: true
  10.       plots.flag.remove: true
  11.       plots.flag.list: true
  12.       plots.flag.info: true
复制代码
如果把default: true这一条 true改成 op,那玩家就不能使用地皮的默认权限，
