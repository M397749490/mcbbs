进入多世界插件生成的配置文件
打开里面的world.yml
你会在里面看到你服务器里的世界，首先顶上三个都是游戏默认就有的三个世界
多世界插件生成的时候会自动在里面写这三个世界，再往下就是你自己创建的世界了
下面我用world世界做例子：
《《号代表解释
worlds:《《世界列表
  world:《《世界名称
    seed: 2297773948324457982
    environment: NORMAL
    type: NORMAL
    hidden: false
    alias:
      name: ""
      color: WHITE
    pvp: false
    scale: 1.0
    respawnworld: ''
    allowweather: true
    difficulty: DIFFICULT《《更改世界难度，难度要用大写字母，默认是EASY
    animals:
      spawn: true
    monsters:
      spawn: true
    entryfee:
      currency: -1
      price: 0.0
    hunger: true
    autoheal: true
    adjustspawn: true
    portalform: ALL
    gamemode: SURVIVAL
    keepspawninmemory: true
    spawn:
      x: 0.0
      y: 64.0

      yaw: 0.0
