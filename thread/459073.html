简介：
         这款插件非常轻量级
         你可以轻松管理时间（白天，晚上，下雨，晴天等……）
         将下雨天从你的服务器上移除也只是一个简单的命令{:10_565:}，包括每个命令的权限
         以其独特的控制，更没有与其不兼容的插件
         支持1.8/1.7 / 1.6 / 1.5 / 1.4 / 1.3 / 1.2等。
         MultiWorld插件是支持滴






指令以及权限：
                  
指令权限 介绍
/cday [世界] cryweather.day给某个世界设置普通天气
/cnight [世界] cryweather.night给某个世界设置夜晚
/cmorning [世界] cryweather.morning给某个世界设置清晨
/cafternoon [世界] cryweather.afternoon给某个世界设置下午
/cevening [世界] cryweather.evening给某个世界设置午夜
/csun [世界] [持续时间] cryweather.sun设置某个世界晴天的时间
/crain [世界] [持续时间] cryweather.rain设置某个世界下雨的时间
/chelp cryweather.help显示帮助
/cset [世界] [时间-不是持续时间] cryweather.set设置某个世界的时间（雾）
/cweather cryweather.cryweather显示插件版本
/wcnight cryweather.wcday设置全部世界为夜晚
/wcday cryweather.wcnight设置全部世界为普通天气
/wcrain cryweather.wcrain设置全部世界为雨天
/wcsun cryweather.wcsun设置全部世界为晴天
/cEnableRain cryweather.enablerain允许雨天
/cDisableRain cryweather.disablerain禁止雨天




更新：
                  1.支持1.8
              2.可以给服务器去雨
