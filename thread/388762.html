①简介

Customlogin是一款可以替代Customjoin的插件。通过这个插件，你可以方便的自定义服务器玩家登入退出提示消息，或者修改你自己的提示消息！针对特定玩家的提示消息目前还有待开发，等待作者更新中。支持颜色代码！

同样，这款插件我的服建服之初就在用了，没想到论坛里面就然无人转载，今天恰巧碰见一个相关求助者，顺手转了！
关于版本，大家可以下载尝试，我觉得1.6.4-1.7.9应该都可以用，有测试的欢迎反馈给我

②指令

/customlogin - 主要指令
/customlogin help <player|staff|admin> - 帮助指令
/customlogin reload- 重新加载本插件
/customlogin set <prefix|join|quit> - 自定义提示消息
/customlogin setp <prefix|join|quit> - 自定义指定玩家的上下线提示消息 (目前不可用，等待作者更新)

③权限

customlogin.base - 基础指令权限
customlogin.reload - 插件重载指令权限
customlogin.help - 默认帮助指令权限
customlogin.help.staff - 员工（比如管理员/OP/城管）帮助指令权限
customlogin.help.admin - 服主帮助指令权限
customlogin.set.prefix - 自定义提示消息前缀指令权限
customlogin.set.join - 自定义玩家登陆提示消息指令权限
customlogin.set.quit - 自定义玩家退出提示消息指令权限
customlogin.setp.prefix - 自定义指定的玩提示消息前缀指令权限
customlogin.setp.join - 自定义指定的玩家登陆提示消息指令权限
customlogin.setp.quit - 自定义指定的玩家退出提示消息指令权限
