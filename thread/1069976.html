不止是最外面，除了拿 root 权限强行从 kernel 把 pty 抢回来之外别无他法，倒是做好防火墙屏蔽之后 rcon 可以考虑一下
说一下我的想法 nohup screen -dmS mc java -jar paper.jar
第一部分 nohup ，因为 screen 直接接管的是 java ，一旦这个进程没了，在这颗进程树下的一切子进程都会被掐掉，所以最后考虑把重启脚本脱离父进程，直接把管理权交回上级
第二部分 screen 的参数，-d 标记这个窗口启动时直接隐藏，被 nohup 接管的进程没有交互接口，只能无交互方式运行， -m 无视在窗口中的状态，依旧新建窗口， -S 后接一个参数，给窗口命名
第三部分是服务器的启动参数，按照原有脚本调整即可
然后后面的脱离式信号发送可以无视，装x而已，直接 screen -r 上去再 restart 更快
