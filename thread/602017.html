EggDrops is a Bukkit plugin that allows mobs to drop their respective spawn eggs. Everything is fully customizable (See below for more). Although it was built with CB 1.7.9, it is fully compatible with 1.8.

[paper]:配置文件
Config
Default Config

replaceDrops: true   #是否产蛋
dropChance: 50.0    #产蛋的几率50.0就是50% 一半的几率
dropAmount: 1        #每次产蛋的个数
