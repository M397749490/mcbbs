[board]SignBorad


[board]更高端的木牌！


[board]让木牌写上更多的字符！


[board]还可以有更加高端的显示方式！




-------------------------------------------------------------------------------------------------------------------------------------


插件简介:


厌倦了你的木牌上的狭窄空间？现在你可以有多达15行（共600个字符）的文本让你编辑！
虽然牌子上只有四行但是！当你看向牌子的时候你会看到更多！（看到更多你编辑的内容）！
比如为进入RPG房间弄个介绍.................................（脑洞随便开）




-------------------------------------------------------------------------------------------------------------------------------------


设置此插件的牌子：


第一步:为你的牌子想一个名字
第二部:找到你想放置的位置放一个牌子，并在牌子的第一行写上[signboard]

第三部:使用指令/sb board new [boardname]    备注:此处的[boardname]可以自己替换掉你想的名字

第四部:此时你看向这个牌子应该就会显示插件默认设置的内容了

第五部:然后使用指令编辑你创建的board /sb board [boardname] linex [text] 备注:此处的[]内的均可替换，x为行数

到此完成创建..................


-------------------------------------------------------------------------------------------------------------------------------------


此插件的指令大全:


/sb help - Shows plugin description and commands. 列出插件的帮助
/sb howto - Step by step instructions for SignBoard. 创建步骤（应该是）
/sb sign lineX [text] - Edit the sign you're looking at, replacing line 'X' (1-4) with 'text'. 编辑你朝向的木牌内容（1-4行）
/sb board new [boardname] - Create a new board for use in signs. 创建一个新的木牌使用板（英语渣..）
/sb board list - List all your boards. 列出你创建的所有boards
/sb board delete [boardname] - Delete the board named 'boardname'.删除你创建的某个board
/sb board rename [boardname] [newname] - Rename board 'boardname' to 'newname'.重新命名你创建的某个board
/sb board [boardname] lineX [text] - Edit line 'X' on 'boardname', replacing it with 'text'. 编辑你创建的某个board
