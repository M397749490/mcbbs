= = = = 插件介绍 = = = =
FastRespawn —— 死亡自动重生，你死亡的时候，会自动在复活点复活{如果你有权限}
= = = = 功能 = = = =
配置文件!(√)
重新加载命令!(√)
设置重生时间(√)
设置重生后的血量!(√)
您可以启用/禁用死亡自动重生(√)
设置达到重生后的饱食度(√)
您可以启用/禁用玩家掉落时死亡(√)
= = = = 命令 = = = =
/fastrespawn reload          用于重新加载配置
= = = = 权限 = = = =
fastrespawn.use      死亡自动重生【玩家默认拥有】
fastrespawn.reload    使用/fastrespawn reload 指令权限
= = = = 配置 = = = =
enable-fast-respawn: true  ---是否开启自动重生
food-level-at-respawn: 20 ---重生后的饱食度
hearts-at-respawn: 20 ---重生后的血量
no-drops-on-death: false ---开启/关闭掉落死亡
time-of-respawn: 0.2 ---自动重生时间{默认为0.2秒}
