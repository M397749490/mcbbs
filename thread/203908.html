把该权限的权限码添加到默认的用户组【就是普通玩家的的用户组】即可

mangaddp [名字] [权限]     
给组添加某某权限
/manglistp [名字]   
列出某个组的权限
/mangdelp [名字] 权限   
删除某组的某权限
/manuadd [玩家ID] [名字]      
将用户添加到组
/manuaddp    [玩家ID]   [名字]      
给用户权限
/manudelp [玩家ID]   [名字]      
删除用户权限
default      新玩家
builder      正式玩家
moderator 低级管理
admin        OP
owner       腐竹



如有错请纠正！勿喷！
