For Minecraft 1.0.0 (Single Player)
Version 0.6.1
Requires: ModLoader (1.0.0)

四季Mod
SeasonCraftory is an optional mod that adds the four seasons to Minecraft. This mod is able work on its own, but if you use it with RuneCraftory, it adds a whole new experience by dividing up the different seeds you can plant according to which season it currently is.
四季Mod是一个给minecraft增加四个季节的Mod。 但是这个Mod主要是可以为 牧场物语Mod增加更多的可玩性。




The 4 Seasons四季
Spring
春季

The green season. Lasts seven Minecraft days by default. Rains frequently. If using with RuneCraftory, you can find the following seeds in tallgrass: Pink Turnip, Cabbage, Onion, and Strawberry.
绿色的季节，春季会在游戏中持续七天的时间，这个季节经常下雨。
如果同时使用牧场物语Mod，你可以在高草中找到一下几种种子：
芜菁，包菜，洋葱，和草莓







Summer
夏季

The darker green season. Lasts seven Minecraft days by default. Always has thunderstorms. If using with RuneCraftory, you can find the following seeds in tallgrass: Cucumber, Tomato, Corn, Eggplant, and Pineapple.
深绿色的季节，夏季会在游戏中同样持续七天的时间，但是夏季会经常下雷雨。
如果同时使用牧场物语Mod，你可以在高草中找到一下几种种子：
黄瓜，西红柿，玉米，茄子，菠萝






Autumn
秋季

The multicolor season. Lasts seven Minecraft days by default. Weather is normal. If using with RuneCraftory, you can find the following seeds in tallgrass: Potato, Carrot, Yam, Spinach, and Green Pepper.
多彩的季节，秋季在游戏中同样会持续七天的时间，一直正常的天气。
如果同时使用牧场物语Mod，你可以在高草中找到一下几种种子：
土豆，萝卜，甘薯，菠菜，和青椒





Winter
冬季

The snowy season. Lasts seven Minecraft days by default. Snow is frequent but not constant. If using with RuneCraftory, you can find the following seeds in tallgrass: Turnip, Leek, Daikon Radish, and White Cabbage.
下雪的季节，同样会持续七天的时间。会经常下雪。
如果同时使用牧场物语Mod，你可以在高草中找到一下几种种子：
萝卜，韭葱，大根，包心菜





安装：
1. 下载SeasonCraftory0.6.1.zip
2. 解压后所有文件拖入jar
3. have fun 玩吧！
