如果没有基本知识请到这里学习：http://www.mcbbs.net/forum.php?mod=viewthread&tid=492211
前言:
   大概一年多前，我发现了skript，惊讶于他的简单明了，不需要java编程知识就可以让自己的服务器实现无限可能，开始我从最简单的命令开时。随着时间的推移，编辑的脚步越来越复杂，数据量也越来越大，sk原版的数据存储已经不适合了，经常发生数据错误或者丢失的情况，我开始在skunity寻找可以实现高速安全的存储方法，我发现了这个(https://forums.skunity.com/t/myskq-mysql-simplified/3624) 在测试中他工作的非常好, 但是他缺少一些必要的功能比如，多表支持等等。
所以我决定基于自己开发一套API，其中也借鉴不少别人的代码。
支持:
● 简单直观的数据库访问
● 多数据表支持
● 可以在mysql存储多个变量列表
● 存储一个SQL变量/ SQL表变量的值
● 得到的值从SQL变量/ SQL表变量
● 如果检查SQL变量/ SQL表变量设置
● 检查如果一个SQL表变量包含一个值
● 添加一个值到一个SQL表变量
● 从列表中删除SQL变量值
● 删除SQL变量/ SQL表变量
● 许多例子和解释变量存储不同种类的skript
● 不同种类的变量分类存储
● 可以随时通过数据库管理软件查看变量
要求:
● Spigot 版本 “1.10.2” (在1.10.2上面测试的也可能支持1.8和1.9)
● Skript 版本 “dev-20b” by bensku or higher
● SkQuery1 版本 “May-2016” by gatt
● 可选: skUtilities 版本 ”0.7.4” 或更高版本
● 可选 SkRayFall v版本 “1.9.5” 或更高版本
● 一个数据库，包括数据库名字，密码
安装:
警告: 请按照步骤一点一点来，否则会导致错误!
1)下载安装Spigot, Skript, SkQuery 和 skUtilities. (重启服务器)
2) 前往 /plugins/Skript/config.sk. 设置 “player variable fix” 为 true 设置 “use player UUIDs in variable names”为 false.
3)设置“case sensitive” 在config.sk为 false
4) 将databases设置为下面这样子
  1. # ==== Variables ====
  2. databases:
  3.         default:
  4.                 type: CSV
  5.                 pattern: .*
  6.                 file: ./plugins/Skript/variables.csv
  7.                 backup interval: 2 hours
复制代码
5) 重启服务器
6)下载SQLSuite.rar file, 解压以后所有文件放入: /plugins/Skript/scripts/
7) 创建一个数据库
8) 打开 SQLSuiteDB.sk, 在80行处设置数据库信息.
9) 重新启动服务器，如果你没有任何错误，说明安装成功，可以用sql语法测试连接是否正常。
SQLSuite的语法:
存储和操作变量（前提是你懂sk基本知识）
  1. set sqlvar "examplevariable" stored at "Testtable" to "example value"
  2. add "example value" to sql list var "ExampleList" stored at "Testtable"
  3. remove "example value" from sql list var "ExampleList" stored at "Testtable"
复制代码
读取变量（前提是你懂sk基本知识）
  1. set {_singlevalue} to value of sql var "ExampleVariable" stored at "Testtable"
  2. set {_listvalues::*} to value of sql list var "ExampleList" stored at "Testtable"
  3. if sql list var "ExampleList" stored at "Testtable" contains "example value"
  4. if sql list var "ExampleList" stored at "Testtable" does not contain "example value"
复制代码
 检查变量是否存在（前提是你懂sk基本知识）
  1. if sql var "ExampleVariable" stored at "Testtable" exists
  2. if sql var "ExampleVariable" stored at "Testtable" is set
  3. if sql var "ExampleVariable" stored at "Testtable" does not exist
  4. if sql var "ExampleVariable" stored at "Testtable" is not set
复制代码
删除变量（前提是你懂sk基本知识）
  1. delete sql var "ExampleVariable" stored at "Testtable"
复制代码
转换数据类型到MySQL:
Numbers:
  保存numbers类型:
  1. set {_testnumber} to 4set sql var "savednumber" stored at "Testtable" to "%{_testnumber}%"
复制代码
  使保存的number再次使用:
  1. set {_stringnumber} to value of sql var "savednumber" stored at "Testtable"
复制代码
Time/Date 变量 (需要skUtilities):
  保存当前时间和日期到SQL数据库:
  1. set {_currenttime} to convert date now to unixset sql var "ExampleVariable" stored at "Testtable" to "%{_currenttime}%"
复制代码
  读取 time / date 到变量:
  1. set {_stringtime} to value of sql var "ExampleVariable" stored at "Testtable"
  2. set {_stringtimenumber} to {_stringtime} parsed as number
  3. set {_RestoredDate} to convert unix {_stringtimenumber} to datemessage "&aSaved time / date: &e%{_RestoredDate}%"
复制代码
坐标 (传送等需要用):
  设置变量为当前的位置:
  1. set {_temppoint} to sqllocation of player "%player%"
  2. set sql var "ExampleTpPoint" stored at "Testtable" to "%{_temppoint}%"
复制代码
  传送到保存的坐标:
  1. teleport player to sqllocation "ExampleTpPoint" stored at "Testtable"
复制代码
  获取传送点的详情:
  1. set {_x} to sqllocation-x of "ExampleTpPoint" stored at "Testtable"
  2. set {_y} to sqllocation-y of "ExampleTpPoint" stored at "Testtable"
  3. set {_z} to sqllocation-z of "ExampleTpPoint" stored at "Testtable"
  4. set {_yaw} to sqllocation-yaw of "ExampleTpPoint" stored at "Testtable"
  5. set {_pitch} to sqllocation-pitch of "ExampleTpPoint" stored at "Testtable"
  6. set {_world} to sqllocation-world of "ExampleTpPoint" stored at "Testtable"
复制代码

重要信息:
1) 因为SkQuery’s SQL f函数只保存字符串其他类型的都会强制转换为字符串，这个API没有这个问题，但是除了number，time/date,loction以外的数据类型     还是需要转换。
2) 请不要使用 "< none >" 和",||-|-||," 在变量名字中，他会破坏一些已有的功能。
