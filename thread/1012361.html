添加自定义音效
  • 在资源包\assets\minecraft下新建名为sounds，后缀为json的文本，并打开，输入如下
    1. {
    2.     "ouo.s1": {
    3.         "sounds": [
    4.             {
    5.                 "name": "custom/sound1",
    6.                 "stream": true
    7.             }
    8.         ]
    9.     },
    10.     "ouo.s2": {
    11.         "sounds": [
    12.             {
    13.                 "name": "custom/sound2",
    14.                 "stream": true
    15.             }
    16.         ]
    17.     },
    18.     "ouo.s3": {
    19.         "sounds": [
    20.             {
    21.                 "name": "custom/sound3",
    22.                 "stream": true
    23.             }
    24.         ]
    25.     }
    26. }
    复制代码

  • 在资源包\assets\minecraft下新建文件夹sounds，并打开
  • 新建文件夹custom，并打开
  • 分别放入ogg格式的音频文件sound1、sound2、sound3
    如果是较长的音频文件，stream处设为true
    1.11前的playsound格式：
    1. /playsound ouo.s2 @p
    复制代码
    1.11起的playsound格式：
    1. /playsound ouo.s2 music @p
    复制代码


背景音乐的话在sounds.json中的背景音频事件(music.game)下新增音频路径
估计你还是会回来问，我把在已有音频事件中添加额外播放项的方法给写上

在上面提到的sounds.json中添加这么一段，比如
  1. {
  2.         "music.game": {
  3.                 "replace":"false",
  4.                 "sounds": [{
  5.                         "name": "custom/bgm",
  6.                         "stream": true
  7.                 }]
  8.         },
  9.         "ouo.s1": {
  10.                 "sounds": [{
  11.                         "name": "custom/sound1",
  12.                         "stream": true
  13.                 }]
  14.         }
  15. }
复制代码

其中的replace是关键，false代表添加到原有列表，true则代表替换原有列表。

上面提到的可以说是两种不同的方案
前者多用于地图制作中，在特定时刻播放
后者则偏向于满足玩家对背景音乐的多样性要求
