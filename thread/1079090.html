个别系统解释：
*怪物血量显示
其实主要难的地方就是这个json（[{"score":{"objective":"hp","name":"@s"}},{"score":{"objective":"hp_max","name":"@s"}}]中的hp_max和hp分别代表额定血量和实际血量）
(貌似MCBBS的代码文本会吞Tab，所以直接打到普通文本里了w)
{
  "type": "minecraft:generic",
  "pools": [
      {
          "rolls": 1,
          "entries": [
              {
                  "type": "minecraft:item",
                  "name": "minecraft:saddle",
                  "functions":[
                      {
                          "function":"minecraft:set_name",
                          "name": {"text":"","color":"red","italic":false,"extra":[{"score":{"objective":"hp","name":"@s"}},{"text":"/","color":"white"},{"score":{"objective":"hp_max","name":"@s"}}]},
                          "entity": "this"
                      }
                  ]
              }
          ]
      }
   ]
}


然后只要把这个战利品json给敌人头上放置
  1. loot replace entity @s armor.head loot .system:enemy_hp
复制代码
然后用data modify使敌人自己的CustomName改为头上物品的名称就行了
  1. data modify entity @s CustomName set from entity @s ArmorItems[3].tag.display.Name
复制代码
（还要把CustomNameVisible设为1b）

为了防止过于卡顿，我把loot replace和data modify放到了一个function里面
然后循环执行下面的指令就可以显示血量了w/（最好是设一个计时器之类的，不然实体过多会导致占用资源过多！）
  1. execute as @e[tag=enemy] at @s run function .system:display/enemy_hp/display
复制代码
