注意：本插件需要配合贴图使用，否则您可能无法看见界面。

这是什么插件？

本插件内置了一张日历，玩家可以在日历上签到，查看过去的签到记录，以及领取累计签到的奖励。

插件特性：
  • 支持文件保存和MySQL数据库保存。
  • 支持每月和每周累计签到奖励。
  • 您可以浏览签到历史，浏览任意日期。
  • 兼容Lunar插件，可以在日历中显示农历日期

即将加入：
  • PlaceholderAPI变量支持

签到规则如下：
  • 如果错过了某一天的签到，您可以使用补签卡进行补签。
  • 补签时如果达成累计条件，您同样可以获取奖励。
  • 奖励分为每周累计和每月累计，每周累计从周日开始计算，到了下一个周日重置；每月累计从每月1号开始计算，到下月1号重置。
  • 补签只能在每周或每月的这一周期进行。例如，您补签一个星期以前的日期，如果补签日期是上个月，则无法完成补签，如果是这个月，则只会补签每月累计。同样，如果您补签上个月的日期，如果补签日期不是这个星期，也无法完成补签。如果今天是星期天，那么昨天（星期六）则属于上一周。

如何使用？

插件命令：
/calendar - 打开签到界面
/calendar reload - 重载插件
/calendar give [玩家] - 给予玩家补签卡

插件权限：
calendar.admin - 重载插件和给予补签卡权限

配置文件：

  1. #选择语言
  2. language: zh_cn
  3. #选择数据库类型FILE或者MYSQL
  4. database: file
  5. #配置MYSQL
  6. mysql:
  7.   host: localhost
  8.   port: 3306
  9.   user: root
  10.   password: password
  11.   database: calendar
  12. #签到命令设置
  13. commands:
  14.   #每一次签到都会执行的命令，[CONSOLE]为后台执行
  15.   daily:
  16.     - "[CONSOLE]eco give %player% 100"
  17.   #每个星期（从周日开始）累计签到执行的命令
  18.   week:
  19.     #累计签到7次
  20.     7:
  21.     - "[CONSOLE]give %player% apple 1"
  22.   #每个月（从1号开始）累计签到执行的命令
  23.   month:
  24.     #累计签到28次
  25.     28:
  26.     - "[CONSOLE]give %player% diamond 1"
  27. #日历日期格式
  28. date_format: "yyyy年M月d日"
  29. #日历年月选择器格式
  30. month_format: "yyyy年M月"
  31. #补签卡
  32. replenish_card:
  33.   #补签卡显示名
  34.   name: "&6&l补签卡"
  35.   #补签卡材料
  36.   material: NAME_TAG
  37.   #补签卡数据值
  38.   data: 0
  39.   #补签卡lore
  40.   lore:
  41.   - "&a右键打开签到界面"
  42.   - "&a每补签一次消耗一张补签卡"
  43. #进服后是否自动打开GUI，是为true，否为false
  44. open_gui_on_join: true
