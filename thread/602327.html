介绍：
这是一个sponge端用的登陆插件，可用于高版本MOD服

指令：
  1. 玩家命令:
  2. /reg /register <password> <password> - 使用密码进行注册
  3. /register - 使用TOTP生成密码
  4. /changepw /cp /changepassword <password> <password> - 更改当前密码
  5. /log /l /login <password|code> - 使用密码或验证码登录
  6. /logout - 登出
  7. /mail /setemail - 设置邮箱地址
  8. /forgot /forgotpassword - 发送忘记密码邮件
  9. /unregister <uuid|name> - 删除账户

  11. 管理员命令:
  12. /fl <reload|rl> - 重载配置文件
  13. /fl forcelogin <name> - 强制登录一个玩家
  14. /fl <accounts|acc> <name|ip> - 获取用户账号列表
  15. /fl <unregister|unreg> <name|uuid|--all> - 删除用户
  16. /fl <register|reg> <name|uuid> <pass> - 注册一个用户
  17. /fl <resetpw|resetpassword> <name> - 给用户设置新的密码
复制代码

权限：
  1. flexiblelogin.admin - 管理员权限
  2. flexiblelogin.command.login - 使用 /login 命令
  3. flexiblelogin.command.logout - 使用 /logout 命令
  4. flexiblelogin.command.changepw - 使用 /changepassword 命令
  5. flexiblelogin.command.register - 使用 /register 命令
  6. flexiblelogin.command.mail - 使用 /setemail 命令
  7. flexiblelogin.command.forgot - 使用 /forgot 命令
  8. flexiblelogin.no_auto_login - 拥有此权限的玩家无法使用自动登录的功能
  9. flexiblelogin.bypass - 拥有此权限的玩家可以跳过登录
