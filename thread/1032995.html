开服器问题很多还是不要用了= =

@echo off
set restart=0
:restart
set server_name=你服务器的名字（随便填就好了）
title %server_name% 重启次数%restart%次
java -Xms【x】G -Xmx【y】G  -jar 核心名.jar
timeout /t 5 /NOBREAK
set/a restart=restart+1
goto restart

这就是最简单的，x建议是1，y就是你机器运存减去2的数值，核心名字就是例如spigot这种对，那个根目录下的java文件
