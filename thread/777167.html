ArenaCommand



插件简介:

玩家进入某个区域时

玩家/服务端自动运行某个指令


可以用来做什么？

>RPG服进入某个区域后的传送<

>所有服务器的区域的欢迎标语<

>每一块区域的的BGM<

>还有更多....<

未来计划:
>重写整个指令构造<
>创建区域时添加粒子效果<


新更新:使用/ac command <区域名字> add [leave]say xxx xxx xx

在添加的指令前加上[leave]可设置为离开区域时执行的指令

该指令只可为单条指令且不可循环！
因为没必要我觉得


以下是插件介绍:

复制代码

权限:
  1.     ArenaCommand.Arena --区域管理 默认op
  2.     ArenaCommand.Command --指令管理 默认op
  3.     ArenaCommand.Admin --插件管理 默认op
复制代码

-----------------------------------------------------------------

使用教程:
首先，随便找个地方输入/ac arena create <区域名字>
接下来跟着提示分别右键点击左下角和右上角

设置好两个角后，区域就创建完成了。
接下来为这个区域绑定指令
/ac command <区域名字> add <指令>
这个指令默认为玩家进入区域后自动输入的
在指令前加上~可改为系统后台输入
如:ac command golobby add ~spawn %player%      %player%会自动更改为进入区域的玩家的名字
在指令前加上！可改为跨权限输入
如:ac command xxx add ~spawn %player%

当看到以下提示出现后代表指令绑定成功了

这时当玩家进入区域时，就会自行使用命令了！
教程结束
（还有其他的命令可自行探索使用）

----------------------------------------------------------------
目前可用变量:
%player%:玩家名字
%locx%:玩家x坐标
%locy%:玩家y坐标
%locz%:玩家z坐标
