◆介绍◆
TNTBlockDamage is a plugin that takes the blocks affected by TNT and throws it into the air, along with a gravity effect so they fall back down!
这个插件有这种功能：受到TNT爆炸冲击的方块会被炸飞，然后掉下来。
（牛顿：这插件真不错）

DOES NOT WORK WITH Ultimate Cosmetics
不支持Ultimate Cosmetics

This plugin supports any version above 1.8! This includes 1.13 and any future versions. I just have not updated the graphics yet.
这个插件是可以支持1.8以上的版本的，包括1.13或者最新版。作者只是还没更新相关图形（应该是这么翻译的吧）

安装：
1.下载插件（地址在上面）
2.把插件扔进plugins文件夹
3.重启服务器
4.使用插件
5.别忘了给作者5星好评（请一次性付清）
提示：不要太作，点燃一堆TNT（插件仅供娱乐用）
          TNT仍然有破坏性，谨慎使用
命令/权限
命令:
/tnt (点燃一个TNT)

权限：
tntblockdamage.firetnt
