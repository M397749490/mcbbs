标题: 时装工坊怎么支持MOD里的装备
时装没法给MOD里的装备用，有解决方法吗
作者: 二哈大魔王    时间: 2020-8-14 22:12
找到时装工坊配置文件
.minecraft\config\armourers_workshop\overrides.cfg

拉倒最下面 添加即可
  1. ##########################################################################################################
  2. # overrides
  3. #--------------------------------------------------------------------------------------------------------#
  4. # Custom list of items that can be skinned.
  5. # Format [override type:mod id:item name]
  6. # Valid override types are: sword, shield, bow, pickaxe, axe, shovel, hoe and item
  7. # example sword:minecraft:iron_sword
  8. ##########################################################################################################

  10. overrides {
  11.     S:itemOverrides <
  12.      >
  13. }
复制代码


sword:minecraft:iron_sword 这是例子 前面sword是类型 后面是mod装备的ID
