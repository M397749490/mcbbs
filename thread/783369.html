①土豆的教程好像也有一些过时的了(没办法exe改得次数太多了)，可以反复看 minecraft-zh.gamepedia.com/1.13 里的有关描述
②我有一个比较笨的方法，先用execute store result score @p xxx run data get entity ooo Rotation[0] 1000，然后再把其储存到AMS的nbt里。不知道有没有更好的方法
③/execute positioned as @e[type=armor_stand] run tp ^ ^ ^0.01
这里是把tp命令以盔甲架的坐标执行，tp命令的执行者并不明确(实际上tp命令的执行者是一个在出生点区块的虚拟的东西，这条命令相当于在传送那个虚拟的东西到盔甲架的面前，所以什么也没有发生)。
/execute at @e[type=armor_stand] as @s run teleport ~ ~ ~0.01
这条命令把teleport命令以盔甲架的位置执行，但后面as @s中的@s实际指代的还是那个虚拟的执行者。
因此做一个小小的总结：不管是positioned as还是at，都只改变了命令执行的位置，执行者仍然是那个“虚拟的执行者”
④execute as @p at @s run tp @s ^ ^ ^0.01
这条命令，先是as再是at，也就是以玩家的身份，在玩家的位置，执行tp
与你上面的区别便是这个先用as明确指定了执行者是玩家，而上面没有指定执行者，执行者是那个“虚拟的东西”
⑤execute as @p at @s anchored eyes run teleport ^ ^ ^0.01
这条，先ass后at，以玩家的身份，玩家的位置执行后面的命令。唯一的不同是anchored把该命令执行的位置改到了玩家的眼睛的位置。事实上命令默认是以脚的位置执行，以眼睛的位置执行就会造成向上的偏移，使得玩家一直往上走。
execute as @p at @s anchored eyes rotated ~ 0 run teleport ^ ^ ^0.01
跟上面一样的～

②positioned as与at有什么区别？
at包含维度、旋转方向、坐标，positioned as只包含坐标，rotated as只包含旋转方向，in (overworld|the_end|the_nether)只包含维度。（然而没有类似in as什么的东西…）
