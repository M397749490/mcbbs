龙之研究有自己合成修改方法
打开.minecraft\config\brandon3055\Custom Fusion Recipe Info.txt
内有详细介绍
为确保你做的修改进游戏不出现在聚合器里看不到物品材质问题，我简单给个例子，因为它对有：1这种物品写法很莫名
首先在brandon3055内创建个Custom Fusion Recipe.json文本
  1. [
  2.         {
  3.             "mode": "ADD",
  4.                 "result": "actuallyadditions:item_crystal_empowered",
  5.                 "catalyst": "actuallyadditions:item_crystal",
  6.                 "energy": 200000,
  7.                 "tier": 2 ,这里代表等级
  8.                 "ingredients": [
  9.                     "tconstruct:ingots,1,1",这里的,1,1前面的一为数量，后面的1为物品ID
  10.                         "minecraft:dye,1,1",
  11.                         "extrautils2:ingredients"
  12.                 ]
  13.         },
  14.         {
  15.            "mode": "REMOVE",
  16.            "result": "draconicevolution:draconic_staff_of_power",
  17.            "catalyst": "draconicevolution:draconic_pick",
  18.            "ingredients": [
  19.                  "draconicevolution:draconic_ingot",
  20.                  "draconicevolution:draconic_ingot",
  21.                  "draconicevolution:draconic_ingot",
  22.                 "draconicevolution:draconic_ingot",
  23.                 "draconicevolution:draconic_ingot",
  24.                 "draconicevolution:draconic_shovel",
  25.                 "draconicevolution:draconic_sword",
  26.                "draconicevolution:awakened_core"
  27.          ]
  28.     }
  29. ]
复制代码

物品ID不要用tconstruct:ingots:1或者"[tconstruct:ingots]:1"
这种方法来写，会有一些物品显示不出材质
