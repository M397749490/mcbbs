这个问题是末影接口Mod引起的，似乎是它的配方加载出错。
崩溃报告包含了这样一段内容，你可以按照它说的做，试试看。
  1. Note: To start the game anyway, you can disable recipe loading in the
  2. Ender IO config file. However, then all of Ender IO's crafting recipes
  3. will be missing.
复制代码

翻译过来是，如果你一定要启动游戏，可以在末影接口的config文件中，
禁用它的配方加载（recipe loading）。
然而，所有末影接口所有的合成配方都会丢失。
