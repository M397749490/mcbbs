高度自定义的贴图
DMI，作为高度自定义的贴图，致力于解决目前贴图样式单一的情况
你可以自行设计，移动文本，添加变量，制作插件~最后就是一个你的贴图
由于自定义内容过多，关于自定义教程，还请移步https://github.com/Mohist-Community/DiyMagicImage/wiki

优点
DMI完全免费，仅仅接受无偿赞助！
DMI完全没有广告，也完全没有访问限制。
DMI高度自定义，社区提供较多的模板以供选用
模板简单，便于设计，提供调试面板

将要完成
使用拖放布局，设计更方便
添加模板市场，用户可以发布模板
添加字体市场，选择免费公共字体

安装DiyMagicImage（用户可跳过此步骤）
1.将github clone至网站目录
2.修改网站根目录（宝塔称 运行目录）到./public
3.运行composer install
          cp .env.example .env
4.在.env内修改数据库连接方式，网站名称，recaptcha密钥
5.运行php artisan key:generate
          php artisan migrate

插件列表
以下为目前支持的插件列表（DMI可以引入的变量）


View:提供访问量的显示
https://github.com/Mohist-Community/DiyMagicImage/tree/master/app/Plugin/View

Github:提供Github诸如star数,last commit之类的信息
https://github.com/Mohist-Community/DiyMagicImage/tree/master/app/Plugin/Github

Html:将html(含变量)作为输入,转换为图片后输出（不稳定，不建议使用过多）
https://github.com/Mohist-Community/DiyMagicImage/tree/master/app/Plugin/Html

Mcstatus:提供MC服务器运行状态的相关信息
https://github.com/Mohist-Community/DiyMagicImage/tree/master/app/Plugin/Mcstatus

Svg:提供svg输入并输出为图片
https://github.com/Mohist-Community/DiyMagicImage/tree/master/app/Plugin/Svg

Time:将时间以指定格式输出
https://github.com/Mohist-Community/DiyMagicImage/tree/master/app/Plugin/Time

UA:提供User-agent获取到的信息及ip获取到的位置信息(处于隐私考虑不展示ip)
https://github.com/Mohist-Community/DiyMagicImage/tree/master/app/Plugin/UA

网站截图

插件列表
Html：将html编译为png作为图像变量提供添加到贴图
Mcstatus：我的世界服务器状态输出为文本变量，icon输出为图像变量
Time：将指定格式的时间输出为文本变量
UA：将用户浏览器信息解析并作为文本变量，如浏览器，ip解析
View：将贴图访问次数作为文本变量输出
