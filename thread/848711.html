介绍 · Introduction
LotteryPool可以通过让玩家花费参加定时抽奖让你更好地管理你服务器的经济
前置 · Requirements
  • Vault
  • 任何经济插件
如何使用
玩家可以在抽奖开始时看到bossbar的消息并输入指令参与抽奖

指令 & 权限
/lpl - 打开抽奖菜单.

(用户默认拥有权限)



二级指令:
/lpl pool - 打开奖池菜单.
(用户默认拥有权限)

/lpl player - 打开玩家菜单
(用户默认拥有权限)

管理员指令:
(以下指令需权限才可使用)


/lpl admin addpool - 给抽奖池添加奖金
(lp.admin)

/lpl admin removepool - 减少奖池中的奖金
(lp.admin)

/lpl admin forcestart - 强制开始抽奖
- 可能会导致bossbar的一些问题.
谨慎使用.
(lp.admin)

/lpl admin reload - 重载插件.
(lp.reload)

占位符
  • %player% - 文件名
  • %players% - 参与抽奖的玩家数. (用在bossbar)
  • %amount% -奖金数.

  • %taxamount% - 显示彩·票税.
  • %time% - 抽奖持续时间.
  • %totaltime% - 下一场抽奖开始的时间.
