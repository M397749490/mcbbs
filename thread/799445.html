Gui Creation Tool
GUI制作工具
Gui Creation Tool
授权搬运

支持主流菜单/商店插件的GUI创建
使用Gui Creation Tool能节省你手动写物品排布配置的时间
Gui Creation Tool支持以下插件的GUI排布创建：
  • BossShop / BossShopPRO
  • CrazyCrates
  • DeluxeMenus
  • Essentials
  • ShopGui+
  • ChestCommands
  • SuperLobbyDeluxe
  • AutoChestSeller
  • ItemShops
  • aSkyBlock
  • CratesPlus

指令
/GuiCreate 打开一个GUI设置，但没有指定生成哪款插件的排布配置，起到暂存作用，关闭后再次打开可出现关闭前的暂存排布
/GuiCreate Create <插件名> 创建暂存中的物品排布配置
/GuiCreate list 列出Gui Creation Tool支持的插件的名称

权限
guicreate.use 可使用主命令/GuiCreate
