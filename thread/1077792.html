首先，请先理解一个基本知识点：
插件加载之后，主类有且仅有一个实例。
道理非常简单，如果有多个实例，势必导致onEnable多次被调用
那么任务调度、事件监听都会被重复注册
这会带来不可预知的非常非常非常严重的冲突！
我们所有通过ClassLoader强行创造主类实例的各种方法全部都是开玩笑！
除非你很有把握且经过深思熟虑，否则不要自己新建主类的实例！
而且我也不认为有什么常见的使用场景会需要多个主类实例的！
至于主类是如何只有一个实例的，JavaPlugin（也就是主类继承的那个类）
通过使用PluginClassLoader加载主类限制主类拥有多个实例
具体的单例化实现方法没什么太大必要去理解，懂的都会自己去看底层

  2.   public JavaPlugin() {
  3.     ClassLoader classLoader = getClass().getClassLoader();
  4.     if (!(classLoader instanceof PluginClassLoader))
  5.       throw new IllegalStateException("JavaPlugin requires " + PluginClassLoader.class.getName());

防止重复加载主类的实例

重点知识总结如下：
1.同一个插件有且仅有一个主类的实例
2.自己不要新建主类实例（例如new Main() )

正题：如何获取主类实例？

第一种方法：静态变量储存主类实例
静态变量是什么？上网搜索你可以得到很多相关的解释
简单地认为，任何地方调用这个静态变量会得到同一个值，它独立于类的实例而存在
那么主类有且仅有一个实例
此时我们就可以在主类直接声明一个静态变量
那么这个静态变量储存了类的那一个唯一的实例
当在onEnable里把这唯一的实例赋值给这一变量的时候
这个变量就存储了那个实例且保持不变


  3.         public static JavaPlugin plugin;

  5.         @Override
  6.            public void onEnable() {
  7.                 plugin = this;
  8.         }
复制代码

其他类里面通过 Main.plugin 就可以得到实例了（Main是主类名字，你可以改成自己的）
比如说Main.plugin.getLogger()

第二种方法：PluginManager获取
既然Bukkit本身能知道你的插件是不是被重复加载
并且在你试着自己new一个主类实例时抛出异常
（其他还有大量例证不一一举出）
那么Bukkit一定存储了你的主类的实例
该怎么访问呢？
https://bukkit.windit.net/javado ... n-java.lang.String-
这样就可以通过你在plugin.yml里写的name，插件的名字来得到主类实例
比如说Bukkit.getPluginManager().getPlugin("PVPINDemoRL")

第三种方法：JavaPlugin静态方法直接获取

  2.   @NotNull
  3.   public static <T extends JavaPlugin> T getPlugin(@NotNull Class<T> clazz) {
  4.     Validate.notNull(clazz, "Null class cannot have a plugin");
  5.     if (!JavaPlugin.class.isAssignableFrom(clazz))
  6.       throw new IllegalArgumentException(clazz + " does not extend " + JavaPlugin.class);
  7.     ClassLoader cl = clazz.getClassLoader();
  8.     if (!(cl instanceof PluginClassLoader))
  9.       throw new IllegalArgumentException(clazz + " is not initialized by " + PluginClassLoader.class);
  10.     JavaPlugin plugin = ((PluginClassLoader)cl).plugin;
  11.     if (plugin == null)
  12.       throw new IllegalStateException("Cannot get plugin for " + clazz + " from a static initializer");
  13.     return clazz.cast(plugin);
  14.   }
复制代码

对于新手可能难以理解，看不懂的没有关系
具体使用方法在https://bukkit.windit.net/javado ... in-java.lang.Class-
传入的参数是主类这个类本身
还有一个https://bukkit.windit.net/javado ... in-java.lang.Class-
但是要求这个类的类加载器必须是PluginClassLoader才可以访问到主类实例

第四种方法：构造函数
构造函数法可能不是很方便，演示尤其麻烦，我很怕有人不会Java，改了改类名就和我说代码用不了
基本上来说就是你可以在某个类里写一个变量存储主类的实例
这个变量何处赋值？使用构造器
但是构造器的名称与类的名称相同，因此不同名的类有不同的构造器名
而且涉及到了实例变量，这就导致演示很麻烦
我比较建议采取前三种方法

在这四种方法当中：
我最喜欢使用第二种
很多开发者使用第一种
有一些大佬喜欢使用第三种
