因为现在有许多朋友不会开服
特地写了一个教程简单地教开服
本贴用黑箱式教你，不说明每个步骤
（Craftbukkit开服，只能装插件，如果你要mod和插件都装的话就请装mcpc开服源）
手把手就好
只要RP不是坏到顶点的都应该会成功
首先是Windows的开服方法（是其他的也没关系，等等我会提供一个万能的软件，如果真是想不用软件开服的就可以查看倒霉忍者的帖子）
首先下载CraftBukkit
官方地址：http://dl.bukkit.org/latest-rb/craftbukkit.jar
我败了，有人说地址用不了什么的，我把我的发上来
下面是度度网盘
度度网盘
然后放在一个文件夹里面（推荐是干净的文件夹）
接着，新创建1个txt文件（文本文档）
编辑里面的内容为
  1. @ECHO OFF
  2. java -Xms1g -Xmx1g -jar <此处换成你下载到的文件的文件名>.jar
  3. pause
复制代码

此处参考倒霉忍者的帖子
例子
@ECHO OFF
java -Xms1g -Xmx1g -jar craftbukkit-1.4.7-R1.0.jar
pause
然后把.txt改成.bat
双击那个bat文件并显示Done就代表你成功开服了
在那个bat文件中，输入stop就可以正常关服了

然后是设置文件（就是server.properties 是运行那个bat文件之后在他的根文件夹里面出现的其中一样东西
全部中文说明是说明他下面的那串英文
而ture是开启，false是关闭
参考倒霉忍者的帖子（别用鸡蛋扔我啊，所有的开服教程都是从他那里参考过来的）
  1. #Minecraft 服务器设置文件 此类型文件不支持中文，本内容仅供作为说明，true代表执行，false代表不执行
  2. #Sun Mar 11 18:24:34 CST 2012 此为文件生成时间
  3. # 是否开启地狱
  4. allow-nether=true
  5. # 地图文件夹名称，下界与末路之地将会自动以nether,ender加上并用下划线隔开
  6. level-name=world
  7. 目测国内用不上，所以不用管他
  8. enable-query=false
  9. # 是否允许飞行
  10. allow-flight=false
  11. # 远程访问服务器的密码，此项可以留空或删除
  12. rcon.password=
  13. # 服务器端口（25565为默认端口，联机时无需输入）
  14. server-port=25565
  15. # 第5行对应功能的端口
  16. query.port=25565
  17. # 地图类型，Default=默认，FLAT=超平坦，LARGEBIOMES=巨型生物群系
  18. level-type=DEFAULT
  19. # 是否开启远程访问服务器控制台。技术人员可选。
  20. enable-rcon=false
  21. # 地图种子，生成地图文件夹前填入此项（要删除之前生成的地图文件，用这里的配置文件的话，那个地图文件应该叫world），生成特定的地图
  22. level-seed=
  23. # 服务器IP，不输入则为默认IP，内网用户的话请填内网IP，而我们这次是教外网开服
  24. server-ip=
  25. # 最大建筑高度，上限是256，因为Chunk的高度最大值是256
  26. max-build-height=256
  27. # 是否生成NPC
  28. spawn-npcs=true
  29. # 是否开启白名单，没有白名单的玩家进入服务器会被拒绝
  30. white-list=false
  31. # 是否生成动物
  32. spawn-animals=true
  33. # 此处填写服务器默认材质下载链接，链接必须以.zip结尾
  34. texture-pack=
  35. # 用于给http://snoop.minecraft.net网站发送服务器数据，这样玩家可以从客户端上获取服务器信息，目测也没人看，推荐关闭
  36. snooper-enabled=false
  37. # 是否开启极限模式，玩家死亡将自动被ban
  38. hardcore=false
  39. # 是否开启联网模式（正版专用，盗版必改为false！！！！！！！！！）
  40. online-mode=false
  41. # 是否开启PVP，不是战争服就不要开了，有插件可以只有开关pvp
  42. pvp=false
  43. # 游戏难度，与单机相同
  44. difficulty=1
  45. # 玩家第一次进入游戏时的游戏模式 0为生存 1为创造 2好像是极限还是冒险
  46. gamemode=0
  47. # 同时在线的最大玩家数
  48. max-players=20
  49. # 远程访问服务器的端口号，此项可以留空或删除
  50. rcon.port=25575
  51. # 是否生成怪物
  52. spawn-monsters=true
  53. # 是否生成建筑物（包括村庄和地牢）
  54. generate-structures=true
  55. # 可见距离，最大值为10
  56. view-distance=10
  57. # 服务器欢迎信息（显示在玩家联机页面），中文需中文补丁支持和转码（yy的补丁可用（也需要旧版服务器），ICE未知），推荐EmEditor文本编辑器，自带转码功能
  58. motd=A Minecraft Server

端口映射
可以参考倒霉忍者的帖子。。。放心，我会教你其他方法的
好了，如果你是外网开服的话，你需要的是一个端口映射的方法
（表示LZ也败了给端口映射）
你首先下载一个神软件（别嫌麻烦，这是一劳永逸的）
地址和方法详见该帖子（论坛内）
首先无视标题
http://www.mcbbs.net/forum.php?mod=viewthread&tid=57628&highlight=%B6%CB%BF%DA%D3%B3%C9%E4
你跟着他做。。。。
好吧，我教。。。
下载好了软件，打开（要net.framework   4貌似3.5也行）
你看到下面有个
Open New Port

的东西
下面还有几栏框框的，
首先把Protocol调成TCP 然后在Port那里填你在设置文件（server.properties）中的端口号（根据上面的设置文件是天25565 的）
Description是描述，你填什么都可以

如果程序一段时间(数小时或一天，按照路由器规定，我不会规定)没有数据传输(已关服)，路由器可能会删掉UPNP端口，所以推荐开服前映射一次

这上面是从原帖那里抄下来的。。。。。。（好吧我错了） 不过还是建议大家去看一看
最后按Add Port就好了（完成端口映射）

连接方法
在度度搜索IP
有你的IP地址的
那就是你的外网IP
把你的IP给你的好机油们
（前提是完成端口映射后，否则他们不能连接到你的服务器）
可以开始游戏了
