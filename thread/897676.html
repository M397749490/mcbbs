进行以下步骤

在单人
创建一个世界 名字随意
编辑世界为 Diamond_Block
记录此时的坐标
打开.minecraft\save 找到刚刚创建的世界打开
找到 region 文件，复制


在服务器

创建一个世界 可以使用mv create XXX normal 进行

找到后台打开刚刚的世界 替换刚刚的 region 文件

输入 /mv reload 然后/mv tp XXX

然后Tp到刚刚的坐标

/tp XXX X Y Z




到此，您已成功创建了钻石大陆世界！

Multiverse-Core不能创建世界,它只能用来管理已有的世界.
想做个钻石大陆类的世界,首先可以自己在单人模式创建一个虚空世界,然后进入游戏自己雕琢一个"钻石大陆",最后把这个世界文件夹上传到服务器,用Multiverse-Core导入,就能使用了.

你好，请下载个钻石大陆存档
然后把钻石大陆存档解压并命名为 zsdl 然后放到服务端world文件夹
然后进入服务器输入/mv import zsdl normal
然后输入/mv tp zsdl即可前往钻石大陆
