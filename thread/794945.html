交易指令
确保EconomyAPI已经安装好了
向商店添加商品 输入/addbuyitem 该插件支持数字和字符串id
让玩家销售物品，使用/addsellitem
如果您想要从商店中删除一个商品 输入/delbuyitem或/delsellitem
添加折扣输入/adddiscount [百分比]
删除折扣输入/deldiscount
如果你有“trading.edshoplist”权限（默认op拥有）则可以从控制台或游戏聊天中使用这些命令
商品列表编辑后会自动更新，因此不需要重新启动服务器
使用方法：
购买物品/buy [数量] 如果你不输入[数量]你只会买一件
出售一件物品 /sell [id] [数量] 如果你不输入[数量]，你就只出售一件商品 如果你不输入[数量]或[id]，你将出售你的手中物品
输入/buylist 查看你可以购买的商品，并显示价格。输入/selllist查看你可以卖哪些商品和价格
/id 显示您手中物品的ID
开始拍卖 /auc [起始价]
参与拍卖/bat
命令列表：
/buy [数量] -购买
/sell [id] [数量] -出售
/addbuyitem (/abi ) 添加商品
/addsellitem (/asi )添加商品
/delbuyitem (/dbi ) 删除折扣
/delsellitem (/dsi 删除商品
/adddiscount <%> 添加折扣
/buylist (/blist) 查看可购买商品
/selllist (/slist)查看可出售商品
/auc 拍卖
/id 查看手中物品id
/bet 参与拍卖
/shophelp
配置文件
buy:
  #打开/关闭销售系统(buy, addbuyitem, delbuyitem, adddiscount, deldiscount commands)
  active: true
sell:
  #打开/关闭销售系统 (sell, addsellitem, delsellitem commands)
  active: true
auction:
  #打开/关闭拍卖系统 (auc, bet commands)
  active: true
  #拍卖持续时间,以毫秒为单位
  duration: 300000
  #关于正在进行的拍卖的通知的周期性(以毫秒为单位)
  notify-period: 60000
  #开始拍卖的价格。设置0来关闭它
  start-tax: 0
  #终止税(从最后的投标中扣除)。设置0来关闭它
  end-tax: 0
  #Default compensation for loosing the lot. It's paid to a trader if the auction winner has no free space in his inventory to get the lot, and the trader have no free space to get it back. Set 0 to turn it off
  default-compensation: 0
general:
  #插件语言。如果使用-服务器语言。如果您的语言中没有翻译，将会创建一个名为.lng的文件。你得翻译一下。
  language: default
  #消息的字体颜色
  primary-color: a
  #二次消息的字体颜色
  secondary-color: 2
  #错误消息的颜色
  error-color: c
  #如果是true，将创建一个包含所有字符串的文件。你可以编辑字符串。
  save-translation: false
