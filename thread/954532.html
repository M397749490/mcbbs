插件介绍

这是一个是一个简单易用的插件，服主或OP可以通过指令删除、卸载、载入、重载插件等操作，而无需重启服务器
也可列出插件列表，如果插件有版本号也会显示版本号
可以检索插件所注册的命令
也可以反向查询(指通过命令查询是哪个插件所注册的)
可以通过TAB键补全插件名称
也可以从dev.bukkit.org来检索插件最新版
可以将插件导出为文件
无需多加配置权限组(OP还需要权限组？)

简单而实用

原帖内容:
  • Enable, disable, restart, load, reload, and unload plugins from in-game or console.
  • List plugins alphabetically, with version if specified.
  • Get useful information on plugins such as commands, version, author(s), etc.
  • Easily manage plugins without having to constantly restart your server.
  • List commands a plugin has registered.
  • Find which plugin a command is registered to.
  • Tab completion for command names and plugin names.
  • Dump plugin list with versions to a file.
  • Check if a plugin is up-to-date with dev.bukkit.org
  • Permissions Support - All commands default to OP.



食用方式
暗灰蓝色 - 主命令
暗绿色 - 子命令
暗橘黄色 - 可选项

/plugman help - 列出PlugMan帮助

/plugman list [-v] - 列出所有已安装的插件([-v]可以列出版本)

/plugman info [插件名] - 查看插件信息(作者，版本号等)

/plugman dump - 将插件列表和版本生成到txt文件中

/plugman usage [插件名] - 列出插件的所有命令

/plugman lookup [命令] - 看看是哪个插件生成了这个命令

/plugman enable [插件名|all] - 启用指定插件或全部插件

/plugman disable [插件名|all] - 禁用指定插件或全部插件

/plugman restart [插件名|all] - 重新启用指定插件或全部插件(就相当于把这个插件禁用然后再启用)

/plugman load [插件名] - 载入一个插件

/plugman unload [插件名] - 卸载一个插件

/plugman reload [插件名|all] - 重载指定插件或全部插件

/plugman check [插件名|all] - 检查指定插件或全部插件的最新版本
