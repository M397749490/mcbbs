[DontMove]

禁止移动




功能:


如指令介绍所示，进入状态以后，就不能移动了

如果刚好在空中0-0 就尴尬了

十分鬼畜，然后被服务器踢出去0-0

指令\权限:


dm.use                                       使用以下两指令的权限

/dm add <Player>                让一个玩家进入无法移动状态

/dm remove <Player>          让一个玩家离开无法移动状态

配置文件:
  1. open: true
  2. message: "&e[DontMove]&c你不能移动哦"
  3. save: true
  4. loginclear: false
  5. player:
  6.   0: "null"
  7.   1: "null"
复制代码

open指玩家进入无法移动状态后，如果玩家移动 是否提示信息

提示的信息就是下面的message

下面那个Player就是无法移动的玩家，最好别去改，在游戏里添加就行了
save指是否读取配置文件里的player列表，如果填false，则每次重启服务器
后进入不可移动状态的玩家都会退出这个状态
loginclear指退出后重登是否清除不可移动状态，如果填true，则原本进入不可移动状态
的玩家，退出游戏后重登，就可以离开不可移动状态了

不在线的玩家(中文也可以)也可以添加
