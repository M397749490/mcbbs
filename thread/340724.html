利用按键精灵写了一个小工具，可代替中文输入mod
v1.1：增加对当前窗口类名的判断，避免了在非游窗口按T键（或Enter键）会误触发Inputbox
v1.2：增加了对按/键直接输入命令的判断，避免了在按/键输入命令时误触发Inputbox
v1.3：修复连续按聊天触发键出现的bug，修复了Inputbox窗口失去焦点会出现的问题

优点：
无需改变jar文件即可实现快速的中文输入
理论上全版本可用，T键Enter键可选
可以分别设置输入法，打字时无需中英切换（需设置中文为系统默认，游戏窗口单独设为英文）

缺点：
相对于mod来说会占用更多资源

源码V1.3：
  1. UserVar var=DropList{"T":84|"Enter":13}=84 "聊天键（默认T）"
  2. Do
  3.     ke = WaitKey()
  4.     If ke = 191 Then
  5.         Hwnd = Plugin.Window.Foreground()
  6.         sClass = Plugin.Window.GetClass(Hwnd)
  7.         If sClass = "LWJGL" Then
  8.             Do Until WaitKey() = 13
  9.                 Delay 10
  10.             Loop
  11.         End If
  12.     End If
  13.     If ke = var Then
  14.         Hwnd = Plugin.Window.Foreground()
  15.         sClass = Plugin.Window.GetClass(Hwnd)
  16.         If sClass = "LWJGL" Then
  17.             TracePrint "1"
  18.             JC = BeginThread(监测)
  19.             TracePrint"2"
  20.             txt=InputBox(vbcr&"minecraft中文快捷输入"&vbcr&vbcr&vbcr&"by_dxsc","请输入字符串","",0,0)
  21.             Call Plugin.Window.Active(Hwnd)
  22.             Call Plugin.Sys.SetCLB(txt)
  23.             KeyDown 17, 1
  24.             Delay 10
  25.             KeyPress 86, 1
  26.             Delay 10
  27.             KeyUp 17, 1
  28.             Delay 50
  29.             KeyPress 13, 1
  30.         End If
  31.     End If
  32. Loop
  33. Sub 监测()
  34.     For 2000
  35.         Delay 60
  36.         Hwnd1 = Plugin.Window.Find("#32770", "请输入字符串")
  37.         Hwnd2 = Plugin.Window.Foreground()
  38.         If hwnd1 = "" Then
  39.             StopThread JC
  40.         End If
  41.         If hwnd1 <> "" and hwnd1 <> hwnd2 Then
  42.             Call Plugin.Window.Active(Hwnd1)
  43.             StopThread JC
  44.         End If
  45.     Next
  46. End Sub
