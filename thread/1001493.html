(简单の)方法
方法是包含一系列语句的代码块。 程序通过调用该方法并指定任何所需的方法参数使语句得以执行。    ——docs.microsoft.com

有时候我们需要在不同的地方执行相似或相同的任务
为了避免重复的代码
方法 就横空出世了
我们可以通过方法来使我们的代码更加简洁


由于完整的方法内容十分 复杂 (相对而言)
本篇将只会涉猎一二，满足基本的需求
不做过多讲解

一个方法的声明一般需要5个部分
[可选的访问级别] [可选的修饰符] <返回值类型> <方法名>(可选的参数)   
{                                                                                                                  
    // 方法主体                                                                                  
}                                                                                                           

其中 [可选的访问级别] 目前用于类中时，忽略即可
[可选的修饰符] 目前用于类中时，为 static

返回值类型：如果没有返回值，则为 void
否则即为要返回的值的类型
可选的参数：这里声明的参数可以用于方法主体中
在调用方法时要对应号这个参数
