通过酷Q机器人应用实现的Minecraft多人服务器白名单一体化系统（含RCON远程指令系统）

功能简介
★ 白名单一体化系统：简化你的Minecraft服务器白名单管理流程！实现入群审核一键添加白名单、退群自动删除白名单。
★ RCON远程指令系统：简单高效地在QQ群内发送指令并获取返回信息。
★ 本地黑名单系统：自动拒绝黑名单内人员的入群申请。

相对其他RCON机器人应用的优势
★ 可指定需处理消息的群号，不干扰其他群聊
★ 可设置高级管理员与普通管理员
★ 可设置远程指令所需的权限等级
★ 可通过命令轻松重连RCON

应用流程
新成员入群  >> 管理员审核 >> 管理员发送“绑定”命令 >> 新成员发送id >> 机器人自动添加白名单
成员退群 >> 机器人根据本地数据自动删除白名单
管理员发送“命令”命令 >> 机器人执行指令 >> 机器人返回数据

命令菜单
绑定<@某人>：将该成员加入白名单
删除<@某人>：删除该成员的白名单
查询<@某人>：查询该成员在本地登记的白名单
管理+<@某人>：将该成员设为普通管理员
管理-<@某人>：取消该成员的普通管理员
黑名单+<帐号>：将此人加入黑名单
黑名单-<帐号>：将此人移出黑名单
命令<MC指令>：通过RCON发送远程指令
我：查询发送者自己的操作权限
重连RCON：RCON重新与服务器建立连接
