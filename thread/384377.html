也有方法 但是比较麻烦
如果进入服务器失败 服务器端会有日志 像这样:

  2. [Server thread/INFO]: Disconnecting com.mojang.authlib.GameProfile@7a50c6dd[id=530fa97a-357f-3c19-94d3-0c5c65c18fe8,name=test,properties={},legacy=false] (/127.0.0.1:55574): You are not white-listed on this server!
复制代码

当中的"530fa97a-357f-3c19-94d3-0c5c65c18fe8"是uuid
test就是玩家id
可以在whitelist.json中对uuid进行一下替换
把
  1.   {
  2.     "uuid": "xxxxxxxxxxxxxx",
  3.     "name": "test"
  4.   }
复制代码

替换成
  1.   {
  2.     "uuid": "530fa97a-357f-3c19-94d3-0c5c65c18fe8",
  3.     "name": "test"
  4.   }
复制代码

保存文件 然后whitelist reload重新加载白名单 就可以进入服务器了

原因就是一楼所说的uuid问题 新版中是通过uuid区分玩家的
每个正版id都有对应的uuid 白名单中储存的也是uuid
但是盗版状态下产生的uuid不可靠 客户端uuid和白名单不一致就无法进入
如果服务器开启正版验证 是可以正常使用白名单的
