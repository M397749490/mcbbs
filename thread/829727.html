一、简介
1.2新版本来袭！（2018/11/25）
更新内容
[+] 玩家开始/停止挂机时全服提示，让其他玩家知晓
[+] 在TAB列表上标注挂机的玩家
[+] 挂机中释放失明效果
[+] 添加了一些音效
[+] 设定了挂机时玩家无法移动，能有效防止玩家因手残不小心移动而造成挂机中断
[Fix] 修复了一些BUG，提升玩家体验
楼主简直高产似那啥？？？
1.1新版本来袭！（2018/11/18）
更新自定义提示语，挂机指定世界，不同挂机组自定义提示语等等
（补充了1.0原有功能“挂机组”的相关介绍）

这是一款高效实用的挂机插件
支持让你的不同权限组的玩家获得不同额度的经验奖励
同时挂机是会有分钟提示，你可以自定义每分钟奖励的经验值
GUI面板领取经验奖励
二、未来计划（请看）
本插件将会持续更新，请关注本帖留意最新状况！
1、提示语自定义  （已达成部分）
2、兼容更多版本（1.8+）
三、使用方式
Step.1
输入挂机指令，开始挂机

/flyaway start



Step.2
领取你的挂机奖励
打开挂机奖励领取面板后，点击瓶子领取

/flyaway getexp



Step.3
多挂机组教程 新补充！
让你服务器的玩家拥有不同的挂机提示和挂机奖励数额
本插件已预置一个默认组Default 一个自定义组VIP
其中Default为所有玩家初始拥有，所有世界可用

在config.yml添加一个组（非默认组）注意：组名下面的每行都要空出两个空格
格式如下


1.2新版本新补充：
StartBroadcast项：玩家开始挂机时全服提示语，若你不希望这么做，请不要写着项
EndBoardcast项：玩家停止挂机时全服提示语，若你不希望这么做，请不要写着项
以上两项玩家名的变量均为{player}

例如这是VIP组：

  1. VIP:
  2.   Name: "&d&l会员挂机组"
  3.   ExpPerMinute: 3
  4.   StartMessage: "&b&l开始挂机！&a您目前所使用的挂机组为 {group} &a！"
  5.   EndMessage: "&d&l挂机结束！&a挂机组 {group} &a在本次挂机中为您提供了 &6{exp} &a点经验值，输入 &3/flyaway getexp &a可以领取所收集的经验！"
  6.   World: world
  7.   WorldMessage: "&c&l该世界无法挂机！&a请你移步至世界 &b{world} &a开始挂机！"</font>

如何给予玩家挂机组权限？？
So Easy!
给予玩家/权限组权限 volkafk.custom.组名
（例如volkafk.custom.VIP）
玩家挂机时插件会根据TA拥有的权限来判定他应该使用的挂机组
