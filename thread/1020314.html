如题，如何使用NBTexplorer修改玩家当前的进度
或者使用不作弊的方法修改进度（例如修改文件）
求具体方法
作者: (=°ω°)丿    时间: 2020-4-16 13:54
本帖最后由 (=°ω°)丿 于 2020-4-16 14:27 编辑

玩家关于进度的信息以 .json 的后缀名保存在 .minecraft\saves\<地图名>\advancements 文件夹下，打开文本编辑器例如 npp, vscode 即可编辑。
例如：
  1. "minecraft:recipes/redstone/lever": {
  2.   "criteria": {
  3.     "has_cobblestone": "2020-02-29 12:33:05 +0800",
  4.     "has_the_recipe": "2020-02-29 12:33:05 +0800"
  5.   },
  6.   "done": true
  7. }
复制代码
表示该玩家于 2020-02-29 12:33:05 +0800 获得圆石，于 2020-02-29 12:33:05 +0800 解锁该配方。该进度已经被完成。
