标题: 怎么让一个指定区域可以pvp?
如题
我装了一个pvp矿场
我想让矿区内可以pvp
但是矿区外禁止pvp
怎么设置
求大佬解决

作者: 喵    时间: 2019-7-27 23:11
首先把整个矿区圈地
在矿区内输入/res set pvp F
然后在你想可以pvp的地方用创建领地的方法选取两个点
然后/res subzone 主领地名 子领地名 创建子领地
最后输入/res set 主领地.子领地 pvp F 即可
这样就只有在子领地才能pvp了
