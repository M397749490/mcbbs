什么意思啊Group vip already inherits Builder might not be directly

1.创造一个组/mangadd 组的名称比如说VIP
2.可以继承某个权限组（比如说builder基本权限就都有了）
/mangaddi builder 新组名称VIP
3.可以加个称号
/mangaddv 权限组 （前面输入prefix/后面输入suffix） 称号
4.还有什么权限要补充的
/mangaddp 权限组 权限
比如说飞行权限是 essentials.fly
/mangaddp VIP essentials.fly
5.把别人加到这个组
/manuadd 玩家 VIP
6.最后保存一下吧
/mansave

然后 2
输入 /mangaddi builder VIP
你的这个VIP组就有基础权限了（就是可以使用比如说/spawn /money /tpa之类的指令了）
3
你可以给这个组增加一个称号，就是玩家在说话时显示的
你输入 /mangaddv VIP prefix &eVIP
游戏内就会是 VIP玩家名称：嘿~

4
权限组只有基础权限，比如说你想你的VIP玩家可以飞行
你需要输入/mangaddp VIP essentials.fly
essentials.fly是飞行的权限！ 其他权限也这样加
5
差不多设定完了，可以把人加进去了
/manuadd 玩家 VIP
玩家就加入到VIP组了
6
保存一下权限组配设
/mansave        望采纳

作者: 凯文丶    时间: 2015-10-4 21:07
楼主在游戏内输入好/mangadd vip后，到GM配置文件找到groups.yml文件你会看到你的权限组是这样的
  1.   vip:
  2.     default: false
  3.     permissions: []
  4.     inheritance: []
  5.     info:
  6.       prefix: '&c'
  7.       build: true
  8.       suffix: ''
复制代码

接着，把inheritance改为
  1.     inheritance:
  2.     - default
  3.     - g:essentials_builder
  4.     - g:towny_builder
复制代码

prefix:就不用我说了，是称号
permissions：也不用说了是权限
格式：
  1.     permissions:
  2.     - xxxx.xxxx
复制代码

default：是否设置为默认权限组
就这么简单
