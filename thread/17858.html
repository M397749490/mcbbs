server.properties在你的服务器文件夹 通常你看见的名称是server 找到后右键使用记事本打开
你会看见这些代码：
#Minecraft server properties
#Fri Jan 13 17:37:20 CST 2012
allow-nether=true
level-name=world
enable-query=false
allow-flight=false
server-port=25565
level-type=DEFAULT
enable-rcon=false
level-seed=
server-ip=
spawn-npcs=true
white-list=false
spawn-animals=true
online-mode=false
pvp=false
difficulty=1
server-name=Unknown Server
gamemode=0
max-players=100
spawn-monsters=false           把false改成true 保存  重新启动服务器即可！spawn-monsters=true
view-distance=10
