插件特点


本插件最主要的功能就是传送玩家至任意某个地方，插件首先选定一个随机坐标，然后检查这个坐标是否安全，使用Java来获得随机坐标可能并不必要，因为本插件可以从Random.Org这个随机数网站获得随机坐标


随机传送特点
  • 可针对各个世界设置最大/最小传送范围
  • 可以设置禁止传送的黑名单世界
  • 可以设置最大/最小范围的中心
  • 可避免传送进Factions派系区域，WorldGuard区域，WorldBorder边界外，Towny城镇区域，GriefPrevention保护区域，甚至其他玩家周围
  • 可以设置玩家最多可随机传送多少次
  • 可以让玩家第一次进服的时候随机传送，并强制他们执行一个指令（比如/sethome）
  • 可以给随机传送添加冷却
  • 可以给随机传送添加延迟
  • 当玩家处在传送延迟中时，如果他们动了一下，或者被其它玩家攻击了，则传送取消
  • 传送完成后可以给玩家添加无敌时间
  • 传送完成后玩家可听到一个声音，或者看到粒子效果
  • 可付费传送




安全区域检测

传送到一个未知的随机位置可能会是危险的，因为那里可能会有岩浆，本插件可以阻止你传送到那些危险的玩意上！同样，你也不会被传送到水面上，因为谁想掉进大海里呢！传送过程中不会有任何东西可以伤害到你，对于一些比较卡顿的服，如果你被传送卡进了墙里，你会被传送至外面！

本插件除了不会传送到危险区域以外，也不会传送至下面这些插件保护的区域
Factions派系区域
Towny城镇
WorldGuard区域
GriefPrevention区域保护
WorldBorder世界边界
原版世界边界（即默认3千万坐标的那个, 译者注）
附近的玩家

传送门随机传送

不只用指令可以传送，你还可以制作一个用于随机传送的传送门！当玩家进入传送门的时候就会被传送（就好像他们使用了指令一样）同样，你还可以使用传送门来进行跨世界传送！


随机地标传送

除了随机传送至某坐标以外，你还可以让玩家随机传送至某地标！一个预设好的地点，你可以设置许多地标，然后玩家选择随机的一个进行传送
（本插件所指地标非ess的warp地标，而是本插件的地标, 译者注）

你可以：
  • 设置禁止跨世界地标随机传送，那么玩家只能在本世界的地标随机传送
  • 管理这些地标
  • 使用指令来随机传送至地标
  • 地标传送限制
  • 使用木牌或者传送门来进行传送



木牌传送

除了使用指令之外，你还可以让玩家点击木牌进行传送，你可以通过木牌来设置随机传送的世界，以及使用的价格

你可以：

  • 限制木牌传送
  • 阻止玩家撸爆传送木牌
  • 让木牌用于随机地标传送（参上方“随机地标传送”）




随机进服道具箱

本特点与玩家第一次进服随机传送有关，玩家第一次进服被传送后，可在他们周围生成一个箱子，箱子里有可配置的新手物品，如果你安装了Essentials，箱子里的物品甚至可以设置为一个kit礼包，这个箱子只会在玩家第一次进服的时候出现一次

你可以给指令添加多种变量，来让指令的作用变得更丰富

  • /rc portal create <传送门名字> 1000 200  创建一个传送门，传送范围最大是1000，最小是200
  • /rc portal create <传送门名字> 1000   创建一个传送门，传送范围最大是1000，使用默认最小范围
  • /rc portal create <传送门名字> min:200 max:1000  创建一个传送门，范围最大1000，最小200
  • /rc portal create <传送门名字> min:200 max:1000 world_nether  创建通往指定世界并随机传送的传送门

变量使用举例-传送门列表
  • /rc portal list   列出传送门列表
  • /rc portal list <世界名>   列出所选世界的传送门列表

空岛传送模式 [查看Wiki原文]
这是什么功能？

简单地说，当玩家传送至虚空时会在玩家脚下生成一个方块[可配置]，以避免他们掉入虚空，这个功能适合一些生成特殊虚空世界的服务器（比如空岛, 译者注），在这些世界里，即便本插件认定传送目标是有方块的，但是真正传送到那里以后，特殊的世界生成器会移除那些方块

这个功能生效的世界是可以设置的，同样，这个功能有个“自动移除”的特点，当玩家离开他们脚下踩的方块2.5格远以后，那个方块就会消失



配置文件
在插件的文件夹RandomCoords中，你应该能找到一个SkyBlockSave.yml文件，这个文件存储的就是有关空岛传送模式的配置

  • SkyBlock: BEDROCK    玩家传送至虚空时脚下生成的方块种类
  • AutoRemove: true     玩家离开这个方块一定距离以后，该方块是否消失
  • SkyBlockWorlds      该功能生效的世界


末地？

虽然本插件可以让玩家安全地在末地世界进行随机传送，而不至于让他们掉入虚空，但是可能会造成卡顿，如果你把末地世界加入SkyBlockWorlds中的话，玩家可以在虚空中传送，并在他们脚下生成一个方块，这个方法要比普通传送快很多，作者推荐这种方法

随机传送指令 [查看Wiki原文]
（若基础指令/rc和领地内聊天指令冲突，请将/rc改为/rtp，效果相同, 译者注）

——【基础指令】——

  • /rc    玩家若使用这个指令，则会在本世界随机传送，使用默认最大/最小范围
  • /rc player <玩家名> <目标世界> <最大范围> <最小范围>  随机传送某玩家
  • /rc all <目标世界> <最大范围> <最小范围>    随机传送全服所有玩家
  • /rc warp <目标世界>    随机地标传送（参“随机地标传送”部分）
  • /rc warp <玩家名>    让某玩家随机地标传送
  • /rc warp <目标世界> <玩家名>   让某玩家指定世界随机地标传送
   <目标世界> <最大范围> <最小范围> 这些变量并不是必要的，你可以不用添加这些变量


——【/rc player】——

这个指令唯一必须具备的变量是<玩家名>
/rc <玩家名>这个指令和/rc player作用相同

可用变量

  • <最大范围>
  • <最小范围>
  • <max:最大范围>
  • <min:最小范围>
（不加max/min的变量需要考虑顺序，大在前小在后，带max/min的变量则不用考虑顺序问题, 译者注）

使用举例
  • /rc player Jolbol1 world 1000 200本指令会将玩家Jolbol1随机传送至世界world的最大1000最小200的随机地点

同样，本指令可写作：

  • /rc player world 1000 200 Jolbol1
  • /rc player world Jolbol1 1000 200
  • /rc player 1000 world Jolbol1 200
  • /rc player 1000 Jolbol1 world 200
  • /rc player Jolbol1 world min:200 max:1000



更多举例
  • /rc player Jolbol1 min:200   将随机传送玩家Jolbol1 最小范围是200
  • /rc player Jolbol1 1000   将随机传送玩家Jolbol1 最大范围是1000
  • /rc player Jolbol1 custom_world   将玩家Jolbol1随机传送至特定世界任意位置


——【/rc all】——

可用变量

  • <最大范围>
  • <最小范围>
  • <max:最大范围>
  • <min:最小范围>
  • <目标世界>
  • <来源世界>
  • <to:目标世界>
  • <from:来源世界>
（不带英文的变量需要考虑顺序，范围大在前小在后，世界目标在前来源在后, 译者注）

使用举例
  • /rc all world 1000 200 将全服随机传送至世界world的最大1000最小200范围的任意位置

同样，本指令可写作

  • /rc all 1000 200 world
  • /rc all min:200 1000 world
  • /rc all min:200 max:1000 world
  • /rc all 1000 world 200
  • /rc all min:200 world 1000


更多举例

  • /rc all world_nether world  把世界world的所有玩家随机传送至世界world_nether
  • /rc all 1000 200  把全服所有玩家随机传送至他们自己世界最大1000最小200的任意位置
  • /rc all from:world to:world_nether    把世界world的所有玩家随机传送至世界world_nether



——【最大值&最小值】——
这两个设定值代表随机传送的范围，<最大值>代表玩家永远不会传送超出这个值，<最小值>代表玩家永远不会传送小于这个值，最大值和最小值代表的是边界距离传送中心的距离，不是坐标
例如，若最大值设置为1024，最小值设置为200，那么玩家只能在下图的绿色区域中传送



最大和最小范围的中心可以配置

全服玩家&实体传送 [查看Wiki原文]
这个指令会把全服玩家包括实体传送至一个任意的地点

用法

  • /rc radius <半径多少格内> <目标世界> <最大范围> <最小范围> <-e>
  • 如果包含 -e 这个变量，则半径内的实体也会一起传送

需要注意的问题
选择半径除了和方块有关，与方块所在区块也有关，举个例子，如果你的半径设置的小于16,（一个区块宽度），那么这个区块内所有玩家和实体都会被选定传送，如果你的半径设置为32，那么环绕你所在区块的周围8个区块内的玩家实体都会被选定，也就是“2区块半径”

随机数的产生 [查看Wiki原文]
大部分插件使用Java来产生随机数，但是本插件可以使用一种全新的随机数产生方法来生成“真正”的随机数，随机数产生来自网站http://random.org


可能你会好奇类似电脑等电子设备中是如何产生随机数的，电脑程序产生的随机数大部分是“伪随机”——它们是使用数学程序算出来的，虽然这种随机并无伤大雅，但是可能比不上你掷骰子或者抽奖的那种随机性


RANDOM.ORG这个网站可以给所有人提供“真正”随机的数字，这个随机数来源于大气噪声，其随机性相对于电脑算法产生的伪随机数要好，人们使用这个网站进行抽奖等联机游戏，用于科学研究，美术或音乐创作，本随机数项目创建于1998年，创建者是……（以下内容与本插件Wiki无关，欲了解更多请至原帖, 译者注）

道具箱 [查看Wiki原文]
创建道具箱

在RandomCoords文件夹里你可以找到一个BonusChest文件夹，你可以在这个文件夹里创建一个YML文件，文件名即为道具箱的名字（下划线_在道具箱标题中自动变为空格）

文件夹中有默认的道具箱文件BonusChestExample.yml 请不要修改，因为无法保存，如果你想创建一个新的道具箱，请新建一个YML文件

以下是一个例子，大部分数据并不需要详细说明



  • Odds 几率属性
指的是这个道具箱出现的几率，例子中的45代表有45%的几率会出现一个箱子


  • Data/Amount/Durability  子ID/数量/耐久
这三个值都可以是一个随机数，你可以给它们界定一个范围，比如例子里的耐久1:1500，玩家就会得到一把耐久在1-1500之间的钻石镐

另外，子ID也是可以随机的，例如羊毛，子ID在1-16之间，可以设置Data: 1:16来获得随机彩色的羊毛


  • &p 玩家名变量
在物品名、物品lore、SkullOwner里填写&p 可自动变为领取道具箱的玩家名




BonusChestConfig.yml

本配置文件设置的是不同的世界里生成特定的道具箱，第一次加载的时候这个文件里是空的，你可以自己添加内容，例如
  1. BonusChestExample:
  2. - world

道具箱相关指令 [查看Wiki原文]
想要给道具箱添加物品，你可以使用下列指令

  • /RC Chest {文件名} -> 这个指令会将你的背包物品储存至道具箱“文件名.yml”
  • /RC Chest {文件名} -o -> 这个指令功能同上，但是会抹去之前的该文件所有内容
  • /RC Chest {文件名} -i -> 这个指令可以添加你的手持物品至道具箱
  • /RC Chest {文件名} -d -> 这个指令会将你的背包物品存储至道具箱，同样也包含物品的耐久
