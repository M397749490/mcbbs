作者: 2759159258    时间: 2017-9-18 18:51
额。。。可以这样，走进划定区域把生物自然生成关掉
然后走出区域再打开

●  ●
  ^
scoreboard objectives add A dunmy
execute @a[dx=,dy=,dz=](方括号里的是划定区域坐标) ~ ~ ~ scoreboard players set @a A 1
execute @a[score_A_min=1] ~ ~ ~ gamemode doMobSpawning true
execute @a[dx=,dy=,dz=] ~ ~ ~ gamemode doMobSpawning false
(重复4次，把东南西北4个方位都设定，保证一出去就改回生物刷新)
或者一进入区域各种/kill @e[type=怪物名]，然后配合/gamemode doEntityDrop false即可。
不过很麻烦，如果楼上的插件你用得来的话，你就用吧(我担心改群系会生成一些不该有的东西，或者地图崩了，我就是受害者!!!)配合上面的gamemode doMobSpawning false
OK
