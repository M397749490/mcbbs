简介

RandomItemDropper

With this plugin, you can easily drop random items between two locations based on chance rates!
有了爷，你只管框地设物定概率，剩下的爷来包办！




特点



自动掉落，无需手操

掉落片区数量无限制


可以自行设置某样物品的掉落率


可切换【异步掉落 / 同步间时】掉落两种模式（下图有例）


便捷增删物品


高度可自定义的消息提示支持


爷支持的MC版本横跨1.7~1.16



食用方法

1. 先创建一个片区 (/rid create <片区>)


2. 给片区定点，设立区域 (/rid loc1 <片区>)(/rid loc2 <片区>)


3. 加入你希望在这个片区随机掉落的物品(/rid addItem <片区> <物品>)
P.S. <物品>字段需要对着物品名好好填，可以查阅此处物品列表，但我觉得这个带图的更适合


4. 开始设定对应物品概率(/rid setChance <片区> <物品> <概率>)
P.S. 所有物品掉落概率总和必须等于100%

5. 你可以自由切换【异步掉落 / 同步间时】掉落两种模式(/rid async <片区>)
P.S. 如果你开了异步掉落模式的话，得再用以下指令来设置每隔多少秒一掉/rid setAsyncDelay <片区> <延迟>

6. 看看某个片区的相关信息(/rid info <片区>)



7. 大功告成，EV8D掉起来(/rid drop <片区> <item size(暂时不明白指什么)>)




指令集


  • /rid drop <profile> <item size>
  • /rid create <profile>
  • /rid delete <profile>
  • /rid loc1 <profile>
  • /rid loc2 <profile>
  • /rid addItem <profile> <material>
  • /rid removeItem <profile> <material>
  • /rid setChance <profile> <material> <chance>
  • /rid async <profile>.
  • /rid setAsyncDelay <profile> <delay>
  • /rid info <profile>
  • /rid reloadConfig
