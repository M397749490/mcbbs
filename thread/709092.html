提取码: b93k
资源包包含Roland GM/GS sound Set 音源的0-120号乐器+打击乐器 共121个音色全音域
效果：
http://www.bilibili.com/video/av9370116/
点进up空间查看更多红石音乐作品

注：资源包音色全部使用playsound命令播放，不替换任何原版音色
注：先下使用说明，先下使用说明，先下使用说明，音色乐器对照表和使用方法都在里面
注：资源包从1.7.10或者更早版本至1.12都能用 跟距各个版本的playsound命令格式使用
注：资源包里的长音没有stopsound命令就无法控制长度，要使用长音 请用有stopsound命令的版本（1.9.3后）推荐1.10.2

α和β版使用上没有区别 效果也基本没有（应该）区别，β是精简版
推荐 尽可能用α版

关于补丁：补丁只能给α版使用
补丁和资源包放一起 加载的时候前置就行
补丁不添加音色
补丁添加了数字以外的音高写法

写法1：cdefgab + 升降 +音阶
升降用 + - 或 # b 都行
例如 c4+     c4-    c4#  c4b

写法2：音阶 + zsxdcvgbhnjm
zsxdcvgbhnjm为用键盘位置模拟1个音阶的钢琴键盘
zxcvbnm对应cdefgab，sdghj对应黑键
例如 4z

加了补丁两种写法和数字可以同时使用
补丁c4  c5只能使用其中一个
c4为  c4  和 4z 对应中央C（数字音高60）
c5为  c5  和 5z 对应中央C（数字音高60）

关于好东西3.0：这个是一键发声部生成器（自己写的）
可用版本1.9-1.11
