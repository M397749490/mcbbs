插件简介



Timeismoney让你每分钟都可以赚钱！（真实时间）。
Timeismoney是一个系统的自动取款机，玩家可以每分钟都获得钱。
Timeismoney支持iConomy，BOSEconomy和Essentials Eco。

权限&指令      

timeismoney.create 创建ATM机

/timeismoney reload 重载插件
配置文件解读
  1. #每分钟获得钱数
  2. AMOUNT_PER_MIN: 5
  3. #每日最大在线获得钱的分钟数
  4. MAX_TIME_PER_SESSION: 10000000
  5. #每日最大获得钱数
  6. MAX_AMOUNT_PER_DAY: 10000000
  7. #切换为AFK暂离状态扣钱数
  8. AFK_TIME_SECONDS: -1
  9. #下为语言文件
  10. CASH_MACHINE_CREATED: 在线取款机创建！
  11. CASH_MACHINE_DESTROYED: 在线取款机摧毁！
  12. GET_MONEY: <-获得钱->
  13. HAS_BEEN_ADDED_TO_YOUR_ACCOUNT: 已经添加到您的账户!
  14. MAX_AMOUNT_PER_DAY_REACHED: 今天获得的现金已满
  15. THANK_YOU: 谢谢!
  16. NEW_SOLD: '你现在有 : '
  17. HI: '你好 '
  18. TIME_SPENT: '在线时间 : '
  19. MINUTE: ' 分钟.'
  20. CONNECTION_TIME: 'Connection time : '
  21. AFK_SECONDS_IGNORED: ' seconds of AFK ignored.'
  22. CONFIGURATION_RELOADED: Timeismoney 插件重新加载中...
