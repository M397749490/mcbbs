抱歉没仔细看你的第二个问题，你可以在配置里设置下蹲才能创建商店，配置如下【plugins\QuickShop\config.yml】：

  1. #Should we require players be sneaking to create and use shops?
  2.     #是否需要潜行才能进行创建或交易？
  3.     sneak-to-create: true
  4.     sneak-to-trade: false
