如题。自己写的一个mod，在开发新方块时发现不能调用setSoundType方法，导致不能设置方块声音。

由于Block类中的setSoundType方法被标记为protected，导致无法正常调用。
请问如何才能调用这个方法？
代码如下：

  10. import net.minecraftforge.fml.common.eventhandler.SubscribeEvent;

  14.     protected SoundType blockSoundType;

  19.     protected Block setSoundType(SoundType sound) {
  20.         this.blockSoundType = sound;
  21.         return (net.minecraft.block.Block) Block;
  22.     }

  24.     Block pineapple_block = new BlocksRegister().setRegistryName(name_1).setUnlocalizedName(YummyFood.MODID+":"+name_1).setCreativeTab(CreativeTabs.DECORATIONS);

在开发新方块时发现不能调用setSoundType方法

在你自己的方块的构造器里调用不就好了。protected 访问级修饰符允许你在这个类的子类中调用被修饰的方法。

  1. public class MyBlock extends Block {
  2.   public MyBlock(Material mat) {
  3.     super(mat);
  4.     this.setSoundType(...); // 这样是可以的。
  5.   }
  6.   @Override // 你实在是在意的话你也可以直接把这个方法重新暴露出来。
  7.   public Block setSoundType(SoundType type) {
  8.     return super.setSoundType(type);
  9.   }
  10. }
