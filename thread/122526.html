OpeningHours简介：

任何玩家（除了在config.yml中指定的玩家之外）在服务器开放时间外登录的玩家将会得到一个非常明确的消息（可以自行设置）告诉他们服务器的开放时间与关闭时间。在服务器即将关闭之前，玩家也会在60秒（可以设定）之前得到通知。
OpeningHours安装：
将OpeningHours.jar放入/plugins重启服务器即可
OpeningHours权限：
'openinghours.ignore'权限可以使一名玩家在开放时间外登录
OpeningHours设置：
  1. #24小时制 必须在单引号内
  2. serverOpeningTime: '09:00'
  3. serverClosingTime: '19:00'

  5. warnSecondsBeforeClose: 60

  7. #以下内容可以设置哪些人可以在开放时间外登录 用小写逗号隔开
  8. #权限 "openinghours.ignore" 也可以做到这一点
  9. ignoreFor: tarzan, jane, douglas

  11. #可以使用的内容 %serverOpeningTime%  开放时间, %serverClosingTime%    关闭时间,
  12. #%warnSecondsBeforeClose%   关闭之前的时间and "\n" 换行.

  14. messages:
  15. serverClosed: 'This server is currently closed.\n\nOpening hours from %serverOpeningTime% to %serverClosingTime%.'
  16. warnBeforeClose: 'This server closes in %warnSecondsBeforeClose% seconds.'
  17. kickPlayer: 'Everybody is kicked because this server is currently closed.\n\nOpening hours from %serverOpeningTime% to %serverClosingTime%.'
  18. errorOpenNotAfterClose: 'Opening time should be before closing time. Plugin disabled.'
