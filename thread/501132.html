LevelDB Viewer
暑假最后几天闲着又没事干，于是就用Java写了这么一个小程序，专门用来研究 MCPE 的地图结构
现在发到论坛上来，供有兴趣的同学研究使用
这个程序使用 GPL 协议保护其版权并开放源代码以供研究


LevelDB 是什么？
LevelDB 是 Google 公司开发的一款开放源代码的十分高效的 Key-Value 结构的数据库。由于其性能十分强悍，常常被许多做 数据分析&数据挖掘 的公司和企业使用。自 MinecraftPE 拥有无限地图以来，LevelDB 便是其默认的地图储存格式。详细信息请查看维基百科的介绍。


LevelDB Viewer 怎么用？

要使用LevelDB Viewer，请先安装 Java Runtime Environment (JRE)，二进制可执行文件及安装包可以在 Java 官网: java.com 下载
Windows NT 平台的系统下请使用记事本，在 LevelDBViewer.jar 的同级目录下新建一个拓展名为 .bat 的批处理文件，将以下内容粘贴至文件中并保存文件:
  1. javaw -jar LevelDBViewer.jar
复制代码
OS X 系统下可以直接双击 LevelDBViewer.jar
其它 Unix 类型的系统 (Ubuntu、GNU Linux、CentOS 等，需要 AWT) 请打开终端，输入命令或者将如下命令保存在脚本中:
  1. java -jar LevelDBViewer.jar
复制代码
