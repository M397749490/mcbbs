介绍 · Introduction
这款插件包含了很多有助于建筑的小功能.
特点

  • - 一些WorldEdit的小功能
  • - 简化Worldedit的指令
  • - 穿墙、夜视、高级飞行模式
  • - 可以用头颅来放置特殊方块
  • - 阻止限制你建筑的事件
  • - 可直接激活铁活版门
  • - 旗帜编辑器
  • - 皮革装备编辑器
  • - 修复攻击速度以便于减少阻挡视野
  • - 用权限来限制观察者模式的传送

配置
  1. #关闭天气变更
  2. disable-weather-changes: true
  3. #关闭红石
  4. disable-redstone: false
  5. #关闭方块物理效果
  6. disable-physics: true
  7. #关闭重力效果
  8. disable-gravity-physics: false
  9. #关闭爆炸
  10. disable-explosions: true
  11. #防践踏
  12. disable-soil-trample: true
  13. #防落叶
  14. disable-leaves-decay: true
  15. #修复攻速
  16. fix-attackspeed: false
  17. #防止龙蛋传送
  18. prevent-dragon-egg-teleport: true
  19. #防止末地传送门传送方块
  20. remove-end-gate-from-blocks: false

/secretblocks, /blocks – 打开特殊方块菜单

builders.util.banner
/banner, /bm – 打开旗帜编辑器

builders.util.color
/color, /armorcolor – 打开皮革护甲编辑器

builders.util.noclip
/noclip, /nc – 开启穿墙模式

builders.util.nightvision
/nv, /n – 开启夜视模式
