Every wanted a player to teleport to a random location. Or maybe use a command to get back to the lobby. I did so I decided to make this plugin.

作者原话,意思是每个玩家都会想要随机传送到一个地方,或者用一个指令回传送大厅,所以他决定制作这个插件.
简介:
这个插件添加了可配置的传送,以及设置传送大厅.
可以在配置中设置指定的世界,以及传送冷却时间
传送最大距离,以及传送大厅的设置
命令:
/tptools reload——重新加载
/tpr——随机传送
/hub——回传送大厅
/lobby——回传送大厅
/setlobby——设置传送大厅
/sethub——设置传送大厅
权限:
tptools.reload——重载插件
tptools.use.*——玩家权限,能使用/tpr,/hub,/lobby
tptools.use.tpr——能使用/tpr
tptools.use.hub——能使用/hub<回传送大厅>
tptools.sethub——能使用/sethub设置传送大厅
tptools.tpr.nocooldown——此权限随机传送无需冷却[坑钱]
配置:
  1. ##TP Tools##
  2. ##By JGSB##

  4. #禁用自动更新功能
  5. auto-update: false

  7. #TPR config
  8. #只允许玩家在指定的世界使用
  9. multiworld: false
  10. worlds:
  11. - 'world'
  12. - 'world_nether'
  13. - 'world_the_end'
  14. #最大的传送距离
  15. max-distance: 10000
  16. #传送的冷却时间
  17. cooldown: 60

  19. #传送大厅[使用/setlobby后有]
  20. #Do NOT change unless you know what you're doing. Otherwise set the lobby ingame with /sethub
  21. World: 'world'
  22. x: 0
  23. y: 64
  24. z: 0
  25. yaw: 0
  26. pitch: 0
