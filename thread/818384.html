要看楼主用的什么权限组插件了...
  1. 请在 GadgetsMenu/config.yml 和 GadgetsMenu/mystery boxes/mystery boxes.yml 的 Execute-Command
  2.       改成你的权限插件的命令
  3.       如：
  4. PermissionsEx插件: pex user {PLAYER} add {PERMISSION}
  5. GroupManager插件: manuaddp {PLAYER} {PERMISSION}
  6. PowerfulPerms插件: pp user {PLAYER} add {PERMISSION}
  7. LuckPerms插件: lp user {PLAYER} permission set {PERMISSION}
  8. CloudNet permission插件: cperms user <user> add permission <permission>
复制代码
记住需要修改多个Execute-Command
