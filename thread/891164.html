GUI Shop Spawners
所需前置：
Vault
SilkSpawners (1.12版本需要)
Mineable Spawners (1.13/1.14版本需要)

这个插件能帮助你简单的创造一个你所指定的刷怪笼，或者你可以通过设置金钱来允许玩家通过金钱来购买指定的刷怪笼。

指令：
  • /spawners 打开一个可视化的刷怪笼商店
  • /spawners reload 重载本插件
  • /spawners edit price [生物标签] [新的价格] 修改指定生物的刷怪笼的价格
  • /spawners edit status [生物标签] [true/false] 确定该生物的刷怪笼是否允许被售卖

权限：
  • guishopspawners.shop 允许使用 /spawners
  • guishopspawners.reload 允许使用 /spawners reload
  • guishopspawners.admin 允许使用 /spawners edit 和 /spawners list
