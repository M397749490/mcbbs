计分板有一个stat.useItem.ID的判据，会在玩家使用“ID”指定的物品时自动加一分。ID自己填写物品的英文ID，要加上minecraft:
/scoreboard objectives add 123 stat.useItem.ID
创建一个名叫123的，在玩家使用指定ID的物品时会自动加一分的计分板。
然后使用/scoreboard players set @a 123 0就可以用了。
之后你可以高频连接/execute @a[score_123_min=1,score_123=1] ~ ~ ~ 指令
最后使用/scoreboard players set @a 123 0还原就好了。
2、/clear 选择器 物品ID 数据值 最大数量 数据标签
选择器就是类似于@a，@p这样的
物品ID就是你想清楚的物品的英文ID
数据值用来区分同一ID不同颜色的物品（比如羊毛），同时也可以表示工具已经消耗掉的耐久。也是用来指定物品的。
最大数量代表会最多清除多少物品，如果是0不会清除。
数据标签也是用来指定物品的，一般可以无视，除非你想清除有指定名字或指定附魔等等的物品

以上方法均只能在MC1.8使用
