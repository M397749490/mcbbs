你拿其他服的图装过来会有mod变更，ID改变，物品丢失的问题，所以不能直接启动。如果非要启动的话，就在你的启动bat里java路径后加上这一行：
-Dfml.queryResult=confirm
完整的给你参考一下，大概是这样（你的路径和内存还有jar名称跟这个可能不一样）：
  1. @ECHO OFF
  2. SET BINDIR=%~dp0
  3. CD /D "%BINDIR%"
  4. "C:\Program Files\Java\jre7\bin\java.exe" -Xmx1024M -Xms1024M -jar-Dfml.queryResult=confir cauldron-1.7.2-1.1147.04.147-server.jar
  5. PAUSE
复制代码

这样启动后，FML就会自动替删除区块里丢失的物品。开完后地图建筑可能会变得破破烂烂，得自己修复。
不过地图内原版的物品不受影响。
