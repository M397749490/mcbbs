DelayCommand
延迟执行命令

功能介绍:
  • 添加多个延迟命令
  • 自定义语言
  • 开关提示
  • 支持args延迟限制（不是只能限制主命令）
配置文件:
配置文件Config.yml


  2. #版本:1 by:Yukun
  3. #汉化by:寡姐
  4. #Placeholders:
  5. #- %player% 玩家的id变量
  6. Commands:
  7.   ###########
  8.   #  例子   #
  9.   ###########
  10. #  #命令的名称,不区分大小写.
  11. #  warp:
  12. #    #延迟时间.
  13. #    Time: '80'
  14. #    #是否开启这个延迟命令.
  15. #    Fuzzy: 'false'
  16. #    #用args来限制延迟命令.
  17. #    #例如玩家输入warp都可以延迟命令，如果设置了args比如设置了一个test2
  18. #    #然后玩家输入warp test2就会延迟命令，输入其他warp xxx并不会延迟.
  19. #    Args:
  20. #      - 'test2'
  21. #      - 'test3'
  22.   ################
  23.   # 延迟命令添加 #
  24.   ################

  28.     Args:
  29.       - ''

  32.     Fuzzy: 'true'
  33.     Args:
  34.       - 'xuyuedi steak 64'

  37.   ###################

  39.   ###################
  40.   #可用单位：ticks.seconds.
  41.   DelayFormat: 'ticks'

  43.   ###################
  44.   #     语言设置    #
  45.   ###################
  46.   EnableDeadMessage: 'true' #开关死亡断开命令延迟消息.
  47.   EnableSendingMessage: 'true' #开关输入延迟命令时提示消息.
  48.   EnableWaitingMessage: 'true' #开关延迟命令执行中时重新输入一个命令后的冷却提示.
  49.   EnableCommandSentMessage: 'true' #开关命令发送消息.

语言文件Messages.yml

  1. #消息配置文件
  2. #Placeholders:
  3. #- %time% 延迟时间
  4. #- %command% 执行中的命令变量
  5. Messages:
  6.   #消息后缀.
  7.   Prefix: '&b延迟命令&f >> &7'
  8.   #输入延迟命令提示
  9.   Sending: '别动!正在执行你输入的命令,请稍等.......'
  10.   #成功执行命令后提示.
  11.   CommandSent: '&a你输入的命令执行成功'
  12.   #玩家移动或动了时断开执行命令的提示.
  13.   Moved: '&c你动了一下，执行命令断开!'
  14.   #在执行另一个命令时又输入一次执行命令提示.
  15.   Waiting: '请稍等 %time% 秒另一个命令正在执行中.'
  16.   #玩家执行命令时死亡提示
  17.   Dead: '你在执行命令的过程中死亡。命令断开'
  18.   #进入战斗时提示
  19.   Tagged: '&c你进入战斗，命令断开!'
