传动杆

传动杆 是机械动力中的一种基础机械组件。可以被用来连接两个动力组件，并传递旋转，也是唯一可以放置 传送带 的组件。


连接组件


当两个动力组件被一个传动杆连接时，提供给任一组件的 旋转动力 也会以同一速度被提供给另一个组件。同样，应力 也会通过传动杆传递，因此，这有可能导致整个应力网络超载。


传送带


[[传送带]] 必须被放置在两个水平且平行的传动杆之间。传送带可以 水平 ，垂直 ，或者 45°倾斜 放置。此外，除了其他传动杆以外，两个传动杆之间不能有任何的方块。


[[黄铜机壳]] 可以被放置在传送带的任一部分上，包括含有传动杆的部分。


[[传送带侦测器]] 不会侦测任何包含传动杆部分的传送带上的实体。


传输器

传输器 是一种高级的机械组件，通常与机械动力的 [[漏斗]] 以及 [[提取器]] 一起使用，是机械动力将物品移入和移出库存的物流系统的一部分。传输器主要是用于将一个库存中的物品转移到另一个相邻的库存中。


使用方法


被动传输


传输器可以被放置在两个存储方块中间的方块空间中，例如 可调节板条箱。这两个块中的一个或者两个都可以是被 [[黄铜机壳]] 包裹的 [[传送带]]。所有在输入库存中的物品都会自动传输至输出库存中。


过滤传输


传输器有一个过滤槽，可以在其中放置任意物品，从而将传输器设置成仅传输指定的物品。或者，你可以通过在过滤槽中放置 过滤器 或者 属性过滤器 来更加精确的决定需要传输以及不需要传输的物品。


传送带

传送带是机械动力中一个基础的机械组件，主要用于传递旋转，移动物品和实体以及制造 连携齿轮箱。如果没有障碍物，你可以将传送带放置在呈 水平 垂直 或 45°倾斜 的 传动杆 上。你也可以将 [[黄铜机壳]] 放置在传送带的任意部分，从而连接几个传送带附加的方块，包括 传送带隧道。


传递旋转


当 旋转动力 被传输到传送带上的任意一个传动杆上时，传送带会向其连接的每个传动杆传递相同的力。如果两个传动杆都连接到外部的动力源时，除非他们旋转方向以及速度都相同，否则无法使用传送带将这两个传动杆相连。


在低版本中 传送带的表面必须是水平的，因此不能将传送带放置在垂直放置的轴上。最好使用连携齿轮箱来实现这些操作。


物品以及实体运输


如果一个物品在移动着的传送带上，那么传送带就会将其附着在表面并携带到传送带的末端，然后再将其抛出。传送带上的物品不会被 [[鼓风机]] 吹动，也不会被玩家捡起。但是在传送带上的物品仍然可以应用 洗涤配方 熔炼配方 以及 烟熏配方。放置在传送带上的 漏斗 可以收集物品。[[传送带侦测器]] 也可以检测或弹出传送带上的物品。此外，如果传送带被黄铜机壳覆盖，则可以通过漏斗将物品添加到存储方块中。你也可以通过 提取器 或者 传输器 来移动物品。


玩家或者怪物将会被移动的传送带困住。不过玩家可以通过进入潜行状态或者跳跃来离开传送带。


传送带侦测器

传送带侦测器 是一种基于红石的组件，它可以检测并弹出在 [[传送带|传送带]] 上的物品。


合成


需要 1 红石粉， 1 侦测器， 1 铁锭， 以及 1 [[黄铜机壳]]


" alt="" />


使用方法


传送带侦测器必须被放置在一个无角度的传送带旁。<br>
传送带侦测器与含有传动杆的传送带部分不兼容，但和有 [[黄铜机壳]] 的传送带部分兼容。


" alt="" />


传送带侦测器有一个过滤槽，可以放置用来过滤物品的 [[过滤器，属性过滤器|过滤器，属性过滤器]]。


传送带侦测器有四种工作模式。你可以使用 [[扳手]] 来切换它的模式。


" alt="" />


检测模式


如果在与传送带侦测器相邻的传送带上有与过滤器相匹配的物品就输出红石信号。这个红石信号是连续的，且直到这个传送带上没有过滤器中的物品时，红石信号才会消失。


脉冲模式


当相邻传送带上的与过滤器相匹配的物品通过传送带侦测器的中心时，传动带侦测器将会输出红石脉冲信号。与检测模式不同，即使传送带被暂停且物品仍位于传送带侦测器的中心，该红石信号也不会是连续的。


弹出模式


与脉冲模式相同，当传送带侦测器侦测到与过滤器相符的物品时，就会将该物品往远离传送带侦测器的方向推离传送带。这个模式会将物品作为一个实体放置在这个世界。如果在传送带侦测器正对着 1 格远处有传送带，则会将物品弹出到该传送带上。如果一个实体或者一个物品将传送带堵塞，则传送带将暂停运行，且传送带侦测器会输出一个持续的红石信号，直到障碍物被清除。


均分模式


与弹出模式相同，只是会弹出物品数量的一半。如果物品数量是奇数，无法平均分配，则多余的物品将会被保留，不会弹出。


怪物侦测


如果在移动的传送带上有怪物，无论传送带侦测器是什么模式都会发出连续的红石信号。你无法将怪物列入检测的黑名单，且他们不会受到弹出或均分模式的影响。

修改配方

Create使用了在1.13版本被首次引入的JSON格式的配方形式。你可以通过你自己的数据包来更改或创建你所需要的的配方。无论是你整合包作者还是普通玩家，本文都将引领你了解数据包的基本形式，以及使用Openloader（Darkhax）和CraftTweaker（Jared）来修改出满足你需求的配方。


数据包是什么？


从 Minecraft Wiki 可以了解到，“数据包系统为玩家提供了一种进一步自定义 Minecraft 体验的方法”。数据包可以包含以下内容：不使用命令方块执行的命令，额外的配方，自定义战利品表（怪物和方块的掉率，战利品箱内的物品），新的进度，tags（可以用于配方中的一类物品）以及维度。由于本文将帮助你自定义你的配方，所以我们的关注点主要在额外的配方和tags。在原版，你可以通过在地图存档的 datapcks 文件夹中添加数据包来加载它。但如果你想要你所有的存档都加载数据包，Openloader或许是一个很好的工具。


我需要什么？


编辑器：至少，你需要学会如何访问 Minecraft 文件夹以及一个文本编辑器。但是，在没有高亮显示的文本编辑器中编写 JSON 文件显然不是一件愉快的事情。因此，我们推荐使用带有高亮显示以及语法验证的文本编辑器。你可以使用装载相应插件的 Notepad++ 或者装载相应插件的 Eclipse ，IDEA ，或者其他你习惯使用的编辑器。


Openloader (可选): Darkhax 所写的 Openloader 是一个实用的模组，它使得整合包作者们写的数据包可以在全局范围被应用。它是一个轻量级的，能在 1.14.4 和 1.15.2 使用的模组。


CraftTweaker (可选): CraftTweaker 可以帮助你获取所有有效的配方，并查看一个物品是属于什么 tag。这使得CraftTweaker 成为了在游戏中调试配方的一个极佳工具。但是要切记，CraftTweaker 允许完全清除配方。如果你添加了一个新配方，你通常会想要老配方消失。如果这个配方被添加在 .jar 文件中，那么 CraftTweaker 将会是禁用它的最佳选择。


JEI (可选): 我们建议使用 JEI 来快速查看你的更改。你当然可以不使用它，但它的确是一个十分有用的工具。


注意：这些模组都不是由Create开发团队所开发，对于在使用这些模组时您可能遇到的任何问题，Create开发团队概不负责


设置


要开始开发数据包，你首先需要将数据包的根目录放置在 saves 文件夹 /saves/world_name/datapacks/你数据包的根目录 或者 openloader 文件夹 /openloader/data/你数据包的根目录。我们建议使用命令 /datapack list，来查看你是否正确的调用了数据包。 数据包名称不能以数字开头且只能包含小写字母，数字及下划线！！！


在数据包根目录中，您需要一个名为 pack.mcmeta 的文件，其中包含了数据包的基本信息。 pack.mcmeta 文件的示例如下:


{

        "pack": {

                "pack_format": 5,

                "description": "Your interesting description"

        }

}

除了 pack.mcmeta，你还需要在同一目录下放置一个 data 文件夹。其中需要有一个名为 your_data_pack_name 的新文件夹，（当然，这只是作为示例讲解。你可以根据你自己的需求更改文件夹名）


在这个新文件夹中你需要有 recipes 文件夹以及 tags 文件夹。


" alt="数据包的文件结构" />


完成这些步骤后，重新启动游戏或使用命令 /reload 来应用你的更改， (/relaod 会更快), ，并执行 /datapack list 来查看你的数据包是否被正确加载。


" alt="数据包的加载" />


如果数据包未显示，请检查其文件结构。如果正确加载却显示红色，请使用


/datapack enable "file/your_data_pack_name" 来启用数据包，并重新使用 list 命令进行检查。


可以在 这里 找到这些步骤的完整过程。


添加一个配方


配方以JSON文件形式编写。可以在Create Github找到配方的示例，这或许对你有些启发。


首先，在 recipe 文件夹添加一个新的 JSON 文件（与数据包的命名方式相同，文件扩展名为 .json ）。一个 JSON 文件只能添加一个配方。


第一个例子是通过洗涤石灰沙来获得粉碎锌矿石。


使用 F3 + H 可以使你看到物品 ID 的有关信息，你需要通过这些物品 ID 来修改你的配方。


{

    "type": "create:splashing",

    "ingredients": [

            {

                    "item": "create:limesand"

            }

    ], 

        "results": [

                {

                        "item": "create:crushed_zinc_ore",

                        "count": 1,

                        "chance": 0.1

                }

        ]

}

执行命令 /reload ，然后你应该可以在 JEI 中看到这个配方（如果你安装了 JEI 的话），或者可以亲自尝试一下配方是否完成。


" alt="JEI 界面" />


注意： 在 Create 0.2.3 中，粉碎锌矿石的 ID 是 crushed_zinc，但在 Create 0.2.4+ 中，它的 ID 变成了 crushed_zinc_ore！


添加合成配方也是一样的简单 这个工具 或许会有所帮助


删除配方 （需要 CraftTweaker）


要删除一个配方，你需要执行命令 /ct dump recipes。这个命令将所有可用配方转储到 logs 文件夹中的 crafttweaker.log 文件中。在这里，你可以检查你所有的配方。


要删除一个配方，你需要在 Minecraft 的 scripts 文件夹中创建一个新的 .zs 文件（只有在安装了 CraftTweaker 的情况下才会存在），然后像这样 <recipetype:create:splashing>.removeByName("create:splashing/soul_sand"); 添加一个链接。


这行代码会删除灵魂沙的洗涤配方。如果你要删除其他配方，必须更改其配方类型以及配方名称。


Tags


要想在合成配方中使用 tag，你需要使用 "tag": "modname:tag_name"


例如， "tag": "forge:ingots/copper" 将接受所有以及被添加到 ingots/copper 中的铜锭。


tag 只能在合成原料中使用。


加载蓝图

你可以使用蓝图模块来从 .nbt 格式的文件中加载结构并将其引入世界。
加载并定位 蓝图 之后可以通过 蓝图加农炮 来直接在世界中放置结构。
在这个工作流程中，你需要：



  • 空白蓝图 x1

    (蓝图与笔也可以)

  • 蓝图桌 x1


加载


合成一张 蓝图桌 并将其放置在地面上。

打开蓝图桌并在左侧的输入界面中放置 空白蓝图。


" alt="" />


方格区域显示了要加载到物品中的蓝图文件。
你可以将其更改为 /schematics 文件夹中任意有效文件。   



  • 滚动 文本来选择你想要加载的蓝图文件。

  • 按 √ 按键来确认你的选择。在你确认后，蓝图桌就会将这个蓝图写入物品中。


蓝图桌的处理时间取决于你的蓝图文件的大小。
在技术方面 - 蓝图已经被上传到服务器以便于在服务器游玩时使用。
如果你的蓝图格外的庞大，你可以在上传时关闭蓝图桌界面，过了一段时间后再返回。



  • 完成后，在输出槽取出 蓝图 并拿着这个蓝图。


初始放置


" alt="" />


你有两个选择来进行初始放置：使用 部署 模式，或者直接输入坐标。



  • 如果要放置没有输入坐标的蓝图，请在边界框在所需位置附近时，手持 蓝图 右键单击 来放置蓝图。（稍后可以改变位置）

  • 如果要在空中定位，按住 Ctrl 来以一个固定距离锁定选择的位置。
    你可以在按住 Ctrl 的同时，通过 滚轮 来修改距离。右键单击 以确认你的选择。

  • 跳过坐标部分


如果您从其他工具，先前的会话或您的朋友那里已经保存了特定的坐标，
你可以通过在 潜行状态 下 右键单击 来打开蓝图界面。


" alt="" />


坐标需要你输入数字，其他选项都可以通过 滚轮 修改。



  • 输入你需要的坐标后按 E 或者 ESC 来确认并关闭界面。

  • 如果你复制了带有逗号分隔的坐标 x,y,z，只需要 GUI 界面按下 Ctrl-V 来直接输入复制的坐标。


微调


当你设置完初始位置后，将会显示该结构的全息图 (除非该蓝图由其他玩家所拥有)。
注意：这时并没有方块被放置，只是提供预览效果。只有你能查看这个全息图，其他玩家并不会看到。
在这一步，你可以使用工具来进一步地调整结构的位置。


" alt="" />


按住 [左-Alt] 并 滚动 可以使你修改不同的选项，并显示一些有关如何控制他们的说明。



  • 使用 移动，转动 以及 翻转 工具的方法如下。先指向蓝图的一边，按住 Ctrl 然后使用 鼠标滚轮。
    这需要一段时间来适应，但这个可以让你在经济情况下选择你的 快捷栏。

  • 部署 工具使得你可以使用光标来重复初始定位。
    你也可以通过在 潜行状态 下 右键单击 来修改这些坐标。

  • 在 创造模式 下，还会有一个叫 打印 的附加选项，它将直接把蓝图中的结构放置在选定的位置及方向上。
    在打印后，这个蓝图依然存在，并可以根据需要重新进行部署。

动力辊压机

动力辊压机是机械动力中最早被制作也是最重要的机器之一。主要用于辊压/压缩机器下方的物品。


他主要的用途是 [[制板|Create's-Materials]]，这些板被广泛地运用在各个机器的合成配方中，比如说 [[机壳|Casing]].


动力辊压机由内部的 [[传动杆|Generate-and-Convey]] 驱动，可以从两侧为其提供动力。像传动杆一样，辊压机将会沿轴传递 [[转动|The-Basics-of-Rotation-in-Create]]。注意：无论动力辊压机的功率有多大，它始终会以一个恒定的速率辊压/压缩物品。


辊压


默认情况下，动力辊压机会尝试标记其下方的物品。你可以通过两种方式来对此进行设置：



  • 当被放置在任何方块上方 1 格时，辊压机将会在收到红石信号后对其下方物品进行处理，且对没有辊压配方的物品不会生效。

  • 当被放置在 [[传送带|Generate-and-Convey]]上方 1 格时，它将会自动对传送带上的物品进行辊压，并且在动力辊压机运行时，传送带是停转的。没有辊压配方的物品将会被忽略。


压缩


当动力辊压机被放置在 [[工作盆]] 上方时，它将压缩里面的物品而不是辊压。它会尝试将工作盆中的物品以 2x2 (例如萤石) 或 3x3 (例如铁块) 形式合成。


如果在工作盆中存在有有效配方，动力辊压机将会自动进行处理，无论工作盆内部是否还有剩余空间。

应力


到了这里，我们已经介绍了大量关于 [[旋转|Generate and Convey]] 以及 [[转速|Changing Gears]] 的相关内容，接下来我会为你介绍本mod中最后一个重要机制： 应力。应力是机械动力对于扭矩的一种简化实现方式，在实际应用中可以平衡旋转系统出现的一些问题。要想理解应力，我们需要将组件分为两个门类： 应力产生装置 以及 应力消耗装置。每个应力产生装置都会产出特定的 应力量 ，而应力消耗装置则由其对应的 应力影响值。只要系统的总应力量大于或者等于系统的总应力影响值，系统就能正常运转 ，各组件也能正常工作。但是，如果系统的总应力影响值大于了总应力量，那么系统会超载，所有的组件都会停止工作。只有当总应力值大于或者等于应力影响值时，系统才能恢复生产。


SU以及转速


组件的应力影响值也会受到其转速的影响。所有的组件都有一个 基础值，这一基础值指的是 1 RPM 的转速所产生的应力值/应力影响。想要获取特定部件对系统的有效应力值/应力影响，你需要将基础值乘以其转速。举个例子，一个水车 (基础值为 4 SU)以 5 RPM 的转速运行，它会给系统产生总计20 SU的应力值；而以10 RPM转速旋转，则会产生40 SU的应力值。消耗装置遵循着一样的逻辑：一个粉碎轮以20 RPM的转速运行，将会对系统产生160 SU的应力影响值。


一般来说，一些组件 只能传递 旋转能，例如传动杆以及齿轮，对系统完全没有应力影响。由此，大大降低了预测总消耗装置所需的总产生装置数量的难度，而且，你还可以出于美观的目的将机器与产生装置分隔开，这不会有任何的应力损失。

应力的产生与传递

机械动力中许多机器都需要供能后才可以运行。这个能量被称为旋转动力或 旋转。机械动力中也有几个机器可以通过不同方式来产生旋转动力，他们通常被称为 应力产生装置 。仅仅依靠应力产生装置并不能让你有效地推进模组流程，你还需要将产生的旋转动力传递给需要的机器。机械动力中有许多方块可以实现这个功能。所以你最好还是要多模块地协同发展，才能熟悉各个模块的功能以及如何协作运行。在较为艰苦的环境中了解不同的处理复杂的连接问题的方法是极其重要的。在下方 你将找到应力产生装置的一个列表及其简要说明，以及了解如何传递旋转动力。


可以将多个应力产生装置连接在一起，使得整个应力网络有更大的应力及容量。当你向应力网络添加 新的应力产生装置时，你需要先检查一下是否与要连接的应力网络旋转方向一致，这是十分重要的。当你将两个旋转方向不同的组件连接到一起时，这些组件会断裂，从而无法运行。但是，要排除这个故障也很直接，很简单——你只需要使你应力产生装置反转，从而与整个应力网络向同一方向旋转就可以解决问题。

水车是一种最基本的应力产生装置。水车这个概念听起来应该是十分熟悉的，特别是对于经常玩模组的人来说。为了使水车旋转，你需要做的只是要使得它周围有水流动。你需要注意水流的方向，因为当水流反方向流动时，水车只会以一半的速度运行。

鼓风机


鼓风机是一种稍微高级一点的应力产生装置。尽管鼓风机可以使用旋转动力来吹风，但他们也可以作为应力产生装置来产生旋转动力。要使得鼓风机成为应力产生装置，它们必须正面朝下，并在其正下方有热源（例如火和岩浆）存在。然后使用红石信号激活鼓风机，它就会开始旋转。

熔炼引擎


熔炼引擎比上述的两个应力产生装置都要昂贵，不过也拥有了更大的应力容量。首先，你需要两部分来使得熔炼引擎开始运作：熔炼引擎本身以及一个飞轮。熔炼引擎需要放置在熔炉上，然后将飞轮装上去。你需要让这个熔炉燃烧来驱动熔炼引擎运作。但是请注意，一旦熔炉熄灭，熔炼引擎也会停止运行。

传动杆


传动杆最基础也是最廉价的传递旋转动力的方法。他们会沿直线传播旋转动力到每一个连接的轴上。

齿轮


齿轮也可以作为传动轴使用，但它们的主要用途有些许不同。齿轮会在传递旋转动力的同时，将旋转传递给与之相邻的其他齿轮。直接相邻的齿轮的旋转方向是相反的。<br>
当混用大齿轮以及小齿轮时 [[旋转速度|Changing Gears]] 也会相应改变。<br>
两个成 90° 的大齿轮可以在转角处传递旋转。

传送带


你需要两个朝向相同的传动杆来放置传送带。传送带可以以 3 种形式被放置， 水平 垂直 以及 45°角倾斜（参考下方的图片）。手持传送带并右键单击一个传动杆，之后你会看到一些例子效果，然后将你的视角移动到你想连接的第二根传动杆上，若粒子效果变成绿色，则说明可以在这个传动杆上放置传送带。当传送带被放置后，他会在两个传动杆之间传递转动，同时保持转向以及速度不变。你也可以手持传动杆右键单击传送带的任意位置来添加一根旋转轴，这时，你就可以通过这根传动杆来将其他的组件连接到传送带上。传送带也可以用来运输物品，参考 [[这一页|Belts]] 来获取更多信息。

手持方块放置器

填坑，搭墙，替换墙面，规划路线，特定样式放置方块，...
这一用途广泛的方块放置器可以帮助你完成各式各样的工作。


手持方块放置器 可以放置以及替换一定范围内的方块，同时它还有着高自定义性以及可升级性。



  • 首先，[左键单击] 一个在你周围的方块，将其选中为放置材料。
    方块放置器会尝试使用你所选定的方块进行接下来的放置以及替换方块的工作。

  • 潜行时[右键单击] 方块放置器，可以打开它的配置界面。
    在这里你可以调整方块放置器的工作（放置/替换）模式，生效区域，放置样式，以及其它的一些设置。

  • 当你配置好了你的方块放置器，只需关闭配置界面， [右键点击] 一定范围内的方块，
    你就可以替换这一方块，或者在这个方块上放置另一个方块。


配置


" alt="配置" />


将鼠标悬停在各个按钮上，你可以查看这一按钮的用途。




  • 替换模式 切换，控制这一方块放置器是否为替换方块模式，就像是一些mod的方块替换器一样。
    当开启时，被方块放置器射出的光线击中表面的方块，会被替换为方块放置器图标左边的方块。
    关闭时，方块放置器只会简单地向外拓展这一表面，在这一表面上放置方块。

    注意：当替换模式启用后，方块放置器会破坏替换前的方块，这些方块将会以掉落物的形式出现。如果你升级了方块放置器的 机体，你就可以替换那些硬度更高的方块了。




  • 如果 对角线延伸 按钮被启用，且方块放置器有一个可生效的区域，
    那些只是在对角线上相邻的方块也会被算作是一个表面。




  • 如果 忽视材料分界 按钮被启用，且方块放置器有一个可生效的区域，
    同一面但种类不同的方块会被算作一个相同的表面。




  • 在 延伸范围 上滑动[滚轮]，可以调整方块放置器生效的区域大小。
    注意：若没有升级方块放置器的 增大 部件，方块放置器一次性只能放置一个方块。




  • 样式 可以定义一些特定的条件，来控制方块放置器会在哪些方块上生效。
    在升级了方块放置器的生效范围后，样式功能将会发挥出惊人的效果。
    实心 是默认样式，它会在区域内的所有位置上生效。
    棋盘 样式会让方块放置器每隔一个方块生效一次，最终的效果看上去犹如一个棋盘。
    % 随机 会对区域内的每个方块进行随机选择是否生效的操作，有三种不同的几率供你选择、




升级


方块放置器有五种可供升级的选择：
(所有的配方都可以在JEI内查到，对着方块放置器按下 'U' 键即可。)



生效范围 (增大)


提升方块放置器一次性生效的方块数量。



  • 默认：最大生效范围为 1x1.

  • 黄铜升级：最大范围提升至 5x5 (3m 半径)  

  • 异彩化合物升级：最大范围提升至 13x13 (7m 半径)



速度 (加速)


提升每秒可射击次数，按住 [右键] 可以重复射击



  • 默认：每秒 ~2 次

  • 黄铜升级：每秒 ~3 次

  • 异彩化合物升级：每秒 ~10 次

    由于服务器延迟，测试结果可能会稍有不同



距离 (范围)


提升最远可操控的方块的距离



  • 默认： 最大距离为15m  

  • 黄铜升级：最大距离为30m  

  • 异彩化合物升级：最大距离为100m  



力量 (机体)


在 替换模式下，这一属性决定了放置器可以破坏的方块的最高硬度。



  • 默认： 最大可破坏硬度： 2 (泥土，木头，石头)

  • 黄铜升级：最大可破坏硬度： 5 (矿石，金属块)

  • 异彩化合物升级：任何东西都可以破坏 (黑曜石， ...)  


在创造模式下，任何方块都可以被替换。



方块采集 (回捡)


在 替换模式下，这一升级可以自动重定位掉落的物品位置。



  • 默认： 掉落物不会被重定位

  • 黄铜升级：掉落物会被重定位为玩家的位置

  • 异彩化合物升级：掉落物会被直接捡回玩家背包


创造模式下，替换模式不会产生掉落物。

在这个流程中，界面中的状态文本将显示当前进度以及潜在的问题：

    • "区块未加载" - 加农炮想要在未加载的区块放置方块，移动加农炮或者通过其他方式加载区块。




  • 正在运行 - 绿色指示灯，加农炮正在运行。





放置设置


" alt="" />


当你配置 蓝图加农炮 时，你可以通过界面中的选项来进行调整。
按住 Shift 可以获得这些选项的更详细信息。




  • 替换行为 - 左侧的 4 个按钮

    这些选项配置了 蓝图加农炮 在什么情况下可以替换世界中原有的方块。
    4 个按钮对应了 4 种不同的设置，通常在左边可以看到更详细的替换条件(除了 不要替换方块)



    1. 不要替换方块 - 最低的宽限度，如果在世界上已经存在方块，那么加农炮会跳过该位置。这样会用蓝图将原有区域掩埋，不会在地下或者表面放置方块。

    2. 用固体方块替换工作区域内的方块 - 加农炮会考虑是否替换世界上的固体方块，前提是在蓝图中该位置的方块也是固体方块。这将防止将 透明方块 （例如栅栏或者植物）放置在地下以及表面。

    3. 使用任何方块替换工作区域内的方块 （默认）- 有 用固体方块替换工作区域内的方块 一样的作用，并且不会使得固体方块被空气所替换。

    4. 用空气替换工作区域内的方块 - 有最后 2 个选项一样的作用，即使蓝图上的该位置没有方块，也会用空气替换在工作区域内的方块。这会清除在地下的蓝图的内部空间，同时也会导致在结构周围的地形就像被切掉了一样。




  • 跳过缺失的方块 - 第 2 组中的第 1 个按钮

    如果启用此选项，蓝图加农炮 就不会因为方块的缺失而暂停工作。
    它会跳过这个方块，继续下一个方块的放置。这可能会导致结构的某些部分未完成。
    这个选项有以下优点：



    • 过滤 - 如果你想省去结构中的某些方块，只要不在 蓝图加农炮 附近存放该材料，并启用 跳过缺失的方块 这个选项。注意：请确保其他材料的数量充足。

    • 分割工作负担 - 如果你想在大型结构上使用多个蓝图加农炮，请为每个加农炮都设置它不需要放置的方块，并按此在加农炮附近的箱子中提供所需材料。如果加农炮像这样分工合作，它们将会更快地完成结构的打印。
      确保所需材料的数量充足，没有加农炮要放置同一方块，以及所有大炮的蓝图都部署在同一位置。




  • 保护 Tile Entities - 第 2 组中的第 2 个按钮
    如果启用此选项，则加农炮 不 会替换任何有数据存储的方块（例如 箱子 熔炉）
    如果你要移除的地形里恰巧由这些物品组成，那么请禁用该选项。

提取器

提取器是一种高级的机械组件，它通常与机械动力的[[漏斗]]以及[[传输器]]一起搭配使用，是机械动力将物品移入和移出库存的物流系统的一部分。提取器用于在世界（库存）中提取物品，并将他们放置在传送带上。


使用方法


被动提取


提取器可以放置在存储方块的任意一侧，例如[[可调节板条箱]]，也可以放置在 [[黄铜机壳]] 包裹的 [[传送带]] 的侧面或者底部。提取器将自动从相邻的库存中提取物品并将其放置在提取器所在的方块空间中。


如果一个运动的传送带在这个方块空间（指提取器所在的方块空间）下，那么这些物品将会与其他物品一样，被传送带所运输。


过滤提取


提取器有一个过滤槽，可以在其中放置任意物品，从而将提取器设置成仅在相邻库存中提取指定的物品。或者，你可以通过在过滤槽中放置过滤器或者属性过滤器来更加精确的从相邻库存中提取指定的物品。


改变齿轮转速

仅仅有组件的旋转是远远不够的，有时需要对旋转速度进行更多的控制。特别是对于那些需要 最低旋转速度 的机器（比如说搅拌器）来说尤为重要J。可以借助一些具有 加速 或者 减速 能力的方块来实现这一点。

当与连携齿轮箱一起使用可调节连携齿轮箱时，可以比齿轮更好地控制传送带的速度。可以提高与之相连的传送带的 输入 速度，也可以减少与传送带相连的传动杆的 输出 速度。


当作为一个输入源使用时，可调节连携齿轮箱会基于所收到的模拟红石信号来增加与之相连的传送带的速度。当收到 15 格的满格信号时，将会使得传送带以原来的两倍速运行，当收到小于 15 强度的信号时，则会在 1x - 2x 中按比例增加传送带的转速。<br>
" alt="" />


当作为一个输出源使用时，可调节连携齿轮箱基于所收到的模拟红石信号来减缓与之相连的传送带的速度。当收到 15 格的满格信号时，将会使得传送带以原来的半速运行，当收到小于 15 强度的信号时，则会在 0.5x - 1x 中按比例减缓传送带的转速。<br>
" alt="" />


当没有动力时，可调节连携齿轮箱不会影响传送带的速度，并会以普通连携齿轮箱一样存在。


转速控制器


尽管需要更多的材料来制作，但转速控制器是控制速度的最好方法。当一个大齿轮放置在转速控制器的顶部时，它会根据滚动条中设置的转速进行旋转。当你按住 Shift 进行滚动时，速度会 1格1格地增长/减少。

应力 & 容量


在Create 0.2+中，以一种高度简化的，类似于扭矩的方式使得旋转动力得到了一些平衡。


应力产生装置的应力容量是有限的。 "应力消耗" 和 "应力增加"是动力学系统中两个相对的值： 产能器提供能量,机器和部件消耗能量 如果应力消耗殆尽，与其连接的所有机器都将停止工作，直到应力增加或者应力消耗得到缓解才会继续工作
应力的改变量与其转速相关增加组件速度会按成比例地增加其应力或容量。


可以参考以下的示例：
假设一个水车可以提供刚好足够的动力来驱动四个相同速度的风扇



  • 如果使用齿轮将风扇的速度增加一倍会使风扇风力更强，但整个能量网络会停止，直到你将风扇数量减半或水车数量增加一倍，能量网络才会重新运作。

  • 与之相类似，你能够以同样的水车驱动八个以原来的一半速度运行的风扇。


默认来说，组件只能用于 传递 旋转动力，像传动轴和齿轮就一点都不会有 应力影响。这使得你可以简单的对你装置所需的应力产生装置的数量进行预计，因此不会导致你的流水线有产能过剩的情况出现。
所以，你可以较为科学的对应力影响以及在基础速度下的整个机器网络中的应力容量进行优化。如果你对更详细的信息有兴趣，可以查看[[这个网页|Stress Units, Capacity and Impact#SU and Speed]]

漏斗

漏斗是一种高级的机械组件，它通常与机械动力的[[提取器]]以及[[传输器]]一起使用，是机械动力将物品移入和移出库存的物流系统的一部分。漏斗可以从世界以及传送带中收集物品，并将其放入相邻的库存中。


用法


被动收集


漏斗可以放置在存储方块的任意一侧，例如[[可调节板条箱]]。漏斗会将其所在的方块空间中符合条件的物品自动放入相邻的库存中。

过滤收集


漏斗有一个过滤槽，可以在其中放置任意物品，从而将漏斗设置成仅收集指定的物品。或者，可以将 [[过滤器]] 或者 属性过滤器 放在过滤槽中来更加精确的控制漏斗收集与不收集的物品。也可以将其运用于 批量处理，这样就可以使得物品在没被处理前不会被漏斗收集。

鼓风机

鼓风机是机械动力中一个重要的机械组件。可以用来移动实体和物品，也可以作为应力产生装置而使用。于此同时，大批量的洗涤、熔炼以及烟熏也少不了鼓风机的参与。


推与拉


当链接到 旋转动力 时，鼓风机会在面前的几个方块产生气流，并且根据旋转方向决定是推还是拉动实体以及物品。


大量物品处理


当鼓风机的气流通过[水](<a href="http://minecraft.gamepedia.com/Water" target="_blank">http://minecraft.gamepedia.com/Water</a>)，[岩浆](<a href="http://minecraft.gamepedia.com/Lava" target="_blank">http://minecraft.gamepedia.com/Lava</a>)，或者[火焰](<a href="http://minecraft.gamepedia.com/Fire" target="_blank">http://minecraft.gamepedia.com/Fire</a>)时，相关方块下游的气流将会根据特定的配方处理通过的物品。包含水的气流将应用洗涤配方，包含岩浆的气流将像[熔炉](<a href="http://minecraft.gamepedia.com/Furnace" target="_blank">http://minecraft.gamepedia.com/Furnace</a>)一样冶炼物品，但不会应用[烟熏炉](<a href="http://minecraft.gamepedia.com/Smoker" target="_blank">http://minecraft.gamepedia.com/Smoker</a>)的配方。包含火的气流将像[烟熏炉](<a href="http://minecraft.gamepedia.com/Smoker" target="_blank">http://minecraft.gamepedia.com/Smoker</a>)一样熏制食物。 这些配方都可以在[[传送带]]上的物品应用。


警告： 如果你将不存在冶炼配方中的物品进行冶炼（例如工具以及烟熏食品），这些物品将会被 焚烧。如果你不小心将错误的物品进行冶炼，这将会导致灾难性的后果，又或者说你只是把这个当做一个垃圾桶来处理物品。过滤器可以帮助控制需要进行冶炼的物品。


产生应力


将鼓风机正面朝下面对热源 (火焰，岩浆，[熔岩块](<a href="http://minecraft.gamepedia.com/Magma" target="_blank">http://minecraft.gamepedia.com/Magma</a>)，或者一个 [营火](<a href="http://minecraft.gamepedia.com/Campfire" target="_blank">http://minecraft.gamepedia.com/Campfire</a>)) 并由 [红石](<a href="http://minecraft.gamepedia.com/Redstone" target="_blank">http://minecraft.gamepedia.com/Redstone</a>) 驱动。那么鼓风机就会以 16 RPM 输出 32 SU 的旋转动力。如果鼓风机与加上 1 个[羊毛](<a href="http://minecraft.gamepedia.com/Wool" target="_blank">http://minecraft.gamepedia.com/Wool</a>)的[[动力轴承]]相连，那么这将变成机械动力中最紧凑的产生应力的装置。


齿轮

齿轮 是机械动力中传递转动的最基本的机械组件。当两个齿轮相邻时，如果给任一齿轮提供 旋转动力，那么这个力也会被传递到与之相邻的齿轮上。


大齿轮 是较大的齿轮，可以在转角处传递旋转，以及被[[转速控制器|转速控制器]]催动。


使用方法


连接组件


齿轮有三种主要的链接方法：



  • 可以在两个相邻方块的同一朝向的面上放置两个小齿轮。这样，当向一个齿轮提供旋转动力时，另一个齿轮将会以相同速度但不同方向进行旋转。

  • 可以在同一方块的相邻面上放置两个大齿轮，这样可以在转角处传递旋转动力。如上所述，速度不会改变，但方向会相反。请注意，若在三个相邻面都放置大齿轮将会导致整个系统无法旋转。

  • 可以将小齿轮放在大齿轮的对角来改变转速。


除了使用齿轮传递旋转动力以外，也可以像使用[[传动杆]]一样使用齿轮，从而可以将机械组件通过齿轮相连。当然，这也可以用于在同一轴上连接多个齿轮。


调整速度


使用前文所提到的使用小齿轮和大齿轮的对角相连从而改变速度的机制，组件的速度可以容易地加倍或减半。这对于一些需要最低转速的机器，如 [[动力搅拌器]] 而言，是非常有效的。你可以通过重复地沿用上文提到的机制来轻易的改变转速。只要你没超过机械动力的转速极限 256RPM ，你就可以轻易地将转速加快一倍或者减缓一半。


或者你可以通过将大齿轮连接到一个[[转速控制器]]来准确的控制转速。
