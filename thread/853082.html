作者: Chelover_C60    时间: 2019-3-26 21:59
在询问命令相关问题是最好附上版本
1.12及之前需要用到标签，因为无法使用目标选择器指定拥有nbt的实体，比并且需要大量的命令方块组
  1. /scoreboard players tag @e[type=item] add diamond {Item:{id:"minecraft:diamond",Count:9b}}
  2. /scoreboard players tag @e[type=item] add nether_star {Item:{id:"minecraft:nether_star",Count:1b}}
  3. /execute @e[tag=diamond] ~ ~ ~ execute @e[tag=nether_star,r=1] ~ ~ ~ entitydata @s {Item:{id:command_block}}
  4. /execute @e[tag=nether_star] ~ ~ ~ kill @e[tag=diamond,r=1]
  5. /scoreboard players tag @e remove nether_star
  6. /scoreboard players tag @e remove diamond
复制代码

1.13可以只用一个命令，放进循环保持激活命令方块即可
  1. /execute as @e[type=item,nbt={Item:{id:"minecraft:diamond",Count:9b}}] at @s if entity @e[type=item,nbt={Item:{id:"minecraft:nether_star",Count:1b}}] store success entity @s Age short 6000 run data merge entity @e[distance=..1,type=item,nbt={Item:{id:"minecraft:nether_star",Count:1b}},limit=1] {Item:{id:command_block}}
