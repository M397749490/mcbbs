最近下了一个curse整合包，把它解压就有manifest.json，modlist.html，overrides文件夹，然后就发现可以在这个基础上改下做自己的整合这个是某个整合包的manifest.json，打开后改下大概就这个格式：(这样做有点麻烦）
  1. {
  2. "minecraft": {
  3. "version": "1.12.2",
  4. "modLoaders": [
  5. {
  6. "id": "forge-14.23.5.2807",（forge版本，可以改）
  7. "primary": true
  8. }
  9. ]
  10. },
  11. "manifestType": "minecraftModpack",
  12. "manifestVersion": 1,
  13. "name": "整合包名称（可以中文）",
  14. "version": "1.2.3（整合包版本）",
  15. "author": "作者",
复制代码
假如要整合包下journeymap这个mod
打开curseforge会看到右边有这样的列表
projectID填mod右边的项目 ID

关于此项目
项目 ID 32274
已创建 20 2008年9月 2011
上次发布的文件 22 11月 2018
总下载量 44,077,244
许可证 All Rights Reserved


那么这个projectID就填32274
而fileID填写那个mod打开其中一个版本网址最后那些数字
比如这个文件https://minecraft.curseforge.com ... eymap/files/2640111，fileID就填2640111
modlist.html这个文件测试没有也许可行，用HMCL测试可以认出，我没用mmc和twitch启动器测试，所以不确定
不过有些mod没有发布在curseforge，所以要预留在overrides文件夹里
而HQM任务配置，魔改，服务器的配置也在里面

我就做了一个简单的curse整合包
