顺便再翻译一下指令怎么样？

  • /lottery <page> - scroll through commands
  • /lottery [addtopot/atp] <lottery name> <money> - add money to the pot of a lottery
  • /lottery config reload - reload config
  • /lottery create <lottery names> - create a section for a lottery in the config
  • /lottery draw <lottery name> - force draw a lottery
  • /lottery info <lottery name> - receive information for a lottery
  • /lottery list <page> - list lotteries in a page
  • /lottery list <config|name|pot|time> <page> - list lotteries in a page user a filter
  • /lottery load <lottery names> - load a lottery
  • /lottery load - load unloaded lotteries
  • /lottery reload <lottery names> - reload specific lottery
  • /lottery reloadall - reload all lotteries
  • /lottery reward <player> <lottery name> <x tickets> - reward a user tickets for a lottery
  • /lottery save - force save lotteries
  • /lottery unload <lottery name> <delete> - unload a lottery
  • /lottery update - check for plugin updates
  • /lottery version - get plugin version
  • /lottery winners - list past lottery winners
  • /lottery buy <lottery name> <x tickets> - buy a ticket for a lottery
  • /lottery claim - claim a reward
  • /lottery guic - open the gui.
  • /lottery guic <lottery name> - opens a lottery creator in the gui.
