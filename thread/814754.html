特点
3.5版本只兼容1.11-1.14
兼容旧版本请下载旧版本的插件
这个插件可以在你关闭箱子后自动整理箱子,每个玩家都可以用/chestsort指令来开关这一功能.
但玩家需要chestsort.use权限才能使用该指令.
如果有权限的话,玩家登录后第一次打开箱子会有信息提示如何使用这个功能
现已支持自动整理背包物品

指令
/chestsort 或 /sort  ——启用或关闭自动整理箱子
/invsort 或 /isort

整理玩家背包（不包括快捷栏）.


/invsort hotbar 或 /isort hotbar

整理玩家快捷栏物品.


/invsort all 或 /isort all

整理玩家背包和快捷栏物品.




权限


chestsort.use
允许使用自动整理箱子和/chestsort 指令

chestsort.use.inventory
允许使用/invsort 指令来整理背包

热键
鼠标中键

在任意格子内点击即可触发


潜行点击

在空格子内按下潜行键（默认Shift）+左击 触发


双击

在空格子内双击触发


潜行右击

在空格子内按下潜行键（默认Shift）+右击 触发





第三方插件
CrackShot

所有CrackShot的武器会被自动分组并放入默认武器分类.


InventoryPages

ChestSort会忽略 "下一页" 和 "上一页" 的按钮来以防破坏菜单.

  48. # 可用变量:
