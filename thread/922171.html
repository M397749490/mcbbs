LorinthsRpgMobs
简单的怪物编辑插件
插件简介
  • 这是一个简单的修改生物强度的插件,它可以根据生物距离重生点的距离来计算生物的强度。  (出生地可以自己设置1个或多个)

插件作用
  • 增加怪物的伤害/生命值
  • 可以根据等级给怪物装备武器或者护甲
  • 自定义怪物头顶的显示文本
  • 支持Worldguard区域单独配置怪物的属性
  • 自定义怪物身上的药水效果
  • 根据怪物的等级，配置不同的掉落物

插件的指令
  • /lrm - 显示指令的帮助信息.
  • /lrm butcher [radius] - 清除区域内的所有怪物.
  • /lrm region - 查看region的指令.
  • /lrm reload - 重载配置文件.
  • /lrm spawnpoint - 查看spawnpoint的指令.
  • /lrm update - 插件升级.

插件的权限
  • lrm.admin-管理员权限
  • lrm.butcher-允许运行清除怪物的指令
  • lrm.update-允许使用更新指令

插件兼容
  • Mob Hunting
  • Heroes
  • Skill API
  • MythicMobs
  • Health Bar
  • Mob Health
  • Elite Mobs
