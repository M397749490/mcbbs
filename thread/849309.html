                                                        DeathCrystal    死亡水晶

                                                                           一款轻量级的道具保护插件  BY：EhzXog


                                                             服务器玩家抱怨死亡后物品掉光?

                                                          直接开启死亡不掉落好像少了一点感觉，

                                                                   本插件将是你的最佳选择!
                                                        DeathCrystal 插件介绍
轻量级的自定义物品保护插件
  • 插件在玩家死亡時自动侦测背包中是否有死亡水晶，若有该道具則该次死亡不会掉落物品、装备、经验。
  • 可让死亡水晶通过挖掘方块几率获得，支持自定义方块、概率、数量等等。
  • 可让死亡水晶通过击杀生物取得，支持自定义生物类型、概率、数量等等。
  • 可自定义死亡水晶模型，名称以及说明。


                    图片儿：






指令：
    /deathcrystal help - 插件帮助
    /deathcrystal give <玩家> <数量> - 给予指定玩家死亡水晶，不输入玩家默认为自己   
    /deathcrystal reload - 重新载入插件
权限：
    dc.admin - 所有权限。默认op

配置文件详解
#死亡水晶的外观
item: Diamond
#是否启用附魔效果
enchantEFX: true
#每次死亡保护消耗的数量，如果不想消耗则设置为0
amount: 1
#不启用死亡水晶的世界
disable-world:
- world_nether
- world_the_end
#从方块掉落
drop-from-block:
#方块种类
  Diamond_Ore:
  #是否启用此方块
    enable: false
    #掉落概率
    chance: 50
    #最少掉落数量
    min-amount: 1
    #最多掉落数量
    max-amount: 4
    #掉落水晶时触发的音效
    sound: ENTITY_PLAYER_LEVELUP
    #是否只在生存模式下掉落
    survival-only: true
    #是否允许使用精准采集时也掉落
    allow-silk-touch: false
  Diamond_Block:
    enable: false
    chance: 50
    min-amount: 1
    max-amount: 1
    sound: ''
    survival-only: true
    allow-silk-touch: false
#从生物掉落
drop-from-mob:
#生物种类
  Zombie:
    enable: false
    chance: 50
    min-amount: 1
    max-amount: 4
    sound: ENTITY_PLAYER_LEVELUP
    #是否只有在玩家击杀该生物时掉落（若设定为false无论那种死亡都会进行掉落）
    player-only: true
  Creeper:
    enable: false
    chance: 50
    min-amount: 1
    max-amount: 2
    sound: ''
    player-only: true
