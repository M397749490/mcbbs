AcidWater
此插件作者为PetteriM1

此插件是一款酸水(雨)插件，当玩家碰到

水或者是雨的时候，会自动给予玩家中毒效果

其持续时间，药水等级，开关按钮均可在配置文件上定义.

配置文件

  1. #开启酸雨
  2. acid-rain: true
  3. #开启酸水
  4. acid-water: true

  6. #酸性持续时间(刻)
  7. acid-duration-ticks: 60
  8. #检测遇酸延迟(刻)
  9. acid-check-ticks: 20

  11. #中毒效果强度,0似乎是中毒I
  12. effect-amplifier: 0
  13. #可见效果
  14. effect-visible: true
