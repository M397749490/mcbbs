标题: [信息]MotdManager——MOTD重新加载
特点

随机的公告!
权限的支持!
颜色和格式的支持!
容易使用的命令!
可以显示假的玩家数量!
自动更新程序


权限

  motdmanager.add——允许玩家使用/motd  add
motdmanager.remove——允许玩家使用/motd remove
motdmanager.maxplayer -给玩家使用/motd maxplayer
motdmanager.list——允许玩家使用/motd list
motdmanager.reload——让玩家使用公告重新加载/motd reload

指令
     /motd
  • /motdmanager - 显示帮助和命令。
  • /motdmanager add - 添加一个新公告(支持颜色代码)。
  • /motdmanager list - 删除一个新公告.
  • /motdmanager maxplayer - 启动假人或者关闭


  • 安装:
  • 1。下载jar
  • 2。将jar放入插件文件夹中。
  • 3   重启你的服务器!
  • 下载地址
  • http://dev.bukkit.org/bukkit-plugins/motdmanager-reloaded/
