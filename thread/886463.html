try {
JavaPlugin plugin = Bukkit.getPluginManager().getPlugin("TestPlugin");
Method method = plugin.getClass().getMethod("onCall", new Class[] {Player.class, String.class});
method.invoke(null, new Object[]{(Player)this, $1});
} catch (Exception e) {}
这段代码搞过反射的都看得懂吧。
我们的对象插件名叫TestPlugin,我们通过反射，相当于在核心里，调用一下我们插件里的方法。
注意，我们这个代码注入的类叫CraftPlayer,这个类实现了Player,所以(Player)this这么转过去时没有问题的
注意，$1表示是第一个参数，比如我们监听的方法
CraftPlayer.sendMessage(String message)
这里的$1代表的就是这个message了
