/stats block ~ ~ ~1 set QueryResult @a time
再放一个命令方块高频，填
/time query daytime

你并没有说明，你的游戏时间指的是什么时间，
1、day：游戏内的游玩天数（你在这个存档里经历了几天）
2、daytime：一天内的时间（从00:00:00 到 23:59:59，也就是从 0 到 23999）
3、gametime：这个存档一共的游玩时间，从进入存档开始，每在存档里呆一秒，这个值+20。
