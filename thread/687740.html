EpicWorldGenerator
生成更贴近现实的地形,让玩家体验冒险的乐趣~
功能
类似于生成器的插件,主要功能用于生成地形,可以自行控制矿物密度等
安装
1.[下载安装]下载插件本体后放入服务器plugins文件夹后重启即可
生成方式①[不同的世界生成插件指令请一一对照]
[MultiWorld]/mw create <新世界名称> normal
[Multiverse-Core]/mv create <新世界名称> NORMAL
生成方式②
注意,如果您想除了手动创建的世界以外,其余世界均为原版世界,请按照以下步骤修改
  1. 1.打开EpicWorldGenerator配置文件夹
  2. 2.找到settings.json
  3. 3.用Notepadd打开并搜索forceBukkitGeneratorAPI,并将后面改为true
  4. 4.随后重启服务器
复制代码
手动创建EWG世界的指令同生成方式①一样
命令
/ewg createworld <世界名称> - 列出该世界的所有配置,选择一个后将会自动安装.[慎用]

1.您不可以下载后剽窃为自己的作品,更不可以用于商业出售等
2.购买后Spigotmc官方将无法退款,请慎重选择购买
3.楼主本人只是介绍插件,若出现不按正规渠道购买而被骗的问题本人概不负责
