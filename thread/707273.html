前言
之前开服需要个能对权限限时的插件, 但找了几个不适合我的服务器, 大多不支持UUID, 所以我花了大概2周之间做了这个插件
配合点券商店, 实现点券购买VIP(权限及物品), 氪金服的好选择!
本插件支持 1.7.10-1.12 大部分服务器, 1.9以下的服务端可能需要把中文配置进行转码, 也可以下载帖子后面的语言文件。
功能/特性
  • 可在配置文件中编辑权限包(可含有多个权限组和多个权限)
  • 时间可以累加
  • 支持UUID
  • 添加、设置、移除-命令执行失败时自动记录, 方便事后有据可依
  • 支持多世界权限(需要权限插件支持)
  • 支持mysql保存数据
  • 支持跨服
  • gui显示自己的权限包
  • 权限包到期可执行自定义命令(支持PlaceholderApi变量)
  • 等等...

权限
权限用途默认权限归属
permissionstime.*插件的全部权限.op默认拥有.
permissionstime.me查看你自己拥有的权限包.玩家默认拥有.
permissionstime.packages查看服务器拥有权限包的权限.op默认拥有.
permissionstime.get查看玩家拥有的权限包.op默认拥有.
permissionstime.give给予玩家权限包使用时间的权限.op默认拥有.
permissionstime.set重置玩家权限包使用时间的权限.op默认拥有.
permissionstime.remove删除玩家的某个权限包的权限.op默认拥有.
permissionstime.removeall删除玩家的所有权限包的权限.op默认拥有.
permissionstime.reload重载配置的权限.op默认拥有.
命令
好多人都说命令太长, 其实是有别名的, 请使用 /pt
命令用途
/permissionstime查看全部命令
/permissionstime me查看你自己拥有的权限包.
/permissionstime packages [权限包名]查看服务器拥有的权限包(输入第二个参数可以查看该权限包的详细信息).
/permissionstime get<玩家名>查看玩家拥有的权限包.
/permissionstime give <玩家> <权限包名> <时间> <单位:d或h或m>给玩家某个权限包一定时间的使用时间. 时间单位: d=天, h=小时, m=分钟
/permissionstime set <玩家> <权限包名> <时间> <单位:d或h或m>重置玩家某个权限包一定时间的使用时间. 时间单位: d=天, h=小时, m=分钟
/permissionstime remove <玩家名> <权限包名> [是否删除跨服权限 是:t 否:f]删除玩家的某个权限包.
/permissionstime removeall <玩家名> [是否删除跨服权限 是:t 否:f]删除玩家的所有权限包.
/permissionstime reload重载配置.

已知问题(作者提醒)
  • 如果插件不能正常工作,如1.7.10版本配置文件需要改成ANSI编码。
  • 如果出现问题一般退出服务器重进就能解决。
  • 插件重载不会重置在线玩家的权限, 如有必要请重启服务器。
  • 玩家每次登陆会重置权限包涉及的权限。请不要单独给予玩家涉及的权限。
  • 服务器关闭时, 插件被禁用的顺序不一, 会导致玩家有权限留存。 如果配置的权限包删掉原来设置的权限(或修改世界), 会导致插件无法清理原有的权限及权限组。(你可以配置一个不使用的权限包, 权限包内含有你想清理的权限及权限组即可。)
