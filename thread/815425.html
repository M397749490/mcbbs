前言
mcbbs内有不少职业插件，有些可以自己配置自己改，有些是固定的，今天教大家怎么样使用三个插件来制作一个自己的职业插件，为PVP添加玩法
对于大部分RPG腐竹来说，职业插件有可能是你服务器重要的玩法，所以如果开RPG的或者开生存服的腐竹们可以看看

可能有人说：好好的弄一个职业插件不就行了，为什么要这么麻烦自己弄
楼主：其实我是想分享一下另外一个制作职业插件的方法，让大家知道 ：喔~原来职业插件还能这样弄的



插件准备工作
制作原创职业插件需要准备三个插件
楼主已经为你们准备好下载链接了
Chestcommands钟表菜单插件:点我你最棒
RPGitemsRPG武器制作插件:点我你最棒
Groupmanager权限组插件:点我你最棒



需要的知识
明人不说暗话,你只要懂权限组的配置，RPGitem的制作方式，懂得编辑菜单
就足够你制作这个职业插件了
虽然说是插件，但其实根本就不是pwp
只是三个插件结合发展出来的新玩法
再次提醒！不是插件
但因为方便介绍，我在下文都把这个玩法称为'职业插件'

职业玩法的制作原理

菜单插件就不用解释了，是职业插件的GUI页面，里面可以让玩家购买职业
购买职业技能，查看其它职业等

到RPGitem插件，这个是用于职业插件的各种技能制作，这个大家就懂了吧

再来是权限组插件，如果玩家pvp的时候把全部职业的技能都放一遍那岂不是要爆炸
权限组插件就可以避免这个问题
打个比方，玩家1的职业是剑士，他只能使用剑士的技能，其他的例如法师的用不了
当他切换成法师的时候才能使用法师的技能，而这时候剑士的技能他就用不了了


开始工作

开始工作前，我先介绍一下，本次教学我会分开三个部分去教学，以插件为分类
先从最简单的groupmanager开始，然后到rpgitem，最后用chestcommand打包


GroupManager

前面说过，Groupmanager是用来控制玩家选择哪个职业就只能使用哪个职业的技能
所以Groupmanager的准备很简单,下面为大家准备了几个例子

#那么我就需要准备好以下的几个权限节点
#玩家使用该职业的权限
jobs.jianshi.use
#玩家选择该职业的权限
jobs.jianshi.own
#玩家使用该职业的权限
jobs.fashi.use
#玩家选择该职业的权限
jobs.fashi.own
#玩家使用该职业的权限
jobs.lieshou.use
#玩家选择该职业的权限
jobs.lieshou.own


RPGitems
手把手教学
假如说我想创作一个 剑士的1技能
#创建职业物品
/rpgitem 剑士1 create
#更改展示出来的名字(自己喜欢什么就改什么)
/rpgitem 剑士1 display &c&l利刃突刺
#更改技能的显示的物品
/rpgitem 剑士1 item 341            (改成粘液球)
#修改该物品的伤害(技能就是技能，怎么可能让释放技能的法杖有伤害呢，那样谁还要买武器2333)
/rpgitem 剑士1 damage 0
#修改技能的手持名称(可自定义)
/rpgitem 剑士1 hand &e&l>>&9剑士的一技能
#修改技能的类型(可自定义)
/rpgitem 剑士1 type &9&l技能
#添加技能
#我以利刃突刺技能为例
#该技能右键可以向前突进五格
#冷却10秒
#大家可以自己选择喜欢的技能
#详情前往rpgitem的教学贴查看
/rpgitem 剑士1 power teleport 200 5
#隐藏技能的描述避免混乱
/rpgitem 剑士1 togglePowerlore
#为技能添加描述(可自定义)
/rpgitem 剑士1 description add &f&l剑士短暂集气后向前突刺五格，冷却10秒
#到最最最重要的部分了,前面说过我们要使得选择了剑士的人只能使用剑士的技能
#这时候我们就要为技能添加上使用权限
#至于这个权限有什么用，到chestcommand配置的时候会说明
/rpgitem 剑士1 permision jobs.jianshi.use true
