这个插件不支持1.8的新生物！


Supported Entites - 支持实体
Bat, Creeper, Skeleton, Ocelot, Wolf, Slime, MagmaCube, Blaze, CaveSpider,
Chicken, Cow, Enderman, Ghast, Giant, Horse, IronGolem, Minecart, MinecartChest,
MinecartFurnace, MinecartTnT, MushroomCow, Pig, PigZombie, Sheep,
Silverfish, Snowman, Squid, Villager, Witch, Wither, Zombie, Spider.


Commands - 命令

- 权限 -
/Description: Main command
/Permission: mmim.command
这两个权限都最好不要给玩家吧..
召唤出来的生物死亡后是会掉物品的

下面这些命令不管怎么用都是一样的！
估计是作者怕跟别的插件冲突吧...
主命令：/mobsmountinmobs
次命令： /mobsmountinmobs - /mm, /mobsmount, /mobsm,
/mmount, /mmim, /mmm, /mobsmim, /mmountim, /mmimobs

- 例子 -
/mobsmountinmobs <Mob1> <Mob2>
Description: used to mount mobs
- 查看支持实体 -
/mobsmountinmobs <list/supported>
Description: used to list supported entities



当你把<Mod1>设置成蝙蝠时..你会发现..~
