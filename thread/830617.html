非常感谢，问一哈，我的世界正版启动器和和其他启动器有什么区别

1. 正版启动器通常都能正常地启动比较新的游戏版本，
     而其他启动器不一定，或者需要更新启动器本身。
2. 正版启动器下载游戏的下载源一定是 Mojang 官方，而其他启动器可能还提供别的下载源。
    例如 HMCL 启动器提供 bangbang93 的 BMCL 下载源、Curse 提供的下载源等。
3. 就启动 MC 以外的功能而言，其他启动器一般还带有更新 Forge、Liteloader 等的功能。
    而正版启动器没有。
4. 官方启动器可以接收 Mojang 方面的 MC 新闻和更换正版皮肤，而其他启动器一般不能。
5. 某些特殊的启动器具有自己的特别功能。
    比如 MultiMC 启动器允许多个 MC 游戏公用一套资源文件来节省硬盘空间，
    这一点正版启动器和不少其他启动器都做不到。

真的非常感谢，还有一个，怎么更新JAVA版本

按步骤来就可以了。
1. 首先，右键 点击开始按钮，弹出菜单最上面一个就是“应用与功能”。
2. 点击打开“应用与功能”，在页面正中间有个“搜索此列表”搜索框，在框中输入 java 按回车。
3. 如果出现了 Java，将它们全部右键点击，选择卸载，跳转第 6 步。
    如果没有出现 Java，展开以下内容。
4.

    手动找到你的 Java 装在了哪儿，将 Java 所在的文件夹整个删掉。
    你可以从启动器中复制 Java 的路径，按下 Windows 徽标键+ R 键打开“运行”窗口，
    将路径粘贴进去，删掉 javaw.exe 然后按回车，就可以找到 Java 的路径。
5. 再打开运行窗口，输入
  1. regedit
复制代码

    按回车，打开注册表管理器，依次打开 HKEY_LOCAL_MACHINE 和 SOFTWARE 两个文件夹，
    然后把文件夹中名字带有 Java 的文件夹全部删除，然后重启电脑。

这两部操作有风险性，即使操作完也不一定能保证 Java 被彻底删除，
并不推荐这样做，以后也千万不要用什么游戏盒子来装 Minecraft，因为绿色版 Java 太糟糕了。


6. 点击 https://java.com/zh_CN/ ，点击“免费 Java 下载”，就可以下载到 Java 的安装包，
    点击打开，安装即可。
    安装过程中，为保险起见，关掉所有的其他程序。安装成功后，可以考虑重启一下电脑。
7. 至此 Java 安装全部完成。
