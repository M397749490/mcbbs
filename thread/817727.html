作者: SPGoding    时间: 2018-8-27 19:31
本帖最后由 SPGoding 于 2018-8-27 19:53 编辑

execute as @a at @s if entity @s[y=-2,dy=-100000000] run kill @s
杀死所有在虚空的玩家。
至于为什么从 -2 开始，因为玩家的坐标基准点在脚上，玩家在虚空的时候坐标差不多是 -2。
至于为什么把选择器放在 execute at 后面，因为当指定 y 以后，命令系统会自动把 x z 的值代为执行位置，如果不用 execute at 指定执行位置很可能会出现意外情况。不过用 x dx z dz 指定全范围也不是不行，但那样选择器太长不好看。
至于为什么要把选择器写在前面的 if entity，不然 run 后面命令太长很难看，这样只需要在后面用 @s 指代虚空玩家即可。
