这里是computercraft的发布贴：http://www.minecraftforum.net/topic/892282-11-computercraft-121/

安装好后打开\.minecraft\mods\ComputerCraft\lua\rom\programs

新建一个文本文档，并输入以下代码
  1. pw = "7198"

  3. write "Password: "
  4. input = read()
  5. if pw == input then
  6.   print "Welcome..."

  8.   redstone.setOutput("back",true)
  9.   sleep(3)
  10.   redstone.setOutput("back",false)

  12. else
  13.   print "Incorrect Password "
  14.   os.shutdown()

  16. end
复制代码
  1. pw = "7198"
复制代码
引号内就是正确的密码，可以随便改（只要游戏中打得出）

  1. redstone.setOutput("back",true)
  2.   sleep(3)
  3.   redstone.setOutput("back",false)
复制代码
这控制输入密码后激活哪边的红石和红石亮的时间


然后保存，去除后缀名，这个文件的名字就是密码门的指令

进游戏后右键电脑，输入文件名就可以了，再输入密码就可以了
