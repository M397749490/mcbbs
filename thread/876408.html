介绍
这款插件添加了新的机制、物品和工具来增加原版的生存机制。

入门
首先，木制和金制工具都被删除了。



所以没有木制工具你如何生存?

不要害怕, 这些新物品可以让你活下去。



理解工具用法


  • 用手砍树? 别想了. 你必须使用一把 短柄斧或斧头 才能破坏任何木制方块。
  • 空手挖土? 也别想了. 你必须使用铲子才能挖掘泥土或沙子。
  • 挖石头? 你必须使用鹤嘴锄或镐子。
  • 收获水果或蔬菜? 你必须使用镰刀来收割。
  • 割羊毛?你必须使用剪刀。
  • 放置人造方块? 你必须副手装备锤子才能放置。
生存发展
首先你要找点树. 破坏叶子来获得树苗合成木棍。
  • 树叶有25%的几率掉落1根木棍。



接下来找点沙砾以收集燧石。
  • 沙砾有 50% 的几率掉落一个燧石，可空手破坏
沙砾一般在湖泊、溪流、高山、洞穴和悬崖附近生成。

如果你找不到沙砾，你也可以这样合成:



现在你可以制作短柄斧了。



使用短柄斧来砍木头，将木头合成为模板和木棍。

现在你可以制作鹤嘴锄了。



然后找一些 石头. 现在你无法破坏石头，你需要合成铲子。

想要合成工作台,你需要合成最后一样工具： 锤子



锤子用于制作 工作台 和 建造人工方块.(详情如下)

获取武器
你可以选择使用石剑或小刀来作为你的基础武器。

小刀 可给予击中的目标中毒效果,但造成的伤害更少。



从牛和羊身上获取皮革和线

口渴度
如果你渴了,请合成一个碗来装水, 右键水源后你就可以获得一碗水。

喝水可以止渴, 但喝炼药锅里的纯净水效果更佳。

合成
之后你可以这样合成工作台:



你可以用工作台来将你的工具升级为石制工具。

使用铲子挖掘沙砾更加高效。



我们需要更深入一些
想要去探索地底世界? 你需要火把。

但首先你需要打火石才能点燃火把。





和原版的打火石一样，你可以用于烤肉、熔炼物品。

但耐久只有8. 右击地面来生火。

潜行+右击可以进行熔炼。



步骤:
  • 将未熔炼或生肉放入熔炼格内。
  • 点击右边的格子获取。
  • 点击打火石或ESC退出该页面。
熔炼配方:

任何可煮熟的食物



木炭



玻璃



红砖



想要合成熔炉,你需要深入了解。

破坏粘土方块来获得粘土或这样合成:



用打火石将粘土烤成红砖,这是合成熔炉的必备材料。



熔炉合成配方：



现在你可以使用熔炉来熔炼物品了。

定居
是时候建个房子了,确认工作台在你身边。

合成一些箱子来存储你的物品。



使用锤子建造房屋更加方便. 所有人工合成的方块都只能使用锤子来放置。



副手手持锤子，主手手持方块，你可以开始建造房屋了!

每个已放置的方块都有10%的几率减少锤子1点耐久度。

安装
安装插件
首先将SurvivalPlus.jar扔到你的服务器文件夹内, 开启服务器并让插件生成文件夹. 最好在一个新开的服务器安装这款插件. 如果你已经开服,那么玩家已获得的资源可能就会破坏这款插件的游戏体验.
设置配置文件
完成插件安装后你可以打开插件的 config.yml 进行配置. 你可以开关特定的游戏机制和合成配方. 确认你已认真阅读配置wiki来让你理解配置.
特别提醒:
  • 最好在你完成设置配置后不要再进行更改.
更改语言文件
你可以打开 lang_EN.yml 更改为你想要的语言.
语言文件包括了大多数自定义物品的名称和描述.
战利品表
强烈推荐编辑你的服务器的 战利品表. 战利品表包含了如原版村庄生成的箱子里的战利品，同时也包括怪物掉落的物品. 我推荐删除本插件已经删除的战利品 (比如木制、金质工具). 你可可以在插件配置里看到本插件更改了战利品表，你也可以手动修改。 我将稍后再wiki内进行详细的介绍.
最后一步
最后一步是分配权限. 你不需要处理很多权限, 你的玩家也不需要什么特殊的权限才能使用这款插件.
完成
完成以上步骤后, 你就应该可以正常使用SurvivalPlus了


配置

默认配置
你可以按照以下步骤关闭插件的一些特性:
1) 打开plugins/SurvivalPlus
2) 打开config.yml
3) 完成编辑后保存文件并重载.
让我们看看 config.yml
  1. MultiWorld:
  2.   EnableResourcePack: true
  3.   ResourcePackURL: <link here> #你可以在配置内找到地址
  4.   NotifyMessage: true
复制代码

插件使用了自定义的资源包. 你不需要更改任何内容.如果你关闭了资源包,那么玩家就看不到自定义工具和物品的材质了. 如果你的服务器已经使用了自定义的资源包，你可以下载本插件的资源包并合并资源包并在配置内关闭使用资源包．
消息提醒可以让玩家知道玩家必须在登录时知道服务器使用了资源包．
  1. LocalChatDist: -1
复制代码

LocalChatDist 为默认的玩家聊天范围.
默认关闭. (n = -1)
更改数值:
- n = -1 : 关闭本地聊天
- n = 0 : 自言自语
- n > 0 : 与指定范围内的玩家聊天

复制代码

Survival-Enabled - 启用插件的大量全新的生存机制. 关闭这些则会移除插件的一些工具如镰刀、短柄斧等的功能.
LimitedCrafting - 启用这些后玩家只能合成已解锁配方的物品.
BreakOnlyWith - 这一选项会阻止不使用正确工具挖掘方块的玩家破坏方块.
PlaceOnlyWith - 启用这一项会让玩家只能在副手手持锤子的情况下才能进行建筑.
DropRate - 掉率决定了挖掘沙砾掉落燧石、挖掘树叶掉落木棍的几率.
Torch - 替换原版的火把合成配方.
