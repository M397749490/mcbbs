我刚才全部看了一遍  有些怪点有怪 有些没有 我感觉是怪物刷新设置的问题 还请大佬给一个正确的设置方式  ...


1例子：/mm spawners create 怪物名称 刷怪点名称  创建刷挂点（鼠标指向的地方哦）
2例子：/mm s set 怪物名称  cooldown 30    死亡后 30秒复活
3例子：/mm s set 怪物名称  healonleash true 设立怪物离开刷新点范围后是否回血？ 可以无视 也可以加上
4例子：/mm s set 怪物名称  leashrange 15  设置怪物可以离开生成点多远15就差不多
5例子：/mm s set 怪物名称  maxmobs 1  设置刷怪点最大刷怪数量 一次性只刷1个
6例子：/mm s set 怪物名称  radius 1 在你的刷怪点 复活
7例子：/mm spawners copy 刷怪点名字 刷怪点名字2，这个是复制这个刷怪点的 指令 用于批量安放刷怪点
按着我的一步步来100%设置好  如果你怪物配置也没错的话
