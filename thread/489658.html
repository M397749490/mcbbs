⊙我在使用修为果插件时候,发现一个BUG,穿着加血的装备吃,血量是加加血装备的血量+修为加的血量所以我果断放弃了,删掉了修为果插件！
⊙之后我又找到了HealthPlus配合RPGitem做了一个生命果,又郁闷的是,不知道为什么只要玩家死一次就加三心,玩家疯狂自杀最后血量刷到了800多！{:10_501:}最后又删了
{:10_523:}所以我找到了他DakadoHealth{:10_523:}

指令:
/dhp help:
☆查看帮助

/dhp buy <数量>
☆花钱购买最大血量，可以在config里设置一心的价格！(需要前置vault)

/dhp increase <玩家> <数量> (需要插件2.7版本以上才有此命令)
☆查看玩家增加了多少最大血量？原话：Adds player's max health.

/dhp add <玩家> <数量> (需要插件2.7版本以上才有此命令)
☆为此玩家增加多少最大血量

/dhp set <玩家> <数量>
☆设置玩家的最大血量为 <数量>

/hp <玩家>
☆查看此玩家的血量与最大血量

/dhp reset <玩家>
☆重置玩家的最大血量

/dhp reload
☆重载配置
权限:
hp.help ------ 查看帮助的权限
hp.buy ------ 购买血量的权限
hp.increase ------ XXX的权限(不懂)
hp.decrease ------ XXX的权限(不懂)
hp.check ------ XXX的权限(不懂)
hp.hp ------ 增加血量的权限
hp.hp.others ------ 给别人增加血量的权限
hp.reset ------ 重置别人血量的权限
hp.set ------ 设置血量的权限
hp.heal.others ------ XXX的权限(不懂)
