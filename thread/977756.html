Reply
关键词回复
功能:
  • 指定关键词问答
  • 模糊与精准问答之分
  • 撤回玩家说的带关键词的话
  • 触碰关键词可禁言该玩家
  • 易懂的配置文件

配置文件与使用方法:
config.yml
  1. ####################################
  2. #         欢迎使用Reply            #
  3. #全局变量:                         #
  4. #  '#'——换行符                     #
  5. #关键词子功能:                     #
  6. #  撤回: true——让玩家说的话无法发出#
  7. #  禁言:                           #
  8. #    time: 10 ——禁言玩家10秒       #
  9. #  音效: 'xx' ——回复时提示音效     #
  10. ####################################
  11. Message:
  12.   #{time}——禁言的时间
  13.   禁言提示: '&c小老弟你说了违禁词,禁言&a{time}&c秒'
  14.   #{time}——禁言计时
  15.   禁言中: '&c禁言中还剩&a{time}&c秒解禁'
  16.   #{模糊数量}——模糊词条的数量。{精准数量}——精准词条的数量。#——换行符
  17.   重载提示: '&e&l重载成功#&e&l已更新模糊词条&a{模糊数量}&e&l个#&e&l已更新精准词条&a{精准数量}&e&l个'
  18. Reply:
  19.   精准列表:
  20.     wdnmd:
  21.       问: 'wdnmd'
  22.       答: '栽种，爬'
  23.     help:
  24.       问: '服务器怎么玩'
  25.       答: '&c&l服务器玩法:#&axxxxx#&axxxxx#&axxxxx'
  26.       撤回: true
  27.       音效: 'ENTITY_PLAYER_LEVELUP'
  28.   模糊列表:
  29.     1:
  30.       问: '垃圾服务器'
  31.       答: '&c垃圾你ma呢？'
  32.       撤回: true
  33.       禁言:
  34.         time: 10
复制代码
模糊词条:  举个简单的例子,在模糊列表添加一个关键词为玄的然后在聊天栏输入：玄月 他也会触发这个词条。
精准词条:  玩家输入的词必须和配置文件词条一模一样，例如关键词是wdnmd如果玩家输入wdnmd啊啊啊啊 是不会触发的。
