——功能——

  是不是还在为传送而烦恼？  没关系，让看似不起眼的小钟表来解决问题，ClockCommand能把没用的钟变成万能的菜单！
  • 把杂乱的功能堆积在一起
  • 走到哪带到哪，方便携带
——安装及使用方法——

1.把插件下载好，丢入plugins文件夹内
2.使用插件把ClockCommand载入服务器或重启服务器
3.照下面说的方法配置
4.输入“/cc”重载插件
5.大功告成啦！
——指令——
  
/cc     重置配置文件

——权限——
  
无，默认是所有人都可以打开和点击钟表菜单的物品，但执行每个物品背后的指令是需要对应指令的权限的

——配置——

CC:
#没卵用
  config:
#没卵用
    navigation-id: 347
#开启菜单用到的物品的ID，比如这里的347是钟表的代码，所以默认打开菜单的工具是钟表
    inventory-name: '&9&l服务器菜单'
#菜单顶上显示的名称
  Commands:
#按键列表
    Hub:
#物品项目名（只是在配置里而已，在游戏中是看不到的）
      item-name: '&9&l传送到主城'
#鼠标移到按键上显示的名称
      item-command: <player>/spawn
#点击按键后使用的指令
      item-id: 120
#按键对应的物品ID，例如这里的“120”是末影传送门的ID
      item-id-number: 0
#上面所说的物品ID附加值（具体看物品代码表了，后面的2啊，3啊就是附加值）
往下还可以继续依此类推添加，只要前面的物品项目名（例如这里示例的“Hub”）不重复就行。注意啦，有些同学把物品项目名以外的东东修改了，如“&9&l”改成了“&8&l”...唉，惨（wo）不（dou）忍（xiao）睹（pen）啊（le）！下面有一个例子，自己参考一下吧！

例：
CC:
  config:
    navigation-id: 347
    inventory-name: '&9&l[服务器]指令菜单'
  Commands:
    Hub:
      item-name: '&9&l领取新手礼包'
      item-command: <player>/kit Tools
      item-id: 130
      item-id-number: 0
    XXX：（不与已有的重复就行，比如说上面有Hub了，下面就不能用了，很多人就是挂在这个地方）
      item-name: '&9&l（不要管）传送到生存'
      item-command: <player>/res tp sc
      item-id: 2
      item-id-number: 0
推荐用Notepad++修改，修改后记得保存。
