AdvancedColorSigns
简单粗暴 没有介绍 2.3KB的轻量级插件 丢入服务器直接使用
可以在服务器的牌子内使用颜色代码例如 &e &c 这种
授权搬运



权限节点
AdvancedColorSigns.create.ColorSign - 使用颜色写入的权限
如果想让全体玩家都能用&那么丢到[ruby=（以ESS举例）]default组[/ruby]里去就是了



使用方法
首先你要放一个牌子 然后输入颜色代码即可
  1. # 颜色变量列表
  2. # &0 黑
  3. # &1 蓝黑
  4. # &2 深绿色
  5. # &3 深蓝
  6. # &4 暗红
  7. # &5 深紫
  8. # &6 金
  9. # &7 灰
  10. # &8 深灰
  11. # &9 INDIGO
  12. # &A 绿~~
  13. # &B 蓝
  14. # &C 红
  15. # &D 粉
  16. # &E 黄
  17. # &F 白
  18. # &M 划除
  19. # &N 下划线
  20. # &L 加深
  21. # &K 随机
  22. # &O 斜体
  23. # &r 重设&r后的颜色符号
  24. #大小写并没有关系
