服务器是1.15.2版本的，人多的时候很卡，人少不卡，试用过站内的G1收集器方法和https://www.mcbbs.net/thread-839828-1-1.html，服务器并没有得到TPS改善，反而延迟峰值更高更卡
站内优化帖已经看过很多了。推荐一些干货呗？下面是我目前用的启动参数，我感觉只用 -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseFastAccessorMethods 这三个都比一长串要好很多
  1. @echo OFF　
  2. set c=-1
  3. :start
  4. set /a c+=1
  5. title Inirial Release(%c%)
  6. java -server -D64 -Xmx5200M -Xms5200M -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseFastAccessorMethods -XX:+UseG1GC -XX:+UnlockExperimentalVMOptions -XX:MaxGCPauseMillis=100 -XX:+DisableExplicitGC -XX:TargetSurvivorRatio=90 -XX:G1NewSizePercent=40 -XX:G1MaxNewSizePercent=60 -XX:G1MixedGCLiveThresholdPercent=35 -XX:+AlwaysPreTouch -XX:+ParallelRefProcEnabled -Dusing.aikars.flags=mcflags.emc.gs -jar paperclip.jar
  7. goto start
  8. pause
