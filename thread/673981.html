EditableSign

懒人必备，快速改牌子

0.这东西有什么用？

原版Minecraft中，如果告示牌写错了，则只能破坏重新放置（NBT党：你过来！）

然而这东西可以免除破坏牌子的麻烦！

1.食用EditableSign的正确姿势

丢进plugins文件夹，然后你们都懂...

2.如何修改？

潜行状态下右击牌子。（必须在有对应权限并且WorldGuard说OK的时候才可以）

3.命令/配置文件/权限列表

/es - 切换可/不可编辑模式

/es help - 帮助大法！

/es reload - 重载插件

editablesign.edit - 允许玩家编辑告示牌

editablesign.colorsign - 允许玩家在告示牌中加入颜色代码

editablesign.bypass - [默认管理员]跳过冷却时间

editablesign.<世界名> - 允许玩家在指定世界使用编辑牌子功能





  2. # 插件挂了就发送这个
  3. ErrorMessage : "&c [ES] : 看起来有点问题。"
  4. # 想要使用WordGuard保护，打开它
  5. WorldGuard: true
  6. # 牌子冷却时间（指的是牌子被编辑后对牌子生效的冷却），输入0为关闭
  7. SignCoolDown: 0
  8. # 冷却时间，输入0为关闭
  9. WriteCoolDown: 0
