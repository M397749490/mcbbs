· 简介
这个插件可以说是基础插件之一
可以做到指定世界指定物品指定方式
下载该插件优先修改配置文件！
插件暂不支持MOD物品和*，下一个版本会支持，大概在三天后发布
配置方法均在配置文件中有写

BanItem is a simple lightweight & configurable per world ban item plugin. The main goal of the plugin is to disable specifics blocks in specifics worlds.


· 指令/权限
· 指令
   - /banitem reload 重载配置文件（可能存在一秒不到的卡顿）
   - /banitem info 查看手中物品的信息（包括物品英文ID和与该物品相关的权限）
· 权限
   - banitem.bypass.[worldname].* 有权限的玩家可以在该指定世界绕过所有禁止的物品
   - banitem.bypass.[worldname].[materialName] 有权限的玩家可以在指定世界绕过对指定物品的禁止

    • banitem.bypass.* - bypass the banitem in all worlds (default: OP)
      • banitem.bypass.[worldname].*
      • banitem.bypass.[worldname].[materialName]
    • banitem.command.* - give access to /banitem command (default: OP)
      • banitem.command.reload
      • banitem.command.info

    You have 2 commands:
    • /banitem reload: to reload config.yml
    • /banitem info: to get information about the current item in your hand (for example the material name to put in config.yml)

  7. # -- Informations: --
  8. #   - Blacklist contains list of blocked items
  9. #   - Whitelist contains list of allowed items only, so the following options are blocked:
  10. #      - Placing, breaking, picking up, dropping & interacting with the banned item
  11. #   - Worlds can be written single 'world', multiple 'world, world_the_end', or you can include all worlds with '*'
  12. #   - Options can be written single 'break', multiple 'break, place' or you can include all options with '*'
  13. #
  14. # Blacklist: block ...
  15. # - place: when the item is placed
  16. # - break: when the item is breaked
  17. # - pickup: when the item is picked up
  18. # - drop: when the item is dropped
  19. # - interact: when the player use right click with main hand on the placed item
  20. # - use: when the player use right click with the item in the main hand
  21. # - creative: applies only if the player is in creative mode
  22. # - inventory: when the player try to take/put the item from/in an inventory
  23. #
  24. # Whitelist: allow ...
  25. # - place: place the item
  26. # - break: break the item
  27. # - pickup: pick up the item
  28. # - drop: drop the item

  30. # - use: when the player use right click with the item in the main hand
  31. # - inventory: when the player try to take/put the item from/in an inventory

  33. # No permission message (for /banitem)
  34. no-permission: '&cYou do not have permission.'
