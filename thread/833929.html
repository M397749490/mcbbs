CustomLevelsExp

自定义等级经验




该插件是因为朋友和我说他在用这个插件（http://www.mcbbs.net/thread-637794-1-1.html），但是这个插件在跨服后会导致服务器卡死，于是我帮他重写了一份。

插件功能：
使用数据库记录的经验值
游戏内可见的等级缩放（同时支持1.7和1.8的两种经验缩放）
使用公式定义的每级经验

插件指令：
  1. /CustomLevelsExp exp - 显示你当前等级所持有的经验
  2. /CustomLevelsExp need - 显示你当前还需多少经验升级
  3. /CustomLevelsExp totalexp - 显示你总共有多少经验
  4. /CustomLevelsExp set XX [player] - 为某人设置经验为XX（留空为自己）
  5. /CustomLevelsExp set XXL [player] - 为某人设置等级为XX（留空为自己）
  6. /CustomLevelsExp give XX [player] - 给予某人XX经验（留空为自己）
  7. /CustomLevelsExp give XXL [player] - 给予某人XX等级（留空为自己）
复制代码


插件支持PlaceholderAPI，你可以使用以下字符串来显示对应数值：
  1. customlevel_need: 显示你当前还需多少经验升级
  2. customlevel_exp: 显示你当前等级拥有的经验
  3. customlevel_level: 显示你的当前等级
  4. customlevel_totalexp: 显示你的总经验
