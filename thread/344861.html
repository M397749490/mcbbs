标题: 如何限制OP的权限
例如gamemode，give等OP本来有权使用的指令，现在希望取消这些权限（对所有OP生效），该如何操作
无需具体指令，只要告诉我该改动什么或者去除哪个组的权限
作者: 温柔的微笑    时间: 2014-9-28 19:10
我记得   admin  这个权限组的权限 和 op 一模一样 , 把要弄的 op  加入这个权限组即可,需要去掉什么权限 直接去掉这个权限组的权限就ok了~
作者: a8105    时间: 2014-9-28 20:05
/manuadd ID admin

/mangaddp admin -essentials.give
/mangaddp admin -essentials.gamemode
作者: 云闪    时间: 2014-9-28 22:45
groupmanager插件配置文件里面有一个将op设为完全权限的选项，取消它就可以像普通玩家一样限制op的权限了
作者: 筒子    时间: 2014-9-29 09:46
先/manuaddp 玩家名字  -groupmanager.*
这样他就没有权限去修改权限组了，如果不禁止的话OP可以自己给自己权限的
禁止完了然后
/manuaddp 玩家名字 -essentials.give
/manuaddp 玩家名字 -essentials.gamemode
