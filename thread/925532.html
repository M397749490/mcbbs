预置使用说明（内附教程链接，使用该预设包前请仔细阅读！）
1、本预设适用于Blender 2.79或2.8x，C4D不支持该预设包。
2、在大多数情况下，如果文件名没有特殊说明，即代表同时适用于Blender2.79和Blender2.8x，有特殊说明的已经在文件名中说明了，按照对应的版本导入即可。部分模型（比如僵尸等人形模型）在2.8x里会出现Bug，请直接使用2.8x的人物模型导入相应生物的皮肤使用。
3、如何导入人物模型？选择"文件"->“追加…”，找到模型，比如“BSS Character Rig V3 - 2.8 Version .blend”人物模型，找到“Collection”文件夹，双击“BSS RIG V3 APPEND”即可导入。
4、导入BSS Character Rig V3 - 2.8 Version .blend人物模型时会出现一堆额外的物体，请在导入之后直接按删除键（X键+确认或者直接DEL键都可以）即可，剩下的就是人物模型了。
5、如何修改BSS Character Rig V3 - 2.8 Version .blend人物模型的皮肤？请看上面的视频。
6、人物模型默认显示单层皮肤，双层皮肤需要拖动控制器来实现，具体操作方法见下。
7、如何导入其他模型？和上面相同的步骤，不过导入的不是“Collection”，而是"Object"文件夹，进入之后找到自己需要的模型即可导入（可以按住Ctrl或Shift多选）；有一些包含骨骼的模型（比如箱子，活塞什么的），需要将物体和骨骼一起导入才能实现骨骼的效果（比如箱子打开，活塞推拉等动作）。
8、使用该预制包时遇到了问题欢迎前往BOXSCAPE STUDIOS的Discord频道询问（链接在上面），或者在这个贴下留言，私信我都可以，我会尽力向官方反馈问题的。
9、该预设包里的人物模型详细介绍现已推出，点击这里来查看。
10、如果你认为该预制包还不错的话，可以考虑回复或者评分支持一下，感谢您的支持！
