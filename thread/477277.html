国外知名派系公会插件



什么是Factions？

这个插件是一个为服务器玩家服务的插件，为玩家提供了一个“占山为王”，成立自己的组织的平台，领导者可以自由决定派系成员的去留。派系之间也可以开战或结盟，让我们为财富和领地而战！





怎么安装Factions？

1.关闭服务器

2.下载Massive core并拖入plugins文件夹

3.将本插件拖入plugins文件夹

4.重启服务器





配置文件

官网提到，在大多数情况下，默认的配置可以保证此插件在服务器上正常工作，所以配置文件没有必要做修改，实在有需要的可以访问官网提供的配置文件查看详情点我访问




指令

1.概述
  1. /f 基本指令
  2. /f l,list [page=1] 列出所有派系
  3. /f f,faction [faction=you] 派系信息
  4. /f p,player [player=you] 派系成员信息
  5. /f join <faction> [player=you] 加入派系
  6. /f leave 离开派系
  7. /f home [faction=you] 传送回派系基地
  8. /f map [on/off=once] 派系版图
  9. /f status [page=1] [faction=you] 查看成员是否在
复制代码
2.创建
  1. /f create <name> 创建一个派系
  2. /f name <new name> 重命名派系
  3. /f desc <desc> 更改派系介绍
  4. /f motd [new=read] 更改派系motd
  5. /f sethome [faction=you] 设置派系基地
  6. /f unsethome [faction=you] 取消派系基地
复制代码
3.随从

  1. /f inv,invite <player> [yes/no=toggle] 是否可以邀请成员加入
  2. /f kick <player> 踢出玩家
  3. /f title <player> <title> 设置公会玩家头衔
  4. /f promote <player> 提升玩家
  5. /f demote <player> 降级玩家
  6. /f officer <player> 设置玩家官职
  7. /f leader <player> [faction=you] 设置玩家为派系领导
复制代码
4.资产
  1. /f money b,balance [faction=you] 查看派系资产
  2. /f money d,deposit <数量> [faction=you]  贡献资产
  3. /f money w,withdraw <数量> [faction=you]  取出资产
  4. /f money ff <数量> <factionA> <factionB> 由派系A到派系B
  5. /f money fp <amount> <faction> <player> 由派系到玩家
  6. /f money pf <amount> <player> <faction> 由玩家到派系
复制代码

5.领地
  1. /f sc/seechunk 查看你所在区块
  2. /f claim o/one 将一个区块划入领地
  3. /f claim a/auto 将走过的地方划入领地
  4. /f claim f/fill 填充领地
  5. /f claim s/square [半径=1] 将半径1的正方形以内的区块划入领地（我认为这里的半径是指正方形的半个边长）
  6. /f claim c/circle [半径=1] 将半径1的圆以内的区块划入领地
  7. /f claim all <all|map> <公会> <新公会> 吞并公会领地

  9. 下面这些指令与上面的对应且作用相反

  11. /f unclaim unclaim
  12. /f unclaim o/one
  13. /f unclaim a/auto
  14. /f unclaim f/fill
  15. /f unclaim s/square [半径]
  16. /f unclaim c/circle [半径]
  17. /f unclaim all <all|map> <公会>

  19. /f access 管理访问记录
  20. /f access v/view 管理访问记录
  21. /f access p/player <player> [yes/no] 玩家是否可以访问
  22. /f access f,faction <公会> [yes/no] 公会是否可以访问
复制代码
6.关系
  1. /f ally <公会>  与另一个公会联盟
  2. /f truce <公会>  与另一个公会休战
  3. /f neutral <公会>  对另一个公会中立
  4. /f enemy <公会> 对另一个公会宣战
复制代码
派系与派系间默认关系是中立的，这可以通过指令修改，结盟与休战是相互影响的，但宣战是单方面的，如果有人想成为你的敌人，你就必须接招。

7.权限
  1. /f perm set [perm=all] [relation=read] [yes/no=read]
复制代码

首先，一个派系的领导可以使用/f perm命令查看某人可以再这个派系中做什么，任何人都可以用/f perm show或/f perm show yourfaction查看派系的权限配置，使用/f perm show <faction> <perm> 来查看一个指定的权限，例如/f prem show <faction> build 就可以显示build权限在派系中的配置情况。最后两个参数[relation]是指关系状态，例如宣战，休战，中立等，举个例子/f perm set lever truce yes 便是允许在休战时在派系领地上使用拉杆。

8.flags
  1. /f flag [faction=you] [flag=all] [yes/no=read]
复制代码

首先，flag是一个Boolean，只有yes或no，任何玩家可以使用/f flag 派系名字查看派系的flag。并不是所有的flag都可以修改。第一次使用建议使用/f flag safezone 和/f flag warzone，这些flag可以让他们在一些特殊情况下工作。

9.admin
  1. /f admin [on/off=flip] 管理员模式，不受任何限制
  2. /f disband [faction=you]  在管理员模式下，强行解散某派系
  3. /f powerboost <p|f|player|faction> <name> <#>可以给一个派系或玩家额外的权力
  4. /f v,version 显示插件版本

帮我解答下 为什么2.8.3版的连配置文件都找不到了 究竟隐藏到哪里去了

配置文件放在服务器根目录的mstore文件夹里！而不是插件目录，里面全部是用的json方式储存，
factions_faction  文件夹是派系的列表，所以派系的全是用的加密的文件名，打开后就能找到相应的派系
这个文件夹里默认有3个系统自带领地，
warzone是战场
safezone是安全区域，也就是主城，你可以开启管理模式加入这个派系，然后圈地主城
none是野外，所有玩家默认在这个里面
factions_mconf文件夹是配置文件所在。可以看楼主发的配置文件官方说明
factions_mflag文件夹是相应的派系flag的信息文件，里面的json可以汉化，
factions_mperm这个文件夹也可以汉化
factions_mplayer这个文件夹是玩家列表的，一般新玩家会自动生成一个玩家
然后其他的文件夹是哪个前置插件的配置文件夹了，
