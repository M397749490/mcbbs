FoodMC
在MC中定制你的食物



简介
FoodMC是史上第一款可以创建食物的插件
它允许管理员创建任何他们想要的食物，随意定制
你可以控制这些食物的食用权限，外观，效果，甚至音效
非常强大
官方开发团队表示 他们还会解决你在使用过程中遇到的任何困难

/foodmc - foodmc.command - 主菜单
/foodmc list - foodmc.list - 列出所有食物
/foodmc manage <参数> - foodmc.manage - 管理所有的食物
/foodmc info - foodmc.info - 插件信息
/foodmc troubleshoot - foodmc.troubleshoot - 检修故障
/foodmc menu - foodmc.menu - 打开菜单（应该是GUI菜单）
/foodmc reload - foodmc.reload - 重载配置文件
/foodmc give <Player> <Food> <数量> - foodmc.give - 给某个玩家指定数量的指定食物
注意：使用 /foodmc命令时，如果<Food>参数（食品名称）单词数量超过一个（也就是中间有空格）时，应该用“_”
来代替空格，例如“Rotten Eggs”在使用的时候应该写成"Rotten_Eggs"

怎么新增一个独一无二的食物
第一步 - 选择外观 （本步骤建议开启VPS进行）
到 这里 选中一个心仪的“头”（外观是由带皮肤的头颅实现的），左键单击它，会自动将命令复制到剪贴板
如果无法自动粘贴（我用Chorme就无法粘贴，刚刚发现解决办法），请访问 这里 直接复制编辑框内全部的内容
然后到 这里  ，把复制到的文本粘贴到那个编辑框中，点击提交
然后顶部的 URL后面会显示出一个连接，复制
到"foods.yml"中，把复制到的东西粘贴到 "link"项后面
对其他选项按照例子进行修改润色
重启服务器（必须重启，不能reload，也不要使用插件管理如YUM和PluginMan等进行重载）

API
  1. Food food = FoodManager.getFood(name);
  2. food.anyMethod();

  4. FoodManager.getFoods(); - Get all of the foods
