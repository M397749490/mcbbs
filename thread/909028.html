标题: 利用 批处理文件(.bat) 在同一个.minecraft文件夹中同时支持多个不同的整合包
本帖最后由 common 于 2019-8-28 19:10 编辑

当你自制或下载了一个大型整合包，想要调整mod，该怎么办？将 .jar 文件剪切\粘贴 入\出 mods 文件夹。但是，如果你想要两个甚至至多个不同的整合包，该怎么办？复制一份.minecraft的上级文件夹？还是版本分离？但是，不管是复制.minecraft的上级文件夹还是版本分离，都带来了一个问题——数据一致性。例如 当你升级mod版本的时候，你需要在多个不同的文件夹中更新 .jar 文件，当你修改配置文件的时候，你需要在多个文件夹中修改，当你写MT/CT脚本，你需要把脚本文件复制到多个文件夹。总之，所有更新数据的操作，在你拥有两个甚至多个不同的整合包的时候，都会乘二甚至乘n。
当你有一堆可选择的优化/配置MC的mod的时候(例如AIImprovements BetterPlacement BetterSprinting Bloodmoon HardCoreDarkness ClassicCombat fencejumper等)，当你因为某些原因(比如玩某些地图时禁用所有对战斗增幅/调整的mod)而要禁用一些mod，原来的方法是手动将所有要禁用的mod找出来放到其他地方，但很容易漏掉一些，导致玩了一段时间才发现，还要关掉MC调整mod后重启。

看了一下启动器版，发现貌似没有拥有这个功能的启动器，于是本着 不屈 不挠 不作 不死心 的精神，选择了 windows 自带的批处理文件(.bat)功能(在linux /mac下有类似的sh脚本)，通过在mods和一个闲置mod文件夹(modl)之间移动.jar文件的方式，实现了自动将需要的mod放入mods文件夹的功能

下面是脚本教程


禁用所有mod.bat
  1. set disknow=%~d0
  2. rem 注释：获取盘符存入disknow备用

  4. set pathnow=%cd%
  5. rem 注释：获取当前路径存入pathnow备用

  7. set modspath=%pathnow%\.minecraft\mods
  8. rem 注释：计算mods文件夹路径存入modspath备用

  10. set modlpath=%pathnow%\.minecraft\modl
  11. rem 注释：计算modl文件夹路径存入modlpath备用

  13. %disknow%
  14. rem 注释：调用disknow切换到当前驱动器

  16. move "%modspath%\*.*" "%modlpath%"
  17. rem 注释：将mods文件夹中的所有文件放入modl文件夹

  19. cd %modspath%
  20. rem 注释：调用modspath切换到mods文件夹

  22. for /D %%i in (*) do move %%i "%modlpath%"
  23. rem 注释：将mods文件夹中的所有子文件夹放入modl文件夹

  25. pause
  26. rem 注释：执行完毕，暂停以查看查看结果和排查错误，不想暂停的可以删除pause这一行

自定义名称.bat
  1. call 【需要先执行的其他批处理文件文件名1，含.bat后缀】
  2. call 【需要先执行的其他批处理文件文件名2，含.bat后缀】

  4. set pathnow=%cd%
  5. rem 注释：获取当前路径存入pathnow备用

  7. set modspath=%pathnow%\.minecraft\mods
  8. rem 注释：计算mods文件夹路径存入modspath备用

  11. rem 注释：计算modl文件夹路径存入modlpath备用

  13. rem 注释：三行set语句必须在所有move语句之前，否则move语句找不到路径

  15. move "%modlpath%\【需要启用的MOD文件名1，包含.jar后缀】" "%modspath%"
  16. move "%modlpath%\【需要启用的MOD文件名2，包含.jar后缀】" "%modspath%"

  18. pause
  19. rem 注释：执行完毕，暂停以查看查看结果和排查错误，不想暂停的可以删除pause这一行
复制代码


包含move语句的脚本必须在所有move语句之前有那三句set语句，否则找不到路径
用这个模板的批处理文件管理mod，需要一个非版本分离的MC，将所有脚本文件放到与.minecraft文件夹同一个目录下，将中文中括号【】内的内容连同中括号一起替换为你需要的内容。将所有的mod分组，分别放入 各自的分组.bat 比如，启用战斗辅助mod.bat 启用信息助手类mod.bat 启用科技类mod.bat 启用魔法类mod.bat 启用性能优化mod.bat 启用生存辅助mod.bat

，然后通过 call调用其他批处理文件 的方式，将这些模块组合成启动脚本
比如
启用基础mod.bat
  1. call 启用信息助手类mod.bat
  2. call 启用性能优化mod.bat
  3. call 启用原版微调mod.bat
复制代码
启用原版风格整合包.bat
  1. call 启用基础mod.bat
  2. call 启用战斗辅助mod.bat
复制代码
启用正常生存整合包.bat
  1. call 启用原版风格整合包.bat
  2. call 启用生存辅助mod.bat
  3. call 启用魔法类mod.bat
  4. call 启用科技类mod.bat
复制代码

当你的mod升级，改名，增加，删除的时候，直接修改对应的模块的move语句，这样不管这个模块有多少次调用，都只用修改一个地方
运行批处理文件，可以直接双击写好的.bat文件，当然，在执行前，要执行一次 禁用所有mod.bat 或者把 call 禁用所有mod.bat 语句放到顶层批处理文件的开头

修改脚本前，备份.minecraft文件夹，因为这是直接对文件系统操作，所以如果写错了可能把mod文件放到其他地方

这些脚本调用 windows系统的功能，所以与所有非强制版本隔离的启动器兼容，linux/mac 系统也可以利用.sh脚本实现类似的功能，只是脚本就要你自己写了，如果有谁提供了linux/mac系统用的脚本，可以私信或回复我，我会更新到帖子里
这些脚本基于win10系统，不清楚windows的批处理脚本语法是否有过改变，所以在win10以外的windows不一定能运行，出现这种问题，可以在脚本文件的最后一句加上 Pause 暂停以查看执行结果及是否报错，然后根据报错情况排查解决问题

这些脚本用到了.minecraft文件夹下modl文件夹作为中转，如果这个文件夹在你的.minecraft文件夹中已经存在并且有其他作用，可以将脚本中所有modl修改为其他用不到的文件夹

按照这个思路，不仅可以管理mod，还可以管理多个不同设置的配置文件，就不举例子了，可以自行修改脚本
核心思路是，利用批处理文件，将 替换文件 这一动作标准化，可以反复执行，组合调用，节省了时间，同时减少错误

我不会制作启动器，如果可以的话，启动器作者可以按照这个思路，将这个功能加入启动器
