很多开群组服的服务器服主都知道，群组服可以允许使用动态状态栏。
其实，不只是群组服可以动态状态栏，其实就算是非群组也可以的！
但直到现在，我都无法正常调配完毕该插件，计划暂时暂停，
以后会在这里公布非群租的插件转载帖的跳转~

插件介绍：

作者的话：After seeing all the plugins for bungee that allowed animated server icons and MOTD's I thought I'd do the community a favor and release a free one. Built off code by bigteddy98, this is also open source but is designed to be for anyone who has a server, not just developers.
翻译：当我看到跨服端的所有插件，允许服务器图标和公告的动画的时候，我想帮社区一个忙和发布一个免费的插件。bigteddy98给我打造了一份代码，这也是开源的，但被设计成任何服务器，不仅仅是开发人员。

总的来说，这个插件支持：
· 动态状态栏图标
· 动态状态栏文字
· 动态状态栏玩家列表
· 动态的玩家数量显示
· 可自行改变动态速度
· 支持动态编辑状态栏
   (可直接修改而不用关服)
· 支持多种变量显示
· 支持自行制作变量

但是，很多服主装了进去，却不会去进行安装。那么我们现在就来教导你们这个插件的配置方法~

好了，看到这个例子是不是心动了呢？
下面，让我来教你们如何去进行这种样子的编辑吧！
配置前的工作：

安装插件，并运行一次，然后关闭bungee
在plugins的目录里会生成一个AnimMOTD目录
进入后你会看到这些文件，我在下面会逐一解释

  • player-list-frames —— 玩家列表

在里面，你会看到有一个文件1.txt
打开后，里面居然是空的！
这些不要在意，因为本来就是空的。
(：玩我呢。。。)
这里需要自行进行设置
但，这个设置了的话，需要先关闭动态编辑
详情看config.yml文件配置
否则，将会永久报错无法显示！

好的，现在开始进行该文件的例子：在文件1.txt输入以下文字
  1. §a§lExample List
  2. §9§lJoin NOW!
复制代码
因为可以动态的说，只有这个不能显示动态呢，都是静止的！
那么，不用着急，新建一个文件，叫2.txt，再输入以下文字
  1. §2§lExample List
  2. §c§lJoin NOW!
复制代码
然后，你再打开看看？现在就会闪烁了！
。。。。。。
相信你们能看懂了对么？就是按照顺序，对每个list显示进行设置。
例如第一个list的文件名就是1.txt
第二个就是2.txt，第三个就是3.txt
但是，必须留意的是：如果你是输入到10.txt的话，它会重复显示1.txt的内容！
那么，该怎么办？不用担心，个位数不行，改两位就好，意思就是
第一个为01.txt，第二个为02.txt。。。。。。第99个为99.txt
（我想没这么多的人可以输入这么多吧？）


  • server-icon-frame —— 动态图标(多了个有s的不用理会)
这个文件夹，摆放的都是你的图标文件。
可以让这种图标也进行动态显示的！
只是，如果你不想让他出错，建议不要使用GIF
一律使用png，但是，也不要弄成动态png
你需要将你动态图标的各个样子截一个图，然后
像玩家列表那里一样，对图标进行一个个改名。
然后，就可以了~

补充：
图标大小建议64x64，128x128左右哦！
不符合标准都会导致显示错误或崩溃的~

  • variavles —— 变量目录
这个文件夹，摆放的是你制作的变量文件
官网虽然有下载链接，但是却没有任何文件
我也尝试制作过一个的，但是失败了。
这个文件夹不会对显示有任何的影响，可以无视。
（：你这是在偷懒对么？）

  • config.yml —— 插件基础配置文件
打开配置文件，你可以看到里面有五行的文字
现在我来给大家来一个个进行一下解释
update_delay: 300 #文字切换时间
AnimatePlayerList: false #玩家列表开关
AnimatePlayerCount: false #玩家数量开关
use_And_as_color_symbol: true #用"&"代替"§"
live_edit: true #动态编辑(可以不关bungee直接修改)
这些是针对状态显示的一些配置修改的！
注意：如果开启AnimatePlayerList，必须关闭live_edit，
否则状态显示将会报错，无法进行显示！

  • motd_line1.txt —— 动态motd第一行
  • motd_line2.txt —— 动态motd第二行
（：这个设置简单啦~跟上面的都一样对么？新建多几个副本啥的，你就告诉我用什么名字就好了~）
其实，你们这么想就错了，这个设置和上面的设置方式截然不同！
如果想获得上面例子的样子，你需要这么输入：
motd_line1.txt
  1. §4§l>>>§7§l>>     §c§lExample MOTD     §7§l<<§4§l<<<
  2.   §4§l>>>§7§l>>   §c§lExample MOTD   §7§l<<§4§l<<<  
  3.     §4§l>>>§7§l>> §c§lExample MOTD §7§l<<§4§l<<<   
复制代码

motd_line2.txt
  1. §b§l☆ §3§lMinigames§b§l/§c§lSurviavl§b§l/§d§lCreative §b§l☆
  2. §b§l☆ §a§lMinigames§b§l/§4§lSurviavl§b§l/§e§lCreative §b§l☆
  3. §b§l☆ §2§lMinigames§b§l/§f§lSurviavl§b§l/§6§lCreative §b§l☆
复制代码
然后，保存，你就可以获得像例子一样的
那样炫酷的MOTD显示啦~
各种都可以做出来的哦~


  • player_count.txt —— 玩家数量动态显示
该文件，可以修改玩家数量显示那个地方的文字哦~
（：嘛，就是在信号左边的那些数字对吧）
对，如果你想修改那部分的玩家数量显示文字
可以像motd_line那部分一样这么写哦~
例子的话，也很简单：
  1. §d玩家数量: §a%COUNT%§7/§C%MAX%
  2. §5玩家数量: §2%COUNT%§8/§4%MAX%
复制代码
（：弄进去，看人数，眼好花。。。）
