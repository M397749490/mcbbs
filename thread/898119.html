借助计分板，先给所有人分数记为0，再给有箭的玩家分数记为1，最后给分数为0的玩家箭即可

建立计分板
  1. scoreboard objectives add arrow dummy
复制代码

循环执行以下命令
  1. scoreboard players set @a arrow 0
  2. scoreboard players set @a arrow 1 {Inventory:[{id:"minecraft:arrow"}]}
  3. give @a[score_arrow=0] arrow

使用了弓后这个计分板的分数会增加，那么接下来我们得检验玩家身上是否没箭，检验方法，给玩家一个tag，比如

  1. /scoreboard players tag @a add usebow {Inventory:[{id:"arrow"}]}
  2. /scoreboard players tag @a add havebow {Inventory:[{id:"arrow",Count:1b}]}
复制代码


然后反选tag即可

这样只要背包里有一支箭的玩家都会拥有这个标签，那么想让玩家使用了弓之后如果没箭了就补充一支箭应该怎么做呢？
按照如下要求做：
（注意以下代码完全可以丢到函数里面直接执行）
  1. #↓放入循环命令方块，先不要保持开启
  2. scoreboard players tag @a add usebow {Inventory:[{id:"arrow"}]}
  3. #放入连锁命令方块，保持开启
  4. scoreboard players tag @a add havebow {Inventory:[{id:"arrow",Count:1b}]}
  5. #放入连锁命令方块，保持开启
  6. execute @a[score_usebow_min=1] ~ ~ ~ scoreboard players tag @s[tag=usebow] remove usebow
  7. #放入连锁命令方块，保持开启
  8. execute @a[score_usebow_min=1] ~ ~ ~ give @s[tag=!usebow] arrow 1 0
  9. #以上工作做完之后，把循环命令方块改为保持开启
