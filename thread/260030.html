[redstone_dust]Project HungerGames[redstone_dust]


[diamond_gem]前言：[diamond_gem]



这是个新出的饥饿游戏插件，目前的最高版本为0.6，这个插件有以下特性：

· 很多自定义设置（随机计算出生点，信息等）

· 获取获胜者列表

· 你可以使用你自己的地图，或者使用本插件生成一个。

· [这里有个游戏大厅！]

· 随机放置补给箱内物品（配置在箱子里你要生成什么物品）

· 广播随机信息（可配置）

更多特性请自行体验，这里就不多说了嘛=w=

[iron_ingot]配置文件：[iron_ingot]

VERSION:
EnableUpdater: 是否启用自动升级
EnableMetrics: 是否启动汇报指标
BugsReport:
  Enable: 是否启用BUG汇报
  Name: 你的名字
  Mail: 电子邮箱？
Maps:
  Folder: 地图所在文件夹。
  GameRules: 允许的游戏规则(比如：keepInventory)
  DefaultTime: 世界的固定时间。
  Generate:
    Enable: 是否启用生成器
    Name: 要生成的世界名字
  Borders:
    Enable: 是否添加世界边境
    Radius: 世界的边境半径
    Type: 有"INVISIBLE"（隐形）, "SQUARE"(矩形), "ROOFING"（屋顶）  "CYLINDER"（圆柱）四种类型。使用"INVISIBLE" 需要前置插件“worldedit”
    Material: 边境所用的方块ID，如果你在类型上面写了"INVISIBLE", 你可以选择跳过
    Meta: 边境所用方块的附加值(没有填0？还是省略？)
Lobby:
  World: 大厅所在的世界。
  Spawn:
    X: 出生点的X坐标。
    Y: 出生点的Y坐标。
    Z: 出生点的Z坐标。
  Countdown:
    Time: 达到最小玩家数目时开启游戏的延迟，比如一个躲猫猫地图需要4个人才能开始，这里填50就是说满4人，50秒后开始游戏
    ExpBarLevel: 把秒数显示在经验条上。
  Protect: If you want to prevent griefing on your lobby. Useless if you have WorldGuard or something like this.
Game:
  MinPlayers: 达到这里的最小玩家数就开始倒计时。
  MaxPlayers: 可加入的最大玩家数。
  SpawnDistance: 50
  AutoSneak: 是否启用“隐形人”(隐藏玩家ID标签).
  RandomItems:
    Delay: 多长时间后刷新箱子内道具
    Items: Items which can spawn. Use this format : 'Probability': '{"enchantments":{"First enchantment name":First enchantment level},"name":"Name","material":"The material (type)","lore":["First line of the lore."]}'. There are examples in the config file. A list of available enchantments is available here : http://jd.bukkit.org/rb/doxygen/ ... _1_1Enchantment.htm and a list of available materials is available here : http://jd.bukkit.org/rb/doxygen/ ... t_1_1Material.html.
    Chests: Spawn items in chests.
    Distance: The random distance (generated from the spawn).
    Thundering: Strike a lightning effect on the random location.
  Motd:
    Change: If you want to change the motd (messages are in the configuration //messages.yml//).
  Countdown:
    Time: Before enable damages.
    ExpBarLevel: Displays the countdown in the exp bar of each player.
  DeathSound:
    Sound: The sound that is played (you have a list here : http://jd.bukkit.org/rb/apidocs/org/bukkit/Sound.html).
    Volume: The volume of the sound (between 0 and 1).
    Pitch: 'The pitch of the sound (between 0 and 1).
Spectators:
  Enable: Enable the spectators.
  Mode: If "GHOST_FACTORY" does not work, set the value to "INVISIBLE_POTION".
  Permissions:
    Chat: If spectators can chat.
    PickupItems: If spectators can pickup items on the floor.
    Interact: If spectators can interact.
Kits:
  Selector:
    Name: The name of the kits selector (and the inventory).
    Material: The material of the kits selector. Use the same format than others materials.
  List: List of each kit. Use the same format than others items. Please note that an example is available and you can create them directly from the game. The first item is the icon.
Log:
  Console: If you want to log actions into the console.
  File:
    Enable: Log actions into a file.
    Directory: The log directory. Only if enabled.
