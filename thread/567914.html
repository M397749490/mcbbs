关于你的问题，最简单的方法就是：
修改Ess中的建筑项目，将项目改为false即可。
打开Essentials的config.yml找到

  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |               Essentials 建筑控制                    | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7.   # 禁止各种物理现象和行为
  8.   # 查看更多信息,请访问 http://wiki.ess3.net/wiki/AntiBuild

  10.     # 玩家是否可以建造:
  11.     # 设置为 true 可以禁用那些没有权限玩家的建造
  12.     # 设置为 false 将使 EssentialsXAntiBuild 从不阻止玩家建造
  13.     build: true

  15.     # 玩家是否可以使用物品(当玩家没有build权限的时候):
  16.     # 设置为 true 可以禁用那些没有权限玩家的使用物品
  17.     # 设置为 false 将使 EssentialsAntiBuild 从不阻止玩家使用物品
  18.     use: true

  20.     # 玩家无法建造时是否提示玩家
  21.     warn-on-build-disallow: true

  23.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  24.   # 你加载了一次Essentials后,就可以在plugins/EssentialsX/items.csv中找到物品ID列表.
  25.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  26.   alert:
  27.     on-placement: 10,11,46,327
  28.     on-use: 327
  29.     on-break:

  31.   blacklist:

  33.     # 阻止玩家放置以下方块
  34.     placement: 10,11,46,327

  36.     # 阻止玩家使用以下物品
  37.     usage: 327

  39.     # 阻止玩家破坏以下方块
  40.     break:

  42.     # 阻止活塞推动以下方块
  43.     piston:

  45.     # 阻止发射器发射以下物品
  46.     dispenser:
复制代码
