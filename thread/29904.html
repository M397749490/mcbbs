现在开始讲了....
首先，什么是bukkit：
bukkit是一个MC服务端，原先是MC爱好者们共同创建的一个服务端。现在已经被MOJAN编进工作组。他俗称水桶服，因为他的名字和LOGO都是水桶，象征这MC里面的水桶（非常有用）...

为什么要用bukkit：
当然你也可以用官方的，但是MOD，插件相对比较少。bukkit服务器的插件/MOD也都是爱好者们自己写出来的。bukkit一般都是专业服务器用的服务端，因为它可以使游戏变的更好玩，好管理。

现在下载好了？创建一个文件夹，名字自拟，因为服务器文件会在同一个文件夹里面生成，有一次我把它放到桌面了...后果...

把JAVA文件放进文件夹，把文件的名字复制下来（不带.jar)（其实你换名字都可以...就把你换的名字复制下来...），不要把.jar也换了就好了...

现在打开文本或者类似的东西（比方说notepade++）准备复制东西...

Windows


要是你装的是JAVA6,记住要把刚才记下来的文件名写在那：


  2. @ECHO OFF
  3. SET BINDIR=%~dp0

  5. "%ProgramFiles%\Java\jre6\bin\java.exe" -Xmx1024M -Xms1024M -jar <你的文件名>..jar
  6. PAUSE

Linux


这个跟WINDOWS不一样...创建完文件夹后需要在终端输入 ： 'cd ~/文件夹名字'

创建个文本，保存为craftbukkit.sh，输入：

  1. cat > craftbukkit.sh << EOF
  2. #!/bin/sh
  3. BINDIR=$(dirname "$(readlink -fn "$0")")
  4. cd "$BINDIR"
  5. java -Xmx1024M -Xms1024M -jar craftbukkit.jar
  6. EOF
  7. chmod +x craftbukkit.sh
复制代码

需要检查一下是不是可以开启的，然后，在终端里面输入：~/文件夹名字/craftbukkit.sh开启服务器

MAC OS


打开终端 ，在Application/Utilities，输入：

  1. cd ~/Desktop/
  2. mkdir BukkitServer
  3. cd BukkitServer/
  4. curl -O
  5. http://cbukk.it/craftbukkit.jar
  6. mv craftbukkit-1.1-R3.jar
  7. CraftBukkit.jar
  8. echo "cd ~/Desktop/BukkitServer/" >>
  9. start.command
  10. echo "java -Xms[RAM]M -Xmx[RAM]M -jar CraftBukkit.jar" >>
  11. start.command
  12. chmod +x start.command
  13. open -a TextEdit
  14. start.command
复制代码

这样应该会打开一个叫"LaunchServer"的文件，找到[RAM]然后换成：512，1024，1536，2560，3072，5120
我想大家应该知道这是服务器内存吧?这个需要看你的电脑配置，你电脑1G填个5120是个很不错的选择...（TROL）
512：0.5G     1024:1G  
1536:1.5G     2560：2.5G  
3072：3G     5120:5G

这个服务器会建立在你的桌面上，会在bukkit sever里面，点"LaunchServer.command"开启

bukkit服务器指令

我想大家应该知道指令怎么用吧？在服务器里面输入/ xxx的，或者在服务器的黑框里面直接输入

所有的1.2.5 bukkit 指令如下，有一些更老版本用不了：

/ban <玩家名>                                                     ban掉玩家
/ban-ip <玩家IP>                                                  ban掉IP
/banlist                                                                被ban名单
/deop <玩家名>                                                   取消玩家OP资格
/game mode <玩家名> <0或1>                             设置玩家游戏模式（1为创造，0为生存）
/give <玩家名> <物品名或ID> <数量>                  给玩家物品
/help                                                                    帮助...
/kick <玩家名>                                                     踢掉玩家
/kill <玩家名>                                                       杀死玩家
/list                                                                      在线玩家名单
/me <你的状态>                                                   可以在服务器上面显示你的状态...
/op <玩家名>                                                       给玩家OP权限
/pardon <玩家名>                                                清除玩家banned状态
/pardon-ip <IP>                                                   清楚IPbanned状态
/plugins                                                               所有插件名单
/reload                                                                 从新加载所有服务器文件
/save-all                                                               保存所有服务器文件
/save-off                                                              关闭自动保存
/save-on                                                              开起自动保存
/say <要说的话>                                                  对所有玩家说话
/stop                                                                   安全关闭服务器
/tell <玩家名> <要说的话>                                    仅对玩家说话
/time <set|add> <数字>                                       设置时间
/timings <reset|merged|separete>                         给插件定时
/tooggledownfall <世界名>                                    开启，关闭下雨
/tp <玩家1> <玩家2>                                          把1传送到2
/version                                                               服务器版本
/whitelist                                                             白名单
/xp <玩家> <数量>                                             给玩家一定的经验

这里面最重要的就是stop了...要不然会导致插件，服务器，地图等各种错误...

出現這種問題可能是您的最大内存堆（-Xmx）超出了您的計算機最大内存導致的，請嘗試修改您的 Java 啓動參數。
