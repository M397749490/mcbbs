简介
这插件的用途很简单，防止（创造）玩家乱扔东西。插件默认只限制创造模式玩家，有"antidrops.bypass"权限的玩家会不受该插件的限制。更多限制选项查看配置文件。

权限
如果配置文件内bypass.use 为 true，权限 antidrops.bypass 会生效

指令
无

配置文件
  1. config:
  2.   version: 0.5
  3. creative-only: true ——是否只限制创造模式
  4. bypass:
  5.   use: false ——是否使用该权限
  6.   permission: antidrops.bypass
  7. block:
  8.   creative: —— 创造
  9.     chest-use: true ——能否限制使用箱子
  10.     death-drops: true ——是否限制死亡掉落
  11.     signs: false ——能否限制使用牌子
  12.   survival: ——生存
  13.     death-drops: false ——是否限制掉落
  14.   adventure: ——冒险
  15.     death-drops: false ——是否限制掉落
  16. dev:
  17.   debug: false
  18. remove-item: false ——移除物品否？
  19. deny-drops: true ——禁用掉落？
  20. deny-pickup: true ——禁用拾取？
  21. no-block-drops: false ——无方块掉落？
