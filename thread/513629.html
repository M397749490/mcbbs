首先打开config，然后把action-one: KICK和action-two:BAN后面这些参数改成NONE，不然这个插件就会把类似作弊的玩家Ban掉（不过你想Ban的话就当我没说）下面是我的config文件，根据自己的需要修改：
  1. # AntiCheat configuration file
  2. # Please report any bugs: https://github.com/m1enkrafftman/AntiCheatPlus/issues
  3. xray:
  4.   # 是否使用xray作弊检测?
  5.   check-xray: false
  6.   # 是否发送xray作弊警告给管理员?
  7.   alert: false
  8.   # 多长时间(秒)进行一次xray作弊检测?
  9.   alert-interval: 60
  10.   # 是否对创造模式的玩家进行xray作弊检测?
  11.   check-creative: false
  12. spam:
  13.   chat:
  14.     # 是否开启防滥发信息?
  15.     block-speed: true
  16.     block-repetition: true
  17.     # Valid actions = NONE,KICK,BAN,COMMAND[command]
  18.     action-one: NONE
  19.     action-two: NONE
  20.   # 是否开启防滥发指令?
  21.   command:
  22.     block-speed: true
  23.     block-repetition: true
  24.     # Valid actions = NONE,KICK,BAN,COMMAND[command]
  25.     action-one: NONE
  26.     action-two: NONE
  27. system:
  28.   # 是否关闭自动更新?如果关闭将要手动去官网进行升级
  29.   auto-update: false
  30.   # 是否把作弊警告发送到控制台?
  31.   log-to-console: false
  32.   # 是否生成日志文件?
  33.   log-to-file: true
  34.   # 是否显示调试信息?
  35.   verbose-startup: false
  36.   # If silent mode is on, players will not be stopped when they try to hack, and AntiCheat will do everything possible to keep them unaware of their rising hack level.
  37.   # 是否开启安静模式,任会把信息放送给管理员和控制台,普通玩家不会受到任何提示

  39.   # 是否开启管理员免除检测?

  41.   # 是否进行多次作弊检测?

  43.   # 反正我猜这个是没人用的.
  44.   enterprise: false
  45. # 免除检测列表
  46. disabled-checks:
  47. - EXAMPLE_CHECK
  48. disable-in:
  49. - example-world
  50. - example-world-2

然后就是配置最主要magic文件了，所有的反作弊参数都要在这里修改，这个建议自己调整，因为每个服务器的mod或者插件不同，参数自然也要自己调试，比如我的服务器有工业，所以我的飞行参数就会比纯净服的参数要高。
参数可以去log文件夹里面去看日志（前提是config开启了记录功能），比如像下面就是玩家放置方块的参数没有调好

只需要去magic文件里面把放置方块参数改成玩家的参数就可以了，这一步是最后一步也是最重要和非常需要耐心的一步。
