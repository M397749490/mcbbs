/rpgitem 瞬移羽毛 create
/rpgitem 瞬移羽毛 display 瞬移羽毛
/rpgitem 瞬移羽毛 hand 传说中凤凰的羽毛
/rpgitem 瞬移羽毛 type 消耗品    【不是消耗品随便改】
/rpgitem 瞬移羽毛 quality Epic   【品质设置】
/rpgitem 瞬移羽毛 item 288       【外观设置】
/rpgitem 瞬移羽毛 power consume  【是否设为一次性消耗品，不是就删掉这条】
/rpgitem 瞬移羽毛 drop [怪物名] [几率]  【掉落设置】
/rpgitem 瞬移羽毛 description add 备注自己填
/rpgitem 瞬移羽毛 power teleport 100 10   【冷却时间100为5秒，10为传送距离】
/rpgitem 瞬移羽毛 lore 描述自己填
