  1. /ge list [页数] - 附魔列表
  2. /ge enchant <附魔> <等级> - 附魔手中物品
  3. /ge book <玩家> <附魔> <等级> - 获得附魔书
  4. /ge tierbook <玩家r> <品质> <等级> - 给予随机品质的附魔书
复制代码
而且你还要给你自己权限（如果你是op可以忽略）：
  1. goldenenchants.user
  2. - 用户权限 (使用附魔)
  3. goldenenchants.admin
  4. - 管理员权限
