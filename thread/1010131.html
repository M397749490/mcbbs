BedrockX-Lua

                                                                      ——再一次，改变BDS

耗时四周开发与测试，轻量，快捷，简单。为你自己开发高自定义mod

更新时间：2020年4月18日 (具体以 Github 最新 Commit 为准，Github源码仍在高速迭代中)

交流群：975811168

* 功能概述：
  • 让复杂的数据库变简单。抛弃传统的文件存储数据，让一切数据增删改都可以一行完成。
  • 和其他Mod的高效配合，经济API绑定，领地API绑定，数行完成一个简易出售商店
  • 对玩家完全友好的操作界面，内嵌自研GLang编译器，复杂GUI，动态GUI轻松搞定，摆脱单调的按钮GUI
  • 深入考察服主需求，经过一周的实地功能调研，为服主提供了定时API与延时API等常用操作，摆脱命令块的卡顿和bug，不要再让常加载区块成为卡服凶手。同时和服务器本身高效配合，支持背包查看修改(可实现多服背包同步），支持运行指令并获取输出，完美以玩家身份运行(完美修复execute的问题），获得玩家坐标等基本操作
  • 高度自定义的事件系统。玩家进入 退出 发言等常用事件，让一切尽在掌控。
  • 高扩展性。内置游戏内完美指令支持，命令块，玩家，控制台都可以直接调用Lua命令！！！同时，Lua支持什么，你就可以用什么。Lua有第三方的sqlite库，curl库，快速开发与高端功能需求，同时满足！
  • 专为开发者设计的多线程模型，突破语言本身限制，Native Json解析器支持，Socket支持，事件驱动的线程间通信，多服聊天/云黑名单轻松搞定

* 优势：
  • 热重载，交互Shell，所见即所得，对服主友好
  • 尽管BedrockX为开发者提供了一套简便的开发API,但是依然要求用户有支持C++17的IDE,对个人用户来讲是一个很大的不便。仅仅需要一个简单的与经济关联的TPA，可能都要花一个小时来初始化环境。BDS Mod开发不应该止步于高门槛。每个人都应该能用几分钟为自己服务器定制简单Mod!
  • 因此，BedrockX-Lua应运而生，得益于Lua简单的语法和BDX强大的API接口，一切需要命令方块高级玩家思考建造数小时的工具，都可以通过简单几行代码写出。

* 预编译文件地址：https://github.com/Sysca11/BedrockX-bin

* 教程文档：https://github.com/Sysca11/BedrockKit-doc/tree/master/bdxlua-doc
