作者: 秋风残叶    时间: 2017-6-1 16:37
默认的NCP就是检测作弊飞行然后踢出，个人认为不需要修改（可能会误报）
如果你真的想搞的狠一些，就是那种一检测到就踢人，打开NCP的config，找到相应检测名称（我用作弊飞行SurvivalFly举个例子）
  1.     survivalfly:
  2.       active: true
  3.       extended:
  4.         vertical-accounting: true
  5.       stepheight: default
  6.       hbufmax: 1.0
  7.       setbackpolicy:
  8.         falldamage: true
  9.         voidtovoid: true
  10.       actions: log:flyshort:3:10:f cancel vl>100 log:flyshort:0:10:if cancel vl>400 log:flylong:0:5:cif cancel vl>1500 log:flylong:0:5:cif cancel cmd:kickfly
复制代码

请看actions部分，本部分最后那个cmd:kickfly（也就是踢出作弊飞行玩家）是要等到作弊等级大于1500时才触发，你就可以把这个cmd:kickfly提到前面来，例如
  1.       actions: log:flyshort:3:10:f cancel vl>100 log:flyshort:0:10:if cancel cmd:kickfly
复制代码

这么一来作弊等级大于100,就会被NCP检测到然后踢出

我还是那句话，个人不建议修改，因为可能误报
