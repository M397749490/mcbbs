标题: Bukkit服务端指令与权限
本帖最后由 qwbestplayer 于 2013-3-8 17:53 编辑

注意：这里讲的是能在服务端使用的Bukkit服务端指令，部分也能在游戏内使用。
指令
描述
使用方法
权限
version
显示服务器版本
version
bukkit.command.version
plugins
列出服务器的所有插件
plugins
bukkit.command.plugins
reload
重启所有插件
reload
bukkit.command.reload
timings
记录所有插件事件发生时间
timings  <reset|merged|separate>
bukkit.command.timings
tell <player>  <message>
给一个玩家发私信
tell  <player> <message>
bukkit.command.tell
kill
允许玩家自杀，回到重生点（丢失物品）
kill
bukkit.command.kill
me
在游戏里跟自己说话（？）
me  <message>
bukkit.command.me
help or ?
显示指令列表
help
bukkit.command.help
kick <player>
把一个玩家提出服务器
kick  player1
bukkit.command.kick
ban <player>
封禁一个玩家
ban  player1
bukkit.command.ban.player
banlist
显示封禁玩家列表
banlist
bukkit.command.ban.list
pardon <player>
解除玩家封禁
pardon  player1
bukkit.command.unban.player
ban-ip <ip>
封禁一个IP
ban-ip  192.168.1.5
bukkit.command.ban.ip
pardon-ip <ip>
解除IP封禁
pardon-ip  192.168.1.5
bukkit.command.unban.ip
op <player>
给予OP权限
op  player1
bukkit.command.op.give
deop <player>
取消OP权限
deop  player1
bukkit.command.op.take
tp <player1>  <player2>
把一个玩家传送到另一玩家的位置
tp  player1 player2
bukkit.command.teleport
　

tp <player1> <x> <y> <z>
把玩家传送到指定坐标
tp player1 0 70  12
give  <player> <data-value> [number]
给玩家指定数量的指定物品  物品代码
give player1 3 31
bukkit.command.give
stop
关闭服务器
stop
bukkit.command.stop
save-all
保存服务器地形
save-all
bukkit.command.save.perform
save-off
关闭服务器自动保存
save-off
bukkit.command.save.disable
save-on
开启服务器自动保存
save-on
bukkit.command.save.enable
list
显示在线玩家列表
list
bukkit.command.list
say <message>
服务器广播
say  <message>
bukkit.command.say
whitelist <on/off>开关白名单
whitelist  on
bukkit.command.whitelist.enable
whitelist off
bukkit.command.whitelist.disable
whitelist <add/remove>  <player>将玩家添加/移出白名单
whitelist  add Notch
bukkit.command.whitelist.add
whitelist remove Notch
bukkit.command.whitelist.remove
whitelist list
显示白名单玩家列表
whitelist  list
bukkit.command.whitelist.list
whitelist reload
重新读取白名单文件
whitelist  reload
bukkit.command.whitelist.reload
time <add/set>  <amount>设置时间
time  add 6000
bukkit.command.time.add
time set 0
bukkit.command.time.set
gamemode <0/1/2> <player>
改变游戏模式  0生存1创造2冒险
gamemode  1 Notch
bukkit.command.gamemode
xp <player>  <amount>
给玩家经验
xp  Notch 100
bukkit.command.xp
toggledownfall
开关雨/雪
toggledownfall
bukkit.command.toggledownfall
defaultgamemode <0/1>
设定新玩家游戏模式
defaultgamemode  1
bukkit.command.defaultgamemode
seed
导出地图
seed
bukkit.command.seed
enchant <user>  <enchant number or ID>  <level> <force>
附魔手中物品
enchant  Notch 1 1 1
bukkit.command.enchant
weather <weather>
改变天气
weather  clear
bukkit.command.weather
clear <user>
清空玩家背包
clear  Notch
bukkit.command.clear
difficulty <diff level>
设置游戏难度
difficulty  0
bukkit.command.difficulty
spawnpoint <User>  <x> <y> <z>
设置玩家复活点
spawnpoint  Notch
bukkit.command.spawnpoint
GameRule
开/关指令
GameRule <command> true/flash
bukkit.command.gamerule
