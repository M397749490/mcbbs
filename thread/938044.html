Chair
前言：
简单的椅子插件看了下论坛还没1.15的就搬了
然后百度搜索和论坛搜索找了一下也没找到重复的，如果我二搬了请提醒我
I don't want to have a huge plugin, making tons of things. If you need a simple chair plugin, give it a try.
If you need more, you should probably use another one.
简单来说这个插件很轻便，没有多余的功能
实际上他只有10kb
如何使用：
没有前置依赖，将插件放到plugin文件夹中，然后重新启动服务器即可。
如何做到椅子上：
直接右键config中配置好的方块（楼梯什么的已经默认配好了），就可以坐上去了，然后shift下来
配置供参考请勿直接复制使用：
这里做了简单的汉化（好像不汉化也看得懂）（论坛把生效的方块吞了，插件是自带生效方块的）
  1. # ----------------------------------------------------------------------------------------------------------------------
  2. # Chair, version 1.2 -  Configuration file.
  3. # .
  4. # You will find an explanation of all parameters here:
  5. # https://github.com/arboriginal/Chair/blob/master/src/main/resources/config.yml
  6. # ----------------------------------------------------------------------------------------------------------------------

  8. onlyEmptyHand: true # (true or false) 如果true，玩家只能空手才能坐上去
  9. dirBlocksFace: true # (true or false) 如果为true，则将玩家镜头转到与椅子方块（如楼梯）相同的方向
  10. maxDistToBlock: 2 # （整数）最大距离（单位：方块），玩家只能在这个范围才能坐到椅子上
  11. minBlocksAbove: 1 # (整数) 最小距离，同上

  13. #生效的方块
  14. # Available values: https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html (only work for blocks material)
  15. allowedBlocks:
复制代码
指令：
只有一个：/chair-reload 或者是/chair reload (作者这里打了-，不知道要不要，本人还没用过，测试后再修改)
权限：
  • chair.reload (default: op)允许使用 /chair-reload 这个指令
  • chair.use (default: true)允许使用椅子
