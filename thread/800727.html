LikeMe


介绍
       LikeMe可以允许玩家之间互相点赞（介绍就这么简洁啦）

功能
  • 只允许玩家点赞一个玩家一次
  • 显示点赞信息
  • 两种消息提示
  • 可开关免打扰模式
  • 提供了PlaceholderAPI变量
  • 提供了API方法
  • 支持数据库

命令（无需权限）
  1. /likeme 玩家游戏名   #给某玩家点赞一次
  2. /likemegui   #打开个人点赞信息
复制代码

配置
  1. noLikeMessage: '&c不能再赞同一个玩家了'
  2. noPlayerMessage: '&c当前玩家不在线'
  3. noGiveMeMessage: '&c不能给自己点赞'
  4. # 点赞消息
  5. message:
  6.   # 是否启用title消息
  7.   # 需要ProtocolLib前置插件
  8.   title: true
  9.     # 如果启用，则显示心形符号
  10.     heart: true
  11.     giveMainText: '&c&lLike'
  12.     getMainText: '&cLike'
  13.     giveSubText: '&fgive %player_name% a like'
  14.     getSubText: '&fget a like from %player_name%'
  15.   # 是否启用聊天消息
  16.   text: true
  17.     # 如果启用，则显示心形符号
  18.     heart: true
  19.     giveText: '&fgive %player_name% a like'
  20.     getText: '&fget a like from %player_name%'
  21. mysql:
  22.   enable: false
  23.   sql: 'jdbc:mysql://localhost:3306/数据库名'
  24.   root: 'root'
  25.   password: 'password'
复制代码

PlaceholderAPI变量
  • %likeme_getLikeInt%   玩家自己的获赞数
  • %likeme_giveLikeInt%   玩家自己的点赞数

开发者API（LikeMe）
  1. 目标玩家的获赞数   getGetLikeInt(String playerName)
  2. 目标玩家的已赞数   getGiveLikeInt(String playerName)
