支票插件1.1



用途：这个插件，是一款不错的轻质量插件，输入/wd 数量

即可生成一张支票，右键之后可以获得对应的钱




指令：/withdraw, /withd, /wd.






















我设置的默认编码是UTF-8，如果是不同的编码，请复制一下文本替换到插件内。

以下是汉化配置



Item:
  Name: "&6&l一张支票 &7(右键使用)"#Version: 1.1

#Author: AMiracleName        （时光如年汉化）
#ReloadedConfig: "&e&l支票 &8> &7重新加载 config.yml" // Will add soon
#Permissions: "&6&l[&e&l支票&6&L] &8> &7你没有权限进行此操作!" // Will add soon
WithdrawUsage: "&6&l[&e&l支票&6&L] &6&L: &a&l/withdraw <数量>"
NotEnoughMoney: "&6&L[&e&l支票&6&l] &6&L: &a&l你没有足够的资金开这张支票."
Below1Billion: "&6&L[&e&l支票&6&L] &6&L: &a&l支票的最大金额不能超过一亿."
Error404: "&6&L[&e&l支票&6&l] &6&l: &a&l错误！你没有输入一个有效的数字?"

Item:
  Name: "&6&l一张支票 &7(右键使用)"
