ShendMotd
——————————————
这个是我的第6个原创作品
这个插件的功能是
更改游戏外Motd
更改游戏内Motd
加入信息
ICON服务器图标
——————————————
使用方法
1.下载ShendMotd

2.放到plugins文件夹内

3.重启服务器

4.如果出现

ht.png (24.26 KB, 下载次数: 0)

下载附件

2016-9-24 00:17 上传

 则说明载入成功并且成功开服！

5.修改Config.yml即可
——————————————
配置
[spoiler]
#版本: 1.0.0
#作者By: shend2002

#是否开启Motd.
enablemotd: true
motd:
#在游戏中的Motd.
  ingame: '&b&l感谢您使用ShendMotd &f- &e作者By:shend2002    &7这个Motd的设置可以在您的plugins/ShendMotd/config.yml进行设置 '
#在游戏外的Motd. (不用重启服务器)
  system: '&b&l感谢您使用ShendMotd &f- &e作者By:shend2002    &7&l这个Motd的设置可以在您的plugins/ShendMotd/config.yml进行设置'
#在游戏中的加入/离开信息.  
  join: '%player 加入了游戏 '
  left: '%player 离开了游戏 '
icon:
#设置服务器ICON图标
#ICON图标必须为 64x64 像素的图片!
  set: false
  name: server.png
