前言
  • 其实楼主才刚学Java不久，最近实在是闲的蛋疼，于是就花了几个小时的时间写出了这款插件......
  • 可以说这款插件是楼主的处女座，不过从测试的效果来看还是不错的，也算是个比较实用的插件吧
  • 楼主学生党，所以更新缓慢，如果有什么好的建议可以在评论里写下来，有时间的话我会看一看并一一回复的
  • 如果你看到排版是绿色的 请将你的浏览器更改至兼容模式~

介绍
  • [1.0.0]这款插件十分的小，几乎不占服务器什么内存
  • [1.0.0]可以根据实体的身高生成合适高度的血(粒子效果)，避免了空气喷血的情况
  • [1.0.0]可以在config.yml中手动开关插件中的溅血效果和实体受伤时发出的类似于方块被挖掉的声音
  • [1.1.0]可以开启五颜六色的血
  • [1.1.0]可以自定义溅血的血量
  • [1.2.0]可以控制血颜色——目前支持 红 黄 蓝 绿 四种颜色
  • [1.2.0]将配置文件内容换成中文

指令&权限
指令:
  • /bloody    重新加载config.yml配置文件
权限:
  • 暂无


配置文件(config.yml)

  1. 开启Bloody插件: true  //是否开启溅血效果
  2. 血颜色: 红 //溅血的血颜色 目前支持 红 黄 蓝 绿 四种颜色
  3. 出血量: 200  //溅血的血量的血
  4. 开启彩色血: false  //是否开启五颜六色的血
  5. 开启声音: true  //是否开启受伤音效
  6. 重置消息: 插件重载成功!  //插件重载后发送的信息
