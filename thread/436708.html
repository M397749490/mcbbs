MOD使用方法
Commands:
  • /nick <nick> - 为自己设置别名
  • /color <color> - 为自己设置一个颜色，输入random则水机
  • /realname <nick> - 看ID
  • /coords - 聊天窗口喊出你的坐标
  • 以下OP才可使用，不翻译了，类似于权限组
  • /group - OP Only command. Can take these subcommands:
    • create <Name>- Creates a group with Name
    • remove <Name> - Removes group Name
    • addUser <Group> <Name>- Adds user Name to Group
    • delUser <Group> <Name> - Removes user Name from  Group
    • color <Group> <color> - Sets a color for the group.
    • save - Saves the groups to a file in the world root
    • load - Loads the groups from a file in the world root

Infernal Sky Color

这个MOD可以改变天空与迷雾的颜色

注意：它会消除太阳,月亮,星星,云

站内贴传送带：点我传送

使用方法
/skycolor 0(1) [r] [g] <过渡时间>
禁用只需要在颜色前面添加一个负号
/skycolor 0(1) -[r] -[g] - <过渡时间>
这个颜色是保存到世界,然后传到当前服务器已连接上的玩家
1是天空/迷雾/虚空
0是overworld,但我不知道他是修改哪
R,G,B值是颜色
你输入命令必须把R,G,B的颜色各项÷10,否则亮瞎眼
你也可以更高的数值来亮瞎你的眼
过渡时间(天空颜色转换速度)
默认值为5000(5秒)，你填写时把秒数*1000就是了
