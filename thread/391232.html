作者: 网络摆渡客    时间: 2015-1-27 17:52

作者: 青橘短衫丶    时间: 2015-1-27 20:20
在此目录下plugins\GroupManager\worlds  新建一个文件夹（文件夹的名字是你暮色森林世界的世界名字）然后重启服务器 再关闭服务器，你新建的文件夹里会出现两个文件打开groups.yml  在
Builder:
    default: false
    permissions:
    - essentials.fly
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      default: false
      prefix: '&2'
      build: true
      suffix: ''
添加红色字体那一项 ，列哥回答望采纳！
