标题: [code] 代码块转义 bug
code 代码块中的斜杠 \ 会被视作转义字符并进行处理，这无论怎样想都是不对的。

例如：以下代码
"foo": "\"bar\""
被放到 code 代码块中以后会变成：
  1. "foo": ""bar""
复制代码


这一错误造成很多编程/命令相关的帖子在涉及到转义时内容被论坛吃掉，造成代码/命令编译/运行不能，望修复，感谢。
