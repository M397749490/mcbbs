HECobCommand
地狱指挥网

插件介绍
地狱插件系列
HECobCommand

简介：
它是一个超强的BC跨服命令插件
可以让BC中的各个子服之间互相发送命令
让指挥网的所有子服执行一个命令
子服重启自动重连指挥网
跨服命令组与跨服延时命令(新增)
跨主机服务器之间指挥(新增)
插件安全性加密(新增)
例如：
你在"主大厅"使用 /cob send 空岛服 run  time set day
就可以在名为"主大厅"的子服中将"空岛服"的时间设置为白天
你也可以让某些菜单以及其他奖励插件执行跨服命令
将奖励等发送到其他子服等
再例如:
使用其他签到或奖励类插件，让插件执行指挥网的跨服命令
让签到等插件的奖励发送至另一个子服

1.下载HECobCommand压缩包

3.重启BungeeCord，编辑HECore的配置文件

指令与权限

命令：

/cob send <配置中子服名称> run <命令>
向指挥网中的一个子服发送命令，运行的命令不需要加/
例:
/cob send 大厅 run time set day


/cob send global run <命令>
向一个指挥网中所有子服发送命令


/cob send <配置中子服名称> delay <延时时常 单位tick> run <命令>
向指挥网中的一个子服发送延时命令，20tick=1秒，运行的命令不需要加/
例:
/cob send 大厅 delay 20 run time set day


/cob group <配置的命令组名称>
运行一个配置好的命令组，在BC的plugins\HECore\commands文件夹中配置
例:
/cob group global

! 玩家变量为 %player% ¡

HECob.admin
