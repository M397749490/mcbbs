SuperRider--骑宠插件
[此排版来自PCD小组]

插件介绍:
      这是一款可以超级强大的骑宠插件，你可以骑着到处飞行，行走。宠物还能帮你打怪，自带养成系统.
插件功能:
  • 1. 本人独家设计的行走，飞行算法，可以上下左右移动，并不是一味的只能向前，灵活度极高.
  • 2. 支持原版全部生物,支持4D模型。
  • 3. 强大的GUI操作，解放腐竹双手，基本实现免除配置文件配置.
  • 4. 可以根据生物的模型来调整坐骑位置.
  • 5. 支持自定义名字，模型，移动速度等.
  • 6. 支持末影龙(众所周知末影龙的yaw等数据与其他生物不太一样)
  • 7.所有生物都支持飞行，可自动开关飞行模式
  • 8. 骑宠自动跟随，不用担心走丢噢
  • 9. 支持宠物攻击敌人，主人可控制开关自动寻敌
  • 10.支持自定义食物，自定义恢复宠物的血量。下面有图
  • 11. 可自定义宠物升级属性增长公式,支持血量,经验值，攻击力.
  • 12.支持自定义公式设置宠物杀死敌人后增长的经验值
  • 13.宠物死亡后需要使用宠物复活石来复活.

指令介绍:
       /pet help:指令帮助

       /pet gui:打开GUI界面

       /pet give player:给玩家一个宠物复活石

       /pet create effect id name id:damage data:创建一个自定义食物 name表示显示物品名字 data表示恢复血量的范围，格式1-2

         /pet send entity id player:给玩家一个 宠物

         /pet send effect id player:给玩家一个自定义食物

操作提示:
                1.宠物自动寻敌模式,主人潜伏状态下，点击地面即可开关寻敌模式(宠物会自动寻敌并击杀)
                2.飞行控制.视角控制飞行角度，往前即可根据视角方向飞行
                3.喂养自定义食物，手持食物点击宠物即可回血.
                4.长按宠物即可骑乘.
注意事项:
      1.将4D模型以文件夹的形式放入skin文件夹中.
      2.文件夹包括(skin.json,skin.png)注意:文件名字也必须是skin
      3.文件夹名别用中文
      4.讲skin.json中的[attach]1552918[/attach]修改为geometry.文件夹名
         然后就可以了
常见问题:
      腐竹1:老师，我这个人物怎么没坐在上面啊.
      回答: 坐位的Y轴位置 默认是生物的高度,如需调节,可进入GUI->OP操作->修改数据->Y轴位置进行调节
      腐竹2:大神,这个飞行是怎么飞的.
      回答:视角控制飞行角度,往前走即可根据视角方向飞行.

                    5.添加可设置宠物大小
                    6.添加生物狐狸,北极熊.

                   1.修复末影龙因为上次修改造成的不能召唤BUG

                   1.修复代码字母错了造成的某些生物无法召唤
                   2.添加主人取消宠物攻击目标(潜行状态点击地面)
                   3.更改宠物开关自动寻敌的方式,改为(潜行状态下，长按地面）
         V1.0.2(2020.4.17):
                   1.添加宠物自动寻敌模式(主人通过潜行模式下，点击地面开关自动寻敌)
                   2.添加config.yml文件,宠物升级属性公式,可以设置宠物升一级属性的增加公式.
                   3.删除喂养食物,可自定义NBT物品作为食物，可设置恢复血量的值范围，并且附带粒子效果
        V1.0.1(大更新):
                   1.添加宠物攻击(当主人被攻击或者主人攻击他人是会帮忙)
                   2.添加宠物属性，等级，攻击力，血量，经验值.会随着每一级的增长而增长
                   3.添加宠物死亡复活石,当宠物死亡后必须花费宠物复活石来复活
                   4.添加宠物打死生物会增加经验值
                   5.添加主人喂养食物恢复宠物血量。
