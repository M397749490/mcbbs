LayoutGenerator

前言

此软件仅供Slimefun附属插件开发者使用



  • 开始写这个时候，目的纯粹是为了自己开发Slimefun附属方便，因此只在ubuntu16.04系统上进行了测试（自己的电脑），没有在windows平台 / macOS平台进行测试（毕竟我也没有啊）
  • 第一次大量使用ansi控制码进行编程，如果错误欢迎dalao指正
  • 只要Slimefun的机器布局保持使用int数组，这个资源就不算过期（笑）



食用方法

  • 带参数运行下载的jar文件

    参数 含义
    --length (-l) 指定布局的行数（默认：5）
    --load (-ld)读取形如 "{0, 1, 2, 3}" 的int数组（将自动计算布局行数）
    --debug 开启Debug模式
  • 等待程序出现形如 "[(X) 0 | (Y) 0]" 的光标坐标指示器
  • 用按键 ↑，↓，←，→控制光标"X"进行移动（就像玩传统的RPG游戏一样）
  • 用 Ctrl 键对当前光标"X"所在的格子进行标记 / 反标记
  • 当布局设计完成后，按 Alt 退出程序，在程序结束前将会自动输出一段形如 "{0, 1, 2, 3}" 的int数组（即布局）

注意事项

  • 此软件使用JNativeHook库进行全局按键监听，使用JCommander库进行命令行处理，两个库已打包进jar文件，不需要另外下载库文件
  • 由于JNativeHook库（貌似）只能监听全局按键，我也没有找到其它方法来只对单个窗口进行按键监听，所以会出现在其他窗口按按键也会使LayoutGenerator进行操作
  • 除了按键 ↑，↓，←，→，Ctrl 以外，按下其它任何按键都会使程序退出，但如果不用 Alt 键退出将会产生警告（这是一个故意的设定）
