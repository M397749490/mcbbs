这是一个功能强大,配置简单的自定义成就插件

特性:



  • 30种可编辑的主成就
  • 自定义成就的名称，描述和颜色
  • 成就奖励可以是:钱/物品/自定义奖励(指令)
  • 记录玩家完成的成就和日期
  • 自定义记录成就的书
  • 完成成就时会有特效
  • 获得记录成就的书时会有音效
  • 玩家获得成就时全服通知
  • 可以选择是否需要Vault做前置
  • 支持SQLite或MySQL
  • 兼容UUID系统
  • 可在游戏或控制台使用指令
  • 极大的灵活性，选项??和自定义
  • 重量轻，易于安装，易于使用

成就类型:

  • 30种基础可用的成就类型(具体配置里说)
  • 将指令作为奖励或者成就(同上)

安装指南:

  • 下载该插件
  • 放入plugin加载
  • 配置成就
  • 重载
  • 结束

指令&权限:

CommandDescription
/aach or /aach help查看帮助
/aach book获得记录成就的书
/aach stats显示玩家完成的成就
/aach list显示所有的成就
/aach top显示排行
/aach give ach name给予玩家一个成就
/aach check ach name检查玩家是否完成成就
/aach delete ach name删除给予玩家的成就
/aach reload插件重载
/aach info显示插件信息
PermissionDescription
achievement.get获得成就的权限
achievement.book对应/aach book
achievement.reload对应/aach reload
achievement.give对应/aach give ach name
achievement.check对应/aach check ach name
achievement.delete对应/aach delete ach name
achievement.list对应/aach list
achievement.*获得插件的完全控制权
