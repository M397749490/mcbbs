作者: ⊙u⊙    时间: 2019-5-24 15:33
一个名为 #temp 的虚拟玩家。
temp既temporary，意为临时。
#的作用是保证不会被真实存在的temp玩家扰乱咱们的数据。
#还有一个作用是不会在记分板display时显示。
如果希望既显示于记分板，又能保证不为真实玩家，可用$

求助怎么去重遍历呀？假设有两个挨在一起的经验球，我执行下面的命令会把两个经验球都kill掉，

如果用@e ...
首先distance=0.001..1其实还是有点不好的，因为可能会完全重叠。然后在执行过程中不能直接kill，所以我先给了一个tag然后再kill


  1. execute as @e[type=experience_orb] store result score @s cppValue run data get entity @s Value
  2. execute as @e[type=experience_orb] at @s run function cpp:combine_xp_orb_each
  3. kill @e[tag=remove,type=experience_orb]
复制代码

function cpp:combine_xp_orb_each
  1. tag @s add self
  2. scoreboard players operation #temp cppValue = @s cppValue
  3. execute as @e[type=experience_orb,tag=!self,distance=..1] run scoreboard players operation #temp cppValue += @s cppValue
  4. execute store result entity @s Value short 1 run scoreboard players get #temp cppValue
  5. execute as @s[tag=!remove] run tag @e[type=experience_orb,tag=!self,distance=..1] add remove
  6. tag @s remove self
