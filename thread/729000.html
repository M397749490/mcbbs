时间就是金钱 —— 在线获得金钱

Time Is Money

简介：

时间就是金钱插件可以让你选择多长时间给多少钱和定时执行命令。
举个梨子:
你可以每十分钟给所有人一个钻石+100金币。

这个插件还有挂机检测功能，如果你在挂机，是不会获得奖励的(可以配置)。

TIM还包含ATM功能!


配置文件：

范例配置文件:

config.yml:

  1. configuration-version: 12

  3. debug-log: false

  5. # You can disable the plugin's payout feature in certain worlds
  6. disabled_in_worlds:
  7. - "creative_world"

  9. # You can define if the player gets a payout whether player is afk or not.
  10. # the permission tim.afkbypass would avoid this for certain user or groups.
  11. afk_payout: false
  12. display-messages-in-chat: true
  13. display-messages-in-actionbar: true
  14. display-messages-in-actionbar-time: 10
  15. give_money_every_second: 600
  16. store-money-in-bank: false

  18. # Payouts will be delivered by "chance" instead "permission".
  19. choose-payout-by-chance: false

  21. # You can add as many payouts you want. You only can choose between "permission"
  22. # and "change", not both.
  23. payouts:
  24.   1:
  25.     payout_amount: 50
  26.     max_payout_per_day: 1000
  27.     # chance: 10
  28.     permission:
  29.   2:
  30.     payout_amount: 100
  31.     max_payout_per_day: 10000
  32.     commands:
  33.       - /give %player% diamond 1
  34.     # chance: 90
  35.     # You can use any permission name you want. e.g. myserver.donor
  36.     permission: tim.vip

  38. # Translations
  39. message: "&aYou earned &c%money% &afor 10 minutes online time!"
  40. message_payoutlimit_reached: "&cYou have reached the payout limit today. You earned 0[        DISCUZ_CODE_0        ]quot;
  41. message_afk: "&cYou havn't earned money because you were afk!"
  42. message_actionbar: "&aYou earned &c%money% &afor 10 minutes online time!"
  43. message_payoutlimit_reached_actionbar: "&cYou have reached the payout limit today. You got 0[        DISCUZ_CODE_0        ]quot;
  44. message_afk_actionbar: "&cYou havn't earned money because you were afk!"
  45. message_atm_noperms: "&cYou don't have the permission to use ATM's!"
  46. message_atm_nomoneyinbank: "&cYou don't have enough money in bank!"
  47. message_atm_nomoney: "&cYou don't have enough money!"

  49. # ATM -> Place down a sign with [atm] on the first line to use it!
  50. enable_atm: true
  51. atm_title: "&cATM"
  52. atm_withdraw: "&cWithdraw"
  53. atm_deposit: "&cDeposit"
  54. atm_balance: "&cBank balance:"

  56. # You can seperate the ATM balances for different worlds by group them. Just set group-atms to true and write atm_groups as described below.
  57. # Note: Existing bank accounts will be removed when enabling this feature.
  58. group-atms: false
  59. # Example groups for seperating all worlds:
  60. #atm_groups:
  61. #  group1:
  62. #  - world
  63. #  group2:
  64. #  - world_nether
  65. #  group3:
  66. #   - world_the_end

指令：

/tim - 重载配置文件
/atm <player> - 打开玩家的ATM
/atm - 打开ATM

权限：

管理员权限：
tim.reload (/tim) - 重载配置文件
tim.admin (/atm <player>) - 查看玩家的ATM
tim.atm.place - 创建ATM牌子

玩家权限：
tim.atm.use - 使用ATM牌子
tim.use (/atm) - 使用权限
