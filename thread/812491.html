最后，最重要的环节：判定玩家是否在领地范围内，或方块、实体是否在领地范围内。
讲解一下以下方法的判定原理：

设领地某边缘最底部的坐标为(a,b,c)，领地某边缘对角最高部的坐标为(l,m,n)，实体、方块所在位置的坐标为(X,Y,Z)，由题意得：
如果 (a<X<l 或者 a>X>l) 并且 (b<Y<m 或者 b>Y>m) 并且 (c<Z<n 或者 c>Z>n) PS：括号表示优先级
那么 就返回值为true，否则为false。

  2. public boolean isLocationInRegion(Location l) {
  3.                 for (String area : this.领地所有区域) {
  4.                         if (!l.getWorld().getName().equals(this.getConfig().getString(area + ".World"))) {
  5.                                 continue;
  6.                         }
  7.                         int X = this.getConfig().getInt(area + ".POS1.X");
  8.                         int Y = this.getConfig().getInt(area + ".POS1.Y");
  9.                         int Z = this.getConfig().getInt(area + ".POS1.Z");
  10.                         int X2 = this.getConfig().getInt(area + ".POS2.X");
  11.                         int Y2 = this.getConfig().getInt(area + ".POS2.Y");
  12.                         int Z2 = this.getConfig().getInt(area + ".POS2.Z");
  13.                         if ((Y > l.getY() && Y2 < l.getY()) || (Y < l.getY() && Y2 > l.getY())) {
  14.                                 if ((X > l.getX() && X2 < l.getX()) || (X < l.getX() && X2 > l.getX())) {
  15.                                         if ((Z > l.getZ() && Z2 < l.getZ()) || (Z < l.getZ() && Z2 > l.getZ())) {
  16.                                                 return true;
  17.                                         }
  18.                                 }
  19.                         }
  20.                 }
  21.                 return false;
  22. }

第二、判断领地的方法是直接遍历整个领地名，这样效率也是相当低。鄙人研究领地插件，发现其使用Map储存对应区块内的所有领地，在判断时先计算出对应区块，再遍历对应区块的所有领地。这样虽然消耗内存，但可以在多领地的情况下极大地提升效率。
