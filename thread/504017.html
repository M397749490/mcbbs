Idisguise

伪装成任何原版生物



idisguise是一个简单的伪装的插件，你可以伪装成任何原版生物并选择你的属性(例如猫的三种外观，马的颜色，末影人手上的方块）


伪装后可能从自己的视角看还是普通的玩家，但从别的玩家视角来看和普通生物完全一样

也许你可以伪装成末影人去偷偷拆别人家然后被玩家看到你还可以装什么也不知道

你可以伪装成苦力怕出现在基友背后让他们吓一跳

你可以伪装成僵尸正大光明的打别人

你可以伪装成普通小生物若无其事的进别人家翻东西

你可以伪装成小猫卖萌


这一切看你的想象力啦


接下来是指令和权限（楼主人肉翻译机）：


指令：

commandDescriptionPermission
/disguise helpShows information about the available commands
（这个不翻译了）		no permission
/disguise player <name>Disguise as a player
（伪装成玩家）		iDisguise.player.<name>
/disguise ghost <name>Disguise as a ghost
（伪装成幽灵）		iDisguise.ghost AND iDisguise.player.<name>
/disguise randomLet your server choose what you disguise as
（随机伪装）		iDisguise.random
/disguise reloadReload the config.txt file
(重载插件）		iDisguise.reload
/disguise statusShows what you are disguised as
（插件状态）		no permission
/disguise <mobtype>Disguise as a mob
（伪装成生物）		Read the permission section below
/disguise [ subtype] <mobtype> [ subtype]Disguise as a mob with the given subtypes
（伪装成生物（有其他种类的））		Read the permission section below
/disguise <subtype>Change your subtype(s)
（切换种类）		Read the permission section below
/undisguiseUndisguise yourself
（解除伪装）		iDisguise.undisguise (only required if you turn this on in config.txt file
/undisguise *Undisguise everyone on the server
（给所有玩家解除伪装）		iDisguise.undisguise.all
/undisguise <player>Undisguise someone else
（给某玩家解除伪装）		iDisguise.undisguise.others
/odisguise <player> helpShows information about the available subcommands
（显示替代指令）		iDisguise.others
/odisguise <player> player <name>Disguise another player as a player
（让其他玩家伪装成其他玩家）		iDisguise.others
/odisguise <player> ghost <name>Disguise another player as a ghost
（让其他玩家伪装成幽灵）		iDisguise.others
/odisguise <player> randomLet your server choose what someone else disguises as
（让其他玩家随机伪装）		iDisguise.others
/odisguise <player> statusShows what someone else is disguised as
（显示其他人在伪装什么）		iDisguise.others
/odisguise <player> <mobtype>Disguise another player as a mob
（让其他玩家伪装成生物）		iDisguise.others
/odisguise <player> [ subtype] <mobtype> [ subtype]Disguise another player as a mob with the given subtypes
（让其他玩家伪装成生物（有附种类）		iDisguise.others
/odisguise <player> <subtype>Change someone's subtype(s)
（切换别的玩家的种类）		iDisguise.others

config：


# If set to true the disguises will be saved when the plugin is disabled（如果是true，的话当此插件失效时会自动保存）

save-disguises: true
# If set to true every disguised player has his original name above his head （如果是true，伪装的的玩家头上会有玩家的名字）
show-name-while-disguised: false
# Here you must put the worlds where disguising should be allowed （这里写上可以进行伪装的世界的名字）
permitted-worlds: {"world","world_nether","world_the_end"}
# If set to true players are undisguise when they hit another player （如果是true，当玩家攻击别的玩家时）会失去伪装
undisguise-on-hit-other: false
# If set to true the sound system is enabled, for more information visit http://dev.bukkit.org/bukkit-plu ... pages/sound-system/
（如果是true，伪装时也会有声音（意思就是伪装猫的时候会发出猫叫，其他同理））
sound-system: true
# If set to true players are undisguise when they are hit by a projectile (e.g. arrow, snowball)  （如果是true当玩家被投射物击中时失去伪装，例如箭）
undisguise-on-projectile-hit: false
# If set to false disguised players cannot be damaged （如果是false，伪装的玩家不能被伤害）
entity-damage-while-disguised: true
# Here you must put the language code, for more information visit http://dev.bukkit.org/bukkit-plu ... s/config-languages/（这里写语言）
localization: enUS
# If set to true players are undisguised when they are hit by another player or mob  (如果是true，当玩家被生物或玩家击中的话会失去伪装）
undisguise-on-hit: false
# If set to true mobs cannot target disguised players  （如果是true，生物不会主动攻击伪装的玩家）
no-target-while-disguised: false
# If set to true players must have "iDisguise.undisguise" permission to undisguise  （如果是true，玩家必须要有iDisguise.undisguise权限才能解除伪装）
permission-for-undisguise: false
# If set to true the plugin automatically checks if an update is available  （如果是true，插件自动检测更新）
check-for-updates: true
