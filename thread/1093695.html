介绍
本插件为AmazingBot的附属插件
请安装下面的插件才能使用
AamazingBot:
https://www.mcbbs.net/forum.php?mod=viewthread&tid=1093672
由于酷Q没了,很多酷Q的群管理插件也没法用了
所以开发了这款插件,起码能防止刷屏

功能
10秒内超过5次发言直接禁言用户(可开关)
自动同意加好友(可开关)
自动同意进群(可开关,有时会获取加群信息失败)
拉黑用户(被拉黑用户一旦发言将会立马撤回消息并禁言用户10天,
防止骂人后自己退群过几天加群又骂人的恶心人)
取消拉黑
超过设置消息长度自动禁言发送者10分钟,可自行设置
发送消息包含设置的违禁词自动撤回并禁言发送者10分钟,并向机器人主人发送详情(需要机器人好友)

配置文件
#自动同意进群
auto_accept_group: true
#自动同意好友
auto_accept_friend: true
#目前没用
auto_mute: true
#拉黑列表
permmutes: {}
#这个别管
debug: false
#最长消息长度,超过禁言10分钟
max-length: 300
#拉黑的关键词会撤回并禁言发送者10分钟,并且会给机器人主人发送详情
banned-words:
  - "完全软件批量自动化操作"
  - "让你自己轻松躺赚"
  - "电脑或手机"
  - "了解加VX"
