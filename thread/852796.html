GWMAutoResetMine
GWM自动重置矿物
这款插件允许你创建许多可以自动重置的矿物
试用视频

特点
完全不限量
完全可配置

依赖
Sponge API 7
GWMLibrary
（请见下载）
可选的
Holograms

指令

名称指令权限
主命令/gwmautominereset (/autotominereset, /gwmarm, /arm)
命令列表/gwmautominereset help
保存配置/gwmautominereset savegwm_autominereset.command.save
重载插件/gwmautominereset reloadgwm_autominereset.command.reload
重设矿区/gwmautominereset reset <mine>gwm_autominereset.command.reset.

配置

每次重载插件时都会尝试更新

如果要禁用它

请在config.conf中为变量CHECK_UPDATES赋值false。


没写的就是没用到


在GWMAutoMineReset.jar/mines下你可找到实例文件

去创建一个新矿区, 用.conf 格式 在/config/gwm_auto_mine_reset/mines


ID - 矿物的ID.

NAME - 矿区名字.

WORLD - 矿区所处世界

FIRST_POSITION - 第一个坐标.

SECOND_POSITION - 第二个坐标

RESET_DELAY - 重置间隔时间

REGENERATE_ALL_BLOCKS - 如果设置为true，所有块将被重置。若为false，则只重置空气块

TELEPORT_LOCATION - 在矿区重置后传送玩家到这个坐标

SEND_RESET_MESSAGE -  是否发送重置信息true/false)

CUSTOM_RESET_MESSAGE - 重置消息

RESET_MESSAGE_RADIUS - 发送重置信息的半径

SIGN_LOCATION - location of sign.

CUSTOM_SIGN_TEXT - text of sign.

HOLOGRAM_LOCATION - location of hologram.

CUSTOM_HOLOGRAM_TEXT - text of hologram.

AIR_PERCENT_TO_FORCE_RESET - (0.0 - 1.0) 当空气块的百分比达到多少，强制重置

AIR_PERCENT_TO_RESET - (0.0 - 1.0) 当空气块的百分比达到多少，重置。否则不重置

BLOCKS - 矿物的id:格式
