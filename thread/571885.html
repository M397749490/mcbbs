|| 功能介绍

1. 可使用图灵机器人接口,并使用此接口获取航班,列车,天气,新闻信息




2. 可使机器人回复的某些句子转换为私聊发送

请结合上面的图一起观察.



3. 可自定义词库并且随机发送指定语句




4. 可使用SimSimi词库
(下面是来自SimSimi的2机器人互掐以及游戏聊天效果图,请准备好狗粮)

|| 配置文件

Config.yml

  1. Key: false
  2. #图灵机器人接口APIKEY,当值为"false"时为禁用图灵机器人接口
  3. UsePrefix: true
  4. #是否使用关键字符触发聊天效果,true为启用,false为禁用
  5. UseJoinMesseng: true
  6. #是否在玩家加入服务器时发送一条信息,true为启用,false为禁用
  7. UseSpecificReply: true
  8. #是否启用特定语句词库,true为启用,false为禁用
  9. UseKeyWord: true
  10. #是否启用关键字词库,true为启用,false为禁用
  11. UseSimSimi: true
  12. #是否启用SimSimi词库,true为启用,false为禁用
  13. Prefix: '#'
  14. #设定触发机器人聊天的关键字符,当UsePrefix为true时启用
  15. ChatPrefix: §3§l[聊天机器人] => §b
  16. #设定机器人聊天时候的前缀,这个是每次机器人发送消息必带的.
  17. JoinMesseng: 欢迎%player%进入服务器!
  18. #设定玩家加入游戏时发送的信息,%player%为加入游戏玩家的名字,%lv%为玩家等级,当UseJoinMesseng为true时启用
  19. PrivateChat: http
  20. #当机器人回复的话语中包含这些关键字中的一个会将公开信息改为只向你发送消息,可用";"来添加更多关键词 例如: http;新闻
  21. NotFindReturnMessage: 你在说什么啊?我听不懂哎...;我不听,我不听!我听不懂!
  22. #设定当图灵机器人接口为关闭状态,词库中没有对应的词条所发送的消息,可用";"来增加更多语句
复制代码

KeyWord.yml

  1. 机器人: 谁叫我?;§l有人叫我吗?;诶? 好像有人叫我诶
  2. 事情: 什么事情?;是麻烦事吗?;什么事情 告诉我好吗?
  3. 关键词1: 回复语句1;回复语句2;回复语句3;...
  4. 关键词2: 回复语句1;回复语句2;回复语句3;回复语句4;...
  5. #优先级: KeyWord词库>图灵机器人接口 即当启用此词库与图灵机器人接口时,如果玩家发送句子中包含此词库中的词条,则会发送此词条中的回复语句而不是图灵机器人接口传来的
  6. #可以自己拓展词库,";"号用来将回复语句隔开,使用时就是用随机一条回复语句,可以使用颜色代码§b等
  7. #"§"是按住ALt,然后依次按下小键盘上的1,6,7后松开ALt键
复制代码

SpecificReply.yml

  1. Who are you?: I'm ChatterBot;我是话唠机器人!
  2. 关键句子1: 回复语句1;回复语句2;回复语句3;...
  3. 关键句子2: 回复语句1;回复语句2;回复语句3;回复语句4;..
  4. #优先级: SpecificReply词库>KeyWord词库>图灵机器人接口 即当启用此词库与KeyWord词库时,如果玩家发送句子中包含此词库中的词条也包含了KeyWord词库中的词条,则会发送此词条中的回复语句而不是KeyWord词库中的
  5. #可以自己拓展词库,";"号用来将回复语句隔开,使用时就是用随机一条回复语句,可以使用颜色代码§b等
  6. #"§"是按住ALt,然后依次按下小键盘上的1,6,7后松开ALt键

如何食用?
红色代表重要!
(可以关闭图灵机器人功能)
1.下载本插件
2.放到服务器的plugins文件夹里
3.运行一次服务器
4.打开图灵机器人官网:http://www.tuling123.com/ 并且注册账号,如果有账号可以跳过这一步

5.注册完后进入个人中心:
6.设置你的机器人名字之类的(可跳过):
7.选择机器人接入
复制API Key后面的字符串
8.打开plugins/Chatterbot/config.yml 将 Key后面的null改成第七步中复制的内容
9.打开服务器输入/tc就好了
配置区
                              
#Key在上面有详细教程
Key: null
#是否启用图灵机器人云词库
Enabled: true
#玩家加入时是否发送消息
JoinMesseng: true
#是否启用字符判断
UsePrefix: true
#就是句子的前缀,当你发送[#内容]机器人也会鸟你,UsePrefix启用时才会启用
Prefix: '#'
#机器人的前缀,随便改,颜色只支持§不支持&
ChatPrefix: §3§l[聊天机器人] => §b
#当玩家加入服务器时发送的消
Messeng: 欢迎来自[address]地区的玩家:[player]进入服务器!
#自定义回答,每个不同的句子用";"隔开,跟着例子弄即可
#当玩家发送/tc abc时,在abc冒号后面3个句子中随机选出一句回答,依葫芦画瓢增加就行!
SpecificReply:
  abc:你说什么?;我听不清!;&e你_大_点_声_音_啊!;§cabc?§l没听过!
  句子1:回答1;回答2;...;回答n
  句子2:回答1;回答2;...;回答n
#关键字回复
Keyword:
#  关键字1:语句1;语句2以此类推,下面为例子(和楼上差不多)
  a:你想干嘛?;你说说你想干嘛啊
  你:我叫殇啦!;你你你,你什么你;我怎么啦?

优先级:SpecificReply>KeyWord>图灵机器人词库
                              
                              
变量及空格之类代码:
[player]玩家名字,暂时不支持中文(除机器人名字)
[address]玩家所在地址(除机器人名字其他都有效)
_空格叔叔(除机器人名字其他都有效)
|换行(除机器人名字其他都有效)
;分隔句子(只有SpecificReply以及KeyWord)
