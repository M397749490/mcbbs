指令
/grapple give <player> <unbreakable>
给某个玩家一个无限耐久的抓钩
如果是给自己<player>可以省去
<unbreakable>为true的话是无限耐久，反之普通的。

/grapple reload
重新加载配置文件


权限
"grapplinghook.craft.basic" - 允许制作普通的抓钩，默认为开启
"grapplinghook.craft.unbreakable" - 允许制作无限耐久的抓钩，默认为开启
"grapplinghook.use" - 允许使用抓钩，默认为开启
"grapplinghook.command.reload" - 重新加载配置文件，默认op拥有权限
"grapplinghook.command.give.self" - 允许使用指令给自己普通的抓钩，默认op拥有权限
"grapplinghook.command.give.others" - 允许使用指令给别人普通的抓钩，默认op拥有权限
"grapplinghook.command.give.self.unbreakable" - 允许使用指令给自己无限耐久的抓钩，默认op拥有权限
"grapplinghook.command.give.others.unbreakable" - 允许使用指令给别人无限耐久的抓钩，默认op拥有权限
"grapplinghook.admin" - 所有权限的总权限(拥有这一个权限，所有权限都会获得)，默认op拥有权限
"grapplinghook.player" - 制作和使用的总权限(拥有这一个权限，2个制作权限和1个使用权限都会获得)，你可以在config配置文件中单独取消某个权限


配置文件
basic: true
  ##是否可以制作无限耐久的抓钩
  unbreakable: true
##抓钩部分
grapple:
##抓钩的力度
  strength: 0.2
##权限部分
permission:
##玩家默认拥有权限
  playerdefault:
   ##是否允许制作普通的抓钩，默认开启
    craftbasic: true
    ##是否允许制作无限耐久的抓钩，默认开启
    craftunbreakable: true
    ##是否允许使用抓钩，默认为开启
    use: true
##消息部分
locale:
##没有权限显示的信息
  noperm: '&4你没有权限!'
  ##无效玩家显示的信息
  invalidplayer: '&4那不是一个有效的玩家'
  ##如果控制台输入指令显示的信息
  onlyplayers: '&4只有玩家才能使用这个指令!'
  ##给玩家一个普通的抓钩，玩家显示的信息，%player%是给玩家抓钩的OP/控制台。
  givebasic: '&2%PLAYER%给了你一个普通的抓钩!'
  ##给玩家一个无限耐久的抓钩，玩家显示的信息，%player%是给玩家抓钩的OP/控制台。
  giveunbreakable: '&2%PLAYER%给了你一个无限耐久的抓钩!'
  ##重新加载配置文件显示的信息
  reload: '&2插件的配置文件重载完成!'
