Confirm Menu
——在执行指令之前先确认

|介绍
本插件能够让您在执行任何指令（包括其它插件的指令）之前弹出一个 GUI 确认窗口，点击确认后才能执行该指令，并且可在 Spigot 1.8-1.15 的任意一个版本中使用。
除了英语之外，确认菜单 插件还支持法语和西班牙语。
开源地址：https://github.com/MaximePremont/ConfirmMenu
捐助链接：https://www.paypal.me/MaximePremont

|图片

|权限
"confirmmenu.skip"：跳过确认菜单（确认菜单是可以选择不使用的）
"confirmmenu.update"：在加入服务器的时候接收插件更新信息

|指令
貌似没有指令

|配置
config.yml：
  1. # 以下指令在执行前需要先弹出确认菜单：
  2. Commands: "stop, reload"

  4. # 是否在打开确认菜单时播放声音
  5. OpenSound: true
  6. # 服务器管理员是否默认跳过确认菜单（权限：confirmmenu.skip）
  7. SkipPermsForOP : false
  8. # 自定义消息（支持颜色代码）
  9. Text:
  10.     ConfirmMessage: "&e你确定？"
  11.     MenuTitle: "&8&l确认菜单"
  12.     MenuConfirm: "&a&l确认"
  13.     MenuCancel: "&c&l取消"
  14.     NewVersion: "&e确认菜单 插件有更新！"
  15.     UpdateFail: "&c无法自动检查更新！"
  16. # 重启服务器后对于语言的修改才有效
  17. # 支持的语言：英语（EN）|法语（FR）|西班牙语（ES）|其它（OTHER）
  18. Language : "OTHER"
  19. # 是否自动检查更新并将更新消息发送到后台
  20. UpdateCheck: true
