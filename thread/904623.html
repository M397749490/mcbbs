Notes
纸币
无邪的插件交流群: 170032890

功能简介
玩家可通过聊天界面,发送提现消息提现!
提现后获得相应面值的'纸币'~
然后手持'纸币'右键,可获得相应的钱。

用途说明
可灵活用于一些以物易物的插件,达到经济支持!
也能用于玩家存储自己的经济!
普遍的灵活使用案例通常相对于shopkeepers村民商店插件
众所周知,村民商店是经典的以物易物的插件,但是也仅限于
以物易物,使用此插件,可以突破这个限制,我开发此插件的
初衷也是于此,但不仅限于此,并且这个插件很灵活,可以用于
各种场景,如mm掉落,道具消耗,兑换,以及获得道具中使用~

配置文件
  1. # 最小提现金额
  2. min-money: 50
  3. # 最大提现金额
  4. max-money: 50000
  5. # 提现关键字
  6. # 如聊天发送 提现100
  7. chatAction: '提现'
  8. # 纸币设定
  9. # %amount%为面值变量
  10. item:
  11.   # 1.13版本及以上可能物品的id会有所变动，请参阅对应版本的id表
  12.   id: PAPER
  13.   data: 0
  14.   name: "&6&l银票 &7(右键)"
  15.   lore:
  16.   - "&9类型: &6银票"
  17.   - "&7&m=-=-=-=-=-=-=-=-=-="
  18.   - "&b面值: &c%amount%"
  19.   - "&7&m=-=-=-=-=-=-=-=-=-="
  20.   - "&6&l?&e&l江湖通币&6&l?"
  21.   - "&7&m=-=-=-=-=-=-=-=-=-="
  22.   - "&9获得方法:"
  23.   - "  &7聊天界面发送 '提现 %amount%'"
  24.   - "  &7之后会从你的账户扣走 %amount% 铜钱！"
  25.   - "  &7并且给你一张等值的票子~！"
  26.   - "&7&m=-=-=-=-=-=-=-=-=-="
  27.   # 获得纸币面值的行号(往第一行从0开始数)，该行必须有'%amount%'
  28.   vault-amount-location: 2
  29. # 消息文本
  30. message:
  31.   # 提现消息
  32.   withdrawal:
  33.     notInvEmptySlot: "&7您的背包满了,请清理一下再试！"
  34.     success: "&a提现成功，本次提现 {0} 铜币&7！"
  35.     insufficient: "&7您的可提现钱不足 {0} &7！"
  36.     range: "&7您的提现范围是 &a{0} &7-&a{1} &7！"
  37.   useNotes: "&a使用成功，您的铜币余额增加了 {0} &7！"
  38.   reload: "&a重载！"
