创建一个新物品

  • 您需要在src目录下创建一个“ItemExample.java”的类文件
  • 类文件的基本结构如下：

  1. package net.minecraft.src;

  3. public class ItemExample extends Item
  4. {
  5.     public ItemFood(int i)
  6.     {
  7.         super(i);
  8.         maxStackSize = 64;
  9.     }

  11.     public ItemStack onItemRightClick(ItemStack itemstack, World world, EntityPlayer entityplayer)
  12.     {
  13.     }
  14. }
复制代码

  • 此时需要使Minecraft识别您所添加的物品，打开"Item.java"进行编辑。
  • 在文件的低端您应该可以发现一大堆实体变量，在下面添加一个新的实体变量。具体说明如下：


  1. public static Item example = (new ItemExample(95)).setIconIndex(42);
复制代码
  • 这一语句可以为您添加一个使用物品ID为256+95的物品，并使用图标42，此时这个物品看起来应该像是告示牌。当前这个物品没有属性，也不能被合成。但是在您编译并运行Mincraft后即会添加这一物品。
