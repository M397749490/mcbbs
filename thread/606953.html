作者: YingHuaDan    时间: 2016-7-21 10:10
打开基础插件配置文件，修改为这样就行
  1. # 玩家是否可以建造:
  2.     # 设置为 true 可以禁用那些没有权限玩家的建造
  3.     # 设置为 false 将使 EssentialsXAntiBuild 从不阻止玩家建造
  4.     build: false

  6.     # 玩家是否可以使用物品(当玩家没有build权限的时候):
  7.     # 设置为 true 可以禁用那些没有权限玩家的使用物品
  8.     # 设置为 false 将使 EssentialsAntiBuild 从不阻止玩家使用物品
  9.     use: false

  11.     # 玩家无法建造时是否提示玩家
  12.     warn-on-build-disallow: false
