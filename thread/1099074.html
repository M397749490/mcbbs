标题: 如何利用资源包修改唱片名称中的曲目信息
如题，唱片名称包含“音乐唱片”和下方的曲目信息（例如“C418-Cat”）
“音乐唱片”是可以用铁砧修改的，但曲目信息如何修改呢？能否用资源包实现？
作者: ⊙u⊙    时间: 2020-8-11 15:23
替换中文语言下某段文字内容
  • 从先前版本jar里复制出来的minecraft文件夹中，里面有个lang文件夹，打开
  • 里面有个en_US.lang的文本文件，打开
  • 同时得知，语言文本的存放位置为assets\minecraft\lang\en_US.lang
  • 搜索关键字creative，其中有一行是gameMode.creative=Creative Mode
  • 搜索关键字gui，其中有一行是gui.no=No
  • 搜索关键字command block，其中有一行是tile.commandBlock.name=Command Block
  • 在教程\assets\minecraft下新建名为lang的文件夹，并打开
  • 新建名为zh_CN的txt文本，后缀改为lang，并打开
  • 输入以下，保存
  1. gui.no=不，不是的
  2. gameMode.creative=不要脸模式
  3. tile.commandBlock.name=内挂方块
复制代码


*注意事项
在1.11起，这个lang文件的名字也是要求全小写，如原本的
en_US.lang变为en_us.lang
zh_CN.lang变为zh_cn.lang

在1.13起，这个lang文件后缀为json，里面的内容变为json格式之外，
部分名字也有略微的变化，如原本的
en_us.lang变为en_us.json
内容则从
  1. gui.no=No
  2. tile.commandBlock.name=Command Block
复制代码
变为
  1. {
  2.   "gui.no": "No",
  3.   "block.minecraft.command_block": "§d内挂方块"
  4. }
复制代码
