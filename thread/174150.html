如果不玩MOD弄只bukkit不是更方便吗.w.

到http://dl.bukkit.org/下载一只服务器端，如果是Windows在同一个目录下新建一个run.bat（只要是.bat就可以），里面输入
  1. java -Xmx1024M -jar craftbukkit.jar -o false
  2. PAUSE
复制代码
，其中-Xmx1024M是分配最大1GB RAM，craftbukkit.jar要改成你的服务器端的文件名，-o false是关闭在线模式（允许盗版）

而Linux则用nano run.sh，然后输入
  1. #!/bin/sh
  2. BINDIR=$(dirname "$(readlink -fn "$0")")
  3. cd "$BINDIR"
  4. java -Xmx1024M -jar craftbukkit.jar -o flase
复制代码
同样，-Xmx1024M是分配最大1GB RAM，craftbukkit.jar要改成你的服务器端的文件名，-o false是关闭在线模式（允许盗版）

Windows启动双击run.bat即可，Linux就./run.sh（用绝对地址也可以=-=
