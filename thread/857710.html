1.安装插件
1、丢入你的plugins文件夹
2、(重要)插件配置文件config.yml中填入正确的服务器 SID 以及 KEY
3、打开您的服务端，载入各类充值渠道费率即为配置成功
4、开冲！
     服务器内输入/vexrmb create (想充值的金额) w 即可获取WX充值二维码
     服务器内输入/vexrmb create (想充值的金额) q 即可获取Q钱包充值二维码
     服务器内输入/vexrmb create (想充值的金额) z 即可获取支付宝充值二维码
