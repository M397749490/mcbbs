楼上两个说的都对，
字符串是不能使用==比较的，因为==会比较内存地址。
应使用equals()方法
其次,
你的事件类(你的主类)并没有被注册为事件类。
也就是说，你有事件方法，但是你没告诉插件，插件不会管你。
推荐看看站内教程
或者直接加上
  1.     @Override
  2.     public void onEnable(){
  3.             try {
  4.             Bukkit.getPluginManager().registerEvents(this,this);
  5.             }catch(Error err) {}
  6.     }
复制代码
