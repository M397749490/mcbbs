SuperAntiWDL

添加对Bungeecord和Bukkit/Spigot的支持

特点:
● 反 Laby Mod
                       ● 反 VoxelMap MOD (小地图)
                                    ● 反 ReiMiniMap MOD (另一种小地图)
                                          ● 反 Damage Indicators MOD (血量显示)
                                        ● 反 World DownloaderMOD (地图下载)
                                    ● 反 Schematica MOD (保存地图建筑)
                   ● 反 LiteLoader MOD (API)
                   ● 反 5zig Mod (自定义皮肤)
          ● 反 Forge Mod (API)
                       ● 控制台禁止恶意MOD的Log
● 反黑客登录     
                                                          ● Notification System通知系统 (在Config.ym里开启)
● 自定义惩罚命令

命令:

无

变量:

            ● %player% - 玩家名字
        ● %ip% - 玩家IP地址
          ● %uuid% - 玩家的UUID

权限:

  superantiwdl.bypass.mod.liteloader - 无视 LiteLoader 的保护!
superantiwdl.bypass.mod.forge - 无视 Forge 的保护!
superantiwdl.bypass.mod.5zig - 无视 5zig 的保护!
superantiwdl.bypass.mod.bettersprinting - 无视 BetterSprinting 的保护!
        superantiwdl.bypass.mod.schematica - 无视 Schematica Mod 的保护!
superantiwdl.bypass.mod.labymod - 无视 Laby Mod 的保护!
superantiwdl.notify.mod.<ModName> - 接收某个MOD的通知(<ModName>为小写)

#白名单
whitelist: []
#MOD检测管理 设置false为关闭true为开启
disable_mods:
  rei: false
voxel: false
  damageIndicators: false
  worldDownloader: true
  schematica: false
  Forge: false
  LiteLoader: false
  BetterSprinting: false
5zig: false
#消息通知
notification-messages: false
#玩家被踢出的日志
logging: true
#控制台显示被禁止的MOD
log-blocked-mods: true
#黑客登录
enabled: true
