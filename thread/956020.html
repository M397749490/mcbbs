需要填写sound.json并放入材质包文件(路径：assets/minecraft)内以让游戏识别音频的路径
编写很简单的，example：
{
        "sfx_positive":
        {
                "category": "record",
                "sounds":
                [{
                        "name": "sfx_positive",
                        "stream": false
                }]
        },
                "everythingsuck":
        {
                "category": "record",
                "sounds":
                [{
                        "name": "everythingsuck",
                        "stream": false
                }]
        }
}
