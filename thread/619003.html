CommandsItem
可以给手上的物品绑定指令
----------------更好的给物品绑定指令

指令列表:
/ci add <命令标记> 给手上的物品添加一个命令标记
/ci remove 删除一个命令标记
/ci reload 重载插件


命令标记设置:
插件加载后会生成文件夹
找到config.yml
     例子1
1:
  #命令标记
    permission: "jason.say"
    #需要的权限,没有这行就不需要权限
    exe: "player"
    #执行方式,server为后台,player为玩家
    is_op: true
    #是否用OP权限执行
    is_use: true
    #是否消耗当前物品
    cmds:
    #执行的命令列表
    #变量:
    #玩家:{player}
      - "say {player} 你好"



上面的命令标记是1(可以随意更改或者添加)
那么你拿着手上的物品输入/ci add 1。就能成功给手上物品绑定指令say {player} 你好
  就是这么简单...
