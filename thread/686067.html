CC-DH 10.0
一款强势的死亡提示插件

一、简介 Description
这款插件有好多种功能，死亡以后不会给你死亡界面而是标题提示还有几秒钟复活！是不是有些心动~

二、功能 Features
·自定义配置
·多语言
·标题提示
·复活需等待的时间
·浮空字提醒 [HolographicDisplay前置]
·PVP限制[防止玩家战斗时逃跑]
·计分板
·治疗箭
·音效&特效
·死亡后掉落头颅
·每秒点击次数统计[ActionBarAPI前置]

·死亡箱子[死亡以后所有东西会进入箱子，玩家可以搜刮]
