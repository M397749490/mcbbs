◆ 插件功能 ◆
本插件只适合版本1.11-1.11.2服务器
（但是作者即将支持低版本，敬请期待）
本插件利用服务器材质包发挥功能，可以创造出自定义材质的方块，你可以创造出一个六面均为某一自定义图片的一个方块
这些方块的本体都是刷怪笼，玩家可以使用任何镐子破坏并获得（别担心，是获得自定义材质方块，不是获得刷怪笼，更没有经验掉落），如果你不想让玩家获得，请将这些方块放置在安全的区域

因为这些方块的本体都是刷怪笼，所以你还可以制作一些奇♂怪的东西

◆ 指令 ◆
/ub add <图片的网址>  添加一种方块
/ub gui打开所有已添加的方块菜单，点击可获得方块
/ub remove <方块编号>移除一种方块
/ub reload重载插件
/ub rename <方块编号> <新名字>给方块重命名
/ub addtile <图片网址> <宽几格> <高几格> 允许一张图片跨越多格

没有任何玩家可执行的指令或者权限，一切由管理员操作

◆ 配置文件 ◆
  1. # 检查更新
  2. enable-update-checker: true

  4. # 自动下载
  5. auto-download-updates: true

  7. # 破坏此方块时是否有粒子效果
  8. noParticles: true

  10. # 设置为true，则原刷怪笼材质将完全不可见，设置为false，可以见到刷怪笼背景材质
  11. noSpawnerTexture: false

  13. # 如果你已经有一个服务器材质包了，请把zip文件的链接放在这里
  14. existing-resource-pack: "NONE"

◆ 注意事项[必看] ◆

  • 本插件利用服务器材质包工作，请玩家在进服之前把“服务器材质包”设定为启用
  • 玩家可以放置，或者使用镐挖取这些方块(不会有经验掉落)，如果你不想让玩家得到这些方块，请把这些方块放在安全的地方
  • 大量自定义材质方块可能会卡客户端
  • 玩家客户端更换材质包不会影响本插件功能
