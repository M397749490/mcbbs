标题: [安全]WaterLimiter —— 只有在领地中的水和岩浆可流动![1.7.2-1.16]
简介
服务器中大量流动水会严重卡服，但是限制流动水也会造成很多不便，本插件可以限制只有在领地内的水以及岩浆可以流动，一旦超出领地范围所有的水流都会停止。本插件基于bukkit1.7.2编译(2.2.0版本开始基于spigot-1.15.2),理论支持全版本。

权限&指令
  • WaterLimiter reload: 重载配置文件



配置文件
以下为2.2.0版本前配置


  2. world:
  3.   residence:
  4.     LAVA: true
  5.     WATER: true
  6.   world:
  7.     LAVA: true
  8.     WATER: true
  9.     high:
  10.       LAVA: 0
  11.       WATER: 0
  12. world_nether:
  13.   residence:
  14.     LAVA: true
  15.     WATER: true
  16.   world:
  17.     LAVA: true
  18.     WATER: true
  19.     high:
  20.       LAVA: 0
  21.       WATER: 0
  22. world_the_end:
  23.   residence:
  24.     LAVA: true
  25.     WATER: true
  26.   world:
  27.     LAVA: true
  28.     WATER: true
  29.     high:
  30.       LAVA: 0
  31.       WATER: 0
复制代码

residence下代表领地内液体流动设置true为阻止，false为可流动。world为领地外液体流动设置，true为阻止，false为可流动。high设置代表了在此高度以下水流和岩浆在非领地范围内也可流动，不受world配置项限制。


安装方法

直接扔进plugin
注意必须限制Essentials中允许水流流动，否则本插件不会生效。



演示截图

图示中正中玻璃方块为领地范围，领地中水流皆可流动，领地外，水流不流动。
