◆介绍◆
This plugin prevents players from sprint-flying to prevent excessive chunk-generation.
This is especially useful in 1.14 servers as the world format is extremely unoptimised and chunk-generation causes a lot of lag.
The plugin also adds a cooldown to elytra/firework usage to prevent players from reaching very high speeds for chunk-generation on elytras.
Moreover, trident/riptide usage is also throttled in the rain for the same reason.  
There is currently no configuration options for this plugin, but they will be added if there is high demand for it.

这个插件可以防止玩家用鞘翅滑翔时速度过快，使区块过度加载。
在1.14版本的服务器中很有用（因为mojang负优化），过度加载区块会造成卡顿。
这个插件还添加了鞘翅/烟花的冷却时间，防止玩家在天上逮虾户导致区块过度加载。
此外，三叉戟和激流附魔在雨中也会受限制。
目前插件没什么配置选项，如果有需要，后面会添加。
命令/权限
speedlimiter.bypass - 绕过插件的所有限制
配置文件

  2. elytra-cooldown: 15
  3. trident-cooldown: 5
