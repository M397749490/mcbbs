更多的玩法 server

停更说明

由于是第一次写，不够熟练，有很多问题存在，起名也过于随意，更多的玩法server永久停更

建议不要下载了，因为任何bug都不再维护，也不兼容后续新坑

--------------------------------------------------------------------------------

特色功能

在任意维度死亡后，包括自定义维度，及原版本来不存在的维度中死亡后仍能通过/trigger mwsback返回，且并非采用常加载死亡区块

--------------------------------------------------------------------------------

版本预告

将更名为更多的玩法 v1.0.0 文件结构调整，前缀更新，更简单的使用

实际版本会有所出入，作者是初三党了，学业为重

加入 home ，spawn，使用手册

玩家数据备份，无限设置 home，tp请求多位储存，爆炸保护由全局防爆调整为局部防爆，需玩家手动放置爆炸节制器

玩家可设置昵称（非聊天栏中），home家可设置名称，玩家的基本信息可以通过书与笔查询（不仅玩家信息）

采票系统 可全自动开奖、无限制购票（可设置购买上限）、无需人工兑票、奖品以积分形式发放

--------------------------------------------------------------------------------

适用场景：局域网联机、原版服务器、不想使用ESS等插件的服务器（大服人家都自己写插件了呜呜）

适用版本：20w30a+

数据包请和资源包配合使用，资源包目前仅语言文件，无需担心卡顿

命名空间 mws 一般前缀 mws translate前缀 xxx.mws.

CustomModelData 暂未添加物品 预计使用 12520000-12529999

资源包中的zh_cn.json可适当修改 但请适度 有关作者的信息不得修改

注意事项：请不要直接使用修改@e的指令 例如kill @e, tp @e 等等 如果有必要，务必使用@e[tag=!mws]

                 因使用此类指令而造成的bug概不负责

2.ESSD (Essentials Datapack)

    TPA、BACK

    /trigger <mwstpa|mwstpahere> set <uid> 发送传送请求 (tpa将传送至对方,tpahere将对方传送至当前坐标点而非玩家)

    /trigger mwstpacancel 取消已发送请求 (仅对在线玩家生效)

    /trigger <mwstpdeny|mwstpaccept> 拒绝/接受传送请求

    /trigger mwsback 返回上一坐标点

    当腐竹未设置请求自动取消时间默认为120秒，通过 /scoreboard players set #mwsvalue mwstpaccd <time> 设置时间 (单位:秒)
