我的服务器是cauldron服，机子总内存1g，但是生存服务器经常崩溃，平常在线不会超过3人，看原因是内存溢出，我安装了自动重启等优化插件也没有用，还是会崩溃。
以下是错误报告

>run.sh: line 2:  1253 Killed                  java -Xms1024m -Xmx1024m -jar cauldron-server.jar nogui


作者: 红石大触    时间: 2017-1-16 00:41
您好，我经过分析，去查Java错误大全（需要翻墙）中，1253 Killed的显示为内存分配失效，无效内存量或内存回收机失效！
建议您写成这样：
run.sh的内容：
java -Xmn128M -Xmx1024M -jar cauldron-server.jar nogui
意思：
运行jar包，随机最小内存为128M，最大内存为1024M（1G）
注：
如果楼主机子是Linux的，像-Xmx 一个数M（后面跟的必须是M，我试过了，G，T，KB，B，都不行）
大部分除Windows外。
