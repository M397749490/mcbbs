这个方法最大的问题就是非常复杂。如果你有耐心的话，我可以教你一些思路：

首先最关键的就是数据包，虽然没有直接的数据包能让玩家摆出拉弓的姿势，但是我发现，玩家拉弓发出的是PacketPlayOutEntityMetadata数据包
顺藤摸瓜，就可以得知，这个数据包可以让接受到的玩家看见目标玩家使用手中物品，包括钓鱼，吃东西，以及拉弓
是不是可以利用这个来做出拉弓的动作呢？
首先目标玩家手中的物品必须是弓，当然可以使用其他材质。这样我们就可以创建一个数据包，并广播到除了目标玩家以外的玩家：

  1. public void gunPose(Player player) {
  2.         DataWatcher watcher = new DataWatcher(((CraftPlayer) player).getHandle());
  3.         watcher.register(new DataWatcherObject<>(6, DataWatcherRegistry.a), (byte) 1);
  4.         PacketPlayOutEntityMetadata packetPlayOutEntityMetadata = new PacketPlayOutEntityMetadata(((CraftPlayer) player).getHandle().getId(), watcher, true);
  5.         Bukkit.getOnlinePlayers().forEach(p -> {
  6.             if (!p.getName().equals(player.getName())) {
  7.                 ((CraftPlayer) p).getHandle().playerConnection.sendPacket(packetPlayOutEntityMetadata);
  8.             }
  9.         });
  10.     }

如果你不希望枪械是弓，而是其他物品，也有解决办法。首先你要保证枪械的物品和对应的弓材质是一样的，发送PacketPlayOutEntityEquipment包，让接收到的玩家看见目标玩家手中的武器变成了弓:
  1. public void gunPose(Player player) {
  2.         ItemStack itemInMainHand = player.getInventory().getItemInMainHand().clone();
  3.         if (itemInMainHand == null) {
  4.             itemInMainHand = new ItemStack(Material.BOW);
  5.         }
  6.         itemInMainHand.setType(Material.BOW);
  7.         net.minecraft.server.v1_12_R1.ItemStack item = CraftItemStack.asNMSCopy(itemInMainHand);
  8.         PacketPlayOutEntityEquipment packetPlayOutEntityEquipment = new PacketPlayOutEntityEquipment(((CraftPlayer) player).getHandle().getId(), EnumItemSlot.MAINHAND, item);

  10.         DataWatcher watcher = new DataWatcher(((CraftPlayer) player).getHandle());
  11.         watcher.register(new DataWatcherObject<>(6, DataWatcherRegistry.a), (byte) 1);
  12.         PacketPlayOutEntityMetadata packetPlayOutEntityMetadata = new PacketPlayOutEntityMetadata(((CraftPlayer) player).getHandle().getId(), watcher, true);
  13.         Bukkit.getOnlinePlayers().forEach(p -> {
  14.             if (!p.getName().equals(player.getName())) {
  15.                 ((CraftPlayer) p).getHandle().playerConnection.sendPacket(packetPlayOutEntityEquipment);
  16.                 ((CraftPlayer) p).getHandle().playerConnection.sendPacket(packetPlayOutEntityMetadata);
  17.             }
  18.         });
  19.     }
复制代码
建议参考optifine或者mcpatcher的自定义物品材质，可以提供更人性的材质修改。
这个数据包可以让玩家持续做出拉弓动作，但是玩家做出其他动作（例如切换物品，丢弃物品，物品更新）的时候会取消，我目前的做法是用BukkitRunnable循环，每隔一段时间操作一次。你也可以用监听器，这个就不多阐述
