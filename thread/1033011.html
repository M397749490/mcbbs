如果是破坏后的粒子效果一般在assets\minecraft\models\block的json文件中（记事本可以打开，名字都是对应物体的英文名称），但是由于这些文件都存在子级父级关系推荐你弄懂材质包再来修改粒子指定文件夹。
比如以梯子的json文件（ladder.json）为例：
文件中存在格式：
  1. {
  2.     "ambientocclusion": false,
  3.     "textures": {
  4.         "particle": "block/ladder",
  5.         "texture": "block/ladder"
  6.     },
  7.     "elements": [
  8.         {   "from": [ 0, 0, 15.2 ],
  9.             "to": [ 16, 16, 15.2 ],
  10.             "shade": false,
  11.             "faces": {
  12.                 "north": { "uv": [ 0, 0, 16, 16 ], "texture": "#texture" },
  13.                 "south": { "uv": [ 0, 0, 16, 16 ], "texture": "#texture" }
  14.             }
  15.         }
  16.     ]
  17. }
复制代码

其中 "particle": "block/ladder",指定了破坏粒子贴图位置，即assets\minecraft\textures\block中的ladder贴图
