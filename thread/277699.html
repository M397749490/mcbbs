大家好，这里是Soft。话不多说，直接进入正题。两周前学了统计与概率，讲投针试验的时候老师说了一个通过随机数和概率计算圆周率的方法，上课就想到可以用MC来实现，于是两周之中就抽了点时间做了这个。

预备知识：
任取三个正数，能构成钝角三角形的概率是：
设这三个正数中最大的一个为a，另外两个分别为x，y.
则有0<x≤a，0<y≤a；即点（x，y)在直角坐标系XOY中正好构成一个边长为a的正方形。
(i)要构成一个三角形,则须满足:x+y>a,这样的点的集合表示的是正方形面积a^2的一半,
(ii)而x，y，a形成钝角三角形，还需满足x2+y2<a2，这样的点组成的是四分之一的
圆（πa2/4)减去一个三角形（a2/2)后的弓形。
于是概率P=[（πa2/4)-（a2/2)]/a2=(π-2)/4
所以我就利用随机数生成器和1.8强大的记分板系统将这种算法在MC中实现了。

展示：

这就是所有电路。左边一半是随机器，右边一半是检测器。

随机器不断生成3个1-18内的随机数a,b,c，被送到右边进行判断。若能构成钝角三角形则会输出。如此循环计算，每次计算大概耗时2s左右。这里挂了一会机，已经进行了一千多次运算：
m=1566,n=391(m为总次数，n为成功次数）
∴n/m=P(构成钝角三角形的）=（π-2）/4
解得差不多为3，当然计算次数过少，误差还是比较大的。

原理
随机器大家都比较熟悉了，就不再赘述了。主要讲解一下检测部分。
  1. 1.三组主随机器在两个子随机器中抽取一个

  3. 2.各组子随机器抽取三个1~18的随机正整数存入a,b,c

  5. 3.确认是否存在以a,b,c为三边的三角形
  6. (1)求a+b,a+c,b+c的值
  7. ①if a+b＞c
  8. /scoreboard objectives operation @a a+b += @a b
  9. /scoreboard objectives operation @a a+b += @a a
  10. ②if a+c＞b
  11. /scoreboard objectives operation @a a+c += @a c
  12. /scoreboard objectives operation @a a+c += @a a
  13. ③if b+c＞a
  14. /scoreboard objectives operation @a b+c += @a c
  15. /scoreboard objectives operation @a b+c += @a b
  16. (2)将a+b,a+c,b+c与c,b,a相减
  17. ①a+b-c
  18. /scoreboard objectives operation @a nc += @a a+b
  19. /scoreboard objectives operation @a nc -= @a c
  20. ②a+c-b
  21. /scoreboard objectives operation @a nb += @a a+c
  22. /scoreboard objectives operation @a nb -= @a b
  23. ③b+c-a
  24. /scoreboard objectives operation @a na += @a b+c
  25. /scoreboard objectives operation @a na -= @a a
  26. (3)检测a+b-c,a+c-b,b+c-a是否全部大于1
  27. /testfor @p[score_nc_min=1]
  28. /testfor @p[score_nb_min=1]
  29. /testfor @p[score_na_min=1]

  31. 4.确认是否存在以a,b,c为三边的钝角三角形
  32. （1）求a2,b2,c2的值
  33. /scoreboard objectives operation @a a2 *= @a a
  34. /scoreboard objectives operation @a a2 *= @a a
  35. /scoreboard objectives operation @a b2 *= @a b
  36. /scoreboard objectives operation @a b2 *= @a b
  37. /scoreboard objectives operation @a c2 *= @a c
  38. /scoreboard objectives operation @a c2 *= @a c
  39. (2)求a2+b2,a2+c2,b2+c2的值
  40. ①a2+b2
  41. /scoreboard objectives operation @a a+b2 += @a b2
  42. /scoreboard objectives operation @a a+b2 += @a a2
  43. ②a2+c2
  44. /scoreboard objectives operation @a a+c2 += @a c2
  45. /scoreboard objectives operation @a a+c2 += @a a2
  46. ③b2+c2
  47. /scoreboard objectives operation @a b+c2 += @a c2
  48. /scoreboard objectives operation @a b+c2 += @a b2
  49. (3)将c,b,a与a2+b2,a2+c2,b2+c2相减
  50. ①c2-(a2+b2)
  51. /scoreboard objectives operation @a nc2 += @a c2
  52. /scoreboard objectives operation @a nc2 -= @a a+b2
  53. ②b2-(a2+c2)
  54. /scoreboard objectives operation @a nb2 += @a b2
  55. /scoreboard objectives operation @a nb2 -= @a a+c2
  56. ③a2-(b2+c2)
  57. /scoreboard objectives operation @a na2 += @a a2
  58. /scoreboard objectives operation @a na2 -= @a b+c2
  59. (4)检测c2-(a2+b2),b2-(a2+c2),a2-(b2+c2)任意一个大于1
  60. /testfor @p[score_nc2_min=1]
  61. /testfor @p[score_nb2_min=1]
  62. /testfor @p[score_na2_min=1]

另外提供另一种设想以供参考：
随机在[0,k]中抽取一个a和一个b，如果a^2+b^2<k^2则视为有效数据
如果m次中有n次有效，那么n/m约等于PI/4。
证明的话，画个图，a横轴b纵轴，这样有效部分就是一个0为圆心k为半径的圆在第一象限的部分。
这种办法可以简化很多关于abc的讨论，只要一步判断就可以出结果。
另外用模电随机可以很容易的把数据扩大到[1,1000]或者更大，接高频的话可以每2tick输出一个随机数据。
