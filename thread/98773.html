综合包注意事项
1. 多世界的新世界没权限问题，请戳插件地址查看解决方案
2. 因为SCS半砖bug较多作者们不经常更新，暂且从152包中移除
3. 名字标签编辑插件会与血条插件有点冲突，血条会覆盖掉玩家名字标签，reload插件才能恢复。可通过禁用玩家血条来解决。
player-bars:
  enable: false
  display-style: 1
  text-mode: false

当然，如果你能通过其他的方法实现定时/ne reload 也是可以的
NametagEdit 与 Health Bar 不共存！！！
4.关于重生点设置，唉... 众口难调啊，如果你不满意整合包的重生处理，打开essential下的config，翻到最下面，找到以下部分，根据个人口味修改
  1. # 设置为 lowest, 如果你想使用 Multiverse 处理重生
  2. # 设置为 high, 如果你想使用 EssentialsSpawn插件 处理重生
  3. # 设置为 highest, 如果你想强制使用 EssentialsSpawn插件 处理重生
  4. respawn-listener-priority: high

  6. # 设置为true,来使玩家死后,重生在自己家,而不是出生点
  7. respawn-at-home: true
