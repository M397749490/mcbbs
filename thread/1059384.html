标题: 如何让基岩变成可以被仅一种工具可挖掘
想制作一个能挖掘基岩的镐子，镐子做出来了却卡在了基岩挖掘这一步，我应该如何改变基岩的属性让他能且只能被这个镐子挖掘?
作者: 天辉胡萝卜    时间: 2020-6-10 06:18
在镐子的onItemUse里面判断挖掘的是不是基岩，是的话替换成空气然后生成基岩掉落物

  1. public boolean onItemUse(ItemStack stack, EntityPlayer player, World world, int x, int y, int z, int side, float hitX, float hitY, float hitZ)
  2. {
  3.     if(!world.isRemote)
  4.     {
  5.         if(world.getBlockId(x, y, z) == Block.bedrock.blockID)
  6.         {
  7.             world.setBlockToAir(x, y, z);
  8.             EntityItem entityitem = new EntityItem(world, player.posX, player.posY, player.posZ, new ItemStack(Block.bedrock));
  9.             world.spawnEntityInWorld(entityitem);
  10.             stack.damageItem(1, player);
  11.             return true;
  12.         }
  13.     }
  14.     return false;
  15. }
