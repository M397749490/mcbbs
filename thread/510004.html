简介：
        建立无需红石驱动的灯，用指定工具直接打开的灯
        无需红石，只需右击。
        当你不会食用红石或杠杆，右击你的灯,让它照耀吧！
        便捷，简单，易学，MC小白的最佳选择！
权限：
autolamp.use 允许使用指令（/lamp）
autolamp.add 添加(一个)灯
autolamp.remove
 移除添加(一个)的灯
autolamp.info
 显示灯的信息
autolamp.always_on 始终开（灯）
autolamp.always_off 始终关（灯）


指令：
         /lamp      -------菜单
使用方法：
               ToolID=                          Tool Item ID, You can use id as ID or ID:DATA, for example 5 or 5:4
               大概是这样的：你可以用原版的ID或ID：序号作为插件ID食用，例如5 或者5:4
               CheckOnStartUpdates=     改成0来停止更新检测.
               检测升级工具吧
