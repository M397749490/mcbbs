可不可以，详细说说，纯小白

Essentials的Config.yml里面
  1. # 设置为 lowest, 如果你想使用 Multiverse 处理重生.
  2. # 设置为 high, 如果你想使用 EssentialsSpawn插件 处理重生.
  3. # 设置为 highest, 如果你想强制使用 EssentialsSpawn插件 处理重生.
  4. respawn-listener-priority: lowest
复制代码

这个选项设置为lowest就可以重生在当前世界的出生点了

关于跑酷世界
你可以用
/spawn 权限组  来设置一个权限组的出生点你可以设置为到一个世界更改权限组。。
而关于领地问题
我不怎么懂你的意思
是让普通玩家能创建领地
还是让普通玩家有use权限？
添加权限的方法：
/res set 领地名称 权限 t/f
整个领地的权限
/res pset 领地名称 玩家名字 权限 t/f
单个玩家的权限
