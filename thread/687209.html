作者: a8105    时间: 2017-4-16 22:15
CommandSender sender=执行指令的对象,他可以是一个命令方块,后台,玩家等
Command cmd=指令,他可以当前指令的各种详情,详情参考https://jd.bukkit.org/org/bukkit/command/Command.html
String label=当前指令的名称或别名
一个指令可以拥有多个别名
例如plugin.yml里:
command:
  test:
    usage: /<command> help
    aliases: [ts,tt]
String[] args:参数
例如/test abc def
的abc与def就是参数:
args的长度为2
args[0]=abc
args[1]=def
