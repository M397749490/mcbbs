如题，怎么使用命令实现以上效果
作者: 晴路卡    时间: 2020-3-20 00:12
用紫色的命令方块在无需红石的模式下执行以下命令

execute positioned 0 0 0 as @e[type=minecraft:creeper,dx=100,dy=100,dz=100] at @s if entity @a[distance=..3] run kill @s
execute positioned 0 0 0 run kill @e[type=minecraft:creeper,dx=100,dy=100,dz=100,nbt={ignited:1b}]
execute positioned 0 0 0 run kill @e[type=minecraft:tnt,dx=100,dy=100,dz=100,nbt={Fuse:1s}]
fill 0 0 0 20 20 20 air replace fire
其中橙色的坐标部分是可修改的，比如第三条命令表示的是清除掉x在0-100，y在0-100，z在0-100立方体范围内的即将爆炸的TNT
