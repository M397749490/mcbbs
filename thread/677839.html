Advanced PVP Stats Version BETA1.0
帅气的PVP信息插件

一、简介 Description
这是一款PVP信息插件, 本人推荐此插件是因为这款插件简单操作而且灵活使用.

二、功能 Features
  • 简单实用
  • 自定义
  • 计分板不会闪现
  • 个人信息
    • 杀人数
    • 死亡数
    • 连杀数
  • 连杀奖励
  • GUI&计分板个人信息
  • 超轻量13KB

三、图片 Picture [请点开大图查看]
                                         
     

四、指令&权限 Command&Permission
  • /stats | 查看个人信息
  • /stats <玩家> | 查看指定玩家的信息
  • /stats reload | 刷新配置

五、配置 Configuration
Config.yml 汉化V1.0

  1. kill-streak: '&e%player% 到达了 %streak% 连杀!'
  2. broadcast-message: false  #是否开启公告
  3. gui-frame-id: 160   #GUI边框ID
  4. gui-frame-subid: 0  #GUI副边框(?)[可以自己去尝试一下.]
  5. scoreboard-title: '&cPVP&6丨&b&n个人信息'
  6. scoreboard-lines:  
  7. - '&r&m--------------------'
  8. - '&e&l玩家ID: &a%player%'
  9. - '&b&l杀敌数: &a%kills%'
  10. - '&c&l连杀数: &a%killstreak%'
  11. - '&a&l死亡数: &a%deaths%'
  12. - '&ewww.服务器.net'
  13. - '&r&m--------------------'
  14. broadcast-streaks-after: 5  #连杀多少次以后会发送公告
  15. use-scoreboard: true
  16. gui-kills-title: '&b&l杀敌统计 &2- &6&l%name%'
  17. gui-kills-lore: '&e%kills% 人'
  18. kills-item-type: 276   #GUI显示杀敌数物品显示ID
  19. deaths-item-type: 152   #GUI显示死亡数物品显示ID
  20. killstreak-item-type: 1   #GUI显示连杀数数物品显示ID
  21. gui-deaths-title: '&c&l死亡统计 &2- &6&l%name%'
  22. gui-deaths-lore: '&e%deaths% 次'
  23. gui-killstreak-title: '&f&l连杀统计 &2- &6&l%name%'
  24. gui-killstreak-lore: '&e%killstreak% 次'
  25. Rewards:  #奖励板块
  26.   killstreak:   #连杀到达一定程度可执行指令
  27.     '5':
  28.     - say %player% 恭喜你到达了5连杀
  29.     - say %player% 祝贺祝贺.
