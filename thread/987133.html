插件可以做到:
(假定消息为[test])
  • 屏蔽服务器中消息[test]的显示
  • 屏蔽服务器包含[test]这串文字的消息的显示
  • 屏蔽服务器中以[test]开头的消息的显示
  • 屏蔽服务器中以[test]结尾的消息的显示

插件配置 Config.yml
  1. # Message Blocker by MC-Resources - https://mc-resources.store
  2. ##开源  https://github.com/MC-Resources-Store/message-blocker
  3. ##翻译来自潜水E
  4. #请把要屏蔽的信息放到message行，不需要颜色字符
  5. #'mode'的类型:'contains'[包含],'exact'[等于],'starts_with'[以'message'开头],
  6. #             'ends_with'[以'message'结尾]
  7. #如果'ignore_case'设定为true,消息的大小写将不会被检测
  8. #'bypass_permission'填写权限，有权限的会允许接收到消息
  9. #请注意这不仅会影响服务器,还会影响玩家消息

  11. blocked:
  12.   #如果消息等于[eaxact]'Message Blocker'就屏蔽(不区分大小写)
  13.   - message: 'Message Blocker'
  14.     mode: 'exact'
  15.   #是否屏蔽大小写
  16.     ignore_case: true
  17.   #如果有下方权限可以不被屏蔽
  18.     bypass_permission: ''
  19.   # 如果消息包含[contains]'气息遮蔽'(区分大小写)
  20.   - message: '气息遮蔽'
  21.     mode: 'contains'
  22.     ignore_case: false
  23.     bypass_permission:
  24.   - message: 'Weakness'
  25.     mode: 'contains'
  26.     ignore_case: false
  27.     bypass_permission:
  28.   - message: 'slow'
  29.     mode: 'contains'
  30.     ignore_case: true
  31.     bypass_permission:
  32.   - message: 'experience'
  33.     mode: 'contains'
  34.     ignore_case: true
  35.     bypass_permission:
  36.   #屏蔽信息'冷却'(不区分大小写)
  37.   - message: '冷却'
  38.     mode: 'contains'
  39.     ignore_case: true
  40.     bypass_permission: ''
复制代码
值得注意的是 有时要禁用消息的真正内容需要在后台找到
比如客户端显示的是[给予玩家Mr_qian_s虚弱效果*100 999999s]
但真正的消息是后台里的[Given Weakness (ID 18) * 100 to Mr_qian_s for 99999 seconds]
这是我用于自己RPG服的配置
因为用了skillapi技能作为攻击手段 普通攻击要给虚弱效果
一长串的药水给予消息特别烦人
我添加了一个message为Weakness
那么服务器在给予玩家药水效果"虚弱"时就不会在聊天框显示
