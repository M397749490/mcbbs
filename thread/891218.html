前言


最近有开服的朋友
以一张静态的图片挂在直播间的方式
宣传服务器
这样做既容易违反直播间规定
又难达到宣传效果
而招聘主播费用较高、时间不能保证
且不适用于长期的生态展示




功能


本插件可控制一名指定的玩家
自动跟随服务器内其他活跃玩家
可设置每个玩家被直播的时间
从而生成直播画面

你需要一台电脑，打开一个客户端
登录设置在插件中的账号
按F3+P关闭暂停画面
打开直播工具绑定窗口
即可开始后台直播了
不影响玩别的游戏哦

插件未用到新版本中的特性API，理论上1.8-1.14通用。
欢迎回复更多功能建议、BUG反馈




命令与权限以及配置文件


玩家命令:
无
OP命令:
/live target <name>                      设置目标玩家为直播对象
/live time <second>                      设置每个玩家被直播的时间
/live recorder <name>                  设置目标玩家为直播录制者
/live reset                                        重设直播时间, 将自动切换直播目标
/live reload                                      重载插件配置文件
权限:   
无
配置文件：

  1. #提示信息前缀
  2. prompt-prefix: '&a直播助手'

  4. #全局配置
  5. setting:
  6.   #直播员名字
  7.   recorder-name: Recorder
  8.   #每个玩家的直播时间
  9.   record-seconds: 15
  10.   #判定为不活跃的时间
  11.   inactivity-timeout: 5
  12.   #镜头俯角
  13.   camera-pitch: 45
  14.   #镜头距离
  15.   camera-distance: 3
  16.   #自动为直播员添加的权限
  17.   recorder-permission:
  18.     #如果安装了多世界插件，这个一定要设置
  19.     - mv.bypass.gamemode.*
  20.     #领地插件传送和移动权限
  21.     - residence.admin.*
  22.   #给予上述权限所用的指令
  23.   permission-command: 'lp user {recorder} permission set {permission} true'


  26. #提示信息
  27. message:
  28.   reload-success: '&e配置信息重载成功'

  31.   target-set: '&e已设置目标玩家为直播对象'
  32.   recorder-set: '&e已设置目标玩家为直播录制者'
  33.   invalid-player: '&e目标玩家不存在'
