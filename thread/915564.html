简介:
此mod仅添加了一种物品，即末影袋。
可用不同染料在合成台中对其进行染色。
具有104格的空间供存储物品..

同时具有配置文件可修改黑名单物品,默认为背包本身。

鉴于1.15你们不一定装JEI...合成如下

image.png (10.17 KB, 下载次数: 15)

白色方块为羊毛
其他颜色将颜料和白色背包放合成台里合成得到

配置文件:


  1. #Server configuration
  2. [server]
  3.         #A list of item registry names that arenot allowed in ender bags.  Format is modid:name.
  4.         blacklist =["ender_bags:white_bag", "ender_bags:orange_bag","ender_bags:magenta_bag", "ender_bags:light_blue_bag","ender_bags:yellow_bag", "ender_bags:lime_bag","ender_bags:pink_bag", "ender_bags:gray_bag","ender_bags:light_gray_bag", "ender_bags:cyan_bag","ender_bags:purple_bag", "ender_bags:blue_bag","ender_bags:brown_bag", "ender_bags:green_bag","ender_bags:red_bag", "ender_bags:black_bag"]
