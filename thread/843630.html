作者: 3TUSK    时间: 2019-2-9 02:55
Sponge 里的 Player 是个 DataHolder。所以：

  1. import org.spongepowered.api.data.key.Keys;  // Keys 所在的包
  2. import com.flowpowered.math.vector.Vector3d; // Vector3d 的包

  4. Player player = ...; // 先设法拿到玩家对象
  5. if (player.supports(Keys.TARGETED_LOCATION)) { // 然后确定这个玩家支持 TARGETED_LOCATION 这个数据
  6.     player.offer(Keys.TARGETED_LOCATION, new Vector3d(x, y, z)); // 设定新的 targeted location
  7. }
复制代码


这样应该就可以了。Keys.TARGETED_LOCATION 还用于决定末影之眼飞出去时的朝向。

Keys 类下还有一大堆数据键可以使用——唯需注意使用前先检查目标是否支持这个数据。
