插件介绍
本插件是一款老牌的RPG物品编辑器，可以轻松编辑物品的名称，lore，附魔，NBT标签，无法破坏等自带属性，同时，本插件自带了可以添加至物品的十余种属性（如“物理伤害”等），另外，还可设置玩家手持物品获得被动buff/debuff，攻击敌人时触发技能，使用物品执行指令或召唤特殊技能，等等。

物品属性
可以使用指令给手持物品添加各种属性，目前属性一共21种
你可以使用本插件自带的属性指令来加属性，也可以通过直接加Lore来添加属性

添加属性的指令（按TAB键可显示所有属性名）
/attribute stats <属性名> <属性值> [加在第几行]

<player>是玩家名变量

元素属性
元素属性一共四种：水/火/土/风，每种元素属性都有相应的“元素值”
拥有元素属性的武器在攻击时可以通过“元素值”来提升基础攻击
还有几率给自己添加buff以及给敌人添加debuff
  1. Water:
  2.   Keylore: "&c水之元素"
  3.   # 下面这个值乘以“元素值”即为基础攻击的加成
  4.   Scale_Base_Additional_Damage: 0.05
  5.   # 下面这个值乘以“元素值”即为基础攻击的百分比加成
  6.   # 举例：一把剑基础攻击为30，拥有“水之元素”且元素点为20
  7.   # 那么其加成后的攻击力=30*(1.2%*20)+(0.05*20)=38.2
  8.   Scale_Base_Percent_Damage: 1.2
  9.   # 使用拥有元素属性的武器攻击时可以给自己添加buff
  10.   Potion_To_Attacker:
  11.     REGENERATION:
  12.       # 自己获得此buff的几率=(下面这个值*元素点)
  13.       Scale_Chance: 0.2
  14.       # 自己获得此buff的时长=(下面这个值*元素点)
  15.       Scale_Duration: 1
  16.       # buff的等级
  17.       Grade: 2
  18.   # 使用拥有元素属性的武器攻击时可以给敌人添加debuff   
  19.   Potion_To_Victims:
  20.     SLOW_DIGGING:
  21.       # 敌人获得此debuff的几率=(下面这个值*元素点)
  22.       Scale_Chance: 0.05
  23.       # 敌人获得此debuff的时长=(下面这个值*元素点)
  24.       Scale_Duration: 1
  25.       # debuff的等级
  26.       Grade: 1
  27.   Resistance:
  28.     Fire: 2.5
  29.     Water: -1
  30.     Nature: 0.5
  31.     Wind: -2

保存物品
当你做好了一件很棒的RPG物品以后，使用指令
/myitems save <保存名>
即可保存该物品，使用指令
/myitems load custom <保存名>
即可取回物品

保存的物品位于item.yml里，可直接在文件中编辑物品属性

安装与使用
使用本插件前，需安装AgarthaLib前置，该前置和插件本体可一起获得，故不在本帖放出

指令与权限
  • 已经在上方介绍过的指令不在此处赘述
  • 本插件的TAB补全功能十分强大，如果不知道该输入什么指令参数，按TAB键可自动补全

  • /myitems - 插件帮助
  • /myitems detail - 显示手持物品详细信息
  • /myitems amount - 设置手持物品堆叠数量
  • /myitems data - 设置手持物品子ID
  • /myitems material - 设置手持物品种类
  • /setname <名称> - 设置物品名称
  • /setlore <行数> <内容> - 设置lore
  • /insertlore <行数> <内容> - 插入一行lore
  • /addlore [内容] - 添加一行lore，可留空
  • /removelore <行数> - 删除一行lore
  • /clearlore - 删除全部lore
  • /addflag <flag> - 添加flag
  • /removeflag <flag> - 移除flag
  • /clearflag - 删除全部flag
  • /addenchant <附魔> <等级> - 添加附魔
  • /remenchant <附魔> - 移除附魔
  • /clearenchant - 删除全部附魔
  • /unbreakable - 设置物品无法破坏状态
  • /myitems repair - 修复物品lore耐久
  • /myitems reload - 重载插件

本插件没有任何权限需要给玩家
