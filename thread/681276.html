     介绍
       可用前置插件
  * 此段有助于让您的计分板变得更好，请查看
  + PlaceholderAPI (站外 | 站内)
  + Vault (站外 | 站内)
  + WorldGuard (站外 | 站内)
  + 任一经济插件 (前提必须支持Vault)

       特点
  * 此段包含了插件的基本特点
  ┌ 防闪烁！自定义更新时间！
  ┌ 支持禁用计分板世界
  ┌ 支持权限组判断 (一个权限组可多个计分板)
  ┌ 支持颜色代码以及&k代码
  ┌ 可配置计分板
  ┌ 多个计分板(无限个)
  ┌ UTF8变量 (链接)
  ┌ 可设置显示时长
  ┌ 支持判断文本！让你的计分板有更多内容
  ┌ 爬动计分板，让你的计分板都可以爬
  ┌ 随机颜色，以及随机格式(随机颜色 &x | 随机格式 &y)
  ┌ 自定义变量 | 想显示啥，就显示啥
  ┌ 高度兼容 (兼容目前主流的版本)
  ┌ 信息可自定义
  more...

  问:为什么我的PAPI变量没有更新？
  答: PlaceholderAPI已经禁用了自行下载变量拓展的功能，这得您亲自下载 /papi ecloud download.....

     命令&权限
       命令
  * 此处您必须得看
  [] 为 选填
  <> 为 必填
  


  2.   /ibr | 查看所有命令
  3.   /ibr hide | 隐藏计分板
  4.   /ibr show | 显示计分板
  5.   /ibr toggle | 开/关计分板
  6.   /ibr set <页码> | 设置页面
  7.   ( <page> 只能为整数不能留空)
  8.   /ibr reload [文件] | 重载配置文件
  9.   ( [文件] 可以为 空, board, config 或者 messages )
  10.   /ibr info | 显示计分板的更多信息
  11.   /ibr create <页码> <显示时间> | 创建一个计分板并为它设置显示时长
  12.   /ibr add <标题/行> <页面> <世界> <权限组> <行数> | 为一个页面的计分板添加行数/标题/世界组/权限组
