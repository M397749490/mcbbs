太多相同ip的账号同时在线同时在线导致无法注册或进入游戏这个意思吗
用的哪个登录插件呀，我默认你用的是authme
有个简单的办法改下authme的配置
maxRegPerIp: 1
就是最大注册玩家数把1改高

下面两个改成0禁用
IP最大登录玩家数量
maxLoginPerIp: 0
IP最大进入玩家数量
maxJoinPerIp: 0

是指登录的时候显示同一ip的其他账号，不希望他显示的话
authme登录插件可以改下配置：
displayOtherAccounts:  false

如果是BC导致无法获取玩家真实ip
BC配置文件里：
ip_forward: true
子服spigot.yml里
bungeecord: true
