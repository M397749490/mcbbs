一款类似天黑请闭眼，三国杀之类的小游戏插件

插件特色：
自动开始
自定义信息
玩家随机变更职业
随机名字
大厅牌子
自定义资源包
保存玩家数据，游戏结束恢复
自定义玩家皮肤
蹦极服支持
插件不带有保护功能，请自行用WorldGuard类似插件设置保护
插件命令权限：
玩家命令
/murder help - 显示帮助页面 (murder.player)
/murder join <ArenaID> - 加入指定场地 (murder.player.join.<arena>)
/murder leave - 离开场地 (murder.player.leave)

管理命令
/murder start <ArenaID> - 开始一个指定场地 (murder.admin.startgame)
/murder setname <ArenaID> <Name> - 指定一个 <ArenaID>的名字 (murder.admin.setname)
/murder savearena <ArenaID> - 保存指定场地所有数据. (murder.admin.savearena)
/murder reload - 保存并且重载所有数据. (murder.admin.reload)
/murder addarena <ArenaID> - 添加一个指定ID到场地编号 (murder.admin.addarena)
/murder removearena <ArenaID> - 移除一个指定场地编号的场地 (murder.admin.removearena)
/murder addspawn <Arena> lobby - 添加大厅出生点 (murder.admin.spawns)
/murder addspawn <Arena> players - 添加玩家出生点 (murder.admin.spawns)
/murder addspawn <Arena> loot - 添加战利品生成点 (murder.admin.spawns)

murder.admin.createsign 创建牌子权限

玩法：
【目击证人】试着活下去，并且可以收集5个物资（钻石）组装成武器（一个冷却为3秒的枪）。目击证人都有移动速度加成的道具让其更快的逃离凶手。
【凶手】在保证自己活下来的前提下杀掉所有目击证人（钻石斧，可以丢出去再捡回来）。杀手玩家可以5个收集物资获得移动加成。
【警察】必须找到杀手并且杀死，如果不小心击杀了目击证人则会导致自己失职扣除武器（就是变成目击证人）。


自研究的造游戏过程：
/murder addarena <地图编号>      # 地图编号随便一个数字/murder setname <地图编号> <地图名>     #刚才你的数字加上后面一个游戏名，进行代号的绑定。
/murder addspawn <Arena> lobby - 添加大厅出生点
/murder addspawn <Arena> players - 添加玩家出生点
/murder addspawn <Arena> loot - 添加物资生成点

完，可以加入游戏了。
