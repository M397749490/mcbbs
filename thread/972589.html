使用步骤

1. 安装插件到你的plugins目录下
2. 重启服务器
3. 客户端安装对应的mod
4. 输入/music 开始体验！

插件指令

普通玩家
  • /music <ID>   ——————————— 点歌
  • /music help     ——————————— 获取帮助
  • /music vote     ——————————— 投票切歌
  • /music stop     ——————————— 停止播放这首歌
  • /music nomusic —————————— 不再参与点歌
  • /music list       ——————————— 获取点歌列表
  • /music search <歌名>   —————— 搜索歌曲
  • /music select <序号>    —————— 选择搜索的歌曲
  • /music nextpage  ————————— 搜索下一页
  • /music lastpage   ————————— 搜索上一页
  • /music hud enable  [位置] ————— 启用Hud
  • 后面接false表示关闭
  • /music hud [位置] x y  ——————— 设置Hud位置

管理员（要在配置文件加管理员的ID）
  • /music reload    ———————————  重载配置
  • /music next       ———————————  强制切歌
  • /music ban <ID> ——————————  禁止点歌的音乐的ID
  • /music delete <序号>   ———————  删除队列
  • /music addlist <ID> ————————  添加空闲列表的歌单
  • /music clearlist ———————————  清空空闲列表的歌曲
  • /music url —————————————— 添加一首url的歌曲

开启需要权限后
  • /music <ID>    ———————————  AllMusic.addmusic
  • /music search <歌名>  ———————  AllMusic.search
  • /music select <序号>    ——————— AllMusic.search
  • /music nextpage  —————————— AllMusic.search
  • /music lastpage   —————————— AllMusic.search
  • /muisc vote ————————————— AllMusic.vote
