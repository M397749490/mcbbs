SpawnerName:
  MobName: 怪物名字
  World: 世界名字
  SpawnerGroup: 刷怪点属于哪个组
  X: 0
  Y: 0
  Z: 0
  Radius: 刷怪区域半径
  RadiusY: 刷怪区域高度半径
  UseTimer: true  
  MaxMobs: 1
  MobLevel: 1
  MobsPerSpawn: 1
  Cooldown: 0
  Warmup: 0
  CheckForPlayers: true
  ActivationRange: 40
  LeashRange: 32
  HealOnLeash: false
  ResetThreatOnLeash: false
  ShowFlames: false
  Breakable: false
  Conditions: []
  ActiveMobs: 1


根据你的描述，应该把刷怪区域调大，也就是

  Radius: 刷怪区域半径
  RadiusY: 刷怪区域高度半径

因为刷怪是在区域内随机刷出，刷怪范围调大意味着刷怪看起来随机

防止玩家挂机刷怪的话，可以调低这个：


  MaxMobs: 10 —— 刷怪区域最多存在几个怪物
  MobsPerSpawn: 2 —— 一次刷新几个怪物


注意：maxmobs需要大于等于mobsperspawn

emmm还有一个方法阻止玩家在一个地方挂机刷怪

  Cooldown: 60
  Warmup: 10


提高cooldown（冷却），降低warmup（预热），玩家的观感就是：每到新的区域很快就会刷怪，而刷了一波后了刷怪就会变慢

推荐你去看一下这个：
http://mineplugin.org/MythicMobs#.E5.88.B7.E6.80.AA.E7.82.B9.28Spawners.29

当你设置好刷怪点的时候，plugin/mythicmobs/spawner里面会出现一个新的文件，去里面改，改完了重启就是了。
如果你觉得改完重启麻烦的话，可以使用指令在游戏内修改：
/mm s set 刷怪点名字 warmup 刷怪准备时间时间
/mm s set 刷怪点名字 cooldown 冷却时间
/mm s set 刷怪点名字 maxmobs 最大怪物数量
/mm s set 刷怪点名字 mobsperspawn 单次生成怪物数量
如果觉得没有帮助的话，可以用我上面给出的网址获得更多信息。
