GlowAPI

依赖于 PacketListenerAPI
此插件允许你更改玩家和生物的发光效果

使用方法
  1. @EventHandler
  2. public void onJoin(final PlayerJoinEvent event) {
  3.     //Delay the update by a few ticks until the player is actually on the server
  4.     Bukkit.getScheduler().runTaskLater(this, new Runnable() {
  5.         @Override
  6.         public void run() {
  7.             //Set the event's player glowing in DARK_AQUA for all online players
  8.             GlowAPI.setGlowing(event.getPlayer(), GlowAPI.Color.DARK_AQUA, Bukkit.getOnlinePlayers());
  9.         }
  10.     }, 10);
  11. }
