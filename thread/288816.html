大家好，我是SOSxx，这个插件支持1.7.2，说实话，当时我看到这个插件，瞬间尿了，尼玛，此插件太多高能，请注意
介绍：
搞基开始前戏,玩家要互相喂食（喂食play）(默认情况下是可可豆)（生吃可可豆？）。当romance-mode(也称为ready-to-love模式)被激活后（也就是开始想跟你捡肥皂的意思）,您将看到心在你的基友身边(要安装PlayEffect插件)。如果有两个玩家活跃ready-to-love模式中,玩家可以右击对方,属于浪漫的基情(in-love模式)（肥皂掉落的意思）。如果玩家花有时在一起(一名玩家必须接近另一个)（还必须肥皂掉落）有机会happy-event,生一个孩子。一位大鼻子婴儿（有种给别人代生的感觉啊）。

一本正经的作者的自言自语：
为什么我需要这个插件吗?
有趣,有趣,有趣!（作者：老公你说有趣吧！）
生产村民的新方法。（其实是促进肥皂的出售）
玩家可以使用love-mode在短时间内无法PVP。（如果这是异性恋咋办呐）

命令：

/romance reload — 重启插件
/romance give [num:<数量>] [player:<对象玩家>] — 给东西给玩家或对象玩家（肥皂行吗？）（估计是喂食，我也不知道）


权限（本插件的最亮的亮点）：

romance.lover — 激活"ready-to-love" 模式
romance.push-in-love — 用东西给对象玩家玩喂食play(love potion)（为啥我不翻译这里= =因为我手贱用谷歌翻译了下这，然后出来春药2333）
romance.father — 喜当爹（没妈妈？卧槽，真这样玩？肥皂满地飞啊）
romance.command.reload — 重启插件
romance.command.give —能用给肥皂的权限
romance.command.give-to — 允许玩家给爱的物品（肥皂）给对象玩家, 示例： /romance give num:5 player:fromgate


配置（请备好24K纯金眼再看）：

Configuration
To configure Romance plugin you must edit config.yml file:
general:
  language: english  # 语言
  language-save: false # 保存语言文件 (如果你不想过当**就别想汉化这插件了，要汉化自己打开这个)
  check-updates: true # 更新提示
romance:
  item-activator: INK_SACK:3 # Love item. Names supported. You can use something like "&6Love potion:INC_SACK:3（墨囊）" to define cocoa with name "Love potion" as love-item.（爱的物品，可以设置类似的，可以命名可可豆和爱的物品的春药）（实际不懂其中意思，没有基友跟我测试那插件没办法）
  give-payment: 0.0 # Payment for /romance give command.
  ready-to-love:
    time: 30s         # Duration of ready-to-love mode  (支持格式: HH:MM:SS, XXs, XXm, XXh, XXms)（肥皂掉落时间）（H：时 M：分 S：秒 ms：毫秒）
    effects: # List of effects that will randomly played around the player during this mode（会给附近同样是这个准备捡肥皂的模式的人给BUFF）（嫉妒的力量么）
    - effect:heart num:5 offset:0.4 speed:0.3  
    - effect:heart num:3 offset:0.4 speed:0.2
  in-love:
    broadcast-inlove-message: true  # Inform everyone on server that someone fall in love :)（告诉别人，我已经捡了他的肥皂了）
    minimal-distance: 4  # Distance to keep this mode. If player is move too far love-mode will be disabled.（不能离4格外，否则没有肥皂捡）
    time: 30s         # Duration of in-love mode  (supported format: HH:MM:SS, XXs, XXm, XXh, XXms)（捡肥皂的时间）
    effects: # List of effects that will randomly played around the player during this mode（嫉妒的心）
    - effect:heart num:10 offset:0.7 speed:0.5
    - effect:heart num:15 offset:0.9 speed:0.6
    interact-sound:  # List of SOUND effects (effect name:volume:pitch) that will played randomly when one "lover" right-clicks another（貌似是啪啪啪的音效）（不过用小黑和猫叫声当叫床声有点丧心病狂啊）
    - ENDERMAN_IDLE:1:1.5
    - ENDERMAN_IDLE:1:0.5
    - CAT_MEOW:1:0.5
    - CAT_MEOW:1:1.5
    baby-born-sound: # List of SOUND effects (effect name:volume:pitch) that will played randomly when villager spawned（婴儿出生的声音）
    - LEVEL_UP:1:2.5
  after-love:
    cooldown-time: 3m          # Duration of after-love mode  (supported format: HH:MM:SS, XXs, XXm, XXh, XXms)（事后时间）
    enable-on-player-join: true  # Enable after-love mode when player joined a server（真正让一个玩家当孩子加入服务器）
happy-event:
  chance: 10   # Chance is bounded to player interacting event during the "in-love" mode.（捡肥皂次数）
  name-the-baby: true       # Set the name of baby
  name-mask: '%firstname% %lastname%' # Name mask. Supported placeholders: %firstname% %lastname% %father% %mother% %random%
  name-case-conversion: true # First letter in name will uppercased, other - lowercased
  name:
    last-name-suffix:  # Rule to generate the %lastname%. For example if player is fromgate, you can get: fromgatson, fromgats, fromkin, fromney, etc（名）.
    - son
    - s
    - kin
    - kins
    - ney
    - 'off'
    - ov
    - shvily
    - enko
    - ovich
    fist-name-suffix:   # Rule to generate the %firstname%. For example if player is fromgate, you can get: from, fromy, fromgi, froma, fromge, fromgo, etc.（姓）
    - ''
    - ''
    - ''
    - y
    - i
    - a
    - o
    - e
    - ey
    - ow
    random-names: # List of names that will used in for %random% placeholder. You will get on of name listed here.（随机名字）
    - Bob
    - John
    - Obana
    - Gaylord
    - Helga
    - Mikola
pvp-protection:  # 搞基之中是自动禁止PVP（防FFF团）
  protect-players-in-love: true
  protect-ready-to-love: true
