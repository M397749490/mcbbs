作者: hypocisy    时间: 2019-9-13 21:40
GP插件没用过，但是你可以试试Essentials 和 EssentialsXAntiBuild + GroupManager，
然后在GroupManager配置文件中的Default组添加以下权限：
  1.     - essentials.build.destroy.*
  2.     - essentials.build.drop.*
  3.     - essentials.build.interact.*
  4.     - essentials.build.pickup.*
  5.     - essentials.build.place.*
  6.     - essentials.build.use.*

  1. mirrors:
  2.       world:
  3.           world_nether:
  4.           - users
  5.           - groups
  6.           world_the_end:
  7.           - users
  8.           - groups
  9.           all_unnamed_worlds:
  10.           - users
  11.           - groups
  12.       NewWorld：# 这个是要分离权限的世界名
