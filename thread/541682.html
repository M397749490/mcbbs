今天给大家带来一款我自己写的小插件

粒子商店 ParticleShop

一个神奇的粒子跟踪插件。:D

命令 :
  • /ps set
  • 设置粒子 | choose the kind of particles
  • /ps stop
  • 关闭粒子 | Prevent the partcles
  • /ps list
  • 列出你所能使用的粒子列表 | list the list of particles that you can use


用法:
创建一个牌子,第一行打ps,第二行打购买这种粒子需要的钱数(EconomyAPI),第三行打粒子类型(可以打0-21以内的数字)

买好粒子之后 打/ps list 查看粒子的序号, 然后/ps set <序号> 就成功设置了粒子
粒子形状跟WalkParticle的形状差不多。

如果有bug欢迎在本帖回复
