是权限组问题，权限组默认被设置为游客权限组
你可以修改权限文件就行了
你依次打开然后修改下列内容就行了
打开plugins\GroupManager\worlds\world\groups.yml
然后在文件夹内看到下列内容
  1.   Default:
  2.     default: true
  3.     permissions:
  4.     - -bukkit.command.kill
  5.     inheritance:
  6.     - g:groupmanager_default
  7.     - g:bukkit_default
  8.     - g:essentials_default
  9.     - g:towny_default
  10.     info:
  11.       prefix: '&e'
  12.       build: false
  13.       suffix: ''
  14.   Builder:
  15.     default: false
  16.     permissions: []
  17.     inheritance:
  18.     - default
  19.     - g:essentials_builder
  20.     - g:towny_builder
  21.     info:
  22.       prefix: '&2'
  23.       build: true
  24.       suffix: ''
复制代码

将“Default”的default: true中的[true]删掉输入false
将“Builder”中的default: false中的[false]删掉输入true
然后重启服务器就行了
