复制代码
ItemStack 有 setCount 方法可以用：newStack.setCount(stack.getCount())。


以 get 和 set 开头的方法属于 Java 中一种类似调用约定的东西，更具体的可以去搜索 Getter 和 Setter 的相关概念。
