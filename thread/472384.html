作者: a215051606    时间: 2015-7-20 22:52
给所有世界权限的话是这样
打开\plugins\GroupManager\config.yml文件，设置这里就可以

world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
    配置的时候上面的世界不要动！  红色字部分删除掉不要了。    下面是列子：
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
        plotworld:      （这是地皮世界的权限，与主世界的权限不一样
          www1:         （这是名为www1的世界。与主世界不一样。与plotworld地皮世界全系一样）
          - users
          - groups

          www2:         (这是名为www1的世界。与主世界不一样，使用 plotworld地皮世界里的 groups.yml,但是使用自己独立的 users.yml)
        - groups  


还有那个继承的那个  继承成功之后还要输
mangaddi [VIP组名字] builder
比如叫做vip
mangaddi vip builder

解决请采纳。
