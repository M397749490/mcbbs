首先win+R打开输入
  1. mysql -u用户名 -p密码
复制代码
默认用户名为root。
然后在cmd中
  1. create database xxx;
复制代码
创建名为xxx的库
Authme的配置
  1. DataSource:
  2.     backend: 'mysql'    #启用mysql
  3.     caching: true      #启用缓存
  4.     mySQLHost: '127.0.0.1'          #Mysql的位置，如果是本机就设置127.0.0.1
  5.     mySQLPort: '3306'         #Mysql的端口号，默认为3306
  6.     mySQLUsername: 'root'        #Mysql的用户名，默认为root
  7.     mySQLPassword: 'xxx'       #Mysql的密码，
  8.     mySQLDatabase: 'authme'       #Mysql的库名，创建库指令为create database authme;
复制代码
其它关于DataSource: 的配置建议保持默认

coreprotect的配置
  1. # MySQL是一个扩展选项而不是必须的.
  2. # 如果你决定使用MySQL,开启下列选项并且填写下面的内容.
  3. use-mysql: true        #启用mysql
  4. table-prefix: co_        #表前缀，保持默认即可
  5. mysql-host: localhost        ##Mysql的位置， localhost 也表示在本机
  6. mysql-port: 3306           #Mysql的端口号
  7. mysql-database: coreprotect        #Mysql的库名，创建库指令为create database coreprotect;
  8. mysql-username: root        #Mysql的用户名
  9. mysql-password: xxx        #Mysql的密码
复制代码
