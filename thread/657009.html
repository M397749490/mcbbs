自从2017年一月14日开始，由于插件太乱，这个项目已经被放弃。感谢所有支持的人。



SamB440's Reporter是目前最流行的反馈插件之一，玩家可以通过这个插件来举报违规的熊孩子，提高服主的处理效率，让熊孩子都能及时地得到处罚。这款插件拥有人性化的GUI和实用的指令。所有的提示内容都能在配置文件中设置。
插件同时支持MySql，可以做到在线提交/处理反馈的功能.

指令


  2. /Report - 打开GUI面板
  3. /Report <玩家名> <原因> - 向管理员举报某个玩家
  4. /Report list - 浏览 logger.txt 文件中所有的反馈
  5. /Report clear - 清空 logger.txt 文件中所有的反馈
  6. /Report on - 开启反馈功能
  7. /Report off - 关闭反馈功能
复制代码

权限

  1. reporter.reportview - 反馈后是否提示
  2. reporter.list - 浏览 logger.txt 中的报告
  3. reporter.clear - 清空/删除 logger.txt 中的报告
  4. reporter.GUI.Player - 浏览'player' 面板
  5. reporter.GUI.Staff - 浏览 'staff' 面板
  6. reporter.toggle - 开启/关闭 反馈功能.
复制代码

配置文件


  1. #举报玩家时的提示内容
  2. ReportEntry: '&bAdding an entry under the name: '
  3. #指令/report list输出时每行的颜色
  4. ListColour: '&9'
  5. #未填写理由时的提示内容
  6. NoReasonError: '&c&oPlease enter a reason.'
  7. #找不到日志文件时的提示
  8. LogFileError: '&c&oError: Entry could not be added - Log file not available!'
  9. #发生未处理的异常时的提示
  10. GeneralError: '&cHmm.. It seems like something went wrong here!'
  11. #没有权限时的提示
  12. No_Permission: '&cNo permission!'

  14. #玩家提交了反馈后提示的大标题内容(需要report.reportview)权限
  15. ReportTitle: '&aNew report submitted'
  16. #同上，小标题
  17. ReportSubtitle: 'Use /report list to check!'
  18. #是否开启检查更新
  19. Update_Check: true
  20. #MySQL配置
  21. MySQL_Enabled: false
  22. Host: 'localhost'
  23. Port: 3306
  24. Database: 'TestDatabase'
  25. Username: 'user'
  26. Password: 'pass'
  27. #不要编辑下面的内容
  28. Reports: 0
