CreativeLimited

创造限制



这个插件主要是放在创造服使用的


用途：

> 禁止玩家使用鞘翅

> 禁止玩家丢弃物品

> 禁止玩家放置物品

(还可以有更多)



指令:

/cl reload ——重载配置



权限:

CreativeLimited.Elytra:                         ——允许使用鞘翅
CreativeLimited.Drop:                          ——允许玩家丢弃物品
CreativeLimited.PlaceBlock.Skull:            ——允许放置所有头颅
CreativeLimited.PlaceBlock.Beacon:         ——允许放置信标
CreativeLimited.Commands.Reload:         ——允许使用/reload指令

(所有权限默认op拥有)



配置文件(必看):
  1. #禁止物品丢弃
  2. BanDrop:
  3.   All: true
  4.   Message: "&9服务器禁止乱丢垃圾"
  5. #禁止放置方块
  6. BanPlaceBlockBlock:
  7. #是否开启限制方块放置，true为限制，false为不限制
  8.   Enable: true
  9.   #限制的头颅的列表（需全部为大写）
  10.   #DRAGON : 龙头
  11.   #WITHER : 凋零骷髅头
  12.   #ZOMBIE : 僵尸头
  13.   #SKELETON : 骷髅头
  14.   #CREEPER : 苦力怕头
  15.   #PLAYER : 史蒂夫头
  16.   Skull:
  17.     - DRAGON
  18.     - WITHER
  19.     - ZOMBIE
  20.     - SKELETON
  21.     - CREEPER
  22.     - PLAYER
  23.   #是否限制信标放置，true为禁止，false为不禁止
  24.   Beacon: true
  25.   #当玩家被禁止放置方块时发送的消息
  26.   #"%block%"会自动转化为方块的名字
  27.   #（如不发送要请写''）
  28.   Message: "&9服务器禁止放置&b%block%"
  29. #禁止使用鞘翅
  30. BanElytra:
  31.   Enable: true
  32.   Message: "&9服务器禁止使用鞘翅"
