现在请忽略这项,这是为未来的更新
automatic_payments: false
如果设置为 true, 当玩家购买物品后直接付款给卖家,而不是发送到卖家的信箱
enable_cut: true
如果设置为 false, 市场不会采取税收交易
cut_amount: 0.05
税收的百分比
enable_metrics: true
是否禁用 PluginMetrics
这里面没写怎么禁止上市
