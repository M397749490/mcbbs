改不了，直接 setblock 放一个新的吧。
如果想保留其他的方块状态，只能穷举，例如要把 facing 改成 north 并保持 a 不变：
execute if block ~ ~ ~ xxx[a=true] run setblock ~ ~ ~ xxx[a=true,facing=north]
execute if block ~ ~ ~ xxx[a=false] run setblock ~ ~ ~ xxx[a=false,facing=north]
