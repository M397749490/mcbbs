特色：
一、完整的RPG系统
二、操作简单
三、高自由度
四、可以自定技能，以及该职业可以装备的道具


功能：

Classic 基本：
   - 自定权限、名称
   - 可自订职业转职（如可自由设定某某某转职成某某某职业）
   - 可以使用双职业（主职业、副职业）
Permitted Skiills 自主技能：
   - 开启指令:skill<skillname>
   - 服务器开设这可以制定新技能，也可以调整
Permission Skills 权限成为技能：
   - 可以将权限设定为一项技能，可以设置某职业才有某权限
Binding Skills 绑定技能：
   - 使用：/bind <skillname>来绑定技能，绑定后用右键使用
   - 再使用一次/bind来解除绑定
Inventory Restrictions 装备限制：
  - 可自由限制职业可以穿戴的装备
Levels 等级：
   - 使用/leve;来查看自己的职业等级以及距离下一等级所需的经验
   - 可自由设定经验值曲线
   - 可设定每多少级增加多少血量
   - 可设定死亡后掉落的经验值
EXP-Soures 经验值来源：
   - 技能：使用技能时获得
   - 合成：合成物品时获得
   - 挖掘：挖到矿物时获得
   - 击杀：杀死生物时获得
   - 砍伐：砍掉原木时获得
   - 对战：杀死玩家时获得
Health/Damage 生命与伤害自定：
   - 自定环境伤害
   - 自定怪物血量、伤害
   - 允许玩家在床上回复生命值
   - 允许玩家自定血量
Mana 法力：
   - 输入/mana来查看自己的魔力
   - 可自定自己的魔力
Parties 组队：
   - 可设定是否共享经验值、互相伤害
   - 组队加成经验
   - 团队技能

支援插件：

Campaign 任务插件
MobArena 副本插件
MobHealth 血量显示插件
HealthBar 抬头显示HUD插件
指令：
一般指令：

/hero
   - 查询指令
/bind
   - 绑定指令
/level 或者/hero level或者/lvl
   - 绑定指令，绑定右键使用技能，再次输入解除绑定
/mana
   - 查看自己当前的魔力
/cooldowns或者/cd
   - 查看当前技能的冷却时间
/health或是/hp
   - 查看当前血量
/hero leaderboard
   - 查看玩家等级排行榜

技能指令：

/skills或者/skilllist
   - 查询可用技能
/skill <skill><args>
   - 查看技能参数

队伍指令：

/party invite <player>
   - 邀请玩家进入队伍
/party accpt <player>
   - 准许玩家加入队伍
/party leave
   - 离开队伍
/p <message> 或是 /party <message>
   - 队伍私聊
/party mode [pvp:exp]
   - 队伍PVP经验共享
/party ui
   - 老衲没明白这个
/party who
   - 查看队伍里有什么人

管理员指令：

/hero admin class <player> <Job>
   - 设定玩家职业
/hero admin prof <player> <Job>
   - 设定玩家副职业
/hero admin exp <player> <Job> <amounts>
   - 给与玩家某职业经验值
          ·可以使用'prim'(主职业)or 'prof'(副职业)来选择给予
/hero admin level <player> <Job> <amounts>
   - 设定玩家某职业的等级
          ·可以使用'prim'(主职业)or 'prof'(副职业)来选择给予
/hero admin heal <player>
   - 治疗玩家
/hero admin hp <player> <amounts>
   - 给予玩家血量
/hero admin reload
   - 重新读取heroes插件
/hero admin saveall
   - 存储heroes插件
/hero debug dump
   - 将heroes插件的debug文件清空

转职指令：

主职业：
   - 输入/hero choose [主职业名称] 选择要转入的主职业后输入 /hero confirm 确定
副职业：
   - 输入/hero prof [副职业名称] 选择要转入的副职业后输入 /hero confirm 确定



权限：

heroes.classes.*
   - 允许转职成所有职业
heroes.classes.职业名称
   - 允许转职成指定职业
heroes.reset
   - 允许让玩家回到预设职业
heroes.admin.exp
   - 允许设置別人的经验值
heroes.admin.classchange
   - 允许設置別人的职业
heroes.admin.healthchange
   - 允许設置別人的血量
heroes.admin.reload
   - 允许重新读取插件
heroes.bind
   - 允许綁定技能
