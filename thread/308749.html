各MOD使用教程：

1：注意事项：游戏名字必须英文 不能带符号  不可以安装任何作弊MOD  否则直接ban  毫不留情
2：圈地插件使用教程 手里拿着线：沿着你要圈的空间的对角线，在一端点击左键、另一端点击右键。
然后打开对话框，输入： /res create 土地的名字    前提是你有钱   领地价格一格方块0.02游戏币 土地名字只能由英文或数字组成。如果圈地失败首先检查你是否有足够的钱，在对话框输入/money查看金钱。如果钱没有问题再检查有没有把别人的地圈到你的范围里去了 =。=
圈地插件常用命令：  /res create 土地的名字 ，根据你刚才选取的空间创建一块属于你的领地
/res remove  土地的名字 ，取消一块你的领地，键入这个命令后会看到红色提示，要求你输入： /res confirm ，输入这个命令后领地才会真正的被取消掉。
/res set 领地名字 事件类型 true或false ，此命令用来开启/禁止自己领地内的某类事件，举个例子，你不希望自己的领地内发生PK，你的领地叫做MyLand，此时可以敲入命令：/res set MyLand pvp false 。命令的最后一个位置，写true表示开启，写false表示禁止。
/res pset 领地名字 玩家名字 事件类型 true或false ，和前一条命令相同，惟一的区别是只为某个特定的玩家设置事件权限。  常见的事件类型请参看下表：  事件类型   详细解释   默认值
   animals   领地内是否允许刷出动物   是   
monsters   领地内是否允许刷出怪兽   是   
place   领地内是否允许建造   否   
destroy   领地内是否允许拆除   否   
creeper   领地内是否允许JJ爆炸   是   
tnt   领地内是否允许使用TNT   否   
damage   领地内是否允许造成伤害（包括pvp、火焰、跌落等）   是
   ignite   领地内是否允许点火   是  
  firespread   领地内是否允许火势蔓延   否  
  lavaflow   领地内是否允许岩浆蔓延   否
   waterflow   领地内是否允许大水蔓延   否  
  pvp   领地内是否允许PK   是
   healing   领地内是否会回血（无视饥饿度）   是  
  move   是否允许玩家走入领地   是   
piston   领地内是否允许活塞运动   是  
  container   领地内是否允许打开箱子炉子等容器   是
   use   领地内是否允许使用物品（如拉杆、按钮等）   是  
  bucket   领地内是否允许用桶子   是  
   3：锁箱子插件：玩家可以拿着牌子  右键箱子上锁    如果要共享箱子   先空手右键箱子   然后输入/lockette 3 其他人名字    还要增加的话输入/lockette 4 名字   
4：播放器使用教程：播放器打开方法：空手按住SHIFT  右键播放器  可以打开    然后可以放入碟子 刻录机使用教程：首先放入空白唱片，第一行写歌曲名字（不能太短）  第2行写歌曲地址:MP3结尾    （http://www.5dutv.cn/           在这个网站里有大量外链歌曲   也可以自由上传）  输入好之后   右下角变成绿色就刻录成功  点击Etch    成功！
  5：语音MOD：按住V可以和附近玩家语音交流   不要按太久   会掉线
