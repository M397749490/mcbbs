雫 API
更简单的API，提供MC服务器状态查询，随机二次元图片等

功能介绍
1. 随机图片API：随机获取二次元背景图（图片均为原图）
2. MCAPI：查询服务器基础信息，支持返回文本、JSON、状态贴图（可自定义MOTD、背景图片）
3. MCRCON：使用RCON控制你的MC服务器，可用于在线商店、对接机器人等
4. 网易云音乐解析：解析网易云音乐直链（暂不支持VIP歌曲）
