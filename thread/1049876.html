/obadmin: 管理员命令
/obadmin version: 显示 BentoBox 及其组件的版本
/obadmin tp <player>: 传送到玩家的岛屿
/obadmin tpnether <player>: 传送到玩家的岛屿

/obadmin info <player>: 获得您当前所在或者指定玩家的岛屿信息
/obadmin add <owner> <player>: 将玩家添加到队长的队伍中
/obadmin kick <team player>: 从队伍中踢走玩家
/obadmin disband <owner>: 解散队长的队伍
/obadmin setowner <player>: 将岛屿转交给玩家

/obadmin resets: 修改玩家的重置次数

安装教程
Aoneblock是Bentobox的附属插件，如果您需要使用Aoneblock，您需要首先安装Bentobox并在\ plugins \ BentoBox \ addons加入本插件
安装推荐您一键安装所有适用的Bentobox插件
官网打包下载地址
1.将Bentobox加入插件文件夹中，重新加载服务器
2.打开Bentobox文件夹中的config.yml，查找默认语言并更改为zh-CN
3.将Bskyblock加入plugins \ BentoBox \ addons文件夹中，重启
4.生成配置文件后使用我提供的配置文件覆盖并进行更改
5.删除位于服务端根目录下的[Aoneblock_world] 重启
建议关闭地狱及末地
FAQ
(本人翻译+补充,没用的没有加入)
Q:有哪些阶段?
A:共有11个阶段,分别为:Plains,Underground, Winter, Ocean, Jungle, Swamp, Dungeon, Desert, The Nether, Plenty, Desolation, and The End.每个阶段都会生成不同的方块,自动切换为对应的群系.
Q:完成11个阶段后会发生什么?
A:重复11个阶段
Q:遇到了石头之类的方块无法采集怎么办
A:用手撸,本插件依旧会让您获得石头[之类的]物资
Q:生成的方块为液体怎么办?
A:用桶装
Q:会生成生物吗?
A:会,每个阶段都会生成不同的生物
Q:会生成箱子吗?
A:会,箱子会有不同的稀有度
Q:岩浆和水会在哪个阶段生成?
A:岩浆会在第九阶段生成,水会在第六阶段生成[详情oneblock.yml]
Q:最终目标是什么?
A:无
Q:为什么我加入level插件后没有用?
A:插件自带等级,请输入/is count
Q:我开启了地狱和末地的生成,为啥没东西
A:本来就没...
Q:有count的阶段变量吗?
A:变量列表:https://bentobox-world.readthedocs.io/en/latest/gamemodes/AOneBlock/Placeholders/
Q:为什么没有xxx权限?
A:权限列表:https://bentobox-world.readthedocs.io/en/latest/gamemodes/AOneBlock/Permissions/
