标题: 且听我语
初三党终于迎来了短短十几天的寒假... 就最近一次我们大上海的质量抽查而言，还不错。就又能抽出时间来写代码了。我反编译了一遍几乎所有的启动器，感觉还是达不到我的要求，就准备再建个启动器玩玩。正好我的 Minecode Studio 也需要启动器，我准备开个新坑——专门提供高性能低内存的启动器。毕竟，不是所有人的设备都满足启动器的开销的。先把别人实现的大幅度修改下，再把 JVM 也给裁剪下，我想应该没什么问题了。原本打算用 C# 或者 Java 来写启动器，但考虑到要跨平台的因素，最终还是选择自己用 C++ 来实现。有些启动器的内部代码说实话写的不咋地，还不开源，开源的还没有注释，却表面功夫做的很到位，宣传的比实际运行的厉害多了... 我们搞技术的不追求过度的美，能符合自己的审美就可以了。C# 和 C++ 相比有利有弊吧，当时我也用 C# 来开发 Minecode Studio，开发到一半，发现内存就已经占了 100MB 了，显然与我的 “极速且不失美观” 开发标准背道而驰（关键是 C# 的 UI 绘制还慢）。我之前的几个项目开发了也蛮久了，我尽力吧，争取在今年夏天把它们发布出来。原先关注我的那些朋友们应该都不在茶馆里混了，这篇小短文也不知有多少人看到，反正关注者有多少我也无所谓了，这么几年在 Minecraft 搞软件开发也是全凭着自己的兴趣的。但在 mcbbs 里发布软件开发贴的奇葩估计也只有我了，知音者难寻啊。很多人说我是大佬，其实也没什么值得被人称为大佬的，一路走来，凭着强烈的兴趣和不服输的干劲才有今天如此的小有成就的。近年来 Minecraft 社区也不景气，像我这样的，应该已经很少了吧...
