Features 插件特性
  • 可自行整理自己的紅石音樂到選單裡面
  • 只需將.nbs歌曲“tracks”文件夾內
  • 隨機播放歌曲使用隨機音樂
  • 使用隨機音樂模式
  • 能夠配置菜單按鈕，聊天消息和更多
  • 可設定玩家登入服務器內就可以自動播放音樂
  • 可在服務器內自行重新載入配置
  • 服務器音樂廣播模式
  • 配置大廳選項

Commands 命令
  • /music - 打開音樂列表
  • /music <頁碼> - 打開音樂列表中指定的頁
  • /music item 拿到插件的物品可以直接打開
  • /music off - 關閉音樂
  • /music random - 播放隨機音樂
  • /music shuffle - 啟用隨機音樂模式
  • /music shuffle skip - 跳到下一首歌曲（只適用於已啟用隨機播放模式）
  • /music reload - 重新載入插件配置
  • /music radio [on/off] - 打開或關閉廣播音樂
  • /music radio skip - 跳過廣播音樂

Permissions 權限
  • music.list - 打開音樂選單的許可
  • music.random - 使用隨機音樂的許可
  • music.shuffle - 使用隨機音樂模式的許可
  • music.shuffle.skip - 使用隨機音樂模式跳到下一首的許可
  • music.reload - 使用重新載入插件的許可
  • music.radio - 使用廣播模式的許可
  • music.radio.skip -  使用廣播模式跳到下一首的許可
  • music.item.spawn.[shuffle/radio/random/list] 拿出其中一音樂插件的物品的許可
  • music.item.use.[shuffle/radio/random/list] 使用其中一種音樂插件的許可

Installation 插件安裝方式
  • 將您需要的版本丟入插件資料夾中
  • 重啟服務器
  • 使用/music 開啟音樂
Adding extra songs 添加額外音樂
  • 原文預設音樂下載 here.
  • 將下載好的.nbs音樂檔丟入 插件資料夾內的tracks資料夾內
  • 使用/music reload 重新載入配置
  • 使/music 開始享受音樂

# The size of the musiclist GUI
# NOTE: make sure the size is at least 9
# also make sure the size can be divided by 9
# (for instance: 9, 18, 27, 36, 45, 54, etc.)
# The specified size does NOT include the top-row
# containing navigation items
# If the requirements above are not met, the plugin
# will use it's default-value

# The action which will be performed when a player
# joins the server
# 3 = turn on server-radio
# 2 = play random song
# 1 = enable shuffle-mode
# 0 = do nothing

# Use #TOTAL to insert the total amount of pages
