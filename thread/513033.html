需要一定LINUX技巧

白菜们不要看了

linux开服好处： 快速,稳定,占用资源低,服务器出错率低

材料：
centos6系统的服务器
XSHELL
百度云上的服务端。
先准备
安装安全狗（防止DDOS攻击！）
linux命令(一行一个 完成之前的再继续)：
wget www.safedog.cn/safedog_linux32.tar.gz
tar xzxf safedog_linux32.tar.gz
cd safedog_linux32
setenforce 0 #关闭selinux
./install.py #出现暂停就一路回车 如果出现 select mod什么的 就按ctrl + c
之后你的服务器就能抗一般小规模DDOS攻击,当然尽量选择高防服务器,否则大流量就会被打死。

点击导出下载,就会出现一个提示框 先别里 放在一边
服务器上安装aria2c：
wget http://pkgs.repoforge.org/rpmfor ... 2-2.el6.rf.i686.rpm
rpm -ivh rpmforge-release-0.5.2-2.el6.rf.i686.rpm
yum -y install aria2

然后 把那个提示框的东西复制 在服务器上输入
比如我的：
aria2c -c -s10 -k1M -x10 -o "123.rar" --header "User-Agent: netdisk;5.2.7;PC;PC-Windows;6.2.9200;WindowsBaiduYunGuanJia"  --header "Cookie: 这个是COOKIE,所以打码"  --header "Referer:马赛克"
在服务端输入
然后就可以下载了.
之后,直接解压
如果是zip文件输入 unzip 文件名
比如 unzip 123.zip (你刚刚下载的文件)
如果是RAR
百度linux安装winrar方法.
我的安装方法：
  1. [root@localhost ~]# tar zvxf rarlinux-5.3.b5.tar.gz
  2. rar/
  3. rar/rar.txt
  4. rar/license.txt
  5. rar/readme.txt
  6. rar/order.htm
  7. rar/whatsnew.txt
  8. rar/acknow.txt
  9. rar/rar
  10. rar/unrar
  11. rar/rar_static
  12. rar/makefile
  13. rar/default.sfx
  14. rar/rarfiles.lst
  15. [root@localhost ~]# ls
  16. anaconda-ks.cfg  install.log         rar                     rpmforge-release-0.5.2-2.el6.rf.i686.rpm  RPM-GPG-KEY.atomicorp.txt
  17. huoji.rar        install.log.syslog  rarlinux-5.3.b5.tar.gz  RPM-GPG-KEY.art.txt                       safedog_linux32
  18. [root@localhost ~]# cd rar
  19. [root@localhost rar]# make
  20. mkdir -p /usr/local/bin
  21. mkdir -p /usr/local/lib
  22. cp rar unrar /usr/local/bin
  23. cp rarfiles.lst /etc
  24. cp default.sfx /usr/local/lib
  25. [root@localhost rar]# rar
复制代码
然后
解压
unrar x 你刚刚的文件名字
注意 别解压到你的根目录下了

然后
vim 开服.bat
看里面的代码
比如我的是
"C:\Program Files\Java\jre7\bin\java.exe" -Dfml.ignorePatchDiscrepancies=true -Xincgc -Xmx1024M -jar cauldron-1.7.10-1.1231.01.207-server.jar

开服服命令就是
java  -Dfml.ignorePatchDiscrepancies=true -Xincgc -Xmx1024M -jar cauldron-1.7.10-1.1231.01.207-server.jar
即可！
