相对应java，C#有GUID，他们生成的机制不同，但是你也可以通过拿到字符的hash来得出GUID:

  2. string input = "asdfasdf";
  3. using (MD5 md5 = MD5.Create())
  4. {
  5.     byte[] hash = md5.ComputeHash(Encoding.Default.GetBytes(input));
  6.     Guid result = new Guid(hash);
  7. }
