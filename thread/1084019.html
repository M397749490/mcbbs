模组简介
铁质喷气背包是一个以FE能源为动力的喷气背包模组。
这个模组默认添加的所有喷气包都是可以通过JSON文件配置的。
而且这个模组允许你通过自定义的方法，个性化地配置你自己的喷气背包。
自定义配置
自定义配置喷气背包可以通过简单地复制+粘贴一个默认的jetpack jsons并更改名称(以及其他所有值)来完成。
修改内容：
1.文件的名称以及JSON中 "name" 的值
需要注意的是，JSON中的 "name" 应该全是小写，并使用下划线替代空格。
JSON中的变量见下方
Name:
喷气背包的名字。必须全部为小写，并使用下划线替代空格。这将用于注册名称和本地化名称。对于本地化名称，喷气背包的名称将被自动格式化。
  1. {
  2.   "name": "emerald"
  3. }
复制代码
Disable:
决定了该喷气背包是否可以使用。
  1. {
  2.   "disable": false
  3. }
复制代码
Tier：
喷气背包的阶段。确保每一阶段至少有一个喷气背包(例如1,2,3都至少有一个喷气背包)。阶段一是创造背包。
  1. {
  2.   "tier": 5
  3. }
复制代码
Colour:
喷气背包的颜色。这个颜色应该是十六进制值。
  1. {
  2.   "color": "41f384"
  3. }
复制代码
Armor points:
喷气背包所给予的护甲值。
  1. {
  2.   "armorPoints": 4
  3. }
复制代码
Enchantability:
喷气背包获得优质附魔属性的概率。
  1. {
  2.   "enchantability": 15
  3. }
复制代码
Crafting material:
用于制造喷气背包及其组件的材料。语法是使用 modid:itemid 表示物品，标签: modid:tagid 表示标签。
  1. {
  2.   "craftingMaterial": "tag:forge:gems/emerald"
  3. }
复制代码
Creative:
该喷气背包是否只能在创造中使用。
  1. {
  2.   "creative": false
  3. }
复制代码
Rarity:
喷气背包的稀有程度。这基本上只是用来改变 tooltips 的颜色。有效值是0-3。
  1. {
  2.   "rarity": 0
  3. }
复制代码
Capacity:
喷气背包中所能容纳的FE量。
  1. {
  2.   "capacity": 48000000
  3. }
复制代码
Usage:
在飞行/悬浮时消耗的FE数量。
  1. {
  2.   "usage": 880
  3. }
复制代码
Vertical speed:
向上飞行时的速度。
  1. {
  2.   "speedVertical": 1.03
  3. }
复制代码
Vertical acceleration:
垂直加速度
  1. {
  2.   "accelVertical": 0.17
  3. }
复制代码
Sideways speed:
向前飞行时的速度
  1. {
  2.   "speedSideways": 0.21
  3. }
复制代码
Descending hover speed:
在悬浮模式中，按Shift下降的速度
  1. {
  2.   "speedHoverDescend": 0.45
  3. }
复制代码
Hover speed:
在悬浮模式中，自然下降的速度
  1. {
  2.   "speedHover": 0.0
  3. }
复制代码
Sprint speed multiplier:
冲刺时相对于原来的速度
  1. {
  2.   "sprintSpeedMulti": 2.0
  3. }
复制代码
Sprint fuel multiplier:
冲刺时相对于原来消耗的燃料量
  1. {
  2.   "sprintFuelMulti": 4.0
  3. }
复制代码
实例：
  1. {
  2.   "name": "emerald",
  3.   "disable": false,
  4.   "tier": 5,
  5.   "color": "41f384",
  6.   "armorPoints": 4,
  7.   "enchantability": 15,
  8.   "craftingMaterial": "tag:forge:gems/emerald",
  9.   "rarity": 0,
  10.   "capacity": 48000000,
  11.   "usage": 880,
  12.   "speedVertical": 1.03,
  13.   "accelVertical": 0.17,
  14.   "speedSideways": 0.21,
  15.   "speedHoverDescend": 0.45,
  16.   "speedHover": 0.0,
  17.   "sprintSpeedMulti": 2.0,
  18.   "sprintFuelMulti": 4.0
  19. }
