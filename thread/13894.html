首先先准备矿车和铁轨+一桶水
然后挖一个1X2的坑
一共2列 X X X 俯视
             X    X
             X    X
             X X X
然后一排挖通 另一排每隔4层放一个矿车
X    C X
X    X X
X    X X
X    X X
X       X     
X    C X就这样一直放下去
最后在道一桶水
X    C X
X S X X
X X X X
这样就完成了 下去就跳下去  上去就朝上点右键 比下去还快
而且很简单..
