作者: 浅念哥    时间: 2018-5-13 01:09
需要用管理员身份创建领地的快捷方法是使用 /resadmin 替代 /res。
比如：/res create 测试领地
替换为：/resadmin create 测试领地
作者: zykool    时间: 2018-5-13 17:28
