一个小小的指令问题
怎么用命令检测和村民交易后触发红石或者和一个村民交易到限定数量触发红石？
作者: 爱心魔王FHC    时间: 2016-8-16 17:40
创建一个叫traded（名字可自定，中文除外）的计分板（判据：与玩家交易）
/scoreboard objectives add traded stat.tradedWithVillager
然后玩家与村民交易计分板分数会自动+1
1、检测和村民交易后触发红石
把traded分数至少为1的玩家的分数设为0，用脉冲/高频激活，比较器输出（执行成功就会有输出）
/scoreboard players set remove @a[score_traded_min=1] 0
2、和一个村民交易到限定数量触发红石
同理/scoreboard players set remove @a[score_traded_min=限定数量] 0
