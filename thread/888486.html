作者: mine新时代xs    时间: 2019-7-19 20:09
龙之进化模组在渲染实体时崩溃了
可能性：龙之进化模组默认是提供了护甲3D、能量水晶光影、能量核心光影和反应堆光影的
它们可能并不支持你的电脑
在config文件夹下的Brandon3055文件夹中找到DraconicEvolution.cfg并使用记事本/notepad++打开
找到
  1.     # This allows you to disable just the Energy Crystal shader. This shader can be a lot lagier than the reactor's shader since there are usually a lot more of them (The fallback crystal texture is not soooo bad...).
  2.     B:useCrystalShaders=true

  4.     # Set this to false if you prefer the original look of the reactor beams.
  5.     B:useReactorBeamShaders=true

  7.     # Set this to false if your system can not handle the awesomeness that is shaders! (Warning: Will make cool things look horrible!)
  8.     B:useShaders=true
复制代码

这三个true全部改为false即可
