本款插件的想法借鉴于 RealDualWield
(https://www.spigotmc.org/resourc ... without-mods.30816/)
众所众知，MineCraft 1.9 新增加的双持系统中，无法在副手使用武器 (剑类武器) 进行攻击。 本款插件突破了这个原版限制，使玩家能够使用副手攻击。

在使用本插件之前，请确保您的服务器安装了 TabooLib。

!插件特色:


- 高度可自定义的配置文件
- 使用副手来进行攻击
- 理论兼容大多数物品属性插件 (仅测试 SX-Attribute)
- 兼容副手附魔
- 轻量级
- 基于 TabooLib 的语言系统
- 开发者 API

!配置文件:
  1. # 如服务器安装反作弊，则在副手攻击时有概率会被反作弊误判。
  2. # 这里可以在副手攻击前给予玩家绕过反作弊的权限，以达到不被误判的效果。
  3. # 如服务器未安装反作弊，可填写 "NONE" 以绕过此检测。
  4. GRANT-PERMISSIONS:
  5. - "NONE"

  7. # 触发副手攻击所需要的条件。
  8. ATTACK-REQUIRE:
  9.   # 权限条件，如果玩家没有该权限则不会触发副手攻击。
  10.   # 填写 "NONE" 以绕过权限检测。
  11.   PERMISSION: "NONE"
  12.   # 副手物品的描述判断条件，当副手物品的任意行数填有以下字段时触发副手攻击。
  13.   # 在这里无需填写任何颜色符号，填写 "NONE" 以绕过描述检测。
  14.   LORE-KEY: "副手武器"
  15.   # 当主手持有食物时，且饥饿度使玩家能够食用主手食物时。就会同时触发两个操作 (则副手攻击，主手食用食物)
  16.   # 如改成 TRUE，则会优先补充饥饿度再进行副手攻击。 (优先度调整)
  17.   FOOD-LEVEL: true

  19. # 触发副手攻击之后的冷却设定。
  20. ATTACK-COOLDOWN:
  21.   # 副手物品的冷却字段，当副手物品的任意行数填有以下字段时触发 {0} 时长的冷却效果。
  22.   # 冷却单位: 秒。
  23.   LORE-KEY: "副手冷却: {0}/s"
  24.   # 是否在 ACTIONBAR 上显示冷却。
  25.   ACTIONBAR-DISPLAY: false
  26.   # 是否在 副手显示栏 上显示冷却。
  27.   OFFHAND-BAR-DISPLAY: true
  28.   # 在冷却时段尝试使用副手攻击时，是否给玩家发送信息。
  29.   CHAT-BAR-DISPLAY: false
