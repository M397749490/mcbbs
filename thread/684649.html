声明：如果电脑出事请不要找我算账！
最近发现Linux的性能貌似比Windows要好...于是就心血来潮写了这个教程...
这里以Ubuntu Kylin为例（我不是打广告！）
1.游玩准备
0.一个Linux系统
1.Java（推荐Oracle的Java，OpenJDK也行，最好是Java8）
2.HMCL（除非你有别的启动器）
3.一个终端（应该不会被卸载吧...）

2.下载Java并安装
1.首先，我们来到了Linux-Java的下载网页

2.然后下载它
这里需要注意一下：
（1）如果是32位系统：下载Linux
（2）如果是64位系统：Linux与Linux x64均可（推荐Linux x64）
3.下载完成后你会得到一个jre-8u121-linux-x64.tar.gz或者jre-8u121-linux.tar.gz
这是一个压缩包文件，记住它的位置
4.打开终端
5.切换至root用户：
方法有两种：
（1）输入
  1. su root
复制代码
然后输入root的密码
（2）输入
  1. sudo -i
复制代码
然后输入当前用户的密码
6.在/usr下建立java目录
  1. cd /usr
  2. mkdir java
复制代码
7.将刚才的解压包丢进/usr/java

  1. cp 你安装包所在的位置/安卓包的名字 /usr/java
  2. 例如：cp /桌面/jre-8u121-linux-x64.tar.gz /usr/java/
复制代码
8.用终端自带的命令解压它

  1. tar -zxvf 压缩包的名字
  2. 例如：tar -zxvf jre-8u121-linux-x64.tar.gz
复制代码
解压后你会得到一个"jre1.8.0_121"（如果压缩包是jre-8u121-linux-x64.tar.gz）
注：如果你的压缩包是jre/jdk-"数字1"u"数字2"开头，那么解压得到的目录就是"jre/jdk1.数字1.0_数字2"
9.编辑配置文件

  1. sudo vim /etc/profile
复制代码
在文档末添加：

  1. JAVA_HOME=你jre/jdk文件夹的路径（例如：/usr/java/jre1.8.0_121/）
  2. PATH=$JAVA_HOME/bin:$PATH
  3. CLASSPATH=.:$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar
  4. export JAVA_HOME
  5. export PATH
  6. export CLASSPATH
复制代码
保存退出：
按下ESC键，进入命令行模式，输入：

  1. :wq
复制代码
10.测试是否安装成功：
输入
  1. source /etc/profile
复制代码
然后

  1. java -version
复制代码
若响应
  1. java version "1.8.0_121"
  2. Java(TM) SE Runtime Environment (build 1.8.0_121-b13)
  3. Java HotSpot(TM) 64-Bit Server VM (build 25.121-b13, mixed mode)
复制代码
或者类似的文本，及安装成功
11.重启电脑
12.教程结束

3.下载HMCL并启动
1.来到huanghongxun的原贴
2.滚动页面到这里

3.进入通用版jar链接&下载它
4.打开它所在的文件夹
5.打开终端
6.输入

  1. java -jar
复制代码
7.将jar拖入终端，拖入后（各有不同）

  1. java -jar '桌面/HMCL.jar'
复制代码
8.在终端内按下回车键，出现

  1. [11:58:57] [main/INFO] *** Hello Minecraft! Launcher 2.7.6.23 ***
  2. [11:58:57] [main/INFO] Initialized settings.
复制代码
然后就会蹦出我们熟悉的HMCL界面

添加新的客户端，开始游玩吧
如果出现BUG，请翻页
