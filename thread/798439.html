如何把旧存档的物资转移到新存档？
光羽传说第三版支持物资继承，如何把旧存档的物资转移到新存档？这很简单
首先，给客户端装上1.7.10的创世神mod，然后进入旧存档，
在地皮世界建造一个这样的建筑
(底层是5×5的圆石)
然后，把你所有需要转移的物资装进这些箱子
(这么多箱子够你装了吧？)
然后，开启作弊，用木斧左击这个方块

然后右键这个方块

然后站到这个位置
对，就是这个位置
先输入指令//copy
注意是双斜杠
然后输入指令//schematic save theitemcopy
一样是双斜杠
这过程中不能退出游戏，否则就得重新左右击方块，然后重新输入指令
指令全部输入完毕后，退出旧存档，进入新存档
进入新存档的地皮世界，找个能放下这个建筑的空地
然后站稳了，打开作弊，输入指令//schematic load theitemcopy
一样是双斜杠
当你发现周围出现了这个建筑后，退出游戏，删掉创世神mod
然后再进入游戏，打开箱子，发现你的物资成功转移

疑难问答：
：我想修改客户端配置怎么办？
：尽量不要修改

：游戏内标有“不能使用”字样的物品是什么东西？
：是不可以使用的物品，严重破坏游戏平衡

：启动器一打开就无响应怎么办？
：请重新开启启动器，然后别操作电脑，等一会即可
  因为它可能在寻找java或寻找某些配置文件

：游戏客户端启动时黑屏了怎么办？
：别关客户端，也别操作电脑，等一会即可
  可能是电脑可用内存太少的原因，关掉一些不必要的应用程序，
  或者杀毒、清理垃圾、加速一下。

：我想作弊怎么办？
：不能作弊哦(在某些特殊情况下作者允许使用的指令除外)

：设置错了重生点而无法回到废弃凋灵宫殿怎么办？
  ：在你周围放一张床，打开作弊，使用指令/time set 18000
  然后睡一觉，再把床挖了，再想办法弄死自己
  重生，即可回到废弃凋灵宫殿

：我想联机玩这个地图：
：此客户端不支持联机，请把此客户端里的地图、
mod、材质包、assets文件夹、config文件夹、
  customnpcs文件夹都移入联机客户端，替换联机客户端的同名文件夹，
  并把class文件夹里的文件压缩到联机客户端的核心文件里并替换源文件即可，
  注意联机客户端必须是1.7.10的版本哦。

：我玩的时候感觉很卡
：请参阅：https://user.qzone.qq.com/3315302995/blog/1517575217

：我想添加其它mod怎么办？
：允许添加其它mod，但是不能加大幅降低游戏难度的mod，
   在主世界自然生成矿物、建筑…(除怪物外)的mod，生成的怪物会破坏地形的mod，
   会修改原本mod特性的mod(附属、扩展、联动除外)，有现代科技的mod，跟原本mod冲突的mod
