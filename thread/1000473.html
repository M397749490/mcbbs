检测服务器MSPT并发送数据
┃ 简介
此插件可以提供管理员或玩家服务器的MSPT(一游戏刻有多少毫秒)
十分轻量,只有11KB
支持在物品栏稍上方的位置上显示
没有配置文件

┃ 用法
/tickmonitor 然后按TAB补全可以看到插件的选项
→/tm disable 隐藏
→/tm enable 显示
→/tm getlatest 聊天栏展示一次
→/tm monitor 在活动栏显示
→/tm reset 重置选项
/tm 和/mspt 是简略指令

┃ 使用API
The API fires the event "MonitoringCycleCompleteEvent"
Event cannot be cancelled
It passes the time frame that has elapsed (enum Timeframe) and a set of doubles that are the observed milliseconds per tick for the event's timeframe
event.getTimeframe() -> MonitoringCycleCompleteEvent.Timeframe
event.getData() -> List<Double>

如何读懂数据:
游戏正常情况下每秒钟(s)有20游戏刻(tick),这是游戏在服务器运行的基本属性
一秒又包含了1000毫秒(ms)
1000毫秒(ms) ÷ 20游戏刻(tick) = 50ms
因此,如果你的MSPT超过50,你服务器就缺少TPS了,每秒钟的游戏刻会减少
效果就是游戏变慢,如果是10游戏刻的服务器,农作物就会半速生长
MSPT越低,服务器越好
Are you a sucker for bringing your server to peak performance, but /tps isn't quite accurate enough for you?

TickMonitor allows you to monitor your server's MSPT (milliseconds per tick) - which is helpful for finding processes that take up lots of CPU power. Rule of thumb: if your MSPT are below 50 ms, your server should run on *20.00 TPS!
