抱歉哈, 今天才看见
我现在再总体说一下:
比如你要 连接你的 起床端 那么就是
1 . 首先 打开 你的 起床端
2. 随后打开 plugins里的 起床插件的 文件夹的 config
3. 使用 自带的 Ctrl+F搜索“bungeecord”
4. 然后我看下面 我插入的 代码

  1. bungeecord:   
  2. enabled: true
  3. hubserver: lobby#1     #游戏结束后返回的大厅
  4. endgame-in-lobby: false     
  5. full-restart: true
  6. spigot-restart: false   #以上三项不用修改
  7. motds:
  8. lobby: "&a等待中..."     #游戏未开始时显示的Motd，要和上面的一样[ 也就是 ServerJoiner 所配置的一样]
  9. running: "&c游戏中..."     #游戏进行时显示的Motd [ 也就是 ServerJoiner 所配置的一样]
  10. stopped: "&c暂停中..."     #服务器关服时显示的Motd，当重启的时候也会显示这个[ 也就是 ServerJoiner 所配置的一样]
  11. full: "&e人数已满"    #当服务器满人时显示的Motd [ 也就是 ServerJoiner 所配置的一样]
