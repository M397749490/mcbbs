public class Test {

    public static void main(String[] args) {

        new b();

    }

}



class a {

    public static Object c = b.d;

}



class b extends a {

    public static Object d = "";

}


单独这样是不会锁的，因为类加载首先 defineClass，然后调用 <clinit>，已经被调用过 <clinit>的不会再次调用
加载顺序是这样的

首先加载 b 类，b 类的超类是 a
因此最先 defineClass a
然后 defineClass b  

这个时候 c d 都是 null
main 里调用的是 b，因此调用 b 的 <clinit>
b需要a，所以调用 a 的 <clinit>
调用 a.c = b.d，b.d 这时候是 null，因为 b 的 <clinit> 还没跑
然后 a <clinit>返回，b <clinit> 开始跑，b.d = ""

两个线程会锁，因为类加载(<clinit>)是要上锁的，著名的静态内部类单例模式就是基于类加载要上锁实现的
两个线程同时加载两个类，两个线程各自拥有自己类的锁，因此会死锁
也只有两个线程加载这两个类的各一个会锁
