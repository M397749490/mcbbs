——插件权限解析——
EasyKits插件
权限■┐
         ■┌EasyKits.kits.cooldown - 给这权限之后才会受到冷却时间的限制
        ■├EasyKits.kits.maxuse - 给这权限之后才会受到最大领取次数的限制
        ■└EasyKits.kits.礼包名称 - 给这个权限之后才能领取相应的礼包

指令■┐
        ■┌/kit [礼包名称] - 领取一个礼包
        ■├/kit create [礼包名称] - 创建一个礼包(当前背包的物品)
        ■├/kit remove [礼包名称] - 删除一个礼包
        ■├/kit price [礼包名称] - 设置领取这个礼包的价格（前置Vault）
        ■├/kit show [礼包名称] - 展示一个礼包
        ■├/kit cooldown [礼包名称] 时间 - 设置礼包领取时间的间隔例如：1s/1m/1h/1d
        ■├/kit maxuse [礼包名称] 次数 - 设置礼包每个玩家最高领取次数
        ■├/kit reset cooldown [礼包名称] 玩家 - 重置玩家的领取冷却时间
        ■├/kit reset maxuse [礼包名称] 玩家 - 重置玩家的最大领取次数
        ■├/kit give 玩家 [礼包名称] - 给予玩家一个指定礼包
        ■├/kit book - 给所有有权限的人一本书，查看可领取的礼包
        ■├/kit list - 列出礼包的列表（如果你喜欢用指令）
        ■└/kit reload - 重载插件
Banitems插件[ItemLoreStats插件就不过多介绍了]
指令■┐
      ■┌/BanItem help查看帮助
      ■├BanItem add添加物品到黑名单
      ■├/banitem add 理由-拉黑物品并说明理由  
      ■├/banitem addall 理由    拉黑该ID下的所有附属物品 如羊毛35:*
      ■├/BanItem del移除黑名单的物品
      ■├/BanItem clear清除所有禁用物品
      ■├/BanItem list显示禁用物品名单
      ■└/BanItem reload重载插件

权限■┐
       ■┌Banitem.help
       ■├Banitem.add
       ■├Banitem.del
       ■├Banitem.clear
       ■├Banitem.list
       ■├BamItem.reload
       ■└Banitem.*
   ╔──────╗
   │权限解析 ╚──────────────────────────────────────╗
   │banitem.int.<itemid>:<data>           | 交互物品                                  │
   │banitem.click.<itemid>:<data>         | 左键或右键物品                        │
   │banitem.break.<itemid>:<data>       | 破坏被ban物品方块                   │
   │banitem.place.<itemid>:<data>        | 放置被ban物品/方块                 │
   │banitem.pickup.<itemid>:<data>      |拾取被ban物品/方块                  │
   │banitem.craft.<itemid>:<data>         |合成被ban物品/方块                  │
   │banitem.bypass.<itemid>:<data>               | 包含以上所有权限           │
   │(Data 是物品ID后面的附加值, 没有则不必填写, 如 35:4 和 1523:2000) │
   ╚─────────────────────────────────────────────╝

ItemDurability插件
                              ┏─────────┓
                              │权限-指令■┓  │
                              ┗──────■┏指令：/nj hand <数值> 设定手持物品耐久[-1为无限耐久]
                                              ■┗权限：ItemDurability.admin 默认为管理员权限-OP

教学开始
[spoiler]
接着上一章的权限组-创建一个普通的权限组后加:2倍伤害权限[战士比较抗打]在晋级战士后血量会比较多例如：55HP
因为是战士所以血量应该是最多的-例如[出肉的德玛西亚其他的职业都不要超过这HP即可，例如战士的这个权限组名称为：zs 则┓
[职业武器]-钻石剑ID为：276我们可以用RPGitems插件或者CommandBocks又或者是背包编辑器制作该职业的武器[不要变态属性或者伤害]例如[背包编辑器/CommandBlock]-锋利-IV截肢杀手-II亡灵杀手-III荆棘-I抢夺III火焰附加III附加伤害-15丨属性：生命值+15%攻击力+10%即可
[RPGitems]-伤害20-25 被动技能-天沟[沟石头.泥土.草快.沙子即可不要传送！]速度提升一级.火炕二级.抗性二级.即可.
建议搭配Lores插件修改武器名字和武器的Lore这样会更有效果[除RPGitems武器道具]。
[做好武器之后就可以进行绑定职业了]-Banitem插件┓
                                                          [不推荐] ■┗先Ban了钻石剑然后把钻石剑[276]的使用权限给战士组[zs]即可
                                                                       ■┗需要配合EasyKits插件
                                                               [推荐]■─ItemLoreSats插件━┐
                                                                                                     ─┘
■┏/ils export <Item_name>将你手中的物品保存到<itme_name>■──────╗
■┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╠[OP指令]
■┗/ils give <player_name> <Item_name>给玩家<item_name>中的物品■─╝
不需要配合Easykits插件-
用脚本方块的[判定权限组][无视权限]指令项来执行指令┓
/sbinteract create [@group:zs][@bypass /ils give <player> <itme_name>]
创建点击触发：[探测权限组是否为:zs][(如果是则)无视权限执行:/ils give <player> <itme_name>指令]
