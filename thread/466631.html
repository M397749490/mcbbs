getMaxHealth这么简单的方法有必要用NMS吗？。。
如果你要使用NMS，我建议简单的功能直接用反射来实现，这样就不需要导入NMS包了。弄个判断服务器版本的。然后就可以根据这个版本号来 Class.forName("net.minecraft."+服务器版本+".XXX")
我这边有个现成的方法：
  1.   private static Class<?> getCraftClass(String name) {
  2.     String version = getVersion() + ".";
  3.     String className = "net.minecraft.server." + version + name;
  4.     Class clazz = null;
  5.     try {
  6.       clazz = Class.forName(className);
  7.     } catch (ClassNotFoundException e) {
  8.       e.printStackTrace();
  9.     }
  10.     return clazz;
  11.   }
  12.   private static String getVersion() {
  13.     return org.bukkit.Bukkit.getServer().getClass().getPackage().getName().replace(".", ",").split(",")[3];
  14.   }
