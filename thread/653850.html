LevelRegion
--= 高速快捷的区域等级限制 =--

——————————————————————————————————————

注意
本插件为 Skript 编写，使用前请确保你了解 Skript(.sk) 的基本使用方法

——————————————————————————————————————

插件作用

最简单的配置
设置一个区域的等级限制



插件特性

将一个WorldGuard区域设定进入等级



插件权限

无



插件命令

无
配置文件实时更新无需重载






插件配置

version: 1.0 // 插件版本 请勿更改 //
prefix: §c§l[§4§lLevelRegion§c§l] // 插件前缀 //
region:
  example:      // ID 随意 不可重复 //
    name: example  // WorldGuard 区域名称 建议创建区域时 使用较长的名字 最好不要和世界名重复 //
    maxlevel: 100    // 最大进入等级 //
    minlevel: 10      // 最低进入等级 //
    message: '{p} §4你无法进入这里！'    // 无法进入提示 //

如何使用


1. 将 Skript, Skquery, WildSkript, WorldRegion 放入插件文件夹后重启

Skript - https://github.com/bensku/Skript/releases (Works on 1.7-1.10)
SkQuery 1.7, 1.8, 1.9 - http://republicansensei.com/SkQuery 1.7-1.8-1.9.jar
SkQuery 1.10 - http://republicansensei.com/SkQuery 1.10.jar
WildSkript 1.8- http://republicansensei.com/WildSkript 1.7-1.8.jar
WildSkript 1.9- http://republicansensei.com/WildSkript 1.9-1.10.jar
WorldGuard - https://dev.bukkit.org/projects/worldguard

2. 将 Load-LevelRegion.sk， LevelRegion.sk 放入
"/plugins/Skript/scripts/" 文件夹内

3. 输入指令 /sk reload all 载入脚本  完成 !
