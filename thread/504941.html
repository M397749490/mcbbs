①简介

这是BungeeAdminTool的补丁插件，他修复了该插件在非正版验证服务器使用时的一个问题：当一个玩家被封禁后，该玩家可以简单的修改游戏名字母的大小写来绕过封禁重新登录服务器，由于很多插件都是不区分大小写的，所以，这样就如同没有封禁。当前版本只支持全服封禁的情况。

注意：你必须先安装BungeeAdminTool，并将其数据存储方式设置为mysql。

②如何安装

  • 放入Bungee的Plugins目录中，重新启动BungeeCord，启动时会有报错发生，那是因为在首次加载时还没有设置数据库连接参数，请忽略；
  • 修改配置文件中的数据库连接参数，跟BungeeAdminTool配置文件中的数据库设置一致即可，然后重新启动BungeeCord

③配置文件
  1. # 数据库连接账号数据, 自动从BungeeAdminTool配置文件中读取, 无需配置
  2. mysql:
  3.   username: username
  4.   password: password
  5.   database: database
  6.   host: localhost
  7.   port: 3306
  8. # 检测到已被封禁时, 发送给玩家的理由
  9. banReason: '§4该帐号已被封禁, 请不要尝试通过修改游戏名大小写来绕过封禁!'

④开发计划

  • 支持单服封禁的情况
  • 支持通过读取BAT的配置文件自动设置数据库连接参数

⑤补充

这个插件是为自己的服务器开发的，目前尚没有发现bug，如果你在使用中发现了任何bug，欢迎反馈！
