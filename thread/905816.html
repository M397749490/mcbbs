你想在生存模式下使用屏障和基岩吗?
Or do you want to add destroy or place block conditions?
?。。。?。。。?。。。?。。。?。。。?。。。?。。。?。。。?。。。?。。。?。。。?。。。?。。。?
功能

1.显示附近的屏障和结构方块

2.破坏创造模式的方块，比如基岩和屏障

3.设置破坏和掉落的条件

  • Menu-Break - 通过菜单破坏物品.
  • Menu-Drop - 通过菜单破坏的物品将会掉落.
  • Vanilla-Break - 可以徒手或通过特定物品破坏方块.
  • Vanilla-Drop - 物品以常规方式掉落.
  • Explode-Break - 可通过爆炸破坏方块.
  • Explode-Drop - 炸毁的物品可掉落.
  • World and Location - 限制破坏地点.

4.放置条件
  • World and Location - 限制破坏地点.
5.权限系统
6.购买&给予创造模式方块

  22.     description: Allows destroy barriers.
  23.     default: op
复制代码
指令
/barrierplus → 显示插件版本
＊<>: 必要项, []: 可选项
/barrierplus
/barrierplus help
/barrierplus reload
/barrierplus buy <item>
/barrierplus buy <item> [player]
购买已配置的方块. 你可以设置数量与价格.
/barrierplus give <item> [amount]
/barrierplus give <item> [amount] [player]

  2. config-Version: 1
  3. Metrics-Logging: true
  4. Log-Coloration: true

  6. # 菜单物品
  7. Menu-Item-Type: 'PLAYER_HEAD'
  8. # To identify the menu. 你需要将 "&" 换成 "§" .
  9. #If you don't have a menu in your server, you can set '' to use a vanilla item.
  10. Menu-Item-Name: '§e§l屏障 §6§l菜单'

  12. # 显示附近的屏障.
  13. Barrier-Show-Distance: 10

  15. Message:
  16. Prefix: '&7[&dBarrierPlus&7]&r '

  18. No-Perm-Barrier-Place: '&c你没有防放置屏障的权限.'
  19. Commands:
  20. noPermission: '&c你没有使用该命令的权限!'
