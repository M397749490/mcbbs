1.8同样可以做到:
  1. /scoreboard objectives add a dummy
  2. /scoreboard players set @a a 1 {SelectedItem:{id:"minecraft:bow",tag:{NBT可自行更改}}}
  3. /execute @p[score_a_min=1] ~ ~ ~ scoreboard players set @e[type=Arrow,r=1] a 1
  4. /execute @e[type=Arrow,score_a_min=1] ~ ~ ~ effect @e[r=1] minecraft:poison 1 1
  5. /scoreboard players set @e[type=Arrow,score_a_min=1] a 2 {InGroud:1b}
  6. /kill @e[type=Arrow,score_a_min=2]
