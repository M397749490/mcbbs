（注：在学习编写插件之前请先熟练掌握Java知识。建议阅读本文之前先阅读http://www.mcbbs.net/thread-41414-1-1.html这个帖子）



        嗯，我也刚刚开始学习编写插件的。虽然插件文档很多，但是有时候会觉得无从下手，相信很多人有跟我一样的困难，于是我现在就用我写的第一个插件作为例子说一下编写插件最基本的内容。


       我的插件编写环境：JDK7（现在的Bukkit都是用Java7编译的，所以我们的开发环境也要一致）（过会不要问为什么我的是中文的）；IDE：Eclipse Kepler Service Release 1（上面提到的那个帖子中用的Netbeans，其实用这两个都很好，细节方面大同小异）；编码方式：UTF-8；（我用这个是兼容性强一点，特别在插件编写中如果出现中文，就不能用ANSI这样的单字节编码了，不然会乱码，GBK没试过不知道效果如何）BukkitAPI：bukkit-1.6.4-R2.0.jar.

       本次编写插件的目的：通过一个可控的配置文件修改末影龙的攻击力，并且在攻击时能够附加一个反胃效果。

       那么我们就开始了，Eclipse上来的一些准备工作，然后我们新建一个Java项目，名字随意，这里我用的是EnderdragonEX，JRE选择JavaSE-1.7；在下一步中记得在库(Libraries)中导入BukkitAPI文件。


        然后我们先在/src/中建立一个包，这里我建的是.com.mewsf.enderex(注：必须全部小写，且不能包含org.bukkit等字样)；并新建插件的主类，这里我用的是EnderdragonEX.java(后面为了方便，我没有再给各个监听器单独建类，而是把他们都写到主类里了)

       第二个重要部分是写plugin.yml，bukkit依赖这个识别插件，下面是我写的plugin.yml：（我就不详细说明各项作用了）
  1. name: EnderdragonEX
  2. main: com.mewsf.enderex.EnderdragonEX
  3. version: 1
复制代码
然后是插件的配置文件config.yml:（注：其实可以不用写，但是为了过会写插件图方便，我就先写好它。其实这样有一个缺陷，就是当文件被破坏时会报错）
  1. #末影龙伤害
  2. Damage: 10
  3. #是否开启反胃效果
  4. Nausea: true
  5. #反胃效果持续时间(注:实际效果中的时间为{设置值/服务器TPS})
  6. #默认值约为1秒(服务器最大TPS为20)
  7. NauseaTimer: 20
复制代码
关于配置文件的简单教程见此：http://forums.bukkit.org/threads/tutorial-intermediate-configuration-yaml-make-configs.45383/（目前暂时无力汉化）


        然后！就是代码了。
  1. package com.mewsf.enderex;

  3. import java.io.File;

  5. import org.bukkit.configuration.file.FileConfiguration;
  6. import org.bukkit.entity.Entity;
  7. import org.bukkit.entity.EntityType;
  8. import org.bukkit.entity.LivingEntity;
  9. import org.bukkit.event.EventHandler;
  10. import org.bukkit.event.Listener;
  11. import org.bukkit.event.entity.EntityDamageByEntityEvent;
  12. import org.bukkit.plugin.java.JavaPlugin;
  13. import org.bukkit.potion.PotionEffect;
  14. import org.bukkit.potion.PotionEffectType;

  16. public class EnderdragonEX extends JavaPlugin{
  17.         @Override
  18.         public void onEnable(){
  19.             File configFile = new File(getDataFolder(), "config.yml");     //定义config.yml
  20.         if (!configFile.exists()) {            //此段代码用于config.yml不存在时生成此文件
  21.             saveDefaultConfig();
  22.         }
  23.     FileConfiguration config = getConfig();    //读取config.yml
  24.     final int nauseatime = config.getInt("NauseaTimer");     //以下三个final都是把config.yml中的
  25.     final int damage = config.getInt("Damage");              //数值转化为插件中的常量
  26.     final boolean nausea = config.getBoolean("Nausea");

  28.     /*
  29.      *下面是更改末影龙伤害的监听器
  30.      */
  31.         class DamageEventListener implements Listener  {
  32.         @EventHandler
  33.         public void onEntityDamagedByEntityEvent(EntityDamageByEntityEvent event) { //调用了实体被实体攻击时的事件
  34.         final Entity damager = event.getDamager();                 //获取攻击者
  35.            if (damager.getType() == EntityType.ENDER_DRAGON) {        //如果攻击者是末影龙
  36.     event.setDamage(damage);                                   //将伤害值改为已定义好的damage
  37.         }
  38.         }
  39.         }
  40.         class Nausea implements Listener {                          //反胃效果的监听器
  41.                 @EventHandler
  42.                 public void onEntityDamagedByEntityEvent(EntityDamageByEntityEvent event) {
  43.                         Entity damager = event.getDamager();
  44.                            if (damager.getType() == EntityType.ENDER_DRAGON) {
  45.                                    LivingEntity victim = (LivingEntity) event.getEntity();    //定义victim对象为被攻击者
  46.                         victim.addPotionEffect(new PotionEffect(PotionEffectType.CONFUSION, nauseatime, 1));
  47.                         //增加药水效果
  48.                            }
  49.                 }
  50.         }
  51.     getServer().getPluginManager().registerEvents(new DamageEventListener(), this);  //注册更改末影龙伤害的监听器
  52.         /*
  53.          * 下面是根据配置文件决定是否开启反胃效果
  54.          */
  55.     if (nausea == true){
  56.             getServer().getPluginManager().registerEvents(new Nausea(), this);
  57.         }
  58.     getLogger().info("插件载入正常.");
  59.         }
  60.         @Override
  61.         public void onDisable(){
  62.             getLogger().info("插件已被卸载.");
  63.         }
  64. }
