标题: 新的附件格式上传权限已分配完毕
这三个新格式分别为txt、jar、schematic。
  • txt即最简单是文本文档，是之前的缺失。
  • jar文件大家都很熟悉，服务器插件等小应用基本是jar格式的，为了方便辛勤的搬运工，
便于大家上传些小的插件，特开放此类附件上传权限。
  • schematic格式附件，
这个也许大家都会有些陌生，下面有一则介绍:
Schematic文件格式为一种由玩家社区所创建的用于存储Minecraft世界信息，进而可以通过第三方应用程序（如MCEdit, MinecraftNote Block Studio,红石模拟器以及WorldEdit等）进行编辑。方块和数据的目录以YZX的排序存储，也就是说X坐标的变化最频繁。这与Classic，Indev以及Anvil文件格式中的方块排序相似。
详见：
Schematic文件格式（Schematic File format）    by djxgame
http://www.mcbbs.net/thread-66047-1-1.html


  • LV1~LV12用户组及全体管理人员都有权使用上述三种新附件
  • 最大尺寸(单位：KB)        txt:200;jar:2048;schematic:500
