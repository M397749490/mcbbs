本插件是一个轻轻轻轻轻量级插件

总共命令就两条，嗯对，两条

插件功能：




权限                             指令

默认OP/sb set 玩家ID 加入消息给该玩家设置一个加入消息
默认OP/sb remove 玩家ID删除该玩家的加入消息

本插件适用于经济类服务器

例如可以让肝帝们花费金币来设置一条加入消息2333
支持颜色代码！！！！！！
这样一来又多了一种消耗肝帝金币的方法

config
  1. #玩家ID
  2. weiai_qiannian:
  3. #加入消息的内容
  4.   Mes: §4唯爱千年
  5. #配置简单易懂23333，可以从配置文件设置也能用指令
  6. #指令可以配合菜单（懒人必备）
