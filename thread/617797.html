                                                              EarthQuak              [fly]地震[/fly]

             什么意思呢？
    游戏开始时,被预判为地震的受害者会有失明,缓慢,还有一个稻草
   稻草等待20秒CD可以右键,给受害者光明和加速一点点时间
  而受害者需要打一下其他玩家,这样把自己的受害者身份转移给他
而游戏赢家怎么算呢？ 根据游戏时间内,没有被转移最多的玩家视为赢家


                  
                             作者名字: shades161


                               命令&权限
/eq help [页数]/eq help 1~4查看所有命令Earthquake.use.command
/eq join <游戏ID>/eq join 1加入某游戏Earthquake.use.command
/eq quit/eq quit退出加入中的游戏Earthquake.use.command
/eq info <游戏ID>/eq info 1查看“1”游戏信息
Earthquake.use.command
/eq start <游戏ID>/eq start 1直接强制开启游戏“1”Earthquake.admin
/eq stop <游戏ID>/eq stop 1强制关闭游戏“1”Earthquake.admin
/eq createarena or /eq create/eq createarena创建游戏(/eq create <游戏id>)不填默认为“1”Earthquake.admin
/eq set <游戏ID> <管理/属性> (变量)/eq set 1 minPlayers 4设置游戏“1”的属性Earthquake.admin
/eq arenatool/eq arenatool输入这个后,用木棍像创世神一样设置pos1~2点ok
Earthquake.admin

变量
例子信息
minPlayersInteger(Number)/eq set 1 minplayers 4设置最小能开始游戏的人数
maxPlayersInteger(Number)/eq set 1 maxplayers 10设置最大上限的游戏人数
timerInteger(Number)/eq set 1 timer 12设置游戏的时间长度
startDelayInteger(Number)/eq set 1 startdelay 10设置游戏准备开始等待的时间
waitDelayInteger(Number)/eq set 1 waitdelay 30设置游戏等待的时间
displayNameString(No spaces)/eq set 1 displayname &5Arena_1给游戏“1”设置个有颜色的名字
enabledboolean(True/False)/eq set 1 enabled true全部基础的都弄好,输入这个即可开始游戏
endPositionLocation(where you are standing)/eq set 1 endposition设置游戏结束后回到点
quitPositionLocation(where you are standing)/eq set 1 quitposition设置游戏退出回到的点
lobbyPositionLocation(where you are standing)/eq set 1 lobbyposition设置游戏大厅
PlayerSpawnLocation(where you are standing)/eq set 1 playerspawn设置玩家出生点
ItSpawnLocation(where you are standing)/eq set 1 itspawn设置受害者的出生点
RegenArea2 Locations(Set with arenatool)/eq set 1 regenareapos1~pos2点弄完后,输入这个




                                                         怎么设置游戏？？l
               1.先输入/eq create [游戏名字]
            2./eq arenatool 开启圈地模式
            3.拿起背包的木棍,选择pos1-2点(创世神一样)
            4.输入/eq set [游戏名字] regenarea 保存两点
5.输入/eq set [游戏名字] minplayers/maxplayers <人数> （设置最小开始人数/最大上限人数）
6.分别输入/eq set [游戏名字] playerspawn[设置玩家出生点]
          /eq set [游戏名字] itspawn[设置“it受害者”出生点]
7.分别输入/eq set [游戏名字] endposition[结束游戏后的点]
         /eq set [游戏名字] quitposition[退出游戏后的点]
           /eq set [游戏名字] lobbyposition[大厅]
8.输入/eq set [游戏名字] enabled true
9.给玩家权限,然后清空背包,输入/eq join [游戏名字] bingo~
