我的世界为什么把玩家添加到另一个权限组里没有地皮使用权限
作者: 黙殇    时间: 2019-8-18 18:37
本帖最后由 黙殇 于 2019-8-19 22:20 编辑

继承权限组即可
方法：打开 /plugins/GroupManager/worlds/world/groups.yml 进行修改

新的权限组:
    default: false
    permissions:
    inheritance:
    - default
    - builder
    info:
      build: true
      prefix: ''
      suffix: ''


注意加粗斜部分 意思为新的权限组将继承builder组和default的权限
也就是这两个组原有的权限这个新的权限组都有
