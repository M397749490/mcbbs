配置文件：

这次配置文件多了些东西:

  1. #A_Config_Of_BlockHeals
  2. #Mon Jul 31 21:30:50 CST 2017
  3. Heal_per_Destroying=1
  4. Damage_per_Destroying=8
  5. ENABLED=AT
复制代码
这是我的配置文件，他的路径依然是服务器根目录/plugins/config/BlockHeals.cfg

下面我将对其进行一一讲解：

前两行是说明内容，不用管。

第3行是一次破坏所恢复的生命值，同样的，支持小数。

第4行是一次破坏所造成的伤害，支持小数。

最后一行是模式：T是启动插件恢复功能,AT是启动插件造成伤害功能,F是关闭插件。在修改文件后记得/reload或者重新启动服务端。

下次更新：

1、针对不同方块进行不同的生命恢复或造成伤害（可以自定义）。

2、可以调整每次破坏方快造成的伤害或生命（可以自定义）。

3、可以选择在哪些区域对玩家的破坏造成伤害或生命恢复（像使用领地插件那样）。

4、我绝对不跳票了（再跳我...苟...）

应用：

1、某些末日生存服务器（这样虐玩家会不会打我qwq）

2、小游戏服务器。

.....看了下你插件源代码
建议你先仔细学下再码插件......
Bukkit提供了YamlConfiguration类用于读写配置文件,你这写的蛋疼的.......你可以看看我的是怎么写的
https://github.com/Ldcr993519867/BedwarsXP/blob/master/src/ldcr/BedwarsXP/Config.java
关键代码如下
初始化配置文件
  1. File file = new File("plugins/BedwarsXP/config.yml");
  2.                 if (!file.exists()) {
  3.                         ldcr.BedwarsXP.Main.sendConsoleMessage("§6§l[BedwarsXP] &b配置文件不存在,正在创建...");
  4.                         ldcr.BedwarsXP.Main.plugin.saveResource("config.yml", true);
  5.                 }
复制代码
加载配置文件
  1. YamlConfiguration config = YamlConfiguration.loadConfiguration(file);
复制代码
读数据
  1. int xp = config.getInt("XP." + key, 0);
复制代码

你的写法效率相当低下,每次读取数据都要加载一次配置文件,在玩家多时会造成频繁读写硬盘
正常的写法应该是在插件加载时就完成加载工作,需要读取数据时直接调用加载时创建的YamlConfiguration获取数据
另外,你还应该看看java命名规范,什么时候应该大写什么时候应该小写,你这代码完全没有按规范命名
