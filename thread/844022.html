大概思路：
每个tick判断一下粒子行驶总距离是否大于两点之间的总距离，如果大于则删除该粒子。

首先，你得知道目前玩家(playerPos)的位置和目标Entity的位置(targetPos)，然后求出单位向量，就是从playerPos到entityPos的单位向量。
大致这么求：
  1. private static double[] getUnitSpeed(double fromX, double fromY, double fromZ, double toX, double toY, double toZ, double speed) {
  2.                 double distance = MathHelper.distance(fromX, fromY, fromZ, toX, toY, toZ);
  3.                
  4.                 double unitX = (toX - fromX) / distance;
  5.                 double unitY = (toY - fromY) / distance;
  6.                 double unitZ = (toZ - fromZ) / distance;
  7.                
  8.                 return new double[] {unitX * speed, unitY * speed, unitZ * speed};
  9.         }

额缩紧好像乱了...
然后你粒子在x，y，z轴的速度就是这个单位向量的x，y，和z。

接着（重要）！在constructor里务必保存一下该粒子从playerPos到targetPos的总距离及最开始的playerPos，以便之后使用。

接着（更重要）！重载Particle#renderParticle，并判断一下目前粒子离最开始playerPos的距离是否大于总距离，如果是的话则调用Particle#setExpired(true)来删除粒子。

楼主可以把链接里的代码稍微改一下，然后调用的时候把fromX, fromY, fromZ改成玩家当前的位置，并把toX, toY, toZ改成生物当前的位置就行了。
