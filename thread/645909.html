场地设置的指令:

  • /arena create <arenaname> - 创造新场地
  • /arena remove <arenaname> - 移除一个场地
  • /arena setlobbyspawn <arenaname> - 设置游戏等待大厅
  • /arena setspsectatorsspawn <arenaname> - 设置死亡玩家观战点
  • /arena setmainlobby <arenaname> - 设置主大厅
  • /arena setminteams <arenaname> <value> - 设置一个场地中一个队伍的最小人数
  • /arena setmaxteams <arenaname> <value> - 同上,这是最大人数
  • /arena setteamsize <arenaname> <value> - 设置队伍人数上限
  • /arena addspawn <arenaname> - 添加出生点
  • /arena addchest <arenaname> <defaultChestType> <refillChestType> - 设置添加到游戏里的箱子,在箱子前输入
  • /arena removechest <arenaname> - 移除箱子
  • /arena join <arenaname> - 加入比赛
  • /arena leave - 离开比赛
  • /arena list - 显示一场比赛中的人数
  • /arena forcestart <arenaname> - 强制开始一场比赛

  • 添加玩家出生点 /arena addspawn <arenaname>
