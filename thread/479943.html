世界名称 /mvm set alias 中文名称
世界名称颜色 /mvm set color (颜色)

颜色必须要用英文输入这样：（看不懂是什么颜色用百度翻译）
  1. AQUA, BLACK, BLUE, DARKAQUA, DARKBLUE, DARKGRAY, DARKGREEN, DARKPURPLE, DARKRED, GOLD, GRAY, GREEN, LIGHTPURPLE, RED, YELLOW, WHITE
