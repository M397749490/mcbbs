AdvanceParticle是什么插件？
【 它是一款能够在玩家身上或方块上添加粒子效果的一款小插件 】

  • 支持Craftbukkit版本(1.5.x、1.6.x、1.7.x、1.8.x、1.9.x、1.10.x、1.11.x、1.12.x、1.13.x、1.14.x)
  • 支持Spigot版本(1.5.x、1.6.x、1.7.x、1.8.x、1.9.x、1.10.x、1.11.x、1.12.x、1.13.x、1.14.x)
  • 支持PaperSpigot版本(1.8.x、1.9.x、1.10.x、1.11.x、1.12.x、1.13.x、1.14.x)
  • 在方块上设置粒子效果
  • 在玩家上设置粒子效果
  • 可在config.yml中启用或关闭
  • 可在message.yml中汉化相应内容
  • 可在列表中找到已有的粒子效果
  • 可找到存在粒子效果的方块点
  • 利用权限系统来限制玩家是否能够使用相应的粒子效果
  • 未来计划
  • 添加新的粒子效果
  • 修复插件Bug

  • 其他权限
  • advanceparticle.reload - 允许使用 /ap reload
  • advanceparticle.particle - 允许使用 /ap particle
  • advanceparticle.spawner - 允许使用 /ap spawner
  • advanceparticle.delete - 允许使用 /ap delete <名称>



  • /ap 或 /advanceparticle - 主命令
  • /ap reload - 重启插件
  • /ap particle - 查看粒子效果列表
  • /ap spawner - 查看所有的粒子点名称
  • /ap remove - 移除身上的粒子效果
  • /ap add <粒子效果> - 为自身设置一个粒子效果!
  • /ap set <名称> <粒子效果> - 为脚下的方块设置一个粒子效果
  • /ap setlooking <名称> <粒子效果> - 为你正在朝向的方块设置一个粒子效果
  • /ap delete <名称> - 移除一个粒子点
