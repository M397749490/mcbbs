插件命令：


  1. /wa password <密码> - 在此设置你在webportal的密码
  2. /wa mailbox - 打开虚拟物品空间
  3. /wa reload - 重新载入
  4. /wa save - 保存
  5. /wa view <玩家ID> - 查看某个玩家
  6. /wa set <玩家ID> <权限(buy,sell,admin)> <yes> - 反正也就你用得上
  7. /wa help - 帮助
复制代码
使用方法：


1，在游戏中输入命令/wa password <密码>
先注册一个不同于登录游戏的密码，这个密码完全是为了登录网站用的。
2，输入命令/wa mailbox
3，在弹出的箱子中，把物品放进去。
4，登录你的网站，在设置选项下的物品里。出售你的物品。
同样，输入/wa mailbox 打开箱子可以取出你购买的物品。
