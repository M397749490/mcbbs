插件の简介


Features — 功能








  • arenas支持Solo(单人)或Teams(团队)模式。团队可以设置想要的队伍玩家数量。您可以与大型团队一起创建Mega模式游戏。
  • 100％可配置，自定义设置的消息，arenas(场地)，商店，商店物品价格，升级选单。
  • 创建无限的arenas(场地)。
  • 可以与其他迷你游戏插件一起设置。
  • 支持一个世界的多个arenas(场地)。
  • 胜利烟花。
  • 死亡观众，可以传送给其他玩家讯息。
  • 支持BungeeMode强制玩家加入游戏。
  • 支持MySQL在服务器之间共享玩家统计信息。
  • 内置coins和souls(不知道)系统，需要用到vault。
  • 100％可配置的村民商店。
  • Lightweight rollback system。
  • VIP的coins倍乘。
  • 主大厅和游戏中可以使用记分板。
  • 支持UUID。
  • 玩家统计：wins. kills, deaths, blocks breaked, blockes places, projectiles launched and projectiles hit, beds breaked。
  • 自动加入命令和告示牌，可以随机加入。配置自动加入告示牌可以选择单人或团队。
  • 显示arenas(场地)状态和玩家数量状态。（自定义）
  • 用弓箭击中玩家可以显示玩家血量。
  • 自定义物品，例如火球。
  • 钻石和绿宝石生成的全息图。
  • 显示时间的全息图直到下一个物品产生。
  • 床全息图.
  • 在玩家杀了敌人或获胜会执行奖励命令。
  • 公告系统中，可以设置显示自订义提示和技巧或宣传网站。
  • 创建统计数据全息图，并以x分钟的时间去更新它们。
  • 根据您选择的统计资料，设置告示牌排行榜，显示排行榜玩家，还可以将玩家头颅放在告示牌上，以显示玩家。
  • 支持PlaceHolderAPI，可以在任何兼容的插件上显示Pro Bedwars统计信息。
  • 游戏命令白名单。
  • 创建派对命令(/party)并与您的朋友一起玩。
  • 加入告示牌后的玻璃根据游戏状态改变颜色。
  • 可配置村民商店里内容和价格。
  • 蹦极模式随机arenas(场地)。你可以有一个以上的arenas(场地)在你的蹦极服务器和每场比赛将有一个不同的竞技场。
  • 支持文档的数据库:MongoDB。
  • 惊人的团队升级系统，可以与钻石一起使用。(不太清楚)





Setup — 游戏设置 — MultiArena 服务端



  • 购买并下载 ProBedWars.jar 到服务器资料夹下的plugin
  • 启动服务器
  • 创建一个新的arenas(场地) - 用法:/bwarena create <arenaname>
  • 设置队伍最大玩家个数 - 用法:/bwarena setmaxteams <arenaname> <value>.
  • 设置队伍最小玩家个数 - 用法:/bwarena setminteams <arenaname> <value>
  • 创建队伍 - 用法:/bwarena createteam <arenaname> <teamname>
  • 设置队伍出生点 - 用法:/bwarena addspawn <arenaName> <teamname>
  • 设置队伍的床(站在床上指针朝床) - 用法:/bwarena setbedspawn <arenaName> <teamname>
  • 设置队伍重生点 - 用法:/bwarena setrespawn <arenaname> <teamname>
  • 设置队伍产卵点(铁锭与黄金) - 用法:/bwarena setitemsspawn <arenaname> <teamname>
  • 设置队伍村民商店点 - 用法:/bwarena setvillager <arenaname> <teamname>
  • 设置队伍升级商店点 - 用法:/bwarena setvillagerupgrade <arenaname> <teamname>
  • 重复 步骤6-12 直到完成你所有的队伍
  • 设置钻石生成点 - 用法:/bwarena adddiamondgenerator <arenaName>
  • 设置绿宝石生成点 - 用法:/bwarena addemeraldgenerator <arenaName>
  • 设置大厅出生点(加入游戏的点) - 用法:/bwarena setlobbyspawn <arenaname>
  • 设置旁观者出生点 - 用法:/bwarena setspectatorsspawn <arenaname>
  • 设置主大厅出生点(退出或结束游戏的点) - 用法:/bwarena setmainlobby <arenaname>
  • 设置队伍数量 - 用法:/bwarena setteamsize <arenaname> <value> (如果要Solo单人模式，后面的value请设置1)
  • 取得选取游戏arenas(场地)区域的工具 - 用法:/bwarena wand 再来选取你想要的游戏arenas(场地)区域(像领地一样)
  • 储存arenas(场地) - 用法:/bwarena save <arenaname>
  • 完成!

場地 設置 命令


  • /bwarena wand - 使用工具来选取场地区域
  • /bwarena create <arenaname> - 创建新的场地
  • /bwarena createteam <arenaName> <teamName> - 在场地内创立新的队伍
  • /bwarena remove <arenaname> - 删除场地
  • /bwarena setlobbyspawn <arenaname> - 设定场地大厅出生点
  • /bwarena setspectatorsspawn <arenaname> - 设定玩家死亡后出生的地方
  • /bwarena setmainlobby <arenaname> - 设定玩家结束或离开后传送到大厅的地方
  • /bwarena setminteams <arenaname> <value> -设定最少需到达多少队伍才可以开始游戏
  • /bwarena setmaxteams <arenaname> <value> - 设置场地最多玩家的数量
  • /bwarena setteamsize <arenaname> <value> - 设置队伍玩家数量
  • /bwarena addspawn <arenaname> <teamName> - 设置队伍的玩家出生点
  • /bwarena setbedspawn <arenaName> <teamName> - 设置队伍的床
  • /bwarena savebed <arenaName> <teamName> - 保存所放置的床为队伍的床 (需包括方向) (需要面向床头)(不清楚)
  • /bwarena setrespawn <arenaName> <teamName> - 设置队伍玩家重生点
  • /bwarena setitemsspawn <arenaName> <teamName> - 添加队伍产卵点
  • /bwarena setvillager <arenaName> <teamName> - 设置队伍村民商店
  • /bwarena setvillagerupgrade <arenaName> <teamName> - 设置队伍升级商店
  • /bwarena adddiamondgenerator <arenaName> - 添加钻石产卵点在脚下 (动态与全息图将在游戏开始后产生)
  • /bwarena addemeraldgenerator <arenaName> - 添加绿宝石产卵点在脚下 (动态与全息图将在游戏开始后产生)(作者好像把后面的emerald打成diamond了)
  • /bwarena save <arenaName> - 保存场地到 arenas.yml
  • /bwarena list - 显示所有场地
  • /bwarena forcestart <arenaname> - 减少倒数时间并且强制开始游戏
