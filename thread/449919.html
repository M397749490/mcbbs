ESS配置文件打开按提示配置

  1. # 是否开启安全传送功能
  2. # 如果此项设置为true, 则会尝试传送玩家到最近的安全地点
  3. # 如果设置为false, 将会取消传送并发送一则警告消息
  4. teleport-safety: true

  6. # 传送功能的冷却时间(以秒为单位),如/home, /tp等命令.
  7. teleport-cooldown: 10

  9. # 传送延迟时间(以秒为单位),在玩家被确实传送之前的时间.如果玩家在该时间内移动了或者受到攻击,传送将取消.
  10. teleport-delay: 0

  12. # 传送时无敌时间(以秒为单位)在玩家被确实传送之前的时间内,其他玩家不能攻击该玩家.
  13. # 这同样可以阻止该玩家攻击其他玩家.
  14. teleport-invulnerability: 4
