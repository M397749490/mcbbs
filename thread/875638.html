不会。只有原版的那几个声音事件会自动播放。想要自动播放的话你可以把你的音乐文件名加到原版声音事件的下面。

未响应是因为音乐文件太大了，你需要在 sounds.json 里面对应位置加上
  1. "stream": true
复制代码
以开启流式读取，就不会未响应了。
具体结构见 Wiki

如果你只想让自己的音乐自动播放，这辈子也不想再听到一次原版音乐，可以加一句 "replace": true。例如
  1. {
  2.     "music.game": {
  3.         "replace": true,
  4.         "sounds": [
  5.             {
