插件命令

/vip reload
/vip getversion
/vip add <player> [period]
/vip remove <player>
/vip list
/vip remaining [player]
/vip generatecode
/vip removecode
/vip listcode
/vip code <VIP-code>
一般大家用到的是这三个命令

/vip add (玩家ID) (期限 单位为天) 为制定玩家添加VIP
/vip remove (玩家ID) 移除指定玩家的VIP
/vip list 查看VIP列表
