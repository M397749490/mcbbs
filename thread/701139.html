  伪装成你想要变成的样子吧<带GUI>
  所有生物都有其不同的能力，包括飞行，爬墙，火球等等
  灵感来源于变形MOD，你可以变形成你已经杀死过的生物/玩家
  你可以选择通过掠杀玩家来夺取他的变身能力<这些都是可配置的>





  /morph help: 列出插件帮助列表 - morph.morph
  /morph <mob>: 变形成指定生物 - morph.morph
  /morph toggle: 开启/关闭 玩家的变形能力 - morph.toggle
  /morph view [true/false]: 是否能看见变形状态 - morph.view
  /unmorph <all: player>: 变回玩家形态 - morph.morph
  /morph status: 显示你变形成了什么生物 - morph.morph
  /morph near: 显示附近是否隐藏着变形后的玩家 - morph.morph
  /addmorph <player> <mob>: 为玩家添加变形成这种生物的能力 - morph.morph.modify
  /delmorph <player> <mob>: 删除玩家变形成这种生物的能力 - morph.morph.modify


  - morph.morph - 使用 /morph command 的权限
  - morph.* - 使用全部指令的权限
  - morph.changeview - 使用 /morph view 的权限
  - morph.toggle - 使用 /morph toggle 的权限
  - morph.view - 使用 /morph view 的权限
  - morph.into.* - 赋予玩家变身为所有玩家的能力
  - morph.into.<mob> - 给玩家变形成<mob>的权限
  - morph.bypasskill.<mob> - 给玩家不用杀<mob>，就可以变形成<mob>的权限
  - morph.bypasskill.* 给玩家不用杀任何生物就可以变形成他们的权限
