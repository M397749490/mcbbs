CustomSpawnersEco






What is CustomSpawnersEco?

CustomSpawnersEco is an addition to the CustomSpawners plugin. It allows you to buy, sell, and trade CustomSpawners spawner blocks. This lets everyone on a server utilize the full functionality of CustomSpawners.
Prerequisites

CustomSpawners requires that you have the following plugins also installed:
  • CustomSpawners v0.2.1 or later.
  • Vault
Downloads

You can download CustomSpawnersEco from the download button above.
Current Version: 0.1 BETA
CustomSpawnersEco is also on Github! Find it here:https:github.com/thebiologist13/CustomSpawnersEco
Wiki and Usage

After you download CustomSpawnersEco, place it in your plugins folder and make sure no other versions of CustomSpawnersEco are in there too. Then, start up your server with CustomSpawners and Vault too. You can then start using the plugin.
The basic commands for CustomSpawnersEco are the /cseco buy, /cseco sell, and /cseco setworth commands though.

The "/cseco buy [id]" command allows you to buy a CustomSpawner. It uses the same selection system as CustomSpawners. It gives a block of the spawner you specify, but charges you the specified amount by "/cseco worth [id]". You can also sell a spawner you have in hand with "/cseco sell". Those with permission may also use the "/cseco setworth [id]". This sets how much a spawner block is worth. The amount a spawner is worth must be set before users can buy it.
Additional information on the commands, permissions, and usage for CustomSpawnersEco can be found on the Wiki.
