前言
最近想让游戏难度提升一下，又不想破坏游戏平衡，加上根本没时间学java，所以我就看上了这个【MobProperties】这个mod，并且花了一些时间去研究他的语法，格式，我也是醉了，完全就是一个json脚本。不过要可惜的是这个mod只可以修改怪物属性，和某种情况下物品属性。最主要是可以联机使用，服务器一开启就能自动载入，节省了不少时间。


安装
成功安装该mod后会生这3个文件。
【MobProperties】是放怪物当前mc所使用的怪物的名称（包括mod）
【MobProperties.json】提供你自由的编辑不限制于MobProperties目录里的文件。
【MobProperties.cfg】auto_generate_files=true，为当前使用的怪物生成一个空的属性文件，放在MobProperties目录，false直接使MobProperties.json，而不会用MobProperties目录里文件的设置。


关于
所有的怪物属性都是这样的格式。
{
   "_name": "",
   "drops": [],
   "stats": []
}
_name：怪物的名字
drops：怪物死亡时候
stats：怪物生成时候

要注意每个语句后面要加逗号来分割

函数的书写方式，例如：
{
    "_name": "Zombie",
    "drops": [
         {
               "function": "函数名",
               "属性": 数值,
               .................
         },
         ..................

    ],
    "stats": [
         {
               "function": "函数名",
               "属性": 数值,
               .................
         },
        .................

    ]
}


常规函数

函数参考Toast Wiki http://fathertoast.wikia.com/wiki/Mob_Properties

choose                                       类似与select和但与select又有不同。

                                                  *functions：里面填写要执行的操作。
                                                   weight：通过这个数值可以让choose选择那个语句最有可能会执行。
                                                  例如：
                                                  "function": "choose",
                                                  "functions": [
                                                         {
                                                                  "weight": 1,   
                                                                  "function": "函数1"
                                                         },
                                                         {
                                                                  "weight": 1,        
                                                                   "function": "函数2"
                                                         },
                                                         {
                                                                  "weight": 2,                        //这个函数执行几率要比另外两个大        
                                                                   "function": "函数3"
                                                         }

all                                               指定几率执行。
                                                  count：执行几率。例如：0.15，15%。默认1，100%。
                                                  *functions：里面填写要执行的操作。
                                                   例如：
                                                   "function": "all",
                                                    "count": 0.3,
                                                    "functions": [
                                                          {
                                                                  "function": "函数",                //30%几率会执行该函数
                                                                  ..................................
                                                          }
                                                   
                                            
if_burning                                 如果正在燃烧。
if_wet                                        如果正在水中，包括下雪。
if_wither_skeleton                    如果是凋零骷髅。
if_has_potion_X                        如果物带有X药水效果，X为药水效果ID。
if_check_nbt_X                         如果怪物nbt格式中某一项数据类型为X的数据，可以用操作符进行操作运算。
if_beyond_X                              自己翻译。。
if_raining                                  如果是在下雨天。
if_thundering                            如果在打雷。
if_moon_phase_X                     如果月亮位置在X（full，waning_gibbous，third_quarte，waning_crescent，
                                                  new，waxing_crescent，first_quarter，waxing_gibbous）。
if_past_day_time_X                  如果时间的值大于X（0~23999)。
if_past_world_time_X              如果存在这个世界的时间大于X。
if_past_world_difficulty_X       如果安装了末日mod的话当前世界的难度是X（peaceful，easy，normal，hard）。
if_difficulty_X                           如果当前世界难度是X。
if_in_dimension_X                    如果在范围X。
if_in_biome_X                           如果在生物群X。
if_on_block_X                           如果在方块X。
if_below_X                                如果在方块的高度X。
if_player_online_X                    如果玩家X在线。
（以下函数只能用在drops里面）
if_recently_hit                            如果某个玩家在过去5秒打过这个怪物。
if_rare                                         如果这个掉落是稀有掉落？(1%-40%几率)。
if_rare_super                              如果这个掉落是超级掉落？（1%-5%几率）。
if_above_looting_X                     如果这个怪物被附魔有“掠夺”等级X的东西击中。
if_killed_by_X                             如果这个怪物被X杀死（X是一个实体ID）。


状态函数

name                                          为这个怪物设定一个名称。
                                                  *value：自定义一个名称给这个怪物。

modifier                                    修改怪物指定属性
                                                  *attribute：属性的字符串。参考：http://minecraft.gamepedia.com/Attribute，
                                                  常用：
                                                  generic.maxHealth（最大生命值），
                                                  generic.followRange（跟随范围）
                                                  generic.knockbackResistance（抵抗击退效果几率）
                                                  generic.movementSpeed（移动速度）
                                                  generic.attackDamage（攻击力）
                                                  value: 一个整数范围的数值去修改这个属性。
                                                  operator: 修正操作，0：基础+value，1：基础*value，2：基础=基础*(1 + value)
                                                  override：覆巢操作，为true时operator无效，直接会覆盖怪物基本数值
                                                  直接用value的数值，默认为false。

equip                                         装备指定装备到一个怪物身上。
                                                  *id：装备的ID，可以是字符串。
                                                  slot：部位（0 - 手，1 - 脚，2 - 腿部，3 - 身体，4 - 头部）。默认0。
                                                  dop_chance：改装备掉落的几率，默认是0.085。
                                                  damage：这里不知道是翻译成耐久还是攻击力，请自行测试，默认是0。
                                                  count：装备的数量，默认为1。
                                                  item_stats：这个参数可以对改装备作更多的操作。后面会给例子。

potion                                        赋予药水效果。
                                                  *id：药水效果的ID。
                                                  amplifier：药水级别。默认0(1 level)。
                                                  duration：持续时间，默认2147483647，20 ticks=1 second。
                                                  ambient：药水效果显示，默认false。
                                                  override：覆盖操作，是否覆盖本身自带的药水效果，默认false。

riding                                        让改怪物骑指定怪物头上。
                                                *id：被骑的怪物的ID。
                                                 stats: 这个参数可以修改被骑的怪物更多的属性。后面会给例子。

ridden_by                                与上面一样，只不过颠倒，ID是被哪个怪物骑。

nbt                                           直接操作nbt格式数值。
                                                http://minecraft-zh.gamepedia.com/%E5%8C%BA%E5%9D%97%E6%A0%BC%E5%BC%8F
                                                *tags：在里面可以做更多的操作，后面会给例子。

drops                                        这函数可以在怪物生成是就设定掉落物，可以写在stats里面。
                                                *functions：这个参数里面可以写对掉落物更多的操作。
                                                 count：掉落几率。默认1。

enchant                                   可以给指定装备附魔。
                                                id：附魔效果ID，默认随机-1。
                                                level：附魔效果级别。默认1。

spawn                                      生成指定怪物。                                       
                                               *id：怪物ID。
                                                count：生成怪物数量。默认不写。
                                                tags：可以做根据nbt格式更多操作，后面给例子。
                                                stats：可以在里面写更多怪物的操作。
