介绍：
本插件是一款基于Economy经济API的圈地插件，十分强大。

使用：
将前置插件与本插件一起扔到服务端plugins文件夹里，重新启动服务器即可。


命令：

命令
用途
land pos1 设置第一个点
land pos2 设置第二个点
land buy 圈地
land sell 出售领地
land give 赠送领地
land here 查询此处领地
land whose 查询TA的领地
land list 查看自己领地列表
land invite 共享领地
land kick 取消共享（大概）
land invitee 查看领地共享者（大概）
land option 领地 选择（大概）
land options 领地 查看选择（？？？）

配置：
config.yml
  1. <font face="微软雅黑"><span style="background-color: white;"># 这里设置语言 半汉化是jpn(eng, kor, jpn)
  2. language: jpn
  3. # 这里设置一个人最多多少块地 NaN无限
  4. max-land: NaN
  5. query-min-length: 3
  6. # 这里设置一个方块多少钱
  7. price:
  8.   per-block: 100
  9. # 白名单世界可以让玩家在不买地之前不能修改方块
  10. white-world-protection: [sc]

  12. # 显示如果玩家试图修改白名单世界
  13. show-white-world-message: true

  15. # 禁止购买的世界
  16. buy-forbidden: [zc]

  18. # 防止液体流动（貌似是）
  19. block-flowing: true

  21. auto-save: 300</span></font>
