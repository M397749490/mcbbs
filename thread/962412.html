这个插件有什么用？
  • 它可以提高生存模式和（可使用合成台的）小游戏（如吃鸡和空岛战争）的游戏体验
  • 它可以创建自定义的方块，方块包括贴图、物品显示（背包中的）、可执行命令、合成、熔炉配方、酿造配方
  • 结合快速合成和拆解功能模块，并且可以处理自定义物品
  • 你也可以删除原版合成，创建自定义食物，工具和武器，并附加一些额外效果，比如可以破坏基岩的镐子，可以在你挖矿时自动熔炼矿石（和熔炉一样）的镐，礼品箱（类似于战利品模组）等等，查看下面的功能，阅读“教程”中的一些图片，然后你就会发现这其实挺简单的。
它对写新插件有什么用处？

例子
  1. # 在此处添加命令的标签（命令为 /command）
  2. <command>:
  3. # 命令所需的参数数量（-1是无限量）
  4. arguments: <number>
  5. # 命令的描述
  6. description: <description>
  7. # 用法错误时发送给用户的用法用法
  8. usage: <usage>
  9. # 执行命令的权限
  10. permission: <permission>
  11. # 这个命令的别名
  12. aliases:
  13. - <aliase 1>
  14. - <aliase 2>
  15. [...]
  16. # 使用命令时会被执行的命令
  17. # 对服务器端命令使用"server:<command>"
  18. # 参数的占位符是“ {x}”，其中x是从0开始的参数编号（“ {-1}”用于放置所有参数）。对于参数0，占位符为{0}，对于参数1，占位符为{1}，
  19.   以此类推...
  20. # "{sender.name}" 是执行命令的玩家的占位符
  21. commands:
  22. - <command 1>
  23. - <command 2>

创建物品
物品存储在名为item_packs的文件夹中。 首先让我们创建一个包来存储自定义物品。在该文件夹中创建一个名为myitems.yml的文件。  
现在，我们将创建一个物品。打开文件并键入以下内容：
  1. # 这是物品ID, 确保它是独一无二的（不重复）.
  2. MyBigStone:
  3.    # 该物品的材料（材料查看上方材料表）
  4.     material: STONE
  5.     # 这个物品损坏（耐久度为0）了吗？在这种情况下并不是！
  6.      damage: 0
  7.     # 看！一个附魔的石头
  8.     # 用法: 附魔名称（查看上面附魔表）:等级
  9.     enchantments:
  10.      - DAMAGE_ALL:2
  11.     # 物品的名称 (但是不是镐 -- 2333)
  12.     name: '&6镐子'
  13.     # 这个镐子的lore -- 其实是石头
  14.     lore:
  15.    - '&r这个镐子可以破坏基岩. 没错. (雾)'

创建高级物品

上一章：
创建物品

该插件带有一些额外的方法，可改善服务器游戏体验。让我们看看你能做什么。
打开您的物品包（见前文）并黏贴以下内容：
  1. #确定这个ID（SpecialLeatherItem）是独一无二的
  2. SpecialLeatherItem:
  3.     material: LEATHER_CHESTPLATE
  4.     damage: 0
  5.     enchantments:
  6.     - PROTECTION_PROJECTILE:10
  7.     - DURABILITY:2
  8.     name: '&6不可思议的皮革胸甲'
  9.     lore:
  10.    - '&r无论如果，这并没有那么好'
  11.     # 你可以使用RGB颜色码来给皮革染色
  12.     # 每种颜色的范围0 - 255.
  13.     dye:
  14.       red: 100
  15.       green: 100
  16.       blue: 100
  17.     # 头颅可以展示主人（owner）的皮肤
  18.     # 如果材料（material）不是PLAYR_HEAD且耐久度（damage）为3，这个功能将无效
  19.     skull:
  20.       owner: You
  21.     # 这里是设置 NBT 标签的部分
  22.     # 用法: 标签1,标签2,标签3,...
  23.     # 别输入空格
  24.     # 除了空标签，每一个标签都有一个种类和数值
  25.     # 用法 type(种类):value (数值)  (除了空标签null)
  26.     # null是用来创建一个新的列表.
  27.     # 在下面的例子中，第一条nbt使物品不可损坏
  28.     # 另外一条给物品增加20伤害
  29.     nbt:
  30.    - Byte:1,String:Unbreakable
  31.     - String:generic.attackDamage,String:AttributeModifiers,null,String:AttributeName
  32.     - String:generic.attackDamage,String:AttributeModifiers,Integer:0,String:Name
  33.     - String:mainhand,String:AttributeModifiers,Integer:0,String:Slot
  34.     - Double:20,String:AttributeModifiers,Integer:0,String:Amount
  35.     - Integer:0,String:AttributeModifiers,Integer:0,String:Operation
  36.     - Long:894654,String:AttributeModifiers,Integer:0,String:UUIDLeast
  37.     - Long:2872,String:AttributeModifiers,Integer:0,String:UUIDMost
  38.     # 这是物品最重要且最灵活的部分——额外数据值(The extra data values)，但是你需要支持它的插件或者自己写一个.
  39.     # 在此示例中，我们将使用以下信息:
  40.     # specialeffect.name: EXPLODE   特殊效果名:爆炸
  41.     # specialeffect.radius: 5                  特殊效果半径:5
  42.     # 使用插件，你可以从自定义物品中得到这些数据标签来执行额外的效果。
  43.     # 为什么我给你看这个？因为本插件也使用这种标签
  44.     data:
  45.       specialeffect:
  46.         name: EXPLODE
  47.         radius: 5

创建具有自定义材质的方块
上一章：
创建高级物品

感谢LapisDemon的好点子！

本插件可以用自定义贴图创建新方块，无需mod，只要一个材质包
怎么创建它呢？

打开你的物品包并黏贴以下内容:
  1. # 这是物品ID, 确保它是独一无二的.
  2. HappyFace:
  3.    # 填写物品的材料，不是方块的材料！
  4.     material: REDSTONE_TORCH
  5.     amount: 1
  6.     name: '&c带来快乐的脸'
  7.     lore:
  8.    - '&r一个古怪的物品. 当放置时会出现一个笑脸.'
  9.     # 我们需要额外数据来创建方块
  10.     data:
  11.      # 你可以把它和自定义物品的材质结合
  12.       custom:
  13.        # 方块ID (注意，ID有限制)
  14.         block: 1
复制代码

记得设置物品的配方

在这之后，我们需要创建材质。本插件附带一个材质包，打开它，找到这个文件夹:
texturepack\assets\minecraft\textures\blocks\lapisdemon\bonus\mushroomblocks

方块的ID是1，所以编辑材质001。建议使用16x16的材质，避免卡顿。

创建高级物品

本插件可以用自定义贴图创建新方块，无需mod，只要一个材质包
怎么创建它呢？

打开你的物品包并黏贴以下内容:
  1. #自定义物品的ID
  2. badsword:
  3.     material: STONE
  4.     amount: 1
  5.     name: '&c一把烂剑'
  6.     lore:
  7.    - '&r我知道，看着很烂'
  8.     data:
  9.      # 你可以把它和自定义方块材质结合!
  10.       custom:
  11.        # 自定义物品ID，保证ID是独一无二的（注意，ID大小有限制）
  12.         item: 0

创建高级合成配方
上一章：
创建合成配方

在创建配方之前，你需要创建一个物品。打开你的物品包，然后键入一下内容
  1. MyBiggerStone:
  2.     material: COBBLESTONE
  3.     damage: 0
  4.     enchantments:
  5.    - DAMAGE_ALL:4
  6.     name: '&6附魔石'
  7.     lore:
  8.    - '&r你做过的最牛的圆石.'
复制代码

现在创建一个新的配方。打开recipes.yml文件

输入以下内容
  1. CRAFT_MyBiggerStone:
  2.   type: craft
  3.   shaped: true
  4.   permission: my.stoneplus
  5.   slot:
  6.     '1':
  7.       material: COBBLESTONE
  8.     '2':
  9.       material: STONE
  10.       # 这个物品槽里要放两块石头
  11.       amount: 2
  12.     '3':
  13.       material: COBBLESTONE
  14.     '4':
  15.       material: STONE
  16.     '5':
  17.      # 这里要放的是自定义物品
  18.       custom: MyBigStone
  19.     '6':
  20.       material: STONE
  21.     '7':
  22.       material: STONE
  23.     '8':
  24.       material: COBBLESTONE
  25.     '9':
  26.       material: STONE
  27.   output:
  28.   # 这里输入自定义物品的ID
  29.     custom: MyBiggerStone
  30.     amount: 1
复制代码

创建礼品箱

上一章：
创建高级物品

要创建礼品箱，首先我们需要带有一些附属数据的自定义物品，复制黏贴这个物品到你的物品包。
  1. # 物品ID
  2. MegaChest:
  3.    # 我们将要使用头颅主人（skull owner）创建一个迷你箱子. 所以我们需要一个玩家头颅（player_head）
  4.     material: PLAYER_HEAD
  5.     amount: 1
  6.     # Damage 0 代表骷髅头. 3 代表玩家头
  7.     damage: 3
  8.     skull:
  9.      # 头颅的皮肤
  10.       owner: 'MHF_Chest'
  11.     name: '&r好&6箱子'
  12.     data:
  13.      # 我们将要创建的礼品箱的ID
  14.       giftchest: 'MegaChest_loot'
复制代码
现在我们已经有了物品，接着创建配方。你应该知道怎么做。

下一步：打开giftchest.ym文件，黏贴以下代码：
注意：如果文件里有一些默认的内容，请删除它们。因为老版本的插件会生成一些过时的例子
  1. # 礼品箱的ID，确保它是独一无二的
  2. MegaChest_loot:
  3. # 使用时礼品箱将会随机掉落列表中的一个物品
  4.   items:
  5.    # 掉落物的ID，运行机制和自定义物品类似: 你可以设置 nbt,附魔, 耐久（damage）等等。但是你不能设置数据标签（data）
  6.     stone:
  7.       material: STONE
  8.       amount: 4
  9.       enchantments:
  10.      - DAMAGE_ALL:2
  11.     diamond:
  12.       material: DIAMOND
  13.       amount: 1
  14.       name: '&4钻石'
  15.       enchantments:
  16.      - DAMAGE_ALL:4
  17. # 如果你需要的话，可以尝试添加自定义物品为掉落物，以下两行为例子
  18. #    a_custom_item:
  19. #      custom: YOUR_ITEM_ID    （YOUR_ITEM_ID-你的自定义物品ID）
  20. # 使用时的音效
  21.   sound: BLOCK_GRASS_BREAK
  22. # 使用时的粒子效果
  23.   particle:
  24.     name: SMOKE
  25.     amount: 10
复制代码
