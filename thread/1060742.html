前言
本插件用于记录近期玩家击杀记录
当达到一定值时，根据配置文件设置，执行对应的「惩罚」或后台指令
还赠送PVP状态开关功能（带CD）
原本我只是想写个简单的控制PVP状态和恶意杀人惩罚插件的...
突然想到了喵都的「Artifact」
结果顺手做了五个主流的出来...真的是厨力爆炸
如果你是9Nine厨，你会玩的很嗨
如果不是...就当正常的PVP惩罚用吧
什么？你问我为什么没有「OverLoad」和「OverDrive」，你做给我看看


特点
可自定义项目较多，惩罚措施高达11种！
插件占用较小且兼容性高
支持手动输入指令进行「惩罚」
「Artifact」技能特效十分炫酷
9nine厨狂喜


指令、权限组和配置文件
指令
  1. /pm set  改变你的PVP状态
  2. /pm set 玩家  改变这个玩家的PVP状态
  3. /pm reload  重载配置文件
  4. /pm clearall  清空所有进行中的惩罚
  5. /pm clearsall  清空所有击杀记录
  6. /pm list  查询列表
  7. /pm clear 玩家ID  清除这个玩家近期的击杀记录
  8. /pm use 玩家ID 技能ID 数值   对这个玩家使用对应的[方法]惩罚（无需带「」）
复制代码
权限组
  1. pm.set  默认玩家拥有  使用/pm set
  2. pm.list  默认玩家拥有  使用/pm list
  3. pm.cd  默认OP拥有  无视/pm set的CD
  4. pm.op  默认OP拥有  无视杀人惩罚
