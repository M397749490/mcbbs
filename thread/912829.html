我觉得吧，没有shop是正常的吧，你看qshop是副本商店，也就是系统商店

引用一下bbs量子商店原贴
管理员GUI商店
  • /shop open - 打开商店主页面
  • /shop open [shop] - 打开指定的商店
  • /shop editor - 打开游戏内的编辑器
  • /shop info - 插件信息
  • /shop reload - 重载GUI模块
玩家箱子商店
  • /chestshop create [购买价格] [出售价格] [admin<true/false>] - 在你看着的箱子处创建商店
  • /chestshop remove - 删除你看着的商店
  • /chestshop list - 列出你的所有商店
  • /chestshop reload - 重载这一模块
插件
  • /qshop editor - 打开GUI商店编辑器
  • /qshop reload - 完全重载插件

你看和你发的图片，qshop其实是副本商店，然后chestshop是量子商店吧。
我觉得可能是这个商店插件和什么插件的指令冲突了也有可能
