Nkit
Nukkit上的礼包插件


[ 插件简介 ]
-
给你的玩家发放一份独特的礼包吧！
目前插件还在测试版本，许多功能都没有完善，不过你可以配合其它插件来实现各式各样的礼包效果


[ 插件特性 ]
-
  • 简易的礼包创建过程
  • 完美支持其他插件添加的物品
  • 完美支持物品的NBT属性
  • 自动穿上礼包中的盔甲
  • 当玩家背包空间不足时，将物品丢弃在地上
  • are more...


[ 使用方法 ]
-
首先，将你想添加进礼包中的物品放在背包中(位置随意)
然后，将需要穿上的盔甲穿在盔甲栏中(可以不穿)
接着输入命令 /nkit create [礼包id] 即可成功创建一个礼包
如果想将礼包给予玩家可以使用 /nkit give [礼包id] [玩家id]
当前玩家还无法自主领取礼包抑或是扣除金币等，请自行配合其他插件实现

[ 命令&权限 ]
-
除了create，其余命令控制台均可使用
nkit.admin - 使用所有命令
/nkit list - 列出所有的礼包
/nkit del [礼包id] - 删除一个礼包
/nkit create [礼包id] - 创建一个礼包
/nkit give [礼包id] [玩家id] - 将一个礼包给予一个玩家


[ 配置文件 ]
-
本插件无配置文件，只有一个config.yml用于存储礼包数据
