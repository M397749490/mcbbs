楼上几个人是水出来的么？


/give @p minecraft:diamond_sword 1 0 {ench:[{id:16,lvl:10000}]}

一万级锋利的钻石剑。



/give @p minecraft:diamond_sword 1 0 {ench:[{id:16,lvl:10000},{id:17,lvl:10000},{id:18,lvl:10000},{id:19,lvl:10000},{id:19,lvl:10000},{id:21,lvl:10000}]}

剑附魔各一万的钻石剑。



/give @p minecraft:bow 1 0 {ench:[{id:48,lvl:10000},{id:49,lvl:10000},{id:50,lvl:10000},{id:51,lvl:10000}]}

各种弓附魔的魔弓



/give @p minecraft:diamond_boots 1 0
{AttributeModifiers:[{Operation:0,UUIDLeast:1,UUIDMost:1,Amount:10000.0,AttributeName:generic.movementSpeed,Name:Speed}]}

一万速度的钻石靴（建议别用，这不是飞，这是传送）


饱食度是药水效果，个人感觉你单击不用命令方块检测就没戏。(加速我是变成更改基础速度，而不是药水效果）
