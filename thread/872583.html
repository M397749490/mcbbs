介绍：
某生存服的玩家们表示NK没有末地莫得灵魂，于是就有了这个插件。
有何特性？
  • 末地主岛
  • 末地小型岛屿
  • 末地传送门
  • 末影水晶
  • 黑曜石平台
  • 黑曜石柱
  • 返回传送门
  • 紫颂树（由于紫颂树是生长于末地高岛的，所以目前暂时不会遇到）
  • 末地之诗
  • 末影龙
未来展望
  • 末地中型岛屿
  • 末地高岛
  • 末地荒岛
  • 末地折跃门
  • 水晶召唤龙
末地结构（末地城）将在即将发布的结构插件中实现，尽请期待。
末影龙未来将在某生物插件中实现，敬请期待。
主岛可能和原生的不太像，未来尽力优化吧。

使用：
将本插件丢进服务端plugins文件夹内，重新启动服务器即可。没有命令与权限。

配置：
config.yml
  1. # 末地传送门是否传送玩家
  2. enable-end-portal: true
  3. # 末地返回传送门是否已激活（建议激活）
  4. exit-portal-activated: true
  5. # 是否生成末影龙
  6. spawn-ender-dragon: true
  7. # 生成器参数
  8. generator:
  9.   end:
  10.     coordinate-scale: 684.412
  11.     height:
  12.       scale: 1368.824
  13.     detail:
  14.       noise-scale:
  15.         x: 80.0
  16.         y: 160.0
  17.         z: 80.0
