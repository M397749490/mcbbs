介绍

[娱乐]NeverLogOff —— 觉得难度不够？玩家下线防杀？让玩家保持在线吧！[全版本]
这个插件太复杂了=-=并且还要同步血量等等一堆操作，不够优雅233复杂就意味着容易出问题

那么这个插件的原理是什么呢？
如果玩家下线时血量低于某个阈值，就会直接杀死玩家。注意：这里的“下线”不包括玩家被踢出等等，所以不用怕被反作弊踢出也算下线遁。
以下几种情况玩家会被检测血量：
  • 玩家使用Esc菜单的断开连接
  • 玩家客户端掉线。例如强制关闭客户端，拔电源（woc），作弊客户端等等。
  • 玩家/服务器 断开网络

大概是我发布过的最简单的插件（43行）

命令&权限
无

配置文件
  1. # 血量阈值，这里的值是半心。20半心 = 10心 = 一排血 = 标准玩家血量。
  2. # 默认 6半心 = 3心 = 30%标准血量 = 某h开头的作弊客户端的秒退阈值。
  3. threshold: 6

  9. import org.bukkit.plugin.java.JavaPlugin;
  10. import org.bukkit.scheduler.BukkitRunnable;

  12. public final class Main extends JavaPlugin implements Listener{
  13.     private int threshold;

  15.     @Override
  16.     public void onEnable() {
  17.         saveDefaultConfig();
  18.         reloadConfig();
  19.         threshold = getConfig().getInt("threshold");
  20.         getServer().getPluginManager().registerEvents(this, this);
  21.     }

  23.     @EventHandler
  24.     public void onJoin(final PlayerJoinEvent event){
  25.         final Player player = event.getPlayer();
  26.         if(!player.isDead())
  27.             new BukkitRunnable() {
  28.                 @Override
  29.                 public void run() {
  30.                     if(player.isOnline() && !player.isDead())
  31.                         if(player.getHealth() < threshold)
  32.                             player.setHealth(0);
  33.                 }
  34.             }.runTask(this);
  35.     }

  37.     @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
  38.     public void onKick(final PlayerKickEvent event){
  39.         Player player = event.getPlayer();
  40.         if(player.getHealth() < threshold)
  41.             player.setHealth(threshold);
  42.     }
  43. }
