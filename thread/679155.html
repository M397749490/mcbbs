Windows Azure（Windows Server 2012）开服教程


一.关于Azure

Windows Azure是微软基于云计算的操作系统，和Azure Services Platform一样，是微软“软件和服务”技术的名称。可运行Windows Server系统及Lunix系统（本教程以Windows Server 2012为例），在Azure上开服需要在控制面板配置一些关于对外的端口映射的配置，以后具体说。
P.S.不过本人并不推荐在这上面开服，价格贼贵。(不过现在好像可以1块钱试用一个月，有1500的信用额）
