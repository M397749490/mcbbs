Part 0、为判断的视觉化做准备


有时候思考问题如果仅靠数据的计算和大脑的模拟，不仅耗时烧脑，还容易出错。
因此如果我们能将代码工作过程视觉化(可视化)，往往有助于我们解决问题。
P.S: 若Part 0看不懂，建议直接转到Part 4使用已经整合好的类，因为Part 1/2/3中做的工作，其实并没有比Part 0多多少。

在视野/身位判断这个问题中，最重要的就是让视线可视化就像在眼睛上装个红外射线
因此我们先准备两个在MC中绘制线段的函数。
要画线段，就得知道起点和终点
于是我们写下
  1. public void drawLine(Location start, Location end){}
复制代码

根据初中平面向量知识，在平面中若有A、B两点，用B点坐标减去A点坐标，我们将得到一条从A射向B的射线（向量）。
于是得到
  1. Vector ray = end.clone().substract(start).toVector();
复制代码
其中ray为从A射向B的射线
clone()是复制终点
substract(start)是对复制后的终点进行减法操作，减去起点start后得到射线
toVector()将得到的射线转为向量。

我们将这个向量称为偏移向量
因为我们要绘制的是起点到终点这条射线上的数个点
所以我们还要根据要绘制的点的数量，让偏移向量每次只从起点向终点移动一小段距离

假设我们每隔0.1个距离单位就绘制一个点，那么我们一共要绘制(射线长度/间隔)个点
  1. double dotCount = ray.length() / 0.1;
复制代码
得到要绘制的点的数量以后，我们还要得到单位偏移向量，即每绘制完一个点之后，向终点移动的向量。
  1. Vector offsetUnit = ray.multiply(1 / times);
复制代码
有了起点、单位偏移向量、绘制点数，我们就可以开始绘制线段了。

Part 3、判断目标的头是否在视野中心


由Part 2中第一项判断知，玩家视线在目标头部时，视线向量和玩家眼睛到目标头部的偏移向量之间的夹角是很小的，我们默认他为5°。

但和Part 2不同，大部分目标的头部都很小，若目标离得有一定距离，误差会有所增加。

因此Part 3我们要多考虑一个变量：距离
这个变量很好获取
  1. double distance = loc_entity_eye.distance(loc_target_head);
复制代码
根据常识我们知道，距离越远，目标看起来就越小。近则反之。
而目标越小，视线和偏移向量之间所允许的最大夹角就越小
即两者成反比：距离 * 最大夹角 = 常数
得最大夹角 = 常数 / 距离
设常数为25
  1. double fov_focus_fixed = 25 / distance;
复制代码
求得修正后的最大夹角，与angle进行判断后，再进行Part 2中第2部分的判断

类似的，Part 2中如果要追求更高的精确度，也可以进行距离修正。

  159.                 // 可以再加上几个身体的判断，服务器资源的消耗和判断的准确性自己把握
  160.                 return isTargetLocationInSight(entity, loc_target, target) || (target instanceof LivingEntity ? isTargetLocationInSight(entity, loc_target.add(0, ((LivingEntity) target).getEyeHeight(), 0), target) : false);
  161.         }
  162.         
  163.         /**
  164.          * 观察者是否在盯着目标的头看
  165.          * @param entity 观察者
  166.          * @param target 目标
  167.          * @return boolean 盯久了会害羞所以还是false比较好
  168.          */
  169.         public boolean isLookingHead(LivingEntity entity, LivingEntity target) {
  170.                 // 不同世界无法判断
  171.                 if(entity.getWorld() != target.getWorld()) {
  172.                         return false;
  173.                 }
  174.                
  175.                 // 获取观察者眼睛的位置
  176.                 Location loc_entity_eye = entity.getEyeLocation();

  178.                 // 获取观察者视线向量
  179.                 Vector lookingVec = loc_entity_eye.getDirection();
  180.                
  181.                 // 获取目标头的位置, 大概没有眼睛不在头上的生物吧？！
  182.                 // 有的话就改改 TODO
  183.                 Location loc_target_head = target.getEyeLocation();
  184.                
  185.                 double distance = loc_entity_eye.distance(loc_target_head);
  186.                
  187.                 // 得到空间坐标中起点射向终点的向量
  188.                 Vector ray = loc_target_head.subtract(loc_entity_eye).toVector();
  189.                
  190.                 // 获取观察者视线向量与射线向量之间的夹角
  191.                 float angle = (float) Math.toDegrees(ray.angle(lookingVec));
  192.                
  193.                 double fov_focus_fixed = FOV_FOCUS_NORMAL / distance;
  194.                
  195.                 // 如果角度超出了聚焦视野最大角度
  196.                 if(angle > fov_focus_fixed) {
  197.                         // 就认为观察者没有盯着目标的头看
  198.                         return false;
  199.                 }
  200.                
  201.                 // 判断目标是否能被观察者看见
  202.                 return isTargetInSight(entity, target);
  203.         }
  204.         
  205.         /**
  206.          * 观察者在目标的身后
  207.          *
  208.          * @param entity 观察者
  209.          * @param target 目标
  210.          * @return boolean 是否在身后
  211.          */
  212.         public boolean isBehind(LivingEntity entity, LivingEntity target) {
  213.                 // 不同世界无法判断
  214.                 if(entity.getWorld() != target.getWorld()) {
  215.                         return false;
  216.                 }
  217.                
  218.                 // 获取观察者位置
  219.                 Location loc_entity = entity.getLocation();

  221.                 // 获取目标的位置
  222.                 Location loc_target = target.getLocation();
  223.                
  224.                 // 和平面坐标系上 B点坐标减去A点坐标得到A->B 一样
  225.                 // 得到空间坐标中起点射向终点的向量
  226.                 Vector ray = loc_target.subtract(loc_entity).toVector();
  227.                
  228.                 // 只考虑平面偏移
  229.                 ray.setY(0);
  230.                
  231.                 // 获取目标正视的方向
  232.                 Vector lookingVec_target = loc_target.getDirection();
  233.                
  234.                 // 只考虑平面方向
  235.                 lookingVec_target.setY(0);
  236.                
  237.                 // 得到两向量夹角
  238.                 double angle = Math.toDegrees(ray.angle(lookingVec_target));
  239.                
  240.                 // 若射线方向跟目标面向方向夹角小于露出背部的最大角度就认为是背对了
  241.                 // 这里我没有判断目标是否在观察者视野里，背对背也是存在的情况
  242.                 return angle < ANGLE_BACK;
  243.         }
  244.         
  245.         public void drawLine(Location start, Location end) {
  246.                 // 不同世界无法画线
  247.                 if(start.getWorld() != end.getWorld()) {
  248.                         return;
  249.                 }
  250.                
  251.                 Vector offsetUnit = end.clone().subtract(start).toVector();
  252.                 double times = offsetUnit.length() / 0.2;
  253.                 offsetUnit.multiply(1 / times);
  254.                 drawLine(start, offsetUnit, times);
  255.         }
  256.         
  257.         public void drawLine(Location start, Vector offsetUnit, double times) {
  258.                 Location currentLoc = start.clone();
  259.                 // 避免绘制线段过短
  260.                 if(times < 1) {
  261.                         times = 1;
  262.                 }
  263.                 for(; times > 0; times--) {
  264.                         currentLoc.getWorld().spawnParticle(Particle.FLAME, currentLoc, 1, 0, 0, 0, 0);
  265.                         currentLoc.add(offsetUnit);
  266.                 }
  267.         }
