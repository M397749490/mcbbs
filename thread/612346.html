密码门DoorCode添加密码到一个门里吧！




功能：
密码门你懂得
可配置玩家进去之后多久关门，或者门开后几秒自动关门
作者汉化！反编译1小时
命令：
CommandDescription
/bc helpDisplays the help page.
/bc create <name> <code>Creates a new code.
/bc remove <name>Removes a code.
/bc change <name> <code>Changes the code.
/bc buttons <name>Adds all buttons for a code.
/bc resetbutton <name>Creates a reset button.
/bc setdoor <name>Sets a code's door.
/bc codesLists all codes.


权限只有一个
DoorCode.admin-所有权限
配置文件：


config：


codes：
这个是密码门保存，不用管







步骤：

/bc create 门的名字 门的密码

之后会有提示，自己按照提示做吧！

注意：

门只能是铁门

铁门的摆放位置只能是关闭的！不懂的话自己慢慢试吧！
汉化了好久，你懂得！
用处：
服务器活动什么的，藏宝活动什么的
