UltraSkills+
精简的空岛生存系技能插件


★》简 介《★
UltraSkills是一款仿照Hypixel Skyblock制作的空岛生存系技能插件
你可以把他当作精简版的MCMMO
挖矿、农业、伐木、酿造、附魔、战斗、捕鱼七种技能类型
若你想制作一款仿Hypixel Skyblock的空岛
那么这款插件是不错的选择
注!该插件目前有较大的局限性比如
无法自定义每种技能升级时执行的奖励
无法自定义每种技能升级时添加的属性参数
无法自定义每种技能升级所需要的经验（当前只可统一每种经验升级为指定的数量）
但上述功能作者已经在筹备添加
但其中的挖矿技能需要Worldguard的区域,国内使用较少
所以这款插件非常适合空岛服务器但不适合陆地生存
购买本插件前请慎重考虑,短期内可能无法满足你的需求
该插件为付费插件|价格为19.9USD|约合人民币140元

★》功能《★

  • 七大技能(挖矿、农业、伐木、酿造、附魔、战斗、捕鱼)
  • 每个技能包括25个等级,可在GUI中直观地查看详细内容
  • 可在ActionBar上显示玩家的生命值/防御值/魔力值
  • 管理员帮助指令
  • 提升技能等级时给予奖励(属性、金币等)
  • 漂亮的玩家交互菜单
  • 支持PlaceholderAPI变量
  • 像Hypixel的技能菜单
  • 支持权限、Vault及经济插件
  • 自定义WG矿区内的矿石自动恢复的时间及每种矿石给予的挖矿经验值
  • 大部分的内容都是可以配置的(MANA和矿区界面暂时无法翻译)
  • MySql支持
  • 给物品添加效果并消耗法力值(该视频为油管视频,有条件的可以看一下)[地址]
  • 支持MMOITEMS的生命、防御属性
  • 自定义每种技能每提升一个等级给予的金币数量
  • 可设置全局每种经验升级所需要的经验（暂不可以设置每个技能不同的经验数）

★》指令/权限/变量《★


  • 玩家命令
  • /Skills - 查看玩家可用的指令
  • /Skills menu - 打开技能菜单
  • 管理员命令
  • /Skills Help - 查看插件帮助
  • /Skills setlevel <技能类型> <等级> <玩家> - 设置指定玩家指定技能的经验等级
  • /Skills addregion <区域名> - 添加一个WorldGuard区域为矿区
  • /Skills delregion<区域名> - 移除一个WorldGuard矿区
  • /Skills Regios List - 列出所有WorldGuard矿区
  • /Skills Ores - 打开WorldGuard矿区设置


  • UltraSkills.openmenu - 允许使用打开技能菜单的权限
  • UltraSkills.setlevel.fishing - 允许使用指令更改玩家的捕鱼技能等级
  • UltraSkills.setlevel.farming - 允许使用指令更改玩家的农业技能等级
  • UltraSkills.setlevel.foraging - 允许使用指令更改玩家的伐木技能等级
  • UltraSkills.setlevel.mining - 允许使用指令更改玩家的采矿技能等级
  • UltraSkills.setlevel.alchemy - 允许使用指令更改玩家的酿造技能等级
  • UltraSkills.setlevel.combat - 允许使用指令更改玩家的战斗技能等级
  • UltraSkills.setlevel.enchanting - 允许使用指令更改玩家的附魔技能等级
  • UltraSkills.setlevel.* - 允许使用指令更改玩家任何技能等级
  • UltraSkills.addregion - 允许玩家添加WorldGuard矿区
  • UltraSkills.delregion - 允许玩家删除WorldGuard矿区
  • UltraSkills.regionlist - 允许玩家使用指令列出所有WorldGuard矿区
  • UltraSkills.oresmenu - 允许玩家打开WorldGuard矿区编辑菜单



  • %UltraSkills_Health% - 玩家生命值
  • %UltraSkills_MaxHealth% - 玩家最大生命上限
  • %UltraSkills_Defense% - 玩家的防御值
  • %UltraSkills_Mana% - 玩家的魔力值
  • %UltraSkills_Mining_Level% - 玩家的采矿技能等级
  • %UltraSkills_Farming_Level% - 玩家的农业技能等级
  • %UltraSkills_Foraging_Level% - 玩家的伐木技能等级
  • %UltraSkills_Fishing_Level% - 玩家的垂钓技能等级
  • %UltraSkills_Combat_Level% - 玩家的战斗技能等级
  • %UltraSkills_Alchemy_Level% - 玩家的酿造技能等级
  • %UltraSkills_Enchanting_Level% - 玩家的附魔技能等级
