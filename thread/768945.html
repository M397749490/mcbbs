标题: [自定义魔法]可以做魔法师了
详细介绍
[color=rgba(0, 0, 0, 0.541176)][color=rgba(0, 0, 0, 0.541176)]插件介绍
这是一款可以自定义魔法的插件，你可以用它设置多个魔法物品，自定义所有属性，[你可以用它设置 生命药剂，回城卷轴，爆炸卷轴，闪电卷轴 等功能，发挥你的想象力吧 ! ]

[color=rgba(0, 0, 0, 0.541176)]指令大全
/magic add [模式] [物品ID:特殊值] --- 添加一个魔法物品
/magic del [物品ID:特殊值] --- 移除一个魔法物品
/magic see [物品ID:特殊值] --- 查看该魔法物品的属性
/magic level [世界名] --- 添加/移除一个禁止魔法的世界
以上指令只能控制台/OP使用

[color=rgba(0, 0, 0, 0.541176)]功能介绍
a模式  [释放范围内的魔法支持生物/NPC/玩家(不包括自己)]
b模式  [给自己释放魔法]
c模式 [执行多控制台指令/玩家使用多指令]
支持 [禁止使用魔法的世界，设置多个魔法物品]

[color=rgba(0, 0, 0, 0.541176)]配置实例
A模式配置选项
范围: "范围半径"
伤害: "数值"
燃烧: "燃烧时间:机率"
药水: "药水id:药水等级:药水时间:机率"
加血: "血量:机率"
爆炸: "爆炸伤害:机率"
闪电: "闪电伤害:机率"
吸血: "吸取血量:获得血量:机率"
消耗物品: "数量"
提示: "自定义魔法释放提示"
冷却时间: "秒数"
====================
B模式配置选项
加血: "血量:机率"
药水: "药水id:药水等级:药水时间:机率"
无敌: "无敌秒数:机率"
消耗物品: "数量"
提示: "自定义魔法释放提示"
冷却时间: "秒数"
====================
C模式配置选项
控制台指令: "tell %p 你是zz"
玩家使用指令: "me 我本来就是zz"
消耗物品: "数量"
提示: "自定义魔法释放提示"
冷却时间: "秒数"
所有选项都可以关闭改成false即可，每个魔法物品都可以自定义
PS：魔法是点地触发
====================
Config.yml配置文件
兼容模式: false[若不能正常使用魔法物品请打开]
禁止使用魔法的世界: []
