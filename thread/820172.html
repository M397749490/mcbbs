游戏简易教程【看到就是学到哦！！！】

快捷查询物品【直接在物品栏搜索输入首字母】
快捷查询物品【在任务手册内对着想要查合成的物品按U或R】
游戏默认NEI是关闭的按O打开【OPQ的O不是零】
其他物品可以看一下，下方的相应的教程

指令

经济类:

/money

查看自己金钱


/baltop

查看
金钱排行


传送类:

/spawn

传送至出生点

/res tp [领地名]

传送至某个领地

/sethome

创建家

/home

传送回家

/delhome

删除家

/tpa [玩家名]

申请传送至某玩家所在位置

/tpahere [玩家名]

申请让某玩家传送至你所在的位置

/back

返回上一次传送的地点/死亡地点

领地类:

【使用木锄选择地块】

/res select size

显示已选择区域的尺寸，特别需要注意Y轴的尺寸是否正确

/res create [领地名]

选择好区域后创建一个叫做[领地名]的领地

/res subzone <领地名> [子区域名]

在领地内创建一块子区域

/res remove [领地名]

移除一个叫[领地名]的领地

/res current

显示你所在的领地

/res list

显示你拥有的领地

/res listall

显示服务器内所有领地

/res rename [旧名称] [新名称]

重命名领地

/res message [领地名] [enter/leave] [信息]

设置[进入/退出]某领地时候显示的信息

/res message [领地名] remove [enter/leave]

移除[进入/退出]某领地时候的信息

/res tp [领地名]

传送至某领地





/res set [领地名] [权限名称] [t/f]

/res pset [玩家ID] [权限名称] [t/f]

设置某领地对于某玩家的权限(t为打开，f为关闭)


权限名称一览表:

trusted:所有权限

container:是否能使用箱子，
发射器
等

bucket:设置是否能使用桶

ignite:点火的权限

piston:活塞是否能使用

build:建造权限，包括毁坏和放置

destroy:毁坏权限

place:放置权限

move:进入权限

tp:传送权限

use:使用权限，工作台，炉子等

monsters:设置是否刷新
怪物

animals:设置是否刷新动物

flow:液体流动，包括水和岩浆

waterflow:水的流动

lavaflow:岩浆流动

healing:设置是否能自动恢复生命

pvp:设置是否能pvp

游戏教程！！！
问：盖亚3怎么打？
答：先做熏香和护盾生成器
然后在做药水与信标【信标用来增加状态  召唤盖亚3的信标即可】
然后泰拉一套全附魔 泰拉剑也要全部附魔
药水加力量二
多做一些熏香


问：矿物怎么获得？
答：做凝矿兰【给与魔力  石头放在旁边即可】

问：石头怎么获得 ？
先做半砖熔炉 然后圆石在半砖熔炉里面烧  

问：俄矿怎么获得
答：筛矿获得

问：奇点怎么获得
答：有物质聚合器【改变模式就可以了】
【拿个物品管道连接产原石的导入物质聚合器】
问：IC2的防爆石怎么获得
答：1
制作出 建筑泡沫 和 泡沫喷枪
然后 将流体/固体装罐机 模式修改成混合流体与固体模式，左边水槽放水，通电。
左上角放置建筑泡沫喷枪，中间放置建筑泡沫
然后摆放铁质脚手架，右键喷上建筑泡沫。
建筑泡沫可使用沙子直接变成防爆石，然后用镐采集下来即可。
