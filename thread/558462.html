这是一个优秀的PVE，非常好,但他是免费的（质量不亚于收费插件）

游戏介绍:
在一波一波僵尸中活下来，升级武器装备
游戏总共有三个难度（EASY, NORMAL, HARD）,两个模式:
STANDARD（战役）　　　　 无限生命,通过所有的回合和波
DEATHMATCH（死亡竞赛）　1条命，坚持最后者胜利

特点:
  • 升级或者自定义出生点　random or custom spawn locations
  • 丰富的配置文件　　　　highly configurable
  • 三种难度　　　　　　　easy, normal and hard mode
  • 可选重生保护　　　　　optional spawn protection
  • 可选等待大厅　　　　　optional pre lobby
  • 开始职业　　　　　　　starting kits
  • 内置商店系统　　　　　inbuilt shop system
  • 可选金钱插件　　　　　optional Vault economy integration
  • 完整的记分板统计　　　scoreboard statistics
  • 开源([size=14.6667px]Github releases)　  Open Source
  • 积极开发　　　　　　　under active development

指令(插件WIKI):[spoiler]基本指令
指令描述
/zvp help帮助
/zvp reload重载插件
/zvp status列出所有地图状态
/zvp status [Arena ID]列出指定地图
/zvp list [Arena|Lobby|Sign|Kit]列出指定项目
/zvp update自动下载最新版
玩家指令
/zvp join [Arena ID]加入游戏
/zvp leave离开游戏
地图指令
/zvp record [duration (in hours)]设置一个新的统计记录，可持续时间
/zvp stop终止所有地图
/zvp stop [Arena ID]停止指定地图
/zvp addkit [kitname]添加新职业
/zvp removekit [kitname]删除职业
配置指令见安装部分


权限:
PermissionUsage

zvp.statusAllow use of status and list command

zvp.manage.lobbyAllow lobby management. Includes all lobby related things
zvp.manage.signAllow sign management. Includes all sign related things


安装:

安装大厅:
  • 输入 /zvp add lobby

安装场地:
  • 输入 /zvp add arena ，会得到选区工具
  • 进行选区(类似创世神)，要求包括地图
  • 编辑 arena configuration.
安装一个多边形场地:
  • 输入 /zvp add arena polygon 会得到多边形选区工具
  • 选点(详情看创世神多边形选区) polygon selection in WorldEdit.
  • 完成输入 /zvp add arena finish 清除选点输入 /zvp add arena clear
  • 编辑 arena configuration.
安装自定义出生点:
  • 输入 /zvp add position
  • 点击出生点
  • 输入 /zvp reload 完成并重载
安装等待大厅:
  • 去等待大厅区域（必须在同一世界，并且不在游戏场地内）!
  • 输入 /zvp add [Arena-ID] preLobby 创建
  • 输入 /zvp add [Arena-ID] preLobbyPosition 设置等待大厅传送点
  • 输入 /zvp reload 重载
