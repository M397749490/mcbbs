预发布版是Minecraft的测试机制，如果该版本作为正式版发布，那么预发布版的游戏文件将与启动器推送的正式版完全相同。

然而，预发布版主要用于服主和Mod制作者的预先体验，如果发现较严重漏洞，该预发布版会被新的预发布版代替。因此对于普通玩家建议持观望态度。

Minecraft 1.9仍未发布，1.9-pre2为其第2个预览版。

转载本贴时须要注明原作者以及本帖地址。


UPDATE: Minecraft 1.9 Pre-Release 2 is now available.
更新：Minecraft 1.9 预发布版 2 现已放出。（点这里查看 Minecraft 1.9 预发布版 1）

Bugs fixed in 1.9-pre2:
1.9-pre2版本中修复了以下的bug:
  • [Bug MC-35127] - Wrong NBT TAG Type for fallTime in FallingSand Entities
  • [Bug MC-35127] - fallTime（掉落时间）NBT标签的数据不正确
  • [Bug MC-35714] - Sounds loop/restart when exiting screens
  • [Bug MC-35714] - 唱片机被破坏并且音乐停止后，在玩家关闭物品栏的时候，即使没有唱片机的情况下音乐也会再次响起
  • [Bug MC-89928] - Portals not placing the player at correct coordinates
  • [Bug MC-89928] - 玩家经过传送门后位置不正确
  • [Bug MC-90101] - Mob Spawner is overwriting (ignoring?) Pos[x,y,z] data of entity
  • [Bug MC-90101] - 刷怪笼覆盖了（无视了？）NBT数据 “Pos[x,y,z]” 所指定的刷怪地点
  • [Bug MC-91290] - Skeletons with no AI spawning naturally
  • [Bug MC-91290] - 游戏中刷出了没有AI的骷髅
  • [Bug MC-95538] - /playsound command doesn’t work with selectors not resolving to exactly one entity
  • [Bug MC-95538] - /playsound 指令在只有一个可播放声音目标的情况下，使用@a的话指令会提示无法找到玩家

译注：这几个bug都是我挨个点进去看描述才翻译出来的，不然只看标题实在是太歧义。

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要魔法上网。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
