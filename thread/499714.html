作者: Smaoll    时间: 2015-9-6 19:57
运用到插件Essentials，请打开该插件的config.yml
1.设置世界收费
创建地标/setwarp fb然后在Essentials的config.yml中设置收费
找到经济设置选项。
  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |               Essentials 经济设置                    | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7. # 查看更多信息,请访问 http://wiki.ess3.net/wiki/Essentials_Economy

  9. # 设置玩家第一次登录服务器时拥有的金钱,默认为0.
  10. starting-balance: 0

  12. # worth-# 定义物品的价格,用来使玩家输入"/sell"后,以这种价格将物品卖给服务器.
  13. # 现在该项设置的文件是worth.yml

  15. # 定义玩家每次使用命令时所要花的钱,空格由"-"代替,带有"example"的是例子.
  16. # 一些命令例如/repair拥有独立的花费,可以在essentials wiki查看更多信息
  17. command-costs:
  18.   # /example costs $1000 PER USE
  19.   #example: 1000
  20.   # /kit tools costs $1500 PER USE
  21.   #kit-tools: 1500
复制代码

在command-costs: 项下添加warp-fb: 1000
  1. command-costs:
  2.   warp-fb: 1000
复制代码

意思就是命令/warp fb要使用1000游戏才能传送，这是命令收费。（如要自行添加请注意格式，空格用“-”代替）

当然，你也可以使用命令收费插件

2.禁止back返回。
我们可以通过设置世界权限与给予权限来允许玩家通行。
第一条中的warp是完全可以越过该权限直接传送的。
所以请打开Essentials的config.yml，找到如下代码
  1. # 设置为true,启用每个世界传送单独的权限.
  2. # 支持 /world, /back, /tp[a|o][here|all],但是不支持 warps.
  3. # 给予玩家某个世界的传送权限 essentials.world.<worldname>
  4. # 不包括 /home 命令, 下面有单独的设定.
  5. world-teleport-permissions: false
复制代码

并将 world-teleport-permissions: false设置为true，效果如下
  1. world-teleport-permissions: true
复制代码

现在来讲解如何给予权限。
权限节点为 essentials.world.世界名
假设我mv创建的世界名为 fuben，那么我给玩家权限 essentials.world.fuben 玩家即可进入此世界。
默认玩家是没有任何世界的传送权限的，也就是说，像主世界这些你都需要添加所需权限。
但是副本世界的权限节点不添加，就可以实现注释所说功能。
# 支持 /world, /back, /tp[a|o][here|all],但是不支持 warps.
