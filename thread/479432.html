在开服的bat里面加入死循环(仅适用于window)
  1. [url=home.php?mod=space&uid=39305]@echo[/url] off
  2. :begin
  3. java -jar minecraft_server.jar //开启服务器,minecraft_server.jar换成你服务器的jar
  4. ping 127.0.0.1 -n 3 >nul      //延时 3秒
  5. goto :begin  //重新循环
