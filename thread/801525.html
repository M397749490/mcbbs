为什么要重制 Why to Reload
首先，感谢原作者 @leeyao 所做的工作。
原链接：http://www.mcbbs.net/thread-471208-1-1.html
原插件有严重的刷经验、刷物品、卡服BUG，严重影响服务器的正常运行。
该插件最新版本发布日期为 2015年9月30日，已经过去三年之久，
原作者已经有一年没有登录过MCBBS了，对此插件进行更新的可能性不大。
因此我决定对此插件进行部分修改，并在原作者指定的EPL-1.0协议，开源发布。
由于原版插件有一些严重BUG，建议各腐竹迁移到本重制版插件。

特性和截图 Features&Screenshots
[带有*的为重制版特有功能]
  • 随机扣除且掉落背包中的 n 格物品
  • * 可以设置哪些物品被赦免，死亡不掉落。
  • 对玩家添加三种负面药水效果。
  • 扣除一定百分比的金钱，或者定量的金钱
  • 扣除/掉落一定百分比的EXP，或者定量的EXP
  • * 可以设置是否掉落经验球，防止刷取经验
  • 自定义文本信息和语言
  • 设置某些世界不启用本插件
（有任何疑问，请首先注意看下面的 常见问题 FAQ）
截图中的书本为我服的新手指南，指南针为快捷菜单，均不会掉落，其他的掉落物品和经验、金钱通过提示信息发送给玩家。





重制版更新日志 Update Logs
  • [架构更新] 将编译工具由 Maven 迁移为 Gradle
  • [架构更新] 插件所需 JDK 版本升级为 1.8，请升级到 Java 8 使用本插件
  • [严重BUG] 修复了取物品 dropList 时，由于背包中有多个 相同 ItemStack 导致无法跳出 while 循环，导致服务器卡死并关机的问题
  • [严重BUG] 修复了玩家死亡时，经验球掉落，但是经验不扣除，从而可以无限刷经验的问题
  • [严重BUG] 修复了玩家死亡时，本应只清空 n 格物品，背包却被全部清空掉落的问题
  • [一般BUG] 修复了与其他插件配合时，物品不能删除，但是生成掉落物的BUG
  • [功能更新] 增加 Bypass 配置项，可设置哪些物品不会掉落
  • [功能更新] 增加 Summonxp 配置项，可设置经验掉落时，是否生成经验球供其他玩家拾取
  • [功能更新] 增加随机上限功能，默认为 dropAmount*2，杜绝后台卡死服务器，并在后台提示取值次数，供腐竹监控性能状态
  • [功能更新] 修改提示文本样式

指令&权限 Commands&Permissions
指令 权限 说明
N.A.DeathPenalty.*所有权限
/dp reloadDeathPenalty.reload重新加载配置文件
N.A.DeathPenalty.item死亡不掉落物品
N.A.DeathPenalty.money死亡不掉落钱
N.A.DeathPenalty.exp死亡不掉落经验
N.A.DeathPenalty.buff不受debuff影响

常见问题
Q: 为什么不能扣除经验？A: 请确保安装了 Essentials 插件，且/exp指令能正常使用。
Q: 为什么我的服务器无法使用？A: 请确保您的服务端 Java 版本高于 1.8
Q: 为什么掉落物品显示代码（如LAVA_BUKKIT）？A: 请确保安装 LangUtils 插件。
Q: 为什么掉落物品显示英文（如lava bukkit）？A: LangUtils 的配置时加载英文（en-us），你需要修改配置使其加载中文（zh-cn）或其他语言。
