前言
注意
       此插件同其他CommandSign不同，本版本为高版本重置版，之前的插件因为无法支持api7，基本算作弃坑了

什么是CommandSigns Reloaded？
            CommandSigns Reloaded是一个对低版本的牌子指令插件重置的插件！这个插件允许服务器管理员通过右键牌子绑定对应指令，玩家可以通过右键牌子直接执行绑定在牌子上的指令。

米二的话
米二也在用这款插件，这是一款非常方便的一款小巧的插件，功能十分强大，希望你们喜欢。

Tips
如果你需要频繁的修改牌子，建议你试一试米二开发的KSE牌子编辑器哦~

安装方法
下载本插件的最新版本
  • 将本插件放置在您的mods文件夹下
  • 开启服务器
  • 进入游戏并输入“/csign”
相关指令
  • /csign add  指令解析： 将一条指令绑定给下一个你右键的牌子


  注意: 你需要在执行此指令后右键一个牌子

      关键字：
1）
  1. /csign add <指令>
复制代码
       此指令将会在玩家邮件牌子的激活时候，相当于玩家执行/<指令>(译者注：指令部分带不带"/"都行)
2）
  1. /csign add console:<指令>
复制代码
       此指令将会在激活时候，让控制台执行指令

3）
  1. /csign add Tollainmear:<command…>
复制代码
       此指令将会在激活时候，让Tollainmear玩家（如果在线的话）执行指令

4）
  1. /csign add console:give @p wool 16
复制代码
       您可以使用@P关键字来替换激活者的ID

5）
  1. /csign add wait 1000
复制代码
       wait关键字允许指令延续指定毫秒之后再执行。
  • /csign set  指令解析： 配置对应牌子的相关参数

     1）
  1. /csign set onetime true
复制代码
       这个指令将会让指定的牌子仅能激活一次。您可以使用
  1. /csign set onetime false
复制代码
       来让这个牌子成为无限次的（译者注：默认无限次）。

     2）
  1. /csign set cooldown [秒数]
复制代码
       这个指令将会将指定的牌子修改为：经过冷却时间后才能激活的牌子。（译者注：以秒为单位，默认为0）
        如果想禁用，请设置为：
  1. /csign set cooldown 0
复制代码
     3）
  1. /csign set price [价格]
复制代码
       这个指令将会将制定的牌子设置为付费使用（默认为0）。如果想禁用请使用：
  1. /csign set price 0
复制代码
     4）
  1. /csign set permission my.perm.to.use.my.sign
复制代码
       这个指令允许你讲牌子修改为需要指定权限才能激活，默认不需要额外权限，如果你希望改回无权限，你需要:
  1. /csign set permission ""
复制代码
     5）
  1. /csign set redstonable true
复制代码
        这个指令将允许玩家通过红石信号充能激活这个牌子对应的指令，注意：
        此时，如果此牌子对应的指令中包含关键字@p的话，将不再指代激活者，而是最近的一个玩家！

     6）
  1. /csign set redstoning true
复制代码
       这个指令将会在牌子激活的时候发送红石充能信号给周围的方块。
  • /csign list  指令解析： 列出所有绑定在牌子上的指令
  • /csign remove [序号]  指令解析： 删除指定序号的指令
  • /csign clear  指令解析： 删除所有绑定的指令
  • /csign error  指令解析： 当玩家缺少权限或者游戏币的时候，激活的指令

     1）
  1. /csign add error <指令>
复制代码
       当玩家没有足够的游戏币（或者没有权限的时候），这部分指令将会替代“无权限”或者“余额不足”

     2）
  1. /csign list error
复制代码
       同/csign list，只不过仅显示error的指令列表

     3）
  1. /cs remove error <序号>
复制代码
       同/csign remove。
  • /csign unsafe  指令解析： 此指令将允许你将指令绑定给其他方块！
权限

  • csigns.set - /csign set
  • csigns.add - /csign add
  • csigns.remove - /csign remove
  • csigns.list - /csign list
  • csigns.clear - /csign clear
  • csigns.unsafe - /csign unsafe
  • csigns.version - 使用 /csigns 的权限
  • csigns.create - 创建指令牌子的权限（译者注：请谨慎管理此权限，可获取控制台权限）
  • csigns.destroy - 破坏一个指令牌子的权限
  • csigns.use - 使用指令牌子的权限
