★Touchscreen Holograms★

点击全息图执行指令丨类似SignShop
此排版来自PCD小组，内容格式来自残叶dalao

插件功能
可将单个或多个指令绑定在全息图上，通过点击全息图来执行指令

指令与权限
指令
功能
所需权限
/touchscreenholograms 或 /touch 或 /th
插件主要指令，显示插件信息 版本 作者
touchscreenholograms.admin
/th help
显示插件帮助
touchscreenholograms.admin
/th add <全息图名> <指令>
在指定全息图上添加指令
touchscreenholograms.admin
/th remove <全息图名> <指令编号>
删除指定全息图的指定指令
touchscreenholograms.admin
/th details <全息图名>
显示指定全息图的全部指令并给出编号
touchscreenholograms.admin
/th clearall <全息图名>
删除指定全息图上的全部指令
touchscreenholograms.admin
/th list <全息图名>
显示全部已绑定指令的全息图
touchscreenholograms.admin
注：绑定指令时无需在指令前加"/"或引号
如需在全息图test上绑定指令/say 233，使用/touch add test say 233即可

指令类型
默认情况下，插件将以点击全息图玩家的身份执行指令。如果在指令前加上下面这些前缀，指令将以其他方式执行。
前缀 功能
console: <指令> 以控制台权限执行指令
op: <指令> 以OP权限执行指令
server: <子服务器> 将玩家发送至指定子服务器（需要BungeeCord）
tell: <内容> 向点击全息图的玩家发送消息，支持颜色代码

变量
可在指令内加入以下变量：
{player} 玩家ID
{world} 所在世界
{online} 当前在线人数
{max_players} 最大在线人数

请加上命令部分的说明：

console: <command> 通过后台输出指令
/touch add <hologram> console:<command>

sever: <server> 通过控制台输出指令   
/touch add <hologram> sever:<command>
命令台输出的指令无法识别变量例如{player}

op: <command> 提示玩家权限执行指令   
/touch add <hologram> op:<command>
提升权限执行的指令会在玩家输入栏产生命令提示

tell: <message> 提示玩家权限执行指令   
/touch add <hologram> tell:<message>
对玩家说一句话，不能执行指令
