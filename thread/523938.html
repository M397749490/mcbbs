沙发是给了地址的，我这里贴过来给你
先创建一个计分板
  1. /scoreboard objective add test dummy
复制代码

然后探测，高频
  1. /execute @a ~ ~ ~ detect ~ ~-1 ~ minecraft:diamond_block 0 /scoreboard players set @p test 1
复制代码
  1. /scoreboard players set @a test 0
复制代码
  1. /execute @e[score_test=1] ~ ~ ~ /setblock ~ ~3 ~ grass
复制代码

这条指令就会不停地探测有没有玩家踩在钻石块上面，有的话就在玩家上面刷草方块。
然后你可以

而且你也应该看得到是要1.8+的版本才能使用。
