介绍：
本插件是个前置，可用于在Java插件的注释中注册命令和事件、加载Groovy脚本、动态加载库和插件。没有任何命令与权限，仅是一个依赖库

使用：
将本插件丢进服务端plugins文件夹内，然后把其它使用本插件作为前置的插件也扔进去，重新启动服务器即可。

开发：
在注释中注册命令：
创建一个命令class
  1. import cn.nukkit.command.CommandSender;
  2. import tech.teslex.pi.annotations.PiCommand;

  4. class Commands {
  5.     @PiCommand(command = "test", description = "test command", usage = "usage test", aliases = {"text"}, permissions = {"testplugin.test.use"})
  6.     public void test(CommandSender commandSender, String s, String[] args) {
  7.         commandSender.sendMessage("test response");
  8.     }
  9. }
复制代码
然后注册这个class
  1. import tech.teslex.pi.PiApi;

  3. Commands c = new Commands();

  5. PiApi.registerCommands(c);
复制代码
注册事件
  1. import cn.nukkit.event.player.PlayerJoinEvent
  2. import cn.nukkit.event.player.PlayerMoveEvent
  3. import tech.teslex.pi.PiApi
  4. import tech.teslex.pi.annotations.PiOn

  6. @PiOn
  7. void onJoin(PlayerJoinEvent e) {
  8.     e.player.sendMessage "§eHey, bro!"
  9. }

  11. @PiOn
  12. void onMove(PlayerMoveEvent e) {
  13.     def x = e.player.x as int
  14.     def y = e.player.y as int
  15.     def z = e.player.z as int

  17.     e.player.sendPopup "§e${x} : §a${y} : §c${z}"
  18. }

  20. PiApi.registerEvents(this)

从网络上动态加载库或插件
  1. import tech.teslex.pi.PiApi;
  2. import tech.teslex.pi.dependencies.PiDependency;
  3. import tech.teslex.pi.dependencies.PiDType;

  5. PiDependency jwt = new PiDependency("JWT", "java-jwt-{VERSION}.jar", PiDType.LIBRARY, "3.3.0", "http://central.maven.org/maven2/com/auth0/java-jwt/{VERSION}/java-jwt-{VERSION}.jar");

  7. PiApi.requireDependency(jwt);

  5. autostart = true // optional, default true

  7. someVar = "i'm a string"

  11. server.logger.info(someVar)

  14. // ... etc.
