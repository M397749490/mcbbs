引言
在1.13中，execute store ... 取代了 stat，我一直在想，怎么样可以实现把nbt标签与命令的返回值联系起来呢？正巧，在维基上找到了这样的一段话：
...将返回值储存在目标坐标方块在标签路径的NBT标签上...

卧槽，如此神奇？那么就来试一试。
需要

1个命令方块
数据包里的函数
指令

循环型命令方块：
  1. function shoot:givedata
复制代码

函数 givedata.mcfunction


  2. #添加标签
  3. tag @a[nbt={Inventory:[{Slot:-106b,id:"minecraft:bow"}]}] add bow_player
  4. give @a[tag=bow_player,nbt={SelectedItem:{id:"minecraft:snowball",Count:1b}}] snowball 1
  5. execute at @a[tag=bow_player] run tag @e[type=minecraft:snowball,limit=1,distance=..2,tag=] add bow_snowball
  6. #生成箭
  7. execute at @e[tag=bow_snowball] run summon minecraft:arrow ~ ~1 ~ {Tags:["bow_arrow"],damage:4b,pickup:2b}
  8. #复制扔出雪球的 Motion
  9. execute store result entity @e[tag=bow_arrow,limit=1] Motion[0] double 0.01 run data get entity @e[tag=bow_snowball,limit=1] Motion[0] 100
  10. execute store result entity @e[tag=bow_arrow,limit=1] Motion[1] double 0.01 run data get entity @e[tag=bow_snowball,limit=1] Motion[1] 100
  11. execute store result entity @e[tag=bow_arrow,limit=1] Motion[2] double 0.01 run data get entity @e[tag=bow_snowball,limit=1] Motion[2] 100
  12. #添加新tag以防被再次选择
  13. tag @e[tag=bow_snowball] add bow_snowball_old
  14. tag @e[tag=bow_arrow] add bow_arrow_old
  15. tag @e[tag=bow_snowball] remove bow_snowball
  16. tag @e[tag=bow_arrow] remove bow_arrow
  17. tag @a[tag=bow_player] remove bow_player
  18. #清除雪球
  19. kill @e[type=minecraft:snowball,tag=bow_arrow_old]
复制代码

原理
原理就是将雪球的Motion复制到弓箭上，使用
  1. <div>execute store result entity @e[tag=bow_arrow,limit=1] Motion[0] double 0.01 run data get entity @e[tag=bow_snowball,limit=1] Motion[0] 100</div><div>省略数组第一个元素以及第二个元素的复制命令，重复了
  2. </div>
复制代码
这里要注意倍率中有0.01与100，因为Motion中的元素都是双精确浮点数（就是小数啦，现在还没搞清楚数据类型d与b）但一输出就变成整数了，这时这样可以取到2位的精度。

将弓放到副手，左手拿一个普通的雪球（有nbt的话就会堆叠不到一起去）
右键丢出雪球，雪球会被立即替换成箭，会有显示bug（好像发现了什么）
箭会顺着雪球的轨迹走，直到落地或砸在生物上
请勿往自己脚下砸，会有伤害的
