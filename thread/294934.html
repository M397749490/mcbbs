The code 1：代码（原名：The code）（本人测试可用版本：1.5+）（作者标注：1.6.2）

       介绍：

the Code是一个Minecraft地图。你需要解决一个谜题以得到一个代码，每一个答案都将以代码形式给出。用铁砧将纸重命名，然后把纸扔在漏斗里，一个新的房间将会开放。一共有30个谜题。这些谜题并不简单，我做了全新的谜题或我用一些旧的概念，并结合出新的概念。它有使用新的美丽的石英块。但你将要看到的视频和截图中，石英是不是这地图唯一用到的1.5更新的方块。它也包含一个记分牌，更名为commandblocks、阳光传感器，比较器，被困的箱子，可见的名字标签上面的生物，红石块，重命名过的箱子，更多的记分版，漏斗以及更多。哦，我猜你想要下载链接？好，你去：

The code 2：无尽（原名：The code 2：Infinite）（本人测试可用版本：1.5+）（作者标注：1.6.2）

the Code的续集就在那里。如果你还没玩过the Code，我建议你去试试。如果你玩过第一部，别以为这张地图会和那张一模一样。当然，这地图仍有难题，仍然是由石英制成的，而门的长走廊没了，也不是把代码放在漏斗里。然后你想问这是什么样的一张地图？嗯，如果要我说，我会给很多答案。比方说，我从代码的“无限”的方面制作了一张新的地图。

The code 3：结束（原名：The code 3：End）（本人测试可用版本：1.7+）（作者标注：1.7.4）
       介绍：
将the Code和the Code II相结合，不分伯仲，the Code III诞生了。在the Code III中你可以选择你要解决的第一个难题。像各种各样的复杂的分线探索。它含有大量的Minecraft技巧，当然，就像在代码和代码II中的一样。让我们看看这是否会让你的思维陷入混乱。

第一部原介绍：
the Code is a minecraft puzzle map.In it you need to solve a puzzle to get a code, every solution is in the form of a code. If you rename paper to that code using an anvil, then throw the paper in a hopper, a new room will open. There are 30 puzzles. These are not just regular puzzles, I've made entirely new puzzles or I used some old concepts and combined them with new concepts.It's got a beautiful look using the new quartz blocks. But you'll have to look at the video and screenshots to see that.The quartz is not the only 1.5-piece that's in this map. It also contains a scoreboard, renamed commandblocks, a light sensor, comparators, trapped chests, visible name tags above mobs, the redstone block, renamed chests, more scoreboards, hoppers and much more.Oh, you want to have the download link I guess? 第二部原介绍：
There it is, the sequel to the Code. If you haven't played that map yet, I suggest you play that first. If you have, don't expect anything like that map at all.Sure, this map still has puzzles and is still made of quartz, but the long hallway with doors is gone, and there is no hopper to throw a code in either. What does this map have then you ask? Well, if I say that, I'm going to spoil a lot. Let's say I took the "Infinite" level from the Code, and made a new map from it.
第三部原介绍：
Take the awesomeness from the Code and the Code II, combine that and there you have it: the Code III. In the Code III you can actually choose which puzzle you are going to solve first. Like a big tree with all kinds of branches to explore. It contains a ton of minecraft tricks of course, just like in the Code and the Code II. Let's see if this turns your mind into a blown mind.
