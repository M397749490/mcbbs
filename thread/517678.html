作者: xRPQx    时间: 2015-10-31 04:24

打开GroupManager
打开config
添加你要弄的世界,如下

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          plotworld:
          - users
          all_unnamed_worlds:
          - users
          - groups
          world1:
          - users (红色的就是要添加的,world1可以变换成你想要的世界名，注意下面只要- user~~)
然后游戏里输入/manload
你会发现,worlds里面多了一个文件夹
复制一份原来就有的世界文件夹里的group拷贝过去
进入修改

找到builder
找到info
找到build
修改后面的true为false
然后游戏里输入/manload
即可

求最佳

作者: Lolitamc    时间: 2015-10-31 10:26
关闭玩家建筑权限/mangaddv builder build false
给予玩家交互权限/mangaddp builder essentials.build.interact.*
这样玩家只能使用把物品 而不能建造和破坏    求最佳
