BlockEffects是一个轻量级的小插件，当玩家点击或踩在方块上时，就会触发一个药水效果
目前有5种触发方式：LEFT_CLICK（左键点击）, RIGHT_CLICK（右键点击）, WALK（踩踏）, BREAK（破坏）, PLACE（放置）
你可以自定义触发时的消息、执行的命令、药水效果等
拥有冷却时间以及每种方块不同的触发权限，这个插件适用于跑酷，PVP这样的游戏模式上，如果有想法，生存上也可以使用


  • /blockeffects - 查看插件信息
  • /blockeffects blocks - 查看所有已配置的方块


  • blockeffects.blocks - 允许查看所有已配置的方块
  • 你可以自定义不同的方块不同的权限

  16. # <name> - 自定义备注，随便取
  17. # <material> - 方块的material值 (Material: http://**.com/spigot-material)
  18. # <message> - 触发时收到的信息
  19. # <trigger-type> - 触发方式 (WALK, LEFT_CLICK, RIGHT_CLICK, BREAK, PLACE)
  20. # <permission> - 自定义权限
  21. # <potion-effect> - 药水效果 (http://**.com/spigot-potioneffect)
  22. # <potion-duration> - 药水时间
  23. # <potion-amplifier> - 药水等级
  24. #
  25. #  <name>:
  26. #    material: <material>
  27. #    message: <message>
  28. #    trigger: <trigger-type>
  29. #    permission: <permission>
  30. #    effect:
  31. #      type: <potion-effect>
  32. #      duration: <potion-duration>
  33. #      amplifier: <potion-amplifier>
  34. #    commands:
  35. #      - "<command1>"
  36. #      - "<command2>"

  38. #例子

  44.     effect:
  45.       type: REGENERATION
  46.       duration: 25
