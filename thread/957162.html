我的方法是监听PacketPlayOutEntityStatus包，当status==2时设置LivingEntity的受击冷却为0
这是我监听PlayOut的所有包，在僵尸攻击村民的时候监听到的特殊的包(同时监听到的还有PacketPlayOutAnimation和PacketPlayOutEntityMetadata,第一个是和攻击者的动作相关，第二个我没测)
如果这种方法有遗漏或者会出bug的地方，或者有更好的办法实现这个功能的，请dalao将方法贴在回复区，万分感谢
下面是我的整个PacketListener的代码(因为是在自己服务器上用所以没有管nms的版本号问题)
(所有关于数据包的资料全部来源与idea反编译和wiki.vg/Protocol)

  19. public class IPacketListener extends PacketAdapter{

  23.         private static Field bF = null;

  30.                         e.printStackTrace();

  38.                                                    .plugin(JavaPlugin.getPlugin(Main.class))

  43.         public void onPacketSending(PacketEvent event) {
  44.                 PacketContainer container = event.getPacket();
  45.                 PacketPlayOutEntityStatus packet = (PacketPlayOutEntityStatus) container.getHandle();
  46.                 if(this.packet == packet) {
  47.                         return;
  48.                 }else {
  49.                         this.packet = packet;
  50.                 }
  51.                 CraftWorld cWorld = (CraftWorld) event.getPlayer().getPlayer().getWorld();
  52.                 WorldServer nmsWorld = cWorld.getHandle();
  53.                 try {
  54.                         int entityID = (int) aF.get(packet);
  55.                         if(nmsWorld.getEntity(entityID) != null) {
  56.                                 Entity damaged = nmsWorld.getEntity(entityID).getBukkitEntity();
  57.                                 byte status = (byte) bF.get(packet);
  58.                                 if(damaged instanceof LivingEntity && status == 2) {
  59.                                         ((LivingEntity)damaged).setNoDamageTicks(0);
  60.                                 }
  61.                         }
  62.                 } catch (Exception e) {
  63.                         e.printStackTrace();
  64.                 }
  65.         }

  67. }
