一、MOD介绍
作者把所有的介绍都放在视频里了，不过撸主悲催的加载不了。
欢迎大家访问作者的网址：http://www.atomicstryker. net
这个MOD为主角增加了驯服野生蝙蝠的能力。当你驯服了一只蝙蝠，它会跟随并且保护你，随着它的成长它会获得不同的能力。
驯服方法：对地或者蝙蝠右击南瓜饼。驯服后，可以右击蝙蝠让它停下。
右击蝙蝠可以查看蝙蝠的信息或重命名。
二、宠物蝙蝠特点
  • 如果不在战斗状态，蝙蝠会跟着你。
  • 如果它卡住了或者它跟不上你了，它会转移到你的背包中。
  • 蝙蝠不能接触火，岩浆和爆炸事故。
  • 蝙蝠掉血＝增加经验
  • 升级时，它会增加攻击威力和生命上限。
  • 到达三级时，蝙蝠宠物将会有三分之一的可能做出带有生命偷取效果的攻击。
  • 如果蝙蝠死掉了，它会跑到你的背包里头，需要喂养才能复活。
  • 把受伤的蝙蝠和南瓜饼一起合成可以治愈蝙蝠。
  • 手持蝙蝠会给予你夜视能力，不管它们健康不健康。
  • 一个宠物蝙蝠不会转移给其他人，会保持自己的主人。
  • 其他玩家也可以养活它们把南瓜派丢在附近。
  • 只有新鲜的南瓜派才会计算掉落。
  • 是的，你可以残暴你的蝙蝠，你的恶意，你将用南瓜派主宰蝙蝠的一切生命。
  • 完全康复的蝙蝠不多。

四、安装方法
  • 1.如果你没有安装Forge，那么请在这里下载并安装Forge，Forge安装方法：打开Forge压缩包把里面的内容全部拖入.minecraft/bin文件夹下的minecraft.jar文件里，注意安装前先备份一个minecraft.jar文件，防止安装失败后无法打开游戏。
  • 2.下载宠物蝙蝠MOD压缩包。
  • 3.把下载到的压缩包文件剪切到.minecraft/mods文件夹下。
  • 4.打开游戏享受吧！
五、配置文件
配置文件是.minecraft/config文件夹下的PetBat.cfg文件，用记事本打开。
# Configuration file
# Generated on 13-1-25 下午3:16


####################
# general
####################


general {
    I:"glisterBatEffectDuration (s)"=300（翻译：拿着蝙蝠夜视效果的世界（s））
    B:manualEnabled=true（翻译：手拿蝙蝠是否启用，true为真，false为假）
}




####################
# item
####################


item {
    I:ItemPocketedPetBat=31743（翻译：喂养的蝙蝠物品ID）
}
