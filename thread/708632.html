OnlineLog
GitHub https://github.com/OnlineMC/OnlineLog
简介

他会记录你的服务器一段时间内的玩家在线情况
玩家在线日志会保存到 /plugins/OnlineLog/log 文件夹下文件名为日期的形式例如 2017-07-19.yml 这样
您可以通过使用 Notepad++、sublime text、vi 等等这样专业的文本编辑器来查看

他的格式是这样的
时:分:秒|在线人数
例如图上面第2行的记录
22:49:25|0
所代表的意思就是 在今天22点49分25秒 服务器有 0 人在线

配置文件

  1. version: 1.1
  2. #记录频率 单位/分钟 不建议设置太低的频率
  3. time: 10

  5. #是否在控制台显示在线玩家信息
  6. echoOnlineLog: false

  8. #服务器无人在线时 不会向控制台输出日志(如果启用上面那项的话)
  9. continueLog: true

  11. #服务器无人在线时 不会写入日志
  12. continueSave: true
