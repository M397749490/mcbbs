今日知识

  • 关于java中的赋值类运算符
赋值类运算符包括两种：

* 基本的赋值运算符
    =

* 扩展的赋值运算符
    +=
    -=
    *=
    /=
    %=

  • 赋值类运算符优先级：先执行等号右边的表达式，将执行结果赋值给左边的变量
  • 注意以下代码
  1. byte i = 10;
  2. i += 5; 等同于： i = (byte)(i + 5);

  4. int k = 10;
  5. k += 5; 等同于： k = (int)(k + 5);

  7. long x = 10L;
  8. int y = 20;
  9. y += x; 等同于： y=(int)(y + 5);
复制代码
  • 结论
扩展类的赋值运算不改变运算结果类型，假设最初这个变量的类型是
byte类型，无论怎么进行追加或追减，最终该变量的数据类型还是byte类型

  • 例题
  1. //基本的赋值运算符
  2. int i = 10;

  4. System.out.println(i); //10

  6. i = i + 5;

  8. System.out.println(i); //15
复制代码
  1. //扩展的赋值运算符【+= 运算符可以翻译为"追加/累加"】
  2. i += 5; //等同于: i = i + 5;

  4. System.out.println(i); //20

  6. i -= 5; //等同于： i = i - 5;

  8. System.out.println(i); //15

  10. i *= 2; //等同于： i = i * 2;

  12. System.out.println(i); //30

  14. i /= 4; //等同于： i = i / 4;

  16. System.out.println(i); //7

  18. i %= 2; //等同于： i = i % 2;

  20. System.out.println(i); //1
复制代码
  • 错误示范/改正
  1. //10没有超出byte取值范围，可以直接复制
  2. byte b = 10;
  3. //b = 15; //可以，编译通过，15没有超出byte取值范围
  4. //编译错误，为啥呢？
  5. //编译器只检查语法，不运行程序，编译器发现b + 5 的类型是int类型，b变量的数据类型是byte
  6. //大容量向小容量转换，需要加强制类型转换符，所以以下类型编译报错
  7. //b = b + 5;

  9. //纠正错误
  10. b = (byte)(b + 5);

  12. System.out.println(b); //15
复制代码
  1. byte x = 10;
  2. x += 5; //等同于x = (byte)(x + 5); 其实并不等同于： x = x +5
  3. System.out.println(x); //15

  5. byte z = 0;
  6. z += 128; //等同于 z = (byte)(z + 128);
