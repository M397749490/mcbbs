               一些废话

                 相信玩过高级太阳能和重力装甲的都知道，自工业2实验版更新到800以上版本后，高级太阳能的MT核心就无法在合成
        那么楼主给大家搬来一个很好解决这个问题的mod，有人会说可以用NPC,MT3来修改合成，嗯是的，相对于MT3
                 合成修改此mod不需要你手动编辑文本，不需要像NPC一样开创造修改合成，你只需要安装它就能在生存模式中进行使用

                  原文介绍
                  I got bored with all the issues with Gravisuite and Advanced Solars having broken recipes, and although there are many ways to fix them,
             there are other underlying issues in Gravisuite like most of the items having broken localisation, it hacking it's way to get key bindings  
          instead of using the rather convenient IC2 API functions and the missing texture issue of block_side.png.png. It was good enough as
time as any to use ASM, so I made a "simple" one class mod to fix them.
