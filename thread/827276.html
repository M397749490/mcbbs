怎么让怪物在被打之前一直站在原地不动被打了之后才会攻击目标?还有怎么设置怪物活动范围
作者: MC_Shenfeng    时间: 2018-11-2 21:27
将怪物摸版设置为僵尸猪人(pigzombie)
如果需要更改怪物模型请安装联动Disguise插件(前置请去帖子找)
这里是mmWiki
例子
怪物1:
  Mobtype: PIGZOMBIE
  Display: '&c???'
  Health: 100
  Damage: 100
  DamageModifiers:
  - BLOCK_EXPLOSION 0
  - ENTITY_EXPLOSION 0
  - FALL 0
  Disguise:
    Type: player #这里列举的是伪装为玩家的怪物
    Player: '&c???'
    SKIN: 正版ID
-
关于活动范围需要运用刷怪点
给刷怪点加个leashrange
例子:/mm s set xxx leashrange 5
这个刷怪点刷的怪只能在5格内移动
