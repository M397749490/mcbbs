插件配置
ResNames:#设置开启辐射的领地名字,玩家在此领地内将会有辐射影响
  - 'a'
tick: 20#玩家每隔多少tick上升1辐射值,20tick=1秒
PlaySound: true#上升辐射值时是否有声音提示
MaxPoint: 100#辐射值最大值,到达最大值将死亡
KillMsg: 'none'#死于辐射后提示的消息,none为不提示
Scoreboard:
  Enable: false#是否开启计分板显示
  title: '&aInfo'
  text: '&cPoints:'
item: #辐射物品设置,可以按照此格式创建多个物品!
  普通抗辐射药丸:
    type: 'pill'#辐射物品类型,现在只能使用 pill药丸
    name: '&a普通抗辐射药丸'#物品名字
    id: '337'#物品id 支持副id 如'397:3'
    lore:
      - '&e食用后减少20辐射值'#物品lore
      - '&7这里是卖萌的第二行233'
    value: 20#使用后降低的辐射值
    msg: '&a你的辐射值减少了20,当前辐射值为: %value%'#使用后的消息提示
  高级抗辐射药丸:
    type: 'pill'#辐射物品类型,现在只能使用 pill药丸
    name: '&6高级抗辐射药丸'#物品名字
    id: '337'#物品id 支持副id 如'397:3'
    lore:
      - '&e食用后减少50辐射值'#物品lore
      - '&7这里是卖萌的第二行233'
    value: 50#使用后降低的辐射值
    msg: '&a你的辐射值减少了50,当前辐射值为: %value%'#使用后的消息提示
#########################################
#以下未启用
########################################
  Helmet:
    type: 'armor'
    name: '&aHazmat Helmet'
    id: 298
    lore:
      - '&eThis is very useful'
    SlowMultiples: 2


插件指令
/fs 查看帮助
/fs info 查看自己的辐射信息
/fs set <玩家名> <辐射度> 设置玩家的辐射度
/fs add <玩家名> <辐射度> 增加玩家的辐射度
/fs give <玩家名> <物品名> <数量> 给予玩家物品
/fs list 列出物品名列表
/fs reload 重载配置
