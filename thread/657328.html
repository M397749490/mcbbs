SwornGuns
SwornGuns可以为原版Minecraft服务器拥有枪械，它可以让你把正常的物品变成厮杀枪械，无论是火焰喷射器，火箭筒，狙击抢，或步枪！只要SwornGuns你就可以抛弃那卡顿枪械MOD。并且SwornGuns是完全完成免费的一款插件。

用途
权限

/swornguns reload

-== 特点 ==-
使用普通的Minecraft物品模拟枪
使用普通的Minecraft物品模拟弹药
使用普通的Minecraft的物品，以模拟手榴弹等
可定制的弹药类型
可自定义枪的声音
枪升级
爆头
所有的枪是完全可自定制的
和更多功能！
这个插件支持大多权限插件，如果枪需要权限，该枪的权限节点是：
例：
机枪=“swornguns.fire.machinegun”
猎枪=“swornguns.fire
SwornGuns有一种影响类型的选择。
radius,time(ticks),effect
radius,time(ticks),effect,datavalue
因此，燃烧效果：
play_effect_on_release=4,200,MOBSPAWNER_FLAMES
默认情况下，SwornGuns有4枚手榴弹类型（手榴弹/闪光/燃烧弹/烟雾弹）。烟雾弹和燃烧弹（在配置）显示的例子说明了如何使用配置的影响。可以在这里找到的影响列表

关于UltimateArena这款游戏插件

大家可以发现UltimateArena建号一个游戏房时有各种职业的默认武器会有一些锄头，粘液球啥的后来我看了一些原贴发现他的武器支持插件刚好就是这款SwornGuns插件，然后我发现MCBBS竟然没人搬运然后就…

我自己刚刚研究了一下枪械文本内容如下：
  1. gunName=&e双筒猎枪       #枪的名字
  2. -------
  3. gunType=269                       #枪类型
  4. ammoType=295                  #弹药类型
  5. ammoAmtNeeded=1          #弹药AMT需要
  6. bullet Delay Time=14          #子弹延迟时间
  7. reload Type=PUMP            #重载型
  8. -------
  9. roundsPerBurst=2            #爆裂数
  10. bulletsPerClick=7             #每点击
  11. gunDamage=1                  # 枪伤害
  12. armorPenetration=1         #装甲穿透
  13. maxDistance=32               #最大距离
  14. bulletSpeed=3                   #子弹速度
  15. accuracy=0.25                    #准确率
  16. recoil=1                               #反冲
  17. knockback=1                      #击退
  18. -------
  19. canAim=false                    #可以瞄准
  20. explodeRadius=0             #爆炸半径
  21. explosionDamage=0       #爆炸伤害
  22. fireRadius=0                     #火灾半径
  23. canHeadshot=false          #可以爆头
  24. canClickLeft=true            #可以单击左
  25. canClickRight=false        #可以点击右
  26. --------
  27. outOfAmmoMessage=&6这把枪需要&c种子       #弹药耗尽的消息
  28. --------
  29. bulletType=SNOWBALL  #子弹类型
  30. gunSound=ghast fireball  #枪的声音
  31. needsPermission=true    #需要许可
  32. has SmokeTrail=true       #有烟特效
  33. --------
  34. has Clip=true                    #有夹
  35. max Clip Size=14             #最大剪辑大小
  36. reload Gun On Drop=true #重新装入枪
  37. reload Time=60               #重新加载时间
  38. --------
  39. localGunSound=false         #地方枪声
