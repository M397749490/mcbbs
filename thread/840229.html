VexTeam
—— 高端UI队伍系统，兼容归来 ——

声明：未经允许禁止转载
原创作者：inrh，Karlatemp

如果有问题，可以加群反馈：457600295


简介&功能
  • VexTeam是VexView的免费附属插件
  • 允许玩家自由组队
  • 加入队伍后左上角会显示个人HUD
  • 如果安装了BlueFriends插件，将会显示个人头像
  • 允许服主自定义队伍最大人数（现在支持无限人数）
  • 可以自定义开关经验分享/物品分享/队内免伤
  • 支持队伍传送以及勿扰模式
  • 支持了MySQL
  • 支持UUID存储方式
  • 支持自行添加队伍传送黑名单世界
  • 提供了API：https://inrh.coding.me/VexTeam/

安装方式
  • 务必使用VexView2.3及更高版本插件
  • 将VexTeam和MXBukkitLib（点击）插件放入服务端
  • 将贴图压缩包里的东西放入：.minecraft\vexview\textures
  • 启动服务器
  • 自定义配置


注意
  • 目前队伍状态头像只能显示自己
  • 关于经验共享，在 "expshare.percent" 中，如果为10，就分享了0经验，所以，你应该把它调更大的数字（推荐默认：20）
  • 如果有什么问题和建议，可以加群反馈

命令
  1. /team   #无需权限
复制代码
配置
  1. system:
  2.   # 是否以uuid模式储存数据
  3.   uuid: true
  4. mysql:
  5.   # 是否启用数据库存储
  6.   enable: false
  7.   # 数据库链接
  8.   # data_name为数据库名
  9.   sql: 'jdbc:mysql://localhost:3306/data_name'
  10.   # 存储玩家数据的表名，确保该表名不存在、不被占用
  11.   playerSql: 'playersql'
  12.   # 存储队伍数据的表名，确保该表名不存在、不被占用
  13.   teamSql: 'teamsql'
  14.   # 数据库用户名
  15.   root: 'root'
  16.   # 数据库密码
  17.   password: 'password'
  18. team:
  19.   # 一个队伍最大人数
  20.   max: 6
  21. teleport:
  22.   # 是否启用传送功能
  23.   enable: true
  24.   # 禁用传送功能的世界
  25.   disWorld:
  26.     - scworld
  27.     - end_www
  28. expshare:
  29.   # 是否启用经验共享功能
  30.   enable: true
  31.   # 经验分享的半径
  32.   radius: 10
  33.   # 经验分享的百分比（百分比越大，击杀者收益越少）
  34.   percent: 20
  35. itemshare:
  36.   # 是否启用物品共享功能
  37.   enable: true
  38.   # 物品分享的半径
  39.   radius: 10
  40. protect:
  41.   # 是否启用队内保护功能
  42.   enable: true
  43. gui:
  44.   # 队伍状态HUD的位置
  45.   # 左上角则填 1
  46.   # 左中边则填 2
  47.   # 右上角则填 3
  48.   # 右下角则填 4
  49.   position: 1
  50.   # 多少秒刷新一次HUD
  51.   time: 1
