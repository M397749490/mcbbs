为什么要使用这个插件？

它可以让你的地狱变得更加困难或者只是关闭一些指令在特定的世界。
可以禁止一些不必要的指令在特定世界输入！

我为什么要搬运这个插件？


在本站没有找到1.16.x的多世界命令禁止插件，然后我自己写了一个

代码比较乱，不太敢发出来。刚好在逛Spigotmc.org

的时候看到了这个插件。随后就进行了搬运！




指令
/cwl help 显示帮助信息
/cwl add <世界> <指令> 在某世界添加屏蔽指令
/cwl remove <世界> <指令> 移除在某世界屏蔽指令




权限

commandworldlimiter.world.<世界名> - 允许玩家绕过特定世界中的禁止
commandworldlimiter.world.* - 允许在所有世界使用所有禁止的命令
commandworldlimiter.command.add - 允许使用命令“/cwl add”
commandworldlimiter.command.remove - 允许使用命令“/cwl remove”
commandworldlimiter.command.* - 允许使用所有cwl命令
commandworldlimiter.* - 对该插件中的所有权限




配置文件

# 禁止命令列表。
forbidden_commands:   
"world":  
- /help  
"world_nether":   
- /something  
# 如果启用，玩家在进入世界后会得到一个被禁止的命令列表
info_to_player: true  
# 玩家尝试使用禁止命令后将收到的消息
command_forbidden_message: "&c你没有在这使用命令的权限."  
# 如果为真，则在切换世界后将显示该消息
info_forbidden_commands: "&e以下为你不能使用的指令。"  
# 限制显示给玩家的禁止命令数量。如果要显示所有命令，请使用-1
info_commands_max: -1
