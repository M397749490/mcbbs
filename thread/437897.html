RailMail -- 发送一个真正的邮件


这个插件可以做什么？
它取代了传统的邮件，它将真实的东西（书籍和邮箱）作为基础的邮件系统。（完刷Essentitals邮件系统）
-------------------------------------------------------------------------------------------------

它怎么来工作？
1.创建一个邮箱。（见图）



2.合成一些空邮件（书与笔），配方是不成形的，只是一个羽毛和一张纸。如果服务器启用了它，你也可以使用/mail
new去免费拿去一些空邮件。



3.写邮件。
写完的仅仅是一个便宜的书和笔，村民无法交易它。如果第一行是在[Subject:Test]，信的名字将是Test。


4.如果你喜欢的话，你可以添加附件。点击你想把你的附件再合成台里单击左键到邮件上。如果你想把附件放下来，拿起书与笔并右键单击合成栏内任何空槽。




5.将书的名字签名为 接收者 的名字

6.右击任何的一个邮箱（你的手上应该拿着邮件）

7.收件人将立刻或者是根据设置的时间收到邮件

8.收件人就可以阅读这封信并且提取附件（如有）

如果收件人的邮箱已满，这本书不会被发送，发送者会收到通知。


命令

/mail [page-number] 显示帮助[页]



/mail version 显示版本号



/mail new 给玩家一个新的空邮件（服务器如果开启）



/mail send（OP权限） 不用邮箱发送邮件



/mail bulksend （OP权限） 给所有在线玩家发送邮件



/mail spawn <mailbox|stationary>（OP权限）  快速的在邮箱里生成一封或几封邮件



/mail open [player]（OP权限） 打开[player]的邮箱





权限

只要给realmail.user.*的权限就可以了

附指令：   /mandaddp [组] [权限]   <Ess自带的权限插件>

怎么修改配置文件？




  1. dateformat: MM/dd/yy hh:mma zzz
  2. #邮件日期格式显示
  3. universal_mailboxes: false
  4. #玩家可以通过任意邮箱接收邮件（不是自己的）
  5. enable_attachments: true
  6. #玩家是否可以添加附件
  7. login_notification: true
  8. #在登录时显示是否有未接受邮件
  9. mailbox_rows: 2
  10. #邮箱大小排数（格） 一排有9格
  11. max_attachments: 4
  12. #最大的附件数量
  13. let_players_spawn_stationary: false
  14. #是否允许玩家用/mail new拿取空邮件
  15. lock_mailboxes: true
  16. #是否锁邮箱 如果锁定则只有创建它的人才可以打开
  17. prefix: "&f[&6Mail&f]"
  18. #所有消息的前缀，可以用&+颜色代码来改变颜色
  19. verbose_errors: false
  20. #是否消除Bug（自动更新？）
