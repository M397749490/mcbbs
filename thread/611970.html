这是一个能帮助广大服主解决手动刷末影龙的问题！
他有什么用呢？


  • 机制性让玩家自己刷新末影龙
  • 省去手动刷新末影龙，省去刷新末地
  • 可自定义刷新冷却时间
  • 更多.......


作者的原话：

A lightweight plugin created for my server (DireNode, thus the Dire before my plugins) to regulate the ender dragon.  When the ender dragon is killed, a message will be broadcasted to the server saying that it was killed, and by who, and a cooldown which can be set in the config (default to one hour) will start to count down. Once the cooldown reaches 0, any player can say /spawndragon and a new one will appear if they are in the end.  The ender dragon does not drop a portal, and instead the dragon egg and drops are inserted into the killer's inventory directly.




个人演示：



第一次击杀末影龙后。



此刻末影龙已经被消灭，末地空荡荡的，这个时候可以使用指令召唤（由于OP所以无视冷却时间，但玩家会受到时间限制！详细指令往下看~）




如图，当然玩家不可能做到，因为只有末影龙被击败后才会开始冷却倒计时，所以大可放心末地N头末影龙的情况！




指令


/spawndragon  ——在末地刷新一头末影龙
/dragoncooldown  ——查看当前冷却完毕的世界（时间到了就可以使用上面那个指令刷新末影龙了）
/forcedragon  ——强制生成一只末影龙（效果的话就和上面的第三张图片一样）
/setdragoncooldown 【冷却时间】  ——设置玩家刷新末影龙的冷却时间
/resetdragoncooldown  ——重置末影龙冷却时间（意思就是当玩家立马就可以使用/spawndragon刷新一头末影龙！慎用）


给玩家的限权

diredragon.spawn  ——玩家可以使用/spawndragon此指令
diredragon.cooldown  ——玩家可以使用/dragoncooldown查看距离可刷新末影龙的冷却时间








其他限权





diredragon.*  ——所有指令的限权
diredragon.forcespawn  ——强制刷新的限权
diredragon.setcooldown  ——设置冷却时间的限权
diredragon.resetcooldown  ——重置冷却时间的限权











配置文件

成功加载插件后会生成一个配置文件夹，里面只有一个config文件
cooldown: 0
Default Cooldown: 1h
Dragon Alive: true
First Run: true

cooldown:0

冷却时间，默认是以下面的那个【Default Cooldown】为标准。
若需要修改，请在后面带上时间单位的第一个字母在后面。
举个例子：
我想设置给玩家刷新末影龙的时间为1天，意思是1天可刷新一次末影龙。
就将【0】改成【24h】即可，若在游戏内可使用指令:
/setdragoncooldown 24h 即可
这样玩家在输入/dragoncooldown时就会发生变化。
注意：冷却时间是从末影龙被杀的那一刻起，才开始倒计时。
