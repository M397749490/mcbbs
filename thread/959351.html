-------------------------------------------------------------------------------------------

[功能/用途/展示]

+为你的RPG服务器添加更多自定义材质

+提供源码工作区，可自行配置功能，可拓展性强。

+理论上配合Mcr制作器可以无限拓展材质

[材质拓展教程][进阶]

在应用材质拓展教程时，您可能需要一定的mcreator基础，在论坛中有很多优秀的mcr教程帖子，请自行搜索查阅吧!

材质拓展的原理非常简单，我提供了模组的工作区、源码你只需要通过几个简单步骤即可自行添加/修改物品

1.下载并安装mcreator模组制作器 个人推荐1.9.1版本，最新版也行，但是1.12.2建议用这个

2.找一个你喜欢的位置：将工作区解压到你选的位置

3.打开mcreator1.9.1模组制作器，点第二个按钮，跳过更新提示，发现左上方多出一个rpgitemhelper的工作区

4.双击进入工作区，开始编辑

5.根据需要自行魔改，添加材质

6.后续更多精彩内容还在编辑...先发布了


[自定义武器大小]

这其实算是通用教程，因为在1.12.2（或者更前面的版本）可以通过json文件决定武器的大小，手持位置

虽然json机制为很多人带来不便，但如果你熟悉了这些参数+使用批处理 json就会成为你非常喜欢的一个机制

json文件是新版mc的特性，她决定了mc材质的引用路径，缺失json文件材质是不能正常显示的

json文件的位置:#用解压软件打开模组 ./assets/rpgitemhelper/models/item(block) 方块文件为block，其他为item

1.创建一个json文件/下载Rhelper配套的json生成器（下载地址看下方的[Json文件批量生成方法]）

2.将创建好的json文件命名为weapon[数字]

3.修改/添加物品代码

原版武器大小:

{

  "parent": "item/handheld",

  "textures": {

    "layer0": "rpgitemhelper:items/weapon"

  }

}

其他模组武器大小

在其他模组中如果你发现了一个武器的大小很合适，那么你可以打开查看

该模组的json并复制使用这个代码(依靠这个或许能复刻各种模组的武器(3D模型除外))

当然如果你熟悉mcr制作器，也可以给武器使用3d模型外观(但......时装工坊不香吗)

4.将编辑好的json文件扔入刚提到的路径覆盖，完成！
