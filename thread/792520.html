能不能在配置文件里面修改

你可以在Essentials文件的config.yml里面，禁掉烟花，一般服务器都有ESS的
# 当以下方块被放置或破坏,或物品被使用时会出现警告   # 你加载了一次Essentials后,就可以在plugins/Essentials/items.csv中找到物品ID列表.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶   alert:     on-placement: 10,11,46,327     on-use: 327     on-break:    blacklist:      # 阻止玩家放置以下方块     placement: 10,11,46,327      # 阻止玩家使用以下物品     usage: 327      # 阻止玩家破坏以下方块     break:      # 阻止活塞推动以下方块     piston:      # 阻止发射器发射以下物品 dispenser:

照着上面增加烟花的ID，就能禁掉了
