作者的话


AdminPlayerMenu is a plugin meant for the Server Owner to help out their staff learn/know every command they can execute to manage players, and make them learn quickly and easily with just one command!

本插件可以让腐竹轻松地了解玩家的信息，并操作与该玩家有关的指令！

使用方法(必看)
使用本插件前最好安装Essentials (废话，现在哪个服没有这个)
如果想要显示更多变量，必须安装PlaceholderAPI作为前置
安装好以后，可以下载相应拓展包，具体操作方法：

输入指令/papi ecloud download server
输入指令/papi ecloud download player
输入指令/papi ecloud download statistics
以上是一些基础的拓展包，以下再推荐几个常用的拓展包
经济插件变量/papi ecloud download vault
点券插件变量/papi ecloud download playerpoints
多世界插件变量/papi ecloud download multiverse
最后，重载插件/papi reload

所有变量可以在这里找到，添加更多变量！

安装好本插件后，可把下方两个汉化好的配置文件放入相应文件夹，并重启服务器
插件具体配置方法，参下方配置文件

如果用指令下载拓展包下载不了怎么办？

指令
- /admin - 打开在线玩家选择菜单
- /adminoffline - 打开离线玩家选择菜单
- /admin reload - 重载插件
- /admin search <玩家> - 寻找一个玩家的信息

权限
没必要看……默认OP操作就好
- adminplayermenu.use - 打开菜单
- adminplayermenu.search - 使用搜索玩家功能 "/admin search <玩家>"
- adminplayermenu.reload - 重载插件
