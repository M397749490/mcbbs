二。config设置

  1. version: 4.0.2
  2. options:
  3.   debug: true
  4.   hooking:
  5.     mcmmo: false（是否连接mcmmo插件）
  6.   give-mobs-names: false（给予怪物随机名字）
  7.   give-all-mobs-names: false（给所有怪物随机名字）
  8.   display-mob-equipment: true（显示怪物装备）
  9.   can-mobs-pick-up-equipment: false（怪物可以捡起装备）
  10.   blank-mob-spawn:（有关怪物出生设置）
  11.     enabled: false（是否开启）
  12.     skeletons-spawn-without-bow: false（骷髅出生不拿弓）
  13. multiworld:
  14.   enabled-worlds:（已经读取到的世界）
  15.   - world
  16. drops:（掉落物品设置）
  17.   item-chance: 0.25（物品掉落概率）
  18.   socket-gem-chance: 0.2（宝石掉落概率）
  19.   identity-tome-chance: 0.1（鉴定卷轴掉落概率）
  20.   custom-item-chance: 0.1（自定义物品掉落概率）
  21.   unidentified-item-chance: 0.1（未鉴定物品掉落概率）
  22. components:（其他组件设置）
  23.   creature-spawning-enabled: true（生物是否出生）
  24.   repairing-enabled: true（是否能够修理物品）
  25.   socketting-enabled: true（是否允许镶嵌宝石）
  26.   identifying-enabled: true（是否允许鉴定物品）
  27.   distance-zones-enabled: false（距离区域开启）
  28.   populating-enabled: false（不是很理解=。=）
  29. display:
  30.   item-display-name-format: '%generalprefix% %itemtype%'（物品显示名称！）

三。品质设定（核心）文件夹tiers

根据版本不同有些会以文件夹形式显示，有些则单独为tiers，yml。

这里给出我修改过的作参考

此处的文件名代表这个品质被读取的时候的名称，注意不是显示名称
  1. displayName: 优秀（品质的显示名称可中文）
  2. displayColor: BLUE（品质名称的颜色）
  3. identificationColor: DARK_RED （说明品质的项目颜色：可以忽略）
  4. enchantments:（附魔）
  5.   safeBaseEnchantments: true （保存基础附魔：指该品质下一定会出现的附魔项目）
  6.   safeBonusEnchantments: false（保存随机附魔：指该品质的随机附魔一定会出现，这块不要去动他动了就没有随机附魔的效果了）
  7.   allowHighBaseEnchantments: true（允许最大基础附魔）
  8.   allowHighBonusEnchantments: true（允许最大随机附魔）
  9.   baseEnchantments: []（基础附魔项目）

五。identifying。yml（鉴定卷轴设定）

  1. version: 4.0.0
  2. items:
  3.   identity-tome:
  4.     name: '&5Identity Tome'（鉴定卷轴显示名称可中文）
  5.     lore:
  6.     - '&7Right-click while holding'（鉴定说明可中文）
  7.     - '&7this to begin identifying!'
  8.   unidentified:
  9.     name: '&dUnidentified Item'（未鉴定物品名称可中文）
  10.     lore:
  11.     - '&7Find an &5Identity Tome &7to'（未鉴定说明可中文）
  12.     - '&7identify this item!'
复制代码
六。socketting.yml（宝石设定）
  1. version: 4.0.0-B
  2. options:
  3.   can-drop-socket-gems-on-items: false（是否允许从物品掉落宝石）
  4.   prevent-multiple-name-changes-from-sockets: false（有点复杂可以忽略）
  5.   use-attacker-item-in-hand: true（攻击物品允许在手中使用）
  6.   use-attacker-armor-equipped: false（攻击物品允许装备）
  7.   use-defender-item-in-hand: false（防御物品再手中使用）
  8.   use-defender-armor-equipped: true（防御物品允许装备）
  9.   socket-gem-material-ids:（宝石的id）
  10.   - DIAMOND
  11.   - EMERALD
  12.   - NETHER_STAR
  13. items:
  14.   socketted-item-socket: '%tiercolor%(Socket)'（凹槽显示名称可中文）
  15.   socketted-item-lore:
  16.   - '&7Find a &6Socket Gem&7 to fill a &F%tiercolor%(Socket)&7'（凹槽注释可中文）
  17.   socket-name: '&6Socket Gem - %socketgem%'（宝石名称可中文）
  18.   socket-lore:
  19.   - '&7Right-click while holding this gem'（宝石注释可中文）
  20.   - '&7in your hand to begin socketting!'
  21.   - '&8(&8%type%&8)'
复制代码
七。指令（搬运贴已给出，此处为复制为大家阅读方便）
/mythicdrops spawn (-a [数量]) (-t [品质]) (-mind [最低耐久] (-maxd [最大耐久]):给自己生成指定的物品
/mythicdrops gem [player] (-a [数量]) (-g [宝石]):给player指定的镶嵌宝石
/mythicdrops unidentified [player] (-a [数量]):给player封印的物品
/mythicdrops tome [player] (-a [数量]):给player物品解封符
/mythicdrops give [player] (-a [数量]) (-t [品质]) (-mind [最低耐久] (-maxd [最大耐久]):给player指定的物品
/mythicdrops custom [player] (-a [数量]) (-t [品质]) (-mind [最低耐久] (-maxd [最大耐久]):给player自定义物品
/mythicdrops customcreate [几率出现] [几率掉落]:生成一个自定义物品
/mythicdrops tiers:列出全部的物品品质
/mythicdrops modify name [物品名称]:修改手持物品名称
/mythicdrops modify lore add [描述]:添加手持物品描述
/mythicdrops modify lore remove [X行]:移除手持物品的第X行描述
/mythicdrops modify lore insert [X行] [描述]:为手持物品的第X行插入描述
/mythicdrops modify lore modify [X行] [描述]:修改手持物品第X行的描述
/mythicdrops modify enchantment add [附魔] [等级]:添加手持物品附魔
/mythicdrops modify enchantment remove [附魔]:移除手持物品附魔

八。具体操作实例以我的良好品质为例：
1.编辑你想要的品质
文件名：uncomonsa.yml
  1. displayName: 良好
  2. displayColor: GREEN
  3. identificationColor: DARK_RED
  4. enchantments:
  5. safeBaseEnchantments: true
  6. safeBonusEnchantments: false
  7. allowHighBaseEnchantments: true
  8. allowHighBonusEnchantments: true
  9. baseEnchantments: []
  10. bonusEnchantments:（随机的附魔）
  11. - DAMAGE_ALL:1:2（锋利1-2）
  12. - DAMAGE_UNDEAD:1:3（不死伤害1-3）
  13. - DAMAGE_ARTHROPODS:1:3（截肢伤害1-3）
  14. - FIRE_ASPECT:1:2（点燃1-2）
  15. - KNOCKBACK:1（击退1）
  16. minimumBonusEnchantments: 0（最小拥有附魔数量）
  17. maximumBonusEnchantments: 1（最大拥有附魔数量）
  18. lore:
  19. minimumBonusLore: 0
  20. maximumBonusLore: 0
  21. baseLore: []
  22. bonusLore: []
  23. maximumDurability: 0.5
  24. minimumDurability: 0.25
  25. minimumSockets: 0（最小拥有凹槽数）
  26. maximumSockets: 1（最大拥有凹槽数）
  27. chanceToSpawnOnAMonster: 0
  28. chanceToDropOnMonsterDeath: 1.0
  29. chanceToBeIdentified: 0.25（被鉴定出该品质的概率）
  30. chanceToHaveSockets: 0.3（拥有凹槽的概率）
  31. broadcastOnFind: false
  32. itemTypes:
  33. allowedGroups:
  34. disallowedGroups:
  35. allowedItemIds:
  36. - WOOD_SWORD（只允许木剑和木斧）
  37. - WOOD_AXE
  38. disallowedIds:
复制代码
我现在设置的是品质只能赋予木斧，木剑。他们最多拥有1个附魔最少为0，附魔项目有锋利1-2，不死1-3，截肢1-3点燃1-2，击退1.最多拥有1个凹槽，最小为0.且出现凹槽的概率为30%
2.输入命令/mythicdrops spawn  -a 10(数量） -t uncomonsa(这个是文件名称）
