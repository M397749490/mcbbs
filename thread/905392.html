LittleBanItem
小型物品禁用
判断材质、名称、lore、以及所在容器的物品禁用插件
无邪的插件交流群: 170032890

|

违禁物品判断逻辑流程:
首先基于材质名称判断
        判断: 如 'DIAMOND_SWORD' (钻石剑材质)，则判断所有钻石剑。
然后再对于物品名称模糊判断
        如果物品带有name也清理(del: false)处于关闭，先判断该物品是否在忽略清理的材质。
           然后判断物品名称是否违禁。
              模糊判断: 如物品名 '腐竹之剑'，则判断物品的名称是否包含 '腐竹之剑'这段文本。
然后再对于物品标签(lore)模糊判断
        物品带有lore标签也清理(del: false)处于关闭，先判断该物品是否在忽略清理的材质。
           然后判断物品标签(lore)是否违禁。
               模糊判断: 如物品标签包含 '攻击力 99999999'，则判断物品的标签是否包含 '攻击力 99999999'这段文本。
然后再对容器(一般是背包和箱子)进行总判断
        容器有自定义名称也清理(del: true)处于开启
           判断包含此物品的容器的自定义名称是否包含被忽略清理的关键字。
              模糊判断: 如容器自定义名称包含 '菜单'，则判容器的自定义名称是否包含 '菜单'。
        容器有自定义名称也清理(del: false)处于关闭，则跳过清理。


配置文件:
  1. itemHasNameDel:
  2.   # 物品带有name名称是否清理
  3.   del: false
  4.   # 当(del: false)时
  5.   # 忽略有自定义名称的物品的材质，既这种材质的物品即使有自定义名称也清理
  6.   # 这里不能模糊识别，需要精确材质名称
  7.   IgnoreMaterial:
  8.   # 命名牌(RPG服务器禁用)
  9.   - NAME_TAG
  10.   # 物品带有此类名称时，既包含这种名称的物品就被清理
  11.   IgnoreNames:
  12.   - '&4腐竹的测试武器'

  14. itemHasLoreDel:
  15.   # 物品带有lore标签是否清理
  16.   del: false
  17.   # 当(del: false)时
  18.   # 忽略有lore的物品的材质，既这种材质的物品即使有lore也清理
  19.   # 这里不能模糊识别，需要精确材质名称
  20.   IgnoreMaterial: []
  21.   # 物品带有此类标签时，既包含这种标签的物品就被清理
  22.   IgnoreStrings:
  23.   - '攻击力 9999999999'

  25. # 对应于materials的材质列表，然后会判断itemHasNameDel和itemHasLoreDel的条件。
  26. inventoryHasNameDel:
  27.   # 点击的背包有名称是否清理
  28.   del: true
  29.   # 当(del: true)时，既物品在有自定义名称的背包也清理
  30.   # 忽略有名称的背包名称 包含的词汇，既这物品如果在此类背包内就不清理
  31.   IgnoreNames:
  32.   # 可模糊识别
  33.   # '某某某菜单'
  34.   - '菜单'
  35.   # 有颜色，需要判断颜色
  36.   - '&a菜&b单'

  38. # 被服务器禁用的物品的材质名称
  39. materials:
  40. # 命名牌
  41. - NAME_TAG
  42. - ender_pearl
  43. # 命令方块矿车
  44. - COMMAND_MINECRAFT
  45. # 命令方块
  46. - COMMAND_BLOCK
  47. # 紫讼果
  48. - chorus_fruit
  49. # 紫颂花
  50. - chorus_flower
  51. # 红石
  52. - redstone
  53. message: "&c清理违禁物品 &4{0}"
