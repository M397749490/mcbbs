既然防止爆炸，那么米二就先把知道的爆炸相关的参数都提一下：

1：UU机爆炸为电压问题：
; If you really really really don't want to have your machines explode if you don't pay attention to voltage, you can disable that here.
enableEnetExplosions = true
; Same for cable meltdown
enableEnetCableMeltdown = true

其中，enableEnetExplosions = true的值改为false，可避免电压问题造成的机器爆炸（如你所说的UU机爆炸）；
其中，enableEnetCableMeltdown = true的值改为false，可以避免电压问题造成的烧导线问题。


2：核反应堆爆炸和核弹爆炸
; Maximum Explosion power of a nuke, where TNT is 4.
nukeExplosionPowerLimit = 1
; Maximum explosion power of a nuclear reactor, where TNT is 4.
reactorExplosionPowerLimit = 1
; Enable the nuke
enableNuke = true

上面字段nukeExplosionPowerLimit是核弹的爆炸范围，设置为0为仅破坏自己；
reactorExplosionPowerLimit是反应堆爆炸范围，设置为0为仅破坏自己（相当于反应堆内部的部件随之销毁）；
enableNuke 是否启用核弹（建议设置为false）。


最后，考虑到安全问题，请在配置完成后，重启游戏并坚持这些更改是否奏效！
