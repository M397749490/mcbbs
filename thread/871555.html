正文前先声明：）
本文主要是借ShiChunAn 大大在18年8月的两次末影之眼定位要塞的方法，因考虑到许多年幼玩家并没有接触到矩阵和参数方程，所以特此推出一次函数联立方程（初中就会学）的方法，未经许可不得以任何形式转载
注意：如有意游览原帖，请戳链接 http://www.mcbbs.net/thread-799313-1-1.html 顺带一提，本文中所提到的‘坐标’只记录x和z坐标，不包括y坐标

一、原理：

在我的世界中，所有的物品实体都有一个记录它当前状态的xyz坐标
万物的坐标穿连到一起形成了一个坐标系，我们可以将它想象成平面直角坐标系，进行函数计算。众所周知，两点确定一条直线，如果两条直线不平行，那它们一定会相交。我的世界中的末影之眼会沿一条直线向最近的终界要塞飞去，它的飞行路线就是一条直线，如果我们确切知道两条末影之眼向同一个终界要塞飞去的路径，就可以通过函数联立求点坐标的方式获取要塞的大体坐标。

#include<cstdio>
#include<algorithm>
using namespace std;
double b[2];
bool bs=false;
double find_k(int x1,int y1,int x2,int y2)
{
        return (y2-y1)/(x2-x1);
}
void find_jiexishi(int x,int y,double k)
{
        if(bs==false){
                double t=k*(double)x;
                b[0]=(double)y-t;
                bs=true;
        }
        else{
                double t=k*(double)x;
                b[1]=(double)y-t;
        }
}
void liefangcheng(double k1,double k2)
{
        int x=(b[1]-b[0])/(k1-k2);
        int y=k1*x+b[0];
        printf("最终结果：P（X:%d, Y:%d）",x,y);
}

四、关于误差：

是的，这一个定位要塞的方法误差是很大，产生这么大误差的原因有以下几点：

1.不得不说，这个方法确实没有前人所做的三角函数和间析的方法好，这个方法纯粹是暴力暴算，硬求解析式，所以误差大点是难以避免的，但你经不住它简单不用动脑子啊。说实话，这个方法确实适用于那些数学基础差的玩家。

2.没有用小数计算。在我的世界中每个坐标都有保留三位小数，这个方法并没有将小数也罗列进去，这导致算出来的函数斜率会有细微偏差，再加上本来末影之眼掉落的坐标也不准确，有误差就无法避免了。

3.在我编写这个方法的c++程序时，没有用高精度的加减乘除，所以假如你所在的地方太过偏僻，计算的数值可能会超过int的存储空间，简单来说就是电脑编程软件放不下这么大的数了，这可能会导致答案的出错。

4.
这套程序还有一个弊端，就是在做除法时我是直接把结果强转成小数存的(如下文)，所以会有计算误差，如果有哪些c++巨佬看到了我的“不合格”的代码，可以尝试自己修改一下，或者就等我慢慢更新吧。
double find_k(int x1,int y1,int x2,int y2)
{
return (y2-y1)/(x2-x1);
}

{
if(bs==false){
double t=k*(double)x;
b[0]=(double)y-t;
bs=true;
}
else{
double t=k*(double)x;
b[1]=(double)y-t;
}
}
