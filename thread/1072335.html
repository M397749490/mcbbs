不是，是把玩家的最大生命值记录在计分板上，不管玩家当前生命值有没有达到最大血量，显示玩家目前的血量 ...

1.16版本中
/attribute @p minecraft:generic.max_health get可以获取玩家的最大生命值
使用execute的store子命令即可存储在计分板中
/execute store result score 玩家id 计分板名 run attribute @p minecraft:generic.max_health get
注:attribute只允许单个目标，如果想做到多人可以使用execute
