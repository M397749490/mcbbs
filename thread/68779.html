简介：WorldEdit是一个在游戏内操作简便的世界编辑器，支持单人以及多人模式，其中：
单人版为Single Player Commands（单人命令Mod）以及Single Player Console（单机控制台Mod）直接包含；
多人版为CraftBukkit、CanaryMod、Spout的WorldEdit插件。

利用WorldEdit你可以：
  • 一次性改变选定区域内的千百万种方块
  • 超过一百种方法来改变世界或者修复问题
  • 移走你想移走的大量chunks
  • 用刷子雕刻世界以及修建山脉
  • 修复难看的地方例如：被破坏的不平的水，遗失的雪地，大量的火等等

概述
一、Sessions[注1]
当你选定一个区域，或者改变了某些参数的时候，你的信息将会被传到一个临时的session，处于登录状态的时候这个session将一直存在，离线之后十分钟，这个session将会被移除，而十分钟内将继续保留。不同用户的session是不一样的。
Session所包含的内容：
1.  你当前的选择区域
2.  你的历史操作记录
3.  你操作方块的最大限制
4.  你选区域的信息记录，供恢复操作使用

注1：session计算机用语，实在不适合被翻译

二、历史记录
所有的操作都被保存在你的历史记录里面，一共可以记下最新的15次操作，这个记录包含了之前的方块和新的被WorldEdit改变过的方块。如果想恢复改变之前的状态，输入//undo来执行这项操作。如果你恢复之后又改变了注意，你可以输入//redo来重复之前的操作
如果希望清除操作历史，你可以输入/clearhistory指令

注2：区域选定相关的操作（如选定一个顶点）不属于方块操作，不属于历史记录的一部分

三、方块支持
方块支持指的是是否支持方块所包含的所有信息，例如支持箱子代表的是是否包含箱子里的物品，当进行移动，复制粘贴等操作的时候，箱子里的物品是否被移动，复制粘贴。

方块种类 单人 水桶 是否支持的具体说明
箱子 否 是 箱子内的物品
熔炉 否 是 熔炉燃料以及产物
炼药锅 否 是** 炼药锅中的水
附魔台 否 是** 附魔台中的物品
酿造台 否 是** 酿造台中的原料产物
刷怪笼 否 是** 不同的刷怪种类
音符盒 否 是 音符盒当前音调
激活的活塞 否 是**活塞是否依然激活
唱片机 否 是** 唱片机中的唱片
木牌 否 是 木牌中的文字
发射器 否 是 发射器中的物品
末地传动门框架 否 是** 框架中的末影之眼
其他的方块 是 是 其余的所有原版方块
** 代表的是5.4版本以后才加入的支持


四、物品支持
只要是支持对应方块，那么里面的物品是都可以支持移动复制粘贴等操作的
