标题: 所有权限在Multiverse-Core新生成的世界里失效
给默认权限组设置的权限在本来就有的主世界、领地世界都能使用，我新生成了一个资源世界之后，所有权限（包括CC菜单、sethome这种权限全部失效），只有/spwan能用了 = = 请问怎么解决
作者: little_xi    时间: 2019-12-18 15:12
把权限插件里面的世界设置调整一下
把父世界里面权限加给子世界
默认生效权限在 world，找到子世界一项在里面添加你所要添加的世界
例如在GroupManager插件里面的config文本有一项
  mirrors:
        # 多世界设置,世界列表中子世界将参照父世界的设置.
        # 第一个世界 'world' 是主世界名称
        # 子世界 'world_nether' 和 'world_the_end' 将会
        # 与父世界使用相同的玩家/用户组文件.
        # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
        # all_unnamed_worlds将会使用所有未定义的世界
        world:
          name:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
这里的name就是子世界意思
作者: Nnnnerd    时间: 2019-12-18 15:39
已解决，是GroupManager的镜像问题，使用mv创建新世界后权限没有自动镜像，进入GroupManager的配置文件-worlds文件夹-world-复制groups和users两个yml，覆盖到worlds里新创建的世界的文件夹内就行
