2015-10-6更新：汉化已提交原作者，Bukkit原版自带汉化！

*特♂性*
用图形界面管理你的队伍（好友）
好友聊天室 ( 可禁用 )
加入/退出信息 ( 可禁用 )
好友传送 ( 可禁用 )
UUID支持

*指♂令*
/friends add [玩家] ---------- 添加好友
/friends remove [玩家] ---------- 移除好友
/ friends accept ---------- 同意好友请求
/friends deny ---------- 拒绝好友请求
