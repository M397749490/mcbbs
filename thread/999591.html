配置文件:




  1. #作者Diry UHC爱好者 默认编码为UTF-8 乱码的话请自行转码 MCBBS UID1430569 有问题可以询问

  3. #武器[安德鲁]的名字 加颜色例子: §a安德鲁{下面的消息提示同样}
  4. ItemName: "§a安德鲁"

  6. #权限[在DefaultGive设置为false的时候开启]
  7. GivePermission: anduril.give

  9. #玩家是[true]/否[false]有权限获得武器
  10. DefaultGive: true

  12. #如果玩家没有权限，将会显示
  13. NoMessage: "你没有anduril.give权限"

  15. #如果玩家使用了/Anduril reload指令 并且他不是op 会提示
  16. NoOpReload: "你不是op"

  18. #op才能看anduril指令列表
  19. Oplook: false

  21. #药水效果倍率 0为默认  Speed是速度药水 Kang是抗性提升
  22. Speed: 0
  23. Kang: 0

  25. #是否开启合成
  26. Recipe: true

  28. #是否开启合成权限
  29. RecipePermission: true
  30. #合成权限
  31. RecipePermissionSet: adl.qx
  32. #玩家没权限合成提示
  33. RecipeMsg: "你没有权限合成"
复制代码
