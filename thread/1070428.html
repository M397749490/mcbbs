下面是apple.json的
  1. {
  2.   "parent": "item/generated",
  3.   "textures": {
  4.     "layer0": "item/apple"
  5.   },
  6.   "overrides": [
  7.     {
  8.       "predicate": {
  9.         "custom_model_data": 1
  10.       },
  11.       "model": "neverlag:auto_generated/orange"
  12.     }
  13.   ]
  14. }
复制代码
这样就可以将apple{CustomModelData:1}的材质替换成orange的了
