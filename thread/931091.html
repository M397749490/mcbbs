关于Residence问题



A：圈地被限制了大小怎么办？？？
B：在服务器文件夹找到"Residence"文件夹打开之后找到"groups.yml"右键打开找到：
Groups:
    Default: #组名，不要删除这个组
       #删除下面的井号可将此配置应用到其他组
       #Mirror:
         #- 'group1'
         #- 'group2'
       Residence:
           # 该组玩家是否可以创建领地
           CanCreate: true
           # 玩家可以拥有的最大领地数量
           MaxResidences: 3
           # 领地可包含的最大物理区域
           MaxAreasPerResidence: 2
           # 领地最大格数（东西方向）
           MaxEastWest: 16
           # 领地最小格数（东西方向），设为-1则不限制
           MinEastWest: 3
           # 领地最大格数（南北方向）
           MaxNorthSouth: 16
           # 领地最小格数（南北方向）
           MinNorthSouth: 3
           # 领地最大格数（高度）
           MaxUpDown: 256
           # 领地最小格数（高度），设为-1则不限制
           MinUpDown: 3
           # 可创建领地的最小高度
           MinHeight: 0
           # 可创建领地的最大高度
           MaxHeight: 255
           # 所在区域可拥有的最大子领地数量
           MaxSubzonesInArea: 3



A：进入和离开领地的语句怎么改？？？
B：/res message [领地名] [enter/leave] [信息] - 设置进入/退出某领地时候显示的信息
enter是进入
leave是离开



A：玩家怎么设置一些领地内的权限呢？比如不让某某某玩家进入.
B：原贴不是有吗?为什么还要问啊
/res pset [领地名字] [玩家ID] [权限] [true/false]
权限列表：(更多的请至原地查看)
container：是否能使用箱子，发射器等
bucket：设置是否能使用桶
ignite：点火的权限
piston：活塞是否能使用
build：建造权限（包括destroy和place）
destroy：毁坏权限
place：放置权限
move：进入权限
tp：传送权限
use：使用权限（工作台，炉子等）
subzone：是否能设置子空间
tnt：设置tnt是否有效
creeper：设置JJ怪是否有效（设置F的话JJ怪就废了）
damage：设置领地内是否能造成伤害（不能防止被挤死）
monsters：设置是否刷新怪物
animals：设置是否刷新动物
firespread：火是否能蔓延
flow：液体流动，包括waterflow和lavaflow
waterflow：水的流动
lavaflow：岩浆流动
healing：设置是否能恢复生命
pvp：设置是否能pvp






关于ChestCommands问题



A：为什么我编辑好的两个菜单放入服务器后，从第一个菜单点击打开第二个菜单，但他会瞬间关闭？？？
B：我举个例子：
TreeDiagramB2:
  NAME: ''
  ID: 160
  DATA-VALUE: 4
  KEEP-OPEN: true
  POSITION-X: 2
  POSITION-Y: 2
对比一下是不是发现和你的有所不同，其实解决办法很简单
在你的菜单DATA-VALUE:XXX下面加上KEEP-OPEN: true就可以了！
还是不会的话，我给个文件你当做查看：
菜单.yml (7.67 KB, 下载次数: 0)

点击文件名下载附件



A：为什么玩家打不开菜单呢？？？
B：那是因为有可能你没有给予玩家权限，给予下面两个权限即可.
/mangaddp [玩家所在的组] chestcommands.item.[你菜单的名字].yml
/mangaddp [玩家所在的组] chestcommands.open.[你菜单得名字].yml
使用/list即可查看所在的组
例子：
比如我的菜单文件名是[菜单] 玩家所在的组是[builder] 那么我就这样：
/mangaddp builder chestcommands.item.菜单.yml
/mangaddp builder chestcommands.open.菜单.yml






关于PlotSquared的问题



A：怎么多给玩家一个地皮
B：给予玩家权限：/manuaddp [玩家] plots.plot.2



A：请问要怎么自定义地皮世界呢？
B：我好想记得原贴上写有教程吧....
/plot setup
/plot setup PlotSquared
/plot setup default
/plot setup 64
/plot setup 54
/plot setup 3 [地皮下面的方块可自定义]
/plot setup 2 [地皮表面的方块可自定义]
/plot setup 44 [没认领地皮前的围墙]
/plot setup 44:1 [认领地皮之后的围墙]
/plot setup 42 [路面宽]
/plot setup 64 [路面的高度]
/plot setup 155 [路面的方块]
/plot setup 1 [墙下面的方块]
/plot setup 64 [墙的高度]
/plot setup true/false [是否开启基岩]
/plot setup [地皮世界的名字注意不能使用中文]



A：无法在地皮使用箱子商店怎么办？？？
B：关于这个问题站内已有解决办法
打开PlotSquared再打开config然后找到worlds.yml打开，找到下面这几行然后改成这样就可以了
  flags:
      use: 63,68,130,323
      break: 323,130



A：要怎么修改进入地皮后屏幕中央显示的文字？？？
B：找到PlotSquared文件夹打开找到translations再扎到PlotSquared.use_THIS打开
然后再文件内容内找到
titles:
  title_entered_plot: $1地皮世界
  title_entered_plot_sub: $4该地皮主人 %s
  prefix_greeting: '$1%id%$2> '
  prefix_farewell: '$1%id%$2> '






关于authme的问题



A：玩家注册上限怎么办？？？
B：打开aunthme文件夹找到config.yml文件然后打开找到[maxRegPerIp: 1] 1的意思就是同一个IP只能注册一个账号.






关于一些其他的问题



A：怎么设置一个世界禁止挖矿呢？？？
B：关于这个问题有很多解决办法，我在这里只列举一个(权限解决)
/mangaddp builder -essentials.build.break.1
解释： [builder]指玩家所在的组     [-essentials.build.break.1]禁止玩家破坏方块[1]就是不能被破坏方块的id

关于Multiverse-Core问题



A：为什么我创建一个世界后进去聊天发现世界名是乱码的？？？
B：在创建一个世界时不能使用中文名.
错误例子：/mv create 生存世界 normal [×]
正确列子：/mv create scsj normal [√]



A：创建一个世界后怎么把世界名字改成中文名？？？
B：找到Multiverse-Core文件夹再找到worlds.yml打开
  1.   world:#你创建世界时的名字这个不能改
  2.     ==: MVWorld
  3.     hidden: 'false'
  4.     alias: '&6&l主城'#在这里改成你想要改的名字
  5.     color: WHITE
  6.     style: NORMAL
  7.     pvp: 'false'
  8.     scale: '1.0'
  9.     respawnWorld: ''
  10.     allowWeather: 'true'
  11.     difficulty: EASY
