[ JustEnoughIDs (JEID) - ID上限增加 ]

简介 - 翻译自 CurseForge 主页原文
这个模组通过在 1.12 的游戏中使用 1.13 的区块格式，解除方块、物品、生物群系、药水和附魔 ID 的上限限制。
准确地说，这个模组在将区块存储到 NBT 时使用了一个方块状态调色盘（blockstate palette），同时使用了一个 int 整型的生物群系数组，而不是一个 Byte 数组。
这个模组不会与其他模组出现太多的不兼容问题，但是如果你发现有模组和这个模组不兼容，请到 这里 反馈。
与 NotEnoughIDs 模组不同，加了这个模组之后，你仍然可以删掉其他模组，不会引起存档损坏。
JustEnoughIDs is a lightweight mod that removed the block, item, biome, potion, and enchantment ID limits by using the 1.13 chunk format in 1.12.
More specifically, it uses a blockstate palette when saving chunks to NBT, and uses an int biome array rather than a byte biome array. There should be very few incompatibilities with other mods, but in case you find one, please report it to the issue tracker. Unlike NotEnoughIDs, removing a mod is supported, and won't cause corruption of the worlds created with that mod.

特别需要注意的是，如果删掉这个模组，就会损坏你的存档。这个模组也不能代替 NotEnoughIDs，更多细节请看 FAQ 部分。
Extremely important: Removing JustEnoughIDs will break your world. It is equivalent to loading a 1.13 world in 1.12! JustEnoughIDs cannot load NotEnoughIDs worlds, see the FAQ for more details.



[ FAQ - 常见问题 ]

这个模组和其他模组兼容吗？
JustEnoughIDs 和失落之城（The Lost Cities）模组目前是不兼容的，希望下个版本能兼容。
然而，因为 1.12 生物群系的数组的原因，某些模组可能需要额外的自定义支持。例如，某个生物群系可能在 F3 调试屏幕中显示
  1. "Mod doesn't support extended biome IDs -- Report to JEID"
复制代码

或某些命令不能正常地使用。地形生成模组是支持的，所以不会出现生物群系 ID 的变动。
如果遇到这种情况，请向作者反馈。

安装 JEID 之后，旧的存档还能玩吗？
可以。只是新的区块会以 1.13 的格式加载了。

可以把安装了 NEID 的存档转换成 JEID 的存档吗?
目前暂时不能。但是，同时使用 NEID 和 JEID 是可以的。这种情况下 JEID 对方块和物品 ID 的修复功能将被禁用，由 NEID 来解决，只有生物群系的 ID 限制将被解除。这样，你使用 NEID 的旧存档就仍然可以用，同时还可以增加足够多的群系。

这个模组会损坏我的存档吗？
不会。
