插件介绍

可以使用FlightControl选择，可以在categories.yml中配置，也可以给玩家权限
可以控制玩家是否可以飞行
  • 世界
  • 区块
  • 地形，地区类型
  • 战斗中
  • 其他玩家的范围中
  • 国土（Lands）
  • 领地（GriefPrevention）
  • 城镇（Towny）
  • 所有东西都可以命名
  • 临时飞行
  • 飞行速度（全服和个人）
  • 掉落保护
  • 自动更新（可以不用动config.yml）
  • 自动加载配置（可以不用不断重载插件配置）
  • 游戏中 config 文件设置（用指令）
  • 自定义声音
  • 插件自带汉化文件！

插件指令&权限
指令
  • /flightcontrol - 查看插件所有指令
  • /flightcontrol actionbar - 启用/关闭操作栏发送消息
  • /flightcontrol autoenable - 启用/关闭自动飞行
  • /flightcontrol autoupdate - 启用/关闭自动更新
  • /flightcontrol combat - 启用/关闭战斗禁止飞行
  • /flightcontrol enemyrange <range> - 设置怪物攻击范围内禁止飞行
  • /flightcontrol falldamage - 启用/关闭掉落伤害
  • /flightcontrol reload - 重载插件
  • /flightcontrol speed (0-10) - 设置飞行速度
  • /flightcontrol trails - 开启/关闭飞行轨迹粒子
  • /flightcontrol update - 更新 flightcontrol 插件
  • /flightcontrol vanishbypass - 开启/关闭隐身时飞行失效

权限
  • flightcontrol.admin - 使用 FlightControl 管理指令 (默认op)
  • flightcontrol.bypass - 无视所有飞行限制
  • flightcontrol.category.CATEGORY - 根据类型控制飞行
  • flightcontrol.flyall - 在未禁用的所有区域飞行
  • flightcontrol.flyspeed - 设置飞行速度
  • flightcontrol.flyspeed.others - 设置其他玩家飞行速度
  • flightcontrol.tempfly - 可以临时飞行
  • flightcontrol.tempfly.others - 可以给其他玩家临时飞行
  • flightcontrol.fly.WORLDNAME - 在指定世界飞行
  • flightcontrol.fly.WORLDNAME.REGIONNAME - 在指定区块飞行
  • flightcontrol.nofly.WORLDNAME - 禁止指定世界飞行
  • flightcontrol.nofly.WORLDNAME.REGIONNAME - 禁止指定区块飞行
  • flightcontrol.nearbypass - 跳过 "nearby_disable" 检查权限
  • flightcontrol.towny.own - 在自己的城镇中飞行 (Towny)
  • flightcontrol.lands.own - 在自己的国土上飞行 (Lands)
  • flightcontrol.lands.trusted - 在信任的国土上飞行 (Lands)
  • flightcontrol.claim.own - 在玩家的领地上飞行 (GriefPrevention)
  • flightcontrol.claim.trusted - 在信任的领地上飞行 (GriefPrevention)
