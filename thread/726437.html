Not Ai Mobs
简介：一个小插件，可以让你的服务器里的怪物不对玩家进行攻击，就像动物那样变成被动的生物。

命令：/notaimob 列出各个怪物的配置情况，相当于把config.yml复制过来。

配置：
artificialintelligence:
  msg:
    title: '&6NotAiMobs: '  //上图中第一行（标题）。
    cont: ' &6%NUMBER%. &e%MOBS% &7| &f%VALUE%'  //每一行的文字，%NUMBER%为编号，%MOBS%为怪物种类，%VALUE%为true或者false，不要改这三个变量。
  disableAll: false    //是否让所有怪物都不进行对玩家的攻击？
  mobs:
    zombie: true  //是否让僵尸不攻击玩家，下同。
    skeleton: true //骷髅  
    creeper: true  //苦力怕
    spider: true  //蜘蛛
    blaze: true  //烈焰人
    slime: true //史莱姆
    cavespider: true  //洞穴蜘蛛
    magmacube: true //好像是岩浆怪？
    silverfish: true  //蠹虫（第一眼以为是鱿鱼还大吃一惊）
