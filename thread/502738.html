Simplebackpacks——简单的指令背包



simplebackpacks是最简单而又最好用的背包插件
只需要把它上传到你的plugins，并给你的用户权限节点，就可以愉快的玩耍了



那么先简单的介绍一下功能
                          -使用指令打开自己的背包
                          -管理员可以用指令查看他人背包
                          -管理员可以设置是否死亡清空玩家的背包
                          -管理员可以设置死亡物品是否掉落到地上
                          -背包大小基于一个简单的权限节点

然后唯一一个指令：/backpack (player)
使用就可以打开自己的背包了，管理员可以打开其他人的背包

权限节点：
权限节点说明
backpack.use 使用指令打开背包
backpack.use.other使用指令打开别人的背包
backpack.exempt.empty-on-death有这个权限死亡不清背包
backpack.limit.X背包行数，X可为1-6行

默认配置：
# Enable debug info in console
debug-mode: false
# Enable colors in console output
color-logs: true
# Should the user's backpack empty to the ground when they die?
# A false value will leave the player's backpack contents alone.
empty-backpack-on-death: false
# If empty-backpack-on-death is true should we drop the items to the ground?
# A false value will just make the backpack items disappear.
drop-backpack-items-on-death: false
