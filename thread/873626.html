介绍 · Introduction

这款插件是原Builder插件的分支插件!
所有知识产权归jrbudda 所有
原插件链接: https://dev.bukkit.org/projects/builder-citizens2

插件版本:
- spigot 1.8: 1.0.2
- spigot 1.11: 1.0.4
- spigot 1.12: 1.0.6
- spigot 1.13 (1.12 mcedit schematics): 2.0.6
- spigot 1.13 (1.13 sponge schematics): 3.0.0
- spigot 1.14 (1.13-1.14 sponge schematics): 4.0.1
点击 这里 选择对应的版本!

让你的NPC建造schematic建筑吧. 有了这款插件，NPC可以使用mcedit/worldedit 生成的schematic文件来一个一个方块地手动建造.
特点 · Features
NPC可以:
  • 一格一格地建造 MCEdit/Worldedit schematics建筑.
  • 重建已有建筑.
  • 需要玩家提供建材.
使用方法
  • 创建NPC并给予 'builder' trait.
    • /npc create Bob --trait builder
  • 使用 /builder load 指令加载schematic:
    • /builder load house
    • 示例加载了 house.schematic 文件.
  • 把NPC放到建筑区域.
  • 使用指令开始建造:
    • /builder build

详情查看 Citizens 2 Wiki
