不确定你的npcmod的版本是哪个，这边我就先假设是1.7.10好了

npc的抛射物中有一项变数，代表抛射物是否嵌在方块内
这应该就是你要的东西

不过我并没有找到类似的事件来描述一个抛射物嵌到方块内了(可能有，但我没找到...)
所以目前比较实际的做法大概就是：搜索一定范围内嵌入地面上的抛射物，如果这东西是特定NPC丢的，那么就打雷并移除这个抛射物

但有一个难处：描述抛射物是否嵌入方块内的变数是protected，而另一个ticksInGround变数(描述抛射物嵌在地上多久了)是private
所以如果要取得这些资讯的话，要不是从NBT里找，要不就是用反射修改权限后存取。


我刚刚根据你的状况，写了个脚本来试试(NPCmod的版本是1.7.10)，代码如下：
Init:
  1. var projectileClass = java.lang.Class.forName("noppes.npcs.entity.EntityProjectile");
  2. var inGroundFile = projectileClass.getDeclaredField("field_70193_a");
  3. inGroundFile.setAccessible(true);
  4. npc.setTempData("reflect_inGround",inGroundFile);
复制代码
Update:
  1. var se = npc.getSurroundingEntities(30);
  2. for(var i = 0 ; i<se.length ; i++){
  3. if(se[i].getType() == 0 && se[i].getMCEntity().class.getName() == "noppes.npcs.entity.EntityProjectile"){
  4.   var pro = se[i].getMCEntity();
  5.   if(npc.getTempData("reflect_inGround").getBoolean(pro) && pro.func_85052_h()==npc.getMCEntity()){
  6.    world.thunderStrike(pro.field_70165_t,pro.field_70163_u,pro.field_70161_v);
  7.    pro.func_70106_y();
  8.   }
  9. }
  10. }
