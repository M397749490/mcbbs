如下做法即可：
第一步
  下载GuoItemLoreCommand
  https://www.mcbbs.net/thread-682208-1-1.html
第二步
  装入服务器的plugins
  重启服务器
第三步
  打开GuoItemLoreCommand的ClickTrigger.yml文件
  如下输入配置
打开菜单:
  # 触发时检测的描述，既物品上的Lore
  检测描述: '&d&k&c&d'
  # 触发的点击类型，可以是 左键 右键
  点击类型: 右键
  # 所有模块条件通过后由玩家身上发出的指令，支持玩家名变量%player%
  # [op]: 开头将会让玩家以最高权限使用指令
  玩家指令: []
  # 所有模块条件通过后由后台发出的指令，支持玩家名变量%player%
  后台指令:
  - 'dm open menu %player%'
  # 所有模块条件通过后是否向玩家发送一条信息
  开启使用提醒: true
  # 所有模块条件通过后向玩家发送的信息
  使用信息: '&8[&e系统&8] &f你打开了一个福利罐'
  # 用于检测物品数量以及消耗物品
  物品模块:
    需求堆叠数量: 1
    需求不足提示: '&c需要同时持有&e1&c个此物品时才能使用'
    # 若为消耗true，则所有模块条件通过后将会拿走需求堆叠数量个物品
    是否消耗物品: true
  # 用于让物品在一次使用过后在一段时间内无法再次使用
  # 可用于物品技能的冷却，礼包领取间隔
  冷却模块:
    是否启用该模块: true
    # 拥有相同冷却组的触发将会共享冷却
    冷却组: '福利罐'
    # 单位为毫秒
    冷却时间: 10000
    是否提醒冷却中: true
    # 尝试使用冷却中的物品时的提示信息，%less%为剩余冷却时间变量
    冷却中提醒信息: '&8[&e系统&8] &f你需要等待 &c%less% &f才能开启第二个福利罐'
  # 用于让物品需要某权限才能使用
  权限模块:
    是否启用该模块: false
    检测的权限: '药品权限.天堂的痊愈药剂'
    是否提醒权限不足: true
    权限不足提示信息: '&c使用此物品需要到达&e七级&c，请升级后再尝试使用'
  # 用于限制物品需要玩家在某种姿势下使用
  动作模块:
    是否启用该模块: false
    需要奔跑: false
    需要蹲下: false
    需要格挡: false
    需要浮空: false
    姿势不对是否提示: false
    姿势不对提示信息: '&c该物品需要在蹲下时使用'
  # 启用该模块前请确认安装了PlaceHolderAPI
  # 且用到的变量都已经下载
  # 判断式符号支持>，>=，<，<=，=
  变量模块:
    是否启用该模块: false
    判断项目:
      判断等级:
        判断式: '%player_level%>=30'
        不通过是否提示: true
        不通过提示信息: '&c等级不足，附魔等级至少要到达30级。'

  然后将
   后台指令：
   - 'dm open menu %player%'
  中的menu改成你的菜单名
第四步
  按你所说，用书打开菜单  找一本书，在随便一行Lore中加入Lore：§d§k§c§d

至此完成
