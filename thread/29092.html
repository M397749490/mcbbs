说明:

简介:
使用 MineCars 你可以在灰色羊毛 (正常街道)和黑色羊毛(高速公路) 上不用轨道,只需要使用方向键驾驶你的矿车 (你也可以自定义街道和高速公路的方块).. 每个人可以使用 /mcg [1,2,3]来换档,所以你可以自由的控制车的速度. 燃料系统可以让你为你的汽车购买燃料.
注意:本插件需要Vault!
命令:
/mcg gear [1,2,3] 换挡
/mcg fuel 查看自己的燃料
/mcg prices 查看燃料价格
/mcg buy 使用钱/物品购买燃料
/mcg reload 重新载入设置
/mcg adminfuel 管理员专用免费汽油(......)
/mcg help 或 ? 查看帮助命令

权限:
minecars.*                              # 开放所有权限
minecars.admin.*                    # 管理员汽油和重载设置的权限
minecars.admin                       # 管理员汽油权限
minecars.admin.reload             # 重载设置权限
minecars.buyfuel                     # 购买汽油的命令权限(/mcg buy)
minecars.useCommands          # /mcg命令的权限
minecars.move                        # 使用汽车的权限
minecars.create                        # 放置汽车的权限
minecars.fuelstation.use       # 使用加油站的权限
minecars.fuelstation.create    # 建造加油站的权限
minecars.fuelstation.destroy   # 破环加油站的权限
minecars.license.use             # 使用驾照牌的权限
minecars.license.create          # 创造驾照牌的权限
minecars.license.destroy         # 摧毁驾照牌的权限


加油站牌子和驾照牌牌子的建造方法
加油站: 在牌子第一行写上 Fuel Station
驾照牌:在牌子第一行写上 License

对插件的内容进行了汉化(plugin.yml没汉化= =||||别吐槽我)
然后个人在帮助信息里添加了命令的描述..(P.S.命令的描述有些许的吐槽)
