大概意思就是作者他原来也有一个服务器，然后自己编写插件，但是后来把服务器关闭了，但是不想让自己的插件埋没，所以把他发出来进行优化公布，提供给其他玩家使用。



  1. <b>Commands:</b>
  2. <font color="#2c2c2c">/tutorials – View all tutorials you can start by command     启动教程</font>
  3. <font color="#2c2c2c">/tutorial <tutorial> [player] - Start the tutorial for you or a certain player   为一个玩家启动教程</font>
  4. <font color="#2c2c2c">/tutedit <tutorial> - Create / Edit a tutorial   创建/编辑教程</font>
  5. <font color="#2c2c2c">/tutedit – View all tutorials / Reload the plugin / Force-save tutorials       保存重载之类的</font>
  6. <font color="#2c2c2c">/abort - Exit the chat input   退出聊天</font>
  7. <font color="#2c2c2c">No more commands needed because everything is customizable via an awesome gui!          不需要更多指令，所有的都可以通过gui配置</font>

  9. <b>Permissions:</b>
  10. <font color="#2c2c2c">tutorialcreator.edit – Access the /tutedit command to edit tutorials via the gui   使用gui</font>
  11. <font color="#2c2c2c">tutorialcreator.startvillager.<tutorial> - Start a tutorial by right-clicking the villager         通过右键村民开始教程(单个的)</font>
  12. <font color="#2c2c2c">(tutorialcreator.startvillager.* - Start all tutorials by right-clicking the villager)       右键开始所有教程</font>
  13. <font color="#2c2c2c">tutorialcreator.startcommand.<tutorial> - Start a tutorial by using /tutorial <tutorial>   使用命令开始某个教程</font>
  14. <font color="#2c2c2c">(tutorialcreator.startcommand.* - Start all tutorials by using /tutorial <tutorial>)     可以开始所有教程</font>
  15. <font color="#2c2c2c">tutorialcreator.forcetutorial – Start tutorials for other plays     给别的玩家开始教程</font>
  16. <font color="#2c2c2c">tutorialcreator.bypassinvis – See players that are currently in a tutorial      查看当前在教程中的玩家</font>
  17. <font color="#2c2c2c">tutorialcreator.removevillager – Shift-rightclick villagers to open the villager-gui     右键村民打开gui</font>
  18. <font color="#2c2c2c">tutorialcreator.bypasstestserver - Have no restrictions when the testserver-mode is activated   使用 testserver-mode 没有任何限制</font>
