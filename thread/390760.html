兼容性测试

理论上兼容的版本：
1.2.5-1.5.2
测试过的版本：
1.6.4 MCPC+完美兼容
1.7.2 Cauldron 完美兼容
1.7.10 Cauldron完美兼容
-=-=-=-=-=-=-=-=-=-=-
插件特性

1.禁止任意ID物品（方块）的持有权限
2.禁止任意ID物品（方块）的使用权限
3.禁止任意ID物品（方块）的放置权限
4.禁止任意ID物品（方块）的合成权限

-=-=-=-=-=-=-=-=-=-=-

使用方法
由于此插件指令很少，因此绝大部分工作是在其配置文件中进行的

Config.yml：
  1. #这是插件的名字，不要改
  2. TekkitCustomizer:
  3.   #是否保护地表不受（原版）爆炸破坏
  4.   ProtectSurfaceFromExplosives: true
  5.   #￥%%！…………@##看不懂
  6.   RemoveUUMatterToNonRenewableItemRecipes: true
  7.   #强制加载本插件的世界列表
  8.   EnforcementWorlds:
  9.   - world
  10.   - DIM1
  11.   - DIM-1
  12.   Bans:
  13.     #禁止使用权限
  14.     UsageBanned:
  15.     - 27585:2:Divining Rod III:Makes mining trivial, undermining the server economy.
  16.     - 27526:*:Philosopher's Stone:Bypasses anti-grief to change blocks in protected areas without permission.
  17.     - "4432:*:grass:\u4f60\u4e0d\u80fd\u4f7f\u7528\u5b83\uff01"
  18.     - 1:0:a:asdasd
  19.     #禁止持有权限
  20.     OwnershipBanned:
  21.     - 27556:*:Catalytic Lens:Bypasses anti-grief to change blocks in protected areas without permission.
  22.     - "7:0:grass:\u554a\uff1f""
  23.     #禁止放置权限（不好用，请添加到禁止使用权限列表）
  24.     PlacementBanned:
  25.     - "404:0:a:\u5657\uff01""
  26.     - 50:0:a:asdasd
  27.     #这个是指列表里的物品会被世界清除，比如你添加个TNT进去，那么他就会把地图上放置着的TNT全都删除掉。就像遗迹，TNT会被清掉。（谢谢阿邱~）
  28.     WorldBanned: []
  29.     #禁止合成权限
  30.     CraftingBanned:
  31.     - 50:0:a:asdasd
  32. #格式：
  33. #    - ID:Dm:name:reson
  34. #    eg.:
  35. #    - 1:*:Stone:Item Banned
复制代码



格式请严格参照以下格式！
  1. ####
  2.     - ID:Dm:name:reson
  3.     eg.:
  4.     - 1:*:Stone:Item Banned
复制代码


其中
Dm为损耗值（有色羊毛和武器的损耗程度）
name栏位可以随意填写（英文）
“：”必须为英文输入法的：
“-”前是四个空格，不是Tab输入的大空格


注：若想加入中文，请将编码转为ANSI！

指令&权限

因为原插件的重载指令实在太麻烦了
貌似有20个字母之多
于是我修改了重载指令
现在的重载指令是
/banload
查看方块信息和手中信息的指令
/blockinfo
(仅OP有权查看)

权限：（引自miaolu大大的原帖）
权限:
如果你想要某个玩家可以合成禁止的物品或者放置以及使用禁止的物品的时候,你就需要他了
比如我禁止了世界锚(451:0:XXXXXX)和私人锚(451:2:XXXXXX)
然后我想让那个玩家能放置以及使用私人锚
tekkitcustomizer.451.2.use
这个为使用权限,如果你放置了私人锚并且禁止了所有,玩家打不开,需要这个权限才能打开界面
tekkitcustomizer.451.2.craft
这个为合成权限
tekkitcustomizer.451.2.place
这个为放置权限
tekkitcustomizer.451.2.own
这个权限不清楚,求好心人指教,谢谢.
tekkitcustomizer.451.2.*
这个为ID为451:2的物品的所有权限
tekkitcustomizer.451.*.*
这个为ID前面为451的所有物品的所有权限
