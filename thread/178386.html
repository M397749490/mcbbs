最近搬运了个MOD 可是那说明 顿时哭了 跪求翻译
下面是翻译内容：（翻译有奖- -）（禁止机翻）
1. Downloading the file:
  • Hit the 'Download' button right above this. (The yellow button)
  • Wait 5 seconds, and then click 'Skip Ad'. (Ads are to support the creator, me, make a little money for creating the mod)
  • Download both the class files as well as Cloakboard
~FILES INCLUDED IN THE .ZIP~
  • cape template.png
  • 2 class files
  • CloakBoard files

2. Installing the cape mod: (hard way)
- Use the official launcher to download and start once Minecraft 1.6.2.
- Go to the minecraft base folder (the official launchers shows it when you click "Edit Profile" as "Game Directory")
- Go in subfolder "Versions"
- Rename the folder "1.6.2" to "1.6.2_MCwCB"
- Go in the subfolder "1.6.2_MCwCB"
- Rename "1.6.2.jar" to "1.6.2_MCwCB.jar"
- Rename "1.6.2.json" to "1.6.2_MCwCB.json"
- Open the file "1.6.2_MCwCB.json" with a text editor and replace "id":"1.6.2" with "id":"1.6.2_MCwCB" and save the file
- Copy the files from the MCwCB ZIP file in "1.6.2_MCwCB.jar" as usual (you can use the 1.5.2 instructions for this) and remove the META-INF folder from "1.6.2_MCwCB.jar".
- Start the official launcher
- Click "Edit Profile"
- Select "Use version:" -> "release 1.6.2_MCwCB"
- Click "Save Profile"
- Click "Play" or "Login" to start the game. If only "Play Offline" is available, then log out and log in again to fix it.

Installing the cape mod: (easy way)

- Forge or Modloader
- Extract the class file of your version
- Zip the file
- Drop in mods folder

3. Uploading your cape:
  • Create a cape with the template I have provided for you. (cape template.png)
  • Go to http://nodesoftware.com/MCwCB/and login, and then upload your cape.
Now that you are on the website, you have 2 choices to uploading your cape.

Classic Uploader:
  • Choose "Classic Uploader" and upload your cape.
CloakBoard:

  • Download the CloakBoard client from the website
  • Login
  • Upload your capeThings to Remember:
    • YOUR CAPE MUSTBE NAMED yourusername.png.(Examples: notch.png, iminecrafter.png, random.png)
    • If it is cape.png, cape_template.png, or somethingthat doesn't have onlyyour username in it, it won't work.(If you make the mistake, just re-upload a cape with the correct name.)
    • Want to upload a new cape? Just re-do number 3, and enjoy! (Remember to wait 24-48 hours)
    • Here is a big cape gallery: http://minecraftcapes.com/(remember to name a downloaded cape: yourusername.png)
    • If you want me to upload a screenshot of you with the cape, mail me the screenshot, you'll see it up here soon! (I do need more screenshots anway. :D)
    • You need a zipping program or some sort of mod installing program to install my mod. (These are very easy to get, just use the friendly Google!)
    • I highly suggest using Paint.NET or GIMP to edit.
    • On the cape template, F is front, B is back.
    • If you aren't going to provide any info on why the mod is not working, then it would be pointless to post as we cannot help.

    Mod Compatibility:
    • Zombe's fly mod - not officially tested but as of now, not working

  • Smart Moving - Not compatibile
