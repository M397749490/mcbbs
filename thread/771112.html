购买
插件支持版本1.7-1.9
7欧元 = 51RMB
近期作者原贴没有声明要将插件麻烦发布
插件权限
玩家默认拥有权限
宠物PVP权限：
battlepets.battle.request
battlepets.battle.accept
不battlepets.battle.send
把这3个给玩家就好了
插件指令
新名字 /bp name
重新命名你的宠物/bp menu
打开宠物菜单/bp cancel
取消你的宠物攻击/bp shop
打开宠物商店/bp reload
重启插件/bp egg 生物ID
