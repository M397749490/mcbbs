这个东西不建议使用,极度不稳定.不能打开箱子菜单,悬浮字全部暴露原型(盔甲架),怪物很僵硬etc.

但是配置并不难.
目前能看得下去的版本只有0.3.4.6-snapshot,这里仅仅拿这个做例子.
0.3.4.6支持Java1.12.2与BE1.5.0互相连接.
使用"java -jar proxy本体"运行一次后,目录下会出现一个config.yml.
我把重点翻译一下:

  2. # 将proxy绑定在哪,用于基岩版的连接
  3. #类似于java版服务器的server.properties里的server_ip和server_port
  4. # IP 0.0.0.0 意味着监听来自任何IP的连接
  5. udp_bind_ip: '0.0.0.0'
  6. udp_bind_port: 19132

  8. ...


  11. # 基岩版上服务器列表的MOTD
  12. motd: '&aServer by DragonProxy'

  14. # 需要被代理的服务器.
  15. # 即BE端可以通过dragonproxy连接的java服务器
  16. remote_server_addr: '127.0.0.1'
  17. remote_server_port: 25565

  19. # Ping穿透
  20. # 如果设置为true,则直接从java版服务器获取motd人数显示在BE上
  21. ping_passthrough: false

  23. # 服务器验证方式
  24. # online  : 用dragonproxy来进行模拟正版登录
  25. # offline : 不进行登录,无法进入有正版验证的服务器.
  26. # cls     : 尚未实现
  27. # hybrid  : 混合模式,即同时允许online和offline
  28. #一般设置为offline
  29. mode: offline

步骤1: 安装Java 8（或更高），下载该jar文件。
步骤2: 建立一个正常的Minecraft PC / Mac的服务器。你也可以使用Bukkit /水龙头/ glowstone / spongevanilla / bungeecord。
步骤3: 通过运行命令运行代理：java -Xmx256M -jar dragonproxy-x.x.x.jar 在256M内存大小和dragonproxy-x.x.x.jar是文件名。
步骤4: 通过在控制台输入停止关闭服务器。
步骤5: 编辑remote_ip和remote_port config.properties和改变你的Minecraft PC / Mac服务器，如127.0.0.1 25565。
步骤6: 再做一步3，你应该能够连接到一个电脑/苹果服务器通过你的计算机/服务器从口袋/赢得10版。
