打开服务端下的文件 config/forge.cfg 找到以下两处 将 false 修改为 true 后开启 会自动删除错误方块/实体 (修改后开启第一次接近那里可能会崩 第二次就好了)
  1.     # Set this to true to remove any Entity that throws an error in its update method instead of closing the server and reporting a crash log. BE WARNED THIS COULD SCREW UP EVERYTHING USE SPARINGLY WE ARE NOT RESPONSIBLE FOR DAMAGES.
  2.     B:removeErroringEntities=false

  4.     # Set this to true to remove any TileEntity that throws an error in its update method instead of closing the server and reporting a crash log. BE WARNED THIS COULD SCREW UP EVERYTHING USE SPARINGLY WE ARE NOT RESPONSIBLE FOR DAMAGES.
  5.     B:removeErroringTileEntities=false
复制代码
