作者: a2785771345    时间: 2016-4-24 13:47
找到   服务端\plugins\GroupManager config.yml用Edit with Notepad++打开   找到分组  world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
添加自己要加的世界对齐只能英文如我要加的世界是ying
  world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
          ying
          - users
然后进入worlds找到ying的文件夹进入找到groups.yml用Edit with Notepad++打开找到
Builder:
    default: true
    permissions: []
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      prefix: '&2'
      build: true
      suffix: ''
这就快完成了   然后把  build: true改为build: false   好了普通玩家就不能在ying的世界破坏方块和放东西了
