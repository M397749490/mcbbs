不要双击jar打开，打开记事本里面放这些内容，然后保存成“启动服务器.bat”，注意“点bat”这里
把这个文件和服务器jar放在一起，然后

  1. cd /d %~dp0

  3. set serverJar=spigot-1.12.2.jar

  5. :boot
  6. java -Dfile.encoding=UTF-8 -Xms8G -Xmx10G -d64 -jar "%serverJar%" nogui

  8. @echo 15秒后重启服务器
  9. @timeout /t 15

  11. goto boot

  13. exit
复制代码
↑
这里能直接复制

:boot底下的那行就是你正常启动服务器的参数，我这里是我的Spigot用的，
至少记得改最小内存和最大内存（8G和10G）。

这些东西的功能是在服务器意外关闭后等15秒自动重启。
把"spigot-1.12.2.jar"改成你的服务端jar文件名，
要彻底关闭服务器，在15秒倒计时期间在窗口里按Ctrl+C（复制的快捷键），
然后右上角点X关了。
试试看你双击这个bat文件，然后stop，能不能看到15秒倒计时？
如果能看到，代表服务器成功关了
还是看不到的话需要进一步查找其他信息
