你只要让你和你的小伙伴们的电脑上都安着Hamachi（Hamachi很好安，如果实在找不到或者安不上，加我Q316975110，我来帮你安），然后启动蛤蟆吃，点击“网络”，选择创建一个局域网什么的那个，然后输入服务器ID和密码，并且记下来。然后你就有一个Hamachi服务器了。把你的服务器ID和密码发给小伙伴，他们同样开启Hamachi，点网络，加入现有网络，再把ID和密码输入进去，然后你就发现你的Hamachi服务器里多了一个人，那个就是你的小伙伴。小伙伴进来以后，你就打开MC，点单人游戏，进入或者创建一个世界，（进去以后你最好在最初的出生点附近，要不然你跑远了你可能就找不到小伙伴了。所以建议创建一个新世界）。进入游戏后按Esc，找到“对局域网开放”点一下，选择好游戏模式和是否允许作弊什么的，然后点击开放，然后对话框里会出现：本服务器将在XXXX开放这么一句话（XXXX是一个数字），然后你要记下这个数字，发给小伙伴。然后你再打开Hamachi，在电源按钮的旁边有一串较大的数字：XX.XX.XXX.XXX（X还是数字，数字有不同。格式也可能不同，如：还可能有：XX.XXX.XXX.XXX这样的可能）这串数字也记下来，然后和前面发给小伙伴的数字组合，就成了XX.XX.XXX.XXX:XXXX（比如，发给小伙伴的是6489，电源按钮旁边的是25.37.455.217的话，那么组合起来就是25.37.455.217：6489。冒号要加上）然后把组合的数字记下来，发给小伙伴，让小伙伴打开同样版本的MC（就是MOD，整合包也要是一模一样的），点多人游戏，直接连接，输入组合的那串数字，然后加入。（如果无法连接就让你的小伙伴把框框里的数字全部删掉再重新输一遍。）就完成了。有疑问加我Q316975110

你可以改个蛤蟆吃服务器，很容易的下载一个1.6.2、1.5.2、1.4.2什么版本都行的服务端.zip下载，然后下载个蛤蟆吃，你朋友也要弄蛤蟆吃，蛤蟆吃里有个网络你创建新网络，然后输入网络ID，你可以填写蛤蟆吃上的那串数字，然后密码大部分都是123，然后让你的伙伴加入你的蛤蟆吃IP（我说的是蛤蟆吃,不是游戏里的），然后那个服务端里面有个server.properties这个玩意对不对，点击进入server-ip=找到这个然后在=后面输入蛤蟆吃IP，然后保存，服务端里面有个开服.bat的，你先右键点击一下找编辑，@echo OFF
SET BINDIR=%~dp0
CD /D "%BINDIR%"
"%ProgramFiles%\Java\jre7\bin\java.exe" -Xmx1024M -Xms1024M -jar mcpc-plus-1.6.2-R1.1-forge871-B97.jar
PAUSE
是不是这样的，你把"%ProgramFiles%\Java\jre7\bin\java.exe" 这个改成你的JAVA文件所在处复制地址输入上去，后面的Xmx1024M -Xms1024M这个2个1024都改成512，然后保存。
你在点击开服记住一定要是.bat结尾的，如果是.txt你就重名令将.后面的改成bat就行然后开服点击，一直等到出现Done<任意的一个数字后面有s）!For help,type "help"or "?"就是开服成功的意思然后进和服务端搭配的版本游戏添加服务器输入蛤蟆吃IP就可以玩了。（插件是plugins吧插件放到这来）（world这个是地图你可以把里面的备份，然后弄成你要的服务器地址）（给OP的话在开服的黑色字里输入op ip记住不要输入/这个在游戏里当上了OP后也可以在里面输入，里面就要/这个呢。 关服一定要输入stop不然就白玩了不要加/这个。
