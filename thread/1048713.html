# 此项配置请慎重开启
# 开启正版玩家的UUID
# 优点是正版玩家更换id时不会清空数据
# 缺点是一旦已有正版玩家注册的话，，，工作量不敢想象
# 此项配置需要spigot；Cauldron或者PaperSpigot
premiumUuid: false


想获得正版的UUID得开这个
但是 emmmm
如果已经有正版玩家注册过的话
开启这个
这个玩家的所有数据将会丢失 因为UUID发生了变动

然后看清楚这个插件的配置
正版帐户无法登录离线玩家的现有帐户

也就是说你得新拿一个没有注册过的正版号
来测试自动登录功能
