【Java版 1.13】
①循环型不受制约保持开启：/execute at @e[type=minecraft:item,nbt={Item:{id:"minecraft:diamond",Count:1b},OnGround:1b}] if block ~ ~-1 ~ minecraft:grass_block run summon minecraft:item ~ ~ ~ {Item:{id:"minecraft:emerald",Count:1}}
②连锁型条件制约保持开启（连接在①后面）：/execute as @e[type=minecraft:item,nbt={Item:{id:"minecraft:diamond",Count:1b},OnGround:1b}] at @s if entity @e[type=minecraft:item,nbt={Item:{id:"minecraft:emerald"}},distance=..0.01] if block ~ ~-1 ~ minecraft:grass_block run kill @s
①为召唤绿宝石，②为清除钻石（②指令这么长是为了防止清除多余的钻石）
注：如果丢钻石太快导致合并则无法转换，需捡起重新丢
