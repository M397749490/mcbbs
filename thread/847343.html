怎样在某个区域内检测背包特定格子内是否携带了某样物品
作者: Alxeh    时间: 2019-2-24 00:04
execute positioned x y z run execute if entity @a[distance＝..10，nbt＝{Inventory:[{id:"minecraft:xxx",Slot:100b}]}]
命令中Slot的值代表玩家身上的某个物品栏，具体请看图。
