特点：
- 一个获取生物头的指令。
- 几乎全部生物的头颅。
- 一个头的黑名单，用于禁止一些头颅的使用。
- 生物死亡时可以掉落对应的头，并且几率可配置。
- 可以通过合成表合成头颅，可配置可关闭。
- 几乎所有的信息都是可配置的。
- 可以出售头颅（需要Vault）
- 会有更多……毕竟现在这只是一个开始！

配置讲解：
heads.yml：
这里是配置关于怪物掉落头颅的配置文件，每种头颅都有五个选项：
  1. blazeHeadN: MHF_Blaze
  2. blazeHeadC: 25
  3. blazeHeadDN: "\u70c8\u7130\u4eba\u7684\u5934"
  4. blazeHeadP: 10.0
  5. blazeHeadEN: Blaze
复制代码
N：Name，指的是怪物死亡时掉落的头颅的种类。上面这样指的是在烈焰人死亡时掉落烈焰人的头颅。如果我想要在烈焰人死亡时掉落僵尸的头颅，那么把MHF_Blaze改成MHF_Zombie即可。
C：Chance，指的是死亡时掉落头颅的几率。值的范围为0-100，单位为百分之一。25则为25%，100则为必定掉落，0则为必定不掉落。
DN：Display Name，指的是掉落的头颅的物品名。
P：Price，指的是使用/sellhead出售这个头颅时得到的钱的数量。

config.yml：
blacklistOn: true  //是否开启头颅黑名单？
blacklistwOn: true  //是否开启世界黑名单？（指在一个世界内能否用头颅）
whitelistOn: false  //是否开启白名单？
whitelistwOn: false  //是否开启世界白名单？
sellHeads: true  //是否开启头颅售卖？
dropHeads: true  //是否开启头颅掉落？
craftHeads: true  //是否开启头颅合成？
autoReloadOnFirstJoin: true  //不懂。
disableCrafting: false  //是否关闭头颅合成？（感觉有点多余）
themeColor1: DARK_BLUE  //不懂↓
themeColor2: GOLD
themeColor3: GRAY
themeColor4: DARK_AQUA
blacklistw: []  //↓这四个分别是世界黑名单、黑名单、白名单、世界白名单的内容。
blacklist: []
whitelist: []
whitelistw: []
lore:  //头颅物品的描述，见下图↓
