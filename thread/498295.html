-     ◇ RandomLocation可以通过输入指令将玩家传送到预设范围内的任何地方 ◇     -

-     ◇ 还可通过配置将首次登陆的玩家随机传送至一个位置，以便获得更多资源 ◇     -

-     ◇ 该插件还支持设置木牌(或传送门)作为固定传送点，使玩家取得快速通道 ◇     -




·特点(features)：
          √ 使用方便，基本上只需设置一个范围就可以使用了
          √ 拥有完整的权限及指令，并且可以自定义传送范围
          √ 支持多世界，并且不会影响到WorldBorder的使用
          √ 轻量级插件，占用内存不多，且可以设置定期刷新
          √ 首次加入的玩家可被随机传送到一个无人的初始点
          √ 非常安全的传送，不会让玩家卡在方块内导致死亡
当RandomLocation有新版本发布时会通过游戏内(聊天框)进行通知，但是它不会下载任何东西，想禁用此功能可以在config.yml中将AutoUpdater后面的Enable，这个单词冒号后面的true改为false即可。
(注意：是在这个单词后面的第一个Enable，因为有多个Enable，所以必须认真的找清楚，这个插件的设置格式应该就是...一个功能，然后后面写上一堆“启用”“通知OP”之类的选项，也就是说一个功能有多个子功能)
·指令及权限(commands and Permission)(引用旧搬运帖)：
权限: RandomLocation.Use (普通用户组权限)
          /rSpawn <ZoneName> - 在名为<ZoneName>的区域内传送
你需要把这个权限给玩家，不然无法使用上面的指令(木牌和传送门)传送
权限: RandomLocation.Admin(管理员权限)
          /rLoc - 显示帮助
          /rLoc Create <区域名> - 创建新区域
          /rLoc pos1/2 <区域名> - 设置区域的边界。将读取玩家脚下的坐标
          /rLoc radius <区域名> <#范围> - 快速设置区域范围，将是以你为中心半径<#范围>的圆
          /rLoc fitWorldBorder <区域名> - 如果你有WorldBorder插件可以直接把区域范围跟边界重合
          /rLoc option - 列出区域中可以设置的选项
          /rLoc option <区域名> info - 查看区域的信息
          /rLoc option <区域名> setPerm <权限节点> - 设置区域内的自定义权限，权限节点格式为 "RandomLocation.<权限节点>"
          /rLoc del <区域名> - 删除一个区域
          /rLoc list - 列出所有区域
          /rPlayer <玩家名> <区域名> - 直接随机传送一个玩家到某区域
          /rReload - 重启插件





传送设置教程
(Tip：当你在游戏内根据教程完成范围的设置后，所设置的信息会出现在zone内，你可以在里面进行二次修改)

首先，你需要在游戏内输入“/rLoc create 区域名”，区域名可以是英文，比如说“/rLoc create zhushijie”
这时候RandomLocation就会判定你要开始进行范围的设置，你就可以进行下面的操作~~~~~~~~~~~~~
站在第一个方块上，输入“/rLoc pos1 区域名”，然后站在第二个方块上，输入“/rLoc pos2 区域名”，区域名
必须和第一次输入的指令一致，当然区域名也可以理解为“被限制的范围所使用的名称”~~~~~~~~~~~~~~
完成上面的步骤之后，就可以使用“/rSpawn 区域名”在你所设置的范围内(两个方块之间的任意方块)随机传送

设置木牌传送点(右键木牌就可以传送，无需指令)
使用一个原版的告示牌即可，一共有四行，在第一行输入“[rl]”，然后第二行输入“区域名”，第三行和第四行可以随便写，完成后第一行的文字会是绿色的，第二行的文字会是青色的，下面的则是黑色的，这说明的设置成功了！
设置传送门随机传送
先设置好两个传送区(Zone1&Zone2)，然后使用“/rLoc setType Zone2 p”把第二个的属性调整为传送门。最后，使用“/rLoc setPortalDest Zone2 Zone1”设置传送门的目标区域，玩家一旦走进这片区域(Zone2)就会自动被传送到另一个传送门区域(Zone1)
