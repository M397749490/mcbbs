MCEmoji

这个插件可以让你在MC中打出彩色的颜文字(不是黑白字符)

输入触发文字，能被自动替换为Emoji

让玩家看到这些颜文字需要加载一个资源包

帖后会讲述使用资源包的三个方法

[提示]自带资源包已经过期，请根据下文教程自己替换自己的资源包为如下外链：
http://pan.plyz.net/s/?u=2937040729&p=emojix.zip
[提示]Linux下请手动修改emoji.yml为UTF-8无BOM格式，否则会出现无效、乱码等现象
[用法]


将插件安装到plugins目录，载入一遍后，斟酌修改生成的配置文件，满足自己服务器的需要（见下）

当玩家输入您设定好的触发文字，并且符合触发条件，就能自动将触发文字转换成指定颜文字





[配置文件]


emoji.yml（左边的左右括号[]也会被检测！）

  1. …
  2. #左边是触发文字，右边是颜文字（后面我会讲右侧是这样的原因）
  3. [阴险]: 鴀
  4. [滑稽]: 鴁
  5. [茶杯]: 鴂
  6. …
复制代码

config.yml

  1. #是否允许每个人都能发颜文字
  2. #如果false，只有拥有emoji.chat权限的用户才能发出
  3. everyone: true
  4. #是否自动向玩家推介下方资源包
  5. auto: true
  6. #这个资源包的本质是一个材质包，原理是替换mc材质中的字体文件，实现颜文字发出，这个字体包是作者自己的，域名绑定了免费空间，月流量非常有限，建议腐竹自己下载后搭建材质服务器。也可以让美工自行修改材质，替换emoji.yml
  7. address: http://shader85.site/emoji.zip
复制代码






[使用资源包的方法]


1、直接使用上方我的资源包，并酌情修改emoji.yml

(推荐)2、自行搭建资源包服务器，酌情修改emoji.yml

（有美工的情况下，最好）3、自行修改mc材质文件，创建资源包，搭建包服务器，根据修改的文字使用emoji.yml




[原理]


这个资源包的本质是一个材质包，原理是替换mc材质中的的一些生僻字（mc的字体文件保存为png格式，一个文件里有大约16*16个字），请自行翻找核心文件，或者参考我材质包中的目录（mc中的字体分为半角和全角，大多数文字都是半角字体，如果被改成颜文字会造成显示不全！所以我使用了一些生僻的繁体汉字作为修改，汉字都是全角字体），修改完后，输入这个字体就会变成表情



[预览](因为亮度原因这些图片看上去比夜晚好看，在黑色背景下图片锯齿严重)
