关闭碰撞箱
1.12以上：
  1. /team add example
  2. /team modify example collisionRule never
  3. /team join example @a
复制代码

1.12及以下
  1. /scoreboard teams add example
  2. /scoreboard teams option example collisionRule never
  3. /scoreboard teams join example @a
复制代码
