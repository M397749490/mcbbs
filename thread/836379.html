RemoteMcServerManager
RemoteMcServerManager 简称 RMSM 他可以远程控制您的服务器
RemoteMcServerManager 拥有很多强大的功能，具体有哪些亮点呢？我们一起往下看。


来首歌


主要功能
  • 完整的 Minecraft 服务器管理功能
  • 支持跨平台，Windows 和 Linux 都能运行，甚至可以运行在手机上
  • 内置 FTP 文件传输功能 [未实现!][2019年1月3日会实现的][鸽了 我真的懒得写了 反正也没几个人用]
  • 可以运行Shell命令
图片

使用方法windows 点击自带的cmd文件就可以啦
linux: java -jar Daemon或Client.jar

daemon需要将mc服务端放进 Server文件夹里面

配置修改:
daemon
  1. [Server]
  2. # 绑定IP 默认: 0.0.0.0
  3. ip=0.0.0.0
  4. # 监听端口 默认: 25560
  5. port=25560
  6. # 连接口令 默认: Rmsmanager233
  7. password=Rmsmanager233
  8. # 服务器启动命令 默认: java -jar server.jar
  9. command= java -jar server.jar
