配置文件
  1. DelayInMinutes: 10 ← 多少分钟保存一次
  2. SaveAllWorlds: false ← 是否为所有世界备份
  3. Worlds: ← 世界列表
  4. - world ← 默认只有world （因为没启动SaveAllWorlds）
  5. EnableSaveMSG: true ← 保存是否有提示
  6. SaveMSG: '&aStarting world save...' ← 提示信息可以汉化
  7. SaveMSG2: '&aWorld save completed!' ← 保存成功信息
  8. SavePlayersEverywhere: false ← 保存玩家坐标
  9. CheckForUpdates: true ← 是否检测插件更新，建议关闭改成false
  10. DisableDefaultWorldSave: false ← 是否关闭保存功能
  11. ExtraOptions: ← 额外功能
  12.   SaveOnLogin: false ← 登录时是否保存
  13.   SaveOnLoginCount: 50 ← 登录后多少时间保存
  14.   SaveOnQuit: false ← 退出时，同上
  15.   SaveOnQuitCount: 50 ← 退出时，同上
  16.   SaveOnBlockBreak: false ← 破坏放假时是否保存
  17.   SaveOnBlockPlace: false ← 摆放方块时是否保存
  18.   SaveOnBlockBreakcount: 500 ← 破坏XX数量后是否保存
  19.   SaveOnBlockPlacecount: 500 ← 我想你明白了
  20.   EnableSelfInventorySave: false ← 是否保存背包内容
  21.   EnableDebugMSGs: false ← 是否启动debug提示 ，没什么用
  22.   CheckSavingStats: false ← 检测状态
  23. EnablePowerSave: false ← 无视
  24. BroadCastWorldErrorIg: false ← 无视
  25. BackUp: ← 备份设置
  26.   EnableBackup: false ← 是否启动
  27.   EnableBackupMSG: true ← 是否有提示
  28.   EnableAutoBackup: false ← 是否自动备份
  29.   EnablePlayerKickWhileBackup: false ← 备份时是否踢出玩家
  30.   KickMSG: Server is making a backup... ← 踢出时提醒
  31.   IntervalOrDay: INTERVAL ← 可以选择INTERVAL或者DAY（单位）
  32.   BackupHoursInterval: 4 ← 小时
  33.   Date: 0 ← 这些都是天数之类的设置
  34.   DateDayDelay: 7
  35.   EnableBackupPurge: false
  36.   AutoPurge: false
  37.   RemoveBackupXAfterDay: 4
  38.   EnableMaxBackups: true
  39.   MaxBackups: 10
  40.   WarningMSG: '&aWarning! Backup has been executed!' ← 备份提示信息
  41.   WarningMSG2: '&aBackup Finished!' ← 成功备份信息
  42.   DirectoryNotToBackup: ← 可以无视
  43.   - thisisntgoingtobebackuped
