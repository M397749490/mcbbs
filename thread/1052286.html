https://www.mcbbs.net/thread-882506-1-1.html
(出处: Minecraft(我的世界)中文论坛)

先加载世界：
/mv load world_the_end

然后在末地输入
/mvm set keepspawninmemory true


当然，请确认你没有安装什么会卸载世界的优化插件
