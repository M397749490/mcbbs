领地保护扩展


前置插件：Residence

插件作用：
可以在Residence的基础上自定义添加受保护的实体/物品/方块，主要作用于MOD中不受Residence保护的，比如工业的箱子可以无视领地打开，工业扳手可以无视领地拆卸机器，神秘要素罐子无视领地偷要素，装备架之类无视领地使用等....。这些东西添加进去让它受某个权限保护即可~

插件命令：/rpe reload  重载插件配置

插件配置：
# 可自行添加flag权限在保护列表内
# 示例：若填 "*" 则表示所有
# CustomResidenceProtectBlockIdList:
#   container:
#   - "MEKANISM_BOUNDINGBLOCK"
#   - "MEKANISMGENERATORS_REACTOR:0"
#   - "MEKANISMGENERATORS_REACTOR:3"
#   use:
#   - "*"
#   build: []
# 实体ID类似于："minecraft:pig"

CustomResidenceAntiItemIdList:
  container: []
  use: []
  build: []
CustomResidenceProtectBlockIdList:
  container: []
  use: []
  build: []
CustomResidenceProtectEntityIdList:
  container: []
  use: []
  build: []
