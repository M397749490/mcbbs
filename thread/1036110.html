现有功能介绍/特色


可以有效的限制服务器中玩家的交互行为

可以限制玩家与方块的交互  e.g.上床睡觉 按下按钮 拉拉杆

可以限制玩家打开某个界面(mod服适用  e.g. 禁止玩家打开蒸汽机 同时不影响其他机器




权限


权限
注释
gui.override
允许玩家打开已经被禁止的界面
block.override
允许玩家与已经被禁止交互的方块交互
limited.checktype
允许玩家在聊天窗输入check type来查看方块的type
limited.list
允许玩家使用指令/gui list
limited.override
赋予玩家该插件的全部权限




指令


指令
作用
备注
/gui help
显示帮助
如果指令冲突可以使用/xgui
/gui list block
查看被禁止交互的方块

/gui list gui
查看被禁止交互的界面

/gui save block <Type>
添加方块标签到禁止交互名单

/gui save gui <Title>
添加界面标签到禁止交互名单
在手动往名单中添加包含空格的Title时
请先将空格替换为%20
/gui remove block <Type>
将指定方块移出禁止交互名单
/gui remove gui <Type>
将指定界面标签移出禁止交互名单
在手动往名单中删除包含空格的Title时
请先将空格替换为%20
check type
进入方块标签检查模式
不需要输入/
ok
退出标签检查模式
不需要输入/

以上指令默认仅OP可用
