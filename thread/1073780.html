所以最好在启动脚本里使用 screen 之类的东西, 你可以自己百度一下XD
或者复制我这个东西到你的启动脚本 可能比较复杂233

# 服务器在哪个目录执行, 一般填写你的服务端根目录
HOME_PATH="/home"
NAME=$(cat /proc/sys/kernel/random/uuid)
# 开始创建 screen
screen -dmS $NAME
echo "启动的会话名: $NAME"
echo "$NAME" > ~/fuwuqi.txt
screen -S $NAME -p bash -X stuff $"cd $HOME_PATH && java -Xmx1G xxxx"

就完事了。进到服务器就输入 screen -S $(cat ~/fuwuqi.txt) 完事。
