我先拿彩虹猫枪MOD来做示范吧

彩虹猫枪下载地址：http://www.mcbbs.net/thread-285789-1-1.html（未汉化）

这是没有汉化的彩虹猫枪


我们这就开始汉化

Starbound\mods\nyan-cat\items\guns\nyancat进入主要的材质核心

nyancat.gun就是我们要打开的猎物
用记事本打开它

内容为
{
"itemName" : "nyancat",

"rarity" : "Legendary",
"maxStack" : 1,
"dropCollision" : [-8.0, -3.0, 8.0, 3.0],
"inspectionKind" : "gun",
"inventoryIcon" : "poptartgunicon.png",
"shortdescription" : "Pop-Tart Gun",
"weaponType" : "Meme Gun",
"description" : "Nyan nyan nyan nyan nyan~!",

"image" : "poptartgun.png",
"handPosition" : [-5, -2],
"firePosition" : [10, 1.5],
"fireOnRelease" : false,
"walkWhileFiring" : true,
"twoHanded" : true,
"level" : 10,
"fireTime" : 1,
//"recoilTime": 0.01,
"spread" : 1,
//"multiplier" : 0,
//"classMultiplier" : 0,
"accuracy" : 100,

"projectileType" : "nyancatspawner",
"projectile" : { "speed" : 20, "power" : 100 },

"muzzleEffect" : {
"fireSound" : [ { "file" : "/sfx/gun/nyancat/loop0-25.wav" } ]
}
}

shortdescription" : "Pop-Tart Gun就是我们要汉化的名字
如果直接把他改成中文字，就会导致材质丢失的效果，所以我们要用Unicode来帮助汉化
Unicode地址：http://tool.chinaz.com/Tools/Unicode.aspx

然后放入里面去就像这样
{
"itemName" : "nyancat",

"rarity" : "Legendary",
"maxStack" : 1,
"dropCollision" : [-8.0, -3.0, 8.0, 3.0],
"inspectionKind" : "gun",
"inventoryIcon" : "poptartgunicon.png",
"shortdescription" : "\u5f69\u8679\u732b\u67aa",
"weaponType" : "Meme Gun",
"description" : "Nyan nyan nyan nyan nyan~!",

"image" : "poptartgun.png",
"handPosition" : [-5, -2],
"firePosition" : [10, 1.5],
"fireOnRelease" : false,
"walkWhileFiring" : true,
"twoHanded" : true,
"level" : 10,
"fireTime" : 1,
//"recoilTime": 0.01,
"spread" : 1,
//"multiplier" : 0,
//"classMultiplier" : 0,
"accuracy" : 100,

"projectileType" : "nyancatspawner",
"projectile" : { "speed" : 20, "power" : 100 },

"muzzleEffect" : {
"fireSound" : [ { "file" : "/sfx/gun/nyancat/loop0-25.wav" } ]
}
}
这样名字就OK了

接下来弄介绍，介绍是description后面的就是介绍了。和名字一样，也用Unicode转码

然后放进去就是这样：
{
"itemName" : "nyancat",

"rarity" : "Legendary",
"maxStack" : 1,
"dropCollision" : [-8.0, -3.0, 8.0, 3.0],
"inspectionKind" : "gun",
"inventoryIcon" : "poptartgunicon.png",
"shortdescription" : "\u5f69\u8679\u732b\u67aa",
"weaponType" : "Meme Gun",
"description" : "\u4e00\u628a\u5a01\u529b\u0031\u0030\u0030\u7684\u67aa\uff0c\u5728\u521d\u671f\u7b80\u76f4\u65e0\u654c\uff01",
"image" : "poptartgun.png",
"handPosition" : [-5, -2],
"firePosition" : [10, 1.5],
"fireOnRelease" : false,
"walkWhileFiring" : true,
"twoHanded" : true,
"level" : 10,
"fireTime" : 1,
//"recoilTime": 0.01,
"spread" : 1,
//"multiplier" : 0,
//"classMultiplier" : 0,
"accuracy" : 100,

"projectileType" : "nyancatspawner",
"projectile" : { "speed" : 20, "power" : 100 },

"muzzleEffect" : {
"fireSound" : [ { "file" : "/sfx/gun/nyancat/loop0-25.wav" } ]
}
}
