Placeholders?
Current-Players
Type %cplayers% and the line will show the current amount of players on this server.
Maximal-Players
Type %mplayers% and the line will show the maximal amount of players which can play on the server.
Motd
Type %motd% and the line will show the current motd of the server.

变量
当前玩家
输入％cplayers％，该行将显示此服务器上当前玩家的数量。
最大玩家
输入％mplayers％，该行将显示可以在服务器的玩家的最大数量。
Motd
输入％motd％，该行将显示服务器的当前motd。

FAQ?
The Plugin says my server isnt reachable but everything should work
Check if it is right spelled, case sensitive
The server is offline but will be online soon: Disable server-alive in the config.If it still doesnt work, write me a PM.
I want a line to be empty but i cant write 'nothing' into the chat
Simply write [SPACE].

It might take a while to load, allow up to 30seconds, if it doesnt appear, write me a PM.
An Error appears, what should i do now?
If the error happens every time you click on the sign or just happens more then one time, send me a PM with Spigot Version, Java Version and the Error itself.
Can I use Color ?
BungeeSigns supports color codes with the '&' char.

Installation
You have to copy the content of you BungeeCord config.yml file inside the bungeeconfig.yml file (inside BungeeSignsPremium directory). Then you restart the server and it should work fine.

?安装
将BungeeCord config.yml文件的内容复制到bungeeconfig.yml文件（BungeeSignsPremium目录中）。然后重启服务器，插件应该运行正常

Q&A - Support
Q: The command /createbssign is just messaged back in white when i typ it
A: Please recheck your installation, have you copied the content of your bungeecord-config into bungeeconfig.yml? Is the plugin in the spigot server plugins folder?
-> If the Problem still appears please open a Conversation on Spigot with me and provide the information described at "5. Support Request"
Q: There is only "Server loading.." on the sign
A: Please check the installation like mentioned in Question 1. Please check if you have opened every port of your servers.
Check if the IP-Adresses in your bungeeconfig.yml are equal to the global ip from your server.
-> If the Problem still appears please open a Conversation on Spigot with me and provide the information described at "5. Support Request"
Q: There is an error like "java.lang.NoClassDefFoundError: com/google/gson/Gson"
A: Check that your minecraft version is 1.8.6 or above
-> If the Problem still appears please open a Conversation on Spigot with me and provide the information described at "5. Support Request"
