标题: RPGitem如何调用Pex权限组的
在用RPGitem做技能时 用的右键就使用相关命令，本来想设计成右键来解锁合成.(事先我们设的个别物品不能合成，设计通过RPGitem物品来解锁合成)但是后面不管怎么试，RPGitem就是无法跳过权限限制来使用pex的开放合成权限，总是提示你没有权限组使用命令。在此想问有什么办法来能调用pex的最高权限来实现这个功能.

相关命令
/ rpgitem 物品id power command 2 right `右键学习图纸` `/pex user {player} add banitem.craft.解锁的合成id` `



以下是rpgitem的相关命令


/rpgitem [物品] power command 冷却时间:[整数值] [left,right] 展示名:[字符] 指令:[字符] 给 [物品]  添加指令技能，冷却时间为 [游戏刻]. 工具提示为 [提示文本].  [指令]  会在  [左键/右键] 后运行. *注意*: 如果你想在 [提示文本]  或 [指令]  留空， 那么要在字符串周围加 `符号。 例如: `/say Hello`
/rpgitem [物品] power command 冷却时间:[整数值] [left,right] 展示名:[字符] 指令:[字符] 权限:[字符] 给 [物品]  添加指令技能，冷却时间为 [游戏刻]. 工具提示为 [提示文本].  [指令]  会在  [左键/右键] 后运行， 并给予运行此 [指令] 的 [权限]. *注意*: 如果你想在 [提示文本]  或 [指令]  或  [权限] 留空， 那么要在字符串周围加 `符号。 例如: `/say Hello`

/rpgitem [物品] power command 冷却时间:[整数值] [left,right] 详细条目:[字符] 运行指令技能 [左键/右键] 释放. [详细条目] 处格式为 [显示文本] | [指令] | [权限]. 工具提示为 [显示文本]. 显示文本和指令必须用 | 这个符号分隔开.  如果有提供给玩家 [权限]，此 [权限] 仅使用的这一次有效，然后被移除

问题解决了
我们受snowclay推荐的插件启发
这个插件的作用是把后台指令作为玩家指令使用，无视权限.
如果能把这个作用调转,就能用这个命令了
我们自己开发了一个把玩家指令作为后台指令使用.并且用权限节点来限制玩家权限组使用这个命令.

最终命令是:
/rpgitem 47 power command right 2 右键学习图纸 `c /pex user {player} add banitem.craft.4161:0` *

/pex前面的c就是我们开发的一个小型后台命令插件指令.
