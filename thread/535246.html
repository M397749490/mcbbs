特点
- 设定权限来设置彩色标签
- 自定义的前缀和尾缀
- 在TAB列表中显示标签
- 自定义加入和退出的信息
- 作为其他插件的API
- 支持所有1.8版本
- 在名字下面显示血量
- 支持UUID
- 有专用的BungeeCord版本
- 下载:https://www.spigotmc.org/resources/namemanagerbungee.7552/
- 可以为指定用户组设置名字标签- 可以设置动态名字标签
指令
普通指令
/nm prefix 名字 给指定玩家添加前缀
/nm suffix 名字 给指定玩家添加后缀
/nm clear 名字 清除指定玩家的所有修改
/nm rainbow 名字 给指定玩家设置动态名字标签
/nm uuid 名字 显示指定玩家的uuid
/nm reload 重启插件
/nm group 显示组命令(下面介绍)
组指令
/nm group prefix 组名 设置某组的前缀
/nm group suffix 组名 设置某组的后缀/nm group add 组名 新增一个组
/nm group remove 组名 移除某组
/nm group list 列出所有的组
/nm group rainbow 组名 设置某组的动态名字标签

配置文件
  1. # 是否打开登入和退出消息?
  2. Messages: false

  4. # 加入退出信息是否包括本插件编辑的前/后缀?
  5. CustomNameForMessages: false
  6. Join: '&a[+] %player%'  //加入消息
  7. Leave: '&c[-] %player%'  //退出消息

  9. # 是否在名字标签下显示血条?
  10. HealthBelowName: false
  11. HealthFormat: '&c?'  //血条格式(即每个血条块的形状)

  13. # 如果想在BC的全服tab列表中显示，请打开本项
  14. Bungee: false

  16. # 是否关联到Vault?
  17. Vault: false</font>
