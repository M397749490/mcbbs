这个MOD是JEI的附属
需要配合JEI来食用
论坛链接：JEI

功能介绍
JER的第一个功能是查看生物掉落物(图片全部来自作者原贴 加载可能有点慢)

第二个功能是查看地牢箱子的掉落物和掉落几率
第三个功能是查看矿物的分布情况
第四个功能是查看作物的生长和掉落情况

DIY功能介绍
通过增加一个world-gen的json文件到jer的配置文件夹然后在游戏里调节diy设定来制作你自己的矿石分布
你还可以在游戏里使用/profile [chunk amount] [all]来创造一个world-gen的json文件,他将从新生成的世界开始重新分析矿物分布
这个功能只推荐整合包作者和有经验的玩家来使用
它还需要重新启动游戏才能使用新配置的数据
以上是我翻译的 下面是作者的原文
By adding world-gen.json to the JER config folder and toggling the DIY setting ingame you can make your own ore distributions.You can even use /profile [chunk amount] [all] to create a world-gen-scan.json that will get the distributions from a generated world so you don't have to guess. These features are quite advanced and only recommend for pack makers or experienced players. It also requires a game restart to start using newly profiled data.
