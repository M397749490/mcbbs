如题
BedwarsRel如何在bungeecord模式下设置真实死亡后观战而不是回到BC里设置的大厅？
作者: 孤判嘞    时间: 2019-4-17 20:26
打开楼主的伺服器根目录
BedwarsRel/config.yml
将bungeecord:
  enabled: false
  hubserver: hub
  endgame-in-lobby: true
  full-restart: true
  spigot-restart: true
的 enadled:false
换成 enadled:true
即可！
希望可以采纳！
