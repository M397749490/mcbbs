简介：

这款插件的名字叫：怪物掉落箱

它的前置插件是：Mythicmobs

（前置插件下载地址：https://www.spigotmc.org/resourc ... ator%E2%97%84.5702/）

顾名思义 这款插件的功能就是怪物死亡时可以在原地生成一个箱子里面包含这次怪物的掉落物
（只有Mythicmobs配置文件里配置的掉落物（见下图）会在箱子里）

话不多说 直接上图



而且你也完全不必担心他会刷箱子

因为它会在规定时间后消失(见上图，可配置)

也不用担心它会被破坏

RPG和生存都适用

注意：如果重启或者停止服务器会移除所有掉落箱（重载配置文件不会），防止箱子永远摆在那里
更新记录：
2016.1.16
1.添加击杀者才能拾取（可配置）
2.添加全部怪物都变箱子的功能
3.添加当掉落物为空时是否有箱子功能
4.修复一些BUG
2020.5.5
1.宠物击杀的尸体箱现在归主人所有
2.现在可以改变尸体箱的类型了
3.支持领地插件 可配置领地内不生成尸体箱
4.可配置拿出所有物品后尸体箱直接消失
5.现在尸体箱会正常恢复方块了
2020.7.13
1.可配置关闭背包时自动拾取剩余掉落物

指令：

/mdc reload------重载配置文件


权限：
mdc.reload 重载权限

无
配置文件：
使用新版本请先删除旧版本的配置文件
# 尸体箱方块类型 例: 126:4或342
type: 54
# 尸体箱消失的时间 设为0则不消失
time: 200
# 非击杀者是否可以开尸体箱
publicChest: false
# 设为true只有mobsBlock里的怪物不会变尸体箱 false则只有mobsList里的会变尸体箱
All: true
# 是否开启关闭背包一键拾取剩余物品
closepickup: false
# 当掉落物为空时是否出现尸体箱
zero: true
# 当拿出所有物品时尸体箱是否消失
clear: true
# 会变箱子的mm怪物类型
mobsList:
- 'SkeletonKing'
mobsBlock:
- 'SkeletalKnight'
PickUpMessage: '&4&l你不是击杀者，不可拾取该尸体箱！'
# 领地内是否掉落尸体箱 (需要领地插件 未装则改配置不生效)
Residence: true
