命令
# 部分命令均支持 TAB 自动补全 #

/g [message] - 帮派聊天
/guild help - 查看插件帮助
/guild list - 查看帮派列表
/guild info - 查看帮派信息
/guild create [name] - 创建帮派
/guild disband - 解散帮派,
/guild invite [player] - 邀请入帮
/guild join [guild] - 加入帮派
/guild kick [player] - 踢出帮派
/guild leave - 退出帮派

p.s. /guild 可以用 /gu 代替

权限
guild.* 允许使用所有命令
guild.player.* 普通玩家权限

guild.player.help 允许使用  /guild help
guild.player.list 允许使用 /guild list
guild.player.info 允许使用 /guild info
guild.player.create 允许使用 /guild create
guild.player.disband 允许使用 /guild disband
guild.player.invite 允许使用 /guild invite
guild.player.join 允许使用 /guild join
guild.player.kick 允许使用 /guild kick
guild.player.leave 允许使用 /guild leave

guild.player.chat 允许使用 /g

使用前请先导入相应的表（v1.2.3 可自动创建），并且确保 MySQL 的 wait_timeout 至少大于 7200 秒，推荐 28800 秒。
