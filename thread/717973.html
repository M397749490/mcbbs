如题

测试插件的时候总是得多等15秒好烦啊

好像是当服务端不是最新版的时候就会等15秒

好像是parperspigot服务端才检测最新版←_←

然而服务端自己也知道自己很烦,留了个选项,可以让开发者很容易的干掉他←_←

命令: 无
权限: 无
配置文件: 无
注意!这个插件不要放入plugins文件夹使用
他应该放入于开服命令同目录下进行使用

先上使用图片:



这个图片竟然也挂了↓,只能重新截图,只截图控制台了↑

这个图片竟然挂了↓,只能上小图了↑


安装方法:

下载插件
例如服务端的目录在:
服务端/生存服
则插件放到服务端/生存服目录下:


修改服务器的启动参数:
例如
java -Xms1024M -Xmx1024M -jar paperclip1.11.2.jar
改为:
java -javaagent:NOWait15Seconds.jar -Xms1024M -Xmx1024M -jar paperclip1.11.2.jar
必须跟在java的后面,不能在-jar的后面

享受从此你的服务器每次开启时都+15s的快感吧!

复制代码
摘自CraftBukkit的启动类，可以看出这里检测了一个SystemProperty，只要给这个蜜汁属性IReallyKnowWhatIAmDoingISwear赋一个值就行了，随便什么都行。像lz这样写个Instrumentation当然也是没问题的，不过没有必要，只要在-jar 前加上-DIReallyKnowWhatIAmDoingISwear就可以了。举个例子：
