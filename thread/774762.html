标题: [编程]KatLib——A Scala Sponge library[1.9-1.12]
KatLib
KatLib是一个作者自用的使写Sponge插件更容易的类库，它包含一些常用的类库和Scala，作者写的大部分插件需要KatLib。
下载时请确保版本和你使用的API版本对应。
功能
KatLib提供的功能有:
  • Classes to reduce boilerplate in the main plugin file
  • 自动创建插件帮助命令
  • 帮助保持配置文件元素顺序
  • 创建Text对象的简写
