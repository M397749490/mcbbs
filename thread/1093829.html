Hello, ...

Since the author of the 1.12 version of Cute Mob Models, yarrmateys, abandoned the mod, we decided to recreate CMM (... as a resource pack).

Why make a resource pack instead of a mod? It’s because we have absolutely no idea how to code. That being said, this resourcepack still requires OptiFine to be installed.
This is not a 1:1 recreation of CMM, as there are some limitations on OptiFine's part, that and we want to build new things upon it.
This resourcepack is still a work in progress.

大家好，因为Cute Mob Models mod 1.12版本的作者yarrmateys不再维护这个mod了，所以我们决定以资源包的形式重新制作CMM。
为什么要制作资源包而不是mod？【MCBBS@快乐小方】这是因为我们完全不知道应该如何写代码。话虽如此，这个资源包仍然需要安装OptiFine才能使用。
由于OptiFine有较大的局限性，并且我们希望在资源包中添加更多的内容，所以这个资源包与CMM mod并不是完全等同的。

NOTE: This resource pack requires at least OptiFine 1.14.4 HD U F4 or F5 in order to function properly!

If the resource pack is not working correctly, please check if:
"Video Settings > Quality > Custom Entity Models" is set to ON.
"Video Settings > Quality > Random Entity" is set to ON.【MCBBS@快乐小方】
If this does not fix the issue, please do report that, preferably with some screenshots, down under the topic.

This resourcepack is still a work in progress.
