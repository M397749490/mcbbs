只用于单个地图的配方位于以下位置
.minecraft/versions/<版本号>/saves/<存档名>/data/recipes/<命名空间>/<文件名.json>
如果你是要修改原版配方，命名空间用minecraft

关于配方如何填写，可以参考ruhuasiyu的【1.13-1.15】原版模组入门教程（虽然不是1.12，但是json格式是一样的）

然后说下战利品表吧
.minecraft/versions/<版本号>/saves/<存档名>/data/loot_tables/<命名空间>/<文件名.json>
相关教程可参考[CBL∫2b]Loottable - 创造一个看脸讲玄的世界 总索引

  "type": "crafting_shaped",

  ],
  "key": {
    "#": {
      "item": "minecraft:planks",
      "data": 4
    }
  },
  "result": {
    "item": "minecraft:acacia_boat"
  }
}

这里代表的是木板(minecraft:planks)下面的data就是木板的数据值，4就是金合欢木的木板。
上面的可以随便改哦～
