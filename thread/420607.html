What does this plugin do?

This plugin allows your players to have (multiple) virtual chests!

这个插件允许你服务器里的玩家拥有一个或多个虚拟箱子


这个插件的好处：
1、不需要合成
2、不会占用身上的一个格子
3、可以说数量不限制
4、死亡不掉落
5、需要权限，没有权限的玩家无法使用（需要赞助的服主可以卖箱子哦）
更新内容
6.支持UUID
7.增加SQLite 和 MySQL数据库支持
8.修复了书的文字消失问题
9.修复了物品lore消失的问题（类似rpg武器的各种描述、名字、功能等）
10.修复了骷髅头bug
11.配置文件可以修改中文（注意转码）
12.增加数据转移，当插件更新时，可以把congfig文件转为数据库，老的配置文件config会备份为congfig_old

Commands:（指令）

/chest <number> - Opens the chest with the number <number>  (If no number is used it will default to chest number 1)

使用指令/chest <数字> - 打开指定数字号的虚拟箱子（如果只输入/chest 将会默认打开1号箱子）

/admchest <player> <chest_number> - Opens the chest from a player - Since v1.5

使用指令/admchest <玩家> <箱子号码> - 打开指定玩家的该号箱子（建议不要把此权限给玩家，给op用的指令），此功能只有1.5版本及以上才能使用
Permissions:（权限）

To open at least one chest: chestmaster.open

可以打开至少一个箱子（如果没有给其他权限，只能打开1号箱子）：chestmaster.open

To use /admchest: chestmaster.admchest - Since v1.5

可以使用指令/admchest - 需要1.5及以上版本建议此权限不要给玩家:chestmaster.admchest

Permission to open multiple chests: chestmaster.multiple.amount

有权限打开除了1号以外的其他箱子: chestmaster.multiple.amount
例如：/manuaddp zhangsa chestmaster.multiple.5,那么张三就可以输入/chest 5打开5号箱子，但不能打开2号3号等箱子

amount should be replaced with the amount of chest the player should be allowed to open (Ex: If you give them the permission chestmaster.multiple.5 they will be able to use from /chest 1 to /chest 5)

这一条说的如果给了chestmaster.multiple.5 权限，那么玩家可以打开1-5号箱子，颗事实上我在服务器测试只能打开5号箱子

This plugin sends statistics about the usage to the server http://mcstats.org/. You can disable it in the config file You can also disable the updater on the config

自动更新可以在config文件里关闭

  ★如果觉得输入指令麻烦，可以搭配RPGitem，快捷菜单等插件免指令使用★
！注意：1、v1.5版本支持1.8,1.7.4，1.52，实测支持1.7.2，兼容mcpc
              2、1.5版本新增/admchest <玩家> <箱子号码>指令，但是最好不要用，因为当玩家和op同时打开一个箱子                     时，玩家往里面放的东西会消失，此指令不能打开离线玩家的箱子
