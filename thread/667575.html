作者: cc7w    时间: 2017-1-26 21:33
跟着教程走↓
地皮被认领时可以读取sch文件

首先设置好没有认领时你的地皮世界



然后建设好模板




无视上面的regen和delete
最后一行 我认领了地皮 建设好了模板

然后站在地皮内输入



/p schematic save

然后到后台plugins/PlotSquared/schematics/
里面会生成一个文件 把它重命名成一个简单的名字
这里我命名成 aaa.s.......






然后前往plugins/plotsquared/config/world.yml#

找
    schematic:
      specify_on_claim: false
      on_claim: false


把onclaim改成true
把file: 'null'
改成
file: aaa←那个名字

然后保存
后台 /p reload

然后地皮被认领时候就会自动读取这个模板了

其他的都不管
按照原贴
第一步,下载桥梁temple文件！
第二步,放入plugins\PlotSquared\templates下！
第三步输入指令/plot template import 世界名字 bridge

删掉生成的世界 （多世界插件里面有关地皮的也要删）
然后删掉地皮配置中worlds.yml         
再去\plugins\PlotSquared\schematics\GEN_ROAD_SCHEMATIC      
吧里面的文件放到\plugins\WorldEdit\schematics

用创世神导入schematics        
修改成你想要的路  然后在保存
（这样可以帮助你理解如何生成路面）
放回原来的地方
intersection是十字路口
plot是地皮
sideroad是路


可以修改宽度
plugins\PlotSquared\templates下的tmp-data同步修改
高度64不要改
