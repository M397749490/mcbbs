我做了什么手脚？[BUG修复了什么]


直接移除了MOD的respawnHunger功能
也就是config中的

    # hunger value set after respawning for peaceful/easy difficulty [vanilla: 20] [range: 0 ~ 2147483647, default: 20]
    I:respawnHungerValue=20

这项配置将不再生效，丢失此功能


[食用方法]
随便下载个压缩工具，用压缩包打开原来的MOD

然后把修复补丁[即RespawnHungerModule.class]替换
