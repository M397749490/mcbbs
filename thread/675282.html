作者: ysy960108    时间: 2017-2-19 09:06
如果有mv多世界插件，在配置文件里设置world里 build:false即可
如果有领地插件，那么可以找到Flags: ,添加一个world世界的配置，看起来如下：
  1.     # 这个是世界flag,不在领地中时
  2.     Flags:
  3.         Global: #下面这些为世界总体默认flag设置, 这会覆盖各个组的设置
  4.             use: true
  5.             build: true
  6.             ignite: true
  7.             firespread: true
  8.             damage: true
  9.             creeper: true
  10.             tnt: true
  11.             pvp: true
  12.         World:
  13.             use: true
  14.             build: false
  15.             ignite: false
  16.             firespread: true
  17.             damage: true
  18.             creeper: true
  19.             tnt: true
  20.             pvp: false
复制代码

这样就单独设置了在world世界且不在领地中时，玩家无法破坏放置方块和pvp，可以use。
