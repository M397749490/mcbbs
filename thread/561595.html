是Bungeecord就对了，这个问题我在1.7测试BC时遇到过，当时网上没什么好的解决方式我就慢慢尝试修复，其实因为所有的世界都在world文件夹后，服务器启动时它会一个个取读但是有时候它会无视在world里面的地图，只取读了world这么一个，才造成了登录时dimension错误，因为玩家没地方生成233
我当时研究出了两种方式
第一种（治标不治本，但是快）
将所有地图文件夹内（除了world地图以外）的.dat文件删除，意思就是把地图内玩家的坐标之类的信息全部删除，让服务器重新加载（这种有时候无效，还不建议）
第二种（有点麻烦，但是复制修改还是很快的）
dimension错误是因为地图没有一直被加载，然后服务器默认就不加载了（这样说你懂不懂？）
嘛实际操作一下就会懂的，你打开cauldron.yml
到最下面你会发现
  1. world-environment-settings:
  2.   normal:
  3.     keep-world-loaded: true
  4.   nether:
  5.     keep-world-loaded: true
  6.   the_end:
  7.     keep-world-loaded: false
  8. 还有XXX
复制代码

你要做的就是将你的地图名称加到这列表里面例如你有一个地图叫做mcbbs你就这样加
  1. world-environment-settings:
  2.   normal:
  3.     keep-world-loaded: true
  4.   nether:
  5.     keep-world-loaded: true
  6.   the_end:
  7.     keep-world-loaded: true
  8.   mcbbs:
  9.     keep-world-loaded: true
复制代码

the_end是末地世界，默认是false你最好也改成true
keep-world-loaded的意思就是保持世界加载，然后dimension问题就自解了~
