  插件特性  

  • 能让你使用钥匙来打开宝箱
  • 打开宝箱只需要使用工作台（包括玩家自带的2*2的），而不需要任何指令
  • 每个宝箱给予玩家1个物品
  • 支持MythicDrops和CrackShot中的物品（这两个插件都可在mcbbs的插件版找到）



  如何使用  

打开工作台，放入宝箱和钥匙，点击合成结果栏的泥土，就可以立即获得宝箱中的物品，同时进行全服公告



  作者的截图  












  指令  

  • /lc give <crate/key> <类型> [数量] [玩家]（给予玩家指定类型的宝箱或钥匙）
  • /lc reload（重载插件）
/lc可以替换为/lootcrates或/crates



  权限  

  • LootCrates.give
  • LootCrates.reload



  自动更新  

插件中含有自动更新器，可以自动的检查更新并提醒你，确保你使用的是最新的版本。如果你想禁用自动更新，可以把配置文件中的
  1. checkUpdate: true
复制代码
改为
  1. checkUpdate: false
复制代码


  配置文件  

  1. #宝箱名#
  2. crateNames: "&lCrate %name%"
  3. #宝箱附注#
  4. crateLore: "Crate: "
  5. #钥匙名#
  6. keyNames: "&lKey %name%"
  7. #钥匙附注#
  8. keyLore: "Key: "

  10. #开箱时是否公告#
  11. broadcastUnboxes: true
  12. #使用数据统计（会上传数据至mcstats.org）
  13. useMetrics: true
  14. #自动检查更新
  15. checkUpdate: true

  17. #宝箱配置
  18. crates:

  20.   Default:

  26.       - DIAMOND 5 name:&6Diamond   
  27.       - DIAMOND_BLOCK 2 x:2
  28.         #ID 数量 [附魔：种类 等级]

  30.         #ID 数量 附注 [附魔：种类 等级]

  33.       # This required "useEconomy" set to true and with Vault installed
  34.       #需要将“useEconomy”设置为ture，并且安装了Vault
  35.       - LEATHER_CHESTPLATE 1 color:255,165,2 money:50.0
  36.   NoLock:
  37.     material: ENDER_CHEST
  38.     rewards:

  40.       - DIAMOND 1
