这是一款强大的全息插件,支持图片和文字符号，有很多功能和自定义内容，性能好。

  • 语言和设置百分百可自定义
  • 插件性能好,不会照成卡服现象
  • 支持生成图片：玩家头颅,二层皮肤头颅,URL链接,文件
  • 支持动态文字制作,不需要下载附属
  • 支持修改彩虹颜色符的颜色和符号例如&u
  • TAB补全指令(甚至可以检测文件夹内的图片进行补全),几乎所有命令都可以
  • 支持Unicode符号和PAPI占位符
  • 修改动态本文的延迟


/holo help -> 查看帮助
  权限: None
/holo info <Holo-ID> -> 查看指定全息图的信息
  权限: GHolo.Info
/holo list [<Radius>] -> 列出所有全息图/地标
  权限: GHolo.list
/holo create <Holo-ID> -> 创建新的全息图
  权限: GHolo.Create
/holo remove <Holo-ID> -> 删除全息图
  权限: GHolo.Remove
/holo tp <Holo-ID> -> 传送到全息图的位置
  权限: GHolo.Tp
/holo tphere <Holo-ID> -> 把全息图移动到你的位置
  权限: GHolo.TpHere
/holo arow <Holo-ID> <Text> -> 给全息图添加一行文字
  权限: GHolo.ARow
/holo rrow <Holo-ID> <Row> -> 删除全息图内的指定第几行文字
  权限: GHolo.RRow
/holo irow <Holo-ID> <Row> <Text> -> 给全息图指定行内添加一行文字
  权限: GHolo.IRow
/holo srow <Holo-ID> <Row> <Text> -> 更改全息图指定行的文字
  权限: GHolo.SRow
/holo mrow <Holo-ID> <Row> <Row> -> 把全息图第x行和第x行的文字进行替换
  权限: GHolo.MRow
/holo image <Holo-ID> avatar/helm/file/url <Value> [<Size>] -> 给全息图导入图片
  权限: GHolo.Image
/holo copy <Holo-ID-Source> <Holo-ID-Target> -> 复制全息图到另一个全息图
  权限: GHolo.Perm
/gholoreload -> 重载插件
  权限: GHolo.GHoloReload

创建全息图，动态字和添加,替换,复制,导入文件,URL,头像,双层头像的方法


/holo create test #创建一个全息图
/holo arow test 我是全息图内的文字 #添加一行文字
/holo irow test 1 我才是第一 #在第一行插入一行文字
/holo mrow test 2 1 #把第一行文字替换到第二行
/holo copy test test2 #把test全息图复制到test2全息图
/holo image test avatar/helm 玩家id 16,16 导入玩家的头颅皮肤/双层覆盖,设置他的大小
把一个图片文件放入GHolo\images中
/holo image test file test.png 16,16 #导入一个图片文件,设置他的大小
找到一个图床,把图片放进去,获取图片链接
/holo image test URL xxxx 16,16 #导入一个链接内的图片,设置他的大小
