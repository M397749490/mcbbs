作者: lgou2w    时间: 2019-5-17 13:39
Vault 插件仅仅只是提供一层开发者 API 接口，由于你获取的是 Economy 经济服务，所以你需要给服务器安装至少一种经济插件。例如Essentials 等等。否则你 setupEconomy 函数里面永远获取不到有效的经济服务提供者。
