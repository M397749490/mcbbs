如果那个插件支持PlaceholderAPI，就能创建自己的变量
如果是HD，你需要安装HolographicExtension才能支持PlaceholderAPI；
下面是PlaceholderAPI的方法：
  1. public class MicroWars extends PlaceholderExpansion {
  2.     // 防止/papi reload 挂钩失效
  3.     public boolean persist() {
  4.         return true;
  5.     }
  6.     public String getAuthor() {
  7.         return "作者";
  8.     }

  10.     public String getIdentifier() {
  11.         return "test";
  12.     }
  13.     public String onPlaceholderRequest(final Player player, final String s) {
  14.         if (s == "awa") {
  15.             return "233";
  16.         }
  17.         return "";
  18.     }
  19. }
复制代码

然后使用%test_awa%，就会显示“233”
这个方法只能用在最新版PlaceholderAPI
