可以实现 写个附属什么的就行了
(我是萌新 有哪里说错还请大佬指正)
以WorldGuard插件圈的领地举例 这个插件本身就能丢进lib里当api用
import下面一系列程序包让你的附属获取WorldGuard的圈地范围
com.sk89q.worldguard.protection.ApplicableRegionSet
com.sk89q.worldguard.protection.managers.RegionManager
com.sk89q.worldguard.protection.regions.ProtectedRegion

虽然和你的要求有点出入 但是类似的逻辑是能用的
当然如果要实现的话 还要import res的圈地事件 自行研究吧(大雾

    *WorldGuardRegionHook

  2.     @Override
  3.     public List<String> getRegionNames(Location loc) {
  4.         List<String> regionNames = new ArrayList<>(1);  
  5.         RegionManager regionManager = com.sk89q.worldguard.WorldGuard.getInstance().getPlatform().getRegionContainer().get(BukkitAdapter.adapt(loc.getWorld()));     
  6.         if(regionManager != null){
  7.             ApplicableRegionSet applicableRegionSet = regionManager.getApplicableRegions(BukkitAdapter.adapt(loc).toVector().toBlockPoint());
  8.             Set<ProtectedRegion> regionSet = applicableRegionSet.getRegions();
  9.             //清除父类领地
  10.             Iterator<ProtectedRegion> itr = applicableRegionSet.iterator();
  11.             while (itr.hasNext()) {
  12.                 ProtectedRegion region = itr.next().getParent();
  13.                 while (region != null) {
  14.                     regionSet.remove(region);
  15.                     region = region.getParent();
  16.                 }
  17.             }
  18.             for (ProtectedRegion region : regionSet) {
  19.                 regionNames.add(region.getId());
  20.             }
  21.         }
  22.         return regionNames;
  23.     }
