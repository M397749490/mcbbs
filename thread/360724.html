mv中文设置教程：
进入服务器文件夹\plugins\Multiverse-Core，找到worlds.yml
打开，最好用notepad++，然后找到世界对应的 alias: 'world'
其中world就是你要的世界名
就像这样：
之前的世界叫123
worlds:
  '123':
    ==: MVWorld
    hidden: 'false'
    alias: '123'
    color: WHITE
    style: NORMAL
之后就改成了 IF
worlds:
  '123':
    ==: MVWorld
    hidden: 'false'
    alias: 'IF'
    color: WHITE
    style: NORMAL

作者: fanglys    时间: 2014-11-3 18:21
修改前缀的话这个需要使这两个世界使用独立的权限表，找到/Groupmanager/config.yml使用notepad++或者其他文本编辑工具打开并编辑：
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          替换为地皮世界的名字:
          - users     //只继承主世界的users.yml，不继承groups.yml
          替换为资源世界的名字:
          - users     //只继承主世界的users.yml，不继承groups.yml
          all_unnamed_worlds:
          - users
          - groups
复制代码
之后重新加载权限组插件/manload
然后在/Groupmanager/worlds/目录会生成名字有地皮和资源两个世界世界名命名的目录，里面各自有一个groups.yml。
将同目录下world中的groups.yml复制到上述两个新目录并覆盖自动生成的上述两个groups.yml。
打开上述地皮世界目录下的groups.yml，找到默认组的下列代码：
    inheritance: []
    info:
      prefix: ''
      build: true
      suffix: ''
复制代码
修改为
    inheritance: []
    info:
      prefix: '[地皮] '
      build: true
      suffix: ''
复制代码

同理修改资源世界的groups.yml
修改完后重新加载权限组插件/manload
