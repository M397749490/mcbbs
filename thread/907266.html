再顺便问一句，有没有记录敌对生物仇恨对象的NBT
没有。如果要吸引仇恨的话，可以用带有特定 owner 的雪球去砸。
例子：先召唤一个 tag=233 的雪球，然后：
  1. data modify entity @e[type=snowball,tag=233,limit=1] owner.L set from entity @p UUIDLeast
  2. data modify entity @e[type=snowball,tag=233,limit=1] owner.M set from entity @p UUIDMost

这里是将雪球的 owner 变成玩家 @p，也就是让被雪球砸到的生物的仇恨在 @p 身上。
