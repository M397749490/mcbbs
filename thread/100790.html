前置插件(非必要)：Vault

如题，这是可以最大程度自由调用各种声音、视觉特效的插件

&#10051;可设置登陆后的自动特效
&#10051;可让效果囊括周围玩家
&#10051;支持方块破裂效果和物品掉落效果
&#10051;支持随机烟花
&#10051;支持对怪物施放特效
&#10051;支持对方块施放特效
&#10051;支持声音特效。例如：/sparksound enderdragon_growl - 将发出末影龙的吼声
注：block中的id和字符串，都表示方块英文名称，比如stone

eg：/sparkblock set savename 3 stone

命令：

  1. /stupdate - 下载更新

  3. /sparkmenu - 基础库存菜单
  4. /spark - 帮助菜单和命令用法
  5. /spark list - 效果列表
  6. /spark list <组> - 列出指定组的效果
  7. /spark stop - 停止当前效果
  8. /spark <效果> - 施放指定效果
  9. /spark potion <颜色> - 施放药水破裂效果
  10. /spark swirl <颜色> - 施放药水旋绕效果
  11. /spark block <字符串类型> - 施放方块破裂效果
  12. /spark blockid <id> - 施放方块破裂效果
  13. /spark itemdrop <颜色> - 施放物品掉落效果
  14. /spark player <玩家名称> <效果> - 对其他玩家施放效果
  15. /spark player <玩家名称> potion <颜色> - 对其他玩家施放药水破裂效果
  16. /spark player <玩家名称> blockid <字符串类型> - 对其他玩家施放方块破裂效果
  17. /spark player <玩家名称> swirl <颜色> - 对其他玩家施放药水旋绕效果
  18. /spark player <玩家名称> itemdrop <物品ID> - 对其他玩家施放物品掉落效果
  19. /spark player <玩家名称> stop - 停止其他玩家效果

  21. /sparkblock - 显示SparkBlock方块帮助菜单
  22. /sparkblock set <保存名称> <间隔时间> <效果> - 在面前的方块上施放效果
  23. /sparkblock set <保存名称> <间隔时间> potion <颜色> - 在面前的方块上施放药水效果
  24. /sparkblock set <保存名称> <间隔时间> blockid <字符串类似> - 在面前的方块上施放方块破裂效果
  25. /sparkblock <保存名称> <间隔时间> itemdrop <物品ID> - 在面前的方块上施放物品掉落效果
  26. /sparkblock stop <保存名称> <效果类型> - 停止一个已保存的效果并移出内存
  27. /sparkblock list <组> - 查看指定的SparkBlock效果参数
  28. /sparkblock start <保存名称> <效果> - 启动一个已保存的效果
  29. /sparkblock remove <保存名称> <效果> - 移除一个已保存的效果
  30. /sparkblock firework - 查看SparkBlock Firework烟花帮助列表
  31. /sparkblock firework set <保存名称> <间隔时间> <参数> - 在面前的方块上施放烟花效果
  32. /sparkblock firework start <保存名称> - 启动一个已保存的烟花效果.
  33. /sparkblock firework remove <保存名称> - 移除一个已保存的烟花效果.
  34. /sparkblock firework stop <保存名称> - 停止一个已保存的烟花效果并从内存移除.
  35. /sparkblock firework list - 列出烟花效果参数.
  36. /sparkblock firework list <组> - 列出指定组的效果

  38. /sparkfw - 查看SparkFireworks烟花帮助菜单
  39. /sparkfw <参数> - 施放一个烟花效果
  40. /sparkfw player <玩家名称> <参数> - 对其它玩家施放烟花效果
  41. /sparkfw help - 查看烟花命令说明
  42. /sparkfw list - 列出烟花参数
  43. /sparkfw stop - 停止当前的SparkFirework烟花效果
  44. /sparkfw change <旧属性> <新属性> - 更改同组中烟花效果的属性
  45. /sparkfw add <新属性> - 为当前烟花效果添加属性
  46. /sparkfw remove <旧属性> - 移除已激活的烟花效果属性

  48. /sparkmob - 查看SparkMob怪物帮助菜单
  49. /sparkmob <效果> - 对当前怪物施放指定效果
  50. /sparkmob firework <参数> - 对当前怪物施放烟花效果
  51. /sparkmob potion <颜色> - 对当前怪物施放药水破裂效果
  52. /sparkmob block <字符串类型> - 对当前怪物施放方块破裂效果
  53. /sparkmob itemdrop <物品id> - 对当前怪物施放物品掉落效果
  54. /sparkmob stop - 停止当前怪物的效果
  55. /sparkmob deactivate - 取消激活怪物控制
  56. /sparkmob list - 列出所有可用的SparkMob效果
  57. /sparkmob firework list - 列出所有可用的怪物烟花参数

  59. /sparksound - 查看SparkSound声音帮助菜单
  60. /sparksound <声音> - 播放声音效果
  61. /sparksound login set <声音> <玩家名称> - 为指定玩家设置登陆音乐效果
  62. /sparksound login remove <玩家名称> - 移除指定玩家登陆音乐效果
  63. /sparksound login group <权限组> set <声音> - 为指定权限组设置登陆音乐效果
  64. /sparksound login group <权限组> remove - 移除指定权限组登陆音乐效果
  65. /sparksound list - 列出可用的音乐效果

  67. <组>是指一个效果类型
  68. <保存名称>指将所做的改动保存到的文件名，用于下次加载

  70. 比如：/spark list potion - 将显示所有的potion效果
