fishing_rod.json
  1. {
  2.     "parent": "item/handheld_rod",
  3.     "textures": {
  4.         "layer0": "items/fishing_rod_uncast"
  5.     },
  6.     "overrides": [
  7.         {
  8.             "predicate": {
  9.                 "cast": 1
  10.             },
  11.             "model": "item/fishing_rod_cast"
  12.         }
  13.     ]
  14. }
复制代码
抛出前的json有个predicate定义抛出后使用fishing_rod_cast，
你的fisning_rod连overrides都没有，自然不会读取fishing_rod_cast
