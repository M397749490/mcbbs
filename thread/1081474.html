如题，如何让所有玩家背包中的所有武器一键无限耐久（就是集体施展无限耐久nbt，想要1.12.2的数据包，谢谢大佬）
作者: Freeze_Dolphin    时间: 2020-7-19 12:17
使一个物品无限耐久应该是item.getItemMeta().setUnbreakable(true);

所以你只要遍历一下背包就可以做到了

Inventory inv = ...;
for (int s = 0; s < inv.getSize(); s++) {
    ItemStack i = inv.getItem(s);
    if ( ... ) { ... } // 对物品作出判断，判断是否是武器
    ItemMeta im = i.getItemMeta();
    im.setUnbreakable(true);
    i.setItemMeta(im);
}
