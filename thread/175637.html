这个插件让扔出末影珍珠会有冷却时间和金钱的花费。
目标


  • 平衡PVP
  • 阻止利用末影珍珠自由进出领地
配置文件

例子(默认设定):
cooldown: 3000 #冷却时间(毫秒)

price: 0 #价格

showMessage: true #显示提示信息

此外还能自定义提示信息! 可谓狂霸酷炫X炸天!






  • 1.玩家在冷却时间内不能投掷下一个末影珍珠
  • 2.设定投掷需要花费的钱
  • 3.提示信息则会在玩家不能使用末影珍珠却使用时发出提示(不会扣除末影珍珠)
命令
/epc reload 重载命令

权限
enderpearl.cooldown:拥有冷却时间
  default: true

enderpearl.use:使用
default: true

enderpearl.pay:需要花钱
default: true

enderpearl.admin:能使用/epc reload重载命令
  default: op



英语小词典
1.default  默认 n.(名词)
2.true 真(在此意为开启/关闭) adj.(形容词)
3.false 假 adj.(形容词)
