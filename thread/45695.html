本帖最后由 v_sky 于 2012-10-7 17:13 编辑

一款专门在MC里录制视频的MOD，比FRAPS之类的专业多了。而且这个MOD可以在低配置的情况下流畅录制视频！
MineVideo使您能够记录游戏中的画面与触摸一个按钮。需要MODLOADER！
按F4开始录制，在录制状态下按F4结束录制。按F6调出设置菜单。


Audio Recording=是否录制音频。选项：On、Off
Audio Format=音频格式
Stereo=是否开启立体声。选项：On、Off
Sample Rate：音频的频率，默认为8000mHz。
Output Directory=输出目录。
File Name Template=文件名格式


Video Format=视频格式。
Frame Rate=录制时的FPS。
Output Directory=同上。
File Name Template=同上



下载链接（Bukkit Dev）：
