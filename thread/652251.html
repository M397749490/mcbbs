粘液科技 - 介绍



粘液科技是一个Bukkit插件，旨在一定程度上代替Mod。
使得Bukkit类服务器无需Forge即可享受Mod般的体验。
它提/供了你能想到的一切，从背上背包出门探险到喷气背包遨游天际。
作者同样还加入了 API 让dalao们快速安装/编写这款插件的 Addons。
你的服务器玩家，是不是已经厌倦了无聊的纯净生存？
那么你绝对会喜欢这款插件！它新增了400+个物品，给服务器生存带来更多的乐趣！


Slimefun DEV



粘液科技 - 权限 & 指令
指令：
  1. /slimefun - 基础的粘液科技指令 (或使用 /sf)
  2. /sf cheat - 允许你通过作弊获取粘液科技所有物品
  3. /sf guide - 给自己一本粘液科技指南
  4. /sf give <玩家ID> <粘液科技物品名> - 给某位玩家粘液科技物品
  5. /sf version 显示粘液科技版本及其Addons</font>
  6. /sf research <玩家ID> <研究名/all/reset> 通过指令来获取/重置研究</font>
  7. /sf stats [玩家] - 显示关于你的统计或其他玩家的统计</font>
  8. /sf timings 展示关于粘液科技的一些性能信息</font>
  9. /sf debug_fish [Debug模式] 给予你自己一个debug工具</font>
  10. /sf version 展示粘液科技版本&扩展版本
复制代码


权限：
  1. slimefun.cheat.items 可以使用 /sf cheat 及可切换至作弊模式
  2. slimefun.cheat.researches 可以使用 /sf research 解锁/清空研究
  3. slimefun.command.timings 允许使用 /sf timings
  4. slimefun.stats.other 允许你查看其他玩家的统计
  5. slimefun.android.upload-script 允许玩家上传自己的机器人脚本至服务器
  6. slimefun.android.bypass 允许你编辑他人的机器人
  7. slimefun.cargo.bypass 允许你使用他人的货运节点
  8. slimefun.inventory.bypass 允许你在受保护的区域打开粘液科技的机器
复制代码



注意事项

在食用本插件中您需要注意 :
使用本插件时为保证汉化文件不被丢失，请关闭 Slimefun 与 CS-CoreLib 的自动更新
此插件需要 CS-CoreLib 支持，请至贴内下载指定版本以保证最全汉化。

16.粘液科技机器人无视领地破坏

危害等级：中
实施难度：中
解决方案：在权限管理的配置文件当中移除玩家权限 slimefun.android.upload-script （上传或使用安卓机器人脚本的权限）
或在配置文件当中禁用可编程安卓机器人
[m](如果您为了玩家更好的体验, 可以仅禁用有破坏/放置功能的机器人)[/m]
实际上改改class就可以不破坏箱子熔炉啥的


19. 使用“能源与电力”当中的机器刷取物品
危害等级：高
实施难度：中
解决方案：
在配置文件中禁用“能源与电力”当中的机器。
(如果为了您的玩家更好体验，可以在每次重启前 /kickall 踢出所有玩家)


20. 使用“古老祭坛”刷取物品
危害等级：中
实施难度：中
解决方案：
在配置文件中禁用“古老祭坛” ANCIENT_ALTAR
V4.1.9 已修复


21. “古老祭坛”配合漏斗矿车转化原版物品
危害等级：中
实施难度：中

解决方案：
在配置文件中禁用“古老祭坛”(ANCIENT_ALTAR) 或 禁止漏斗矿车的使用
V4.1.9 貌似修复 安全起见禁用漏斗矿车吧



22. 利用“伐木斧头”破坏领地和消耗服务器资源
危害等级：中
实施难度：低

解决方案：
在配置文件中禁用“伐木斧头”
（并不怎么卡233）

23. 使用阳光传感器代替太阳能板制作数字挖矿机/高级数字挖矿机
危害等级：低
实施难度：中
触发流程：
数字挖矿机/高级数字挖矿机 (DIGITAL_MINER/ADVANCED_DIGITAL_MINER) 的配方需要太阳能板，而使用阳光传感器代替后，挖矿机同样能够运行，某种程度上减降低了成本。

解决方案：
如有需要，可在配置文件中禁用DIGITAL_MINER和ADVANCED_DIGITAL_MINER

个人注：其他的物品也是可以这么做的，例如里面需要的24K金块

===========================================================

SEISMIC_AXE 地震斧

SCROLL_OF_DIMENSIONAL_TELEPOSITION 维度传送卷轴
PICKAXE_OF_VEIN_MINING 矿脉稿 (V4.1.7及以后版本已修复 / 但仍然可以选择封禁)
EXPLOSIVE_PICKAXE 爆炸镐
TOME_OF_KNOWLEDGE_SHARING 知识巨著
DIGITAL_MINER/ADVANCED_DIGITAL_MINER 数字挖矿机/高级数字挖矿机

============================================================

封禁物品教程：
打开 /plugins/Slimefun 下的 Items.yml
您可能会看见以下内容:
  1. ORE_CRUSHER:
  2.   double-ores: true
  3.   enabled: true
  4.   can-be-used-in-workbenches: false
  5.   allow-enchanting: true
  6.   allow-disenchanting: true
  7.   required-permission: ''
  8.   wiki: https://github.com/TheBusyBiscuit/Slimefun4/wiki/Ore-Crusher
  9. GRANDMAS_WALKING_STICK:
  10.   enabled: true
  11.   can-be-used-in-workbenches: false
  12.   allow-enchanting: true
  13.   allow-disenchanting: true
  14.   required-permission: ''
  15.   wiki: https://github.com/TheBusyBiscuit/Slimefun4/wiki/Walking-Sticks
复制代码
此处使用 Notepad++ 作为教程演示， 按下 Ctrl+F 搜索你需要的物品，此处以(SCROLL_OF_DIMENSIONAL_TELEPOSITION) 维度传送卷轴
为例：

在查找目标内填写: SCROLL_OF_DIMENSIONAL_TELEPOSITION，单击 "查找下一个".
您会看见以下内容:

SCROLL_OF_DIMENSIONAL_TELEPOSITION:
  enabled: true
  can-be-used-in-workbenches: false
  allow-enchanting: true
  allow-disenchanting: true
  required-permission: ''

将其中的 enabled: true 改为 enabled: false, 封禁物品完成.
重启服务器后就会生效.
