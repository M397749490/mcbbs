以后请把版本号说一下
我这里是1.9的
首先创建俩个记分板
  1. /scoreboard objectives add kill playerKillCount
复制代码
  1. /scoreboard objectives add death deathCount
复制代码

摆放方法均为保持开启 绿色的均为条件制约
  1. testfor @a {SelectedItem:{id:"minecraft:diamond_sword",Count:1b,tag:{display:{Name:"killer"}}}}
复制代码
检测你是否手持名叫"killer"钻石剑
  1. /scoreboard players set @a[score_kill_min=1] kill 0
复制代码
如果有，则设置所有记分板kill大于等于1的人记分板kill项目=0
  1. /tellraw @a ["",{"selector":"@p[score_death_min=1]"},{"text":" is foolish"}]
复制代码
如果设置成功（没打死就不算的意思），则告诉所有人: <那个记分板death大于等于1的人>is foolish
  1. /scoreboard players set @a[score_death_min=1] death 0
复制代码
将所有记分板death大于等于1的人记分板death项目=0

想你那样子在原版里一般只能用命令实现
