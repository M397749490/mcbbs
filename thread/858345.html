TreasureHunt 介绍

TreasureHunt - 寻宝插件 - 在你的服务器地图放置超级宝藏
让你的玩家通过冒险去寻找这些宝藏
增加玩家的玩法乐趣~~
在世界的某地方生成宝藏
在世界自动生成宝藏
在海洋或者岩浆中生成宝藏
当玩家在线人数达到生成宝藏
自定义创建宝藏类型
自定义创建宝物
宝箱保护
UUID支持


该插件为付费插件价格为2.99USD请到原贴购买
TreasureHunt 图示
TreasureHunt 指令权限
/th - 查看你可以使用的权限命令
/th help - 寻宝帮助
/th list - 显示所有可以寻到的宝藏
/th top - 显示当前寻宝玩家的信息
/th start - 开始寻找宝藏
/th despawn - 移除世界上的所有宝藏

treasurehunt.item - 使用寻宝指令
treasurehunt.command.help - 查看寻宝帮助
treasurehunt.command.list -显示可以在世界上寻找到的宝藏
treasurehunt.command.top - 显示当前寻宝玩家的信息
treasurehunt.command.start - 开始寻找世界宝藏
treasurehunt.command.despawn - 移除世界上的所有宝藏
TreasureHunt 安装教程
1.从正确的渠道获取插件
2.将获取到的插件放进服务端的 plugins 文件夹
3.重启服务器
