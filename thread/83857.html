作者: xeji    时间: 2013-1-31 16:28
手拿木斧，左键一角，右键一角，两角之间的长方体为选择区域：
//set id - 将选中的区域变为某物品(如果是不可放置或者没有放置点的物品会成为被扔出的状态)
//undo - 还原上一次的WorldEdit行动
//redo - 还原上一次的//undo（这个说明可能有误）
//move x - 将区域移动x块。移动时需正对着你要移动的区域，他就会帮你移动到你正对的地方
//move x up - 将区域向上移动x块
//move x down - 将区域向下移动x块
/criticalhit [enable|disable]
开启关闭致命一击

/clouds [enable|disable]
是否显示云

sprinting [enable|disable]
总是冲刺

climb
无需梯子能攀爬任何墙面

spawner <TYPE>
改变玩家所在区域刷怪器的怪物种类

effect <list|remove TYPE|add TYPE [DURATION] [STRENGTH]>
设置药水效果

fog [tiny|small|normal|far]
改变视野距离

enderman pickup [enable|disable]
Enderman拾取物品开启关闭

enchant <list|remove|add TYPE [LEVEL]>
对当前物品附魔

xp <add QTY|get|set XP>
XP (player experience)经验值命令

hardcore <enable|disable>
是否开启变态模式（游戏最高难度）

calc
计算机

useportal <normal|nether|end|PORTAL>
传送命令
特别提示: 输入 “= 算式”可以简单的使用计算机
比如: = 4 * 4

更多命令帮助信息输入?/help <命令名称>

helmet [ITEM] [QTY] [DAMAGE]
换头盔和头盔的防御度啥的。。

slippery <BLOCK> [SLIPPERYNESS]
让某个块变得很滑（像冰）

longerlegs
让腿更长，可以跳2格等

atlantis
亚塔兰迪斯模式

spawnportal
制作一个地狱传送门

clone [QUANTITY]
复制你正在看的npc （鼠标对着的）

killall <MOBTYPE>
杀掉指定的某个怪

flammable <BLOCK> [CATCH] [SPREAD]
让某个块可燃烧

clearwater
让水变得清澈

confuse [DISTANCE]
让附近的怪眩晕

confusesuicide
让怪互咬 搞内讧

cyclepainting
可以看你对着的那幅画 （也就是能不把画拿下来再放上去 可以直接更换）

bring [ENTITY]
让某个物到你这来

superpunch [DISTANCE|reset]
揍某个npc （越来越邪恶了）

phelp [COMMAND]
给帮助

bindid <ID> <COMMAND> {ARGS}
下面有 设置快捷键

unbindid <ID>
取消快捷键

reskin <FILENAME>
穿皮肤

weather <lightning|thunder|rain>
天气 这mod无敌了

/fly [SPEED]
改变飞的速度，5差不多了

/music [play|pause|skip|stop]
可以换音乐

有许多其他的 这几个是最主要的
也许会出错的命令指令列表
有些被删除或者更改了指令 有些1.4不可用

ascend
将玩家移到自己上面一层

biome
告诉玩家在神马环境里 （沙漠，下雪，平原等）

bind <KEYCODE> <COMMAND> {COMMANDPARAMS}
- 给一个指令设置快捷键 格式：bind <键盘的某个键><指令>{指令的参数}个人觉得这个没啥大用 我还是喜欢直接输入- -

cannon [STRENGTH]
这个可以往自己前方发射tnt 格式：cannon 威力/举例 例如cannon 15 就往自己前方15格发射

chest <drop|get|fill|swap>
可以弄一箱子的东西 例如 chest fill 46 就搞了一柜子tnt（1.4没用了貌似）

clear
将聊天窗口清理 （例如你刷了一堆tnt会有一堆give 46 输入了这个全部空白）

config <setglobal [reset]>
可以保存你的配置 （不清楚这个干啥）

damage
伤害 开/关

defuse [all]
去掉自己附近所有已点燃的tnt

descend
- 将你移到你下面的一层

destroy [all]
破环东西

difficulty <LEVEL>
设置难度 （0~3 例如difficulty 3）

drops
物品掉落 开，关

dropstore
把你身上的东西生成一个箱子放在身旁

duplicate [all]
复制你选择要复制的物品

explode [SIZE]
在自己身边弄个爆炸- – （这翻译囧 例：explode 10 就相当于一颗威力10的tnt在自己身边爆炸 但不会伤到自己）

exterminate [SIZE]
可以杀掉你选取的某个npc

extinguish|ext [all]
在自己附近生成火

falldamage
开启，关闭掉落伤害

firedamage
开启，关闭 烧伤伤害

fly
可以飞

freeze
将怪物冻住，他无法攻击你

goto <NAME>
去设置的一个点 （没用过 类似传送）

grow [all]
让自己世界里所有的东西长大 （水稻，树等）

heal <HEALTH>
- 给自己疗伤 输入负的就是减血

health <min|max|infinite>
更换自己的生命 （没啥用）

help [COMMAND]
给某个你输入的指令一些建议帮助 例如 help time 他会告诉你怎么用这个指令

home
将你传送至出生点

infiniteitems
- 开，关无限物品

instantkill
超级屠杀 一击秒杀怪物

instantmine
超级挖矿 除了地壳以外都是点一下就破环

instantplant [grow]
超级种树 可以（种下的树就生长）

item <ITEMCODE|ITEMNAME> [QUANTITY] [DAMAGE]
给自己某个物品 例：give 46 60 给自己60个tnt

itemdamage
物品损伤开，关

itemname
可以探测某个物品

itemstack <ITEMID|ITEMNAME> [QUANTITY]
让某个物品突破叠加64

jump
跳到光标停留的地方

keepitems
可以保留身上的物品 死了也不丢 （渣渣 能刷都）

kill
把自己杀死 （- -）

killnpc [all|monster|animal]
把自己附近所有怪物抹杀咯

light
光线开，关

listwaypoints
显示所有路标

macro <edit|create|dir|folder|delete|list|FILENAME {PARAMS}>
运行某个东西 （不懂此物）

maxstack [ITEMID|ITEMNAME|all] [STACKSIZE]
让物品叠加上限

mobdamage
- 怪物伤不了你

msg <MESSAGE>
添加信息 （不懂这干嘛的）

music [VOLUME]
切换音乐的高低

noclip
不懂这个

output
还是不懂

platform
往自己脚下放个玻璃

plugin <list|enable [MODNAME]|disable [MODNAME]|dlist>
列出所有插件

pos
换自己的角度，位置（不懂）

reach <DISTANCE|reset>
抓取距离 这个很有用 一般举例向下是3 这个可以随便改 例如reach 10 就可以破环自己脚下10格
refill [all]
将自己身上所有物品弄到上限

rem <NAME>
- 移掉某个路标

removedrops [all]
和drops一样

rename <COMMANDNAME> <NEWNAME>
给某个指令换名称

repair [all]
将身上的物品全部修复 （损坏的镐子等）

reset
将玩家的设置换回默认的

return
-将玩家弄回传送之前的地方

ride
-可以骑任何光标指示的怪物 （骑jj怪咯）

sc <FILENAME>
这个有待改善

search <SEARCHTERM>
可以搜索某个物品

set <NAME>
- 添加路标

setjump [JUMP|reset]
可以让自己跳的更高

setspawn [<X> <Y> <Z>]
设置脚下的那一点为出生点

setspeed [SPEED|reset]
- 更换玩家移动速度

skin <USERNAME>
把自己的皮肤换成某个玩家的

spawn <NAME|ID|random|list> [QTY]
-可以召唤某个怪 例如 spawn 50 10000 就是召唤10000只jj怪 电脑不太好的别乱用

spawnstack <NAME|ID|list|random>
召唤几只叠在一起的怪 例如 spawnstack 50 50 50 50 就是4只叠在一起的jj怪

superheat [all]
将自己所有物品转换成烧制后的样子 （粘土-砖头）

tele <X> <Y> <Z>
传送

time [set|get|day|night [minute|hour|day [TIME]]]

换时间

timeschedule <reset | <TIME1> <TIME2>>
可以锁定时间

unbind <KEYCODE|all>
设置某个指令的热键

useportal
把自己移到地狱去

waterdamage
水伤害开，关

world <load|save|seed|new|exit|list|backup>
可以备份，重建自己的世界

world load <FILENAME>
装载一个世界

world save
保存游戏

world seed [SEED]
更换自己世界的种子文件

world new [FILENAME] [SEED]
在指定的地方创建新的环境

world exit
可以强制退出世界 不存档 （若房子被烧了 屋子被jj怪炸成平地了或者被城管光顾了用这个不错）

world list
将自己saves文件里所有的世界列出来

world backup
备份所有的世界

WorldEdit指令

//set 物品ID
放置

//copy
拷贝

//paste
粘贴

//replace 物品ID 新物品ID 丨丨丨水//replace 9 8
替代

//walls 方块ID
造围墙

//sphere 物品ID 半径
造实心球体

//hsphere 物品ID 半径
造空心球体

//hcyl 物品ID 半径
造圆圈

//hcyl 物品ID 半径 高度
造圆柱

//cyl 物品ID 半径 高度
造实心圆柱


（以下小熊改编）
//copy
复制这个区域的所有东西，除了画以外，全部都能复制，包括红石电路
//paste
复制前请站好你的位置，比如我复制一块区域，站在这个区域的正上方
那么我黏贴的时候，东西就会出现在我的脚下，而且是不能改变这个东西的方向的，比如我这个房子的门是朝南的
那么我面朝北复制这个房子，房子还是出现在朝南的位置
注意！！WE之前请一定要看清楚这块区域有没有锁的箱子或者商店，如果你直接WE掉，那么这个箱子占用的这两格子将永远被保护，半砖商店的物品将永远卡在那里，消不掉！！！//rotate 【角度】
让你复制过的建筑先面对你旋转多少度，记住要在//copy之后，在//paste之前使用
