②不检测挖掘等级就是说即使你是空手
loot give @s mine ~ ~ ~ mainhand
挖钻石矿也会掉钻石

③我建议你直接先判断玩家手持物,即
execute as @s[nbt={SelectedItem:{id:"minecraft:diamond_pickaxe"}}] run loot give @s mine ~ ~ ~ mainhand
再执行相关命令

⑤execute as xxx run loot ...... mainhand就可以，百问不如一试，注意原来的方块不会消失，手上的物品也不会减耐久。

首先kill mine fish只能使用entity block fishing类型的战利品表，或未指定类型的。第二，挖掘时并不检测挖掘等级。第三，没明白你的意思。第四，在物品那里写上diamond_pickaxe{Enchantments:[{lvl:1s,id:"minecraft:silk_touch"}]}
第五，物品处填写mainhand即可，幸运效果不影响红石数量
