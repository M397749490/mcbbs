作者: mine新时代xs    时间: 2019-7-31 17:16
大多数mod提供了在特定的世界阻止它们的自然生成的配置选项
请说出你要阻止生成的东西
比如工业2的橡胶树可以在config文件夹中的IC2.int文件夹内的这里修改哪些世界不生成橡胶树：
  1. ; Enable generation of rubber trees in the world.
  2. rubberTree = true
  3. ; Comma separated list of dimensions to not generate rubber trees in
复制代码

举例，如果我不想它在DIM-1和DIM1生成橡胶树
  1. ; Comma separated list of dimensions to not generate rubber trees in
  2. DIM-1,DIM1
复制代码

即可
如果你想要阻止其他什么mod的生成，发给我mod名字和搬运贴地址，我帮你找配置文件中的相关内容
配置好后删除地皮重新生成即可，不想重新生成的话就没办法了，但未加载的区块的地皮则不再会生成
