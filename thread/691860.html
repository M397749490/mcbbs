  Commands - 命令
大多数命令在功能上是会根据玩家是否具有  .user 或者 .admin 权限发生更改的，关于权限的更多信息你可以在 这里 找到。
标注有 * 为管理员命令
/ht 显示如何访问其他功能
/ht help    显示帮助页面
/ht command 显示可用命令 (以权限为基础)
/ht friend|f <add|remove> <旅馆名称> <房间号> <玩家名字> 在指定的旅馆房间信任列表内添加或删除玩家 - 被信任的玩家将会和房间主人拥有同样的房间使用权限
/ht friend|f <list> <旅馆名称> <房间号> 列出指定房间的玩家信任列表
/ht sethome 如果在创建模式下，允许你设置默认旅馆和默认房间，其他玩家可以回设置的家
/ht home|hm <旅馆名称> [房间号] 允许你传送到旅馆或者旅馆房间
/ht list [世界名字] 列出当前/指定世界的所有旅馆列表
/ht rlist <旅馆名字> [世界名字] 列出指定/当前世界指定旅馆的所有房间
/ht check [玩家名字] 列出你/指定玩家租用的所有房间列表
/ht creationmode|cm <enter|exit> 进入/退出创建模式
/ht creationmode|cm reset 保存数据文件以防止插件出错
/ht create|c <旅馆名字> 创建一个目前选择的旅馆
/ht room <旅馆名字> <房间名字> 在指定的酒店内创建当前选择的房间
/ht delete <旅馆名字> 删除指定旅馆
/ht delr <旅馆名字> <房间名字> 删除指定房间
/ht rename|ren <原旅馆名字> <新旅馆名字> 重命名指定旅馆
/ht renum <旅馆名字> <原房间号码> <新房间号码> 重新编排房间号码
/ht sellh <旅馆名字> <玩家名字> <价格> 以优惠的价格将你的旅馆出售给指定玩家
/ht buyr <旅馆名字> <房间名字> 如果房间所有者提供给你了房间转让邀请接受邀请
/ht sellr <旅馆名字> <房间名字> <玩家名字> <价格> 以优惠的价格将您的房间出售给指定的玩家
/ht buyh <旅馆名字> 购买旅馆（如果所有者给你发送了邀请）
/ht reload * 重载插件配置
/ht remove <玩家名字> <旅馆名字> <房间名字> * 从指定房间的所有者移除指定的玩家
/ht roomreset <旅馆名字> <房间名字> * 重置指定房间
/ht resetroom <旅馆名字> <房间名字> * 还原指定房间为原始状态
/rg f <hotel-旅馆名字|hotel-旅馆名字-房间名字> <标志> <标志值>* 例子: /rg f hotel-banana greeting &gWelcome to the banana hotel
/rg f hotel-banana-13 farewell &rCome back soon to room 13 of the Banana hotel!
使用此命令，您可以更改旅馆和房间区域上的任何标志的值

   How to set up a hotel - 如何创建一个旅馆
  • 你可以在游戏用使用命令 /hotels help 获取创建旅馆帮助
  • 进入旅馆创建模式:
    使用命令 /ht [creationmode|cm] [enter] 进入旅馆创建模式
  • 创建旅馆和房间:
    拿出你的 WorldEdit 魔杖（木斧） 并且选取旅馆的左上角和右下角或者使用 //sel poly  进行多边形选择，左键单击第一个点并且右键任何一个点（Y坐标相同的） 然后使用  //expand [up|down] 来把你的酒店包围起来。
    使用 /ht [create|c] [hotelName]
    现在选择其中一个房间并输入 /ht [room] [hotelName] [roomNumber] (如果你改变了他，你可能需要将房间设置为长方体 /sel cuboid)
    你现在可以使用 /ht [cm] [exit] 退出创建模式，你的背包和装备将会恢复。

   Integrations - 联动
  • Gringotts (一个插件):
    关于这个插件，我给各位找到了两个相关链接
    https://www.spigotmc.org/resourc ... icial-release.3473/
    https://dev.bukkit.org/projects/gringotts
    你可以使用Gringotts插件而不是Essentials作为经济插件来使用 items（物品） 而不是 money（金币）
  • Receptioners（接待员）:
    如果您希望将NPC作为接待人员，则需要以下插件：
    Citizens 2  CommandNPC  ChestCommands
    你必须在 ChestCommands 插件文件夹中设置一个菜单. 这里有一个可以与旅馆相联工作的例子。
    然后你必须创建一个新的 Citizens NPC 或者选择编辑一个已经存在的.
    /npc create &1Receptioner --type villager
    然后你需要把ChestCommands菜单配置文件中"command:"绑定到你的NPC上. 在下面这个例子中，命令被设置为 /hotelpig
    /npc addcmd false noPerm hotelpig
    你现在有一个可以被点击然后打开菜单的NPC，菜单将展示旅馆内可用客房并且允许你通过点击其中一个物品来租用它们。请注意，您必须已经创建了房间，并放置了一个房间牌子才能工作（如果你不想让你的玩家看到房间牌子，你可以把牌子藏到隐藏的房间中，但是，在菜单物品的lore中添加租用的时间和价格是个好主意）。

    打开 config.yml 文件并更改 language 项: 对任何可用语言。
    如果你修改了局部语言而且不希望插件插件干扰, 请设置此项为 custom
