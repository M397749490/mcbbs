脚本魔杖直接右键吗？我要的是1.7.10呀0.0

那你早又不说清楚你的版本。
1.7.10要使用脚本，要先到你java的安装目录的jre/lib/ext里把nashorn.jar复制到MC的mods里再启动MC。
用脚本魔杖打开NPC的GUI，进入设置，选“开启”为“是”，
然后进入Scripts标签，点“运行”，粘贴下面的脚本：
  1. npc.getMCEntity().stats.spawnCycle = -1;
复制代码

点“更新”，粘贴下面的脚本：
  1. var mcnpc;
  2. if (world.isRaining() && (mcnpc = npc.getMCEntity()).hasDied && mcnpc.killedtime < new Date().getTime()) {
  3.         npc.reset();
  4. }
复制代码

然后这个NPC就只会在雨天复活。
不过这样之后，打开这个NPC的复活时间界面客户端会崩溃，所以要么添加脚本后不再修改复活时间，要么先把脚本删除，修改复活时间，再把脚本粘贴回去。

如果是1.12.2的话，用脚本魔杖右键点击npc就可以编辑这个npc的脚本。
下面这个脚本可以让npc只在雨天重生。
  1. var System = Java.type("java.lang.System");

  3. function init(event) {
  4.         event.npc.getMCEntity().stats.setRespawnType(-1);
  5. }

  7. function tick(event) {
  8.         var npc = event.npc;
  9.         var mcnpc;
  10.         if (npc.getWorld().isRaining() && (mcnpc = npc.getMCEntity()).hasDied && mcnpc.killedtime < System.currentTimeMillis()) {
  11.                 npc.reset();
  12.         }
  13. }
复制代码
