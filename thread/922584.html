标题: skript怎么判断物品lore存在"攻击力: +1"的那一行！！！
我想要实现这样的功能比如某物品的lore是(两行)
"123456"
"攻击力: +123"

先判断这个物品的lore是否存在"攻击力: +"
然后 设置一个变量为存在"攻击力: +"的这一行描述

就是说 这个变量等于"攻击力: +123"
然后就从这么变量中删除"攻击力: +",这样这个变量就成了"23"
再让这个变量+1  就成了"24"
然后再让这个变量加上"攻击力: +",这个变量就成了"攻击力: +24"
然后再设置原本的那一行lore 为这个变量。。
大致就是这个想法。
现在就是不知道怎么判断 存在某文字的那行描述

作者: lmyalmy    时间: 2019-11-12 10:29
on damage:
  set {_damageIncrease} to 0
  set {_lore::*} to lore of tool of player
  loop {_lore::*}:
    if loop-value contains "攻击力: +":
      set {_display} to loop-value
      set {_first} to first index of "攻击力: +"
      add 6 to {_first}
      set {_display} to subtext of {_display} from character {_first} to the length of {_display}
      set {_damageIncrease} to {_damageIncrease} + {_display} parsed as number
  set damage to damage + {_damageIncrease}
