五边形写实ParallaxOcclusionMapping(视差映射)贴图
兼容版本：1.7 / 1.8 / 1.9 +
需要 GLSL Shaders Mod 与 五边形材质
请使用SEUS v11等支持POM的光影配置文件





本资源包内为纯视差高光贴图，需要和普通材质同时加载使用
当然也可以套到五边形普通版使用，只不过会缺点点东西
视差贴图详细信息{512-256-128-64} 法线贴图详细信息{32-16}
配置要求：（SEUS v11 下）
[512x] 16G+ RAM GTX980+
[256x] 8G+ RAM GTX780+
[128x] 4G+ RAM GTX660+
！部分侧面无视差贴图,由于着色器的漏洞，使用视差会鬼畜！
