ShulkerBox BackPacks
可层层套娃的潜影盒背包
简介
此插件可以允许玩家潜行右键打开潜影盒而不需要放到地上
RPG服必备的轻量级背包插件(依赖于原版潜影盒功能)
比较有意思的是：你可以让潜影盒套潜影盒,相当于把物品藏到背包A里的背包B里的背包C……
本插件不支持MOD端,会显示右键交互事件错误

功能·命令·权限
功能:
手持潜影盒右键潜行就能打开它,经测试副手不行
自定义使用权限
用潜影盒套潜影盒
禁止或允许更改潜影盒的名字
禁止把潜影盒放在背包外的地上
支持所有游戏中有潜影盒的版本(1.11+潜影盒加入)
命令·权限:
/sbbpReload 需要权限ShulkerBoxBackPacks.reload,用以重载插件
ShulkerBoxBackPacks.use 默认使用权限,可更改
ShulkerBoxBackPacks.nesting 默认套潜影盒的权限,也可更改
配置文件

  2. # ShulkerBox BackPacks 此插件适用于 Craftbukkit / Spigot
  3. # 作者: Brandon (ThirtyVirus) Calabrese
  4. #
  5. # YouTube:      https://www.youtube.com/channel/UC04QdEl71CFDogk8pzY7Geg
  6. # Twitter:      https://twitter.com/Thirtyvirus
  7. # SpigotMC:     https://www.spigotmc.org/members/thirtyvirus.179587/

  9. # 插件功能的权限设置,分别为使用背包的权限、"套娃"的权限
  10. permission: ShulkerBoxBackPacks.use
  11. nesting-permission: ShulkerBoxBackPacks.nesting

  13. # 是否允许潜影盒套潜影盒
  14. nesting: true
  15. # 最多能套几层? (-1代表无限)
  16. nesting-depth: 3

  18. # 禁止服务器修改潜影盒名 (兼容其他的改名插件)
  19. use-renamed-boxes: true

  21. # 仅禁止对特殊形式给潜影盒改名(如颜色|加粗|斜体等...)
  22. # 如果上一项设置false,这一项它将自动会禁用
  23. use-formatted-renamed-boxes: true
