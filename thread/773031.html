举个能输出数值的标签的栗子?

byte short int float double 类型的都是可以的，比如

  1. data get entity @s Pos[0] 1000
复制代码
就会返回玩家自身x坐标*100的整数部分。

  1. data get block ~ ~ ~ Inventory[0].Count
复制代码
就会返回当前位置的容器的第一个有物品的格子内的物品数量。Inventory是一个list，即[]括起来的，[0]表示它的第一个分量。

获得返回值后还需要配合execute来将其写入记分板或实体/方块的nbt中，这就要用到子命令store了。

举个例子，
  1. execuet store result score <span id="kM0.2625959945765193">@s count</span> data get @s Inventory[0].Count
  2. scoreboard players remove <span id="kM0.2625959945765193">@s count</span> 1<div>execuet store entity <span id="kM0.2625959945765193">@s Inventory[0].Count byte 1 run scoreboard players get <span id="kM0.45482890568779966">@s </span>count</span></div>
复制代码
会将玩家背包的第一个物品的数量-1。稍微注意一点，Inventory[0]指的是玩家第一个有物品的格子而不是左上角一个格子，Inventory只记录有物品的格子。如果要获得Slot:0b，需要判断玩家是否有这个格子再获得数据
  1. @s[nbt={Inventory:[{Slot:0b}]}]
复制代码


至于方块也是类似的，不过除了容器以外其它的方块很少有数据值

倍数其他人已经说得很清楚的，比如存储实体位置可以先×1000，最后返回再×0.001即可保证0.001的精度。另外就是注意保存到nbt时，给定的nbt的数据类型必须与填写的一致，要求为float的位置不能用 double
