要用脚本来管理脚本，代码如下
  1. :start
  2. ECHO ================================================================
  3. ECHO 请输入你要打开的bat名或者编号
  4. ECHO 1：BC.bat BC端开服脚本
  5. ECHO 2：SC.bat 生存服开服脚本
  6. ECHO 3：RPG.bat RPG服开服脚本
  7. ECHO 自定义： 自定义脚本名.bat
  8. ECHO 99：退出
  9. SET /P NAME=输入完成后请回车：
  10. IF "%NAME%"=="1" BC.bat
  11. IF "%NAME%"=="2" SC.bat
  12. IF "%NAME%"=="3" RPG.bat
  13. IF "%NAME%"=="自定义" 自定义脚本名.bat
  14. IF "%NAME%"=="99" EXIT
  15. GOTO start
复制代码
