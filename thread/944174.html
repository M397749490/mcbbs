Cultivate

本插件允许重编自使,禁止售卖


两种功能: 采集 And 培养 And 建筑



采集:

1.命令帮助: [/cul block]

       /cul block admin     打开或关闭管理员模式,进行方块编辑

       /cul block list     列出所有已经被保存的方块

       /cul block item <A> <B>     将手上物品保存为采集速度A的B灵锄

       /cul block give <B> <C>     把灵锄B给玩家C

       /cul block remove <D>     删掉方块D

       /cul save <D> <E> <F> <G>     保存一个方块其名字为D刷新时间为E-F,采集耐久度为G

2.创建一个方块

       首先打开管理员模式,然后拿着需要被采集的物品点击一个方块,然后会出现提示,让您输入上述/cul save指令,这样即可创建一个方块,第一次创建的方块是不会有悬浮字体显示的,您需要采集一次后,他才会开始显示,或者重启服务器也可以.创建完毕的方块如图:

培养:[low版本无该功能]
1.命令帮助[/cul]
     /cul check     鉴定被培养的物品
     /cul getid     查看手上物品id[该命令无多大用处]
     /cul addid     允许玩家培养您手上的物品类型
     /cul list     列出所有保存的物品
     /cul save <A>     将手上物品保存为名字为A的物品
     /cul give <B> <A>     给予玩家B物品A,该命令会将物品A的名字或lore的%p%部分转化为B的名字
     为什么需要替换%p%呢？下面将会进行解释

2.创建一个培养皿     培养之前,首先需要创建一个培养皿,培养皿的名字中需要包括&c<<培养皿,然后是他的lore需要包括下面部分
  •       拥有者: %p%     这里先填写%p%,然后使用save指令保存,再用give指令获取
  •       编号: A123    这个编号可以随意输入,在后面的更新中会使用到
  •       成功率: 10     这里填写任意的一个数字,成功率为数字/100

3.创建一本培养技能书
     接下来是一本培养技能,培养技能的名字内需要包括&1<<培养技能,然后lore需要包含下面内容:
  •       成功率: 50     这会在培养皿的基础上增加成功率
  •       最低品质: +3     即培养成功时最少为培养物品增加多少品质
  •       首次加成: +3     物品第一次培养成功获得品质加成
  •       浮动范围: 0-100     开头必须为0-然后一个数字,培养成功时多给予随机的品质

建筑:
1.命令帮助[/cul build]
     /cul add <A>     将玩家A添加为你的朋友,该玩家不会被你的炮塔攻击,会被你的祭坛治疗
     /cul build admin     打开建筑管理模式,用于保存建筑
     /cul build saveblock <A>     将选择的区域的建筑保存为A
     /cul build saveitem <A>     将背包内物品保存为A生成时所需要的物品
2.了解建筑
     建筑可以用于生成方块,攻击敌人,恢复血量,还会有其他更新,您可以提出要求

3.配置建筑

    type: "turret_0"
    description: "每隔1秒发射一个弓箭"
    damage: 5
    #箭塔的伤害
    range: 10
    #一个箭塔的攻击范围有多广
    time: 20
    #一个箭塔被放置后可以持续多久
    limit: 3
    #一个玩家可以放置几个
    id: 261
    #在菜单中显示的物品id
    height: 4.5
    #箭从核心上面多高的地方射出
heal:

    type: "heal_0"
    description: "每隔delay秒恢复heal血"
    heal: 5

    range: 10
    #祭坛恢复血量范围
    time: 21

 建筑类型:[基本变量]type
  • turret_0    箭塔,可以发射一只箭
  • heal_0    祭坛,可以恢复指定范围内你的朋友生命值
  • produce_0    工厂,用于定时生成方块
建筑存在时间:[基本变量]time
  一个建筑生成后可以维持多久,-1即为永久,除非玩家自行删除

显示名字:[基本变量]name
  在gui中显示的名字

显示描述:[基本变量]description
  在gui中的lore显示用;来换行

建筑显示:[基本变量]limit
  一个玩家可以创建的一个建筑的限制数目
显示id:[基本变量]id
  在gui中显示的物品的id
攻击伤害:[箭塔变量]damage
  一个弓箭命中目标造成的伤害
功效范围:[范围变量]range
  箭塔攻击范围,祭坛治疗范围
高度:[位置变量]height
  箭塔发射箭矢高度,工厂生成方块高度
恢复血量:[恢复变量]heal
  祭坛每次为朋友恢复血量的数额
特效间隔:[时间变量]delay
  工厂生成方块间隔,血量恢复间隔
方块id:[方块变量]blockid
  工厂生成方块的id

4.保存建筑
     i.保存方块
         1.输入/cul build admin打开建筑管理员模式
         2.左键一个点,右键一个点,来选择建筑,然后关闭管理员模式,将选择范围内不需要的方块击破,建筑必须且只能包括一个核心方块
         3.输入/cul saveblock <A>,将建筑保存为A的模型
     ii.保存物品
         1.将建筑所需方块放入背包中(建筑方块在建筑删除时将返回背包),并在背包中加入额外需要的物品
         2.输入/cul saveitem <A>,将背包内物品保存为A创建时所需物品          iii.重载服务器

5.生成建筑
    i.先放置一个核心方块[基础设置为绿宝石]
    ii.确保有足够的空间用于生成建筑
    iii.拿出一个建筑券(建筑券自己创建,只要名字符合配置要求就行)右键绿宝石,然后按照GUI进行就可以

7.删除建筑
    i.在管理建筑页面中可以删除建筑
    ii.玩家退出游戏,时限建筑也会被删除
    iii.建筑到了时限也会自动删除


配置:
Level:
  0s: '§f凡品'
  1s: '§a低品'
  2s: '§b中品'
  3s: '§e高品'
  4s: '§d稀有'
  5s: '§6极品'
  6s: '§5神品'
holo:
  - "%name%"
  - "§e§l刷新时间: %time%"
  - "§e§l状态: %type%"
build:
  block: 133
  item: "§a建筑券"
message: "§a请点击绿宝石块来进行建筑创建"

  • Level 是用来保存培养并鉴定后lore显示内容的
  • Build 中的block为建筑核心方块id,item为用于右键核心方块生成建筑
  • holo 则是用来保存采集方块显示的,有下面几种变量
  • %name%    ---方块名称
  • %time%    ---剩余时间,如果为0则显示已刷新
  • %type%    ---方块状态,为等待刷新或可采集
