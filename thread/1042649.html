当然这只是求两点之间的距离
要对不同玩家显示不同距离的话
首先你需要执行这条命令：

  1. execute as @a run function loy:func1
复制代码
然后loy:func1的内容应该是这样：
  1. tag @s add p1
  2. execute as @a[tag=!p1] run function loy:func2
  3. tag @s remove p1
复制代码
loy:func2的内容
  1. tag @s add p2
  2. function loy:dist
  3. tellraw @a[tag=p1] [{"text":"你与"},{"selector": "@a[tag=p2]"},{"text":"的距离为："},{"score": {"objective": "dist","name": "@a[tag=p2]"}}]
  4. tag @s remove p2
复制代码
loy:dist的作用应该是将tag为p1和tag为p2的玩家的距离通过帖子内的方法输出到p2的dist这一记分板上
