所需环境

windows 64位系统:

java 1.8 32/64位

linux:

java 1.8 32/64位


使用教程

第一步:下载编辑器并解压

第二步:在同级目录下创建MythicMobsToolConfig文件夹

第三步:将MM配置文件MythicMobs文件夹复制到MythicMobsToolConfig目录下

第四步:打开编辑器[目前之能用怪物功能,技能暂时未完成]

第五步:写上保存路径,并保存

第六步:将写好的配置文件放在对应目录即可
PS:本使用教程将会越来越简洁~
