如果是这样，可以使用GuoItemLoreCommand果式物品描述指令例如：
现在Mythicmobs的物品配置里输入需要检测的Lore：
  1. 实验品:
  2.   Id: 283
  3.   Data: 0
  4.   Display: '实验品'
  5.   Lore:
  6.   - '&8&m                      '
  7.   - '&a我是试验品'      #这就是要检测的Lore
  8.   - '&8&m                       '
  9.

MythicMobs输入完成后，然后打开plugins\GuoItemLoreCommand，找到ClickTrigger.yml
进去后输入:
  1. 实验:
  2. #这是至关重要的检测Lore
  3.   检测描述: '&a我是试验品'
  4.   点击类型: 右键
  5. #这个是左键/右键后执行的指令
  6.   玩家指令:
  7.   - '[op]:say 我是试验品'
  8.   开启使用提醒: false
  9.   物品模块:
  10.     需求堆叠数量: 1
  11.     需求不足提示: '&c需要同时持有&e1&c个此物品时才能使用'
  12. #这是物品左键/右键后是否消耗
  13.     是否消耗物品: true
  14.   冷却模块:
  15.     是否启用该模块: false
  16.     冷却组: '无'
  17.     冷却时间: 20000
  18.     是否提醒冷却中: false
  19.     冷却中提醒信息: '&e生命药剂&c类道具处于冷却中，剩余时间&e%less%&c。'
  20.   权限模块:
  21.     是否启用该模块: false
  22.     检测的权限: '药品权限.天堂的痊愈药剂'
  23.     是否提醒权限不足: false
  24.     权限不足提示信息: '&c使用此物品需要到达&e七级&c，请升级后再尝试使用'
  25.   动作模块:
  26.     是否启用该模块: false
  27.     需要奔跑: false
  28.     需要蹲下: false
  29.     需要格挡: false
  30.     需要浮空: false
  31.     姿势不对是否提示: false
  32.     姿势不对提示信息: '&c该物品需要在蹲下时使用'
  33.   变量模块:
  34.     是否启用该模块: false
  35.     判断项目:
  36.       判断等级:
  37.         判断式: '%player_level%>=30'
  38.         不通过是否提示: true
  39.         不通过提示信息: '&c等级不足，附魔等级至少要到达30级。'
