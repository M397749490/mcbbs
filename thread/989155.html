「使用教程」
一.技能栏贴图设置
1.修改默认技能栏贴图
  默认技能栏贴图处于default_skill_bar.json文件中，由textureLocation对象所描述
  例如本插件默认使用minecraft材质包的textures/gui/widgets.png纹理（纹理的定位由dataLocation对象确定），并且通过正确的设置  offsetX offsetY和width以及height来引用纹理中hotbar部分纹理
  使用本地纹理时，填写dataLocation的location需要注意domain，如果是minecraft材质包则无需前缀，如果是其他mod的材质包记得添加domain，例如skillview:textures/gui/widgets.png
  使用远程纹理可以将dataLication的type设置为0，然后location填为正确的网络图片即可（仅支持http以及https协议）
2.修改已有玩家的技能栏贴图
  请操作数据库
二.技能贴图设置
默认技能贴图处于miss_skill_texture.json目录中
新增技能贴图时请用miss_skill_texture.json作为模板在此基础上添加
新增技能贴图需要在plugins/SkillView/texture目录下添加和SkillAPI技能同名
例如一个技能叫做a，那么SkillAPI技能文件名该叫做a其name也该叫做a
三.如何使用竖直技能栏
请将default_skill_bar.json的direction设置为1
注意:该功能目前存在于2.4.x及以上版本，并且请确保玩家开启了全屏（F11）
四.注意事项
1.修改默认技能栏贴图并不能对现有玩家有任何影响，如果想要对现有玩家造成影响，请手动在数据库依次修改
2.改完配置文件记得重启服务器
3.请千万注意，每次测试最好都用新的玩家id
4.技能图标尺寸请使用16x16
5.windows平台使用插件时，请将配置文件转码为ANSI编码
6.请务必使用mysql数据库，本插件的本地模式存在一些未查明的问题
7.mysql数据库请使用5.7.x版本
8.请使用SkillAPI-1.90及以上的付费版本
9.本插件不支持&颜色转义，请使用§
10.插件安装完成后，请关闭服务端完成插件配置再启动服务端
11.如果未使用Spigot服务端，出现任何问题请自行解决
12.1.12.2客户端请确保forge版本大于等于23.5.2814
13.1.14.4客户端请确保forge版本大于等于28.2.0
「配置文件」
一.插件命令
1.skbar
    使用该命令打开技能栏配置Gui，然后通过拖动物品即可完成技能栏配置（目前存在物品可被拖动到玩家背包的bug）
二.文件配置
1.config.json
db:数据库对象
  url:连接mysql数据库的url（数据库请使用5.7.x版本）
  username:用户名
  password:数据库密码
  dbname:数据库名（无需手动创建）
  tbname:表名（请勿手动创建）
use_mysql:是否启用数据库（当前版本必须使用数据库，本地模式存在保存数据失败的问题）
skill_config_gui:skbar命令技能栏配置Gui相关配置对象
  title:Gui的title
  lore:分割item的lore，不支持&颜色转义，请使用§
  deny:点击到错误位置时的提醒消息
  allowed_slot:允许使用的技能槽（实验性功能）
  disallowed_slot_message:当玩玩家试图在不允许使用的技能槽配置技能时的提示信息
  show_gui_delay:玩家加入服务器后显示技能栏的延迟（如果玩家电脑配置过低，可能无法显示技能栏，所以请设置为100tick）
{
  "db": {
    "url": "jdbc:mysql://127.0.0.1:3306?useUnicode=true&characterEncoding=UTF-8&useSSL=false",
    "username": "root",
    "password": "88888888",
    "dbname": "skillview",
    "tbname": "player_skillbar"
  },
  "use_mysql": false,
  "skill_config_gui": {
    "title": "技能栏配置",
    "lore": [
      "将技能移动到下方完成绑定",
      "第二行",
      "第三行"
    ],
    "deny": "点击到错误位置",
    "allowed_slot": [
      1,
      2,
      3,
      4,
      5,
      6,
      7,
      8,
      9
    ],
    "disallowed_slot_message": "不允许使用该技能槽"
  },
  "show_gui_delay": 100
}

2.default_skill_bar.json
offsetX:技能栏X偏移量
offsetY:技能栏Y偏移量
numSkillSlot:技能栏数量（如果你不懂，请填为9，如果不为9可能出现各种问题）
slotEdgeX:技能槽X偏移量
slotEdgeY:技能槽Y偏移量
textureLocation:纹理位置对象
  dataLocation:数据位置对象
    location:数据位置
    type:数据位置类型（1为使用MC的ResourceLocation，0为远程，如果不懂，请使用1类型）
  offsetX:纹理起始X偏移量
  offsetY:纹理起始Y偏移量
  width:纹理宽度
  height:纹理高度
{
  "offsetX": 0,
  "offsetY": -22,
  "numSkillSlot": 9,
  "slotEdgeX": 3,
  "slotEdgeY": 3,
  "textureLocation": {
    "dataLocation": {
      "location": "textures/gui/widgets.png",
      "type": 1
    },
    "offsetX": 0,
    "offsetY": 0,
    "width": 182,
    "height": 22
  },
  "skills": []
}

3.miss_skill_texture.json
请参考default_skill_bar.json中的textureLocation
{
  "dataLocation": {
    "location": "textures/gui/widgets.png",
    "type": 1
  },
  "offsetX": 192,
  "offsetY": 0,
  "width": 16,
  "height": 16
}

1.将文件放入plugins目录下
2.按照使用教程来配置插件
二.客户端mod安装
1.将skillview-<forge版本>-<mod版本>.jar放入mods目录下

「bug与开发计划」
一.已知存在的bug或问题
2.2.5版本已知bug
1.skbar物品可拖动到玩家背包
2.不使用数据库会造成数个未知错误，严重时导致插件无法正常工作
3.除Spigot以外的其他服务端都有很大可能性不可正常工作
4.使用横向技能栏时，玩家的氧气条绘制于错误的位置
5.技能图标颜色从第二个开始就不正常
2.4.3版本已知bug

1.使用横向技能栏时，玩家的氧气条绘制于错误的位置
2.客户端按钮快捷键本地化无效
3.快速点击skbar命令的gui会出现报错
4.技能图标颜色从第二个开始就不正常
2.5.0版本已知bug

1.默认快捷键按钮组错误2.技能图标颜色从第二个开始就不正常
