EnderChest
这个插件完全替换原版的末影箱（原版末影箱的物品将返还玩家背包）并使末影箱支持跨服


依赖前置
  • MySQL
  • SimpleORM


下载地址
https://github.com/caoli5288/EnderChest/releases/download/v0.3/enderchest-0.3.jar

指令和权限

  • enderchest.use - 允许玩家使用指令打开末影箱 - 默认OP
    • /enderchest
    • /echest
    • /ec
  • enderchest.size.<行> - 默认玩家末影箱的行数
  • enderchest.extra.<行> - 额外增加玩家末影箱的行数


默认配置
  1. dataSource:
  2.   url: jdbc:mysql://localhost/test
  3.   user: root
  4.   password: root
复制代码


使用指南
  • 将本插件与依赖插件放入服务端plugins文件夹
  • 运行之后会在plugins/enderchest生成config.yml
  • 修改对应数据库的信息并重启服务端
  • Enjoy it!
