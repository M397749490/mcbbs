使用静态（static）字段将插件主类储存起来以供其他类访问。

  1. public class ExamplePlugin extends JavaPlugin {

  3.     public static ExamplePlugin INSTANCE;

  5.     public ExamplePlugin() {
  6.          INSTANCE = this;
  7.     }
  8. }
复制代码


这样在其他类中就可以访问了：
  1. ExamplePlugin.INSTANCE.getConfig();
  2. ExamplePlugin.INSTANCE.saveConfig();
