下面的是代码，建议不要直接复制，提高自己的动手能力

  1. @echo OFF　
  2. set c=-1
  3. :head
  4. color 02
  5. set /a c+=1
  6. rem a为设置的内存大小,单位为MByte。
  7. rem b为设置的自动开启时间，单位为秒。
  8. rem 下方"JAVA"若无法启动，请改为JAVA路径。
  9. set a=3000
  10. set b=6
  11. title 已重启%c%
  12. JAVA -Xincgc -Xmx%a%M -jar PaperSpigot-1.8.8-433.jar  -nojline
  13. echo 服务器，%b%秒后将会为您启动服务端～┊
  14. ping -n %b% 127.1>nul
  15. goto head
复制代码

注意事项：
Windows系统用ANSI编码进行编写
Linux系统用UTF-8编码进行编写
不然会出现乱码
