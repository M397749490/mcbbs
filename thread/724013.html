VPS的内存是8G
启动器里面的代码
@echo OFF

:start
set a=6000
title RPG服
color a　　　　　　　　　　　　　　
echo *************************************
echo *         正在开启服务端            *
echo *************************************
"C:\Program Files (x86)\Java\jre1.8.0_144\bin\java.exe" -Xincgc -Xmx1G -XX:MaxPermSize=1G -jar mc.jar
color C
echo *************************************
echo *     正在重启服务端  [10秒]        *
echo *************************************
ping 127.0.0.1 -n 60 > nul
goto start
这是1G的，可以开服，求解
