WebAPI

WebAPI提供了一个非常强大的用于管理和监视Sponge服务器的RESTful API和网页面板，你可以在其提供的面板中查看服务器资源占用率、玩家聊天记录、指令使用记录并通过网页端进行插件的禁用、重载以及配置文件的编辑。同时，您还可以通过网页端进行不同世界的规则配置，并对去进行卸载等操作。如果您安装了一些其他的插件，比如Universal Market等，该网页同时可以进行插件的物品更新等操作。

  • 关于基础：查看当前内存占用、CPU占用、生成TPS趋势图与玩家报表、记录后台回显

  • 关于记录：查看并筛选聊天记录、命令使用记录

  • 关于多世界：修改配置信息（实体限制、视距限制 etc.）、禁用、启用世界（联动Nucleus）

  • 关于权限：查看用户、用户组权限信息（联动Nucleus）

  • 关于联动：对MMCRestrict\Tickets、UniversalMarket etc. 有较好的支持，可以直接提供页面进行插件配置。




关于面板配置
您可以通过两种方式进行面板的搭建。

     A.集成配置：将前端集成于插件中，通过插件自带Web服务器进行访问。
     B.独立配置：将前端搭建于独立Web服务器，通过RESTFul API进行通信。（未实测）

A.集成配置教程
  • 将插件放置在 mods 文件夹中并重启。
  • 如果你需要远程访问，找到插件配置文件，编辑 webapi/config.conf，找到 host=localhost 项并修改为 host="0.0.0.0"。
  • 在服务器内使用 /sponge plugins 命令进行插件重载。
  • 此时访问 服务器IP:8080 应该可以看到面板主页，但无法登陆。
  • 回到插件所在config文件夹，找到 webapi/permissions.conf 中的 whitelist 项，将访问IP添加至白名单，或修改 useWhitelist = false。
  • 使用命令 /webapi users add <用户名> <密码> 添加用户，或者您也可以使用 /webapi users add <用户名> 添加一个拥有随机密码的用户。

B.独立配置教程
  • 将插件放置在 mods 文件夹中并重启。
  • 找到插件配置文件，编辑 webapi/config.conf，找到 adminPanel=true 修改为 false 关闭自带Web服务器。
  • 下载前端文件并搭建在独立Web服务器上，测试访问。
  • 编辑前端目录中 config.json 并对所有要进行监控的服务器进行配置。（注意是apiUrl，端口不同默认为8081，同样在config.conf中配置。）
  1. window.config = {
  2.      "servers": [
  3.          {
  4.              "name": "要监控的服务器A",
  5.              "apiUrl": "https://server1.my-mc-servers.com:8081",
  6.          },
  7.          {
  8.              "name": "要监控的服务器B (可选)",
  9.              "apiUrl": "http://localhost:8080"
  10.          }
  11.      ]
  12. }</font>

关于插件配置
插件指令
创建用户：/webapi users add <用户名> <密码> 或 /webapi users add <用户名> (随机生成密码)
更改密码：/webapi users pw [name] [newpassword]命令。
删除用户：/webapi users remove [name]。
所有涉及 /webapi * 的权限节点均为 webapi.users.add

用户权限
更改面板用户的权限，需要编辑 /config/webapi/user.conf 配置文件。（推荐直接通过面板进行权限配置）
  1. users {
  2. }
  3. test {
  4. password="就不给你看"
  5. permissions { #在此处修改权限节点，种类在后面会讲到
  6. "*"=true
  7. }
  8. }
  9. rateLimit=10 #rateLimit可以指定某个用户每秒可执行的操作数。
  10. }</font>

For instance, 获取多世界信息的js实例。
  1. const req = require("request");
  2. const _   = require("lodash");

  4. const BASE_API_URL = "http://localhost:8080/api/v5";

  6. const HEADERS = {
  7.     "x-webapi-key": "ADMIN",
  8. };

  10. req.get({ url: BASE_API_URL + "/world", json: true, headers: HEADERS }, (err, res, body) => {
  11.     console.log("--- WORLDS ---");
  12.     console.log(err);
  13.     console.log(res.statusCode);
  14.     console.log(JSON.stringify(body, null, 2));
  15.    
  16.     const world = _.first(body.worlds);
  17.     if (!world) {
  18.         console.log("No worlds!");
  19.         return;
  20.     }
  21.    
  22.     req.get({ url: BASE_API_URL + "/world/" + world.uuid, json: true, headers: HEADERS }, (err, res, body) => {
  23.         console.log("--- WORLD " + world.name + " ---");
  24.         console.log(err);
  25.         console.log(res.statusCode);
