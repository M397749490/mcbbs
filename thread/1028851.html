标题: 关于LeftClickEmpty事件
我在做forge mod的时候，想要实现“当玩家左键点击空白处，会调用某个功能”的效果，于是监听了LeftClickEmpty事件
  1. /**
  2.      * This event is fired on the client side when the player left clicks empty space with any ItemStack.
  3.      * The server is not aware of when the client left clicks empty space, you will need to tell the server yourself.
  4.      * This event cannot be canceled.
  5.      */
  6.     public static class LeftClickEmpty extends PlayerInteractEvent
  7.     {
  8.         public LeftClickEmpty(EntityPlayer player, ItemStack stack)
  9.         {
  10.             super(player, EnumHand.MAIN_HAND, stack, new BlockPos(player), null);
  11.         }
  12.     }
复制代码
但是我发现这个事件仅在客户端运行，无法直接被服务器端接收
而我想调用的那个功能是在服务器端运行的（主要是攻击实体的功能）
所以想请问一下各位大佬，注释要我“tell the server yourself”，具体该怎么tell呢？
游戏版本为1.10.2，谢谢大佬们~

LeftClickEvent当然是客户端事件了，服务器上可没有鼠标（滑稽）。
如果仅仅是实体受到伤害的事件，监听LivingDamageEvent或者AttackEntityEvent即可，如果就是想监听点击，且需要攻击实体，需要发送一个CPacketUseEntity包过去来“告诉”服务器，“我在攻击实体”。
