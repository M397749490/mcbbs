RandomXYZ -> 可配置的随机传送
介绍：单机随机传送，完全不兼容服务器。
特性：
  • 支持指令设置
  • 支持距离设置
  • 支持提示设置
  • 不传送到空中
  • 水面信息提示
指令：/rxyz随机传送
配置文件：
路径：.minecraft\liteconfig\config.1.11.2\RandomXYZ.json
  1. {
  2.   "x": 300,
  3.   "z": 300,
  4.   "msg": "随机传送成功!",
  5.   "cmd": "rxyz"
  6. }
