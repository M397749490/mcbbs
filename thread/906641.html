  Suit
套装
无邪的插件交流群: 170032890
功能简介
玩家可通过收集一系列装备进行穿戴,并且支持额外背包槽位拓展!
从而获得额外的属性加成!
并且根据穿戴的件数，玩家可以获得不同程度的属性提升！

用途说明
可增添服务器色彩，提高玩家的积极性!
培养玩家的收集欲望!
提高服务器的氪金率[(主要用途)]！
配置文件
极易配置
config.yml
  1. # 我很喜欢通过判断物品名的方式来鉴别套装或者其它
  2. # 这个插件也是判断物品名的(但是还多了一个lore限制)
  3. 关闭头颅皮肤: true
  4. # 开启后 %p%羊皮盔 和 超级无敌霹雳羊皮盔 就是一样的
  5. 套装名变量对比识别: true
  6. suit:
  7.   suit1:
  8.     name: '&a羊皮套装'
  9.     list:
  10.     - '%p%羊皮盔'
  11.     - '%p%羊皮靴'
  12.     - '%p%羊皮甲'
  13.     - '%p%羊皮腿甲'
  14.     attribute:
  15.       '1': []
  16.       '2':
  17.       - '&a攻击力 &c+5'
  18.       - '&a生命值 &c+15'
  19.       '3':
  20.       - '&a攻击力 &c+10'
  21.       - '&a生命值 &c+30'
  22.       '4':
  23.       - '&a攻击力 &c+15'
  24.       - '&a生命值 &c+45'
  25. type:
  26.   # 判断装备的槽位是否正确，然后计算套装
  27.   prefix: '类型'
  28.   chestplate: '胸甲'
  29.   helmet: '头盔'
  30.   leggings: '护腿'
  31.   boots: '靴子'
  32.   offhand: '副武器'
  33.   mainhand: '主武器'
  34.   # 其它槽位，背包
  35.   otherSlot:
  36.     # 1 槽位: 名称
  37.     # 主手槽位 0到8 和装备栏槽位 36到44及以上 不可注册使用
  38.     '9': '项链'
  39.     '10': '戒指'

message.yml
  1. COMMAND:
  2.   STATS: 查看详细属性！

  4.   SUIT: '&6[&c套装&6]'

  6.   first: '&6套装 {0} &7({1}/{2})'
