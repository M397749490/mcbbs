DeadSociety
本帖不再更新
介绍
如果社会礼崩乐坏会发生什么? 如果没有人能够拯救你你又该怎么办?
面对灾厄,你不能只担忧而坐以待毙,你应该行动起来,准备面对难以预知的未来.
尸潮涌至,末日将至.欲想苟活于末世,唯有与幸存者戮力同心.
病毒仍在幸存者中扩散而引起恐慌. 你必须准备好充足的物资来抵御怪物们的进攻.

必要前置
> Java 8
非必要前置

[1] Vault 和经济插件
> 用于支持击杀奖励、任务或其他功能.

[2] WorldEdit 和 WorldGuard
> 用于设置区域.
请安装最新版本的 WorldGuard | WorldEdit.

[3] Citizens
> 用于任务.
用NPC来显示任务,你需要在lang.yml内设置指定的NPC并用 /Trait 设置任务.
请使用最新版本的Citizens.

特点

> 僵尸特性 <

  • 僵尸不会在白天燃烧.
  • 僵尸会造成更高的伤害.
  • 僵尸会跑得更快.
  • 僵尸有几率造成不同类型的感染.
  • 僵尸有几率掉落肠子.
  • 僵尸无法破坏木门.
  • 僵尸可以被捕捉. 僵尸只能在被麻醉后才能捉到. 注射可以麻醉僵尸.
  • 僵尸在受伤时变得疯狂(速度 & 力量).
  • 被麻醉的僵尸拥有可以储存物品的背包. 背包可以放在被麻醉的僵尸身上.

> 玩家特性 <

  • 玩家会口渴.
  • 玩家在击杀僵尸或其他玩家后可以获得随机奖励.
  • 玩家可以接受无限的击杀任务.
  • 玩家可以在发射TNT后创建爆炸屏障. TNT爆炸也会有动态效果.
  • 玩家饿死后会获得永久的反胃效果.
  • 玩家可以通过指令打开个人背包.
  • 玩家可以右击爬上栅栏. 必须在栅栏所在方块才有效.
  • 玩家可以右键打开铁门.
  • 玩家可以搜寻宝箱.
  • 死后自动重生.
  • 玩家可以栖息地并标记其位置.
  • 玩家可以在指定范围内聊天. 可以用指令开关这一功能.
  • 玩家可以进入辐射区来搜寻更好的战利品.
  • 玩家可以通过右键指南针来追踪地区 | 栖息地的位置.
  • 玩家可以随机传送.
  • 玩家在杀死僵尸或其他玩家后可以获得金钱奖励.
  • 玩家可以使用自定义物品. 比如抗生素，止痛药，收音机，手电筒.
  • 玩家有几率受伤感染并持续流血40秒.只有绷带才能治愈收口.
  • 玩家可以穿上僵尸的肠子来防止僵尸的进攻 (看脸).
  • 玩家会因用受感染的瓶子饮水而感染. 玩家将因感染而死亡. 另外,在被污染的水源地装水就会导致水瓶被污染 .
  • 玩家可以从炼药锅内无限取水.
  • 玩家可以用炼药锅来过滤污水.
  • 站在传感器附近或上面的玩家或怪物可能会被炸死. 要想创建传感器, 你只需要2个拌线钩和线.
> 总体特性 <

  • 陷入蜘蛛网的玩家会受到伤害 (荆棘蛛丝).
  • 所有自定义物品会显示物品名并在掉落时显示悬浮文字.
  • 信仰之跃会使玩家因为牛顿之力而缓慢几秒.
  • 生物死亡不会掉落经验值.
  • 可以用马鞍来召唤马, 马鞍无法被取下.
> 管理员特性 <

  • 创建宝箱.
  • 创建区域. 区域分为两种. 安全区 & 辐射区.
  • 可在配置内编辑自定义物品.
  • 创建牌子物品商店.
  • 可编辑死亡消息.
  • 关闭某种生物的生成, 例如: 豹猫、骷髅、蜘蛛.
  • 防止打开、破坏或放置某种物品到这些传送点传送点并能让玩家传送到这些传送点.

> 客户端特性 <

  • 插件开发者 API
  • 自动更新配置系统.
  • 插件更新检测.
  • 支持多世界.
  • 支持语言.



指令
> 默认 <
  • /DS -显示以下指令.
  • /DS Commands - 显示所有指令.
  • /DS Permissions - 显示所有权限.
  • /DS Reload - 重载所有配置.

> 物品 <

  • /Items [give | list] - 给予或列出物品.

> 区域 <

  • /Zones - 显示关于区域的指令.
  • /Zones List - 列出所有可以区域.
  • /Zones Teleport <区域> - 传送到一块区域.
  • /Zones Create <区域> <区域类型> - 创建指定类型的区域.
  • /Zones Spawn <区域> - 设置一块区域的传送点.
  • /Zones Remove <区域> -移除一块区域.

> 战利品编辑 <

  • /LootWand -获得战利品编辑器法杖.
> 背包指令 <

  • /Backpack -打开你的个人背包.
> 口渴度 <

  • /Thirst - 显示你的口渴度.
  • /Thirst Refill - 设置你的口渴度为100%
  • /Thirst Refill <玩家名> - 设置一位玩家的口渴度为100%
  • /Thirst Help - 相关指令

> 任务 <

  • /Quest - 显示相关指令.
  • /Quest Start - 开始一个随机任务.
  • /Quest Info - 显示任务信息.
  • /Quest Cancel - 取消任务.
> 栖息地 <

  • /SetCamp - 设置你的栖息地.

> 传送点 <

  • /SetSpawnPoint - 设置玩家的传送点.
  • /SetSpawnPoint [传送点] - 设置一个已有传送点的传送点.
> 随机传送 <

  • /RandomSpawn - 传送到随机一个传送点.

> 喊话 <

  • /Shout toggle - 开关喊话模式.

权限
默认
  • ds.use - 使用 /DS 指令.
  • ds.commands - 使用 /DS 指令.
  • ds.permissions - 使用 /DS Permissions 指令.
  • ds.reload - 使用 /DS Reload 指令.
物品
  • ds.knife - 用来切割动物, 截肢, 切肉或切绳子.
  • ds.guts - 当你穿上肠子后, 行尸走肉将不会以你为目标.
  • ds.medpack - 获得10秒的生命恢复II.
  • ds.bandage - 获得10秒的生命恢复II.
  • ds.flashlight -右键开关灯.
  • ds.antibiotics - 用来治愈你的食物中毒或僵尸病毒.
  • ds.painkillers - 获得20秒的伤害吸收II和缓慢I.
  • ds.stimpak - 获得10秒的速度和最大生命值I.
  • ds.injection - 右键行尸走肉使其麻醉.
  • ds.radio - 收音机指令: #backup - 备份请求.
  • ds.c4 - C4会在输入密码后定时引爆.
  • ds.flaregun - 用来发射信号,可以让附近的玩家看到.
  • ds.items.* - 使用所有物品.
  • ds.items.cmd - 使用 /Items 指令.
物品商店
  • ds.items.shop.use - 允许右键牌子购买物品.
  • ds.items.shop.create - 允许创建牌子商店.
  • ds.items.shop.break - 允许玩家破坏牌子商店.
  • ds.items.infinite - 允许玩家免费购买物品.
  • ds.items.shop.* - 物品商店所有权限.
区域
  • ds.zone.use - 使用 /Zones 指令.
  • ds.zone.list - 使用 /Zones List 指令.
  • ds.zone.teleport - 使用 /Zones Teleport 指令.
  • ds.zone.create - 使用 /Zones Create 指令.
  • ds.zone.spawn - 使用 /Zones Spawn 指令.
  • ds.zone.remove - 使用 /Zones Remove 指令.
  • ds.zone.immune - 免疫辐射.
  • ds.zone.* - 所有相关权限.
区域牌子
  • ds.zone.sign.use - 允许玩家使用区域传送牌子.
  • ds.zone.sign.create - 允许玩家创建区域传送牌子.
  • ds.zone.sign.break - 允许玩家破坏区域传送牌子.
  • ds.zone.sign.* - 所有相关权限.

方块权限
打开方块
  • ds.open.<material> - 打开指定类型的方块.
  • ds.open - 可打开所有的方块.
  • 例如, 如果你禁止了打开发射器, 权限将为 ds.open.dispenser

破坏方块
  • ds.break.<material> - 可破坏指定类型的方块.
  • ds.break - 可破坏所有类型的方块.
  • 如果你想要破坏箱子, 你需要 ds.break.chest 权限
放置方块
  • ds.place.<material> - 可放置指定类型的方块.
  • ds.place - 可放置所有类型的方块.
  • 如果你要放置钻石矿,权限为 ds.place.diamondore

战利品编辑器
  • ds.loot.create - 创建战利品.
  • ds.loot.break - 破坏战利品.
  • ds.loot.cmd - 使用 /LootWand 指令.
  • ds.loot.* - 战利品编辑器所有权限.

感染
  • ds.infection.immune - 免疫病毒.
  • ds.infection.cmd - 感染后执行指令.

生存
  • ds.irondoor - 右键开铁门.
  • ds.waterbottle - 无限从炼药锅内取水.
  • ds.climbing - 攀爬栅栏.
  • ds.leash - 捕捉被麻醉的僵尸.
  • ds.fall - 断腿效果.
  • ds.sensors - 防止传感器的爆炸伤害.
  • ds.respawn - 死亡自动重生.
  • ds.barrels - 破坏爆炸屏障.

背包
  • ds.backpack - 打开个人背包.
  • ds.backpack.keep - 死亡保存背包.
  • ds.backpack.* - 所有相关权限.

行尸走肉
  • ds.walker.inv - 打开被麻醉的僵尸的背包.
  • ds.walker.backpack - 打开未被麻醉的行尸走肉的背包.
  • ds.walker.* - 所有相关权限
口渴度
  • ds.thirst - 使用 /Thirst 指令.
  • ds.thirst.refill - 使用 /Thirst Refill 指令.
  • ds.thirst.refill.others - 使用 /Thirst Refill <Player> 指令.
  • ds.thirst.help - 使用 /Thirst Help 指令.
  • ds.thirst.* - 所有相关权限.
任务
  • ds.quests - 使用所有的 /Quest 指令.
  • ds.quests.npc - 右键NPC来选择任务.
栖息地
  • ds.camp.set - 使用 /SetCamp 指令.
地点追踪
这些权限作用于玩家右键指南针来打开菜单来追踪位置.
  • ds.compass - 允许玩家打开菜单.
  • ds.track.camp - 允许玩家追踪栖息地位置.
  • ds.track.zone - 允许玩家最终一块区域的位置.
  • ds.track.* - 所有相关权限.
传送点
  • ds.spawnpoint.set - 使用 /SetSpawnPoint 指令.
随机传送
  • ds.random.spawn - 使用 /RandomSpawn 指令.
随机传送牌子
  • ds.random.spawn.sign.use - 允许使用随机传送牌子.
  • ds.random.spawn.sign.create - 允许创建随机传送牌子.
  • ds.random.spawn.sign.break - 允许破坏随机传送牌子.
  • ds.random.spawn.sign.* - 所有相关权限.
喊话 (聊天距离)
  • ds.shout - 使用 /Shout toggle 指令.
  • ds.chat.disabled - 关闭聊天功能.
额外奖励
  • ds.perk.receive - 击杀其他玩家或僵尸获得额外奖励.
  • ds.perk.sign.use - 使用额外奖励牌子.
  • ds.perk.sign.break - 破坏额外奖励牌子.
  • ds.perk.infinite - 无限购买.
  • ds.perk.sign.* - 所有相关权限.
所有权限
  • ds.* - 插件的所有权限.
