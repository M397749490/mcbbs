这个插件名叫：barAPI
需要前置插件：Item Lore Stats
1.如何做到如你上方图片效果？
首先，安装Item Lore Stats插件，重启服务器，然后找到配置文件。
找到这一项：
usingBarAPI: false
#是否使用BarAPI插件
把false改为true即可打开显示。
2.如何做到如你上方图片信息？
首先，找到Item Lore Stats配置文件里的这一项：
health:
#生命值
   name: 生命值
   colour: '&a'
   splitter: /
   #当前生命值和最大生命值分割的标示
level:
#等级
   enabled: true
   #是否显示这一项
   name: 等级
   colour: '&e'
exp:
#经验
   enabled: true
   name: 经验值
   colour: '&b'
   splitter: /

把对应的生命值，修为，真气改为
体质，修为，真气
即可达到如图效果，望能帮助您。
