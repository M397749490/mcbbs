多摇奖机 | 摇奖不止一种
可以创建多个摇奖机，玩家可以通过指令来打开不同的摇奖机


安装与使用
想让玩家使用金钱来摇奖，需安装Vault前置

创建摇奖与奖品设置方法

  • 打开template.yml，你可以在这里创建新的摇奖，插件默认自带了名叫“default”的摇奖，想要创建更多抽奖的话请按照default的格式来创建，本教程接下来以default抽奖举例
  1. Templates:
  2.   default:
  3.     # 这是默认抽奖吗？
  4.     default: true
复制代码
  • 打开config.yml，你可以在这里新建抽奖（template部分的名字必须和template.yml里的对应）或者编辑已有的抽奖
  1. SlotMachines:
  2.   default:
  3.     Name: '&c默认抽奖'
  4.     Title: '&4抽奖 #1'
  5.     # 在这里填写template.yml相对应的名称
  6.     Template: default
复制代码
  • 在config.yml里的Elements部分编辑各种摇奖图标以及它们出现的几率
  1.     Elements:
  2.       apple:
  3.         Material: APPLE:0
  4.         Name: '&c苹果'
  5.         # 如果该物品是玩家头颅，可以在这里写上头颅的hash码
  6.         SkullHash: nothing
  7.         Enchanted: false
  8.         # 摇到此图标的几率，该几率按照权重来计算
  9.         Chance: 45.0
复制代码
  • 在config.yml里的Combinations部分设置摇出不同的三个组合获得的奖励名称，请注意，这些奖励的顺序是按照优先度来排列的，优先度越高越靠前，比如：摇出三个苹果后会优先获得摇出三个苹果的奖励，而不会获得摇出一个苹果的奖励，因为摇出三个苹果的奖励更优先
  • 可以使用ANY:ANY:ANY来代表“鼓励奖”，但是基于优先度考虑请把鼓励奖放在所有奖品的最后
  1.     Combinations:
  2.     # 摇出三个apple可获得奖励“x10”
  3.     - apple:apple:apple-x10
  4.     # 摇出一个apple可获得奖励“x2”
  5.     # 注意看：apple这个结果可能出现在三个转轮中的任何一个
  6.     # 所以要写三次！
  7.     # ANY代表摇出任何结果
  8.     # 所以可以用ANY:ANY:ANY代表“鼓励奖”
  9.     - apple:ANY:ANY-x2
  10.     - ANY:apple:ANY-x2
  11.     - ANY:ANY:apple-x2
  12.     - carrot:carrot:carrot-x20
  13.     - bread:bread:bread-x30
  14.     - melon:melon:melon-x40
  15.     - cake:cake:cake-x50
复制代码
  • 在Rewards部分设置各个奖励名称代表的执行指令奖励
  1.     Rewards:
  2.       x10:
  3.         cmds:
  4.         - eco give %p 1000

指令与权限
  • /smg help - 插件帮助
  • /smg open <抽奖机名> - 直接打开某摇奖
  • /smg setcurrencyitem <抽奖机名> - 手持物品，设置某摇奖消耗此物品
  • /smg reload - 重载插件

建议给玩家的权限
smg.user - 玩家基础权限
smg.open - 直接使用/smg open打开摇奖
