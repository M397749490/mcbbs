多功能的图版显示插件


插件简述Synopsis
什么是RadioBoard ?

RadioBoard是一个功能强大的基于数据包的多功能地图插件，它具有广泛的API和优化的代码，可提供最佳的性能和游戏体验，RadioBoard能够创建电路板并允许用户自定义重要的内容，从图像,GIF到按钮和开关
RadioBoard具有极其准确的点击检测功能和完整的教程，其中包含如何制作自定义电路板 和 显示屏


指令 Command
电路板
/radioboard board create <名称> <map-id> 创建一个电路板(对准物品展示框使用)
/radioboard board remove <名称> <map-id> 删除指定名称的电路板
# <map-id>类似于电路板与显示屏之间的互相辨识ID
显示屏
/radioboard display create <名称> <map-id> <档案名称> <x：y>
根据电路模板创建一个新的显示，可以在 /plugins/RadioBoard/providers/下找到
/radioboard display remove <名称> - 永远删除显示屏(很长一段时间!吗)
查看
/radioboard list board    查看所有已創建的电路板的详细信息
/radioboard list display  查看所有已創建的显示屏的详细信息



权限Permission
- radioboard.admin        - 允许运行所有命令
- radioboard.board.<board>.view     - 允许查看指定电路板
- radioboard.board.<board>.interact - 允许与指定电路板进行交互(触发事件)，如果他拥有查看权限

进阶-显示屏入门

images/文件夹是RadioBoard在加载图像时检查的位置。

providers/文件夹是我们的显示屏文件的存放处。

首先你会看到的是width和height。分别代表宽度和高度,且应以像素为单位，并且与您电路板的大小相同。举个例子，如果您的电路板是6乘6，每个地图宽128像素，宽度和高度应为6 * 128或768
接下来是background-image。这是可选的，但如果需要，您可以设置背面图像。它将自动调整大小以完全适合电路板。图像应存在于/plugins/RadioBoard/images/文件夹中。

BUTTON(按钮)
按钮需要的不仅仅是图像文件。它需要一个 clicked-image 和一个 unclicked-image 文件，只要按下/未按下按钮就会显示它。
command是指每当玩家点击按钮所运行的指令。运行时，如果命令以 / 开头，那么它将视为由玩家执行。它还会将%player_name%转换成使用按钮的玩家的名称。
button-delay是按钮被触发后保持触发状态(clicked)的时间。按下时，玩家不能按下按钮直到它回复未触发状态(unclicked)。

  3.       clicked-image: "<image file>"
  4.       unclicked-image: "<image file>"
  5.       command:

SWITCH(开关)
这很简单，与按钮(BUTTON)类似。开关有2种状态，每当改变状态时都运行指令。它们还有2个图像，用于关闭和开启状态。这些指令与按钮(BUTTON)的指令相同。

  3.       on-image: "<image file>"

复制代码
CLOUD(遮蔽)
此类型略有不同。它不是主图像，而是作为叠加层，因此它可以为矩形区域提供混浊效果。
transparency是CLOUD计算混浊的数值。 0表示完全透明，255表示完全不透明。
delay是CLOUD会以多少毫秒为单位的时间更新一次。不要将此值设置得太低，特别是如果CLOUD覆盖大面积，如9个物品展示框，否则可能导致客户端出现问题。

如何加载和测试您的显示器

要进行测试，首先要确保在游戏中构建了一个电路板，并保存了一个提供程序文件/plugins/RadioBoard/providers/。
运行指令/radioboard display create <名称> <map-id> <display-file> <宽> <高>，您的显示屏名称可以是您所想的。<map-id>，<宽>和<高>则应该与您的电路板相同。
<display-file> 应该与你保存显示屏/plugins/RadioBoard/providers/中的文件名相同。
<名称>如果您之前已经创建了一个，则可以使用相同的，因为它会覆盖旧的名称。
