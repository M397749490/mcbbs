# 灵工艺我的世界「轻」开服器

已有主要功能

  • 服务器管理
  • 回显文本汉化、上色
  • 自定义快捷命令 | 自定义命令教程
  • 快速玩家管理列表
  • 崩溃自动重启(关服自动重启)
  • 服务端配置文件管理
  • 服务端文件结构图
  • 服务端插件、模组文件管理
  • 计划任务、一次性任务
  • 编码转换
  • 样式代码
  • 世界游戏规则快速设置
  • RCON设置
  • 快捷生成开服脚本(Bat、sh)
  • 资源广场，下载服务端与环境

拓展功能

  • 可设置发送命令编码，以防文本乱码
  • 可设置服务端配置文件格式，兼容所有版本
  • 支持手机服务端 Nukkit 开服与配置文件模式
  • 软件支持自定义标题用来区分多个服务端

计划开发功能

暂无，如果您有好的建议，欢迎前往提供 | 传送门

# 使用方法
轻版使用易语言开发所以可能有误报产生，不放心可以使用下面的C#Pro版

  • 下载软件
  • 将软件放在除C盘的其他盘内 [可选 | 推荐]
  • 打开软件，软件会创建 server 文件夹
  • 下载一个服务端，然后将服务端放入开服器创建的 server 文件夹
  • 在开服器 本体设置 中，选择刚才下载的服务端核心
  • 在控制面板中点击开服
