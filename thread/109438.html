唔，因为换ID，加上那帖子很久没更新，所以就新开帖了



开始游戏前需要清空物品栏(可选)

游戏开始会自动切换到飞行模式，结束再切换回来

支持多棋盘

阻止玩家从游戏外放置摧毁方块

游戏开始后无法离开棋盘附近

游戏结束后会自动恢复物品栏

1.4.7如果使用1.5.1插件版本，则只有时间奖励不会有完成奖金

命令(1.5.1版本)

  1. /wd play [easy/medium/hard] [棋盘名称] - 进行指定难度的游戏，不输则为默认棋盘和难度
  2. /wd spectate [棋盘名称] - 观战
  3. /wd hint - 开启提示模式。放置错误会提示，但是奖金会减少
  4. /wd check - 显示正确答案并将错误以萤石标记。会减少奖金
  5. /wd info - 查看棋局信息
  6. /wd list - 查看所有棋盘
  7. /wd quit - 离开游戏/观战/等待
  8. /wd setboard [棋盘名称] - 创建棋盘
  9. /wd delboard [棋盘名称] - 删除棋盘
  10. /wd reload - 重载配置

命令(1.4.7版本)

  1. # 选定一个难度开始游戏
  2. /play [难度等级] [棋盘名称]
  3. # 列出棋盘和使用状态
  4. /list
  5. # 退出游戏
  6. /quit
  7. # 检查游戏是否完成
  8. /check
  9. 揭开答案
  10. /solve
  11. # 生成一个空棋盘
  12. /setboard [棋盘名称]
  13. # 重载配置并重置游戏
  14. /reload
复制代码


权限：

  1. wooldoku.admin - setboard，delboard和reload的权限
  2. wooldoku.player - 基本游戏权限
复制代码


配置(1.5.1)：
  1. # 启用广播
  2.   Announce: true
  3. # 启用经济
  4.   Vault: true
  5. # 提示模式奖金乘数
  6.   HintMultiplier: 0.5
  7. # 默认棋盘名称
  8.   DefaultBoard: default
  9. # 默认棋盘模式
  10.   DefaultDifficulty: easy
  11. # 为True则禁止背包不清空加入游戏(即使为false插件也会自动保留好物品)
  12.   NoInvToJoin: false
  13. # 游戏结束后等待队列中的玩家需要几秒进入游戏
  14.   QueueCountDown: 3
  15. # 时间奖励(时间奖励-完成所用时间=额外奖金)
  16.   BonusTime:
  17.     Easy: 90
  18.     Medium: 180
  19.     Hard: 320
  20. # 棋盘列表
  21. Boards:
  22. # 棋盘名称
  23.   'Board':
  24. # 所在世界
  25.     World: world
  26. # 坐标
  27.     X: -5
  28.     Y: 52
  29.     Z: 0
  30. # 完成各种模式的奖励
  31.     Prizes:
  32.       Medium: 310
  33.       Hard: 320
  34.       Easy: 300
