-【插件简介】-

                 
①插件介绍
       这是一款可以限制武器/防具的有效期插件,它可以支持mod服和rpgitem
②运行环境
  • JAVA7~8
  • Bukkit/Spigot/Cauldron
  • 一台可以运行的服务器...
  • and so on...

-【插件截图】-
首先准备一把武器/防具,并输入指令/vi  set 1(天数自定义)

然后就是这样

然后拿着,砍一下动物


就是这样,等到明天就会自动刷新掉了

/vi set x——设置x天有效期权限vi.use
