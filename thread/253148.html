部分插件介绍：
crazylogin
一款不错的登录插件，已经汉化
使用方法同xauth一样
占用内存偏中
多数人对这个插件不怎么熟悉
【MCPC端】用xauth的话经常玩家会被清空背包
所以我宁愿损多点内存来减少点麻烦


savenger
savenger，中文名称拾荒者死亡保护
一款很必要的插件
当你死了以后东西照样保存在背包
只是前置插件占内存有点多
如果不需要的话请把ProtocolLib和savengr删掉
这样你的服务器会流畅很多
需要设置才能使用
设置方法：
/mangaddp default savenger.savenge
/mangaddp default savenger.level
/mangaddp default scavenger.exp
/scvron
在后台或者游戏中打这4个指令设置




ScriptBlock
脚本方块，一个强大的插件
它的功能基本的代替了命令方块和命令牌子
命令方块都能实现这些插件的功能
也必须得自己设置玩家才能使用
详细方法点此网址：http://www.mcbbs.net/forum.php?mod=viewthread&tid=76134&highlight






quickshop
便捷商店插件
只要用出售或者回收的物品，左键点击
输入价格
即可轻松开商店
只要指令/qs
什么系统商店设置方法通有



客户端纯净即可
就介绍那么多了
