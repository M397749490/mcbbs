对了看你的目录名你应该用的是hmcl，
之前我用它的fabric自动安装貌似有bug，安装了启动不了，
你可以去fabric官网下载安装器自己安装而不用hmcl的自动安装
下载地址是：https://fabricmc.net/use/
有两个“Download Installer”，linux和os x用左边的，windows用右边的
fabric安装完之后再安装fabric api：https://www.curseforge.com/minecraft/mc-mods/fabric-api/
附件是最新的1.16.1的Fabric API

fabric-api-0.15.0+build.379-1.16.1.jar
