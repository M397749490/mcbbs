3.插件命令和权限
  • / bcd重新加载
    • 重新加载config.yml
    • booscooldowns.reload
  • / bcd clearcooldowns <player> [command]
    • 清除命令的所有活动冷却时间（或指定命令）
      • booscooldowns.clearcooldowns

  • / bcd clearuses <player> [command]
    • 清除设定的所有命令（或指定命令）权限
      • booscooldowns.clearuses

  • / bcd clearwarmups <player> [command]
    • 清除命令的所有等待（或指定命令）就是需要等待3秒才可执行某命令
      • booscooldowns.clearwarmups

  • / bcd限制
    • 显示您仍然可以使用有限命令的时间
    • booscooldowns.list.limits
  • / bcd set <category> <command> <value> [group]
    • 设置一些东西到config.yml（见下文）
      • booscooldowns.set

  • / bcd startglobalreset
    • 启动所有已配置的全局限制重置计时器
    • 您只需使用一次，即可在所需时间启动计时器（例如:g. sunday midnight）
      • booscooldowns.globalreset




补充
<category>
可以是冷却，等待，价格，物品消耗，经验花费，限制，消息

<command>
可以是*或任何以/开头的命令（用命令添加命令，用_ like / home_set替换空格）

<value>
可以是number（用于等待，冷却，价格，经验花费，限制），ITEM，数字（用于itemcost），消息字符串（现在不能包含空格，编辑config.yml）

[group]
可以是任何组，如果没有指定，将设置为默认组
