这是一个能够让你伪装成怪物或玩家的插件

1号玩家(左边)是使用了命令的，2号玩家(右边)是没使用命令的




命令：
  1. /disguise可以使用 /d 或者 /dis 来代替
  2. /disguise <怪物> [baby] - 伪装成一个怪物或怪物婴儿
  3. /disguise player <玩家名称> - 伪装成其他玩家
  4. /disguise un - 解除伪装
  5. /disguise stats - 关于你的伪装信息
  6. /disguise unall - 取消所有人的伪装
复制代码


权限：
  1. iDisguise.* - 全部权限
  2. iDisguise.player.<玩家名称> - 拒绝伪装成该玩家
  3. iDisguise.<怪物名称> - 伪装成指定怪物。例如：iDisguise.spider
  4. iDisguise.player - 伪装成玩家
  5. iDisguise.baby - 伪装成婴儿
  6. iDisguise.admin - 解除所有人伪装
  7. iDisguise.undisguise - 解除伪装(可在配置文件中启用/禁用)
复制代码


配置：
  1. # 保存伪装信息
  2. save-disguises: true

  4. # 伪装时有实体伤害
  5. entity-damage-while-disguised: true

  7. # 是否可以解除伪装(见权限)
  8. permission-for-undisguise: false

  10. # 攻击时解除伪装
  11. undisguise-on-hit: false
