测试版是Minecraft基岩版的测试机制，主要用于下一个正式版的特性预览。
然而，测试版主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。适用于正式版的领域服务器与测试版不兼容。
如果在测试版中遇到旧版存档无法使用的问题，测试版将允许你将存档上传以供开发团队查找问题。
Minecraft基岩版 1.16 仍未发布，1.16.0.59为其第6个测试版。
转载本贴时须要注明原作者以及本帖地址。
正文:https://feedback.minecraft.net/hc/en-us/articles/360042961851-Minecraft-Beta-1-16-0-59-Xbox-One-Windows-10-Android-


NOTE: This beta is a work in progress version of the full Nether Update. Some features seen in Java Edition snapshots may not yet be present.
注意：当前正在追赶下界更新的进度，所以一些Java快照中已有的特性还未加入。

4.（重要）新版本产生的一个非常严重的bug(该bug的编号为MCPE-74305):传送门的出口如果同一刻需要出现多个实体，则只会随机保留一个出现。这一个bug不仅仅适用于地狱门，末地门也是如此。拜这个bug所赐，现在基岩版的所有双维度刷怪塔全部报废，刷沙机也报废。再加上第一条所说的伪露天被当作bug修复，基岩版生电直接爆炸，重工业几乎无一幸免。

补充：简单的解释一下关于基岩版怪物生成机制
基岩版怪物生成判定是从上向下进行生成判定，且通过判定一个方块上表面是否可以生成怪物来确定一个生成点是否有效。（原本）在最上方的有效生成点会被视作露天生成，之后往下的一律视为洞穴生成。如果最上方有方块但并非有效生成点，那么生成判定会跳过露天生成。露天和洞穴的生成怪物上限是相同的，也就意味着露天生成占怪物生成当中相当重要的一部分。在这个版本更新之前，基岩版可以通过在最上方的有效生成点上铺上地毯（在更早的版本中，半砖同样可以达到此效果）来使系统不会跳过露天生成，而是向下重新搜寻最上方的有效生成点，并判定为露天生成。这一方法被称为伪露天，通过这一方法，基岩版可以成功地在遮挡光源的情况下不影响怪物刷新效率。
