提个思路吧，下课时间不长，这个是傅里叶的最简单情形之一



实现就是summon三个盔甲架A B C，A固定于原点，B绕A不断/execute run tp转圈，C绕B不断/execute run tp反向转圈（两个相对运动），并保证两者循环周期相同。然后再弄另一个连续执行的命令在C正下方放方块。

假设椭圆长轴2a，短轴2b，那么A距离B应该是(a + b) / 2，B距离C应该是(a - b) / 2

本轮均轮大法！
假设O(0,0)是中心，最初点O，A，B按上述顺序共线（假定A在O东边R远，B在A东边r远，R>r，坐标系建立是上北右东），
A绕O以某一角速度逆时针转动，同时B绕A以同一角速度顺时针转动。
在某一时刻，假设他们已经转了θ角度。A在O东偏北θ角度R远，B在A东偏北θ角度r远。
则A(Rcosθ,Rsinθ)，B(Rcosθ+rcosθ,Rsinθ-rsinθ)。
B在以O为中心，长轴是R+r，短轴是R-r的椭圆上！
