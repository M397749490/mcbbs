指令：
/sw reload  重载~~~~
/sw become <hero>   使用<英雄>
/sw info   信息
/sw join <game>  加入游戏 《》
/sw leave <game> 退出
/sw create <game> 创建
/sw finish <game> 结束
/sw delete <game> 删除
/sw <game> set <gametime/lobbytime> <time> 设置大厅等待时间
/sw <game> set <point1/point2/lobby>  设置加入点~~~貌似？
/sw <game> add spawnpoint   出生点~~~

权限：允许使用/重新加载或/帮助命令:
superwars.op.commands   允许 使用游戏创建/编辑命令
superwars.play.commands 允许 使用加入和离开的命令
