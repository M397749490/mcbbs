主手或者副手如果有水桶 并且视角面朝底端 水会自动在脚下倒出


就是这个效果


作者: WYL0zhu    时间: 2020-7-31 19:39
本帖最后由 WYL0zhu 于 2020-8-1 13:17 编辑

先放一个（保持开启），里面写：
  1. execute as @a[x_rotation=90,nbt={SelectedItem:{id:"minecraft:water_bucket"}}] at @s run setblock ~ ~ ~ minecraft:water
复制代码

，然后在刚才放的那个命令方块的输出端放一个 （保持开启），里面写：
  1. execute as @a[x_rotation=90,nbt={SelectedItem:{id:"minecraft:water_bucket"}}] at @s run replaceitem @s weapon.mainhand minecraft:bucket
复制代码

。再放一个（保持开启），里面写：
  1. execute as @a[x_rotation=90,nbt={Inventory:[{Slot:-106b,id:"minecraft:water_bucket"}]}] at @s run setblock ~ ~ ~ minecraft:water
复制代码

，然后在刚才放的那个命令方块的输出端放一个 （保持开启），里面写：
  1. execute as @a[x_rotation=90,nbt={Inventory:[{Slot:-106b,id:"minecraft:water_bucket"}]}] at @s run replaceitem @s weapon.offhand minecraft:bucket
复制代码

就好了。

@a[x_rotation=90]
这个目标选择器可以选择到视线朝向最下方的玩家。
@a[x_rotation=90,nbt={SelectedItem:{id:"minecraft:water_bucket"}}]
选择主手持有水桶的人
@a[x_rotation=90,nbt={Inventory:[{Slot:-106b,id:"minecraft:water_bucket"}]}]
选择副手持有水桶的人。

exe主/副手持有水桶的人执行以下函数。
没有函数的话可以用命令方块链。不过命令方块链必须指定@a而不能使用@s
1.使用execute run setblock在玩家脚下放置水方块；
2.用replaceitem将玩家的主手或副手的桶替换成空桶。记得优先判定主手。
