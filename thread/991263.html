前置插件
您需要ProtocolLib才能使插件正常工作。
您还将需要货币插件（如Vault），
并且还需要一个插件来处理货币，例如Essentials。

currency.yml
  1. #Let the plugin know what currency you want to use
  2. #for your player's auctions

  4. #Put 'Vault' for Vault Currency(Default)
  5. #Put 'Skript' for Skript Currency
  6. #If you misspell the currency type, it will automatically select Vault
  7. currency-type: 'Vault'

  9. #If your currency does not work the auction won't either
  10. #There are two possible errors:
  11. #Error 404 = The currency plugin is missing
  12. #Error 505 = The player's currency is unreachable (Frequently caused by undeclared/misspelled skript variables)

  14. #----------- Skript Configuration -----------
  15. #Use %player% for player's name
  16. #The variable should be like in skript but without braces
  17. #Example: {balance.%player%} would be balance.%player%
  18. skript-variable: 'balance::%player%'

兼容插件
此插件兼容Citizens，您可以创建一个NPC，单击该NPC即可打开菜单！为此，您还需要HolographicDisplays或Holograms！
两者都安装时，HolographicDisplays具有优先权。
创建的NPC就像普通的NPC，您可以对其进行任何编辑。
这个插件的货币也很灵活！您可以使用普通Vault，也可以将Skript可变货币用作货币！有关Skript用法的更多信息，只需检查currency.yml配置中的注释即可。
该插件具有HeadDatabase兼容性！
您可以将项目的ID设置为'skull：hdb- id'，并显示具有该ID的头像！
如果ID无效，则头像将成为问号。
您可以通过简单地使用以下命令来分配没有HeadDatabase的纹理头：'skull：username '
