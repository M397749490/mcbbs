模拟了咏唱过程——低头注视着卷轴便是咏唱，咏唱需要时间<--创意所在
其实还可以加几个内容，比如受到攻击咏唱打断，嗯难度也不高
--教程--
很好接下来教程走起~
如有错误欢迎指出~毕竟我没有准备好写贴的指令,凭记忆码的字
首先讲简单的
地图图案怎么改的呢？当然工作量如此大不可能是手建
自然是用软件——百度/谷歌:Map Item Editor
地图信息是保存在地图文件夹里的data文件夹
名称为map_x.dat 注：x是指数字 即是打开的地图的损伤值(数据值)
以二进制格式保存/*具体请看wiki*/所以可以用软件编辑
那么接着就是卷轴的内容了
初始化是建几个分数 全部都是dummy类型
一个用于检测玩家拿着哪个卷轴,这里就叫做:selectedScroll
通过计分板对于玩家分数处理的同时后面可带NBT用以检测NBT的这一设定
以及SelectedItem的NBT来检测，反复将此分数清零并且反复激活：
  1. scoreboard players set @a selectedScroll 1 {SelectedItem:{tag:{display:{Name:XX卷轴}}}}
复制代码
这样拿着XX卷轴的时候分数就为1了
一个用于检测玩家是否正在咏唱，也就是有没低头:isSpelling
这时检测方式是检测玩家的UUID标签rx,rxm,也就是玩家视线的竖直角度
另外还有横向角度ry,rym具体可以按F3打开调试界面看左上角的facing数值改着试试

  1. scoreboard set @a[rx=30,rxm=-90] isSpelling 1
复制代码
同样是反复清零此分数与激活以上命令
接着就是咏唱时间的因素了，有多种方式
我这里用了计分板记录玩家时间:time
根据命令方块激活延迟，没记错的话用最快脉冲不断减去time分数1的话
应该是减20分每秒

  1. scoreboard players remove @a time 1
复制代码

这里的用法是不断减去1分数
当达到特定分数(时间)时--就触发魔法有关的命令方块(输出)
当玩家开始咏唱时--将time分数设置为咏唱需要的时间
但，这里有个问题，我的一个解决方式是--我们需要再加一个分数:reset
这是为了判断玩家是不是已经在咏唱中了
也就是只把reset分数为0的开始咏唱的玩家time重置
  1. scoreboard players set @a[score_selectedScroll_min=1,score_selectedScroll=1,score_isSpelling_min=1,score_reset_min=1] time 100
复制代码
重置之后立刻将reset设为1
同时不断检测——
不断将抬头、没有选择卷轴、切换卷轴(以及你想加入的其它情况如受到攻击)的玩家的reset设为0
这里只例举其中一条指令,将没有咏唱的玩家reset为0,请大家举一反三,也能加深印象：

  1. scoreboard players set @a[score_isSpelling=0] reset 0
复制代码

这个问题在于不加入reset(或者用其他方法解决)的话，玩家开始咏唱后
time会不断重置，就无法减去数值了
好了，教程就至此吧
