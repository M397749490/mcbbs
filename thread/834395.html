  • Holographic Displays支持
  • Vault支持
  • CrackShot支持
  • 基于权限
  • 自定义生物模型
  • 单玩家和全球玩家的不同皮纳塔模型
  • 用于预览的GUI
  • 大多数信息都是可自定义的
  • 可购买(需Vault支持)
  • 4种类型的礼物(钱,物品,命令,枪)
  • 礼物箱
  • 逼真的破坏以及失明特效
  • 支持多种语言


      *[]内为必填项, <>内为可选项
     /pinata create [皮纳塔名] <玩家ID> - 在某玩家位置生成一个皮纳塔
           或 /pinata create [世界名] [x] [y] [z] [皮纳塔] - 在指定位置生成一个皮纳塔
     /pinata buy [皮纳塔名] - 购买皮纳塔 (需Vault支持)
     /pinata list - 列出所有的皮纳塔
     /pinata preview [皮纳塔名] - 预览皮纳塔的掉落
     /pinata reloadconfig - 重载配置文件
     /pinata setcrate - 设置皮纳塔箱子在一个特殊的地方
     /pinata cratelist - 列出所有已生成的
箱子

         pinata.* - 所有命令的权限
         pinata.player.* - 使用礼物箱和指令
         pinata.player.crate - 使用箱子
         pinata.player.sign - 使用木牌
         pinata.command.* - 使用所有指令
         pinata.command - 使用 /pinata
         pinata.command.list - 列出所有皮纳塔
         pinata.command.buy - 购买皮纳塔
         pinata.command.preview - 预览
         pinata.admin.* - 管理员命令
         pinata.admin.reload - 重载配置文件
         pinata.admin.create - 生成皮纳塔
         pinata.admin.create.others - 在其他玩家的位置生成皮纳塔
         pinata.admin.notify - 在进入服务器时获取关于插件更新的通知
         pinata.admin.freeall - 免费购买所有的皮纳塔
         pinata.admin.crate.destory - 破坏箱子
         pinata.admin.crate.list - 列出所有的箱子
         pinata.admin.crate.set - 设置箱子
         pinata.admin.sign.set - 设置木牌
         pinata.admin.sign.destroy - 破坏木牌
         pinata.use.default - 使用预先配置的 "default" 权限 (你可以编辑每个权限)

  10. #     cost: <数量> //购买皮纳塔的话费.仅在安装Vault时可用.设置为“-1”禁用购买
  11. #     type: <public/private> //设置皮纳塔的类型. 设置为"public"允许所有的玩家击败皮纳塔并获得它的掉落物. 设置为"private"则仅允许生成它的玩家击败
  12. #     blindness-effect: <true/false> //当皮纳塔被生成时玩家是否应该失明

  15. #     full-blindness-effect: <true/false> //是否启用完全失明效果？
  16. #     crate-time: <秒> //在被生成后皮纳塔将被栓在礼物箱上多少时间？
  17. #     health: <数量> //皮纳塔拥有的生命值数量
  18. #     mob-type: <实体类型> //所有的实体类型在这里: https://minecraft.gamepedia.com/Mob

         Q:在哪里可以反馈bug/建议?
         A:在这里
         Q:我的皮纳塔不能被生成!
         A:确保任何插件(例如WorldGuard)不会干扰生成
         Q:有变量吗?
         A:你可以在指令礼品和holo全息图中使用%player%变量
         Q:你打算更新这个插件吗?
         A:是的!我已经添加了更新通知,当插件有更新时你将获得推送!
         Q:我该如何使用Pinata API?
         A:有关事件和方法，请查看此文档
         Q:如何使用皮纳塔礼物箱？
         A:
         1.将一个箱子放在指定位置
         2.在查看已放置的箱子时输入指令/pinata setcrate <礼物箱名>
         3.现在你可以在礼物箱里买到皮纳塔了！
         (不要用WorldEdit等非常规方法除去箱子)
         Q:如何启用/禁用万圣节模式?
         A:默认情况下禁用万圣节模式，您可以在config.yml中启用它
         Q:如何创建一个皮纳塔木牌？
         A:
         Q:如何在随机的自定义位置生成皮纳塔?
         A:只需在X，Y或Z坐标中使用~字符
         例如/pinata create world 14~50 80 100 default
         它会在14~50X,80Y,100Z之间的随机X坐标生成皮纳塔
         Q:如何更改插件的语言?
         A: 目前有：英语，波兰语，德语，法语，西班牙语和荷兰语(当然还有汉语)
         要在config.yml中启用语言环境编辑语言环境值，请使用以下前缀：
         英语 - en
         波兰语 - pl
         德语 - de
         法语 - fr
         西班牙语 - es
         荷兰语 - nl
         汉语 - cn
