问题：如何为函数添加"minecraft:tick"标签
版本：1.13, 17w50a
作者: pineapple_    时间: 2017-12-23 10:46
打开.minecraft/saves/(世界名称)/datapacks
然后新建文件夹，最好用小写字母和数字命名
然后打开该文件夹创建一个记事本，命名为pack.mcmeta
注意拓展名为.mcmeta，你创建的应该是pack.mcmeta而不是pack.mcmeta.txt，一定要注意拓展名
打开pack.mcmeta，最好用Notepad++打开，
添加代码
  1. {
  2.    "pack": {
  3.       "pack_format": 3,
  4.       "description": "."
  5.    }
  6. }
复制代码


保存并关闭pack.mcmeta
在该文件夹内再创建文件夹，命名为data

打开data文件夹，在里面新建一个文件夹
用小写字母或数字命名，作为函数的命名空间(就是function a:b的a部分的名称)
再打开该文件夹，新建文件夹命名为functions，然后打开将mcfunction放进去

回到data文件夹，新建文件夹命名为minecraft，

打开，新建文件夹命名为tags
打开tags再新建文件夹functions
打开functions新建记事本，命名为tick.json
同样要注意拓展名是json
用Nopead++打开
添加代码
  1. {
  2.   "replace": false,
  3.   "values": [
  4.     "函数命名空间:函数名"
  5.   ]
  6. }
复制代码

这样保存就可以了
