=>效果


=>特性
  • 可以设置权限给予加入的物品.
  • 如果有一个玩家已经有的加入物品便不会进行再次给予.
  • 重生给予加入的物品 (配置)
  • 防止物品掉落,防止死亡掉落.

=>配置
  #配置名称，不能重复.
first-item:
    id: 347
    # 物品ID.
    name: '&f[&e&lxxx&f]&a传送菜单'
    # 物品显示名称.
    data-value: 0
    #data值，一般羊毛等物品会用到
    cooldown-seconds: 0
    # 使用冷却时间.
    command: 'chc open CD'
    # 绑定在物品上指令
    # 右键触发.
    # 有一些特殊的前缀可以使用额外功能
    # 'console: ' (通过控制台执行指令)
    # 'op: ' (通过op执行指令)
    # 'server: ' (<font><font>BungeeCord的服务器名称，切换服务器用的)</font></font>
    # 'tell: ' (发送消息给玩家)
    #
    # 可以使用的标志有 %player% 和 %world%.
    #
    # 多个命令的书写形式: 'command; command2; command3'
    lore:
      - '&7右键打开'
    # 物品描述.
    block-movement: false
    # 是否能移动物品.
    slot: 1
    #物品所在位置.
    permission: ''
    # 获得或者使用这个物品的权限，建议留空.
    first-join-only: false
    # 第一次加入时赠送一个物品
    give-at-respawn: true
    # 死亡重生后重新发送一个物品
    allow-drop: false
    # 是否允许扔掉.
    give-on-world-change: false
    # 世界改变的时候重新赠送物品.
    disabled-worlds: ''
    # 不能使用这个物品的世界，填写''取消限制.
