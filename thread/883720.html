作者: west.myth    时间: 2019-7-10 14:37
   “[]”代表所需替换的内容，“（）”代表作为提示，可以删去的内容。
Name [物品名称]
ShortName [物品短名，在游戏中使用指令时的物品名就是这个]
//The ammo this gun uses (shortName)
Ammo [所用弹药的物品短名,如果想使用多种弹药只需再添加一行Ammo即可]
Icon [在物品栏中显示的图标，填写assets\flansmod\textures\items中的文件名]
//Colour in Red, Green, Blue, each going up to 255.（材质颜色）
Colour 255 255 255（填255即可）
ItemID [在不冲突的前提下随意]
//Reload time in ticks, 1/20ths of a second（装弹时间）
ReloadTime [正整数，每20为一秒]
//The amount of gun recoil, all relative : Sten = 1, Mp40 = 3, Kar98kSniper = 20（后坐力，MP40为3，Kar98kSniper为20）
Recoil [正整数]（不宜过高）
//Number of bullet entities to create, useful for shotguns, defaults to 1（每次发射产生的子弹数，霰弹枪用，默认为1）
NumBullets [不是霰弹枪就填1，是散弹填写每颗霰弹产生的子弹数]
//Damage in half hearts（伤害）
Damage [任意正整数]
MeleeDamage [近战伤害，任意正整数]
//The higher this value, the more the bullets spread（子弹离散度）
Accuracy [任意正整数]
//Time in ticks between rounds（两次射击的时间间隔，直接影响射速）
ShootDelay [任意正整数，每20为1秒]
ShootSound [射击音效，填写assets\flansmod\sounds中的ogg文件名]
ReloadSound [装弹音效，填写assets\flansmod\sounds中的ogg文件名]
Mode [SemiAuto/FullAuto/Brust]（半自动/全自动/连发点射）
//The number of bullets to fire each round（如果没设置Mode为Brust请无视本段代码）
NumBurstRounds [任意正整数]
OneHanded [Ture/False](是否可以双持，1.71首次出现)
//Bullet speed, default 3.0(子弹速度，默认为3）
BulletSpeed [任意正整数]
//Default scope settings. Usually for aiming down sights. In which case, use FOVZoomLevel, not ZoomLevel（默认瞄准效果设置）
Scope [None,如果有则填写assets\flansmod\gui中的瞄准效果贴图]
ZoomLevel [正常放大倍数，填写大于等于1的数]
FOVZoomLevel [瞄准放大倍数，填写大于等于1的数]
//Deployable Settings（部署设置）
Deployable [Ture/False]（可否部署）
DeployedModel None（关于固定武器的写法将在后续章节提及）
//Model settings
Model [3D模型，填写com\flansmod\client\model\模型文件夹 中的模型，格式为:文件夹.模型文件名称]
Texture [枪械皮肤，填写assets\flansmod\skin中的文件名]
Modelscale [正数](具体值在toolbox内确认后再填，toolbox的调整不会影响模型本身，只是为这里提供参照）
//Attachment Settings（配件设置）
AllowAllAttachments [ture/false]（如果为true则会允许添加所有配件）
//List here all the attachments allowed on this gun by shortName and separated by spaces（在这用短名列出所有允许的配件，用空格隔开）
AllowAttachments [ture/false/配件1 配件2 配件3……]（如果为true则会允许添加所有配件）
AllowBarrelAttachments [允许的枪管配件，同上]
AllowScopeAttachments [允许的瞄准镜配件，同上]
AllowStockAttachments [允许的枪托同上]
AllowGripAttachments [允许的下挂配件，同上]
NumGenericAttachmentSlots 1
//Paintjob Settings（涂装设定）
//Format is "Paintjob iconName textureName requiredDyeAmount requiredDyeColour" Multiple colours may be listed in order, seperated by a space
（格式为Paintjob 图标文件名 材质文件名 需要的染料数量 需要的染料颜色，增加的需要列出，空格隔开）
//Dye colours are "black", "red", "green", "brown", "blue", "purple", "cyan", "silver", "gray", "pink", "lime", "yellow", "lightBlue", "magenta", "orange", "white"
（染料颜色有黑、红、绿、棕、蓝、紫、蓝绿、银、灰、、粉红、黄绿、黄、亮蓝、品红、橙、白）
//Paintjob 图标文件名 材质文件名 需要的染料颜色 需要的染料数量（与上面的英语注释不同，但正确写法的确如此，如果需要多个涂装只需多写几行即可）
