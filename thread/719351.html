推荐插件:
  • Essentials - 经济插件如果你不止有一个世界，可以使用MultiWorldMoney。

  • MultiInv - 管理背包，将背包存档在每个世界中分开。

首次安装和配置:
(有关升级，请参阅每个版本的更新日志。)
  • 下载插件（ASkyBlock.jar）和其他插件（Vault）
  • 放入你的插件文件夹
  • 重新启动服务器 - 生成配置文件和空岛世界
  • 停止服务器
  • 打开 /plugin/ASkyBlock 文件夹
  • 打开config.yml 并按照自己的意愿进行调整。 您可能还想更改其他配置文件，如 blockvalues.yml 和challenges.yml
  • 再次启动服务器
  • 使用权限管理插件对权限进行调整
  • 登录服务器并输入 /is 开始空岛生存！
（以下操作是可选的）
  • 更改空岛设置。
  • 检查challenges.yml 并按照你的喜好去配置。
  • 不使用地狱风格的空岛 （查看 config.yml ）（记住删除名为ASkyBlock_nether的世界，如果你这样做会重新生成）
  • 如果你喜欢使用空岛主城，请设置你的主城，去一个远离其他岛屿的地方输入 /asadmin setspawn 然后会在该位置设置一个空岛主城。
  • 在该区域内使用 /asadmin info 来告诉你主城的位置

玩家命令:
(在游戏中使用 /is help 可以看到全部的命令，此处可能并不全面)
  • /island - 生成一个新的岛屿，打开菜单或将玩家传送到他的岛屿
  • /island help - 展示帮助信息
  • /island go -传送到你的岛屿
  • /island go <数字> - 传送到岛屿传送点  (使用 /sethome <数字> 可设置)
  • /island biomes - 打开生物群系菜单
  • /island cp 或 controlpanel - 打开操作菜单
  • /island expel - 强制将一个玩家驱逐出你的岛屿
  • /island reset 或 restart - 重新开始岛屿（有限制次数和冷却时间，请慎重使用）
  • /island lang - 允许玩家改变插件的语言
  • /island level - 岛屿排名
  • /island level <玩家> - 显示该位玩家的岛屿排名
  • /island lock - 锁定一个岛屿，没有人可以进入
  • /island ms 或 minishop - 打开迷你商店，如果没有经济系统本功能关闭
  • /island top - 展示空岛前十名
  • /island settings - 设置岛屿属性
  • /island sethome - 设置当前位置为传送点
  • /island spawn -传送到空岛世界主城
  • /island warps - 查看可用的坐标列表
  • /island warp <名字> - 传送到一个坐标点
团队相关命令:
  • /island invite - 邀请玩家加入到你的团队，一次只能邀请一个人。
  • /island accept 或 reject - 接受或拒绝一个邀请.如果玩家已经有一个岛屿了,该岛屿将会被删除。
  • /island team - 查看团队信息
  • /island teamchat - 开启团队聊天模式，不受别人的打扰，使用此功能的前提是必须在配置文件中启用了该功能，只有团队的成员才能看到聊天，管理员可以监听聊天
  • /island leave -离开一个岛屿，返回出生点
  • /island kick or remove <玩家> - 只能由领导者使用 - 删除团队成员. 如果该玩家在线，他背包的所有物品将会掉落并把玩家传送到主城.如果玩家不在线，将会在该玩家下一次登录时将玩家踢出并发送给玩家被团队驱逐的信息。
  • /island makeleader <玩家> -空岛所有权转让给团队的一个成员，只能由领导者使用。
管理员命令
（通过 /asadmin 命令查看（在游戏中检查的最新命令集，此页面可能不是最新的）
  • /asadmin reload -重新加载所有配置文件
  • /asadmin delete <玩家> - 删除玩家的岛屿
  • /asadmin completechallenge <玩家> <挑战名> - 为玩家完成挑战
  • /asadmin resetchallenge <玩家> <挑战名> - 重置玩家的挑战
  • /asadmin resetallchallenges <玩家> - 清除玩家的所有挑战
  • /asadmin purge [天数] - 将删除超过指定天数未登录玩家的空岛，建议先备份世界，在没有玩家的时候使用
  • /asadmin info <玩家> - 显示玩家和岛屿的信息
  • /asadmin info challenges <玩家> - 显示玩家挑战完成状态
  • /asadmin spy - 监听团队聊天，必须有适当的权限。
  • /asadmin topten - 不译，作者说这命令永远都不需要运行 →_→
  • /asadmin unregister <玩家> - 从岛上删除一个玩家，不删除岛屿
  • /asadmin clearreset <玩家> - 清除玩家的岛屿重建次数
  • /asadmin clearresetall - 将游戏中每个玩家的设置更改为config.yml中的值.
  • /asadmin setbiome <领导者> <群系> - 设定领导者的岛屿生物群系。
  • /asadmin setrange <领导者> <距离> - 将领导者的岛屿的保护范围设置为岛屿距离的最大值。
  • /asadmin topbreeders - 列出服务器实体数量最多的10个岛屿，只搜寻加载的岛屿。
团队编辑命令:
  • /asadmin team kick <玩家> - 将玩家踢出所在的团队.
  • /asadmin team add <玩家> <领导者> - 添加玩家到领导者的团队.
游戏命令:
  • / asadmin register <玩家> - 将最近的岛屿注册到指定玩家。 请在岛屿上使用此命令。
  • / asadmin setspawn - 设置空岛世界主城。 主城特殊规定和保护。
  • / asadmin tp <玩家> - 传送到玩家的岛屿
  • / asadmin unregister - 将此岛屿的领导者驱逐。请在岛上使用此命令。
  • / asadmin deleteisland confirm - 删除你所在的岛屿。 请注意，您必须键入完整的命令。
  • / asadmin info - 提供您所在岛上的信息。
  • / asadmin setrange - 设置您所在岛屿的范围。如果这个区域为主城，范围可以大于空岛距离。

欢迎木牌:
  • 欢迎木牌是玩家制作传送坐标的一种简单的方式。 每个玩家只能生成一个坐标。 他们通过在牌子的第一行写[WELCOME]来创建一个欢迎木牌。 如果牌子创建成功，该行将变为绿色。 如果有问题，会变红。
