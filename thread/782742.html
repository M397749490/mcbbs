BUNGEECHATFILTER   ·   高级蹦极聊天过滤器&全方位管理 ！

简介

一个非常强大的 Bungee 聊天管理,
可制定你自己的规则，屏蔽敏感词句、命令.

并对其执行操作，
(取消、替换、公告、消息、踢出、命令）

插件默认也能防止玩家刷屏、重复消息. 监听玩家的指定命令，
可制定每个规则的权限

同时, 该插件也支持正则表达式匹配, 让玩家投机取巧不成.



适用于 Bungee 1.8 - 1.12 ,  插件开源.
理想的高级 Bungee聊天管理 插件.

  4. ## Bungee Chat Filter (蹦极聊天过滤器)-配置文件       ##
  5. ## v1.7 ## 注释汉化 Arasple
  6. ##########################################

  8. #是否启用监听命令
  9. Monitor Commands: true

  11. #监听命令的列表
  12. Commands:
  13. - msg
  14. - message
  15. - m
  16. - tell
  17. - whisper
  18. - w
  19. - g
  20. - global
  21. - s
  22. - l
  23. - local
  24. - url
  25. - website
  26. - hub
  27. - shop
  28. - broadcast

  30. #是否启用防刷屏
  31. AntiSpam: true
  32. #是否启用防重复内容
  33. AntiRepeat: true
  34. #最小聊天间隔 (单位: 毫秒)
  35. Minimum-Chat-Delay: 1500
  36. #最小重复内若间隔 (单位: 毫秒)
  37. Minimum-Repeat-Delay: 60000
  38. #当玩家被阻止刷屏/重复内容时提示的消息
  39. AntiSpamMessage: '&c请勿刷'
  40. AntiRepeatMessage: '&c请勿重复同一内容'

  42. #规则组 - 以下内容为本插件的配置格式, 请按照该格式添加你自己的规则
  43. #rules:
  44. #   rulename:                       - 规则名
  45. #       regex:                      - 匹配的内容(可选用正则表达式)
  46. #       ignores:                    - 若匹配到该内容, 则不执行任何操作
  47. #       permission:                 - 越过该规则组的权限
  48. #       actions:                    - 以下是匹配到后所执行的操作
  49. #           deny: true              - 是否取消该聊天事件.
  50. #           message: <message>      - 将向玩家发送一条消息 (支持变下方变量)
  51. #           kick: <message>         - 将踢出玩家并显示该信息 (支持变下方变量)
  52. #           alert: <message>        - 将发送全服公告 (支持变下方变量)
  53. #           remove: true            - 玩家信息照常发送, 但将移除匹配到内容
  54. #           replace:                -  将随机替换的内容 (支持变下方变量)
  55. #               - word1
  56. #               - word2
  57. #           lower: true             - 将强制把消息内容中的字母转小写
  58. #           pcommand: (command)     - 蹦极命令, 将会使玩家发送一个命令到蹦极. 不需要包含斜杠. (支持变下方变量)
  59. #           scommand: /(command)    - 服务器命令, 将会使玩家发送一个命令到服务器. 必须包含斜杠 (支持变下方变量)
  60. #           ccommand: (command)     - 控制台命令, 将会让控制台执行一个命令, 不需要包含斜杠 (支持变下方变量)
  61. #                                      请注意, 目前无法执行当前服务器控制台的命令.

  63. #变量                       - 以下变量可用于本插件的任何提示信息
  64. #
  65. # {player}                          - 玩家的名称
  66. # {message}                         - 玩家发送的原消息
  67. # {arguments}                       - 玩家命令第一个参数后的所有字符串内容
  68. #                                       (例如玩家执行命令 "/send Zedwick Hello!" , 该变量将会显示"Zedwick Hello!" )

  70. rules:

  72. #利用正则表达式过滤单词 **, 并用强制替换为列表中的随机单词
  73.     swearfilter1:
  74.         regex: (?i)(f+u+c+k+|f+u+k+|f+v+c+k+|f+u+q+)
  75.         actions:
  76.             replace:
  77.                 - fudge
  78.                 - frack
  79.                 - funk
  80.                 - fork

  82. #利用列表形式的正则表达式过滤这些单词, 并用强制替换为列表中的随机单词
  83. #首项目为 (?i)(cunt 以不区分大小写. 但列表形式的正则表达式匹配末项必须以 ')' 结尾
  84.     swearfilter2:
  85.         regex:
  86.             - (?i)(cunt
  87.             - whore
  88.             - fag
  89.             - slut
  90.             - queer
  91.             - bitch
  92.             - bastard
  93.             - dick
  94.             - gay)
  95.         actions:
  96.             replace:
  97.                 - lovely
  98.                 - sweetie
  99.                 - sexy

  101. #利用正则表达式过滤单词 Nigger(黑鬼) , 踢出该玩家并全服公告
  102.     swearfilter3:
  103.         regex: "n[^a]gg+(a|er|uh)"
  104.         actions:
  105.             deny: true
  106.             alert: "{player} 因种族歧视被踢出服务器"
  107.             kick: "黑人怎么了? 惹你了?"

  109. #自动将单词bloodsplat替换为带颜色的
  110.     colorReplace:
  111.         regex: "bloodsplat"
  112.         actions:
  113.             replace:
  114.                 - "&cBloodsplat"
  115.                 #前提是该服务器必须支持彩色聊天且该玩家有权限


  118. #当玩家试图要OP的时候, 随机替换为下列句子并发送一个警告消息
  119.     askforOP:
  120.         regex: "(?i).*给我OP.*|.*我想要OP.*"
  121.         actions:
  122.             replace:
  123.                 - 能ban掉我吗?
  124.                 - 我在使用X-Ray
  125.             message: '&c请勿要OP了'

  127. #当玩家聊他内容中超过4个单词且全部大写时, 强制转化为小写
  128.     CAPSPAM:
  129.         regex: (\p{Lu}|\s){4,}
  130.         actions:
  131.             lower: true

  133. #当玩家没有权限时, 禁止使用&k, &l, &o代码
  134.     AntiFormatText:
  135.         regex: '&[k-o]'
  136.         permission: bungeefilter.antiformatbypass
  137.         actions:
  138.             remove: true
  139.             message: '&c你没有权限使用格式字体'

  141. #当玩家没有权限时, 移除彩色代码
  142.     AntiColorText:
  143.         regex: "&[0-9 a-f]"
  144.         permission: bungeefilter.colorbypass
  145.         actions:
  146.             remove: true
  147.             message: '&c你没有权限使用彩色代码'

  149. #当玩家聊天内容中包含疑似服务器IP的时候, 踢出该玩家.
  150.     AntiAdvertising:
  151.         regex: (^.*([0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}).*$)|(^.*((mc|play)\.(.*)\.(com|net))|((.+)\.(.*(mine|craft).*)\.(com|net)).*$)
  152.         ignores: (^.*minecraftserver.*$) |(^.*minecraftserver2.*$)
  153.         actions:
  154.             kick: '&c请勿宣传其它服务器.'
  155.             deny: true

  157. #快捷命令 - 自动替换/hub为/server hub
  158.     CommandShortcut:
  159.         regex: /hub
  160.         actions:
  161.             pcommand: /server hub
  162.             deny: true

  164. #快捷命令 - 自动替换/shop为/server shop
  165.     CommandShortcut2:
  166.         regex: /shop
  167.         actions:
  168.             scommand: /warp shop
  169.             deny: true

  171. #自定义蹦极命令 - 公告
  172.     CreateCommand:
  173.         regex: /broadcast #执行命令
  174.         permission: "!bungeefilter.broadcast" #所需权限
  175.         actions:
  176.             alert:
  177.             - ''
  178.             - '&5[公告] &a{player}&f: {arguments}' #替换参数为命令后的内容
  179.             - ''
  180.             deny: true

  182. #快捷命令提示 - 当玩家执行/url或/website时提示玩家本服官网
  183.     CreateCommand2:
  184.         regex: (/url)|(/website)
  185.         actions:
  186.             message: "&l&6[智能检测]&3 本服官网为 &6www.minecraftserver.com"
  187.             deny: true

使用介绍    &    命令权限



                    · 创建一个新的规则 :

                                       - 这个很容易做到，你只需要复制已有的规则
                                       - 并更改一下规则的名称（不能重复），
                                       - 若有需要可自定义添加其它的操作.


                    · 正则表达式 :

                                       - 推荐一个教程，点我访问

                    · 变量 - VARIABLES :

                                       - 插件仅提供了三个变量，
                                       - 你可以在配置文件中的任意字符串提升内使用，
                                       -
                                       # {player} - 玩家的ID  (发送消息/命令的)
                                       # {message} - 玩家发送的原始消息
                                       # {arguments} - 玩家命令后的参数

                    · 命令权限 :
                                        /Bfreload - 重载配置
                                       
                                       - bungeefilter.reload (重载配置)
                                       - bungeefilter.bypass (越过规则检测)
                                       - bungeefilter.bypass.spam (越过刷屏检测)
                                       - bungeefilter.bypass.repeat (越过重复内若检测)
                                       - 你可以在配置文件中自定义权限
                                       - 注意：本插件所有权限均基于Bungee，推荐使用LuckPerms
