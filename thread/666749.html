你对原版的僵尸骷髅感到厌烦了吗。
你想要新的，更可怕的怪物来挑战自我吗，那么这个mod可以帮助你。
本模组已经停止更新
注意：这个mod有比较尖利刺耳的音效和比较血腥突兀的画面表现
玩家普遍反映这个mod比较让人害怕，请游玩前考虑你的承受能力
此模组已经停止更新
不要试图在很多模组的整合包里放这个
++简介++
++怪物++
==突变史蒂夫==
速度：普通
HP：40
攻击力：16（8心）
掉落物/几率：皮革/高；活塞/中；粘性活塞/中；菌丝/中；地狱砖块/高
史蒂夫因为摄入过多的药剂、被僵尸啃噬，突变成了畸形的怪物。
他的左手十分的坚硬（堪比麒麟臂），任何爆炸抗性低于液体（500/威力5）的方块均会被变异史蒂夫破坏，攻击附带击退效果。是个十分难缠的怪物。
你可以通过查阅MinecrfatWiKi爆炸抗性词条来认识什么方块可以阻挡它。
==腹中胎儿==
速度：快
HP：40
攻击力：12（6心）
掉落物/几率：粑粑/高；婴儿之眼/中；甜菜/低；煤炭/高；烟花/高
这个不幸的孩子的母亲拒绝生出它。无穷的疼痛使它看起来像是个蠕动的不断变形的肉块。
它会将自己隐藏在阳光无法直射到的最深的洞穴中。
它的移动速度很快，如果且靠近它，它会发出刺耳的闷叫声。并给予你一个失明效果。所以尽量远离是明智的。
特有掉落：婴儿之眼
拿在手里右键任何方块，方块会瞬间变为掉落物，效果等同于精准采集。任何方块都可以采集，包括基岩！（使用消耗耐久）
==攀爬者==
速度：慢
HP：24
攻击力：8（4心）
掉落物/几率：任何染料/高；西瓜种子/低；地狱疣/中；绿宝石/中；糖/高
一具由洞穴蜘蛛杀死的尸体，尸体中残余的毒液将这个未啃食完的尸体变异成了类似蜘蛛的亡灵。现在它的行为类似于蜘蛛，可以爬墙。
移动速度比较慢，但高墙并不能阻止它。
==粘液飞头==
速度：非常快
HP：30
攻击力：10（5心）
掉落物/几率：粘液飞头肉/高；皮革/高；地狱疣/低；红色蘑菇/高；红石/中
当粘液进入一具尸体时，一种新的怪物诞生了。这是一个拖着内脏的头颅，总是渴望着身体。
它的移动速度使得攻击它变得十分困难，并且你每对它攻击一次，它就会在它的身体里增殖出一个史莱姆（最小型号）来干扰你的移动，尽量快速解决是上策。
特有掉落：粘液飞头肉
左键单击一个动物，将其转换成粘液飞头。警告：对玩家也有效，会使玩家立即死亡且转换为粘液飞头。（只能使用一次）
==霜冻异怪==
速度：慢
HP：45
攻击力：16（8心）
掉落物/几率：任何彩色玻璃/高；浮冰/高；各种马铠/非常低；普通箭以外的箭/高
浑身包裹着严寒，没有人知道它来自何方。包裹它的寒冷是如此强烈，以至于你在其附近会立即觉得行动迟缓（缓慢20秒）并且会受到伤害，它会冻结周围环境（走过的地方形成一个范围的雪，水冻成冰）。你可以通过它脚下的雪的范围来确认会不会受到伤害。
==堕落领袖==
速度：慢
HP：60
攻击力：20（10心）
掉落物/几率：堕落领袖脊柱/低；铁栅栏/中；黑曜石/高；普通箭以外的箭/高；铁轨/高
曾经他是一个受欢迎的领导者，但是他的决策失误导致了数百万人的死亡。当许多勇敢的人联合起来推翻了他的统治后，堕落的领导者**身亡。他的罪孽让他的灵魂永远的禁锢在他那可怜的身体里，因而让他产生了无穷的愤怒。它的攻击欲望和坚硬的皮肤使得它是一个棘手的对手。
特有掉落：堕落领袖的脊柱
可以用来攻击，虽然带有极强的击退效果，但是它能造成的伤害很低（使用不消耗耐久）
==血腥少女==
速度：慢
HP：20
攻击力：4（2心）
掉落物/几率：血腥**/低；面包/高；骨头/高；钻石/非常低；粘土/中
非常危险的怪物，它可以在地底的洞穴中被发现。它的外观如同一个死去的女人的尸体，不断的发出哀嚎，仿佛它还有一丁点灵魂。它的哀嚎声可以在很远的地方就能听到。咋一看它其实并不强，但是当它攻击你时，皮肤会逐渐泛红，当皮肤完全变红时，不管你拥有多高的护甲，也会被它一击必杀。
特有掉落：血腥**
右键一个方块将这个方块替换为一个岩浆源（不流动），潜行右键任意方块将这个方块替换成一个水源（不流动）（使用消耗耐久）
==僵尸鸡==
速度：慢
HP：16
攻击力：8（4心）
掉落物/几率：幸运蛋/高
长夜（低亮度）或者不死的存在（僵尸等）有时会导致僵尸鸡的出现。尽管它们很小很不起眼，但是它们相当难以杀死。尽管如此，这不是僵尸鸡最危险的地方，僵尸鸡如果看到普通鸡，它们会优先攻击普通鸡并将普通鸡转化为僵尸鸡（同僵尸转化村民）。所以保护好你的鸡舍是十分必要的。
特有掉落：幸运蛋
右键投掷，比起普通鸡蛋能砸出小鸡外，它还可以随机砸出别的东西（僵尸鸡，各种物品，点燃的TNT等），至于到底是什么？谁知道呢（笑。
==礼盒怪==
速度：中等
HP：26
攻击力：1
掉落物/几率：礼盒怪之魂/非常高；火药/高；TNT/中；末影珍珠/中；烟花/高
礼盒怪会在能下雪的生物群系中找到。它看起来非常弱，但它有非常烦人的特殊能力，在靠近玩家时，它会在玩家周围瞬间生成一个礼物盒形状的建筑（构成这个建筑的礼盒方块会随时间渐渐消失），并在盒子里生成几只苦力怕。稍有不慎便GG。所以远距离击杀是个不错的办法。
特有掉落：礼盒怪之魂
右键使用，生成一个礼盒怪（一次性）
==双首异客==（1.5更新）
速度：中等
HP：40
攻击力：4
掉落物/几率：红石/高；骨头/中；烤土豆/低；皮革帽子（满耐久）/高；皮革裤子（满耐久）/高；皮革外套（满耐久）/高；皮革靴子（满耐久）/高
双首异客会在黑暗中生成，它的速度中等，会自动追逐玩家，像僵尸一样，它会在白天燃烧
当它追上玩家时，它会破坏玩家脚下的两格方块并困住玩家，这时它不会攻击你，除非你试图逃离
它会一直守在困住你的坑洞周围直到其死亡或者玩家死亡。
==闹鬼牛==（1.6更新）
速度：中等
HP：24
攻击力：12
掉落物/几率：牛刷怪蛋/高，失落的阳光/极低
致命的寄生生物在发作时可以控制动物，几乎所有寄生虫都寄居在牛的脑内，而痛苦的刺激将会使它们苏醒。
当你用除了剑与弓以外的武器（包括空手）攻击牛时，牛就会被转化为闹鬼牛，如果转化的时候是白天，那么将会被强制转为夜晚。
==异形水鬼==（1.7更新）
速度：快
HP：20
攻击力：无
掉落物/几率：生鱼/高，生鲑鱼/高
只能在水中生成和活动，本身没有攻击力，但会将靠近水源的玩家拉至水下窒息而死。
并且，除了鱼镖以外任何近战武器都不能对他造成伤害
其名字Topielec（或称vodyanoy）来自斯拉夫神话中青蛙般脸的裸体老人，拥有绿色胡子和长发，带着满身的藻类，全身都是黑色的鱼鳞。手部是蹼爪，长着鱼的尾巴和像炽热的煤一样燃烧的眼睛的水精灵（水怪）。
他经常被当地人称为“祖父”或“祖先”。据说它会将人拖入水中。
当它愤怒时，它会打破水坝，冲破水磨坊，淹死人和动物。（因此，渔民、磨房主、和养蜂人会献出牲祭安抚它。）它会将人拖下水在它的水下宫殿充当奴隶。

==关于bug（建议玩这个模组之前都要看看）==
这模组有一年多没更新了，不排除作者弃坑的可能，
新版本水怪有问题，但估计没办法修了

现在写几个解决方法：
水鬼刷新太多的问题，打开Deadly Monsters的配置文件，找到这条
# Precentage Topielec spawn chance, for example 25 means 25%. [range: 0 ~ 999, default: 25]     
I:topielecSawnChance=25
把 I:topielecSawnChance=后面的数字改小就行，数字代表生成的百分比  
数字必须是0~999之间的自然数

实在觉得难受，可以把这个怪生成关了，在配置文件找到这条
topielec {
# Set to true if you want to disable Topielec [default: false]
B:topielecDisabled=false
B:topielecDisabled=把后面的false改成true就可以禁止水怪生成

新版本闹鬼牛的生成有问题，写几个解决方法：
打开Deadly Monsters的配置文件，找到这条
# Haunted Cow spawn rate. Default for Zombie is 8.
[range: 0 ~ 999, default: 8]
    I:hauntedCowSawnRate=8
将I:hauntedCowSawnRate=8里的8改成1

或者，直接禁止牛生成
    # Set to true if you want to disable Haunted Cow
[default: false]
    B:hauntedCowDisabled=false
将B:hauntedCowDisabled=false中的false改成true

++物品++
==强化钢筋==
右键对着石头或者圆石使用，会将石头强化/圆石转换为强化钢筋石头/圆石，强化钢筋圆石/石头不会被突变史蒂夫破坏，如果不想辛苦挖黑曜石，这是便宜的对付突变史蒂夫地方法。
==拉粑丸==
吃下这个，你就可以消耗饱食度拉出一坨粑粑……（警告，饱食度不满会扣血）。
==粑粑==
如你所见，这是一坨粑粑。
它虽然很臭，但是有利于环境。如果你在粑粑的四个方向放置树苗，树苗会立即生长成成树。每催生一棵树，粑粑会消耗掉一点，一坨粑粑可以催生四棵树。要拉粑粑，你需要吃一颗拉粑丸。
==达贡之矛==（1.5更新）
投掷武器，可以投掷，投掷击中怪物后掉落在地上，
可以捡起来重复使用，伤害5（两格半）心，有击退效果
==日光降临==（1.7更新）
闹鬼牛的掉落物（几率极低），右键使用可以直接将夜晚转变为白天
==鱼镖==（1.7更新）
共有石、铁、钻石和黑曜石四种材料的鱼镖
当你在水中并且拿着鱼镖时，右键水源可以捕鱼，生鱼有几率掉落
是唯一可以杀死异形水鬼的近战武器
++方块++
==圣诞树==
会在其四周随机刷新出礼物盒，礼物盒效果类似幸运方块。鬼知道它能开出什么。（爆炸、怪物、各种物品等都有几率，礼物盒产生的爆炸不会影响圣诞树）
==混凝土==
可以染色。混凝土需要放置一段时间来干燥，在未干之前非常脆弱，任何实体触碰和在其上面放置物品等都会消失。但干燥后的爆炸抗性如同黑曜石，防爆。干燥的混凝土挖掘后不会有掉落物。
==围栏系统==
围栏柱
防爆，可以叠放，抗性很高
铁围栏
同样防爆，只能放置在围栏柱的四个方向，并只能向四个方向延伸8格距离
铁丝网
防爆，只能放置在围栏柱和铁围栏上，主要对付可以爬墙的怪物，实体碰到铁丝网时会受到很小的伤害并且被击退一段距离。
==灵魂之眼==
非常危险的设备，它有三个状态。分别是休眠；唤醒；苏醒
休眠状态
这个状态是无害的，在被光线照射一段时间后会变成这样。
唤醒状态
这个状态同样是无害的，但是它随时会完全苏醒，这意味着你应当尽快远离它。
苏醒状态
最危险的状态，所有眼睛全部打开，并且工作范围内会有黑烟状的粒子效果。在苏醒状态时，它会在随机的时间内（看脸，通常每个工作的间隔比较长，为1~3分钟）将工作范围内的生物全部杀死。杀死后生物不会掉落它本身的掉落物，而是每个生物随机掉落一个物品（如铁锭、红石、火药，掉落几率不高）。对玩家也有效果，所以应当远离。
工作范围为以其为中心半径为四的正方形。

这模组有一年多没更新了，不排除作者弃坑的可能，所以就算是bug估计也修不了了

刷新太多的话，打开配置文件，找到这条
# Precentage Topielec spawn chance, for example 25 means 25%. [range: 0 ~ 999, default: 25]
    I:topielecSawnChance=25
把 I:topielecSawnChance=后面的数字改小就行

实在觉得难受，把这个怪生成关了吧，在配置文件找到这条
topielec {
    # Set to true if you want to disable Topielec [default: false]
    B:topielecDisabled=false
B:topielecDisabled=把后面的false改成true就可以禁止水怪生成
