标题: ChestCommands菜单问题
ChestCommands菜单仍不掉，摧毁物品之后在菜单原来的位置会出现菜单。
作者: 水煮清娃    时间: 2018-8-9 18:36
因为绑定了菜单设置不能丢弃，你可以找到CustomJoinItems目录修改里面的 items.yml 配置。

  1.   #配置名称，不能重复.
  2. first-item:
  3.     id: 347
  4.     # 物品ID.
  5.     name: ' &3&n&l梦里幽境&6&l生存服'
  6.     # 物品显示名称.
  7.     data-value: 0
  8.     #data值，一般羊毛等物品会用到
  9.     cooldown-seconds: 1
  10.     # 使用冷却时间.
  11.     command: 'cd'
  12.     # 绑定在物品上指令
  13.     # 右键触发.
  14.     # 有一些特殊的前缀可以使用额外功能
  15.     # 'console: ' (通过控制台执行指令)
  16.     # 'op: ' (通过op执行指令)
  17.     # 'server: ' (<font><font>BungeeCord的服务器名称，切换服务器用的)</font></font>
  18.     # 'tell: ' (发送消息给玩家)
  19.     #
  20.     # 可以使用的标志有 %player% 和 %world%.
  21.     #
  22.     # 多个命令的书写形式: 'command; command2; command3'
  23.     lore:
  24.       - ' &7&l右键打开'
  25.       - ' &a&l不可丢弃'
  26.     # 物品描述.
  27.     block-movement: false
  28.     # 是否能移动物品.
  29.     slot: 1
  30.     #物品所在位置.
  31.     permission: ''
  32.     # 获得或者使用这个物品的权限，建议留空.
  33.     first-join-only: false
  34.     # 第一次加入时赠送一个物品
  35.     give-at-respawn: true
  36.     # 死亡重生后重新发送一个物品
  37.     allow-drop: false
  38.     # 是否允许扔掉.
  39.     give-on-world-change: false
  40.     # 世界改变的时候重新赠送物品.
  41.     disabled-worlds: ''
  42.     # 不能使用这个物品的世界，填写''取消限制.
复制代码
把  allow-drop: false  改成 allow-drop: true 就可以扔掉了
