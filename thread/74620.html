File（文件）：
1、New（新建） 新建一个文件，文件中包括：
  • java project JAVA项目，他代表着JAVA编译的开始
  • project 项目，但是现在还不用了解
  • package 包 包用来放设不同的类，避免类名冲突，但访问要先访问包再能访问类，相当于避免插口插错线的颜色（←  ←色盲消散）
  • class 类，他很难形容，他就像为了执行某个动作而存在的东西，你把他看成人的动作一样就行，为了做到想做的而执行
这几样是最常用的，也是开始需要的，其他的等以后慢慢了解到了再去了解
