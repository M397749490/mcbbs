MineChat支持iOS， WIndows Phone 以及 android，你可以用你的手机连接到您的Minecraft服务。使用MineChat，你可以聊天在服务器内聊天，如果你是服务器的管理，还可以向发送服务器指令例如：/ban，/kick等 。当你离开家或者你的电脑有问题时，你可以随时登录服务器，管理你的服务器，及时的处理服务器内的突发事件。
PS：MineChat分免费和付费版本（Lite是免费版本，功能有所限制）

注意：
  • MineChat不支持登录含有mod的服务器
  • 部分服务器可能禁止使用MineChat，使用前请确认您的服务器是否允许使用
  • MineChat不能移动您所在的位置（但可以用/warp /home），请确保你在游戏中处于安全位置。

ios：免费版 付费版

#最新版更新到 4.00

有人说不知道这什么用安卓版教程如下：
  • 安装完成后，打开程序，按 OK 进入设置


  2.设置菜单,在
  • 第一栏填写登录的用户名(需要正版登录请使用邮箱)
  • 第二栏填写登录的密码
  • Font是字体选择
  • Font Size是字号选择
  • Spawn on connect 是当你登录后会自动/spawn把你传送到出生点
  • Alert Sound 和 Alert Vibrate 可以设置提示效果
  • 填写完设置后记得按右上角的保存，千万不要忘记哦~


3.然后添加你想登录的服务器，点击 加 进去
填写好服务器信息，后保存

4. 返回服务器菜单登录你的服务器，就可以跟你基友聊天了，2333。
