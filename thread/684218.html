作者: 浅念哥    时间: 2017-4-2 21:41
有很多办法，我说一下：
清空一个玩家的背包 /eci 玩家
清空经验值 /xp set 玩家 0
如果你想从文件角度删除
打开服务端根目录usercache.json，搜索玩家名找到对应的uuid
请在关服时，打开世界文件夹下的playerdata文件夹，找到同名uuid.dat删除

清空经验值/exp set <玩家名> 0
