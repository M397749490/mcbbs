作者: 网络摆渡客    时间: 2014-12-2 09:04
使用notepad++打开地皮配置文件，作如下配置：
  1.     economy:
  2.       UseEconomy: true    #开启经济支持
  3.       CanPutOnSale: true    #是否允许出售
  4.       CanSellToBank: true    #是否允许卖给服务器
  5.       RefundClaimPriceOnReset: false
  6.       RefundClaimPriceOnSetOwner: false
  7.       ClaimPrice: 1000.0     #领取地皮的价格
  8.       ClearPrice: 2000.0      #清空地皮的价格
  9.       AddPlayerPrice: 100.0     #给地皮添加一个可信玩家的价格
  10.       DenyPlayerPrice: 100.0
  11.       RemovePlayerPrice: 0.0
  12.       UndenyPlayerPrice: 0.0
  13.       PlotHomePrice: 0.0
  14.       CanCustomizeSellPrice: true
  15.       SellToPlayerPrice: 10000.0
  16.       SellToBankPrice: 6000.0
  17.       BuyFromBankPrice: 10000.0
  18.       AddCommentPrice: 0.0
  19.       BiomeChangePrice: 0.0
  20.       ProtectPrice: 0.0
  21.       DisposePrice: 0.0
复制代码
上面没有全部注释，请比着葫芦画瓢。
