矿物插件

功能：

1.多倍稿子，lore判断

2.矿物记录，开服到现在

3.每日矿物记录

4.累计矿物记录。

5.每日第一名挖矿最多奖励
6.每日累计第一名矿物奖励
7.生存挖矿PVP掉落




自定义多项奖励
每日9点自动重置奖励领取
介绍：
插件放入服务端后。就可以开始使用了
1.多倍挖矿稿使用方式

手持稿子添加一行lore：&f灵魂之稿:3

这个时候挖矿的时候就会是3倍了

可以和附魔的时运叠加哟。



提示：

（颜色符号必须&f，且只能开头有）（某人有些懒）

（注意稿子必须有名称，lore设置的name）

（为了防止刷矿，挖到的煤，铁，不会给原矿。会自动熔炼）

（如果稿子附魔到了精准，则不会产生效果）



效果图：







这个时候挖矿就变成5倍了，5这个数字可以自定义



2.矿物记录

输入/ama open

即可打开排行页面

他会记录你今天的挖矿数量



也会记录今天挖矿最多的人




也会记录累计挖矿最多的人。最多显示18名。

（因为服务器就我一个挖过矿，所以就显示了我一个人）





如何设置每天累计第一奖励呢？

手持物品。

输入指令


/ama set 奖励ID 2

（奖励ID不能重复，否则多项奖励会被覆盖）

（2代表了是设置 每天 累计第一 奖励）

（每天累计第一奖励，就是你今天挖矿累计排名是不是第一。）

我的操作：


我手持了我特定某个rpg物品。

然后输入了指令

之后我们打开gui来看



只要今天早上9点之前都算昨天

昨天保持了第一。早上9点后，就可以领取。


如何设置每天挖矿第一名的奖励呢

注意这个是每天挖矿第一名

手持物品

输入指令

/ama set 物品ID 1

即可。

可以设置多个物品奖励





然后就是PVP功能了

服务器内，生存区，世界必须是world

被玩家打死后，你背包的矿物就会掉落



必须是玩家打死，世界必须是world

如果不是world，就不会。

如果你不想开启这个功能，你就不要用world世界
