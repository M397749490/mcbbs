标题: 关于“img”代码
请问“img”代码几级才可以使用？
谢谢
作者: 凛    时间: 2019-8-24 17:49
随着等级的增加，会员将会获得更高的权限。详情如下：
权限等级备注
允许发表站外链接
Lv1 +

允许上传附件或图片
Lv2 +

允许设置回复奖励
Lv3 +

允许评分
Lv4 +

允许签名中使用[img]代码Lv4 +
有[img]代码就能在签名中添加图片了
允许发起投票帖Lv7 +

允许转让道具Lv9 +
Lv0 - Lv8只能购买和使用道具
允许使用[hide]代码Lv7 +
即回复可见功能。注意只有部分版面允许回复可见使用。
允许签名中使用Discuz!代码Lv5 +
利用Discuz!代码可以实现文字移动，qq图标等功能
允许隐身Lv6 +他人无法查看到你的在线状态
允许在服务器板块发布服务器宣传贴Lv6 +服务器板块：http://www.mcbbs.net/forum-server-1.html
允许发匿名帖
Lv7 +

允许自定义头衔
Lv9 +

除此之外，在签名最大字数，每日上传附件总量，每日帖子评分总量等限制方面有数量上的差别，但一般而言感觉不出来，就不详细列出了。
