MiaoScriptPackageManager

喵式脚本包管理工具

新版本MiaoScript将在9月底发布 具体进展请加群 650545561

这是一个 MiaoScript 脚本插件 同时支持 Bukkit Sponge
本体插件传送门 => MiaoScript


安装教程

  • 当前版本已经内置此插件
使用教程(所有命令均支持自动补全 包括插件名称)
  • mpm list 查看当前 MiaoScriptPackageCenter 存在的插件列表
  • mpm install [插件名称] 安装插件
  • mpm update [插件名称] 更新插件(需要reload才能生效) (暂未实现)
  • mpm delete [插件名称] -[f|full] 删除插件(带上f或者full会同时删除插件目录)
  • mpm reload [插件名称] 重载插件
  • mpm upgrade [插件名称] 直接更新插件到当前环境 (暂未实现)
