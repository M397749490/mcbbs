肯定有问题。block state json 的用途是把每一个可能的方块状态组合对应到某一个具体的方块模型上去。你看一下原版小麦的 block state json 你就知道了。如果你是希望所有 AGE 的状态都是一个模型的话，可以试试这样写 block state json：

  1. {
  2.   "forge_marker": 1,
  3.   "default": {
  4.     "model": "ccc:block_crop"
  5.   },
  6.   "variants": {
  7.     "age": {
  8.       "0": {},
  9.       "1": {},
  10.       "2": {},
  11.       "3": {},
  12.       "4": {},
  13.       "5": {},
  14.       "6": {},
  15.       "7": {}
  16.     }
  17.   }
  18. }
复制代码


ModelLoader.setCustomModelResourceLocation 是给物品模型的，和方块无关。
90% 的方块模型不需要注册，只需要正确编写 block state json 即可。
（那些需要“注册”的模型都是重新实现的 IBakedModel，绝大多数时候你不需要这么复杂的东西……）

  1. // 订阅 ModelRegistryEvent 并调用下列代码
  2. // block 是你的那个方块的引用。
  3. // AGE 是你用的名为 AGE 的 IProperty 字段，换成你实际使用的那一个。
  4. BlockStateMapper.registerBlockStateMapper(block, new StateMap.Builder().ignore(AGE).build());
