这个插件非常水，非常非常水，但它是我原创的。

功能：
这个插件呢，就是禁言掉某个世界的所有玩家！
非常简单粗暴对不对
被禁言时尝试说话会提示红色的”你不能在此世界说话“
在小游戏服主城里用比较合适,也有"不充值就不让说话"之类的玩法

权限：
拥有ke.shutup.bypass的玩家可以不受此插件的影响

指令：
可能会有吗qwq

对于“这个插件为什么会这么水”的解释：
其实这个插件本应是我小游戏服自用的，但是MCBBS缺等级就拿出来了

萌萌哒求版主不删_(:з」∠)_

源代码:
public class Shutup
  extends JavaPlugin
  implements Listener
  {
  public void onEnable()
  {
    getServer().getPluginManager().registerEvents(this, this);
    for (World world : Bukkit.getWorlds()) {
      getConfig().addDefault(world.getName() + ".block", false);
    }
    getConfig().options().copyDefaults(true);
    saveConfig();
    Bukkit.getConsoleSender().sendMessage("[KE][Shutup]加载完成,插件作者:kilpikonna");
  }
  @EventHandler
  public void onPlayerChat(AsyncPlayerChatEvent e)
  {
    Player p = e.getPlayer();
    if (!(p.hasPermission("ke.shutup.bypass"))){
            if ((getConfig().getBoolean(p.getWorld().getName() + ".enable")))
            {   
                p.sendMessage(ChatColor.RED + "你不能在此世界说话");
                e.setCancelled(true);
            }
    }
  }
}
