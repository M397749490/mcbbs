OutdoorsPresent

野外宝箱插件，节假日时制作专属节假日宝箱吧

特点：
  • 一切可观信息均可自定义
  • 野外宝箱全息显示名
  • 每个宝箱独立的强大个性化自定义
  • 全可发送信息的地方均支持Title、ActionBar、公告、指令、OP指令、控制台指令、延迟、玩家信息、音效、全服音效，全服Title、全服ActionBar
  • 全可播放效果的地方均支持粒子效果，环境音效，烟花，延迟
  • 活生生的野外宝箱，需要使用武器攻击至死才可打开
  • 使用武器可自定义额外消耗的武器耐久量
  • 自定义出没世界，出没概率

使用截图：




指令：
/present create [ID] 在脚下位置生成一个宝箱
/present reload  重载配置文件
指令权限：
outdoorspresent.create  允许使用/present create 指令
outdoorspresent.reload  允许使用/present reload  指令

复制代码

发送信息
  settings.yml文件夹下的sends节点均支持一下格式信息
  lang.yml信息默认为一行，可根据需求更改为多行并配合一下格式信息
  变量：
   {player} 玩家ID
   {name} 宝箱显示名
玩家信息
  给玩家发送信息
  格式：
    message: 信息
  示例：
    sends:
      message: 宝箱被破坏

全服公告
  给全服玩家发送信息
  格式：
    broadcast: 信息
  示例：
    sends:
      broadcast: {player} 打开了 {name} 宝箱

执行指令
  让玩家执行一条指令
  格式：
    command: 指令
  示例：
    sends:
      command: spawn

执行一条OP指令
  让玩家执行一条OP指令
  格式：
    op: 指令

执行一条控制台指令
  让控制台执行一条指令
  格式：
    console: 指令

发送一个屏幕标题
  给玩家发送一个屏幕标题
  格式：
    title: 主标题,副标题,淡入时间,淡出时间
  给全服玩家发送一个屏幕标题
  格式：
    titleAll: 主标题,副标题,淡入时间,淡出时间

发送一个动作栏信息
  给玩家发送一个动作栏信息
  格式：
    actionBar: 信息
  给全服玩家发送一个动作栏信息
  格式：
    actionBarAll: 信息

发送一个音效
  给玩家发送一个音效
  格式：
    sound: 类型,音量,音高
  给全服玩家发送一个音效
  格式：
    soundAll: 类型,音量,音高

延迟
  执行发送信息的时候延迟
  格式：
    delay: 毫秒
  示例：
    message: 你将在1秒后收到一个屏幕信息
    delay: 1000
    title: 屏幕信息,你收到了一条消息,20,40,20
