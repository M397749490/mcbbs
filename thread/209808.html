普通玩家能破坏是因为Lz没有禁止领地内的建造权限...【后面的t  和  f   是..  我自己的标记..  无视掉..】

King  改为你自己的领地名....

  1. /res set King admin：领地的全权管理权限，仅能给与某玩家
  2. /res set King container true：是否能使用箱子，发射器等      t
  3. /res set King bucket false：设置是否能使用桶           f
  4. /res set King ignite false：点火的权限             f
  5. /res set King piston true：活塞是否能使用               t
  6. /res set King build true：建造权限（包括destroy和place）    t      
  7. /res set King destroy true：毁坏权限              t
  8. /res set King place true：放置权限             t
  9. /res set King move true：进入权限            t
  10. /res set King tp true：传送权限             t
  11. /res set King use true：使用权限（工作台，炉子等）     t
  12. /res set King subzone true：是否能设置子空间      t
  13. /res set King tnt false：设置tnt是否有效                 f
  14. /res set King creeper false：设置JJ怪是否有效（设置F的话JJ怪就废了）          f
  15. /res set King damage false：设置领地内是否能造成伤害（不能防止被挤死）          f
  16. /res set King monsters false：设置是否刷新怪物        f
  17. /res set King animals true：设置是否刷新动物         t
  18. /res set King firespread false：火是否能蔓延       f
  19. /res set King flow true：液体流动，包括waterflow和lavaflow    t
  20. /res set King waterflow：水的流动
  21. /res set King lavaflow：岩浆流动
  22. /res set King healing true：设置是否能恢复生命    t
  23. /res set King pvp false：设置是否能pvp     f
