 2013/5/4Anyone out there who knows any C, C++, GLSL, or the like, and has looked at my code (namely in composite.fsh and final.fsh) has probably laughed at how unorganized and difficult to change my code is. I started SEUS as a complete newbie at programming, and I just haven't taken the time to apply my new coding skills to my old code. Not only does my messy code mean unnecessary calculations, but it means that SEUS is very hard to change, which makes updating and bugfixing difficult for me.

I've decided to completely rewrite composite.fsh with the focus of keeping things organized, consistent, and easy to change. This should make updating and bugfixing a lot easier in the future. I'm also considering using a completely new version numbering system that will make a little more sense to people unfamiliar with SEUS.

As far as getting RC8 out, I'm probably just going to release a variant of k25, since this seems to be the most compatible release for everyone. This will be done within the next few days when I get the time.
