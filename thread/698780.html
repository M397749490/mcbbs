插件讲解
OpGuard是一个能够保护OP不被他人或者BUG所利用，并可以覆盖命令/OP和/deop覆/ opguard。    OpGuard提供了使用密码限制访问/ op（/ opguard op）的功能，对于保持没有密码的玩家不能操作。 如果恶意玩家以某种方例如:利用BUG获得OP,OP恶意给予他人OP， 当安装OpGuard时，不知道密码的管理将无法对其他玩家进行操作。    与其他“Anti-Forceop”插件相比，OpGuard是最具特色的，可配置的，安全的。 发行版用Java 8编译  如果您的服务器未运行Java 8，OpGuard将自动禁用自身他有什么特点呢他可以处理插件的信息几乎是可以配置的,他还有自带的反后门可以说很强大！他不只有这几个功能他的功能很多更多详细的请在汉化文本里查看！

指令讲解
命令：/ opguard  
别名：/ og  
用法：  
/ opguard op     
设置玩家的操作。   如果设置了OpGuard的密码，则必须包含该密码。   
/ opguard deop     从玩家移除操作。   如果设置了OpGuard的密码，则必须包含该密码。   
/ opguard列表   列出所有经过验证的管理。   
/ opguard密码<新密码>   设置OpGuard的密码。   这只有在OpGuard没有设置密码的情况下才有效。   
/ opguard reset <当前密码>   删除OpGuard的密码。   当前密码必须正确才能删除。   
/ opguard reload    重新加载OpGuard的配置。   如果设置了OpGuard的密码，则必须包含该密码
权限
opguard.warn
收到OpGuard的通知和警告 / opguard命令只能由经过验证的管理和后台访问
