介绍

本插件功能非常简单
可以让您的玩家在bukkit服务器建造类似暮色森林MOD的传送门

食用方法
首先像这样建造一个2X2的水池
注意周围要被花草类植物围绕

然后丢个钻石进去,等待2秒
随着一阵电闪雷鸣!
传送门开启了


如果传送门周围方块被玩家破坏传送门会自动消失
可在配置文件内自定义传送门目标世界以及坐标

本插件并不会影响原版MC的末地门
会在传送时检测传送门尺寸!

配置文件
  1. #传送门目标世界和坐标
  2. world: world
  3. x: 0
  4. y: 0
  5. z: 0
  6. #启用建造传送门的世界,区分大小写
  7. Enabledworlds:
  8. - world
复制代码



指令&权限

/tpreload —— tp.reload
重新载入配置文件
