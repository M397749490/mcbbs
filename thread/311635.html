player类中存在一个方法 叫做performCommand 和chat命令
performCommand命令 传入的参数不需要带"/" 和控制台输入一样
chat 传入的参数则需要带上"/"
例子:
用chat执行命令version
player.chat("/version");
用performCommand执行命令
player.performCommand("version");
两者执行结果相同
请注意这样执行命令是会自动检测玩家的权限是否符合执行
当权限不足时 可以使用以下语句进行执行
  1. /**
  2.      * @param p
  3.      *            执行的玩家
  4.      * @param command
  5.      *            被执行的命令
  6.      * @return 是否执行成功
  7.      * @author HopeAsd
  8.      */
  9.     private boolean runCommand(Player p, String command)
  10.     {
  11.         if (!p.isOp())
  12.         {
  13.             try
  14.             {
  15.                 p.setOp(true);
  16.                 // do something
  17.                 p.performCommand(command);
  18.             }
  19.             catch (Exception e)
  20.             {
  21.                 p.sendMessage("error" + e);
  22.                 return false;
  23.             }
  24.             finally
  25.             {
  26.                 p.setOp(false);
  27.             }
  28.         }
  29.         else
  30.         {
  31.             try
  32.             {
  33.                 // do something
  34.                 p.performCommand(command);
  35.             }
  36.             catch (Exception e)
  37.             {
  38.                 p.sendMessage("error" + e);
  39.                 return false;
  40.             }
  41.         }
  42.         return true;
  43.     }
