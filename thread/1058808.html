建议使用箱子和命令方块一起做。
https://minecraft-zh.gamepedia.com/原始JSON文本
https://minecraft-zh.gamepedia.com/箱子
https://minecraft-zh.gamepedia.com/命令/setblock
https://minecraft-zh.gamepedia.com/命令/replaceitem
https://minecraft-zh.gamepedia.com/命令/give
https://minecraft-zh.gamepedia.com/命令/clear

先摆一个箱子（用于自定义的交易）。在其任意面摆上一个循环命令方块，并连接3个连锁命令方块(注意命令方块的朝向和模式)。




循环命令方块里写：
  1. execute unless data block ~ ~1 ~ {Items:[{Slot:0b}]} run replaceitem block ~ ~1 ~ container.0 minecraft:potato{isRecipes:1b,display:{Lore:['{"text":"使用1 Money 交易。","color":"blue","italic":false}']}}
复制代码
从上往下数第1个连锁命令方块里写：
  1. clear @p minecraft:potato{isRecipes:1b}
复制代码
从上往下数第2个连锁命令方块里写：

  1. execute if entity @p[scores={Money=0..}] run scoreboard players remove @p Money 1
复制代码
从上往下数第3个连锁命令方块里写：

  1. give @p minecraft:potato
复制代码
然后就好了。部分命令根据交易的不同可以实现自由改动。

版本1.13+
比如说我在坐标为x y z的位置有个箱子
里面放着个tnt
那么按顺序高频执行以下命令：
  1. execute at x y z unless data block ~ ~ ~ Items[{id:"minecraft:tnt"}] run say tnt被取走了
  2. execute at x y z unless data block ~ ~ ~ Items[{id:"minecraft:tnt"}] run data modify block ~ ~ ~ Items append value {id:"minecraft:tnt",Count:1b}
复制代码

每当tnt被取走之后就会输出“tnt被取走了”
并且补充箱子内的tnt
需要编辑记分板只要把第一条命令后面的say替换成对应的scoreboard命令就可以了
当然要检测是哪个玩家拿走的其实有点麻烦
最偷懒的方法就是扣最近的玩家的Money了吧
把say tnt被取走了替换成
  1. scoreboard players remove @a[limit=1,sort=nearest] Money 1
复制代码

而不是用箱子做界面

没有命令基础就很难讲，况且问的还是一整个系统。

=======

牌子命令，牌子记录执行的命令，右键执行。其中命令应记录卖家，标记买家，单次交易所需的金币，和交易的处理等。
玩家右键则自动识别是买家还是卖家。
买家，则判断金币是否充足，是则走一遍处理，否则返回一个温馨提示。
卖家，你也没要求如何补货和提现我就不说了

=======

execute store ... data get ... Count 获取箱子内某槽位物品的数量并记录到记分板。
记分板内分数减1并写回到箱子槽内的某物品数量，实现箱子内物品数量减一。

在玩家位置生成一个数量为1的掉落物，data modify修改此物品的id和tag等同于箱子内物品的id和tag。（当然顺序应该是先生成掉落物继承id和tag如有需要的话修改数量，然后才是修改箱子内物品的数量甚至是清除箱子内的该物品）
