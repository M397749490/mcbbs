简单防熊 v1.0

采用钓鱼执法的方式对盗窃和纵火进行抓捕和记录

作者：MineCrocodile


核心探测原理：
1. 持有指定的诱饵物品超过一段时间
2. 在指定的范围内纵火

主要函数文件：
  1. # 给指定创造模式玩家16个诱饵钻石，用来手动放置，把MineCrocodile修改为自己的ID
  2. execute as @p[name=MineCrocodile,gamemode=creative,nbt=!{Inventory:[{id:"minecraft:diamond",tag:{HideFlags:1}}]}] run give @s minecraft:diamond{HideFlags:1} 16

  4. execute as @a[gamemode=!creative,nbt={Inventory:[{id:"minecraft:diamond",tag:{HideFlags:1}}]}] run scoreboard players add @s xhz_score 1

  6. # 发布公告
  7. execute if entity @a[scores={xhz_score=600}] run say 出生点抓住疑似熊孩子一人
  8. execute if entity @a[scores={xhz_score=600}] as @a[scores={xhz_score=600}] run say 嫌疑人就是我，快来出生点看我
  9. execute if entity @a[scores={xhz_score=600}] as @a[scores={xhz_score=600}] run say 在线玩家请输入 [抓熊] @s 方便管理搜索记录 谢谢！

  11. # 诱饵生成处，每次抓捕后自动补货 "14 56 5" 可修改为箱子坐标
  12. execute if entity @a[scores={xhz_score=600}] run data modify block 14 56 5 Items append value {Slot:6,id:diamond,Count:12b,tag:{HideFlags:1}}


  15. # 于书中记录熊孩子ID
  16. # 14 57 14为记录用箱子坐标，可根据情况修改
  17. # 13 57 14为记录用牌子坐标，可根据情况修改
  18. execute if entity @a[scores={xhz_score=600}] run data modify block 14 57 14 Items append value {Slot:0,id:written_book,Count:1b,tag:{pages:["["",{"text":" "}]"],title:BearKidsList,author:IMYVM}}
  19. execute if entity @a[scores={xhz_score=600}] run setblock 13 57 14 air
  20. execute if entity @a[scores={xhz_score=600}] run setblock 13 57 14 minecraft:oak_wall_sign[facing=west]{Text1:"[{"selector":"@a[scores={xhz_score=600}]","color":"red"}]"} replace
  21. execute if entity @a[scores={xhz_score=600}] run data modify block 14 57 14 Items[0].tag.pages[0] set from block 13 57 14 Text1
  22. execute if entity @a[scores={xhz_score=600}] run setblock 14 58 14 redstone_block replace
  23. execute if entity @a[scores={xhz_score=600}] run setblock 14 58 14 air

  25. # 处理熊孩子 持续tp，修改模式为冒险，清除背包内钻石和打火机
  26. execute if entity @a[scores={xhz_score=600}] run tag @a[scores={xhz_score=600}] add xhz
  27. execute if entity @a[tag=xhz] as @a[tag=xhz] run tp @s 8 56 8
  28. execute if entity @a[tag=xhz] as @a[tag=xhz] run gamemode adventure @s
  29. execute if entity @a[tag=xhz] as @a[tag=xhz] run clear @s minecraft:diamond{HideFlags:1}
  30. execute if entity @a[tag=xhz] as @a[tag=xhz] run clear @s minecraft:flint_and_steel{HideFlags:1}
  31. execute if entity @a[tag=xhz] as @a[tag=xhz] run scoreboard players reset @s xhz_score

  33. # 检测纵火，坐标为要检测有无纵火的范围，建议设置为封闭区域如木质房子等
  34. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4] run scoreboard players add @s xhz_timer 1
  35. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=61..}] run scoreboard players reset @s xhz_timer

  37. # 重置已离开检测区域的玩家计时器，distance后数字需根据房子大小调整
  38. execute positioned 13 56 7 run scoreboard players reset @a[distance=10..] xhz_timer

  40. # 于房间内纵火检测
  41. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=1}] run scoreboard players reset @s xhz_setfire_1s
  42. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=1}] run scoreboard players reset @s xhz_setfire_3s
  43. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=1}] run scoreboard players reset @s xhz_setfire

  45. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=2}] run scoreboard players operation @s xhz_setfire_1s = @s xhz_setfire
  46. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=59}] run scoreboard players operation @s xhz_setfire_3s = @s xhz_setfire
  47. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=60}] run scoreboard players operation @s xhz_setfire_test = @s xhz_setfire_3s
  48. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_timer=60}] run scoreboard players operation @s xhz_setfire_test -= @s xhz_setfire_1s

  50. # 定义纵火犯
  51. execute as @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_setfire_test=1..}] run scoreboard players set @s xhz_score 600


  54. # 诱饵打火机，每次抓捕后自动补货，"16 57 8"为箱子坐标
  55. execute if entity @a[x=13,y=56,z=7,dx=4,dy=4,dz=4,scores={xhz_setfire_test=1..}] run data modify block 16 57 8 Items append value {Slot:0,id:flint_and_steel,Count:1b,tag:{Damage:58,HideFlags:1}}

  57. execute as @a[scores={xhz_setfire_test=1..}] run scoreboard players reset @s xhz_setfire_test
复制代码

解释：
目前各类保护插件已经能将熊孩子们的破坏降到最低，回档方便，但是往往已经造成了一定的损失才能被发现，有些损失可能永远不会被发现，如果能在早期就对潜在的熊孩子进行识别，能显著提高其他玩家的体验。
本数据包采用钓鱼执法的方式，对触发数据包条件的玩家进行抓捕、公告和记录，实用性好，已在自己的服务器里抓到数名小熊孩子，提前中止了进一步熊孩行为
