作者: pineapple_    时间: 2018-2-8 09:39
版本是什么，
计时也有很多歧义的，
是当mc中的钟(比如现在是17:05之类的)
还是当做秒表(比如从干了什么开始已经过了1分25秒)
还是正常的计时器(比如已经开始计时15分钟了该给玩家一个钻石了)

这三个看似类似，但是目的不同，第一个是用于判断mc的时间，比如是不是快要黑天了什么的，
第二个的目的是得到"1分25秒"这个结果，而第三个是得到给玩家一个钻石的结果，所以是有区别的

拿1.9以上举例，第一种的理想的实现方式一定要在1.9以上，
需要命令/time query daytime
配合stats，把得到的值输出到记分板，而通过记分板的分数来计算出当前mc中24小时制的时刻。如果是1.8，只能高频给记分板加分，先time set 0和scoreboard players set x xx 0，1?20秒=mc时间3.6s，这就慢慢换算吧

第二种实现方法很多，常用的就是记分板加分，记分板的分数可以用实体，也可以用假名，用实体用execute @e[score_xx_min=20] 来代表1s过去了，假名需要用scoreboard players test +condition模式的(制约模式)来检测1s。
第三种和第二个差不多，不过不需要一秒一秒加，而是一直加1分，直到触发事件，比如5秒触发，就直接加分到100，用execute或者scoreboard players test来实现事件(比如给玩家一个钻石)

上面都是简单介绍了一下，哪个还不明白需要具体命令的就回复

mc一天的时间可以用计分板来达到
如果是游戏的一天：
  1. /scoreboard objectives add time dummy 时间
复制代码

在出生点的区块生成一个拿来做炮灰的蝙蝠
  1. /summon minecraft:bat ~ ~1 ~ {ActiveEffects:[{Id:14,Amplifier:0,Duration:999999,ShowParticles:0b}],Invulnerable:1b,IsBaby:1b,Age:-2147483648,IsBaby:1b,Silent:1b,NoAI:1b,NoGravity:1b,Tags:["timer"]}
复制代码

每gametick不断对蝙蝠的time分数加一，达到计时器效果（20gametick为1s）,用循环命令方块自动激活高频执行此指令
/scoreboard players add @e[type=Bat,tag=Timer] time 1
然后每天早上重置
阳光传感器下面放普通cb，里面写
  1. /scoreboard players set @e[type=Bat,tag=Timer] time 0
