这是一款先进的聊天插件；可以帮助玩家进行更加优化的私聊等帮助
是时候放弃邮箱系统。它让玩家可以查看未读消息。

这个插件不支持Java 7。请更新您的Java版本为Java8 。


  • 可以有多个服务器(不是Minecraft服务器)代表一个话题,派系,团队等等。
  • 可以联系多个服务器（BC）
  • 每个玩家将会有一个独立的形象
  • 丰富的API为开发人员构建Minecord的扩展插件。
数据库：

[size=14.6667px]这个插件要求数据库来存储数据；[size=14.6667px]测试,建议使用MySQL

[size=14.6667px]确保你使用了正确的配置方式 详细可以参考下面的配置文件

[size=14.6667px]不建议私自修改配置文件 Mincord会生成一份mysql的配置表

配置文件：

[size=14.6667px]代码(文本):
例如#占位符# #的占位符
主机= # host-of-database #
用户名= #用户名#
密码= #密码#
格式= # #格式
message-load-count = # message-load-count(弃用)#

[size=14.6667px]主机使用的URL连接到数据库。[size=14.6667px]它可能包含或不包含一个端口。默认的IP[size=14.6667px]是localhost:3306。

[size=14.6667px]用户名是一个帐户的用户名在数据库系统。[size=14.6667px]推荐使用root帐号,因为你可能会撤销权限,Minecord需要其他账户。


[size=14.6667px]如何显示一名玩家发送的消息：

[size=14.6667px]消息负载系统只会处理玩家的部分聊天数据
[size=14.6667px]这个选项是现在弃用由于Minecord会加载用户的<未读消息>。

命令：
  • info:显示Minecord版本。
  • reload <配置数据库db | | |零(全部)>——重新加载数据。
  • [size=14.6667px]server <名称>——
  • [size=14.6667px]servers < desc |零> <依据(真|假)|零> <邀请(真|假)|零> <永久(真|假)|零> <成员名>——寻找一个服务器一个过滤器和显示它的信息。
  • [size=14.6667px]channel <服务器名称> <名称>——显示一个通道信息根据提供的服务器和通道名称。
  • [size=14.6667px]channels <服务器名称> < desc |零> <主要(真|假)|零> <成员名>——寻找一个通道在一个服务器一个过滤器和显示的信息。
  • gui——目前禁用
  • join <服务器名称> <通道名称|零>——加入一个服务器。
  • [size=14.6667px]leave,离开你当前的服务器。默认的服务器并没有离开。
  • [size=14.6667px]profile <用户名>,查看用户的配置文件参数字符串作为名称。
  • create <名称> < desc |零> <依据(真|假)|零> <邀请(真|假)|零>——创建一个服务器
  • editserver < server >——使用GUI配置服务器 弃用
  • [size=14.6667px]select <服务器|通道>——选择一个服务器或一个通道配置命令
  • [size=14.6667px]deselect ,删除上面的做选择
  • set > <属性——配置属性的选择
  • setview < server > <频道>——集你想看信息在你的聊天频道
  • 这些指令都是基于Minecord的
