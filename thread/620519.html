安装了匠魂强化mod，并修改了配置文件
http://www.mcbbs.net/thread-425981-1-1.html
在.minecraft/config/IguanaTinkerTweaks/main.cfg文件中找到
  1. #  [range: 1 ~ 99, default: 6]
  2.     I:maxToolLevel=6
复制代码


把=后面的6改成其他数字即可（建议11）

然而这样高的等级也只是然并卵
需要在配置文件继续修改
  1. toolleveling {
  2.     # Adds a random bonus on these levelups if 'RandomBonuses' is enabled
  3.     I:BonusesAtLevels <
  4.         2
  5.         3
  6.         4
  7.         5
  8.      >
复制代码

这里是修改工具升到第几级会有随机属性（笨拙是1级，以此类推）
  1. # Adds an extra modifier on these levelups if 'ExtraModifiers' is enabled
  2.     I:ModifiersAtLevels <
  3.         2
  4.         4
  5.         6
  6.      >
复制代码

这里是修改工具到第几级有更多的强化槽
