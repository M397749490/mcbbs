LobbyNK

插 件 简 介
LobbyNK是一款基于Nukkit的完善的大厅系统，它独揽一系列零散的功能，将他们结合在一起，很适合游戏服！

命 令 权 限
命令：
/lobby set（loc1-loc8）
/lobby set spawn - 将出生点
/spawn - 传送到出生点
/build [player] - 启用/禁用buildmode [为另一个玩家]
权限：
lobbynk .build.own - 允许玩家自己使用/build。
lobbynk.build.other - 允许玩家使用/build [玩家]
lobbynk.build
lobbynk.lobby.set - 允许玩家设置大厅
lobbynk.transfer - 允许跨服
lobbynk.doublejump - 启用二连跳
行走粒子
lobbynk.effect.angry
lobbynk.effect.bonemeal
lobbynk.effect.bubble
lobbynk.effect.explode
lobbynk.effect.heart
lobbynk.effect.flame
lobbynk.effect.redstone
lobbynk .effect.ink
lobbynk.effect.enchant
lobbynk.effect.remove（删除效果）
聊天 ( 对应的尾缀对应格式 可在chat.yml中修改 )

lobbynk.admin
lobbynk.moderator
lobbynk.builder
lobbynk.supporter
lobbynk.youtuber
lobbynk.premium

  18. CompassImages: true
