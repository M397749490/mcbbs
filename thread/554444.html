作者: 爱心魔王FHC    时间: 2016-2-10 19:30
为什么要用红石高频
用命令方块高频是不会卡的
1.8：/summon FallingSand ~ ~0.5 ~ {Tile:152}
1.7：/summon FallingSand ~ ~1 ~ {Tile:152}

在命令方块里输完指令后在命令方块上面放上红石块高频就开始了
如果出现一堆提示
输入/gamerule commandBlockOutput false

建议你可以把这个藏在地底下，没人会去挖吧

作者: lzs1234    时间: 2016-2-10 20:14
清除点燃的TNT：
/kill @e[type=PrimedTnt]
前面说的效果：
/scoreboard objectives add TNT dummy
/scoreboard players add @a TNT 0
高频：
/scoreboard players set @a TNT 1 {SelectedItem:{id:tnt}}
/clear @a[score_TNT_min=1] minecraft:tnt
/kill @a[score_TNT_min=1]
完事（高频第一个指令不知道是否能用，没试过）
