Full Server Tick是指

  1. Full Server Tick is the best representation of your servers performance, in the Pct Tick Column. If this value hits 100%, then your server is unable to keep up and will begin losing TPS. There is no magical solution to improving Full Server Tick, it is merely provided to see a better summary of your overall server performance and you can improve it by improving other timings on your server such as entities and plugins.
