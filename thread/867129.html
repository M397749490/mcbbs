彩色聊天需要安装ESS附属插件essentials-chat
安装之后再ess内config.yml里修改  [路径：plugins\Essentials]
  1. chat:
  2.   radius: 0
  3.   # 是否设置为默认聊天格式，需要与chat插件兼容。
  4.   format: '&f{DISPLAYNAME}&7:&f {MESSAGE}'
复制代码

彩色前缀需要安装ESS附属插件EssentialsGroupManager
安装之后在groups.yml里修改  [路径：plugins\Groupmanager]
  1. prefix: '&e' #
  2. 前缀，若将引号中的内容改为“&c[VIP]&2”，该组所有玩家名则会显示为：[VIP]绿名，输入“/list”查看在线人数时就可以看到。颜色设置在这里看
