（简介）

WatchCat是一个全面的反作弊插件。 它可以阻止大部分比较流行的作弊。 它具有和先进的算法，可以快速地检测每个作弊者。

（功能）

以下作弊已证实是可检测的:

战斗:
  • KillAura - 杀戮光环
  • MultiAura - 杀戮光环
  • Criticals - 自动暴击
移动:
  • IrregularMovement - 不合理的移动
    - Fly - 飞行
    - Speed - 加速
    - Clip - 穿墙
    - Velocity - 速度
  • Glide (IrregularMovement) - 滑翔
  • LongJump (IrregularMovement) - 跳远
  • LiquidWalk - 水上行走
  • HighJump (IrregularMovement) - 跳高
  • Step (IrregularMovement) - 快速走上方块
  • Teleport (IrregularMovement) - 传送
  • InventoryMove - 点击背包时行走
玩家:
  • NoFall - 取消摔落伤害
  • MorePackets - 非法数据包
    - Timer - 变速器
    - KeepAliveFrequency - 刷心跳包有什么用
  • FastBreak - 快速挖方块
  • Freecam - 灵魂出窍（屏幕不会抖！！！）
追踪:
  • PlayerESP - 玩家透视
  • ChestESP - 箱子透视

请注意，其他类似的作弊也是可检测的。

（指令）

/watchcat - 显示插件信息
/watchcat notification <messages> - 给管理员发送信息
/watchcat kick <player> <message> - 踢出一个玩家
/wc ban <player> <message> - 封禁一个玩家
/wc unban <player> - 解封玩家

/watchcat 可以使用 /wc 代替


（权限）

watchcat.commands.kick - 使用 /wc kick 的权限
watchcat.commands.reload - 使用 /wc reload 的权限
watchcat.commands.notification - 使用 /wc notification 的权限
watchcat.commands.ban - 使用 /wc ban 的权限
watchcat.commands.unban - 使用 /wc unban 的权限
watchcat.notification - 收到通知的权限


（前置）

兼容的服务器版本: 1.8.x, 1.9.x, 1.10.x, 1.11.x, 1.12.x, 1.13
请安装ProtocolLib


（兼容性）

WatchCat支持:
  • ViaVersion
  • ProtocolSupport


WatchCat可能不支持:
  • 任何修改玩家攻击/移动的插件
  • PerWorldPlugins插件
