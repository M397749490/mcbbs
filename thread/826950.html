每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。
Minecraft 1.14 仍未发布，18w44a 为其第 4 个预览版。
转载本贴时须要注明原作者以及本帖地址。
A Village & Pillage Java Snapshot
一个村庄与掠夺更新的JAVA版快照
It's a very spooky day today, zombies everywhere, bats flapping around... It must be october 31st, Halloween! Man, can you imagine if it were also friday the 13th? That'd be truly scary.

Here at Mojang, we celebrate halloween in style: with snapshots! And this weeks snapshot is another doozy! New cats! New blocks! Lots of new blocks!

Keeping in the spooky theme of the day, though, we've not added any new functionality to the new blocks contained within this snapshot. How fiendish of the developers! What could they possibly be for? We may never find out... At least not today.

今天是一个非常诡异的日子，到处都是僵尸，蝙蝠到处扑腾......今天是10月31日，Halloween（注：Halloween不是万圣节）！小伙子，你能否想象他同时也是第13个星期五？ 这太可怕了。
在Mojang，我们以这样的风格庆祝Halloween——快照！ 而这周的快照是非常出色的！新的猫！新的方块！还有很多新的方块！

但是，保持现在的怪异主题，我们没有为这个快照中包含的新方块添加任何新功能。 开发者太可恶了！ 他们的（功能）可能是什么？ 我们可能永远都找不到......至少今天不行。

更改内容：
  • Split cats and ocelots to their own creatures and updated cats with new features!
  • 将猫与豹猫分开为两种生物，并更新了猫的新特性
  • Added lots of new blocks!
  • 增加了一堆新方块
  • You can now right click on signs with dyes to change the text color
  • 你现在可以用染料右键告示牌以更改文字颜色（From Minecraft Wiki:字体的默认颜色更改回黑色。)
  • Lots of performance improvements, especially to client stuttering!
  • 很多性能的改进，尤其是客户端的卡顿
  • Added "Programmer Art" in the resource pack menu: it's the old textures, easy to use!
  • 在“资源包”菜单中添加 “Programmer Art”——他是旧的材质，更容易使用
    @kakafou12 :Programmer Art指那些没有jappa之前notch, jeb, 晚餐骨头自己硬刚的材质

猫与豹猫：
  • Stray cats can be tamed
  • 流浪猫可以被驯服
  • Tamed cats can give lovely (or less lovely) morning gifts to their owners
  • 被驯养的猫会在每天早晨给主人一些可爱的（或者不那么可爱的）礼物
  • Ocelots can't be tamed, but they might start trusting you if you feed them with fish
  • 豹猫不能被驯服，但是如果你用鱼(From Minecraft Wiki:鲑鱼或鳕鱼)喂它，他可能会信任你
  • Phantoms are terribly scared of cats - how convenient!
  • 幻翼现在会害怕猫——这多方便啊！
  • Cat collars can now be dyed
  • 猫的项圈现在可以被染色了
  • Added several new cat skins!
  • 给猫增加了新的皮肤

新方块：
Even more! Can you believe it?!

All of these blocks currently have no functionality and are only available in the creative inventory. This will change really soon, we just wanted to get the actual blocks themselves out there as soon as we could! They might also change visually, too!

甚至还会有更多（新方块）！你相信吗？！

这些新方块目前没有任何作用，你只能在创造模式的物品栏中找到他们。他们可能会很快改变（添加实际功能），我们只是想尽快把新方块带进游戏中。他们的材质仍然可能会发生变动！

新快照中的技术变革：
  • Players, armor stands and wither now have loot tables
  • 玩家、盔甲架和凋灵现在有战利品表了
  • Changed NBT chat components
  • 更改了 NBT chat components
  • Removed award part of /drop command (loot now does the same thing)
  • 删除 /drop 命令的奖励部分（战利品现在做同样的事情）

NBT CHAT COMPONENT：
  • Block variant {"nbt": <path>, "block":"<coordinates>"}, where <coordinates> field uses same format as /setblock
  • 方块变量 {"nbt": <path>, "block":"<coordinates>"}, 其中 <coordinates> 字段使用与 /setblock 相同的格式
  • Entity variant {"nbt": <path>, "entity":<selector>}, where selector field uses same format as /kill
  • 实体变量 {"nbt": <path>, "entity":<selector>}, 其中 selector 字段使用与 /kill 相同的格式
  • Additionaly, if field interpret is present and set to true, contents of selected tags will be interpreted as chat components
  • 另外，如果存在字段 interpret 并设置为true，则所选标签的内容将被解释为chat components
  • Works same as selector components:
  • 与选择器组件相同的工作：
    • if there are no elements, returns empty string
    • 如果没有元素，返回空字符串
    • if there are multiple elements, merges them with ,
    • 使用 , 分割多个元素

战利品表（LOOT TABLES）：
  • New loot table functions: set_lore, fill_player_head
  • 新的战利品表函数：set_lore, fill_player_head
  • Removed loot table condition: entity_present
  • 删除了战利品表条件：entity_present
  • New loot table conditions: damage_source_properties, location_check, weather_check and two special modifiers: inverted and alternative
  • 新的战利品表条件：damage_source_properties，location_check，weather_check 和两个特殊修饰符：inverted和alternative

修改的条件（MODIFIED CONDITIONS）
ENTITY_PROPERTIES
Now uses same predicate syntax as advancements (like player_killed_entity). 现在使用与进度（advancements）相同的谓词语法，比如player_killed_entity。Parameters are now described in apredicte field. 现在在apredicte字段中描述参数。Now uses same predicate syntax as advancements (like player_killed_entity). 现在使用与进度（advancements）相同的谓词语法，比如player_killed_entity。Parameters are now described in apredicte field. 现在在apredicte字段中描述参数。 If this field is empty object, any entity is accepted (but still has to be present).如果此字段为空对象，则接受任何实体（但该实体必须存在）。

修改的函数（MODIFIED FUNCTIONS）
SET_NAME
Added new parameter entity (same values as entity_present condition). If present, name will be resolved with that entity (allows using selector and score components).添加新的参数entity（与entity_present具有相同的值）。如果存在，将使用该实体解析名称（允许使用选择器和score components）。

新函数NEW FUNCTIONS
FILL_PLAYER_HEAD
Copies player profile info to player head item.将玩家资料信息复制到玩家头颅（物品）。

参数Parameters
  • entity - source of profile (same values as entity_presentcondition, will do nothing if it's not player).来源于profile（与entity_presentcondition具有相同的值）
SET_LORE
Adds or replaces lore lines.新增或替换lore

参数Parameters
  • lore - list of lines (in chat component format) to be added.要加入的所有行（按照chat components格式）
  • replace - if true, previous lore is erased.如果为true，则原有的lore会被删除
  • entity - if present, name will be resolved with selected entity (same values as entity_present condition).如果存在，将使用该实体解析名称（允许使用选择器和score components）。

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要魔法上网。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
