如果你在使用 Windows，那么推荐你使用 Pixelmon 启动器。下面的大多数教程针对 Minecraft 官方启动器。
这是一个安装 Pixelmon 的教程，覆盖了客户端部分的安装说明，这样你就可以加入单人游戏，或是加入已经存在的 Pixelmon 服务器。如果你需要将 Pixelmon 安装到服务器，那么请查看服务器安装部分。（见2楼）
这篇教程建立在你已经购买并安装了 Minecraft 的前提，如果你还没有安装 Minecraft，那么请先安装。
安装需求
  • 一份电脑版 Minecraft
    • 只有电脑（Java 版）Minecraft 可以运行 Pixelmon，携带版（包括 Windows 10 Edition）和主机版（Xbox，WiiU，Switch）都不能运行
  • 2 GB 可用内存
  • 64 位 Java 8
注意
  • 如果 Minecraft 正在运行，那么请退出
  • 确定你有 2 GB 可用内存，注意这将必须使用 64 位的 Java，如果你不知道如何分配内存，请看3楼（原文）。
  • 确保你使用的是付费的 Minecraft 而不是破解的 Minecraft，否则你的 Pixelmon 在退出时不会被保存，这将不会修复。
  • 不要使用 Technic 启动器安装 Pixelmon。如果你这样做，你将不会获得初始精灵宝可梦（原文），也不能使用 Pixelmon 的特性，不兼容的情况将不会修复，请使用 Minecraft 启动器或 Pixelmon 启动器。
  • Pixelmon jar 文件是全局的，你可以在服务器和客户端同时使用。
  • 如果你使用了其他的 Mod，请查看不兼容列表（原文）确保避免不兼容的情况发生。
版本
Pixelmon 兼容很多的 Minecraft 版本，在下方的表格中详细的列出了。每个不同的 Minecraft 版本都需要不同的 Pixelmon 版本运行。注意现在只有 Minecraft 1.10.2 版本的 Pixelmon 接受更新，更早的版本将不会继续更新或是修复 BUG。

The Forge installer

Forge 安装
  • 找到推荐的 Forge 版本并安装（files.minecraftforge.net）。根据你的电脑选择下载 Installer-win （Windows）或 Installer（Mac OS/Linux）。
  • 下载的文件是一个自动安装器，只需运行并选择 client。（国内可用启动器自动下载）
  • 当 Forge 安装完成后，打开 Minecraft 启动器。
  • 选择 "Launch Options" 菜单。
  • 编辑已有存档或创建新的存档。
  • 找到下拉菜单里的你安装的 Forg版本，选择。
  • 保存
  • 启动 Minecraft
  • 关闭 Minecraft，你不能开着 Minexraft 安装 Pixelmon
Pixelmon 安装

Minecraft 启动器，重要的选项和按钮使用蓝色加粗
  • 检查你下载的 jar 文件的大小是否在 380 MB 左右，如果明显较小，那么下载一定是出错了，你可能需要重新下载
  • 打开 Minecraft 启动器
  • 编辑安装了 Forge 的版本
  • 打开游戏目录
    • 你可以使用资源管理器打开游戏目录，就是有点难找。
  • 找到或创建 “mods”文件夹
  • 将下载的 Pixelmon 文件放入
    • 不要解压文件 ，完整的放进去
  • 保存
  • 启动 Minecraft ，在主菜单找到 Mods 选项，你应该在里面看到了 Pixelmon。
故障排除
  • 如果你按照了说明，但是 Minecraft 崩溃了，那么请看看这篇崩溃指南
  • 如果 Minecraft 一直加载或是非常卡顿，那么你需要分配更多内存，如果你不知道怎样做，请看3楼
  • 如果你还是有问题，或是 Minecraft 不断崩溃，或是 FAQ 不包含你的疑问，那么请在帮助中心提问

修复内存问题
安装 Pixelmon 过程中最常见的问题就是系统内存用尽了。Pixelmon 有大量的资源，比如模型，材质，还有音乐，这些相比于原版 Minecraft 来说都需要更多的内存。大多数的 Mod 都需要更多的内存，如果没有达到，则可能造成 Minecraft 停顿或崩溃。
确定原因
并不是Minecraft出错都是因为内存问题，你必须先确认是内存引起的问题。
崩溃
Minecraft崩溃报告的一部分，高亮的区域说明内存耗尽.

如果Minecraft尝试启动时崩溃了，那么这可能是内存问题。你需要查看崩溃报告以确认是内存问题。在 “Description”后的第一排即是原因，看看是不是以下原因：
  • "java.lang.OutOfMemoryError: Java heap space"
  • "net.minecraftforge.fml.common.LoaderException: java.lang.OutOfMemoryError: Java heap space"
  • "net.minecraftforge.fml.common.LoaderException: java.lang.NoClassDefFoundError: com/pixelmonmod/pixelmon/..."
  • "SplashProgress has detected a error loading Minecraft."
  • "Caused by: java.lang.IllegalAccessError: tried to access field net.minecraft.client.renderer.entity.RenderManager.field_178636_l from class com.pixelmonmod.pixelmon.client.ClientProxy"
  • "at net.minecraft.world.World.getSkyColorBody(World.java:1477)"
如果崩溃报告以任何以上开头，那么即是内存原因。
冻结
  • 如果 Minecraft 在启动界面冻结了，那么很可能是内存耗尽。Forge 加载材质和模型时("Reloading — ModelManager") 常常会造成内存耗尽。
  • 如果游戏时 Minecraft 严重的卡顿，那么很可能是没有足够的内存流畅运行。
Pixelmon 启动器
如果分配的内存少于 2 GB，Pixelmon 启动器将不会启动 Minecraft。虽然这可以防止大部分内存问题，但还是可能有一些问题发生。
  • 如果你已经分配了 2GB 内存，但是 Minecraft 仍然崩溃或冻结，请查看 这篇文章
  • 如果 Pixelmon 启动器不允许你分配超过 1200 MB 的内存，请查看 这篇文章
分配更多内存
JVM参数 "-Xmx2G" 为下划线标注

修复内存问题，必须先分配更多内存
Minecraft 启动器
  • 选择 "Launch options"，保证开启了 "Advanced settings"
  • 选择 Pixelmon 的 Profile
  • 找到 "JVM Arguments" ，找到 "-Xmx"。将后边的更改为 "-Xmx2G"
  • 开启 Minecraft，如果没有问题，那么你分配了足够的内存










Pixelmon 启动器
Pixelmon 启动器设置

  • 在主界面找到右上方的齿轮按钮，打开
  • 找到 "Maximum memory (MB)", 添加到至少 2G.
    • 如果不允许分配超过 1200 MB 的内存，请查看 这篇文章

服务器
  • 找到用于启动你的服务器的命令。这决定于你如何启动，可能在一个可运行文件里 (比如 ".bat" 或 ".command" 文件), 或者直接在控制台输入
  • 找到 "-Xmx". 在这之后代表你使用的内存数（ "-Xmx1G" 或 "-Xmx512M"）. 将其更改为 "-Xmx2G".
    • 如果你没有找到 “-Xmx”类似的文字，那么直接添加
    java -Xmx2G -jar minecraft_server.jar nogui
  • 开启服务器
其他问题
如果更改 JVM 参数后服务器没有正常启动，那么很可能是以下原因
32 位的 Java
如果你在使用 Windows，那么你可能使用了 32位的Java，这将不允许分配足够的内存运行 Pixelmon。如果你使用了32位的Java，那么会出现以下信息：
Error occurred during initialization of VMJava HotSpot(TM) Client VM warning: ignoring option MaxPermSize=128m; support was removed in 8.0Could not reserve enough space for <数量>KB object heap
你可以在这里下载64位的Java。确保你选择了 "Windows x64"版本

设置 Java 安装于 Pixelmon 启动器
在安装64位Java之后，找到安装路径
  • 在 Windows 上，默认的安装位置是"C:\Program Files\Java\jdk1.8.0_<版本>\bin\java.exe"。
  • 在 Mac OS X，默认的安装位置是 "/Library/Java/JavaVirtualMachines/jdk1.8.0_<version>.jdk/Contents/Home/bin/java".
在你找到安装路径之后，你需要配置 Minecraft 使用这个文件，这令 Minecraft 使用你安装的 Java 版本。
  • 在 Minecraft 启动器，编辑 Profile，找到“Java executable”，启用。接着将其替换为之前找到的安装路径的 .exe 文件位置，保存 Profile。
  • 在 Pixelmon 启动器，点击右上角的齿轮按钮，打开启动器设置。点击 “Select Java Install”，选择你的 Java .exe 文件，接着点击 “Continue”来保存更改的设置。
32位操作系统
如果你在使用Windows，并且你不能安装64位的Java，那么你可能在使用不能运行64位程序的32位的系统。你可以看看崩溃报告中“System Details”的“Operating System”，如果包含“(x86)”，那么你的操作系统是32位的，你需要升级你的系统到64位的系统。下方就是一个32位系统的例子：
Operating System: Windows 10 (x86) version 10.0
32位 CPU
如果你不能升级至64位系统，那么你的CPU可能是一颗32位的CPU，你需要购买新电脑。
RAM不足
Win7 的内存查看，这个电脑内存不足以运行 Pixelmon.

如果你已经升级至64位Java，但是仍然发生原来的错误，那么你的电脑没有充足的内存运行Pixelmon。右键桌面的“计算机”（Windows 7/8）或“此电脑”（Windows 10），选择“属性”来查看你的内存。在“已安装的内存(RAM)”后方，如果你安装了少于或等于 2GB 的内存，你需要安装更多内存。这需要你购买内存条（就是那种能拿在手上的），并且插入你的电脑。详情请百度。
全局 Java 设置
Windows 系统有一个限制所有 Java 程序的内存使用的特性，查看你的崩溃报告，如果你看到了多个“-Xmx”，那么这个全局设置防止你分配足够的内存。
以下为一个被全局设置影响的例子，注意用户定义了一个 "-Xmx2G"  并且有一个附加的 "-Xmx512M" 用户没有定义。
JVM Flags: 5 total; ... -XX:MaxPermSize=128m -Xmx2G -Xms256M -Xmx512M
按照以下步骤移除全局限制：
  • 右键桌面的“计算机”（Windows 7/8）或“此电脑”（Windows 10），选择“属性”
  • 左侧的选项中选择 "高级系统设置".
  • 一个 "系统属性" 窗口会打开，选择 "环境变量" 按钮
  • 在 "环境变量" 窗口，寻找 "系统变量" 中的 "_JAVA_OPTIONS".
  • 选择 "_JAVA_OPTIONS" 并点击 “删除”
  • 重启计算机
  • 重启后，启动 Minecraft 看看是否成功启动

服务器 Mod 安装
这是一个将 Pixelmon 安装至多人服务器的教程。如果你只是想普通的玩一下 Pixelmon 而不是开一个服务器，请查看一楼的教程。
要求
  • 一份正版 Minecraft，使用 Mojang 账号购买
    • 只有电脑版可以运行 Pixelmon，主机版和携带版都不可以
  • 4 GB 可用内存
  • 64位 Java 8
注意
  • 这个教程仅针对本地主机，即只有使用同一局域网的玩家才可以进入，如果你需要将你的服务器发布，以便让其他玩家进入，那么请查看这篇教程
  • 如果你在使用外部托管服务，那么安装可能会不同，请找你的服务提供商咨询更多的详细信息
  • 这篇教程只会介绍 Forge, Pixelmon, 拓展模组, 和 SpongeForge. 拓展模组 和 SpongeForge 等可选的安装方式，每种方式都有不同的服务器管理方法
  • Pixelmon jar 文件同时可用在客户端和服务器
  • 越多的玩家将占用越多的内存，作为最小需求，我们使用了 4 GB
  • 请不要使用使用盗版服务器运行 Pixelmon，如果你这样做，玩家的数据将不会保存，这个 BUG 将不会修复
  • 请不要使用 Technic 启动器的模组，这将造成错误和游戏崩溃，这些问题也不会修复。如果你很在意提供整合包，那么请看 Pixpack 页面
  • 你如果想获得更多的支持，请访问 support tracker 或加入 Pixelmon Discord
版本
Pixelmon 兼容很多的 Minecraft 版本，在下方的表格中详细的列出了。每个不同的 Minecraft 版本都需要不同的 Pixelmon 版本运行。注意现在只有 Minecraft 1.10.2 版本的 Pixelmon 接受更新，更早的版本将不会继续更新或是修复 BUG。
现在还没有 Minecraft 1.11 或 1.12使用的 Pixelmon。下方的表格列举了最新的各个版本的 Pixelmon。

Forge 安装
  • 找到推荐的 Forge 版本并安装（files.minecraftforge.net）。根据你的电脑选择下载 Installer-win （Windows）或 Installer（Mac OS/Linux）。
  • 下载之后，将其放在一个你想要用来开服的文件夹里，新建文件夹是很简单的。
  • 运行下载的文件，选择 "server" 安装
  • 完成后，打开文件夹，在 forge-[版本]-universal.jar 的文件夹打开终端或命令行界面
  • 输入以下指令 java -Xmx4G -Xms4G -jar forge-[版本]-universal.jar nogui
  • 界面很快会停止，这时你需要同意 Mojang 的最终用户协议，并把 eula.txt 最后一排的 false 改为 true
  • 重新执行第5步
Pixelmon 安装
  • 打开服务器文件夹的 /mods 文件夹
  • 如果你的服务器正在运行，请输入命令 /stop 关闭服务器
  • 前往下载页面并下载你需要的版本
  • 将下载的 jar 文件放入 /mods 文件夹
    • 不要压缩或解压此文件
  • 重启服务器，你的服务器就变成了 Pixelmon 服务器
  • 你可以更改 Pixelmon 的配置文件来自定义服务器，如果你更改了，你需要重启服务器以使更改生效
拓展模组安装
这只是一个可选的部分，用于自定义服务器，如果你不需要拓展模组，请跳过这一章
  • 查看 拓展模组 页面，寻找兼容你的版本的模组
    • 拓展模组有不同的版本，分别支持不同版本的 Pixelmon，请注意查看版本信息
  • 当你选定拓展模组后，前往 下载页面 下载文件
  • 下载完毕后，将 jar 放入 /mods 内，重启或启动服务器让 Mod 生效
    • 部分拓展模组有其他的安装步骤，请在发布页面仔细查看
    • 拓展模组的配置也在 Pixelmon 配置文件的目录下
SpongeForge 安装
这是一个可选的部分，如果你不需要插件，你可以跳过这一步
  • 打开 /mods 文件夹
  • 在 这个页面 下载 Sponge。注意 Minecraft 1.8.9 以下的版本不推荐使用 Sponge
    • SpongeForge 需要特定的 Forge 版本，也需要特定的 Minecraft 版本
  • 选择 SpongeForge 版本 (最新的稳定版本是推荐版本), 下载文件
  • 将下载的文件放入 /mods 文件夹
    • 注意 jar 文件命名格式为 spongeforge-[Minecraft 版本]-[Forge 版本]-[API]-BETA-[Spongeforge 版本].jar。请保证你使用了相应的 Forge 版本。
  • 重启服务器，你的服务器现在安装了 SpongeForge了，查看 这个页面 查找插件
故障排除
  • 如果你遇到了问题，请在 support tracker 或加入 Pixelmon Discord 提问
  • 如果你安装了可选的 SpongeForge，请查看 SpongeForge 文档
  • 如果你使用拓展模组出现问题，请前往 sidemod issue tracker.
