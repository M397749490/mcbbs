SurpriseEggs v2.0 即将到来！
拿着一个龙蛋然后输入 /se open......哇塞! 你打开了一枚龙蛋!
这是什么？
装了这个插件， 有权限的玩家可以通过输入一行命令或者右键摆在地上的龙蛋来打开它们。 当然， 所有内容都是可以配置的！

命令说明
  • /se open —— 打开你手上的龙蛋！
  • /se reload —— 重载配置文件
权限说明
  • SurpriseEggs.use —— 右键打开地上的龙蛋
  • SurpriseEggs.open —— 使用命令打开手上的龙蛋
  • SurpriseEggs.reload —— 重新载入配置文件
       (OP默认拥有上述所有权限)
配置文件

  1. # config.yml 配置文件 由@Mayomi 汉化
  2. # 龙蛋的容量（必须是9的倍数）
  3. Size: 27
  4. # 全局物品会出现的几率
  5. Chance: 0.25
  6. # 龙蛋的标题（右键龙蛋或者指令打开龙蛋后会在左上角显示的名称）
  7. invTitle: "&6&lSurpriseEgg"
  8. # 在关闭龙蛋后，物品是否掉（乱）落（飞）
  9. dropItemsOnClose: true
  10. # 是否可以通过右键来打开地上龙蛋，如果false 点击就会乱飞
  11. rightClickToOpen: false
  12. # 是否开启统计，不建议关闭
  13. useMetrics: true
  14. # 是否开启自动更新
  15. checkUpdate: true
  16. # 对于1.7.X 必须要用物品格式代码
  17. # 物品名称格式:
  18. # http://jd.bukkit.org/rb/apidocs/src-html/org/bukkit/Material.html
  19. # 附魔名称格式:
  20. # http://jd.bukkit.org/rb/apidocs/src-html/org/bukkit/enchantments/Enchantment.html
  21. # 染色物RGB颜色代码:
  22. # http://www.rapidtables.com/web/color/RGB_Color.htm
  23. # 这些是一些例子
  24. Items:
  25.   - DIAMOND 5 name:&6Diamond
  26.   - DIAMOND_BLOCK 2 x:2
  27.   - DIAMOND_SWORD 1 enchant:KNOCKBACK 2
  28.   - DIAMOND_PICKAXE 1 lore:Most_useful_pickaxe_ever! enchant:SILK_TOUCH
  29.   - DRAGON_EGG 1 chance:0.1
  30.   - LEATHER_CHESTPLATE 1 color:255,165,2
  31.   - PAPER 1 name:&cMoney lore:Right-Click_to_earn_it money:50
  32. #可用的变量 x enchant lore name chance color money
  33. #变量 x lore name chance money 可用于所有物品
  34. #变量 enchant 推荐用于可附魔的装备
  35. #变量 color 可用于皮革装备
  36. #x：物品出现百分比
  37. #enchant：装备附魔
  38. #lore：物品描述
  39. #name：物品名称
  40. #chance：物品出现几率
  41. #color：皮革装备颜色
  42. #money：可以获得的金钱 （使用此选项玩家将不能得到此物品）
复制代码

自动更新
这个插件带有一个自动更新检查系统， 来确保你在使用最新的， 没有很多bug的版本。然而如果你因为某些原因想要禁用它， 你可以在 plugins/SurpriseEggs/config.yml 中把 checkUpdate 设置为 false。
Metrics
这个插件使用 Hidendra 的metrics系统, 这代表着以下信息将会被收集并发送到 mcstats.org:
  • 一个独特的服务器ID
  • 服务器的Java版本
  • 服务器是在线模式或离线模式
  • 插件的版本
  • 服务器的版本
  • 服务器的系统版本信息
  • 服务器的CPU核心个数
  • 在线的玩家数量
  • Metrics的版本
你可以通过修改 plugins/SurpriseEggs/config.yml 并且将 useMetrics 改为 false 来禁止这项服务。
