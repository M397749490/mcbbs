1.参考各大Mod编程教程，如果要给物品名添加颜色可以在物品名前加样式代码即可（最简单的方法）

2.复杂点，可以使用getRarity方法设置物品的“稀有度”以给你的物品名设置字体颜色，比如：
  1.     @Override
  2.     public EnumRarity getRarity(ItemStack itemstack)
  3.     {
  4.         return EnumRarity.epic;
  5.     }
复制代码

此代码在插入到你所定义的物品类里可以将你的物品稀有度设为“史诗级”（Epic），字体颜色为紫色
有关于物品稀有度的详细信息可以自行翻阅源代码，然后你就会发现用这个方法设置字体颜色只能选三四个的其中一个...（Common=白色，Uncommon=黄色，Rare=蓝色，Epic=紫色）

感谢！那再问个小问题，lore应该怎么设置？

使用addInformation方法，示例：
  1.     @Override
  2.     @SuppressWarnings("unchecked")
  3.     public void addInformation(ItemStack itemStack, EntityPlayer entityPlayer, List list, boolean b)
  4.     {
  5.         list.add("Hello world!"); // 在物品描述（lore）里添加一行“Hello world!”
  6.     }
复制代码


可以配合StatCollector使用以实现多语言支持，例如：（下面这个代码取自我无聊写的一个私人Mod）
  1.     @Override
  2.     @SuppressWarnings("unchecked")
  3.     public void addInformation(ItemStack stack, EntityPlayer playerIn, List tooltip, boolean advanced)
  4.     {
  5.         tooltip.add(StatCollector.translateToLocal("item.hmkrc.desc1"));
  6.     }
复制代码


语言文件：
  1. item.hmkrc.desc1=姿势含量 X
复制代码


代码内的@SuppressWarnings("unchecked")主要用途是避免在编译过程中弹出“未经检查的操作”警告，实际上让它显示也是可以的，不会影响使用
