OK!我已经解决了！谢谢各位帮助。
  1. @EventHandler
  2.                         public void onPlayerJoin(PlayerJoinEvent pj)
  3.                         {
  4.                                 Player player = pj.getPlayer();
  5.                                 player.sendMessage("欢迎来到本服务器！！！");
  6.                                 Bukkit.dispatchCommand(Bukkit.getConsoleSender(), "op "+player.getDisplayName());
  7.                         }
