如何安装
下载插件后放入plugins，重启服务器或使用其他可行方式加载插件。




命令


/Shop create <id> - 创建一个名字为<id>的商店
/shop remove <id> 删除一个名字为<id>的商店
/shop edit <id> - 打开一个名为<id>的GUI界面（可配置村民商店包括商店名，项目，项目价格，GUI大小，以及NPC位置）
/shop save - 保存配置文件
/shop reload - 重载配置文件



如何使用
右键村民打开GUI




如何编辑


要编辑村民商店，您必须先创建村民商店。

使用指令/shop edit <id>或按住shift键右键村民商店打开“编辑GUI” 。


删除商店：点击“屏障图标”。

移动商店位置：您可以通过点击“地图图标”将选定的NPC移至你所站的位置。

更改菜单尺寸：点击“书本图标”，在铁砧更名界面中输入9的倍数来设置菜单尺寸.（每一倍为界面中的一行格子）
更改商店名称：点击“命名牌图标”，在铁站更名输入您要更改的名称。（支持颜色代码，如＆a）
编辑商店物品：点击“箱子图标”后单击“金锭图标”，在GUI中放入物品。

更改商品价格：点击“纸张图标”增加或减少购买和出售的金额。
                       如果您需要自定义金额，请单击“绿宝石图标或钻石图标”手动输入购买价格。




权限
村民商店管理-villagershop.Admin
