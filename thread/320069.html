本节我们来讲attackHook函数

attackHook作用是当点击或攻击了一个生物mob(动物，怪物，玩家)时会触发这个函数，并返回数据。

mob就是指游戏中的实体

格式如下

  1. function attackHook(attacker,victim){}
复制代码

怎么用呢？

很简单，首先attacker代表进行了点击或攻击动作的mob

victim则代表被点击或攻击的mob

好，接下来我们来看一个小小的实例

  1. function attackHook(attacker,victim){
  2.         var A=getPlayerEnt();
  3.         if(attacker==A){
  4.                 clientMessage("你别打了！");
  5.         }
  6. }
复制代码
getPlayerEnt的作用是获取玩家的实体ID

然后与刚刚获取的sttacker的实体ID进行比较，如果正确就在屏幕上显示“你别打了！”

所以只有玩家进行攻击会显示而生物攻击不会，比如僵尸攻击你。
