0、一个空白的插件


介于BBS上关于Spigot插件的教程较少且不完整于是这个教程就诞生了~参考内容：官方Wiki
因为网上Java基础教程略多，请有Java基础的人再来
本教程使用Eclipse。

1、启动Eclipse。
最好不要设置工作空间，默认就好。


2、创建一个新Java项目
在包资源管理器上右键：
项目名自定，推荐为插件名。
然后点击完成。


3、导入Spigot核心
核心见http://www.mcbbs.net/thread-433216-1-2.html。


选择刚才下载的核心。
然后按确定。


4、创建一个新的包


包名可以是
域名如
com.xxx
net.mcbbs
等等
开头最好不要大写。
点击完成即可！


5、创建一个类并且让他继承主类


名称随意点击完成即可。
这时会自动生成代码：
  1. package com.abc;

  3. public class MySpigotPlugin {

  5. }
复制代码
我们要让他继承主类：
  1. package com.abc;

  3. public class MySpigotPlugin extends JavaPlugin {

  5. }
复制代码
一秒后，就开始报错了······
因为事先并没有导入包。
  1. package com.abc;

  3. import org.bukkit.plugin.java.JavaPlugin;  //导入包

  5. public class MySpigotPlugin extends JavaPlugin { //继承主类

  7. }
复制代码
这样就可以了！



6、让插件吱一声
要让插件在启动/关闭的时候吱一声，就要添加这两个方法：
  1. package com.abc;

  3. import org.bukkit.plugin.java.JavaPlugin;  //导入包

  5. public class MySpigotPlugin extends JavaPlugin { //继承类
  6.     @Override
  7.     public void onEnable() {
  8.             //启用插件时自动发出
  9.     }

  11.     @Override
  12.     public void onDisable() {
  13.             //关闭插件时自动发出
  14.     }

  16. }
复制代码


这样一个插件就制作好了，虽然并没有什么卵用。


7、让服务器知道这个插件
然后在文件名中写入：
  1. plugin.yml
复制代码
在里面写入
  1. name: MySpigotPlugin      #插件名
  2. main: com.abc.MySpigotPlugin      #插件的包名+主类
  3. version: 1.0       #版本
复制代码
空格绝对不能忘了，否则就读不出来这个插件了~


8、导出插件


然后右键项目，导出

然后弄好之后就导出完毕了。
这时候就可以放入服务器了√
