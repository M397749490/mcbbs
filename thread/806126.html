管理命令

  • “modbanner.bypass” - 通过permon用户使用禁止的mod时不会被踢这个权限
  • modbanner.command.add - / modbanner add（将mod添加到黑名单）（名称不需要相同，你可以使用光线来阻止：[xxray，ExtremRaYXXD]等）
  • modbanner.command.remove - / modbanner remove（从黑名单中删除mod）
  • modbanner.command.list - / modbanner list（查看所有列入黑名单的mods）
  • modbanner.command.manage - / modbanner（add / remove / list）
重新加载命令
  • modbanner.command.reload - / modbanner reload（重新加载配置/禁止的mods（如果通过命令添加mods则不需要））
信息命令
  • modbanner.command.modinfo.player - / modinfo player（查看所有mods播放器使用）
  • modbanner.command.modinfo.mod - / modinfo mod（查看使用该mod的所有玩家）
