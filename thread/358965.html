今天搬运插件是Economy经济插件。



经济主要插件使用方法


商店（EconomyShop）：

首先放一个牌子
第一行写         shop
第二行写物品  价格
第三行写物品    ID
第四行写出售  数量

收购（EconomySell）：

首先放一个牌子
第一行写         sell
第二行写物品  价格
第三行写物品    ID
第四行写收购  数量

领地（EconomyLand）：
领地指令就说最基础的了

/startp设置位置1
/endp设置位置2.
输入/land buy购买领地
