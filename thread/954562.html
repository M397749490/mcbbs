作者: TUCAOEVER    时间: 2020-2-8 11:05
本帖最后由 TUCAOEVER 于 2020-2-8 11:07 编辑

下载并安置 Skript https://github.com/SkriptLang/Skript在 plugins/Skript/scripts 内新建 1.sk 文件
将如下代码输入 1.sk 文件内
  1. command /x:
  2.     trigger:
  3.         loop all players:
  4.             set glowing of loop-player off
复制代码
输入指令 /x 即可关闭当前在线玩家的发光效果
当然如果需要包括没上线的玩家也关闭
  1. on join:
  2.     set glowing of player off
复制代码
即可在玩家加入时关闭他们的发光效果
