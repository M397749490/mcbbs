崩坏广场是一款专为留言板，个人博客等（BoomSquare）打造的WEB站点，通过精心的设计与耐心的研究，配合Markdown强大的排版功能，带来前所未有的书写体验。
感谢@printempw 的皮肤站。正是我参考了他的皮肤站的样子，才促使我成就了崩坏广场

☆ 简介

不知道大家对mc的官网，或者是论坛有什么看法。用Dz？还是用Pw？我感觉这2个对于mc比较庞大。有大部分功能用不上，或者是你想要的功能没有（我是指我的世界），现在，有了崩坏广场，你可以用他做官网的同时提供论坛功能，亦可以作为博客来使用。留言和博客可自由切换。实现与主流authme插件对接等等。 更多请移步GitHub


▲ 特点
功能丰富 ：
  • 支持Markdown语法，支持高亮代码 [√]
  • 支持Sqlite3,比一些流行的数据库在大部分普通数据库操作要快
  • 支持Mysql[有时间介绍配置方法]
  • 可只由切换 留言 和博客 模式 [×][下个计划实现]
  • 支持于皮肤站账号系统对接 [×]
  • 支持authme插件对接 [×]
  • 更多后续完善

崩坏广场的优点：
  • 专注你的文字内容而不是排版样式，安心写作。
  • 随时修改你的文章，不必像字处理软件生成若干文件版本导致混乱。
  • 可读、直观、学习成本低。
  • 统一管理authme账号，实现与登陆插件对接等功能

得心应手 ：
  • 简洁高效的编辑器，轻松的导出 HTML、PDF 和本身的 .md 文件, 纯文本内容。
  • 兼容所有的文本编辑器与字处理软件；
  • 优雅的界面，加上Markdown让你写作更完美

★ 快速指南
1. 使用 Nginx 作为uwsgi的代理
暂时没有完成，下面仅供参考



以下出现的配置，均在已打包，记得去修改
需要修改： nginx_web.conf
无需修改： uwsgi_params
目录不存在请创建 mkdir /etc/nginx/conf/

网站路径：Boom-square
nginx_web.conf
server {
    listen 8030;
    server_name localhost;
    charset     utf-8;
    access_log      /home/nginx_access.log;
    error_log       /home/nginx_error.log;
    client_max_body_size 75M;


    location /static {
        alias /Boom-square/static;
    }

   location / {
       include    /etc/nginx/conf/uwsgi_params; # 记得将上面的uwsgi_params 放入这个路径
       uwsgi_pass unix:/xxxx/uwsgi.sock; # 指定uwsgi的sock文件, 配置方法请参考uwsgi.ini里面的[socket=/xxxx/uwsgi.sock]
    }
}

修改uwsgi.ini配置文件

  2. vim /Boom-square/uwsgi.ini
  3. [uwsgi]
  4. # 启动uwsgi的用户名和用户组
  5. uid=root
  6. gid=root

  8. # 指定IP端口      
  9. http=0.0.0.0:8080
  10. # 项目目录
  11. chdir=/Boom-square/
  12. # 指定静态文件
  13. static-map=/static=/Boom-square/static

  15. #### 下面一般不需要修改 ####
  16. ......
复制代码

cp /Boom-square/nginx_web.conf /etc/nginx/conf.d
cp /Boom-square/uwsgi_params /etc/nginx/conf/
