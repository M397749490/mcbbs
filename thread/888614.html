功能：
  • 通过指令创建活动，玩家加入进活动抽取奖励
    （可能有一定误差，原帖的英文很难理解至少我的水平不行应该掺杂了俚语）
  • 可以自定义配置消息
  • 可以自定义配置计分板


命令与权限：
  1. /giveaway start < 持续时间 > <奖励…> 开启活动
  2. /giveaway join 加入活动
  3. - giveaways.start
  4. - giveaways.join
复制代码

配置文件：
  1. Messages {
  2.     # 赠送完成后发送到服务器的消息
  3.     completedGiveaway="&b{winner} &7已赢得 &6{giveaway} 的奖励"
  4.     # 当玩家加入赠品时发送给玩家的消息。
  5.     joinGiveaway="&b{playerName}&a你已经加入这次奖励活动\n&7 &b#{position} 是你的兑奖号"
  6.     # 当没有人加入赠品时发送到服务器的消息
  7.     noParticipants="&7没有人加入 &b{playerName}&7发起的奖励活动! &c:("
  8.     # 启动赠品时发送到服务器的消息
  9.     startedGiveaway="&b{playerName} &7已为 &6{giveaway} 增加奖励，快来加入吧"
  10. }
  11. Pagination {
  12.     # 在行间添加空格，看起来更好！
  13.     # 请参考图片修改，我就不修改了
  14.     addSpace=true
  15.     # 在此处插入分页页脚
  16.     footer="&8[&aJoin Giveaway&8]"
  17.     # 在此处插入分页填充
  18.     padding="&7&m-"
  19.     # 在此处插入分页标题
  20.     title="&6{pluginName}"
  21. }
  22. Scoreboard {
  23.     # 记分板上赠品中参与者显示的文本
  24.     # 请参考图片修改，我就不修改了
  25.     participants="&6Participants:"
  26.     # 记分板上剩余时间数的文本
  27.     timeRemaining="&6Seconds Remaining:"
  28.     #记分板顶部的标题
  29.     title="&6{pluginName}"
  30. }
