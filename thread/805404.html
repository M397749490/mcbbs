什么是 SkinsRestorer？
  • SkinsRestorer是一个在离线模式的服务器显示正版皮肤的插件，通过使用命令或者初次加入时插件自动获取皮肤，玩家可以更改皮肤，即使用正版ID对应的皮肤，非正版玩家也可以通过指令加载某个正版ID的皮肤。

一些工具：
一些可用于自定义皮肤的有用工具（搬运注：打不开请自行解决，经测试下面的链接均正常）
SkinFile Generator （自定义皮肤文件生成器）:
  • 在 SkinFile Generator，用户可以上传自己的皮肤，来获得一个特定的.skin文件，你（服主或服务器技术——译者注）可以将其放在 SkinsRestorer 的 Skins 文件夹中使用。地址：https://riflowth.github.io/SkinFile-Generator/
SkinSystem （自己搭建一个皮肤站）:
  • 如果你是服主或服务器技术技术，你可以通过使用 SkinSystem，将Authme（和论坛）与位于你服务器的 SkinSystem 网站连接（作为自己的皮肤站使用——译者注），以使你的玩家能够上传自定义皮肤。地址：https://github.com/riflowth/SkinSystem/

如何安装 SkinsRestorer？
安装 SkinsRestorer 非常简单
按照这个小指南操作，你将不会出错
需要更多帮助请查看 -> [官方英文wiki]
  • 对于 Spigot & CraftBukkit 服务端:
    • 将插件 jar 文件放入 /plugins 文件夹中；
    • 重启服务器；
    • 【可选】 编辑位于 ./plugins/SkinsRestorer/ 文件夹中的配置文件。
  • 对于 BungeeCord 群组服:
    • 将插件 jar 文件放入每个 Spigot 子服的 /plugins 文件夹中；
    • 将插件 jar 文件放入每个 Bungeecord 服务端的 /plugins 文件夹中；
    • 检查并设置每个 Spigot 子服的 spigot.yml -> bungeecord: true
    • 在 Bungee 服务端中正确设置权限
    • 重启服务器；
    • 【可选】 编辑位于 Bungee 目录下的 /plugins/SkinsRestorer/ 文件夹中的配置文件；
  • 对于 Sponge 服务端（作为模组/MOD使用）:
    • 将插件的 jar 文件放入 Sponge 的 ./mods/ 文件夹中；
    • 重启服务器；

玩家指令:
  • /skin - 主命令
  • /skin <skinname> - 设置你的皮肤为其他正版ID的皮肤
  • /skin update - 更新“你现在所使用的皮肤对应的ID”的最新皮肤为你的皮肤
  • /skin clear - 清除你的皮肤
  • /skins - 打开皮肤选择菜单 ( 只可用于Spigot 1.13 以上的版本, 该 GUI 可用于选择服务器已缓存的其他 ID 的皮肤 )
管理员指令:
  • /sr - 管理员主命令
  • /skin set <playername> <skinname> - 设置玩家皮肤
  • /skin clear <player> - 清除一个玩家的皮肤
  • /skin update <player>  - 更新一个玩家的皮肤
  • /skin reload - 重新加载配置和区域设置
  • /sr props <playername> - 返回玩家的皮肤属性信息
  • /sr reload - 重载插件配置和语言文件（如果使用数据库则必须完全重启服务器）
  • /sr status - 检查插件状态
额外的权限节点:
  • skinsrestorer.bypasscooldown -> 允许忽略“更改皮肤的冷却时间”
  • skinsrestorer.bypassdisabled -> 允许绕过“禁用皮肤列表”
