BungeeReport


插件介绍

这是一个可高度自定义的跨服举报插件。当玩家举报后管理员将收到举报的详细信息。

插件截图







使用教程

安装
将此插件放在bc端的plugins目录下即可

使用
使用命令 /report <玩家> <原因> 即可举报其它玩家
使用命令 /reporttoggle 即可开启/关闭举报提醒

配置文件

汉化版
  1. REPORT:
  2.   COOLDOWN: 60
  3.   USAGE:
  4.     INCORRECT:
  5.       - '&c请使用： /report <player> <reason>'
  6.     NO-REASON:
  7.       - '&c请说明举报 &e<target>&c 的原因！'
  8.       - '&c请使用： /report <target> <reason>'
  9.     SUCCESSFULLY:
  10.       - '&a你成功举报了 &e<target> &a！'
  11.   NOTIFY-MESSAGE:
  12.     - '&7&m-----------------------------------------'
  13.     - '&f 玩家&a <player>&f 举报了玩家 &c<target> &f'
  14.     - '&f 原因： &e<reason>'
  15.     - '&f 服务器： &9<server>'
  16.     - '&7&m-----------------------------------------'
  17.   TOGGLE-MESSAGE:
  18.     ENABLED: '&f你已&a开启&f了举报提醒'
  19.     DISABLED: '&f你已&c关闭&f了举报提醒'
  20.   HOVER:
  21.     MESSAGE: '&a点击这里连接 &e<server>&a 服务器'
  22.     COMMAND: '/server <server>'
  23.   TITLE:
  24.     ENABLED: true
  25.     LINES:
  26.       1: '&a&l新举报'
  27.       2: '&f玩家&a <player>&f 举报了玩家 &c<target>'
  28. CANCEL-SERVERS:
  29.   REPORT-COMMAND:
  30.     - 'Hub'
  31.     - 'Lobby'
  32.     - 'PreHub'
  33.     - 'PreLobby'
  34.   NOTIFY-MESSAGE:
  35.     - 'PreHub'
  36.     - 'PreLobby'
  37. OTHERS:
  38.   NO-ONLINE: '&c<target> 目前不在线！'
  39.   NO-SERVER: '&c你不能在服务器 <server> 中举报玩家！'
  40.   NO-CONSOLE: '&c只有玩家才能使用这个命令！'
  41.   NO-YOURSELF: '&c你不能举报你自己！'
  42.   NO-PERMISSIONS: '&c你没有权限使用这个命令！'
  43.   COOLDOWN-FORMAT:
  44.     SECOND: '秒'
  45.     SECONDS: '秒'
  46.     MINUTE: '分'
  47.     MINUTES: '分'
  48.   COOLDOWN: '&c你需要等待 &e<cooldown> &c后才能再次举报这个玩家！'
复制代码

部分配置解释
COOLDOWN -> 举报的冷却时间
CANCEL-SERVERS -> REPORT-COMMAND -> 禁止举报的服务器
CANCEL-SERVERS -> NOTIFY-MESSAGE -> 禁止举报提醒的服务器

命令&权限

命令列表
命令描述
report <玩家> <原因>举报某个玩家
reporttoggle开启/关闭举报提醒

权限列表
权限描述
Report.command.report/report 命令的使用权限
Report.notify接收举报提醒的权限
Report.command.togglereports/reporttoggle 命令的使用权限
