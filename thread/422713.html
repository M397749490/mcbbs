Commands/Permissions


CommandDescriptionPermission
/djBasic information about the plugin-/-
/dj help插件这个插件的命令-/-
/dj toggle [player]开启与关闭[Player]的二段跳doublejump.toggle[.others]
/dj reload重新载入 DoubleJump++ configdoublejump.reload
/dj item [player]给一个Item给[Player]doublejump.item[.others]
-/-可以使用  DoubleJump++doublejump.use
-/-
  DoubleJump++所有权限
doublejump.*
-/-不用设置,默认OPdoublejump.bypassncp
-/-不用设置,默认OPdoublejump.bypassanticheat
/dj item [player]建议不设置,默认OPdoublejump.item.*
/dj toggle [player]建议不设置,默认OPdoublejump.toggle.*




Config


enabled: true
是否启用插件
auto-update: true
是否自动更新
falldamage: true
是否开启掉落伤害
damagemultiplier:1
(掉落伤害倍数×1)
allowinliquids: false
在水/岩浆里是否禁用二段跳
togglecooldown: 0
使用指令开启二段跳的冷却时间
mode: COOLDOWN/FOOD/POWER
FOOD - 每次使用消耗饱食
POWER - 有权限就能用(不确定)
cooldown: 0
使用二段跳的冷却时间
usexpbar: true
仅在POWER模式下可使用,将冷却时间在经验条上显示
注意:可以刷等级！可以刷等级！因为很重要！所以说2变遍！
================
bypassanticheat: false
bypassnocheatplus: false
这2个只是避免与反作弊插件的***
如果你打了anticheat或nocheatplus就改成T吧
================
maxcheckexemptiontime: 0
设置0为禁用
只是为了防止飞行时间过长被T出
一半情况下无需更改
================
item:
  id: 280
这里默认是木棍(#280)
  displayname: '&6Doublejump'
设置Item名字,右键即可开启与关闭
onjoin: true
这里默认加入时自动开启
locked: true
设置True时,你不能控制移动/下降
  slotid: 9
把这个Item锁定在第9个格子
worlds:
- world
          - world_nether
            - world_the_end
可用的世界
flycommands:
- /fly
如果输入了/fly这个命令,那么这个插件自动关闭
你可以自己添加与飞行有关的指令
boost:
  forwardmultiplier: 1.5
X和Z值的量乘后得出的值
简单点说就是推进效果,与移动速度有关
  upwards: 1
二段跳的弹跳高度
================
  effect: SMOKE
# Effects: Effects:
这里可以选择弹跳中的特效,应该与Hive_jumppads特效一样
Hive_jumppads特效链接：Click
================
  sound: PISTON_EXTEND
# Sounds:
这里可以选择弹跳时的音效,应该与Hive_jumppads音效一样
Hive_jumppads音效链接：Click
