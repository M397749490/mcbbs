AlmostFlatLandsReloaded
呼伦贝尔大草原
授权搬运

简介
如果你不想使用原版的超平坦地形生成器，那么这个插件明显很适合你
图片

指令和权限
  • /AFLR help [页数] - (查看帮助)
  • /AFLR info - (显示信息)
  • /AFLR reload -[[size=14.6667px]AlmostFlatLandsReloaded.Reload] (重载插件)
  • [AlmostFlatLandsReloaded.UpdateMessage] (拥有此权限的玩家可以收到插件的升级信息)
使用方法
  • Multiverse：/mv create [世界名] normal -g AlmostFlatLandsReloaded
  • Bukkit：在Bukkit.yml中
  1. worlds:
  2.   WorldName:
  3.    generator: AlmostFlatLandsReloaded
复制代码
文件

  • config.yml：
  1. Version: 1.0

  7. GameVersion:

  9.   Version: v1_12_R1

  15. ShowUpdateMessage: true
