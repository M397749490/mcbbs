领地配置文件plugins\Residence\config.yml文本编辑器打开（非记事本）：
  1. # These groups correspond to the Permissions groups defined in your '<worldname>.yml'
  2. Groups:
  3.     Default: #group name
  4.        # Information about the Residence zone that the player can define.
  5.        Residence:
  6.            # Determins if this group can create residences or not.  This option can be overriden with the permissions node 'residence.create'
  7.            CanCreate: true
  8.            # The maximum number of Residences a player can have.一个普通玩家总共能创建几个领地
  9.            MaxResidences: 3
  10.            # The maximum number of physical areas a residence can have.一个领地最多能包含的物理区域个数
  11.            MaxAreasPerResidence: 2
  12.            # The maximum number of blocks a Residence can be, East to West (X).东西方向最大宽度
  13.            MaxEastWest: 16
  14.            # The maximum number of blocks a Residence can be, North to South (Z).南北方向最大长度
  15.            MaxNorthSouth: 16
  16.            # The maximum number of blocks a Residence can be, High to Low (Y).垂直方向最大长度
  17.            MaxUpDown: 256
  18.            # The lowest altitude this group is allowed to protect.最低保护高度
  19.            MinHeight: 0
  20.            # The highest altitude this group is allowed to protect.最高保护高度
  21.            MaxHeight: 255

MOD安装方法
1.找到Minecraft文件夹 (If you don't know how to, look it up)

2. 将ZIP文件里的portalgun文件夹解压到.minecraft/mods/文件夹内.

3. 如果你想更改设置 (例如: 方块ID),去 /mods/portalgun/文件夹然后打开 mod_PortalGun.properties文件。

4.如果发现没有一些音效，请把protalgun文件夹下的resources文件夹覆盖到 .minecraft文件夹下
