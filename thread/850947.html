按键教程指南

插件使用方法
我自己服务器用到的喇叭插件太麻烦了 所以我们就以喇叭插件来做例子
先在游戏内输入/vvc create [配置文件的名称]创建新的配置
大喇叭插件需要用到的指令是vexhorn send 后面是喇叭内容
那么在配置文件的这一栏内把输入的指令放过来 后面增加一个变量
  • #指令,%player%代替玩家%message%代替消息
  • command: "player:vexhorn send %message%"

[color=rgb(51, 102, 153) !important]复制代码

然后配置一下 使用成功后 左下角信息栏的提示
  • #当玩家使用完成后发送什么消息
  • complete: "成功发送"
  • 然后是设置一下界面的字样
  • titles:
  •   #上方字样，彩色用§
  •   title:
  •     - "&e使用大喇叭"
  •   #输入栏描述字样
  •   subtitle:
  •     - "&b请输入需要发出的内容"

[color=rgb(51, 102, 153) !important]复制代码

然后是设置背景图片需要用到的位置
这里的背景图片宽度以及高度 使用Windows自带的画图软件打开图片 在下方可以看到图片的尺寸
  • bg:
  •   #UI背景图片位置([local]什么的或者地址)
  •   url: "[local]cpvvguibg.jpg"
  •   #背景图片宽度（像素)
  •   width: 960
  •   #背景图片高度（像素）
  •   height: 600

[color=rgb(51, 102, 153) !important]复制代码

然后是设置一个按钮
按钮id不需要管它 有一个按钮上的字 可以随便你改
然后改一下按钮默认时候的图片
然后改一下按钮在鼠标放上去后显示的图片
然后按钮的宽度和高度 一样是在Windows自带的画图软件内查看
输入栏里的空格用什么代替 这一栏可以不用管它
  • button:
  •   #id，这里只要不重复任何数字都可以
  •   #用指令创建会自动帮你随机
  •   id: 10
  •   #按钮字样
  •   text: "发送"
  •   #两个按钮图片
  •   normal: "[local]cpvvnormalbutton.png"
  •   hover: "[local]cpvvbuttonhover.png"
  •   #按钮图片宽度
  •   width: 78
  •   #按钮图片高度
  •   height: 22
  •   #输入栏里的空格用什么代替(有些指令不支持空格)
  •   char: " "

[color=rgb(51, 102, 153) !important]复制代码

最后面这些东西可以不用去管它
  • txt:
  •   #同上面id，只要不一样什么都可以，也会自动随机
  •   id: 30
  •   #输入栏最高能有多少个字符
  •   char: 20
  • #不用理他
  •   item:

[color=rgb(51, 102, 153) !important]复制代码

然后设置好你的配置文件后 打开游戏
先让喇叭插件给你一个喇叭
手持喇叭插件给予你的物品
输入指令/vvc set [你设置好配置文件的名称]
然后会让你重载一遍插件
输入/vvc reload进行重载
然后右键刚刚设置好的物品 就可以进行发送内容了
