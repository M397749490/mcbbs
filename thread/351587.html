Feature Overview
  • Have additional structures generate in a newly generated world
  • Add any number of structures to the automatic generation
  • Export and import structures (between worlds)  - Now with schematic support
  • Easier building with special tools and commands
  • Add randomized chest content to generating structures
  • Generate structures within other structures
  • Design complete 2D and 3D mazes

Complete Feature Overview: Recurrent Complex Wiki


这是一个自动生成建筑的MOD，它不像之前的那些自动建筑模组，它是自然生成的！（正是因为这样子，生成世界的速度很慢）就像那些山和水一样，并且刷率很高！有了它，你玩生存就不用在担心庇护所的问题了！还能更轻松的获取大量资源！


请注意区分其他建筑MOD，此MOD房屋简单，强在无需手动。开图既有，适合冒险旅行者安装，开图时甚为耗时（如没有安装其他MOD），属于正常情况。
