大的便利,所以为什么不直接增加物品本身最大堆叠呢?由于游戏机制问题,默认最大

配置文件位于config/UltimateStack内

Setting.cfg
配置默认堆叠大小

  1. # Configuration file

  3. general {
  4.     # 设置物品(除了原始堆叠为1的物品)默认最大堆叠，可被其他设定覆盖   范围:1-32767
  5.     I:"Default MaxStackSize"=1000
  6. }
复制代码

CustomOre.cfg

新增自定义类型

  1. # Configuration file

  3. #####################################################################################
  4. # customore
  5. #--------------------------------------------------------------------------------------------------------#
  6. # 设置自定义类型   注意类型名称前要加S:
  7. #####################################################################################

  9. customore {
复制代码


OreMaxStackSetting.cfg
配置矿典或自定义类型的优先级以及默认堆叠

  1. # Configuration file

  3. #####################################################################################
  4. # orelevelsetting
  5. # 设置矿典或类型的级别，级别高的可以覆盖级别低的设定  范围1-10
复制代码
ItemMaxStackSize/模组名.cfg

配置单个物品的堆叠数量

自动获取物品对应的本地化名称(中文名)方便配置


示例:ItemMaxStackSize/flammpfeil.slashblade.cfg

  1. # Configuration file

  3. #####################################################################################
  4. # itemstackmaxsize
  5. #--------------------------------------------------------------------------------------------------------#
  6. # 设置物品对应最大堆叠    #范围(range):1-32767   设置为0则由矿典或类型决定
  7. #####################################################################################

  9. itemstackmaxsize {
  10.     # 耀魂碎片  #范围(range):1-32767  
  11.     #  包括此Item 的矿典或类型:[]
复制代码
