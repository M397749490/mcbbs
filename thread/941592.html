预发布版是Minecraft Java版的测试机制，如果该版本作为正式版发布，那么预发布版的游戏文件将与启动器推送的正式版完全相同。
然而，预发布版主要用于服主和Mod制作者的预先体验，如果发现重大漏洞，该预发布版会被新的预发布版代替。因此建议普通玩家持观望态度。
Minecraft 1.15.2 仍未发布，1.15.2-pre1为其第1个预览版。
转载本贴时须要注明原作者以及本帖地址。


Minecraft 1.15.2 Pre-Release 1
Minecraft 1.15.2 Pre-Release 1
A Minecraft Java Pre-Release
Minecraft Java版预发布版


We are going to release 1.15.2 for Minecraft: Java Edition which will fix a few bugs, starting with this pre-release. We expect this to go live next week.
Java版1.15.2即将到来，该版本包含一些漏洞修复。
Changes in 1.15.2 Pre-Release 1
1.15.2第一版预发布版改动

  • Bees no longer anger when a nearby nest/hive is destroyed using a silk touch tool
  • 蜜蜂不再会因附近的蜂巢/蜂箱被玩家以附有精准采集魔咒的工具采集而被激怒
  • Added doPatrolSpawning and doTraderSpawning game rules that control spawning of patrols and wandering traders, respectively
  • 加入 doPatrolSpawning 及 doTraderSpawning 两条游戏规则，分别可用来控制 灾厄巡逻队 及 流浪商人 是否会自然生成
  • Added gui_light option in block models to allow controlling light when rendering model as item in GUI
  • 为方块模型加入 gui_light 选项，可以其控制用户界面中该模型的光照渲染
  • Controls light when rendering block model inside slot. If set to side, model will be rendered like block. If set to front, model is shaded like flat item
  • 若gui_light设为 side 则该物品模型的光照将会以方块模型来渲染，若其设置为 front 则该物品模型将被作为物品来渲染
  • Fixed bugs
  • 漏洞修复

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。Java版的启动器下载地址在上文已经提供。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
