允许玩家以城镇的模式进行集体生活，支持土地的买卖
领土形状可在游戏中任意调整
和WorldEdit和WorldGuard完美配合，提供更优秀的功能
领土以木牌的形式进行买卖，更为直观

不知道是我这里的服务端版本不符还是怎么的，出现了一些小问题：

1.银行如果存入方块，重载插件(当然，这插件没有重载指令)时插件会崩溃，重载前建议将"城镇名称.yml"中contents的值改为''
2.无法使用栅栏来划分领土(栅栏无法定位到当前地域)
3./plot info指令无效
4.将加入条件设为经济后，无法加入，提示未启用邀请系统
5.默认领土价格貌似无效，会变成空值

删除城镇后，必须使用worldguard命令来删除领土、地域等，否则该区域一直处在WorldGuard控制下。例如：/region remove pap_plot_pl




别名：
  1. /town = to
  2. /territory = te
  3. /territories = te
复制代码


命令：
  1. /mct - 查看基础管理指令
  2. /mct addtown <城镇名称> <镇长名称> - 建立城镇
  3. /mct removetown <城镇名称> - 删除城镇
  4. /mct info player <玩家名称> - 玩家信息
  5. /mct info town <城镇名称> - 城镇信息
  6. /mct join <城镇名称> - 加入城镇
  7. /mct list towns - 城镇列表
  8. /mct list invite - 邀请列表
  9. /mct refuse - 拒绝邀请
  10. /mct cancel <城镇名称> - 取消邀请
  11. /mct donate - 捐赠信息

  13. /town add territory <地域名称> - 购买地域。命令后加-admin不需支付金钱
  14. /town add assistant <镇民名称> - 提拔助理
  15. /town add player <玩家名称> - 邀请玩家
  16. /town remove territory <地域名称> - 删除地域
  17. /town remove assistant <助理名称> - 免除助理
  18. /town remove player <玩家名称> - 逐出城镇。加-r表示彻底移除
  19. /town remove invite <玩家名称> - 移除邀请。加-all表示全部
  20. /town remove request <玩家名称> - 移除请求。加-all表示全部
  21. /town remove self - 脱离城镇
  22. /town active <城镇名称> - 设置有效城镇
  23. /town active reset - 设置有效城镇为所属的城镇
  24. /town list territories - 地域列表
  25. /town list players - 城镇镇民列表
  26. /town list requests - 未处理请求列表
  27. /town list invites - 未处理邀请列表
  28. /town motd - 查看motd
  29. /town motd set <消息> - 设置MOTD内容
  30. /town setmayor <镇民名称> - 设置新任镇长
  31. /town bank deposit currency <金额> - 存钱
  32. /town bank deposit <方块ID或英文名称> <数量> - 存方块
  33. /town bank withdraw currency <金额> - 取钱
  34. /town bank withdraw <方块ID或英文名称> <数量> - 取方块
  35. /town bank check currency - 查看银行资金
  36. /town bank check <方块ID或英文名称> - 查看银行方块数量
  37. /town spawn - 传送到所属城镇
  38. /town spawn <城镇名称> - 传送到指定城镇
  39. /town spawn set - 设置城镇出生点
  40. /town economy buyableplots <true/false> - 城镇领土是否允许出售
  41. /town joinmethod invitation - 城镇需要邀请才能加入
  42. /town joinmethod economy - 城镇需要付钱才能加入
  43. /town pvp friendlyfire <on/off> - 开启/关闭PvP

  45. /territory add player <玩家名称> - 授予玩家该地域权限
  46. /territory add plot <领土名称> - 在这片地域创建领土
  47. /territory redefine - 重定义地域
  48. /territory player <玩家名称> - 剥夺玩家在这片地域的权限。命令后加-r彻底移除
  49. /territory remove plot <领土名称> - 移除领土
  50. /territory active <地域名称> - 设置活动地域
  51. /territory list plots - 所属领土列表
  52. /territory list players - 地域成员列表
  53. /territory flag <标志名称> (参数) - 为地域设置标志值(参看WorldGuard中标志名称)

  55. /plot add player <玩家名称> - 授予玩家该领土权限
  56. /plot add guest <玩家名称> - 让玩家成为该领土的客人
  57. /plot redefine - 重定义领土
  58. /plot remove <玩家/客人名称> - 从领土中移除权限。加-r彻底移除
  59. /plot active <领土名称> - 设置有效领土。命令后加-q可以不需先设置有效城镇和地域，直接定位该领土
  60. /plot list players - 查看领土内玩家列表
  61. /plot sign build - 创建交易木牌
  62. /plot sign demolish - 摧毁交易木牌
  63. /plot sign setpos - 在屏幕准星对着的位置创建交易木牌
  64. /plot info - 查看领土信息
  65. /plot flag <标志名称> (参数) - 设置flag
  66. /plot economy forsale <true/false> - 是否出售
  67. /plot economy setprice <价格> - 设置领土价格
复制代码


注：有效城镇/地域/领土指的是今后执行命令的地区。这是为了省去繁琐命令而设定的。

权限：
  1. mct.admin - 全部权限
  2. mct.removetown - 移除城镇
  3. mct.warp - 传送回自己城镇
  4. mct.warpforeign - 传送到其它城镇
  5. mct.createtown - 创建城镇
  6. mct.withdrawoutside - 在城镇外从银行取东西
  7. mct.flag - 设置flag

配置：
config.txt
= =很神奇，居然是TXT格式的、、

  1. # 启用经济
  2. economyEnabled = true
  3. # 镇长能够购买地域(Territory)
  4. mayorsCanBuyTerritories = true
  5. # 每格方块的价格
  6. pricePerXZBlock = 1

  8. # 购买地域(Territory)需要的城镇达到最少人口
  9. minNumPlayersToBuyTerritory = 3
  10. # 允许PvP
  11. allowTownFriendlyFireManagement = false

  13. #选择工具(用于定位区域)默认为木锄 (ID 290)
  14. quickSelectTool = 290

  16. #每条命令发布时记录冗长信息
  17. logCommands = false

城镇名称.yml

  1. # 城镇名称
  2. townName: pap
  3. # 所属世界
  4. worldName: world
  5. # MOTD信息
  6. motd: use /town motd set <message> to set MOTD!
  7. # MOTD字体颜色
  8. motdColor: GOLD
  9. # 出生点坐标及世界
  10. spawnLocation:
  11. - '-287'
  12. - '99'
  13. - '207'
  14. - world
  15. # 镇长
  16. mayor: test
  17. # 地域列表
  18. territs:
  19. - pap_territ_te
  20. # 助理列表
  21. assistants: []
  22. # 市民列表
  23. residents:
  24. - test
  25. # 是否PvP
  26. friendlyFire: false
  27. # 默认领土价格
  28. defaultPlotPrice: '10'
  29. # 需要金钱才能加入
  30. economyJoins: false
  31. # 领土可以购买
  32. buyablePlots: true
  33. bank:
  34. # 银行金钱
  35.   townFunds: '49616'
  36. # 银行方块
  37.   contents: ''
