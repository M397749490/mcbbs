简介
Ever wanted to see how good the loot capacitors found in dungeons are but were too lazy to look it up?  This mod is just for that.
Simply add it to your mods folder and the secrets will be revealed.
For reference, a basic capacitor has a level of 1, double is 2, and octadic is 3
Config available to turn off flavor text for easier readability
Note: Client-side only mod, will be ignored by servers.
从地牢箱子中搜索到一堆电容却不知其好坏？
被电容的无厘头说明给雷住？这个Mod就是你的最好选择
电容信息显示是末影接口的附属模组，使电容的属性在信息框中显示，默认所有类型的电容都显示
以等级的形式显示，基础电容是1级，双层电容是2级
八位电容是3级，这可作为你判断其他电容好坏的依据
没有这个Mod的情况下，你只能通过一次次的尝试来知道特殊电容的特性
[内心：我是个懒人啊]
同时它还会隐藏对电容说明文字，这些文字无用，数量多且不换行，导致信息框很大，对低分屏不太友好
以上的这些功能都能在配置文件中（.minecraft\config\lootcapacitortooltips.cfg）中修改

注意，它是客户端Mod，服务端无需安装

配置文件
.minecraft\config\lootcapacitortooltips.cfg
# Configuration file
# 配置文件
general {
    B:"Enable Flavor Text?"=false
    # 是否显示趣味性叙述文字？
    I:Precision=2
    # 数据精度
    B:"Show Durability of Totemic Capacitor?"=true
    # 是否显示不死图腾电容的耐久度？
    B:"Show Levels of Endergy Capacitors?"=true
    # 是否显示末影接口：管道拓展提供的的电容等级？
    B:"Show Levels of Regular Capacitors?"=true
    # 是否显示末影接口本身提供的一般电容的等级？
}
