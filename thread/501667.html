不知道该怎么取中文名,很简单的插件,多用性很强.
插件开启关闭均为英文提示,不做中文汉化(反正汉化了也没啥意义……)
请务必看到最后的如何使用！否则会出错！

注意：本插件要求你有独立的世界供给玩家登陆！ 独立的世界！ 使用mv/mw创建的世界也可以！ 一定要是独立的世界！！！！！
插件基于1.8.8 CraftBukkit编译,理论全版本通用，目前已知不兼容PaperSpigot1.7系列修改过CraftBukkitAPI的版本,其他兼容问题请在回复中反馈兼容性情况！
使用范例:
1> 游戏服务器,用来控制玩家在等待大厅的行为.
2> 普通生存服务器,模拟大服的登陆服. 高大上！


功能:
（所有功能都可控开关！）
-登陆传送到指定世界的指定点
-指定世界内禁止破坏方块
-指定世界内禁止放置方块
-关闭指定世界的天气
-指定世界虚空传送
-指定世界没有饥饿
-指定世界不会互相伤害
-加入游戏清空背包（MCBBS版初始关闭）
-加入游戏清空装备（MCBBS版初始关闭）
-加入游戏强行生存模式.
-指定世界禁止怪物生成
-对应事件提示信息
功能演示视频：
http://player.youku.com/player.php/sid/XMTMzNDg1MzIzMg==/v.swf

权限
无，op bypass一些破坏限制

命令
-setpoint  - 设置登陆地点 需要OP

安装方式:
1>下载
2>放到plugin目录里,开服,关服.
3>把解压的文件夹和.jar放到你的plugins文件夹中
4> 进游戏，在你想要玩家登陆传送的地方输入/setpoint
5> 完工！
配置文件及对应解释：
lobbyWorldName: YourWorldNameHere
#登陆服世界名字
break: false
#是否允许破坏
place: false
#是否允许放置
Weather: false
#是否允许天气
hunger: false
#是否允许饥饿
damage: false
#是否允许伤害
joinTeleport: true
#加入传送
voidTeleport: true
#虚空传送
joinInventoryClear: false
#加入清空物品栏
joinEquipmentClear: false
#加入清空装备栏
forceSurvival: true
#强制生存模式（加入）
preventSpawn: true
#禁止怪物生成
