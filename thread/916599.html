成了这个样子
![123](<a href="https://www.mcbbs.net/plugin.php?id=link_redirect&target=https%3A%2F%2Fupload.cc%2Fi1%2F2019%2F09%2F30%2Fh3TjwF.png" target="_blank">https://upload.cc/i1/2019/09/30/h3TjwF.png</a>)


我个人表示强烈不习惯
所以就找到了这个方法


原理


就是用插件和我们自己写的 CSS 将 MCBBS 在相关标签上强制加的 css 给“抹掉”。谁请的临时工
![123](<a href="https://www.mcbbs.net/plugin.php?id=link_redirect&target=https%3A%2F%2Fupload.cc%2Fi1%2F2019%2F09%2F30%2FVhQxLF.png" target="_blank">https://upload.cc/i1/2019/09/30/VhQxLF.png</a>)


方法


首先你需要一个插件，名字叫 User CSS
![123](<a href="https://www.mcbbs.net/plugin.php?id=link_redirect&target=https%3A%2F%2Fupload.cc%2Fi1%2F2019%2F09%2F30%2F8t0msO.png" target="_blank">https://upload.cc/i1/2019/09/30/8t0msO.png</a>)
目前该插件只支持 Chrome(和使用了这个核心的浏览器)。
下载地址(需科学上网): [User CSS](<a href="https://chrome.google.com/webstore/detail/user-css/okpjlejfhacmgjkmknjhadmkdbcldfcb" target="_blank">https://chrome.google.com/websto ... jkmknjhadmkdbcldfcb</a>)
本插件的离线安装版本可以在本帖附件找到。
Firefox 上应该也有相关插件能达到这个目的。
安装之后，打开 MCBBS，并打开 User CSS 的编辑窗口，输入下面的 CSS 代码:


#um { display: inherit!important; }

emm，然后你应该就能看到原来的用户信息界面了。
![123](<a href="https://www.mcbbs.net/plugin.php?id=link_redirect&target=https%3A%2F%2Fupload.cc%2Fi1%2F2019%2F09%2F30%2F3wglCt.png" target="_blank">https://upload.cc/i1/2019/09/30/3wglCt.png</a>)
