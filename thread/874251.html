枪械防御
插件特色
1.提供了枪械的绑定
2.这款插件可以根据lore进行判断枪械伤害的提升或者别人枪打自己伤害的降低

指令
/csa-reload - 重载插件

   配置文件
                                                                                      
                                          
  1. # 在 armors 中
  2. # <Material 名稱>:<抵禦傷害數值>
  3. # 若果數值是正數，則為抵禦傷害值
  4. # 若果數值為負數，則為傷害增量值
  5. # ===================================================
  6. # 在 armors 中
  7. # <Material 名称>:<抵挡伤害数值>
  8. # 若数字为正数，则为抵挡伤害数值
  9. # 若数字为负数，则为伤害增加数值

  11. diamond-armor:
  12.   # lore: support regex; 支持 regex 判断
  13.   lore: "Armor-DIAMOND"

  15.     - DIAMOND_BOOTS:1.1
