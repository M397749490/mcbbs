作者: Flowers_花花    时间: 2018-10-12 16:58
  1. @echo off&setlocal enabledelayedexpansion        
  2. set a=-1
  3. :ok
  4. set /a a+=1
  5. title 重启次数:%a% 【服务器名字】
  6. set /a s=3+1
  7. for /l %%i in (1,1,!s!) do (
  8. set /a s-=1
  9. color D
  10. ping -n %s% 127.1>nul
  11. echo 倒计时开始！ !s!)
  12. echo 服务器开始运行！
  13. java -Xmx3G -Xms1G -jar 核心名
  14. goto ok
  15. pause
复制代码

这个崩溃自带重启 把你的核心名字替换进去就行了
