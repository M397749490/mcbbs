3.修改配置文件
{:10_508:}礼袋中没有你想要获得的物品？就来修改配置文件吧！
必须要加载Mod运行过一次游戏，然后打开config文件里的lootbags.cfg文件进行修改。
3.1修改掉落概率

首先找到下面的文字进行修改

"drop chances" {
    # This is the resolution of the bag drop chances.  Only change this if you want bags with rarity resolutions > 0.1%
    I:"1 Weighting Resolution"=1000 【强烈建议不要修改！】{这里翻译过来是加权，涉及到权重知识。这里我猜测可能是权重的总和。
这里我把它称为总数，下面的掉落几率与这个有很大关系。修改可能造成游戏闪退！！！
}
# This controls the drop chance for monsters, passive mobs, and players for each bag in a resolution up to 0.1%.
   如果总数为1000时，200表示20%概率会掉落礼袋，1000则为100%。概率：数值/总数，这里的概率其实是权重。（最大值只能填总数，超过总数游戏会闪退！！！）
    I:"2 Common Bag Monster Drop Chance"=200  普通礼袋怪物掉落概率
    I:"2 Common Bag Passive Mob Drop Chance"=100 普通礼袋怪物掉落概率
    I:"2 Common Bag Player Drop Chance"=100 普通礼袋玩家掉落概率
    I:"3 Uncommon Bag Monster Drop Chance"=100 不同寻常礼袋怪物掉落概率
    I:"3 Uncommon Bag Passive Mob Drop Chance"=50 不同寻常礼袋怪物掉落概率
    I:"3 Uncommon Bag Player Drop Chance"=50 不同寻常礼袋玩家掉落概率
    I:"4 Rare Bag Monster Drop Chance"=50 稀有级礼袋怪物掉落概率
    I:"4 Rare Bag Passive Mob Drop Chance"=25 稀有级礼袋怪物掉落概率
    I:"4 Rare Bag Player Drop Chance"=25 稀有级礼袋玩家掉落概率
    I:"5 Epic Bag Monster Drop Chance"=25 史诗级礼袋怪物掉落概率
    I:"5 Epic Bag Passive Mob Drop Chance"=10 史诗级礼袋怪物掉落概率
    I:"5 Epic Bag Player Drop Chance"=10 史诗级礼袋玩家掉落概率
    I:"6 Legendary Bag Monster Drop Chance"=10 传奇级礼袋怪物掉落概率
    I:"6 Legendary Bag Passive Mob Drop Chance"=5 传奇级礼袋怪物掉落概率
    I:"6 Legendary Bag Player Drop Chance"=5 传奇级礼袋玩家掉落概率

    # This is the chance for any of the special hidden bags to appear, most are obtained by killing specific named entities.
    I:"7 Special Bag Drop Chance"=250 隐藏礼袋掉落概率，经测试未发现
}
如有错误，请反馈我修正


3.2---添加战利品中可获得的物品（白名单）和 删除战利品中可获得的物品（黑名单）
这个比较麻烦，首先需要找到物品的名字（不是ID）。
例如：工作台的名字是：minecraft:crafting_table

如果你只添加少量的原版物品，在这里查询物品名字
如果你要添加MOD的物品，推荐安装提取物品mod来获得物品名称。
mod获得物品名字教程：
先安装 提取物品名称ID的mod，启动游戏后在根目录找NameWakander文件夹

找到txt文件

用搜索工具找到要添加的物品
例如工业TNT：
IC2:blockITNT, ic2.blockITNT.name, 工业TNT, 0
找到后就取前面的英文IC2:blockITNT。


NEI获得物品名字教程：
点击E键，然后点击左下角的选项按钮，如果没有请按O键打开NEI

然后点击工具


点击数据存储


物品面板一定要是CSV，然后在物品按钮点存储


然后在MC目录的dumps文件里找到item.csv文件
打开后，就有物品的名称和ID了，包括原版和MOD的物品。{:10_513:}
如何找到对应的物品名称呢？


在游戏中查看ID，例如图中工业TNT 后面的“210”就是工业TNT的ID

然后在item.csv中搜索210 物品ID的左边就找到了工业TNT的名称：IC2:blockITNT

添加战利品中可获得的物品（白名单）
如果我想在普通礼袋中添加物品，该怎么做呢？
————添加方法——————
添加白名单格式：<物品名字> <id后面的（如果没有则为0）> <最大叠加数（不建议调太大）> <权重（数越大，出现概率越大，建议不要写小数）>
物品名字 （例如工业TNT）IC2 blockITNT（如果有“：”冒号要换成空格！）
id后面的： 例如：再生药水的ID是"373:8193"，水瓶的ID是"373"，如果要添加再生药水，则填8193。如果要添加水瓶，则填0。（如果是工具，则代表工具剩余的耐久）
最大叠加数：物品出现最大数量，如果是10，则出现数量为1-10。（不能为0）
权重：物品出现的概率，数越大，出现概率越大（不能为0）
权重大家可能不知道填多少，这里给个参考：
物品 权重
苹果 15
金苹果 1
书本 20
红石 5
马鞍 2
金锭 10
铁锭 5
腐肉 16
钻石 3
权重指打开单个礼袋出现的频率，并不指多个礼袋出现的频率。

例如：
IC2 blockITNT 0 64 15
代表工业TNT，最多64个，权重为15
在lootbags.cfg中找到下面的文字，找到对应的礼袋添加。
"whitelisted bag items" {
    # These whitelists are related to the associated bag type, so an item whitelisted in Common bags will not show up in other bag types.
    S:"Common Bag Whitelist"普通礼袋 <
  在这里添加想要的物品，例如工业TNT↓↓↓
    IC2 blockITNT 0 64 15
     >
    S:"Epic Bag Whitelist" 史诗级礼袋<
在这里添加想要的物品
     >
    S:"Legendary Bag Whitelist" 传奇级礼袋<
在这里添加想要的物品
     >
    S:"Rare Bag Whitelist" 稀有级礼袋<
在这里添加想要的物品
     >
    S:"Uncommon Bag Whitelist" 不同寻常的礼袋<
在这里添加想要的物品
     >
}
删除战利品中可获得的物品（黑名单）
在游戏中输入/lootbagsitemdump的指令，可在游戏目录的dumps的文件夹中找到LootBagsItemDump.txt的文件
找到“XXXX LootBags Drop Table XXXX”下的列表都是在游戏中礼袋可获得的物品和信息。

在lootbags.cfg中找到下面的文字，添加黑名单物品。
"blacklisted items" {
    # Adding a modid and internal item name or Ore Dictionary name to this list will prevent the bag from
dropping the item.  Tries for Ore Dictionary before trying through the modlist.The modlist must be in the form
<modid> <itemname> <damage> on a single line or it won't work right.  Example to blacklist iron ingots:
minecraft iron_ingot 0 <OR> ingotIron.  An entire modcan be blacklisted by just entering the modid and nothing
else.
    S:"Global Blacklist" <
        lootbags itemlootbag 0

        在这里添加黑名单的物品，例如青铜剑↓↓↓
        IC2  itemToolBronzeSword 0
     >
}


例如我要把工业2mod的青铜剑加入礼袋黑名单。
可以在LootBagsItemDump.txt文件找到这句话
IC2  itemToolBronzeSword  0  0.787  3
去除后面两个项目，变成下段文字：
IC2  itemToolBronzeSword 0
直接加入黑名单，礼袋中就不会出现青铜剑了。
3.3---其他设置
    S:"Max Tier Craftable"=Legendary （礼袋最高的级别，选择选项填入：None, Uncommon, Rare, Epic, Legendary.）

    I:"Maximum Items Per Bag"=5（每个礼袋最多获得的项目（格数），只能填1-5，不能多于5或少于1，不与下面的设置冲突）

    I:"Minimum Items Per Bag"=1（每个礼袋最少获得的项目（格数），只能填1-5，不能多于5或少于1，不与上面的设置冲突）

    I:"Number of Bags to Upgrade"=4（合成到下一等级的礼袋所需要的数量）


其他设置请到文件自行设置。

        customnpcs:npcCoinGold:0:1:64:20
        customnpcs:npcCoinDiamond:0:1:64:20
        customnpcs:npcCoinEmerald:0:1:64:20
