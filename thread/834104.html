将烧炼配方的type修改为blasting即为高炉的烧炼配方, 换成smoking即为烟熏炉的烧炼配方。原版中blasting/smoking配方比smelting的配方烧炼时间减半，所以速度快一倍。
例如
  1. {
  2.         "type": "smoking",
  3.         "ingredient": [
  4.                 {
  5.                         "item": "minecraft:rotten_flesh"
  6.                 }
  7.         ],
  8.         "result": "minecraft:rabbit_hide",
  9.         "experience": 0.1,
  10.         "cookingtime": 200
  11. }
复制代码
则用烟熏炉可烧炼腐肉成兔子皮.


现在村民的职业为如下格式
  1. {VillagerData:{profession:"minecraft:farmer",level:1,type:"minecraft:plains"}}
