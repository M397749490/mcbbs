怎么设置开启  木牌传送啊  ？？？？？？

单纯开启的话，请在essentials的config.yml里找到这个位置：
  1. # Essentials Sign Control
  2. # See http://wiki.ess3.net/wiki/Sign_Tutorial for instructions on how to use these.
  3. # To enable signs, remove # symbol. To disable all signs, comment/remove each sign.
  4. # Essentials Colored sign support will be enabled when any sign types are enabled.
  5. # Color is not an actual sign, it's for enabling using color codes on signs, when the correct permissions are given.

  7. enabledSigns:
  8.   #- color
  9.   #- balance
  10.   #- buy
  11.   #- sell
  12.   #- trade
  13.   #- free
  14.   #- disposal
  15.   #- warp
  16.   #- kit
  17.   #- mail
  18.   #- enchant
  19.   #- gamemode
  20.   #- heal
  21.   #- info
  22.   #- spawnmob
  23.   #- repair
  24.   #- time
  25.   #- weather
复制代码
将需要的木牌功能前面的#号删除后保存修改即可（你要的是warp）。记得重启服务器。

为什么  传送木牌  设置好了  为什么我就拿传送  其他玩家就不可以传送了？

服主和OP自己自然不用多虑，但其他玩家还有个具体的权限设定问题。嫌麻烦的可以直接给相应玩家组赋予essentials.warps.*权限，
  1.     [Warp]
  2. <Warp地点名字>
  3.       [玩家组]
  4.     [传送费用]
复制代码
自己要注意管住玩家，设好费用，不要滥用warp，不然卡死。。。
