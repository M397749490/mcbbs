新开地下城系统欢迎冒险者的加入！
强烈建议下载群共享内客户端，已经整合，插件齐全，保证游戏质量

（主城内有地狱门和末地门，在商店隔壁一层）

出了主城过了大桥有传送点
/warp sky                      传送到空岛
/warp xiaomogudao              传送到小蘑菇岛
/warp damogudao                传送到大蘑菇岛
/warp world                    传送到生存世界
/warp shop                     传送到系统商店（二层有收购）
/warp zhucheng                 传送回传送点
-----------------------------------------------
新手注意：野外偶尔刷怪 死亡扣钱 野外PVP开启 走出主城周围居民区有很多资源

不要随意破坏他人成果

不要贪心

不要占便宜没够，吃亏难受

破坏别人家被事主发现被打死，不负责

关于注册及登录

/register XXX                    XXX为密码 注册账号
/login XXX                       XXX为密码 登陆账号
/changepassword 老密码 新密码    更改密码
--------------
关于传送

/spawn                           传送到主城
/back                            传送到死去点或上一次传送点
/sethome                         设置家
/home                            传送到家
/myspawn                         回到床边
/tpa XX                          传送到玩家身边
/tpaccept                        玩家同意传送
/warp 监狱                       到达监狱
---------------
关于锁箱子

将牌子放置在箱子，显示[私有]和你的名字时，箱子上锁成功


关于系统命令
/money                           查看自己的钱数

/money pay 玩家名 钱数               将自己的钱转账给ID
---------------
关于领地
t为可以的，开启。
f不可以的，关闭。

/res create 领地名                   创建领地
/res remove 領地名                   删除领地
/res select size 领地名              查看你的保护区尺寸/价格
/res tp   地区名                     传送到某个保护区
/res set 领地名 权限 t/f             设置领地权限
/res pset 領地名 玩家姓名 权限 t/f   给其他玩家保护区权限
/res listall                         查看服务器内所有保护区列表
/res list                            查看属于你的保护区列表
/res area                            为你有的保护区添加/替换/移除一些区域

领地权限：
build-- 建造权限
use--使用权限（不包括箱子）
move--移动权限
container--使用箱子权限
piston--活塞权限
place--
destroy--是否允许毁坏
PVP--你的保护区内是否允许PVP（如果服务器未开启PVP，此权限无用）
tp--是否允许传送到这个保护区
admin--给予一个玩家设立此保护区权限的权利
subzone--为保护区设立子区域的权限
monster--保护区是否刷怪
animals--是否会生成动物
healing--保护区内是否会自动回血
tnt-----TNT
creeper--炸毁
ignite--点火
firespread--火势能否蔓延
bucket--保护区内能否使用桶
flow--液体能否流动
lavaflow--岩浆是否可以使用
damage--保护区内你是否会被物体伤害。


熔炉

附着在熔炉顶部的漏斗只会向矿石物品槽注入物品；附着在侧面的只会向燃料槽注入物品；下方的漏斗只会从成品槽抽出物品。
