简介

你是否曾想过为不同的世界设置不同的服务器资源包？或是只用一个命令切换当前的资源包？如果有，那这就是你需要的。

这款插件允许你为每个世界设置一个服务器资源包，或是为整个服务器设置一个，它还可以设置在多个世界中使用同一个资源包。

它也与BungeeCord平台上的Bungee Resourcepacks插件兼容，而且如果Bungee Resourcepacks已经应用了服务器资源包，那么它不会让客户端重新下载资源包。


它可以方便的做到诸如武器皮肤或是实现不同世界不同贴图的功能，rpg服应该比较需要这类功能
———————————————————————————————————————————————————————————————————————————————————
指令/权限

要执行任意一个/wrp命令，都需要 worldresourcepacks.command 权限


/wrp reload [resend]    权限：worldresourcepacks.command.reload    重新加载配置文件; 如果在reload后面加“resend” ，则重新给所有在线的玩家发送资源包


/wrp version   权限：worldresourcepacks.command.version   查看插件的版本


/wrp generatehashes  权限：worldresourcepacks.command.generatehashes   手动生成资源包的哈希值


执行任意一个/usepack命令，都需要 worldresourcepacks.command.usepack 权限


使其他玩家载入资源包需要 worldresourcepacks.command.usepack.others 权限


玩家如果要使用特定的资源包需要 worldresourcepacks.pack.<资源包名称>  权限或是在配置文件里另外配置的权限


/usepack   列出所有当前你可用的资源包


/usepack <资源包名称> <玩家名>  给指定的玩家载入指定的资源包

配置文件

配置文件汉化如下，直接复制黏贴即可
useauthme: false
debug: true
#是否在启动服务器时生成资源包的哈希值:
autogeneratehashes: true
messages:
  usepack: 你现在正在使用 %pack%资源包!
  packlisthead: "可用的资源包:"
  nopacks: 没有可用的资源包!
packs:
  lobbypack:
   # 资源包的链接必须可以直接下载！以文件名收尾的那种！
   # 说白了就是点开来什么都没有只会开始下载文件的那种链接！
    url: http://example.com/lobbyresourcepack.zip
   # 这里填写资源包文件的哈希值
   # bukkit不支持，所以写在这里的东西并不重要
    hash: abcdef012345678abcdef012345678abcdef0123
   # 资源包的真实版本,取决于ViaVersion!
   # 1 1.8以上
   # 2 1.9以上
   # 3 1.11以上
    format: 1
   # 玩家是否需要相应的权限才能使用资源包
   # 权限格式: bungeeresourcepacks.pack.<资源包名称>
    restricted: false
   # 如果你不想使用bungeeresourcepacks.pack.<packname>格式
   # 你也可以在这里自定义一个
    permission: bungeeresourcepacks.pack.lobbypack
  gamepack:
    url: http://example.com/minigameresourcepack.zip
    hash: 012345678abcdef012345678abcdef012345678a
  # Empty pack 是用来重置成默认材质用的空包，不建议改动，因为这里作者做好了现成的。
  emptypack:
    url: https://github.com/Phoenix616/Bu ... /Empty.zip?raw=true
    hash: 3934d29cc6f7c271afdc477f6dd6b2ea90493825
#在这里你可以配置空包的名称
empty: emptypack
server:
  pack: lobbypack
  # 如果用户正在使用这些资源包就不可更改的包的列表
  # 如果没有主资源包则第一个会被用来重置
  # 并列共存的资源包列表
  #secondary:
  #- lobbypack
  # 当玩家登入/传送到世界多久之后发送资源包
  send-delay: 10
worlds:
  lobby:
    pack: lobbypack
    #secondary:
    #- gamepack
  minigame:
    pack: gamepack
<blockquote>useauthme: false

说明

当服务器资源包发送到客户端时，它将在下载完成后立即冻结客户端。（与手动应用资源包相同）这是因为客户端必须重新加载所有资源，检查哪些资源重叠并对它们进行其他计算和操作。这不是下载或网速的问题，因为客户端将在本地缓存资源包文件，如果它们的哈希值没有改变就不需要重新下载它们。

这需要多长时间取决于PC的性能和纹理的大小（HD包需要更长时间），这些都是玩家应用的所有资源包中使用的。因此，即使服务器资源包不包含任何高清纹理或纹理，客户端仍将完全重新加载所有本地应用的资源包
