使用方法

游戏截图

messages.yml:
  1. plugin-prefix: '&6[&b%s&6]&r '
  2. reload-succeed: '&a插件重载成功!'
  3. help:
  4. - '&a============ &bInlay &6插件帮助 &a============'
  5. - '&e/Inlay help &d- &b查看帮助'
  6. - '&e/Inlay reload &d- &b重载插件'
  7. - '&e/Inlay list &d- &b查看所有宝石'
  8. - '&e/Inlay open &d- &b打开镶嵌界面'
  9. - '&e/Inlay see &d- &b查看已镶嵌的宝石'
  10. - '&e/Inlay give <玩家名> <宝石> <数量> &d- &b给予玩**石'
  11. - '&e/Inlay givescroll <玩家名> <数量> &d- &b给予玩家合成卷轴'
  12. only-player: '&c控制台无法使用此命令(&4请在游戏内执行&c)!'

  16. gui:
  17.   inlay: '&e&l镶嵌界面'

  20.   accept: '&e&l拆下宝石'

  24. nullslotlore: '&6[&a空槽&3<%s&3>&6]'

插件权限

Inlay.default  基础权限(默认给所有玩家)
Inlay.admin  管理员权限


插件命令

/Inlay help - 查看帮助

/Inlay reload - 重载插件

/Inlay list - 查看所有宝石

/Inlay open - 打开镶嵌界面

/Inlay see - 查看已镶嵌的宝石

/Inlay give <玩家名> <宝石> <数量> - 给予宝石
