在Mobs文件夹里编辑怪物 写出来就可以了
  1. mizhijuren:
  2.   Type: PIG_Zombie
  3.   Display: '&blv60&c迷之巨人'
  4.   Health: 7000
  5.   Damage: 50
  6.   DamageModifiers:
  7.   - FALL 0
  8.   - SUFFOCATION 0
  9.   AIGoalSelectors:
  10.   - 0 Clear
  11.   - 1 meleeattack
  12.   Equipment:
  13.   - yinlinggun:0
  14.   - xuedun:5
  15.   Drops:
  16.    - tongqian 64 1
  17.    - suiyin 1 0.2
  18.    - suiyin 1-2 0.2
  19.    - exp 500
  20.   BossBar:
  21.     Enabled: true
  22.     Title: '&a<mob.name> &a&l生命&8[&b&l<mob.hp>&f/&b&l<mob.mhp>&8]'
  23.     Range: 40
  24.     Color: GREEN
  25.     Style: SEGMENTED_20
  26.   Options:
  27.     AlwaysShowName: true
  28.     KnockbackResistance: 0.3
  29.     AttackSpeed: 14
  30.     FollowRange: 40
  31.     Silent: false
  32.     RepeatAllSkills: true
  33.     PreventRenaming: true
  34.     PreventOtherDrops: true
  35.     PreventRandomEquipment: true
  36.     PreventRenaming: true
  37.     Despawn: false
  38.     PreventItemPickup: true
  39.     PreventLeashing: true
  40.     PreventMobKillDrops: true
  41.     ThreatTable: true
  42.   KillMessages:

  44.   Skills:
  45.   - message{m="&d[&4魔界&d]&e歷經一陣天搖地動，<mob.name>&e出现在了经验副本！"} @PlayersOnServer ~onSpawn
  46.   - disguise{d=giant} [url=home.php?mod=space&uid=1326953]@self[/url] ~onSpawn
  47.   - skill{s=黄色跟踪} @Self ~onTimer:100
  48.   - skill{s=橙色跟踪} @Self ~onDamaged 0.1
  49.   - sendtitle{title="&a大捷!";subtitle="&blv60&c迷之巨人已被消灭!";d=200} @PlayersOnServer ~onDeath
