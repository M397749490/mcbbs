如何检测玩家指定的物品栏格位是否为指定物品？
然后执行replaceitem把这个格位替换成别的东西
是不是/replaceitem @p[]？
这个选择器能不能选择玩家指定物品栏格外的物品


用execute也行
作者: CR_019    时间: 2020-3-7 10:02
本帖最后由 chaoren019 于 2020-3-7 10:18 编辑

用目标选择器
例子（最内层3项可选）
@e[nbt={Inventory:[{Slot:1b,id:"minecraft:stone",Count:64b}]}]
Slot：指定槽位
id：指定物品名
Count：指定物品数量

replaceitem @p inventory.0 stone 2
修改玩家物品
这里的inventory指按下e键后的上面27个槽位，hotbar指快捷栏9个槽位，和nbt的inventory的Slot标签有所不同

检测用execute然后replaceitem：
  1. execute if data entity @p {Inventory:[{Slot:0b,id:"minecraft:iron_block"}]} run replaceitem entity @p container.0 minecraft:iron_ingot
复制代码
这条指令会把玩家物品栏第一格的铁块换成铁锭想检测其他槽位的话可以改成检测玩家背包是否有铁块，去掉Slot就行了，然后用clear清除铁块，再give玩家对应物品就行了
  1. execute if data entity @p {Inventory:[{id:"minecraft:iron_block"}]} run clear @p minecraft:iron_block
复制代码
但是想替换那个格子的话就比较麻烦了，要穷举
