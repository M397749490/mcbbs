因为物品模型里没有添加particle贴图，这是你发的材质包里的蘑菇煲模型（assets/minecraft/models/item/mushroom_stew.json）
  1. {
  2.         "credit": "Made with Blockbench",
  3.         "texture_size": [32, 32],
  4.         "textures": {
  5.                 "1": "item/mushroom_stew"
  6.         },
复制代码
要想显示吃食物的粒子需要添加"particle":"item/mushroom_stew",如
  1. {
  2.         "credit": "Made with Blockbench",
  3.         "texture_size": [32, 32],
  4.         "textures": {
  5.                 "1": "item/mushroom_stew",
  6.                 "particle":"item/mushroom_stew"
  7.         },
