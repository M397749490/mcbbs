在需要获得仇恨的实体头上生成个带owner与被仇恨实体UUID一致的雪球
比如说在单tick执行以下命令
  1. execute as @e[type=skeleton] at @s run summon snowball ~ ~2.5 ~ {Motion:[0.0d,-10.0d,0.0d],Tags:["temp"]}
  2. execute at @e[type=skeleton] as @e[tag=temp,limit=1,sort=nearest] run data modify entity @s Owner set from entity @e[type=armor_stand,limit=1,sort=nearest] UUID

任意玩家的UUID怎么测？
作者: 晴路卡    时间: 2020-7-18 22:15
HtYang 发表于 2020-7-18 22:09
任意玩家的UUID怎么测？

你把最后那段“from entity @e[type=armor_stand,limit=1,sort=nearest] UUID”的选择器改成玩家的就行了
比如说
  1. execute as @e[type=minecraft:iron_golem] at @s run summon snowball ~ ~4.5 ~ {Motion:[0.0d,-10.0d,0.0d],Tags:["temp"]}
  2. execute at @e[type=minecraft:iron_golem] as @e[tag=temp,limit=1,sort=nearest] run data modify entity @s Owner set from entity @e[type=minecraft:player,limit=1,sort=nearest] UUID
复制代码

就是让铁傀儡攻击最近的玩家
你自己比较下几个不同的地方
