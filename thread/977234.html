此插件用于缓解   多世界背包插件导致的游戏性降低问题

让服主可以在 不区分背包 的情况下
对玩家物品进行 “软限制”
从而增加多世界间的关联性
调和服务器的整体游戏性

案例

玩家 A
携带了违禁品 B C D 在背包 或 装备栏
他通过传送门 或 指令 或 其他插件的传送
到了世界 X 或 Y 或 Z
XYZ 三个世界都属于 违禁品受限世界
那么玩家 A 的传送将被取消
回到主世界主城

彩蛋功能

由于本为限制拔刀剑在其他世界的平衡性
因此顺带修复了一个假刀BUG
玩家在右键的时候Q丢刀，会丢出一个真刀留下一个假刀
1.12.2版的最新版拔刀剑貌似仍然存在此问题
故加了对玩家在拔刀右键后Q键的监测
由于是附带功能，不喜欢的话也可以直接在config里把它关了
↓↓↓

配置文件

# 前缀
Prefix: "&b[Snowk]&e"
# 主功能 - 传送检测是否开启
enableTeleportListener: true
#在这里添加你要限制的世界（支持多个世界）
BannedWorlds:  
  - world
  - DIM-1
# 发现禁用物品后，传送玩家回主城的坐标 world, x, y, z
spawnWorld: world
spawnPosX: 206
spawnPosY: 72
spawnPosZ: 324

# 禁用的物品ID
bannedItemId:
  - 336
  - 4280
  - 1
  - 4282

# 彩蛋功能 - 拔刀剑假刀BUG修复器
# 改为 false 可关闭功能
enableBladeBugFixer: true
# 填入你服务器内拔刀剑的所有ID
bugItemId:
  - 4279
  - 4280
  - 4281
  - 4282
  - 4283

# 消息列表 - 可以改为任意消息，支持中英文，颜色符号&，§ 皆可
MessageRejectItem: "在传送时，检测到您携带了违禁品，请检查背包 物品ID： &c"
MessageTeleportBack: "您被禁锢在了主城"
MessageLock1: "您在进行右键的同时，该物品无法被丢出！ "
MessageLock2: "物品§c已上锁§e，需要 §a切换手持物品 §e来解锁丢弃"
MessageUnlock: "锁定已解除"
MessageReload: "插件重载成功！"
MessageReloadState1: "传送监测功能已启用"
MessageReloadState2: "传送监测功能已禁用"
MessageReloadState3: "拔刀剑SA刷刀修复器已启用"
MessageReloadState4: "拔刀剑SA刷刀修复器已禁用"
MessageNoPermission: "尚无相关权限组"
