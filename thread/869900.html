作者: 叽叽小石头    时间: 2019-5-31 07:39
修改GroupManager配置文件config.yml
  mirrors:
        # 多世界设置,世界列表中子世界将参照父世界的设置.
        # 第一个世界 'world' 是主世界名称
        # 子世界 'world_nether' 和 'world_the_end' 将会
        # 与父世界使用相同的玩家/用户组文件.
        # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
        # all_unnamed_worlds将会使用所有未定义的世界        #主世界名称一般为world，这里改成你的主世界名称
        world:
          #子世界名称，
          #需要继承主世界权限的世界
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          # all_unnamed_worlds其他全部世界
          all_unnamed_worlds:
          - users
          - groups
