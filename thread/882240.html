通过前四章的教学，我们的光影效果也逐渐完整。现在请你加载这个光影后进入水下，有没有一种违和感？是的，水下的世界同样看的很清晰，这是因为缺少雾导致的。在现实世界中无时无刻存在着雾，当我们向远处眺望时，远处的事物会变得朦胧。在MC中，眺望远处同样可以有朦胧的效果，这一章我们就向世界中添加雾来实现这个效果。

开始编写光影文件

这次我们需要同时对三个渲染器共六个文件进行更改，分别是gbuffers_textured、gbuffers_skybasic和gbuffers_textured_lit，但是更改的内容是一致的，我这里之说其中之一。

gbuffers_textured.vsh：
  1. #version 120

  3. varying vec4 color;
  4. varying vec4 texcoord;

  6. void main() {
  7.     vec4 position = gl_ModelViewMatrix * gl_Vertex;
  8.     gl_Position = gl_ProjectionMatrix * position;
  9.     gl_FogFragCoord = length(position.xyz);
  10.    
  11.     color = gl_Color;
  12.     texcoord = gl_TextureMatrix[0] * gl_MultiTexCoord0;
  13. }
复制代码
gbuffers_textured.fsh：
  1. #version 120

  3. uniform sampler2D texture;
  4. uniform int fogMode;

  6. varying vec4 color;
  7. varying vec4 texcoord;

  9. void main() {
  10.     gl_FragData[0] = texture2D(texture, texcoord.st) * color;
  11.    
  12.     if(fogMode == 9729)
  13.         gl_FragData[0].rgb = mix(gl_Fog.color.rgb, gl_FragData[0].rgb, clamp((gl_Fog.end - gl_FogFragCoord) / (gl_Fog.end - gl_Fog.start), 0.0, 1.0));
  14.     else if(fogMode == 2048)
  15.         gl_FragData[0].rgb = mix(gl_Fog.color.rgb, gl_FragData[0].rgb, clamp(exp(-gl_FogFragCoord * gl_Fog.density), 0.0, 1.0));
  16. }
复制代码

代码解释

首先看一下我们都干了些什么，这些文件都是在第三章中创建的，这里只解释更改的内容。
在顶点着色器中，我们把gl_Position = ftransform()换成了三行代码。之前用的是MVP全自动变换(第二章中有解释)，但是很多光照计算和雾计算是发生在MV变换后P变换前，所以我们要把MVP变换拆出来。
在片段着色器中，定义了一个雾类型变量uniform int fogMode，OptiFine会把雾的类型传递到这个变量中。在MC中，我们看到的雾分为两种：一种是我们大多数时间看到的线性雾，OptiFine有一个放大功能，默认是C键，放大后看远处会有朦胧感，这就是线性雾的效果；另一种是指数雾，我们到水下后，只有眼前极近的距离能看清楚，稍微远一点就看不清了，这是因为雾在按照指数级增长。
之后，我们用if-else的方式判断雾的类型，其中，9729为线性雾，2048为指数雾。在if分支中，分别实现最基本的线性雾和指数雾。
