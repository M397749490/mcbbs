突发奇想用了一天的时间做出来的一个随机数生成器。

用法：

导入完数据包后当然得用个命令来使用。
  1. summon minecraft:area_effect_cloud ~ ~ ~ {Tags:[数据],Duration:数据}
  2. #如果在function里执行上方命令，请务必再跟随此条命令: function random:main  
复制代码
Tags内可填入(请勿填两个，楼主都不知道会发生什么):      
   set_random_number（生成随机数）
     生成一个名字和标签为random_system的效果云，并携带着0~n(可在Duration里自定义n)之间
     分数的random_number（计分榜）。若已存在random_system，则会清除旧的random_system。
   clear_random_number（清除随机数）
     清除场上的random_system跟random_number。这条基本没有太大用处 ，可无视(=v=)

Duration内可填入:
   0~2147483647（最大随机数生成范围）
     也就是随机数最大会生成到哪，比如写Duration:100那么生成的random_system的random_number
     就会是0~100以内的某个数字。

使用上面的指令生成出一个random_system后，它的random_number计分榜分数就是一个随机数,
可以将这个计分榜放进需要随机数的系统当中。


例子：
如果循环下面的命令就会一直给全体玩家一块铁锭或金锭或是钻石，并且获得钻石的几率最小。
  1. summon minecraft:area_effect_cloud ~ ~ ~ {Tags:[set_random_number],Duration:10}
  2. #function random:main  在function里执行请写入这条命令
复制代码
生成一个随机数。
  1. execute if entity @e[name=random_system,scores={random_number=0..5}] run give @a minecraft:iron_ingot 1
  2. execute if entity @e[name=random_system,scores={random_number=6..9}] run give @a minecraft:gold_ingot 1
  3. execute if entity @e[name=random_system,scores={random_number=10}] run give @a minecraft:diamond 1
复制代码
侦测random_system的random_number随机分数,并执行对应的命令。


原理：
这里就说点核心命令
在获取到最大随机数后计算此数字以二进制方式需要多少位数
  1. execute if score @e[name=random_system,limit=1] system_number matches 2.. run scoreboard players add @e[name=random_system] time_random 1
  2. #（system_number是最大随机数 ，time_random是二进制位数，初始为1）如果可以除2加一个位数
  3. execute if score @e[name=random_system,limit=1] system_number matches 2.. run scoreboard players operation @e[name=random_system] system_number /= @e[name=random_system] 2_random
  4. #2_random是2用来当除数 ，将system_number数除2
  5. execute if score @e[name=random_system,limit=1] system_number matches ..1 run scoreboard players set @e[name=random_system] system_number 0
  6. #如果system_number不可以除2,则将system_nomber设为0
  7. execute if score @e[name=random_system,limit=1] system_number matches 2.. run function random:times
  8. #如果system_number还可以除2则递归，也就是会除到不能除以2位置
复制代码


求完位数后将给随机分配给每个位数1或0 （得使用计分板模拟一串二进制数字，不知道有没有更好方法）
  1. scoreboard players operation @e[name=random_system] random_number += @e[tag=random_system,sort=random,limit=1] system_number
  2. #（random_number就是要生成的随机数，system_number在这边初始分数是1跟0）给random_number的位数"1"或是"0"
  3. scoreboard players operation @e[name=one] system_number *= @e[name=random_system] 2_random
  4. #（@e[name=one]的system_number代表“1”，而@e[name=random_system]的代表“0”）为了要进位所以"1"得乘2
  5. execute if score @e[name=random_system,limit=1] time_random matches 1.. run scoreboard players remove @e[name=random_system] time_random 1
  6. #time_random（位数）要减1
  7. execute if score @e[name=random_system,limit=1] time_random matches 1.. run function random:random_number
  8. #如果还可以进一位则递归
复制代码
最后如果生成的随机数不在最大随机数以内则重新生成随机数
