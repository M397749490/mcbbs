推荐frp
详细地址https://github.com/fatedier/frp
我这里特地下了一个讲解一下怎么配置配置frp服务端
编辑frps.ini文本
  1. [common]
  2. bind_port = 7000
复制代码

然后运行命令行frps -c frs.ini配置frp客户端

编辑frpc
  1. [common]
  2. server_addr = 127.0.0.1
  3. server_port = 7000 #服务器的端口根据服务器bind_port

  5. [ssh]
  6. type = tcp
  7. local_ip = 127.0.0.1
  8. local_port = 22 #本地要映射的端口
  9. remote_port = 6000 #映射到服务器的端口
复制代码
然后frpc -c frc.ini
然后你就可以访问服务端的ip:6000的方式访问
建议可以加入
token = 12345678 #服务器连接密码
这样可以防止别人用你的机器来映射他的端口
更多详细配置可以看github里面的说明
