插件介绍：
这是一个非常简单的插件，作用是玩家死亡后随机复活。修复了地狱和末地的bug（目前仅有极小概率复活在地狱基岩层上）。还可以设置不同的世界不同的复活规则喔。大学时间多了持续更新哈哈


截图：





目前是以死亡位置为中心的一定矩形范围内随机复活哦~


指令：
/rr set 设置当前世界随机范围，输入指令后有详细说明。
/rr setworld [true/false] 设置当前世界是否使用随机复活规则。
/rr size 查看当前世界随机复活范围。
/rr reload 重新加载配置文件(修改配置文件后使用)
/rr 查看插件介绍
/rr [?/help] 查看帮助
注意：set setworld size这三个指令在控制台不能使用只能在游戏中输入。（以后会解决这个）


权限节点：
RandomRespawn.default插件普通指令权限 所有人都拥有
RandomRespawn.user随机权限 所有人都拥有（若玩家无此权限则不随机重生）
RandomRespawn.reload重载权限 op拥有
RandomRespawn.set设置权限 op拥有

注意：
  • 此插件要在ess重生设置为highest以下才可生效（默认是lowest所以一般情况下均可生效）。


已知BUG：
  • 有很小几率卡住（破坏方块即可，也可以传送走，一般出现在网络不好的情况，所以建议随机范围调小）
  • 有几率重生在不安全的地点（火，地狱基岩层上）
