提示： A player with the same IP is already in game!

作者: Goodlucky31    时间: 2016-12-25 13:22
也许你装了限制单IP登录指定个帐号的插件，那么别人开小号进服就无法了，
也可能你装了上面那个插件后 但你服务端设置出错，导致全部人进服IP都显示127.0.0.1

群组服解决办法是：
在服务端下的spigot.yml文件打开
  bungeecord: true
即可。
