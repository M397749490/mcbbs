ClearFlanBullet

定时清理Flan's Mod的子弹实体


  • 插件作用：
因为装有Flan's Mod的服务器玩家射出的子弹过多卡在区块边缘(无法达到未被加载的区块)又没有碰撞的机会所以这些子弹实体会一直卡在那儿，累积过多的子弹实体会浪费服务器资源。而此插件可以定时清理这些子弹实体，减轻服务器没必要的负担。


  • 插件配置：
# 清理子弹实体的间隔时间(秒)
ClearFlanBulletSecondTime: 360
# 是否开启清理时的公告通知
Broadcast: true
# 清理时公告通知内容，可自定义
BroadcastMessage: §6[§bClearFlanBullet§6]§a哎呀呀，这次清理了 §d{BulletAmount}个 §a子弹，这东西要是被人捡到可危险惹~

  • 指令：
/cfb clear  手动清理Flan's Mod的子弹实体
/cfb reload  重载插件配置


  • 权限：
  1. permissions:
  2.   cfb.*:
  3.     description: Clear flan's mod bullet.
  4.     default: op
  5.     children:
  6.       cfb.help: true
  7.       cfb.clear: true
  8.       cfb.reload: true
  9.   cfb.help:
  10.     description: Clear flan's mod bullet help.
  11.     default: false
  12.   cfb.clear:
  13.     description: Manual clear flan's mod bullet.
  14.     default: false
  15.   cfb.reload:
  16.     description: Reload the plugin configuration.
  17.     default: false
