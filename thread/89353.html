说明
装上mod你将具有的能力
  • 像鹰一样飞翔!
  • 炸飞一切（Blow shit up!）= =
  • 使靠近你的生物着火!
  • 跳得非常高!
  • 在水下呼吸和鱿鱼一起嬉戏!


BUGS
- 依然会受到火焰伤害

按键说明：
钢铁侠套装的使用（装备全套钢铁侠套装后按相应的键使用）:

z = 射出一只箭

x = 发出粒子特效 (在作者学会之前这个功能是无效的-。-)

c = 在你周围产生爆炸

v = 在你瞄准的地方产生火焰

b = 爆炸！

space = 飞

shift = 滑翔


合成：










套装效果展示：

飞行

着火

射箭

爆炸



安装方法：
1下载安装forge
2.删除minecraft.jar内的MATA-INF文件夹
3.将压缩包放在mods文件夹里
4.开始游戏

你可以在config文件夹里可以更改相关的id
