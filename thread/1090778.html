解决方法来源于网络，无非是进PE后执行以下四行命令

  1. cd [PE下你的系统盘盘符]:\windows\system32
  2. bcdedit /set {default} osdevice boot
  3. bcdedit /set {default} device boot
  4. bcdedit /set {default} detecthal 1
