标题: this关键字引用构造函数出错
源代码如下：

public class javaTest2
{
        private String name="asd";
        private int age=5;

        public javaTest2()
        {
                this(name, age);//报错-显式调用构造函数时不能引用实例字段
                                        //修改途径通过静态这两个成员变量就可以编译通过，求回答为什么能通过
        }

        public javaTest2(String name, int age)
        {

                this.name = name；
                this.age = age;
                System.out.println(age + "岁的" + name + "诞生了！");
        }

        public static void main(String[] args)
        {
                new javaTest2();
        }
}

作者: qianji20000420    时间: 2017-4-15 00:58
个人的一点见解：
类的静态成员变量是程序访问了类的某个静态变量或者是静态方法的时候分配的空间   而构造函数也是可以抽象为一种静态方法   那么静态的成员变量在调用构造函数的时候就已经初始化完成了。
而如果是非静态的成员变量  在你没有实例化完这个对象的时候是不可直接调用这个没有实例化的字段的。
