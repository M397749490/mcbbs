复制代码
这段代码先导入了bukkit里的一些插件包（Spigot的插件基于Bukkit插件开发），然后新建一个主类，继承了JavaPlugin，注意看里面的两个重写的方法，一个是onEnable(),一个是onDisable(),这两个代码重写的是什么呢？onEnable是指服务器插件被启用，当服务器插件启用时，执行onEnable()，onDisable()是指服务器插件被关闭，当服务器插件被关闭时（可以是服务器关闭，可以说插件重载），执行onDisable的事件。

我们今天的第一个任务就是让服务器控制台启用插件时说“mrmen插件被启用”，这个比较简单，而且Java新手都能看懂这个代码。
只需要一个System.out.println()，就可以往控制台输出信息

在onEnable添加代码System.out.println("mrmen插件被启用")
  1. package mc.mrmen;

  3. import org.bukkit.plugin.java.JavaPlugin;

  5. public final class Mrmen extends JavaPlugin {

  7.     @Override
  8.     public void onEnable() {
  9.         // Plugin startup logic
  10.         System.out.println("mrmen插件被启用");

  12.     }

  14.     @Override
  15.     public void onDisable() {
  16.         // Plugin shutdown logic
  17.     }
  18. }
复制代码

这样一个最简单的插件就完成了，我知道各位正在阅读本帖的人想象力很丰富，可能会尝试搞多行System.out.println(),这个是没关系的，想搞多少行就搞多少行，你可以试着在onDisable()写System.out.println()

我们写好了代码，如何生成jar包呢？
很简单，直接运行这个代码，然后会在控制台出现一大坨东东。
如果你看到BUILD SUCCESS的话，那你就成功了！你可以在你的项目文件管理器
