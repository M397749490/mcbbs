Mod介绍




这个MOD增加了许多非常酷的方块来伪装你周围的环境。MOD里的每个方块都有极为有用的功能，它可以让你非常简单的把你心爱的钻石隐藏起来，或者是惩罚每一个试图去偷钻石的玩家。隐藏的门和压力版，隐藏的拉杆甚至是更多。你需要特别注意的是那些幽灵方块，这些方块是处处可见的，可是有的方块你却可以正常地步行穿过它。如果你是擅长做陷阱的可怕的男人，谁又会有胆量到一个到处充满岩浆陷阱的房间来偷盗你的钻石呢？





物品介绍








  • 1. 伪装箱子   默认ID=4081

放到地下后，它会伪装成周围方块的样子，有箱子的特性。

  • 2. 伪装楼梯   默认ID=4082

放到地下后，它会伪装成周围方块的样子，有楼梯的特性。

  • 3. 伪装压力板Ⅱ   默认ID=4083
放到地下后，它会伪装成周围方块的样子，他是一个比较特殊的压力板，用于红石信号的电源。
  • 4. 伪装压力板Ⅰ   默认ID=4084
放到地下后，它会伪装成周围方块的样子，他是一个比较特殊的压力板，用于传播红石信号。
  • 5. 伪装按钮   默认ID=4085
放到地下后，它会伪装成周围方块的样子，有按钮的特性。
  • 6. 伪装红石   默认ID=4086
放到地下后，它会伪装成周围方块的样子，有红石的特性。
  • 7. 伪装拉杆   默认ID=4087
放到地下后，它会伪装成周围方块的样子，有拉杆的特性。
  • 8. 幽灵方块   默认ID=4088
放到地下后，它可以被穿透，也就是说可以穿过它。
  • 9. 伪装活板门   默认ID=4091
放到地下后，它会伪装成周围方块的样子，有活板门的特性。
  • 10. 伪装伸缩方块   默认ID=4093
放到地下后，它会伪装成周围方块的样子，一旦有红石激活它，他就会伸缩到你放置它的方向的格数为10格，例如你从右面把它方下它就会在激活时往右面伸到10格，当红石没有激活它时，它又会变回1格。
  • 11. 伪装玻璃   默认ID=4094
放到地下后，它除了伪装的一面是周围方块的样子，其余的面都是玻璃。
  • 12. 火把拉杆   默认ID=4095
放到地下后，它会伪装成火把，有拉杆的特性，不过依然会照亮周围。
  • 13. 伪装木门   默认ID=4362
放到地下后，它会伪装成周围方块的样子，有木门的特性。
  • 14. 伪装铁门   默认ID=4363
放到地下后，它会伪装成周围方块的样子，有铁门的特性。
  • 15. 伪装火焰弹   默认ID=4364
它是合成以上伪装物品的必要品。





合成














配置文件

配置文件是.minecraft/config文件夹下的SecretRoomsMod.cfg文件，用记事本打开。
# Configuration file
# Generated on 13-1-19 下午1:55
####################
# camoblocks
####################
camoblocks {
    I:camoButtonBlock=4085（翻译：伪装按钮的物品ID）
    I:camoChestBlock=4081（翻译：伪装箱子的物品ID）
    I:camoGate=4093（翻译：伪装伸缩方块的物品ID）
    I:camoGateExt=4092（翻译：伪装伸缩方块扩展的物品ID）
    I:camoIronDoor=4089（翻译：伪装铁门的物品ID）
    I:camoLeverBlock=4087（翻译：伪装拉杆的物品ID）
    I:camoPlateAllBlock=4084（翻译：伪装压力板Ⅰ的物品ID）
    I:camoPlatePlayerBlock=4083（翻译：伪装压力板Ⅱ的物品ID）
    I:camoRedstoneBlock=4086（翻译：伪装红石的物品ID）
    I:camoStairBlock=4082（翻译：伪装楼梯的物品ID）
    I:camoTrapDoor=4091（翻译：伪装活板门的物品ID）
    I:camoWoodDoor=4090（翻译：伪装木门的物品ID）
    I:ghostBlock=4088（翻译：幽灵方块的物品ID）
    I:oneWay=4094（翻译：伪装玻璃的物品ID）
    I:torchLever=4095（翻译：火把拉杆的物品ID）
}
####################
# camoitems
####################
camoitems {
    I:camoIronDoor=4107（翻译：伪装铁门的物品ID）
    I:camoPasteID=4108（翻译：伪装火焰弹的物品ID）
    I:camoWoodDoor=4106（翻译：伪装木门的物品ID）
}




安装方法

  • 1.下载密室MOD压缩包。
  • 2.剪切到.minecraft/mods文件夹里。
  • 3.打开游戏享受吧
