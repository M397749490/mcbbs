  RedisBungee

#注意: RedisBungee 不是 Redis



一、插件介绍

RedisBungee 是一个可以将你的多个BungeeCord服务器连接起来的插件,适用于一些中大型服务器适用.

Github

注意: RedisBungee 是 BungeeCord 插件



二、安装教程

1.  需要一个 RedisBungee 插件(请自行购买)

2. 需要2个BC服务器或者更多也可以

3. 一个 Redis(非插件) 大于或者等于 2.6的版本

4. Java7 或者 Java8



三、插件特性

拥有良好的稳定性

在进入游戏界面显示所有BC代理总人数

使用 Redis 进行后端储存(机翻)

拥有API供开发者使用 JavaDoc地址

覆盖 /glsit,/find 等指令

添加 /sendtoall 指令(将一个指令发送至所有BC服务器)




四、 配置文件

  1. # RedisBungee 配置文件.
  2. # 请阅读维基百科: http://minecraft.imaginarycode.com/

  4. #Redis 服务器IP
  5. redis-server: 127.0.0.1
  6. #Redis 服务器 端口(默认 6379)
  7. redis-port: 6379
  8. #Redis密码,如果你的没有Reids密码 请设置为 required
  9. # 如果你的Redis密码为 纯数字 请删除 ""
  10. redis-password: ""
  11. # Redis服务器最大连接数.
  12. # 默认值为 8. 请不要改变这个值,除非你有一些
  13. # 插件或者大量的玩家.
  14. max-redis-connections: 8

  16. # 服务器名字(可随意取,但绝不要重复!)
  17. server-id: test1

  19. #是否启用 RedisBungee 指令,请用该选项会覆盖 glist 和 find
  20. #
  21. #如果你的BC版本是 787+ 请删除 modules.yml 以及 modules 文件夹 里面的
  22. # - jenkins://cmd_find - jenkins://cmd_list
  23. register-bungee-commands: true

  25. # 白名单IP
  26. # RedisBungee 不会进行任何操作
  27. exempt-ip-addresses: []
复制代码


五、插件指令

命令
权限
用法
/glist
bungeecord.command.list
/glist 显示当前BC服务器在线.
/glist showall显示所有BC服务器在线.
/find
bungeecord.command.find
/find <玩家> 查询该玩家在哪个BC服务器.
/lastseen
redisbungee.command.lastseen
/lastseen<玩家> 查询该玩家最后在线时间.
/ip
redisbungee.command.ip
/ip <玩家> 查询该玩家IP.
/sendtoall
redisbungee.command.sendtoal
/sendtoall <指令> 给所有BC服务器发送指令.
/serverid
redisbungee.command.serverid
/serverid 查询该BC服务器的名字.
/serverids
redisbungee.command.serverids
/serverids 查询所有BC服务器名字.
/pproxy
redisbungee.command.pproxy
/pproxy <玩家> 检测该玩连接的BC服务器.
/plist
redisbungee.command.plist
/plist 显示当前BC服务器在线人数

/plist <server> showall

显示 <server> BC服务器在线人数




六、安装Redis(重点)


Redis 支持 64位 或者 32 位,这里要看你个人的选择了

Windows 版本:
下载地址
1. 选择你要下载的版本 这里我下载了 3.0.504.msi 版本(另外分 msi 和 zip 版本 根据个人喜好)

2. 当你安装后 找到Redis路径 打开 redis.windows.conf 文件

搜索找到 #requirepass

删掉 # 号 改为
  1. requirepass 你的密码
  2. #如果不需要密码 请勿删除 # 号
复制代码
这样你就完成了密码的设置!

3. 运行 Redis,打开 Cmd控制台(win+X), 用 控制台 选择你的 Redis文件路径

使用命令登录 Redis
  1. redis-cli.exe -h 127.0.0.1 -p 6379 -a 123456
  2. #h: Redis Ip
  3. #p: Redis 端口
  4. #a: Redis 密码
复制代码
你可以输入 ping 来测试 是否连接
