马铃薯枪MOD
鄙人已完全汉化
一、mod介绍
大家好！这是我的新MOD，马铃薯枪mod。不过，它实际上是增加了马铃薯和胡萝卜的各种武器。这里有mod的所有合成，图片，描述。

三、武器
马铃薯：
马铃薯主要是用于马铃薯枪，但它也可以成为弹药。
马铃薯枪：

  • 武器类型：枪/弓
  • 弹药：马铃薯
  • 伤害：1 / 2&#10084;（如果完全加载会造成4&#10084;）

毒马铃薯枪：

  • 武器类型：枪/弓
  • 弹药：毒马铃薯
  • 伤害：1 / 2&#10084;（如果完全加载会造成4&#10084;）
  • 特殊：使目标进入中毒形态

马铃薯火箭筒：

  • 武器类型：抛掷爆炸炸弹枪
  • 弹药：马铃薯手榴弹
  • 爆炸水平：水平很弱（爆炸很弱，只会打破沙石和硬度底的方块）
  • 撸主发现能力：它能把生物炸很远，如果爆炸正对生物那么它会把生物炸飞200-500米高
马铃薯手榴弹：
  • 武器类型：抛掷爆炸炸弹
  • 爆炸水平：水平很弱（爆炸很弱，只会打破沙石和硬度底的方块）
  • 撸主发现能力：它能把生物炸很远，如果爆炸正对生物那么它会把生物炸飞200-500米高
马铃薯炸弹
  • 武器类型: 爆炸方块
  • 爆炸水平：普通TNT爆炸大小
马铃薯核弹
  • 武器类型：爆炸方块
  • 爆炸水平：4个普通TNT大小

胡萝卜：
胡萝卜主要用于胡萝卜弓，但你也可以把胡萝卜做成剑。
胡萝卜弓：
  • 武器类型：枪/弓
  • 弹药：尖锐的胡萝卜
  • 伤害：1 / 2&#10084;（如果完全加载会造成4&#10084;）
金胡萝卜弓
  • 武器类型：枪/弓
  • 弹药：尖锐的胡萝卜伤害：1 / 2&#10084;（如果完全加载会造成4&#10084;）
  • 特殊：使目标中毒，可以很容易地杀不死生物和毒死苦力怕

胡萝卜剑
  • 武器类型：剑
  • 伤害：2&#10084;
  • 耐久度：33

四、作物/食物
  • 豪华的马铃薯：

恢复7个饥饿度。
  • 金马铃薯

恢复10个饥饿度并获得抵抗提升形态。
  • 煮熟的胡萝卜/马铃薯：
恢复3个饥饿度。
  • 腐烂的胡萝卜/马铃薯：

恢复1/2个饥饿度并让你中毒。把它们放在工作台上可以把它们变成可以种植的。
五、目前已知BUG
  • 马铃薯手榴弹有巨大的爆炸威力。
  • 枪/弓发出的实体不可以看见，马铃薯炸弹的实体只是一个白色立方体。
  • 方块被马铃薯炸后可能会不正常更新。
  • 腐烂的胡萝卜/马铃薯不会生成。

这就是我所知道的错误。请报告任何你发现的错误或通过私信来告诉我。如果你有任何问题，我会尽快帮你解决。
六、安装方法
客户端：
  • 1.如果你没有安装Forge，那么请在这里下载并安装Forge，Forge安装方法：打开Forge压缩包把里面的内容全部拖入.minecraft/bin文件夹下的minecraft.jar文件里，注意安装前先备份一个minecraft.jar文件，防止安装失败后无法打开游戏。
  • 2.下载马铃薯枪MOD的压缩包。
  • 3.把下载到的压缩包文件剪切到.minecraft/mods文件夹下（如果没有mods文件夹请自行创建）。
  • 4.打开游戏享受吧！
服务端：
  • 1.如果你没有安装Forge，那么请在这里下载并安装Forge，Forge安装方法：打开Forge压缩包把里面的内容全部拖入.minecraft/bin文件夹下的minecraft_server.jar文件里，注意安装前先备份一个minecraft_server.jar文件，防止安装失败后无法打开游戏。
  • 2.下载马铃薯枪MOD的压缩包。
  • 3.把下载到的压缩包文件剪切到mods文件夹下（如果没有mods文件夹请自行创建）。
  • 4.打开游戏享受吧！
水桶端：
  • 1.下载马铃薯枪MOD的压缩包。
  • 2.把下载到的压缩包文件剪切到plugins文件夹下（如果没有plugins文件夹请自行创建）。
  • 3.打开游戏享受吧。
