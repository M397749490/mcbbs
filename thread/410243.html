最简单的插件
下面是一个插件的例子，他会创建一个名为“ExamplePlugin”的插件，插件的介绍为“An example plugin”
  1.     [Plugin("Example Plugin", "An example plugin", "1.0", "MiNET Wiki")]
  2.     public class MyPlugin : MiNETPlugin
  3.     {
  4.         public override void OnEnable()
  5.         {
  6.             //Code to execute when plugin gets enabled.
  7.         }
  8.         public override void OnDisable()
  9.         {
  10.             //Code to execute when plugin gets disabled.
  11.         }
  12.     }

命令监听器
你可以创建自己的命令，下面的示例代码会监听命令“/wiki”并返回“You learned this from the Wiki”
  1.     [Command("wiki", "Wiki.Example")]
  2.     public void WikiCommand(Player source, string[] arguments)
  3.     {
  4.         source.SendMessage("You learned this from the Wiki");
  5.     }
复制代码

Wiki.Example是玩家使用这个命令的权限
