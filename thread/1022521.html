作者: wjwrh    时间: 2020-4-18 19:44
可以不用装权限组插件的
打开服务端目录下面的permissions.yml
添加上
  1. we.default:
  2.     description: Default permissions
  3.     default: true
  4.     children:
  5.         worldedit.*: true
复制代码

重启服务器即可
