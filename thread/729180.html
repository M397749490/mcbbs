插件の简介

Introduction — 简介


厌倦了普通命令来修复物品了吗？ 那就找对插件了！

RepairGUI 以新的修复方式来增加物品修复的方式。




Features — 功能


GUI - 可以依照喜好来自定义配置
经验或金钱 作为修复付费的种类
每项物品支持 - 可以配置各个物品的价格类型与费用。
一次修复一个物品或一次修复所有物品。
自定义讯息。
有效率的code - 不Lag延迟！

指令の解说


  • /repair - 打开 GUI
  • /fix - 打开 GUI
  • /repairreload - 重载配置与讯息文件





权限の解说


  • repairgui.use - 允许使用 /repair 与 /fix 指令
  • repairgui.repair-all - 允许一次修复所有物品
  • repairgui.* - 允许使用上面两个权限
  • repairgui.reload - 允许使用 /repairreload 指令
