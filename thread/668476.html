这个插件是一个非常简单的插件，也是我第一次用YourPlugin写的一个插件
~但是也不知道是否是原创了
他能让你的服务器暂时无法加入(连op也进不去)

配置文件:
无

指令:
/FakeClose ——暂时不然其他人进入服务器(输入这个指令后会提示你未知指令但是已经生效了~)


权限:
ServerJoin.use——使用上面指令的权限


下载地址:
ServerJoin.jar (2 KB, 下载次数: 38)
2017-1-29 17:35 上传
点击文件名下载附件


已知bug：禁止服务器加入后得再输入一次才能允许加入 如果不输入指令那服务器就一直无法加入 只能删除插件


开源(仅供学习):
是否 b = false;
处理事件
玩家指令(e)
{
如果(e.获取指令().一样("/FakeClose") && e.事件().hasPermission("ServerJoin.use"))
{
如果(b == false)
{
b = true;
}
再 如果(b == true)
{
b = false;
}
}
}
处理事件
玩家进入服务器(e)
{
如果(b == true)
{
e.事件().踢出("服务器暂时关闭")
}
}
}
