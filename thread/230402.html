多世界，我想大家都已经很清楚了吧？
我就不多介绍了，简单的概述一下就好了：
依靠这款插件，你可以建造除主世界.地狱.末地第*个世界
下面是命令：
创建正常/虚空/平坦/末地你可以使用这个命令：
/world create worldname_environment（预设码）　（种子）

例如：
/world create waterworld/flat::2;7,5x1,5x3,5x12,90x9;1;biome_1,village
创建一个平坦世界～
/world list to list all available

列出可用的世界
/world copy worldname newworldname

复制一个世界
/world delete worldname

删除一个世界
下面是权限时间：
命令的权限：
命令权限默认可用人
/world create（世界创建）myworlds.world.createop
/world unload（卸载世界）myworlds.world.unloadOP
/world list(列出世界列表）myworlds.world.listOP
/world info（显示世界信息）myworlds.world.infoOP
/world delete（删除世界）myworlds.world.deleteNO
/world weather(调节世界天气）myworlds.world.weatherOP
/world time (调节世界时间）myworlds.world.timeOP

聊天权限：
玩家在另一个世界说话，另一个玩家在第二个世界听得到-
myworlds.world.chat.world1.world2
玩家在一个世界说话，每个世界听得到-
myworlds.world.chat.world1
玩家可以与另一个世界的人说话-
myworlds.world.chat.*.world2
全球联通-
myworlds.world.chat.*.*
通用权限：
玩家可以进入一个指定的世界：
myworlds.world.enter.[世界名字]
玩家可以进入任何一个世界：
myworlds.world.enter.*
玩家是否能建立世界：
myworlds.world.build.[世界名字]
