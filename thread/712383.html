    1. 指定禁止某个世界(不会影响其他世界)
    2. 禁用飞行命令

    4. 禁用飞行进入世界

上面的所有消息都是可以自定义的
指令：
/awf or /awf help        显示帮助命令
/awf disable                 禁用禁止飞行功能 [重载或重启服务器后失效]
/awf enable                 启用插件[如果你禁用过本插件]
/awf list                        列出被禁止的世界
/awf add world            添加新的被禁止世界
/awf remove world      从禁止列表删除该世界
/awf reload                  重载插件
/awf info                      显示本插件的信息

权限：
  antiworldfly.use:
    description: 允许开启/关闭/添加/删除指令.
    default: false
  antiworldfly.fly:
    description: 允许在禁止飞行的世界中飞行.
    default: false  
  antiworldfly.*:
    description: 所有权限.
    default: op
