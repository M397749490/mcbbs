设定页



介绍
就是背包整理



使用方式
R + C 键打开设定页面。R 键整理背包。

功能
  • 对物品栏的物品排序、垂直方向分类、水平方向分类（仿照 1.12.2 的 Inventory Tweak 的三种模式！）
  • 可以调整点击间隔的时间！即使设有NoCheatPlus或者禁用了inventory.fastclick的伺服器上也可以使用！
  • 移动背包里所有箱子里有匹配的物品！
  • 一堆客户端的“调整”！


主要选项
  • 按键设置
  • 调整点击间隔的时间 - [更多选项] -> [addIntervalBetweenClicks]
  • 隐藏整理按钮提示 - [更多选项] -> [showInventoryButtonTooltips]
  • 隐藏整理按钮 - [更多选项] -> [inventoryShowSortButtons]
  • [“调整”] 让瞬间破坏也有挖掘延迟 - [原生客户端“调整”] -> [instantMiningCooldown]
  • [“调整”] 关闭物品栏时自动把鼠标的物品放回背包 - [原生客户端“调整”] -> [preventCloseGuiDropItem]
  • [“调整”] 岩浆下看得更清晰 - [原生客户端“调整”] -> [disableLavaFog]


已计划加入的功能（尚开发中）
  • 一键切换背包设定档，把快捷栏切换成预先设定好的配置。
