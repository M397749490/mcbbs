丢MM哪个文件 大佬举个例子

放进mm的item文件夹
举个例子
在item文件夹 创建一个名为 宝石前置.yml
  1. empty-take-ref:
  2.   Id: 381
  3.   Display: '&c空孔位'
  4. unknow-take-ref:
  5.   Id: 166
  6.   Display: '&c找不到该宝石'
  7. take-hbs:
  8.   Id: 378
  9.   Display: '&c红宝石孔'
  10. take-lbs:
  11.   Id: 378
  12.   Display: '&c蓝宝石孔'
  13. 次级红宝石:
  14.   Id: 45
  15.   Display: '§f&l次级红宝石[+1攻击]'
复制代码



在镶嵌插件的SLOT中
  1. '红宝石孔':
  2.   name: '红宝石'
  3.   # 显示在取出界面的  宝石孔的样子
  4.   take-ref: 'take-hbs'
  5. '蓝宝石孔':
  6.   name: '蓝宝石'
  7.   # 显示在取出界面的宝石孔的样子
  8.   take-ref: 'take-lbs'
复制代码


在镶嵌插件中的Material中
  1. '次级红宝石':
  2.   name: '&f次级红宝石'
  3.   # 引用Mythicmob的items的物品id
  4.   ref: '次级红宝石'
  5.   chance: 0.9
  6.   # 孔位id
  7.   slot: '红宝石孔'
  8.   lores:
  9.     - '&a攻击力：+1'
复制代码
