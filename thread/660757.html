{：钻石：}介绍
什么是poreRT？PoreRT就是Pore，只是某些方面不一样。
PoreRT是为了帮助bukkit插件移植到海绵而不需要重写插件。
目前可让一些插件运行，但我无法保证他能够完美的运行。
以后我会逐渐地在海绵中测试测试一些插件，所以我们以后会看到他能带来什么。
原贴内容：
[扰流]
PoreRT是毛孔，但与它有不同的角度.PoreRT旨在帮助将插件从Bukkit移植到海绵，而无需完全重写插件。目前有一些工作插件，但我不确定它们的工作程度。我将在接下来的几周内尝试将一些插件移植到海绵上，所以我们会看到它的结果。
[/扰流]

毛孔是一个给海绵端提供对bukkit平台插件所兼容的插件
这个是延续孔隙所做出对1.10+支持的版本（希望后续版本也是）
请注意，该项目还在进行大量开发以及还没有考虑的功能。

原文：
Pore是即将推出的SpongeAPI的插件，旨在为平台上的Bukkit插件提供兼容性。这是Pore的延续，可以添加更多功能并将其更新为1.10（并且有望超越）。请注意，该项目仍处于重大开发阶段，尚未被视为功能性项目。插件维基页面的状态具有我测试过的一些插件的状态。如果您有一个希望获得支持并且目前无法正常运行的插件，请在此处提出问题。

安装方法：
  • Back up your existing system. 备份你的服务端
  • Install Sponge, detailed instructions can be found here .安装sponge，详细说明可在这查看
  • Copy the PoreRT Snapshot into your server's mods directory.复制PoreRT Snapshot到你服务器的mods文件夹
  • Make a plugins directory in your server's base directory.创建一个名为 plugins的文件夹到你服务器的根目录
  • Copy any of the plugins you want to try into the plugins directory.将你想尝试的插件复制到 plugins文件夹内
