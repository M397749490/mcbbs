第一步


下载好对应版本的多世界插件和PlotMe核心和生成器

第二步


把Multiverse-Core（或者是其他的多世界插件）和Plot-Core丢进/plugins.
第三步


启动一次服务器，目的是生成配置文件

第四步


打开
  • /plugins/Plot-Core/config.yml


复制代码

.\plugins\PlotMe\PlotMe-DefaultGenerator\config.yml

  1. <i><font size="2">/plotme claim <player> 为别人认领你脚下的地皮
  2. /plotme auto 自动认领顺序下一个地皮
  3. /plotme home[:#] 设置家，如果你有多个:
  4. /plotme home 会带你去你1号地皮.
  5. /plotme home:2 会带你去2号地皮.
  6. /plotme home[:#] <player> 去别人家/plotme home id 会带你去他的1号地皮.
  7. /plotme home:2 id 会带你去他的2号地皮.
  8. /plotme list 列出你的地皮
  9. /plotme list <player> 列出别人的地皮
  10. /plotme info 列出你站在的地皮的信息(包括地皮id, 主人,地形, 日期, 结束 帮助).
  11. /plotme comment <text> 评论一下（留言）到当前的地皮
  12. /plotme comments 查看各种留言
  13. /plotme biome 查看目前地形
  14. /plotme biome <biome> 改变当前地皮的地形
  15. /plotme biomelist 列出可设置地形
  16. /plotme tp <id> 传送到某个地皮
  17. /plotme id 查看当前地皮的id和坐标
  18. /plotme clear 将地皮初始化到认领时候的样子（地形哦~慎用）
  19. /plotme reset 还原地皮（慎用，解除占领的）
  20. /plotme add <player> 给某个玩家在你地皮建造的权限
  21. /plotme remove <player> 移除某个玩家在你地皮建造的权限
  22. /plotme setowner <player> 过户你的领地给玩家</font></i>
