暴走日报
这个插件需要使用java8，并适用任何版本的spigot。这个插件具有更新新闻和报纸的功能。插件代码已经过优化。


特点
使用简单
自定义config
支持玩家变量%player%和%server%变量
在聊天窗口点击一段文字获取报纸
自定义报纸内容
支持彩字和经济
报纸是一本书
可以创建标题


食用
1.下载本插件和前置
2.丢到plugins文件夹
3.重启服务器
4.配置文件


图片




指令
/news - 在聊天窗口,获得最新的报纸
权限:默认Default
/newspapers - 获得最新的报纸
权限:默认Default
/newsmanager reload
别名: /nm reload - 重载插件
权限:默认Op


配置
%player% - 玩家名字的变量
Config.yml
  1. #插件标题
  2. PluginTitle: '&e=========&a暴走日报&e========='
  3. #报纸的名字
  4. BookTitle: "&e暴走日报"
  5. #报纸的作者
  6. BookAuthor: "王尼玛"
  7. #报纸的Lore
  8. BookLore:
  9. - "&b新鲜事简单报。"
  10. - "&b王尼玛带你看速报！"
  11. #报纸的价格
  12. BookPrice: 50
  13. #是否卖出报纸,忽视即可
  14. Book: 'true'
  15. #玩家获得报纸是否收钱,true为开启，false是关闭
  16. Economy: 'true'
复制代码
book.yml
  1. #每一页报纸的大标题
  2. Title: "&7=========&a暴走日报&7========="
  3. #书的内容
  4. Book:
  5.   - "/header/这是第一页的小标题/line/行一/line/行二/header/这是第一页的小标题/line/行一"
  6.   - "/header/这是第二页的小标题/line/&a绿色的字/line/&b蓝色的字"
  7.   - "/line/行一/line/行二/line/行三/line/行四"
复制代码
New.yml
  1. #这个文件忽视即可
  2. Title: '&e=========&a暴走日报&e========='
  3. News:
  4.   - '&b本报纸由暴走日报提供'
复制代码
