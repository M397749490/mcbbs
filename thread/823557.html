楼上你们这些人都是认真的吗。。。
server.properties里面
level-type=DEFAULT
DEFAULT - 正常
FLAT - 超平坦
LARGEBIOMES - 巨大生物群系
AMPIFIED - 放大化
CUSTOM - 自定义超平坦，配合generator-settings食用

作者: 新手村头目    时间: 2018-10-12 22:45
这个问题很简单，首先准备前置
1.多世界插件
2.更好的地形生成器 （这个可自选）
在有多世界插件的前提下输入
/mv create 世界名 normal -t largebiomes
即可创建大型群落地图。若是想创建更大的地图，可以使用第2项的地形生成器达成。
