MinecraftChat 是一歀由 AlexKvzos 开发、雪尼 汉化的即时服务器Web聊天客户端。（MIT 协议）
描述
这是一款非常轻量级的应用，基于 Node.js 环境。通过网页端登录任何 有/无正版验证 的服务器，这样很适合就可以无需等待游戏载入。

在你的服务器上安装
  1. <font size="2">git clone https://github.com/AlexKvazos/MinecraftChat
  2. cd MinecraftChat
  3. npm install && grunt build
  4. npm start</font>
复制代码

应用将开启端口 3000 或通过 PORTenvironment 变量指定端口。

Grunt 任务
  • grunt debug - 创建一个无压缩版的客户端应用
  • grunt build - 创建一个压缩版的客户端应用
  • grunt watch - 当客户端代码变动时自动运行 grunt debug
  • grunt server - 启动服务器并服务端自动重启
