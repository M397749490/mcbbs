设置:
  1. values:
  2.   min: 1[分钟]
  3.   max: 5[如果设置5，那么只能输入1-5之间的数]
  4.   item-prize: 57<<[获得钻石块]
  5.   # Your message if the value is incorrect
  6.   wrong-value-message: '&cWrong number, try again!'[猜测错误的提示]
  7. broadcaster:[广播]
  8.   enable: true[允许][false禁止]
  9.   # Values below are set in seconds.[秒为单位]
  10.   # When you want it to start after the correct answer.[当你想要知道正确数字]
  11.   start-delay: 60[延迟60秒]
  12.   # How often you want the message announced (in seconds).[多久后公布消息][秒为单位]
  13.   interval: 120[2分钟]
  14.   # Your broadcast message[你的广播消息]
  15.   # Do NOT delete the min and max variables
  16.   broadcast-message: '&2Guess a number between %min% - %max%'
  17.   # Your broadcast message for the winner
  18.   # Do NOT delete the player variable
  19.   broadcast-winning-message: '&9%player% &2has won the prize!'
  20. Source[玩家获奖的提醒]
