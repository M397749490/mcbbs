M y S k i l l G e r m






插件简介:


  • 让玩家可以释放MythicMobs技能。
  • 设置每个技能的攻击力、法力、冷却、职业、权限计算公式。
  • 提供给开发者一个技能框架，让开发者更便捷且可以更专注的制作技能萝莉。
  • 新颖的技能释放逻辑。
  • 便捷的配置文件。
  • 高效且无限拓展的技能框架。
  • 自定义指令，防止指令冲突。

插件预览:


拥有多种技能触发机制


  • 玩家在0.3秒内shift连击两次后，将手中所持的武器移动到第九格，此时玩家切换手持槽即为释放技能。
  • 可以将技能绑定到武器上 支持判断 左、左+shift、右、右+shift
  • 想法很多，还没来得及写.....

多种条件判断


  • 权限条件(好吧，你懂了)
  • 变量条件，玩家必须拥有某技能的变量
  • 等级条件，玩家必须高于目标等级
  • 有需要的就留帖，看见秒更

完全自定义的公式


  • 每个技能的伤害、法耗、冷却可以任意编写
  • 乘除加减小括号大括号随便你用(只要你会)
  • 可以将任何PAPI返回的数字变量加入到公式中(例如%player_level%)

指令介绍:


  • /myskillgerm reload 重载插件(OP)
  • /myskillgerm list 列出全部技能
  • /myskillgerm check 查看当前可以绑定的技能
  • /myskillgerm info <技能> 查看技能信息
  • /myskillgerm strive <技能> 给技能升级
  • /myskillgerm set <键> <技能> 将的技能绑定到[1-8]键上(myskill.set)
  • /myskillgerm cancel <键> 取消该键的技能绑定
  • /myskillgerm add <ID> <数量> 给玩家指定数量的技能点(OP)
  • /myskillgerm remove <ID> <数量> 移除该玩家指定数量的技能点(OP)
  • /myskillgerm delete <ID> 移除该玩家的技能数据(OP)

非开发者如何使用



  • 下载本插件和所需依赖

  • 丢进plugin开服

  • 将编写好的MM技能按照格式写进Skill文件

  • 将所需的技能拓展包放入SkillExpensions文件夹下

  • 重载插件，开始享受你的技能



开发者如何编写自己的技能


⊙ 建一个java项目下载MySkillGerm并依赖

⊙ 创建类并让你的类继承于Skill并在你的类名上标注@SkillGerm注解

⊙ 导出jar包并放到插件文件夹下的SkillExpensions下后重载或者重启

⊙ 注意：一个jar包可以有多个技能类

⊙ SkillExpensions下可以放N个jar包

⊙ 如果您愿意分享您写好的技能拓展包，您可以自己发布或者联系我

package com.germ.skills;



import com.germ.myskill.Skill.component.Launcher;

import com.germ.myskill.Skill.component.Trigger;

import com.germ.myskill.Skill.entry.Skill;

import com.germ.myskill.Skill.entry.SkillGerm;

import org.bukkit.entity.LivingEntity;

import org.bukkit.util.Vector;



import java.util.UUID;



/**

 * @auther Germ

 * @data 2020/4/7-17:53

 * @aim

 */

//不写此注解不会读取

@SkillGerm

public class JumpBack extends Skill {

//extends Skill 不写拓展不读取



        //无参数构造方法 并向父类传输一个 Skill

        //构建Skill时建议使用

        //Builder.create(UUID.fromString("UUID"), "技能名") 并自己加上需要的参数后 build

    public JumpBack() {

        super(Builder.create(UUID.fromString("12c9aaac-c597-46d8-89fd-f3b11920c8a4"), "后跳")

       .cooldown("1234")

       .build());

    }



        //技能逻辑 当然你可以重写父类的 冷却 伤害 等的方法来实现更多的骚操作

    @Override

    public void cast(Launcher launcher, Trigger trigger) {

        LivingEntity livingEntity = launcher.getLivingEntity();

        Vector vector = livingEntity.getEyeLocation().getDirection().clone();

        vector.setX(-vector.getX()).setZ(-vector.getZ()).multiply(0.8).setY(0.3);

        livingEntity.setVelocity(vector);

    }



}
