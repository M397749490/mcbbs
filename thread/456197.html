世界介绍

主城世界：服务器主城世界 玩家传送中心 在这里玩家可以进行传送 也可以在这里兑换物品

生存世界：10000*10000的范围 在这里玩家可以随意生存 部分物品需要在此兑换 且商店也设于此

资源世界：4000*4000的范围 每周将会更新一次 在这里你可以不用担心资源缺乏 ps：请不要在这里建家 否则刷新后均不赔偿

地皮世界：64*64的大地皮 每人最多可领取3块 在这里既可以生存 又可以建造 简直是一举两得

地狱 末地：原版地狱 末地地图

部分插件命令
LWC

/cprivate 创建一个私有物品锁，其他人无法打开使用和无法破坏你锁定的东西。
/cpublic 创建一个公共物品锁，你锁定的物品，所有人都可以打开和使用，但无法破坏。
/cdonation 创建一个捐赠锁，所有人都能打开箱子放东西到里面，但无法取出。
/cpassword <Password> 创建一个密码锁，只有知道密码的人才能打开和使用，但无法破坏。
/cmodify 修改现有的私人保护，如共享给指定的人或组。
/cunlock <Password> 解锁密码锁
/cinfo 查看加锁保护的信息
/climits 查看你能加密保护的最大数量值
/cremove 解除物品保护锁
/cremoveall 解除这个玩家的所有保护锁
/lwc mode <persist|droptransfer>
/lwc flag <name> <on|off> 选择上锁模式
/lwc menu <basic|advanced> 选择菜单样式


PlotMe

/plotme claim <player> 为别人认领你脚下的地皮
/plotme auto 自动认领顺序下一个地皮
/plotme home[:#] 设置家，如果你有多个:
/plotme home 会带你去你1号地皮.
/plotme home:2 会带你去2号地皮.
/plotme home[:#] <player> 去别人家/plotme home id 会带你去他的1号地皮.
/plotme home:2 id 会带你去他的2号地皮.
/plotme list 列出你的地皮
/plotme list <player> 列出别人的地皮
/plotme info 列出你站在的地皮的信息(包括地皮id, 主人,地形, 日期, 结束 帮助).
/plotme comment <text> 评论一下（留言）到当前的地皮
/plotme comments 查看各种留言
/plotme biome 查看目前地形
/plotme biome <biome> 改变当前地皮的地形
/plotme biomelist 列出可设置地形
/plotme tp <id> 传送到某个地皮
/plotme id 查看当前地皮的id和坐标
/plotme clear 将地皮初始化到认领时候的样子（地形哦~慎用）
/plotme reset 还原地皮（慎用，解除占领的）
/plotme add <player> 给某个玩家在你地皮建造的权限
/plotme remove <player> 移除某个玩家在你地皮建造的权限
/plotme setowner <player> 过户你的领地给玩家
