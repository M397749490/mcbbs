第一区 功能性魔法
我们先看看汉化后的sever/plugins/Magicspells/spells-command.yml
恩不错{:10_513:}
  1. list:
  2.     spell-class: ".command.ListSpell"
  3.     name: 列表
  4.     always-granted: true
  5.     description: 列出你所学会的所有咒语.
  6.     only-show-castable-spells: false
  7.     reload-granted-spells: true
  8.     spells-to-hide: []
  9.     str-prefix: "&d你学会的咒语&r:"
  10.     str-no-spells: "&c你一个咒语都不会,麻瓜们,好好学习吧!"
复制代码


这个是个最基本的魔法，我们来解析一下吧！{:10_496:}
  1. list:←魔法ID只要不重复即可
  2. spell-class: ".command.ListSpell"←魔法class文件，差不多就是一个魔法的原形
  3. name: 列表←魔法名称&施法名称，比如我这里写的是"杀"那么以后就可以用/c 杀 来释放这个魔法了
  4. always-granted: true←萌新一来到服务器就会么？
  5. description: 列出你所学会的所有咒语.←备注/c 帮助 列表① 可以看到这个
  6. only-show-castable-spells: false←只看可以释放的魔法么？
  7. reload-granted-spells: true←输入时自动再次检测玩家的魔法么？这个必须填true否则有bug
  8. spells-to-hide: []←需要影藏的魔法，填写ID，用英语半角逗号隔开
  9. str-prefix: "&d你学会的咒语&r:"←列表魔法专属的str②，意思是你用/c 列表 的时候你的魔法列表前面跟的东西
  10. str-no-spells: "&c你一个咒语都不会,麻瓜们,好好学习吧!"←这个几乎没可能显示，除非你影藏的魔法里面有list这个魔法
  11. ①/c "帮助"如果修改过就随之改变，"列表"也是
  12. ②str:显示的文本
复制代码


让我把它改简单一点{:10_509:}
  1. list:
  2.     spell-class: ".command.ListSpell"
  3.     name: l
  4.     always-granted: true
  5.     description: 列出你所学会的所有咒语.
  6.     only-show-castable-spells: false
  7.     reload-granted-spells: true
  8.     spells-to-hide: []
  9.     str-prefix: "&6你学会的咒语&r:"
  10.     str-no-spells: "&c吓!你都没有魔法，你是怎么看到这条消息的"
  11. 这样以后输入/c l 而不是/c 列表 就可以查看魔法列表了
复制代码


接下来再看看帮助魔法{:10_530:}
  1. help:←魔法ID，下次我不写了
  2.     spell-class: ".command.HelpSpell"←魔法类型，同上
  3.     name: 帮助←同上
  4.     always-granted: true←上
  5.     description: 获得指定咒语的信息.←(懒得写同上两字了)
  6.     require-known-spell: true←帮助后的<咒语名>是否必须是自己会的
  7.     str-usage: "&a用法&r: /cast 帮助 <咒语名>"←如果别人输入/c 帮助 却不输入<咒语名>时显示的str
  8.     str-no-spell: 你不知道那个名称的咒语.←如果require那个后面是true,那么如果你不会一个叫<咒语名>的魔法就会显示
  9.     str-desc-line: "%s - %d"←%s是name ，%d是description
  10.     str-cost-line: "&a消耗&r: %c"←%c这个以后会讲到的，是消耗str
