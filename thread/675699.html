介绍

Citizens CMD是一个Citizens的附属插件
你能给npc绑定指令来右键执行,和自定义执行权限
使用简单,适合萌新腐竹
↓
安装方法
下载citizen和citizen cmd，放入服务器的plugins，重启服务器
↓
指令&权限
在给npc编辑指令时，需要先选定那个npc
面朝要编辑的npc输入指令/npc sel
v2.1开始支持placeholderapi的变量，你可以选择不安装。
插件自带玩家名字变量%p%和%player%
v2.1的指令&权限
  1. citizenscmd.* #管理员权限

  3. 指令:/npcmd  
  4. 作用:查看所有指令
  5. 权限:citizenscmd.npcmd

  7. 指令:/npcmd add  <console | message | none | permission | server> 绑定的指令 -L
  8. 作用:给NPC绑定指令
  9. 权限:citizenscmd.add
  10. 例子:
  11. -  /npcmd add console fly %player%
  12.    右键后，后台会执行指令/fly 右键的人的名字
  13. -  /npcmd add message &b这是一句测试的话
  14.    右键后，发送一句话在玩家的聊天窗口
  15. -  /npcmd add none fly
  16.    右键后，拥有essentials.fly权限的人会执行指令fly，反之则提示无权限
  17. -  /npcmd add essentials.fly fly
  18.    右键后，让玩家暂时拥有essentials.fly权限，并且执行指令fly
  19. -  /npcmd add essentials.fly fly -L
  20.    左键后，让玩家暂时拥有essentials.fly权限，并且执行指令fly
  21.    划重点，这里是左键执行指令
  22. -  /npcmd add server lobby
  23.    右键传送到子服lobby
  24.    这是BC服的功能

  26. 指令:/npcmd remove <left | right> <id>
  27. 作用:删除NPC绑定的指令
  28. 权限:citizenscmd.remove

  30. 指令:/npcmd cooldown  秒数
  31. 作用:添加冷却时间 使用此指令的
  32. 权限:citizenscmd.cooldown
  33. 例子:/npcmd cooldown 100然后这个npc就会有100秒的冷却，从右键时开始算

  35. 指令:/npcmd reload
  36. 作用:重载插件
  37. 权限:citizenscmd.reload

  39. 指令:/npcmd list
  40. 作用:看看该NPC绑定了哪些指令
  41. 权限:citizenscmd.list

  43. 指令:/npcmd edit <cmd | perm>  <left | right> <id> <新的指令/新的权限>
  44. 作用:编辑一个指令或者权限到NPC  
  45. 权限:citizenscmd.edit

  47. 指令:/npcmd price <价格>
  48. 作用:让NPC在使用时收取金币
  49. 权限:citizenscmd.price
  50. #这个指令需要你安装vault以及任意一款经济插件，例如essentials

  52. 指令:/npcmd sound <sound> [volume] [pitch]
  53. 作用:让NPC在使用时发出音效
  54. 权限:citizenscmd.sound

config.yml

v2.1的config.yml

  2. #开启更新,true为开启，false为关闭
  3. check-updates: true
  4. #设置语言文件 EN, PT, BG, RO, NO, CH
  5. #改成ch是繁体中文
  6. lang: 'en'
  7. # npc的基础冷却时间，单位是秒
  8. default-cooldown: 0
  9. # 收费提示，当NPC需要收费时提示玩家，玩家需要按shirt+右键  确认执行指令
  10. shift-confirm: true
  11. # Select cooldown display format, SHORT = 3m 3s | MEDIUM = 3 min 3 sec | FULL - 3 minutes 3 seconds
  12. cooldown-time-display: MEDIUM
