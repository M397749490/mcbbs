[传送]RandomTeleport —— 多功能随机传送插件[1.8-1.11]

插件特点

随机传送冷却时间 (防止熊孩子刷地图)

随机传送声音

随机传送 titles 提示(1.8以上版本的特性)

可以设置的随机传送范围

需要设置花费游戏币来随机传送



指令/权限

/randomtp - 随机传送 ( 也可以使用/rtp ). - 权限randomtp.tp

/randomtp reload - 重新加载插件配置文件 - 权限randomtp.reload

/randomtp help - 显示插件的信息和帮助



配置文件

  1. #--------------------#
  2. #                    #
  3. # 多功能随机传送插件 #
  4. #  作者 ItsLewizzz   #
  5. #--------------------#
  6. #------------------------#
  7. # 设置
  8. Cooldown: 20
  9. # 随机传送的冷却时间(防止熊孩子刷地图) 单位:秒
  10. # 如果设置为0则是关闭冷却时间
  11. Range: 500
  12. # 玩家随机传送的最大范围
  13. commandCost: 0
  14. # 设置随机传送时需要花费多少游戏币
  15. # 设置为0则是随机传送不需要游戏币
  16. #------------------------#
  17. # Title 公告
  18. Title:
  19.   Enabled: true
  20. # 是否启用 随机传送Title公告 开启true关闭false
  21.   MainTitle: '&a&lSUCCESS'
  22. # 主标题设置(支持颜色代码)
  23.   SubTitle: '&eYou have randomly teleported!'
  24. # 副标题设置(支持颜色代码)
  25. #------------------------#
  26. # 随机传送 音效
  27. Sound:
  28.   Enabled: true
  29. # 是否启用 随机传送音效 开启true关闭false

  31. # 设置随机传送的音效 你可以在这个网站查看所有音效名字 http://docs.codelanx.com/Bukkit/1.8/org/bukkit/Sound.html
  32. #------------------------#
  33. # 信息 设置
  34. Messages:
  35.   Prefix: '&e&lRANDOMTP &7>'
  36. # 插件前缀设置(支持颜色代码)
  37.   noPerm: '&cYou do not have permission to do this!'
  38. # 没有权限使用指令的提示
  39. #------------------------#
