标题: 物品无法获取
1.81版用minecraft_server创建服务器后，世界里面的任何物体都无法毁坏，打到最后要坏时自动还原了，这个是怎么回事，如何解决
服务器配置如下：
#Minecraft server properties
#Sun Oct 23 10:04:11 CST 2011
level-name=My World
allow-nether=true
view-distance=10
spawn-monsters=true
online-mode=false
difficulty=3
gamemode=0
spawn-animals=true
max-players=20
server-ip=
pvp=true
level-seed=hello World!
server-port=25565
allow-flight=false
white-list=false
motd=A Minecraft Server
useSMPAPI=true
