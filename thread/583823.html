插件使用简介：
实际上这个插件的使用相当简单了,但是在生成空岛时请注意,由于清空周围方块有bug,所以被我去掉了,暂时还未想到代替方法,所以请在超平坦世界生成空岛.

挖石机使用简介：
将挖石机放在原石的上方，在挖石机上方放箱子，箱子第一格放稿，再点击一次挖石机，即可自动挖下方的原石，每挖一次镐的耐久减一，配合刷石机使用效果更好，每个存档内只能启动一个挖石机。

写给地图作者：

如果你们想要在地图中附带本插件，可以不经过我的许可，但是请注明插件作者。
另外是关于配置文件：
首先请找到您的地图文件夹中的issettings.txt文件
(一般是 /sdcard/games/com.mojang/minecraftWorlds/地图名/ssettings.txt)
这便是空岛小帮手的配置文件

其中JsVersion是插件版本，请勿更改，因为如果配置文件中的版本与插件版本不符会重写配置文件。
iswcisland为该地图是否有一个空岛。
islandX为空岛基准点的X坐标，islandY为Y坐标，islandZ为Z坐标。
islandlevel为岛屿等级，目前无用。islandresettimes为剩余岛屿重置次数。
islandhomeX为岛屿的家的X坐标，slandhomeY为Y坐标，islandhomeX为Z坐标。
homeX为家的X坐标，homeY为家的Y坐标，homeZ为家的X坐标。

如何设置地标：
1.找到warps:
2.在它的下一行输入地标名称:X坐标,Y坐标,Z坐标
(如果不知道当前坐标可以使用未完工的小地图)
PS:地标系统目前不支持中文并且有些bug.

请问你是怎么做到修改稿子耐久的，可以教我吗？

这个吧大概就是先判断一下箱子第一格是不是镐，然后再设置箱子第一格为镐，耐久加一。
具体就是(假设箱子的坐标为dX,dY,dZ)
  1. if(Level.getChestSlot(dX,dY,dZ,0) == 270 && Level.getChestSlotData(dX,dY,dZ,0) < 60 || Level.getChestSlot(dX,dY,dZ,0) == 274 && Level.getChestSlotData(dX,dY,dZ,0) < 132 || Level.getChestSlot(dX,dY,dZ,0) == 257 && Level.getChestSlotData(dX,dY,dZ,0) < 251 || Level.getChestSlot(dX,dY,dZ,0) == 285 && Level.getChestSlotData(dX,dY,dZ,0) < 33 || Level.getChestSlot(dX,dY,dZ,0) == 278 && Level.getChestSlotData(dX,dY,dZ,0) < 1562)
  2. {
  3. //设置镐的耐久（不过要注意镐的耐久加上一才等于游戏中减一）
  4. Level.setChestSlot(dX,dY,dZ,0,Level.getChestSlot(dX,dY,dZ,0),Level.getChestSlotData(dX,dY,dZ,0)+1,1);
  5. }
  6. else
  7. {
  8. //把箱子第一格清空
  9. Level.setChestSlot(dX,dY,dZ,0,0,0);
  10. }

  12. Level.getChestSlot(x,y,z,slot)是得到在x，y，z的箱子的第slot格的物品ID
  13. Level.getChestSlotData(x,y,z,slot)是得到在x，y，z的箱子的第slot格的物品数据值
  14. Level.setChestSlot(x,y,z,slot,id,data,amount)是设置在x，y，z的箱子的第slot格的物品，id为物品序号，data是数据值，amount是数量。
  15. (注意一下，箱子的格数是从零开始的)
