                 【跨服教程】
好了，你现在准备好了兄弟！你需要一个跨服的BungeeCord端
那么你可以去官网下载，也有人不明白怎么下载，
当然，你需要官网的地址！【点我进入官网】
这里面下载的方式非常奇怪
我完全可以说
你直接点击里面的最终将成功创建
下面的BungeeCord就可以了。。。
因为版本不同，不推荐上面的方式
你需要自己寻找，这些就不需要讲了


恭喜你下载了太爽了！你差不多完成25%了！
然后需要做一个BAT文件，就像开服一样，因为它是一个软件程序
当然，开群组的时候连BungeeCord也要跟着开哦！
BAT怎么弄？？？？
》》》》》》》》》》》》》》》》》》
创建BAT文件【先创建个文本文档，在文档里复制以下文字】
【java -jar BungeeCord.jar】
然后保存，重命名为 【启动跨服.bat】
即可完成！哇！你已经完成65%了！
跨服就是这么简单！
然后启动！！！生成配置文件！！！
哇塞太爽了！

不要嚣张哦！进入最难阶段！
配置BungeeCord文件
文件如下【BungeeCord启动后生成的config.yml】



  • groups:
  •   md_5:     根据【天空学院】指出这是一个BUG，请不要默认为md_5否则会被熊孩子钻空子毁灭服务器！
  •   - admin
  • disabled_commands:
  • - disabledcommandhere
  • player_limit: -1
  • stats: 5725e7e4-e536-44f1-97a3-c72087ed0fcb[不可修改!]
  • permissions:
  •   default:
  •   - bungeecord.command.server
  •   - bungeecord.command.list
  •   admin:
  •   - bungeecord.command.alert   [权限列表,一般不用管]
  •   - bungeecord.command.end
  •   - bungeecord.command.ip
  •   - bungeecord.command.reload
  • listeners:
  • - max_players: 1 这里填写的最大玩家限制，只是摆设，你可以设置更高显示的就更高
  •   fallback_server: lobby[默认服务器（新玩家入服的第一个服务器）]
  •   host: 0.0.0.0:25565[这个端口是公开的，用于给玩家进入服务器，请注意，如果保留默认，进入你的群组服IP就是0.0.0.0:25565如果你进入的是原来服务器IP就无法实行在线跨服！]
  •   bind_local_address: true
  •   ping_passthrough: false
  •   tab_list: GLOBAL_PING
  •   default_server: lobby[默认服务器（新玩家入服的第一个服务器）它只是一个代号不用管它]
  •   forced_hosts:
  •     pvp.md-5.net: pvp
  •   tab_size: 60
  •   force_default_server: false[默认服务器，改为true]
  •   motd: '&1Another Bungee server'[服务器的标语，可中文，原版太难看，建议更改]
  •   query_enabled: false
  •   query_port: 25577
  • timeout: 30000
  • connection_throttle: 4000
  • servers:[群组服务器的列表]
  •   lobby:
  •   [这里是服务器大厅（新玩家入服的第一个服务器），你想改什么名就什么，必须英文，改完后需要同时修改上面的default_server: xxx]
  •     address: localhost:25565  【这是默认端口25565.，localhost这个代表的是你服务器的IP，保险起见，把这里填写为你准备的登录服的IP地址+端口吧】
  •     restricted: false
  •     motd: '&1Just another BungeeCord - Forced Host' 【不用管】
  • ====================================================
  • #打个比方你需要多个服务端链接
  • servers:[需要跨服的服务器列表]
  •   server1:[你要把server1设置为服务器大厅（新玩家入服的第一个服务器），就要修改上面的default_server: server1]
  •     address: localhost:25566
  •     restricted: false
  •     motd: '&1Just another BungeeCord - Forced Host'
  •   server2:
  •     address: localhost:25567
  •     restricted: false
  •     motd: '&1Just another BungeeCord - Forced Host'
  •   server3:
  •     address: localhost:25568
  •     restricted: false
  •     motd: '&1Just another BungeeCord - Forced Host'
  •   server4:
  •     address: localhost:25569
  •     restricted: false
  •     motd: '&1Just another BungeeCord - Forced Host'</P>
  • <P align=left> 注意：以上的端口不可和上面host: 0.0.0.0:25565[这个端口是公开的，用于给玩家进入服务器]的一样！
  • ====================================================
  • ip_forward: false[改为true]
  • online_mode: true[设置为false,除非你想开正版服]
  • 以上server2,server3都是可以更改的
  • 修改完成！！！
开启BungeeCord！然后开启你全部的服务器！
登入IP地址，爽爆了你成功了！
当然，BungeeCord有很多附属的插件提升功能
这需要你自己找哦！
然后，基本的指令
/server 服务器名字 【填写的是代号哦】
即可跨服！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！
