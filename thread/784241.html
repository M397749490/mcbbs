今天在服务器输入附魔指令发现不能附魔出高级别的魔。。。
于是找到了这款插件，我查了，，bbs上还没有这款插件的搬运，我就先放这里咯！！
特点：

想要荒谬（高级）的附魔吗?然后使用UberEnchant !这个插件允许您添加任何级别的附魔(是的，只测试了15000级)的任何项目。这包括食品、工具、剑、盔甲,块,但是如果你把方块放置了，附魔将会丢失。使用简单，虽然功能远没有rpgitem那么强，但对我而言够了。
需要vault
命令：
  • 颜色代码支持! !
  • /uadd enchant<附魔类型> <等级>
    给你手上的东西添加一个附魔
  • /uadd enchant all <等级>
    给你手上的东西添加所有附魔
  • /uadd effect <效果> <秒> <等级>
    添加指定的药剂效果持续时间以秒为单位
  • /uadd name <名字>
    添加物品名字
  • /uadd lore <描述内容>
    附加自己写的描述
  • /ucost add <附魔类型> <等级>
    查取增加该附魔的花费
  • / ucost del <附魔类型>
    查取删除该附魔的花费
  • /ucost extract <附魔类型>
    查取提取一个附魔的花费
  • /uset name <名字>
    物品的显示名称设置为<名字>
  • /uset lore <行> <描述>
  • 去掉指定药水效果
  • /udel enchant <附魔效果>
  • 去掉指定药水效果
  • /udel effect <药水效果>
    去掉指定药水效果
  • /udel name
    去掉名字
  • / uextract <附魔类型 >
    去掉指定的附魔
  • /uinsert lore <行> <描述>
    制定第几行加入描述（后面加入）
  • /uclear enchant|lore|effect
    清除附魔，描述，效果
  • / ulist
    列出可用的附魔效果
  • / uhelp
    列出所有的命令


权限：
  • 默认为op权限
  • 免费使用一个特定的附魔
    uber.enchant.<enchantment>
  • 免费提取附魔
    uber.extract.enchant.free
  • 花费金币来提取一个特定的附魔
    uber.extract.enchant.<enchantment>
