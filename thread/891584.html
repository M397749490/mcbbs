标题: [1.12.2]如何使用记分板计时然后每隔60s自动刷新“道具”的生成？
版本是1.12.2，举个例子，就比如说每隔60s在 1 2 1 的坐标生成一个不会消失的钻石块掉落物[这个钻石块掉落物就是道具]，玩家可以拾取，且不断刷新。但是要让它不会重复，就是说过了120s之后玩家在捡起那个钻石块掉落物时不会捡到两个，而是一个。请问如何做到？谢谢大佬！
作者: xmdhs    时间: 2019-7-25 20:25
本帖最后由 xmdhs 于 2019-7-25 21:27 编辑

先创建一个记分板

/scoreboard objectives add test dummy

然后高频下面的指令，命令方块放在你想刷新的位置。

/execute @e[name=item.tile.blockDiamond,r=5] ~ ~ ~ scoreboard players set @a test 1200

再高频这个。 x y z 填想刷新的位置的坐标

/execute @a[score_test=0] x y z summon minecraft:item ~ ~ ~ {Item:{id:"minecraft:diamond_block",Count:1b}}

最后再高频这个

/scoreboard players remove @a test 1

作者: 爱心魔王FHC    时间: 2019-7-25 22:01
/summon item 1 2 1 {Item:{id:"diamond_block",Count:1},Age:4800s}
这个物品召唤出来在60s后会消失，然后你用一个计时器每隔60s激活一次命令方块就行了
https://www.mcbbs.net/thread-494593-1-1.html
红石计时器论坛有很多，或者如果你需要命令方块计时器：
创建记分板
/scoreboard objectives add time dummy
高频
/scoreboard players add A time 1
/scoreboard players test A time 60 60
下面这个指令接在上面指令的后面，用连锁，条件制约，保持开启
/scoreboard players set A time 0
再接下面的指令，也是连锁，条件制约，保持开启
/summon item 1 2 1 {Item:{id:"diamond_block",Count:1},Age:4800s}
