这是一个在你Minecraft服务器上提供额外等级系统的插件。如果您愿意，该插件可以选择将自己的Minecraft原版等级系统与插件同步，当然，你也可以使用插件自己的系统。

[size=14.6667px]需要前置：
权限插件，Vault


[size=14.6667px]


  • 插件100％可配置
  • 支持UUID
  • 支持MySQL和YML
  • 升级类型（正常，配置）
  • 等级上限
  • 您可以设置插件是否有等级上限
  • 您可以设置等级上限。
  • 升级的难度
  • 您可以更改升级的难度。
  • 升级时经验重置
  • 您可以设置升级后玩家的经验是否会重置。
  • 杀死玩家/怪物,破坏方块获得经验
  • 死亡掉落经验
  • 等级提升奖励
  • 执行命令，发送消息和给予物品;
  • 经验倍数
    • 您可以按组编辑经验倍数，并可以选择价格

  • PlaceholderAPI
    • 玩家等级：％playerlevels_level％
    • 玩家经验：％playerlevels_exp％
    • 还需要多少经验到下一级：％playerlevels_required_exp％
    • 到下一级的总经验：％playerlevels_total_exp_required％
    • 该玩家的经验百分比（到下一级别）：％playerlevels_total_exp_required_percentage％
    • 该玩家的进度（到下一级别）：％playerlevels_total_exp_required_pbar％

  • EssentialsChat集成
    • {} PLAYERLEVELS_EXP
    • {} PLAYERLEVELS_LEVEL
    • {} PLAYERLEVELS_REQUIREDEXP
  • 该插件具有背包交互功能
  • 顶尖的GUI
  • 选择使用与Minecraft原版等级系统同步的等级系统
  • 奖励系统
  • 可配置等级
  • 可配置玩家聊天前缀
  • 命令可以由控制台执行
  • 以及更多!
[size=14.6667px] ?

  • /level
    • 功能: 查看您自己的级别
    • 权限: 无权限
  • /level help
    • 功能: 插件帮助页面
    • 管理员权限: playerlevels.admin
    • 玩家权限: 无权限

  • /level reload
    • 功能: 重新加载插件
    • 管理员权限: playerlevels.admin
    • 玩家权限: 无权限

  • /level top
    • 功能: 查看服务器等级排行榜
    • 权限: 无权限

  • /level <玩家>
    • 功能: 查看其他玩家的等级
    • 权限: 无权限

  • /level give <玩家> <数值>
    • 功能: 给玩家提升等级
    • 权限: playerlevels.give

  • /level set <玩家> <数值>
    • 功能: 设置玩家的等级
    • 权限: playerlevels.set

  • /level take <玩家> <数值>
    • 功能: 给玩家降低等级
    • 权限: playerlevels.take

  • /level giveexp <玩家> <数值>
    • 功能: 给玩家经验
    • 权限: playerlevels.giveexp

  • /level setexp <玩家> <数值>
    • 功能: 设置玩家的经验
    • 权限: playerlevels.setexp

  • /level takeexp <玩家> <数值>
    • 功能: 扣除玩家经验
    • 权限: playerlevels.takeexp

  • /level clear <玩家>
    • 功能: 设置玩家经验为0并设置等级为初始等级
    • 权限: playerlevels.clear

  • /level booster
    • 权限: 查看你是否开启了奖励功能
    • 权限: 无权限

  • /level booster <玩家>
    • 功能: 查看该玩家的奖励,如果该玩家获得了奖励
    • 权限: 无权限

  • /level booster set <玩家> <数值> <时间(分)>
    • 功能: 设置玩家奖励的时间与数量
    • 权限: playerlevels.booster

  • /level booster add <玩家> <数值> <时间(分)>
    • 功能: 给玩家增加限时的奖励
    • 权限: playerlevels.booster

  • /level booster gi <玩家> <数值> <时间(分)>
    • 功能: 给玩家配置中的奖励
    • 权限: playerlevels.booster
