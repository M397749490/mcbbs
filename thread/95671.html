MCPC-1.4.7-R1.1测试通过


缩写：KCIR

目的是让指定区域的区块一直在内存中保持加载，可以为红石、命令方块，抑或是主城等一些地标建筑提供快速加载，以便减少文件系统负载

这点和NoSpawnChunks完成相反，是否相容倒是没测试过，公司只能运行服务端= =

此外，能有效阻止玩家在传送后落入墙壁或掉落

  1. 指令：
  2. # 添加条目到列表中
  3. /kcir add（只限游戏) 或 kcir add [世界] [x] [z]
  4. # 从列表中删除条目
  5. /kcir remove（只限游戏) 或 kcir remove [世界] [x] [z]
  6. # 从chunks.txt加载条目
  7. /kcir load
  8. # 存储到chunks.txt
  9. /kcir store
  10. # 清除列表
  11. /kcir clear
  12. # 打印列表
  13. /kcir list
复制代码


关于选择区域的说明：KCIR提供了几种工具来进行选取区域——Circle(圆)、Ellipse(椭圆)、Square(正方)、Rect(长方)
参数用法（符号“!”不能少）：
圆：
world 0 0 !circle 24
# 以X：0，Z：0为中心，直径24
椭圆：
world 0 0 !ellipse 20 10
# X：0，Z：0，宽度20，高10
正方：
world 0 0 !square 20
# 从X:-20，Z：-20 X：20，Z：20选取一千六百个方块
长方：
world 0 0 !rect 20 10
# 从X:-20，Z：-10 X：20，Z：10选取八百个方块

可以和kcir add命令结合
eg：/kcir add world 0 0 !ellipse 20 10（指令+参数的写法仅限控制台）

Plugins/KCIR文件夹中的chunks.txt文件也是以给出的参数形式保存的，可以手动修改

  1. 配置：
  2. # 当插件启用时，自动将 chunks.txt 文件中的所有块都加载到内存。
  3. autoLoadChunks: false
  4. # 将范围条目储存为单个条目，chunks.txt中的内容会被覆盖
  5. storeAsSingle: false
