RPGshop
RPG商店
简介
这是一个仿Shopkeepers交易系统的插件。但是你可以用多个物品或钱换取（购买）物品，当然也包含自定义的物品。
你一样可以搭配其他插件來用
食用方式
  • 使用[NPC]创建商店
  • Shift+右键点击NPC编辑商店，初次设置需设置商店的名称以及商店大小
  • 将要卖得东西放入(一定要先选好位置，编辑完物品要求后换位置会导致该物品要求不见)，右键编辑物品要求。
  • 将要购买该物品的需求物放入，如果有需要用到钱请点"设置金钱"。
  • 都设置完毕后关闭所有页面就完成了。

  • 使用[指令]创建商店
  • 输入指令/rpgshop create [商店编号] [商店名字] [商店大小] 创建一个商店。
  • 输入完毕后会自动跳出编辑物品页面，同上，依样画葫芦
指令权限
指令
说明
/rpgshop enable
 开启/关闭对NPC进行编辑
/rpgshop list 查看所有的商店名字以及编号
/rpgshop create <商店编号①> <商店名称②> <商店大小③> 创建商店
/rpgshop edit <商店编号> 编辑指定的商店
/rpgshop copy <商店编号1> <商店编号2> 将商店1的所有设置覆盖到商店2
/rpgshop remove <商店编号> 移除指定商店
/rpgshop trade <商店编号> 与指定商店进行交易
/rpgshop reload 重载插件
权限
说明
默认
chestshop.Command 可否使用除/rpgshop trade 以外的指令 op
chestshop.NPCedit可否对NPC进行Shift+右键进行编辑 op
chestshop.NPCtrade 可否对NPC进行交易或以/rpgshop trade进行交易true
配置文件
  • config.yml:

  1. NPCeditEnable: false                                                                #是否开放对npc进行编辑.true开启，false关闭
  2. message:
  3.   trade_success: §a成功购买了 §7<amount> 个 §r<item>     #购买成功后的提示，<amount>:物品数量;<item>物品名称
  4.   trade_failure: §c你没有足够的物品购买!                                    #没有足够物品购买后的提示
  5.   inventory_full: §c你的背包没有空间了!                                      #背包满了的提示
  6.   need_title: §7---[购买要求]---                                                   #购买要求的标题
复制代码

  • lang.yml
这个文件可以覆盖Minecraft默认物品的名称(包括钱)，使用方法如下：
  • 先去wiki查看物品名称
  • 再到lang.yml输入[物品名称]:[覆盖名称]
  • 钱的设置为Money:[名称]
#有些物品可能与该网站的名字不相同，可以看商店显示的名字作依据。
