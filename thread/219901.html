朋友插件
/friend add <username>[td]发送一个玩家一个朋友请求
[/td]
/friend remove <username>[td]从你的朋友列表中删除一个朋友
[/td]
/friend accept[td]接受好友请求
[/td]
/friend deny[td]拒绝一个朋友的请求
[/td]
/friend help[td]列出所有FriendMe命令
[/td]
/friend list online[td]所有在线好友列表
[/td]
/friend list offline列出所有离线在线朋友

组队插件
/team - 查看可以使用的队伍插件指令
/team create <名字> - 创建一个队伍
/team disband - 解散自己的队伍（队长）
/team vault - 打开自己队伍的仓库
/team invite - 邀请玩家至你的队伍（队长）
/team kick - 将某玩家踢出自己的队伍（队长）
/team tag <名字> - 修改自己的队伍名（队长）
/team leave - 退出你的队伍
/team list - 显示队伍列表
/team who [队伍名] - 显示队伍成员在线、离线情况。
/team chat - 更改聊天模式[公共/队伍]
/team sethome - 设置一个队伍的家（队长）
/team home - 传送到自己队伍的家
