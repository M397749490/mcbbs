安装

设置要求
MC服务器软件有一些系统要求。有可能你已经满足了这些要求，但是并不妨碍检查。
这些是最低限度的要求，这些是使用MC Server Soft运行和运行Minecraft服务器所必需的。
  • .NET Framework 4.5
  • Java 8
  • 具有4GB内存的Windows 7,8或10操作系统
  • 互联网连接稳定，有线是非常优先的
  • 端口转发功能调制解调器/路由器（适用于在线多人游戏）
