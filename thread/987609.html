打开服务器config/academy-craft-data.conf文件，找到
  
  1. shift_tp {}
复制代码


这个就是物品传送，然后改成
  1.         shift_tp {
  2.           enabled: false,
  3.           damage_scale: 1.0,
  4.           cp_consume_speed: 0.1,
  5.           overload_consume_speed: 0.1,
  6.           exp_incr_speed: 1.0
  7.           }
复制代码

这样就能禁止学习和不显示在gui里面了
