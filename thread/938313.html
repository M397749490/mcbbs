PAPI

AdvancedHelp支持PAPI。这意味着您可以在任何地方使用PAPI中的任何占位符！

AdvancedHelp的内置占位符：

%player% - 返回玩家名称

%time% - 返回时间

如何使用PlaceholdersAPI中的占位符：

1.下载PlaceholderAPI

2.下载占位符， /papi ecloud download <名称>

3.重新加载papi，/papi reload

4.在AdvancedHelp中使用占位符！

命令

来自：https://www.mcbbs.net/thread-810888-1-1.html
/help - 打开帮助信息
/help <page number> - 翻页
/help <catagoryName> - 打开指定的类别
/help <catagoryName> <page number> - 指定类别翻页
/ahelp reload - 重载配置文件
/ahelp help - 显示额外的帮助（仅对于管理员）
你可以使用 /? 或是 /ehelp 来替代 "help"

权限

来自：https://www.mcbbs.net/thread-810888-1-1.html

help.use - 让玩家允许使用 /help 命令

help.reload - 重载配置文件命令的权限节点

help.<categoryName> - 允许玩家查看指定的类别，当类别的 Default 设置为 false 时，需要拥有权限才能查看

help.override - 如果拥有这个权限，使用 /? 时将显示 bukkit help 页面

建议默认组中否定 bukkit help的权限节点

- -bukkit.command.help
