可能在输入指令的时候出了一点问题
假设你用的是GroupManager插件
再打开指定世界的权限组配置的时候可以看到默认组(Builder)的配置如下
  1. Builder:
  2.     default: true
  3.     permissions:
  4.     inheritance:
  5.     - default
  6.     - g:essentials_builder
  7.     - g:towny_builder
  8.     info:
  9.       prefix: '&2'
  10.       build: true
  11.       suffix: ''
复制代码

你可以让你的VIP权限组继承这个权限组,比如这样
  1. VIP:
  2.     default: false
  3.     permissions: []
  4.     inheritance:
  5.     - Builder
  6.     info:
  7.       prefix: '&2'
  8.       build: true
  9.       suffix: ''
复制代码

也有可能会出现其他的问题,那么你可以直接继承Builder组所继承的组,列如这样
  1. VIP:
  2.     default: false
  3.     permissions: []
  4.     inheritance:
  5.     - default
  6.     - g:essentials_builder
  7.     - g:towny_builder
  8.     info:
  9.       prefix: '&2'
  10.       build: true
  11.       suffix: ''
