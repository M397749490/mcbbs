现在我先来说说 权限！
<backpack> =  这个背包的名字，就假如我有个背包是MypackKing  然后我在这里输入MypackKing，然后他们就可以买这背包了，

[size=13.333333969116211px]Command Permissions:   
  • rb.reload - Access to the '/rb reload' command    -就是重启这config。dll这东西，就不用每次都重启服务器了！
  • rb.list - Access to the '/rb list' command        -呃，列出来所有背包吧
  • rb.<backpack>.buy - Access to the '/rb buy' command  - 可以买某个背包
  • rb.<backpack>.give - Access to the '/rb give' command   -这就是作弊的了，可以给某人某个背包 不用花钱！
[size=13.333333969116211px]Backpack Permissions:
  • rb.<backpack>.use - Can open the backpack               -可以使用背包
  • rb.<backpack>.craft - Can craft the backpack if recipe is enabled            -可以制作背包（制作的什么在配置文件里面可以改）
                        可能会说你没有权限使用啊什么，  那是因为你没有给权限。你懂的 GroupManage 要用了   /mangaddp default（这是默认组） 《permission（这就上面看吧）》  在给用户组权限的时候不用加边上的两个《》  比如 /mangaddp default rb.MypackKing.buy  这样这个用户组就可以买背包了，像不能用背包是因为你没有给rb.《backpack》.use这权限



指令！！
[size=13.333333969116211px]Player Commands:   普通人的
  • /rb list - List all backpacks with their sizes and prices   查看所有的背包 就是第一幅图我发的那样
  • /rb buy <backpack> - Purchase a backpack for the price in the config file            买某个背包，backpack就是背包的名字
[size=13.333333969116211px]Admin Commands:     不普通人的
  • /rb reload - Reloads the config and messages file         重启config这个dll啦~~~
  • /rb give <player> <backpack> - Give a player a backpack     给某人一个背包，不用花钱噢
  • /rb view <player> <backpack> - View a player's backpack    查看熊孩子的背包！！！
