世界名可以传送到暮色输入/mv info,或者直接去worlds文件夹看
  1. config:
  2.   fallbackworld: world # 达到上限后传送进来会被传送到名为 world 的世界
  3.   worlds:
  4.     DIM1: # 限制的世界名 改成暮色的世界名就行了
  5.       limit: 1 # 限制的玩家数量 现在是1
  6.       sign:
  7.         world: world # 显示的名字 可以理解为显示这个世界的代名词
  8.         x: 0
  9.         y: 0
  10.         z: 0
  11.         text: # 这下面的文本最多只支持四行
  12.         - '%world%'
  13.         - '%current% / %limit%'
  14.         # 支持的变量 %limit% %current% %world%</pre>
