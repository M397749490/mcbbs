npc脚本如何把npc杀死后执行指令：例如：class exp 玩家 1


作者: 粘兽    时间: 2019-5-25 21:04

  1. function died(e){
  2.     if(e.source != null && e.source.type == 1){
  3.         var name = e.source.name;
  4.         e.npc.executeCommand('class exp '+name+' 1')
  5.     }
  6. }

以上是高版本的做法。

如果你是1.7.10 需要在killed监听下写入:
  1. if(event.source != null && event.source.type == 1){
  2.     var name = event.source.name;
  3.     npc.executeCommand('class exp '+name+' 1')
  4. }
