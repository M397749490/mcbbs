玩家每次死亡都会重生在主城，怎么让玩家重生在当前世界的重生点

多世界插件已经拥有

下面是ess插件配置
  1. # 当我们第一次出生时,出现在哪个出生点？
  2.   # 如果你想要使用世界自带的出生点,则设置为"none".
  3.   spawnpoint: default

  5.   # 是否想要玩家第一次进入服务器时赠送新手礼物? 设置为 ''禁用此功能.
  6.   # 这个赠送不会花费金钱,也可以给予权限.
  7.   #kit: ''
  8.   kit: tools

  10. # 设置为 lowest, 如果你想使用 Multiverse 处理重生.
  11. # 设置为 high, 如果你想使用 EssentialsSpawn插件 处理重生.
  12. # 设置为 highest, 如果你想强制使用 EssentialsSpawn插件 处理重生.
  13. respawn-listener-priority: lowest

  15. # 如果设置为true,玩家死后会重生在自己家,而不是出生点.
  16. respawn-at-home: false

  18. # 文件结尾 <-- 到此, 你已经完成了ESS的设置.
