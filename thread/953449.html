插件功能

  • 全自定义信息
  • 编辑简单高效
  • 支持最多 15行信息
  • 支持不同世界不同计分板
  • 可自定义更新时间
  • 可用作动态计分板

插件命令

/sh on
开启计分板
权限: sh.command.sh/sh off
关闭计分板
权限: sh.command.sh

SCOREHUD.YML
  1. ---
  2. # 不要修改.
  3. # 仅供内部使用.
  4. scorehud-version: 1

  6. # 更改计分板标题.
  7. # 可以是任意数量.
  8. server-names:
  9. - "§e§lServer §6§lName"

  11. # 注意: 您可以通过README.md找到指向所需/支持的插件链接.
  12. # 重要项: 计分板最多只能设置15行.
  13. #
  14. # 您可以编辑下面已经设置的行，并根据需要进行调整.
  15. #
  16. # 如果您希望每个世界都显示相同的计分板，请在config.yml中将per-world-scoreboard设置为false.
  17. #
  18. # 如果您启用不同世界不同计分板，并且想要其他世界显示默认计分板
  19. # 信息在下方,然后在config.yml中将use-default-score-lines设置为true.
  20. #
  21. # 之后编辑信息就完成了.
  22. #
  23. # 您需要添加插件来添加对称号的支持.
  24. # 如果要支持某个插件，请让该插件的插件作者通过添加插件来添加对ScoreHud的支持.
  25. #
  26. # 有关附加组件的列表，请点击此处 https://github.com/JackMD/ScoreHud/blob/master/README.md#addons.
  27. score-lines:
  28. - "§d名称: §5DobeShadow"
  29. - "§b在线: 1 §d/ 10"
  30. - "§6权限组: §a服主"
  31. - "§c监狱等级: §6A"
  32. - "§a空气值: §20§c/§20§c/§20"
  33. - "§d坐标: §d-316§3/§d9§3/§d-390"
  34. - "§6加载: §a78.22 §c| TPS: §b20"
  35. - "§2世界: §7world"
  36. - "§2世界名: §7主世界"
  37. - "§eIP: §6127.0.0.1"
  38. - "§a派系: ^cRankKing"
  39. - "§c延迟: §d12"
  40. - "§3投票: "
  41. - "§cwww.mcbbs.net"

  43. # 如果要为每个世界显示不同的计分板，请在config.yml中将“per-world-scoreboard”设置为true.
  44. # 之后，编辑以下内容就完成了.
  45. scoreboards:
  46. # 示例配置:
  47. # -------------------
  48. # "世界名":     | 世界名 (worlds文件夹内世界名称)
  49. #   lines:          | 此行很重要,缺失会导致服务器崩溃.
  50. #   - " Line #1"    | 第一行自定义信息.
  51. #   - " Line #2"    | 最多只能15行.
  52. #--------------------
  53.   "world":
  54.     lines:

  57.   "world 2":

  60.     - " §bLoad: §a{load}"
