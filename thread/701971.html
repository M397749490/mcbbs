标题: Residence插件可否设置为领地存在有时间限制？
RT，例如我现在设置了领地，七天后领地自动消失这样。。
作者: 水煮清娃    时间: 2017-7-1 23:36
可以设置自动清理多少天不上线的玩家领地，但是不能设置领地创建多少天后删掉。
例子：60天后世界world中不上线的玩家将被自动删除领地，设置在config.yml里面

  1.   AutoCleanUp:
  2.     # HIGHLY EXPERIMENTAL residence cleaning on server startup if player is offline for x days.
  3.     # Players can bypass this with residence.cleanbypass permission node
  4.     Use: true
  5.     # For how long player should be offline to delete hes residence
  6.     Days: 60
  7.     # Worlds to be included in check list
  8.     Worlds:
  9.     - world
