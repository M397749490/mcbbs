ChatFilter - 永远不会看到任何脏话！

使用插件“ChatFilter”，您可以向文件添加脏话，不允许玩家发出去。

用法：
使用/ chatfilter命令将脏话添加到列表中！


您可以使用以下指令：
/chatfilter ADD - >向列表中添加脏话

/chatfilte REMOVE - >从列表中删除脏话

/chatfilte LIST - >列出所有禁止的脏话

/chatfilte RELOAD - >重新加载配置


权限：
权限很简单。
filter.admin- >
use /chatfilter and bypass the filter不会翻译

filter.bypass- >
bypass the filter不会翻译   

配置:

  1. # Configuration file for the ChatFilter plugin
  2. # Use this file to edit the messages of the plugin

  4. Prefix: '&7[&bChatFilter&7]'
  5. NoPermission: '%prefix% &cYou dont have permission to use this command!'
  6. ListMessage: '%prefix% &eForbidden words:'
  7. ListLayout: '%prefix% &7- &b%word%'
  8. NoBannedWords: '%prefix% &cThere are no banned words.'
  9. Usage: '%prefix% &cUsage: &7/chatfilter <ADD | REMOVE | LIST | RELOAD> [<Word>]'
  10. SuccessfullyAdded: '%prefix% &aYou successfully added the word &e%word%'
  11. SuccessfullyRemoved: '%prefix% &aYou successfully removed the word &e%word%'
  12. SavingError: '%prefix% &cAn error occured while attempting to save the word to the file. Please see the console for more information.'
  13. WordNotForbidden: '%prefix% &cThe word is not forbidden.'
  14. NotPlayer: '%prefix% &cYou need to be a player!'
  15. ConfigReloaded: '%prefix% &aThe config was successfully reloaded!'
