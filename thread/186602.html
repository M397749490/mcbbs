      不多说，直接上内容
1.     level-name = 服务器名称(这里必须使用英文)
2.     hellworld = 地狱世界(true=开启 false=关闭)
3.     spawn-monsters = 生成怪物(true=开启 false=关闭)
4.     spawn-animals = 生成动物(true=开启 false=关闭)
5.     online-mode = 在线模式(盗版服请设false)
6.     max-players = 服务器上限人数(好友不多的建议10 否则设置多少消耗多少内存)
7.     server-ip = 用于绑定服务器地址(建议留空 Hamachi例外)
8.     pvp = 友军伤害(true=开启 false=关闭)
9.     server-port = 服务器端口
10.  white-list = 启用白名单
11.  #服务器隐藏设置
12.  verify-names = 检测昵称,第一个重名昵称将被kick
13.  spawn-protection = 重生点保护范围(单位:格 如32及32x32)
14.  levelName = 服务器名称
15.  onlineMode = 在线模式
16.  autoSave = 自动保存
17.  autoSaveMins = 服务器自动保存时间(单位:秒)
18.  autoBackup = 自动备份
19.  autoBackupMins = 自动备份时间(单位:秒)
20.  keepBackupHours = 保留备份时间,超过将删除备份(单位:天)
21.  autoRestart = 自动重启(服务端检测到错误时)
22.  autoRestartMins = 自动重启时间(单位:秒)
23.  exitOnFailure = 退出失效(未知)
24.  port = 端口
25.  internalPort = 内部端口
26.  rconPort = 远程端口
27.  rconPassword = 远程密码
28.  useWhitelist = 是否启用特定的人才可加入服务器
29.  useSMPAPI = 使用多核处理
30.  c10tArgs = 是用C10T参数(好像是10进制的意思)
31.  c10tMins = C10T处理时间(单位:秒)
32.  maxPlayers = 同max-players
33.  defaultGroup = 默认组(此为Steam组,盗版无视)
34.  useSlashes = 使用斜杠语法(默认dots语法)
35.  memory = 内存(及服务端最高吃多少内存)
36.  useMsgFormats = 使用信息格式(未知)
37.  msgTitleFormat = 信息标题格式
38.  msgFormat = 信息格式
39.  localChatRadius = 当地信息交互(AAA协议)
40.  debug = 调试模式
41.  alternateJarFile = 备用的jar文件(建议留空)
42.  guestsCanViewComplex = 来宾可以查看(Complex好像是函数)
43.  ipAddress = IP地址(建议留空)
