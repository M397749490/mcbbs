标题: [1.12-1.7.2][Mycommands——我的命令]多个家多地标
本帖最后由 afkavril 于 2017-6-15 17:56 编辑
主要用于Forge服的MOD里的所有命令：
单人貌似跟权限没太大关系，主要是多人。
/back      返回上一个位置
/fly          开启/关闭飞行
/god         上帝模式（貌似怪物不打你？）
/delhome        删除家（名称）
/sethome        设置家（名称）  比如说/sethome 家   
/home             回家    比如说  /home 家
/delwarp        删除地标
/setwarp        设置地标
/warp            查看存在地标
/setspawn        设置出生点
/spawn       返回出生点
/day       白天
/night     晚上
/sun   晴天
/rain   雨天
/repair    维修手中该物品
/Heal    恢复生命值
/tpa 传送玩家（对方需要接受请求）
其中有些命令可以对其余玩家使用，前提你是管理员（op）比如/fly player

所有的命令都可以在配置文件中进行设置开关 ture/false
true = Op Only | false for All
true=管理员仅有的权限     false=全部玩家

以上所有的命令均可以在help 面板里查询到
关于home可以设置几个家，默认为5个 如果想要更多的可以这样去更改
在你的游戏目录\.minecraft\config\mycommands   找到文件名字为mycommands 用记事本或者notepad++打开
然后看最下面
homes {
    I:homes=5
}

homes=5代表默认5个  更改数字达到你想要的数量，然后保存  进入游戏即可


更新说明：
从1.9.4-04版本开始 或者更高版本添加了Tpa 指令1.9.4-1.10.2为通用
