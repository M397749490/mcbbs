更新！1.3版本,已经支持FAWE！卡服再见！
重要：最好不要把他和clearlagg等清除实体的插件混用，如果迷宫的怪没了，迷宫的奖品（钻石块，各种盔甲）等于白送，这肯定不是任何管理员希望看到的。

腐竹们如果希望使用的话，最好自己根据服务器情况配置物品列表，比如默认有tnt，而大部分服务器对tnt不待见，就可以删掉，某些可能造成通货膨胀的稀有物品最好不要给，或者可以调低稀有爆率，并且增大迷宫大小，提高难度。

如果想让迷宫简单一点，可以修改刷怪几率让他少刷怪，并且把迷宫体积改小，当然，宝物也要减少啦～

前置要求：WE，FAWE

懒人包墙内地址：http://pan.baidu.com/s/1b77Cmy，里面前置插件的版本都是钦定的！如果你之前已经装过了前置插件那么只需要取出对应缺少的使用即可,如果出现NoSuchMethodError或者NoClassDefError则可以把原来的WE和FAWE卸载掉换成懒人包自带的。对于没有安装过的小白，只需要把里面能找到的jar都丢进你的plugins就可以了。

懒人包结构：MazePlugin-1.X.X-XXXX/libs/FastAsyncWorldEdit-bukkit-XXX.jar   FAWE插件
MazePlugin-1.X.X-XXXX/dep-worldedit/worldedit-bukkit-6.1.2.jar    WE插件
MazePlugin-1.X.X-XXXX/MazePlugin-1.3-XXXXX.jar    本体

WE：我想有开服经验的小伙伴都懂


FAWE介绍：自己在论坛搜吧(搜索炸了)，总之是一款很厉害的异步编辑器插件，依赖于WE。

插件本体：MazePlugin :

一个在服务器上面随机生成迷宫的插件！代码GPLV3开源。基于spigot构建但是用的都是bukkitAPI.

作用：根据配置随机生成指定大小的迷宫并且在里面放上宝箱和怪物，开始探险吧！

1.3 R2改动：加入多个2D迷宫，新增3D类型
2D类型列表:基于深度优先的递归回朔, Aldous Broder算法，随机Kruskal算法。


3D类型基于Aldous Broder的推广


参见：https://en.wikipedia.org/wiki/Maze_generation_algorithm


迷宫内死亡后，自动归还进入的时候寄存的物品，并且将死亡掉落的物品重新分配到迷宫的箱子里面

迷宫箱子内的武器装备不再能堆叠


现在不是每次进入迷宫都发装备了，增加了5分钟冷却。


防挂机设定放宽，减少误判

玩法命令：

/StartMazeTour 开始一次迷宫旅行
/Abort 放弃，玩家被传送会出生点，所有物品剥夺，增加了冷却，现在必须在/StartMazeTour执行五分钟后才能使用
/Finish 当玩家抵达起点对角的终点后使用，本轮游戏结束，所有玩家传送回出生点位，其中第一个玩家和他的伙伴获得所有身上的宝物，
其他人身上的物品有70%几率消失掉

/GenMaze 管理员命令，立即重设迷宫，第一次运行需要执行一次

/SetSize <size> 管理员命令 设置迷宫大小，同时触发迷宫重建


配置文件：
增加了几个入口，建议删除上一版设置文件。

plugin.yml设置：
lastWidthX : 32  //请勿手动修改，程序会自动填写这个字段

currentWidthX : 48 //迷宫长度，只支持正方形迷宫，换算到mc要乘以6倍才是方块数

OriginX : 100000 //迷宫生成起点X

OriginY : 192

OriginZ : 100000 //迷宫生成起点Z

Chance_Takaramono_rare : 0.02 //每个宝物是稀有组的几率，终点箱子生成的时候会乘以4

Chance_Chest : 0.02 //每个非墙壁的块（3 X 3)上生成一个宝箱的几率

Chance_Monster : 0.1 //每个块(所有3 X 3)上方生成怪物的概率

Takaramono_try_count: 3 //在每个宝箱里面生成宝物的尝试次数

Takaramono_generation_count : 3 //每次尝试生成的宝物数量，总数为 : Takaramono_try_count * Takaramono_generation_count 如果宝物出现重叠则会
少

Maze_Material_Wall : BEDROCK //迷宫墙壁的材料

Maze_Material_ROOF_A : OBSIDIAN //道路上方屋顶的材料

Maze_Material_ROOF_B : GLOWSTONE //墙壁上方屋顶的材料

Maze_Material_Light : SEA_LANTERN //灯笼的材料，这几种材料如果设置不正确，就会按照默认的选项生成，如果不生成灯笼或者换成不发光的方块，难度则会进一步提高(僵尸小白会在迷宫自然生成)，但是可能会导致实体过多。

world : world //定义生成在哪个世界，在正式服务器里面请不要在冥界或者末路之地生成，因为这两个维度出生点在0,0,0，Abort,Finish指令无法工作。这个选项还不太成熟，以后会给多世界进行支持

迷宫中禁止某些命令：
为了防止用传送命令作弊，可以自定义迷宫内部不准使用的命令
修改plugins/MazePlugin/banned_commands.txt 每个命令换一行，被禁止的命令出了迷宫就会恢复，op不受影响。这个文件不要留空了，实在没有就写个example_command这样的无效命令（我懒）
自定义刷怪蛋和宝箱物品配置：
全部以换行符分界，每行是一种材料/实体类型
如果填写不正确，对应的实体/材料将不会生成
plugins/MazePlugin/enchantments.txt : 附魔列表，为宝箱内的武器/护甲/书籍随机附魔
plugins/MazePlugin/takaramono.txt : 一般的宝物，生成几率较大
plugins/MazePlugin/takaramono_rare.txt : 稀有的宝物，钻石之类的可以放在这里
plugins/MazePlugin/spawner_egg_entities.txt : 如果宝物列表有刷怪蛋，那么这个文件定义了刷怪蛋可能刷的怪
如何填写材料？请参照bukkit API的以下几个类文档：
建筑和装备材料：

请在mc wiki里面搜索对应材料，查看它的名称，就是数据值下面那个，根据名称到https://hub.spigotmc.org/javadocs/spigot/org/bukkit/Material.html 的 Enum Constant Summary下面找到对应的名字，写入takaramono.txt,takaramono_rare.txt，即可在宝箱中生成对应的物品，迷宫本体的材料设置也请参考这条

附魔:

所有mc 1.10的附魔在这里：https://hub.spigotmc.org/javadoc ... ts/Enchantment.html
找到Field Summary， 里面是所有附魔的名称，拷贝到enchantments.txt就能使用，至于怎么选？这就考验你的英语水平了2333，最无脑的办法当然是全都添加一遍了。

刷怪蛋定义：
到mc wiki里面找到你要得实体，然后查看它的名称，根据名称到 https://hub.spigotmc.org/javadoc ... ity/EntityType.html 的 Enum Constant Summary 找到对应的值，放到 pawner_egg_entities.txt里面


现在离线玩家不会被卡死在迷宫了
