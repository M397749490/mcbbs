随便写了段代码，适用1.8，1.7自己稍微改改就行了。

首先你需要新建一个类：
  1. public class WorldGen implements IWorldGenerator {
  2.     @Override
  3.     public void generate(Random random, int chunkX, int chunkZ, World world, IChunkProvider chunkGenerator, IChunkProvider chunkProvider) {
  4.         if (world.provider.getDimensionId() == 0) {//主世界
  5.             for (int k = 0; k < 5; k++) {// 5代表生成的频率，目前代表每个chunk有五次生成机会
  6.                 // 初始点x坐标
  7.                 int x = chunkX * 16 + random.nextInt(16);
  8.                 // 初始点y坐标
  9.                 // 这里范围为[10, 64]
  10.                 // 其中的10为最低值，54是向上延伸最高高度
  11.                 int y = 10 + random.nextInt(54);
  12.                 // 初始点z坐标
  13.                 int z = chunkZ * 16 + random.nextInt(16);

  15.                 (new WorldGenMinable(Blocks.beacon.getDefaultState(), 5/*每次生成的数量*/, BlockHelper.forBlock(Blocks.sand)/*要替换的方块，这里是沙子*/)).generate(world, random, new BlockPos(x, y, z));
  16.             }
  17.         }
  18.     }
  19. }
复制代码

之后在postInit里面加入：
  1. GameRegistry.registerWorldGenerator(new WorldGen(), 0);
复制代码

这段代码会在10-64高度内生成信标，如果还不懂就看注释
