在服务端文件加下加world文件夹，将地图文件放到这个文件夹内即可
但我不建议使用开服侠来开服务器，本不好ui方面优化比较差、
你可以在服务端下面新建一个star.bat文件写以下参数（记得使用ANSI编码）
  1. @echo OFF
  2. :head
  3. Title 服务器
  4. java -server -Xincgc -Xmx6G -Xms6G -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseCMSCompactAtFullCollection -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=40 -XX:+UseConcMarkSweepGC -XX:CMSFullGCsBeforeCompaction=2 -XX:CMSInitiatingOccupancyFraction=70 -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar Minecraftserver.jar
  5. echo **********************************************************
  6. echo 服务器关闭，将会重新启动服务端
  7. echo **********************************************************
  8. goto head
复制代码
