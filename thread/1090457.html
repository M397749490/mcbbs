MessageRepeat
关键词回复

简介
这是一个可以触发关键词然后回复信息的插件
类似于这样



命令
命令:
  • /msrepeat help 查看帮助信息
  • /msrepeat on 开启/关闭关键词回复功能
  • /msrepeat reload 重载配置文件
  • /msrepeat [关键词] [回复词]添加关键词
  • /msrepeat remove [关键词]删除关键词
  • /msrepeat color [colorid]改变回复词至指定颜色
  • /msrepeat repeater 开启/关闭复读功能

权限
权限:
  • msrepeat.reload- 重载插件的权限
  • msrepeat.on - 开启/关闭关键词回复功能的权限
  • msrepeat.add 增加关键词的权限
  • msrepeat.remove 删除关键词的权限
  • msrepeat.color 改变回复词颜色的权限
  • msrepeat.repeater 开启/关闭关键词复读功能的权限

安装&配置
安装插件
将插件丢入plugins文件夹
配置文件
  1. config:
  2.   repeater:
  3.     config: false
  4.     # 是否开启复读功能
  5.   color: a
  6.   # 改变本插件的提示回复颜色
  7.   messagerepeat:
  8.     config: true
  9.     # 是否开启关键词回复的功能
  10.     message:
  11.       #触发回复关键词 回复文本
  12.       '啊这': '这啊'
