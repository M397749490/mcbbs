首先，先看一下最最最基础和简单的代码
  1. public class Helloworld{
  2.                    public static void main(String[] args){
  3.                   System.out.println("Hello World");
  4.            }
  5. }
复制代码
这是一个最简单的控制台程序，控制台生成
  1. Hello World
复制代码
这个代码的解析如下
  1. public class Helloworld{
  2. //公共类 类声明 类名（与文件名一样）
  3.                    public static void main(String[] args){
  4. //公共方法 静态方法 无返回值 主方法 字符串数组 变量名
  5.                   System.out.println("Hello World");
  6. //调用println方法往控制台输出文本并且回车
  7.            }
  8. }
  9. //这坑爹代码又白打
复制代码
  1. //这坑爹代码又白打
复制代码
java默认引用一个包，无需再次引用（引用也不会出错）
  1. import java.lang.*;//这是java的默认方法库
复制代码

  1. //单行注释
  2. /*多
  3. 行
  4. 注
  5. 释*/
