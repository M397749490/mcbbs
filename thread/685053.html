作者: 雪狼神    时间: 2017-4-7 09:32
  1. craft
  2. @remove
  3. glass:* + glass:* + glass:*
  4. glass:* + eye_of_ender:0 + glass:*
  5. glass:* + ghast_tear:0 + glass:*
  6. = end_crystal:0:1
复制代码

如果你不知道原版这个公式是怎么写的，输入/rmextract(好像是这个吧?) 生成一个原版配方公式的文件,如果是要看mod里物品的合成公式,/rmextract <mod名>,在RecipeManager/recipes/disabled/下可以看，然后在里面搜索这个物品的公式，在craft下面一行加上@remove


~ 创建新的物品合成公式 ~


你可以在上面创建的那个文件的下面继续输入
比如添加一个新的末影水晶的合成公式
  1. Craft 水晶
  2. 20:0 + 20:0 + 20:0
  3. 20:0 + 381:0 + 20:0
  4. 20:0 + 399:0 + 20:0
  5. = 426:0:4
复制代码

这样原版之中要用恶魂之泪合成给替换成下界之星了，然后可以合成出4个末影睡觉
