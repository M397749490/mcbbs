打开Groupmanager/config.yml：
  1. mirrors:
  2.          # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.          # 第一个世界 'world' 是主世界名称
  4.          # 子世界 'world_nether' 和 'world_the_end' 将会
  5.          # 与父世界使用相同的玩家/用户组文件.
  6.          # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.          # all_unnamed_worlds将会使用所有未定义的世界
  8.          world:
  9.              world_nether:
  10.               - users
  11.               - groups
  12.              world_the_end:
  13.               - users
  14.               - groups
  15.              all_unnamed_worlds:
  16.               - users
  17.               - groups

  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.

作者: xRPQx    时间: 2015-9-9 12:52
打开GroupManager
打开config
添加你要弄的世界,如下

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          plotworld:
          - users
          all_unnamed_worlds:
          - users
          - groups
          world1:
          - users
(红色的就是要添加的,world1可以变换成你想要的世界名，注意下面只要- user~~)

然后游戏里输入/manload
你会发现,worlds里面多了一个文件夹，进去修改group权限即可~
