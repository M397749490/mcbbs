Inquisitor收集玩家资料和统计数据，并将它们存储在一个 MySQL 数据库。它还提供了内置 web 服务器和模板化系统，可以在 web 上查看玩家的数据。

这个插件使用Plugin Metrics数据收集平台（bukkit已内置）。要停止收集数据，在Plugin Metrics配置文件 （plugins/PluginMetrics/config.yml） 中设置"退出"的选项值为 true 。


版本更新
  • V2.18已经发布！
  • 已释放v2.10版本！
安装这个插件需要一个数据库驱动程序访问数据库。如果您已经使用MySQL可以跳过此步骤。如果这是您第一次配置MySQL，请继续阅读。
下载插件的 jar 文件，将其放入您的插件文件夹，运行Bukkit。在控制台上，配置插件连接到以前创建的 MySQL 数据库。

命令

下面列出的所有命令在控制台中输入必须带"inq"这个前缀，在客户端聊天窗口中都带有前缀"/ inq"。所有命令必须都在一行中输入。
<xxx>表示必须输入的参数，像玩家名称的值。
[xxx]代表可选参数。
用|分隔参数代表的选择 ；在管道的两侧使用参数。
所有其他命令文本是字面上输入。但是......

配置

插件的全局配置文件位于：plugins/Inquisitor/config.yml 这是一个标准的yaml格式的配置文件
建议您不要直接编辑此文件。该插件提供的命令来改变或者在游戏中或从控制台文件中的所有设置。如果您决定要手动编辑该文件，请尽量避免在服务端开启时编辑，因为服务端可以覆盖您的更改。
该配置文件分有多个部分。每个部分对应的一组命令。
如果配置文件中不存在某个的选项，则假定这个选项的值为默认值。
全局
这些选项存在"global"一节中，可以用inq set......命令，进行配置，除非另有说明。
选项类型默认版本说明
debug布尔值false所有指定打开调试。打开调试，在控制台将会显示额外的消息。信息量很多。所以您通常不应该开启这个选项，这可能会影响 MC 服务端的性能。
数据库
这些选项存在"db"一节中，可以配置inq db......设置命令，除非另有说明。
选项类型默认版本说明
debug布尔值falsev2.0设置时，将显示所有正在针对数据库执行的 SQL 查询。所有查询都使用预处理的语句，这非常安全并且速度很快。由于此查询参数不会显示，所以你不会看到的查询中的具体问题。
url字符串none所有数据库的 JDBC URL。此 URL 类似jdbc:mysql://localhost/dbname。必要时可以替换不同的主机名和数据库名。如果您的 MySQL 服务器使用非默认端口，把一个冒号和端口号添加在主机名后面 （例如，jdbc:mysql://localhost:4567/dbname).
username字符串none所有连接到数据库时使用的用户名。此用户，在数据库中必须具有CREATE、 ALTER、 DROP、 INDEX、 INSERT、 UPDATE、 DELETE和 SELECT 权限的。
password字符串none所有连接到数据库时使用的密码。密码在配置文件中以明文形式存储，但在控制台或在游戏中显示为"*******"。
prefix字符串none所有表名称前缀。如果该插件配置为使用其他插件或应用程序正在使用的数据库，您可能需要设置此前缀以避免表名称冲突。
share布尔值true所有这个选项控制是否和其他服务器共享数据。此选项通常不应改变，即使该插件只运行在一台服务器上。
统计数据引擎
这些选项存在"stats"一节中，可以使用inq stats......set命令，命令配置，除非另有说明。
选项类型默认版本说明
debug布尔值falsev2.0如果设置，将显示关于引擎的各种详细信息的消息。
flushCheckInterval整数10000v2.0以毫秒为单位，检查需要刷新的缓存的统计组实例之间的间隔。
玩家统计信息
这些选项存在"player"一节中，可以用inq 球员设置......命令，进行配置，除非另有说明。
选项类型默认版本说明
debug布尔值falsev2.0如果设置，将显示关于各种播放器统计详细信息的消息。
flushInterval整数60000v2.0以毫秒为单位，在指定的间隔之间把缓存的播玩家统计信息保存到数据库。
bedCheckInterval整数20000所有以毫秒为单位，在指定的间隔之间对玩家的床执行检查，以查看它们是否仍然存在。
deleteAge整数-1v2.2生存时间，以毫秒为单位之后, 超过这个时间值的玩家统计信息将会从数据库中删除。这是以毫秒为单位，所以要非常小心!值为-1 将禁用此功能。
Web 服务器
这些选项存在"webserver"一节中，可以用inq web 服务器设置......命令中，配置，除非另有说明。
选项类型默认版本说明
playersColumns字符串too longv2.0显示玩家列表。
playersSortColumn字符串namev2.0要排序的玩家列表的默认字段名称。
playersSortDir字符串ASCv2.0玩家列表默认排序的方向。有效值为升序和降序，分别为"ASC"和"DESC"。
playersRestrictColumns字符串too longv2.0显示被ban的玩家列表。
playersPageSize整数50v2.0每个页面默认显示的玩家数。
port整数8080所有端口设置。
upgradeWebRoot布尔值truev2.0如果您做了模板的自定义设置，则应设置为 true。如果这个选项设置为 false，它们不会被覆盖。
worker整数5所有工作线程的数量设置。
