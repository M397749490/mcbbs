Changelog 1.6.4?
  • Area quests
  • Cloner tabs
  • Mailman role
    • Dialogs can send mails
    • Quests can send mails
    • Mails can start quests
  • Spawner job
  • More work on boss job (still not done)
  • Slay command (alternative for butcher and killall)
  • More included sounds
  • Edit villagers with the npc wand
  • Availability with levels
  • Conversation job
  • Dialogs can have commands as well
  • Bug fixes
  • Changes texture/music location from .minecraft/assets/customnpcs to .minecraft/customnpcs/assets/customnpcs
  • Optimized some stuff
  • Added dirty fix for command dialog option on mcpc+ servers
Area quests: Place down a Waypoint block give it a name and range -> create a new quests set it to Location -> edit it and type in the name of your block. Once a player comes near the block with your quest it will complete

Mailman role: When you set an npc to Mailman it will make it interactable. When players interact with it they will be able to send mails to players that have played on the server before. Players will be able to get their mail from mailboxes. When you go near mailmans it will tell you whether you have mail

Spawner job: You can hide them wherever you want and make them spawn entities you have cloned with the mob cloner. The spawner will spawn his entities when it goes into battle.

The /slay command can be used to kill nearby entities, there is /slay all, /slay animals, /slay mobs or just /slay <entityname>

Conversation job: With the conversation job you can have npcs talk with eachother in sequence. At the end of a conversation you can also make it start a quest.

The location for storing textures has changed, because the new version of the minecraft launcher was clearing the assets folder. The new location is .minecraft/customnpcs/assets/customnpcs.

That's about it for now. Have fun.
~Noppes

ps. This version also still works for 1.6.2
