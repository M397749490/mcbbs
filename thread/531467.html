作者: 52Dora    时间: 2015-12-15 23:38
1.使用forge自带的RenderingRegistry注册生物的渲染器（Render），在那个渲染器里指定好僵尸的材质
2.若是在1.8里注册一个生物并且带刷怪蛋，略麻烦，下面照搬自本人无聊写的一个私人Mod：
  1.         // 寻找可用的实体ID
  2.         int mhId = EntityRegistry.findGlobalUniqueEntityId();
  3.         // 注册一个实体....的刷怪蛋
  4.         // 参数：实体的类，实体内部名称，实体数字ID，刷怪蛋的颜色（前景？），刷怪蛋的颜色（背景？）
  5.         EntityRegistry.registerGlobalEntityID(EntityYudachi.class, "Yudachi", mhId, 0x473A52, 0xFFD8A1);
  6.         // 仅仅注册刷怪蛋是不够的，这才是注册实体
  7.         // 参数：实体的类，实体内部名称，实体数字ID，当前Mod的instance，（后面三个不明？很久没接触过差不多忘了
  8.         EntityRegistry.registerModEntity(EntityYudachi.class, "Yudachi", mhId, ModMain.instance, 64, 1, true);
复制代码

据说build 1450（还是2450）之后注册刷怪蛋的方法变简单了，不过本人并没有尝试过

建议在GitHub上找些类似更多生物的模组源代码进行研究（如果要照套，记得查阅版权说明是否允许
