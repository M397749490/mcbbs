  • 这个插件将会在新的世界生成棋盘，不会影响其他世界。
  • 你可以跟你的好友一起玩耍，并可以选择挑战的模式：easy(简单), normal(一般), hard(困难)。
  • 可设置得分奖励。
如何使用
请使用CraftBukkit 1.8及更高的版本来进行游玩。
将"ReversiLab.jar"放到你的插件列表中。
你可以使用"/rev single"来开始一个游戏。
你可以使用"/rev versus (玩家名字)"来邀请一个玩一同进行游戏；被邀请的玩家可以使用"/rev accept"开始一个游戏。
指令
指令是"/reversi"，也可以缩写为"/rev"。
  • /rev single [easy|normal|hard] - 设置并开启一个游戏(难度)。
  • /rev versus (玩家名字) - 邀请一位玩家一同进行游戏。
  • /rev accept - 接受邀请。(需要有人邀请才能输入)
  • /rev deny - 拒绝邀请。(需要有人邀请才能输入)
  • /rev cancel - 关闭游戏。(关闭黑白棋游戏)
  • /rev spectator (玩家名字) - 查看观察者。
  • /rev rank [win|lose|played|ratio] [versus|easy|normal|hard] - 显示排名分数
  • /rev reload - 重启插件。
权限
  • reversilab.command - 允许使用 "/rev" 。
  • reversilab.single - 允许使用 "/rev single" 。
  • reversilab.versus - 允许使用"/rev versus" 。
  • reversilab.accept - 允许使用 "/rev accept " 。
  • reversilab.deny - 允许使用 "/rev deny "。
  • reversilab.cancel - 允许使用 "/rev cancel " 。
  • reversilab.spectator - 允许使用 "/rev spectator " 。
  • reversilab.rank - 允许使用 "/rev rank " 。
  • reversilab.reload - 允许使用"/rev reload "。默认只有OP拥有
  • reversilab.* - 允许使用ReversiLab插件所有指令。
