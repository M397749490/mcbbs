这个插件能干嘛？自定义物品，在游戏内，可以自定义物品名称、配方、能力，附魔物品的名称颜色的物品颜色。
比如，一把铁剑，你可以做一个附魔书，附魔后可能是瞬间击杀，可能是失明（译者：近战失明貌似有用...）等，或者两个都有。弓箭也一样，你可以给OP创建一个无敌的武器...







指令列表


/ci create <物品名称> <要给予的玩家>  创建一个物品并给予某个玩家/ci info 显示手中物品的信息
/ci reload 重新载入配置文件
/ci help 显示所有指令





刮刮乐！


我怎么会告诉你颜色代码在这里？
http://www.minecraftwiki.net/wiki/Formatting_codes


创建项目
一般每一个项目都有11个值：
1 名字（物品ID）
2 身份
3 合成方法
4 权限
5 显示出来的名字
6 攻击力
7 颜色
8 附魔能力

例子

  1.   SwordExample:
  2.     ID: 276
  3.     DisplayName: Sword Example
  4.     UsePermission: false
  5.     Abilities:
  6.     - Poison
  7.     - Lighting
  8.     - Death
  9.     Lore:
  10.     - This is lore
  11.     - This is another lore
  12.     Color: §6
  13.     UseRecipe: false
  14.     UseCustom: true
  15.     Enchantments:
  16.     - KNOCKBACK
  17.     EnchantmentsLevel:
  18.       KNOCKBACK: 2
复制代码


  • ID = 物品ID
  • Displayname = 显示名称
  • UsePermission = 用户权限 （一般普通组）
  • Abilities = 能力（比如上面的能力是 Poison中毒 Lighting被雷劈 Death死亡（或者攻击力？））
  • Lore = 不知道怎么翻译了 = = 绝杀？？？
  • Color = 颜色 请查看帖子上方刮刮乐！
  • UseRecipe = 配方
  • UseCustom =  就是上说的“绝杀”项目名称 删除就变成虚假的了，就是在游戏里显示，但是无作用
  • Enchantments = 附魔 （上面的是击退）
  • EnchantmentsLevel = 附魔等级 （上面的是击退 2 ）



到此恭喜你设置好了！！！！！ 你可以重启服务器或者用/ci reload 重新载入配置文件 然后/ci create <刚才填写的名称> <要给的人>、
