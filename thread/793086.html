作者: 决战堂    时间: 2018-5-2 11:05
/mv help 查看帮助

/mv modify set difficulty 0/1/2/3 这个是改难度设置成0就是和平了

difficulty 0 = 和平
difficulty 1 = 简单
difficulty 2 = 普通
difficulty 3 = 困难

重启以后恢复 你要确定关服的时候是输入 stop 关服
作者: Mr.柴    时间: 2018-5-2 12:00
/mv modify set difficulty 0
/gamerule doMobSpawning false
两个指令都在地皮输一次
