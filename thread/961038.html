MultifunctionEss
综合超强超多功能的插件
——插件全部功能都可独立彻底关闭或者开启,并且99%可自定义——

  ▊插件模块介绍

《世界管理模块》
   生物无法生成 (支持-自定义世界和生物)
   携带物品无法加入世界 (支持-自定义世界和物品,装备栏和物品子Id)
   无法使用物品 (支持-自定义世界和物品与物品子Id)
   (指定世界指定高度无法破坏/放置方块 白名单/黑名单(世界保护) 全局设置 死亡掉落 具体请看下面的世界管理介绍)

《物品处理模块》
   掉落物清理 (支持-指定世界或者全部世界,自定义开关此功能,自定义提示和清理周期,是否异步)
   绑定物品 (支持-自动绑定玩家背包物品,命令绑定手中物品,所需物品,可绑定物品Id和名字,绑定保护,是否异步)
   命令进行物品保存 (支持-Lore 名字 附魔 子Id)
   命令对物品Lore和名字进行多种操作

《玩家管理模块》
   命令设置玩家加入和退出提示 (支持-默认提示)
   玩家Tp,Back,Warp (支持-自定义权限,传送延迟,过期时间,金币,WarpGui)
   命令设置玩家头顶称号 (支持-目前只是简单的一个功能,后续扩展)
   超强命令执行 (支持-让 后台 使玩家执行 自身权限/OP权限 命令)
   0.4.1版本 新增 >
   玩家自定义命令绑定功能 (支持-最多绑定数量)

《玩家属性模块》
   目前包含属性(12) > 攻击 防御 暴击几率 暴击伤害 嗜血几率 嗜血量 诛心 弑魔 生命 百分比生命 穿透伤害 坚毅
   需求类属性(3) > 等级需求 权限 耐久
   具体内容请看下面的 玩家属性模块 介绍

《Lore触发命令模块》
   物品Lore触发命令 (支持-多种条件,多种触发方法,多命令,OP/后台/自身 权限执行)

《命令管理模块》
   0.4.1版本 新增 >
   全局自定义命令绑定功能

需求类属性 > (未达到需求时 是不会加载物品属性的)

耐久 (物品耐久)

  ▊命令帮助

- 命令大全帮助 -
/mfe  -查看命令帮助
/mfe pm  -玩家模块命令帮助
/mfe pm2  -玩家传送和Warp命令帮助
/mfe im  -物品模块命令帮助
/mfe reload  -重新加载插件

# 玩家模块命令帮助
- 命令绑定功能
/mfe bc 命令1 命令2  -将命令1绑定为命令2
/mfe bc del 序号  -删除指定序号的命令绑定
/mfe bc list  -展示全部命令绑定内容
输入 命令2 即触发 命令1
命令内 %p代表玩家名字 _代表空格 不允许出现 : 符号

- 玩家加入提示功能
/mfe setj 玩家名字 提示  -设置指定玩家的加入提示
/mfe setq 玩家名字 提示  -设置指定玩家的退出提示
提示内 _代表空格 %p代表玩家 null代表删除

- 后台使玩家执行命令
/mfe opcmd 玩家名字 命令  -让玩家以管理员权限执行命令
/mfe cmd 玩家名字 命令  -让玩家以自身权限执行命令
命令内 %p代表玩家名字

- 玩家头顶称号
/mfe settag 玩家名字 称号  -设置玩家头顶称号
称号内 null代表删除

# 物品模块命令帮助
- 绑定功能
/mfe bd  -绑定手持物品

- 物品 lore和名字 操作功能
/mfe name 名字  -为手中物品设置名字
/mfe lore add 指定lore  -为手中物品添加指定lore
/mfe lore setlin 行数 指定lore  -设置手中物品指定行数的lore
/mfe lore del 指定lore  -删除手中物品指定lore
/mfe lore dellin 行数  -删除手中物品指定行数的lore
lore或者名字支持颜色代码[&]

- 物品保存功能
/mfe Item give 玩家 代号 数量  -获取此代号物品
/mfe Item Save 代号  -以此代号保存手持物品
/mfe Item remove 代号  -删除此代号物品
保存物品时 请重新用此插件修改物品名字
否则物品名字会变成英文名字 只需要修改一次即可

# 玩家传送和Warp命令帮助
- 玩家传送和Warp
/tp 玩家名字  -强置传送到玩家哪里
/tpall  -强置全服玩家传送到你这
/tpa 玩家名字  -请求传送到玩家哪里
/tpaccept  -接收别人的传送请求
/tpadeny  -拒绝别人的传送请求
/back  -返回死亡位置或者上一个位置

/setwarp 坐标名字 所需权限  -以你的位置设置一个坐标
/delwarp 坐标名字  -删除一个坐标
/warp 坐标名字  -传送到这个坐标
所需权限内 null代表不需要权限
