作者: Timtokivd    时间: 2015-7-30 10:04
想要添加这个权限需要你打开权限组插件的config.yml
找到这些
       world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
然后替换为
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          此处替换为刷怪世界的名字:
          - users       //只继承主世界的users.yml权限表，不继承groups.yml
          all_unnamed_worlds:
          - users
          - groups
然后重启服务器
并复制主世界的groups.yml（在/plugins/groupmanager/worlds/world）到新生成的目录中
再把你那个build改成false
在perimissions:（添加）
    - essentials.build.drop.*         //丢弃
    - essentials.build.interact.*     //交互
    - essentials.build.pickup.*      //捡拾
    - essentials.build.use.*          //使用
这样玩家就有基本权限，但是只是不能破坏了
