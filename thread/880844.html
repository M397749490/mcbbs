下载附件

2020-2-8 10:47 上传

  • 此模组添加了一个新物品：搬运架，它可以被用于箱子和木桶的搬运。
  • 拥有标签 carry_chest-spawner 的玩家可以使用搬运架复制刷怪笼。

获得方式

  • 向地上扔 6 块铁锭 来合成 搬运架。

使用方式

  • 主手拿搬运架对所要搬运的方块右键，搬起方块；
  • 搬起后对所要放下的位置右键，放下方块。

已知 BUG

  • 使用搬运架放置的箱子无法与已有的箱子合并成大箱子。

模组信息

  • 命名空间：carry_chest
  • CustomModelData：23333~23335

使用命令

命令效果
loot give @s loot carry_chest:carrier获得搬运架。
tag @s add carry_chest-spawner给予自己使用搬运架复制刷怪笼的能力。
tag @s remove carry_chest-spawner剥夺自己使用搬运架复制刷怪笼的能力。
function carry_chest:remove移除模组建立的记分板。

不能合并大箱子可以考虑一下在放下箱子时检测隔壁是否有未合并的同方向箱子，如果有就在放下箱子时给他[type=left]或者[type=right]的属性，这样就能自动合并了,并且我自己试了一下这个指令有效
execute if entity @s[y_rotation=-180..-135.01] if block ~-1 ~ ~ minecraft:chest[type=single,facing=south] unless block ~1 ~ ~ minecraft:chest[type=single,facing=south] run setblock ~ ~ ~ minecraft:chest[facing=south,type=left] replace
