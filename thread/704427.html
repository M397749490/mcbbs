将Skript.jar放入Plugins文件夹中 重载或重启
这时会自动生成一个名为 Skript 的文件夹
将你写的脚本放入Skript/Scripts文件夹 然后客户端或服务端输入sk reload [脚本名]
如果看到 Successfully reloaded 脚本名.sk 那么这个脚本就加载成功了

- 插件介绍 -
Skript 是一个非常流行的服务器插件
它可以允许你不需要掌握任何的Java知识 从而用脚本模拟出插件的效果
你可以用它制作出任何游戏内容
登陆 排行榜 公告 点券系统 会员系统 强化系统 武器属性等
甚至你可以用它来代替你的Essentials！

正篇
&1.这些东西是什么?
           首先打开你的Notepad(推荐 不推荐使用记事本) 新建一个后缀为.sk的文件到Plugins/Skript/Scripts
             (你也可以在Scripts文件夹内创建一个后缀为.txt文件 然后将后缀改为.sk)
             然后打开
                Skript 一般的语法结构是由 触发器 →  条件 → 效果组成的
             当所有条件满足 效果就会被触发
             举个栗♂子
           
  1. on chat: #当玩家发出信息的时候
  2.     if message contains "这服咋玩啊": #如果信息包含字符 "这服咋玩啊"
  3.         message "&6输入 /xx 打开新手教程" to player #发送信息给玩家
复制代码
            这就是一个简单的小脚本(之前写的那个被吞了..)
             注意 如果语句后面有一个 ":"(冒号) 必须用4个空格或1个tab进行缩进 否则脚本会报错并且无视该语句的判断
             并且你不能在你的脚本中用半角符号 (如 "：")
             所有的语句和文档都在上面的文档中 本帖不再过多介绍
             另一个栗♂子
  1. on join: #在玩家进入服务器的时候
  2.     if player has the permission "我真帅": #如果玩家拥有权限 "我真帅"
  3.         if player has permission "VIP": #如果玩家拥有权限 "VIP"
  4.             set join message to "&6帅气的 &f%player% &6进入了服务器" #设定进入信息为 "xxx(省略)"
  5.             strike lightning effect at the player #在玩家的位置生成一道雷电(不会造成伤害)
复制代码
             %player% 为Skript的玩家变量
