标题: [1.14]选择器中的坐标选择失效？
我想要获取位于主世界坐标23 65 179的一个物品展示框的数据，于是我使用了以下指令。
/execute as @e[type=minecraft:item_frame,x=23,y=65,z=179] run data get entity @s
结果我得到了主世界中所有物品展示框的信息，满满一屏幕。
我一开始以为是1.13以后的新特性需要加上距离，于是我改成了：
/execute as @e[type=minecraft:item_frame,x=23.5,y=65.5,z=179.5,distance=3] run data get entity @s
然后我得没有得到任何数据
