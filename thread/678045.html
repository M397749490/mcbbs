Time Is Money
时间就是金钱

本插件是另一款同名TimeIsMoney插件，
并非目前广泛使用的版本，请在使用前确认清楚，
该插件是否为你所需要的那一个插件。
另一个版本：站内链接点我跳转

≡ 插件介绍 ≡
一个服务器开了好长时间了，玩家也玩了很久了。。
只不过，这些时间又没有办法变成金钱，真浪费呢~
这个插件可以让你在游戏内的每时每刻都可以赚钱！

≡ 搬运授权 ≡

≡ 插件特性 ≡
  • 可设置每一段时间内，服务器给予玩家金钱/给予物品/执行命令
  • 可禁止AFK(挂机)状态下玩家的金钱获得(可禁用该功能)
  • 插件自带ATM取款机
  • 无需建造提款机，直接到账更便捷

≡ 图片展示 ≡
ATM机显示


≡ 命令权限 ≡
命令/行为作用权限
"/tim"重载插件tim.reload
"/atm"通过命令直接打开ATM机tim.use
"/atm <player>"给其他玩家打开ATM机tim.admin
放置ATM牌子在随意地点放置ATM牌子tim.atm.place
使用ATM牌子使用已被放置的ATM牌子tim.atm.use
挂机奖励挂机时仍然可以获取奖励tim.afkbypass

≡ 配置文件 ≡
Config.yml[已汉化]
  1. # 配置文件版本，不要修改
  2. configuration-version: 12

  4. # 插件自动更新，建议开启
  5. auto-update: true
  6. # DEBUG模式，测试时可开启
  7. debug-log: false

  9. # 你可以禁止某些世界的获取奖励功能
  10. disabled_in_worlds:
  11. - "creative_world"

  13. # 你可以定义是否给挂机玩家奖励
  14. # 给予tim.afkbypass权限可忽略此项
  15. afk_payout: false
  16. # 在聊天框内显示奖励信息
  17. display-messages-in-chat: true
  18. # 在物品栏上方显示奖励信息
  19. display-messages-in-actionbar: true
  20. # 在物品栏上方显示奖励信息的显示时间
  21. display-messages-in-actionbar-time: 10
  22. # 给予金钱奖励的间隔时间
  23. give_money_every_second: 600
  24. # 给予的金钱是否直接存储到ATM机内
  25. store-money-in-bank: false

  27. # 同样IP的多名玩家是否给予多份奖励
  28. # 如为false，则仅给其中一位以奖励
  29. allow-multiple-accounts: true

  31. # 可通过几率给予奖励
  32. # 但是给予几率和依照权限给予
  33. # 你只能选择其中一个方向执行
  34. choose-payout-by-chance: false

  36. # 你可以选择任意数量的奖励
  37. payouts:
  38.   1:
  39.     # 每一次给予的金钱量
  40.     payout_amount: 50
  41.     # 当天可给予的最大金钱量
  42.     max_payout_per_day: 1000
  43.     # 获得该奖励的几率，去掉下方的#可直接使用
  44.     #chance: 10
  45.     # 获得该奖励的权限，不填默认无
  46.     permission:
  47.   2:
  48.     payout_amount: 100
  49.     max_payout_per_day: 10000
  50.     # 每一次给予的时候后台执行的命令
  51.     commands:
  52.       - /give %player% diamond 1
  53.     # chance: 90
  54.     # 你可以设置任何你想要的权限，例如：myserver.donor
  55.     permission: tim.vip

  57. # 翻译信息
  58. message: "&r[&aTIM&r]&a你获得了&c%money%&a金钱奖励!"
  59. message_payoutlimit_reached: "&r[&aTIM&r]&c你今天可获得的最大奖励数额已满，你无法再获得奖励!"
  60. message_afk: "&r[&aTIM&r]&c你无法获得金钱奖励，因为你正处在挂机状态下!"
  61. message_multiple_ips: "&r[&aTIM&r]&c你无法获得金钱奖励，因为你正在同时开启多个账号!"
  62. message_actionbar: "&a你获得了&c%money%&a金钱奖励!"
  63. message_payoutlimit_reached_actionbar: "&c你今天可获得的最大奖励数额已满，你无法再获得奖励!"
  64. message_afk_actionbar: "&c你无法获得金钱奖励，因为你正处在挂机状态下!"
  65. message_atm_noperms: "&r[&aTIM&r]&c你没有权限使用ATM机!"
  66. message_atm_nomoneyinbank: "&r[&aTIM&r]&c你没有足够的钱存储在银行内!"
  67. message_atm_nomoney: "&r[&aTIM&r]&c你没有足够的钱!"

  69. # ATM -> 请在牌子的第一行输入[atm]以建造ATM机!
  70. atm_title: "&cATM"
  71. atm_withdraw: "&c取"
  72. atm_deposit: "&c存"
  73. atm_balance: "&c银行账户余额:"

  75. # 你可以设置每个世界组有不同的ATM机(即金钱在这些世界下不同步)
  76. # 注意: 启用此功能后，现有的银行账户内的所有金钱将会被移除!
