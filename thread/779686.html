这个就是检测头部物品属性的id
把头颅的id加进去就行了
然后mm写物品的话
xstk:
  Id: 397
  Data:
  Display: '&e骷髅头颅'
  Lore:
  - '&3生命值: &d+100'
  Enchantments:
  - DURABILITY:0  
  Options:
    Unbreakable: true
    Color: 0,255,0
这样做出来的头颅就会读取属性了
