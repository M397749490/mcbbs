FreeSwitchTitle
新人,如果有不好的地方请大神勿喷~欢迎大家提交BUG~写这个插件就是为了满足我服务器里面的玩家,然后这个奇葩的插件就出来了~
计划
1、玩家血量值          √
2、手撸伤害值          ×
3、移动速度值          √
4、 梨子效果~          √
简介
这个插件可以让一个玩家,同时拥有多个称号,并且可以随时切换!还可以给某个称号添加一个BUFF效果,颗粒效果!
命令 & 权限
指令                                  权限                                                介绍
/fst list                            无                                 查看自己已拥有的称号列表
/fst list [玩家]              fst.list.admin                     查看某个玩家的称号列表
/fst view                         无                                 查看现在正在使用的称号
/fst view [玩家]           fst.view.admin                  查看某个玩家正在使用的称号
/fst use [ID]                   无                                 使用这个称号(称号ID可以用/fst list查看)
/fst add [玩家] [ID] [称号]           fst.add.admin         给某个玩家添加一个称号
/fst del [玩家] [ID]        fst.del.admin                          删除某个玩家的一个称号
/fst set [玩家] [ID] [join|health|move|allow] [内容]        fst.set.admin        给指定玩家的某个称号加上一个BUFF
