外置登录的话，如果你正在使用 HMCL，可以在目录下创建一个名为 authlib-injectors.json 的文件
文件内容如下:

  2. {
  3.     "urls": [
  4.         "https://littlesk.in/api/yggdrasil/"
  5.     ]
  6. }
复制代码
这样即可在打开启动器时，自动弹出新建账号
