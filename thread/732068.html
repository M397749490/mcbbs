注意 这是Sponge插件 最低支持SpongeAPI 7


介绍
这是一款PVP竞技场插件，它允许管理员在服务器上创建多个竞技场并进行游戏


特点
支持1v1和2v2
可创建多个竞技场
支持创建包含原版物品以及MOD物品的工具包，支持附魔和耐久度
加入游戏时自动保存玩家的物品
取消重生界面

命令
1.创建竞技场
您需要以管理员权限创建竞技场
指令：/ba create arena <竞技场名称>

2.设置出生点
您需要设置大厅 两队的出生点 观察点 (共四个出生点)，<出生点类型>可以是lobby spectator a b
指令：/ba edit <竞技场名称> spawn <出生点类型>
设置大厅：/ba edit <竞技场名称> spawn lobby
设置观察点：/ba edit <竞技场名称> spawn spectator
设置A队出生点：/ba edit <竞技场名称> spawn a
设置B队出生点：/ba edit <竞技场名称> spawn b

当完成以上步骤(1和2)时，竞技场部分已设置完成，可以进行游戏

3.创建工具包
支持创建包含原版物品以及MOD物品的工具包，物品上的附魔和耐久度也会被保存
您需要在背包内准备好物品，插件将会保存背包内的物品
如需修改原先创建好的工具包，可使用相同的指令重新创建并覆盖
指令：/ba create kit <工具包名称>

玩家指令：
/ba join <模式> #加入一个游戏，其中<模式>可填solo或doubles，solo指1v1，doubles指2v2
/ba kit <工具包名称> #获得一个工具包
/ba quit #退出游戏
