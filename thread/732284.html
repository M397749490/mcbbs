已解决
Essentials的config.yml
  1. # 是否关闭加入、退出游戏的提示消息
  2. # 当启用后, 具有对应权限的玩家加入、离开游戏将不会在公屏上显示消息
  3. # In addition, people with essentials.silentjoin.vanish will be vanished on join.
  4. allow-silent-join-quit: true

  6. # 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
  7. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  8. custom-join-message: "none"

  10. # 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
  11. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  12. custom-quit-message: "none"
