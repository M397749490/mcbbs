特性
  • 玩家可通过卷轴传送
  • 基于权限
  • 非常轻量
  • 指令简单
  • 易于配置
  • 可设置延时 (可设置)
  • 传送期间移动则取消 (可设置)
  • 可设置 Bypass 权限
  • 多世界支持
  • 可随机传送 (可设置在制定区域内随机传送)

权限
  • - scrollteleportation.teleport 允许使用
  • - scrollteleportation.give 允许使用给予指令
  • - scrollteleportation.walkbypass 允许玩家无视传送期间走动造成的传送取消
  • - scrollteleportation.delaybypass 允许玩家无视传送等待时间
  • - scrollteleportation.usesbypass 允许玩家无视以上两条限制
  • - scrollteleportation.potioneffectbypass 允许玩家忽略药水效果
  • - scrollteleportation.set 允许玩家使用/scroll set
  • - scrollteleportation.create 允许玩家使用/scroll create
  • - scrollteleportation.reload 允许玩家使用/scroll reload

指令
  • /scroll 显示Scroll Teleportation 信息
  • /st  这是/scroll 的缩写.
  • /scroll give <卷轴代号> <玩家> 给予玩家该卷轴 (玩家处不填则给自己)
  • /scroll create <卷轴代号> <卷轴显示名> <延时> <使用次数> 创造一个卷轴.
  • /scroll reload 重载
  • /scroll set <变量> <卷轴代号> <值> 给该卷轴的某变量设置值
