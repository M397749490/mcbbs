作者: 晴路卡    时间: 2020-6-6 15:15
1.13+
先搞个死亡数记分板和计玩家数的记分板
  1. scoreboard objectives add death deathCount
  2. scoreboard objectives add num dummy
复制代码

然后依次高频执行以下命令
  1. tag @a[scores={death=1}] add dead
  2. execute as @a[scores={death=1}] run scoreboard players set #player num 0
  3. execute as @a[tag=!dead] if entity @a[scores={death=1}] run scoreboard players add #player num 1
  4. execute as @a[scores={death=1}] if score #player num matches 1 run say "只剩一人"
  5. scoreboard players set @a[scores={death=1}] death 0
复制代码
其中“say "只剩一人"”可以替换为你要执行的命令
当然如果这是个游戏的话别忘了在游戏结束的时候执行
  1. tag @a[tag=dead] remove dead
