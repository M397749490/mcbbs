复制代码
假如tag=sethomex的实体只存在一个且在x<0的位置时，执行这两条命令，你会发现这两条命令都会执行失败
execute @e 后面的坐标如果在世界外，则会执行失败，游戏也不支持把实体tp到世界边界之外
利用这个特性，通过二分法可以得到玩家到负边界的距离。你问二分法是什么？去百度啊：https://baike.baidu.com/item/二分法/1364267?fr=aladdin
首先把玩家的sethomex记分板分数设置为-30000000
检测负边界距离你是否大于30000000，如果大于则成功给tag=sethomex加上30000000分，如果不大于，则利用刚刚那个特性加分失败，
如果大于，就再将基准点向负边界移动30000000格，如果小于，再以原来的位置为基准点，再在新基准点检测到负边界是否离基准点大于15000000，大于就再加15000000分，不大于，加分失败，
如果大于，基准点再想负边界移动15000000格，小于还以原来的位置为基准点，再在新基准点检测到负边界是否离基准点大于7500000，以此类推，不断将上次检测的格数÷2直到为1，tag=sethomex的分数即为玩家到负边界的距离，距离-30000000即为玩家所在的坐标
保存玩家所在x轴和z轴坐标都用这个办法，获取y轴坐标的办法要简单一些，只需要检测玩家脚下有多少个方块，将tag=sethomey 的实体执行命令影响方块数的stats保存到sethomey记分板，execute @e[tag=sethomey] ~ ~ ~ testforblocks ~ ~-1 ~ ~ 0 ~ ~ 0 ~即可检测玩家脚下有多少个方块，并将结果记入记分板
  1. kill @e[tag=sethomey]
  2. summon area_effect_cloud ~ ~ ~ {Tags:["sethomey"]}
  3. scoreboard objectives add sethomey dummy
  4. scoreboard players add @e[tag=sethomey] sethomey 0
  5. execute @e[tag=sethomey] ~ ~ ~ stats entity @e[tag=sethomey] set AffectedBlocks @s sethomey
  6. execute @e[tag=sethomey] ~ ~ ~ testforblocks ~ 0 ~ ~ ~-1 ~ ~ 0 ~
  7. scoreboard players operation @s sethomey = @e[tag=sethomey] sethomey
  8. kill @e[tag=sethomey]

复制代码
玩家有一个数据标签是Dimension,如果玩家在下界，则Dimension后面的值就是-1，如果在主世界则Dimension后面的值就是0，如果在末地则Dimension后面的值就是1，这样就可以区分玩家在哪个世界执行了function
分别给在不同世界执行function的玩家加上不同的标签，可以防止玩家在不同的世界错误传送
得到玩家在记分板里的各位数
operation中的/=和%=的作用分别是原分数÷另一个分数取整数和原分数÷另一个分数取余数
比如123456789÷10的整数部分是12345678，余数是9，则9就是个位数，把12345678÷10取余数就是8,8就是十位数，整数部分再÷10取余数……以此类推，而且记分板内的分数只支持-2147483648到2147483647为有限位数，所以可以很轻松得到记分板里的各位数

  6. scoreboard players set 100000 home 100000
  7. scoreboard players set 1000000 home 1000000
  8. scoreboard players set 10000000 home 10000000

  3. scoreboard players operation @s home %= 10 home
  4. execute @s[score_home=1,score_home_min=1] ~ ~ ~ tp @e[tag=home] ~10000000 ~ ~
