正式版是Minecraft经过一段时间的预览版测试之后得到的稳定版本，也是众多材质、MOD与CraftBukkit插件会逐渐跟进的版本。官方正版登陆器也会第一时间进行推送。建议玩家与开服的朋友关注其相关Mod及其所需的API、CraftBukkit与其插件的更新，迎接新的正式版吧！专注于单人原版游戏的玩家可立即更新，多人玩家请关注您所在的服务器的通知。
请勿将版本号中不加任何前缀的1.8.X与一年多前的Minecraft Beta 1.8混淆。
转载本贴时须要注明原作者以及本帖地址。

https://twitter.com/Dinnerbone/status/536892698817724416
Minecraft 1.8.1 已经发布。
Dinnerbone: "Minecraft 1.8.1 is now avaliable to download in your launcher."
Dinnerbone: 现在可以在启动器上下载 Minecraft 1.8.1。

新内容：
以下内容来自Minecraft Wiki:
Credits 感谢名单
  • Ryan Holtz (TheMogMiner) and Michael Stoyke (Searge) are now mentioned in the credits
  • Ryan Holtz 和 Michael Stoyke 现在已经在感谢名单中
Gamerules 游戏规则 (/gamerule)
  • doTileDrops no longer affects entities
  • doTileDrop 游戏规则不再影响实体
Jack o'Lanterns 南瓜灯
  • Can be used to create iron golems and snow golems again
  • 南瓜灯（重新）可以被用来制作铁傀儡与雪傀儡了。
Maps 地图
  • Changed some colors
  • 更改了一些颜色
Mobs 生物
  • No longer run from creepers
  • 怪物不再从即将爆炸的爬行者边逃跑
Performance 性能
  • Various improvements
  • 一些增强
  • Many optimizations
  • 很多优化
Potion of Leaping 跳跃药水
  • Can now be extended with redstone
  • 现在可以用红石延长时效了
Witch Huts 女巫小屋
  • Newly generated witch huts can spawn witches on Y 64 to 71
  • 在新版本中生成的女巫小屋可以在 y=64 to 71 之间生成女巫了（以前是66-71？）
  • This allows for three spawning floors in witch farms
  • 这可以让女巫塔拥有3层刷怪空间
Options 设置
  • Renamed "Multiplayer Settings" to "Chat Settings".
  • 把“多人游戏设置”重命名为“聊天设置”（中文未测试）
  • Off/fancy/fast clouds
  • 可以调节云朵了（就像Optifine Mod里一样）
  • Off/on entity shadows
  • 可以开关生物影子了
  • Fast/fancy now only controls leaves and rain particles
  • 现在快速／高质量只控制叶子和雨点了
Dropped items 掉落物品
  • Now rotate on fast graphics
  • “快速”质量设置中掉落物品也会旋转了
问题修复

修复了116个漏洞
116 Issues Fixed
链接为英文

更新1.8后有些人会出现FPS过低的情况，请进入视频调节更改启用缓冲区顶点对象选项，一般情况下这问题就解决了~

对于非正版用户：可以到推荐启动器列表寻找合适的启动器。如有仍疑惑请到原版问答板块提问。
