         [Magic Martial Arts]     插件介绍：
这是一款小型的、能够生成NPC并绑定命令在NPC上面的插件。功能强大，使用简单！
该插件会有如此中二的名字原因是....它将作为一系列小游戏插件的前置。当然小游戏插件会在将来缓慢更新。敬请期待！
输入/mma可以查看该插件的命令清单。

         [Magic Martial Arts]     权限&指令：
MagicMartialArts.use 默认op。

/mma set [物品类型]  [物品标签] [是否掉落true/false]   将手上的物品录入物品库。

                [物品类型]可选列表: HELMET 头盔   CHESTPLATE 胸甲

                               LEGGINGS 护腿  BOOTS 靴子  ITEMS 手持物品

/mma itemlist 获取所有物品库里的物品标签。

/mma model [模型名称]  在你的位置生成一个标签为[模型名称]的模型。

/mma modellist 获取所有模型库里的模型名称。

/mma setModel [模型名称] [参数名称] [内容

设置头盔:  /mma setModel [模型名称]  HELMET [头盔名称。

设置胸甲:   /mma setModel [模型名称]  CHESTPLATE [胸甲名称

以此类推，可用参数列表：HELMET 头盔  CHESTPLATE 胸甲

                       LEGGINGS 护腿  BOOTS 靴子  MAX_HEALTH 最大生命

                       DISPLAY_NAME  显示名称  ITEM_IN_HAND

DAMAGEABLE 是否可以被伤害（true 不可被伤害    false 可被伤害）

/mma createModel [模型名称] [怪物类型]。

常用怪物类型：僵尸 ZOMBIE  僵尸村民  ZOMBIE_VILLAGER

       狼  WOLF   女巫  WITCH    蜘蛛  SPIDER  雪人  SNOWMAN

       骷髅  SKELETON   史莱姆  

/mma getStick  获取秒杀棒，可以清除不可被伤害的模型



/mma deleteModel [模型名称] 删除模型。

/mma delete [物品类型] [物品标签]  删除某物品库里的物品。

/mma bindCommand [模型名称] [add添加/delete删除] [执行命令]。

/mma clone [克隆对象] [新的名称] 克隆一个已存在的模型。

            [Magic Martial Arts]     使用教程:
这一天，May兴高采烈地在他的服务器安装了MMA插件，打算试一试，于是他阅读了MMA的使用教程。
May打算先新建一个名叫example的模型试试手。
于是他输入了指令：/mma createModel example zombie
经过多次实践，May发现最后一段指令“zombie”还可以替换成
僵尸村民  ZOMBIE_VILLAGER 狼  WOLF
女巫  WITCH    蜘蛛  SPIDER  雪人 SNOWMAN
骷髅  SKELETON    史莱姆  SLIME 等其他怪物，且不区分大小写。
(/mma createModel [模型名称] [类型])
因为May想让这个模型成为站在主城的招待，所以他想让这个模型不会受伤。
于是他输入指令：/mma setModel example damageable false
如果他输入指令：/mma setModel example damageable true这个模型被攻击时就会受伤。
(/mma setModel [模型名称] [参数名称] [内容]  设置模型的参数)
May想让这个模型戴上绿帽子，于是他拿着绿帽子，输入指令：/mma set Helmet h true
将绿帽子取名为h。
(/mma set [物品分类] [物品标签] [是否可掉落true/false] 将手上的物品添加进物品库。注意！物品标签不可重复，否则会出错！)
物品标签列表: helmet:帽子 chestplate:胸甲 leggings:护膝 boots:靴子 items:手持物品
在这之后，May分别把胸甲起名为c，靴子起名为b录入了物品库,火把起名为i录入了物品库。May想检查物品是否进入物品库，于是输入/mma itemlist查看物品列表。
当May兴奋地用/mma model example 召唤出模型时，令人扫兴的一幕发生了。
（/mma model [模型名称]  在你的位置和状态召唤模型！如果你在抬头，那么模型也会抬头。）
是的，这个模型没有穿上May精心准备的衣服！但是聪明的May一下就找到了问题所在。
他输入命令/mma setModel example helmet h
(/mma setModel [模型名称] [参数名称] [内容]  设置模型的参数)
可用参数列表：HELMET 头盔 CHESTPLATE 胸甲
LEGGINGS护腿  BOOTS 靴子  MAX_HEALTH 最大生命(整数)
DISPLAY_NAME  显示名称 ITEM_IN_HAND 手中物品
DAMAGEABLE是否可以被伤害（true可被伤害  false 不可被伤害）
模型成功穿上了帽子。May用指令依次让模型穿上胸甲、靴子，拿起火把。
May再次使用/mma model example召唤模型。

这时问题又来了。因为May设置让模型无法被破坏，所以旧的没用模型无法清除了。于是May输入/mma getStick 得到了无敌毁灭棒。
May用无敌毁灭棒敲了旧的模型一棒，旧的模型挂掉了！
May还使用/mma setModel example display_name Azombie 将模型的展示名称设置为Azombie。
在此之后，May想给模型绑定命令，这样当玩家左击模型时，就会以玩家自己的身份自动执行命令或者说话。
于是May输入指令/mma bindCommand example add May使用了指令/spawn
（/mma bindCommand [模型名称] [add添加  delete删除] [如果add 这是一段话或者一段指令]）
紧接着May输入指令/mma bindCommand example add /clearMay
这样一来，生成的模型在被左击时，左击的玩家会先说“May使用了命令/spawn”，然后再使用指令“/clear May”
May输入/mma bindCommand example查看模型绑定的命令，发现这样做太坑了。
于是输入/mma bindCommand example delete 删掉了最底下的一条命令“/clear May”
在此之后的某天，May突发奇想，想要复制一个一毛一样的模型，于是他输入指令
/mma clone example example2
这样example2就和example一毛一样了！
温馨提示：/mma help可以查看插件的帮助~
教程结束~~~撒花撒花~~~
