标题: [PHP] Libvirt-Manager —— 几行代码就可以管理你的 KVM 虚拟机


Libvirt-Manager
一个简单的 Libvirt 虚拟机管理器，使用 PHP 开发。


它可以启动、关闭、强制结束或读取虚拟机信息，列出虚拟机列表等。
这个项目是为了让开发者管理虚拟机更简单，更轻松。
你需要安装 PHP_SSH2 模块来使用此管理器。
Github：https://github.com/kasuganosoras/Libvirt-Manager

连接到服务器的示例代码
  1. include("libvirt/libvirt.php");
  2. $Libvirt = new Libvirt();
  3. $Libvirt->setHost("192.168.3.181", 22, "/data/libvirt/");
  4. $Libvirt->connect("root", "123456");
复制代码
Libvirt Manager 需要通过 SSH 连接到服务器进行操作，请确认你的服务器已启用 sshd 服务。
在示例代码中，192.168.3.181 是服务器地址，22 是服务器端口，/data/libvirt/ 是你希望 Libvirt 使用的数据储存目录。
在登录时，请使用用户名和密码（目前暂不支持证书登录），示例代码中的用户名和密码分别是 root 和 123456

创建虚拟机示例代码
  1. $Libvirt->createDisk("Test", "qcow2", "30G");
  2. $Libvirt->createVMXML("Test", 2, 2048576, "/data/libvirt/images/Test/Test.qcow2", "/data/iso/CentOS-7-x86_64-Minimal-1804.iso", "cdrom", "network", "default", $Libvirt->randomMac(), "virbr0", 0, 0, 5902);
  3. $Libvirt->define("/data/libvirt/Test.xml");
  4. $Libvirt->setPermission("Test");
  5. $Libvirt->start("Test");
