一个奇♂怪的插件


似乎就是编辑物品名下面那一排奇怪的东西

作者的话大概是这样

你只需要像上图一样合成 不需要任何指令
只需要命名牌，您就可以设置1行甚至6行的信息每一行都有一个独立的权限[感谢@ffc2412966076 提供的翻译]
可以使用重新加载插件命令来重新加载所有更改在你物品上的配置


权限表
  • loretag.lines1-3 : 允许玩家更改 1、 2、 3 条信息
  • loretag.lines1-6 : 允许玩家更改 1、2、3、4、5 、6 条信息
  • loretag.reload : 重载插件指令的权限，写 /lt reload 重载
  • loretag.* : 给予所有权限 - 一般是给 OP 的;
一行一行调♂教的权限

  • loretag.line <1 - 6> :顾名思义，一个一个改 不过要从第1行的权限开始 如果第1行的权限没有的话就不能给第2行的权限.
    比如.: 你给玩家 "loretag.line6"权限,那么你就需要先给 1 到 5 行的权限!

配置文件
你可以在这里调♂教装备的
item-list:一排都是金的- GOLD_BOOTS   - GOLD_CHESTPLATE - GOLD_HELMET- GOLD_LEGGINGS钻石的- DIAMOND_BOOTS- DIAMOND_CHESTPLATE- DIAMOND_HELMET- DIAMOND_LEGGINGS
锁链的- CHAINMAIL_BOOTS- CHAINMAIL_CHESTPLATE- CHAINMAIL_HELMET- CHAINMAIL_LEGGINGS
铁的- IRON_BOOTS- IRON_CHESTPLATE- IRON_HELMET- IRON_LEGGINGS
皮革不解释- LEATHER_BOOTS- LEATHER_CHESTPLATE- LEATHER_HELMET- LEATHER_LEGGINGS

作者的介绍原话

Features:
  • You only need to craft the item like the image on top of the plugin page. No special commands and no complications;
  • Using only name_tag, you can set one line, or 6 lines of your item lore using the craft table;
  • You can personalize the list of allowed itens to allow change the lore;
  • Permissions for each line;
  • Reload command to reload all changes you make on item-list configuration;
