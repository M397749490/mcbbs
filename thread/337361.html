第二个可以通过关闭水的流动性来实现  在插件目录essentials  plugins文件夹下的config文件，在里面找到 water-flow: false 将其修改为 water-flow: true 下面是一些你可能需要的设置 lava-flow: false # 阻止 岩浆的流动 water-flow: false # 阻止 水的流动 water-bucket-flow: false # 阻止 水桶水的流动 如果你想要快速找到这些，例如快速找到阻止水流动选项可以这样做： 按下Ctrl键和F键，一般会出现一个搜索的界面，然后再搜索water-flow:字样就可以快速找到了
