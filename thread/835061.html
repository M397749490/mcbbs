关于:
这个插件是很有名的The Bridge小游戏的重置版。

特点:
  • 自定义加入退出信息
  • 自定义击杀信息
  • 可编辑一个队伍的最大人数
  • 结束命令
  • 可编辑队伍颜色
  • 可编辑地图大小

安装:
  • 下载插件
  • 放进服务端的 plugins 文件夹
  • 启动/重启服务器
  • 等待
  • 将配置文件改为本帖内的官方汉化配置
  • 安装完成

截图:







制作:
1. 使用/tb create <名称>创建一个新游戏
2. 设置团队出生点和得分点(如下图):

3. 设置中心桥梁(使用/tb set center bridge)
在下面设置底部(/tb set bottom)

4. 使用/bridge保存设置！
这是出生点的大小

设置团队得分处的时候，你应该站在下图的位置。

这就是全部，如果你还是不懂可以加入Discord

  • /tb set team <team number> spawn
  • /tb set team <team number> edge
  • /tb set center bridge
  • /tb set bottom
  • /tb create <name>
  • /tb delete <name>
  • /tb edit <name>[attach]1273523[/attach]
  • /tb save
  • /tb join <name>
  • /tb play
  • /tb leave
