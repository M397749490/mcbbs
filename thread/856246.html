作者: lgou2w    时间: 2019-4-8 12:27
鸡蛋、箭这些属于弹丸实体 Projectile。获取砸中的实体可以通过监听 ProjectileHitEvent.getHitEntity()，或者可以通过 EntityDamageByEntityEvent 实体受伤由实体造成事件判断伤害源。Projectile.getShooter?() 来获取这个弹丸的发射者，判断 instanceof Player 那么就是玩家发射的。

作者: mcbzhu    时间: 2019-4-8 15:47
我的方式:
//定义被实体伤害事件
        EntityDamageByEntityEvent damageEvent = null;
        //定义被投掷的鸡蛋
        Egg egg = null;
        //定义花费的金额
        double vaultCost = 0.0D;

        //得到受到伤害的实体
        Entity entity = event.getEntity();

        //判断 是否属于 被实体伤害事件,不是就终止程序
        if (!(event instanceof EntityDamageByEntityEvent)) {
            return;
        }
        //是,则继续...强转为被实体伤害事件
        damageEvent = (EntityDamageByEntityEvent)event;

        //判断造成伤害到是否是鸡蛋,同理 不是就终止程序
        if (!(damageEvent.getDamager() instanceof Egg)) {
            return;
        }
        //如果是就得到这个鸡蛋
        egg = (Egg)damageEvent.getDamager();
