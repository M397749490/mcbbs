NESS Anti-Cheat
请允许我为大家介绍一款可靠准确的反作弊：
这款反作弊插件历时一年多的开发，目前已经进入公测阶段。虽然它看起来与其他类似插件没有什么不同，但是它的特点在于它的报告清晰准确，不会困惑管理员。它同时也可以迎合您的喜好，允许自定义封禁玩家时使用的命令。并且这款反作弊是完全免费的！

功 能
目前经过测试可用于检测以下作弊：

AntiFire - 火焰无伤
AutoSneak - 自动潜行
AutoSteal - 自动潜行
Blink - 闪现
BunnyHop - 超级跳
FastBow - 快速射箭
FastLadder - 快速爬梯
FastSneak - 快速潜行
Flight - 飞行
Glide - 滑翔
High CPS - 连点
Jesus - 水上漂
Kill Aura - 杀戮光环
Liquids - 与液体相关的作弊
NoClip - 穿墙
NoFall - 坠落无伤
NoSwing - 无视后摇
NoWeb - 无视蛛网
Phase - 穿墙
Reach - 攻击范围增幅
Regen - 快速回血
Scaffold - 自动搭路
Speed - 移动加速
Spider - 爬墙
Step - 自动跳跃
Timer - 改变时间
Tp Aura - 传送

注意：NAC虽然可以在1.9+版本的服务器上运行，但兼容性不佳，甚至有可能对新版本的特性产生误报（滑翔鞘翅、漂浮药水等）！

特 点
  • 高度可自定义信息
  • 高度可自定义配置
  • 自动检测新版本

指 令
/ness toggle [feature] > 开关指定功能、开发模式、延迟补偿等。
/ness ban [username] [reason] > 以 [reason] 的原因封禁一名叫[username]的在线玩家。
/ness banwave > 开启封禁浪潮
/ness time > 查询封禁浪潮已运行时间
/ness clear > 清理所有玩家的违规嫌疑
（可以使用 /ness clear All All 或 /ness clear All Flight 来清理玩家在特定作弊类型的嫌疑）
/ness unban [player] > 解除对[player]的封禁

权 限
NESS.bypass.[check] > 无视特定检测（例如 NESS.bypass.killaura 或 NESS.bypass.flight）
NESS.command.[command] > 使用特定指令
NESS.notify.hacks > 接受通报嫌疑玩家
NESS.notify.developer > 回送开发者调试信息（只在开启开发者模式时有效）
NESS.notify.queue > 接受通报封禁浪潮排队玩家清单

配 置
  1. Configuration:
  2. # 封禁浪潮的处理频率（秒）
  3.   BanWaves: 60
  4. # 封禁浪潮处理的玩家作弊等级需达到多高
  5.   VLForBanwave: 150
  6. # 玩家作弊等级达到多少立即封禁
  7.   VLForInstaban: 400
  8. # 延迟补偿
  9.   LagPossibility: 50
  10. # 作弊等级达到多少开始通报
  11.   MinimumVL: 20
  12. Settings:
  13. # 是否开启开发者模式
  14. # 开发者模式下，若玩家未被封禁，则调试信息会发送至拥有 NESS.notify.developer 权限者
  15.   DeveloperMode: false
  16. # 是否关闭延迟补偿（强烈不建议）
  17.   Cancel: false
  18. # 是否开启NAC反作弊
  19.   Global: true
  20. # NAC是否通报嫌疑玩家给有权限者
  21.   ServerOnly: false
  22. # NAC是否禁止手动启动检测功能
  23.   ManualBan: true
  24. # NAC是否自动处理封禁指令 （关闭后仅可使用指令封禁）
  25.   HandleBans: true
  26. # NAC是否删除所有物品的附魔等级 > 100
  27.   AllowEnchants: false
  28. # NAC是否自动检测新版本 （建议开启）
  29. CheckForUpdates: true
  30. Prefix: '&4NESS>&7'
  31. # NAC是否更高频率地通报较高作弊等级的玩家
  32. VlCols:
  33.   - '&a'
  34.   - '&6'
  35.   - '&c'
  36. # 占位符: %duration% %player% %hack% %token%
  37. BanMessage:
  38.   - '&c&l[NESS Anti-Cheat]'
  39.   - '&r你已经被此服务器封禁，持续时间为 %duration%'
  40.   - 'Token ID: %token%'
  41. CommandsOnBan:
  42.   - 'say 玩家 %player% 已经因为 %hack% 被封禁！'
  43. CommandsOnBanwave:
  44.   - 'say 玩家 %player% 已经因为 %hack% 被封禁！'
  45. Messages:
  46.   WarnHacks: '%prefix% &e%player% &7被怀疑为 %vlCol%%hack% &7作弊。'
  47.   IsQueued: '%prefix% &e%player% &7正在等待封禁浪潮。'
  48.   NoPermission: '%prefix% 你没有相应的权限！'
  49.   WasBanned: '%prefix% &e%player% &7已经被 &4NESS&7 封禁。'
  50. # 在开发者模式下禁用某些检测，您便可以测试一些作弊功能
  51. DisabledChecks:
  52.   - '0'
  53.   - 'exampleHack'
  54. DisabledWorlds:
  55.   - 'exampleWorld'
