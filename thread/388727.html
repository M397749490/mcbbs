  2.   # 如果你想要使用世界自带的出生点,则设置为"none".
  3.   spawnpoint: default

  8.   kit: 'newerfood'

  10. # 设置为 lowest, 如果你想使用 Multiverse 处理重生.
  11. # 设置为 high, 如果你想使用 EssentialsSpawn插件 处理重生.
  12. # 设置为 highest, 如果你想强制使用 EssentialsSpawn插件 处理重生.
  13. respawn-listener-priority: highest

  15. # 如果设置为true,玩家死后会重生在自己家,而不是出生点.
  16. respawn-at-home: true
复制代码
在ess的config里找到这一段，把 respawn-listener-priority 设为 lowest ，这样服务器就会优先使用MV的重生点。至于 spawnpoint 你可以根据需要让玩家在MV重生点重生或者在世界出生点重生。 respawn-at-home 也是，根据需要自定让玩家是不是在自己家重生。
