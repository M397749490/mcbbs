标题: 我的世界需求配置
首先这里不提及 Windows Xp（xp目前系统版本太老）
                         Windows 10（该系统适合办公，笔记本除外 能安装此系统都能玩）

这里就讲讲win7
最低配置
CPU 1.5G+ GHz多和处理器/2.0+GHz单核处理器
内存 Windows 7 32位 1.5+ G
Windows 7 64位 3.0+ G
显卡 NVIDIA GeForce Mx440 / ATI Radeon 7 或者以上
硬盘 至少80M剩余空间


推荐配置
    CPU 2.0G+ GHz多和处理器/2.5+GHz单核处理器
内存 Windows 7 32位 3.0+ G
Windows 7 64位 4.0+ G
显卡 按照市面上的一千左右的显卡就可以算中等配置了
硬盘 至少265M剩余空间

以上就是基本可以玩我的世界游戏的配置，官方并没有发布配置问题
（关于32位和64位系统）
32位和64位意味着电脑CPU一次能处理的最大位数
我个人建议内存2G装备32位系统，内存4G装64位系统（可以物理增加内存）
如果购买了新电脑还是建议大家安装64位系统，才会合理分配电脑性能
