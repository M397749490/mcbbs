是不是你用命令方块直接执行的teleport
导致tp时使用命令块的坐标和面向(没有...所以默认向北)

简单点说，缺了个执行者的面向，补一个
写这样应该就可以了(不记得at包不包含rotated as)
execute as @p at @s run teleport @s x y z
execute as @p rotated as @s run teleport @s x y z
execute at @p run teleport @p x y z
execute rotated as @p run teleport @p x y z
任意一个应该都可以
