SkyWars

Nukkit服务器上的SKYWARS插件
注意:此插件还在测试状态，不建议用于正式开服！

警告:在安装之前，请将你的SkyWars世界(您想要设置的)复制到服务器目录(不是插件目录)中的"arenas"文件夹中，以避免崩溃

安装:
1.输入/sw create <房间名>
2.点击大厅中的开始游戏牌子
3.当你点击完牌子后时，传送到指定的SkyWars世界并开始点击位置
4.点击所有出生点位置时，输入/sw finish
5.开始游戏

配置文件示例:
config.yml(插件版本:0.0.3):

lobbyX: 128.0 #浮空字和大厅的x坐标
lobbyY: 86.0 #浮空字和大厅的y坐标
lobbyZ: 128.0 #浮空字和大厅的z坐标
lobbyWorld: world #浮空字和大厅的世界
dataProvider:
  yaml: true
  mysql: false
economyapi-enabled: false #是否使用经济API
customeconomy-enabled: false  #未知
joinMessage-enabled: false #是否屏蔽进服消息
quitMessage-enabled: false #是否屏蔽退服消息
hologram-enabled: true #是否开启浮空字
hologramX: 128.0 #摆设
hologramY: 86.0 #摆设
hologramZ: 128.0 #摆设
hologramWorld: world #摆设
reward-amount: 100 #奖励金钱数
mysql: #mysql配置
  url: ''
  login: ''
  password: ''
  database: ''

arenas.yml(插件版本0.0.3):

sw1: #房间号
  settings:
    slots: 4 #房间最大容纳玩家
    time: 5 #未知，建议不更改
    mode: solo #房间模式
  sign: #房间状态木牌的配置
    world: world #世界
    x: 128.0 #x坐标
    y: 87.0 #y坐标
    z: 130.0 #z坐标
  pos1: #第一个出生点的配置
    world: sw1 #世界
    x: 127.0 #x坐标
    y: 89.0 #y坐标
    z: 118.0 #z坐标
  pos2: #同第一个出生点的配置(pos2就是第二个出生点的配置，pos*就是第*个出生点的配置)
    world: sw1
    x: 117.0
    y: 89.0
    z: 128.0
  pos3:
    world: sw1
    x: 127.0
    y: 89.0
    z: 138.0
  pos4:
    world: sw1
    x: 137.0
    y: 89.0
    z: 128.0


命令:
/sw create <房间名>(需要OP)
/sw finish(需要OP)
