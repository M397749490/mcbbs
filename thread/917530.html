标题: 樱MOD 竹子泛滥
地皮全是竹子，MOD是樱，如何在不删除MOD的前提下  限制生长或者  禁止生长呢？  
作者: NoName德里奇    时间: 2019-10-3 16:51
1. 在.minecraft/config文件夹中找到sakura.cfg然后删除
2. 更新樱MOD版本至0.0.5：https://www.curseforge.com/minec ... ra/download/2786822
3. 重启服务端，生成新的config文件，内容如下：
  1. # Configuration file

  3. general {
  4.     # Changes generate rate of BambooShot. Increase value to gen more BambooShot.
  5.     # Min: 0
  6.     # Max: 2000
  7.     I:bambooshot_weight=90

  9.     # Changes generate rate of Pepper. Increase value to gen more Pepper.
  10.     # Min: 0
  11.     # Max: 2000
  12.     I:pepper_weight=90

  14.     # Changes generate rate of Vanilla. Increase value to gen more Vanilla.
  15.     # Min: 0
  16.     # Max: 2000
  17.     I:vanilla_weight=90
  18. }
复制代码

把所有的90替换成0，保存，再重启服务端。
这样还没有生成的区块就不会长竹子了。
最后你只要清除掉已经生成的竹子就可以了。
