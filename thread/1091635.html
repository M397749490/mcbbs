来自Mojang的特性
追踪SnowballEntity的渲染路径，可以在类 net.minecraft.client.render.entity.EntityDispatcher 里面找到函数 registerRenderers ，有这样一句：

  1. this.register(EntityType.SNOWBALL, new FlyingItemEntityRenderer(this, itemRenderer));
复制代码
这句话导致了继承雪球的渲染类的想法破产，因为雪球没有相关的渲染类。

通过解包Minecraft本体文件，关于Snowball的图片也只有assets/minecraft/texture/item/snowball.png一张雪球物品的图片。可以看出，雪球实体是没有自己的模型的。

怎么办？
通过对上述语句的追踪，我们可以发现雪球实体类SnowballEntity继承了ThrownItemEntity类。在游戏中对雪球实体的观察，可以发现实体的模型类似于雪球物品的图片。结合网络上查找到的资料，可以推测雪球物品图片就是雪球实体的渲染模型，而关键就在类中的函数 getDefaultItem


客户端与服务端的通信
投掷物的渲染需要在Mod里面加入通信，来使得投掷物正确地在客户端被渲染。
首先需要在BasketballEntity里面加入发包函数，用于篮球生成的时候通知客户端
  1. @Override
  2.     public Packet<?> createSpawnPacket() {
  3.         super.createSpawnPacket();
  4.         PacketByteBuf buf = new PacketByteBuf(Unpooled.buffer());
  5.         buf.writeInt(this.getEntityId());
  6.         buf.writeUuid(this.getUuid());
  7.         buf.writeDouble(this.getX());
  8.         buf.writeDouble(this.getY());
  9.         buf.writeDouble(this.getZ());
  10.         return new CustomPayloadS2CPacket(new Identifier("chicken", "basketball"), buf);
  11.     }

在客户端主类中加入实体生成函数，用于解析包并生成实体
  1. private static void spawnEntity(PacketContext context, PacketByteBuf buffer) {
  2.         int entityId = buffer.readInt();
  3.         UUID uuid = buffer.readUuid();
  4.         double x = buffer.readDouble();
  5.         double y = buffer.readDouble();
  6.         double z = buffer.readDouble();
  7.         context.getTaskQueue().execute(() -> {
  8.             BasketballEntity entity = new BasketballEntity(BasketballEntityInstance,context.getPlayer().world);
  9.             entity.setPos(x, y, z);
  10.             entity.setEntityId(entityId);
  11.             entity.setUuid(uuid);
  12.             entity.updateTrackedPosition(x, y, z);
  13.             ((ClientWorld) context.getPlayer().world).addEntity(entityId, entity);
  14.         });
  15.     }

并在onInitializeClient函数中加入渲染器注册以及实体生成函数的注册
  1. @Override
  2.     public void onInitializeClient() {
  3.         EntityRendererRegistry.INSTANCE.register(Basketballentity, (entityRenderDispatcher, context) -> new FlyingItemEntityRenderer<BasketballEntity>(entityRenderDispatcher,context.getItemRenderer()));
  4.         ClientSidePacketRegistry.INSTANCE.register(new Identifier("chicken","basketball"),CxkChickenClient::spawnEntity);
  5.     }
