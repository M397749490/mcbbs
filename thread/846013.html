简介


UltimateKits为您的服务器引入了一个功能强大但直观的系统，允许玩家和管理员预览和购买精心制作的游戏礼包。礼包可以轻松绑定到任何方块上，并配置为出售礼包以维持经济平衡。独一无二的礼包编辑器使其成为服主的最爱，这些服主希望在服务器上添加一些东西，以提高利润并保持玩家的积极性！

常见问题解答
如何设置免费的有冷却的礼包? - 将价格设为 0, 将冷却开启如何将一个礼包不显示在礼包菜单中显示? - 将礼包加入Kit Editor中GUIOptions的黑名单中。为什么我无法修改礼包在菜单中显示的图标? - 你可以的! 请看 Kit Editor 中的 GUI Options.如何为我的礼包添加冷却? - 输入 /uk edit (礼包名)，然后点击 General Options 选项，最后在 Delay Option 中调整. (冷却是按秒算的  例如 24 小时 就是 86400 秒)

使用方法
Kits(Default)允许玩家查看所有礼包/kits
PreviewKitultimatekits.use.<礼包名>查看一个指定礼包/pk <kitname>
UK Help(Default)显示礼包查看的相关信息/uk help <page>
UK Reloadultimatekits.admin重载配置与语言文件/uk reload
UK Editultimatekits.admin用GUI菜单编辑礼包/uk edit <kitname>
UK Setultimatekits.admin使你正在看着的方块显示礼包/uk set <kitname>
UK Removeultimatekits.admin从你看着的方块上移除礼包/uk remove
Keyultimatekits.admin给玩家一个礼包密钥，这些密钥可用来购买礼包终极密钥给予所有物品，定期密钥给予一些物品/uk key <kitname> <Ultra/Regular> <Player/All> <amount>
UK Settingsultimatekits.admin允许你使用一个GUI菜单编辑所有配置/uk settings
-ultimatekits.kit.<kitname>允许您让玩家访问该特定礼包-
-ultimatekits.buy.<kitname>允许你购买特定礼包-
