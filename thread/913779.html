Stop Render是一个仅限客户端的mod，它添加一个配置来禁用某些tile实体的tile实体特殊渲染器。
这个mod的目的是让玩家能够禁用一些可能有些迟钝的TESR。



用法:
打开config文件夹，找到stoprender.cfg配置文件

例如删除胸甲渲染
  1. general {
  2.     # The full class name for tile entities whose TESR is to be removed.
  3.     # E.g. "net.minecraft.tileentity.TileEntityChest" for chest.
  4.     S:TILE_ENTITIES < net.minecraft.tileentity.TileEntityChestnet.minecraft.tileentity.TileEntityEnderChest >
  5. }
复制代码
这同样适用于修改的区块实体。只需输入tile实体的类的类名，例如

  1. cn.davidma.tinymobfarm.common.tileentity.TileEntityMobFarm
复制代码

注意：

这个mod是在我发现某些mod的某些tile实体特殊渲染器太资源太高之后制作的
导致客户端出现严重的性能问题。该mod基本上取消绑定给定的tile实体的TESR，从而获得更好的性能。
