插件介绍

这是一款全新的宠物插件，玩家可获得宠物蛋并通过积累步数来孵.化，玩家可给宠物命名，放出宠物并让其与其它宠物战斗来提升等级，从而提高各种属性，当宠物死亡时，可使用宠物食物来将其治愈，我测试插件的时候越来越感觉玩法像宝X梦


获得宠物蛋 | 积累步数孵.化
可通过指令来获得宠物蛋，然后将其放在副手并走50米（可配置）即可随机孵.化出一种宠物
可能孵.化出10种宠物之一：牛，猪，羊驼，哞菇，僵尸猪人，北极熊，兔子，羊，僵尸，鸡（权重可配置）
孵.化出的宠物可用铁砧来命名，命名后的宠物不能改名

Attention
宠物并不会与主人绑定，谁拥有宠物头颅谁就是主人，因此，宠物头颅可以作为物品来出售
当宠物主人死亡，宠物会跟着死亡，当宠物主人放出宠物后下线，宠物也会死亡
濒.死状态的宠物放不出来


安装&指令&权限
  • 使用本插件前需安装前置ProtocolLib（但我没有看出这个前置在哪里被用到了）

指令
  • /rpgpets help - 插件帮助
  • /rpgpets give <玩家名> food/egg [数量] - 获得宠物食物/神秘.蛋
  • /rpgpets give <玩家名> <宠物种类> <等级> - 直接获得一个宠物头颅
  • /rpgpets minify - 手持宠物输入此指令可让宠物变回幼年状态
  • /rpgpets deminify - 手持宠物输入此指令可让宠物变回普通状态


权限
下列权限酌情给玩家
  • rpgpets.command.minify - 使用让宠物变回幼年状态的指令
  • rpgpets.command.deminify - 使用让宠物变回普通状态的指令

配置与汉化
pets宠物配置示例
  1. maxLevel: 20                    # 宠物可达到的最大等级
  2. baseExpRequirement: 10          # 从等级 0 开始想要升级所需经验
  3. expRequirementMultiplier: 1.5   # 从等级1开始，每升一级所需经验为上一级升级所需经验的多少倍
  4. randomWeight: 10                # 一个宠物的随机权重
  5.                                 # “权重”是什么:
  6.                                 # 权重代表一个宠物孵化时选定种类的出现几率
  7.                                 # 当只有两种宠物种类时，如果A宠物的权重为1，B宠物的权重为3，那么A宠物生成概率25%，B是75%
  8.                                 # 总而言之: 越高权重，越有更高几率生成
  9. base:                           # 当宠物为等级 0 时的属性
  10.   speed: 1                      # 基础移动速度
  11.   attackDamage: 1               # 等级 0 时的伤害
  12.   knockback: 0.5                # 等级 0 时的击退
  13.   maxHealth: 10                 # 最高可达到的血量 (玩家为: 20)
  14. levelup:                        # 当宠物每升一级，这些属性会相应增长
  15.                                 # 计算方式: 升级后属性(level) = 基础属性 + 等级 * 每级倍增值
  16.   speed: 0.1                    # 每升一级，移动速度增加多少
  17.   attackDamage: 0.5             # 其它同上
  18.   knockback: 0.05
  19.   maxHealth: 5
  20. babymodifier:                   # 当宠物时幼年期时，可以获得一个属性倍增效果
  21.                                 # 计算方式: 倍增后属性(level) = 升级后属性(level) * 幼年倍增值
  22.   speed: 1.5                    # 幼年期宠物移动速度倍增值
  23.   attackDamage: 0.5             # ...
  24.   knockback: 0.25
  25.   maxHealth: 0.5
