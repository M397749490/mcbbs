BedwarsRel说明
  • 该页上的所有内容，在 { } 括号里面的，应该用一个单独的值替换.这些东西是每个游戏或者服务器的个别参数. 参数的描述你可以在命令wiki页面找到. 在这些说明中并不是所有命令的参数都显示.

插件安装
  • 从 SpigotMC.org 上下载插件或者自己从Github上复制源码编译成jar文件!
  • 把jar文件移动到目标服务器插件文件夹.
  • 开启服务器插件将会开始运作并生成配置文件和语言文件.
  • 前往单端或群组服务器配置游戏.

设置游戏-单端
  • 确保你使用了 Multiverse-Core 或者 Multiworld  载入了一个起游戏地图。
  • 使用 /bw addgame 命令开始创建起床游戏。
  • 现在使用 /bw addteam 命令添加游戏团队. 最少创建两个团队。
  • 下一步，你需要站在合适的队伍的出生点的位置使用 /bw setspawn 命令.
  • 站在床的前面设置队伍的床, 鼠标指针指向床或者站在床的上面使用 /bw setbed 命令。
  • 站在合适的资源刷新点位置使用过 /bw setspawner 命令
  • 现在设置游戏世界. 飞到游戏地图的右上角使用 /bw setregion {game} loc1 来设置第一个位置 ，飞到游戏地图的的左下角使用 /bw setregion {game} loc2 来设置第二个位置.
  • 现在到了设置游戏大厅的时间了. 切换到大厅世界, 前往玩家将要被传送到的位置使用 /bw setlobby 命令.
  • 如果你在配置文件中将 "mainlobby-enabled"选项开启了,你需要设置主大厅. 前往主大厅位置使用 /bw setmainlobby 命令.
  • 现在使用 /bw save {game} 来保存这个游戏! (如果显示错误，你可能漏掉了什么东西)

设置游戏-群组
  • 创建一个 bungeecord 服务器 (竞技场/地图).
  • 这个 bungeecord 服务器应该在关闭后重启, 因为插件将会在每个游戏结束后关闭服务器. 这可以用以下示例脚本完成：
  • @echo off
  • :restart
  • java -Xms512M -Xmx1024M -XX:MaxPermSize=128M -jar spigot.jar
  • timeout /t 10 /NOBREAK
  • goto restart
  • pause
  • The timeout /t 10 /NOBREAK 命令将使脚本等待10秒，然后服务器将重新启动. 这个时间可以用来中断重启和按Ctrl + C关闭命令行.
  • 更新插件配置 (config.yml) 设置 hubserver 能够连接到正确的大厅服务器. 然后通过开启bungeecord部分来启用插件
  • 开启并加入 bungeecord 服务器设置起床游戏 (使用单端服的方法). 重要:当 bungeecord开启时一个单端服务器只能创建一个起床游戏!

牌子设置
  • 创建一个游戏开始牌子必须符合以下格式:
  • 第一行: [bw]
  • 第二行: {game}
  • 放置好牌子之后，他将会自动变成游戏加入牌子。

重要说明
  • 当你对游戏进行了更改的时候你需要使用 /bw save {game} 来保存游戏. 这是自觉的意识, 因为当你做错什么事的时候它不会自动保存, 它不会直接崩溃游戏.

常见问题解答
  • 我可以在哪里找到插件权限?
  • 你可以在这里找到插件的所有权限: https://github.com/BedwarsRel/BedwarsRel/wiki/Permissions
  • 我可以在哪里找到插件命令?
  • 当插件运作的时候使用 /bw help 命令或者在 Github-Wiki 页面阅读: https://github.com/BedwarsRel/BedwarsRel/wiki/CommandsYou
  • 没有op的玩家不能点击牌子加入游戏, 为什么?
  • 这是因为你的服务器设置引起的. 在你服务器的 server.properties 里设置 spawn-protection 项为 0 .
  • 我想修改语言文件
  • 你可以在这里找到所有关于这个的信息: https://github.com/BedwarsRel/BedwarsRel/wiki/Localization
  • 我的商店系统不工作
  • 首先检查你的控制台是否有报错.或许它会告诉你哪个物品需要修复. 如果你不能找到一个合适的解决方案那么恢复原来的 shop.yml 文件重新开始.
