标题: ClassStringConstReplacer —— 汉化|高效|可复用|易编辑
ClassStringConstReplacer v1.0 by Karlatemp.

| 翻译, 如此简单


简述:
只修改class中的字符串内容，不修改其他信息，不损坏Jar包
使用映射表操作, 只要jar不是混淆的, 而且信息没大改, 修可以作用到后续版本

系统支持: 全部能使用Java的系统
Java 版本: Java 8 及 以上
怎么使用:
  • 前往下载地址下载 ClassStringConstReplacer.jar 和 MXBukkitLib.jar 并放在同一目录里
  • 打开命令行, cd 进入此目录
  • 输入
    java -jar ClassStringConstReplacer.jar -output mapping...json G:\Java\....jar
    生成 Mapping 文件. (请注意, 这将覆盖掉output的原有内容)
  • 下载一个好的编辑器(不要用自带的记事本), 个人推荐VSCode. 打开生成的 mapping.json, 编辑他, 然后保存
  • 输入
    java -jar ClassStringConstReplacer.jar -process mapping...json -output out.genernal.jar G:\Java\....jar
    获取翻译好的 jar
  • 如果出现类似
    [Class Pre check] [WARNING] org/spigotmc/builder/VersionInfo.toString()Ljava/lang/String; 存在 13 个字符串. 但是映射表只有 2 个字符串.
    之类的, 那就说明这个位置的映射已经对不上了, 需要更新. (删掉此区块并更新)
  • jar 有更新, 使用以下命令获取新的映射表
    java -jar ClassStringConstReplacer.jar -preview mapping...json -output mapping...json G:\Java\...jar
    获取更新.
    注意: 这不会覆盖映射表原来有的内容, 也就是旧的不需要重新翻译(如果乱了就需要翻译)
    此操作不会自动修改对不上的映射表, 需要手动删除出错部分更新

Tips:

  • 编辑时, 如果可以的话, 打开JD-GUI对照编辑, 免得把一些关键字 (如 java.version) 给换了.
  • 出现了 . (点号) 尽量不要去动他
  • 汉化服务器插件时, 有 net.minecraft.server 字眼的不要碰
  • JD-GUI/源码 中 此字符串出现在 System.getProperty, Boolean.getBoolean, Integer.getInteger, Class.forName, 的, 都不要碰
  • 如果翻译的项目是开源的, 你可以很快的根据类名和开源地址得到源码文件
  • 注意别把json的格式弄坏了
  • JSON语法
  • JSON 在线解析
  • 有特殊需要的你可能需要用反编译去编辑 E.g: [("The number of:" + var1) -> (var1 + "的数量")]
