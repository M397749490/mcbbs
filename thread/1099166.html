SX-Level附属插件-不同等级执行指令

[让你的SX-Level等级插件升级执行命令吧]

插件简介
                                                                                                                                                                                             

SL-cmd是为了让使用SX-Level插件的腐竹可以实现在不同等级实现不同的指令，原版经验等级该插件无效,请尽情发挥你的脑洞吧！！！其他版本暂无测试，不知能否兼容其他版本！！



插件教程
                                                                                                                                                                                             

配置：config
  1. #变量只有一个：%player% == 玩家
  2. #插件名称
  3. tag: "&a[&6等级&a]"
  4. SLevel:
  5.   #识别id，用于判断是否达到使用上限
  6.   1:
  7.     #打开领取限制的开关
  8.     countenble: true
  9.     #限制领取的次数
  10.     countlimit: 1
  11.     #触发奖励等级
  12.     level: 10
  13.     #触发后执行的指令
  14.     Command:
  15.       - "/say %player%"
  16.     #自身的消息
  17.     Message: "&a恭喜您升级到了10级"
  18.     broadcastMessage:
  19.       #是否启用全服通告
  20.       enble: true
  21.       Message: "&A[全服通告]: &f恭喜玩家 &a%player% &f升级到了10级！"
  22.   2:
  23.     countenble: true
  24.     countlimit: 1
  25.     level: 20
  26.     Command:
  27.       - "/say %player%"
  28.     Message: "&a恭喜您升级到了20级"
  29.     broadcastMessage:
  30.       enble: true
  31.       Message: "&A[全服通告]: &f恭喜玩家 &a%player% &f升级到了20级！"
  32.   3:
  33.     countenble: true
  34.     countlimit: 1
  35.     level: 30
  36.     Command:
  37.       - "/say 你好"
  38.     Message: "&a30级"
  39.     broadcastMessage:
  40.       enble: true
  41.       Message: "&A[全服通告]: &f恭喜玩家 &a%player% &f升级到了30级！"
复制代码



指令：

  1. /slc reload 7重启插件
  2. /slc set {player} {level} 设置玩家的等级
  3. /slc add {player} {level} 加玩家的等级
  4. /slc take {player} {level} 减少玩家的等级
