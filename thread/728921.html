插件の简介


Introduction — 简介



TagsGUI符合EULA，聊天称号的一款插件，在某方面有助于服务器添加了特权。

增加捐赠者的意愿

对于特权玩家或玩家是一个很好的插件

一款好的福音




Features — 功能



100%配置：

  • language.yml - 讯息
  • config.yml - 配置, 称号
  • animation.yml - 动画



聲音

包适选择称号时，刪除称号时，开启GUI时，关闭GUI时等等！



後,前綴

可以配置称号, 允許後缀或前缀称号





Confused Slot — 还在困惑看不懂Slot是啥吗？







Installation — 安装



  • 购买之后下载插件并丢到服务器内的Plugin文件夹即可，之后开启服务器来生成插件文件。

指令の解说



  1. - /tags - 打开 称号GUI.
  2. -> 别名: /tag
  3. -> 权限: 没有

  5. - /tags reload - 重载 TagsGUI 配置文件
  6. -> 权限: tags.admin
  7. -> I might need to fix this to reload all files.

  9. - 将在新版本添加 -
  10. - /tags create <page> <name> <type (suffix OR prefix)> - 创建一个称号
  11. -> Beta 命令。 即将推出

  13. - 将在新版本添加 --
  14. - /tags delete <page> <name> - 删除一个称号
  15. -> Beta 命令。 即将推出

  17. - 将在新版本添加 -
  18. - /tags list - 称号列表
  19. -> Beta 命令。 即将推出
