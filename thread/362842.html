作者: 周润发    时间: 2014-11-10 23:47
从后台打开这个文件 路径：/plugins/GroupManager/worlds/world/groups.yml 打开这个文件找到你vip组的位置
vip:
    default: false (这边是默认组的选择  不要改动)
    permissions:
    - essentials.chat.shout （这边是玩家权限）
    - essentials.fly
    - essentials.kit.firework
    - essentials.kits.firework
    - marry.default
    - plotme.limit.1
    - plotme.limit.2
    - plotme.use
    - plotme.use.add
    - plotme.use.remove
    - quickshop.create.buy
    - quickshop.create.sell
    - scriptblock.interact.use
    inheritance:
    - builder      （这边是继承的权限组 我继承的是builder组的）
    info:
      prefix: ''     （这边是称号前缀）
      build: true  （这边是方块的破坏与放置一些的 一定要写成true）
      suffix: ''       （称号后缀）

总结一下：我估计你是      build: true 这行写的是build: false  把他给成true就好了。
