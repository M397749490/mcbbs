RealPing
一款简单又十分好用的延迟测试插件！
它可以让你服的玩家知道与服务器的延迟大小。

特点
1=非常轻便
2=让你服玩家知道延迟大小
3=让你知道服的延迟大小


指令
/ping —— 查看自己的延迟大小
/ping <player> —— 查看某个玩家与服务器的延迟大小


权限
realping.ping —— 默认玩家持有，使用/ping命令
realping.ping.others —— 默认管理员持有，使用/ping <player>命令

配置文件

config.yml:
  1. ##################################
  2. #     Variables / RealPing       #
  3. #    翻译:MCBBS:Smile_Sun        #
  4. # {PING}   = 玩家延迟.           #
  5. # {TARGET} = 玩家名字.           #
  6. ##################################
  7. messages:
  8.     error: '&c没有找到玩家 "{TARGET}" .'
  9.     usage: '&c用法: /ping [player]'
  10.     noPerm: '&a你没有权限使用这个命令'
  11.     selfPing: '&3延迟检查> &f你的延迟 &7{PING}ms&f.'
  12.     otherPing: '&3延迟检查> &f玩家 &7{TARGET} &f的延迟是 &7{PING}ms&f.'
