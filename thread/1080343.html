我知道我排版不行啦 有好心人给点排版建议嘛

原理就是  在spigot源码里面有这么一行
  1. if (Main.class.getPackage().getImplementationVendor() != null && System.getProperty("IReallyKnowWhatIAmDoingISwear") == null) {
  2.                     Date buildDate = new SimpleDateFormat("yyyyMMdd-HHmm").parse(Main.class.getPackage().getImplementationVendor());

  4.                     Calendar deadline = Calendar.getInstance();
  5.                     deadline.add(Calendar.DAY_OF_YEAR, -14);
  6.                     if (buildDate.before(deadline.getTime())) {
  7.                         System.err.println("*** Error, this build is outdated ***");
  8.                         System.err.println("*** Please download a new build as per instructions from https://www.spigotmc.org/go/outdated-spigot ***");
  9.                         System.err.println("*** Server will start in 20 seconds ***");
  10.                         Thread.sleep(TimeUnit.SECONDS.toMillis(20));
  11.                     }
  12.                 }
复制代码
所以说 你设置 SystemEnv IReallyKnowWhatIAmDoingISwear 变成随便一个东西就行了
我这就是个 java agent 去设置 并且获取了些有没有过期然后输出提示
