需要使用JAVA8



[size=14.6667px]
NO依赖条件-新！
[size=14.6667px]您可以为NPC设置您想要的名字！还有空格！（用法：把';'作为空格，例如：“Name; With; Spaces”）
你可以通过NPC运行命令！ - 新！
[size=14.6667px]您可以设置每个NPC的皮肤！
您可以为NPC上传和设置自定义皮肤！
您可以设置交互冷却时间！
您可以通过NPC切换入口！
如果NPC将用眼睛跟随玩家，您可以切换！
你可以设置NPC手中的物品和盔甲！
您可以设置禁用入口时显示的“状态”！
您可以更改NPC将连接的服务器！
您可以设置特定的JavaScript条件来加入服务器！
您可以显示服务器组！
您几乎可以配置插件的每个消息！
自定义线系统，可显示您想要的任何内容！
在游戏NPC编辑器中- 新！
[size=14.6667px]为自定义Line System挂钩to PlaceholderAPI和MWdWPlaceholder插件！ - 新！




  • / bnpc create <name / name; with; spaces> <NPCtype> <arg s> - 您在您的位置创建一个NPC！
  • / bnpc edit -打开NPC的游戏内编辑器！ - 新！
  • / bnpc select - 您选择最近的NPC，或者您只需按Shift +右键单击即可选择！
  • / bnpc info -显示NPC的信息！
  • / bnpc list -显示每个创建的NPC！
  • / bnpc skin <list / set / upload> <skinFileName> -上传，列出或设置NPC的皮肤！
  • / bnpc line <add / addAt / remove / set> <index / text> -编辑NPC的行
  • / bnpc cmds <add / remove / removeAll / list> <commandType> <command> - 编辑NPC运行的命令！
  • / bnpc delete - 删除您选择的NPC！
  • / bnpc update - 更新NPC信息！
  • / bnpc togglejoin - 如果玩家可以加入，您可以切换！
  • / bnpc equip <add / remove / reset> <slot> - 在您选择的插槽中为选定的NPC配备手中的物品！
  • / bnpc toggleLC -如果NPC会用眼睛跟随玩家，你可以切换！
  • / bnpc tp -选定的NPC将传送到您当前的位置！
  • / bnpc withelist -如果没有权限的玩家可以加入，您可以切换！
  • / bnpc setserver <server1，server2> - 您设置NPC指向的新服务器！
  • / bnpc setstatus <status> - 您设置切换入口时NPC显示的内容！
  • / bnpc setname <name> -设置NPC的名称！
  • / bnpc reload -重新加载配置和NPC！

自定义皮肤系统说明：
您需要将png文件放在BungeeNPC - > skins文件夹中并使用命令/ bnpc upload SkinFileName（whitout .png）
当皮肤准备好后会给你一个通知，然后，你将它应用到NPC by / bnpc setskin SkinFileName就是这样！





[size=14.6667px][size=14.6667px]命令语法：
/ bnpc create <name / name; with; spaces> <npcType> <arg s>

[size=14.6667px]说明：
“<name / name; with; spaces>”：这里放置NPC的名称，以使用你需要的空格使用';' 而不是空间！

“<npcType>”：在这里你放置了你想要的NPC类型，avaliables：
“Command”： NPC将在右击上运行命令！
“Bungee”： NPC将连接并显示一个BungeeCord服务器！
“库存”：尚未完成，但可能！

“<arg s>”：根据您选择的NPC类型而有所不同：
“Bungee”：将显示的服务器！
右键单击将运行NPC的命令！（稍后可以使用命令或游戏内编辑器进行更改）
