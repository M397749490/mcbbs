玩 法 介 绍
Prison是国内很受欢迎的一款监狱插件，进入服务器后，每个玩家都成为了囚犯，然后自己挖矿，砍树，生存，升级，凭一己之力，称霸服务器。

建议：
    Prison监狱服务器可以加入一款EpicGuild插件，设置付费创建公会，让玩家创建/加入公会，组建家族。
    配合baoshi(宝石) cuilian(淬炼)插件使用，武器玩法更加新奇。
    配合Item Lore Stats(属性)插件使用，让装备/武器的属性更加多。
    强烈建议添加PlotMe PlotSquared(地皮)插件，可以让玩家有家，个人建议使用PlotSquared，修改地皮模版为监狱。

命 令/权 限
玩家指令：
  1. /prison 总命令
  2. /prison help 查看帮助
  3. /prison version 查看运行插件的版本号
  4. prison.manage 权限节点
复制代码
矿场创建指令：
  1. /mines addblock <矿场名> <方块ID> <几率> 设置方块在矿场刷新比率
  2. /mines reset 刷新指定矿场
  3. /mines info <矿场名> 查看该矿场的信息
  4. /mines list 查看所有矿场
  5. /mines removeblock <矿场名> <方块ID> 删除方块在矿场刷成
  6. /mines delete <矿场名> 删除一个矿场
  7. /mines redefine <矿场名> 重新划定矿场的区域（需要先用创世神选取两个点)
  8. prison.mines.manage 权限节点
