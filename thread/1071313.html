就是检测玩家是否死亡，死亡后将游戏模式改为观察者模式且tp到指定位置
如果玩家全部变为观察者模式，就将所有玩家的游戏模式改为冒险模式且tp到指定位置
求大佬解答
作者: Duan_Jue_cui    时间: 2020-7-3 07:38
用计分板，先创建一个计分板记录玩家死亡分数的计分板：/scoreboard objectives add death deathCount (显示名字，可填可不填) 2.然后在来检测死亡的玩家，如果玩家死亡就会加1分：/testfor @a[score_death_min=1] 这样就会检测所有death计分板上分数为至少为1的玩家，如果检测到，则会输出红石信号，写这个命令的命令方块要用循环命令方块或高频红石来激活，然后在输出端放比较器和红石中继器，这样才能将信号输出的更远。 3.接下来就是执行你需要的指令了，但因为这里面包含这我弄的计分板限制条件，所以你如果要指定玩家，就要在@a、@p、@r的后面加上[score_death_min=1]，直接接在后面，不加空格 4.这一步就是将death计分板上分数为1的玩家分数清零：/scoreboard players set @a[score_death_min=1] death 0
