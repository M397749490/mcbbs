什麼是MOREFISH?

MOREFISH是一款釣魚插件內有比賽功能還可以賣魚很好玩



插件效果圖:







COMMANDS:

  /mf help 查看全部指令
/mf start 時間  開始一場釣魚比賽 時間以秒數為單位 例如 我要把比賽時間設為5分鐘 就打300
/mf stop 暫停一場釣魚比賽
/mf top 查看目前比賽的前4名
/mf clear 清除目前的所有排名
權限:

morefish.admin默認:op
提供玩家釣魚比賽的所有指令
morefish.top 默認:ALL
提供玩家查看釣魚排行的指令
morefish.shop默認:OP
有此權限的玩家可以使用/ morefish shop命令
配置:

General

locale: 'en'
文件的區域設置 為語言文件加載'lang_.yml'。
支持的語言：en，kr
check-update: true
切換新版本通知。
auto-start: false
啟用插件後，開始釣魚比賽。
您可以使用此功能將比賽用作服務器的內容。
use-boss-bar: true
啟用老闆欄功能顯示比賽的剩餘時間。只適用於1.9+。
only-for-contest: false
如果是真的，不要改變香草釣魚，除非比賽開始了。
no-fishing-unless-contest: false
如果是真的，除非比賽正在進行，否則人們不能釣魚。
contest-disabled-worlds: []
玩家無法參加比賽的世界名單。
使用示例：
contest-disabled-worlds:- 'world_nether'- 'world_the_end'
replace-only-fish: false
在釣魚時保持垃圾和珍貴香草物品的外觀。
save-records: false
保持釣魚記錄停止比賽或服務器關機。
您必須鍵入“/ mf clear”才能清除記錄。
Auto-running
enable: false
切換自動運行功能。使用它，釣魚比賽將以預定定時器定期開始。
required-players: 5
參加比賽的玩家數量最少。
timer: 300
比賽時間的秒數。
start-time
比賽時間自動啟動的時間表。
period: 3600
每場比賽開始之間的秒數。
Fish shop
enable: true
啟用魚店功能。
multiplier: 0.1
用於計算魚類價格的乘數。
（價格=（長×乘數）+附加價格從稀有）
round-decimal-points: true
捨棄價格。（例如$ 99.9 - > $ 99.0）
Messages

announce-catch: -1 announce-new-1st: -1
發送消息的方式。
'-1'表示服務器廣播，'0'僅用於捕獲者，正數表示通告消息的半徑。
當此數字設置為“100”時，100個塊中的玩家將收到該消息。
broadcast-start: true broadcast-stop: true
宣布釣魚比賽的開始/停止。
show-top-when-stopping: true
設置比賽結束時是否顯示最終排名。
contest-bar-color: 'blue'
老大棒的顏色為比賽。
有關顏色列表，請訪問https://hub.spigotmc.org/javadocs/spigot/org/bukkit/boss/BarColor.html
top-number: 3
在排名中顯示的頂級記錄數。
當它設置為'5'時，'/ morefish top'命令將按第5條記錄顯示排名。
Item Format

display-name: "%raritycolor%%fish%"
魚品的顯示名稱。
