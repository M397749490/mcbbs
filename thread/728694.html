插件介绍
这是一款可以轻松设置哪些物品不会被拾取的插件。
有些时候，我们不想拾取一些“无用的”“垃圾”物品
现在EpicPick会帮你过滤掉你不想拾取的物品

指令
普通玩家指令
/ep help             打开EpicPick帮助页面
/ep setting          打开屏蔽列表，点击动作条中的物品来屏蔽它
/ep changemode    打开/关闭 精准匹配模式（默认为关闭）
备注：如果你启用精准匹配模式，只有相同附魔，名称等属性完全一致的物品才不会被拾取
备注：如果你关闭精准匹配模式，只要物品ID相同，该物品就不会被拾取

管理员指令
/ep setting ID         为某个玩家进行设置
/ep changemode ID    改变某玩家拾取匹配模式

权限
EpicPick.*     拥有所有权限
EpicPick.help      使用帮助的权限
EpicPick.settingself    普通玩家指令权限
EpicPick.settingother     管理员指令权限

EpicPick.line.1   屏蔽列表可用行数：1行
EpicPick.line.2   屏蔽列表可用行数：2行
EpicPick.line.3   屏蔽列表可用行数：3行
EpicPick.line.4   屏蔽列表可用行数：4行
EpicPick.line.5   屏蔽列表可用行数：5行
EpicPick.line.6   屏蔽列表可用行数：6行

备注：需要手动添加权限哦~
如 /mangaddp admin EpicPick.*

配置文件
可通过修改plugins\EpicPick 目录下的message.yml文件来编辑/ep help指令的提示信息


效果图
输入/ep setting打开屏蔽列表后 鼠标左键动作条上的物品会自动加入屏蔽名单 被屏蔽的物品无法拾取

输入/ep setting打开屏蔽列表后 鼠标左键屏蔽列表内的物品会自动移除屏蔽名单
