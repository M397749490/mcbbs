AntiSpam
== 说明
防刷频, 防脏话。
默认是每秒只能发一句话，并且无法连续发相似的话。
// 最近的更新加入了正则的支持和从数据库读取配置、数据库记录日志的支持。

本插件以GPLv2发布，你可以免费使用，也可以修改源代码再发布。
如果你修改了插件的源代码或者进行再发布、转载，请牢记以下几点。
* 不得抹去作者信息
* 需注明本帖地址
* 公开修改过的代码
本插件源码地址 Github
== 权限
- spam.bypass       拥有这个权限可以跳过屏蔽
- spam.admin    OP权限, 使用命令的权限。
== 命令
"/spam add abc                   将 abc 添加到脏话屏蔽列表",
"/spam remove abc            将 abc 从脏话屏蔽列表移除"
