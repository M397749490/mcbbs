                                                                                     想要一些保安来保卫自己的领地？ 怪物允许你产生怪物成为你的团队!                                                                                 
他们会攻击敌方玩家和怪物! 你甚至可以命令你怪物。 让他们跟着你或一个地区巡逻。
                                     路人甲:纳尼!好厉害的样子                                    [diamond_gem]介绍[diamond_gem]
             这是一款怎么样的插件开头说了                                                                                  [glowstone_dust]安装方法[glowstone_dust]
选择相应的版本下载,然后丢入plugins。重启服务器,然后...嘿嘿


                                                       怪物的类型:                                         
有4个怪物类型:
剑客,弓箭手,法师,泰坦。                                                                                                                                剑客和弓箭手的皮革盔甲颜色可以选择。您可以修改怪物属性配置,并选择性地如果你愿意你可以禁用它们。


注意:
派系怪物将自动分类任何单位满足作为敌人,友好的或中性的。
玩家和派系怪是敌对派系的人将被视为敌人。 如果设置的选项,敌对怪物也会被视为敌人,除了爬行者,它不会攻击。
玩家和派系怪物从自己和盟军派系将被视为友好， 所有其他单位是中性的。
我方派系怪物会自动攻击敌方单位。 它将由中立单位攻击时保护自己。 它永远不会攻击友方单位。
法师和弓箭手有些很坏的目标,并且可能不小心攻击友方单位。 可以通过设置防止损害友军炮火noFriendlyFire配置为true。



配置文件:(半人工)

# = = = = = FactionMobs配置= = = = =

#查看默认配置。 yml(完整的评论和解释)

# https://github.com/Scyntrus/FactionMobs/blob/master/config.yml


#设置的最大数量派系怪物可以生成

#(0 =没有限制)

mobsPerFaction: 0


#自然生成敌怪物的攻击

attackMobs: true


#防止敌人破坏友好的玩家和怪物

noFriendlyFire: true


#防止玩家破坏暴徒在同一个团队

#球员不能伤害友方怪物

noPlayerFriendlyFire: true


#最低等级要求为了产生单位,你可以选择从“RECRUIT”,“MEMBER”(正常),“OFFICER”(主持人)和LEADER”(管理)。

minRankToSpawn: MEMBER


#只能在家里出生(如果是Towny那么就是只能在城镇里出生,其他的没试过)

onlySpawnInTerritory: true


#攻击一个成员或单位将农业附近的友军

alertAllies: true


#启用这个选项将允许玩家医友方怪物

#通过右键单击一个苹果

feedEnabled: true

260 #的Id项用于饲料,默认(苹果)

feedItem:260

#回血量

feedAmount: 5


#显示上面的怪物的派系标记怪物(黄色)

displayMobFaction: true


#设置正常移动速度之间的暴徒(推荐 3和 5默认3)

mobSpeed:3


#设置怪物的速度当巡逻(推荐之间 175 3,默认.175)

mobPatrolSpeed: .175


#设置距离怪物将尝试pathfind(推荐16至64,默认64)

mobNavRange:64


#允许使用/融合,命令设计用于命令块

fmcEnabled: true


#不长错误消息输出控制台。 禁用调试。

silentErrors: true


#特定配置= = = = = =怪物


弓箭手怪物的基础设置

Archer.enabled: true

#血量

Archer.maxHp: 20

0.0 #自定义伤害,将使用默认伤害(正常的伤害是2.0)

Archer.damage: 0.0

#派系权力这个怪物身上生成

Archer.powerCost: 4.0

#花钱生成这个怪物Vault做前置

Archer.moneyCost: 0.0

#实验,您可以指定这个怪物下降1项。 (条目ID)

Archer.drops: 0

法师怪物的基础设置:(注意了)

Mage.enabled: true       (别改)

Mage.maxHp: 20         (法师怪物的最高血量)

#法师的伤害不可修改

Mage.powerCost: 6.0        

Mage.moneyCost: 0.0           花钱生成这个怪物Vault做前置

Mage.drops: 0

剑客怪物的基础设置:

Swordsman.enabled: true

Swordsman.maxHp: 20    (剑客的最高血量）

4.0 #普通伤害

Swordsman.damage: 0.0

Swordsman.powerCost: 5.0

Swordsman.moneyCost: 0.0          花钱生成这个怪物Vault做前置

Swordsman.drops: 0

泰坦怪物的基础设置:

Titan.enabled: true

Titan.maxHp: 40         （还是血量)

15.0 #普通伤害

Titan.damage: 0.0

Titan.powerCost: 11.0

Titan.moneyCost: 0.0               花钱生成这个怪物Vault做前置

Titan.drops: 0

不知道什么鬼的基础设置:

SpiritBear.enabled: true

SpiritBear.maxHp: 30        (依然是血量）

6.0 #普通伤害

SpiritBear.damage: 0.0

SpiritBear.powerCost: 7.0

SpiritBear.moneyCost: 0.0                  花钱生成这个怪物Vault做前置

SpiritBear.drops: 0


# = = = = = =自动保存选项


#使周期性保存在服务器崩溃的情况下

自动保存: false


#服务器蜱虫之间保存(20蜱虫= 1秒)

#这应该设置bukkit autosaveyml文件

#或与任何世界自动保存插件使用。

saveInterval:6000


终于到了万众瞩目的命令和权限了
路人甲:快快快！！

/fm info      获取信息(更方便的打/fm)
/fm spawn archer （archer可以换成swordsman,mage,titan)这就是传说中的召唤怪物！！！
召唤权限:fmob.spawn
控制怪物的指令：(注意:要先右键了后再打这些指令)
/fm order X    （X替换成follow,stop,goHome,setHome,patrolHere,moveToPoint,forgive。下面会讲这些是什么)
   follow----让怪物跟着你
   stop------告诉你的小怪去哪里你告诉他们去最后停在那
   goHome-让怪物回家
   setHome-设置你脚下的方块为怪物的家
   patrolHere--告诉你的小怪巡逻，他们的家和你的当前位置之间(大概意思应该是让怪物在它们家和你脚下的位置之间的地方巡逻）
   moveToPoint--告诉你的小怪到你想要的（什么鬼。。。)
   forgive---告诉你的小怪停止攻击任何中立玩家，激起他们(这。。)
需要权限:fmob.order
PS：更多指令请打开https://dev.bukkit.org/bukkit-plugins/faction-mobs/pages/commands/
