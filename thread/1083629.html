MC-Admin
一款有点好用的mc服务器和插件管理平台 点击前往
服务器的服主功能
  • 展示玩家数量和每日上线数量,同时进行一周玩家数量分析
  • 可在线方便下载各种服务端核心
  • 可在添加服务器信息后,定时每小时获取到服务器的情况,当前玩家数量,motd等等
  • 可在添加mysql信息后,进行对插件管理,目前支持authme,playertitle,playerpoints等更多插件

插件的开发者:可方便的添加付费插件

   验签功能实现原理:
  • 在平台上注册登录
  • 选择开发者功能,添加插件,获取对应秘钥
  • 获取验签代码,修改插件名和秘钥,同时获取用户签名sign, 会在启动会自动发送请求到mc-admin平台进行验签
  • 验签结果: 如果没注册过插件,失败,如果注册过但是秘钥不对, 失败  ,如果插件名和秘钥对了,但是请求者ip和sign不对失败
  • 插件请求会自动将用户ip和对应的服务器端口保存下来,可在平台手动获取sign,或者直接新增ip都可

  42.                             "?sign=" + sign +

  44.                             "&pluginName=" + PLUGIN_NAME +
  45.                             "&secretKey=" + SECRET_KEY;
  46.                     URL url = new URL(urlStr);

  50.                     String current;

  52.                         stringBuilder.append(current);
  53.                     }
  54.                     String verifySign = stringBuilder.toString();
  55.                     if ("true".equals(verifySign)) {
  56.                         // TODO 验证成功进行操作
  57.                     } else {
  58.                         // TODO 验证失败进行操作
  59.                     }
  60.                     this.cancel();
  61.                 } catch (IOException e) {
  62.                     // TODO 网络或者其他问题进行打印消息提醒,并会自动一分钟后重试
  63.                 }
  64.             }
  65.         }.runTaskTimerAsynchronously(PlayerTask.getInstance(), 0, 20 * 60);
  66.     }

  68. }

2020-12-09 补充:
cdk验签规则:
mc-admin网址新增 cdk列表,可以进去查看
这个cdk原理是这样的  
1: 先生成对应插件的cdk,然后这里是可以设置每个cdk可被绑定几次,然后每个cdk是否需要验证端口
2: 服主使用了该cdk第一次请求会自动认证成功并记录,之后的话也一样,有绑定次数就可绑定新ip,没有就返回验证失败
3: 请求路径 http://mcadmin.ljxmc.top/api/public/cdk/verifySign
4: 请求参数还是之前的,没变
原理:
这个是先有cdk然后设置绑定次数,然后被使用了自动绑定到对应ip和端口
