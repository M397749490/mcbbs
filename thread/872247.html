【插件简介】
可以方便的控制服务器里的合成/炼制

【插件特点】
自定义工作台合成
自定义熔炉炼制
可自定义从熔炉获得的炼制经验(1.13+)
可禁用/启用游戏原始的合成
方便的GUI编辑界面
允许有特定权限的玩家合成被禁用的东西
多语言支持:英语，法语，意大利语和中文
可以将自定义NBT属性数据添加到合成（1.13+）
可以使用资源包中的自定义模型（通过 customModelData选项）（1.14+）
方便地为现有的合成方法生成复制品
工作台上支持药水合成
支持从1.8.8版本到1.14版本
支持其他自定义合成插件中的项目
如 Custom Items、Items Adder、Additions、 MMO Items！
甚至可以禁用其他插件里的自定义合成

【使用方法】
创建一个新的合成/炼制方法

1.    输入/recipes add [ID]   创建一个新的合成方法
2.    在左侧选择你想要创建的类型
3.    编辑项目
4.    编辑完成之后，按"E"退出编辑
5.    输入/recipes rl 更新插件配置
禁用游戏里原始的合成
1.    把你要禁止合成的东西拿在手上
2.    输入/recipes disable   禁止此物品合成

【权限与指令】
指令
/recipes add（id）
建一个新的合成方法
/recipes edit (id)
编辑现有的合成方法
/recipes remove (id)
删除指定合成方法
/recipes copy (id) (new id)
创建一个合成方法的副本
/recipes vary (id)
生成常见变化
/recipes disable
禁止合成你手上的东西
/recipes enable
重新启用禁用的合成
/recipes list
列出所有的自定义和被禁用的合成方法
/recipes rl
重新加载配置文件
权限
recipecontrol.admin
允许使用/recips 指令
recipecontrol.bypass.(id)
允许合成被禁用的物品
recipecontrol.custom.(id)
允许合成指定的自定义合成物品。使用recipecontrol.custom.*可以合成所有自定义合成物品
