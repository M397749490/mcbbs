想到一个办法来计算平均TPS了！
I find out a way to calculate the avg. of the TPS!
首先time set night，这样时间就会在13000刻了，到太阳出来时是24000刻（或者0刻）
First i use "time set night", and the time will become 13000 ticks. It will be 24000 ticks(or 0) when the sun raise and start buring those zombies.
那么24000-13000=11000
so 24000 ticks - 13000 ticks = 11000 ticks
然后记录从time set night开始计时，直到僵尸开始燃烧所用的时间
I started counting the time as soon as i use time set night, and stop when the zombies start buring.
结果用时14'49"=889sec
It takes 889 seconds.
11000ticks/889sec=12.3734tps!

从13000 ticks开始计时，到24000 ticks时停止，所以是24000 ticks - 13000 ticks = 11000ticks
在11000ticks用了889秒，也就是11000 ticks per 889 Seconds(每11000 刻 有 889 秒)
然后因为TPS是需要每秒作为单位，所以需要除以889得到结果
11000 ticks per 889 Seconds
------------------------------------------（我是分数线
                 889
=12.3734 ticks per (1) Second
=12.3734 tps
