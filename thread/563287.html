　　大理石材质非常注重细节，所以我作图的时候就是开的512x。这里放出的也是512x。不过感觉256x也能撑起这个细节。这个材质有边缘凹凸效果的。
　　只是MC没有反光这个比较蛋疼。

效果展示

http://i12.tietuku.com/ba3b2ae22ddaa626.png



cube.json
  1. {
  2.     "elements": [
  3.         {   "from": [ 0, 0, 0 ],
  4.             "to": [ 16, 16, 16 ],
  5.             "faces": {
  6.                 "down":  { "texture": "#down", "cullface": "down" },
  7.                 "up":    { "texture": "#up", "cullface": "up" },
  8.                 "north": { "texture": "#north", "cullface": "north" },
  9.                 "south": { "texture": "#south", "cullface": "south" },
  10.                 "west":  { "texture": "#west", "cullface": "west" },
  11.                 "east":  { "texture": "#east", "cullface": "east" }
  12.             }
  13.         }
  14.     ]
  15. }
复制代码


需要修改的方块json，zm就是坐面，db是另一个材质。
  1. {
  2.     "parent": "block/cube",
  3.     "textures": {
  4.         "particle":"blocks/db",
  5.         "down": "blocks/db",
  6.         "up": "blocks/zm",
  7.         "north": "blocks/db",
  8.         "east": "blocks/db",
  9.         "south": "blocks/db",
  10.         "west": "blocks/db"
  11.     }
  12. }
