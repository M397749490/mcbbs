作者: cx868    时间: 2014-1-31 20:20
在/plugin/Residence/config.yml里面找到这几行  替换进去
  1. Residence:
  2.            # 玩家是否可以创建领地.这个设置可被 'residence.create' 权限覆盖.
  3.            CanCreate: true
  4.            # 玩家允许拥有最大领地数.
  5.            MaxResidences: 10000
  6.            # 一个领地的最大物理区域数目.
  7.            MaxAreasPerResidence: 99999999
  8.            # 一个领地在东西方向最大距离 (X坐标).
  9.            MaxEastWest: 99999999
  10.            # 一个领地在南北方向最大距离 (Z坐标).
  11.            MaxNorthSouth: 99999999
  12.            # 一个领地在上下方向最大高度 (Y坐标).
  13.            MaxUpDown: 256
  14.            # 允许创建领地的最低高度.
  15.            MinHeight: 0
  16.            # 允许创建领地的最高高度.
  17.            MaxHeight: 255
