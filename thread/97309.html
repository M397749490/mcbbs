  综述


   SimpleCarts，是一个面向玩家的、可以使你的矿车更加容易、搞笑地被使用的解决方案。这是与MinecartMania和CraftBook相对的选择，它仅仅只是使用时少了点麻烦。



功能




    这个插件使用“control blocks”放置在铁轨的下面，铁轨或充能铁轨可以表现出多种功能。当矿车从这些控制方块（control blocks）上经过时，功能被激活，可以利用的控制方块有：
·Booster（加速器）:把一个矿车加速为2倍（默认为金块）
·Bouncer（保镖）：反转一个矿车的方向（默认为羊毛）[大兴注：作者称它为保镖]
·Brake（减速器）：把一个矿车减速为1/2（默认为灵魂沙）

·Ejector（驱逐器）:把一个玩家从矿车上赶下来（默认为铁块）
·Elevator（电梯）:把一个矿车传送到正上方或正下方的电梯方块上（默认为钻石块）
·Intersection（中转站）：选择矿车的前进方向（默认为砖块）
·Station（站点）：完全停止一个载着玩家的矿车，而一旦被激活，它就会失效（默认为黑曜石）
除了中转站（大兴注：因为它经常被放置在拐角处，而那里经常是通有红石能量的地方），所有的方块都可以以红石充能的方式来无效它们的功能。SimpleCarts也拥有一些“功能性方块”（这些方块的类型无法被改变）：
·Collector（收集器）:当矿车与箱子碰撞时会被收进箱子里（总为箱子）
·Diepwnser（发射器）:被充能时生成一个矿车（总为发射器）


  SimpleCarts只在玩家乘在矿车上时起作用。未使用和动物乘坐的矿车不适用本插件，而是按照游戏本体的机制运行。（大兴注：此处废话略多，概括之）

  玩家可以简单地通过推矿车来设置矿车的运动方向。在传统方法的基础上，停止矿车的方法也被提供了。由于都被移除了，不管是牛还是苦力怕都不敢站在你铁轨通过的地方



使用方法



  使用方法很简单，通过把指定的方块放在铁轨下面就可以得到相应的效果，这是一个几乎囊括了所有控制方块的铁轨系统：还有2个命令方块，别在意，老朽拿来做收费车站的

你可以发现几乎没有充能铁轨，因为有了这个插件，你可以简单地通过上下左右来开矿车而且速度恒定而快速（嫌不够快可以加加速器），通过充能可以禁用这些控制方块，使它们变得更加可控。把一个箱子放在铁轨的尽头可以实现回收，差不多就这样了

设置文件

  设置文件位于
plugins\SimpleCarts中，名字叫config.yml，别跟老朽说你找不到，插件运行一次就会生成



下面是设置文件的设定



BlockIDs:                         #控制方块的ID设置，注意只能设置实体方块，玻璃什么的是不行的哦
  booster: 41                             
  bouncer: 35
  brake: 88
  ejector: 42
  elevator: 57
  intersection: 45
  station: 49
Collector:                  
  active: true                        #收集器是否启用
  auto-dispose: false             #是否自动清理收集来的矿车（是否收集一个清理一个）
Dispenser:
  active: true                     #发射器是否启动（大兴注：这在1.4以后应该已经失效了，因为游戏自带了发射器发射矿车的功能）
  auto-refill: false                #自动填充（是否发射一个填充一个）
Economy:
  enable-vault: false          #是否利用Vault插件实现经济系统
  cost-per-ride: 20           #每次搭乘的收费
Language:
  override: false               #是否被覆盖
  iso-code: enUS               #语言文件码
Minecart:
  destroy-on-eject: false        #当玩家被驱赶时破坏矿车
  drop-on-eject: false             #当玩家被驱赶时以物品形式掉落矿车
  destroy-on-exit: false           #当玩家离开时破坏矿车
  drop-on-exit: false               #当玩家离开时以物品形式掉落矿车
  punch-to-stop: true            #是否推矿车以停止它
  speed-multiplier: 100           #速度系数（这是玩家在铁轨上运行的默认速度，即使在没有加速铁轨的情况下）
Path:
  remove-empty-carts: false      #是否清除在路线上的空矿车
  remove-entities: true              #是否清除在路线上的所有效用和攻击性生物
  kick-players: false                   #是否踢掉路线的闲杂人等（卧槽这是有多金贵的路线啊）
Redstone:                                 #以下都是是否可以通过充能来禁用它们的设置，你会发现没有intersection
  booster: true              
  bouncer: true
  brake: true
  ejector: true
  elevator: true
  station: true
Worlds:                                   #是否在指定的世界适用此插件
  world: true                                   
  world_nether: true
  world_the_end: true
