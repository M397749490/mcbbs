Fake Max Player Count
伪装最大玩家数量


首先，这是一个Sponge插件，而不是占据服务端插件版绝大多数的Bukkit插件。
虽然说服务端插件版开设了Sponge版块，但是当我纵览整个版块的原创插件的时候，发现这样的Sponge插件根本没有。。。所有标记为Sponge插件的原创插件都是选错类型了的。。。所以本人应该可以说，这个插件是整个服务端插件版的第一个原创Sponge插件。
所以这个插件不能：
  • 直接使用在使用BukkitAPI的服务器（如CraftBukkit、Spigot等）上
  • 使用低于Java8的版本运行（因为Sponge服务端依赖Java8）

不过这个插件可以：
  • 使用在Minecraft 1.8.9和Minecraft 1.10.2对应的SpongeForge上
  • 使用在Minecraft 1.8.9对应的SpongeVanilla上
  • 使用在BungeeCord上

注意，使用时请拖进mods文件夹（BungeeCord端请拖进plugins文件夹）。

Sponge插件开发的一小步，MCBBS原创Sponge插件发展的一大步。

========我是正式介绍内容的分隔线========

这个插件的作用很简单，就是修改服务器显示的最大玩家数量，就像下面这样：

在加入这个插件并运行一次服务端后，会在：
  • Sponge服务端的
    “config/com.github.ustc_zzzz.fakemaxplayercount/com.github.ustc_zzzz.fakemaxplayercount.conf”
  • BungeeCord端的
    “plugins/FakeMaxPlayerCount/FakeMaxPlayerCount.conf”
出现一个配置文件。
默认的配置文件长这个样子：
  1. fakemaxplayercount {
  2.     type=floating
  3.     value=1
  4. }
复制代码
如果设置type为floating，就代表最大玩家数量是现有玩家数量加上value这么多，比如默认的就是现有玩家数量加一，也就是上面的图片显示的效果。
此外，还可以设置type为fixed，这表示最大玩家数量固定在value这个值。
