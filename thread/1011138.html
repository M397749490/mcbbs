两个改重启的方法
spigot.yml里面填写脚本名字
  1.   restart-script: start.bat
复制代码


或者改启动脚本
  1. :ST
  2. java -jar paper.jar
  3. ECHO 服务器关闭，将在5秒后重启...
  4. CHOICE /t 5 /d y /n >NUL
  5. GOTO ST
复制代码

java -jar paper.jar 是启动服务器的那一行指令
/t后面的数字就是延时时间（秒）
GOTO ST 是回到ST的位置
