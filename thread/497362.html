本MOD需要Guide API与Baubles API
Baubles API添加了4个装备栏，允许装备1个项坠,2个指环和1个腰带。
本MOD添加了一堆有用的物品和工具。此外，还增加了一个制作符文，一个独特的制作系统,没有GUI。
此MOD主要是增强了玩家的环境适应能力可以做到以下几点：
飞行，潜水，穿墙，爬墙，瞬移，水(岩浆)上漂，免疫环境伤害，等等。

物品
项坠Pendants
项坠是用来防御的。他们会被动地保护你免受一类的伤害，根据其类型。例如，
唤风者的项坠会保护你免受所有掉落伤害，狱火项坠则保护你不受任何火焰伤害
一个额外的防御层也是可以的，并且可以通过快捷键（设置按键菜单）来打开或关闭。

腰带Belts
腰带将提会供一个被动能力。他们会被动地提供一类的特效，例如，
唤风者的腰带会让你走得更快，衍变腰带则让你在世界各地传送。

指环Rings
指环将提会供一个能力，如飞行，但也可作为进攻性武器。
你有两个环槽，这意味着你可以选择各种不同的组合。

掉落物&其它
为了获得装满的云瓶，带着空的云瓶，去高度200以上自动获得。
你可以通过杀死恶魔猫获得恶魔之心，他们出生在地狱。恶魔之心是一种罕见的掉落。
你可以杀死鹰来获得鹰翼，他们在丛林中出生。一个难得的掉落。
鱼鳞和贝壳都可以通过合成充满鱼腥味的皮袋来随机获得。



充能
充能是本MOD所有的装饰品供能的方式。每组装饰品的供能以不同的方式

唤风者Windmaker's
如果你站在高度200以上。这样是在一个相当快的速度充能，因此在天空中建立你的家也许不是一个坏主意。

狱火Infernal
如果你是在一个炎热的地方。
如果你正在燃烧，他们将获得充能（火抗药水工作）。另外，在下届会得到你需要的充能。
如果你是一个纵火狂，你可能想定居在下届。

水栖Aquatic
在水之中。如果你只是站在1格的水或更多，您的项目将开始充能。
如果你能控制的潮汐，海洋将成为你的家。

繁花Floral
如果外面是晴天，而你是在阳光直射。如果外面阳光灿烂，你和天空之间没有任何阻碍，你将开始充能。
让太阳光束的照射下来的你，自然会成为你的庇护所。

衍变Transposing
当你在末地的时候。不管你在哪里，你都会获得充能。如果你不看末影人，他们不会伤害你，末地将是你的开始。

蕴能水晶Focus Crystals
你不能总是在正确的时间在正确的地方，而这就是蕴能水晶的作用，蕴能水晶可以在对应的环境中充能（就和充电电池一样）

合成
可以合成一本书来看
合成符文/符文合成Crafting Rune / Rune Crafting
合成符文
合成符文是为了得到平凡腰带，指环，项坠，以及其他一些很棒的功能。
为了使用它，把它放在世界里，在他周围放置合成所需的物品，然后右键单击就能获得所需的物品。

比如将羊毛围绕合成符文放置然后点击合成符文就可以合成云朵（要用精准采集）
其它的合成可以在书中查阅。
请注意,制作的顶部网格是北方。如果你面对其他方向它不会工作。
可以使用F3菜单找到你面朝哪个方向。

特殊合成：
围绕合成符文放置一圈萤石合成白天
同理一圈黑曜石则是夜晚
萤石与云朵交错放置则是闪电

符文合成
ps;使用的是惰性符文不是合成符文
同样，将惰性符文其放置在世界上，和周围以某种材料（见下文），以转换为该类型的符文。
云朵 -> 唤风者符文
岩浆 -> 狱火符文
水 -> 水栖符文
草 -> 繁花符文
末地石 -> 衍变符文
