RecipeManager 2
复合配方更易制！

插件特性







  • 能够自定义合成配方
  • 禁止某系原有的配方
  • 在得到配方结果时可以自定义一些有趣的东西
  • 甚至支持一些插件或mod里的物品配方管理
  • 本插件拥有很多能方便调节整个配方的一些标签
  • @permission 能够给配方(或结果)给予一个特殊的权限，没有权限是无法使用配方(或得到合成结果)
  • @remove、@restrict、@overwrite 分别为删除/限制/覆盖现有的配方，包裹原版的配方
  • 更多内容详见“basic recipes.html”
新增特性







  • 普通配方与无序配方可以有多个结果
  • 熔炉现在可以定制燃烧时长或指定一个范围内燃烧时间随机
  • 熔炉现在可以定制燃料与燃烧时长啦
  • 更多内容详见“basic recipes.html”

Flag标签的介绍与应用
开头标签 - 只适用于文本开头或配方开头
@individualresults
别名:@individual		Allows multi-result recipes to have individual result outcomes, instead of a chance based outcome between all results.
用法:放置在'Craft', 'Combine', 'Smelt', 'Fuel'上面或下面, 不可放在结果处
@failmessage
别名:@failmsg		当制作配方失败时, 修改失败时显示的消息
用法:@failmessage [消息或false]
例子:@failmessage <red>你失败了! 哇哈哈哈哈!
@addtobook
别名:@recipebook		此标签是快速向配方书里添加配方的快速渠道
用法:@addtobook <书本ID> [页码<num>]
例子:@addtobook testing book // 向'Testing Book.yml'这本书中添加配方
        @addtobook random stuff volume 3 // 向'Random Stuff.yml'这本书中添加配方, 并以3页书页为例
@restrict
别名:@disable, @denied, @deny		限制这个配方让所有人都无法使用
用法:@restrict [配方失败时的消息]
例子:@restrict <red>禁止使用!
@remove
别名:@delete		删除原有配方
用法:放置在'Craft', 'Combine', 'Smelt', 'Fuel'上面或下面, 不可放在结果处(可以使用'true'或'false'来开启或关闭)
例子:详见帖中
@override
别名:@edit, @overwrite, @supercede, @replace		覆盖原有配方, 使其结果变为现有的结果
用法:放置在'Craft', 'Combine', 'Smelt', 'Fuel'上面或下面, 不可放在结果处(可以使用'true'或'false'来开启或关闭)
例子:详见帖中
@displayresult
别名:@resultdisplay, @showresult		设置配方显示的结果(仅结果图标更改, 不影响得到的物品)
用法:@displayresult <item or first> | [silentfail]
例子:@displayresult first // 显示的结果为原设定的结果
        @displayresult diamond_helmet:120 // 显示的结果为一个受损的钻石头盔
结尾标签 - 只适用于配方结尾
@spawnegg
别名:@monsteregg, @egg		设置生物蛋生成的生物类型
用法:@spawnegg <实体类型>
例子:@spawnegg creeper // 使生物蛋生成的生物为爬行者
        @spawnegg horse // 使生物蛋生成的生物为马
@cloneingredient
别名:@clone, @copy, @copyingredient		克隆一个配方在材料匹配时获得的结果(?)
用法:@cloneingredient <参数>
例子:@cloneingredient data // 只复制数据值
        @cloneingredient data +2 // 只复制数据值并且添加2
        @cloneingredient amount * 2 // 复制数量并乘以2
        @cloneingredient data % 2 // 先将这个数据值除以2然后再得到它余下的
        @cloneingredient data | amount | lore // 只复制这些参数
        @cloneingredient all // 复制整个配方的结果
@itemunbreakable
别名:@unbreakable		使配方的结果为不可破坏
用法:@itemunbreakable [false]
例子:@itemunbreakable // 使结果为不可破坏
        @itemunbreakable false // 移除不可破坏属性, 使得该物品可以被销毁
@itemname
别名:@name, @displayname		给配方的结果设置一个名称
用法:@itemname <文本或false>
例子:@itemname <light_purple>奇怪的物品
        @itemname <yellow>{player}的剑
@fireworkchargeitem
别名:@fireworkcharge, @fireworkeffect		设置烟花的冲锋效果
用法:@fireworkchargeitem <效果参数>
例子:@fireworkchargeitem trail | color 255 0 0, 0 255 0 | type ball_large
        @fireworkchargeitem type creeper | color 0 255 0 | fadecolor 255 0 0, 0 255 0 | flicker
@itemlore
别名:@lore, @itemdesc		给配方的结果添加一行Lore(描述)
用法:@itemlore <文本>
例子:@itemlore <red>非常棒的物品
        @itemlore <magic>第二行的描述增加一些干扰效果
        @itemlore <gray>该物品制作于{world}:{x},{y},{z}
@skullowner
别名:@skullitem		设置头颅的拥有者以便显示皮肤
用法:@skullowner <名字>
例子:@skullowner Notch
        @skullowner {player}
@banneritem
别名:@banner		自定义一个旗帜
用法:@banneritem <基本颜色> | [模式] <颜色> | [...]
例子:@banneritem black
        @banneritem red | circle_middle blue | skull yellow
        @banneritem green | half_horizontal yellow | circle_middle orange
@monsterspawner
别名:@spawner, @mobspawner		设置刷怪笼中刷出的生物类型
用法:@monsterspawner <实体类型>
例子:@monsterspawner creeper
        @monsterspawner horse
@fireworkitem
别名:@firework, @fireworkrocket		设置烟花火箭的效果
用法:@fireworkitem effect <效果数据>
        @fireworkitem power <0-128>
例子:@fireworkitem effect color 0 255 0
        @fireworkitem effect trail | color 255 0 0 | type burst
        @fireworkitem effect color 255 0 200, 0 255 0, 255 128 0 | trail | type ball_large | fadecolor 255 0 0, 0 0 255, 0 255 0
        @fireworkitem power 1
@potionitem
别名:@potion		制作一瓶药水, 只适用于POTION
用法:@potionitem <基本效果>
        @potionitem custom <自定义效果>
例子:@potionitem level max | type FIRE_RESISTANCE | extended // 一瓶基础的抗火药水
  进阶药水例子:
        @potionitem type POISON | splash // 将药水瓶的类型设置为飞溅型
        @potionitem custom type WITHER | duration 10 // 添加一个凋灵效果
        @potionitem custom duration 2.5 | type BLINDNESS | amplify 5 // 添加一个失明效果
@getrecipebook
别名:@getbook, @bookresult		用指定配方书里的配方结果覆盖现在的配方结果
用法:@getrecipebook <书本ID> [页码<num>]
例子:@getrecipebook recipe stuff // 匹配'Recipe Stuff.yml'为例
        @getrecipebook vanilla_recipes volume 2 // 匹配'vanilla_recipes.yml'第二页的内容
@enchantitem
别名:@enchant, @enchantment		给结果添加一个指定等级的附魔
用法:@enchantitem <附魔> [等级]
例子:@enchantitem OXYGEN // 添加一个1级的水下呼吸附魔
        @enchantitem DIG_SPEED max // 添加一个满级的效率附魔
        @enchantitem ARROW_INFINITE 127 // 添加一个127级的无限附魔
        @enchantitem SHARPNESS remove // 删掉这个附魔
@leathercolor
别名:@leathercolour, @color, @colour		设置皮革防具的颜色
用法:@leathercolor <R> <G> <B>
例子:@leathercolor 255 0 0              // 皮革防具呈现红色
        @leathercolor 0 255 0                // 皮革防具呈现绿色
        @leathercolor 0 0 255                // 皮革防具呈现蓝色
        @leathercolor 0 0 0                   // 皮革防具呈现黑色
        @leathercolor 255 255 255      // 皮革防具呈现白色
@hide将物品的属性隐藏, 但不会让效果消失
用法:@hide <参数>
例子:@hide attributes // 隐藏剑上的伤害属性
        @hide placedon | destroys // 隐藏可放置/可破坏的字样
@enchantedbook
别名:@enchantbook, @enchantingbook		给附魔书添加附魔效果
用法:@enchantedbook <附魔> [等级或最大值]
例子:@enchantedbook efficiency // 添加效率附魔, dig_speed为别名
        @enchantedbook damage_all max
        @enchantedbook arrow_fire 127
        @enchantedbook sharpness remove
@bookitem
别名:@book		修改一本成书的内容
用法:@bookitem title [文本]
        @bookitem author [文本]
        @bookitem addpage [文本]
例子:@bookitem title 盗窃的艺术 // 将成书的标题设为'盗窃的艺术'
        @bookitem author 灰狐 // 将成书的作者设为'灰狐'
        @bookitem addpage <bold>O<reset>很久以前...
        @bookitem addpage // 添加一页空白的内容
        @bookitem addpage \n\n\n\n<italic>      完. // 这页内容新行4次(\n)
@noresult阻止该配方的制作(方便进行调试)
用法:将其放置在配方的结尾, 也就是结果的后面即可生效
例子:无例子
通用标签 - 适用于文本开头, 配方开头以及结尾(整理中...)
