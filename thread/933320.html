标题: spigot1.14.4-InventoryType与InventoryHolder的问题
问题：在1.14.4的inv测试，漏斗（可能还有其他类型）inv无法找到相应的holder

过程：
// 创建一个InventoryHolder
InventoryHolder holder = () -> null;
// 创建一个漏斗Inventory
Inventory inv = Bukkit.createInventory(holder, InventoryType.HOPPER, title);
// 输出该Inventory中的InventoryHolder
system.out.println("create inv: hopper to holder " + inv.getHolder());

结果为: 'create inv: hopper to holder null' 该getHolder为空指针

但是一般的箱子inv的holder却还在，不知道有什么方法能解决，谢谢了




作者: Saukiya    时间: 2019-12-17 13:29
已解决：
NMS对象 CraftCustomInventoryConverter converter = new CraftCustomInventoryConverter();

Inventory inv = converter.createInventory(holder, type, title);
