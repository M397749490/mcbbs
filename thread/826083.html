当你在采矿，探索洞穴或者在晚上时，你或你的玩家是否有足够的火把？那么这个插件适合你！
  • 需要前置WorldGuard



主要特点：
  • WorldGuard支持
  • 测试于Spigot 1.13
  • 火把自动从背包中放出
  • 火把可以放置在一条水平的线上
  • 可以放置火把的黑名单 (??不是很懂)
  • x，y，z轴的边界
  • 在插件加载时自动检查更新，在OP加入和命令时进行更新检查
  • 可以为其他玩家启用/禁用该功能
权限:
  • autotorch.auto - 允许玩家打开和关闭自动放置火把
  • autotorch.listcommands - 允许玩家列出插件中的所有命令
  • autotorch.autoothers - 允许玩家为其他玩家启用自动火炬放置
  • autotorch.admin - 允许玩家查看插件信息，重置配置，重置启用了autotorch的玩家列表并检查更新
  • autotorch.* - 上面列出的所有权限
命令：
  • /at - 列出所有命令
  • /at t - 启用/禁用自动火把放置
  • /at t <player> - 启用/禁用其他玩家的自动火把放置
  • /at reset - 重置配置文件
  • /at clear - 禁用每个人的自动火把放置
  • /at update - 检查SpigotMC的更新
  • /at about - 显示有关插件的信息
安装：
您只需将文件下载并复制到plugins文件夹即可。如果你需要配置任何你需要启动服务器的东西，那么你可以进入AutoTorch文件夹，在那里你可以找到config.yml



配置：
  1. ＃使用AutoTorch v1.2.0于XX
  2. ＃感谢您使用AutoTorch！如果您和您的玩家喜欢这个插件，请留下评论 - 这有很大帮助！
  3. ##
  4. 从v1.2.0开始，如果你从旧版本升级，请更改'player.frominventory'而不是'frominventory'
  5. player:
  6.   frominventory: false #从背包里放置火把
  7. plugin:
  8.   loginupdatechecker: true #OP登陆时检测更新
  9. block:
  10.   radius: 10 #半径
  11.   lightnesslevel: 4 #光照等级
  12.   blacklist: #黑名单
  13.   enabled: false #开启
  14.   list: #放置的方块
  15.   - GRASS
  16.   - DIRT
  17.   boundaries:
  18.   x:
  19.   enabled: false
  20.   min: 0
  21.   max: 1000
  22.   y:
  23.   enabled: false
  24.   min: 4
  25.   max: 30
  26.   z:
  27.   enabled: false
  28.   min: 0
  29.   max: 1000
  30. worldguard:
  31.   enabled: true
  32.   regions:
  33.   - __global__
