标题: [1.12.2-1.7.X][Mod Control——模组控制]让不被欢迎的Mod远离服务器
本帖最后由 ksgfk 于 2019-1-22 23:06 编辑

该Mod只能用于服务端，客户端安装无效!
===================================================
Mod描述:这个MOD是一个服务器工具，允许你规定哪些mod可以在服务器内使用
英文原文:This mod is a small server utility that allows you to filter which mods players that join your server are allowed to use.

----------------------------------------------------------------------------------------------------------------------------------------------------
Mod效果截图:
↓这是客户端加入了黑名单中的mod，尝试连接服务器的效果，这里的例子是矿物追踪


可以看到直接被服务器T了请不要在意提示了啥(我芦苇没有开挂!)
↓这是客户端缺少了白名单和灰名单的mod的提示

----------------------------------------------------------------------------------------------------------------------------------------------------

Mod配置:

注意：1.7和1.8以上的配置稍微有些不同

在把本mod扔进mods文件夹并启动服务端一次后，会在服务端 根目录/config 下生成ModControl文件夹
1.8+
ModControl下会有4个文件

ModControl.cfg是配置文件
blackList.txt是黑名单列表，包含用户无法安装的所有mod
whiteList.txt是白名单列表，包含用户可以安装的所有mod
greyList.txt是灰名单列表，包含用户必须安装的所有mod

打开ModControl.cfg，可以看到以下内容
  1. # Configuration file

  3. settings {
  4.     # On which list should a mod be that is in no file? 0=BlackList, 1=WhiteList
  5.     I:DefaultBehaviour=1

  7.     # The default Kick Message for when a player has a mod from the blacklist installed. %s will be replaced by the modid
  8.     S:DefaultBlackListKickMessage=You aren' allowed to use %s.

  10.     # The default Kick Message for when a player does not have a mod from the greylist installed. %s will be replaced by the modid
  11.     S:DefaultGreyListKickMessage=You need to have %s installed.

  13.     # Whether Operators can ignore this mod
  14.     B:Op-Bypass=false
  15. }
复制代码

我将I:DefaultBehaviour的值调整为0，这样就可以在blacklist.txt中填写我们不希望进入服务器的mod
将Op-Bypass的值调整为false，这样可以阻止拥有OP权限的人忽略该mod

现在打开blackList.txt，按照以下格式填写
  1. modid:踢出服务器时显示信息
复制代码
注意！踢出服务器时显示的信息不能是中文，否则会乱码，我改成UTF-8格式也没用

例如，我们想把矿物追踪加进去。

在这里可以找到modid
我们把这段代码加到blackList.txt中
  1. scenter:Please delete your mod "scenter",don't imitate LuBenWei
复制代码
保存，重启服务器，看看加了矿物追踪后是不是不能进服务器了(芦苇nb!)

接着，我们打开whiteList.txt和greyList.txt，将允许在服务器使用的mod全部按照上面的格式添加好
例如服务器里现在有mcp、minecraft(我怀疑forge是把原版mc当成mod加进去了)，但是我们又想让玩家必须安装小地图才能进服
老办法获取modid，将以下代码添加到whiteList.txt和greyList.txt
  1. mcp:mcp
  2. minecraft:minecraft
  3. xaerominimap:xaerominimap
复制代码
保存，重启服务器，在客户端里删掉小地图，看看是不是不能进服了，而且会提示xaerominimap

建议：让灰名单和白名单同步，防止技术熊修改modid进入服务器

1.7
由于楼主没用过1.7的，所以可能会和实际情况有些出入
ModControl下会有1个文件：ModControl.cfg
打开ModControl.cfg
  1. # Configuration file

  3. settings {
  4. # The Kick Message an user will get when using a mod that's not allowed, %s will be replaced with the mod id [default: You are not allowed to use %s]
  5. S:Kick-Message=You are not allowed to use %s

  7. # ListType (0=BlackList, 1=WhiteList) [range: 0 ~ 1, default: 0]
  8. I:ListType=0

  10. # ModIds seperated by ; [default: ]
  11. S:ModIds=journeymap;NotEnoughItems

  13. # Users that will not be affected by this mod. Seperated by ; [default: ]
  14. S:IgnoredUsers=

  16. # Server Operators will not be affected by this mod [default: true]
  17. B:Op-Bypass=true

  19. }
复制代码
其实就是把黑名单搬到配置文件夹了.

小提示：你还可以使用命令“/ mc reload”重新加载设置，而无需重新启动服务器。
