可以通过检测玩家头部、脚部来达到是否“泡水”
例如：1.脚部
  1. execute as @a at @s if block ~ ~ ~ water[level=0] run tag @s add A
复制代码
2.头部
  1. execute as @a at @s if block ~ ~ ~ water[level=0] run tag @s add B
复制代码
以免玩家一直拥有tag，需要
  1. tag @a[tag=A] remove A
复制代码
  1. tag @a[tag=B] remove B
复制代码
然后再将同时拥有tagA、B的做个记号，例如计分板A、tagC
