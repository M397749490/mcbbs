想设计一把剑，它的攻击力会随着攻击的次数减少。我写了一个ItemSword的子类，通过重写 getAttributeModifiers(EntityEquipmentSlot slot, ItemStack stack) 方法如下：
  1. public Multimap<String, AttributeModifier> getAttributeModifiers(EntityEquipmentSlot slot, ItemStack stack) {
  2. CapaIronWeapon cis = stack.getCapability(CapabilityLoader.CAPA_IRON_WEAPON, null);
  3.                 Multimap<String, AttributeModifier> multimap = HashMultimap.<String, AttributeModifier>create();
  4.                 if (slot == EntityEquipmentSlot.MAINHAND) {
  5.                         float damage = (float) (this.swordType.getAttack() * cis.getHardness() * 0.02 * cis.getPurity() * 0.01
  6.                                         * (0.5 + Math.sqrt(0.5 + cis.getSharp() * 0.02 * cis.getPurity() * 0.01)));
  7.                         float speed = this.swordType.getAttackSpeed();
  8.                         multimap.put(SharedMonsterAttributes.ATTACK_DAMAGE.getName(),new AttributeModifier(ATK_DAMAGE_MODIFIER_UUID, "Attack damage", damage, 0));//每次调用，传入的damage的值都不同
  9.                         multimap.put(SharedMonsterAttributes.ATTACK_SPEED.getName(),
  10.                                         new AttributeModifier(ATK_SPEED_MODIFIER_UUID, "Attack speed", speed, 0));
  11.                 }
  12.                 return multimap;
  13.         }
复制代码


每次调用该方法时,AttributeModifier中都会获得一个不同值的变量damage，以达到产生不同攻击力的需求。经测试攻击实体后，攻击力确实发生了变化，但是属性标签显示的攻击力却不会改变，
