Whitelist Pro更加专业的白名单
(版本:1.0)
它可以让不是白名单的玩家以旁观者进入服务器
基础命令
/ wl-显示有关白名单的命令和统计信息/ wlon-激活白名单。
/ wlon-停用白名单。
/ wladd-将启用白名单。
/ wlrem-从白名单中删除玩家。
/ wllist-列出白名单中的玩家。
/ wlreset-从白名单中删除所有玩家。
/ wlbypass-激活白名单时，切换是否具有旁路权限的玩家可以加入。

权限

  • whitelistpro.info-访问/ wl。
  • whitelistpro.on-访问/ wlon。
  • whitelistpro.off-访问/ wloff。
  • whitelistpro.add-访问/ wladd。
  • whitelistpro.remove-访问/ wlrem。
  • whitelistpro.list-访问/ wllist
  • whitelistpro.reset-访问/ wlreset
  • whitelistpro.managebypass-访问/ wlbypass。
  • whitelistpro.bypass-如果启用了绕过，则允许玩家绕过白名单。
  • 注意：如果在启用白名单的情况下关闭服务器或重新加载服务器，则服务器将自行停用并从白名单中删除所有人员。
