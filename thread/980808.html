goupoints —— 一款全新的点券插件

插件特性
  • 支持并只支持MySQL数据库
  • 可自定义的点券名字
  • 内置两种点券
  • 内置PAPI变量支持
  • 插件理论全版本适配
  • 如果觉得好用的话~点赞评分一下下呗~
  • 服务器长时间没有玩家时可能会发生一个数据库报错
  • wait_timeout=31536000
    interactive_timeout=31536000
  • 需要在数据库的my.ini文件中添加以上内容(这是数据库的锅我不背
  • my.ini一般在C:\ProgramData\MySQL\MySQL Server 8.0这里


插件前置
  • SQLibrary
  • PlaceholderAPI
  • 注意！此SQLibrary前置与PlayerpPoints的SQLibrary前置为不同作者所制
  • 所以本插件与PlayerPoints不兼容

插件指令
  • gp me : 显示你的点券余额
  • gp give <name> <points> : 增加玩家点券
  • gp givebind <name> <points> : 增加玩家绑定点券
  • gp giveall <points> : 增加所有玩家点券
  • gp givebindall <points> : 增加所有玩家绑定点券
  • gp take <name> <points> : 减少玩家点券
  • gp takebind <name> <points> : 减少玩家绑定点券
  • gp look <name> : 查询玩家点券
  • gp set <name> <points> : 设置玩家点券
  • gp setbind <name> <points> : 设置玩家绑定点券
  • gp reload : 重载插件

插件权限
  • gp me : 默认
  • gp give <name> <points> : gp.give
  • gp givebind <name> <points> : gp.givebind
  • gp giveall <points> : gp.giveall
  • gp givebindall <points> : gp.givebindall
  • gp take <name> <points> : gp.take
  • gp takebind <name> <points> : gp.takebind
  • gp look <name> : gp.look
  • gp set <name> <points> : gp.set
  • gp setbind <name> <points> : gp.setbind
  • gp reload : gp.reload

插件变量
  • %gou_points% 点券变量
  • %gou_bindpoints% 绑定点券变量

特殊姿势
  • 在give指令的points里指定负值同样起到take的作用

后续计划
  • 完全可自定义的货币系统
  • 优化代码及逻辑
  • 安排点赞三连
