插件介绍

- 这是一个非常简单的插件.既小又简单.你可以在配置文件内设置任何你想要阻止的指令.
- 此插件只能控制台使用被禁止的指令.其他人都不能使用被禁止的指令.
- 感谢你们使用我搬运的插件.
配置文件
cmds-list:
- bukkit:plugins
- plugins
- help
- version
- bukkit:op
- bukkit:deop
- minecraft:stop
error-text: §c该命令已经被禁止.
权限与指令
- /AntiCmds Add [command]
  权限：anticmds.add
  介绍：添加要阻止的命令.
- /AntiCmds Delete [Command]
  权限：anticmds.del
  介绍：从config.yml中删除禁用命令.
- /AntiCmds Reload
  权限：anticmds.reload
  介绍：重载插件.
