!!!接下来的内容，没有看过站内搬运贴教程就不用看了，先看那个!!!



接下来，我会为你逐字逐句地解析这个看似复杂实则简单的例子，各个部分在脚本中起到的作用。

on player chats:
当玩家聊天时触发下面的脚本
- determine passively cancelled
取消玩家发送消息这个行为，也就是不让消息发出去
- announce "<element[§f§l『<tern[<player.is_op>].pass[§c].fail[§b]><player.name>].on_hover[§e世界: 朋友的服<n>§e等级: <player.xp_level>级<n>§e延迟: <player.ping>ms<n>§e金钱: 未开放<n><n>§c签名: <player.flag[qm]||无>].type[SHOW_TEXT]>§f§l』§f: <context.message>"
发送新的聊天消息，能做到帖子开头的效果的核心

这么长，是不是看了就头大？没关系，让我来慢慢梳理。
我们先把它拆分成三段
“<element[§f§l『<tern[<player.is_op>].pass[§c].fail[§b]><player.name>]


<element[                 ]> 的作用，就是将里面的文本包括起来，让后面的on_hover作用在一整个文本上。相当于数学里的 ( 1 + 7 ) x 3 ，如果不加这个括号，就变成了 1 + 7 x 3 ，这能一样吗？回到脚本里，如果不加这个括号，也许就会出现前面的几个文本不显示悬浮文本，而后面的文字显示的情况。

<tern[     第一处     ].pass[    第二处   ].fail[       第三处        ]>的作用是判断玩家是否为op，如果是，就显示红色名字，反之，则显示蓝色名字。

当这个tag被填充时，它会判断第一处的是true还是false，<player.is_op>。
当第一处为true时（你是op时），输出    第二处   
当第一处为false时（你不是op时），输出       第三处        
也就是说，当它完全被填充后，这么长的一个<tern[.......].pass[......].fail[.....]>就会变成    第二处   或是       第三处      
你完全不用发费更多的力气写if判断玩家是不是op，
- if <player.is_op> :
    - announce "....."
- else :
    - announce "......."

<player.name>输出聊天的玩家的id
.on_hover[§e世界: 朋友的服<n>§e等级: <player.xp_level>级<n>§e延迟: <player.ping>ms<n>§e金钱: 未开放<n><n>§c签名: <player.flag[qm]||无>].type[SHOW_TEXT]>

这么长一串的tag，它的主干就是  .on_hover[.........].type[SHOW_TEXT]
它的作用就是当鼠标移动到一些文本上时，显示..........
type[SHOW_TEXT]就是显示的类型（有展示物品什么的，具体去帮助手册查）
<n>是换行
§f§l』§f: <context.message>"

<context.message>的作用就是输出聊天玩家的聊天内容
