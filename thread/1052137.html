借助局部坐标配合标记实体即可

执行一次
summon armor_stand ~ ~ ~ {Tags:["circle"]}
循环
execute at @e[type=armor_stand,tag=circle] run setblock ^  ^ ^5 stone
execute as @e[type=armor_stand,tag=circle] at @s run tp @s ~ ~ ~ ~1 ~
其中5为半径
最后等圆画出来后打掉盔甲架即可

作者: 晴路卡    时间: 2020-5-28 11:26
1.先搞个记分板（单此执行）
  1. scoreboard objectives add rotation dummy
复制代码
2.放一个盔甲架
3.每tick把盔甲架的水平朝向值记录到记分板，加1，返还到盔甲架的NBT里（依次高频执行）
  1. execute as @e[type=minecraft:armor_stand] store result score @s rotation run data get entity @s Rotation[0] 1
  2. scoreboard players add @e[type=minecraft:armor_stand] rotation 1
  3. execute as @e[type=minecraft:armor_stand] store result entity @s Rotation[0] float 1 run scoreboard players get @s rotation
复制代码

我们就能获得一个旋转的盔甲架
4.在盔甲架面朝方向N格放置方块（高频执行）
  1. execute as @e[type=minecraft:armor_stand] at @s positioned ^ ^ ^20 run setblock ~ ~ ~ minecraft:white_concrete replace
复制代码

比如这样就能画一个半径为20的圆 你可以更改“^ ^ ^”之后跟着的数字来改变这个半径
5.绕一圈后，停止高频
