EssentialsGUI——让你的Essentials使用起来更方便/更友好吧！（V1.0.0）
国际惯例：先来图片（补图）


在您下载该插件前请注意：

  • 该插件要求使用Essentials或者EssentialsX作为前置
  • 这个插件的主要功能是让你配置Essentials可以使用直观又方便又友好的GUI来配置
  • 使用此插件您可以一键配置您的工具包和地标点等
  • 使用这个插件您可以看到所有你想看到的关于地标点的选项，玩家可以通过使用GUI来传送到你设置的地标点
  • 这个插件是BossShopPRO的一个拓展插件，你需要BossShopPRO才可以使他工作！
This plugin uses your Essentials (or EssentialsX) configuration files to create very playerfriendly and intuitive chest GUI menus.

Using this plugin players will be able to preview your Essentials Kits (including all items) and purchase or receive them with one simple click.

If you enable the warp GUI players will be able to see a fancy list of all possible warps and teleport to them by simply clicking the warp icon they want.

EssentialsGUI is a BossShopPro addon. It requires BossShopPro in order to work.

插件特点：
  • 使用起来非常简便！
  • 即安即用：无需配置，立即使用这个插件（当然如果你需要，一切都可以进行配置）
  • 支持木牌使用
  • 支持Essentials或EssentialsX（1.8+服务器福音）

  • Super easy and intuitive to use
  • No need to invest time in configuration: Everything ready to be instantly used (Everything is configurable if you want to customize the plugin though)
  • Sign support
  • Supports both Essentials and EssentialsX


权限：
（因为这个插件是依赖BossShop的所以你需要给出BossShopPRO打开菜单的相关权限）
EssentialsGUI created menus use the same permissions as any other BossShopPro menu:

  • BossShop.open - Allows to open all shops via sign/command
  • BossShop.open.sign - Allows to open all shops via sign
  • BossShop.open.sign.<shopname> - Allows to open the named shop via sign
  • BossShop.open.command - Allows to open all shops via command
  • BossShop.open.command.<shopname> - Allows to open the named shop via command

How to set up EssentialsGUI signs?
Simply put the sign text defined in your configuration files into the first line of your sign. Default sign texts: '[Kits]' and '[Warps]'.

地标传送配置文件
  1. ## warpshopitem:
  2. ## Here you can define the look and functionality of every warp icon.
  3. ## By default clicking a warp and as result executing the warp command is free.
  4. ## The reward of clicking the icon is the warp command being executed.
  5. ## Possible warp delays, prices or required permissions depend on your Essentials settings
  6. ## as all this plugin does is making the player execute a specific warp command.
  7. ## One possibility to make your automated warp icons look different is by using the placeholder '%warpid%' which will be replaced with the id of the icon (from 0 to <amount of icons> -1).
  8. ## In the default configuration the warpid is combined with modulo in order to generate colorful wool icons. Of course you can remove the durability line if you do not want that effect.
  9. warpshopitem:
