接下来在main里面输入
  1. @Override

  3.         return super.onCommand(sender, command, label, args);

复制代码
接下来我们写一个打招呼的插件
  1. public class Main extends JavaPlugin implements Listener {
  2.     @Override
  3.     public boolean onCommand(CommandSender sender, Command command, String label, String[] args) {
  4.         if(command.getName().equalsIgnoreCase("Hi"))//command获得的指令为Hi时输出“你们好”。
  5.         {
  6.             sender.sendMessage("你们好");
  7.             return true;//返回true告诉服务器执行指令
  8.         }
  9.         return false;
  10.     }
  11. }
复制代码
接下来就是注册这个指令了，在plugin.yml加入如下代码
  1. commands:
  2.   Hi: //指令名称
  3.     description: Hi//指令
  4.     usage: /<command>
复制代码
