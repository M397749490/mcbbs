思路是这样：
authme的sha256的格式：$SHA$salt$sha256(sha256(password)+salt)
前面的“$SHA$”是固定不动的，salt是盐，十六个字符，可以自行获取到，密码，根据输入计算出authme-sha256格式的字符串拿去比对
至于修改，不是难事啦，把新密码和那个帐号的salt代进去算，注册更不用说~
注册：随机生成十六个字符的小写字母加数字混合的salt，然后算，拼接，还有其他的数据表字段自己想
俺自己造的轮子：
  1. public static String encrypt(String password, String salt) {
  2.         String hash = sha256(sha256(password)+salt);
  3.         String encryptedStr = "$SHA$"+salt+"$"+hash;
  4.         return encryptedStr;
  5. }

对了，如果要直接操作数据库，把authme缓存关了
