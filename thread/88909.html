你是不是觉得“Player Joined the game”，“Player left the game”会有人看不懂或者不够特别？
CustomMessages自定义信息插件，解决了你的问题！
（话说我曾经就为修改这个东西在这里问来问去的..别嫌我无聊）

指令（Commands）:

/cm join [enable|disable|reset|message] - 开启/关闭/还原/列出 进入游戏信息显示
/cm join [player|group] [enable|disable|reset|message] - 设置特定组或玩家进入游戏信息
/cm quit [enable|disable|reset|message] - 开启/关闭/还原/列出 离开游戏信息显示
/cm quit [player|group] [enable|disable|reset|message] - 设置特定组或玩家离开游戏信息
/cm globaljoin [enable|disable|reset|message] - 开启/关闭/还原/列出 所有人进入游戏信息显示
/cm globalquit [enable|disable|reset|message] - 开启/关闭/还原/列出 所有人离开游戏信息显示
/cm firstjoin [enable|disable|reset|message] - 设置第一次加入服务器信息
/cm colors - 查看颜色代码
/cm variables - 查看所有的变量
/cm reload - 重新加载插件


修改信息时可以使用的变量（Current Message Variables）:

/name -玩家名字
/nname - 玩家昵称
/count - 特殊玩家数量
/online - 当前玩家在线时间
/maxonline - 玩家允许在线最大时间
/prefix - 该分组的前缀
/suffix - 该分组的后缀
/group - 玩家所在的组
/world - 玩家所在的世界


权限（Permission Nodes）:

CustomMessages.* - 允许所有指令
CustomMessages.join - 允许使用 /cm join
CustomMessages.join.other -允许使用 /cm join [player]
CustomMessages.join.group - 允许使用  /cm join [group]
CustomMessages.quit - 允许使用  /cm quit
CustomMessages.quit.other - 允许使用  /cm quit [player]
CustomMessages.quit.group - 允许使用  /cm quit [group]
CustomMessages.globaljoin - 允许使用  /cm globaljoin
CustomMessages.globalquit -允许使用  /cm globalquit
CustomMessages.firstjoin - 允许使用  /cm firstjoin
CustomMessages.noprefix - 允许移除配置前缀
CustomMessages.reload - 允许重载插件

配置文件（Config Files）

true为开启，false来关闭
config:
  must-have-permissions-to-show-current-messages: false
#是否需要权限显示信息
  send-messages-to-console: true
#是否把信息显示在控制台上
  debug: false
#这个..不解释
  global-join-message: '&e/name &e加入了游戏.'
#修改加入信息
  global-join-message-enabled: true
#是否显示加入信息
  global-quit-message: '&e/name &e离开了游戏.'
#修改离开信息
  global-quit-message-enabled: true
#是否显示离开信息
  global-firstjoin-message: '&d欢迎新人 /name 来到了服务器大家庭!'  
#修改第一次加入服务器的信息
  global-firstjoin-message-enabled: false
#是否显示第一次加入信息（ESS自带此功能并且支持中文，建议能关闭的关闭）
  message-prefix: '[&aCM&f] '
#信息的前缀
#以下是特定组或玩家进出服务器的信息，可以按照所给方法设置特定人的信息
users:
  example:
    join: '&4Example joined the server'
    join-enabled: true
    quit: '&5Example is gone now'
    quit-enabled: true
groups:
  examplegroup:
    join: /prefix&4/name joined the game
    join-enabled: true
    quit: /prefix&4/name left the game
    quit-enabled: true


支持中文信息(ANSI格式)
支持颜色代码&1&2&3&4..
