命令 /data 修改告示牌的文本。（穷举大法！）
  1. data modify block <告示牌坐标> Text1 set value '{"text":"<文本>"}'
  2. data modify block <告示牌坐标> Text1 set value '{"text":"<移动一格的文本>"}'
  3. data modify block <告示牌坐标> Text1 set value '{"text":"<移动两格的文本>"}'
  4. ...
复制代码

至于怎么移动，空格，更多空格需要使用 \\u0020（直接加在文字前后即可）。
