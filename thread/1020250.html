CutePortals —— 灵巧传送门

插件特点：
  • 创建跨服传送门
  • 跨服后执行指令
  • 跨服后执行 玩家/后台 指令


插件截图：
  • 其实就是传送门的截图,也没什么好说的



插件指令：
  • /cps create <子服名称> <执行的指令> - 创建跨服传送门
  • /cps remove - 删除传送门
  • /cps goto <子服名称> <执行指令> - 跨服后执行指令
  • /cps reload - 重载配置文件
  • 具体怎么使用,我会在下面讲


插件权限：
  • cuteportals.create - 创建跨服传送门
  • cuteportals.use - 使用跨服传送门
  • cuteportals - 查看插件帮助


使用方法：
  • 如何创建传送门？
  • 使用小木斧选择一片区域
  • 选择完成后,使用指令 /cps create <子服名称> <执行的指令> 进行创建传送门
  • 子服名称必须为你bc配置文件里的名称,执行的指令默认是后台执行,若需要玩家执行,则...
  • 在后面输入 {player};若不需要执行指令,则在末尾输入 {none}
  • 例子: /cps create sc warp a {player} - 则会在传送到sc子服后,由玩家执行warp a的指令

  • 如何创建传送门且不跨服？
  • 使用小木斧选择一片区域
  • 选择完成后,使用指令 /cps create {none} <执行的指令> 进行创建传送门
  • {none}就表示不跨服,进入传送门后,会直接执行设置的指令
  • 其他的和上面一样

  • 如何使用goto指令？
  • 输入指令 /cps goto <子服名称> <执行指令> 即可使用
  • 规则和上面的一样,只是可以直接执行指令,和菜单搭配使用效果更加


安装方法：
  • 安装前置: worldedit
  • 将插件丢进plugins文件夹后重启服务器即可
  • 所有要使用此插件功能的子服,都需要安装哦


插件下载：
