（我甚至怀疑Forge是否会被取代）（划掉）



简介
Fabric是一个1.14快照版本的Mod加载器，目前最新版本对应MC的18w50a的快照。Fabric采用Fabric Loader的加载器来实现加载Mod，类似于Forge的Forge Modloader。
Fabric采用Yarn的反混淆方式反编译反混淆Minecraft源代码，与Forge的Minecraft Coder Pack不同。




如何安装（这才是关键）
警告：Fabric只能在Java 8的环境下加载。
目前Fabric未能给出给官启安装的方法，目前只能安装至MultiMC启动器。
从https://fabric.asie.pl下载Fabric的最新版本，下载JAR文件到桌面上之后，按照下面的方法开始安装。
MultiMC安装：
单击“复制MultiMC实例URL”。这会将一个URL复制到MultiMC模板的ZIP到剪贴板。启动MultiMC。单击左上角的“添加实例”按钮，然后选择“从ZIP导入”，并将URL粘贴进去。不要忘记设置实例名称，否则它将启动原版游戏！
安装到服务器：
转到下载页面并选择所需的加载器版本，稍后选择游戏/映射版本。
单击“下载服务器启动器”或“复制服务器启动器.JAR URL”。使用此命令下载服务器启动器。
此外，下载指定Minecraft版本的原版服务器.JAR，这些通常可以在Mojang的版本公告博客文章中找到。
将两个.JAR放在同一目录中。在目录的命令窗口中运行命令：
java -Xmx[RAM amount, for example 2G] -jar fabric-loader-[version].jar [minecraft server JAR] [arguments…]
然后服务器就可以运行起来了。
