__前言      
       没什么想说的，就想吐槽一下各种带木牌GUI啊铁砧GUI的登录插件老贵老贵这个事情。顺便再说一下ProtocolLib的GPLv2协议是魔改过的可以兼容GPLv3这件事，虽然允许了但是这东西貌似还是违反了Bukkit的协议吧允悲。
       本插件需要AuthMe本体以及ProtocolLib作为前置插件使用，测试环境为1.10.2但是理论上1.9+通用，本插件将会在一段时间内持续更新。
       1.8的别试了，等下一个版本 手动允悲

__配置
      
  1. #以下是自动生成的配置文件，这里将额外增加一些注释
  2. #是否输出调试信息，布尔变量（true/false），建议为false
  3. Debug: false
  4. #使用铁砧（anvil）或木牌（sign）进行登录
  5. WindowType: anvil
  6. #木牌登录时，玩家输入的密码所在的行数，默认为3
  7. SignLoginLine: 3
  8. #对界面文本进行处理的脚本语言，ScriptEngine所支持的语言均可填入，默认为js
  9. #脚本变量列表:
  10. #    - line
  11. ## line变量为当前处理的文本
  12. #   - player
  13. ## player变量为玩家的Java对象
  14. #   - plugin
  15. ## plugin变量为插件主类的Java对象
  16. ##脚本最后一次操作的结果将作为显示在界面上的文本，所以建议在最后一行对line变量进行赋值，例如在JavaScript中使用line="something"
  17. ScriptEngine: js
  18. #脚本文件的路径，默认为config.yml同目录下的script.js，文件不存在不会影响插件的运行
  19. ScriptPath: C:\path\to\server\plugins\AuthMeGUI\script.js
  20. #玩家已注册时的状态替换字符串，默认为“登录”
  21. RegisteredStatueMessage: 登录
  22. #玩家未注册时的状态替换字符串，默认为“注册”
  23. UnregisteredStatueMessage: 注册
  24. #玩家状态替换变量，在稍后的界面文本设置中填写此变量，将会被替换为上方两条配置中的一个
  25. StatueVariable: '%statue%'
  26. #玩家名称替换变量，在稍后的界面文本设置中填写此变量，将会被替换为玩家的用户名
  27. PlayerVariable: '%player%'
  28. #玩家自定义名替换变量，在稍后的界面文本设置中填写此变量，将会被替换为玩家的自定义名
  29. PlayerCustomVariable: '%player_custom%'
  30. #玩家显示名替换变量，在稍后的界面文本设置中填写此变量，将会被替换为玩家的显示名
  31. PlayerDisplayVariable: '%player_display%'
  32. #玩家IP替换变量，在稍后的界面文本设置中填写此变量，将会被替换为玩家的IP地址
  33. PlayerIpVariable: '%player_ip%'
  34. #玩家等级替换变量，在稍后的界面文本设置中填写此变量，将会被替换为玩家的等级
  35. PlayerLevelVariable: '%player_level%'
  36. #服务器IP替换变量，在稍后的界面文本设置中填写此变量，将会被替换为服务器的IP地址
  37. ServerIpVariable: '%server_ip%'
  38. #铁砧登录时界面上显示的文本，第一行为显示的物品的名字，之后为该物品的lore，可以使用上述的替换变量
  39. AnvilInfo:
  40. - 输入密码%statue%§k
  41. - 完成后点击头像即可登录
  42. #木牌登录时界面上显示的文本，最多填写四行，可以使用上述的替换变量
  43. SignInfo:
  44. - '%player%'
  45. - 请在下一行输入密码
  46. - §k
  47. - 点击完成进行%statue%
