标题: Linux 怎么进入mc服务器后台？？？
我自己买了一个腾讯云服务器，然后自己搭了一个mc服务器在上边，当时是 执行开服的时候 是在mc服务器后台的，然后我关闭了我连接腾讯云服务器的工具，再重新连接上，进入的是腾讯云的命令窗口，我现在想到我mc服务器后台窗口 给我自己op怎么办？
作者: bgfjhf    时间: 2019-11-20 11:40
centos7？ yum install screen；screen -S mc；在里面cd到游戏目录运行启动脚本就可以了，以后输入screen -rx mc即可回到游戏运行界面
作者: Zapic    时间: 2019-11-20 12:21
如果不会用Linux,建议使用Windows.
一般连接到Linux服务器使用的是SSH而不是用他给的工具.
SSH客户端一般Win10自带,或者使用XShell或者Putty.
这个说起来有一大堆门路,但是看起来楼主貌似分不清TTY和SSH,还是建议使用简单易用的Win.

如果执意要用Linux也不是不行.
使用SSH连接到服务器后,安装一个Screen,安装方法具体参考你的发行版.
然后在Screen里运行MC服务端,以免断开SSH后服务端被终止.
