-----------特殊功能部分-------------



1. 本插件支持mysql，并且可以在本地（yml）与数据库之间热切换
你可以在后台通过指令切换数据存储方式

2. 本插件支持vault插件。
你可以在保留其他经济插件的同时享用UltiKits套件，不过请勿删除本经济插件！

-----------插件命令详解-------------



1. 基础功能

        指令                                     功能                      权限                      说明

/money                               查看金币                    玩家               

/bank                                  查看存款                    玩家               

            /ck [数额]                            存入金币                    玩家     数额不低于1000

/qk [数额]                            取出金币                    玩家               

             /ultipay [玩家] [数额]             给别的玩家转账          玩家       对方可以不在线

             /givemoney [玩家] [数额]       给某玩家金币             后台       只可以后台执行

             /takemoney [玩家] [数额]       没收某玩家金币          后台       只可以后台执行



             /mvdb [toLocal/toDataBase]   移动数据至yml/mysql  后台       只可以后台执行

         （移动数据库时建议开启白名单阻止玩家进入，不然谁知道会发生什么）

-----------配置文件详解-------------



#设置true为使用mysql数据库，设置false为使用yml储存数据

enableDataBase: false

注意：如果你只是想要单纯的将数据移动到数据库/yml，那么请在后台使用指令更改

这里直接改的话数据是不会同步过去的，这样也有另一个用处，你可以持有双份数据，当作备份？


# 填写你的Host, 默认为Localhost

host: localhost

# 填写你的Mysql端口, 默认为3306

port: 3306

# 填写你的用户名，默认为root

username: root

# 填写你的密码

password: root

# 填写你需要连接的数据库

database: minecraft


'是否开启银行利息'
enableInterest: true

#利率单位为万分之，只可以是整数！

interestRate: 3

#每隔多长时间发一次利息 单位（秒）

interestTime: 1800

'是否开启自动版本检查' 强烈推荐打开！
enable_version_check: false

  • %ue_bank%  玩家存款数量
