 [ruby=控制台垃圾信息过多的解决方案]Console Spam Fix 1.8.5[/ruby]

特点与功能
  • 该插件完美运行于bukkit（水桶端）/spigot（水龙头端）/paper端，同时支持KCauldron
  • 能够隐藏含有指定文字的信息，不让其出现在控制台和日志文件内
  • 配置文件一目了然，打开就会
  • 可以使用/csf reload来重新读取配置文件
  • 几乎不会损失服务器性能
  • 没有任何前置插件


食用说明
  • 把下载好的jar文件塞进plugins文件夹里面
  • 重启服务器。如果plugins文件夹里面出现了consolespamfix文件夹，说明启动成功
  • 修改consolespamfix文件夹内的config文件
  • /csf reload，出现成功的提示，说明安装与配置工作完成


权限与指令
  • csf.admin - 允许玩家使用本插件的指令。OP默认拥有这个权限（控制台也有）
  • /csf reload - 需要csf.admin权限 - 重新载入配置文件


注意！
  • 该插件并不会隐藏除了堆栈跟踪以外的报错/警告，只会隐藏一般的信息（即白字，和除了堆栈跟踪以外的warn黄字警告/error红字报错这两类日志）


配置文件（部分翻译）
  1. #所有含有关键字/句的信息都将不会出现在控制台和日志文件里
  2. #每行对应一个关键字/句，多个关键词/句请分多行输入
  3. #注意：不必将需要屏蔽的句子整句输入
  4. #插件会屏蔽所有含有关键词的控制台信息
  5. # 举个例子:
  6. #
  7. # Messages-To-Hide-Filter:
  8. # - 'WARNING: unlocalizedName'
  9. #
  10. # 所有含有WARNING: unlocalizedName的信息都不会出现在控制台和日志文件里
  11. # 不必将想屏蔽的信息整句打上去，但是输入的部分越多，插件就能过滤得越准确

  13. Messages-To-Hide-Filter:
  14. - 'WARNING: unlocalizedName'
  15. - 'moved wrongly'
  16. - '以此类推，注意单引号是英文的单引号'

  18. #支持颜色和格式代码
  19. #Minecraft颜色和格式代码参考: [url=http://minecraft.gamepedia.com/Formatting_codes]http://minecraft.gamepedia.com/Formatting_codes[/url]
