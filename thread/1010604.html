作者: qazsedc15987    时间: 2020-4-7 17:31
用记事本写：
@echo off&setlocal enabledelayedexpansion       
set a=-1
:ok
set /a a+=1
title [名字] 重启次数:%a%
set /a s=2
for /l %%i in (1,1,!s!) do (
set /a s-=1
ping -n %s% 127.1>nul
echo 开服倒计时开始！ !s!)
echo 服务器开始运行！
'java路径' -Xmx9G -Xms3G -jar 核心名字.jar
goto ok
pause
保存，后缀名改成.bat，运行就好了
