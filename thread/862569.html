聊天栏输入：
1、kill @a[distance=..10,name=!自己的名字]
杀死以自己为中心10格以内不是自己名字的玩家

或者
2、kill @a[distance=2..10]
杀死以自己为中心的2格以外，10格以内的玩家

再或者麻烦一点：
3、tag @s add foo
kill @a[distance=..10,tag=!foo]
tag @s remove foo
1、先给自己加一个 tag ：foo
2、杀死以自己为中心10格以内，tag 不是 foo 的玩家
3、移除 tag ：foo
