Boop

Boop是一款聊天类型的插件，作用就是@玩家，在提到某玩家时他会自动变颜色，并且对方会受到提示声以及标题，并且可以@全体。所有的显示方式以及颜色都可以自定义。

配置文件：
  1. version = 6
  2. prefix = "@"
  3. name {
  4.     recolor = true
  5.     color = "aqua"
  6.     color-all = true
  7.     alt-color = "aqua"
  8. }
  9. title {
  10.     use = true
  11.     text = {text = "有人@你！", color = yellow}
  12. }
  13. message {
  14.     recolor = false
  15.     color = "green"
  16. }
  17. sound {
  18.     play = true
  19.     sound = "entity.experience_orb.pickup"
  20. }
  21. groups = [
  22.     "全体"
  23. ]
  24. restricted = [
  25.     "全体"
  26. ]
  27. aliases {
  28.     "069a79f4-44e9-4726-a5be-fca90e38aaf5" = ["God"]
  29. }
  30. blacklisted-channels = [
  31.     "io.github.nucleuspowered.nucleus.api.chat.NucleusChatChannel$StaffChat"
  32. ]
复制代码

权限：
boop.group.staff
允许AT所有人

命令：
/sponge plugins reload Boop
