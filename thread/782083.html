前言：在整合服务端的时候突发奇想写一个万用bat启动脚本吧，然后一写就是几百行，索性作为独立软件发出来拉倒

小喵服主助手

MeowCat Minecraft Server Helper

先上开服成功的截图吧
Libigot1.5.2
Craftbukkit1.12.2
Spigot1.12.2
WaterFall1.8.x-1.12.x
以上所用服务端均来自http://www.mcbbs.net/thread-782055-1-1.html

以上测试配置均未添加启动参数，使用PATH环境变量中的java

程序特点
1.支持所有jar服务端
2.支持将jar直接拖入bat启动服务器
3.当未指定服务端jar时自动寻找目录下的jar文件


未开发功能

3.服务器常用配置文件修改

程序配置
运行一次程序后，会自动生成配置文件config.bat，照着里面的注释修改，已经介绍的很清楚了
  1. rem ==========================================
  2. rem MeowCat Minecraft Server Runner Config
  3. rem @author MeowCat Studio MlgmXyysd
  4. rem @time 2018/2/14
  5. rem @lastupdate 2018/2/17
  6. rem Copyright (C) 2014-2018 MeowCat Studio
  7. rem Powered by MlgmXyysd All Rights Reserved.
  8. rem ==========================================
  9. rem 程序版本识别，不要尝试修改！！！
  10. rem Program version,Do NOT modify
  11. set configver=4
  12. rem 程序显示语言（zh_CN，en_US），填别的默认中文zh_CN，区分大小写，这并不会改变log语言
  13. rem Display language(zh_CN, en_US),default Chinese zh_CN,case sensitive,does not change the log language
  14. rem example: set lang=zh-hans
  15. set lang=zh_CN
  16. rem jar服务端文件的完整地址，请在开头和结尾加上双引号(")，留空不启用自动运行选项
  17. rem jar server file complete address, please add " at the beginning and end, blank to disable auto run option
  18. rem example: set jarpath="D:\Server\MinecraftServer.jar"
  19. set jarpath=
  20. rem java启动参数，留空不附加启动参数，非专业建议百度，请勿乱写！！！！！！！
  21. rem Java launch argument, blank to no additional launch argument
  22. rem example: set argument=-Xms1024M -Xmx1024M
  23. set argument=
  24. rem java.exe程序完整地址，请在开头和结尾加上双引号(")，留空使用PATH中的java路径
  25. rem java.exe program complete address, please add " at the beginning and end, blank to use default in the environment variable PATH
  26. rem example: set javapath="C:\Program Files\Java\jre\bin\java.exe"
  27. set javapath=
  28. rem 自动重启服务器开关，填写true将自动重启服务器，填别的不使用自动重启功能
  29. rem Auto restart the server, type true will auto restart the server when the server stopped,type the other to disable auto restart
  30. rem example: set restart=true
  31. set reboot=false
