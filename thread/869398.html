Minecraft Java 版 1.14.2


Today we're releasing 1.14.2, a release that addresses a few issues left from 1.14.1. We wanted to release these fixes as soon as possible as they had a big impact to gameplay, but we do also have a bunch of less critical bugfixes releasing soon in an upcoming 1.14.3 - stay tuned!
今天我们发布了 1.14.2，它解决了 1.14.1 中剩下的一些问题。我们希望尽快发布这些修复内容，因为它们对游戏有很大的影响，但我们也有一些不太重要的修复内容将在 1.14.3 中发布，请继续关注！

CHANGES IN 1.14.2
1.14.2的更改

  • All light will now be re-calculated the first time you open a world saved in a pervious ve
  • 当你第一次打开旧版本存档的时候所有的光照都会被重新计算
  • Errors encountered while loading regions now print more diagnostics to the log file
  • 现在加载存档时若遇到错误会向日志文件中输出更多诊断信息
  • Fixed so parrots can spawn on grass blocks and not only on
  • 鹦鹉现可在草方块上生成
  • Added server-side chunk count to debug screen
  • 在调试界面中加入了Server Chunk Cache项目
  • Modified raider spawning so they can only ever spawn in fully loaded chunks
  • Raider现只能在强加载区块生成（待考证）
    Raider在英文wiki中被重定向至掠夺者页面，详见该页面；而突袭(Raid)中的怪物也可称为"Raider"。则此翻译存在歧义，尚待进一步考证。（引用自Pre1发布页面：http://www.mcbbs.net/thread-866088-1-1.html）
  • Increased search radius for bell when starting a raid from 48 to 64 blocks
  • 袭击中鸣钟的高亮范围从48格增加至64格
  • Fixed bugs
  • Bug修复

正式版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。Java版的启动器下载地址在上文已经提供。
对于非正版用户
非正版用户也请使用启动器下载游戏，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
