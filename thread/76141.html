什么是 ItemScript (IS)
ItemScript 是一种 基于 JavaScript 语法的脚本语言。
所以如果您想编写 ItemScriptPlugin 您需要先学会 JavaScript ！
什么是 ItemScriptPlugin (ISP)
ItemScriptPlugin 是一种 由 别的引擎载入、运行、处理的 CraftBukkit 插件。
什么是 ItemScriptPluginEngine (ISPE)
ItemScriptPluginEngine 是一个 ItemScriptPlugin 的加载、运行、处理引擎。
可以加载、运行、处理 ItemScriptPlugin ！


如何能让 CraftBukkit 使用 ItemScriptPlugin？
您只需要下载 ItemScriptPluginEngine 然后放进服务端的 plugins 文件夹中即可，无需任何配置！
(注：运行一次后才会出现 itemPlugins 文件夹~)


如何安装 ItemScriptPlugin？
如果您正确的安装了 ItemScriptPluginEngine 那么我相信您的服务端目录下一定会多出一个 itemPlugins 目录~
然后把 ItemScriptPlugin 放入 itemPlugins 然后按照原作者的要求即可完成安装！


如何编写 ItemScriptPlugin 插件？
这个您不用担心，我为此准备了一个 说明文档 也就是类似教程的东西，如果您会 JavaScript，那么您学起来一定很轻松~
不过如果您不会，那么我推荐您先去学习一下 JavaScript，再来学习这个~
