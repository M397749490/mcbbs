核心战争(也叫"群雄争霸")是一款基于PvP模式的游戏，一共有四个队伍，分别是红、蓝、黄和绿。你的队伍的目标是保护好自己队伍和核心并摧毁其它三个队伍的核心，你可以在地图上随意的挖掘资源、建筑等，你可以在 阶段1 和 阶段2 加入一个队伍里面，超过了 阶段2 就无法继续加入了，当你的队伍摧毁了其它队伍的核心后，你的队伍将获得最后的胜利。(内容来自此处)
核心战争曾是个受欢迎的小游戏(在花*庭、地**空、像**光等服仍然存在)。

为什么进行二搬？
原因1：由于原贴在2016年时发布，距离今年2019年已经有3年之久(中途也没见有改动)，

原因2：由于1.5.5版已经在GitHub发布，这也导致一些服主们认为停止更新了。

原因3：该版本是新的开发者开发，并不是先前开发者开发。该版本增加了比老版本多20+的功能，原贴已经不适用该版本！

(特性)
  • 物品栏上的动作条
  • boss血量
  • 可备份(防止丢失)
  • 完全自定义的记分板
  • 强大的恢复地图系统
  • 反快速挖矿(作弊类型fastbreak、nuker)
  • 当游戏开始,开始第一阶段,其它团队核心被摧毁,游戏结束.
  • 可配置游戏图片
  • 队伍命令及控制
  • /MyXP Command.
  • /MyStats Command.
  • /GiveXP Command.
  • 酿造和武器商店
  • 私人箱子、私人酿造台和私人熔炉
  • 4个团队(红色,蓝色,绿色,黄色)及每个团队拥有的核心.
  • 地图中间的钻石(来自第3阶段[可配置]).
  • 方块可再生
  • 无法破坏的方块
  • 自定义Boss(凋灵、铁傀儡)
  • Boss商店(使用 '下界之星' 打开它)(当你杀死了一个Boss后,所有与你同个团队的玩家都将获得)
  • 自定义服务器MOTD(大厅中,阶段X)
  • 更多粒子效果(破坏核心、熔炉、游戏结束、玩家死亡)
  • 死亡和声音效果(这些效果由'效果'菜单中的“玩家”选择).
  • 经验,经济,属性管理系统
  • 团队,旁观者,职业,投票地图
  • 盔甲架与村民木工
  • 团队Sings.
  • 玩家重生.
  • 魔法信标(魔法基地药水商店)
  • 保护区域.
  • 高度自定义聊天.
  • 高达48个职业.

游戏包含5个阶段

阶段1：(准备期)
核心处于无敌状态，无法破坏.

阶段2：(攻击时期)
核心在这个阶段失去了无敌状态.

阶段3：(钻石阶段)
钻石会在地图中间产生。

阶段4：(BOSS阶段)
在地图特定区域产生BOSS.

阶段5：(防御和攻击阶段)
攻击核心的伤害将会提升为 -2

坚持到最后一个团队将取得胜利(判断机制:只剩下最后一个队伍的核心存活时)！

/Anni: 提供 核心战争 的命令.
/Anni Save [Map, Config, Lobby, BossMap,All]: 保存地图, 配置文件, BOSS地图, 所有.
/Anni Start: 开始本次游戏.
/Anni MapBuilder: 获取地图设置工具.

/Spectator exit: 退出旁观者模式.

/Team: 使用团队加入命令, 显示玩家列表或更改团队:
* 用法:
    加入团队: /Team [团队名称]. 例子:/Team Blue.
    需要显示玩家列表, 只需输入 /Team 查看.

/Area: 创建保护区域的命令.
* 用法: /Area[create, delete] [名称] [Allow PVP?] [Allow Damage?][Allow Hunger?].
    要允许使用 "true", 禁止使用 "false", 例子: /Area create Lobby false false false.

/Vote: 用于投票给地图.
* 用法: /Vote [地图名称].

/Kit: 使用命令打开玩家的职业菜单.
* 其它用法: [AnniKits,annikits, KitsAnni, kitsanni].

/EnderChest : 使用命令打开私人箱子.
* 其它用法: [ec, chest,enderchest, echest, enderc].

Anni XP 拓展命令:
/MyXP: 显示玩家XP.

/Shop: 打开职业商店.

/AnniXp: 给予玩家XP.
* 用法: /AnniXp give[玩家] [数量].

/GiveXp: 扣除你的XP给予其它玩家.

* 用法: /GiveXp [玩家] [数量].
