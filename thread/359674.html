作者更新了，搬过来了，1.3.1tails对应0.7.0foxlib，老版本删掉了
更新内容待补充（自带汉化）


游戏中的新体验
首先进入游戏，按esc，然后点击尾巴编辑器
有英文的地方，点击可以切换尾巴，耳朵和翅膀


翅膀分为金属和天使可以在材质里面更换


右边是调色面板，可以更改尾巴翅膀和耳朵的颜色

更新具体内容（所有）
增加了耳朵，天使翅膀和金属翅膀（统称翅膀）




与星系mod和其他mod兼容

更新ru_ru.lang（感谢nekoinemo！）

更新zh_cn.lang（感谢vikaleidoscope！）


Changelog:


Changelog:

  • Fix compatibility issue with Galacticraft and other mods that add their own player classes
  • Fix export so it now exports all parts data
  • Update ru_RU.lang (Thanks NekoiNemo!)
  • Update zh_CN.lang (Thanks ViKaleidoscope!)







安装方法：
把tails.jar 和foxlib.jar插件一起放到mod文件夹
如果不放foxlib，会自动下载，重启游戏即可
