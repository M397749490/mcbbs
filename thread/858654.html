预发布版是Minecraft的测试机制，如果该版本作为正式版发布，那么预发布版的游戏文件将与启动器推送的正式版完全相同。

然而，预发布版主要用于服主和Mod制作者的预先体验，如果发现致命漏洞，该预发布版会被新的预发布版代替。因此对于普通玩家建议持观望态度。

Minecraft 1.14 仍未发布，1.14 Pre-Release 5 为其第 5 个预发布版，第 37 个预览版。

转载本贴时须要注明原作者以及本帖地址。





Minecraft 1.14 Pre-Release 5
A Village & Pillage Java Pre-Release
一个村庄与掠夺更新的预发布版


Update: We're now on pre-release 5 and we expect this to be the last pre-release before the full release. We aim to release Village & Pillage for Minecraft: Java Edition on Tuesday, April 23rd.
更新：我们现在发布了 Pre-Release 5，我们预计这将是正式版发布之前的最后一个预发布版。我们的目标是在4月23日星期二发布村庄与掠夺更新的正式版。

CHANGES IN 1.14 PRE-RELEASE 5
1.14 Pre-Release 5 中的改动
  • Optimisations to nether portals, they will now keep the other side loaded for 15 seconds after an entity goes through
  • 下界传送门优化：当实体穿过它到达某一侧后，它会保持另一侧继续加载 15 秒
  • Fixed more lighting issues that were discovered since yesterday
  • 修复直到昨天为止发现了的更多的光照问题
  • Fixed a case where block entities weren't being ticked correctly
  • 修复实体方块不被正常处理（tick）的情况
  • Updated the game credits
  • 更新了游戏开发者名单



FIXED BUGS IN 1.14 PRE-RELEASE 5
1.14 Pre-Release 5 中的漏洞修复
  • MC-148580 - Server lighting still broken in 1.14 pre-4
  • MC-148580 - 在 1.14 pre-4 中，服务器光照仍然不正常

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要魔法上网。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
