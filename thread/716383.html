我的也是5.3.2,我自己新创了一个号打字,然后它会提示"你需要通过认证才能通过聊天".可能你的插件设置有问题.
你看看比如以下有没有正确设置.

# 在登录前允许玩家说话吗
        allowChat: false
# 在玩家登录前是否隐藏服务器消息
        hideChat: false
# 未登录玩家允许使用的命令
        allowCommands:
        - '/login'
        - '/register'
        - '/l'
        - '/reg'
        - '/email'
        - '/captcha'
# 允许未登录的玩家走动
        allowMovement: false
# 允许登录服务器的玩家名称
        allowedNicknameCharacters: '[a-zA-Z0-9_]*'
如果不行可以开启这个:
# 是否立即踢出没注册的玩家
        kickNonRegistered: false

总的问题就是,要不是插件的config设置错误,要不是插件出问题了(自身的问题或别的插件冲突).如果到最后还是不行就要再下个插件了（或者单独安装这个插件看看是不是冲突）.可以说说你的服务器版本,我可以帮你找下这个插件.
