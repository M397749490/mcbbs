服务端文件夹/plugins/Multiverse-Core/worlds.yml
#世界名
  【你需要改的世界名】:
    spawning:
      ==: MVSpawnSettings
#动物
      animals:
        ==: MVSpawnSubSettings
        spawn: 'false'
        spawnrate: '1'
        exceptions: []
#怪物
      monsters:
        ==: MVSpawnSubSettings
        spawn: 'false'
        spawnrate: '-1'
        exceptions: []


或者输入指令/mv modify set difficulty 0
