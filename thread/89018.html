注意：
由于本插件作者弃坑多年，自身bug无人维护修复，某些情况下会出错清空玩家账户资金，如果一定要用，请想办法定期备份账户资金资料，或启用mysql 更安全一些！

适用版本： 1.2.4~ 至今 （可能还会继续向上兼容） 可用于MCPC+

权限、指令、用法
  1.     iConomy.help:
  2.         介绍: 允许查看帮助信息
  3.         默认拥有权限者: op
  4.         指令: "/money help"
  5.     iConomy.holdings:
  6.         介绍: 查看资金
  7.         默认拥有权限者: op
  8.         指令: "/money"
  9.     iConomy.holdings.others:
  10.         介绍: 查看其它人资金
  11.         默认拥有权限者: op
  12.         指令: "/money <名字>"
  13.         例:
  14.           - "/money Nijikokun"
  15.     iConomy.top:
  16.         介绍: 查看资金排行榜
  17.         默认拥有权限者: op
  18.         指令: "/money top"
  19.     iConomy.payment:
  20.         介绍: 发送钱给其它人
  21.         默认拥有权限者: op
  22.         指令: "/money pay <名字> <数额>"
  23.         例:
  24.           - "/money pay Nijikokun 30"
  25.     iConomy.accounts.create:
  26.         介绍: 创建账户
  27.         默认拥有权限者: op
  28.         指令: "/money create <名字> [数额]"
  29.         例:
  30.           - "/money create Nijikokun"
  31.           - "/money create Nijikokun 30"
  32.     iConomy.accounts.remove:
  33.         介绍: 移除一个存在的账户
  34.         默认拥有权限者: op
  35.         指令: "/money remove <名字>"
  36.         例:
  37.           - "/money remove Nijikokun"
  38.     iConomy.accounts.give:
  39.         介绍: 给予他人一个指定的数额
  40.         默认拥有权限者: op
  41.         指令: "/money give <名字> <数额>"
  42.         例:
  43.           - "/money give Nijikokun 30"
  44.     iConomy.accounts.take:
  45.         介绍: 从他人账户中移除一定数额资金
  46.         默认拥有权限者: op
  47.         指令: "/money take <account-name> <amount>"
  48.         例:
  49.           - "/money take Nijikokun 30"
  50.     iConomy.accounts.set:
  51.         介绍: 给他人账户设定指定数额的资金
  52.         默认拥有权限者: op
  53.         指令: "/money set <名字> <数额>"
  54.         例:
  55.           - "/money set Nijikokun 30"
  56.     iConomy.accounts.status:
  57.         介绍: 查看账户状态 (可见, 隐藏, 其它)
  58.         默认拥有权限者: op
  59.         指令: "/money status <名字>"
  60.         例:
  61.           - "/money status Nijikokun"
  62.     iConomy.accounts.status.set:
  63.         介绍: 设置账户状态 (可见 (1), 隐藏 (0))
  64.         默认拥有权限者: op
  65.         指令: "/money status <名字>"
  66.         例:
  67.           - "/money status Nijikokun"
  68.     iConomy.accounts.purge:
  69.         介绍: 清空所有账户到初始值
  70.         默认拥有权限者: op
  71.         指令: "/money purge"
  72.     iConomy.accounts.empty:
  73.         介绍: 清空所有账户数据
  74.         默认拥有权限者: op
  75.         指令: "/money empty"
