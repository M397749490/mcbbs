CommandStudio
工具介绍
什么是 CommandStudio？
CommandStudio 是一款能让你写指令并以最简单的方式将它们导入到 Minecraft 中的工具。它可以让你的编写更简单。

它如何工作？
在 CommandStudio 中，你用代码来代替命令方块。你的代码每一行代表一个命令方块。例如你输入以下代码：
  1. say hello
  2. say world
  3. summon Zombie ~ ~1 ~

概念
CommandStudio 是为垂直向上的命令方块串设计的，所有的命令方块都会指向上。

方块模式
默认情况下，所有的命令方块都是链式命令方块(CCB)，不需要红石信号激活（实测都是uncond模式）。
你可以用类似于下面这段代码作为开头来改变命令方块的模式：
  1. r0:say ok
复制代码
这个命令方块会变成需要红石信号激活的RCB，你可以用以下字符来改变命令方块的模式：
字符 效果
i ICB
r RCB
c CCB
0 需要红石信号激活
1 不需要红石信号激活
? cond模式
! uncond模式
默认情况下，每个命令方块都是c1!，你可以用关键字 default 来改变：
  1. default r0
  2. say I'm a repeating command block that needs redstone to be active
  3. say Same as above

  5. default 1
  6. say I'm a repeating command block that doesn't need redstone to be active

命令方块串的位置
默认情况下，命令方块会生成于执行这段命令的命令方块的正上方。你可以用关键字 position 使命令方块串生成在固定的地方：
  1. position 150 50 40
  2. i0:say I'm a command block and I live at 150 50 40
  3. say I'm a command block and I live at 150 51 40

  5. position ~5 ~ ~
  6. i0:say I'm 5 blocks beside my summoner

  8. // 你可以像这样生成两个命令方块串

占多行的一条命令
默认情况下，每条命令会像Notepad++那样一直向右延伸。如果你想把一条非常长的命令显示在几行中，你可以在后面所有行中加一个空格，例如：
  1. execute @r ~ ~ ~
  2.   setblock minecraft:chest 0 replace
  3.   {Items:[{id:"minecraft:potato",Count:2}]}

变量
你可以用变量来储存数据并再次调用，所有的变量名前必须加"$"：
  1. $position = 1345 56 -257
  2. setblock $position stone

存储过程
这会让你重复使用一条或多条命令，你可以用关键字 def 来定义。名字前必须加上一个"^"：
  1. def ^inline_def( $y = ~ )
  2.   50 $y 70

  4. def ^multiple_lines( $e, $block )
  5.   execute $e ~ ~ ~ setblock ~ ~ ~ $block
  6.   kill $e

  8. i0:^multiple_lines( @e[type=Bat], tnt )
  9. tp @p ^inline_def( 37 )

转义
为了防止一些字符被理解错误，你可以在前面加上"\"：
  1. $var = cool
  2. say the $var\est
  3. say \$var

包含其他文件
你可以使用关键字 include 导入其他文件：

  2. def ^hello($what)
