一、做准备工作
使用方法：我们拿spigot1.11端做示范，打开记事本
输入：
@ECHO OFF
java -Xincgc -Xms1G -Xmx2G -XX:MaxPermSize=128M -jar spigot-1.11.jar

保存，并将.txt后缀改为.bat 有的电脑可能默认没有显示后缀，像这样选择就可以了

让服务器载入其他地图的方法：
因为我们整合的服务端带有多世界插件
所以服主可以把下载好的地图解压到服务端文件夹下
然后在游戏内输入
/mv import 地图名字
然后插件就开始读取地图文件
/mv tp 地图名字
就可以去到那个世界了
（注意：地图名字不能中文，后果自负）
