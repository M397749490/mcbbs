FRP反向代理
—— Fatedier Reverse Proxy 高性能反向代理服务器     

简介
这是一款由国人开发的反向代理服务器，也就是我们常说的映射软件。
这款软件由go语言编写，并且是开源的。
它带有一个独立的管理面板，可以轻松地查看目前的映射。
此映射软件经过本人测试，性能不错，对于并发连接处理很好。
因为这是免费开源的，您如果想要使用，首先您需要一台拥有公网地址的服务器。
配置不需要非常高，1核1G内存2M宽带的服务器足以带动50人的服务器。
很多主机商都非常便宜，这里就不举例了。
目前本人的服务器也在使用此映射，经过3个月的测试，非常稳定，大家可以放心使用。
官方中文文档地址：https://github.com/fatedier/frp/blob/master/README_zh.md

配置(服务端)
推荐使用NotePad++等专业编辑器编辑配置文件，否则可能会出现无法读取的问题！
服务端配置文件名：frps.ini

  1. # [common]是不可或缺的部分
  2. [common]
  3. #文字地址或主机名为IPv6必须封闭
  4. #在方括号内，如“[ 1 ]：：：80“，”[主持人]：IPv6协议”或“[ IPv6主机%区]：80”
  5. bind_addr = 0.0.0.0
  6. bind_port = 7000
  7. # UDP端口用于KCP协议，它可以同“bind_port”
  8. #如果不设置，KCP被禁用的纤维
  9. kcp_bind_port = 7000
  10. #如果你想支持虚拟主机，你必须听设置HTTP端口（可选）
  11. vhost_http_port = 80
  12. vhost_https_port = 443
  13. #如果你想配置或重新加载相关的仪表板，dashboard_port必须设置
  14. dashboard_port = 7500
  15. #仪表板用户和密码为基本认证保护，如果不设置，默认值是admin
  16. dashboard_user = admin
  17. dashboard_pwd = admin
  18. #仪表资产目录（仅用于调试模式）
  19. # assets_dir =。/静
  20. #控制台或日志文件路径/ frps.log一样真实。
  21. log_file =./ frps.log
  22. #跟踪、调试、信息、警告、错误
  23. log_level =信息
  24. log_max_days = 3
  25. #特权模式是唯一支持的模式，因为v0.10.0
  26. privilege_token = 12345678
  27. #心跳配置，不推荐修改默认值
  28. # heartbeat_timeout的默认值是90
  29. # heartbeat_timeout = 90
  30. #只允许你绑定端口的材料清单，如果你什么都没有，不会有任何限制
  31. privilege_allow_ports = 2000-3000300130034000-50000
  32. # pool_count每个代理将改变max_pool_count是否超过最大值
  33. max_pool_count = 5
  34. # authentication_timeout手段的超时时间（秒）时，将FRP材料
  35. #如果authentication_timeout为零，时间不验证，默认为900s
  36. authentication_timeout = 900
  37. #如果subdomain_host不是空的，你可以设置子域当类型的HTTP或HTTPS在材料的配置文件
  38. #当子域的测试，使用路由主机test.frps.com
  39. subdomain_host = frps.com
  40. #如果TCP流复用时，默认为true
  41. tcp_mux = true

配置文件(客户端)
客户端配置文件名：frpc.ini
  1. # [common] 是不可或缺的部分
  2. [common]
  3. # 文字地址或主机名为IPv6必须封闭
  4. # 在方括号内，如“[ 1 ]：：：80“，”[主持人]：IPv6协议”或“[ IPv6主机%区]：80”
  5. server_addr = 0.0.0.0
  6. server_port = 7000

  8. # 如果你想连接相关的HTTP代理，可以设置http_proxy这里或在全局环境变量
  9. # 它只能是当TCP协议
  10. # http_proxy = http://user:pwd@192.168.1.128:8080

  12. # 控制台或日志文件路径./frpc.log一样真实。
  13. log_file = ./frpc.log

  15. # trace, debug, info, warn, error
  16. log_level = info

  18. log_max_days = 3

  20. # 认证
  21. privilege_token = 12345678

  23. # 连接将被预先设定，默认值为零
  24. pool_count = 5

  26. # 如果TCP流复用时，默认的是真实的，它必须与服务器设置相同
  27. tcp_mux = true

  29. # 代理名称将改为 {user}.{proxy}
  30. user = your_name

  32. # 决定是否退出程序，当第一次登录失败，否则连续重登FRP
  33. # 默认 true
  34. login_fail_exit = true

  36. # 通信协议连接到服务器
  37. # 现在支持TCP和KCP，默认是TCP
  38. protocol = tcp

  40. # 代理的名字你想开始分'，'
  41. # 默认是空的，意味着所有的代理
  42. # start = ssh,dns

  44. # 心跳配置，不推荐修改默认值
  45. # heartbeat_interval的默认值是10，是90 heartbeat_timeout
  46. # heartbeat_interval = 30
  47. # heartbeat_timeout = 90

  49. # SSH代理名称相同服务器的配置
  50. # [common] 部分用户如果不是空的，它会变成 {user}.{proxy} 就像 your_name.ssh
  51. [ssh]
  52. # tcp | udp | http | https, 默认是TCP
  53. type = tcp
  54. local_ip = 127.0.0.1
  55. local_port = 22
  56. # true 或 false, 如果是true，服务器和客户端之间的信息将被加密，默认为false
  57. use_encryption = false
  58. # 如果为true，消息将被压缩
  59. use_compression = false
  60. # 绑定的服务器对外端口
  61. remote_port = 6001

  63. [dns]
  64. type = udp
  65. local_ip = 114.114.114.114
  66. local_port = 53
  67. remote_port = 6002
  68. use_encryption = false
  69. use_compression = false

  71. #解决您的域名[server_addr]所以你可以使用http://web01.yourdomain.com浏览web01和http://web02.yourdomain.com浏览web02
  72. [web01]
  73. type = http
  74. local_ip = 127.0.0.1
  75. local_port = 80
  76. use_encryption = false
  77. use_compression = true
  78. # HTTP用户名和密码是HTTP协议的安全认证
  79. # 如果没有设置，您可以访问这个custom_domains无认证
  80. http_user = admin
  81. http_pwd = admin
  82. # 如果服务端配置了subdomain_host，您将可以在此设置，然后通过 http://web01.frpc.com/ 访问此映射服务。
  83. subdomain = web01
  84. custom_domains = web02.yourdomain.com
  85. # HTTP类型是唯一有用的位置
  86. locations = /,/pic
  87. host_header_rewrite = example.com

  89. [web02]
  90. type = https
  91. local_ip = 127.0.0.1
  92. local_port = 8000
  93. use_encryption = false
  94. use_compression = false
  95. subdomain = web01
  96. custom_domains = web02.yourdomain.com

  98. [plugin_unix_domain_socket]
  99. type = tcp
  100. remote_port = 6003
  101. # 如果插件的定义，local_ip和local_port是无用的
  102. # 插件将处理得到的服务器联系
  103. plugin = unix_domain_socket
  104. # 参数设置前缀“plugin_”插件需要
  105. plugin_unix_path = /var/run/docker.sock

  107. [plugin_http_proxy]
  108. type = tcp
  109. remote_port = 6004
  110. plugin = http_proxy
  111. plugin_http_user = abc
  112. plugin_http_passwd = abc<font size="3">
  113. </font>

启动你的FRP服务端与客户端
启动服务端：
右键FRPS.exe，创建快捷方式，然后右键→属性
在最前面输入[cmd /c ]在目标后面加上[ -c frps.ini]
记得空格，括号不要加进去
看起来应该是这样：
  1. cmd /c "D:\frps\frps.exe" -c frps.ini
复制代码
然后点击 "应用"，"确定" ，然后运行这个快捷方式。

启动客户端：
与启动服务器的方法相同，只不过将步骤里的所有 frps 改为 frpc
