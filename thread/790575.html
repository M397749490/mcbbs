本人觉得功能强大到不能呼吸，但是去定制的话贵到不能呼吸。就发到这里给大家看看有没有人也想要这样的插件吧。
不止rpg，生存服用也会很有特点。
这是我臆想中的config.yml

  1. #这个臆想中的插件的用法是手持单个物品执行指令用使用lore实现大量指令的运行。
  2. #这个插件最初的想法是摘除宝石，但是突然觉得好像功能可以更强大。
  3. #用法大概是这样: 比如某个物品的第一条lore是"&a功能1: 获得金钱 &e10000"，
  4. #玩家手持物品输入/ilrc run 1，
  5. #系统执行命令/eco give 该玩家 10000。
  6. #并且更换该行lore为"&c已使用功能1:&7你的金钱已经获取。"
  7. #配置文件可以像下面这种。权限的话op拥有前四条，玩家默认有第五条。
  8. Help: #插件帮助
  9. - "&a&n     ItemLoreReplaceCommands     "
  10. - "&a/ilrc create <编号> <lore> 创建一个检测的lore。"
  11. - "&a/ilrc replace <编号> <lore> 更换编号中对应的lore。"
  12. - "&a/ilrc addcmd <编号> /<cmd> 为该条lore添加指令。"
  13. - "&a/ilrc reload 重载插件"
  14. - "&a/ilrc run <对应行> 运行手持物品某行描述的功能。"
  15. - "&a&n     ItemLoreReplaceCommands     "
  16. - "&b本插件由XXX提出，XXX编写。"
  17. cmdlore:
  18. 1:
  19.   oldlore:"&a功能1: 获得金钱 &e10000"
  20.   newlore:"&c已使用功能1:&7你的金钱已经获取。"
  21.   cmd: #更换lore后执行的指令，可以设置多条指令共同执行。
  22.    - '/eco give %player% 10000'
  23.    - '/xxx xxx'
  24.    msg: "&a第 &c%n% &a行描述的功能已经被使用。"
  25. null: #若检测的该行lore没有在配置中则发出提示语，并且不执行任何指令。
  26. - "&c没有该功能，请检查您输入的行数是否正确！"

如果有插件大佬能写出来，岂不美哉？上精品帖子有何难？
为了某些同学不能理解我解释一下
  1. item: 随便一个东西，比如纸
  2. 第一行lore: 获得金钱 10000
复制代码
手持这个东西输入/ilrc run 1(对应行也就是1)
然后系统就执行指令了/eco give 该玩家 10000
接着这个东西就变成了
  1. item: 随便一个东西，比如纸
  2. 第一行lore: 已使用功能1:你的金钱已经获取。
复制代码
它的配置应该是这样

  1. 1:
  2.   oldlore:"功能1: 获得金钱 10000"
  3.   newlore:"已使用功能1:你的金钱已经获取。"
  4.   cmd: #更换lore后执行的指令，可以设置多条指令共同执行。
  5.    - '/eco give %player% 10000'
  6.    msg: "&a第 &c%n% &a行描述的功能已经被使用。"
