Minecraft基岩版是指包括Minecraft手机版（Android、IOS）、Win10版（VR）、主机版（XboxOne、NS、PS4）在内，使用“基岩引擎”（C++语言）开发的Minecraft统一版本。

正式版是Minecraft基岩版经过一段时间的测试版测试之后得到的稳定版本，也是众多材质、Addon和官方领域服会逐渐跟进的版本。与此同时Google Play、Win10 Store等官方软件商店也会推送此次更新。


Our developers have been hard at work getting top issues addressed for this hotfix. Several of these were reported by players, so keep those reports coming at bugs.mojang.com! Even more fixes are already in the works for another update coming soon.
我们的开发人员致力于在此更新中解决首要问题。因为一些bug是由玩家汇报的，所以请保持在bugs.mojang.com上汇报漏洞！更多的漏洞修复已经包含在另一个即将推送的更新里。

This update is currently only available on Windows 10 but will be releasing to all other platforms soon. The update is still multiplayer compatible with devices running any version of 1.16.
此更新目前仅限Windows 10，其它平台将很快推送。此版本与1.16的多人联机兼容。

2020年7月8日：1.16.1更新（仅PS4）

Today we are releasing a hotfix for PlayStation 4 that will enable you to clear your sign in data when launching the game, which we hope will avoid the issue where the game is getting stuck on the loading screen and potentially crashing.
今天我们为PS4推送了一个版本，可以在游戏加载时清除你的登录信息，希望这能避免因为卡在加载界面而导致的崩溃问题。

  • Implemented a workaround button combination on startup to clear the player's download cache on PS4 (MCPE-84790)
  • 加入了一个组合按键，可以在游戏启动时清除玩家的下载缓存。

You may wish to try the following after the game has updated to version 1.16.1.03:
更新1.16.1.03后，你可能要执行以下操作：
  • 启动游戏
  • 当游戏加载界面出现时，按住以下组合键：
  • 长按 L1 + R1 + L2 + R2 + OPTIONS键 + 触摸板键，直到进入游戏主界面为止


2020年6月29日：1.16.1更新

Fixes:
bug修复：
  • Fixed several issues with Netherite items being lost in fire or lava (MCPE-70774, MCPE-79753, MCPE-84796)
  • 修复了下界合金锭在熔岩中丢失的问题
  • Recipe Select button prompt shows when hovering over a non-craftable recipe book item using controller (MCPE-79725)
  • 使用手柄和配方书中的不可制作物品交互时，会正常显示合成配方了
  • Recipe selected items put in the crafting input grid can now be hovered over with the controller to see their tooltip names
  • 用手柄放置在工作台网格中的物品，现在会将名称悬浮在上方以便查看物品名字了
  • Fixed a crash that could occur when playing an emote and suspending the game (MCPE-73325)
  • 修复了使用表情和暂停游戏时可能发生的崩溃问题
  • Fixed a crash that occurred on PlayStation 4 due to other players using custom skins
  • 修复了PS4上因其它玩家使用自定义皮肤而导致的崩溃问题
  • Emotes can no longer be equipped before unlocking them (MCPE-84810)
  • 解锁表情前不可以再使用了
  • Custom skins once again work properly on multiplayer (MCPE-48207)
  • 多人游戏中会正常显示自定义皮肤了
