ModpackHandler
FAQ:
Q:什么是ModpackHandler?
A:它提供了整合包制作者很需要的几个功能
  • 检查整合包更新
  • 检查资源文件是否完整
  • 检查系统是否支持
  • 修改游戏窗口标题
  • 添加玩家进入地图时显示的聊天框信息
都可以通过修改配置文件来实现

Q:这东西我都会写啊干嘛还发出来
A:这是混分你懂吗

使用方法:
上面讲到了 多功能 这里不提了
接下来的版本会添加更多功能 只是我没想到← ←

这3个功能的自定义通过修改Config文件(.minecraft/config/ModpackHandler.cfg 不存在则需要运行一次游戏)来实现
所以你先把mod放到mods文件夹里 运行一次游戏 期间的提示框随便按 反正也没效果
然后打开.minecraft/config/ModpackHandler.cfg文件 按照以下信息来一 一修改
← ←由于注释是英文的这里就把中文的注释写出来
  1. handler-settings {
  2.     # 是否开启Assets(资源文件)的检查模块 更改为false来关闭
  3.     B:"Enable Assets-Cheaker"=true

  5.     # 是否开启系统检查模块 更改为false来关闭
  6.     B:"Enable System-Cheaker"=true

  8.     # 是否开启版本更新检查模块 更改为false来关闭
  9.     B:"Enable Version-Cheaker"=true

  11.     # 资源文件不存在时提示的信息
  12.     S:invalid-assets=你的Assets(资源)文件不完整或不存在 将导致游戏中没有声音 没有中文 是否访问下载页面?

  14.     # 发现新版本整合包时提示的信息 %s代表获取到的新版本名 不要删了它
  15.     S:new-version-message=发现新版本整合包: %s  是否前往官网更新?

  17.     # 发现系统不支持时提示的信息 %s代表使用者的系统名称 不要删了它
  18.     S:unsupported-system-message=你的系统: %s 不被该整合包所支持
  19. }


  22. modpack-info {
  23.     # (NEW)整合包使用的资源导航文件 本Mod将会根据json来检查客户端的Assets是否完整(准确性99.99%)
  24.     # 以下的路径是 资源文件夹\indexes\ 的相对路径 以下即代表 assets\indexes\{MC版本}.json
  25.     # 一般不用修改 除非你要检查MC其他版本的资源导航文件
  26.     S:modpack-assets-name={MC版本}.json

  28.     # 整合包的资源文件下载链接 在判断使用者没有安装资源文件或资源文件不完整时会弹出该对话框
  29.     S:modpack-assets-website=http://example.com

  31.     # 整合包的名称 通常跟对话框的标题有关← ←
  32.     S:modpack-name=Example

  34.     # 整合包的版本 这很重要 如果你想实现检查更新就要好好填
  35.     S:modpack-version=1.0.0

  37.     # 检查更新功能最重要的部分:
  38.     # ModpackHandler会访问该网站读取其源码来作为获取到的新版本 然后与客户端的版本比较
  39.     # 因此你需要写一个php 内容为<?php echo "<版本号>"; ?> ←别忘了双引号 你也可以写一个txt 直接写入版本
  40.     # 但永远别忘了正确修改链接值
  41.     S:modpack-version-check-web-site=http://example.com

  43.     # 整合包的官网 用于显示有新版本更新的对话框后 玩家访问的网址 如果你没有 则填MCBBS的发布帖链接
  44.     S:modpack-web-site=http://example.com
  45. }

  47. modpack-requird {
  48.     # 整合包兼容的系统 如果使用者的系统不在其中将会被强制关闭客户端
  49.     # "<"和">"间每行一个系统名称
  50.     # 可以用$win来代替所有版本的windows系统 $linux代替linux $mac代替macox
  51.     S:requird-system-name <
  52.          $win
  53.          $linux
  54.          $mac
  55.      >
  56. }

  58. modpack-settings {
  59.     # 玩家每进入一次地图就会在聊天框中发送下列输入的字 可以写若干行 都会在游戏中显示出来
  60.     # 可以使用MC的颜色代码
  61.     S:messages-to-player <
  62.         §l§f[§3§lModpackHandler§l§f]§f 运行成功 _(:з」∠)_今天没吃药
  63.      >

  65.     # MC窗口的标题 可以写中文等字符 (缺陷:游戏刚启动时会显示原来的标题 直到加载到本Mod才会更改自定义标题)
  66.     S:minecraft-title={检测到的MC版本}

  68.     # 这个很重要 代表着你的整合包需要的资源文件夹地址 资源文件检查模块会根据这个地址来检查资源文件是否存在及完整
  69.     # 注意: 这个值是相对于.minecraft文件夹的相对地址 比如下面的就是代表".minecraft\assets"
  70.     S:modpack-assets-file=assets\
  71. }
