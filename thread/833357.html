             ItemEquivalent可以让玩家生存变得更方便，
             通过出售、购买物品方式进行物品间的等价交换
             指令功能齐全，方便管理员管理插件









https://www.bilibili.com/video/av67633548





指令作用权限
/ie显示插件信息无
/ie help显示帮助信息无
/ie reload重载配置文件itemequivalent.reload
/ie give <玩家>给予玩家转换桌itemequivalent.give
/ie value look查看手上物品价值itemequivalent.value.look
/ie value remove移除手上物品价值itemequivalent.value.remove
/ie value set <价值>设置手上物品价值itemequivalent.value.set
/ie coin look <玩家>查询玩家金钱itemequivalent.coin.look
/ie coin set <玩家> <数量>设置玩家金钱itemequivalent.coin.set
/ie coin give <玩家> <数量>给予玩家金钱itemequivalent.coin.give
/ie coin take <玩家> <数量>扣除玩家金钱itemequivalent.coin.take






按键 条件 作用
Shift+右键 点击背包物品 显示物品价值
Shift+左键 打开转化桌后点击物品 出售物品
Shift+右键 点击转化桌内物品 移除物品
Shift+左键 点击转化桌内物品 购买一组物品





变量 信息
%itemequivalent_coin% 玩家金钱数目
