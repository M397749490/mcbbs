介绍 · Introduction
末影人由于长得太高而经常被修脚大师打死，有了这款插件就不同了.
在头上有方块的玩家会被末影人强制传送

最新版只支持1.13+
兼容旧版本请下载1.1版的插件
指令 & 权限

/letp reload - 重载配置
/letp debug [on/off] -切换调试模式


lethals.endermentp.admin - 允许使用/letp 指令
lethals.endermentp.bypass - 末影人不会传送有这个权限的玩家



汉化配置 · Configuration
  1. # debug - 调试信息
  2. # threshold - 在玩家被传送前可攻击的次数
  3. #           - 必须大于 0
  4. # delay - threshold减少1的冷却 (单位为刻)
  5. #       - 必须大于 0
  6. # tpDistance - 玩家被传送的距离
  7. #            - 必须大于 0
  8. debug: false
  9. threshold: 1
  10. delay: 200
  11. tpDistance: 5.0
