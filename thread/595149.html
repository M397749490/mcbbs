作者: 照烧鸡腿饭    时间: 2016-6-25 12:37
有两种方法，通过基础插件的配置设定，通常不需要安装额外插件

1. 基础插件GroupManager设定世界权限
先看/plugins/groupmanager/config.yml，查看权限继承设定，如果没有继承可以跳过这一步
mirrors:
        # 多世界设置,世界列表中子世界将参照父世界的设置.
        # 第一个世界 'world' 是主世界名称
        # 子世界 'world_nether' 和 'world_the_end' 将会
        # 与父世界使用相同的玩家/用户组文件.
        # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
        # all_unnamed_worlds将会使用所有未定义的世界
        world:
          world_to_set:
          - users

这里world是被继承权限的世界（通常是主世界）world_to_set改成你要设定的世界名，设定好后这个世界就只继承world的users.yml了，注意要把取消继承的groups.yml的权限补回到要设定的世界

确认权限继承没有问题以后，修改/plugins/groupmanager/worlds/world_to_set/groups.yml，其中world_to_set就是要修改的世界名，如果你的服务器普通玩家组是Builder，那么把Builder组底下的build: true 改成build: false即可

2. 用residence领地插件自带的配置实现（不是自己的或者给了权限的）领地外不能建筑
修改/plugins/residence/config.yml，配置指定世界领地外默认为build: false
Flags:
        Global:
            ......（全局设置，此处省略）
        world_to_set:
            build: true
