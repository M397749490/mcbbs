Command Cooldown
这个插件允许服务器管理员对任何他们想要的命令设置冷却时间。

插件介绍

  • 任何命令的可定制冷却时间
  • 时/分/秒时间格式
  • config.yml中的可自定义消息
  • 允许您不必输入config.yml的命令
  • 列表命令显示所有带有冷却时间的命令
  • 为命令提供别名的选项。添加一个别名将使别名也计入冷却时间。
  • 通过分步演练，智能添加和删除命令。
  • bStats追踪
  • 自动更新检查器
  • 能够为带有参数的命令添加冷却时间。例如 /home

插件指令&权限
指令

  • /cc help - 查看插件所有命令
  • /cc list - 查看限制命令列表
  • /cc bypass - 开启&关闭跳过冷却
  • /cc add [cooldown] [command] [arg1] [arg2]... - 创建一个命令
  • /cc newalias [alias] [command] - 创建一个新的名称和冷却
  • /cc remove [command...] - 删除一个命令
权限
  • commandcooldown.* - 允许玩家访问所有指令（不可操作）
  • commandcooldown.admin - 允许玩家使用所有指令（可操作）

配置文件

请把此配置文件放入plugins/CommandCooldown文件夹
