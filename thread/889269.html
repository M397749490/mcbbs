SavageSkyblock —— 革新性终极空岛

简介
几乎囊括空岛的大部分内容，替代高版本的福音——任务自定义添加/空岛等级/空岛银行/计分板/地标设置/空岛生物群系/空岛价值

授权证明
暂无

效果图
待补

命令&权限
命令:
/isa只有op才可以用的说，/is才是玩家命令
  • /isa setspawn - 设置spawn点（即重生点、主城点）
  • /isa reload - 乌拉，重 载 插 件！
  • /isa delete <玩家> - 永久删除指定玩家的岛屿（真的很久！）
  • /is - 唔姆，打开岛屿面板～
  • /is help - 查看帮助，有什么不懂的就来问我吧～
  • /is spawn - 传送至主城～
  • /is home/go - 传送回岛屿（欢迎回家～）
  • /is invite <玩家> - 邀请指定基友到你的岛屿～
  • /is join|accept <玩家> - 申请加入指定基友的岛屿～
  • /is promote <玩家> - 升级指定玩家～
  • /is demote <玩家> - 降级指定玩家～
  • /is kick <玩家> - 将某个熊孩子踢出岛屿（擦盘子声
  • /is version - 查看插件版本～
  • /is worth - 查看玩家岛屿在排行榜上的位置～【你算老几呢？】
  • /is top - 打开排行榜GUI～
  • /is perms - 打开权限GUI～
  • /is create - 创建岛屿，开始你的岛屿生涯！
  • /is biome - 呼啦，设置生物群系～
  • /is delete - 删除岛屿……你确定要这样做吗？
  • /is warp <warpName> - 传送至地标！
  • /is warps - 打开地标GUI～
  • /is upgrades - 打开升级GUI～
  • /is sethome - 设置当前位置为家～
  • /is teleport <岛屿/玩家> - 传送到玩家的岛屿，和他一起嗨皮～
  • /is rules - 修改岛屿规则，你的岛屿你做主～

权限:
  • isa.admin - 管理员权限搞事情搞事情
  • skyblock.fly - 岛屿飞行权限，我要自由翱翔
  • skyblock.block.hopper.5 - 漏斗限制为5.
  • skyblock.block.spawner.5 - 刷怪笼限制为5.
  • skyblock.members.5 - 默认岛屿成员数量上限为5.
  • skyblock.protection.100 - 岛屿保护限制为100(?)
  • skyblock.resets.5 - 默认岛屿重置次数上限为5.

PAPI变量
  • %skyblock_island% 岛屿名称
  • %skyblock_is-bank% 岛屿银行金钱
  • %skyblock_is-top% 岛屿排名
  • %skyblock_is-worth% 岛屿价值
