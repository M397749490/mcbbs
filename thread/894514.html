作者
NightExpress

兼容版本
1.14-1.16

介绍 · Introduction
这款插件可以让你的玩家在菜单内轻松地购买、出售物品或权限、指令。
你只需在菜单内即可编辑商店及物品。

现已更新分为两个模块：管理员GUI商店、玩家箱子商店

最新版已不再支持1.13
特性
管理员GUI商店
管理员可以使用游戏内菜单编辑器来创建和编辑商店.

特性:
  • 使用简单! 可使用游戏内编辑器创建或编辑商店.
  • 100%可自定义! 你可以更改插件的一切!
  • 可自定义商店内操作的鼠标快捷键 (购买/出售/选取).
  • 支持使用Citizens的NPC来打开商店.
  • 点击/购买/出售时触发音效.
  • 交易记录.
商品:
  • 出售原版和自定义的物品.
  • 出售以玩家、管理员或控制台身份执行的指令.
  • 出售永久权限. [需要Vault]
  • 同一商店内的不同商品可同时进行交易.
  • 在商店菜单内可设置预览物品，可以与实际交易物不一致.
商品数量:
  • 可设置玩家单次交易的最小和最大商品数.
  • 可设置持续时间 (或永久出售),例如可设置为: 在1天内只能购买或出售1件该商品。
  • 可设置一次性购买或出售商品.
数量选取菜单:
  • 可通过可自定义的菜单来选取交易的商品数量.
  • 可固定原版物品的最大堆叠数 (如禁止堆叠武器)
  • 可设置每次交易每件物品数的下限和上限.
  • 可选取交易几组物品.
  • 可修改物品堆叠数 (比如+1, -1)
  • 购物狂欢 (也就是打折):
  • 可设置购物狂欢的激活时间和持续时间.
  • 可给不同的商店设置不同的购物狂欢时间或使用全局设置.
  • 可设置每天或每段时间的折·扣
  • 可给每种商品设置是否会被购物狂欢影响价格.
货币:
  • 每个商店都可以设置自定义的货币名!
  • 默认有3种类型的货币: 物品、经验值和Vault
  • 外部货币: MySQL-Tokens
  • 会在商店界面显示商店货币名和玩家的余额.
限制:
  • 商店可交易物品的类型和数量没有限制.
  • 可禁止玩家以特定的游戏模式打开商店.
  • 可在特定的世界禁用商店.
  • 每个商店可设置独立的使用权限.


玩家箱子商店


和QuickShop一样，可以让玩家用箱子创建自己的商店.
特性:
  • 使用方法简单! 在游戏内使用商店编辑器设置商店.
  • 可将商店设置为物品库存无限制的管理员商店.
货币:
  • 可在配置内设置全局模块货币. 目前只能使用Vault.
  • 可更改货币名和货币物品.
创建:
  • 可设置开店费用.
  • 可设置关店费用.
  • 可设置不同权限组的商店限制.
限制:
  • 可在特定世界禁用箱子商店.
  • 可禁止交易特定类型的物品.
  • 可见交易特定名称和lore的物品.
  • 可设置只能在WorldGuard 区域内开店.
  • 可设置只能在 PlotSquared 地皮内开店.
显示:
  • 可在自定义展示界面内显示商品!
  • 可使用商品占位符以特定的间隔动态显示标题!
GUI:
  • 显示你所拥有的商店的可自定义GUI, 你可以在这个GUI内传送或编辑商店.
  • 可更改商品及其价格或关店的编辑器GUI.
保护:
  • 防止被活塞推动.
  • 防爆.
  • 防熊.
  • 防盗.

拍卖行
需要Vault作为经济前置！
简易的指令和GUI
自定义指令缩写
Listing Announces!
拍卖行：
  • 在特定世界内禁用拍卖行
  • 在特定游戏模式禁用拍卖行
  • Broadcast when new listing is added.​
GUI：
  • 100%自定义GUI
  • Define slots for auction listings.
  • Add your own custom items to the GUI.
  • Modify any item slot, name, material, lore!
  • 支持PlaceholderAPI
Listings：
  • 设置价格上下限
  • 可设置拍卖税
  • Define max. amount of listings for each rank or make it unlimited!​
存储：
  • Define time in seconds before listing will expire.
  • Define time in seconds before expired listing is removed.
  • Define time in seconds before sale history is cleaned.​
物品：
  • 100%支持自定义物品
  • All item attributes are supported: model data, name, lore, enchants, tags, etc!
  • An ability to forbid items with certain names.
  • An ability to forbid items with certain lores.
指令 & 权限
管理员GUI商店
  • /shop open - 打开商店主页面
  • /shop open [商店名] - 打开指定的商店
  • /shop editor - 打开游戏内的编辑器
  • /shop reload - 重载GUI模块


玩家箱子商店
  • /chestshop create [购买价格] [出售价格] [admin<true/false>] - 在你看着的箱子处创建商店
  • /chestshop remove - 删除你看着的商店
  • /chestshop list - 列出你的所有商店
  • /chestshop reload - 重载这一模块
插件
  • /qshop reload - 完全重载插件

使用教程
菜单商店
如何 创建/编辑 商店:
1. 输入 /shop editor
2. 选择商店或点击 'Create new shop' 创建商店.
3. 按照插件引导编辑.
4. 新商店你需要在 config.yml 内编辑才能加到商店主菜单内
5. 完成!

如何为商店添加物品/按钮:
1. 打开商店 .yml 文件 (位于 /shops/ 文件夹)
2. 添加这部分内容:
  1. custom-items:
  2.   filler:
  3.     material: BLACK_STAINED_GLASS_PANE:0:1
  4.     name: ''
  5.     lore: []
  6.     skull-hash: ''
  7.     slots: 45,46,47,48,49,50,51,52,53
  8.   next-page:
  9.     material: LIME_STAINED_GLASS_PANE:0:1
  10.     name: '&a&lNEXT PAGE '
  11.     lore: []
  12.     skull-hash: ''
  13.     slots: '53'
  14.     type: NEXT
  15.   prev-page:
  16.     material: RED_STAINED_GLASS_PANE:0:1
  17.     name: '&c&l 上一页'
  18.     lore: []
  19.     skull-hash: ''
  20.     slots: '45'
  21.     type: BACK
  22.   return:
  23.     material: ORANGE_STAINED_GLASS_PANE:0:1
  24.     name: '&6&l返回主菜单'
  25.     lore: []
  26.     skull-hash: ''
  27.     slots: '49'
  28.     type: RETURN
  29.   balance:
  30.     material: GOLD_NUGGET:0:1
  31.     name: '&e&l金钱'
  32.     lore:
  33.     - '&e &7你的钱包里有: &e%balance%%currency%'
  34.     skull-hash: ''
  35.     slots: '48'
复制代码
3. 自由编辑物品
3.1 可用类型为:
  • RETURN - 返回到主菜单
  • NEXT - 下一页
  • BACK - 上一页
  • EXIT - 关闭菜单
  • NONE - 静态物品，点击不会有任何反应.

如何创建商店牌子:
1. 放置一个告示牌
2. 在告示牌的第一行输入: QShop
3. (可选) 在第二行输入商店id.
4. 完成!

如何绑定商店到NPC身上:
1. 打开商店文件 (yml).
2. 设置 'citizens.enabled' 为 'true'
3. 设置 'citizens.npc-id' 为NPC id.
4. 完成!

如何绑定主菜单到NPC身上:
1. 输入 /npc select [id] 选择一个NPC
2. 输入 /trait qshop
3. 完成!

出售指令:
控制台身份: '[CONSOLE] say Console [指令]'

OP身份: '[OP] broadcast OP [指令]'

玩家身份: 'me player command'

使用 %p 代表玩家名.

更新记录

3.5.0
配置变更
请备份并删除插件每个模块内的settings.yml 文件! 旧版的文件不兼容该版本!


菜单商店

重制商品数量:
  • 现在可以正确显示商品的最低出售价格和收购价格。
  • 现在可以正确显示出售全部商品的总价。
  • 现在你可以使商品只能购买一次！
  • 现在你可以设置最低交易数量，玩家无法购买少于该数值的商品。
  • 现在你可以设置最高交易数量, 玩家无法购买多于该数值的商品。
  • 除此之外，你还可以设置激活上述限制的时间，如一名玩家每1小时最多只能购买64个草方块，最少只能购买16个草方块。
  • 修复物品数量平衡器，现在会在商品数量超出交易数量范围外时阻止玩家购买多于一组的商品。
  • 修复价格数字格式。

重制购物狂欢:
  • Added per product option which defines if product price will be affected by Happy Hours or not (true by default).
  • 现在可以受到设置每个商店的购物狂欢时间。
  • 添加新的商店选项：是否使用全服的购物狂欢时间。
  • 可设置多个购物狂欢时间
  • 可设置为多天和多段时间.
  • 现在你可以在主菜单内禁用每个商店是否开启购物狂欢.
  • 防止收购价高于出售价.

编辑器:
  • - 优化数量管理器，现在你可以更容易地管理你的商品了！

  • [修复] 在商品lore处显示的出售全部商品的总价错误。
  • [修复] GUI模块的指令现在会直接打开主商店菜单而非帮助页面.


箱子商店

[新增] 可以让玩家在特定商店内搜索特定商品的搜索指令.
[新增] 可为正数和负数的价格设置不同的格式.
[新增] 不再需要HolographicDisplays/CMI来显示商店信息.

[修复] 管理员商店会影响店主的钱数的漏洞。
[修复] 可能修复了玩家视频不出现在商店列表菜单内的问题。
[修复] 一些在编辑器内出现的价格问题。
[修复] 性能优化。
