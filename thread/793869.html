命令书
CommandBooks
介绍
可以用书本来保存你写的命令，然后让玩家执行它，支持多行，可以用后台执行，可以设置使用的次数。

命令
  1. /cb - 显示有关CommandBooks插件的版本信息。（别名：cb，命令手册）
  2. /cb create [uses]- 从主手中的书中创建一个命令手册，并带有可选的最大使用次数
复制代码

注:如果你使用了griefprevention领地插件，有个银行/税收功能的/cb指令会冲突，则导致命令书的指令无法使用。
解决办法一：请使用/commandbooks:cb 来代替使用。
解决办法二：打开config/sponge/global.conf
定位到如下位置:
  1. commands {
  2.         # Command aliases will resolve conflicts when multiple plugins request a specific command,
  3.         # Correct syntax is <unqualified command>=<plugin name> e.g. "sethome=homeplugin"
  4.         aliases { }
复制代码
修改为如下样式:
  1. aliases {
  2.     cb=commandbooks
  3.     }
复制代码
即可正常使用。

权限
  1. commandbooks.use
  2. commandbooks.command.info
  3. commandbooks.command.create
复制代码
给玩家commandbooks.use即可。

创建一个命令书
想要创建一个命令书，只需打开一本正常的Minecraft手册，没错就是书与笔。并在其中添加你所希望的命令，然后签名。
命令可以是多行的，但新命令必须在新行开始。
在一行的最开头添加 $ 符号，这代表使用控制台来执行命令而不是玩家。
而想在命令中添加玩家的名字，使用[p]
例:
  1. $time set day
  2. $world tp world [p]
  3. home
复制代码
此项示例会让控制台设定默认的世界为白天，并且传送使用命令书的玩家到名为“world”的世界，在让玩家回到他的家(如果他有的话)

最后如果要成功创建一本命令书的话，要把你写好命令并且签过名的手册拿着主手中，然后输入/cb create 。
书的标题会在方括号里，这表示命令书成功创建了，这样创建的命令书是不限次数的使用。
而如果要限制使用次数的话应该在创建的时候输入/cb create [次数]。
