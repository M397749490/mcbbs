插件命令
  • /ychat reload - 重载插件

插件权限
  • yakochat.main - 重载插件权限
  • chatformat.<format-name> - 指定聊天格式
例如: chatformat.vip 这是vip组的聊天格式权限

可用变量
  1. PlaceholderAPI 可选变量
  2. %player% - 获取玩家的名字
  3. %player_displayname% - 获取玩家的显示名称
  4. %player_uuid% - 获取玩家的UUID
  5. %player_ping% - 获取玩家的ping
  6. %player_level% - 获取玩家所处世界名
  7. %player_can_fly% - 获取玩家是否能够飞
  8. %player_flying% - 玩家是否正在飞
  9. %player_health% - 获得玩家的生命值
  10. %player_max_health% - 获得玩家的最大生命值
  11. %player_saturation% - 玩家是否处于饱和状态
  12. %player_food% - 获得玩家的饱食度
  13. %player_gamemode% - 获取玩家的游戏模式
  14. %player_x% - 获取玩家的x坐标
  15. %player_y% - 获取玩家的y坐标
  16. %player_z% - 获取玩家的z坐标
  17. %player_direction% - 玩家的方向
  18. %player_exp% - 获得玩家经验值
  19. %player_exp_to_next% - 获得玩家下一个等级等级所需的经验
  20. %player_exp_level% - 获得玩家的等级
  21. %player_speed% - 获取玩家的当前速度
  22. %player_max_air% - 玩家最大的氧气值
  23. %player_remaining_air% - 玩家剩余氧气值
  24. %player_item_in_hand% - 获取玩家手持物品信息
  25. %server_online% - 获取当前在线玩家数
  26. %server_max_players% - 获取最大玩家数
  27. %server_motd% - 获取服务器motd
  28. %server_ram_used% - 获取已用内存
  29. %server_ram_free% - 获取可用内存
  30. %server_ram_total% - 获取总内存
  31. %server_ram_max% -获取最大内存
  32. %server_cores% - 获取可用处理器核心
  33. %server_tps% - 获取当前TPS
  34. %server_uptime% - 获取当前正常运行时间
  35. %time% - 获取当前时间
  36. LuckPerms 可用变量
  37. %luckperms_prefix% - 玩家前缀
  38. %luckperms_suffix% - 玩家后缀
复制代码

插件配置
  1. # YakoChat 配置文件
  2. # 格式列表
  3. formats:
  4. # 格式名称
  5.   default:
  6. # 优先级
  7.     priority: 10
  8. # 玩家前缀
  9.     prefix: '&7%luckperms_prefix%&r'
  10. # 名称颜色
  11.     name_color: '&8'
  12. # 显示名称
  13.     name: '%player_displayname%'
  14. # 玩家尾缀
  15.     suffix: '&7| '
  16. # 聊天颜色
  17.     chat_color: '&7'
  18. # 格式名称
  19.   staff:
  20. # 优先级
  21.     priority: 20
  22. # 玩家前缀
  23.     prefix: '&7%luckperms_prefix%&r'
  24. # 名称颜色
  25.     name_color: '&6'
  26. # 显示名称
  27.     name: '%player_displayname%'
  28. # 玩家尾缀
  29.     suffix: '&7| '
  30. # 聊天颜色
  31.     chat_color: '&f'
  32. # 聊天格式
  33. chat: '{prefix}{name_color}{name}{suffix}{chat_color}{message}'
