  2.     enabled: true
  3.     enchanted: true
  4.     material: INK_SACK:14
  5.     name: '&f[&b活动限定&r&f]&r &c&l过载芯片'
  6.     socket-display: '&c&l过载芯片 &f&l<'
  7.     lore:
  8.     - ''
  9.     - ' &f| &a物理伤害: %var_a%%'
  10.     - ' &f| &c物理防御: %var_b%%'

  14.     - ''
  15.     variables:
  16.       a: 6
  17.       b: -6
  18.     variables-per-lvl:
  19.       a: 0
  20.       b: 0
  21.     variables-types:
  22.       a: PHYSICAL_DAMAGE_TYPE
  23.       b: PHYSICAL_ARMOR_TYPE
  24.     variables-percentage:
  25.       a: true
  26.       b: true
  27.     min-level: 1
  28.     max-level: 1
  29.     min-success-rate: 25
  30.     max-success-rate: 100
  31.     item-types:
  32.     - '*ARMOR'
  33.     - '*WEAPON'
复制代码


这个宝石镶嵌到 武器 上的时候 护甲削减 不能正常生效，但是 伤害增加 能正常生效。
镶嵌到 护甲 上的时候 护甲削减 和 伤害增加 都能正常生效

另外，如果在 variables-types: 里面填写 加成词条(如PVE_DAMAGE，PVP_DAMAGE等) 时，该词条不能正常生效
