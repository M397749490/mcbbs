 不解释...

打开方式选记事本，然后敲入以下代码：
  1. public class HelloWorld {
  2.     public static void main(String[] args) {
  3.         System.out.print("Hello,world.");
  4.     }
  5. }
复制代码
现阶段，你不需要理解这里的每一行代码。只需要知道第1行声明了一个类，它的类名与文件名相同，虚拟机运行字节码时会找到这个和文件名相同的类名(这个类名就叫做主类)里的main函数(不可以打成Main或者MAIN,JAVA对大小写敏感)执行(在第2行声明)。
什么是类:

从作用上来分一共有三种类，本阶段你只需要知道两种(额，第3种是抽象类和接口)。
一种是相当于一个箱子(更科学的叫法是方法的集合)，里面有许多的一种类型的函数(就像out类里装的都是输出函数)。
一种相当于一个模具(额，难道要叫可以创建实例的类吗...)，这种类可以创建一个实例(对象)，类中含有有关这件东西的数据和方法(如human类里有age数据和eat()方法)

第3行main函数调用了System.out类(属于上述的第一种类)里的print函数，作用是向标准输出设备(控制台)输出你给的东西。

你还可以让print函数做算术:
  1. System.out.print(1+2+3+3*2);
复制代码
输出结果是12，JAVA也懂得运算优先级。你也可以给这个算式加上括号改变优先级，例：
  1. System.out.print((1+2+(3+3)*2)/5);
复制代码
输出为3，不管是第几层括号，都用的是圆括号。



实际上在JDK看来，你的代码是这样子的：
  1. public class HelloWorld {public static void main(String[] args){System.out.print("Hello,world.");}}
复制代码
JDK会忽略所有的回车和一些无意义的空格，许多童鞋不知道为什么代码的前面要有空格。
记住，代码是给人看的，没有这些缩进和回车，写出来的东西你自己也看不懂。它们的作用是增强代码的层次感(你一眼就可以看出来main函数是属于Helloworld类的)。如果你一定要写成机器式的单行风格的话，我建议的用记事本打开.class文件看看里面的东西有多恐怖...
