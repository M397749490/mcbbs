标题: 权限组问题

可是每次重启服务器后一部分玩家都会被移动至builder组
然而我就要开始手动移回去
请问是哪里出现了问题

          - users
          - groups
          world_the_end:
          - users
          - groups
        zy:
          - users
        plotworld:
          - users
         F1:
          - users
          all_unnamed_worlds:
          - users

作者: qq1440357514    时间: 2015-6-25 08:06
将世界里面的 groups 你想要一进去就变成那个权限组的那个权限组 后面的 default:false 改成 true
然后将 Builder权限组后的default:true改成false 确认其他权限组都改成false就留一个
