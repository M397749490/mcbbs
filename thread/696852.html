Change log for Patch 1.51 - June 7th 2017
1.51版本 更新日志 2017/6/7

  • Fix for MCCE 4743 - Crafting table or furnace crashes game (SD Mode)
  • 修复 MCCE 4743 - 合成台和熔炉使游戏崩溃（SD 模式）
  • Fix for MCCE 4736 - Cursor / crosshairs not aligning (SD Mode)
  • 修复MCCE 4736 - 指针/十字准星不对齐（SD模式）

Change log for Patch 1.51 - June 8th 2017

  • Fix for Chinese Traditional Text.
  • 修复繁体中文字符相关问题
