概率系统
如何在CrazyEnvoys中使用概率系统：

如果你打开了任何tier文件，就应该能识别和概率有关的三个配置，他们就是Spawn-Chance，Chance和Use-Chance

Spawn-Chance是特定的等级/天降宝箱类型在世界中生成的概率,无法将其关闭,如果想要他始终生成特定的等级,请将它设置为100

Chance是奖品给玩家的概率，从另一方面来说这个是可以关闭的,但是关闭了之后他会随机选择，下面会进行解释

Use-Chance如果开启这个选项,他会在每一个奖品文件中使用上面的概率设置,如果关闭，他会以1/n的概率从有可能的部分中随机选择一个奖品,其中n是Tier文件中的奖品数量


有关大量奖品的其他信息
如果你设置了多个奖品，并且将设置Bulk-Prizes.Toggle设为关闭和某个奖项的概率为100％，那他就没有机会再选出另外的奖项了，设置为开启，就能保证至少有一个选项被选中，而且还有机会获得更多的奖项

如果你想每次都给一个特定的奖品，和一个额外的随机奖品，请把chance机率设置为100,并在配置文件写下以下内容

Bulk-Prizes:
   Toggle: true
   Random: true
   MaxBulk: 2


检查所有奖品
1,循环查看奖品列表，检查每一个奖品
2,检查单个奖品是否达到被选中的成功概率
3,如果成功就将奖品放入获奖名单，如果失败就什么都不会发生
4,继续执行循环，重复步骤2和3，直至达到列表末尾



检查完所有的奖品之后
1,从上一步的物品列表中随机选择一个奖品（他不用担心这种状态下在crate文件中获得奖品的机会）
2,一旦选择了奖品，奖品就会给玩家

权限

显示所有疯狂天降宝箱命令。

显示天降宝箱开始或结束的时间

显示所有当前的箱子位置。

envoy.ignore
使天降宝箱发送给用户的消息静音
/envoy flare [amount] [player]
envoy.flare.give
给玩家一个能开启天降宝箱的信号弹
/envoy edit
envoy.edit
把玩家设置为编辑模式，让他们可以编辑掉落位置

envoy.start
启动天降宝箱事件。
/envoy stop
envoy.stop
停止当前的天降宝箱事件。

envoy.center
设置随机宝箱掉落的中心
需要envoy.bypass权限来使用所有的命令
使用flares你需要envoy.flare.use权限

物品:
说明：这个选项用来设置物品材质和部分物品数据
用途：
· Item:<物品>
· Item:<物品>:<耐久>
· Item:<物品>:<耐久>#<自定义模型数据>
· Item:<物品>#<自定义模型数据>
· Item:<皮甲，药剂>:<颜色>
· Item:<皮甲，药剂>:<红>,<绿>,<蓝>
· Item:<药水>:<药水效果>
例子：
Items:
  - 'Item:Golden_Apple'
  - 'Item:Diamond_Chestplate:50'
  - 'Item:Diamond_Chestplate:50#32'
  - 'Item:Diamond_Chestplate#32'
  - 'Item:Leather_Chestplate:Blue'
  - 'Item:Leather_Chestplate:0,0,255'
  - 'Item:Potion:Heal'

· Item:<MONSTER_EGG>:<生物名字>
例子：
Items:
  - 'Item:MONSTER_EGG:Creeper'

名字:
说明：此选项用于设置物品名称。
用法：
· Name:<物品的名字>
例子：

盾牌和旗帜
如何为盾牌和旗帜添加颜色和图案？

用法和信息

用法： <图案>:<颜色>
RGB： <图案>:<红>,<绿>,<蓝>
颜色：https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/DyeColor.html
图案：https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/block/banner/PatternType.html
*请注意，由于MC中的某些内部内容并不总是允许每种颜色工作，因此RGB选项可能并不总是有效。
展示物品
如果你想在盾牌和旗帜上添加颜色和图案,请这样展示物品:将物品设置为旗帜或者盾牌，然后使用名为Patterns:的选项并使用物品选项


例如:
    1:
      DisplayName: '&a&lFancy Shield'
      DisplayItem: 'SHIELD'
      Patterns:
        - 'HALF_HORIZONTAL:RED'
        - 'RHOMBUS_MIDDLE:BLACK'
        - 'STRIPE_TOP:RED'
        - 'STRIPE_BOTTOM:WHITE'
        - 'STRIPE_MIDDLE:BLACK'
        - 'CIRCLE_MIDDLE:WHITE'


物品选项
如果你希望给玩家一个标有颜色和图案的旗帜或者盾牌,那么它们的作用就类似于物品列表中的常规选项
例：
Items：
  - ' Item：Shield，HALF_HORIZONTAL：RED，RHOMBUS_MIDDLE：BLACK，STRIPE_TOP：RED，STRIPE_BOTTOM：WHITE，STRIPE_MIDDLE：BLACK，CIRCLE_MIDDLE：WHITE '

RGB示例：
这是用于如果您希望使用自定义颜色而不是Minecraft的预设颜色。
例：
  1:
      DisplayName: '&a&lFancy Shield'
      DisplayItem: 'SHIELD'
      Patterns:
        - 'HALF_HORIZONTAL:255,0,0'
Items:
  - 'Item:Shield, HALF_HORIZONTAL:255,0,0'
注：255,0,0是RGB中的红色
