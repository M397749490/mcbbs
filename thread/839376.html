大家好，我是某个可爱的新人（估计现在已经不能这么叫了）今天给大家带来：Mac系统的开服教程

相信有许多人用的是mac苹果系统，却头疼怎么在Mac系统上开服，因为整合包几乎全都是针对Windows系统的。

而且Mac上也没有什么好用的映射软件。所以今天我就给大家带来这个教程。本人第一次发教程，如有错误，敬请谅解。

——第一步——


在mcbbs或官网下载纯净版官方服务端，以在mcbbs下载为例




——第二步——

安装java命令行SDK（不是系统自带的）

进入网址：https://www.oracle.com/technetwork/java/javase/downloads/jdk11-downloads-5066655.html

下载完后，运行dmg映像里的安装包，完成java命令行SDK的安装

——第三步——

将你在第一步中下载的服务端jar文件移动到个人文件夹根目录下，方便操作。

然后打开终端，输入：

java -jar server.jar

但此时服务器是打不开的，因为没有同意elua

打开个人文件夹下的elua.txt

再次打开终端，输入：

java -jar server.jar

稍等片刻，如图：

再输入stop停止服务器

此时用文本编辑器打开个人文件夹下的server.properties

找到online-mode，将true改为false

——第四步——

在终端输入：

ifconfig

记住自己的内网IP地址

接着，进入路由器管理页面

这里以小米路由器为例


——最后一步——

再次在终端输入：


java -jar server.jar
先等待等待服务器开启
然后百度一下“ip”，查看你的外网ip

最后让小伙伴们在“添加服务器页面”输入你的服务器IP地址：

地址为：（你的外网IP地址）:（之前设置的外部端口）

然后，恭喜你，大功告成！
