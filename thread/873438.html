插件简介 Descriptions
Elytra Race允许你创建竞技场
在里面用鞘翅进行游戏（类似于Hypixel派对游戏内的坐鸡过圈的游戏）
同时还支持计分板中死亡、成功的信息解释
同时还内置游戏的粒子、跳板和传送板等系统。


特色 Features
Elytra Race有以下几点特色：
  • 独立的竞技场
  • 独特的游戏机制
  • 计分板系统
  • 粒子效果支持（需要EffectLib 5.1/Vault 该系统仅支持1.8-1.10）
  • 实时显示的木牌系统
  • 玩家的信息显示系统
  • 跳板/传送板
  • 死亡水（玩家触碰到水死亡）



关于设置竞技场 How to setup a minigame
1.首先需要安装好 EffectLib 和 Vault 以及本插件
2.建筑好地图，存放在一个独立的世界
3.输入/elytrarace setmainlobby来设置游戏结束后的传送点（也是所有游戏的主大厅）（在第二次创建时不用设置）
4.首先输入/elytrarace create <竞技场名称>来创建竞技场
5.再次输入/elytrarace setlobby <竞技场名称>来设置一个竞技场的大厅
6.随后输入/elytrarace setspawn <竞技场名称>来设置一个出生点（必须大于1,玩家会从这里传送进来）
7.在终点放一个岩浆块，玩家需要破坏才能赢。
可选：在紫珀块上放置一个石质压力板，然后再在另一个地方输入/elytrarace setteleportationpoint，当玩家踩踏到装置，会传送到指令设置的地方
可选：在粘液块上放置一个石质压力板，玩家踩到就能弹跳
7.设置牌子让玩家进入即可，牌子格式：【第一行：Elytrarace，第二行：竞技场名称】


指令 Commands
  • /elytrarace setmainlobby —— 设置主大厅
  • /elytrarace create <名称> —— 创建一个竞技场
  • /elytrarace delete <名称> —— 删除一个竞技场
  • /elytrarace list —— 列出所有竞技场
  • /elytrarace join <名称> —— 加入一个竞技场
  • /elytrarace lobby —— 离开竞技场
  • /elytrarace stop/start <竞技场> —— 快速结束/开始一个竞技场游戏
  • /elytrarace setteleportationpoint —— 设置传送点
  • /elytrarace help —— 列出指令



权限 Permissions
  • elytrarace.admin —— 管理员指令使用权限
  • elytrarace.sign —— 允许创建牌子
  • elytrarace.* —— 所有权限
  • elytrarace.help —— 允许使用/elytrarace help指令
