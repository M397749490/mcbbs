Outfits——服装插件

====================================

这款插件的特点：

1：他拥有一个GUI面板，让你快速操作

2：里面自带了一种货币来购买物品【名字为：coins】

3：也可以使用权限和命令



还有其他的玩法哟

====================================



/of help 查看帮助

命令                                权限                                用处：

/of gui 无权限 打开GUI面板
/of reload outfit.reload 重新加载插件
/of add ID 数量outfit.admin 为某个玩家增加XX货币
/of remove outfit.remove 删掉当前你在穿的服装
/of coins 无权限 查看自己的游戏币
/outfitvillager 布吉岛[大神指一下]




权限：


outfit.head.头颅名字[给玩家在面板的使用权限]
