插件简介
  • 很多人应该用过FeatureBoard
  • 但是这个插件是收费的 而且经常DNS ERROR
  • 然后我无聊就又写了一个MiaoBoard

MOD服请先按照此文章修复类库 并且用Java8以上版本运行 [点击查看]

使用方法
  • 必须需要PlaceholderAPI
  • 如果记分板不显示 请先看下面配置说明的提示
  • 下载地址: https://www.spigotmc.org/resources/placeholderapi.6245/
  • 输入下列命令 安装PAPI的扩展组件
  • papi ecloud download player
  • papi ecloud download vault
  • papi ecloud download server
  • papi ecloud download javascript
  • papi reload
  • 注意: 如果你的版本低于 1.7.10 PlaceholderAPI 可能定期产生报错 不会影响使用
  • 然后安装本插件 即可生效

记分板time选项使用技巧

当初设计这个的时候用来活动公告之类的

我还加了一个变量 %time_left_到期时间%
