作者: BenLi豪    时间: 2017-4-8 16:54
应该是Essentials插件 如果你知道不是那就是AuthMe 插件了
下面是Authme的登陆信息的配置
  1. # 是否需要在登录或者注册后显示欢迎消息(welcome.txt)？
  2.     # 你可以在 welcome.txt + 使用不同的颜色和一些替换符号 :
  3.     # {PLAYER} : 玩家名， {ONLINE} : 显示在线人数， {MAXPLAYERS} : 显示服务器最大人数，
  4.     # {IP} : 玩家IP， {LOGINS} : 登录的玩家数， {WORLD} : 玩家当前所在的世界名， {SERVER} : 服务器名
  5.     # {VERSION} : 当前服务器版本， {COUNTRY} : 玩家的国家
  6.     useWelcomeMessage: true
  7.     # 是向全服广播 welcome.txt 还是只对登录的玩家显示？ 设置为false将只对登录的玩家显示
  8.     broadcastWelcomeMessage: false
  9.     # 是否延迟加入游戏消息在玩家登录后才显示？
  10.     delayJoinMessage: true
  11.     # 是否移除加入游戏的消息？
  12.     removeJoinMessage: true
  13.     # 是否移除离开游戏的消息？
