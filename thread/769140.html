这个是我开龙珠服时遇到的问题，当时真的头疼了好久，逛了BBS也没有解决方法，用什么插件都不管用
后来还是决定靠自己解决算了，就去翻mod的配置文件最后终于被我发现了
教程如下：
进入服务器，打开/config文件夹，你会在里边看到这个配置文件jinryuujrmcore.cfg
把它下载到桌面然后用Notepad++打开，
然后在里边找到这一段：
# Server Sided! If 'false' then Explosion Griefingis on, If 'true' then its off. (may reduce lag if true)
B:"ExplosionGriefing Off"=false
把B:"ExplosionGriefing Off"=false 这里的false改成true就可以了
这一段的大概意思是如果假爆炸可用，如果真不可用（作者英语差，翻译原谅）
