在自动化真人秀中C位出道！


[1.16.5] Create 101 第二季

故事背景
欢迎来到大型偶像团体竞技养成真人秀 —— Create 101
0202年，还有什么比偶像真人秀更有趣、更有意义呢？当然没有。在这里，来自几十所技校的101位工程练习生，将由全民投票角逐出11人组成全新的偶像限定团体。究竟谁能用优雅的自动化设计惊艳全场，最后C位出道呢？
收集来自观众的票据，最终登上偶像宝座吧！注意不要在传送带上乱跑乱跳！

介绍
你是否已经厌倦了忙碌于这种整合包：在机器间扮演人形物品摆放机？
你应该试试Create 101 —— 你可以在这里专注于设计完美的生产线，并乐在其中。你将设计装置来解决自动化挑战，打造强力的附魔工具，建造9x9的机械合成台来制作最终物品，最后，用TNT炸掉它来获得随机的创造物品！

整合包特点
  • 轻量。目前共70个模组
  • 无任务，无剧情
  • 精心设计的线路，让玩家无需跑图，专注自动化
  • 和平模式可玩
  • 中后期无需挖矿
  • 所有物品配方经过精心规整，同一功能不会存在两种物品

主要模组
  • Create 机械动力
  • Mekanism 通用机械
  • Refined Storage 精致存储
  • Apotheosis 神化
  • Quark 夸克

游玩注意事项
  • 这个整合包并不是为新手设计的
  • 禁止利用游戏漏洞（刷物品、刷TNT、透视等等）
  • 多查询JEI。大多数矿物（除铁、石英、红石）都不自然生成，而是通过盆栽产出
  • 最终物品是“神秘三角”，请自行查询配方
  • 有部分配方需要先将一定数量的物品装入抽屉，然后将抽屉从侧面破坏。物品将保留其中
  • 死亡掉落可自行关闭
  • 一些方块免疫凋灵。在JEI中搜索“凋灵”可以看到。
  • 破坏丛林树叶会掉落可可豆。丛林树苗有合成方法
  • BoP世界类型不是很推荐，因为有可能找不到海带。必要时可以创造模式拿一个。

游玩流程（剧透警告）
依次自动化铁板、粘液球、烈焰粉、黄铜板、集成电路、玫瑰石英、光辉石、暗影金属、原子合金、下界之星。打造自己的附魔工具，用引雷三叉戟生成闪电。建造涡轮和核能发电机提供能量。用Portality完成跨维度物流。完成最终配方“神秘三角”。制作创造物品。
光辉石制作方法：将异彩化合物扔在光源旁（光源会被吞掉），或激活的信标上。
虚空金属制作方法：将异彩化合物扔进虚空。
