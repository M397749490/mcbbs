安装方法

只要解压就能玩

因为用的是BMCL启动器，启动后先输入名字，然后调整好 javaw 路径,游戏版本选择1.6.2-mod+光影+单击命令+optifineC4就能开始游戏啦！（小海 的mod全是放在1.6.2-mod+光影+单击命令+optifineC4里的，想玩没有mod的也可以选择其他的）

对了，要安装最新的 Java 与 .net Framework 4.0哦！





因为是小海 在SF_Chipan大神的懒人包的基础上加入了各种科技mod所做的，所以先附上原先懒人包的mod列表：

OptiFine_HD Ultra C4 高清修复

通用中文输入修正

NihongoMOD 汉语输入
