BookNews 5.2
服务器的更新通知书

此插件需要前置 PlaceholderAPI



插件特色Features
  • 易于阅读的配置文件
  • 高版本支持 ( 1.8+ )
  • 支持 颜色代码
  • 支持 占位符(变量)
  • 支持 点击/悬停文本


配置文件Config.yml

  2. #是否自动更新此插件
  3. check-update: true
  4. #前坠显示名称
  5. Prefix: '&e&l[BookNews] '
  6. #开启时延迟
  7. OpenBookDelaySecond: 5
  8. #开启时音效
  9. OpenBookSoundEffect:
  10.     enable: true
  11.     sound-effect: ENTITY_PLAYER_LEVELUP

  13. Open-Book-Onjoin:

  15.     enable: true
  16.     #if true，玩家加入服务器时打开书。
  17.     #if false，它只在（/booknews new）时为玩家打开书。
复制代码

注意：请在交互式单词占位符(变量) 后留一个空格！

指令&权限

/booknews reload: 重载插件
权限: booknews.admin.reload



/booknews news: 更新通知书内容
权限: booknews.admin.new



/news: 查看所有更新通知书内容
权限: booknews.news



权限: booknews.skip      有权限者将被跳过而不打开更新书
