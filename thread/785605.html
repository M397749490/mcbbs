标题: 我的世界1.8Citizens2——NPC插件（一款简单方便的NPC插件）


itizens2(公民2)是一款非常有趣的NPC插件，他可以给服务器带来故事背景，风格，是纯净服务器必备的选择！ 可以创建一个NPC，让它说话，让它走动，让他当守卫等等。 它也有很多扩展插件(扩展插件有时间我会说明)其功能很强大，可以让NPC自动打怪物或者把NPC当作BOSS来做副本 我就不多说了，请看指令&权限。




部分指令(更多指令请在游戏中查询)：

右键选择NPC后可进行一下操作
/citizens help           获得帮助。
/npc help           获得帮助。
/npc create       [名字] [说的话]
/npc remove     删除选中npc /npc                 查看选中NPC信息
/npc move        移动选中mpc到你身边
/npc rename     重命名选中npc /npc set [text]  设置选中npc的话
/npc add [text] 给选中npc再加话
/npc reset         删除选中npc说的话
/npc equip        编辑选中npc持有物（右键给NPC自己手上的装备，给完后再输一遍确认）
/npc tp             传送到选中npc那
/npc talkclose   设置选中npc在你接近说不说话
/npc lookat       设置选中npc在你接近转不转身看你
/npc setowner [player-name] 设置选中npc主人
/npc list (name) (page)     看自己或他人拥有的npc
