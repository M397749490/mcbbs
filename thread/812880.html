MineResetLite for 1.13
更好的矿区 1.13重制版
前言
依然是自己服务器需要重置的这款插件, 并使用了1.13新版API


*下面的内容均使用2693149792的帖子内容

指令区域
  1. /mrl list
  2. 权限: mineresetlite.mine.list
  3. 列出所有矿区
  4. /mrl p1 (-feet)
  5. 权限: mineresetlite.mine.create
  6. 设置矿区的点1为你站着的方块
  7. /mrl p2 (-feet)
  8. 权限: mineresetlite.mine.create
  9. 设置矿区的点1为你站着的方块
  10. /mrl create <矿区名>
  11. 权限: mineresetlite.mine.create
  12. 创建一个矿区（需要用创世神选择2个点也可以用上面的/mrl p1和p2的指令）
  13. /mrl info [矿区名]
  14. 权限: mineresetlite.mine.info
  15. 显示这个矿区的信息
  16. /mrl set <矿区名>  <(方块id)  <几率>%        例如/mrl set test 1 100%(设置矿区test的石头填充为100%)
  17. 权限: mineresetlite.mine.composition
  18. /mrl unset <矿区名>  <方块id>
  19. 权限: mineresetlite.mine.composition
  20. 移除一个矿区的某一个方块生成
  21. /mrl reset <矿区名> (-s)
  22. 权限: mineresetlite.mine.reset
  23. 重置矿区会在聊天栏显示重置ps：所有玩家都能看的到(/mrl reset 矿区名 -s)可以不显示聊天栏的信息
  24. /mrl flag <矿区名> <类型> <数值>
  25. 权限: mineresetlite.mine.flag
  26. 设置矿区的参数
  27. resetDelay: 重置分钟数（/mrl flag test resetDelay 1  设置1分钟test矿区的更新）
  28. resetWarnings:每分钟重置警告(/mrl flag test resetWarnings 1,2   在矿区刷新1分钟和2分钟内发出英文告示提醒玩家)
  29. fillMode:一般用在监狱风云数值用true和false？？？（不明）
  30. surface:（不明）
  31. silent:重置沉默（定时刷新后不会提示刷新矿区的聊天栏提示数值：true或者false）
  32. /mrl erase <矿区名>
  33. 权限: mineresetlite.mine.erase
  34. 删除矿区
  35. /mrl tp <矿区名>
  36. 权限: mineresetlite.mine.tp
  37. 传送到矿区重置时玩家设置的地方
  38. /mrl settp <矿区名>
  39. 权限: mineresetlite.mine.settp
  40. 设置矿区重置后在矿区里的玩家传送的地方
