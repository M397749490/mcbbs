修改配置config.yml参数即可获得你需要的功能
例如 想让使用 /kit tools 这个命令要1500元，可以这样设置

command-costs:
  kit-tools: 1500

原始配置代码：
  1. command-costs:
  2.   # /example costs $1000 PER USE
  3.   #example: 1000
  4.   # /kit tools costs $1500 PER USE
  5.   #kit-tools: 1500
