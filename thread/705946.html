auto-clear:
  task1:

    required-plots: -1
    confirmation: true
    days: 7
    worlds:
    - "*"
    # See: https://github.com/IntellectualS ... /wiki/Plot-analysis
    calibration:
      variety: 0
      variety-sd: 0
      changes: 0
      changes-sd: 1
      faces: 0
      faces-sd: 0
      data-sd: 0
      air: 0
      air-sd: 0
      data: 0


要启用地皮过时管理，把 'enabled' 改为true，然后设置过时的天数。如果玩家超过这个天数没有上线，地皮会被清除。
