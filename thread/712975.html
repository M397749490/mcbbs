TabooActivationCode 以下简称（TAC），是一款简单的兑换码插件。

类似的插件有 CashCode，CommandCode 等，但是这些插件都有一些多多少少的问题。

例如 CommandCode 没有查询功能，CashCode 不能本地储存，以及这个插件的自动更新竟然他妈的无法关闭！！！这并不是什么大问题，问题是他妈的更新网站空间过期了！！！每次开服都会刷出一段巨他妈长的报错。或者是卡很长时间。

所以我思考了很久，最后决定自己 TMD 写一个。

本插件及内容禁止任何人转载到任何地方


免责声明：

  • 本插件不是 CashCode 的重置插件。
  • 本插件没有任何一段代码来自 CashCode。
  • 本插件的所有代码均为独立开发，包括工具类！
  • 本插件的命令模块部分借鉴自 CashCode。

插件功能：

  • 支持 MYSQL 数据库储存
  • 支持 YAML 本地储存
  • 支持导入 CahsCode 数据
  • 支持检查兑换码的兑换记录
  • 支持检查玩家的兑换记录
  • 允许暂时关闭某项兑换码
  • 一键导出，无任何屁事
  • 多线程操作，绝不卡服
  • 所有玩家提示均可自定义
  • 彩蛋


插件命令：

  • /tac - 管理员主命令 [tac.admin]
  • /tac create [命令] [数量] [备注] - 生成激活码( "%n%" = 空格，"%d%" = 换行，"%p%" = 玩家 )
  • /tac checkuser [玩家] - 查看玩家的兑换次数
  • /tac checkcode [文本] - 查询兑换码的详细信息
  • /tac cleancode [模式] - 清理兑换码( "ALL" = 全部，"USE" = 已用，其他 = 指定备注 )
  • /tac importcode [备注] - 从 CashCode 中导入兑换码( "ALL" = 全部，其他 = 指定备注 )
  • /tac exportcode [备注] - 导出兑换码到文件中。
  • /tac togglecode [备注] [模式] - 更改兑换码的模式( "ENABLE" = 开启，"CLOSED" = 关闭 )
  • /tac reload - 重载插件配置，更新数据库需要重载插件。


  • /cash - 玩家主命令 [tac.use]
  • /cash - 打开兑换界面，该界面仅支持版本( 1_8_R3，1_9_R2，1_10_R1，1_11_R1，1_12_R1 )
  • /cash [文本] - 使用兑换码

什么？兑换码格式？TAC 的所有兑换码格式均为 4-4-4-4-4。
例如：0B42-3E4E-48D7-4A0F-8A59


插件帮助（插件安装）：

  • 放到服务端里重启服务器。
  • 如果你需要使用 MYSQL，则配置 MYSQL 的数据。
  • 如果你不需要 MYSQL，则需要将 "Settings.Myqsl.Enable" 项目改为 false
  • 调整完毕后再次重启服务器。
  • 注意！ 如果你的服务器为 1.8 以下( 含 1.8 )，且使用本地储存。
  • 因为编码问题请勿在备注或指令中写任何汉字！

插件帮助（生成兑换码）：

  • 首先确保插件已经安装成功，并且没有任何问题。
  • 比如你想要生成 100 条，命令为 /p give %p% 100 的兑换码。
  • 输入指令 "/tac create p%n%%p%%n%100 100 测试兑换码"
  • 绑定命令中，由 %n% 代替空格，%p% 代替玩家，%d% 换行。
  • 生成过程由异步进行，在这期间最好不要操作数据库，我不保证不会出现意外。
  • 生成过程可在控制台查看。
