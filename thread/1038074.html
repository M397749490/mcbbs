玩家移动的方式有多种（走 跑 蹲走 游泳）
与其用记分板判据不如之间检测前后游戏刻坐标的变化
创建几个记分板：
  1. scoreboard objectives add PosX_l dummy
  2. scoreboard objectives add PosY_l dummy
  3. scoreboard objectives add PosZ_l dummy
  4. scoreboard objectives add PosX dummy
  5. scoreboard objectives add PosY dummy
  6. scoreboard objectives add PosZ dummy
复制代码

高频执行以下命令：
  1. execute as @a run scoreboard players operation @s PosX_l = @s PosX
  2. execute as @a run scoreboard players operation @s PosY_l = @s PosY
  3. execute as @a run scoreboard players operation @s PosZ_l = @s PosZ
  4. execute as @a store result score @s PosX run data get entity @s Pos[0] 10
  5. execute as @a store result score @s PosY run data get entity @s Pos[1] 10
  6. execute as @a store result score @s PosZ run data get entity @s Pos[2] 10
  7. execute as @a run scoreboard players operation @s PosX_l -= @s PosX
  8. execute as @a run scoreboard players operation @s PosY_l -= @s PosY
  9. execute as @a run scoreboard players operation @s PosZ_l -= @s PosZ
  10. tag @a add move
  11. tag @a[scores={PosX_l=0,PosY_l=0,PosZ_l=0}] remove move
  12. execute as @e[tag=move] run say move
复制代码

玩家一旦移动就会输出“move”.
