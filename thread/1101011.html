不用数据包的话也有
先创建一个记分板
  1. /scoreboard objectives add value dummy
复制代码
然后在1tick内执行
  1. scoreboard players set #3 value 3
  2. summon area_effect_cloud ~ ~ ~ {Duration:1,Tags:["random_num"]}
  3. execute as @e[tag=random_num] store result score #output value run data get entity @s UUIDMost 0.0000000001
  4. scoreboard players operation #output value %= #3 value
  5. execute if score #output value matches 0 run give @a sponge
  6. execute if score #output value matches 1 run give @a clock
  7. execute if score #output value matches 2 run give @a potion
复制代码
前四步生成个药水云根据UUID得到一个随机数 后三步根据得到的随机数分别给海绵，钟或药水
