AsyncPlayerChatEvent事件，我想玩家说的话满足条件后执行player.chat("/" + cmds);虽然能执行但是会报错
请问有替代他的事件或者方法么？
答案（六楼也一样）:
Bukkit.getScheduler().scheduleSyncDelayedTask(Main.getInstance(), new Runnable() {
public void run() {
Bukkit.dispatchCommand(player, cmds);
}},  2L);
