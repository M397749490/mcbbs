很有趣的问题呢，其实之前我在写LambdaCraft的时候也试过~不过好像没人发现这个彩蛋233

比较简单的来说，旋转跳应该是把玩家的鼠标视线扭动和左右按键的移动结合起来判断，可以归结成如下的规则：

* 如果按下了W/S，不进行计算
* 否则，根据玩家按键方向和玩家视线转动方向综合计算速度改变的方向和大小。

去CS里简单的试了一下，D+右=右旋 D+左=左旋 A+左=左旋 A+右=右旋，大概可以写成两个标量相乘。
判断移动键是否按下，可以使用Minecraft类本身提供的keyBinding。判断视野转动方向，可以在每Tick计算玩家rotationPitch的改变量。

具体的实现思路就是侦听PlayerTickEvent，在客户端进行逐帧计算。

  1. // 侦听PlayerTickEvent

  3. EntityPlayer player = ...;

  5. float dYaw = player.rotationYaw - player.lastTickRotationYaw;
  6. int dirKeyboard = ((A按下?-1:0)+(D按下?1:0)) * (W或S按下?0:1);
  7. int dirLook = Math.signum(dYaw);
  8. int moveDir = dirKeyboard * dirLook;

  10. float velDirChange = dYaw * moveDir * X; // X为速度方向改变的敏感度系数
  11. float speedAddition = dYaw * moveDir * Y; // Y为速率增加敏感系数

复制代码

接下来就是三角函数换算了……分成两步：第一步把玩家的速度的yaw旋转角增加velDirChange再换算回去（要用到反三角和三角），第二步把玩家的视线方向拿出来，丢掉y分量，normalize，绕y轴旋转90度，然后乘以speedAddition。得到的这个矢量用来代表玩家获得的速度增加，直接把它加到当前速度上。

然后感觉主要问题就是调参数了……一切的手感都由参数决定w

EDIT: 看跳跃感觉或许还有沿视线正向或反向的少量速度增加？如果写出来感觉不科学的话可以试试加一下。
