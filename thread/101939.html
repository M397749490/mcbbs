标题: [管理|娱乐][汉化]Pacifism——和平主义[1.4.7-1.5.1]
这是一个倡导和平的插件(-_-#)

一段时间不杀戮，则可获得和平模式(输入命令)
成为和平主义者后如果猎杀怪物或玩家，则取消和平模式
和平主义者能在死亡后保留物品、装备和经验
和平主义者能够治疗自己
和平主义的等待时间和治疗的冷却时间可以配置
和平主义者死亡丢失的物品可以配置
治愈时可以有视觉特效和声音特效

命令：

  1. /pacifism - 成为和平主义者
  2. /heal - 医治自己(如果你是和平模式)
  3. /removepacifist [名称] - 移除一个玩家的和平模式, 不加参数则作用于全部玩家. (仅限OP)
  4. /pacifistinfo - 查看和平主义者死亡丢失什么
复制代码


权限：

  1. 无
复制代码


配置：

  1. # 治疗时烟雾特效.
  2. playeffect: true

  4. # 治疗时声音效果
  5. playsound: true

  7. # 治疗指令冷却时间--秒
  8. healcooldown: 20

  10. # 多少分钟能够获得和平模式
  11. timereq: 60

  13. # 杀戮玩家导致丢失和平模式
  14. playerkill: true

  16. # 杀戮怪物导致丢失和平模式
  17. mobkill: true

  19. # 和平模式死亡丢失物品
  20. loseitems: false

  22. # 和平模式死亡丢失装备
  23. losearmor: false

  25. # 和平模式死亡丢失经验
  26. losexp: false
