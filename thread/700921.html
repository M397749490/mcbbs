标题: 领地res select shift如何禁止
  服务器有玩家利用res select shift瞬移到很高的坐标，严重卡服，请问如何禁止该指令。
作者: wunan84    时间: 2017-6-26 23:45
你可以直接把res select禁了，让玩家用工具圈地就好
在配置文件内SelectCommandAccess: true改为false就行

不过也有弊端，那就是res  select size无法用了。
不过也不算大问题。
毕竟大多数都是工具圈地，也不影响游戏

还有种办法就是加其他插件，例如下面这款
[安全|管理]limitCommand —— 限制玩家使用某些命令[全版本]
