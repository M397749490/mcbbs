作者: 寂    时间: 2016-8-17 07:13
如果你的领地插件版本是2.x.x
在Config中找到groups节点，复制下groups.default节点下的所有内容，并粘贴到groups下，然后修改粘贴后的Deafault为你的权限组插件中的组名称：看起来应该是这样：
Groups:
    Default:
      xxxxx:
      .......
     OtherGroup:
      xxxxx:
      .......

其中的节点：
            MaxResidences: 3
           # 表示这个组每个玩家最大拥有的领地数量
           MaxAreasPerResidence: 2
           # 表示这个组的玩家允许在每个领地中创建的最大的子领地数量
           MaxEastWest: 16
           # 领地最大的横向长度（东西）
           MaxNorthSouth: 16
           # 领地最大的纵向长度（南北
           MaxUpDown: 256
           # 领地最大高度。
           MinHeight: 0
           # 领地下界允许的最小高度
           MaxHeight: 255
           # 领地上界允许的最大高度。
            Economy:下的 BuyCost: 0.05 表示一个方块的价格
红色字体表示你可能需要修改的。
