书本菜单是一款显著区别于目前主流背包菜单的插件，它可以高度自定义书本，赋予文字各种功能，
你可以为其添加指令、跳转菜单、跨服传送和网页url等功能，每一本书和其中的文字都可拥有着独立的权限，
插件支持json格式编写（其实主要就是用json格式编写）。
它也支持隐藏内容（拥有权限的人或达到变量要求才显示出内容）。

教程
首先，先来认识和熟悉JSON格式和基本操作。

JSON代表JavaScript对象编写规则
它是一种常用的数据存储和配置格式，类似于YAML。
通过将它们混合在一起，我们得到了具有颜色、样式和动作的多行文本的简洁明了的文本。

JSON语法的简短指南
  • Starts with `{` ends with `}`
  • Each value is key-pair, multiple values separated by comma
  • String value is "Surrounded by quotes"
  • Numbers and Bool value (true / false) are not surrounded by quotes.
  • Quotes around keys are optional, but recommended

然后要介绍的是来自2019年1月6号的一次更新，
这个更新里添加了一段文字多条指令的功能和console身份标记符号的特色
现在你可以赋予多条指令于一段文字内
原 command: "spawn", console: true
新 commands: "*spawn", "say Hello"
只需在命令前添加个*，即为以console身份执行指令
