GrassMobs 草地刷怪

完美实现上述功能



使用截图




(截图的时候生成几率调的太大了，所以各种被虐)



功能介绍

当玩家在草方块上移动时，有1/10000的几率生成怪物，并且会有提示(万分比可以自己配置)

同时支持开启或关闭某种怪物的生成，支持MythicMobs插件的怪物的生成

支持只使用MythicMobs中的怪物!

同时，本插件也拥有怪物清理功能，10分钟进行一次，每次进行时将每个区块内实体数量大于30怪物全部清除

(清理算法我自己想的，暂没有进行优化，目前不知道会不会对服务器造成卡顿，如果不信任可以在config中关闭)



配置文件
Worlds:
  - 'world:10'
#启用的世界:cent值
#例如world:10 就是world中的cent是10，未定义的世界不启用该功能
#cent为刷新几率 万分之几
actionbar: true
#是否使用ActionBar(1.8以下服务器请关闭)
msg: true
#刷怪时是否启用消息提醒
CleanMobs: true
#是否启用清理怪物

#建议下面怪物开的越少，cent的值调的越高
Mobs:
  CREEPER: true
  #苦力怕
  GHAST: true
  #恶魂
  MAGMACUBE: true
  #岩浆怪
  SILVERFISH: true
  #蠹虫
  SKELETON: true
  #骷髅
  SLIME: true
  #史莱姆
  WITCH: true
  #女巫
  ZOMBIE: true
  #僵尸
  GIANT: true
  #巨人
  BLAZE: true
  #烈焰人
MythicMobs:
  enable: true
  #是否启用MythicMobs
  only: false
  #只使用MythicMobs生成怪物功能，其它怪物全部关闭
  Mobs:
    - 'Example'
  #启用的MythicMob(在mm插件中配置好的)
