第二步-修改bat


java -server -Xmx4G -Xss512K -Xaggressive -Xalwaysclassgc -Xconmeter:dynamic -Xshareclasses -jar spigot-1.8.8.jar

全参数都加上 会让处理器占用提高 处理器比较渣的 看下面介绍去选择附加参数


参数注释

-server  

服务器运行模式，为持久运行优化



-Xmx4G   

服务端最大使用的运行内存 不可超过你总硬件运行内存


Xss512K

每个线程的堆栈大小，OpenJ9默认是1024KB，对于MC，512KB足够了



-Xaggressive
更激进的性能优化，OpenJ9的文档指出它会在未来版本作为默认选项



-Xalwaysclassgc

始终在全局垃圾回收期间执行动态类卸载检查，减少内存占用



--Xconmeter:dynamic

动态检测大对象区或小对象区域的使用情况





-Xshareclasses

OpenJ9的高速类共享功能，减少内存占用与启动时间，适合多个JVM运行相似代码的环境，或定期重启JVM的环境，对于群组服非常有用。



-jar spigot-1.8.8.jar

运行名为spigot-1.8.8.jar的核心文件

根据你服务端核心名做更改


以下是我大厅的bat完全配置


@echo OFF
@set a=0
:Menu
@title 大厅[127.0.0.1:25510]重启次数: [%a%]
@echo ===========================================================================================
@echo.
@echo                                         正在开启大厅服务器
@echo.
@echo ===========================================================================================
java -server -Xmx1G -Xss512K -Xaggressive -Xalwaysclassgc -Xconmeter:dynamic -Xshareclasses -jar spigot-1.8.8.jar
@echo ===========================================================================================
@echo.
@echo                                       大厅服务器将在10秒后重启
@Echo.   
@echo ===========================================================================================
@ping -n 10 127.0.0.1>nul
@set /a a=%a%+1
@goto Menu
pause
