PoorWorldGenerator
拥有生成一个资源极度匮乏的世界的程度的能力

特点
  • 生成沙漠化的世界
  • 少量木头
  • 极少矿物
  • 极少水源和岩浆湖
  • 陡峭的地形
  • 快速生成区块


使用方法
  • 1.下载插件并放到Plugins目录里面
  • 2.生成世界

    • 使用 Multiverse-Core 插件: /mv create <世界名> normal -g PoorWorldGenerator
    • 使用 MultiWorld 插件: /mw create <世界名> plugin:PoorWorldGenerator
    • 让主世界用此生成器:
    • 编辑 bukkit.yml
    • 在底部添加

    1. worlds:
    2. <主世界名称|一般是world>:
    3. generator: PoorWorldGenerator
