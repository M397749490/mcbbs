作者: God_SF    时间: 2019-1-20 14:26
右键编辑 启动服务器的 .bat
看到例如这样的文字
java -Xmx5G -Xmx5G
修改为 系统内存 减去 1.2G （右键计算机即可看见系统有多少内存）如果有5G 5120m内存那么减去1.2G 1200m 就为3920m
java -Xmx3920m -Xmx3920m
这样可以保证服务器内存能够稳定运行
