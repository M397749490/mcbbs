界面美化篇
我门来看看下面这个整合包的修改过的界面效果


界面的背景和按钮都很炫酷不是吗怎么做到的呢首先我们首先我们需要安装两个MODCustom Main Menu还有Resource Loader
还有一个可以制作标题的网页(会ps自行制做的话不要也行)
好了接下来我开始讲解
安装了这两个MOD后打开一次游戏后打开.Minecraft/config/CustomMainMenu/mainmenu.json(用notepad++打开)
相关代码

首先是修改背景

  1.     "自定义名称":
  2.     {
  3.                 "background":
  4.                 {
  5.                         "image" : "mainmenu:background.png",
  6.                         "mode" : "fill"
  7.                 }
  8.     }
复制代码

然后在.Minecraft/resources/mainmenu
加入你的背景图图片名称.png
texture是按钮材质的路径
代码中的mainmenu:图片名称.png中的mainmenu指的就是文件路径
重进游戏后就会发现背景换了，然后这样太麻烦了，我们可以加入刷新按钮等
代码如下
  1.         "自定义名称":
  2. {
  3. "text" : " ",
  4. "posX" : -20,
  5. "posY" : 0,
  6. "width" : 20,
  7. "height" : 20,
  8. "alignment" : "top_right",
  9. "tooltip": "xxxxxxxxxxxxxxxxxxxx",
  10. "texture" : "mainmenu:refresh.png",
  11. "action" :
  12. {
  13. "type" : "refresh"
  14. }
  15. }
复制代码


重进游戏这样就加入了一个刷新在右上角，有什么config更改点击一下这个按钮就能刷新，不用重建游戏了
text是按钮会显示的字，像这样输入：“卧槽”，就会在按钮上显示卧槽
alignment是按钮的方位，然后posX，posY是以前面设置的方位为中点，再进行移动
其他alignment所用到的方位还有center,top_left,top_middle,bottom_left,bottom_right,bottom_middle(待补充)
tooltip是鼠标移动过去后会弹出显示的文本，像上面的代码就是显示xxxxxxxxxxxxxxxxxxxx
width和height就是按钮的大小了
type就是按钮的类型refresh在这里是刷新的意思
其他的类型分别还有：openGui，openLink，quit(待补充)
如果是openGui，openLink这两种类型还需要像这样
  1. "action" :
  2.             {
  3.                 "type" : "openGui",
  4.                 "gui" : "界面类型"
  5.             }
复制代码
  1. "action" :
  2.             {
  3.                 "type" :"openLink",
  4.                 "link" : "网页地址"
  5.             }
复制代码
界面类型有singleplayer,multiplayer,options,languages（待补充）
更改标题
  1.     "自定义名称":
  2.     {
  3.                 "modpack":
  4.                 {
  5.             "image" : "mainmenu:标题图片名称.png",
  6.             "posX" : -125,
  7.             "posY" : -145,
  8.             "width" : 250,
  9.             "height" : 150,
  10.             "alignment" : "center"
  11.                 }
  12.     }
复制代码
当然也可以弄纯文本的非按钮
  1. "texts":
  2.     {
  3.         "mojang":
  4.         {
  5.             "text" : "\u7248\u6743Mojang AB",

  8.             "color" : -1,
  9.             "alignment" : "bottom_right"
  10.         }
  11. }
