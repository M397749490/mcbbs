这个的意思是世界被加锁了, 意思就是说你应该已经开了一个服务器了. 是不是之前开到后台去忘关了?
你可以重启服务器然后再开一次服务端试试
或者输入
ps -A | grep java
找到残留的 java 进程, 找到其 PID 然后
kill <pid>
