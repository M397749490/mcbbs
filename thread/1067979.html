改变你服务器玩家皮肤的一种方法

使用
  • 将一个玩家的皮肤设置为另一个玩家的皮肤：/ skin set <player> <player2>
  • 将玩家当前应用的皮肤保存到配置中：/ skin save <玩家> <名称>
  • 将玩家的皮肤设置为已保存的皮肤：/ skin set <玩家> <名称>
  • 将玩家的皮肤重置为默认设置：/ skin reset <player>
  • 删除保存的皮肤：/ skin remove <名称>
  • 设置默认皮肤：/ skin setdefault <名称>
  • 删除默认皮肤：/ skin cleardefault

组态
  • keep-skin-after-logout：[true / false]-使服务器在离开游戏后保留玩家的自定义皮肤，以便在重新加入后可以自动重新应用。
  • keep-skin-after-shutdown：[true / false]-使服务器关闭后，服务器保留玩家的自定义皮肤。
  • 默认皮肤：<皮肤名称> -一种皮肤，将应用于没有其他自定义皮肤的任何玩家。

权限
  • skinsetter.reload-允许您使用/ skin reload子命令
  • skinsetter.set-允许您对自己使用/ skin set子命令
  • skinsetter.set.other-允许您在其他子服务器上使用/ skin set子命令。
  • skinsetter.set.online-允许您将一个玩家的皮肤设置为另一个玩家的皮肤
  • skinsetter.set.saved-允许您将玩家的皮肤设置为已保存的皮肤
  • skinsetter.save-允许您对自己使用/ skin save子命令
  • skinsetter.save.other-允许您在其他子服务器上使用/ skin save子命令
  • skinsetter.save.overwrite-允许您使用/ skin save覆盖已经存在的皮肤
  • skinsetter.reset-允许您对自己使用/ skin reset子命令
  • skinsetter.remove-允许您使用/ skin remove子命令
  • skinsetter.setdefault-允许您使用/ skin setdefault子命令
  • skinsetter.cleardefault-允许您使用/ skin cleardefault子命令
  • skinsetter.skin。<名称> -允许您将玩家皮肤设置为名为<名称>的已保存皮肤

NPC支持

[size=14.6667px]在1.2.0版和更高版本中，您现在可以使用SkinSetter更改由玩家创建的Player NPC的皮肤。您可以使用在线选择的皮肤，基于用户名的皮肤，甚至可以使用已保存在配置中的皮肤。为此，只需使用 / npc select[size=14.6667px]选择一个NPC，然后运行 / skin setnpc <player> <skin>[size=14.6667px]。
