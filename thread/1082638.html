标题: 如何在数据包里禁用一个原版合成配方
如果我想在数据包里禁用一个原版的合成配方而不禁用原版数据包,我该怎么做?
作者: xmdhs    时间: 2020-7-20 20:01
自己新建一个数据包，使用相同的路径用相同的文件名覆盖原版的配方即可。

比如 data\minecraft\recipes\acacia_boat.json

作者: WYL0zhu    时间: 2020-7-20 22:12
改成
  1. {
  2.     "type":"minecraft:crafting_shaped",
  3.     "pattern":["#"],
  4.     "key":{"#":{"item":"minecraft:barrier"}},
  5.     "result":{"item":"minecraft:barrier","count":1}
  6. }
复制代码
即可。
