1.就是改音量，但既然你说会把自己放进去的也改没，那就是不行
2.不行，音乐间隔是写在里面的
3.这个方法可以有...把无声的ogg放进材质包内，并重命名为对应音乐的名字。

或者这样，把这个无声的ogg命名为mute.ogg然后放到材质包的下面这个位置
像这样...
assets/minecraft/sounds/mute.ogg

然后附件的txt，下载后手动把后缀命名为json，之后放置到以下这个位置
assets/minecraft/sounds.json

不想下载附件的自己新建个txt也可以，复制以下内容保存并修改后缀...
  1. {
  2.   "music.game": {"category": "music","sounds": [{"name": "mute","stream": false}]},
  3.   "music.game.creative": {"category": "music","sounds": [{"name": "mute","stream": false}]},
  4.   "music.game.end": {"category": "music","sounds": [{"name": "mute","stream": false}]},
  5.   "music.game.nether": {"category": "music","sounds": [{"name": "mute","stream": false}]}
  6. }
