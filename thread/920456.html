光环插件Guanghuan

给玩家添加权限(可自定义)
使其在游戏内获得一定范围(可自定义)的光环效果(自定义药水效果/时间/等级)
原本光环默认对自己与队友生效 但是在配置中可以配置是否对自己生效(因为有负面效果)

服主们可以利用这个插件给某些玩家添加负面效果！
例如除了自己，身边的人都会中毒！(天生毒体)
例如包括自己，身边的人都会获得治疗/防御/力量效果！(牧师)
例如包括自己，身边的人都会获得夜视/急迫效果！(吸血鬼？)
还可以自定义更多的组合效果……
目前每种光环只能配置一种效果，未来如果需要会修改为多种，但是你也可以添加多个光环来实现同样的效果。

权限：
gh.admin - 使用/gh reload的权限 默认OP拥有
不论添加了什么光环，OP都会自动拥有，本人暂时无能力解决



配置文件：

config:
  speed:
    per: 'gh.speed'
    range: 10
    effect: 'SPEED'
    time: 200
    level: 2
    me: true
  jump:
    per: 'gh.jump'
    range: 10
    effect: 'JUMP'
    time: 200
    level: 4
    me: true
  fire:
    per: 'gh.fire'
    range: 10
    effect: 'FIRE'
    time: 200
    level: 0
    me: true

#per = 权限
#range = 光环范围 实际生效范围为：X*Y*Z
#time = 时间 每20tick=1秒 例如填200=10秒
#level = 效果等级 0=1级 1=2级 以此类推
#me = 光环是否对自己生效 true / false
#effect = 效果如下 必须大写
#Fire着火无等级 但是也要填写数值
#添加新光环需要严格按照格式来，否则会报错或无法使用。

#SPEED 速度
#FAST_DIGGING 急迫
#SLOW_DIGGING 挖掘疲劳
#INCREASE_DAMAGE 力量
#HEAL 瞬间治疗
#HARM 瞬间伤害
#JUMP 跳跃提升
#CONFUSION 反胃
#REGENERATION 生命回复
#DAMAGE_RESISTANCE 抗性提升
#FIRE_RESISTANCE 防火
#WATER_BREATHING 水下呼吸
#INVISIBILITY 隐身
#BLINDNESS 失明
#NIGHT_VISION 夜视
#HUNGER 饥饿
#WEAKNESS 虚弱
#POISON 中毒
#WITHER 凋零
#HEALTH_BOOST 生命提升
#ABSORPTION 吸收
#SATURATION 缓慢
#FIRE 着火

使用教程：
光环配置成功后在游戏内输入/gh reload
然后为你的玩家添加你在config里设置的相应权限即可生效
你问我怎么添加权限？？
/manuaddp 玩家 权限
/mangaddp 用户组 权限
