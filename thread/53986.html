全物品



说明
装上mod你将具有的能力
  • 像鹰一样飞翔!
  • 炸飞一切（Blow shit up!）= =
  • 使靠近你的生物着火!
  • 跳得非常高!
  • 在水下呼吸和鱿鱼一起嬉戏!


BUGS
- 依然会受到火焰伤害

按键说明：

钢铁侠套装的使用（装备全套钢铁侠套装后按相应的键使用）:

z = 射出一只箭

x = 发出粒子特效 (在作者学会之前这个功能是无效的-。-)

c = 在你周围产生爆炸

v = 在你瞄准的地方产生火焰

b = 爆炸！

space = 飞

shift = 滑翔

更新日志：
v2：
1.添加了Jervis（不知道的去看电影去），它会随时提醒你的燃料和装备的消耗等级。
2.添加了燃料等级和武器启动延迟
3.在配置文件中添加了开关Jervis的选项
4.修复了看着天空会报错的bug（奇葩= =）
5.移除了弓箭 加入子弹（依旧没有自制声效）
6.Jervis只会在装备了头盔时的启动。
安装方法：
1下载安装forge
2.删除minecraft.jar内的MATA-INF文件夹
3.将压缩包放在mods文件夹里
4.开始游戏{:10_512:}

P.S.你可以在config文件夹里可以更改相关的id
