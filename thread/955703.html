删除完毕之后用这个开服bat    自行复制下面的到你的bat然后修改核心名字 内存  java 位置
  1. @echo off
  2. ::关闭回显
  3. set isre=0
  4. ::是否重启 0为关 , 1为开
  5. set retime=5
  6. ::设置重启等待时间
  7. set restart=0
  8. ::设置重启次数初始值，默认为0，请勿修改
  9. set maxre=-1
  10. ::重启多少次后不再重启,设置成-1关闭
  11. :start
  12. ::start节点

  14. CLS
  15. ::清除屏幕上内容

  17. set server_name=
  18. ::服务器名称，会在服务端的标题处显示
  19. set min_ram=2048
  20. ::最小内存，默认2048，单位MB
  21. set max_ram=8192
  22. ::最大内存，默认8192，单位MB
  23. set tm1=%time:~0,2%
  24. set tm2=%time:~3,2%
  25. set tm3=%time:~6,2%
  26. [url=home.php?mod=space&uid=219329]@Echo.[/url]
  27. echo  现在时间：%date% %tm1%点%TM2%分
  28. @echo. -----------------------------------------------------------------
  29. @echo.                         %server_name%服务器     

  31. @echo.           注意:关闭服务器前请在后台输入stop保存玩家数据
  32. @echo.                      否则可能会出现回档情况
  33. @echo.
  34. @echo.                      服务器正在启动中,请稍等……
  35. @echo.
  36. @echo. -----------------------------------------------------------------
  37. ::启动时的一些显示

  39. ::警告，如果你使用x86架构的Java(即32位)，最大内存不能超过1024MB
  40. set jar_name=XXXXX.jar
  41. ::设置服务端核心名称，默认路径为该批处理文件所在的根目录，需要写入文件后缀
  42. if %isre% == 0 (title %server_name%服务器 最大内存%max_ram%M) else (title %server_name%服务器 最大内存%max_ram%M 重启次数%restart%次)
  43. ::设置的服务端标题，调用上面的一些变量，可酌情修改

  45. java -server -Xincgc -Xmx%max_ram%M -Xms%min_ram%M -Xss512K -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseCMSCompactAtFullCollection -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=4 -XX:+UseConcMarkSweepGC -XX:CMSFullGCsBeforeCompaction=2 -XX:CMSInitiatingOccupancyFraction=70 -XX:-DisableExplicitGC -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar %jar_name%
  46. ::Java命令行开服代码，不推荐修改，已进行优化，32位Java运行可能会有些许问题，如有问题请替换为下方代码
  47. ::java -Xincgc -Xmx%max_ram%M -Xms%min_ram%M -Xss512K -XX:+AggressiveOpts -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=4 -XX:+UseConcMarkSweepGC -XX:CMSFullGCsBeforeCompaction=2 -XX:CMSInitiatingOccupancyFraction=70 -XX:-DisableExplicitGC -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar %jar_name%

  49. @echo. -----------===服务端关闭，即将在五秒内重启,按Ctrl+C终止重启===------------
  50. @echo.
  51. @echo.               %server_name% --- 玩家数据保存完毕 已关服
  52. @echo.
  53. @echo. -----------------------------------------------------------------

  55. set/a restart=restart+1

  57. if %isre% == 0 (goto stop) else (goto restart)
  58. :restart
  59. ::restart标签
  60. ::设置重启次数自加一，请勿修改
  61. timeout /t %retime% /NOBREAK
  62. if %restart% == %maxre% (goto stop) else (goto start)
  63. :stop
  64. if %isre% == 0 (echo 未开启自动重启，如果需要，请到bat中开启) else (echo 已经自动重启%maxre%次，停止自动重启，按任意键关闭)
  65. pause
复制代码
