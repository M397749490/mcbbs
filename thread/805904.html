关于2.7.0
AdditionsLegacy extension
A magical extension! Provides support for servers as old as 1.8.8
(possibly older, though untested). Just drop this in the extension folder
and QuestWorld should work fine.
Important
This is by no means official support for old server versions. It was created as
a test for the new adapter system that aimed to provide some compatibility
between 1.12.2 and future version 1.13.
PlaceholderAPI support
If installed, translatable text will fill in placeholders.
There is also a Papi extension that adds a placeholder comparison mission,
though it is in early beta.
