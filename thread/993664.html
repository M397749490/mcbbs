有一把弓，发射出一个箭。在半空中(箭落下的抛物线)会生成好几个箭，随后带粒子效果。好几个箭落在地上。求这个的数据包
Minecraft版本是1.15.2的

作者: MineCommander    时间: 2020-3-22 17:31
本帖最后由 MineCommander 于 2020-3-31 11:56 编辑

让一支射出的箭不停的在下方生成箭就完了：
  1. /execute as @e[type=arrow] at @s run summon arrow
复制代码

但是仅仅这样是不够的，因为新生成的箭还会继续生成更多的箭，更多的箭又会生成超多的箭...直到游戏崩溃。
所以我们要给生成出来的箭搞个标记，避免无限套娃。
  1. /execute as @e[type=arrow,tag=!spawned] at @s run summon arrow ~ ~ ~ {Tags:["spawned"]}
复制代码

大致意思就是，让没有标记的箭生成箭，并给生出来的箭加上标记。但有标记还不够，因为没带标记的箭落在地上的箭矢如果不及时清理的话还会继续生成箭....所以我们要加一个箭是否落在地上的判断：
  1. /execute as @e[type=arrow,tag=!spawned,nbt={inGround:0b}] at @s run summon arrow ~ ~ ~ {Tags:["spawned"]}
复制代码

最后需要粒子效果的话，直接再加一个particle就行了：
  1. /execute as @e[type=arrow,tag=!spawned] at @s run particle flame ~ ~ ~ 0.1 0.1 0.1 0 2
复制代码


最后总结，就这两条命令：
  1. /execute as @e[type=arrow,tag=!spawned,nbt={inGround:0b}] at @s run summon arrow ~ ~ ~ {Tags:["spawned"]}
  2. /execute as @e[type=arrow,tag=!spawned] at @s run particle flame ~ ~ ~ 0.1 0.1 0.1 0 2
复制代码

（塞进循环命令方块并开启即可。）
