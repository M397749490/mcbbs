先创造一个探测死亡次数叫die的计分板，还有一个叫time的计分板
  1. /scoreboard objectives add time dummy
复制代码
  1. /scoreboard objectives add die deathCount
复制代码

高频伺候
  1. /gamemode 3 @a[score_die_min=1]
复制代码
  1. /tp @a[score_die_min=1] x y z
复制代码
  1. /scoreboard players set time @a[score_time=0] 0
复制代码
  1. /scoreboard players set @a[score_time=0] die 0
复制代码
  1. /tp @a[score_time=0] x1 y1 z1
复制代码
