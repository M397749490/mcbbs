更新汉化v1.1
修复上个版本中一个玩坏了的class文件（虽然不影响正常使用）。

http://yunpan.cn/lk/87juquixve
汉化版：
http://yunpan.cn/lk/873cuhzfve
（为了便于识别，汉化版重命名为“MinecraftSP_cn.jar”）


快速使用帮助（新手向）
将以下代码写成.bat文件，保存在“MinecraftSP_cn.jar”同目录下，执行即可。（注：“MinecraftSP_cn.jar”无需解压）
  1. set APPDATA=.\
  2. java -jar MinecraftSP_cn.jar
