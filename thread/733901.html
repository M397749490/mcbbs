配置文件:

# NoSpawnChunks 插件配置文件介绍
# By 狐小夜

# 选择要自动卸载区块的地图. 如果选择 '*' 将自动卸载服务器内的所有地图.
# 如果你真的选择,它将卸载所有世界的区块.
worlds:
  - '*'
# 是否开启服务器区块自动卸载.
# 插件将每隔多少分钟回收一次服务器区块.
task:
  enabled: true
  interval: 15

# 服务器产生的 Java 垃圾回收机制(即自动清理Java垃圾模式)
# 是否开启 Java 垃圾自动清理机制,如果是请默认选择 task: true
# 是否卸载服务器运行所产生的垃圾
# 每当插件开启卸载区块的时候,是否同时开始清理.
garbageCollector:
  task: true
  unloading: false

# 是否保持服务器主城(出生点)的区块不加载
keepSpawnInMemory: false


命令和权限
/nsc查询插件版本
/nsc reload重新加载配置文件
/nsc unloadchunks立即卸载服务器区块
nospawnchunks.reload重置插件配置权限
nospawnchunks.unloadchunks卸载服务器区块权限
