作者: strawmaine    时间: 2012-9-19 21:16
1. 确保你电脑已经安装了java
2. 新建个服务器目录，把下载的craftbukkit-1.3.1-R2.0.jar放进去
3. 在服务器目录里新建一个txt文本（注意windows不要隐藏文件后缀），内容写为：
  1. @ECHO OFF
  2. SET BINDIR=%~dp0
  3. CD /D "%BINDIR%"
  4. Java -Xincgc -Xmx1G -jar craftbukkit-1.3.1-R2.0.jar
  5. PAUSE
复制代码
保存，txt文件重命名为“启动.bat”
4. 双击“启动.bat”来第一次启动服务器
5. 服务器启动后耐心等待，等到出现类似于
  1. Done (6.278s)! For help, type "help" or "?"
复制代码
这样的提示之后，输入stop并回车，之后服务器会关闭。
6. 用记事本打开服务器目录下新生成的server.properties文件，将里面改动为：online-mode=false 并保存退出
7. 以上为入门知识。
