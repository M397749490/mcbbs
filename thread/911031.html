作者: 叽叽小石头    时间: 2019-9-2 19:45
服务端\plugins\PlotSquared\config\worlds.yml
找到需要开启刷怪的世界
    event:
      spawn:
        egg: false
        breeding: false
        custom: true
    natural_mob_spawning: false
    mob_spawner_spawning: false
这些false全都改为true
