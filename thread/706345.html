作者: nsisogf    时间: 2017-7-14 19:00
根据
[WARN]: Exception in thread "Server console handler"
[WARN]: java.lang.OutOfMemoryError: Java heap space
[WARN]: Exception in thread "Thread-1"

可知在服务器运行Thread-1线程和“Server console handler”线程时抛出异常“ java.lang.OutOfMemoryError”
异常描述“Java heap space”
java.lang.OutOfMemoryError：内存溢出或没有可用的内存提供给垃圾回收器时，Java 虚拟机无法分配一个对象，这时抛出该异常。

综合错误描述可知原因是因为Java堆栈设置过小原因导致内存溢出
请结合Jre位数（x64，x32）在服务器启动脚本中的“-Xmx [内存大小]”设置合理的服务器运行内存。
