  2. items=276

问题应该出在配置文件上，指定了model路径之后就不需要再指定texture路径了，让模型文件来处理足矣，把配置文件内的texture=ceshi删除吧，只要你的贴图是放在你设置的路径中（下面代码摘自你模型代码内，ceshi贴图应放在assets/minecraft/texture/miaofu文件夹内），就应该不会出错了。
  1. "textures": {
  2.                 "0": "miaofu/ceshi",
  3.                 "particle": "miaofu/ceshi"
  4. }
