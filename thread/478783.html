[diamond_sword]服务端介绍
· PaperSpigot是一款基于Spigot服务端进一步优化修改而来的MineCraft原版服务端（Spigot大法好）,但相比Spigot服务端来说有着显著的性能提升（Tiles几乎不再消耗CPU时间，爆炸算法优化，红石不再卡服，流水算法优化，区块压缩节约内存，优化Spigot自带的Anti X-ray等等），并且有许多可自定义项目（船损坏依然掉落船，各种地形生成的开关等等）。

· 由于基于Spigot开发，也必须使用BuildTools来进行构建
https://ci.destroystokyo.com/job/PaperSpigot/322/

·关于兼容性，几乎兼容所有Spigot插件/Bukkit插件

· 关于地图/插件导入- 经测试，直接替换同版本服务端即可（但为保险起见请先备份）

· 关于更多的优化内容（引用贴内的内容,感谢原作者）
  1. paper.yml中可以优化性能的参数：

  3. keep-spawn-loaded，spawn区块是否常驻内存，设置为false可以减少一定的内存占用和计算量

  5. * tick-next-tick-list-cap，每tick最大的运算量，减少数值可以提高TPS，例如设置为8000

  7. * tick-next-tick-list-cap-ignores-redstone，达到上面的运算阀值是否无视红石运算，设置为true可以显著减少红石对服务器性能的影响。

  9. * optimize-explosions，是否开启爆炸算法优化，设置为true可以提升一定的服务器性能

  11. * use-async-lighting，是否让光照的逻辑运算异步化，设置为true可以使得光照运算不再影响TPS，强烈推荐设置为true

  13. * cache-chunk-maps，是否缓存chunkmaps，可以让区块的数据更多得被复用，可以一定程度提高性能，推荐设置为true

  15. * fast-drain，快速液体流动运算，推荐设置为true，可以减少液体流动运算对服务器性能的影响</font>

[diamond_gem] 其他问题

下载后如何开启？
答：像其他服务端那样开启即可
  1. @echo OFF
  2. java -Xmx1024M -Xms1024M -jar 下载到的文件的名字.jar
  3. PAUSE

答：请确定安装了JAVA8

关于服务端的稳定性？

关于Papertools的是用方法，现在有AppleTop成员soutou 来为大家讲解
用官方提供的Tools有什么好处呢？
①：能时刻获得最新的版本
②：不用担心服务端是否被动了手脚，都是官方的git直推的


具体如何使用呢，↓↓↓↓↓↓↓↓
首先请从官方的地址获取最新的Tools工具
https://ci.destroystokyo.com/job/PaperSpigot-BuildTools/
然后改如何使用这个Tools工具呢，首先你需要git的环境，请百度msysgit，并下载，下载后打开，并选择安装路径进行安装
安装过程可能较慢，推荐使用代理
然后你需要创建一个bat脚本来运行这个tools，下面是一段示范↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓

@echo off
title paperspigot制作工具，制作by AppleTop - soutou
set startdir=%~dp0
set bashdir="F:\msysgit\bin\bash.exe"  此处请替换成你的msysgit安装路径中bash.exe文件的路径
%bashdir% --login -i -c "java -jar ""%startdir%\PaperTools.jar"""
pause

然后你就只需要慢慢等待他推完了~ 如果你还有更多的问题可以私信我的QQ：303178853
