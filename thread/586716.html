Nick 昵称管理
用于基于bukkit的我的世界服务端的昵称管理插件。专注不卡服与跨服可用。

前置需求
  • 服务端版本1.8+
  • Java版本1.8+
  • iTag用于显示头顶标签


指令说明
/nick set <nick>
    * 设置自己的昵称为<nick>。
    * 需要`nick.set`权限。
/nick set <nick> <player>
    * 设置目标的昵称为<nick>.
    * 需要`nick.admin`权限。/nick see <nick>
    * 查找在线玩家中拥有特定的人。
    * 不需要额外权限。
/nick allow <player>
    * 给予玩家修改昵称的权限5分钟。
    * 需要`nick.admin`权限。
/nick reload
    * 重新载入配置文件中的语言和白名单部分 。
    * 需要`nick.admin`权限。

安装说明
插件默认使用数据库，如果没有远程数据库，请在配置文件里面将
dataSource:
    url: xxxxxxxxx
的url后面改成jdbc:sqlite:nick.db后，重启服务器即可。
