Minigames Party
这里可以让每个小游戏弄到60秒长而且变换 这个插件还在查找“八哥”（BUG）中 我会尽快找到并且上传以最快速度上传最好
可以添加
  • HorseRacing
  • Spleef
  • Bomber
  • ColorMatch
  • MineField
  • SeaBattle
  • jumpnrun
  • 未来计划:
    • sheepfreenzy, Frostbite etc.
Setup
  • 1.设置一个大厅（嘎嘎）
  • 2. 指令/mp setlobby
  • 3. 去某处位置大厅下（X，Z都不重要，只有Y··原句照搬
  • 4. /mp setup
  • 5. （你们都喜欢的）创建一个加入的牌子（把[party]写在第2行)
指令：
  • /mp help
  • /mp setlobby | sets the main lobby
  • /mp setup | used for the setup at the beginning
  • /mp list | lists all loaded minigames
  • /mp stats | shows your player statistics
  • /mp leave | leaves the game
  • /mp join | joins the game
  • /mp setcomponent [minigame] [component] | this command changes any component of a minigame, e.g. spawn, lobby, spectatorlobby, finish
