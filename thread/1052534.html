插件简介

EasyShop是一款追求高效率、批量制作的菜单商店的插件，它的主要目的是用于快速创造菜单商店，对应的，插件在方便配置的同时也放弃了一些功能的实现。如果你追求效果更好的菜单商店，并且你能够有办法应付单页数千行的配置文件，我个人推荐使用你使用virtualchest。再次强调：本插件追求的是以尽可能方便快捷的方式创造菜单商店，而非实现更多功能

已实现的功能：
1. 出售物品
2. 收购物品
3. 支持物品meta值
4. 支持为单个商品设置特定货币

主要缺陷：
1. 单个格子不能同时实现收购和出售
2. 不能批量交易（可能会在之后添加）

使用方法

要使用插件创建一个商店，你只需要在配置文件里的“Shops”中添加如下一项即可：

  2. Shops{
  3.   # 商店代号，用于tab补全，最好是英文或者数字
  4.   "shop1"{
  5.     # 商店名称，也就是菜单商店的标题
  6.     Name="shop1"
  7.     # 商品，格式为：商品id,meta（UnsafeDamge，用于区分相同id的物品，比如羊毛的不同颜色）,价格，货币
  8.     Items=[
  9.       "minecraft:wool,1,20,dollar",
  10.       "minecraft:planks,2,10,rmb"
  11.     ]
  12.   }
  13. }
复制代码

可以看到，商店的物品就是在Items这一项中添加即可，每添加一行，就可以为商店添加一个物品
每一行分为4个部分，每个部分都要用英文逗号分隔，一是物品id（例如minecraft:wool），二是物品meta值，三是物品的价格（负数代表收购），四是物品交易使用的货币，每一行的末尾应该加上一个英文逗号，除非它是最后一项（没看懂请直接看示例）
另外，每个商店最多只能54个物品，如果你的配置文件不正确，将无法打开商店。


完整配置文件示例


  2. Shops{
  3.   # 商店代号，用于tab补全，最好是英文
  4.   "shop1"{
  5.     # 商店名称，也就是菜单商店的标题
  6.     Name="shop1"
  7.     # 商品，格式为：商品id,meta（UnsafeDamge，用于区分相同id的物品，比如羊毛的不同颜色）,价格，货币，使用英文逗号分隔
  8.     Items=[
  9.       "minecraft:wool,1,20,dollar",
  10.       "minecraft:planks,2,10,rmb"
  11.     ]
  12.   }
  13.   "shop2"{
  14.     Name="shop2"
  15.     Items=[
  16.       "minecraft:wool,1,20,dollar",
  17.       "minecraft:planks,2,10,rmb"
  18.     ]
  19.   }
  20. }

  22. # 货币显示名称
  23. rmb="点券"
  24. Coin="金币"
