题记：

尽管mcbbs是一个很快的服务器，但是

经常上mcbbs的人要不要更快呢？

我教大家用hosts修改来加快进入mcbbs





了解hosts？

{简单地说，hosts就是不用把网址上传到坑爹的DNS服务器，可以直接用IP访问，可以大量减少减少时间}


首先是mcbbs ping值的截图

（附加：ping是测试一个网址的IP以及速度，比如在cmd中输入ping www.google.com）

然后，我们可以得出www.mcbbs.net的ip地址，



然后，最重要的来了

进入你的hosts文件夹


hosts文件在不同操作系统（甚至不同Windows版本）的位置都不大一样：
  • Windows NT/2000/XP/Vista/7/8（即微软NT系列操作系统）：默认位置为%SystemRoot%\system32\drivers\etc\，但也可以改变。动态目录由注册表键\HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\DataBasePath决定。
  • Windows 95/98/Me：%WinDir%\
  • Linux及其他类Unix操作系统：/etc
  • Mac OS 9及更早的系统：System Folder: Preferences或System folder（文件格式可能与Windows和Linux所对应的文件不同）
  • Mac OS X：/private/etc（使用BSD风格的hosts文件）
  • OS/2及eComStation："bootdrive":\mptn\etc\
  • Android：/system/etc/hosts
  • Symbian第1/2版手机：C:\system\data\hosts
  • Symbian第3版手机：C:\private\10000882\hosts，只能使用具有AllFiles权限的文件浏览器（也就是塞班系统的最高权限）访问，而绝大部分文件浏览器都不行(如X-plore和ActiveFile)[1]。
  • iOS（iPhone）：/etc
  • iOS（iPad）：/private/etc
  • webOS:/etc


然后，点击hosts，选择用记事本打开它，如果你是小白，可以用软件辅助你修改



然后再hosts中

插入：
  1. # Section Start：mcbbs
  2. 223.6.253.56        www.mcbbs.net
  3. # Section End：mcbbs
复制代码
