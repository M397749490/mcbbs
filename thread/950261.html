近期在将我原来使用ANT构建的项目改成使用Maven时，解决依赖问题时搭建了一个Maven镜像站，现在分享给大家使用。
本项目参考了@Lss233 Lss233's.OSS()

使用方法
  • pom.xml

  1.     <repositories>
  2.           <repository>
  3.                 <id>minecraft</id>
  4.                 <url>https://repo.headway.link/repository/minecraft/</url>
  5.           </repository>
  6.           <!-- Other repositories -->
  7.     </repositories>
复制代码
或
  • setting.xml


  1.   <mirrors>
  2.     <mirror>
  3.       <id>headway-dmulloy2</id> # 随意填
  4.       <mirrorOf>dmulloy2-repo</mirrorOf> #填写pom.xml上面的repository id
  5.            <name>headway dmulloy2</name> # 随意填
  6.        <url>https://repo.headway.link/repository/dmulloy2-repo/</url> # 或https://repo.headway.link/repository/minecraft/
  7.         </mirror>
  8.   </mirrors>
复制代码
