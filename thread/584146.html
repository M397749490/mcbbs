一个简单的插件 可以让你购买任何玩家的头颅 并且支持金钱插件

还有一个黑名单可以防止你不想让玩家购买的指定头颅

你还可以设置村民来制作一个商店 如下图



特点

可配置的价格

简单的命令

村民商店

黑名单




安装 兼容1.7-1.9

正版和离线服务器


需要前置插件

  • Vault
  • 经济插件
[size=14.6667px]指令
[size=14.6667px]使用指令 /buyh help 来查看所有指令

玩家的命令
  • /buyh - 等同于 /buyh help
  • /buyh help - 所有的插件命令
  • /buyh <player> - 购买一个玩家的头
  • /buyh <player> [quantity] - 购买指定数量的玩家头
[size=14.6667px]管理员命令

  • /buyh help - 所有的插件命令
  • /buyh blacklist - 显示黑名单
  • /buyh blacklist <name> - 添加一个名字到黑名单
  • /buyh whitelist <name> - 从黑名单删除一个名字
  • /buyh newshop <name> - 生成一个村民商店
  • /buyh reload - 重载插件配置

# true if you want to see the prefix "[BuyHead]" in front of every messages
# The prefix is editable in the language files

# The price one head will cost
