这个是根据物品描述(Lore)判定的，所以你只要给菜单加上需要判定的Lore就可以了。
在菜单配置文件中加上:
  1. Options:
  2.   Lock-Player-Inv: true
  3.   Bind-Item-Lore:
  4.     - '主菜单'
复制代码
这样一来只要是Lore中含有"主菜单"三个字的物品就都可以用来打开你这个菜单，但有个小缺陷就是左右键都能够打开菜单。我的服务器是使用Ess自带的礼包功能创建一个新玩家进服时就自动发送给玩家的礼包，礼包中就包含其描述(Lore)中有"主菜单"字样的钟表，礼包配置如下:
  1. kits:
  2.   newkit:
  3.     delay: -1
  4.     items:
  5.       - clock 1 name:§f●§a§l游戏§6§l菜单§f● lore:&7-&0>&7点击打开主菜单
复制代码
