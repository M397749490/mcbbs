这个大概要mod配合吧
mod主类中注册一个频道
并且写这么一个方法
@NetworkCheckHandler
@SideOnly(Side.SERVER)
    public static boolean check(Map<String, String> remote, Side side) {
        // 把这个remote发送给频道
    }
然后在bukkit插件中监听这个频道，接收信息并读取
