PlugMan 是一个用来管理其他插件加载卸载的插件，可以让你不用重启服务器就添加/删除插件

1.5.2版本的插件请见原先的帖子：传送门
插件指令列表：


插件指令 指令描述
/plugman help 展示插件帮助
/plugman list [-v] 按字母排序显示当前所有插件，加-v则显示它们的版本
/plugman info [plugin]展示一个插件的信息
/plugman dump 将所有插件的信息和版本保存到一个文件中
/plugman usage [plugin] 列表出插件所注册的指令列表
/plugman enable [plugin|all] 开启一个/所有插件
/plugman disable [plugin|all] 关闭一个/所有插件
/plugman restart [plugin|all] 重启一个/所有插件
/plugman load [plugin] 加载一个新插件
/plugman reload [plugin|all] 重载一个/所有插件
/plugman unload [plugin]
 卸载一个插件

权限节点：
权限 描述
plugman.admin 允许使用所有该插件的指令
plugman.update 可以让玩家看见插件更新的情况动态信息
plugman.help 可以使用帮助指令
plugman.list 可以列出指令列表
plugman.info 允许使用/plugman info指令
plugman.dump 同上
plugman.usage 同上
plugman.enable 同上
plugman.enable.all 同上
plugman.disable 同上
plugman.disable.all 同上
plugman.restart 同上
plugman.restart.all 同上
plugman.load 同上
plugman.reload 同上
plugman.reload.all 同上
plugman.unload 同上
