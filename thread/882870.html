/scoreboard objectives add time dummy
上面那条执行一次，下面的全部高频
/scoreboard players set @e[tag=!b,type=arrow] time 20
/scoreboard players tag @e[score_time_min=19,type=arrow] add b
/scoreboard players remove @e[type=arrow] time 1
/execute @e[type=arrow,score_time_min=0] ~ ~ ~ particle cloud ~ ~ ~ 0 0 0 0 5

我说个大概思路吧
设置所有tag=!b的箭time的记分板为20（20刻为1秒）
给time=19的箭添加tag=b
time减1
在time大等于0的箭处都设置粒子指令（用execute）
