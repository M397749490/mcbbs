本服是公益服并且愿意承担虚假宣传的一切后果

服务器核心版本：1.16.2
可跨版本登录,最低可支持1.4.7以上的客户端进入服务器
已开启正版验证
这是一个兴趣使然的原版纯净服务器。
Red For All（RFA）始创于2020-05-15，服务器按年续租，长期开放,
以原版困难生存为主，允许使用红石，允许高频红石、三向、世吞等，不限制TNT使用，但请勿无意义的炸服。

服务器内小伙伴们有爱互助。
开荒阶段，欢迎所有小可爱加入。
生电是为了更好的建筑。欢迎红石大佬以及建筑大佬的加入。
亦欢迎小可爱们前来围观打酱油。


请小可爱们加上QQ群。并改成游戏名，以后游戏里有啥问题好找人.

---------特色---------
服务器是否追版本？服务器尽量贴近mojang发布的正式版本，若新发布的正式版本无重大bug均会同步更新

服务器尽量还原原版，无领地插件，无tpa、无home（请小可爱们妥善保存物品。

服务器不设立任何OP，OP数量为0，所有人均没有特权，特殊情况才会使用服务器后台并会在群内告知所有动态，如果在游戏内发现有任何人有OP权限或特殊权限可截图联系群内管理。

服务器开放co插件查询权限。

服务器开放砍树插件，前来享受一键砍树吧（开荒阶段开放一键砍树，如果不喜欢一键砍树插件可加群发起投票噢，投票通过则删除插件

新加入斩首插件，增加所有生物头颅掉落几率，玩家头颅亦可掉落哟。 来吧，展示。

因为部分不可再生资源获取困难，设立系统商店，出售一些不可再生资源，比如鞘翅、潜影盒、石英等。尽量建造生电设施获取资源。




---------规则-----------
理论上所有资源均共享，但是如果有一些东西不希望别人动的，请放牌子标注，或放末影箱内。服内玩家均会尊重您的举动。
1. Java 版正版验证
2. 禁止各种外挂、黑客端、作弊mod
3. 禁止利用游戏特性复制物品（不包括TNT实体、地毯、铁轨）
4. 服务器已安装反外挂插件，请自重。
5.本服为公益服，仅接受无偿赞助，无任何氪金项目。
