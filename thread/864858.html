标题: forge修改内存问题
使用forge1.12.2和eclipse，启动之后发现会在加载完毕进入主页面时卡住，出现Caused by: java.lang.OutOfMemoryError: Java heap space 的错误，应该是内存不足溢出的问题，然后想问一下forge修改游戏启动的内存大小是在哪里改的，试了几个bat文件发现没效果。希望大佬们能给予帮助，谢谢！
作者: 3TUSK    时间: 2019-5-12 07:04
在 Run -> Run/Debug Configuration... 中找到 Minecraft 启动的配置，VM Arguments 里如果有 -Xmx 和 -Xms，那两个就是了。
