作者: ⊙v⊙    时间: 2016-3-5 12:51
也就是建立sb，检测deathcount项
  1. /scoreboard objective add Died deathCount
  2. /testfor @a[score_Died_min=1]
  3. /scoreboard players set @a Died 0
复制代码
第二个接高频，成功检测触发第三条。
