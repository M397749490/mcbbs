楼主想知道为什么 VB 不直接显示 InitializeComponent 吗？因为你在它后面附加的代码写到很多地方也能发挥作用，例如 Loaded 事件处理。
我看了你写的代码。你考虑事情基本上是在用 C# 的思想，然后翻译 VB 代码出来。
我建议你把 VB 代码移动到 C# 代码前面。因为这种程序属于可以快速拼凑出来的程序，而不是那种非要动工程的。这种情况下应当选用 VB 来降低拼凑代码时的成本。例如通过代码编辑器的下拉框快速创建事件处理程序，以及使用隐式收缩转换。

作者: Nukepayload2    时间: 2018-2-18 15:04
代码有一处违背 .NET 代码风格。
Dim versions As Version() = Application.launcherCore.GetVersions().ToArray()
这里，看右边的调用能清楚地知道 versions 是 Version 数组。所以不应该写 As Version()。
还有，VB 代码风格约定要求不写空参数列表的括号，除非会带来歧义。
因此，那一行代码应该改为：
Dim versions = Application.launcherCore.GetVersions.ToArray
