集合

集合是Scala标准库中提供的重要的函数式编程API。在函数式编程中，我们期望值是[ruby=Immutable]不可变[/ruby]的 ，对集合进行操作的时候，总是想创建一个新的集合，而不是对旧的集合进行修改。但是简单实现的不可变的集合会带来很多性能问题。Scala通过实现高效的[ruby=Persistent data structure]持久化数据结构[/ruby]解决了这些问题，使得使用不可变数据结构进行函数式编程成为可能。本节将简单介绍一些常用的集合类，其他更多的集合类请参考Scala标准库文档

Array

支持不可变数据结构并不意味着不支持可变的数据结构，例如：scala.collection.mutable包中的集合类和Array都是可变的数据结构，Array作为最基础的一种数据结构，其底层实现是十分高效的，直接对应了Java中的数组类型的值，对其中任意元素的访问和修改拥有O(1)的时间复杂度。但是Array一旦创建，其大小就是不可变的。具体用法请参考Scala标准库文档，其常见用法如下例所示：
  1. val names: Array[String] = Array("foo", "bar")
  2. val firstName: String = names(0)
  3. val secondName: String = names(1)
  4. val oldNames: Array[String] = names.clone
  5. names(1) = ""
  6. val namesLength: Int = names.length

List

List是最简单的不可变函数式数据结构，可以简单的用代数数据类型来表示。往List头部加入、删除一个元素的操作为O(1)，包括计算List长度的操作在内，大多数对List的操作时间复杂度为O(n)。具体用法请参考Scala标准库文档，其常见用法如下例所示：
  1. val names: List[String] = List("foo", "bar")
  2. val newNames: List[String] = "cxx" :: names
  3. val newNamesLength: Int = newNames.length

Set

Set是不包含重复元素的集合，其主要实现是HashSet，出于性能原因，其使用了比List要复杂得多的实现，但仍然是不可变的数据结构。具体用法请参考Scala标准库文档，其常见用法如下例所示：
  1. val names: Set[String] = Set.empty
  2. val names0: Set[String] = names + "foo"
  3. val names1: Set[String] = names0 + "bar"
  4. val names2: Set[String] = names1 - "foo"
  5. val containsFoo: Boolean = names2.contains("foo")

Map

Map集合将类型K的键映射到类型V的值，其主要实现是HashMap。具体用法请参考Scala标准库文档，其常见用法如下例所示：
  1. val ageMap: Map[String, Int] = Map.empty
  2. val ageMap0: Map[String, Int] = ageMap + ("Aqua" -> 5)
  3. val ageMap1: Map[String, Int] = ageMap0 + ("Tamaki" -> 17)
  4. val ageMap2: Map[String, Int] = ageMap1 - "Aqua"
  5. val tamakiAge: Option[Int] = ageMap2.get("Tamaki")
