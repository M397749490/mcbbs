Ultimate_Economy



一、功能

1.商店系统，可定制物品及价格使用以下指令分别创建玩家商店和管理员商店。创建的商店是以村民在你所站的位置生成出来，商店大小为9的倍数，最大为54（两个箱子的容量）
Adminshop管理员指令:
-/adminshop create <shopname> <size:9,18...54>  创建商店商店大小必须为9的倍数
-/adminshop delete  <shopname>  删除商店
-/adminshop move <shopname> <x> <y> <z>  移动商店
-/adminshop addItem <shopname> <material> <slot><amount> <sellPrice> <buyPrice> 添加商品
-/adminshop removeItem <shopname> <slot>   移除商品
-/adminshop addSpawner  <shopname><entity type> <slot> <buyPrice>    添加刷怪蛋
-/adminshop removeSpawner <shopname> <slot>移除刷怪蛋
-/adminshop editItem <shopname> <slot> <amount><sellPrice> <buyPrice>  编辑商品
-/adminshop addEnchantedItem <shopname> <material> <slot><amount> <sellPrice> <buyPrice> [<enchantment> <lvl>] 添加附魔（只能附魔可以附魔的物品）
-/adminshop addPotion <shopname> <potionType> <potionEffect><extended / upgraded / none> <slot> <amount><sellprice> <buyprice>
添加药水效果，extended意味着时间的长短，upgraded意味着I级，II级。none即无
Playershop玩家指令：
-/playershop create <shopname> <size:9,18...54> 创建商店 商店大小必须为9的倍数
-/playershop delete <shopname>删除商店。所有存储的物品都不见了!!
-/playershop  <shopname> <x><y> <z> 移动商品
-/playershop changeOwner <shopname> <new owner>   更改商店拥有者
-/playershop addItem  <shopname><material> <slot> <amount> <sellPrice><buyPrice>   添加物品
-/playershop removeItem  <shopname><slot>    移除商品，小心，所有该物品都会被移除消失。
-/playershop addEnchantedItem <shopname> <material> <slot><amount> <sellPrice> <buyPrice> [<enchantment><lvl>] 添加附魔
-/playershop addPotion <shopname> <potionType> <potionEffect><extended / upgraded / none> <slot> <amount><sellprice> <buyprice> 添加药水效果
填充/补充玩家商店：

要填充玩家商店中的商品，请将商品卖给商店。你不需要付钱。要查看存储的项目，请按鼠标中键。要返回正常的商店视图，请再按一次。

商店自带GUI,您可以使用此GUI轻松配置商店。你也可以通过更改配置文件或指令配置商店，强烈建议用GUI可视化界面。
您可以通过以下方式打开EditorGui：
- / adminshop editShop  <商店名字>
- / playershop editShop  <商店名字>如下图所示红色代表该位置已经配置过物品，青色表示该位置为空，即无商品。可以通过点击方块进入配置对应商品GUI界面

二.经济系统，可与Vault关联
管理员指令:
-/giveMoney <player> <amount> 给玩家钱但不从其他玩家那里拿钱。金额可以是正数也可以是负数。如果是负数，您可以从玩家中删除货币。
- /maxHomes <number>  更改每位玩家的最多home数量.
-/maxJobs <number>  更改每个玩家的最大加入工作数.
-/maxJoinedTowns <number> 更改每个玩家的最大城镇数
-/ue-language <language> <country> 选择语言文件
更改插件的语言。
可用语言：
-de DE
-en US
-cs CZ
-fr FR
-zh CN
玩家指令：
-/money 在聊天中显示您的钱。
-/bank <on / off> 禁用/启用记分牌。
-/shopList 此命令列出所有可用的管理员商店。
-/pay <playername> <amount>  使用此命令，您可以向其他玩家支付您的钱。
-/setHome <homename>使用此命令最多可以设置3个home（默认）。
-/delHome  <homename>此命令删除home。
-/home  使用此命令，您可以传送到您的某个home

三。城镇系统
管理员指令:
-/townworld enable <worldname>
将世界定为城市世界。现在玩家可以找到城镇，玩家不能在城外与世界互动。
-/townworld disable <worldname>
禁用世界的城市世界功能。所有城镇和所有权都将被删除。
-/townworld setFoundationPrice <worldname> <price>
设定玩家在特定城镇世界中找到城镇时必须支付的价格。
-/townworld setExpandPrice <worldname> <price>
设定玩家如果按照地块扩展他的城镇必须支付的价格。
玩家指令:
-/town create <townname> 玩家找到了一个新城镇。该命令只能在活跃的城镇世界中执行。
在你所站的城镇上，村民将会产生。在城镇上，村民们可以加入和离开城镇。
-/town delete <townname>  玩家删除他的城镇。该命令只能在活跃的城镇世界中执行。
-/town expand <townname>玩家通过地皮扩展他的城镇。该命令只能在活跃的城市世界和与城镇相连的地皮上执行。扩张的价格来自城镇银行。
-/town addCoOwner <townname> <playername>   此命令将玩家作为共有这添加到城镇。除了允许添加其他拥有者和删除城镇之外，该拥有者在城镇中拥有所有权限，例如所有者。
-/town setTownSpawn <townname>    玩家设置城镇出生点。只有城镇居民可以在他镇内的城镇世界中执行这个命令。
-/town bank <townname>   返回城镇的银行账户金额。只有镇主可以看到这个数额。
-/town moveTownManager     将城镇管理村民移动到您所站的位置。只能由城镇居民在城镇内执行。
-/town plot setForSale <price>
可由城镇所有者或您所站立的地块的所有者执行。此命令设置您正在出售的地皮。该命令在您的位置产生一个销售村民，其他玩家可以从您那里购买该地块。
-/town tp <townname>    可由大家执行。传送到特定城镇的城镇。
- /town pay <townname> <amount>    可以由每个玩家执行。您可以通过帐户向城镇帐户付款。
四.工作系统。与Jobs相似的工作体系
管理员指令：
-/jobcenter create <name> <size（9,18,27 ...）>   创建工作中心
- /jobcenter delete <name> 删除工作中心
-/jobcenter move <name> 移动工作中心
-/jobcenter job createJob <jobname> 工作中心创建工作
-/jobcenter job delJob <jobname>  工作中心删除工作 ，这个指令讲删除工作并踢出所有该工作的玩家
- /jobcenterjob addItem <jobname> <material> <price>  添加种植物，通过种植赚钱。
- /jobcenter job removeItem <jobname> <material> 移除种植物
-/jobcenter job addMob <jobname><entity> 添加怪物，通过打怪赚钱
-/jobcenter job removeMob  <jobname><material>  移除怪物
-/jobcenter job addFisher <fish/treasure/junk> 给渔民增加战利品
- /jobcenterjob delFisher <fish/treasure/junk> 给渔民删除战利品
- /jobcenter addJob <jobcentername > <jobname> <material><slot>
此命令将创建的工作添加到工作中心。材料用于插槽中的图标。
这允许您将相同的作业添加到多个工作中心。.
-/jobcenter removeJob <jobcentername> <jobname> 移除工作
在工作界面，通过鼠标点击对应的工作来加入或退出工作。左键加入，右键退出。
玩家指令:
-/jobList 工作列表.
-/joobInfo <jobname> 工作信息.
-/myJobs 我加入的工作.

ultimate_economy.playershop  - 所有的玩家指令
ultimate_economy.home  - 所有home指令
ultimate_economy.pay  - / pay指令
ultimate_economy.info.bank  - / bank 指令

ultimate_economy.info.shoplist  - / shopList指令
ultimate_economy.info.myjobs  - / myJobs指令
ultimate_economy.info.jobinfo- / jobInfo指令
ultimate_economy.fastshop- / shop指令
