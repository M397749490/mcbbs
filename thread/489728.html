总的来说：


这是一个翻新版本,以前的quake的插件，它再现了原小游戏的服务器hypixel quakecraft。相比旧的quakedm版本，这个版本是更好的代码。它也带来了更可怕的特点：定制你自己的轨道炮，从商店购买升级，更方便、合理设置，玩家的记录，所以还在等什么！现在就下载吧!{:10_512:}

游戏简图：












玩家可以使用的命令：
/quake hub - 传送到大厅
/quake join - 随机加入游戏
/quake join {id} -加入指定房间（id）游戏
/quake leave - 离开目前的游戏如果大厅没有设置可以使用如下命令来完成操作：
/quake shop - 打开商店
/quake customizer - 打开轨道炮定制
/quake record 打开个人记录

管理员可以使用的命令：
/quakeadmin arena create {id} {name} － 创建一个id为id，名字为name的竞技场
/quakeadmin arena spawn {id} - 设置id为id的竞技场的大厅
/quakeadmin arena remove {id} － 移除id为id的竞技场
/quakeadmin match create {id} {arenaId} {minimumPlayer} {maximumPlayers} - 设置id为id的竞技场的房间号为arenaId，最小玩家数为minimumPlayer，最大玩家玩家数为maximumPlayers
/quakeadmin match remove {id} - Remove a match with specified id？不知道
/quakeadmin hub －设置大厅

权限：
quake.admin - 管理员权限
