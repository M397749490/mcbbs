装GroupManager插件
在./plugins/GroupManager/config.yml中
  1. mirrors:
  2. # 以下根据我自己的理解来的,不懂再问哈
  3. # 所有列在这里的世界都可以进行一个单独的权限设置
  4. # 这里的"world" "world_nethe" "world_the_end" 可以不用管
  5. # 如果非要知道的话 好吧其实就是对应的服务器中的主世界 地狱 以及末地2333
  6. # 其中 "all_unnamed_worlds" 表示所有未在这里列出的世界

  8. #各类栗子
  9. # world2: (World2会有它自己的权限组和用户【即会有它自己的groups.yml 以及 users.yml】)
  10. # world3:
  11. # - users (World3会使用world2的users.yml,但是会有自己的groups.yml)
  12. # world4:
  13. # - groups (World4会使用world2的groups.yml,但是会有自己的users.yml)
  14. # world5:
  15. # - world6 (这会从world6中镜像一份groups.yml和users.yml)
  16. ##其中world2是父世界 即你服务器的主世界(默认为"world" 如果你没在 "server.properties" 下更改的话)
  17. world:
  18.   world_nether:
  19.   - users
  20.   - groups
  21.   world_the_end:
  22.   - users
  23.   - groups
  24.   all_unnamed_worlds:
  25.   - users
  26.   - groups
复制代码

  1. # 假定父世界为world
  2. # 要分离权限的世界为 test

  4.   world_nether:
  5.   - users
  6.   - groups
  7.   world_the_end:
  8.   - users
  9.   - groups
  10.   all_unnamed_worlds:
  11.   - users
  12.   - groups
  13. test:   ##test世界使用自己的users.yml和groups.yml
