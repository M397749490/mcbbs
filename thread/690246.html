◆ 插件作用 ◆
本插件可以给玩家创造一个庞大的箱子“网络”，只有设定好的物品种类才能进入该“网络”，玩家可以远程将特定种类的物品存进“网络”，也可以利用共享功能随时把物品取出来

————【你可以用它做什么】————
挖矿，收割作物分类放进网络
远程存取物品，远程仓库，远程邮寄物品

————【你还可以用它做什么】————
发挥你的想象力，制作女巫塔，猪人塔，生鱼塔无红石自动分类


◆ [教程]创建主箱 远程存物 ◆
使用本插件前，请先安装BKCommonLib前置 不需要安装前置
下载jar文件，扔进plugins文件夹，重启服务器

【一，权限】
与玩家有关的权限有两个，一个是创建主箱，一个是创建共享箱
autosort.use
autosort.use.withdraw
本插件的权限系统颇为灵异，以上两个权限是玩家默认有的
如果你不想让玩家使用这些功能，请给玩家权限组加带横杠“-”的权限
-autosort.use
-autosort.use.withdraw
然后再给单个玩家相应两个权限即可，但是灵异在哪呢……
这么做以后连OP都不能创建了，必须单独再给OP权限才行


【二，创建主箱】
所谓“主箱”就是整个箱子网络的核心，所有物品都会存放在这个主箱里
请靠着墙放置一个箱子，然后箱子上面一格放置一个贴在墙上的木牌

【三，物品组】
此为管理员设定内容，但是玩家可以使用
你是不是觉得设定物品种类一个一个输入太麻烦？完全可以设定物品组！一个物品组可以包含很多种类的物品！基础指令[仅OP可用]
/addasgroup <物品组名> <物品种类 空格隔开>

比如，我的僵尸猪人塔会掉落金粒，金锭，腐肉，金剑，那么我可以
/addasgroup TEST 371 266 367 283
然后在创建主箱的时候，物品种类填写TEST就可以啦

◆ 指令&权限 ◆
玩家基础权限
autosort.use
autosort.use.withdraw

这两个权限玩家默认有，不想让全服都使用的话请给玩家权限组加带横杠“-”的这两个权限然后再单独给玩家上权限
若是出现OP无法操作的情况，也给OP加上以上权限
其它权限不再赘述（我都说了这个插件权限系统很灵异）


玩家基础命令
指令中的网络名前面不需要带任何符号
/autosort <网络名> 将背包内27格特定物品存入网络
/autosortall <网络名> 将背包连同快捷栏36格特定物品存入网络
↑↑↑搞不清这两个指令为什么还要区分↑↑↑
/addtonet <网络名> <玩家名 空格隔开> 给自己的网络添加成员
/remfromnet <网络名> <玩家名 空格隔开> 给自己的网络移除成员
/listasgroups 列出所有物品组


管理员命令
/asreload 重载插件
/addasgroup <物品组名> <物品ID 空格隔开> 创建物品组
/modasgroup <物品组名> <物品ID 空格隔开> 添加物品到物品组
/delasgroup <物品组名> 移除物品组
/asremnet <创建者> <网络名> 删除箱子网络
/aswithdraw [创建者] <网络名> 打开箱子网络

◆ 配置文件config ◆

  1. # 调试模式，0代表关闭
  2. debug: 0
  3. # 跨世界设定，默认false代表可以跨世界，true代表只能在本世界传送物品
  4. worldRestrict: false
  5. # 当有不止一个主箱的时候，是否优先填入空主箱？默认false
  6. fill-emptier-first: false
  7. # 当有不止一个主箱的时候，低权重主箱会自动向高权重主箱转移物品
  8. # 不推荐开启，可能会卡服
  9. keep-priority-sorted: false
  10. # 箱子网络传送物品的距离，0是无限制
  11. proximity: 0

◆ 需要注意的问题 ◆

1, 所有的箱子默认只有创建者可以使用，但是经测试，这些箱子并不能防止漏斗矿车偷物品，所以请把箱子放在安全的地方

2, 请不要往箱子里塞设定种类以外的物品，某些因素可能导致种类外物品被吞掉

3, 教程中提到的三种箱子：主箱 存物箱 共享箱，只有主箱是真正存物品的
