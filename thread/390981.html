需求MOD Lain的BilicraftComments：[1.8/1.7.x/1.6.x][SSP/LAN/SMP][Forge]LainCraft[中文输入][更多语言]
配置文件：
  1. # 是否在弹幕前面加上玩家名字
  2. appendUsername: true
  3. # 允许的弹幕类型
  4. allowedMode: [0, 1, 2, 3]
  5. # 最短弹幕维持时间（单位: Tick）
  6. minLifeSpan: 40
  7. # 最长弹幕维持时间（单位: Tick）
  8. maxLifeSpan: 400
  9. # 发送弹幕的最小间隔（单位: Tick）
  10. commentInterval: 100

  12. # 提示信息
  13. messages:
  14.     tooFastToComment: "&4你真快! 不是么? 请休息一下."
  15.     invalidArguments: "&4一些奇怪的参数是不被允许的."
  16.     internalError: "&4发生了一个内部错误."
  17.     noPermission: "&4你没有权限这么做."
  18.     reloadConfig: "&2配置文件重新加载完毕."
复制代码
权限设置：
BilicraftComments.comment: 允许拥有此权限的玩家发送弹幕 （默认OP）
BilicraftComments.reload: 允许拥有此权限的玩家重新载入插件配置文件 （默认OP）
