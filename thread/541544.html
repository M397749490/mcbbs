空岛战争

SkyWarsReloaded 2.8.4


插件已经经过了汉化，部分汉化有错误，我会一步一步的完善。
插件的内核部分没有汉化，基础信息已经汉化完毕。
插件需要自行配置才能更好的进行游戏。
默认的空岛战争设置有点普通。

插件指令（汉化完成）
  1. 在服务器中使用/swr join -允许玩家加入游戏。玩家放入队列,并传送到大堂一旦最小数量的玩家加入游
  2. /swr quit - 允许玩家加入游戏。
  3. /swr start - 强制开始一个游戏
  4. /swr kit - 打开工具菜单
  5. /swr menu - 打开菜单选在游戏中。
  6. /swr shop - 打开当前所在的游戏的商店。
  7. /swr glassshop - 打开当前所在游戏的玻璃商店.
  8. /swr permkitshop -打开一个菜单,玩家可以购买永久。
  9. /swr particleshop -打开粒子效果商店
  10. /swr trialshop - 打开踪迹商店。
  11. /swr stats - 查看玩家的排名状态。
  12. /swr setspawn - 设置游戏的大厅。
  13. /swr spectate - 允许一个玩家观看比赛的进展
  14. /swr reload - 重启配置，商店配置及工具配置。
  15. /swr list -列出所有地图目前和表明他们是否注册
  16. /swr create <地图名> - 创建一个地图
  17. /swr save <地图名> - 保存地图
  18. /swr edit <地图名> - 编辑地图
  19. /swr delete <地图名> -删除地图
  20. /swr register <地图名> - 注册地图
  21. /swr unregister <地图名> - 解除注册地图
  22. /swr games - 列出游戏
  23. /swr endgame <游戏序号> - 结束游戏 (Use "all" to end all games)
  24. /swr addpoints <玩家名> <游戏币> - 增添这个玩家的游戏币
  25. /swr removepoints <玩家名> <游戏币> - 删除玩家游戏币
  26. /swr setglass <玩家民> <颜色> - 设置这个玩家的玻璃颜色
  27. /swr seteffect <玩家名> <粒子> - 设置这个玩家的粒子效果
  28. /swr setprojeffect <玩家名> <粒子> - 设置这个玩家的踪迹粒子
  29. /g - 全服聊天!
  30. /leave - 离开游戏！
复制代码
插件权限
swr.play - 使用指令join, quit, kit, and stats 的权限.（玩家权限，请分配个玩家）
swr.spectate - 允许玩家使用出席观看命令.
swr.opchest – 允许玩家使用OP箱子.
swr.timevote – 允许玩家使用时间投票选项.
swr.jumpvote – 允许玩家使用跳跃提升.
swr.weathervote - 允许玩家使用天气投票.
swr.usecolor - 允许玩家更改玻璃颜色.
swr.useeffect - 允许玩家使用粒子效果.
swr.useprojeffect - 允许玩家使用踪迹粒子.
swr.signs – 允许玩家设立空岛战争牌子.
swr.global - 允许玩家使用全服聊天.
swr.start - 允许玩家使用/swr start权限.
swr.shop - 允许玩家使用商店.
swr.spectateshop - 允许玩家使用出席观看商店.swr.admin - 管理员权限
swr.ignoreLobbyGuard - 允许玩家忽略大厅警卫 (更改大厅世界)
swr.vip - 给VIP玩家的一些倍数奖励
swr.maps - 列出所有地图.
swr.kit.<kitname> - 给玩家使用固定箱子的权限
swr.kit.free.<kitname> - 给玩家使用免费的固定箱子的权限
swr.permkits - 允许玩家购买永久道具 (永久道具在文件 <kitname>.yml里设置）
swr.color - 允许玩家使用聊天色彩.
swr.colorshop - 允许玩家使用玻璃颜色商店.
swr.colorglass.<玻璃颜色> - 给一个玩家玻璃设置颜色.
swr.effect.<粒子效果名> - 给玩家一个粒子效果. （全部粒子效果在文件 particleeffects.yml里).
swr.projeffectshop - 允许打开踪迹粒子效果商店.
swr.projeffect.<踪迹粒子效果名> - 给玩家一个踪迹粒子的权限. (全部踪迹粒子效果在文件projectileeffects.yml里).

牌子(加入游戏牌子)

第一行: [swr]
第二行: <mapname>
创建游戏
创建一个游戏加入牌子，
一个空岛战争游戏就创建了，
创建非常简单
