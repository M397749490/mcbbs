2.引用作者的话

Adequacy is a simple Minecraft mod that checks whether or not the installed Java runtime is recent enough to be able to run the game with the installed mods. If it's not, a warning message will appear with a prompt to download the latest version.

大概意思如下
Adequacy是一个普通的Minecraft模组，它可以检查你的JAVA版本是否能够加载你安装的MOD。如果你的JAVA版本不够高的话，一个警告窗口将会出现，同时警告信息中带有能下载最新版本JAVA的链接。

（这只是大概意思，并不是逐词翻译！）

4.关于安装
下载得到本模组后，直接放进mods文件夹即可（前提是你安装了Forge）


5.关于使用

此MOD没有在游戏中添加任何物品或者是文字显示，它的作用是在启动之前检查一下你安装的MOD是否能被你当前所使用的JAVA的版本所加载，如果有一个MOD超出了你的JAVA的承受范围（比如说你刚刚安装了一个需要用JAVA8的MOD，然而你的JAVA仅仅是JAVA7），就会出现下面这个会话框，提示你应该升级你的JAVA。（多用于整合包的制作过程。）

意思：
标题：你的JAVA版本过时了！
第一段：你安装的一个或是更多的MOD需要一个更高的JAVA版本，且这个版本比你已经安装了的JAVA的版本要高。
第二段：你将不能玩这些MOD直到你把JAVA升级到所需的最低版本。升级它是很容易的，从官网下载最新的JAVA并安装就行了。
第三段：在安装那个JAVA之后，重启你的游戏，然后你就应该可以玩了。
按钮：点击这里下载最新的JAVA版本！
好了，这个MOD的文字显示就是那么多……这个MOD最重要的作用就是，减少一些由于JAVA版本不能满足MOD的需要而引起的Crash，方便修理游戏
但是注意，这个MOD并不能发现或者是解决MOD之间的冲突！
