插件配置

config.yml

  2. BarAPI: false
  3. #是否启用BarAPI
  4. BarMessage: "&b&l %player 又骂脏话了!~"
  5. #BarAPI文字
  6. BarTime: 5
  7. #BarAPI时间(秒)

  9. takemoney: 0
  10. #启用经济的话骂人拿走多少钱
  11. todowhenoutofmoney: "kick and ban and clearmoney and clearinv"
  12. #如果没有足够的钱的话干嘛
  13. #kick = 踢        ban=**      clearmoney=玩家钱数归0      clearinv =清空玩家当前背包
  14. reason: "&想骂人要有钱!"
  15. #如果使用了kick这里填上理由


  18. runcommand: false
  19. #是否运行指令
  20. commandtype: console
  21. #指令类型(player/console)
  22. command: "mute %player 10s"
  23. #指令

  25. notifysender: true
  26. #是否提醒说脏话的人
  27. notification: "&c&l此服务器禁止说 %message !"
  28. #提醒时发布的消息

指令/权限
指令 权限 描述
/clc add clc.add 添加脏话一枚
/clc remove clc.remove 移除脏话一枚
/clc reloadclc.reload 重载插件
/clc help clc.help 查看帮助
/clc check clc.check 检查这个词是否被屏蔽
