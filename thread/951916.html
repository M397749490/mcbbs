AnimationLib
活性变量插件 运用数**算处理变量
一、前言
这个插件是我在使用UltimateBossBar插件时遇到的,它是前者的前置插件
由于这个插件作者的插件都比较好用,所以把前置搬过来了
已经申请作者的搬运许可,但是他好像已经半年没上Spigot了
需要使用java8
二、用途
  • 这个插件可以使用加减乘除乘方开方运算处理变量
比如你的血量是400,500 + (2 * %player_health%) 的数值就是1300

  • 当然,此作者的两款插件需要这个作为前置,

分别是UltimateBossBar1.1以上版本和AnimatedMenu2.4以上版本

  • 进行不同区域公式运算
  • 支持使用PlaceHolderAPI
  • 支持使用数据库

三、配置文件
Auto-Download-Placeholders: true
#在这里你可以组合多个数字变量成一个
#因为Java考虑了运算符的优先级，因此以下两种例子的结果是相同的:
#5 + (3 * %player_health%)  五加(三乘玩家血量)
#5 + 3 * %player_health%   五加 三乘玩家血量
#搬运者补充:如果要实现 五加三 乘玩家血量也就是(5+3) * %player_health%  即8乘血量
#乘法运算的乘号可以省略,跟什么向量应该没关系:
#5 + 3%player_health%
Formulas:
  #这里是公式的编辑模块,你可以简化一些运算为公式进行调用
  #以下展示了几个例子，即便他们好像并没有什么用处:
  #square(x) 表示X的平方即 (x * x)
  #mod 是 modulus(貌似是比率的意思,但实际上不是). 128 mod 100 = 28, 7 mod 4 = 3 看样子这个就像是减法
  overkill: '101(((4(5 + 3%player_food_level%) / square(2)) - 5) / 3) mod 100'
  useless:
    #sqrt(x) 是开平方X, 所以 sqrt(4) 结果就是2 , sqrt(16) 结果就是4
    value: 'sqrt(%player_health% * %player_health%)'
    #可以为每个公式指定格式，或者（请见底部）用全局格式
    #以下是一个JDK运算的帮助文档:
    #https://docs.oracle.com/javase/t ... /decimalFormat.html
    format: '#.##' #四舍五入到两位小数
  reversed-food: '-%player_food_level% + 20'
    #逆转你的饥饿等级,例如现在是8,实际上写的是12;饥饿等级是20,显示确是1
  server-sum: '%bungeecord_server1% + %bungeecord_server2%'

#使用 MVdWPlaceholderAPI 获取变量而不是 删减版(clip's) PlaceholderAPI
Use-MVdWPlaceholderAPI: false

Bungeecord也支持的一些变量作为参考:

  • %player_name% 玩家名
  • %player_displayname% 玩家伪装名
  • %player_server% 玩家所在服
  • %player_ip% 玩家IP
  • %player_uuid% 玩家UUID
  • %player_ping% 玩家延迟
  • %player_locale% 玩家所在地?
  • %player_has_permission_<permission>% 玩家拥有<>内权限
  • %player_has_mod_<mod>% 玩家拥有mod
  • %player_mod_version_<mod>%.如果玩家没有安装这个MOD那么会转向false
  • %server_online% 服务器在线人数
  • %server_online_<server>% 某服务器在线人数
  • %server_uptime% 开服时间?
  • %server_ram_used% 服务器内存使用
  • %server_ram_free% 服务器空闲内存
  • %server_ram_total% 服务器内存总量
  • %server_ram_max% 服务器最大内存
