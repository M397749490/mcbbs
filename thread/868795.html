你咋排查出是Flan's mod的锅的，这是应用能源和Flan's mod冲突导致的
id为2的维度已经被注册了，所以修改AE2的维度id才是上上策，Flan只是个没什么人玩的小众模组，应用能源作为老牌大型科技模组它的配置文件更容易配置
在它的配置文件中找到以下内容：
spatialio {
    D:spatialPowerExponent=1.35
    D:spatialPowerMultiplier=1250.0
    I:storageDimensionID=2
    I:storageProviderID=-11
}

将I:storageDimensionID=2修改，把2改成其他不冲突的数值即可
