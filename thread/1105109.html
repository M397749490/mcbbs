不透明的原因是材质(materials)文件没改

在资源包中新建materials
新建文件entity.material
里面写上
  1. {
  2.   "materials": {
  3.     "version": "1.0.0",
  4.     "pig:entity_alphatest": {},
  5.   }
  6. }
复制代码


不显示盲猜文件不全 或者定义失败
一个实体在资源包中至少需要以下定义 实体 贴图 模型 渲染控制器 缺少一个都不会加载
