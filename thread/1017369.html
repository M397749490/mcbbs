功能摘要：
  • 可选择在玩家加入时和最后一名玩家离开时开始备份
  • 可以设置玩家在线时才启用备份
  • 使用命令 /backup 立刻开始备份
  • 自定义备份间隔（以分钟为单位）
  • 限制存储使用量（超过限制时删除最早的备份）
  • 备份提示可以启用或禁用
  • 可备份多个世界
  • 备份会被压缩储存以减少使用的存储空间
  • 可以在备份之间设置最小间隔，以防止同时进行多个备份
  • 插件会自动更新！
  • 多线程！


BackupOnEvent是为了开放式生存服务器设计的备份插件。
可以在玩家加入时和最后一名玩家离开时开始备份，可以设置有玩家在线时才开始备份，也可以使用命令 /backup 立刻开始备份。
所有备份的世界都会被压缩到带有日期的zip文件中，例如2019-08-21_11h23m-enayet123-world.zip

此插件利用多线程来防止您的服务器在备份时崩溃，然后会检查配置文件，如果存储空间使用量超出限制，插件将会自动删除最早的备份。
此插件还可以自动更新。


汉化配置

plugins/BackupOnEvent/config.yml

  1. #要备份的世界
  2. BackupWorlds:
  3.   world_nether: true
  4.   world_the_end: true
  5.   custom_named_world: false
  6.   world: true
  7.   nether: true
  8.   the_end: true
  9. #是否在玩家加入/退出时备份
  10. RunBackupOn:
  11. #玩家加入时备份
  12.   playerJoin: false
  13. #玩家退出时备份
  14.   playerQuit: false
  15. #最后一个玩家退出时备份
  16.   lastPlayerQuit: false
  17. #自动备份间隔时间（分钟）
  18.   repeatIntervals:
  19.     minutes: 720
  20. #只有有玩家在线时才开启自动备份
  21.     whenPlayersAreOnline: true
  22. #是否隐藏备份信息
  23. HideMessage:
  24.   onJoin: true
  25.   onQuit: true
  26.   backupAnnouncement: false
  27. #是否只有OP才能使用/backup指令
  28. BackupCommand:
  29.   opsOnly: true
  30. #备份最大占用空间（MB）
  31. BackupStorage:
  32.   maxInMegaBytes: 102400
  33. #同时可以进行的备份数量，设置为0禁用
  34.   minimumIntervalInMinutes: 1
  35. #是否自动更新
  36. AutoUpdate:
  37.   enabled: false
复制代码





指令
/backup 默认OP才能使用，立刻开始一次备份
