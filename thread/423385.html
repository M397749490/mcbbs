GearSignature 装备签名



介绍


GearSignature是一款轻量级的插件，他会自动为工具，武器，物品，等东西自动添加签名。



图片







工作台里面制作的物品会获得 XX 制作的物品

创造模式的物品/指令给予的物品会获得 XX 作弊给予的物品




指令



指令简化指令 介绍
/gearsignature list /gs list 查看可以添加签名的物品【ID】
/gearsignature add <物品ID> /gs add <物品ID>增加可以添加签名的物品【输入ID】
/gearsignature remove <物品ID> /gs remove <物品ID>取消可以添加签名的物品【输入ID】
/gearsignature reload /gs reload重载设置
/gearsignature save/gs save 保存设置【游戏内增加的】

权限


权限 介绍 默认
gearsignature.* 给予全部权限-
gearsignature.list给予查看可以添加签名的物品的权限全部玩家
gearsignature.sign给予自动为装备添加签名的权限全部玩家
gearsignature.add给予增加可以添加签名的物品的权限 OP
gearsignature.remove 给予取消可以添加签名的物品的权限 OP
gearsignature.reload给予重载设置的权限 OP
gearsignature.save给予保存设置的权限 OP
gearsignature.dropcheated 给予可掉落作弊物品的权限 OP
gearsignature.pickupcheated 给予可捡起作弊物品的权限OP

默认设置文件内，作弊物品不可掉落【OP除外】。



设置文件




- 默认介绍
enabled true 启动/关闭插件
survival_signatureMessage 看汉化文件 制作物品的签名
creative_signatureMessage 看汉化文件 作弊物品的签名
creative_signCheatedItems true创造模式背包物品将被添加为作弊物品
creative_signOnlySignatureItems true 只给已经添加了的物品ID增加签名
creative_allowDropCheatedItems false 作弊物品可否掉落
creative_allowPickupCheatedItems false作弊物品可否捡起
date_enabled true增加制作时间
date_message 看汉化文件 签名的时间显示方式
date_format yyyy-MM-dd时间格式
signatureItems 无视掉 无视掉
