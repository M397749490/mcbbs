标题: 【3.14.10.0更新】返坑的樱花夜翻更新日志惨遭蹂躏
然而这里是一只回坑的樱花带来的翻译更新
午夜更新宅2333，让我们看下去吧！

3.14.10.0更新内容~
公告-Nelson Sexton

哈喽【标准开头XD】

更新内容：

添加：
  • 添加新的物品右键菜单，可快捷填充弹药/修复
  • 添加“附近的物品“UI，在背包中可以快捷的观看附近地上的掉落物了
  • 使用Ctrl+F组合键可进行快捷的物品移动操作（枪架or展示柜
  • 给游戏物品/车辆添加了更多颜色
  • 添加路障建筑的消失时间设置/雨水天气选项至Config设置选单
  • 在”我喜爱的服务器”列表中添加了快速取消喜爱的按钮（原来必须进入该服务器然后按ESC点右下角的Unfavorite
  • 在Option中添加了白天/夜晚的环境效果调节按钮


改进：

  • 改善了内存管理机制
  • 改进了Requip热键
  • 物品存放分化，附近物品显示在物品栏中
  • 合成面板可显示合成该物品所需的技能等级了
  • give/vehicle/teleport/experience指令可免去玩家名使用（默认对自己
  • help [指令]可在单人游戏中使用了
  • 改进了物品机制，同一区域可支持更多物品存在了
  • 改进对象/资源的一些物理问题
  • Improved world hints not to show behind the dashboard.
  • Improved zombie/animal/vehicle state updates to use basic position compression.
  • Improved buildable intersection displacement to better avoid forcing into objects.

调整：

  • 玩家扔掉的物品将出现在玩家前方（细节赛高
  • 老司机开车的时候手部会受到限制
  • 可制作物品将在合成界面显示为绿色，不可制作则为红色
  • 种植技能的加成速度降低了
  • DebugUI调整（FPS显示/延迟显示
  • 不同技能每级所需经验值不再是一样的了
  • 防止意外，调教了几个空心可致死的物体
  • 删除了New survivor这个默认名称
  • orientation of items in trophy cases.

修复：
  • 修复建筑放置在玩家出生地的问题（如果你想用建筑堵出生地会提示Too near to spawn
  • 修复受伤后瞬间回血的BUG
  • 修复物品不显示数量的问题
  • 修复标签消失的问题
  • 修复制作Pitchfork时的问题
  • 修复了移除管理权限时，管理员能力不会立即无效的BUG
  • 修复地图UI
  • Fixed tooltips showing up underneath inventory selection/drag.
  • Fixed override glasses mythic hook point.
  • Fixed birch/pine trophy case using maple sticks.
  • Fixed default easy/hard armor multipliers backwards.
