插件自身的reload指令暂时无法更新别名，/reload 命令因为在MCPC上被禁用了 无法测试，只在1.7.10Thermos上进行过测试

暂时只支持PlayerPoints，Mcrmb插件，需要其它点券插件支持请留言

作用：注册新的命令，玩家花费点券 可以以后台/OP身份 执行一条或多条命令，只负责执行无法判断执行结果。

占位符：$player执行命令的玩家名，$arg1-$arg9玩家输入的第一个至第九个参数，$multiargs被$arg引用的参数之后剩下的所有参数,$points该命令需要的点券数，

1.0.2


配置文件：

  1. #使用的点券插件，目前支持PlayerPoints，Mcrmb
  2. PointsPlugin: playerpoints
  3. #默认信息提示
  4. DefaultMessages:
  5.   NoPointsMessage: "You don't have enough points to run this command"
  6.   NoPermissionMessage: "You don't have the permission to run this command"
  7.   WrongArgsMessage: "Wrong usage"
  8.   SuccessMessage: "You have payed to run this cmd"
  9. #自定义命令列表
  10. PointsCommands:
  11. #命令的名字 玩家可以输入/Command1 来执行这个命令
  12. Command1:
  13. #需要的点券数量
  14.     Points: 666
  15. #点券数量不足的提示
  16.     NoPointsMessage: "You don't have enough points to run this command"
  17. #需要的权限
  18.     Permission: ''
  19. #没有权限的提示
  20.     NoPermissionMessage: "You don't have the permission to run this command"
  21. #命令后参数数量限制 -1 为不限制
  22.     RequiredArgs: 1
  23. #参数错误的提示
  24.     WrongArgsMessage: "You should use this command: /command1 arg1 arg2"
  25. #描述命令
  26.     description: 'text command 1'
  27. #命令的别名， 可以使用这些别名来执行命令
  28.     aliases:
  29.     - 'vipheal'
  30. #执行这个命令会运行的其它命令
  31.     runcmd:
  32.     - 'op:heal'
  33.     - 'console:shock $arg1'
  34. #执行成功的提示
  35.     SuccessMessage: "You have payed to run this cmd"

玩家消耗点劵关人咋搞

如果你是指使用 ess的 jail 来关人的话
jail的用法/jail <player> <jail name> [time]
那么在配置文件里添加一条
  1.   PayJail:
  2. #需要的点券数量
  3.     Points: 666
  4. #点券数量不足的提示
  5.     NoPointsMessage: "你需要x点券来执行这个命令"
  6. #命令后参数数量限制 -1 为不限制
  7.     RequiredArgs: 1
  8. #参数错误的提示
  9.     WrongArgsMessage: "用法/payJail 玩家名"
  10. #描述命令
  11.     description: 'pay to move someone to a jail'
  12. #命令的别名， 可以使用这些别名来执行命令
  13.     aliases:
  14.     - 'guanren'
  15.     runcmd:
  16.     - 'op:jail $arg1 要关进的监狱的名字 时长'
  17. #执行成功的提示
  18.     SuccessMessage: "已经花费x点券执行此命令"
