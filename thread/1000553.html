                  主要关于motion的
  一些计分板及实体的说明：
计分板X0,Y0,Z0用于记录实体坐标
X1,Y1,Z1用于记录目标坐标
发射点实体对应的标签：起点
TNT对应标签：勇敢的阶级弟兄
目标对应标签：可靠的同志
TNT落点对应标签：终点
避免TNT重复被修改motion的标签：233
（建议不要把实体标签弄成中文 [我只是为了演示] ）
  一、我们要有一个tp枪，就像这样，把药水云坐标设为目标
  1. #生成
  2. execute at @e[tag=起点,limit=1] run summon minecraft:tnt ~ ~0.1 ~ {Tags:["勇敢的阶级弟兄"],Fuse:60}

  二、TNT飞起来了
  1. #记录实体的pos值
  2. execute as @e store result score @s X0 run data get entity @s Pos[0] 100
  3. execute as @e store result score @s Y0 run data get entity @s Pos[1] 100
  4. execute as @e store result score @s Z0 run data get entity @s Pos[2] 100

  6. #代入目标的pos值
  7. execute at @e[tag=起点,limit=1] as @e[type=minecraft:area_effect_cloud,tag=终点,limit=1] run scoreboard players operation @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] X1 = @s X0
  8. execute at @e[tag=起点,limit=1] as @e[type=minecraft:area_effect_cloud,tag=终点,limit=1] run scoreboard players operation @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] Y1 = @s Y0
  9. execute at @e[tag=起点,limit=1] as @e[type=minecraft:area_effect_cloud,tag=终点,limit=1] run scoreboard players operation @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] Z1 = @s Z0

  11. #加减出TNT的motion值
  12. scoreboard players operation @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] X1 -= @e[tag=起点,limit=1] X0
  13. scoreboard players operation @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] Y1 -= @e[tag=起点,limit=1] Y0
  14. scoreboard players operation @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] Z1 -= @e[tag=起点,limit=1] Z0

  16. #TNT走抛物线Y轴需要额外增加的motion值
  17. scoreboard players add @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] Y1 2670

  19. #将分数代入TNT的motion值
  20. execute as @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] store result entity @s Motion[0] double 0.0003552 run scoreboard players get @s X1
  21. execute as @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] store result entity @s Motion[1] double 0.0003552 run scoreboard players get @s Y1
  22. execute as @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] store result entity @s Motion[2] double 0.0003552 run scoreboard players get @s Z1

  24. #保证不会重复修改TNT的motion值
  25. tag @e[type=minecraft:tnt,tag=勇敢的阶级弟兄,limit=1,tag=!233] add 233

六、使用时是否会出现BUG？
Q：长按鼠标右键会怎样？
A：会出来很多TNT，会有一部分TNT由于还没落地在空中自爆毁坏地形，增长TNT爆炸的延迟时间即可解决。

Q：快速右键多个地方会怎样？
A：有时太快第二个右键出来的TNT会和第一个右键出来的TNT飞向同一个目标，减少tag为“终点”的药水云的存活时间即可解决。

Q：TNT飞出来的时候顶上撞到方块会怎样？
A：TNT直接偏离路径。

Q：把目标设在墙上或天花板会怎样？
A：TNT滑落到地上爆炸。

  七、一些说明
分散开TNT落点并不是为了隐藏TNT落点的误差。

X轴motion值（y）与X轴坐标差（x）的函数解析式：y=0.03552x
Y轴motion值（y）与Y轴坐标差（x）的函数解析式：y=0.03552(x+2670)
Z轴motion值（y）与Z轴坐标差（x）的函数解析式：y=0.03552x

常量0.03552和常量2670是多次测量出来的。
