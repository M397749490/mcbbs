插件一句话介绍：

MoneyVouch是一款能将金钱绑定到纸上然后右击使用获得金钱的一款插件

重制内容：
  • 已汉化
  • 新增config.yml配置文件
  • 增加在信息里的三种变量%cost%，%player%，%money%
  • 可自定义的插件前缀
  • 可自定义纸钞的名字
  • 可自定义的纸钞Lore
  • 可自定义的多行提示信息
  • 可自定义的提示信息
  • 更改主指令为/monv
  • 修复了一个bug：多个纸钞在手上时会把手上的物品直接刷没
  • 将权限名修改为：monv.create，monv.redeem.money，monv.reload
  • 将版本兼容至1.8+
  • 优化了Vault前置的加载
  • 当玩家使用指令/monv create [金额]时重制版本的插件将会判断玩家是否是op，不是则会收取 [金额] 的费用

指令：
====== [纸钞插件 ======
/monv create [金额] 创建一个纸钞  默认给予所有人，权限节点monv.create
/monv reload 重载插件 默认给予OP，权限节点monv.reload



注：如果你的玩家不能领取纸钞，请给予该权限 monv.redeem.money

Config.yml设置：

  1. Prefix: "&6[&a纸钞插件&6]"
  2. Vouch:
  3.   Name: "&b一张纸钞"
  4.   Lore:
  5.     - "&6右键使用"
  6.     - "&6价值： &e%cost%"
  7. Done:
  8.   - "&6[&a纸钞插件&6]&7纸钞创造成功"
  9.   - "&6[&a纸钞插件&6]&b价值: &a$%cost%"
  10. redeemMsg:
  11.   - "&6[&a纸钞插件&6]&a领取成功,你领取了一张§6$%cost%§a的纸钞"
  12.   - "&6[&a纸钞插件&6]&a你当前的金币为 §6%money%"
  13.   
  14. noPerm: "&c权限不足"
  15. reloadDone: "&a插件已重载"
  16. wrongLength: "&c参数不正确"
  17. noEnoughMoney: "&c你身上的钱不足以创建一张钞票~"
  18. noNum: "&c你输入的字符不属于数字!"
  19. cantCreateOVouch: "&c无法创建0$的纸钞"
