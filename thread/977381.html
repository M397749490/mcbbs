插件介绍

这是一个即简单而且非常小的插件（只有37KB）

它可以让你的玩家轻松知道这个蜂箱里面养了多少只蜜蜂.

使用方法

1.将下载好的插件放入服务器端的plugins文件夹内
       2.通过重启服务器或者第三方插件加载插件.
       3.进入服务器后空手右键一个蜂箱就会提示你里面有几只蜜蜂啦.

指令与权限

/bb （查看插件的版本）

/bb reload （重载插件）

(/bb reload)权限为BBeeChecker.reload

配置文件

###################

#                 #

#   BBeeChecker   #

#    By: bonn2    #

#    汉化：京川    #

###################

# 玩家右键时发送信息（false则不发送）

ClickOnBlock: true

# 告诉玩家手上峰箱内的蜜蜂数量（设置为false则不告诉玩家）

ClickInAir: false

# 你想要在哪里显示信息（聊天框内或者是血条.）(chat or hotbar)

MessageLocation: chat

# 将描述添加到配置内.(卸载插件后配置将持续存在.)

lore: true

# 插件将告诉玩家的的消息。

# 使用 %number% 来代表蜜蜂的数量(这是一个变量)

# 物品的描述信息

Lore:

  AmountSingle: §r这里面有 §6%number% 只蜜蜂.

  AmountPlural: §r这里面有 §6%number% 只蜜蜂.

# 在聊天栏内显示的信息

ChatMessage:

  AmountSingle: §r这里有 §6%number% 只蜜蜂.

  AmountPlural: §r这里有 §6%number% 只蜜蜂.

# 输入错误命令时显示的消息(如输入/bb relaod便会显示这条信息.)

InvalidCommand: §c无效的命令用法!

# 重新加载配置时显示的消息.

# 设置为true时可禁用.

disableMetrics: false

# 请不要随意改变这里（这里是配置版本信息）
