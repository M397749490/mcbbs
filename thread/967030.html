  1. new SlimefunItem(Category c, ItemStack item, String id, RecipeType rt, ItemStack[] recipe); // c是该物品处在的分类，item是将要添加的物品，id是该物品的标识，id最好是全大写英文，空格用下划线代替，rt是合成方式，RecipeType包含所有粘液科技原版合成方式，recipe必须是一个length为9的物品堆数组，若其中有空气，请用null代替
复制代码
注意如果使用RecipeType.ANCIENT_ALTAR（远古祭坛）时，recipe[4]是不可为空的，原因请结合远古祭坛的特性自己思考
如果要使用粘液科技自带的物品作为合成表的话，请打出SlimefunItems.然后让ide自动补全（这个类包含了所有粘液科技原版物品，是ItemStack形式）


研究（需要经验解锁的那个）
先说一下：
  • 一个研究可以包含多个物品
  • 一个研究有一个唯一数字编号（id），如果id发生重复的话会报错
  • 研究的名称貌似是可以重复的，而且可以使用中文
