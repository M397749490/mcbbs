KickIdlePlayers-CMIVersion

踢出服务器人多/卡顿时还在挂机的玩家

原插件MCBBS发布贴(支持Essentials的版本):
https://www.mcbbs.net/thread-917470-1-1.html
插件重置已获得原作者@Ghost_Chu允许重制版插件开源地址https://github.com/shaokeyibb/KickIdlePlayer

警告，此插件仅能通过判断玩家AFK是否符合机制并踢人，使玩家进入AFK的功能由你的CMI负责而不是本插件，请务必注意

功能:
1.当TPS低于指定值，服务器玩家人数大于指定值，玩家AFK时长超过指定值时踢出玩家
2.当服务器人满时有玩家尝试进服时，踢出正在AFK的玩家以允许新玩家进服

安装方式:1.使用plugman/yum热加载插件或直接加载插件
2.于plugins/KickIdlePlayers/config.yml配置插件
3.使用plugman/yum热重载插件或直接重启服务器
4.enjoy it!

config.yml(配置文件)
  1. #当在线玩家数大于一下值时才会开始踢出玩家
  2. players: 8
  3. #玩家需要AFK超过以下时长(秒)才会被踢出
  4. max-idle-time: 3600
  5. #服务器TPS必须低于以下数值才会开始踢出玩家
  6. kick-tps: 18.50
  7. #踢出玩家提示
  8. kick-message: "&cYour already 3600 secs no any actions, you was kicked from server cause server is busy."
  9. #是否启用当服务器满时踢出AFK玩家
  10. kick-afking-players-when-server-is-full: true
  11. #服务器满时踢出玩家的提示
  12. kick-afking-full-message: "&cServer is full, you was kicked cause you are in AFK mode."
复制代码
本版本插件仅支持CMI，如需支持Essentials的版本请前往原贴
