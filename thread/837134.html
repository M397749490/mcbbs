CrossServerChat

插件用于学习 没有任何加密/验证代码 使用时请注意端口安全！ (或不使用)
下载地址:https://github.com/euOnmyoji/CrossServerChat/releases/
开源地址:https://github.com/euOnmyoji/CrossServerChat

本插件单独工作 不依赖任何跨服服务端。



配置文件(server 1):

  1. server-socket {
  2.     ip="null"
  3.     name="[MTS]"
  4.     port=5210
  5. }
  6. sockets {
  7.     name {
  8.         ip="127.0.0.1"
  9.         port=5209
  10.     }
  11. }
复制代码


配置文件(server 2):

  1. server-socket {
  2.     ip="null"
  3.     name="[PTS]"
  4.     port=5209
  5. }
  6. sockets {
  7.     name {
  8.         ip="127.0.0.1"
  9.         port=5210
  10.     }
  11. }

复制代码



配置文件
server-socket 为当前服务器的聊天socket监听端口
sockets为向哪些ip地址发送聊天socket
name为当前服务器的前缀 发送socket的时候会自动带上这个前缀(支持颜色代码&)

插件用于学习 没有任何加密/验证代码 使用时请注意端口安全！ (或不使用)


本插件所用所有代码均为原创。
