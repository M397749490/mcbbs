指令+权限
  • /lottery - 列出插件所有指令
  • /lottery [抽票池] enter - 加入一个等待开奖的抽奖池
  • /lottery [抽票池] info - 列出该抽奖池的详细信息
  • /lottery list - 列出当前正在等待开奖的抽奖池



教程

1.输入/lottery create 奖池名

2./lottery [奖池名] jackpot [item/money] [数量]似乎不能添加物品?
栗子：/lottery Test jackpot money 233

3./lottery [奖池名] price [价格] 设置一张抽票多少钱

4./lottery [奖池名] percent [0-100]
设置每张票中售出价格的百分之多少纳入总奖池

栗子：/lottery Test percent 50 Test的每张门票的50%将纳入奖金池

5./lottery [奖池名] entries [数量] 设置每个玩家最多在同一个奖池买多少票

6./lottery [奖池名] time [数量][M/H/D] 设置开奖一次要等多久
栗子：/lottery Test time 2H
此指令设置了Test奖池将在2小时后开奖
M=分钟 H=小时 D=天

7./lottery save 不知道为啥作者有这个指令，反正输入不吃亏

8./lottery [奖池名] start 开启奖池，之后会有一条奖池开启输入指令加入的消息

如果要设置自动重置奖池的话输入/lottery 后可以看到有一条，或者配置文件中修改autorestart=true
