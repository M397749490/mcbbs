简介:

这个插件很容易流行在一个大型德国服务器中

输入一个命令可以打开一个窗口,在这个窗口你可以选择你自己的靴子

这些靴子不是普通的靴子,他们有他们各自的功能





特征:

Simple GUI(GUI界面)
Permissio(权限)
Colored Boot(有颜色的靴子)
Boots with Effect(有特殊效果的靴子)
Fourteen Awesome Boots(14双靴子)
When GUI open Sound(打开GUI有声音)
Effects only when press SHIFT(特效只有按SHIFT时才能出来)
Language per user (Client Language)(语言,现在支持德语和英语)
Current Languages are German and English(支持英语)
命令:
/Boots - 打开靴子菜单
权限:
/Boots - premiumboots.use


作者将来想做的:

  • Permission (1.2)(实现)
  • More Boots (1.3)(实现)
  • Lore in Boots (1.4)(实现)
  • Better Effects (1.1)(实现)
  • Colored Boots (1.1)(实现)
  • Language per user (Client Language) (1.5)(实现)
  • For each Boots a Permission (未实现 每个靴子的权限)
  • Villager where you can choose Boots (未实现 在村民那里可以选择靴子)





如何使用?

下载这个插件,吧.jar放入plugins文件夹,运行游戏,输入/boots打开界面选择靴子,然后按住shift即可
