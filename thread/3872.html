服务器详细设置描述:





  6. #服务器基本设置
  7. level-name           = 服务器名称(这里必须使用英文)
  8. hellworld            = 地狱世界(true=开启 false=关闭)
  9. spawn-monsters       = 生成怪物(true=开启 false=关闭)
  10. spawn-animals        = 生成动物(true=开启 false=关闭)
  11. online-mode          = 在线模式(盗版服请设false)
  12. max-players          = 服务器上限人数(好友不多的建议10 否则设置多少消耗多少内存)
  13. server-ip            = 用于绑定服务器地址(建议留空 Hamachi例外)
  14. pvp                  = 友军伤害(true=开启 false=关闭)
  15. server-port          = 服务器端口
  16. white-list           = 启用黑名单,在banned-players插入玩家名
  17. #服务器隐藏设置
  18. verify-names         = 检测昵称,第一个重名昵称将被kick
  19. spawn-protection     = 重生点保护范围(单位:格 如32及32x32)
  20. levelName            = 服务器名称
  21. onlineMode           = 在线模式
  22. autoSave             = 自动保存
  23. autoSaveMins         = 服务器自动保存时间(单位:秒)
  24. autoBackup           = 自动备份
  25. autoBackupMins       = 自动备份时间(单位:秒)
  26. keepBackupHours      = 保留备份时间,超过将删除备份(单位:天)
  27. autoRestart          = 自动重启(服务端检测到错误时)
  28. autoRestartMins      = 自动重启时间(单位:秒)
  29. exitOnFailure        = 退出失效(未知)
  30. port                 = 端口
  31. internalPort         = 内部端口
  32. rconPort             = 远程端口
  33. rconPassword         = 远程密码
  34. useWhitelist         = 是否启用特定的人才可加入服务器
  35. useSMPAPI            = 使用多核处理
  36. c10tArgs             = 是用C10T参数(好像是10进制的意思)
  37. c10tMins             = C10T处理时间(单位:秒)
  38. maxPlayers           = 同max-players
  39. defaultGroup         = 默认组(此为Steam组,盗版无视)
  40. useSlashes           = 使用斜杠语法(默认dots语法)
  41. memory               = 内存(及服务端最高吃多少内存)
  42. useMsgFormats        = 使用信息格式(未知)
  43. msgTitleFormat       = 信息标题格式
  44. msgFormat            = 信息格式
  45. localChatRadius      = 当地信息交互(AAA协议)
  46. debug                = 调试模式
  47. alternateJarFile     = 备用的jar文件(建议留空)
  48. guestsCanViewComplex = 来宾可以查看(Complex好像是函数)
  49. ipAddress            = IP地址(建议留空)
  50. javaArguments        = Java参数
