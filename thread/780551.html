两个方法：
1.修改Groupmanager配置文件。（内有注释）
①下方为没有分开世界权限即所有开的新世界均继承父世界的权限组。
  1. mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds:
  16.           - users
  17.           - groups
复制代码

②下方为和楼主一样情况案例（来自配置文件注释），楼主如果想分权限按照这个来写就行。不想分按照①即可。
  1. #  world2:      (World2 将会拥有自己的独立设置)
  2.     #    world3:
  3.     #    - users    (World3 使用 world2 的 users.yml,但是使用自己独立的 groups.yml)
  4.     #    world4:
  5.     #    - groups   (World4 使用 world2 的 groups.yml,但是使用自己独立的 users.yml)
  6.     #  world5:
  7.     #    - world6   (这个世界使用从world5镜像过来的设置文件)
复制代码

2.将路径plugins/GroupManager/worlds/内的world文件夹内的  groups.yml和users.yml  复制到其他世界名字文件夹下。
作者: _皮蛋_    时间: 2018-2-9 21:01
groupmanager为例，当你生成新世界后，plugins\GroupManager\worlds下会生成一个名为新世界名的文件夹，里面包含的东西就不介绍了，把普通世界的groups.yml 以及user.yml丢进去覆盖之，/manload重载一下即可，当然，你也可以给不同的世界设置不同的权限。
