-SpecialHeads-

这款插件。。太逆天了。。
吓的屁滚尿流
能拿去任何头颅。。
甚至还能设置PVP[杀玩家]/PVE[杀生物]杀死掉落头颅[配置可以调整]
还能设置头颅掉落经验

命令与对应权限
/head help specialHeads.getHead帮助
/head extra specialHeads.getExtraHead 特殊头颅菜单
/head give specialHeads.getHead 给你自己头颅或者玩家头颅
/head info 无(即使有也没用。） 查看作者




最新版本的头颅:
Blaze=烈焰人的头
Cow=牛的头
其他的请自行百度！


推荐配合正版皮肤显示插件使用
点我跨越帖子

修复了玩家客户端看不见的原因(不见效果）

[fly]拿下别人的头威胁他[/fly]
记得点赞

具体的配置

# CONFIG FILE - [SpecialHeads - by arthurmaker]
dropPlayersHeads: true【是否PVP掉落头颅】
playersHeadChance: 10【PVP玩家头颅掉落概率】
{概率说一下,10=10%,1=1%以此类推}
giveExtraExpOnPlayerHead: false【这是。是玩家掉落头颅时给经液吗】
dropMobsHeads: false【掉怪物的头】
mobsHeadChance: 5【怪物头颅掉落概率】
