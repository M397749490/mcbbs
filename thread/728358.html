EpicMobs - 史诗怪物

插件特性:
  • 自由配置刷怪世界
  • 自由配置刷怪范围
  • 自由配置怪物掉落物
  • 指令添加掉落物
  • 可选是否限制原版部分功能
  • 自由配置怪物名字/血量/伤害

插件指令:
  • 管理员命令:
    /em additem <args> #将手上的物品添加至掉落物中(args不能重复, 物品标识)
    /em spawn <mobs_id> <mob_type>
    #在准心处生成一只史诗怪物, 必须是在mobs.yml内的!
    /em killall #清理本插件所生成的所有怪物
    /em reload #重载插件配置
    管理权限: em.admin
  • 玩家命令: 无

插件用法:
插件配置文件一共有三个,config.yml, item.yml和mobs.yml
item.yml不用去改，用命令添加物品就行了!

mobs.yml配置方法如下:
  1. text:
  2.   Name: "&b[&a一阶怪物&b]"
  3.   Distance: 50
  4.   Health: 50
  5.   Damage: 10
  6.   DropExp: 0
  7.   Drop: {}
复制代码
这是默认的一个怪物配置，可以复制然后粘贴，编辑自己所需的。
Name是怪物前缀，前提是你有在config.yml下的MobCustomName添加怪物名字!
例如: MobCustomName我加了个ZOMBIE:僵尸, Name为[Lv.10], 达成条件后，生成的怪物名字为: [Lv.10]僵尸, 条件就是范围，世界，还有有设置MobCustomName!
Distance是生成范围, 以世界重生点为中心点, 上面的配置是距离世界重生点50格内的怪物, 如果达成config.yml下的条件, 就会按这个配置来设定!
Health是怪物的血量, Damage是伤害, DropExp是死亡掉落的经验值!
Drop是掉落物，例如我加了个参数为frist的物品,
在Drop下加- "frist 1 100", 意思是, 100%掉落一个参数为frist的物品
在Drop下加- "frist 1-3 100", 意思是, 100%随机掉落1~3个参数为frist的物品

config.yml
  1. AllowWorld:
  2.   - "world"
  3. World:
  4.   world:
  5.     - "text"
  6. AllowType:
  7.   - "ZOMBIE"
  8. MobCustomName:
  9.   - "ZOMBIE:僵尸"
  10.   - "SLIME:史莱姆"
  11. Anti:
  12.   Monster: true
  13.   Animals: true
  14.   EntityDefaultDrops: true
  15.   EntityDefaultDropExp: true
复制代码
这是默认生成的config.yml, AllowWorld是允许生成史诗怪物的世界列表。
World是配置哪个世界允许生成哪些史诗怪物, AllowType是允许生成的怪物类型。
MobCustomName是怪物名字, 并不是生成后直接设置的名字, 看mobs.yml说的！
Anti下的Monster如果为true, 那这个世界会禁止除了允许的怪物类型之外的其他怪物的生成, Animals和Moster差不多, 但是只限制动物, 而不是怪物!
EntityDefaultDrops如果为true, 那史诗怪物不会掉落原版物品!
EntityDefaultDropExp如果为true, 那就不会掉落怪物原来掉落的经验!

大概的用法就是这样子, 给点人气不会扣自己的人气喔~
