OreAnnouncer


插件简介

OreAnnouncer是一个当玩家挖掘矿石（也能被设置为任何方块）时会发送公告的Minecraft服务器插件。它支持许多不同的功能，比方说通报坐标 (你还能隐藏或加密它们)。你也能设置是用它来通报给服主或是给所有的玩家。除此之外，本插件还支持光源检测，能在光照等级不足的情况下禁止玩家挖矿或者发送警报。

插件特性

特性
  • 可以通报每一个方块 (不只是矿物)
  • 可以仅仅列出某些坐标
  • 可以设成只有当玩家数大于X的时候才会通报坐标
  • 可以混淆坐标
  • 光照控制系统，可以在玩家无光挖矿的时候发送公告
  • 记录系统（[译者注]可以查看你不在的时候都有哪些人偷偷开挂挖矿）
外部特性
  • 重力更新器
  • 数据统计系统

指令

/oa help
  显示帮助页面
/oa hide  隐藏通报信息
/oa reload  重载配置文件

权限

oreannouncer.alertupdates
  允许接收更新提示
oreannouncer.bypass.announce
 当挖掘方块时不发送提示
oreannouncer.bypass.place
  当挖掘自己放置的方块时不发送提示
oreannouncer.cmd.help
  允许使用 /oahelp
oreannouncer.cmd.hide
  允许使用 /oahide
oreannouncer.cmd.reload
 允许使用 /oareload
oreannouncer.see
 可以看见通报的消息
oreannouncer.*
 包含插件所有权限

  32.   alert-wrong-messages: true
  33.   # [译者注]以下为光照系统，用于检测玩家是否在黑暗的地方挖矿，用来防夜视挂和矿透矿踪
  34.   # [译者注]貌似没有对夜视药水的支持……而且对动态光源很不友好
  35.   light-level:
  36.     # 是否启用光源系统
  37.     enable: false

  39.     alert-only-if-lower: true
  40.     # 是否防止玩家在低于设定的最大光照等级的情况下破坏方块
  41.     prevent-break: false
  42.   # 占位符:
  43.   # [译者注]在信息中可以使用
  44.   # %player% = 玩家名
  45.   # %lightlevel% = 方块的光照等级
  46.   # %number% = 矿石的总数
  47.   # %x%, %y%, %z% = x,y,z 坐标
  48.   # 光照等级: 当光照等级<="max-light-level"时发送警报, 100为每一次都会发送警报, 0则是只有完全黑暗时才发送警报
  49.   # [译者注]以下方块列表仅为示例，可以自行按照格式添加【任意方块】，可以不是矿物！
  50.   list:
  51.     DIAMOND_ORE:
  52.       max-light-level: 100
  53.       #[译者注]在这里设置提示消息！single和multiple可以分单复数……对于我们中国人来说没多大用吧23333
  54.       #[译者注]coordinates是带有坐标的提示格式
  55.       single: "&6%player% &e发现了 %number% 块钻石矿！"
  56.       multiple: "&6%player% &e发现了 %number% 块钻石矿！"
  57.       coordinates:
  58.         single: "&6%player% &e发现了 %number% 块钻石矿！. &7[x:%x%&7 z:%z%&7]"
  59.         multiple: "&6%player% &e发现了 %number% 块钻石矿！. &7[x:%x%&7 z:%z%&7]"
  60.     EMERALD_ORE:
  61.       max-light-level: 0
  62.       single: "&6%player% &e发现了 %number% 块绿宝石矿！"

  72. # / = = = = = = = = = = = = = = = = \
  73. # |            坐标设置             |

  75. coordinates:
  76.   # 当玩家凿方块的时候是否通报坐标

  78.   # 通报坐标时的最小玩家数(0=无论有多少人在线都会通报)
