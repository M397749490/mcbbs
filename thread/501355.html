今天我终于制作出了原版的登陆插件
并突破了无法禁止玩家输入指令的瓶颈
请看视频介绍

=================原理详解=================


首先是视频中已经讲过的限制玩家使用指令的方法
不断在玩家处放置/破坏一个地狱门
这里不多赘述，视频中演示很清楚了

这里主要讲获取玩家输入的密码
以及如何判定和存储的密码相同


分如下几个模块

1. 获取玩家输入
2. 给第一次进入服务器的玩家创建密码
3. 与存储的密码进行比较
4. 进行下一个循环


我们一个一个来
首先是创建所需要的计分板

  • /scoreboard objectives add passwd dummy 密码
    用于存储玩家的密码
  • /scoreboard objectives add passwdVerify dummy 密码验证
    用于暂时存储玩家输入的密码
  • /scoreboard objectives add passwdTime dummy 密码时间
    用于存储玩家已输入的密码的位数
  • /scoreboard objectives add passwdJoinGame stat.leaveGame 离开游戏
    用于检测玩家进入游戏 (这个判据会在玩家离开游戏时加一
    也就是说如果一个玩家这个计分板值为1 说明他刚刚进入游戏)



1. 获取玩家输入

这个很简单啦 基础指令

/scoreboard players add @a[score_passwdTime=6,score_passwdTime_min=1,score_passwdJoinGame_min=1]
passwdVerify 1 {SelectedItemSlot:0}
这个命令的意思是 当一个玩家要输入第1到第六位密码时(由score_passwdTime=6,score_passwdTime_min=1体现)
并且还未登陆(由score_passwdJoinGame_min=1体现)
并且选中第一个格子 让他的passwdVerify值加一


用这个原理将第1-8个格子穷举出来
这就是获取当前输入

那么进入下一个循环时 需要将已输入的密码向左移一位
也就是个位变成十位 十位变成百位...
例如:1->10    123->1230
翻译成 人话就是将原来的计分板值乘十 用到了opeartion

  • /scoreboard players set passwdTime passwdVerify 10
  • /scoreboard players operation @a[score_passwdTime=6,score_passwdTime_min=1,score_passwdJoinGame_min=1] passwdVerify *= passwdTime passwdVerify
如此两小部分即可获得玩家输入的密码

2. 给第一次进入服务器的玩家创建密码 (前提是玩家没有存储的密码)

  • /tellraw @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,score_passwd=0] {text:"",extra:["成功创建密码 请牢记"],color:gray}
    #输完六位就可以提示了
  • /scoreboard players operation @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,score_passwd=0] passwd += @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,score_passwd=0] passwdVerify
    #把已输入的密码加到原密码上

对判据的解释:
  • score_passwdTime=6,score_passwdTime_min=6 -> 已输完六位密码
  • score_passwdJoinGame_min=1 -> 玩家还未登陆
  • score_passwd=0 -> 玩家无存储的密码


3. 与存储的密码进行比较 (前提是玩家有存储的密码)
比较的最简单方法就是作差法
a>b <=> a-b=0
所以将玩家保存的密码与验证的密码相减即可 用到了operation

  • /scoreboard players operation @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,score_passwd_min=1] passwdVerify -= @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,score_passwd_min=1] passwd

  • score_passwdTime=6,score_passwdTime_min=6 -> 密码输完了第六位
  • score_passwdJoinGame_min=1 -> 玩家还未登陆
  • score_passwd_min=1 -> 玩家有存储的密码


然后就是对密码正确的玩家的处理
  • /tellraw @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,
    score_passwdVerify=0,score_passwdVerify_min=0,score_passwd_min=1] {text:"密码正确",color:gray}
    #提示
  • /tp @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,
    score_passwdVerify=0,score_passwdVerify_min=0,score_passwd_min=1] @e[name=spawn,type=ArmorStand,c=1]
    #传送
  • /scoreboard players reset @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,
    score_passwdVerify=0,score_passwdVerify_min=0,score_passwd_min=1] passwdJoinGame
    #将他标记为已登录

对密码错误的玩家的处理
  • /tellraw @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,
    score_passwdVerify=-1,score_passwd_min=1] {text:"密码错误",color:gray}
    #提示
  • /tellraw @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,
    score_passwdVerify_min=1,score_passwd_min=1] {text:"密码错误",color:gray}
    #提示
  • /scoreboard players set @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,
    score_passwdVerify=-1,score_passwd_min=1] passwdTime 0
    #将他输入的密码位数置为零
  • /scoreboard players set @a[score_passwdTime=6,score_passwdTime_min=6,score_passwdJoinGame_min=1,
    score_passwdVerify_min=1,score_passwd_min=1] passwdTime 0
    #将他输入的密码位数置为零
  • /scoreboard players set @a[score_passwdTime=0,score_passwdTime_min=0,score_passwdJoinGame_min=1,
    score_passwd_min=1] passwdVerify 0
    #重置他已输入的密码



4. 进行下一次循环

  • /scoreboard players add @a[score_passwdTime=6,score_passwdJoinGame_min=1] passwdTime 1
    #给所有玩家输入位数加一
  • /tellraw @a[score_passwdTime=6,score_passwdJoinGame_min=1] {text:"",extra:["请输入密码第",{score:{name:"*",objective:"passwdTime"},color:red},"位:"]}
    #提示

然后给未登陆的玩家状态效果
  • /gamemode 2 @a[score_passwdJoinGame_min=1,m=1]
  • /tp @a[score_passwdJoinGame_min=1] @e[name=passwd,type=ArmorStand,c=1]
  • /effect @a[score_passwdJoinGame_min=1] minecraft:slowness 5 10 true
  • /effect @a[score_passwdJoinGame_min=1] minecraft:jump_boost 5 250 true
  • /effect @a[score_passwdJoinGame_min=1] minecraft:regeneration 5 10 true


整个流程就结束了
所有指令会在百度网盘中发出
