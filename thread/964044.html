这个直接按照wiki或MCBBS的教程写就成了。。。
在地图的data/advancements文件夹里建一个新的文件夹，改成你想要的名字，然后如果你只要这一个进度，把它的文件名记为root.json
或者可以建一个和原版进度文件夹名（adventure、end、husbandry、nether、recipes、story）相同的文件夹，在里面随便命名一个.json文件
实在看不懂可以抄借鉴一下原版进度
比如说下面这个
  1. {
  2. "parent": "minecraft:adventure/root",
  3. "display": {
  4. "icon": {
  5. "item": "minecraft:red_bed"
  6. },
  7. "title": {
  8. "translate": "advancements.adventure.sleep_in_bed.title"
  9. },
  10. "description": {
  11. "translate": "advancements.adventure.sleep_in_bed.description"
  12. },
  13. "frame": "task",
复制代码
如果你是新开的文件夹，删掉parent字段，如果你是在原版文件夹上新增，就把parent后面的值改为该文件夹内的任一你需要的进度
可以把display里的参数换成你要的内容
然后既然你要用命令给予进度，就把criteria里改成impossible好了
然后删掉requirements字段
最后就像这样：（假设进度位于地图存档/data/advancements/a/root.json）
  1. {
  2.   "display": {
  3.     "icon": {
  4.       "item": "minecraft:gold_block"
  5.     },
  6.     "title": {
  7.       "text": "体谅作者",
  8.           "color":"blue"
  9.     },
  10.     "description": {
  11.      "text": "体谅作者",
  12.          "color":"blue"
  13.     },
  14.     "frame": "task",
  15.     "show_toast": true,
  16.     "announce_to_chat": true,
  17.     "hidden": false
  18.   },
  19.   "criteria": {
  20.     "a": {
  21.       "trigger": "minecraft:impossible"
  22.     }
  23.   }
  24. }
复制代码
然后在命令方块输入：
advancement grant @p only a/root
题外话：1.11之前的成就不能自定义，现在的进度显示格式是：“进度已达成！”，下一行显示title里的内容
(没开游戏实测，手残勿喷)

我暂时认为这个是一个根进度吧（一个进度页面最左侧的进度为根进度，需要指定backgroung，进度页面的底面）
对于非根进度，需要指定parents标签，即父进度，详见wiki
以你说的这个进度为例
{
  "display": {
    "icon": {
      "item": "minecraft:gold_block"
    },
    "title": {
      "text": "体谅作者！"
    },
    "description": {
      "text": "这里写介绍"
    },
    "frame": "task",
    "show_toast": true,
    "announce_to_chat": true,
    "hidden": false,
    "background": "minecraft:textures/block/quartz_block_top.png"
  },
  "criteria": {
    "a": {
      "trigger": "minecraft:impossible"
    }
  }
}
