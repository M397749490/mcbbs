============ 非凡RPG 3.X 转换工具介绍 ============
最后更新于: 2019/01/18

!!! 请仔细阅读整个介绍以避免任何本可以避免的问题 !!!


需要:
- 非凡RPG 3.9.x
- 非凡RPG 插件文件夹
- Spigot 服务器

无法转换的模块:
- 隔绝宝石 (在 4.0 中移除)
- 能力宝石 (在 4.0 中移除)
- 非凡附魔 (在 4.0 中移除)
- 掉落物
- 祝福粉末
- 自定义物品
- 修复系统
- 分解系统

注意事项:
- !!! 不要复制非凡RPG插件文件夹中除了'CONVERTED_DATA'文件夹的其他任何数据 !!!
- 转换过程中可能遇到一些小错误 (比如1.12的物品名不会转换到1.13).
- 如果你不是初次对这些数据使用这个工具, 请确保已经删除了旧的 'CONVERTED_DATA'(转换数据) 文件夹!!!


转换步骤:
0. 在配置中启用所有你想转换的模块.
1. 如果你安装了非凡RPG插件, 请先在/plugins/文件夹中删掉它.
2. 如果你安装了量子RPG(非凡RPG 4.0版本的新名字)插件, 请先在/plugins/文件夹中删掉它.
3. 将 DI-ConvertTool 安装到/plugins/文件中.
4. 启动服务器.
5. 在控制台中观察服务器运行状态.
6. 如果一切运行良好, 检查非凡RPG插件文件夹中是否有一个名为 'CONVERTED_DATA'(转换数据) 的新文件夹.
7. 如果你没有现存的量子RPG插件文件夹, 那就安装到/plugins/文件夹中, 然后重启服务器来创建一个.
8. 在 'CONVERTED_DATA'(转换数据) 文件夹中(第6步) 有一个 'modules'(模块) 文件夹. 关闭服务器. 复制粘贴到量子RPG的插件文件夹中.
9. 启动服务器看看一切是否良好. 大功告成.

在所有模块都测试过一遍了, 没有发现 bugs/错误 . 如果你遇到了什么问题 - 请在Discussion页面报告.

Extra: 制作一个自定义物品 (18.10.5)


尽管有了Wiki，还是有很多人不知道怎么做一个RPG物品，看到这么多的指令觉得无从下手，所以写了这篇Extra来讲讲我是怎么做一个自定义物品的。

准备工作
/di customitems - 自定义物品模块.
/di modify - 物品信息修改.
/di set - 物品属性设置.

制作一个自定义的非凡RPG物品大约就需要这三个模块的指令.
/di modify - 这个是最开始做的工作，用于修改物品名字和添加一些装饰性的Lore.
/di set - 这个是主要做的工作，给物品添加/设置属性值，还有安排槽位.
/di customitems - 这个是最后做的工作，保存为自定义物品以便以后获取.

工作过程
第一步: 安排格式
就是喜欢搞一些花里胡哨的东西，我一般做RPG物品会参照原本的格式，如果你想做的特色一点也可以.
  • /di modify name <名字> - 更改物品的显示名.
  • /di modify lore add [字符串] [行数] - 添加Lore.
  • /di modify lore del [行数] - 删除Lore.
  • /di modify lore clear - 清空Lore.
  • /di modify flag add  - 添加一个物品标识.
  • /di modify flag del  - 删除一个物品标识.
  • /di modify nbt add  <值> - 添加一个NBT标签.
  • /di modify nbt del  - 删除一个NBT标签.
  • /di modify enchant <附魔> <等级> - 附魔物品.
  • /di modify potion <效果> <等级> <持续时间> [范围] [粒子] [R,G,B] - 修改药水效果.
  • /di modify eggtype <实体类型> - 更改刷怪蛋的类型.
  • /di modify color  - 更改皮革甲的颜色.

  • 使用/di modify name修改物品名字
  • 使用/di modify lore add添加不是属性的装饰用Lore(或者是武器介绍啊什么的)。
  • 使用/di modify flag add添加一些物品标识
    • 一般添加的有:
      • HIDE_ATTRIBUTES - 隐藏那些"在主手上: 7伤害"这样的东西.
      • HIDE_ENCHANTS - 隐藏附魔内容，这样只能看到附魔的光辉.
      • HIDE_UNBREAKABLE - 隐藏不可破坏标志.
    • 你可以在这里找到所有可用的物品标识.
  • 如果你还想要修改别的那就是你自由发挥了~

第二步: 设置属性
这一段就要用设置属性相关的指令了.
  • /di set attribute <属性> <值> <第二值> [行数] - 设置物品的属性.
  • /di set bonus <属性> <值> [行数] - 设置物品的属性增益.
  • /di set level <数字> [行数] - 设置物品的等级需求.
  • /di set class <职业壹,职业贰,以及其他> [行数] - 设置物品的置业需求.
  • /di set ability <能力> <等级>   <冷却> [行数] - 添加一个能力到物品上.
  • /di set damagetype <伤害种类> <数量> [行数] - 设置物品的伤害类型.
  • /di set armortype <防御种类> <数量> [行数] - 设置物品的防御类型.
  • /di set ammotype <子弹种类> [行数] - 设置弓的子弹类型.
  • /di set slot <插槽种类> [行数] - 添加一个空插槽到物品上.

  • 使用/di set damagetype设置伤害类型
    • 有6种伤害类型:
      • Physical - 物理伤害
      • Magical - 魔法伤害
      • Water - 水属性伤害
      • Wind - 风属性伤害
      • Fire - 火属性伤害
      • Potion - 毒属性伤害
    • 不同的属性能造成一些特殊效果，这些东西不在这里细讲，我会再写一篇Extra来介绍的.
    • 与之对应的还有/di set armortype设置防御类型(属性抗性).
  • 使用/di set attribute和/di set bonus设置属性
    • 有24种物品属性(剔除防御类型):
      • DIRECT_DAMAGE - 真实伤害, 无视护甲.
      • AOE_DAMAGE - 范围伤害.
      • PVP_DAMAGE - PvP附加伤害.
      • PVE_DAMAGE - PvE附加伤害.
      • DODGE_RATE - 躲避敌人攻击的纪律.
      • ACCURACY_RATE - 减少攻击被躲避的几率.
      • BLOCK_RATE - 格挡敌人攻击的几率.
      • BLOCK_DAMAGE - 格挡敌人攻击的伤害百分比.
      • LOOT_RATE - 增加掉落率.
      • BURN_RATE - 点燃敌人5秒的几率.
      • PVP_DEFENSE - PvP附加防御.
      • PVE_DEFENSE - PvE附加防御.
      • CRITICAL_RATE - 造成暴击的几率.
      • CRITICAL_DAMAGE - 暴击伤害倍数.
      • DURABILITY - 物品耐久.
      • DURABILITY_UNBREAK - 物品不可损坏.
      • MOVEMENT_SPEED - 提升移动速度.
      • PENETRATION - 护甲穿透.
      • ATTACK_SPEED - 提升攻击速度.
      • VAMPIRISM - 一定数量的伤害值将转变为治疗.
      • MAX_HEALTH - 增加最大生命值.
      • BLEED_RATE - 使敌人流血的几率.
      • DISARM_RATE - 缴械几率.
      • RANGE - 增加攻击范围.
  • 使用/di set slot来添加槽位
    • 有四种槽位(可能带s(pl.)太久没做我忘记了):
      • Gem
      • Ability
      • Enchant
      • Rune
  • 自由发挥时间~(比如设置等级要求和职业要求)

第三步: 保存物品
  • /di customitems get  <数量> - 获取一个指定的自定义物品.
  • /di customitems give <玩家>  <数量> - 给予玩家一个自定义物品.
  • /di customitems drop <世界>     <数量> - 在世界的某处掉落一个自定义物品.
  • /di customitems save <名字/路径> - 保存手上的物品为一个自定义物品.
  • /di customitems delete <名字/路径> - 删除一个自定义物品.
  • /di customitems list - 列出所有自定义物品.

使用/di customitems save保存物品.
以后就可以通过/di customitems get来获得物品.

  1. HIDE_PLACED_ON
复制代码

  1. HIDE_POTION_EFFECTS
复制代码

  1. HIDE_UNBREAKABLE
复制代码
▲设置显示/隐藏不可破坏属性.
