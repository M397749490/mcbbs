☆MoodTitle|心情称号☆
放飞自我表达心情！让聊天有更多乐趣~~
插件由来:
   被高温天气热到不想说话，聊天时想分享给别人我现在的状态~

☆简介☆
*这个插件的称号都是以包计，当然，你也可以一个包里只加一个称号~~
什么叫心情？喜怒哀乐，当前状态，做什么事，意愿和愿望
心情多种多样、夏天有身处夏天的心情，春天有身处春天的心情……

☆插件要求☆
游戏版本：理论全版本，测试版本1.12.2
插件版本：1.0
服务端核心: spigot
必须前置: PlaceholderAPI 站内帖 点我跳转
附: 另外还需要支持papi的聊天插件 如MiaoChat(免费)跳转、DeluxeChat(付费)等等
*发挥 如无则删除或修改

配置文件:
*配置文件有 玩家数据文件 、称号库文件 、消息文件
titles.yml

titles.yml

message.yml

message.yml

  2. # gui显示
  3. gui:
  4.   # 主界面名称
  5.   maingui: '&b心情库'
  6.   # 次界面名称
  7.   gui: '&b心情库'
  8. # 格式
  9. format:
  10.   contains: '&7&m          &e[&a{0}&e]'
  11.   titlePackageFirst: '&7&m==========&a前缀内容&7&m=========='
  12.   titlePackageSecond: '&7&m==========&b后缀内容&7&m=========='
  13. # 消息如题
  14. message:
  15.   clearprefix: '&7你成功取消了前缀心情！！'
  16.   clearsuffix: '&7你成功取消了后缀心情！！'
  17.   setprefix: '&a你成功设置了前缀心情 {0} &a快发个消息表示一下吧！！'
  18.   setsuffix: '&a你成功设置了后缀心情 {0} &a快发个消息表示一下吧！！'

聊天插件配置使用方法，以MiaoChat为例，具体的使用请参阅miaochat帖子
Format.yml


  2. Format.yml
  3. player: # 前缀 名称 后缀
  4.   text: '%mt_prefix%&b%player_name%%mt_suffix%'
  5.   tip:
  6.   - ''
  7.   - '&7点击与我聊天'
复制代码


插件命令:
/moodtitle(mt) open 无权限 打开主界面，仅限玩家打开
/moodtitle(mt) reload 权限moodtitle.reload 重载

插件PlaceholderAPI 变量:
%mt_prefix% 前缀称号
%mt_suffix% 后缀称号
