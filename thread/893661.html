介绍 · Introduction
Racing这款插件无需修改配置即可让你的玩家参加各种竞赛。用于举办活动的话这款插件可谓是不二之选.
特点
无需修改配置 | 6种竞赛类型 |支持多场竞赛|支持圈数 | 关联mcMMO | 支持所有载具
关联NoteBlockAPI  | 竞赛药水效果 | 支持多语言 | 开源 | 使用Vault收取入场费 | 关联Discord
告示牌入场 | 开源 | 在竞赛时禁用指令 | 竞赛奖励 | 全息排行榜 | 支持多语言
前置
  • ProtocolLib
  • HolographicDisplays (可选, 用于在创建竞赛时显示提示)
  • NoteBlockAPI(可选, 在竞赛时播放音乐)
  • Vault (可选, 扣除入场费)
  • 赛车需要如Carz或Ucar这类能直接操控矿车的插件
安装
  • 下载JAR文件并放入插件文件夹内
  • 确认你拥有管理员权限或 racing.admin 权限
  • 输入 /rc create <名称> 创建竞赛
  • 输入 /rc start <名称> 开始竞赛


示例

/rc create boat  - 创建竞赛
/rc settype boat boat - 更改竞赛类型为赛艇
/rc addspawnpoint boat - 设置起点（可设置多个起点）

权限
  • racing.admin - 管理员权限.
  • racing.modify - 修改竞赛的权限.
  • racing.moderator - 可以开始/停止 竞赛.
  • racing.player - 可以参加竞赛 (玩家默认拥有该权限).
指令
建造赛场

  • /rc create <race> - 创建竞赛
  • /rc delete <race> - 删除竞赛
  • /rc addcheckpoint <race> - 添加记录点
  • /rc deletecheckpoint <race> <位置> - 删除记录点
  • /rc tpcheckpoint <race> <position> - 传送到记录点
  • /rc addstartpoint <race> - 添加起点
  • /rc deletestartpoint <race> <位置> - 删除起点
  • /rc tpstartpoint <race> <位置> - 传送到起点
更改竞赛属性

  • /rc setspawn <race> - 设置竞赛传送点
  • /rc setname <race> <名称> - 设置竞赛名
  • /rc setstate <race> <状态> - 状态可以为 enabled·开启|disabled·关闭|under_construction·维护中
  • /rc settype <race> <类型> - 类型可以为 player·赛跑|horse·赛马|pig·赛猪|elytra·鞘翅飞行|boat·赛艇|minecart·赛车
  • /rc setsong <race> <音乐名> - 设置竞赛音乐
  • /rc setentryfee <race> <费用> - 收取入场费
  • /rc setwalkspeed <race> <speed> - 修改行走速度，默认的行走速度为 0.2
  • /rc unsetsong <race> - 取消竞赛音乐
  • /rc playsong <song> - 播放音乐 (用于测试)
  • /rc stopsong - 停止播放中的音乐 (用于测试)
  • /rc addpotioneffect <race> <药水效果> <强度> - 竞赛时的药水效果.
  • /rc removepotioneffect <race> <药水效果> - 删除药水效果.
  • /rc clearpotioneffects <race> - 删除竞赛的所有药水效果
开始和停止竞赛

  • /rc start <race> - 开始竞赛
  • /rc start <race> [laps] - 以指定圈数开始竞赛
  • /rc startrandom - 随机开启一个竞赛
  • /rc stop <race> - 停止竞赛
  • /rc skipwait <race> - 跳过竞赛开场等待时间
  • /rc leave - 离开竞赛
  • /rc join <race> - 加入竞赛
其他指令

  • /rc reload - 重载插件.
  • /rc list - 列出所有竞赛
  • /rc spawn <race> - 传送到竞赛传送点.
  • /rc info <race> - 查看竞速信息
