在这个长方体中，点I是中心点，点P是你要测试的点。你只需要计算出从点I到点P的方向向量，就能知道这个点是否在区域内。
公式：
I=(D+F)/2
V=P-I
Px = |V*Xlocal|
Py = |V*Zlocal|
Pz = |V*Zlocal|

只要满足：
2*Px<=Xlength,
2*Py<=Ylength,
2*Pz<=Zlength,

点就在区域内

然后对于单个立方体输入(x1,y1,z1)与(x2,y2,z2)，我们在输入时将其处理为一个最小点(minX, minY, minZ)和一个最大点(maxX, maxY, maxZ)，然后编写contains(double x, double y, double z)方法，该方法的实现也非常简单：

  1. public boolean contains(double x, double y, double z) {
  2.     return x >= minX && x <= minY && y >= minY && y <= maxY && z >= minZ && z <= maxZ;
  3. }
