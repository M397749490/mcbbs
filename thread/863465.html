兼容模组服， 已测试的有Spigot1.6.2、Spigot1.13.2、1.14 、1.16.X、Uranium端、KC端
兼容1.6.X以上版本，向上兼容

命令：
/fh reload 重载配置
/fh list 查看哪些世界被屏蔽了/fh set 消耗自己的饥饿度（方便测试插件效果）
/fh add [世界名] 屏蔽一个世界（不填写世界名默认为当前世界）
/fh del [世界名] 取消屏蔽一个世界（不填写世界名默认为当前世界）
/fh ps 开/关玩家查看屏蔽世界的权限(默认开启)
配置文件：config.yml
屏蔽某些世界的话在config.yml配置文件中的shieldWorldList，这些世界将不会被插件监听，故此死亡后饥饿度与原版机制一致。
  1. # true表示玩家可以输入/fh list来查看被屏蔽的世界
  2. playerIsShow: true
  3. # 屏蔽的世界，插件将不会监听这些世界，一个都没有的话将会监听所有世界
  4. shieldWorldList:
  5.   - world
  6.   - zc
复制代码


如上配置的话world和zy世界死亡后饥饿度与原版机制一样，本插件不会做监听。如果以上配置文件中没有你所包含的世界名字，那么没有被包含的世界就会被本插件监听，进而控制复活时的饥饿度。
世界默认就不支持中文名字吧，所以这个编码就没有啥要求了，爱咋玩就咋玩。嘻嘻
