搜噶~那你知道怎么设置领地圈地面积大小嘛= =

找到服务端内的插件文件夹   打开：“Residence|  找到config.yml   

搜索：”MaxAreasPerResidence: 2“

然后把
  1. MaxAreasPerResidence: 2
  2.            # The maximum number of blocks a Residence can be, East to West (X).
  3.            MaxEastWest: 256
  4.            # The maximum number of blocks a Residence can be, North to South (Z).
  5.            MaxNorthSouth: 256
  6.            # The maximum number of blocks a Residence can be, High to Low (Y).
  7.            MaxUpDown: 256
复制代码
不是256的改为256就OK了   {:10_512:}
