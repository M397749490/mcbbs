如题，1.8有一个功能是替选方块，可以实现材质包中一块多图，也就是可以实现一个方块放下时伪随机材质，但是后续在1.9里移除了替选方块
我的问题是1.9移除了这个选项，那这个随机方块贴图是不是就在后续版本无法用了啊，后续版本有办法实现一块多图吗
作者: GeForceLegend    时间: 2020-6-9 16:03
实际上可以通过修改方块状态文件实现此类效果，原版就可以做到。
方块状态文件的格式以及修改参考WIKI
需要做的就是先制作各个贴图不一样的方块模型，然后再在方块状态文件中写入以随机引用，同时可以修改各个模型的权重。
例如想要给石头弄一个替选模型，石头的方块状态文件如下：
  1. {
  2.       "variants": {
  3.             "": [
  4.                   { "model": "block/stone" },
  5.                   { "model": "block/stone_mirrored" },
  6.                   { "model": "block/stone", "y": 180 },
  7.                   { "model": "block/stone_mirrored", "y": 180 }
  8.             ]
  9.       }
  10. }
复制代码
原版的方块状态文件中stone.json、stone_mirrored.json以及这两个模型绕y轴旋转180°得到的模型，总计4个，在游戏中被随机引用。
假设我们弄的替选贴图的名称为stone2.png，我们可以在models/block下新建一个stone2.json，内容如下
  1. {
  2.       "parent": "block/cube_all",
  3.    "textures": {
  4.             "all": "block/stone2"
  5.       }
  6. }
复制代码
然后在方块状态文件中添加刚才新建的模型
  1. {
  2.       "variants": {
  3.             "": [
  4.                   { "model": "block/stone" },
  5.                   { "model": "block/stone_mirrored" },
  6.                   { "model": "block/stone", "y": 180 },
  7.                   { "model": "block/stone_mirrored", "y": 180 },
  8.                   { "model": "block/stone2 },
  9.                   { "model": "block/stone2", "y": 180 }
  10.             ]
  11.       }
  12. }
复制代码
这样游戏就会在石头上随机使用原版贴图和stone2.png了，只不过因为没有调整权重，stone2只有三分之一的概率被使用。

如果你想弄个stone2_mirrored也可以，不过stone2_mirrored需要修改父模型为block/cube_mirrored_all
想要修改权重的话，以{ "model": "block/stone" }为例，修改为{ "model": "block/stone", "weight" = 2 }可以使这个模型被使用的几率增大。没有weight的模型默认weight为1，分权重除以总权重就是这个模型被引用的概率
