CONF 配置文件
BanSave.yml
封禁玩家保存的名单
  1. # 罪人名单
  2. # 被封禁的人都保存到这里
  3. # 玩家ID:解封需要的权限
复制代码

Permission.yml
保存权限的配置
  1. # 注: 因为我太菜了，所以搞不了游戏内配置
  2. # 编号:
  3. # FatherPer: 权限
  4. # SonPer: 权限
  5. Test:
  6.   FatherPer: test.f
  7.   SonPer: test.s
复制代码

Lang.yml
语言配置
  1. # 版本号 勿动
  2. version: 1.0
  3. # 成功封禁玩家时
  4. succeed: "&a成功封禁该玩家."
  5. # 没权限封禁
  6. noper: "&c您无法封禁该玩家，原因：该玩家不能被您封禁."
  7. # 想封禁op时
  8. isop: "&c您想封禁op？"
  9. # 发给被封禁但没有被封禁成功的玩家
  10. warn: "&c刚刚有人想封禁你，幸好Ta充的不够多."
  11. # 被封禁的玩家被踢出时的消息
  12. banned: "&c哦吼，您被封禁了."
  13. # op被封禁时，欲解封
  14. opban: "&c人家是op都能被ban，你以为这是你能解除的吗？"
  15. # 没有权限解禁
  16. nopertounban: "&c你没有权限解禁."
  17. # 解禁
  18. noban: "&a已解除该玩家的封禁啦!"
  19. # 别人被封禁时进来的消息
  20. ban: "&c你已被封禁!"
