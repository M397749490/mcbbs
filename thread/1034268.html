如何获取玩家最后受到攻击的时间
作者: Ling_Haner    时间: 2020-4-30 19:45
本帖最后由 Ling_Haner 于 2020-4-30 19:57 编辑

全局变量
HashMap<UUID,Long> times = new HashMap<UUID,Long>()

public void onDamage(EntityDamageByEntityEvent event)
{
  if(event.getEntity() instanceof Player)
    {
      times.put(entity.getUniqueId(),System.currentTimeMillis());
    }
}
这样 times里就存储了最后一次伤害的时间
