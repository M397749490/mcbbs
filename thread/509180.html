大家好，这里是D`Y`O，今天给大家带来一篇有关《gps的简单使用》教程~~
华丽丽的分割线~~

gps作为定位系统，已经应用于国防，航天，甚至于平民百姓当中(废话……)

电脑mod中的gps系统由服务器和用户组成。
我们知道现实中gps由卫星来定位，一颗卫星是定位不了的，至少要3颗卫星才能定位。

同样的，cc中需要4台电脑作为定位服务器（o,x,y,z）才能定位。这4台电脑必须装上无线modern。

然后给上图中指着的电脑输入 gps host 0 0 0



然后分别给另外3个电脑输入相应的坐标
如我输入的是
gps host 3 0 0
gps host 0 3 0
gps host 0 0 3

然后给一台带无线的turtle写下面的程序：
  • --程序名:gps
  • rednet.open("right")
  • print("rednet open")
  • print("Man I am so lost right now!")
  • local x, y, z = gps.locate(5)
  • if not x then --if gps.locate didn't work, it won't return anything. So check to see if it did.
  •    print("Failed to get my location!")
  • else
  •    print("I am at (" .. x .. ", " .. y .. ", " .. z .. ")") --This prints 'I am at (1, 2, 3)' or whatever your coordinates are
  • end



运行程序gps

定位成功了，坐标是(4,5,0)

如果你放了第5台服务器，可以直接使用gps host命令，会自动从另外4台服务器获得坐标



这篇教程就此结束，觉得好的给点金锭和人气吧~~
