TimeChat插件会把当前时间加在每条聊天信息前面 所以你们可以看到每条信息的发送时间 这是我的第一个插件希望你们喜欢！

TimeChat prefixes the current time for each chat message so you can see when a message has been sent! This is my first plugin and I hope you like it!
If you feeling generous and want to donate, you can do so here. It would mean a lot to me!

结论：前缀均为独立的 需要在两个插件的配置文件分别修改

指令:
  • /TimeChat - 显示帮助指令
  • /TimeChat setformat - 设置时间显示样式
  • /TimeChat SetTimeZone - 设置时区
  • /TimeChat Reload - 重载配置


权限:
  • timechat.setformat - 设置时间显示样式的权限
  • timechat.settimezone - 设置时区的权限
  • timechat.reload - 重载配置的权限

配置:
设置时间显示格式:
你可以用彩色代码(例如:&a)来装饰你的时间显示!
例如: '[%hour%:%min%:%sec%] <%player%>: %msg% '

设置时区:常用时区代号:
  • 重庆:Asia/Chongqing
  • 哈尔滨:Asia/Harbin
  • 香港:Asia/Hong_Kong
  • 澳门:Asia/Macao
  • 上海:Asia/Shanghai
  • 中国:测试后发现时间不准确

没找到你需要的时区代号？
时区代号一览：http://dev.bukkit.org/bukkit-plugins/timechat/pages/all-the-time-zones-available/

变量:
%hour% - 显示小时%min% - 显示分钟
%sec% - 显示秒
%daysmonth% - 显示今天是这个月的第几天
%daysyear% -显示今天是今年的第几天.以上两条信息感谢@andylizi @ybw0014 的汉化建议
%month% - 显示月份
%year% - 显示年份
%player% - 显示玩家的名称
%msg% - 显示聊天信息
