首先，我们需要下载askyblock插件和askyblockEX插件还有vault1.4.1以上版本和java8运行环境（不用java8部分功能报错）



askyblock：主体插件生成空岛的
askyblockEX：是空岛保护加强，对mod容器保护更好（主要没权限玩家可以使用mod容器，有这插件后不怕玩家没权限使用）
vault：经济插件，注意只能使用这个经济插件，其他经济插件无效！

由于楼主给大家都准备好了的：https://pan.baidu.com/s/1nwyiuuP
下载后是个压缩包，打开解压三个插件，加入服务器，然后删除旧经济插件(如果有的话)，插件自带汉化（windows代码，linux系统自行转码）请大家等待一下我们即将设置空岛为主要世界

问1为什么切换世界会清理背包
答：请确实config中的这两个配置是取消
   # Reset Challenges - if this is true, player's challenges will reset when they
   # reset an island or if they are kicked or leave a team. Prevents exploiting the
   # challenges by doing them repeatedly.
   resetchallenges: false

   # Reset inventory - if true, the player's inventory will be cleared when they start
   # or restart and island. Default is true.
   # Note: if you have MultiInv running or a similar inventory control plugin, that
   # plugin may still reset the inventory when the world changes.
   resetinventory: false

问2为啥在空岛死亡后无限掉虚空
答：可能你没有正确设置空岛的出生位置，请在空岛config中找到这行
   # Allow /island teleport when falling. If set to false, all teleporting is
   # disabled until death from the void or until you hit something.
   # See commands that this will block too
   # Using "*" (with quotes) will block ALL commands when falling
   allowfallingteleport: false
   blockingcommands:
   - home
   #- anotherCommand
   #- andAnotherOne
   #- "*"
把allowfallingteleport: true设置这样就可以了（是设置为true）

问3为啥空岛开久了会有报错
答：可能热力膨胀mod造成的，你需要每天定时清理怪物

问4空岛需要哪些mod
答：我认为需要工业，拔刀，神秘，热力膨胀，通用机械，植物魔法，AE（不知bug请不要加），龙之研究，无中生有（没有他就没矿石了！），星辉，等

问5为啥没使用熔岩桶权限
答：你需要在essentials你面解除熔岩桶的ban

问6为啥默认是最多3个玩家一起在空岛生存呢，能不能加大
答：可以的，权限askyblock.team.maxsize.数字
数字可以设置20，也可以15，总之不能设置1-2否则会出问题
