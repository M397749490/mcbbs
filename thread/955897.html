开始

安装Oraxen

安装Oraxen非常简单!你只需要将Oraxen.jar与ProtocoLib.jar拖放至你的/plugins/ 目录下再重启服务器即可开始使用Oraxen

注意：Oraxen仅在PaperSpigot与Spigot 1.14+进行过环境测试，其余版本自行测试

你当然可以不使用ProtocoLib，但可能会因此失去部分功能支持

常见问题

Q：Oraxen是模组吗? A：Oraxen并非模组.而是Minecraft服务端插件，它允许你使用材质包添加新的物品，方块和其他的小玩意儿

Q：Oraxen只能使用它自带的材质包吗?我可以使用自己的吗? A：如果你是玩家。Oraxen使用的材质包不会替换任何原版物品，所以你依然可以使用自己的材质包。   如果你是服主。你需要将自己的材质包集成至Oraxen的材质包中(只需将文件拖放到Oraxen的/pack/文件夹中)或将Oraxen材质包和你的材质包整合在一起(但你每次都要这么做，这很麻烦)

Q：我想向Oraxen提出建议/问题 A：登录github并将建议/问题提交至官方仓库：git.io/oraxen

给别人物品

给玩家Oraxen物品。如果此命令所指定的目标玩家背包已满，物品将掉落在他的脚下

使用

  1. /o give <物品> # 将一个物品给予你自己
  2. /o give <玩家> <物品> # 将一个物品给予玩家
  3. /o give <玩家> <物品> <数量> # 将一定数量的物品给予玩家

创建合成配方

这个命令允许你直接使用配方生成器将新配方添加至配置中。有关它的更多信息，参见配方

使用

  1. /o recipes open <配方类型> # 创建并打开指定配方类型的配方生成器
  2. /o recipes open # 打开你已创建的配方生成器
  3. /o recipes save <名称> # 将你的配方以一个名称进行保存
  4. /o recipes save <名称> <权限> # 与上条指令相同，但加上了权限限制
复制代码

权限

oraxen.command.recipes # 允许你通过 /o recipes 指令创建合成配方

插件重载

这个插件允许你以一种非常快捷且无bug的方式重新加载oraxen的配置文件(欢呼吧！你再也不需要用类似Plugman,Yum的插件重新加载oraxen啦！)然而需要注意的是，自定义配方不能使用该指令重新加载。

使用

  1. /o reload # 重新加载物品配置文件，重新生成材质包并上传
  2. /o reload items # 重新加载物品配置文件
  3. /o reload pack # 重新生成材质包并上传

合成配方

众所周知，Minecraft拥有工作台中的无序、有序、以及熔炉等一些配方种类，它们非常有趣

有序：以一种固定的配方制作物品，例如剑，盔甲
无序：以不固定的配方制作物品，例如发酵蛛眼
熔炉：在熔炉中烧炼物品，例如铁矿石

但Oraxen目前仅支持设置有序配方

如何创建一个配方？

你可以在上文创建合成配方看到所有需要的命令及权限

第一步：打开一个配方创建界面

首先使用/o recipes open 打开有序配方创建界面,这将打开一个工作台： 然后将材料放在左边，将成品放在右边

该死，我忘记带上一种材料,我此时可以关闭背包吗?

当然，你随时都可以关闭背包，要重新打开编辑界面。只需要输入/o recipes open,你会发现原来的物品还保存着

我好了，怎么加载它？

你必须注册你的配方。你必须为配方想好一个名字，然后使用命令/o recipes save 名字 权限(可选)进行保存。然而Oraxen目前尚不知道如何在游戏中加载这些配方，所以你有必要重启服务器对此进行加载

我该如何编辑我的配方？

你可以在含有配方类型的名称的文件名中(例如shaped.yml)编辑它,找到你的配方并更改其材料，成品或者权限。

了解基础

如您所见，Oraxen可以生成自定义物品以及它们的材质包。Oraxen还可以为它们绑定机制。

Oraxen文件结构



全局配置

在配置文件夹的根目录中，您会找到两个文件： settings.yml，其中包含有关Oraxen的各种设置 mechanics.yml，其中包含全局机制设置

物品配置

这个子文件夹含有您创建的所有物品。您可以在任何文件中创造一个新物品，甚至可以创建新文件或删除现有文件： 您还可以在单个文件中进行所有操作，但是将它们存储在各个有独特名称的文件夹中将有助于管理

资源包

资源包是Oraxen的关键，即使Oraxen可以自动生成所需要的大多数文件，当您需要提供有关物品的材质，所有的一切都可以在Pack文件夹中进行管理。您可以在Textures文件夹中添加材质，并在models文件夹中添加模型。同时您还可以在Pack文件夹的根目录更改资源包的基本文件，例如pack.mcmeta，资源包的图标等等

合成配方

这个文件夹包含了所有已添加的配方，并且按照配方类型进行排序。 例如：shaped.yml包含所有的有序配方。 您几乎没有机会直接编辑此文件，因为在游戏中使用Oraxen的相关命令直接生成配置更简单且快捷

Pack options

与大多数允许您创建自定义物品的插件不同，Oraxen支持创建材质包：也就是说，您可以在配置中直接设置所需的材质，插件将负责生成材质包。对于Minecraft来说，每个物品的材质都由被称为模型的json文件进行管理。大多数物品具有非常简单的模型，该模型仅显示二维材质。为了避免重复且无聊的编写此json文件，您可以要求Oraxen自己生成它。

The pack folder

这个文件夹（./plugins/oraxen/pack）包含您的材质包。它的工作原理类似于普通的Minecraft材质包，但更加简单。您可以将材质拖拽到textures文件夹中，而模型这拖拽到models文件夹中。您也可以在这些文件夹中创建子文件夹，使其更加整洁方便，但这并非必需。Oraxen在生成完材质包后，材质包会出现在此文件夹中，名称为pack.zip

创建简单的2d物品

将所需要的材质放入./plugins/oraxen/pack/textures。然后您可以要求Oraxen通过叠加材质来生成模型：

  1.   Pack:
  2.     generate_model: true
  3.     parent_model: "item/handheld"
  4.     layers:
  5.       - example_image1.png #不需要png扩展名
  6.       - example_image2.png
复制代码

Minecraft需要parent_model字段。实际上，这使您的物品可以从Minecraft原版继承物品模板的渲染值。您可以查看Minecraft的默认模型以查找新模型，但我个人将item/handheld用于武器，并将item/handmade用于普通物品

使用json模型

创建json模型可能非常耗时，但json允许您创建非常酷的东西(例如3d物品)。将json模型与Oraxen集成起来真的很容易：将材质放在./plugins/oraxen/pack/textures中，将模型放入./plugins/oraxen/pack/models中。然后，您可以要求这个模型在您的一个物品上启用：

  1.   Pack:
  2.     generate_model: false
  3.     model: example_model.json #json扩展名并非使强制性的

Mechanics

介绍

在Oraxen上制作非常漂亮的物品并修改其属性是非常容易的，但如果我们想做更多的事情呢？机制允许你为你的物品设置具有特定配置的特殊能力。例如：您可以创建一个可以开采基岩的稿子，或者是一把可以吸血的剑。

如何给物品添加机制?

物品专用配置

正如您在上文初学者教程中看到的那样，您只需要在您的物品配置文件中添加一个新的Mechanics结构，就可以在该结构中填写你所需要的所有机制

  1. example_item:
  2.   material: DIAMOND_AXE
  3.   Mechanics:
  4.     # 你的机制应该位于这里

  6.     example_mechanic:
  7.       example_option: true

  9.     another_example_mechanic:
  10.       another_option: "example text"
复制代码

在物品配置中Mechanics的每个小节都允许你修改机制的各种设置（修改仅对单个物品有效）。也就是说，如果您给一个镐子添加了挖矿机制并设置其开采5x5区域，那么你也可以在其他镐子上添加但设置为开采3x3区域

全局设置

这些设置保存在Oranxen文件夹的mechanics.yml文件中。这些设置允许您更改使用所有该机制的物品的全局参数。这些设置在某些情况是非常有用的（即使您很少会用到）例如：破坏基岩机制bedrockbreak允许你开采基岩。但大多数服主都不希望玩家挖穿世界。此时你就可以在全局设置中更改破坏基岩机制的参数（这会影响所有所有使用该机制的物品）。

  1. bedrockbreak:
  2.   enabled: true
  3.   disable_on_first_layer: false
  4.   durability_cost: 500

Bigmining

这允许你同时挖掘不同的方块。在默认情况下，此机制将用于锤子，并允许你同时开采3x3范围的方块

物品配置

  1. bigmining:
  2.   radius: 1 # 破坏半径
  3.   depth: 1
复制代码

bottledexp

这允许你通过单击鼠标右键将你的经验转化为附魔之瓶。你可以设置转换百分比

物品配置

此比率对应与1经验转化为1附魔之瓶的经验数量。

  1. Mechanics:
  2.   bottledexp:
  3.     ratio: 0.95 # 你会失去1/20的经验
复制代码

全局配置

  1. bottledexp:
  2.   enabled: true
  3.   durability_cost: 1
复制代码

全局配置
