有价值的有赏哦

命令与权限




/ItemExchange help 获取帮助信息

/ItemExchange reload 重载插件

/ItemExchange create ExchangeItemID ExchangeItemCount ProjectName
创建一个兑换ExchangeItemCount个ExchangeItem的名为ProjectName项目

/ItemExchange create hand ProjectName 创建一个兑换手中物品的名为ProjectName项目

/ItemExchange setCount ProjectIndex Count 设定兑换项目用几个不同的物品兑换

/ItemExchange set ProjectIndex Count ItemID ItemTotal
设置项目用于兑换的第Count个物品的ID及数量

/ItemExchange set ProjectIndex Count hand 设置项目用于兑换的第Count个物品为当前手中的物品

/ItemExchange delete ProjectIndex 删除一个兑换项目
管理员添加ItemExchange.Admin权限
玩家添加ItemExchange.User权限
