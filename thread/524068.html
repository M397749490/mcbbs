指令&权限：
/scoreboard show  -> 展示你的计分板在聊天窗 -> 没有权限
/scoreboard reload -> 重载配置文件                    -> scoreboard.reload
/scoreboard toggle -> 显示/隐藏你的计分板        -> scoreboard.toggle
