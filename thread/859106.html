Checkpoints是GCNT开发的插件。该项目于2017年8月27日作为服务器的定制插件启动，但后来已成为公共插件。
Checkpoints有三个内置的跑酷系统。简易跑酷有普通模式，有多种难度（简单、中等和困难）。然后是一个关卡系统，它的工作方式与普通模式相同，但它被赋予了名称、起点、终点等等。
Checkpoints是一个基于告示牌的跑酷系统。单击检查点告示牌，保存点将设置到您的位置。当你重生或输入/cp时，你将被传送到那个点。
有关如何为关卡设置黑名单的信息，请转到2.2.2版的更新说明或单击此处。

命令:
  • /checkpoints 主命令
  • /checkpoints setspawn 设置出生点
  • /checkpoints reload 重载插件
  • /checkpoints teleport 返回最后一个检查点
  • /checkpoints reset <玩家> 重置玩家的检查点
  • /checkpoints sendback <玩家> 让玩家返回最后一个检查点
  • /checkpoint 返回最后一个检查点
  • /level 关卡列表
  • /level list 所有关卡列表
  • /level leave 退出你现在所在的关卡
  • /level join [关卡名称] 如果不指定关卡，它将打开“加入”菜单。如果你指定了一个关卡，它将让你加入该级别。
  • /level kick <玩家> 把玩家从他现在所在的关卡中踢出
  • /level create <关卡名称> <难度> 创建一个名称为<关卡名称>、难度为<难度>的关卡. <难度>必须为easy medium hard中的一个
  • /level remove <关卡名称> 删除一个关卡
  • /level setstart <关卡名称> 设置关卡的起点
  • /level setcreator <关卡名称> <创建者> 把关卡的创建者设置为<creator>
  • /level setname <关卡名称> <显示名称> 设置关卡的显示名称. 可以使用颜色代码(&)
  • /level setend <关卡名称> 设置关卡的终点. 你必须站在一个压力板上. 下面的方块无关紧要.
  • /level check <关卡名称> 检查关卡设置是否正确
  • /level info <关卡名称> 获取关卡信息

  • 使用/level create <关卡名称> <难度> 创建关卡。难度可以是“easy”(简单)、“normal”(普通)或“hard”(困难)。
  • 使用/level setstart <关卡名称> 设置关卡的出生点。玩家加入游戏后将被传送到这个位置。
  • 设置级别的结束位置。你必须站在一块石压板上，压板下面的方块无关紧要。为此，请使用/level setend <关卡名称>。
  • 可以选择使用/level set creator <关卡名称> <创建者>和/level setname <关卡名称> <显示名称>设置级别的创建者和显示名称。
