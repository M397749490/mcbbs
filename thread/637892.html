Simple Trade
1.前言

关于交易类型的插件实际上现在已经有很多了，但是我还是自己写了一个新的。本人接触插件并不是很久，并且由于测试不足可能会出现bug，请及时向我反馈。这个插件将会持续更新，希望大家多多包涵。


2.功能

直观的界面和丰富的功能，基本不需要教学便会使用。可以让两个在线玩家之间互相交易物品与金钱，或者将自己的物品展示给对方，并避免了交易欺诈等行为。
本插件基于Spigot1.10服务端编写，但理论上可以支持1.9版本。 1.8和以下版本尚未进行过兼容性测试。


3.特征

(1)全新设计的GUI交易界面 包含显示玩家头像/按键声音等功能
(2)使用铁砧GUI来键入交易金额
(3)可在交易中选择切换末影箱库存来进行交易 *可配置权限
(4)不完全依赖Vault 您也可以选择不启用金钱交易
(5)准备/确认按钮设计 不需要等待倒计时等设定 交易更方便
(6)Config内可自订禁用世界列表 等待时间等条目
(7)金钱交易税率 当玩家使用金钱交易时会被扣税 *可自订
(8)可使用指令 也可使用潜行+右键来快捷执行邀请/接受交易
(9)双方物品为空时无法确认交易
(10)当一方交易物品变动时会重置双方的准备/确定按钮 使得交易安全无比
(11)可自订的标题信息
(12)当准备时自动为交易物品排序
(13)持续更新中


4.使用方法

1.使用/stinvite 玩家名 或者下蹲+右键玩家来邀请对方进行交易
2.当对方使用/staccept指令或下蹲+右键回应即可开启双方交易面板
3.将您需要交易的东西放在左边的物品槽位内，而右边会同步显示对方的交易物品
4.若需要进行金钱交易 点击上方的铁锭 并在展开的铁砧面板内键入您希望交易的金额
5.键入的数值为合法后铁锭会变为金锭 并可用鼠标悬浮以查看自己/对方的交易金额
6.当您准备好自己希望用以交易的物品后 点击自己头像旁的按钮进行准备，此时灰色按钮会变成绿色
7.若您或对方改动了交易条目 会自动重置双方的准备按钮到灰色的未准备状态
8.当对方点击了其准备按钮后 您可再次确认对方与自己的物品 并再点一次准备按钮 此时绿色的准备按钮会变为附魔的确认状态
9.当您想要否决交易 此时您也可以右键该按钮来重置到未准备状态
10.当双方均完全确认 交易即完成

6.安装方法

(1)下载本插件并置入plugins文件夹内
(2)运行一次服务端以生成配置文件 接着自订完所需选项后再次重启服务端
(3)在游戏中键入/sthelp即可查看指令帮助

*若需要使用金钱交易选项则需要前置插件Vault
*切换末影箱功能将导致玩家拥有移动末影箱 请谨慎开启(默认关闭+无权限)


7.指令 权限与配置

指令
/stinvite 玩家名   进行邀请交易
/staccept             接受交易
/streject              拒绝交易
/sthelp                展开指令帮助
/streload              重新载入Config配置文件(该指令不会显示在/sthelp里) v1.11新增

权限 - 红字为默认关闭 绿字为默认开启
simpletrade.* - 全部权限
simpletrade.command.*     - 允许使用全部指令
simpletrade.command.stinvite   -允许使用stinvite指令
simpletrade.command.staccept   -允许使用staccept指令
simpletrade.command.streject   -允许使用streject指令
simpletrade.command.streload     - 允许使用streload指令 v1.11新增
simpletrade.command.sthelp   -允许使用sthelp指令
simpletrade.trade.money     - 允许使用金钱交易功能
simpletrade.trade.endchest - 允许切换末影箱背包

配置 - 所有的配置选项均有中文标注

隐藏被停用的按钮,就是下面两个功能的。如果开启了但是因为没权限不能用不会隐藏。
HideDisableButton: false

启用末影箱切换功能, 关闭后即使有权限的玩家也不能使用
EnableEndchestSwitch: false


启用金钱交易，当无经济插件(Vault)时会无视该选项停用
EnableMoneyTrade: true

金钱交易税 单位%，当为0或负数时不启用税
MoneyTradeTax: 0.0

启用下蹲+右键玩家进行邀请/接受交易功能
EnableRightClickInvite: true

邀请等待时间 单位秒
InviteConfirmTime: 15
玩家上线后需要等待多长时间才能使用交易 单位秒  *当为0时不启用上线等待 v1.2新增
LoginCooldownTime: 60

自定义的交易面板名 例如:§9交§d易§2面§c板。过长可能会导致其后的提示信息超出界面 建议不超过6个汉字宽
TradeTitle: '§9交易面板'

开启新交易时的标题提示
OpenTitleInfo: '§2欢迎使用交易系统'

交易最大距离限制 单位格 ，当为0时为无限制
TradeMaxDistanceLimit: 10

允许跨世界交易, 当跨世界时会忽略上面的最大距离限制
AllowTradeBetweenWorld: false

启用头像皮肤显示，关闭可轻微降低服务器压力。盗版服也可用，会替换成对应的正版账号头像(如果有的话)。
EnableSkullSkin: false

当玩家受伤时自动取消进行中的交易 v1.11新增
CancelTradeWhenPlayerDamaged: true

当玩家移动超出交易距离限制设定时自动取消进行中的交易 v1.2改动
CancelTradeWhenPlayerMoveOutRange: true

当玩家改变所处世界时自动取消进行中的交易  v1.11新增
CancelTradeWhenPlayerChangeWorld: true

当玩家传送时自动取消进行中的交易  v1.2新增

9.BUG与不兼容插件/mod

1.由于Mojang服务器原因有时收不到头像皮肤 重新开启一个交易界面可能解决
2.在登录插件中未登录状态依然可以通过右键+下蹲与其他玩家交易，但是无法开启交易面板(AnthMe登录插件)。然而，这种情况下仍然会导致状态统计出错，使得该玩家在重新上线之前无法交易。已新增一个配置选项用来避免该问题。3.在某种情况下玩家可以卡到输入金额的金锭 已在版本v1.2.1修复本问题

更新向导:
如果您安装了之前的版本而想要更新至新版本，请按照下面的步骤更新:
1.下载最新版本的插件
2.关闭你的服务器，然后删除原先的插件和Config文件(在plugins/SimpleTrade文件夹内)以生成新版本的配置文件。
3.你可能需要备份一下你的Config选项，新生成的配置文件将会是默认的选项。

11.关于1.9系列版本
目前的测试下，v1.2版本支持1.9.4但不支持1.9,中间版本尚未测试

12.关于1.8改动版
该版本基于Spigot1.8.3重置了原插件的声音格式(这也导致了1.8版的按键声音与1.10版出入较大)与副手检查，理论上可以支持到1.9之前所有1.8系列。由于版本原因与测试不足，不得不删除了自定义标题/起始语的选项(本地测试中该功能造成了报错与乱码)。而且由于版本降级带来的其他问题暂且不明，故不推荐此版本。若想使用完整最新的版本，请使用1.10+的服务端。
