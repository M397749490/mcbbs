作者: OAO_miao    时间: 2015-7-14 22:39
在server.properties中开启pvp，然后在领地配置文件（plugins/Residence/config.yml）中全局禁止pvp
在大约60多行的位置有这样一段内容：
  1.     Flags:
  2.         Global: #these are default for all worlds unless specified below, they can be overridden per group
  3.             use: true
  4.             build: true
  5.             ignite: true
  6.             firespread: false
  7.             damage: true
  8.             creeper: true
  9.             tnt: false
  10.             pvp: false
复制代码

将pvp设置为false 就是全局关闭pvp啦
pvp区域用领地插件圈地，使用/resadmin set pvp true 开启相应领地的pvp（需管理员权限）
