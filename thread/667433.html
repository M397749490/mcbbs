使用新版Res领地插件
打开config，找到
Optimizations:
    # 默认的世界
    DefaultWorld: world
    DisabledWorlds:
      # 开启后插件不在此世界加载
      List:
      - xxx
      - xxx
      # 禁用所有世界监听
      DisableListeners: true
      # 禁用所有世界命令
      DisableCommands: true

最新版本下载地址：http://ltcraft.lt/Residence/
