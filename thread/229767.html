每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。
适用于正式版的MOD不兼容预览版，而且大多数MOD都不提供对每周快照的支持。
Minecraft 1.8仍未发布，14w05a 为其第 8 个预览版。
注意！旧版启动器已经无法启动Minecraft 1.6以及之后的快照，请看下面的说明。
本版新闻除非特别说明，否则均允许转载，但转载必须注明本帖地址。



有一天这段文字将会包含一些真正能改变人类命运的重要信息，并且没有人会知道因为没有人会跳过这段文字。噢，对不起，那是啥？快照？哦是的当然了，这儿就是了。

对生存模式进行的重要修改：
  • 只能复制一本书的原本或是其副本，而不能无限复制下去。
  • 充能的激活铁轨将能使实体离开矿车

针对地图制作者的重要修改：
  • 添加了一个旁观模式（/gamemode spectator）。还没全做完。
    • 除了其他旁观者，玩家看不到旁观者。（只有旁观者才能看见旁观者）
    • 旁观者可以查看道具栏等，但是不能修改。
    • 旁观者可以穿过任何实体/方块而不与之发生操作。
    • 旁观者可以点击实体来从它们的视角观察。（译者提示：从不同怪物的视角观察世界会有各种有趣的效果！）
    • 旁观者不能使用任何方法使用物品、放置方块、移除方块或者与方块交互。
    • 旁观者也许还会有些 bug

如果你找到了任何bug，请把它汇报到 http://bugs.mojang.com。如果你不汇报bug，我们将无法修复它！

此前与本次更新相关的快讯列表：
（来自cyqsimon）Minecraft 1.8第七个快照已经到来！本更新对游戏有很大改动，具体包括：生存模式更新、冒险模式和命令方块增强外加一些杂项！我们已经做了一坨针对客户端和服务端的优化工作（还有很多没公布呢），以及大量针对后台插件API的工作。

生存模式提升：
  • 针对方块的更新
    • 3个新石头种类：花岗岩Granite、闪长岩Diorite、安山岩Andesite
    • 苔石砖可合成
    • 门可堆叠
    • 史莱姆方块/粘液方块
    • 增强红石驱动方块的功能
  • 其它
    • 火焰的蔓延更科学了
    • 修理以及附魔的大幅度改变
    • 村民交易以及人工智能的更新
    • 生物掉落物品机制的改变

命令方块、冒险模式更新：
  • 新命令
    • 加入/blockdata命令，用来更改拥有附加值的方块属性
    • 加入 /clone 命令，用来复制大面积的区域，worldedit 至此可以消失了
    • 加入 /fill 命令，用来用单一方块填充大面积的区域或者替换这一区域中的特定方块，同样类似worldedit和mcedit
    • 加入/particle 命令，用来显示粒子效果
  • 对已有命令的修改
    • 为/kill命令加入可选实体参数，可以指定所有实体
    • 为/clear加入可选数量参数，这样可以限制物品以及NBT数值的最大值
    • 为/tp 命令加入可选朝向参数，可以自定义实体传送后的朝向
    • 增加实体选择符@e用以将目标指向特定实体。
    • @p, @e 等参数现在支持自定义全部三个维度
  • 其它
    • 冒险模式不再允许放置以及摧毁方块
      • 但这不是绝对的...可以变哦
    • 为大多数容器加入Lock:{'string'}NBT标签，用于锁闭容器

杂项：
  • 皮肤增强
    • 皮肤格式已经更新，支持第二层皮肤
    • 添加“自定义皮肤”菜单
    • 正版用户现在可以在游戏内调整哪一部分皮肤可见
  • 修复了许多元老等级的bug
  • 新的bug汇报网站

对于正版用户，可以直接接收到新版官方启动器的快照推送。前提是：
  • Profile中的Version Selection勾选Enable experimental development versions ("snapshots")一项
  • Use version选择Use latest version

  • 你使用的启动器能够在线读取官方的版本列表，并具备下载功能。
