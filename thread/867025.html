cmd示例

启动参数如下：

  1. // 以下参数仅支持1.14.4及以上版本！
  2. -account string                账号（正版登录/第三方登录）
  3. -name string                游戏ID（盗版登录）
  4. -auth string                验证服务器（外置登陆） (default "https://authserver.mojang.com")
  5. -uuid string                直接根据uuid读取配置文件进入游戏
  6. -remove                        删除配置模式
  7. -ip string                        服务器IP
  8. -port int                        端口，默认25565 (default 25565)
  9. -realms                        加入领域服
  10. -t int                                自动重新抛竿时间 (default 45)
复制代码

可能有人看不懂，所以给了一些例子来供各位参考：

  1. //以下仅为 1.13.2 版本的例子！
  2. autofish.exe -offline-mode -name Steve -ip my.hypixel.net
  3. //1.13.2离线
  4. autofish.exe -online-mode -account 10001@qq.com -ip my.hypixel.net -passwd 233
  5. //1.13.2正版验证
复制代码
  1. //以下仅为 1.14.4及以上版本的例子！
  2. autofish.exe -name Steve -ip my.hypixel.net -port 25565 -t 60
  3. //1.14.4离线
  4. autofish.exe -account 10001@qq.com -ip my.hypixel.net -port 25565 -t 60
  5. //1.14.4正版验证
  6. autofish.exe -account 10001@qq.com -auth https://skin.example.com/api/yggdrasil -ip my.hypixel.net
  7. //1.14.4外置登录
  8. autofish.exe -account 10001@qq.com -realms
  9. //1.14.4进入领域服
