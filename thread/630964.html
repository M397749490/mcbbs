banitem插件只能禁止持有，不能禁止使用【右键】
要想禁止使用【右键】，需要用ESS插件来才行
  1.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  2.   # 你加载了一次Essentials后,就可以在plugins/EssentialsX/items.csv中找到物品ID列表.
  3.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  4.   alert:
  5.     on-placement: 10,11,46
  6.     on-use:
  7.     on-break:

  9.   blacklist:

  11.     # 阻止玩家放置以下方块
  12.     placement: 10,11,46,4833,368,4844  

  14.     # 阻止玩家使用以下物品
  15.     usage: 4833,368,4844

  17.     # 阻止玩家破坏以下方块
  18.     break:

  20.     # 阻止活塞推动以下方块
  21.     piston:

  23.     # 阻止发射器发射以下物品
  24.     dispenser:
复制代码
如以上配置，4833为工具盒4844为满耐久的镭射枪。工具盒被阻止放置，使用，也就是说，在游戏内，允许你持有，【拿着】但不能使用，【右键】。只能当合成材料来用。镭射枪同上。不过注意一点，你需要banitem插件，来处理0耐久的和1耐久【也可以说是电力】的镭射枪，玩家做出来的镭射枪默认是0电力【耐久】，所以你必须要ban掉4844:27【好像有好像没有= =记不清了】和4844:26【这个绝对有！】获得方法：/give OP名字 4844:26 1 即可，然后拿在手上，输入/banitem add 理由（这个可以随意填写，不过建议还是用我这提醒）
例：您好，若想使用镭射枪来合成什么什么机器【= =莫怪，我真记不得这玩意可以合成什么机器了】，如果想合成，请前往商店购买合成专用的镭射枪。

例子：使用banitem with nbt来ban右键（使用）
首先我们假设在游戏里手持工业镭射枪输入banitem add d:-1
这样就ban了镭射枪。此时，进入banitem配置文件夹，打开banlist.yml，搜索”镭射枪“
可以看到如下代码：
  1. IC2_ITEMTOOLMININGLASER:
  2.   CurrentId: 4152
  3.   damage@-1:
  4.     CurrentName: 采矿镭射枪
  5.     reason: 该物品已被禁用
  6.     nbt: {}
复制代码

然后我们把这段代码整段剪切，再打开NoUseList.yml，粘贴到文件尾部。
保存好这两个文件，在游戏中输入banitem reload重载插件配置，就实现了禁止物品使用的功能，而且是禁止任意电量的镭射枪右键使用。
