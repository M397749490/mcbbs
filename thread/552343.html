前一阵子试了下IDEA开发环境，个人感觉比eclipse要好，尝试使用IDEA的过程中，遇到了一些坑，网上的资源也比较老。
于是总结了下搭建过程和大家分享，其实我没怎么学过Java开发，代码层面上也就是能大部分看懂。
要写个mod的话，还需要补充很多的知识，和阅读大量的代码。废话不多说。
这篇文章主要是介绍如何搭建IDEA15 Forge开发环境，然后附上一个导入别人mod源码&编译成jar文件的初学者向教程：

0. Java相关
首先要下载JDK，不是JRE
下载地址：
JDK8: http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html
JDK7: http://www.oracle.com/technetwork/java/javase/downloads/jdk7-downloads-1880260.html
任选其一安装，最好装x64的。安装后要配置JAVA_HOME环境变量

Forge src 给了我们一个简单的Example Mod
从左侧的工程栏里打开\src\main\java\com\example\examplemod\ExampleMod代码是
  1. package com.example.examplemod;

  3. import net.minecraft.init.Blocks;
  4. import cpw.mods.fml.common.Mod;
  5. import cpw.mods.fml.common.Mod.EventHandler;
  6. import cpw.mods.fml.common.event.FMLInitializationEvent;

  8. @Mod(modid = ExampleMod.MODID, version = ExampleMod.VERSION)
  9. public class ExampleMod
  10. {
  11.     public static final String MODID = "examplemod";
  12.     public static final String VERSION = "1.0";
  13.    
  14.     @EventHandler
  15.     public void init(FMLInitializationEvent event)
  16.     {
  17.                 // some example code
  18.         System.out.println("DIRT BLOCK >> "+Blocks.dirt.getUnlocalizedName());
  19.     }
  20. }
复制代码
