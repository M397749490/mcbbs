  1. # 传送功能的冷却时间(以秒为单位),如/home, /tp等命令.
  2. teleport-cooldown: 0    也就是两次指令的间隔时间

  4. # 传送延迟时间(以秒为单位),在玩家被确实传送之前的时间.如果玩家在该时间内移动了或者受到攻击,传送将取消.
  5. teleport-delay: 0    也就是输入了指令后需要等待的时间

plugins/essentials文件夹下的config.yml,不要用记事本打开，查找teleport-delay: 3改为teleport-delay: 0
这后面跟的就是秒数，0即没有延迟
五个家:/sethome 家的名字，设置五个就是五个家
