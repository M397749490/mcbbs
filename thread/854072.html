看到有人不在进行更新Server Log插件了那么这个坑我来接上

那么这款日志可以干啥呢



- 玩家加入

- 玩家退出

- 踢出玩家

- 玩家死亡

- 玩家重生

- 玩家传送

- 游戏模式改变

- 阻止位置

- 阻止休息

- 聊天

- 命令

- 物品拾取

- 物品掉落

- TPS

- RAM使用

- 实体数量（每个世界）

-玩家数（每个世界）




等于说游戏内的所有东西都能记录在log日志中

使用方法

1）下载插件。
2）停止服务器。
3）将“Server Log.jar”文件放在服务器上的plugins文件夹中。
4）启动服务器。



中文配置文件

  1. #       占位符:
  2. #           [player]   - 调用该事件的玩家。
  3. #           [time]     - 玩家调用该事件的时间。
  4. #           [tps]      - 服务器具有的 TPS。(仅在 tps 字符串中使用!
  5. #           [count]    - 计算计数。
  6. #           [ram]      - 服务器正在使用的 ram。(仅在 ram 使用字符串中使用!
  7. #           [message]  - 玩家发送的消息 (仅在异步聊天事件字符串中使用!
  8. #           [ip]       - 玩家称之为事件的 IP。
  9. #           [reason]   - 玩家调用该事件的原因。(仅在启动事件字符串中使用!
  10. #           [block]    - 纵的块。
  11. #           [bucket]   - 被清空的水桶。(仅在空桶事件字符串中使用!
  12. #           [previous] - 玩家以前的游戏。(仅在游戏符号更改事件字符串中使用!
  13. #           [new]      - 玩家的新游戏。(仅在游戏符号更改事件字符串中使用!
  14. #           [x]        -"x" 位置。
  15. #           [y]        -"y" 位置。
  16. #           [z]        -"z" 位置。

  18. #                                MM = 月 dd = 天 yyyyyyy= 年
  19. #                                HH = 小时 mm = 分钟 ss = 秒
