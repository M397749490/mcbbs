这是一个在服务器中也可以使用的颜色聊天模组，可以随意更名名称以及设置颜色，增加颜色组。主要用于不能使用插件的Forge服
命令:
  • /nick <nick> - 为自己设定一个昵称。留空昵称为重置
  • /color <color> - 为自己设定一个颜色。留空显示颜色列表，或进入“随机”得到一个随机的颜色
  • /realname <nick> - 看谁是背后的昵称
  • /coords - 喊出你的坐标
  • /group - OP使用的命令，可以用的子命令

    • create <Name>- 创建一组 名称
    • remove <Name> - 删除组 名
    • addUser <Group> <Name>- 将用户名称添加到组
    • delUser <Group> <Name> - 从组中移除用户名称
    • color <Group> <color> -为该组设置颜色
    • save - 将组保存到世界根文件中
    • load - 从一个文件中加载该组的位置根

  • /colorchat - OP使用的命令，可以用的子命令

    • version - 显示版本 colorchat
    • save users - 将用户保存到世界根目录文件中
    • load users - 从一个文件中加载用户根目录
    • save groups - 将组保存到世界根目录文件中
    • load groups - 从一个文件中加载组的根目录
    • 点击 下载地址（原网站）

    下载需要翻墙。。
