您好,对于简单的套装系统,您可以输入下列命令:
/scoreboard objectives add 变量名 dummy
使用时钟电路不断激活分别输入了命令scoreboard players set @a 变量名 数字1、命令scoreboard players set @a 变量名 数字2 {Inventory:[{Slot:100b,id:"minecraft:装备名",tag:{display:{Name:自定义名称,Lore:["描述"]}}},{Slot:101b,id:"minecraft:装备名",tag:{display:{Name:自定义名称,Lore:["描述"]}}},{Slot:102b,id:"minecraft:装备名",tag:{display:{Name:自定义名称,Lore:["描述"]}}},{Slot:103b,id:"minecraft:装备名",tag:{display:{Name:自定义名称,Lore:["描述"]}}}],SelectedItem:{id:"minecraft:装备名",tag:{display:{Name:自定义名称,Lore:["描述"]}}}},与命令effect @a[score_变量名=数字2,score_变量名_min=数字2] 状态效果ID 秒数 等级 true的三个命令方块。
变量名为同一串英文/或数字字符串,数字1与数字2为不同的两个数字,五件装备依次为靴子、护腿、胸甲、头盔,与手持物品。装备名可在游戏中按下F3+H后将光标移至背包中的相应装备上查看,自定义名称与描述非必需,可根据您的需求进行删改,多行描述可使用Lore:["第一行描述","第二行描述","第三行描述"]等的格式编写。状态效果ID可在该页面查询,秒数建议为略长于您时钟电路周期的一个数字,等级为您实际需要的等级数减一,省略true会导致粒子效果出现,可能影响视觉体验。更多不同套装效果设定可通过增加类似于后两者的命令方块组合来增加。若您还有任何其它疑问请向我发送消息,我会尽量为您解答。
