作者: OAO_miao    时间: 2015-4-9 11:37
楼主可以看一下这个教程https://www.crafter.me/mc/?page_id=124 修改json直接加载相应的jar,效果和覆盖进核心jar是一样的,但是有点难.
比如我之前的整合包 json是这样的:
  1. {
  2.         "id": "1.7.2-LiteLoader1.7.2",
  3.         "time": "2013-10-25T14:00:00+01:00",
  4.         "releaseTime": "2013-10-25T14:00:00+01:00",
  5.         "type": "release",
  6.         "minecraftArguments": "--username ${auth_player_name} --version ${version_name} --gameDir ${game_directory} --assetsDir ${game_assets} --uuid ${auth_uuid} --accessToken ${auth_access_token} --tweakClass com.mumfrey.liteloader.launch.LiteLoaderTweaker",
  7.         "libraries": [
  8.                     {
  9.       "name": "mod172:optifine:172"
  10.     },
  11.     {
  12.       "name": "mod172:inputfix:172"
  13.     },
  14.     {
  15.       "name": "mod172:TooManyItems:172"
  16.     },
复制代码

实际文件路径是.minecraft\libraries\mod172\TooManyItems\172\TooManyItems-172.jar这样(zip后缀直接改成jar就行)
