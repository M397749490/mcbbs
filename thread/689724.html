说明


  • 之前的版本（1.4.7-1.8.1）由 LZX6238 大大搬运并汉化，地址：http://www.mcbbs.net/thread-224529-1-1.html

不过这个插件久久未更新，bukkit页面也是“This project is abandoned”（弃坑的意思）。甚至适用于minecraft1.9服务器的版本(Chestshop-5)还是由热心“用户”Lyxnx插手修改的（不过相关spigot页面已经不存在了）。
不过呢，1.10版本开始，作者迷之填坑。（添加了1.8，1.10，1.11的物品ID，详见作者Jenkins更新日志：https://ci.minebench.de/job/ChestShop-3/changes。）（不要在意1.9了_(:з」∠)_）

运行正常，不报错


使用方法


玩家商店：
在一个箱子（之后用于商店库存）附近（1格距离）放一块牌子。
牌子这么写：
首行  
第二行 数量
第三行 B 买入价格：卖出价格 S
第四行 商品ID

如下图
（买入价格和卖出价格是对于牌子的使用者而言，而不是创建者本人，别搞反了（PS：此处没有故♂事））

创建成功后如下图（Phoenix616是创建者名字）



系统商店：
放一块牌子(因为是系统库存，不需要箱子)。
牌子这么写：
首行  Admin Shop
第二行 数量
第三行 B 买入价格：卖出价格 S
第四行 商品ID


对于使用者（俗称顾客）而言，单机鼠标右键买入、左键卖出。

按住shift+鼠标右键全部买入、shift+左键全部卖出。（config.yml中可以设置）



实用指令

/iteminfo 显示当前手持物品的信息（名称和ID）
/cstoggle显示/隐藏商店发来的信息（比如：某某某从你的商店买了balabala这种信息）

权限


权限子权限说明
ChestShop.shop.* 商店创建和使用总权限
ChestShop.shop.create.* 创建各种种类的商店
ChestShop.shop.buy 购买权限
ChestShop.shop.sell 出售权限
ChestShop.mod 给撤销商店和打开玩家商店箱子的权限
ChestShop.admin OP适用的最高管理权限 （上述MOD权限+创建admin商店的权限）


关于汉化

本人顺手整理的汉化，仅汉化了商店适用信息（如截图所示，买入、卖出等显示在玩家界面左下角的信息）（最近写论文比较紧张，未汉化物品_(:з」∠)_中学英语水平以上，可以不用）。


先带着原版插件运行一次服务器，用下面给的loacl.yml覆盖 服务器根目录\plugins\Chestshop 下的同名文件，重启服务器或者reload本插件。
