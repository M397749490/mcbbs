2.乘法、除法、求余运算符
乘法和除法的运算符跟数学里的就不一样了，乘法运算符在Java表示为“*”，除法运算符为“/”。注意千万不能使用中文符号里的“×”和“÷”，必须使用英文符号“*”和“/”。

  1. public class helloworld

  8.     int d = b / a;
  9.     System.out.println(c);
  10.     System.out.println(d);
  11.   }
  12. }

二、自增自减运算符
自增自减运算符的作用就是将变量进行加1或减1计算，这个符号放在变量前后都能更改变量结果。
自增运算符号为“++”，自减运算符号为“--”。
举个栗子，同时用自增和自减运算符:
  1. public class helloworld
  2. {
  3.   public static void main(String args[])
  4.   {
  5.     int i = 6;
  6.     int j = 5;
  7.     i++;
  8.     j--;
  9.     System.out.println(i);
  10.     System.out.println(j);
  11.   }
  12. }
复制代码

结果:
  1. 7
  2. 4
复制代码

解析:i++实际上可以写成i = i + 1;，只不过简写了而已，两个是一样的。
注意:大家尝试下把这种运算符放在数字前面试试效果，这两个含义是不同的，将这种运算符放在前面含义是先是变量进行运算，再使用变量;而放在后面的含义是使用这个变量后再将变量进行运算。大家可以试试修改例子的代码试试有什么不同。

三、关系运算符
关系运算符是用来确定一个值和另一个值的关系，既然是关系，那么结果就是对和不对（真和假），真就是true，假就是false。
这个蛮多的，有下列关系运算符:
  • “==”: 表示是否相等
  • “!=”: 表示是否不等
  • “>”: 表示是否大于
  • “<”: 表示是否小于
  • “>=”: 表示是否大于或等于
  • “<=”: 表示是否小于或等于

1.“==”与“!=”
大家看前面的解释，应该都懂了吧？
我们看栗子:
  1. [code]public class helloworld
  2. {
  3.   public static void main(String args[])
  4.   {
  5.     int i1 = 6;
  6.     int i2 = 6;
  7.     boolean b1 = i1 == i2;
  8.     boolean b2 = i1 != i2;
  9.     System.out.println(i1);
  10.     System.out.println(i2);
  11.   }
  12. }
复制代码

解析:看了上述代码，我们都知道，i1=i2，那个i1 == i2是正确的，它返回了真(true)，而i1 != i2是错误的，它返回了假(false)，那么程序结果是？
  1. true
  2. false
复制代码

2.“>”、“<>”、“>=”、“<=”
这个的返回值依然是真或假。
看栗子咯:
  1. public class helloworld
  2. {
  3.   public static void main(String args[])
  4.   {
  5.     int i1 = 6;
  6.     int i2 = 12;
  7.     boolean b1 = i1 > i2;
  8.     boolean b2 = i1 < i2;
  9.     boolean b3 = i1 >= i2;
  10.     boolean b4 = i1 <= i2;
  11.     System.out.println(b1);
  12.     System.out.println(b2);
  13.     System.out.println(b3);
  14.     System.out.println(b4);
  15.   }
  16. }
复制代码

结果:
  1. false
  2. true
  3. false
  4. true
复制代码

解析:i1是6,i2是12，i1 > i2很明显不对，所以为false;i1 >= i2也很明显不对，所以是false;其它两个意思是i1比i2小和i1小于或等于12，因为满足其中一个条件，所以为true。
注意:这个只能比对数字，不能比对对象。

四、逻辑运算符
逻辑运算符的作用是对此二进制数的逻辑关系，结果为true和false。
逻辑运算符分三种:“&&”，“||”，“!”。
“&&”即与运算符，它会先判断两边是否都为true，两边都为true，结果就是true;其中有一边或两边是false，结果就是false。
“||”即或运算符，它会先判断其中一边是否为true，只要有其中一边是true，结果就是true;如果两边都为false，结果就为false。
“!”即非运算符，如果这个表达式为true，结果就是false;反之如果这个表达式为false，结果就为true。也就是说这个运算符放在一个表达式的前面，就取它的相反值并进行赋值。
看这个栗子，同时使用了三种逻辑运算符:
  1. public class helloworld
  2. {
  3.   public static void main(String args[])
  4.   {
  5.     boolean b1 = (555 > 333) && (233 < 466);
  6.     boolean b2 = (555 > 333) || (222 > 333);
  7.     boolean b3 = !(65 > 88);
  8.     System.out.println(b1);
  9.     System.out.println(b2);
  10.     System.out.println(b3);
  11.   }
  12. }
复制代码

结果:
  1. true
  2. true
  3. true
复制代码

解析:使用了与运算符的一句代码中的555>333和233<466都是正确的，所以变量b1为true。
使用了或运算符的一句代码中555>333是正确的，222>333是错误的，但或运算符只要一边为true结果就是true，所以变量b2为true。
使用了非运算符的一句代码中65>88是错误的，但前面有“!”运算符，这个运算符取相反值赋值[true(真)的反义词就是false(假)]，所以变量b3为true。

五、三元运算符
三元运算符的作用是对3个表达式进行比较，条件判断语句的值为true时，结果就取第二个表达式的值；条件判断语句为false时就取第三个表达式的值。
让我们看一个栗子:
  1. public class helloworld
  2. {
  3.   public static void main(String args[])
  4.   {
  5.     boolean b = (555 > 333) ? true : false;
  6.     System.out.println(b);
  7.   }
  8. }
复制代码

这段代码编译后运行结果是:
  1. true
复制代码

解析:555>333是对的，所以它应该为true，所以变量b的值为“true”，如果括号里的表达式为false，那么这个程序就会输出“false”。
