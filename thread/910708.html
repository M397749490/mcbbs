【前言】作者原话

大家好，我是貘，經過了一年多，不知道還有多少人記得《驅逐魔族》這張地圖呢 ? 今天要介紹的地圖是他的重製版《驅逐魔族II - 追擊 !》，不只遊戲版本更新到了目前的最新版本，遊戲內也新增了許多以前做不到的小功能，許多系統都進行了重製，就等玩家們慢慢去發掘啦 ! ~ 另外，此地圖沒意外的話之後也會慢慢更新，雖然進度應該會挺慢的XD，並且每次更新基本上只需要動到資料包的部分，因此可以做到保存玩家資料的無痛更新，而更新教學都會放在 KuKuO 的官網裡。

简介 :
这是一张非常需要团队合作的RPG地图，各个地区的魔族会掉落什么素材需要亲自慢慢探索，许多野外Boss需要依靠团队合作想办法才能够击败，除了初始村庄以外，这地图还有许多的村庄，击败占领村庄的地区魔王后，各地区前往该村庄的传送门会解除封印，就可以更快速地在各个村庄间快速移动，在攻打Boss之前，不妨买栋房子睡个觉，便可以设置重生点，可以大大增加冒险的方便性
地图特点 :
★    上百种不同丰富的每日任务(游戏中 0 时重置)，包含采集、净化、讨伐、护送、调查、抢劫......，任务奖励随等级做调整，等你来挑战。

☆    5 种职业可供选择，不同职业有其各自的特性及专属的打法，发挥创意研发新玩法让角色的实力更上一层楼吧 !

★    使用随机系统，让NPC的回答更丰富、更逼真。

☆    杀怪及打王都采用LA机制(尾刀的人才会获得奖励)，但经验值是范围內的所有队友共同获得，尾刀尾起來 !

★    以对话方式推动剧情，增加互动感，也除去要一直带着剧情书的麻烦，减少了背包空间的占用，更不用担心发生把书弄丟的窘境。

☆    各式各样的进度辅助玩家寻找游戏目标，独特的魔族图鉴可以满足喜欢收集卡片的玩家的收藏欲。

★    武器和装备皆是以主线升级方式强化，分为了普通、高级、稀有、传说 4 种等級。

☆    就算吃饱也不会回血，回血一律靠恢复药水。

★    装备升级在合成时有可能失败，失败时只会扣除合成费用，材料不会消失。

☆    完善的住宅系统，每个村庄都有房屋可供购买，先抢先贏。

★    各村庄的物价都不相同，貨比三家才是王道。

常见Q&A

Q1 : 可以保留玩家的资料更新地图吗 ?
       可以，通常像v2.0.1升到v2.0.4这种，改变的只有最右边的数字，是属于小规模的版本更新，这类更新通常都可以无痛进行更新。 但如果像是v2.0.15升到v2.1.0这一种就属于比较大规模的更新，若想保存玩家资料，就不建议进行这类更新，保存玩家资料的更新教学如下 :
1. 备份原本的地图存档
2. 下载新版本的地图存档3. 将原本地图存档內的 "datapacks文件夹" 刪除
4. 将新版本地图存档內的 "datapacks文件夹" 复制回原本地图存档內
5. 重新启动服务器或输入指令 "/reload"
6. 在游戏中输入指令 "/function dotm_2:updata_map"7. 等待更新完成

Q2 : 可以 隐藏/显示 右边的银行存款吗 ?
       版本2.0.1之前可以输入指令 "/scoreboard objectives setdisplay sidebar money" 來显示银行存款，输入 "/scoreboard objectives setdisplay sidebar" 來隐藏銀行存款。 版本2.0.2之后可以在银行的地下室(创造模式可自动进出)开启或关闭。


Q3 : 游戏內的时间要怎么改 ? 想快点重置每日。
       非常不建议更改时间，若是非不得已，输入以下两个指令 "/scoreboard players set #system_hr playtime_minute 23"、"/scoreboard players set #system_min playtime_minute 59"。 输入完成后，每日任务将会在一分钟內重置。


Q4 : 如果不小心把村民打死了怎么办 ?
       正常来说所有 NPC 都是无敌状态，若使用冒险模式还可以击杀 NPC 的话请至官网回复该 NPC 的坐标，如果是作弊使用创造模式击杀村民，一律不负责复原，请勿作弊。
