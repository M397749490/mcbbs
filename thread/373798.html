第二章: 变量


变量是什么？


在java里，变量可以理解成一种临时储存。
比如我在第一行代码里进行了一个复杂的计算，获得了一个结果，而我希望在第二行和第三行里都用到这个结果
那么如果在第二行和第三行代码里都重新进行一次运算会严重拖慢程序速度，从而有了变量。

java中变量定义(创建)格式：
[变量属性] [变量类型] [变量名];
也可以给变量一个初始值:
[变量属性] [变量类型] [变量名] = [初始值];


比如，我要定义一个叫 testInt 的 public的整数变量，那就是:
  1. public int testInt;
复制代码

如果我要他初始值为2:
  1. public int testInt = 2;
复制代码


变量名称不可以使用数字开头，但可以（虽然一般会被嫌弃）使用中文。

关于变量的拓展知识:
在java里，变量是以指针的形式存在的， 至于指针是什么，可以理解成这样：
在java中，所有变量的值都储存在内存中，而值的地址则会由变量储存。 所以你每次调用这个变量的时候，这个变量会试着从自己储存的内存地址从内存里找到你赋予这个变量的值。 而有时候变量并没有储存任何地址或者储存的地址无法在内存内找到，而这个时候java就会丢出NullPointerException, 也就是大家所熟(chou)知(hen)的NPE

你可能会问为什么反正都要储存一个东西，不管是不是内存地址，为什么不直接储存变量的值呢？这是因为电脑中内存地址的长度是固定的， 而你使用的变量的值的长度却不会固定，所以如果直接储存你赋予的值的话电脑无法分辨在内存中的哪些字节是你要的，而到哪里停止之后是其他程序在内存中储存的信息。

对于变量名字的标准:
毕竟语言是人家外国佬开发的，所以标准肯定是英文喽。
java有个硬性规定(bytecode却没有不过你一般也不会写字节码), 那就是变量名不能用数字或者特殊符号开头，也不能使用java语法中的任何单词(for, if, static, class, public这种)[当然字节码里还是可以的所以这个规定是在编译器里的规定]。
然而对于变量名字还有个软性规定(就是你可以不遵守电脑也能正常运行只是会被喷)
  • 变量名必须要简短的描述出这个变量所储存的信息
  • 变量名必须为英文，可以包含数字和符号(当然不能以数字开头)  <-- 你可以用中文不过会被嫌弃
  • 变量名的单词必须小写
比如我要储存一个临时数据(Temporary Data)，那变量名就会写成这样: tempData
比如我有多个临时数据:
tempdata1
tempdata2
或者
tempdata_1
tempdata_2

既然讲到了软性标准那在讲几个关于命名的标准吧(就是你可以不遵守电脑也ok, 只是其他人不ok)
  • java的包名一般是小写字母
  • 类名称一般每个单词首字母大写 <--类名称也是支持中文的，同样会被喷而已
  • 方法名称(也支持中文)一般是英文单词，简短的描述出方法的用途，第一个单词全小写，之后的每一个单词第一个字母必须大写
  • 方法所需要传入的数据变量名也必须描述出需要的信息

比如我有一个处理玩家背包信息的类，这个类中有一个方法是来检测玩家背包是否可用，返回一个布尔值，需要传入一个玩家和临界值，那么我会这样写:
玩家背包处理器: player inventory processor
是否可用: Is it valid?
临界值: limit/threshold
玩家: player

  2.     public static boolean isValid(Player player, int threshold) {
  3.         /*代码省略*/

这次的叫他Varible好了。
变量值呢，大家都知道，就是x或者y。反正知道是一个代数就对啦
怎么说呢....Java里面的代数就像是一个盒子，里面装的一个值
需要代数的时候Java会自己伸手去抓盒子里的东西。但是你必须要告诉他要从那个盒子里面抓。
Java有9种常用的盒子(变量值)我一一解释:
byte: 做插件基本没啥用的东西, 就是一个字节
short: 短的整数, 从 -32768到32767
int: 中等长度的整数 从-2147483648到2147483647
long: 最长的整数 从-9223372036854775808 到 9223372036854775807
记住：上面几个只能是整数(不能带小数点)
float: 很好用的记录数字的盒子，正常用途用这个,细节很麻烦，不过支持小数点
double: 我认为是float的两倍，所以想用就用吧
记住：上面的六个只能是数字(不带文字)
char: 能塞得下一个Unicode的盒子,比如说 "你", "a", "哈" 等
String: 一段只能用Unicode代码或英文的东西, 比如说 "Hello" ,"Sup" , "Everything is Awesome"  , "\u4f60\u597d"
Boolean: 一个盒子，只装true(对)，或者false(错)，只能保留两个值。很有用。
记住：Boolean只能装true或者false!
