介绍：
隐藏玩家，相信大家都接触过，当然这个插件比一些其他的隐藏玩家插件要好，某些功能比较实用。


特征：
无需API支持
支持SP1.8/1.7.10
支持Bungeecord
（这两点就是说你可以放在BC端里运行，也可以放在服务端里边使用此插件）
可修改变量（消息，隐藏玩家的物品等，下边配置会详细介绍）
当玩家进入服务器时，会赠送给你那个钟（隐藏玩家的物品可以自己设置）
当玩家改变世界时，插件会默认将所有玩家显示
当玩家切换模式时，会有酷炫的粒子效果，看图：


需要注意的几点：（这个写在前边，原因不说了）
如果你需要将此插件以BC端的形式运行，那么你就需要将本插件配置文件内打上Yes
Prefix: '&6[&2HidePlayer&6]> '
#插件前缀
Message:
  Reload: '&bConfig File &6Reloaded'
#重载插件的提示文本
  Noperm: '&4&lYou don''t have the permission !'
#没有权限时的提示文本
  HidePlayer:
    'On': '&2&lAll &6&lPlayer &2&lHide !!'
    'Off': '&4&lAll &6&lPlayer &4&lShow !!'
#开启关闭的提示文本
Item:
  Name: WATCH
#这里的WATCH是钟...（废话），可以修改自己喜欢的隐藏玩家的物品，英文就打上我的世界里边的物品英文就可以了
  ShowPlayer:
#这里是隐藏玩家的一些消息设置
    DisplayName: '&2&lShow &4&lPlayer'
#不多说自己改吧= =
    Lore1: '&6&l&m================='
    Lore2: '&4&lClick Here'
    Lore3: '&4<o Show Player'
    Lore4: '&4&lWorld: &2%world'
#这里的变量说一下，%world 表示玩家目前所在世界
    Lore5: '&6&l&m================='
  HidePlayer:
#隐藏玩家时的一些消息设置（同上，自己改）
    DisplayName: '&2&lHide &4&lPlayer'
    Lore1: '&6&l&m================='
    Lore2: '&4&lClick Here'
    Lore3: '&4<o Hide Player'
    Lore4: '&4&lWorld: &2&l%world'
    Lore5: '&6&l&m================='
JoinMessageFriends: true
#这里也要说一下，这个插件有个指令可以增加好友，然后好友上线会有提示，而且呢，当你添加了好友的那个人，是不会被隐藏掉的
WorldEnable:
#开启关闭的世界，仿照例子自己添加世界即可
  '1': world
  '2': secondworld
  '3': Moreworld


如何使用？
和其他隐藏玩家的插件差不多咯，右键切换隐藏/显示的模式即可
然后那个配置里的Hide/Show player消息文本可以自己设置自己喜欢的OwO

指令&权限：
/hp help,h - 查看插件帮助
/hp on - 隐藏玩家 (hideplayer.on)
/hp off - 显示玩家 (hideplayer.off)
/hp credit - Credit Plugin （这是什么用的.....我也不清楚）
/hp reload - 重载插件
/hp [g,give] - 给自己一个钟 (hideplayer.give)
管理员权限: hideplayer.*
/hp add <Player> - 添加一个好友到好友列表里边(hideplayer.add)
/hp del <Player> - 从好友列表里删除一个好友 (hideplayer.del)
/hp [nofriends,nf] - 隐藏所有的玩家包括好友列表里的人 (hideplayer.friends)
