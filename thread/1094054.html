作者: renyunzhong    时间: 2020-8-5 09:51
可以是可以，用查找箱子内缺失物品可以做到，不过原版受到位置限制，比如只能点击容器或者箱子矿车做到，不能用指令，也没法检测左右键，而且还比较卡。如果能用tellraw做GUI一般不会用箱子。

具体方法是通过放置一个箱子里面在特定栏位有特定Tag的菜单物品，比如在Slot:10b的位置有tag为{Tags:["1"]}的石头
然后通过指令检测箱子：
/execute unless data block x y z Items[{Slot:10b}] run say 233
连锁条件或函数/execute unless data block x y z Items[{Slot:10b}] at @p run kill @e[type=item,nbt={tag:{Tags:["1"]}}]
