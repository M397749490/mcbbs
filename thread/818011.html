标题: Minecraft 基岩版 1.6（水域更新 第三阶段）发布
本帖最后由 AZWorld 于 2018-8-29 23:25 编辑
Minecraft 基岩版是指包括Minecraft 手机版（Android、IOS）、Win10版（VR）、主机版（XboxOne、NS）在内的 使用“基岩引擎”（C++语言）开发的Minecraft 统一版本。
正式版是 Minecraft 基岩版经过一段时间的测试版测试之后得到的稳定版本，也是众多材质、Addon和官方领域服会逐渐跟进的版本。与此同时Google Play、Win10 Store等官方软件商城也会推送次更新。
New Features:
新特性:
  • Phantom mobs will now spawn in the night skies if a player hasn't slept in over three in-game days. (Please note that there is a bug currently where phantoms may not swoop down- we will be fixing this bug as soon as we can!)
    如果一个玩家在 3 天内没有睡觉，幻翼会在夜空中生成(请注意现在仍然有 bug 可能会导致幻翼不会飞下来 - 我们正在尽可能快的修复这个 bug)
  • Barrier Blocks
    屏障
    • Great for map makers to limit players and mobs to certain areas of the world
      对于地图制作者来说，这是个把玩家和生物限制在指定区域的好东西
    • Can be placed in Creative mode and are invisible in Survival and Adventure modes
      在创造模式中可以被放置，在生存和冒险模式中不可见
    • Can only be obtained using commands and do not appear in the Creative inventory
      屏障没有加入到创造模式物品栏，仅允许通过命令获得

Changes:
改动:
  • Menu and inventory tabs can now be navigated using the [ and ] keys (Can be remapped in Settings)
    菜单和物品栏选项卡现在可以使用 [ 和 ] 键来切换（可以在设置中重新设置）
  • Pages can now be turned in the Book & Quill using the controller bumper buttons
    (书的)页面现在可以使用手柄的保险杠按钮进行翻页。
  • Personal Game Mode is now set to the Default Game Mode option when first joining a world
    当加入一个世界/存档时，个人游戏模式将被设定为世界/存档的默认游戏模式
  • Added the 'doinsomnia' game rule to toggle Phantom spawning when commands are enabled
    [版本独有]加入 doinsomnia 游戏规则，用于调整幻翼是否会生成
  • Added fresh new icons to game invite and achievement notifications on Nintendo Switch
    [Nintendo Switch]在游戏邀请和成就提示的 UI 中加入了新的图标
  • Adjusted mouse input sensitivity for slower turning at lower values
    调整了鼠标的灵敏度，使得在设置成较低值下转动的更慢

Fixes:
修复:
修复了 86 个漏洞
Crashes/Performance
崩溃/性能
  • Fixed several crashes that occurred during gameplay
    修复游戏过程中发生的一些崩溃
  • Fixed a crash that occurred when using Pick Block in a spot where a mob just died
    修复了当生物刚死亡时使用选取方块键发生的崩溃
  • Fixed a crash that occurred when players were spawning and the spawn point was getting set every tick
    修复了当玩家重生，并且重生点每一刻都被设定时发生的崩溃
  • Fixed a crash that occurred when joining a game and downloading Greek Mythology textures
    修复了加入游戏并下载希腊神话材质包时发生的崩溃
  • Increased performance for menu load times
    提高加载时菜单耗时性能


General
常规
  • Fixed the "Ahoy” and "Atlantis" achievements not unlocking on Nintendo Switch
    [Nintedo Switch] 修复了无法获得成就"啊嘿！"和成就"亚特兰蒂斯？"的问题
  • Fixed an issue that caused touch screen actions to repeat after touch release
    修复了当轻触释放后重复触屏行为的问题
  • Fixed controls becoming unresponsive after resuming the game from standby (MCPE-22195)
    修复待机后进入游戏无法操作(MCPE-22195)
  • Operator permissions are now granted to players when the host creates a world with Trust Player Permissions set to Operator
    当创建一个信任玩家权限为操作员的世界时，将给予操作员权限
  • Fixed the upload failure that occurred when exporting to Remix3D
    修复了当导出到 Remix3D 时发生的上传错误


Gameplay
游戏体验
  • Firework Rockets once again give the proper boost when using Elytra (MCPE-30821)
    MCPE-30821 - 在使用鞘翅时烟花火箭再次适当地加速
  • Crouching on ladders will no longer stop when opening the pause menu or inventory screen
    当潜行在梯子上打开暂停菜单或物品栏屏幕时，会继续潜行
  • Fixed the speed boost given by Dolphins being too slow when wearing armor with Depth Strider
    修复当穿有深海探索者的靴子时海豚给予的加速效果过慢的问题
  • The Resistance effect will now protect against the Wither effect (MCPE-21515)
    MCPE-21515 - 抗性提升效果现在将抵抗凋零效果
  • Players no longer clip through blocks and suffocate while swimming (MCPE-34112)
    玩家在游泳时不再卡方块和窒息(MCPE-34112)
  • Players are now able to return to the Overworld if an End Portal is on their spawn point (96153)
    玩家如果出生点在末地传送门上现在能够返回主世界了


Items
物品
  • Buckets now stack properly when getting ejected from crafting output
    当从合成输出中弹出时，桶可以正确堆叠了
  • Fixed an exploit that allowed players to obtain a 'Water' item (MCPE-28883)
    修复了一个文件可以获得水物品的漏洞(MCPE-28883)
  • Fixed an exploit that allowed items to be duplicated using the Recipe Book (MCPE-36167)
    修复了允许通过配方书复制物品的漏洞(MCPE-36167)


Mobs
生物
  • Guardians no longer attack fish (125705)
    守卫者不再攻击鱼(实体)
  • Fixed Guardians spawning even when Mob Spawning is disabled (MCPE-34027)
    MCPE-34027 - 修复即使在禁用生物生成下守卫者仍然生成的问题
  • Fixed issues with the Ender Dragon disappearing or dying for little to no reason
    修复了末影龙无故消失或死亡的问题
  • Drowned now have a much easier time attacking players that are swimming above them
    溺尸现在更容易攻击那些在他们上面游泳的玩家
  • Fixed Strays and Skeletons having trouble leaving the water to attack players
    修复流浪者和骷髅难离开水去攻击玩家的问题
  • Wolves no longer get stuck attacking Skeletons that are underwater
    狼不再困在水下攻击骷髅
  • Fixed a bug where Parrots could ride Donkeys and Mules (MCPE-25737)
    修复了鹦鹉可以骑乘驴和骡的问题(MCPE-25737)
  • Blazes now attack Snow Golems (MCPE-13191)
    MCPE-13191 - 烈焰人现在将攻击雪傀儡
  • Elder Guardians now drop Wet Sponges when killed
    远古守卫者被杀死后会掉落湿海绵
  • Fixed monster spawners appearing empty on converted Console Edition worlds
    修复了主机板转换存档后，刷怪箱出现空白的问题
  • Hostile mobs in boats can no longer attack from every angle (MCPE-16938)
    船上敌对的生物不再能从各个角度进攻(MCPE-16938)
  • Dolphins can no longer attack players through solid blocks
    海豚不再能通过实心方块攻击玩家
  • Baby Horses, Donkeys and Mules can no longer be pushed through solid blocks (MCPE-20114)
    马的幼体，驴，骡不再能穿过固体方块(MCPE-20114)
  • Creepers no longer remain white or quickly flash when killed
    爬行者在被杀死时不再显示白色或快速闪光
  • Entities following a target entity will now navigate properly over slabs
    跟踪目标实体的实体现在将正确地在台阶(半砖)上进行导航
  • Used chests can now be equipped to Mules and Llamas (MCPE-32152)
    MCPE-32152 - 使用的箱子现在可以装备给骡子和羊驼


Blocks
方块
  • Underwater plants can now be placed in water columns that originate from the top water source blocks
    水下植物现在可以被放置于从顶部水源方块制造出的的水柱上
  • Kelp now mimics Seagrass in its placement and can be placed on most blocks underwater (MCPE-33747)
    MCPE-33747 - 海带现在可以像海草一样放置，可以放置在大部分水下
  • Kelp that is planted by players will now grow over time
    玩家种植的海带会随着时间而增长
  • Chemistry blocks in a world uploaded to a Realm are no longer corrupted
    上传到 Realm 的存档中的化学方块不再被损坏
  • Observers will now detect changes with Droppers, Dispensers, Brewing Stands, Farmland, Saplings, Sugar Cane, Fire, and Grass blocks
    侦测器现在可以侦查到投掷器、发射器、酿造台、耕地、树苗、甘蔗、火和草方块的变化
  • The amount of fuel in Brewing Stands now converts from Console Edition worlds (MCPE-34677)
    在主机版转换世界后酿造台能量不会消失（MCPE-34677）
  • Activating an End Portal will now replace any blocks inside the portal (MCPE-28344)
    MCPE-28344 - 激活末地传送门将取代传送内部的所有方块
  • Fixed certain variants of Rails having an incorrect hitbox size
    修正了某些铁轨的错误碰撞箱大小
  • Land plants can no longer be placed underwater (MCPE-34124)
    陆地植物不能再水下放置(MCPE-34124)
  • Command Blocks now correctly conduct Redstone power (MCPE-33021)
    MCPE-33021 - 命令方块现在会正确的引导红石电流
  • Fixed an issue that allowed rails to be duplicated (MCPE-18230)
    修复了铁轨重复的问题(MCPE-18230)
  • Fixed the Cactus hitbox being displayed too low
    修复仙人掌碰撞箱过小的问题


Realms
领域服(Realms)(基岩版)
  • The owner of a Realm, once again, no longer counts towards the player limit of a Realm
    Realm 的主人不再计入 Realm 玩家限制
  • Improved error messaging when attempting to join a Realm via invite link with an outdated version of the game
    改进了当尝试通过带有过期版本的游戏的 Realm 邀请链接加入时的错误信息


World Generation
世界生成
  • Fixed floating Rails that generated in abandoned mineshafts (MCPE-23189)
    废弃矿洞中不再生成浮空的铁轨(MCPE-23189)


Graphical
图形
  • Improved the Trident throwing animation
    改进三叉戟的投掷动画
  • Visibility now increases over time when submerged in flowing water
    当潜入水中时能见度会随着时间的推移而增加
  • Cocoa Beans now display correctly when using HD Resource Packs (MCPE-30552)
    当使用高清材质包时可可豆将会正常显示(MCPE-30552)
  • Field of View can once again be adjusted when the "FOV Can Be Altered by Gameplay" option is disabled (MCPE-32403)
    MCPE-32403 - 视场(FOV)再次调整时，"FOV可以通过游戏调整"选项被禁用
  • Redstone dust now renders on the sides of Glass blocks (MCPE-21542)
    MCPE-21542 - 红石粉现在呈现在玻璃块的侧面
  • Resource packs once again apply when joining a multiplayer game that has a pack enabled (MCPE-33770)
    当多人游戏有资源包启用时资源包再次应用(MCPE-33770)
  • Fixed Texture Packs having a placeholder icon on the Pack Validation screen on Android devices
    材质包在 Android 设备的包验证屏幕上占位符图标不会消失
  • The Ender Dragon is no longer missing the texture on its neck when playing the Norse Mythology Mash-up Pack (MCPE-33966)
    在挪威神话主题包中，末影龙脖子上的材质不会消失
  • Food particles no longer gradually change position after swimming and will always come out of the player's mouth area (MCPE-33984)
    MCPE-33984 - 食物的颗粒在游泳之后不再逐渐变换位置，总是从玩家嘴的位置出来
  • Fixed a rare case of Ender Chests from Console Edition worlds converting to normal Chests with Ender particles (MCPE-26717)
    修复了在罕见的情况下，主机板在转换存档时把末影箱转换为带末影粒子的普通箱子(MCPE-26717)
  • Leads no longer flicker when playing in split-screen multiplayer
    当分屏进行多人游戏时游戏不再闪烁
  • Particles from Enchanted Arrows no longer drift in flowing water
    从附魔箭飘出的粒子在流动的水中不再漂移
  • Water Bottle icons no longer have red liquid on Android devices. It wasn't creepy or anything (MCPE-34167)
    [Android]水瓶图标不再有红色液体。那不是让人害怕的任何东西(MCPE-34167)
  • Players no longer appear to be floating above Minecarts (MCPE-33787)
    玩家不再矿车上浮空了(MCPE-33787)
  • Swimming through certain waterlogged blocks no longer removes underwater fog (MCPE-33917)
    游过特定的带水方块不再移除水下迷雾(MCPE-33917)
  • Oculus Rift mirror screen view now displays properly on monitors with 4K resolution
    [Oculus Rift]镜像屏幕在 4K 显示器上显示正常


Audio
声音
  • Lowered the volume of the 'punching air' and 'punching mobs' sound effects
    降低了'punching air'和'punching mobs'的声音大小
  • Fixed the sounds of items breaking twice for Boats, Minecarts, Paintings, and Armor Stands
    修复了船，矿车，画，盔甲架破坏时响起两次声音的问题


User Interface
用户界面(UI)
  • Items can once again be crafted from the Recipe Book while the Craftable filter is disabled and the player only has enough materials to craft a single recipe
    当合成过滤器被禁用，并且玩家有足够多的材料合成一次时，物品可以再次通过合成书合成
  • Quickly moving a stack of items in the inventory with a controller no longer leaves items behind (MCPE-34694)
    使用控制器快速移动物品栏中的一组物品时不再会遗漏物品(MCPE-34694)
  • Fixed the Cancel button not appearing on Windows 10 devices when joining a cross-platform world
    [Windows 10]修复了当加入跨平台世界时取消按钮消失的问题
  • Opening Book & Quill on touch devices no longer causes blocks to break (MCPE-29752)
    MCPE-29752 - 在触屏设备上打开书和羽毛笔不再导致摧毁方块
  • The gamepad cursor can now be used to navigate Villager trades (MCPE-33330)
    游戏手柄光标可以正确指向村民交易(MCPE-33330)
  • Multiple items can now be collected from the Villager trading output slot (MCPE-32635)
    MCPE-32635 - 现在可以从村民交易输出槽中收集多个物品
  • Fixed overlapping issues with the Dragon Head equipped on the inventory screen
    修复了在物品栏界面装备龙首时的重叠问题
  • The Crafting Table's output field hover state now matches the field's size
    工作台的输出区域悬停时现在可以正确匹配区域大小
  • Quick moving items from the hotbar to a container now works as intended (MCPE-19952)
    MCPE-19952 - 从热键栏到容器快速移动物品的行为现在正常了
  • Hitting the Enter key in the inventory no longer moves the cursor in/out of the text field or grabs/drops items
    在物品栏中按下回车键(Enter)不再将光标移入/移出文本字段或选取/丢弃物品
  • Selecting the output of an uncraftable recipe no longer causes the output item to disappear
    使用无法合成配方时的输出不再导致输出项消失了
  • Fixed inconsistent behavior when Attack/Destroy is mapped to Right-Click on the mouse (MCPE-23383)
    修复攻击/破坏被应用在鼠标右键时行为不一致(MCPE-23383)
  • Levers now have a "Use" controller hint
    拉杆在控制器提示上现在有"使用"提示文本


Commands
指令
  • Using '/fill doors' now fills the chosen area with doors instead of air blocks
    现在使用 /fill doors 指令将会在指定区域填充门方块(而不是空气方块)
  • Using the '/setblock' command on Redstone components will now properly update and power the mechanism (MCPE-21218)
    MCPE-21218 - 使用/setblock命令在红石成分上现在会正确地更新和驱动
  • Cloning containers no longer removes their custom names
    复制容器时不再删除它们的自定义名称
  • Slabs with 'can_place_on' tags can once again be placed by players in Adventure mode
    带有“can_place_on”标签的台阶可以再次在冒险模式中被玩家放置


Add-Ons:
附加件:
  • Updated templates for 1.6.0 with new assets and behaviors can be downloaded from minecraft.net/addons
    现在已经可以在 minecraft.net/addons 下载到更新了新的资源包和行为包的 1.6.0 版本模板
  • Fixed several issues with Fish textures that pertained to Resource Packs
    修复了属于资源包的鱼材质的一些问题
  • 'minecraft:behavior.player_ride_tamed' will now override all other AI goals
    'minecraft:behavior.player_ride_tamed'将会覆盖其它任何的AI目标
  • 'movement.sway' once again allows mobs to move properly
    'movement.sway'再次可以允许生物准确移动
