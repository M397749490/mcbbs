众所周知，添加自定义指令的方式一共有三种

其一：利用plugin.yml（最常用）

其二：通过事件监听

其三：命令映射

现在许多Bukkit开发教程都只教学了如何利用plugin.yml来添加你自己的指令

而使用事件监听来添加指令在你理解了事件监听器的原理之后也很容易理解

但是命令映射教程比较少


plugin.yml使用起来最方便，但是指令名称不可变化

事件监听可以自由监听任何指令，但是无法以此显示指令的信息

命令映射则没有这些弊端，你甚至可以在游戏内注册指令


下图为图形化Bukkit插件编程网站PVPIN中命令映射的操作


需要注意的是，PVPIN使用了大量自己编写的方法

因此这行代码已经没用了


NukkitAPI中，你可以直接这样

  1. getServer().getCommandMap()
复制代码

但是BukkitAPI并没有直接开放获取服务器CommandMap的方法

因此必须利用反射


那么命令映射就需要一些其他相关操作


首先创建一个指令以及其对应的处理器

  1.         Constructore<PluginCommand> c;
  2.         PluginCommand cmd;
  3.         //声明Constructor和指令cmd
  4.         try {
  5.             c = PluginCommand.class.getDeclaredConstructor(String.class, Plugin.class);
  6.             //强行获取类中的字段，包括非public字段
  7.             Demo plugin = this;
  8.             //主类的实例，Demo是插件的名字，如何获取主类实例不作讲解
  9.             c.setAccessible(true);
  10.             String name = "demo";
  11.             //指令名，这里是/demo
  12.             String description = "这是一个演示命令";
  13.             //指令介绍
  14.             String usageMessage = "输入/demo";
  15.             //指令用法
  16.             Listaliases = new ArrayList();
  17.             aliases.add("demonstration");
  18.             //指令别名（列表）
  19.             cmd = c.newInstance(name, plugin);
  20.             /* 运用集合的构造方法
  21.              * 构造器并没有写明需要多少个Object
  22.              * PluginCommand cmd = c.newInstance(new Object[]{name, plugin});
  23.              * initialize
  24.              */
  25.             cmd.setAliases(aliases);
  26.             //设置别名
  27.             cmd.setDescription(description);
  28.             //设置介绍
  29.             cmd.setUsage(usageMessage);
  30.             //设置用法
  31.             cmd.setPermission(null);
  32.             //设置权限，权限不作讲解
  33.             cmd.setTabCompleter(null);
  34.             //设置tab补全的处理器（这个和使用plugin.yml添加指令一样，不作讲解）
  35.             cmd.setExecutor(null);
  36.             //设置命令的处理类（这个和使用plugin.yml添加指令一样，不作讲解）
  37.         } catch (Exception e) {
  38.             e.printStackTrace();
  39.         }
复制代码




       然后再注册指令

  1.     try {
  2.             Field f = SimplePluginManager.class.getDeclaredField("commandMap");
  3.             //强行获取类中的全部字段，包括非public字段
  4.             //org.bukkit.plugin.SimplePluginManager
  5.             f.setAccessible(true);
  6.             CommandMap map = (CommandMap) f.get(this.getServer().getPluginManager());
  7.             //利用映射获取CommandMap
  8.             map.register(name, cmd);
  9.             //注册指令
  10.         } catch (Exception e) {
  11.             e.printStackTrace();
  12.         }
