http://minecraftbuildcraft.wikia.com/wiki/Filler
version 3.4.x+: Clearing is done from top to bottom layer, items cannot be picked up in the first 1/2 second and vanish after a further half second. This change was made to stop the filler being used as a cheap quarry alternative. This can be disabled in the Buildcraft config file by setting the variable 'B:filler.destroy' to false.

3.4的改动。为了防止使用Filler代替Quarry，掉落方块只存在半秒就被销毁。可以在配置文件中将B:filler.destroy设置为false来禁止。
