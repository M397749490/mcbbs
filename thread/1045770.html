测试版是Minecraft基岩版的测试机制，主要用于下一个正式版的特性预览。

然而，测试版主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。适用于正式版的领域服务器与测试版不兼容。

如果在测试版中遇到旧版存档无法使用的问题，测试版将允许你将存档上传以供开发团队查找问题。

Minecraft基岩版 1.16 仍未发布，1.16.0.61为其第8个测试版。

转载本贴时须要注明原作者以及本帖地址。

https://feedback.minecraft.net/hc/en-us/articles/360043160912

bug修复：
修复了58个bug

Crashes and Stability
崩溃和稳定性
  • Fixed several crashes that could occur during gameplay
  • 修复了游玩时可能发生的崩溃问题
  • Fixed a crash at launch on Samsung Galaxy S Duos 2
  • 修复了Samsung Galaxy S Duos 2上启动时的崩溃问题
  • Fixed a crash that could occur in the End
  • 修复了在末地可能发生的崩溃
  • The game no longer crashes when the /kill command is used while the dragon is respawning
  • 龙在重生时使用/kill命令不会再崩溃了
  • Fixed some crashes that occurred when changing dimensions, including going through portals with tamed animals (MCPE-346330)
  • 修复了维度之间穿梭的崩溃问题，包括携带被驯服的宠物穿过传送门时
  • Using the /fill command with Soul Fire no longer causes the game to crash (MCPE-65672)
  • 在灵魂火上使用/fill命令不会再发生崩溃了

General
常规
  • Fixed an issue when reloading characters wearing classic skins
  • 修复了重载经典皮肤发生的问题
  • Improved reliability of loading characters (MCPE-55968)
  • 改善加载字符的可靠性
  • Improved offline support for characters
  • 改善离线角色的加载支持
  • Classic skins are now loaded before Character Creator skins on multiplayer servers
  • 多人游戏中会在角色创建器之前加载经典皮肤了
  • An error message will now appear when the uploading and downloading world file size exceeds maximum
  • 上传和下载的存档过大会发出报错消息
  • Fixed an issue that could cause a failure when trying to import large worlds with limited space available on Windows 10
  • 修复了win10上导入旧世界时可能失败的问题

Gameplay
游玩
  • Changed mob population cap to only count mobs with spawn rules (MCPE-54378)
  • 更改生物数量上限，现仅会统计具有生成规则的怪物
  • Mob despawn range is now tied to Simulation Range (MCPE-65570)
  • 生物反生成的范围现和模拟范围绑定
  • Fixed an issue that sometimes caused Villagers to not link up to job sites correctly in multiplayer worlds (MCPE-49580)
  • 修复了多人游戏中村民有时无法与工作点连接的问题
  • Fixed an issue that could cause overlapping Villages to be repeatedly created and destroyed
  • 修复了会重复创建和摧毁覆盖村庄的问题
  • Parity: Water now freezes from the edges, matching the Java Edition
  • 特性同步：水首先从边缘冻结，匹配Java版
  • Fall damage protection will now work as expected from tall heights (MCPE-74561)
  • 摔落保护会正常工作了
  • Flying too fast with elytra into an unloaded chunk will no longer cause death by kinetic energy (MCPE-55671)
  • 用鞘翅飞到未加载的区块时不会再感受到动能了
  • Fixed ravines not being positioned correctly compared to older versions
  • 修复了与旧版本相比较峡谷定位不准确的问题
  • Fixed players being able to duplicate items by closing the title while on the respawn menu
  • 修复了使用重生菜单的关闭标题来刷物品的问题
  • Dropping items enchanted with Vanishing now works correctly (MCPE-65649)
  • 丢弃具有消失诅咒的物品时不会再消失了
  • Players can now only enchant one compass at a time, using an anvil in Survival
  • 玩家只能用一个铁砧一次附魔一个指南针了
  • Fixed an issue that sometimes caused Redstone torches to get stuck on or off when reloading a world (MCPE-48054)
  • 修复了重新加载存档后红石火把卡住或掉落的问题
  • Fixed an issue that could cause Kelp to stop growing too soon - Kelp now checks the block in the ticking queue when attempting to add itself (MCPE-57330)
  • 修复了海带可能停止生长的问题—现在会检查方块刻决定是否生长
  • Feather Falling and Protection enchantments now give the correct player damage protection (MCPE-74561)
  • 摔落保护和保护会正常工作了

Mobs
生物
  • Parrots no longer get stuck in flight mode (MCPE-64370)
  • 鹦鹉飞行时不会再卡住了
  • Mobs that panic now do so for all damage types
  • 生物受惊吓时会执行同样的受伤行为了
  • Mobs that can pick up armour now prioritise Iron over Chainmail
  • 可拾取护甲的生物穿戴锁链装备前会优先捡起铁装备

Blocks
方块
  • Walls now connect to most blocks placed above them (MCPE-65404)
  • 墙壁可以和大多数方块连接了
  • Falling blocks are now broken by partial blocks that are placed above piston arms facing up
  • 掉落的方块会被活塞的朝上臂部分给破坏了
  • Mushroom Stems now drop the correct block when mined with a Silk Touch tool (MCPE-69012)
  • 蘑菇柄可以用精准采集工具正常采集了
  • Target block redstone signal duration is based on projectile type, long for trident and arrows, short for other projectiles (MCPE-65413)
  • 标靶的红石信号时间取决于投射物，三叉戟和弓箭较长，其它投射物较短
  • Redstone torches will no longer get stuck on or off when reloading the world (MCPE-48054)
  • 重新加载存档后红石火把不会再卡住或掉落了
  • Conditional setting for command blocks is now saved when copying via Structure Block
  • 使用结构方块复制方块时会保存命令方块的条件设置了
  • Fixed an issue which allowed Jack 'o Lanterns to be placed on the side of blocks, breaking some Marketplace content
  • 修复了将南瓜灯方块其它方块旁边时会破坏一些市场内容的问题
  • Mushroom stems no longer drop brown mushroom blocks when silk touched (MCPE-69012)
  • 使用精准采集蘑菇柄不会再掉落棕色蘑菇方块了

Graphical
图形
  • Fixed an issue where chunks would flicker after altering render distance values
  • 修复了更改渲染距离后区块闪烁的问题
  • Fixed an issue that caused maps to become invisible (MCPE-76166)
  • 修复了地图隐形不可见的问题
  • Paintings now render correctly (MCPE-69652)
  • 画会正确渲染了
  • Beacon beams now render correctly (MCPE-76224)
  • 信标光束会正确渲染了
  • The flame animation now shows correctly on burning mobs and flame arrows (MCPE-76224)
  • 燃烧的怪物和火矢箭的火焰动画会正常显示了
  • Fixed an issue that stopped animated textures working correctly (MCPE-76180)
  • 修复了会导致停止动画材质播放的问题
  • Fixed an issue that prevented firework particles from appearing correctly (MCPE-76341)
  • 修复了会导致烟火粒子无法正常显示的问题
  • Tooltip backgrounds and the controller cursor now render correctly (MCPE-76154, MCPE-76168)
  • 工具提示的背景和控制器光标会正确渲染了

User Interface
用户界面
  • Fixed an issue that caused enchanted items to flicker with cursor movement
  • 修复了附魔的物品会随着光标移动而闪烁的问题
  • Fixed an unhelpful error message that appeared when trying to play online without proper account permissions
  • 修复了账户无权限并尝试在线游戏时会出现的无用信息
  • Fixed getting stuck loading resources after pressing 'Back' while on the 'Your Realm will soon be updated screen
  • 修复了在Realms界面点击返回后加载资源不久后会卡住的问题
  • Fixed an issue that prevented native text/character input when using Korean or Chinese virtual keyboards (MCPE-62596)
  • 修复了使用韩语和汉语虚拟键盘时无法输入本机文本和字符的问题
  • Fixed text on signs extending past the edge of the sign (MCPE-64315)
  • 修复了文本越过告示牌边界的问题
  • Fixed account error number -9 being displayed when launching the game while signed into an account, but no network connection
  • 修复了无网络下启动游戏并登录账号时显示 -9 错误的问题
  • Parity: Anvils now read “Enchantment Cost” rather than “XP Cost”
  • 特性同步：铁砧现在会读取“附魔点数”而不是“XP点数”
  • Fixed an issue that occasionally prevented inventory items being selected when using touch controls with classic UI
  • 修复了经典UI下使用触控时偶尔会阻止选择物品的问题

Commands
命令
  • Fixed an issue with teleporting 'tick_world' entities over large distances could cause them to disappear
  • 修复了远距离传送'tick_world'实体时会消失的问题
  • Now when teleporting an Armor Stand to a player, it rotates the Armor Stand to the player's orientation (MCPE-35979)
  • 将盔甲架传送到玩家时会旋转到面对玩家的方向了

Add-Ons
附加包
  • Elytra is now data-driven
  • 鞘翅变为数据驱动
  • Custom bones in geometry now respect their custom parent bones' transformations
  • 自定义的骨头模型现会遵循父级的变化
  • Fixed particles spawning with lifetimes that were less than 2x the current frame time would often not draw at all. This affected the ghost trail for the Advanced Mining content, and any other content that has particles with lifetimes that are really short
  • 修复了粒子的生命周期小于当前帧的2倍时间下基本没法绘制的问题。这对Advanced Mining的ghost trail内容，以及其他生命周期很短粒子的内容都有影响
