什么是forge？
Forge 是一个依赖组件可以让你安装Mods
(modification/修改，可以有更多不同的东西，比如车，飞机，还有更多功能）
使用forge installer（forge 安装器）安装forge（安装器应该是.jar 文件）, 然后到启动器里的profile选择你安装的版本，
然后直接点Play就行了。

“minecraft” 文件夹怎么找（windows是 “.minecraft”，mac是”minecraft“)：
Mac：打开finder，按住 Command-Shift-G 然后输入 "~/Library/Application Support/"
然后就可以找到minecraft文件夹。

Windows：使用cmd输入 %appdata%\.minecraft\ 点击启动，然后就找到.minecraft啦。
（或者直接从Minecraft【我的世界】里到资源包点击“打开资源包文件夹”然后就进去了）

----->如何在mac里面使用windows整合包/懒人包：<-----

-当你下载一个懒人包/整合包是RAR格式，
请到App Store(商店）下载“The unarchiver”这个软件（免费）然后解压。
（因为Mac自带的解压器解压不了RAR, 而且解压zip的时候很容易乱码［特别是中文］）

1.当我们解压完以后rar/zip会变成一个文件夹，打开，
2.然后你应该会找到一个exe格式的启动器（windows的启动器）然后和一些其他的文件夹，

但对我们（mac）来说没有什么太大用处的东西。
3.在 应用程序（Application）里面的Utilities 文件夹 里找到 终端（Terminal），打开，
4.输入 defaults write com.apple.finder AppleShowAllFiles -bool true 再关闭窗口。
（不用担心，这些文件不会伤害你的电脑，而是用来显示隐藏文件。假如你不想要他们，就在终端里输入
defaults write com.apple.finder AppleShowAllFiles -bool false)
5.打开 Finder 回到下载的懒人包里面，现在里面一个会出现一个 .minecraft 文件，也就是我们需要的文件。
6. 现在到我们电脑里的Applicaton Support文件夹里把 "minecraft" 拖到桌面上，然后重命名".minecraft" 到 "minecraft"，
7.现在这个文件夹就会变成非隐藏文件，之后把桌面上的的 minecraft 文件夹拖到Application Support 里面就大功告成了。
现在启动 Minecraft 启动器，就可以用懒人包了/整合包！！！



----> 注意事项：<----

（-请事先安装 JAVA 才可以启动启动器）

（-并且自己了解一些关于Forge的信息如果你想安装mod）

1.楼主推荐自己安装Forge因为这样的话不容易发生不兼容之类的事情。
（楼主不用整合包，自己看有什么mod然后自己下载）

2.许多的光影不与 Intel 显卡兼容，所以请下载与Intel显卡兼容的光影。（通常会标注）（所有Apple产品使用Intel显卡）

3.最好把解压后的文件拖进mod文件夹里，假如不解压的话有时候mod会运行不了。

4.更新最新版JAVA！（如果你发现更新完之后minecraft不好用啦。。请自行搜索。。因为毕竟是java，谁知道怎么回事）

5.如果启动器更新不了请自行翻墙！或者到这里下载最新版！！

6.有一些mod不一定兼容Mac的Intel Core, 比如有一些Shaders（光影），所以千万要先看一下mod是否兼容然后再使用。
