不识别UUID

其实也没什么好解释的

亲测 最新的群组端可使用
使用教程
从原贴下载插件放入群组端 plugins文件夹里
重启服务器
后台输入whitelist on打开白名单
命令：
/whitelist on 启用白名单。
/whitelist off 禁用白名单。
/whitelist add Lonely 将玩家Lonely添加到白名单
/whitelist remove Lonely 删除玩家Lonely的白名单。
/whitelist list 获取白名单中的用户列表。
/whitelist message get 显示踢出消息。
/whitelist message set new 设置踢出消息。
白名单的权限只有 whitelist.admin

配置文件
  1. #是否打开白名单
  2. enabled: true
  3. #无白名单时踢出信息
  4. kick_message: 你不在白名单内 请在群里进行申请！
  5. #白名单列表 可手动添加 按照格式即可
  6. whitelist:
  7. - Lonely
