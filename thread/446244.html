1.介绍BungeeCord服务端:
小白看得懂的介绍:
相信各位小伙伴都玩过国内外大型的云群组服务器，就是进入后可以选择模式，然后进入另一个服务器

此类服务器统称为云服务器，其核心为BungeeCord[以下简称BC]

BC服务器并不能直接连入，它可以称为服务器中专站，而非一个插件，并且可以把多个服务器链接到一起



主要介绍:[转自贴吧]

BC是新一代的服务器云群集插件，目标是将成为最可靠的一代。以前类似插件是由Raphfryk所开发的CraftProxy，CraftProxy主要功能是支援本地缓存服务器chunk以减少连接服务器的卡顿，次要功能就是可以让多服务器互相联接，形成一个大服务器联盟(主要因为craftbukkit暂时不能使用上服务器的多核心,当单一服务器人数过多时将会造成服务器TPS[Ticks per second]过低的现象。用上联接插件后，将能把玩家分配到不同的端口，轻松解决瓶颈)。因为Raphfryk投入开发Spout的项目已经把CraftProxy+ServerPort遗弃，加上新版本Minecraft封包加密，CraftProxy的缓存chunk这项主要功能将很难实现，所以CraftProxy被遗弃。随之出现的插件就是本帖所介绍的BC，将由md_5(md5所参与开发的插件众多[其中有Essentials],累积的经验以保证本插件非常稳定)带领继续开发，并保持开源精神。BC将会比CraftProxy更优秀和包含更多功能。

BC的宗旨是提供更稳定和让服务器主更简单的设置就能让他们的服务器联接到云上和允许玩家使用传送门于这些服务器之间互相连接(你可以使用他们开发的传送门插件Janus或者从CraftProxy时期已经存在的老牌多功能传送插件Transporter[依然更新中])。

BC提供/server 这一个服务器指令快速传送到不同服务器,如果有安装Janus还包含非常简单的传送门。

6.注意事项[重要!]

4个子服务器的核心文件都是spigot1.7.10

也就是说，自带反X-ray，自带优化的核心

并且客户端版本1.7.x-1.8.x都可以连入服务器！

插件不可用，楼主只是一个示例，插件只是为了告诉大家需要安装那些插件，并没有进行配置，建议全部删掉然后自己进行DIY！否则会造成崩溃无法连入不能登录等等情况！

但是！ 这个核心只加载1.7.10的插件和部分1.7.2的插件，如果遇到插件不加载或者其他问题，请注意检查版本

推荐进入版本:1.7.2

为什么呢？ 因为1.7.2版本兼容这个核心最好，并且1.7.2进入服务器可以加载任何皮肤！【Mojang从1.7.10往后开始，非正版服务器不加载正版皮肤，就算您正版登录了也不行】

11.食用方法[重要！！]
当服务器已经依次开启之后，
输入您的服务器IP地址25565的端口号。
然后连接 这个BC服务器，然后你就会发现，你进入了一个服务器，就是我设置的[大厅服务器]了

在任意子服务器内输入/server [服务器名字,名字就是BC下的config里的server名字]来连接其他服务器
我默认的服务器名称是:
Lobby server 大厅服务器
Island server 空岛服务器
War server    战争服务器
Original server原版服务器

最近有无法跨服的问题，提示服务器不存在，可能是java问题，不过本人电脑可以跨服

当然，你也可以装上一些跨服插件，比如跨服星门，跨服地标等等，不过个人推荐用chc插件，直接右键打开钟，然后按方块直接传送服务器，比较高大上感觉qaq

重要:在BungeeCord的Config中，我将默认管理员md-5更换为Little_Guang，这样可以防止一些人利用md-5的管理员账号进入服务器，当然您也可以修改它，改成您的名字，也可以将admin的管理权限撤销掉。
