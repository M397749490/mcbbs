一些使用上的细节(小教程)

  • SunLight 会覆盖原版命令，但是不用慌
  • /minecraft:命令 即可使用原版命令 比如 /minecraft:time set 100
  • 有一些命令是bukkit和spigot
  • SunLight重新加载命令是 /SunLight reload 但会卸载所有世界 然后再全部重新加载
  • 则会导致玩家在其他世界游玩被强制传送到主世界
  • 加权限命令 /lp user 玩家名 permission set 权限 true
  • 加称号 /lp user 玩家名 meta set 称号 倾国倾城
  • 加昵称 /lp user 玩家名 meta set 昵称 全角模式
  • 修复光照 /cleanlight
  • 商店帮助 /shop
