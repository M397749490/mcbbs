AutoQueue  自动队列
---------------------------------------------------------------------------------------

这是什么？（已经停止汉化维护）
如果您有在您的服务器上的景点或区域，并希望限制访问他们的时间延迟，AutoQueue允许你使用一个简单而有效的系统定义的队列，并使用符号让用户加入他们。没有什么前置，只需要有这个插件和有权限就好了OvO~

权限列表：
autoqueue.admin - 此权限的用户可以创建、修改或删除队列，将可以使用所有的命令！
【作者也就给了这一个吧~QAQ】

命令列表：
核心指令：
对于这个插件的核心命令：/autoqueue
其他的别名（都是一个激活命令的，意思一样）：
- /attraction
- /autoq
- /aqueue

基本指令：
- /autoqueue <exit|list>，用来使用户离开/退出一个队列

高级指令：
- /autoqueue <name> create - 创建一个名为<name>的自动队列
- /autoqueue <name> remove - 删除一个名为<name>的自动队列
- /autoqueue <name> start - 开始为一个名为<name>的自动队列的计时器
- /autoqueue <name> halt - 停止和复位一个名为<name>的自动队列计时器，且使所有玩家退出队列。
- /autoqueue <name> setcommand <value> - 当名为<name>的自动队列计时结束时，服务器将执行<value>这个命令（目前不支持占位符）
- /autoqueue <name> setcountdown <value> - 设置一个时间<value>使玩家们必须等待后再将会被传送。这个数值必须设定在1分钟以及以后，举个例子：value=1:01，玩家将会等待61秒
- /autoqueue <name> setlocation - 设置玩家们的自动队列传送位置

如何使用，举例：
（要求：首先你得拥有 autoqueue.admin 权限，不然你将会无法执行这一系列的指令）

步骤1：为你的队列想一个名字吧
我将使用一个示例的名字“Icefall”。你的队列名称通常都得在16个字符一下（不支持中文），一旦我选择了我的名字，就可以使用这个命令来创建我的队列：/autoqueue Icefall create

步骤2：为你的队列设定一个传送位置
你只需要在你需要在玩家传送的位置站着，且输入这个命令来设定好传送位置：/autoqueue Icefall setlocation【作者其实还有一大堆话，我觉得都是废话，教程就得精简】

步骤3：为你的队列设定高级定义
在上面的指令中，有一项是让玩家等待后再传送到指定位置，这个非常简单~我只需要输入：/autoqueue Icefall setcountdown 2:05，就可以轻易的让玩家等待125秒钟后传送到指定位置！
