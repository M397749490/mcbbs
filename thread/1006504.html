作者: 黑茶RGO    时间: 2020-4-2 22:47
版本：1.13+
创建一个叫health的血条
bossbar add health "血量"
bossbar set minecraft:health max 20
bossbar set minecraft:health players @s
bossbar set minecraft:health color red
然后高频这条指令：
execute as @a store result bossbar minecraft:health value run data get entity @s Health
