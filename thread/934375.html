作者: GeForceLegend    时间: 2019-12-21 21:04
原版jar中并不存在sounds文件夹，所有的音效文件的名称经过混淆处理后存放在.minecraft/assets/objects里面。想要知道音效文件有哪些的话先打开assets/indexes/版本号.json，再在里面搜索sounds.json，可以搜到一条字符串。例如1.14.json里面可以搜到以下内容：
  1. "minecraft/sounds.json": {
  2.         "hash": "b9be2246b416bbff0749415d4482a06d82fee78a",
  3.         "size": 195388
  4. }
复制代码

这个b9be2246b416bbff0749415d4482a06d82fee78a就是sounds.json的名称。每个版本的sounds.json里面都包含了这个版本包含的音效文件在资源包内应该使用的名称，可以对照着WIKI查询。不过WIKI上只有1.13扁平化以后的声音事件了。
找到想要的文件名称后像搜索sounds.json一样在版本号.json里面搜索想要的声音文件即可，例如1.14的ambient/underwater/enter1（ogg音频文件）的字符串是9579b9b2dc9d2be2fe1d6a81c2e99b6a45650bf3，在1.14.json里面搜索enter1就可以找到
