TAB
一款全新的TAB修改插件！


命令
/tab —— 打开帮助菜单
/tab reload —— 重载配置文件
还有四个命令是非常普遍的，在这里我就不说了



权限
tab.admin —— 所有命令的权限



配置文件

  1. #刷新时间(单位:秒)
  2. delay: 1

  4. # %online% = 在线玩家数
  5. # %ping%   = 玩家延迟
  6. # %nick%   = 玩家的nick名字
  7. # %IP%     = 玩家的IP
  8. # %time%   = 时间（服务器时间为准）
  9. # %rank%   = PVP称号的声望变量 (bukkit only)
  10. # %money%  = 玩家身上的金钱 (bukkit only)
  11. # %server% = 服务器玩家 (bungeecord only)
  12. # %deluxetag% = 插件 DeluxeTags 的变量(bukkit only)

  14. header:

  19. footer:

  25. ###################################

  27. ###################################
  28. #是否开启显示 header 和 footer
