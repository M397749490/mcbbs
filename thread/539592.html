  4. backup-file: backups/
  5. #备份的日期格式
  6. backup-date-format: yyyy-MM-dd-HH-mm-ss
  7. #不懂
  8. backup-empty-server: false
  9. #是否禁用压缩
  10. disable-zipping: false
  11. #删除压缩包的间隔
  12. delete-schedule:
  13. #时间间隔
  14.   intervals:
  15.   - 3d
  16. #时间频率
  17.   interval-frequencies:
  18.   - 4h
  19.   - 1d
  20.   - 5d
  21. #是否开启备份提示
  22. broadcast-message: true
  23. backup-message: '[自动备份]'
  24. custom-backup-message: '开始备份地图'
  25. custom-backup-message-end: '备份地图成功'</SPAN>

作者: Kirito刀剑神域    时间: 2017-7-15 12:27
之前没有看懂delete-schedule这个东西是怎么设置的，后来弄懂了，这里详细说一下：
  1. delete-schedule:
  2.    intervals:
  3.        - 3d
  4.        - 4w
  5.        - 6m   
  6. interval-frequencies:
  7.        - 1d
  8.        - 1w
  9.        - 0
复制代码

这是配置的示例。正确的看法是一个interval对应一个frequency。比如说第一个配置：interval是3d而frequency是1d。这就意味着：对于3天前的存档（3d），每天只保留1个存档（1d）。同理接下来两个就是：对于4周以前的存档（4w），每周只保留1个（1w）；对于6个月以前的存档（6m），不保留人任何存档（0）。
时间的单位支持：'h' = 小时, 'd' = 天, 'w' = 周, 'm' = 月, 'y' = 年。大概就是这样。
