FucWither
阻止凋灵破坏方块（不包括自身爆炸与头颅爆炸）
初次使用请在BDS目录下创建config文件夹
本插件支持在BDXCore与BedrockX中加载
本站下载按钮提供的是支持BDXCore的版本
如需在BedrockX中加载，请下载云盘中带_BDX后缀的版本

Configuration file
config/fuc-kwither.json:
  1. {
  2. "enableWitherDestroy": false, //将此项设为false后凋灵将无法破坏方块（不包括爆炸）
  3.                               //并且enableSkullDestroy将无效
  4. "enableSkullDestroy": false //将此项设为false可以仅关闭头颅破坏（不包括爆炸）
  5. }
