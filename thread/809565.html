CoreProtect是一款为大型服务器打造的可记录和管理数据的插件，可对方块、流体、容器进行记录，在您需要的时候可对其进行回档/恢复操作，避免了更大的损失。当然不会影响您的服务器性能

CoreProtect由2012初开始积极开发的，到现在，已经算是老牌插件，广受大家的喜爱

功能
  • 快速高效的数据记录
  • 快速回档/恢复没有滞后
  • 多线程确保服务器性能不受影响
  • 可以不用配置，直接把插件放在服务器上使用
  • 基于SQLite的数据存储
  • 可选MySQL数据存储
  • 简单使用命令
  • 执行回档/恢复，随时可以取消该操作
  • 简单查询方块数据
  • 基于搜索的高级查询工具
  • 分页日志
  • 自动更新检查
  • 支持多世界
  • 可在配置自行开关选项
  • 可对指定玩家，全部玩家或你周围进行回档
  • 可让回档/恢复中，跳过某些方块
  • 可记录玩家基本动作（如开门）
  • 记录液体、树等与玩家相关操作
  • 回档/恢复可选半径
  • 轻松删除旧的日志数据
  • 支持WorldEdit
  • 可作为API
  • 更多功能
命令
  1. /co help - 显示命令列表
  2. /co inspect - 切换检查状态（处于检查状态，可以通过交互动作来检查）
  3. /co rollback <参数> - 回档方块数据
  4. /co restore <参数> - 恢复方块数据
  5. /co lookup <参数> - 查询方块数据
  6. /co purge <参数> - 删除旧方块数据
  7. /co reload - 重载配置
  8. /co version - 查看插件版本
复制代码
权限
  1. coreprotect.*  全部权限
  2. coreprotect.inspect  允许使用inspect命令.（即/co i 的权限）
  3. coreprotect.lookup  允许使用lookup命令.
  4. coreprotect.rollback  允许使用rollback命令.
  5. coreprotect.restore  允许使用restore命令.
  6. coreprotect.purge  允许使用purge命令.
  7. coreprotect.reload  允许使用reload命令.
  8. coreprotect.help  允许使用help命令
  9. coreprotect.lookup.block  可以使用否定节点来限制方块记录查询.
  10. coreprotect.lookup.click  可以使用否定节点来限制动作记录查询.
  11. coreprotect.lookup.container  可以使用否定节点来限制容器记录查询.
  12. coreprotect.lookup.kill  可以使用否定节点来限制实体死亡记录查询.
  13. coreprotect.lookup.chat  可以使用否定节点来限制聊天记录查询.
  14. coreprotect.lookup.command  可以使用否定节点来限制命令记录查询.
  15. coreprotect.lookup.session  可以使用否定节点来限制登陆信息查询.
  16. coreprotect.lookup.playername 可以查询玩家曾使用过的ID（通过查询UUID）
复制代码
快捷命令
/co near - 查找半径为5的数据
/co undo - 取消回档/恢复操作

更详细命令
/co rollback u:<user> t:<time> r:<radius> a:<action> b:<blocks> e:<exclude>
解释
      <user> 回档指定玩家
      <time> 回档指定时间
           1w（一周） 1d（一天） 1h（一小时） 1m（一分钟） 1s（一秒）
      <radius> 指定半径
      <action> 限定查找某类型操作
            a:block - 方块放置/破坏
            a:+block - 放置的方块
            a:-block - 破坏的方块
            a:click - 玩家交互
            a:container - 取出和放入容器的物品
            a:+container - 放入容器的物品
            a:-container - 取出容器的物品
            a:kill - 动物怪物死亡
            a:chat - 聊天发送的消息
            a:command - 使用的命令
            a:session - 玩家的登陆和注销
            a:+session - 玩家的登陆
            a:-session - 玩家的注销
            a:username - 用户名更改
      <blocks> 限定回档某方块
            想回档石头则是 b:1
            想回档多个方块则是 b:1,5,7
            可以在这里查找物品ID：http://minecraft-ids.grahamedgecombe.com/
      <exclude> 不希望回档的方块
             不想回档TNT则是 e:46
      <hashtag> 其它操作
             你还可以在末尾自行添加（可以不添加）
             必须带有 #
             下面是可用的列表
             #preview - 预回档/恢复
             #count - 返回查询中找到的行数
             #verbose - 在回档/恢复期间显示信息
             #silent - 在回档/恢复期间显示少量信息

  23. # 如果true启用，则其它查看可以使用CoreProtect API

  26. # 如果回档没有指定一个半径，就按照该选项的默认值去执行

  31. # 如果不带半径, 你可以使用"r:#global"

  35. # 物品从容器被取出等操作会在回档操作张红
