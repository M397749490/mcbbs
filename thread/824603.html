插件介绍

这个插件可以让你用Citizens的NPC来打开Elitemobs精英怪物商店来让玩家购买/售出精英怪物装备.
  • 可设置出售的装备品质范围 - 这可以让你在不同的地方设置不同等级的商店以此来平衡经济
  • 可设置出售的装备数量
  • 可设置商店换货的时间 - 玩家不能像原版Elitemobs的商店那样手动刷新商店.
  • 是否开业 - 玩家必须等待商店开门才能购买.
  • 可配置商店物品

前置
  • 必要前置:


    • Citizens
    • EliteMobs

    可选前置:
    • NPCDestinations - 用这款插件来更换NPC的位置来达到开店和关店的效果


指令
  • /emcs {子指令}
  • /emcs help 插件帮助
  • /emcs info 显示选区的NPC商店信息

示例信息:
  1. === [ EMC Shopkeeper Info ] ===
  2. Shop Name: 精英怪物装备商店
  3. Shop Size: 54 - 54
  4. Tier Range: 0 - 10
  5. Update Interval (ticks): 120000
  6. Enabled: True
复制代码

  • /emcs size <最小值> <最大值> 设置商店出售的装备数
  • /emcs tier <最小值> <最大值> 设置商店出售的装备的品质
  • /emcs enable <true|false> 是否开启商店
  • /emcs update_ticks <刻> 设置商店换货间隔


NPCDestinations的指令
  • /nd locemcs <loc#> set 保存指定位置的设置
  • /nd locemcs <loc#> clear 清除指定位置的设置

Citizens的指令
  • /npc sel 选取NPC
关联NPC Destinations

  • 选择一个NPC
  • 在npc destinations内配置NPC
  • 输入 /nd info 并点击 emcs 来启用
  • 然后点击 '?' 来查看配置物品.
