作者: 阴阳师元素祭祀    时间: 2017-1-1 10:17
/scoreboard objectives add time dummy
创建一个积分版
然后拿出高频cb
里面输入
/scoreboard players add time time 1
激活【一秒激活20次
60秒=20*60=1200

然后高频探测
/scoreboard players test  time time 1200
后面在放个连锁 制约
/scoreboard players set time time 0
在放个连锁 制约
give @p 物品

作者: ruhuasiyu    时间: 2017-1-1 23:16
用周期为1分钟的漏斗时钟，电路为
石头        向左的比较器    向右的漏斗   向左的漏斗    向右的比较器   石头
红石粉     向右的粘性活塞   红石块           空气      向左的粘性活塞    红石粉


漏斗中放入75的物品（由于漏斗传输的速度是0.4秒一个，所以周期为 0.4*75*2=60秒）
在红石块的上方放置命令方，命令为
  1. give @a minecraft:stone 1 0
复制代码
(版本1.8以上)

无名氏wyw，方法很简单:做一个双向计时器。1.放一个嘴对嘴的漏斗。2.用两个比较器接上漏斗。3.比较器接两个石头。4.两个石头上放上红石。5.两个红石都接着活塞。6.活塞的版面接着红石块。只放一个红石块留一个空。（如果红石块在漏斗上面你就放对了）7.你会发现有一个漏斗上没方块，一个漏斗上有红石块。在上面没方块的漏斗里放77个东西，就是1组13个。8.ok，其中一个比较器的频率是1分钟。       有不懂的加我qq3204645858.
