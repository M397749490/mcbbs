介绍：
本插件是数据库前置，支持MySQL与SQLite。没有任何命令与权限，只是一个依赖库

使用：
将本插件丢进服务端plugins文件夹内，然后把其它需要使用本插件作为前置的插件也扔进去，重新启动服务器即可。

配置：
config.yml
  1. #
  2. general:
  3.   language: default
  4.   save-translation: false
  5.   debug-mode: false

  7. # Plugin Configuation
  8. DbLib:
  9. # true - use MySQL, false - use SQLite
  10.   use-MySQL: false
  11. # ORMLite configuration
  12.   ORMLite:
  13.     debug: false
  14.     keep-alive-interval: 1000

  16. # SQLite file
  17. SQLite:
  18.   file-name: nukkit.db

  20. # MySQL Configuration
  21. MySQL:
  22.   host: localhost
  23.   port: 3306
  24.   database: db
  25.   username: nukkit
  26.   password: tikkun
