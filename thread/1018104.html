这是田园物语V1.0整合包的V2.0重置版,简称田园物语V2.0。
这次重置增加了21个辅助类别的模组，强化、修改了 以匠魂为主体、丰收节日为副项的生存机制。
简而言之，您在本次整合包游玩中将无比艰辛。
首当其冲的是匠魂的生存机制，让您能真切感受到空手撸树的乏力，被迫捡石子的痛苦,寻找砂砾的艰辛。
营养学模组能让您深刻意识到烹饪的重要性，意识到您应该踏上丰收、挑战潘马斯工艺烹饪的旅途。
还是您觉得累了,想要泡杯茶喝？
以上种种，是在  匠魂生存模组 和 丰收节日模组 机制的架构下支撑本整合游玩的关键。

整合包概念
以新生存机制虚拟的背景故事
接下来的内容可供您遐想，纯属虚构，仅为增加代入感而作
概念：荒岛迷踪
在到达这个陌生世界时，曾经参加过一场真人秀的荒岛求生节目，
那时候可谓非常投入，正当此时，由于兴奋，为了去证明你的实力，
什么也没有多想的你，直接就踏入漆黑、潮湿的深山洞穴里，全程只有你和摄像机。
漆黑里能与之作伴的只有摄像机了，它的夜视功能，成为了你最后的救命稻草。
在直播厅里，观众们都被这个幽森的黑洞而感到害怕，充斥着各种尖叫、骚乱，
这档节目的节目组开心极了——收视率的瞬间膨胀。很快，全世界都在关注着你的一举一动。
在山洞里，你有了惊奇的发现——稀有生物、水源、古人生活遗迹等等，甚至在某个地方还充斥着隐隐约约的光源......
咚！
                  你莫名其妙间踩空了，摔进了一个洞中之洞，原来这里就是那微弱光源的所在之处！你越来越兴奋了，以为这只是正常的节目效果。
可是，真的只是节目效果这么简单而已吗？
意外往往就是这么突然，你和摄像机在下落过程中，越来越快、越来越快，甚至你已经没有知觉去触碰摄影机了——人 机 分离，
等到恢复知觉之时，摄像机已经在你的下方了......观众和节目组这才意识到这次的事件正在走向不可饶恕的恶化，
但一切都晚了，原本喧闹尖叫，刹那间鸦雀无声。节目组彻底地绝望了....
最后伴随着摄像机的坠毁，屏幕一片空白，留给世人的只有无法解开的谜底。
而对于你，噢！我的伙计！
你是世界上第一个到达地底的人——幸运地被地底的河水“接住了”。可是你什么都记不起来了.......
于是，你踏上了探知自己身世之谜的旅途。
你面对的挑战究竟是凶多吉少,还是悲喜交加？究竟是生存选择了你，还是你支配了生存?

问题解决

1 )  少数人可能因为JAVA与系统不匹配[例如：电脑操作系统为64x，java却为32x]会导致以下情况：
①出现窗口提示：由游戏非正常退出，请查看日志文件，或联系他人寻求帮助。
②游戏乱码，只能关闭

※经测试，解决办法如下：
①检查自身系统的操作位数(32x 或 64x)，检查JAVA位数(32x或64x)
②如果是32x下到了64xJAVA，请用 IE浏览器 打开JAVA官网直接下载
③如果是64x下到了32xJAVA，请点击下方  火狐浏览器官网直达链接
根据官网提示下载64x的火狐浏览器，然后再打开JAVA官网下载即可。
④上述操作完毕后，请您安装好JAVA(32x或64x),然后点击系统任务栏开始按钮
找到 配置JAVA 这个应用程序,在弹出的 JAVA控制面板里点击左上角的 JAVA
的栏目后,再点击 查看 在弹出的 Java运行环境设置 中找到与您系统不匹配的
Java版本(32x的Java会显示为x86,64x会显示为x86_64,请看清楚再取消)，
将它的 启用 取消勾选即可,完成后关闭控制面板,再打开启动器检查Java即可。

2 )  本整合包文件不可与其他Mc版本放置一起，将引起上述无法游玩的情况。
此处启动器有一些bug,请不要勾选  启用游戏特定设置(不影响游戏版本)
（测试的原因是启动游戏时启动器的识别混淆）
