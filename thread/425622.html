我没听明白。。。 你是想说服务器名称不知道是什么么？

下面是config的一部分：有汉化 来自一个很远的地方

  1.   # 是否强制默认服务器 不强制则自动上一次登陆时服务器
  2.   force_default_server: false
  3.   tab_list: GLOBAL_PING
  4.   # 服务器名称
  5.   motd: A Minecraft Server
  6.   # 默认从哪个服务器启动
  7.   default_server: server1
  8.   forced_hosts:
  9.     pvp.md-5.net: pvp
  10. timeout: 30000
  11. servers:
  12. # 此处定义服务器名称
  13.   server1:
  14. # 服务器ip 一般直接localhost:+端口号
  15.     address: localhost:25565
  16.     restricted: false
  17. # 此服务器的Motd
  18.     motd: A Minecraft Server
  19. # 正版登陆
  20. online_mode: false
