★ 简介
这个MOD加入了一个新的敌对生物：邪猎者
这个生物属于“灾厄村民”中的一个生物
因此你可以体验一个刺激的生存模式

原文：
HunterIllager


This mod is add hunterillager

It will be a bit exciting for survival!


★ 特色
邪猎者会住在刷在平原生物群系的木屋中，然后在木屋旁巡逻，当他们看到动物和玩家时，它们会用箭进行攻击（1.14.4版本还有一部分邪猎者会使用回力镖），他们还是很强悍的，当他们杀死玩家时，他会发出挑衅的笑声。而且，当他找到一个掉落的食物时，他会将它捡起并在战斗时比较虚弱的时候吃下回复体力。

顺带一提，邪猎者也会攻击僵尸一类的夜晚野外刷新的敌对生物。
在邪猎者的木屋中，会刷新一个战利品箱子。

原文：
They live on WoodHut in Plain Type biome and crawl around the house
Seeing animals and players attack with arrows
They're a little sassy, and when they defeat the enemy they emit a saucy laughter

Also, when they find food they pick it up and eat it when it gets weak in battle


★ 配置文件
配置文件只有1.12.2版本会生成，路径：.minecraft/config
还是要吐槽以下这配置文件的不规范= = 可能也就我有这点闲心来仔细研究翻译配置文件了
  1. # 配置文件

  3. general {
  4.     # 当你设置为true时，动物会逃避邪猎者
  5.     B:animal_RanAway=true

  7.     # 当你设置为true时，邪猎者将会使用深色橡木作为他们木屋的主题
  8.     B:darkoak_theme=false

  10.     # 这里时邪猎者木屋的生成率X，那么在X个平原生物群系中会出现一个邪猎者木屋
  11.     # Min: 500
  12.     # Max: 1000
  13.     I:woodhutGen=540
  14. }


复制代码

原文：
  1. # Configuration file

  3. general {
  4.     # When this is true, HunterIllager use Dark Oak theme on WoodHut
  5.     B:animal_RanAway=true

  7.     # When this is true, HunterIllager
  8.     B:darkoak_theme=false

  10.     # WoodHut Rarity Given this value as X, 1 hut will spawn in X plain type biome chunks
  11.     # Min: 500
  12.     # Max: 1000
  13.     I:woodhutGen=540
  14. }
