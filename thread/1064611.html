FuturePlots
   目前广泛应用的PlotSquared插件存在诸多问题，如不支持经济前置，在红石核心使用会出现很多BUG，即使是正常使用也会出现许多蜜汁BUG。因此，这款插件诞生了！这是一款操作便捷、兼容性更高、BUG更少的地皮插件！支持经济前置和红石分支核心！
原作者：
tim03we （来自NukkitX论坛）
前置插件：
EconomyAPI（经济前置）用于在玩家领取/清空/删除地皮时扣费，如果您选择在FuturePlots配置中禁用EconomyAPI，那么您无需下载此插件作为前置。
EconomyAPI下载地址：
原贴地址
Border System（边界系统）
非硬性前置！如果您想更改您地皮的边界，请下载它！如果您无需更改边界，那么就不用下载。
Border System下载地址：
https://nukkitx.com/resources/bordersystem-futureplots.479/ （原贴地址）
https://www.mcbbs.net/thread-1064572-1-1.html （站内地址）


命令（如何使用）：
将插件及其前置插件放入服务器plugins文件夹，重启服务器。
进入游戏，管理员输入/plot generate 生成的世界名字 以生成一个地皮世界，无需提前导入一个地皮世界。生成完地皮世界后，可以在配置文件对一些细节进行修改。下面是详细内容：
————————————————————————————————————————————————————
命令           二级命令(前面记得带上/plot )   简写                   描述
/plot                                                        plots, p           总命令                          
           generate <world>                         gen                生成一个地皮世界
           addhelper <player>                       trust              添加一个地皮管理员
           addmember <player>                                         添加一个地皮成员，只有地皮主人在线时他才能进行建造和破坏。
           removemember <player>              rmmember      移除一个地皮成员
           removehelper <player>                 rmhelper         移除一个地皮管理员
           auto                                                                  自动寻找一个空地皮
           claim                                            c                    领取（购买）一个地皮
           clear                                             reset              清空一个地皮
           dispose                                                              销毁一个地皮
           delete                                          del                 删除一个地皮
           help <page>                                                       呼出地皮命令帮助
           home <number> <world>                h                     前往你的地皮
           homes                                                               列出你的地皮
           info                                             i                     展示地皮信息
           deny <player>                                                   禁止一个玩家进入你的地皮
           undeny <player>                                               允许一个玩家进入你的地皮
           kick <player>                                                    从你的地皮中踢出某个玩家

配置文件汉化：
本汉化配置文件仅供参考，不可直接复制到config中使用！
  1. ---
  2. # 请勿更改版本，这会导致文件被删除。
  3. version: "1.1.0"

  5. # Available languages: eng, deu, kor（支持的语言）
  6. lang: "eng"

  8. # Available providers: yaml（数据的提供/储存方式，支持MySQL，不过没有特殊需求的话一般不用管这项，用yaml即可）
  9. provider: "yaml"

  11. # How many plots a player can own（每个玩家最多能领取多少地皮）
  12. max-plots: 4

  14. # Determine if you should be teleported to the plot border when the plot is claimed（当地皮被领取时是否传送玩家到该地皮边界）
  15. teleport-on-claim: true（true为开启/启用，false为关闭/禁用，下同）

  17. # Whether the popup should appear when you enter a plot（当玩家进入一个地皮时，是否弹出下方popup显示）
  18. show-popup: true

  20. # Decide here whether Economy should be used for claiming, emptying and deleting plots（是否在领取地皮，清空地皮和删除地皮时启用经济前置，即执行上述操作时是否扣费）
  21. economy: true

  23. # Here you find the plot configurations,
  24. # how the plot world should look like later, when the world is generated for the first time（地皮世界生成的样子）
  25. default-settings:（默认设置）
  26.   plotSize: 32（地皮大小，即多少x多少边长大小）
  27.   roadBlock: "43:6"（构成每个地皮之间的道路的方块）
  28.   wall:（构成地皮边界的方块）
  29.     unclaimed: "44:0"（未被领取时）
  30.     claimed: "44:1"（已被领取时）
  31.   bottomBlock: "7:0"（构成地皮底部的方块）
  32.   plotFloorBlock: "2:0"（构成地皮表层的方块）
  33.   plotFillBlock: "1:0"（填充地皮的方块）
  34.   roadWidth: 7（道路宽度）
  35.   groundHeight: 64（地皮从底部到表层的高度）
  36.   price:（价格，仅启用经济前置时生效）
  37.     claim: 500（领取地皮价格）
  38.     clear: 300（清空地皮价格）
  39.     delete: 100（删除地皮价格）
  40.     dispose: 500（解锁地皮价格）
  41. ...
