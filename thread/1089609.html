木 牌 系 统
该插件大概提供了三个办法 (只是大概...



第一个:购买幸运方块的木牌(单独购买幸运方块)
在木牌的第二行写上!LuckyShop
在第三行写上一次出售的数量
然后玩家点击即可购买



第二个:打开幸运商店的木牌
在木牌的第二行写上!LuckyShop
第三行写上shop
然后玩家点击即可打开商店



第三个:兑换幸运金币的木牌
方块奖品中有一种奖品是幸运金币
玩家手持金币右键点击该木牌即可兑换随机金钱
木牌第二行写上!LuckyCoin即可创建

玩家指令
/lb help 查看插件帮助
/lb shop 打开幸运方块商店
玩家权限
luckyblocksuper.use.break 挖掉幸运方块并获得奖励
luckyblocksuper.use.place 放置幸运方块
luckyblocksuper.use.BuySign 使用木牌购买幸运方块
luckyblocksuper.use.BuyCmd 使用指令购买幸运方块
luckyblocksuper.use.shop 打开幸运方块商店
luckyblocksuper.use.partyblock 使用派对方块
luckyblocksuper.use.ebow 使用爆炸弓
luckyblocksuper.use.redeemcoins 使用幸运硬币兑换钱
luckyblocksuper.use.placeHorse 使用RayHorse方块放置马
luckyblocksuper.use.wand.<魔杖名> 使用魔杖
luckyblocksuper.use.ammo.<可投掷名> 使用可投掷物品

管理员指令
/lb admin 查看管理员指令帮助
/lb admin menu 查看管理员物品菜单，管理员可随意获得魔杖等物品
/lb admin give <数量> [玩家] 给予幸运方块，玩家名缺省默认自己
/lb admin givecoins <数量> 给予幸运硬币
/lb admin stopparty 强制停止所有幸运方块派对
