标题: DeluxeTags,怎么设置右键一个物品就可以获得某个称号
作者: Orange-Xo    时间: 2020-7-6 15:45
提示: 作者被禁止或删除 内容自动屏蔽
作者: 名副其实    时间: 2020-7-6 15:45
  1. 称号1:
  2.   # 触发时检测的描述，既物品上的Lore
  3.   检测描述: '&7右键使用获得"XXX"称号'
  4.   # 触发的点击类型，可以是 左键 右键
  5.   点击类型: 右键
  6.   # 所有模块条件通过后由玩家身上发出的指令，支持玩家名变量%player%
  7.   # [op]: 开头将会让玩家以最高权限使用指令
  8.   玩家指令:
  9.   - '[op]:deluxetags set %player_name% AAA'
  10.   # 所有模块条件通过后由后台发出的指令，支持玩家名变量%player%
  11.   后台指令: []
  12.   # 所有模块条件通过后是否向玩家发送一条信息
  13.   开启使用提醒: true
  14.   # 所有模块条件通过后向玩家发送的信息
  15.   使用信息: '&e[系统] &b你已成功切换称号&aXXX。'
  16.   # 用于检测物品数量以及消耗物品
  17.   物品模块:
  18.     需求堆叠数量: 1
  19.     需求不足提示: '&c需要同时持有&e1&c个此物品时才能使用'
  20.     # 若为消耗true，则所有模块条件通过后将会拿走需求堆叠数量个物品
  21.     是否消耗物品: true
  22.   # 用于让物品在一次使用过后在一段时间内无法再次使用
  23.   # 可用于物品技能的冷却，礼包领取间隔
  24.   冷却模块:
  25.     是否启用该模块: true
  26.     # 拥有相同冷却组的触发将会共享冷却
  27.     冷却组: '生命药剂'
  28.     # 单位为毫秒
  29.     冷却时间: 20000
  30.     是否提醒冷却中: true
  31.     # 尝试使用冷却中的物品时的提示信息，%less%为剩余冷却时间变量
  32.     冷却中提醒信息: '&e称号更换&c类道具处于冷却中，剩余时间&e%less%&c。'
  33.   # 用于让物品需要某权限才能使用
  34.   权限模块:
  35.     是否启用该模块: false
  36.     检测的权限: '药品权限.天堂的痊愈药剂'
  37.     是否提醒权限不足: false
  38.     权限不足提示信息: '&c使用此物品需要到达&e七级&c，请升级后再尝试使用'
  39.   # 用于限制物品需要玩家在某种姿势下使用
  40.   动作模块:
  41.     是否启用该模块: false
  42.     需要奔跑: false
  43.     需要蹲下: false
  44.     需要格挡: false
  45.     需要浮空: false
  46.     姿势不对是否提示: false
  47.     姿势不对提示信息: '&c该物品需要在蹲下时使用'
复制代码

安装GuoItemLoreCommand之后，将上述文本复制进点击触发.yml中
开头称号1可以随意修改
XXX处为你的称号(是实际显示的名称)
AAA处为称号的实际名称
