这里是Zesty@白宝石。新年第二天里为大伙再带来一款非常有趣的插件，即今天将介绍给大家的PaintBall War Edition。
彩弹射击小游戏是指两支队伍在一个竞技场内互相以雪球对射. 如果一个玩家被击中的话, 他将自动离开竞技场并等到下一场比赛开始(即为无血量设定). 在彩弹射击小游戏大厅内你将可以看见其他玩家, 选择你的队伍并等到足够多的玩家, 或者是等到比赛结束之后开始游戏. 满足了以上要求之后, 倒计时开始, 并进行下一场游戏.

基本特性：
无需客户端安装Mod即可进行游戏
大部分内容可以自定义
每个队伍包含多个出生点，分别是指红队、蓝队和观察者。每次比赛都将自动分配
只要四个指令你就能轻松做好一个竞技场并加入至竞技场循环列表内

深入细节的配置可以使小游戏和外部游戏分离，并且拥有非常好的反作弊系统
集成经济功能，用于商店和排名系统
多种数据统计：例如分数、杀敌、死亡、击中等

指令和权限：
玩家：
/pb help显示帮助页面- paintball.general
/pb lobby加入大厅
/pb blue加入蓝队
/pb red加入红队
/pb random随机加入队伍
/pb spec加入观察者
/pb leave离开队伍，如果不在队伍内离开游戏
/pb toggle是否启用小游戏内的提示信息
/pb shop [id]购买加强以及额外补给物品等- paintball.shop.not<id>
/pb stats显示你的数据
/pb rank显示你的排名
/pb top根据分数显示前十位玩家
/pb cash显示小游戏内的资金


管理员：
/pb admin显示管理员帮助指令- paintball.admin
/pb admin reload重新载入插件并将所有玩家从游戏和大厅内移出
/pb admin softreload等待所有游戏结束之后重新载入插件
/pb disable设置是否允许新游戏进行
/pb admin lobby spawn设置一个大厅出生点
/pb admin lobby remove移除大厅出生点
/pb admin next <arena>强制进入下一个竞技场
/pb admin cash <player> [amount]显示玩家金钱，加上后续参数即为给他那么多金钱
/pb admin rank <player> [amount]显示玩家排名，加上后续参数即为给他点数
/pb admin reset <all/player> [value]重置所有玩家或特定玩家的所有数据或特定数据
/pb admin helmet <blue/red/spec>将队伍的帽子改为你手中正在拿着的物品


竞技场：
/pb arena显示竞技场帮助页- paintball.arena
/pb arena <name>创建一个新的竞技场
/pb arena <name> blue创建蓝队出生点
/pb arena <name> red创建红队出生点
/pb arena <name> spec创建观察者出生点
/pb arena <name> remove删除竞技场
/pb arena <name> delblue删除蓝队出生点
/pb arena <name> delred删除红队出生点
/pb arena <name> delspec删除观察者出生点
/pb arena <name> size <number>定义竞技场的大小（暂时无用）
/pb arena info <name>获取竞技场的信息
/pb arena list获取竞技场的列表
