插件介绍

MC中的黎明杀机
功能非常完整、完美复刻了黎明杀机的修机、开箱、捉人、放板(2.6更新)、多职业并且可以自定义职业

拥有api可以自定义技能等(专业版更多)
可以使用木牌来开始游戏
支持BC和MYSQL数据库

插件指令

/dbd join [竞技场名称]   加入竞技场  如不输入竞技场名称为随机加入（专业版）
/dbd leave 离开游戏
/dbd stats [玩家名]    查看玩家游戏统计（专业版）
/dbd create [竞技场名]   创建竞技场
/dbd gui  打开竞技场设置gui
/dbd set [generator/jail/survivorspawn/door] [数] 以你脚下创建为[发电机/监狱/幸存者出生点/门] 数
/dbd set [lobby/hunterspawn]  设置脚下为[游戏大厅/猎人出生点]
/dbd version 查看插件版本
/dbd debug 发电机速度修理模式（仅限游戏内的幸存者使用）
/dbd exit 退出竞技场编辑模式
/dbd buy [角色名]  购买一个角色
/dbd edit [竞技场名] 进入竞技场编辑模式
/dbd generatorgpeed [乘数]   发电机维修速度加倍
/dbd finish 保存地图
插件权限
- dbd.join         加入游戏的权限
- dbd.create     创建游戏的权限
- dbd.start       强制开始游戏的权限

游戏相关设置

1.首先创建一个竞技场/dbd create 不解释
2.站在你想要设置等待大厅的位置输入/dbd set lobby
3.站在你想要设置猎人出生点的地方输入/dbd set hunterspawn
4.站在你想要设置发电机（必须为末影箱）上面输入/dbd set generator [1-5]
5.地图上放置的箱子会自动启用为游戏箱，放置的橡木活板门为板子
6.站在你想要设置监狱的方块上输入/dbd set jail [1-7]
7.设置幸存者出生点/dbd set survivorspawn [1-4]
8.设置幸存者大门：/dbd set door [1-3]
（这里的门并不是真正意义的门，只是一个区域，当幸存者修复完所有发电机后到达这里获得胜利）
9.全部设置完成后会显示：
All points were set.Save now with /dbd finish
告诉你已经全部设置完成，如果没有提示则证明你遗漏了什么，这时候输入 /dbd finish即可保存
ps.橡木活板门即为板子
木牌设置教程：
第一行输入[dbd]
第二行直接输入竞技场名
然后右键木牌启用即可
