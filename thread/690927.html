前言:  
  调用过NMS的方法的都知道，你调用NMS的版本必须与你服务器的版本相对应。我这里说的版本不是1.8.8啊1.8.7啊这类，而是类似于v1_8_R4啊v1_8_R1这类，1.8这么多版本，其实在服务器的版本里只有1_8_R1、1_8_R2、1_8_R3（别的同理）。那如果你想多版本兼容，最傻的方法便是做添加一个版本的核心到你插件的库里导入再添加另一个版本的核心进你的库里导入，这样比较麻烦，而我这种是将多个服务器核心添加到库里然后用抽象类根据服务器版本来挂钩对应版本的方法。
下面进入正题:
  在你的插件库里添加你想要兼容的服务器核心版本。

  在主类添加一个判断版本号获取对应NMS的方法

  1.         private Boolean setUpNms()
  2.         {
  3.                 String version = Bukkit.getServer().getClass().getPackage().getName().replace(".", ",").split(",")[3];
  4.                 getLogger().info("你的服务器运行在版本："+version);
  5.                 switch(version)
  6.                 {
  7.                 case "v1_8_R1":
  8.                 nms = new v1_8_R1();
  9.                 break;
  10.                 case "v1_8_R2":
  11.                 nms = new v1_8_R2();
  12.                 break;
  13.                 //别的版本以此类推
  14.                 }
  15.                 return Boolean.valueOf(nms != null);
  16.         }

指出楼主几个不足之处
1. NMS接口不需要再多加abstract修饰符，因为里面的方法默认就是抽象的。
2.setUpNms的返回值最好使用boolean而不是Boolean，拆包封包也是很消耗时间的
3.方法结尾没有必要再加return了
