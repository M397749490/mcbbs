上面的方法试的但还是无法进入？    试试这个 打开开始菜单 运行 输入 cmd 输入ipconfig 回车 找到本地连接的Default Gateway 记下来  然后在浏览器的网址栏输入 这个Default Gateway 后面的数字 出现方框 里面的账号和密码都是admin 找到转发规则——Dmz主机 然后在方框输入你的本地连接IP地址 然后点保存 别人就能进来了
