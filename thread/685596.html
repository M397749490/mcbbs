AddLight——隐形的光源

简介
一个Bukkit插件（其他服务端没有测试过，可用欢迎反馈），可以在服务器中添加不可见的光源，亮度可调哦~
可以收费添加光源XD
依赖插件:
从4.0.0版本开始，AddLight不再需要LightAPI的前置。

但如果你在使用老版本的插件，你需要LightAPI  作者：BeYkeRYkt.
因为BeYkeRYkt经常改变这个API, 所以下面给出各版本对应的LightAPI。

AddLight 1.4.0 —— LightAPI 2.0.2 用于 1.8.8 ~ 1.9.4
AddLight 1.5.0 —— LightAPI 3.0.0 用于 1.8.8 ~ 1.10
AddLight 3.1.1 —— LightAPI 3.1.0 用于 1.8.8 ~ 1.10
AddLight 4.0.1 —— 1.8.8 ~ 1.11

作者授权


使用方法
添加光源：
  • 手持萤石粉左键添加，右键移除XD
命令：
  • /AddLight help 显示插件的帮助
  • /AddLight [enable|on] : 允许添加隐藏光源
  • /AddLight [disable|off] : 禁止添加隐藏光源
  • /AddLight ConnectedBlocks : 使选中的所有方块发光 (很友善？)(需要WorldEdit)
  • Create lights to all connected blocks (be very carreful)这句不会翻译
  • /AddLight <number>: 调整光线亮度 (1-15)
  • /AddLight [reload] : 重载插件
权限：

  • AddLight.admin :具有其他所有权限（除去intensity和bypass.cost）
  • AddLight.user : （只具有use权限）
  • AddLight.use : 允许玩家使用这个插件
  • AddLight.worldedit : 允许使用/AddLight ConnectedBlocks命令（貌似）
  • AddLight.connected : AddLight 可以用于所有连接块（雾）
  • AddLight.intensity : 玩家可以改变光线亮度
  • AddLight.bypass.cost : 有该权限的玩家无需花费（VIP？）
