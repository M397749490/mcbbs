C O M B A T I N F O
战 斗 信 息 显 示


CombatInfo 插件可以：
自定义战斗消息——
    显示攻击你的人的名字与你攻击的人的名字
    显示攻击你的人的血量值与你攻击的人的血量值
    支持消息的自定义，可在配置文件中配置
自带修复——
    自带小数修复，你不会看到 0.5649646541654 ← 这种血量值
    ——你会看到 0.5
    支持显示血量值与显示【爱心】值的切换
    如一位玩家的血量值是 10.0 你可以切换选择 显示为 5.0
支持消息的不同输出方式——
    —— 最普通的方式 输出到聊天栏
    —— 输出到 ActionBar （需要 ActionAnnouncer 插件的支持 | Mcbbs.net | Spigotmc.org |）
    —— 输出到 Title（标题）

配置文件


我觉得我写的确实很清楚了=￣ω￣=


  1. setting:
  2. #全局设置
  3.   message-to-chat: true
  4.   #战斗消息是否输出到聊天栏
  5.   message-to-action-bar: false
  6.   #战斗消息是否输出到 ActionBar  需要 ActionAnnouncer 插件支持
  7.   message-to-title: false
  8.   #战斗消息是否输出到标题行

  10. format:
  11.   health-use-heart: true
  12.   #血量显示格式
  13.   # true —— 即 ? 的数量 普通玩家最大值为 10.0
  14.   # false —— 即玩家的血量 普通玩家最大值为 20.0
  15.   

  17. message:
  18. #消息设置
  19. #支持使用颜色代码 请使用 '&'
  20. #支持使用变量 变量列表：
  21. #%damager% 攻击者的名字
  22. #%damager-health% 攻击者的血量
  23. #%victim% 受伤者的名字
  24. #%victim-health% 受伤者的血量
  25.   damager: '&a[&6战斗信息&a] &2您&a(&2%damager-health%&c?&a)&e攻击了&4%victim%&a(&4%victim-health%&c?&a)'
  26.   #显示给攻击者的消息
  27.   victim: '&a[&6战斗信息&a] &4您&a(&4%victim-health%&c?&a)&e被&2%damager%&a(&2%damager-health%&c?&a)&e攻击了'
  28.   #显示给受伤者的消息
