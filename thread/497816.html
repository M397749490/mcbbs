这次给大家带来了个轻量级插件



插件介绍：
适合中小型服务器使用（大型也支持），玩家挖爆一个钻石原矿就会在屏幕上显示，如果自己服务器没有安装反矿物追踪和透视（反透视会有点拖慢服务器），就可以试试这个插件，如果玩家作弊了，那么一直显示挖到钻石是不是很奇怪？那么这个玩家肯定是使用矿物追踪或者透视了！


先上个图，无图无真相



指令和权限（非常神奇。。其实也没用，不过无聊发下）

指令说明
/diad查看插件版本和作者
权限说明
diamondsdug.diad打开/diad的权限


为了尊重作者发下英文版和汉化
-----DiamondsDug-----
Created by Petrosaurus
Version:8.0


汉化
-----挖钻石（插件汉化名字。。表示自己翻译好难听）-----
由Petrosaurus创造这个插件
版本：（我一直想知道，怎么会有那么高的版本？还是我翻译错了？）




配置文件"config.yml''（支持彩色字体）
  • info: true （true是开启插件，false是关闭插件）
  • message: '&e玩家 &6%player% &e找到了&c钻石' （玩家打掉钻石原矿在屏幕显示的）
  • prefix: '&f[&a防作弊系统]'  （屏幕最前面显示的文字，就是图片上面显示的[Diamonds]）
  • heal: true （打掉钻石原矿的时候，顺便回满血量）
  • sound: false （打掉钻石原矿会发出一个怪声（类似于猫叫）小心玩家第一次挖钻石被吓惨。。）
  • lacotion: true （不知道，求大神汉化！）





唯一变量：%player%（玩家姓名）


下载地址：1.7.2（DiamondsDug）插件下载

已知BUG

  • 玩家如果用精准采集运上家里再打爆（也会显示）
  • 创造模式下，打爆原矿也会显示
  • 如果还有什么BUG，请及时回帖说明，谢谢！
