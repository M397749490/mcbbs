印象中，op如果不是用/resadmin指令进行领地操作的话，也是跟普通玩家受到一样的权限限制的，你可以让op试试/resadmin create指令，可以的话就能确定是权限问题。


虽然说不需要手动给权限，但有些服务端是需要一个个给的，不知道是不是LP和GM权限插件不同的问题，我用GM都是一个个给，即使插件说有默认普通玩家有该权限


打开你领地插件文件夹里的 group.yml文件，检查一下权限组相关
group.yml 部分中文注释：

  1. Groups:
  2.     Default: #组名，不要删除这个组
  3.        #删除下面的井号可将此配置应用到其他组

  6.          #- 'group2'
  7.        Residence:

  11.            MaxResidences: 3

  15.            MaxEastWest: 16

  17.            MinEastWest: 3

  19.            MaxNorthSouth: 16
  20.            # 领地最小格数（南北方向）
  21.            MinNorthSouth: 3
  22.            # 领地最大格数（高度）
  23.            MaxUpDown: 256
  24.            # 领地最小格数（高度），设为-1则不限制
  25.            MinUpDown: 3

  27.            MinHeight: 0
  28.            # 可创建领地的最大高度
  29.            MaxHeight: 255
  30.            # 所在区域可拥有的最大子领地数量
  31.            MaxSubzonesInArea: 3
  32.             # 最大子领地深度
  33.             # 一个领地中的子领地中的子领地深度为2
  34.             # 设为0以禁用子领地

  44.            SubzoneMinNorthSouth: 3

  46.            SubzoneMaxUpDown: 256

  50.            CanTeleport: true
