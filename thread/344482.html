 创建后有2个Unturned.exe

把其中一个右键===属性 找到目标

在目标的后面的方框里输入

”*:\Steam\steamapps\common\Unturned\Unturned.exe" -nographics -batchmode +secureserver/服务端名字(可多创建)”在-前面是你的Un目录

比如我的是
“F:\Program Files\Steam\steamapps\common\Unturned\Unturned.exe" -nographics -batchmode +secureserver/服务端名字”

每个+（加）和-(减)前面都要有空格 否则出错 引号后也要有空格

2335是我的服务器名称 也算是在游戏里面的名称

改好后点确定 然后打开刚刚改的那个Unturned.exe

打开后有个像CMD一样的窗口
在里面输入“shutdown”必须手动输入(版本3.6.6和后面版本请无视)
输入完俺Enter键 会自动退出 然后重新打开刚刚那个 修改过目录的Unturned.exe 这就是开服成功了
开服成功后在根目录里会出现Servers文件夹
打开后会有你那个服务器名称
3.6.6后的：

打开刚刚编辑的那个快捷方式（打开后目录有servers后直接关闭）
进入“\Unturned\Servers\刚刚输入的名称\Server”
会有“Commands.dat”


在里面输入：
Password 密码
Maxplayers 人数 （上线16）
Map 地图名称
Welcome 欢迎语
port 端口（默认27015）
┌PVP 玩家伤害
     └ PVE 无玩家伤害
Mode 游戏难度（normal普通难度 easy简单难度 hard困难难度 gold黄金难度[需要买DLC才能进]）
loadout 出生装备 （loadout 物品ID/物品ID/物品ID/......可多打）
perspective 视角(第一人称first 第三人称third 两种人称都有both)


我写的是
Name caominjia168
Password caominjia168
Maxplayers 24 3.0.2以后人数最多为24人
Map Devtest  （最初的地图）
Welcome 欢迎来到caominjia168
Mode easy
loadout 1/2/3/4/5
perspective both


（地图都在,,,\Steam\steamapps\common\Unturned\Maps目录内也可以去创意工坊下载）
然后保存
打开那个修改过的Unturned.exe（可以把名称修改一下 以防看错）
然后打开你的steam左上角有个查看 查看里有个服务器
点击服务器

play-----connect
IP 是127.0.0.1（自己内网IP）
Port是27015
password（密码）：自己填写在Commands.dat里填写的密码

注：在服务端上输入help是服务器指令

如果是猫连接的话 可以在游戏内的服务器列表找到
