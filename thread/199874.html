两种

Ferullo
"R" = 放大
"F" = 装载弹♂药
"C" = 打开枪械状态设置 GUI
鼠标左键（或者右键····好久不玩···不觉得了）开枪

flan's
团队控制
G : 打开团队选择菜单
H : 打开团队得分菜单


飞机或载具控制
（这些设置可以在游戏选项里更改）
E : 离开飞机或载具
R : 飞机或载具的加载物品栏

飞机（简单控制模式）与载具
W : 加速
S : 减速/后退
A : 左转
D : 右转
左Ctrl : 机枪射击
V : 扔炸弹l
空格：爬升（仅限飞机）
左Shift : 下降（仅限飞机）
C : 切换控制模式（仅限飞机）

飞机（鼠标控制方法）
其它控制与上面相同，除了爬升与下降：
鼠标上/下：爬升/下降
鼠标左/右：左转/右转
左键：机枪
右键：炸弹
鼠标右键开枪
