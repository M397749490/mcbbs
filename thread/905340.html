NeverLag1.3.0清道夫

看到  #不清理的世界名字
  NoClearItemWorld:
里面有个 -'DIM-42'
把你里面的世界全删了就行了
  1. # 清理掉落物品
  2. ClearItem:
  3.   #是否开启
  4.   Enable: false
  5.   #不清理的世界名字
  6.   NoClearItemWorld:
  7.   - 'DIM-42'
  8.   #清理周期
  9.   Delay: 900
  10.   #不清理的物品ID，如贵重物品
  11.   NoClearItemIDList:
  12.   - 7
  13.   #是否清理展示框
  14.   ClearItemFrame: false
  15.   #是否清理船
  16.   Boat: fasle
  17.   #是否清理经验球
  18.   ExpBall: true
  19.   #是否清理正在坠落的方块
  20.   FallingBlock: true
  21.   #是否清理画
  22.   Painting: false
  23.   #是否清理矿车
  24.   Minecart: false
  25.   #是否清理箭头
  26.   Arrow: true
  27.   #是否清理雪球
  28.   Snowball: true
  29.   #清理时的提示信息
  30.   Message: '&6[&b服务器娘&6]&a哎哟，这次清理了 &c%COUNT%个 &a垃圾，我感觉自己萌萌哒~'
  31.   #清理前的提示
  32.   PreMessage: '&6[&b服务器娘&6]&a地上的掉落物将在 &e%TIME%秒 &a后清除！'
