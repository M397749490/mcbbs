插件介绍

Head Drops插件可以让怪物和玩家死亡后掉落他们的头，你可以设置掉落几率


插件指令

  1. /hd mobhead <mobname> - 给你一个怪物头
  2. /hd head [player] <playerhead> - 给其他玩家一个[玩家]的头
  3. /hd myhead - 给你自己一个自己的头
  4. /hd info [player] - 点击头会显示头属于哪个玩家
  5. /hd reload - 重载插件

插件权限

与指令对应部分就不翻译了

  1. headdrops.help: Use /hd command
  2. headdrops.head: Use /hd head <playerhead>
  3. headdrops.head.other: Use /hd head <player> <playerhead>
  4. headdrops.mobhead: Use /hd mobhead <mobname>
  5. headdrops.info: Use /hd info
  6. headdrops.info.other: Use /hd info <player>
  7. headdrops.reload: Use /hd reload
  8. headdrops.mobheaddrops: 玩家击杀怪物后是否掉落头，有该权限才掉落
  9. headdrops.playerheaddrops: 玩家击杀玩家后是否掉落头，有该权限太掉落
