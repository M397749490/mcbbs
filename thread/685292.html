下面是更新记录：
  1. BetonQuest v1.9
  2. Notes:
  3. This version breaks compatibility with plugins hooking into BetonQuest. I’m sorry for that. Ask devs to update these plugins.

  5. The error reporting feature was improved. If you see a lot of error messages when reloading the plugin (not stack traces, just regular, human-readable messages), it’s probably because there are real problems in your quests.

  7. BetonQuest won’t accept .yml extensions at the end of conversation names in main.yml. If your conversations aren’t working (the plugin says they don’t exist), check if you have these extensions in the main.yml file and remove them.

  9. Fixes:
  10. action objective now detects fire interaction
  11. empty condition now skips armor and off-hand slots
  12. Items can be used cross-package
  13. New sound names are now used by default
  14. Fixed doubled quest items when dropping them is blocked by another plugin
  15. Lore and name now appear on heads and written books with custom data
  16. Fix error when trying to add air (empty hand) with /q item command
  17. Main page now can exceed a single page in the journal
  18. The plugin will reconnect to the database if something goes wrong
  19. Fishing objective now only accepts stuff from water
  20. Properties in mobkill objective (left and amount) has switched places
  21. Changes:
  22. Complete rewrite of item conditioning - read the docs to discover new features (previous syntax is still working without any behavior changes)
  23. Books in items.yml now automatically wrap pages, like the journal and main page
  24. Main page and entries in the journal can manually split pages with | character
  25. New lines in conversations can be made with \n
  26. Interval in delay objective is now configurable
  27. craft and potion objectives now use items defined in items.yml file
  28. Potion items are now defined with type: argument instead of data value
  29. You can now use spaces between first options in conversations
  30. Static events can now be fired with /q event - eventID command
  31. Locations can have vectors defined directly in instruction strings
  32. Locations can be variables which resolve to location format
  33. Point condition can now check exact point amount with equal argument
  34. In chest conversation IO items can be specified with durability values after a colon
  35. Mobs spawned with spawn event can have armor, items in hands and custom drops
  36. Unbreakability of quest items can be disabled (if you want to use unbreakable tag instead)
  37. Ranges in locations are now a separate argument (10;20;30;world;4 is now 10;20;30;world 4)
  38. main.yml is now the only required file in the package. Empty files can be deleted
  39. Custom settings (i.e. EffectLib particle effects) are moved from main.yml to custom.yml
  40. Additions:
  41. Compatibility with Shopkeepers (shopkeeper event, shopamount condition)
  42. Compatibility with PlaceholderAPI (ph variable and betonquest placeholder)
  43. Compatibility with HolographicDisplays (holograms visible based on conditions)
  44. Compatibility with RacesAndClasses (race, class, exp, level, mana conditions/events/variables)
  45. Compatibility with LegendQuest (race, class, attribute, karma conditions/variables)
  46. Compatibility with WorldEdit (paste a schematic event)
  47. New condition riding - check if the player is riding an entity
  48. New condition world - check the world in which the player is
  49. New condition gamemode - check player’s game mode
  50. New condition achievement - check if the player has an achievement
  51. New condition variable - check if a variable matches a pattern
  52. New event lever - switches a lever
  53. New event door - opens/closes doors, trapdoors and gates
  54. New event if - run one of two events, depending on condition
  55. New event movenpc - move Citizens NPC to a location
  56. New event variable - set a variable in variable objective
  57. New objective vehicle - entering a vehicle entity
  58. New objective variable - lets players define their own variables for you to use
  59. New objective kill - kill players who meet specified conditions
  60. New objective breed - breed animals (only 1.10.2+)
  61. New variable %location% - resolves to player’s location
  62. Keyword unbreakable can be used in items to make them unbreakable
  63. When a conversation option is selected, a Bukkit event is called (for developers)
  64. Chat can be paused while in conversation, it will display when finished
  65. Objectives can be completed for players with /q objective player complete
  66. Option full_main_page controls if the main page is a separate page in the journal
  67. Mobs spawned with spawn can be marked; you can require marked mobs in mobkill objective
  68. Firework support in items
  69. Relative package paths, where _ means one package up
