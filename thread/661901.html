原贴地址

ServerListPlus 由【Sponge专组】搬运


ServerListPlus插件是一款简单而又非常强大的MOTD插件。它几乎能改变所有部分，甚至还能让你自定义显示每个玩家数量。

请注意：该插件需要安装前置"StatusProtocol"来使用该插件的所有功能。

关于授权：


功能Features

修改MOTD
服务器LOGO:可以是图片，链接，或者使用玩家的头来显示。

修改最大玩家人数

自定义显示玩家人数的格式

玩家列表显示信息：当玩家光标停留在玩家人数时显示信息。

还有更多的功能。


图片Picture

安装Installation


  • 同样可以安装到PAPER,Spigot，BC（关于CB嘛。我没测试过，但是原作者贴出来是可以支持的）
  • 下载插件和前置插件(如果不需要自定义玩家数量的话可以不用)。
  • 丢到服务器mod文件夹(不如果不是Sponge核心的话，扔进Plugins文件夹即可)。
  • 重启。
  • 修改ServerListPlus.yml文件。
  • 插件默认不做任何事情，直到使用了/slp enable，这个插件的功能才会生效。
  • 开始使用。

指令Commands

  1. /slp -显示有关插件的信息，并列出所有能用的指令。
  2. /slp reload 或者 /slp rl -重启插件。
  3. /slp save -保存插件配置。
  4. /slp enable -启动插件。
  5. /slp disable -关闭插件。
  6. /slp clean <favicons/players/requests> -删除制定功能的缓存。
