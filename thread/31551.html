我是新手,不知道有没有人发过
由于我是用水桶服务器的,而且不知道版本号((被踹..
我想有很多人想为自己的服务器设置公告吧
那我教你怎么设置吧   会的高手请勿喷我....
=================================
1.请到这里下载 插件 http://115.com/file/c265f7o3
2.安装插件后,用记事本打开[AutoMessage]里面的[config.yml]
打开后即可编辑(内容如下)


  2. settings:
  3.   enabled: true
  4.   interval: 45
  5.   prefix: '&d[&d服务器主&d]'
  6.   random: false
  7.   logToConsole: true
  8. messages:
  9. - '&6欢迎来到[Emmed]服务器!'
  10. - '&6希望你游戏愉快!'
  11. - '&6本服,只希望玩家不要随意破坏!!'
  12. - '&6服主: Guitar 管理: bieber !!'  
复制代码
可以设置字的颜色,例如 &6 = 橙色 &5 = 紫色 其他的不知道 = =+
