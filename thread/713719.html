主机版即Xbox 360，Xbox One版，PlayStation 3/4/Vita版，WiiU版，Switch版，由4J Studios为Mojang开发。
迎接新的正式版吧！
转载本贴时须要注明原作者以及本帖地址。
Change log for Content Update 48 - July 31st 2017
  • Fix for crash that occurs when animals try to breed after being put in love mode by a player that is no longer in the level.
  • 修复玩家使动物进入繁殖模式后不在此存档的动物尝试繁殖时发生的崩溃。
  • Fix for crash when joining a game while another player is sleeping in a bed.
  • 修复另一个玩家睡觉时玩家加入游戏崩溃的bug
  • Fix for random crash that can occur when exiting a game.
  • 修复退出游戏时随机崩溃的bug

Change log for Patch 1.56 - July 31st 2017
  • Fix for "Public" game option being disable for Mini Games.
  • 修复迷你游戏的“公共”游戏选项被禁用的问题。
