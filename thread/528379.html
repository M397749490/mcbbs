标题: 如何使用指令不effect一个指定计分板里的玩家
比如我创造了个计分板，之后让玩家加入，之后让玩家触发一个效果，之后不给那个指定的计分板玩家效果，如何做？
作者: lzs1234    时间: 2015-12-5 21:24
Danger_S.M 发表于 2015-12-7 21:20
额，就是不给A计分板的玩家效果，而是给B计分板或其他计分板的玩家效果

/scoreboard objectives add test dummy
创建计分板test
/scoreboard players set @e test 1
给所有实体设置计分板test分数1
/scoreboard players set @a[score_A_min=-2147483648] test 0
给所有分数在计分板能储存的最小值（包括最小值）以上的人test分数设为0（也就是说在A上有分数的都会被设为0）
/effect @a[score_test_min=1] XXX
给test分数为1的玩家XXX效果
