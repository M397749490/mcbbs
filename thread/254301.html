【绿色天空的绿宝石系列插件搬运及汉化第二弹——EmeraldMarket】

本插件由本人与@灰机rp  @航空兔子 合作完成搬运


EmeraldMarket is an emerald based economy plugin. You can create shops and add Items and prices. Each user has a bank-account where he can deposit his emeralds for buying itmes from shops.
EmeraldMarket（绿宝石商店）是一个绿宝石经济插件。你可以制作商店和添加物品和价格。每一个用户有一个绿宝石账户用于从商店购买绿宝石。

特点


FEATURES:

    Buy and sell whit emeralds
    Bank-account for each user
    Buy and sell items with metadata (like books and fireworks)
    Create infinite shops
    Users can create their own shops to sell their Items with own prices
    Create ATMs
    Scoreboard which displays the balance of now playing players


1.用绿宝石购买和售出物品
2.每一个用户都有银行账户
3.购买和售出带有附加值的物品（像书和烟花火箭）
4.制作无限商店
5.使用者可以制作他们自己的商店并以自定的价格销售
6.制作ATM机
7.展示现在在线玩家账户资金的记分板
安装

扔进plugins并重启服务器

并给玩家下列权限：
  1. emeraldMarket.open.*
  2. emeraldMarket.create.private
  3. emeraldMarket.add
  4. emeraldMarket.destroy.private
复制代码
可以通过使用下列命令完成权限添加的工作：
/mangaddp builder emeraldMarket.open.*
/mangaddp builder emeraldMarket.create.private
/mangaddp builder emeraldMarket.add
/mangaddp builder emeraldMarket.destroy.private

使用

无限商店

特点：
买物品
卖物品
无限物品
无限绿宝石
创建
输入     /em creat shop
右键一个绿宝石块

添加物品
有三种方法添加可以 买(别人的东西)/卖(给别人) 的物品。

把要添加的物品拿在手上
输入 /em add <收购价> < 卖出价>
右键相应绿宝石商店方块

把要添加的物品拿在手上
输入 /em add <物品数量><收购价> < 卖出价>
右键相应绿宝石商店方块

输入 /em add <方块id[:方块数据值]> <物品数量><收购价> < 卖出价>
右键相应绿宝石商店方块

注意
如果你想让一个物品不可被 买(别人的东西)/ 卖(给别人) ,在命令中把相应位置的价格设为0

移除物品
你可以这样从商店中移除物品:
输入 /em remove <物品在商店中的编号(1-36)>
右键相应绿宝石商店方块

使用
右键绿宝石商店方块,一张存货清单会打开
现在你可以看到这个商店在     收购/卖出 的物品
左键买下商店中的物品
右键出售你的物品

重要事项
你不能在银行里没有任何绿宝石时买东西
你物品栏中必须有一个空位来收购物品
你不能销售你物品栏中没有的东西


私人商店

特点：
卖掉你的物品
从其他玩家那购买物品
能大量的储存待销售物品库存
其他玩家购买物品付账会直接添加进你的账户
你收购其他玩家物品的金额会直接从你的帐户扣除

加入物品
参看SHOP部分教程
更改物品
参看SHOP部分教程
使用
右击一个商店方块，会打开一个物品栏

2.你可以即时看到这家商店的库存
3.如果存货空了，你必须添加物品进入库存
4.点击你想打开库存的物品

5.你可以放入物品进入货存或者从货存中取出物品

右击/左击一个物品格 移动一个物品
Shift点击一个物品格 移动整组物品
重要：
不是店主的玩家打开商店只会显示出普通的商店界面
可以为一个物品在商店中存放最多36组的库存

ATM

特点：
存储你的绿宝石
买东西时，绿宝石自动从你的帐户里扣除
卖东西时，绿宝石自动加入你的帐户

创建：
输入/em create atm
rigthclick a diamond block
右击一个钻石块

使用：
右击一个ATM方块，会打开一个物品栏 左图

那里至少有一个绿宝石块
点击它，会打开另一个物品栏 中间的图

现在你可以从你的帐户里放进/取出绿宝石 右图

左击/右击一个绿宝石的物品框：移动一个绿宝石
shift点击一个绿宝石的物品框：移动整组绿宝石

重要
你的帐户里可以看见的最大绿宝石数量是82944个
如果到达最大值，你可以加入更多的绿宝石，它们还在，只是不会显示
