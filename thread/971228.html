  1. @echo off
  2. title 标题

  4. ::分配内存 带上单位
  5. set ram=1024M

  7. ::核心jar,不需要带后缀名
  8. set jar=

  10. ::服务器崩溃后自动重启时间
  11. ::手动重启的话注释掉本行或者删掉本行
  12. ::同时需要注释掉下面的"ping -n %sec% 127.0.0.1>nul"
  13. set sec=10

  15. :1
  16. ::每次任意键后重启(过时自动重启后)清屏
  17. cls

  19. ::颜色  第一个字符为背景色,第二个为字体色
  20. color 9f

  22. ::懒的解释hhhh
  23. echo ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
  24. echo 服务器正在开启.....
  25. echo ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓

  27. ::核心命令
  28. java -Xmx%ram% -Xms%ram% -jar %jar%.jar

  30. ::手动重启请注释掉本行
  31. ::并将"::pause"行取消注释
  32. ping -n %sec% 127.0.0.1>nul

  34. ::pause
  35. goto :1
