YaWhiteList

本插件最大特点 使用组的方式来管理白名单和黑名单
黑名单可能是送的（？）下一次更新新功能的时候排版一定好看（下次一定下次一定）
指令：*若使用白名单或黑名单功能本插件将代理 /ban /whitelist /unban 指令
  1. /ywl add id [group] - 向白名单/组添加玩家
  2. /ywl del id [group] - 从白名单/组删除玩家
  3. /ywl ban id [group] - 向黑名单/组添加玩家
  4. /ywl unban id [group] - 从黑名单/组删除玩家
  5. /ywl tempban id time reason - 为黑名单玩家添加到期时间和理由
  6. /ywl addg [type:whitelist/blacklist] [group] - 添加白/黑名单组
  7. /ywl delg [type:whitelist/blacklist] [group] - 删除白/黑名单组
  8. /ywl copyg [type:whitelist/blacklist] [group] [group] - 把一个组复制到另一个组
  9. /ywl clean [type:whitelist/blacklist] id - 清除一个玩家所有的状态
  10. /ywl view [type:whitelist/blacklist] id - 查看玩家在什么组
  11. /ywl version - 显示版本
  12. /ywl help - 显示帮助
  13. /ywl reload - 重载配置文件
