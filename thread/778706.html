AdvancedBan

一款更高级的处罚管理系统


简介
    这是一款由国外大佬Leoko制作的一款集封禁、禁言、警告、踢出于一体的多功能惩罚插件。它有许多令人瞩目的功能：
    1.自定义封禁、踢出等所有的惩罚提示消息，可以使用变量、颜色代码等丰富多彩地展现惩罚公告。
    2.警告功能。如果玩家行为不足以封禁，但又不甘心简简单单的一说了事，那么就警告他！插件新增的警告功能可以给玩家下达一份警告通知，而且服主可以在config.yml上面修改被累计警告达到一定次数的处罚。对于那些屡次警告不思悔改的玩家极其有用。
    3.违规历史。管理员可以方便地查询玩家的违纪记录，从而再也不用担心忘记是否违纪的问题了！
    4.支持Mysql！服主们可以使用Mysql存储数据。
    5.支持BungeeCord！
    作者Leoko的主页：http://skamps.eu/  <-大家可以去捧捧场

插件命令

以下命令参数中，[]框住的为必须参数，<>框住的为可选参数。
| 这个符号表示“或者”
-s 加入这个参数表示私下惩罚，即不向全服务器公告玩家受罚一事。
符号@和#不可省略
/kick [玩家名字] <-s> <原因 | @原因模板>         //原因模板在下面解释
踢出一个玩家

/ban /mute /warn [玩家名字] <-s> <原因 | @原因模板>
封禁/禁言/警告一个玩家

/banip [玩家名字/IP] <-s> <原因 | @原因模板>
封禁一个玩家的IP地址，如果输入玩家名字，那么就封禁玩家在服务器所记录的IP。

/tempban /tempmute /tempwarn [玩家名字] [Xmo|Xd|Xh|Xm|Xs|#时间模板] <-s> <原因 | @原因模板>
临时封禁/禁言/警告一个玩家，该时间为指定的时间或者时间模板的时间。

/tempipban [玩家名字/IP] [Xmo|Xd|Xh|Xm|Xs|#时间模板] <-s> <原因 | @原因模板>
临时封禁/禁言/警告一个玩家的IP，该时间为指定的时间或者时间模板的时间。
此命令也可以写成: /tipban

/change-reason [ID] [新的原因]
更改ID为[ID]的惩罚原因
/change-reason [ban/mute] [玩家名字] [新的原因]
更改玩家的处罚的原因

/unban /unmute [玩家名字]
取消封禁/禁言一个玩家

/unwarn [ID]
取消ID号为[ID]的警告处罚

/unpunish [ID]
取消ID号为[ID]的处罚

/warns <玩家名字>
查看你自己或者一个玩家的警告记录

/check [玩家名字]
获得玩家状态：UUID/IP/国家/封禁状态/禁言状态/警告次数

/banlist <页数>
获取到目前为止所有有效的惩罚状态。

/history [玩家名字] <页数>
See all currently active punishments
用这个命令需要权限  ab.history

/advancedban reload
重载所有的消息配置和一些设置

/advancedban help
显示所有的命令以及简明扼要的解释

/systemprefs
显示一些对于配置插件有用的系统消息
插件权限

ab.ban.perma - 使用/ban
ab.ban.temp - 使用/tempban
ab.ban.exempt - 有此权限者无法被ban
ab.ban.notify - 收到被ban通知
ab.ban.undo - 使用/unban

ab.tempban.exempt - 有此权限者无法被临时ban
ab.tempban.notify - 收到被tempban通知

ab.ipban.perma - 使用/ipban
ab.ipban.temp - 使用/tempipban
ab.ipban.exempt - 有此权限者无法被ban-ip
ab.ipban.notify - 收到被ban-ip通知

ab.tempipban.exempt - 有此权限者无法被临时ban-ip

  1. # 默认的消息模板在Messages.yml上面
  2. # 这些模板可以在封禁、禁言、警告上面有效
  3. # 以下变量可以使用：
  4. #   %OPERATOR% - 管理员名字
  5. #   %REASON% - 惩罚原因
  6. #   %PREFIX% - 插件前缀（在Messages.yml定义）
  7. #   %DURATION% - 离处罚结束还剩的时间(如果为永久处罚，则为-1).
  8. #   %DATE% - 处罚开始的日期
  9. #   %ID% - 显示处罚的ID(也就是第一次处罚为0,，第二次处罚为1，第三次处罚为2，以此类推)
  10. #   %HEXID% - 显示处罚的ID（16进制）
  11. # 对于警告来说还有%COUNT%变量，显示到目前为止被警告的次数
