[size=14.6667px]又到了激动人心的
[size=14.6667px]食用方法了
[size=14.6667px]1.把插件买了
[size=14.6667px]2.把插件放入你的Plugins文件夹(本人推荐1.7版本,因如果选择食用1.7版本,则1.8向上支持,但1.8却不会向下支持)  
[size=14.6667px]3.进入服务器,在你心仪的大厅位置打下/arenapvp setlobby
[size=14.6667px]4.找一个小黑屋(误)来输入/arenapvp setlobbyhotbar
[size=14.6667px]5.来设置竞技场(具体怎么设置看下面)
[size=14.6667px]杀人系列：
[size=14.6667px]首先我们要知道，这个插件的职业虽然有14个，但是却分为5大类，他们分别是
[size=14.6667px]BuildUHC, MCSG, Pots, Otro和Meetup.
[size=14.6667px]首先准备一份可食用的竞技场
[size=14.6667px]像用We那样不过是用站的方式确认两个点(WE如果不知道是啥那你去死好了)
[size=14.6667px]（当然为什么要分类得看下面）
[size=14.6667px]这个就是个BuildUHC系列的竞技场例子
[size=14.6667px]首先站在图里的Point1,Point2,依次输入/bmap set point1(2) BuildUHC 1
[size=14.6667px]详解指令:
[size=14.6667px]/bmap set Point1 [种类] 地图编号/名字(想怎么写怎么写但是不能中文或者重复
[size=14.6667px]然后站在图中的p2,p1(这里是竞技场出生点,你爱设那里设哪里,不过不能出竞技场或者在空气上)[格式与上面的没区别]
[size=14.6667px]当这些准备工作准备好了
[size=14.6667px]便可以输入/bmap enable [种类] [地图编号]
[size=14.6667px]然后
[size=14.6667px]大功告成了！！！！！
[size=14.6667px]啧啧啧
[size=14.6667px]这只是介绍了一个种类
[size=14.6667px]咱们再来一个吧
[size=14.6667px]Pots和Otro(说好只有一个呢)
[size=14.6667px]别急，因为他们是一起的!
[size=14.6667px]现在的话,就不用输入Point2（1）了
[size=14.6667px]我们只需要输入/bmap set p1(2) [地图种类] [地图编号]
[size=14.6667px]/bmap enable [地图种类] [地图编号] 就可以啦！
[size=14.6667px]Otro同理:
[size=14.6667px]/bmap set p1 McSg 1
[size=14.6667px]/bmap set p2 McSg 1
[size=14.6667px]最后,使用/bmap enable Otro 1
