MoarStuff
警告
此插件作者已弃坑，并且该插件有一定难度学习，不建议使用本插件
简介：
MoarStuff是一个能在Bukkit服务器创造自定义物品的插件，它不需要安装任何的MOD。你可以创造自定义食物、饮料、弓箭、护甲、剑、方块、钓鱼杆等。例如，给人凋零药水效果的弓箭，喝完让人速度快的汤，攻击时，让怪物爆炸的剑！这一切都靠你的想象力！



<-----你相信这是不加MOD的合成吗！！

安装：
1.下载这个插件
2.把解压之后的文件放入服务器的plugins文件夹里
3.重启服务器
4.编辑配置文件，创造新的自定义物品
5.给个回复支持我吧(=^.^=)




创建自定义物品：
MoarStuff插件的作者正在不断考虑添加新的自定义效果。
从可以射出末影之眼的弓箭，到获得药水效果的汤，再到可以抓到熟鱼的钓鱼杆。
这个插件正在不断添加新内容。
所以你们有什么新的点子，不妨告诉我，我会联系作者的！


创建自定义物品的步骤
*.在plugins\moarstuff\物品种类 里复制一份新的默认自定义物品配置文件（建议保留并不要修改默认配置文件，这样创建新的物品就不会麻烦）
*.重新命名这个文件（建议以物品名称命名）
*.用一个编辑器打开 (建议NOTEPAD!!!)
*.开始自定义你的物品吧（下面有详细说明，编写中）！
*.重载插件或重启服务器（插件不自带重载命令）

自定义物品配置文件：弓箭：

  1. #####################################
  2. #     这是样本文件                  #
  3. #         作为样本， 建议不要编辑!  #
  4. #####################################
  5. #
  6. #========================================================================================================
  7. #           ***名字***
  8. # 弓箭的名字 - 这个名字是在游戏里显示的名字, 并且支持颜色代码 &
  9. name: '&2示例弓箭'
  10. #========================================================================================================
  11. #           ***描述***
  12. # 弓箭的描述. 也会显示在游戏中.
  13. # 如果需要添加行, 只需要按格式添加.. 例如:
  14. # 6: '测试弓箭'
  15. # 记住要与前面对齐!
  16. description:
  17.     1: '&d描述行1'
  18.     2: '&a描述行2'
  19.     3: '&6描述行3'
  20.     4: '描述行4'
  21.     5: '&3描述行5'
  22. #========================================================================================================
  23. #          ***权限***
  24. # 合成这个物品的权限（建议为英文）
  25. permission: MoarStuff.Bows.Bow1
  26. #========================================================================================================
  27. #           ***物品ID***
  28. # 合成后物品ID，只能为原版原有的ID
  29. item-type: 261
  30. #========================================================================================================
  31. #               *** 合成 ***
  32. # 如果合成没有摆放规则,即任意摆放都可以. 则直接在下面添加物品ID. 例如:
  33. # ingredients:
  34. # - 02
  35. # - 07
  36. #
  37. # 如果合成有摆放规则, 配置有一些难度.
  38. # Each number represents a possible spot in the recipe.
  39. # Next to the number, after the semicolon, add the item id which it represents
  40. # 例如:
  41. # 1: 2
  42. # We just made it so that '1' represents 2 or 'grass'.
  43. # When we call it in our shape, it will represent grass in the crafting table spot.
  44. # The numbers are ordered like so:
  45. # 左上, 上, 右上, 左, 中, 右, 左下, 下, 右下
  46. recipe:
  47.     shapeless:
  48.         ingredients: []
  49.     shaped:
  50.         ingredients:
  51.             a:
  52.             b:
  53.             c:
  54.             d:
  55.             e:
  56.             f:
  57.             g:
  58.             h:
  59.             i:
  60.         shape: aaa,aaa,aaa
  61. #========================================================================================================
  62. #           *** 效果 ***
  63. #
  64. # 这是整个插件最难配置以及最精华的地方.
  65. #
  66. # Bows only have the option to check when the bow fires, or when the arrow from the bow hits.
  67. #
  68. effects:
  69.     on_shoot:
  70.         test:
  71.     on_hit:
复制代码
