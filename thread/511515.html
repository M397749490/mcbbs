这个插件能在游戏中给玩家显示MOTD，还可以设置成每天都不一样的哦！想知道怎么做吗，往下看↓↓↓
变量（可添加在MOTD中）
  • %player% - 玩家列表
  • %nick% - 玩家昵称列表，支持彩字，支持显示前缀后缀
  • %world% - 某个世界的玩家列表
  • %time% - 时间.(0-24000)
  • %weather% - 天气 (rain 或者 clear)
  • %ip% - 玩家的IP
  • %playerlist% - 在线玩家
  • %d% - 现实中的天数
  • %mo% - 现实中的月数
  • %yr% - 现实中的年数
  • %h% - 现实中小时
  • %mi% - 现实中分钟
  • %s% - 现实中秒
  • %exp% - 玩家经验
  • %lev% - 玩家等级
  • %totalexp% - 总的经验？
  • %food% - 玩家饥饿值
  • %x% - 玩家的X坐标
  • %y% - 玩家的Y坐标
  • %z% - 玩家的Z坐标
  • %op% - 玩家是否是op（ture/false）
  • %mode% - 玩家游戏模式（生存/创造/冒险）
  • ^example.example - 检测玩家是否有example.example权限（ture/false)
  • /n - motd中的下一行（相当于回车)
  • %whitelist% - 在白名单中的玩家列表
  • %banlist% - 被踢的玩家列表了
  • %timestat% - 白天或黑夜
  • %allowednether% -服务器是否有末地 (true | false)
  • %allowflight% -PVP是否允许 (true | false)
  • %serverip% - 服务器IP
  • %serverport% - 服务器端口
  • %serverid% - 服务器id（随机数字）？
  • %env% - 玩家所在世界环境（普通/地狱/末地）
  • %nplayersonline% - 在线玩家数
  • %nmaxplayers% - 服务器最多玩家数
  • %ptime% - 玩家的时间 (也许不和世界时间一样)？
  • %ptimestat% - 玩家的白天或黑夜？
  • %worlds% -服务器运行的世界？
  • %plugins% - 服务器上的插件
  • %day% - 我的世界天数

j接下来说说怎么改变每天的MOTD
在游戏里输
/motd set <内容>设置默认MOTD
/motd set <月> <日> <内容>设置哪一天的特殊MOTD
或直接改配置文件
在REALMOTD文件夹
1、设置一个某天的特殊MOTD
在配置文件（最新版，其他版本的配置文件可能不同）里有个mode：，在冒号后面填Daily
创建一个名为motd_<月>_<日>.txt  注意是txt不是yml
然后在里面写MOTD
如果没有哪天的MOTD，就会使用默认的MOTD
2、设置随机MOTD
在配置文件（最新版，其他版本的配置文件可能不同）里有个mode：，在冒号后面填Radom
在创建许多txt名字随便写，越多越好
3、设置永久MOTD
在配置文件（最新版，其他版本的配置文件可能不同）里有个mode：，在冒号后面填Single
在创建一个名为motd.txt的文件
然后在里面写MOTD
Config文件（最新版）
  1. command: '>'
  2. decorators:
  3.   - 'color_names'
  4.   - 'custom_formatting'
  5.   - 'rainbow'
