作者: 天辉胡萝卜    时间: 2020-3-7 03:03
你可能在服务器的ess插件里面关闭了水的流动

先关闭服务器，打开服务器目录下的plugins\Essentials\config.yml
找到这一行

  1. protect:
  2.   # 总体的物理现象或行为的设置
  3.   prevent:                                 # 阻止以下现象(译注:true就是阻止,false是允许,这里需要注意一下)
  4.     lava-flow: false                       # 阻止 岩浆的流动
  5.     water-flow: true                      # 阻止 水的流动
  6.     water-bucket-flow: false               # 阻止 水桶水的流动
复制代码


把water-flow那里的true改成false，之后保存，再开启服务器
