常见的问题：
Lawful版 和 Anarchy 版分别有什么区别？
Anarchy 版使用的是核心mod，而 Lawful 版的不是
通常 Lawful 版侵入较小（可以更好的兼容其他 MOD ），但大多数情况下最好是使用 Anarchy 版

该 MOD 用的是什么协议？我可以在我的整合包中使用它吗？
使用的是 GPLv3 协议，与原来的 FoamFix 一样
因此，只要在 GPL 下发布对 FoamFix 的修改，并且 FoamFix 中的任何代码都保留在GPL或兼容许可下，就可以将其用于任意整合包。

FoamFixUnofficial 与原先的 FoamFix 有啥区别？
并没区别，我没做任何的改变。我构建的所有东西都在 FoamFix's source code
但是，这些构建署名用的都是我的密钥而不是 asie’s 的，因为我没有 asie’s 个人密钥的备份

FoamFix 可以只在服务端上拥有而客户端没有或者客户端拥有而服务端没有吗？
当然可以

你能否将 FoamFix 移植到 1.7 中？
完全没必要，FoamFix 只是专门针对 1.8 以上才会出现的问题进行优化的。

我可以在开发环境中运行 FoamFix 吗？
可以，但你需要 手动 反 BON2 混淆

好，我安装了 FoamFix 后，还需要做什么吗？
1. 安装 BetterFPS – 他针对优化了 FoamFix 没有进行优化的部分
2. 打开 forge.cfg ，将 alwaysSetupTerrainOffThread 选项开启
3. 关闭 mipmap
4. 在服务端中将 max-tick-time 设为 0 ，预防崩溃
