每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。
Minecraft 1.13 仍未发布，17w46a为其第5个预览版。

Minecraft 快照 17w46a

Java 1.13 的快照


这周的快照修复了新的命令系统的大量bug，包括我们正在测试的新的命令UI，以及配置数据包的命令！

变动
  • 对马的模型进行了更多调整。
  • 新的命令UI的样板，这仍然不是最终版本。现在任何时候按下tab都会列出命令建议的参数。
  • 新命令 /datapack，详情如下。
  • 新的命令UI在多人模式可以使用了。

已修复的bug
  • MC-121658 - 在对局域网开放中打开作弊不能对初始玩家生效。
  • MC-121690 - 不设置方块状态会导致只检测默认方块状态的方块，而不是任意的方块状态的方块。
  • MC-121691 - /teleport 的旋转参数不工作。
  • MC-121694 - /summon 命令生成的生物没有武器。
  • MC-121754 - /ban 不能把被ban的玩家踢出。
  • MC-121756 - 尝试添加已有的计分板会导致错误。
  • MC-121791 - gameLoopFunction 的异常会导致崩溃。

/DATAPACK
  • 用于控制数据包的命令
  • 包含如下子命令
  • enable <数据包> - 使<数据包>生效
  • disable <数据包> - 使<数据包>失效
  • list [available|enabled] - 列出所有/生效/失效的数据包
  • 默认数据包都是生效的，但是如果你令其失效的话，你可以通过下述指令令其重新生效：
  • enable <数据包> - 使<数据包>生效，并使用默认的加载顺序
  • enable <数据包> first - 使<数据包>生效，并将其放在其它包前面（优先级最低）
  • enable <数据包> last - 使<数据包>生效，并将其放在其它包后面（优先级最高）
  • enable <数据包> before <指定包> - 使<数据包>生效，并将其放在<指定包>前面（优先级比其低）
  • enable <数据包> after <指定包> - 使<数据包>生效，并将其放在<指定包>后面（优先级比其高）

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要vpn。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验快照版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
