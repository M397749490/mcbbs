启动器下载游戏文件过慢如何解决
作者: Tykkit    时间: 2017-8-16 18:52
你好，Minecraft : Java 版官方启动器的游戏文件提供商为亚马逊。
由于该服务器在国外，进行网络请求时需要走海外路线，速度会大幅降低。
你可以通过使用隧道协议进行下载。
另，您也可以使用支持BMCLAPI的启动器，在本论坛的软件资源板块里有。
由于官方启动器在启动前创建一个叫做launcher_profiles.json文件并依赖其配置并启动Minecraft，故您无法手动导入。
不过，你可以在官方启动器中先下载核心文件，安装ModLoader后手动导入。
官方启动器的Minecraft存储位置根据您的操作系统不同而不同。
  1. Windows: %Appdata%\.minecraft //%Appdata%是环境变量，此路径可以在资源管理器中打开
  2. macOS: ~/Library/Application Support/minecraft //在macOS中，Library文件夹已被系统隐藏，此路径可以在Finder中按下Cmd+Shift+G打开
  3. Linux: ~/.minecraft //在Linux中，.minecraft文件夹被隐藏
