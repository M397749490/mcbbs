InfoBook简介
InfoBook，一个简单的bukkit插件，可以在玩家第一次登录时获得一本书（当然，这书是管理员写的）。
你可以把命令使用方法或者如何获得VIP权限写在书上，总之，这都是你制定的！
玩家只能得到一次书 (你可以给多个或多次)，书的内容可以通过配置文件改变！

注意事项
该插件不会因新版本发布而自动更新，你可以在配置文件中调整是否开启自动更新！

配置文件
# InfoBook全服公告书

# 插件会在服务器启动时检查新版本吗（默认关闭）
version-check: false

# 语言（默认英语）
language: en

# 第一次登陆，每个玩家都会有以下列表的书
onlogin:
  -bookname

# 玩家不能删除以下列表的书（就是书受到保护）
protected:
  -bookname

# 你能决定，哪本书在onlogin列表上不会被保存。玩家已经得到信息，所以玩家每次登录都会得到这些书。
dontsave:
  -bookname

# 你可以从库存中销毁这些书（默认关闭）
destroy-on-drop: false
# 如果为开启，需要添加权限节点（如下）
# infobook.book.<bookname>

# 没有这些许可，玩家不会自动得到书籍（默认关闭，就是自动得到书籍）
per-book-permissions: false

# ★图书配置
books:
default:
   slot: 9
   author: 'Admin'
    #作者
   title: 'Informations'
    #书名
   description:
    #描述
     - 'First line'
     - 'Second line'
   pages:
    #内容
     - '&cInformation book &x &x&0Here you &xcan put&xinformations.'
     - 'Second page of our book.'
