生物群系是什么？（千万不要看黑块中的字哟~）
生物群戏是特定种类生物繁衍生（gao）息（ji）的地方，如：丛（sheng）林（suo），沙（luan）漠（lun），沼（zao）泽（she）之类的

使用方法：

1.新建一个世界
2.在更多世界选项中找到世界类型那个按键上点个3,4下就出来了
3.出现本mod中的世界类型即可


本mod生物群系所含大小介绍：

>岛屿型Island: 0 x Default. 只有海，一望无际的海啊~.
>微型Micro: 0.25 x Default. 超级小的生物群系(几乎每个群系只有 1chunk), 你甚至直接用走的来穿过每个群系. 洞穴也超小的.
果然名不虚传，随便走过条河都跨了3个生物群落，分别是Taiga,river,jungle
>迷你型Mini: 0.50 x Default . 比微型的稍大些 (每个群系有 2-4 chunks). >小型Small: 0.75 x Default . 快跟默认一样了.
>默认Default: 默认
>稍多型More:在小型和稍大型之间 (1.25 x Default)
>稍大型Large: 这就是官方的巨型生物群系 (1.5 x Default)
>大型Big: 1.75 x Default
>超大型Huge: 2 x Default
>巨型Giant: 2.25 xDefault>Massive: 2.5 x Default
>无限型Infinite: 25x Default  (不可能走出去, 除非你出生在群系的交界处上)(楼主亲测时直接crush了)
