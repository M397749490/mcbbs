玩家在指定区域时，免疫任何伤害
支持在 PlaceholderAPI 中设置区域名变量
例如：战争服停火区，PVP保护区等

图片
这插件哪来的图片


配置文件
  1. region:
  2.   - 'world:spawn:&a保护中'
  3.   - 'world_the_end:spawn:&6虚空保护中'
  4.   
  5. Placeholder:
  6.   default: '&4无保护'
复制代码


使用帮助
假如，你想给 PVP 世界的 spawn 区域，设立为安全区
并且变量为 '[安全区]'
  1. region:
  2.   - 'PVP:spawn:&a[安全区]'
  3.   
  4. Placeholder:
  5.   default: '&4无保护'
复制代码
这里的 default 代表不在任何区域时
