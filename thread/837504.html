下面这个命令在聊天栏有效，在RCB或者用tick.json都没什么效果==不是@s的问题用@e也没用execute as @a[tag=poisoning] if block ~ ~ ~ minecraft:water run effect give @s minecraft:poison 1 1 true

原因是没有指定坐标
聊天框输入的话坐标就会为你当前坐标
命令方块里执行的话就会为命令方块的坐标
tick.json的话则为0 0 0

所以as和if之间，补上at @s，使用当前执行者的坐标。
