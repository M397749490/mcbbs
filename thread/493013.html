每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。

然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。
适用于正式版的MOD不兼容预览版，而且大多数MOD都不提供对每周快照的支持。

Minecraft 1.9 仍未发布，15w35a为其第14个预览版。

转载本贴时须要注明原作者以及本帖地址。




By order of the bone, today is officially declared a Wednesday.
因为Dinnerbone的要求，应该在周三的快照提前到今天发布。

（注：每周快照一般在周三发布）

Wednesday.
周三。

Have you ever noticed how weird that word is? Wednesday. Wednesday. It makes no sense!
你是否注意到这个词很诡异？周三。周三。没有意义！

Anyhows, we’re not going to be in the office much this week so we thought we’d bring you a snapshot today to fix some issues brought about by last weeks experimental changes. I also put some clothes on some zombies, as I couldn’t help but blush every time one of them walked past.
我们本周不打算呆在这个办公室里太久，所以我们今天带来了快照来修复些上周快照中的问题。我也在一些僵尸的身上穿上了衣服，因为我不能在经过不穿衣服的它们时不脸红。

Notable changes:
值得注意的更新：

  • Finished the magic trick in which we vanished chunks. They were hiding under the hat this whole time.
  • 解决了区块消失的问题。它们藏在了帽子底下。
  • Fixed some old memory leaks in the client.
  • 修复了一些客户端中的老的内存泄露问题。
  • Put some clothes on the zombies. They may be post mortal, but that’s no reason to be indecent.
  • 给一些僵尸穿上了衣服。因为它们以前可能是普通人，没有理由让它们不雅。
  • Slight rebalancing of tools & weapons.
  • 稍微平衡了工具和武器。
  • Even more experimental performance enhancements. Guaranteed to break at least one heart.
  • 更多实验性的性能提升。保证至少伤透一颗心。
  • Fixed some old memory leaks in the client. Sorry, did I say this already? I forgot.
  • 修复了一些客户端中的老的内存泄露问题。蛤，之前说过了？我忘了。
  • Liked the command blocks? That wasn’t even their final form.
  • 喜欢命令方块？这不是它们的最终形式。


And these are some of the fixed bugs:
BUG修复：

  • [Bug MC-45763] – Some blocks are facing the wrong way if placed in an Item Frame
  • [Bug MC-45763] – 一些方块在物品展示框中方向不正确
  • [Bug MC-86925] – Running out of memory when exiting
  • [Bug MC-86925] – 退出时内存用完
  • [Bug MC-86937] – Empty Chunks duplicate one-another and cause weird behaviour
  • [Bug MC-86937] – 很多的空区块并导致奇怪的行为
  • [Bug MC-87050] – (2 bugs in one) Glitch with adding attributes to items in 1.9
  • [Bug MC-87050] – (2合1BUG）1.9中物品添加属性的问题


Please report any and all bugs you find in Minecraft to bugs.mojang.com. If nobody reports a bug, we can’t fix it!
在bugs.mojang.com报告Minecraft的BUG。没人汇报BUG的话，我们不会修复它！

To get snapshots, open your launcher and press the “New Profile” button. Call it “snapshots” and check the box saying “Enable experimental development snapshots” and save. To switch to the normal version, you can select it in the dropdown at the bottom left corner of the launcher. Back up your world first or run the game on in a different folder (See the “new profile” dialog).
为了获得快照，打开启动器并点击New Profile按钮，打开snapshots并选择Enable experimental development snapshots并点击保存。如果要选择普通的版本，你可以选择在下拉菜单中在启动器左下角的按钮上面。在开始快照前备份你的世界或在不同的文件夹中启动（见new profile对话框）。

Snapshots can corrupt your world, please backup and/or run them in a different folder from your main worlds.
快照可能毁坏存档，记得备份和/或在与你的存档不同文件夹里运行。

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。启动器在上文已经提供。适用于全PC平台。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。如有仍疑惑请到原版问答板块提问。

关注最新版本资讯，请关注mcbbs新闻版 Minecraft官方版本信息索引（自正式版1.0.0至今）与版规

关于本次更新的详细内容，请关注稍后 Minecraft 1.9（战斗更新）特性列表 的更新。
