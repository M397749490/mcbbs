标题: [1.7.2]forge+optifine+显血+TMI基础整合
注意：现在的1.7.2的forge和optifine都处于测试版，不保证稳定性以及兼容性

自己随手弄得整合包，但是由于forge和现有的optifine的兼容问题导致他们安装在一起就会出现显示菜单的时候游戏崩溃的问题。而NEI还没有出1.7.2，而TMI的1.7.2的版本和forge不兼容（兼容的TMI还没有发布）。
游戏内部包含了一个纯净版，一个forge版本(包含了两个mod)，两个optifine版本。TMI默认没有启用，启用TMI只需要在json文件的"libraries"里面添加上他的引用

这是一段实例
  1. {
  2.         "id": "1.7.2-Forge10.12.0.997",
  3.         "time": "2014-01-09T08:50:28-0500",
  4.         "releaseTime": "1960-01-01T00:00:00-0700",
  5.         "type": "release",
  6.         "minecraftArguments": "--username ${auth_player_name} --version ${version_name} --gameDir ${game_directory} --assetsDir ${game_assets} --uuid ${auth_uuid} --accessToken ${auth_access_token} --tweakClass cpw.mods.fml.common.launcher.FMLTweaker",
  7.         "libraries": [
  8.                 {
  9.                         "name": "TMI:TooManyItems1.7.2"
  10.                 },
  11.                 {
  12.                         "name": "net.minecraft:launchwrapper:1.9",
  13.                         "serverreq": true
  14.                 },
  15. 后面省略1500字……
