均在1.16.1测试
先执行一次这条命令
  1. /forceload add -32 -32 32 32
复制代码

然后再在以需要发射弹射物的玩家为执行者执行以下命令（也就是说创个包含下面这些命令的mcfunction再execute as @a执行是最方便的）：
  1. summon minecraft:area_effect_cloud 0.0 0.0 0.0 {Duration:114514,Tags:["motion"]}
  2. execute at @s run teleport @e[tag=motion] 0.0 0.0 0.0 ~ ~
  3. execute as @e[tag=motion] at @s run teleport @s ^ ^ ^1
  4. execute at @s anchored eyes run summon minecraft:arrow ^ ^ ^0.1 {Tags:["test","init"]}
  5. data modify entity @e[tag=init,limit=1] Motion set from entity @e[tag=motion,limit=1] Pos
  6. tag @e[tag=init] remove init
  7. kill @e[tag=motion]
复制代码

想要把速度改大只要改第三条最后向前tp的距离就行了
