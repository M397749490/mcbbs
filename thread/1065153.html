PureNotice


关于:


PureNotice 是一款简单好用的海绵端公告插件，可以用于在聊天框自动发送带功能的公告。


用法:


将jar包放到服务端的mods/plugins/下然后启动服务端即可。


命令:



  • pn 展示插件的版本和作者信息。

  • pn reload 重载插件（配置文件）


权限:



  • pn.command.client.main 用于命令 "pn"

  • pn.command.admin.reload 用于命令 "pn reload".


功能:



  • 点击公告信息执行命令

  • 按住Shift点击公告信息可以插入命令或者消息到聊天框

  • 点击公告信息可以打开一个网页

  • 鼠标移动到公告消息上可以显示额外的悬浮信息

  • 自带语言切换功能，默认包含英语和汉语，也可以自行新增语言配置文件

  • 公告可随机发送

  • 服务器启动后第一条消息支持延时发送

配置文件:


主配置文件:

main {

    # 首条公告在服务器启动后延时多少秒后发送

    firstDelay=20

    # 发送频率，多少秒发送一条

    interval=120

    # en_US 或者 zh_CN

    language="zh_CN"

    # 公告标签

    prefix="&e[&a&lPureNotice&e]&r"

    random=false

    # 不要配置文件更改版本号！！！

    version="1.0"

}

messages {

    "1" {

        message="&f感谢使用 &aPureNotice&f，这是一条没有任何功能的普通消息。"

    }

    "2" {

        click="/help"

        hover="&e点击&f 执行 &a/help"

        message="&f感谢使用 &aPureNotice&f，这条消息用于展示 &e点击&f 本消息执行命令的功能。"

    }

    "3" {

        hover="&e按住Shift + 点击本消息&f 将会插入 &a/list&f 到聊天框。"

        message="&f感谢使用 &aPureNotice&f，这条消息用于展示 &eshift + 点击&f 本消息插入命令或者消息到聊天框的功能。"

        shiftInsert="/list"

    }

    "4" {

        clickUrl="https://www.baidu.com/"

        hover="&e点击&f 打开网址： &e<a href="https://www.baidu.com/" target="_blank">https://www.baidu.com/</a>"

        message="&f感谢使用 &aPureNotice&f，这条消息用于展示 &e点击&f 本消息打开链接的功能。"

    }

    "5" {

        click="/help"

        clickUrl="https://www.baidu.com/"

        hover="当 &e点击执行命令&f 和 &e点击打开网站&f 都配置的时候，只有 &c点击执行命令&f 生效。"

        # 当点击执行命令和点击打开网站都配置的时候，只有点击执行命令生效。

        message="&f感谢使用 &aPureNotice&f，这条消息用于展示&e所有功能都配置上的效果。"

        shiftInsert="/list"

    }

    "10" {

        message="&f感谢使用 &aPureNotice&f，这条消息用于展示配置文件中 &e消息索引&f 不是必须每加一条消息就在原有索引上增加1。"

    }

}

语言配置文件:

main {

    # 不要更改配置版本号！！！

    version="1.0"

}

messages {

    commandMain="§aPureNotice§r 版本："

    commandMainAuthors="§aPureNotice§r 作者：§a§l"

    commandMainDesc=主命令

    commandMainHelp="§epurenotice(pn) reload §f重载PureNotice"

    commandReloadDesc=重载本插件

    configOut="配置文件已过期并已被覆盖，旧的配置文件已保存在配置文件目录"

    disabled="§aPureNotice 已关闭§r"

    firstRun="本次可能是第一次运行本插件，配置文件已初始化"

    languageOverWritten=语言配置文件已过期并已被覆盖

    loaded="§aPureNotice 已加载§r"

    loading="§aPureNotice 正在加载§r"

    noInit="配置文件已存在，无须初始化"

    reloaded="§aPureNotice 已重载§r"

    reloading="§aPureNotice 正在重载§r"

}

主配置文件用于配置发送的信息和功能等，语言配置文件用于配置插件的各种提示信息。


汉化方法


插件首次启动默认是英文，启动完毕后将本帖中的汉语主配置文件覆盖旧的配置文件后重置本插件即可汉化完毕。（不是语言配置文件，汉化语言配置文件在主配置文件中配置language="zh_CN"就可以自动生成，无需手动配置）
