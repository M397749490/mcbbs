所有物品都有对应的模型文件（一个扁片也是模型）。具体改法你可以把原版的那个物品的模型复制出来，然后加上
  1. "display": {
  2.     "gui": {
  3.         "scale": [1.375, 1.375, 1],
  4.         "translation": [-4, -4, 0]
  5.     }
  6. }
