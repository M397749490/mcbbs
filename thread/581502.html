打开Ess配置-config.yml
找到与下面相关的
  1. # 当以下方块被放置或破坏,或物品被使用时会出现警告
  2.   # 你加载了一次Essentials后,就可以在plugins/Essentials/items.csv中找到物品ID列表.
  3.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  4.   alert:
  5.     on-placement: 10,11,46,327
  6.     on-use: 327
  7.     on-break:

  9.   blacklist:

  11.     # 阻止玩家放置以下方块
  12.     placement: 10,11,46,327

  14.     # 阻止玩家使用以下物品
  15.     usage: 327

  17.     # 阻止玩家破坏以下方块
  18.     break:

  20.     # 阻止活塞推动以下方块
  21.     piston:

  23.     # 阻止发射器发射以下物品
  24.     dispenser:
复制代码

把你要禁止和不要禁止的物品ID写上去就可以，你的问题就是把46 和 327 删掉就可以使用了
