没用的废话
Chenghao作为我第一个作品居然得到了那么多人的支持、但是当时水平比较低很多功能都没法实现（现在还是个菜鸡） 我本次回归 花费了大量时间去策划与编写 前几天出来一个称号插件 但是问题太多 限制太多 感觉没有必要就删除了。
本来是想发布付费插件的、但是想了又想。 赚哪些钱我也发不了财、本次回归只是为了给我的朋友们更好的游戏体验，没有完成的承诺虽然已失败但是会继续坚持。
我发现已经有很多相同的属性称号插件了，甚至也同时支持了 AP、SA这些属性插件、但是我想我的还是有必要发出的、第一是那么多人的期望、第二是我也为此忙碌了一个多月、第三我认为我的插件操作会更简单更适合小白腐竹、所有属性、BUFF功能都由lore 实现

使用教程、常见问题
很多人都不明白插件的真正使用方法 请仔细阅读
1、首先需要前置插件FGive
2、编辑称号物品 （将物品名（name）看做称号、介绍（lore）看做属性） 配合lore物品编辑插件
3、编写完成后 使用fgive插件 将物品保存到物品库中 fgive bc id  这里id任意 就是赐予称号时的id 例如：fgive bc 测试称号
4、赐予玩家称号 /ch add 玩家id 称号id 时限  例如：ch add Binggun 测试称号 -1
     测试称号是上一步骤保存的物品id -1是时限 -1代表永久 1代表一天 5代表五天
5、打开称号仓库查看是否赐予成功/ch open
赐予称号：注意：物品需要 命名与添加一行或多行lore介绍
将称号显示在聊天栏中 需要其他聊天插件配合 此插件只提供 PAPI变量 不修改聊天前缀
详细教程
首先准备一个物品 修改名称（物品名将成为称号名） 修改lore介绍 属性将在lore介绍里读取
然后使用fgive插件 保存物品 或者 直接赐予玩家
/Chenghao add 玩家id fgive(id) -1 fgive(id) 是fgive插件保存的物品名 -1为 永久 1 为一天
/Chenghao add 玩家id -1 将手中的物品当做称号赐予玩家
注意事项 赐予BUFF属性时 此行介绍只可出现一组数字 例如 10速度： 10 是不允许的 判断等级时会判断成 1010
删除称号:
/Chenghao delete 玩家id 点击即可删除玩家的称号
打开称号仓库:
/Chenghao open
称号如何显示： 目前版本不正常正常聊天显示 需要配合聊天插件 与变量
变量为：%Chenghao_use% 使用中的称号名
/Chenghao set id 时限
/Chenghao set id 物品id 时限
用于设置玩家称号时限
主指令缩写：ch

常见问题：
问：旧插件的数据兼容新插件数据嘛？ 已支持转换
答：不兼容 但是正在写转换功能请关注插件的更新
问：变量报错如何解决？
答：是否将旧插件变量扩展文件删除 此插件不在需要扩展文件实现变量 因此使用变量扩展会与插件冲突
问：1.7.10版本一直报错是什么导致的？
答：1.7.10不正常头顶显示称号 因此Team:  设置为 false 即可
问：为什么赐予称号无效
答：赐予称号的物品 必须修改名字 并且添加一行lore介绍
Chenghao插件数据转换教程：
先将旧数据 备份（以免错误丢失） 另存到桌面（哪里都行）
删除Chenghao 安装ChenghaoPro 删除插件内的Chenghao文件夹 让ChenghaoPro生成新的数据文件
服务器启动成功后 将 旧数据 Player 文件夹改名 Player1  将 config.yml 文件改名 config1.yml
改名后移动到 新生成 plugins/Chenghao文件夹内
服务器内输入指令/ch used 提示转换成功 查看后台是否有报错
关于模板问题 模板就没办法恢复数据了 你可以重新编辑物品并保存在 fgive 插件内了 也相当于保存了模板
