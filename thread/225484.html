简介：
[bow]这个插件是能够创造多个世界的一个插件。指令非常的简单，而且方便操作。[arrow]


特点：

[lava_buket]1.支持世界的删除
[lava_buket]2.支持多达10个世界
[lava_buket]3.命令很简洁，你只要记住 /multiworld  、 /MW 、 /GOTO
[lava_buket]4.支持，使用命令 /MW移动
[lava_buket]5.你现在让某个世界和另外一个世界相接在一起[好Ji友啊~]（这个比较难弄）


[chest]命令：

/mw help - 查看帮助列表传送去别的世界[帮助之源~]
/mw spawn [世界名] - 回到这一个世界的出生点
/mw create [世界名] [世界类型] [世界种子] - 创造一个新世界
世界类型包括：normal【一般】|nether【地狱】|planets【行星】|flatland【平原】|pixelartroom【pixel平面图世界】|the_end【末界】|solarsystem【太阳系】|plugin【插件】|ocean【海洋】|desert【沙漠】|epiccaves【洞穴】|
/mw delete [世界名] - 删除一个世界
/mw save - 保存插件信息
/mw reload - 重载插件
/mw list - 查看已有世界列表
/mw listgens - 查看可选择的世界类型
/mw move [玩家名] [世界名] - 将某玩家传送到某的世界
/mw spawn [某世界] - 回到出生点
/mw setspawn - 设置本世界出生点
/mw debug - 进入调试模式
/mw info [世界名] - 查看该世界的信息
/mw unload [世界名] - 重新加载一个世界
/mw link [目标地狱] [世界名] - 连接[目标世界]地狱和[世界名]
/mw link-end [目标末界] [世界] - 连接[目标世界]末界和[世界]
/mw flags - 显示全部标志列表
/mw setflag [世界名] [标志名] [值] - 改变标志值
/mw getflag [世界名] [标志名] - 查看标志值。输入"*"可以查看该世界全部标志状态

[diamond_gem]小备注：被粉色加粗下划线的文字是比较重要的命令！绿色的是世界类型~可以在[世界类型]中替换！棕色加粗字体是高级管理命令。普通字体则命令为一般命令~不做特殊解释

[redstone_torch] 小备注[很重要~不重要谁会提·。·]：因为登陆世界信息是保存在游戏的配置文件里的，所以插件如果卸载但是退出前又是在另一个世界的话，那这位玩家是无法进入游戏的。卸载插件前务必转移所有其他世界人员。

[redstone_torch]2.注意插件要放在plugins中！
