标题: [管理] InventoryShop —— 面板商店 | 居然有这么棒的商店系统 [1.8+]


妈耶...居然有这么好用的商店插件...这是一个简单的面板商店系统，支持一键购买和**商品，最最重要的是，作者默认提供了一些配置，基本囊括了所有的物品，而且设计好了价格！可以为服主省下不少的麻烦...







注意！开启命令中，玩家项是非必要参数，输入 /shop open <商店名字> 即可开启商店！

插件命令:
  • /shop open <商店名字> [玩家名字] - 开启商店
  • /shop list - 列出所有商店
  • /shop reload - 重载插件

插件权限:
  • shop.command.usage - 查看命令使用方法
  • shop.command.open - 开启商店
  • shop.command.open.others - 为指定玩家开启商店
  • shop.command.list - 使用 /shop list 命令
  • shop.command.reload - 使用 /shop reload 命令

文件详解 ( config.yml ):

  1. # 点击一次更改交易数量图标商品数量发生的变化
  2. # 示例: '1', '1,2,4', '1-4'
  3. amountRegex: '1,2,4,8,16'

  5. # 是否允许玩家将彩色名字的商品**到商店
  6. ignoreColoredDisplay: true

  8. # 每个商品的 lore
  9. iconsLore:
  10. - '&cLeft Click &6- buy, &cRight Click&6 - sell'
  11. - '&eBuy price: &a{buy_price}'
  12. - '&eSell price: &c{sell_price}'

  14. # 改变交易数量图标配置
  15. extraIcon:
  16.   enable: true
  17.   slot: 53
  18.   id: iron_ingot
  19.   name: '&eChange amount'
  20.   lore: []
