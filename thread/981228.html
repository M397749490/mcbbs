看到有些dalao在其他帖子里问两个或多个Bungee如何整合, 这里结合我自己的经验来介绍一下.

为什么要用多Bungee互联

我有经营一个公益服, 服务器有三个群体想要在一起玩:
- 一个是位于欧洲的玩家群体, 人很少但是有;
- 一个是位于大陆的玩家群体, 这是人最多的;
- 还有一个是位于澳洲的玩家群体, 人很少, 几乎没人在线;
这时候问题来了, 蹦一次极就能解决的问题, 为什么要蹦三次呢?
原因是这样的, 我希望能够让这几个区域的玩家都能够在在线列表中出现, 因为这样能够显得服务器更热闹, 而且还想要不同区域的玩家的聊天信息能够互通. 单个BungeeCord是无法实现的.
好, 那接下来就讲一下如何实现.
实现方法

首先搭建3个BungeeCord网络, 具体搭建方法请参考论坛内其他教程, 这里不再详述. 我们给这三个BungeeCord网络分别根据地理位置命名: CN, NL, SG.
然后
安装RedisBungee插件到BungeeCord

下载RedisBungee插件: https://github.com/minecrafter/RedisBungee
这里有个坑, 官方版的RedisBungee可能导致一些奇怪的问题, 需要自行修复. 因为RedisBungee是付费插件, 所以请自行购买后私聊我提供购买证明,我可以发给你LinTx的修复版本.
下载完成后将RedisBungee-0.5.1.jar放置到每个BungeeCord的plugins文件夹里, 然后运行每个BungeeCord来生成初始化配置文件. 然后就可以先不用管了.

Redis服务器位置的选择和安装Redis服务器

既然用到了RedisBungee那么一定就需要Redis了:
Redis是一個使用ANSI C編寫的開源、支援網路、基於記憶體、可選永續性的鍵值對儲存資料庫。從2015年6月開始，Redis的開發由Redis Labs贊助，而2013年5月至2015年6月期間，其開發由Pivotal贊助。在2013年5月之前，其開發由VMware贊助。

Redis和MySQL类似, 但更简单也更轻便. 由于Redis服务器需要从各个区域进行连接, 因此在我的部署过程中我选择使用香港的服务器搭建. 建议在实际部署过程中按照自己的需求, 部署在几个BungeeCord网络的中点位置以最大化优化延迟.关于安装, 这里只提供CentOS下的安装方法, 其他操作系统下的安装方法大同小异:1. 首先SSH登入服务器, 切换到root权限;

设定RedisBungee

回到RedisBungee, 每个BungeeCord的plugins目录下RedisBungee的配置文件config.yml都需要按照以下内容进行修改:
  1. # RedisBungee configuration file.
  2. # PLEASE READ THE WIKI: https://github.com/minecrafter/RedisBungee/wiki

  4. # The Redis server you use.
  5. # Get Redis from http://redis.io/
  6. redis-server: 这里填你的Redis服务器IP地址或域名, 建议写IP地址
  7. redis-port: 这里填你的Redis服务器的端口
  8. # OPTIONAL: If your Redis server uses AUTH, set the password required.
  9. redis-password: "这里填你的Redis密码,注意要带两边的引号"
  10. # Maximum connections that will be maintained to the Redis server.
  11. # The default is 8. This setting should be left as-is unless you have some wildly
  12. # inefficient plugins or a lot of players.
  13. max-redis-connections: 8

  15. # An identifier for this BungeeCord instance.
  16. server-id: 这里填这台BungeeCord的代号,例如cn. 每台BungeeCord的代号不能相同.

  18. # Whether or not RedisBungee should install its version of regular BungeeCord commands.
  19. # Often, the RedisBungee commands are desired, but in some cases someone may wish to
  20. # override the commands using another plugin.
  21. #
  22. # If you are just denying access to the commands, RedisBungee uses the default BungeeCord
  23. # permissions - just deny them and access will be denied.
  24. #
  25. # Please note that with build 787+, most commands overridden by RedisBungee were moved to
  26. # modules, and these must be disabled or overridden yourself.
  27. register-bungee-commands: true

  29. # A list of IP addresses for which RedisBungee will not modify the response for, useful for automatic
  30. # restart scripts.
  31. exempt-ip-addresses: []

跨BungeeCord聊天

要实现跨BungeeCord聊天难度很高, 目前我找到的支持RedisBungee的类似插件只有YinwuChat和另一款付费插件, 这里只介绍免费的YinwuChat:

https://www.mcbbs.net/thread-836393-1-1.html

安装和部署请参考上面的链接. 安装好之后在每个BungeeCord上安装后按照说明开启Redis支持并完成每个BungeeCord的设定:

  1. redisConfig:
  2.   openRedis: true
  3.   ip: '这里填写Redis服务器的IP地址(注意带引号)'
  4.   port: 这里填写Redis服务器的端口
  5.   maxConnection: 8
  6.   password: '这里填写Redis服务器的密码(注意带引号)'
  7.   selfName: 这里填写BungeeCord代号
  8.   forwardBcTask: true
  9.   forwardBcMessageToQQ: true
  10.   forwardBcMessageToWeb: true
  11.   forwardBcAtAll: true
  12.   forwardBcAtOne: true
  13.   selfPrefixFormat:
  14.   - message: '&8[其他群组]&r'
  15.     hover: 来自其他群组的消息
  16.     click: ''
