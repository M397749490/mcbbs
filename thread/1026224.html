该参数:The JVM 启动参数 – MC 1.15 更新

准确使用这些设置, 只更改 Xmx 和 Xms. 这些设置可以根据任何大小的内存（甚至只有500MB）下运行且自行调整

java -Xms10G -Xmx10G -XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200 -XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC -XX:-OmitStackTraceInFastThrow -XX:+AlwaysPreTouch  -XX:G1NewSizePercent=30 -XX:G1MaxNewSizePercent=40 -XX:G1HeapRegionSize=8M -XX:G1ReservePercent=20 -XX:G1HeapWastePercent=5 -XX:G1MixedGCCountTarget=8 -XX:InitiatingHeapOccupancyPercent=15 -XX:G1MixedGCLiveThresholdPercent=90 -XX:G1RSetUpdatingPauseTimePercent=5 -XX:SurvivorRatio=32 -XX:MaxTenuringThreshold=1 -Dusing.aikars.flags=true -Daikars.new.flags=true -jar 核心文件名.jar nogui


上次更新: Apr 06 2020 3:30PM EST
注意: 这些设置还在测试阶段。如果遇到旧一代的GC问题，请到Paper的Discord界面反馈
我最后一次设置1.15中效果尤其明显。这些设置在Java 8和Java 11(JDK11)上都有效!!!
这些设置仍然推荐老版本MC1.8-1.15+使用
