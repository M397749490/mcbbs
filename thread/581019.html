这个插件是用来限制玩家行动的, 它放在登录服或者主城服里效果最好
它的功能是:
  -  限制玩家丢弃物品
  -  限制玩家在物品栏内点击物品
  -  限制玩家拾取物品
  -  限制玩家发送消息

它的配置是:
Drop: true
  #禁用丢弃物品
Inventory: true
  #禁用点击物品栏
Chat: true
  #禁用发送消息
Pickup: true
  #禁用拾起物品

它的权限是:
  允许丢弃物品:      ke.zc.ddr
  允许点击物品栏:  ke.zc.dio
  允许发送消息:      ke.zc.dc
  允许拾起物品:      ke.zc.dp

它没有指令
