如果不是你的期望的话可以试试这条
  1. /execute as @a  at @s if block ~0.2 ~-1 ~ minecraft:stone if block ~-0.2 ~-1 ~ minecraft:stone if block ~ ~-1 ~0.2 minecraft:stone if block ~ ~-1 ~-0.2 minecraft:stone run kill @s

多个if block嵌套
如果还嫌范围大的话就调整那些大小为0.2的值(比如改为execute as @a  at @s if block ~0.3 ~-1 ~ minecraft:stone if block ~-0.3 ~-1 ~ minecraft:stone if block ~ ~-1 ~0.3 minecraft:stone if block ~ ~-1 ~-0.3 minecraft:stone run kill @s就会使范围缩小)
