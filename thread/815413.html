前言

我以前也是一位只会spigot和KC之类的服主，但当我一次看到高版本如此丰富的新内容时

我决定，我要去做出一个高版本的模组服务器。sponge核心，也在BBS发现了。

相比以往的核心，sponge是非常特殊的。他有着多线程的优化，也有着KC无可媲美的模组兼容性。

但sponge的优化，总被人诟病。因此。我打算写这个教程，希望对sponge的服主们有所帮助
（本帖参考sponge的wiki编辑，如有雷同，纯属巧合）

注：不保证所有的sponge服使用后都能有效果。仅供参考。


Forge与forgeChunkLoading文件


这两个文件均在config文件夹中。

Forge

  1. #开启后会自动移除一些可能导致错误的实体，有极小风险
  2.     B:removeErroringEntities=true
  3.         
  4.     #同上，这个则是移除可能导致错误的方块
  5.     B:removeErroringTileEntities=true

这两个选项是可以很大程度上避免你因为某种模组的问题而崩服的。当然只是很大程度，不是百分百。

  1. # 多线程加载地形
  2.     B:alwaysSetupTerrainOffThread=true

这个选项可以充分发挥你服务器其他核心的力量。可以选择性的开启（假如你的核心不多主频很高，可以不开）

  5.         auto-save-interval=1500

  2.         item-merge-radius=2.5
  3.         # 是否保持单个世界出生点附近256个区块加载，建议为false，减少损耗
  4.         keep-spawn-loaded=false
  5.                 # 树叶自然腐烂是否开启,false可稍微的提升tps

  8.         load-on-startup=true

  10.                 max-chunk-unloads-per-tick=1000

server.properties文件

主要修改为视距与生成实体选项。
  1. # 出生点的保护半径 设置为0 则为出生点脚下的方块
  2. spawn-protection=16
  3. # 一个tick的最长等待时间，如果超过此数值，将会结束服务器
  4. # 设置为-1禁用此选项
  5. max-tick-time=60000
  6. generator-settings=
  7. # 强制玩家以默认游戏模式进入服务器
  8. # 关闭则以最后一次下线的游戏模式进入
  9. force-gamemode=false
  10. #是否开启下界（地狱）
  11. allow-nether=true
  12. # 默认的游戏模式
  13. # 这里修改后，请用nucleus插件再次进行修改，否则可能无效，会以nucleus设置的为主。
  14. gamemode=0
  15. # 允许服务器开启针对 GameSpy4 协议的监听。用于收集服务器信息。
  16. enable-query=false
  17. player-idle-timeout=0
  18. # 难度
  19. # 0-和平 1-简单 2-普通 3-困难
  20. #请根据你服务器需要的难度进行修改
  21. difficulty=1
  22. # 怪物是否生成
  23. # 若设置为false所有怪物将不会生成。
  24. # 若为true夜晚正常刷怪
  25. # 一些模组刷怪笼会无视此选项（这个会影响你的服务器性能）
  26. <font color="#008080">spawn-monsters=true</font>
  27. op-permission-level=4
  28. # 是否开启PVP
  29. pvp=true
  30. snooper-enabled=true
  31. # 生成地图的类型 若无特殊要求 默认default即可
  32. level-type=default
  33. hardcore=false
  34. enable-command-block=false
  35. # 最大玩家数量设置
  36. max-players=20
  37. # 越小对CPU负荷越高。越大对带宽要求更高
  38. # 强烈不建议小于64
  39. <font color="#ff0000">network-compression-threshold=250</font>
  40. resource-pack-sha1=
  41. # 游戏边境方块最大数量 默认即可
  42. max-world-size=29999984
  43. # 设置服务器要监听的端口
  44. # 默认为25565
  45. server-port=25565
  46. # 如果你想把你的服务器绑定到特定的 IP 上去请设置这一项。强烈建议将这一项留空。
  47. server-ip=127.0.0.1
  48. # 是否生成村民
  49. spawn-npcs=true
  50. # 是否允许飞行
  51. allow-flight=false
  52. # 默认世界的名字
  53. level-name=world
  54. # 服务器的视距，请不要设置太高，否则对性能有严重的消耗！
  55. <font color="#ff0000">view-distance=4</font>
  56. resource-pack=
  57. # 是否生成动物
  58. <font color="#008080">spawn-animals=true</font>
  59. # 是否开启白名单模式
  60. white-list=true
  61. # 是否在新区块生成特殊的结构（例如村庄）
  62. # 此选项即便关闭，地牢仍然生成
  63. <font color="#008080">generate-structures=true</font>
  64. # 是否开启正版验证
  65. # 盗版服务器请关闭，否则无法进入服务器
  66. online-mode=false
  67. # 允许建造的最高高度，地形也会受到限制
  68. max-build-height=256
  69. # 地图种子，默认为空即可
  70. level-seed=
  71. prevent-proxy-connections=false
  72. #服务器的motd，不过一般使用ServerListPlus插件进行设置。

插件、模组的优化

插件
推荐使用catclearlag。
但注意以下问题

一、请设置一个区块内的怪物最好不要太少。否则会出现
无法扔东西（一定几率会被卡没）
不掉落原版掉落物

二、unloadchunk指令可能会导致无法扔东西的bug，而且这个东西最好不用。
三、最好不要用地皮插件，目前sponge的地皮插件不稳定性太高，容易造成难以挽回的损失。
四、nucleus插件很强大请仔细研究其用处。
五、最好不要让服务器实体过多，否则会造成你动都动不了的卡顿...

模组
推荐使用：formfix（内存）、AI Improvements（AI优化，就是让怪物智商下降）、Betterfps
AI Improvements模组可能会导致游戏难度降低，请自行考虑是否添加

Timings

如果卡顿，多看timings分析问题。
开启方法为
在后台或者游戏内输入sponge timings on
然后稍等几分钟。
再输入sponge timings report
打开网址自行分析（大多是 实体或者区块刷新、卸载，地图保存或者是其他问题）
