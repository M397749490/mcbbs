不是，这个功能不是res插件自带吗？
这个就是你要的wiki教程
打开res的插件文件夹，找到 flags.yml ，打开
然后你会看见找个东西
  1. Global:
  2.   Flags:
  3.     Global:
  4.       use: true
  5.       build: true
  6.       ignite: true
  7.       firespread: true
  8.       damage: true
  9.       creeper: true
  10.       tnt: true
  11.       pvp: true
复制代码
然后只需要按照格式，加入一个世界就行，比如一个叫sc的世界
  1. Global:
  2.   Flags:
  3.     Global:
  4.       use: true
  5.       build: true
  6.       ignite: true
  7.       firespread: true
  8.       damage: true
  9.       creeper: true
  10.       tnt: true
  11.       pvp: true
  12.     sc:
  13.       use: true
  14.       build: false
  15.       ignite: true
  16.       firespread: true
  17.       damage: true
  18.       creeper: true
  19.       tnt: true
  20.       pvp: true
复制代码
这样在sc世界就需要圈地才能建筑了
