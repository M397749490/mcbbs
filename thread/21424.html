指令
/ dt setdest<name> - 在设定龙骑士可以前往目的地。
&#8226;/ dt setstat<name> - 在设置玩家可以装载龙如果“UseStations：”在配置设置为“Ture”的一站。

END的目的地。

/ dt  mount- 召唤坐骑龙。
/ dt listdest - 显示所有可用的目的地列表。
/ dt liststat - 显示所有可用的坐骑龙列表。
/ dt travel <name> - 在给定的目标让player的龙。
&#8226;/ dt ctravel<X><Y><Z> - 让player的龙给坐标。
&#8226;/ dt ptravel<name>的 - 让我们的player给player龙。

/ dt sethome  - 设置player homepoint。
/ dt home - 安装自动带来的player去他家点到龙player。
&#8226;/ dt remdragons的 - 移除所有的龙，在player的当今世界，没有对他们的骑手。
