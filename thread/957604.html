Module Launcher 是什么  
Module Launcher简称ML是由Ploer_Shile与回忆开发的制作的支持全版本、全拓展启动，支持多渠道服务器验证的易语言启动模块




说明
本类帖子与软件编写原因主要是为Module Launcher开发做个示范，同时探索模块内是否拥有BUG，以便及时定位与修改。




本源码实现了皮肤站的完全外置管理，如：
  • 外置登录注册找回密码
  • 外置皮肤广场，可收藏至衣柜
  • 外置管理用户列表，可添加，删除，角色，可改名，可删除材质
  • 外置管理衣柜，可添加删除，改名，可为角色安装材质
  • 外置上传材质


注意：
Module Launcher不处理开了谷歌验证的皮肤站，如果对假人注册存在顾虑，可在皮肤站内开启谷歌验证
