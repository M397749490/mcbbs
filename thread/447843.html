这是一个pvp游戏:你可以用你的弓箭一射杀死一个人。
第一杀死20人的赢得一轮,也可以在配置中改变。
如果您设置了多个出生点系统将在一个随机的一个点出生。
尽管这可能是一个老minigame,但它仍然是一个伟大的街机游戏。
——这是一个非常好玩的游戏！值得一试！

/ oitc savearena <竞技场>保存竞技场mgoneinthechamber.setupmgoneinthechamber.setup
/ oitc setmaxplayers <竞技场> <统计>设置最大玩家人数mgoneinthechamber.setupmgoneinthechamber.setup
/ oitc setminplayers <竞技场> <统计>设置最小玩人数mgoneinthechamber.setupmgoneinthechamber.setup
/ oitc setarenavip <竞技场> <真/假> 设置是否需要批准在加入竞技场mgoneinthechamber.setupmgoneinthechamber.setup
/ oitc removearena <竞技场> 删除一个竞技场mgoneinthechamber.setupmgoneinthechamber.setup
/ oitc removespawn <竞技场> <统计>删除一个竞技场的游戏出生点mgoneinthechamber.setupmgoneinthechamber.setup
/ oitc加入<竞技场>加入竞技场
/ oitc leave离开竞技场

/ oitc stop<竞技场>强行关闭竞技场mgoneinthechamber.stopmgoneinthechamber.stop
