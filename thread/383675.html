郑重声明：此Mod与 @huanghongxun  的MyUI无任何关系！

先发一个效果图




本Mod可编辑：
  获取服务器状态&进入服务器
  顶部公告（可网页获取并可以滚动）
  自动检测客户端版本
  客户端标题
注：进入服务器按钮一点即可进入

更改上面内容需更改本Mod的配置文件（.minecraft/config/New Gui.cfg）
请用Notepad++打开！
配置教程
  1. # Configuration file

  3. online {
  4.     S:Downloads=http://
  5. #客户端下载地址url
  6.     S:Url=http://www.seawform.com/example/
  7. #检测客户端版本的地址url，格式为http://XXXXXXXXX/，别漏了最后的 / 号
  8. #检测客户端版本的网页格式请见下一个折叠内容↓
  9.     D:Version=1.0
  10. #本地客户端版本
  11.     B:VersionCheck=false
  12. #是否开启版本检测，true表示是，false表示否
  13. #如果设置否，则无视这一块内容
  14.     B:zAnnouncementCheck=false
  15. #是否从网页获取公告，需 VersionCheck 设置为true和本项设置为true才可获取公告
  16. }


  19. server {
  20.     B:1sTwoAddress=false
  21. #如果是双线服务器请将这里设置为true
  22.     S:Address1=127.0.0.1
  23. #服务器IP地址
  24.     S:Address2=127.0.0.1
  25. #若 1sTwoAddress 设置为false则无视它
  26. #若 1sTwoAddress 设置为true，则这是服务器的另一个IP地址
  27.     S:Announcement=
  28. #客户端顶部公告
  29.     B:AnnouncementMove=true
  30. #是否开启公告的滚动模式
  31.     S:Captain=Minecraft 1.8
  32. #客户端标题
  33. }


复制代码


如果你要检测客户端版本是否最新/获取顶部公告，这是关于获取版本的网页格式（重要！否则客户端崩溃！）
检测版本：
  1. {"Version":"你要设置的版本号"}
  2. #设置的版本号必须是个数字！如1.0, 2.0
复制代码
接着把你的网页文件改名为update.html
例子:http://www.seawform.com/example/update.html

获取公告（编码为UTF-8无BOM格式！）：
  1. {"Announcement":"此处填写公告"}
复制代码
接着把你的网页文件改名为announcement.html
例子：http://www.seawform.com/example/announcement.html
