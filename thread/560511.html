插件介绍：

首先，这是一个有菜单的颜色插件
这个插件允许玩家在颜色管理中设置他们自己的聊天颜色和昵称颜色。
不仅仅可以设置颜色，还可以设置字体。
并且设置后，如果不再次使用颜色代码的情况下，在游戏中的聊天都将显示已设置的颜色与字体
颜色管理的配置文件并不复杂。并且每一种颜色对应每一条权限。
也就是说，默认的情况下，需要有对应的聊天颜色的权限节点，方可以在颜色管理中使用。

指令：

  • 打开颜色管理界面（主指令）：/color 或 /col 或 /c
  • 重新加载插件： /color reload 或 /col reload 或 /c reload
  • 重置某玩家的昵称的颜色字体：  /color reset chat [玩家id]
  • 重置某玩家的聊天的颜色字体：  /color reset nick [玩家id]
  • 插件版本信息： /color about|version|ver

权限节点：

玩家建议权限：
  • color.use - 使用权限
  • color.reset.nick 重置自己的昵称的颜色字体的权限
  • color.reset.chat 重置自己的聊天的颜色字体的权限

管理员建议权限：
  • color.reload 插件重载权限
  • color.reset.others 重置其他人的聊天或昵称的颜色字体的权限
