MCSignONDoor是什么？

MCSignOnDoor是一款JAVA软件，用于MineCraft服务器维护时或者更换IP时能够及时通知玩家的东西
当你的服务器维护或者更换地址时，玩家可以通过motd和入服提示来看到你想对他们说的话♂


使用方法

低级版本：
重新创建一个.bat脚本（因为这不是插件，你放到插件文件夹是没用的！），输入
  1. java -jar MCSignOnDoor.jar --message "Gone Fishin' Back in Five Minutes!"
复制代码



那么进服的玩家就会看见是这样的！

高级版本用法
  1. java -jar MCSignOnDoor.jar -m "服务器维护到x:xx,请稍后进入" -p 25565 --motd "XXXX's Server" --players 1000/1000
复制代码
分析：
“服务器维护到x:xx,请稍后进入”   就是你想对进入服务器玩家说的话
“p 25565" 就是你服务器的端口
"xxxx's server" 就是服务器临时的motd
"1000/1000”就是服务器虚拟的玩家人数



如果我改成
  1. java -jar MCSignOnDoor.jar -m "服务器维护中，若空虚请去打苹果一顿" -p 25565 --motd "服务器维护中，若空虚请去打苹果一顿" --players 1000/1000
复制代码

常见问题
为什么我把这个插件加到插件文件夹中却无法运行?
因为这个并不是craftBukkit服务器插件,这是一个独立的Java应用,你必须创建新脚本运行。
