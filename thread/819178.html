已经自行解决     那么话题来了  到底采纳谁

自定义物品config.yml最下面有两个世界加成
npcModifier:
  worldNEW:
    healthMultiplier: 0
    damageMultiplier: 0
    expMultiplier: 0
    location:
      x: 0
      y: 0
      z: 0
  worldNEW_NETHER:
    healthMultiplier: 0
    damageMultiplier: 0
    expMultiplier: 0
    location:
      x: 0
      y: 0
      z: 0
调成0即可
