作者: huwei5201314789    时间: 2016-8-30 09:05

使用ESS插件设置即可，
  1.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  2.   # 你加载了一次Essentials后,就可以在plugins/EssentialsX/items.csv中找到物品ID列表.
  3.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  4.   alert:
  5.     on-placement: 10,11,46
  6.     on-use:
  7.     on-break:

  9.   blacklist:

  11.     # 阻止玩家放置以下方块
  12.     placement: 10,11,46,4833,368,4844    ###如果想禁止放床，这里也可以加上355床的ID

  14.     # 阻止玩家使用以下物品
  15.     usage: 4833,368,4844,355  ###这里加上床的ID即可，也就是355，

  17.     # 阻止玩家破坏以下方块
  18.     break:

  20.     # 阻止活塞推动以下方块
  21.     piston:

  23.     # 阻止发射器发射以下物品
  24.     dispenser:
复制代码
以前ess插件不支持MOD物品，现在开始支持MOD物品了，只需输入正确的物品ID即可,至于原版物品的ID，百度自寻吧，我虽然很想发，但是
