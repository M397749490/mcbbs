[iron_ingot]教程[iron_ingot]


先创建记分板

/scoreboard objectives add naw dummy

/scoreboard players set @p naw 0

give指令：

  1. /give @p[score_naw=0] stone_sword 1 0 {display:{Name:"新手石剑",Lore:["攻击僵尸的武器"]}}
复制代码
  1. /give @p[score_naw=0] stone_axe 1 0 {display:{Name:"新手石斧",Lore:["一般般的石斧"]}}
复制代码
  1. /give @p[score_naw=0] stone_pickaxe 1 0 {display:{Name:"新手石镐",Lore:["一般般的石镐]}}
复制代码
  1. <blockquote>/give @p[score_naw=0] stone_shoevl 1 0 {display:{Name:"新手石铲",Lore:["一般般的石铲"]}}
复制代码
讲解：

给记分板naw最大为0的玩家物品

最后~~~
  1. /scoreboard players set @p naw 1
复制代码
  1. /tellraw @p[score_naw_min=1] {text:"只能领取一次新手奖励",color=red}
复制代码
讲解：

把玩家的naw调成1

如果玩家naw记分板为1或以上就说这句话
