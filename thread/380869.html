1.7.2-1.12.2
此服务端为官方服务端，其优点为 简单，方便，稳定，启动速度快，兼容的MOD比现在所谓的MOD服更多！（所谓的MOD服是大家俗称的MCPC+，CD端，KC端）

1.7.2官服：
下面我说明一下那三个MOD的使用方法：

登录系统：
新的玩家将会被要求注册一个密码
使用/register <密码> <重复一次密码> 来注册
注册之后，该玩家的账号将被系统保护。任何尝试使用该账号登陆的人将被要求登陆。
使用/login <密码> 来登录
如果不登陆，玩家将会被锁在出生点，无法使用命令，移动或者打开背包
补充说明一点！！！！当没有登录或注册的话是看见一片漆黑的！！！      还有，当同一台电脑在没有重启情况下登陆过一次后面是不用登录的！！
命令：
login <密码> - 当你的IP更换之后登陆服务器
register <密码> <重复一次密码> - 第一次登录服务器时注册账号
原帖地址：
http://www.minecraftforum.net/fo ... teleport-protection

基础指令：
/sethome <数字1-8>
设置你的家，支持无参数和参数1-8，一共可以设置⑨个家

/home <数字1-8>
回到你的家，与/sethome对应

/goto [玩家名]||[坐标X] [坐标Y] [坐标Z]

/goto [玩家名]传送到指定玩家身边
/goto x y z传送到坐标X,Y,Z处

/spawn
返回出生点

/b2d
返回死亡地点

/back
返回传送之前的位置

游戏内可以用原版的/help指令查看命令如何使用

搬运贴地址：
http://www.mcbbs.net/thread-319603-1-1.html

方块保护：
MOD里面就一个方块叫SimpleLock
把这个方块 放到 你的地盘地下（相当于地基），这个方块就会锁住他上面的区域，放置者会成为拥有者，可以操作该方块锁住的区域，也可以干掉干掉该方块。
想多人共有区域的话，在方块上插个牌子，上面打上共有给哪个玩家的名字，最多共有4个（牌子也只能打4行），共有的玩家就可以操作该方块锁住的区域，但是不能操作这个Block，因为不是拥有者!!!
（MOD作者说为什么只锁上面呢，是因为当玩家操作的时候，就一个方块要计算，如果一个方块锁一片的话，那么当操作的时候，整片区域都得加载一遍，那计算量就成倍翻，对服务器来说会很卡）

字体颜色+昵称：
命令:
  • /nick <nick> - 为自己设定一个昵称。留空昵称为重置
  • /color <color> - 为自己设定一个颜色。留空显示颜色列表，或进入“随机”得到一个随机的颜色
  • /realname <nick> - 看谁是背后的昵称
  • /coords - 喊出你的坐标
  • /group - OP使用的命令，可以用的子命令


    • create <Name>- 创建一组 名称
    • remove <Name> - 删除组 名
    • addUser <Group> <Name>- 将用户名称添加到组
    • delUser <Group> <Name> - 从组中移除用户名称
    • color <Group> <color> -为该组设置颜色
    • save - 将组保存到世界根文件中
    • load - 从一个文件中加载该组的位置根


  • /colorchat - OP使用的命令，可以用的子命令


    • version - 显示版本 colorchat
    • save users - 将用户保存到世界根目录文件中
    • load users - 从一个文件中加载用户根目录
    • save groups - 将组保存到世界根目录文件中
    • load groups - 从一个文件中加载组的根目录

无法开服各种问题FAQ：

未经同意禁止在其他地方套用下方字迹！

  • 为什么服务器出生点附近的方块只有OP能破坏，而玩家破坏不了？
  • 因为服务端默认设置为16x16的出生地保护。
  • [diamond_pickaxe]关闭方法是打开服务端的server.properties文件，将下面的spawn-protection=16  改为0即可，记得保存
  • 为什么我用我的内网能进而外网进不了？？
  • 那是因为你的DMZ没设置好，再检查一下！
  • 请问端口号是干嘛的？
  • 如果是用DMZ的方法那个就没有用的，默认为25565
  • 为什么我服务器开成功了，后台也可以输入指令使用，也能正常关闭。可是连内网都无法连接？？
  • 很有可能是因为你电脑系统开了防火墙没关，只要关闭就好了，关了不影响电脑正常使用。
  • 为什么我进游戏后黑漆漆的一片？
  • 因为你没有注册，注册方法上面有写
  • 很多指令我不知道咋办？
  • 游戏中输入/help 即可
  • 为啥我下载了解压后启动器没了？？
  • 那是因为你杀毒软件吃了= =把他加入到白名单即可
  • 为什么有些盆友能连有些连不了？
  • 有可能是两个不同的网络需要跨服的线路不通导致延迟过大搜不到信号！
  • 怎么弄OP？？？
  • 在控制台那输入  op 你的名字  即可！
  • 为什么MOD加了就崩溃？
  • 这是MOD的问题了，有可能是你把客户端类MOD加了进去。也有可能是那个MOD有前置MOD。或者那个MOD不支持多人等多种原因。
  • 在成功开服后进入服务器的时候为啥卡住而且后台有报错？？
  • 一般是MOD问题，你可以一个个删MOD排查，或者整个mods文件夹删除再试试（服务端）
  • 我开服时，控制台到下面这行就不动了，怎么解决啊？？？
