-内容误新人
代码来自此教程帖的第一章
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <algorithm>
#include <cmath>
#include <iostream>
#include <iomanip>
using namespace std;
int main()
{
cout<<"Hello,world";
return 0;
}

我不明白教程一开始设这么多预处理命令是为了什么？？
一开始只需要iostream头文件(控制输出输入）就足够了，我的教材是到了第六章才开始讲预处理命令的
新人很容易就会被误导

另外在第三章"赋值“中，楼主使用的是可读性极差的“a”"b""c"
好歹也讲一下命名法吧（本人教材用的是匈牙利命名法）

还有，很多都代码不加注释，有意思

-被阉割得太严重
关于赋值那一章我的教材一共讲了超过20多页
(包括命名法、语法可读性、表达式、运算符、优先级等等)
然而楼主不到500字就把它讲完了。。。
补充一下：那一章连“变量”是啥都没讲明白
