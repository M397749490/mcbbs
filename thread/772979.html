PayDay
PayDay是一个Sponge插件，可以根据设定好的时间间隔给玩家游戏币奖励。
食用方法
你可以通过修改在Sponge配置文件夹中的配置文件(payday.conf)来调整这个插件是如何工作的。
  1. timeamount="1"
  2. payonjoin="true"
  3. enableafkpay="true"
  4. timeunit=Hours
  5. payamounts={
  6.     "players"= {
  7.         "permission"= "*",
  8.         "amount"= 50.0
  9.     }
  10. }
复制代码

可用的时间单位包括:
  • Nanoseconds
  • Microseconds
  • Milliseconds
  • Seconds
  • Minutes
  • Hours
  • Days

你可以使用这样的格式分配不同的奖励
  1. payamounts={
  2.     "my group"= {
  3.         "permission"= "*",
  4.         "amount"= 50.0
  5.     },
  6.     "my group 2"= {
  7.         "permission"= "requires.this.permission",
  8.         "amount"= 19.99
  9.     }
  10. }
复制代码

如果权限设置为*,那么所有玩家都能获得奖励。
与其它插件的配合
如果配置文件中的enableafkpay设置为false，同时Nucleus的AFK模块是启用的，那么PayDay会在给予玩家奖励之前，检查玩家现在是否是AFK状态。如果是，那么玩家将不会收到任何奖励。
