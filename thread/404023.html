[rose_red]简便电路讲解[rose_red]

我们先要为开启电路做准备
那就需要用到一下指令

  1. /scoreboard objectives add kill playerKillCount 罪恶指数
  2. /scoreboard objectives setdisplay sidebar kill
复制代码
然后为了让旁边的罪恶指数显示出来，所以需要这两个指令被激活
  1. 先 /scoreboard players set @p kill 1
  2. 后 /scoreboard players set @p kill 0
复制代码
然后就是利用红石比较器+漏斗的高频来激活是否达到指定指数的判定
我相信会用红石的人已经会用这个红石高频了，但是虽说是高频，用起来不不会卡
如果不知道的请自行上网查找，或下载地图查看
而判定指令是这个
  1. testfor @p[score_kill_min=2]
复制代码
testfor @p[score_kill_min=2]
注意：上面这行指令中，被加粗字体可以自行修改
然后后面的话，就不用我说了，按照你们的高智商，绝对可以知道后面要怎么样的，应为后面其实是可以举一反三的！！！如果还不懂，你们可以自行下载地图脑补
所以我们最后就讲讲停止吧
  1. /scoreboard objectives remove kill
复制代码
/scoreboard objectives remove kill
注意：上面被加粗的字体中，可以切换，但是切换条件必须是以下两条中，加粗的字体被更改时，才可以更改
/scoreboard objectives add kill playerKillCount 罪恶指数
/scoreboard objectives setdisplay sidebar kill
最后系统完成
