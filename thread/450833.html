介绍
这是一个略轻量的插件，提供了无线红石的功能。赶紧吧你的无线红石mod卸载了吧！
特点  Features

·十分简单的发射和接收信号！                           
·没有延迟，信号传输的时间！                           
·如果你想要的话你也可以设置一个延迟！            
·许多命令来控制插件，查看你的“无线网络”的信息！            
·特殊的管理员指令和权限来控制玩家是否能使用！           

如何使用
使用命令创建一个 发射器/接收器/屏幕：
  • 待在你想要创建 发射器/接收器 的地方
  • 使用/wr transmitter 频道名称 来创建发射器， 或者使用 /wr receiver 频道名称 来创建接收器， 或者 /wr screen 频道名称 来创建屏幕。
  • 一个牌子出现在了这里，如果你写的频道存在，它就被成功创建了，否则，牌子就会消失，完成了！
使用牌子创建一个 发射器/接收器/屏幕：
  • 在你想要创建 发射器/接收器 的地方 放一个牌子
  • 在第一行， 输入 [transmitter] 来创建一个发射器, [receiver] 来创建一个接收器, 或者 [screen] 来创建一个显示器。
  • 在第二行输入你想要写的频道名称，如果不存在会自动创建一个（最好不要写中文）


这表示了创建发射器时频道已经存在：（图估计是老版本的）

删除一个发射机/接收机/屏幕：
  • 破坏牌子！
  • 完成！



指令
  • /wr transmitter <频道名称> - 在你站的位置创建一个信号发射器
  • /wr receiver <频道名称> - 在你站的位置创建一个信号接收器
  • /wr info <频道名称> - 查看一个频道的名称(是否激活).
  • /wr list [页] - 列出所有的无线频道.
  • /wr lock / unlock <频道> - 锁定 / 解锁 一个频道. 接收器不会对锁定频道反应
  • /wr admin - 用命令来管理无线频道
    • /wr admin <频道名称> addowner <用户ID> - Adds a owner to the given channel, Only if you are a owner of that channel to.（这句话翻译不来）
    • /wr admin <频道名称> removeowner <用户ID> - Removes a owner from the given channel, Only when you are a owner to.（这句话翻译不来）
    • /wr admin backup - 将数据 (所有的频道)备份成一个zip文件在根目录
    • /wr admin wipedata - 删除数据 (所有的频道, 并且在这之前先备份

  • /wr remove <频道名> - 删除整个频道配置和所有链接
  • /wr help [页码] - 列出帮助信息

权限与插件支持


插件支持

  • Vault, 以及许多权限插件 比如 PEX, bPermissions...
  • PermissionsEx
  • PermissionsBukkit
  • bPermissions
  • GroupManager
  • OP Permissions, 没有再bukkit找到插件，只使用基础权限
权限

  • wirelessredstone.* - 所有的权限
  • wirelessredstone.create.* - 允许你创建所有类型的标记
    • wirelessredstone.create.transmitter / receiver / screen - 允许创建专有信号的标记

  • wirelessredstone.remove.* - 允许删除所有的标记
    • wirelessredstone.remove.transmitter / receiver / screen - 允许删除指定类型的标记

  • wirelessredstone.commands.* - 提供使用下面命令的权限
    • wirelessredstone.commands.help - 允许使用/wr help 来查看帮助信息
    • wirelessredstone.commands.info - 允许查看频道信息
    • wirelessredstone.commands.list - 允许列出频道列表
    • wirelessredstone.commands.lock - 允许使用 /wr lock / unlock 命令
    • wirelessredstone.commands.removechannel - 允许直接删除整个频道（必须是管理员或者频道所有者）

  • wirelessredstone.admin.* - 提供使用下面命令的权限
    • wirelessredstone.admin.isAdmin - 这个权限使你能管理频道, 你将获得所有频道的所有权
    • wirelessredstone.admin.addowner - Allows you to add an Owner to a channel.（这句话翻译不来）
    • wirelessredstone.admin.removeowner - Allows to remove an owner to channel.（这句话翻译不来）
    • wirelessredstone.admin.backupdata - 允许备份数据库
    • wirelessredstone.admin.wipedata - 允许删除整个数据库。不要给任何人这个权限，很危险

配置
配置文件在 plugins/WirelessRedstone/config.yml
语言文件 - 1.8.4b后
  • 默认为英文 (存储为default.yml)
    • 如果你想改变语言文件, 请前往 this page.
    • 如果你想创建一个语言文件, 前往 those instructions.
文件内
  1. Language - 需要解释吗？（我感受到了作者的恶意） 用于选择语言文件。在上面查看更多信息
  2. ColourfulLogging - 默认为true。 允许插件将消息和颜色显示在控制台。 这很有意义，如果你要查找无线红石插件的调试消息你可以很快的找到
  3. checkForUpdates - 如果你不想被更新消息骚扰（原文是：一个了不起的新版本和新伟大的xxxx……）, 吧它设置成false。
  4. useSQL - 设置数据库存储。 如果设置为true,它将使用SQL数据库, 否则使用YAML文件。
  5. cancelChunkUnloads - 如果设置为True, 当某区块有一个标记，插件会防止区块卸载。
  6. cancelChunkUnloadRange - 如果设置为true, 这个字段范围的区块有标记，块不会卸载，默认设置为4;
  7. UseVault - 如果你使用Vault作为你的权限插件，设置为true。 不是设置为false
  8. DebugMode -如果设置为true,插件会对使用者发出信息
  9. DropSignWhenBroken -如果设置为true, 无线信号会在删除标记时断开.设置为false,则不会
