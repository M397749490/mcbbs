——————什么是Myz——————
MYZ不只是一个插件。这是Minecraft的一个完整的重新想象。具有高度拟真的新游戏模式，MYZ旨在效仿，增强DayZ和MineZ的组合。新的怪物，项目，聊天功能多，MYZ有很多牛B的地方，几乎无限的复活的机会。

生存和发展的后世界末日的荒地。不过要小心 - 你必须密切关注你的饥饿，健康，饥渴，能见度和温度。且不说增强不死怪物和BOSS。当你死了 - 你会死 - 变成僵尸，并得到了第二次机会，在生存。

请参阅下面的链接的功能和高度可配置选项的完整列表。

——————命令与权限——————
命令部分
/Myz —— 查看所有命令
/Myz manage spawns —— 设置僵尸生成的地方
/Myz reload config —— 刷新配置
/Myz spawn —— 设置重生点
/Myz manage engineer —— 给予你一个木棒，然后创建场地
/Myz reload userdata —— 刷新用户数据
/Myz manage chests —— 设置地图里的宝箱
/Myz version —— 查看插件现在的版本
/Myz respawn chests —— 删除宝箱
更多命令请去原帖查看

权限部分
Myz.play —— 把这个给玩家就行了

复制代码

config.yml —— 默认配置
  1. language

  3. This string entry grants access to set your default locale for MyZ by entering the language's locale code. The locale files can be found in /plugins/MyZ/locales and a locale appendix can be found here to determine the language per locale code. Each locale that doesn't have a language default is automatically overwritten in English (en_CA).
复制代码
  1. worlds

  3. A list entry that allows you to choose what worlds you want MyZ to be enabled on. Simply enter the names of each world you would like to play MyZ on (in list format).
复制代码
  1. operation_tick

  3. A curious field that defines how often MyZ should run scheduled tasks (like bleeding, infection, temperature, etc. actions). This number is represented in game ticks. Every game tick is 1/20 (0.05) of a second. Increasing this number will help increase performance, but will reduce quality and result in unexpected increases in scheduled action executions (ie. thirst decay will happen at a longer delay than specified). It is recommended that you leave this value at 1 unless you are experiencing severe performance issues. If you do change it, you should be mindful of the effects on thirst decay, bleed and infection delay and temperature modifiers.
复制代码
  1. auto-update

  3. A boolean field - whether or not MyZ should automatically check for and download updates from BukkitDev.
复制代码
  1. save_delay

  3. The delay (in ticks) between saving all user data. Higher numbers will result in a longer delay between saving, and saves occur every time MyZ shuts down. However, any unsaved data will be lost if the server crashes.
