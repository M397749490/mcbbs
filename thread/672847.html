首先我先声明下，这款插件为重制插件，非原创！
本人无聊闲逛插件帖子，突然看到了一个非常不错而且又很新奇的插件
也就是这款Coins——硬币特效插件
(本插件原地址被墙，上面为搬运贴地址)
但是发现这款插件不向下支持，并且主要的缺少了一些让这款插件更加完美无缺的功能，于是就在原有的功能上重制了此款插件，增添了一些功能
(经过测试与修改支持1.6x-1.10.2)
——————————————————————————————
首先
这款插件本先拥有的功能为。。。
算了不说了 你们自己看原搬运贴 不过多解释了(上面已经给出)
正文：
重置内容如下
1.从内核汉化
2.向下支持(1.6.x - 1.7.x)
(也就是说1.6+版本以上此重制插件全部支持)
3.支持定时定点撒币
（自定义一块区域，每过多长时间撒币）
4.支持撒币特效
5.增加玩家交互性,玩家可以通过/sabi 硬币数量 来进行撒币
（也就是说玩家可以输入指令花费金钱撒币）
6.增加撒币拾取音效，可自定义撒币拾取时的音效
7.自定义撒币的物品ID
（也就是说不单单是小黄花，可以是一些金锭啊金块啊什么的东西）

指令：
/sab 列出所有可使用的指令
/sab drop 游戏ID 硬币数量 半径  --- 以目标玩家为半径撒出指定的硬币数量
/sab drop x,y,z,世界名 硬币数量 半径  --- 以目标地点为半径撒出指定的硬币数量
/sab list  --- 列出当前正在进行的撒币任务
/sab create 硬币数量 半径 循环秒数  ---  在脚下创建一个硬币生成点,每隔某些秒数,将会撒出指定的硬币
/sab delete 任务ID  --- 删除一个正在进行自动撒币的任务ID
/sabi 硬币数量   --- 玩家使用,消耗指定游戏币可撒出相应的硬币数量

权限节点
sabi.sabi  -- 玩家使用/sabi 进行撒币的权限(玩家)
--OP默认拥有以下权限--
sabi.admin -- 插件重载(/sab reload)权限(OP)
sabi.drop   -- 撒币(/sab drop)权限(OP)
sabi.remove  -- 移除地上的硬币权限(OP)
sabi.list        -- 列出当前正在进行的定时撒币任务(OP)
sabi.create  -- 创建定时撒币任务权限(OP)
sabi.delete  -- 删除定时撒币任务权限(OP)

配置文件

#硬币名
nameOfCoin: '被撒出硬币'
#当玩家拾取到金币时,将发送一条小消息告诉他拾取到了多少游戏币
#1.7以下推荐填写:§a您拾取到一枚金粒,原来是面额为(§e%amount%§a)的游戏币！
pickupMessage: '&2获得游戏币: &a$%amount%'
#硬币的材质ID
yingbiitemID: 371
# 每一枚硬币的价值,为随机数
# from为最小值,to为最大值
moneyAmount:
  from: 3.0
  to: 8.0
#给予整数游戏币
roundedMoney: false
# 硬币是否可以堆放?
stackCoins: false

  ENDER_DRAGON: 64
  PLAYER: 3

playerDrop: true

preventAlts: true
# 怪物生成时是否掉落硬币?
spawnerDrop: false
#中立生物是否掉落硬币?
passiveDrop: false
#硬币被捡起时播放的播放声音
pickupSound: true
soundName: 'BLOCK_LAVA_POP'
#击杀怪物后,掉落硬币的概率,0.9为90%
dropChance: 0.9
#列出你想要在哪个世界禁止本插件的功能.
#下面示例为使撒币插件在 'creative' 和 'plots'世界中禁止:
#    disabledWorlds:
#    - plots
#    - creative
disabledWorlds: []

#允许玩家使用/sabi 数量 进行撒币

#玩家使用撒币功能时,一次性最多能撒出多少个硬币?防止一次性撒出过多造成卡顿
sabimax: 20


#玩家死亡时是否惩罚?
loseOnDeath: true
#如果启用上面那个功能,那扣除游戏币的随机数的最小值与最大值为?
moneyTaken:
  from: 100
  to: 150
#死亡复活后发送的提示信息为:
deathMessage: '&4- &c$%amount%'
#定时撒币是否启用?
dssbOn: true
#每多少秒循环一次?
dstime: 30
#定时信息(x,y,z,世界名 硬币数量 半径_定时秒)
dssblist: []
#是否启用撒币时的特效?
texiao: true
