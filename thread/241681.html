前言
通上红石信号，就会出现一些用光做的桥、门、铁轨之类的。鉴于没有太大的变更，具体的玩法请转看：http://www.mcbbs.net/forum.php?m ... hlight=%B9%E2%C7%C5里的说明，或者看我在网上搜到的一个介绍光桥的视频（中文的）。

几天前看到更新到了1.7.2，但是好像启动有点问题，一直等作者更新版本。昨天终于等到版本更新，试了一下也没什么问题。另外，虽然我在mod里面找到了中文的语言文件，但好像作者没有把那文件加载进去，所以我稍微处理了一下= =，所以想玩中文的请下载我盘里的mod。

更新



  • Fixed grav lift GUI not showing up - Ooops!
  • Each light machine has its own length limit, in the config file（现在每个光设备都有了长度限制，但可以在配置文件里修改）
  • Changed the max length of the light rail from 100 to 50, and its default length is 25
  • Light blocks are now explosion resistant - Oops!（防爆）
  • Update checker up and running again.
  • Light bridges now carry on the activation signal to adjacent blocks.
