BetterKits 更好的礼包插件此插件适用于Bukkit1.7.10+及Sponge1.9.4+

插件已实现功能:
  • 支持NBT数据
  • 支持cauldron服务端
  • 工具包预览(仅Bukkit,SpongeAPI未实现此功能)
  • 自定义每个工具包的冷却时间
  • 分配每个工具包的独立权限
  • 使用指令给玩家指定数量工具包
  • 自定义领取指令

命令和权限:
  • / kit [工具包名] - 获得一个礼包（权限：betterkits.kit.[工具包名],betterkits.kit代表拥有所有礼包领取权限）
  • / kits - 礼包列表（权限：betterkits.list显示可领取礼包，betterkits.listall显示所有礼包，包括无法领取的礼包）
  • / kitcreate [工具包名] - 创建一个新的礼（权限：betterkits.create）
  • / kitpreview [工具包名] - 预览礼包(仅Bukkit)（权限：betterkits.preview）
  • / kitgive [玩家名] [工具包名] [数量] - 给指定玩家指定数量的礼包（权限：betterkits.give）
  • / kitdelete [工具包名] - 删除礼包（权限：betterkits.delete）
  • / kitedit [工具包名] - 编辑指定的礼包内容（权限：betterkits.edit）
  • / kitclearcache - 编辑礼包后使礼包生效（权限：betterkits.clearcache）
  • / kitreload - 重新加载config（权限：betterkits.reload）基本安装和配置


基本安装和配置:
  • 将jar文件复制到“./ plugins /”（Bukkit）或“./ mods /”（Sponge）下。
  • 重启服务器。
  • 在服务器中创建一个区域用于放置箱子(确保玩家无法开启箱子)。
  • 放置箱子，并把您需要的礼包物品放于箱子中。
  • 只能使用小箱子,并站于箱子上，鼠标指向箱子，输入“/ kitcreate [工具包名]”创建礼包。
  • 你可以通过放置一个箱子，并重复前面的说明，以创建更多工具包。
  • 警告：不要破坏您为礼包所做的箱子！插件会直接读取箱子内容,箱子内物品不会存入config。另外确保玩家无法打开和破坏箱子。
配置文件:(Sponge)
  • config.yml
    1. AllowedChests=[
    2.     CHEST#允许使用的箱子名称
    3. ]
    4. KitTitleFormat="&4%name"#箱子标题
    5. StarterKit=tools#第一次进入服务器的初始礼包
    复制代码

  • data.conf
    1. Kits=[
    2.     {
    3.         commands=[]#自定义领取指令
    4.         cooldown=0#冷却时间，单位秒
    5.         name=tools#礼包名称
    6.         world=world#礼包箱位置-世界名
    7.         x=0#礼包箱位置-x坐标
    8.         y=64#礼包箱位置-y坐标
    9.         z=0#礼包箱位置-z坐标
    10.     }
    11. ]
    复制代码

  • messages.conf汉化
    1. KitAlreadyExist="&4存在同名工具包"

    5. KitRemoved="&6工具包已移除"
