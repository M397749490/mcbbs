这是shenmegui嘞?

这是一款能够让你右键下界之星就可以相当于使用/spawn的插件。
作者制作初衷只是因为玩家觉得输入/spawn很麻烦。*不想吐槽什么了
**右键等于/spawn的下界之星下文中我简略成S星！



神奇的地方：
这个插件可以配置材质(默认下界之星)，冷却时间，显示名称和描述
等很多神奇的配置。*有兴趣的朋友可以去原帖看，很多东西都可以配置哟~


指令&权限：
/spawnstar reload重载插件。
/spawnstar status显示配置设置。
/spawnstar give <玩家ID> [数量]给玩家S星。

权限介绍默认拥有
spawnstar.use使用S星的权限。都有
spawnstar.admin使用所有本插件指令的权限。op
spawnstar.give使用给S星指令的权限。op
spawnstar.reload使用重载指令的权限。op
spawnstar.status使用显示配置设置指令的权限。op
实在太懒，直接从bukkit页面复制过来的。


配置文件
  1. # This is the config file for SpawnStar plugin v1.5别管

  3. # localized language support语言
  4. language: en-US

  6. # Note: use only one enabled/disabled list, and comment out or remove the other启用世界
  7. # enabled worlds list (use this list for a default-deny world policy)
  8. #enabled-worlds:
  9. #  - enabled_world1
  10. #  - enabled_world2

  12. # disabled worlds list (use this list for a default-allow world policy)禁用世界
  13. disabled-worlds:
  14.   - disabled_world1
  15.   - disabled_world2

  17. # material to be used as spawnstar item. Set item data using a colon, example: WOOL:5材质
  18. # invalid item data may be reset, so use only valid item data values for a given material
  19. item-material: NETHER_STAR

  21. # minimum distance from spawn目的地最小距离
  22. minimum-distance: 10

  24. # cooldown time in seconds冷却时间（秒）
  25. teleport-cooldown: 60

  27. # warmup time in seconds传送时间(秒)
  28. teleport-warmup: 5

  30. # particle effects during warmup粒子效果
  31. particle-effects: true

  33. # require shift-click to use spawnstar item是否需要按shift键才能使用
  34. shift-click: true

  36. # remove item from inventory ( on-use使用之后 | on-success使用成功之后 | never 从不)是否使用后删除
  37. remove-from-inventory: on-use

  39. # allow spawnstar items to be used in crafting recipes能不能合成出来
  40. allow-in-recipes: false

  42. # cancel teleport if player takes damage传送时，受到伤害是否取消传送
  43. cancel-on-damage: false

  45. # cancel teleport if player moves传送时，玩家移动是否取消传送
  46. cancel-on-movement: false

  48. # cancel teleport if player interacts with another block传送时，玩家与方块交互是否取消传送
  49. cancel-on-interaction: false

  51. # maximum number of spawn star items that can be given at once (-1 for no limit)一次最多给几个S星，默认无限制。
  52. max-give-amount: -1

  54. # if player is in netherworld, try to respawn in matching overworld如果玩家在下界，尝试匹配到合适的世界/spawn
  55. from-nether: true

  57. # if player is in end world, try to respawn in matching overworld如果玩家在末地，尝试在匹配世界/spawn
  58. from-end: true

  60. # lightning strike at spawn location on use雷击目的地否？不明觉厉
  61. lightning: true

  63. # write log entry on use使用时写入log
  64. log-use: true
