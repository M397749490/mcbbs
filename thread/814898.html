标题: 关于1.13盔甲架问题
众所周知，1.13取消了/entitydata这个指令
那么要如何调整盔甲架呢（如让盔甲架长手、让盔甲架躺着等）
作者: (=°ω°)丿    时间: 2018-8-16 15:35
本帖最后由 Teenager_Yang 于 2018-8-16 16:31 编辑

1.13以前：/entitydata 实体 {实体数据}
1.13：/execute as 实体 run data merge entity @s {实体数据}
—————— 举个例子 ——————
1.13以前：/entitydata @e {Pose:{RightArm:[233f,233f,233f]}}
1.13：/execute as @e run data merge entity @s {Pose:{RightArm:[233f,233f,233f]}}
