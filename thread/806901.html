NyBattle - 插件详情

插件当前处于测试版, 希望大家帮忙测试更完善本插件
咸鱼一只, 可能写得烂, 希望dalao嘴下留情

一、前言
让你在MC里玩到类似绝地求生的小游戏
来一场刺激的绝地MC吧？hhh

二、特性
  • 自定义计分板/99%的提示消息
  • 支持BungeeCord
  • 支持游戏胜利/参赛奖励
  • 支持自定义语言文件
  • 支持多竞技场/牌子显示
  • 每个竞技场都可单独配置
  • 显示陀螺仪/缩圈进度/航线进度

三、命令
玩家-命令
/battle join <arena> #加入一个竞技场(BC不需要)
/battle leave #离开当前竞技场
管理-命令
/battle create <arena> <world> #创建一个竞技场(一个世界一个竞技场)
/battle name <arena> <arena> #设置竞技场别名(显示的名字)
/battle border <arena> <size> #设置边界初始大小
/battle setitem <arena> <D/C> #设置空投/箱子物品
/battle setlobby <arena> #设置竞技场等待大厅
/battle setend<arena> #设置游戏结束点
/battle min <arena> <amount> #设置竞技场最少人数
/battle max <arena> <amount> #设置竞技场最大人数
/battle list #查看竞技场列表及状态
/battle delete <arena> #删除竞技场
/battle reload #重载插件配置
/battle restart #重置全部竞技场 慎用!
权限: battle.admin

四、创建流程
先输入/battle create <arena> <world> 创建一个世界竞技场
再设置竞技场的name, border, setlobby, setend, min, max等配置项
再输入/battle setitem <arena> <D> 设置空投箱刷新物品
再输入/battle setitem <arena> <C> 设置普通箱子刷新物品
输入/battle restart或重启服务器, 推荐重启

创建牌子, 放置一个牌子
在第一行输入[nybattle], 第二行输入竞技场名(不是别名)
然后创建, 自动刷新显示
