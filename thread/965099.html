标题: [安全|传送]VoidSpawn——把进入虚空的玩家传送到安全地带[1.6.4-1.15]
引用原文的话
This plugin will teleport players to spawn when they enter the void. This is useful on hub servers that have open void that players jump into.
这个插件可以把进入虚空的玩家传送到重生点，在开启虚空的大厅服务器十分管用

功能
不少RPG服务器玩家血量远远超过原版的20，成千上万甚至过亿也很正常。这就导致玩家跳虚空迟迟无法死亡，导致服务器负担严重，使用此插件可以完美解决此问题
  • 在玩家跳入虚空的时候传送
  • 支持多种传送方式
  • 支持命令执行模式
  • 支持防止玩家越过下界的基岩层
  • 支持回到自己的岛屿(需要IslandWorld 或 ASkyblock 或uskyblock空岛插件)
  • 支持多世界MV插件
  • 支持开启死亡掉落保护
  • 支持传送时提示信息
指令·权限
指令》其中<>为必填 []为选填
  • /vs - 显示插件的版本号
  • /vs help - 显示插件所有指令帮助
  • /vs mode <模式> [世界] - 设置当前所在世界/指定世界的传送模式[如果不输入world则需要在前台指令]
     可选的模式：
     1.Touch 当玩家进入虚空时会把他传送到跳下虚空前踩到的陆地，如果陆地被摧毁，则会回到世界传送点
     2.Spawn 传送到设置的传送点，需要先用/vs set设置世界
     3.None 删除世界模式
     4.Command 开启指令模式
  • /vs modes - 显示所有传送模式及其帮助
  • /vs set [世界] - 设置一个世界的虚空传送点，和ESS的spawn没有什么关系但可以相同
  • /vs remove [世界] - 删除当前所在世界/指定世界的传送点
  • /vs reload - 重载插件
  • /vs message [信息] - 设置传送信息，支持颜色代码.如果 [信息] 留空则视为取消
  • /vs command [命令] - 设置命令传送模式进入虚空时执行的指令。如果 [命令] 留空则视为取消
  • /vs offset <数值> [世界] - 设置当前所在世界/指定世界的误差传送量，也就是说设置成多少就可以掉下虚空多远。 误差0的意思就是触碰虚空就传送。
  • /vs hybrid <true/false> [世界] - 设置混合模式.如果设置为true,就可以在命令模式下将随着设置的任何模式一起运行 Defaults to false if not set.
  • /vs keepinventory <true/false> [世界] - 如果是false，玩家掉虚空会请背包。默认是true
  • /vs toggle - 快速开启/关闭传送模式
  • /vs detector <Void/Nether> [世界] - 设置世界的特殊传送选项,默认是前者进入虚空传送，后者则是适用于下界的防止玩家进入上层基岩层的模式
  • /vs sound <音效代码> [音量] [音调] - 设置玩家进入虚空时播放的音效
权限:
  • vs.admin.* - 拥有所有/voidspawn 命令的权限
  • vs.admin.set - 拥有/voidspawn set 命令的权限
  • vs.admin.reload -拥有 /voidspawn reload 命令的权限
  • vs.admin.remove - 拥有/voidspawn remove 命令的权限
  • vs.admin.mode - 拥有 /voidspawn mode 命令的权限
  • vs.admin.help - 拥有/voidspawn help 命令的权限
  • vs.admin.message - 拥有/voidspawn message 命令的权限
  • vs.admin.command -拥有 /voidspawn command  命令的权限
  • vs.admin.offset - 拥有 /voidspawn offset 命令的权限
  • vs.admin.detector - 拥有/voidspawn detector 命令的权限
  • vs.admin.sound - 拥有 /voidspawn sound  命令的权限
  • vs.* - 拥有所有命令的权限
  • vs.player.toggle - 拥有/vs toggle 命令的权限
