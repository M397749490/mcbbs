很简单的一个插件,能于服务器清单修改在线玩家人数,瞬间让你的服务器成为最人气的服务器！

注意事项
  • 请自己衡量风险,使用本插件将会修改你的CraftBukkit.jar
  • 建议最好下载适合版本对应你的服务端版本使用

插件安装
  • 先下载Bibo38Lib和ChgUsers,并把他们放在你的服务器插件文件夹
  • 请备份你的Craftbukkit JAR档
  • 重新启动服务器(不要输入reload完成本步骤)
  • 现在将需要一点时间替换Class文件
  • 在Windows系统上将会出现一点异常消息,但请别担心,这完全正常
  • 完成后服务器将自动停止,请手动重新启动服务器
  • 如果服务器启动成功代表本插件安装完成

手动安装
  • 下载ChgUsers
  • 创建脚本并输入
    1. java -jar ChgUsers.jar
    复制代码
    *有可能因为你的Java问题需要输入完整的Java路径而不是"java"
  • 输入你的Craftbukkit JAR档路径
  • 等待完成


插件卸载
只需要从你的插件文件夹中删除Chguser.jar
不过会在你的Craftbukkit JAR档中留下一点垃圾文件
你可以先输入/chguser remove清理垃圾文件然后再删除本插件

插件指令
  • /chguser help [指令] — 查看本插件某个指令的详细用法和指令权限设置
  • /chguser remove — 从服务器中删除本插件
  • /chguser reset — 重置在线玩家数量为正常值
  • /chguser reload — 重载本插件配置
  • /chguser autoadd [数字] — 自动增加或减少玩家数量为正常值
  • /chguser setplayers [数字] — 设置在线玩家为一个固定数字

支援的权限插件
本插件支援很多权限插件,你可以使用Vault控制他们
