作者: 爱心魔王FHC    时间: 2016-7-30 14:01
2、创建一个叫riding的计分板
/scoreboard objectives add riding dummy
给僵尸马上有僵尸的马设置分数为1
/scoreboard players set @e[type=EntityHorse] riding 1 {Type:3,Passengers:[0:{id:"Zombie"}]}
给所有僵尸马设置分数为0，用比上面慢一点的高频
/scoreboard players set @e[type=EntityHorse] riding 0
然后修改NBT
entitydata @e[type=EntityHorse,score_riding_min=1] {Invulnerable:1}
entitydata @e[type=EntityHorse,score_riding=0] {Invulnerable:0}

1、创建一个叫poison的计分板
/scoreboard objectives add poison dummy
给在地上的毒箭设置分数为1
/scoreboard players set @e[type=Arrow] poison 1 {Potion:"minecraft:poison",inGround:1b}
然后以箭为中间fill地毯
/execute @e[type=Arrow,score_poison=1,score_poison_min=1] ~ ~ ~ fill ~-1 ~ ~-1 ~1 ~ ~1 minecraft:carpet 5
然后要不要kill箭什么的看你要怎么弄
