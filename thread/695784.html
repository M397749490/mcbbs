这个插件有什么用:
√指针
√用量查看
√插件查看
√简单清理缓存
√系统查看

插件权限:
无，所有指令均只有op才能输入

配置文件:
无

指令:
====服主区===
/sc class ——查看服务器内所有加载的插件的主类
/sc dosage——查看地址大小、空闲内存、最大可用内存、虚拟机可用处理器的个数
/sc config ——查看服务器的操作和真实ip
/sc java ——查看Java的配置
/sc clear ——简单清理一次内存
/sc pl ——查看服务器内所有插件，按顺序和标号依次输出
/sc update ——刷新插件列表
/sc field —— 查看所有插件主类里的变量的偏移值和所占字节(没有被修饰为private和static的)
====高级管理区(指针)====
说真这玩意没卵用(滑稽
/sc pointer isword——指针是否正常工作
/sc pointer free [偏移值] —— 释放指定偏移值的内存
/sc pointer allocate [扩充大小] ——扩充内存，输出扩充内存的偏移值，你可以往这个偏移值里面塞东西
/sc pointer reallocate [偏移值] [内存大小] ——重新分配内存
/sc pointer putint [偏移值] [数字] ——往指定的偏移值里面塞数字
/sc pointer getint [偏移值] ——获取指定偏移值里面的值(必须是一个数字)
