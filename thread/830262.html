拾取经验需要SharkSK作为附属插件
事件为:
[on] exp[erience] change
当玩家获得经验时
例子:
on exp change:
    message "&a&l+ %event-number%XP"
// 获得经验时，发送提示

Bossbar需要SkRayfall附属插件
(add|set) bossbar %字符串% for %玩家%
例子
on exp change:
    set bossbar "23333" for event-player
