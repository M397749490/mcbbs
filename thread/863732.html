怎么配置？自己对照这个改吧
  1.   plotworld:
  2. # 世界的名称
  3. # 如果修改世界名称,修改plotworld为新的世界名车

  5. # 你可以拥有多个地皮世界
  6. # 如果有多个世界,复制plotworld下面所有项并修改plotworld为新的世界名车

  8.     PlotAutoLimit: 1000
  9. # 使用/plot auto （自动领取地皮指令）的搜索范围 默认是1000
  10. # 如果是1000，表示搜索范围是1000*1000，如果这个范围没有空闲地皮，就好显示一个错误
  11.     PathWidth: 7
  12. # 这是路径包括地皮路的宽度 默认是7
  13.     PlotSize: 32
  14. # 地皮的大小，默认是32
  15. # 如果是32，则表示每块地皮的大小事32*32即1024个格子
  16.     BottomBlockId: '7'
  17. # 这是地皮世界的底部，默认是基岩（7）
  18.     WallBlockId: '44'
  19. # 这是环绕在地皮周围的方块，默认是石台阶（44）
  20. # 可以使空气（0）
  21.     PlotFloorBlockId: '2'
  22. # 这是每块地皮表层的方块，默认是草方块（2）
  23.     PlotFillingBlockId: '3'
  24. # 这是每块地皮表层的底层之间的方块，默认是泥土（3）
  25.     RoadMainBlockId: '5'
  26. # 这是路中央的方块，默认是橡木木板（5）
  27.     RoadStripeBlockId: '5:2'
  28. # 这是路边上的方块，默认是云杉木板（5:2）
  29.     RoadHeight: 64
  30. # 这是路的高度（y坐标）。默认是64
  31.     DaysToExpiration: 7
  32. # 这是地皮的过期时间（以天为单位），默认为7天
  33. # 设置为0为永不过期，过期的地皮不会被清除，会被添加到/plotme expired 列表
