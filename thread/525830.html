CratesPlus

设置个礼物箱子，玩家有钥匙可以打开获取随机里面物品
支持MCPC，任意物品



插件特色：

自定义箱子

游戏内可编辑

开箱子播放音效

开箱子施放烟花（新版本取消）

需要钥匙

钥匙无法放置

GUI界面

设置简单，有投票系统（新版本取消）

支持全息显示

插件命令：

/crate settings - 编辑礼物箱子
/crate reload - 重载礼物箱子
/crate create <name> - 创建礼物箱子
/crate rename <old> <new> - 重命名礼物箱子
/crate delete <name> - 删除礼物箱子--shift+左键点击删除放置的箱子
/crate crate <type> [player] - 给予指定礼物箱用于放置
/crate key <player> [type] - 不指定type则给玩家一把随机钥匙，指定type则给予指定箱子钥匙.
插件权限：
cratesplus.admin - 管理员权限. 默认 OP.
cratesplus.updates - 插件更新权限. 默认 OP.
设置布奏：
1,/crate create aaa创建名为aaa箱子
2，/crate settings - 编辑礼物箱子，选择创建的aaa进行编辑，物品直接放入即可
3，/crate crate aaa zmdoyouknow给予自己aaa礼物箱，zmdoyouknow为ID，可以放置在任何区域，自带防偷盗
4，/crate key @p aaa给予附近玩家一把aaa礼箱的钥匙
