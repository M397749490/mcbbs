标题: 小组人数显示不全影响成员管理

一直我都有一个问题，就是小组人数显示不全
我不知道是不是我一个人的问题，所以没有提过
但是今天我在给一个刚刚通过小组审核的人点同意的时候不小心同意了另外一个人
有论坛小组管理的人都知道每天都有不同的人“不小心”点到申请加入
现在有一个很严重的问题就是，不止是小组界面的成员列表，成员管理的界面也是一样的
小组页面的成员列表普通成员是按加入时间倒叙的方式排列的
但是在成员管理的界面成员确是正序排列
所以我在成员管理里无法管理后面那一大截的成员，导致我无法踢出我不小心放进来的人。
反正就是很不方便，有没有抢救方法能够让我管理所有的成员

给你一个临时补救的方法：
首先小组首页是能看到新加入的成员的（算了当我没说，这个列表很迷），复制他们的UID。然后进入成员管理界面，在列表中最后一个人那里右键打开开发者模式，每一个人就是一个li标签，在后面再插入一个li标签：
  1. <li>
  2. <a href="home.php?mod=space&amp;uid=123" class="avt"><img src="http://www.spr-bbs.com/uc_server/avatar.php?uid=123&amp;size=small"></a>
  3. <p><a href="home.php?mod=space&amp;uid=123">用户名</a></p>
  4. <p><input type="checkbox" class="pc" name="muid[123主要修改这里的UID]" value="4"></p>
  5. </li>
复制代码

然后就可以操作了

例如，你要踢出混乱（3038），代码可以这么写：
  1. <li>
  2. <a href="home.php?mod=space&amp;uid=3038" class="avt"><img src="http://www.spr-bbs.com/uc_server/avatar.php?uid=3038&amp;size=small"></a>
  3. <p><a href="home.php?mod=space&amp;uid=3038">用户名</a></p>
  4. <p><input type="checkbox" class="pc" name="muid[3038]" value="4"></p>
  5. </li>
复制代码

前面三个UID填不填不要紧，只是展现链接和头像，最后一个checkbox的name中的UID才是重点。合着DZ这是直接把对象数组扔外面了吗

经过测试，方法可行，只要不失误。

当然你也可以直接修改现有元素。不过这事最好找个对HTML更了解的人操作。
