SanzunoKawa
重置版! 修复上个版本的重大BUG! 优化代码结构!<br />
拥有让服务器支持单服单世界程度的能力
最大程度模拟原版地狱门/末地门的特性
单服单世界: 把末地/地狱放到一个单独的服务器里面

特点
  • 地狱门跨服

    • 主世界和地狱的坐标互相转换 (*8)
    • 自动生成地狱门
    • 在范围内(正方形半径 x,40,y,10,z,40)的地狱门复用

  • 末地门跨服


视频效果
Bilibili

使用方法
  • 1.下载插件并放到Plugins目录里面 (注意 每个子服都要装)
  • 2.子服装上 WorldTyper 插件(MCBBS)
  • 3.等服务器完全启动后关闭
  • 4.编辑 plugins/SanzunoKawa/config.yml 内有注释
  • 5.编辑 plugins/WorldTyper/config.yml 内有注释
  • 6.再次启动服务器
  • 7.(可选)装一些额外插件，比如说跨服聊天/玩家信息同步插件


注意事项
  • 插件需要 Redis 支持!!!
  • 插件不带玩家信息同步(不限于背包,状态)，请自行安装其他插件
  • 实现一个服只有一个世界的插件: WorldTyper
  • 目前未实现传送门传送物品/生物 (在做了)
  • Mod 支持? 玩家跨服我觉得是支持的
  • 推荐新的服务器使用此插件，旧服迁移到单服单世界可能会出现地狱门传送位置错误的情况


配置文件
  1. # 调试模式 | 打开后会看到很多调试信息
  2. debug: false
  3. # 这个服在BC里面配置的名字 | 比如说这个世界是主世界服务器 就写world
  4. server_name: world
  5. # 主世界对应的子服
  6. world_server: world
  7. # 地狱对应的子服
  8. nether_server: nether
  9. # 末地对应的子服
  10. the_end_server: the_end
  11. # Redis 设置
  12. redis:
  13.   # ip
  14.   host: 127.0.0.1
  15.   # 端口
  16.   port: 6379
  17.   # 密码 没有的话留空
  18.   password: ''
