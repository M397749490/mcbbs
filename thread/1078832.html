插件介绍


一款支持自定义登入、登出显示的插件，非常的简洁，支持高版本！

还可以支持标题文字显示！



使用方法


下载此插件，放入 plugin 文件夹，重启服务器并更改配置文件！



插件命令


/Joinmessage set <Message> -> 改变玩家登入信息，使用 %player% 替代玩家 ID

/Leavemessage set <Message> -> 改变玩家登出信息，使用 %player% 替代玩家 ID

/Languages -> 查看所有支持的语言



配置文件&汉化


  1. #玩家加入
  2. Join: "[&a+&r] &6欢迎玩家 &6&l%player% &6加入服务器！"
  3. #玩家退出
  4. Leave: "[&a-&r] &6玩家 &6&l%player% &6暂时离开了服务器！"
  5. #新加入的玩家
  6. New-Player: "[&a+&r] &6欢迎玩家&6&l%player% &6第一次加入服务器！"
  7. #是否选择打开新加入玩家提示：默认开启
  8. First-Join-Message: true
  9. #语言选项：默认EN
  10. Language: EN
  11. #标题文字显示：默认开启
  12. Title-Onjoin: true
  13. #主要标题（第一行）
  14. Title-Onjoin-Message-Main: 欢迎
  15. #附属标题（第二行）
  16. Title-Onjoin-Message-Bottem: 来到我们的服务器
