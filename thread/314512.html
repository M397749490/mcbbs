原文：

Hello!

In-case you don't know, right now Unturned is going through a massive overhaul for optimizations, Steam servers and Workshop support which isn't currently on the public branch.

The overhaul is getting to be such a huge patch that from now on it will be referred to as the 3.0 Update! Over the last several days a huge amount of progress has been made on this front:

-Localization is now completely possible, as all the language files are stored in a folder in the game directory. You can easily copy the English folder and make a translation, or download someone else's from the Steam workshop.

-All the backend for external assets is complete. Animations, textures, models, anything you can think of is able to me modded and added to.

-Steam cloud and local saves (now stored outside of the registry) use the same easily readable file format meaning it is very easy to iterate upon the saving system, it will be more reliable and it is simple to configure custom data.

-The in-game level editor is now mildly functional allowing you to form the terrain, configure textures and move objects! (Thanks to /u/zaph34r for helping with world/screen axis restriction math!) A level can now be up to 64km2 if you choose:

翻译：

Hello！

当前你不知道的情况下，我正在以千方百计进行着一个大规模检修的优化。目前Steam服务器和创意工坊的对游戏支持，并未面向公共使用。 (这句话作者在上次更新说明说过一次)

大规模检修(游戏优化)慢慢形成一个庞大的补丁——从现在开始将被称为3.0更新！在过去数天中已在这几个方面取得大量的进步：

-游戏本地化(像我的世界一样选择游戏语言)现在是完全可能实现的，因为所有的语言文件都存储在游戏目录下的文件夹中。您可以轻松地复制英文文件夹，并进行翻译，或从创意工坊下载别人的翻译。  

- 所有关于外部资源的平台创建已经完成。动画，纹理，模型，反正任何你能想到的都能够自己进行修改和添加。 （就像我的世界一样改变材质，增添MOD）

- Steam云和当地存档（现保存在注册表之外）使用相同、容易阅读的文件格式，就意味着它很容易在存档系统进行迭代（“迭代”是程序术语，就是不停的代换的意思），自定义存档数据将会变得更加可靠和配置简单。

-游戏中的关卡编辑器现在只有小小的功能，但能让你编辑地形，配置纹理和移动对象！ （感谢/U/ zaph34r在世界和屏轴的限制数学方面帮助我！）现在如果你选择A级地图面积可到64km2：(如图)





现在，这些地图可能实际上只能加载到一个基本的水平(我不懂...)——我开始研究如何将玩家相关的东西（存储的物品，服装，药品等）带到这些地图上！最有可能我会在本周晚些时候公布一个更新帖子。

实际上这次更新大多只是修复bug，如:在没有石头的地方放置更多的石头，等等。
但有一个新增加的：现在你可以屏障掉某个玩家的麦克风，只要打开玩家菜单(按键盘P键)，在菜单点击你所要屏障的玩家的名字，然后选择"Mute"选项即可。

感谢您的阅读！
