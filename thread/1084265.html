在此实例配置文件中

demo为奖励的编号 暂无实际用处
mode为奖励的激活模式
目前激活模式有
Daily  每日签到
若激活模式为Daily则values需设置为1

continuous  连续签到
若激活模式为continuous则values为连续签到的数量  即签到几天可以获得奖励礼包  如果为2则连续签到2天

fastival  节日签到
若激活模式为fastival则valuse需设置一个具体的日期格式如'2020-07-22'

top  前几名签到奖励
若激活模式为top则values可以设置为一个数字代表每天前几名签到的可以获取奖励也可以设置为一个字符串'%3%'这代表第三名签到的人可以获得指定奖励

PAPI占位符
%SignIn_player%   玩家姓名
%SignIn_world%   玩家所在世界
%SignIn_is%   本日玩家是否签到  会返回两种信息[已签到、未签到]

%SignIn_allNumber%   玩家总签到数量

%SignIn_thisMonthNumber%   玩家本月签到数量
%SignIn_cNumber%   玩家连续签到数量

%SignIn_LoginNumber%  今天登录人数
%SignIn_SignInNumber%  今天签到人数

%SignIn_rank%  获取玩家今天签到排名
%SignIn_SignInTime% 获取玩家今天签到时间





#指令与权限#
/qd                                    -主命令 打开签到界面  [无权限]
/qd reload                         -重载配置文件  权限[SignIn.Reload]
/qd clean                           -清理无效礼包  权限[SignIn.Clean]
/qd set prize [奖励名称]     -配置奖励物品   权限[SignIn.setPrize]
/qd list                               -展示今日和昨日的登录人数签到人数签到玩家统计数据 权限[Sign.list]
/qd info [玩家名]                -展示查看某个玩家签到信息 权限[SignIn.info]
/qd signin [玩家名]             -直接签到功能，可利用此命令实现后台签到 权限[SignIn.signin]
/qd card [give/set/remove] [玩家名称] [数量]     -改变玩家补签卡数量 权限 [SignIn.card]
/qd me                               -查看自己签到统计信息 [无权限]
/qd help                             -查看指令帮助
/qd off message                -屏蔽提醒消息
/qd prize give [玩家名称] [奖励名称]  - 给玩家指定奖励  权限[SignIn.givePrize]
/qd prize list [玩家名称]      -查看指定玩家所有奖励
