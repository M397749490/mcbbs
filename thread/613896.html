作者: chenxiutao030    时间: 2016-8-2 13:27
①打开./GroupManager/config.yml
　　如果假设禁止的世界名称为"A"。
　　将文件设置为：
　　world:
　　world_nether:
　　- users
　　- groups
　　world_the_end:
　　- users
　　- groups
　　all_unnamed_worlds:
　　- users
　　- groups
　　A:
　　- users
　　- groups

重启服务器后在要禁止的世界输入
mangaddp builder -essentials.tpa   就行了
