插件指令与权限
作者原文
Commands [alias /lc]:
/lobbycompass get - Gives you the compass.
/lobbycompass reload - Reloads the config file.
/lobbycompass help - Shows the help message.
Permissions:
  • lobbycompass.*: Gives access to all LobbyCompass2 permissions.
  • lobbycompass.use: Gives permission to use the compass by right clicking.
  • lobbycompass.get: Gives permission to get the compass with /lc get.
  • lobbycompass.reload: Gives permission to use the /lc reload command.
Help permissions: [/lc help]
  • lobbycompass.help.*: Let you see all the help messages.
  • lobbycompass.help.get: Let you see the help message for the /lc get command.
  • lobbycompass.help.reload: Let you see the help message for the /lc reload command.

指令相关(/lobbycompass可以用/lc替换):
/lobbycompass get      得到一个指南针  
/lobbycompass reload   重载插件
/lobbycompass help     获得帮♂助（其实给的就是上面那俩 打/lc也可以）

配置文件
作者原文
Configuration File:
  • compass-name - The name of the compass in your hand
  • compass-inventory-name - The name of the inventory in your compass
  • get-compass-worlds - List of worlds where players should have a compass
  • get-compass-on-join - Define if players get the compass when they login in a world where they should have compass.
  • executedByPlayer option: Will be run as a command from the player if true, otherwise it will be executed by the console (use %name% to get the player name)
  • isBungeeCommand option: Will execute that command as a BungeeCord command (INFO: currently only working for /send <player> <server> or /connect <player> <server>, they are both the same, you can also use the %name% to send the player who cliqued)
  • Others should be self-explanatory.

非官方的菜单配置教程
一个栗子！
第一步在options:下方添加一个ID 例如test（大概是使用前需要声明变量）注意格式对齐啊喂！
第二步按照格式在最下方添加
test:
    name: '&c&l测试'
    lore:
    - '&7回到出生点'
    item: stone
    cmd: spawn
    executedByPlayer: true
    position-in-inventory: 30
    isBungeeCommand: false

test是在options下方添加的那个玩意儿
name是指菜单内物品名称
lore是指名称下方的描述
item当然是指显示是什么物品啦~
cmd当然是执行的命令啦
executedByPlayer是指玩家或控制台执行命令
position-in-inventory是指物品所在的位置（0为第一个）
isBungeeCommand上面有 就不说了
这样 你在游戏中输入/lc reload
