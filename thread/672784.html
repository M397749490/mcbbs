Bank



介绍
The new, realistic loan system ! Players will no longer need to wait! Main news: Added Bank's storage, so players can transfer some money to the storage. Added /bank menu command, that will show all important details

新的、现实的贷款制度！玩家将不再需要等待！
主要作用：
添加银行的存储，让玩家可以转移一些钱的存储。
添加/bank 菜单命令，将显示所有重要细节。
特性
1.玩家可以从服务器上借钱
2.VIP利益率
3.管理员可以改变全球利率
4.管理员可更改还款期
5.玩家可以选择自己的还款期
6.管理员可以更改偿还时间（如每50天必须偿还一次）
7.自动检测系统各期系统检查所有贷款和还款金额自动回收资金
8.可配置的messages.yml
9.简单的存储系统
10.YAML数据存储
指令&权限
/bank -默认命令，它显示帮助菜单
/bank menu -简单信息菜单
/bank interest -显示当前利率
/bank vipinterest -显示当前VIP利率
/bank borrow <借款金额> <每次还款的金额> -借款
/bank balance -显示玩家的余额（银行里面的钱）
/bank save <钱数> -存钱
/bank withdraw <钱数> -从银行提钱 (bank.admin)
/bank setInterest -设置普通玩家利率 (用百分比)
/bank setVipInterest -设置VIP玩家的利率 (用百分比)
/bank minRepayments -设置最多还款天数 (超过立刻扣钱)
/bank speedup - This will bypass periodical checking and starts the check now (Warning! Use this command soberly, it will withdraw the repayments from player's account)不懂

普通玩家给予bank.player权限
VIP玩家给予bank.VIP权限
