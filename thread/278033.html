介绍：
本插件支持创建多种类型的小游戏。应该是很常见的插件，看没人搬就搬运过来了。
总体上和Battlearena是类似的插件
但是个人感觉配置起来选择更多点
而且支持的游戏类型也不少
注意 本插件与LimitedCreative（创造保护）冲突
感谢@kaituo0070  告知
164版本似乎可以在172上运行

可用的游戏类型有：
单人游戏（类似单人闯关类型的）
竞速游戏
寻宝游戏
多人PVP（有队伍、无队伍、多种类型、最后幸存、夺旗）
Spleef（掘一死战）

wiki
http://mineauz.com.au/minigames/wiki/index.php?title=Main_Page

权限
http://mineauz.com.au/minigames/wiki/index.php?title=Permissions
请注意给玩家使用牌子加入的权限
minigame.sign.use.*

命令
比较多= =欢迎其他人补完
http://mineauz.com.au/minigames/wiki/index.php?title=Commands
主命令/mgm /minigame

基本用法注意！！！！！172命令与164之前版本不同 按照下面步骤做提示 Invalid 的请告诉我
本人写的例子版本为164为基础写的


以多人团队死亡竞技为例
/minigame create <小游戏名称> [类型]
多人团队死亡竞技类型是teamdm注意！172的版本开始命令不同
团队死亡竞技改为TEAMS

之后设置点
到各个位置输入命令即可
/minigame set <小游戏名称> start <r(红队)/b(蓝队)> [人数]
设置蓝队或者红队的出生点以及这个出生点允许的人数
/minigame set <小游戏名称> end
设置游戏结束的时候玩家的位置
/minigame set <小游戏名称> quit
设置玩家退出游戏时候的位置
/minigame set <小游戏名称> lobby
设置大厅位置

然后是参数
/minigame set <小游戏名称> maxplayers <数量>
设置最大玩家数量
/minigame set <小游戏名称> minplayers <数量>
设置最小玩家数量
/minigame set <小游戏名称> maxscore <分数>
设置最大分数
/minigame set <小游戏名称> minscore <分数>
设置最小分数
/minigame set <小游戏名称> timer <时间长度>
设置游戏的持续时间 例如 5m 即为5分钟
/minigame set <小游戏名称> lives <数量>
设置允许有几条命
/minigame set <小游戏名称> scoretype <类型>
允许的类型 pvp的话 kills 比较好

然后是玩家初始装备
主命令
/minigame set <小游戏名称> loadout
+
remove [装备配置名称]
添加一套装备配置
create [装备配置名称]
移除一套装备配置
add <物品名称/id> [数量] [-l 装备配置名称]
添加单个物品
add <ME/SELECTED/SLOT> [-l 装备配置名称]
注意大写
ME 是添加自己身上的装备
SELECTED 选择的装备
SLOT 应该是下面一行的装备
clear [-l 装备配置名称]
清空一个装备配置里面所有物品
装备的选择则是利用牌子来选择
牌子的格式是
第一行 [Minigame]
第二行   loadout
第三行 装备方案名称

基本的就这些
最后注意
/minigame set <小游戏名称> enabled true
来启用游戏


玩家基本命令
/minigame join 名称
/minigame quit 名称

指令                   权限                介绍
/minigame create [名字]-minigame.create-创建游戏
/minigame set [名字] [类型]-仅管理员可用-修改游戏类型
/minigame join [名字]-minigame.join-加入游戏
/minigame start [名字]-minigame.start-强制开始游戏
/minigame stop [名字]-minigame.stop-停止一个游戏
/minigame quit [玩家]-minigame.quit-让一个玩家退出
/minigame quit ALL [竞技场名称]-minigame.quit-让这个竞技场的所有玩家强制退出
/minigame hint [玩家]-minigame.treasure.hint-在寻宝游戏里暗示这个玩家
/minigame revert [名字]-minigame.revert-竞技场重置
/minigame info [游戏名称] [页面]-minigame.info-貌似是游戏的信息
/minigame end [玩家]-minigame.end-强制结束一个玩家的游戏，如果是团队游戏，退出的玩家那方失败。
/minigame end [团队] [游戏类型]-强制结束一个团队的游戏
/minigame help-minigame.help-帮助
/minigame list-minigme.list-列出所有的游戏
/minigame toggletimer [名称]-minigame.toggletimer-设置多人游戏时间
/minigame delete [名称]-minigame.delete-删除一个游戏
/minigame partymode [开true/关false]-minigame.partymode-打开或关闭Party模式？
/minigame deniedcommand add [命令]-minigame.deniedcommands-禁用一个命令
/minigame deniedcommand remove [命令]-minigame.deniedcommands-取消禁禁用一个命令
/minigame deniedcommand list-minigame.deniedcommands-被禁用命令的列表
/minigame globalloadout-minigame.globalloadout-打开Loadout，适用于任何小游戏
/minigame spectate [名称]-minigame.spectate-加入旁观者
