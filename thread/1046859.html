Arclight ⚡

在 Forge 上使用 Mixin 实现的 Bukkit 服务端。

本服务端将于 1.17 版本使用 Java 11，请尽快升级您的 Java 版本。

可能会问到的问题

Q: 有 1.16.4/1.16.3 吗？
A: Forge 在 1.16.5 支持加载 1.16.4/1.16.3 的模组，同时 1.16.4 客户端可以进入 1.16.5 服务器，请使用最新版

Q: 可以带多少 mod？
A: 放逐之路整合包（需删除 Performant 并升级 ExtendedNether），约 130 mods


Q: 会有 Fabric 版本吗？
A: 有此方面的计划，如果您对 Fabric 相关开发熟悉，也可以来帮助开发
