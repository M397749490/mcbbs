TitleLib

当前版本：1.2

更新时间：2018/5/6

使用说明

首先，非程序员请关闭页面。指令发送什么的没有写。
这是我在给自己服务器写插件时顺便写的一个插件。当时发送title和actionbar都得用上，Player可以sendTitle，但是actionbar没有找到怎么用，然后就用nms写了一个，无视版本的lib（不过，1.7以下没有title和actionbar的就没办法用了）
如插件不适用你的版本也别汇报，没空更新了


使用方法

所有文字内容均可直接使用颜色代码&，函数将自动转换。

发送title：
  1. TitleLib.sendTitle(Player player, String title, String subtitle);
复制代码
指定玩家，title与subtitle，淡入时间 70 ticks，显示时间 100 ticks，淡出时间 60 ticks，相当于指定了下面的函数的3个时间参数。


发送title：
  1. TitleLib.sendTitle(Player player, Integer fadeIn, Integer stay, Integer fadeOut, String title, String subtitle);
复制代码
指定玩家，title与subtitle，以及淡入淡出和显示时间。


发送actionbar:
  1. TitleLib.sendPlayerActionbar(Player player, String text);
复制代码
指定玩家和actionbar的内容，向用户发送actionbar。

插件原理

有一个根据当前server版本获取nms类的函数，使用nms类发包完成title与actionbar的操作。另外，多次发送actionbar可能造成客户端卡顿（不清楚原因，反正我服务器就这样）
