介绍:
       之前想开服务器写的结果跳票了就发出来了
       支持RPG武器支持保存LORE和改名

       只测试了1.7.10,欢迎测试其他版本反馈。       已经更新到V2.0,0版本
       支持全版本
       支持KC，Cauldron，MCPC等核心      暂不支持Spigot,       目前已经停更至于为啥因为我没时间比较懒=-=或许啥时候有时间会进行更新吧
      我觉得也没人会接坑
        


指令：
/sp create [物资名] 创建一个物资点
/sp setTime [物资名] [时间/秒] 为物资设置刷新时间
/sp setStartMessage [空投名] [提醒]空投降落倒计时开始计算时(支持[x][y][z])
/sp setMiddleMessage [空投名] [提醒]空投降落倒计时至一半(支持[x][y][z])
/sp setEndMessage [空投名] [提醒]空投降落的提醒(支持[x][y][z])
/sp add [空投名]将你手中的物品添加至空投可能出现的物品堆中
/sp setNumber [空投名] [数量-数量]设置一个空投内可能出现的物品数  最大几率性(0-54)
/sp addRefresh [空投名]在你脚下设置一个空投刷新点
/sp start [空投名] 此空投将开始进行刷新(重启服务器可达到同样的效果)
/sp remove [空投名]删除一个空投
