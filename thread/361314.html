是想要每个世界都有独立的权限表吗？
如果是：打开/Groupmanager/config.ym找到并编辑如下代码，注意格式（你最好复制现有的内容来修改不要敲回车键，除非你能确保不键入tab缩进）
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           子世界1的名字:
  9.           - users     //只继承主世界的users.yml，不继承groups.yml
  10.           子世界2的名字:
  11.           - users
  12.           其他世界类似...
  13.           all_unnamed_worlds:
  14.           - users
  15.           - groups
复制代码
之后重新加载权限组插件/manload
然后在/Groupmanager/worlds/目录会生成以各个子世界名为名字的目录，里面各有一个groups.yml。
将同目录下world中的groups.yml复制到上述各个目录并覆盖自动生成的groups.yml。
打开编辑各个世界的groups.yml即可。编辑后记得需要/manload重载插件。

我想问…生成后怎么编辑…

使用notepad++打开每个groups.yml。
从上小学开始，老师就教比着葫芦画瓢和举一反三了，照猫画虎也是好的。
某个世界中的groups.yml是该世界的各个用户组的权限设置，
每个用户组都由这几部分构成：
  1.   Builder:                              //用户组名
  2.     default: false                      //是否为默认组
  3.     permissions:                        //权限
  4.     - plotme.limit.5                    //权限列表
  5.     - residence.select
  6.     - residence.create
  7.     - signshop.signs.*
  8.     inheritance:                        //继承
  9.     - default                           //继承Default组权限
  10.     - g:essentials_builder
  11.     - g:towny_builder
  12.     info:                               //组信息
  13.       prefix: '&2[建筑师] '             //组用户前缀
  14.       build: false                      //是否开启建造
  15.       suffix: ''                        //组用户后缀
复制代码
格式注意事项：
1、任何缩进都是空格缩进，不得使用tab缩进
2、属性和值之间必须有空格，比如abc: 100是正确的，abc:100是错误的
3、权限格式为“    - 权限名”，“-”前后的空格数要正确
