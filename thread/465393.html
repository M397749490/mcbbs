Story 故事剧情【背景】：

Times are tough in your home town of Norfield and it seems like everyone is struggling. Every month you risk losing your home to the bank. Now that the bank has taken your most precious possession and disaster strikes, all seems hopeless. But this disaster offers a unique opportunity.


在你的城镇——Norfield，艰难的时刻。每个人都在为金钱而苦苦挣扎。你每个月都有可能被银行拿走一大笔金钱。现在，银行拿走了你所有的财富，一切似乎都没有希望了。但是这场灾难却给你提供了一个独特的赚钱机会。




Notes 注意：

  • This map is for Minecraft 1.8.7 (no mods).
  • There is a custom resource pack in the level directory so if you're playing in single player mode then it should load automatically. If you're playing on a server then the 'resources.zip' file in the level directory can be copied out and installed just like a normal resource pack.
  • If you're playing on a server then you must enable command blocks and set difficulty to normal in the server config.
  • This map should be multiplayer compatible for 2 or 3 players.


这张地图需要在Minecraft 1.8.7版本下游玩。[没有mod]

Map profile 地图简介：

Satoshi's Treasure is a multi-episode adventure map focusing on story, puzzles, and large-ish builds. Like typical adventure maps, you go around exploring places, killing monsters, collecting items, talking to NPCs, and unlocking the next part of the story. In addition there is a CTMish aspect where solving puzzles gives you Code Fragments. If you have all of the correct Code Fragments in the last episode then you can try to claim Satoshi's Treasure. This is a real treasure hunt.

这地图是一种多集类的寻宝探险地图。有很大的杂交构建。你需要去探险、杀死怪物、收集物品、和NPC对话，开启下一段故事！

如果你拥有了所有正确的宝藏代码【游戏中的银行卡】，你就可以尝试着拿到宝藏。这是一个真正的寻宝游戏！

Game screenshots 游戏截图：















[slimeball]Raiders 攻略[slimeball]

首先出生在家中，一开始并没有什么新鲜的剧情。把家中的资源拿走。【小麦、火把、煤炭、鸡肉等】

出门遇见Chet【一个西装男】这个西装男是银行的，他来向你索要钱财【就是上面所说的银行拿走了你的财富】，但是你没有钱，他要你的马。你去骑马后会掉虚空，马也就被拿走了。在村庄内每个屋子里的宝箱等都搜刮掉。

村内商店：

服装店、铁匠铺、食品店、海鲜店、书店等。

服装店：可以更换不同颜色皮革衣。

铁匠铺：铁毡，可修复物品。

食品店：有许多的蛋糕，在老板旁边的熔炉可找到5个南瓜派和1个蛋糕。

海鲜店：最里面的箱子里可找到冰块和鱼。

书店：无用，很多书架。

某村民家有铁剑。

装备整理好后，朝着村门口走。走了很长时间后发现桥断了。

这时返回，到食品店找妹子Sura和她说话触发剧情。她让你回家看看。你进入家里后可触发剧情，眼前一晃，妹子Sura过来了。你家发生地震，出现了一个大坑。

大坑内有一个大箱子，里面有Satoshi的银行卡【代码卡】和一本遗书还有一张地图。

地图标志有一个红色的”X“，跑到红色X的地方你会找到一个遗迹。

在这里你就可以打怪、探索、解密。”里面有迷宫也有死路“慢慢地和伙伴一起游玩吧！

到了最后的下水道里，整个下水道有一处光亮，用你的石镐敲碎后就可以上去啦！
