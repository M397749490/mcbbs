formats.yml
题主那么久没反应，那我编辑一下：
  1. NORMAL:
  2.   # 使用这个格式的条件，比如: 'player.isOp()'需要玩家是OP
  3.   - requirement: null

  5.     # 信息部分
  6.     msg:
  7.       # 默认聊天颜色
  8.       # (when the player doesn't have any permission of trchat.color.force-defaultcolor.<CODE>)
  9.       default-color: 'f'
  10.       hover: '&7时间: %server_time_h:mm:ss a%'

  12.     # 自定义 Json 格式部分 (消息之前的部分)
  13.     parts:
  14.       world:
  15.         text: ' %multiverse_world_alias%&7|'
  16.         hover: |-
  17.           &r
  18.           &8> &7位置: &3%multiverse_world_alias%&7>>&2%player_x%,%player_y%,%player_z%
  19.           &6> &e点击申请向ta传送
  20.           &r
  21.         command: '/tpa %player_name%'
  22.         # (可选) 使用这个JSON的条件
  23.         requirement: null
  24.       part-before-player:
  25.         text: '&r%chenghao_use%'
  26.         hover: |-
  27.           &r
  28.           &8? &7称号:   &r%chenghao_use%
  29.           &8? &7生命值: &c%player_health_rounded% ?
  30.           &6? &e点击私聊
  31.           &r
  32.         suggest: '/msg %player_name% '
  33.       player:
  34.         text: '&7|&f%essentials_nickname%'
  35.         hover: |-
  36.           &r
  37.           &8? &7延迟:   &3%player_ping% 毫秒
  38.           &8? &7生命值: &c%player_health_rounded% ?
  39.           &6? &e点击私聊
  40.           &r
  41.         suggest: '/msg %player_name% '
  42.       part-before-msg:
  43.         text: '&7: &r'
  44.         hover: |-
  45.           &r
  46.           &8? &7延迟:   &3%player_ping% 毫秒
  47.           &8? &7生命值: &c%player_health_rounded% ?
  48.           &6? &e点击私聊
  49.           &r
  50.         suggest: '/msg %player_name% '
复制代码
  1. %multiverse_world_alias%多世界的世界名变量
  2. %player_name%玩家名
  3. %player_ping%玩家延迟
  4. %player_health_rounded%玩家生命值（取整）
  5. %player_x%,%player_y%,%player_z%玩家的X, Y, Z轴坐标
