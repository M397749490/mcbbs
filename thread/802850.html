那1000代表几分之几？

原文默认是：
  1. I:"1 Weighting Resolution"=1000
复制代码

这代表了，总值为“1”时（1相当于0.1%）也就是普通袋子的掉落率为20%

如果改成：
  1. I:"1 Weighting Resolution"=2000
复制代码

就代表了，在总值为“1”的前提下（1相当于0.05%）袋子掉落率为10%，默认值的二分之一

所以要往小了改，概率才会变高

作者: LRual    时间: 2018-7-3 14:29
可以通过修改第一个文件里的这一段后面的数值来修改掉落率


  2. "drop chances" {
  3.     # This is the resolution of the bag drop chances.  Only change this if you want bags with rarity resolutions > 0.1%
  4.     I:"1 Weighting Resolution"=1000
  5. }
复制代码


默认为1000
