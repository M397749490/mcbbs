  1. /gamerule doMobSpawning false
复制代码

这个代码是禁止怪物生成的
如果要做到不被破坏话其实也很简单
1.打开插件文件夹
2.打开GroupManager内的worlds
3.打开你要修改的世界名称
4.打开groups.yml
5.
  1.   Builder:
  2.     default: true
  3.     permissions: []
  4.     inheritance:
  5.     - default
  6.     - g:essentials_builder
  7.     - g:towny_builder
  8.     info:
  9.       prefix: '&2'
  10.       build: true
  11.       suffix: ''
复制代码

将build: true   改成build: false 即可，然后重载权限组插件
重载插件的指令是/manload
