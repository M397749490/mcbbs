EssentialsGeoIP 插件默认配置文件中的 GeoIP 数据库获取地址因 http://www.maxmind.com/ 的**调整 [ 需要登陆才可以下载 ] 导致无法下载数据库而引发的报错

注1: 同样的,插件 AuthMe 也因为无法下载 GeoIP 数据库导致报错

方法1: 你可以在那个网站申请注册一个账号,然后等待审核. 通过后即可登录账号获取 GeoLite2 数据库
方法2: 下载楼主的 GeoIP 数据库直接塞进 EssentialsGeoIP 的配置文件里

最新版本的 EssentialsGeoIP 已经修复了这个问题,但你仍然需要帐号才能下载数据库.
这边放出我的 Key 给大家,免得还得等待半天的注册审核.
  1. database:
  2.   show-cities: true
  3.   download-if-missing: true
  4.   # Url for country
  5.   download-url: "https://download.maxmind.com/app/geoip_download?edition_id=GeoLite2-Country&license_key={LICENSEKEY}&suffix=tar.gz"
  6.   # Url for cities
  7.   download-url-city: "https://download.maxmind.com/app/geoip_download?edition_id=GeoLite2-City&license_key={LICENSEKEY}&suffix=tar.gz"
  8.   # License key for downloads
  9.   license-key: "FHDOh1GGxDTs5X36"
  10.   update:
  11.     enable: true
  12.     by-every-x-days: 7
  13. show-on-login: true
  14. show-on-whois: true
  15. # "enable-locale" enables locale on geolocation display.
  16. # Language is determined by Essentials/config.yml "locale" section.
