这个bug有什么用？
在一些跑酷地图中会有如下设置：
站在某方块上获得跳跃提升效果 跳跃一次后消失
一般来说 获得跳跃提升效果要使用如下命令（1.13+）：
  1. execute as @a at @s if block ~ ~-0.1 ~ [方块名] run effect give @s minecraft:jump_boost 999999 [等级] true
复制代码
同时标记scoreboard的值（1.13+）：
  1. execute as @a at @s if block ~ ~-0.1 ~ [方块名] run scoreboard players operation @s [分数1] = @s [分数2]
复制代码
清除跳跃提升效果要使用如下命令（1.13+）：
  1. execute as @a at @s if score @s [分数1]< @s [分数2] run effect clear @s minecraft:jump_boost
复制代码
[分数1]的准则为dummy（虚拟类） [分数2]的准则为minecraft.custom:minecraft.jump（跳跃次数）
因为出现了跳跃次数 所以只要利用这个bug 就可以避免效果的清除
就看看bugjang会不会在1.16修复这个bug了
