已在本地服务器测试

# 服务器在哪个目录执行, 一般填写你的服务端根目录

HOME_PATH="/home"

# screen 里执行的启动脚本路径, 启动脚本内容在我下一个代码块中

SCRIPT_PATH="/home/your/server/launch.sh"

# 会话名, 这里直接使用随机UUID

NAME=$(cat /proc/sys/kernel/random/uuid)

# 开始创建 screen

screen -dmS $NAME

echo "启动的会话名: $NAME"

screen -S $NAME -p bash -X stuff $"cd $HOME_PATH && bash $SCRIPT_PATH\n"


启动脚本:
# 其实是抄的 yys 大佬的

while true

do

    java -jar server.jar

    echo " --- 服务器崩溃,尝试重启 --- "

done


另外，如果你想进入会话，那么使用
screen -S [会话名]
即可。另外作为docker舔狗如果你想后台运行服务器的话强烈建议使用docker
