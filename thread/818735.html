介绍
这款插件可以让你在minecraft中玩井字棋.但这种井字棋是高级版的.你需要在6X6的场地中将4个棋子连成一条线来获胜.

注意:插件不支持1.13但支持1.13.1


特点
  • 更大的游戏场地(6X6)
  • 排行榜
  • 数据记录
  • 支持玩家对战
  • 可观战
  • 和有AI的电脑对战
  • 可以一键删库然后跑路
  • 支持自定义语言

指令&权限
  • /tictactoe open - 打开主菜单
  • /tictactoe info - 显示插件信息
  • /tictactoe help - 显示帮助信息
缩写: "/tictactoe": "/ttt"

  • tictactoe.menu : 打开主菜单
  • tictactoe.computer : 与电脑AI对战
  • tictactoe.settings : 允许打开设置菜单
  • tictactoe.clear : 允许你删库
  • tictactoe.* : 给予你插件的所有权限
