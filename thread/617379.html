作者: xRPQx    时间: 2016-8-8 11:25
打开GroupManager
打开config
添加你要弄的世界,如下

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          plotworld:
          - users
          all_unnamed_worlds:
          - users
          - groups
          world1:
          - users
          world2:
          - users
          worldX:
          - users
(红色的就是要添加的,world1/2/X可以变换成你想要的世界名，注意下面只要- user~~)
然后游戏里输入/manload
你会发现,worlds里面多了X个文件夹
复制一份原来就有的世界文件夹里的group拷贝过去
进入修改即可
按你的要求，如在world1这个世界是[ABC]这个前缀
打开worlds -- > world1文件夹，打开groups，搜索builder，找到下面的prefix，设置为 prefix: '[ABC]'
/manload即可

作者: 蓝色的鲨鱼    时间: 2016-8-8 11:35
镜面权限组
打开服务端内plugins→GroupManager→config.yml[推荐使用notepad++或EverEdit等软件打开]
找到mirrors:这一项
更改为[例子]：
  mirrors:
        world:
          world_nether:
          - groups
          zy:               #zy和world_nether为世界名
          - groups
此为镜面权限组 然后进入游戏 去想要实现与主世界不同称号的世界 如一个叫zy的世界
①/mv tp zy
②/mangaddv builder prefix [蓝色的鲨鱼]     #builder为权限组     [蓝色的鲨鱼]为前缀
