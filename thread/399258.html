AnvilColors

AnvilColors is a plugin will let you rename items with color codes in anvils!
让你服务器的铁砧支持彩色代码!还能添加标识!



这个插件经测试,支持1.6.4~1.7.10,1.8未测试,应该可行


How to use it - 如何使用
When naming the item just use an '&' then put a color code listed below.
To get your colored item, take it out of the anvil. To use it you must be OP or have the permission: anvilcolors.use
你需要权限anvilcolors.use才能够使用 '&' 否则将无效命名为彩色，默认为OP

Commands - 命令

/addlore <lore> - 添加标识
/removelore <line number> - 移除<第几行>的标识



Permissions - 权限

anvilcolors.* - Allows all commands
- 允许使用所有命令 -
anvilcolors.use - Allows you to use colors in anvils
- 允许使用铁砧命名彩色(&) -
anvilcolors.lore.* - Allows you to add and remove lores.
- 允许添加/删除标识 -
anvilcolors.lore.add - Allows you to add lores.
- 仅允许添加标识 -
anvilcolors.lore.remove - Allows you to remove lores.
- 仅允许删除标识 -
anvilcolors.color.* - Allows you to use all colors.
- 允许使用所有颜色代码(默认) -
- 需要anvilcolors.use-

以下三条基本没用

anvilcolors.color.color - Allows you to use all colors (not including formatting codes).
- 允许你使用所有颜色(不支持格式代码) -
anvilcolors.color.formatting - Allows you to use all formatting codes.
- 允许你使用格式代码 -
anvilcolors.color.<color> - Allows you to use a color where <color> is the color without an '&'.
- 允许您使用一个颜色，这里的<颜色>没有一个是“&” -
