服务器有格雷 热力 ic 想禁用除格雷以外的矿物 怎么解决
作者: 忆梦cat    时间: 2019-9-6 15:49
本帖最后由 忆梦cat 于 2019-9-6 16:09 编辑

IC可以通过该配置文件关闭矿物生成
IC2.ini
  1. [worldgen / copper]
  2. ; Enable generating this ore
  3. enabled = false
  4. [worldgen / lead]
  5. ; Enable generating this ore
  6. enabled = false
  7. [worldgen / tin]
  8. ; Enable generating this ore
  9. enabled = false
复制代码
热力同样如此
config\cofh\world\config.cfg
  1. # If TRUE, CoFH World will not generate features at all. This option is intended for use when you want another mod to handle ore generation but do not want to blank out the various .json files yourself. Flat Bedrock may still be used. [default: false]
  2.     B:DisableAllGeneration=true
