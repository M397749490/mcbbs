mcQuery
少写代码 — 多做件事
麦块开源插件API


mcQuery是一个快速，小巧，功能丰富的Minecraft插件程式库。通过使用多种易於使用的API，可以更简单操作玩家丶实体丶物品与物品栏丶路径丶世界丶事件处理丶移动动画。其主要结构参考JavaScript的jQuery程式库。


如何简单？

  • 取得物件并进行操作

    取得名叫Jerrylum的玩家，并设置其生命值为满。
    1. $(“#jerrylum”).set(“hp:100%”);
    复制代码

  • 简单增加过滤条件

    所有身在spawn世界中的玩家，设置其生命值为满。
    1. $(“.player world: spawn”).set(“hp:100%”);
    复制代码

  • 制作  — 一切从简

    所有血量低於10并身在spawn世界中的玩家，给予金苹果两个
    1. $ item = $(".ItemStack","type:GOLDEN_APPLE; name: 补给包");
    2. $ player = $(".player world: spawn; hp: <10");
    3. player.send("给予低血量补给包").addItem(item);
    复制代码

  • 监听事件一目了言

    所有玩家在登入时自动传送到出生大堂
    1. $(“.player”).on(“Join”,new function(){
    2.         void Do(){
    3.                 player().tp(“loc:spawn 0 64 0”);
    4.         }
    5. });
    复制代码

  • 监听被筛选目标

    所有生存模式玩家在点击指令方块(id: 137)时着火
    1. $(“.player gm: 0”).on(“click”,new function(){
    2.         void Do(){
    3.                 if(block().is(“typeid: 137”) ){
    4.                         player().onfire(true);
    5.                 }
    6.         }
    7. });
    复制代码

  • JSON 封包

    取得名叫Jerrylum的玩家，并发出封包
    1. $ a = “§0黑色”;
    2. $ b = $.json("黑色","color:black");
    3. $ c = $.json("点击传送到")
    4.           .add("大堂","cmd: /spawn")
    5.           .add(“！”);
    6. $(“.jerrylum”).send(a)
    7.                  .send(b)
    8.                  .send(c);
    复制代码









    特色
  • 重新宣告物体
    令用$符号将物件重新宣告即可使用mcQuery 方法简单快捷。
    1. Player p = Bukkit.getPlayer("jerrylum");
    2. $ var = $(p);
    复制代码
  • 采用物体选择器 MCSOL
    选择器使用类似於网络的css层叠样式表，以下是其中规则：
    1. #
    2. 设置名称过滤，如果选择器没有指明种类，种类会被设为玩家
    3. 例：#jerrylum

    5.   .
    6. 设置种类过滤，如果没有设置将会回报错误
    7. 种类: entity, player, location, item, inv, world
    8. 例：.player

    10. x: [y...]
    11. 设置列阵属性
    12. 例:
    13. 一个值 -> hp: 10
    14. 多个值 -> loc: world,0,64,0
    15. 如果内容有空格必须使用引号 -> chatname: 'jerry lum'
    16. 多个列阵使用;分隔 -> hp: 10; lv: >10

    18. >
    19. 乘坐物检测，目标和乘坐物都必须通过过滤选择器
    20. 例: .jerrylum hp:10 > .player
    复制代码

  • 拼接式方法(Method)
    可以连续对目标拼接式设定，节省时间：
    1. $("#jerrylum").onfire(true).set("lv:-1").send("Level down!")
    复制代码
  • 设定和回传方法(Method)
    减去set丶get关键字，放置变数就是设置，否则就是回传：
    1. $ p = $("#jerrylum");
    2. p.name("Jerry");
    3. p.send( p.name() );//Jerry
    复制代码
