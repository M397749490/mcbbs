Armor Health——装甲即是血量

敌人不可能击穿我们的装甲

(因为我们根本没有装甲︿(￣︶￣)︿)

原文介绍：
This mod changes armor so that instead of reducing damage taken it increases the player's max health. It does this by replacing the armor's default attribute modifiers which give armor points with an attribute modifier that increases max health by a value based on how many armor points you would get from that armor piece. That value is obtained by multiplying the amount of armor a piece gives by a value set in the config.

简单的介绍：
再也没有装甲值这个东西了！

自从装甲更新后，伤害其实是有计算公式的，并不是伤害完全减免

这就是为什么即使你装甲值很高但还是会被小僵尸锤死在墙角(T＿T)

现在装甲值直接变为血量加成

虽然在背包里介绍没有变化但穿上后就会变为血量加成
