你可能需要Nucleus这个插件
http://www.mcbbs.net/thread-787354-1-1.html
具体设置方法如下：
在配置文件内可以找到下面几行，是在找不到就ctrl+F搜索spawn
  1. spawn {
  2.     # 如果设置为true，如果玩家尝试重生在自己的床上，Nucleus将会覆盖此行为，如果设置为false，Nucleus将会忽视在床上重生。
  3.     affect-bed-spawn=true
  4.     # 如果设置为true，Nucleus将会尝试强制将第一次加入服务器的玩家传送到指定地点。
  5.     # 只有在你需要使用Nucleus无视其他插件处理重生和出生规则的时候将此项启用。
  6.     force-first-spawn=false
  7.     # 这个部分将在单独世界或者全世界控制重生和/spawn的工作特性。
  8.     global-spawn {
  9.         # 如果此项和"spawn-on-login"项都被设置为true，玩家将会在登录的时候被传送到"target-spawn-world"项所对应世界的出生点。
  10.         on-login=false
  11.         # 如果设置为true，重生（例如死亡之后的重生）将会把玩家送往"target-spawn-world"项对应的世界的出生点，如果设置为false，他们将会被送往当前世界的出生点。

另外 home这里也有设置关于重生的选项
  1. home {
  2.     # 如果设置为true，如果一个玩家有超过其权限允许的家上限（"home-count"）的话，他将不能使用任何回家指令直到他删除了多余的家。
  3.     prevent-home-count-overhang=true
  4.     # 如果设置为true，玩家重生将会回到他们默认名为home的家。
  5.     respawn-at-home=false
  6.     # 如果设置为true，Nucleus将会尝试确保玩家的回家指令会传送到附近的安全区域(例如：其他玩家将传送地点的方块打碎)。
  7.     use-safe-warp=true
