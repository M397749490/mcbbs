Set Effect——效果设置

允许整合包制作者们自定义当玩家穿上整套装备所获得的效果
目前只能增加药水效果
默认情况下：
穿戴整套皮革盔甲所获得的效果：跳跃提升
穿戴整套金盔甲所获得的效果：急迫
穿戴整套锁链盔甲所获得的效果：速度
穿戴整套铁盔甲所获得的效果：防火
穿戴整套钻石盔甲所获得的效果：力量

这个模组是专门为整合包制作者们定制的，因为它是可以高度配置的。
PS：diamond=钻石套 gold=金套  chain=链锁套 iron=铁套 Leather=皮革套

配置文件：

  1. {
  2.         "type": "diamond", //装备
  3.         "effects": [{   
  4.                 "potion": "minecraft:strength",  //所获得的药水效果
  5.                 "amplifier": 0, //药水效果的强度
  6.                 "length": 10  //药水效果所持续的时间
  7.         }]
  8. }
复制代码


PS：装备不是只能添加一种效果，你可以添加多种效果。
例子:

穿皮革套，玩家获得的跳跃提升强度从1变成10
  1. {
  2.         "type": "leather",
  3.         "effects": [{
  4.                 "potion": "minecraft:jump_boost", //皮革套
  5.                 "amplifier": 0, //强度0，默认
  6.                 "length": 10 //持续时间10
  7.         }]
  8. }
复制代码


穿链锁套，玩家获得强度为1的“速度“效果和强度为10的“生命恢复“效果
  1. {
  2.         "type": "chainmail", //链锁套
  3.         "effects": [{
  4.                         "potion": "minecraft:speed", //速度
  5.                         "amplifier": 0, //强度为0，默认
  6.                         "length": 10 //持续时间为10
  7.                 },
  8.                 {
  9.                         "potion": "minecraft:regeneration", //生命恢复
  10.                         "amplifier": 10, //强度为10
  11.                         "length": 100 //持续时间100
  12.                 }
  13.         ]
  14. }
