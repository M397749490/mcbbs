2-5.寻找我们想要的信息
根据BDN的例子，可以具体看一下是怎么找的。
架设有一个Player对象，如何向这个对象对应的玩家发送一个Hello guy!的信息？
2-5-1.利用JD找到想要的信息
JD可以直接找到Player类里怎么发信息，左侧找到Player类，搜索ctrl+F，用一些关键词，如“message”等
便可找到Player类从CommandSender类里继承来sendMessage的方法
之后点击sendMessage便可指向CommandSender类中对sendMessage方法的描述
因此得知sendMessage的作用是Sends this sender a message，所以应该可以直接调用：
p.sendMessage("Hello guys!");
【真的很方便鸭！】

自我解读一下其实讲的就是以jar为格式的插件文件，本质上是个压缩文件，解压下来可以看到根目录必然有个plugin.yml的文件，该文件标明了主类，依此可以找到主类class文件
2.简单的插件
在BDN这一小节直接以实例制作的方式来了解Bukkit插件的编写，这里先引用一下原话：
新建一个java工程，导入服务端jar文件到Libraries中，并且创建tdiant.helloworld.HelloWorld类作为插件的朱磊，并且继承JavaPlugin类，在主类里覆写onEnable方法和onDisable方法
并且还贴上了代码：【因为java第一次接触的原因 我在代码内的关键字里添加了超链接 连入RUNOOB,同时附上《Java类库的概念以及import的使用方法》】

package tdiant.helloworld;  
import org.bukkit.plugin.java.JavaPlugin;  
public class HelloWorld extends JavaPlugin {
           @Override
           public void onEnable(){
                  System.out.println("Hello World");    }
           @Override         
           public void onDisable(){      
}  
}  
一点点啃完这个最简单的代码以后，大致初步了解了意思
之后需要创建plugin.yml文件，输入以下内容：
name:xxx（文件名）
main:xxx.xxx.xxx（主类名）
【api-version:1.13】如果插件基于新版API1.13及以上，需要增加该条
version:x（版本）
author:xxx（作者）
以下附上该文件的分析：
键 意义 备注
name 插件名 英文、数字、下划线
main 完整主类名 完整的主类名
version 版本 例如v0.0.1
author 作者 你叫啥！

在这个插件被加载后，会在控制台输出Hello World字符串 即为插件正常工作（撒花撒花）

因为对于JAVA并不是特别熟悉，因此在此用一个小实例来解释：
public class mcbbs {
    public static void main(String[] args) {
        System.out.println("mcbbs.net");
    }
}

保存后，通过以下命令来执行：
javac mcbbs.java
java mcbbs
即可输出内容“mcbbs.net”
javac作用是将java源文件编译为class字节码文件，因此会出现一个mcbbs.class的文件
之后java则是打开class文件，但是java之后不加.class 直接跟着类名就行了
