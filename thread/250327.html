特点：

     它可以给予服务器上的玩家，提供自动公告信息，是服务器必备的插件
     它比其他自动公告插件设置的更容易一些，更丰富一些.
命令：（也可以一键后台设置）

/ram start - 启动消息
/ram stop - 停止消息
/ram reload - 重新载入这个插件
/ram msg - 帮助说明
/ram msg show - 显示所有的消息
/ram msg add [msg] - 增加一条消息
/ram msg del <msgID> - 删除一条消息
/ram msg edit <msgID> [msg] - 编辑一条消息
/ram prefix - 帮助说明
/ram prefix show - 显示前缀
/ram prefix set [prefix] - 设置消息的前缀
/ram suffix - 帮助说明
/ram suffix show - 显示消息的后缀
/ram suffix set [suffix] - 设置后缀
/ram interval - 帮助说明
/ram interval show - 显示每个消息的间隔
/ram interval set <interval> - 设置每个消息的间隔
/ram starttime - 帮助说明
/ram starttime show - 显示消息开始的时间
/ram starttime set <starttime> - 设置开始的时间
/ram startuptime - 帮助说明
/ram startuptime show - 显示启动时间
/ram startuptime set <startuptime> - 设置启动时间
/ram ran - 帮助说明
/ram ran show - 显示设置的随机消息
/ram ran set <bool> - 设置随机消息
/ram info - 显示此插件的相关信息
/ram version - 显示插件的版本
/ram help - 显示所有帮助

设置：

1.下载插件，把插件放入 plugins中，然后运行服务端你懂的，运行完毕后再关闭，会生成一个RichAutoMessage文件夹 打开
2.打开messages 删掉里面的所有文字，然后一行一个消息， 打上你想设置的消息
3.打开 config 开始设置
normal:
  prefix: '&c[公告]'    前缀
  suffix: ''                 后缀
  interval: 20            每个消息的间隔（S）
  random: false         是否按照消息的设置顺序，随机发送消息
pro:
  startuptime: 20      这个是服务器开启后，过多长时间开始发送消息
  starttime: 2            多长时间启动此插件，建议不要修改
这个插件比Automessage插件感觉方便一点，本来论坛上也有，可是没更新了，给需要的朋友吧~
