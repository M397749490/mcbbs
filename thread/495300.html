插件介绍

是不是觉得背包太小了？

但是拥有了这款插件，永远不是梦！



合成方法

也可以输入/backpark打开
合成好背包只要点击Shift+鼠标右键即可打开背包
温馨的作者还给玩家留了升级功能（花费的金钱和升级上下限可配置！）
只要花上适量的钱即可升级
注意了！如果你站在那里不动，发现别人悄悄靠近你按右键，
就说明他正在访问你的背包（可禁止）

权限
permissions:
  backpacks.cancraft:
    description: Allows player to craft a Backpack
    default: true

  backpacks.commands:
    description: Allows player to use /backpack commands
    default: op

配置
min-level: 1
max-level: 6
allow-stealing: true
backpack-recipe:
  shapeless: false
  '1': string
  '2': string
  '3': string
  '4': string
  '5': leather_chestplate
  '6': string
  '7': string
  '8': string
  '9': strin
