DEV版本 ← 最新、但非推荐版本


插件特性
简单易用，支持侧推活塞，支持权限系统，弹飞方块、各种实体（比如玩家、怪物、物品等等）



计划更新特性（目前还没）
使用弹力活塞时避免掉落伤害

PS:这个计划早在1.3x版本就有了，作者到现在都没有把这坑填上OTZ....

权限：
  1. pistonjump.jump
  2. 允许弹飞站在活塞上的玩家 (默认: op)
  3. pistonjump.reload
  4. 允许使用指令/pistonjump reload 重载配置文件  (默认: op)
  5. pistonjump.placesign
  6. 允许放置 PistonJump 木牌改变弹射威力 (默认: op)
复制代码

指令：

/pistonjump reload 重载配置文件


如何改变弹射威力？

  1. 在活塞下放置木牌，格式如下 (需要有 "pistonjump.placesign" 权限)

  3. 行1: [PistonJump]  (不区分大小写)

  5. 行2: 0.0 - 8.0  (这里填你想要的威力值)

  7. 提示: 如果设置 0.0, 会没有弹射效果!
复制代码

演示视频

配置文件
  1. #==================#
  2. #   Basic Config   #
  3. #==================#
  4. Player:
  5. # 忽略权限 ( true为是，false为否)
  6.   IgnorePermission: false
  7. #启用侧推活塞
  8.   EnableSidewaysPiston: true
  9. # 如果设置为false, 活塞下木牌上的值会被忽略
  10. # (最大值为 8.0)
  11.   CheckSign: true
  12. # 牧人弹射玩家威力. 如果设置为0, 那么就需要用木牌来设定弹射威力
  13.   DefaultPower: 3.0

  15. Block: ——方块
  16.   Enable: true ——是否启用
  17.   EnableSidewaysPiston: true ——侧推是否启用
  18.   CheckSign: true ——是否检测木牌
  19.   DefaultPower: 0.0 ——默认弹射威力
