已经将汉化导致的不能镶嵌问题修复

本插件对生物掉落机制重新设计，并将其修改成近似暗黑破坏神中的风格。


Github 源码 |Jenkins 开发版
（均为英文）


特性
  • 创建出像非常流行的暗黑破坏神中那样的工具，并且带有前缀、后缀还有颜色；
  • 可以让生物随机掉落附魔的、带有属性的甚至是自定义的物品；
  • 一切都是以可定义的几率进行随机计算而产生的
  • 可以由自己添加个性化的前缀和后缀；（非常有趣的特性！）
  • 可以添加药水效果至lore.txt（即为武器属性）；
  • 易于使用：将本插件拖入plugins文件件内然后重新启动或者重新开始你的服务器即可；
  • 创建自定义物品并可以定义掉落几率（custom.yml中已经附带了汉化组神器以及另一个神秘神器，请下载查看详情）；
  • 将宝石和可镶嵌的装备放入火炉内可以完成镶嵌工作；
  • 使用鉴定卷轴来鉴定未鉴定的物品；
  • 自动升级至最新版（会将部分翻译文本覆盖回英文版，可关闭）
  • 随机生成一些藏有魔法物品的废墟

权限和命令
由于插件本身非常简单，所以只有一条指令，请不要怀疑作者忘了添加
/diablodrops [种类]：将一个此插件生成的掉落物送给输入命令者，权限为：diablodrops.dd种类的详解：
空：随机生成物品
tome：鉴定卷轴
socket：宝石
custom：自定义的物品
新增的指令
modify lore：修改物品描述
modify name：修改物品名称
enchant add：增加附魔效果
enchant remove：移除附魔效果
reload：重新载入（译者注：终于加了这条指令呃~）
repair：修理手中的物品

信息
custom.yml文件的编写
首先你需要以能够保留文本格式的工具打开，这里推荐使用Notepad++工具，虽然曾经受到过争议但是其易用性还是非常值得推荐的。
第一行写上你的装备的名字。
Material那里是实际装备，可以直接写物品的英文名也可以写物品ID，请参考这里：点我参考
Color填写的是颜色，必须是下列的颜色中的一个（请注意下划线）：Black,Dark_Blue,Dark_Green,Dark_Aqua,Dark_Red,Dark_Purple,Gold,Gray
由于比较简单我就不翻译颜色的意思了，小学僧也能懂的吧~
Enchantments写上附魔特性，必须是英文，请使用MineCraft自带的英文进行参考
示例：

  1. 白宝石之剑:
  2.   Material: Diamond_Sword
  3.   Color: White
  4.   Enchantments:
  5.     DAMAGE_ALL: 1
  6.     DAMAGE_ARTHROPODS: 2
  7.     DAMAGE_UNDEAD: 3
