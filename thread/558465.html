Corpses2尸体插件2
这个是让玩家在地上出现尸体的插件
作者原意是给战争服用的
这个插件是可以让地上生存你的尸体
并且可以打开里面的东西
而且这是一个轻量级插件！
并且可以显示你的名字/彩色的名字！
与旧版尸体插件增加/减少/修复的东西：
1.去掉那群指令
2.关闭部分权限
3.增加更好的生成尸体的指令
4.修复点击床可以让尸体消失

指令只有一个~:
/spawncorpse [玩家id]——生成一个玩家的尸体
权限：
corpses.spawn——可以使用spawncorpse指令

配置文件[以2.0版的]


  1. corpse-time: 10 #尸体存留时间/默认以秒为单位
  2. on-death: true #死亡后产生尸体[好像是这样翻译]
  3. looting-inventory: true #尸体是否有玩家背包里的物品/也就是杀死玩家后得到的尸体可以右键打开尸体拿出物品啦~/死亡掉落战争服必备~
  4. show-tags: false #是否显示名字标签
复制代码

注意！
第三行的looting选项中，如果你设置了死亡不掉落，则可以进行无限刷物品！
如果只要尸体的可以设置成false！
如果你是战争服会死亡掉落，可以开启true，好像死亡掉落的物品会在尸体里！
请各位服主测试！
