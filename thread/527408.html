怎样禁止？

使用neverlag插件即可，里面有扫地大妈功能，也有实体清理功能，只要把实体清理这个功能关闭就行了，在config中设置
#实体清理
ClearEntity:
  #是否开启
  Enable: true
  #清理周期
  Delay: 1200
  #是否仅到达数量上限才清理
  OnlyClearWhenLimit: false
  #限制数量
  Limit: 1200
  #是否清理动物
  Animals: false
  #是否清理怪物
  Monster: true
  #是否清理鱿鱼
  Squid: true
  #是否清理村民
  Villager: false
  #清理时的提示信息
  Message: '&b&l[智能清理系统]&a&l清理了 &c&l%COUNT% &a&l个实体'
