见到别人服务器牌子上写着“[Warp]”“XXX”右键可以传送，而自己的服务器却
希望把不同的地标(warp)设置不同的权限？
只要拥有这个老牌的插件，这一切都不是梦！


首先是作者给出的简介：
Easy Warp is a way to warp (teleport) yourself and other to different places easily, for both admins and users.
?Warp yourself and others.
?Create and delete warps.
?Change different config settings (settings are explained in the config.yml for easy use)
?Allow for delays before warping to prevent 'pvplogging' or anything such as this on certain servers.
?Create and use warps signs.
?Use permissions.
翻译：
Easy Warp可以让玩家传送到地标变得更加简单。
?传送自己和别人。
?创建和删除地标。
?修改不同的配置设置（设置在config.yml里看起来使用更简单）。
?延迟传送，防止在某些PVP服务器上逃跑(这句话是我自己的理解，实在翻译不出)。
?创建和使用地标牌子(牌子传送地标)。
?使用权限。

地标牌子的制作方法：(戳这里看原版)

1.创建一个牌子；
2.第一行写上“[EASY WARP]”；
3.第二行写上你要传送的地标的名字；
4.OK！

指令以及权限！！！(终于会弄表格了！)
                    
指令 权限 介绍
/warp <地标> easywarp.command.warp
传送到某地标
  /warp <地标> [玩家] easywarp.command.warpother 传送某玩家到某地标
/setwarp <地标>easywarp.command.setwarp 设置某地标
/delwarp <地标> easywarp.command.delwarp删除某地标
/listwarpseasywarp.command.listwarps 显示地标列表
/easywarp reload easywarp.command.reload 重载插件
/easywarp import easywarp.command.import 该命令尚不明确,知道的朋友下方回复
/easywarp helpeasywarp.command.help   插件帮助
空easywarp.sign.create 创建地标传送牌子
空easywarp.sign.use 使用地标传送牌子
空 easywarp.warp.<地标>有权限传送到这个地标
空 easywarp.delay.bypass无视传送等待时间,直接传送
                                    
                                    
                                             
                                          
                          
                                             


亲测，CraftBukkit(1.8.x，1.7.x)和Cauldron(1.7.2)可以使用，其余版本未测试

配置文件
config.yml中的重要项目：
  1. per-warp-permissions: false
  2. #地标是否分权限
  3. #signs-require-permissions: false
  4. 地标传送木牌需要权限
  5. #signs-per-warp-permissions: false
  6. #地标传送木牌需要区分地标权限(彻底晕了)
  7. permissions-bypass-delay: false
  8. #使用权限无视传送延迟
  9. ops-bypass-delay: false
  10. #OP无传送延迟
  11. warp-other-bypass-delay: true
  12. #传送其他玩家无延迟
  13. signs-bypass-delay: true
  14. #地标传送木牌无延迟
  15. allow-warp-overwrite: false
  16. #允许地标改写(?)
