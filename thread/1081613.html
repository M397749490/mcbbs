插件介绍
本作是由战地(Battlefield)系列游戏为灵感而编制的射击小游戏插件，旨在将现有大型射击游戏的内容以插件的形式在服务器中呈现出来，以供与基友们共同玩♂耍。

插件仍在完善阶段,未来将加入更多的游戏模式和新的功能，以创造一个更加有竞技性的游戏环境.但同样因为仍在测试，插件可能会有些许不稳定因素在里面，作者希望每位使用本插件的服务器运营者可以多去原贴以及Discord反馈bug.

本插件适合小游戏子服，不适合加入其它游戏元素

插件元素



  • 竞技场的数量由你决定！你可以创建任意数量的竞技场，让每一场游戏的竞技场都不相同。
  • 全自动的游戏模式！游戏配置完成之后完全实现全自动运行，无须人工干预.且大多数计分板和文本等都完全可配置.
  • 超多种类的武器！在这个插件中枪械种类很多，从突击步枪到泵动式霰弹枪应有尽有.你甚至还可以使用匕首、搏斗、手雷.
  • 玩家自定义偏好武器！玩家可以根据自己的喜爱来对武器进行安装配件.
  • 经验系统！玩家通过进行游戏即可获得经验，经验可以用来解锁新的武器和为他们的武器定制配件.
  • 多种游戏模式！插件目前有死斗(个人竞技)，团队竞技两种游戏模式，未来将会更新更佳有趣多彩的游戏模式.

可配置的武器！目前插件里已经有四十多种预先配置好的武器，所有武器都可以编辑，你也可以容易地添加属于自己服务器的武器.

                                 命令与权限        
玩家指令(Player commands):

/bg help: 查看玩家可以使用的命令.

/bg join [id]:
- id: 游戏的ID
玩家可以用这个命令去加入一场正在大厅等待状态中的游戏

/bg leave:
当玩家在游戏中时,可以用这个指令离开游戏.

/loadout:
打开武器配件配置,需要注意的是:这个功能在玩家四级前是不开放的.

/loadout rename [loadoutid] [name]:
- loadoutid: 需要重命名的武器配件配置
- name: 新的名字
对武器配件配置进行重命名

管理员指令（Admin commands）:

(权限节点: battlegrounds.creategame)
/bg creategame [id]:
- id: 新游戏的ID
创建一个新游戏，在你配置完成后玩家们就可以在这里面快乐玩耍啦~

(权限节点: battlegrounds.reload)
/bg reload:
重载插件

(权限节点: battlegrounds.removegame)
/bg removegame [id]:
- id: 需要移除的游戏ID
移除一个存在的游戏

(权限节点: battlegrounds.setgamesign)
/bg setgamesign [id]:
- id: 游戏ID
信息木牌，玩家将会在这个木牌上看到这场（ID）的游戏的进行状态、人数、地图名字，玩家可以和木牌互动来加入游戏.

(权限节点: battlegrounds.setlobby)
/bg setlobby [id]:
- id: 游戏ID
创建一个游戏大厅，玩家们可以在这里面等待游戏.

(权限节点: battlegrounds.setmainlobby)
/bg setmainlobby:
创建一个主大厅，玩家游戏结束后将会传送到这里.

地图命令（Arena commands）:

(权限节点: battlegrounds.createarena)
/bg createarena [id] [arena]:
- id: 游戏ID
- arena: 地图ID
需要管理者通过创建创世神选区的方法来创建一个游戏区域，当玩家在游戏里跑图跑出这个范围时将会被送回游戏地图内，当这个命令被成功运行后，一个全新的地图将会加入插件的地图池中（即可以让玩家游玩.）

(权限节点: battlegrounds.removearena)
/bg removearena [id] [arena]:
- id: 游戏ID
- name: 需要移除的地图名字
移除一张已经启用/未启用的地图

(权限节点: battlegrounds.addspawn)
/bg addspawn [id] [arena] [teamid]:
- id: 游戏ID
- arena: 地图名字
- teamid: 将在这张地图里对决的队伍ID，只作用于团队竞技模式中.(你可以理解为团队标识,譬如CS中的警匪)
当游戏开始时，一个队伍将会被传送至你设定的这个出生点.

(权限节点: battlegrounds.removespawn)
/bg removespawn [id] [arena] [index]:
- id: 游戏名
- arena: 地图名
- index: 上一个指令的Teamid
移除一个出生点.

配置文件
  1. # 不要修改
  2. version: 2.0.0

  4. # 插件语言
  5. locale: en

  7. # 在游戏中可以使用的命令
  8. # 不在列表中的命令在游戏中用不了
  9. # 在下列中添加： '*' (包含引号) 玩家将可以使用任何指令
  10. game-allowed-commands:
  11. - battlegrouds
  12. - bg
  13. - leave

  15. # 竞技场不受建筑和破坏的影响
  16. game-arena-protection: false

  18. # 将局内聊天传到后台
  19. game-broadcast-chat: false

  21. # 玩家加入/离开游戏的模式
  22. game-default-join-gamemode: SURVIVAL
  23. game-default-leave-gamemode: SURVIVAL

  25. # 当下列实体受到伤害时使用溅血效果
  26. game-display-blood-effect:
  27.   hellhound: true
  28.   player: false
  29.   zombie: true

  31. # 游戏中枪支的一般精度
  32. # 调大数值将会增大扩散，同理调低数值将会减小扩散
  33. game-firearm-accuracy: 10.0

  35. # 总体火器伤害修正
  36. # 高伤害改为低数值，低伤害改为高数值
  37. game-firearm-damage-modifier: 1

  39. # 玩家可以加入游戏的游戏阶段
  40. game-joinable-states:
  41. - Waiting

  43. # 移动健康栏配置
  44. game-mob-health-bar:
  45.   # 健康栏以什么符号为结尾
  46.   end-symbol: "&8]"
  47.   # 玩家当前健康状况分隔符
  48.   health-symbol: "|"
  49.   # 显示在生命栏的红心数量
  50.   length: 20
  51.   # 健康栏以什么为开始
  52.   start-symbol: "&8["

  54. # 有些子弹能穿透某些材料，将这些材料写在下面
  55. game-pierceable-materials:
  56. - AIR
  57. - BARRIER
  58. - CARPET
  59. - CROPS
  60. - FENCE
  61. - IRON_FENCE
  62. - LADDER
  63. - LEAVES
  64. - LONG_GRASS
  65. - REDSTONE_WIRE
  66. - SIGN_POST
  67. - STAINED_GLASS_PANE
  68. - THIN_GLASS
  69. - WALL_SIGN

  71. # 计分板配置
  72. game-scoreboard:
  73.   # 是否开启计分板
  74.   enabled: true
  75.   # 计分板的内容
  76.   # 用""空行
  77.   lobby:
  78.     layout:
  79.       line0: "&6Countdown: &f%bg_countdown%s"
  80.       line1: " "
  81.       line2: "&6Players: &f%bg_players%"
  82.       line3: "  "
  83.       line4: "&6Gamemode: &f%bg_gamemode%"
  84.       line5: "&6Arena: &f%bg_arena%"
  85.       line6: "&8%bg_date%"
  86.       title: "&6&lBattlegrounds"
  87.     worlds: "*"

  89. # 用来加入游戏的木牌所显示的文本
  90. game-sign-layout:
  91.   line-0: "%bg_state%"
  92.   line-1: "&l%bg_gamemode%"
  93.   line-2: "%bg_arena%"
  94.   line-3: "&8&l%bg_players%/%bg_maxplayers%"

  96. # 用来加入游戏的木牌所显示的游戏状态
  97. game-sign-state:
  98.   disabled: "&8&l[ DISABLED ]"
  99.   ingame: "&4&l[ IN GAME ]"
  100.   resetting: "&9&l[ RESETTING ]"
  101.   starting: "&6&l[ STARTING ]"
  102.   waiting: "&2&l[ WAITING ]"

  104. # 玩家获得自定义武器的最小等级
  105. loadout-creation-level: 4
