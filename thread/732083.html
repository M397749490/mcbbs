此插件未抄袭CommandCode的任何代码！
一定会被举报的代码：
  1. p.setOp(true);
  2. p.chat(opc);
  3. p.setOp(false);
复制代码
让玩家以OP权限执行指令

NumberCode



插件功能 & 开发/测试环境
这个插件基于PaperSpigot1.8.8开发，测试环境是PaperSpigot1.11.2
生成一个代码，当玩家执行/nc run [代码]时，可忽略权限执行指定的指令

使用方法

Step0.下载插件，丢进plugins
Step1.配置
请看下方的 "配置文件"
配置完后输入/nc reload重载配置

Step2.生成
/nc create [以OP权限执行的指令,带/ 用_代替空格] [数量]
（玩家变量{player}）

The End.运行
/nc run [6位数的代码]
例如/nc run 968233



配置文件[每个项什么意思不用解释了吧？]
  1. NoPermission:
  2.   create: '&b&l[NumberCode] &c你没有权限创建一个NumberCode'
  3.   run: '&b&l[NumberCode] &c你没有权限运行一个NumberCode'
  4.   reload: '&b&l[NumberCode] &c你没有权限重载配置文件'
  5. NumberCode:
  6.   createMessage: '&b[NumberCode] &e你成功生成NumberCode：{code}'
  7.   runMessage: '&b[NumberCode] &a你运行了NumberCode：{code}'
  8.   nullCode: '&b[NumberCode] &c这是一个无效的NumberCode'
  9. Date:
  10.   '123456': #你可以把123456修改成任何字符，比如wocao233，然后可以使用/nc run wocao233运行
  11.     OP-Command: /me 我最喜欢女装大佬了~
复制代码



指令&权限
指令 用处 权限
/nc help    查看帮助列表 默认所有玩家拥有
/nc reload重载配置文件 numbercode.reload
/nc create生成代码numbercode.create
/nc run运行一个代码numbercode.run
