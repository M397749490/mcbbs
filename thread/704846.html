-相关指令-
/jrmctp [数量] [玩家]  增加训练点
/jrmca [set or add] [属性] [数量 or Max] [玩家]
属性可以是力量、敏捷、活力
/jrmca Set All Max可以设置属性全满
/jrmca Set All Reset重置属性
