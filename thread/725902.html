插件介绍
本插件可以给你的服务器添加各种自定义的神奇效果的物品
其机制与RPGItems类似 你可以在配置文件里编辑各个物品
然后使用指令来获得物品或者让玩家获得物品

你可以用这个插件做出什么样的物品

自定义名称 lore 附魔 药水效果 NBT标签的物品


使用了以后能加减血量 加饥饿 加经验 加药水buff 加Vault金钱的物品


使用了以后产生自定义粒子效果 音效 烟花效果 甚至产生雷击的物品


使用了以后出现聊天消息 Title消息 Actionbar消息的物品


使用了一个物品，能获得其它几个物品的物品
可以用这个机制做一个“礼包”


使用后能产生一次爆炸的物品
可设置爆炸的产生来源 苦力怕/TNT/火球

爆炸来源“火球”其实就跟发射火球没有区别

能让使用者传送到箭落地/喷溅药水落地位置的物品


使用后能进行GUI动画抽奖的物品

该插件自带了一个动画抽奖 [动图来自外网 图挂速告知]




使用后能生成怪物的物品
可自由设置怪物的属性 被动技能 怪物buff 盔甲 甚至杀死怪物后生成的奖励
还能设置怪物骑在其它实体上


你还可以给物品添加自定义合成配方



怎么个使用法？
你可以设置：

- 当玩家手持物品点击时触发效果
- 当玩家吃（食物）喝（药水）时触发效果
- 当玩家投掷出喷溅药水时触发效果
- 当玩家投掷出滞留药水时触发效果
- 当物品被发射器发射出时触发效果
- 当玩家射出（箭）时触发效果
- 当玩家按Q扔出物品时触发效果
- 当玩家与某方块交互时触发
- 当玩家踩上某方块时触发

同样，也可以给物品使用增加被动条件

- 只有在某世界才能使用
- 只有拥有某权限才能使用
- 使用该物品必须冷却X秒
- 玩家必须拥有多少等级才能使用
- 玩家必须用怎样的姿势与方块交互才能使用
- 玩家必须在某个WorldGuard区域内才能使用

使用方法
本插件编辑物品完全通过配置完成
请在配置文件的item文件夹中找到example.yml并编辑物品
编辑完成请务必使用/item reload指令重载插件

<when>
—— 触发效果的方式（主动条件） ——

如果此项缺省代表所有主动触发条件均可触发
更多教学请参配置Tutorials/Conditions.txt

  1.   when:
  2.     ########## 主动条件 ##########
  3.     # 当玩家手持物品点击时触发
  4.     - interact
  5.     # 当玩家吃（食物）喝（药水）时触发
  6.     - consume
  7.     # 当玩家投掷出喷溅药水或者扔中玩家时触发
  8.     - splash
  9.     # 当玩家投掷出滞留药水或者滞留效果对玩家生效时触发
  10.     - lingering
  11.     # 当该物品被发射器发射出时触发 物品将会消失 并产生其效果
  12.     - dispense
  13.     # 当玩家射出（箭）并命中时触发
  14.     - arrow
  15.     # 当玩家按Q扔出物品落地时触发
  16.     - drop
  17.     # 当玩家与方块交互时触发
  18.     - blockinteract
  19.     # 当玩家踩上某方块时触发
  20.     - blockstep

指令&权限

  • /item reload - 重载插件 (合成配方无法通过此指令重载 请重启服务器)
  • /item list - 查看RPG物品列表
  • /item get <物品名> [数量] - 获得一个物品 注意大小写
  • /item give <玩家> <物品名> [数量] - 给玩家一个物品 注意大小写
  • /item giveall <物品名> [数量] - 给所有在线玩家一个物品
  • /item remove <玩家> <物品名> [数量] - 从玩家背包中移除一个物品
  • /item shop - 打开物品GUI商店 - 需要权限 item.command.shop
