介绍 · Introduction
GameAPI可以让插件开发者轻松地创建小游戏. 这款插件提供了插件交互和很多事件.

文档和源码请查看:
https://github.com/kangarko/GameAPI

该插件为CoreArena的前置插件
背景
不同的小游戏插件无法关联，如果你开发过小游戏的话你就会知道这点, 你必须制作大量的classes - 如竞技场、竞技场管理器、计时器等东西. 这个插件库可提供更简单的方法 - 或是指引你如何制作.


前置 · Requirement
  • Java 8 +
  • Spigot 1.7.10 +


提醒
请勿将该API置入你的插件内 - 它会破坏插件.
