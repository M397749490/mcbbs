RT,具体情况是这样的：
      服务器拥有3个世界-ZC-XYX-SC
     如何用GroupManager权限组让玩家在这三个世界里拥有不同的权限
作者: xRPQx    时间: 2016-7-18 13:19
打开GroupManager
打开config
添加你要弄的世界,如下

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          plotworld:
          - users
          all_unnamed_worlds:
          - users
          - groups
          world1:
          - users
          world2:
          - users
          worldX:
          - users
(红色的就是要添加的,world1/2/X可以变换成你想要的世界名，注意下面只要- user~~)
然后游戏里输入/manload
你会发现,worlds里面多了X个文件夹
复制一份原来就有的世界文件夹里的group拷贝过去
进入修改即可（添加权限、删除权限等等）


按你的要求，直接多次使用上述步骤，就可完成3个世界分别权限~
