MCNature —— 一款轻量化的游戏自然管理插件








前言:

本插件目前正在中国版我的世界某服务器上稳定运行，长达1年半的时间，所以您可以放心使用啦!


特色介绍：

  • 本插件允许您创建一个虚拟的游戏日期，如初始值为2000年01月01日，度过一个游戏日（20分钟）后，数据库将会被更新，日游戏期将变为2000年01月02日。
  • 插件设计了多个季节，其中，每个不同的月份都对应不同的季节名称，如2月为早春，3月为仲春、4月为晚春、5月为初夏、6月为仲夏...详情请看下面的配置文件选项。
  • 插件设计了自定义天气生成，各天气可根据不同月份而调整生成的概率与持续时间，高度自定义。
  • 插件支持PlaceholderAPI，您可以将游戏天气、游戏季节、游戏日期显示在您的计分板上！
  • 特殊的天气效果，如寒潮、旱灾、酸雨，其中寒潮与旱灾都会影响作物的生长（原理是直接设置当前世界的randomTickSpeed）。


注意事项：

  • 本插件为了实现多个服务端同步数据，只支持MySQL存储，无法保存在Configuration Yaml文件中。
  • 如果您使用单个服务端，请将配置文件中的MainControlServer选项改为true；如果您使用多个服务端，则只需将其中一个服务端的MainControlServer选项改为true，其他都需要改为false。

如何使用：
  • 插件本体放入 服务端目录/plugins 文件夹内
  • 重启您的服务器，等待服务端生成配置文件
  • 在配置文件内配置数据库或其他需求
对应变量：
  • %MCNature_getGameDate% —— 获取当前游戏日期
  • %MCNature_getGameYear% —— 获取当前游戏年
  • %MCNature_getGameMonth% —— 获取当前游戏月
  • %MCNature_getGameDay% —— 获取当前游戏日
  • %MCNature_getSeason% —— 获取季节名称
  • %MCNature_getWeather% —— 获取天气名称

public class MCNatureAPI {

    /**
     * @return 返回游戏的季节
*/
public static Season getGameSeason(){
        int month=PluginMain.getInstance().getDateManager().getGameTimeMonth();
        switch (month){
            case 1:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("WINTER_STAGE_2");
            case 2:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("WINTER_STAGE_3");
            case 3:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("SPRING_STAGE_1");
            case 4:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("SPRING_STAGE_2");
            case 5:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("SPRING_STAGE_3");
            case 6:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("SUMMER_STAGE_1");
            case 7:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("SUMMER_STAGE_2");
            case 8:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("SUMMER_STAGE_3");
            case 9:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("AUTUMN_STAGE_1");
            case 10:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("AUTUMN_STAGE_2");
            case 11:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("AUTUMN_STAGE_3");
            case 12:
                return PluginMain.getInstance().getSeasonManager().getSeasonByName("WINTER_STAGE_1");
            default:
                return null;
        }
    }

    /**
