卫星地图

PS2:渣配慎入，很多面板服比如酷牛明文写着不能用...


此贴有人搬运过，但是已经停更，所以我再次进行更新搬运
原帖http://www.mcbbs.net/thread-346319-1-1.html


简介
像现实中卫星地图一样显示你的服务器地图！
——————————————————————

插件特性

1.自定义高度大小

2.地图同步更新（关闭游览器时）
3.可以在地图上看到玩家的头像
4.可以看到玩家们的实时聊天

(左下角聊天框与玩家头上的聊天气泡)
5.可以看到玩家所在的位置
6.可以看到目前世界的游戏时间
7.可以看到当前世界的天气情况
8.可使用其他插件搭配dynmap使用

(需要其他插件支持)
9.可自行配置整体高度

使用方法
如果你使用spigot/bukkit开服，那么可以在http://你的服务器IP:8123/查看
如果你使用spigot/bukkit在你自己电脑上开服，则在http://localhost:8123/查看
注意，一开始加载时地图为黑色，这是很正常的情况，请耐心等待地图慢慢加载
(貌似只有玩家走过的地方才会渲染？)

命令
显示和隐藏玩家
——————————
/dynmap hide : 从地图上隐藏所有玩家
/dynmap hide 玩家名字 : 从地图上隐藏某玩家。
/dynmap show : 让所有玩家重新显示在地图上。
/dynmap show 玩家名字 :  让某玩家重新显示在地图上

地图渲染
——————————
/dynmap render : 渲染你当前站的地方
/dynmap fullrender : 从你的位置开始渲染全图(或从那个世界的中心,如果从服务器控制台发出)。
/dynmap fullrender world : 全图渲染并从world这个世界的中心开始。
/dynmap fullrender world:surface : 全图渲染世界world地图名为surface的中心。
/dynmap radiusrender radius : 渲染以你为位置半径radius的区域。
/dynmap radiusrender radius mapname : 渲染在世界world地图名为mapname半径radius
/dynmap radiusrender world x z radius : 渲染在世界world以x,z为中心点半径为radius
/dynmap updaterender : 更新渲染所有地图
/dynmap updaterender mapname : 更新渲染地图名为mapname以x,z为中心点
/dynmap updaterender world x z : 更新渲染在世界world所有地图为mapname以x,z为中心点
/dynmap updaterender world x z mapname : 更新渲染在世界world地图名为mapname以x,z为中心点
/dynmap cancelrender world : 取消任何在世界world中正在进行中半径渲染/全图渲染
/dynmap purgequeue : 清除区域更新队列
/dynmap purgeworld world : 清除世界world中所有的地图文件
/dynmap purgemap world map : 清除世界world中的所有地图
/dynmap pause all : 暂停所有地图渲染(更新和完整/半径呈现)
/dynmap pause none : 恢复所有地图渲染

数据收集
——————————
/dynmap stats:显示所有世界的地图的渲染数据。
/dynmap stats world:显示世界world的地图的渲染数据。
/dynmap triggerstats:显示所有被触发的渲染。
/dynmap resetstats:重置所有世界的地图的渲染数据。
/dynmap resetstats world:重置世界world的地图的渲染数据

标记
——————————
/dmarker add <label> icon:<icon> set:<set-id> : 在当前地点添加新标记，名称为label，图标文件名为icon，标记类型为set-id（可自定义）
/dmarker add id:<id> <label> icon:<icon> set:<set-id> : 在当前地点添加新标记，ID为id，名称为label，图标文件名为icon，标记类型为set-id（可自定义）
/dmarker add id:<id> <label> icon:<icon> set:<set-id> x:<x-coord> y:<y-coord> z:<z-coord> world:<Worldname> : 在坐标(x-coord,y-coord,z-coord)添加新标记，ID为id，名称为label，图标文件名为icon，标记类型为set-id（可自定义）
/dmarker movehere <label>:更新第一的位置标记匹配给定的标签来匹配当前玩家的位置
/dmarker movehere id:<id>:更新标记的位置与给定ID匹配当前玩家的位
/dmarker update <label> icon:<newicon> newlabel:<newlabel> : 将名为label的标记的icon更新为newicon，名字更新为newlabel
/dmarker update id:<id> icon:<newicon> newlabel:<newlabel> : 将ID为id的标记的icon更新为newicon，名字更新为newlabel
/dmarker delete <label> : 删除名为label的标记，以第一个找到的为准
/dmarker delete id:<id> : 删除ID为id的标记
/dmarker list : 列出所有标记
/dmarker list set:<set-id> : 列出类型为set-id的所有标记
/dmarker icons : 列出所有可用的图标
/dmarker addset <label> hide:<hide-by-def> prio:<priority> minzoom:<minzoom> : 在名为label的标记中添加新的标签类型
/dmarker addset id:<id> <label> hide:<hide-by-def> prio:<priority> minzoom:<minzoom> : 在名为label且ID为id的标记中添加新的标签类型
/dmarker updateset <label> newlabel:<new-label> hide:<hide-by-def> prio:<priority> minzoom:<minzoom> : 更新名为label的标记中的所有标签类型
/dmarker updateset id:<id> newlabel:<new-label> hide:<hide-by-def> prio:<priority> minzoom:<minzoom> : 更新名为label中ID为id的标记的标签类型
/dmarker deleteset <label> : 删除名为label的标记的标签类型
/dmarker deleteset id:<id> : 删除ID为id的标记的标签类型
/dmarker listsets : 列出所有标签类型
/dmarker addicon id:<id> <label> file:"filename" : 安装新图标在名为label的标签ID为id（从服务器安装，filename为路径）.
/dmarker updateicon id:<id> newlabel:<label> file:"filename" : 更新图标.
/dmarker deleteicon id:<id> : 删除标签ID为id的图标
/dmarker addcorner : 在当前地址添加corner
/dmarker addcorner <x> <z> <world> : 在名为world的世界里，坐标为x,z的地方添加corner
/dmarker clearcorners : 清除所有列表中的corner
/dmarker addarea <label> : 根据设定的corner（一般是4个组成长方形），添加名为label的新区域
/dmarker addarea id:<id> <label> : 根据设定的corner（一般是4个组成长方形），添加ID为id的新区域
/dmarker deletearea <label> : 删除名为label的区域
/dmarker deletearea id:<id> <label> : 删除ID为id的区域
/dmarker listareas : 列出所有区域
/dmarker updatearea <label> <arg>:<value> ... : 更新名为label的区域
/dmarker updatearea id:<id> <arg>:<value> ... : 更新ID为id的区域
/dmarker addline <label> : 根据设定的corner添加名为label的线
/dmarker addline id:<id> <label> : 根据设定的corner添加ID为id的线
/dmarker deleteline <label> : 删除名为label的线
/dmarker deleteline id:<id> <label> : 删除ID为id的线
/dmarker listlines : 列出所有线
/dmarker updateline <label> <arg>:<value> ... : 更新名为label的线
/dmarker updateline id:<id> <arg>:<value> ... : 更新ID为id的线

世界地图配置命令
——————————
/dmap worldlist:列出所有世界配置(启用或禁用)
/dmap worldset worldname enabled:<true|false>:设置世界worldname启用或禁用
/dmap worldset worldname center:<x/y/z|here|default>:设置世界worldname地图中心位置为<x/y/z|here|default>
/dmap worldset worldname extrazoomout:<N>:设置额外的缩小水平为世界“worldname”
/dmap worldset worldname title:<label>:设置世界worldname标题为label
/dmap worldset worldname sendposition:<true|false> sendhealth:<true|false>:设置世界worldname是否显示位置和显示血量

/dmap worldset worldname order:<N>:设置世界worldname地图mapname的位置N
/dmap worldreset worldname:重置世界“worldname”其默认模板配置
/dmap worldreset worldname templatename:重置世界“worldname”模板templatename配置
/dmap maplist worldname:列出世界worldname所有地图

/dmap mapdelete worldname:mapname:删除世界worldname地图mapname
/dmap mapadd worldname:mapname attrib:val attrib:val:创建新地图“mapname”世界“worldname”,与给定的属性(所有“mapset”参数是可用的)
/dmap mapset worldname:mapname order:<N>:设置世界worldname地图mapname的位置N
/dmap mapset worldname:mapname prefix:<prefix>:设置世界worldname地图mapname的前缀
/dmap mapset worldname:mapname title:<label>:设置世界worldname地图mapname的title标题
/dmap mapset worldname:mapname icon:<icon-file>:设置世界worldname地图mapname的图标地址(相对于“webpath”目录)
/dmap mapset worldname:mapname mapzoomin:<N>:设置世界worldname地图mapname的放大级别
/dmap mapset worldname:mapname perspective:<perspective> shader:<shader> lighting:<lighting>:设置世界worldname地图mapname的角度,材质和照明
/dmap mapset worldname:mapname img-format:<format>:设置世界worldname地图mapname的图片格式(jpg,png jpg-q90,jpq-q95,等等)。
/dmap perspectivelist列出所有的观看点
/dmap shaderlist:列出所有光影
/dmap lightinglist:列出所有照明

杂项
——————————

/dynmap sendtoweb message ...[color=inherit !important]:发送消息到一个web ui
/dynmap ids-for-ip ip-address : 玩家id列表,从给定的IP地址登录(至少最近)
/dynmap ips-for-id player-id : IP地址列表,用于连接服务器玩家ID
/dynmap add-id-for-ip player-id ip-address : 鉴于玩家ID添加到给定的已知的ID列表前面的IP地址
/dynmap del-id-for-ip player-id ip-address : 从已知的ID列表删除给定玩家ID对于给定IP地址。
/dynmap webregister : 开始注册自己的账户登录web界面
/dynmap webregister player-id : 开始注册另一个用户的帐户登录web界面
