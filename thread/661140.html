AdminShop
AdminShop, as the title implies, is a plugin that allows server admins to create unlimited item shops for their players to use.
requires an Economy plugin to be installed, and without it will not work.
系统商店，顾名意义，他可以让OP在服务器里创建无限商店供玩家使用。
此插件需要一款经济插件，否则将无法运行


Downloads
You grab the latest build off of GitHub, here
你可以在GitHub查看最新的构建，点击此处


GitHub Repository
You can view AdminShop's GitHub Repository,here
你可以在这查看AdminShop的源码


Commands
/setshop <价格> [<buy shop>]
If you rightclick a sign after using this command,it will become an AdminShopif it was not one already. If it was, it will simply update to the item you'reholding and the parameters inputed. If you want the shop to be a sell shop, youinput true, otherwise you can disregard it - a buy shop is one where playerscan sell their items to the sign.
输入指令后右键牌子就可以变成系统商店
如果在这之前这个牌子已经是个商店了，他会自动覆盖原先的商店
如果想变成收购商店，在后面加上true即可
只需要输入/setshop <价格>  后面的不用输入，要弄收购时再加true即可


Permissions
adminshop.create - Gives player permission to create an AdminShop.
允许玩家创建系统商店
adminshop.remove - Gives player permission to break/delete an AdminShop
允许玩家删除系统商店
adminshop.modify - Gives player permission to modify an existing AdminShop.
允许玩家修改系统商店
adminshop.command.setshop - Gives player permission to use /setshop
允许玩家使用/setshop

Simply drop the downloaded JAR into your mods folder along with Sponge and an Economy plugin
and start your server!
下载JAR文件，安装经济插件，拖入mods文件夹，开启服务器！
