菜单配置




为了在/ia菜单中显示物品，你必须打开menu.yml并添加你想要的物品名称到某一分类中(以下示例是添加一个物品到hoes分类)
  • hoes:
  •   enabled: true
  •   icon: ruby_hoe
  •   name: '&3&lHoes'
  •   items:
  •     - ruby_hoe
  •     - crystal_hoe
  •     - spinel_hoe
  •     - turquoise_hoe
  •     - aqua_hoe
  •     - amethyst_hoe
  •     - my_new_custom_hoe
你会发现文件里有一个特殊的分类all，它有一个特殊的属性show_all_items，它将显示所有你创建的物品
  • all:
  •   enabled: true
  •   icon: ruby_block
  •   name: '&3&lAll'
  •   show_all_items: true

插件不工作
在向作者反馈之前:
  • 确保插件是最新版本
  • 确保不是其他插件干扰
  • 引起此问题的原因
  • 服务器版本，使用/version查看并将版本信息发送给作者
  • 插件版本
  • 你是否编辑过配置文件
  • 你是否编辑过资源包
  • 将配置文件压缩并发送给作者
  • 插件是否在控制台或聊天区显示错误信息
  • 服务器的完整日志文件
  • 服务器IP
  • 给作者OP权限，他将帮助你解决（或者给他创造模式、/pl、ItemAdder、/tp、/i等权限)

耐久
ItemAdder有一个可选的耐久度系统
你可以为一个物品设置自定义耐久度例如:
  • custom_sword:
  •    enabled: true
  •    permission: custom_sword
  •    model_id: 1
  •    vanilla_type: DIAMOND_SWORD
  •    name: '&fTest'
  •    specific_properties:
  •       attack_damage: 8
  •       attack_speed: 1.2
  •       max_custom_durability: 200
  •       custom_durability: 32
  •       disappear_when_broken: false

可以发现，这里有几个特殊属性:max_custom_durability, custom_durability 和 disappear_when_broken
你可以不必设置此属性,如果你不需要插件处理耐久度,请在config.yml中禁用custom_durability                                                            


max_custom_durability: 最大耐久                                                                                                      disappear_when_broken: 当耐久为零时物品是否消失
       custom_durability: 初始耐久



可以看到,物品上有一个耐久度显示





它和原版的一样准确



如果你启用了物品栏调试模式(F3+H),请不要与插件的混淆                                                                     




耐久可用于:                                                                                                                                    


  • 剑
  • 枪
  • 盔甲
  • 钓鱼竿
  • 工具
  • 弓
  • Shields

Craft recipe
合成该物品的配方
  1. craft_recipe:
  2.   enabled: true
  3.   amount: 2 #物品的数量
  4.   pattern:
  5.     - XXX
  6.     - XPX
  7.     - DKD
  8.   ingredients:
  9.     P: philosopher_stone
  10.     K: knife
  11.     D: diamond
  12.   return_items: #gives some items back when crafting without consuming them
  13.                 #(like water bucket in vanilla Minecraft)
  14.     play_sound: knife #合成时播放一个音效
  15.     reduce_durability: #reduces durability of an item in the crafting table
  16.                        #and doesn't consume it on crafting
  17.                        #(must be a tool or sword to lose durability)
  18.       knife: 1 #<item name or material>: <amount>
  19.     increment_durability:  #increments durability of an item in the crafting table
  20.                            #and doesn't consume it on crafting
  21.                            #(must be a tool or sword to get durability)
  22.       philosopher_stone: 1 #<item name or material>: <amount>
  23.     replace: #replaces an item in the crafting table and doesn't consume it on craft
  24.         DIAMOND: crystal #<old item name or material>: <new item name or material>

Result recipe
用任何原料合成任何物品的配方，如果你想为一个物品创建多个合成配方，这将非常有用
  1. result_recipe:
  2.   enabled: true
  3.   pattern:
  4.     - XXX
  5.     - XPX
  6.     - DKD
  7.   ingredients:
  8.     P: philosopher_stone
  9.     K: knife
  10.     D: diamond
  11.   result: # 合成出的物品
  12.       item: DIRT
  13.       amount: 1 #合成物品的数量
  14.       damage_value: 0 #耐久度 (就是物品下面的绿条条)
  15.   return_items: #合成后返回的物品
  16.                 #(比如原版中的水桶)
  17.     play_sound: knife #合成时播放的音效
  18.     reduce_durability: #reduces durability of an item in the crafting table
  19.                        #and doesn't consume it on crafting
  20.                        #(must be a tool or sword to lose durability)
  21.       knife: 1 #<item name or material>: <amount>
  22.     increment_durability:  #increments durability of an item in the crafting table
  23.                            #and doesn't consume it on crafting
  24.                            #(must be a tool or sword to get durability)
  25.       philosopher_stone: 1 #<item name or material>: <amount>
  26.     replace: #replaces an item in the crafting table and doesn't consume it on craft
  27.         DIAMOND: crystal #<old item name or material>: <new item name or material>

  29. #you can create multiple rules for result_recipe
  30. #you just have to make the rule start with "result_recipe"

  32. result_recipe_2:
  33.   #...
  34. result_recipe_3:
  35.   #...
  36. result_recipe_...:
  37.   #...

Smelting recipe
你还可以创建自定义冶炼配方，为服务器添加有趣的机制，例如：

  • cup_of_hot_water: #示例物品
  •    enabled: true
  •    permission: cup_of_hot_water
  •    model_id: 5
  •    name: '&fCup of hot water'
  •    smelting:
  •        enabled: true
  •        ingredient: cup_of_water #ingredient to be smelt/cooked
  •        amount: 1 #result amount (cup_of_hot_water)
