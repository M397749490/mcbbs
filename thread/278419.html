打个比方吧，potion引导到一个接口类了

以下都在Item类里：
覆盖requiresMultipleRenderPasses，返回true，说明要多次渲染。
覆盖getIconFromDamageForRenderPass，参数1是damage，参数2是渲染次数（表示第几回的渲染），返回相应的IIcon。
覆盖getColorFromItemStack，参数1是ItemStack，参数2是渲染次数，返回一个int表示的RGB颜色值。

比如ItemMosterPlacer的相应覆盖就是这样：



  3. @SideOnly(Side.CLIENT)
  4. public boolean requiresMultipleRenderPasses()
  5. {
  6. return true;
  7. }

  9. @SideOnly(Side.CLIENT)
  10. public IIcon getIconFromDamageForRenderPass(int par1, int par2)
  11. {
  12. return par2 > 0 ? this.theIcon : super.getIconFromDamageForRenderPass(par1, par2);
  13. }



  17. @SideOnly(Side.CLIENT)
  18. public int getColorFromItemStack(ItemStack par1ItemStack, int par2)
  19. {
  20. EntityList.EntityEggInfo entityegginfo = (EntityList.EntityEggInfo)EntityList.entityEggs.get(Integer.valueOf(par1ItemStack.getItemDamage()));
  21. return entityegginfo != null ? (par2 == 0 ? entityegginfo.primaryColor : entityegginfo.secondaryColor) : 16777215;
  22. }
