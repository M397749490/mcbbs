~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
Hello people,
this is the first part of a blog format I want to start called The Command Blog. It will be about vanilla Minecraft commands most likely using command blocks.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
First off, how to get a command block if you didn't already know: /give YOURNAME minecraft:command_block
Write this command into the chat and press Enter.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
I wanted to start this with something I found was really funny. You can give villagers a mohican (haircut) by putting an anvil on their head.
Here is the command for that:


/replaceitem entity @e[type=Villager,r=5] slot.armor.head anvil
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
So, this uses the replaceitem command. @e[] defines some parameters for the target entity. These parameters are: It works on villagers (type) in a radius of 5 blocks (r). You can raise the radius if you want by changing r=5 to for example r=20. You could also take this parameter out. It's just for making sure that only villagers you want to change will be changed. The item which gets replaced is in the helmet slot of the villager (Actually there is no item in this slot. So you replace nothing). The new item is an anvil. This anvil makes the villager looking like a punk. That's it!


You just copy and paste this into your command block (make sure there are the target villagers nearby), power it with redstone (e.g. redstone block, button, lever...) and fill your village with punks.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
I hope you enjoyed that. I want to post more of this. Also more useful stuff. ;)
Leave a diamond for me.  
Suggestions and reactions are always appreciated!  
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

我觉得这个东西真的很有趣. 你可以给村民剃个莫希干头 （注释①）(发型) 把铁毡放在他们头上.
这是命令指令


  1. <b><font color="#000000">/replaceitem entity @e[type=Villager,r=5] slot.armor.head anvil </font></b>
复制代码


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
嗯,使用replaceitem，@e[] 给目标实体定义一些参数（注释②），这些参数的意义是: 半径5个方块里的村民 (标签type)起作用，你可以把r=5改变成任何,比如r=20，你也可以不加这个参数，这只是确保只有村民会改变，物品就将会被放置在村民的头上(类似头盔设定) (其实在头盔槽并没有任何东西 所以你放了也没有(?))，那个要放置的物品就是铁毡，铁毡会让村民看起来剃了个莫希干头，That's it!


你把命令直接复制粘贴到命令方块里就可以了 (确保周围是有村民的(注释②))， 任何激活命令方块 (e.g. 红石方块，按钮，拉杆...) 然后看着你的村民变成小混混吧。
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
