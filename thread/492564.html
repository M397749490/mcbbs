插件介绍
This plugin allows one to configure commands to be executed after a certain time period. It supports repeated command, it also supports the commands to be executed at a specific time (12:00PM for instance). One can configure the console to use any command one would normally type in the console.
鸡饭+人工修正：
该插件允许一个配置命令，在一定时间段后执行。它支持重复命令，它还支持命令将在一个特定的时间执行(24小时制)，可以再任何类型的服务器执行任何命令。

特点
Allows for repeating commands.
Command for reload the config file.
Allow for specific-time commands.
Easy to configure.
Lightweight.
Optional: Delay before it starts the schedule so that all other plugins can load.
No trouble with anything permissions-wise.
Update Checker to automatic update your plugin.
鸡饭+人工修正*2：
允许重复命令
重新加载配置文件命令
允许特定时间执行命令
易于配置
轻量
可选：在它启动前的延迟，以便所有其他插件可以加载(什么鬼)
自动更新

命令
/csc help - Show a list of commands
/csc reload - reload the config file
鸡饭+人工修正*3：
/csc help 显示帮助信息
/csc reload 重载


使用权限
ConsoleScheduler.use - User with this permission has full access to the plugin commands
鸡饭+人工修正*4：
consolescheduler.use -这允许用户完全访问插件的命令

配置文件
Bukkit配置文件讲解
所有的都可以在配置文件下面来设定
定时命令的设置：
Command3:
    SpecificTime:
    Hour:
    Minute:
    Second:
    Command:
相对应如下
名字[随便写，不要重复，用英文]:
    定时执行[设置为 true]:
    小时:
    分钟:
    秒:
    执行的命令[要执行的命令，不加 / ]:
例如我要设置服务器在下午两点关闭
233:
    SpecificTime:true
    Hour: 14
    Minute: 0
    Second: 0
    Command: stop
间隔执行命令的设置：
Command3:
    After:
    Repeat:
    Command:
相对应如下
Command3[随便写，不要重复，用英文]:
    After[执行的间隔，以秒为单位]:
    Repeat[重复执行，一般设置为 true ]:
    Command[执行的命令]:
例如我要设置服务器一秒给玩家abc一个钻石块
fsrffs:
    After:1
    Repeat: true
    Command: give abc 57 1
