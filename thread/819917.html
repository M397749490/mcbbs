插件介绍
这个插件可以用粒子特效来使你的worldedit的选择可视化。
你可以自定义粒子的类型、数量或启用高级网格。
插件作者因为找不到好用的同类插件于是就自己制作这款支持低版本的创世神区域选择可视化插件。

最新版插件已从WorldEditCUI更名为WorldEditSUI
最新版已不兼容1.8

说明
  • 这款插件不支持早期的Worldedit 7.0.0快照版本 你需要下载这个版本
  • 兼容版本:
  • WorldEdit (Minecraft  1.8.x-1.14.x)
  • AsyncWorldEdit(Minecraft  1.8.x-1.12.x)
    和AsyncWorldEditPremium(Minecraft  1.8.x-1.14.x)
  • FastAsyncWorldEdit(Minecraft  1.8.x-1.13.x)

  • 默认的粒子效果是最理想的.你也可以在配置内改成你想要的粒子效果
  • 这个插件的效果并没有同名的mod那么好用。但这个插件的优点就是你不需要安装mod。
指令&权限
如果你使用的是最新版插件请将cui改成sui
  • /wecui - wecui.command  - 主指令
  • /wecui reload - wecui.command.reload - 重载插件
  • /wecui toggle - wecui.command.toggle - 开关显示
  • /wecui toggleclipboard - wecui.command.toggleclipboard - 开关显示粘贴板内容

  1. # WorldEditSUI 插件 by KennyTV

  3. # 如果启用，则粒子位置仅在每次选择时计算一次，然后进行缓存。
  4. # 从本质上讲，这完全消除了较高的CPU使用率，但是如果进行了很多选择，则会导致某些缓存。
  5. #
  6. # 如果遇到并发错误，请禁用此功能。
  7. cache-calculated-positions: true

  9. # 可以在这里找到所有粒子的列表: https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Particle.html
  10. # 请注意，高版本引入的粒子不适用于旧版本。
  11. # 显示您当前的选择。
  12. #
  13. # 如果你想使用的粒子需要额外数据（REDSTONE，FALLING_DUST，BLOCK_DUST，BLOCK_CRACK，ITEM_CRACK），
  14. # 您可以在插件的“Spigot”页面的底部阅读有关如何执行此操作的信息。
  15. particle: FLAME
  16. # 显示剪贴板（使用WorldEdit的// copy命令之后）。
  17. # 可以使用 “/wesui toggleclipboard” 命令启用。
  18. clipboard-particle: VILLAGER_HAPPY

  20. # 每格方块显示的粒子数.
  21. # 推荐数值2-4. 可以设置为1-5.
  22. particles-per-block: 3

  24. # 此数字确定每次发送粒子之间应有多少tick。（发送粒子即粒子的闪烁，下同）
  25. # 可以设置为5至200。
  26. # 供参考：20个Minecraft tick等于1秒-> 10tick等于0.5秒-> 1tick等于0.05秒。
  27. particle-send-interval: 12

  29. advanced-grid:
  30.   # 如果启用，则所选内容不仅会显示在轮廓上，
  31.   # 而且在轮廓之间有一个网格（选择越大，网格越大）。
  32.   # 大约需要2到3倍的计算量，但是看起来很棒！
  33.   enabled: false
  34.   # 每个方块应显示多少个粒子。
  35.   # 建议的数量是2到3。可以设置为2到5。
  36.   particles-per-block: 2

  38. advanced-clipboard-grid:
  39.   # 您也可以为剪贴板视图启用网格。
  40.   # 与高级网格设置相同，但适用于剪贴板。
  41.   enabled: false
  42.   particles-per-block: 2

  44. particle-expiry:
  45.   # 如果启用并且在给定的秒数内未更改选择，则将停止发送粒子
  46.   enabled: false
  47.   expires-after-seconds: 180
  48.   # 如果启用，则通知玩家粒子过期后是否消失。
  49.   expire-message: true

  51. # 如果设置为"none"，则将显示每个玩家的选择。
  52. # 否则，只有具有设定权限的玩家才能选择粒子。
  53. permission: "none"

  55. send-particles-to-all:
  56.   # 如果启用，粒子将被发送给所有玩家，而不仅仅是发送给拥有WorldEdit选择的玩家。
  57.   # 当一组玩家共同进行构建时可能会很有用。
  58.   enabled: false
  59.   # 您还可以通过权限限制那些看到粒子的用户。保留"none"可让所有玩家看到它们。
  60.   # 警告：如果您有一个（不好的）权限插件，该插件没有缓存其检查或需要一段时间进行权限检查，请将其保留为“ none”。
  61.   view-others-particles-perm: "none"
  62.   # 如果希望人们看到其他玩家选择的不同粒子，可以在此处进行设置。
  63.   others-particle: FLAME
  64.   others-clipboard-particle: VILLAGER_HAPPY

  66. # 如果设置为false，则玩家必须首先使用'/ wesui toggle'才能看到粒子。
  67. show-selection-by-default: true
  68. # 如果设置为false，则玩家必须首先使用'/ wesui toggleclipboard'才能看到粒子。
  69. show-clipboard-by-default: false

  71. # 保存“开关”（即开关状态）到文件，以便在玩家退出并重新启动服务器后保持更改。
  72. # 这也包括剪贴板切换。
  73. persistent-toggles: false

  75. # 可以将可见粒子的距离更改为从1到500（如果您出于某种原因希望看到粒子500块远）。
  76. # 这不会以任何方式影响到服务器的性能。
  77. particle-viewdistance: 99

  79. # 建议启用此功能，否则您会错过新功能和整体改进。
  80. update-checks: true
