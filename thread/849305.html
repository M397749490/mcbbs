Brotkasten

这是一款可以自定义定时聊天公告以及Boss血条公告的插件
现已支持PAPI变量

命令&权限：
重载插件配置文件
/brotkasten reload
/brot reload
权限: brotkasten.command.brotkasten (主命令), brotkasten.command.brotkasten.reload (重载命令)

设置自定义Boss公告 (非配置文件)
/bossbar set --color 颜色 --time 时间 消息
/bb set 消息
权限: brotkasten.command.bossbar (主命令), brotkasten.command.bossbar.set (发送公告命令)
参数:
  • 颜色 (可选): White, Green, Blue, Red, Yellow, Pink, Purple 选其中一个
  • 时间 (可选): 倒计时秒数或者 ‘infinite’（不限时间）
  • 消息: 显示的消息, 支持 & 颜色格式

恢复Boss血条公告的自动公告
/bossbar skip
/bossbar next
/bossbar continue
权限: brotkasten.command.bossbar (主命令), brotkasten.command.bossbar.skip (恢复命令)


配置文件：
  1. # 这里可更改血条公告
  2. BossBar {
  3.     # Messages, 公告消息
  4.     # 消息格式: {Flags}消息
  5.     # Flags:
  6.     #  <from>% - 血条公告的起始位置
  7.     #  <to>% - 血条公告的结束位置
  8.     #  <time>sec 或 <time>min - 显示持续时间
  9.     #  <color> - 血条公告的颜色, white, green, red, blue, yellow, pink 或 purple
  10.     #  <divs>ticks - the amount of subdivisions the bar shall have 0, 6, 10, 12 or 20
  11.     # Message:
  12.     #  可以使用 & 颜色格式
  13.     Messages=[
  14.         "{100%, 0%, 10sec, green}&a感谢您使用 &rBrotkasten"
  15.     ]
  16.     # 两条消息的间隔时间, if a boss bar finishes earlier the next one won't
  17.     # play until this time has passed. If the bar is displayed for more than
  18.     # the specified amount of seconds it will not be interrupted!
  19.     MinDelay=30
  20. }
  21. # 这里可更改聊天消息公告
  22. Chat {
  23.     # 两条消息的间隔时间
  24.     Delay=30
  25.     # Messages, 每行消息为一条公告
  26.     # 你可以创建类似 Markdown-Like 的链接在 (Text)[Action]
  27.     # 可以使用的行为:
  28.     #  - 执行命令
  29.     #  - 外部浏览器打开链接
  30.     Messages=[
  31.         "&9非常酷的Sponge公告插件 [Sponge](https://spongepowered.org)",
  32.         "&e迷路了? 点击 [这里](/spawn) &e返回到刚才的位置"
  33.     ]
  34. }
