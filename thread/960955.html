注意:本插件是为插件开发者制作的
在服务器里面仅作为前置插件使用并没有其他功能

对于开发者来说 Bukkit中许多的命令都比较复杂 比如你要执行一个简单的命令需要很多代码
而CXPreposition则解决了部分BukkitAPI内代码复杂的地方
使用例子:
这是BukkitAPI打开一个Yml文件的流程:
1.先找到文件夹 若文件夹不存在 则创建
2.再找到文件 若文件不存在 则创建
共10行代码        
  1. File Path;
  2.                 Path=new File(CPath+"\\plugins\\Menu\\Menus.yml");
  3.                 FolderPath=CPath+"\\plugins\\Menu";
  4.                 if(!Path.exists()) {
  5.                         Path=new File(CPath+"\\plugins\\Menu");
  6.                         Path.mkdirs();
  7.                         Path=new File(CPath+"\\plugins\\Menu\\Menus.yml");
  8.                         Path.createNewFile();
  9.                         MenuConfig = YamlConfiguration.loadConfiguration(Path);
  10.                 }
复制代码
再看看用CXPreposition中的CXYamlConfiguration类吧
  1. <div><font size="2">CXYamlConfiguration LotInfo=new CXYamlConfiguration();</font></div><div><font size="2">LotInfo.Load("Lottery", "Lottery.yml");//第一个参数表示文件夹 第二个表示文件名</font></div><div></div>
复制代码
仅仅只需要2行代码即可完成
再比如存储一个Inventory类
用Bukkit API 你需要把所有的ItemStack分别罗列在yml文件里面
但是使用CXPreposition则是这样的
  1. <div><font size="2">Inventory a=Bukkit.createInventory(null,9,"Test");</font></div><div><font size="2">LotInfo.setInventory("Path",a);</font></div>
复制代码


读取:
  1. Inventory b=LotInfo.getInventory("Path");
复制代码
还有 关于创建ItemStack的 仅需一行即可创建一个完好的ItemStack
  1. ItemStack IS=CXItemStack.Create(1,64,"&4Test","&4这是|一个测试")//Lore用|换行
复制代码
在调试的时候 如果出现BUG被抛出则需要定位抛出的位置是在哪 或者说是程序运行到哪退出 关于调试 CXPerposition也有类
  1. <div><font size="2">CXMessage.ProcessReport();//后台发1</font></div><div><font size="2">CXMessage.ProcessReport();//后台发2</font></div><div><font size="2">CXMessage.ProcessReport();//后台发3</font></div>
复制代码
有了这个调试起来会快不少
比如 如何从一个List<ItemStack>里面随机一个物品?
  1. <div><font size="2">List<ItemStack> b;</font></div><div><font size="2">ItemStack a=CXRandom(b,1).get(0);</font></div>
复制代码
编程 效率和简洁度十分重要 越少的代码执行越多的功能就显得很重要了
再比如 如何快速的获得一个Title不同但是内容相同的Inventory?
Inventory b=Bukkit.createInventory(null,9,"Test");
Inventory a=CXInventory.create(b,"Test1");
