我在写一个判断用户掉线重登的脚本，语言Py3.7，
其中一部分是通过字典映射达到switch跳转的目的，原代码如下：

switch = {
    'run': run,
    'ChangePassword': ChangePassword,
    'CoverEnterImg': CoverEnterImg,
    'CoverGameIme': CoverGameIme,
    'ChangeTallButton': ChangeTalkButton,
    'AddGameVersion': AddGameVersion,
    'RemoveGameVersion': RemoveGameVersion,
    'getColor': getColor
}  # 注册可用命令
choice = input('AURORA >>>')
print(choice)  # 调试用|正式版本删除
switch.get(choice, default)


我通过输入getColor后，程序直接结束

尝试过打断点，仍未找到问题，希望各路大神能予以解惑。

***************************************

原因：switch跳转的映射没有添加括号，
将switch修改为如下即可。


switch = {
    'run': run(),
    'ChangePassword': ChangePassword(),
    'CoverEnterImg': CoverEnterImg(),
    'CoverGameIme': CoverGameIme(),
    'ChangeTallButton': ChangeTalkButton(),
    'AddGameVersion': AddGameVersion(),
    'RemoveGameVersion': RemoveGameVersion(),
    'getColor': getColor()
}  # 注册可用命令
