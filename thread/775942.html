【问题所在】java 不是一个可用的命令/程序，原因是您没有设置java的环境变量
【方案】1.添加环境变量，具体还麻烦您百度关键词"java环境变量"
  2.修改批处理文件(.bat)
       右键编辑您的启动脚本 XXX.bat ，把里边的 java 改成您的Java安装地址，例子:
  1. C:/java/bin/java.exe -jar quit.jar
  2.   请勿复制。这里是当java安装在c盘根的java目录里时的例子
