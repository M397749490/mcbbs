感谢大家支持
安装:
  • 下载“FancyTab.jar”
  • 把“FancyTab。jar”装在你的插件文件夹
  • 重新启动/重新加载服务器
  • 编辑config.yml
  • 重载插件/tabreload

可用变量
%username% - 显示玩家的真实名字

%displayname% - 显示玩家的显示名

%numplayers% - 显示在线玩家的数量

%maxplayers% - 显示最大玩家上限

%ip-address% - 显示玩家的IP地址

%day% - 显示系统日期的天

%month% - 显示系统日期的月

%year% - 显示系统日期的年

%hours% -显示系统时间的小时

%minutes% - 显示系统时间的分钟

%seconds% - 显示系统时间的秒

%version% - 显示FancyTab的版本

%servername% - 显示服务器的名称

%serverip% - 显示服务器的IP地址

%motd% - 显示MOTD的消息(MOTD)

# 支持彩色字体  '&' + 颜色代码.
# 可以使用特殊字符
# 如果你的内容超过了16个字符则只会显示前16个
命令
/tabreload 重载插件

不兼容的插件:
HealthBar
CombatLog
FakePlayers
TagAPI(老版本)
配置
  1. # linux系统请转码为utf-8
  2. logConsole: true

  4. useMetrics: true
  5. autoRefresh: false
  6. refreshInterval: 5

  8. Slots:
  9. - '&b&l服务器版本：1.7.2'
  10. - '&1&l欢迎来到本服'
  11. - '&a&l在线人数：%numplayers% '
  12. - '&9&l您好,%username%'
  13. - '&e&lQQ群：xxxxxxxx'
  14. - '&4&l愉快的玩耍吧~~'
复制代码

还可以设置假人哦  就是把你要显示的名字写进配置里啦 很多人不懂怎么设置其实就是在配置文件的slots里面添加一些假人的名字即可
