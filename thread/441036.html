呐呐，配置文件的食用方法呢，我肚子饿了~
看这里↓
一个样例告诉你一切！
（配置文件中自带此样例）
Example:

    Id: 1                       #方块的ID[就是':'前面的]

    Data: 0                   # 方块的Data值[就是':'后面的]

    Probability: 30          # 概率，此为30%

    Permission: false       # 是否设置为权限获得，false为不设置，true为设置

    Exp: 100                # 给予的EXP值

这个样例↑表示的就是当挖掉石头(ID为1)的时候
有30%的几率会掉100点经验值
且没有权限限制
PS:你不会以为只能添加一个吧？你可以添加无数个！
只需在后面增加新的相同格式的配置即可！
样例可以自己删去


F&Q

问：那么有权限限制该怎么办呢？

答：将Permission设为true。

追问：权限是什么？

答：就是EasyExp.配置的项，如样例的权限就是EasyExp.Example，

       注意规范大小写哦！

问：那么彩色羊毛玻璃那些有Data值的怎么办呢？、

答：设置Data值即可。

问：如何重载？

答：/EasyExp reload 或 /eexp reload，
       重载权限为EasyExpAdmin.use。
