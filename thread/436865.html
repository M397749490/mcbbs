你可以下载一个传送门插件，比如gate
然后设置初始传送点和最后传送点就可以了
创建门gate create id
设置门的进入位置为你站着的地方gate setfrom id
设置传送到的地点为你 站着的位置gate setto id
打开传送门gate open id
每个指令前都加/而且id就是传送门名字
