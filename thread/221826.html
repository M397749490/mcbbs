这个插件使你可以更简易的启用或屏蔽部分指令.它与权限插件(例如GroupManager?)相兼容.

指令列表:
/disablecommands - 打开帮助菜单
/disablecommands add <command> - 增加指令到屏蔽列表(不用带/).
/disablecommands remove <command> -把指令从屏蔽列表中移除.
/disablecommands list - 在屏幕上列出屏蔽列表.
/disablecommands reload - 重新加载配置文件.
/disablecommands update- 执行手动进行插件更新检查.


权限列表:
disablecommands.*: 给玩家此插件的所有权限.
disablecommands.bypass: 无视本插件的指令限制.
disablecommands.add: 获得增加指令到屏蔽列表的权限.
dsablecommands.remove: 获得把指令从屏蔽列表移除的权限.
disablecommands.list:  获得在屏幕上列出屏蔽列表的权限.
disablecommands.reload: 获得重新加载配置文件的权限.
disablecommands.update:  获得执行手动进行插件更新检查的权限.

安装方法及一个简单的例子[尊重原著,总感觉谁都知道- -]:
你只需要把DisableCommands.jar放到plugins文件夹下然后开服就行了!
增加一个指令到屏蔽列表你只需要使用指令:/disablecommands add [不加斜杠的指令 和命令方块一样]例子:输入指令:/disablecommands add op Console.这就会使玩家不能使用/op指令,控制台无视限制.

下面是没有人要看的东西!
注:
本程序可以使用手动更新系统,他运作的顺序是这样的:
连接到curseforge.com
与在curseforge.com的插件最终版本进行比较,如果curseforge.com的版本比较新将会收到更新提示.
您可以在配置文件设置让它自动下载或禁止自动检查.
