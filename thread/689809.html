玩家的话，在领地里输入 /res set move f  禁止移动 和 /res set tp f 禁止TP 的确可以防止别人进来，但是领地有一个卡移动权限的BUG，就算你禁止了MOVE TP  也能进来，这个问题的解决方法就是下载最新的领地插件，目前最新的领地插件已经修复了这个BUG。
作者: 水煮清娃    时间: 2017-5-1 14:39
如果你是想默认建立领地只能建立的玩家自己移动可以设置一下默认领地规则，这个是可以后期自由修改的。设置默认移动为关闭就行，每个人创建领地之后都是只能自己移动。

到配置里找到这个文件plugins\Residenceflags.yml
找到下面这个
FlagPermission:
    move: true

把true改成false就行了
