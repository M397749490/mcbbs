可以通过GUI的方式直接合成

昨天晚上更新的帖子
没有更新指令与权限
我给忘记了qwq
现在补上
指令如下
/fastcraft 插件命令
/fastcraft toggle 开启和关闭快速合成 在后面加上ID就是开启和关闭某个玩家
权限：fastcraft.command.toggle 推荐给玩家
权限:fastcraft.command.toggle.other 这是加上ID的那个权限
/fastcraft craft 打开快速合成界面
/fca reload 重载插件指令
/fca debug  开启debug
使用权限：
fastcraft.use




配置文件
  1. language: ZH-CN
  2. #语言选择,填上ZH-CN就是中文
  3. #下面有我翻译的文件
  4. default-enabled: true
  5. #是否开启快速合成 默认开启
  6. toolbar:
  7.   gap: true
  8. #GUI界面按钮位置更改
  9.   layout:
  10.     page-prev: 0
  11.         #上一页按钮
  12.     page-next: 8
  13.         #下一页按钮
  14.     multiplier: 3
  15.         #合成数量位置更改[铁砧]
  16.     workbench: 4
  17.         #打开原版工作台按钮位置
  18.     refresh: 5
  19.         #刷新按钮位置
  20.   multiplier-order: 1, 2, 3, 4, 6, 8, 12, 16, 24, 32, 48, 64
  21. #这是合成数量可供选择的配置文件
  22. #默认给了一次性合成1 2 3 4 6 8...等等
  23. #假如添加一个一次性合成10个进去 那就是
  24. #multiplier-order: 1, 2, 3, 4, 6, 8, 10, 12, 16, 24, 32, 48, 64
  25. #当然这个顺序可以乱，不过乱了玩家点也容易错 所以还是按顺序加
  26. # 是否开启debug
  27. debug: false
