bedwarrel插件

打开你的bedwarsrel的配置文件
搜索找到bungeecord这一行
应该正常配置是如下的

bungeecord:
  enabled: false
  hubserver: hub
  endgame-in-lobby: true
  full-restart: true
  spigot-restart: true
  motds:
    lobby: |
      $regionname$
      &7[&b$currentplayers$&7/&b$maxplayers$&7]
    running: |
      $regionname$
      &7[&b$currentplayers$&7/&b$maxplayers$&7]
    stopped: |
      $regionname$
      &c[Stopped]
    full: |
      $regionname$
      &7[&b$currentplayers$&7/&b$maxplayers$&7]
locale: en

我先来给你解释一下作用- -
enable  是否打开跨服功能，你需要设置为true
hubserver  是设置你的起床大厅，玩家如果在分服输入/bw leave退出，会传送到你所设的服务器，至于名称是按照你bc配置文件里的服务器名
endgame-in-lobby  是游戏结束后是否会传送回起床大厅，建议开启
full-restart  不清楚，可以不动
spigot-restart  应该是设置游戏结束后是否重启服务器，这个看你自己情况开启吧，如果设置开启，你需要在启动服务器的bat的尾部加入这一条  goto head  用以自动使用短时间内重启服务器
motd  就别动了吧

另外bedwarsrel说是有mysql支持，但是配置文件中并没有这一项
应该是我版本太老还是什么吧
你可以把你的配置文件发过来我帮你看看

数据库在配置文件里

# 数据库配置[目前只配置MySQL]
database:
  # 数据库主机
  host: localhost
  
  # 数据库端口
  port: 3306
  
  # 数据库名称
  db: database
  
  # 数据库用户名
  user: root
  
  # 数据库密码
  password: secret
  
  # 连接池的配置
  connection-pooling:
  
    # 最小连接池大小
    min-pool-size: 3
   
    # 最大连接池大小
    max-pool-size: 50



# Bungeecord 服配置
bungeecord:
# 启用 Bungeecord 服
# ture  开启 Bungeecord 兼容模式
# false 关闭 Bungeecord 普通模式
  enabled: false

# ungeecord 大厅服务器名字
# 类型: string
  hubserver: hub
