大概的按照上图所示填写，分别是Name-文件名，Output Directory-输出目录(选择你Nukkit的plugins目录)
然后我们在右侧的Available Elements中把compile output拖到左侧的Jar文件(BukkitToNukkit.jar)中
然后点击‘+’把plugin.yml和其他需要的文件(例如config.yml)选中然后点击OK，然后点击OK
-------------------------------------------------------------------
第三步：创建Jar Application Run/Debug
点击菜单栏Run → Edit Configurations

点击左侧“+” → Jar Application

在Name里面写一个名字，在Path To Jar中写入你Nukkit服务端的核心文件
Work Directory中输入你服务端的运行目录（一般填入Nukkit服务端核心文件所在目录）
然后在下面的Before Launch中点击‘+’ → Build Artifact → 选择你刚刚设置的Artifact
然后一直OK
