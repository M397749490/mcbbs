HorizonAPI

强大的开发者API



简介：

HorizonAPI是一款为开发者制作的插件，功能强大，目前在早期开发中。
该插件由工作室另一位成员开发，本号代发该插件。



命令 & 权限：
无



插件功能（对开发者）：

1.事件
PlayerJumpEvent 玩家跳跃时触发

2.工具类
TitleSender 给玩家发送Title，即屏幕中间的大字

3.NMS数据包监听器
PacketHandler 可以监听玩家给服务器或服务器给玩家发送的所有数据包



用法示例：

1.监听玩家跳跃事件
  1. @EventHandler
  2. public void onJump(PlayerJumpEvent e){
  3.     e.getPlayer().sendMessage("你跳跃了！");
  4. }
复制代码

2.给玩家发送Title
  1. #参数为：玩家实例, 主标题, 副标题, 淡入时间, 停留时间, 淡出时间
  2. API.getAPI().getTitleSender().sendTitle(p, "主标题", "副标题", 20, 20, 20);
复制代码

3.监听数据包
  1. API.getAPI().addPacketListener(new PacketHandler(){
  2.     @Override
  3.     public void onPacketReceiving(PacketEvent e){
  4.         if(e.getPacket() instanceof PacketPlayInFlying){
  5.             e.getPlayer().sendMessage("你移动了！");
  6.         }
  7.     @Override
  8.     public void onPacketSending(PacketEvent e){
  9.         if(e.getPacket() instanceof PacketPlayOutPosition){
  10.             e.getPlayer().sendMessage("你刚刚被传送了！");
  11.         }
  12.     }
  13. });
