[经济]Fe —— 一个简单轻量的经济插件[全版本]

特征

很稳定丨安装即用丨支持Mysql丨vault支持

命令/权限
玩家命令 - fe.member
/fe - 查看余额 - fe.balance
/fe [ID] - 查看某个玩家余额 - fe.balance.other
/fe send [ID] [金额] - 转账 - fe.send
/fe top  - 查看全服最富有的5个人 - fe.top
/fe help - 查看插件帮助 - fe.?
管理命令 - fe.admin
/fe grant [ID] [数量] - 给某玩家钱 - fe.grant
/fe deduct [ID] [数量] - 扣除某玩家钱 - fe.deduct
/fe set [ID] [数量] - 设置某玩家钱 - fe.set
/fe create [名字] - 创建一个账户 - fe.create
/fe remove [名字] - 删除一个账户 - fe.remove
/fe clean - 清除所有账户 - fe.clean
/fe reload - 重载插件 - fe.reload

插件所有权限
fe.*
/fe 可以用 /money 代替

配置

  1. # Fe Config - loyloy.io
  2. # holdings - The amount of money that players will start out with
  3. # prefix - The message prefix
  4. # currency - The single and multiple names for the currency
  5. # type - The type of database used (sqlite, mysql, or mongo)
  6. holdings: 10.0            //开始的钱
  7. maxholdings: -1                //最大的钱 -1为无限
  8. prefix: Fe             //插件前缀
  9. topsize: 5               //排行榜显示玩家的数量
  10. currency:                //货币名称
  11.   negative: false
  12.   major:
  13.     single: Fe
  14.     multiple: Fe
  15.   minor:
  16.     enabled: false
  17.     single: Fe
  18.     multiple: Fe
  19.   prefix: ''
  20. type: sqlite         //储存类型
  21. autoclean: true              //清理别的插件的账户
  22. mysql:            //下面都是数据库配置
  23.   host: localhost
  24.   port: 3306
  25.   user: root
  26.   password: minecraft
  27.   database: Fe
  28.   tables:
  29.     accounts: fe_accounts
  30.   columns:
  31.     accounts:
  32.       username: name
  33.       money: money
  34.       uuid: uuid

autoclean 是用来清理原本就存在的Vault账户
如果之前用其他支持Vault的经济插件，在开启这项后会清空账户数据
也就是说安装该插件之前所有的钱都会被清空

这是我的理解，官方是这样说的
