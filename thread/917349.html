 MobStack
来自搬运工的话:在下新人一枚,有些格式请大佬们指出,我会最快时间改正.

简介:
           1.怪物堆叠是一个简单的堆叠插件,它能让你的服务器堆叠怪物.
           2.这是以刷怪玩法为主服务器的好选择.
           3.此插件能提升服务器的体验.
默认配置:
  1. # 这是MobStacks的配置
  2. # 由ce_phox制作, 版本: 1.3.1

  4. # 插件前缀信息
  5. Prefix: '&bMobStacks &r&7|'

  7. # 控制台执行命令的消息:仅能在玩家身上执行.
  8. Players-Only: '&cOnly Players can execute this command!'

  10. # 玩家在未获得所需许可的情况下执行命令控制台的消息
  11. NoPermission: '&4You don''t have the permission to do that!'

  13. # 被堆叠生物显示的名称: 需要{amount} 和{type},不然插件无法正常工作.
  14. #   {amount}: 被堆叠生物的数量.
  15. #   {type}  :被堆叠生物的种类.
  16. CustomName: '&e&l{amount}x &r&a{type}'

  18. # 堆叠生物的延迟:tick
  19. # (20 ticks = 1 second)
  20. Delay: 1

  22. # 堆叠生物的范围半径
  23. Radius: 5

  25. # 禁止堆叠的生物/实体的黑名单
  26. BlackList:
  27. - minecart
  28.   - minecart_chest
  29.   - minecart_command
  30.   - minecart_furnace
  31.   - minecart_hopper
  32.   - minecart_tnt
  33.   - minecart_mob_spawner
复制代码
指令:

/ms spawnstack [amount] [type]//生成一个怪物堆叠体 [怪物数量] [种类]
/ms removeall//清除所有
/ms remove [radius]//清除某范围内怪物堆叠体 [半径大小]
/ms help//帮助
/ms about //关于插件

权限配置:

mobstacks.spawnstack
mobstacks.remove
mostacks.notify
