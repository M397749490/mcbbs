Radical Reports —— 举报系统



插件介绍
Description — 简介

Radical Reports 是一款允许玩家举报违规的玩家
这款插件是独一无二的举报插件！（先声明，这话是作者说的不是我说的）
插件里有很多的功能，几乎都可以自定义！
Features — 功能

  • 显示举报与被举报的玩家线上/离线状态
  • 显示UUID
  • 显示举报ID
  • 显示举报的理由
  • 显示举报玩家。有助于确认是否乱举报
  • 显示玩家举报时间（以服务器所在地的时间为准）
  • 可以使用删除键来把举报删除（没测试过）
  • 可以配置权限, 前缀, 允许举报自己等
  • 自定义消息
  • 所有拥有举报权限的玩家在举报成功后会收到通知
  • 数据库举报 - 启动服务器时自动保存数据以防任何延迟
  • 优化 - 在举报时不会延迟
  • 立刻回应（这里应该指的是消息吧？）与更新。
  • 多语言支持 - 只需要修改语言文件
  • 未读的举报消息
  • 显示举报时的自定义特效
  • Bungeecord 支持 - reports are network-wide.（不太懂）
  • Beta的工作人员模式与自定义隐身插件支持
  • 配置中使用/n来断行
  • 简易明瞭的举报GUI - 岩浆桶是指有违反规定的，纸张是指不确定/未定
  • 工作人员模式会有一个传送指南针，一个严惩玩家GUI与一个冰冻玩家物品
  • 每秒点击次数检测 - 当玩家每秒点击次数达到配置中的数值时，将以工作人员模式通知玩家
  • 配置文件中可以配置工作人员模式命令

命令与权限说明
Commands — 命令

  • /report <player> <reason> - 允许举报违规的玩家。如果没有输入理由，会打开选择理由的GUI
  • /reports [reload] - 重载配置
  • /reports - 打开所有举报消息的GUI
  • /staff - 在聊天栏中显示显示所有拥有 reports-command-permission 权限的玩家。（不太懂）
  • /staff mode - 切换工作人员模式
  • /freeze <player> - 冰冻玩家。被冰冻的玩家不能攻击/损伤/移动

reports-command-permission 应该是指 radicalreports.reportscommand

Permissions — 权限

只有这两个


  • radicalreports.reportscommand - 允许使用举报命令
  • radicalreports.staffmode - 允许使用工作人员模式命令
