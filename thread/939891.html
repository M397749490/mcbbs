这个书有问题
指令有问题给不了

如果仅仅是简单的功能不建议使用过于复杂的函数
具体思路就是创建tigger型计分板，然后高频监测该计分板项目数值达到一定设定值的玩家，
然后通过连锁性命令方块的条件制约模式执行你要的命令，之后再将该积分项设为0
书中放的命令则是将计分板设为某个值


例子：
/scoreboard objective add 记分板名 trigger
然后放一个保持开启的循环命令方块（确保该区块为常加载区块），输入/scoreboard players enable @a 计分板名
之后再放一个保持开启的循环性命令方块，输入/tp @a[scores={计分板名=1..1}]  x y z，


并在后面接上一个条件制约保持开启指令方块（注意！两个命令方块的箭头要对齐！！），输入：
/scoreboard players set @a[scores={计分板名=1..1}] 计分板名 0
目的是把玩家的分数重置，准备下次执行。这里依然使用触发时的目标选择器，为了避免一些可能性很小的bug

之后打开我给你的那个命令生成器。之前忘了说，它的默认版本似乎是1.12.2？，所以在界面最上方的设置中调为你所需的版本（1.14）
按照我上一个回复打开成书编辑，这次要在执行命令中输入/trigger tritrip set 1
以此类推，若需多个功能多设几个计分板就行

新设一个计分板/scoreboard objectives add tritrip trigger

高频重复执行或给符合特定选择器条件的玩家/scoreboard players enable @s tritrip

给玩家书本:
/give @p written_book{pages:["[\"\",{\"text\":\"TEST BOOK\",\"bold\":true,\"color\":\"blue\"} ,{\"text\":\"\\n\\n\",\"color\":\"reset\"},{\"text\":\"\\u06e9 No.1 home\" ,\"color\":\"dark_red\",\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/trigger tritrip set 1\"}}, {\"text\":\"\\n\\n\",\"color\":\"reset\"},{\"text\":\"\\u231b No.2 place1\", \"color\":\"gold\",\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/trigger tritrip set 2\"}},{ \"text\":\"\\n\\n\",\"color\":\"reset\"},{\"text\":\"\\u273f No.3 place2\",\ "color\":\"dark_green\",\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/trigger tritrip set 3\"}}]"] ,title:BookABC,author:abc,display:{Lore:["gogoabc"]}}

高频重复侦测玩家一点选其中一个就执行不同tp命令:
/execute if entity @s[scores={tritrip=1}] run function tript:ttrb1
/execute if entity @s[scores={tritrip=2}] run function tript:ttrb2
/execute if entity @s[scores={tritrip=3}] run function tript:ttrb3

当执行trigger tritrip set 1时
将执行.minecraft\saves\TEST地图档\datapacks\资料包名\data\tript\functions
内的ttrb1函数，其内容为
tp 到某座标
trigger tritrip set 0将该值归零

其他依此类推，当执行trigger tritrip set 2时执行ttrb2函数；执行trigger tritrip set 3时执行ttrb3函数。

作者: 475336721    时间: 2020-1-11 11:23
这个很简单
记分板里有一个种类叫trigger
使用/scoreboard objective add 记分板名 trigger 就可以了
然后在常加载区块放一个循环常开的命令方块
内容是/scoreboard players enable @a 你刚刚创的名字 效果是不停的把这个记分板的修改权限开放给玩家（开放一次就能使用一次所以需要循环）
之后在你的指令室里放上/tp @a[score_名称=1,score_名称_min=1] x y z的指令方块 效果是检测trigger记分板分数为1的玩家，把他们tp到你指定的坐标，循环常开指令方块
之后接上/scoreboard players set @a 名称 0 连锁制约常开指令方块 目的是在执行一次传送某玩家的指令后把这个玩家的分数重置
要点来了：
用二楼的生成器 在指令书文字段落编辑里有一个点击事件写上/trigger 名称 set 1 外面表面文字随你喜欢，效果是玩家点击这段文字就会自动执行将自己分数设为1的指令 一个让人回城的指令书就完成了
另外：以上指令都可以被优化或者有更优解，更多功能不同执行方法但是指令书激活方式基本一样。不设定自动重置的话会无限执行 破坏力等同于bug请谨慎测试
