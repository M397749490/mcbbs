我认为是你的GroupManager设置了多个世界权限组，意思是将你的主世界权限与地皮世界权限分割开来了。
打开文件 \plugins\GroupManager\config.yml 并找到配置项
  1.   mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
复制代码

将其下方的配置改为
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           plotworld:
  9.           - users
  10.           - groups
  11.           all_unnamed_worlds:
  12.           - users
  13.           - groups
