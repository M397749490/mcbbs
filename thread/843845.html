随后双击启动spongevanilla-1.12.2-7.1.5.jar
会得到下面这些东西


写好一个bat处理器
Java8的参数可以是：
java -Xms最小内存(如Xms1G) -Xmx最大内存(如Xmx1G) -jar 核心(本文核心采用spongevanilla-1.12.2-7..5.jar)-XX:+AggressiveOpts -XX:+UseCompressedOops
* -XX:+AggressiveOpts的含义是尽可能的使用更多对性能有帮助的优化功能
* -XX:+UseCompressedOops的含义是指针压缩，可以减少一定的内存占用（64位才支持）

下面是我的个人心得时间！

我发现很多人都觉得海绵端麻烦，好像很不友好一样。
其实你真心钻研进去还是很好理解很好做好的。我第一次接触1.12就是海绵端，当时我研究了一个星期才搞懂，觉得挺有意思的，好像又回归了第一次做服务器的那种感觉。
我当时第一次做服务器是14岁，2011年，做的第一个服务器是1.4.7。当时的教程和MC服务器的环境没有现在这么多好大佬，全是自己钻研。漏洞百出，很难修复。

言归正传！

在1.12服务器内例如神奇宝贝骑着精灵飞行(只要是能骑着飞的东西)，是会直接踢出服务器，自动判定为飞行作弊！
我们打开server.properties文件,找到allow-flight=false
把false改为true即可关闭判定。
竟然讲到server.properties文件这里了，就给一些新服主稍微再多说一点把。
level-name=world(这个是默认世界名，禁止使用中文)
例如在你的服务端下，有一个世界文件夹为world和另一个叫TQT（随便取名....禁止中文）的世界文件夹
当你把上面的选项world改为TQT，再开启服务器的话，他会加载TQT的世界，改会world就会加载world世界了!（我在某个人身上被坑了一次....就是这里）
server-port=25565(默认)
这个是服务器的端口，如果是面板服可以无视。VPS或独立机要注意！
1.这里端口设定是多少，需要在防火墙放开！
2.同时开启的两个服务器，端口不能一致！
3.禁止使用80端口.（网页使用的端口）
server-ip=
这里面板服可以默认不填,自己的独立机需要填上内网IP。
然后进行端口映射，会得到一个外网IP，可以给外网IP绑上域名(需要解析)，然后可以添加到服务器，也可以用作网页使用。
这里我推荐使用樱花内网穿透http://www.mcbbs.net/thread-787879-1-1.html
max-build-height=256(最大建造高度)
white-list=false(白名单开关，打开需要在文件夹下whitelist.json添加UUID)
online-mode=true(正版验证登陆)最近有一个皮肤站的外置登陆，如果使用的话需要打开这个。关闭即为离线登陆。
PVP=true(PVP开关)
difficulty=2(生存难度1,2,3)
gamemode=0(主世界玩家的模式)
max-players=20(最大在线人数)

接下来讲解一下难倒许多人，让许多人觉得海绵端特别不友好的Nucleus和Luckperms

在讲核心插件和权限插件之前，先简单的讲讲前置。
PlaceholderAPI变量前置占位符插件
http://www.mcbbs.net/thread-779661-1-1.html这里是详细查看地址
简单来讲就是1.7.10的<>,%%,(),{},[]这种格式变量，稍微了解一下。例如计分板，钟表菜单等等。
Nucleus核心插件
http://www.mcbbs.net/thread-726958-1-1.html
里面有提到名字的占位符即{%player%}就代表ID。假设我的ID是TVXQ。
/eco add TVXQ 100
给TVXQ添加100金钱
菜单写入指令，把TVXQ替换为{%Player%}即可。是不是觉得变简单了，变的很好理解了？
往下面看我们看到这么一条给权限的指令,是什么意思呢？我们来慢慢拆解解读。


/nucleus setupperms [USER|MOD|ADMIN} <groupname>
开头/nucleus setupperms为指令开头不需要去理解，知道就行了
中间的 USER|MOD|ADMIN 指的的是权限,我们联系上后面的<groupname> groupname的意思是权限组的组名，我们用的LP权限插件默认在default组
/nuclus setupperms USER default
整个指令的意思就是给default组添加玩家的权限。如果把USER改为ADMIN，即为给default组添加Admin权限(服主权限)
但是玩家还是没有back回去和rtp随机传送权限，我们就需要用到LP权限插件去给玩家组添加这两个权限。、
添加back权限 /lp group default permission set nucleus.back.base
添加rtp权限 /lp group default permission set nucleus.rtp.base
下面还有添加指令的冷却和间隔以及收费，很好理解慢慢看~我就不讲解了。

下面来讲Luckperms权限插件，其实不需要我怎么讲
http://www.mcbbs.net/thread-714807-1-1.html非常详细，特别好！
我简单讲讲指令方面，以免很多人犯迷糊。我特别喜欢指令解读。
例如给玩家添加一个飞行权限/lp user 玩家ID permission set nucleus.fly
例如给权限组添加飞行权限/lp group 权限组 permission set nucleus.fly
lp是插件名，user后面接玩家ID   group后面接权限组名   permission set意思为添加权限
nucleus是我们用的核心插件(1.7.10是Essentials)  fly为指令
nucluse.fly即为飞行权限节点。
权限节点对应插件名+指令
例如/pay id 100 向某玩家支付100
权限节点为economylite.pay
添加权限为/lp group default permission set economylite.pay

例如查看余额/balance
权限节点为economylite.balance
添加权限为/lp group default permission set economylite.balance

下面讲一下Luckperms插件的称号
不是很难，理解好了指令非常简单
例如/lp user TVXQ meta addprefix 10 &2[新手]
指令的意思是给TVXQ添加一个称号为新手，颜色是&2(颜色代码表http://minecraft.yxzoo.com/46211)
那么指令解读的时候这个10是什么意思呢？
其实这个10你可以理解为新手这个称号的编号。如果有比这个10编号大的，比如编号为11的高手称号。那么默认覆盖更换成11这个高手称号。这个就是优先级的意思。这个是玩家不可更换的称号，所以服主要设置这个VIP称号的时候要注意优先级。

我讲一下newhonor插件和ultimatechat聊天插件把！
打开ultimatechat文件夹下的config.conf(打开后会有很多变量，能看懂的都看看)
找到最下面
   prefix {

        format="{newhonor}{player_option_prefix}"

        hover-messages=[

            "&3Rank: &f{newhonor}{option_display_name}"
    }

    suffix {

        format="{player_option_suffix}"

}



"{newhonor}{player_option_prefix}"

hover-messages=["&3Rank: &f{newhonor}{option_display_name}"]

这么更改玩家在聊天的时候就会显示两个称号，一个是newhonor称号插件（玩家可自由开关称号显示）,一个是luckperms的称号。
