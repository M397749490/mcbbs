标题: 【C#】预告：KMCCC
KMCCC：Kblack's Minecraft Complex Core Code
这将会是一个C#(.Net)的启动器模块，预计最终大小将在100K-150K左右
这个启动模块将会提供的功能有：
1. 获取版本列表及详细信息
2. 启动某个版本
3. 对已经启动的MC修改某些属性
4. 获取服务器状态
5. 计划中

目前这个启动模块仍旧在开发中。

PS：
本模块开源且为LGPL协议
