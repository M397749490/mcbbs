--------------------------------------------------------

FramePicture可以将你的图像显示到画框（也就是物品展示框）里头去

URL可以为网络图片链接或者本地图片

本地图片需放在plugins\FramePicture\image\里

目前支持gif、jpg、png格式

前置插件：Vault

  1. 命令：
  2. # 设置图像地址
  3. /fp set <URL>
  4. # 获取画框的源地址
  5. /fp get
  6. # 取消创建一个画框
  7. /fp cancel
  8. # 重载插件
  9. /fp reload
复制代码

  1. 权限：
  2. FramePicture.set
  3. FramePicture.get
  4. FramePicture.cancel
  5. FramePicture.reload
复制代码

  1. 配置文件：
  2. AutoSize:
  3. # 是否自动调整尺寸
  4. Enabled: true
  5. # 宽
  6. Width: 135
  7. # 高
  8. Height: 135

  10. Money:
  11. # 是否标价（就是这玩意强迫的装vault）
  12. Enabled: false
  13. # 价格
  14. CreatePrice: 10.0

  2. 放置一个画框（物品展示框）
