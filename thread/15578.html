标题: 【MOD】服务器Mod索引


基本上所有的服务器Mod都必须先安装Mod API "ModloaderMp"，所以推荐先到服务器装Mod必备这个帖下载并安装所有的装Mod必备，这样就不怕Mod出错才去安装，所有装Mod必备的API都必须安装到服务端Jar，而大多数的Mod都可以整个zip压缩档放进mods就可以了，方便更换版本/删除。

  • 服务器Mod可以整个Zip放进服务器目录mods，方便更换版本/删除
  • 所有的服务器Mod都必须先安装Mod API "ModloaderMp"
  • 进有安装服务器Mod的服务器必须先在客户端安装相应的Mod，版本必须相同
  • 如果找不到相应客户端或不懂安装某一个Mod或某一个Mod的客户端欢迎回帖询问(态度最好好一点)
