前言
你还在用着随时可能会爆炸的外置图床吗?
那么请你阅读以下版规
所有此类帖子若出现大规模图片挂掉版主发现后则将撤销版头推荐/高亮，直至补图后恢复高亮.

本来都被加过高亮(或别的)的帖子又被撤去，还要一个个仔仔细细补图，你心中会是什么感受？
为了避免劣质图床出现问题，在这里推荐大家使用本地图床(然后请详细阅读本贴内文)

材料准备
1.一台本地的最好不关机的Windows电脑(或者一个Windows servers的服务器)
2.一个安放图片的本地文件夹
3.一个http映射工具(推荐路.由.侠)

什么是IIS
iis是Internet Information Services的缩写，意为互联网信息服务，是由微软公司提供的基于运行Microsoft Windows的互联网基本服务。

直白一点解释，IIS服务就是运行在Windows电脑是的一个进程，作用就是建设网址网站，而图床所需要的，也是这个。IIS服务器就是运行着IIS服务的电脑(一般服务器主机配置略高家用电脑)。

端口映射
端口映射其实就是常说的NAT地址转换的一种，其功能就是把在公网的地址转翻译成私有地址， 采用路由方式的ADSL宽带路由器拥有一个动态或固定的公网IP，ADSL直接接在HUB或交换机上，所有的电脑共享上网。

以下说明常见的五种映射类型及相关作用：

TCP：对我们来说暂时只有开我的世界Java版服务器时使用

UDP：对我们来说暂时只有开我的世界基岩版服务器时使用

HTTP：可将网站映射到外网供访问

HTTPS：可将网站映射到外网供访问并加密数据(需SSL证书)

SOCKS5：可映射代理服务器

在接下来的教程中我们将会用到http来映射网站
这里推荐映射软件为路.由.侠，因为主流的映射软件中只有它能永久进行http映射
花生壳：免费有时间限制
Sakura Frp：不支持http映射

记住一个点，你的图床的域名即在网络中代表你的本地根目录

在本地计算机上安装Hyper-V虚拟机
Hyper-V是微软提出的一种系统管理程序虚拟化技术，能够实现桌面虚拟化。Hyper-V最初预定在2008年第一季度，与Windows Server 2008同时发布。Hyper-V Server 2012完成RTM版发布。

说白了Hyper-V就是利用自家的物理机来搭建云主机

Hyper-V是基于物理机上的完全独立的电脑，它也需要RAM，且是通过分配物理机获得

物理机需要RAM不低于8G，否则不建议使用，如果强制使用那会使得你的物理机和虚拟机同时卡爆

查看物理机RAM的方法是右键“此电脑”，点击“属性”，即可查看

简单的HTML代码
图床建立好了，不安排一个小网页放进去怎么行。
简单的HTML代码介绍

<html>文本开头

<title>网页标题

<body>网页文件主体

<h1>大号字

<p>新建一个段落

</br>不新建段落，空一行

</s>或</del>中间一根删除线就像这样

那么这样我们就可以建立一个简单的网站
  1. <html>
  2. <head>
  3. <title>我的图床网站</title>
  4. <body>
  5. </p><h1>欢迎来到我的网站</h1></br>
  6. <del>虽然什么也没有</del></p>
  7. </body>
  8. </html>
