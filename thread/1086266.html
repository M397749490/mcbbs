什么是Atom?

Atom 是github发起的专门为程序员推出的一个跨平台文本编辑器。具有简洁和直观的图形用户界面，并有很多有趣的特点：支持CSS，HTML，JavaScript等网页编程语言。它支持宏，自动完成分屏功能，集成了文件管理器。
Atom 支持CSS，HTML，JavaScript等网页编程语言。它支持宏，自动完成分屏功能，集成了文件管理器。
通过丰富的插件机制可以完成各种语言开发, 常用于web 开发, 也可用于 php 等后端开发.

Atom有何优势?


在Atom的官网已经给出Atom的简单特点，简单概况之

  • 跨平台 Atom works across operating systems. Use it on OS X, Windows, or Linux.
  • 易拓展 Search for and install new packages or create your own right from Atom.
  • 智能代码补全 Atom helps you write code faster with a smart and flexible autocomplete.
  • 文件浏览器 Easily browse and open a single file, a whole project, or multiple projects in one window.
  • 多窗口 Split your Atom interface into multiple panes to compare and edit code across files.
  • 查询与替代功能 Find, preview, and replace text as you type in a file or across all your projects.

除此之外，在我看来Atom还有其他优点
  • 继承有git，能通过图形化界面操作git。对于不懂git的小白，你可以借此为你的配置文件建立仓库，来对你的配置文件进行版本控制。

为何不使用Notepad++?


1. 首先，我从2012年起就在用Notepad++，一直认为Notepad++是一款非常优秀的软件，已经过去了8年，Notepad++并无做出体验性有实质内容的重大更新，其他编辑器从各方面已经开始超过Notepad++，Notepad++正在失去其优势。
2. Atom近几年更新非常频繁，有很多很多功能包等等出现。与Notepad++相同，都是一款较为轻量级的编辑器。
3. Atom目前不论是流畅性，拓展性，还是美观程度都完胜于Notepad++
4. 近几年，Notepad++的作者不断将其政治观点强加于自己的软件，迫使人们接受与事实相违背的信息，这与程序开发的初衷不符。




有人可能会建议你使用VSCode，的确VSCode比Atom强大，但是Atom更适合被称为一款轻量级的编辑器，而不是一个重量级的集成开发环境。
