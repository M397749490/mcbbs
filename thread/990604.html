作者：
这是一个简单的插件，它提供了注册自定义命令使其有效功能的功能。
自 Minecraft 1.13+ 以来，选项卡完成被引入。一个不错的功能，能够更快地输入命令，并查看哪些命令，你可以使用。
问题在于，只有已注册的命令才算有效，并显示在选项卡完成中。
有很多插件在那里提供自己的自定义命令。但是，他们没有一种方法来注册这些自定义命令。它们不被视为有效，因此不会显示在选项卡完成中，并且在聊天中也标记为红色，就像它们不存在一样。此插件解决了这一点。您可以在配置中根据需要定义尽可能多的自定义命令，插件将为您注册这些命令。它不会修改命令的任何功能。它只是帮助你使他们有效！更多信息和预览图像可以在我们的GitHub上找到。

功能：
  • 注册自定义命令以使其有效
  • 为其启用选项卡完成和有效的语法
  • 向每个命令添加说明和用法消息

安装方法：
  • 转到我们的版本并下载最新版本
  • 停止服务器
  • 将 jar 文件放入服务器的插件文件夹中
  • 启动服务器并等待插件的文件夹被创建并打开它
  • 打开 config.yml 并添加要注册的所有命令
  • 按照配置中给出的格式
  • 确保不添加斜杠（"/"）
  • 为每个命令提供说明和用法消息
  • 重新启动服务器
  • 确保重新启动，而不是重新加载
  • 只有重新启动才会注册新命令

配置文件config.yml :

  1. # 此配置文件包含您要注册的所有命令
  2. # 格式很重要，所有键都是必需的
  3. # 当前包含的命令只是一个示例，您可以删除它们
  4. #
  5. # 格式
  6. # commandName:
  7. # description: 命令的描述
  8. # usageMessage: 有关如何使用命令的消息
  9. #
  10. commands:
  11.   menu:
  12.     description: Opens the menu
  13.     usageMessage: /menu
  14.   playermenu:
  15.     description: Opens the player menu
  16.     usageMessage: /playermenu
