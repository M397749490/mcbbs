标题: 1.8命令方块 趣味炸弹II 可控制地雷
                                 Hey,大家好，今天给大家带来一个新的命令方块教程，叫做“可控制地雷”（※注：本教程为本人灵感，并非抄袭！！）




首先：创建2个积分榜——fishing 和 detonate :
/scoreboard objectives add detonate stat.useItem.minecraft.fishing_rod

/scoreboard objectives add fishing dummy

讲解一下：积分榜“detonate”是用来引爆炸弹的，也就是说当你使用鱼竿时会把“detonate”的分数设为1
积分榜“fishing”是用来探测玩家手上拿的物品。

接下来给自己一个放置炸弹和一个引爆炸弹的主要物品：

/give @p minecraft:fishing_rod 1 0 {display:{Name:"DETONATE!!",Lore:["The right mouse button point me!!!!!!!!!!!!"]},ench:[{id:51,lvl:999}],Unbreakable:1b,HideFlags:63}

这条指令是给玩家一个叫做DETONATE!!的钓鱼竿，钓鱼竿用来引爆炸弹

/give @p minecraft:spawn_egg 1 98 {display:{Name:"Bomb"}}

这条指令是给玩家一个豹猫的，自定义命名为Bomb


以上为最基本的指令


                                下面指令用高频激活（建议命令放块fill高频

下面是物品探测指令，一共9条：

/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:2b}],SelectedItemSlot:2}


/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:0b}],SelectedItemSlot:0}


/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:4b}],SelectedItemSlot:4}


/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:1b}],SelectedItemSlot:1}


/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:5b}],SelectedItemSlot:5}


/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:3b}],SelectedItemSlot:3}


/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:6b}],SelectedItemSlot:6}


/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:7b}],SelectedItemSlot:7}



/scoreboard players set @a fishing 1 {Inventory:[{id:"minecraft:fishing_rod",Damage:0s,tag:{display:{Name:"DETONATE!!"}},Slot:8b}],SelectedItemSlot:8}


这9条指令意思是探测玩家物品，如果玩家手上有拿这个物品就会把玩家fishing积分设为1



给豹猫一个华丽消失的效果（这个不解释，上一期说过）

/entitydata @e[type=Ozelot,name=Bomb] {NoAI:1,Silent:1b}

/effect @e[type=Ozelot,name=Bomb] 7 10000 1

/effect @e[type=Bat,name=TNT] 14 10000 1


在豹猫身上生成两只蝙蝠，一个叫TNT,另一只叫TNT2

/execute @e[type=Ozelot,name=Bomb] ~ ~ ~ /summon Bat ~ ~ ~ {CustomName:"TNT2",CustomNameVisible:1,ActiveEffects:[{Id:14,ShoColorwParticles:0b,Duration:99999}],Silent:1b,NoAI:1,Attributes:[{Name:generic.maxHealth,Base:1}]}

/execute @e[type=Ozelot,name=Bomb] ~ ~ ~ /summon Bat ~ ~ ~ {CustomName:"TNT",CustomNameVisible:1,ActiveEffects:[{Id:14,ShowParticles:0b,Duration:99999}],Silent:1b,NoAI:1}


蝙蝠TNT的任务的放置炸弹，TNT2蝙蝠的任务是引爆炸弹和方块替换

把TNT下方方块替换成草方块（大家可以自己改)

/execute @e[type=Bat,name=TNT] ~ ~ ~ /setblock ~ ~-1 ~ minecraft:grass

把TNT下方方块替换成TNT

/execute @e[type=Bat,name=TNT] ~ ~ ~ /setblock ~ ~-2 ~ minecraft:tnt

好了，TNT的使命完成了，可以把它清除了：

/effect @e[type=Bat,name=TNT] 7 10000 1


下面积分榜就要上场了（积分榜为了是不和其他玩家冲突)

当玩家拿着鱼竿DETONATE!!并使用一次后（当玩家右键使用鱼竿就会把TNT激活）在TNT上方放置一个红石块

/execute @e[score_fishing_min=1,score_detonate_min=1] ~ ~ ~ /execute @e[type=Bat,name=TNT2] ~ ~ ~ /setblock ~ ~-1 ~ minecraft:redstone_block

为了不让其他玩家发觉，在红石块放置后马上在TNT上面放置一个草方块：

/execute @e[score_fishing_min=1,score_detonate_min=1] ~ ~ ~ /execute @e[type=Bat,name=TNT2] ~ ~ ~ /setblock ~ ~-1 ~ minecraft:grass

这样就可以完全掩盖住，但是这有个缺点，就是激活TNT时会发出声音


再做一些小清空就完成了

/scoreboard players set @a detonate 0

/scoreboard players set @a fishing 0

为了是让积分榜不断在1和0之间切换，这样就能无限激活~~~~


教程就到这里，不算难，大家可以来学一下，如果有什么不明白可以看一下下方的视频或下载maps的存档来研究。百度云下载点我~~~~~
