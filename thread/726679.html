介绍：
这个MOD可以让玩家在睡觉时给其他玩家提示，让他们也能够尽快睡觉
只有在同一个世界的才会收到消息
提示消息可自行改成中文，修改任何无难度

样式


如何修改？

打开config文件夹，用文本打开Morpheus.cfg文件
  1. # Configuration file
  2. groundlevel {
  3.     # 地面(1-255) [范围: 1 ~ 255, 默认: 64]
  4.     I:settings=64
  5. }
  6. settings {
  7.     B:是否启用提示=true
  8.     B:是否包括矿工=true
  9.     S:OnMorningText=醒醒, 醒醒, 起床了... 大家早上好!(睡觉天亮后的提示)
  10.     S:OnSleepText=现在正在睡觉.(晚上玩家躺下时候的提示)
  11.     S:OnWakeText=离开了自己的床.(没测试,应该就是字面意思)
  12.     I:SleeperPerc=50
  13. }
复制代码


安装：
如果是服务器的话，直接拖入服务端的mods文件夹即可，客户端无需安装
如果是联机的话，各个客户端都要安装
