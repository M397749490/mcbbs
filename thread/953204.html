可是如果创建了一个骷髅的TYPE,会在白天一直燃烧,还会自动攻击玩家,如何创建一个不燃烧且不主动攻击人的 ...

  AIGoalSelectors:
  - 0 clear
  - 1 attacker
这样只有玩家攻击时怪物才会反击
不受阳光伤害就只能戴帽子，或者
  DamageModifiers:
  - FIRE_TICK 0
  - FIRE 0
不过后者会免疫火焰伤害
