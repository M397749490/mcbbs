房屋购买/出售方法：

在门边(左或右)放置木牌

第一行：[buy house]或[sell house]第二行：类别编号
第三行：房子编号

第四行：价格加上$，留空则以配置文件中的默认价格

购买木牌放在铁门左边或右边出售木牌虽然说可以随便放，但还是建议放在铁门左边或右边，不然不好标识啊。。。

对于木牌并没有限制重复性，所以得管好木牌的权力目前并没有对门牌和房子内物品做出限制(不知道是不是我测试有问题)，所以你得自行配合其它插件进行保护

权限&命令：
命令 功能 权限
/house help [页面] 帮助菜单
/house reload 重载配置
/house all [页面] 显示所有拥有的房子 houses.show.house
/house me 显示你的房子 houses.show.house
/house player <玩家名称> 显示一个玩家拥有的房子 houses.show.house
/house class <类别> 显示某个类别所有拥有的房子 houses.show.house
/house number <编号> 显示指定编号所有拥有的房子 houses.show.house
/house add <玩家名称> <类别> <编号> 为房子添加一个主人 houses.add
/house remove <玩家名称> <类别> <编号> 为房子移除一个主人 houses.remove
/house price [类别] 显示所有类别或指定类别的价格 houses.show.price
/house home 传送到你的家 houses.home
/house tp <类别> <编号> 传送到指定房子 houses.tp
/house sign register <半径> 注册半径内所有木牌到数据库 houses.sign.register
/house sign change <类别> 自动为当前世界指定类别的每块木牌设置价格 houses.sign.change
允许玩家通过木牌购买房子 houses.sign.buy
允许玩家通过木牌出售房子 houses.sign.sell
允许玩家创建交易木牌 houses.sign.create


配置：
  1. # 使用衔位
  2. use-class-rankings: true
  3. # 类别价格自动填充
  4. use-class-prices: true
  5. # 自动关闭铁门的延时秒数
  6. autoclose-door-delay: 3

  8. classes:
  9.   # 类别名称
  10.   '1':
  11.     # 衔位名称
  12.     rank: Emperor
  13.     # 价格
  14.     price: 100000
  15.   '3':
  16.     rank: Badass
  17.     price: 75000
  18.   '7':
  19.     rank: Regular_guy
  20.     price: 30000
  21.   '11':
  22.     rank: Poor_labourer
  23.     price: 10000
  24.    
  25.   # 没有房子的衔位名称
  26.   homeless: default
  27.   # 放置出售木牌时, 第四行价格会自动变为此类别买价的百分之多少
  28.   sell-percentage: 75
