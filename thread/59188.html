众所周知，目前最普遍的服务端分为2种：
官方服务端和我们熟悉的Bukkit服务端
我们先要了解这两个服务端：
官方服务端
官方服务端是由mojang开发的对Minecraft的服务端
            具有十分基本的功能（例如/gamemode,/ban,/give等）
             优点：
             相对于Bukkit 操作更加简单
             相对于Bukkit来说稍加流畅
             可以安装联机MOD（例如入侵MOD，工业MOD等）
             缺点：
             缺少防偷防盗的措施，会导致Grifer横行霸道（Grifer即是破坏者）
            
Bukkit服务端
Bukkit服务端是由Bukkit开发小组针对Minecraft开发的多功能服务端            可以通过插件拥有大量的功能
            优点：
            拥有充满开拓性的功能。
            拥有相对于官方服务端更好的管理
            缺点：
           操作相对于官方服务端较复杂，需要相当的理解能力（或者经验）
           无法与Minecraft版本同步(注：这个缺点在1.1解决了，详情见Wiki)
           插件需要移植成Bukkit版本

首先，我们举个栗子：
你可以在桌面创建了一个文件夹叫做：Minecraft Bukkit Server1.3.2
将你下载的Craftbukkit-1.3.2-R1.0复制粘贴到这里
到此，我们的第一个需要已经完成，下面就是第二个：Start.bat首先，创建一个txt文件叫做Start并打开
然后确定你的java版本是jre6还是jre7
如果是jre6，请在txt里输入：
@ECHO OFF
SET BINDIR=%~dp0
CD /D "%BINDIR%"
"%ProgramFiles%\Java\jre6\bin\java.exe" -Xincgc -Xmx1G -jar craftbukkit-1.3.2-R1.0.jar
PAUSE

如果你是jre7，那么请在txt里输入：
@ECHO OFF
SET BINDIR=%~dp0
"D:\Program Files\Java\jre7\bin\java.exe" -Xincgc -Xmx1G -jar "%BINDIR%\craftbukkit-1.3.2-R1.0.jar"
PAUSE

折叠区关于的是上述文本的解读，可看可不看

@ECHO OFF
SET BINDIR=%~dp0
"D:\Program Files\Java\jre7\bin\java.exe" -Xincgc -Xmx1G -jar "%BINDIR%\craftbukkit-1.3.2-R1.0.jar"
PAUSE

上述文本是jre7的文本青色处为你的java路径，jre6和jre7因为拥有不同的java.exe路径所区分开来
紫色处为你分配的内存，1G表示已分配的内存，如果你想分配2G内存，你就需要将Xmx1G改为Xmx2G。
紫红色为服务端jar的名称，而且必须和你的jar文件的名字完全匹配！！！！


当你编辑好了以后，保存txt文件，将后缀名重命名为bat        大功告成！！！

这两项搞定后你距离开服的脚步就不远了！！！现在我们开始打开Start.bat

大家可以明显地看到，会有系统找不到指定文件的这类蛋疼通知，
已经你的bukkit版本过期的无聊通知。
当然这些你们都不用管了，当出现所谓的"Done (0.xxxs)! For help, type "help" or "?"时你就可以光荣的关掉你的服务器窗口。
在Start.bat所在的文件夹里可以看到以下名字的文件：
banned-ip.txt           (被BAN的IP，使用这个IP的人无法登陆这个服务器）
banned-player.txt   （被BAN的Player名字，使用这个名字的人无法登陆这个服务器）
ops.txt                   （OP的名字，这里面的名字表示的就是服务器里拥有OP权限的人）
server.properties    （这个很重要，我会单独列出）
whitelist.txt             （白名单，用于在server.properties的whitelist=true开启时，给与玩家进入的权利）
bukkit.yml               （用于一些设置，例如出生点保护等）

world,world_nether,world_the_end文件夹   （世界的文件）

还有一些我不知道什么用的：help.yml,wepif.yml

我们先就这个server.properties来说
这个文件是用来编辑服务器的各项设置的。我们就以1.3.2的server.properties举例：
#Minecraft server properties
#Sun Oct 21 15:49:35 CEST 2012
allow-nether=true 是否开启地狱，如果为false即不可开启
level-name=world 世界的名字，假设为XXX，那么世界的名字就是XXX,XXX_NETHER,XXX_the_end
enable-query=false 使用GameSpy4远程监控服务器（不建议开启）
allow-flight=false    允许作弊，如果为true即是允许TMI以及Zombie'mod之类的作弊
server-port=25565  默认的Server端口，改为别的的话IP就是主IP+：+端口
level-type=DEFAULT  世界类型，SUPERFLAT即是超平坦，LARGEBIOME即是大型生态群系
enable-rcon=false 启用远程控制服务器的控制台
level-seed=           地图种子输入这里
server-ip=5.97.110.179     （我的小私服的IP暴露了！）输入IP的地方，内网hamachi联机的输入hamachi IP,外网输入本机宽带IP
max-build-height=256 最大高度限制，也许低一点可以缓解卡？
spawn-npcs=true 生成NPC，false即为不可生成
white-list=false  开启白名单，false即为不开启，谁都可以进；true即为开启，需要加白名单
spawn-animals=true 生成动物，false即为不可生成
snooper-enabled=true 是否定期对snooper发送信息（也就相当于发送bug之类的，不建议开启）
hardcore=false  极限模式，false为不开启，true为开启
texture-pack=  材质包，你需要把材质包的url写在这里，这样玩家已进入服务器就可以自动下载并且使用下载的材质包
online-mode=false  这个就是万恶的OM（盗版必须修改成false，否则无法进入服务器），如果你是正版请不用修改（默认为true），但为了盗版大局，请设置为false
pvp=true  开启PVP，false为不开启
difficulty=0 难度，0为和平，1为简单，2为中等，3为困难（需要和spawn-monster配合使用）
server-name=Text   服务器名字，一个没用的玩意
gamemode=0 默认的游戏模式，0为生存，1为创造，2为冒险。
max-players=20 最大玩家限制，你可以修改成几百人！但是注意你**的内存和等等
spawn-monsters=false 生成怪物，为false即是不生成（需要与difficulty配合使用）
view-distance=10 可以看到的距离，接近于设置迷雾（这个是越低，服务器越流畅）
generate-structures=true 是否生成建筑（NPC村子，地牢，要塞），false即为不可生成
motd=A Minecraft Server 服务器的欢迎信息，可以随便设置

好吧，如果这些你们还不懂的话，我真的就是无地自容了= =
当你设置完成你的那些可爱的server.properties以后，我们就可以重新启动服务器了。
当最后一行出现了"Done (0.xxxs)! For help, type "help" or "?"时，大功告成，你可以进入服务器体验了。
