插件介绍
注意：本插件的玩法仅适合空岛服

本插件为空岛服增添了功能丰富的“精灵”，涵盖挖矿、砍树、耕种、杀戮、拾荒、钓鱼、饲育七个职业，它们可以为你不停地工作（饥饿值充足的情况下），并把它们获得的战利品放进与之关联的箱子里，可代替玩家参与空岛服后期无聊而机械的游戏过程

挖矿精灵Miner
挖矿精灵可以不停地挖掘其正前方一块方块，并将挖到的方块放进与之关联的箱子里，适合和空岛刷石机配合使用

安装与使用
若要使用本插件购买精灵/使用金钱回复饥饿值功能，需安装Vault前置

指令与权限
  • /minion - 插件基础指令
  • /minion store - 打开精灵商店
  • /minion give <玩家名> <精灵名> <数量> - 给予精灵（精灵名区分大小写）
  • /minion reload - 重载插件

建议给玩家的权限
  • minions.player.* - 玩家基础权限，包括以下几个权限
      - minions.player.rename - 给精灵重命名
      - minions.player.linkchest - 给精灵添加关联的箱子
      - minions.player.store - 打开精灵商店

  • minions.skin.<皮肤名称> - 给精灵换肤，使用*代表全部皮肤

  • minions.place.<组名> - 玩家一次可放出的最大精灵数量
玩家一次可放出的最大精灵数量受到“组”权限的限制，欲配置“组”请至config.yml，例如
  1. # 玩家可放出的精灵的最大数量受到权限限制
  2. # 比如，玩家拥有minions.place.vip权限，那么玩家最大允许放出5只精灵
  3. MaxMinionsAllowed:
  4.   - minions.place.default:3
  5.   - minions.place.vip:5
  6.   - minions.place.god:10
复制代码
你可以添加更多组设置

酌情给玩家的权限
  • minions.admin.bypasslimit - 拥有此权限的玩家无视最大放置数量限制
