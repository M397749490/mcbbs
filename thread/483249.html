Eclipse 设定 MCP 目的：
在 Windows-based OS (XP, Win7 x32/x64)下，利用 Java Eclipse IDE 编程工具设定 MCP 套件，以开发 MineCraft MOD 扩充模块。

MCP 描述
MCP, Minecraft Coder Pack，系由一群热爱 Mincraft 游戏的 Hacker 高手所提供出专为其开发 MOD 扩充模块的 Java 编程套件。该套件的作用主要在于可将 Minecraft 软件反组译 (de-compile)为 Java 源代码，以便于 MOD 开发人员撰写模块，而可以覆载 (override)并扩展 (extend)游戏的功能，丰富游戏的内涵。

准备工具：
　o WinRar: http://www.rarlab.com/download.htm , 或 7zip: http://www.7-zip.org/ 。
　　Eclipse(本例使用 3.6 版): http://www.eclipse.org/downloads/

　o (Eclipse IDE for Java EE Developers will work fine)。

　o Minecraft server software: http://www.minecraft.net/download.jsp ,下载 "minecraft_server.jar" 。

　o Java JDK (本例使用 1.6.0 版本): http://www.oracle.com/technetwor ... ownloads/index.html

　o MCP: <http://mcp.ocean-labs.de/index.php/MCP_Releases

安装导引与步骤

1. 安装 JDK 并确实设定 JRE 与 JDK 环境变量路径 (Environment Variable Path)，可参考：http://www.java.com/en/download/help/path.xml

2. 下载 MCP (Minecraft Coder Pack)套件。目前使用版本为 3.1，兼容于 Minecraft Beta 1.5_01 client and 1.5_02 server。

3. 将所下载的 mcp31.zip 解压缩至 \MCPs\mcp31 目录。后述步骤即以该起始目录简称为 %mcp%。

4. 可先执行 %mcp% 目录内 updatemcp.bat 将 MCP 套件作最新更新。

5. 将 "%APPDATA$\.minecraft" (游戏安装预设文件夹)内的 "bin" 与 "resources" 文件夹复制 (copy)至 %mcp%/jars 目录下。
(P.S.  复制后位于  %mcp%\jars\bin\ 目录下的 minecraft.jar，可将 ModLoader 压缩文件内的所有档案，均拖曳至 minecraft.jar 内，以方便尔后开发的 MOD 程序均能与 ModLoader 兼容。

6. 将 "minecraft_server.jar" (从官方网站下载)复制至 %mcp%/jars 目录下。

7. 执行  %mcp%\decompile.bat ，稍待，系统会花上一段时间执行反组译工作。
(P.S. 若有安装 ModLoader 则反组译过程会显示一些错误讯息，可以忽略之。)

8. 利用 7zip or WinRAR 开启 %mcp%\jars\bin\minecraft.jar，将压缩文件内所有档案，除了 \net 文件夹与扩展名为 .class 不要解压外，其它所有档案均解压拖曳至 %mcp%\src\minecraft 目录下。

9. 将 %mcp%\conf\pathches 目录内的 "Start.java" 与 "hy.java" 复制至  %mcp%\src\minecraft 目录下。

10. 执行 eclipse，并将 workspace 设定至 %mcp%\src 目录 ([File] → [Switch Workspace] → [Other...])。

11. 新增 Java 专案 ( [File] → [New] → [Java Project]  )，在 "Project Name" 字段填入 "minecraft" 并按下 [FINISH] 按键。

12. 开启 [Project] → [Properties] → [Java Build path]，切换至 [Libraries] Tab，点击 [Add external jars] 按键，新增下列四个位于 %mcp%\jars\bin 目录下的 .jar 檔：minecraft.jar, jinput.jar, lwjgl.jar, lwjgl_util.jar。

13. 在上一步骤的设定窗口下 ( [Java Build path] → [Libraries] )，个别展开 (expand)包括 jinput.jar, lwjgl.jar, lwjgl_util.jar 等三个档案 (除了 minecraft.jar 不用外)，选择 [Native Library] 并按下 [Edit] 按键，将其位置 (Location)设定为 %mcp%\jars\bin\native。

14. 按下 [OK] 按键回至 eclipse 主画面后，开启 [Run] → [Run Configurations...]，在出现的对话框左侧的列表下，选择并双击 (double click) "Java Application"，会再出现对话框。在 [Name] 字段下可填入如 "MC_Config" 的执行名称；在 [Main Class] 字段的右侧，按下 [Search...] 按键，选择 "Start - (default package)"，按下 [Apply] 按键最后再按下 [Run] 按键，即可开启 Minecraft 游戏。

完成！ 至此即可以在 Java Eclipse IDE 开发环境下开发 Minecraft MOD 模块。至于程序撰写指引，可参考 MCP Wiki 教学 (若有安装 ModLoader，则亦须下载 Javadoc API 文件 参考撰写接口规范 (interface)。
