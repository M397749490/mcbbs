A： 循环 不受制约 红石控制/保持开启（这里随便，方便解ban建议用开关）
  1. execute run clear @e[type=player] tnt 64

B：循环 不受制约 红石控制/保持开启
  1. execute run kill @e[type=tnt]
复制代码
C：连锁 条件制约 红石控制
  1. tellraw @a {"text":"发现有人试图点燃TNT，已处理"}
