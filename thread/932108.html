感谢诸多热心玩家的付出。

1.15是嗡嗡蜂群的首个版本，也是一次Java版的主要更新，发布于2019年12月10日。此次更新加入了蜜蜂及其相关物品，如蜂箱、蜂巢和蜜脾。除此以外，此更新也专注于修复漏洞和改善性能并且添加了许多原本基岩版独有的特性。

新内容
方块
蜂巢
  • 在繁花森林、平原和向日葵平原生物群系自然生成。
  • 可以容纳蜜蜂。
  • 可以储存蜂蜜。
    • 蜂巢内的蜂蜜含量会随着蜜蜂采蜜完成并回到蜂巢酿蜜完成后增加。
    • 玩家可以对其使用剪刀获得蜜脾，使用玻璃瓶获得蜂蜜瓶。
    • 如果玩家在其中有蜜蜂时破坏此方块，这些蜜蜂会对玩家敌对。
      • 使用精准采集工具挖掘蜂巢不会使蜂巢内的蜜蜂敌对，但在蜂巢外的蜜蜂会敌对。
      • 将点燃的营火放置在蜂巢下方安全地收获蜜脾和蜂蜜瓶而不会使蜜蜂敌对。
    • 蜂巢中蜂蜜的数量会随蜜蜂完成旅行、成功回到蜂巢而增加。
    • 玩家可以从蜂巢中收获蜜脾和蜂蜜瓶。
  • 是一个方块实体且不能被活塞推动。
  • 若已经包含蜜蜂，则在创造模式下被瞬间挖掘后掉落自身。
蜂箱
  • 可以使用6块木板和3个蜜脾合成。
  • 与蜂巢功能相似，但不需要精准采集也能掉落。
蜂蜜块
  • 可使用4个蜂蜜瓶合成。
    • 合成后玻璃瓶不会被消耗。
  • 具有比粘液块更强的粘性：
    • 玩家的跳跃能力被大幅减低。
    • 玩家在其上方行走会非常缓慢，而且不能疾跑。
    • 对地毯和台阶之类的非完整方块也会造成影响。
  • 当蜂蜜块被活塞推动或拉动时，它会尝试移动同一个方向上的所有相邻方块。
    • 与粘液块运作原理相同。
    • 蜂蜜块不会和粘液块粘在一起。
  • 如果实体站在被活塞移动的蜂蜜块上，那么实体会跟着蜂蜜块移动而移动。
  • 接触到蜂蜜块侧面的实体会缓慢滑落。
  • 着陆在蜂蜜块上会减少坠落伤害。
    • 坠落伤害被减少到正常情况下的1/5：等价于方块顶端(下落距离 - 3) / 5)；或者说，从第三个方块开始，每个方块减少4/5的坠落伤害，如此类推。
  • 生物会避免走到上面。
  • 不会传导红石信号。
  • 放置在蜂巢或蜂箱旁边时，偶尔会有蜜蜂过来“吃掉”它们。
蜜脾块
  • 仅用于装饰。
  • 可使用四个蜜脾合成。

物品
蜂蜜瓶
  • 可在蜂巢或蜂箱的honey_level为5时对其使用玻璃瓶获得。
  • 回复6和2.4饱和度同时解除该玩家身上的中毒状态效果。
  • 可用来合成糖。
蜜脾
  • 可在蜂巢或蜂箱的honey_level为5时对其使用剪刀获得。
  • 可用于合成蜂箱或者蜜脾块。
刷怪蛋
  • 加入了蜜蜂刷怪蛋。

生物
蜜蜂
  • 拥有10生命值。
  • 在蜂箱和蜂巢附近集群生活。
    • 如果蜜蜂无巢可归，它会一直游荡直到寻找到一个。
    • 可以藏进蜂巢或蜂箱里。
      • 最多可容纳3只蜜蜂。
  • 当玩家攻击蜜蜂时，所有属于同一个蜂巢的蜜蜂会尝试攻击该玩家。
    • 当它们的蜂箱或蜂巢被破坏时，它们也会攻击破坏者。
      • 在巢底下放置营火会使蜜蜂变为被动型。
    • 蜜蜂拥有Anger数据标签，初始值为0。
      • 当被攻击时，该值会变为700刻左右。
    • 当它们攻击时，会给予目标10秒的中毒状态效果。它们会在攻击后50至60秒内死亡。
    • 当蜜蜂攻击玩家时，它们的眼睛会变红。
    • 受节肢杀手魔咒影响。
  • 可以使用任何种类的花（包括凋零玫瑰）喂食蜜蜂来使其繁殖。
    • 像其他被动型生物一样，蜜蜂会跟随手持花的玩家。
      • 如果玩家手持花站着不动，它们会在玩家周围降落。
  • 蜜蜂可以在花上降落，并进入“授粉”状态：它们周围会出现苍白色的颗粒，同样颜色的颗粒效果也会从它们身上发出。
    • 蜜蜂会试图给凋零玫瑰授粉，虽然这会使其被凋零状态效果伤害。
    • 当蜜蜂为花授粉时能听到细微的振动声。
    • 在进入“授粉”状态后蜜蜂会返回它们的蜂巢。
    • 当足够的授粉状态下的蜜蜂返回蜂巢后，蜂巢会被蜂蜜填满。此时玩家可以拿着玻璃瓶并按右键收集蜂蜜。然而，所有蜂巢内的蜜蜂在玩家这么做时会立即出现并攻击玩家。
    • 尽管会被凋零玫瑰给予的凋零状态效果伤害，蜜蜂仍会试图为其传粉。
  • 会尽量避开水。
  • 被蜜蜂杀死的玩家会显示死亡信息：“<玩家>被螫死了。”

命令格式
data
  • 现在可以将storage作为目标，使用通用的键值对存储。
    • 每个存储都可以通过独立的命名空间ID区分。
    • 该存储在同一世界的所有维度内共享。
    • 存储中的数据在重新加载中仍然存在。
execute
  • 加入了子命令execute if predicate。
    • 核算定义在数据包路径下predicates中的自定义谓词。
  • 加入了子命令execute store storage。
    • 将命令的执行结果存储至data的存储目标中。
schedule
  • 加入了新的可选语法schedule ... [append|replace]。
    • 默认为replace。
  • 加入了新的语法schedule clear <id>以移除已有的schedule操作。
    • 返回已移除的schedule操作数。
  • 拓展了schedule以便多次对相同函数进行操作。
spectate
  • 语法为spectate [target] [player]。
    • player - 将要旁观的玩家。
      • 此玩家必须处于旁观模式。
      • 如果省略，则使用@s。
    • target - 将要令玩家进入的旁观视角所属的目标。
      • 如果省略，使玩家停止旁观。
clickEvent
  • 加入了copy_to_clipboard动作。
实体选择器
  • 新的选择器参数predicate允许应用定义在数据包路径下predicates中的自定义谓词。
游戏规则
  • doInsomnia
    • 幻翼是否能够在夜晚生成。
  • doImmediateRespawn
    • 玩家死后立即重生，不显示死亡画面。
  • drowningDamage
    • 玩家是否会受到溺水伤害。
  • fallDamage
    • 玩家是否会受到跌落伤害。
  • fireDamage
    • 玩家是否会受到火焰伤害。
战利品表
  • 战利品表谓词现在能在独立文件定义并被实体选择器在execute if命令中使用。
  • 在location_check条件中加入了新参数选项。
    • offsetX、offsetY、offsetZ – 位置的可选偏移量。
  • 加入了reference。
    • 其导入数据包中predicate路径下定义的条件，通过name参数选择。
  • 加入了time_check条件。
    • 检测一天的时间。
      • value – 可接受值的范围。
      • period – 如果存在，则时间将模除以这个值（例如，如果将该值设置为24000，则该值将以天为周期运行）。
  • 新的函数：copy_state——将掉落方块的方块状态属性复制到物品的BlockStateTag中
    • 参数：
      • block——方块状态属性的来源（方块ID）
      • properties——方块状态属性名的列表，其内的所有值都必需在block指定的方块上存在

游戏内容
进度
  • 加入了bee_nest_destroyed、safely_harvest_honey、slide_down_block进度触发器。
  • 加入了进度“胶着状态”，获得方法为贴着蜂蜜块的侧面下滑。
    • 位于“冒险”标签下。
  • 加入了进度“与蜂共舞”，获得方法为在一个蜂巢下放置营火，然后安全地采集蜂蜜。
    • 位于“农牧业”标签下。
  • 加入了进度“举巢搬迁”，获得方法为使用带有精准采集魔咒的工具采集一个包含3只蜜蜂的蜂巢。
    • 位于“农牧业”标签下。
控制
  • 潜行和疾跑现在可以在设置界面切换“按住”和“锁定”。
    • 允许玩家在切换到其他界面时保持潜行。
    • 同样影响在创造模式向下飞行的玩家。锁定后，玩家会保持向下飞行直到解除锁定。

常规
实体谓词
  • 现在接受检查玩家属性的player字段。
    • 在实体不是玩家时失败。
    • 字段：
      • level – 允许的玩家等级范围。
      • gamemode – 与gamemode命令相同的值
      • stats – 要匹配的统计信息列表。接受的字段：type（例如minecraft:custom）、stat（例如minecraft:sneak_time）和value（整型的range）。
        • 例如，{"stats":[{"type":"minecraft:used","stat":"minecraft:fishing_rod","value":{"min":2,"max":10} }]}如果玩家已经使用了2-10次钓鱼竿，则成功；不在此范围内的使用次数会失败。
      • recipes – 合成配方ID表。一个布尔值表示玩家是否解锁此配方。
      • advancements – 成就ID表。如果其值的类型为布尔类型，将执行成就完成情况的检查。如果值为对象，检查准则的完成度。
  • 实体谓词现在允许使用team字段以匹配队名。
语言
  • 加入了意第绪语。
定位谓词
  • 现在接受block与fluid子谓词。
    • 字段：
      • block – 精确匹配方块ID。
      • fluid – 精确匹配流体ID。
      • tag – 匹配方块/流体ID。
      • nbt – 匹配方块NBT（仅方块）。
      • state – 名称/值的属性映射。值可以是整型、布尔值、字符串或具有可选的最小和最大属性的对象。
  • 现在可以接受light子谓词。
    • 对象拥有一个整型范围——light——用于匹配可见光（天空变暗和方块亮度的最大值）。
谓词
  • 加入了自定义谓词。
    • 战利品表的条件部分现在可以被定义为predicates目录下单独的数据包资源。
颗粒
  • 新的颗粒：dripping_honey、falling_honey、falling_nectar、landing_honey。
闪烁标语
  • 加入了下列闪烁标语文本：
    • "In case it isn't obvious, foxes aren't players."
    • "Buzzy Bees!"
    • "Minecraft Java Edition presents: Disgusting Bugs"
统计
  • 加入了玩家与铁砧和砂轮互动次数的统计数据。
标签
  • 加入了minecraft:bee_growables、minecraft:crops、minecraft:beehives flowers、tall_flowers方块标签。
  • 加入了minecraft:arrows、minecraft:beehive_inhabitors实体标签。
  • 加入了flowers、tall_flowers物品标签。
  • 加入了portals方块标签。


更改
方块
钟
  • 现在会在接收红石信号后鸣钟。
营火
  • 现在能被锹熄灭。
堆肥桶
  • 现在由木台阶合成（和基岩版一致），而不是木栅栏和木板。
暗海晶石
  • 现在用黑色染料合成，而不是墨囊。
发射器
  • 现在可对蜂箱发射剪刀来收集蜜脾。
    • 蜜脾物品会掉落到地面上。
  • 现在可对蜂箱发射玻璃瓶来收集蜂蜜瓶。
  • 现在可对水发射玻璃瓶来收集水瓶。
  • 现在可以放置盔甲架。
  • 从发射器射出的火焰弹现在会点亮营火。
  • 烟花火箭现在会沿着发射器的朝向从发射器中发射。
末地石砖
  • 现在硬度为3。
  • 现在爆炸抗性为45。
耕地
  • 手动放置在耕地上不会使其变为泥土的方块现在被活塞推到耕地上时也不会使其变为泥土了。
  • 现在会使生物窒息。
铁门
  • 现在必须使用镐来采集才能使之以物品形式掉落。
大型蕨
  • 现在掉落小麦种子。
西瓜梗和南瓜梗
  • 附着在果实上的梗方块被破坏后又会掉落种子了。
铁轨
  • 现在的摆放方向与玩家面朝的方向相同，而不再总是朝向南北放置。
红石比较器
  • 现在可以使用红石比较器来检测蜂巢和蜂箱内蜂蜜的含量。
    • 输出强度等于蜂巢中蜂蜜的量。
脚手架
  • 增加了脚手架作为熔炉燃料的燃烧时间，现在可以烧炼2个物品，而不是0.25个。
去皮木头
  • 现在可以使用去皮原木合成。
湿海绵
  • 现在放置在下界中会被烘干。

物品
船
  • 现在用作熔炉、高炉和烟熏炉的燃料时可以烧炼6个物品，而不再只能烧炼1个。
刷怪蛋
  • 溺尸、尸壳、僵尸和僵尸村民现在可以通过对成年实体使用刷怪蛋来生成对应的幼年实体。

生物
常规
  • 生物现在能够更好地躲避熔岩。
末影龙
  • 移除了翅膀材质中透明部分的一个黑点。
  • 移除了死亡中末影龙的翅膀底部的部分材质。
铁傀儡
  • 现在使用generic.attackDamage属性。
  • 现在会在受到一定程度的伤害后开裂。
    • 开裂程度增加时都会播放音效。
    • 每减少总血量的1/4，开裂程度就会加深一次，共4种开裂状态。
  • 现在可以通过使用铁锭来治愈。
    • 每次治疗时都会播放音效。
  • 每次治疗回复25生命值。
    • 从1到满血需要治疗4次。
史莱姆、岩浆怪和豹猫
  • 现在使用generic.attackDamage属性。
鹦鹉
  • 即使玩家骑乘在其他实体上，现在鹦鹉也能站在该玩家的肩膀上了。
  • 不再能模仿末影人、北极熊、狼和僵尸猪人的声音。
生成
  • 现在可繁殖的生物成组地自然生成时，组内会有一定几率生成幼年个体。
    • 狐狸、牛、羊、猪和鸡的几率为5%，狼、羊驼和马的几率为10%。
村民
  • 傻子村民现在不再拥有显示职业等级的徽章。
僵尸村民
  • 从村民转化来的僵尸村民不再消失。
狐狸
  • 现在会生成于所有针叶林生物群系变种中。

非生物实体
末影龙火球
  • 更改了材质，类似于火焰弹在材质更新后的版本。
经验球
  • 作为实体被杀而成为战利品掉落的经验球现在会出现在同一时刻和位置上。
  • 现在是半透明的。

世界生成
树木
  • 桦树又能在黑森林中生成了。
甜浆果丛
  • 现在能生成在巨型针叶林生物群系。

命令格式
effect
  • effect clear命令现在会在未给定target参数时默认作用于@s。
kill
  • 若不给定任何target参数，则第一个参数默认设置为@s。
NBT聊天组件
  • 为NBT存储加入了变种：{"nbt": <路径>, "storage": "<资源ID>"}。

游戏内容
进度
  • 进度中的物品判定现在会将实际的魔咒和储存的魔咒区分开，例如储存在附魔书里的魔咒。
    • stored_enchantments用于匹配存储的附魔。
  • 繁殖蜜蜂现在能获得“我从哪儿来？”进度。
  • “成双成对”进度现在还需要繁殖蜜蜂。
  • “均衡饮食”进度现在还需要蜂蜜瓶。
  • 现在可以用光灵箭获得“瞄准目标”进度。
控制
  • 鞘翅现在可以在玩家跳跃后立刻打开并滑翔，而不需要等到玩家开始下坠后才可以这么做。
食物
  • 所有食物（包括蛋糕）现在都可以在创造模式下食用。
极限模式
  • 极限模式世界现在会提示返回菜单。
配方书
  • 堆肥桶的配方现在由木台阶解锁，而不是木栅栏。
  • 许多配方现在只需要一个材料就能解锁，而不是9个。
  • 许多放置1个方块就能合成的物品配方不再在玩家拥有9个原材料后解锁。
睡眠
  • 使用床重设出生点现在会在聊天栏中显示“已设置重生点”信息。
  • 如果村民躺在一张床上，而玩家尝试在该床上睡觉，那么现在村民会被赶下床。
  • 若玩家尝试白天在床上睡觉，则现在该玩家的重生点会设置在该床旁边。
状态效果
  • 瞬间伤害
    • 加入了图标。
  • 瞬间治疗
    • 加入了图标。
  • 饱和
    • 加入了图标。
交易
  • 图书管理员现在以9个绿宝石出售1个书架，而不是6个绿宝石出售3个书架。

常规
方块模型
  • 方块在物品栏中的模型现在更明亮了。
区块格式
  • 生物群系现在会存储Y坐标的信息，使得生物群系可以沿竖直方向变化；此前，生物群系仅储存X坐标和Z坐标的信息。
    • Level标签中为每个区块排列的Biomes能够容纳的整数从256个更改为1024个。每个数组都为4x4x4区块体积中的生物群系。这些体积会按照Z、X和Y排列，也就是说，数组中第一个4×4值是关于区块中Y轴0-3而言，下一个值为Y轴4-7而言，如此类推。

  • 版本升级为5。
调试界面
  • 不再显示第二行“区块更新（chunk updates）”的计数器。
