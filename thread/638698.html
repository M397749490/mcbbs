作者: Goodlucky31    时间: 2016-10-7 14:30
Java 要下载适应你电脑版本的 Java
如：64位的电脑不要下载32位的Java

查询自己电脑Java位数
打开cmd 输入
java -version
回车 看  Java Hotspot（TM）后面那行
是64位的会显示为 64-Bit  

通常启动器设置的启动内存应该在512MB-1024MB为 正常 2048MB也行
别太大。不是越大越好，不然启动不了的
或检查你的显卡驱动问题哦
