前言 Preface

1.13水域更新作为Minecraft官方此次最重要的更新，确实使Minecraft的世界变得更加多彩；
但致命的是，由于官方此次对API改动较大，许多经典插件都待重写，一些停更的插件而因此瘫痪；
BungeeCord已经可以支持1.13，但还没有针对1.13的跨服星门插件；
但也不要因此而沮丧，这个插件可以帮助你，作者形容到：
BungeePortals is a super-simple, very user-friendly and lightweight Bukkit plugin that hooks in with WorldEdit allowing you to create and remove portals with ease.
（BungeePortals是一个非常轻量级、对使用者友好的Bukkit插件，依赖WorldEdit可以允许您用简单的方式创建跨服传送门）
如果你刚刚好想搭建一个1.13的BungeeCord群组服务器，那就下载吧！
注意：本插件基于Bukkit但需要BungeeCord桥接支持，请不要在底下发类似“无法使用、跨服”的问题，请注意搭建BungeeCord主体！（本插件需安装在Bukkit而不是Bungee）

插件特色 Feature

  • 轻量级：插件本体仅32.4KB，绝对纯净和无害
  • 快速上手：对于新手十分友好，只要你会基本的WorldEdit操作、BungeeCord的基本知识和学会几个指令就可以使用！

  • 更多特色：还有更多在游戏中期待吧！


如何上手创建一个传送门 Use the plugin to build a portal

首先，在开始之前，请搭建好BungeeCord群组，并保证配置正确可以进行传送！

之后确定要从哪个服务器到哪个服务器，玩家出发的服务器我们可以称作服务器a，到达的服务器可以称作服务器b。

然后在服务器a中安装BungeePortals，重启服务器建造传送门的框架（必须是长方形，不过可以进行修整）。

在框架的左下角用WE的小木斧左键，然后在右上角点击右键，这样便选择好了传送门框架。

接下来是最重要的一步：打开指令输入框，键入/bportals create <服务器b的名称（位于bc的config.yml的servers中）>后插件会自动为你的框架中填充传送门方块，进入传送门方块就可以进入对象服务器。

如果想删除一个传送门，可以在指令框中输入/bportals remove <服务器b名称>会删除选区中的服务器传送门方块



命令总览 Command list



  • /bportals —— 显示游戏菜单
  • /bportals reload ——重载游戏菜单
  • /bportals forcesave —— 强制保存游戏数据
  • /bportals create <指定服务器> —— 创建服务器传送门
  • /bportals remove <指定服务器> —— 删除服务器传送门
  • /bportals clear —— 清除选区记录
