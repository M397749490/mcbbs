ProtectCreative v0.9-AnotherVersion

        本插件是作者在重构过程中发现一时半会出不来然后0.7版刷屏严重临时写的一个版本（插件名称以下简称PCAV）

    制作原因

        其实就是作者手残了把All-U-Want放进了服务器的整合包里= =

    插件功能


          
  • PCAV独有的特殊兼容技巧使得可以被用于CraftBukkit，Spigot，MCPC，Cauldron，KCauldron
  • PCAV有别于旧版本的虚体监控技术使得All-U-Want从根源处失效【需要ProtocolLib】
  • PCAV相比旧版本新增了严格模式，在严格模式下，所有带tag的虚体创建请求一律拒绝【需要ProtocolLib】
  • 此外，严格模式支持黑名单，使得她可以不止用于创造服
  • PCAV相比旧版本自由度更高。若您在正常模式下第一次开服，可以选择关闭监听以提高性能


    插件效果

        


    使用方法

        放入服务端plugins文件夹。

        可能需要ProtocolLib插件。

        启动服务器。

    配置文件
   
  1. # hardmode为严格模式开关
  2. # 请注意：开启hardmode必须ProtocolLib前置
  3. # 默认：false：关闭  true：开启
  4. hardmode: false
  5. # useprotocol为ProtocolLib支持开关
  6. # 请注意：开启hardmode后此选项失去作用
  7. # 在普通模式下未安装ProtocolLib此选项失去作用
  8. # 默认：true：开启  false：关闭
  9. useprotocol: true
  10. # uselistener为监听开关
  11. # 请注意：开启hardmode后此选项失去作用
  12. # 在普通模式下未安装ProtocolLib关闭此选项插件失去作用
  13. # 在安装了ProtocolLib的情况下可以关闭此选项以提升性能
  14. # 默认：true：开启  false：关闭
  15. uselistener: true
  16. # blacklist为黑名单
  17. # 请注意：关闭hardmode后此选项失去作用
  18. # 这个选项将会禁止虚体被创建，可用于魔杖
  19. # 修改标准：【以166方块和50方块为例】
  20. # blacklist:
  21. #  - 50
  22. #  - 166
  23. blacklist: []
