一、问答版常识 ——

  • 阅读以论坛总规章与问答版块版规为首的问答版块置顶帖。
  • 将问题发布在错误的版块与类别会增加主题内无意义的回复、延迟问题被解决的时间，甚至使本来有可能被解答的问题失去这个机会。请在发布前按照基岩版问答→联机问答→Mod问答→原版问答→周边问答的顺序来考量您问题的分类。
  •        若它是关于基岩版的，无论是联机还是js，请将其发布在基岩版问答版块；
  •        否则，若它牵涉到多人游戏，无论是Mod导致的崩溃，还是他人无法看见您的皮肤，请将其发布在联机问答版块；
  •        若非如此而它涉及Mod，无论是Forge相关还是光影水反，请将其发布在Mod问答版块；
  •        若你的问题是在纯净的原版中发生的，不涉及到联机和mod等内容，则请将其发布在原版问答版块；
  •        剩下的，包括对于论坛的疑问，以及跟mc相关的问题，您都可以发布在周边问答版块。
  • 问答版块的任何版主都不是答题机器,我们的主要职责是处理违规的主题与回复,以及随时间推移更新、改良问答版块的规章制度,尽一切努力使问答版块成为一个为用户提供提问及答疑机会的平台。因此除非是追问在您发布的悬赏中回答的版主,否则请不要在有非版务相关的疑问时直接私信询问版主,也请尽量不要因邀请回答问题而@版主。
  • 无意义的长标题或内容、用图标制作的"小剧场"、攻击性的言辞、自说自话的"幽默"、违规自顶,甚至是连帖自顶,对问题的解答没有任何实际意义上的帮助,实际上,它们反而会对问题的解答带来负面的影响。您应该在编写标题时将问题准确地概述,在帖内客观地叙述问题,并完整地将可能有助于解答者解决问题的资料一并给出,认真回复解答者,并在获得答案后采纳对方,若有需要,善用楼层右下角的举报,这些行为同时将对您未来的论坛生涯有帮助。
  • 同样的,信口开河的妄语、没有实际帮助的回复、疯狂的水帖、考虑不周的冲动发言,与攻击性的言辞对积分的增长和获取最佳答案与相应的金粒及爱心都不会有任何帮助，违规转账更是在挑战版主的底线。再次重申,问答版块对即便轻度的违规也有长达六个月的处理期限。版主封禁违规用户只需几秒,哪怕那是你耗费了几天、几个月的时间努力积攒积分的账号。

Q:如何提问？
答:
提问之前：善用论坛搜索和搜索引擎搜索；mod/插件问题阅读站内搬运贴（如果有的话）；
提问时：
按照问答版常识的指引选择提问的版块；
尽量在标题中描述出你所遇见的问题；
在帖子内给出你的游戏版本，所装mod/插件，在什么情况下发生了此问题以及能否复现；
展现出你为了解决这个问题做了哪些努力，以便回答者能更好的对症**；
描述你所想要达到的目标而不是过程（有特殊需求除外）；
清楚的描述你的问题以及需求（如获得一个插件/mod，使游戏/服务器能够正常运转，实现某项功能等）；
如果你对答案不甚理解，请点击左下角的回复按钮来追问，并准确的说明是哪里不能理解或哪一步无法实现。
问题被解决之后：点击解决你问题的回复的右下角，设置其为最佳。


Q:如何设置最佳？
答:在回答者的右下角，评分旁边，有个“最佳答案”，点击即可。

如果是jvm.dll, libjvm.so，那么就需要更新Java（卸载其余Java版本）。

问题:/server指令可以绕过Authme的登录怎么办？ 玩家不需要输入/login就可以跨服
解决方案:
请更换authmeBC版或者安装luckpermsBC版  lp group builder permission set bungeecord.command.server false
/server绕过登录插件的原理是，bungeecord的/server指令优先级大于子端的Authme上的/login，因此当使用/server跨服时，bc会绕过登录服的登录限制以跳转到其他服务器。
或者安装luckpermsbungee版  输入  lp group default permission set bungeecord.command.server false server=你的登录服名
