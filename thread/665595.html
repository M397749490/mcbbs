执行命令
给每一个目标执行一条命令
命令支持颜色代码和变量。颜色列表看这里. 变量看这里.
当命令中含有双引号“”或大括号{}时，会报错。必须更改掉他们各自的消息变量.这是因为双引号和花括号是MM需要使用的。如果你必须要使用他们，请用<&sc>来代替引号，
用<&rc>代替 {
用<&lc>代替 }
这是个作用非常多的技能。
比如可以用这个技能设定怪物死了可以让玩家解锁武器配方
怪物死了有几率让玩家获得技能
还有什么杀僵尸有0.001%的几率触发彩蛋什么的巴拉巴拉巴拉
更深入的教程请看命令技能教程
选项
选项
缩写
描述
默认值
commandc将执行的命令



例子
正确地写命令技能

Skills:
- command{c="give <target.name> gold_bar 20"} @trigger ~onInterac
- command{c="minecraft:tp <target.name> <mob.uuid>"} @self ~onDamaged
- command{c="minecraft:summon Zombie ~ ~ ~ <&lc>NoAI:true,CustomName:<&dq>Summoned Zombie<&dq><&rc>"}
- command{c="minecraft:summon Zombie ~ ~ ~ {NoAI:true,CustomName:<&dq>Summoned Zombie<&dq>}"}[/td]
无效的命令技能
这个错误的例子没有使用用于指代的消息变量替换掉""和{}
（所以它最终无法运行）
Skills:
  - command{c="minecraft:summon Zombie ~ ~ ~ {NoAI:true,CustomName:"Summoned Zombie"}"

百分比生命治疗
在2.3加入
依据目标最大生命值的百分比进行治疗
啊，又是2.3的新功能。
其实方便了很多，一些RPG服务器里面可以设计一种这样的牧师，什么每过10秒治疗周围单位最大生命值的10%之类的。
因为RPG服务器有的有用ILS之类的插件，所以有一些比较肉的职业要治疗起来很困难，这个技能就解决了。
同样计算差的同学也不用按计算器了

JSON消息发送
在2.3.2添加
警告！下方信息无比复杂，懒癌患者可以跳过。不过作用巨大。


这是原地址：http://mythicmobs.net/manual/doku.php/skills/mechanics/jsonmessage
发送一条JSON信息. JSON消息可以是聊天框的鼠标悬停时间, 点击事件以及一些在其他消息机制中不可用的甚至是难以置信的特性.这个技能也支持颜色代码 和 消息变量.
JSON消息比普通的消息语法更高级. 语法需要一些额外的符号. 如果你对JSON一无所知, 你可以访问 这个页面亦或是这个页面 来寻求帮助
请注意，在JSON机制中，如果你想使用双引号，那么你必须使用单引号以替代。

选项
属性
别名
描述
默认
messagem发送一条JSON信息. Must be surrounded by double-quotes.



例子
你也能使用Bukkit的颜色代码


   Skills:
  - jsonmessage{m="[{'text':'&aHey, i am a JSON message!'}]"} @trigger ~onInteract
  - jsonmessage{m="[{'text':'Hey, i am a red JSON message!','color':'red'}]"} @trigger ~onInteract

这是一个“鼠标悬停事件JS信息"，意思是，当玩家鼠标飘过去的时候，就会看到这个信息
Skills:

你也可以使用'clickEvent'选项来开启一个”点击事件JS信息“，如果用了'run_command'标签，则它还会执行命令。它可以和/mm signal 相呼应，以此来制作一个”任务怪物“——对，你没听错，新版本只要你脑洞够大，就可以用MM搞出任务系统！！！


  Skills:
  - jsonmessage{m="[{'text':'&7With me, you can create hover events','hoverEvent':{'action':'show_text','value':{'text':'&aI am a hover event :)'}}}]"} @trigger ~onInteract
迟到了好久的实例：

  Skills:
  - jsonmessage{m="[{'text':'&6&n<mob.name> :&7&n哇哈哈哈！谁能挑战我？？！！','hoverEvent':{'action':'show_text','value':{'text':'&a点击将传送到怪物身边 '}},'clickEvent':{'action':'run_command','value':'/tppos <mob.l.x> <mob.l.y> <mob.l.z>'}}]"} @PlayersInRadius{r=5000} ~onSpawn

上面的实例可以在怪物诞生时发送一条信息，点击后可以传送到怪物身边。。。。。

跳跃
令怪物跳向目标。如果速度足够大才可以跳到目标，否则最多只能尽力往那个方向跳。

选项
属性
别名
描述
默认值
velocityv跳起的最大速度100
noisen怪物落地点的偏离程度1



特别说明
由于该技能的工作机制，你可以使用较大的速度值。这个技能计算速度的方式不太一样，100只能说是一般般。

举例
这个技能会使怪物向目标方向跃起，并在落地时重击地面。

CrushingLeap:
  Cooldown: 10
  Skills:
  - leap{velocity=200} @target
  - delay 20
  - jump{velocity=-100}
  - effect:explosion @self
