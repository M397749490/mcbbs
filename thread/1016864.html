DynamicSlot

让最大人数永远大一！

二搬原因

原贴的版本过于老久，且DynamicSlot相比原贴也更新了许多，故做此二搬



插件简介

这个插件可以持续的让你的最大比在线人数大一，并且你可以自由修改

让玩家有一种"我是最终填满服务器的玩家！"的错觉，吸引玩家
心理学欺骗服主进帖



安装方法

1.将DynamicSlot.jar放入plugins文件夹
2.在DynamicSlot文件夹中更改config.yml
3.重新启动服务器


命令
/ dynamicslot：
检查看帮助菜单
权限：dynamicslot.list

/ dynamicslot set：
更改dynamicslot配置
实例：/ dynamicslot set max 5
权限：dynamicslot.config

/ dynamicslot reload：
重载dynamicslot配置
权限：dynamicslot.reload


功能
设置最小人数
设置最大人数
设置比当前在线人数更多的人数
自定义服务器最大人数大小（无限制的任何整数）
蹦极支持！


配置文件
# DynamicSlot config

# Use to fix slot at specified amount
# put 1 into this if you want like ItsJerryAndHarry server
# Example: fixedslot: 1 , server will always have 1 slot (but player always can join)
# -1 = disable
fixedslot: -1

# Minimum slot that can be
# -1 = disable
min: -1

# Maximum number that slot should slot expand
# -1 = unlimited
max: -1

# How much slot should more that player
# Example: min: 5 , slotleft: 2 , if there are 8 player online , server will full at 10 slot
slotleft: 1

#limit total player in the server
# -3 = unlimited , -2 = follow max: , -1 = disable
playerlimit: -3

# Message that player receive when server is full
# Color code allow (%) Example: %c for RED)
# just put -1 if you want to disable (can disable only when playerlimit is Unlimited or Disable)
# Please use '-' infront of message
kickfullmsg: -&c&lSORRY , SERVER IS FULL!%newline%PLEASE TRY AGAIN LATER.
