在玩家使用一个物品时 获取到玩家的游戏模式 判断他是不是创造模式

1.有多种方法...不过都在Item类里面。在你自己的物品的类里这样：
  1. @Override
  2. public ItemStack onItemRightClick(ItemStack stack, World world, EntityPlayer player)
复制代码

或者这样：
  1. @Override
  2. public boolean onItemUseFirst(ItemStack stack, EntityPlayer player, World world, int x, int y, int z, int side, float hitX, float hitY, float hitZ)
复制代码

都可以调用到使用的玩家。不过第二个onItemUseFirst的调用时间是在方块触发之前（也就是说，如果你手持xxx右击了熔炉，那么onItemUseFirst必定在熔炉方块的onBlockActived之前触发），然后按5楼说的方法找isCreativeMode即可。
shift+右键没有单独的判定，需要手动调用EntityPlayer的isSneaking()来判断。shift+左键同理，不过Item类里貌似只有这样一个东西：
  1. public boolean onLeftClickEntity(ItemStack stack, EntityPlayer player, Entity entity)
复制代码


2.物品列表混乱...因为是Forge接管物品id所以只能通过自行调整物品注册顺序来解决咯。
