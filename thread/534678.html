这个我正好知道。
首先确定你的配置文件是否启用。文件目录为“\.minecraft\config\LatMod\XPT.cfg”
  1. # Configuration file

  3. general {
  4.     # Teleporter cooldown
  5.     #  [range: 1 ~ 3600, default: 3]
  6.     I:cooldown_seconds=3

  8.     # Enable crafting recipes
  9.     #  [default: true]
  10.     B:enable_crafting=true

  12.     # Levels required to teleport in same dimension
  13.     #  [range: 0 ~ 200, default: 20]
  14.     I:levels_for_1000_blocks=0

  16.     # Levels required to teleport to another dimension
  17.     #  [range: 0 ~ 200, default: 30]
  18.     I:levels_for_crossdim=0

  20.     # -1 - Disabled
  21.     # 0+ - Enables Recall Remote crafting and usage [range: -1 ~ 200, default: -1]
  22.     I:levels_for_recall=0

  24.     # Only linking will cost levels, teleporting will be free
  25.     #  [default: false]
  26.     B:only_linking_uses_xp=false

  28.     # Soft blocks are like torches - you can walk trough them, BUT it solved the 'getting stuck in block' issue [default: true]
  29.     B:soft_blocks=true

  31.     # Unlink teleporters when one is broken
  32.     #  [default: false]
  33.     B:unlink_broken=false
  34. }
复制代码

代码部分：
    # -1 - Disabled
    # 0+ - Enables Recall Remote crafting and usage [range: -1 ~ 200, default: -1]
    I:levels_for_recall=0
是否允许回程传送器使用：-1是禁用，0是使用但不消耗，1-200就是消耗了。

然后，进游戏，把黄色的传送门放在地上，用黄色的镜子外观的道具右击黄色传送门，镜子道具变成被附魔的样子，同时会有文字提示你连接成功。

外出拿着镜子长按就可以回程。
