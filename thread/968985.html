插件介绍:
    本插件是Nukkit平台的一个登陆插件
插件特点:
     1.密码加密
     2.全GUI操作
     3.自定义语言文件
     4.多种配置可自定义     5.更新迅速
     6.断线重连
     7.登陆后执行命令
配置文件:
      
  1. #注册传送至出生点
  2. TeleportOnRegister: false
  3. #固定登陆地点,登陆后传送回原位置
  4. LoginTeleport: false
  5. #出生点坐标
  6. Spawn:
  7.   world: world
  8.   x: 0
  9.   y: 0
  10.   z: 0
  11.   yaw: 0
  12.   pitch: 0
  13. #玩家进入后几秒钟打开登陆界面
  14. #如果数值过小可能导致玩家未加载完导致无法打开登陆界面
  15. #单位秒
  16. WaitOpen: 5
  17. #密码错误踢出
  18. KickErrorPassWord: false
  19. #掉线后多久能够重连
  20. Reconnected: true
  21. #掉线后多久能够重连,单位分钟
  22. ReconnectedTime: 10
  23. #密码位数
  24. PassWordLength: 6
  25. #开启登陆命令
  26. EnableCommand: false
  27. Commands:
  28. #op: OP权限执行
  29. #console: 控制台执行
  30. #不加 玩家执行
  31. #%player% 表示玩家
  32.   onLogin:
  33.     - 'op:say 欢迎回来'
  34.   onReg:
  35.     - 'op:say 欢迎你的到来!'
复制代码
插件命令:
     /doglogn help - 查询帮助     /doglogn changePassword - 修改密码
     /doglogn adminchange 玩家 密码 - 强行修改玩家修改密码
     /doglogn setspawn - 设置出生点
     /doglogn reload - 重载插件 (doglogin.admin)
