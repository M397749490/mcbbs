标题: [其他]PrivilegeEscalation —— 给物品绑定上无视权限的指令
本帖最后由 1582952890 于 2017-9-16 10:24 编辑

        
  • 简介
    • 该插件可以将多个命令绑定在一个特定的物品上，支持mod物品和不同的nbt。
    • 绑定在物品上的命令在执行的时候不会因为权限不足而被阻止，腐竹们可以不用头疼各种权限组的问题。
    • 提供给予该特定物品的指令，可以配合chest commands, bossshop等插件使用。
    • 仅支持1.7.10，支持mod服，前置插件ProtocolLib。
  • 使用方法
    • 显示使用说明
    • /pe help
    • 显示所有绑定情况 (要求OP)
    • /pe all
    • 标记物品为特定物品 (要求OP，被标记的物品才能绑定命令)
    • /pe mark <标记名(唯一标识)> <是否消耗(true或者false)> <仅作为命令物品(true或者false)> <冷却时间(整数, tick)> <触发按键(1-> 左键, 2 -> 右键, 其它整数 -> 任意)>
    • 例: /pe mark sayaka fasle true 40 1
    • 注: 仅作为命令物品时会失去原本的左右键功能
    • 添加命令 (要求OP)
    • /pe add <标记名(唯一标识)> <绑定的命令(可出现空格)>
    • 例: /pe add sayaka tp 0 120 0
    • 清空命令 (要求OP)
    • /pe clean <标记名(唯一标识)>
    • 例: /pe clean sayaka
    • 清除标记 (要求OP)
    • /pe del <标记名(唯一标识)>
    • 例: /pe del sayaka
    • 给予玩家 (要求OP)
    • /pe give <玩家名> <标记名(唯一标识)> [数量]
    • 例: /pe give kyouko sayaka 64
    • 注: 数量默认为1
