简介


Nukkit 的优点：

Nukkit 由 Java 编写，拥有强大的多线程性能，可以更好地利用你的主机资源，让玩家们更欢快的游戏
源代码根据 LGPL 协议开放，方便开发者和腐竹对于 Nukkit 的学习
采用了类似 PocketMine-MP 的结构，提供了高效的插件解决方案。也便于大家对 Nukkit 作出代码贡献

启动服务端

请先安装Java，要求Java SE版本为1.8或更高.
在Nukkit的jar文件所在目录下打开命令行（或切换路径到Nukkit所在路径），
然后运行如下命令即可启动（我们假设您的jar文件名为nukkit.jar）：
java -jar nukkit.jar
