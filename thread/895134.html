前言
大内网环境我在这里就不介绍了，请百度：
简而言之就是在内网环境下开服务器无法穿透！需要一个外网的中转站来中转流量。如同花生壳，hamachi等...
Frp是目前支持协议最广的开源的内网穿透项目，支持TCP，UDP，HTTP，HTTPS等等
服务器搭建教程：
  • frp下载地址：https://github.com/fatedier/frp/releases 下载你服务器系统支持的版本
  • linux安装教程：解压到一个目录下
    1. tar -xvf ****.tar.gz
    复制代码
    1. 修改配置vi frps.ini
    复制代码
    1. [common]
    2. bind_addr = 0.0.0.0
    3. bind_port = 7000            # 客户端与服务端进行通信的端口，即frp服务端口，需与客户端server_port一致
    4. authentication_timeout = 0  # 关闭时间验证，如果服务器与客户端存在时差
    5. token = 12345678 # 客户端与服务端通信的身份验证令牌
    6. bind_udp_port = 7001 # 是否使用udp端口，不使用删除或注释本行；
    7. kcp_bind_port = 7000 # 是否使用kcp协议，不使用删除或注释本行
    复制代码
    更多修改请百度一下！
    运行：
    1. ./frps -c ./frps.ini
    复制代码
    在后台保持运行：

    1. nohup ./frps -c ./frps.ini
    复制代码

  • 使用HTTP，HTTPS穿透必须添加域名
  • 服务器必须输入“ip:端口”的形式（eg.127.0.0.1:7000）
