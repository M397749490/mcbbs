2.5.0-beta2.31
IMPORTANT FIX!
重要修复！
It seems that in 1.12 a lot of mods are adding custom traits to Tinkers' Construct and this has started to cause naming collisions. This release contains a fix for the issue by having all traits added by BaseMetals have a unique internal name that is unlikely to conflict. If you're using any of the Base Metals releases for 1.12, please update to this one immediately.
看起来在1.12很多mod在匠魂里加了很多功能，而这会导致命名冲突。这个版本通过使用一个独特的内部名称解决了这个问题，已经不会冲突。你要是使用任何1.12的基础金属请立即更新此版本
