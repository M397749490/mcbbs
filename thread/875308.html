  2. Default: (tile: 50, entity: 50)
  3. Type: Integer
  4. Description: The time - in ms - that (tile) entity operations can consume to calculate before the server skips on to the next task. Values between 10 - 20 for tiles and 20 - 25 for entities have been reported to provide a good performance increase.
