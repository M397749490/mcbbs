介绍 · Introduction
你是否版本的更新导致你开放的插件无法使用?那么有了这款插件你就无需浪费时间重新开发了.

Remain 可以让你开发的插件兼容 Minecraft 1.13.2 和 1.12.2甚至最低兼容至 Minecraft 1.7.10 而无需更多代码. 你所需要做的就是使用Remain的classes 而不是Spigot提供的.

今天仍有大约20%的用户仍在运行1.8.8的服务器, 很多 methods 在1.13版本已经无法使用所以插件开发者可能开发的插件只支持最新版本.

特性
  • 使用 Minecraft 1.12 和 1.13 的材料名并兼容这两个版本.
  • 可发送1.17.10至1.13的音效class
  • 在所有版本内发送 Boss Bar
  • 在所有版本发送 标题和子标题
  • 在所有版本发送 Action Bar
  • 在所有版本编辑物品和实体的NBT标签
  • 在所有版本发送 attributes
  • 在所有版本发送 粒子效果
  • 在所有版本设置 元数据
  • 在所有版本设置 刷怪蛋
  • 在所有版本设置 药水效果
  • ...还有更多!

安装
  • 你需要将源码导入你的插件内. 详情查看 GitHub .
  • 通过Remain#setPlugin设置你的插件instance

如何使用
插件文档和源码请查看:
https://www.github.com/kangarko/remain


前置 · Requirement
  • Java 8 +
  • Spigot 1.7.10 +


声明
商业用途和非商业用途均可，只要注明原作者即可。

你可以在你的所有插件内使用 Remain,不论是付费还是免费插件, 混淆代码与否. 然而你在Spigot、MCMarket或是其他地方发布插件时，你必须在插件介绍内提供该插件的链接.

谢谢.
