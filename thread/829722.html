如题 十分感谢
作者: Back_Wheel    时间: 2018-11-11 15:00
/gs settexture <shop|item|money> <按钮>  设置指定GUI的按钮材质为手上的物品:
shop的按钮有:
up        上一页
next      下一页
info       介绍(上一页旁边)
nowinfo 重置,商店信息(最后一行中间一格)
item      收件箱(介绍旁边)
max      从大到小排序
min       从小到大排序
api        货币筛选
me        查看我出售的物品(改变为头时在新版本会显示玩家的头的皮肤材质)
item的按钮有:
up
next
nowinfo
额外的back按钮
