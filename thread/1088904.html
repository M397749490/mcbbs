VentureChat —— Spigot上名列前茅的Bukkit聊天插件

简介
VentureChat 插件是一个实用的聊天插件，它在Spigot上的Bukkit聊天插件排名可是名列前茅的。
让 VentureChat 如此出色的大部分原因在于其多功能性。VentureChat 在所有类型的服务器（大型或小型 Bukkit或Bungee）上均能很好地运行。该插件还具有许多可配置和可切换的特殊功能，包括管理GUI，禁言管理，JSON悬停，昵称，聊天频道，跨服/单服聊天频道，分组服务器聊天频道，专用聊天频道，占位符（很多占位符功能）等等。 。如果涉及聊天的内容，VentureChat可以做到。

VentureChat的特点
  • 1.可控制的聊天频道系统：每一位玩家都可以自己选择他们想进入的聊天频道。
  • 2.JSON格式：现在可以根据配置中自定义的 JSON组 来进行配置在玩家的前缀和名称上的消息。
  • 3.禁言：您可以将聊天频道中的某位玩家临时禁言（只能选择几分钟），也可以一次性将整个聊天频道禁言。
  • 4.全服经验：如果你是 BC 服务器，这项效果可以让全服的玩家禁言（包括全部聊天频道）
  • 5.强制执行：您可以强制某个玩家或所有玩家同时发送一条消息或执行一条命令。
  • 6.聊天频道权限：您可以创建具有权限的聊天频道。例如：专属于管理员或VIP会员的聊天频道，只需给予相关权限即可。
  • 7.聊天频道距离：您可以配置玩家接收到该聊天频道的距离，例如：指定的范围（如10x10的空间）
  • 8.发言冷却的时间：您可以设置玩家发言的冷却时间（以秒为单位），以确保玩家之间发送的消息可以有一定的时间的间隔。有可绕过冷却的权限。
  • 9.全服聊天：您可以让一个聊天频道实行全服聊天（该项只适用于 BC 服务器）
  • 10.Towny 格式：您可以选择使用 Towny 前缀，例如显示玩家所在的 IP 国家和 Towny 标题
  • 11.设置一个聊天频道与聊天文字的颜色：您可以为每个聊天频道的前缀与聊天文字设置 1 种颜色
  • 12.敏感词屏蔽：您可以在配置中设置 需要屏蔽的敏感词 ，以此屏蔽掉粗语或您想要的任何内容。
  • 13.无需切换，快速聊天：玩家可以使用 /channel <频道名称> [message] 直接将消息发送到该频道，而无需切换到该频道。
  • 14.组队聊天：玩家可以加入其他小队或建立自己的小队。
  • 15.自定义格式：您可以使用默认的频道、组队的聊天格式，也可以自定义格式。
  • 16.MySQL日志记录：您可以选择使用 MySQL 数据库来记录服务器上的所有的聊天记录和命令执行记录。
  • 17.支持PlaceholderAPI变量：所有VentureChat自带的PlaceholderAPI变量只能在聊天格式，JSON格式和VentureChat的审核GUI中有效。
  • 18.自定义监听( SPY )格式
  • 19.可自定义插件的输出信息
  • 20.自动重载：您可以在游戏中编辑 VentureChat 的配置文件，它将自动重载插件以进行即时更新。
  • 21.1.16以上的版本，支持 16 进制的颜色代码 （RGB）
  • ……

安装教程
1. 此插件需要安装前置：Vault，ProtocolLib和PlaceholderAPI。
VentureChat 本身会与 EssentialsChat 造成冲突，请确保您的服务器上没安装EssentialsChat。

2.如果您是单子服，只需将VentureChat.jar拖到您的plugins文件夹中，重启服务器即可。

3.如果你是 BC 服，要使用跨服聊天，需要将 VentureChat.jar 拖到 BC 端与子服的插件文件夹中，并打开 bc 模式，重启服务器即可
  1. # 是否开启 BC 模式
复制代码

4.在插件的配置文件生成在 plugins/VentureChat 文件夹中，您可以将路径默认值更改为自己喜欢的设置路径，可以实现：一个文件夹，多服收益。Wiki 上提供了更多有关 VentureChat 配置的详细教程（建议英文好的朋友去看）。

  3.     #频道前缀颜色

  5.     #频道聊天颜色
  6.     chatcolor: "None"
  7.     #是否开启该频道的禁言
  8.     mutable: true
  9.     #是否开启该频道的敏感词过滤
  10.     filter: true
  11.     #是否在玩家进入服务器时，自动加入到该频道
  12.     autojoin: true
  13.     #是否将该频道设置为默认频道
  14.     default: true
  15.     #该频道在子服内的权重
  16.     distance: 0
  17.     #设置该频道的聊天延迟：例子：3 秒才能说一句话
  18.     cooldown: 3
  19.     #是否开启该频道 BC 模式
  20.     bungeecord: false
  21.     #该频道的另外一个名字（该项代表频道名字的变量）
  22.     alias: g
  23.     #设置该频道的权限
  24.     permissions: None
  25.     #设置该频道的聊天格式
  26.     format: '&f[&2Global&f] {vault_prefix} {player_displayname}&2:{vault_suffix}'
