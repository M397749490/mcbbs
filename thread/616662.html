简介:
这是一个可以使用GUI界面购买商品的插件,你可以在游戏中自定义图标,可以自己修改物品价格.
配置直接在游戏中设置,不用一直重载插件,修改之后可以立即使用.

设置:
   1.下载本插件和vault插件.
   2.将插件放进服务器的plugin文件夹内.
   3.重新加载你的服务器.
   4.配置在游戏内完成.
   游戏版本: 1.9-1.10


其他版本请自己测试可以把结果回复一下,谢谢
命令or权限:
命令 介绍 权限
/shop
打开商店 guishop.items.<商店>
/ashop folder <商店> create创建一个商店,图标为你手中物品 guishop.folder.create
/ashop folder <商店> delete删除指定商店 guishop.folder.delete
/ashop folde <商店> add <itemname> <价格>为这个商店添加物品的名字和价格 guishop.folder.add
/ashop folde <商店> remove <itemname> 删除这个商店的这个物品 guishop.folder.remove
/ashop item <名字> create创建一个项目 guishop.item.create
/ashop item <名字> deletes删除一个项目 guishop.item.delete
/ashop item打开所有项目列表 无
/ashop sigin <商店> <定制文本> 当单击这个文本的时候打开文件夹 guishop.sign
/lore <line1> <line2> 我并没有搞懂什么意思,可能是设置lore之类的 guishop.lore
/ashop folder 打开所有商店列表 无
/name <name> 设置手中物品的项目名称 guishop.name
