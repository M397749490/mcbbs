标题: 关于 flying is not enable to 你的server
就是 我用mm弄了一个会飞的马  但是服务器把我闪退了 理由是：flying is not enable to the server {飞行不允许再你的服务器}
想问问 怎么弄才可以让我能骑马飞行呢
作者: xmdhs    时间: 2018-8-17 22:17
只能关闭内置反飞

server.properties 文件中的

allow-flight=false  //是否允许飞行

设置为 true
