经过测试，是可以的。
FriendMe是一个可以让你拥有好友的插件，打怪，挖矿孤单？让好友陪伴你！


命令：
/friend add [玩家名]   添加该玩家为好友
/friend remove [玩家名]  删除该玩家好友
/friend accept 接受好友请求
/friend deny 拒绝好友请求
/friend help 查看帮助
/friend list 好友列表
/friend list online 查看在线的好友
/friend list offline 查看离线的好友
/friend load  重载插件配置



权限：

friendme.user                玩家的权限
friendme.admin           管理的权限


配置：
  1. #-------------------------#
  2. # Bungee Cord Instances   #
  3. #-------------------------#
  4. bungee: false
  5. #-------------------------#
  6. #     Plugin Metrics      #
  7. #-------------------------#
  8. metrics: true
  9. #-----------------------------#
  10. #     Attacking Friends       #
  11. #-----------------------------#
  12. friendly-fire: false
  13. #---------------#
  14. #     BarAPI       #
  15. #---------------#
