Fur[/url]naceNotify
熔炉通知插件
———————————————————————————————————————
这个插件能实现什么功能？
答：可以看到熔炉内烧的物品的进展，如图

———————————————————————————————————————
[指令]
/furnace reload #重载插件
/furnace toggle #熔炉切换
/furnace info #熔炉的信息

/furnace #disableworld  
你可以选择一个世界禁用

/furnace disableplayer  #选择一个玩家查看
——————————————————————————————————————
[变量]
{Prefix} =前缀.
{PlayerName} = 玩家的名字.
{PlayerDisplayName} = 取消玩家的名字.
{PlayerIP} = 玩家的IP.
{PlayerX} = 现在的X坐标.
{PlayerY} = 现在的Y坐标.
{PlayerZ} =现在的Z坐标.
{PlayerUUID} = 玩家的UUID.
{ServerName} = BC的server名字.
{ServerIP} = BC的server  ip.
{PlayerXP} = 等级.
{PlayerGamemode} = 玩家的模式.
{PlayerHealth} = 玩家的生命.
{World} = 玩家所在的世界名字.
{CookTime} = 熔炉烧的时间.
{SmeltItem} = 烧的物品的名字.
{Fuel} = 燃料名称.
{FuelAmount} = 剩余烧的量(比如说煤可以烧8个).
——————————————————————————————————————
[权限]
furnace.reload   #重载插件
furnace.notify   #让你接收到信息(就是那个高大上的信息显示)
furnace.disableworld   #可以设置禁用的世界
furnace.info   #可以使用
/furnace info 命令
furnace.toggle   #让你禁用或启用这个插件
furnace.toggle.exempt   #熔炉切换
furnace.toggle.bypass  #允许你不用上面的
furnace.toggle.others   #允许你使用熔炉切换对其他玩家
furnace.plotbypass   #地皮插件内显示
furnace.factionbypass   #类似于派系插件的一个显示
furnace.skyblockbypass   #对空岛显示的权限，island？
furnace.cooldownbypass   #允许绕过冷却时间？
