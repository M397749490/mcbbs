求解
作者: nihongchun    时间: 2018-7-19 10:04
  Disguise:
    Type: player
    Skin: 'Cow'
    Player: '&a&l怪物'
    Burning: false
    Blocking: true
    Invisible: false
    ShowName: false
    Sneaking: false
    Sprinting: true
    ModifyBoundingBox: false   加这样几条       Skin: 'Cow'  里面的就是皮肤名 可以在NAMEMC查找   要配合LibsDisguises付费版使用
