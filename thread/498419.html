*****************************************************************



*****************************************************************

-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-
插件介绍:
  • 自动检测上线玩家[模式/OP权限]后核对
  • 自动撤去没有OP白名单的玩家OP权限
  • 自动恢复没有模式白名单的玩家模式为设定模式
  • 可以防止他人入侵后台获得OP
  • 可以防止服务器内OP给小号OP权限
  • 可以防止OP给他人创造模式
其他说明:
当服务器新招聘一名OP时,如果考核失败,这名OP可能
会趁腐竹不在时创建一群小号,然后全部OP或者给予
创造模式,也有人熊到OP密码后登陆OP账号进行所谓的
"全民OP"或者"全民创造"，而这个插件就可以防止这种
事情.
工作原理:
假如给玩家xxx了OP权限,那么此玩家登陆后,插件会检测
文件内是否写有此玩家游戏名,没写就会直接被撤去OP
同样游戏模式也可以是被检测的对象,例如一枚生存服内
一名OP给一名玩家创造模式,如果此玩家不在插件白名单
内将会被还原原来的游戏模式..............................
防止不靠谱OP滥用权限       :D................
配置文件:    (1.72版本)
BackEnd:
  VersionDONOTCHANGE: 2
#插件版本
  UpdateChecking: true
#是否允许检测更新
  Metrics: true
#不用管的一个选项
Players:
#玩家名字添加处
  AllowedOp:
#允许是OP的玩家
    - EnkyHD
  AllowedGamemode:
#允许更改游戏模式的玩家
    - EnkyHD
Block:
#某方面的检测是否开启
  PlayersFromChangingGameMode: true
  OPingNonAllowedOPs: true
  OPInConsole: true
Stats:
#统计数据(次数)                                                            
  blockedInConsole: 0
  blockedByCommand: 0
  playersDeopOnJoin: 0
插件权限:   
重载指令:/autodeop reload
重载插件权限: autodeop.reload
插件0.6版本后被删除的权限
成为 OP 权限: autodeop.allowop
更改模式权限: autodeop.allowgamemod
