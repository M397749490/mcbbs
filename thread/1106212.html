MOD简介（摘自原搬运贴）

这个模组类似于之前的老牌血量显示模组，但是它有两种显示血量的方法：心(hearts)，数值(numeric)。这个模组也可以显示生物状态及护甲。界面在1.11.2版本有所升级。这个模组在左上角显示生物受伤、回血、装甲的状态。 MOD在Curseforge上的类型：界面(Cosmetic)、地图和信息(Map and Information)

配置文件（摘自原搬运贴）

  1. 文件名：torohealthmod
  2. 内容如下：
  3. # Configuration file
  4. client {
  5.     # Damage Text Color [default: RED]     //受伤颜色（默认红色），在等号后面输入大写的颜色英文，例如"GREEN"。
  6.     S:"Damage Color"=RED
  7.     # Heal Text Color [default: GREEN]     //回血颜色（默认绿色），在等号后面输入大写的颜色英文，例如"RED"。
  8.     S:"Heal Color"=GREEN
  9.     # Display Health Bars [default: HEARTS]     //显血方式（默认心），在等号后面输入大写的显示方案，例如"NUMERIC"，将心条改为血条。
  10.     S:"Health Bar Display"=HEARTS
  11.     # Location of Health Bar [default: TOP LEFT]     //显示位置（默认左上角），在等号后面输入大写的位置，例如"TOP RIGHT"，右上角。
  12.     S:"Health Bar Position"=TOP LEFT
  13.     # With CUSTOM position, sets X position of Health Bar [range: -20000 ~ 20000, default: 0]     //自定义血条x轴位置。
  14.     I:"Health Bar X"=0
  15.     # With CUSTOM position, sets Y position of Health Bar [range: -20000 ~ 20000, default: 0]     //自定义血条y轴位置。
  16.     I:"Health Bar Y"=0
  17.     # Delays hiding the dialog for the given number of milliseconds [range: 50 ~ 5000, default: 400]     //血量显示毫秒数（默认400）。
  18.     I:"Hide Delay"=400
  19.     # Shows a 3D model of the entity being targeted [default: true]     //是否显示生物3D图案（默认是），可改为否"false"。
  20.     B:"Show 3D Model of Entity"=true
  21.     # Show Damage Indicators [default: true]     //是否显示血量变化数字（默认是），可改为否"false"。
  22.     B:"Show Damage Particles"=true
  23. }
