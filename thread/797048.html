经过一个星期的鏖战，额终于把这个模组刚出来啦。鉴于大家普遍喜欢把Minecraft当做养老游戏，为啥不来体验下介个模组呢
这个模组旨在添加一些比较特别的游戏规则，且每隔一段时间便会自动更换游戏规则，这会让Minecraft变得更像“休闲”向的游戏哦
注：该模组的最新版已无需任何前置模组啦= =

功能简介
某天，史蒂夫手握钻石剑大砍四方，由于怪物的孱弱与史蒂夫的强大，顿时哀嚎遍野、哭声连绝……
看着史蒂夫凶残的背影和狰狞的表情，巫婆默默地留下了泪水……
在向史蒂夫施以恶毒的诅咒后，登时雷声四起，怪物成群结队向史蒂夫咏唱起了复仇的悲歌……
“血债血偿的时刻，到了！”

好啦，开玩笑的啦，以上图片均截取自在某些特殊规则开启时会发生的情景。
（目前的游戏规则有10个）
每次规则更迭的时间为 20——40分钟 （可能不大准确），当然也可能存在更迭到与上一次规则相同的情况
同样，如果你是欧洲人的话，可能会更迭到“无规则”
如果你是非洲人的话，可能会更迭到两个、甚至三个规则同时存在的情景= =
不要小看这些规则，因为很多规则可不是你有神装就能够抗拒的哦，而且如果不做好提前准备是很容易被秒掉的。
请注意你的左下角，这是代表你的世界中诅咒的类型（当然觉得碍眼的话可以通过配置文件关掉类型显示）
同样，世界的“特殊规则”规则和其持续时间可以使用指令来进行修改哦。
现在规则的自动循环与持续时间也可以通过配置文件修改啦= =。
此外，除了游戏规则的更新，这个模组也对原版世界的规则与生物做出了一定的调整：
游戏难度被锁定，调和平是没用哒（可通过配置文件取消）
新版本已不再锁定对死亡不掉落和者怪物生成游戏规则的调控
怪物生成时血量不会低于45点，能够攻击的怪物攻击力不会低于4点（可配置）
新版本已不再强化玩家属性
在游戏规则更迭以及玩家重生时该模组将会给予玩家一定的无敌时间（可配置玩家复活时是否给予无敌时间）
那么，这个世界究竟更新了那些不一样的规则捏？

新增游戏规则
不同的游戏规则ID对应着不同的游戏规则：
ID: -1 ,无规则，如果指令设置为 -1 则为全规则同步配置，比如 /setRule -1 为规则全开，/cancelRule -1 为规则全关。
ID: 0 ,无规则，最新版已规定该规则可以自动出现。
ID: 1 ,一击必杀，所有生物造成的伤害可以秒杀除了自己以外的生物，对boss无效。很经典的规则= =。
ID: 2 ,永夜，在这段时间内将会是午夜，且一直都在打雷和下雨，天启四骑士骷髅（1.10.2版本以后的事情啦）将会经常出现。

可以很清楚地看到本模组新增的三个指令：
/setRule 要开启的特殊规则的ID [持续时长秒数]
开启本世界的一个特殊规则ID，其中如果不明确世界规则ID的话可以参看下方的规则说明。其中持续时长为可选项，如果没有关闭事件循环且不进行填写的话将会自动生成一个持续时间（1200 —— 2400 秒）
注意：请不要填写 /setRule -1 酱紫= =。
/getRule
获得该世界正在执行的所有特殊规则的ID、名称及到下次规则更新所剩余时间（秒）
/getRuleID
从本质上来讲，该指令就是把消息框内下半部分ID与其对应特殊规则规则的说明“复述”一次，以防止玩家在游戏内忘记规则名称与ID的对应关系。

新版本新增指令：
/cancelRule 数字(游戏规则ID) [数字（时长：秒数）] 移除一项规则并设定下次规则循环到的剩余时间，与 /setRule 同理，是该指令的反向指令。同样，如果想要快速移除所有规则可以设置 /cancelRule -1 酱紫。
/cancelAllRules [数字（时长）] 移除所有规则并设置下次规则循环到的剩余时间，等同于 /cancelRule -1 。
/gamerule doRulesCycle true或false：设定游戏特殊规则是否自动循环。 doRulesCycle 现已成为游戏规则的一部分，如果想在游戏内设置所有规则是否循环的话可以在 /gamerule 中查询并修改 doRulesCycle 游戏规则。
以上所有指令均属于OP指令，但都可以在命令方块内执行

配置文件
利用配置文件可以做到好的好的事情，比如设置多重定向规则……酱紫。
authority {
    #If true,the rule will change by time cycle,default:true.
   B:doRuleCycle=true//默认状态下规则是否启用自动循环，即决定了第一次进入游戏时 gamerule 为 doRulesCycle 的游戏规则是 false 还是 true。
    #Every Rule fix cycle time seconds,true cycle time = staticCycleChangeTime + (0to thisvalue),default:1200
   I:fixCycleChangeTime=1200//如果开启规则循环，则规则循环的补偿时间（秒数），自动规则循环时间=固定循环时间+ 0——规则循环的补偿时间内的任意整数。
    #Lock difficulty to hard,default:true.
   B:lockDifficult=true//是否锁定难度为“困难”模式，这决定了你的调整难度界面上的那个按钮是否有用，如果你有经常用和平模式刷怪的习惯额建议你开启。在服务器中可以考虑关掉否则服务器的难度将永远是“困难”。
    #If strengthen mobs,all mobs'attackDamage will not lower this value,default:4.
   I:mobMaxAttackDamage=4//在开启强化怪物的情况下，所有能攻击的怪物的攻击力不会低于该值。
    #If strengthen mobs,all mobs'health will not lower this value,default:45.
   I:mobMaxHealth=45//在开启强化怪物的情况下，所有怪物的初始生命值不会低于该值。
    #When player respawn,set invincible for 30 seconds,default:true.
   B:setInvincibleWhenRespwan=true//在玩家重生后是否给予玩家30秒无敌（其实就是瞬间治疗）效果，制作解谜地图的玩家可以考虑关掉它。
    #Show rule icon,default:true.
   B:showIcon=true//将当前世界现有的规则以贴图形式绑定在屏幕坐下角，如果觉得图标不习惯或者与其他模组冲突可以关掉该配置。
    #Every Rule static cycle time seconds,default:1200
   I:staticCycleChangeTime=1200//如果开启规则循环，则规则循环的固定时间（秒数），该项与规则循环的补偿时间共同计算出下一次规则更迭所需要的时间。
    #If true,the mobs will be strengthen when spawn,default:true.
   B:strengthenMobs=true//是否开启强化怪物，如果选是，一般情况下原版的怪物都会被强化。
}
existrulewhenstart {
    #Open rule which ID is 1 when game start ,default:false.
   B:bstr1=false//这些内容决定了你第一次进入游戏（或第一次开启服务器）时便已经存在的规则，如果有哪一项是 true ，则一开始进入游戏便有了这样的规则。
