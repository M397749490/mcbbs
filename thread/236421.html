  • 地皮生成器和管理分离
  • 全面支持UUID
  • 0.16版本移除的创世神保护

命令
  1. /plotme claim <player> 为别人认领你脚下的地皮
  2. /plotme auto 自动认领顺序下一个地皮
  3. /plotme home[:#] 设置家，如果你有多个:
  4. /plotme home 会带你去你1号地皮.
  5. /plotme home:2 会带你去2号地皮.
  6. /plotme home[:#] <player> 去别人家/plotme home id 会带你去他的1号地皮.
  7. /plotme home:2 id 会带你去他的2号地皮.
  8. /plotme list 列出你的地皮
  9. /plotme list <player> 列出别人的地皮
  10. /plotme info 列出你站在的地皮的信息(包括地皮id, 主人,地形, 日期, 结束 帮助).
  11. /plotme comment <text> 评论一下（留言）到当前的地皮
  12. /plotme comments 查看各种留言
  13. /plotme biome 查看目前地形
  14. /plotme biome <biome> 改变当前地皮的地形
  15. /plotme biomelist 列出可设置地形
  16. /plotme tp <id> 传送到某个地皮
  17. /plotme id 查看当前地皮的id和坐标
  18. /plotme clear 将地皮初始化到认领时候的样子（地形哦~慎用）
  19. /plotme reset 还原地皮（慎用，解除占领的）
  20. /plotme add <player> 给某个玩家在你地皮建造的权限
  21. /plotme remove <player> 移除某个玩家在你地皮建造的权限
  22. /plotme setowner <player> 过户你的领地给玩家</font></i>

如何使用创世神
You can safely give your users WorldEdit commands without worrying about them modifying other people's plots. PlotMe uses the //gmask function within WorldEdit to restrict the blocks they can change. Only plots which the player is owner or helper on can be modified by WorldEdit. Your admins can use /plotme weanywhere, to remove the restriction for themselves temporarily to modify roads for example.

你可以给你的玩家worldedit权限而不担心他们修改其他人的地皮。plotme使用//gmask命令可以在限制下用worldedit改变方块块。只有地皮的所有者或助手可以使用worldedit修改自己的地皮。管理员可以使用/plotme weanywhere，去除限制，自己暂时修改公路。

Version 0.13c Additions




  • Updated to use UUIDs on Owner, Current Bidder, Allowed players, Denied players and commenters




    • On first start, server will fetch the UUID of every player in the database. This is made in an asynchronous process and should cause minimal lag to the server.
    • When testing if a player can build in an area, his UUID is now compared instead of his name.
    • Soon Mojang will allow players to change name. To compensate for that, when a player logs on the server, it will verify and update when needed his name on plots. This is also done asynchronously but I believe it could cause issues on dense servers with many many plots. If it becomes a problem, I might turn this into a manual process. The player would need to type a command to update plots with his name.
    • When you set a plot to a player, add a player, deny a player, if that player is not online, it will query the mojang server to fetch his UUID. This way, if the player changes name before he logs back on there is less chance of issues.
