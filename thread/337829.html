Cauldron linux Ubuntu VPS开服流程
感谢aa210063654的帖子
参考：http://www.mcbbs.net/thread-103119-1-1.html

环境：ubuntu 14.04 64bit Vps

用putty登录SSH
  1. apt-get install openjdk-7-jre
  2. mkdir /目录
  3. cd /目录
  4. wget http://sourceforge.net/projects/cauldron-unofficial/files/1.7.10/cauldron-1.7.10-1.1206.01.170-server.jar/download
  5. wget http://sourceforge.net/projects/cauldron-unofficial/files/1.7.10/libraries-1.1207.01.zip/download
  6. upzip libraries-1.1207.01.zip
  7. touch start.sh
  8. echo 'java -Xincgc -Xms1G -Xmx1G -Xss1M -server -jar cauldron*.jar' >start.sh
  9. chmod a+x start.sh
  10. sh ./start.sh
复制代码

然后经过短暂滚屏会出现无法开启服务器
修改eula=false为eula=true
  1. sed -i "s/eula=false/eula=true/g" `grep eula=false -rl /目录`
复制代码

开启服务器
  1. apt-get install screen
  2. screen -S "Minecraft server"
  3. sh ./start.sh
复制代码

服务器正式启动了~~~咕驰咕驰

关闭客户端检测是否为正版
  1. sed -i "s/online-mode=true/online-mode=false/g" `grep online-mode=true -rl /目录`
复制代码




FAQ
Q1：我不想要1.7.10版本该如何？

A：wget部分是下载cauldron 1.7.10，和libraries-1.1207.01.zip
如果想下载其他的，请自行到上面的网盘寻找。

Q2：wget 不管用~

A：使用windows在网盘里下载cauldron和libraries，使用filezilla登录sftp上传到对应的目录里。
