服务器熊孩子到处用骨粉的BUG刷钻石求一个插件可以防止这样的BUG
作者: =w=卖萌=w=    时间: 2015-2-1 01:47
你的服务器是 几点几的？

其实不需要什么插件！~
你直接打开
essntials   插件里的 config.fml 文件~

找到
  1. # 当以下方块被放置或破坏,或物品被使用时会出现警告
  2.   # 你加载了一次Essentials后,就可以在plugins/Essentials/items.csv中找到物品ID列表.
  3.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  4.   alert:
  5.     on-placement: 10,11,46,327
  6.     on-use: 327
  7.     on-break:

  9.   blacklist:

  11.     # 阻止玩家放置以下方块
  12.     placement: 10,11,46,327,408

  14.     # 阻止玩家使用以下物品
  15.     usage: 327,351:15

  17.     # 阻止玩家破坏以下方块
  18.     break:

  20.     # 阻止活塞推动以下方块
  21.     piston:

  23.     # 阻止发射器发射以下物品
  24.     dispenser:
复制代码

把这一段话在 你的服务端里找到 然后
把
  1. # 阻止玩家使用以下物品
  2.     usage: 327
复制代码

改成
  1. # 阻止玩家使用以下物品
  2.     usage: 327,351:15
复制代码

就行了 ~


要是想禁止漏斗矿车偷东西的话！
就将

  1. # 阻止玩家放置以下方块
  2.     placement: 10,11,46,327
复制代码


改为

  1. # 阻止玩家放置以下方块
  2.     placement: 10,11,46,327,408
复制代码
