原贴地址：http://tieba.baidu.com/p/2780177052

1.修改移动速度
先是移动速度修改:
路径: ...\Starbound\assets
修改文件default_actor_movement.config，右键记事本打开
Ctrl+F打开查找
"walkSpeed" : ？速度（咱是英语渣）
"runSpeed" : 跑速度
"flySpeed" : 飞行速度
以上都是移动速度，30左右就跑的没溜了，太快的话地图加载跟不上，容易死机

2.无限跳和无限飞
接下来是轻功，踏雪无痕
同一个文件
"multiJump" : false
把false改成true，就能无限跳了，NPC等怪物也能，不过他们不会一直跳，当然如果把下面这句也改成true
"autoJump" : false
那就是无限飞了，怪物也会无限飞，哦，是跳很高

3.背部提灯亮度
背部提灯的照明范围：
Starbound\assets\items\armors\backitems\lanternstick\lanternstick.back
鼠标右键使用记事本来打开lanternstick.back这个文件。
字码无规律特别乱，一定要慢慢仔细找到单词"amount" : 1,
只需要修改那个数字1就可以了，修改到10或20背后提灯的亮度足够用了，太大不知道会不会死机。
保存后关掉窗口进入游戏。

4.无跌落伤害
这次修改文件player.config，也是右键记事本打开，修改这个文件只对新建人物有效，也就是需要新开档
合理使用Ctrl+F快捷键可以轻松修改
了
"fallDamageFactor" : 改成0就免疫跌落伤害了

5.无限潜水和取暖
妈妈再也不怕我潜水着凉了，这个修改绷带也很纠结，改了以后有绷带不就无敌了，所以就往后放一放，改无限潜水和取暖，不废话
同上一弹文件
"breathDepletionRate" : 改成0就无限潜水了
"comfortRegen" : 烤火时的热量恢复率，烤火时才有效

6.燃料修改
无尽宇宙，任我游
法
Starbound\assets\items\generic\crafting\coalore.item
记事本打开coalore.item "fuelAmount" : 2 默许是1煤炭转2燃料

7.无限饥饿
一年吃一块肉，一块肉饱一年
饥饿度修改也是之前摔伤潜水那个文件
"foodDepletionRate" :改成0就不会饿了
好了这一弹结束

7.死亡无惩罚
让我再死一千年， 文件不变
"percentile" :死亡惩罚，0.3是掉30%的钱，改为0死掉就不会扣钱了，改成负数不能加钱，千万别试，我不是开玩笑，真的别改负数

8.床加速回血
路径是 Starbound\assets\objects\generic\woodenbed
文件名woodenbed.object依旧记事本打开，Ctrl+F查找
"amount" : 0.02
改成多少自己决定，修改完进游戏工作台做一张木床（由于只修改了木床的数据，所以只有木床加速回血），楼主身边没电脑，没测试，不过应该没问题

9.操作范围
我手长我自豪，月亮也能够得着
文件嘛，还是那一个，要新建人物的样子
"initialBeamGunRadius" : 物块和物质枪的操作距离，改成100基本上就能全屏操作了

10.钻石电钻的耐久，效率，工作范围
修改小福利这一弹是专门给没事做的毕业党的福利，修改钻石电钻的耐久，效率，工作范围，让他们很容易收集材料做豪宅~

路径:Starbound\assets\items\tools
这个文件diamonddrill.miningtool
依旧是右键记事本打开文件
耐久值"durability" : , 默认好像是3000
"tileDamage" :默认好像是3.7改成15.7或者18.7
blockRadius是范围，最大7，再大容易游戏崩溃
twoHanded后面改成true可以把钻子改成单持

11.修改皮革
今天的第10更，自从我的膝盖中了一箭，诶呀，到现在都还没好
路径：Starbound\assets\items\guns\test
文件：bow.gun（这是木弓的）steelbow.gun（铁弓的）
还是右键记事本打开
Ctrl+F查找
"powerProjectileTime" : [0.9, 1.1],
后面那个括号就是蓄力时间啦~改成[0.0 9.9],就OK啦~
还有那个必掉皮革的
路径：Starbound\assets\treasure
文件：hunting.TREASUREPOOLS
依旧右键记事本打开
查找到
[0.7 [ "alienmeat" ] ],
[0.3, [ "leather" ] ]
修改成
[0.0, [ "alienmeat" ] ],
[1.0, [ "leather" ] ]
完毕，之后用弓击杀小怪必掉皮革
9.9可能一只怪掉10个皮革，也可能游戏崩溃，交易把9.9换成1.0
