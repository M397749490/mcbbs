鹦鹉为1.12的新宠物，它可以在你停下的时候飞到你的肩膀上
此插件可以自定义鹦鹉什么时候在你肩膀上，什么时候飞下来

以下为默认设定
平时走路干活鹦鹉都不会脱离
如果你跑太快了就会脱离
往下跳超过2-3个方块时也会脱离
如果你潜行了也会脱离
如果你死了就会离开（你可以更改配置让它永远做你的朋友，死了都不会走）
受到伤害时会脱离
切换世界时会脱离（你也可以改配置让他不会丢）
玩家如果没有权限，则使用原版的机制

以下是楼主改的配置，不是默认的
  1. releaseParrots:
  2.   sneak: true
  3.   fall: true
  4.   glide: false
  5.   death: false
  6.   damage: true
  7.   teleport:
  8.     sameworld: false
  9.     netherportal: false
  10.     changeworld: false
复制代码
都是些简单的英文，不用我翻译了吧= =

丢到plugin文件夹重启服务器即可
然后是给权限
releaseParrots.sneak
releaseParrots.fall
releaseParrots.glide
releaseParrots.death
releaseParrots.damage
releaseParrots.worldchange

这个插件无需任何前置
