作者: 帕帕武    时间: 2020-8-16 23:08
config.yml里面有这条
你可以用worldguard来让玩家在无pvp区域里使用rpgitem
support:
  world_guard:
    enable: true
    force_refresh: false
    disable_in_no_pvp: true
    show_warning: true

或者你可以用权限组插件让玩家在那个世界没有使用权限

先给物品
/rpgitem permission 东西 rpgitem.use.权限
然后删除在那个世界的那条指令（记得开不同世界不同权限）
作者: 帕帕武    时间: 2020-8-16 23:12
config.yml中有
support:
  world_guard:
    enable: true
    force_refresh: false
    disable_in_no_pvp: true
    show_warning: true

所以你可以用worldguard来让玩家在无PVP的区域无法使用rpgitem

你还可以让玩家在某个世界没有权限使用
方法：
输入/rpgitem permission 东西名字 rpgitem.use.权限名字
然后给玩家那条负权限就可以了
（记得开不同世界不同权限）
