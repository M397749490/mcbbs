exe是编译之后的jar  没办法再加东西了
jar可以自定义后直接用批处理运行。以下内容用notepad另存为扩展名为bat的文件
  1. @ECHO OFF
  2. SET BINDIR=%~dp0
  3. CD /D "%BINDIR%"
  4. java -Xmx1024M -Xms1024M -jar minecraft_server.jar
  5. PAUSE
复制代码
或者命令行java -jar minecraft_server.jar命令
