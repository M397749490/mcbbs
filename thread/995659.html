W系列 | 交流群: 807182388
更新时间：2020年3月24日 (具体以 Github 最新 Commit 为准)

简介

   你可以通过 WPrefix 以高效简洁的 GUI 形式, 配置称号, 供玩家购买与选择称号.

使用强大的 EasyAPI formatter 系统, 高度自定义, 可以接入任何其他使用 EasyAPI formatter 的 插件, 完美贴合.

注意：WPrefix 使用 GPLv3 协议进行授权, 进行二次开发必须开源, 本贴禁止非授权转载.

GitHub 免费开源


介绍

安装

您可在 Release 中下载打包好的 .jar 文件
再将其放入 plugins 文件夹.
同时, 请安装依赖节的插件.

使用GUI

您可以通过 /wprefix gui 打开 GUI.

称号可以设置的内容有:

                                                   内容: 即称号显示出来的样子, 支持颜色符 (& §).

                                                   介绍: 商店中显示的说明.

                                                   位置: 左或右.

                                                   优先级: 谁更靠前, 数字越高越靠前.

                                                   能否堆叠: 即可否和其他称号一起使用.

                                                   药水效果: 支持在佩戴称号时给予 buff 填ID.

                                                   效果等级: 效果
