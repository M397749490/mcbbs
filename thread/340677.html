本工具只是一个过渡产物，针对对中文输入与将来forge的兼容性担忧的同学以及手残不知如何安装中文补丁的同学。

工具使用简单，占地面积也小w,只需要中文聊天的同学不妨来试一试
下面开始介绍啦~
使用方法：打开工具和程序，在游戏中按t键就可呼出文本框，输入中文后按回车键即可~
下载地址：http://pan.baidu.com/s/1pJ0Uydt
觉得好就回复下呗=w=
autohotkey源代码(还请大家多多指教)：
  1. ~t::
  2. IfWinActive,Minecraft 1.8
  3. {
  4. Gui, Add, Edit,x0 y0 w300 h40 vneirong,
  5. gui,show,x0 y0
  6. Loop
  7. {
  8. GetKeyState, state,enter, P
  9.   if state=D
  10.   {
  11.   GuiControlGet,neirong
  12.   Clipboard=%neirong%
  13.   gui,destroy
  14.   WinActivate,Minecraft 1.8
  15.   WinWaitActive,Minecraft 1.8
  16.   break
  17.   }
  18.   else
  19.   {
  20.   }
  21. }
  22. send,{ctrl down}
  23. send,{v down}
  24. sleep 100
  25. send,{ctrl up}
  26. send,{v up}
  27. send,{enter}
  28. }
  29. else
  30. {
  31. }
  32. Return
