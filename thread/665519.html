这个不算什么报错，关闭KC的自动更新就行了。具体操作：
将kcauldron.yml中的
  1. updatechecker:
  2.   quiet: false
  3.   symlinks: KCauldron.jar
  4.   enable: true
  5.   autorestart: false
  6.   autoinstall: false
复制代码

改为
  1. updatechecker:
  2.   quiet: true
  3.   symlinks: KCauldron.jar
  4.   enable: false
  5.   autorestart: false
  6.   autoinstall: false
复制代码

即可。
