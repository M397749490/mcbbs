ZNpcs
介绍
船新的NPC插件
它支持BungeeCord
同样支持PlaceholderAPI
它具有自己的API和NPC
它无需公民插件作为前置 放入插件文件夹即可

作者的话
我无法找到更好的用于服务器的NPC插件了
找到的也是旧版 不在更新了/更新过慢的
所以它来了 完全免费不需要付钱

功能
可以使用指令和服务器(BC)的操作
轻巧，插件最大占用存储仅为70KB
这个插件优化不错
实时更新,更改任何东西无需重载插件
100％可自定义，该插件有messages.yml

指令
/znpcs action <server:cmd> <run>
给NPC添加指令
/znpcs create <id> <皮肤> <名字>
创建一个NPC
/znpcs delete <id>
删除一个NPC
/znpcs equip <hand:helmet:chestplate:leggings:boots>
给NPC上装备 hand手 helmet头盔 chestplate盔甲 leggings护腿  boots鞋子
/znpcs lines <信息>
给NPC添加文字信息
/znpcs move <id>
移动NPC到你脚下
/znpcs toggle <holo:name:look:mirror:glow>
更改npc holo全息 name名字 look看向玩家  mirror视角(v0.7) glow发光(v0.5)


/znpcs skin id <皮肤>
给已有的npc换肤
