EssentialsAntiBuild
在GroupManager\worlds\[世界文件夹]\groups.yml文件中
你的默认权限组(一般服务器是Builder)下面permissions下添加
- essentials.build.* (添加建造权限)
- -essentials.build.break.<id>:<data> (删除挖指定物品的权限)
然后把builder的info的build:后面改成false
就可以禁止玩家在此世界挖这种矿物
除此之外还有 原理是同样的
None        essentials.build.break.<id>[:datavalue]        允许破坏一个方块
essentials.build.craft.<id>[:datavalue]        允许合成一个物品
essentials.build.drop.<id>[:datavalue]        允许掉落一个物品
essentials.build.interact.<id>[:datavalue]        允许与一个方块或者物品互动
essentials.build.pickup.<id>[:datavalue]        允许收集一个物品
essentials.build.place.<id>[:datavalue]        允许摆放一个方块

抱歉权限组分离方式给错了
到GroupManager插件配置文件夹下打开config.yml
在最后的mirrors下添加一个子项为你的世界的名字即可
如需要隔离的世界为New World 就改成这样
  mirrors
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
        New World:

文件中的解释:
        # 多世界设置,世界列表中子世界将参照父世界的设置.
        # 第一个世界 'world' 是主世界名称
        # 子世界 'world_nether' 和 'world_the_end' 将会
        # 与父世界使用相同的玩家/用户组文件.
        # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
        # all_unnamed_worlds将会使用所有未定义的世界
