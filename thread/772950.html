即可得到一个很棒的球。





算法很简单，对rotx和roty循环即可，然后添加一个判断用于删除过近的雪球。
sphere/main.mcfunction
  1. scoreboard objectives add rotx dummy
  2. scoreboard objectives add roty dummy
  3. scoreboard players set #stepx rotx 5
  4. scoreboard players set #stepy roty 5

  6. kill @e[type=snowball]
  7. summon minecraft:snowball ~ ~ ~ {NoGravity:1,Tags:["as"]}
  8. execute as @e[tag=as] at @s run function sphere:rot
复制代码


sphere/rot.mcfunction
  1. scoreboard players set @s rotx 0
  2. execute store result entity @s Rotation[0] float 1 run scoreboard players get @s rotx

  4. scoreboard players operation @s roty += #stepy roty
  5. execute store result entity @s Rotation[1] float 1 run scoreboard players get @s roty

  7. execute as @s at @s run function sphere:rotx
  8. execute as @s[scores={roty=..180}] at @s run function sphere:rot
复制代码


sphere/rotx.mcfunction
  1. summon snowball ^ ^ ^10 {NoGravity:1,Tags:["a"]}
  2. execute as @e[tag=a] at @s if entity @e[distance=..0.5,tag=!a] run kill @s
  3. tag @e[tag=a] remove a

  5. summon snowball ^ ^ ^-10 {NoGravity:1,Tags:["a"]}
  6. execute as @e[tag=a] at @s if entity @e[distance=..0.5,tag=!a] run kill @s
  7. tag @e[tag=a] remove a

  9. scoreboard players operation @s rotx += #stepx rotx
  10. execute store result entity @s Rotation[0] float 1 run scoreboard players get @s rotx
  11. execute as @s[scores={rotx=..359}] at @s run function sphere:rotx
