欧拉角

实际上这就是个求欧拉角的问题，只不过由于MC的关系，实体的坐标轴和世界上方块的坐标轴并不一样，y方向和z方向是反过来的，导致原本比较简单的问题变得复杂起来。不过，这里为了方便讨论，一律以MC的方块坐标轴为准，也就是x轴朝东，y轴朝天，z轴朝南。

然后通过修改盔甲架的三个方位角，也就是NBT中Head的三个参数，我们可以注意到是这个样子的：

  • 第一个参数代表头部围绕x轴逆时针的旋转角度（360度为一周）
  • 第二个参数代表头部围绕y轴顺时针的旋转角度（360度为一周）
  • 第三个参数代表头部围绕z轴顺时针的旋转角度（360度为一周）

我们注意到，后两个参数和正常的坐标系里逆时针为正的约定不一致，所以在后续计算时要加上负号取相反数。在下面的内容中，如无旋转方向的特殊声明，以上面的约定为准。

当然了，在三维空间里我们经常分不清顺时针和逆时针，这里有一个简单的办法：像竖大拇指一样掏出你的右手，把大拇指和坐标轴的正方向重合，那么剩下四个手指旋转的方向就是绕该轴逆时针的方向，如果换成左手，那么就是顺时针，相信读者只要学过中学物理，都应该玩过这套把戏。

此外，旋转的次序是先x后y再z，也就是xyz顺规。为什么要强调旋转的次序？因为不同的次序导致的旋转结果是不一样的，这个大家仔细想想就很容易明白了。

而原帖希望转换到这个xyz顺规的旋转方式是什么样子呢？
输入的ABC是这个部件的木杆指向的方向 （比如1 1 1或者2 2 2 是沿着体对角线方向 -1 -1 -1 是和那俩相反的方向）t是指向这个方向之后再绕着轴旋转的弧度。

一种可行的旋转方式如下：

  • 先让脑袋对应的那根木杆绕y轴旋转t
  • 再让木杆绕x轴逆时针旋转一个角度theta_1
  • 再让木杆绕y轴顺时针旋转一个角度theta_2，使木杆正对着(A, B, C)的方向

同理，这三个方位角同样被称为欧拉角，只不过使用的是yxy顺规。

至此，问题演变为：把yxy顺规的三个欧拉角表示的旋转，用xyz顺规的三个欧拉角表示。

在可行性这一点，我们倒是不用担心表示不出来，因为数学上已经证明，对于任意的旋转，都可以使用三个欧拉角表示。


线性变换

对于线性代数熟悉的读者可以跳过这一部分。

为了方便理解，我们先从一个二维的例子开始：对于坐标点(x, y)，求其绕原点逆时针旋转theta角后的结果。

这个明显是送分题嘛。我们令
  1. x = r*cos(phi)
  2. y = r*sin(phi)
复制代码
那么旋转后的结果就是
  1. x' = r*cos(phi+theta) = r*cos(phi)*cos(theta)-r*sin(phi)*sin(theta) = x*cos(theta)-y*sin(theta)
  2. y' = r*sin(phi+theta) = r*sin(phi)*cos(theta)+r*cos(phi)*sin(theta) = x*sin(theta)+y*cos(theta)
复制代码

现在直接把问题放到三维：对于坐标点(x, y, z)，求其绕z轴逆时针旋转theta角后的结果。

这个也很明显是送分题嘛。绕z轴旋转自然z坐标不会动了，x坐标和y坐标和上面描述的是一样的。
基于原点还有什么操作比较有用呢？
  1. 绕z轴逆时针旋转：(x, y, z) => (x*cos(theta)-y*sin(theta), x*sin(theta)+y*cos(theta), z)
  2. 沿z轴放大两倍：(x, y, z) => (x, y, 2z)
  3. 沿x轴中心对称：(x, y, z) => (x, -y, -z)
  4. 把上面两个操作复合一下：(x, y, z) => (x, -y, -2z)

我们可以注意到，这些变换都有着以下的形式（a-i都是常数）：
  1. x => a*x+b*y+c*z
  2. y => d*x+e*y+f*z
  3. z => g*x+h*y+i*z

变换后的坐标都只包含x/y/z分别和一个整数的乘积的和。这种变换我们称之为线性变换。
如果我们不想考虑坐标而只考虑变换这件事，我们可以单独变换所需要的九个数提出来，排成一张3x3的表：
  1. a b c
  2. d e f
  3. g h i

我们称这张表为一个3x3的矩阵。

把两个矩阵代表的变换复合的过程，我们称其为矩阵的乘法。

对于矩阵乘法，百度百科上的定义已经够清楚了，这里只是想让读者知道，变换的复合可以使用矩阵乘法的方式表示。

现在我们把对于三个坐标轴旋转的矩阵写出来：

绕x轴逆时针旋转theta：
  1.                  1                0                0
  2.                  0  math.cos(theta) -math.sin(theta)
  3.                  0  math.sin(theta)  math.cos(theta)

绕y轴顺时针旋转theta：
  1.    math.cos(theta)                0 -math.sin(theta)
  2.                  0                1                0
  3.    math.sin(theta)                0  math.cos(theta)

绕z轴顺时针旋转theta：
  1.    math.cos(theta)  math.sin(theta)                0
  2.   -math.sin(theta)  math.cos(theta)                0
  3.                  0                0                1

很明显，如果两种旋转是等价的，那么它们对应的矩阵中的九个数，应该是一模一样的。

当然啦，这个式子很复杂，但是只有左下角的五个元素是需要关心的，我们把它和已知的矩阵一对应，就可以很容易地把结果求出来了。

这是最后的代码。使用了numpy简化了矩阵运算，可读性应该比原帖好一些：
  1. #!/usr/bin/python3

  3. import math, numpy

  5. def calculate_armorstand_rotation(a, b, c, theta):

  7.     def matrix_rotate_x(theta):
  8.         return numpy.matrix([[               1,                0,                0],
  9.                              [               0,  math.cos(theta), -math.sin(theta)],
  10.                              [               0,  math.sin(theta),  math.cos(theta)]])

  12.     def matrix_rotate_y(theta):
  13.         return numpy.matrix([[ math.cos(theta),                0, -math.sin(theta)],
  14.                              [               0,                1,                0],
  15.                              [ math.sin(theta),                0,  math.cos(theta)]])

  17.     def matrix_rotate_z(theta):
  18.         return numpy.matrix([[ math.cos(theta),  math.sin(theta),                0],
  19.                              [-math.sin(theta),  math.cos(theta),                0],
  20.                              [               0,                0,                1]])

  22.     def norm(x, y):
  23.         return math.sqrt(x * x + y * y)

  25.     theta_0, theta_1, theta_2 = math.radians(theta), math.atan2(norm(a, c), b), math.atan2(-a, c)

  27.     matrix = matrix_rotate_y(theta_2) * matrix_rotate_x(theta_1) * matrix_rotate_y(theta_0)
  28.     m11, m21, m31, m32, m33 = matrix[0, 0], matrix[1, 0], matrix[2, 0], matrix[2, 1], matrix[2, 2]
  29.    
  30.     z_rotation = math.atan2(-m21, m11)
  31.     y_rotation = math.atan2(2 * m31, norm(m21, m11) + norm(m32, m33))
  32.     x_rotation = math.atan2(m32, m33)
  33.    
  34.     return math.degrees(x_rotation), math.degrees(y_rotation), math.degrees(z_rotation)

  36. if __name__ == '__main__':
  37.     a, b, c, theta = eval(input())
  38.     result = calculate_armorstand_rotation(a, b, c, theta)
  39.     print('/summon Armor_Stand ~0 ~1 ~0 {Pose:{Head:[%.8fF,%.8fF,%.8fF]}}' % result)
