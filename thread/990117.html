多世界的话你可以 mv create zy normal  这个是创建一个世界  或者 你把要弄得主世界手动加入world 在world 创建一个新的文件夹比如说 123然后把新世界里面的东西放进去  然后 重启服务器 进入服务器后 输入mv import 123 normal 即可  然后指令 setspawn Builder .setspawn default 最后输入mv setspawn 即可
