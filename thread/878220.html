解锁背包栏位这个在3#的链接所指向的帖子里有所提及.
http://www.mcbbs.net/thread-726323-1-1.html

在帖子附带的汉化后的config.yml里的100行后开始(该config已过时，仅为注释示例，请勿直接复制--该帖原话):
  1. slots:
  2.   # 是否启用背包锁定
  3.   enabled: true
  4.   # 下面这两项别改！别改！别改！
  5.   locked: DIAMOND_HOE:19
  6.   buyable: DIAMOND_HOE:18
  7.   # 除了快捷槽以外 背包内初始有几格是免费的
  8.   free: 2
  9.   # 解锁背包槽需要花费金钱
  10.   money:
  11.     enabled: true
  12.     # 第一行每格解锁花费1000，第二行2000，第三行3000
  13.     cost:
  14.       line1: 1000
  15.       line2: 2000
  16.       line3: 3000
  17.   # 解锁背包槽需要等级
  18.   level:
  19.     enabled: true
  20.     # 是否扣除相应等级
  21.     spend: false
  22.     # 解锁每行需要的等级
  23.     required:
  24.       line1: 20
  25.       line2: 30
  26.       line3: 40
