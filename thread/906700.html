CHANGES IN 19W34A
在19w34a的更改

（以下译名为暂定译名）

  • Added Bees
  • 添加了蜜蜂
  • Added Bee Nests and Hives
  • 添加了蜂窝和蜂箱
  • Added Honeycomb
  • 添加了蜂房
  • Added some dispenser functionality
  • 给发射器增加了一些功能
  • Minecraft:Java Edition new requires OpenGL 2.0
  • Minecraft：Java版现在必须要使用OpenGL 2.0了（译者注：之前是可以兼容支持OpenGL 2.0以下的显卡的）
  • New function for loot tables called copy_state
  • 添加了用于战利品表的新函数 copy_state
  • Fix bugs
  • 修复了一些bug
