抱歉，悬赏贴发布10小时后才看到

sk版本2.1以下与2.2以上的loop语法有些微差别
高版本更加注重的是比较

使用loop语句可能是比较正常且普遍的做法

很不巧，我不知道铁傀儡在sk里面的名字，所以我注册一个指令来看看到底是叫什么
由于不会有什么越权的情况，我不添加使用权限了，请在使用后直接删除即可。
command /LoopMyLovelyEntity:
    trigger:
        loop entities in radius 10 around player:
            send  "%loop-value%"


输入这个指令以后，将会输出你身边10格的生物名
你需要造一个铁傀儡，然后就能通过这个指令看到铁傀儡的名字了
当然请不要忘记，你也是一个生物，所以输出的第一个肯定是"你"的ID
(麻烦让铁傀儡在呆你周围10格内)

可能是  iron golem ？ 我猜的

我举一个例子吧，把指令换成触发器
on break of bedrock:
#破坏基岩时
    loop entities in radius 10 around event-block:
#这里的event-block是破坏的基岩
        if "%loop-value%" is "iron golem":
#这个iron golem是我猜的
            send "你周围10格内有铁傀儡"
            exit loop
#当判断到有铁傀儡就退出loop，而不是loop所有范围内的生物后自然结束，这有助性能

方块同理
on break of bedrock:
    loop blocks in radius 10 around event-block:
        if "%loop-value%" is "dirt":
            send "你周围10格内有泥土"
            exit loop

你的要求？
on break of bedrock:
    loop blocks in radius 10 around event-block:
        if "%loop-value%" is "dirt":
            add 1 to {_ThisBreak}
            if {_ThisBreak} is 10:
                send "完蛋了，10个泥土了"
                exit loop

#{_巴拉巴拉}前的_代表这是一个可爱的临时变量，仅在该事件中使用，在使用后立刻销毁
#当然gc就是销毁之后的后事了
#这货比private还private，这事件外的完全无法"访问"
#你也不必担心有两个玩家一起在用的问题，虽然我不确定实现的原理是什么，但是肯定是不用担心的

返回false的话，写一个elif就好了，欸 话说有elif语句么，写成else if吧

我主要就是死在 如何检测特定实体及实体数量是否达标 的问题上，其他都OK
而且这里的 %loop-value% 应该是 Iron Golems，我也不知道为什么自带s，单填Iron Golem是无效的，无法被检测到
我也曾在铁傀儡的ID这里卡着，最后是通过输出检测值才知道要改成 Iron Golems，不管是一个还是多个都应如此
至于如此写法：

on break of bedrock:
    loop blocks in radius 10 around event-block:
        if "%loop-value%" is "dirt":
            add 1 to {_ThisBreak}
            if {_ThisBreak} is 10:
                send "完蛋了，10个泥土了"
                exit loop

直接使用并不奏效，貌似2.3版本的 on break of xxx 失效了？（可能是后续版本修复但我没更新233）
而且 dirt 应该是要改成 dirt block，否则也不会起效。

经过修改后能生效的写法是：

on break:

        if event-block is bedrock:

                loop blocks in radius 10 around event-block:
        
                        if "%loop-block%" is "Dirt block":
                        
                                add 1 to {_ThisBreak}
                                
                                if {_ThisBreak} is 10:
                                
                                        send "完蛋了，10个泥土了"
                                       
                                        exit loop

（每行中间习惯加空格了233，方便自己阅读）
至于实体的话可以直接照抄，如：

on break:

        if event-block is bedrock:

                loop entities in radius 10 around event-block:
        
                        if "%loop-entity%" is "Villager":
                        
                                add 1 to {_ThisBreak}
                                
                                if {_ThisBreak} is 10:
                                
                                        send "完蛋了，10个村民了"
                                       
                                        exit loop
