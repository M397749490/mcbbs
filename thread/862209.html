插件介绍
一,前言
最近我和我好兄弟安生被频繁骚扰，骚扰的内容就是能不能安排个称号sk站内的有点花里胡哨不太想用，所以这个称号脚本就诞生了qwq
 原作者小明,完善以及修复安生

二,特性
1.GUI称号：
在gui显示拥有称号和未拥有称号，点击拥有称号即可携带。简单方便
2.指令简洁:
不要烦恼不会用这个称号脚本，你只要输入/prefix 就可以轻松操作这个脚本
3.变量：
可以把称号变量设置到各种聊天插件里和计分板里
三,命令(图片形式)
普通玩家
/prefix gui (页数 1-3) - 打开称号库GUI
管理员
/prefix add (称号) (称号描述) - 添加称号到称号库中（称号描述可以换行比如:测试_ 测试'_'就是换行符）
/prefix set (编号) (新称号) (新描述) - 更改称号以及描述
/prefix give (称号) (玩家) - 给予玩家称号库内称号
/prefix list (页数 1-15) - 打开称号编号列表
/prefix delete (称号) - 删除称号库指定称号
/prefix remove (称号) (玩家) - 删除玩家指定称号
四,权限
prefix.add     添加称号权限
prefix.set     设置称号权限
prefix.give    给予称号权限
prefix.gui     打开称号库权限（需要给玩家）
prefix.list    打开称号编号列表权限
prefix.delete  删除称号库称号权限
prefix.remove  删除玩家称号权限
五,变量
%prefix_name% 称号变量
%prefix_number% 称号总数变量
%prefix_player% 玩家拥有称号数量变量
