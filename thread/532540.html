作者原文：
Welcome to Shaders Configurator !    HOW TO USE:  To use it, put the jar where you want and double-blick on it to open it. It runs with java ;)  Actually, it's not a mod but a tool.     This software works on Windows, mac and linux, what's much better ! :D   With this tool, you can edit shaders but not all because it depends on the code. if the author has specific methods, it won't work... So you have to test with some shaders.   But it works with my shaders ;) You can find them there: http://www.minecraft-france.fr/mod-docteurdreads-shaders-1-7-2/    Thanks a lot ! :D


使用指南：
这不是一个MOD，而是一个编辑器。所以它不需要任何Forge之类的API。它只需要JAVA。打开一个光影包（import shaders），自定义想要的效果，之后保存（save shaders），就完成啦。（位置随意）下载地址：
http://www.planetminecraft.com/mod/shaders-configurator/（需翻墙）
