Particle Effect Combinator
粒子特效组合器


粒子特效组合器（ParticleEffectCombinator ，简称PEC）是一个理论上可以同时作用于Sponge 1.10-1.12等服务端的Sponge插件。

事情起因

没啥原因，就是我想写一个基本不需要编程的基于Sponge的粒子特效插件，没了。

使用方法

首先，你要扔进mods/目录底下，然后启动服务端。

启动后会出现一个名为config/pec/effects的目录，所有可以调用的粒子特效都在里头，均应为以.conf为后缀的HOCON格式文件。

比如说你想画个半径为2.5格的球，这个配置文件格式应该长这样：

  1. pec {
  2.   type = sphere
  3.   radius = 2.5
  4. }
复制代码

然后你把它放到名为sphere.conf的文件里，启动服务端，运行一下/pec display sphere命令，你就能看到一个光滑圆润的球出现在你旁边了。

但是这个球球心的位置在你的脚下，你需要平移一下。你可以把配置文件改成这样：

  1. pec {
  2.   type = offset
  3.   interpolation = 1.5
  4.   child = {
  5.     type = sphere
  6.     radius = 2.5
  7.   }
  8. }
复制代码

我们首先定义了一个偏移（Offset），然后通过设置interpolation代表偏移的量为1.5格，然后child代表偏移的究竟是什么。你还可以定义orientation决定偏移的方向，默认方向是(0, 1, 0)，也就是向y轴正方向，在游戏中向上偏移。

然后你想要让这个球随着时间流逝以渐变的形式一点点出现。你可以这么改配置文件：

  1. pec {
  2.   type = offset
  3.   interpolation = 1.5
  4.   child = {
  5.     type = sphere
  6.     radius = 2.5
  7.     child {
  8.       type = time-offset
  9.       interpolation = { 0 = 0, 1 = 20 }
  10.     }
  11.   }
  12. }
复制代码

现在开始出现的情况稍微有一点费解了——我们指定了一个球的child，这是怎么一回事？

一个球的child是什么？其实就是组成这个球的每一个粒子。我们只要通过控制每一个粒子的出现时间，就可以让整个球的出现方式渐变化了。

time-offset就是用于调整延时的——我们通过设置interpolation修改它的延时。Interpolation的中文翻译是插值，相当于各位中学数学课上手绘函数图像的连线阶段——根据几个特定的点把整个函数图像画出来。

interpolation = { 0 = 0, 1 = 20 }规定了这个函数当自变量为0时的值为0，自变量为1的时候为20，那么自变量为0.5的时候自然就是10，自变量为0.75的时候自然就是15，依此类推。这个函数的图像是一条直线。

实际上，PEC还规定了一种简写方式：interpolation = 5等价于interpolation = { 0 = 5, 1 = 5 }，也就是常数值函数，这种方式刚刚我们已经用到过了。

PEC还规定，球面底部的点对应自变量为0的情况，顶部的点对应1。也就是说，最先出现的是底部的点，然后过了20tick也就是大概1s后顶部的点最后出现。也就是说，会观察到下面的现象：



最后说一下PEC中很可能会用到的东西：表达式。

可以这么说，只要出现数字的地方，都可以替换成表达式，比如说interpolation = 1.5，你可以写成interpolation = 3/2，可以写成interpolation = 1-cos(2pi/3)，可以写成啥都行，只要它是个格式正确的表达式。不过需要注意的一点是，HOCON中如果要用到加号和乘号，需要在两边加上引号，比如说：interpolation = 1+1/2是不行的，你必须写成interpolation = "1+1/2"。

你还可以定义一些constant，然后在表达式里引用它们，比如说：

  1. pec {
  2.   type = offset
  3.   constant {
  4.     s = 25pi
  5.     r = sqrt(s/(4pi))
  6.   }
  7.   interpolation = 3/2
  8.   child = {
  9.     type = sphere
  10.     radius = r
  11.     child {
  12.       type = time-offset
  13.       interpolation = { 0 = 0, 1 = 20 }
  14.     }
  15.   }
  16. }
复制代码

我们定义了s，紧接着我们定义的r就用到了s，然后我们在球的radius里引用到了r。

命令权限

所有命令都以/pec开头。

可用命令如下：

  • /pec version
    用来查看版本信息
  • /pec list
    用于列出所有可用的粒子特效
  • /pec reload
    用于重新加载所有配置文件中的粒子特效（Sponge自带的reload系统也可以）
  • /pec display <effect-name>
    用于释放粒子特效
    • /pec display <effect-name>
      本身代表在玩家脚下位置释放粒子特效给所有玩家
    • /pec display <effect-name> for zzzz_ustc
      代表释放的粒子特效只给zzzz_ustc看（for和at可以一起使用）
    • /pec display <effect-name> at 233 33 333
      代表在(233, 33, 333)处释放粒子特效（for和at可以一起使用）


可配置权限如下：

  • pec
    代表这个插件需要用到的所有权限
  • pec.list
    代表执行/pec list命令需要用到的权限
  • pec.reload
    代表执行/pec reload命令需要用到的权限
  • pec.send.<effect-name>
    代表执行/pec display <effect-name>命令需要用到的权限
