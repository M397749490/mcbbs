HoloBroadcast
花里胡哨没卵用的全息公告

★》简 介《★
HoloBroadcast可以向玩家发送全息图公告信息
且支持声效和粒子效果甚至是文字动画效果
它几乎是当前第一款全息图公告插件,且内容可以跟随玩家视角平滑移动
你可以在游戏的HB设置界面中任意切换是否接收自动公告
你也可以将全息公告改为发送在聊天栏中的公告
支持CatServer和Mohist

★》功能《★

  • 向全体玩家发送全息公告
  • 给指定玩家发送全息消息
  • 玩家可以在游戏内更改自己的全息消息接收设置
  • 当玩家触发特定事件时给玩家发送全息消息
  • 全息消息支持动画效果(变量)
  • 支持在全息公告上显示悬浮物品
  • 可设置禁止发送全息消息的世界
  • 接收全息消息时给玩家发送声效
  • 战斗标签系统(可设置玩家在战斗时是否接收全息消息)
  • 模板功能(仅使用一个模板ID指令即可给玩家发送多行全息消息)
  • 自动公告系统
  • 全息消息可附加粒子效果
  • 支持RGB颜色代码(&<#ffffff>)(仅1.16+)
  • 极高的可配置性
  • 插件开发者API
  • 支持PlaceHolderAPI和MVdWPlaceHolderAPI
  • 支持PlotSquared(玩家进入地皮时发送全息消息)
  • 支持Factions
  • 支持多个Minecraft版本
  • 异步运行,性能高效

★》指令/权限/变量《★
因游戏内指令无法汉化,请各位服主查看这里的指令帮助,本插件指令大部分为管理员使用

  • /hb broadcast [内容] - 给全息在线玩家发送一条全息公告
  • /hb setting - 打开个人全息消息接收设置(适合玩家使用的指令)
  • /hb reload 重载插件
  • /hb broadcasttemplate [模板ID] <参数>- 给全体在线玩家发送一条预定模板的全息公告
  • /hb clear - 清除当前正在发给你的全息消息(酌情给予玩家使用权限)
  • /hb sendduration [玩家名] [持续时间(单位tick)] [内容] - 给指定玩家发送指定时间的全息消息
  • /hb send [内容] - 给指定玩家发送一条全息消息
  • /hb sendtemplate [玩家名] [模板ID] <参数> - 给指定玩家发送指定时间的预定模板全息消息

  • holobroadcast.help - 使用 /hb help 指令
  • holobroadcast.settings - 使用 /hb help 指令
  • holobroadcast.send - 使用 /hb send 指令
  • holobroadcast.senddurationmessage - 使用 /hb sendduration 指令
  • holobroadcast.sendtemplate - 使用 /hb sendtemplate 指令
  • holobroadcast.clear - 使用 /hb clear 指令
  • holobroadcast.clear.other - 使用 /hb clear <玩家> 指令
  • holobroadcast.reload - 使用/hb reload 指令
  • holobroadcast.blankline - 使用 %bl% 变量
  • holobroadcast.newline - 使用 %nl% 变量
  • holobroadcast.item - 使用 %item_XXXX% 变量
  • holobroadcast.sound - 使用 %sound_x_XXXXX,x,x% 变量
  • holobroadcast.particle - 使用 %particle_x_XXXXX,x% 变量


变量请在全息消息内插入

  • %nl% - 换行
  • %bl% - 空出一行
  • %item_材质英文ID% / %item_材质英文ID:子ID%  - 显示悬浮物品
  • %animation_动画ID% - 显示预定的动画效果
  • %sound_频率(tick)_声效ID,音量,音调% - 发送全息消息时每隔多少tick播放一次音效
  • %particle_频率(tick)_粒子ID,粒子数量% - 发送全息消息时每隔多少tick显示一次粒子效果
  • %template_模板ID% - 显示特定模板的内容
  • (但如果不是broadcasttemplate或sendtemplate指令则%argument_XX%变量无效)
  • 支持placeholder的变量
  • 可使用RGB颜色代码&<#HEXCOLOR>
