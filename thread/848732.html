介绍 · Introduction
这款插件可以让你输入指令来给其他玩家来献血
指令

  • /blood - 帮助页面
  • /blood <玩家名>
  • /blood check <玩家名>
  • /blood set <玩家名><献血数>
权限

  • blood.use -  "/blood" 和 "/blood <玩家名>"
  • blood.check -  "/blood check <玩家名>"
  • blood.set -  "/blood set <玩家名><献血数>"



特点
  • 缩写指令 /bd (/bd player)
  • 查看目标的血量!
  • 可自定义消息前缀!
  • 设置玩家血量  (需权限)
