TabooLib 了解一下？

  1. BOOK-TEXT:
  2. # 书本类型注释
  3. - '[book]'
  4. - '书本单行文本'
  5. - '&4书本单行文本'
  6. - '&4&l书本单行文本'
  7. # 翻页注释。
  8. - ''
  9. - '<@1>'
  10. - '<@1> | <@1> 单行重复变量'
  11. - '<@1> | <@2> 单行不同变量'
  12. # 书本内容变量，注意！所有变量必须写到 [book] 类型底部
  13. # 因为一旦检测到 "@option" 这几个关键字，便会停止书本内容的检测。
  14. - '@option:1'
  15. - '    text: 文本'
  16. - '    command: /say 执行命令1'
  17. - '    showtext: 显示文本1'
  18. - '@option:2'
  19. - '    text: 测试'
  20. - '    command: /say 执行命令2'
  21. - '    showtext: 显示文本2'
