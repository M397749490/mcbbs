What can The F key do
客户端的 F 键能玩出什么花样？


这个插件是什么？
自从 1.9 出了双持功能以后，你就可以通过 F 键来将物品交换左右手，而对于我这种喜欢玩红石和建筑的人来说，这个功能非常鸡肋。
那么我也不能让它闲着，有什么办法可以利用起来呢？这个插件就是一个例子。
创意来自 FCommand 插件，但是这个插件功能太少，因此我就想着自己重写一个，于是就有了这个作品。
理论上支持 1.9+ 的所有版本，如果有不支持的版本请通过回复告诉我。
至于为啥叫 WTF 呢……
大概是因为我玩了两天 GTA5，天天街上飙车到处撞……然后路人 NPC 就会大喊 WTF……所以就有了这个名字
这是个粗鄙之语，小孩子不要学


有什么功能呢？
  • 支持按下 F 执行指定命令
  • 支持潜行按下 F 执行指定命令
  • 支持抬头按下 F 执行指定命令（抬头角度 > 80°）
  • 支持低头按下 F 执行指定命令（低头角度 > 80°）
  • 支持 PlaceholderAPI 变量
  • 支持设置按键冷却时间
  • 可以设置特定操作不影响双持切换物品


如何使用这个插件？
  • 首先下载 WTF.jar 》https://cdn.zerodream.net/assets/WTF.jar
  • 丢进服务端的 plugins 文件夹
  • 启动或重启服务器，也可以用 PlugMan / Yum 执行载入插件
  • 编辑 plugins/WTF/config.yml，根据提示增加你的命令
  • 保存，输入 /wtf reload 重载配置


权限列表
默认给下面这两个权限就行了
  1. wtf.use      给普通玩家的权限，可以使用所有功能
  2. wtf.admin  给管理员的权限，可以重载配置文件
复制代码
如果你想单独设置每个功能的权限，请看下面
  1. wtf.normalf      正常按下 F
  2. wtf.sneakingf   潜行时按下 F
  3. wtf.lookupf      抬头时按下 F
  4. wtf.lookdownf  低头时按下 F
复制代码

PlaceholderAPI 变量
支持使用 PlaceholderAPI 变量，例如 %player_name%
如果服务器安装了 PlaceholderAPI 插件，相关功能会自动启动。


多条命令
支持同时执行多条命令，每条命令用英文分号 ; 隔开，如果命令内容本身带有分号，请用 %3B 替换


配置文件
以下是参考用的配置文件
  1. # What can the F key do?
  2. # 支持 PlaceholderAPI 变量，需要安装该插件才能使用
  3. # 支持多条命令，用英文分号 ; 隔开，如果命令中含有分号，请用 %3B 代替
  4. # 如果设置为 "" 即留空，将不会执行命令，同时也不会影响双持切换物品
  5. # 当正常按下 F 时
  6. NormalF: "say %player_name% 牛逼！;say 我是第二条命令"
  7. # 当潜行按下 F 时
  8. SneakingF: "say 潜行按下 F"
  9. # 当抬头按下 F 时
  10. LookUpF: "say 抬头按下 F"
  11. # 当低头按下 F 时
  12. LookDownF: "say 低头按下 F"
  13. # 需要间隔多久才能按一次
  14. Delay: 5
  15. # 按太快的时候提示内容，也支持 PlaceholderAPI
  16. TooFast: "&c[&6WTF&c] &e按这么快想累死我呀！"
