1./testfor @p[score_objective_min=10] objective指变量名称
2.按照你这个来看判据使用totalkillCount更合适
/scoreboard objectives add kill totalkillCount

/effect @a[score_kill_min=1] minecraft:instant_health 1 0
重置分数
/scoreboard players set @a kill 0
