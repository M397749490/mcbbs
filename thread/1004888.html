插件特点
  • 高度优化
  • 1.8 PvP
  • 老版本工具伤害
  • 老版本武器伤害
  • 老版本玩家重生
  • 禁用特定物品的合成
  • 金苹果冷却
  • 改进战斗（修复）
  • 禁用弓冲击(对于自己)
  • 老版本锋利伤害
  • 禁止使用横扫
  • 禁止玩家转动展示框
  • 分世界设置
  • 非常方便的gui界面
  • 支持反作弊
  • 支持重载
  • 每一点都是可以配置的
配置文件（不要直接复制，此文件不全[泥潭特性 给我吃了一大截]）
  1. settings:
  2. # 是否希望插件在每次启动时检查更新？
  3.   check_for_updates: true
  4.   # 大幅度提高性能，但是不建议经常使用。
  5.   async: false
  6.   # 当事件触发时，您想在游戏中接收其他信息吗？（debug）
  7.   # 如果你想通过我们的网络向我报告一个bug，这非常有用。
  8.   developer_mode: false
  9. combat:
  10.   settings:
  11.     #您想让您的服务器使用旧的PvP吗？
  12.     old_pvp: true
  13.     # 你想使用 1.8 的武器的伤害吗？
  14.     old_weapon_damage: true
  15.     # 你想使用 1.8 的工具的伤害吗？
  16.     old_tool_damage: true
  17.     # 你想使用 1.8 的锋利的伤害吗？
  18.     old_sharpness: true
  19.     # 是否要禁用横扫攻击？
  20.     disable_sweep_attacks: true
  21.     # 你想让玩家不能通过弓攻击自己吗？
  22.     disable_arrow_boost: true
  23.     # 您想使用 1.8 的重生吗？
  24.     old_player_regen: true
  25.     # 如果你不想禁用这些世界
  26.     # （禁用世界）<-以上设置不会应用于这些世界。
  27.     disabled_worlds:
  28.    - example_world

  30. # 你想让吃金苹果有冷却吗？
  31. # 冷却单位 秒
  32. golden_apple_cooldown:
  33.   golden_apple:
  34.     enabled: true
  35.     cooldown: 10
复制代码
命令
  1. - /CombatPlus Reload (重载插件)
  2. - /CombatPlus Menu (打开此插件的 gui 菜单)
复制代码
权限
  1. -cp.admin（允许使用所有管理命令）
  2. -cp.bypass*（绕过所有内容）
  3. -cp.bypass.gapple（绕过金苹果冷却）
  4. -cp.bypass.items（绕过已禁用的物品制作）
  5. -cp.bypass.rotate（绕过物品展示框的禁用旋转）
  6. -cp.bypass.offhand（绕过禁用的副手选项）
  7. -cp.bypass.bowboost（绕过禁用的使用弓箭自我伤害选项）
