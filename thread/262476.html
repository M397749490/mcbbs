介绍
这个插件可以显示你对怪物／玩家的伤害，这个伤害是显示在游戏里的并不是在聊天信息，这类似RPG一样


指令 & 权限
指令权限描述
/dh-显示关于这个插件的作者于信息
/dh helpdamageindicators.admin显示帮助
/dh reloaddamageindicators.admin重新加载配置


配置
# The format of the damage indicators that will pop out of the entities.
format: '- &c&l{damage}'
# &c&l=颜色  {damage}=伤害[必须]'

decimal-places: true
# 弹出伤害.
# 如果开启小数就会显示这样: "5.0", "1.5".
# 没开启就只显示个位数: "5", "1".小数: decimal-places: true

配置示例及需要注意的地方
配置文件示例1:

format: '&c&l{damage}'
decimal-places: true

效果:
{
    5.1
}
配置文件示例2:

format: '&2&l{damage}'
decimal-places: false

效果
{
    5
}
