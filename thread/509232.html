服务器命令:

后台指令不用/,游戏中指令需要前面加一个/
例如:后台 kill 9nuoyu 游戏 /kill 9nuoyu
Name [文本] - 设置服务器名称
Port [端口号] - 设置服务器端口
password [文本] - 设置服务器密码
Maxplayers [数值] - 设置服务器最大玩家数
Map [mapname] - 设置服务器地图
PvP - 允许PVP
PvE - 不允许PVP
Mode [简单/普通/困难/黄金] - 设置服务器难度
loadout [itemid] - 设置出生装备(如果有多个那么id1/id2/id3)
owner
players 查看在线玩家
Cycle [数值] - 设置服务器日夜循环周期
Day - 更改时间到黎明
Night - 更改时间到黄昏
Investigate [玩家名 或 ID] - 显示选中玩家的信息。（只在控制台可见）
perspective [first/third/both] - 设置默认人称和允许人称(first是第一,third是第三,both允许H切换)
Kick [玩家名 或 ID]/原因（可中文） - 无理由/有理由踢出
Ban [Name 或 ID]/原因/持续时间 - 在X秒内无理由/有理由封禁
Unban [玩家名 或 ID] - 解除玩家封禁
Bans - 在控制台查看所有被封禁的玩家
Admin [SteamID / Player] - 给予被选中玩家管理权限
Unadmin [SteamID / Player] - 撤销被选中玩家的管理权限
Admins - 在控制台查看所有管理员
Permit [SteamID / player] - 给予选定玩家白名单
Unpermit [SteamID] - 将选中玩家从白名单内移除
Permits - 在控制台查看所有在白名单的玩家
Experience [玩家名 或 SteamID]/数值 - 给予选定玩家XX点经验值
Players - 查看所有在线玩家
Say [文本] - 以“服务器”名义发送公告
Welcome [文本] - 设置玩家进入时的欢迎词
Slay [Steam ID / 玩家名] - 处死玩家
Give [玩家名 或 ID]/物品ID/数值 - 给予XX玩家物品
Vehicle [玩家名 或 ID]/车辆ID - 在选定玩家前面的空地生成特定的车
Zombie [player name 或 ID]/数值- 生成僵尸（似乎现在无用了）
Teleport [玩家名A 或 id]/[玩家名B 或 ID] - 传送玩家名为 A 到 玩家名为 B 的位置
Timeout [数值] - 在一定时间内关闭服务器
Debug - 在控制台显示所有好玩的信息
Bind [IP} - 为服务器绑定IP地址
Save - 保存现在的世界和玩家。
Shutdown - 关闭服务器（请先记着保存啊！）
ROCKET/其他插件命令(整理论坛)
ROCKET API
god [SteamID | Player] - 无敌
heal [SteamID | Player] - 治疗
home - 回家(回到绑定的床)
i [itemid] - 给你自己一个指定物品
investigate - 显示一个玩家的steamid64
clear - 清理地面物品
compass - 显示你面向的方向
p  - 列出权限
rocket - 关于rocket的信息
tp [SteamID | Player] - 传送到一个玩家
tphere [SteamID | Player]/[SteamID | Player] - 传送一个玩家1到玩家2的位置
exit - 离开游戏(无需等待冷却)
v [vehicleID]/[SteamID | Player] -   给玩家一辆汽车
vanish [SteamID | Player] - 隐身
boardcast [message] 公告一条信息

Buildinglock建筑锁插件
lock - 将附近5m范围内的建筑设为自己的(建筑会无敌，但是除了保险柜还是可以被拿)注:当然别人的就不能锁了
unlock - 将附近5m范围内的建筑解锁(生命值降低为5，并且可以被别人再次锁)注:当然别人的就不能解锁了
dlock - 摧毁附近5m范围内所有建筑
chklock - 查询附近5m范围内建筑拥有者(没有被锁就是没输出)
TPA传送插件
tpa [SteamID | Player] - 玩家发送传送请求
tpa yes - 接受请求(最先发送的请求)
tpa deny - 拒绝请求(最先发送的请求)
tpa ignore - 忽视上一个请

ZaupFeast空投插件
frun - 马上运行一次空投
runfeast - 同上

Uconomy经济插件
balance - 查看自己的货币数量
pay [SteamID | Player]/数量 - 将自己相应数量的货币给他
Globalban同步封禁
ban [SteamID | Player]/原因/时间 - 跨服封禁一个玩家/理由/时间
kick [SteamID | Player]/原因 - 踢出一个玩家/理由
slay [SteamID | Player] - 禁止玩家进行操作并且封禁一年
Apok Wrecking Ball破坏球
wreck <实体类型> <半径> 创建一个破坏列表
wreck confirm 确定破坏掉破坏列表的所有实体
wreck abort 中止进行中的破坏
wreck scan <实体类型> <半径> 扫描并且列出半径内的实体数量
wreck teleport b/s 传送到最近200米的 路障/建筑
KIT礼包
kit <指定礼包名> 获取设定的礼包
Private Messaging私聊信息
pm [SteamID | Player] <message> 给玩家发送一条私聊信
ZaupClearInventoryLib清理装备
ci [SteamID | Player] 清理玩家所有装备
ci self 清理自己的所有装备
Back In Black回死亡地点
backinblack 回上一个死亡地点
bib 同上
bibz 同上
BackInBlack status 查看你的回死亡地点功能是否开启
BackInBlack [enable|on] 开启重生回死亡地点功能
BackInBlack [disable|off] 关闭重生回死亡地点功能
BackInBlack timelimit status 查看重生回死亡地点的冷却时间
BackInBlack timelimit [enable|on] 开启对重生回死亡地点的冷却
BackInBlack timelimit [disable|off] 关闭对重生回死亡地点的冷却
BackInBlack timelimit set [seconds] 设置对重生回死亡地点的冷却时间<秒>
BackInBlack help 查看插件帮助
Apok JailTime监狱小黑屋
jail set <jailname> 创建一个名为<jailname>的监狱,以你的位置为准,监狱会保存坐标.
jail unset <jailname> 删除一个名为<jailname>的监狱
jail list cells 查看存在的监狱列表
jail add [SteamID | Player] <second> <jailname> 添加一个玩家到<jailname>监狱,可设置时间<秒>（如果无时间,将使用默认时间1800s)
jail remove [SteamID | Player] 释放监狱玩家
jail list players 查看囚犯列表
jail teleport <jailname> 传送到<jailname>监狱
