标题: 更长的一天
本帖最后由 qq74357130 于 2020-3-6 07:58 编辑

原理：
通过一个盔甲架来计时，使得每分钟有40秒的 doDaylightCycle 是 false，有20秒是 true。这样相当于把每天的时间延长为原来3倍。

实现：
开局：
/scoreboard objectives add time dummy//加一个计分板
/give @p minecraft:turtle_spawn_egg{display:{Name:"{\"text\":\"Timer\"}"},EntityTag:{Small:1,id:"minecraft:armor_stand",Tags:["Timer"]}} 1 //获得一个带有标签“Timer”的盔甲架刷怪蛋，需要自己手动放置出来

每tick循环的命令：
execute at @e[tag=Timer,scores={time=0}] run gamerule doDaylightCycle false
execute at @e[tag=Timer,scores={time=800}] run gamerule doDaylightCycle true
scoreboard players add @e[tag=Timer] time 1
execute at @e[tag=Timer,scores={time=1200}] run scoreboard players set @e[tag=Timer] time 0

讨论：
1、doDaylightCycle 是false的时候，晚上睡觉可能会失败，大家有没有解决方法？（不过当成失眠的设定也不错2333
2、需要依赖一个盔甲架来计时，开局需要手动设置一下。有没有办法回避这一点？
