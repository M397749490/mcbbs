这种情况我以前遇到过
是LWC下载sqlite的相关dll库，却被墙了，导致整个服务端无法使用sqlite
解决办法：
1、翻墙
2、去服务端板块下载有LWC的服务端，将DLL复制过去

mysql配置：

  2. database

  4. adapter: (default: sqlite) Which database type you want to use.
  5. path: (default: plugins/LWC/lwc.db) Path to that database.
  6. host: (default: localhost) The address of the host the database is on.
  7. database: (default: lwc) The name of the database.
  8. username: (default: '') The username LWC uses to connect to the database.
  9. password: (default: '') The password of the username above.
  10. prefix: (default: lwc_)
