Function introduction - 功能介绍
在Minecraft更新1.16开始，Minecraft就开始支持更多的颜色，而插件Iridescent的功能也是非常简单,它利用ProtocolLib的功能支持，实现了拦截其他插件发出的信息，为其替换成十六进位制颜色的文本与渐变文本

Plugin features - 插件特色
  • 颜色标签：可以在文件 colors.yml 中创建，它可以使用在计分板，列表，通知栏.MOTD，标题，聊天，木牌等要.
  • 使用标签要以<@标签名字>格式（例如：<@fuchsia>）
  • 十六进制颜色：和传统的＆b等旧版颜色代码一样可以替换文字的颜色，不过这次您可以使用16进制的颜色<#颜色代码>为格式（例如：<#ff00ff>）
  • 渐变标签：可以给文字增加渐变<$<@标签名字>>或<$<#十六进制编码>>为格式
  • （例如：<$<@lime>>展示文本 <$<@rust>>）
  • 支持与大多数插件：由于Iridescent的工作方式，可以支持在许多插件中使用颜色标签和十六进制颜色代码
  • 游戏内创建标签：插件可以使用命令添加颜色标签无需打开配置文件来一个个添加与修改
  • 可以使用权限的聊天颜色：根据给予玩家的权限，他们可以在聊天中使用权限内部可以使用的颜色
  • 多国语言支持
  • 可自定义语言文件
  • 简单易懂的配置文件

Commsnds＆Permissions - 命令和权限
插件命令和权限：
  • / i ridescent reload-重新加载插件颜色与配置   [irid.command.reload]
  • / i ridescent帮助-显示插件帮助 [irid.command.help]
  • / i ridescent create [＃十六进制] [标签名称]-创建一个颜色标签 [irid.command.create]
  • / i ridescent delete [标签名称] 删除现有的标签 [irid.command.delete]
  • / i ridescent list [页码]显示可用的自定义颜色（每页10种颜色） [irid.command.list]
  • 颜色标签：[irid.chatcolor.color-tag-name]
  • 任何颜色：[irid.chatcolor.hex]
  • 颜色等级：[​​irid.chatcolor.gradient]
