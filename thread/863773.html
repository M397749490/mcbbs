  1. // 构造器中传入的是音效事件名，用于 sounds.json
  2. public static SoundEvent my_cd_sound = new SoundEvent(new ResourceLocation("my_mod", "cd.1"));

  4. @SubscribeEvent
  5. public static void regItem(RegistryEvent.Register<Item> event) {
  6.   event.getRegistry().register(new ItemRecord("my_mod.cd.1", my_cd_sound).setRegistryName("my_mod", "cd_1"));
  7. }

  9. @SubscribeEvent
  10. public static void regSound(RegistryEvent.Register<SoundEvent> event) {
  11.   // 这里设定的是音效事件的注册名，和上面那个 sounds.json 用的无关！
  12.   // 为方便起见可以使用一样的名字，这里为了说明差别使用了不一样的名字。
  13.   event.getRegistry().register(my_cd_sound.setRegistryName("my_mod", "cd_1"));
  14. }
复制代码


然后按照 https://minecraft-zh.gamepedia.com/Sounds.json 的说明，在你的 Mod 的资源目录下新建 sounds.json 文件（src/main/resources/assets/<modid>/sounds.json）并正确关联音效文件（必须是 OGG 格式）即可。
这里使用的音效事件的注册名是 my_mod:cd_1，但 sounds.json 中应使用的是 cd.1，就像这样：
  1. {
  2.   "cd.1": {
  3.     "sounds": {}
  4.   }
  5. }
