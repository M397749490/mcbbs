HologramsPlus

此插件是 holograms 的扩展插件，作用是在原来的基础上增加支持papi变量的功能，可在全息上显示变量并定时刷新。

安装：
HologramsPlus-1.0.0.jar
Holograms-3.1.5.jar
PlaceholderAPI-4.4.jar
（可安装更高的版本）

先创建一个全息 （什么？不知道怎么创建？）

出现了列表后可直接用鼠标点击，将其转变为动态全息即可

配置文件中的
  1. general {
  2.     # How often the holograms (and their placeholders) should be refreshed, in seconds.
  3.     updateRate=60
  4. }
复制代码
默认是60秒更新一次，可以改为1，即1秒更新一次。

如果想删除可以使用 /hologramsplus select disable 关闭指定的全息
