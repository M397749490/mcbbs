大佬，问你个问题，怎么在某个位置掉落一个物品？（相当于空降 不在破坏任何方块的时候） ...

使用EntityItem

            EntityItem itemEntity = new EntityItem(world,
                    x,y,z.itemStack);

            world.spawnEntity(itemEntity);

案例：
  1.     public static void dropStack(World world, ItemStack stack, BlockPos pos) {
  2.         if(stack != null && stack.getCount() > 0) {
  3.             float rx = world.rand.nextFloat() * 0.8F;
  4.             float ry = world.rand.nextFloat() * 0.8F;
  5.             float rz = world.rand.nextFloat() * 0.8F;

  7.             EntityItem itemEntity = new EntityItem(world,
  8.                     pos.getX() + rx, pos.getY() + ry, pos.getZ() + rz,
  9.                     stack.copy());

  11.             float factor = 0.05F;

  13.             itemEntity.motionX = world.rand.nextGaussian() * factor;
  14.             itemEntity.motionY = world.rand.nextGaussian() * factor + 0.2F;
  15.             itemEntity.motionZ = world.rand.nextGaussian() * factor;
  16.             world.spawnEntity(itemEntity);

  18.             stack.setCount(0);
  19.         }
  20.     }
