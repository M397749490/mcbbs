Git 快速入门
本教程面向新手（小白可以走了，高玩也可以先撤）
V1.1（2015年07月22日10:06:20）

1.简单介绍Git
Git是一款免费、开源的分布式版本控制系统，用于敏捷高效地处理任何或小或大的项目。
---百度百科

简单来说Git就是可以帮助我们克隆我们的每一个版本，并且可以推送到服务器中，团队中的成员可以下载下来，同时与自己当前的代码进行合并。综上所述，就是一个可以让团队工作更为快捷的系统。（听不懂没关系，反正我也不懂）。

2.简单认识GitHub

作为开源代码库以及版本控制系统，Github拥有140多万开发者用户。随着越来越多的应用程序转移到了云上，Github已经成为了管理软件开发以及发现已有代码的首选方法。---百度百科

什么是私有项目，什么是公有项目：
简单理解为：私有项目指的是只能够团队成员或个人所修改拥有、下载，公有项目指的是所有人都可以下载到你的代码。

GitHub可以理解为是一个免费的Git服务器。但是也有一些缺陷：

1.团队项目不能私有，这意味着你的项目必须开源。（乐于分享的人和壕请无视

如果你已经慎重考虑并且已经选择了GitHub。那么我们暂时不提供教程（太TM简单了！）

最后说一下为什么要使用Git库（虽然有点繁琐，但请认真看完）：
因为我们在开发中，我们是在不断的探索，不断的前进，但是路上会有很分岔路。如果我们走了一条分岔路，发现这条路不可行，那么想要重新另外一条路的过程将会非常繁琐。因为修改了过多的代码后，靠记忆力进行逆操作是很难完成的。如果使用了Git就不同了，利用Git可以快速回到一个完好的版本，把代码恢复到想要的时间点。在团队合作开发中，每一位成员进行了操作后，想要和其他成员进行合并将会是非常复杂的一个过程，还要找出改了哪里。如果有Git，团队中的成员可以快捷的提交自己的版本，如果其他成员获取后可以自动与自己的代码进行合并（不是简单的替换），同时不妨碍自己写的代码，只会添加进相应的代码。如果出现重复或冲突，Git会出现一段提示在代码中，可以清楚的看到自己的和别人的对比，然后就可以自己选择修改。

3.搭Git服务器或者选择其他免费Git库。

首先非常感谢廖雪峰老师的教程，如果想深入的可以去看他的。



温馨提示：如果你不打算搭建请跳过这一部！



准备工作：


搭建Git服务器需要准备一台运行Linux的机器，强烈推荐用Ubuntu或Debian，这样，通过几条简单的apt命令就可以完成安装。远程仓库实际上和本地仓库没啥不同，纯粹为了7x24小时开机并交换大家的修改。

---廖雪峰

1.下载并安装Git：官方下载地址。Git在linux下的按照非常简单只需通过 $ sudo apt-get install git 即可。




2.创建用户并Git用户，并运行Git服务：
  1. $ sudo adduser git
复制代码
 即可。


3.创建证书登陆：获取全部用户的公钥，即id_rsa.pub文件。把公钥导入到 /home/git/.ssh/authorized_keys 中，一行一个




4.初始化库（库可以理解为就是储存区）：假如我们要在 /usr/git/p.git 作为Git仓库。在该目录下输入：$ sudo git init --bare g.git
Git就会创建一个裸仓库，裸仓库没有工作区，因为服务器上的Git仓库纯粹是为了共享，所以不让用户直接登录到服务器上去改工作区，并且服务器上的Git仓库通常都以.git结尾。然后，把owner改为git：
  1. <font color="#2f4f4f">$ sudo chown -R git:git sample.git</font>
复制代码



5.禁用Shell登陆：该项是出于安全的考虑，限制用户不可以登陆Shell，可以通过设置 /etc/passwd 来完成。在该文件中找到类似于     git:x:1001:1001:,,,:/home/git:/bin/bash 的一行，修改为
  1. <font color="#2f4f4f">git:x:1001:1001:,,,:/home/git:/usr/bin/git-shell</font>
复制代码

  这样修改后，用户就可以正常使用ssh，但是无法登陆Shell。

如果你不想交保护费给Github 又不想 公开你那珍贵的源码，亦没有服务器，可以考虑使其他免费服务商，很多都可以设置为私。你也可以使用SVN，当然不推荐，版本控制系统有很多，可以自己选择。推荐使用以下：
  • BitBucket: 私有工程最多5个人，对他们家的产品像Bamboo和JIRA之类的整合很不错。
  • GitLab:无限私有工程，无限Collaborators。就是想自己搭个服务器也比GitHub便宜，还有免费CI用。
  • Coding:包含了任务，讨论，文档等功能。无限私有工程，项目成员最多10人，1G空间。中文支持。
  • Git @ OSC：开源中国，可创建 1000 个项目，不限私有或公有；支持 SSH、HTTP 和 SVN 访问，中文支持。
