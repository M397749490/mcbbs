前言
本插件灵感来自你问我答板块的一个求插件悬赏提问
提供指令，输入后再在聊天框输入文字，可以修改物品的名称以及Lore介绍


特点
简单上手，兼容性高
让玩家也能使用，支持限制物品最大lore行数
支持锁定lore文本，无法添加对应的lore及删除


指令、权限组和配置文件
指令
  1. /ml name  进入名字设置模式
  2. /ml addlore  进入lore添加模式
  3. /ml dellore  移除手上物品最后一条lore
  4. /ml clear  清除手上物品所有lore
  5. /ml create  进入op模式的lore添加模式
  6. /ml reload  重载配置文件
复制代码
权限
  1. ml.name  让玩家使用对应指令 默认玩家拥有
  2. ml.addlore  让玩家使用对应指令 默认玩家拥有
  3. ml.dellore  让玩家使用对应指令 默认玩家拥有
  4. ml.maxlore.数量  重新设置玩家可以添加最大行数
