SntuAuth Pro
v2.1.0

特点
Pro版本免费公开
同时支持 Oracle，mysql，sqlserver三大热门数据库
自动建表及配置 只要修改config里面的数据库参数就行了哦~小白也会！


本版本更新内容
  • 增加验证失明状态
  • 增加未验证是否可以移动选项
  • 修复未验证无法找回密码的BUG
  • 修复未验证实体伤害BUG
  • 更换为Pro版支持数据库方式，将不再提供原版的更新
  • 修复规定时间无需登录无效 BUG
  • 去除AuthMe插件支持



用法：

登录方法:  输入密码->登录成功！

注册方法:  输入自己玩家名->输入密码->再输入一次->邮箱->注册完成！

找回密码功能:   /sauth forgot [邮箱] ->去邮箱找验证码->/sauth upwd [验证码] [新密码] [再输入一次]->修改密码完成


配置文件

  1. #SntuAuth-Pro 版本
  2. #语言 目前支持（需要自行添加）
  3. #简体中=zh_CN
  4. #繁体中=zh_TW
  5. #English=en_US
  6. #日本の=ja_JP
  7. language: 'zh_CN'

  9. ServerName: '§e【§cS§eN§bT§aU§5服务器§e】'

  11. #注册密码最低长度 默认最低4位密码
  12. RegPasswordLength: 4
  13. #登录前等待时长 过时踢出玩家(单位:秒)
  14. BeforeLoginWaitingTime: 120

  16. #验证是否开启失明
  17. LoginBlindnessEffect: true
  18. #验证是否允许移动
  19. LoginMove: false

  21. #是否显示Prop提示（物品栏上面一点的位置提示）
  22. ShowProp: 'true'
  23. #设置多少分钟内自动登录 单位:分
  24. AutoLoginTime: 2


  27. #-----------------邮箱设置------------------------
  28. #具体设置请自行百度
  29. #邮箱设置 发送邮件用 （不会设置的不要修改 默认的公开可用）
  30. #使用smtp地址
  31. SmtpHost: 'smtp.163.com'
  32. #使用smtp身份验证
  33. SmtpAuth: 'true'
  34. SmtpPort: '465'
  35. #邮件编码 如果发送的邮件乱码请更改这个值 utf-8
  36. EmailTextEcoding: 'gb2312'
  37. #设置发送帐号密码
  38. AuthenticationUserName: '授权邮箱如xxx@163.com'
  39. AuthenticationPassword: '授权密码'
  40. #以下可以修改
  41. #邮箱显示的服务器 不能使用颜色代码
  42. EmailServerName: 'XXX服务器'
  43. #服务器qq群 用于找回密码时宣称
  44. EmailQQGroup: '123456789'

  46. #----------------数据存储方式-------------------------
  47. #数据存储方式
  48. #参数详细
  49. #local本地储存(不使用数据库，默认) DataType后填写 local
  50. #oracle数据库 DataType后填写 oracle
  51. #mysql数据库 DataType后填写 mysql
  52. #sqlserver数据库 DataType后填写 sqlserver

  54. DataType: 'local'
  55. #以上如果填的是local 以下数据库信息就不要填了，默认好了
  56. #数据库 ip
  57. IP: '127.0.0.1'
  58. #数据库 端口
  59. Port: '3306'
  60. #数据库 登录用户名
  61. LoginName: 'root'
  62. #登录密码
  63. LoginPwd: 'root'
  64. #数据库名(oracle数据库这里是 服务名sid 如orcl)
  65. DataBaseName: 'test'
  66. #自动创建的表名
  67. TableName: 'sntuauth_db'
