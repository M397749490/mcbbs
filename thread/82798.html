你想要捕捉你玩家的PVP行动吗? 现在你可以了. 把.jar文件放进你的插件文件夹, 重启服务器, 更改它的设置, 重启服务器——搞定!

这个插件保存玩家的杀人或死亡记录于一个MySQL数据库，就这样简单:

Table name: pvpstats [游戏台名称]
Colums:                [柱(?)]
- name     [名字]
- kills        [杀人]
- deaths  [死亡]

这是你需要的显示你的玩家PVP体验的基本设备.

命令：

/pvpstats {amount} - 显示杀手排行榜. 默认: 10(名)
/pvpstats reload - 重载配置文件

权限节点:

    pvpstats.reload:       描述:重载的资格        默认用户组: op    pvpstats.count:       描述: 被统计的权限       默认: 开启

Configuration: <<code yaml>> MySQL: true MySQLhost: localhost MySQLuser: [sql user] MySQLpass: [sql password] MySQLdb: [sql database]

PVPArena: false checkabuse: true<</code>>
No port needed ;)

PVPArena: should pvpstats try to hook into PA?
checkabuse: should pvpstats disallow scoring by killing of the same player in a row?

Requirements:

  • a MySQL database
