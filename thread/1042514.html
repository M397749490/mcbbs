标题: [纯净][BDX][JsRunner]可以直接运行的BDX&JsRunner服务器端[1.14.x]
本帖最后由 简思缘 于 2020-9-20 07:39 编辑

适用于Windows Server 2016及以上与Linux上的Wine。
(Windows Server 2008-2012 SP2虽然也有办法运行，但是需要弄运行库，所以不推荐）

1.14.x下载链接：


2020-9-20 update:
已存在适配1.16.x的BDX版本，https://www.mcbbs.net/thread-1074322-1-1.html


发现很多人不会配置BDX和JsRunner，所以我就弄了个配置好的。

解压压缩包，点击start.bat即可运行服务器。
无需其他操作！把你的时间放在打磨服务器质量上！

这是BDS服务器端，携带了BDX与JsRunner（能装JS和DLL插件）。


添加dll插件只要把dll复制到bdxmod文件夹即可。

添加js插件只要把js复制到js文件夹即可。


相关信息

BDX:https://github.com/Sysca11/BedrockX-bin


JsRunner:hhttps://www.min删除我ebbs.com/resources/win-bds-js-bdsjsrunner.807/updates


如果对你有帮助的话，就给个评分吧QWQ
