VariableTriggers（VT）是CraftBukkit中的一个插件，它是ScriptBlock①二次开发的产物。
VT内置一种语法类似于VisualBasic（VB）②或是易语言③的脚本语言，虽然是脚本语言，但是也有IF条件分歧、声明变量(或变量数组)、条件循环的方法。
我们可以将服务器看做一台电脑，VT就是电脑的操作系统。
那么我们可以把这些与服务器互动的方法称为Variable Triggers Application Programming Interface（VTAPI）④
玩家通过一些行为来触发Triggers（触发器）⑤，见表格
触发器类型
下级分类
地点触发
点击方块 踩踏方块
命令触发
输入命令
区域触发
进入区域
事件触发
玩家死亡 实体死亡 破坏方块 放置方块 重生 加入服务器 退出服务器
点击实体 生成实体 聊天 定时器
你可以在玩家输入一条命令时通过占位符判断玩家是否拥有某权限，来像普通插件一对命令进行监听⑥
VT支持三种变量⑦：
Integer    Int    整数型
String      Str    字节集
Boolean  Bool  布尔型/逻辑型
以及一种数组⑧：字节集数组，它可以在申明后存储无限量的字节集而只用下标来区分它们
VT提供一种占位符，分为普通占位符和功能性占位符，你可以分别把它们视为无参有返回值方法⑨和有参有返回值方法
它们会像Java方法一样，有的只是返回数据（占位符），有的会对服务器进行操作后返回数据（功能性占位符），后者一般返回bool
最后我们要介绍的是Variable Triggers Scripts（VT脚本），目前全部的标准格式是 @大写语句
VT脚本会对服务器或是储存的变量进行操作，一般需要参数，没有返回值
通过总结不难看出，VT的潜力是足以写出SignShop，Residence甚至是Ess这样大型插件一样的脚本的

①ScriptBlock可以把命令文本绑定在任何方块上,点击或踩踏你绑定的方块就可以实现依次运行多条命令
②Visual Basic是一种由微软公司开发的可视化编程语言。源自于BASIC编程语言。VB拥有图形用户界面（GUI）和快速应用程序开发（RAD）系统，程序员可以轻松的使用VB提供的组件快速建立一个应用程序。
③易语言是一门计算机编程语言。以“易”著称，以包括中文的多种语言作为程序代码表达的语言形式
④Application Programming Interface（API，应用编程接口）是操作系统留给应用程序的一个调用接口，应用程序通过调用操作系统的 API 而使操作系统去执行应用程序的命令（动作）
⑤Triggers（触发器）可以在程序做出某行为时触发特定事件，例如易语言中窗口创建完毕时会调用一个子程序，在Minecraft中一般即为用户做出某行为从而触发某脚本
⑥监听，即是指定触发器的触发针对某个事件，例如易语言中窗口创建完毕事件就是触发器对的一种监听
⑦变量来源于数学，是计算机语言中能储存计算结果或能表示值抽象概念。变量可以通过变量名访问。在指令式语言中，变量通常是可变的。在一些语言中，变量可能被明确为是能表示可变状态、具有存储空间的抽象（如在Java和Visual Basic中）；但另外一些语言可能使用其它概念（如C的对象）来指称这种抽象，而不严格地定义“变量”的准确外延。在VariableTriggers单纯为以不同格式储存数据的方式。
⑧数组，就是相同数据类型的元素按一定顺序排列的集合，就是把有限个类型相同的变量用一个名字命名，然后用编号区分他们的变量的集合，这个名字成为数组名，编号成为下标。
