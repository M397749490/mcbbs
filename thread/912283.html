3.配置文件
配置文件：

  1. # 插件CustomJoinMessaje
  2. # 作者Jonagamerpro1234
  3. # 版本号 1.3.6
  4. # 搬运作者MarkStank
  5. #
  6. # 有两个变量显示消息中玩家的名称 | <Name>, <DisplayName> | 这两个变量可以小写.
  7. #
  8. # | 加入 | 这里有多个选择, 包括:
  9. # | true = 自定义消息开启 | false = 游戏默认消息 | none = 禁用消息|
  10. #
  11. # | 离开 | 这里有多个选择。包括[跟上面一样] :
  12. # | true = 自定义消息开启 | false = 游戏默认消息 | none = 禁用消息|
  13. #
  14. # |音效|格式|
  15. # |sound_name;音量;音高|
  16. # |Ej 1.9.  BLOCK_NOTE_PLING;10;2|
  17. # |其他音效在https://hub.spigotmc.org/javadocs/spigot/org/bukkit/Sound.html上查找|
  18. #
  19. Config:
  20.   Update: true
  21. Messages:
  22.   Join:
  23.     Enabled: true
  24.     Text: '&6[&a+&6]&b <name>&7 加入服务器'
  25.   Quit:
  26.     Enabled: true
  27.     Text: '&6[&c-&6]&b <name>&7 离开服务器'
  28. Sounds:
  29.   Join:
  30.     Sound: NOTE_PLING;10;2
  31.     Enabled: true
  32.     Use-Per:
  33.       Enabled: false
  34.       Permission: 'cjm.sound.join'
  35.   Quit:
  36.     Sound: NOTE_PLING;10;2
  37.     Enabled: true
  38.     Use-Per:
  39.       Enabled: false
  40.       Permission: 'cjm.sound.join'
