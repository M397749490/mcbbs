海绵的nucleus的warp 怎么设置冷却时间





作者: 恋    时间: 2018-12-5 15:44
config\nucleus\commands.conf
  1. warp {
  2.     # The commands below are aliases of these commands. Set to false to disable them.
  3.     aliases {
  4.         nwarp=true
  5.     }
  6.     # 指令冷却时间，单位为秒，玩家要等待到设置的时间后才可以使用指令，设置0则为禁用此功能。
  7.     cooldown=0
  8.     # 是否启用此指令
  9.     enabled=true
  10.     # 指令等待时间，单位为秒，玩家需要等待到设置的时间后才可以触发指令【移动和使用指令会打断等待时间】，设置为0则禁用此功能。
  11.     warmup=0
