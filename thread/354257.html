Order Cancellation

Order ID: #ee4d51860fdf44f1b19ff7a1e6d9095a

Hi,

This is a cancellation notice for your previous order #ee4d51860fdf44f1b19ff7a1e6d9095a.

Why was my order canceled?

Most likely we have received a refund or void request. If you did not issue such a request yourself, or believe that it was done in error, contact us through our support center.

What will happen to my game/gift code?

If you bought a game, the created game profile will be deleted and you will no longer be able to play the game.

If you bought a gift code, the gift code will be revoked. If the code already has been redeemed, the created game profile will be deleted, and the person who redeemed the code will no longer be able to play the game.

If you have any further questions or want to learn more about our refund policies, visit our support center.

Best regards,
Mojang.
