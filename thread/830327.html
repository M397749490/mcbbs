需要达成的目标
当到达第10天时难度设置为简单
进阶内容

作者: SPGoding    时间: 2018-11-16 10:39
# gameLoopFunction
scoreboard objectives add day dummy
scoreboard objectives add const dummy
scoreboard players set 10 const 10
execute @p ~ ~ ~ stats entity @s set QueryResult @s day
execute @p ~ ~ ~ time query day
execute @p ~ ~ ~ scoreboard players operation @s day %= 10 const
execute @p[score_day=0,score_day_min=0] ~ ~ ~ difficulty 1
scoreboard players reset @p day

没必要用/time query day吧....用记分板就好啦~

先建立记分板time和一个AEC用来记录分数
  1. /scoreboard objectives add time dummy
  2. /summon area_effect_cloud ~ ~ ~ {Tags:["1"]}
复制代码

再高频
  1. /scoreboard players add @e[tag=1] time 1
复制代码

再判断时间
  1. /execute @e[tag=1,score_time_min=240000] ~ ~ ~ /difficulty 1
  2. /execute @e[tag=1,score_time_min=240000] ~ ~ ~ /scoreboard players set @e[tag=1] time 0
复制代码
