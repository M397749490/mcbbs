对于这种玄学问题,都有一种通用解决方案.
那就是:排 插 件
有插件ABCDEFGHIJKLMN,其中ABC为基础插件(权限组/经济/前置).
那么可以这样反复重启:
#1:无插件启动
#2:ABC
#3:ABC DEF
#4:ABC DEF GHI
...
#*:ABC DEF GHI JKL MN

假设在#3时出现问题,那么再这样重启:
#1: ABC D
#2:ABC DE
#3:ABC DEF
哪一次开始出现问题就找哪个插件的麻烦.

不是在#5出现问题而在#1就已经出问题?
直接把锅丢给服务端吧.

然后对于出现问题的东西:
更新 删除 同类替代

排查问题从未如此简单.
