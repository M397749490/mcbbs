摘抄答案：
用N++修改Residence的配置文件Group.yml路径如下 plugins→Residence→Groups.yml
用Ctrl+F 搜索红字部分的英文即可
       Residence:
           # 玩家是否可以创建领地.这个设置可被 'residence.create' 权限覆盖.
           CanCreate: true
           # 玩家允许拥有最大领地数.
           MaxResidences: 5
           # 一个领地的最大物理区域数目.
           MaxAreasPerResidence: 3
           # 一个领地在东西方向最大距离 (X坐标).
           MaxEastWest: 64
           # 一个领地在东西方向最小距离 (X坐标).
           MinEastWest: 3
          # 一个领地在南北方向最大距离 (Z坐标).
           MaxNorthSouth: 64
           # 一个领地在南北方向最小距离 (Z坐标).
           MinNorthSouth: 3
          # 一个领地在上下方向最大高度 (Y坐标).
           MaxUpDown: 256
           # 一个领地在上下方向最小高度 (Y坐标).
           MinUpDown: 3
           # 允许创建领地的最低高度.
           MinHeight: 0
           # 允许创建领地的最高高度.
           MaxHeight: 255
