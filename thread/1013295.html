介绍
WorldEditCUI mod制作的接力棒如今从Mumfrey，lahwran传递到 mikroskeem 手上啦！感谢维护~


介绍：
        WorldEditCUI其实就是让你在用创世神（WorldEdit）时，有红色的框框，能让你看到自己的选取范围之类的。B嗷~~


原帖介绍：
        WorldEditCUI为配合WorldEdit的客户端Mod，为其添加用户界面。本Mod可以让你在WordEdit中选择的区域用可视且可调节的方格显示出来，角落部分还会特别标明，这样服务器管理员使用WorldEdit时可以最大程度地避免选择出错，还可以直观地看出他们选择的范围。


作者原话:
        A graphical user interface for WorldEdit. WorldEditCUI is designedto assist in using WorldEdit, as well as preventing accidental errors.
Please note that this is not WorldEdit, which allows you to make changesto your world, but WorldEditCUI, a frontend for WorldEdit. You must haveWorldEdit installed on your server.





使用说明及注意事项
  • 该Mod不包含WorldEdit，只是用来辅助WorldEdit使用的，所以请先安装WE才能正常使用本mod。
  • 该Mod需要的前置是 Fabric ，（然而遗憾的是Fabric与Forge并不兼容）。
  • 下载好后直接将文件拖进mods文件夹里就好啦。
  • 1.16.2+01 (这个版本也可以用在 1.16.3 和 1.16.4中噢)
  • 下载地址在github，不用**嗷。（如果实在下不了可以在评论区里吱亿声）
