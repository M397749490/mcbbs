根据你的要求速成了一个数据包（用法是把压缩包放到存档的datapacks文件夹下）
foxxxxx.zip (3.07 KB, 下载次数: 9)
2020-5-9 19:46 上传
点击文件名下载附件

首先你需要一个进度json
fox_hurt/advancements下面
  1. {
  2.          "criteria": {
  3.              "thefox": {
  4.                      "trigger": "minecraft:player_hurt_entity",
  5.                      "conditions": {
  6.                            "entity": {
  7.                                  "type": "fox",
  8.                                  "nbt": "{Tags:[\"mg-4\"]}"
  9.                    }
  10.                }
  11.           }
  12.       }
  13.   }
复制代码
这样玩家在攻击一只带有mg-4这一tag的狐狸时就会触发fox_hurt:thefox这一进度
然后搞个高频执行的mcf，里面的内容是
  1. execute as @a[advancements={fox_hurt:thefox=true}] run effect give @s minecraft:blindness 5 1 false
  2. advancement revoke @a[advancements={fox_hurt:thefox=true}] from fox_hurt:thefox
复制代码

这会给每个触发fox_hurt:thefox进度的玩家五秒的失明效果
然后移除玩家具有的fox_hurt:thefox这一进度
