插件介绍
这是一款可以自定义合成物品的插件，他可以让你自定义合成一个物品，并且可以修改那个物品的名称，附魔，lore等等！


插件截图
可以设置自定义的lore和name


下面勿笑..~ヽ(●-`Д?-)ノ！




食用方法
1>下载插件！
2>装插件
3>配置插件文件
4>拿起工作台开始合成

插件无指令无权限



配置文件
1.1.2版本，仅供参考
  1. # 汉化By:Auange_M夜幕|PCD小组审核组长|有任何问题咨询Q929149568
  2. # 插件版本:v1.1.2
  3. Items:
  4. # 第一个物品的代码
  5.   Chaojigaozi:
  6.   # 制作出来的物品的ID,子id请添加[:<子id>]
  7.     Item: '278'
  8.     #制作出来物品的数量
  9.     Amount: 1
  10.     # 制作出来的物品的名称name,可以使用彩色代码
  11.     Name: '&4&l超级镐子'
  12.     # 制作出来的物品的描述lore,可以使用彩色代码(可以多行)
  13.     Lore:
  14.      - '&b&l这是一把自定义合成做成的镐子哦'
  15.     # 制作出来的物品的附魔,格式<附魔名称>:<附魔等级>,如果不需要附魔请直接把这一项删除
  16.     Enchantments:
  17.     - 'DURABILITY:300'
  18.     # 工作台的自定义摆放
  19.     # X为空气Air,意思为不摆放材料
  20.     # 其他字母在Ingredients上选择添加
  21.     # 工作台一共三行,可以自行设置摆放格式
  22.     ItemCrafting:
  23.      - 'EEE'
  24.      - 'XIX'
  25.      - 'XIX'
  26.      # 材料字母代码
  27.      # 格式为:<字母代码>:<材料的ID>:<物品的子ID>,如果不需要<物品的子ID>请删除":<物品的子ID>"
  28.     Ingredients:   
  29.      - 'E:388'
  30.      - 'I:265'
  31. # 下一个物品格式如上
  32.   Shi:
  33.     Item: '351:3'
  34.     Amount: 1
  35.     Name: '&7&l夜幕的大便'
  36.     Lore:
  37.      - '&a超级珍贵的夜幕大便'
  38.     ItemCrafting:
  39.      - 'XXX'
  40.      - 'XIX'
  41.      - 'XEX'
  42.     Ingredients:
  43.      - 'E:295'
  44.      - 'I:351'
