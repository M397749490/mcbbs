错了，你要自己new 一个 ItemBlock 而不是调用 Items.getItemFromBlock！
你都还没注册呢就想着获取，当然会给你空气。
  1. @SubscribeEvent
  2. public static void regItem(RegistryEvent.Register<Item> event) {
  3.   event.getRegistry().register(new BlockItem(myBlock).setRegistryName(myBlock.getRegistryName()));
  4. }
