Essentials MySQL Storage Extension
Essentials MySQL存储拓展


| 简介

       Essentials MySQL Storage Extension是什么东西呢？Essentials相信大家都很熟悉，但是Essentials MySQL Storage Extension是怎么东西呢，下面就让楼主带大家一起了解吧。
　　Essentials MySQL Storage Extension，其实就是ess同步插件，大家可能会很惊讶Essentials怎么会不支持MySQL储存数据呢？但事实就是这样，楼主也感到非常惊讶。
　　这就是关于Essentials MySQL Storage Extension插件了，大家有什么想法呢，欢迎在评论区告诉楼主一起讨论哦！

    你还在寻找economy的同步方案? 你还在纳闷无法全服ban玩家?
    这个拓展就可以完美地解决这个问题!

    Essentials MySQL Storage Extension,简称EMS,支持同步essentials的所有数据(包括但不限于经济,邮件,家等等).凡是存在essentials\userdata文件夹下的数据都可以同步.

| 特色

  ● 支持在线和离线UUID (不适用于非UUID服务器,所以只适用于1.7.10及更高版本)
  ● 支持一键删除数据库中不活跃玩家数据
  ● 兼容性极高,可同步下列插件离线时获得的金钱
      ○ 兼容QuickShop插件
      ○ 兼容ChestShop插件
      ○ 兼容AuctionHouse插件
      ○ 兼容PlayerShopGUI插件
      ○ 兼容Shopboot插件
  ● 提供在服务器关闭或重新启动时删除整个Essentials/userdata文件夹的选项
  ● 提供当玩家离开服务器并且数据保存在数据库中时自动删除用户数据文件的选项
  ● 支持使用命令将所有用户数据文件导入数据库。
  ● 支持使用命令将数据库中的所有用户导出回essentials用户数据文件夹 (因此可以随时删除插件而不丢失数据)
  ● 支持使用命令从数据库数据中获取经济排名
  ● 能够自动过滤玩家的数据文件并删除无用数据
  ● 配置简单易懂
  ● 轻量级,使用很少的资源,异步执行同步任务.不影响服务器性能或TPS

|  安装

  1.将插件放在plugins文件夹下,确保已安装Essentials
  2.启动服务器,等待其生成配置.生成完毕后关闭服务器.
  3.打开配置文件,设置数据库信息并配置插件
     你需要自行创建数据库,插件会在你指定的库中自动创建表.
     数据库创建教程自行百度,这里就不赘述.
  4.启动服务器,检查服务器后台是否有报错,插件是否正常运行.
  5.输入 /ems import 将essentials的数据导入数据库.

| 指令

指令
所需权限
用途
/ems 或 /ems help  
无
打开帮助菜单
/ems baltop
EMS.baltop
获取经济排行前十的玩家
/ems reload
EMS.admin
重载插件
/ems import
EMS.admin
将ess插件的所有本地数据导入MySQL
这将覆盖掉已有数据
/ems export
EMS.admin
将MySQL中的数据导出插件ess数据文件夹(userdata)
这不会删除MySQL内的数据.
导出前请先确认是否已禁用本地数据
/ems saveAndKick
EMS.admin
踢出服务器内所有玩家并保存他们的数据
/ems remove <name>
EMS.admin
删除数据库内的指定玩家数据
