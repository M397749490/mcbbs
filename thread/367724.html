1.不明所以，是圈地还是什么房子？
2.mangaddv 组 prefix 【前缀】
manuaddv 玩家 prefix 【前缀】
3.修改.\plugins\GroupManager\worlds\world\groups.yml
Builder:
    #默认组，确保全部组只有一个是true
    default: true  
    permissions: []
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      prefix: '&2'
      build: true
      suffix: ''
