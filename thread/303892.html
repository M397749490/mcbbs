=A=  表示版聊比较困难=A=

首先你得有个编辑yml文件的软件 Notepad++

然后用这个软件打开GM插件的config.yml
然后你估计会看到这样一段
  1.   mirrors:
  2.         world:
  3.           world_nether:
  4.           - users
  5.           - groups
  6.           world_the_end:
  7.           - users
  8.           - groups
  9.           all_unnamed_worlds:
  10.           - users
  11.           - groups
复制代码

把这一段改为：
  1.   mirrors:
  2.         world:
  3.           all_unnamed_worlds:
  4.           - users
复制代码

  然后保存  重启服务器=A=
