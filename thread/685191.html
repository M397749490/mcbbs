简介：
这个插件会防止玩家刷屏、发出网址等，而且可以让脏话什么的替换成你想要的字


特点：
AntiCAPS：防止全是大写的句子，在中国好像没啥用
AntiURL：防止玩家发网址宣传什么的
AntiSpam：防止玩家刷屏
Antiswear：过滤脏话233
AntiIP：防止玩家发IP
配置文件解释：
  1. enabled:
  2. //是否开启一些功能
  3.   antiCaps: true
  4.   antiIp: true
  5.   antiUrl: true
  6.   antiSpam: true
  7.   antiSamechars: true
  8.   antiReplacer: true
  9. Message:
  10.   antiIp: '&c(IPs)'
  11.   antiUrl: '&c(URL)'
  12.   antiSpam: '&c(Spam)'
  13. maxcapspercent: 40
  14. //句子里最大的大小字母占整个句子的单词数量的最大百分比
  15. spamsimilaritypercent: 90
  16. //刷屏检测灵敏度
  17. //越小越灵敏
  18. //但会影响玩家说话
  19. //很大影响
  20. sendMsgSenderMsgIfBlocked: true
  21. //如果玩家说的话被屏蔽替换了，是否发生信息给玩家
  22. prefix: '&c[ChatRules]'
  23. //插件的前缀
  24. MsgBlocked: '&cYour message was blocked by chat rules'
  25. //发送给玩家的信息
  26. debug: true
  27. //debug
  28. whitelistedAddress:
  29.     - 0.0.0.0
  30.     - play.relexplay.es
  31.     - www.google.com.pe
  32.     - www.youtube.com
  33. //网站\IP白名单
  34. replacerules:
  35.     - shit > poopie
  36.     - fuck > wump
  37.     - damn > great
  38.     - fuk > wump
  39.     - arse > bottom
  40. /*
  41. 脏话替换
  42. 格式：
  43. 脏话 > 被替换信息
  44. 举个梨子：
  45. 这破服务器真TM卡，VIP居然不能飞，还要60000 > 这服真TMD好玩，新手有人带，玩不腻
复制代码


指令：
/crclear >> 清空聊天记录
/crreload  >> 重载插件


权限：
chatrules.clear >> 使用/crclear
chatrules.reload >> 使用/crreload
chatrules.bypass >> bypass全部检测
chatrules.bypass.url >> bypassURL检测
chatrules.bypass.ip >> bypassIP地址检测
chatrules.bypass.spam >> bypass刷屏检测
chatrules.bypass.caps >> bypass大写检测
chatrules.bypass.char >> bypass太多相同文字检测
