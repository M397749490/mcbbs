标题: 1.13命令方块 爆炸弓explosion bow
本帖最后由 Alxeh 于 2018-8-13 16:53 编辑

原理：将手持名为“爆炸弓”的弓的玩家射出的箭命名为“explosion arrow”，再探测落到地面上的“explosion arrow”并在上面生成瞬间爆炸的crepper。整个命令只需要四个CB，一个循环接3个链锁（都是不受制约）。
首先给予玩家一把爆炸弓：
  1. /give @p minecraft:bow{display:{Name:"{"text":"爆炸弓" }",Lore:["将普通箭矢变为爆炸箭矢"]},Enchantments:[{id:"minecraft:power",lvl:1}],HideFlags:1} 1
复制代码

接下来就是CB部分了
1.探测手持爆炸弓的玩家，并将他射出的箭命名为“explosion arrow”，循环激活：
  1. /execute at @a[nbt={SelectedItem:{id:"minecraft:bow",tag:{display:{Name:"{"text":"爆炸弓" }"},Enchantments:[{id:"minecraft:power",lvl:1}],HideFlags:1}}}] run data merge entity @e[type=minecraft:arrow,distance=..2,limit=1,nbt={inGround:0b}] {CustomName:"{"text":"explosion arrow"}"}
复制代码


2.在实体“explosion arrow”上生成火焰粒子效果，这条可有可无，纯粹是视觉效果，连锁上条激活：
  1. execute at @e[type=minecraft:arrow,name="explosion arrow"] run particle minecraft:flame ~ ~ ~ 0 0 0 0.07 4
复制代码

3.探测名为“explosion arrow”，nbt为{inGround:1b}的实体箭，在上面生成瞬间爆炸的creeper，连锁上条激活：
  1. /execute at @e[type=minecraft:arrow,name="explosion arrow",nbt={inGround:1b}] run summon minecraft:creeper ~ ~ ~ {Fuse:0,ExplosionRadius:3.5}
复制代码
Fuse控制爆炸时间，
ExplosionRadius控制爆炸威力。




4.最后一步，也是至关重要的一步，清除那支箭，不然就会无限生成creeper，连锁上条激活：
  1. /kill @e[type=minecraft:arrow,nbt={inGround:1b},name="explosion arrow"]
复制代码


楼主研究了一下午，才实现了爆炸箭的功能，期间遇到了许多问题。
普通的弓发射的箭，主手切换成爆炸弓后也会爆炸，于是楼主给爆炸弓发射的箭矢命名来解决这一问题，但是命名过的箭为什么会有蓝色的药水粒子效果？难道是特性？（滑稽）用data命令也没有发现任何与粒子有关的nbt，暂时未解决。
还有就是如果用普通弓发射的一瞬间切换成爆炸弓，发射的箭矢也会爆炸，这个需要手速。



如果还需要射中实体后产生爆炸，可以使用下面的CB组：
楼主用了2个循环，5个连锁和1个脉冲搞定
首先加一个检测用的循环CB：


  1. /execute if entity @e[type=minecraft:arrow,name="explosion arrow"]
复制代码
这条命令是用来检测“explosion arrow”是否存在的，加红石比较器连接脉冲CB：
  1. /execute at @e[type=minecraft:arrow,name="explosion arrow"] run summon minecraft:arrow ~ ~ ~ {CustomName:"{"text":"2"}"}
复制代码
以上两个CB是单独的，不与下面的CB连接。
下面我们再放置第二组CB：
第1，2条同上，主要是检测玩家是否手持爆炸弓以及生成粒子效果：
循环激活：
  1. /execute at @a[nbt={SelectedItem:{id:"minecraft:bow",tag:{display:{Name:"{"text":"爆炸弓" }"},Enchantments:[{id:"minecraft:power",lvl:1}],HideFlags:1}}}] run data merge entity @e[type=minecraft:arrow,distance=..2,limit=1,nbt={inGround:0b}] {CustomName:"{"text":"explosion arrow"}"}
复制代码


  1. /execute at @e[type=minecraft:arrow,name="explosion arrow"] run particle minecraft:flame ~ ~ ~ 0 0 0 0.07 4
复制代码

3.将刚刚生成的名为“2”的箭tp到“explosion arrow”，因为连接着循环CB，这条命令会一直重复：
  1. /execute as @e[type=arrow,name="explosion arrow"] run tp @e[type=arrow,name="2"] @s
复制代码
4.如果“explosion arrow”射到了地上，清除它：
  1. /kill @e[type=minecraft:arrow,name="explosion arrow",nbt={inGround:1b}]
复制代码
5.如果射到实体上，“explosion arrow”会消失，只会剩下“2”，这时在“2”上生成瞬爆creeper；如果射到地上，上一条命令已经清除它了：
  1. /execute unless entity @e[type=minecraft:arrow,name="explosion arrow"] run execute at @e[type=minecraft:arrow,name="2"] run summon minecraft:creeper ~ ~-0.5 ~ {Fuse:0,ExplosionRadius:3.5}
复制代码
6.如果成功生成creeper，清除“2”（注意这个CB一定要设置为条件限制）：
  1. /kill @e[type=minecraft:arrow,name="2"]
复制代码

这组CB也有一些问题，因为用了红石比较器，会有2红石刻的延迟，也就是说如果箭射出去很快就射中实体（2 ticks之内），那么CB就失效了。这个问题楼主会想办法克服，也欢迎论坛大佬批评指导
