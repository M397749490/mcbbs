来愉快地制作自定义GUI吧~自定义它们的颜色、大小、配置和用法！
这个插件有无限的可能性，但是你有[ruby=馊]好[/ruby]主意吗？（-当然啦-） 此处Muse Dash梗
你可以做一个服务器选择器、一个商店、一个工具包……只要你脑洞够大~
Make custom GUIs and allow them to be any colour, size, configuration, and usage. There are limitless possibilities and ideas you can make a GUI for ranging from a server selector, an admin shop, a kit GUI or even all of them together!

授权许可：


特点
  • 在任何物品上绑定你想要的指令
  • 将所有的空格子一键换成你想要的任何东西~
  • 支持PlaceHolderAPI(占位符)哦~
  • 给面板中的物品设置上任何名称和Lore
  • 根据需要创建制作不同的面板~
  • 用热键打开面板
  • 在面板上购买/出售物品
  • 轻松用箱子生成面板



  • Use any item and assign it as many commands as you want
  • Set all the empty slots to any item you want
  • Use Placeholder API to allow for further customization
  • Set items in the GUIs to any name and a lore as long as you require it to be
  • Make as many different Panels as you wish
  • Complete format control. Set the plugin tag and look to anything you want
  • Open panels with items in your hotbar
  • Buy and Sell items from the Panels
  • Generate Panels from chests easily

命令
  • /cp [面板] [玩家] | 打开面板~ ("[面板]"留空以打开配置中的第一个面板~)
  • /cp <面板> item [玩家] | 获取面板中的物品(?)
  • /cpc | 关闭面板~
  • /cpg | 启用/禁用生 成 模 式!
  • /cpr | 哒哒, 重 载 插 件!

权限
  • commandpanel.panel.default | 只要你不搞事，玩家默认都是拥有此权限的~该权限允许玩家打开需要默认权限的面板。
  • commandpanel.* | 只要拥有了此权限，就可以尽情搞事~
  • commandpanel.panel.[面板权限] | 打开面板所需要的权限~([面板权限]在配置文件里设置~)
  • commandpanel.item.[面板权限] | 获取面板中的物品(?)的权限~([面板权限]在配置文件里设置~)
  • commandpanel.reload | 重载插件娘的权限~
  • commandpanel.close | 只要你不搞事，玩家默认都是拥有此权限的~该权限允许玩家关闭面板(即/cpc)
  • commandpanel.other | 给其他玩家打开面板~
  • commandpanel.generate | 用箱子生成面板的权限~

生成面板:
怎么生成一个面板呢？
  • 在箱子里填♂满你想要的物品，将物品重命名为你想要的
    (保留空白区域为空，待会儿一键填♂满)
    (彩色代码什么的直接用'&'就好了啦~生成的时候会生效的~)
  • 输入/cpg 以启动 生 成 模 式 !
  • 打开箱子~于是面板就生成啦~面板的名称是这时的日期哦~
  • 打开你的config.yml，愉快地进行后续设置~

指令标签:
示例: "op= gamemode creative" (划重点！等号后面的空格必须要~)
"op=" 以OP权限执行命令
"server=" (在BungeeCord环境下)将玩家传送到一个特定服务器
"console=" 以控制台权限执行命令
"msg=" 向玩家发送消息
"buy=" 玩家购买物品，用法:"buy= [价格] [物品名] [物品数量] [物品数据值]" (需要 Vault) 栗子: 用3块钱买12棵草 "buy= 3 GRASS 12"
"sell=" 玩家出售物品，用法:"sell= [价格] [物品名] [物品数量] [物品数据值]" (需要 Vault) 栗子: 12棵草卖3块钱 "sell= 3 GRASS 12"
