我来说通俗一点...


首先，这里指的tag(标签)有别于游戏中的scoreboard tag。
后者是游戏中使用命令，给实体加上标签，之后在选择器里用于被选中，如 @e[tag=me]
而前者是事先在游戏外的数据包内，给方块/实体/流体/函数(function)/物品加上标签，之后同样用于被选中，如
execute if block ~ ~ ~ #namespace:block
@e[type=#namespace:entity]
function #namespace:run_list

minecraft:tick.json，于以下位置的一个json文件
datapacks\<数据包名称>\data\minecraft\tags\functions
其中，minecraft为命名空间。（命名空间，namespace，用于区分同名函数以防撞车）
此minecraft:tick.json中列出的mcfunction将会每tick在游戏中被运行一次。
里面大概长这样
  1. {
  2.   "replace": false,
  3.   "values": [
  4.     "uin:tick/pass",
  5.         "uin:test"
  6.   ]
  7. }
复制代码

1.12版本还没有tick.json，因此要作到每tick运行函数需要依靠 /gamerule gameLoopFunction <函数路径>

1."#(命名空间):tag"不是表示一个函数，而是表示一组被标记为"(命名空间):tag"的函数，而"(命名空间):tag"是函数标签。详见下方推荐教程
2."有'minecraft:tick标签的函数'"是在minecraft/tags/functions/tick.json中引用的函数，意义就是将引用的函数贴上了'minecraft:tick'标签。游戏每刻都会调用被标记为"minecraft:tick"的函数
