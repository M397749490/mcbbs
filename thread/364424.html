如何使用
进入你的服务器.
输入/register 密码进行注册
输入/login 密码进行登录

安装:
  • 将jar文件放入plugins_mod
  • 开启服务器
  • 第一次创建会建立一个配置文件, 'plugins_mod/RainbowAuth/config.properties' ,随意修改.你可以通过 '/rauth load config' 重新读取
  • 建立数据库文件
  • 登录
  • 使用 /rauth setauthspawn 设置新出生点

设置:
  • auth.spawn - 传送玩家的位置. (0 -1 0 不传送)
  • auth.unathorized.canbreak - 玩家未登录时可否破坏方块.
  • auth.unathorized.candropitem -玩家未登录时可否丢物品.
  • auth.unathorized.canmove - 玩家未登录时可否移动.
  • auth.unathorized.canplaceandinteract - 玩家未登录时是否会与其他物体互动.

命令:
  • /login <password> - 登录.
  • /register <password> - 注册.
  • /unregister - 删除你的注册信息.
  • /changepass(changepw, changepassword) <老密码> <新密码> - 更改密码.
  • /rainbowauth, /rauth -管理员命令
  • /rauth save/load database/config -  重新读取数据库或者配置文件.
  • /rauth register <username> <password> -  注册一个玩家.
  • /rauth unregister <username> -  删除一个玩家.
  • /rauth setauthspawn -  设置未注册的玩家传送点.

权限:
  • rainbowauth.admin - 可以使用/rainbowauth
  • rainbowauth.login - 可以使用 /login
  • rainbowauth.register - 可以使用 /register
  • rainbowauth.unregister - 可以使用/unregister
  • rainbowauth.changepass - 可以使用 /changepass
