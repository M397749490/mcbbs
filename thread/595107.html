注：以下指令用连续激活的命令方块激活


当敌方玩家靠近Boss时，把Boss的fire积分设为1，fire2积分设为0，切换近战武器。


  1. /execute @a[team=red] ~ ~ ~ /scoreboard players set @e[name=tower,r=2,team=blue] fire 1
复制代码
  1. /execute @a[team=red] ~ ~ ~ /scoreboard players set @e[name=tower,r=2,team=blue] fire2 0
复制代码



当敌方玩家远离Boss时，把Boss的fire积分设为0，fire2积分设为1，切换远程武器。


  1. /execute @a[team=red] ~ ~ ~ /scoreboard players set @e[name=tower,rm=2,team=blue] fire2 1
复制代码
  1. /execute @a[team=red] ~ ~ ~ /scoreboard players set @e[name=tower,rm=2,team=blue] fire 0
复制代码

Boss对推塔兵（僵尸猪人）的仇恨：

因为僵尸猪人不会向骷髅主动进攻，但是我们注意到两个Boss都有特定的UUIDLeast，我们可以利用ownerName来实现生物的互拼



创建以下积分榜：
  1. /scoreboard objectives add fight2 dummy
复制代码
  1. /scoreboard objectives add fight4 dummy
复制代码

积分榜fight2用于给塔附近的猪人的fight4积分榜加分

积分榜fight4用于在猪人头顶生成由雪球（owner：对方防御塔）对猪人拉仇恨，对防御塔进行攻击


给塔附近的敌方推塔兵的fight2积分榜加分：
  1. /execute @e[name=tower,team=blue] ~ ~ ~ /scoreboard players add @e[type=PigZombie,r=6,team=red] fight2 1
复制代码

给积分榜fight2积分大于0的猪人的fight4积分榜加分：
  1. /execute @e[score_fight2_min=1] ~ ~ ~ /scoreboard players add @e[score_fight2_min=1] fight4 1
复制代码

在塔的仇恨范围内的猪人拉起仇恨：
  1. /execute @e[score_fight2_min=1,score_fight4=1] ~ ~ ~ /summon Snowball ~ ~6 ~ {ownerName:"00000000-0000-0001-0000-000000000001",CustomName:"1",direction:[0.0,-30.0,0.0],Motion:[0.0,-0.9,0.0]}
复制代码

因为蓝方防御塔的UUIDLeast为1，当雪球砸到猪人身上时，猪人会判定雪球的ownerName，00000000-0000-0001-0000-000000000001和UUIDLeast：1为一对，所以猪人会向标签UUIDLeast：1为1的实体发起进攻（这里既蓝方防御塔）

不断生成雪球，不断拉仇恨：
  1. /scoreboard players set @e[score_fight4_min=12] fight4 0
复制代码

推塔兵的装备升级


推塔兵I   玩家需要3级等级



推塔兵II   玩家需要6级等级

创建以下积分榜：

  1. /scoreboard objectives add pigz dummy
复制代码
  1. /scoreboard objectives add pigz2 dummy
复制代码
  1. /scoreboard objectives add pigz3 dummy
复制代码

积分榜pigz和pigz3用于给积分榜pigz2加分
积分榜pigz2用于给猪人加分并升级猪人手中的装备

确保每个猪人都在的pigz积分榜上，方便给pigz2加分：
  1. /scoreboard players set @e[type=PigZombie] pigz 0
复制代码

给每个猪人的pigz3不断加分，方便给pigz2加分：
  1. /scoreboard players add @e[type=PigZombie] pigz3 1
复制代码

当pigz3分加到一定程度时，给pigz2加
  1. /execute @e[type=PigZombie,score_pigz3=12] ~ ~ ~ /scoreboard players add @e[type=PigZombie,score_pigz=0] pigz2 1
复制代码

探测猪人pigz2分数=1时，给猪人添加装备：
  1. /testfor @e[type=PigZombie,team=blue,score_pigz2_min=1,score_pigz2=4]
复制代码
红石比较器一头连上输出以上指令的命令方块，另一头连上输出猪人装备的无循环激活的命令方块

确保能够不断给每个猪人更换装备，pigz2的分值不能过大，因为分值过大会导致更换装备过慢所以score_pigz2=4是一个合适的数值

限制pigz2和pigz3的加分：
  1. /scoreboard players set @e[score_pigz2_min=10] pigz2 10
复制代码
  1. /scoreboard players set @e[type=PigZombie,score_pigz3_min=12] pigz3 13
复制代码

有人会问：为什么要添加两个辅助加分榜？为什么要限制加分？
原因是：pigz只是一个辅助加分，方便探测到每一个推塔兵，不是pigz2主要加分来源，pigz3才是，因此一个用于探测，另一个用于真正的辅助。
至于限制加分，这是个非常重要的为题。因为从/execute @e[type=PigZombie,score_pigz3=12] ~ ~ ~ /scoreboard players add @e[type=PigZombie,score_pigz=0] pigz2 1”这条指令上我们可以发现，pigz3分数小于12的猪人才能给自己加分。如果猪人过多，加分的速度越快，装备很可能就不能及时换上。所以，我们把pigz3_min=12的猪人的pigz3分数设为13，是不让装备换好的猪人参与加分，这样以来及时猪人再多，加分的速度也不变（猪人越多pigz3的速度加分越快，每增加一个猪人就提升2倍的加分速度）
