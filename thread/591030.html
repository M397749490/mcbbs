这是java导致的，你这个Mod沉浸工程ImmersiveEngineering-0.7.2.jar是在java8环境下制作的，我给你刷新下记忆

Java 1.7 是使用ConcurrentHashMap#keySet() returns a Set<K> 而  1.8 是 ConcurrentHashMap#keySet() returns a ConcurrentHashMap.KeySetView<K,V>`.

总之你要么升级服务器的java，要么拿掉这个Mod
