标题: 关于工业2exp里cfg的使用与IC2合成配方的疑惑
故事是这么开始的：我和小伙伴一起钻研怎么用ic销毁/循环利用万恶的hot water，在查资料的时候发现minetweaker3可以修改ic提取机的配方，但是本着少装一个mod是一个的心态解压了ic的mod，然后在\assets\ic2\config找到了文件名叫extractor.ini（提取机）的ini，打开看到了如下一段文字：
  1. ; To change/remove/add/replace recipes, modify this file and put it in the
  2. ; "minecraft/config/ic2" folder. Do NOT modify the file inside of the IC2 jar file.
复制代码
大意是：想修改配方，复制这个文件到"minecraft/config/ic2"目录下再修改（为什么不是.minecraft呢）。请勿修改jar里的文件。

众所周知误，config目录里ic2的cfg只有IC2.ini一个。但是extractor.ini标注的建立时间是15年，其中shaped_recipes.ini和shapeless.ini更是在15年3月6号被添加进jar（版本号#417）但是我们并不看Jekins的变更记录所以没有人发现。
提取文件之后，我参照漂白羊毛的代码，把
  1. ; Compressed Air Cell
  2. IC2:itemCellEmpty@5 = IC2:itemCellEmpty
复制代码
改成
  1. ; Empty Cell Recycle
  2. IC2:itemCellEmpty@* = IC2:itemCellEmpty @ignoreSameInputOutput</font></font></font>
复制代码
这样所有装了东西的单元都能通过提取机还原回空单元了从此ic有了自己的液体垃圾箱。这是路径下所有ini对应的机器：
blast_furnace 高炉
block_cutter
方块切割机
compressor压缩机
extractor提取机
general （即config\IC2.ini）
macerator 打粉机
metal_former_cutting 金属成型机_切割模式
metal_former_extruding 金属成型机_辊压模式
metal_former_rolling 金属成型机_拉伸模式
ore_washer 洗矿机
shaped_recipes 工作台_有序合成
shapeless_recipes 工作台_无序合成
thermal_centrifuge热能离心机
uu_scan_values （不详）

抱着“搞不好能修复热能离心机不能合成的bug”的心态，打开shaped_recipes.ini，仔细查看结构之后发现一坑未平一坑又起：一些配方，比如火力发电机，是有2个配方的，一个铁炉配方一个火炉配方，但是游戏里只能用第一个！所以下面这句注释到底说了什么……
  1. ; Line breaks are only allowed with a leading \ character, but never before =.
复制代码
按照完整的格式写完代码之后，游戏里还是只能用一个，这次变成我刚改的那个了……难道还有别的mod掺和把多余的配方删掉了？

恩....总之就是个修改ic2配方达成热水销毁的效果....这样做热核就不需要什么鬼蒸汽机了

另外，关于uu_scan_values， 这个东西是记载了一些方块或物品定义的uu值(复制一个这个东西需要多少UU)
这东西会被ic2拿来计算用UU复制其他东西所需要的量是多少。
ic2会根据这个和他知道的合成配方去计算所有根据配方产出的东西的UU值(所以要是有别的mod的东西能被ic2从配方找到，那么那个东西就可以用uu复制)
