标题: iCraftCDN —— 更方便的下载服务端和插件
本帖最后由 zjc2004 于 2020-7-21 10:59 编辑

这个是我为了方便我自己快速下载各个服务端而搭建的，基于网站目录程序 Directory Lister呈现，利用定时指令来获取最新的服务端。
不保证全部区域都有高的下载速度。
Server文件夹内是服务端，Plugins文件夹内是插件我只放置了一些常用的、经常更新的服务端或插件，如果你想在上面添加别的服务端/插件，欢迎联系我。
同步脚本可于此查看https://github.com/sheip9/iCraftCDNSyncShell

插件/服务端的名字是固定的，后面不带版本号，大家可以利用此在开服的时候添加数行指令使实现开服时自动获取最新的服务端和插件（谨慎使用）
示例：
Linux:

  1. wget -O paperclip.jar http://cdn.icraft.team/Servers/Paperclip-1.16.jar
  2. wget -O plugins/EssentialsX.jar http://cdn.icraft.team/Plugins/EssentialsX/EssentialsX.jar
  3. java -YourOpinion -jar paperclip.jar
复制代码

Windows:
  1. certutil.exe -urlcache -split -f http://cdn.icraft.team/Servers/Paperclip-1.16.jar paperclip.jar
  2. certutil.exe -urlcache -split -f http://cdn.icraft.team/Plugins/EssentialsX/EssentialsX.jar plugins/EssentialsX.jar
  3. java -YourOpinion -jar paperclip.jar
复制代码

如有不足，欢迎提出。
