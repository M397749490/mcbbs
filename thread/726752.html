跨服传送菜单

◆ 插件介绍 ◆
本插件可让玩家在进入服务器的时候获得一个物品（可配置），玩家点击物品即可打开子服选择菜单，点击相应按钮即可传送至子服，适合安装在群组服务器的登录服，菜单内按钮除了传送至子服外，还有许多其它功能
使用该插件 将其放入子服文件夹即可 不需要放入BC

插件特点
子服开启/关闭 按钮显示不同
可给菜单按钮lore添加多种变量 如在线玩家数 最大玩家数 ping值等等



PlaceholderAPI变量支持
千种变量 -> PlaceholderAPI变量大全


点击按钮 -> 打开网页
点击按钮后会在聊天栏显示一段文字，点击文字即可打开网页


点击按钮 -> 显示一段文字
可用于介绍服务器玩法 服务器规则等


点击按钮 -> 打开子菜单
适合某些需要分各个子服的小游戏

◆ 指令&权限 ◆

指令只有一个

默认不需要给玩家任何权限 如果你想添加权限限制 请参配置文件

  59. background-pinging: true

  62. # 如果你的服务器响应极慢 请设置的高一点

  67. # 该设置项有bug 当还处于冷却中时 再次点击可以将此物品从背包内取出
  68. # 所以不推荐设置 可能在你把background-pinging设置成false后才会稍微起点作用
  69. # 如果真的要设置，请设置一个大于1000的值，任何小于1000的设置值都会当做0来看待
  70. selector-open-cooldown: 0

  72. # 设置缺失的语言字段 比如 -> cooldown-message: ''
  73. cooldown-message: '&c你现在不能使用这个 请等待 {x} 秒'


  76. # -------------------- 子服选择菜单 -------------------- #

  78. # 没有权限 ssx.drop 的玩家将不能丢出子服选择菜单物品
  79. cancel-item-drop: false

  81. # 没有权限 ssx.move 的玩家将不能在背包内移动子服选择菜单物品 包括把物品切换至副手
  82. cancel-item-move: false
