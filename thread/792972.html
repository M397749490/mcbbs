作者: AAAA哥    时间: 2018-5-1 01:18
熟知的地皮插件有两个。
一是plotme、二是ps,也就是plotsquared
plotme的话比较常见,容易使用。ps的话(plotsquared)基本上使用起来有一点麻烦,但功能比较丰富,比如合并地皮。新手不建议直接用ps上手。（熟悉了plotme想转换ps的话,ps有转换命令）
首先是plotme，下载地址是http://www.mcbbs.net/thread-236421-1-1.html
这个的话创建方法很简单，基本上输入一段命令就能解决。
  1. /mv create plotworld normal -g PlotMe-DefaultGenerator
复制代码

然后是ps，下载地址是http://www.mcbbs.net/thread-573771-1-1.html
创建比较麻烦,两种办法
方法一（命令搬运于原帖）
  1. /plot setup
  2. /plot setup PlotSquared
  3. /plot setup default
  4. /plot setup 地皮高度 设置为64就好了
  5. /plot setup 地皮大小
  6. /plot setup 地皮下面的方块的ID 一般都是泥土 ID为3 如有需求可自定义
  7. /plot setup 地皮表面方块ID 一般是草方块 ID为2
  8. /plot setup 没认领前围墙的ID 默认是44
  9. /plot setup 认领后围墙的ID 默认是44:1 两个应该可以设置相同方块
  10. /plot setup 路面宽
  11. /plot setup 路面高 设置64就可以了
  12. /plot setup 路面的方块 默认是石英块 ID155
  13. /plot setup 墙下面的方块 默认是石头 ID1
  14. /plot setup 墙的高度 一般是64
  15. /plot setup true/false 是否开启基岩
  16. /plot setup 世界名字 不能中文
复制代码

方法二
下载地皮模版,比如ps宣传图带有的那个城镇。再输入以下命令即可（站内同样附带有地皮的模版）
  1. /plot template import [地皮世界名字] [文件名]
