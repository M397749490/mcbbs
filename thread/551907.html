作者: a2605393469    时间: 2016-2-5 01:33
有一种办法就是圈地之后PVP权限是直接开启的不是关闭的，打开领地配置文件config。
找到下面
    ResidenceDefault:
        build: false
        use: false
        container: false
        pvp: false         #<<<一一此处改成true
        tnt: false
        creeper: false
        flow: false
        piston: false
        ignite: false
        firespread: false
以后你服务器所有人圈地之后，领地就是默认开启PVP权限，想关系就需要手动关闭
