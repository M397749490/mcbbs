这是一个和PlotMe类似的地皮插件，功能差不多，且强大很多。

创建方式：
Multiverse-core插件：/mv create competition_world normal -g InfinitePlots
MultiWorld插件：/mw create competition_world Plugin:InfintePlots
其中competition_world可以改成你想要的世界名称
如果不想要默认的地皮大小，那么创建世界时输入
(这是Multiverse-Core的)/mv create competition_world normal -g InfinitePlots:地皮的宽
MultiWorld不知道怎么弄


命令：

/plot info 地皮信息

/plot name 设置地皮名称

/plot claim 领取脚下的地皮

/plot unclaim 将脚下的地皮删除

/plot addbuilder 添加可以建筑的玩家

/plot removebuilder 效果和上面相反

/plot flag 设置地皮权限标记

/plot setbiome 设置生物群系

/plot reset 重置地皮

/plot decorate 生成建筑，好像是用schematic文件

/plot protection 保护，具体输入命令查看

/plot list 查看有权限的地皮列表
