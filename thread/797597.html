“这服怎么玩？” 想必刚刚进服的玩家看到服务器里丰富杂乱的玩法，常常会感到找不到头绪，而现在，可以使用本插件的各个场景教程来一步步引导玩家，让玩家快速熟悉服务器玩法。本插件适合：制作新手进服教程，展示服务器地图上每个地标及其用途，指引玩家找到NPC，制作RPG服过场剧情等等

场景设置
一个完整的教程由多个“场景”串联而成，可设置每个场景将玩家传送到某地点，显示聊天/actionbar/title消息，触发控制台指令，添加药水效果等，还可锁定玩家动作和目视角度，让玩家专心进行教程

MySQL支持

教程与场景
正式开始本插件教程之前先介绍两个指令：
  • /st save - 保存已编辑内容至配置文件
  • /st reload - 从配置文件重载
这两个指令请务必经常使用，以避免在游戏里编辑的内容丢失

创建教程与场景

  • 使用指令/st create <教程名> 创建教程
  • 使用指令/st addpoint <教程名> <切换方式> 创建一个场景，<切换场景>可选timed延时，clickblock点击方块，checkpoint到达坐标（注意，你执行此指令时所站的位置会被默认设置为该场景开始时的位置[timed]/你需要到达的位置[checkpoint]，而你的“腿”所处的那个方块会被设置为需要点击的方块的位置[clickblock]）
  • 重复创建多个场景，你也可以在配置文件tutorialsaves.yml里编辑场景
  • 每个场景都有场景序号，执行教程时会按照场景序号一个一个进行，第一个场景的序号是1（但是在配置文件中是0，千万不要搞混，实际场景序号-1=配置文件中序号）


编辑场景

当一个场景在进行中时会发生什么？可以通过指令编辑或者配置编辑来给场景添加各种元素
插件提供了非常清晰的指令来给场景添加元素，消息类内容均可添加彩色代码，指令类内容可添加PlaceholderAPI变量（玩家名变量是%player_name%）

  • 给场景添加Title标题
/st editpoint <教程名> <场景序号> title <title/subtitle> <内容>

  • 给场景添加actionbar消息
/st editpoint <教程名> <场景序号> actionbar set <内容>

  • 给场景添加显示的聊天消息，可多条
/st editpoint <教程名> <场景序号> messages add <内容>

  • 给场景添加触发的控制台指令，可多条
/st editpoint <教程名> <场景序号> commands add <不加斜杠的指令>

  • 给场景添加音效
/st editpoint <教程名> <场景序号> sound set <音效名>

  • 手持一个烟花火箭，给场景添加烟花效果
/st editpoint <教程名> <场景序号> firework add

  • 手持一个药水，给场景添加药水效果
/st editpoint <教程名> <场景序号> potion add

  • 该场景进行时玩家不能随意移动
/st editpoint <教程名> <场景序号> lockplayer true

  • 该场景进行时玩家不能随意转动视角
/st editpoint <教程名> <场景序号> lockview true

教程NPC

本插件自带了生成NPC的特性，但是生成的NPC能直接打死……
所以还是绑定Citizens生成的NPC吧

使用指令/st npc bind <NPCID> <教程名> 便可将教程绑定至NPC
完成后的NPC头顶会自带两行悬浮字内容，可通过下列指令设置这两行字的内容
  • /st npc text <NPCID> top <文字内容>
  • /st npc text <NPCID> bot <文字内容>

可使用下列指令调整这两行字的高度
  • /st npc height <NPCID> <数值>
