然后是原理

好啦，其实就是用一个箱子矿车往玩家脸上糊，然后玩家点击即可打开菜单。
至于如何判断玩家是否点击：
（lz这里使用了穷举，穷举每一个格子，这里列出1个）
（@s为菜单箱子矿车）
  1. scoreboard players tag @s add Have0 {Items:[{Slot:0b}]}
复制代码
  1. execute @s[tag=!Have0] ~ ~ ~ execute @a[tag=CartOwner] ~ ~ ~ function hbcommand:commands/slot0
复制代码
（不知道为什么这两条写在一个代码框里会被吃掉一个）
就是说那个矿车有{Slot:0b}（即那格有物品）时加一个Have0标签
如果那个矿车没有Have0则执行命令

至于如何关联玩家和其对应的菜单
我这里用了PlayerID和OwnerID计分板
要检测时用PlayerID减去OwnerID（或者反过来）
PlayerID为0的玩家即为拥有者。

如何检测玩家不手持菜单：
  1. scoreboard players set @a Cart 1 {SelectedItem:{id:"minecraft:clock",tag:{display:{Name:"§6§l菜单"}}}}
  2. execute @a[tag=HoldingMenu,score_Cart_min=2,score_Cart=2] ~ ~ ~ function hbcommand:system/remove
  3. scoreboard players set @a Cart 2 {SelectedItem:{id:"minecraft:clock",tag:{display:{Name:"§6§l菜单"}}}}
  4. execute @a[tag=HoldingMenu,score_Cart_min=1,score_Cart=1] ~ ~ ~ function hbcommand:system/remove
