#1 导出插件Jar时出现"资源与文件系统不同步"解决方法

回归正题，解决方法:
NotePad++保存好之后，右键eclipse中的yml文件
之后直接按F,嗯其实就是刷新了。
再导出就木有问题了



#2 写了个变量，出现了"The local variable 变量名 is never read"?

:嗯，这东西是什么回事？怎么没有解决方法？解决就直接清空？是我写错变量了吗......
:嗯？翻译之后又是什么鬼？局部变量从来没读取过????
好吧，说白了其实就是:
这个变量从未使用过。
不用理，继续往下写。你写好功能之后自然会消失，因为使用过了



#3 怎么在Config.yml配置文件中使用变量和& 在线等 急!!!

这个主要俩种方法
一个是{{ var }}直接写在YAML的值里
能不能用我不知道(这特么是官方文档说的)
(var = 变量名) {{ }}为俩个而且不可以改

另一个是主流的方法。用String的一个变量.replaceAll(改动符, 改动后)
这种方法可以很完美的作用到配置文件中。我们可以这样写
String cf1 = getConfig().getString(路径).replaceAll( //[变量//], a);
//是正则表达式的转义，你只要使用了[，]，{，}，.(小数点)都要转义
转义方法就是在字符前加" // "
功能就是获取Config中"路径"的一个String,并把里面的"[变量]"替换为变量a
效果比如: (假设变量a值为Player)
原句:你对[变量]造成了99点伤害
修改后:你对Player造成了99点伤害(这也是你获取到的内容)
之后就可以直接player.sendMessage(cf1)了
(不知道你们懂没懂2333)
(至于为什么用All,因为某些情况下直接replace会提示类型 'char' 报错，只能替换单字节字符)

接下来就是这么用&了
通过上面的方法
config.replaceAll("&","§")
即可.
