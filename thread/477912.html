v0.3.1版本!

本插件通常为BC蹦极端大厅子服务器使用
作用是将大厅的插槽物品无法进行
移动
丢弃
捡取
只支持1.8.x
(假如大厅有本“管理菜单”或“新手入服手册”)
（那么你肯定非常需要此插件!）
Spigot链接

插件指令:
/proitem -查看作者信息
/proitem reload -重载配置文件

插件权限:
moveitem.bypass -可移动物品
itemdrop.bypass -可丢弃物品
itempickup.bypass -可捡取物品
proitem.reload -重载配置文件


配置文件详解:
#作者:Lamplight(By)
#插件首发地址为www.Mcbbs.net
#欢迎光临中国 “我的世界” 论坛!

# true 为确定/false 为否定

#关闭物品在库存里移动?
disable-item-move: false
#关闭物品在库存里丢弃?
disable-item-drop: false
#关闭物品在库存里捡取?
disable-item-pickup: false

#移动激活音效
Enablemovesound: true
#音效设置
No move sound: CHICKEN_EGG_POP

#丢弃激活音效
Enabledropsound: true
#音效设置
No drop sound: CHICKEN_EGG_POP

#捡取激活音效
Enablepickupsound: true
#音效设置
No pickup sound: CHICKEN_EGG_POP

#不允许移动时是否关闭背包
No move close: true

#插件前缀
prefix: "&4&l[安全物品保护] "
#库存里无法移动语言设置
moveitemMessage: "&c&l服务器不允许移动物品!"
#库存里无法丢弃语言设置
itemdropMessage: "&c&l服务器不允许丢弃物品!"
#库存里无法捡取语言设置
itempickupMessage: "&c&l服务器不允许捡取物品!"
noperm: "&6&l你没有权限执行此指令!"
reload: "&d&l插件已重载!"




##        是否开启语言提示?
Message: true
#        单独插槽是否允许移动
#        1-9从左往右依次数
#         true 为不允许移动/false 为允许移动
