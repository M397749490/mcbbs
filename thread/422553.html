作者: 上白丶慧泽音    时间: 2015-3-15 18:52
  [礼包名]:
    delay: 86400
    items:
      - 物品ID 数量
/mangadd [组名字]
/mangaddp [组名字] essentials.kit.[礼包名]
/mangaddv [组名字] build true
/mangaddv [组名字] prefix [称号内容]
/mangaddi [组名字] default
/mangaddi [组名字] builder

/manuadd [玩家] [组名字]
/mangaddp [组名字] essentials.[指令]  只支持essentials命令 如给tp essentials.tp 飞行  essentials.fly
/manload 保存下配置
