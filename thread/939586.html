代码如下
  1. double new_timeStemp = System.currentTimeMillis();  //获取最新的时间戳
  2. double old_timeStemp = database.getLong("playerData.TimeStemp");  //获取插件目录下已保存的时间戳
  3. String old_date = new SimpleDateFormat("yyyyMMdd").format(old_timeStemp);  //将已保存的时间戳转成Date形式（只保留了年月日）
  4. String new_date = new SimpleDateFormat("yyyyMMdd").format(new_timeStemp); ////将最新的时间戳转成Date形式（只保留了年月日）
  5. sender.sendMessage(old_date);  //发送出一条旧的时间戳的message
  6. sender.sendMessage(new_date + "new"); //发送出一条最新的时间戳的message 为了方便区分 我在后面加了"new"这个单词
复制代码
然鹅游戏中在生成第一次时间戳配置的时候
转换成date的时间是对得上的
