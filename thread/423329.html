请在plugins\GroupManager文件夹下找到config.yml文件打开之后搜索
          all_unnamed_worlds:
          - users
          - groups
删除这些将所有世界权限独立。。。
/nick可以再ess文件下配置     
搜索command-costs:
  # /example costs $1000 PER USE
  #example: 1000
  # /kit tools costs $1500 PER USE
  #kit-tools: 1500
在后方按照格式添加
/nick:100000
可是玩家在使用此项命令时花费10W元

                                             如有错误欢迎大家指出~
