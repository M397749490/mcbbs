插件简介
  • 觉醒插件，一款可以进行六次觉醒的插件
  • 有一至五觉，还有至高觉醒 为服务器增加了玩法
  • 注:本插件必须在JAVA8的环境下运行
  • 注:本插件必须有Citizens作为前置插件


指令
  • 指令/Am zh ID 数量 给玩家多少个铸魂石
  • 指令/Am jx ID 数量 给玩家多少个觉醒石
  • 本插件的指令默认OP才能使用
  • 玩家使用将提示没有此命令




食用方法
  • 觉醒插件内有铸魂石和觉醒石
  • 需要先将武器铸魂才能进行觉醒
  • 分别有无觉醒、一觉、二觉、三觉、四觉、五觉、至高觉醒
  • 觉醒等级越高几率越低 失败还有几率降低觉醒级数
  • 若失败将会有几率降低觉醒级别
  • 无觉醒 -> 一觉 几率80% 失败掉觉 0% 增加伤害3%
  • 一觉 -> 二觉 几率50% 失败掉觉 20% 增加伤害7%
  • 二觉 -> 三觉 几率20% 失败掉觉 20% 增加伤害16%
  • 三觉 -> 四觉 几率8% 失败掉觉 20% 增加伤害35%
  • 四觉 -> 五觉 几率2% 失败掉觉 20% 增加伤害50%
  • 五觉 -> 至高觉醒 几率0.1% 失败掉觉 5% 增加伤害100%

安装方法

JAR安装
直接安装JAR文件 安装之前并没有安装过名字为pvpin_js_rt的插件[我的原创插件]
若有也是可以安装的 可能会有不必要的麻烦
  • 下载最新版的插件
  • 把它放在你的服务端plugins目录下
  • 确保服务端里面有Citizens插件
  • 确保服务器是JAVA8环境
  • 重启服务器
  • 收集BUG并反馈


JS安装
安装JS文件 必须确保之前已经安装过pvpin_js_rt的插件[我的其他{非鉴定插件}原创插件]
安装过鉴定JAR【插件】后就不需要再次安装JS文件了
  • 下载最新版的JS
  • 把它放在你的服务端pvpin/plugins/player目录下
  • 确保服务端里面有pvpin_js_rt插件[我其他的原创插件]
  • 确保服务端里面有Citizens插件
  • 确保服务器是JAVA8环境
  • 重启服务器
  • 收集BUG并反馈
