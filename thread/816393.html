前言

记得以前有一种说法，说马的血量越高跑的速度越慢，后来又看见某红石大佬（记不清是谁了）的一个视频中测量马奔跑速度的小装置，于是今天突发奇想，用1.13的新命令data研究了一下马的血量与速度的关系


提出猜想

马的血量越高，移动速度越慢



验证猜想

#以下内容涉及具体指令，不想看可跳过

①先添加两个dummy型记分项"speed"和"health"
  1. scoreboard objectives add speed dummy "speed"
复制代码
  1. scoreboard objectives add health dummy "health"
复制代码

②之后弄两个循环不受制约保持开启的命令方块分别输入
  1. execute as @e[type=minecraft:horse] store result score @s health run data get entity @s Attributes[0].Base 10000000
复制代码
  1. execute as @e[type=minecraft:horse] store result score @s speed run data get entity @s Attributes[2].Base 1000000000
复制代码

   用于存储每只马的"generic.maxHealth"和"generic.movementSpeed"属性值
   （此两命令结尾的数值可调整，用于放大数据使其更精确）
③记住以下指令以便切换查看两项数据的值
  1. scoreboard objectives setdisplay sidebar speed
复制代码
  1. scoreboard objectives setdisplay sidebar health
复制代码

至此，大功告成！快召唤几只马试试看吧~ ovo
