你设定不刷怪那么肯定不刷

你可以把
      animals:
        ==: MVSpawnSubSettings
        spawn: 'false' 改成 true
以及
      monsters:
        ==: MVSpawnSubSettings
        spawn: 'false' 改成 true

或者游戏内输入指令
/mvm set monsters true 世界名称 ←启动刷怪
/mvm set animals true 世界名称 ←启动刷动物

true改成false就是关闭。
