http://www.mcbbs.net/thread-552368-1-1.html
(出处: Minecraft(我的世界)中文论坛)
这个可以做到 下载相应的插件版本加入服务器
然后手持需要拿着而不能右键使用的岩浆
再输入/banitem nbt add d:-1 这个并不是ban掉物品 而是检测nbt
再次输入/banitem add f:useinnbt 进行不能使用但是可以参与合成或者拿在手上
如果要进行没收/banitem add f:useinnbt c:true

【推荐方案】使用Essentials插件(ESS)：

  2.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  3.   # 你加载了一次Essentials后,就可以在plugins/Essentials/items.csv中找到物品ID列表.
  4.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  5.   alert:
  6.     on-placement: 10,11,46,327
  7.     on-use: 327
  8.     on-break:

  10.   blacklist:

  12.     # 阻止玩家放置以下方块
  13.     placement: 10,11,46,327

  15.     # 阻止玩家使用以下物品
  16.     usage: 327
复制代码

   在ess的配置文件中查找那些禁止掉岩浆(id:10,11,327)的选项，去掉它们。如去掉 useage 中的 327 ，然后重载。
   随带一提，玩家们可能需要建筑权限和使用权限.
