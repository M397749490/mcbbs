世界边界
为了防止跑图，世界边界可以在每个地皮世界启用。选项可以在 worlds.yml 中的 worlds.<world>.world.border
地皮边界会处在里中心地皮 (0,0) 最远的地皮上，而且会防止区域外的区块读取。
如果你在边界之外已经有了地皮，世界边界不会很有效。

你可以使用地皮的过时系统：
在资料夹中 settings.yml 寻找以下节


  2. enabled-components:
  3.   plot-expiry: false
复制代码

  2. #这是一个实例
  3. auto-clear:
  4.   task1:
  5.     threshold: 1
  6.     required-plots: -1
  7.     confirmation: true
  8.     days: 7
  9.     worlds:
  10.     - "*"
  11.     # See: https://github.com/IntellectualSites/PlotSquared/wiki/Plot-analysis
  12.     calibration:
  13.       variety: 0
  14.       variety-sd: 0
  15.       changes: 0
  16.       changes-sd: 1
  17.       faces: 0
  18.       faces-sd: 0
  19.       data-sd: 0
  20.       air: 0
  21.       air-sd: 0
  22.       data: 0
复制代码
要启用地皮过时管理，把 'enabled' 改为true，然后设置过时的天数。如果玩家超过这个天数没有上线，地皮会被清除。
取自- Minecraft插件百科
