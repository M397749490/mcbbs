VirtualChestEnchantments



一个用于执行命令时附魔物品的 VirtualChest 附属

插件依赖的 VirtualChest 版本不得低于 1.0.0-rc-4

下面是一段利用了 VirtualChestEnchantments 的示例：

  1. virtualchest {
  2.   Rows = 1
  3.   TextTitle = "&f效率五"
  4.   UpdateIntervalTick = 20
  5.   Slot4 {
  6.     Item {
  7.       ItemType = "minecraft:diamond_pickaxe", UnsafeDamage = 0, Count = 1
  8.       DisplayName = "&a点击左键或右键为钻石镐附魔效率五"
  9.     }
  10.     Action {
  11.       CommandBefore = "tell: &a为玩家 %player_name% 附魔效率五"
  12.       Command = "enchant: minecraft:efficiency:5"
  13.       KeepInventoryOpen = true
  14.       HandheldItem {
  15.         ItemType = "minecraft:diamond_pickaxe"
  16.         SearchInventory = true
  17.       }
  18.     }
  19.   }
  20. }
