                                               §1.5 使用注释


这一节我们来学习使用注释。对语句进行注释是个很好的习惯，如果语句很多的话，写着写着就会忘记前面写的代码的作用，很可能需要重写。而这个时

候正好体现出了注释的重要性，添加注释，除了自己方便阅读，更可以让别人更好理解自己的程序，所以我们需要进行一些注释，方便别人阅读你的代码。

·  使用注释的方法：
注释在任何地方都能用~
-   注释的种类
    单行注释
    // 这是这是个单行注释个单这是个单行注释行注释
    多行注释
/*
这是多行注释
这是这是多行注释多行注释
这是多这是多行注释行注释
这是这是多行注释多行注释

这是多行注释
*/
