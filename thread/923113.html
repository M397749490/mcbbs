#1 - 内核汉化的软件安装

/

在这里，我们使用< Class Edit >作为我们的内核汉化软件
使用这款软件的原因是他方便好用，还支持搜索功能等

下载页面: https://sourceforge.net/projects/classeditor/

嗯，下载之后，你应该会得到一个压缩包，打开，主体就是里面的
ce.jar(或者是classedit.jar)
双击打开就行啦，方便又快捷！虽然页面是全英文
不过你可以尝试用这个软件汉化这个软件，嘿嘿嘿

#2 - 内核汉化软件的使用

/

在这里，我们使用< Class Edit >作为我们的内核汉化软件
使用这款软件的原因是他方便好用，还支持搜索功能等
······


/

你现在应该已经打开了
ce.jar
我们或许可以看见如下页面:


这就对了,说明成功运行了

那么接下来，我们就要开始使用它。我们先要把文件载入进去


点击右上角的" Open "，会出现文件选择页面。请注意，这里需要的不是jar文件，而是class文件！
提取Class文件的方法:
你需要有一个压缩软件，如好压。之后右键jar包，在拉出的菜单中找到
" 解压到当前文件夹 " / " 解压到 xxxx "
选择，解压。这时候你应该会获得一些文件:


如上，这个示例插件连config都没有，更别说语言文件了
但它内部确实有一个Gui菜单，全英文，这就是我们汉化的目标

META-INF以及像config诸如此类的配置文件不用理会。还有Luange......等等
我们只需要注意一下com，org等文件夹。双击打开它，你可能还会见到N个文件夹
一路打开过去，直到看见一大堆Class文件，如下图


推荐使用jd-gui等反编译工具查看源代码。当你找到一些字符串，而且它确实有显示出来的话，那就是你汉化的目标了


使用刚刚介绍的软件沿着你解压出的插件文件路径，找到Class文件，打开
这时，你的Class Edit应该会变成这样:


太棒了。不是吗？我要怎么开始修改捏......
不要着急，点击这里:


接着，你又会看见一些乱啊七啊八啊糟啊的东西。不要紧，我们点击这里:


然后会弹出一个下拉菜单。我们拉到最下面，点击" UTF8 "


然后选定后，在点击旁边的" Apply "


接着，会出现一些变化


这就是我们要汉化的东西啦。当然，里面也混杂了一些其他的东西
我们需要有足够的视力，或许使用......搜索功能



瞧，出现了！这时候我们就需要修改它们了。我们需要把右上角的" 只读模式 "点击一下，设为关闭



看，现在我们可以编辑了。我们可以直接编辑编辑区中的最后一行，也就是那串信息



编辑好后，点击下方的" Modify "


接着在上面一行行的列表里随便点击一个，看见你刚刚编辑的那个变成了:


说明修改成功。此时的Class文件已经自动保存。全部汉化完毕后，我们就可以将Class文件打包
打包和解压一样，当你编辑了多个Class文件的时候，可以直接选定你刚刚解压出来的文件，新建一个后缀为" .jar "的压缩文件
你要确保，这个压缩文件一打开，就可以看见 Plugin.yml 文件！(bukkit的,Sponge同理)
或许，你可以直接把编辑好的Class文件拖进jar包里。
之后一如既往，丢进服务端的Plugins文件夹，即可运行测试。
