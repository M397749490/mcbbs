    先说好，这个插件是一个让玩家给服务器投票，顺便让玩家获得奖励的插件
    你可以让玩家在一些站点上给 你的服务器 投票

    既然这是一个投票生态相关的插件，显然得有个平台来提供此类功能
    言下之意，谁知道玩家有没有投票，谁来统计玩家投票数呢？这些都需要站点来承担

    目前，有一些站点，正在提供此类功能。
    国外站点较多(如 planetminecraft.com)，而国内站点则较罕见

国内生态正在建设中:

    如果你觉得这可能会是广告，可以不戳开来
    (下方示例来自 akadia平台，其站点正在绝赞测试中)

    它正在提供免费提供接收、验证、处理、储存、和发送玩家投票来帮助服主促进正反馈生态
    服主可添加votifier与本插件来加入投票生态，玩家为服务器投票后上线自动获取奖励。
    现已支持我的世界国际版、基岩版、手机版、无正版验证等服务器!

可高度客制化的 投票listener  插件，功能超多！

插件说明：
    这个插件是 投票listener 插件
    你在下面可以看到完整的 插件功能列表，其中有一些Wiki链接，戳进去以获得更多信息
    目前，该插件比其他使用了 votifier listener监听器 的插件具有更多的功能
    对于1.12和更早版本的服务器，请使用v5.13.6版本的插件，作者不再支持这些版本

    你必须正确配置 votifier(前置) 才能使投票生效
    每次玩家投票都将在后台里显示
    如果想要更方便地配置文件，你可能需要理解YAML语法

前置：
  • Votifier / NuVotifier / VotifierPlus（或使用votifier事件的任何其他插件）- 必须正确设置才能获得投票
  • Vault（可选）- 给予投票的玩家 金币的功能，需要vault才能正常工作
  • Java 8

插件特点：
  • 在投票后，可以给予玩家奖励：
    • 在特定站点或每个站点上，给服务器投票后给予奖励（在 VoteSites.yml 中配置）
    • 所有站点 All Sites - 在所有站点上投票的奖励
    • 首次投票 First Vote - 玩家首次投票的奖励
    • 投票次数（每天/每周），累积投票奖励 - 即投票x次获得奖励
    • 里程碑 Milestones - 在一定投票数后给予玩家奖励（可以每月重置）
    • VoteStreak - 在玩家连续投票x次后给予奖励（区别于上面的两个功能，是按GUI中每行单独计算的）
    • VoteParty - 服务器内（或已投票）的每个人在总投票数量达到一定值时都能获得奖励
    • VoteCoolDownEnded - 当玩家可以再次投票时给予奖励
  • 强大的奖励系统
    • 领奖励的许多特效：
      • 声音
      • 粒子
      • title 与 subtitle
      • 血条 bossbar
      • 快捷栏上面的 actionbar
      • 喷烟花
    • 获取奖励限定要求：
      • 权限
      • 世界（即白名单世界；玩家得呆在哪些世界里才能获得奖励）
      • 奖励几率
      • 玩家在线/离线（根据玩家是否 在线/离线 设置将会给予的奖励）
      • VaultGroup（为某些权限组提供奖励）
      • Javascript表达式（使用基于判断 true/false 的javascript表达式来给予奖励）
    • 基础奖励：
      • 执行指令
      • 给予物品（支持NBT）
      • 金币
      • 经验值
      • 发消息（发广播/发给玩家）
    • 高级奖励：
      • 延迟奖励（例如，延迟奖励10分钟）
      • 定时奖励（在特定时间发放奖励）
      • 随机奖励 / 随机执行指令
      • JavaScript表达式（只能使用基于判断 true/false 的javascript表达式）
      • 执行JavaScript
      • 优先级奖励（一串奖励列表，根据 权限/几率 从上往下依次执行，来给予玩家奖励）
      • 高级优先级（与上面的优先级相同，但不需要复杂的奖励文件）
      • 选择奖励（让玩家选择奖励）
      • 玩家离线时给予奖励
      • 药水
      • 幸运奖励（的确是看脸）
      • 选择在哪些服务器(子服)上给予奖励（在某些情况下有用，例如BC群组服上）
      • 重复奖励（重复执行奖励文件，重复一定次数或直到满足条件）
    • 配置文件的格式在所有文件中都一样（不会累死你）
    • 能够在插件中注入inject自己的 自定义奖励 和 奖励要求
    • 在奖励中使用javascript
    • 还有更多！
  • 投票提醒
  • 支持群组服
  • 投票信息：
    • 总票数（/vote total）
    • 上次您投票的时间（/vote last）
    • 下次什么时候可以投票（/vote next）
    • 今天谁投过了票（/vote today）
  • 你可以配置格式
  • 离线玩家的投票支持（默认支持）
  • 最佳投票者（所有时间/每月/每周/每天）- 可以按排名给予他们奖励
  • VoteForwarder-跨多台服务器投票
  • 支持Tab补全
  • 支持UUID
  • 使用json来修改提示信息
  • 牌子
  • PlaceHolderAPI扩展
  • 玩家可以使用GUI （/ vote GUI，/ vote top 等）- 你也可以禁用他们
  • 最佳投票者的计分板（只在禁用了GUI的情况下显示）
  • 投票可获得点数
  • 内置 VoteShop ，花费投票点来购买东西（你可以使用 BossShop 来获得更高级的功能）
  • 支持BossShop
  • 支持LeaderHeads
  • 支持AuthMe
  • 在游戏中用GUI配置文件（/ av GUI）
  • 支持Web网页
  • 从另一个插件转换
  • 支持 Flat file / SQLite / MySQL（能够切换和保留数据）
