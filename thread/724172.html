  • 这个插件可以给玩家发送的聊天信息添加颜色代码，使聊天看起来更加的炫酷，梨子之前也搞了类似的插件，但是这个插件比梨子的功能更多，因为它可以自定义添加的颜色代码，支持多种方案。
  • 没错，我就是来砸梨子的场子的。（ 梨子的插件: http://www.mcbbs.net/thread-446510-1-1.html ）









插件命令:
  • /rc help - 帮助列表
  • /rc list - 列出已加载的颜色方案
  • /rc enable <方案名字> - 开启颜色方案
  • /rc disable - 关闭颜色方案
  • /rc reload - 重载配置

插件权限:( /rainbowchat = /rc )
  • rainbowchat.admin.* - 所有管理命令
  • rainbowchat.default - 命令 /rainbowchat
  • rainbowchat.list - 命令 /rainbowchat list
  • rainbowchat.disable - 命令 /rainbowchat disable
  • rainbowchat.scheme.<名字> - 允许使用颜色方案
  • rainbowchat.admin.reload - 命令 /rainbowchat reload

颜色代码方案是允许自定义的，这里我不进行讲解，你可以自己看配置文件，很简单的，以下是作者提供方案的展示图:

















配置文件:
  1. # 插件输出信息的前缀
  2. prefix: "&b[&a炫彩&b聊天&a]"

  4. # 插件的优先级
  5. # 这里可以设置为: LOW, NORMAL, HIGH
  6. # 如果插件不能正常工作，请尝试调整为 NORMAL 或 HIGH
  7. priority: "LOW"

  9. # 炫彩方案部分
  10. schemes:
  11.   # 方案名字
  12.   gray:
  13.     # Colors:
  14.     # "colors" 中的每一个字符表示一个颜色代码
  15.     # 例如: "hello" 的输出将会变为 "&7h&8e&7l&8l&7o"
  16.     colors: "78"
  17.   rainbow:
  18.     # 只是彩虹的颜色的一个例子
  19.     colors: "4c6eab95"
  20.   admin:
  21.     # 如果你需要使一个字符添加多个颜色代码，请使用括号
  22.     # 例如: "hello" 的输出将会变为 "&b&lh&c&le&b&ll&c&ll&b&lo"
  23.     colors: "(bl)(cl)"
  24.   green:
  25.     # 你也可以将“无括号”和“有括号”组合在一起
  26.     # 例如: "hello" 的输出将会变为 "&a&oh&2e&a&ol&2l&a&oo"
  27.     colors: "(ao)2"
  28.   rgby:
  29.     colors: "ca9e"
  30.   red:
  31.     colors: "cc44"
  32.   pink:
  33.     colors: "(dn)(5n)"
  34.   redgreen:
  35.     colors: "(clo)(alo)"

  37. # 插件消息部分:
  38. messages:
  39.   # 全局变量 (你可以在下面任何一个消息中使用):
  40.   # %prefix% - 插件的消息前缀，在配置文件中第一项可以设置
  41.   # %cmd% - 替换为 /rainbowchat 或 /rc 命令
  42.   use_help_for_help: "%prefix% &c使用 /%cmd% help 获取帮助"
  43.   help_message: "%prefix% &a插件命令列表:"
  44.   # 插件命令列表格式: %subcmd% - 子命令; %desc% - 命令描述
  45.   help_cmdformat: "&a/%cmd% %subcmd% &e%desc%"
  46.   # 命令描述
  47.   help_help_desc: "命令列表"
  48.   help_list_desc: "已加载的方案列表"
  49.   help_enable_desc: "开启颜色方案"
  50.   help_disable_desc: "关闭你正在使用的颜色方案"
  51.   help_reload_desc: "重载配置文件"
  52.   arg_name: "<名字>"
  53.   list_message: "%prefix% &a已加载的颜色方案:"
  54.   # 当输入 /rc list 时，玩家有权使用的颜色方案前缀显示 (权限: rainbowchat.scheme.方案名字):
  55.   list_has_permission: "&a- "
  56.   # 无权使用的颜色方案前缀显示，你可以填写 <hide> 来隐藏显示无权使用的方案
  57.   list_no_permission: "&c- "
  58.   err_no_perms_list: "&c抱歉，你缺少权限运行此命令! (rainbowchat.list)!"
  59.   err_enable_second_arg: "%prefix% &c你需要提供一个方案名字!"
  60.   err_style_not_found: "%prefix% &c颜色方案未找到，请输入 /%cmd% list 查看所有方案"
  61.   # 以下两项的变量: %style% - 已开启的方案
  62.   enable_activated: "%prefix% &a颜色方案 %style% 开启成功，输入聊天内容试试吧!"
  63.   err_no_perms_for_style: "&c你没有权限使用 %style%!"
  64.   disable_disabled: "%prefix% &a颜色方案已关闭！"
  65.   err_no_perms_disable: "&c你没有权限使用这个命令 (rainbowchat.disable)"
  66.   reload_reloaded: "%prefix% &a插件配置文件已重载!"
  67.   err_no_perms_reload: "&c你没有权限使用这个命令 (rainbowchat.admin.reload)"
  68.   err_no_perms_default: "&c抱歉，你缺少权限运行此命令! (rainbowchat.default)!"
