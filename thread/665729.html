    这是一个用来管理、完服务器的插件。支持craftbukkit, spigot, cauldron, bungeecord

开源地址 https://github.com/IzzelAliz/BugRepGUI
目前版本 1.7
  • 自动回复或手动回复
  • 高度自定义
  • BungeeCord 支持
  • 现在在线的拥有提醒权限的技术/OP可以收到新提交的通知了!!!!
  • 统计信息
  • GUI面板管理
  • 使用SQLite / MySQL 数据库
  • 内置多语言(cn，en) 各种版本支持
使用姿势一览

1. 先提交一个bug

2. 接着OP/技术发现了#(滑稽)

3. 然后技术把这个bug给解决了，就可以给提交者发一些消息

4. 如果别人提交完了就下线了，他上线的时候就会收到通知



命令:


  2. /自定义 一个用于提交bug的自定义命令
  3. /bug view 查看所有已提交的bug
  4. /bug report 提交一个bug
  5. /bug view history 查看历史记录
  6. /bug stats text 查看文本统计信息
  7. /bug reload 重载此插件
复制代码

权限:

  1. bugrepgui.admin: BugRepGUI 所有的权限
  2.    bugrepgui.view: 可以查看所有的提交
  3.    bugrepgui.sendback: 允许给提交者发送消息
  4.    bugrepgui.execute: 允许你解决一个bug（也就是点一下        
  5.    bugrepgui.notify: 允许接受新提交的通知消息
  6.    bugrepgui.stats.text: 允许查看文本统计
  7. bugrepgui.user:
  8.    bugrepgui.report: 提交一个bug
复制代码
配置:

  1. #BugReportGUI设置
  2. debug: false
  3. #sqlite或者mysql
  4. database: sqlite
  5. #如果数据库设置为MySQL，这些就要填
  6. mysql-url: 'localhost'
  7. mysql-port: 3306
  8. mysql-username: ''
  9. mysql-password: ''
  10. mysql-db: ''
  11. ###########################################################################
  12. #这里是管bug列表里的时区和时间 #
  13. # 这里是一张国家代码表                                      #
  14. # [url=https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2]https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2[/url]                        #
  15. ###########################################################################
  16. locale: 'US'
  17. #多语言设置，目前有cn，en
  18. lang: 'en'
  19. #当你按着shift键左键单击一个bug，就会自动发送这段话
  20. auto-sendback-msg: '§eThanks for your reporting'
  21. #用于自定义结束输入的文字,默认#end#
  22. #目前只支持数字，英文字母，部分标点
  23. stop-sign: '#end#'
  24. #用于提交bug的自定义命令
  25. alias: 'report'

关于汉化

第一次启动后，汉化可能为乱码，请打开目录下的lang_cn.yml，更改编码为UTF-8，输入/bug reload 即可

你需要在每个子服务器和bungee服务器上安装这个插件，并且每个插件都必须设置MySQL。
