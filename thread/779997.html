                                         简介
                                这个插件能让你服务器的红石火把“全新升级”，让你的红石火把能够感应一些事件
                                                               并做出一定的反应（熄灭点燃）


                                         特点
                                                                       制作、放置红石传感器（以下简称RPS）
                                                              通过右键修改RPS的传感条件
                                                           无需重新加载插件便可重载配置（雾
                                                              可以设置每个按钮的所需权限
                                                                  
                                                                  命令
/ignorerps[size=14.6667px]: 通过[size=14.6667px]rps.invisible这个权限，你可以使用这个命令来切换RPS的状态（绕过设置）
/rps reload[size=14.6667px]: 重载config配置文件
/rps give <user> [amount][size=14.6667px]: 给予一个玩家RPS

                                                       支持插件

                                                                         权限

rps.place (默认玩家拥有)[size=14.6667px] : 允许玩家放置RPS
rps.create (默认玩家拥有)[size=14.6667px] [size=14.6667px] : 允许玩家制作RPS
rps.admin (默认OP拥有)[size=14.6667px] : 允许玩家使用/rps
rps.invisible(默认OP拥有)[size=14.6667px] : 允许使用/[size=14.6667px]ignorerps熄灭RPS[size=14.6667px]

[size=14.6667px]                                                                                          配置文件
  1. rps:
  2.   update-checker: true #自动更新
  3.   use-particles: true #粒子效果
  4.   maxRange: 20 #最大检测范围
  5.   defaultRange: 5 #默认检测范围
  6.   defaultownerOnlyEdit: true #默认是否只能RPS主人编辑RPS设置
  7.   defaultInverted: false #默认反向???
  8.   defaultOwnerTrigger: true #默认RPS所有者是否能触发RPS
  9.   defaultPlayerEntityTrigger: true #默认玩家是否能触发RPS
  10.   defaultHostileEntityTrigger: false #默认敌对生物是否能触发
  11.   defaultPeacefulEntityTrigger: false #默认和平生物是否能触发
  12.   defaultDroppedItemsTrigger: false #默认掉落的物品是否能触发
  13.   defaultInvisibleEntityTrigger: false #默认非实体能否触发
  14.   defaultVehcileEntityTrigger: false #默认马/驴等能否触发
  15.   defaultProjectileEntityTrigger: false #默认火焰弹/箭等物品是否能触发
  16.   defaultownerOnlyTrigger: false #默认是否只有RPS所有者能触发
