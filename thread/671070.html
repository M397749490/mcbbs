这是一个非常简单并且轻量级的插件

功能:
在玩家首次进入和回到服务器时在游戏中部显示大字消息
效果图:


权限:
tittlemotd.show - 显示消息

配置文件(已汉化):
  1. # 喜欢这个插件?不如试着去看看他的升级版 TitleMotdAdvanced 吧
  2. # 这个插件的Advanced版本拥有 400+ 的 Placholders 和动画!

  4. # 注释:
  5. # True代表是 False代表否 自己更改就好了 相信大家都明白的
  6. # 内容允许使用颜色代码"&"
  7. # Advanced版本是收费的...可以去spigotmc原贴上看有介绍

  9. # 首次加入时的信息
  10. firstjoin:
  11.   # 广播信息给全体玩家
  12.   broadcast: false
  13.   # 广播标题内容(上方大字)
  14.   title: '在这里更改首次进入的标题'
  15.   # 广播信息内容(下方小字)
  16.   subtitle: '在这里更改首次进入的信息'
  17.   # 信息淡入时间 (20 Ticks = 1 秒)
  18.   fadein: 40
  19.   # 信息停留时间(Ticks)
  20.   staytime: 200
  21.   # 信息淡出时间(Ticks)
  22.   fadeout: 40

  24. # 回到服务器时的信息
  25. rejoin:
  26.   # 广播信息给全体玩家
  27.   broadcast: false
  28.   # 广播标题内容
  29.   title: '在这里更改回到服务器时的标题'
  30.   # 广播信息内容
  31.   subtitle: '在这里更改回到服务器时的信息'
  32.   # 信息淡入时间(Ticks)
  33.   fadein: 40
  34.   # 信息停留时间(Ticks)
  35.   staytime: 200
  36.   # 信息淡出时间(Ticks)
  37.   fadeout: 40
