     前言


在国外论坛看到这个插件，发现国内没有人搬运，就搬运过来了并翻译成中文，个人感觉这是一款比较好的GUI商店插件，售价为6EUR。



     插件介绍


这是一款高级GUI商店插件，玩家可以上架自己的物品在GUI里进行交易物品

前置：[必备]Vault |[可选] PlayerPoint | [可选]TokenManager | [可选]MySQLToken


优点：


  • 轻松通过指令创建自己的商店
  • 支持上架附魔的物品，被命名的物品，旗帜等
  • 不需要在配置文件中设置，只需要通过指令来管理商店
  • 高级美化版GUI界面
  • 支持分页
  • 支持NPC插件

     使用方法


一、创建一个GUI商店

二、创建一个商品类别

三、上架手中的物品到指定的商品类别中

四、设置商品价格

五、创建完毕



     指令&权限


/ shop - 打开GUI商店 - zshop.use

/ 配置文件中的指令 - 打开GUI商品 - zshop.use

/ shop <类别名称> - 打开指定类别的GUI商店

/ shop reload - 重载插件 - zshop.reload

/ shop help - 查询帮助 - zshop.help

/ shop hand - 出售手中持有的物品 - zshop.hand

/ shop handall - 出售与手中持有物品相同的所有物品 - zshop.hand.all

/ shop all - 出售背包中的所有物品 - zshop.all

/ shop config - 查询所有配置指令 - zshop.config

/ shop config add <类别> <物品ID> <出售价格> <购买价格> <最大商品购买数量> - 上架指定类型的物品 - zshop.config.add.item

/ shop config remove <类别> <物品ID> - 下架指定类型的商品 - zshop.config.delete.item

/ shop config items <类型> - 显示类别下的商品信息 - zshop.config.items

/ shop config categories - 显示类别信息 - zshop.config.categories

/ shop config gui <类别> - 编辑GUI商店的装饰 - zshop.config.gui

/ shop config edit <购买/出售> <类别> <商品ID> <新价格> - 修改商品信息 - zshop.config.edit.item

/ shop boost <商品ID> <新类型> <介绍> <时间> - 商品添加介绍（zshop.boost）

/ shop boost show - 显示当前的所有上架商品 - zshop.boost.show

/ shop boost stop <商品ID> - 下架指定商品 - zshop.boost.stop
