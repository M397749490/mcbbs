SkyWars是现在2016人气最火排名第一的Minecraft小游戏：Minecraft排名前五的小游戏[油管需要梯子]

空岛战争是在玩家人数由4人或8人展开的一场惊心动魄斗争的一款小游戏！
游戏开始玩家各自出生在一个小空岛上[也可以开启双人模式，
小岛上各自都有宝箱，为了获取胜利概率[风险]，到其他岛屿去寻找资源，战胜其他玩家！
只有活到最后者乃为胜者！

【安装插件】
  • Server must be running at least Java 7.  服务器必须至少运行java 7。
  • Server must be at least Minecraft version 1.7.8. 服务器Minecraft版本必须至少1.7.8。
  • Download SkyWars from the Download link on this page.从本页中的下载链接Download SkyWars
  • Put SkyWars.jar into your plugins directory, and restart the server.把skywars.jar到你的plugins目录，并重新启动服务器。
  • SkyWars is now functional with the two default arenas! SkyWars现在有两个默认的竞技场！

【配置教程】




安装命令
命令权限描述
/swsskywars.setup列出目前所有可用的skywars设置命令

/sws start <Name>skywars.setup开始创建一个新的竞技场，这将放弃所有未保存的竞技场。

/sws setpos1skywars.setup设置第一个位置，从哪里开始复制竞技场。[和下面配合就像圈地]

/sws setpos2skywars.setup设置与第一个位置相反的位置。

/sws addspawnskywars.setup在当前位置添加一个玩家出生点到竞技场上。

/sws saveskywars.setup保存到您插件配置文件下。

/sws createkitskywars.setup从您的当前背包创建一个工具包。

/sws update-arena<Name>skywars.setup更新某个竞技场


1.开始创建一个新的竞技场！/sws start 竞技场名字   [请确保你竞技场里的箱子全部放好配置物品！
2./sws setpos1 设置竞技场第一个点[圈地插件一样，但是不需要任何辅助工具， 方块
3./sws setpos2 设置第二个点
4./sws addspawn ，一般都是4人图或8人图，在每个小岛上添加玩家出生点输入这个指令
5./sws save 保存你设置好的地图。
6.然后在插件的配置文件下main-config.yml里第16行enabled-arenas: 下添加你刚刚创建的竞技场名称
8.重启服务器，载入插件配置文件
