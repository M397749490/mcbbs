-----简介-----

海绵端上的扫地大妈，可以每间隔一段时间自动帮你清扫地上的物品~


-----指令-----

/cleanup - 手动清理地上的物品
/tickstat - 查看当前服务器TPS


-----配置文件-----

  1. autoPurge=true                             #是否开启自动清理
  2. incognito=false                              #是否向玩家发送提示信息（false为发送，true为不发送）
  3. messages {
  4.     "cleanup_done"="&b[&e扫地娘&b] {count}个垃圾被扫走了..."                 #清理时发送的信息
  5.     "cleanup_soon"="&b[&e扫地娘&b] 请注意，地上的物品将在20秒后清除..."               #清理前发送的提示信息
  6. }
  7. purgeInterval=900                   #每次清理的间隔（秒）
  8. purgeWarning=20                   #清理前多少秒发送提示信息
复制代码



-----下载和安装-----
度盘：链接: http://pan.baidu.com/s/1qXABQHI 密码: s4rc
原贴：http://www.mediafire.com/file/93f5ch0cca737m2/twentyticks.jar
