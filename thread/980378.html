Player Information
作者的话：
这个插件从Hypixel的空岛获取灵感，你可以用shift+右击一个玩家，将会向你展示玩家的盔甲、手持物品等。这个插件也是这个插件的改善版。因为没有插件既像这样又能自己配置，所以我决定免费制作这样的插件。








特点：
  • 可配置的GUI（标题）
  • 可配置每个项目的物品
  • 重载配置命令
  • 自定义界面
  • 根据需要用命令创建多个项目
  • shift+右击取得玩家信息
  • 可以禁止获取NPC的信息
  • 支持PlaceholderAPI(站内搬运)
  • 可以禁止让其他玩家获取你的信息（用命令）
  • 使用命令查看其它信息
  • 提示信息可自由修改

命令&权限：
/playerinfo - 获取帮助 - playerinformation.help
/playerinfo reload - 重载配置文件 - playerinformation.reload
/playerinfo view <玩家名> - 查看玩家信息 - playerinformation.view
/playerinfo toggle - 切换启用/禁用玩家信息 - playerinformation.toggle


用法：
1.放入服务端plugins文件夹下，重启服务器，生成配置文件
2.在配置文件中修改声音名（1.8与1.9+的声音名不同，配置文件里有需要的链接），修改物品材质（特别是1.13+）。
3.保存配置文件，重启服务器（或使用/playerinfo reload指令）
如果还是不会，可以询问作者。（spigot或discord）

重要！1.13+必看
如果想要使用彩色玻璃，需要在配置文件中material改为彩色玻璃名，并将data设置为0，例如：
  1. fill-inventory:
  2.   enabled: true
  3.   material: BLACK_STAINED_GLASS_PANE
  4.   name: '&f'
  5.   data: 0
  6.   amount: 1
