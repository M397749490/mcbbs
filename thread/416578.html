这个插件，死亡BAN，
可以允许你设置BAN时间
可以让你给玩家增加命
可以设置玩家例外于BAN（需权限组，但这是废话吧。）

让我们愉快的开极限吧，poi~。。
更新于三月三日
更新日志

3.3：
增加/deathbans查询命令，查询玩家自己剩余命数！(无需权限)


命令列表

- /deathbans      -查询玩家剩余命数(无需权限)
- /deathbans unban - 解除玩家的BAN
- /deathbans addlives - 给玩家加命
- /deathbans takelives - 从某个玩家那里得到命，，这是干啥的。。。应该是删除命吧
- /deathbans perms - 列出这个插件的所有权限

权限列表


  • - deathbans.exempt - 使玩家免除死亡BAN
  • - deathbans.admin - 允许使用管理员命令 (unban解ban, addlives加命, takelives删除命, perms权限列表)
  • - deathbans.* - 给予全部权限

config详解
  1. # Default Deathbans Config
  2. # Ban Time in seconds.
  3. bantime: 5400    #BAN的时间
  4. startinglives: 1    #起始命的条数（本人建议作者添加233）
