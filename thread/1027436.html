给距玩家半径5个方块以内的盔甲戴上玻璃头
  1. execute as @e[type=armor_stand,distance=..5] at @s run data modify entity @s ArmorItems[3].id set value "minecraft:glass"
复制代码

minecraft:glass可以换成其他方块ID，如换成minecraft:redstone_block就能给盔甲架头部戴上红石块
