玩家命令
命令所需权限说明
/vd join [arena]villagedefense.join.%arena%
villagedefense.join.* (所有竞技场)		加入指定竞技场
/vd randomjoin需要villagedefense.join.* 权限加入所有竞技场随机加入一个未开始竞技场
/vd stats (在线玩家)无查看你(或他人)的游戏信息
/vd leave无退出当前游戏. 你可以在config.yml文件中关闭它
/vd top [statistic]无查看Top10榜
/vd selectkitvillagedefense.command.selectkit在游戏中更换套装

管理命令

你可以使用 villagedefense.admin.* 权限给予玩家所有管理权限


命令所需权限说明有效执行者
无villagedefense.updatenotify插件更新通知权限无
无villagedefense.command.override在游戏中不限制使用任何命令无
无villagedefense.admin.sign.create (创建游戏木牌) villagedefense.admin.sign.break (破坏游戏木牌)你可以创建或破坏木牌无
/vd create [arena]villagedefense.admin.create创建竞技场玩家
/vd [arena] editvillagedefense.admin.create编辑竞技场玩家
/vda listvillagedefense.admin.list列出可用竞技场玩家/后台
/vda stopvillagedefense.admin.stopgame停止你正在游戏的竞技场玩家
/vda forcestartvillagedefense.admin.forcestart强制启动你所在的竞技场玩家
/vda respawn (player)villagedefense.admin.respawn villagedefense.admin.respawn.others在你所在竞技场指定一个玩家重生玩家

/vda delete [arena]villagedefense.admin.delete删除竞技场玩家

位置类型:START(开始), END(结束), LOBBY(大厅)		玩家

/vda addorbs [amount] (player)villagedefense.admin.addorbs villagedefense.admin.addorbs.others向你或你指定的玩家增加硬币玩家/后台(指定其他玩家时)

4.0.0 - New era is here

It's a big one! 这是一个大更新！
4.0.0 pre-release users must reset language.yml!

[Added]Limited rotten flesh hearts level that users can get to 30 (prevents tons of hearts that will break game fun) 限制腐肉升级血量等级到30 (防止玩家拥有大量的血量破坏游戏乐趣)
[Added]Zombie idle processor to save server load and prevent lag! Game will halt spawning zombies for x seconds (wave / 15 rounded down) in wave to save performance a bit without spawning tons of hordes at once.  僵尸闲置处理器可以节省服务器负载并防止滞后！游戏将暂停生成僵尸 X（波数/15  向下取舍）秒，以节省一点性能而不会一次产生大量的僵尸
[Added]Zombie spawn limiter, maximum of 750 zombies can be spawned in wave now, any amount higher will be set to 750 and zombies will receive extra hearts as waves increments. Health is based on (zombies this wave - 750 / 15 rounded up)   僵尸生成限制，每一波最多能生成750个僵尸，任何超过750的数量都将被设置成750并且随着波数的增加僵尸的血量也会增加。血量是基于(波数 - 750/15 ?四舍五入)
[Added]Game will now clean rotten fleshes from ground spawned after game ends in arena world in radius of 150 blocks near arena start location     游戏将在结束时把游戏世界中以游戏开始位置为中心半径150格的方块范围内的地面上的腐肉清理掉
[Added]Tab completer for some command arguments 某些命令的参数补全
[Added]Legacy data converter for YAML files, data saved in YAML was broken since ~3.11.x, user data will migrate safely and player stats will be updated   YAML的旧数据转换器，YAML在 ~3.11.x版本被破坏，使用它用户数据将会安全的迁移并更新玩家统计信息
