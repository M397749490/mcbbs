标题: ItemLoreStats
ItemLoreStats插件玩家自己合成的装备，工具都带有属性
如何才能关闭掉这些属性或者 设置低一些

作者: lichi2050    时间: 2016-3-6 02:38
打开config

defaultCraftedDurability:
  enableDurabilityOnCrafted: true ←合成装备时是否带有耐久属性（想关闭设置为false）
  enableDurabilityOnDrops: true ←掉落后是否还有耐久属性
  tools:
    bow: '&7150-250'
    shears: '&770-130'
    stick: '&7190-270'
    string: '&7160-290'
    blazeRod: '&7210-340'
    flintAndSteel: '&730-60'
    fishingRod: '&730-80'
    carrotStick: '&725-50'
    wood: '&7150-300'
    stone: '&7250-350'
    iron: '&7300-600'
    gold: '&7550-750'
    diamond: '&7700-1100'
  armour:
    leather: '&71300-1450'
    iron: '&71700-2300'
    chainmail: '&71550-2050'
    gold: '&72200-2500'
    diamond: '&72400-3200'
    mobHead: '&71600-2550'
如果想设置低一点调整下材料数据即可，然后到
defaultCraftedArmour:
  enableArmourOnCrafted: true ←合成护具时是否带有属性（想关闭设置为false）
  enableArmourOnDrops: true ←掉落后是否还有属性
  armourStatFormat: '&3[statName]: &b[statValue]&3%'
  armour:
    leather: '&b3.6-7.3'
    iron: '&b7.8-15.6'
    chainmail: '&b6.2-12.5'
    gold: '&b5.7-11.4'
    diamond: '&b10.4-20.8'
    mobHead: '&b4.0-15.0'
如果想设置低一点调整下材料数据即可，然后到
defaultCraftedDamage:
  enableDamageOnCrafted: true ←合成武器时是否带有属性（想关闭设置为false）
  enableDamageOnDrops: true ←掉落后是否还有属性
  damageStatFormat: '&3[statName]: +&b[statValue]-[statValue2]'
  tool:
    bow: '&b3.6-7.3'
    wood: '&b7.8-15.6'
    stone: '&b6.2-12.5'
    iron: '&b5.7-11.4'
    gold: '&b10.4-20.8'
    diamond: '&b4.1-15.5'
