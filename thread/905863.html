DeluxeTags
一款简洁的称号插件



玩家可以根据他们的权限选择他们的称号
玩家可以从/tags中选择他们的称号
也可以由管理员强制给予玩家一个称号
也可以给予玩家某个称号的权限,由玩家自行去/tags佩戴

支持EssentialsChat和其他支持使用PAPI变量的聊天插件
支持PAPI变量 (可以在任何能显示PAPI变量的地方显示)
原帖内容
[size=14.6667px]Allow players the ability to select an active "chat tag" based on the tags they have permission for!

Players can select a tag from the /tags GUI or you can optionally use the "force_tag" option and apply tags to players via permission nodes.

If you choose to use this plugin without DeluxeChat, you must set deluxe_chat: false in the config for DeluxeTags to register the vanilla chat listener!

If you use DeluxeChat, you must set that option to true!

This plugin is very easy to use and simply adds a few placeholders to display the tag/tag information anywhere in your DeluxeChat formats!

Now supporting EssentialsChat and other chat formatting plugins!

[size=14.6667px]This can be used as an "extra prefix" as it does not require a player to have a specific group. To allow a player access to a tag, they simply need the permission node for it - deluxetags.tag.<identifier>




如果您使用的是 DeluxeChat 作为聊天插件
请将plugins/DeluxeTags中的 Deluxe_Chat: false 改为 true
如果您使用的是LiteChat,MiaoChat,EssentialsChat等插件请保持 false

/tags
打开称号选择GUI
deluxetags.gui
(注意,此权限玩家默认不拥有,请您手动给予玩家)

/tags select <称号别名>
使用指令手动选择一个称号
deluxetags.select
(注意,称号别名≠称号)

/tags list
查看自己有什么称号(以信息的方式发送给玩家)
deluxetags.list
/tags list all
查看管理员一共设置了多少称号(以信息的方式发送给玩家)
deluxetags.list.all

/tags list <某个人>
查看某个人一共拥有什么称号
deluxetags.list.player
/tags set <某个人> <称号别名>
给某个玩家强制设置某个称号
deluxetags.set

/tags create <称号别名> <称号>
创建一个称号
deluxetags.create

/tags delete <称号别名>
删除某个称号
deluxetags.create

/tags setdesc <称号别名> <称号描述>
给某个称号设置一个描述词
deluxetags.setdescription

/tags reload
重载插件的所有配置

deluxetags.reload
/tags version
查看插件版本(默认拥有)

deluxetags.forcetag.<称号别名>
如果玩家有这个称号,则强制给其佩戴上此称号

deluxetags.tag.<称号别名>
给予玩家更换此称号的权限(或:让玩家拥有此称号)






PlaceholderAPI变量
%deluxetags_tag% —— 玩家的称号 (这才是真正的称号)
%deluxetags_identifier% —— 玩家所佩戴称号的简(别)称 (不是称号)
%deluxetags_description% —— 玩家所配戴的称号的描述
%deluxetags_amount% —— 玩家有多少个称号(返回值是数字)

MVdWPlaceholderAPI变量
{deluxetags_tag} —— 玩家的称号 (这才是真正的称号)
{deluxetags_identifier} —— 玩家所佩戴称号的简(别)称 (不是称号)
{deluxetags_description} —— 玩家所配戴的称号的描述
{deluxetags_amount} —— 玩家有多少个称号(返回值是数字)
(如果您使用EssChat请使用这些变量,并安装MVdWPlaceholderAPI)

Q:我使用的是EssenitalsChat,道理我都懂,你能帮帮我吗
A:(首先确保您的EssenitalsX和EssenitalsXChat都是最新版本)
在/plugins/Essenitals/config.yml中 找到format:
往你喜欢的地方(必须在两个'中)插入{deluxetags_tag}


Q:我使用的是其他支持PAPI变量的聊天插件,咋办
A:插♂入变量即可
在这里插入一条你们可能会遇到的问题


Q:插件GUI界面所有变量加载不出来?
A:我在测试中关闭Deluxe_Chat后使用汉化文件没问题
你们不妨试试

具体使用步骤
1.把插件丢入/plugins中

2.下载PlaceholderAPI插件以及
任意一个支持PAPI变量的聊天插件(推荐LiteChat)
还有一款权限插件(推荐LuckPerms)

3.重启服务器(不推荐使用Yum或/reload命令)

4.在/plugins/DeluxeTags中找到config.yml
并使用Notepad++或VS CODE等编辑工具打开

5.找到位于最下方的 deluxetags:
按照我举的例子添加一个你想要的称号
(例如我想要一个 &7[&bVIP&7] 称号)

  2. deluxetags:
  3. #称号别称,记住了哈 (deluxetags.tag.别称)
  4.   vip:
  5. #显示顺序,数字越小越靠前
  6.     order: 1
  7. #两个引号内填写称号 少了一个引号或者一个"一个'都会导致报错
  8.     tag: '&7[&bVIP&7]'
  9. #称号的描述
  10.     description: '&c这系你独享的称号!'
复制代码
然后输入/tags reload


6.给予玩家称号的权限
GroupManager(Plus): /manuaddp 你或玩家的ID deluxetags.tag.vip
PermissionEX: /pex user 你或玩家的ID add deluxetags.tag.vip
LuckPerms: /lp user 你或玩家的ID permission set deluxetags.tag.vip true
(如果是给予某个权限组称号的权限请结合下面的第七步)

7.给予默认权限组打开称号选择GUI的权限
GroupManager(Plus): /mangaddp default deluxetags.gui
PermissionEX: /pex group default add deluxetags.gui
LuckPerms: /lp group default permission set deluxetags.gui true
(如果是给予某个玩家打开GUI的权限请参考第六步)

8.让玩家输入/tags 点击佩戴称号~

9.在你的计分板/聊天插件等能显示内容或支持PAPI变量的地方添加
%deluxetags_tag%变量,就能让玩家看到了~
