AAC的配置文件并没有统一的kick（踢人设置）
而是根据各种作弊（飞行，速攻，透视，爬墙之类的）每项都有它自己的设置，并且默认每项都有踢人这个功能，我就拿配置文件第一个和你说
# Angle 这个作弊会强行将玩家角度调整到正面面对攻击对象
angle:
   # 是否启动该检测
   enabled: true
   
   # 这些就是限制了
   max_diff: 0.30

   # 同上
   max_player_diff: 0.15
   
   # 同上（具体介绍看你自己的配置文件）
   min_dist: 2.0
   
   # AAC是否取消这个攻击
   cancel_false_hits: true
   
   # 如果检测到作弊，执行
   thresholds:
      6: "aacstaffnotify {player} is suspected for Killaura (Angle) (ping = {ping}, tps = {tps})" ← 就是游戏内的提示
      12: "aackick {player} Impossible angles in attacks" ← 这是即将执行的指令
