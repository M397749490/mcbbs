二.这里面有什么？
你下载下来之后，里面会有两个jar文件，不要直接把zip文件放进plugins目录下。
一个jar名字里有Bukkit，那个就放进Bukkit或Spiogot服务器。
另外一个名字有Bungee，在你希望有多服务器支持你才需要这个jar，并且不要计划使用RabbitMQ。
如果你打算使用Bungee，把jar放在BungeeCord的Plugins目录底下并重启服务器。
原文:
There are two jar files inside the zip. One is labeled "Bukkit" and goes on your Bukkit/Spigot servers. The other is labeled "Bungee". You only need the "Bungee" jar if you want multi-server support and DO NOT plan on using RabbitMQ. (config below)
If you plan on using Bungee then place the jar labeled "Bungee" in your BungeeCord's "plugins" folder and restart your servers.

三.前置
  • Java8（必须）
  • LibsDisguises or iDisguise （可选）（指令/troll control 和 /troll duck）
  • ProtocolLib （可选）（指令/troll foolsgold）
  • PowerNBT（可选）（指令/troll attachcommand）
  • RabbitMQ 提供多服务器支持
原文：
Requairement
Java 8+
Optional?
LibsDisguises or iDisguise are required for /troll control and /troll duck. Those commands will simply be disabled if the libraries aren't provided.
ProtocolLib is required for /troll foolsgold and /troll nightmare. Those commands will simply be disabled if the library isn't provided.
PowerNBT is required for /troll attachcommand. That command will simply be disabled if the library isn't provided.
RabbitMQ (or BungeeCord with the included plugin) for cross-server support. If neither is provided, /gtroll will simply act as an alias of /troll.
