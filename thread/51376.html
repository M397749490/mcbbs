答疑区（不断更新）
Q1 MOD安装器能够自动安装任何MOD吗？
A1 不一定。只能够安装带有脚本的ZIP格式的MOD压缩包，但是对于直接把所有文件拖入minecraft.jar的这类MOD，您可以把MOD压缩包存为ZIP格式，并在注释中加入如下代码：
  1. !VERSION 1
  2. CD ".minecraft"
  3. CD "bin"
  4. ZIPDELETE "minecraft.jar" "META-INF"
  5. ZIPPUT "minecraft.jar" "$TEMP\jar\*"
  6. RETURN 0
复制代码
Q2 我是懒人包作者，我希望使用公共源发布自己的懒人包。
A2 请通过站内信或是邮件的方式联系作者。

Q3 为什么没有设置JAVA的32位或是64位的选项？
A3 设置JAVA的目标CPU是一件很不妥的事情，您应该在设置JRE位置时选择合适的路径（例如64位的C:\Program Files\Java\jre7\bin，32位的C:\Program Files (x86)\Java\jre7\bin），而不是使用64位的JRE却加入-d64参数来启动。

Q4 启动时出现Could not create Java virtual machine.
A4 请在设置中降低内存的最大值和最小值。

Q5 你无视了Linux用户
A5 有能力玩转Linux的用户应该会采用写bash脚本之类的方式来启动游戏而不是使用启动器。

Q6 杀毒软件报毒了
A6 啊咧，被误杀了？请联系作者并告知您的杀毒软件名称与版本，感谢您的支持。

Q7 主界面没有“安装MOD”按钮？
A7 请删除旧版本的MCLauncherCustom.dll再试一次。

Q8 主界面这么难看？
A8 本人美工水平有限，但是好在每个人都可以设计界面，以后会有更好看的设计出现。

可以参考一下材质包的安装方法（见1L“截图中出现的MOD以及列表文件”部分）
假如压缩包里有如下两个文件夹
into jar
into mods
我现在要把into jar下面的东西丢入minecraft.jar
而把into mods下面的东西丢入mods文件夹
脚本应该这么写
  1. !VERSION 1
  2. CD ".minecraft"
  3. ;先解决jar的问题(这一行是注释)
  4. CD "bin"
  5. ZIPDELETE "minecraft.jar" "META-INF\*"
  6. ZIPPUT "minecraft.jar" "{$TEMP}\into jar"
  7. ;再解决mods的问题(这一行也是注释)
  8. CD ".."
  9. ;上一行是返回上级目录(这一行还是注释)
  10. COPYDIR "{$TEMP}\into mods" "mods"
  11. ;上一行是把into mods目录复制成mods目录(这一行仍然是注释)
  12. RETURN 0
