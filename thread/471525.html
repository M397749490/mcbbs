xKit
更好的管理玩家礼包发放的插件. 可以通过GUI来创建新的礼包.


特色
  • 通过GUI来自定义礼包内容。
  • 2种计时器模式 - 周期礼包和每日礼包。
  • 基于MySQL，可以多个服务器同步使用。
  • 领取礼包时可执行多条指令。
  • 可通过控制台发放礼包。
  • 支持设定领取权限！
  • PlaceholderAPI变量支持！


依赖前置
  • MySQL
  • SimpleORM
  • ProtocolLib
  • PlaceholderAPI (可选) - 如果你需要变量。


截图




PlaceholderAPI 变量
  • xkit_<kit_name>_okay
    • 能领取 <kit_name> 时 返回 true.
    • 否则返回 false.
  • xkit_<kit_name>_next
    • 返回下一次可领取的时间（秒）.
    • 否则返回 -1.
  • xkit_<kit_name>_nextdate
    • 返回下一次可领取的日期.
    • 否则返回 null.


指令和权限

xkit.admin - op
  • /xkit all
    • 检视所有已定义的礼包
  • /xkit add <kit_name>
    • 定义新礼包
  • /xkit add-token <player> <token> [amount]
    • Add specific token for player.
  • /xkit del <kit_name>
    • 删除已定义的礼包
  • /xkit set <kit_name>
    • 设置礼包内含物品
  • /xkit set <kit_name> permission [permission]
    • 设置领取所需权限
  • /xkit set <kit_name> period [period_second]
    • 设置礼包领取间隔（秒）
  • /xkit set <kit_name> day [period_day]
    • 设置礼包领取间隔（天）
  • /xkit set <kit_name> token [token_name]
    • Add token for specific kit.
  • /xkit set <kit_name> command [command]
    • 设置领取同时后台执行命令
    • 格式为JSON数组
    • 示例"/xkit set kit1 command ["kill %player%", "kick %player%"]
    • %player%被替换成玩家名
  • /xkit kit <kit_name> [player_name]
    • 领取指定礼包。当后接玩家名时，可以使特定玩家强制领取而无视间隔和权限

xkit.use - 默认
  • /xkit kit <kit_name>
    • 领取指定礼包。

  5.       permission: '&cYou don''t have permission!'
  6.       cooling: '&cCooldown left %time% sec(s).'
  7. dataSource:
  8.   url: jdbc:mysql://localhost/test
  9.   user: root
  10.   password: root

使用指南
  • 将本插件与依赖插件放入服务端plugins文件夹
  • 运行之后会在plugins/xkit生成config.yml
  • 修改对应数据库的信息并重启服务端
  • Enjoy it!
