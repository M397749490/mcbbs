设置开发环境

1安装JDK是你要做的第一件事。如何安装？http://zhidao.baidu.com/question/351018707.html JDK预装在MacOSX系统中，所以mac用户可以跳过这一步。 2接下来你要下载Minecraft Coder Pack（MCP）下载地址XXX 解压到任意文件夹，以下为配置方法，配置好的MCP115提取码an74gf1t
(1)从官网下载一个对应版本的Minecraft_Server.jar拷贝到Jars目录下
(2)将MC目录下的bin文件夹全部拷进MCP下的Jars内.
(3)复制资源文件,将MC目录下的resources文件夹拷入MCP的Jars内
(4)安装ModLoader(并打上反编译修正补丁),有条件还要安一个AudioMod,别忘记删掉验证文件.
(5)安装ModLoaderMP.
      之后运行MCP下的decompile.bat开始反编译 然而反编译完毕后MCP会对源代码进行一次正编译来验证源代码是否可用,Server在正编译阶段会报大量错误,这是ModLoaderMP导致的,我们需要修正这个错误并重新完成正编译的最后阶段.修正的方法是将MCP目录下的src\minecraft_server\net\minecraft\server内的MinecraftServer.java的第519至第555行全部替换为一个} 之后你需要运行MCP目录下的updatemd5.bat重新进行用于验证的正编译.打开bat后输入Yes,回车. 如果一切顺利,大约几十秒后你就能完成全部正编译工作了(如果遇到错误可能是因为你的MinecraftServer.java没有修复正确).
3在http://www.eclipse.org/下载Eclipse
配置Eclipse可以参见http://www.mcbbs.net/thread-18938-1-1.html
这里就不再发一次了

这是Modloader的”模版“，我会解释一下它的构成。
  1. package net.minecraft.src;
复制代码
这行是打包，你可以在mcp目录下的src\net\minecraft\src下找到这个文件

  1. public class mod_*** extends BaseMod
复制代码

这行的意思是定义了一个类，类名要与文件名相同，可以用26个字母，下划线_，数字和美金符号$来起名字，但是数字不能开头，比如123abc这个类名就是非法的。”extends“是继承的意思，相当于mod_***是BaseMod的儿子，它可以使用BaseMod里的方法。
  1. public void load()
复制代码


这个是Modloader的构造函数。

  3.         return "1.2.5";
  4. }
复制代码


这个是获得版本号，永远都不要return null。

新方块(Block)


1.首先新建一个叫mod_Block的类，代码如下
  1. package net.minecraft.src;

  3. public class mod_Block extends BaseMod
  4. {
  5. public static final Block Namehere = new BlockNamehere(160, 0).setBlockName("anynamehere").setHardness(3F).setResistance(4F).setLightValue(1F);

  7.         public void load()
  8.         {
  9.                 Namehere.blockIndexInTexture = ModLoader.addOverride("/terrain.png", "/image.png");
  10.                 ModLoader.registerBlock(Namehere);
  11.                 ModLoader.addName(Namehere, "In-Game Name Here");
  12.                 ModLoader.addRecipe(new ItemStack(Namehere, 1), new Object [] {"#", Character.valueOf('#'), Block.dirt});
  13.         }

  15.         public String getVersion()
  16.          {
  17.                          return "1.2.5";
  18.         }
  19. }
复制代码
  • （160,0）是在terrain.png里的位置
  • 方块ID不可以高于255,125-255可以用
    1. Namehere.blockIndexInTexture = ModLoader.addOverride("/terrain.png", "/image.png");
    复制代码
    上面代码里的images.png放在mcp/lib目录下,这是这个方块的贴图,16像素x16像素大,至于images.png在哪里请自行脑补
    1. setBlockName("anynamehere").setHardness(3F).setResistance(4F).setLightValue(1F);
    复制代码
    setBlockName后的括号填这个方块在游戏里显示的名字,setHardness是硬度(1-10以内,地基是-1,刷怪笼是11),setResistance是抗炸度，setLightValue是亮度（注意：亮度设置得太高MC会崩溃）每个数字后面都记得要加F哟
    1. ModLoader.registerBlock(Namehere);
    2. ModLoader.addName(Namehere, "In-Game Name Here");
    3. ModLoader.addRecipe(new ItemStack(Namehere, 1), new Object [] {"#", Character.valueOf('#'), Block.dirt});
    复制代码
    registerBlock是在游戏里注册这个方块，addName后的括号内的In-Game Name Here是方块的里名字，就是你在箱子，合成台等里看见的名字，new Object后面的代码的意思是用一个泥土合成一个方块，你可以在后面的章节获得更多信息。

复制代码
  • Material这个不用多说，你可以在Material.java看到所有的材料
  • 你可以在idDroopped里修改破坏后掉落的物品,如果你想掉落多种物品,if可以帮到你
  • quantityDropped设置掉落数量,修改return后的数字就行了

新食物


新建一个新类mod_Food


  1. package net.minecraft.src;

  3. public class mod_Food extends BaseMod
  4. {
  5.         public static final Item Namehere = new ItemFood(5001, 4, 1F, false).setItemName("anynamehere");
  6.         
  7.         public void load()
  8.         {
  9.                 Namehere.iconIndex = ModLoader.addOverride("/gui/items.png", "/image.png");
  10.                 ModLoader.addName(Namehere, "In-Game Name Here");
  11.                 ModLoader.addRecipe(new ItemStack(Namehere, 1), new Object [] {"#", "#", Character.valueOf('#'), Block.dirt});
  12.         }
  13.         
  14.         public String getVersion()
  15.         {
  16.                 return "1.2.5";
  17.         }
  18. }
复制代码
  • newItemFood后面数字的意思：第一个是id，第二个是填满多少个半个鸡腿（现在这里是4，就是填满了两个鸡腿），第三个数字是饱和程度，当饱和度没有了食品栏就会抖动。
  • 后面的那个“false”说明狼不可以吃这个食物，当你设为true的时候就可以把这个食物给狼吃
