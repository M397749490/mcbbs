帮助
CommandShop可以让你做一个商店，玩家可以购买的命令！
这个插件可以设定价格购买指令权限，所以玩家只有一次的
购买权限，他还需要Vault经济插件作为前置插件

特征
  • 自定义GUI - 拥有所有命令的一个不错的库存GUI！
  • 自定义的邮件 - 格式，并在打开的消息的颜色！
  • 使用方便 -在漂亮的GUI界面将让玩家可以查看哪些插件，他们买什么他们还没有购买。 CommandShops还允许你使用任何插件的经济你要Vault
  • 用户化 - 该配置将允许您设置默认价格和多个命令放心！它可以作为输入一个命令，和你做一样容易！该配置还可以让你改变的东西，如出现在聊天文本。你可以改变许多东西，可以在配置中可以看见：<PUT LINK HERE!!!>

命令
  • /commands - 打开GUI界面
  • /commands help - 打开插件帮助菜单
  • /commands list - 列出所有可购买指令
  • /commands reload - 重新加载插件
  • /commands add - 你无需打开文本即可配置！用法：/commands add 命令 费用 标题
  • Command可以缩写成CMD

权限
  • commands.use - 可以使用 /commands command. 玩家权限
  • commands.help - 可以使用  /commands help command. 玩家权限
  • commands.list - 可以使用  /commands list command. 玩家权限
  • commands.reload - 可以使用  /commands reload command. OP权限
  • commands.add - 可以使用  /commands add command. OP权限

原理
这个插件的原理是锁定用户访问做的命令。一旦他们买了命令就能解锁使用，使他们可以使用命令时。这没有什么关系添加和删除权限。所以一定要确保玩家还有权他们所购买，否则他们将购买它，就无法使用它的命令。

Vault?
本插件主要依赖Vault插件，如果没装，这个插件将无法正常使用
插件下载网址http://dev.bukkit.org/bukkit-plugins/vault/
