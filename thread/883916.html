此贴源起http://www.mcbbs.net/forum.php?mod=viewthread&tid=883544
以前从来没有注意到mod的依赖问题，直到这个问题我才吓一跳，那么多mod为了避免依赖问题内置了前置
你可能会说这很方便，但当出现java.lang.IllegalAccessError崩溃的时候你就不会这么觉得了
就拿上面链接里的问题来说，当同时拥有了多个内置了不同版本的cofhcore前置模组的类的时候，就会有可能出现：
  1. java.lang.IllegalAccessError: tried to access class cofh.api.transport.IEnderAttuned from class cofh.lib.transport.EnderRegistry
复制代码
（这个情况是旧版本的类的访问级别在新版本改变了，感谢3TUSK的解疑XD）

于是你需要去一个一个模组找，一个一个删除，这何尝不是痛苦的过程呢TAT
况且版本不同会带来一些很奇怪的bug，以后估计组整合包都得注意一下了XD

此贴写给那些被这个崩溃折磨的人，其他mod类似的错误（tried to access class xxxx form...）都只需要找出内置这些类的模组并删除对应类就行了
这里的错误是删除内置cofhcore前置模组的类的文件夹cofh（注意不要误伤cofhteam自家的mod！！！）
