我是在写每个人不同的出生点，我想的原理是把每个人要出生的地方信息（世界、X、Y、Z、角度）储存在配置文件，然后用重生事件，触发重生事件时就读取配置文件里面的地方信息，然后用teleport传过去，但老是有一点偏差，就是偏了一些坐标，很迷，求解答
保存出生点信息代码如下：
  1. getConfig().set(player0+".World", player.getWorld().getName());
  2.                         getConfig().set(player0+".X", Double.valueOf(player.getLocation().getX()));
  3.                         getConfig().set(player0+".Y", Double.valueOf(player.getLocation().getY()));
  4.                         getConfig().set(player0+".Z", Double.valueOf(player.getLocation().getZ()));
  5.                         getConfig().set(player0+".Yaw", Float.valueOf(player.getLocation().getYaw()));
  6.                         getConfig().set(player0+".Pitch", Float.valueOf(player.getLocation().getPitch()));
  7.                         saveConfig();
复制代码

（player0是player.getPlayerListName()得到的玩家名称）
重生事件的代码：
  1.         @EventHandler
  2.         public void PlayerResawnEvent(PlayerRespawnEvent PlayerRespawnEvent) {
  3.                 Player player = PlayerRespawnEvent.getPlayer();
  4.                 String player0 = player.getPlayerListName();
  5.                 player.teleport( new Location(Bukkit.getWorld(getConfig().getString(player0+".World")), getConfig().getDouble(player0+".X"), getConfig().getDouble(player0+".Y"), getConfig().getDouble(player0+".Z"), (Float)getConfig().get(player0+".Yaw"), (Float)getConfig().get(player0+".Pitch") ) );
  6.                 }
