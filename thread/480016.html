怎么开启领地水流动

作者: 迷途的村庄    时间: 2015-8-3 10:07
  1. flow：液体流动，包括waterflow和lavaflow
  2. waterflow：水的流动
  3. lavaflow：岩浆流动
复制代码


/res set <领地名> [权限] [true/false/remove] - 设置某领地的权限
开启领地水流动:/res set <领地名> flow true
