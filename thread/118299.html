原理是,按下按钮后激活一排活塞,活塞压在红石线上使7条红石线各自带上1或0,
7跳线分别对应显示屏上的3个红石灯
举个栗子:输入8就是1 1 1 1 1 1 1
在举个饭粒:输入1就是0 1 0 0 1 0 0
输出同过天上的线飞上显示屏

按钮激活红色部分的红石线后通过绿色部分
:b
之后给黄色部分最下面的羊毛充能,让最下面的火把熄灭
之后火把依次向上改变使最上面的火把亮起
红石信号通过蓝色部分,使紫色部分的活塞激活
黑色部分红石块救活下面的红石线
goto b
由此让红色线一直激活


之后是复位
