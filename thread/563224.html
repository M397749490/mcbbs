一个为游戏所制作的组队向插件?
该插件允许玩家在你的服务器内组建属于他们自己的队伍！?

插件特性：
队伍系统
  • 队员与队长
  • 队内聊天
  • 关闭队友伤害
  • 队伍邀请以及邀请冷却时间
  • 队伍玩家描述设置
  • 队伍信息设置{?}
  • 可用管理员命令进行队伍删除与更名
  • 为队伍设置基地/家
  • 限制队伍成员数量
  • 限制队伍名为队伍
  • 设置玩家黑名单
附加功能
  • 玩家标签系统
  • 队伍总杀敌数系统
  • 经验分配系统
  • 为无权限玩家隐藏命令{?}
  • 所有游戏命令都可以自定义配置
  • 所有聊天信息都可以限制显示
  • 基本语言信息(英语与德语){本地址包括中文汉化}
  • 系统日志保留
外部功能
  • 支持UUID
  • API系统
  • 支持JSON
  • 指标系统
  • 支持GriefPrevention插件
    [本站地址：http://www.mcbbs.net/thread-546955-1-1.html，外链地址：http://dev.bukkit.org/bukkit-plugins/grief-prevention/]
  • 支持DeluxeChat插件
    [本站无下载地址，外链地址：https://www.spigotmc.org/resources/deluxechat.1277/(此插件需使用7.50美元/约50人民币购买)]
  • 支持EssentialsChat插件
    [本站地址(总插件)：http://www.mcbbs.net/thread-464701-1-1.html]
  • 支持PermissionEX插件
    [本站地址：http://www.mcbbs.net/thread-377414-1-1.html，外链地址：http://dev.bukkit.org/bukkit-plugins/permissionsex/]
  • 支持GroupManager插件
    [无本站与外链地址]
  • 支持SQL(网络)与YAML(本地)数据库
  • 支持Vault
    [本站地址：http://www.mcbbs.net/thread-78310-1-1.html，外链地址：http://dev.bukkit.org/bukkit-plugins/vault/]
  • 更新检查系统

你也可以禁用某些功能，你也可以
删除/取消对应功能的权限
或
在配置文件内直接禁用功能。

A groups plugin for your server bukkit or spigot.?

This plugin allows the creations of parties, or groups, in your server. Parties can be configured in every aspect, from commands to messages.?

Features
  • Party system
    • Members and leaders
    • Private chat for the party
    • Prevent friendly-fire
    • Invites with cooldown
    • Description for the party
    • MOTD for the party
    • Delete/Rename parties with admin commands
    • Set the home of your party
    • Limits members of the party
    • Limits name of the party
    • Blacklist names party
  • Additional Features
    • Tag system
    • Total Kills system
    • Divide EXP system
    • Hide commands without permission
    • Every command is configurable
    • Every message is configurable
    • Basic resource messages (en & it)
    • Log system
  • External Features
    • UUID support
    • API system
    • JSON support
    • Metrics system
    • Support GriefPrevention
    • Support DeluxeChat
    • Support EssentialsChat
    • Support PEX and GroupManager
    • Support SQL and YAML database
    • Support Vault
    • Check-for-updates system

You can also disable some functions, just remove/negate the permission of the function or disable it from config.





Permissions
[size=14.6667px]You can use the basic permission for users:
parties.user.*
[size=14.6667px]For admins you can give all permissions of the plugin with:
parties.admin.*
[size=14.6667px]If you want the full list visit here.

Configuration
The config.yml is provided with comments to help the user to create the better configuration, a list of available tags or anexplanation about the option.
The entire configuration is divided into 3 files:
- config.yml (Default configuration here)
- data.yml
- messages_xx.yml
You can change xx for change language (Supported en and it), remember to create the file with your translated messages!

How works Parties API?
[size=14.6667px]You can implements Parties in your plugin for get information about the party of a player.
I have created for developers a lot of methods for hook into the parties, for example add/remove players, get all players, etc..
Visit this wiki for see how works my api.

[size=14.6667px]Plugins Supported
GriefPrevention:
You can grant permission on all your partymates with the command /party claim, choose 3 different permissions: build/container/access. You can remove permission with /party claim remove.

DeluxeChat:
Parties have 7 tags for DeluxeChat: party, desc, motd, prefix, suffix, kills, rank. "%parties_TAG%"

EssentialsChat:
Parties have 7 tags: party, desc, motd, prefix, suffix, kills, rank (All in maiusc). "{PARTIES_TAG}"

[size=14.6667px]How install Parties?
1. Download from this page
2. Put the downloaded file in the folder plugins (Of your server directory)
3. Reload server
