插件描述

  • 简单方便的创建方法
  • 支持单端多竞技场
  • 快捷，无延迟
  • 基于最新 PocketMine API
  • 支持自动重置竞技场
  • 支持自动填充物品箱



插件安装

> 安装插件：
  • 下载最新发布版或测试版
  • 导入插件文件夹 /plugins/
  • 重启服务器

> 创建竞技场：
  • 创建竞技场使用 /sw create <竞技场名称>
  • 进入设置模式 (命令 /sw set <竞技场名称>)
  • 使用设置命令 (不用添加 /), 你可以通过命令来设置竞技场

> 设置命令：

命令描述
help列出所有设置命令
done退出设置模式
slots <槽位>设置竞技场物品槽位
level <世界名>设置竞技场世界
spawn <玩家数>设置竞技场出生点
joinsign更新加入游戏木牌
enable启用竞技场
savelevel保存世界为 '世界名.zip'


命令/权限

> 命令/权限：
  1.     /sw help:
  2.         Description: 列出 SkyWars 所有命令
  3.         Permission: sw.cmd.help (OP)
  4.     /sw create:
  5.         Description: 创建竞技场
  6.         Permission: sw.cmd.create (OP)
  7.         Usage: /sw set <竞技场>
  8.     /sw remove:
  9.         Description: 删除竞技场
  10.         Permission: sw.cmd.remove (OP)
  11.         Usage: /sw remove <竞技场>
  12.         Note: 此改动将在重启后生效
  13.     /sw set:
  14.         Description: 进入设置模式
  15.         Permission: sw.cmd.set (OP)
  16.         Usage: /sw set <竞技场>
  17.         Note: 仅用于游戏内玩家使用(控制台无法使用)
  18.     /sw arenas:
  19.         Description: 列出所有竞技场
  20.         Permission: sw.cmd.arenas (OP)
