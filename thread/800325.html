针对楼主和2L我补充一下：、

如何看自己在哪个权限组：一般插件初始化之后，每个人刚进服务器都会进入插件自动生成的default组 这个就是初始组

后台给OP的话：
除了2L的给予方法，也有另外一种方法
/lp user XXXXX permission set *
就可以了，意为给XXXXX所有权限。

如何给予别人权限的话：
举个例子，我们想给某个人ban人的权限，那么从
http://www.mcbbs.net/thread-727722-1-1.html
这个权限文档里找到nucleus.ban.base

然后输入
/lp user XXXXX permission set nucleus.ban.base
即可
意思是给XXXXXban人的权限。

作者: xfdf123456    时间: 2018-6-22 12:52
在服务端按步骤依次输入
/luckperms creategroup admin    新建一个叫做ADMIN的权限组
/luckperms group admin permission set * true   
给admin组使用所有命令的权限(*可以换成其他权限 如想要/hat命令就可以输入/luckperms group admin permission set hat true)
/luckperms user 【换成玩家名】 parent add admin 把玩家加入到admin组
