添加自定义音效
  • 在资源包\assets\minecraft下新建名为sounds，后缀为json的文本，并打开，输入如下
    1. {
    2.     "ouo.s1": {
    3.         "sounds": [
    4.             {
    5.                 "name": "custom/sound1",
    6.                 "stream": true
    7.             }
    8.         ]
    9.     },
    10.     "ouo.s2": {
    11.         "sounds": [
    12.             {
    13.                 "name": "custom/sound2",
    14.                 "stream": true
    15.             }
    16.         ]
    17.     },
    18.     "ouo.s3": {
    19.         "sounds": [
    20.             {
    21.                 "name": "custom/sound3",
    22.                 "stream": true
    23.             }
    24.         ]
    25.     }
    26. }
    复制代码

  • 在资源包\assets\minecraft下新建文件夹sounds，并打开
  • 新建文件夹custom，并打开
  • 分别放入ogg格式的音频文件sound1、sound2、sound3
    如果是较长的音频文件，stream处设为true
    1.11前的playsound格式：
    1. /playsound ouo.s2 @p
    复制代码
    1.11起的playsound格式：
    1. /playsound ouo.s2 music @p
    复制代码
