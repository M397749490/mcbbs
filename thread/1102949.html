使用方法：（文件下载见帖子最后）
1、解压文件到.minecraft/saves/存档名称/data/functions
2、进游戏输入/scoreboard players tag @s add calculate（如果提前进入了游戏先输入/reload）
3、输入一次/function 2_to_10:main来初始化
4、输入/scoreboard players set @s input 任意二进制数来设置要转化的二进制数
5、再次输入/function 2_to_10:main来开始转化
注意：·由于计分板输入大小的限制（-2147483648~2147483647），太长的二进制数无法被转化
    ·同时只能有1名玩家拥有calculate标签

2_to_10:main

  1. scoreboard objectives add input dummy
  2. scoreboard players set 1 input 1
  3. scoreboard players set 2 input 2
  4. scoreboard players set 10 input 10
  5. scoreboard players set multiply input 1
  6. scoreboard players set input_num input 0
  7. scoreboard players set input_num_sum input 0
  8. scoreboard players operation input_backup input = @a[tag=calculate] input
  9. function 2_to_10:2to10 if @a[tag=calculate]
  10. scoreboard players operation @a[tag=calculate] input = input_backup input
  11. tellraw @a [{"text":"输入："},{"score":{"objective":"input","name":"input_backup"},"color":"aqua","bold":true},{"text":"\n输出："},{"score":{"objective":"input","name":"input_num_sum"},"color":"red","bold":true}]
复制代码
2_to_10:2to10
  1. scoreboard players operation input_num input = @a[tag=calculate] input
  2. scoreboard players operation input_num input %= 10 input
  3. scoreboard players operation input_num input *= multiply input
  4. scoreboard players operation multiply input *= 2 input
  5. scoreboard players operation input_num_sum input += input_num input
  6. scoreboard players operation @a[tag=calculate] input /= 10 input
  7. function 2_to_10:2to10 unless @a[tag=calculate,score_input=0]
复制代码
主要原理：（其实是挺水的函数xd）
主运算在2to10函数中进行，该函数循环的次数为输入二进制数的位数，每次获取数字从后往前的1位并进行运算
二转十方法：每一位数x2^(i-1)，其中i为数字位数
例如输入1001，循环4次，第一次余除10获得个位的1，将其乘以2^0=1，并存储到input_num_sum用于累加中，最后再将该数整除10，变为100
第二次余除10获得十位的0（100%10=0，为原数字的十位），将其乘以2^1=2
以此类推，当整除4次10后，一个4位数便会为0，这也是循环的原理
在函数最后调用自身，加入限制条件判断玩家输入的数直到整除10到值小于等于0时停止运行
function 2_to_10:2to10 unless @a[tag=calculate,score_input=0]
最后输出的时候input_backup是玩家的输入，input_num_sum是转化好的结果
另外函数会保留上次运行的输入，运算一次后不改变分数依然是原先的分数，可以再次运算
