安装与使用
如果想制作使用空岛等级的任务，需安装ASkyBlock/USkyBlock空岛前置

指令与权限
  • /q  /quests - 插件基础指令，打开任务分类菜单
  • /quests a reload - 重载插件
  • /quests a update - 检查更新
  • /quests help - 插件帮助
  • /quests q <任务ID> - 直接开始任务
  • /quests c <任务分类ID> - 直接打开任务分类
  • /quests a - 查看管理员指令帮助
  • /quests a opengui q <玩家名> - 强行为玩家打开任务菜单
  • /quests a opengui c <玩家名> <任务分类> - 强行为玩家打开任务分类菜单
  • /quests a moddata fullreset <玩家名> - 清除玩家所有任务记录
  • /quests a moddata reset <玩家名> <任务ID> - 清除玩家指定任务记录
  • /quests a moddata start/complete <玩家名> <任务ID> - 强制开始/结束玩家的任务

建议给玩家的权限
quests.command - 使用/q 打开任务分类菜单，选择/提交任务


配置文件
任务配置格式
该配置已过时，仅供参考

  1. quests:
  2.   'blockbreak1':
  3.     # 任务类型
  4.     # MINING挖掘方块 MININGCERTAIN挖掘特定方块 BUILDING放置方块 BUILDINGCERTAIN放置特定方块 MOBKILLING击杀生物
  5.     # MOBKILLINGCERTAIN击杀特定生物 PLAYERKILLING击杀玩家 INVENTORY背包内有足够用于提交的物品
  6.     # ASKYBLOCK空岛等级 USKYBLOCK空岛等级 TIMEPLAYED游戏时间 EXP等级 TOTALEXP经验点 WALKING行走距离
  7.     type: MINING
  8.     # 该任务可以重做吗
  9.     redoable: true
  10.     # 是否开启冷却以及冷却的时间分钟
  11.     cooldown:
  12.       enabled: true
  13.       minutes: 30
  14.     # 接受此任务需要完成的任务前提  
  15.     # requires: 'blockplace1'  
  16.     # 世界限定  
  17.     # worlds:
  18.     #   restricted: true
  19.     #   allowed-worlds:
  20.     #   - 'world'
  21.     # 要完成任务的指标，在该任务里代表“10个方块”  
  22.     value: 10
  23.     display:
  24.       item: 'WOOD_PICKAXE'
  25.       name: '&9挖掘方块 I'
  26.       lore:
  27.       - '&7想要完成这个任务你必须:'
  28.       - '&7挖掘 10 个任意方块'
  29.       - ''
  30.       - '&7奖励:'
  31.       - '&7$500'
  32.       - ''
  33.       - '&7当前: %progress%/10 个'
  34.     # 任务完成执行的控制台指令，%player% 代表玩家名称  
  35.     rewards:
  36.     - 'type:command, value:[eco give %player% 500]'
