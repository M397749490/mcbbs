Wouldn’t it be awesome if you were able to paint blocks in Minecraft? This resource pack doesn’t exactly let you paint blocks but it does allow you to spawn blocks in a wide variation of colors. It works for 6 different types of blocks such as wood planks and fence posts. Use this resource pack if you want to add some colors to your next creations!
And by the way, it doesn’t replace any of the default blocks!
Creator: Fernancraft277998
Type the following text command to spawn any of the following blocks found in the list further down: /setblock ~ ~ ~ <type> <id>
  • Dirt (ID: 1 – 13)
  • Stone (ID: 8 – 15)
  • Planks (ID: 7 – 14)
  • Fence (ID: 6 – 14)
  • Stained Glass (ID: 0 – 15)
  • Stained Glass Panels (ID: 0 – 15)
Let’s say you wanted to spawn a green Oak Wood Planks block then you would need to type the following command: /setblock ~ ~ ~ planks 6
Even though it’s only possible to use the blocks by using the setblock command it’s still pretty cool as you can use it to add some colors to your creations
作者：Fernancraft277998
（这类也分为Addons吧）
如果能在Minecraft内自定义方块的色彩，那将造福多少建筑党啊，这个材质能让自定义游戏内6种方块的颜色，分别是：石头，泥土，玻璃，玻璃板，栅栏，木板。如果你想更好的装饰你的建筑，快来下载这个材质吧
不替换任何原版方块
获得方块方法：
输入指令： /setblock ~ ~ ~ <type> <id>
泥土：Dirt 颜色值：(ID: 1 – 13)
石头：Stone 颜色值：(ID: 8 – 15)
木板：Planks 颜色值：(ID: 7 – 14)
栅栏：Fence颜色值： (ID: 6 – 14)
玻璃：Stained Glass 颜色值：(ID: 0 – 15)
玻璃板：Stained Glass Panels 颜色值：(ID: 0 – 15)
如果你想得到个绿色的木板，就输入：
/setblock ~ ~ ~ planks 6
虽然它只能通过指令来获取方块，但也是非常酷非常有用的。:) 希望它能激发你更多的创造灵感
