二、作者的话

It is a plugin for your Hub/Lobby, that allows you to customize many features of the light server lobby powerful and free for all.
This plugin has been tested in version 1.10
Please report any error in version 1.8 1.9 and 1.11 to correct it immediately

这是一个大厅管理类型的插件,它有许多特色和特点,并且,它永久免费提供给大家。这个插件在1.10上测试了,请大家在1.8,1.9,1.11测试然后把错误信息给他。
