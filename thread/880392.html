BGM:



简介：如果你玩过Vazkii的Botania Garden of Glass mod那么你应该对鹅卵石不陌生，

          这个Mod就引用了这个概念，你可以空手右击一个土方块或草方块来获得鹅卵石，

          合成表中摆放成2X2的样子就可以合成,

          这个Mod适用于一些特定的地形和整合包使用，如：空岛，

          当然你也可以可以指定使用的世界类型，可以右击的方块，掉落的物品。

配置文件：
代码粘贴了几次都没成功也不知道为什么
# Configuration file

general {

    ##########################################################################################################
    # rite clicker
    #--------------------------------------------------------------------------------------------------------#
    # Here you can make changes to the mod features.
    ##########################################################################################################

    "rite clicker" {
        S:"Blocks that should drop the pebbles:"=minecraft:grass, minecraft:grass_path, minecraft:farmland, minecraft:dirt 可以掉落鹅卵石的方块
        B:"Do you want the right click function to only work when sneaking?"=true 只在潜行模式下右击才会掉落鹅卵石
        S:"Here you can specify the world types RiteClicker should NOT work in"=default, customized, largeBiomes, amplified, flat, botania-skyblock
         指定无法掉落鹅卵石的世界类型
        S:"Item that should be dropped on right click:"=riteclicker:pebs 右击方块掉落的物品
        S:"Sound that should be played when block is right clicked:"=block.grass.hit 右击方块播放的声音
    }

}
