HotPotato


来一把烫手山芋小游戏吧
GitHub开源: https://github.com/lt-name/HotPotato_Nukkit
当前插件版本: v1.0.2-SNAPSHOT



玩法：

在爆炸倒计时结束前，将手中的土豆递给别人(打别人一下)
倒计时结束时，手中持有土豆的将阵亡，同时随机从存活玩家中选出一名给予土豆
最后的幸存者即是胜利者

插件命令：

  如果命令与其他插件存在冲突，请参考config.yml配置文件

  玩家命令：
    /hotpotato help 查看帮助
    /hotpotato ui 打开ui
    /hotpotato join 房间名 加入房间
    /hotpotato quit 退出房间
    /hotpotato list 查看房间列表

  设置命令（仅op可用）：
    /hotpotatoadmin help 查看帮助
    /hotpotatoadmin ui 打开ui
    /hotpotatoadmin setwaitspawn 设置当前位置为出生点
    /hotpotatoadmin addrandomspawn 添加当前位置为随机出生点
    /hotpotatoadmin setwaittime 数字 设置游戏人数足够后的等待时间
    /hotpotatoadmin setgametime 数字 设置爆炸等待时间
    /hotpotatoadmin startroom 强制开启所在地图的房间
    /hotpotatoadmin stoproom 强制关闭所在地图的房间
    /hotpotatoadmin reloadroom 重载所有房间
    /hotpotatoadmin unloadroom 关闭所有房间,并卸载配置



配置文件：
config：
  1. 插件命令: hotpotato
  2. 管理命令: hotpotatoadmin
  3. #@p 代表玩家 &con 代表控制台权限
  4. 胜利执行命令:
  5.   - me 我胜利了
  6.   - tell "@p" 恭喜获得胜利！&con
  7. 失败执行命令:
  8.   - me 我失败了
  9.   - tell "@p" 很遗憾你失败了！&con
复制代码

PlayerInventory文件夹为玩家背包保存数据，用于在玩家进入房间时保存背包，并在退出时还原，不建议手动更改
Rooms文件夹为房间配置数据，请按照命令帮助进行设置，不推荐手动更改
Skins文件夹为皮肤文件数据（版权问题，插件不自带皮肤，请自行搜集）
为了得到更好的游戏效果，请自行寻找16个(最好16个，即房间最大人数)普通皮肤，放到Skins文件夹中
添加皮肤方法：在Skins文件夹中新建一个文件夹，用皮肤名字命名（或者自定义个，反正用来区分就行），将皮肤图片放到里面并重命名为skin.png即可
