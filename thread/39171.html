第一个问题：
岩浆桶不能倒出来，是essentials插件的物品禁用功能，默认禁用了327岩浆桶。解决办法：文本编辑器（不推荐记事本）打开服务器plugins\Essentials\config.yml，在 EssentialsProtect 的设置部分，将如下位置的327都删掉
  1.   blacklist:

  3.     # Which blocks should people be prevented from placing
  4.     placement: 10,11,46,327                                                   这里    ,327  删掉

  6.     # Which items should people be prevented from using
  7.     usage: 327                                                                       这里   327  删掉

  9.     # Which blocks should people be prevented from breaking
  10.     break:

  12.     # Which blocks should not be pushed by pistons
  13.     piston:
复制代码
至于"点门会一次性进行开关两下动作"，我猜测是没有权限开这个门的正常现象而已。一般因为普通用户组权限过低，或者是你尝试打开的是别人领地里的门。
