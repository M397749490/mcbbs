每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。

然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。

Minecraft 1.14 仍未发布，18w48a为其第9个预览版。

Minecraft Snapshot 18w48a
A Village & Pillage Java Snapshot
Minecraft快照18w48a
村庄与掠夺更新的Java版快照


We've been doing a great job with the 'Pillage' part of the Village and Pillage update for a while now, which means it's time for the 'Village' part. So today the first village of the Village and Pillage update gets a makeover!
我们在村庄与掠夺更新的“掠夺”部分干的不错，所以我们该开肝“村庄”部分了。就在今天，村庄与掠夺中的第一个村庄更新开始装修了！

Don't worry other villages, you'll be getting the makeover treatment very soon too...
别担心别的村庄，接下来会轮到它们的……

CHANGES IN 18W48A
18w48a的更改

  • Added Grindstone functionality
  • Updated plains villages
  • 为砂轮加入了功能
  • 更新了平原村庄

GRINDSTONE
砂轮
  • Moved inventory/crafting table repairing into the Grindstone, this will be its new home
  • Has the ability to remove all non-curse enchantments from an item; for each enchant removed some XP is reimbursed
  • 将合成栏中的工具修复移动到磨石中
  • 可以移除物品上所有的附魔（除了诅咒附魔），每个被移除的附魔都会返还经验

UPDATED PLAINS VILLAGES
更新后的平原村庄
  • The plains villages have got an updated look
  • The new look is adapted to the Plains biome, both when it comes to climate and to available resources
  • Uses the mysterious Jigsaw block for generation
  • Adds new structure files, quite a lot actually
  • 平原村庄外观已更新
  • 新的外观更适应平原生物群系，表现在气候特点和可用资源方面
  • 使用神秘的拼图方块来生成
  • 加入了一大堆新的结构文件，是真心多

DEDICATED SERVER
专用服务器

SERVER.PROPERTIES
SERVER.PROPERTIES
  • difficulty and gamemode settings now accept string names (integer values are still allowed as legacy option)
  • Server will exit faster if eula.txt is not set
  • difficulty和gamemode选项现在可使用字符串（整数数值虽过气但仍可使用）
  • 当eula.txt未指定时，服务器现在会更快退出

COMMAND LINE
命令行
  • Added new option --help. Not going to tell you what it does.
  • New command line option initSettings initializes eula.txt and server.properties with defaults, then exits
  • 加入了新的命令行选项--help。我才不告诉你它是干啥的呢。
  • 新的命令行选项initSettings会初始化eula.txt和server.properties，然后退出

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要魔法上网。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
