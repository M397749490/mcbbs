首先计分板：
/scoreboard objectives add count dummy

第一种：
  1. /tp @a ~ ~ ~
复制代码
  1. /stats block ~1 ~ ~ set QueryResult @a count
复制代码


第二种：
  1. /execute @a ~ ~ ~ /scoreboard players add @a count 1
复制代码


重置(第二种)：
  1. /scoreboard players set @a count 0
