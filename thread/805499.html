Akkariin MCLauncher 简洁美观的启动器 | 方便实用 | 基于 WebKit | 自动下载
嗨，欢迎使用 Akkariin MCLauncher 启动器，这个启动器属于本人暑假练手作品，功能上可能有些欠缺，我还会不断更新，谢谢支持。

简介
Akkariin MCLauncher 是一个简单方便实用的 Minecraft 启动器，拥有大部分常用的功能和小部分没什么卵用的功能。
目前支持的特性BUG：
  • 启动目前所有正式发布的版本 ( 已经支持 1.13 )
  • 正版、离线模式、Authlib 登录
  • 自动下载 libraries
  • 地图管理
  • Mod 管理，一键启用禁用删除
  • 资源下载广场
  • 自定义启动器背景
  • 启动后直接连接服务器
  • 自定义验证服务器
  • 自定义头像获取服务器
  • 自定义下载服务器
  • 支持游戏版本隔离，独立每个版本
  • 完全可修改的界面
* 在任何界面下，按下鼠标右键都可以重置启动器状态，启动游戏后不可重置。
** Authlib 需要服务器支持，目前仅支持单个 Profile

关于自定义
因为启动器界面是基于 HTML 开发的，如果您有 HTML 基础的话，可以自行修改。
启动器在运行后会将前端文件释放到目录下的 html 文件夹内，您可以自由修改这些内容。
修改后仅限于您个人使用，请勿将修改过的启动器文件二次发布到任何地方。
