RealTimeTranslation 2.1
一款促进国际商业化的插件

一、简介 Description
这款插件大型服务器都会用到，国外的人和中国人聊天的时候就能够直接翻译句子！能够促进国际化。这款插件连接上了谷歌翻译API！不过不用担心，没有VPN照样是可以用的~

二、功能 Features
  • 所有玩家都是单独翻译的
  • 简易的API适合开发者使用
  • MySQL支持，让玩家在多个服务器里无需重新设置翻译语言

三、图片 Picture

四、指令&权限 Command&Permission
/rct setlang -- rct.setlang -- 设置翻译语言

/rct toggle [指定玩家] -- rct.toggle (rct.toggle.other) -- 切换语言. 自定义: 指定玩家 切换其他玩家的语言设置

/rct reload -- rct.reload -- 刷新Config和所有玩家的文件夹

-- rct.getTranslated -- 翻译语言的权限

五、配置 Configuration
defaultLang -- 默认的语言设置
noTranslatePrefix -- 这段将添加到每个消息的最前面，将不会翻译
UseMySQL -- 如果插件需要使用MySQL
MySQL -- MySQL设置
Host -- MySQL主机
Port -- MySQL端口
Database -- MySQL数据库名称
User -- MySQL账号
Password -- MySQL密码

  5.         api.getClientLanguage(e.getPlayer()); //Return the Players Client Language

  7.         api.getLanguage(e.getPlayer()); // Returns the Language the Player specified in the Plugin

  9.         api.getLanguageCode(e.getPlayer()); //Returns the Language Code of the Player (e.g. "en", "de")
