标题: bungeecord多台服务器内网怎么跨服
我有两台云服务器 其中一台开bc和3个子服 内网ip192.168.1.97 另外一台内网192.168.1.219 准开4个子服内网连接到192.168.97的机器上 求大佬教一下bc和子服怎么配置
作者: Misaka。    时间: 2019-10-7 19:00
首先,给你一个站内的教程贴地址,可以的话请仔细阅读一下。https://www.mcbbs.net/thread-450015-1-1.html

然后呢,关于楼主的问题,我的建议如下：
第一,假设第一台有三个子服分别是A1，A2，A3,A4其中A1为登录服(大厅);A4为另一台主机
那么,bc子服设置可以如下
servers:  #服务器
  A1:
    motd: '&1服务器简介'
    address: 127.0.0.1:25565 #这里端口必须为当前主机开放端口
    restricted: false
A2:
    motd: '&1服务器简介'
    address: 127.0.0.1:20002
    restricted: false
A3:
    motd: '&1服务器简介'
    address: 127.0.0.1:20003
    restricted: false A4:
    motd: '&1服务器简介'
    address: 192.168.1.1:25565  #注意,这里必须填写另一台主机的外网地址加开放端口！
    restricted: false
为了安全起见,请务必把
ip_forward: true
这条设置设置为 true
并且把所有子服 spigot.yml 中设置 “bungeecord: true”  (登录服请设置为false)

另一台主机也请按照上面来设置,注意,这一台主机也请设置一台类似登录服的子服来二次验证登录,
否则会有安全隐患！  此主机的登录服bungeecord选项也得设置为false

注意啦,跨另一台主机的子服地址必须是外网,而不是内网地址！
有些复杂,可能说得不太清楚

更多,请自行仔仔细细阅读教程贴,多看,多做,多实验。

作者: DeathKnight    时间: 2019-10-8 12:52
借用楼上的回答，你用了BC之后所有的流量都是从BC转发到子服的，所有子服均需设置bungeecord: true 客户端不是直连到子服的，所以你的配置只要在BC上配置子服的内网IP + 端口 就行。
