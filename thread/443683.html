/mv modify set difficulty 0 这是和平，地图的话，你可以导入地图之后再创建个与那个地图文件相同名字的世界，权限不足是没有领地的交互权限使用指令给就好了
作者: 鸠流の熊    时间: 2015-5-10 11:17
