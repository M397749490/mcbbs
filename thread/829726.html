1.由于你没有说你用的商店插件名称，暂时假定为quickshop
2.玩家创建商店需要给予相关权限
  1. quickshop.use                                  -允许使用quickshop  
  2. quickshop.create.sell                       -允许使用/qs sell  
  3. quickshop.create.buy                      -允许使用/qs buy  
  4. quickshop.create.changeprice        -允许使用/qs  
复制代码

将以上4个权限给到玩家所在权限组，1.7.10一般为builder组，sponge一般为default组
指令：
1.7.10      mangaddp builder quickshop.use        其他权限自行替换
sponge     lp group default set quickshop.use     其他权限自行替换

3.限制商店数量，打开quickshop配置文件，找到一下代码
  1. limits:
  2.     #Disable these if you're not using them! If this is false, the rest of this section is ignored
  3.     #设置为false将会关闭这项功能
  4.     use: false
  5.    
  6.     #The default number of shops players can make
  7.     #默认玩家拥有商店的最大数量
  8.     default: 10
  9.    
  10.     #Players with these permissions can create these amounts of shops.
  11.     #可设置该权限的玩家能拥有商店的最大数量
  12.     ranks:
  13.         #Anyone with 'quickshop.vip' permissions, can create 20 shops instead of 10.
  14.         #拥有'quickshop.vip'权限的玩家可创建20个，而不是10个
  15.         quickshop.vip: 20 #Players with quickshop.vip can make 20 shops.
复制代码
将use：fasle       改为true
将default   改为你想要限制的数字
