怎么弄vip权限组
作者: 网络摆渡客    时间: 2014-11-12 18:33
用notepad++打开/Groupmanager/worlds/world/groups.yml文件：
1、复制里面的Builder组或者Default组的权限节点，粘贴到这个文件最下方。
2、将组名改为vip
3、修改增加删除permissions:下的权限即可，类似这样：

  2.   Vip:                  #vip用户组组名
  3.     default: false   #这里务必是当前这样
  4.     permissions:
  5.     - essentials.fly
  6.     - essentials.tp
  7.     - essentials.tphere
  8.     - mp.double_coins
  9.     - MyPet.npc.storage.max.20
  10.     - plotme.limit.10
  11.     - scavenger.free
  12.     - vanish.vanish
  13.     inheritance:
  14.     - builder
  15.     info:
  16.       prefix: '这是VIP组前缀 '
  17.       build: true
  18.       suffix: ' '
复制代码


注意，一定严格按照已有的格式来，不要随便添加删除空格。不要使用回车，除非你知道将tab缩进换成空格缩进。
