Drops Query —— 掉落查询插件

本插件可以查询到玩家的掉落物品记录,并且帮助恢复物品


使用前
玩家:腐竹,腐竹，我刚刚挖矿的时候，被别人射进岩浆里了,好多好东西都没了，你能帮我恢复吗？
腐竹：不能，我不知道你有没有真的掉物品
玩家：QAQ......

使用后
玩家：腐竹,腐竹，我刚刚挖矿的时候，被别人射进岩浆里了,好多好东西都没了，你能帮我恢复吗？
腐竹：好的，稍等下，你能告诉我你在哪里掉的吗？
(物品恢复中...)
玩家：太好了↖(^ω^)↗

PS：插件使用教程请查.0和1.1的功能介绍

[新] V1.1版本功能及使用方法


1.1版本更新内容1.修复1.0版本的几个小BUG
2.增加Config配置文件，可以设置无掉落记录模式了
3.增加恢复指令，可以直接将物品恢复给指定玩家
4.配置读取性能的优化

1.1新指令
指令列表 指令说明 所需权限
/Drop RestoreQuery [玩家] [编号] 给玩家恢复指定编号的物品 Drops_Query.admin


1.1配置文件说明
NoDrop: false

当NoDrop为false时，插件将不记录死亡时无任何物品掉落的记录，而当改成true时，即使你死亡时没有任何物品掉落也会记录起来

恢复玩家物品：
输入/Drop RestoreQuery [玩家] [编号]指令即可恢复玩家指定编号的掉落记录物品PS:需要先让玩家清空自己的物品栏才可以进行恢复(装备栏可以不清空)

然后物品就恢复了






V1.1版本下载地址:http://pan.baidu.com/s/1c0pjgwK



V1.0版本功能及使用方法


使用方法


1.举例，有个玩家正在挖矿




突然，冒出了个小白，一箭将你射进了岩浆


于是玩家东西没了，找腐竹恢复ing..
插件指令权限列表
指令列表 说明 所需权限
/Drop Query [玩家] 查询玩家的所有掉落记录Drops_Query.admin
/Drop OpenQuery [玩家] [编号] 查看某个编号的掉落记录Drops_Query.admin
/Drop delete [玩家] 删除玩家的所有掉落记录Drops_Query.admin
/Drop deleteall 删除所有的记录数据 Drops_Query.admin
/Drop reload 重新加载插件 Drops_Query.admin



然后，这个玩家的东西全没了，那么，你可以按照下面的教程查询该玩家的掉落物品
1.首先，输入/drop Query [玩家ID]来查询这个玩家的近期死亡记录
我们可以看到编号3的记录，没错，按照类型判断，就是这条记录了补充说明：
世界记录了玩家在那个世界死亡
XYZ记录了玩家死亡的坐标
类型记录了玩家的死亡方式
时间记录了玩家死亡是在什么时候
数量记录了玩家死亡时共掉落了几格物品

附：插件死亡类型解释表
类型名称 说明
摔死 玩家从高处摔落死亡
岩浆 玩家掉岩浆里烧死
烧死 玩家被火烧死
淹死 玩家被水淹死
怪物击杀 玩家被怪物正常攻击击杀
骷髅击杀 玩家被骷髅的箭射死
苦力怕爆炸 玩家被苦力怕的爆炸炸死
窒息 玩家卡在墙里或者被沙子等物品窒息
铁毡压死 玩家被高处掉落的铁毡砸死
药水伤害 玩家收到中毒,瞬间伤害等药水效果死亡


我们确定了是编号3这条记录
接着输入/drop OpenQuery [玩家] [编号]来查询这条记录的详细信息，输入后会打开一个界面，里面就是玩家所掉落的物品信息




里面的东西你可以直接取出来，还给玩家
PS:本插件也可以查询到装备栏的物品，以及任何形式的死亡(除了/suicide和/kill两种特殊死亡除外不能查询)
v1.0版本下载地址：http://pan.baidu.com/s/1sjJkNRf
