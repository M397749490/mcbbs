Coordinate
  1. 模型:
  2. [the] (x|y|z)(-| )(coord[inate]|pos[ition]|loc[ation])[s] of %locations%
  3. %locations%'[s] (x|y|z)(-| )(coord[inate]|pos[ition]|loc[ation])[s]
  4. 表示位置的一个坐标
  5. 示例:
  6. player's y-coordinate is smaller than 40:
  7.         message "Watch out for lava!"
复制代码
或者
Location
  1. 模型:
  2. [the] [event-](location|position)
  3. [the] (location|position) %direction% [%location%]
  4. 事件发生的坐标
  5. 示例:
  6. drop 5 apples at the event-location # exactly the same as writing 'drop 5 apples'
  7. set {_loc} to the location 1 meter above the player
