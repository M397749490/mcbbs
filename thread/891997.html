★插件介绍★


本插件是一款支持1.14的，睡觉？？？？ 插件，到晚上，制定玩家（可设置）上♂床，可以愉快的跳过整个夜晚！

★插件命令和权限★


指令:
/sleepy                                                                                                                          显示插件详情
/sleepy reload                                                                                                                重载插件
权限:
sleepy.reload                                                                                    重新加载插件权限

★基础操作★


进入游戏,到晚上直接上床,跳过夜晚。这个大概可以设置不需要所有人都上传就可以跳过

★配置文件&语言文件★



config:
  1. # Sleeper Configuration #

  3. # 需要多少玩家上传才可以跳过这个夜晚？
  4. # - A number  - 可以设置一定数量的
  5. # - HALF      - 需要一半玩家
  6. # - ALL       - 这个世界的所有玩家！
  7. required-sleeping: HALF

  9. # 所有玩家都上床后，还需等待多长时间（单位tick, 20tick=1s)
  10. new-day-delay: 40

  12. # 设置玩家需要在床上呆多长时间（单位tick, 20tick=1s)
  13. # 0<数值<12100 (详见 https://minecraft.gamepedia.com/Day-night_cycle)
  14. new-day: 1000

  16. # 哪些世界禁用该插件
  17. # 下面的世界是两个例子，以下两个世界不用睡觉
  18. disabled-worlds:
  19.   - world_nether
  20.   - world_the_end


  23. #下面是一些提示文本，可以自行酌情修改
  24. messages:
  25.   playerNowSleeping:
  26.     message: "&c%player% 正在睡觉."
  27.     show: CHAT
  28.   playerNoLongerSleeping:
  29.     message: "&c%player% 不睡了."
  30.     show: CHAT
  31.   toSkipNeeded:
  32.     message: "&c%value% 需要更多玩家上床睡觉才能跳过夜晚."
  33.     show: ACTION_BAR
  34.   toSkipSatisfied:
  35.     message: "&b看来已经够了，晚安!"
  36.     show: ACTION_BAR
  37.   afterNightSkipped:
  38.     message: "&e&l起床啦啦啦啦!"
  39.     show: ACTION_BAR
