Grouped Nodes

mcmmo.* - Allows use of every single mcMMO feature and command .
mcmmo.tools.* - Allows the use of All the Tools permissions.
mcmmo.ability.* - Allows the use of all the abilities.
mcmmo.item.* - Allows the use of the Item permissions.
mcmmo.chat.* - Allows all Chat permissions Including Admin chat.
mcmmo.skills.* - Allows all the skills permissions.
