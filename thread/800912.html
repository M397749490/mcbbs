LagPoint

LagPoint 是一款先进的计算延迟的插件,它不使用玩家的延迟数据,通过分析数据包来计算玩家的延迟

因此它可以检测出玩家的真实延迟

可以有效防止黑客伪造延迟(Pingspoof Hack)



功能

  • 防止 Pingspoof 绕过
  • PlaceholderAPI 支持
  • 开发者使用的 API
  • 查看玩家延迟的命令
  • 如果你需要任何其他功能,请在 Discord Server 上告诉我(https://discord.gg/pEvY55J)

延迟点数

LagPoints 与 Ping 值不大一样

  • 0 - 10: 几乎没有延迟
  • 10 - 30: 微弱的延迟
  • 30+: 巨大的延迟


命令

/lagpoint - 查看自己的延迟

/lagpoint <player> - 查看其他玩家的延迟


PlaceholderAPI & Api
%lagpoints_player% : 玩家LagPoints
  1. //获取玩家 LagPoints
  2.         LagPointAPI api = LagPoint.getInstance().getLagPointAPI();
  3.         int lagpoints = api.getLagPoints(player);
