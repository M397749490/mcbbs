全局
  • 改进的服务器列表
    • 可以在添加或编辑服务器时隐藏服务器IP
    • 服务器版本显示在连接进度条的左侧
    • 服务器延迟提示现在能够显示服务器与客户端之间是否存在不匹配的协议版本。
    • 无法加入不匹配的服务器
  • 改进的设置菜单
    • 将聊天设置重命名为多人游戏设置
    • 为披风所有者加入不显示披风的选项
    • 加入全屏与垂直同步切换
  • 改进的F3功能
    • shift+F3会显示统计扇形图
    • 能够显示玩家朝向与角度
    • 能够显示玩家位于哪一个区块内（采用X与Z坐标标定）
    • 按着F3的同时按下P能在窗口失焦时切换自动暂停。
    • 按着F3的同时按下H切换出详细的项目说明。
    • 按着F3的同时按下T能够重载材质包
  • 更新语言文件
游戏内容
  • 改进的多人游戏
    • op.txt内无内容时，出生地保护会被禁用。
    • 出生地保护半径现在可以在server.properties内配置
  • 改进的物品栏管理
    • 选取方块按键也支持物品的复制了，能够给予你一组
    • 鼠标在物品上悬停时按下1-9热键能够将物品与指定物品栏中的物品交换。
    • 创造模式中shift点击物品能够将其移入生存模式物品栏
  • 添加与改进了一些命令
    • /difficulty改变难度的命令[9]
      • /difficulty 0 = 和平
      • /difficulty 1 = 简单
      • /difficulty 2 = 普通
      • /difficulty 3 = 困难
    • 可切换开关PvP[10]
    • 加入/spawnpoint命令以更改玩家出生点
      • /spawnpoint <玩家> <x> <y><z>
    • 加入/w，可作为/tell的简写
    • 加入/weather以更改当前天气，并设置新的天气的持续时间
      • /weather [clear | rain | thunder] <时间>
    • 加入/gamerule <游戏规则><true/false>以查询与更改游戏规则，应用于命令方块。
      • /gamerule doFireTick来改变火势是否可以蔓延
      • /gamerule doMobLoot来改变生物是否掉落物品
      • /gamerule doMobSpawning来改变攻击型生物是否刷出
      • /gamerule doTileDrops改变方块是否会掉落
      • /gamerule keepInventory改变玩家死亡以后物品是否掉落
      • /gamerule mobGriefing改变爬行者、末影人与凋灵是否能改变方块（如爬行者的爆炸和末影人搬走方块的行为）
    • 加入/clear以清空玩家的物品栏
    • 更改/xp，这样其可以用于把某玩家的等级提高到指定级数
    • 更改/tp以支持相对坐标
  • 加入命令目标符[11][12][13]
    • 可用参数：
      • @p - 最近的玩家
      • @a - 所有玩家
      • @r - 随机玩家
      • @f - 最远的玩家
    • 可以用[]定义参数，句式为x=0，这里x为参数
    • 可用的参数：
      • x,y,z - 坐标
      • r - 距离
      • m - 游戏模式
      • l - 最小经验级数
      • lm - 最大经验级数
      • rm - 最小距离
    • 某些变量只能用于@a：
      • c - 返回玩家数量的最大值。如果低于0则无效。
  • 升级声音引擎
    • 为放置木头、石头、植物、沙砾类似属性的方块添加音效。
    • 为行走在沙子、沙砾、灵魂沙、草丛的行为添加音效。
    • 为僵尸、骷髅、牛、猪、蜘蛛、末影人、恶魂、蠹虫、岩浆怪、狼、末影龙、蝙蝠、铁砧添加音效。
    • 为治愈僵尸、感染村民添加音效。
    • 为着火及剪羊毛添加音效。
    • 为攀爬梯子及搭乘矿车添加音效。
    • 每隔5级为升级添加音效。
    • 为液体添加持续的环境噪声。
  • 改进的传送门
    • 生物、物品与抛射物可以穿过传送门，并保持其初始速度[14][15][16]
    • 实体会瞬间通过传送门，但有较长的冷却时间[17]
    • 着火的实体（比如烈焰人火球）可能通过传送门离开下界，并烧掉主世界的一些东西。[18]
    • 传送门能根据实体进入的地点传送实体[19][20]
    • 穿过传送门之后玩家的朝向被修正
    • 创造模式中的玩家传送可以在瞬间完成
  • 改进的冒险模式
    • 用适当的工具能够开采方块
    • 能够放置方块了
  • 改进的繁殖机制
    • 鸡现在用种子来繁殖了，而不是以前的小麦。[21]
    • 猪现在用胡萝卜来繁殖了
  • 你现在可以还原一个荒凉的小村庄或者自己建一个全新的村庄[22]
  • 诸多小的改进
    • 在BOSS血条之上添加BOSS名称
    • 钓鱼与繁殖也能够获得经验
    • 已生成的世界可以在世界选择菜单中重新生成。
    • 改变多个物品的图标
    • 使用/give能够立即将物品放入物品栏
    • 门、活板门、拉杆与按钮无法再用鼠标左键激活[23]
    • 为物品添加可以用作别名命名的NBT标签
    • 为生物添加可以决定是否会消失的NBT标签
  • 修正漏洞
    • 修正/me命令只能由OP使用的问题
    • 修正/tell命令工作不正常的问题
    • 解决部分光照问题
    • 解决穿戴附魔盔甲时，手持任何物品都会发光的问题
    • 修正在潜行时，皮肤的第二层无法正常显示的问题
    • 修正烈焰人生成不正常的问题
    • 修正宠物会随机传送的问题
    • 修正在禁止pvp的服务器中，玩家依然可以通过使用带有火焰附加魔咒的剑伤害其他玩家的问题
    • 修正在矿车中的实体不可见的问题
[编辑] 世界生成
  • 可自定义的世界类型生成[24]
  • 使得超平坦世界可自定义[25][26]
    • 现在可以用方块ID、数据值与高度定义不同的地层
    • 可改变生物群系
    • 所有的生成选项都储存在预设中，可供分享与再使用
    • 多样化的地形装饰（除了村庄外）都可定义
    • 默认预设：
      • 传统平地 - 2;7,2x3,2;1;village
      • 挖洞者的梦想 -2;7,230x1,5x3,2;3;stronghold,biome_1,decoration,dungeon,mineshaft
      • 水之世界 -2;7,5x1,5x3,5x12,90x9;1;biome_1,village
      • 主世界-2;7,59x1,3x3,2;1;stronghold,biome_1,village,decoration,dungeon,lake,mineshaft,lava_lake
      • 雪之王国 - 2;7,59x1,3x3,2,78;12;biome_1,village
      • 无底洞 - 2;2x4,3x3,2;1;biome_1,village
      • 沙漠 -2;7,230x1,5x3,2;3;stronghold,biome_1,decoration,dungeon,mineshaft
      • 红石就绪 - 2;7,3x1,52x24;2
    • 一个预设的例子：95;35:2;2x20;1;stronghold –95为格式版本，后面跟一个分号，分号后面为地层信息。每个新地层之间都用逗号隔开，必须由方块ID（35）构成，可以用冒号与其附加数据值相连（:2）。在方块ID之前可以用2x代表层数的厚度。地层定义完毕之后，加入你想生成的结构，包括其选项。
  • 在沼泽中加入沼泽小屋[27]
  • 蠹虫方块会罕见地出现于山脉生物群系
    • 山脉生物群系中平均每个区块生成一个怪物蛋。
  • 在雨林生物群系以及村庄中会出现胡萝卜与马铃薯[28]
方块 &物品
  • 命令方块
    • 被红石激活后会运行事先编辑好的命令
    • 为冒险模式所设计
    • 只有OP才能编辑，而且server.properties中的enable-command-block必须启用
    • 只能通过/give playername 137获取[29][30]
  • 信标
    • 定位为游戏后期的方块
    • 不断发出光芒，具有垂直向上的光束效果，且会为一定范围内的玩家提供正面效果
    • 激活条件为：在其下建造一个由钻石块/金块/铁块/绿宝石块构成的金字塔，再选择一种效果
      • 最简单的金字塔需要9个方块；最高等的需要164个
    • 必须暴露在阳光下才能运作
    • 随着金字塔层数的加高，可应用的效果变多，且效果作用范围加大
    • 选择一种效果需要消耗1个铁锭、钻石、金锭或绿宝石
    • 下列效果的解锁层数需求依次递增：
      • 速度、速掘
      • 抗性提升、跳跃提升
      • 力量
    • 当金字塔达到最大值4层，可以选择副效果
      • 副效果为生命恢复，或是某个主效果的等级II
    • 信标给予的效果比药水产生的颗粒效果要少
  • 铁砧[31]
    • 用于物品修复、合并附魔、重命名任何方块与物品。代价是经验的消耗
    • 工具也能用其原材料修复
    • 相同等级魔咒合并会提升1级等级；不同等级合并会保留最大值
    • 冲突的魔咒会被移除其中之一
    • 使用以及坠落均会加重其损耗程度——损耗程度依次为铁砧，轻度损耗的铁砧，重度损耗的铁砧
    • 具有四种朝向，无法被活塞推动
    • 经验值消耗会因魔咒等级与稀有程度而变化——最大消耗为39级经验[32]
      • 欲知铁砧合并魔咒的原理，参见铁砧机制条目
    • 铁砧会受重力影响，给予玩家或生物与下落高度成正相关关系的伤害。被铁砧杀死的玩家会出现信息“XXX被铁砧压扁了”。
    • 铁砧落在下列方块上时会摧毁该方块：大多数透明方块（火把、铁轨等）上
  • 刷怪箱
    • 加入若干NBT标签用于更改某些核心刷怪规则
      • 刷怪范围
      • 最大刷出实体数量
      • 纵向刷怪半径
  • 红石中继器
    • 用另一个中继器向该中继器侧向充能能够得到锁存效果
    • 中继器位于锁存状态时，第二个红石火把将不可见，换成一道黑灰色的横条。此时中继器输出不随输入改变
  • 花盆[33]
    • 允许玩家种植所有植物类方块[34]
    • 右键点击种植，左键点击可以同时回收两者
  • 圆石墙[35]
    • 还具有其变种苔石墙
    • 与栅栏特性类似——可彼此连接，与其他方块连接，与栅栏门匹配，具有1.5格高的碰撞箱
    • 区别在于边角处与上置其他方块处的视觉高度较高
  • 木头
    • 放置时的朝向依据其放置表面方位而定
      • 方块侧面：侧放
      • 方块顶面或底面：正放
  • 楼梯
    • 支持墙角处的楼梯[36]
  • 物品展示框 [37]
    • 任何东西都可以放在展示框里[38]
    • 钟、指南针与地图均可正常工作——地图上只会显示其所身处的展示框的地标[39][40][41]
    • 在创造模式中，使用选取方块按键能直接得到选中的方块或物品
  • 头颅[42]
    • 为生物被玩家杀死时的罕见掉落物
    • 只能由凋灵骷髅掉落，但也存在爬行者、僵尸、骷髅与玩家的头颅
    • 可以有16个方向的摆放，或是悬挂在墙上
    • 可穿戴
    • 使用外部编辑器编辑其NBT标签的话，玩家头颅可指定为特定玩家的头颅——名称为“XXX的头”
  • 活板门
    • 活板门可以根据鼠标的指向放在方块的上面或者下面。[43]
  • 按钮
    • 激活时长提高0.2秒
    • 新合成配方——只需要一个石头
  • 木质按钮
    • 可被箭激活
    • 需要一个木板合成
  • 火
    • 依据难度不同，蔓延速度也不同[44]
  • 树苗
    • 降低碰撞箱体积
  • TNT
    • 现在可被火焰箭激活
  • 马铃薯
    • 可种植在湿润耕地上，成熟后采集得到1-4马铃薯
    • 可被骨粉立即催熟
    • 可烹饪得到烤马铃薯
    • 罕见掉落毒马铃薯
    • 马铃薯回复0.5饥饿点数；毒马铃薯回复1饥饿点数，并有一定几率中毒；烤马铃薯回复3饥饿点数
  • 胡萝卜
    • 可种植在湿润耕地上，成熟后采集得到2-4胡萝卜
    • 可被骨粉立即催熟
    • 可与金粒合成金胡萝卜
    • 胡萝卜回复2饥饿点数，金胡萝卜回复3饥饿点数
  • 萝卜钓竿
    • 可以用来控制猪的行动
    • 猪会朝着玩家手持萝卜钓竿指向的方向移动
    • 手持萝卜钓竿的玩家也会吸引附近的猪
    • 在骑猪过程中逐渐损耗，最终吃掉胡萝卜，只剩钓鱼竿。[45][46]
    • 起步较慢，但最终能达到最大速度5格/秒[47]
    • 可右键获得瞬间爆发速度，但耐久消耗加剧
    • 用钓鱼竿和胡萝卜对角摆放合成[48]
  • 南瓜派 [49]
    • 回复4饥饿点数
    • 合成方法：南瓜、鸡蛋与糖
  • 下界之星
    • 由凋灵掉落
    • 用于合成信标
    • 像附魔装备一样发光
  • 夜视药水
    • 由金胡萝卜与粗制的药水合成
  • 隐身药水[50]
    • 能够隐藏玩家本身、名称标签与披风[51]
    • 攻击型生物只有你撞到它们或是主动攻击它们，他们才会反击
    • 喷溅隐身药水也可以让生物隐身，尽管部分生物并不完全隐身
    • 由发酵蛛眼与夜视药水合成而得
  • 药水
    • 现在可以得到任何可用的药水效果、等级与持续时间
    • 有关数据以NBT标签形式存储，但药水色彩不变
  • 地图
    • 合成得到空地图，右键使用后会变成地图
    • 地图初始缩放比例较大，还可以扩展（通过与纸合成）[52]
    • 同一地图上，玩家可以看到其他玩家
    • 地图可以克隆[53]
    • 移除文本标题
    • 玩家不在地图显示范围中时，会显示为一个小圆圈
  • 盔甲
    • 钻石盔甲的袖子内层有一个V形开口
    • 对皮革盔甲进行了大幅度修改
  • 皮革盔甲
    • 一共有16,777,216种可用的染色[54] [55]
    • 可以在工作台中使用不同的颜料来染上复杂的颜色。
    • 其标签会显示出其颜色。
    • 可以用炼药锅来洗掉他的颜色 [56][57]
    • 更改物品与模型的颜色与材质
    • 现在具有双重材质，其中一层为其本来的颜色
生物
  • 凋灵
    • 凋灵是一种由玩家召唤出的具有飞行能力的有三个头的Boss型生物会主动投机非玩家或不死生物。
    • 召唤凋灵需要呈T字型放置4块灵魂沙以及在其顶部放置三个凋灵头颅进行召唤。
    • 在生成后，会闪烁蓝光同时恢复生命值并逐渐变大，在这一阶段凋灵为无敌状态（约几秒钟时间），在此之后凋灵开始攻击玩家和生物。
    • 每一个头颅会瞄准独立的目标并产生被称为凋灵之首的火焰投射物，投射物在接触后会爆炸。
    • 凋灵会发射两种不同类型的投射物：第一种投射物为蓝色，由其较小的头颅中发出；第二种投射物颜色稍暗，由其较大的头颅瞄准玩家后发出。
    • 当被投射物集中后，玩家会获得“凋灵药水II”的效果，这一效果类似于中毒效果，但是玩家的生命值变为黑色。
    • 凋灵会持续回复生命
    • 当凋灵生命值低于一半时会提高其护甲并对弓箭攻击免疫。
    • 在杀死时会掉落下界之星。
    • 凋灵在被召唤出后，主世界的天空会变暗。
  • 凋灵骷髅
    • 携带石剑并在被玩家杀死后极少数的情况下会掉落石剑。
    • 掉落骨头、煤，极少数情况下掉落凋灵骷髅。
    • 在玩家为击中后玩家会获得凋灵效果。
    • 在下界要塞中生成。
    • 会在极少数的情况下，取决于难度，会生成可以拾取盔甲、头部、物品、方块、武器、工具的凋灵骷髅。[58] -盔甲和工具以及剑会自动进行更换（如果可能并比其自身装备更好的话）[59][60][61][62][63][64][65][66][67]物品则会再该骷髅被杀死后100%几率掉落。[68]在其被杀死后会掉落其手持物。[69] [70]
    • 所有装备都是有实际功能的：如剑和工具会增加伤害，盔甲则会对其进行保护。
    • 掉落物会有极低的几率掉落稀有并损坏的工具。
    • 随着难度的上升，会更有可能生成装备有工具的凋零骷髅，当其被玩家杀死后也会有极低的几率掉落。
  • 女巫
