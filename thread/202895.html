介绍
       Skytext是一个根据你的需要在一定区域内生成文字的插件
比如使用/skywrite hello_world 0 就会在你脚下用方块写出hello world来。你可以用这款插件来在传送门或是其他重要区域写上文字信息。或者印上大大的服务器文字LOGO——这可比自己搭方便多了。（当然字会变得很大）
哇，它还会旋转！
          *在1.1+版本可以在配置文件中添加信息组并设置，也就是说信息属性被保存下来了
          举个栗子，如果你有一个小游戏区，你可以把所有内部传送门上放上不同的文字。如果其他插件支持，那么你也可以拥有一个狂霸酷炫叼炸天的游戏文字计数器！


特性
  • 自动绘制决定的文本
  • 循环改变文字
  • 在服务器选择界面显示的附表文字（作者没介绍）
  • 允许在指定位置改变文字
  • 旋转文字

前置插件

  • worldedit

命令

备注:想要在获得的文字里拥有间隔，请用符号“_”表示一个单位长度的间隔


在站的地方创造一个拥有特定旋转角度和可选坐标的信息

  • /skytext <信息> <单次旋转角度 (0,90,180 或 270)> [x] [y] [z] [所在世界]

在配置文件创造新的信息组并设置一条默认信息

  • /skytext create <信息组名称> <信息>

往一个信息组中添加一条信息

  • /skytext set <信息组名称> <信息>

改变信息组设置(1.12新功能)

  • /skytext set <信息组名称> set <世界|tick数|旋转角度|方块id|数据库id|l位置> <信息>

重载配置文件

  • /skytext reload

配置文件
messages:# Wooo是信息组的名字，你可以在游戏中使用命令添加更多信息组或直接在配置文件中添加
  wooo:    # 决定所在的世界位置  
  world: world    # 信息组位置  
  location: 145,67,115    # 旋转一次信息的间隔  
  ticks: 500  
  # 旋转角度
  rotation: 0  
  # 绘图所用方块的ID，-1号ID意思是means leave the same as the schematic（自动采用，使规则化地不相同绘制？）     blockid: -1  
  # 所用方块的数据库中保存的ID  
  dataid: 0  
  # 循环显示的信息  
  messages:
   - hello  
   - world
权限
  • skytext.write 写信息的权限
  • skytext.create 创造信息组的权限
  • skytext.reload 重载配置文件的权限


未来计划
  • 复原功能（不然你要用WE选择区域后清除）
  • 计分板提示文字功能 (只是有大字在空中飘着是不够的!)
