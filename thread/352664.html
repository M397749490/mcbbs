首先，引用作者自己的介绍：

Steve's Factory Manager is a Minecraft mod which allows you to set up systems that moves and manages items between inventories and machines. One simply places a Machine Inventory Manager block connected to inventories (directly or through cables) and then specify commands in the manager's interface. These commands are set up in a flow chart way. This means that these are graphical commands and therefore no programming knowledge is required.
史蒂夫工厂管理MOD，是一个Minecraft的MOD（这不废话），它允许你建立一个可以在容器与机械之间移动并管理物品的物流系统。简单一点的，可以只是用一个工厂管理器连接各个容器（直连或者通过工厂线缆），然后右击打开管理界面，设定“命令”。你编辑的这些“命令”将会以一个流程图的形式来展现，这也就意味着，这是个图形化的操作界面，你不需要有任何编程知识。
（稍后介绍工厂管理器和工厂线缆）

汉化者总结：

这是我见过的功能最强大的物流向MOD，没有之一

如果你能玩转这个MOD，你就可以考虑卸载Applied Energetistics了。
（大雾，AE2有很多独特的功能，怎么能说删就删呢）

从上到下，依次是：方块伪装器-普通，方块伪装器-双面，方块伪装器-变换
普通的版本只能储存一个伪装方块的信息= =
伪装器-双面可以储存两个伪装方块的信息，并可以通过反转（Invert）功能快速切换（求证实）
伪装器-变换还不清楚特性，希望有玩家发现后补充，感激不尽

一些特性：
1.这些方块伪装出来的方块可以骗过NEI的高亮显示和Waila！
区别的方法只有一个——用手敲，看粒子效果（所以你还可以搞出一个可以敲碎的基岩来作死）
2.一个伪装器可以六个面的材质都不一样哦。NEI高亮显示指向某个面时，显示的方块名一定是材质所对应的原方块名。
3.需要接入工厂管理网络才能使用，但伪装材质并不会因为你打掉工厂管理器而消失，必须通过工厂管理器来设定清除伪装材质。
