JAVA1.13+命令方块商店


本教程使用货币为绿宝石,可替换成其他物品,甚至是计分板分数




第一步:


                                    第三层 ←连锁模式 条件制约 保持开启 箭头向上

                                    第二层 ←连锁模式 条件制约 保持开启 箭头向上

搭建一个命令方块组合                  第一层 ←脉冲模式 不受制约 红石控制 箭头向上  ←并贴上按钮或放压力板

当然,第一层的脉冲模式命令方块,也可以替换成<循环模式 不受制约 红石控制 箭头向上







第二步:



输入命令,创建一个名为"shop"的dummy类型计分板

  1. /scoreboard objectives add shop dummy
复制代码


第三步:
打开第一层的命令方块,输入命令:
  1. execute as @p[distance=..2] store result score @s shop run clear @s minecraft:emerald 0
复制代码
命令中,"clear @s minecraft:emerald 0" 中的emerald(绿宝石)可替换为其他物品,并且,数字"0"是不可变量

@p[distance=..2]的作用是限制@p的范围,类似于旧版本中[r=2]的作用,甚至可以再增加条件"limit=1"以达到最大程度的指向最近的一名玩家

[为什么不用x,y,z,dx,dy,dx限制范围?]
因为不利于大批量制作商店,而且每个x,y,z和dx,dy,dz都要重新输入


整条命令的作用:检测玩家背包是否有绿宝石这种物品




第四步:


打开第二层命令方块,输入命令:
  1. execute as @p[distance=..2] if score @s shop matches 3.. run clear @p[distance=..2] minecraft:emerald 3  
复制代码
命令中,"if score @s shop matches 3.."中的"3",与结尾的"minecraft:emerald 3"中的"3"这个数值必须相同,且必须为整数值∵前半段if语句中的"3"是用于判断玩家是否持有这个数量及以上的货币
如果if语句中的"3"<clear中的"3",则会出现我拿着两块钱就能买你3块钱东西的现象(简称白嫖)
∴这两个整数值必须相等

如果想改变价格,同时修改两个数值即可                                          


emerald(绿宝石)可替换为其他物品

整条命令的作用:付款

第五步:


打开第三层命令方块,输入指令:
  1. give @p[distance=..3] minecraft:coal 8
复制代码
给予玩家8个煤炭
命令中"[distance..3]",为什么是3呢?因为怕给了钱不给货!不过可以让第一层的命令方块下陷一格,即可改回2

当然,第三层命令方块内的指令还可以随便改成其他的指令比如give summon scoreboard enchant effect kill之类的


更多花样


什么?你想存钱?



新加一个名为money的dummy类型计分板:

  1. /scoreboard objectives add money dummy
复制代码



炫富榜(加不加都行):
  1. /scoreboard objectives setdisplay sidebar money
复制代码
取消显示炫富榜:
  1. /scoreboard objectives setdisplay sidebar
复制代码


命令方块摆法同上教程

第一层命令方块的命令不变
第二层命令方块数字改为"1"(可以设置得更高,但还是得记得两个数值要相同)
第三层命令方块的命令更改为:
  1. /scoreboard players add @p[distance=..3] money 1
复制代码

取钱:
第一层命令方块的命令更改为:
  1. execute as @p[distance=..2] store result score @s shop run scoreboard players remove @p[distance=..2] money 0
复制代码
第二层命令方块的命令更改为:
  1. execute as @p[distance=..2,limit=1] if score @s shop matches 1.. run scoreboard players remove @p[distance=..2] money 1
复制代码
第三层命令方块的命令更改为:
  1. give @p[distance=..3,limit=1] minecraft:emerald 1
复制代码


结合这些东西,我们甚至可以全程使用"money"这个"电子钱包"
比如玩家想卖掉甘蔗,第三层命令方块就是add @p[distance..2] money 1,而不是give绿宝石


关于/pay(玩家之间转账)
从左到右,打横摆
    (假装是拉杆)>
最左边是付钱玩家所站的位置,最右边是收钱玩家所站的位置
当最左边的玩家按下按钮时,扣除该玩家的钱,并增加最右边玩家的钱

缺点就是不能玩家自己自定义转出的钱数......得靠拉杆慢慢的+1+1+1+1或者+10+10+10+10.....(玩家A:在?给我12345块钱?,玩家B:***)

更多玩法,可以自己慢慢研究,挺有趣的

注意事项:
1.因为命令中"@p[distance..2]"这个数值小,所以玩家只能在命令方块的前一格按按钮,虽然能增加"limit=1"这个条件,但还是可能会探测到其他在范围内的玩家。
2.本商店系统实验版本为1.15.2
