MiniGames
BowWars
指令/权限
管理指令
/bwarena - 所有管理员命令
/bwarena create <竞技场名称> - 创建新的竞技场
/bwarena delete <竞技场名称> - 删除竞技场
/bwarena maxplayer <竞技场名称> <人数> - 设置最大玩家
/bwarena setlobby - 设置大厅
/bwarena spawnpoint <竞技场名称> - 为指定的竞技场设置重生点
玩家指令
/bw join <竞技场名称> - 加入游戏/竞技场
/bw leave - 离开游戏/竞技场
/bw stats <player> - 查看玩家信息
/bw shop - 打开商店
权限列表
bw.arena -所有管理指令
bw.shop -打开商店
bw.shop.create -创建商店
bw.stats -查看在<玩家>信息
游戏教程
创建游戏
/bwarena create <名称>
设置最大人数
/bwarena maxplayer <竞技场名称> <人数>
设置游戏大厅
/bwarena setlobby
设置重生点
/bwarena spawnpoint 2
然后就可以了开始游戏了
/bw join <竞技场名称>
开始游戏后每个玩家都会获得一把弓一把箭?，
注意：死亡掉落物品的，所以游戏制作完毕后记得输入指令
/gamerule keepInventory true
