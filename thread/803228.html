配置文件
可以使用/limitbuild reload 重载配置文件！

  1. #启用的世界名
  2. worlds:
  3.         - world

  5. permission:
  6.         #有这个权限的玩家可以无视领地权限来建造 建议给建筑师等
  7.         pass: moci.limit.pass  
  8.         #使用/limitbuild reload 的权限 无权限不会有任何提示！
  9.         command: moci.admin

  11. #需要屏蔽的事件
  12. Settings:
  13.         #下面两个分别是方块破坏和放置
  14.         BlockBreakEvent: true
  15.         BlockPlaceEvent: true
  16.         
  17.         EntityDamageByEntityEvent:
  18.                 #这个设置为false指允许玩家在领地内打怪物
  19.                 Monsters: false
  20.                 #除了怪物还剩啥不需要我说了吧？
  21.                 Others: true
  22.         #玩家交互事件是指的踩田
  23.         PlayerInteractEvent: true
  24.         #实体交互事件是指的踩田
  25.         EntityInteractEvent: true
  26.         #下面两个是收水放水
  27.         PlayerBucketFillEvent: true
  28.         PlayerBucketEmptyEvent: true

  30. #提示的消息
  31. msg: "&7您只能在自己的领地内破坏！"

源代码
本插件开源。
您可以访问我们的Git(/Share/ResAddon-LimitBuild) 来查看本插件源码。
这里也直接放出关于判断权限的代码，方便您使用。

  1. private boolean hasPerm(Location loc, String name) {
  2.    ClaimedResidence res = Residence.getInstance().getResidenceManager().getByLoc(loc);
  3.    return res != null ? res.getPermissions().playerHas(name, "build", true) || res.getPermissions().playerHas(name, "trusted", true) : false;
  4.                 }
