1.12.2版本 方法名字改了
注册方块时需要调用ForgeRegistries.BLOCKS.register（） ...

请使用注册事件 RegistryEvent.Register<Block> 和 RegistryEvent.Register<Item>。不要使用任何其他的方式。

  1. @Mod.EventBusSubscriber(modid = "mymodid")
  2. public final class BlockLoader {
  3.     @SubscribeEvent
  4.     public static void onBlockRegister(RegistryEvent.Register<Block> event) {
  5.         event.getRegistry().register(myBlock); // 只有一个方块的时候用这个，否则换成 registerAll
  6.     }
  7. }
