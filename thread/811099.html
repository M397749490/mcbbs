简介


可以通过自定义武器来模仿任何第一人称的

射击游戏，凭借先进的枪械技术以及高

度的可自定义性来创造属于你自己的游戏




职业【武器种类】

很用心的对照翻译
   
特色
                   ■武器商店（购买自定义的武器）
                   ■枪械种类众多：如上图
                   ■支持重载Reload
                   ■自定义武器音效
                   ■自定义合成
                   ■等等
插件安装

㈠下载插件.jar安装至服务器
㈡重启服务端即可使用。。。


教程：入门级
1.创建武器：在游戏内输入/shot get <武器名称>，创建成功后配置文件中的weapons文件夹内会生成一个文本
假如我们的名字叫做 my_little_friend，你还需要给予玩家权限 crackshot.use.my_little_friend

2.配置：打开配置文件，在第一步做完之后，weapons文件夹内会生成一个新的文本，打开它
  1. example:
  2.     Item_Information:
  3. #物品的名称，可以修改颜色
  4.         Item_Name: "&eCocoPops"
  5. #物品的种类，即为模板这里使用351:3染料
  6.         Item_Type: 351~3
  7. #物品的lore，可修改（即将鼠标放在物品上显示的内容）
  8.         Item_Lore: "&eA cluster bomb that releases|&e10 bomblets upon detonation."
  9.         Sounds_Acquired: BAT_TAKEOFF-1-1-0
  10. #删除未使用的标签：真
  11.         Remove_Unused_Tag: true
  12.     Shooting:
  13. #右键射击：启用
  14.         Right_Click_To_Shoot: true
  15.         Cancel_Right_Click_Interactions: true
  16. #射弹量（这里是手榴弹所以可以理解为一次甩出几颗手雷）
  17.         Projectile_Amount: 1
  18. #子弹种类:射出去的类型 snowball,egg,arrow,grenade,flare,fireball,witherskull,energy,splash.
  19. #分别为雪球、蛋、箭、手榴弹、耀斑、火球、骷髅、能量、飞溅。
  20. #这里是手榴弹
  21.         Projectile_Type: grenade
  22.         Projectile_Subtype: 351~3
  23. #射速
  24.         Projectile_Speed: 12
  25.         Sounds_Projectile: EAT-2-1-28,EAT-2-1-32,EAT-2-1-36
  26.         Sounds_Shoot: FIRE_IGNITE-2-0-0
复制代码
3.保存，这样一把简单的武器就制作完成


指令与权限


命令解释权限
/shot     查看插件信息
/shot list all  列出武器列表
/shot config reload   加载插件配置crackshot.reloadplugin
/shot give <user> <weapon> <amount>  给予玩家武器crackshot.give.<weapon>
/shot get <weapon> <amount>得到武器crackshot.get.<weapon>   
/shot reload        加载武器
使用<weapon>的权限crackshot.use.<weapon>
购买<weapon>的权限crackshot.buy.<weapon>
创建<weapon>商店的权限crackshot.shops.<weapon>

建议：给予玩家三条权限
crackshot.use.all
crackshot.buy.all
crackshot.shops.all
