语言文件食用方法：
下载插件本体和适合自己服务器系统版本的语言文件
运行一次ItemLoreStats，解压下载的语言文件，将language-en.yml
放进plugins文件夹的ItemLoreStats文件夹内替换即可

指令如下：

/ils - 查看全部命令
/ils version - 查询版本
/ils stats - 将物品的信息 显示到聊天界面
/ils createlore - 创建一组装备，以供测试插件使用
/ils reload - 重载插件
/ils repair - 修复物品
/ils name <文本> - 修改物品名字
/ils lore <玩家名字> <行数> <文本> - 直接修改玩家手中的物品
/ils give <玩家名字> <物品名字> - 给玩家保存的物品
/ils export <物品名字> - 将手持物品保存，以便使用指令继续某个玩家此物品

权限如下：

ils.admin - 使用全部命令的权限
ils.use.<职业> - 物品职业的限制权限

①怎么把上面的属性添加到物品上？

假如我要把钻石剑添加上50的攻击力

方法①：手持钻石剑使用lores插件输入/lore add &5攻击力:+50

方法②：手持钻石剑使用ils插件输入/ils lore 行数 &5攻击力: +50

PS:使用ils插件添加属性时例如攻击力:后面需要空格，使用lores插件添加属性时不需要空格

PS2:颜色代码可以随意使用


②如何绑定物品给玩家？

假如我要把钻石剑绑定给bear_child

方法①：手持钻石剑使用lores插件输入/lore add &6绑定给 bear_child

方法②：手持钻石剑使用ils插件输入/ils lore 行数 &6绑定给 bear_child


PS:颜色代码可以随意使用

③如何设置物品等级要求？

假如我要把钻石剑的使用等级要求设置为50

方法①：手持钻石剑使用lores插件输入/lore add &7等级要求:50

方法②：手持钻石剑使用ils插件输入/ils lore 行数 &7等级要求: 50

PS:使用ils插件绑定时绑定给:后面需要空格，使用lores插件绑定时不需要空格
PS2:颜色代码可以随意使用

④如何设置物品职业要求？

假如我要把钻石剑的使用的职业要求设置为剑客
方法①：手持钻石剑使用lores插件输入/lore add &4职业要求:剑客
方法②：手持钻石剑使用ils插件输入/ils lore 行数 &4职业要求: 剑客
想使用此剑的玩家必须拥有[ils.use.剑客]权限才能使用此物品
PS:使用ils插件绑定时绑定给:后面需要空格，使用lores插件绑定时不需要空格
PS2:颜色代码可以随意使用




⑤如何用Boss血条来显示玩家的基本信息？

安装BarAPI至plugins文件夹
用压缩软件打开
ItemLoreStats.jar并用Notepad+++打开config.yml
找到usingBarAPI:并把冒号后改为true

就会在游戏中用Boss血条显示你的生命、等级、经验值三项数据
要自定义显示出的这三项数据的名称就要在配置文件中找到
bossBar:
  splitter: " | "
  colour: "&7"
  health:
    name: "Health"
    colour: "&a"
    splitter: "/"
  level:
    enabled: true
    name: "Level"
    colour: "&e"
  exp:
    enabled: true
    name: "Exp"
    colour: "&b"
    splitter: "/"
把三个name:后面的名字分别修改即可，colour:后面是颜色!(随便你怎么改)
⑥如何让怪物掉落ils的物品？
在服务器运行一次MythicMob，打开MythicMob文件夹
创建一个**剑.yml在Mythicmob里的Items文件夹
打开**剑.yml输入以下配置
**剑:
  Id: 276
  Data: 0
  Display: '&b**剑'
  Lore:
    - '&d攻击力:+50'
    - '&d致命打击:+50%'
    - '&d剧毒攻击:+50%'
    - '&d寒冰攻击:+50%'
    - '&d凋零攻击:+50%'
    - '&f此剑十分强大'
  Enchantments:
  Options:
保存，关闭，创建一个大屌怪.yml在Mythicmob里的Mobs文件夹
打开**怪.yml输入以下配置
**怪:
  Type: PIG_ZOMBIE
  Display: '&b**怪'
  Health: 5000
  Damage:
  Skills:
  Drops:
  - **剑 1 1
  Equipment:
  Options:
保存，关闭，重置MythicMob插件【/mm reload】
进入游戏生成一个**怪【/mm m spawn **怪】
杀死它之后，掉落物品图片如下

使用这个插件遇到的一些问题以及解决办法。
1.spigot.yml关于血量的设置:
attribute:
    maxHealth:
      max: 2000000.0
    movementSpeed:
      max: 2000000.0
    attackDamage:
      max: 2000000.0
当血量设置过大的时候,例如调成2.0e7,当服务器重启之后spigot.yml关于血量设置会恢复成默认的200万，这时候如果的MM怪物血量超过了200万，那么重启后这个怪物当前血量会变成20。
解决办法：1.换个版本的ILS。2.把spigot.yml文件属性调成只读(开服会报错，spigot.ymll拒绝访问)

2.rpgitem攻击无效:
rpgitem配合ILS做RPG武器，把RPGITEM攻击调成0 （隐藏默认攻击），然后发现攻击怪物没有伤害，但是ILS的攻击伤害提示是有造成伤害的。换成MM做的武器能造成伤害，后台无报错。
解决办法：换个RPGITEM或者换个版本ILS

3.玩家被高攻击武器打死后身上装备变成两件,刷装备.
解决办法：RPGITEM与ILS版本不兼容，自行探索换版本.
