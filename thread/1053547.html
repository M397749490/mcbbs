_cnCommand_  命令/权限节点

  • /cn help 页码 ——— 查看指令帮助
  • /cn set 名称 ——— 设置自己的中文名 - cn.set
  • /cn set 名称 -t ——— 设置自己的临时中文名 - cn.set.temporarily
  • /cn setother ID 名称 ——— 设置他人的中文名 - cn.setother
  • /cn setother ID 名称 -t ——— 设置他人的临时中文名 - cn.setother.temporarily
  • /cn reset ID ——— 重置某人的中文名 - cn.reset
  • /cn reset ID -t ——— 临时重置某人的中文名 - cn.reset.temporarily
  • /cn check ID ——— 查询某人的中文名 - cn.check
  • /cn givecard ID ——— 给予某人一张改名卡 - cn.getcard
  • /cn usecard ——— 食用一张改名卡 - cn.usecard

   加上 -t 参数为临时执行 重新进入服务器即还原
   set/setother/usecard 均受到maxlength影响(请看settings.yml)
   若命令执行者金额有cn.maxlength.bypass权限 则不受影响

Q1: TP玩家是使用原ID还是中文名
A1: 仅可使用原ID

Q2:如何复原ID
A2:打开plugins/ChineseName/config.yml
找到你的ID 将那一行删掉
     你当然可以使用/cn 原ID (大雾)

Q3: 关于重名安全性问题
A3: 插件无法预防重名问题

可以使用Deluxechat等插件

在鼠标悬浮ID上显示

例如:

- '原ID: &b%player%'
- "中文名:%player_displayname%"
