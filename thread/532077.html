整合黑科技讨论室，带你走进脑洞大开之人的世界。
为了填补制作新整合时没帖子发以及没时间更新教程的空缺，于是怒开新坑，讲点关于整合时的黑科技。
本期为世界篇1，讲讲如何限制地图与传送门。

（1）Lockdown，锁定特殊地图
想让玩家只许使用你所预设的地图而不能创建新地图？Lockdown来帮你。
玩过Crashlanding或Blastoff的玩家会记得，
在创建新地图的时候没办法对地图进行任何设置但是一创建出来就是作者所预设出来的地图，
这是怎么做到的呢？这就用到了Lockdown这个mod。
下载Lockdown，丢进mods文件夹，启动一次游戏，去config文件夹中找到Lockdown.cfg，用记事本或其他方式打开可以看到以下内容：

  1. # Configuration file

  3. "main menu" {
  4.     B:"Disable Multiplayer Button"=false //是否取消多人游戏按钮
  5. }


  8. "world creation" {
  9.     B:"Disable Game Mode Button"=true //是否取消游戏模式按钮
  10.     B:"Disable More World Options Button"=true //是否取消更多世界选项按钮
  11.     B:"Disable Regular World Creation"=true //是否取消正常世界生成
  12. S:"World Template Directory"=/XXX //世界模板目录
  13. }
复制代码
前4项不多说，基本上就是FTTT，如果你希望玩家只使用预设地图的话
第五项是用来让mod读到你所预设的地图存档，XXX就是存档名
（可以改名，不要犯傻），
然后把你的预设存档直接丢进.minecraft文件夹就好了。
接下来再启动游戏看看创建新地图，就会是这个效果：

（2）RestrictedPortals，锁定传送门
不希望玩家过早进入地狱或末地，那么就从传送门上下手吧。
使用本Mod后可以在config中修改进入地狱或末地传送门的条件。
下载RestrictedPortals，丢进mods文件夹，启动一次游戏，去config文件夹中找到RestrictedPortals.cfg，用记事本或其他方式打开可以看到以下内容：
  1. # Configuration file

  3. general {
  4.     S:"Item to Unlock the End"=minecraft:ender_eye //进入末地门前需要合成过一次末影之眼
  5.     S:"Item to Unlock the Nether"=minecraft:flint_and_steel //进入地狱门前需要合成过一次打火石
  6. B:"Use keys rather than Items specified above"=false //改为合成钥匙来解锁，会覆盖上面两个
  7. }
复制代码
首先默认第三项是false，你只需要合成前两项的对应物品就能解锁然后进入地狱或末地门了。
但如果第三项改成true，就需要合成本Mod所增加的末地门或地狱门钥匙来解锁了。
末地门或地狱门钥匙的合成你可以用Minetweaker来修改
（MT大法好）。
