关于兼容性

本插件在1.7.10,1.12.2,1.15.1版本测试可用，所以理论上支持1.7.10-1.15.X,如有无法使用的版本，请带报错回复，谢谢


这个插件有啥用？
它允许每个玩家有自己独立的出生点，当然，也可以创建默认出生点

命令和权限

基础命令
/sos spawn 回到服务器默认出生点
Setownspawn.spawn

/sos ownspawn 回到自己的独立出生点
Setownspawn.ownspawn.own

/sos setspawn 设置自己的独立出生点为当前所在位置
Setownspawn.set.own

/sos delspawn 删除自己的独立出生点
Setownspawn.del.own

进阶命令
/sos ownspawn ID 传送到指定玩家的独立出生点
Setownspawn.ownspawn.others

/sos setspawn ID me 设置指定玩家独立出生点为你当前所在位置
Setownspawn.set.others.me

/sos setspawn ID self 设置指定玩家独立出生点为目标玩家当前所在位置
Setownspawn.set.others.self
[Setownspawn.others.* —— 包含Setownspawn.others.me和Setownspawn.others.self]

/sos delspawn ID 删除指定玩家的独立出生点
Setownspawn.del.others

/sos defaultspawn 或 /sos ds 设置默认出生点为你当前所在位置
Setownspawn.set.ds

/sos reload 重载插件
Setownspawn.reload

/sos 或 /sos help 显示帮助
Setownspawn.help

建议给玩家的权限
Setownspawn.spawn
Setownspawn.ownspawn.own
Setownspawn.set.own
Setownspawn.del.own
