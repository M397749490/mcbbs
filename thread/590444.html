本帖最后由 1582952890 于 2017-9-16 20:11 编辑

描述
可以将白名单数据保存在MYSQL中，并且支持UUID，当你修改你的ID后也可以进入！

指令与权限
  • /mywl add {player} - 添加一个玩家到白名单 - MySQLWhitelist.add
  • /mywl del {player} - 从白名单移除一个玩家 - MySQLWhitelist.del
  • /mywl on - 启用白名单 - MySQLWhitelist.on
  • /mywl off - 停用白名单 - MySQLWhitelist.off

配置文件
  1. #Mysql Settings
  2. host: localhost
  3. user: root
  4. password: password
  5. database: minecraft
  6. port: 3306
  7. table: mysql_whitelist

  9. #status of the whitelist
  10. enabled: true
