SGLogin2.4支持Sqlite、MySql、邮件找回密码、管理员指令、用户修改密码、邮箱找回密码、支持jdbc和c3p0两种数据库连接池、禁止某世界输入某指令、
强制用户登陆位置与登陆后传送置上次下线的位置等等！
按照大家的反馈，此插件与MOD服无冲突！
开发核心改用1.16.1

把本插件丢进Plugin中，设置好数据库用户名密码，库名什么的，插件启动时会自动生成数据表，不用自己创建（MySql）。如果你不想看这些说明和配置文件，那么你直接跑到下方的下载密码就行了，使用就是这么的简单，配置文件里也全是中文！
指令并不用记，查看时输入下面这两个就够了！
查看普通玩家指令：/sglogin help
查看管理员指令：/sglogin admin

指令：
登陆：/l 密码 或 /login 密码
注册：/reg 密码 再次输入密码 或 /register 密码 再次输入密码
密码修改：/changepassword [旧密码] [新密码] [重复新密码]
邮箱绑定：/email add [邮箱] [确定邮箱]
邮箱修改：/email [旧邮箱] [新邮箱] [重复新邮箱]
查看邮箱：/email show
忘记密码，只需在未登陆时输入：/recover [自己绑定的邮箱]
玩家默认有以上权限
管理员权限，默认OP有权限
sglogin.admin.*
sglogin.admin.password
修改用户密码：/sglogin changepassword [用户名] [新密码] [重复密码]
sglogin.admin.register

手动添加一名用户：/sglogin register [用户名] [密码] [重复密码]
sglogin.admin.remove
移除一名用户：/sglogin remove [用户名]
(移除只是删除数据库中的数据，不删除游戏数据)
重新加载配置文件：/sglogin reload

如果你在使用中遇到BUG还是新需求，都能在下方评论留言，希望大家评个分，谢谢了！

看完配置文件你肯定有点儿蒙！
具体使用是这样的：
1.先设置玩家登陆时的位置，输入/sglogin spawnset，默认就设置的是你所在的世界的位置和方向。
2.设置玩家登陆后要传送的位置，输入/sglogin before，默认就设置的是你所在的世界的位置和方向。
3.开启强制登陆位置，输入/sglogin enable true，true为开启，false为关闭
4.开启玩家登陆后传送到他上次下线所在的位置和方向，输入/sglogin tp true，true为开启，false为关闭（默认是开启的）
*1、2、3步骤不能省略，否则可能功能不正常！
和配置文件中说的一样，这个是为了加快登陆速度，原理就是因为虚空世界加载的方块非常少，所以速度快。所以说，如果你登陆和传送的是一个世界的话，真的没有必要开启此功能，而且本插件不会传送登陆世界和玩家上次登陆世界为相同的情况，比方说，你强制登陆的位置为world，而玩家上次下线的世界也是world，这样的话，只会传送到第2步，也就是你设置的位置。
这个功能如果你不懂的话，你按照我写的4个步骤试一试，效果很明显的！
