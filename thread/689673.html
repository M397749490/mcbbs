配置文件:
  1. Enable fly message: '&e&lFly >&r&b Fly mode Enable for %player%'
  2. disable fly message: '&e&lFly >&r&b Fly mode Disabled for %player%'
复制代码
   Enable fly message 为开启飞行后发送的文字
   Disable fly message 为关闭飞行后发送的文字

指令权限：
/fly #开启/关闭 飞行            权限：cmd.fly.use
