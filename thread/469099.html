最近看到 Minecraft MOD制作：从入门到精通上面的多材质方块版本过低，用了以后电(cheng)脑(xu)成功爆(bao)机(cuo)


那么我就在这里说一下怎么做1.7.10的多材质小型方块吧！
准备材料：
1、一个充满人脑洞的大脑
2、一个充满电脑洞的Eclipse（及其它做mod需要的东东）


好滴，开始做mod！
这里我以我做的生化提取机为实例（←其实这是个带Gui的方块。。。然而这个方块的Gui是用上一篇教程的方法画的）
新建类BlockBioExtracter以后其他配置不说
重要的是这个
添加成员变量：
  1. IIcon icon1;
复制代码
添加成员函数：
  1. @Override
  2.         @SideOnly(Side.CLIENT)
  3.     public IIcon getIcon(int number, int face)
  4.     {
  5.         if(number==0 || number==1)
  6.                 return icon2;
  7.         else
  8.                 return icon1;
  9.     }
  10.         
  11.         @Override
  12.         @SideOnly(Side.CLIENT)
  13.     public void registerBlockIcons(IIconRegister p_149651_1_)
  14.     {
  15.         this.icon1 = p_149651_1_.registerIcon("biomod:BioExtracter");
  16.         this.icon2 = p_149651_1_.registerIcon("biomod:BioExtracterTb");
  17.     }
复制代码


getIcon函数中：
number参数代表着方块的哪一面（0：底，1：顶，2/3/4/5分别是前后左右）
face参数代表你面朝哪一面（这里我没有用到）
registerBlockIcons就是注册方块的材质拉，使用IIconRegister.registerIcon("modid:texturename")，相信大应该可以理解


这样，多材质效果就完成了！


下面是不满格方块的效果制作：


先添加isOpaqueCube函数

  1.         public boolean isOpaqueCube()
  2.     {
  3.         return false;
  4.     }
复制代码


这个函数是用来检测方块是不是满的(true=是,false=不是)
如果不添加这个坑爹的函数，你就会发现你的方块下面带有透视效果。。。可以自己去试试
然后，在构造函数里面添加
  1. this.setBlockBounds(0.25F, 0.25F,0.25F, 0.75F, 0.75F,0.75F);
复制代码
前三个参数代表方块的坐标最小的那个点的坐标（相对于满方块的最小坐标增大多少），后三个代表最大的；

全部添加完了以后
一个（标题）的方块就制作完毕！
