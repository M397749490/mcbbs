网络测试
目前正在进行网络测试.任何非玩家控制物品如车辆，丧尸，路障，房屋，和物品，都已在服务器中停用(简单来说就是没办法用了)
我的计划是每天将一种非玩家控制(如车辆，丧尸，路障，房屋，和物品)进行优化，并且恢复使用，以达到来测试该对象对游戏性能有多大影响
如果全部优化好后，服务器性能肯定比以前要好上几倍!








原文:







Network Test
There is currently a network test going on.All non-player elements such as vehicles, zombies, barricades, structures anditems are turned off in multiplayer.
The idea is that each day one element willbe optimized and re-introduced, then analyzed to see how much it impactsperformance.
If all goes well networking should be muchbetter after everything is turned back on!
