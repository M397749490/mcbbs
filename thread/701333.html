Yum 插件简介
  • PlugMan不会用?看不懂?来试试这个插件吧!
  • 简便、快捷、多功能
Yum 插件特色
  • PlugMan的基本功能 load unload reload 都有 并且稳定!
  • 输入指令/yum del <插件名称>即可删除插件!
  • 输入指令/yum fdel <插件名称>即可删除插件包括插件文件夹!
  • 输入指令/yum list即可查看插件列表!
  • 输入指令/yum info <插件名称>即可查看插件详情!
  • 并且提供以下高级功能(注意: 高级功能仅限仓库插件)

    • 输入指令/yum repo list 即可查看可以下载的插件列表!
    • 输入指令/yum install <插件名称>即可下载插件!
    • 输入指令/yum update <插件名称>即可升级插件!

  • 提供能耗监控功能

    • 输入/mi lag 查看服务器能耗信息
    • 输入/mi event <插件名称> 查看插件事件能耗信息
