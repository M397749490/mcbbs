介绍 · Introduction
MoonWorldGenerator可以让你创建自定义的月球世界

当你用这款插件创建新世界后，请勿卸载该插件! 世界的地形是用该插件来加载的.

不要在创建新世界后修改配置，否则可能会损坏区块。但你可以编辑世界结构.已生成的结构不会改变.
环境
1. "Normal" 环境
  • 普通的天空
  • 主世界的怪物(爬行者、僵尸、骷髅等)
  • 自定义地形和树


2. "Nether" 环境
  • 地狱赤红天空
  • 地狱生物 (僵尸猪人、恶魂等)
  • 没有地狱顶部基岩
  • 自定义地形和树


3. "End" 环境
  • 末地天空
  • 末地怪物 (末影人、末影龙)
  • 没有末地岛
  • 没有黑曜石塔
  • 末影龙
  • 传送门
  • 以黑曜石为底层方块
  • 没有结构
  • 自定义地形和树


宝箱

  • 普通的箱子 - 什么都没有
  • 陷阱箱 - 打开时激活TNT

指令
  • /mwg reload - 重载配置
  • /mwg pos1 - 设置第一个选取点
  • /mwg pos2 - 设置第二个选取点
  • /mwg createstructure <名称> - 根据选区创建结构
  • /mwg editstructure <名称> - 在游戏内编辑结构
  • /mwg liststructure - 列出可用结构
  • /mwg editconfig - 在游戏内编辑配置


使用方法
下载插件并放到插件文件夹内.


Multiverse-Core
  • /mvcreate <世界名> <环境> -g MoonWorldGenerator



MultiWorld:
  • /mw create 世界名 plugin:MoonWorldGenerator
