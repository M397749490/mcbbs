什么是 DreamFish?

DreamFish 是 Myitems 作者旗下的一款增强钓鱼趣味的插件
不知道为什么站内迟迟没有人拿过来搬运? (或许是因为汉化内容太多??)
因为服务器转型 这款插件不经常用了 就把汉化一并发上来
如果有需求的朋友可以拿过去直接用 也希望大家能做出更多的鱼种

DreamFish 插件特色

钓鱼机制的改变
玩家再也不能挂机钓鱼



需要使用鱼饵才能够使用钓竿钓鱼
鱼饵可以通过商店进行购买(也可以通过钓)



完全GUI界面
轻轻松松学会插件使用方式



插件指令:

- 关于钓鱼:

/fish help [页数] - 查看帮助
/fish load [鱼名] [玩家] [数量] - 给予指定玩家指定数量的指定鱼
/fish list - 显示所有鱼
/fish menu - 打开钓鱼插件GUI面板
/fish about - 关于插件信息
/fish reload - 重载插件


- 关于鱼饵:

/bait use - 使用鱼饵(右击/自动消耗也都可以不需要写指令)
/baid load [鱼饵名] [玩家] [数量] - 给予指定玩家指定数量的指定鱼饵
/bait list - 显示所有鱼饵


插件权限:

dreamfish.admin
dreamfish.command.reload
dreamfish.command.fish.load
dreamfish.command.fish.list
dreamfish.command.bait.load
dreamfish.command.bait.list
