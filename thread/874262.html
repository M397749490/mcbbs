AJ跑酷
插件特色
1.自动生成跑酷
2.将跑酷保持在一个特定区域内
3.奖励每次跳跃
4.根据分数奖励
5.可设置每次跳跃的声音
6.完全自定义的消息
7.在操作栏中显示玩家的当前得分
8.支持MySQL和YAML存储
9.启动跑酷时的传送点
10.记录高分的玩家
11.玩家被传送时/挂机时跑酷自动结束
12.Minecraft 1.7.10-1.16.1版本兼容
13.玩家可以自己选择跑酷的方块
14.自定义每次跳跃的粒子效果和粒子数量

设置方法
                                                                           

1.你需要使用/ajParkour setup create <区域名字>创建一个区域
2.然后你需要设置区域位置使用指令/ajParkour setup pos1，/ajParkour setup pos2[例如worldedit的//pos1和//pos2],你也可以直接用worldedit选取区域，选取后用指令/ajParkour setup we
3.接着你需要选择难度，难度有easy[简单] medium[中等] hard[困难] expert[专家]和balanced[综合]              当您想要更难的跑酷时，综合模式将提高难度级别
4.你可以选择设置玩家掉落后被传送到的位置
如果未设置，则他们只会正常掉下去（但插件会防止玩家受到掉落伤害）
站在你希望他们传送到的地方输入/ajParkour setup fallpos
5.确保已设置所有必需的位置，并输入/ajParkour setup info，确保没有选项是红色的
6.如果已设置所有必需的点，然后使用/ajParkour setup save保存并启用区域

PAPI变量
                                                                           
                       
  1. %ajpk_stats_top_name_<number>%  - 排行榜上<number>名的玩家的名字
  2. %ajpk_stats_top_name_<number>_area% - 区域名 <area> 的排行榜上<number>名的玩家的名字
  3. %ajpk_stats_top_score_<number>% - 排行榜上<number>名的玩家的分数
  4. %ajpk_stats_top_score_<number>_area% - 区域名 <area> 的排行榜上<number>名的玩家的分数
  5. %ajpk_stats_highscore% - 玩家最高得分
  6. %ajpk_stats_highscore_<area>% - 在<area>区域中玩家最高的得分      
  7. %ajpk_current% - 玩家目前分数
  8. %ajpk_jumping% - 正在跑酷的玩家人数
