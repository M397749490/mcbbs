代码的协议还没想好，所以暂时All Right Reserved

github 教程(也就是介绍)

注意事项

  • 模组提供api，可供开发者使用，同样可以前往教程出查看
  • 模组自带汉化，请放心使用
  • 可以在不通知我的情况下使用本模组与整合包之中，但是不允许用于商业用途
  • 发现任何bug都可以向在github上新建issue汇报
  • 欢迎参与进来帮助我完善教程的翻译、模组的测试

更新列表
1.0.1 1.1 update:
  • 修复bug
  • 解决双铝问题：不同mod的铝矿物辞典的不同导致一个整合包有两种铝，通过互相注册铝词条解决
  • api加入了一系列新特性，尤其是支持ManaCraft1.1的匠魂插件和自动配置文件同步的注册等
  • 加入了信息卡，用于sausage core系列模组添加提示

1.2 update:
  • 修复bug，清理代码
  • 重写能源部分
  • 添加颜色类
  • 调试棒！带来的是1.13才有的NBT语法高亮！

1.3 update:
  • 修复bug，清理代码，移除了一些奇怪的东西
  • ATP系统——与生物无关

  • 强化双铝问题的解决方案——更加完备

1.4 update:
  • 修复bug，清理代码，移除了一些奇怪的东西
