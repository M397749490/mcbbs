安装了这款插件后，怪物会随机掉落一些卡牌。玩家可以通过收集卡牌来兑换奖励。


特点
卡牌

卡牌就是这款插件的核心. 默认敌对怪物有20%的机率会掉落卡牌. 卡牌就是有自定义名称和描述的一片纸. 默认包含了Minecraft原版的所有生物和一些被移除了的生物.

卡包
玩家可以购买卡包来开包获得卡牌


收藏书

收藏书可以用于存储卡牌，且只有将卡牌放入收藏书后才视为收集到了该卡牌
收藏书可能会吞掉与卡牌无关的物品

玩家可以收集卡牌来兑换奖励，当玩家收集齐同一个品质的卡牌后即可兑换奖励 旧版本不可用
其它
兼容插件Towny、MobArena、Vault

如何印卡
复制已有的卡牌并修改这些：

Series: 'Your Series Here' <- 这可以是任何东西,比如当前年份、印卡时间

Type: 'Your Type Here' <- 卡牌的类型, 如果是怪物卡, 你可以命名为Monster或是其他你想到的名字.

Has-Shiny-Version: true/false <- 该卡牌是否拥有闪光版本的卡

Info: 'Your Info Here' <- 卡牌描述. 输入 "None" 则不显示.

指令 & 权限
  1. /cards reload (cards.reload)
  2. /cards list (cards.list)
  3. /cards list <player> (cards.list.others)
  4. /cards listpacks (cards.listpacks)
  5. /cards giveaway <rarity> (cards.giveaway)
  6. /cards giverandomcard <mob> <player> (cards.giverandomcard)
  7. /cards giveboosterpack <player> <name> (cards.giveboosterpack)
  8. /cards givecard <rarity> <name> (cards.givecard)
  9. /cards getdeck <number> (cards.getdeck)
  10. /cards giveshinycard <rarity> <name> (cards.giveshinycard)
  11. /cards toggle (cards.toggle)
  12. /cards create <rarity> <name> <series> <type> <hasShiny> <info> (cards.create)
  13. /cards buy pack|(card) (<rarity>) <name> (cards.buy)
  14. /cards worth (cards.worth)
  15. /cards resolve <player> (cards.resolve)
  16. /cards reward <rarity> (cards.reward)
  17. 开包权限 - (cards.openboosterpack)
  18. 使用特定序数的收藏书 - (cards.decks.#)
