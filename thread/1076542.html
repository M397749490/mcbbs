1.15.2 原版服务端CentOS安装命令:
  1. yum install -y wget && yum update && useradd server && wget -O /home/installMC.sh https://ddos_ling.gitee.io/minecraftserver-download/1.15.2/1.15.2server.sh && sh /home/installMC.sh

1.15.2 Paper服务端CentOS安装命令:
  1. yum install -y wget && yum update && useradd server && wget -O /home/installMC.sh https://ddos_ling.gitee.io/minecraftserver-download/1.15.2/1.15.2paper.sh && sh /home/installMC.sh
复制代码
安装提醒

请在root下运行本脚本
如果提示: 用户“server”已存在 ，请直接去掉命令内的“useradd server &&”
安全警告: 为保证服务器安全，请在安装完毕后为server用户设置密码！命令：passwd server
