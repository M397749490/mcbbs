比如检测特定的萝卜柑


设立
/scoreboard objectives add used_coas stat.useItem.minecraft.carrot_on_a_stick
/scoreboard objectives add goataway dummy

获取
/give @p minecraft:minecraft:carrot_on_a_stick 1 0 {effects:["goataway"]}

手持检测, 加分处理(同t连锁、按顺序执行)
/scoreboard players tag @a remove goataway
/scoreboard players tag @a add goataway {SelectedItem:{tag:{effects:["goataway"]}}}
/scoreboard players set @a[tag=!goataway] used_coas 0
/scoreboard players add @a[score_used_coas_min=1] goataway 1
/scoreboard players set @a used_coas 0
