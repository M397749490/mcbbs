作者: 恋    时间: 2019-5-14 10:47
这个是官方服务端核心 什么都加不了的 需要一个bat就可以运行服务器
  1. @echo[/url] OFF
  2. title 1.14 纯净
  3. SET BINDIR=%~dp0
  4. CD /D "%BINDIR%"
  5. java -Xmx2G -Xms1024M -jar  minecraft_server.1.14.jar
  6. PAUSE
复制代码
