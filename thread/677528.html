PowerRanks
这是一个权限组插件
你可以为所有权限组添加前缀
你可以设置称号和名字的颜色
原文

PowerRanks is a plugin that adds ranks to your server.
For every rank you can set a prefix so other players can see what rank you have.
You can also set the ChatColor and NameColor for every rank.
Questions? Read the questions part first before asking it!






初始权限组有：Member, Vip, Moderator, Admin 和 Owner
你可以无限添加权限组




指令：

*指令权限权限用处
*/powerranks helppowerrank.cmd.help默认帮助菜单
*/powerranks check <playerName>powerrank.cmd.check默认查看玩家的权限组
*/powerranks set <playerName> <rank>powerrank.cmd.setop将玩家移入权限组
*/powerranks addperm <rank> <permission>powerrank.cmd.setop添加权限在权限组
*/powerranks delperm <rank> <permission>powerrank.cmd.setop删除权限在权限组
*/powerranks addinterance <rank> <interance>powerrank.cmd.setopAdd a interance to a rank
添加权限组继承的权限组
*/powerranks delinterance <rank> <interance>powerrank.cmd.setopRemove a interance from a rank
删除权限组继承的权限组
*/powerranks reload [config/plugin/all]powerrank.cmd.reloadop重置插件



config.yml：


  2. # 以下变量：
  3. # [rank] 权限组名字
  4. # %player% 玩家名字
  5. # %msg% 玩家发送的信息
  6. chat:
  7.     enabled: true
  8. #是否开启
  9.     format: '[rank] %player%: %msg%'
  10. #聊天格式
复制代码



Ranks.yml：


  2. Default: Member
  3. #默认权限组
  4. Groups:
  5.   Member:
  6. #权限组名称
  7.     permissions: []
  8. #权限组权限
  9.     interance: []
  10. #权限组继承的权限组
  11.     prefix: '[&aMember&r]'
  12. #前缀
  13.     chatColor: RESET
  14.     nameColor: RESET
