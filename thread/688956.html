标题: 新特性 完成“进度”自动执行指令
本帖最后由 chyx 于 2017-4-27 22:27 编辑

这个版本里 一个“进度”达成后可以按顺序执行一系列指令。
示例：
{
    "criteria": {
        "test": {
            "trigger": "location"
        }
    },
    "rewards": {
        "commands": [
            "/advancement revoke @s only chyx:chyx",
            "/say Myself: @s",
            "/setblock ~ ~ ~ redstone_block"
        ]
    }
}



这个就会在达成“进度”后运行里面的指令


不过这个“进度”的trigger是每秒检查一次的 而且必定达成。而且每次完成“进度”后都会让玩家清除自己的“进度”。
因此每秒玩家都会执行里面的指令一次。

这个可以简单的让玩家拥有无限夜视/饱和，或者让玩家进入某区域后自动给自己物品/药水效果/移动到下一关卡，而且不需要任何命令方块。

命令可以在各种事件的时候自动执行，而不需要想过去那样用一个高频时钟不停检查。

注意“进度”也可由cb来让玩家直接达成，这样也会执行里面的指令。
如果在ccb串里有这样的指令，这些在“进度”里的指令也会在下一个ccb之前全部执行完毕。
简直可以看成子程序。

而且各个“进度”里的指令们也可以互相调用。。。。要是以后的命令地图里一个命令方块都没有，我一点都不会惊讶。
