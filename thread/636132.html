前言


这插件本来是我写给我服务器用的，本来连配置文件都没有，写死在代码里，想了想加了个配置文件，然后大家一起分享吧。



功能

功能:记录在线时长，输入命令计算所得游戏币






命令与权限以及配置文件

命令:
/pm   领取签到游戏币奖励
权限:   
无
配置文件
  1. #每分钟多少游戏币
  2. money: 3
  3. #每分钟是否开启公告提示
  4. bm: true
  5. #每分钟提示什么
  6. #需要上面的开启公告提示
  7. bms: "&b服务器娘&6 >> &a又是漫长的1分钟，别忘了记得输入/pm领取在线奖励"
复制代码

那个全服公告提示的意思就是每分钟提示玩家可以领取钱。你觉得烦可以关掉。
这个插件会记录每个玩家的在线时长，当他领取完游戏币奖励又被清空时长啦~\(≧▽≦)/~
默认UTF-8格式，乱码自行转码



截图

图炸了我也没办法
公告提示，可关闭

输入/pm

这是我根据我服务器的经济清空设置的每分钟可以兑换3块钱，你们也可以直接设置

配合公民2使用更佳
