当然还有更简单的方法，就是创建一个新的末地折跃门渲染类，将上面的代码全部复制，并删除信标光柱渲染的方法，然后添加到TileEntityRendererDispatcher.renderers中。
  1. TileEntityRendererDispatcher.renderers.put(TileEntityEndGateway.class, new YourEndGatewayRenderer());

那么，这两个条件又从哪里来的呢？我们可以看到Minecraft的源代码里是这样的：
  1. public boolean isSpawning()
  2.     {
  3.         return this.age < 200L;
  4.     }

  6.     public boolean isCoolingDown()
  7.     {

  9.     }

这两个值的声明为：
  1.     private long age;
  2.     private int teleportCooldown;
