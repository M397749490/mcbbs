标题: Minecraft 基岩版 1.14.0.12 发布（仅PS4）
本帖最后由 zyjking 于 2019-12-14 20:21 编辑

Minecraft基岩版是指包括Minecraft手机版（Android、IOS）、Win10版（VR）、主机版（XboxOne、NS、PS4）在内，使用“基岩引擎”（C++语言）开发的Minecraft统一版本。

正式版是Minecraft基岩版经过一段时间的测试版测试之后得到的稳定版本，也是众多材质、Addon和官方领域服会逐渐跟进的版本。与此同时Google Play、Win10 Store等官方软件商店也会推送此次更新。

https://feedback.minecraft.net/hc/en-us/articles/360037910991

NOTE: This hotfix is currently only available only on PlayStation 4 (Version 2.00) and many of the fixes will reach other platforms in another hotfix soon.
注意：此补丁仅在PS4上可用（游戏版本2.0.0），其它平台的修复将在不久后推送另一个补丁

Fixes:
bug修复

修复了17个bug

  • Crashes / Performance
  • 崩溃/性能
    • Fixed several crashes that could occur during gameplay
    • 修复了游玩时可能发生的崩溃问题
    • Fixed several crashes that could occur when converting a world from PlayStation 4 Edition (MCPE-58594)
    • 修复了无法将旧PS4版本的存档转换为新基岩版存档的问题
    • Fixed a crash that could occur when signing into a Microsoft Account
    • 修复了无法登录微软账号的问题
    • Fixed a crash that could occur in the trial version when performing an action that would unlock a trophy
    • 修复了试用版解锁奖杯时发生的崩溃问题
    • Having many Editions worlds no longer increases startup time
    • 优化其它版本的存档加载速度

  • General
  • 常规
    • Fixed the error that would occur when pressing the 'Unlock Full Game' button in the trial version
    • 修复试用版中点击“解锁完整版”发生的崩溃问题
    • Fixed the 'Error Number 0' account error that occurred on the main menu and Store
    • 修复了在主页面和商店页面发生的“错误代码0”的账号问题（XX-XXXXX-0）

  • Gameplay
  • 游玩
    • View bobbing once again behaves correctly when facing North and South (MCPE-56214)
    • 面向正南或正北时的视角摇动动画正常了
    • Shulker Boxes with items are no longer missing from chests after converting a world from PlayStation 4 Edition (MCPE-58465)
    • 转换PS4版本存档不会再导致潜影盒消失和丢东西了
    • Fixed world conversion enabling cheats on Survival worlds (MCPE-58499)
    • 修复了转换PS4生存模式的存档会开启作弊的问题
    • Fixed some trophies unlocking for all players during a multiplayer session
    • 修复了多人游玩时会自动解锁奖杯的问题

  • Mobs
  • 怪物
    • Bees will now die after attacking (MCPE-53860)
    • 蜜蜂蜇人后会去世了

  • Graphical
  • 图形界面
    • Fixed broken textures appearing after Resource Packs are deactivated
    • 修复禁用材质包后材质仍不正常的问题
    • Fixed some Character Creator items appearing incorrectly
    • 修复某些角色创建器的东西显示不正常的问题

  • User Interface
  • 用户界面
    • Fixed an issue that caused some players not to be able to leave the Inventory screen on the Marketplace
    • 修复一些玩家无法退出市场的个人物品界面的问题
    • Fixes to Character Creator screens when scrolling with the right thumbstick
    • 修复了PS4手柄右摇杆无法上下滚动角色创建器的问题
    • Fixed placeholder text appearing on the Resource Packs and Behavior Packs screens
    • 调整材质包和行为包界面的占位符文本位置
