这次我们要讲的是在世界上生成矿物的问题
首先，要讲的是Minecraft的坑爹世界有个坑爹编号   叫  做   （~木~鱼~）  world.provider.dimensionId
world.provider.dimensionId是指世界的编号（似乎说过了）
当它的值是0时，代表着这个世界是主世界
当它的值是-1时，代表着这个世界是地狱
当它的值是1时，代表着这个世界是末地

In fact，就算你自己生成一个世界出来，也同样有一个编号！
比如，半条命mod里面的半条命世界的编号值似乎就是4（似乎而已，我没偷窥过源码，所以有待考证）

好啦，我们继续讲
有了编号，我们就能指定矿物生成在哪个世界上
既然是生成矿物，就一定要用到这个接口：IWorldGenerator
（如果你想自己麻烦的要死的去继承WorldGenerator类我也不反对，神一样的孩子，大胆去干吧！）

创建完这样两个类以后，我们就要开始正式生成矿物啦！
首先你得有一个方块（废话，没有方块你去生成啥？）+一个主类（废话，没有主类你这个mod都是不存在的）
再假想你的方块的注册在主类里，方块名为FirstOre，主类名FirstMod
再再假想你要在主世界里面创建矿物
于是，我们的OreGenerator类里面的generateSerface函数变成了这样：
  1.         @Override
  2.         protected void generateSurface(World world, Random rand, int chunkX,
  3.                         int chunkZ) {
  4.                 for(int k = 0; k <= rand.nextInt(8); k++){
  5.                 int posX = chunkX + rand.nextInt(16);
  6.                 int posY = rand.nextInt(36) + 20;
  7.                 int posZ = chunkZ + rand.nextInt(16);
  8.                
  9.                 (new WorldGenMinable(FirstMod.FirstOre, 2 + rand.nextInt(7))).generate(world, rand, posX, posY, posZ);
  10.         }
  11.                
  12.         }
复制代码
我们来解析一下这段程序：
posX和posZ那两句不要改
for(int k = 0; k <= rand.nextInt(8); k++)里面的rand.nextInt(8)，其中的8的那个位置的数字越大，矿物越多
int posY = rand.nextInt(36) + 20;里面的rand.nextInt(36)+20是指这个矿物是在高度（从基岩往上面算）20~56的范围内生成

(new WorldGenMinable(FirstMod.FirstOre, 2 + rand.nextInt(7))).generate(world, rand, posX, posY, posZ);是生成语句，2 + rand.nextInt(7)是矿物数量（应该看得懂吧）
好啦，矿物生成问题到此结束！
