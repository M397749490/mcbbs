插件特性
隐藏1.13+的命令显示


效果截图


命令
/commandsendhidden    显示当前版本信息
/commandsendhidden rl    重载


配置


  2. # 允许的匹配规则
  3. # 优先级比 denys 高
  4. allows:
  5.   # 允许以 essentials: 开头的命令显示
  6.   - '^essentials:'

  8. # 禁止的匹配规则
  9. denys:
  10.   # 拒绝任何包含 : 的命令显示(但是如果满足 allows 是会还是会显示的)
  11.   - '\:'
  12.   # 匹配全部 (拒绝显示任何命令)
  13.   - ''
  14. # 无视规则的权限
  15. bypass: commandsendhidden.bypass
复制代码

注: 采用正则表达式匹配
所以denys中如果有一项是 'a' 的话那么命令中带 a 的都不会显示



权限节点
commandsendhidden.command    允许执行 /commandsendhidden 命令
commandsendhidden.bypass        绕过检测, 这条权限可以在配置中修改
