与ichat配合使用可以变成一个简单的称号系统，下面详细描述

ichat配置文件&介绍
首先介绍一下ichat
ichat，顾名思义，是一个控制聊天格式的插件
配置文件很简单：
这是上面插件功能中介绍的配置：
handle-me: true
date-format: HH:mm:ss
message-format: '*゜+w&9[&c勇者]&f[表][+displayname]&a [里]+name+suffix&f.*: +message'
me-format: '* +name +message'
iname-format: +{wName}[+prefix+group+suffix&f] +displayname
me-permissions: false
variable-refresh: 100
如上配置中&c代表浅红色，w代表世界，&f为白色，displayname为称号，name为玩家ID，suffix为后缀，message为聊天信息

特别说明
使用该插件需要把ess设置中的
change-displayname:
改为false
然后，dispnamechanger就会完全取代ess来控制玩家名称信息
那么登陆服务器&登出服务器就会显示dispnamechanger中设置的名字
比如我设置的是膝枕达人，那么在服务器中会显示为

下线，聊天栏中也是如此
因如此聊天栏会导致不知道玩家是谁
所以就要用到ichat

修改ichat配置文件
在配置文件中，如下一栏为ichat的主要配置
message-format: '*゜+w&9[&c勇者]&f[表][+displayname]&a [里]+name+suffix&f.*: +message'
你可以任意修改这里的格式，两个不同的可被识别选项之间要用＋分开
上图格式的效果就是插件功能介绍中图片显示的聊天格式了
ichat就介绍到这里了，接下来介绍DNS插件
[spoiler]DNC相关指令

/rename 重新设定一个称号
/rename ID 称号 设定指定玩家的称号
/newname 设定一个新的称号
/reset 重置【清除】称号信息
/checkname ID 查询一个玩家的称号
/displaylist ID 查询所有在线玩家的称号
[/spoiler]

特别注意
本插件的称号是可以带空格的，不过需要 - dispname.changespace这个权限节点。

效果如图，那么如何带空格呢？
在使用/rename，/newname的时候，用""标注，如/rename "&6诹访子神游队 &c委员长"

权限节点篇-细分



- dispname.change 修改称号的权限
- dispname.changespace 修改称号时候使用空格的权限
- dispname.color 修改称号时候使用颜色的权限
- dispname.color.aqua 水绿色权限 对应&b
- dispname.color.black 黑色权限 对应&0
- dispname.color.brightgreen 明绿色权限 对应&a
- dispname.color.darkaqua 深青权限 对应&3
- dispname.color.darkblue 深蓝色权限 对应&1
- dispname.color.darkgreen 深绿色权限 对应&2
- dispname.color.darkgrey 深灰色权限 对应&8
- dispname.color.darkred 深红色权限 对应&4
- dispname.color.grey 灰色权限 对应&7
- dispname.color.indigo 槐蓝色权限 对应&9
- dispname.color.orange 橙色权限 对应&6
- dispname.color.pink 粉红色权限 对应&d
- dispname.color.purple 紫色权限 对应&5
- dispname.color.red 红色权限 对应&c
- dispname.color.style.bold 粗体权限
- dispname.color.style.italic 斜体权限
- dispname.color.style.magic 虚幻字体权限
- dispname.color.style.strike 删除线权限
- dispname.color.style.underline 下划线权限
- dispname.color.white 白色权限 对应&f
- dispname.color.yellow 黄色权限 对应&e
- dispname.changeother 修改他人称号的权限
- dispname.check 检查称号的权限
玩家默认的权限：dispname.list和dispname.check

权限节点篇-部分汇总

- dispname.color.* 使用所有字体样式的权限
- dispname.color.style.* 适用所有字体特殊样式的权限
- dispname.color.all 使用所有字体颜色的权限

关于如何在服务器中使用

—————————————————————————————————————————
适用于普通服务器：可以使用收费插件，例如pay4commands等指令收费插件，使玩家获得/rename，/newname的权限来修改称号
特别注意：示例中pay4commands需要把指令的大小写都设定收费，所以建议寻找其他更好用的收费插件，仅仅是示例
适用于战争&RPG服务器：
命令方块：
本插件可以识别服务端发出的指令，也就是说，可以使用rename @p 称号来获得称号
可以在相关任务&剧情点结束后放置能够获得此称号的命令方块机关来获得称号
Giftcard：
相关请查询bukkit.org中Giftcard插件
地址：http://dev.bukkit.org/bukkit-plugins/giftcard/
该插件可以做到通过礼品卡的形式发放物品&权限&指令【有指令当然也可以发称号啦】
其他：
其他诸多牌子-指令连接插件
GUI界面指令插件等亦可利用
