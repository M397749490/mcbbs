PS：MCBBS怎么原帖地址变必填了=。=

本插件制作完成的那一天，MCBBS炸了

于是决定分享出来

但是今天凌晨分享的时候，MCBBS又炸了

Lockette方便，但是不能防漏斗矿车，于是制作了这个插件

这个插件的功能就是，当漏斗矿车经过任意内含物品的容器时，会产生一个范围8的大爆炸（对方块无影响），并全服公告爆炸坐标。。。。。。

现在改为需要权限获得公告，如需全服公告则需要给全局boomminecart.broadcast权限，部分人获得公告则给这些人权限就行


之所以更新如此迅速是因为自己的服务器测试1.1的时候发现Lockette支持模式下对双箱无效

1.4版本非常完善了，基本上不用更新了，就此弃坑吧

  21.     public void onDisable() {

  28. class HMBOOM implements Listener  {
  29.    
  30.     private HopperMinecart entity;

  32.     private void Boom(InventoryMoveItemEvent ev){
  33.         if (ev.getDestination().getHolder() instanceof HopperMinecart) {
  34.             ev.setCancelled(true);
  35.             if (entity != (HopperMinecart) ev.getDestination().getHolder()){
  36.                 entity = (HopperMinecart) ev.getDestination().getHolder();
  37.                 double x,y,z;
  38.                 x=entity.getLocation().getX();
  39.                 y=entity.getLocation().getY();
  40.                 z=entity.getLocation().getZ();
  41.                 World world = entity.getWorld();
  42.                 List<Entity> entities = entity.getNearbyEntities(10, 10, 10);
  43.                 entity.remove();
  44.                 world.createExplosion(x,y,z,8, false,false);
  45.                 Bukkit.broadcast(
  46.                         String.format(
  47.                                 "§a[爆破小分队]§6成功炸毁一台漏斗矿车于§d【%1$s，%2$d，%3$d，%4$d】",
  48.                                 world.getName(),
