Even More Commands Than Just That!
- Commands -?
  • /Help - Displays Help Menu
  • /Help Set <LINE NUMBER> <LINE> - Set's a specified line to something new.
  • /Help Add <LINE> - Add's a entirely new line to the Help Menu
  • /Help Remove <LINE NUMBER> - Remove's the specified line from the Help Menu.
  • /Help Reset - Reset's the config to Default Settings.
  • /Help Clear - Clear's the entire help menu.
?
- Permissions -?
  • -/Help - Everyone
  • -/Help Set/Add/Remove/Reset/Clear - help.administrate



简介

这个插件可以自定义/help 菜单，就是玩家输入/help之后，看到的不是指令，而是你自定义的内容！

指令

/Help - 显示帮助菜单
/Help Set <行数> <内容> - 设置某一行帮助内容.
/Help Add <行> - 新增一行
/Help Remove <行数> - 移除一行内容.
/Help Reset - 重置所有设置.
/Help Clear - 清除整个帮助菜单.


权限

-使用/Help指令 - 默认拥有
-使用/Help Set/Add/Remove/Reset/Clear指令 - help.administrate
