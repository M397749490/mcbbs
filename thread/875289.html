你开错端了亲  是另一个  不要双击  有启动脚本的
  1. @ECHO OFF
  2. color 0A
  3. title 服务器后台
  4. SET BINDIR=%~dp0
  5. java -Xmx4096M -Xms1024M -jar Catserver.jar
  6. PAUSE
复制代码

保存为bat，放到服务端文件夹下运行即可
