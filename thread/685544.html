LobbyLeave
大厅传送插件[BungeeCord]




一、简介 Description
大厅允许玩家有 lobby leave.use 通过命令连接大厅服务器
服务器名称可以在配置中指定。



二、指令 Command
/lobby - 返回大厅
/l
/hub
/leave - 离开（回到大厅）
/quit


三、权限 Permission
lobbyleave.use - 使用权限

四、配置 Configuration
servername：你的大厅服务器名字
