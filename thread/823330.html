KLevelCommandList
作者:离人(Kuns

插件基础介绍
本插件能够让玩家到达一定等级后
触发无数条指令（可以自定义）
触发一条可开关的公告（自定义）

推荐RPG服使用
1.可以到达等级后发送公告
2.到达等级后给予称号
3.又或者传送到某个限定的宝物副本
还有其他功能，腐竹们自己发掘

插件效果截图







插件安装
直接丢进plugins文件夹即可



指令与权限
/kl reload      *重载插件
/kl set 玩家ID 等级  *给玩家设置等级
本插件无权限节点



配置文件


config
#变量只有一个：{p} == 玩家
Level:
  10级:
    #如果到了这个等级就执行指令
    level: 10
    #执行的指令
    Command:
    - "/xp 1 {p}"
    - "/xp 2 {p}"
    - "/xp 3 {p}"
    - "/xp 4 {p}"
    #执行完指令给玩家发送的话
    Message: "§a恭喜您升级到了10级"
    #全服通知
    broadcastMessage:
    #如果为true就开启并通知全服
      enble: true
      Message: "&A[全服通告]: &f恭喜玩家 &a{p} &f升级到了10级！"
  20级:
    level: 20
    Command:
    - "/xp 5 {p}"
    - "/xp 6 {p}"
    - "/xp 7 {p}"
    - "/xp 8 {p}"
    Message: "§a恭喜您升级到了20级"
    broadcastMessage:
      enble: true
      Message: "&A[全服通告]: &f恭喜玩家 &a{p} &f升级到了20级！"
  30级:
    level: 20
    Command:
    - "say 你好"
    Message: "30级"
    broadcastMessage:
      enble: true
      Message: "&A[全服通告]: &f恭喜玩家 &a{p} &f升级到了30级！"
