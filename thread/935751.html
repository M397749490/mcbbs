                                                                         功 能                                                                              

本插件可以代替服务器的锻造合成类的插件
虽然是国外人开发的,但你仅需看配置文件及/ecraft help 中的指令
便可以很快的掌握这款插件,目前许多服务器都用这款插件来做商城    ,   锻造.

本插件有付费与免费2个版本，那为什么要购买它，而不去用免费的EpicCraftings呢？
因为：

EpicCraftings :
-     支持自定义配方
-     支持合成配方权限
-     支持自定义界面
-     支持合成GUI菜单
-     完全兼容1.8-1.15
-     不支持配方分类
-    每个配方最多只能有15个材料
-    不再更新

EpicCraftingsPlus:
-     支持用GUI创建自定义配方
-     支持配方分类
-     支持合成时间
-     支持合成完成执行指令
-     支持添加随机型配方
-     支持交互物品时执行自定义命令
-     /ecraft create {配方名字} 便捷高效快速的创建配方(GUI(不用打开配置文件了)
-     /ecraft edit 便捷高效快速编辑一个配方 (GUI)
-     支持配方合成额外条件：玩家等级,SkillAPI职业,金钱,变量
-     支持配方合成成功概率
-     完全兼容NBT标签
-     完全兼容药水
-     完全兼容怪物蛋 (全版本)
-     完全兼容彩色盔甲,特殊箭矢 (1.9+)
-     完全兼容玩家头颅
-     完全兼容盾牌
-     完全兼容附魔书
-     完全兼容烟花
-     完全兼容lore/NBT属性
-     支持隐藏玩家不能的配方
-     支持合成物品的随机附魔等级
-     支持合成物品的随机lore
-     支持一次性配方
-     支持无限配方材料
-     支持配方菜单中的翻页按钮
-     完全兼容 Boss 插件
-     完全兼容1.8-1.16
-     永久更新

4.我想在合成成功时只执行指令 如何做? 空降
在SpigotMC的原贴上 作者说道
#Instead of giving an item, with this option you can execute a command to the player. You can set multiple commands by adding a ";" before the next command.
command: pex user %player% group set VIP
command: "pex user %player% group set VIP;eco give %player% 500"

所以可以这样实现:
直接在配方节点下加入
  1. command: 你要执行的指令
复制代码
这样 合成时就不会获得配方合成物 而是只执行指令了
如果你要执行多个指令的话 可以在配方节点下加入
  1. command: 你要执行的指令;第二个指令
复制代码
(注意这些指令不用带"/")

5.我想给配方添加合成冷却 怎么搞?空降

#Here you can set a cooldown in seconds for the item to craft (This means that the item will be created in 30 minutes). IT IS VERY IMPORTANT THAT YOU /DEOP YOURSELF BEFORE TESTING THIS OPTION OR YOU WILL BYPASS THE COOLDOWN.
cooldown: 1800


所以我们只需要在配方节点下添加:
  1. <font face="Tahoma">cooldown: {冷却时间(秒)}</font>
复制代码
