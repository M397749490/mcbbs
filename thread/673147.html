                             高度可定制的投票监听,这个插件有许多功能！

1.作者的原话:
This plugin is an advanced vote listener. You can see the full feature list below, some with links to wiki to explain them further. This plugin has more features than all other voting plugins out there. If you enjoy it please leave a review and if you need help feel free to contact me. If you want to support me adding more features feel free to donate.
(#这个插件是高级的投票监听器。您可以看到下面的完整功能列表，一些与wiki的链接进一步解释。这个插件有比所有其他投票插件更多的功能。如果你喜欢它，请留下评论，如果你需要帮助，请随时与我联系。如果你想支持我添加更多的功能，随时捐赠#)




2.这个插件需要的前置:

*Votifier / NuVotifier（或使用votifier事件的任何其他插件)
*Vault（可选） - 直接给钱
*Java 8
  

3.这个插件的特点:

1.给予玩家奖励投票
2.强大的奖励系统
3.其他奖励 - 给予玩家奖励可以从以下入手（配置在VotinPlugin / Rewards.yml）:
                . FirstVote - 奖励第一次投票
                . 一天内的所有网站 - 所有投票网站的投票奖励
                . 投票x投票数量（每天/周选项） - 投票x奖励次数
                . VoteParty - 服务器上的每个人（或投票的人）在x个全局投票后获得奖励
                . 里程碑 - 给玩家1次奖励投票x次数
4.累积奖励
5.VoteReminding（也支持VoteRemind）
6.查看来自播放器或服务器的总投票（/ vtotal）
7.查看上次投票的时间（/ vlast）
8.查看下一次可以投票（/ vnext）
9.查看今天投票的人（/ vtoday）
10.自定义格式
11.离线玩家投票支持
12.最高选民（每月/每周/每日最高选民奖励支持）
13.VoteForwarder - 在多个服务器上投票
14.选项卡完全支持
15.UUID支持
16.牌子
17.PlaceHolderAPI扩展
18.Player GUI（/ vote GUI，/ vote URL，/ vote Reward）
19.投票效果（声音，粒子，标题，BossBar，ActionBar，烟花）
20.记分板
21.投票点 - 可以使用VoteShop，BossShop
22.使用GUI（/ av GUI）设置/编辑游戏
23.附加组件
24.Flat file/ SQLite / MySQL支持


4.如何使用？点击此处查看基本设置指南：
1.安装插件（拖放到插件文件夹）
2.重启服务器
3.确保votifier正确设置，如在服务器获得投票 - 好的视频教程可以在这里找到
4.Now setup VoteSites /奖励：
创建VoteSites：
      手动添加到VoteSites.yml（参见其中的示例）
      创建投票，/ av gui（中间点击投票并输入名称）
设置奖励文件：
      创建/配置投票，/ av gui（中间点击奖励图标创建新的奖励文件）
      在AdvancedCore / Rewards / REWARDNAME.yml中手动创建文件
      列表奖励文件，你想要它，只是把没有.yml文件的名称（你也可以使用/ av gui在投票网站上添加它的游戏）
5.投票和测试如果一切正常，使用/ av投票做假投票
6.默认情况下，玩家将获得VotingPlugin.Player的权限（给他们主要的玩家命令）
7.其他配置请根据你的喜好
