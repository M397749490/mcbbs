Mod介绍

还在为修改Minecraft标题而发愁吗？还在为修改源文件和绕验证而绞尽脑汁吗？

想要修改服务器的游戏窗口标题，甚至将窗口标题作为您的服务器公告板吗？



如果你有以上需求，又不懂得修改源码，这个mod就是为你而准备的！

无需任何技巧，只需修改服务器配置，让所有客户端享受高度定制的标题！

更新（重要！）

1.0.1 —— 修复客户端本地游戏是导致游戏卡死或崩溃的问题


教程

本mod单机使用不会有任何效果，专为服务器设计。



在服务端运行一次后，会出现一个config文件，修改该文件即可满足您的定制需求。

需要服务端和客户端同时安装此mod，即可更换标题。


  1. # Configuration file

  3. general {
  4.     # Minimum time to change title.(Must greater than 0, in seconds)
  5.     # 最小标题更换时间
  6.     I:changeTimeLowerBound=20

  8.     # Maximum time to change title.(Must greater or equal than minimum time, in seconds)
  9.     #最大标题更换时间，实际的标题更换时间将在这两个世界组成的时间段中随机选择，二者相等即为定时更换。
  10.     I:changeTimeUpperBound=20

  12.     # Which type do you want to use? (CYCLE/RANDOM)
  13.     # 更换方式，填入CYCLE即为按顺序循环，填入RANDOM即为随机选择
  14.     S:changeType=RANDOM

  16.     # What title(s) do you want to show? (should not contains character '`')
  17.     # 您希望什么文字出现在服务器标题上？一行一个，但不能包含字符'`'（就是上方键盘1左边那个点）
  18.     S:windowTitle <
  19.         Minecraft 1.7.10
  20.         Minecraft 我的服务器
  21.         服务器Q群： 欢迎各位的到来
  22.      >
  23. }
