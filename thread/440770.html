这是一个简单的小插件,允许用户进行二段跳! 这个插件是不需要任何前置插件的,所以你不必担心需要安装其他插件!
论坛里的那几个二段跳插件装到服务器后会出现许许多多的问题，无奈之下我只好自动动手用翻译器在网上找了这个插件，我用的是spigot1.7.2-0.4的服务端测试的，没发现什么问题，比论坛里原有的那几个感觉稳定多了，所一搬过来分享给大家一起用，也是为了自己以后好查看这个插件的信息。

= = = = = = = = =配置= = = = = = = = =

message: '&6Wooossh'                 跳跃时自动显示的消息!不想显示就设置成 '' 就可以了
jumplenght: 1                                 玩家进行二段跳时候的推进力!
jumpheight: 1.0                              玩家二段跳时的高度，最低0.0 最高2.0
jumpdelay: 2                                   二段跳的冷却时间，单位是秒
jumpwithxp: false                          跳跃延迟时间是否显示在经验管的地方

= = = = = = = = =权限= = = = = = = = =
dj.jumper               (给一个玩家SuperJump)
dj.help                    (显示了插件的信息页面)
dj.reload                (重新加载插件权限)
dj.remove              (命令/ djremoveall烫发)
dj.toggle                (你doublejummp命令启用和禁用)
dj.regen                 (给一个玩家回复)
dj.blindness           (给一个玩家失明)
dj.speed                 (给一个玩家速度)
dj.jump                  (给一个玩家跳)
dj.potions              (给予所有的跳跃效果)
dj.*                       (给你的所有DoubleJump权限)
= = = = = = = = =命令= = = = = = = = =
/dj 或 /doublejump                               (显示了插件信息)
/doublejump help                                 (显示了命令)
/doublejump reload                              (重新加载配置)
/doublejump enable <player>           (启用的doublejump玩家,如果他们没有)
/doublejump disable <player>           (禁用doublejump对于一个玩家如果他们有)
/doublejump removeall                       （关闭所有玩家的二段跳效果）
