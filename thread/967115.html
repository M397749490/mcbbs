众所周知，船在冰上特别快，在蓝冰上更快。

但是一说到冰道船到底有多快，网上就众口不一了：有说30m/s的，有说80m/s的，有言之凿凿200km/h的，有说不超过40m/s的……
就连大佬李芒果（ilmango）说的都不一定对，他说是75米每秒（av22050801）。

然而问题来了，为什么我说以上数字都是错的呢？因为不论你是冰、浮冰还是蓝冰的跑道，船都有一个加速的过程，换句话说船的速度是变量，不是定值，随便跑完一段跑道然后直接速度=路程/时间得出来的数据都是错的。
  • 零.先放出结论免得太长不看
虽然说冰船的速度是变量，但是它的速度有一个最大上限，这个最大上限是定值，是可以测量得到的。
船在普通冰上的最大速度为40.00m/s，既2.0000b/gt；在蓝冰上更快，最大速度为72.526m/s，既3.6263b/gt。
可见开头所列举的各种错误数字也差的不少，只有李芒果的相对最准，差了2.2m/s。

   3.数据采集方式。
         前方高能

为了真正有效的研究出冰道船的加速规律和最大速度，我gt采集一次船的位移（x坐标）和对应的时间（单位为gt）。
然而这么丧心病狂的采集速度（一秒钟采集20次数据）绝不是玩家手动能完成的，而且玩家开船的时候不能敲指令。所以我请来了/data命令来帮忙。具体实现方式如下：
在-2 107 0 放置一个讲台方块（其实坐标是随意的），上面放一本成书（内容任意，反正也得被清除掉）
然后用循环命令方块链接若干连锁命令方块执行如下命令：
  1. <font face="微软雅黑">循环：/data modify block -2 107 0 Book.tag.pages append from entity @p[scores={Switch=1..2}] Pos[0]
  2. 连锁1：data modify block -2 107 0 Book.tag.gtTemp set value 1234567
  3. 连锁2：/execute store result block -2 107 0 Book.tag.gtTemp double -1 run scoreboard players get @p Timer
  4. 连锁3：/data modify block -2 107 0 Book.tag.pages append from block -2 107 0 Book.tag.gtTemp</font>
复制代码
这一串命令的效果是：
先将玩家的x坐标（Pos[0]）写入到书的pages列表中（list类型nbt只能存储一种类型的数据，事先清空了pages这个列表。）然后将玩家的Timer分数乘以-1，写入到书的pages列表中。如此循环直至玩家抵达终点。

由于指令方块有跳刻执行之类讨厌的特性（bug），这一串指令可以有效暴露出采集失败的数据，便于剔除。

通过这种方式，我们把整个运动过程中每一gt的位移和时间都记录在了讲台上的一本书里。
接下来对着讲台按下F3+i，这是游戏默认的热键，可以将准星对准的方块/实体的全部nbt复制到剪贴板，然后送到word文档里，用替换整理了数据格式，将其导入到matlab中。

这样我们就将全部的数据导入成为了matlab中的一个行向量（非常长）。这个行向量的名字叫做Raw，原始数据的意思。
  • 二.数据处理
然后就没有mc的事儿了。关掉mc，在matlab中执行如下指令：
  1. <font face="微软雅黑"><div>for i=1:1:Length;

  3.     k=2-mod(i,2);

将位移与速度间隔排列的Raw整理成2行，非常多列的一个矩阵。其中第一行是位移，第二行是对应的时间。
继续执行以下指令：
  1. <font face="微软雅黑">for i=1:1:(Length/2-1);
  2. Data(3,i)=Data(1,i+1)-Data(1,i);
  3. end</font>

  1. <font face="微软雅黑">for i=1:1:(Length/2-2);

a和v呈现出非常好的线性关系。换句话说，加速度是速度的一次函数。
这是一个非常重要的发现，解一个微分方程我们就可以得到v,a和x关于t的函数关系。
设a=kv+m
式中：a为加速度，单位为b·gt[sup]-2[/sup];
v为速度，单位为b·gt[sup]-1[/sup]；
k为加速系数，其绝对值称为加速比，单位为gt[sup]-2[/sup]；
m为初始加速度，单位为b·gt[sup]-2[/sup]。
将a表示为dv/dt，这就是一个非常简单的微分方程
dv/dt=kv+m
。解该微分方程可得v=m/k*(e[sup]kt[/sup]-1)，速度v对t积分得到x=-m/k*t+m/k[sup]2[/sup]*(e[sup]kt[/sup]-1)
式中：t为时间，单位为gt；
      x为位移，单位为b。
由此公示可得最大速度v[sub]m[/sub]=-m/k。x-t图渐近线为x=-m/k*t-m/k[sup]2[/sup]=v[sub]m[/sub]*t-m/k[sup]2[/sup]，这也是距离较远且时间较长时用于计算时间或者距离的简化公式。

在普通冰跑道和蓝冰跑道上分别跑一次，用上述方法测量，使用matlab的拟合工具，拟合出a与v的关系，测量出k与v的值，并计算出最大速度。如下表所示：

  • 四.更精准的测量方式
上述计算速度和加速度的方法是不够精准的，这样测量出来的k和m也有一定的误差。为了更加深入的研究冰船运动的规律，我们需要寻找更加精准的测量方式。
在我们获取的所有数据中，只有原始数据（位移和时间）的可信度是最高的。虽然v和a有误差，但是a=k*v+m的线性关系仍然是成立的。根据冰船运动的渐近线方程
x=-m/k*t-m/k[sup]2[/sup]=v[sub]m[/sub]*t-m/k[sup]2[/sup]，我们需要至少个数据来确定k和m：冰船运动的最大速度，也就是x-t渐近线的斜率，以及x-t渐近线纵截距。

那么又回到开头的问题了：怎么测量速度？

答：截取3600m跑道中最后的约1000格，用对应的位移差除以时间差。

完成这些数据的测量之后，我们有了一组新的冰道船公式。（若无说明，则单位均为b（格）和gt（游戏刻，1gt=0.05s））
蓝冰：
位移x = 3.6263 × t + 310.8117 × (e[sup]-0.01178 × t[/sup] - 1)
速度
v = 3.6263 × (1 - e[sup]-0.01178 × t[/sup])

加速度
a = -0.01178 × v +0.04311 = 0.04311 × e[sup]-0.01178 × t[/sup]



（这个很有用）船行时间近似公式t = x ÷ 72.526+ 4.2457（单位为米、秒）
普通冰：
位移x = 2.0000 × t + 90.7324 × (e[sup]-0.02180 × t[/sup] - 1)
速度
v =2.0000 × (1 - e[sup]-0.02180 × t[/sup])

加速度
a = -0.02180 × v +0.04311 = 0.04311 × e[sup]-0.02180 × t[/sup]



（这个很有用）船行时间近似公式t = x ÷ 40.000 + 2.2938（单位为米、秒）

注意：船行时间近似公式是近似公式，只适用于冰道长度比较长的情况。
普通冰道超过120格时适用，蓝冰道超过800格时适用。
  • 五.冰船运动公式的物理意义
虽然我们已经知道了冰船的最大速度，但在这些公式中仍然隐藏着不少有趣的东西。
上文已经说明，无论是什么冰道，初始加速度m都为一个定值。初始加速度相同，这意味着什么？
这代表这可以有一个恒力F恒定推动着这艘船，F给船的加速度是恒定的
0.0431070730488597
b/gt[sup]2[/sup]，而船的实际加速度与速度是一次函数，说明有另一个力f阻碍船的前进，这个阻力与船速成正比。F就是玩家划船的推动力，f就是冰道具有粘性对船的阻力！这种阻力和速度方向相反，且成正比例的运动，属于阻尼运动，那么刚才那个k它就有了一个新的名字，阻尼系数。（严格来说k的绝对值是阻尼系数）
阻尼系数表示冰道的粘滞程度，它的倒数就表示了冰道的光滑程度。
看到没有，我们为船的运动找到了一个合适而且简洁的物理模型！

MC终于讲了一回物理。来人，把牛顿的棺材板撬开。

1.这些公式有什么用？
这里我通过两道例题来简单展示一下。
例题1：Alex在下界基岩上层修建了一条长为400格的普通冰道，从冰道一端开船到另一端，需要多长时间？
解：上文中有近似公式t = x ÷ 40.000 + 2.2938（单位为米、秒）
代入x=400，t=400+40.000+2.2938=12.2938秒。

例题2：冰船在蓝冰道上前行多长时间，船速可以达到它在普通冰上的极限速度？
解：蓝冰船速度公式：
v =3.6263 × (1 - e[sup]-0.01178 × t[/sup])

普通冰的速度极限是2.0000，将v=2.0000代入公式中，化简得
e[sup]-0.01178 × t[/sup]=0.4485

两端取自然对数得-0.01178 × t = -3.1044
解得t = 263.5340 gt ≈ 264 gt = 13.3 秒。

2.还有哪些方面是可以研究的？
答：冰道船的运动不一定要限制在一条笔直的、只能沿着x或z方向的冰道上，它可以沿着斜对角线走（据说这样速度可以提升到根号2倍，有待探究）；冰道的构成也不一定是固定的，在普通冰道的两端可以有一段蓝冰，让船更快的到达最高速度，节省时间；如何让冰道船在下界不脱轨（获得绝对准确的朝向）也是一个值得研究的方向；以及通过其他方式给船加速，比如@**xyz 提到的tnt，或者更节能的粘液块……
