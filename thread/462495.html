论坛搬运帖子：传送

食物是通过方块底部有火方块就可以进行烧烤，就是图上面的那个
Food List:
  • Raw pork -> Cooked pork
  • Raw chicken -> Cooked chicken
  • Raw beef -> Roasted beef
  • Raw fish -> Cooked fish
  • Potato -> Baked potato
  • Wheat -> Bread
  • Raw salmon -> Cooked salmon [since 1.7]
  • Raw mutton -> Cooked mutton [since 1.8]
  • Raw rabbit -> Cooked rabbit [since 1.8]

矿石是通过方块底部有岩浆才可以进行烧烤
Ores & Co. List:
  • Cobblestone -> Cleanstone
  • Iron ore -> Iron ingot
  • Gold Ore -> Gold ingot
  • Sand -> Glass
  • Clay -> Bricks
  • Netherrack -> Netherbrick
  • Log -> Charcoal
  • Cactus -> Cactus green / dark green dye
  • Crashed stone brick -> Clean stone brick
  • Clay block -> Stained clay block [since 1.7]
  • Wet sponge -> Dry sponge [since 1.8]

本帖内最新版本玩家默认有烧烤的权限
Permissions
  • bbq.deny- 禁止用户烧烤
  • bbq.recipes -默认的权限,就是可以烧烤,然而这并没有什么卵用

比较旧的版本权限和最新版本有变动,请到旧帖子查看
