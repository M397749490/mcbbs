在配置文件当中把配置改为：
  1.   use-action-bar: true
  2.   #
  3.   # The text to display on the action bar.
  4.   # Available filters:
  5.   #   {combo}       - the player's current click combo
  6.   #   {class}       - the player's main class name
  7.   #   {level}       - the player's main class level
  8.   #   {exp}         - the player's main class exp
  9.   #   {expReq}      - the player's main class required experience
  10.   #   {expLeft}     - the player's main class experience until the next level
  11.   #   {health}      - the player's current health
  12.   #   {maxHealth}   - the player's max health
  13.   #   {mana}        - the player's current mana
  14.   #   {maxMana}     - the player's max mana
  15.   #   {name}        - the name of the player
  16.   #   {attr}        - the player's attribute points
  17.   #   {sp}          - the player's main class skill points
  18.   #   {value:<key>} - a skill value
  19.   action-bar-text: '{combo}-{class}-{level}-{exp}-{expLeft}-{attr}'
复制代码
