论坛里有很多类似于多世界限制类插件，可以看得出很多人需要，但是由于开发人员的技术良莠不齐，造成用户体验不是很好，我将这些功能进行整合，但并未抄袭他人代码，有兴趣的可以反编译看看，希望大家能够喜欢

注：本插件编译环境为OpenJDK1.8可能在部分Java版本加载失败
ps:我自认为这个插件的源码写的相对规范(大神勿喷)，所以我将在第二次更新时附赠源码供新手学习

WorldLimiter —— 你想要的插件
简介
此插件可以方便的单独设置每个世界的规则，比如禁止破坏，禁止飞行，禁止说话等内容

多世界限制功能列表
以下是已经完成的功能
多世界飞行限制
多世界放置限制
多世界破坏限制
多世界指令限制
多世界说话限制
多世界漏斗限制
待完成
多世界使用限制
欢迎大家留言提交更多的限制功能

指令
就一个指令
/worldlimiter reload 重载插件

图片
想不出来应该放哪个测试图，不如去看下面的配置文件吧

配置文件
  1. ###########################
  2. # 世界限制 作者:糖果群组插件组
  3. ###########################

  5. #飞行限制
  6. fly:
  7.    #是否开启
  8.    enable: true
  9.    #拥有此权限可以不受限制(@请改为需要增加权限的世界)
  10.    #例如拥有worldlimiter.world,fly权限的玩家不受world世界的飞行限制
  11.    permission: 'worldlimiter.@.fly'
  12.    #需要禁止飞行的世界(无法防止作弊飞行)
  13.    worlds:
  14.    - CannotFlyWorld
  15.    
  16. #放置限制
  17. build:
  18.    #是否开启
  19.    enable: true
  20.    #拥有此权限可以不受限制(@请改为需要增加权限的世界,#请改为方块ID，如果为*表示所有方块)
  21.    #例如拥有worldlimiter.world.build.1权限的玩家不受world世界的限制，可以放置ID为1的石头
  22.    permission: 'worldlimiter.@.build.#'
  23.    #需要禁止放置方块的世界
  24.    worlds:
  25.    - CannotBuildWorld
  26.    
  27. #破坏限制
  28. break:
  29.    #是否开启
  30.    enable: true
  31.    #拥有此权限可以不受限制(@请改为需要增加权限的世界)
  32.    #例如拥有worldlimiter.world.break权限的玩家不受world世界的限制
  33.    permission: 'worldlimiter.@.break'
  34.    #需要禁止破坏方块的世界
  35.    worlds:
  36.    - CannotBreakWorld
  37.    
  38. #指令限制
  39. command:
  40.    #是否开启
  41.    enable: true
  42.    #拥有此权限可以不受限制(@请改为需要增加权限的世界,#请改为不需要限制的指令，如果所有改成*)
  43.    #例如拥有worldlimiter.world.fly权限的玩家可以在world世界使用fly指令
  44.    #而拥有worldlimiter.world.*权限的玩家可以再world世界使用任何被限制的指令
  45.    permission: 'worldlimiter.@.cmd.#'
  46.    #需要限制指令的世界(此配置文件与上文不完全一致)
  47.    #worlds下面的格式为 世界名[指令1,指令2,指令3]
  48.    #例子 world[tpaccept,money] 表示在world世界不能使用/tpaccept和/money开头的指令
  49.    #格式里面的符号均为英文符号，例如逗号为英文逗号，不会打的复制这个 —— ,
  50.    #最后一个指令不需要加逗号[tpaccept,money]
  51.    worlds:
  52.    - CannotBreakWorld[tpaccept,money]
  53.    
  54. #漏斗限制
  55. hopper:
  56.    #是否开启(开启后指定世界的漏斗将失去作用)
  57.    enable: true
  58.    #需要禁止漏斗使用的世界
  59.    worlds:
  60.    - CannotUseHopperWorld
  61.    
  62. #说话限制
  63. chat:  
  64.    #是否开启
  65.    enable: true
  66.    #拥有此权限可以不受限制(@请改为需要增加权限的世界)
  67.    permission: 'worldlimiter.@.chat'
  68.    #需要禁止说话的世界
  69.    worlds:
  70.    - CannotUseHopperWorld
  71.    
  72. #以下是语言文件
  73. langs:
  74.    cannotfly: '&c你无法在这个世界飞行'
  75.    cannotplaceblock: '&c你无法在这个世界放置此方块'
  76.    cannotbreakblock: '&c你无法在这个世界破坏此方块'
  77.    cannotusecommand: '&c你无法在这个世界使用此指令'
  78.    cannotchat: '&c你不能在这个世界讲话'
