ValidityPeriod——有效期插件

2.0版本发布！！！

Author:HundunStar bioBean

From:Unknown Domain 未知之域小组
From:BioStarry 生化星空小组
From:TAS 上古之石美工工作组
不多说了看效果

首先
先准备好
一把かわいいの明光闪闪的铁剑

然后，输入指令！/vp create 1d3s
这里的1d3s代表一天零三秒
具体看指令列表

然后你的铁剑就变成了这样

成功设置了1天0时0分3秒的有效期对不对？

然后我愉快的一挥铁剑（想必玩家挥铁剑的时候肯定是不愉快的）
开始计时啦！

然后当到期以后，我再次一挥铁剑
（别告诉我你拿着铁剑永远不挥，这有和没有没啥区别）

铁剑不见啦！

指令列表：
/vp help  获取指令列表

/vp create <有效期>  设置有效期
说明一下
有效期是这样子的
标准格式xdxhxmxs，其中x是正整数
不过你可以在xd、xh、xm、xs中任取任意项，然后写到有效期中
如：/vp create 1d3s
/vp create 2h4m6s
记住一定要按顺序哟！不能什么4s6m的出现，报错了不怪我哟！

/vp remove  删除物品有效期

权限：
vp.create  可以使用 /vp create
vp.remove  可以使用 /vp remove
