[---效果图---]
第一次进入服务器显示
以后进入服务器显示

安装方法
                                                1.丢入插件文件夹
                                                                                     2.重启
                                                3.修改配置，完成

配置文件

#看不懂
onlynewplayers: false
usebungee: false
#对新玩家的提示
new:
  title: "第一行内容"
  subtitle: "第二行内容""
returning:
#对所有老玩家提示
  title: "第一行内容"
  subtitle: "第二行内容"!"
#烟花效果配置
durations:
  fadein: 20
  stay: 30
  fadeout: 20
firework:
  enabled: true
  type: BALL_LARGE
  color:
  - 255,0,0
  - 0,255,0
  - 0,0,255
  flicker: true
  trail: false
  distancefromplayer: 0
