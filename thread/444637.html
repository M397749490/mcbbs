前言

珠宝工艺2 是一个魔法向的模组，你可以制作一些实用的饰品并佩戴它们
饰品这种东西当然少不了强化，不同的强化材料能够给你带来不同的效果
作者本来是打算对珠宝工艺做一次较大的更新，但后来发现更新的东西太多了
索性直接做成了一个全新的mod. 尽管Mod已经发布了多个稳定版本
作者还是将本mod视为一个WIP mod. 用作者原话就是
" The base is there, but there is so much more stuff that i want to add
which is why this mod is currently in alpha in my heart."
(基础虽然已经打好了, 但是我还有太多的东西想要添加进去
这也是为什么这个mod目前在我心中还处于alpha版本)

Mod介绍

本模组自带饰品存放栏，所以不必担心会占用原版物品栏
同时本模组也自带一本介绍手册, 但是目前介绍部分主要为英文
如果对自己英文水平有自信的话, 以下介绍就不需要再看了, 手册均有介绍

先上图好了








详细介绍
方块
1. 暗影矿石：极为罕见的一种矿石，会在Y轴坐标5~8之间生成，需要钻石镐挖掘

2. 暗影方块：9块暗影锭合成. 天色越暗，它的透明度越高
当夜晚降临时，它会变为完全透明的

3. 熔炼坩埚：熔炼坩埚是你制作饰品制作所需要的第一个方块
它能够将矿石或金属锭熔炼成熔融金属，进而用于制作各类饰品
手持矿物或其他金属锭右击坩埚即可放入其中并开始熔炼(不需要燃料!)
空手Shift+右击会取出放入的物品

4. 模具台：模具台对于制作首饰极为关键. 但在使用它之前你首先需要将模具放入其中
只需简单的右键就能将模具放入，空手Shift+右击会取出模具
然后你就可以左键将熔炼坩埚中的熔融金属倒入其中
左键模具台便可取出冷却后的首饰或金属锭
需要注意的是你必须将模具台放在熔炼坩埚的正前方，不然它是不会起作用的

5. 珠宝合成台：你可以在这个合成台上为你的首饰添加宝石(注：珠宝合成台无GUI)
手持首饰右击合成台将首饰放入，同样，手持宝石右击会放入宝石
在手册中你会找到所有能够放入宝石的列表
空手Shift+右击会退回物品，合成过程中左键能够查看合成进度
合成完毕左键取出首饰. 你可以重新为首饰镶嵌宝石
只需将旧的首饰与新的宝石放入合成台即可, 有50%退换旧宝石

6. 展示台：用于储存单一物品, 数量上限约等于无限. 它会显示出内部储存物品的3D模型
并会尝试显示包括名字, 数量, 伤害, 耐久等属性. 手持物品右键它会储存物品
左键取出一组，Shift+左键取出一个物品. 注：有动画的哟~

7. 石手基座：这个拥有神秘形状的方块是用于仪式搭建的

8. 诅咒之眼：同样被用于仪式的搭建, 当物品摆放完毕后
右键诅咒之眼激活仪式

物品
1. 珠宝工艺2手册：就是我前面说的指导手册，包含了几乎mod里所有的内容

2. 暗影锭：将暗影矿石在熔炼坩埚中熔炼后获取，为合成材料

3. 神偷护手(很好玩)： 手持神偷护手Shift+右击能够偷取奸商村民的东西
当然前提是你需要先右键村民打开他GUI一次
而且是有成功率的, 一不小心被别的村民发现就不好了

4. 粘土模具：烧炼后可获取真正的模具, 一共五种
对应四种首饰和金属锭模具

5. 模具：放在模具台制作对应首饰或金属锭

6. 首饰：终于到了最为重要的部分......
制作需要熔炼坩埚, 模具台以及模具, 具体做法前文已经说得很详细了
佩戴的首饰是可以在外表显示出来的




7. 水晶：各种颜色都有，目前的作用仅仅是与首饰结合让首饰更好看一点
未来会有更多用处

8. 各种液态桶：没什么用处，就是空桶右击熔融坩埚会装一桶液体, 再次右击倒回去

9. 珠宝强化石(创造)：就是用来作弊的, 开创造能够快速实现首饰的强化
右键打开GUI，至于怎么用，打开GUI相信你很快就学会了

掉落
1. 心：新添加的怪物掉落物，一共四种颜色
红色心：踩上去的时候治疗一个心, 满血无效
蓝色心：踩上去会给你一颗额外心, 当受到伤害时会首先被消耗掉, 不会恢复
黑色心：同蓝心有着相同作用, 同时当你拥有黑心时, 你周围的怪物会受到持续伤害
白色心：会为你提供一点点保护, 第一次踩上去会给予你半颗神圣之心, 当第二次的时候
半颗心消失, 并给予你一颗额外的心(永久)

2. 半心：同满心作用相同, 只不过效果变为半颗心

你所见到的所有心会在左下角显示出来

仪式
仪式用于强化你的首饰，搭建过程在手册中有详细介绍, 手册中将整个仪式分成了五层
一层一层垒上去就可以了. 当完成仪式的搭建后, 将首饰放进中间的基座中
然后在周围的基座中放入随意数量的强化材料, 之后右键诅咒之眼进行仪式激活
当仪式完成后, Shift+右键取出强化后的首饰, 请确保所有强化材料均被消耗后再取下首饰
强化材料
强化材料能够为你的首饰添加不同属性. 需要注意的是，每种强化材料在提供正面属性的同时, 也会附带一个负面属性. 因此需要玩家对属性进行取舍

1. 烈焰粉：
耳环：当玩家燃烧或在岩浆中时有几率治疗玩家； 减少玩家一半水下氧气量, 并加倍氧气消耗
项链：玩家不会燃烧；在水中时玩家受到半颗心/tick 的持续伤害
戒指：玩家空手攻击的怪物会受到燃烧伤害
手镯：允许玩家能够站立在火焰上并且能够在岩浆上行走；玩家在水中游泳速度降低

2. 羽毛
耳环：弓箭只有33%的概率射中玩家；但是射中后的伤害加倍
项链：玩家有25%的概率免疫掉伤害；燃烧及岩浆伤害加倍
戒指：正在攻击你的怪物有几率被眩晕；玩家造成的伤害减半
手镯：玩家下降很慢并忽视摔落伤害；玩家走得更慢

3. 末影之眼
耳环：除非直视末影人, 否则他们不会攻击你；当你直视末影人时会获得负面buff
项链：玩家会被指引向末影传送门；当玩家攻击时玩家会获得致盲buff
戒指：有几率被指向附近矿物；玩家视野减少
手镯：玩家在末地移动速度增快；玩家会有随机概率被传送到随机地点...

4. 末影珍珠
耳环：末影珍珠会随机传送你；用来打怪物会产生燃烧效果？
项链：攻击者会受到等同于玩家所受到的伤害的伤害；玩家会变的更脆弱
戒指：玩家攻击的怪物会被随机传送；玩家对于末影人的伤害减少
手镯：如果玩家在低于3颗心时受到伤害, 玩家会被传送至出生点；玩家接触到水后会被随机传送

5. 黑曜石
耳环：掉落的铁砧和弓箭无法对其造成伤害；当一定数量的弓箭或铁砧砸到你后, 下一次的铁砧下落会直接砸死你
项链：玩家将拥有双倍的防御；玩家在水中会缓慢受到伤害并且无法游泳
戒指：玩家攻击伤害翻倍；在攻击一段时间后攻击速度会减慢, 伤害也会降低
手镯：玩忽视摔落伤害；当玩家摔落多次之后会开始受到伤害, 并且移动速度降低
诅咒
会有以下三种方式获取诅咒点数
1. 偷村民东西失败(被抓到)
2. 在仪式基座上没有任何东西的情况下激活仪式
3. 丧心病狂的攻击中立生物
诅咒会伴随你直到死亡. 重生后旧的诅咒会消失, 但会有一个随机的新诅咒伴随着你

诅咒一共有十种，各位慢慢试吧，有惊喜哦~~
