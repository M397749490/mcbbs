作者: 栗子.    时间: 2019-8-8 11:26

（我是基岩版原版找出来的，大概放在<资源包>.zip\textures\lang 里面吧）


你可以在材质包内添加.lang文件，并且把其中的“item.record_<唱片名>.desc=”后面的文字更改为你想要的
例如

  1. item.record_11.desc=Sainkho Namtchylak - lost river #
  2. item.record_13.desc=C418 - 13 #
  3. item.record_blocks.desc=C418 - blocks #
  4. item.record_cat.desc=S.H.E - 波斯猫 #
  5. item.record_chirp.desc=C418 - chirp #
  6. item.record_far.desc=C418 - far #
  7. item.record_mall.desc=C418 - mall #
  8. item.record_mellohi.desc=C418 - mellohi #
  9. item.record.name=音乐唱片 #
  10. item.record_stal.desc=C418 - stal #
  11. item.record_strad.desc=C418 - strad #
  12. item.record_wait.desc=C418 - wait #
  13. item.record_ward.desc=C418 - ward #
复制代码
