储存单元
你的另外一个背包



插件介绍
他能干什么？
他可以把你某些占用空间的东西放到背包里面
他是一个可以携带的！并且以末影箱的方式保存在背包
他的储存上限为java的最大数量
并且可以单独世界禁用
禁止某些物品储存
当然普通的末影箱并不是背包
背包的合成也是可以修改的
具体下面说

插件的命令以及配置文件
命令：
/dsu help 插件命令查看 目前我还没有汉化这部分 后续会汉化的
/dsu reload 重载插件
/dsu give xx 1 给予XX玩家一个背包
/dsu allow ID 让玩家可以查看单元
/dsu remove 取消玩家查看单元

权限
dsu.dsu 使用权限
dsu.allow /dsu allow 使用权限
dsu.remove /dsu remove 权限
dsu.interface.interaction 这个权限我没弄懂
op权限
dsu.give 给玩家储存单元权限
dsu.reload 重载插件权限
