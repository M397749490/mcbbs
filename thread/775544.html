MythicMobsExtension

介绍
本插件通过API链接到mythicmobs，可以给你的mythicmobs插件添加60多种机制、50多种条件和10多个目标

开发版支持1.13 请前往Jenkins下载
新版本的插件现由BerndiVader维护 https://github.com/BerndiVader/MythicMobsExtension
新版请前往Github下载：https://github.com/BerndiVader/MythicMobsExtension/releases

必要前置

至少4.1以上版本的mythicmobs
4.1版本的mythicmobs支持1.8和1.9

本插件是否兼容不确认 你可以尝试一下
非必要前置

一些机制需要用到HolographicDisplays

一些技能支持Faction

部分技能支持worldguard

配置

配置文件为一些开关,基本不需要更改
  1. Configuration:
  2.   # DO NOT edit the version number
  3.   Version: 1
  4.   Debug: false
  5.   Update_Notification: true
  6.   Patches:
  7.     NaN_Patch: true
  8.   Modules:
  9.     Mythic_Players: true
  10.     Mythic_Thiefs: true
  11.     Cached_Owners: true
  12.   Entities:
  13.     Mythic_Parrot: true
  14.   Compatibility:
  15.     Worldguard: true
  16.     Factions: true
  17.     RPGItems: true
  18.     MobArena: true
  19.     Holographic_Displays: true
复制代码
配置描述

  • Version: 不要改变版本信息
  • Debug: 开启调试日志, 位于 .../MythicMobsExtension/log/
  • *调试暂不可用*
  • UpdateNotification: 插件更新提醒
  • NaN_Patch: 开关NaN Patch
  • Mythic_Players: 开关Mythic Players模块
  • Mythic_Thiefs: 开关Mythic Thiefs模块
  • Cached_Owners: 开关setcachedowner机械的 Cached Owners 模块
  • Mythic_Parrot: 开关自定义实体 mythic_parrot
  • Compatibility: 开关其他插件支持
