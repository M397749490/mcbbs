简介
MazeGenerato
   是一个可以直接帮你制作出一个完美的迷宫而且不会延迟你的服务器             而且生成的速度非常快，迷宫的建筑也非常整齐的插件经测试
1.7.2完美运行，作者暂时没有更新其他版本 待更新


v0.1特性
更好的生成,不会延迟你的服务器在生成大迷宫。组块创建迷宫的每秒的速度快

配置
默认配置:
# MazeGenerator V1.0 By Dablakbandit
# Currently Empty due to everything done inside the plugin,
# When features are added, they will to the config

[diamond_axe]使用与创造方法
1：下载插件放在plugins里面，运行服务器
2：使用多世界 创造一个超平坦地形 2：你可以打算直接生成
3：然后找一个中间点 打下面指令 迷宫将创造你中间

指令
/maze create <args>                                     迷宫创造加下面参数
Available args:                                                            参数
B:<Block>                          墙的方块【要物品英文，不能物品ID，下面有物品英文】
W:<Width>                       迷宫面积【面积是4变形的】
P:<Passage_Width>         通道宽度【这个应该好理解 建议1或2】
H:<Height>                              高度【一般5】
R:<Roof_Block>                屋顶方块【要物品英文，不能物品ID，下面有物品英文】要V2.0版本
F:<Floor_Block>                地板方块【要物品英文，不能物品ID，下面有物品英文】要V2.0版本
N:<Name_Of_Maze>

[diamond_sword]指令演示
注意红色字可以改变
/maze create B:Stone W:40 P:1 H:5 R:Glowstone F:Grass N:123
意思创造一个墙面为石头 面积为40 通道宽度为1 高度为5 屋顶为萤石 地板为草方块 名字为123的迷宫
现在暂时不能换地板和屋顶 待v2.0版本

[minecart_track]权限
mazegenerator 创造迷宫

[diamond_helmet]方块英文
点击查看
注意！要用(minecraft:英文)这种英文 所表示的才可以用
