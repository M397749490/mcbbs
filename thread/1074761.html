前言：
      鉴于linux（centOS/debian/ubuntu）相较于Windows server系统来说，无可视化操作让系统的资源使用率提高，但是由于全指令操作，对于架设服务器有一定难度。MCDR（作者Fallen_Breath）是一个非常好用的外挂服务端工具，基于python环境，它可以基于原版vanila、fabric、spigot等等服务端对服务器进行外挂，QuckBackup、stathelper等等插件都十分的好用。此贴将会一步一步从头开始，交大家如何在linux系统中架设一个MCDR外挂的原版服务器。

首先放出MCDR github链接:https://github.com/Fallen-Breath/MCDReforged & MCDR插件资源:https://github.com/TISUnion

三. MCDR架设
     1. python3安装
            由于大多数 linux 系统预装的 python 版本均为 python2，但是MCDR是基于 python3 的环境编译的，所以我们第一步需要自行安装 python3 环境
         1.1 安装依赖环境
  1. yum install zlib-devel bzip2 bzip2-devel readline-devel sqlite sqlite-devel openssl-devel xz xz-devel libffi-devel
复制代码
       1.2 下载 python3
  1. wget http://npm.taobao.org/mirrors/python/3.8.0/Python-3.8.0.tgz（这里使用国内镜像源，也可以去官网自行下载安装并上传至VPS服务器）
复制代码
         1.3 解压对应压缩包
  1. tar -xzf Python-3.8.0.tgz
复制代码
         1.4 在 /usr/local 下创建文件夹——python3
  1. mkdir /usr/local/python3
复制代码
         1.5 编译与安装
             （1）进入解压文件路径
  1. cd Python-3.8.0
复制代码
             （2）生成makefire文件
  1. ./configure --prefix=/usr/local/python3
复制代码
             （3）操作makefire文件并安装
  1. make
  2. make install
复制代码
         1.6 配置 python3
             （1）备份旧 python 与 pip
  1. mv /usr/bin/python /usr/bin/python2_backup
  2. mv /usr/bin/pip /usr/bin/pip2_backup
复制代码
             （2）修改软链接
  1. ln -s /usr/local/python3/bin/python3 /usr/bin/python
  2. ln -s /usr/local/python3/bin/pip3 /usr/bin/pip
复制代码
             （3）检查是否生效
  1. python -V
  2. pip -V
复制代码
         1.7 修改 yum 配置
               由于修改了 python 的版本，会导致依赖于旧版本的程序出现错误，如 yum，请对如下文件做修改
  1. vim /usr/bin/yum
复制代码
               将 #!/usr/bin/python 修改为 #!/usr/bin/python2.7（我这里改为2.7的原因是本机预装的旧版本为python2.7，各位可以去 /usr/bin 文件夹下查看自身旧版本配置）
  1. vim /usr/libexec/urlgrabber-ext-down
