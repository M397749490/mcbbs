类型构造器

在Scala中，可以用类型作为[ruby=Type Constructor]类型构造器[/ruby]的[ruby=Type Parameter]类型参数[/ruby]来构造新的类型，也能以其他类型构造器作为类型参数。语法如下例所示：
  1. class Identity[T](value: T)
  2. class Product[A, B](left: A, right B)
  3. trait Functor[F[_]]
复制代码
类型参数可以指定[ruby=Upper Bounds]上界[/ruby]（<:）和[ruby=Lower Bounds]下界[/ruby]（>:）来限定其范围。如果没有指定其上界或下界，则Any为其上界，Nothing为其下界。语法如下例所示：
  1. trait Foo[T >: Nothing <: Any]
  2. trait Foo[T <: AnyRef]
  3. trait Foo[T >: Null]
  4. trait Foo[T, U]
复制代码
类型参数还可以指定其是否[ruby=Covariant]协变[/ruby]（+）或[ruby=Contravariant]逆变[/ruby]（-），如果没有指定其是否可以协变或逆变，则默认是[ruby=Invariant]不变[/ruby]的。粗略来说传出一个值的位置是协变位置，传入一个值的位置是逆变位置。当协变逆变与上界下界一起使用的时候情况情况可能会变得很复杂，在没有必要的情况下建议减少协变、逆变、上界、下界的使用，以免引入不必要的复杂性。语法如下例所示：
  1. trait List[+T]
  2. trait Map[K, +V]
  3. trait Func[-T, +R]

参数化类型

通过类型构造器构造的类型叫做参数化类型。对于所有类型参数T，需要符合其对应的上界U、下界L，类型T需要有（L <: T <: U）的子类型关系。参数化类型与其同一类型构造器构造的其他参数化类型的子类型关系较为复杂，跟其类型参数是协变还是逆变有关，一般而言对于类型B <: A，以及参数化类型P[T]：
  • 如果类型参数T是不变的，则P[A]和P[B]没有子类型关系
  • 如果类型参数T是协变的，则P[B] <: P[A]
  • 如果类型参数T是逆变的，则P[A] <: P[B]

类型的类型

对于一般的类型而言，在任意情况下都可以作为一个值的类型出现。然而，类型构造器本身虽然是类型，但是却不能作为值的类型的，需要其他的类型作为参数，才能成为值的类型。因此，我们需要讨论类型本身的类型，一般而言将类型称作Type，而将类型的类型称作Kind。例如：
  • 对于[ruby=Proper Type]普通类型[/ruby]，例如String，其Kind是[ruby=Zero Order]零阶[/ruby]的，写作：*
  • 对于类型参数为“一个普通类型”的类型构造器，例如List[T]，其Kind是[ruby=First Order]一阶[/ruby]的，可以看作是以类型作为参数并返回一个类型的函数，写作：* -> *
  • 对于类型参数为“两个普通类型”的类型构造器，例如Map[K, V]，其Kind是一阶的，写作：* -> * -> *
  • 对于类型参数为“一个类型参数为普通类型的类型构造器”的类型构造器，例如Functor[F[_]]，其Kind是[ruby=Second Order]二阶[/ruby]的，就跟高阶函数一样，这里也叫做[ruby=Higher Kinded Type]高阶类型[/ruby]，写作：(* -> *) -> *
Scala的Kind并不多，基本上是[ruby=Untyped]无类型[/ruby]的。粗略来说忽略掉协变、逆变、上界、下界，只有（*）以及（->）可以构造Kind。在Scala REPL中可以通过（:type）指令查看值的类型，使用（:kind）指令查看类型的类型。
