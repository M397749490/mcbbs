十字弓擁有更加好的射程以及有更大的傷害
十字弓擁有不同的箭既種類
例如黑耀石箭 鑽石箭 玻璃箭 火箭 TNT箭 鐵箭 石箭 金箭 木箭等等
而當中唔同箭有不同既功能
火箭可以燒著所有生物
玻璃箭雖然只可以用一次 但是造成更大既傷害
http://www.youtube.com/watch?v=dtevAs-fIx8&feature=player_embedded

--------------------------------------------------------------華麗分隔線---------------------------------------------------
安裝:
Client:
Hard Way
1. Place ModLoader and ModLoaderMp into the minecraft.jar file   
將Modloader及ModloaderMP放進Minecraft.jar CrossbowsV2.3.zip (163.66 KB, 下载次数: 1656)
2012-5-18 23:06 上传
点击文件名下载附件



2. Place the files from the "place in jar file" folder into minecraft.jar   
解壓rar然後將"place in jar file" 入面的东西放入minecraft.jar


3. DELETE META-INF!
4. Play!
