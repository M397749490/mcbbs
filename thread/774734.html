特殊保存
这是在论坛发布的第二个插件贴啦！距离上一个发布的帖子已经过去差不多一年多了
话不多说，步入正题！
这款插件的作用： 各位服主在制作服务器的过程中有没有遇过下面的问题？
比如目前RPG服务器的某武器兑换材料是钻石，但是呢，有些不平衡的地方想把钻石改成绿宝石
这时候怎么做？有的服主使用村民插件去兑换等等...但是这种办法比较难用
毕竟不是每个玩家天天都在线或者看公告的，就会造成很多玩家找服主问
“为什么兑换不了武器了！”
这时候，这款插件就发挥出自己的用处啦！当你把兑换材料保存一份在插件中
即使是mm的物品，只需要轻轻重新设置一遍
玩家上线，或者进行活动的时候就会更新背包内的物品！这时候是不是减少了很多工作量呢！
只需要一句命令！

这个插件不是只能修改材质！是全部同步，比如你现在保存了普通的钻石，想修改名字
那么全服玩家拥有过该钻石的背包都会变成你修改的名字，如果你修改了lore，那么lore也会
nbt也一样！！！不是只能变换材质！


实用方法
指令篇:

ssit create 编号                      创建一个保存项目
ssit set 编号                 设定一个保存项目的物品
ssit list                         显示所有已经保存的项目
ssit give 编号                         给予某项目的物品
ssit delete 编号                                删除某项目
ssit reload                                          重载插件
ssit update            更新目前在线所有玩家的物品

Ps: 注意，上面的命令显示在游戏中不一定是这样显示
只会显示根据当前输入命令的人的权限进行显示
比如控制台就不能执行也不会显示ssit set这条命令，而op拥有全部显示和执行的权限
而普通玩家则全部没有

具体食用步骤篇:

首先创建一个项目,譬如test
【指令: ssit create test】
然后手上拿一个需要保存的物品,输入命令进行保存
【指令: ssit set test】
现在已经完成了！你可以把物品给予玩家或者进行某种方式流出去
最后,如果你想更新这个项目
只需要拿新的东西再输入一遍命令
【指令: ssit set test】
那么如果配置文件已经配置了的话，全服玩家就会自动更新了
如果没有配置，觉得会卡顿服务器，那么也可以手动更新
【指令: ssit update】

常见问题

Q: 这个插件到底有什么用？什么叫做同步？
A:
同步的意思就是说，你把一个物品在我插件做了一个标记
然后你修改了这个物品，然后插件会检查所有玩家的背包或手中物品【看你配置】
进行重新设置

Q: 如果同步了,那数量会同步吗？比如钻石变成绿宝石？
A:
会同步，比如你现在保存的是名字叫“超级钻石”的物品，并且a玩家拥有30个
比如你修改成“超级绿宝石”的物品，那么该玩家的背包也会变成“超级绿宝石”30个
【该玩家指的是所有玩家】

Q: 那你在物品身上做的标记\标识是什么？靠什么识别出来不同的保存物品项？
A:
靠的是NBT，我在你保存的时候对物品添加了一条nbt
不会修改物品的name和lore，这样的话大部分插件都可以认为物品并没有被改变

Q: 为什么模组服务器不能进行同步更新？
A:
个人技术问题，没有办法找到模组端对应的NBT类，如果后续找到的话会进行更新！
