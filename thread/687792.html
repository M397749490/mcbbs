　　这款插件最初只是我的另一款插件（SimpleOnlineTime）的商店功能，但是随着开发能力的提升，我把插件做的可扩展性越来越强，以至于曾经的“商店功能”如今已经成为了一款独立的菜单插件，反客为主，之前的那款插件也成为了本菜单插件的一款附属。
　　SimpleMenu拥有简单的设计结构、可扩展的API、高效的执行效率，但是相应的，这个插件的功能无法做到（可能是永远无法做到）像DeluxMenu那样强大。
　　因为Simple系列插件的设计原则永远都是：用户优先 和 最简单。

V1.1.1-Release 更新公告：
  - 修复造成非1.11版本按钮无法正常触发的严重Bug，务必在更新时用压缩包内的两个文件覆盖旧的同名文件
  - 这应该是最后一版对模块的API进行大改动的版本
  - 重构条件的载入部分，新增条件的缓存，现在同类型的条件可以分开写成很多条了。
  - 新增菜单打开的权限，具体详见下发菜单的配置文件示例


模块 更新公告：
  - 因为对API的大改动，所有模块都需要更新。
  - 内置的基础模块（BasicRequirement）更新至V1.2.0，请删除旧的模块，插件会创建新版本，或是手动从下方下载并替换旧版本
  - 新增在线时间所需的模块，请配合插件SimpleOnlineTime使用

插件用途：
　　如题目所言，这是一款菜单插件，提供了自定义菜单的功能和几个基础的按钮“点击条件”。面向开发者，插件提供了简单的API，可以非常简单的编写自己想要的“点击条件”，甚至不需要太多的Java知识，你只需要会使用IDE、编译为Jar文件即可。在结尾我会说明如何开发"条件" : )

  2. 标题: '&e&l菜单1'
  3. #打开这个箱子需要的权限，只可以写一条权限
  4. #如果没有这一项则默认只有管理员可以打开
  5. #'无'表示任何人都可以打开。
  6. 打开权限: '无'
  7. 按钮:
  8.   #这是商品的标识ID，同一页面之间不可以重复，用来记录购买行为等，不可使用中文，一旦确定请不要轻易改动。
  9.   item1:
  10.     #在商店栏中的坐标，X为1-9,Y为1-6
  11.     X: 1
  12.     Y: 1
  13.     #图标请填写物品ID，如果有子ID，则格式为：主ID|子ID 数量；如果没有子ID，则格式为：主ID 数量
  14.     图标: 35|4 1
  15.     名称: '&6按钮1'
  16.     Lore:
  17.       - '&a第一行'
  18.       - '&b第二行'
  19.       - '&6需求：拥有权限perm1.asd'
  20.       - '&6需求：支付金钱100'
  21.       - '&6需求：支付2绿色羊毛'
  22.     #图标是否有附魔光泽，如果物品图标本身就有附魔效果（例如附魔书），请不要开启。默认为true
  23.     附魔光泽: true
  24.     #满足条件的玩家点击才有效
  25.     #通用格式为：条件;条件内容
  26.     #现在支持如下的条件：
  27.     #无，即不检查任何条件
  28.     #权限：拥有权限
  29.       #格式为：条件;第一条权限;第二条权限;..更多权限...
  30.     #Vault：拥有Vault金钱、拥有并支付Vault金钱
  31.       #格式为：条件;金钱数量（可以是小数，前提是经济插件支持）
  32.     #物品：拥有物品、拥有并支付物品；
  33.       #物品格式为：主ID|子ID|数量|名称，其中名称填“无”（不含引号）适用于没有名称的物品，颜色符号使用§；
  34.       #格式为：条件;物品1;物品2;物品3;...更多物品...
  35.     #注意区分条件的大小写，一定要和上方列出的完全一致
  36.     条件:
  37.       - 拥有权限;perm1.asd
  38.       - 拥有并支付Vault金钱;100
  39.       - 拥有并支付物品;35|5|2|无
  40.     #格式为 执行者;指令
  41.     #执行者可以为：SELF OP CONSOLE 分别对应：玩家自己 以OP身份 控制台
  42.     #变量%player%为当前玩家
  43.     #添加条数不限
  44.     #无，即不检查任何条件
  45.     执行指令:
  46.       - SELF;say 这是第一条指令
  47.       - OP;say 我是%player%，这是第二条指令，以OP权限执行
  48.       - CONSOLE;say 你好，%player%，这是第三条指令，控制台执行
  49.     #如果你想点击按钮以打开其他界面（可以是其他任何插件的），那么请把这项设置为false
  50.     点击后关闭: true
