把默认世界的组配置文件分到别的世界去
作者: MiorOvkCheung    时间: 2014-2-6 01:52
本帖最后由 MiorOvkCheung 于 2014-2-6 01:53 编辑

先打开权限插件的配置文件夹，config.yml内的

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups

这一段，把你需要切换的世界名称加进去~

例如：（我需要切换到的世界名称为PEworld）

        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
          PEworld:
          - users
          - groups
