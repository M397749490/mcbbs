SimpleHP - 血量管理

这是一个轻量的血量管理插件
它可以用一个指令查看/设置玩家的血量

----------------------Commands / 指令---------------------
-----------English / 英文-----------
1. /simplehp
- Show your HP to yourself
2. /simplehp <see> <PlayerName>
- Show <PlayerName>'s HP to you!
3. /simplehp <set> [PlayerName] <HP>
- Set <PlayerName>'s HP to <HP>.
4. /simplehp <add> [PlayerName] <HP>
- Add <HP> to <PlayerName>.

-----------Chinese / 中文----------
1. /simplehp
- 查看您现在的血量
2. /simplehp <see> <玩家ID>
- 查看<玩家ID>的血量.
3. /simplehp <set> [玩家ID] <血量>
- 把<玩家ID>的血量设置为<血量>.
4. /simplehp <add> [玩家ID] <血量>
- 给<玩家ID>加<血量>

----------------------Installing / 安装插件----------------------
-----------English / 英文----------
1. Place this plugin file (SimpleHP.jar) to the "plugins" folder.
2. Start/restart the server or use Plugman to load this plugin.
3. Replace the config.yml in SimpleHP folder with the config.yml in "EnglishConfigFile" folder.
4. Restart the server or use Plugman to reload this plugin.
5. Done!

-----------Chinese / 中文-----------
1. 把这个插件放到plugins文件夹内
2. 重启/启动服务器或用YUM加载插件
3. 完成!
