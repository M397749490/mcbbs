你是不是觉得地狱太过单调，除了地狱要塞就没什么可以探索的了呢？ （没有装任何改变地狱的MOD） 你是不是曾想  过在地狱有地牢呢？


你只要装了这个MOD，以上问题，都可以解决（实现）~~~
介绍：

这个MOD使地狱会生成地牢，让探索地狱变得更加有趣。config文件可以设置生成地牢的频率，默认是8
每个地牢都会含有两个箱子。你能从地牢的箱子中获得：某个 刷怪蛋（罕见），火（制作链甲的材料）（罕见），颜料等。
地牢中的刷怪箱，多是岩浆怪，僵尸。也有别的，很少见。




原文：

For Minecraft 1.7.2 with MinecraftForge installed.A simple mod to add overworld style dungeons to the nether, to make exploring the nether slightly more interesting. Config file to change how often it tries to place a dungeon, default is 8 times.Will contain up to 2 loot chests, and a spawner for either Skeletons (rare), Blazes (rare), Magma Slimes or Zombie Pigmen. Walls are Nether Brick and Nether Brick Fence, floor is Nether Brick with the odd Quartz block.
