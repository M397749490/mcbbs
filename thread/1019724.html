Wind——为服务器添加风的机制!

wind加入了风的元素(风速、风向及其造成的影响),让Mc更符合现实,适用于大多生存服/末日生存服

搬运认证:



     功能介绍


  • 8种船新风的机制(稍后会在下面列出),包含龙卷风、暴风雪等
  • 高自定义 你可以通过配置文件对其大多机制进行修改和设置
  • 可自行修改算法公式决定风速和风向
  • 可全面控制不同天气的影响以及会在那种风速下运行





     风的效果


1.游戏中加入粒子效果以显示风向


2.加入了龙卷风天气,它将会卷起并抛出方块/实体.虽然少见，但是破坏力极大!


3.加入了吹动方块的机制,在特定的风速下方块会被风带动(根据方块的抗爆能力)

因此请尽量采用石砖等抗爆能力高的方块建造屋顶从而避免房屋受到破坏!

【图中是为了凸显插件效果而设置,实际上默认的风吹效果没那么强】


4.在风的影响下,会令雪层堆积更加严重!


5.风向将影响玩家的鞘翅速度,当你顺风飞行时会加速,逆风则减速


6.在风吹影响下，会导致部分生物的移动


7.风向将会对火势蔓延造成一定能影响


8.如果你顺风奔跑可能会摔倒

9.在沙漠旅行时，你将有机会遇到沙尘暴!





     指令



  • /wind                                                        —— 查看风向和风速
  • /wind help                                                 —— 查看插件帮助
  • /wind set <speed/direction> <数值>           —— 设置风向或风速
  • /wind tornado （大小）                              —— 生成一个龙卷风在你准星所指的位置
  • /wind trip （玩家ID）                                 —— 让自己/某个玩家摔倒
  • /wind update                                             —— 按照配置文件的指定算法更新风速和风向
  • /wind reload                                              —— 重载插件



     权限



  • wind.wind                     —— 有权输入指令/wind
  • wind.help                      —— 有权输入指令/wind help
  • wind.set.speed               —— 有权输入指令/wind set speed 来设置风速
  • wind.set.direction           —— 有权输入指令/wind set direction 来设置风向
  • wind.tornado                  —— 有权输入指令/wind tornado 来创建龙卷风
  • wind.trip                        —— 有权输入指令/wind trip 让自己摔倒
  • wind.trip.others              —— 有权输入指令/wind trip (玩家ID） 让其他玩家摔倒
  • wind.reload                    —— 有权输入指令/wind reload 来重载插件
  • wind.update                   —— 有权输入指令/wind update 来刷新风速与风向
  • wind.effect.elytra            —— 让玩家会受到风的影响而令鞘翅改变速度(建议给玩家的权限)
  • wind.effect.trip               —— 让玩家会受到风的影响而摔倒(建议给玩家的权限)
  • wind.effect.particles        —— 让玩家可以看到风的粒子效果(建议给玩家的权限)

      插件关联等事项


WorldGuard:

如果你安装了WorldGuard插件请通过将flag中的 wind-damage设置为deny来防止风的影响。而默认情况下区域的保护将会禁用风的影响， 如果你想要在全局（除了区域外）启用风的影响，则需要在全局的flag设置中将wind-damage改为allow。

PlaceholderAPI:

如果你的服务器有PlaceholderAPI,你便可以使用以下变量：

%wind_speed_short% —— 以两位数字显示风速

%wind_speed% —— 完整地显示风速

%wind_direction_short% —— 以两位数字显示风向

%wind_direction% —— 完整地显示风向

GriefPrevention 及 Lands:

      

       当你安装了GriefPrevention 或 Lands 插件时，受到插件保护的区域将不会受到与风相关的破坏方块的影响。
