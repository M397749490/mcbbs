★ 简介 Introduction
你可以收藏这个帖子以获得更及时的更新消息
该Mod添加了一个趴下匍匐前进的按键（默认：C），使得玩家可以无需使用其它什么方块对自己进行挤压就能通过1格高的空隙。
1.1.0之后版本还添加了一个用于切换趴下状态的按键（默认不会占用其它键）
1.2.0之后版本添加了服务端配置允许/禁止玩家在某些情况下进入趴下状态（配置文件可以在“世界名/serverconfig/goprone-server.toml”中找到）
默认配置：
· 允许在飞行时使用（双脚离地时）
· 骑着其它实体时禁止使用（例如：🐎、🐖、矿车、船等），但配置文件也有一个白名单，你可以按照这个格式（例如：minecraft:boat，把船添加进白名单）把实体的注册ID添加进白名单免受这个配置的限制
原文：
Just adds a keybind (default "C") which sets the player to the crawling pose, allowing them to sneak through 1-block high gaps, without needing to squash something on top of them.

Version 1.1.0 onwards also adds a second keybind (not bound to anything by default) which allows you to toggle being prone.

Version 1.2.0 onwards has server side config options to allow/deny players going prone in certain scenarios (can be found in <world save>/serverconfig/goprone-server.toml).
Config defaults to:

Allow during flight (player not on ground).
Deny while riding another entity (horse, pig, minecart, boat etc.). It also has an exceptions list. Any entities listed by their registry name (e.g. "minecraft:boat") will invert the rule.
