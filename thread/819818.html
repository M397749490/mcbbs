沒有data@@

在 datapacks 下建立一个文件夹（名字随意），里面创建一个文件叫做 pack.mcmeta，内容写
  1. {"pack_format":4,"description":""}
复制代码

在这个文件夹里面再创建一个叫 data 的文件夹，里面创建一个叫 minecraft 的文件夹，再在里面创建一个叫 functions 的文件夹，在 functions 里面创建个文件叫做 foo.mcfunction
  1. execute as @e[type=minecraft:trident] run data merge entity @s {life:233}
复制代码

回到上一级 minecraft 文件夹，在里面创建 tags 文件夹，里面创建 functions 文件夹，在里面创建 tick.json
  1. {"values":["minecraft:foo"]}
复制代码

进入服务器，输入 /reload 命令，至此三叉戟将永远不会自动消失。

有NoSpawnChunks这个插件的情况下，找到
[世界名称]/datapacks/[数据包名称]/data/[命名空间（自己新建文件夹命名）]/functions
这个文件夹，新建
[函数名称].mcfunction
打开来，输入
  1. execute as @e[type=trident] run data merge entity @s {life:0s}
复制代码

然后新建
[世界名称]/datapacks/[数据包名称]/data/[命名空间]/tags/functions/tick.json
输入
  1.     {
  2.             "replace": false,
  3.             "values": [
  4.                                         "命名空间:函数名称"
  5.             ]
  6.     }
复制代码

之后保存
