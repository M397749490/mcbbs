将一些旧版MC指令带回新版Minecraft (如切换gamemode) 与一些指令的简化版

可用旧版更改游戏模式指令
/gamemode sp     设置玩家的游戏模式为旁观模式
/gamemode 0      设置玩家的游戏模式为生存模式
/gamemode 1      设置玩家的游戏模式为创造模式
/gamemode 2      设置玩家的游戏模式为冒险模式

/toggledownfall    切换天气

可用旧版更改难度
/difficulty 1          将优先度设置为简单
/difficulty 0          将优先度设置为和平

可用简化指令
/gm c                  设置玩家的游戏模式为创造模式
/gm 0                  设置玩家的游戏模式为生存模式
/gmc                   设置玩家的游戏模式为创造模式
/gms                   设置玩家的游戏模式为生存模式

/kill                     杀死自己，无需输入玩家名称

/defaultgamemode 1
/defaultgamemode s
/dgm c
/dgm s
设置加入世界的玩家的初始游戏模式

/xps <amount[L]>
增加指定玩家的经验值
用法：/xps <数量> <玩家名>  ，数量后加字母L可以增加指定等级

/modeify                   更改所有玩家的游戏模式
