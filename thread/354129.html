觉得输入命令来看排行榜太麻烦？

So......你需要这个HolographicScoreboard

全息触摸显示计分板

事先说明：本插件需要前置插件HolographicDisplays和ProtocolLib
HolographicDisplays论坛内地址:http://www.mcbbs.net/thread-260010-1-1.html

先上图:图片较大慎入！
命令:
          /hgs list ——查看已有计分板列表
          /hgs create <名字> <刷新时间> <player/console[玩家执行还是后台执行]> <命令>
create命令注意事项：刷新时间后面必须跟着时间单位：秒-s，分钟-m，小时-h.命令和后台输入一样,免掉一个斜杠。
          /hgs move <名字> ——把这个计分板移到你现在的位置[刷新后就会到你设置的位置]
          /hgs remove <名字> ——移除这个计分板
          /hgs reload ——重新载入插件配置
          /hgs save ——保存所有计分板
          /hgs cleanup ——清除所有计分板
          /hgs refresh <名字> ——刷新这个计分板
