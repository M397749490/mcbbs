这是一个手榴弹插件，可以搞出各种各样的手榴弹，有tnt手雷，有隐形手雷，万箭穿心,甚至还有诅咒手雷，冰魄寒光弹之类的多达十几种......
一共有这么几种
Grenade Types
  • classic  一般手雷
  • smokebomb   隐形
  • gluebomb    蜘蛛网阵地
  • pineapple    万箭穿心，把你射成菠萝（好多刺啊）
  • napalm    火焰弹，不解释
  • icicle   缓慢阵地炸弹，减缓你的速度！
  • teardrop (water)    水弹
  • jackhammer  震地锤

    New as of v2.0:
  • pester  我不知道这是什么
  • zapper  好多好多蝙蝠，别人弓箭打不进去
  • decay    僵尸的诅咒，谁走到手雷旁边就是死

用法：/fg.give <玩家> <手雷英文名字> [数量

权限：使用手雷
  • fg.classic: true
  • fg.smokebomb: true
  • fg.gluebomb: true
  • fg.pineapple: true
  • fg.icicle: true
  • fg.teardrop: true
  • fg.napalm: true
  • fg.jackhammer: true
  • fg.pester: true
  • fg.zapper: true
  • fg.decay: true
  • fg.give:op

左键发射
可以在配置文件中修改是否破坏地形
