Restrict Creative
What is this plugin able to do?/这个插件有啥鸟用？
---This plugin marks the items from creative and restrict them for most of events.
--这个插件可以标记物品并限制他们的大多处时间 比如放置 破坏 交互？
Which commands are integrated?/这个插件包含哪些命令？
--Haha nice joke, there aren`t any commands, but there are some
--哈哈这是个玩笑，没有任何命令，但有一些绕过插件的命令
效果图

permissions/权限
restrictcreative.bypass.drop绕过限制
restrictcreative.bypass.brake绕过破坏
restrictcreative.bypass.rename 绕过重命名
restrictcreative.bypass.chest绕过检测
config
RestrictInventoryPut: true
UpdaterChecker: true
[建议关掉以避免不必要的麻烦]
Debug: false
BaseDataEnable: false
username: root
host: localhost
port: 3306
database: restrictcreative
password: password
table: marks

支持
-YAML
-MySQL
BUG
一些mod的工作台或容器可能会绕过插件的检测
