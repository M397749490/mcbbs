UniversalMarket
前言
UniversalMarket
原文：
A MySQL/SQLite based Item Market system powered by Sponge. Intended to replace Global Market from Bukkit/Spigot

翻译：
      这是一个为Sponge服务端打造的用数据库存储数据的基础货物托管商店，目的是为了填补Sponge服务端没有GlobalMarket插件的空白。

什么是UniversalMarket？
      用过Bukkit的腐竹大多都记得GlobalMarket对吧，那是一款支持玩家自助挂售商品的托管商贸插件，本插件是Sponge版的GlobalMarket，使用此插件能够让您的玩家自助创建寄售式商店，此插件有很多灵活的配置可以实现自定义。

关于SpongeAPI？
      这款插件是基于API5.2和API7.1构建的，所以理论上支持1.10.2-1.12.2。

安装方法
  • 下载本插件的最新版本
  • 将本插件放置在您的mods文件夹下
  • 开启服务器
相关指令
  • /um - 打开UI界面
  • /um a [价格] [可选的|数量] - 挂售手中道具
权限
  • com.xwaffle.universalmarket.open - 打开通用市场GUI
  • com.xwaffle.universalmarket.add - 使用指令挂售手中道具
  • com.xwaffle.universalmarket.remove - 移除玩家挂售的商品的权限
配置相关
Database {
    database-name=market
    ip="1.127.0.0"
    password=password
    port="3306"
    # Use a SQL server that's not saved to a file.
    use-external=false
    username=admin
}
Market {
    # 玩家不能挂售在环球市场上的黑名单列表
    blacklist=[]
    # 玩家挂售的商品是否会过期
    enable-market-expire=true
    # 作为挂售商品的手续费
    market-price=1000
    # 成交商品所需上缴的税率
    market-tax=0.2
    # 是否启用按 market-price 标准收费
    pay-to-sell=false
    # 以价格为基数，尝试上架商品是否收取税费
    tax-to-sell=false
    # 默认1天 / 24 小时。以毫秒为单位
    time-market-expires=604800000
    # 一个玩家在同一时间能上架几件商品
    total-items-player-can-sell=10
    # 您可以通过给予权限来定义指定玩家可上架的最大上线。例如：'com.xwaffle.universalmarket.addmax.3'允许玩家同时挂售三件商品
    use-permissions-to-sell=false
}
