每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。
Minecraft 1.13 仍未发布，17w47b为其第7个预览版。
转载本贴时须要注明原作者以及本帖地址。

   
Minecraft 快照 17w47b            
Java版 1.13 的快照

17w47b的更改
  • Lots of bug fixes! But don't worry, this is still an unstable snapshot. :)
  • 修了一堆漏洞，不过别怕，这还是个不稳定的快照噢：）
  • Fixed bug MC-121630 - Shift-Clicking Destroy Item button doesn't clear inventory
  • 按下shift再点清除物品按钮不会清空背包
  • Fixed bug MC-121701 - Pressing escape when sleeping in bed doesn't exit the bed
  • 睡觉时按ESC不会起床
  • Fixed bug MC-122140 - Server list broken
  • 服务器列表坏了
  • Fixed bug MC-122142 - "powered" blockstate is named "powerered" for all trapdoors
  • 活板门的方块状态"powered"写成了"powerered"
  • Fixed bug MC-122143 - Recipe for cut sandstone returns chiseled sandstone
  • 平滑砂岩的配方会返回錾制砂岩
  • Fixed bug MC-122145 - Non-colored terracotta is still named "minecraft:hardened_clay"
  • 未染色的陶瓦依旧被命名为"minecraft:hardened_clay"（硬化粘土）
  • Fixed bug MC-122147 - Acacia fence, fence gate and pressure plate are stored after dark oak ones in Creative inventory
  • 金合欢栅栏、栅栏门和压力板在创造模式物品栏中排在深色橡木之后
  • Fixed bug MC-122163 - Double plants drop their item twice when the support block is destroyed
  • 大型植物在支撑方块被破坏后会掉落物品两次
  • Fixed bug MC-122165 - Sticky pistons destroy their head when retracted (displays particles and plays sound)
  • 粘性活塞在回缩时会破坏掉活塞头部（显示粒子并播放声音）
  • Fixed bug MC-122175 - Not-full-block's particles are very laggy
  • 非完全方块的粒子效果很慢
  • Fixed bug MC-122178 - Two high flowers spawning in place of two high grass in new worlds
  • 新世界生成高草丛的地方都生成了大型花
  • Fixed bug MC-122180 - Uncarved Pumpkins create Jack-o-Lanterns
  • 可以用没雕刻过的南瓜制作南瓜灯
  • Fixed bug MC-122186 - Throwing item stacks causes only one item to appear
  • 丢出一堆物品只显示一个物品
  • Fixed bug MC-122191 - Natural generated sand and gravel do not update
  • 自然生存的沙子和沙砾不会更新
  • Fixed bug MC-122192 - Noteblock always places as powered=true until given a block update
  • 音符盒总是会以powered=true的状态被放置，直到方块获得更新
  • Fixed bug MC-122193 - Trapdoors, doors, and fence gates make no sound and open when shift-clicking them with a block that you cannot place
  • 对活板门，门还有栅栏门在手持方块并按住shift点击时，活板门不出声且会打开，方块无法放置
  • Fixed bug MC-122203 - Any saved toolbars and spawn eggs aren't affected by upgrade paths, saved items removed
  • 所有保存的工具栏和刷怪蛋在升级路径时不受影响，造成保存的物品被移除
  • Fixed bug MC-122207 - With the new IDs, some advancements icons show the wrong block/item
  • 在使用新ID后，一些进度的图标呈现错误的方块/物品
  • Fixed bug MC-122217 - Unlocalized strings on the second customizing page of world type "Customized"
  • “自定义”世界的第二个自定义页上的字符串无法本地化
  • Fixed bug MC-122228 - Opening a double (trapped) chest plays the open and close sound twice
  • 打开大陷阱箱会播放两次打开和关闭的声音
  • Fixed bug MC-122233 - Spruce, birch, jungle, acacia, and dark oak trapdoors cannot be crafted
  • 松树、白桦、丛林木、金合欢木和深色橡木的活板门无法合成
  • Fixed bug MC-122235 - Nether portal blocks do not generate correctly
  • 下界传送门方块生成出错
  • Fixed bug MC-122242 - Shulker box doesn't display the block behind.
  • 潜影盒不会显示其背后的方块
  • Fixed bug MC-122255 - Changed piston behaviour towards Marker-true armor stands in 17w47a
  • 活塞在17w47a对marker盔甲架的行为发生了改变
  • Fixed bug MC-122264 - Creating floating piston heads with redstone blocks
  • 用红石块造出了浮空活塞头

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要vpn。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验快照版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
