脚本方块Plus   脚本方块
可用的三种<交互方式>：点击interact 踩上walk 挖掉break
、

  • /sbp <交互方式> create [脚本内容]       创建脚本方块
  • /sbp <交互方式> add [新的脚本内容]      添加脚本内容
  • /sbp <交互方式> remove                        移除脚本方块
/sbwalk create @bypass /指令
/sbinteract create @bypass /指令
