FarmProtect

概述:
你是否遇过以下情况？
1.不小心一跳，就踩坏了耕地
2.被熊孩子恶意踩坏耕地
3.动物、怪物在田里跳来跳去，踩坏了耕地
那么，今天就是你的幸运日！你发现了一款轻量级保护耕地的插件，FarmProtect！
这是一款轻量级的插件，它可以保护你的耕地不被玩家，动物，怪物踩坏。



关于插件更新(检查更UpdateChecking/自动更新AutoUpdating)
插件是默认开启自动检查更新/自动更新的，这意味着插件会自己连接到dev.bukkit.com检查插件是否有新版本，如果有新版本，插件会自动下载并更新。如果你想关掉，可以在config.yml关闭。


插件配置文件

# 是否开启多世界支持
MultiWorld: true
# 要开启保护的世界
Worlds:
- world
# 是否开启自动检查更新
UpdateCheck: true
# 是否开启自动更新
AutoUpdate: true




插件指令

(/farmprotect可用/fp代替)

/farmprotect reload - 重新加载配置文件
/farmprotect toggle - 切换多世界的支持
/farmprotect add <world> - 增加要保护耕地的世界
/farmprotect remove <world> - 删除要保护耕地的世界



插件权限
farmprotect.reload  允许使用/farmprotect reload命令
farmprotect.multiworld.toggle  允许使用/farmprotect toggle命令
farmprotect.addworld  允许使用/farmprotect add命令
farmprotect.removeworld 允许使用/farmprotect remove命令

已知问题

目前，已经发现展示框保护插件(FrameProtect)
的指令/fp会与耕地保护插件(FarmProtect)的/fp指令冲突，执行/fp指令时候会优先执行展示框保护插件的/fp指令。

解决办法①:使用指令全称/farmprotect

解决办法②(推荐):在展示框保护插件的comfig.yml更改使用的命令

如:
version: 2
language: zh_CN
command: fpt
prefix:§e展示框保护 §7>>> §6
(请不要在意前缀，可随意修改)
我改的是/fpt，你也可以改成别的
