介绍 · Introduction
NPC Police 可以优化你的服务器的审判系统. 这款插件提供了成型的监狱系统、NPC警察、交互系统、悬赏和越狱**.
由于该系列插件翻译难度较大，故省略了原帖的一些废话
特点 · Features
  • 多级基础设置.
    • 服务器 (Config.yml)、世界、区域、监狱和每个NPC的设置
  • 自定义悬赏
    • 基于玩家造成的伤害、杀死NPC、玩家和越狱数设置悬赏
    • 基于状态增加悬赏, (被通缉、被监狱、已越狱、监禁中)
  • 根据时间变动悬赏
  • 自定义消息系统
    • 基于活动距离或监狱限制消息提醒
    • 设置消息延迟
  • 设置保护的NPC、区域
  • 使NPC只攻击他们看到的东西
    • 自定义视野系统可以让NPC透过玻璃、铁砧、冰块等物品看到玩家.
  • 可在逮捕玩家后没收玩家物品，并且有多种返还物品的方式.
    • 可配置禁用的物品，被逮捕后这些物品无法被返还.
  • 自定义大多数事件的指令
    • 全服或分世界:
      • NPC 警告、,警觉的守卫、警觉中(范围内没有守卫)、NPC杀手、玩家状态 (被通缉、被逮捕、已逃脱、已释放)
    • 分监狱
      • 被逮捕、已逃脱、已释放

  • 可自定义每个监狱的
    • 监狱名
    • 多个牢房地点
    • 悬赏
      • 越狱的↑
      • 在监狱内的↑
    • 在监狱内PVP的伤害悬赏
  • 这个系统拓展了其他插件的功能
    • Worldguard (更多可用标志)
      • 设置 PVP, NPC 伤害, NPC 杀死, 越狱时间或通缉的悬赏
      • 设置默认NPC
      • 在玩家进入区域后自动给予玩家标志.
        • 设置NPC视野.
        • 可在添加标志后添加悬赏
        • 玩家被逮捕后发送消息!

    • PlaceholderAPI
      • 提供一些变量.
        • 用户: 悬赏, 总悬赏. 当前状态等
        • 全局: 被通缉次数最多的玩家, 最近的监狱

    • BetonQuest
      • 提供额外的事件、任务目标和任务条件
    • LeaderHeads
      • 悬赏、越狱数、击杀数等排行榜


前置 · Dependency

  • Vault(经济 & 权限)
  • Citizens2(NPC交互)
  • WorldGuard(监狱区域管理)
  • Sentinel
入门教程 · Quick Tutorial
  • 下载最新版本的插件并放到插件文件夹内
  • 开服
  • 编辑文件
  • 使用权限插件, 确认你分了三个权限组(默认权限组: WANTEDCRIMINALS, JAILED, FUGITIVES)
  • 创建worldguard区域来建监狱
    • /region create tutorialjail
  • 创建监狱： /np createjail {缩写} {区域名} {展示名}
    • 如/np createjail tutjail tutorialjail Tutorial Jail
  • 添加牢房,站在牢房内输入 /np addcell
  • 创建 NPC
    • 选择NPC 并输入/np npc
    • 在菜单内点击 X. 这之后会变为复选标记.
  • 在监狱外创建NPC
    • 给予NPC物品
    • 对于 sentry 插件可使用以下指令:
      • /trait sentry
      • /sentry target add group:WANTEDCRIMINALS
      • /sentry target add group:FUGITIVES
    • 对于 Sentinel 插件可使用以下指令:
      • /trait sentinel
      • /sentinel addtarget group:WANTEDCRIMINALS
      • /sentinel addtarget group:FUGITIVES

    • 输入 /np npc 并检查NPC,应该会显示一个标志

  • 在守卫25格内创建另一个可攻击的NPC
    • 攻击这个NPC, 你会看到警告消息或悬赏. 守卫会攻击你因为你对NPC造成了足够多的伤害.
    • 在监狱里, 右击你创建的NPC会出现一个菜单.

  • 监狱监狱预览.
    • 1: 我喜欢在这里放置狱卒来逮捕玩家或使其与玩家交互.
    • 2: 监禁玩家的牢房.
    • 3: 提供越狱的方法, 我使用铁门来让NPC 守卫无法进入监狱
      • 如果玩家离开了监狱, 玩家会被视为已越狱，监狱守卫会抓回玩家.
