第二章——线程基础(中)

第一部分——线程的一些方法
1.1 线程类下常用的方法
thread.start(); —— 开启线程，不讲了
thread.isAlive() —— 返回true如果线程正在运行，反则false
thread.setDaemon(boolean on) —— 把一个线程设置为守护线程，什么是守护线程呢？顾名思义，比如垃圾回收线程，它就是一个守护线程。当所有非守护线程结束了，守护线程也就会结束，但是如果非守护线程永远不会结束，守护线程也永远不会结束。
记住，setDaemon方法必须在start方法前面设置，否则会抛出IllegalThreadStateException
thread.join() —— 这个方法如果执行了就会堵塞执行这个方法的线程，并等待thread执行完成，执行这个方法的线程才能够继续执行。
thread.join(毫秒) —— 和上面一样，但是如果等待时间超过这个毫秒了就不会继续等待了
thread.sleep() ——这个应该不用多说了大家都清楚
thread.setPriority() —— 设置线程的优先级
thread.yield() —— 顾名思义，把当前线程CPU使用的时间暂时让给别的线程，让重要的线程先执行，这个方法一般执行于不是很重要的线程
thread.getState() —— 获取当前线程的状态
状态分以下几种:
Thread.State.NEW —— 线程位于新建状态，还没有执行thread.start()方法
Thread.State.RUNNABLE —— 线程正在执行
Thread.State.BLOCKED —— 线程被堵塞
Thread.State.WAITING —— 线程正在等待
Thread.State.TIMED_WAITING —— 线程正在进行一个有期限的等待
Thread.State.TERMINATED —— 线程消亡

1.2不推荐使用的几个方法:
第一个: thread.stop();
为什么不能使用呢？(不建议)因为实在是太暴力了
我们举这样一个例子
public class Main extends Thread{
static Test t;
@Override
public void run() {
    while (true) {
    int i = t.getFirst();
    int i2 = t.getSecond();
    t.setFirstAndSecond(i+1, i2+1);
    }
}
public static void main(String args[]) {
    t = new Test();
    Main m = new Main();
    m.start();
    try {
        Thread.sleep(100);
    } catch (InterruptedException e) {
        e.printStackTrace();
    }
    m.stop();
    System.out.println(t.getFirst()+", "+t.getSecond());
}
static class Test {
    int first = 5;
    int second = 5;
    public int getFirst() {
        return this.first;
    }
    public int getSecond() {
        return this.second;
    }
    public synchronized void setFirstAndSecond(int first, int second) {
        this.first = first;
        try {
            Thread.sleep(10); //模拟耗时操作
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        this.second = second;
    }
}
}

第二个:suspend()和resume()方法
为什么呢？因为suspend方法是立刻挂起线程，并且不会释放任和锁，所以如果别人线程访问锁的话都会获取不到锁。
第二部分——初步了解synchronized关键字
synchronized可谓是线程里面非常重要的东西了，如果没有锁我们举这样一个梨子:
public class Main extends Thread{
static int i = 0;
@Override
public void run() {
    while (true) {
    if (i == 100) {
        break;
    }
    i++;
    try {
        Thread.sleep(100);
    } catch (InterruptedException e) {
        // TODO Auto-generated catch block
        e.printStackTrace();

    }
}
public static void main(String args[]) {
    Main m2 = new Main();
    Main m = new Main();
    m.start();
    m2.start();
    try {
        m.join();
        m2.join();
    } catch (InterruptedException e) {
        // TODO Auto-generated catch block
        e.printStackTrace();
}
}
}

public class Main extends Thread{
static Object lock = new Object();
static int i = 0;
@Override
public void run() {
    while (true) {
    synchronized (lock) {
    if (i == 100) {
        break;
    }
    i++;
    try {
        Thread.sleep(100);
    } catch (InterruptedException e) {
        // TODO Auto-generated catch block
        e.printStackTrace();
    }
    System.out.println(i);
    }
    }
}
public static void main(String args[]) {
    Main m2 = new Main();
    Main m = new Main();
    m.start();
