标题: 制作一个免费的Minecraft服务器网站（会打字即可）！


此文献给希望把服务器建设的更加完善的各位服主！
假如你没有多余的资金来架设服务器网站，又或者你不太懂网站建设方面的知识，那么这篇文章正是适合你的！
欢迎大家在回复中贴上你制作的网站实例，供大家参考

-
玩家作品： http://jimminecraft.weebly.com/index.html



首先我放一个我已经制作好的实例：http://cupcakemc.weebly.com/index.html


接下来开始教程吧：
一：注册weebly账号
打开weebly官网，输入相关信息后，点击Signup.It's Free!


输入验证码后，点击很好.开始吧！

二.开始创建网站框架
输入网站标题，类型选择个人就行

点击继续后，输入网站域名，这里可以选择免费的二级域名，或者绑定别的域名

点击继续后，再点击
这样一个网站基础框架已经搭建好了


下面我们来继续完善框架
我们点击工具栏的页面

点击添加页面按钮
添加多个页面，并修改页面名称后，点击保存设置

现在可以看到我们的导航栏多了刚才那几个页面

到此为止我们的网站框架已经建设完毕！点击来保存并查看效果

三.完善网站内容
在编辑模式下，我们点选首页
然后将工具栏中的 "段落带图片 "拖拽到首页页面内容中

输入标题”服务器简介“
点击左边图片
点击上传一张图片
点击右下角的小红方块可以调整图片大小
在图片的右侧输入相关内容
这样就完成了一个服务器的简介


接下来添加服务器信息和公告，这儿我们插入一个分隔符（工具栏-》更多-》布局-》分隔符，拖拽到相关位置）
将工具栏基本中的Multiple Columns拖拽到服务器简介下面
这样就将页面分为2块区域
在左边的区域中拖拽入段落并填入相关信息
在右边的区域中拖拽如段落并填入相关信息
。
下面给大家介绍下如何插入视频到页面中
首先按照先前将的方法，拖拽入一个Multiple Columns
然后将自定义html拖拽到左边的区域，点击：Click to set custom HTML
粘贴优酷视频的html代码到此处（分享，复制html代码）
然后再右侧拖拽入段落用来介绍
你也可以在下方放入服务器赞助。


教程指导与服务器规则页面写入相关服务器命令帮助服务器规则等

下面来介绍一下白名单申请页面的制作
首先拖拽工具栏基本中的联系表单到入住申请页面，然后点击表单，这时候工具如会切换到表单编辑模式

首先将”单击此处编辑“改为：白名单申请
按删除将下面的框架删除
拖拽工具栏中的短文本框到页面内，点击此框架，进行修改
更改字段标题为玩家ID，输入字段说明：输入你游戏中的ID


点击save保存，以同样的方式分别插入： 所属网络、Minecraft经验、玩家年龄等
完成后点击表单选项
修改相关选项，点击save保存

点击关闭，后点击发布，保存一下。
后台白名单申请管理：
在后台，点击更多-》表单输入来查看管理白名单申请（注，只有在有至少一条申请存在是，才会出现下图2的界面）



卫星地图页面的编辑
将工具栏中基本中的自定义html拖拽到页面中
点击”Click to set custom HTML“
粘贴
  • <a href=" http://46.51.248.185/dynmap/" title="全屏模式">切换到全屏模式dynmap地图</a>
  • <iframe src=" http://46.51.248.185/dynmap/" width="100%" height="600">
  •   <p>dynmap here</p>
  • </iframe>

复制代码
将http://46.51.248.185/dynmap/ 改为你服务器的卫星地图地址，一般为http://ip:8123
点击发布，保存一下

玩家作品页面的编辑
将工具栏中多媒体中的幻灯片拖拽到玩家作品页面中
选择一个展示形式，点击Continue继续（如遇点击继续后无反应的，点击右上角的X）


点击增加图片，点击Upload Photos，上传玩家图片到幻灯片中

入以后想要增加图片，点击增加图片后，再点击ADD photos

删除图片，点击对应图片上的垃圾桶图标即可
点击发布，保存一下

下载页面，你可以放入你服务器的专用客户端下载地址，或者材质下载地址


最后介绍下LOGO BANNER和模板的更换
LOGO更换：
将鼠标移至网站标题上，点击LOGO，来上传或者使用网络图片来设置服务器LOGO


这样就完成了LOGO的设置


BANNER的更换
将鼠标移至banner上，点击Edit Image

首先删除自带的图片
然后点击工具栏中的Add Image

上传或使用网络图片设置banner，适当调整图片大小后，点击OK保存

再点击右上角的SAVE按钮、
选择 save as default header
这样banner就设置好了

主题更换
选择工具栏中的设计

直接点击你想要的主题，就可以快速切换主题

所有完成后，别忘了点击发布，保存你的网站！
本教程完成后的网站：http://minecraft-xz.weebly.com/index.html

到此为止，一个漂亮的服务器网站已经建设完毕！如有疑问，请回帖
