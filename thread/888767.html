从 1.9 到 1.14，模型格式一笔没改。

assets/minecraft/models/item/diamond_sword.json
{
    "parent": "item/handheld",
    "textures": {
        "layer0": "items/diamond_sword"
    },
    "overrides": [
        { "predicate": { "damaged": 1, "damage": 0.3 }, "model": "items/wooden_sword"}
    ]
}

当钻石剑耐久损失了30%（即 0.3）及以上后，就会变成木剑的材质。

可参见：https://www.mcbbs.net/thread-784662-1-1.html?cp=3 教程中只有 custom_model_data 是 1.14 的新内容，你把它改成 damage 就行了。

另外，负数是不可能的。

突然给最佳，我好懵的…

1.13 的资源包放 1.12 用不了，因为文件变动太多了。

具体操作就是创建 assets/minecraft/models/item/diamond_sword.json，内容是我上面回答的那段 JSON，这样操作就覆盖掉了原版钻石剑的模型文件，可以让 MC 根据你设定的 overrides 来改变指定耐久度下钻石剑的材质。别的就不需要操作什么了，我填写的材质的路径都是原版就自带的。
