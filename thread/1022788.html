1. 修改开服bat
  1. @echo OFF
  2. :head
  3. set a=-1
  4. :start
  5. set /a a+=1
  6. set b=3
  7. color 7
  8. title Login Server [已重新启动 %a% 次]
  9. java -server -XX:+UseG1GC  -jar 服务端核心名字.jar
  10. ping -n %b% 127.1>nul
  11. goto start
复制代码
