命令：

管理命令
  • “modbanner.bypass” - 通过perm**on用户使用禁止的mod时不会被踢这个权限
  • modbanner.command.add - / modbanner add（将mod添加到黑名单）（名称可以不同，例如Xray作弊MOD：[xxray，ExtremRaYXXD]等）
  • modbanner.command.remove - / modbanner remove（从黑名单中删除mod）
  • modbanner.command.list - / modbanner list（查看所有列入黑名单的mods）
  • modbanner.command.manage - / modbanner（add （加入） / remove（删除） / list（列表））
重新加载命令
  • modbanner.command.reload - / modbanner reload（重新加载配置/禁止的mods（如果通过命令添加mods则不需要））
信息命令
  • modbanner.command.modinfo.player - / modinfo player（查看所有玩家mods使用）
  • modbanner.command.modinfo.mod - / modinfo mod（查看使用该mod的所有玩家）
  • --------------------------------------------------------------------------------------------------------------------------------------------------------------------
组态：
您只需更改kick文件的配置，添加/删除请参阅命令！

对于kick消息，您可以使用％mods％来显示禁用的mods玩家正在使用（/ modbanner reload for apply changes）

## 问题：
报告问题：https：//github.com/rodel77/ModBanner/issues 93

原作者是经常在线的
注意：什么是ModBanner：
  • 一个插件，根据他们发送的连接信息，对使用禁用mod的玩家进行踢
什么不是ModBanner
  • 一个插件，以防止任何插件completly
