More TNT

更多的TNTaddon添加了20种新的爆炸物，如燃烧弹、手榴弹、导弹等。还添加了新的爆炸物方块，威力闯难关2倍的TNT到核导弹不等。

合成

你可以在工作台中搜到合成表，但是由于BUG，你无法看到方块的合成表（希望在未来的版本中可以修复）



爆炸物方块

新增了12种新的TNT，要注意有些新增的TNT爆炸时间是不同的，你需要用燧石来点燃他们（除了C4炸弹）

TNT x2, x4, x8：这种新增的TNT不言而喻，爆炸范围x2、x4、x8





基岩炸弹：该TNT可以炸毁基岩





低温炸弹：该TNT可以冻住周围的实体，并把周围的水变成冰，岩浆变成圆石





DYN炸弹：该TNT可以在爆炸时变出一群TNT，能造成更大范围的伤害





汽油弹：该TNT是低温炸弹的反面，可以让爆炸区域着火，并不断爆炸





C4炸弹：该TNT无法被打火石点燃，需要用遥控引爆，遥控的范围是60x60x60格方块。你可以在一个安全的距离外引爆C4炸弹，并且会引爆范围内所有的C4炸弹。当C4炸弹被点燃时，会对周围人发出警报，C4炸弹越多，警报声越响。





核弹：该炸弹的杀伤力远大于上面几个，在爆炸范围内会受到包含放射性的负面效果，还会产生一个巨大的黑色蘑菇云





氢弹：该addon中威力最大的炸弹，比核弹的威力还大三倍，并且带有白色的蘑菇云，虽然没用放射性伤害，但是仅有的20s爆炸时间需要你及时逃离。





粘弹：这是一种普通的TNT，但是在被点燃时会变出蜘蛛网，让他黏在原来的位置。







特斯拉炸弹：该炸弹可以在一定区域内产生闪电，并且燃烧该区域。





投掷型炸弹

像扔雪球一样扔就行，要注意每个炸弹重力不同，所以要小心使用

Caber：威力3



TNT炸弹棒：威力3-24



碎片手雷：威力5，带有碎片粒子，落地时引燃



烟雾弹：让周围的实体失明



震撼弹：威力1，爆炸时可以冻结周围的实体



炸弹棒：威力5



催泪瓦斯：靠近爆炸源的生物会获得失明和反胃



普通的炸弹：威力5，熟悉的形状，落地点燃



燃烧弹：威力2，能产生一片区域的火



钾弹：威力4，在雨天或碰到水时爆炸



磷弹：不会爆炸，但是靠近爆炸源会失明并收到伤害



奇点炸弹：灵感来源于Pixel Gun 3D，不会破坏方块，会吸引实体，被吸到黑洞的实体会被杀死



发射导弹

你可以像使用弓箭一样使用这些物品，你可以把用完的发射器放在在合成网格里在重新装弹。



使用这个物品是有后坐力的

Launcher ( Luft 3 ) = 威力：3
Launcher ( Luft 6 ) = 威力：6
Launcher ( Luft 12 ) = 威力：12
Launcher ( Luft 24 ) = 威力：24



你也可以放置他们：但要使用“Item ground”物品并与其他物品相互作用来展显示他们

旧版（1.12）
More TNT add-on adds more than 20 new explosives to the game! Molotovs, grenades, missiles, and even a black hole!
This add-on is quite different from my old version because it uses custom items and custom entities so it wouldn’t replace anything.
这个MOD添加了超过20种的爆炸物，燃烧瓶、手榴弹、导弹，甚至是black hole！
这和我之前制作的MOD不同，这个新的MOD使用了自定义的物品和自定义的实体，所以它不会占用任何其他东西。



使用方法
This add-on doesn’t support the crafting of these new items however, although this content still works without them.
这个MOD不支持合成，尽管没有合成也能使用

生成TNT
You want to ignite them right? Simply use a flint and steel or a fire charge to do so! They also explode if they’re hurt by explosions and fire.
TNTs use spawn eggs for easier accessibility, this is the list of types and their abilities:
你想要点燃它们，对吧？使用打火石或者火焰弹点燃他们！他们也会被其他爆炸或火点燃（和TNT属性一样）
使用TNT生成蛋可以轻松生成，以下是TNT种类和它们的威力：
  • TNT x2 - 威力：6
  • TNT x4 - 威力：12
  • TNT x8 - 威力：24
  • Dynamite（炸FHC药） - 威力：24 - spreads about（传播到四周）
  • C4（C4炸FHC药） - 威力：5 - instant explosion（立即爆炸） - perfect for rocket-jumping
  • Napalm（凝固汽油弹） - 威力：2 - spreads fire（会产生火焰）
  • Cryocharge - 威力：3 - breaks no blocks（不会破坏方块） - freezes entities around it（冻结周围的实体） - turns lava to cobblestone（把周围的岩浆变成圆石） - turns water to ice（把水变成冰）
  • Sticky bomb（粘性炸FHC药） - 威力：3 - varied fuse time（多种引线时间）
  • sticks to surfaces when detonated
  • Nuke（核弹） - 威力：48 - spreads about（传播到四周） - mushroom cloud（会有蘑菇云） - entities near explosion gets nausea and poison（靠近的实体会获得反胃和中毒效果）
  • Bedrock buster（基岩破坏者） - 威力：6 - breaks bedrock（可以破坏基岩） - spreads fire（会产生火焰）





可抛出的炸弹
These are bombs that you can throw for yourself.
To throw them, simply aim and sneak. Note that some of these bombs have varying weights so becareful when using them.
这是一种可以投掷的炸FHC药
瞄准并潜行来扔出他们，要注意的是有些投弹重量不一样，所以使用的时候请小心

  • Caber - 威力：3
  • TNT sticks - 威力：3 到 24
  • Frag grenade（碎片手榴弹） - 威力：5 - breaks no blocks（不破坏方块） - fragment particles（产生碎片粒子） - fuse is lit when it lands（一旦落地就被点燃）
  • Smoke grenade（烟雾弹） - no explosion（不会爆炸） - blinds entities near explosion（让周围的实体失明）
  • Stun grenade（震撼手榴弹） - 威力：1 - breaks no blocks（不破坏方块） - freezes entities within explosion（在爆炸范围内冻结实体）
  • Dynamite stick（炸FHC药棒） - 威力：5
  • Tear gas（催泪瓦斯） - No explosion（不爆炸） - entities near the explosion gets blindness and nausea（爆炸附近的实体获得失明和反胃效果）
  • Generic bomb - familiar shape - 威力：5 - fuse is lit when it lands（一旦落地就被点燃）
  • Molotov（燃烧瓶） - 威力：2 - spreads fire（会产生火焰）
  • Potassium charge（钾离子电荷弹） - 威力：4 - explodes on condition of getting wet ( weather, water, etc. )（在变湿时爆炸，如下雨、水等）
  • Phosphorus charge（磷离子电荷弹） - no explosion（不爆炸） - entities near explosion gets blindness and damage（附近的实体获得失明和反胃效果）
  • Singularity shell - inspiration taken from Pixel Gun 3D（灵感来自于Pixel Gun 3D） - breaks no blocks（不破坏方块） - sucks entities in ( including players )（把实体吸入，包括玩家） - entities inside the hole gets killed（在洞里的实体会被杀死）
