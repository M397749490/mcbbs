蓝条的渲染需要使用到注册事件情节，这里我就给几个关键的代码吧，如果有点基础应该都能用，不好意思懒癌发作了。
首先是forge事件的注册，我们需要注册在游戏进行中画这些血条啊，饥饿条的事件，一秒是20次
例如我把事件丢在主类，那么在主类的事件里你需要写上：
(PS:主类中要new 一个PlayerDataController()) 初始化一下NBT的实例。

FMLCommonHandler.instance().bus().register(this);
如果是其他的类 那么：
FMLCommonHandler.instance().bus().register(new 其他类());

在主类添加一个方法
Minecraft mc;//定义一个需要用到的成员
@SubscribeEvent//注释这是一个事件
public void playercolumn(RenderGameOverlayEvent.Pre event)//当然这个方法名随意
{
       //那么在这里可以开始判断：
       if(event.type == ElementType.HEALTH) //如果绘制的是血条
          mc = Minecraft.getInstance();//取当前实例
          mc.renderEngine.bindTexture(new ResourceLocation("mod资源目录名:资源路径"));//绑定一个材质,材质可以定义成静态成员，这样就不用每次去取了。
          PlayData playData =  PlayerDataController.instance.getPlayerData(mc.thePlayer);//取到的PlayerEntity丢给存档方法，取到存档类型的玩家数据
         int nowmp =playData.你所定义的数据(当前蓝);//这一部分脑补，你在NBT里面定义了什么就取什么
         //最后使用绘制方法将图绘制出来，这里可以参考szssz的GUI教程，忘记名字了 ，大概是这样吧，
         drawScaledCustomSizeModalRect(........);//怎么绘图自行脑补 完了我还是贴了
         
}

//drawScaledCustomSizeModalRect 方法
public static void drawScaledCustomSizeModalRect(int x, int y, float u, float v, int uWidth, int vHeight, int width, int height, float tileWidth, float tileHeight) {
            float f4 = 1.0F / tileWidth;
            float f5 = 1.0F / tileHeight;
            Tessellator tessellator = Tessellator.instance;
            tessellator.startDrawingQuads();
            tessellator.addVertexWithUV((double)x, (double)(y + height), 0.0D, (double)(u * f4), (double)((v + (float)vHeight) * f5));
            tessellator.addVertexWithUV((double)(x + width), (double)(y + height), 0.0D, (double)((u + (float)uWidth) * f4), (double)((v + (float)vHeight) * f5));
            tessellator.addVertexWithUV((double)(x + width), (double)y, 0.0D, (double)((u + (float)uWidth) * f4), (double)(v * f5));
            tessellator.addVertexWithUV((double)x, (double)y, 0.0D, (double)(u * f4), (double)(v * f5));
            tessellator.draw();
        }
