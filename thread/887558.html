使用Scala REPL

REPL是Read Eval Print Loop的缩写，可以通过Scala REPL来尝试运行一些简单的Scala代码。首先打开cmd然后输入scala进入Scala REPL。然后可以做一些简单的小学算术，例如：
  1. scala> 1 + 1
  2. res0: Int = 2

  4. scala> (1 to 10).sum
  5. res1: Int = 55
复制代码
可以尝试一些以“:”开头的指令，例如“:help”显示帮助信息，“:quit”退出REPL。

第一个Scala程序

在任意位置创建一个文件，命名为Main.scala，并写入代码：
  1. object Main {
  2.   def main(args: Array[String]): Unit =
  3.     println("Hello, World!")
  4. }
复制代码
然后输入以下命令编译并执行：
  1. > scalac Main.scala
  2. > scala Main
复制代码
应该能看到终端内输出了“Hello, World!”。
