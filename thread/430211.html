作者: robbit    时间: 2015-4-6 03:28
你需要查看服务器这个目录的东西:plugins\GroupManager\worlds\world\config

然后你会看到一堆权限组

你只需要设置玩家权限组Builder的build为true就可以了

如下:
Builder:
    default: true
    permissions:
    - plotme.use
    - plotme.use.add
    - plotme.use.remove
    - quickshop.create
    - quickshop.create.sell
    - quickshop.use
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      prefix: ''
      build: true
      suffix: ''
