tp 村民到玩家位置真的对不准的…非要用的话，效果极差，我只随便扯几句。关于胡萝卜钓竿的用法我在分割线下面有更新，强烈推荐。

我就直接复制沙发 FHC红石 提的命令了
scoreboard objectives add talked minecraft.custom:minecraft.talked_to_villager
summon minecraft:villager ~ ~ ~ {Tags:["click_detecter"],NoAI:1b,Silent:1b,Offers:{Recipes:[]},ActiveEffects:[{Id:14b,Duration:2147483647,ShowParticles:0b}]}

把每刻执行的命令改成
（这样就只支持单人了，支持多人又要改）
execute as @p at @s run teleport @e[tag=click_detecter] ^ ^ ^1
execute as @p[scores={talked=1..},nbt={SelectedItem:{tag:{skill:1}}}] run say 我触发了技能 1
execute as @p[scores={talked=1..},nbt={SelectedItem:{tag:{skill:2}}}] run say 我触发了技能 2
scoreboard players reset * talked


这么做效果真的极差，拿胡萝卜钓竿就开心得不行了。


关于胡萝卜钓竿的另一种用法
红色是相对于原回答的改动
把它放到玩家的副手位置，然后主手放任何你喜欢的物品。
# 给两个触发不同技能的道具
# skill:1 和 skill:2 是自定义的，可以改别的
# 物品可以是任何东西，只要这些东西本身没有右键功能就可以
/give @s minecraft:diamond_helmet{skill:1,display:{Name:"\"技能 1\""}}
/give @s minecraft:diamond_sword{skill:2,display:{Name:"\"技能 2\""}}

# 创建用于检测右键的记分板
scoreboard objectives add click minecraft.used:minecraft.carrot_on_a_stick

# 每刻执行
execute as @a run replaceitem entity @s weapon.offhand minecraft:carrot_on_a_stick
execute as @a[scores={click=1..},nbt={SelectedItem:{tag:{skill:1}}}] run say 我触发了技能 1
execute as @a[scores={click=1..},nbt={SelectedItem:{tag:{skill:2}}}] run say 我触发了技能 2
scoreboard players reset * click
