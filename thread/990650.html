PlayerListPlus

Tab列表的高级美化

插件介绍

排版已经更新，感谢网友们的支持！
这个插件是从一个叫BungeeTabListPlus[作者CodeCrafter47]的插件得来
作者从中得出脑洞并做出了一款全新的插件
让其能够在单端使用
顺便一提这个插件的作者就是BeaconPlus2(某付费插件)[站内搬运贴]的作者

插件特点

完全可编辑(Tablist任意位置)
类似于计分板的基础信息显示
各个世界玩家数量显示
普通玩家和OP分离识别
自带PING显示
变量支持
非常轻量，安装即用
支持忽略隐身玩家
异步发送数据包，减少卡顿
支持不同的权限显示不同玩家
支持正版玩家头像显示在左侧
可以在TabList中添加假玩家！
支持改变TabList大小



插件指令

/plp <参数，详见下表>
(所有可用的alias因为太多故不列出)
只有一个总权限 playerlistplus.admin 默认OP拥有
单个Tab格子的自定义内容设置↓
@设置参数=值;@第二个设置参数=值;显示文本请写在最后

1.) set
设置一个格子的内容. 换行使用空格, 动态显示请使用字符 ";"
2.) unset
清空一个格子的所有内容
3.) ping
设置一个格子显示的Ping数字值
4.) unping
取消设置Ping值
5.) enable
启用Tab列表
6.) disable
禁用Tab列表
7.) reload
重载本插件
8.) header
设置顶部Tab栏显示 ,用";"来换行
9.) unheader
清除顶部Tab栏内容
10.) footer
设置底部Tab栏显示,用 ";" 换行
11.) unfooter
清除底部Tab栏内容
12.) gamemode
不明 | 设置Tab栏游戏模式
13.) ungamemode
清除Tab栏游戏模式
