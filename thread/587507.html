改成就确实做不到。但是如果把它放到屏幕中间大字显示出来，效果也比较好。
先建立一个计分板
/scoreboard objectives add seed dummy
其中seed是积分版名
然后在游戏开始时把玩家计分板数值设为0
/scoreboard players @p set seed 0
注意：必须在玩家玩的时候设置，在你的电脑上设置是无效的
也就是说在按下“游戏开始”按钮时设置
然后
高频
/clear @p wheat_seeds 0 0
比较器连接：
/title @p[score_seed=0] title {"text":"获得成就！","color":"yellow","extra":[{"text":"     获得小麦","color":"white"}]}
/scoreboard players @p set seed 1
