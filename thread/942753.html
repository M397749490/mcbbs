"打完"是指只剩下1个玩家吗？
你可以做一个玩家数量检测（当然要只检测非创造、非旁观的玩家），当玩家数量为1时把所有人背包清空再TP。
start.mcfunction（初始化）
  1. scoreboard objectives add logCount dummy "计数"
复制代码

player_check.mcfunction（包含于tick.json/每gt高速执行）
  1. execute as @a[gamemode=!creative,gamemode=!spectator] store success score #PlayerCount logCount run scoreboard players set @s logCount 0
  2. #通过execute让非创造、非旁观玩家执行无意义操作再记录成功次数就可以获得玩家数量
  3. execute if score #PlayerCount logCount matches 1 run clear @a
  4. execute if score #PlayerCount logCount matches 1 run tp @a x y z
  5. execute if score #PlayerCount logCount matches 1 run gamemode adventure @a
  6. #设置游戏模式、清空背包并传送，你可以把x y z修改为指定的坐标
复制代码

@陨星尘
这个简单丫，1.15新加入了一个gamerule刚好可以满足你的需求：doImmediateRespawn。将它设为true就可以不显示“你死了！”的页面而立即重生。然后只要用一个计分板探测死亡再设置gamemode就可以了。
start.mcfunction（初始化）
  1. scoreboard objectives add death deathCount "死亡数"
  2. gamerule doImmediateRespawn true
  3. #将这条神奇的gamerule启用
复制代码

spectator_respawn.mcfunction（包含于tick.json/每gt高频运行）
  1. gamemode spectator @a[scores={death=1..}]
  2. #设置死亡了的玩家的游戏模式
  3. scoreboard players set @a[scores={death=1..}] death 0
  4. #复位
复制代码
