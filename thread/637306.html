CPSMonitor
<目前可以设置自动封杀或者是自动提出>
[详情请看下载区]



插件能够监视你玩家的CPS点击值[鼠标点击速度]

当一个玩家超过了你所设置的CPS点击值之后，就会自动报警[情况严重就会自动BAN]

-

-

-


官方的一些照片....











特点

  1. 自动封杀
  2. 可以设置的CPS限制
  3. 可以设置的消息。
复制代码




  
  1. /cps
  2. 　　权限:没有
  3. 　　描述:显示CPSMonitor所有可用的命令。
  4. 　　/rates <用户名>
  5. 　　权限:cpsmonitor.checkhistory
  6. 　　描述:显示玩家的作弊阶段
  7. 　　/alerts
  8. 　　权限:cpsmonitor.alerts
  9. 　　描述:切换管理员是否接受警告
复制代码


  1. # 等待几秒钟后进行下一次检查
  2. alert-interval: 5

  4. #自定义阶段概率....
  5. possible_rate: 12
  6. probable_rate: 15
  7. definite_rate: 17

  9. # 自动封杀设置
  10. auto-ban:
  11.   enabled: true
  12.   # true = 开启 false = 关闭
  13.   ban_rate: 21
  14.   # 指令用途：封杀那个作弊的玩家
  15.   # Example: ban %cheater_name% %ban_reason% 2w6h12s
  16.   # Example: tempban %cheater_uuid% %ban_reason% 2w6h12s
  17.   command: 'ban $cheater $reason'
  18.   # 全体警告设置
  19.   broadcast: true
  20.   # true = 开启 false = 关闭
  21.   broadcast_format: '&a$cheater was auto-banned by the anti-cheat.'

  23. # Messages
  24. messages:
  25.   # 这个是插件警告的前缀
  26.   prefix: '&8[&c!&8] '
  27.   # 这个是插件警告的信息or格式
  28.   cheat_alert: '&c$cheater &7is &4$level &7using an autoclicker [&c$rate cps&7]'
  29.   # 这个是没有权限使用这个插件所显示的信息！
  30.   no-perm: '&cYou do not have permission to do this.'
