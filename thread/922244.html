你可以使用ChatColor的方法
譬如：
  1. translateAlternateColorCodes
  2. public static java.lang.String translateAlternateColorCodes(char altColorChar,
  3.                                                             java.lang.String textToTranslate)
  4. 转换交替的颜色代码字符到内部的ChatColor.COLOR_CHAR颜色代码字符.如果它后面紧跟着的是0-9, A-F, a-f, K-O, k-o, R 或 r，其它的颜色代码只会被替换.
  5. 译注:这个方法是用来把其他的颜色代码替换成Minecraft本身的.比如我们在Minecraft服务器聊天时，为了输入方便，就使用"&"来替换"§"，服务器要处理这种消息时就要用到本方法.

  7. 范例:System.out.println(translateAlternateColorCodes('&', "&cred&agreen&9blue"));这段代码会把"&cred&agreen&9blue"替换成"§cred§agreen§9blue"，"§"是ChatColor.COLOR_CHAR的默认值.

  9. 原文:Translates a string using an alternate color code character into a string that uses the internal ChatColor.COLOR_CODE color code character. The alternate color code character will only be replaced if it is immediately followed by 0-9, A-F, a-f, K-O, k-o, R or r.

  11. 参数:
  12. altColorChar - 要替换的其他颜色代码.比如:&
  13. textToTranslate - 包含了其他颜色代码的字符
  14. 返回:
  15. 包含了ChatColor.COLOR_CHAR颜色代码字符的文本
复制代码


简单的来说就是
char altColorChar就是需要替换的颜色代码，比如: &
String textToTranslate就是要替换的内容，譬如：ChatColor.translateAlternateColorCodes('&',"&e请输入/nxx来获取资源 & 获取材质");
这样子最终的输出效果为
§e请输入/nxx来获取资源 & 获取材质.
