Simple DoubleJump
SpigotMC
我服需要一个二段跳的插件，在SpigotMC逛了一会
就发现有这个插件，觉得非常小巧轻便，
然后我就搬运过来了。

插件特性有以下特性
  • 1. 更简便
  • 2.中小型服适用
插件指令:
  • /simpledoublejump reload
    • 重载配置文件
    • 权限: sdj.reloadcmd
  • /simpledoublejump toggle
    • 是否开启二段跳模式
    • 权限: sdj.toggle

插件配置文件:
  1. # 作者: TrieuCoding
  2. # 本插件仅仅支持: 1.11, 1.11.2
  3. prefix: '&7[&cSimple Doublejump&7]&r '
  4. #聊天前缀显示

  6. check-update: true
  7. #是否开启更新检查

  9. no-permission: '&c你没有权限来使用它！'
  10. #无权限时发出的消息

  12. reload: '&a重载成功'
  13. #重载完成时发出的消息

  15. cooldown: 3
  16. #冷却时间

  18. particle: FIREWORKS_SPARK
  19. # 粒子效果，你可以去这个网站查看: https://hub.spigotmc.org/javadocs/spigot/org/bukkit/Particle.html

  21. sound: ENTITY_WITHER_SHOOT
  22. # 弹跳时发出的声音，你可以去这个网址查看: https://hub.spigotmc.org/javadocs/spigot/org/bukkit/Sound.html
