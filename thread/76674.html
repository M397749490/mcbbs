简介

本插件功能是使暴露在阳光下的JJ怪、蜘蛛、小黑也能燃烧， 装了这个插件，就不用担心大白天外出被JJ怪、蜘蛛偷袭了！如有需要，玩家也可以燃烧~

配置文件

没什么复杂的东西


  1. updatefrequency: 1000
  2. debugmode: false
  3. burnzombie: true —— 是否烧僵尸，true是，false否，以下不赘述。
  4. burnskeleton: true —— 骷髅
  5. burncreeper: true —— JJ怪
  6. burnspider: true —— 蜘蛛
  7. burnenderman: true —— 小黑
  8. burnplayer: false —— 玩家
  9. burnstarttime: 23750 —— 燃烧起始时间
  10. burnendtime: 12750 —— 燃烧终止时间
