根据对实体造成伤害百分比触发命令 DamageReward
交流群: 1023365448
功能:
1.玩家对实体造成伤害时插件会记录，当此实体死亡后 根据伤害百分比而触发命令
2.可自定义指定名字的怪物才会生效功能
3.支持是否 只能获得最高奖励 或者 全部奖励

命令:
/dr reload  -重新加载配置


配置:
  1. #
  2. # 开启调试模式
  3. Debug: false

  5. # 配置
  6. MobDamage:
  7.   # 怪物名字
  8.   "测试":
  9.     # 如果设置为true 玩家伤害的百分比是100 那么他会获得全部奖励
  10.     # 如果设置为false 玩家伤害百分比是100 那么他会获得最高奖励
  11.     carry_over: true
  12.     # 奖励 (注意 要把高奖励放前面)
  13.     reward:
  14.       "50":
  15.         - "say %p造成50%伤害"
  16.       "5":
  17.         - "say %p造成5%伤害"
复制代码



使用:

我们先用命名牌 随便给一个生物改名为 测试 (其他方法更改也可以)
然后打死这个生物 就会根据配置 触发命令了
