这个插件跟很多lore插件一样，但是我发现mcbbs里面很多这样的插件有bug，而且
都不修复的所以我才想出这个插件，顺便添加千分比获得随机指令
功能对于我来说是挺强大的

用法：
配置文件配置好识别信息后拿手上右键即可执行指令
插件的功能
1:可以右键执行指令
2:可以右键执行随机指令#1.1版本
3:可以直接设置鉴定书“这个方法自己摸索”#1.1版本
4:可以设置飞行卡，转送卡
5:可以设置抽奖彩蛋或者其他
6:反正我个人感觉功能挺多，只要你有想法
7:宝石合成，可以设置右键给宝石，需要多少钻石等
原本这个插件只是用来执行指令，后面我更新了1.1修复了BUG，就不只是执行指令那么简单了
1.3版本强大一些，插件已经完善！自己也用了四个月了！
1.5添加更多功能，修复扣除RPG的BUG！
安装插件
1.直接放进plugins文件夹，然后用yum load加载或者其他插件直接加载！
2.也可以选择放进plugins文件夹后直接重启服务器即可！

简单介绍如何使用该插件：
配合MythicMobs插件或者其他修改武器描述插件
caidan文件的item下面写：
Version: 1.3
item:
  exmple:
#识别物品lore来获得随机指令
    lore: "§b§l幸运彩蛋§1"
#是否启用左键触发
    LeftClick: false
#是否启用右键触发
    RightClick: true
#是否开启物品需求
    enable: true
    #背包没有物品时的提示
    NoItemMessage: "§c你背包缺少所需物品!"
    #物品的主ID
    itemID: 57
    #物品的子ID(无则写0)
    subID: 0
    #物品的数量
    amount: 1
    #权限需求(无需权限则留填写"",有则填入"所需权限")例子"essentials.joinfullserver"
    permissions: ""
    #没有权限时的提示
    NoPerMessage: "§c你没有权限使用该物品!"
    cmd:
      - "100:  give <player> 1 1"
      - "
100:  give <player> 2 1

"
然后重启服务器，或者用其他插件进行重启caidan插件
最后右键含有"
§b§l幸运彩蛋§1
”描述的物品，千分之一百可能获得1石头或者1草方块
千分比的计算，个人觉得百分比不精算，所以用千分比咯！
可以配合MythicMobs，
MythicMobs文件的 items 配置里面写：
caidan:
  Id: 383
  Data: 0
  Display: '§b§l彩蛋'
  Lore:
    - '§b§l幸运彩蛋§1' #识别lore信息，这个和caidan配置的lore一样即可
    - '§a右键有惊喜哦！'
  Enchantments:
  Options:

指令权限
1.5版本才有指令
指令是根据所需要规定物品
/caidan create 【id】 -保存手中物品到插件配置文件中
/caidan remove 【id】删除配置中指定名称的物品
/caidan give id 玩家 给与玩家1个指定物品
/caidan list 显示已有物品列表
