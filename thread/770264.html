啊哦，论坛抽风了。。


这个才对：
  1. @echo OFF
  2. @set a=0
  3. :Menu
  4. color F
  5. @title BungeeCord端 重启次数[%a%]
  6. @echo ####################
  7. @echo 重启次数: %a%         
  8. @echo ####################
  9. java -Dfile.encoding=UTF-8 -jar BungeeCord.jar
  10. @echo 已关闭，将于5秒后重启
  11. @ping -n 7 127.0.0.1>nul
  12. @set /a a=%a%+1
  13. @goto Menu
  14. pause
复制代码

先弄个txt文本，把下面代码复制进去，再做一些修改，保存后把文件后缀“.txt“改为“.bat“

  1. [url=home.php?mod=space&uid=39305]@echo[/url] OFF
  2. [url=home.php?mod=space&uid=107997]@set[/url] a=0
  3. :Menu
  4. color F
  5. @title BungeeCord端 重启次数[%a%]
  6. @echo ####################
  7. @echo      重启次数: %a%         
  8. @echo ####################
  9. java -Dfile.encoding=UTF-8 -jar BungeeCord.jar
  10. @echo 已关闭，将于5秒后重启
  11. [url=home.php?mod=space&uid=260039]@ping[/url] -n 7 127.0.0.1>nul
  12. @set /a a=%a%+1
  13. [url=home.php?mod=space&uid=1121364]@goto[/url] Menu
  14. pause
复制代码
