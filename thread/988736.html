虽然不知道你这堆代码不知道想要干嘛，但是原因是很清楚的
方法传入的时候传入的是实例的引用，所以你修改的时候也会修改实例本身
所以在开始的时候把传入的list复制一份即可，就像这样：
  1. List<String> vsort = new ArrayList<>(sort);
复制代码

另外请不要在循环内使用+连接字符串，而是使用stringBuilder的append的方法进行连接，因为编译的时候会自动使用stringbuilder优化字符串连接的性能，而且这在循环里会引发性能问题：
java内字符串是不可变对象，当你用+连接字符串的时候会创建新的字符串对象，所以会在编译期自动使用stringbuilder连接来优化例如下面代码的性能：
  1. String str="这"+"是"+"连接"+"字符串"
复制代码

会变成
  1. String str=   new StringBuilder("这").append("是").append("连接").append("字符串").toString();
复制代码

但是编译器并不聪明，当你在循环里面用+操作的时候会是这样的：
  1.    
  2. List<String> strList=Arrays.asList("这","是","连接","字符串");
  3. String cache = "";
  4.         for (int i = 0; i < strList.size(); i++) {
  5.             cache = cache + strList.get(i);
  6. }
复制代码

会变成
  1.    
  2. List<String> strList=Arrays.asList("这","是","连接","字符串");
  3. String cache = "";
  4.         for (int i = 0; i < strList.size(); i++) {
  5.             cache =new StringBuilder(cache).append(strList.get(i)).toString();
  6. }
复制代码

这会重复创建对象，造成性能问题，所以请手动使用StringBuilder
