LWC插件是一款有名气的锁箱插件，在命令和操作较Lockette来说比较简洁。
你仍然可以通过向方块上放置牌子来强制上锁方块，你可以通过/lock命令来上锁服务器配置列表中提名的方块~
牌子上可以写上任意内容，这一点就比Lockette要好（个人认为），而且单方块可以共享给很多人。

可以在配置文件中加入MOD方块的ID，这样在游戏中放下的时候就会自动落锁，并且支持/lock命令上锁！

指令：

  • /lwc - LWC主菜单
  • /cprivate - 设置为私有
  • /cpassword <密码> - 设置一个加密锁 "<>"这个括号不需要输入
  • /cpublic - 设置为公用 （但是不能破坏）
  • /cremove 删除自己的保护（输完敲一下要删的）
  • /cunlock <密码> - 解锁密码锁 "<>"这个括号不需要输入
  • /unlock 最普通最常用的简写命令
  • /lock 最普通最常用的简写命令
  • /cmodify 玩家 给玩家共享该上锁方块 玩家名前面加上"@"的话，共享之后他还可以给别人共享

权限：
    lwc.protect - 允许玩家创建和管理自己的保护。它也允许他们使用启用模式和标志。
    lwc.mod - 允许玩家打开【任何】箱子，但不能解锁它们。
    lwc.admin - 管理员权限 - 这个权限应该被视为危险的，如果使用不当，因为这个权限可以给权限拥有者摧毁每一个受保护的方块的权力，仅仅通过一个命令！
    lwc.deny - 让拥有此权限的用户无法访问任何LWC可以保护的东西，例如：使其无法打开或破坏任何上锁的或未上锁的箱子，熔炉等等这个插件可以保护的东西（感谢@Jim_game  翻译）

由于帖子已无法查看，现贴出方法：
打开core.yml配置文件，拉到底，找到：
modes:
    droptransfer:
        enabled: false

        # allow items to be transferred across world boundaries
        crossWorld: false
将 enabled: true 改成 enabled: false 即可。
12-08 : 插件内配置已更新，现默认关闭该功能。

如何添加MOD方块的自动/手动加锁：
打开LWC插件的配置文件 core.yml 找到如下字段
protections:
    denyRedstone: false
    denyHoppers: true
    autoRegister: false
    ignoreBlockDestruction: false
    ignoreLeftClick: false
    ignoreRightClick: false
    ignoreExplosions: false
    allowEntityBreakDoor: false
    allowEntityInteract: false
    quiet: false
    readonly-modify: false
    readonly-remove: false
    blocks:
        chest:
            enabled: true
            autoRegister: private
        furnace:
            enabled: true
            autoRegister: private
        dispenser:
            enabled: true
            autoRegister: private
        sign:
            enabled: true
            autoRegister: private
        wooden_door:
            enabled: true
        iron_door:
            enabled: true
        trap_door:
            enabled: true
        fence_gate:
            enabled: true
        trapped_chest:
            autoRegister: private
            enabled: true
#下面这样的是放下自动落锁的。
        4036:*:
            enabled: true
            autoRegister: private
#下面这样的是不自动加锁，但是输入/lock右键该方块可以直接加锁。
        1404:*:
            enabled: true
#就和原来自带的写法格式一样按照上面的样子写进去就行了，方块ID自己找。
        1404~1:
            enabled: true
#波浪号表示只给1404:1 这个方块开启加锁功能，但不自动。
