作者: 秋韵    时间: 2020-1-31 17:56
来个异步呗
new BukkitRunnable()
{
  public void run()
  {    代码
  }
}.runTaskTimerAsynchronously(你的插件Plugin,60,60);

这个是bukkit自带的定时器，当然你用timer也可以
那两个60是ticks mc的游戏时刻
60=3秒
当然你想只执行一次的话
你在run()方法体里面加个this.cancel()并且判定ticks到60时关闭定时器
就可以实现你所说的功能了
这玩意是异步的，就算自己卡死了服务器也可以玩不用担心
