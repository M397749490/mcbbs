essentials.build 权限中拥有很多子权限，如下：
Various        None        essentials.build        当使用权限系统时允许玩家进行建造，但不支持建造切换。
Various        None        essentials.build.break.<id>[:datavalue]        允许破坏某种方块
Various        None        essentials.build.craft.<id>[:datavalue]        允许合成某种方块或物品
Various        None        essentials.build.drop.<id>[:datavalue]        允许丢掉某种方块或物品
Various        None        essentials.build.interact.<id>[:datavalue]        允许玩家对某种方块或物品进行交互
Various        None        essentials.build.pickup.<id>[:datavalue]        允许玩家拾取某种方块或物品
Various        None        essentials.build.place.<id>[:datavalue]        允许玩家放置方块

如果将 essentials.build 禁用的话，其下的所有子权限都将被禁用，其中包括 essentials.build.interact.<id>[:datavalue]        （允许玩家对某种方块或物品进行交互）。

如果不想让玩家进行拆方块或者放置方块的话，把 essentials.build 权限删掉然后将 essentials.build.place.* 以及 essentials.build.break.* 设置成 false 即可。
