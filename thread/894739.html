功能描述：
每隔一段时间在用户游戏界面上显示配置好的提示信息，可配置多条，每次显示一条，每次间隔时间为配置时间，默认15秒。消息支持颜色代码与文本格式代码，具体支持代码见配置文件。

配置文件：
  1. # tips 显示时间间隔，单位为秒
  2. interval: 15

  4. #消息代码:
  5. #  颜色代码:
  6. #    §0: 黑色
  7. #    §1: 深蓝色
  8. #    §2: 深绿色
  9. #    §3: 墨绿色
  10. #    §4: 深红色
  11. #    §5: 深紫色
  12. #    §6: 金色
  13. #    §7: 灰色
  14. #    §8: 深灰色
  15. #    §9: 蓝色
  16. #    §a: 绿色
  17. #    §b: 浅绿色
  18. #    §c: 红色
  19. #    §d: 浅紫色
  20. #    §e: 黄色
  21. #    §f: 白色
  22. #  格式代码:
  23. #    §l: 加粗
  24. #    §m: 删除线
  25. #    §n: 下划线
  26. #    §o: 斜体
  27. #  §r: 重置所有之前的颜色与格式

  29. # 代码与文字之间要用空格

  31. #tips:
  32. #  - 提示消息1
  33. #  - 提示消息2
  34. tips:
  35.   - §c小窍门： §r使用带有§0§l时运§r附魔属性的稿可以在挖掘钻石矿时获取更多的钻石
  36.   - §c小窍门： §r使用带有§0§l效率§r附魔属性的稿可以在挖掘时能更快的破坏方块
