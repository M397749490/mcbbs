插件简介

这个插件我大概就是，每过一段时间，服务器会发出一段话

你把鼠标移动到这句话上，你就可以看到一串字符（可以自定义）

你在聊天框中打出这串字符

你就可以获得相应的奖励（可自定义）

这个插件大概可以用来当在线奖励，哪个在线玩家手速快，谁就拿得到奖励

配置详解
  1. # ChatReaction version 1.7.1 configuration file
  2. debug: false
  3. #是否开启debug
  4. check_updates: true
  5. #是否开启自动跟新
  6. reaction_stats:
  7. #以下都是数据库设置
  8.   track_stats: false
  9.   top_players_size: 100
  10.   hostname: localhost
  11.   port: 3306
  12.   database: chatreaction
  13.   prefix: ''
  14.   username: root
  15.   password: ''
  16. reaction:
  17. #以下是游戏设置
  18.   interval: 500
  19. #每次比赛的时间间隔，以s为单位
  20.   time_limit: 30
  21. #每次比赛的时长，以s为单位
  22.   players_needed_to_start: 1
  23. #每次比赛开始需要的玩家
  24.   word_character_length: 10
  25. #比赛的单词长度
  26.   ignore_case: false
  27. #是否忽略大小写
  28.   use_custom_words: true
  29. #是否使用自定义单词，自定义单词可以在words.txt里面添加
  30.   split_words_by_line: true
  31.   scramble_custom_words: true
  32.   scramble_at_random: true
  33.   scramble_spaces: false
  34.   disabled_worlds:
  35.   - world_nether
  36.   - world_the_end
  37.   reward_amount: 2
  38.   rewards:
  39. #答出的奖励
  40.   - eco give @p 500
  41.   - give @p diamondblock 100
  42. messages:
  43. #消息设置
  44.   reaction_start:
  45.   - '&8[&e&l手速比赛&8] &b移动到这句话上去查看信息'
  46.   reaction_start_tooltip: '&f%word%'
  47.   scramble_start:
  48.   - '&8[&e&l手速比赛&8] &b移动到这句话上去查看信息'
  49.   scramble_start_tooltip: '&f%word%'
  50.   reaction_end:
  51.   - '&8[&e&l手速比赛&8] &c没有人能在30s内打出这些字符 &4:('
  52.   scramble_end:
  53.   - '&8[&e&l手速比赛&8] &c没有人能在30s内打出这个迷 &4:('
  54.   - '&c这个迷是 &f%word%'
  55.   reaction_win:
  56.   - '&8[&e&l手速比赛&8] &f%player% &a在&f%time%&fs &a内打出了这些字符!'
  57.   scramble_win:
  58.   - '&8[&e&l手速比赛&8] &f%player% &a在&f%time%&fs &a内打出了这些字符!'
  59. hooks:
  60.   qaplugin:
  61.     enabled: true
  62.     hint:
  63.       charge: true
  64.       charge_amount: 100.0
