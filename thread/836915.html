Minecraft原版的台阶、漏斗都是手动计算了旋转过后的碰撞箱，非常的蛋疼+麻烦
MinecraftForge 论坛有一个坏掉的方案，然后修改了一下（主要是在正数区域的方块碰撞箱旋转180度+会出问题）、
http://www.minecraftforge.net/forum/topic/41536-1102aabbsolvedis-there-an-utility-method-to-rotate-an-aabb/

适用于 MC 1.12.x 和 Java 8
也许低版本能用，但是不保证



原理

其中TransformationUtils用来计算旋转矩阵（利用j avax.vecmath）虽然说有很多方法都用不上
然后ExtendedAABB继承了原版的AxisAlignedBB，之后所有的代码里面用ExtendedAABB这个类就行了

rotate方法调用后，先把自生移到origin
  1. this.offset(-0.5d, -0.5d, -0.5d)
复制代码

因为大部分情况下碰撞想是在 (0, 0, 0) 到 (1, 1, 1)
这样的话沿着origin的旋转矩阵就会把碰撞箱移到负数区域

之后就是生成旋转矩阵，同时对较小顶点和较大顶点作变换

  2. Vector3d min = new Vector3d(source.minX, source.minY, source.minZ);
  3. Vector3d max = new Vector3d(source.maxX, source.maxY, source.maxZ);
  4. transformation.transform(min);
  5. transformation.transform(max);
复制代码


最后再
  1. this.offset(0.5d, 0.5d, 0.5d)
复制代码

移动回正数区域

  11. public class TransformationUtils {

  13.     public static Matrix4d createIdentityMatrix4d() {
  14.         Matrix4d identity = new Matrix4d();
  15.         identity.setIdentity();
  16.         return identity;
  17.     }

  19.     public static Matrix4d combineTransformations(Matrix4d... transformations) {
  20.         Matrix4d result = createIdentityMatrix4d();
  21.         for (Matrix4d transformation : transformations) {
  22.             result.mul(transformation);
  23.         }
  24.         return result;
  25.     }


  28.     public static Matrix4d getTranslationMatrix(double dx, double dy, double dz) {
  29.         Matrix4d translation = createIdentityMatrix4d();
  30.         // [ 1 0 0 dx ]
  31.         // | 0 1 0 dy |
  32.         // | 0 0 1 dz |
  33.         // [ 0 0 0 1  ]
  34.         translation.setM03(dx);
  35.         translation.setM13(dy);
  36.         translation.setM23(dz);
  37.         return translation;

  41.     public static Matrix4d getRotationMatrix(Axis axis, int degrees) {

  45.     public static Matrix4d getRotationMatrix(Axis axis, double radians) {
  46.         Matrix4d rotation = new Matrix4d();

  48.         Vec3i direction = EnumFacing.getFacingFromAxis(AxisDirection.POSITIVE, axis).getDirectionVec();
  49.         // Rotation matrix calculation is done in Matrix4d#set(AxisAngle4d), the object is just used
  50.         // to pass in parameters
  51.         rotation.set(new AxisAngle4d(direction.getX(), direction.getY(), direction.getZ(), radians));
  52.         return rotation;
  53.     }
