模组安装
现有1.12.2和1.14.4两个版本的模组。1.12.2版本使用Forge加载，不需要前置模组。1.14.4版本使用Fabric加载，需要fabric-api模组作为前置。此外Fabric版本建议使用Mod Menu模组，它可以让您像使用Forge一样使用图形界面调整模组配置文件。
模组发布在 CurseForge。由于是国外网站速度较慢，如果打不开也可以直接 加群 下载。

安装完成后，请将下载的模型解压放在“.minecraft”下名为“custom-models”的文件夹中（如果是服务器，它与server.jar在同一文件夹下）。 一个模型可以是一个文件夹或者一个zip文件，其中包含model.json和其他贴图文件。 在游戏中使用快捷键可以打开模型选择界面（默认为Ctrl+M），或者也可以使用命令选择模型。最终的文件夹结构如下所示


  • .minecraft
  • └ custom-models
  •    └ alex
  •       └ model.json
  •       └ alex.png
  •    └ steve.zip
  •       └ model.json
  •       └ steve.png


如何建模
每个模型都是一个文件夹或一个zip文件，它必须包含一个名为“model.json”的主JSON文件。贴图文件均存储于根目录，并且必须保存为PNG格式。 有关JSON模式的更多信息，请参考 Wiki，并可下载其他模型文件以供参考。


指令
/custommodel是该mod添加到游戏的唯一指令。它具有以下的子指令：
  • reload <player>：从文件中重新加载模型。 当在游戏运行时修改模型文件后，可以使用此命令重新加载它们。player可省略以为自己重载模型。
  • refresh：在游戏运行时添加或删除模型后，通知模组刷新模型列表。
  • select <model_id> <player>：为玩家player选择ID为model_id的模型。player可省略以为自己选择模型。
  • list：列出当前加载的所有模型。 之后通过点击聊天栏的输出内容即可获得模型选择指令。
  • clear <player>: 清除玩家当前的模型。如果在配置文件中指定了默认模型，则切换到默认模型。player可省略以清除自己的模型。
  • npc <model_id>: 为了兼容 自定义NPC模组 而提供的指令。当创建了使用CPM Male或CPM Female模型的NPC时，使用此指令可为距离玩家最近的一个NPC选择模型。
此外请注意，如果您加入了一个未安装此模组的服务器，您将无法使用这些指令。此时请使用内置的模型选择界面。这些指令的使用权限可以自行设置。


常见问题
Q：我想要一些新功能/报告一些bug！

A：您可以在 Github 提出新问题。 或者，可以通过 QQ群 或者 Discord 与我联系。


Q：这是客户端模组还是服务器模组？**

A：两者都是。 您可以只在客户端安装，这样只有您自己才能看到自定义模型。 或者，您也可以在服务器使用，使每个安装有此模组的每个玩家都能看到新模型。
