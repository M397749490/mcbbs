Install[安装]

  • 【重要】请备份你的存档
  • 【重要】【针对于旧版用户】升级时请删除旧的插件及配置，不要保留
  • 【强迫症充数】丢到插件安装目录后重启服务器
  • 【very重要】请确定您的服务器版本是：CB 1.6.2-R0.1【其他版本没试，因为电脑带不起...如果有小伙伴能帮我测试下就好了】
  • 【也比较重要】需要Vault 以及 BoardAPI 前置








Create&Play[创建&游玩]



创建：



系统定义：


  • 站位自己站就好了。。。
  • 指令： /tntsweeper setboard [游戏难度] [游戏场地名字]
  • 难度分别有：easy[简单]|medium[一般]|hard[困难]



自定义难度：


不得不吐槽，还要自己取坐标。。作者也会偷懒。。

  • 站位
  • 使用指令/tntsweeper setboard custom [游戏场地名字] [x] [y] [p]
  • x/y分别指坐标【意义不明，估计是建设起始坐标】
  • p是生成TNT的概率，默认0.15【15%，参数提交请用小数形式，不要作死写大于等于1或者小于等于0什么的】







游玩：





和扫雷的玩法极其相似，不赘述游戏具体方法。



查看可用游戏场地： /tntsweeper list

开始游戏：/tntsweeper play [游戏场地名字]

围观游戏:/tntsweeper spectate [游戏场地名字]

查看附近多少雷【此处要提一下，所占九宫格中有多少雷】：/tntsweeper legend

指令表：

  • 其实/tntsweeper /ts /tsweep都可用，如果单独打就是显示帮助列表，下面为了方便不打斜杠，指令用ts代替
  • ts help —— 同上
  • ts play [游戏场地名字]  —— 开始游戏 【tntsweeper.player】
  • ts list ——列出场地【tntsweeper.player】
  • ts spectate——围观扫雷【tntsweeper.player】
  • [在开始游戏中未提及]ts quit  —— Go die 【退出游戏】
  • ts setboard ——创建一个游戏场地 【OP默认拥有，或者有tntsweeper.admin权限的人，下面指令不赘述权限】
  • ts delboard——让这个场地GO DIE
  • ts reload——重载配置


Config.yml详解：

Config:  
   DefaultBoard: default /名字为default的场地.
   NoInvToJoin: true //如果这个值为true，玩家必须清空背包
   QueueCountDown: 5 //游戏开始倒计时，然并卵
   Announce: true //如果有人赢这局游戏，全服通告
   EndTeleport: false //如果为false, 玩家将被tp回以前的位置. 否则使用 /setlobby 设置【然而这没有这个指令】
Boards:
  default:
    Location: world,-335,2,681
    Size:
      Prob: 0.15 //TNT 生成概率
      H: 8 //游戏场地大小，下同
      W: 8
     PrizeMultiplier: 1.0 //奖励 = 清除TNT数量*当前值
