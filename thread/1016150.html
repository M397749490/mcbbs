　介绍 Introduction　



  • 这个模组灵感来源于史诗攻城
  • 苦力怕也有特殊技能了:"炸毁墙壁"
  • 即苦力怕与玩家之间有方块阻挡就会自爆
  • 也有可能会自然生成闪电苦力怕
  • 苦力怕能够跳向目标
  • 爆炸能引起火灾
  • 苦力怕的感知(视野)能力将得到加强
　配置 Config　







    3. [general]
    4.         #自然生成闪电苦力怕几率
    5.         #范围: 0.0 ~ 1.0
    6.         powered_prob = 0.3
    7.         #苦力怕是否拥有跳跃能力
    8.         can_leap = true
    9.         #苦力怕是否能引起火灾
    10.         fire_explosions = true
    11.         #苦力怕最大感知(视野)距离 (32 = 原版)
    12.         #范围: 0.0 ~ 2048.0
    13.         follow_range = 64.0
    14.         #苦力怕是否能破坏墙壁
    15.         can_break_walls = true
