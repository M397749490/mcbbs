简单的说呢，就是一个大炮插件，不过是计算角度从天而降，非手持

可自定义使用插件需要支付的物品/金钱

可配合WorldGuard插件保护安全区域

可选插件：Vault(支付金钱使用)、WorldGuard(对不支持的区域禁止使用)

目标点不能超过 120 格

因为是从天而落，所以不能在封闭的环境下使用
默认迫击炮ID是280，也就是木棍。可自行修改。

命令：
  1. /mortar <on|off>: 启用/禁用插件
  2. /mortar setpower <整数>: 设置功率(最大10).
  3. /mortar showpower: 显示功率.
  4. /mortar help: 帮助菜单.
  5. /mortar reload: 重载配置.
复制代码


权限：
  1. mortar.use - 使用权
  2. mortar.* - 全部权限
复制代码

  1. Mortar:   
  2.     # 最大功率
  3.     MaxPower: 5
  4.     # 默认功率

  6.     # 迫击炮ID
  7.     Mortar-Item: 280
  8.     # 放火
  9.     SetFire: True
  10. Costs:

  12.     PayForShots: false
  13.     # 需要支付物品
  14.     UseItems: false
  15.     # 需要支付金钱
  16.     UseEconomy: false
  17. PayWithItems:
  18.     # 需要支付物品ID
  19.     Item: 266

  21.     Amount: 1

  23.     # 支付金额
  24.     Amount: 10.0

  26. UseWorldGuard: false

  30.     ShootingWarnings:

  40.         Use: true
