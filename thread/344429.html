Hi大家好，我是末影矿工。相信很多人都看过指环王三部曲，于是我就根据电影内容做了一个官方逼死mod（和MC里的魔戒mod不一样）。这个系统主要是完成戴上魔戒会隐身的效果。
------------------------------------------<分界线>------------------------------------------
视频（视频中还有一个将魔戒丢入岩浆中会tellraw玩家的功能已删除，应为有时会出现bug）：
http://v.youku.com/v_show/id_XNzkyMDM1NjQw.html
[size=14.4444446563721px]------------------------------------------<分界线>------------------------------------------
首先创建变量Ring
  1. /scoreboard objectives add Ring dummy
复制代码
然后用高频连上一下两部分命令方块
第一部分：
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:0b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:0}
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:1b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:1
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:2b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:2
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:3b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:3
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:4b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:4
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:5b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:5}
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:6b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:6
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:7b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:7
复制代码
[size=14.4444446563721px]
  1. scoreboard players set @a Ring2 1 {Inventory:[{Slot:8b,id:minecraft:golden_apple,Damage:1s}],SelectedItemSlot:8}
复制代码


第二部分：
  1. scoreboard players set @a[score_Ring2_min=1] Ring2 0
复制代码
  1. effect @a[score_Ring2_min=1] minecraft:invisibility 1 1 true
复制代码
第一部分就是讲当玩家手持魔戒（附魔金苹果）的时候，会给该玩家的Ring2值设为1，第二部分就是当玩家Ring2为1的时候给玩家一秒钟的无烟雾的隐身，并且当玩家Ring2大于1后就将Ring2设为0。这样就行了，只要手里拿着魔戒，自己就会隐身（金苹果隐身不了），不拿过一会就还原了。
