简介：
作者原话：一个可配置的插件,它允许您可以使用一个压力板作为把地雷陷阱,一步、爆炸、燃烧、拆除。这个额外的特性可以用于娱乐和PvP。（翻译）
俺的话：将压力板变成地雷！然后Boom shakalaka{:10_508:}

用法：1.准备一个压力板。
2.输/kb toggle  开启放置地雷模式。
3.放置一个压力板。
4.等待玩（dou）家（bi）踩上去！！
5.Boom！！！~~~
6.再次输入/kb toggle  关闭放置地雷模式。

指令：
/kb help-显示帮助
/kb toggle-开启/关闭放地雷模式

权限：
kaboom.enable-允许使用此插件的功能

配置文件：
  1. LandMine:
  2.   WOOD_PLATE:
  3.     Damage: 3.0  
  4. # 爆炸能量，TNT为4.0
  5.     SetFire: false
  6. #是否产生火焰
  7.     BreakBlock: false
  8. #是否破坏方块
  9.   STONE_PLATE:
  10.     Damage: 5.0
  11.     SetFire: true
  12.     BreakBlock: true
  13.   IRON_PLATE:
  14.     Damage: 7.0
  15.     SetFire: false
  16.     BreakBlock: false
  17.   GOLD_PLATE:
  18.     Damage: 10.0
  19.     SetFire: true
复制代码
