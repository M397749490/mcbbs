正式版是Minecraft经过一段时间的预览版测试之后得到的稳定版本，也是众多材质、Mod与服务器插件会逐渐跟进的版本。官方正版登陆器也会第一时间进行推送。

建议玩家与开服的朋友关注其相关服务端、Mod、插件、与API的更新，迎接新的正式版吧！ 专注于单人原版游戏的玩家可立即更新，多人玩家请关注您所在的服务器的通知。

Minecraft Java版 1.14.1 Minecraft Java Edition 1.14.1
一个 Minecraft Java版 正式版 A Minecraft Java Edition Release

Today we're releasing 1.14.1, a small release that addresses some issues left over from 1.14.?We do plan on releasing a 1.14.2 to address further issues whilst we work on the next major update, 1.15.
今天我们发布了 1.14.1，一个处理了一些 1.14 遗留问题的小更新。我们计划在制作下一个大更新 1.15 的同时发布 1.14.2 以修复更多的问题。

1.14.1 的更改 CHANGES IN 1.14.1

  • Fixed bugs
  • 修复漏洞
  • Performance improvements
  • 性能提升
  • Arrows on fire can now light campfires
  • 着火的箭现在可以点燃营火了

  • MC-151057- Redstone components sometimes don't get updated properly
