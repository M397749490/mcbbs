    ②简介:
基本的比赛模式如下：
·[Arena] 赤手空拳竞技模式: 战斗如何取决于你如何修改你的config配置文件。但是！你不能在这种战役里拿任何武器、工具，也不能带走它们（呜呜呜无偿经济劳资不玩了！什么？可以设置奖励钱钱？！）。<无法复活，1v1模式>
·[Skirmish] 手有寸铁竞技模式: 这次就比第一种好多啦，可以想带什么武器、工具就带什么（别想方块了，放置不了的~），也是一对一作战，赢的一方带走对手的掉落物，并带走配置文件里设置的相应的胜利时获得的钱钱~<无法复活，1v1模式>

·[Battlegrounds] 团队竞技模式: 最多允许四个团队(Teams)的人同时竞争，一分钟后杀敌最多的团队胜利，可以携带武器与工具，战斗胜利后那个团队带走相应的钱钱，时间短暂请速战速决！<可以复活，团队模式>



·[Colosseum] 罗马竞技场（歼灭）模式: 必须四个团队同时竞争相互厮杀，战到最后的同一组成员或玩家获胜，整个团队都会获得奖励，可以任意携带工具哦！<无法复活，团队模式>


·[FFA] 个人死亡竞技模式: 可以很多个人一起参加这种模式的比赛，没有团队的划分，所有人一起厮杀，依然是站到最后的人赢得比赛，可以带工具、带走钱钱什么的这种事就不用我反复强调了吧。。。<无法复活，角斗模式>


·[Deathmatch] 个人竞赛模式: 类似于某毛线里面的个人竞技模式，多人参加竞赛，比赛时间只有2分钟，战斗结束后击杀最多的那个人获得胜利。<可以复活，角斗模式>

1、如何创建一个竞技场：


首先你得要先搭建一张像样的游戏地图，这就不用说了吧？


第①种情况——如果你想让这张地图的游戏模式为Arena赤手空拳竞技模式这种1v1的竞技模式，那么你要站在你想要让玩家出生的第一个地区的方块上输入/arena create <竞技场名字>；然后站在你要设置的第二个出生点的方块上输入/arena alter <竞技场名字> 2，如果你想让他们不出生在同一个地区请在第三/四/五......个方块上依次输入/arena alter <竞技场名字> 3/4/5 ，这样你就可以创建无数个出生点，最好不要挨的太近，否则那个玩家一出生就被虐死了骂你op不关我事......


也就是说，一个游戏模式可以创造无数个竞技场。


第②种情况——那么如何创造像Battlegrounds这样的团队的竞技模式呢？要像下面这样做：同上，站在第一/二/三/四个出生点的方块上输入/battlegrounds alter <团队竞技场名字> 1/2/3/4 ；注意，此时原本的'arena'变成了'battlegrounds'，而且！团队竞技模式只能设置4个出生点！设置多了发生什么错误不关我事！


第③种情况——最后就是角斗竞技模式了，这种创建竞技场的方式也十分简单，例如FFA模式，一般来说角斗模式都会有许多玩家一起玩，那就站在第一/二/三/四/五/六/七/八......个出生点的方块上输入/ffa alter <角斗竞技场名字> 1/2/3/4/5/6/7/8 就完成了。


怎么样，创建一个/多个竞技场是不是很简单？最后总结并提出几点重要的事项：
· 创建不同的竞技模式的出生点，就要输入:  /arena(skirmish/battlegrounds/colosseum/ffa/deathmatch) alter <竞技场不同名字> 1/2/3/4/5/6/7/8/9......
· 切记不能让任意两个竞技场名字相同，否则会错误！
· 在<竞技场名字>与后面的数字之间是有空格的，例如：/arena alter myarena 1/2/3/4。
· 创建出生点时第一个出生点是没有1的，像这样:  /arena create myarena   就已经是第一个出生点了！
· 这些竞技场最好都设置在同一个世界里，至于为什么...等等再说吧~

4、如何发起一场决斗:


在很多RPG游戏里面，总少不了决斗(Dueling)的存在。没错！BA竞技场插件正好拥有者这个强大的娱乐功能！说到这里我又忍不住要大力地推荐一下Chest Commands箱子GUI图形界面菜单插件了。（引用ImagineBreaker的帖子）这个插件强大到可以以菜单界面让玩家简便地使用指令。当然！它与我们的BA插件完美兼容，你可以用它来引导你的玩家们进入竞技场的游戏，但是！由于决斗功能指令的特殊，这个就无法执行啦！（那你说这个干什么 魂淡！）现在我们来看看决斗功能的指令：

· 与一个/多个指定的玩家决斗：这时我们需要输入：/<竞技模式> duel <玩家名> 。这样你们就会进入这个竞技模式的随机一个地图进行决斗。例如：/arena duel doubi   。这样你就会跟一个名为"doubi"的玩家进行arena决斗。（团队决战的话需要队长输入:/<团队竞技模式> duel <对方队长名>）你还可以轮番跟别人进行决斗，只需输入：/<(团队)竞技模式> duel <玩家1> <玩家2> <玩家3> 。例如：/arena duel doubi dadoubi shabi 。


· 对决斗下注：平时的决斗我们是没有任何收益的，但是！我们有强大的下注功能！这样我们就能与对方进行有偿决斗。指令如下：/<(团队)竞技模式> duel <玩家> <你服务器里的货币> <钱数> 。比如说假如我服务器的货币是'IQ'，那么我需要输入：/arena duel doubi IQ 100 。这样我就对玩家‘doubi’发起了一次赌注为100元的竞技场挑战。要是他接受了，那么他也得支付100IQ与我决战。谁赢了谁带走全部的钱~~~

· 对决斗作出的选择：一般来说，选择就那么几个：收回决斗，拒绝和接受。首先是收回决斗，如果你女朋友突然间喊你回家吃饭了！你不能在那瞎悠悠了！你必须收回决斗！（这不是不可能的，自己找结婚插件吧233）你就要输入:/arena rescind来收回你刚刚所下的决斗请求。       如果要接受别人的决斗，请输入：/arena accept ，拒绝请输入/arena reject。这这么些。

④权限：（先感谢一下12楼的653224281同学对我的提醒，以下是原文的权限文件）



离开竞技场的权限：
perm: arena.leave

加入竞技场的权限：
perm: arena.join.<game>
examples:

  • arena.join.arena
  • arena.join.skirmish
  • arena.join.colosseum
  • arena.join.battleground
  • arena.join.tourney
  • arena.join.freeforall
  • arena.join.deathmatch

职业系统权限：
arena.class.use.<classname>例如：
  • arena.class.use.gladiator
  • arena.class.use.monk


决斗功能方面的权限：

  • arena.duel.<type>

例如：
  • arena.duel.skirmish
  • arena.duel.spleef
  • arena.duel.arena
  • arena.duel.deathmatch
  • arena.duel.colosseum
  • arena.duel.battleground

Exempting players from being challenged to a duel
If you don't want to be challenged add the following permission to the player/group

  • arena.duel.exempt

其他与BA相兼容插件的使用权限：
It's the same as above only substitute the name of the new type Examples:

  • arena.join.paintball : for paintball
  • arena.join.spleef : for spleef
  • arena.join.ctf : for ArenaCTF (Capture the Flag)

团队方面相关功能的权限：
If you want players to be able to create their own teams, for example to always play with a certain friend. The players will need the following permissions.

  • arena.team.create
  • arena.team.join

管理员的权限：
Permission to create,delete, etc. You can either be op or have the following
perm: arena.admin

如何给玩家加入权限：
(Default) If you don't have a permissions plugin
You can use this as a starting point for your server. Copy this
[| Example permissions.yml]
and put it into your servers permission.yml. Then change as you want later.

bPerms
You need to add the permissions to whatever your default group is. First you select the group you want to add then you add the perm.

  • /group <default group>
  • /group addperm <perm>
Example assuming you want to add to the group "default".

  • /group default
  • /group addperm arena.join.arena
  • /group addperm arena.join.spleef
  • /group addperm arena.join.skirmish

PermissionsEx
You need to add the permissions to whatever your default group is.

  • /pex group <group> add <permission>
Examples (if my default group was called players)

  • /pex group players add arena.join.skirmish
  • /pex group players add arena.join.ctf
  • /pex group players add arena.join.paintball

如何用Group Manager插件加入权限(重点因此翻译)：
输入指令的使用方法：

  • mangaddp <group> <permission>
例子如下：

  • /mangaddp players arena.join.battleground
  • /mangaddp players arena.join.colosseum
  • /mangaddp players arena.join.ctf
