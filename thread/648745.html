标题: 回到死亡点后怪不消失被守尸
  以前服务器在被怪杀死后用back回去怪会被清除掉，但最近不知怎么回事怪不消失了，被杀后back回到点无限被守尸。
  还有一个问题服务器以前输入tpa一个玩家的id开头字母后按tab他会自动补全那个人的全名,但现在不管用了是怎么回事？

作者: 1962853568    时间: 2016-11-16 22:49
/mvm set monsters false
/mvm set animals false
关闭怪物动物生成，需要mv插件

/gamerule doMobSpawning false
关闭自然生成
就可以关怪了
