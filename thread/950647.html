2、可以的，以下是命令（顺序从下往上，我之前无聊做了这个系统，版本1.14）
execute as @a[tag=Q] run tag @s remove Q（删除标签）
execute as @a[tag=Q] run kill @e[type=minecraft:armor_stand,tag=M,limit=1]（命令执行完毕后，删除盔甲架）
tp @a[tag=Q] x y z(坐标)(选择器用这个@a[tag=Q])（想堆堆多少）

execute as @a[tag=Q] run clear @s bed (创造) （如果是创造模式想执行一次扣除一个物品，就写这条指令，如果是其他模式则不用）
execute as @e[type=minecraft:armor_stand,tag=M] if data entity @s {HandItems:[{id:"minecraft:bed",Count:1b}]} run tellraw @a {"text":"咻！","color":"yellow","bold":"true"}（检测盔甲架手上有没有拿指南针（玩家右击以后）（后面这段话是我测试用的，可以随便改））
summon minecraft:armor_stand ~1 ~ ~ {Tags:["M"],NoGravity:1b,CustomNameVisible:0b,Invisible:1,ShowArms:1,Rotation:[0f],Pose:{Head:[0f,0f,0f],Body:[0f,0f,0f],LeftArm:[0f,0f,0f],RightArm:[0f,0f,0f],LeftLeg:[0f,0f,0f],RightLeg:[0f,0f,0f]},Brain:{memories:{job_site:{pos:[I;0,0,0],dimension:"minecraft:overworld"}}}}（召唤一个盔甲架以实现右击检测，这是装置的核心）
execute as @a if data entity @s {SelectedItem:{id:"minecraft:bed"}} run tag @s add Q（这是检测玩家手上是否拿着床（bed）换成别的也行，如果是就给他一个标签Q）
----------------------------------------------------------------------------------------------------------------------------(分割线表示一个命令组)

----------------------------------------------------------------------------------------------------------------------------(分割线表示一个命令组)
execute as @a[tag=Q] unless data entity @s {SelectedItem:{id:"minecraft:compass"}} run tag @s remove Q(把这名玩家的Q标签删除)

3、选取一些右键有特殊属性的方块，这里不阐述，你也可以像楼上说的用告示牌，命令如下：
创建一个计分板:/scoreboard objectives add C trigger
/setblock ~ ~ ~ minecraft:oak_sign{Text1:'{"text":"点我传送","color":"green","bold":"true","clickEvent":{"action":"run_command","value":"trigger C set 1"}}"}'}(生成一个告示牌)
----------------------------------------------------------------------------------------------------------------------------(上面部分手打就行)
scoreboard player set @a[scores={C=1..1}] C 0 (分数归零避免循环tp)
tp @a[scores={C=1..1}] x y z(传送位置)   (传送玩家)----------------------------------------------------------------------------------------------------------------------------
或者你也可以参考第2个问题，把盔甲架放在这个方块前，不要循环tp即可
4、就先假设每秒(20ticks)增加1个口渴值，口渴值满100后算脱水，站在水里每秒(20ticks)减少1个口渴值
创建一个计分板:/scoreboard objectives add thirst dummy    （口渴值）
/scoreboard player set @a thirst 0  (将口渴值设为0)
/scoreboard player set 对照 thirst 0  (与上面进行对照用的)
/scoreboard player set 对照1 thirst 100  (与上面进行对照用的)
再创建一个计分板:/scoreboard objectives add tick dummy    (计时的)
/scoreboard player set 对照 tick 20  (与上面进行对照用的)
又创建一个计分板（统计喝牛奶）
/scoreboard objectives add drinkmilk minecraft.used:minecraft.milk_bucket
/scoreboard player set 对照 drinkmilk 1  (与上面进行对照用的)
----------------------------------------------------------------------------------------------------------------------------(上面部分手打就行)
scoreboard player add 计时 tick 1 (每秒流动，因为循环命令方块每秒执行20次，所以tick计分板的每20分代表1秒)
execute as @a if score 计时 tick >= 对照 tick run execute if score @s thirst >= 对照1 thirst run execute as @a unless block ~ ~ ~ water run scoreboard player add @s thirst 1   (增加口渴值，中间多了一个if，目的是为了防止出现超过100的情况)
execute as @a if score 计时 tick >= 对照 tick run execute if score @s thirst > 对照 thirst run execute as @a if block ~ ~ ~ water run scoreboard player remove @s thirst 1    (减少口渴值，中间多了一个if，目的是为了防止出现负数)
----------------------------------------------------------------------------------------------------------------------------(分割线表示一个命令组)
execute as @a[scores={drinkmilk=1..1}] run socreboard player set @s drinkmilk 0    (重置喝牛奶的次数)
execute as @a if score @s thirst = 对照1 thirst run execute if score @s drinkmilk = 对照 drinkmilk run kill @s   (检测玩家口渴度为100时是否喝牛奶，如果是，就kill)
