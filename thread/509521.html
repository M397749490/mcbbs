VT Timer Plus
Developed by SaraLab

关于插件
________________________________________________________________
插件由Sara实验室小组成员 RaycusMX 开发，
用于扩展 VariableTriggers 插件的Timer功能。
目前只支持VT1，不支持VT2！
(VT2一般好像也用不着)

________________________________________________________________


插件功能
________________________________________________________________
使用VT1的服主可能会发现它的Timer并不好用，
因为它每分钟才触发一次，对于大部分情况来说实在太长了。
安装本插件后，通过修改配置文件可以扩展Timer功能，
数量、开关、周期、运行的世界、运行的VT脚本全都可以自定义。
最快可达1 tick/次。
VT脚本：
  1.     - '@BROADCAST &6[VTTimerPlus] <worldname>'
复制代码
  1.     - '@BROADCAST &5[VTTimerPlus] <worldname>'

使用说明
________________________________________________________________
1) 命令
/vttp [help| ?] 显示帮助信息
/vttp reload 重载配置文件
/vttp save 保存配置
/vttp list 列出所有有效的Timer
/vttp stopall 停用所有正在运行的Timer
/vttp runall 启动所有有效的Timer
/vttp stop [TimerName] 停用一个有效的Timer
/vttp run [TimerName] 启动一个有效的Timer
/vttp setintv [TimerName] [Number] 修改一个有效Timer的触发间隔

2) 权限
全部命令权限：
vttimerplus.help
vttimerplus.reload
vttimerplus.save
vttimerplus.list
vttimerplus.stopall
vttimerplus.runall
vttimerplus.stop
vttimerplus.run
vttimerplus.setintv
OP默认拥有所有权限，vttimerplus.*

3) 配置
config.yml
主要配置文件
AutoSave:
  # 是否开启自动保存
  Enable: true
  # 自动保存间隔，单位秒
  Interval: 300

Timers.yml
自定义Timer配置文件
# 自定义Timer名字
exampleTimer:
  # 是否启动
  Enable: true
  # 触发间隔，单位tick，20 ticks = 1秒
  Interval: 100
  # 指定运行VT脚本的世界，用“$all”表示全部世界
  # 如果脚本中有变量操作，最好只指定一个世界，如world
  Worlds:
  - $all
# Worlds:
# - world
# - world_the_end
  # 指定要运行的VT脚本，脚本必须已被VT加载
  File: example
  Script: TestExample1

#exampleTimer2:
#  Enable: false
#  ...

配置文件请按要求编写，如果出现编写错误，请按照重载后的提示进行修改。
