  1. # 此处列出的世界，它们的设置都会镜像到子世界(继承设置的世界).
  2.        # 第一个元素 'world' 为主世界的名称，同时也是母世界(独立的配置，并镜像给子世界).
  3.        # 其下的元素 'world_nether' 和 'world_the_end' 将使用与母世界相同的user/groups文件
  4.        # 元素'all_unnamed_worlds' 定义了所有未在列表中的世界,同时自动母世界镜像配置文件.<这就是为什么一般情况下，所有世界都共用一种配置，因为它们默认地继承了主世界的配置>
  5.        # 每个子世界都可以选择从母世界镜像的文件， 'groups', 'users' 或是两者皆有.
  6.        world:
  7.          world_nether:
  8.          - users
  9.          - groups
  10.          world_the_end:
  11.          - users
  12.          - groups
  13.          all_unnamed_worlds:
  14.          - users
  15.          - groups
  16.    #  world2:      (world2将会独立 user和groups文件)<此处是关键，后面会有实例>
  17.    #    world3:
  18.    #    - users    (world3将会镜像world2的users.yml文件, 但它的 groups.yml文件将会独立)<自由运用哦~>
  19.    #    world4:
  20.    #    - groups   (world4将会镜像world2的groups.yml文件, 但它的 uset.yml文件将会独立)<自由运用哦~>
  21.    #  world5:
  22.    #    - world6   (此时，world6将完全镜像world5的配置)
