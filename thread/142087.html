-------------------关于环境架设
     由于Minecraft是JAVA语言所编译的游戏，所以在PC上需要有JAVA的JDK支持，下面介绍关于环境的架设：

1.查看系统类型
查看系统类型是为了安装好JAVA相对应的版本，如果版本不对，则会出现以下情况：

Windows查看系统类型的方法有两种：
Windows7查看的方式比较简便，右键点击“计算机”，单机“系统”选项，找到相应行即可。

win7系统.jpg (31.19 KB, 下载次数: 4)

下载附件

2013-7-13 12:35 上传
Windows xp则需要从“命令提示符”中获取信息，步骤：
       打开“命令提示符”（或在“开始”——“运行”中输入“cmd”）——在命令提示符窗口中输入“systeminfo”，如果您的系统是 64位的，会在
“OS 名称:          Microsoft Windows XP Professional”
一行后明确标示出“x64 Edition”
或者在“系统类型”一行出现相应信息（32位则为“X86”）
    或者您也可以在开始>运行中输入“winver”，如果您的系统是64位的，同样会明确标示出“x64 Edition”。

2.安装相应的JAVA
可以到JAVA官网下载最新的JAVA：http://www.java.com/zh_CN/download/manual.jsp
