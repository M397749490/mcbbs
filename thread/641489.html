━━━ 完美无报错BungeeCord端 ━━━

近期，我发现许多腐竹们因为BC的配置文件（config）总是报错无法得到解决，因此我制作了一个可完美防止报错信息的服务端

━━━ 服务端简介 ━━━
1.发生报错，认真检查是否配置错误，修改正确后即可解决报错
2.可使用end关闭并自动重启
3.直接关闭窗口即可，重新开启不会造成报错

━━━ 图片 ━━━


━━━ BC.bat控制台帮助 ━━━
  1. @echo off
  2. title Eailotv_ 简单BungeeCord端
  3. java -Xmx256M -Xms256M -XX:+AlwaysPreTouch -XX:+DisableExplicitGC -XX:+UseG1GC -XX:+UnlockExperimentalVMOptions -XX:MaxGCPauseMillis=45 -XX:TargetSurvivorRatio=90 -XX:G1NewSizePercent=50 -XX:G1MaxNewSizePercent=80 -XX:InitiatingHeapOccupancyPercent=10 -XX:G1MixedGCLiveThresholdPercent=50 -XX:+AggressiveOpts -Dfile.encoding=UTF-8 -jar BungeeCord.jar
  4. exit
