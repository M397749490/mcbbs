第一章第三节：第一个Item和Block
打开上节课的代码，新建两个类
  1. class RunningManItems extends Items
  2. class RunningManBlocks extends Blocks
复制代码

（注意：是Items和Blocks，不是Item和Block类。Items类包含所有原版中Item的对象，Blocks类同理
这两个类分别管理mod的Item和Block，并可以调用原版的Item和Block，这样管理比其他教程在主类管理个人认为更方便一些）
接下来建立第一个Item类
  1. class RunningManIngot extends Item
复制代码
即跑男矿锭，extends Item说明这是一个Item（物品）
在类体中添加构造函数
  1. public RunningManIngot()
  2. {
  3. setCreativeTab(CreativeTabs.tabMaterials);
  4. //设置创造模式所在标签页
  5. //暂时定为这个，后来会改为mod独有的
  6. setUnlocalizedName("RunningManIngot");
  7. //设置未注册名字
  8. //我喜欢与类名相同
  9. //后会用语言文件覆盖
  10. }
复制代码
在RunningManItems中添加
  1. Item running_man_ingot=new RunningManIngot();
复制代码

在主类preLoad方法内添加
  1. GameRegistry.registerItem(RunningManItems.running_man_ingot,"RunningManIngot");
复制代码
两个参数分别为Item对象与注册名字，通常与构造函数中的相同
然后打开游戏就能看到无材质的Item了
下面是第一个Block类
  1. class RunningManOre extends Block
复制代码
即跑男矿石，extends说明这是一个Block

然后添加构造函数
  1. public RunningManOre()
  2. {
  3. super(Materials.rock);
  4. //设置与石头类似的属性
  5. //以后将改为每个Block独有
  6. setCreativeTab(CreativeTabs.tabBlocks);
  7. //同Item
  8. setUnlocalizedName("RunningManOre");
  9. //同Item
  10. }
复制代码
在RunningManBlocks中添加
  1. Block running_man_ore=new RunningManOre();
复制代码
在主类preLoad方法中添加
  1. GameRegistry.registerBlock(RunningManBlocks.running_man_ore,"RunningManOre");
复制代码
与Item同理
现在打开游戏测试吧
