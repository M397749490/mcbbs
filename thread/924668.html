以分数增加判断是否使用了物品
以物品nbt区分不同的技能
如

  1. give @s carrot_on_a_stick{custom:1b}
  2. give @s carrot_on_a_stick{custom:2b}
  3. give @s carrot_on_a_stick{custom:3b}
复制代码

  1. execute as @a[scores={carrot.stick=1..},nbt={SelectedItem:{id:"minecraft:carrot_on_a_stick",tag:{custom:1b}}}] run say 1
  2. execute as @a[scores={carrot.stick=1..},nbt={SelectedItem:{id:"minecraft:carrot_on_a_stick",tag:{custom:2b}}}] run say 2
  3. execute as @a[scores={carrot.stick=1..},nbt={SelectedItem:{id:"minecraft:carrot_on_a_stick",tag:{custom:3b}}}] run say 3
  4. scoreboard players reset @a carrot.stick
