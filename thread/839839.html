标题: [开源]NppMarkdown —— Notepad++ 即时预览 Markdown 工具


NppMarkdown
Notepad++ 即时预览 Markdown 工具



这是一款可以让你在 NotePad++ 里即时查看 Markdown 效果的工具，在日常写文档，博客的时候更方便
其实官方已经有一个插件叫 NppMarkdown 了，但那个插件万年不更新，而且最新版的 Notepad++ 无法使用，所以我就花了点时间造了这个玩意。
此工具使用易语言开发……所以可能会被某些杀毒软件报毒，添加白名单即可

功能介绍
  • 使用 showdown.js 实现 Markdown 即时渲染
  • 内置 Webkit 浏览器内核
  • 支持窗口大小调整，最大化
  • 一个 EXE 即可，无需其他组件
  • 保持顶层显示，不会被编辑器窗口覆盖

使用
  • 运行 NppMarkdown.exe
  • 编辑任意 Markdown 文件
即使不是 Markdown 格式，软件也会尝试渲染
因为内嵌了一个 WebKit 浏览器内核，运行时会生成一个 data 目录以及一个 html 临时文件，因此请不要放在桌面运行以免让桌面变得很乱

关闭 Notepad++ 后，重新打开时不需要重启软件，软件会自动根据窗口类名取得新的窗口句柄。

资源文件
软件在断网的情况下应该是无法使用的，因为调用了以下几个 Js 和 Css
  • https://cdn.jsdelivr.net/npm/bootstrap@3.3.7/dist/css/bootstrap.min.css
  • https://apps.bdimg.com/libs/jquery/2.1.4/jquery.min.js
  • https://cdnjs.cloudflare.com/ajax/libs/showdown/1.9.0/showdown.min.js
  • https://cdn.jsdelivr.net/npm/showdown-table@1.0.1/dist/showdown-table.min.js
  • https://cdn.jsdelivr.net/npm/bootstrap@3.3.7/dist/js/bootstrap.min.js
