标题: 插件发布：极限模式服务器版...
由于还是不能在多人版发帖....所以请斑竹帮忙移贴吧。。。


                这插件顾名思义就是在服务器里玩极限模式,而死了的人会变成幽灵...而幽灵可以看见玩家玩家却不能看见幽灵。。。但是幽灵是什么都不能做的。。。（不能破坏，不能建造...)
Features(特性）:
  • A Fun Way To Die! （这句你们慢慢想....)
  • Health Display Above Players Heads! (Requires Spoutcraft) 可以从别人的头上看到血条（需要spoutcraft当然你也可以不安装..)
  • Ghost Like Feature For Dead Players 幽灵只是给死掉的玩家不掉线而设置的。。。
  • Ghosts Invisible To Live Players 幽灵在活着的玩家面前时隐身的...
  • Chat System For Dead Players死了的玩家有特定的沟通系统
  • Teleport Command For Ghosts (/Haunt Playername)给幽灵的传送指令/haunt 玩家
  • OP/Console Revive Command (/smprevive Playername)op用来复活幽灵
请安装在bukkit的plugin文件夹...
