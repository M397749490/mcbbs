无限流量内存是什么概念？
无限流量 - 一般呢 咱去租什么服务器 都是每个月限制多少G流量 甚至以M为单位的限制流量
当每个月 上传/下载大小 达到这个限制时 就会 给这个服务器断网。
这是一个令人非常深恶痛绝的事情！！
[葡萄你连流量都不知道？右上角退群？]

什么是域名 - 比如 .com/.net 这样的网址就是域名

域名拓展 - www.baidu.com 这个域名
其中.com是一级域名 .baidu是二级域名 www是三级域名
一级域名很多网站都有用 二级域名就被各大企业、平台 抢着用啦
其中 二级域名下可以有几个三级域名 比如 www.baidu.com / tieba.baidu.com
这两个网址 www和tieba 都在baidu下面
诸如此类的还有 xueshu.baidu.com map.baidu.com

域名的作用 - 域名代替了一串IP 任何设备联网都是有一串IP的嘛
[什么是IP]
IP是一种 网络上的 抽象的地址 当你的设备联网 那么它就具备了IP
通过IP 可以区别不同的设备 IP是一串数字和点
举个例子 192.168.0.1 你可以试试用浏览器打开这个IP。
打开了新世界的大门？以后再讲。
[其实我也不是很懂 但是我就是要装个B]
由于IP不方便人类识别、区分 因而出现了域名 每个完整的域名都代表了一个IP
我们连接这域名 - 连接上IP - 访问服务器 - 获得了网页
域名-IP拓展 - 当我们访问一个域名的时候 实际上我们的电脑并不知道这个域名是个什么鬼东西。
这个时候 我们需要一个新的玩意儿----DNS[域名系统] 全世界可以联网的地方 都有DNS服务器
DNS服务器解析域名 让你的电脑知道域名对应的IP 从而连接上去

至于为什么要关掉又重开Git Bash


Git Bash是一种命令行程序 命令行程序是用来执行一些我也说不清的操作...


你可能见过命令行程序 觉得眼熟

win键＋R 打开运行

然后输入cmd 回车

这就打开了Windows默认的命令行程序

至于为什么我们用Git Bash 而不是Windows默认的

我怎么知道我就是个水比 教程这么写我就这么做

所以让你们切换文件夹

hexo clean //清除暂存空间
hexo g //将文章按照模板生成静态网页 保存到暂存空间
hexo d//将本地的静态网页部署到服务器
