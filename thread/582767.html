MonsterPower

未经明示允许严禁转载

  • 介绍
    这插件本来是给某服写的，那边玩家的资源已经彻底的泛滥了，为了更好的恶心死玩家，我研发了这个插件。
    功能: 夜晚来临，怪物们的攻击加倍，速度加倍（加成可设置。
    对可能消耗性能的部分尽可能的进行优化。
    注：“夜晚”指的是MC时间 晚上7点（含7点，星星出现）~早上4点之间（不含4点，天边有点亮色）
    1.8已测试，1.9理论兼容，1.7 3楼已测试，3楼还说支持mod怪物。。


  • 命令&权限
    无


  • 配置文件
    1. # 世界设置
    2. worlds:
    3.     all:  # 所有世界
    4.         # 伤害*2，可以为小数，设为1为正常
    5.         damageModifier: 2
    6.         # 速度I 的药水效果，不可为整数，设为小于1的值为关闭
    7.         speedLevel: 1
    8.     world_nether:  # 针对地狱世界单独设置
    9.         # 伤害*6.66 （嘿嘿嘿
    10.         damageModifier: 6.66
    11.         # 速度V 的药水效果（不受原版药水限制，所以最高可以Integer.MAX_VALUE = 2147483647，但是太高服务器保证炸
    12.         speedLevel: 5

    14. # 不解释，会对那个世界的所有玩家广播。其实我觉得白天的那个提示不怎么好，但是想不到更好的。。
    15. msg:
    16.     night: "&c&l长夜漫漫，怪物们陷入了疯狂……"
    17.     day: "&a&l黎明终于来临，怪物们平息了怒火……"
    复制代码
    上面的设置的效果是：地狱的夜晚怪物造成攻击666%，得到速度V的药水效果。除了地狱外的其他时间，造成攻击200%，得到速度I的药水效果。
    提示：我在服务器里测试时其他玩家已经觉得速度I很变态了，最好不要更大
