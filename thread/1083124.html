原先1.14版本服务端正常启动，昨晚尝试将其升级到1.16版本。除了配置文件和白名单外全部替换，地图也保留，也是如图报错内容。随后单独解压压缩包，什么都不更改，一切默认，启动也是如图报错。
求助是哪里出问题了。端口IPV4的已经更改过了，IPV6的是默认，地图是1.14的旧存档不行，服务器自建存档也不行-.-
已自行解决，解决方案放出来吧:1.16的BDS端需要windows server 2019的系统，windows server 2016可以通过打微软补丁（KB4103723和kb4561616）来实现运作。其余系统sevrer系统没测试（2012我还没试过-.-）
