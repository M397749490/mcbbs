本插件只在1.9于1.10下测试过（理论应该是全版本）
Tested Minecraft Versions: 1.9 1.10
FirstJoinPlus 可以让你以各个方面控制新玩家的进入——给他个新手礼包，特殊的出生点，对他使用后台指令，放烟花，……以及更多！
安装此插件后，现有的玩家不会被告知第一次加入~

FirstJoinPlus allows you to control every aspect of when new players join. Give new players a starter kit, a special spawn location, have the console run commands, launch fireworks, and more!
Existing players won't get told they joined for the first time after installing this.


特性：
  • 新玩家进入时发送公告（可以配置指定的玩家加入数量）
  • 来一发♂火箭或烟雾特效
  • 给玩家一本带有欢迎信息的成书 （书本的梨子在这）
  • 发送一个新手礼包，可以在配置文件中设置。
  • 强制玩家或后台使用配置文件中的指定命令
  • 设置玩家的无敌（所有，包括PVP）时间
  • Announce that a new player has just joined (optionally with the amount of unique players that have joined!).
  • Launch a firework or show a cool smoke effect.
  • Give the player a written book with welcome information (example book here)!
  • Give a starter kit with items defined in the configuration.
  • Force the player or the console to run configurable commands.
  • Set the player as invincible (from everything, including PVP) for a pre-defined amount of time.
  • Much more, check out the configuration below!


高频提问：
  • 新玩家没有出生在首次加入的出生点？
可能某个插件于这个插件冲突，将配置文件中的'delay-everything-below-by'的值设高点，大概5或10（单位是tricks）
  • 想要这个插件每一次加入都是第一次加入？
把配置文件中的'every-join-is-first-join'改为true ——这将会把每一次加入当作第一次加入。对于登陆服(？你可以每次加入都把玩家传送回出生点，每次加入发射一发火箭，以及你可以设置加入退出的信息为“%none”来隐藏他们~
  • 显示的昵称是普通的名字而不是他们的昵称？
这意味着另一个插件设置的显示名称在FirstJionPlus后被获取了，尽管FirstJionPlus后的优先级是正常的。
设置配置文件中的'delay-everything-below-by' 的值高点，大概5或10（单位是tricks）
  • 能不能在新手礼包中做XX？
新手礼包功能已经尽可能做的很简单了，正如配置文件所示，你只能通过物品名称来设置给予的物品，设置给予的金钱。
但是设置nbt，显示的名称，以及lore是不可能的。简单的来说，我只想让这个插件作为一个第一次加入的插件，而不是一个礼包插件。
如果你想做些别的东西，我建议你找个比较完善的礼包插件，然后使用FirstJoinPlus的指令功能来发放他。

  • New players not spawning at the first join spawnpoint?
    You have a conflicting plugin. Set the 'delay-everything-below-by' value in the configuration to a higher value, such as 5 or 10 (this option is set in ticks).
  • Want this plugin to kick in for every join instead of only first joins?
    Set 'every-join-is-first-join' in the configuration to true - this will treat every join as a first join. Great for hub servers as you can have the player teleported back to spawn every join, launch a firework every join, and you can set the join and quit messages to %none to completely hide them.
  • The display name variable is using their normal name and not their display name?
    This means another plugin is setting the display name after FirstJoinPlus is getting it, despite FirstJoinPlus using a normal priority. Set the 'delay-everything-below-by' value in the configuration to a higher value, such as 5 or 10 (this option is set in ticks).
  • Is it possible to do X in the first-join starter kit?
    The starter kit functionality has been left as simple as possible. You can only give items based off of their names and set the amount to give, as shown in the default configuration. Things like setting data values, display names, lore, etc isn't possible, simply because I want to leave this plugin as a first-join plugin and not a kit plugin.

    If you need to do more, I suggest finding a fully featured kit plugin, and using it alongside FirstJoinPlus by having FirstJoinPlus run a command from that kit plugin on first join.




指令：
指令说明权限
/firstjoinplus显示插件信息(none)
/firstjoinplus help显示所有的可用指令(none)
/firstjoinplus reload重载配置文件firstjoinplus.reload
/firstjoinplus setspawn设置新玩家的出生点firstjoinplus.setspawn
/firstjoinplus debug把你作为一个新玩家来测试firstjoinplus.debug
可以用/fjp做为/firstjoinplus的别名，所有的指令默认是op所有，不需要权限插件~

CommandDescriptionPermission
/firstjoinplusShow general plugin information.(none)
/firstjoinplus helpShow all available commands.(none)
/firstjoinplus reloadReload the plugin's configuration.firstjoinplus.reload
/firstjoinplus setspawnSet the location where new players will spawn.firstjoinplus.setspawn
/firstjoinplus debugTest your configuration as a new player.firstjoinplus.debug
The command /fjp can be used as an alias in place of /firstjoinplus. All commands default to OP's, no permissions plugin required!




配置文件

# FirstJoinPlus Configuration -- Configuration Help: http://dev.bukkit.org/bukkit-plugins/firstjoinplus/#
# FirstJoinPlus 配置文件 小烦汉化，注释。
settings:
  #开启自动更新
allow-automatic-updating: true
  #每次加入都是第一次加入
every-join-is-first-join: false
on-first-join:
  #优先级
delay-everything-below-by: 0
  #第一次加入的信息
first-join-message:
    #是否开启
    enabled: true
    #信息
    message: '&d欢迎新玩家 %player_name！'
  #有♂趣的东西
  fun-stuff:
    #播放音乐
    play-sound:
      #是否开启
      enabled: true
      #音乐名称
      sound-name: entity_player_levelup
      #听见的权限
     listen-permission: firstjoinplus.notify
    #烟雾效果
    smoke-effect:
      enabled: true
    #来♂一♂发♂火箭
    launch-firework:
      enabled: true
  #新手礼包
  first-join-kit:
    #是否开启
    enabled: true
    #物品
    #格式： 英文名称:数量 （数量可略）
    items:
    - wood_sword
    - wood_pickaxe
    - wood_spade
    - wood_axe
    - bread:5
  #给一本成书
give-written-books:
    #是否开启
    enabled: false
    #书本的文件
    #范例文件地址：https://github.com/chaseoes/FirstJoinPlus/blob/master/src/main/resources/rules.txt
    book-files:
    - rules.txt
  #给经验
  give-experience:
    #是否开启
    enabled: false
    #给多少等级
    level-amount: 0
  #修改伤害
  modify-damage:
    #关闭pvp
    disable-pvp:
      #是否开启
      enabled: false
      #多久到期
      expire-after: 10
    #上帝模式（无敌）
    god-mode:
      #是否开启
      enabled: false
      #多久到期
      expire-after: 10
  #运行指令
  run-commands:
    #是否开启
    enabled: false
    #指令
    commands:
    - me just joined for the firsttime!
  #控制台指令
run-console-commands:
    #是否开启
    enabled: false
    #指令
    commands:
    - setgroup %player_name newbies
  #药水效果
apply-potion-effects:
    #是否开启
    enabled: false
    #格式 效果:等级:时间
    # 下面为 速度Ⅰ十秒
    effects:
    - SPEED:1:15
  #发送消息
  send-messages:
    #是否开启
    enabled: false
    messages:
    - '&2Welcome to our server,%player_name! Customize this message in the FirstJoinPlus configuration.'
    - '&6http://dev.bukkit.org/server-mods/firstjoinplus/'
  #复位
  reset-state:
    enabled: false
  #传送
  teleport:
    #是否开启
    enabled: false
    #坐标
    #不多解释
    x: 0
    y: 64
    z: 0
    pitch: 0
    yaw: 0
    world: world
#其他信息
other-messages:
  #加入信息
  join-message:
    enabled: false
    message:'&e%player_name joined the game.'
  #退出信息
  quit-message:
    enabled: false
    message:'&e%player_name left the game.'
  #被t的信息
  kick-message:
    enabled: false
    message: '%none'

可以用的变量
变量用于配置文件中显示不同内容（具体看描述）
变量说明
%player_name玩家名称
%player_display_name玩家显示的名称（包括前缀后缀什么的）
%player_uuid玩家uuid（国内基本无用）
%total_players已经加入的玩家数量
%random_player在线玩家中选一个随机玩家
%random_player_display_name在线玩家中选一个随机玩家的显示名称
%none用于加入退出信息中隐藏，不现实任何内容
%player_country玩家的国家(使用GeoIPTool).
%player_city玩家的城市(使用GeoIPTool).
Available Variables
Variables are used throughout the configuration to display different text (see the description).
VariableDescription
%player_nameThe name of the player.
%player_display_nameThe display name of the player.
%player_uuidThe UUID of the player.
%total_playersThe number of unique players that have joined.
%random_playerThe name of a random online player.
%random_player_display_nameThe display name of a random online player.
%noneUsed in join, quit, and kick messages to completely disable them.
%player_countryThe player's country (GeoIPTools required).
%player_cityThe player's country (GeoIPTools required).
