标题: 女仆mod和舰娘mod无法用蛋召唤

版本：1.7.10
MOD分别是：littleMaidMob和ShinColle-1.7.10.rv26
刚装入开服的一段时候正常使用，可以用蛋召唤女仆和舰娘
之后，突然蛋就失效，
但已召唤的女仆和舰娘可以正常使用（雾）
怀疑是世界限制生物数量，但是蛋可以召唤别的其他生物，唯独女仆和舰娘不行
去配置修改了cfg_spawnLimit=20000000
然后仍然无效，现在不知道解决方案了
（无法用蛋召唤外，我飞了好几个世界都找不到一只野生的女仆或舰娘）（死宅哭泣）
作者: DE_SHARK    时间: 2020-3-8 22:23
1. 打开laggremover的配置文件，找到
# The max number of entities that can spawn in a single chunk.
thinAt: 30
将30改大，比如300

2. 打开NeverLag的配置文件，找到
#实体清理
ClearEntity:
  #是否开启
  Enable: true
  #清理周期
  Delay: 1200
  #是否仅到达数量上限才清理
  OnlyClearWhenLimit: true
  #限制数量
  Limit: 1200
限制数量可以改大一点
