Denizen——让你的npc活起来！

——Citizens2附属插件，为npc添加脚本



本插件是最好的创建脚本npc的插件

本插件是citizen2的扩展，必须有前置插件才有效果

主要功能：增加与npc的对话，npc执行指令等

-该插件设计脚本编写，难度较高



下面举个例子(其实是作者举了个栗子)



Cookies:   
#名字
  type: assignment  
#类型
  interact scripts:    #交互脚本
  - 100 Cookie Handler
Cookie Handler:   #脚本名称
  type: interact    #类型  译：互动
  steps:   #步骤
    'Spreading the Word*':   #说这些话
      click trigger:    #点击触发
        script:     #脚本
        - random 3    #3个中随机说
        - chat 'I like cookies!'
        - chat 'MMmm.. cookies are favorite!'
        - chat 'Cocoa and wheat me freak!'
      chat trigger:   #聊天触发
        'Cookies':  
          trigger: 'I love /cookie/s!'   #触发用语
          script: #脚本
          - chat 'Me too!'  #回答这句话
          - narrate '<npc.name> gives you some cookies.'  #字幕：（npc名字）给了你一些饼干
          - give i@cookie qty:6              #脚本
          - zap 'step:Cookies given'    #执行指定脚本
    'Cookies given':
        click trigger:
            script:
            - chat 'How were the cookies?'
            - zap 'step:Spreading the Word'


指令：/npc assignment --set cookies 给指向的npc添加此脚本


再举个例子


Basic Healer:

  type: assignment

  interact scripts:

  - 100 heal me, bro!


Heal me, bro!:

  type: interact

  steps:

    "Need a heal?*":

      click trigger:

        script:

        - if '<player.health>' < '<m:<player.health.max> / 2>' {        # 如果血量低于上限的二分之一

            - look <player.location>            #检查玩家

            - chat 'Woah dude, you are <player.health.formatted>! You could use a heal!'

            - chat 'Just give me another click to get some power!'

            - zap "Healin'" duration:30s   #执行下一个脚本

          } else {

            - look <player.location>

            - chat 'Nice an healthy. Keep it up!'  

          }

    "Healin'":

      click trigger:

        script:

        - ^zap 'need a heal?'

        - ^engage

        - chat "Here goes nothin'!"

        - playeffect instant_spell <npc.location> qty:25

        - playeffect heart <player.location> qty:25 offset:1

        - heal <player>  #治愈玩家

        - disengage
