插件介绍
一、简介
     LindTap参考了斗罗大陆动漫的游戏模式，拥有多种自定义魂环，自定义属性，魂环降落效果，可以让你服务器的玩法和战斗多样化，给玩家带来一种新的体验效果，增加游戏的可玩度。
二、特性
    自定义GUI界面，让你拥有独特的商店界面
    可自定义魂环数量，让你最大限度的使用你的特效
    可自定义魂环显示出来的贴图让你服务器有更多的玩法
    目前只测试过SX属性插件支持其他属性插件暂时没测试
    支持MM之类的怪物掉落获取魂环如果设置的话如请详细看下面教程
    可以设置手中的物品为魂环使用券，设置后右键就可以获取设置的这个魂环
    不要问我为什么魂环插件取这个名不应该是XXX吗，问就是随便想的
    如果有更多的想法可以给我说，我会看情况增加其他新内容
插件指令
/tag 查看插件全部指令
/tag gui 打开魂环商店和魂环仓库界面
/tag set 序号 名称 设置拿在手上的物品为魂环使用券
/tag reload 重载插件

使用教程
     首先下载插件然后放入服务器文件夹的plugins文件夹里面，然后打开客户端点击minecraft文件夹找到里面的vexview文件夹点击到最里面然后解压我发的贴图包就可以了。
config配置教程
password:  序列码发布版这里不用填可以忽略掉
count: 12  自定义设置魂环数量
key: 47   按键码
view: true  GUI开启关闭魂环和键盘按键开启关闭魂环二选一，true是GUI开启关闭魂环false是按键开启关闭魂环
debug: false  按键码查询，开启true按键盘的键左下角就会显示按键码数字
on_off: false  开启或关闭购买前三个魂环才能购买其他魂环的限制
vfx: true  开启或关闭魂环降落特效
设置魂环属性教程
首先我们打开LindTag插件文件里找到里面的data配置文件点开。
data:
  '0': 这里是魂环序号，魂环按0的序号开始一个一个释放出来
    photo: '[local]LindTag//h1.png' 魂环贴图
    name: '200'  这里不是名称是购买需要的点券
    nature:  这下面是设置的属性可以随意设置文本
    - '攻击力: 10000'
    - '闪避几率: 100%'
如果要设置手上拿着的这个物品获得魂环就输入/tag set 0 十年魂环 然后你手上拿着的这个物品就会变成获得魂环的物品这里指令里面的0就是魂环的序号十年魂环这个是物品的名字不支持用其他颜色代码默认颜色：蓝色
