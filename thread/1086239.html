学会阅读提示：
* What went wrong:
Task 'setupDecompWorkspace' not found in root project 'fmltutor'.

意思就是找不到 setupDecompWorkspace 这个 gradle 任务。
有鉴于你使用的是 1.12.2-14.23.5.2854 的 MDK，这是正常的。
这个版本的 MDK 使用 ForgeGradle 3，你不需要运行 gradlew setupDecompWorkspace，只需导入 IDE 即可。
间接说明楼主直接生搬硬套旧版教程……
或者你根据你的 IDE，从 gradlew genEclipseRuns 和 gradlew genIntellijRuns 里选一个运行也可。
