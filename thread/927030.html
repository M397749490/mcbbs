  飞行权限举例:
    RewardType: command
    Reward:
    - manuadd %player% essentials.fly
    PriceType: Vault
    Price: 150
    MenuItem:
    - name:飞行权限
    - 'lore:购买消耗点卷:150点券/月#'
    - id:288
    - amount:1
    Message: '&a交易成功发送给玩家的信息！'
    InventoryLocation: 8

命令模式  指令给玩家添加权限   照葫芦画瓢

这是飞行权限的举例
如果想点券 改下货币属性就行

作者: AzureHanChen    时间: 2019-11-24 19:12
  飞行权限举例:
    RewardType: command
    Reward:
    - manuadd %player% essentials.fly
    PriceType: PlayerPoints
    Price: 150
    MenuItem:
    - name:点击购买飞行权限
    - 'lore:&e价格 &7:150点券'
    - id:166
    - amount:1
    Message: '&a购买成功！'
    InventoryLocation: 1
(如果你使用的是LP,则命令是/lp user %player% permission set essentials.fly true)
