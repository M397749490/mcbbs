前言
This plugin is the easiest and the best plugin to add commands on rightclick on an Armor Stand. This plugin is also lightweight as far as it goes. Next thing this plugin can do is protecting the Armor Stands from destroying and stealing items from them.

  • 这个插件可以像国外/国内的大型群组服那样右键盔甲架(Armour Stand)来进行跨服打开菜单,asCMD也非常的轻便(6.8KB),并且还能保护您的盔甲架不会被破坏




功能
  • 将指令绑定(添加)到盔甲架(Armour Stand)
  • 保护您的盔甲架(Armour Stand)



指令&配置
/ascmd edit  - 切换编辑模式  (只有在编辑模式下，您才可以装饰/摧毁盔甲架)
/ascmd addcmd <console/player> <command>  - 将指令绑定(添加)至盔甲架上
/ascmd clear  - 清除绑定(添加)在盔甲架上的指令
There is no configuration is this version, maybe in future I will add it. In config.yml are stored all armor stands and commands so far.

插件配置#config绑定指令后查看




使用
添加
          1.放置一个盔甲架
          2.输入/ascmd edit
          3.输入/ascmd addcmd （console是控制台/player为玩家） <想绑定的指令>  -右键盔甲架
          4.完成！
清除
          1.输入/ascmd clear  - 右键点击你要删除绑定(添加)指令的盔甲架
          2.完成！
