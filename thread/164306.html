关于各个插件的设置

用户组插件
用户组插件基本上设置好了
使用/manuadd将用户添加到用户组
示范/manuadd 123 WJ 将玩家123添加到玩家用户组
/manuadd abc CSS 将玩家abc添加到创世神用户组
预设了几个用户组
用户组名称 用户组前缀 用户组权限
YK 游客 基本上不能干吗
WJ 玩家 有玩家的权限
OP OP 这个OP不是用/OP加的OP比玩家多了几个权限可以改天气时间和强制传送
JZS  建筑师 可以改游戏模式等等有利于建筑的权限
GM 管理员 基本上拥有全部权限
CSS 创世神 拥有全部权限


领地插件
更改木棒为设置领地的工具
小地图
默认开启雷达映射，想要取消的，打开plugins\Essentials\motd.txt,然后删除&0&0&1&2&3&4&5&6&7&e&f这段文字即可。
其它插件一律默认设置


关于server.properties
#Minecraft server properties

#Mon Jul 01 18:00:53 CST 2013

generator-settings=  

allow-nether=true                               是否允许玩家进入下界

level-name=world                              “level-name”的值将作为世界名称及其文件夹名

enable-query=falseallow-flight=true                                是否允许玩家在安装飞行功能的MOD前提下在生存模式下飞行

server-port=25565                           服务器端口号

level-type=DEFAULT                          确定地图类型

enable-rcon=false                              

force-gamemode=false

level-seed=                                        地图种子

server-ip=                                         服务器IP

max-build-height=256                       玩家在游戏中能够建造的最大高度

spawn-npcs=true                             决定是否生成村民   

white-list=false                                  是否启用服务器白名单

spawn-animals=true                          决定动物是否可以生成

hardcore=false                                 一旦启用，玩家在死后会自动被服务器封禁

snooper-enabled=true                       启用将允许服务端定期发送统计数据到http://snoop.minecraft.net/

online-mode=false                             是否允许在线验证

texture-pack=                                  客户端加入服务器后是否会自动下载材质包。请在这里填入完整的材质包URL

pvp=false                                         是否允许PvP

difficulty=1                                      定义服务器的游戏难度

enable-command-block=true           当启用时地图中的命令方块可以被红石所激活

server-name=Unknown Server
gamemode=0                                  决定游戏模式

max-players=20                                服务器同时能容纳的最大玩家数量

spawn-monsters=true                     决定攻击型生物（怪兽）是否可以生成

generate-structures=true                 决定在生成世界的时候是否包括结构（例如村庄）

view-distance=10                             设置服务端传送给客户端的数据量

spawn-protection=0                         出生点保护范围

motd=A Minecraft Server                  本属性值是玩家客户端的多人游戏服务器列表中显示的服务器名称

                                         ——以上内容来自中文Minecraft Wikihttp://zh.minecraftwiki.net/wiki/Server.properties
