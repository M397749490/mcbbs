Bat文件设置
  1. ::默认的Bat可以启动服务端根据自身需要修改
  2. @ECHO OFF
  3. title [椰汁整合 CB 1.7.2]
  4. java -Xincgc -Xms1g -Xmx1g -jar spigot-1.7.2-R0.4.jar
  5. pause

  7. ::512M代表给服务端分配多少内存
  8. ::一般1024M以及130KB的上传带宽可以开一个20人的服务器
  9. ::如果你要修改 请把两个512M都改了
  10. java -Xms512M -Xmx512M -jar spigot-1.7.2-R0.4.jar
  11. pause
