指令
/bp help         查看命令帮助菜单
/bp list          列出方块粒子的位置
/bp add <Location Name>    例子-- /bp add 123 就是将鼠标所指的方块创建为名字为 123 的粒子方块
/bp delete <Location Name>  例子-- /bp delete 123 就是将鼠标所指的粒子方块变成普通的方块
/bp set <Location Name> <Type>        例子--  /bp set 123 Crit 就是将刚刚创建好的例子方块添加一个名为Crit的粒子效果
/bp types                            列出所有粒子效果
/bp reload                            重新读取配置文件
