简介
      这个插件可以记录最高同时在线玩家数量并发出公告，想要更多功能的拿源代码去开发吧=。=(我懒)，理论上任何版本的任何类型的服务端都可以用，实际上有待大家测试(233还是我懒)。
命令
/rho - 重载插件
权限
rho.use - 重载插件的权限(默认OP拥有此权限)
配置文件
  1. #######################################
  2. # RememberHighestOnline插件   
  3. # 记录最高同时在线玩家并发送公告
  4. #       作者:CMD丶BLOCK_      
  5. #     QQ:1056293351           
  6. ######################################
  7. #记录最高同时在线玩家(改了有何意义233)
  8. Highest: 0
  9. #是否公告
  10. sendMessageToAllPlayer: true
  11. #公告信息(%max%为当前在线人数)
  12. Message: "§b服务器最高在线人数突破 %max% 人了！"
