问我是问对人了我们是刀剑神域百人服大量RPG物品和自定怪物BOSS 精英怪，也是用的这个插件 代码可以这样
/mm s create a14 greenwarrior      比如greenwarrior 是怪物的名字 a14我表示14层小怪刷怪点
/mm s set a14 maxmobs 4         
/mm s set a14 cooldown 13
按顺序输入这3步对着你想设置刷怪点的地方 ， 第一个是设定刷怪点名字和 怪物名字
第2个是设置a14这个刷怪点的 最大可产生的怪物数量 为4  可自己设置
第3个是设置 冷却重生时间 比如要13秒才能重新刷新 1只
小怪可以刷比较快一点

/mm s create b14 bigsquid         至于BOSS的话可以这么设置比如14层BOSS 数量上限为1只重生时间34000秒
/mm s set b14 maxmobs 1           
/mm s set b14 cooldown 34000

恩然后你可以多增加几个点多设置几次就好了 这个插件刷怪文件有个BUG 不稳定时候会消失
所以你的刷怪点文件必须经常备份必要时候可以还原~~~
