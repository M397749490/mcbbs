一、插件简介
在你的MOD服中，是否存在各式各样可以叠加的奇怪加速物品，并且ESS设置里的移动速度限制根本无法限制他们？
玩家只要同时使用多种加速物品即可变身闪电侠，一跑图服务器瞬间爆炸，后台全是xxxx moved wrongly。
并且在战斗中来无影去无踪，根本打不到人。
本插件提供两项功能：跑图玩家公示与移动速度限制。
根据玩家加载的区块数多少进行排名，对第一名进行公示，并且在服务器卡顿时对第一名进行惩罚。
在玩家移动速度过快时，计算出新的基础移动速度，将移动速度限制在合理范围内。

二、配置文件与算法介绍
  1. # 跑图检测间隔
  2. # 由于本人不会操作封包，判定一个玩家加载了某个区块的算法是直接找一个最近的玩家背锅。
  3. # 请注意，如果你的服务器规模大至千人，这个跑图检测会造成较为严重的性能损耗
  4. CheckInterval: 120

  6. # 当服务器Tps小于MinTps，并且第一名加载区块数多于MaxChunk时，会进行全服公告并赋予第一名持续时间为SlowTime的缓慢2
  7. MinTps: 15
  8. MaxChunk: 1000
  9. SlowTime: 30

  11. # 单次Move事件在xz平面上移动距离平方的最大值，高于此值的话会被限速。
  12. # 原版跑步约为0.3，连跳最大为0.9，ESS的Speed 5后跑步约为2.43
  13. # 原版迅捷2跑步约为0.6
  14. # Speed 1飞行最大速度约为1.17
  15. MaxSpeed: 1.3
  16. # 调试选项，打开此选项后，当玩家移动会在后台输出「单次Move事件在xz平面上移动距离平方」
  17. PrintSpeed: false

  19. # 速度保底，避免玩家被我口胡的算法限制的无法移动
  20. MinSpeed: 0.005
  21. # 算法参数，设NowSpeed为「单次Move事件在xz平面上移动距离平方」
  22. # 则新速度为 NumA / (NowSpeed / NumB)
  23. NumA: 0.55
  24. NumB: 0.3

  26. # 为了防止玩家被攻击时击退也会触发限速，当一个玩家被攻击后DamageCoolDown秒不会触发限速。
  27. DamageCoolDown: 3

  29. # 对不平衡的加速物品的最终手段
  30. # 当一个玩家连续多次触发限速时，这次的基础速度会直接设为上次的0.9倍。
  31. # 因此可以调大NumA，调小NumB来让这个算法自适应地计算基础移速。
  32. # 然而如果你用背包编辑器调一个+2速度，你会发现调整基础速度根本无法限制他。
  33. # 于是在玩家的基础速度被设为0.000001以下时，会被直接上一个持续时间很长的 SlowAmplifier级的缓慢，来制裁这种加速物品。
  34. SlowAmplifier: 50
