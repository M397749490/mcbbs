必看-使用教程-疑难解答
1. 前往原帖下载插件
2. 把插件放入服务端的plugins文件夹
3. 启动服务器以生成配置文件
4. (如果需要的话)复制上方配置文件替换服务端配置文件
5. 根据个人需要稍微配置插件
6. 启动服务器

输入/restarter gui无效且报错
1. 打开config.yml，将
  1. gui:
  2.   title: "&a&l重启菜单"
  3.   rows: 1
  4.   fill-item: WHITE_STAINED_GLASS_PANE # 用于填充GUI中空白的物品,如不需要,填写"AIR"
  5.   0:
  6.     slot: 3 # GUI界面按钮的位置,位置从零开始
  7.     item: GREEN_WOOL
复制代码
下的WHITE_STAINED_GLASS_PANE，GERRN_WOOL等形如物品ID的配置类
更改为与您服务端版本适配的物品ID
2. 重载插件

插件只能关闭服务器，不能重启
1. 关闭服务器
2. 右击编辑.bat脚本
3. 在形如“java -Xms512M -Xmx1024M -jar Server-1.12.jar”的上，下各插入一行，内容为“:start”和“goto start”
即
  1. :start
  2. java -Xms512M -Xmx1024M -jar Server-1.12.jar
  3. goto start
复制代码
4. 启动服务器
