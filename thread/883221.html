这款插件能做什么?



  • 创建一个属性,并自定义给他的用途,例如:金币加成,经验加成,点券掉落加成,可用在掉落物计算的公式内,宝石中的属性,药水中的属性
  • 创建一个属性,并在战斗公式中使用,例如:火属性攻击,火属性防御,冰属性攻击,毒攻击,暴击率,暴击伤害,真实伤害等等一系列
  • 创建一个装备,给予他基础的属性,随机的附加属性,指定该装备的穿戴位置,穿戴之后即可获得该装备的所有属性
  • 创建一个强化石,强化一个装备,无上限的强化等级,每级增加的属性都由公式来决定,可以呈曲线上升,失败概率会降级,概率会消失(都由公式控制)
  • 创建一个宝石,镶嵌到装备内,同时给予该装备多条宝石属性,不想用时可取出该宝石继续镶嵌至其他装备
  • 创建一个物品,可以定义为消耗品,右键触发,并且物品消失,恢复生命,右键使用添加永久/限时/下线消失的属性
  • 创建一个物品,可以定义为指令物品,右键触发指令,并且物品消失,执行单条指令或者一串指令

1.如何创建一个属性:

打开config.yml文件夹
找到custom-basic-attribute节点创建一个可自由分配属性点的属性,例如: 力量,蛮力,耐力,体质,魔力
格式如下:
# 所有属性点是单一性的(非范围)
力量:
  #显示文本
  display: "力量"
  # 评分系数 公式
  # 这个装备每增加1点力量加成
  # 将增加这个公式的数量评分
  # 默认"0"
  # {min} 替换成最小值
  # {max} 替换成最大值(如果是属性点的最大值还会是最小值)
  # 比如: 力量: 50
  # {min} 和 {max} 都会替换成 50
  score-coef: "{value.min}*25"
  #强化系数
  # 装备的力量属性为 100 则强化后增加以下公式计算出来的值
  # {enhance.level} = 强化等级
  # {value} = 原本的值
  enhance-coef: "{value}*({enhance.level}*{enhance.level}/206+0.08)"
  #出售系数
  # 如果装备有该属性则装备出售的价格添加以下公式
  # {enhance.level} = 强化等级
  # {value} = 原本的值
  money-coef: "{value}*4"


找到custom-attribute节点创建一个具有范围值的属性,例如: 近战攻击,远程攻击,魔法攻击,闪避,吸血,防御,命中,暴击率,暴击伤害,生命值,魔法值,金币加成,点券加成,技能伤害加成
格式如下:
#属性ID,不可重复
  #物理攻击
  物理攻击:

    display: "物理攻击"

    #这个自定义属性值是否具有最大值和最小值
    #默认为 false
    #比如移动速度,生命值,魔法值不能有最大值和最小值
    #该值为true的属性在调用数值时会随机抽取范围内的一个值来使用
    range: true
    #是否具有百分比的性质
    #默认 为true  
    sign: true
    #是否在面板中隐藏
    #默认false
    #设置为true可以做一些隐藏属性
    hide: false

    # 评分系数 公式 默认 0
    # {value.min} = 最小实际值
    # {value.max} = 最大实际值
    # {sign.min} = 最小百分比
    # {sign.max} = 最大百分比
    score-coef: "({value.min}*8+{value.max}*10)/3+({sign.min}*30+{sign.max}*35)"
    # 强化系数 公式 默认 0
    # 暂时只用作于装备系统
    # {value}替换成装备的属性值
    # {enhance.level}替换成强化等级
    # 最终的值会加到计算值中而不是替换
    enhance-coef: "{value}*({enhance.level}*{enhance.level}/206+0.08)"
    # 出售系数  公式 默认 0
    # 如果装备有该属性则装备出售的价格添加以下公式
    # {value.min} = 最小实际值
    # {value.max} = 最大实际值
    # {sign.min} = 最小百分比
    # {sign.max} = 最大百分比
    #money-coef: "{value.min}+{sign.min}*10"
    money-coef: "{value.min}+{sign.min}*10"

        # 当type的值为: point 时,

4.如何创建装备:

创建装备有3个条件,
1. 需要有一套装备属性(attribute文件夹下的文件)
2. 需要有一个装备类型(config.yml中的custom-equip-type节点)
3. 需要有装备的物品配置(equips文件夹下的文件)


创建步骤:
1.在equips文件夹下面创建一个新的"装备名字.yml"文件,并键入以下内容
display:
  name: "破旧的木剑"
# 默认物品类型
type: diamond_axe
sell-money: "10*{item.level}"
#子数据  默认0
damage: 195
#是否不可破坏 默认false
#1.9以上填true可以配合自定义材质包使用
unbreakable: true
# //                　　1 - 隐藏附魔
# //                　　2 - 隐藏自定义属性
# //                　　3 - 隐藏附魔和自定义属性
# //                　　4 - 隐藏{Unbreakable} (永久不毁)
# //                　　8 - 隐藏{CanDestroy} (可破坏)
# //                　　16 - 隐藏{CanPlaceOn} (可放置在)
# //                　　32 - 隐藏大部分信息(药水信息，书作者，烟花效果等等)
# //                　　63 - 隐藏所有的信息，除了名字和附加文字
#默认 0
hide: 31
#装备的介绍文本
introduce:
- "&6一把腐竹所送的武器"
#更多显示,当满足一定条件时,更换外观的设置
more:
  #随意id
  1:
    # 所需满足的要求
    requi:
      # level: 等级
      # enhance: 强化
      level:
        # 满足的取值范围
        # 最小值
        min: 10
        # 最大值
        max: 20
    #替换的物品类型
    type: diamond_axe
    #替换的物品子数据
    damage: 196
    #替换的物品显示信息
    display:
      #名字
      name: "长剑"
    introduce:
    - "&6稍微有些许锋利的武器"
    - "&6一把打磨过的{display}"


#该装备的属性配置(attribute文件夹下的文件名字)
attribute: 新手_武器_基本
#自定义的装备类型,(config.yml中的custom-equip-type节点中的最底层节点)
equip-type: 长剑


#穿戴要求,满足全部才能穿戴
demand:
  #穿戴职业 可空 默认[]
  #满足其中一个要求即可
  class:
    #默认为 config中的默认职业
    need-classes:
    - "新手"
  #等级
  level:
    # {level} 将替换成这个装备的等级
    # 可以使用自定义公式
    need-level: "{level}"
  #属性点
  # point:
    # #需求的属性
    # #需全部满足
    # need-points:
      # #属性id
      # 力量:
        # #要求的数量
        # # 默认0
        # amount: 20
        # #类型
        # # add 加点大于等于即可
        # # basic 基础属性大于等于即可
        # # other 其他大于等级即可
        # # equip 装备属性大于等于即可
        # #
        # # all 以上属性加起来大于等于即可
        # #
        # # 默认 all
        # action: add
      # 智力:
        # amount: 5
        # action: all




2.输入重载指令"/pr r"重载之后,使用指令"/pr e get 装备名字"来获取刚才创建的装备
3.打开装备栏穿戴即可
