标题: 试一下 Chrome 的 Markdown 插件
前言
其实之前一直没搞明白，之前看到的那些帖子是怎么做出来那些好看的排版的。看了看 mcbbs 用的编辑器，算是个功能强大的 HTML 编辑器吧，但是主要还是有以下两点问题：
  • 易用性上比较薄弱，要做出好看的排版还要下一份工夫。
  • 太过于“强大”，不会排版的人经常编辑出充斥着大大小小花花绿绿 柳绿花红 的字体，左插右排的文字图片，看上去总是那么杂乱土味的文章
正文
所以，就试试看在茶馆发个帖子试试 Chrome 上的这个 Markdown 插件了，对 HTML 编辑器的支持算是很好了，直接在编辑器里面写 Markdown 格式的文本，按一下按钮（或者是用快捷键 SHIFT+CTRL+ALT+M ）就能一键转换为渲染好的 HTML 格式文本。虽然说颜色啊之类没有什么可选择的，但是能表现出简洁美观的排版效果就很不错了。
期望
算是一点小小的期望吧，如果 MCBBS 能支持 Markdown 编辑器就最好了，不过感觉可能性也不是很大，毕竟用的还是 Discuz 的论坛架构嘛。
