Variable Ranking
Papi变量排行

功能介绍:
  • 可以将玩家的"数值"Papi变量进行排行(如%player_level%/%player_health%)
  • 可以指令创建Papi变量排行榜全息图(需要HolographicDisplays插件作为前置)
  • 每分钟自动更新所有的排行榜全息图
  • 可以指令查询某个变量的排行
  • 可自定义排行榜排名数量(尽量在10以内)
  • 本脚本并不是为了便利，配置文件只提供少量可配置内容，只是为了交流提升，并且希望更多人的接触Skript
配置文件与使用方法:
配置文件
#可在配置文件中添加需要排行的Papi变量
#格式为变量|后缀|备注
#变量为需要排行的Papi变量   后缀为排行之后Papi变量的后缀   备注为指令所需要的参数
#RankingNumber为排名的数量
  1. RankingNumber: 5

  3. Variablelist:
  4. - vault_eco_balance|money|金钱
  5. - player_level|level|等级
复制代码
Papi变量:
#后缀为配置文件中某个变量的后缀   排行只需要填数字，不能大于配置文件中RankingNumber的数量
 %Ranking_后缀_排行%                某个变量的第X名的玩家名
%Ranking_后缀_排行_value%     某个变量的第X名玩家的数值
比如:
%Ranking_money_1%                Pension_A(这是我自己的ID)
%Ranking_money_1_value%     8642.00  这代表我这个ID后缀为money的Papi变量的值

命令&权限:
/VariableRanking updata <备注>  ——  更新某个变量的排行榜
权限: VariableRanking.updata
/VariableRanking top <备注>  ——  查询某个变量的排行榜
权限: VariableRanking.top
/VariableRanking create <备注> 创建某个变量的排行榜全息图
权限: VariableRanking.create
/VariableRanking remove <备注> 删除某个变量的排行榜全息图
权限: VariableRanking.remove
/VariableRanking reload 重载脚本文件
权限: VariableRanking.reload

#安装教程:
需要前置插件:
Skript / Skript-Yaml / Skript-Placeholders / HolographicDisplays
兼容版本:
Skript 2.3+ 以上兼容的版本都可以兼容  大概是1.12 - 1.15
将Skript主体以及附属插件放入服务端plugins文件夹中，重启服务器
将解压好的Sk文件放入服务端plugins/skript/scripts文件夹中
输入指令/Sk reload all 重载脚本即可
