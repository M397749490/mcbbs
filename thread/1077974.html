如果仅在楼主限定的情形下，那么问题很简单，只要检测两个玩家谁死亡即可。利用@e无法选择死亡实体的特性，并借助一些标签操作可以轻松解决这个问题。
#游戏内循环
  1. tag @a add dead
  2. tag @e[type=player] remove dead
  3. execute @a[tag=dead,tag=A] ~ ~ ~ say A死了
  4. execute @a[tag=dead,tag=B] ~ ~ ~ say B死了
复制代码


如果要推广，即拥有同种标签的玩家不止一个，可能需要借助记分板进行一些逻辑操作
#建立记分板
  1. scoreboard objectives add death dummy
复制代码
#以下命令循环
  1. tag @a add dead
  2. tag @e[type=player] remove dead
  3. tag @a[tag=dead] add dead0
  4. scoreboard players set A death 1
  5. execute @a[tag=A,tag=!dead0] ~ ~ ~ scoreboard players set A death 0
  6. scoreboard players test A death 1
  7. say A队全部阵亡（此命令使用条件命令方块）
  8. scoreboard players set B death 1
  9. execute @a[tag=B,tag=!dead0] ~ ~ ~ scoreboard players set B death 0
  10. scoreboard players test B death 1
  11. say B队全部阵亡（此命令使用条件命令方块）
复制代码
游戏结束后记得给所有玩家移除dead0这个标签即可
