FeedbackBooks
反馈(意见)书



插件介绍：

This plugin allows your players to share their feedback about your server by writing it in a book.
允许您的玩家通过此插件将意见写入书中来分享他们对您的服务器的反馈
插件内容：

插件目前支持1.7-1.8 版本服务器
至于更新1.8以上的？不存在的
  1. Last Update:Jun 19, 2015
复制代码
最后更新(时间)：2015年6月19日
估计是作者是不打算更新了
但若有一天作者更新了此插件，请看到此贴朋友留言一下 我好去更新=-=
权限：
feedbackbook.get
- 获取书籍的权限
feedbackbooks.log
- 管理权限，接收反馈的权限
Conflg.yml:
  1. #名称和名称说明
  2. item:
  3.   name: '反馈书'
  4.   lore:
  5.   - '&7编辑这本书'
  6.   - '&7通过这本书告诉我们'
  7.   - '&7你有什么想法或建议'
  8.   - '&7都可以通过这本书告诉服务器'
  9.   #物品的库存
  10.   slot: 0
  11.   #是否强制项进入背包（不推荐，会覆盖已满背包内的物品）
  12.   replace: false
  13.   #是否删除反馈
  14.   remove: false
  15. #玩家在签名时收到的信息(留空，将不发送信息）
  16. message: '&a谢谢，你的意见我们会及时处理的。'
  17. book:
  18.   title: '&a反馈书'
  19.   author: '翻译: By 枫林1'
  20.   content: ["&6你好 \n\n &7感谢你参与反馈\n\n &7管理员会及时处理你的反馈的 \n (Page 1)", "Page 2"]
  21. on:
  22. #将本手册交给所有加入了游戏的玩家
  23.   join: true
  24.   #在玩家第一次加入时把反馈书给他们(将忽略已有玩家)
  25.   first_join:true
  26.   first_join: true
  27. log:
  28. #反馈控制台
  29.   console: true
  30.   #给已登录的玩家feedbackbooks.log权限
  31.   players: true
  32.   #反馈保存在（plugins/FeedbackBooks/log.txt）
  33.   file: true
