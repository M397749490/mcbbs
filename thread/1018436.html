标题: 对于最大化恰锭速度的研究
本帖最后由 自由李代数 于 2020-4-14 16:59 编辑

众所周知，恰锭由以下五个阶段组成：
1. 刷新
2. 发现锭贴，点开锭贴并卷到最底
3. 输入字符
4. ReCaptcha
5. Ctrl + Enter

下面是耗时估计（个人亲测）：
第一阶段
我的电脑刷新平均要2.82s，最快应该要1s吧


第二阶段
第二阶段细分为如下三小步：
(1)眼睛发现锭贴 -> 大脑反应过来 -> 手点击锭贴   最快0.2s
(2)进入锭贴  最快0.3s （我要0.6s）
(3)卷到最底部
    a. 狂按空格     0.32s
    b. 右方滚动条 0.58s


第三阶段
这是乱码恰锭大显身手之处。
实际证明，乱码恰锭不是最好，而且节省的时间远不到1秒
   项目    多次平均时间
Ctrl + V      0.23s
单一数字    0.67s
单一字母    0.67s
单一中文    0.37s
一堆数字    0.56s
一堆字母    0.53s
一堆中文    0.33s
谢锭，，， 1.41s
认真写       10s+


第四阶段
目前很难进行数十次ReCaptcha验证，但我个人估计大约耗时在3s~5s左右

第五阶段
本人测试 0.19s


综上所述，最快速度为：
1s + 0.2s + 0.3s + 0.32s + 0.23s + 3s + 0.19s = 5.24s
（实际上有脚本可以帮你做掉除了验证之外的所有步骤，总耗时只要3.1s左右）

这需要如下条件：
1.电脑快
2.反应快
3.直接粘贴剪贴板
4.验证ReCaptcha速度快

而我的速度一般为：
2.82s + 0.3s + 0.6s + 0.4s + 0.35s + 5s + 0.19s  = 9.66s
