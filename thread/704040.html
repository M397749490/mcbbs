首先输入

  1. /scoreboard objectives add daytime dummy

来创建一个dummy计分板

然后高频下面的指令

  1. scoreboard players add <span id="kM0.2053510406985879">@a </span>daytime 0
  2. time query daytime
  3. stats block (执行上面那个time query daytime命令的命令方块的坐标) time set QueryResult @a daytime
复制代码

复制代码
