标题: Minecraft 基岩版 Beta 1.15.0.56 发布

测试版是Minecraft基岩版的测试机制，主要用于下一个正式版的特性预览。

然而，测试版主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。适用于正式版的领域服务器与测试版不兼容。

如果在测试版中遇到旧版存档无法使用的问题，测试版将允许你将存档上传以供开发团队查找问题。

Minecraft基岩版 1.15 仍未发布，1.15.0.56为其第5个测试版。

转载本贴时须要注明原作者以及本帖地址。

https://feedback.minecraft.net/hc/en-us/articles/360040841731


Fixes:
bug修复：

修复了25个bug
  • Crashes/Performance
  • 崩溃/性能
    • Fixed several crashes that could occur during gameplay
    • 修复了游玩时可能发生的崩溃问题
    • Fixed a crash that was sometimes caused by the use of custom blocks
    • 修复了有时使用自定义方块导致的崩溃问题
    • Fixed a crash that could occur when trying to use a custom recipe add-on that also returns items to the player
    • 修复了使用附加包里的自定义合成配方返回物品时发生的崩溃问题
    • Fixed a crash that could sometimes occur when loading a saved game when the player is in water or lava after using a Potion of Fire Resistance or Water Breathing
    • 修复了有时加载已保存的游戏中，玩家使用抗火或水肺药水后在水中或熔岩中时会发生崩溃的问题
    • Fixed an issue that could sometimes cause the game to crash when exiting game with a menu open
    • 修复了打开菜单并退出游戏时有时可能发生的崩溃问题
    • Fixing a crash with enchants being used during melee (MCPE-63517)
    • 修复了使用近战附魔武器攻击导致的崩溃问题
    • Fixed a crash that could occur when loading level data
    • 修复了载入等级数据时可能发生的崩溃问题

  • General
  • 常规
    • Fixed an issue that could cause chunks to be overwritten when converting worlds from Console Editions to Bedrock (MCPE-58480)
    • 修复了将存档从主机版转换为基岩版时可能发生的区块复写问题
    • Maps will now convert from Editions to Bedrock at the correct scale (MCPE-58796)
    • 转换存档为基岩版时地图会正确缩放了
    • Fixed various arm animations in both third person views (MCPE-63088)
    • 修复了前后两种第三人称视角中手臂动画不正确的问题

  • Gameplay
  • 游玩
    • Fixed an issue that would cause blocks to reappear after they have been broken (MCPE-48914)
    • 修复了方块被损坏后会重新出现的问题
    • Fixed Observer blocks not being powered when being moved (MCPE-63785)
    • 修复了观察者方块被移动时无法充能的问题
    • Enchanted weapons now apply their effects correctly again (MCPE-63124)
    • 附魔的武器会正常应用其效果了
    • Changing armour will now update and show the correct armour visually (MCPE-63135)
    • 更换盔甲时会显示正确的盔甲材质了
    • Shearing a sheep will now update the sheep correctly (MCPE-63188)
    • 用剪刀剪羊的时的状态会正常更新了
    • Spruce and Giant Spruce trees no longer generate with missing logs (MCPE-63658)
    • 生成普通和巨型云杉树不会再缺斤少两了
    • Leaves no longer prevent saplings from growing into trees (MCPE-63153)
    • 叶子不会再阻止树苗生长了
    • Hoppers will now collect bone meal from composters placed above (MCPE-63809)
    • 漏斗会从上面的堆肥桶中收集骨粉了

  • User Interface
  • 用户界面
    • The Command Block's UI will now fit correctly inside screens with a 4:3 ratio (MCPE-41730)
    • 更改命令方块UI比例为合适的4：3

  • Add-Ons and Scripting
  • 追加内容和脚本
    • Bee spawn eggs can now be edited in content packs
    • 蜜蜂刷怪蛋可以在内容包中编辑了
    • Fixed an issue that was preventing custom blocks from being used in add-on packs (MCPE-63121)
    • 修复了会组织在附加包中使用自定义方块的问题
    • Fixed an issue with add-ons that could cause the minecraft:timer component to fire prematurely in some conditions
    • 修复了在某些情况下，Minecraft:timer组件可能的加载顺序可能会过早的问题
    • Fixed an issue that was causing particle animation to become inverted
    • 修复了会导致粒子动画翻转的问题
    • Using the minecraft:pushable component in add-ons will no longer break older content
    • 在add-ons中使用minecraft:pushable组件将不再破坏以前的内容
    • Fixed an issue that was preventing animation controllers in behaviour packs from running on dedicated servers and Realms (MCPE-59881)
    • 修复了在独服和Realms上会阻止行为包的动画控制器的运行的问题
