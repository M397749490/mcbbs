monster 一款简单的自定义加强原版怪物的插件
Version: 3.0.0
插件交流群: 1064982471点击加入


功能介绍

  • 自定义原版怪物身上的穿戴装备类型和穿戴几率
  • 自定义怪物穿在身上装备的掉落率
  • 自定义生效的世界
  • 自定义装备的随机附魔数量
  • 自定义控制刷怪笼是否生效
  • 自定义怪物在战力中升级的几率
  • 自定义怪物在战斗中突破为boss的几率(可设置攻击和血量)
  • 自定义怪物每级增加的血量和伤害
  • 自定义开关插件
  • 自定义消息文本
  • 不会对除了正常出生以外的怪物生效

配置内容
  1. # 怪物合金装备生成概率和死亡掉率 1.16有效
  2. netherite: 0.1
  3. netheriteDropChance: 0.001

  5. # 怪物钻石装备生成概率和死亡掉率
  6. Diamond: 0.1
  7. DiamondDropChance: 0.005

  9. # 怪物铁装备生成概率和死亡掉率
  10. Iron: 0.2
  11. IronDropChance: 0.01

  13. # 怪物金装备生成概率和死亡掉率
  14. Golden: 0.2
  15. GoldenDropChance: 0.015

  17. # 怪物锁链装备生成概率和死亡掉率
  18. ChainMail: 0.2
  19. ChainMailDropChance: 0.02

  21. # 怪物皮革装备生成概率和死亡掉率
  22. Leather: 0.2
  23. LeatherDropChance: 0.025

  25. # 装备随机附魔的概率和最大随机附魔数量
  26. Enchantment : 0.4
  27. EnchantmentNumber: 2

  29. # 启用怪物等级规则的世界
  30. worlds:
  31. - "world"
  32. - "world_nether"
  33. - "world_the_end"

  35. # 怪物攻击玩家升级概率
  36. levelProbability: 0.1

  38. # 每级增加血量
  39. levelHealth: 1
  40. # 每级增加伤害
  41. levelDamage: 0.1

  43. # 怪物升级中突变为BOSS的概率(变为BOSS后不会在升级)
  44. levelElite: 0.1
  45. # BOSS血量
  46. levelEliteHealth: 500
  47. # BOSS伤害
  48. levelEliteDamage: 20

  50. # 玩家攻击怪物,怪物瞬移的概率
  51. teleport: 0.01

  53. monsterOnMsg: §a请注意:op开启了超强怪物,超强怪物即将来袭!!!!
  54. monsterOffMsg: §a请注意:超强怪物已经关闭,超强怪物不在刷新!!!!
复制代码

指令和权限
权限:handy.monster,默认op有权限
指令功能
/monster reload重载配置文件
/monster on开启增强怪物
/monster off关闭增强怪物
/monster on [秒]开启增强怪物多少秒
