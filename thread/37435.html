创建一个新方块
——创建一个名为"Stone"的方块

  • 需要在src文件夹下新建一个名为 BlockExample.java 的文件
  • 文件的基本结构如下：

  1. package net.minecraft.src;

  3. import java.util.Random;

  5. public class BlockExample extends Block
  6. {
  7.     public BlockExample(int i, int j)
  8.     {
  9.         super(i, j, Material.rock);    }

  11.     public int idDropped(int i, Random random)
  12.    {
  13.        return 0;
  14.     }
  15. }
复制代码
  • 编辑Block.java可以使该方块添加至Minecraft中。
  • 您应该会在文件底部发现一系列变量的声明，在底部添加一条：

  1. public static final Block example;
复制代码
  • 在声明下面您应该也可以看见这些实体变量的初始化语句，通过以下语句为您的方格初始化：

  1. example = (new BlockExample(92, 1)).setHardness(1.5F).setResistance(10F).setStepSound(soundStoneFootstep);
复制代码

正如之前提到的，这个例子是创建一个名为"Stone"的方块。其中：
  • "new BlockExample (92,1)”为您创建了一个新的方块，第一个数字（92）为方块的ID——必须与众不同。第二个数字（1）为这个方块的材质。
  • "setHardness(1.5F)"代表着摧毁该方块的时间。
  • "setResistance(10F)"代表着该方块的爆炸抗性。
  • "setStepSound(soundStoneFootstep)"代表着当您走过此方块时所发出的声音。

现在您已经成功的创建了一个新的类。可以通过单人指令”/give 92“生成这一方块啦。
