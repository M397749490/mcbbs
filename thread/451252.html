作者: End-Enderman    时间: 2015-5-31 15:08

计分板名字

先用
  1. scoreboard objectives add kill dummy
复制代码
（创造目标），
再用
  1. scoreboard players set @p kill 0
复制代码

用脉冲不断激活
  1. testfor @p[score_玩家名称_min=分数]
复制代码
比较器连接LZ要的命令即可。
另外清零可以用上述的testfor指令，比较器连接
  1. scoreboard players set @p kill 0
复制代码
即可。
