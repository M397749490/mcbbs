DustDeathPenalty

可自定义的死亡掉落，可设置玩家死亡后是否掉落物品，以及掉落物品和掉落经验的概率。同时可以设置不会掉落的物品白名单，以及自定义世界配置。

指令：
/sponge plugins reload DustDeathPenalty 重载插件

权限：
dust.death.drop.disable  拥有该权限的玩家不会掉落任何物品和经验

配置文件：
  1. exp {
  2.     # Whether drop exp
  3.     enable=true
  4.     # Lose half of drop
  5.     lose=true
  6.     # Drop rate
  7.     rate=0.1
  8. }
  9. isSendMsg=true
  10. item {
  11.     # Drop chance
  12.     chance=0.1
  13.     # Whether drop items
  14.     enable=true
  15.     # Is equipment will be dropped
  16.     equipment=true
  17.     # The type don't drop, use /itemdb to get
  18.     whitelist=[
  19.         "minecraft:torch"
  20.     ]
  21. }
  22. # The key is world's name
  23. world {
  24.     world {
  25.         exp {
  26.             # Whether drop exp
  27.             enable=true
  28.             # Lose half of drop
