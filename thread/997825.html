1.12.2版本的

/scoreboard objectives add time dummy
/scoreboard players add @a time 1 {Inventory:[{tag:{a:1b}}]}
/clear @a[score_time_min=6000] stone -1 1 {a:1b}
/scoreboard players set @a[score_time_min=6001] time 0

以上命令全都高频。

然后这样获得特殊的物品 /give @s stone 1 0 {a:1b}

给物品打个没用的nbt，像是A:1，之后命令方块检测玩家背包中是否有nbt标签A:1的物品，如果有就开启计分板计时，比如玩家积分项Timer=6000，用循环命令方块减去1，当到0时清除物品就好了
