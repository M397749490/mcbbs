后记：
这个也是最难搞的一个datapack
昨天我在问答版问如何获取所指方块信息的时候
https://www.mcbbs.net/thread-1062516-1-1.html
给出了使用https://www.mcbbs.net/thread-919112-1-1.html的解决方法
但是工程量浩大，所以是不可能用的
所以就一直找资料，最后google出可以使用area_effect_cloud作为定位方法，具体代码实现如下图所示
  1. #在玩家前3格都生成用于定位的药水云
  2. execute at @s anchored eyes run summon minecraft:area_effect_cloud ^ ^ ^1 {Radius:0f,Duration:2147483647,Tags:[locate]}
  3. execute at @s anchored eyes run summon minecraft:area_effect_cloud ^ ^ ^2 {Radius:0f,Duration:2147483647,Tags:[locate]}
  4. execute at @s anchored eyes run summon minecraft:area_effect_cloud ^ ^ ^3 {Radius:0f,Duration:2147483647,Tags:[locate]}

  6. #判定药水云位置的植物是否符合收获条件，若符合运行function "harvest:harvest:
  7. execute as @e[tag=locate] at @s if block ~ ~ ~ minecraft:carrots[age=7] run function harvest:harvest
  8. execute as @e[tag=locate] at @s if block ~ ~ ~ minecraft:wheat[age=7] run function harvest:harvest
  9. execute as @e[tag=locate] at @s if block ~ ~ ~ minecraft:potatoes[age=7] run function harvest:harvest
  10. execute as @e[tag=locate] at @s if block ~ ~ ~ minecraft:beetroots[age=3] run function harvest:harvest

  12. #将用于定位的药水云清除
  13. kill @e[tag=locate,type=area_effect_cloud]
复制代码
这个样子就很轻松的解决了定位的难题
