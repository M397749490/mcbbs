允许只在黑夜或者白天PvP 配置文件内可修改
插件很简单 内容就是上面的字面意思啦~

版本1.8.1 CB 1.7.9-R0.2
权限(不需要给玩家)

pvpdifftimer.* 全部权限

pvpdifftimer.admin 管理权限

pvptimer reload 重载权限

pvpdifftimer.bypass 白天黑夜均可PVP 无视配置设置



配置文件
  1. # Enable debug messages，linux系统请转码为utf8
  2. Enable-Debug: false
  3. # Default difficulty for disabled worlds. 无需更改
  4. Default-Difficulty: NORMAL
  5. # 世界设置
  6. worlds:
  7.   world:
  8.     #是否在此世界开启本插件,true为开启false为关闭,可以设置多个世界哦只需要复制黏贴格式修改世界名即可
  9.     Enabled: true
  10.     PvP-On:
  11.       # 天黑的时候播报一个通知
  12.       Message: '&4天黑了！PVP开启！小心！难度({difficulty})'
  13.       # Difficulty to set at night
  14.       Difficulty: HARD
  15.       # PvP 开始的时间,13000为黑夜开始,可以自行修改PVP时间哦
  16.       Time: 13000
  17.       # 天黑的时候播放一个声音,不要修改
  18.       Sound: AMBIENCE_CAVE
  19.     PvP-Off:
  20.       # 天亮的时候播报一个通知
  21.       Message: '&2天亮了！PVP关闭！难度({difficulty})'
  22.       # Difficulty to set at day
  23.       Difficulty: NORMAL
  24.       # PvP 结束的时间,0为白天开始,可以自行修改PVP时间哦
  25.       Time: 0
  26.       # 天亮的时候播放一个声音,不要修改
  27.       Sound: CHICKEN_HURT
