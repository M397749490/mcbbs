MultiChat

MultiChat 插件 Nukkit版.

这款插件会根据玩家的权限组修改聊天格式。MultiChat是为权限插件Multipass而创建，并不支持其他权限插件。




权限
multichat.config
允许使用 MultiChat 指令




指令
/chat help
显示 MultiChat 帮助




聊天格式配置
/chat set chat <组> <聊天格式>
配置默认聊天格式
例子:
/chat set chat vip &6[高级会员]%player%: &a%message%






名称标签配置
/chat set name <组> <名称标签格式>
/chat set tag <组> <名称标签格式>
/chat set nametag <组> <名称标签格式>
配置默认的名称标签格式
例子
/chat set tag vip &6[VIP]%player%




权限组聊天格式配置
/chat group chat <组> <聊天格式>
配置定义权限组中的玩家的聊天格式
例子:
/chat group chat vip &6[贵族]%player%: &a%message%






权限组名字标签配置
/chat group name <组> <名字标签格式>
/chat group tag <组> <名字标签格式>
/chat group nametag <组> <名字标签格式>
配置定义权限组中的玩家的名字标签
例子
/chat group tag vip &6[贵族]%player%






重载
/chat reload
重载插件配置
