作者: 最亮的信标    时间: 2020-4-8 10:47
其实记分板更复杂
先手动输入（聊天栏）
/scoreboard objectives add time dummy（创建一个名为time的记分板）
/scoreboard objectives setdisplay sidebar（这里建议开一下右边的记分板显示）
循环命令方块 保持开启/scoreboard players add time time 1（每循环一次给time的time分数+1）
（聊天栏）添加一个假人（这样方便调整） 比如/scoreboard players set t1 time 500（增加一个名叫t1的假人）
然后检测（循环命令方块，但是我更建议在原来的循环上放连锁）/execute if score time time <条件> t1 time run <命令>（条件应该敲上去自己会出来 命令就是你要在这个时候执行什么指令）
如果想让这个东西停掉 我个人建议是再设个值（如stop）然后把第一个命令方块改成/execute if score time time < stop time run scoreboard players add time time 1

JAVA版并不自带延迟功能，基岩版是为了弥补指令和nbt的大部分缺少，并且其实这个功能是抄教育版的，没太大用处
使用1.13以上版本用计分板，1.12建议循环传输信号的中继器

1.13以上：
scoreboard objectives add time dummy
scoreboard players add time time 1
execute if score time time matches (执行延迟秒数除以20) run execute as @a at @s if block ~ ~-1 ~ (方块) run (执行指令)execute if score time time matches (执行延迟秒数除以20) run scoreboard players set time time 0
