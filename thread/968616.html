近期开服的时候发现特殊物品放进一些容器（工作台铁砧熔炉）中会消失属性或者名称报废。。

于是就做了这个插件

配置文件/指令
无需配置也没有指令

使用方法
放入plugin文件夹重启服务器即可

很简单的一个插件，防止玩家用rpg物品合成东西或者烧着玩变成普通物品
通过判断物品是否拥有lore标签来识别是否是rpg物品

更新内容：
1.增加酿造台和附魔台的限制
2.修复了六楼小伙伴提出的bug@红人丶云浩
三月十四号更新：
1.加入配置文件
2.加入对生存2*2合成台的限制
3.加入白名单关键词，比如关键词为123
那么只要物品含有123这条lore则允许放入
注意 是关键词检测 及时lore是“ABC123”
只要有123这段关键词即视为检测通过
这样方便腐竹隐藏lore，可以直接把关键词插入在lore里面
比如关键词“§1§2”那么只要物品含有如“§1§2这是个神奇的物品”
则是检测通过 我也不知道咋形容 这样感觉会好点
如果你的关键词是中文 记得转码

#配置文件
config:
#额外需求可在帖子内留言 看见了会添加
  ##防止背包（四个格子内个合成台）

  rl: true
  rllore: "允许放入熔炉"

  gztlore: "允许放入工作台"
  #防止铁砧

  tzlore: "允许放入铁砧"
  #防止附魔台
  fmt: true
