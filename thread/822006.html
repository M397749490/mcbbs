TabooExamine

独特的新手考核方案
为你的服务器创建试卷

当前版本 v1.0-SNAPSHOT



前言

这个插是我半年前写的，当时做的服务器就是使用这款插件做的新手考核。后来因为电脑出了点毛病导致插件源码全都丢了，然后就理直气壮的鸽了，插件也就顺理成章的发出来了。不过我发现我半年前写的代码竟然还能看的下去，站内那款 TabooLine 我已经看不下去了。



功能

这款插件可以为你的服务器创建考核系统！没错，在服务器里也可以做卷子了！小学生的末日来了！哈哈哈哈嗝。
这款插件有什么特色？
  • 创建无数张试卷（小学生你们完了！！！）
  • 自定义考核问题的数量（你可以创建100道题目，但是考核时只会随机抽取10道）
  • 自定义考核通过的条件（10道题目答对8道即可通过）
  • 自定义考核开始/通过/失败时执行的任意指令（考核通过传送到新手村啥的）
  • 自定义考核所需/跳过权限（你是大会员可以不用做卷子！）
  • 自定义考核冷却时间或是否只能进行一次考核（节假日也要做卷子！）
  • 自定义考核题目的答案数量（不好意思免费版只能做选择题）
  • 完全自定义的界面（所有玩家可见内容均可自定义）
  • 完全自定义的提示（拒绝陋逼提示从我做起）
  • 没有源码（我自己都没有你还想有？）
  • 随缘教程（有心者懂，无心者猜）

命令

命令作用权限

/examine open [考核名称]开始做卷子管理员

/examine reset [玩家] [考核名称]重置卷子数据管理员
/examine reload重载插件管理员

创建考核

本插件提供了一份默认的考核配置，位于：
  1. plugins\TabooExamine\Examines\Example.yml
复制代码
你可以在这个文件下创建任意以 yml 结尾的文件作为试卷配置



考核判断

默认的考核配置中提供了以下配置：

  2. condition:
  3.   # 指当玩家拥有这个权限时则无法进行考核
  4.   permission-deny: '-'
  5.   # 指玩家拥有这个权限时才可以进行考核
  6.   permission-require: '-'
  7.   # 指是否只能进行一次考核，无论考核是否通过
  8.   only-once: true
  9.   # 指考核的冷却时间，格式为 "1d;1h"，时间段之间使用 ";" 分割
  10.   cooldown: '-'
复制代码
部分时间段示范：
时间写法
一天1d
一周7d
一时三十分1h;30m
一分三十秒1m;30s



考核确认

本插件允许你自定义考核的确认界面，默认的考核配置中提供了以下配置可供参考
  1. confirm:
  2.   # 格子号
  3.   # 代表确认界面中物品的位置
  4.   2:
  5.     material: STAINED_CLAY
  6.     data: 5
  7.     name: '&a确认考核'
  8.     lore:
  9.     - ''
  10.     - '&7点击开始考核'
  11.     # 动作（ACCEPT = 确认考核，CLOSE = 关闭界面）
  12.     # 代表点击后是确认考核还是关闭界面。
  13.     action: ACCEPT
  14.   4:
  15.     material: BOOK_AND_QUILL
  16.     name: '&f新手考核'
  17.     lore:
  18.     - ''
  19.     - '&7是否开始新手考核'
  20.     - '&7考核过程中禁止关闭界面'
  21.   6:
  22.     material: STAINED_CLAY
  23.     data: 14
  24.     name: '&4再想想'
  25.     lore:
  26.     - ''
  27.     - '&7我需要在考虑一下'
  28.     action: CLOSE
