作者: a8105    时间: 2019-7-21 19:42
不建议这样new File
建议使用:
假设extends JavaPlugin的是Main类
public class Main extends JavaPlugin{
  public static Main instance;
  onEnable(){
    instance=this;
  }
}
File file=new File(Main.instance.getDataFolder(),"Message.yml");
其次建议使用重新赋值的方式进行重载:
public void reload(){
    message=YamlConfiguration.loadConfiguration(file);
}
