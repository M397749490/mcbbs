Residence Prefix
在领地内聊天有前缀/后缀
注意:本插件依赖于Residence领地插件，测试版本为4.5.7.0,旧版本可能不支持。
ResidencePrefix2完美兼容Residence v2和v4，v4.5.10.0+
介绍
ResidencePrefix通过验证领地主人等方式设置领地的聊天前缀或后缀
指令和权限
指令
/rpset <前缀> 设置当前领地前缀
/rpunset 取消领地前缀
/rplist 查看你的领地列表并遍历是否包含前缀
/rpreload 重载配置文件
权限
rp.reload 重载插件
rp.set 设置前缀
rp.unset 取消前缀
rp.list 查看领地列表是否包含前缀
rp.admin 管理员权限
配置文件
  1. DefaultResidence: 'Welcome'
  2. DefaultPrefix: '&a&l可选前缀'
  3. SettingLength: 12
  4. TogglePrefix: true
  5. ToggleSuffix: false
复制代码
版本日志
------------
0.1 增加领地前缀
0.2 增加领地主人验证 修复多世界颜色代码BUG，增加默认前缀
0.3 增加前后缀并设置开关，可限制前缀长度
------------
2.1 兼容领地插件Residencev2旧版本
------------
3.0 兼容领地插件Residence4.5.10.0以上版本

怎么加啊？

我简单说一下这个
因为bukkit的插件加载机制是A-Z
就是字母从A-Z，而本插件开头字母是R
GroupManager开头是G
所以权限组先加载了
如果没有特定的定制服务端来管理加载插件
可以利用bukkit的插件前置，让本插件在GM前加载即可
具体操作方法：
用压缩软件打开GM的jar包用文本编辑器打开plugin.yml
添加depend: [ResidencePrefix]
保存即可
