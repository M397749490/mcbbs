作者: Zapic    时间: 2019-1-7 21:34
这里提到的Sponge,那么应该会用到Nucleus.
Nucleus可以配置一旦检测到afk就踢出玩家的配置,具体在main.conf:
  1. # +------------------------------------------------------------+
  2. # |                            AFK                             |
  3. # +------------------------------------------------------------+
  4. afk {
  5.     # 如果设置为true,服务器将会在隐身的玩家进入AFK状态的时候发布通告.如果设置为false,只有没有隐身的玩家能够进入AFK状态.
  6.     afk-when-vanished=false
  7.     # 以秒为单位的时间,玩家如果在指定的时间内不活跃,将会自动进入AFK状态.设置为0以禁止此项,或者为玩家分配"nucleus.afk.exempt.toggle"权限.
  8.     afktime=300
  9.     # 以秒为单位的时间,玩家如果在指定的时间内不活跃,将会自动被服务器踢出.设置为0以禁止此项,或者为玩家分配"nucleus.afk.exempt.kick"权限.
  10.     #
  11.     # 请注意,这里的时间不是自从进入AFK之后开始计算的,而是从最后一次活跃的时候开始计算的.如果将此值设置为同"afktime"相等的值,那么相关玩家在进入AFK的同时就被服务器踢出.
  12.     afktimetokick=0
  13.     # 如果设置为true,任何尝试同AFK状态玩家交互的请求都会被告知此玩家处于AFK状态.
  14.     alert-on-command-send=false
  15. ...
复制代码

只要把"afktimetokick"设置为等同于"afktime"的值,那么服务器检测到玩家进入afk状态时就会被立即踢出服务器.
