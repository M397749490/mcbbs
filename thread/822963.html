SimpleCrates
插件信息 About
SimpleCrates（宝箱）是一款基于Nukkit的娱乐的插件，它的作用在于可以让管理/服主自定义宝箱，让玩家点击获得奖励，类似于Bukkit的神秘宝盒，适用于游戏服！
授权搬运 Authorize

申请中

食用方法 Use
食用方法很简单，将其丢入/plugins/内，重载服务器即可，此插件没有任何指令权限，所以只能重启服务器才能加载插件，或者添加插件PlugMan，添加后，测试插件，调用/禁用插件十分方便！
插件指令 Commands
/crates read - 显示项目的信息（在您手中）以便于配置
/crates list - 列出宝箱列表
/crates create <crate> - 创建一个宝箱
/crates delete <crate> - 删除一个宝箱
/crates setblock <crate> - Set the crate block (It will pick the block you're looking at)
/crates additem <crate> - 将物品加入宝箱
/crates addcmd <crate> <command> - 添加奖励命令
/crates removecmd <crate> <command> - 删除奖励命令
/crates givekey <player> <crate> <amount> - 给玩家一个宝箱钥匙
/crates givekeyall <crate> <amount> - 给所有人一个宝箱钥匙
插件权限 Permissions
只有一个
crates.admin - 获得所有权限
配置文件 Config
  1. options:
  2.   #插件前缀
  3.   prefix: '&f[&e&lSimpleCrates&r&f]&f'
  4.   rounds: 3
  5. crates:
  6. #宝箱名字
  7.   default:
  8.   #宝箱显示名
  9.     displayname: '&e&lSimple Crate'
  10.     #使用执行命令/支持多行
  11.     commands:
  12.     - give {user} diamond 1
  13.     - tell {user} Thanks for downloading SimpleCrates!
  14.     #使用执行奖励
  15.     rewards:
  16.       #奖励物品
  17.       items:
  18.         enchantedglass:
  19.           #物品ID
  20.           id: 20
  21.           #物品耐久
  22.           durability: 0
  23.           #物品名
  24.           name: '&r&bEnchanted Glass'
  25.           #物品表情
  26.           lore:
  27.           - Very special indeed!
  28.           #物品数量
  29.           amount: 16
  30.           #物品附魔 '附魔ID': 等级
  31.           enchantments:
  32.             '0': 0
  33.             '5': 2
  34.       #奖励命令
  35.       commands:
  36.       - give {user} cookie 1
  37.       - tell {user} Thanks for opening a simple crate!
