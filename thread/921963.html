标题: 1.13+如何不穷举检测一个实体是否在水里
1.13之前检测实体是否在水里很简单，只需要检测脚的位置或者头的位置是不是water就可以了，但1.13之后多了各种水下植物、含水方块以及气泡柱，这使得检测实体是否在水里变得很麻烦。
那么，除了穷举出所有水、水下植物、含水方块以外，还有什么更简单的办法可以检测实体是否在水里，包括只是脚在水里和头部没入水下（会显示气泡且会有水下音效）两种情况的检测。
检测Air值的办法已排除，因为实体有水下呼吸附魔/效果时会有影响，也无法检测气泡柱，对鱼类和亡灵生物也无效，再加上1.13+出水并不会马上回满氧气值导致实体出水后仍然会被检测到

加个注解和分行吧.

//out
execute as @p at @s
store result score @s air
run data get entity @s Air
即时存储玩家air值

execute as @p[tag=!in] at @s
run tag @s add out
当不处于in状态时,添加out标签

//in
execute as @p[tag=out] at @s
unless score @s air matches 300
run tag @s add in
当air值不等于300时,添加in标签

execute as @p[tag=in] at @s
run tag @s remove out
当处于in状态时,移除out标签

//check1
execute as @p[tag=in,tag=!check] at @s
store result score @s check
run data get entity @s Air
添加check值(即当前air值),为后续提供对比数

execute as @p[tag=in,tag=!check] at @s
run tag @s add check
添加check标签

//check2
execute as @p[tag=check] at @s
if score @s air < @s check
run tag @s remove check
当前air值小于check值时,移除check标签
被执行后会跳回check1为check重新赋值

execute as @p[tag=check] at @s
if score @s air > @s check
run tag @s remove in
当前air值大于check值时,移除in标签
被执行后会跳回最初位置重新赋予out标签

//check3
execute as @p[tag=out] at @s
run tag @s remove check
当状态为out时,移除check标签

execute as @p[tag=in] at @s
if score @s air matches 300
run tag @s remove in
当状态为in但air值为满时,移除in标签
