作者: darkyun    时间: 2017-2-9 14:45
直接使用命令。
/rpgitem 飞行 remove
/rpgitem 飞行 create
/rpgitem 飞行 display 右键飞行
/rpgitem 飞行 hand 飞行符
/rpgitem 飞行 type 稀有
/rpgitem 飞行 item 264
/rpgitem 飞行 armour 0
/rpgitem 飞行 armournum 0
/rpgitem 飞行 power command rightclick 0 右键开启飞行 `fly` * 1
/rpgitem 飞行 give


就创建了一个叫右键飞行的物品。，
