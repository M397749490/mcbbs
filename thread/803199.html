教程（有点乱，别介意，下次就出ooc）

执行一次： /scoreboard objectives add zong dummy  /scoreboard objectives add lei stat.useItem.minecrafr.golden_sword  
/scoreboard objectives add leidian dummy  
/scoreboard objectives add binghuo dummy  
/scoreboard objectives add JS stat.useItem.minecraft.diamond_sword
高频连接
雷
/scoreboard players add @e zong 1
/scoreboard players set @e[score_zong_min=31,type=!ArmorStand] zong 1  
/scoreboard players add @e leidian 1 {SelectedItem:{id:"minecraft:golden_sword",tag:{Unbreakable:1b,HideFlags:3,ench:[{id:16,lvl:4},{id:1,lvl:5}]}}}  /scoreboard players set @e[score_zong_min=30] leidian 0
/execute @e[score_leidian_min=1,score_lei_min=1] ~ ~ ~ /execute @e[type=!Player,c=1,r=7,rm=2] ~ ~ ~ /particle flame ~ ~ ~ 0.1 0.1 0.1 0.4 11  /execute @e[score_leidian_min=1,score_lei_min=1] ~ ~ ~ /execute @e[c=-1,r=5,rm=2,type=!Item] ~ ~ ~ /summon LightningBolt ~ ~-1 ~  /scoreboard players set @e[score_zong_min=30,score_lei_min=1] lei 0
