The New Java Launcher is Live
已推出新的 Java 版启动器
Available on Windows, MacOS, and Linux!
可在 Windows、MacOS 和 Linux 平台使用！

We were nervous when we first heard the rapid footsteps of the Launcher team scurrying up to our desk, but no need to panic - they come bearing good news! The new Launcher has gone live for the Java Edition of Minecraft for Windows, MacOS, and Linux. This is the first, big step in the Launcher team’s quest to create a unified experience for all Minecraft players!
当我们第一次听到启动器团队快步走来的脚步声时我们十分紧张，不过倒没有必要感到惊慌——他们带来的是好消息！Java 版 Minecraft 的启动器已经推出了适用于 Windows、MacOS 和 Linux 平台的版本。这是第一步，是启动器团队为所有 Minecraft 玩家营造统一的游戏体验的一大步！

The fresh new look and feel was created with the player in mind - updated and intuitive UX design along with responsive UI will make getting to the game (or wherever you want to go!) easier than ever. Most importantly, the Launcher has new core logic to support bigger and better things in the future of Minecraft.
全新的外观是全心全意为玩家设计的——现代直观的用户体验设计和响应式用户图形界面设计会让进入游戏（或者别的你要做的事）变得比以往更加容易。最重要的是，启动器有了全新的核心逻辑，能够支撑将来 Minecraft 更恢宏、更出色的规划。



But like a mullet, this article is a mix of business in the front and party in the back. If by the back, you mean technical updates! The new Launcher will handle many issues that will make the user’s experience much smoother:
这篇文章就像[ruby=zī]鲻[/ruby]鱼一样，前半部分正经介绍，后半部分开始狂欢[1]。新的启动器将会解决许多的能使用户体验更加流畅的问题：

  • Improved accessibility features for Windows and Mac users with disabilities
  • 改进针对使用 Windows 和 Mac 系统的残疾用户的无障碍功能
  • Ability to switch between profiles within the Launcher
  • 在启动器内切换档案的能力
  • Added patch notes for new releases
  • 添加了新版本的更新日志
  • Updated News tab
  • 更新新闻选项卡
  • New language system
  • 新的语言系统
  • Reduced the Launcher update download size
  • 减小启动器更新的下载大小
  • Installations (previously called Configurations) can now be played directly from the Installations tab
  • [ruby=Installtaions]配置[/ruby]（之前被称为[ruby=Configurations]配置[/ruby]）现在可以直接在配置选项卡游玩了


Best of all, all you need to do to get the new Launcher is restart your current launcher and it will auto update to the latest version. Yes, even I, someone who electrocuted herself while plugging in a toaster, can easily (and painlessly) update to the new Launcher. You can too!
最后，为了得到新启动器，你需要做的仅仅是重启当前的启动器，然后它就会自动更新到最新版本。甚至像我这种在插烤面包机的时候把自己电到的人都能轻松地（并且无痛地）更新到新启动器，相信你也可以！
