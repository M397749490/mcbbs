作者: Ghost__    时间: 2017-4-3 18:44
直接在地皮输入/gamerule doMobSpawning false 这个是禁止怪物生成的指令 输入完毕后不会清除已有的怪物 再输入/killall mobs 999 即可

作者: 浅念哥    时间: 2017-4-3 19:30
/mvm set animals false 禁止刷动物
/mvm set monsters false 禁止刷怪物
/mvm set diff 0 和平模式
/killall all 清除所有怪物
/mv reload 重载并保存
