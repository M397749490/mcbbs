指令：
指令 说明
/ae 列出其它指令帮助信息
/ae set <name> <p/s> <command> 创建或者更新一个指令区域
/ae remove <name> 移除一个指令区域
/ae list 列出所有指令区域
/ae reload 重新加载





权限：
仅OP可以使用


食用方法：

创建：
1. 使用/ae set sayHello p say hello %PLAYER%来创建一个区域，sayHello是区域的名字，p则代表由玩家执行，如果为s则是由后台执行，%PLAYER%则会被替换成对应的玩家名称,然后会要求点击两个点
