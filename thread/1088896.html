根标签
  • display：可选的显示数据。
    • icon：一个物品的ID，用于显示进度窗口。
      • item：物品的ID。
      • nbt：物品的nbt标签。
    • title：进度的名称，纯文本。
    • title：JSON文本（格式和/tellraw等命令中使用的类似）。
    • frame：图标边框的可选种类。challenge为挑战进度边框；goal为目标进度边框；task为普通进度边框（默认）。
    • background：用于此进度标签的背景的可选目录（仅根进度）。
    • description：进度的描述。
    • description：进度的描述。
    • show_toast：可以为true或false。是否在完成此进度后显示提示信息。默认为true。
    • announce_to_chat：可以为true或false。是否在完成此进度时在聊天窗口提示。默认为true。
    • hidden：可以为true或false。是否在进度屏幕隐藏此进度，直到完成进度。会影响其子进度。当父进度值为true后便无法覆盖。默认为false。
  • parent：此进度的可选的上游进度id（不适用于根进度）。
  • criteria：必须达成的条件。
    • 条件名称：给予此条件的名称（可以为任何字符串，必须唯一）。
      • trigger：此进度的触发条件；指定游戏为进度检查的条件。
      • conditions：当触发器激活时所有需要达成的条件。

  • requirements：可选，所有条件（条件名称）列表。如果所有条件都需要，此项可以被忽略。有多个条件：要求包含了要求条件列表（所有条件都需要被提及）。任一列表中所有条件达成后，进度会完成（基本上是“与”、“或”的条件分组）。
  • rewards：可选，当进度达成时获得的所有奖励。
    • recipes：配方列表。
    • loot：战利品表列表。
    • experience：获得的经验值总数。
    • function：完成进度后执行的函数（以进度获得者为执行者）。

复制代码
大概意思就是将main命名空间里的"tick"mcfunction文件作为tick（详情请见rua的教程）

tick.mcfunction:

  1. clear @a glass_bottle
  2. execute as @e[type=bee,team=a] at @p unless block ~ ~ ~ #minecraft:flowers run tp @s ~ ~ ~ ~ ~
  3. execute as @e[type=bee,team=a] at @s if block ~ ~ ~ #minecraft:flowers run particle happy_villager ~ ~ ~ 0.4 0.4 0.4 0 2

  5. execute as @e[type=bee,team=a] at @s store result score @s log run data get entity @s HasNectar
  6. execute as @e[type=bee,team=a] at @s if block ~ ~ ~ #minecraft:flowers if score @s log matches 1 if entity @p[tag=!get] run setblock ~ ~ ~ air
  7. execute as @e[type=bee,team=a] at @s if score @s log matches 1 run tag @p add get

  9. execute as @e[type=bee,team=a] at @s if block ~ ~-1 ~ #minecraft:beehives if score @s log matches 1 run scoreboard players add @p score 1
  10. execute as @e[type=bee,team=a] at @s if block ~ ~-1 ~ #minecraft:beehives if score @s log matches 1 run playsound entity.experience_orb.pickup ambient @a
  11. execute as @e[type=bee,team=a] at @s if block ~ ~-1 ~ #minecraft:beehives if score @s log matches 1 run xp add @p 1 points
  12. execute as @e[type=bee,team=a] at @s if block ~ ~-1 ~ #minecraft:beehives if score @s log matches 1 run tag @p remove get
  13. execute as @e[type=bee,team=a] at @s if block ~ ~-1 ~ #minecraft:beehives if score @s log matches 1 run data merge entity @s {HasNectar:0b}

  15. execute as @p store result score #level1 log run xp query @p levels
  16. execute as @p unless score #level1 log = #level2 log run give @s bee_nest{CanPlaceOn:["minecraft:grass_block"]}
  17. execute as @p unless score #level1 log = #level2 log run give @s honey_bottle
  18. execute as @p unless score #level1 log = #level2 log run execute as @p store result score #level2 log run xp query @p levels

  20. effect give @a invisibility 1000000 0 true
  21. effect give @a slow_falling 1000000 0 true
  22. effect give @a[scores={sneak=1..}] levitation 1 1 true
  23. scoreboard players remove @a[scores={sneak=1..}] sneak 3

  25. scoreboard players remove @a[scores={death=1..}] score 5
  26. clear @a[scores={death=1..}]
  27. scoreboard players remove @a[scores={death=1..}] death 1

  29. data merge entity @e[type=bee,team=a,limit=1] {CannotEnterHiveTicks:32767}
  30. title @a actionbar [{"text":"Score: ","color":"yellow"},{"score":{"name":"*","objective":"score"},"color":"yellow"}]
  31. execute as @e[type=bee,team=a] at @s if entity @p[distance=1.3..] run tp @s @p
复制代码
clear @a glass_bottle

就是把刚才进度（作者手动获得的）的蜂蜜瓶的瓶子清除
execute as @e[type=bee,team=a] at @p unless block ~ ~ ~ #minecraft:flowers run tp @s ~ ~ ~ ~ ~
execute as @e[type=bee,team=a] at @s if block ~ ~ ~ #minecraft:flowers run particle happy_villager ~ ~ ~ 0.4 0.4 0.4 0 2

execute as @e[type=bee,team=a] at @s store result score @s log run data get entity @s HasNectar
execute as @e[type=bee,team=a] at @s if block ~ ~ ~ #minecraft:flowers if score @s log matches 1 if entity @p[tag=!get] run setblock ~ ~ ~ air
execute as @e[type=bee,team=a] at @s if score @s log matches 1 run tag @p add get

这里就是检测蜜蜂（就是你）脚下如果没有花（所有带“花”标签的方块）就把蜜蜂tp到你身上
如果有，召唤粒子
其他的就是写保险的（以免玩坏）
execute as @e[type=bee,team=a] at @s if block ~ ~-1 ~ #minecraft:beehives if score @s log matches 1 run scoreboard players add @p score 1
