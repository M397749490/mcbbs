BaiMusic

Sponge版的AudioBuffer
需要配套Mod支持
配套Mod用的是AudioBuffer的
因为我懒得没有空自己再弄一个新的Mod了
基础功能也与AudioBuffer相似
除了不能播放本地音乐和不会切世界关闭音乐外

  1. // config.conf
  2. Music {
  3.   "test" {
  4.     URL = "http://m10.music.126.net/20190804164207/8524de6818777448dfef62b346cb922b/ymusic/f01e/9965/c224/532a812106b9fd3bb34be7e803a4946d.mp3"
  5.     Hash = ""
  6.   }
  7.   "test2" {
  8.     URL = "http://m10.music.126.net/20190804164523/c4c23f944e89716a3b419baf1acc0d68/ymusic/5258/0f5f/015c/e23eb784398544031837660e6d233a6e.mp3"
  9.     Hash = ""
  10.   }
  11. }
  12. // 客户端MOD选择 true 是 AudioBuffer , false 是 BaiMusic
  13. // 然而 BaiMusic 的 MOD 还没有写好
  14. Mod = true

插件命令
  1. /bm play player <玩家名> <歌曲名>
  2. 给指定玩家播放指定歌曲
  3. 权限 BaiMusic.Paly.Player

  5. /bm play world <世界名> <歌曲名>
  6. 给指定世界的玩家们播放歌曲
  7. 权限 BaiMusic.Paly.World

  9. /bm play all <歌曲名>
  10. 给服务器全部玩家播放指定歌曲
  11. 权限 BaiMusic.Paly.ALL

  13. /bm play me <歌曲名>
  14. 给你自己播放指定歌曲
  15. 权限 BaiMusic.Paly.Me


  18. /bm stop player <玩家名>
  19. 停止指定玩家的歌曲
  20. 权限 BaiMusic.Stop.Player

  22. /bm stop world <世界名>
  23. 停止指定世界玩家们的歌曲
  24. 权限 BaiMusic.Stop.World

  26. /bm stop all
  27. 停止服务器全部玩家的歌曲
  28. 权限 BaiMusic.Stop.ALL

  30. /bm stop me
  31. 停止你自己正在播放的歌曲
  32. 权限 BaiMusic.Stop.Me


  35. /bm reload
  36. 重置配置文件
  37. 权限 BaiMusic.Reload
