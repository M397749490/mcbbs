Intro 介绍



  • ServerJars 是由 Songoda 工作室开发的一个小工具，它能帮助你最简单高效的获取到服务端的 jar 文件资源
  • 平台每 8min 扫描一次最新服务端构建状况，你可以轻松在网站上下载最新镜像
  • 下载 ServerJars 小工具，并将启动脚本中原本的服务端文件名更改为 ServerJars 文件名，可以实现每次重启服务器时全自动下载更新服务端




Example 使用示例


  • 新建一个文件夹 Server, 将下载的 serverjars-1.jar 放入
  • 新建一个启动脚本 (.bat)，写入相关参数，如

  1. @echo OFF
  2. TITLE Server

  4. :START
  5. CLS

  7. Java -Xms1G -Xmx1G -Xss512K -XX:+AggressiveOpts -XX:+UseCompressedOops -XX:+UseFastAccessorMethods -XX:ParallelGCThreads=4 -XX:+UseConcMarkSweepGC -XX:-DisableExplicitGC -XX:TargetSurvivorRatio=90 -jar serverjars-1.jar

  9. TIMEOUT /T 25
  10. GOTO START

  12. @PAUSE
复制代码

  • 双击该脚本启动，将会生成 serverjars.properties 配置文件
  • 默认下载最新的 Spigot 构建 并启动，你可以关闭脚本进行相关配置
  • 服务端都将存储在 ./jar 目录下




Conf 配置
  1. #Acceptable Versions (latest, 1.15.1, 1.8, etc...)
  2. #Wed Jan 22 20:44:26 CST 2020
  3. version=latest
  4. type=spigot
复制代码

  • version 填写你需要的服务端版本号, 支持 1.8+, 若写 latest 则为最新的服务端版本 (当前 1.15.2)
  • type 写服务端类型, 当前支持的服务端类型如下

  • bungeecord, velocity, waterfall
  • paper, bukkit, spigot
  • vanilla, travertine
