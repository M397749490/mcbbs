我倒是好奇怎么用testfor检测玩家砍人
1.12及之前的 testfor 等价于1.13之后的 execute if entity

首推方案，使用进度
使用 player_hurt_entity 进度触发器指定entity为player，然后奖励函数，在函数中执行命令并剥夺原进度。这是最稳妥的方法

不过看你问的问题我觉得不能对你掌握这种方法有太大希望，那这里提供另一种方法
建立一个准则为造成伤害的记分板
  1. scoreboard objectives add damage minecraft.custom:minecraft.damage_dealt
复制代码
然后在拥有分数的玩家周围检测是否有恰好被攻击的玩家，执行命令并重置分数即可
  1. execute as @a[scores={damage=1..}] at @s if entity @a[distance=..5,nbt={HurtTime:10s}] run say 233
  2. scoreboard players reset @a[scores={damage=1..}] damage
复制代码
注意，此方案存在误判可能
一种情况是，玩家攻击了一个非玩家实体，而此时该玩家恰好被攻击，或周围有一名玩家恰好被攻击，则会产生误判
