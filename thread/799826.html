插件简介：
本插件允许你的玩家贷款，你可以自定义贷款数额，利率，还款期限等，不仅如此，你还可以设置玩家信用额，当信用额到达一个点时玩家将不能继续贷款，你甚至还可以配置惩罚方式！

配置文件详解：
loan.yml
  1. #配置玩家可以在界面中看到的贷款
  2. #最多支持53个

  4. #用于指定在UI的位置
  5. #必须大于0 小于53
  6. '1':
  7.     Name: '&a小额贷款'
  8.     #贷款金额 支持小数
  9.     Loan: 1000
  10.     #每天的利息(利息不是复利计算)
  11.     Interest: 0.01
  12.     #最多可以借几天
  13.     MaxLoanDays: 5
  14.     #至少要有多少信用点
  15.     Credit: 3000
  16.     #用于UI显示用的物品
  17.     Display:
  18.         #物品ID:损伤值
  19.         Item: 1
  20.         Lore:
  21.             - '&a点击进行贷款'
  22.             - '&a金额: 1000 利息: 1%'
  23.         
复制代码
punishment.yml
  1. #始终只会执行最严重的逾期处罚
  2. Punishment:
  3.     #总逾期天数超过1时触发的命令
  4.     '1':
  5.         #本条目表示总逾期天数为1的处罚
  6.         #命令触发间隔 单位秒
  7.         Interval: 20
  8.         #执行的命令 {player}是玩家名变量
  9.         Commands:
  10.             - 'effect {player} 2 40 1'
复制代码
config.yml
  1. # CreditFunction >> 用于计算玩家信用点数 Loan.Amount表示目前拥有的贷款总数 Loan.LeftTotal表示还欠的钱的总数 Loan.Overdue表示当前逾期的天数
  2. # MinCredit >> 玩家能贷款的最低信用要求

  4. CreditFunction: 5000 - Loan.Amount * 500 - Loan.Total - Loan.Overdue * 200
  5. MinCredit: 3000
复制代码
命令：
  1. /loan >> 打开GUI菜单
  2. /loan autoback (数量) >> 自动还款(自动还最早的贷款)
  3. /loan list >> 查看自己当前背负的贷款以及id
  4. /loan back [id] (数量) >> 指定还款</font>
