小小的换了个做法...不用dummy了
  1. 设立
  2. 每tick判据(口渴度)
  3. 饮水判据
  4. scoreboard objectives add thirst stat.playOneMinute
  5. scoreboard objectives add juicy stat.useItem.minecraft.potion

  7. 判断
  8. 饮水后口渴度-900
  9. 口渴度被扣到负分时处理为0分(防止玩家尝试一次喝一年的量...)
  10. 饮水分数归位
  11. scoreboard players remove @a[score_juicy_min=1] thirst 900
  12. scoreboard players set @a[score_thirst=-1] thirst 0
  13. scoreboard players set @a[score_juicy_min=1] juicy 0

  15. 执行
  16. 口渴度为3000或以上的玩家获得药水效果
  17. 3000以下的玩家移除药水效果
  18. effect @a[score_thirst_min=3000] minecraft:slowness 5 2
  19. effect @a[score_thirst=2999] minecraft:slowness 0
