好了不废话了

首先你先把NPCmods解压打开

打开assets文件

打开customnpcs文件

打开sounds.json文本

滑到最下面

第一步
  "songs.ww10": {
    "category": "player",
    "sounds": [{"name": "songs/ww10", "stream": true}]
  }(这里加一个逗号)（然后按空格）



第二步

  "human.male.villager.yes": {
    "category": "player",
    "sounds": ["human/male/villager/Yes"]
  },
(这里一会粘贴我发的代码)
}
第三步
复制/粘贴
  "songs.音乐名字1": {
    "category": "player",
    "sounds": [{"name": "songs/音乐名字2", "stream": true}]
  }

(注意音乐名字不要太长 打个比方：你的音乐名字1是ww3 音乐名字1填ww3 音乐名字2填ww3)
(音乐文件格式必须是ogg)(音乐名必须是字母或数字)中文不行
（不是所有ogg格式的音乐都行具体的我也不知道建议你使用第二位帖了的转换器）
然后把音乐文件添加到
打开sounds文件
(音乐文件移动到)songs文件


之后如何在NPC里播放音乐我就不多说了
