6.输入如下代码
  1. @echo off
  2. :SB
  3. cls
  4. java -Xmx3G -Xms2048M -jar <输入你的服务端JAR文件名>
  5. echo 是否重启？如果重启，请按下任意键，否则请关闭窗口
  6. pause
  7. goto SB
复制代码
注意！记得把“ <输入你的服务端JAR文件名>”改成你自己服务端JAR文件的名称！
7.保存并退出
8.运行“启动脚本.bat”
此时应该成功了！
