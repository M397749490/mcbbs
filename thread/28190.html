介绍:
这个插件可以定义玩家死亡物品,经验,金钱掉落.
我不知道你有没装类似的插件,但如果你装的有些问题或感到不足的话,你可以试试这个.
config.yml配置文件(推荐使用NotePad++查看):
  1. #若要设置死亡不掉物品,可将'初始物品掉落率'与'物品最小掉落率'设置为0
  2. #玩家死亡物品掉落方式,1为按数量比率掉落,2为按价值比率掉落(推荐)
  3. way: 2
  4. #初始物品掉落率,0-100,整数,比如默认75就是死亡掉落比率75%
  5. itemDropPercent: 75
  6. #物品最小掉落率,0-100,整数
  7. itemMinDropPercent: 10
  8. #物品掉落升级花费固定因子,整数,玩家每次升级物品掉落需要花费=增量因子*玩家物品掉落等级+固定因子,玩家初始物品掉落等级为0
  9. itemFixedFactor: 300
  10. #物品掉落升级花费增长因子,整数
  11. itemIncreaseFactor: 10

  13. #若要设置死亡不掉经验,可将'初始经验掉落率'与'经验最小掉落率'设置为0
  14. #初始经验掉落率,0-100,整数
  15. expDropPercent: 75
  16. #经验最小掉落率,0-100,整数
  17. expMinDropPercent: 10
  18. #经验掉落升级花费固定因子,整数,玩家每次升级经验掉落需要花费=增量因子*玩家经验掉落等级+固定因子,玩家初始经验掉落等级为0
  19. expFixedFactor: 150
  20. #经验掉落升级花费增长因子,整数
  21. expIncreaseFactor: 5

  23. #是否开启死亡掉落金钱,true/false,开启的话需要vault插件与经济系统插件,否则请设为false
  24. #如果此项设为false那么上面的物品与经验掉落玩家将无法使用升级指令
  25. #其实只要设置下面的金钱掉落因子都为0就可以不掉金钱
  26. enableMoneyDrop: true
  27. #玩家金钱不足的时候是否扣成负数,true/false,false的话玩家金钱扣到0便不会再扣
  28. moneyNegative: true
  29. #给玩家的优惠1.0-10.0,实数,只有当上个选项为true的时候有效,指玩家钱少于0时给玩家的打折
  30. #比如设置为1.5时,玩家有10块钱,需要扣30块钱,那么玩家先扣10块钱,到0了,再需要扣20块,这20块/1.5=13.3块,也就是说玩家会再扣13.3块
  31. #不优惠的话直接设为1.0就行了
  32. benefit: 1.5
  33. #金钱掉落固定因子,计算方法同上
  34. moneyDropFixedFactor: 50
  35. #金钱掉落增长因子
  36. moneyDropIncreaseFactor: 1

复制代码


什么情况下你需要这个插件:
一:想要简单的使玩家死亡不掉落任何物品或经验值
二:想要自定义玩家物品与经验值按比例掉落,并可升级
三:想要自定义玩家死亡金钱掉落

使用方法:
把jar文件下载下来后放入plugins文件夹,此外还有一个vaule文件夹,与jar文件放一起,即放入plugins文件夹里
运行服务器一次后会生成一个fyx9文件夹,里面有一个config.yml配置文件,视情况修改,vaule文件夹里有个vaule.yml,里面是物品的价值,可以视情况修改
然后重启一下服务器就ok了.

命令:
/drop info:查看自己的掉落信息
/drop upgrade item:升级物品掉落等级
/drop upgrade exp:升级经验掉落等级
下面是OP专用的命令:
/drop set itemPercent [name] [0-100]:设置指定玩家的物品掉落比率
/drop set expPercent [name] [0-100]:设置指定玩家的经验掉落比率
/drop set itemCostLevel [name] [0-100]:设置指定玩家的物品升级花费等级
/drop set expCostLevel [name] [0-100]:设置指定玩家的经验升级花费等级
/drop set moneyCostLevel [name] [>=0]:设置指定玩家的金钱掉落等级

稳定性:十分稳定;且几乎不会与其它插件相冲突.
此插件特色有二,一是功能的强大丰富;二就是安全稳定性,表现在:
>玩家物品恢复会与原来一模一样,包括位置,耐久,附魔等
>玩家死亡退出游戏回来或服务器重启都不会使玩家物品消失,十分安全
>物品,经验,金钱掉落会十分精确(尤其经验这块,很多地方编码难度较大)
>修正玩家附魔导致的经验变化
如果你在使用其它的类似插件,并且出现过物品消失等情况的话,建议你使用此插件.额外的需要说明的是,此插件较为复杂,虽然我已经尽量搞得易懂一些,这也许是你唯一需要付出的代价吧.
(稳定性说明:这里指的是在假定插件无bug情况下运行,插件对于出现意外情况所表现出来的稳定性)
