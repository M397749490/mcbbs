功能：
  • 自定义MOTD和图标，在维护期间展示
  • 开始和结束定时器，这将在时间结束后开始和结束维护模式
  • %Timer%变量可在pingMessage中使用，以显示时间直到定时器时间结束（配置文件的注释中解释了其他变量和技巧)
  • 白名单，以授予特定玩家在服务器上工作时加入的能力。
  • 维护期间加入您的服务器时给与玩家的通知。
  • 几乎所有的消息时可以自定义的，通过语言文件，以多种不同的语言展示
  • 使用ServerListPlus？维护将在启用维护时切换其状态，并在禁用维护时重新启用ServerListPlus。


用法：
  • 下载插件放置到mods文件夹
  • 然后启动服务器修改配置文件即可

命令：
  1. /maintenance on 开启维护
  2. /maintenance off 结束维护
  3. /maintenance aborttimer 如果在运行或者结束维护，计时器将关闭
  4. /maintenance starttimer <minutes> 启动计时器，然后到时间启动维护
  5. /maintenance endtimer <minutes> 启动计时器，然后到时间关闭维护
  6. /maintenance reload 重载
  7. /maintenance update 检测更新
  8. /maintenance remove <name/uuid> 删除白名单
  9. /maintenance add <name/uuid> 添加白名单
  10. /maintenance whitelist 列出白名单
复制代码

权限:
  1. maintenance.whitelist.remove
  2. maintenance.whitelist.add
  3. maintenance.whitelist.list
  4. maintenance.update
  5. maintenance.setmotd
  6. maintenance.motd
  7. maintenance.reload
  8. maintenance.dump
  9. maintenance.timer
  10. maintenance.toggle
复制代码

配置文件：
  1. # 启动维护模式
  2. maintenance-enabled: false

  4. # 启用维护时，服务器MOTD将显示的消息。
  5. # 如果您输入多个条目，则每次刷新时都会随机选择其中一个条目。
  6. # 如果运行计时器，则可以通过在刷新消息中包含‘%timer%’来显示剩余时间(也适用于playercount(-hover)消息)。
  7. pingmessages:
  8.   - "&cMaintenance mode!%NEWLINE%&6We will be back soon!"
  9. # - "Other entry"

  11. # 如果设置为true并且计时器当前正在运行，则将选择来自此池的消息。
  12. # 而不是上面的，所以当计时器正在运行/不运行时，您可以有不同的消息。
  13. enable-timerspecific-messages: false
  14. timerspecific-pingmessages:
  15.   - "&cMaintenance mode!%NEWLINE%&6We will be back in %TIMER%!"
  16. # - "Other entry"

  18. # 如果设置为true，则下面的消息将显示在服务器列表中服务器的右上角，其中通常会显示玩家数量。
  19. # 如果设置为false，将显示正常的播放计数。
  20. #
  21. # 或者，如果要在自定义消息中包含播放者计数，可以使用“%Online%”和“%Max%”(例如“&c Maintenance&7%Online%&8/&7%Max%”)。
  22. enable-playercountmessage: true
  23. playercountmessage: "&4Maintenance"

  25. # 当您将鼠标移到服务器列表中服务器右上角的文本上方时显示，
  26. # 通常显示PlayerCount的位置。
  27. playercounthovermessage: "&cCurrently under%NEWLINE%&cmaintenance"

  29. # 如果启用，且服务器在运行计时器时重新启动，则重新启动后将继续加载计时器。
  30. # 如果服务器脱机时计时器结束，服务器重新启动后将立即停止维护。
  31. continue-endtimer-after-restart:
  32.   enabled: false
  33. # 每次启动、取消或结束计时器时都会设置此值。
  34. # 请勿手动更改此值。
  35.   end: 0

  37. # 如果使用定时器命令：在启用/禁用维护之前断中，将会有广播。
  38. timer-broadcast-for-seconds: [1200, 900, 600, 300, 120, 60, 30, 20, 10, 5, 4, 3, 2, 1]

  40. # 如果禁用之后有更新，您将不再收到任何消息。
  41. # 不建议禁用，因为新版本通常会运行得更好，错误更少。
  42. # 但是，您始终可以使用“/Maintenance update”命令手动检查更新。
  43. update-checks: true

  45. # 用于自动更新配置，请勿更改此值。
  46. config-version: 2
