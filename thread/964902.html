教程：如何让玩家达到指定条件才能游玩粘液科技。这是一篇萌新腐竹也能看懂的教程~
本教程默认使用的Slimefun版本为NOBUTS大佬发布的Slimefun4.1.15重置版
本教程将直接给出详细示例，具体实现方法可根据各位腐竹自己的实际需求进行修改
-
需要用到的插件：
粘液科技本体- > Slimefun
粘液科技前置 -> CS-CoreLib
礼包 -> EasyKitsRel
判定物品Lore来在后台执行指令 -> LoreCommand
让后台以玩家身份执行指令 -> PlayerCommands
菜单 -> DeluxeMenus
权限组 -> LuckPerms
-
使用场景：空岛生存服
示例中使用的服务端来自极简主义·空岛生存，主菜单样式来源于此

原理：
1.取消玩家默认拥有的slimefun.command.guide权限，使得玩家无法通过指令/sf guide获取指导书
2.当玩家达到一定条件后，给予玩家slimefun.command.open_guide权限，使得玩家能够使用指令/sf open_guide来打开指导书菜单
3.将/sf open_guide指令绑定到一个物品上，实现指导书物品化，还原原有的Slimefun指导书设定


步骤：
1) 按照教程正常安装Slimefun插件，这里不再赘述
2) 修改Slimefun插件文件中的plugin.yml，取消默认玩家拥有权限slimefun.command.guide这一设置
    方法：用压缩软件打开jar文件，找到里面的plugin.yml，用编辑软件打开，找到以下设置
  1.   slimefun.command.guide:
  2.     description: Allows you to obtain the Slimefun guide book
  3.     default: true
复制代码
将default: true修改为default: op
  1.   slimefun.command.guide:
  2.     description: Allows you to obtain the Slimefun guide book
  3.     default: op
复制代码
.转码并保存至jar文件(通常情况转码为UTF-8)
3) 制作一个用于绑定指令的物品    这里推荐使用插件Editlore进行物品编辑
    这里楼主已给好样式，可输入以下指令快速制作
  1. /lore name &e&l远古工艺之书 &7(右键打开)
  2. /lore add &f
  3. /lore add &e&l右键点击 &8> &7浏览物品
  4. /lore add &f
  5. /lore add &a&o介绍：
  6. /lore add &f
  7. /lore add &f &f这是一本关于远古工艺的食用指导书~
  8. /lore add &f
  9. /lore set 7 #time_sfguide

注意：在使用Editlore插件对物品进行Lore编辑的过程中可能会出现些许延迟，如果编辑不成功可多输入一次指令，如果发现编辑错了可以使用指令"/lore set  <行数> <内容>"进行更正 (物品名称不算做一行)

4) 使用LoreCommand插件来判定Lore，从而实现物品绑定指令
    这里楼主判定的Lore是#time_sfguide，LoreCommand的配置如下
  1. lore:
  2.   '#time_sfguide':
  3.     permission: 'timekd.cz.level233'
  4.     commands:
  5.      - 'pcmd [player] p:/sf open_guide'
复制代码
这里的设置项'#time_sfguide'正是插件配置上一行中提到的用于判定的Lore，各位腐竹可根据实际需求自行更改
至于绑定这个指令以及添加timekd.cz.level233这一权限的原因，会在接下来进行讲解

5) 测试过程中我们会发现LoreCommand会以后台的身份执行指令，这时我们就需要PlayerCommands插件来让后台以玩家的身份执行打开指导书菜单的指令
    上面LoreCommand的配置第五行正是用来执行这一指令：pcmd [player] p:/sf open_guide
  1. pcmd -> 插件主指令
  2. [player] -> 获取玩家ID (玩家ID的占位符，这一功能来自LoreCommand插件)
  3. p:/sf open_guide -> p:以玩家身份执行指令，/sf open_guide指导书菜单的打开指令
