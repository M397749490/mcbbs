指令


  1. /furniture list (option)  查询所有的家具 (页数)
  2. /furniture give <furniture> (player) (amount) 把多少家具给某玩家
  3. /furniture debug 进入查询模式，可以查询家具的主人等
  4. /furniture manage 进入管理模式，更改主人，增加或减少可使用的玩家
  5. /furniture purge <time> 【不是很懂这个，谁知道了赶紧告诉我呀 谢谢】
  6. /furniture recipe <furniture> (edit/remove) 查询（编辑／删除）家具制作方法
  7. /furniture remove (type/player/world/plugin/ID/Distance/lookat/all) 删除家具
  8. /furniture remove lookat 删除面前的家具
  9. /furniture toggle 开启或者关闭家具
  10. /furniture download <id> (newName) 从http://mcstats.org/plugin/Furniturelib下载一个家具
  11. /furniture delete <name> 删除一个下载的家具
  12. /furniture save 保存下载的家具和编辑或删除的制作方法
复制代码


权限


  1. furniture.craft.<systemID> 制作某家具的权限
  2. systemID就是它们的英文名字
  3. 可以放方块进去的炼药锅就是 barrels 注意没有大写
  4. furniture.place.<systemID>放置某家具的权限
  5. furniture.place.all 放置所有家具的权限
  6. ProtectionLib.admin 【需要protectionLib】
  7. 可以在任何地方 放置家具无视所有领地插件等（上面列举过）

配置文件

这个Dicefurniture本身是没有配置文件的，所有的配置文件都是前置插件furnitureLib产生的，所以配置文件是在／plugin／furnitureLib里面找

CONFIG

  1. #如果正常的config文件的话，上面还有一大段描述的，这里就直接进入正片啦
  2. config:
  3.   UseMetrics: true     #如果设置为true，服务器使用插件的信息会自动发送到
  4. http://mcstats.org/plugin/Furniturelib
  5.   Language: EN_en  #如果要用中文的话输入CN_sm 且文件在下面的下载区域哦
  6.   useParticles: true   #如果设置为true，当没有足够位置放置家具的时候，会有提示颗粒显示
  7.   DisableSitting: false  #如果设置为true，所有的坐和躺的功能将失效
  8.   viewDistance: 100  #可视范围 （设置太高会有增加延迟）
  9.   LimitType: PLAYER #权限设置范围 可用 PLAYER（每个玩家独立）／CHUNK（每个区域独立）／WORLD（每个世界独立）
  10.   glowing: true #如果设置为true，即为可生长的
  11.   CheckUpdate: true  #如果设置为true，即为自动检查更新的
  12.   rotateOnSit: true #如果设置为true，当坐下时可以旋转视角
  13.   Creative: #如果玩家为创造模式
  14.     RemoveItems: false  #如果设置为true，玩家可以拆掉任何家具包括不是自己的
  15.     Interact: true  #如果设置为true，玩家可以与家具交互
  16.     Place: true #如果设置为true，玩家可以放置家具
  17.   PlaceMode: #不用管
  18.     Mode: PRIVATE #不用管
  19.     Access: INTERACT #不用管
  20.   ProtectionLib: #如果你装了 ProtectionLib
  21.     RegeionMemberAccess: false  #如果设置为true，这个区域的主人可以管理任何人的家具。举例如果时领地插件，领地的主人时A，B在这个领地里造了一个椅子，A可以拆掉B的椅子。
  22.   Database: #数据库 其实没必要看这个
  23.     type: SQLite  #有两种 SQLite 保存在FurnitureLib的文档里／MySQL 保存在外部数据库中
  24.     database: furniture #数据库的名字
  25.     user: ROOT #用户名
  26.     password: 123abcdefg #用户密码
  27.     port: 3306
  28.     host: localhost
  29.     importCheck: false
  30.   Purge: #一键清除功能
  31.     time: 30 #每多少秒清除一次家具
  32.     autoPurge: false #如果设置为true，将开启自动清除功能
  33.     removePurge: false #如果设置为true，游戏中也不能开启一键清除功能
  34.   timer:  #自动保存功能
  35.     Enable: false  #如果设置为true，即开启自动保护功能
  36.     time: 300 #每多少秒保存一次
  37.   spamBlock:
  38.     Place:
  39.       Enable: true
  40.       time: 5
  41.     Break:
  42.       Enable: true
  43.       time: 5
  44.     timeDisplay: mm:ss:SSS

CRAFTING

顺便教大家看一下crafting里的文件吧，这个文件里装的就是所有的家具啦，每一个家具都是可以配置的哦～

/plugins/FurnitureLib/Crafting/


以花盆（flowerpot）举例子
FlowerPot: #官方名称
system-ID: FlowerPot #物品ID
name: '&cFlowerPot' #游戏显示名
material: 383 #物品的显示材质 全都是怪物蛋 不可更改
glow: false #生长
lore: ''  #描述 玩过RPG服的人应该都知道这个
crafting: #制作方
  disable: false #如果设置为true，这个家具将不可制
  recipe: XTX,ATA,TAT #以三个字母,三个字母,三个字母 的格式 逗号是英文里的哦～
  index:
      T: 0
      X: 280
      A: 336
