||||||||作者的话||||||||
   Minecraft的PVP系统可能并不完整。制作这个插件的目的就是为了“平衡”PVP的那一点点可玩性。你的生存/PVP服务
器会有人总是跑去出生点杀别人，那些被杀的人一复活就被杀，在这种情况下被杀者可能会一怒之下离开服务器永
远不会回来。而那些恶意杀人者也可能会离开服务器，因为他们没有什么人可以杀了。
  这个插件的主旨就是为了解决这个问题并使PVP变得更加有趣，我们有一些想法，知道该怎么完善这个插件，但仍
需您宝贵的意见与想法！
  PwnPvpBalance的主要功能是两个在PVP的玩家，如果其中一个玩家被另一个虐得十分惨，这个插件就会开始打开连
杀保护效果。当一个玩家打破了连杀X次的界限，此玩家的攻击伤害就会被插件削弱，当然也可以在配置中修改它不
会被削弱。你可以看看这个玩家对决时的样本数据-----戳我！



■当前特性■
  ●连杀保护：如果玩家B被杀死的次数太多，B玩家将会自动切换到保护状态!
  ●连杀削弱：如果玩家B被杀死的次数太多，玩家B会得到一个保护BUFF！
  ○通过保存的玩家连杀数据来断开玩家连接，从而保护玩家安全，而且不重启服务器（可选）
  ●装备加强：玩家没有装备/皮甲将会提高移动速度，还能得到是削弱速度的铁锭/钻石。这些都是可以在配置文件中自行设置！


♂安装方法♀
1.关服
2.把插件扔进服务器的/plugins文件夹中
3.启动服务器，这时你要注意/plugins文件夹中，PwnPvpBalance文件夹和插件的confirg.yml是否生成。如果没有生成，则说明插件
没有被加载
4.编辑PwnpvpBalance插件文件夹中的confirg.yml来配置插件会在哪些世界生效。
5.最后重启服务器以让配置生效！


◇配置文件◆
  1. # 设置插件会在哪些世界启用，不在此列表的世界将会被自动忽略
  2. enabled_worlds:
  3.   - example_world
  4.   - example_world_nether

  6. # 屏蔽BUFF和伤害削弱功能
  7. # 如果设置true会开启全部屏蔽功能(玩家不会被装备多好一些的人连杀多次)
  8. # 如果设置false(默认)，将由玩家被连杀的次数决定是否触发伤害削弱
  9. shield: false

  11. # +/- 在此设置玩家被别的玩家连续杀死多少次后才会触发PVP平衡. 即: 玩家A撸玩家B,如果玩家B被连杀X次（被虐:-D）时，会立即触发插件.
  12. killstreak: 3

  14. # BUFF最大值: 设置BUFF保护的最大效果，在(1 - 9)选择.如果设置1和9则：1 = 削弱%10的伤害
  15. # 9 = 削弱%90的伤害.数值只能填1~9的数字，且不能有小数，必须为整数！9为默认数值，可更改.
  16. max_debuff: 9

  18. # 选择是否通过断开连接来保证玩家安全.
  19. # 如果为True将测量插件产生的的数据.
  20. # 如果为False，当一个玩家退出时，杀敌数会被重置为0.
  21. scale: true

  23. # 对玩家的平衡帮助/禁止杀人会一直持续到退出服务器.如果设置为false,平衡帮助将到
  24. # 插件被重载或者服务器重启后才会结束.
  25. end_on_quit: true

  27. # 此选项功能尚未实现，实现后将用MYSQL数据库来储存玩家的杀敌数据.

  29. # 是否启用插件的调试信息(log日志)启用它就能看到插件的故障信息以及配置信息，并解决它们!
  30. debug_log: false
