复制代码


我们写最简单的hello world
我们写System.out.println("hello world");
注意，一定得在最后加;  ;像一个句号，不写，系统就不知道你写了什么，你不信你删掉eclipse会报错的
好了，最简单的println学会了，我们来学变量
最基本的变量分为:
int
char
String
double

我来一一介绍
int 整数 不可以是小数
char 单个字符，一个字母，不能是汉子
String 字符串，多个字符，可以包括汉字与数字
double 小数

现在我们来写这一段代码
  1. int a=1;
  2. char b=a;
  3. String c="abc";
  4. double d=1.11;
  5. System.out.println("int:"+a+"char:"+b+"String:"+c+"double:"+d);
复制代码


运行结果是
int:1char:aString:abcdouble:1.11
我先普及一下
在定义一个变量的时候
" "是字符串的
' '是单个字符的
而数字不用,直接就可以了


System.out.println()里面，写""是直接显示，不加就是显示这个变量，假如想两个都用的话就用+,比如说
  1. int a=1;

  3. System.out.println("a"+a);
复制代码
他就显示a1,你直接写"a"a是会报错的

读者:不是有运算吗
是啊，是有运算
大家肯定都知道 + - * /吧
+=+
-=-
*=×
/=÷
那如何做一个运算呢?
我们先做一个最简单的运算
int a=1+1;
这个时候a=2
当然，你也可以用变量代替
  1. int a=1;
  2. int b=2;
  3. int c=b/a;
  4. System.out.println("b/a="+c);
复制代码
