插件简介
Anty killaura是一个类似于Hypixel的杀戮光环检测插件，当玩家击打机器人时可以检测其Cps并可以自定义处罚指令，你也可以修改机器人的方位以及名字。但是目前已知非常多做弊端都可以绕过，仅仅为了让一些服主让自己服务器看起来有逼格，可以配合Nocheatplus反作弊使用。
配置文件
  1. # 检测机器人的名字
  2. # '%random' 这个变量可以自动转换成10000000-99999999之间的文字
  3. BotsNicknameFormat: 'DWEN_%random'

  5. # 机器人会被玩家看见吗？
  6. BotsVisible: true

  8. # 机器人会显示在哪里？
  9. # true - 在玩家后面
  10. # false - 围着玩家转（不推荐在显示状态下使用，会影响玩家视线）
  11. BotsAppearance: false

  13. # 机器人会距离玩家多少方块呢
  14. DistanceFromThePlayer: 2

  16. # 对玩家执行控制的频率（以秒为单位）
  17. CheckingFrequency: 20

  19. # 机器人一次会显示多长时间？ (以tick为单位. 1 = 1/20 秒, 2 = 1/10 秒, 5 = 1/4 秒)
  20. BotTimeToRemove: 12

  22. # 向管理员发送信息吗？
  23. SendSuspicion: true

  25. # 向管理员发送的信息
  26. Raport: '&5[DWEN] &cThe player &4%player may cheating now! Check Result:&8(&6%bothits&8)'

  28. # 处罚玩家的命令（可以添加变量%reason）
  29. PunishingCommand: 'tempban %player 10m NA01DABA'

  31. # 如果处罚原因是杀戮光环，那么上面的%reason变量会显示什么呢
  32. AuraReason: 'KillAura'

  34. # 如果玩家没有这些命令(sh.kick, sh.ban)，那么会提示什么呢
  35. NoPerms: '&fYou must be &cOWNER &frank to use that!'

  37. # 如果想用插件自带命令处罚玩家，如果不在线的时候会显示什么呢
  38. OfflinePlayer: '&cThis player is not online!'

  40. # 如果你被管理员使用自带命令踢出后玩家会显示什么呢
  41. ManualKickFormat:
  42. - '&cYou have been kicked out of the server by &4%nick&c!'
  43. - '&cReason: &6%reason'

  45. # 如果你被反作弊使用自带命令踢出后玩家会显示什么呢
  46. AutoKickFormat:
  47. - '&cYou were automatically kicked out of the server!'
  48. - '&cReason: &6%reason'

  50. # 如果你被管理员使用自带命令封禁后玩家会显示什么呢
  51. ManualBanFormat:
  52. - '&cYou have been permanently banned by &4%nick&c!'
  53. - '&cReason: &6%reason'
  54. - '&cDate: &6%date'

  56. # 如果你被反作弊使用自带命令封禁后玩家会显示什么呢
  57. AutoBanFormat:
  58. - '&cYou have been automatically banned by AntyCheat!'
  59. - '&cReason: &6%reason'
  60. - '&cDate: &6%date'
  61. # 如果玩家被封禁后尝试进入服务器会显示什么呢
  62. LoginBanInfoFormat:
  63. - '&cYou are banned on this server!'
  64. - '&cDate: &6%date'
  65. - '&cBan type: &6%type'
  66. - '&cReason: &6%reason

插件命令
/shkick [玩家] [原因] ——踢出玩家
/shban [玩家] [原因] ——封禁玩家（永久，貌似无法取消）
