SuperLogger--超级日志
注.原帖没有插件截图,搬运贴即可不拥有截图,详见版规,帖子永久更新
一、简介
此插件是用于记录日志，其特点是可配置程度高，它可以分类处理不同类型的日志
打个比方，玩家的死亡信息，聊天信息分开记录，容易区别
二、功能
好高能，它可以记录玩家加入退出，使用指令，踢出玩家，无效的加入(比如说过期的客户端，服务器满，不在白名单)
三、命令&权限
/sl load 重新加载插件的配置文件
/sl debug 将测试信息输出到控制台,用于帮助!
/sl version 显示插件版本信息

superlogger.bypass.connection: 加入/退出服务器不被记录
superlogger.bypass.chat: 聊天不被记录
superlogger.bypass.death: 死亡不被记录
superlogger.bypass1.command: 使用命令不会被记录
superlogger.update.notify: 可以接收更新提醒，默认OP
superlogger.bypass.*: 所有信息不被记录
superlogger.: 所有权限，与superlogger.bypass. 和 superlogger.update.notify 相同
四、配置
  1. #自动下载更新
  2. auto-update: true
  3. #如果更新被禁用?我也不大明白
  4. update-notify
  5. #记录额外的调试信息
  6. debug: false
  7. #记录设置
  8. log:
  9. #记录命令
  10. commands: true
  11. #记录之前确保命令有效
  12. check-command-exists: false
  13. #记录聊天
  14. chat: true
  15. #记录玩家加入
  16. join: true
  17. #记录玩家退出
  18. quit: true
  19. #记录玩家被踢出
  20. kick: true
  21. #记录玩家死亡
  22. death: true
  23. #记录失败的登录
  24. failed-connections: true
  25. #同时记录IP
  26. player-ip: true
  27. #记录UUID(1.7以下无效)
  28. player-uuid: true
  29. #记录坐标
  30. coordinates: true
  31. #不会被记录的指令
  32. list:
  33. - 'login'
  34. - 'register'
