AuctionHouse
——by klugemonkey
AuctionHouse可以让玩家在游戏中上架出售自己的物品，以此来增加一种赚钱的方式，该插件的代码是全新的，与同名插件有类似的界面
插件特色
  • 免费
  • 查看拍卖行物品
  • 支持基于物品名称 类型 lore 附魔或卖家的搜索方式来更精准的找到自己想要的物品
  • 按时间/价格等方式进行排序
  • 显示自己出售的物品
  • 取消上架自己的物品
  • 已取消/到期的物品会自动回收
  • 自动清理无效物品
  • 显示并清除最近出售的物品
  • 鼠标悬停在物品上可查看物品的具体信息以及物品下架时间
  • 可选择按固定费用收取还是百分比收取税收上架物品(并且带有确定菜单，防止误操作)
  • 按销售额的百分比征税
  • 设置最低和最高价格
  • 可通过物品名称 类型 lore 附魔 耐久度等方式来限制上架的物品
  • 黑名单列表可通过判断lore来禁止上架物品
  • 黑名单列表支持正则表达式
  • 支持点击一些特殊的物品打开拍卖行
  • 支持点击一些被特殊命名的实体打开拍卖行
  • 支持将按钮设置为玩家头(HeadDatabase支持)
  • 多世界支持
  • 冷却时间支持
  • 自定义音效
  • ... ...

命令及权限
<必填项>[选填项]
  • /ah reload - 重载插件    所需权限:auctionhouse.reload
  • /ah [玩家名] - 打开拍卖行界面/为他人打开界面(为他人打开仅支持控制台使用)    所需权限:auctionhouse.use
  • /ah menu [玩家名] - 以菜单的方式打开拍卖行    所需权限:auctionhouse.menu
  • /ah search <名字> - 搜索<名字>的物品    所需权限:auctionhouse.search
  • /ah help - 打开帮助菜单    所需权限:auctionhouse.help
  • /ah sell <价格> - 出售手上物品    所需权限:auctionhouse.sell
  • /ah selling - 查看你正在出售的物品    所需权限:auctionhouse.selling
  • /ah sold - 查看你最近出售的物品    所需权限:auctionhouse.sold
  • /ah expired - 查看要退回的过期物品    所需权限:auctionhouse.expired
  • /ah cancel - 取消所有物品的出售    所需权限:auctionhouse.cancel
  • /ah return - 退回所有已取消/到期的物品    所需权限:auctionhouse.return
  • *新增* /ah list <价格> - 以服务器的名义上架物品    所需权限:auctionhouse.list
  • *新增* /ah ulist <价格> - 以服务器的名义上架无限出售物品    所需权限:auctionhouse.ulist
其他权限
auctionhouse.cancel.other 允许取消其他物品
auctionhouse.trigger.block 点击方块打开菜单
auctionhouse.trigger.entity 点击实体打开菜单
auctionhouse.trigger.sign 点击牌子打开菜单
所需权限:auctionhouse.auctions.# 允许设置的最大出售 #替换为数字

Meta元数据设置方式
  auctions - 设置玩家可以列出的出售次数
PermissionsEx
  • /pex user <user> set auctions <value>
  • /pex group <group> set auctions <value>
LuckPerms
  • /lp user <user> meta set auctions <value>
  • /lp group <group> meta set auctions <value>

GroupManager
  • /manuaddv <user> auctions <value>
  • /mangaddv <group> auctions <value>
