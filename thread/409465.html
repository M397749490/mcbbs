腐竹指令1、切换游戏模式 /gamemode 1 创造                 /gamemode 0 生存2、把玩家永久封禁/ban 玩家名             封禁ip/ban-ip 玩家名    /op 玩家名 设置op 也就是设置管理员    /unban 玩家名字 解除玩家ban    /money 查看自已有多少钱    /moneygive 玩家 钱金额  [给别人钱]    /eco [give/take/reset] [ID] [数量]给予/拿走/重设，某个玩家的钱 上面方式不行请试试这个 温馨提示：在后台输入指令时 不能填写/ 直接输入 后面的指令    3、经济插件    Q:如何创建一个牌子商店?A:设置木牌(1.2.3.4行这样写):shop价格物品ID或者英文名称数量Q:如何创建一个收购木牌?A:和牌子商店一样，只需把牌子第一行改为sellQ:为什么有一些数据没有保存?A:需要正常关闭服务器才能保存(关服输入/stop)!Q:如何使用飞机场插件?A:飞机场插件提供点击牌子传送的功能,但需要玩家支付费用#设置出发地飞机场木牌:airportdeparture费用目的地飞机场的名字#设置目的地飞机场木牌:airportarrival目的地飞机场的名字(留空,不需要填写任何东西)Q:拍卖插件命令有哪些?A:/auction list [页码] : 查看拍卖列表/auction start <物品ID> <数量> <起始价格> :开始拍卖/auction stop [玩家] : 停止玩家拍卖./auction time <物品ID> <数量> <起始价格> <时间> : 开始限时拍卖/auction bid <玩家> <价格> : 向该玩家的拍卖出价Q:赌博怎么玩?A:/jackpot : 直接赌博命令/casino start : 开设一个赌场游戏/casino quit : 关闭赌场游戏/casino gamble : 向你的赌场游戏赌钱/casino join : 加入一个赌场游戏/casino leave : 离开赌场游戏Q:领地出售插件有什么用?A:OP可以通过预先圈一块领地出售,玩家只需点击木牌就可购买该领地!/property pos1 : 和领地插件的startp一样./property pos2 : 和领地插件的endp一样./property make <价格> : 创建预售领地,会在领地中间自动生成一个购买木牌.4、/setspawn 设置出生点   /lockchest 锁箱子   /unlockchest 解锁箱子   /setworldspawn 设置世界的出生点[用于有多世界插件的服务器}   /sethome 设置家   /home 回家   /warp 查看地标   /setwarp 设置地标   /warp 地标名 传送至地标   /tphere [ID]5、经典指令让某个玩家强制飞到你身边/tpall [ID]让所有玩家飞到你身边，包括OP/tppos [x] [y] [z]传送到x,y,z/kill [ID]搜索杀死某个玩家，= =这个我没用过。。我只喜欢隐身背后放苦力怕娘~\(≥▽≤)/(炸飞)/time set 100 调时间为早上/tp 玩家名字 传送到该玩家 OP指令/back 回到死亡的地方/banitem  item <物品ID>  – 添加/移除禁用物品/banitem  admin <玩家名> – 添加/移除管理员（ 不受禁用物品限制的玩家 ）/banitem list 查看禁用物品列表和不受限制的玩家列表/setprefix <玩家名> <称号> – 设置玩家称号/defprefix <称号> – 设置默认称号/delprefix  <玩家名> <称号> – 设置该玩家称号为默认称号/setnick  <玩家名> <昵称> – 设置玩家昵称/delnick <玩家名> – 还原为真实名称/mute  <玩家名> – 禁言玩家/unmute  <玩家名> – 解除禁言/disablechat – 全体禁言/enablechat – 解除全体禁言/f create <公会名> –  创建公会/f del – 解散公会 (如果你是会长)/f invite <玩家> – 邀请玩家/f accept -接受邀请/f deny – 拒绝邀请/f help – 展示所有命令/f kick <玩家> – 踢出会员/f leader <玩家> – 把会长的职位给其他人/f leave – 离开公会/f motd – 设置公会每日信息/f info – 查看公会每日信息/f info <公会> –  查看此公会每日信息
