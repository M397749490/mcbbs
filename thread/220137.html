每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。
适用于正式版的MOD不兼容预览版，而且大多数MOD都不提供对每周快照的支持。
Minecraft 1.8仍未发布，14w03a为其第4个预览版。
注意！旧版启动器已经无法启动1.8以及之后的快照，请看下面的说明。
本版新闻除非特别说明，否则均允许转载，但转载必须注明本帖地址。



*红色内容没有出现在官方更新日志里

  • /tp now supports rotation arguments
  • /tp 命令现在支持自定义朝向。
  • Player selectors (@p, @e, etc) now support cubic areas. For example: @e[x=0,y=0,z=0,dx=10,dy=10,dz=10] gets all entities between 0,0,0 and 10,10,10
  • @p, @e 等选择性参数现在支持自定义全部三个维度了。比如，@e[x=0,y=0,z=0,dx=10,dy=10,dz=10] 能返回 0,0,0 到 10,10,10 里的所有实体。
  • Added /clone command to copy large areas to other areas
  • 增加了 /clone 命令，用来复制大面积的区域，worldedit 至此可以消失了。
  • Added a /fill command to fill a large area with a block
  • 增加了 /fill 命令，用来用单一方块填充大面积的区域，同样类似worldedit和mcedit。
  • 更新皮肤格式，支持第二层皮肤
  • 增加“自定义皮肤”菜单，用来调整哪一部分的皮肤可见（没正版的赶紧去买啊，现在只要998）

此前与本次更新相关的快讯列表：（引用sjjklh的翻译）

Minecraft 1.8首个快照已经到来！本更新主要有两个焦点：生存模式游戏体验提升，与冒险地图的新炫酷机制！我们已经做了一坨针对客户端和服务端的优化工作（还有很多没公布呢），以及大量针对后台插件API的工作。本快照是第一个1.8快照，所以别忘了备份你的地图！

生存模式提升：
  • 3个新石头种类：花岗岩Granite、闪长岩Diorite、安山岩Andesite
  • 修理以及附魔的大幅度改变
  • 苔石砖可合成
  • 村民交易的更新
  • 门可堆叠
  • 史莱姆方块/粘液方块
  • 大量其他优化、更改、BUG修复以及秘密特性！

冒险地图更新：

  • 冒险模式不再允许放置以及摧毁方块
  • 但上面这句话不是绝对的……可以变哦
  • 增加实体选择符@e用以将目标指向特定实体。
  • 加入/blockdata命令!
  • 为大多数容器加入‘Lock’ (字符串) NBT标签，用于锁闭容器
  • 为/kill命令加入可选实体参数
  • 为/clear加入可选参数，这样可以限制物品以及NBT数值的最大值
  • 大量其他优化、更改、BUG修复以及秘密特性！

对于正版用户，可以直接接收到新版官方启动器的快照推送。前提是：
  • Profile中的Version Selection勾选Enable experimental development versions ("snapshots")一项
  • Use version选择Use latest version
对于非正版用户，前提是：
  • 你使用的启动器能够在线读取官方的版本列表，并具备下载功能。
