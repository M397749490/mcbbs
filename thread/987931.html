配置文件特殊值讲解
不可删除项:
items:  这个不可以删除删除就会报错
20        是物品所在的格数
type     物品的枚举也就是名字，不可为数字
data:    物品的副值，如果没有副值则为0就可以
amount 物品显示的数量
name    物品显示的名字可以用 & 字符
lore       物品的lore，颜色必须用 § 来修饰
许愿物品不可删除项:
lucky 如果幸运值达到这些则百分百执行
pb     许愿几率越小越难
commands  成功之后执行的指令
可选择项:
addlucky  许愿成功或者失败都会增加的值
item.itemname   拥有这个name的物品
item.itemlore     拥有这个lore的物品
item.itemloreRows lore所在的行数不写默认为第0行
item.itemAmount 消耗物品的数量，仅限可堆叠物品
money      许愿所需金币
points       许愿所消耗的点券
failure       失败之后执行的指令
num          限制的点击次数(个人)
open         玩家点击之后跳转界面


指令&权限
MakeWish open [player] [菜单名字]                                       >>打开菜单                                     权限: maw.菜单名
MakeWish reload                                                                  >> 重载config                                  权限: maw.all
MakeWish give [player] [许愿名字] [整数]                               >> 给予玩家lucky值                          (下面全都需要maw.all)
MakeWish delete [player] [许愿名字] [整数]                            >> 删除玩家lucky值
MakeWish set [player] [许愿名字] [整数]                                 >> 设置玩家lucky值
MakeWish deletenum [player] [许愿名字] [整数]                      >> 删除玩家的点击次数
MakeWish givenum [player] [许愿名字] [整数]                         >> 增加玩家的点击次数
MakeWish clear [player] [许愿名字]                                        >> 重新设置许愿的幸运值和点击次数

解释一下[许愿名字]这个值是什么 就是物品的name当然你物品名字带颜色字符你这个许愿名字就需要带颜色字符
例如:
MakeWish give zhi_qiu &b许愿1 100
