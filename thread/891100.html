作者: 尊主    时间: 2019-7-24 21:29

https://www.mcbbs.net/forum.php?mod=viewthread&tid=822475
可以试下这款插件

在mobs.yml文件中 自行添加
# CustomDrops:
#   ZOMBIE:
#     EXP: 10
#     NaturalDrops: true
#     '1':
#       chance: 1.0
#       amount:
#         min: 1
#         max: 2
#       commands:
#       - 'sx give 装备名字 {p} 数量'
#       - 'msg 恭喜 {p} 他获取了一把击杀僵尸时有 1% 获得sx装备'
这个意思是击杀僵尸是  有1%的几率chance
执行指令，也就是给装备的指令
{p}代表玩家变量
