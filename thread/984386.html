在开始新建一个物品之前，首先看看插件生成的默认yml配置文件

Config | 全局设置 （1）


这个一般不使用,如果您有特殊♂需要就填写
原版物品是否能使用/customitem inspect/info 来查看信息
列入自定义物品信息面板中
customitem.info.native / customitem.inspect.native
一般这里是空着的，如果您有需要只需要填写在此
这里是以钻石、绿宝石为例子
  1. nativeItemPermissionExclusions:
  2.   - DIAMOND
  3.   - EMERALD
复制代码
关于源材质的设置,我个人觉得是没有必要开启的(*仅为个人观点)
以下设置为1.14+版本 才可以使用
是否启用方块源材质
将其设置为true，并且没有下载资源包的玩家
Minecraft的源材质会用于自定义方块中
你可以设置某个物品在没有材质的情况下的源材质

如:
在 myBlock.yml 中
item: #物品名称
block:
texture:
textureID: 42
fallback: "minecraft:COBBLESTONE" - 源材质
  1. doFallbackTextures: false
复制代码

默认源材质设置,如果玩家没有使用材质包默认为自定义方块的材质设置为XX
  1. defaultFallbackTexture: NULL
复制代码
需要版本在1.14以上

在1.14版本之前是通过设置物品的损害值来实现自定义材质
但是在1.14之后出现了更好的实现方法
如果您要使用旧的方法请设置为true（低于1.14也设置为true）
建议设置为false

  1. useOldResourcePackFormat: false
复制代码
数据的储存方式 "sqlite", "mysql", "yaml"   YAML < SQLITE < MYSQL（储存选择推荐）
数据储存方式的数据可以自由迁移
当你修改完储存方式以后请使用指令来迁移数据(必须由控制台进行)
"/customitems blockstorage migrate 源储存方式 更改后的储存方式"

迁移会大大降低服务器的速度，如果没有分配足够的内存，则可能导致服务器崩溃！

栗子：
如果您以前使用YAML来储存数据,并且想切换到MySQL，只要将blockStorageFormat更改为MySQL
然后，重新启动服务器，然后从控制台运行命令"customitems blockstorage migration YAML MySQL"

  1. blockStorageFormat: sqlite
复制代码

最后是奇葩的两个设置~（当然你也能知道自己配置错误）
当配置发生错误时使服务器崩溃！！崩溃！！= =奇葩的设置
  1. forceCrashOnInvalidItem: false
  2. forceCrashOnInvalidMySQL: false

生成可选项

continueChanceGrowth - 每次在矿洞中生成新的区块时，继续生成的几率如何改变
continueChance - 在ore生成方法中为十进制(0.0-1.0之间)方块在矿洞中继续生成的几率
blockTypes - 替换的方块(需要生成方法为replace)

|    Custom Item 指令帮助
/(cui)customitems XXXX 为命令
/customitems list - 打开面板查看物品 - customitems.list

/customitems inspect - 查看手中物品信息 - customitems.inspect

/customitems info - 查看物品的相关信息 - customitems.info

/customitems scan - 查看物品id以及变量 - customitems.scan

/customitems give [玩家] [物品] - 给玩家自定义物品 - customitems.give

/customitems get [物品] - 获得自定义物品 - customitems.get

/customitems create/edit - 打开面板来进行自定义物品 - customitems.create

/customitems reload - 重载（测试阶段）建议还是重启服务器来重载 - customitems.reload

/customitems setblock [物品] [世界] x y z -设置方块(与setblock相似)  - customitems.setblock

/customitems drop [物品] [世界] x y z - 将物品放置在准确位置 - customitems.drop

/customitems blockstorage  - 进行数据迁移(具体使用方法见教程)
