Spigot服务端简单整合
Spigot其实就是优化版的CraftBukkit（CB）
例如：
1.速度
2.稳定性
3.功能性
4.兼容性
5.更好的扩展性
理论上支持所有CraftBukkit的插件
插件：
Authme-登录插件
WorldEdit-创世神插件
Essentials-基础插件
AntiX-ray-反矿踪插件
CoreProect-查询插件
Lockette-锁插件
NeverLag-反作弊&优化&清理插件
Vault-经济插件
ScriptBlock-脚本方块插件
Multiverse-多世界插件
Residence-领地插件
论坛超链接出了问题所以贴不了，希望版主谅解
各种教程：
服务器server.properties文件修改（原帖stool版主的服务端核心文件帖）：
大家在服务端找到server.properties，打开这个文本
level-name [ 服务器地图的名称]
allow-nether [ 开启地狱世界 true为开启，false关闭]
view-distance [ 可视距离]
spawn-monsters [ 刷怪物 true为开启，false关闭]
online-mode [ 只有在线玩家可以进游戏 true为开启，false关闭]
gamemode [ 游戏模式 0=生存、1=创造]
spawn-animals [ 刷动物 true为开启，false关闭]
difficulty [ 难度等级 0=和平、1=简单、2=中等、3=困难]
server-name [ 服务器名字]
pvp [ 玩家伤害玩家 true为开启，false关闭]
server-ip [ 服务器IP地址]
max-players [ 最大玩家数]
level-seed[生成地图的时候使用的种子]
server-port [ 服务器端口，默认25565]
allow-flight [ 允许玩家飞行]
white-list [ 白名单]

注意事项：
1.1.7.X服务端版本为1.7.10，主要加载1.7.10的插件，但支持1.7所有版本包括1.8.1进入。
2.转载必须经过楼主同意。
3.不要剽窃整合包内插件到你的服务端，然后声称这是你原创的。
4.不能开服的小朋友尝试把服务端内eula.yml内的false改为true。
