指 令/配 置
/help 打开GUI界面
- helpgui.use
/helpgui 重载插件
- helpgui.reload
配置文件：
  1. # 自定义帮助GUI版本1.0.0
  2. # 开发者：IMinIILLuZionZ
  3. # 这个插件允许一种简单的方法来创建
  4. # 帮助GUI对你的玩家

  6. # 菜单名
  7. InvName: "&5&l帮助菜单"
  8. # 菜单格数 (最多9个)
  9. InvSize: 9

  11. MenuItems:
  12.   Item1:
  13.     # 帮助显示名
  14.     ItemName: "&b&l帮助"
  15.     # 所在位置(1-9格)
  16.     InvSlot:
  17.     # 帮助Lore显示
  18.     ItemLore:
  19.     - "&f&l&m一&c&l&m一&f&l&m一&c&l&m一&f&l&m一&f&l&m一&c&l&m一&f&l&m一&c&l&m一&f&l&m一"
  20.     - "&a打开帮助菜单指令"
  21.     - "&a/help (权限 helpgui.use)"
  22.     - "&a重载插件指令"
  23.     - "&a/helpgui (权限helpgui.reload)"
  24.     - "&f&l&m一&c&l&m一&f&l&m一&c&l&m一&f&l&m一&f&l&m一&c&l&m一&f&l&m一&c&l&m一&f&l&m一"
  25.     # 是否开启执行指令
  26.     Command: true
  27.     # 执行指令 可多个执行 每行一个
  28.     ItemCommand:
  29.     - "tell %player% 指令可以在Config.yml ItemCommand一行修改"
  30.     # 是否开启发送消息给玩家
  31.     Message: true
  32.     # 发送消息在此行修改
  33.     ItemMessage:
  34.     - "消息可以在Config.yml Itemmessage一行修改"
  35.     # 物品显示材质 (英文)
  36.     Material: DIAMOND_BLOCK
