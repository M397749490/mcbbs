如何运用scoreboard存储及调用实体的的位置信息、nbt信息等数据？
举个例子，比如，地上有一把耐久为1的木剑，我想要召唤一个盔甲架在该木剑的位置并使其手持这把木剑该怎么写指令？
目前的逻辑已经实现到直接将盔甲架召唤到木剑位置并消除掉落物木剑，再给予盔甲架装备，但是由于不会操作scoreboard，于是直接使用选择器@s来实现的。
在论坛里翻半天看到好多旧版本的scoreboard指令但是没有看到专门讲1.13的scoreboard指令的。翻了好久还是不太懂怎么用。如果有大佬知道哪有相关资料的还请给个链接。

啊对了...因为可以直接store...data get，所以不需要记分板。

如果要把记分板的分数保存为Damage的话，这样[也就多出了存/取score的步骤]
  1. execute as @e[name="木剑"] store result score @s damage run data get entity @s Item.tag.Damage
复制代码
  1. execute store result entity @e[type=armor_stand] HandItems[0].tag.Damage int 1 run scoreboard players get @e[name="木剑"] damage
复制代码
至于这个 HandItems[0].tag.Damage 是怎么来的
data get entity @e[type=armor_stand,limit=1]  得到一段，其中有这么一部分
{.....,HandItems:[{id:"minecraft:stone",tag:{Damage:2}},{}],....}


HandItems:[{id:"minecraft:stone",tag:{Damage:200}},{id:"minecraft:dirt",tag:{Damage:500}}]

蓝色的为HandItems里的第一个框框...红色为第二个
数字从0数起，所以第一个框为0，第二个框才为1。
所以
HandItems[0]获取到的是{id:"minecraft:stone",tag:{Damage:200}
HandItems[1]获取到的是{id:"minecraft:dirt",tag:{Damage:500}

把路径写详细点
HandItems[1].tag.Damage
得到的就是500

不确定的话可以逐个data get查看自己的路径是否正确
  1. data get entity @e[type=armor_stand,limit=1]
  2. data get entity @e[type=armor_stand,limit=1] HandItems
  3. data get entity @e[type=armor_stand,limit=1] HandItems[0]
  4. data get entity @e[type=armor_stand,limit=1] HandItems[0].tag
  5. data get entity @e[type=armor_stand,limit=1] HandItems[0].tag.Damage
  6. ...

  1. execute as @e[type=item,name="木剑",nbt={OnGround:1b}] at @s run function foo:bar

  3. #foo:bar
  4. summon armor_stand ~ ~ ~ {Tags:["ams"],HandItems:[{id:"wooden_sword",Count:1b,tag:{Damage:1}},{}]}
  5. execute store result entity @e[type=armor_stand,tag=ams,limit=1,sort=nearest] HandItems[0].tag.Damage int 1 run data get entity @s Item.tag.Damage
  6. kill @s
复制代码


以地上的木剑执行
召唤木架(拥有标签，手持木剑)(必须要有这个Damage，不然后面的store没地方存数值...)
获取地[ruby=命令后半部分]上木剑的Da[/ruby]mage值，然后把获取的值储存[ruby=前半部分]到木架手[/ruby]上的木剑里。
清除地上木剑


如果是1.14的话，召唤木架之后，可以使用data modify，直接把地上物品实体的所有物品数据保存到木架上。
  1. data modify entity @e[type=armor_stand] HandItems[0] merge from entity @e[type=item,nbt={OnGround:1b},name="任意剑"] Item
