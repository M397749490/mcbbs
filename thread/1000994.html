插件指令&权限
指令部分
[] - 可选
<> - 必填
() - 指令缩写

  • Bukkit
/tablist (或/tl) - 插件信息
/tl help - 插件帮助
/tl reload - 重载插件
/tl fakeplayers - 创建一个假人到TAB列表中
/tl fakeplayers <add/remove> <name> - 增加/删除一个假人
/tl fakeplayers list - 列出所有假人
/tl toggle - 开启/关闭tab列表显示
/tl toggle all - 开启/关闭所有在线玩家的tab显示
/tabname <name> - 设置你在tab中的名字
/tname <player> <name> - 设置玩家名字tab中的名字
/tl setprefix <player> <prefix> - 设置玩家在tab中的前缀
/tl setsuffix <player> <suffix> - 设置玩家在tab中的后缀
/tl setpriority <player> <priority> - 设置玩家在tab中的排名顺序
/tl removeplayer <player> - 删除玩家的前缀/后缀
/tname reset [player] - 重新设置玩家的tab名字
/tl get [name] - 获取玩家的tab名字

  • Bungee
/tablist - 插件帮助
/tablist reload (或rl) - 重载插件
/tablist toggle - 开启/关闭tab列表
