       UltimateSpawn

        更加方便高能的主城复活点属性设置插件



提示：下载使用这个插件的时候不要使用其它类型的设置复活点之类的插件
如：SpawnTP, Essentials Spawn.



这款插件可以设置那些有趣的内容？

可以设置一个出生点并且可以自定义其中的一些有趣的内容




加入的时候：





ClearChat——清理聊天记录
ClearInventory——？？？
Tp to spawn——传送至复活点
Gamemode——游戏模式
Sound, Firework, Fly——进入音效、烟花欢迎、飞行




保护




Contruct, Explode, Block burn——破坏、燃烧
Anti pickup——不可以捡起物品
drop item——不可以丢弃物品
item move——不会有物品移动速度的增幅效果
item damage——不会有物品的攻击加成伤害
Anti weather——不会有天气的更改
damage——不会被造成伤害
mob spawning——不会有怪物生成

自定义消息




Disable and custom join and quit
自定义加入退出消息
First join Motd and join motd
自定义第一次加入服务器的消息
Broadcast on first join
第一次加入公告欢迎
Disable Death message
停止使用死亡消息
And many messages...
和其他...消息

聊天管理




Clear chat
清理聊天内容


其他



Clear drop items on death
清理死亡掉落物品
Ping command
有关Ping的指令
Broadcast
自动公告

管理员指令:


/us [ help | reload ]
帮助/重载插件
Permission: UltimateSpawn.help & UltimateSpawn.reload
插件帮助和重载的权限



/setspawn, sethub, setlobby
设置自己服务器的出生点、???、???
Permission: UltimateSpawn.SetSpawn
对应的权限
/spawn, /h, /hub, /l or /lobby [player]
Permission: UltimateSpawn.TeleportOthers
对应的权限




Description: Teleport player to spawn
/cc [o | a | c | other] [player]
对于X玩家清理o、a、c、other聊天内容
Permission: UltimateSpawn.clearchat
Description: Clear Chat
清理聊天内容



/bc, broadcast [message]
发送广播
Permission: UltimateSpawn.Broadcast
Description: Clear Chat

玩家指令：
/spawn
回到主城



/ping [player]
Permission: UltimateSpawn.ping
对应权限
