0.前言说明

Player Plot——允许玩家保护并管理属于他们自己的区域




一、功能介绍
Player Plot可提供的保护：
— 未获得允许不可在地皮区域内建造、放置方块
— 未获得允许不可在地皮区域内挖掘、破坏方块
— 未获得允许不可在地皮区域内使用物品（如箱子、门）
— 未获得允许不可在地皮区域内击杀怪物、造成伤害
— 地皮区域内爆炸保护
— 地皮区域内禁止火蔓延
— 地皮区域内禁止活塞触发在地皮外
— 右键龙蛋不会传送在区域外
— 不会让水和岩浆流动在地皮外
— 保护农田，禁止踩踏
— 以及更多保护...

Player Plot的额外功能：
— 可使用数据库储存数据(支持SSL)
— 自定义地皮尺寸、自定义文本语言、自定义地皮数量以及增长数量、还有更多...自定义化
— 支持Dynmap(网页服务器地图，显示地皮区域范围，可自定义颜色)
— 可升级地皮，提升地皮大小（可在config.yml中设置升级后的区域）
— 支持给予其他玩家权限
— 更简化的指令，服务器占用量小。



权限节点

  1. playerplot.deed - 使用 /plotdeed 的权限
  2. playerplot.nolimit - 不再限制地皮大小
  3. playerplot.infinite - 领取N个地皮
  4. playerplot.accessplots - 对所有地皮的使用权限
  5. playerplot.activity - 使用 /plotactivity 的权限
  6. playerplot.delete - 使用 /delplot 的权限
  7. playerplot.view - 使用 /allplots 的权限
  8. playerplot.convert - 使用数据转换命令的权限(转换sql或file)
  9. playerplot.* - 全部权限
