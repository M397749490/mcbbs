想问一下，如果我用/trigger这个指令想同时给玩家速度和力量效果应该怎么去输入 ...

trigger 是一个可以让玩家更改某个计分项数值的命令，配合高频检测可以给予玩家多个效果什么的…不知道是不是你要的

执行一次：
/scoreboard objectives add effect trigger

高频执行：
scoreboard players enable @a effect
effect @a[score_effect_min=1] 力量的ID
effect @a[score_effect_min=1] 速度的ID
scoreboard players reset * effect

然后在你的插件里写
trigger add effect 1

挺麻烦的 如果是插件也许你还有别的解决办法，但我只玩原版并不清楚，可能帮不上什么了
