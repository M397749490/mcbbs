作者: Interpret    时间: 2017-7-10 18:17
在authme登录插件中，打开config文件，找到下面信息，enabled: true 设置为true才可以使用短时间自动登录timeout: 10默认时间为10分钟
  1. settings:
  2.     sessions:
  3.         # 是否开启 Session 缓存.
  4.         # 如果开启 Session 玩家可以在特殊情况下自动登录.
  5.         # 他的IP和名称将会被保存.
  6.         # 在他下次进入服务器时.
  7.         # 如果 名称 IP 都相同 并且没有超出缓存时间.
  8.         # 那么他可以自动登录到服务器.
  9.         enabled: true  #此项设置为false则不使用短时间自动登录机制
  10.         # Session 缓存时间
  11.         timeout: 10  #单位：分钟 超时时间，超过此时间登录的需要重新登录
  12.         # 下次登陆是否需要检查 IP
  13.         sessionExpireOnIpChange: true
