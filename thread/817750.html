我的思路
先生成一个用于轨迹绘制的实体作为开始，然后每几个tick选出一些实体在两旁生成新的实体，最后再用tnt炸开，这样达到无限复制的效果，相当于在不断的分叉。
命令实现
检测实体是否生成（是否开始） - timecount/tick.mcfunction

  1. #测试是否开始生成树木
  2. execute if entity @e[tag=tree_summoner] run function tree:timecount/timecount
复制代码


开始时运行 - start.mcfunction

  1. #主生成器设置
  2. execute at @s run summon minecraft:pig ~ ~ ~ {Tags:["tree_summoner","tree_first"],NoGravity:1b,Invulnerable:1b,DeathLootTable:""}

  4. #计时记分板设置

  6. #分叉随机计时设置
  7. scoreboard objectives add tree_branch dummy
  8. #存在时间设置
  9. scoreboard objectives add tree_age dummy
  10. #预留树干生长时间
  11. scoreboard players set @e[tag=tree_summoner] tree_branch -20
复制代码


开始后每一tick运行 - timecount/timecount.mcfunction //我知道名字取错了

  1. #加速上一个tick生成的枝条

  3. #x
  4. execute as @e[tag=tree_unset] run execute store result entity @s Motion[0] double 0.001 run data get entity @s Motion[0] 1500
  5. #z
  6. execute as @e[tag=tree_unset] run execute store result entity @s Motion[2] double 0.001 run data get entity @s Motion[2] 1500

  8. #分叉

  10. #旋转初始树干
  11. execute as @e[tag=tree_first] at @s run tp @s ~ ~1 ~ ~110 ~
  12. #记分板设置
  13. scoreboard players add @e[tag=tree_summoner] tree_branch 1
  14. #设置所有有可能分叉的实体的  tag 为 branchable
  15. tag @e[scores={tree_branch=15..},tag=tree_summoner,limit=1,sort=random] add branchable
  16. tag @e[scores={tree_branch=5..},tag=tree_first] add branchable
  17. #调用分叉函数
  18. execute as @e[tag=branchable] run function tree:branch/branch
  19. #删除tag
  20. tag @e[tag=branchable] remove branchable

  22. #记录痕迹

  24. #生成盔甲架
  25. execute at @e[tag=tree_summoner] run summon armor_stand ~ ~ ~ {NoGravity:1b,Invulnerable:1b,Tags:["tree_footer"],Attributes:[{Name:"generic.knockbackResistance",Base:1.0}]}
  26. #年龄记分板设置
  27. scoreboard players add @e[tag=tree_footer] tree_age 1

  29. #清场

  31. #清除实体
  32. execute if entity @e[tag=tree_footer,scores={tree_age=100}] run function tree:clear/clear
复制代码


分叉 - branch/branch.mcfunction

  1. #生成新 summoner

  3. #左侧
  4. execute at @s positioned ^0.5 ^ ^-0.5 run summon minecraft:pig ~ ~ ~ {Tags:["tree_summoner","tree_unset"],NoGravity:1b,Invulnerable:1b,Motion:[0d,0.05d,0d],DeathLootTable:""}
  5. #右侧
  6. execute at @s positioned ^-0.5 ^ ^-0.5 run summon minecraft:pig ~ ~ ~ {Tags:["tree_summoner","tree_unset"],NoGravity:1b,Invulnerable:1b,Motion:[0d,0.05d,0d],DeathLootTable:""}
  7. #生成tnt以推进
  8. execute at @s positioned ^ ^ ^-0.8 run summon tnt ~ ~ ~ {NoGravity:1b}

  10. #重置记分板
  11. scoreboard players set @e[tag=tree_summoner] tree_branch 0
复制代码


清场 - clear/clear.mcfunction

  1. #放置对应木头

  3. #2
  4. execute at @e[scores={tree_age=100..}] run fill ~2 ~2 ~2 ~-2 ~-2 ~-2 minecraft:oak_wood
  5. #1
  6. execute at @e[scores={tree_age=50..}] run fill ~1 ~1 ~1 ~-1 ~-1 ~-1 minecraft:oak_wood

  8. #放置对应树叶

  10. execute at @e[scores={tree_age=0..50}] run fill ~2 ~7 ~2 ~-2 ~2 ~-2 minecraft:oak_leaves[persistent=true] keep

  12. #清除实体

  14. #生成器
  15. kill @e[tag=tree_summoner]
  16. #路径
  17. kill @e[tag=tree_footer]
复制代码


命令分析
原理我已经在思路中讲过了，这里就不再赘述了，这里提一个重要的东西。
在分叉树木的时候，因为要一下子生成2只实体，而且要让木头的粗细不一[注]，我们就不能直接setblock/fill了，而且生成的实体轨迹肯定也不能被炸飞，不然就很尴尬了，所以这时候就要清除我们的属性来了，这里采用的是抗击退属性，命令如下，
  1. execute at @e[tag=tree_summoner] run summon armor_stand ~ ~ ~ {NoGravity:1b,Invulnerable:1b,Tags:["tree_footer"],Attributes:[{Name:"generic.knockbackResistance",Base:1.0}]}
