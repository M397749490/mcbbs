infinantcake



Game

一个坑人的小游戏！
谁先吃完谁就赢OvO





作用

这个插件纯属娱乐！
我也觉得意义不明！
这个插件就是在充能的青金石上放蛋糕！
然后你就可以无限吃！



Command

/removecakes : revert all cakes back to normal  - 让蛋糕可以吃完！
/cakehelp : gives instructions on how to make an infinant cake - 帮助！




Permissions

infinantcake.make : make infinant cakes and use help command - 能够使用帮助指令和创建这种蛋糕
infinantcake.remove : remove cakes with remove command  - 能够使用remove指令
