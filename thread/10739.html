 我首先翻译这里
第一行, 用蓝字写的:op-name-color: 'c'
意思是: 如果你是op, 你的名字是什么颜色的?
在这里, 有一个对照表, 你会发现左边是颜色, 右边是&(一个数字或者字母), 在这里面, 你只需要改一下c就行, 在 这句话的后面不是有一个 'c'吗? 不要把' '删除, 如果你要换颜色, 只需把数字或字母写上就行了.

 就是这个自然段
第一行, 用蓝色字写着:teleport-cooldown: 0  <----(你可以更改时间, 用秒计算)
这个就是说你传送人, 传送到家里面, 传送到出生点需要多长时间.
例如: 你把0改成20, 那就说明你输入命令 /tp (玩家1) (玩家2) 之后你得等20秒才能传送过来, 回家和传送出生点一样.
第二行,用蓝色字写着: teleport-delay: 0 <-------(同上)
保持 0, 这个有点问题, 不要修改.
第三行, 用蓝色字体写着: heal-cooldown: 60 就说明60秒用一次 /heal (回血功能)
最后一行, 用蓝色字体写着: default-stack-size: 64 <-----------(64说明物品数量)
这个就是说明如果你用命令 /i (物品) 或者 /give (玩家名字) (物品) 一次给多少.
举例子: 如果改成100, 那么你输入命令就给你100个物品.

第一句话: nether 下面的就是你想不想开启地狱门.
第二段: spawnmob-limit: 10      那就是说明你最多可以生出多少生物(/spawnmob [动物,生物的名字] [数量])
下一句话: warn-on-smite: true    那就是让不让玩家用命令 /lightning 打雷的
下一句话: motd:
       -  '&cWelcome, {PLAYER}&c!'之类的, 这个很好改, 就是如果新手来的屏幕上显示这个信息. &c就是颜色, 我发过,在上面. 就是在字前面写上&(数字或字母) 后面是你想对新来的玩家说的话, 就行了.但是别改太多, 一两个就行了. 如果不放心备份一下. (另存为)
下一句话: rules:
       -  '[1] Be respectful' 之类的, 首先这个是规矩, 在游戏中打入 /rules 肯定和这里是一样的. 所以, 你可以改动一下. 但是只改字母, 不改数字1和标点符号.
