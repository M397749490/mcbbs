标题: 纯原版无基础插件的 CraftBukkit 1.14.4 如何给予玩家组某插件的权限？
服务端环境
版本：CraftBukkit version  (MC: 1.14.4) (Implementing API version 1.14.4-R0.1-SNAPSHOT)

已有的插件：
CatSeedLogin-1.0-SNAPSHOT.jar 登录插件
EnchantDeath.jar 死亡增强插件


服务器
Windows Server 2012

情况是这样的，我想使用EliteMods（https://www.mcbbs.net/thread-822085-1-1.html）插件。

1.14的版本，这个插件中有个命令 /ag 普通玩家无法使用，执行后没有任何回显，没有任何报错。
后来我将我自己赋予op权限，就可以正常执行 /ag 命令。

这个插件需要的权限如下:
参考:https://github.com/MagmaGuy/EliteMobs/wiki/%5BGuide%5D-Permissions-and-commands
  • elitemobs.stats
  • elitemobs.events.kraken
  • elitemobs.events.balrog
  • elitemobs.events.fae
  • elitemobs.checktier
  • elitemobs.adventurersguild
  • elitemobs.currency.user

现在的问题就是，如何在没有基础插件的，没有任何权限组插件的（出于某些原因不想添加基础插件）情况下，如何给予所有玩家添加这些权限。
/mangaddp 命令不存在，所以想告诉我用这个命令的可放弃了。




希望有人解答。如果没有任何办法，又可否推荐一下中小型的权限插件？

如上个回答所说，不安装权限插件的情况下你可以修改plugins.yml来达到给予权限的目的
但同时你也可以使用Bukkit自带的”权限系统“：https://bukkit.gamepedia.com/Permissions.yml
在Permissions.yml添加如下内容：
  1.   elitemobs.user:
  2.     default: true
  3.     children:
  4.     - elitemobs.stats
  5.     - elitemobs.events.kraken
  6.     - elitemobs.events.balrog
  7.     - elitemobs.events.fae
  8.     - elitemobs.checktier
  9.     - elitemobs.adventurersguild
  10.     - elitemobs.currency.user
复制代码
