新版bsg采用了xml格式，于是可以用xml检查器检查了，dtd则可以规定xml文件的结构。
使用方式：在xml声明之后加上以下内容
  1. <!DOCTYPE Machine SYSTEM "https://raw.githubusercontent.com/siiftun1857/Webs/master/bsg_v1.dtd">
复制代码
来引用兼容所有bsg工程文件版本1的dtd
  1. <!DOCTYPE Machine SYSTEM "https://raw.githubusercontent.com/siiftun1857/Webs/master/bsg_0.27.dtd">
复制代码
来引用bsg0.27的dtd
  1. <!DOCTYPE Machine SYSTEM "https://raw.githubusercontent.com/siiftun1857/Webs/master/bsg_0.3.dtd">
复制代码
来引用bsg的0.3dtd
如果xml检查器没报错的话你的存档就可以用了←_←

DTD永久更新，跟进bsg最新版本。

github项目:https://github.com/siiftun1857/Webs
详细解析:http://www.mcbbs.net/thread-555139-1-1.html
