ReflectionFX
介绍
这个轮子来源于一次偶然的机会，听说继承java的MagicAccessorImpl可以调用私有的方法，自己写了一个栗子试了一下真的可以，就有了写这个轮子的想法

这是一个开放的类库，几乎没有任何检查，你甚至可以用来反射这个类库本身
已测试可用版本Java8+ 不会还有人用Java7叭？

包括:
ReflectionAccessor
通用的反射调用接口，可以(任意)反射方法，成员变量，构造对象等

EnumHelper
为枚举设计的接口，可以构造新的枚举实例，增加/删除/修改枚举列表，对于枚举类中枚举项此接口暂时不支持修改

动态绑定
自己定义一个接口，写上方法声明，交给ReflectionFX实现，完成动态绑定
这是一种新的反射方法，至少我没见到过有用这种方法的类库  如果有请务必告诉我，谢谢谢谢!

注:本贴教程的所有内容仅限release 4.2.5和commit 3449b76df09fd0a6ea12f09d1f4e3b38dafece52及之前的版本

实用工具
ReflectionFactory里面提供了一些有用的小工具
ReflectionFactory#constant(Object)
返回一个持有一个常量的ReflectionAccessor
只可以获取它的常量，不可以修改(如果你反射它那就可以)

ReflectionFactory#throwException()
返回一个用来抛出异常的ReflectionAccessor
用这个抛出异常不需要在方法声明里添加throws

ReflectionFactory#UNSAFE
一个JDK Unsafe的包装，Java8到Java14的所有Unsafe的方法
如果在低版本调用高版本才有的方**抛出异常
其中还有一个获取当前JVM运行版本的方法，返回的版本为当前JVM支持的Class文件头最高版本
比如 JVM版本为8会返回52
每加一个版本，这个值会+1

ReflectionFactory#TRUSTED_LOOKUP
JDK 中权限最高的Lookup
可以无视访问权限查找任何类的任何元素

ReflectionFactory#METHOD_HANDLE_INVOKER
用来调用MethodHandle的工具
用这个来调用MethodHandle不需要捕获异常

ReflectionFactory#ACCESSOR
实现了MagicAccessor接口的一个类，包括了一些有用的方法
MagicAccessor
MagicAccessor里面有一些很有用的方法
MagicAccessor#setAccessible(AccessibleObject, boolean)
JDK9或更高的版本里，设置一个默认不可访问的元素可访问时会输出非法访问警告
用这个方法就不会有警告

MagicAccessor#forName(String)
默认实现为调用Class.forName(String)但是不需要捕获异常

MagicAccessor#forName(String, boolean, ClassLoader)
默认实现为调用Class.forName(String, boolean, ClassLoader)但是不需要捕获异常

MagicAccessor#defineClass(ClassLoader, byte[])
用给定的ClassLoader define一个类
因为默认实现为调用传入的ClassLoader的defineClass方法所以不可以为null

MagicAccessor#getCallerClass()
获取调用当前方法的方法所在的类

MagicAccessor#getClassContext()
获取当前调用栈中的每一个栈帧的方法所在的类

MagicAccessor#construct(Class)
实例化一个对象调用无参构造方法
实现为获取类的无参构造方法Constructor然后调用newInstance方法

MagicAccessor#construct(Class, Class[], Object[])
实例化一个对象，调用拥有给定参数类型列表的构造方法
实现为获取类的给定参数列表构造方法Constructor然后调用newInstance方法

MagicAccessor#invokeMethodHandle(MethodHandle, Object...)
和ReflectionFactory#METHOD_HANDLE_INVOKER相同的作用

MagicAccessor#getField(Class, String)
获取类中指定名字的变量

MagicAccessor#getMethod(Class, String, Class[])
获取类中指定名字和参数列表的方法

MagicAccessor#getConstructor(Class, Class[])
获取类中指定参数列表的构造方法

MagicAccessor#getFields(Class)
获取类中定义的所有变量

MagicAccessor#getMethods(Class)
获取定义在类中的所有方法

MagicAccessor#getConstructors(Class)
获取类中定义的所有构造方法

MagicAccessor#throwException(Throwable)
抛出一个异常

MagicAccessor#initialize(Object)
调用一个对象的Object#Object()构造方法


ReflectionFX - 实现原理

ReflectionFX - 实现原理
ReflectionAccessor
反射方法的实现
  1. private static <T> ReflectionAccessor<T> generic(
  2.   ClassLoader callerLoader,
  3.   Class<?> clazz,
  4.   String methodName,
  5.   MethodType type,
  6.   boolean isStatic,
  7.   boolean special,
  8.   boolean isAbstract)
复制代码
在这个方法里面会先实例化一个ClassWriter对象
声明一个类继承jdk的MagicAccessorImpl实现ReflectionAccessor 908行
在实现invoke方法的时候会先判断目标方法是不是静态方法 913行 如果不是静态方法，会先从可变参里面取出第一个对象
之后从可变参里面取出调用方法需要的参数 914行
然后根据最后三个boolean决定方法调用指令然后调用方法 915行
在取出参数的时候会判断目标方法的参数，如果有基本类型会拆箱 1128行
最后判断返回值类型
如果目标方法返回值是void，会返回null 923行
如果目标方法的返回值是基本类型会自动装箱，然后返回 924行
如果目标方法是静态方法并且参数列表为空，会实现无参的invoke方法 929行

反射变量的实现
  1. private static <T> ReflectionAccessor<T> generic(
  2.   ClassLoader callerLoader,
  3.   Class<?> clazz,
  4.   String fieldName,
  5.   Class<?> type,
  6.   boolean isStatic,
  7.   boolean isFinal)
复制代码
同样会构造一个ClassWriter，声明一个类继承jdk的MagicAccessorImpl实现ReflectionAccessor
在invoke方法的实现里面
会先判断可变参是不是null 947行
然后判断数组的长度 952行
目标变量是静态并且数组长度为1表示要改掉变量
目标变量非静态并且数组长度为2也表示要改掉变量
然后加入改掉变量的值的实现 957-1020行
会先判断变量类型为基本类型，如果是会拆箱 957行

如果变量是final，会用Unsafe修改变量
先获取变量的offset 971行
然后取出ReflectionFactory里面的Unsafe 972行
如果是静态变量会直接加载变量的类型 974行
非静态的话会取出可变参的第一个参数 975行
然后加载变量的offset 976行
然后从可变参里面取出第二个参数，判断基本类型拆箱 然后调用Unsafe里面的方法 984-997行

如果变量不是final，会直接用PUT指令 1005-1017行
然后返回新的变量值 1023-1030行

如果变量是static，会实现无参的invoke方法，默认为获取变量的值 1033-1040行

实例化对象的实现
  1. private static <T> ReflectionAccessor<T> generic(
  2.   ClassLoader callerLoader,
  3.   Class<?> clazz)
复制代码
实例化对象只分配内存，所以不需要传入参数
所以会相同的实现两个invoke方法
直接用NEW指令实例化对象然后返回 1090 - 1091行
因为新实例化的对象，JVM会标记为Uninitialized，不可以直接使用，所以也要继承MagicAccessorImpl来跳过字节码检查

反射构造方法的实现

  2.   ClassLoader callerLoader,
  3.   Class<?> clazz,
  4.   MethodType type)
复制代码
因为需要调用构造方法，所以只有当构造方法没有参数的时候才会实现无参invoke方法
默认实现可变参的invoke方法
同样先用NEW指令实例化对象 1058行
然后取出可变参里面的参数 1062行
然后调用构造方法 1063行

绑定方法
绑定方法的时候会实给generator添加一个MethodWriter，方法声明和传入的implementation的方法声明一样 434行
然后在MethodWriter里面添加一个CodeWriter
把所有参数按顺序入栈 436-445行
然后根据传入的kind和invocation添加方法调用指令 446行
最后添加返回指令 447-461行
因为在动态绑定里参数列表和返回值类型是确定哒，所以不用自动装箱和拆箱

绑定变量
和绑定方法一样会先添加方法，根据implementation声明 480行
然后根据变量的类型和修饰符计算出如果要修改变量的话会用到的变量加载指令 485-491行
绑定为PUT的时候，如果变量是final，会调用Unsafe来修改变量，调用方法和ReflectionAccessor的调用方法相同 496-511行
如果变量不是final，会直接用PUT指令修改
会先判断变量如果非静态，会从参数列表加载第一个参数到栈作为被修改的对象 515行
然后用刚才计算出的加载命令加载参数列表第二个参数作为变量的新值 517行
然后添加修改指令 518行
最后空返回 519行
如果绑定为GET，会直接用GET指令加载变量到栈然后返回 525-532行

实例化对象
绑定为实例化对象的方法实现和ReflectionAccesor的实例化对象实现相同
添加方法声明，在方法里用NEW指令实例化对象然后返回 544-547行

绑定构造方法
绑定构造方法时会先NEW指令实例化对象 560行
然后参数列表里面的参数按顺序入栈 564-573行
然后调用构造方法最后返回 575-576行

绑定enum helper
绑定enum helper的时候，原EnumHelper接口里面带泛型的方法除了实现泛型方法之外会另外实现一个具体类型的方法，所以可以自己在绑定点声明方法的时候把泛型改成具体类型

EnumHelper#construct(String)
在这个方法里，新枚举实例的name是传入的name，ordinal是已有的枚举列表的数组长度
用NEW指令实例化一个枚举实例
用传入的name和数组长度做ordinal，调用Enum#Enum(String, int)构造方法

EnumHelper#construct(String, int)
这个方**直接用传入的name和ordinal调用Enum的构造方法，实现和上一个方法相同

EnumHelper#values()
这个方法的实现是直接用GETSTATIC指令取出枚举类里面的枚举列表然后返回
获取枚举类里面的枚举列表并不是直接用一般的$VALUES变量名，而是在绑定时在从类的所有变量里面查找可能的变量
这和MC的EnumHelper也许是相同的实现

EnumHelper#values(Object[])
这个方法是调用Unsafe来更改枚举类里面的枚举实例
更改变量值之前会清空枚举类的Class实例里面的枚举缓存(赋值为null)

EnumHelper#add(Object)
这个方法里面会先实例化一个比枚举类里面的枚举列表长度多1的数组，复制之前的枚举列表，然后把传入的枚举项添加到数组最后，然后用Unsafe改掉枚举类里面的数组
同样也会先清空Class实例里面的枚举缓存

EnumHelper#remove(int)
这个方法里也是复制数组，不会复制传入的索引项，复制之后改掉枚举类里面的数组
其他
ReflectionFactory#constant(Object)
constant的实现是在实现类里有一个私有不可变的非静态常量，在构造方法赋值 878行 884行

ReflectionFactory#throwException()
throwException的实现是从可变参里取出第一个变量，然后用ATHROW指令抛出 863-867行

ReflectionFactory#UNSAFE
Unsafe的实现也是动态绑定，在static代码块里绑定Unsafe的方法，不支持的方**抛出异常 1307-1392行
JVM的版本是在static的开头读取Object.class的类文件头的major version 1231-1236行

ReflectionFactory#TRUSTED_LOOKUP
TRUSTED_LOOKUP是在Lookup类里面的一个静态常量IMPL_LOOKUP，在static里面用反射取出 1254-1282行

ReflectionFactory#METHOD_HANDLE_INVOKER
这个实现是，默认可变参的第一个参数为被调用的MethodHandle，后面的参数是调用MethodHandle传入的参数
