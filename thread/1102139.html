playsound 主命令：（来自 https://wiki.biligame.com/mc/%E5%91%BD%E4%BB%A4/playsound）
  1. /playsound <音效名> <来源> <目标> <发声坐标>
复制代码
吃东西的声音：
  1. /playsound minecraft:entity.generic.eat master @a
复制代码

1.12 的音效文件在 .minecraft\assets\objects 中。想找到特定的音效文件见下：

  • 先用任意文本编辑器（比如 Notepad++）打开 .minecraft\assets\indexes\1.12.2.json 文件；
  • Ctrl+F 搜索关键词（比如获得挑战成就：ui.toast.challenge_complete，具体叫什么名字可在 https://wiki.biligame.com/mc/Sounds.json 搜索）；
  • 每条搜索结果的后面都会有一串乱码样的混淆代码，复制混淆代码，前往 .minecraft\assets\objects 文件夹；
  • 搜索这个混淆代码，再给搜索结果的文件名添加 .ogg 后缀，播放即可。

播放非游戏本体的音效，使用资源包效果最佳，主命令与上方所述相同。

这个……你可以先翻译音效的主体，比如海豚 → dolphin、石头 → stone，然后 Ctrl + F 写入单词（注意先展开 Java 版数据值），回车即可。比如获得经验：经验球 → experience_orb，然后就能找到获得经验的声音是 minecraft:entity.experience_orb.pickup。
当然这就需要你对游戏内容比较熟悉，因为某些东西是翻译不出来的。
