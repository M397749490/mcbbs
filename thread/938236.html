标题: Ess插件配置文件解读教程

Essentials基础系列插件包括以下七个文件：
1.Essentials.jar　　　　　　　　   　总体设置——支持各种作弊命令，可以设置各种有关服务器功能的插件，以下附属插件的功能都经由该插件实现
2.EssentialsGroupManager.jar　　　 组管理——可以给玩家分类，如普通玩家，VIP，管理员，总管理等
3.EssentialsGroupBridge.jar　　　　 组桥接——支撑上一个插件的功能
4.EssentialsProtect.jar　　　　 　　 游戏保护——保护轨道、牌子，还有锁箱功能等
5.EssentialsSpawn.jar　 　 　 　   　出生点设置——设置出生点，仅仅需要一个命令
6.EssentialsChat.jar　　　　　　  　聊天显示设置——可以更改玩家的聊天格式，加前缀后缀尾缀之类，可以设置聊天范围
7.EssentialsGeoIP.jar　　　　　　　玩家来源显示——显示玩家所在的国家，甚至城市

你可以按照需求自行修改
  • &c欢迎, {PLAYER}&c!
  • &f输入 &c/help&f 查看帮助.
  • &6玩家列表: {PLAYERLIST}
  • &6现金余额: {BALANCE}
  • &6现在时间:&r {TIME}{DATE}
  • &6在线人数:&r {ONLINE}

spawn.yml

本帖隐藏的内容你可以为多个权限组设置不同的出生点，命令:/setspawn [权限组]
  • spawns:  #默认行,请不要删除
  •    builder:   #builder权限组的出生点
  •      world: world  #出生点所在的世界
  •      x: 0.0           #X坐标
  •      y: 110.0         #Y坐标
  •      z: 0.0           #Z坐标
  •      yaw: 0.0         #头的左右偏转角度
  •      pitch: 0.0       #头的上下偏转角度
  •    default:   #default权限组的出生点
  •      world: world
  •      x: 0.0
  •      y: 100.0
  •      yaw: 0.0
  •      pitch: 0.0

upgrades-done.yml

本帖隐藏的内容没有与之相关的资料，本文的所有内容都需慎重选择

  • 升级新的的出生点时在spawn.yml中创建新的
  • updateSpawnsToNewSpawnsConfig: true
  • ————监狱——————————————
  • updateJailsToNewJailsConfig: true
  • 警告指标！？
  • warnMetrics: true
  • 将物品价值移动到worth.yml
  • moveWorthValuesToWorthYml: true
  • 将服务器规则移动到配置文件
  • moverulesToFile: true
  • 对应所有用户的文件名！？
  • sanitizeAllUserFilenames: true
  • 新用户有默认的家
  • updateUsersToNewDefaultHome: true
  • 新用户powertool格式！？
  • updateUsersPowerToolsFormat: true
  • 新用户家格式！？
  • updateUsersHomesFormat: true
  • 取消旧的item.csv
  • deleteOldItemsCsv: true

worth.yml

本帖隐藏的内容物品名在Essentials/配置文件/item.csv中查看
每一个物品名后对应一个价格
价格在游戏中使用命令/worth也可以查看
命令/sell出售物品，需要权限
