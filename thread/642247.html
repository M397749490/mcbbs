如何使用
  • 将插件本体放在服务端根目录下的plugins文件夹中。
  • 运行服务端。
  • 手持金锄头选取合适点位并输入相关指令。
  • 测试Title效果。

指令权限
  1. /td world [区域名]  
  2. #为当前世界创建显示区域

  4. /td cube [区域名]  
  5. #以选取的两点为长方体截面的对角创建一个高为最大高度的长方体显示区域

  7. /td cylinder [区域名] [半径]  
  8. #以选取的一个点为圆心创建一个指定半径且高度为最大高度的圆柱体显示区域

  10. /td set [区域名] [enter/leave] [title/subtitle] [信息] [淡入] [显示时间] [淡出]  
  11. #为一个显示区域添加Title

  13. /td del [区域名]  
  14. #删除该区域的所有记录

  16. /td info [区域名]
  17. #查看指定区域的详细信息

  19. /td goto [区域名] [玩家名]
  20. #传送指定玩家至指定区域中心位置

  22. TitleDomain.main  
  23. #全部指令默认OP拥有
