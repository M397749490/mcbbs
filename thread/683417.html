这是因为脚本插件无法识别你所写入的物品
或者是写入的不是英文名而是数字ID

第二个虽然没有什么影响但是会有提示 写多了重载会很烦
MOD服务器如果不更改 aliases 文件根本无法写入英文物品
导致大量的提示 且添加 aliases 会非常的麻烦

这里有个非常简单的办法
是我无意间发现的 如有雷同我也没办法

代码部分

set 变量 to "物品英文名" parsed as item

边界方块
set {barrier} to "barrier" parsed as item
神秘MOD物品
set {itemlootbag} to "thaumcraft itemlootbag" parsed as item
