二、适用于Java的IDE（代码编辑器）*若有问题可以私信作者或QQ（严禁私下的讨论，必须联系我）

   1、IntelliJ IDEA(官网)：
         IntelliJ IDEA 简称 IDEA，是java编程语言开发的集成环境。在智能代码助手、代码自动提示、重构、代码分析、 创新的GUI设计等方面的功能可以说是超常的。旗舰版支持支付宝，目前最新版2020.1已经支持简体中文，是开发mod不错的选择。
         · 下载地址：点我下载最新版（免费版）         不是win或者想要其他版本
2、Eclipse(官网)：
         Eclipse 是一个开放源代码的、基于Java并完全免费的开发平台。就其本身而言，它只是一个框架和一组服务，用于通过插件组件构建开发环境。现在还有很多人使用Eclipse来开发mod。
         · 下载地址：点我下载最新版（64位）         其他版本
         · 安装教程：点我跳转         关于汉化

   3、Visual Studio code(官网)：
         Visual Studio code 是一个开源并完全免费的代码编辑器，属于微软的产品。不仅支持许多文件格式（包含json），并且界面设计简洁、美观，还配有代码自动提示功能。开发Fabric mod绝对是给不二之选。
         · 下载地址：点我下载最新版（64位）         不是win或者想要其他版本
         · 安装教程(含汉化)：点我跳转

三、起始文件fabric-example-mod的下载

要想开发一个基于Fabric的mod，就必须有一个类似于Forge MDK的初始文件。这个文件会有一个例示mod模板，今后我们开发mod时我们会将替换这个例示mod模板改为你的，并且你的mod代码都会被写在这个文件里。所以这个文件极其重要，要完好保存在您的磁盘中，最后会在里面导出你的mod。

   · 下载地址(GitHub)：点我下载fabric-example-mod
