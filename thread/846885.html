介绍 · Introduction
goBrush 这款插件旨在让你简化造山的过程.
使用高度图可以让你在几分钟内快捷轻松地创建矗立的群峦，你也可以使用预设或创建自定义的高度图来使你的建筑更加独特.

最新版只兼容1.13 帖内网盘下载地址为兼容1.8-1.12的旧版
使用方法
用燧石左右键即可
特点
  • - 左击燧石打开菜单，右击放置高度图
  • - 使用高度图可轻易地构造地形
  • - 可修改的配置
  • - 菜单可更改所有设置
  • - 不同的模式可以让你更改交互方式
  • - 可抬起和下推地面任何类型的方块
  • - 支持 PlotSquared
  • - 用于定向塑性的3D模式
  • - 可使用18种高度图笔刷
  • - 创建自定义笔刷
  • - 支持选择抬起的方块时使用全局蒙版
  • - 兼容Worldedit的 //undo 和 //redo

  1. disable-weather-changes: true

  3. disable-redstone: false

  5. disable-physics: true

  7. disable-gravity-physics: false

  9. disable-explosions: true

  11. disable-soil-trample: true

  13. disable-leaves-decay: true

  15. fix-attackspeed: true

  17. prevent-dragon-egg-teleport: true

  19. remove-end-gate-from-blocks: false
复制代码


模式
升降模式
可在抬升和下降模式中切换，也可以以3D的方式运作，在启用flat时有不同的效果。

平滑模式

平滑目标附近的方块到指定高度

3D模式

抬升和下降你所朝方向的方块

自动旋转

基于你的朝向旋转笔刷
如果关闭这个模式则默认为北方

指令&权限
gobrush.use
/gb info
/gb toggle
/gb undo [number] -> //undo
/gb size [number]
/gb intensity [number]
/gb brush [FileName]

gobrush.export
/gb export [FileName] - 基于你的worledit选区创建笔刷

gobrush.admin
/gb reload

gobrush.world.bypass
允许在关闭使用插件功能的世界使用该插件.

gobrush.bypass.maxsize
允许你操作的方块数大于上限

gobrush.bypass.maxintensity
允许你的操作强度超过上限
