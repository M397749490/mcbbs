适用于想用 Electron 来开发启动器的开发者
需要 NodeJS 10 以上版本 (最新的 Electron 5 已经是 Node 12)。

支持功能（简略版）
  • 官方验证，通俗的讲就是根据用户名密码获取 accessToken，功能上和 JMCCC 差不多。
  • NBT读写，这个不多说了，就是可以操作 NBT
  • 存档读取，目前支持读取存档的 LevelData
  • Minecraft 自动安装，自动从 Mojang 官方的源来安装 Minecraft。也支持自己替换源
  • 游戏设置读取/写入，读取 options.txt，修改完之后写回去
  • 资源包读取，读取资源包（zip或文件夹）的 pack.meta，同时能获得其中的图标
  • 玩家 Profile（皮肤），支持根据玩家 uuid 获得玩家皮肤，同时支持官方用户更改皮肤
  • Forge 自动安装，能够爬取 Forge 网页上的内容来获得 Forge 版本信息。根据版本信息自动下载并安装 Forge 到 Minecraft 特定版本。（从1.13后Forge安装过程需要Java参与）
  • TextComponent 解析，支持解析 JSON 或者普通字符串格式的 TextComponent（服务器 motd，或者聊天信息是这种格式，资源包简介甚至也可以是这种格式）
  • Minecraft 版本解析与生成，可以解析 Minecraft 版本信息 （需要的assets，libraries等），同时能够 mixin 版本（你分别有个Forge版本和Liteloader版本，你想要一个既有 Forge 又有 Liteloader 的版本，可以通过这个功能生成）
  • 启动 Minecraft（当然，启动核心肯定有的功能）
  • 正版用户异地登陆验证，也就是每当正版玩家用新的 IP 登陆，想更改皮肤或者用户信息的时候，会需要用户写一下密保问题。可以通过这个功能 1. 检测用户是否需要回答密保问题。 2. 获取密保问题 3. 回答密保问题


详细请见 github的 README
