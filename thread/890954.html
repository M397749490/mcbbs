(Player Report) 举报管理
当前下载量已达到2.9k+

特点:
         >> 轻重★延迟低 免费
         >> 配置文件可以设置所有消息
         >> 活跃的开发者 简易的操作面板
         >> 举报状态实时更新 （仅需要单击即可更新举报状态）
         >> 可设置举报奖励 (支持在线接收与离线接收)
         >> 在举报时可提供图片证据
         >> 可在举报受理页面直接传送至被举报人
         >> 当有人举报时管理员会最快得到通知
         >> 可以设置举报的冷却时间
         >> 与任何Minecraft版本兼容

命令:
/report （玩家名称） (举报原因) >> 举报一个玩家
/reports >> 打开举报面板
/reports clear >> 清理所有举报信息
/reports reload >> 重载所有配置文件
/reports claim >> 领取举报奖励
/reports setupclaimgui >> 设置奖励物品给离线玩家领取
/reports addurltowhitelist >> 添加一个白名单URL地址

权限:
PlayerReport.*  >>  所有权限 (包括管理员指令).
PlayerReport.Admin-Messages  >>  当输入/report 时允许获取管理员指令.
PlayerReport.Help  >>  允许使用指令 /reports help.
PlayerReport.Report  >>  允许使用指令 /report 举报其他玩家.
PlayerReport.Reports  >>  允许使用指令 /reports 打开举报管理GUI.
PlayerReport.Clear  >>  允许使用指令 /reports clear 清除所有举报.
PlayerReport.Reload  >>  允许使用指令 /reports reload 重载配置文件.
PlayerReport.Notify  >>  接收举报信息权限
PlayerReport.ReportTimerBypass  >>  无视举报冷却.
PlayerReport.SetupClaimGUI  >>  允许使用指令 /reports setupclaimgui 设置离线用户举报奖励.
PlayerReport.AddURLToWhitelist  >>  允许使用指令 /reports addurltowhitelist 添加白名单URL
