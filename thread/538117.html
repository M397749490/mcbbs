[管理]RestartEvolution 3.4 —— 重启拓展 [1.6.2-R0.1]



描述：

　　重启拓展是一个插件,它允许管理员启动和停止服务器。
　　通过输入命令服务器脚本自动检测它是否应该停止或重新启动。
                                                         （描述来自原帖英文翻译如有出入勿喷）

指令：
         /re help                        显示RestartEvolution帮助
         /re restart                重启服务器
         /re stop                        关闭服务器
         /re restart now                立即重启服务器
         /re stop now                立即停止服务器
         /re restart time         分钟 XX分钟后重启服务器
         /re stop time                分钟XX分钟后关闭服务器
         /re reload                        重新加载插件
权限节点：
re.restart                           重启服务器
re.restart.now                    立即重启服务器
re.restart.time                    XX分钟后重启服务器
re.stop                               关闭服务器
re.stop.now                        立即停止服务器
re.stop.time                       分钟XX分钟后关闭服务器
re.reload                            重新加载插件

Windows.bat 文件设置  内容引入 @1210127
  1. @echo off
  2. Title Minecraft Bukkit - Modified
  3. :MAIN
  4. java -Xms1024M -Xmx1024M -jar 服务端启动文件.jar
  5. if exist "plugins\RestartEvolution\restart.mcs" goto MAIN
  6. if not exist "plugins\RestartEvolution\restart.mcs" goto END
  7. :END
  8. pause>nul

  1. #重新启动警告
  2. warnings:

  19. #冷却消息（停止）
  20. cms: "&f[&9服务娘&f] &7服务器停止: "

  23. #在聊天中重新启动信息
  24. rm: "&f[&9服务娘&f] &a>>重新启动<<"

  26. #停止聊天
  27. sm: "&f[&9服务娘&f] &c>>停止<<"

  29. # 客户端重启消息
  30. rmc: "&9服务器重启，稍后见"

  32. # 停止消息在客户端

  35. # 分钟的消息

  44. # 警告必须在几秒钟内输入。

  47. arenable: true

  53.   - 900
  54.   - 300

  59.   - 1

  61. #当信息出现时，应该播放声音
  62. restartmessagesound: "NOTE_PLING"
  63. sound_activated: false

  65. # joinmessage - format
  66. jmformatstop: "&f[&9服务娘&f] &7服务器停止: "
