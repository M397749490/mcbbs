标题: 求mc1.13.X生物群系生成代码
注意版本：必须是1.13.X，其他版本代码一律判错
也就是给定特定种子和坐标，能得到"暖水海洋"等答案


既然金粒那么多，就多点要求吧

1.必须是C++版，不支持java，请注意
2.调用方法：
  (1)使用函数实现
    void biome::setseed(long long seed)可以设置种子
    int biome::getbiome(int posx,int posz)可以获取指定方块坐标的种子
    返回生物群系id
    或者返回string类型，表示生物群系名称，是原版id，例如plains,ocean
  (2)如果感觉比较复杂，可以弄文件IO
    输入格式：
      第一行一个整数n，表示操作次数
      接下来n行，第一个数字m表示操作
      如果m=0，则一个整数s表示把种子设为s
      如果m=1，则随后两个整数x,z表示获取x,z位置的生物群系
    输出格式：
      对于每一个m=1，输出一行一个整数或字符串，意义同函数实现
  保证输入的坐标绝对值小于10万
  种子在long long（java的long）范围内
3.可以使用STL，也可以using namespace std;
4.调用一次setseed随后调用20次getbiome为一组，每100组的时间不得超过5秒
  任何时候内存占用不得超过1GB，即使调用上亿次
  可以开O2，请注明
  CPU:Intel(R) Core(TM) i5-6200U CPU @ 2.30GHz
  内存:4GB
  系统:Win10
5.必须保证完全正确：与原版游戏中获得的信息必须完全相同
  只要有一个坐标位置得出了错误答案，就会判错
6.可以进行混淆


检查方法：先看时间和内存使用情况，然后检查正确性：手动进入世界，然后tp到给定坐标，比较是否与输出相同
保证调用时设置的种子各不相同
每个种子调用次数少于40
最好整合成头文件


调用示例：

  1. <p>#include"biome"</p><p>#include<bits/stdc++.h></p><p>using namespace std;</p><p>int main(){</p><p>    ios::sync_with_stdio(false);//io优化，可以无视</p><p>    for(long long s=1900;s<11900;s+=100){</p><p>        biome::setseed(123);</p><p>        for(int x=0;x<256;x+=16){</p><p>            cout<<biome::getbiome(x,0)<<endl;//返回int和string都可以</p><p>        }</p><p>    }</p><p>}</p>

文件调用示例应该不需要

恳请版主需要设置最佳时进行上述检查后再设置
