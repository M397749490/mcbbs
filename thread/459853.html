作者: 2362577123    时间: 2015-6-26 14:03
首先输入/scoreboard objectives add use stat.useItem.minecraft. bow指令，回车，接着用高频连接A命令方块，A命令方块内输入指令：testfor @p[score_use=1,score_use_min=1]比较器接出到B命令方块上，B命令方块内输入你要执行的指令，然后在B命令方块上放置C命令方块，C命令方块内输入：scoreboard players set @p use 0即可实现使用弓则触发B命令方块的效果。
