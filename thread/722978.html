Join and Leave Messages
介绍
1.自定义进服务器公告
2.支持ESS称号
使用方法
1.下载本插件丢进plugins文件夹。
2.服务器版本1.9-1.12 (可能支持1.8以上版本)。
3.只支持Java8。
4.给予玩家权限。
5.进服生效。
截图与配置
messages:
#  QQ 1535821575 汉化完成
#   @th = 玩家名称（无称号）  @th = 称号+玩家名称
#  join: '&7@td &8(@tn) &7has joined the server.'
#  leave: '&7@td &8(@tn) &7has left the server.'
#  no_permission: '&4&lX &cYou don''t have permission.'
  join: '&f玩家 [&e@tn&f] 进入服务器'
  leave: '&f玩家 [&e@tn&f] 退出服务器'
  no_permission: '&4你没有权限'
