作者: qazwsx852    时间: 2017-1-1 22:22
USB Switch
Use adjacent to Machines that require USB Sticks to select Recipes
Add USB Cable to Slot where USB Stick in the Recipe would go
Clicking with USB Stick will write its Data to the selected Slot.
Not usable with Machines that consume USB Sticks, such as Scanners!
Requires a Selector Cover to work, otherwise it always selects Slot 0!
