TpLogin
固定登录地点玩家每次上线都出生在同一位置
版本:1.8-1.10


<< 插件简介 >>
每次进入伺服器都会在同一位置
bukkit的1.5.1版本存在spigot新版核心上会与其他插件冲突，建议大家使用该版本。
玩家在300秒<可设置>内重新进入服务器将不会被传送至设置的登入点


<< 插件指令 >>
/tplogin set - 设置登入点
/tplogin set donator - 强制设置登入点
/tplogin tp - 传送至登入点
/tplogin reload - 重载插件
