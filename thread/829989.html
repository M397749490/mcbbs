说明
插件不会阻止玩家抛鱼竿/收鱼竿等操作，
只是当玩家钓上来鱼并且打算收竿的时候，
如果不满足钓鱼条件，就清空钓上来的物品，玩家什么也得不到。
具体限制：
首先，钓鱼点必须是一个水源，并且周围有3个相连的水源（位置不限），如图

再者，旁边不能有其它实体，否则会把鱼吓跑，（可配置）
最后，对光照等也有一定的要求，太暗了就钓不上来鱼了（可配置）
命令/权限
  1. /lf reload 重新加载配置文件
  2. 需要权限：LimitFishing.use
复制代码
  1. 权限：LimitFishing.pass
  2. 拥有此权限可不受限制

配置
  1. # 所需光照（天空光+人工光），如果光照强度小于这个值，则无法钓鱼
  2. # 设置为0则不启用这个功能
  3. AllLight: 7
  4. # 来自天空的光照，不计算火把等人工光源
  5. # 如果光照强度小于这个值，则无法钓鱼
  6. # 设置为0则不启用这个功能
  7. LightFromSky: 7
  8. # 周围多少格内不能有其它实体
  9. # 设置为0则不启用这个功能
  10. Radius: 1
  11. # 当Radius不等于0时，这项配置才有效
  12. # 你可以将实体添加到这里
  13. # 这样当周围有这些实体时，仍然可以钓鱼
  14. # 默认：画、展示框、经验球
  15. # 你可以在下方的网址查看实体列表
  16. # https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/entity/EntityType.html
  17. NoFear:
  18. - 'PAINTING'
  19. - 'ITEM_FRAME'
  20. - 'EXPERIENCE_ORB'
  21. # 输出的提示，留空则不会有任何输出
  22. # 当玩家没有在水里钓鱼，却把鱼钓上来的时候
  23. msg1: '&e连水都没有,怎么会有鱼?刚刚一定是错觉'
  24. # 光照强度不够的时候
  25. msg2: '&e这里太暗了,完全看不清楚,让鱼给跑了'
  26. # 天空光不够的时候
  27. msg3: '&e还是找个阳光明媚的地方钓鱼吧,这里不好钓'
  28. # 周围有其它实体的时候
  29. msg4: '&e哎呀,周围有东西把鱼给吓跑了'
  30. # 水的范围太小的时候
  31. msg5: '&e这一点点水怎么可能会有鱼,刚刚一定是错觉'
