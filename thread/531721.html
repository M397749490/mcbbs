大家好，我是qredesu，我给大家带来的是一款娱乐型插件！{:10_512:}

这款插件可以用来搞活动或者直接用来当稀有野怪使用，默认巨型生物血量都为100血！

指令与权限
/giants spawn giant <X> <Y> <Z>                      在某坐标生成一个巨型僵尸
/giants spawn slime <X> <Y> <Z>                      在某坐标生成一个巨型史莱姆
/giants spawn magmacube <X> <Y> <Z>          在某坐标生成一个巨型岩浆怪
/giant reload                                                        重载插件
/giant version                                                      查看版本
giants.version         查看版本权限
giants.spawn          生成生物权限
giants.reload          重载插件权限
giants.debug          接收生成信权限
giants.*                所有权限
配置文件简介
config.yml:
Giants Configuration:
  Entities:
                          
自动生成
    Giant: true                          是否开启自动生成巨人僵尸 填 "true"或者"false" true是开启 false是关闭
    Giant Slime: false
                          
是否开启自动生成巨型史莱姆 >否
    Giant Magma Cube: false
                          
是否开启自动生成巨型岩浆怪 >否
  Debug Mode:
                          
是否开启生成巨型生物后通知玩家
    Enabled: false
否
    Debug Message: '&2A {entity} has spawned at X:&F%X &2Y:&F%Y &2Z:&F%Z'        生成生物后的提示

巨型僵尸配置修改
Giants/Giant/giant.yml
Giant Configuration:
  Spawn Settings:
    Chance: 10            自动生成几率  >10%
    Worlds:                  自动生成的世界 以下世界都可以自动生成  (不想在某一个世界自动生成,去除即可)
    - world                    主世界
    - world_nether        地狱
    - world_the_end     末地
  Giant Stats:             巨人僵尸功能设置
    Health: 100              血量修改 >100HP
    Experience: 5           掉落经验 >5个经验
    Drops:                      掉落物品:1-0-0 第一个数字是1 的ID 代表石头 如果你想改变钻石,那就填写264-0-0
    - 1-0-0;1;100/100
  Damage Settings:                          巨人僵尸伤害的阻止设置
    Arrows:
      Damage done by arrow: 10       箭的伤害值
    Fire:
      Allow Fire Damage: true             是否允许火焰伤害   如果是 false 巨人将不会受到烧伤
    Block Damage:
      Allow Suffocation: false              窒息   如果是true 巨人将会因某原因窒息而减血
      Allow Cacti Damage: false          仙人掌伤害     如果是true 巨人走到仙人掌时候,会因此减血
  Attack Mechanisms:                      巨人攻击设置
    Lightning Attack: false                 闪电技能 巨人会打你而发出闪电, false  关闭  ture 开启   
    Stomp Attack:                            踩 技能      
      Enabled: false                            关闭状态
      Explosion Power: 1                   爆炸效果 1
      Light Fire: false                          是否着火 否
    Kick Attack:                                击飞技能
      Enabled: false                           关闭状态
      Kick Height: 1                           击飞高度 1
    Fire Attack:                                 火球技能    靠近的玩家,巨人僵尸将向玩家扔火球
      Enabled: false                            关闭状态
      Ticks for Target: 100                 目标着火时间
      Ticks for Giant: 100                   巨人着火时间
    Throw Boulder Attack:                抵抗技能
      Enabled: false                            关闭状态
      Block Damage: 1                      抵抗伤害 1
    Shrapnel Attack:                         召唤技能
      Enabled: false                            关闭状态
      Baby Zombies: false                  是否生成小僵尸 =否
      Zombies to Spawn: 3                生成僵尸数量3
      Health: 20                                 僵尸的血量20
    Spawn Zombies On Death:          僵尸死亡技能
      Enabled: false                            关闭状态 =否
      Baby Zombies: false                  小僵尸 =否
      Zombies to Spawn: 5                生成数量 5

  Sounds:                                        声音/音效
    Stomp Attack: true                      踩 技能音效
    Fire Attack: true                           火球攻击音效
    Throw Boulder Attack: true          投掷音效
    Kick Attack: true                          击飞音效
    Shrapnel Attack: true                   召唤音效
    Death: true                                  死亡音效
