作者原话：

Quake是一个非常令人上瘾的游戏！这是一个游戏的灵感来自Hypixel服务器。你有一个轨道炮(一个锄头)和轨道炮的目的是杀死其他队友（在Solo里是玩家）右键轨道炮来杀死，可连杀!轨道炮使用后,需要两秒再次“重新加载”和拍摄,轨道炮的重载进程是经验栏,但是你可以升级轨道炮通过购买他们。升级你的锄头(轨道炮)使冷却时间短!第一个队友杀死25个敌方队友（Solo为敌人）赢得游戏!(感谢  Top2001_1 的翻译）

-------------------------------------------------------------------------------
简介：这是一款适用于minecraft服务器的FPS类射击小游戏插件，多用于小游戏服务器，此插件游戏属超快节奏，充满竞技的乐趣与快感！
-------------------------------------------------------------------------------



       如何安装：
一、下载插件，然后放入plugins文件夹
二、重启载入你的服务器
三、创造出竞技场（创造方法请看下一Part)
四、享受游戏吧！
-------------------------------------------------------------------------------
如何创建一个竞技场？

1.
输入/quake create [游戏名] [游戏模式]-创建一个游戏场地
供两个游戏模式可用 1为Solo(单人打) 2为Team(分组打) 必须匹配大小写
2.输入/quake setmin [游戏名] [人数] -设置至少需要多少个玩家来开始游戏。
3.输入/quake setmax [游戏名] [人数] -设置最多只能有多少玩家进行游戏。
4.输入/quake addspawn [游戏名] -设置这个游戏场的出生点。
5.输入/quake save [游戏名] -保存你的设置。
6.开始游戏吧！
【设置游戏等待大厅 [房间列表]】
*你需要使用 WorldEdit 来帮助你完成这个设置.
使用 /quake addlobby 来设立这个列表墙（前提是已经用 WorldEdit 选择了两个点）.
使用 /quake setlobbyspawn 来设置游戏开始和结束将会被传送到这个坐标.
-------------------------------------------------------------------------------
指令与权限
Commands 指令
  • /quake help - 查看所有关于 quake 的帮助
Permissions 权限
  • Quake.player - Default组玩家的权限.
  • Quake.JoinInGame - 加入游戏.
  • Quake.modo - 开始/暂停.
  • Quake.edit - 编辑场地.
  • Quake.lobby - 设置大厅.
  • Quake.VIP - VIP权限.
  • Quake.Shop - 打开商店.
  • Quake.admin - 允许使用所有指令

-------------------------------------------------------------------------------
注意！quake.shop千万别给玩家否则可以无限刷绿宝石！
