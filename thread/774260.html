BiteSkyWars
超级空岛战争


简介
空岛战争是众广周知的一个火爆的空岛战争小游戏
各位挑战者在各自空岛上，等待游戏开始后降落自己的岛，搜刮物品，越过其它岛，开展一场搏斗，成为站到最后的胜利者


特色
  • 高度自定义消息内容
  • 炫酷粒子效果
  • 多彩玻璃笼子
  • 支持数据库
  • 自定义职业
  • 无限竞技场
  • 设置简单
  • 无限牌子
  • 资源投票（不同级别资源内容不同：简单，普通，疯狂）
  • 时间投票（决定早午晚时间）
  • 全息图
  • 计分板
  • 源代码
  • 统计

命令（此命令适用于插件版本1.1.9）
  • /sw - 查看命令
  • /sw create - 创建竞技场
  • /sw spawn - 大厅位置
  • /sw load 地图名 - 加载一个世界
  • /sw save - 保存当前世界
  • /sw tp 地图名 - 传送到一个世界
  • /sw scan - 扫描当前地图
  • /sw build - 改变当前建筑管理模式
  • /sw delete 竞技场名 - 删除竞技场
  • /sw join 竞技场名 - 加入游戏
  • /sw joinr - 随机加入游戏
  • /sw leave - 离开游戏
  • /sw arena - 查看竞技场列表
  • /sw shop - 打开商城菜单
  • /sw menuarenas - 打开竞技场菜单



推荐给玩家权限
  • skywars.vote.*
  • skywars.join
  • skywars.leave
  • skywars.menuarenas
  • skywars.arenas

教程
  • 安装插件，重启服务器
  • 关闭服务器
  • 推荐使用 notepad++ 软件 打开文件 config  （所在位置 plugins/BiteSkyWars ）
  • 改为 build-mode: true
  • 导入地图（如图）
         

  • 启动服务器，进入服务器
  • 设置游戏大厅，输入命令 /sw spawn
  • 输入命令 /sw tp 沙岛空战   #前往沙岛空战地图，这是示范教程，名字根据地图名字
  • 摆放信标（玩家的游戏出生点）（沙岛空战地图已放好信标）
  • 输入命令 /sw create   #创建竞技场
  • 输入命令 /sw scan   #扫描地图（自动设置最小最大玩家，资源位置等）
  • 输入命令 /sw save   #保存当前地图
  • 关闭服务器
  • 打开文件 config （所在位置 plugins/BiteSkyWars）
  • 改为 build-mode: false
  • 启动服务器
  • 加入游戏吧


创建牌子
  • 输入 /sw build
  • 放置牌子
  • 格式
          第一行：[sw]
          第二行：[竞技场名]
