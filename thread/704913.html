首先，尝试镜像主世界

您首先打开GroupManager的Config文件

找到settings-mirrors-world
将下面的内容替换为如下：
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           all_unnamed_worlds:
  9.           - users
  10.           - groups
复制代码

这样子将让末地镜像主世界的权限

其次，如果要单独世界权限，则

打开GroupManager的Config文件

找到settings-mirrors-world
将下面的内容替换为如下：
        world:
  1.           world_nether:
  2.           - users
  3.           - groups
  4.           all_unnamed_worlds:
  5.           - users
  6.           - groups
复制代码

然后再到达末地，使用权限添加指令
  1. /mangaddp [组名] [权限]
复制代码
