STEP1

只有这两个文件夹是储存语言文件的所以只要改这两个文件夹

然后就真正要汉化了……

[blank]BUNDLES篇
前言
这个文件夹是储存关于游戏内生物、物品等等……反正就是游戏中的语言文件和属性的
因此，如果你想要让游戏更富有/不富有挑战性，你可以自己去改里面除语言文件外的
东西，但是这些东西本帖不作介绍。

STEP1
进入文件夹，里面有些文件夹是不用改的，我用绿色箭头标注：

在这些要改的文件夹里，一律改English.dat,其他不改，我要分别讲一下：
Animals
储存动物的，格式：
Name [显示名字]
例：Name deer

Items
储存物品的，格式：
                   Name [显示名称]
(可能没有)  Description [介绍]

例：Name MRE
       Description xxxxx

Vehicles
储存车辆的，格式：
Name [显示名称]              ——注：就是鼠标指针指着这个车时显示的名称=显示名称
例：Name Ambulance
我们要汉化的是[显示名称]里的内容

STEP2
自行汉化一个文件，然后我赌一毛钱你对自己汉化的成果灰常满意，
不过还有最后一步：把编码转为以UTF-8无BOM格式。
以Notepad++举例：
不然会乱码。

STEP3
按照STEP1~2的步骤汉化，然后全部保存，进入游戏测试吧~

FINISH.


[blank]LOCALIZATION篇
前言
这个文件夹是储存菜单栏上文字的内容的，就像一进入游戏按钮上面那些字，如果
对Unturned菜单比较熟悉的可以不改【尽管一半中文一半英文似乎看着不好玩QAQ】

STEP1
打开文件夹，进入English文件夹。

STEP2
你会看到里面有四个文件夹，逐个讲解：

Editor
这个是做地图的编辑器内部的文字，不做地图的可以不改
Menu
这是一进入游戏后那些菜单和那些菜单下的子菜单的内容
Player
这是关于玩家的内容【如死亡信息和一些你自己看到的枪支信息等】
Server
服务器里面一些命令的内容，不联机一般用不到

然后里面你会看到有很多的.dat文件（别问我怎么才能看到这些，见【附录1】）
，一律用上面提到过的Notepad++或者什么的打开，
里面有一行一行的E文，每行的格式基本是这样的：

[内部名称] [显示名称]

中间有空格，但是显示名称里面可以有空格，例如：
Namexxx A Name xxx
[   内部  ] [     显示     ]
我们要汉化的是[显示名称]里的内容
然后尽情发挥你的创造力英语知识来汉化吧！！

STEP3

我赌五毛钱你一定对自己的汉化成果非常满意
但是还有最后一步：把编码转为以UTF-8无BOM格式
这里以Notepad++举例：


STEP4

按照STEP2~3的步骤逐个汉化，然后全部保存好
就可以去游戏里实验一番辣~~

FINISH.

-->浏览…-->找到你复制后的游戏文件夹并双击Unturned.exe-->添加所选文件

STEP2
