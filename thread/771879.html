标题: 我的服务器升级以后会加血，怎么关闭
我的服务器玩家升级以后会加血，我用小号试了下，不仅加血，移动速度也会增加，我没有加什么特定会这样的插件，怎么才能关闭呢？在线等！！！！
作者: MC_Shenfeng    时间: 2017-12-15 16:42
找到itemlorestats插件
关闭升级加血和加速度就行
具体配置
upgradeStatsOnLevelChange:
  enabled: true
  upgradeCap: 5
  stats:
    armour: 0.0
    dodge: 0.0
    block: 0.0
    critChance: 0.0
    critDamage: 0.0
    damage: 0.0
    health: 1.0
    healthRegen: 0.0
    lifeSteal: 0.0
    reflect: 0.0
    fire: 0.0
    ice: 0.0
    poison: 0.0
    wither: 0.0
    harming: 0.0
    blind: 0.0
    movementSpeed: 0.0
    xpMultiplier: 0.0
    pvpDamage: 0.0
    pveDamage: 0.0
    heroesMaxMana: 0.2
后面数字全改成0就行
