FAQs


Q.我看到资源包的模板里选择了音乐！
A. 是的，附加包文本里更改了唱片的文本，但是需要额外的附加包才能实际听到音乐。额外的附加包可以在这里或这里找到。

Q.虽然好像错版了，但是我看到了Java版？
A.有的。可以在这里找到。

Q.GitHub下载太慢了？
A. 有不定期更新的蓝奏云链接，可以在帖子的楼层#2找到。
此外，附件里也有一份普通的版本： meme-resourcepack_v1.2.0.zip (570.46 KB, 下载次数: 36)
2021-2-2 16:12 上传
点击文件名下载附件


Q.模块化是基于什么实现的？
A. 依赖构建脚本的各个参数。为了照顾不会使用命令行的用户，我们也制作了网页打包。这里要感谢 @电量量 提供的服务器。网页打包通常会提供一些比正式版本更新的翻译。需要注意的是，目前网页打包不稳定且有许多已知漏洞。甚至我们团队里的人也说这东西很不稳定如果你发现QQ无法分享网页打包的链接，这是正常现象，请使用浏览器打开。

Q.愚人节快乐！（本贴发布于愚人节）
A. 但是会一直更新下去。如果看到新版本字符串没有及时同步，欢迎到原帖链接提交 Pull request/Issue。

Q.我有些更生草的名字，可以提交吗？
A. 去 GitHub 提交 Issue/Pull request 吧！

Q.有些梗我好像没看懂?
A. 也许终末之诗里有你想要的答案……

Q.有些问题这里没有提及。
A. 去查看 Github 的 README.md，可能会有帮助。如果还是没有，欢迎提交 Issue。
