Lunatrius的Mod合集包含了许多在多人游戏中实用的Mod
更新新版LunatriusCore 该Mod为所有Mod必备组件，缺少将无法运行。
更新了InGameInfo 现在可以在游戏内使用指令/igi save InGameInfo.xml/json/txt保存配置文件了
添加一个Laser Level Mod[1.8],可以在建筑时画出虚拟的激光标记（？），按F12可以打开GUI
Laser Level Add laser markers to make building (repetitive) structures easier! Open the GUI with F12 (configurable).

Mod介绍：
[1.8]InGameInfoXML(此mod的原版也是楼主搬运的，原开发者bspk.rs更新到1.6.4停止更新,1.7.10有人搬运)
直接显示有用的信息在您的屏幕上。
更新日志：（未汉化）
Notes
  • 2.4.1.27+ ~ added support for bspkrs' text format with minor modifications:
    Color codes (&f, &a, &r) have to use the $ symbol instead of the & symbol (&f => $f, &a => $r, ...).
    The syntax for boolean tags (slimes, daytime, raining, ...; check the download page for a list of all tags) has changed a bit.
    Example: The slime tag has to be changed from <slimes[yes/no]> to <if[slimes[yes/no]]>.
  • 2.8.0.58+ ~ you can open a list of all tags by using /igi taglist (functions coming soon, hopefully)
  • 2.8.0.59+ ~ the config is no longer be automatically extracted from the jar file. If you want to tweak it you can use one of the following commands to extract the config:
    /igi save InGameInfo.xml/igi save InGameInfo.json/igi save InGameInfo.txt

InGameInfo目前1.8版本处于不稳定开发版
[1.7.10]显示怪物生成区域（联机有个Hostile插件也可以实现这个）
就如它名字所讲，这个mod可以显示怪物会生成的区域。

[1.7.10/1.8]Stackie堆叠
这个mod可以将大量掉落物品堆叠成2048一叠的效果，估计可以有效减少卡顿。

[1.7.10]Schematica建筑党的福音
这个mod可以扣下服务器中的建筑物，并且可在游戏中实现AR(增强现实）的效果（PS：此段为楼主语）
使用方法：按/（数字键盘）选择Schematic文件，按*选择建筑范围，按-调整导入建筑的位置。

[1.7.10]Profile配置文件
这个插件允许用户建立多种配置文件，允许在它们之间进行快速切换（例如：“挂机”和“正常”，这里的“挂机”图形设置为最小）。它增加了一个命令，“/profile”。在游戏中提供帮助。

[1.7.10]DynIMC
这个Mod的作用是发送自定义的消息到另外的mod，此mod需要支持IMC API的mod（作者意义不明，可能就是跨mod通信吧）
