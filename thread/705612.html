作者: 十中八九.    时间: 2017-7-11 18:11
可以选择两种方式：
1、向需要的权限添加 essentials.build 权限
/mangaddp 需要的权限 essentials.build

2、找到在./plugins/GroupManager/worlds/world 下的 groups.yml
将你需要的权限组（下以 Builder 组为例子）像这样修改：
groups:
  Builder:
    default: true
    permissions:
    -
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      build: true
      prefix: '&e'
      suffix: ''
将 info 下的build: false 改为 build: true

已经在服务器内测试，希望能够采纳！
