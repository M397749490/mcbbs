之前（1.12或以上....吗？）可以用testfor @a[dy=2]

指令做出的东西如何用execute作出相同的效果呢...

作者: ⊙u⊙    时间: 2019-9-28 17:19
  1. /execute if entity @a[dy=2]
复制代码

这个应该完全等价于之前版本的 testfor @a[dy=2]

然而，不推荐使用，因为以前因为命令受限（或者什么其他原因...应该是execute出来之前），只能使用testfor，而testfor最大的弊端就是检测到的东西与后面执行的命令对象没有任何关联。

(不严厉的例子)比如
testfor @a[dy=2]
kill @a[dy=2]

同样的选择对象，testfor的使用就是多余的了


换个思维，检测东西是希望执行后续操作对吧？那么接着执行就是了，比如
execute if entity @a[dy=2] run kill @a[dy=2]
那么问题又来了，execute if 的作用单纯测试某实体/方块是否存在，更多的情况下会是希望以这个实体执行某些指令，所以使用 execute as @a[dy=2] run kill @s 更为合适
（例子不是很好，甚至不需要execute...但是道理差不多就是这样）

不同的目的还可能有不同甚至更好的操作，所以
