Piston Blocker 1.1



说明：

小而轻便的插件，可以防止玩家利用复制BUG（粘液块或活塞压铁轨或南瓜复制BUG）进行复制铁轨和地毯.







如果你们还知道有什么发现活塞复制物品的BUG请通过原网址跟作者反馈哦！


指令：

       / pistonblocker（reload）-重新加载配置

权限：

          command.pistonblocker

pistonblocker 也可以写作：
       pistonblock，pistonb，pblocker，pblock，pb
文件配置(config.yml):
  1. # Show colors in console output (and log files)
  2. #开启就会在后台显示彩色文字信息.
  3. color-logs: true
  4. # Should the piston be removed from the world?
  5. #开启的话，活塞触发BUG就会被清除.
  6. break-piston: true

  8. # If break-piston is true, should we drop the
  9. piston item to the ground?
  10. #break-piston 这个开启活塞触发BUG就会掉落.
  11. # Explosion power above 0.0 (set below) will most likely destroy this drop
  12. #explosion-power这个设置0.0的时候就会破坏BUG掉落物.
  13. drop-piston: false
  14. # If break-piston is true, should we create an explosion effect?
  15. #break-piston这个开启，会有一个爆炸特效.
  16. explosion-effect: true

  18. # If break-piston and explosion-effect are true, what power should that #explosion be?
  19. #break-piston 和 explosion-effect是开启状态下，爆炸的威力如下设置.
  20. # 0.0 will cause no damage to blocks or players (just a visual effect)
  21. #0.0的时候不会有伤害，仅仅特效.
  22. # 3.0 is same as Creeper
  23. #3.0和苦力怕的爆炸威力一样.
  24. # 4.0 is same as TNT power
  25. #4.0和TNT的爆炸一样.
  26. # 6.0 is same as Charged Creeper
  27. #6.0和闪电苦力怕的威力一样
  28. # Anything higher is not advised... You've been warned.
  29. explosion-power: 4.0
