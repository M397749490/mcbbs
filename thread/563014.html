配置文件（用法）：
  1. Location:
  2.   LocX: 0     这个是你要固定的XYZ轴。
  3.   LocY: 0
  4.   LocZ: 0
  5.   LocName: world     这个是你要固定上线的世界
  6.   Msg: §c这里是提示信息，注意提示信息的颜色必须用§而不是&
