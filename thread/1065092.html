安装 JavaScripts 变量拓展

plugins\PlaceholderAPI\javascripts 打开这个目录 新建一个文本文档 后缀改成.js 文件名随意
用记事本或其他文本编辑工具打开
内容写
  1. var Marriage = "%marriage_is_married%";

  3. function Male() {

  5.    if (Marriage == "no") {
  6.        return "§8§l[§7未婚§8§l]";
  7.    }
  8.    if (Marriage == "yes") {
  9.        return "§d§l[§c已婚§d§l]";
  10.    }

  12.    else {
  13.        return "";
  14.    }
  15. }
  16. Male();
复制代码


打开 plugins\PlaceholderAPI目录 打开 javascript_placeholders.yml 文件
里面写上

Marriage:
  file: 你刚才命名的文件名.js
  engine: nashorn

保存 游戏内/papi reload
然后用变量 %javascript_Marriage% 来显示已婚或未婚
