可能是residence造成的 修改plugins\residence\config.yml
找到这一段
  1.     Flow:
  2.       # Level from which one to start lava and water flow blocking
  3.       # This dont have effect in residence area
  4.       Level: 120
  5.       # With this set to true, lava flow outside residence is blocked
  6.       NoLavaFlow: false
  7.       # With this set to true, water flow outside residence is blocked
  8.       NoWaterFlow: false
  9.       Worlds:
  10.       - world
复制代码

把NoLavaFlow和NoWaterFlow都设置成false
