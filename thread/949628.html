# 前言

本人开了一个生存服，用BungeeCord将多个服务端串在一起，一个服务端单独跑一个世界达成所谓的
"BC式负载均衡解决方案"。那么问题来了，服务器在有生存服、资源服、地皮服的情况下，如何让在资源服的玩家输入/p home 回到地皮？那么肯定有人要说:"直接/server dp，然后再/p home不就行啦?"。那你不觉得太low了吗？玩家不会觉得太麻烦吗？



# 插件功能

本插件就是为了解决跨服玩家输入 /p home 回到地皮而生。玩家在不同服务端输入/p home 均可回到地皮服，输入/p auto可以自动领取地皮。



# 插件原理

在Bc端拦截玩家/p home(/p auto)指令,再由BC为玩家执行/server dp,再延时执行/p home



# 插件须知

在使用插件之前，务必将BungeeCord的配置文件中的地皮服的名字改为dp，否则插件不会生效。有反编译能力的老哥可以自行调整。代码不精，还望见谅。

已更新



# 插件安装

在地皮服装有
PlotSquared插件的前提下，将本插件丢到Bungeecord的plugin文件夹目录下面重启BC端即可
