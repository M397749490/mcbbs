楼主，如果装有多世界插件的话必须每个世界输入
/gamerule keepInventory true
这个是更改游戏规则
把死亡掉落更改为死亡不掉落
比如说你只有三个世界 world 地狱 末地
你每个世界都去一次
然后都输入一次
/gamerule keepInventory true
即可
如果创建新世界的话也需要输入
/gamerule keepInventory true
