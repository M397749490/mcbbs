星球探索者（Planet Explorer）背景为一个遥远的星球上，是一款开放式的，集冒险与角色扮演于一体的像素风格沙盒类游戏。这个游戏采用了基于Unity 3D引擎的新开放运算语言系统（OpenCL），能让玩家在任何地方，改变任何地形，创造任何形态的事物。
星球探险家的时间设定为2287年，从地球派出的第一批殖民舰队中的一艘飞船抵达位于印地安座ε星系（Epsilon Indi Star System）的玛丽亚（Maria）行星。在登陆的过程中，巨舰面前出现某物使得飞船失去控制并坠落到星球上。一些殖民者凭借救生艇逃生，但他们发现这片蛮荒之地上充斥着各种试图淘汰地球访客们的生物。现在，这些幸存者必须探索未知之地、收集资源、建设殖民地、生产、战斗并最终征服这片土地。
游戏可以在第三和第一视觉间转换。玩家可以定制自己的角色，组合、创作武器、载具和建筑。同时，玩家必须对抗大量不同智慧程度的敌人并保护幸存的殖民者们。游戏里还会有任务系统，玩家达成npc给予的任务来推动剧情发展。除了单人剧情，还会有随机的单人和多人探险地图。多人游戏会有显著的体现，我们以后会谈到想要添加的游戏模式。

Q&A
Q: This is a voxel game?
A: Yep, believe it or not, voxel does not mean box shaped. Remember Outcast from the late 90s? That was also voxel based. The Cryengine uses voxels to a certain extent as well. The voxel algorithms we're using take more power to calculate than the box form voxels, that's the reason there aren't too many of this type around, yet.
Q：这（尼玛）是像素游戏？
A：嗯，信不信由你，像素并不意味着格子式画面。还记得90年代末期的《放逐者》（Outcast）么？那同样也是像素游戏。Cryengine（一款游戏引擎）也是将像素发挥到某种程度。我们使用的像素算法比格子式的像素要费力得多，这也是为什么这种像素不常见的原因。
Q: What are you trying to achieve with this game?
A: In this game, we're aiming for total freedom for the player (or as much as the hardware limitations at the time of completion allows), which means, the player can build almost anything, weapons, vehicles, etc. On top of that, we will have a story driven adventure to give the player goals to use their creativity to achieve. And if we make money in the process, that's cool too.
Q：你们想通过这个游戏得到什么？
A：我们希望这个游戏能赋予玩家完全的自由（或者说只要硬件允许，怎样打穿这个游戏都行）。这就意味着，玩家可以创造任何事物，武器、载具等等。如果我们能在这个过程中赚钱，也是件很酷的事。
Q: So what if I just goof off and build stuff in game?
A: That's fine with us, the player doesn't have to follow the storyline at all.
Q：要是我就只在游戏里造造东西打发时间呢？
A：那也无所谓，玩家并不需要按着剧情来。
Q: Is this going to have procedurally generated landscapes?
A: No. We'll have a 12X24km continent. Everything will be set so that there will be landmarks. The multiplayer portions of the game will probably feature small procedural landscapes though.
Q：会有程序产生的地形么？（汗一个，应该是随即地形之类的吧。）
A：不，我们会作一个12X24km大小的大陆。所有地形都会固定下来，这样就会有地标。当然，多人游戏里还是会有小型的随机地形。
Q: What platform is this form?
A: So far, only for Windows PC. Probably Mac too at some point.
Q：游戏会登陆哪些平台？
A：目前，只针对Windows个人电脑。以后可能会兼容Mac。
Q: This sounds like a lot of stuff, can my computer even run it?
A: As long as you have a dual core processor and a graphics card that has DX10.1 or above, you should be able to run it (that's what OpenCL requires). We would recommend gt240 or equivalent or above and 3GB of ram is going to be required.
Q：游戏看起来内容很丰富啊。我的电脑跑得动么？
A：只要你的电脑是双核处理器并且显卡支持DX10.1及以上，你就可以玩（这是OpenCL的配置需求）。我们推荐3g内存，gt240或者更高。
Q: Sounds good, when will this be out?
A: It's out in alpha form right now for free, play it now! We'll start charging for this game only when we feel like there is enough content to make it worthwhile
Q：看上去不错，什么时候发售？
A：目前放出的是免费的alpha版，可以玩啦！只有当我们觉得游戏内容完善的时候我们才会收费。
