插件目录中BedWarsRel文件夹中
config.yml中找到# 玩家死亡时背包物品掉落
# 类型: boolean
# true 启用
# false 禁用
player-drops: false


将上面的false改为true 即变为:


player-drops: true

请注意: ....-dorps:后面有一个空格 然后是true
