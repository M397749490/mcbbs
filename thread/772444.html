插件介绍
本插件可以给你的服务器添加完全自定义的箭矢，你可以给箭矢添加完全自定义的粒子效果，伤害，或者各种丰富的技能（给敌人添加debuff，治愈队友，偷取 生命，造成爆炸，无视重力等等）

箭矢“地震之箭”效果


玩家可以在菜单内购买各种箭矢


这些带名字的箭都是预设的，你可以制作完全自定义的新品种箭


安装&技能
  • 使用该插件前需要安装一个前置AgarthaLib（仅付费版需要），该前置插件在原帖和插件本体一起打包提供下载，故不在帖内放出
  • 当玩家背包内有多种箭矢时，按住Shift并滚动鼠标滚轮可以切换当前箭矢使用

制作箭矢范例

  1. EternalFlame:
  2.   Name: "&b<< &c火焰之箭 &b>>"
  3.   # 除了箭矢原版的伤害外的额外伤害
  4.   Damage: 1.2
  5.   # 玩家购买价格
  6.   Price: 25
  7.   # 箭矢的种类，Tipped_Arrow是药箭
  8.   Type: "Tipped_Arrow"
  9.   # 药箭的颜色
  10.   Color: "Maroon"
  11.   # 箭命中目标时出现的粒子效果
  12.   Trail_Particle: "Flame"
  13.   # 技能属性
  14.   Attributes:
  15.   - "Flame"
  16.   - "Ignite"
  17.   # 属性的设置值，Ignite的Duration设置为72000代表箭矢的点燃效果可以持续72000tick
  18.   Options:
  19.     Ignite:
  20.       Duration: 72000
  21.   # 箭矢描述   
  22.   Description:
  23.   - "&f&o永远的燃烧"
  24.   # 箭矢的lore
  25.   Lores:
  26.   - "&2额外伤害&f&l: &c1.2"
  27.   - "&2效果&f&l:"
  28.   - "&2+ &a火焰之箭"
  29.   - "&2+ &a长时间点燃敌人"

指令&权限
  • /ca help - 插件帮助
  • /ca about - 插件信息
  • /ca menu - 打开自定义箭矢菜单
  • /ca list - 列出箭矢列表
  • /ca shoot <箭矢名称> [玩家名] [射速] - 强制让某玩家射出箭
  • /ca load <箭矢名称> [玩家名] [数量] - 让玩家获得箭
  • /ca reload - 重载插件
  • 出现指令冲突可以用/arrow代替/ca

本插件没有任何权限需要给玩家，但是可以设置玩家必须要有某个权限才能购买某种箭
