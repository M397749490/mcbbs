  1. gamerule gameLoopFucntion a:b

  3. a\b.mcfunction:
  4. summon area_effect_cloud ~ ~ ~ {Tags:["marker"]}
  5. tp @e[tag=marker] 0 0 0
  6. function a:c
  7. function a:d
  8. function a:e

  10. a\c.mcfunction:
  11. tp @e[tag=marker] ~1 ~ ~
  12. scoreboard players add @e[tag=pos,score_X=-1] X 1
  13. scoreboard players remove @e[tag=pos,score_X_min=1] X 1
  14. function a:c unless @e[tag=pos,score_X_min=0,score_X=0]

  16. a\d.mcfunction:
  17. tp @e[tag=marker] ~ ~1 ~
  18. scoreboard players add @e[tag=pos,score_Y=-1] Y 1
  19. scoreboard players remove @e[tag=pos,score_Y_min=1] Y 1
  20. function a:d unless @e[tag=pos,score_Y_min=0,score_Y=0]

  22. a\e.mcfunction:
  23. tp @e[tag=marker] ~ ~ ~1
  24. scoreboard players add @e[tag=pos,score_Z=-1] Z 1
  25. scoreboard players remove @e[tag=pos,score_Z_min=1] Z 1
  26. function a:e unless @e[tag=pos,score_Z_min=0,score_Z=0]

  28. a\b.mcfunction续:
  29. summon area_effect_cloud ~ ~ ~ {Tags:["pos2"]}
  30. scoreboard players set @e[tag=pos2] X 9
  31. scoreboard players set @e[tag=pos2] Y 19
  32. scoreboard players set @e[tag=pos2] Z 29
  33. function a:f
  34. function a:g
  35. function a:h

  37. a\f.mcfunction：
  38. execute @e[tag=pos] ~1 ~ ~ function a:i unless @e[tag=pos,r=1]
  39. a\i.mcfunction：
  40. summon area_effect_cloud ~ ~ ~ {Tags:["pos"]}
  41. a\f.mcfuntion续：
  42. scoreboard players remove @e[tag=pos2] X 1
  43. function a:f if @e[tag=pos2,score_X_min=1]

  45. a\g.mcfunction：
  46. execute @e[tag=pos] ~ ~1 ~ function a:i unless @e[tag=pos,r=1]
  47. scoreboard players remove @e[tag=pos2] Y 1
  48. function a:g if @e[tag=pos2,score_Y_min=1]

  50. a\h.mcfunction

  52. scoreboard players remove @e[tag=pos2] Z 1
