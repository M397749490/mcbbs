作者: AzureHanChen    时间: 2019-10-27 14:08
可使用DeluxeMenus优先级实现此功能
具体代码见下(Spigot1.12.2,DeluxeMenus1.12.0)
  1. menu_title: '&e称号菜单'
  2. size: 54
  3. update_interval: 5
  4. items:
  5.   owner-have:
  6.     slot: 0
  7.     priority: 1
  8.     view_requirement:
  9.       requirements:
  10.         haspermission:
  11.           type: has permission
  12.           permission: 'user.suffix.owner'
  13.     material: COAL
  14.     display_name: '&eOwner? &a&o(后辍)'
  15.     update: true
  16.     lore:
  17.     - ''
  18.     - '&f服主尊享的称号'
  19.     - ''
  20.     - '&f称号 &7| &eOwner?'
  21.     - '&f属性 &7| &a&o后缀'
  22.     - ''
  23.     - '&a? &e单击切换'
  24.     left_click_commands:
  25.     - '[close]'
  26.     - '[console] lp user %player_name% meta setsuffix &eOwner?'
  27.     right_click_commands:
  28.     - '[close]'
  29.     - '[console] lp user %player_name% meta setsuffix &eOwner?'
  30.   owner-no:
  31.     slot: 12
  32.     priority: 2
  33.     material: BARRIER
  34.     display_name: '&eOwner? &a&o(后辍)'
  35.     update: true
  36.     lore:
  37.     - ''
  38.     - '&f服主尊享的称号'
  39.     - ''
  40.     - '&f称号 &7| &eOwner?'
  41.     - '&f属性 &7| &a&o后缀'
  42.     - ''
  43.     - '&c? 您没有此称号'
复制代码

此处我使用的是LuckPerms插件,使用Vault更改后缀
所以你需要在能使用PAPI(PlaceholderAPI)变量的地方使用%vault_suffix%,就能看到称号了
