预发布版是Minecraft Java版的测试机制，如果该版本作为正式版发布，那么预发布版的游戏文件将与启动器推送的正式版完全相同。
然而，预发布版主要用于服主和Mod制作者的预先体验，如果发现重大漏洞，该预发布版会被新的预发布版代替。因此建议普通玩家持观望态度。
Minecraft 1.14.2 仍未发布，1.14.2 Pre-Release 3 为其第 3 个预览版。
转载本贴时须要注明原作者以及本帖地址。




Minecraft 1.14.2 Pre-Release 3


CHANGES IN 1.14.2 PRE-RELEASE 3
1.14.2 PRE-RELEASE 3的更改

  • Fixed a couple of bugs
  • 修复几个BUG
  • Errors encountered while loading regions now print more diagnostics to the log file
  • 现在加载存档时若遇到错误会向日志文件中输出更多诊断信息

FIXED BUGS IN 1.14.2 PRE-RELEASE 3
1.14.2 PRE-RELEASE 3 修复的BUG

  • MC-142134 - Light sources spontaneously not working in some chunks
  • MC-142134 - 光源在某些区块内不发光
  • MC-147715 - Entities clip through blocks after travelling through an end gateway
  • MC-147715 - 实体会在通过末地折跃门后卡在方块中窒息
  • MC-148933 - You cannot swim while sneaking
  • MC-148933 - 潜行时不可以游泳
  • MC-149111 - When hovering over a world that needs to be updated, the game calls the current version a snapshot even if it is a release
  • MC-149111 - 已经是正式版的游戏把自己当成了快照版本（单人存档界面在旧版本的存档上提示“在使用此快照打开前，不要忘记先备份该存档”）
  • MC-149916 - Teleporting long distances on servers causes you to clip into the ground
  • MC-149916 - 在服务器中远距离传送会使玩家卡在方块中
  • MC-152272 - Server stops responding after log out error
  • MC-152272 - 玩家断开时出错会导致服务器停止（无响应）

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。Java版的启动器下载地址在上文已经提供。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
