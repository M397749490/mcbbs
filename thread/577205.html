一.基础信息(插件的信息与介绍)

目前此插件支持 1.5.2 1.6.2 1.7.2 1.9

插件原帖:seeplayerinventory


seeplayerinventory

打开一个玩家的背包
添加/删除一个玩家的物品
修改玩家的末影箱
使用一种简单的方法来寻找非法物品
让玩家请求看到其他玩家的背包

三.指令和权限(必须要看)
指令(Commands) 权限(Permission) 介绍(Description)
/spi ? seeplayerinventory.use.help 显示插件的帮助
/spi open inv <player> seeplayerinventory.use.open.inv 打开某玩家的背包[可编辑]
/spi open ec <player> seeplayerinventory.use.open.enderchest 打开某玩家的末影箱[可编辑]
/spi see inv <player> seeseeplayerinventory.use.see.inv 查看某玩家的背包[不可编辑]
/spi see ec <player> seeplayerinventory.use.see.enderchest 查看某玩家的末影箱[不可编辑]
/spi see chest seeplayerinventory.use.see.chest 查看准心面对的箱子[不可编辑]
/spi see request <player> seeplayerinventory.use.see.request 向某玩家发出查看背包请求
/spi see request <accept/decline> <player> seeplayerinventory.use.see.request 接受/拒绝某玩家发送的请求
/spi target seeplayerinventory.use.target target指令帮助
/spi target inv seeplayerinventory.use.target.inv 获取一根[道具]棒子(右键打开玩家背包,可编辑)
/spi target ec seeplayerinventory.use.target.enderchest 获取一根[道具]棒子(右键打开玩家末影箱,可编辑)
/spi menu seeplayerinventory.use.menu 打开玩家菜单
/spi reload seeplayerinventory.use.reload 重载插件
seeplayerinventory.admin 所有指令权限
seeplayerinventory.use.open 打开指令权限
seeplayerinventory.use.see 查看指令权限
seeplayerinventory.checkupdates 自动更新权限


四.插件更新日志
Version 1.6
英文
+ Added inventory see requests.
+ Compatibility with CraftBukkit 1.9.
+ Add Commands:
╠ /spi see request <player>
╠ /spi see request accept <player>
╠ /spi see request decline<player>
! Changed the way to edit a inventory works, now you can edit the armor and the off hand slot, you can even drop items in front of the player.
! Changed the menu skulls so that now the player skin appers instance of the steve skull
* Fixed the error with the View ender chest menu.
* Fixed an error where when a user was viewing another user enderchest/inv he could put items in.


中文
+ 添加请求查看某玩家的物品.
+ 兼容CraftBukkit 1.9.
+ 添加指令:
╠ /spi see request <player>
╠ /spi see request accept <player>
╠ /spi see request decline<player>
! 修改编辑模式,允许编辑玩家的装备栏和手槽(背包的最底下9个格子).
! 修改菜单里的玩家头颅,使玩家的头颅更像史蒂夫的.
* 玩家查看他人背包,可能有点误差.
* 当一个玩家查看另一个玩家的背包/末影箱时,可以给他物品.

Version 1.5
英文
+ Target mode.
+ Add Inventory View Mode and Chet View Mode.
+ Add Inventory View Mode in the inv menu.
+ Compatibility with CraftBukkit 1.7.2 R0.2.
+ Add Commands:
╠ /spi target
╠ /spi target <inv/ec>
╠ /spi see <inv/ec> <Player>
╠ /spi see chest
! Changed the command "/spi open <player>" and "/spi ec <player>" to "/spi open <inv/ec> <player>".
* Fix some little errors.


中文

+ 添加指令:
╠ /spi target

╠ /spi see <inv/ec> <Player>
