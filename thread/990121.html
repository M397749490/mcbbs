Minecraft Server Remote

服务器远程控制

只要安装这个简单的插件，您就可以使用Android应用程序便捷地远程控制服务器。

功能
  • 查看系统运行状况（CPU使用情况，RAM使用情况）
  • 查看在线玩家并通过单击按钮来踢出玩家、封禁或给与OP
  • 一个功能齐全的控制台
  • 登录日志
  • 权限系统（如果添加新用户，他将默认获得所有权限。如果您需要的话，请使用remove命令将其移除）


使用步骤
  • 关闭服务器
  • 将下载的插件保存在“ plugins”文件夹中
  • 重新启动服务器
  • 您可以使用该命令创建新用户：“ msr register <用户名> <密码>“
  • 您应确保服务器端口5718是开放状态（您也可以在配置文件中对端口进行更改）。
  • 现在，您就可以使用服务器的IP和您在步骤3中创建的用户名和密码登录APP进行远程访问了


相关指令
注意：在控制台中运行命令时，无需键入“ / ”
  • 注册新用户：/msr register <用户名> <密码>
  • 删除现有用户：/msr delete <用户名>
  • 向用户添加权限：/msr permission add <用户名> <权限名>
  • 从用户删除权限：/msr permission remove <用户名> <权限名>
  • 显示帮助：/msr help


权限名
  • kick（允许使用“kick”按钮）
  • ban（允许使用“ban”按钮）
  • op（允许使用“op”按钮）
  • console（允许访问控制台）
  • log（允许访问日志）
  • all（允许上述所有权限）
