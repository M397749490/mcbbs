这次呢我为大家带来了可以打颜色字体的新人书的插件

接下来是原帖搬运时间（中文的）：

介绍：

新人书是Bukkit上一个只有一个用途的简单插件.在玩家第一次登录的时候，你可以给他一本写好了的新人书.在填写这些内容的时候可以使用命令来增加, 比如怎么获得VIP或者一些新人必知的东西.玩家只能获得新人书一次(你可以给更多前提是你是op)而且书的内容可以通过config来改变


重要的消息：

  ● 书的每一页只有14行

  ● 每行只能打19个字符（每个中文算两个标点符号或英文算一个）

  ● 可以用彩色字体哦~{:10_512:}

  ● 如果要换行就用&x符号

命令：

命令                                                                  权限                               作用

infobook reloadinfobook.reload重载插件
infobook get <book>infobook.get获得名叫<book>的书，前提是在config中有设置过
infobook save <book>infobook.save把你手中的书作为<book>并且将内容保存在config中
infobook delete <book>infobook.delete从config中删除<book>
infobook give <player> <book>infobook.give给<player><book>

config设置：

# 新人书

# 插件在有新版本时是否在启动服务器时提醒
version-check: false

# 所有以下权限组的玩家在第一次登陆时会获得这本书
onlogin:
  - default

# 所有以下权限组的玩家无法把新人书扔出去
protected:
  - default

# 书的各项内容
default:
  author: Server
  title: Informations
  description:
    - First line
    - Second line
  pages:
    - '&cInformation book &x &x&0Here you &xcan put &xinformations.'
    - 'Second page of our book.'
