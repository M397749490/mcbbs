[ 必要准备 ]


1. 在 .minecraft/scripts下新建一个 TXT 文本文档，随便脸滚键盘输入一串字母作为文件名，然后将后缀改为 zs。

2. 打开文件，第一行输入
  1. import mods.roots.Pyre;
复制代码


3. 接下来输入

  2. Pyre.addRecipe("string name",
  3. IItemStack output,
  4. IIngredient[] inputs,
  5. int xp);
复制代码


将
  1. string name
复制代码
换成一串字母，就是你的配方名称；

  1. IItemStack output
复制代码
换成烧烤得到的产物的名称，例如

  1. <skewers:skewer_beef_cooked>*5
复制代码
是五个牛肉烤串，

  1. <skewers:skewer_porkchop_cooked>
复制代码
是一个猪肉烤串。

将
  1. IIngredient[] inputs
复制代码
换成五个物品名称，也就是你用来烤制的物品。

例如五个生猪肉串：

  1. <skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>
复制代码

  2. int xp
复制代码
换成一个整数，表示你烤制完成后会获得多少级经验。如果不希望有经验产出，直接把这一项删掉。

保存文件，重启游戏，测试一下效果吧。





[ 示例脚本 ]


使用方法：按照上述教程第一步的方法新建一个 ZS 文件，把下面的内容复制粘贴进去保存，重启游戏即可。

  2. import mods.roots.Pyre;

  4. Pyre.addRecipe(

  6.     "cooked_salmon",

  8.     <minecraft:cooked_fish:1>*5,

  10.     [<minecraft:fish:1>,<minecraft:fish:1>,<minecraft:fish:1>,<minecraft:fish:1>,<minecraft:fish:1>]

  12. );

  14. //以上代码修复了根源魔法的柴堆烤鲑鱼5换1的问题

  16. Pyre.addRecipe(

  18.     "SkewerPork",

  20.     <skewers:skewer_porkchop_cooked>*5,

  22.     [<skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>,<skewers:skewer_porkchop_raw>]

  24. );

  26. //添加了烤制猪肉烤串的配方
