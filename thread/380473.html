/mangadd xxx ＝ 创建一个叫做xxx的用户组 　　/mangdel xxx ＝ 删除xxx用户组 　　/manglistp xxx ＝ 列出xxx用户组的权限 　　/mangaddp xxx yyy ＝ 给用户组xxx添加yyy权限 　　/mangdelp xxx yyy ＝ 删除用户组xxx的yyy权限 　　/mangaddv xxx prefix yyy ＝ 给用户组xxx添加yyy的前缀 　　（举例/mangaddv admin prefix &f[&c造物者&f]&c给admin组添加了[红色造物者]的前缀） 　　/mangaddi xxx yyy ＝ 让用户组xxx继承yyy的权限（能够为权限设置剩下不少费事） 　　/manuadd xxx yyy ＝ 将玩家xxx放进用户组yyy 　　/manuaddp xxx yyy ＝ 给用户xxx添加yyy权限

作者: 筒子    时间: 2015-1-2 13:52
首先
我给你写一下指令流程吧
/mangadd 权限组    -创建一个权限组
/mangaddi 权限组 default     -继承所有的基础权限
/mangaddp 权限组 <权限节点如：essentials.fly>      -添加组的权限
/mangaddv 权限组 prefix &eVIP   -添加组的前置称号
/mangaddv 权限组 suffix &eVIP   -添加组的后置称号
/mangaddv 权限组 build true     -开启权限组
这些是完整的创建权限组指令
其次那些一进入没有权限的
你在Group Manager生成的配置文件里面
修改group.yml
groups:
  Default:
    default: true     把这个换成false
    permissions:
    - essentials.help
    -essentials.help.*
    --essentials.help.factions
    -essentials.helpop
    -essentials.list
    -essentials.motd
    -essentials.rules
    -essentials.spawn
    -essentials.eco
    inheritance: []
    info:
      prefix:'&e'
      build: false
      suffix: ''
  Builder:
    default: false   把这个换成true
    permissions:
    -essentials.home
    - essentials.me
    -essentials.msg
    -essentials.sethome
    -essentials.warp
    inheritance:
    - default
    info:
      prefix:'&2'
      build: true
      suffix: ''

这样设置就可以让新玩家一进入服务器就有权限了
