想让盔甲架持续面朝某一实体貌似也不行额

盔甲架的竖直朝向虽然没被渲染 但是还是有的
所以你只要先将盔甲架面朝相应的实体teleport一下
然后再把Rotation[1]的值附给Pose.Head[0]就可以了
比如说
  1. execute as @e[type=minecraft:armor_stand] at @s facing entity @p feet run teleport @s ~ ~ ~ ~ ~
  2. execute as @e[type=minecraft:armor_stand] run data modify entity @s Pose.Head[0] set from entity @s Rotation[1]
