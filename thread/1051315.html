原版模组 幸运方块 Lucky Block

一些废话



        最近闲的没事情干，所以制作了这个数据包。我本来不打算把它发布出来的，但是我找遍整个论坛159个原版模组，都没有幸运方块。于是我就把它发布出来了。目前这个原版模组仍然在测试阶段（明明看版本号就知道了），功能还比较少。我制作了四天之后，终于发布了Alpha0.1版本。

        幸运方块的获得方式：
                1.寻找世界中天然形成的幸运方块。幸运方块只会天然生成在现世（亦称主世界）y<=96的地表，每2X2个区块有10%的几率生成1个幸运方块。

2020-05-30_12.42.58.png (457.76 KB, 下载次数: 5)

                2.通过合成器合成幸运方块（中间的是投掷器）。


                注：合成器合成方式见下图。注意，这里是无序合成。


3.管理员可以通过执行命令 /loot give @s loot lucky_block:lucky_block 来获取幸运方块。

注意事项


        1.本原版模组需要前置 战利品表随机数  方块通用处理  合成通用处理。
        2.本原版模组的CustomModelData使用范围为16210000。
        3.幸运方块原型为石头。
        4.本原版模组理论上适用于 1.14.X、1.15.X、1.16，但是由于本模组使用的 战利品表随机数 前置只适用于 1.16，所以本模组只适用于 1.16 版本。
        5.合成器不是本原版模组添加的。
        6.本原版模组的幸运方块只有40种效果，如果你有什么建议，请在评论区回复。
        7.如果发现有任何bug，请在评论区回复。
        8.如果想要看到本模组的更新，请收藏本模组。
        9.本模组命名空间为lucky_block。
        10.本模组使用的记分板为LB。

致原版模组开发者



        如果你是一个原版模组开发者，并想要向幸运方块添加新的效果，请仔细阅读本条。

        首先，请在函数标签 #lucky_block:events_add 里添加函数，格式为
  1. scoreboard players add $events LB [你想要添加效果的数量]
复制代码
        然后再在函数标签 #lucky_block:events 里添加函数，格式为
  1. execute if score #result random = [目标选择器/玩家名] [记分板] run [你想要执行的效果1]
  2. execute if score #result random = [目标选择器/玩家名] [记分板] run [你想要执行的效果2]
  3. execute if score #result random = [目标选择器/玩家名] [记分板] run [你想要执行的效果3]
  4. ......
  5. execute if score #result random = [目标选择器/玩家名] [记分板] run [你想要执行的效果n]
复制代码
        请确保 [目标选择器/玩家名] [计分板] 的值大于40，因为本模组使用了1-40的效果。
        然后在生存模式下破坏幸运方块，看看有没有你添加的效果吧！
        定义幸运剑的效果时，在函数标签 #lucky_block:sword_events_add 里添加函数，格式为
  1. scoreboard players add $sword_events LB [你想要添加效果的数量]

  1. execute if score #result random = [目标选择器/玩家名] [记分板] run [你想要执行的效果1]
