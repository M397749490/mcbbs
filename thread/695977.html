★插件介绍★

本插件可以给你的玩家提供一个悬空显示的全息GUI菜单界面，玩家用鼠标点击相应全息内容可以出现一系列效果，例如执行指令，出现提示语，打开其它菜单等等，可以让你的服务器更加与众不同！

★安装方法★

下载本插件，扔进plugins文件夹，重启服务器

这个插件不要安装上不配置就用！默认全息菜单中有个切换玩家游戏模式的开关，可以无视权限修改玩家游戏模式！请一定要记得先配置！


本插件需要3个前置插件

  • 前置插件1：ProtocolLib
1.8版本服务器请使用v3.6.5版本前置，1.9+服务器请使用v4.x以上版本前置 站内下载

  • 前置插件2：HoloGUIApi
作者开发的一款API插件 外网下载

  • 前置插件3：PlaceholderAPI
和全息显示的某些变量有关 外网下载 PAPI变量大全


★指令&权限★

/hg help 查看指令帮助

以下指令需要权限hg.admin

/hg reloadconfig 重载插件config
/hg guipagelist <页> 查看都有哪些全息GUI页


以下指令需要权限hg.see（这个权限可以给玩家）

/hg open <GUI页面名>  打开指定的GUI
/hg close 关闭页面
/hg back 返回上一个页面

【②按钮button】
按钮指的是可以点击的图片
请把图片文件放到plugins/HoloGUI/images文件夹
将点击指令设置为/hg open <菜单名> 可点击打开其它菜单


  1.     # 按钮的ID 不要重复  
  2.     example-btn:
  3.       # 按钮的种类 button是可点击按钮
  4.       type: button
  5.       # 按钮的标签文字 会显示在按钮图片的上方
  6.       label: 这是一个按钮
  7.       # 这些文字距离按钮有多少格远，可设置范围5-20
  8.       # 默认距离：按钮15 物品6 生物8 文字10
  9.       label-distance: 6
  10.       # 当这个按钮被鼠标指向了，按钮的标签会变大多少呢（可设置范围0-6 默认4）
  11.       label-zoom-distance: 4
  12.       # 这个按钮的标签将会一直显示，而不是鼠标指向才显示（默认false）
  13.       always-show-label: false
  14.       # 按钮的图片，可以是jpg png gif动图 请把图片文件放到plugins/HoloGUI/images文件夹
  15.       icon: example.png
  16.       # 这个按钮是不是迷你小按钮？普通按钮：18x18像素 迷你按钮：9x9像素 默认false
  17.       mini: false
  18.       # 玩家点击这个按钮执行的指令 可以添加PAPI变量
  19.       onclick: "say %player_name% 你点了这个按钮!"
  20.       # 这个指令是由控制台执行的吗（默认false 由玩家执行）
  21.       execute-command-as-console: true
  22.       # 点击这个按钮发出的声音 默认无声音 需要注意的是1.8和1.9+服务器音效名称不同
  23.       onclick-sound: UI_BUTTON_CLICK
  24.       # 按钮点击声音大小 0是静音 1是大声 默认0.5
  25.       onclick-sound-volume: 0.7
  26.       # 这个按钮图片是对称的吗（某些对称图片的部分瑕疵可能导致生成的按钮不对称）默认false
  27.       symmetrical: false
  28.       # 点击此按钮需要的权限 默认无权限
  29.       click-pemission: "example.permission"
  30.       # 无权限的提示语
  31.       no-permission-message: "&c你没有权限点击这个!"
  32.       # 位置
  33.       position:
  34.         x: -0.3
  35.         y: -0.1

【⑥可切换开关toggle-switch】
这是一种特殊的按钮，它有两个状态：开/关
开和关的按钮图片不同，点击这个按钮可以在两个状态中切换
（警告：默认的主菜单的这个按钮 [下图↓↓↓]，玩家点击了可以无视权限切换游戏模式！所以插件一定要先配置再使用！）


  1.     # 按钮的ID 不要重复         
  2.     example-toggle-btn:
  3.           # 按钮的种类 toggle-switch是可切换开关
  4.       type: toggle-switch
  5.           # 按钮的标签 其中当前变量使用%按钮ID_value%表示
  6.       label: "&l游戏模式: &4&l%example-toggle-btn_value%"
  7.           # 这个开关的标签将会一直显示，而不是鼠标指向才显示（默认false）
  8.       always-show-label: true
  9.           # 这个开关的默认值？
  10.       value: false
  11.           # 当开关为"开"的时候 开关显示的图片
  12.       icon-on: default-toggle-on.png
  13.           # 当开关为"开"的时候 开关标签中%按钮ID_value%显示的内容
  14.       on-value: 创造模式
  15.           # 当开关变为"开"的时候 执行的指令
  16.       onclick-on: gamemode 1 %player_name%
  17.           # 这个指令是在控制台执行的？
  18.       execute-onclick-on-as-console: true
  19.           # 以下四行是当开关为"关"的时候的各种状态
  20.       icon-off: default-toggle-off.png
  21.       off-value: 生存模式            
  22.       onclick-off: gamemode 0 %player_name%
  23.       execute-onclick-off-as-console: true
  24.       # 点击这个按钮发出的声音 默认无声音 需要注意的是1.8和1.9+服务器音效名称不同
  25.       onclick-sound: UI_BUTTON_CLICK
  26.       # 点击此按钮需要的权限 默认无权限
  27.       click-pemission: "example.permission"
  28.           # 无权限的提示语

【⑧鼠标滚轮value-scroller】
可以用鼠标滚轮在一个确定范围内滚动选择一个值（用处不明 毫无用处？）


  1.     # 按钮的ID 不要重复     
  2.     value-scroller-example:
  3.       # 按钮的种类 value-scroller是鼠标滚轮
  4.       type: value-scroller
  5.       # 这个按钮的标签将会一直显示，而不是鼠标指向才显示（默认false）
  6.       always-show-label: true
  7.       # 按钮的标签
  8.       label: "&l数值: %value-scroller-exmaple_value%"
  9.       # 默认值
  10.       default-value: 10
  11.       # 可滚动最小值
  12.       min-value: 0
  13.       # 可滚动最大值
  14.       max-value: 20  
  15.       # 显示数值的格式
  16.       decimal-format: "#.##"  
  17.       # 玩家每次鼠标滚动 数值变化多少
  18.       step: 1  
  19.       # 鼠标滚动时的声音和音量
  20.       onscroll-sound: "BLOCK_LAVA_POP"
  21.       onscroll-sound-volume: 0.1
