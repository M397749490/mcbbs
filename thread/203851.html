以下帮助信息备份
  1. Commands /rpgitem/rpgitem help 分类[字符]显示指令帮助, 或搜索指定 [分类] 下的指令帮助
  2. /rpgitem [物品]在聊天框中显示 [物品] 属性
  3. /rpgitem 物品名[字符] create创建物品. 这个 [名字] 只是用于编辑指令调用它, 并非显示在游戏中物品 [展示名], 你需要用display指令进行更改
  4. /rpgitem [物品] armour 护甲[整数值(0-100)]给 [物品] 设置 [护甲值] (关于装备护甲请参考WIKI相关资料)
  5. /rpgitem [物品] armour显示 [物品] 护甲值 (关于装备护甲请参考WIKI相关资料)

  8. /rpgitem [物品] damage显示 [物品] 当前伤害
  9. /rpgitem [物品] description set 行[整数值] 描述行[字符]给 [物品] 的 [指定行] 添加 [描述文字]

  11. /rpgitem [物品] description add 描述行[字符]给 [物品] 增加 [描述文字]

作者: akeicon    时间: 2014-3-7 11:35
本帖最后由 akeicon 于 2014-3-7 11:40 编辑

插件指令查询里面少了设置耐久的指令的汉化，对应的指令是/rpgitem [物品] durability [耐久]

除此之外还有两条相关指令不是太明白，这里的这条指令使用过后道具本体会生成一个耐久状态栏，和物品本身的耐久显示栏没有任何关系，使用物品之后会消耗的是耐久状态栏里的耐久，消耗到全红装备就会消失。且似乎目前无法使用常规手段修复它。
