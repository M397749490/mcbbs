让你的服务器掉落物品显示你自定义的名字！

插件介绍


此插件可以掉落物品显示全息名称，支持自定义！

可以自己设置玩家多远能看到掉落物名字

支持颜色代码，资源占用不多。

插件配置文件

  1. ###COLOR CODING - Default Minecraft color coding.
  2. #&0 - Black
  3. #&1 - Dark Blue
  4. #&2 - Dark Green
  5. #&3 - Dark Aqua
  6. #&4 - Dark Red
  7. #&5 - Purple
  8. #&6 - Gold
  9. #&7 - Gray
  10. #&8 - Dark Gray
  11. #&9 - Blue
  12. #&a - Green
  13. #&b - Aqua
  14. #&c - Red
  15. #&d - Pink
  16. #&e - Yellow
  17. #&f - White
  18. #&r - Reset
  19. #&l - Bold
  20. #&m - Strikethrough
  21. #&n - Underlined
  22. #&o - Italic

  24. #The color that the amount should be written in the drop name.
  25. Amount Color: "&6"

  27. #Maximum distance any player has to be from the drop for its name to be visible. The higher this number is, the more the plugin might slow down the server.
  28. Maximum Distance: 32.0

  30. #How often the drops should be checking for nearby players (in ticks). Warning: Setting this to a number below 5 might cause lag!
  31. Update Timer: 40

  33. #Any drop listed below will have its name changed to the written value. A list of the available items can be found here -> https://helpch.at/docs/<MC VERSION>/index.html?org/bukkit/Material.html
  34. #In a future update, durability textures will be supported.
  35. Custom Names:
  36.   ENCHANTED_GOLDEN_APPLE: "&dEnchanted Golden Apple"
  37.   ENCHANTED_BOOK: "&eEnchanted Book"
  38.   DIAMOND: "&bDiamond"
复制代码
Custom Names处支持自定义，格式：文字ID：“自定义文字”

搬运者寄语：可以拿来做一些骚名字或者其他好玩的东西，就看各位腐竹的脑洞了。
