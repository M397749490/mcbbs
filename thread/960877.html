插件文件夹内各个文件的介绍


插件在服务器上运行一次后，插件文件夹将出现在plugins文件夹中。此文件夹将包含以下文件和文件夹：
  • effects/
  • locale/
  • styles/
  • config.yml
  • playerparticles.db
  • preset_groups.yml

现在详细讲解各个文件夹的作用：
config.yml

config.yml是配置PlayerParticles插件的地方，如果您的服务器配置不是那么优秀，那么请手动配置此文件，而不是使用原版配置。
config.yml有插件的主体配置部分和数据库部分，插件支持2种数据库：
1.插件自带的sqlite数据库      sqlite您可以不用配置，插件自己生成数据库。             
2.mysql数据库                     需要手动配置。
插件自带的sqlite只能用于单个服务器。非插件自带的mysql可用于bc群组服。

preset_groups.yml
设置用户权限的地方，这里面最多可以设置28个权限组

Effect/Style 文件夹
许多粒子效果和粒子风格都在这里配置
插件版本7.0新增的功能

locale文件夹
这个文件夹里面主要是语言文件，游戏内的GUI菜单、/pp help的提示的语言都在这里面！

playerparticles.db
插件自带的数据库。


占位符



变量
Placeholder		描述
Description
%playerparticles_active_amount%玩家已激活（正在使用）的粒子效果数量
%playerparticles_group_amount%玩家自己弄了多少个粒子特效组
%playerparticles_fixed_amount%玩家生成了多少个定点的粒子效果
%playerparticles_is_moving%玩家是否在移动？true为移动，false为不移动
%playerparticles_is_in_combat%玩家在打架吗？true为在打架，false为不打架
%playerparticles_can_see_particles%玩家有没有设置PlayerParticles粒子效果？true为设置了，false为没设置
%playerparticles_particle_effect_<#>%获取某个玩家正在用的粒子特效的id，将<#>替换为玩家id
%playerparticles_particle_style_<#>%获取某个玩家正在用的粒子风格的id，将<#>替换为玩家id
%playerparticles_particle_data_<#>%获取某个玩家正在用的粒子的数据，将<#>替换为玩家id

权限节点




权限节点
Permission Node		描述
Description		推荐将权限给予以下用户
playerparticles.effect.给予某用户/权限组使用某粒子特效，这些粒子效果的名称我会列在下面Any
playerparticles.effect.*给予某用户/权限组拥有使用所有的特效Any
playerparticles.style.给予某用户/权限组使用某种风格，风格的名称在下面Any
playerparticles.style.*给予某用户/权限组拥有使用所有的风格Any
playerparticles.fixed允许使用/pp fixed创建定点粒子特效Trusted users
playerparticles.fixed.clear允许使用/pp fixed clear删除定点粒子特效Admins
playerparticles.fixed.teleport允许使用/pp fixed teleport传送到某个定点粒子的位置Admins
playerparticles.fixed.unlimited允许无限制创建定点粒子特效，无视config.yml设置的值Admins
playerparticles.unlimited允许无限制的创建粒子特效，无视config.yml设置的值Trusted users
playerparticles.groups.unlimited允许无限制的创建粒子特效组，无视config.yml设置的值Trusted users
playerparticles.gui拥有打开GUI的权限[/pp gui]，config.yml的默认值是无法打开Any
playerparticles.reload允许使用/pp reload重载playerparticles插件！Admins
playerparticles.override允许使用/ppo指令Admins

celebrationNoYes四周出现烟花的效果，其实就是烟花发射的效果+粒子特效
chainsNoYes[链条]脚底四周出现4个点
companionNoYes粒子效果会在玩家身边转圈圈，从头到脚；从脚到头
cubeNoYes一个正方体包围你，正方体会转动
feetNoYes粒子效果出现在脚底
haloNoYes主角光环（最完美的描述
hurtYesNo被仙人掌占便宜[刺]后会显示粒子效果
invocationNoYes脚底出现一个很大的光环[神圣]，光环被像个祭坛
moveYesNo移动后才会显示粒子效果；显示在脚下
normalNoYes粒子特效出现在四周。默认的风格
orbitNoYes粒子特效会盘旋在身边
overheadNoYes粒子特效没有规律的出现在你头上
pointNoYes头上出现一个点
popperNoYes粒子特效从半身到头，像个冰淇淋
pulseNoYes1个圈在你脚下慢慢扩大
quadhelixNoYes一个不倒不立的冰淇淋在你身边，从头到脚；从脚到头
ringsNoYes两个互相垂直的圈围绕着你，如果看后背像个X
sphereNoYes一个圆体把你包住了
spinNoYes头上一个曲线在一直转圈圈
spiralNoYes一个曲线在你半身腰转圈圈
swordsYesNo当你拿剑锤别人的时候[战斗]，粒子特效会显示出来
thickNoYes粒子特效很密集的在你身边乱走，而且还会穿入你的身体
twinsNoYes两条曲线一直转在你身边，不会到头；也不会到脚
vortexNoYes一个由粒子特效形成的圆筒包住了你
whirlNoYes粒子形成的螺旋状出现在你脚底
whirlwindNoYes一个旋流在你脚底，旋流会形成一个圈
wingsNoNo你的后背会出现翅膀
