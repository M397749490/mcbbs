作者原文：
Overview
BinaryCraft is a mod with a miscellaneous selection of blocks, machines and items that I want to have in my modded Minecraft gameplay. I'll be slowly adding more features to this mod as time allows. The items in the mod are fully configurable.
Features
StorageSilo
A single block capable of storing 999 items, with a search feature
CraftingSilo
As the StorageSilo, but with a integrated crafting table
MendingStation
A block that uses RF to repair items with the mending enchantment
Coming soon
watch this space :)
