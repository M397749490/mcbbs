使用方法

* 将config.yml里面的autosort: false 改成true  即可自动整理，插件使用简单没有过多的繁琐


如果你还想增加更多的整理项目请在list下添加
指令

/cleaninventory[tr]清理玩家正在查看的方块(12个街区半径)
/cleaninventory <x> <y> <z>[tr]清除位置的块
/cleaninventory <x> <y> <z> <world>[tr]在世界各地清洁街区

[tr=rgb(247, 238, 255)]清洁项目
[td]
[tr]命令[tr]描述
/cleaningitem get[tr]拿个清洁用品
/cleaningitem set[tr]将清理项设置为手边的项目。
/cleaningitem name[tr]获取清理项名称
/cleaningitem name <name>[tr]设置清理项名称，没有名称的同一项将无法运行
/cleaningitem lore[tr]获取清洁物品的知识
/cleaningitem lore <name>[tr]设置清洁物品的知识，相同的项目没有知识将无法发挥作用
/cleaningitem give <player/@a>[tr]给玩家或所有玩家一个清洁物品
/cleaningitem active[tr]获取清理小活动切换的值。
/cleaningitem active <true/false>[tr]设置清除项活动切换的值。
/cleaningitem durabilityLoss[tr]获取可持续性Loss活动按钮
/cleaningitem durabilityLoss <true/false>[tr]设置持久性Loss活动按钮
/cleaningitem openEvent[tr]获取openEvent活动按钮
/cleaningitem openEvent <true/false>[tr]设置openEvent活动切换
黑名单
[td]
[tr]命令[tr]描述
/blacklist <stacking/inventory> list[tr]得到相应的黑名单
/blacklist <stacking/inventory> list <pageNr>[tr]获取相应的黑名单页
/blacklist <stacking/inventory> clear[tr]清除各自的黑名单
/blacklist <stacking/inventory> add[tr]将手头的项目添加到相应的黑名单中。
/blacklist <stacking/inventory> add <name>[tr]将项目添加到相应的黑名单中
/blacklist <stacking/inventory> remove[tr]将手头的项目从相应的黑名单中删除。
/blacklist <stacking/inventory> remove <name>[tr]从相应的黑名单中删除项目
排序配置
[td]
[tr]命令[tr]描述
/sortingconfig pattern[tr]为玩家获取排序模式
/sortingconfig pattern <pattern>[tr]设置播放机的排序模式
/sortingconfig categories[tr]获取播放机的类别订单
/sortingconfig categories list[tr]获取所有可用类别
/sortingconfig categories set <name,name,name,..>[tr]设置播放机的类别顺序
/sortingconfig autosort[tr]为玩家准备自动开关
/sortingconfig autosort <true/false>[tr]为玩家设置自动切换开关
索金管理
[td]
[tr]命令[tr]描述
/sortingadmin autosort[tr]获取默认的自动关闭开关
/sortingadmin autosort <true/false>[tr]设置默认自动切换开关
/sortingadmin pattern[tr]获取默认的排序模式
/sortingadmin pattern <pattern>[tr]设置默认的排序模式
/sortingadmin categories[tr]获取默认类别顺序
/sortingadmin categories set <name,name,..>[tr]设置默认类别顺序
/sortingadmin categories addFromBook[tr]从手中的书中添加一个类别
/sortingadmin categories getAsBook <name>[tr]得到一个类别，如一本书
/sortingadmin cooldown[tr]获得排序冷却时间
/sortingadmin cooldown set <int>[tr]设置排序冷却时间
/sortingadmin cooldown active[tr]启动冷却开关
/sortingadmin cooldown active <true/false>[tr]设置冷却活动开关

[tr=rgb(247, 238, 255)]命令

    • [tr]给玩家或所有玩家一个清洁物品
  • /cleaningitem set
    • [tr]将清理项设置为手边的项目。
  • /cleaningitem name
    • [tr]获取清理项名称
  • /cleaningitem name <name>
    • [tr]设置清洁项目名称(可以使用颜色代码，如：&1、&5、.https://minecraft.tools/en/color-code.php[tr]只需将“§”改为“&”)。这并不意味着旧的清洁用品将得到一个新的名称，相反，它们将不再工作。使用工作清洁用品/cleaningitem get.
  • /cleaningitem lore
    • [tr]获取清洁物品的知识
  • /cleaningitem lore <name>
    • [tr]设置清洁项目的知识(您可以使用颜色代码：&1，&5，.https://minecraft.tools/en/color-code.php[tr]只需将“§”改为“&”)。这并不意味着旧的清洁用品将得到一个新的名称，相反，它们将不再工作。使用工作清洁用品/cleaningitem get.
  • /cleaningitem active
    • [tr]获取清理小活动切换的值。
  • /cleaningitem active <true/false>
    • [tr]设置清除项活动切换的值。
  • /cleaningitem durabilityLoss
    • [tr]获取可持续性Loss活动按钮
  • /cleaningitem durabilityLoss <true/false>
    • [tr]设置持久性Loss活动按钮
  • /cleaningitem openEvent
    • [tr]获取openEvent活动按钮
  • /cleaningitem openEvent <true/false>
    • [tr]设置openEvent活动切换

[tr]权限

  • chestcleaner.cmd.admin.cleaningitem.rename
    • [tr]玩家是否可以使用/清除项重命名命令
