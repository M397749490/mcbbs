标题: 服务器登陆无伤打怪的问题
怎么让玩家在副本里退出服务器后，再登陆的时候在主城，而不是在副本。急需求解.
作者: nice丿猫    时间: 2017-7-14 17:33
假如你装的登录插件是authme的话，
修改配置文件如下选项可以达到你的需求。
ForceSingleSession: true
# 在每次玩家登陆成功时，退出时传送到世界出生点
# 可以防止玩家在世界各地出生登陆
# 不同于“传送未登陆的玩家到出生点”
# 这个选项在玩家登陆后也会传送
ForceSpawnLocOnJoinEnabled: false
# 存储退出位置
# 这可以防止玩家登陆时丢失退出位置

其他登录插件的话研究一下配置文件也该也有类似选项
