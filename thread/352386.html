服务器防后门利器——PerDisable
                                           禁止权限|指令|非法OP|非法创造
前言：
原本是想做一个禁止权限的插件的，后来做着做着就变成了4个功能= =。
功能：
检查不在配置内的玩家，如果有自动踢出玩家并以非法为理由封禁[禁止的指令则是不能执行该指令]。
可以有效避免后门插件对服务器的破坏。

配置文件：
  1. #处理方式有：
  2. #ban - 封禁
  3. #kick - 踢出
  4. #depermission - 撤销权限
  5. #deop - 撤销OP
  6. #banip - 封禁IP
  7. op:
  8. #检测非法OP
  9.   checkOP: true
  10. #处理方式
  11. #非法OP特殊处理方式
  12. #deop - 撤销该玩家OP
  13.   handle:
  14.     - 'ban'
  15.     - 'deop'

  17. permissions:
  18. #检测非法权限
  19.   checkPermissions: true
  20. #禁止权限列表
  21.   list:
  22.     - '*'
  23.     - '*.*'
  24. #处理方式
  25. #权限特殊处理方式
  26. #depermission - 撤销非法玩家权限
  27.   handle:
  28.     - 'ban'
  29.     - 'dedepermission'

  31. gamemode:
  32. #检测非法创造模式
  33.   checkGamemode: true
  34. #处理方式
  35.   handle:
  36.     - 'ban'
  37. #使用创造白名单
  38.   whiteList:
  39.     - 'Admin'

  41. command:
  42. #开启指令禁止
  43.   checkCommand: true
  44. #禁止指令列表
  45. #如果想防止玩家使用/op指令的变种如/bukkit:op或/minecraft:op指令
  46. #可以使用/*:op格式来禁止
  47. #这里的指令需要输入/
  48.   list:
  49.     - '/op'
  50.     - '/deop'
  51.     - '/*:op'
  52.     - '/*:deop'
  53. #忽略检查的指令列表
  54. #为了让一些使用OP权限执行指令的插件正常使用
  55. #此处的指令一律忽略OP和非法权限检查
  56. #格式同上
  57.   ignorelist:
  58.     - '/me'
  59. #使用指令白名单
  60. #在此列表内的玩家不会检查指令
  61.   whiteList:
  62.     - 'Admin'

  64. #全局白名单
  65. #在这里设置的玩家将不会受到任何检查
  66. whiteList:
  67.   - 'Admin'

  69. spam:
  70. #防刷屏
  71.   checkSpam: true
  72. #一段时间内发言最大次数
  73.   value: 1
  74. #时间,单位秒
  75.   time: 1
  76. #处理方式
  77. #刷屏特殊处理方式
  78. #mute - 禁言
  79. #message - 提示信息
  80.   handle:
  81.     - 'mute'
  82.     - 'message'
  83. #刷屏提示信息
  84.   message: '&c你疑似刷屏了'
