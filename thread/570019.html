=====================================
首先生成一个记事本。。。。
往里输入
  1. set /p a= 请输入第一个数字:

  3. set /p b= 请输入第二个数字:
复制代码

这是赋值部分。。。。
继续输入。。。。
  1. set /a c=%a%+%b%
  2. set /a d=%a%-%b%
  3. set /a e=%a%*%b%
  4. set /a f=%a%/%b%
复制代码

计算部分。。。。
  1. echo================
  2. echo %a%+%b%=%c%
  3. echo %a%+%b%=%d%
  4. echo %a%*%b%=%e%
  5. echo %a%/%b%=%f%
  6. echo================
复制代码

输出部分。。。。。

然后把记事本的后缀名改为.bat
然后。。。。
这还没有完成~

大家有没有发现这个东东一输出就嗝屁了。。。。
所以我们还要加个goto循环
完整代码
  1. :again
  2. set /p a= 请输入第一个数字:

  4. set /p b= 请输入第二个数字:

  6. set /a c=%a%+%b%
  7. set /a d=%a%-%b%
  8. set /a e=%a%*%b%
  9. set /a f=%a%/%b%
  10. echo================
  11. echo %a%+%b%=%c%
  12. echo %a%+%b%=%d%
  13. echo %a%*%b%=%e%
  14. echo %a%/%b%=%f%
  15. echo================
  16. goto again
复制代码

一个计算器完成了~
