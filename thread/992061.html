插件介绍
要创建基于游戏的脚本？
您是否尝试过VariableTrigger？
您是Skript专业的程序员吗？有机会触发TriggerReactor。
TriggerReactor是脚本引擎，具有VariableTrigger的游戏内交互功能以及Skript的高级脚本系统。
您也可以创建触发器以在块上行走，单击块，命令，进入/退出区域以及所有Bukkit事件，自定义权限和第三方插件的事件！
（您可以从Factions，MCMMO等插件中挂接Event，然后做任何您想做的事）

  1. 多线程功能（无延迟）
  2. 6种触发类型：点击，漫游，命令，命名，清单，重复
  3. 或从任何事件创建自定义触发器
  4. 包括49个以上的执行器和43个以上的占位符以便于使用
  5. 或创建自己的执行器并与其他插件进行交互
  6. 直接从javadocs使用方法
  7. 创建动态变量
  8. 稳健的条件系统
  9. 创建和使用循环和数组
  10. 访问第三方插件API

插件指令&权限
指令
  1. /trg - 插件使用帮助
  2. /trg walk[w] [...] - 创建踩踏触发脚本
  3. /trg click[c] [...] - 创建点击触发脚本
  4. /trg command[cmd] [...] - 创建指令触发脚本
  5. /trg custom <event> <name> [...] - 创建自定义触发脚本
  6. /trg synccustom[sync] <name> - 设置同步/异步模式
  7. /trg variables[vars] [...] - 设置全局变量
  8. /trg variables[vars] <variable name> - 将值存储在变量中
  9. /trg run [...] - 运行简单的脚本，不会被触发
  10. /trg sudo <player> [...] - 运行简单的脚本
  11. /trg delete[del] <type> <name> - 删除特定的脚本/变量/等
  12. /trg search - 将所有触发脚本方块显示为发光的石头
  13. /trg list [filter..] - 列出所有脚本
  14. /trg saveall - 保存所有脚本/变量/设置
  15. /trg reload - 重载所有脚本/变量/设置
  16. /trg timings toggle - 开启/关闭时间分析也将重置该系统
  17. /trg timings reset - 重置时间分析系统
  18. /trg timings print - 显示分析结果
  19. /trg timings print xx - 保存分析结果为xx.timings
