插件介绍   

插件版本：1.8-1.12 注意：本插件不支持1.8以下的版本
插件特性：1.在配置列表中，设置广播与广播之间的播放间隔和公告播放的有序/随机的
2.公告也可在游戏中用命令播放!
3.也可以设置，当玩家加入服务器时的动态广播!
插件命令
/aa send <玩家> <秒数> <信息/列表ID>

向一个玩家发送一条动态广播停留n秒

权限: actionannouncer.send


/aa announce <秒数> <信息/列表ID>

向所有玩家发送一条动态广播停留n秒

权限: actionannouncer.announce


/aa reload

重载配置文件

权限: actionannouncer.reload     


/aa start

开启动态广播

权限: actionannouncer.start


/aa stop

关闭动态广播

权限: actionannouncer.stop


/aa add <信息>

给动态广播里添加一条信息

权限: actionannounce.add


/aa remove <列表ID>

删除一条动态广播信息

权限: actionannounce.remove


/aa list

查看动态广播里的所有信息

权限: actionannounce.list


/aa stfu 或 /aa quiet

显示每条信息时是否开启叮咚音效

  5. #启用动态广播
  6. announcer_enabled: true
  7. #开启随机播放
  8. announcer_random: true
  9. #时间间隔
  10. announce_interval: 60
  11. #公告长度
  12. announcement_length: 4
  13. #动态公告播放列表
  14. announcements:
  15. - '&a今天你签到了吗？'
  16. - '&b今天你快乐吗!'
  17. #开启 加入游戏动态广播
  18. announce_on_join: true
  19. #加入游戏动态广播播放文字
  20. join_announcement: '&e欢迎&b%player%!到服务器 当前&f%online%在线'
  21. #禁用动态播放
  22. disable_sounds: false
