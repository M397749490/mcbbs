安装插件

  • 从SpigotMC.org下载插件或从Github下载源码，并自己编译成一个jar文件！
  • 将jar文件移动到目标服务器的plugins文件夹
  • 启动服务器，插件将被激活，并将创建配置和语言设置文件。
  • 进入设置游戏单个服务器或BungeeCord服务器的配置。




安装游戏(单个服务器)

  • 确保您使用Multiverse-Core或MultiWorld导入了一个世界(Bedwars类型的地图)
  • 开始创建你的BedwarsRel游戏输入命令 /bw addgame
  • 现在需要创建下您需要的团队，可输入 /bw addteam 命令，但你必须至少添加2个团队。
  • 接下来，你必须站在所需设置团队的出生点上执行 /bw setspawn 命令即可设置团队的出生点。
  • 要设置一个团队的床，你必须用鼠标(或站在它上面)对着需要设置的床，并设置床的命令为 /bw setbed
  • 资源出生地必须通过站在所需的位置并执行命令 /bw setspawner
  • 现在设置游戏世界的同时，要做到这一点，你必须飞到地图的右上角输入命令 /bw setregion {game} loc1 来设置游戏的第一个位置，然后飞到地图的左下角输入命令 /bw setregion {game} loc2 来设置游戏的第二个位置。
  • 现在就开始设置大厅了。请传送到另外一个世界，然后设置大厅在你的所站在的位置并执行 /bw setlobby 命令。
  • 可选=如果需要设置为“mainlobby”， 必须在Config.yml那里设置，但您必须添加mainlobby，然后设置mainlobby在你的所站在的位置并执行 /bw setmainlobby 命令。
  • 现在输入命令 /bw save {game} 来保存游戏！（如果有错误他会显示）




安装游戏(BungeeCord服务器)

  • 为BedwarsRel的游戏地图创建一个BungeeCord服务器。
  • 这个BungeeCord服务器会在关闭后重新启动，因为BedwarsRel插件将在每个游戏房间结束后关闭而不是重新启动。这可能需要.bat(电脑上的Cmd/命令提示符)的帮助了。例子：
    @echo off
    :restart
    java -Xms{最小内存} -Xmx{最大内存} -XX:MaxPermSize=128M -jar {你的服务器核心名字}.jar
    timeout /t 10 /NOBREAK
    goto restart
    pause
  • 该 timeout /t 10 /NOBREAK 命令将会使服务器等待10秒钟，然后服务器将重新启动。这个10秒钟的时间可以用于中断重启和需要关闭命令提示符的话请敲击 CTRL+ C。
  • 配置BedwarsRel的config.yml，并设置 hubserver 为正确的默认/大厅服务器。然后通过设置使插件 enabled 中的 bungeecord项的每一个子项目为 true
  • 设置和加入新BungeeCord服务器，并按照 安装游戏[单个服务器] 的教程指令。重要：当启BungeeCord的同时，只能每个服务器创建一个游戏，不能有第二个！(意思就是：每个服务器只能拥有一个游戏)
