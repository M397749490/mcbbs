提示.

  • 你不能分发代码.
  • 你不能模仿作者.



指令
  • /animatedtnt turn <true/false> (animatedtnt.command) - 是否开启TNT爆炸动画
  • /animatedtnt range <x/y/z> <0-1000> (animatedtnt.command) - 改变爆炸的大小
配置文件

你可以编辑爆炸的范围
  • Code (YML):
    enable: true
    range:
      x: 2.5
      y: 3.5
      z: 2.5
