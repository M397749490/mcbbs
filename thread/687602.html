下载附件

2017-4-19 20:38 上传
  • <>代表必填 []代表选填
  • /cctv create camera <录像机名字> 进入相机创建模式（左键合成）~默认合成配方：发射器——海绵——黑曜石
  • /cctv create screen <屏幕名字> 进入屏幕创建模式（右键合成）~默认合成配方：黑色羊毛——灰色羊毛
  • /cctv link [录像机名字] [屏幕名字] 连接录像机以及屏幕
  • /cctv modify [参数] [true|false] 如果录像机未连接，就开启所有人都可以使用
  • /cctv delete link 删除所有连接，你不能删除不是你的
