      玩家面向方块的坐标，只要打开F3界面就能看到，但这只对很小的范围内有效，而且这个数值无法获取，也没有实际的用途。而通过1.13强大的局部坐标和递归函数可以获取这个数值并且可以将探测范围扩展到很大：

（关于新指令的用法这里不再详细说，看不懂的请自行找教程贴）
原理讲解：
      总的思想是在玩家眼睛处生成一个盔甲架，继承玩家的朝向，然后递归一路往前移，知道当前位置不是空气为止。
      首先创建五个计分板：
  1. <div><font face="宋体" size="2"><span style="line-height: 24px;">/scoreboard objectives add click minecraft.used:minecraft.carrot_on_a_stick</span></font></div><div><font face="宋体" size="2"><span style="line-height: 24px;">/scoreboard objectives add distance dummy</span></font></div><div><font face="宋体" size="2"><span style="line-height: 24px;">/scoreboard objectives add x dummy</span></font></div><div><font face="宋体" size="2"><span style="line-height: 24px;">/scoreboard objectives add y dummy</span></font></div><div><font face="宋体" size="2"><span style="line-height: 24px;">/scoreboard objectives add z dummy</span></font></div>
复制代码
      click是触发条件，图省事直接用萝卜钓竿了。
      distance是记录递归函数中盔甲架的位移，下面会细讲。
      x，y，z分别记录获取的坐标的x，y，z值。


函数main：
  1. execute as @a[scores={click=1}] at @s run summon armor_stand ~ ~1.62 ~ {NoGravity:1,CustomName:"finder",Invisible:1}
复制代码
      在玩家眼睛处生成一个隐形、无重力的盔甲架，名字为“finder”
  1. execute as @a[scores={click=1}] at @s run tp @e[name=finder] ~ ~1.62 ~ ~ ~
复制代码
      让盔甲架继承玩家的朝向
  1. execute as @e[limit=1,type=armor_stand,name=finder] run function get_coordinate:find
复制代码
      让盔甲架执行find函数


find函数部分：
  1. execute as @s at @s run tp @s ^ ^ ^1
复制代码
      将盔甲架tp到眼睛前面一格的位置。


  1. tag @s add find
复制代码
      给盔甲架一个find标签，假定此刻已经找到玩家所面向的方块


  1. scoreboard players add @s distance 1
复制代码
      盔甲架的distance分数+1，为了防止玩家看着天上或者看着很远很远的地方而导致函数递归非常多次造成游戏卡顿，用distance来记录盔甲架当前的位移，限定递归次数


  1. execute at @s if block ~ ~ ~ air run tag @s remove find
复制代码
      如果当前位置为空气，则之前的假定不成立，移除find标签


  1. execute as @s[tag=!find,scores={distance=0..100}] run function get_coordinate:find
复制代码
      如果没有找到面向的方块（tag=find）或超过递归次数（distance>100），就跳出循环，否则进行下一次递归。当然这里的distance上限可以调的更大，这样可用的探测范围也会更大，不过可能会造成游戏卡顿。最好不要超过4位数


回归main函数


  1. <div>execute as @a[scores={click=1}] store result score @a[scores={click=1}] x run data get entity @e[limit=1,type=armor_stand,name=finder] Pos[0]</div><div>execute as @a[scores={click=1}] store result score @a[scores={click=1}] y run data get entity @e[limit=1,type=armor_stand,name=finder] Pos[1]</div><div>execute as @a[scores={click=1}] store result score @a[scores={click=1}] z run data get entity @e[limit=1,type=armor_stand,name=finder] Pos[2]</div>
复制代码
      将盔甲架的x，y，z坐标分别存到玩家的x，y，z计分板内


  1. <div><font face="宋体" size="2">execute if entity @e[limit=1,type=armor_stand,name=finder,tag=find] run tellraw @a ["",{"text":"you're looking at:","color":"yellow"},{"score":{"name":"*","objective":"x"}},{"text":","},{"score":{"name":"*","objective":"y"}},{"text":","},{"score":{"name":"*","objective":"z"}}]</font></div>
复制代码
      递归函数的跳出分为两种情况，如果此时盔甲架带有find标签，则说明找到了面向的方块，tellraw说出玩家当前的x，y，z分数


  1. execute if entity @e[limit=1,type=armor_stand,name=finder,tag=!find] run tellraw @a ["",{"text":"too far!","color":"red","bold":"true"}]
复制代码
      如果此时盔甲架不带有find标签，则说明是因为距离太远导致循环到了最大上限也没有找到方块，tellraw说出错误信息


  1. <div>kill @e[limit=1,type=armor_stand,name=finder]</div><div>scoreboard players set @a click 0</div>
复制代码
      初始化，清掉盔甲架，玩家的click分数清零


最后把main函数丢个minecraft:tick标签加入高频就行了（感谢如花和chyx的帮助，wiki上关于数据包标签讲的实在看不懂...）
