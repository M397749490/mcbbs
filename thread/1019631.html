您是否还在寻找一款功能强大而又简单的插件？

今天他来了

TPR！！！

插件功能


在指定世界进行随机传送

任意组任意冷却时间

自定义的传送提示

自定义传送范围


插件使用方法


/tpr#随机传送

权限tpr.use

/tpr reload#重载插件

权限无，默认OP

看完了使用方法是不是觉得很简单嘿嘿


Config[很短的哦~~~]


# 插件变量
# !x 随机传送到X坐标
# !y 随机传送到Y坐标
# !z 随机传送到Z坐标
# !s 随机传送冷却时间

# 玩家需要拥有tpr.use权限才能使用随机传送

# 传送坐标为(0,0)

# 传送的范围，-bound 至 +bound例如: -3000 至 +3000

bound: 3000

# 指定随机范围

# 世界名: "最小值,最大值"

bounds:

  world: "-300,400"

  zy: "-100,100"

# 默认冷却时间（秒），拥有tpr.nocool权限的玩家无视冷却.

defaultCooldown: 10

# 权限冷却时间

# 当玩家拥有“tpr.vip1”时冷却时间为8秒。

# 玩家拥有多个权限节点时，冷却时间取最低的那个。

cooldownPermissions:

  vip1: 8

  vip2: 6

  vip3: 4

  vip4: 2

  vip5: 0

# 允许随机传送的世界名

worlds:

  - world

  - world_res

# 传送成功的提示

tpdone: "&6[随机传送]&e随机传送到坐标&8(!x,!y,!z)"

# 冷却提示

tpcooldown: "&6[随机传送]&c传送冷却&e!s&c秒"

# 不允许在当前世界传送的提示

notallowworld: "&6[随机传送]&c当前世界&8(!world)&c无法随机传送!"

# Y轴坐标

# 删除此行的话只会随机传送到地面上

y: 255
