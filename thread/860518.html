  1. ## 0x0C 数据结构

  3. 数据结构指的是相互之间存在一种或多种关系的数据元素的集合和该集合中数据元素之间的关系        

  5. 你可以抽象的理解为数据结构可以维护数据以及数据之间的关系

  7. 这一部分会从比较简单的数据结构一直讲到一些比较困难的数据结构

  9. 你需要注意的是 这里并不会讲到**红黑树**这一数据结构

  11. 所有数据结构的教程都会以一道题来作为引子

  13. 这一部分默认$n$为输入数据规模

  15. ### 0x0D 链表

  17. 我并没有找到链表的题 于是链表没有引子



  21. 链表是一种在内存中非连续非顺序的存储结构 它与数组类似 可以储存一个元素的集合

  23. 对于链表中的每一个节点 我们会维护从这个节点向下一个节点的指针 此时这是一个**单向链表**

  25. 如果我们再维护从这个节点向上一个节点的指针 那么这就是一个**双向链表**

  27. ![img](https://gss0.bdstatic.com/94o3dSag_xI4khGkpoWK1HF6hhy/baike/c0%3Dbaike72%2C5%2C5%2C72%2C24/sign=0dfd76b003087bf469e15fbb93ba3c49/91ef76c6a7efce1b8d7e8131ae51f3deb58f65f7.jpg)

  29. 如图所示的就是一个单向链表



  33. 链表**不支持**随机访问 也就是说你并不可以按照$A[i]$的方式来访问链表中的第$i$个元素

  35. 也就是说 如果你想要在链表中访问第$i$个元素 你就需要从链表头开始不断向前直到找到这个元素为止

  37. 链表可以**快速**进行插入删除 当你需要在当前的节点之后加入元素时 你可以直接新建一个节点
  38. 然后令当前节点指向新建的这个节点 再将新建的这个节点指向原本当前节点指向的节点(a->b变成a->c->b) 删除同理

  40. 链表的访问效率是$O(n)$ 在确定的位置插入删除元素的效率是$O(1)$

  42. 数组的访问效率是$O(1)$ 在确定的位置插入删除元素的效率是$O(n)$ （因为你需要将这个位置后的所有元素向左移或向右移）



  46. 之后给出单向链表的代码 同时给出插入元素的代码

  48. ```cpp
  49. struct Node{
  50.          int val,nxt;
  51. }list[n];
  52. int cnt = 0;//当前节点总数
  53. void insert(int i,int x){//在list[i]这个节点之后插入一个值为x的节点
  54.     ++cnt;
  55.     list[cnt].val = x;list[cnt].nxt = list[i].nxt;
  56.     list[i].nxt = cnt;
  57. }
  58. ```

  60. ### 0x0E 队列

  62. 和链表相同的 队列我也并没有找到适合作为引子的题



  66. 队列作为先进先出(FIFO)结构，支持三个操作

  68. - 在队列的尾部加入一个元素
  69. - 得到队列头部的值
  70. - 删除队列头

  72. 举一个比较现实的例子 当一群人在排队

  74. - 新来的人要加到队伍的后面
  75. - 队伍最前面的人会第一个被服务
  76. - 只有队伍最前面的人会在服务结束后离开队伍

  78. 那么这就是一个比较典型的队列了

  80. 这里给出一种队列的链表实现（这里我们假设队列始终不会空）：

  82. ```cpp
  83. struct Node{
  84.          int val,nxt;
  85. }list[n];
  86. int cnt = 0;//当前节点总数
  87. int head=0,tail=0;//当前链表的头和尾
  88. void insert(int x){//向队列中加入元素
  89.     list[++cnt].val = x;
  90.     list[tail].nxt = cnt;
  91.     tail = cnt;
  92.     if(head == 0)head = cnt;
  93. }
  94. int front(){//查询队列头的值
  95.         return list[head].val;
  96. }
  97. void pop(){//删除队列头
  98.         head = list[head].nxt;
  99. }
  100. ```

  104. 很明显 适合放在这里的题我也找不到



  108. 栈就像货架一样，放在上面的东西先被拿出来，即后进先出(LIFO) 结构，因此只能删除栈尾的元素

  110. 在维护栈的时候 一般数组比链表好写

  112. ```cpp
  113. int stack[n],tail=0;//栈和栈尾的位置
  114. void insert(int x){
  115.     stack[++tail] = x;
  116. }
  117. int top(){//查询栈尾
  118.     return stack[tail];
  119. }
  120. void pop(){//删除栈尾
  121.     tail--;
  122. }
  123. ```

  125. ### 0x10 堆

  127. [【模板】堆](luogu.org/problemnew/show/P3378)

  129. 题目大意：

  131. 你需要支持以下几种操作：

  133. 1. 向**可重集**内加入一个元素
  134. 2. 查询集合内最小值
  135. 3. 删除集合内最小值

  137. 我们认为操作次数为$n$

  139. $n\leq10^6$



  143. 首先我们考虑一个暴力算法 每次加入元素时把元素扔到数组的最后面 每次询问时扫一遍数组 每次删除时将最小值所对应的元素设为一个很大的数$inf$

  145. ```cpp
  146. int set[1000010];
  147. int main(){
  148.         int n,cnt=0;//cnt维护当前集合内元素个数
  149.         cin>>n;//cin是c++的一种读入方式
  150.     while(n--){
  151.         int op;cin>>op;
  152.         if(op == 1){
  153.             int x;cin>>x;
  154.             set[++cnt] = x;
  155.         }
  156.         if(op == 2){
  157.             int ans = inf;
  158.             for(int i=1;i<=cnt;i++)
  159.                 ans = min(ans,set[i]);
  160.                    cout<<ans<<endl;//cout为c++的输出方式 endl表示换行        
  161.         }
  162.         if(op == 3){
  163.             int minVal = inf,pos = 0;//pos维护最小值的位置
  164.             for(int i=1;i<=cnt;i++)
  165.                 if(minVal > set[i])
  166.                     minVal = set[i],pos = i;
  167.             set[i] = inf;
  168.         }
  169.     }
  170. }
  171. ```



  175. 但是我们都知道这样做效率太低了 复杂度可以达到$O(n^2)$ 所以我们要找一个比较优秀的数据结构来解决这个问题

  177. 于是就有了堆这种数据结构



  181. 堆首先是一颗二叉树 其中的每一个节点有两个儿子：左儿子和右儿子 其中的某个儿子可以为空 也可以两个儿子都为空

  183. 当一个节点的两个儿子都为空的时候 这个节点称为**叶子节点**

  185. 当一个节点没有父亲的时候 这个节点称为**根节点**

  187. 同时堆还需要满足对于二叉树中的每一个节点 都需要令其的值小于其左右儿子的值 此时的堆称为**小根堆** 大根堆就是反过来 其他完全一样

  189. 很显然根据堆的这一性质 堆中的最小值就是根

  191. 在插入一个元素的时候 首先将它插入到堆的某个叶子结点之后

  193. 之后不断将这个元素和它的父节点作比较 如果这个元素小于它的父节点 就交换这两个节点

  195. 直到这个元素成为了根或者比父节点大为止

  197. 删除元素时首先删除根 然后令一个叶子结点为根 此时我们称这个节点为当前节点

  199. 之后不断将当前节点和其左儿子比较 进行和插入元素时类似的操作即可



  203. 我并不打算在这里给出堆的代码 其一是堆的代码相对较长 其二是在库中已经有堆的实现了

  205. 这个实现在c++下叫做$priority\_queue$ 翻译为优先队列

  207. 优先队列可以支持以上所提到的几种操作 其内部实现也是堆

  209. 在java下 优先队列是PriorityQueue

  211. 由于已经有了轮子 所以并不建议自己手写堆 毕竟这个东西有一定的几率写错

  213. ### 0x11 单调队列&单调栈

  215. 单调队列和单调栈首先是队列和栈

  217. 之后它们满足队列或栈中的元素单调递增或单调递减

  219. 这一性质可以让我们搞出来很多东西

  221. [滑动窗口](luogu.org/problemnew/show/P1886)

  223. 题目大意：

  225. 给定一个包含了$n$个数的数列和一个正整数$k$ 你需要求出$n-k+1$个区间$[l,l+k-1]$的最大值和最小值

  227. $n\le 10^6$



  231. 我们依然可以写出来一个十分简单的暴力算法：

  233. ```cpp
  234. int arr[maxn],minAns[maxn],maxAns[maxn];//maxn = 1000000
  235. int main(){
  236.     int n,k;cin>>n>>k;
  237.     for(int i=1;i<=n;i++)
  238.         cin>>arr[i];
  239.     for(int i=1;i<=n-k+1;i++){
  240.         minAns[i]=inf,maxAns[i]=-inf;
  241.         for(int j=i;j<=i+k-1;j++)
  242.             minAns[i] = min(minAns[i],arr[j]),
  243.                 maxAns[i] = max(maxAns[i],arr[j]);
  244.     }
  245.     for(int i=1;i<=n-k+1;i++)
  246.         cout<<minAns[i]<<" ";
  247.            cout<<endl;
  248.     for(int i=1;i<=n-k+1;i++)
  249.         cout<<maxAns[i]<<" ";
  250. }
  251. ```

  253. 然后你仔细一算复杂度 居然达到了$O(n^2)$级别 于是你觉得问题很大



  257. 我们发现在我们计算每个区间最大最小值的时候 重复地考虑了许多元素

  259. 那么假如我们记录下来每一个区间有可能成为最大最小值的元素的话 是否可以做到高效率解决问题？

  261. 当然可以

  263. 我们以求区间最小值为例

  265. 我们维护一个单调队列 这个队列需要满足从队列头到队列尾单调上升

  267. 当我们加入一个元素的时候 我们将队列尾部所有大于等于这个元素的元素全部删掉

  269. 当我们删除一个元素的时候 只需要判断队列头是否为这个元素即可

  271. 之后队列头就是这个区间的最小值

  273. 很显然我们发现这个队列里面的元素是所有有可能作为区间最小值的元素 我们只需要考虑一下怎么证明当我们删除一个元素的时候只需要删除队列头

  275. 于是我们对需要删除的元素分为两种情况讨论：

  277. - 需要删除的元素是队列头

  279. 这种情况就直接删除了 没什么好说的

  281. - 需要删除的元素不是队列头

  283. 假如说需要删除的元素不是队列头 那么队列头一定是一个比它小的数

  285. 同时我们知道删除的元素是区间最左端还要往左的那个元素

  287. 于是我们知道队列头一定是在这个数之后被加入单调队列的

  289. 那么按照单调队列的加入方法 这个需要删除的元素早已在加入队列头的时候被删除了 于是不需要再去管他

  291. 证毕



  295. ```cpp
  296. int queue[maxn],s=1,t=0;//s t为队列头尾
  297. void add(int x){
  298.     while(t >= s && x < queue[t])t--;
  299.     queue[++t] = x;
  300. }
  301. int front(){
  302.     return queue[s];
  303. }
  304. void pop(int x){
  305.     if(queue[s] == x)s++;
  306. }
  307. ```

  309. ### 0x12 树状数组

  311. [【模板】树状数组 1](www.luogu.org/problemnew/show/P3374)

  313. 题目大意：

  315. 给出一个包含$n$个数的数列 同时你需要进行m次操作 操作有两种

  317. 1. 将数列中的某个数加上$k$
  318. 2. 查询数列中$[l,r]$的和

  320. $n,m\le10^5$



  324. 我们依然先写出暴力算法的代码

  326. ```cpp
  327. int arr[maxn];
  328. int main(){
  329.     int n,m;cin>>n>>m;
  330.            for(int i=1;i<=n;i++)cin>>arr[i];
  331.     while(m--){
  332.         int op,x,y;cin>>op>>x>>y;
  333.         if(op == 1)arr[x] += y;
  334.         if(op == 2){
  335.             int ans = 0;
  336.             for(;x<=y;x++)ans += arr[x];
  337.             cout<<ans<<endl;
  338.         }
  339.     }
  340. }
  341. ```

  343. 显然的 这是一个$O(nm)$的算法



  347. 在讨论更快的算法前我们需要首先定义一个函数$lowbit$

  349. $lowbit(n)$表示$n$的二进制表达下最低位的1的值

  351. 比如说对于$n = 10 = (1010)_2$ 它的$lowbit(n)$就应当是$2$

  353. 我们当然可以从最低位开始向上枚举判断当前位是否是1 但是很明显这样做的复杂度会是$O(logn)$的

  355. 我们有一个更加简单的做法

  357. 首先我们将$n$的二进制翻转（即0变1 1变0 在代码中的操作为$\text{~}n$） 之后我们会发现翻转后的二进制表达中末尾的一串0会变为一串1 最低位的1会变成0

  359. 于是我们将这个翻转后的数再加上1 那么原数中最低位的1这时还是1 原数中其他位置的值在新数中都被翻转了

  361. 那么。。 我们就可以直接让这两个值做二进制的与（&）操作 得到的值即为lowbit的值

  363. 也就是说 $lowbit(n) = n \& (\text~n+1)$

  365. 我们还知道将一个数翻转后加一实际上就是求这个数的补码 而这个数的补码一般就是这个数的相反数

  367. 所以$lowbit(n) = n\&-n$



  371. 那么它有什么用呢？ 我们找一张图过来

  373. ![img](http://p0.so.qhimgs1.com/bdr/_240_/t01b3cd94b11782f024.png)

  375. 对于一个数$i$ $C[i]$就表示了区间$[i-lowbit(i)+1,i]$这段区间的和

  377. 我们称$i$被$j$直接管辖 当且仅当$j$为最小的$j$使得$i\in[j-lowbit(j)+1,j]$

  379. 我们会发现这个$C$数组很像一棵树 于是这个算法叫做树状数组



  383. 之后我们分两种操作讨论

  385. 第一是单点修改

  387. 我们会发现一个点$i$被$i+lowbit(i)$ 管辖 那么也就是说当我们修改$i$的时候 要顺便把$i+lowbit(i)$修改掉

  389. 我们又发现$i+lowbit(i)$也有可能会被另一个点管辖 于是我们还需要把另一个点修改掉

  391. 显然每一个点都会被管辖 那么我们在当前修改的点的下标大于$n$的时候结束就好了

  393. ```cpp
  394. void modify(int pos,int v){
  395.     A[pos] += v;
  396.     while(pos <= n){
  397.         C[pos] += v;
  398.         pos += lowbit(pos);
  399.     }
  400. }
  401. ```



  405. 每一次修改时$lowbit$的值都至少为上一次修改的$lowbit$值的二倍 所以这个过程最多进行$logn$次

  407. 于是修改的时间复杂度是$O(logn)$

  409. 第二是区间查询

  411. 或许在你看到这个操作名称的时候你想到的是查询$[l,r]$的和

  413. 但是事实上树状数组只能查询$[1,x]$的和 想要查询$[l,r]$的和需要用$[1,r] - [1,l-1]$



  417. 那么我们怎么查询$[1,x]$呢？ 我们发现$x$代表了$[x-lowbit(x)+1,x]$的和 那么我们把这段累加入答案

  419. 之后再求出$[1,x-lowbit(x)]$就好了 直到求的区间为$[1,0]$时结束这个过程

  421. ```cpp
  422. int query(int x){
  423.     int ans = 0;
  424.     while(x){
  425.         ans += C[x];
  426.         x -= lowbit(x);
  427.     }
  428.     return ans;
  429. }
  430. ```

  432. 进行查询的次数实际上就是$x$中1的个数 而我们直到这个值一定在$logx$左右

  434. 于是进行查询的时间复杂度也是$O(logn)$的



  438. 之后我们就得到了一个修改和查询均为$O(logn)$复杂度的优秀算法

  440. 那么对于这个题 这个做法的复杂度就是$O(mlogn)$ 可以过



  444. 思考： 假如我的两个操作分别为将区间内所有元素加上$k$和查询某个点的值 该怎么做?

  450. ### 0x13 线段树

  452. 树状数组是个好东西 可以让我们完成一些对于数列的操作

  454. 但是当我们需要进行的操作比较复杂时 树状数组就可能会变得难以使用

  456. [【模板】线段树1](luogu.org/problemnew/show/P3372)

  458. 题目大意：

  460. $n$个数$m$个操作

  462. 1. 将区间内的每个数加上$x$
  463. 2. 求区间内所有数的和

  465. $n,m\le 10^5$



  469. 这题当然也可以用暴力来写一个$O(nm)$的做法 不过这里不再给出代码

  471. 你也可以用树状数组把每个操作的区间中的每个数都暴力进行修改操作

  473. 但是这样做的复杂度高达$O(mnlogn)$ 它比暴力还慢

  475. 所以我们可以换一种做法做树状数组 使得它支持区间操作和区间求和

  477. 但是这与线段树并没有什么关系 如果你想要了解这个做法可以参考[这篇博客](<https://www.cnblogs.com/lcf-2000/p/5866170.html>)

  479. 这道题最简单的做法是线段树



  483. 线段树是一种能够在比较高效的时间内解决区间问题的数据结构

  485. 首先 线段树是一颗二叉树 每一个节点表示一个区间$[l,r]$

  487. 我们定义$mid = \left|\frac{l+r}2\right|$

  489. 那么对于一个不是叶子结点的节点 其左儿子的区间为$[l,mid]$ 右儿子的区间为$[mid+1,r]$

  491. 于是线段树的深度大约在$logn$左右

  493. 每个节点可以维护这个区间对应的信息 在本题中就是这个区间的和

  495. 如果我们将它表示成一张图 那么它就长成这个样子

  497. ![img](http://p0.so.qhimgs1.com/bdr/_240_/t016b0d2e51e372bef0.png)



  501. 当我们修改一个点$i$的时候 我们可以从根开始不断递归寻找区间为$[i,i]$的叶子结点 并将路径上的所有节点维护的信息修改掉

  503. 当我们查询一个点$i$的时候 我们可以递归寻找这个叶子结点 这个叶子节点的值就是答案



  507. 但是如果只拿线段树来做单点修改单点查询是非常没意义的事情

  509. 我们来考虑怎么快速做区间修改和区间查询

  511. 以上面这颗线段树为例 假如我们需要修改区间$[3,7]$ 那么我们实际上只需要找到所有包含了这几个点的区间做修改即可

  513. 然后我们写出了一段代码

  515. ```cpp
  516. int val[maxn*10],lson[maxn*10],rson[maxn*10];
  517. //val表示这个节点代表的区间的和 lson和rson分别代表这个节点的左右儿子
  518. //线段树上最多会有大概n*4个节点 这里开到n*10只是习惯问题
  519. void modify(int rt,int l,int r,int x,int y,int v){
  520.     //rt是当前节点在线段树上的编号 lr是这个节点的区间 xy是操作区间 v是操作数
  521.     if(l == r){val[rt] += v;return;}
  522.     // 如果已经递归到一个点了 直接修改值就可以结束递归了
  523.     int mid = (l+r)>>1;//(l+r)>>1 等价于 (l+r)/2
  524.     if(mid >= x)modify(lson[rt],l,mid,x,y,v);
  525.     //如果当前节点的左儿子含有操作区间的一部分 就去递归左儿子
  526.     if(mid < y)modify(rson[rt],mid+1,r,x,y,v);
  527.     //右儿子同理
  528.     val[rt] = val[lson[rt]] = val[rson[rt]];
  529.     //当前节点的值就应该是左儿子的值加上右儿子的值
  530. }
  531. ```



  535. 然后我们来考虑怎么求一个区间的和

  537. 再以区间$[3,7]$为例 我们可以将里面每个数搞出来然后求和 但是这没有必要

  539. 因为$[3,7] = [3,3] + [4,5] + [6,7]$

  541. 于是我们只需要求出这些区间的值再求和就可以了

  543. 所以我们又写出了一段代码

  545. ```cpp
  546. int query(int rt,int l,int r,int x,int y){
  547.     if(x <= l && r <= y)return val[rt];
  548.     //如果当前节点被查询区间完全包含 可以直接返回当前节点的值
  549.     int mid = (l+r)>>1,ans = 0;
  550.     if(mid >= x)ans += query(lson[rt],l,mid,x,y);
  551.     if(mid < y)ans += query(rson[rt],mid+1,r,x,y);
  552.     return ans;
  553. }
  554. ```



  558. 现在我们只剩下了一个问题 如果我们有原数列$raw$ 我们怎么构建出这棵线段树？

  560. 所以我们又写了一段代码

  562. ```cpp
  563. int cnt = 0;//表示节点个数
  564. void build(int &rt,int l,int r){//&是c++中的传址
  565.     rt = ++cnt;
  566.     if(l == r){val[rt] = l;return;}
  567.     else{
  568.         int mid = (l+r)>>1;
  569.         build(lson[rt],l,mid);
  570.         build(rson[rt],mid+1,r);
  571.         val[rt] = val[lson[rt]] + val[rson[rt]];
  572.     }
  573. }
  574. ```



  578. 之后我们需要做的是分析复杂度

  580. 从最简单的build开始分析 显然build会访问所有节点 而节点数大约在$4\times n$左右 所以build是$O(n)$的

  582. 然后是query 每个查询的区间总可以分解成大约$log(r-l+1)$个区间后求和 于是复杂度是$O(logn)$的

  584. 最后是modify 我们会发现按照我们的写法modify会需要覆盖包含$[l,r]$中元素的所有节点 于是这个操作的复杂度可以达到$O(n)$



  588. 然后我们就发现modify让我们的操作十分不爽 它太慢了

  590. 我们需要考虑一种让modify和query一样优秀的做法 能不能像query一样把操作区间也分成$logn$个小区间然后只对这几个区间进行操作呢。。？

  592. 我们最大的问题是 如果将一个节点修改以后就不再递归 那么它的儿子怎么办？

  594. 但是。。 如果我们在一个节点上打上一个标记 表示这个节点的所有儿子都需要加上这个标记的话。。 是不是就可以得到一个高效的算法。。？

  596. 可是如果打标记以后 我要查询的区间并不完全包含这个打标记的节点 就会导致query十分麻烦

  598. 那么 我们将标记下传不就好了！

  600. 于是你定义$tag$为标记数组 并写出了下传标记的函数

  602. ```cpp
  603. void pushdown(int rt,int l,int r){
  604.     if(!tag[rt])return;//如果没有标记就不用下传了
  605.     tag[lson[rt]] += tag[rt];tag[rson[rt]] += tag[rt];//更新左右儿子的标记
  606.     int mid = (l+r)>>1;
  607.     val[lson[rt]] += tag[rt] * (mid-l+1);
  608.     val[rson[rt]] += tag[rt] * (r-mid);//维护左右儿子的区间和
  609. }
  610. ```

  612. 并且你将modify改成了这样

  614. ```cpp
  615. void modify(int rt,int l,int r,int x,int y,int v){
  616.     if(x <= l && r <= y){
  617.         tag[rt] += v;val[rt] += (r-l+1)*v;
  618.         return;
  619.     }
  620.     //...
  621. }

  623. ```



  627. 然后问题就来了 你应当在什么时候下传标记？

  629. 很明显的标记下传少了的话会导致答案出错 但是标记下传多了只是会让算法的常数大那么一丢丢丢

  631. 所以你可以直接在modify和query函数的开头下传标记

  633. 复杂度$O(logn)$达成！

0x0D 链表

我并没有找到链表的题 于是链表没有引子

链表是一种在内存中非连续非顺序的存储结构 它与数组类似 可以储存一个元素的集合

对于链表中的每一个节点 我们会维护从这个节点向下一个节点的指针 此时这是一个单向链表

如果我们再维护从这个节点向上一个节点的指针 那么这就是一个双向链表



如图所示的就是一个单向链表

链表不支持随机访问 也就是说你并不可以按照$A$的方式来访问链表中的第$i$个元素

也就是说 如果你想要在链表中访问第$i$个元素 你就需要从链表头开始不断向前直到找到这个元素为止

链表可以快速进行插入删除 当你需要在当前的节点之后加入元素时 你可以直接新建一个节点  然后令当前节点指向新建的这个节点 再将新建的这个节点指向原本当前节点指向的节点(a->b变成a->c->b) 删除同理

链表的访问效率是$O(n)$ 在确定的位置插入删除元素的效率是$O(1)$

数组的访问效率是$O(1)$ 在确定的位置插入删除元素的效率是$O(n)$ （因为你需要将这个位置后的所有元素向左移或向右移）

之后给出单向链表的代码 同时给出插入元素的代码

  1. struct Node{
  2.          int val,nxt;
  3. }list[n];
  4. int cnt = 0;//当前节点总数
  5. void insert(int i,int x){//在list[i]这个节点之后插入一个值为x的节点
  6.     ++cnt;
  7.     list[cnt].val = x;list[cnt].nxt = list[i].nxt;
  8.     list[i].nxt = cnt;
  9. }

0x0E 队列

和链表相同的 队列我也并没有找到适合作为引子的题

队列作为先进先出(FIFO)结构，支持三个操作

  • 在队列的尾部加入一个元素
  • 得到队列头部的值
  • 删除队列头

举一个比较现实的例子 当一群人在排队

  • 新来的人要加到队伍的后面
  • 队伍最前面的人会第一个被服务
  • 只有队伍最前面的人会在服务结束后离开队伍

那么这就是一个比较典型的队列了

这里给出一种队列的链表实现（这里我们假设队列始终不会空）：

  1. struct Node{
  2.          int val,nxt;
  3. }list[n];
  4. int cnt = 0;//当前节点总数
  5. int head=0,tail=0;//当前链表的头和尾
  6. void insert(int x){//向队列中加入元素
  7.     list[++cnt].val = x;
  8.     list[tail].nxt = cnt;
  9.     tail = cnt;
  10.     if(head == 0)head = cnt;
  11. }
  12. int front(){//查询队列头的值
  13.         return list[head].val;
  14. }
  15. void pop(){//删除队列头
  16.         head = list[head].nxt;
  17. }

0x10 堆

【模板】堆

题目大意：

你需要支持以下几种操作：

  • 向可重集内加入一个元素
  • 查询集合内最小值
  • 删除集合内最小值

我们认为操作次数为$n$

$n\leq10^6$

首先我们考虑一个暴力算法 每次加入元素时把元素扔到数组的最后面 每次询问时扫一遍数组 每次删除时将最小值所对应的元素设为一个很大的数$inf$

  1. int set[1000010];
  2. int main(){
  3.         int n,cnt=0;//cnt维护当前集合内元素个数
  4.         cin>>n;//cin是c++的一种读入方式
  5.     while(n--){
  6.         int op;cin>>op;
  7.         if(op == 1){
  8.             int x;cin>>x;
  9.             set[++cnt] = x;
  10.         }
  11.         if(op == 2){
  12.             int ans = inf;
  13.             for(int i=1;i<=cnt;i++)
  14.                 ans = min(ans,set[i]);
  15.                    cout<<ans<<endl;//cout为c++的输出方式 endl表示换行        
  16.         }
  17.         if(op == 3){
  18.             int minVal = inf,pos = 0;//pos维护最小值的位置
  19.             for(int i=1;i<=cnt;i++)
  20.                 if(minVal > set[i])
  21.                     minVal = set[i],pos = i;
  22.             set[i] = inf;
  23.         }
  24.     }
  25. }
复制代码

但是我们都知道这样做效率太低了 复杂度可以达到$O(n^2)$ 所以我们要找一个比较优秀的数据结构来解决这个问题

于是就有了堆这种数据结构

堆首先是一颗二叉树 其中的每一个节点有两个儿子：左儿子和右儿子 其中的某个儿子可以为空 也可以两个儿子都为空

当一个节点的两个儿子都为空的时候 这个节点称为叶子节点

当一个节点没有父亲的时候 这个节点称为根节点

同时堆还需要满足对于二叉树中的每一个节点 都需要令其的值小于其左右儿子的值 此时的堆称为小根堆 大根堆就是反过来 其他完全一样

很显然根据堆的这一性质 堆中的最小值就是根

在插入一个元素的时候 首先将它插入到堆的某个叶子结点之后

之后不断将这个元素和它的父节点作比较 如果这个元素小于它的父节点 就交换这两个节点

直到这个元素成为了根或者比父节点大为止

删除元素时首先删除根 然后令一个叶子结点为根 此时我们称这个节点为当前节点

之后不断将当前节点和其左儿子比较 进行和插入元素时类似的操作即可

我并不打算在这里给出堆的代码 其一是堆的代码相对较长 其二是在库中已经有堆的实现了

这个实现在c++下叫做$priority_queue$ 翻译为优先队列

优先队列可以支持以上所提到的几种操作 其内部实现也是堆

在java下 优先队列是PriorityQueue

由于已经有了轮子 所以并不建议自己手写堆 毕竟这个东西有一定的几率写错

滑动窗口

题目大意：

给定一个包含了$n$个数的数列和一个正整数$k$ 你需要求出$n-k+1$个区间$[l,l+k-1]$的最大值和最小值

$n\le 10^6$

我们依然可以写出来一个十分简单的暴力算法：

  1. int arr[maxn],minAns[maxn],maxAns[maxn];//maxn = 1000000
  2. int main(){
  3.     int n,k;cin>>n>>k;
  4.     for(int i=1;i<=n;i++)
  5.         cin>>arr[i];
  6.     for(int i=1;i<=n-k+1;i++){
  7.         minAns[i]=inf,maxAns[i]=-inf;
  8.         for(int j=i;j<=i+k-1;j++)
  9.             minAns[i] = min(minAns[i],arr[j]),
  10.                 maxAns[i] = max(maxAns[i],arr[j]);
  11.     }
  12.     for(int i=1;i<=n-k+1;i++)
  13.         cout<<minAns[i]<<" ";
  14.            cout<<endl;
  15.     for(int i=1;i<=n-k+1;i++)
  16.         cout<<maxAns[i]<<" ";
  17. }
复制代码

然后你仔细一算复杂度 居然达到了$O(n^2)$级别 于是你觉得问题很大

我们发现在我们计算每个区间最大最小值的时候 重复地考虑了许多元素

那么假如我们记录下来每一个区间有可能成为最大最小值的元素的话 是否可以做到高效率解决问题？

当然可以

我们以求区间最小值为例

我们维护一个单调队列 这个队列需要满足从队列头到队列尾单调上升

当我们加入一个元素的时候 我们将队列尾部所有大于等于这个元素的元素全部删掉

当我们删除一个元素的时候 只需要判断队列头是否为这个元素即可

之后队列头就是这个区间的最小值

很显然我们发现这个队列里面的元素是所有有可能作为区间最小值的元素 我们只需要考虑一下怎么证明当我们删除一个元素的时候只需要删除队列头

于是我们对需要删除的元素分为两种情况讨论：

  • 需要删除的元素是队列头

这种情况就直接删除了 没什么好说的

  • 需要删除的元素不是队列头

假如说需要删除的元素不是队列头 那么队列头一定是一个比它小的数

同时我们知道删除的元素是区间最左端还要往左的那个元素

于是我们知道队列头一定是在这个数之后被加入单调队列的

那么按照单调队列的加入方法 这个需要删除的元素早已在加入队列头的时候被删除了 于是不需要再去管他

证毕

  1. int queue[maxn],s=1,t=0;//s t为队列头尾
  2. void add(int x){
  3.     while(t >= s && x < queue[t])t--;
  4.     queue[++t] = x;
  5. }
  6. int front(){
  7.     return queue[s];
  8. }
  9. void pop(int x){
  10.     if(queue[s] == x)s++;
  11. }

0x12 树状数组

【模板】树状数组 1

题目大意：

给出一个包含$n$个数的数列 同时你需要进行m次操作 操作有两种

  • 将数列中的某个数加上$k$
  • 查询数列中$[l,r]$的和

$n,m\le10^5$

我们依然先写出暴力算法的代码

  1. int arr[maxn];
  2. int main(){
  3.     int n,m;cin>>n>>m;
  4.            for(int i=1;i<=n;i++)cin>>arr[i];
  5.     while(m--){
  6.         int op,x,y;cin>>op>>x>>y;
  7.         if(op == 1)arr[x] += y;
  8.         if(op == 2){
  9.             int ans = 0;
  10.             for(;x<=y;x++)ans += arr[x];
  11.             cout<<ans<<endl;
  12.         }
  13.     }
  14. }
复制代码

显然的 这是一个$O(nm)$的算法

在讨论更快的算法前我们需要首先定义一个函数$lowbit$

$lowbit(n)$表示$n$的二进制表达下最低位的1的值

比如说对于$n = 10 = (1010)_2$ 它的$lowbit(n)$就应当是$2$

我们当然可以从最低位开始向上枚举判断当前位是否是1 但是很明显这样做的复杂度会是$O(logn)$的

我们有一个更加简单的做法

首先我们将$n$的二进制翻转（即0变1 1变0 在代码中的操作为$\text{~}n$） 之后我们会发现翻转后的二进制表达中末尾的一串0会变为一串1 最低位的1会变成0

于是我们将这个翻转后的数再加上1 那么原数中最低位的1这时还是1 原数中其他位置的值在新数中都被翻转了

那么。。 我们就可以直接让这两个值做二进制的与（&）操作 得到的值即为lowbit的值

也就是说 $lowbit(n) = n \& (\text~n+1)$

我们还知道将一个数翻转后加一实际上就是求这个数的补码 而这个数的补码一般就是这个数的相反数

所以$lowbit(n) = n\&-n$

那么它有什么用呢？ 我们找一张图过来



对于一个数$i$ $C$就表示了区间$[i-lowbit(i)+1,i]$这段区间的和

我们称$i$被$j$直接管辖 当且仅当$j$为最小的$j$使得$i\in[j-lowbit(j)+1,j]$

我们会发现这个$C$数组很像一棵树 于是这个算法叫做树状数组

之后我们分两种操作讨论

第一是单点修改

我们会发现一个点$i$被$i+lowbit(i)$ 管辖 那么也就是说当我们修改$i$的时候 要顺便把$i+lowbit(i)$修改掉

我们又发现$i+lowbit(i)$也有可能会被另一个点管辖 于是我们还需要把另一个点修改掉

显然每一个点都会被管辖 那么我们在当前修改的点的下标大于$n$的时候结束就好了

  1. void modify(int pos,int v){
  2.     A[pos] += v;
  3.     while(pos <= n){
  4.         C[pos] += v;
  5.         pos += lowbit(pos);
  6.     }
  7. }
复制代码

每一次修改时$lowbit$的值都至少为上一次修改的$lowbit$值的二倍 所以这个过程最多进行$logn$次

于是修改的时间复杂度是$O(logn)$

第二是区间查询

或许在你看到这个操作名称的时候你想到的是查询$[l,r]$的和

但是事实上树状数组只能查询$[1,x]$的和 想要查询$[l,r]$的和需要用$[1,r] - [1,l-1]$

那么我们怎么查询$[1,x]$呢？ 我们发现$x$代表了$[x-lowbit(x)+1,x]$的和 那么我们把这段累加入答案

之后再求出$[1,x-lowbit(x)]$就好了 直到求的区间为$[1,0]$时结束这个过程

  1. int query(int x){
  2.     int ans = 0;
  3.     while(x){
  4.         ans += C[x];
  5.         x -= lowbit(x);
  6.     }
  7.     return ans;
  8. }
复制代码

进行查询的次数实际上就是$x$中1的个数 而我们直到这个值一定在$logx$左右

于是进行查询的时间复杂度也是$O(logn)$的

之后我们就得到了一个修改和查询均为$O(logn)$复杂度的优秀算法

那么对于这个题 这个做法的复杂度就是$O(mlogn)$ 可以过

思考： 假如我的两个操作分别为将区间内所有元素加上$k$和查询某个点的值 该怎么做?

题目连接【模板】树状数组2

0x13 线段树

树状数组是个好东西 可以让我们完成一些对于数列的操作

但是当我们需要进行的操作比较复杂时 树状数组就可能会变得难以使用

【模板】线段树1

题目大意：

$n$个数$m$个操作

  • 将区间内的每个数加上$x$
  • 求区间内所有数的和

$n,m\le 10^5$

这题当然也可以用暴力来写一个$O(nm)$的做法 不过这里不再给出代码

你也可以用树状数组把每个操作的区间中的每个数都暴力进行修改操作

但是这样做的复杂度高达$O(mnlogn)$ 它比暴力还慢

所以我们可以换一种做法做树状数组 使得它支持区间操作和区间求和

但是这与线段树并没有什么关系 如果你想要了解这个做法可以参考这篇博客

这道题最简单的做法是线段树

线段树是一种能够在比较高效的时间内解决区间问题的数据结构

首先 线段树是一颗二叉树 每一个节点表示一个区间$[l,r]$

我们定义$mid = \left|\frac{l+r}2\right|$

那么对于一个不是叶子结点的节点 其左儿子的区间为$[l,mid]$ 右儿子的区间为$[mid+1,r]$

于是线段树的深度大约在$logn$左右

每个节点可以维护这个区间对应的信息 在本题中就是这个区间的和

如果我们将它表示成一张图 那么它就长成这个样子



当我们修改一个点$i$的时候 我们可以从根开始不断递归寻找区间为$[i,i]$的叶子结点 并将路径上的所有节点维护的信息修改掉

当我们查询一个点$i$的时候 我们可以递归寻找这个叶子结点 这个叶子节点的值就是答案

但是如果只拿线段树来做单点修改单点查询是非常没意义的事情

我们来考虑怎么快速做区间修改和区间查询

以上面这颗线段树为例 假如我们需要修改区间$[3,7]$ 那么我们实际上只需要找到所有包含了这几个点的区间做修改即可

然后我们写出了一段代码

  1. int val[maxn*10],lson[maxn*10],rson[maxn*10];
  2. //val表示这个节点代表的区间的和 lson和rson分别代表这个节点的左右儿子
  3. //线段树上最多会有大概n*4个节点 这里开到n*10只是习惯问题
  4. void modify(int rt,int l,int r,int x,int y,int v){
  5.     //rt是当前节点在线段树上的编号 lr是这个节点的区间 xy是操作区间 v是操作数
  6.     if(l == r){val[rt] += v;return;}
  7.     // 如果已经递归到一个点了 直接修改值就可以结束递归了
  8.     int mid = (l+r)>>1;//(l+r)>>1 等价于 (l+r)/2
  9.     if(mid >= x)modify(lson[rt],l,mid,x,y,v);
  10.     //如果当前节点的左儿子含有操作区间的一部分 就去递归左儿子
  11.     if(mid < y)modify(rson[rt],mid+1,r,x,y,v);
  12.     //右儿子同理
  13.     val[rt] = val[lson[rt]] = val[rson[rt]];
  14.     //当前节点的值就应该是左儿子的值加上右儿子的值
  15. }
复制代码

然后我们来考虑怎么求一个区间的和

再以区间$[3,7]$为例 我们可以将里面每个数搞出来然后求和 但是这没有必要

因为$[3,7] = [3,3] + [4,5] + [6,7]$

于是我们只需要求出这些区间的值再求和就可以了

所以我们又写出了一段代码

  1. int query(int rt,int l,int r,int x,int y){
  2.     if(x <= l && r <= y)return val[rt];
  3.     //如果当前节点被查询区间完全包含 可以直接返回当前节点的值
  4.     int mid = (l+r)>>1,ans = 0;
  5.     if(mid >= x)ans += query(lson[rt],l,mid,x,y);
  6.     if(mid < y)ans += query(rson[rt],mid+1,r,x,y);
  7.     return ans;
  8. }
复制代码

现在我们只剩下了一个问题 如果我们有原数列$raw$ 我们怎么构建出这棵线段树？

所以我们又写了一段代码

  1. int cnt = 0;//表示节点个数
  2. void build(int &rt,int l,int r){//&是c++中的传址
  3.     rt = ++cnt;
  4.     if(l == r){val[rt] = l;return;}
  5.     else{
  6.         int mid = (l+r)>>1;
  7.         build(lson[rt],l,mid);
  8.         build(rson[rt],mid+1,r);
  9.         val[rt] = val[lson[rt]] + val[rson[rt]];
  10.     }
  11. }
复制代码

之后我们需要做的是分析复杂度

从最简单的build开始分析 显然build会访问所有节点 而节点数大约在$4\times n$左右 所以build是$O(n)$的

然后是query 每个查询的区间总可以分解成大约$log(r-l+1)$个区间后求和 于是复杂度是$O(logn)$的

最后是modify 我们会发现按照我们的写法modify会需要覆盖包含$[l,r]$中元素的所有节点 于是这个操作的复杂度可以达到$O(n)$

然后我们就发现modify让我们的操作十分不爽 它太慢了

我们需要考虑一种让modify和query一样优秀的做法 能不能像query一样把操作区间也分成$logn$个小区间然后只对这几个区间进行操作呢。。？

我们最大的问题是 如果将一个节点修改以后就不再递归 那么它的儿子怎么办？

但是。。 如果我们在一个节点上打上一个标记 表示这个节点的所有儿子都需要加上这个标记的话。。 是不是就可以得到一个高效的算法。。？

可是如果打标记以后 我要查询的区间并不完全包含这个打标记的节点 就会导致query十分麻烦

那么 我们将标记下传不就好了！

于是你定义$tag$为标记数组 并写出了下传标记的函数

  1. void pushdown(int rt,int l,int r){
  2.     if(!tag[rt])return;//如果没有标记就不用下传了
  3.     tag[lson[rt]] += tag[rt];tag[rson[rt]] += tag[rt];//更新左右儿子的标记
  4.     int mid = (l+r)>>1;
  5.     val[lson[rt]] += tag[rt] * (mid-l+1);
  6.     val[rson[rt]] += tag[rt] * (r-mid);//维护左右儿子的区间和
  7. }
复制代码

并且你将modify改成了这样

  1. void modify(int rt,int l,int r,int x,int y,int v){
  2.     if(x <= l && r <= y){
  3.         tag[rt] += v;val[rt] += (r-l+1)*v;
  4.         return;
  5.     }
  6.     //...
  7. }
复制代码

然后问题就来了 你应当在什么时候下传标记？

很明显的标记下传少了的话会导致答案出错 但是标记下传多了只是会让算法的常数大那么一丢丢丢

所以你可以直接在modify和query函数的开头下传标记

复杂度$O(logn)$达成！
