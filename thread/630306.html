RT，如何禁止玩家使用Residence领地的PVP保护功能？
指令为/res set pvp false 效果为PVP保护(无法在领地内PVP)，如何禁止使用该功能？

作者: huwei5201314789    时间: 2016-9-2 21:55
找到你的领地配置文件夹打开flags.yml

  1.   FlagPermission:
  2.     move: true
  3.     build: true
  4.     place: true
  5.     destroy: true
  6.     use: true
  7.     container: true
  8.     pvp: false  ###找到这里，将原本的“true”改成“false”即可
  9.     tp: true
  10.     ignite: true
  11.     firespread: true
  12.     bucket: true
