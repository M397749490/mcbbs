斜体特性在最新的1.13craftbukkit服务端中已经取消，已不再需要使用NMS方法。


或许有人已经注意到，将1.12的插件修改升级至1.13后，插件用item.getItemMeta().setDisplayName()这个方法修改物品名称后物品名字会自带斜体，就算用§r也无法取消斜体，下面是这种情况的一个例子：

代码部分：
  1. ItemStack item = new ItemStack(Material.DIAMOND);
  2. ItemMeta meta = item.getItemMeta();
  3. meta.setDisplayName("§a§lTest");
  4. item.setItemMeta(meta);
  5. player.getInventory().addItem(item);

也许有些人觉得这种改变没啥，但是对我来说斜体远不如正常的好看_(:з」∠)_，所以我查了查nms的相关内容，找到了一种解决办法：

代码部分：
  1. ItemStack item = new ItemStack(Material.DIAMOND);
  2. net.minecraft.server.v1_13_R1.ItemStack nbtitem = CraftItemStack.asNMSCopy(item);
  3. IChatBaseComponent comp = ChatSerializer.a("{"text":"§a§lTest"}");
  4. nbtitem.a(comp);
  5. player.getInventory().addItem(CraftItemStack.asCraftMirror(nbtitem));
复制代码

如果要修改的物品名字较多，比如背包菜单那种，可以写一个方法：
  1. private ItemStack setDisplayName(ItemStack item, String name) {
  2.     net.minecraft.server.v1_13_R1.ItemStack nbtitem = CraftItemStack.asNMSCopy(item);
  3.     IChatBaseComponent comp = ChatSerializer.a("{"text":""+name+""}");
  4.     nbtitem.a(comp);
  5.     return CraftItemStack.asCraftMirror(nbtitem);
  6. }
