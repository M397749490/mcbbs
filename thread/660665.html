标题: 关于多世界插件不同世界加载不同权限。
不知道是不是多世界的原因，无论给玩家权限/称号都是，每个世界都像是独立的一样，给玩家权限要挨个世界给一遍，称号也是，寻求解决办法。

就是比如你在地皮世界给了玩家地皮权限，玩家去了主世界，结果就会显示权限不足。
比如在地皮世界给了玩家一个称号，去了其他世界称号会消失
求解决方案，详细点。
作者: Joket_abc    时间: 2017-1-8 18:58
假设要区分权限的世界为 World(主世界) 和 Mine(矿界) 。
1、打开 GroupManager 的配置文件 config.yml
在里面修改
  1.   mirrors:
  2.         world:
  3.           mine:
  4.           - users     #表示mine的用户数据使用world的用户数据，独立称号、独立权限都在内
复制代码
例如下面这样
  1.   mirrors:
  2.         world:
  3.           world_nether:
  4.           - users
  5.           - groups     #表示mine的用户组使用world的用户组，共用称号，共用权限在内
  6.           world_the_end:
  7.           - users
  8.           - groups
  9.           all_unnamed_worlds:
  10.           - users
  11.           - groups
  12.           mine:
  13.           - users
