有人想问，这个插件是什么
特征：
禁止掉落[不允许玩家扔物品]此插件禁止所有玩家扔掉物品
[创造模式除外][可设置]
[此插件可以禁止创造玩家扔东西被生存玩家捡到]
[不允许扔物品]
[有效防止玩家不小心扔掉物品到岩浆]


指南：
1.下载AntiDrops 2.对应版本下载 3.放进plugins文件夹
4.启动服务器 5.修改settings文件夹


权限：
可以将settings.yml文件夹自定义，允许玩家掉落
如果你将settings.yml设置为true，那么玩家允许掉落
默认为antidrops.bypass禁止掉落


命令：没有


配置文件夹[config]
  1. config:
  2.   version: 0.5
  3. creative-only: true
  4. bypass:
  5.   use: false
  6.   permission: antidrops.bypass
  7. block:
  8.   creative:
  9.     chest-use: true[掉落允许][false允许掉落]
  10.     death-drops: true[掉落允许][false允许掉落]
  11.     signs: false
  12.   survival:
  13.     death-drops: false[掉落允许][默认false][请改为true不允许掉落]
  14.   adventure:
  15.     death-drops: false[掉落允许][默认false][请改为true不允许掉落]
  16. dev:
  17.   debug: false
  18. remove-item: false
  19. deny-drops: true
  20. deny-pickup: true
  21. no-block-drops: false
  22. [全版本请用1.5.1插件版本]
