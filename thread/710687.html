Rolecraft是什么?


Rolecraft是由德国友人caliog开发的RPG娱乐向插件，从前身MyRPG到现在的Rolecraft作者一直都在持续的积极更新。
简单来说，Rolecraft是一个非常完善的RPG系统，包含种族、技能、任务系统、自定义怪物和自定义武器道具系统。
该插件与其它RPG向插件的兼容性有待测试(mm/skillapi/magicspells等,后期会一一测试。）

一般指令
  
权限节点
描述
/rolecraft
none
显示插件版本
/rolecraft  help
none
显示可用的指令列表

rc.reload
重载 插件配置和语言文件
/rolecraft  mic
rc.mic
Try to install  the Mobs & Items Creator!
/rolecraft  backup
rc.backup
创建一个备份文件plugins/rolecraft/Data/Backups!
/rolecraft  class [player]
rc.class

/level  set <player> <level>
rc.level.set
更改玩家等级
/level  reset <player>
rc.level.reset

rc.level.reset
给予指定RPG物品(given level 选项需开启.)
