作者: jimmy1234    时间: 2016-5-7 09:53
首先输入/scoreboard objectives add a dummy (a=计分板名称，可以自拟)
然后放置一个命令方块输入
/scoreboard players set @e[type=Item] a 1 {Item:{id:"minecraft:cooked_porkchop"}}
再然后 输入
/kill @e[score_a_min=1,score_a=1]
将这两个都接上高频
那么这样就可以删除熟猪肉啦
其他的？
把/scoreboard players set @e[type=Item] a 1 {Item:{id:"minecraft:cooked_porkchop"}}中的
cooked_porkchop换成其他你要删掉的物品英文名就ok了
比如/scoreboard players set @e[type=Item] a 1 {Item:{id:"minecraft:porkchop"}}
如果你不想当他一下子出来就没掉的话
就别把/kill @e[score_a_min=1,score_a=1]接上高频
