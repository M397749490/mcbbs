介绍


本插件可以用来检测玩家是否有使用杀戮光环(Killaura)，其原理为：作弊玩家能够自动击打周围实体，机器人也会被击打，当击打到一定程度时，会触发处罚

配置文件（慢慢汉化，非常易懂）
# The nicknames of bots
# '%random' is a generated random code causing one player to deal with a differently named bot every time
# '%random' takes the form of a number 10000000-99999999
BotsNicknameFormat: '&c[DWEN]&e%random'

# Will bots be visible
BotsVisible: true

# Where bots will appear
# true - behind the players
# false - randomly around the players (not recommended if bots are visible)
BotsAppearance: false

# How far from the player should the bots appear
DistanceFromThePlayer: 2

# How often control is carried out on players (in seconds)
CheckingFrequency: 20

# How long will the bot appear? (in ticks. 1 = 1/20 sec, 2 = 1/10 sec, 5 = 1/4 sec etc.)
BotTimeToRemove: 12

# Send suspicion to the administration (sh.suspicion)
SendSuspicion: true

# Contents of the report
Raport: '&5[DWEN] &cThe player &4%player may cheating now! Check Result:&8(&6%bothits&8)'

# What command will be called to punish the player
PunishingCommand: 'tempban %player 10m NA01DABA'

# If reason of ban is a killaura, will be determined in this way
AuraReason: 'KillAura'

# If someone without permissions trying to use a ban or kick command (sh.kick, sh.ban)
NoPerms: '&fYou must be &cOWNER &frank to use that!'

# If the player you want to refer to is offline
OfflinePlayer: '&cThis player is not online!'

# The ejected player will see this message if he is kicked by admin
ManualKickFormat:
- '&cYou have been kicked out of the server by &4%nick&c!'
- '&cReason: &6%reason'

# The ejected player will see this message if he is kicked by antycheat
AutoKickFormat:
- '&cYou were automatically kicked out of the server!'
- '&cReason: &6%reason'

# The ejected player will see this message if he is banned by admin
ManualBanFormat:
- '&cYou have been permanently banned by &4%nick&c!'
- '&cReason: &6%reason'
- '&cDate: &6%date'

# The ejected player will see this message if he is banned by antycheat
AutoBanFormat:
- '&cYou have been automatically banned by AntyCheat!'
- '&cReason: &6%reason'
- '&cDate: &6%date'
# Banned player will see this message when trying to enter the server
LoginBanInfoFormat:
- '&cYou are banned on this server!'
- '&cDate: &6%date'
- '&cBan type: &6%type'
- '&cReason: &6%reason'
