SimpleHarvest
简单收获


简介
你觉得手动采集过于麻烦了？
你觉得再种植也麻烦了？
来试试这个吧 用右手点击就是收获！

添加可通过JSON文件配置的右键单击农作物收割
自1.9.4-7的1.0.1-7版及更高版本开始，客户端可以不用装此mod
如果不装 玩家收割后会缺少原本应有的手臂摆动的动画
也就是这个版本后服务器装就可以实现大部分功能

配置文件
  1. { "exhaustionPerHarvest": 0.005, "additionalLogging": true, "crops": [ { "block": "minecraft:wheat", "states": { "age": "7" } }, { "block": "minecraft:nether_wart", "states": { "age": "3" } }, { "block": "minecraft:carrots", "states": { "age": "7" } }, { "block": "minecraft:potatoes", "states": { "age": "7" } }, { "block": "minecraft:beetroots", "states": { "age": "3" } } ] }
复制代码
附加配置
为了使Harvest支持作物，它必须能够在其下拉列表中找到种子。要指定新的种子类型，请使用数据包在Harvest：seeds item标签中定义新的种子项目。

对于开发者
如果您的农作物需要特殊的收割处理，则可以通过Harvest.CUSTOM_HANDLERS为它注册一个自定义的IReplantHandler。
