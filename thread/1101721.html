1. 找到RES文件夹
2. 找到groups.yml文件
3. 修改下列世界设置如我这样
       Flags:
          Permission:
          Default:
          CreatorDefault:
          GroupDefault:
          World:
                Global:
                   #build: true
                sc1:
                    build: false
                sc2:
                    build: false
                sc3:
                    build: false

bulid 就是建筑权限，false就可以关闭玩家的默认建筑权限了必须通过圈地才能开发
