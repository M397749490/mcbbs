打开res
打开groups.yml
找到
Global:
       Default: #组的名字
          Residence:
              # 是否可以创建领地
              CanCreate: true
              # 玩家可以拥有的领地数量最大值
              MaxResidences: 3
              # 领地可包含的最大物理区域
              MaxAreasPerResidence: 2
              # 领地最大格数（东西方向）
              MaxEastWest: 160000000000
              # 领地最小格数（东西方向）
              MinEastWest: 3
              # 领地最大格数（南北方向）
              MaxNorthSouth: 16000000000000
              # 领地最小格数（南北方向）
              MinNorthSouth: 3
              # 领地最大格数（高度）
              MaxUpDown: 256
             # 领地最小格数（高度）
              MinUpDown: 3
          Economy:
              # 购买领地的价格（每格）
              BuyCost: 0.5这些东西
然后把红色的字体一修改
(我只是夸大的修改了下，你可以设置小点）
然后重启即可
