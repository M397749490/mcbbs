  1. 命令：
  2. # 帮助
  3. /re help
  4. # 使用配置文件中的设定重启服务器
  5. /re restart
  6. # 使用配置文件中的设定关闭服务器
  7. /re stop
  8. # 立即重启服务器
  9. /re restart now
  10. # 立即关闭服务器
  11. /re stop now
  12. # 过多少分钟后重启服务器
  13. /re restart time <分钟>
  14. # 过多少分钟后关闭服务器
  15. /re stop time <分钟>

  17. 分钟支持用小数表示，比如0.1
复制代码


已知bug：
stop后的提示信息不是关闭服务器而是重启服务器= =真渺小的错误


  1. 配置：
  2. 好像没什么好说的- -
  3. # 重启时间（上面的restart和stop命令用到的时间，单位：秒）
  4. rt: 300
  5. # 是否打开自动重启
  6. arenable=false
  7. # 自动重启间隔（单位：分钟）
  8. armin=60
复制代码

  1. 权限：
  2. re.restart
  3. re.stop
  4. re.restart.now
  5. re.stop.now
  6. re.restart.time
  7. re.stop.time
复制代码


下载完成后是一个压缩包，直接解压到服务器根目录就行了，使用Start_RestartEvolution.bat开启服务器
