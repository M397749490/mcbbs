IP  网络地址。

端口  可以认为是设备与外界通讯交流的出口。端口可分为虚拟端口和物理端口，其中虚拟端口指计算机内部或交换机路由器内的端口，不可见。

VPS 一台虚拟的服务器[也可以理解为虚拟电脑]

内网IP 内网不属于公共网络，属于私人网络，理论外界不可访问。内网IP及这个网络的分支。也可以理解为内网是一个家，IP就是这个家的门。

外网IP 公共网络，他人可以直接访问该IP的任何一个端口[前提是该端口开启了，防火墙没有锁端口]

Windows 全世界最著名的桌面操作系统。

Linux 一种系统内核，其下有许多分支，例如 Ubuntu centOS Debian等等。

核心 类似一个系统的主要部分，在本文中指服务器核心。Minecraft基岩服务器的所有方块|数据|命令 等，都是由它接受处理并转发给插件处理。若核心和插件冲突时，优先以插件处理。

Java 一种计算机语言，Minecraft Java版就是围绕它来写的。同时，Java是跨系统的编程语言。

映射 2.指端口映射出来的端口，把电脑A的xxxxx端口映射到公网IP上的xxxxx端口，这个过程就叫映射。
