老虎机~~~黑杰克~~~！！！
这是一个允许玩家在游戏中开设赌场进行赌博的插件

从1.4.6-1.5.1都支持=。=

虽然赌博不好{:10_553:}但是这插件确实很好~~~
前置插件：vault


虽然是两个插件，但是性质相同，作者也相同，我就懒得另开帖子了


可以分开使用，SC_Slots.jar是老虎机，SC_Blackjack.jar是黑杰克


没有玩过这俩游戏的自行科普= =

默认只有op能摧毁赌场，不管是不是创造模式

如果一个世界不是在赌场插件加载之前就存在，那么在那个世界赌场会崩溃

老虎机：

木牌第一行输入：[slots]
木牌第二行是玩家每次投注的金额
木牌第三行是你投入赌博机的本金（选填）

黑杰克：

木牌第一行输入：[blackjack]
木牌第二行是你投入赌博机的本金（选填）
木牌第三行是玩家最大下注金额（选填，但是当填写了这行时，第二行也必须填写，否则默认未填）

服务器赌场分别是[slots]和[blackjacks]


投注时左键增加投注额，右键投注

木牌打碎后剩余本金会自动回到账户来

主要使用左键右键操作，别点错了= =

默认都是op权限

# 管理（老虎机和黑杰克）
  sc.admin



---------------------------------------slots老虎机---------------------------------------

命令：

  1. 命令：

  3. # 显示赌场信息
  4. /slots info
  5. # 为赌场注入资金
  6. /slots deposit <金额>
  7. # 从赌场取出本金
  8. /slots withdraw <金额>
  9. # 保存数据
  10. /slots save
  11. # 加载数据
  12. /slots load
复制代码


权限：

  1. # 创建赌场
  2.   sc.slots.create
  3. # 创建服务器赌场
  4.   sc.slots.createserver
  5. # 拆除赌场
  6.   sc.slots.delete
  7. # 查看赌场信息
  8.   sc.slots.info
  9. # 从赌场取出本金
  10.   sc.slots.withdraw
  11. # 为赌场注入资金
  12.   sc.slots.deposit
  13. # 保存数据
  14.   sc.slots.save
  15. # 加载数据
  16.   sc.slots.load
复制代码


配置：

  1. 配置：

  3. config.yml

  5. partial-win:
  6. # 部分胜利
  7.   active: false
  8. # 乘数
  9.   multiplier: 1.0
  10. # 摇滚速度
  11.   roll-speed: 20
  12. # 奖金倍乘
  13.   multiply-winnings: true
  14. # 当赌场本金不足以支付的时候，从所有者账户扣除
  15.   subtract-overcost: true
  16. # 当插件禁用的时候保存赌场数据
  17.   save-on-disable: true
  18. # 当改变或完成一桌赌局的时候保存数据
  19.   save-on-slot-change: false
  20. # 是否直接连接到所有者账户
  21.   linked-to-accounts: false
  22. # 全部本金
