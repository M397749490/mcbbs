  1. ; Comma separated list of blocks and items which should not be turned into scrap by the recycler.
  2. ; Format: <name>[@metadata], metadata * matches any.
  3. ; Ore dictionary entries can be specified with OreDict:<ore dict name> as the name.
  4. recyclerBlacklist = minecraft:glass_pane, minecraft:stick, minecraft:snowball, minecraft:snow_layer, minecraft:snow, IC2:scaffold
复制代码


▲ 格式
  1. recyclerBlacklist = <物品名称>[@数据值]
复制代码
用 * 作为数据值来表示所有数据值
多个物品之间使用英文逗号和一个空格隔开（编辑这种文本不要用中文输入法）
如果要用矿物辞典，则用 OreDict:<矿辞名称> 表示


▲ 例
  1. recyclerBlacklist = minecraft:stick, minecraft:wool@*, minecraft:stone@1, IC2:scaffold@0, OreDict:ingotIron
复制代码
此时回收机黑名单有：原版的木棍、所有颜色的羊毛、花岗岩，IC2的脚手架（普通木质），以及所有标记着铁锭矿辞的物品（如原版铁锭）


注意：上述是较新版本的配置文件，如果是老版本可能会有不同
