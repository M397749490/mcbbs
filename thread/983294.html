DamageParticle
减少受伤粒子数量
介绍：该类型插件在bbs有了一款，但是在1.13以上的版本无法使用，有人找我弄个1.13以上的，我就安排了，其中莫老帮助了我（@602723113 ）
功能:
  • 减少受伤后显示的黑心粒子数量
  • 可自定义限制数量
  • 可限制伤害范围增加心或减少
配置文件:
config.yml
  1. # 默认配置
  2. # 1000以下伤害显示一颗心 1000以上 每满1000伤害增加一颗心
  3. scale: 1000
  4. # 伤害显示基数 (默认最低显示3颗心)
  5. baseValue: 3
