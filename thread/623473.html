作者: Mc_worm    时间: 2016-8-19 14:36
是cc插件的话应该是更改启动指令。我类似的就是像一下这种情况、
主菜单：v11576:
                COMMAND: 'shop'
                NAME: '&b[**]&b商店'
                LORE:
                - '打开商店'
               ID: Diamond
               POSITION-X: 1
               POSITION-Y: 1

以上的概念是使用此键位将开启使用shop指令。那么我们就可以根据主菜单更改子菜单的启动指令。


menu-settings:
            name: '系统商店'
            rows: 1
            command: 'shop'
            auto-refresh: 5
            open-action: 'sound: note pling; tell: &eYou opened the example menu.'
        open-with-item:
           id: Book
           left-click: false
           right-click: true

当我们设置好的时候理论上是可以开启的
但是还是不行请把  KEEP-OPEN: false 改为   KEEP-OPEN: ture

这个选项的意思是是否保持开启。
另外保证所有的配置文件段的名字差异，菜单文件的名字也要注意，因为CC这个插件的指令是很注重大小写这个细节的。
