ServerNick

某人觉得[net.minecraft.server.dedicated.DedicatedServer]太长了,于是有了这个插件.
适用于SpongeForge-1.12.2

其实修改log4j2的配置文件也可以实现类似的效果，使用解压软件打开forge-1.12.2-14.23.4.2705-universal.jar、
将其中的log4j2.xml复制到根目录，使用文本编辑器编辑 %logger -> %logger{1}
那么输出的效果就由[net.minecraft.server.dedicated.DedicatedServer] -> [DedicatedServer]
参考:http://logging.apache.org/log4j/2.x/manual/layouts.html

源代码

  1. @Plugin(id = "servernick")
  2. public class ServerNickPlugin {
  3.     @Inject
  4.     private Logger logger;
  5.     @Inject@ConfigDir(sharedRoot = true)
  6.     private Path configDir;
  7.     @Listener(order = Order.PRE)
  8.     public void onPreInit(GamePreInitializationEvent event) throws IOException, NoSuchFieldException, IllegalAccessException {
  9.         Path configPath = configDir.resolve("ServerNick.conf");
  10.         Sponge.getAssetManager().getAsset(this,"default_config.conf").get().copyToFile(configPath,false);
  11.         ConfigurationNode node = HoconConfigurationLoader.builder().setPath(configPath).build().load();
  12.         String nick = node.getNode("servernick","nick").getString("Server");
  13.         Field loggerField = ReflectionHelper.findField(DedicatedServer.class,"LOGGER","field_155771_h");
  14.         loggerField.setAccessible(true);
  15.         org.apache.logging.log4j.core.Logger origin = (org.apache.logging.log4j.core.Logger) loggerField.get(null);
  16.         Field nameField = org.apache.logging.log4j.spi.AbstractLogger.class.getDeclaredField("name");
  17.         nameField.setAccessible(true);
  18.         nameField.set(origin,nick);
  19.     }
  20. }
