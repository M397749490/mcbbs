地皮的大小就是配置文件里面的config
  • <font size="5">worlds:
  •   plotworld:
  • # 世界的名称
  • # 你可以拥有多个地皮世界
  •     PlotAutoLimit: 1000
  • # 使用/plot auto （自动领取地皮指令）的搜索范围 默认是1000
  • # 如果是1000，表示搜索范围是1000*1000，如果这个范围没有空闲地皮，就好显示一个错误
  •     PathWidth: 7
  • # 这是路径包括地皮路的宽度 默认是7
  •     PlotSize: 32 （这个是你要修改的）
  • # 地皮的大小，默认是32
  • # 如果是32，则表示每块地皮的大小事32*32即1024个格子
  •     BottomBlockId: '7'
  • # 这是地皮世界的底部，默认是基岩（7）


给予玩家领取地皮的权限指令是
/mangaddp default plotme.use   （这个是领取权限）
/mangaddp default plotme.limit.X   （这个后面的”X“可以改成1，这样玩家的领取上限就是1块地皮了）
