工作理念
Core系统是伺服器的基础，它提供了最基础的功能，如封禁玩家以及管理列队
所有其他更具体的功能可以根据需要选择Core系统

XCore于ESS的不同之处在于，ESS仅提供了大量的功能，使得管理员工作更轻松

但ESS不提供 官方API ，也不是一个真正的伺服器管理系统

  但是XCore提供了更多功能！

插件语言
XCore作为多语言插件开发，您可以自定义每条信息，插件也内置了英，德，法三种语言
权限
插件每个指令都有单独的权限

XCore.*  可以使用所有XCore功能
XCore.cmd.* 可以使用所有XCore命令

如果希望可以获得所有权限，可以使用指令：/gruop set ID Admin (BC通用)
如果想要了解全部权限和其他的小东西可以点击这里(这和那个"wiki"不一样吗)


API
使用XCoreAPI,您可以自定义XCore的全部，并且可以与其他插件一起使用
这项功能目前还在开发当中(鬼知道作者为什么要列出来)
其他的东西
XCore内置了屏蔽指令系统，它将屏蔽一些关于玩家可以获取您伺服器信息的一些指令
就像是/Help或/Ver
您只需要在BC和Spigot安装XCore即可使用
当然，您也可以在单个Spigot安装
