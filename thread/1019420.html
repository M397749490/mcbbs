ActionPoints
更多功能的玩家活跃度插件



★》简 介《★
ActionPoints是一款类似于网游中活跃度点数功能的一款插件
安装本插件可以使玩家在游玩时通过一些进行一些游戏操作来获得活跃点数
当活跃点数达到设定的标准时即可执行对应的奖励指令
这样一来会缓解玩家上线后无所事事的状态
使你的玩家更为活跃

该插件为付费插件|价格为3EUR|约合人民币24元

★》功能《★

  • Mysql支持
  • 活跃等级系统(测试版暂不推荐使用)
  • 高度自定义性(自定义每种操作给予的详细点数)
  • 可通过回答问题来获得活跃点
  • 每日活跃点礼包、每15分钟可打开一次的活跃包裹
  • 支持多种类型(破坏、放置、附魔、铁砧修复、合成、聊天、执行特定指令、吃东西等)
  • 自定义活跃分数阶段及其对应的自定义奖励指令
  • 内置给予活跃点数的指令,可配合菜单或其他插件拓展更多玩法
  • 刷分保护(每种游戏行为都有其对应的防刷分设置)
  • 其他插件支持(SuperLuckyBlock、FactionsUUID、ASkyBlock、GriefPrevention等)
  • 支持死亡扣分
  • 支持变量
  • 开发者文档javadoc|API文件

★》指令/权限/变量《★

  • /actionpoints help - 查看插件帮助
  • /actionpoints balance [玩家名] - 查看玩家当前的活跃点
  • /actionpoints give <玩家名> <数量> - 给予玩家指定数量的活跃点
  • /actionpoints reset <玩家名> - 重置玩家的活跃点
  • /actionpoints set <玩家名> <数量> - 设置玩家的活跃点为指定数量
  • /actionpoints beg - 打开活跃点包裹
  • /actionpoints daily - 领取每日活跃点
  • /actionpoints trivia - 通过答题获得活跃点


  • /apadmin help - 显示管理员命令
  • /apadmin reload - 重载插件
  • /apadmin addquestion - 添加自定义答题


  • actionpoints.help - 允许使用指令/actionpoints help
  • actionpoints.give - 允许使用指令/actionpoints give
  • actionpoints.take - 允许使用指令/actionpoints take
  • actionpoints.reset - 允许使用指令/actionpoints reset
  • actionpoints.set - 允许使用指令/actionpoints set
  • actionpoints.admin - 允许使用管理员指令
  • actionpoints.balance - 允许使用指令/actionpoints balance
  • actionpoints.balance.others - 允许使用指令/actionpoints balance查看其他玩家的活跃点
  • actionpoints.norewards - 禁止拥有该权限的玩家或权限组获得活跃点奖励


  • %actionpoints_balance% - 显示当前拥有的活跃点数
  • %actionpoints_fullrank% - 显示当前活跃等级的全称
  • %actionpoints_rankprefix% - 显示当前活跃等级的前缀
