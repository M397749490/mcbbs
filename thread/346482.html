简介:

他的用途?:
他适合使用了自动发卡平台的服务器


使用2.0版本请更新配置文件

该插件相关版本都有对应暴力试验激活码软件,请配合http://www.mcbbs.net/thread-558656-1-1.html食用

如需执行多个指令,请配合该插件进行食用:

http://www.mcbbs.net/forum.php?mod=viewthread&tid=529767



命令:

玩家指令:
/code <激活码> 使用一个激活码
OP指令:
/code create <激活码条数> <命令> 创建X条激活码,%player%为使用的玩家名字
/code output <文件名>(.txt) <命令> 把符合指定命令的激活码导出到plugins/CommandCode/XXX.txt里面
权限:
CommandCode.create       /code create权限
CommandCode.output       /code output权限

配置文件:
  1. #激活码长度
  2. #最小4
  3. Length: 16
  4. #激活码包含字符
  5. String: 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'
复制代码

Mysql版本配置文件:
  1. #激活码长度
  2. #最小4
  3. #当长度过小时,所有组合都用过了,创建激活码时会陷入死循环
  4. Length: 16
  5. #激活码包含字符
  6. String: 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'
  7. #是否使用数据库
  8. Use_sql: false
  9. #当使用数据库时,你需要填写下面这些内容
  10. database: jdbc:mysql://127.0.0.1:3306/database
  11. username: root
  12. password: 123
复制代码


2.0版本配置文件:
  1. #激活码长度
  2. #最小4
  3. #当长度过小时,所有组合都用过了,创建激活码时会陷入死循环
  4. Length: 16
  5. #激活码包含字符
  6. String: 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'
  7. #是否判断新的激活码已存在
  8. CodeEquals: false
  9. #是否开启验证码功能
  10. EnableEquals: true
  11. #是否使用数据库
  12. Use_sql: false
  13. #当使用数据库时,你需要填写下面这些内容
  14. database: jdbc:mysql://127.0.0.1:3306/database
  15. username: root
  16. password: 123
复制代码
