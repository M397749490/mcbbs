简介
BlueFriends-Reload是BlueFriends的重置版，BlueFriends-Reload几乎重制了老版BlueFriends所有代码和贴图，从实用性的角度出发，致力于为MineCraft服务器提供一个良好的社交系统。
功能
  • 为玩家提供一个清晰的好友列表，通过好友列表可以流畅链接到其他所有界面
  • 假人系统，为玩家提供24小时在线的好友
  • 社交属性齐全，包括QQ、邮箱、头像、头像边框等，可自由设置、浏览
  • OP给所有玩家发送邮件、给符合条件的玩家发送邮件、给特定玩家发送邮件
  • 邮件还可以携带附件(即物品)
  • OP给玩家发送系统消息
  • 提供一个不同于VexView的GUI编写方法
  • ....

指令及权限
指令和权限真的很多，
如果没有耐心又不打算对插件默认的GUI做出很大调整的话可以无视这里。
必要的权限已经默认给玩家了，这里就不把权限列出来了，感兴趣的话自己去插件的plugins.yml里看。
几个最重要的指令摆在前面:
/bfadmin maileditor 打开邮件编辑器界面
/bfreload 重载插件
/bfopen main 打开好友列表
管理员指令:
/bfadmin maileditor 打开邮件编辑器
/bfadmin maileditor set subject [主题] 设置邮件编辑器中正在编辑的邮件的主题
/bfadmin maileditor set content [内容] 设置邮件编辑器中正在编辑的邮件的内容
/bfadmin maileditor set items 设置邮件编辑器中正在编辑的邮件的附件
/bfadmin maileditor save 将邮件编辑器中的邮件保存到数据库中(并没有发出去)
(使用/bfopen 邮件列表.yml指令可以查看全服的邮件，在那个界面可以对保存的邮件进行下一步操作)
/bfadmin maileditor load [uuid] 将UUID为[uuid]的邮件导入到邮件编辑器中
(这里的UUID并不需要手动输入，可以通过papi变量+按钮实现图形化操作)
/bfadmin mail sendto [玩家名] [uuid] 向某玩家发送指定UUID的邮件
/bfadmin mail sendif [条件] [uuid] 向符合条件的玩家发送指定UUID的邮件
(条件的写**在Wiki中说明)
/bfadmin mail sendall [uuid] 向所有玩家发送指定UUID的邮件
/bfadmin mail delete [uuid] 删除指定uuid的邮件
/bfadmin messagebox [玩家名] [内容] 向玩家发送一个指定内容的提示框
/bfadmin message [玩家名] [内容] 向玩家发送一条系统消息
/bfadmin fakeplayer create [名称] [昵称] 创建一个假人
/bfadmin fakeplayer remove [名称] 移除一个假人
/bfreload 重载插件
玩家指令:
/bfopen [GUI文件名/映射名] 打开指定的GUI界面
(文件名就是/gui中的文件名，映射名会在Wiki中解释)
/friend query [玩家名] 查询某玩家的个人信息(假人的也可以查)
/friend apply [玩家名] 请求添加某玩家为好友(如果是假人的话就直接添加好友)
/friend accept [玩家名] 接受某玩家的好友请求
/friend reject [玩家名] 拒绝某玩家的好友请求
/friend delete [玩家名] 将某玩家从好友列表中移除
/person set email [email] 设置电子邮件(将会显示在个人信息界面)
/person set qq [QQ] 设置QQ
...省略
/person editbox [标题] [提示内容] [指令1] [指令2] ... 打开一个自定义编辑界面(打开编辑个人信息的输入框就是用的这个指令，具体用**在wiki中解释)
/person mail view [uuid] 查看指定UUID的邮件(玩家必须要收到了这封邮件才能查看)
/person mail delete [uuid] 将指定UUID的邮件从邮箱中移除(并不会移除数据库中的邮件)
/person mail read [uuid] 将指定UUID的邮件标记为已读
/person mail items [uuid] 领取指定UUID邮件中的附件
/person message view [uuid] 查看指定UUID的系统消息(会弹出一个提示框)
/person message delete [uuid] 删除指定UUID的系统消息


安装方法
单端直接把插件丢到/plugins文件夹即可
群组服需要同时在子端和BC端上安装BlueFriends
如需使用MySQL需要在配置文件config.yml中正确设置MySQL相关信息
不需要手动创建数据库，插件会自动创建好
兼容性
插件理论支持1.7.10-1.13.2(取决于VexView的兼容性)
插件已在1.12.2和1.13.2 Spigot端上测试，数据库用的是xampp搭建的MySQL
各位腐竹使用时如果出现了问题请将日志文件(latest.log)上传到帖子下。
已知BUG
有时会有从数据库中读取的数据为空的现象。
直观体现为Placeholder变量无法解析(因为PlaceholderAPI不会用空字符串替换变量)
