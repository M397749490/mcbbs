插件の简介

Introduction — 简介


  • 无限多的蛇跑酷
  • 当创建蛇跑酷时，需要站在指定的方块上（预设：玻璃块），而且蛇跑酷不能有交叉的地方
  • 如果蛇跑酷没有反应时，可能是蛇跑酷的延迟设置为0或负数，当没有运行服务器时，可以在config.yml配置
  • 过多蛇跑酷时，会造成一定的影响
  • 蛇跑酷并未有保护，建议使用保护插件等（例如：WorldGuard）
  • 作者有在1.8.8上做测试，所以应该可以支持更老的Spigot/Bukkit版本


Installation — 安装


购买并下载插件并丢到服务器内的Plugin文件夹即可，之后开启服务器来生成插件文件。

指令の解说


  1. /Parkour list: 列出所有蛇跑酷列表
  2. /Parkour create <name> [delay]: 创建一个蛇跑酷
  3. /Parkour remove [names]: 删除蛇跑酷
  4. /Parkour delay <delay> [names]: 设置跑酷的延迟速度（ticks计算, 1s=20ticks）
  5. /Parkour destroy [names]: 删除并摧毁蛇跑酷
  6. /Parkour start [names]: 开始一个蛇跑酷
  7. /Parkour stop [names]: 停止一个蛇跑酷
  8. /Parkour info [names]: 查看蛇跑酷资讯
  9. /Parkour tp <name> [block]: 传送至蛇跑酷
  10. /Parkour speed <speed> [names]: 设置蛇跑酷速度
  11. /Parkour addblocks <name>: 开启添加方块模式
  12. /Parkour removeblocks <name>: 开启删除方块模式
  13. /Parkour edit <name>: Edit snake blocks types in a parkour
  14. /Parkour nosnakeblock <name>: Set the nosnakeblock of a parkour
  15. /Parkour finish: 完成跑酷修改设置
  16. /Parkour reverse [names]: 设置蛇跑酷往反方向
  17. /Parkour autoreverse [names] [on/off]: 开关蛇跑酷自动往反方向
  18. /Parkour reloadlf: 重载插件语言文件
  19. /Parkour reloadconf: 重载插件配置文件
