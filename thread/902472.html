HungerGames


这是一个非常简单有趣而十分轻量的饥饿游戏插件。你可能没听过饥饿游戏系列，但是放心，这个插件是免费的。你必须通过寻找食物与装备，杀死其他的对手来活下去，直到只剩下自己一个人，那么你就是胜利者。与其他饥饿游戏插件不同的是，这个插件支持极高的版本，简单而又轻量，最重要的是，他无需你设置整个服务器，你可以在任何地方轻松地创建竞技场。
版本说明：-这个插件只能在1.13以上运行
-这个插件永远不会更新到1.12.2以下


功能：
-能创建多个竞技场
-自动更新大厅标志
-自定义每个竞技场，玩家最大/最小上限
-自定义每个竞技场的计时器
-非常轻量
-不需要单独服务器或世界
-支持Vault经济插件
-竞技场设置方式简单
-竞技场箱子中会出现随机物品
-奖励箱能获得更多东西（单独战利品表）
-允许更多战利品表
-允许玩家近距离观战
-智能怪物生成（更智能的引擎即将推出）
-高度可配置
-自定义工具包
-玩家组队
-完全回滚，回复系统（这个我搞不明白了，查看意思后，感觉更迷了）
-每个竞技场有完全不同的东西
-可定制消息
-支持PlaceholderAPI变量
-边境收缩

  17.     # Minimum amount of items that will spawn in bonus chests

  20.     teleport-at-end: false

  22.     # (note: increments of 30, ex: 30, 60, 90, 120, etc)

  74. # - Will not work if more than 1 arena is in a world, will screw up other arenas

  76. world-border:
  77.     # Enable the world borders for arenas
  78.     enabled: false
  79.     # If true, when the game starts a world border will start just outside of the arena
