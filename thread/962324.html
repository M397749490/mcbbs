MultiTitle
简介
简单方便的GUI操作创建称号 每个称号可以设置 指定药水效果以及等级
自动在头顶 和 聊天栏内 显示称号

命令
/ch OP身份输入则打开 管理菜单
/ch 普通玩家身份输入则打开 称号菜单
权限介绍
请使用权限插件 给予 ch.ID   例ch.0  就是 下面 config 里 ID 为0 的称号
注意事项
本插件 装到plugins文件夹 后 需要重启两次服务端
普通玩家 没有权限佩戴任何 称号
请使用权限插件 给予 ch.ID   例ch.0  就是 下面 config 里 ID 为0 的称号

变量
%title% 所拥有称号 无称号则现实为空格
config
介绍
  1. 素素的好兄弟炮炮:      #创建的称号 如变成彩色 就输入Alt + 167   例: §8[§d素素的好兄弟炮炮§8]  因为NUKKIT不支持&
  2.   id: 0      #称号代表的ID
  3.   description: 这是个介绍     #创建时所设置的介绍
  4.   effect: 1     #创建时锁设置的药水ID
  5.   level: 1      #创建称号时 所设置的药水等级
