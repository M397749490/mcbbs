  1.   public boolean callScript(EnumScriptType type, Object... obs)
  2.   {
  3.         //.......................
  4.     ScriptContainer script = (ScriptContainer)this.scripts.get(Integer.valueOf(type.ordinal()));//获取对应事件脚本容器
  5.         //.......................
  6.     script.setEngine(this.scriptLanguage);//为脚本容器设置环境
  7.         //.......................
  8.     for (int i = 0; i + 1 < obs.length; i += 2)
  9.     {
  10.       Object ob = obs[(i + 1)];
  11.       if ((ob instanceof Entity)) {
  12.         ob = ScriptController.Instance.getScriptForEntity((Entity)ob);//若参数为实体则转为脚本实体类型
  13.       }
  14.       script.engine.put(obs[i].toString(), ob);//为环境写入参数
  15.     }
  16.     return callScript(script);//转交至callScript处理并返回其返回值
  17.   }
  18.     private boolean callScript(ScriptContainer script)
  19.   {
  20.     ScriptEngine engine = script.engine;//获取容器的环境
  21.     engine.put("npc", this.dummyNpc);//写入参数npc
  22.     engine.put("world", this.dummyWorld);//写入参数world
  23.     ScriptEvent result = (ScriptEvent)engine.get("event");//获取事件
  24.     if (result == null) {
  25.       engine.put("event", result = new ScriptEvent());//若没有事件则写入新事件
  26.     }
  27.     engine.put("EntityType", entities);//写入参数EntityType
  28.     engine.put("RoleType", roles);//写入参数RoleType
  29.     engine.put("JobType", jobs);//写入参数JobType
  30.     script.run(engine);//运行脚本
  31.         //.......................
  32.     return result.isCancelled();//返回结果
  33.   }

好,我们现在来说,callScript是一个怎样的方法。
听仔细了！
callScript是一个获取对应事件的脚本容器,且给予容器环境,并为其环境写入事件参数与默认参数,最后在环境中执行脚本的一个方法！
没听清？再来一遍！
callScript是一个获取对应事件的脚本容器,且给予容器环境,并为其环境写入事件参数与默认参数,最后在环境中执行脚本的一个方法！
好,我们总结一下:
script是什么?
-script是NPC的属性,他指向他的DataScript对象。
callScript是怎样的方法?
-callScript是一个获取对应事件的脚本容器,且给予容器环境,并为其环境写入事件参数与默认参数,最后在环境中执行脚本的一个方法！
问题总结完了,我们最后再来解释下名词。
DataScript:这是存储脚本容器与脚本基础信息的地方
ScriptContainer:这是储存这脚本源代码和Engine的地方
Engine:脚本的运行环境或者叫做虚拟机？脚本就是在Engine上运行的。
