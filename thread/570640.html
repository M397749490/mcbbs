[fly]JLD 自定义你的消息吧[/fly]


加入 离开 死亡消息


安装
  像平常的软件一样，放进plugins，不过不推荐reload
指令
Command用处
/jld查看帮助
/jld enable <join|leave|death|all>开启三类消息
/jld disable <join|leave|death|all>禁止消息
/jld print在屏幕上写出消息
/jld reload重新读取
/jld set <join|leave>设置消息
/jld version查看版本



权限 前面请加前缀
jld.
    *
    jld
   enable
    disable
    print
    reload
    set
    version
用处同指令




配置


# 可以使用&(http://minecraft.gamepedia.com/Formatting_codes).# <player> = 玩家名字
join:   
  enabled: true #是否启用   
  message: '&e%player% joined the game' #消息l
leave:   
  enabled: true   
  message: '&e%player% left the game'
death:   
  enabled: true
