在有服务端的目录下，新建一个txt文本
写上
@echo off
java -Xms*G -Xmx*g -jar XXX.jar
pause
那个*就填你给服务端分配的最大内存，都填一样的。
XXX就填你的服务端名称
然后另存为bat文件。
运行
