今天发现可以在两个箱子之间建立一种联系，当一个箱子的物品nbt被移除后，另一个箱子的相应物品nbt会同时发生改变。
这绝壁是bug了……除非mojang想在minecraft中引入量子力学……


首先我们新建一个世界，然后在例如0,56,0放置箱子。然后我们弄一个带附魔的物品放入箱子


然后复制
  1. /clone 0 56 0 0 56 0 0 58 0
复制代码
然后移除复制后的箱子的物品附魔
  1. /data remove block 0 58 0 Items[0].tag.Enchantments[0]
复制代码
我们看到0,58,0位置的钻石胸甲已经没有附魔了。



这时我们打开原来位置的箱子看一下，附魔竟然也消失了！




如果修改0,56,0的箱子，0,58,0也会发生改变……

  • 这种联系对于潜影箱也是有效的。
  • 即使把一个箱子的物品拿出来再放进去仍然有效。
  • 即使是自定义的物品标签也是可以生效的。
  • 如果remove相应的物品槽，则不会出现该现象。
  • 但是即使remove了其它槽位，再进行该操作，仍然会有这种现象发生，哪怕移除的是带附魔的该物品的前方槽位（也就是Items中的index改变仍然有这种幽灵般的联系）。当然，如果退出世界，这种关联就会消失……
  • 修改某个箱子(merge)之后，这种关联似乎会消失。
  • 多个箱子之间也可以建立这种联系，其中一个发生改变，其余的均会变化。
所以我猜测当clone时，二者建立了某种联系，然后其中一个箱子的某个Slot物品tag发生变化时，另一个箱子的相应Slot物品tag也会同时改变。
