Multi Experience
更好的多倍经验插件，支持PlaceholderAPI


前言 / Overview
自从我服务器装了Slimefun之后，玩家一直问我要双倍经验，论坛转了一圈，不是对1.12.2的服务器不够友好，就是下载链接挂了= =索性自己写一个（没学过java的我一脸懵逼），参考了我服某OP给我写的经验翻倍栗子（一直说我辣鸡想锤他），还有SCT及以前当技术的服务器腐竹的指导下总算写出来了这插件


功能 / Features
  • 自定义结束时间的经验翻倍
  • VIP系统
  • 玩家死亡掉落经验按相应的倍数减少
  • 占位符支持（需要PlaceholderAPI及Minecraft1.8+你要能找到1.7的PAPI应该也能用）



开发计划 / Plans
  • 给单独的玩家开启限时经验翻倍
  • 给单独的玩家开启不限时经验翻倍
  • 其他语言翻译（除中文外还是让dalao来吧）



安装 / Installation
  • 从Github / Bukkit / Spigot上下载最新版插件
  • 丢到plugins文件夹中
  • 重启/重载服务器
  • 修改配置文件（可选选项）
  • 重载插件/重启/重载服务器（可选选项）
  • 可以愉快的玩耍了

问题解答 / Questions & Answers
  • Q1：为什么我改了配置文件，游戏里却没有生效？
  • A1：手动修改完配置文件后，需要使用reload指令重载插件或者重启服务器才能生效
  • Q2：这插件功能太少，可不可以加入balabala功能？
  • A2：有建议当然是好的，but由于我是初三党，今年要中考，而且我也没学过java基础，开学后很少时间更新插件，也欢迎各位dalao提建议/帮更新，当然我也会抽出时间来回应建议/反馈
  • Q3：这个插件与其他的插件冲突吗？
  • A3：应该是不与其他插件冲突，如果发现冲突的话请反馈给我

指令权限 / Commands & Permissions
指令描述参数权限节点
/multiexp set更改经验翻倍配置，[倍数(Int)][分钟(Int)][是否启用(true)]multiexp.admin
/multiexp enable启用经验翻倍无multiexp.admin
/multiexp disable关闭经验翻倍无multiexp.admin
/multiexp reload重载插件无multiexp.admin
无VIP权限无multiexp.vip

/multiexp也可以换成/mexp和/multiexperience哦



变量列表 / Placeholders
变量名描述
%multiexp_time%显示当前活动剩余时间,如活动结束会提示过期
%multiexp_multiple%显示当前活动倍数
