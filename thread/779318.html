无尽地牢

无穷无尽的地牢世界
更多玩法等你挖掘

介绍
这是一个无尽地牢的服务器模板
地牢世界中包含7层地牢
你可以将其制作成RPG 冒险 生存 解密等类型的服务器
更多玩法等你来拓展

截图

下载地址
百度云
密码：1jon

其它
服务端核心为Spigot1.11.2
装上ViaVersion和ViaRewind可兼容1.7-1.13登入
DungeonMaze是一款非常消耗资源的地牢插件
楼主已经在spigot.yml bukkit.yml server.properties中做好了优化
如不需要可以删除以上3个配置文件
（在地牢跑图的情况下tps理论达到19+，在地面跑图tps理论达到18+）
（如在人多的情况下，地牢跑图理论达到18+，地面跑图理论达到17+）
为迎合32位电脑，服务端内存设置为1024m
如需要更大内存可将以下启动参数写入run.bat
  1. @echo off
  2. Title 无尽地牢 端口：25565
  3. java -javaagent:NOWait15Seconds.jar -Xms1024M -Xmx4096M -jar spigot-1.11.2-R0.1-SNAPSHOT.jar
  4. pause
复制代码
如需更好的优化可使用PaperSpigot或TorchSpigot，并进行优化配置
优化教程1  优化教程2
服务端默认关闭地狱世界 如需要可在server.properties中将
allow-nether=false设置为allow-nether=true
默认难度为3(困难)，如需更改可在server.properties中将
difficulty=3(困难)设置为difficulty=0(和平) difficulty=1(简单) difficulty=2(普通)
默认游戏模式为冒险模式，如需更改可在server.properties中将
gamemode=2(冒险)设置为gamemode=0(生存) gamemode=1(创造) gamemode=3(旁观者)
默认网络压缩阀值为-1，如需更改可在server.properties中的
network-compression-threshold=整数值 进行设置
network-compression-threshold（网络压缩阈值）
默认: 256
建议 (单服): 512
建议 (本地 Waterfall/BungeeCord): -1
此选项控制数据包压缩的阈值，数据包大小达到这个值将会进行压缩。
设置高些能够减轻CPU压力，但会增加网络占用。设置为-1即禁用。
如果你的多个服务器在本地上，或者是同一个数据中心（延迟<2ms），禁用它只应是有益无害的
设置低些能够减轻网络压力，但增加CPU负担，过低会导致客户端卡顿，不建议这么做）
(摘自：http://www.mcbbs.net/thread-608083-1-1.html)
