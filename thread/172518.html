简介
你只要用一个蛋，向一个生物丢过去，它就便成了刷怪蛋（会不会觉得跟EggCatcher一样呢？？）
其实，这个多了几个特点：


1. 当你抓到一只穿着盔甲的生物时，你再丢出来后，它的盔甲仍然还在
2. 当你驯服狼后，把它给抓了，再丢出来后，驯服效果仍然还在
3. 这个插件能让玩家能投射刷怪蛋（所以不需要那个能投射刷怪蛋的插件了，但是我不知道这个插件会不会和那个插件冲突）
4. 当一只僵尸被攻击后，把它给抓了，再丢出来后，血量还是少的
5.你能放置一个牌子，写着：
                   第一行    mobcatcher
                   第二行      <名字>  
                   第三行       范围
                   第四行         空




其实，牌子是保护一个区域，让只有你才能抓这个区域的生物（这个大多数用在养殖动物的区域）
第三行使用不了，需要config配置设置
6. 当抓到生物后，刷怪蛋会显示生物的生命，盔甲，攻击力，名字，是否有被驯服和生物类型
7. 会显示马跳的高度，种类，颜色，是否有被驯服，身上的箱子，名字，鞍和马的盔甲




缺点
1. 如果你使用1.6.2-R0.1版本的服务端的话，你必须确保是2812craftbukkit建立的,其他版本都无效
2.不能stack，堆放，堆叠的意思


权限
mobcatcher.op.* 所有此插件的op权限


mobcatcher.op.*的子权限


mobcatcher.op.catchchance 100抓得到任何生物mobcatcher.op.free 能够免费捕抓任何生物
mobcatcher.op.sign 允许打破任何人的mobcatcher牌子
mobcatcher.op.ignoreprotection 能够在别人的牌子范围内捕抓生物
mobcatcher.op.ignoreconfig 在配置中禁用的生物可以捕抓


mobcatcher.catch.* 能够捕抓所有生物的权限


mobcatcher.catch.* 的子权限
mobcatcher.catch.peaceful.* 能够捕抓所有怪物的权限
mobcatcher.catch.hostile.* 能够捕抓所有动物的权限

config配置
#
#  MobCatcher v3.0
#  
#  For help with the Config file, see the BukkitDev page.  
#  
PluginEnabled:
  world: true 主世界是否可用
  world_nether: true 下界是否可用
  world_the_end: true 末影之地是否可用
  arena: true 竞技场是否可用
  city: true 城市是否可以
CaptureItem:
  Enabled: true 是否使用以下物品捕抓生物
  ItemName: egg 物品名字
  ItemID: 344 物品ID
  UsedOnCapture: true 取消后，只有被设置过物品才能捕抓生物（就是说，不能以其他的方法得到刷怪蛋）
  ReturnedOnSpawn: true 不清楚。。。
ProjectileCaptures:
  SpawnEggsDirectToInventory: false  当捕获生物后，就立刻得到该生物的刷怪蛋，而不是掉在地上
  MissedEggsSpawnChickens: true 丢不中的蛋会有小鸡
  Type: 以下是改变抓生物的种类，就是可以换成丢雪球抓生物
    Egg: true 换成鸡蛋（默认已经是鸡蛋）
    Snowball: false 换成雪球
    Arrow: false 换成箭 （注：箭会杀死生物，最好是别用）
Spout:
  Enabled: true 是否启动射出（不清楚）
SignProtection: 以下是牌子保护的设置
  Default:
    Radius: 10 范围保护（以方块作为计算）
    SignLimit: 3 能够放置牌子的最大数量
  PlayerSet: 玩家设置
    Enabled: false 是否启动以下设备
    MaxRadius: 10 最大范围
SaveDataAndRemoveStackability: true 取消刷怪蛋的一些系统，你看我刚刚简介的特点，第1，2，4，6和7条忠而言之，就是换成和eggcatcher的那一种
EffectsEnabled: true 捕抓生物后，是否有声音的效果
ThrownSpawnEggsEnabled: true 是否能投射刷怪蛋
CanCaptureMobSpawnerMobs: true
IronGolemsProtectVillagersFromCaptures: true
Dispensers: 以下是设置发射器的
  Capture: false 是否能捕获生物
  Shoot: true 是否能射刷怪蛋（原本游戏的是生成生物在发射器前面，true后变成可以投射刷怪蛋）
  Power: 0.5 射得距离
Messages: 信息
  CaptureEnabled: true 捕获生物的信息
  SpawnEnabled: true 放出怪物的信息
  Permissions: true 权限信息
SimpleConfig:简单的配置
  Vault: false 是否用vault插件（捕获一只生物需要金钱）
  PeacefulMobs: 驯良的动物
    ItemName: redstone dust 捕获所需的材料（默认是红石）
    ItemID: 331 捕获所需的材料id
    Amount: 5 捕获一只生物所需的红石
    VaultCost: 10.0 所需的金钱
    Chance: 100 几率
    MustBeKilled: false 杀了后才能抓到
剩下的都和上面的一样～～



指令
/mobc - Displays all command usage 显示所有指令
/mobc item - Displays Capture item setting 显示捕抓生物所需的物品
/mobc clean - Removes data from a spawn egg itemstack 就是把SaveDataAndRemoveStackability的config配置换成false
/mobc projectiles - Displays current projectile settings 显示
/mobc settings [生物] - Displays settings 显示该生物设置
/mobc worlds - Displays which worlds MobCatcher is enabled in 显示那一个世界是被此插件用着的
/mobc area - displays how many Protection Signs the player is within the radius of 显示在半径内有多少个保护牌子（就是mobcatcher的牌子）
/mobc resetsigndata - Deletes all saved sign data 清除所有牌子的记录
