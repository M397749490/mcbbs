【重要说明】
[1]首先感恩前人的辛苦搬运和汉化。现至少有3个关于iConomy的帖子：

【配置文件要点说明】
[1]货币中文使用方法1.

①配置说明：
Currency:
      # Major is the first segment [Major].Minor

      # Major ([Major].Minor) 1.00 Dollar (With Seperate 1 Dollar)
      Major: [ ''Dollar', 'Dollar'' ]   #这个Dollar名称是作为数据的，只支持数字/英文，不能改成中文！

      # Minor (Major.[Minor]) 0.23 Coins  (With Seperate 0 Dollars, 23 Coins)
      Minor: [ 'Coin', 'Coins' ]       #同上

②改中文货币：思路：删除默认货币名称Dollar，在信息文件Template中添加自己的游戏币名称。
    第1步（网盘文件是改好的）：将配置文件config中的Major: [ ''Dollar', 'Dollar'' ] 改为Major: [ '', '' ]   #即删除Dollar
    第2步（需要自己改）：把Template.yml中的 "游戏币" 一词 全部替换为“你的货币名称”即可。


方法2.（未测试---由wyp175 提供）

用Notepad++吧config.yml转成ANSI编码，然后把 'Dollar''改为中文货币名字


[2]起始金钱设定：

    Account:
      # Default account balance when created
      Holdings: 100.0   #这个就是起始金钱，记得要小数点   比如：8.8   30.0
