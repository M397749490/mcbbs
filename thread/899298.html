if data 返回的是指定的 NBT 路径能够在指定的实体/方块实体上获得的 NBT 标签的个数。

例如，
execute if data entity @s SelectedItem.tag.Enchantments[]

这一条命令中，SelectedItem.tag.Enchantments[] 能够获取到 SelectedItem 标签的 tag 标签下的 Enchantments 列表中的所有元素。if data 可以将这些元素的个数返回，所以你就成功得到了附魔的个数。

data和execute if data肯定是不等价，返回的提示信息不一样。不过二者的返回值是一样的。

你这么理解，第一条命令是在获取SelectedItem.tag.Enchantments这个列表的所有内容，data命令不能接受像SelectedItem.tag.Enchantments[]这样的,具有多个NBT的值，所以只有第一种写法。如果是列表，返回元素个数；如果是{}，返回个数，如果是数值，返回数值，字符返回长度。

第二条是在问有没有SelectedItem.tag.Enchantments[]这样的nbt。没有返回0，有返回个数。

所以你可以想想第二种做法的SelectedItem.tag.Enchantments和SelectedItem.tag.Enchantments[]，分别在下面三种情形返回啥，我想这有助于你理解if data以及有无[]的差异
  1. /give @s diamond_axe{Enchantments:[]}
  2. /give @s diamond_axe{Enchantments:[{}]}
  3. /give @s diamond_axe{Enchantments:[{id:"minecraft:silk_touch",lvl:1s}]}
