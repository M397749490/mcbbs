作者: lichi2050    时间: 2015-5-10 13:23
/mw setflag 世界名称 （设定项） （数据）

设定项比如说：
SpawnMonster 生成怪物
SpawnAnimal 生存动物
PvP  PvP不解释

数据就是 true 和 false
true = 启动
false = 关闭

你可以输入 /mw listflags 查看全部的设定项
