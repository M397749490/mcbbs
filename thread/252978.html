好简单：关服，把\plugins\GroupManager\config.yml文件时里的如下内容删了保存，重启服务器就会生成各个世界的文件夹，修改里面的权限组即可（用上面的指令在指定世界输入也可以）。
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups

权利都在GroupManager插件里改
打开伺服器文件在打开GroupManager/worlds这里是世界的名 world是原本的世界，在打开你要改权利的其他世界，然后开groups找Default在看下文
Default:    default: true
    permissions：
    - essentials.warps.*       《把你要的权利放在这里  (permissions:的下一行)
    - -bukkit.command.kill     
    inheritance:
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    info:
      prefix: '&e'
      build: true
      suffix: ''
