BluesCollect

自定义采集插件


插件简介

    这个插件的初衷是因为我去年有做过RPG服务器，有些任务需要玩家去采集药材,石材之类的任务物品,但是不知道怎么做这些药材石材的掉落,因为找不到插件可以自定义方块掉落物,就想着自己整个插件,所以这个插件准的来说应该是去年写了70%然后昨天才完善的,然而RPG已经被我鸽掉了2333



插件功能

    1. 可自定义采集区域 (类似领地插件选择两点创建采集区域)
    2. 可自定义可采集物 (暂时只支持原版物品作为可采集物)
    3. 可自定义采集物的掉落物品 (可以为Mod物品/掉落物物品Lore等...)
    4. 提供了快速传送到采集区域的功能/查看采集区域信息的功能



插件指令权限和配置/语言文件说明

插件指令详情
注意!创建后配置完记得保存区域!否则无效!
1.开始选择区域 /bsc start
2.查看区域信息 /bsc info (区域名)
3.查看自己的区域列表 /bsc show
4.删除指定区域 /bsc remove <区域名>
5.删除保存的物品 /bsc item remove <物品名>
6.保存手上物品到物品列表中 /bsc item save <物品名>
7.创建采集区域 /bsc create <区域名>
8.添加区域采集物 /bsc addDrop <区域名> <采集方块的数字ID> <掉落物名:数量> <掉落几率>
9.设置区域采集资源被采集后的恢复时间(秒) /bsc setTime <区域名> <采集方块的数字ID> <采集时间> <恢复时间>
10.删除设置的采集物信息 /bsc delDrop <区域名> <采集方块的数字ID> (要删除的掉落物名称)
11.保存区域信息(需将区域信息配置完才能保存) /bsc save <区域名>
12.传送到区域位置 /bsc tp <区域名>
使用< >包裹起来的参数表示为必填项,而( )包裹表示为选填项

4. 添加可采集方块(暂时只支持原版的方块~),并添加掉落物(掉落物可以是Mod物品)

使用指令/bsc adddrop <区域名> <可采集方块数字ID> <掉落物名[:数量]> <掉落几率>

这个指令看起来比较复杂,其实并不,比如我刚刚创建了一个名为 啦啦啦 的区域

然后我想让玩家采集 原石 有几率掉落 草药 这个物品

那这里就这么写: /bsc adddrop 啦啦啦 1:0 草药:5 80

1:0就是原石的数字ID,只支持数字ID!! 草药:5表示掉落5个草药

使用指令/bsc settime <区域名> <采集物数字ID> <采集时间> <复原时间>

采集时间就是玩家需要采集多久才能采集完

复原就是物品被采集后恢复所需的时间
