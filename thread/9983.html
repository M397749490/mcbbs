新内容
  • "Nether Update / Second Part of the Adventure Update" 地狱升级，冒险升级的第二部分（7：40左右会出）
  • This update will include new features in the Nether, such as: 会升级地狱，地狱有更多可玩处
    • 地狱石砖
    • 地狱石栅栏
    • 地狱石楼梯
    • 地狱环境
    • 地狱水母的眼泪
    • 烈火棒
    • 地狱树？作物？
    • 金块
    • 俩新的地狱怪物
  • 冒险模式
  • 完成了旧的环境代码还有新的环境
    • 雪地
    • 湿地环境
    • M蘑菇环境
      • 天然的巨大蘑菇
      •   新的蘑菇牛
      • 菌丝方块
  • 新的声音：
    • 矿车 声音
    • 剪刀
    • 弓
    • 大史莱姆
    • 黑基受和银虫
  • 已有的声音变更
    • 下雨
    • 门
    • 新的骷髅走路声音
  • 6个新怪
    • 新的怪比普通的更厉害 也许有boss了
    • 蘑菇牛
    • 村庄 里有npc了
    • 雪人
      • 可以合成
      • 热的地方会融化
      • 走过的地方覆盖上雪
      • 和气的怪 会扔雪球
    • 地狱至少俩新怪
      • 俩都会伤人
      •   岩浆立方
      • 烈火怪 （黑基受有了还要有红基攻）
  • 经验会有用了
  • 喂养动物
  • 增加更多的堡垒，以前只能有3个人
    • 堡垒boss
  • 新的装甲装备系统
    • 增加装备的耐久
  • 游戏设置变更
    • 防御现在移动玩家的手了，不像以前只有个剑浮在那里
