作者: huwei5201314789    时间: 2016-10-16 18:21
1:ess基础插件可以设置，但只能设置统一的进出消息

  1. # 是否关闭加入、退出游戏的提示消息
  2. # 当启用后, 具有对应权限的玩家加入、离开游戏将不会在公屏上显示消息
  3. allow-silent-join-quit: true

  5. # 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
  6. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  7. custom-join-message: "none"

  9. # 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
  10. # 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
  11. custom-quit-message: "none"
复制代码
如果想设置不同权限组不同上线消息，就要用其他插件

3:锁箱子插件，你的是Lockette插件么？如果是，就打开这个插件的配置文件找到

  1. allow-admin-snoop: true
  2. allow-admin-bypass: true
  3. allow-admin-break: true
复制代码

这三项都是管理员强制开箱子的选项。无需拆牌子
