命令介绍：
/build 开启或关闭大厅建筑权限
/lobby set spawn 设置脚下为大厅位置
/lobby set （loc1-8） 设置传送点，最多只能设置八个
/lobby reload 插件重载

权限：
lobbynk.build.own允许使用命令/build
lobbynk.cosmetic.diamond.*允许使用身上特效的钻石特效中内容
依此类推还有
Gold, Iron,Leather,chainmail
lobbynk.effect.*允许使用所有BUFF药水效果
依次类推需要给单独使用只需要把*改成
angry, bonemeal, bubble, explode, heart, redstone, ink, enchant,flame,
speed, jumpboost, levitation, invisibilty, blindness, nausea and nightvision
