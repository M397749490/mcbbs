我拿命令给你做一个吧，坐标会显示在屏幕最右侧

适用于 1.13+

手动执行一次：
scoreboard objectives add pos dummy "坐标"
scoreboard objectives setdisplay sidebar pos

用循环命令方块或函数高频执行：
execute store result score x pos run data get entity @p Pos[0] 1000
execute store result score y pos run data get entity @p Pos[1] 1000
execute store result score z pos run data get entity @p Pos[2] 1000

数字的最后三位是小数点后的，如果觉得还不够准确可以把 1000 改成更大的数…

不过这样有个问题，就是…它不一定是按照 x y z 的顺序显示的，有点丑（

所以可以继续接几条高频执行的命令，把分数按顺序显示在聊天栏：
tellraw @p ["(",{"score":{"objective":"pos","name":"x"}},", ",{"score":{"objective":"pos","name":"y"}},", ",{"score":{"objective":"pos","name":"z"}},")"]

然后从 latest.log 里面就可以把坐标复制出来了。
