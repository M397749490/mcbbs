奇怪的需求...
应该可以在 whitelist.json 中设置。格式如下（参见英文 Minecraft Wiki 的相关页面）：
  1. // 请务必留意 JSON 格式，若 JSON 格式错误，轻则无法重载白名单，重则服务端崩溃
  2. // uuid 字段为角色的 UUID，name 字段为角色名
  3. [
  4.   {
  5.     "uuid": "f430dbb6-5d9a-444e-b542-e47329b2c5a0",
  6.     "name": "username"
  7.   },
  8.   {
  9.     "uuid": "e5aa0f99-2727-4a11-981f-dded8b1cd032",
  10.     "name": "username"
  11.   }
  12. ]
复制代码

修改完成后执行指令 /whitelist reload 重载白名单即可。
