  主命令为 /hideandseek 和 /has：

  /has - 该插件的主要命令 - 无权限
  /has List - 显示游戏地图列表和统计信息 - 无权限
  /has Join - 加入一张游戏地图 - 权限：hideandseek.join
  /has Leave - 离开躲猫猫游戏 - 无权限
  /has Stats - 显示玩家的游戏数据 - 无权限
  /has Lobby - 传送到全局大厅（需要设置） - 无权限
  /has Info - 查看插件信息 - 无权限
  /has Admin - 显示管理员命令列表 - 权限：hideandseek.admin
  /has Create - 创建一张游戏地图 - 权限：hideandseek.create
  /has Delete - 删除一张游戏地图 - 权限：hideandseek.delete
  /has Edit - 修改该游戏地图的详细设置 - 权限：hideandseek.edit
  /has Setlocation - 用于设置多个位置（出生点等） - 权限：hideandseek.setlocation
  /has Setgloballobby - 用于设置全局大厅位置 - 权限：hideandseek.setgloballobby
  /has Check - 检查游戏地图的设置 - 权限：hideandseek.check
  /has Start - 强制开始游戏 - 权限：hideandseek.start
  /has Stop - 强制停止游戏 - 权限：hideandseek.stop
  /has Coins - 修改玩家硬币相关内容 - 权限：hideandseek.coins
  /has Exp - 修改玩家经验相关内容 - 权限：hideandseek.exp
  /has Setmodifier - Change a player modifier - 权限：hideandseek.setmodifier
  /has Powerup - Add a powerup spawner - 权限：hideandseek.powerup
  /has Reset - 重置一个玩家或所有玩家的游戏数据 - 权限：hideandseek.reset
  /has Pastebin - 将你的文件副本上传到 Pastebin - 权限：hideandseek.pastebin
  /has Reload - 重载插件 - 权限：hideandseek.reload

  前置插件：LibsDisguises 或 IDisguise 必要二选一
  LibsDisguises 需要额外安装前置 ProtocolLib 才能正常运行

  ① 使用 /has create <竞技场名称> <寻找者最小人数> <藏匿者最小人数> <最大游戏人数>
  来创建一张游戏地图。例：“/has create 躲猫猫 3 5 16”即可创建一张游戏地图

  红色数字 3 即代表 需要有至少 3 名玩家充当寻找者才能开始游戏
  绿色数字 5 即代表 至少需要 5 名玩家充当藏匿者才能开始游戏
  蓝色数字 16 代表 这个游戏地图最多允许 16 名玩家参与游戏

  而游戏的最小人数是“最小藏匿者人数+最小寻找者人数”，即 最少需要 8 人开始游戏
  
  ② 接下来需要设置区域。使用指令 /has setlocation <arena> lobby 来设置游戏的等待大厅
  然后输入指令 /has setlocation <arena> seekerswaiting 来设置寻找者的等待地点
  接下来输入 /has setlocation <arena> seekersplaying 来设置寻找者开始游戏时传送的地点

  最后输入 /has setlocation <arena> hiders 来设置藏匿者出生的地点

  ③ 现在你可以使用 /has edit <arena> 来启用这张游戏地图（不要忘记 Save保存 和 应用）

  对于 BungeeCord 模式的应用：

  和上述一样，创建游戏地图并设置全局大厅（/has Setgloballobby）
  然后在插件的 config.yml 中设置 bungemode.enabled 选项为 true 并重启服务器
  然后就可以享受你的游戏了！

  Stats（游戏数据）牌子：
  • 第一行 - [has]
  • 第二行 - stats
       

  Auto-join（自动加入）牌子：
  • 第一行 - [has]
  • 第二行 - autojoin

  Join（加入指定游戏）牌子：
  • 第一行 - [has]
  • 第二行 - join
  • 第三行 - 竞技场名称

  Leave（离开游戏）牌子：
  • 第一行 - [has]
  • 第二行 - leave

  Shop（商店）牌子：
  • 第一行 - [has]
  • 第二行 - shop

  Leader Board（排行榜）牌子：
  • 第一行 - [has]
  • 第二行 - top
  • 第三行 - 名次（例如 1、2、3 这样）
