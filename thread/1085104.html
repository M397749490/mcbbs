模组简介
Diggus Maximus是一个为了使得挖掘更加方便的模组。只需要按住绑定的“excavate”键（默认是~，可自行更改），就可以实现连锁挖矿。
该模组可以通过修改配置文件从而高度个性化的配置模组，可选项如下：
  • 1.自动拾取被挖掘的方块
  • 2.一次最多能挖掘的方块的数量
  • 3.从起始方块能延伸出去的最大距离
  • 4.用手挖掘的能力
  • 5.工具耐久度
  • 6.玩家疲劳度
  • 7.黑名单/白名单
  • 8.在工具损坏前停止挖掘
  • 9.支持根据Tag挖掘
配置文件

{
        // Mod enabled or disabled，是否启用该mod
        "enabled": true,
        // Activation key，连锁挖矿绑定键位
        "keybinding": "key.keyboard.grave.accent",
        // Should mine diagonally，是否按斜对角挖矿
        "mineDiag": true,
        // Maximum number of blocks to mine，一次能挖掘的矿物的最大数量
        "maxMinedBlocks": 40,
        // Maximum distance from start to mine，能从起始块延伸出去的最大距离
        "maxMineDistance": 10,
        // Automatically pick up drops，自动捡起掉落
        "autoPickup": true,
        // Tool required to excavate，需要工具来连锁挖矿
        "requiresTool": false,
        // Stop before tool breaks，在工具破损前停止
        "dontBreakTool": true,
        // Stop excavating when tool breaks，在工具破损后停止
        "stopOnToolBreak": true,
        // Should tool take durability，是否消耗工具耐久
        "toolDurability": true,
        // Should player get exhaustion，玩家是否会加速消耗饥饿
        "playerExhaustion": true,
        // Multiply exhaustion when excavating，挖掘时消耗饥饿的倍率
        "exhaustionMultiplier": 1.0,
        // Other items to be considered tools ie: "minecraft:stick"，其他被认为是工具的物品
        "tools": []
}
