我找了几天几夜各大论坛，为了寻找你的名字......，最后终于一个关键词Location在Bukkit官网第一页找到了2333新人搬运贴
起因：因为自己建立的服务器需要，所以努力的寻找了大量的插件，结果，发现每次玩家使用快捷菜单去别的世界的时候总会在出生点出生，举个例子吧，你正在生存世界挖矿，突然发现钻石！！！！然后掉线了。。。手动滑稽~~然后你重新登陆，发现自己在主城世界或者出生点出生的，忘了钻石的坐标......会不会让服主赔呢？....
有了这个插件，就可以让玩家在使用快捷菜单或者mvtp命令的时候回到那个世界上次退出的地方，可单独设置开启或者关闭Commands:
  1. <blockquote>Someone on a forum was griping that when you use Multiverse to teleport to a world, it takes you to spawn instead of the last place you were on said world. I made this plugin to fix that. If you use /mvtp or a portal with a w: destination indicator, it will move you to where you last were on that world assuming you've been there before.
复制代码
  1. Commands:
  2. /ll - Help
  3. No permission node
  4. /ll list - Show all the worlds and last coordinates on that world
  5. lastlocation.list
  6. /ll [world] - Show last coordinates on [world]
  7. lastlocation.showcoords
  8. /ll [world] toggle - Disable teleportation redirection when going to [world]
  9. lastlocation.toggle
  10. /ll [world] clear - Remove the saved coordinates on [world]
  11. lastlocation.clear
  12. Administrative node is lastlocation.admin which just gives you all of the above.
  13. Obviously, this plugin is dependent on Multiverse/Multiverse Portals.
