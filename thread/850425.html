介绍

因为我卸载了ess插件用CMI插件了，导致ess保护插件无法使用，所以才写这个插件
本插件可以让TNT、爬行者、末影水晶、凋零头、凋零生成、恶魂火焰弹、在地狱/末地使用床产生的爆炸破坏方块消失
而且完全可以配置
此插件可以解决使用防爆指令后村民无法繁殖的问题。装上此插件完成设置后，不要关闭防爆即可
使用方法

1.下载插件
2.放入plugins文件夹
3.启动服务器
4.根据自己需要调整配置文件
配置文件
  1. #TNT爆炸保护 true开启保护 false关闭
  2. TNT: true
  3. #末影水晶爆炸保护 true开启保护 false关闭
  4. ENDER: true
  5. #苦力怕爆炸保护 true开启保护 false关闭
  6. CREEPER: true
  7. #凋零头爆炸保护 true开启保护 false关闭
  8. SKULL: true
  9. #凋零生成爆炸保护 true开启保护 false关闭
  10. WITHER: true
  11. #恶魂火焰弹爆炸保护 true开启保护 false关闭
  12. GHAST: true
  13. #末地和地狱是否能使用床 true不能使用 false能使用
  14. BED: true
