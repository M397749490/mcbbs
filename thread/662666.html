KarNoCleanUp - 拒绝补刀

By KarStudio - LSeng



----- 关于我 -----
    各位好，本人是国内一个正版服务器的腐竹。 服务器内目前开发了不少插件，由于已经不再需要或并不重要，经过团队商讨决定发布与MCBBS/Spigot 。    首先说一声抱歉，本人第一次在MCBBS上发布原创内容 不可以保证不出现错误 (盯着版规写本帖)

--- 介绍 ---
这是一个PVP插件

    本插件并不高端，当玩家杀死其他玩家时，将会给予 生命恢复 + 伤害吸收 的效果(即金苹果) 可以在Config内修改/开关其时间和效果 目前仅支持两种

配置文件
  1. NoHungry: true  #饱和开关
  2. KillerSetHealth: true #是否在杀人时恢复血量
  3. HealthSetLevel: 20.0 #恢复多少血量
  4. KillerAbsorption: true #是否在杀人时给予伤害吸收</span>
  5. AbsorptionLevel: 0 #伤害吸收等级(0代表1级 1代表2级 按照effect指令来)
  6. AbsorptionTime: 600 #伤害吸收时间
  7. Health: true  #是否在杀人时给予 生命恢复
  8. HealthLevel: 0 #同理
  9. HealthTime: 100 #同理
  10. Sound: true #是否在杀人时给杀手播放声音 叮！
  11. KSonLevel: true #无用 | KSonLevel是我们的其他插件 无用 且不会发布此插
