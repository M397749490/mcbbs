标题: [编程|前置]ProtocolLib-Forge —— MC协议前置插件 [1.12.2]
ProtocolLib Forge兼容重制版 (CatServer / Magma)

为什么要用这个版本？
相信有不少服务器正在使用包含Forge的服务端，但是在使用ProtocolLib以及相关的插件的时候会遇到错误或者无效的情况。
这个版本的ProtocolLib加入了对1.12版本Forge的兼容性，使用方法和配置文件都与官方版相同。

命令
/protocol config 重载配置文件
/protocol check 检查（官方版的）更新
/protocol version 显示当前版本
/protocol timings 记录执行耗费时间
/protocol listeners 显示监听ProtocolLib的插件

配置文件
  1. global:
  2.   # 自动更新设置
  3.   auto updater:
  4.     notify: true
  5.     download: false
  6.     # 等待多久下载新版本
  7.     delay: 43200 # 12 hours
  8.   metrics: true
  9.   # 自动编译结构修改器
  10.   background compiler: true
  11.   # 禁用自动更新时的MC版本检测
  12.   ignore version check:
  13.   # 覆盖启动时的注入方法
  14.   injection method:
  15.   # 是否启用filter命令
  16.   debug: false
  17.   # 是否对每个警告都输出堆栈追踪
  18.   detailed error: false
  19.   # filter命令所使用的引擎
  20.   script engine: JavaScript
  21.   suppressed reports:
