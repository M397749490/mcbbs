不行，这样不科学(我就是要和mc讲科学，不要喷我)。但是，gbuffers_textured渲染器并没有光照系统，于是我们将目光再次上移至gbuffers_textured_lit。本章节使用gbuffers_textured_lit渲染器实现最基本的光照系统。

开始编写光影文件

在shaders文件夹里再创建两个文件，分别为gbuffers_textured_lit.vsh和gbuffers_textured_lit.fsh并写出代码。

gbuffers_textured_lit.vsh：
  1. #version 120

  3. varying vec4 color;
  4. varying vec4 texcoord;
  5. varying vec4 lmcoord;

  7. void main()
  8. {
  9.     gl_Position = ftransform();
  10.     color = gl_Color;
  11.     texcoord = gl_TextureMatrix[0] * gl_MultiTexCoord0;
  12.     lmcoord = gl_TextureMatrix[1] * gl_MultiTexCoord1;
  13. }
复制代码

gbuffers_textured_lit.fsh：
  1. #version 120

  3. uniform sampler2D texture;
  4. uniform sampler2D lightmap;

  6. varying vec4 color;
  7. varying vec4 texcoord;
  8. varying vec4 lmcoord;

  10. void main() {
  11.     gl_FragData[0] = texture2D(texture, texcoord.st) * texture2D(lightmap, lmcoord.st) * color;
  12. }
复制代码

代码解释

相较于gbuffers_textured，顶点着色器中多了lmcoord，不解释。
main函数中多了lmcoord = gl_TextureMatrix[1] * gl_MultiTexCoord1;其中纹理坐标矩阵(gl_TextureMatrix)的0号矩阵储存的是纹理数据，1号矩阵储存的是光照数据，这里是需要记住的。gl_MultiTexCoord1是1号纹理坐标。这句代码的意思是计算了光照的坐标并赋值给lmcoord。
片段着色器则是又定义了一个2D的纹理采样器uniform sampler2D lightmap;光照贴图(lightmap)，Minecraft会每隔一段时间(可能是几个游戏刻)生成一个光照贴图，用来表示一个物体在当前光照下的亮度。
main函数中则是用同样的方法，根据顶点着色器传来的坐标，从lightmap中获得光照颜色(其实也可以说成是像素受到光照后产生的颜色偏差)后乘进去。这里要注意的是，lmcoord的s轴对应人造光源强度，t轴对应环境光源强度。在这个代码中，如果你把获取像素像素颜色那一段删掉的话，效果会很滑稽。我不放图了，好奇的可以自己试试。
