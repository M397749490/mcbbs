安全重启模式
因为mod服一些保存机制,可能导致刷物品,刷宝可梦神兽的情况出现,于是这款插件就出现了.
服务器重启前进入一个重启模式,玩家会被移除服务器,服务器延迟指定时间后,进行重启.
注意: 本插件只是延迟重启服务器,并阻止玩家在延迟阶段进入服务器,并不能防止所有刷物品的可能!
命令及使用方式
  1. /rtm restart [时间] 多少秒后重启
  2. /rtm cancel 取消当前重启任务
复制代码
执行/rtm restart 时间命令后,服务器会将玩家踢出,并禁止玩家进入服务器.等时间到了之后,服务器会执行/stop命令,进行关服.所以自动重启需要配合启动脚本,才能完成自动重启.下面附上我的启动代码.(本启动代码仅适用于Windows系统)
  1. @set a=0
  2. @ECHO off
  3. :start
  4. @title [服务器名称] - 重启次数: [%a%]次
  5. java -Xms1024M -Xmx10G -jar spigot.jar
  6. @echo #####################################
  7. @echo #                                   #
  8. @echo # 服务端已经关闭，将于5秒后自动重启 #
  9. @echo #                                   #
  10. @echo #####################################
  11. @timeout /t 5 /NOBREAK
  12. @set /a a=%a%+1
  13. goto start
  14. pause
