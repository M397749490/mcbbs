介绍
      本插件能给服务器添加一个全新的玩法！它不仅允许玩家通过杀怪来升级自己的血量*，而且其中本身最大的亮点莫过于其是非常灵活和可配置化的。假设你把它安装到一个PVP或对抗服务器里，那么战斗将会变得更加趣味，因为你的敌人可能会拥有远高于你的血量，而你也可以在有朝一日任意地挫伤他。
      通过努力获得的属性加成绝壁比装备之间的对决爽多了。甚至就算只有铁套，你也仍能干掉对手，只要你有足够的——HP！
  * "通过杀怪……血量"：意义不明

配置文件

     允许你编辑全局设定和个体玩家的设定。

  • 是否获得掉落经验。(全局设定).
  • 自定义不同生物的掉落经验。
  • 开关获得经验的提示。
  • 自定义所有玩家升级所需经验。(<等级> x <你决定的因数>)
  • 自定义玩家第一次加入时拥有的初始血量。
  • 自定义个体玩家的血量。
  • 自定义个体玩家的经验。
  • 自定义个体玩家升级所需经验。
  • 开关个体玩家的升级系统。
  • 开关登陆时提示的一条有关升级方式和血量的信息。




命令与权限
  • /HP  功能：提示当前经验、升级所需经验以及经验百分比      权限：rpghealth.hp

   没错，独一无二的指令！

   *我还没实行/hp <playername>命令,因为这可以推测出敌人的血量，可能会降低游戏的趣味。



建议 / 未来计划
  • 升级烟花效果.
  • 升级马匹血量功能.


V0.4_7更新日志
  • Added that when changing worlds, your HP will get updated.
  • Fixed the error it gave when triggering the command /hp in the console.
  • Changed the message it displays when typing /hp.
  • Added a tip about the command /hp (toggleable in the configuration file).
  • Added the command /gethp <player>. This should only be used by admins. PERMISSON: rpghealth.gethp
  • It now tells you when you don't have permission for a command.
