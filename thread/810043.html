Siege——攻城游戏

注意：
这个插件仅适合一个独立的服务器，不适合多世界。
作者在1.11.2的环境下制作的这个插件，所以这个插件适用于所有1.11.2+版本的服务器。
这个插件可能在1.8+服务器上运行，但作者没有测试过运行情况，可能存在一些BUG。

搬运授权

简介 Description
攻城是一个多人游戏，将玩家分为两队——守卫和刺客
守卫必须通过杀死刺客来保护他们的国王
刺客需要在时间结束之前使国王血量为0
有三个回合，如果前两个回合都是同一队胜利将直接结束游戏
该插件包含一个记分板，在开始游戏前会显示倒计时
在开始后会显示每轮倒计时，国王血量和双方比分等


安装 SETUP
这个插件需要独立的服务器，不适合多世界
在使用其它指令前，你需要使用 /siege create 创建地图。


指令和权限 Commands&Permission

指令 作用 权限
/hub 传送到准备大厅 无
/Siege 显示全部指令 siege.siege
/Siege Create 创建一个攻城地图 siege.siege
/Siege Delete 删除一个攻城地图 siege.siege
/Siege Setlobby 设置一个准备大厅 siege.siege
/Siege Setspawn [Team] 分别设置两个队伍（Guards[守卫], Assassins[刺客]）的出生点 siege.siege
/Siege Setking 创建国王 siege.siege
/Siege Forcestart 强制开始游戏 siege.siege

配置文件 Config.yml

  1. mysql: #Mysql数据库
  2. enabled: false
  3. ip: '127.0.0.1'
  4. port: '3306'
  5. username: 'root'
  6. password: ''

  8. siege: #插件本体设置
  9. game:
  10. min-players: 6 #最少要求多少玩家
  11. king:
  12. name: '&6&lKing Olaf' #国王名称
  13. health: 600 #国王血量
  14. damage-per-hit: 1 #每次攻击伤害
  15. timers:
  16. countdown: 30 #准备时间
  17. match: 360 #比赛时间
