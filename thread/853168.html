BaiAttributes
由于1.12.2的sponge没有RPG类的属性插件,所以我就弄了这个插件...

命令与权限

/baia reload 重置插件
/baia item info 查看手中物品的标签
/baia item set <标签名> 设置标签到手中物品

配置文件

  1. # config.yml
  2. DamageAttributes:
  3.   Damage: Damage.js
  4.   Defense: Defense.js
  5.   CritDamage: Crit.js
  6.   Crit: None.js
  7.   Vampire: Vampire.js
复制代码
  1. # item.yml
  2. item-a1:
  3.   Damage: 10.0
  4.   Defense: 10.0
  5. item-a2:
  6.   Damage: 15.0
  7.   Defense: 15.0
  8. item-a3:
  9.   Damage: 5.0
  10.   Defense: 5.0
复制代码


使用方法
把插件拉到服务器的默认插件文件夹(Sponge默认是./mods/pulgins)
重启服务器,默认配置文件夹(./config)里会多出文件BaiLore文件夹
这样插件就安装完成了...

插件内置了伤害,防御,暴击倍率,暴击几率,吸血等5个属性
你也可以自己通过js脚本添加自己的属性(上面5个属性也是js脚本写的,你们可以自己参考一下)

用/baia item set <标签名>把 item.yml里的id绑定到物品上就好,属性在item.yml里设置
