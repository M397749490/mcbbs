安装方法


如果想使用特效购买功能，必须安装Vault经济插件作为前置！（我想每个服务器都安装了这个吧）
下载jar文件，扔进plugins文件夹，启动服务器，关闭服务器，下载帖内汉化后的配置文件和默认菜单并放入plugins/BetterBowTrails文件夹内，重启服务器





指令

- /arrow - 打开选择特效的GUI菜单
- /arrow set <粒子名称/方块名称> - 直接把箭矢特效设置为某个粒子
- /arrow type - 设置粒子显示模式，是仅飞行时显示还是落地后继续显
- /arrow amount <+/-> - 修改每tick显示的粒子数量，默认数量限制是5，可在config中修改最大限制
- /arrow remove - 移除你的箭矢特效
- /arrow reload - 重载插件
- /arrow help - 显示帮助


权限
- betterbowtrails.use - 打开GUI粒子选择菜单 - 这个权限给玩家
- betterbowtrails.remove.menu - 在菜单中移除粒子特效 - 这个权限给玩家
- betterbowtrails.type.menu - 在菜单中使用“设置特效模式” - 这个可以给玩家，不给的话玩家默认“仅箭飞行时显示特效”
- betterbowtrails.amount.menu - 在菜单中改变粒子数量 - 这个给不给随意，反正粒子数量有限制
- betterbowtrails.set.menu.all - 无视任何权限或者购买，使用所有种类特效 - 这个可以专门给VVVVVIP玩家
-------------------------------------------------后面的不用看了--------------------------------------------
- betterbowtrails.set - 允许使用 "/arrow set <粒子种类/方块种类>" 来设置自己的箭矢特效
- betterbowtrails.type - 用命令 "/arrow type" 修改设置特效模式
- betterbowtrails.amount - 用命令 "/arrow amount <+/->" 修改粒子显示数量
- betterbowtrails.remove - 用命令 "/arrow remove" 移除箭矢特效
- betterbowtrails.reload - 重载插件



PlaceholderAPI支持
- %betterbowtrails_amount% - 显示当前粒子数量
- %betterbowtrails_type% - 显示当前粒子显示模式，是“仅飞行显示”还是“落地后也显示”
- %betterbowtrails_particle% - 显示当前所用粒子特效
