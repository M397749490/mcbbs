在写gui前先了解下cs4 gui的设置组成

以下为基本结构

注释

【type】指这个项的类型

【id】自不用说，也是内部id

【bg】这个为gui的背景图片，但一般不建议超过256*256，不然会有缩放现象

【slots】这个就是设置可以放物品的一项啦

【shiftClickRules】这个是在按住shift后的行为

【labels】这个是文字

然后，再在main.json添加一个tile-entity.json的加载项（当然不添加也行，但你想让main.json越来越大？），具体步骤不赘述

输入以下内容：

{
  "tile-entity": [
    {
      "type": "tileentity:simple",
      "entries": [
        {
          "id": "airdrop_box",
          "modules": [
            {
              "type": "inventory",
              "name": "airdrop_box",
              "size": 27,
              "sides": ["north", "east", "south", "west"]
            }
          ]
        }
      ]
    }
  ]
}

注释

【type】以后不会再说，这个为这个项的类型

【id】填写为内部id

【modules】为这个tile-entity的一些参数

   ┗【type】这个为参数的子参数

   ┗【name】这个为guis的slots的此gui的主体部分（第一个name，按个人来填）

   ┗【size】这个为gui的大小/容量，只有箱子有此参数

   ┗【sides】这个为可输入/输出的面（实际测试无效果 x）实测有效果



填写好以上内容后，在方块/物品的【entries】的【model】下添加参数：

"tileEntity": "<你mod名字>:<tileEntity内部ID>",

"gui": "<你mod名字>:<guis内部ID>"



例子

以上面的空投箱为准


{

  "blocks": [

    {

          "type": "block:simple",

          "entries": [

           {

          "id": "Airdrop_box",

          "creativeTab": "creationitem-blocks",

          "model": "creation_item:airdrop_box",

          "tileEntity": "creation_item:airdrop_box",

      "gui": "creation_item:airdrop_box_gui"

           }

          ]

    }

  ]

}



添加完成后重启游戏



后话

gui的设置共涉及到4个文件，分别为

【main.json】主要为文件的联动设置

【guis.json】主要为gui的本体设置

【tile-entity.json】主要为gui的行为设置

【blocks.json】主要为gui的载体设置
