http://www.mcbbs.net/thread-287747-1-1.html 这个插件可以帮到你，就是这个搬运的家伙太不负责了 搬运质量不怎么样 （最新版本可以去原贴下载http://dev.bukkit.org/bukkit-plugins/csm/）

我简单的介绍一下：
  1. Plugin:
  2.   Updates: true 无视
  3.   Metrics: true 无视
  4. Event:
  5.   Join:
  6.     Enable: true 这个是登录信息可以改成false禁止掉
  7.     Message: '&6%Player &9joined the game!' 或者修改信息~ 中文也支持
  8.   Quit:
  9.     Enable: true 一样不过是退出信息
  10.     Message: '&6%Player &9left the game!'
  11.   Whitelist:
  12.     Enable: true 一样不过是白名单信息
  13.     Message: '&4Sorry. &6You are not on the Whitelist!'
  14.   ServerFull:
  15.     Enable: true 一样不过是满人信息
  16.     Message: '&4Sorry. &6The Server is full, try again Later!'
  17. Server:
  18.   Motd:
  19.     Enable: true 这个是标语（可以设定很多条，或者禁止掉用别的标语插件）
  20.     Messages:
  21.     - '&bA minecraft server'
  22.     - '&4A minecraft server'
  23.     - '&1A minecraft server'
  24.     - '&7A minecraft server'
  25.     - '&6A minecraft server'
  26.     - '&aA minecraft server'
  27.     - '&2A minecraft server'
  28. Command:
  29.   Say:
  30.     Enable: true 玩家说话设定
  31.     Message: '&6[%Player] >>> &b%Message'
  32.   Me:
  33.     Enable: true 私聊设定
  34.     Message: '&6* %Player &b%Message'
  35.   Plugins:
  36.     Enable: true 玩家查看插件没权限的信息
  37.     Message: '&4You dont have Permissions to see the Plugins!'
  38.   Version:
  39.     Enable: true 查看版本没权限的信息
  40.     Message: '&4You dont have Permissions to see the Version!'
  41.   Seed:
  42.     Enable: true 查看seed没权限的信息
  43.     Message: '&4You dont have Permissions to see the Seed!'
  44. DeathMessages:
