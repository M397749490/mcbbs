生物篇
1.树人
x
树人是中立生物，树人将免疫任何类型的武器，除了斧头。它们吸引附近的小动物，并会产下小植物。
2.鼹鼠
x
鼹鼠会钻入地下躲避玩家。
3.迷你傀儡
x
迷你傀儡是夜晚生成，会向玩家扔方块的怪物。
4.银骷髅
x
银骷髅是攻击性的生物，在夜晚和黑暗的地方生成。他们跑得比玩家快。他们扔骨头或银剑。银剑对付狼人很有效。
5.浣熊
x
浣熊如果被激怒就会反击。给他们任何可吃的东西都可以驯服他们。
6.螃蟹
x
在水边的海滩上生成。鱼网可以捕捉它们。
7.翼龙
x
翼龙是有毒的龙，可以在翼龙维度上找到。翼龙蛋可以通过杀死翼龙获得（只能在翼龙维度）。翼龙掉蛋的几率为10%。这种蛋可以通过把它放在火把附近孵化，一旦翼龙长大，就可以装上鞍和装甲。

只能使用翼龙传送法杖访问翼龙维度。它只能使用四次。
翼龙传送法杖可以在任何维度上被激活，并且它将传送玩家到翼龙维度的中心。要返回，玩家可以右键石英门户或建个地狱门。
8.象类
x
大象在沙漠、丛林、平原和森林中生成。猛犸象在寒冷的生物群上生成。给小象10块糖或5块蛋糕可以驯服小象。驯服的大象用烤土豆、面包或干草堆治愈。
驯服的成年大象可以戴上象鞍，使它们可以骑行，并附加额外的东西
如果一个玩家潜行右键他们的大象，它会坐一段时间，此时你就可以骑它了，为了从大象身上下来，骑手必须先让它坐下（即按一下Shift），然后你就可以下来了（在按一下Shift）。印度象可以装备一件特别的豪华服装：
除了衣服之外，还可以给大象一个漂亮的宝座。
套箱可以放在每头大象身上，这样大象就可以携带物品。（放上套箱后，你会获得一把钥匙）
钥匙是用来打开套箱的。猛犸象还可以携带两个额外的箱子。可以制作三种不同的象牙增强材料：木头、铁和钻石。w
成年大象和猛犸可以装备增强过的象牙，你可以用镐右键取下来。当他们穿上牙套并被玩家骑上时，他们会破坏方块。（然而，在多人游戏中默认禁用该特性，以防止破坏地形）
猛犸的破坏力比大象更强。
关于牙套（我这么叫它）的合成配方详见JEI
一个象轿可以放在大象身上（种类不知道限不限），允许它们携带第二个玩家。
为了让第二个玩家下来，首先骑手得让猛犸象坐下（即按shift），然后第二个玩家在靠近猛犸象时按Shift。第二个玩家可以通过按下Shift键来从象身上下来。
9.科莫多巨蜥
x
科莫多巨蜥生成在沼泽和草原。小动物是它们的食物。它们的牙齿具有毒性。杀死科莫多巨蜥后，有25 %的几率掉蛋，把蛋至于火把中（3×3中间放蛋）。可以通过喂食科莫多巨蜥火鸡肉和鼠肉。一个鞍可以放在一个驯服的成年科莫多巨蜥，来达到骑行的目的。
10.巨型傀儡
x
巨型傀儡在夜晚生成，最初只由三个方块组成：头、核和矿石块。当巨型傀儡靠近玩家时，它会激活并形成自己的身体（就是会吸周围的方块）。
它有强大的近战攻击，也有远程攻击，怪物可以投掷方块。
当它受到攻击时，就有机会摧毁它的一个方块。摧毁一个方块的可能性取决于击中位置。如果胸膛打开，傀儡的核心暴露在外，它会受到伤害。w
巨型傀儡受到伤害时，它会变得更加危险。傀儡危险等级的一个暗示是它的头的颜色。蓝色表示没有攻击性。黄色开始攻击，橙色是它受到了相当大的伤害。在即将爆炸的怪物身上可以看到红色。
巨型傀儡将不断尝试获取新的方块。每获得一个方块，怪物就会被治愈（治疗的数量也取决于位置）。w
当怪物能量光环是红色时，寻找掩体可能是明智的，因为怪物爆炸的速度较快。
当一个巨型傀儡死后，它会掉下所有它身体的一部分（包括矿石块）。
11.蜗牛
x
它们行动迟缓，有时藏在壳里。杀死蜗牛会掉落粘液球。
12.昆虫
x
包括蚂蚁、蝴蝶、蛾子、苍蝇、蜜蜂、萤火虫、蜻蜓、蛆和蟋蟀。
有些会掉粘液球。
13.火鸡
x
当火鸡被宰杀时，它们会掉下可以烹饪的火鸡肉。

20.鳄鱼
x
file:///C:/Users/ADMINI~1.PC-/AppData/Local/Temp/msohtml1/01/clip_image063.jpg
鳄鱼会在沼泽生物群中的海滩附近游荡，有时它们会保持静止。
不要被“熟睡”的鳄鱼欺骗，它们随时准备攻击，它们的速度会让你惊讶。它们在水中攻击性很强，速度很快。
鳄鱼用它们的下颚抓食猎物，它们会试着把猎物带到水里（动物世界看过吧）。
如果鳄鱼抓住了你，你可以通过攻击它来获得自由，但不是一定成功。观察鳄鱼的下颚并不容易。
鳄鱼皮可以用来制作鳄鱼盔甲

乌龟会躲避任何比他们大的生物。
乌龟能抵抗大多数攻击，除非它们颠倒过来。
如果你右键点击一只乌龟，你会把它翻过来。这个可怜的小家伙要花些时间才能翻回来。
你可以把西瓜片或甘蔗放在乌龟的旁边，以驯服它们。（这时玩家不能靠近它们，否则它们会绝食）
一旦被驯服，你就可以把它们放在头上！

23.猫（个人觉得跟马有的一拼）
x
file:///C:/Users/ADMINI~1.PC-/AppData/Local/Temp/msohtml1/01/clip_image071.jpgfile:///C:/Users/ADMINI~1.PC-/AppData/Local/Temp/msohtml1/01/clip_image073.jpg
野猫会逃避玩家。你可以在他们附近扔熟鱼，一旦他们吃了，他们就不会逃离玩家。然后你可以给他们一枚奖章来驯服他们。一拿到奖章，你就能命名它们。
驯服的猫咪如果找不到装满猫粮或牛奶的猫砂盒或者猫床的话，最终会发怒。（猫咪头上有一个心情栏）
你可以用右键单击来放置床和猫砂，拿着镐子右键床和猫砂可以回收它们。
如果你要搬运小猫床或猫砂，只要空手右击它而不用拿镐。你可以用这种方式运送躺在床上或垃圾箱上的小猫。当猫在吃东西或喝东西时，你可以看到牛奶/食物水平正在下降。
宠物食品：
生猪肉+生鱼的任意组合
一旦小猫吃了，它会寻找一个未使用的猫砂。
过了一会儿，一个用过的猫砂又会恢复到空状态。你也可以在用过的猫砂上使用沙子来清洁它。（如果不清理，会生僵尸和骷髅。）
一只吃过并且用过垃圾箱的猫会自由地游荡，它会再次变得饥饿，并在小猫床上寻找食物，或者它会在晚上睡觉，或者尝试爬树。（一只猫爬上树，会被困在上面，需要帮助才能下来。）
拿鞭子右键猫咪，可以让猫咪听话坐下。不然猫咪会不停的要食物吃。
先给2只猫咪蛋糕或者熟鱼，然后它们会显示爱心。再过一会儿第一只猫会分娩，需要一张猫床。然后可以产下1~3只猫咪，妈妈会因此掉一点血。
小猫会非常顽皮，会追逐任何物品（不仅仅是毛球），会与玩家玩耍，还会追逐它的妈妈。
如果小猫被攻击，它的妈妈会保护它们。
你可以用三种不同的方式来抓一只猫：如果它是一只小猫，它会骑在你的头顶上。一只成年的猫会扛在玩家的肩膀上。如果你用绳子去抓它，你会扛它的腿。猫不喜欢那样被带走，一旦你把它们丢下就会很生气。
如果猫找不到一个装有食物或牛奶的垃圾箱或床，或者一旦被驯服后你攻击它们，它们也会生气。
一旦猫生气了，它会追逐玩家，偶尔也会伤害玩家。过一会儿猫的脾气就会好起来的。
如果你手上有个毛球，猫会跟着你。
如果你把毛球给猫，它就会跟着毛球玩一段时间，追逐并推它，直到猫感到无聊

PS：关于猫的心情栏：
猫粮：表明猫咪饿了。
笑脸：吃猫粮和牛奶时。
愤怒：不给吃的，或者玩家攻击它。
猫砂盒：表明猫咪需要猫砂盒。
给猫咪玩毛球，它会高兴
给猫咪猫砂盒，它会展示"...."
害怕：表示受到惊吓
树：表明猫咪想爬树。爬上树后下不来，需要玩家把它放下来。
痛苦：表明要分娩了，需要凯蒂猫床。
玩家拿着羊毛球时，猫咪会展示"?"，表示好奇
睡觉时，展示"zzz"。

29.海豚
xxxxxx
file:///C:/Users/ADMINI~1.PC-/AppData/Local/Temp/msohtml1/01/clip_image085.gif
有六种不同的海豚（从普通到稀有）：蓝，绿，紫，黑，粉红和白。最后两种在野外很少见到。
驯服海豚：
你可以通过喂海豚生鱼来驯服它们。海豚越稀有，就越需要生鱼。蓝海豚需要2条生鱼，白化海豚需要12条生鱼。你也可以骑着海豚来驯服它们。稀有的海豚比普通的海豚更容易被发现。

繁殖海豚： 驯养的成年海豚可以通过喂它们熟鱼和保持它们与其他动物的距离来繁殖，这与马的繁殖方式类似。小海豚不能繁殖或驯服。 同一颜色的两只海豚的后代必定是这种颜色。海豚的“遗传值”在1-6之间。（蓝色=1，白化=6）如果你混合和匹配海豚，你有1/3的机会获得紫色或深色海豚，如果父母的遗传值增加3或4，你有1/10的机会获得粉红色或白化海豚，如果遗传值增加5或6。也就是说，在1/10的情况下，通过组合蓝色（1）加黑色（4）海豚或绿色（2）加紫色（3）海豚，可以获得粉色海豚（5）。

驯服：
  兔子可以通过简单的右击驯服。这将使兔子被放置在你的头上，并弹出命名窗口。一旦命名，兔子将被驯服。

繁殖
兔子可以通过喂养金色的胡萝卜然后把它们关在一个封闭的空间进行培育。
某些版本兔子可以通过两只驯服兔子任何颜色在一个开放的空间或外壳附近繁殖。然后他们会自行繁殖，繁殖出几个新的兔子。但他们繁殖得相当迅速，兔子的繁殖计划必须稳定，以减少游戏的滞后或溢出。通常，兔子窝会在3-12宝贝兔子。小兔子的颜色永远是随机的，它不是由父母的颜色决定的，就像小猫。
