简介
    很多服主都有个梦想，就是有一天能够自己写插件，但是除了极少数服主以外，很少有人会写插件。现在这个情况改变了，利用skript你就可以办到。 skript脚本插件功能非常强大，可以写出如essentials这样复杂强大的插件。而不需要学习java知识。您可以轻松地创建复杂的自定义命令，在特定条件下执行效果的触发器，以及只需运行周期性的脚本，所有这些都不需要知道任何关于编程的一点点知识，你只需学习一点点skript脚本编写的方法。如果结合其他skript的扩展插件，功能强大不敢想象。Skript是一个流行的服务器插件。它允许服务器管理员在不写任何Java语言的情况下简单的管理Minecraft，这是用触发器（事件）、条件和效果三个部分做到的。当触发器触发，所有条件均满足，效果就会被触发。Skript的基础想法是——自定义 —— 每个服务器都能在没有自定义插件的情况下表现不同。这比你自己钻研插件和找人写插件快的多。同时你也不需要那么多小插件了，这一个插件就够了。

sk的语法
sk的语法结构一般都是：event → condition(s) → effect(s) 即 事件或触发器 →  条件  → 效果，这样的步骤。
比如一个简单的挖石头提示脚本：
  1. on mine of stone:  #事件及其条件
  2.     send "你挖到一个石头!" to player  #效果
复制代码
是不是很简单。
每一个脚本都可以包含许多事件或触发器，每个触发器或事件对应一系列的条件和效果。
比如发射一个雷击效果的脚本：
  1. #事件:
  2. on leftclick with a golden axe:#左键一个金斧头
  3.     # 条件:
  4.     player has the permission "thor" #检查是否有权限thor
  5.     # 效果:
  6.     strike lightning at the targeted block#在玩家前方释放闪电
  7.     broadcast "%player%释放了雷击技能!"#广播释放闪电的消息
复制代码
高级语法
    skript的语法并不局限于简单的语句，也可以是更复杂的语句。做出更加意想不到的效果。在以后的教程中将详细讲解这些应用。高级语法：条件句，循环句，函数，自定义事件、条件、效果等等，我觉得数组也算。
事件    
    事件就是当一件事情发生的时候，例如玩家点击了东西，打出伤害，死亡，吃东西，移动或一个怪物做了一些事情，甚至是环境自己改变。这些事件的发生的时候就会执行事件下面的效果。
例如：
  1. on explode:
  2.     cancel event
  3. 当爆炸时:
  4.     取消事件的发生
复制代码
一般理解为当什么什么发生的时候：
一般格式为：
on ****：
    条件
    效果
注意空格，事件后都有一个冒号。你可以用4个或8个空格或者使用tab缩进。以后所有脚本遇到一个冒号就要换行缩进，这是严格要求的，否则会出现错误。
条件
    条件执行下一部分代码所要判断的前提。
例如：
  1. #事件:
  2. on leftclick with a golden axe:#左键一个金斧头
  3.     # 条件:
  4.     player has the permission "thor" #检查是否有权限thor
  5.     # 效果:
  6.     strike lightning at the targeted block#在玩家前方释放闪电
  7.     broadcast "%player%释放了雷击技能!"#广播释放闪电的消息
复制代码
效果
    效果可以理解为执行的语句，就是事件发生，条件达到，开始执行语句。
例如：
  1. on damage:
  2.     victim is a player
  3.     victim has the permission "skript.god"
  4.     cancel the event
复制代码
cancel event就是一个效果，他的作用是在符合条件以后，取消受到伤害这个事件。
指令
    Skript允许你自己自定义指令。这些指令和其他插件一样被注册，你可以像使用其他指令一样使用它。这些命令与事件写法大体相似，就是一个用指令触发的事件。指令的完全形式如下：
  1. command /commandname <arguments>: # 这里是注册指令
  2.     description: 这里是指令描述（可以省略）
  3.     usage: 这里是告诉玩家怎么使用指令（可以省略）
  4.     permission: 这里是执行这个指令需要的权限（可以省略代表所有人有权限）
  5.     permission message: 当没有权限的时候提示的信息（可以省略）
  6.     executable by: 这里是指令执行这者可以是players/console/players 和 console （可以省略，代表所有方式执行）
  7.     aliases: 指令的别称或者缩写不可以有空格 （可以省）
  8.     trigger: #触发指令以后执行的代码
  9.         这里写上条件或者表达式当这个指令被执行的时候这些代码将被执行
复制代码
例如：
  1. command /hi:#注册一个hi指令
  2.     permission: skript.hi#执行这个指令所需的权限
  3.     trigger:
  4.         message "hi"<span style="line-height: 1.5;">#执行指令以后给执行的玩家发送一条信息“hi
复制代码
  1. command /hi <player>:#注册一个hi指令，这个指令有一个参数是player类型的
  2.     permission: skript.hi#执行这个指令所需的权限
  3.     trigger:
  4.         send "hi" to argument#执行指令以后给参数所代表的玩家发送一条信息“hi”
复制代码
   对比两个代码，发现指令的参数不同，所执行的效果也不同，第二个代码里面的argument代表参数所代表的玩家，可以简写为arg，有多个参数可以使用arg-1，arg-2来调用。
变量
    变量是用来在储存脚本产生数据的。可以使用变量名称来调用存储在此变量名称里面的数据。sk变量有三种：全局变量，局部变量和options(预设值变量,需要{@变量}的形式调用)形式：
全局变量：
{变量名}
局部变量：
{_变量名}
预设值变量：
options:
    option name: option value
变量初始化：
  预先初始化：
  1. variables:
  2.     {logincount} = 0
复制代码
使用的时候初始化：
  1. on login:
  2.     add 1 to {logincount}
复制代码
变量列表
变量列表一般形式为{变量名::序号}：
列如：
  1. command /staff:
  2.     description: Showsonlinestaff
  3.     trigger:
  4.         loop all players:
  5.             add loop-player to {onlinestaff::*}
  6.             if size of {onlinestaff::*} is 0:
  7.                 message "Nostaffcurrentlyonline!Happygriefing;)!"
  8.             else:
  9.                 message "Onlinestaff: %{onlinestaff::*}%"
复制代码
变量列表我会在第三期教程里面详细讲解
在其他语句调用变量的时候以%变量%形式调用（主要是""里面调用的时候必须%变量%）
循环
    循环语句可以用来完成复杂的任务。比如给所有玩家一个礼物等等，一般循环有loop和while循环。
loop循环的一般形式：
  1. loop <expression to loop>:  #loop 循环体：               
  2.     <condition(s)>      #条件         
  3.     <effect(s)>         #效果
复制代码
一个简单的例子
  1. loop {var::*}:
  2.     set {var::%loop-index%} to loop-value + 1
复制代码
  这里的::我们理解他为域操作，循环变量列表{var::*}，第二句是让var::*的所有成员加1并赋值给{var::%loop-index%}，这样我们就可以批量为某一变量赋值,按照变量列表的方式处理有大量变量的内容可以简单高效。
可以循环的对象：
1、变量列表
2、玩家
3、方块
4、实体
………………
对应的循环值：
loop-value
loop-player
loop-block
loop-entity
循环指定次数
loop number times：
表示循环number次
while循环的一般形式：
  1. while <condition(s)>: #while 循环条件：
  2.     <condition(s)> #条件 改变
  3.     <effect(s)> #效果
复制代码
   只要条件达到while循环就会一直持续下去，所以你在while循环的时候必须给条件一个改变的值或者结束条件，否则可能会使你的服务器奔溃。
条件句
这是一个非常好的特性，当条件满足，将会执行这个触发器。大概形式是这样的：
  1. if <condition(s)>:
  2.     code
  3. else：
  4.     code
复制代码
例如：
  1. on login: #事件--当登陆的时候
  2.     if chance of 50%:  #条件 50的几率
  3.         give a cake to the player #效果执行一个give语句
  4.         send "你获得了登陆奖励 =)" to the player #继续执行一个语句，给玩家发送一条提示语句
  5.     else: #if----else语句
  6.         send "没有获得奖励，下个时段再来" to the player
复制代码
这个脚本是给了每个玩家50%的机会，在登录时收到一个蛋糕，并通知他们得到礼物，如果他们没有收到礼物则通知他们下个时段再来

随机传送插件的编写（例子）需要插件：skript，skRayFall
支持版本：理论支持1.7,1.8,1.9全部版本（只在1.8.8和1.9.4测试）
  1. options:
  2. #随机传送的距离默认5000
  3.     min.x: -2500
  4.     max.x: 2500
  5.     min.z: -2500
  6.     max.z: 2500

  8. #冷却时间你可以使用 ticks, seconds, minutes 和 hours
  9.     cooldown: 120 seconds  #当使用指令命令的时候冷却时间

  11.     tstay: 5 seconds #标题显示时间.
  12.     tfadeout: 4 seconds #标题显示时间.

  14. #需要避开的方块（防止玩家掉到虚空，水，岩浆里面）
  15.     avoid: air or water block or lava block

  17. #消息
  18.     cooldownmsg: &c请稍后再传送
  19.     cooldownusmsg: &c请稍后再试
  20.     teleportmsg: &a你被随机传送到
  21.     teleportmsg2: &6%{_loc::new}%&7, &a生物群系是&6%{_biome}%
  22.     teleporttitle: &a你被随机传送到
  23.     teleportsubtitle: &6%{_biome}%
  24.     permissionmsg: &c你没有权限这么做！
  25.     onlyplay: &c只有玩家才能使用此命令
  26.     rloc: &c请输入目的地
  27.     err: &c支持的目的地有：live，nether，end

  29. command /rspawn [<text>]:
  30. aliases: /rtp
  31. permission: randomtp.cmd.use
  32. trigger:
  33.     if argument 1 is not set:
  34.           if executor is console:
  35.               send "{@onlyplay}"
  36.               if executor is player:
  37.                   send "{@rloc}"
  38.               else:
  39.                   send "{@permissionmsg}"
  40.     if argument 1 is "live":
  41.         if executor is console:
  42.             send "{@onlyplay}"
  43.         if executor is player:
  44.             if difference between {cooldowns::rtp::%player%} and now < {@cooldown}:#冷却时间处理
  45.                 send "{@cooldownmsg}"
  46.             else:
  47.                 set {_loc::old} to player's location#记录玩家当前位置
  48.                 while player's location is {_loc::old}:#while循环，如果玩家的位置没有发生变化就一直循环
  49.                    set {_loc::new} to location at random number between {@min.x} and {@max.x}, 0, random number between {@min.z} and {@max.z} of the world "live"#传送地点随机选择
  50.                     loop blocks above {_loc::new}:#循环传送点的方块
  51.                         if loop-block and block above loop-block are air:#防止卡到方块里面，判定是否为空气
  52.                             if block under loop-block is not {@avoid}:#防止玩家掉到虚空，水，岩浆里面，判定脚下
  53.                                 set {_loc::new} to location of loop-block#传送点修正
  54.                                 set {_biome} to biome at {_loc::new}#获取传送点的生物全息可以不需要
  55.                                 teleport the player to {_loc::new}#传送玩家
  56.                                 if light level at player <= 2:#人性化设计防止传送点是黑的

  58.                                 set {cooldowns::rtp::%player%} to now#冷却时间开始计算

  60.                                 send player title "{@teleporttitle}" with subtitle "{@teleportsubtitle}" for {@tstay} with {@tfadein} fade in and {@tfadeout} fade out#这是title信息需要skRayFall的支持
