作者: 寂华    时间: 2020-4-5 01:24
tp权限不建议给，但是给的话可以这样做
输入/lp user 玩家id permission set -Minecraft.command.tp ture
就给了这个玩家tp权限了
给effect权限同理，只需要把-Minecraft.command.tp换成Minecraft.command.effect就可以了
如果是给用户组，就把user 换成group，然后玩家id那里换成用户组名就可以了
如果还不是太清楚，我可以继续为你解答
