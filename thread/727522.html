阶梯式惩罚
简介
相信很多腐竹的服务器都有类似这种规定：
第一次骂人口头警告，第二次禁言一小时，第三次禁言一天，再犯永久禁言
通常管理员们需要用这种方式来记录每个玩家违规了多少次：

显然，这是低效率的，在多人协作中会由于数据不同步出现各种错误
因此，我花了漫长的几分钟写出了这个插件…以下是使用该插件后的一个情景模拟：
玩家A在聊天频道骂人，管理员X发现后使用命令/swp plus A maren ，插件就按照设定好的内容自动对A进行了口头警告。A更加嚣张，在聊天频道各种大骂，管理员X继续输入该命令，插件自动进行了禁言处理。同时管理员Y也看到了A在骂人，也输入了该命令，但是由于插件设有一个冷却时间，没有对A进行重复处罚。
几分钟之后左下角显示玩家B杀死了玩家C，管理员X输入了/swp plus B daren 命令，插件自动将B临时封禁一天；但马上管理员X发现B不是恶意杀死C的，赶紧输入/swp minus B daren 命令，插件按照预设自动解除了封禁…
End
*每个玩家违规了几次的数据全部储存在players.yml中，如果是离线服务器将会使用玩家名称存储，如果是正版验证服务器将会使用玩家uuid存储

配置文件
  1. # /swp plus 命令对同一玩家操作的冷却时间(单位: 毫秒，默认值300000为5分钟)
  2. # 拥有swp.bypassCooldown.<项目>权限的管理员可以无视冷却时间
  3. cooldown: 300000
  4. # 以下用于储存各种惩罚命令
  5. punishments:
  6.   # chat是一个项目名，你可以用英文，也可以用拼音起类似“maren”“zuobi”“shuaping”等名称
  7.   chat:
  8.     # 基本格式为
  9.     # - '违规次数:惩罚命令:撤销该惩罚的命令'
  10.     #   可以通过将"违规次数"设定为同一个值，达到执行多条惩罚命令的效果
  11.     #   "命令"部分可以填写在服务器后台能够执行的任意命令
  12.     #   命令均是直接通过后台执行，无视权限
  13.     #   ":撤销该惩罚的命令"是可选部分，如果是mute命令不建议填写，因为mute命令的设置、解除是同一个命令，可能会造成错误的禁言
  14.     # 使用{player}替代该玩家的名称
  15.     - 1:tell {player} &c请注意不要骂人！:tell {player} &b我错了冤枉你了…
  16.     - 2:mute {player} 1h
  17.     - 3:mute {player} 1d
  18.     - 4:mute {player}
  19.   # 你可以继续建立项目，例如pvp
  20.   pvp:
  21.     - 1:tempban {player} 1h &c随意攻击其他玩家是不允许的行为:unban {player}
  22.     - 2:ban {player} &c你因多次攻击其他玩家，已被永久封禁:unban {player}
  23.     - 2:banip {player} &c你因多次攻击其他玩家，已被永久封禁:unbanip {player}
复制代码

命令&权限
<项目>表示的是在配置文件中的"chat""pvp"等项目名
所有权限默认op拥有，建议手动给op所在权限组加入“-swp.bypassCooldown.*”权限，使冷却时间对每个op启用
命令 权限 说明
/swp reload swp.reload 重新加载插件配置
/swp plus <玩家> <项目> [次数] swp.plus.<项目> 将<玩家>在<项目>上的违规次数加上[次数](可选，默认为1)，并自动执行惩罚命令
/swp minus <玩家> <项目> [次数] swp.minus.<项目> 将<玩家>在<项目>上的违规次数减去[次数](可选，默认为1)，并自动解除惩罚
/swp see <玩家> <项目> swp.punish.<项目> 获取<玩家>在<项目>上的违规次数
- swp.bypassCooldown.<项目> 在使用/swp plus命令处理<项目>时可以无视冷却时间

更新记录
v1.2
1)移除了/swp punish和/swp set两个命令
2)/swp plus和/swp minus命令可以指定增加的惩罚次数了
3)/swp plus命令拥有冷却时间，防止多个管理同时处罚一个玩家导致惩罚过重
4)/swp minus命令能够根据配置文件内写的内容自动解除惩罚
5)新增加/swp see命令，可以查看某玩家的违规次数
6)支持同一违规次数多个惩罚命令
7)修正了重载配置文件导致的一些问题
