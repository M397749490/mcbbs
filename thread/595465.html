作者: 伪笑    时间: 2016-6-26 00:53
除非不让那些组继承Builder这个组
然后以后要是弄什么权限只能单独弄


用这个做一个例子
  Default:
    default: true
    permissions:
    - quickshop.use
    inheritance:
    - builder
    - g:essentials_builder
    - g:towny_builder
    info:
      build: true
      prefix: '&2'
      suffix: ''

更改为
  Default:
    default: true
    permissions:
    - quickshop.use
    inheritance:
    - g:essentials_builder
    - g:towny_builder
    info:
      build: true
      prefix: '&2'
      suffix: ''

这样子的话，名为Default的组就不会继承Builder了以此类推
或将所有的组里    - builder     删除，其他组的玩家就不会继承  builder  组的权限了
作者: 寂静人心    时间: 2016-6-26 04:21
很简单，你只需要在那个指令的下面加一条 变量   PERMISSION: 这里写权限
然后再把你写的权限给builder组，于是这个按钮也只有 有这个权限的 组 才可以使用了
