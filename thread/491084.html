基本操作：

      
您可以创建一个PaintWar游戏通过选择一个长方体地区WorldEdit和使用/ pw create <名称>。游戏开始时/ pw <名称>开始和停止/ pw stop <名称>。玩家加入游戏/

pw join <名称>。将他们分为两组:红色和蓝色。他们将得到一个铁马盔甲“彩弹枪”,可以无限的雪球。现在,无论他们射击会变成彩色粘土在他们的球队的颜色。

。计分板是比赛的计时器。玩家可以离开/ pw leave

,它列出了玩家目前在游戏。状态和时间的游戏可以得到/ pw status <名称>。  其他下面看






命令与权限:
  • / pw start------ paintwar.start  强制开始
  • / pw stop------- paintwar.stop停止
  • / pw join------- paintwar.join加入 【给玩家】
  • / pw leave----- paintwar.leave离开  【给玩家】
  • / pw status----- paintwar.status状态 【给玩家】
  • / pw list-------- paintwar.list列表
  • /pw create----- paintwar.create  建立场地权限和指令
  • / pw delete ---- paintwar.delete   删除场地权限和指令
  • 所有命令-------- paintwar.*   全部权限
  • 管理命令-------- paintwar.manage  .....不知道
  • 使用命令-------- paintwar.use  可能是使用基本命令吧
