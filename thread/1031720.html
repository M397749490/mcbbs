文件提取码：sywo

教程：

首先在bdx根目录创建一个文件夹叫"DataS"
然后在里面创建一个叫"banassistant"的文件夹
基本完成！
*注：只检测正在进入服务器的玩家

下面是配置文件：

"trust.json"
  1. [
  2.     {
  3.         "playername":"你信任的玩家名称"
  4.     },
  5.     {
  6.         "playername":"你信任的玩家名称2"
  7.     }
  8. ]
复制代码
这是给可以飞行、无敌或有op等的人信任(不会被查）

*注：可以有多个或单个，格式一样即可。

“blacklist.json”
  1. [{"playername":"被ban的玩家名称"}{"playername":"被ban的玩家名称2"}]
复制代码
这是储存被ban的玩家的名称。如想uban某人，就把那人名称的那一栏删去即可。

*注：以上内容都可用命令实现

命令：
  1. trust add 玩家名

  3. #信任某玩家

  5. trust remove 玩家名

  7. #解除信任某玩家

  9. ubs 玩家名

  11. #解封某玩家
  12. #请在控制台使用
复制代码
