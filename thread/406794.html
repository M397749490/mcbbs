打开essentials的配置文件config.yml，找到保护部分（大概在520行）作如下设置
  1.     tnt-explosion: true                    # 阻止 TNT的爆炸
  2.     tnt-playerdamage: false                # 阻止 TNT对玩家造成伤害
  3.     tnt-minecart-explosion: true           # 阻止 TNT矿车 爆炸
  4.     tnt-minecart-playerdamage: false       # 阻止 TNT矿车 对玩家造成伤害
