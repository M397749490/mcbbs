ppa 是给 Ubuntu 用的
可使用如下方法安装 JRE8 (官方源只有JRE11, 所以我们用 AdoptOpenJDK 代替)


  2. # 导入源密钥
  3. wget -qO - https://adoptopenjdk.jfrog.io/adoptopenjdk/api/gpg/key/public | sudo apt-key add -

  5. # 添加软件源
  6. sudo add-apt-repository --yes https://adoptopenjdk.jfrog.io/adoptopenjdk/deb/
  7. # (若不成功可先安装基础包后再试 sudo apt-get install -y software-properties-common)
  8. # (或自行修改 sources.list 文件)

  10. # 更新软件源列表
  11. sudo apt-get update

  13. # 安装
  14. sudo apt-get install adoptopenjdk-8-hotspot

  16. 在包名 adoptopenjdk-8-hotspot 中
  17. 8: 代表JDK版本 可选 8-14
  18. hotspot: 代表虚拟机实现类型 可选 hotspot 或 openj9
  19. 稳定: adoptopenjdk-8-hotspot
  20. 性能: adoptopenjdk-8-openj9 或: adoptopenjdk-11-openj9 (Paper端早已支持11)
复制代码

答案摘录自 https://adoptopenjdk.net/installation.html#archives
