异常

我个人比较喜欢把 Exception 叫做 错误
其实叫异常要更加准确一点

你可能听说过一个编程类游戏就叫做  异常（Exception）

你一定听说过 bug 吧
程序员头发杀手
那么 异常 和 bug 是不是一样的呢？
答案是否定的

bug 指程序的缺陷，在安全，逻辑等方面存在的漏洞
而 异常 则是我们可以事先推测的 意外的 可以对程序正常运行产生影响的 事件
异常 是 bug 的子集
这样我们就可以通过一些手段来对其进行处理
在 C# 中，我们使用 try , catch , finally 这三个关键字完成错误处理

下图是最基本的用法
其中的 catch 和 finally 块都是可选的
