好了 第一步你需要一个Notepad++

第二步骤呢 用Notepad++  打开服务端/plugins/GroupManager/worlds/文件夹内的对应世界的groups.yml文件

找到你创建的VIP分组  
  1.   vip:
  2.     default: false
  3.     permissions: []
  4.     inheritance: []
  5.     info:
  6.       prefix: '&c'
  7.       build: false
  8.       suffix: ''
复制代码

差不多就是上面的格式，下面一步就是修改这些代码，
改成下面这个样式
  1.   vip:
  2.     default: false
  3.     permissions: []
  4.     inheritance:
  5.     - builder
  6.     info:
  7.       prefix: '&a[&cVip&a]&2'
  8.       build: true
  9.       suffix: ''
复制代码
简单的说就是在inheritance：的下面添加上- builder                 （意思是让VIP 分组拥有Builder分组的权限）
然后能把Build后面的false 改为true



然后保存  重启服务器 就OK了~~~~
