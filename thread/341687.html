这样好了 我教你怎么弄那个bat文件
你先新建一个bat文件
然后右键他点编辑
然后把我给你的这个复制上去
  1. @ECHO OFF
  2. TITLE XXX #XXX处服务器名称。
  3. ECHO XXXX #XXX处填写开启服务器的时候的消息，随便写= =也可以删除掉
  4. java -Xms1g -Xmx1g -jar XXX #XXX处为你的服务端jar文件的名字
  5. pause
