这个需要用到数据包。
打开存档目录里的datapacks文件夹，新建一个文件夹，名字根据个人喜好写（示例：xxx）。这个文件夹的名字是数据包的名字。
打开文件夹，新建一个记事本文件，在里面写入以下内容
  1. {"pack": {"pack_format":4,"description":"数据包的介绍"}}
复制代码
然后保存，将记事本更名为pack.mcmeta（请确保你可以修改文件的后缀名）
然后在这个文件夹里再新建一个文件夹，更名为data并打开。
新建一个文件夹，名字根据个人喜好来写（示例：yyy）。这个名字是命名空间。打开
新建一个文件夹，更名为recipes，打开
新建一个记事本文件，打开，写入以下内容
  1. {
  2.         "type":"crafting_shaped",
  3.         "pattern":
  4.         [
  5.                 "ABA",
  6.                 "BCB",
  7.                 "ABA"
  8.         ],
  9.         "key":
  10.         {
  11.                 "A":{"item":"minecraft:iron_bars"},
  12.                 "B":{"item":"minecraft:obsidian"},
  13.                 "C":{"item":"minecraft:beacon"}
  14.         },
  15.         "result":
  16.         {
  17.                 "item":"minecraft:bedrock",
  18.                 "count":64
  19.         }
  20. }
复制代码
保存，将记事本更名为zzz.json（zzz为配方的名字，也是根据个人喜好写）
进入游戏，输入/datapack list   如果数据包能够正常加载，应该能看到名为file/xxx的数据包。如果不能看到，请检查资源包设置是否有误，或者输入/reload后再次尝试。
若资源包加载正常，则可以通过命令/recipe give @s yyy:zzz   来使自己解锁这个配方。此时打开工作台，便可在配方书中找到这个配方，并且能够正常合成（其实，如果游戏规则doLimitedCrafting为默认值false的时候，无需解锁也能够使用）。
