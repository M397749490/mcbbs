ChatMenu

通过聊天栏交互来执行指令

如果你想要你的菜单独特一点的话可以考虑使用哦


指令：

/menu  权限 ：menu.use

配置文件:


  1. # name：每个聊天栏菜单的显示的标题
  2. # Hover：鼠标放在文字上面显示的东西
  3. # cmd：点击文字后执行的指令
  4. # 注意 ： 后面要加空格然后提示文字都要带上双引号""
  5. # 颜色用§(alt+167)换行用\n来代替 排版自己注意排版
  6. Title:
  7.   name1: '              §a§l================§c§l菜单§a§l==============='
  8.   name2: '                                §a§lFirstland'
  9.   name3: '               §b§l===点击下方文字可以直接执行指令==='
  10. Menu:
  11.   name: '§a§l  =>§b§l回城§a§l<=         '
  12.   Hover: §a点击回城
  13.   cmd: /spawn
  14. Menu2:
  15.   name: §a§l =>§c§l自杀§a§l<=
  16.   Hover: §c§l点击自杀
  17.   cmd: /suicide
  18. Menu3:
  19.   name: '        §a§l =>§e§l金币排行榜§a§l<='
  20.   Hover: §e§l点击查看服务器金币排行榜
  21.   cmd: /balancetop
  22. Menu4:
  23.   name: '§a§l =>§b§l钓鱼排行榜§a§l<= '
  24.   Hover: §e§l点击查看服务器钓鱼排行榜
  25.   cmd: /mf top
  26. Menu5:
  27.   name: §a§l =>§e§l设置家§a§l<=
  28.   Hover: §e§l设置一个家
  29.   cmd: /sethome
  30. Menu6:
  31.   name: '       §a§l =>§6§l回家§a§l<='
  32.   Hover: §e§l点击即可回家
  33.   cmd: /home
  34. Menu7:
  35.   name: §a§l =>§6§lTP玩家§a§l<=
  36.   Hover: §e§l点击可以打开TP玩家的列表
  37.   cmd: /mf tp
  38. Menu8:
  39.   name: '    §a§l =>§6§l使用VIP秘钥§a§l<='
  40.   Hover: §e§l点击后在指令后方粘贴秘钥
  41.   cmd: '/usekey '
  42. Menu9:
  43.   name: '   §e§l查看vip到期时间'
  44.   Hover: §a§l点击查看vip时间
  45.   cmd: /viptime
  46. Version: 1.0
