介绍
Gives you the possibility to monitor your server performance.
This plugin is based on the powerful tools VisualVM and Java Mission Control, both provided by Oracle.
This plugin gives you the possibility to use the features provided by these tools in Minecraft itself.
This might be useful for server owners/administrators who cannot use the tools.
Furthermore it especially made for Minecraft itself.
So you can also check your TPS (Ticks per seconds), player ping, server timings and so on.
给你一个监视服务器性能的可能。
这个插件是基于来自于Oracle的强大的工具 VisualVM 和 Java Mission Control
该插件给你一个可能，在Minecraft中使用这些工具
这或许对腐竹或管理员非常有用。
此外他是为Minecraft特别制作的
所以你可以检查TPS，玩家延迟，服务器时间控制等等……

请注意：
这是第一个版本的发布，并不意味着插件已完成，有些命令优化还不够
你可以发现很多GitHub中的东西无法实现（包括输出命令的排版）
[size=14.6667px]
Although the first major version is released, it doesn't mean the plugin is finished. Some commands aren't optimized and as you can see on the Github page a lot of stuff isn't implemented yet (including better command output styling).

It's not easy to develop such plugin and it needs a lot time. If you like the project, leave astaronGithubandcontributethere.

指令
  • /ping - 查看你的延迟
  • /ping <player> - 查看该玩家延迟
  • /stacktrace - 获取当前的线程追踪
  • /stacktrace <threadName> - 指定线程追踪
  • /thread - 输出所有正在运行线程的当前状态
  • /tpshistory - 输出TPS每秒历史
  • /mbean - 列出所有可用的Java环境信息
  • /mbean <beanName> - 指定mbean的所有可用属性
  • /mbean <beanName> <attribute> - 输出此mbean的值数
  • /system - 给你服务器的一般信息 (Minecraft相关)
  • /env - 给你服务器的一般信息 (系统相关)
  • /timing - 获取服务器的Timings列表
  • /monitor - 查看CPU使用情况
  • /graph [heap/cpu/thread/classes] - 给你服务器的数据展示图 (地图)
  • /native - 服务器操作系统信息
  • /vm - 输出虚拟机的信息，如Java垃圾回收，Java启动参数
  • /tasks - 关于服务器的任务运行信息
  • /paper - 输出关于PaperSpigot的Timings列表
  • /heap - 关于服务器内存
