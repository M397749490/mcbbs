每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。

然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。
适用于正式版的MOD不兼容预览版，而且大多数MOD都不提供对每周快照的支持。

Minecraft 1.9 仍未发布，15w46a为其第40个预览版。

转载本贴时须要注明原作者以及本帖地址。



Here it is, this weeks snapshot, going by the fancy name “15w46a” is now available. There are still a lot of bug open on our bugtracker that need to be taken care of before we can release version 1.9 of Minecraft, but with each of these snapshots we are getting a little bit closer to that point.
这就是了，这个星期的快照，达到了了一个精致的名字"15w46a"。这个快照还有很多在我们的bug追踪器上的bug处于未修复状态，在我们发布1.9之前要小心它们，但随着每个快照的发布，我们越来越一点一点的接近1.9了。

Now is also a good time to look into the changes between 1.8 and 1.9 if you are creating resource packs or custom maps with command blocks.
如果你是一个材质包制作者或一个使用命令方块的地图制作者，现在也是一个查看1.8和1.9之间不同地方的好时机。

Notable changes:
值得注意的更新：

  • Fixed a lot of bugs
  • 修复了很多bug。
  • Updated version number
  • 更新了版本号。
  • Less strict about entities behavior, but more strict about the colors they use
  • 放松了实体行为限制，但是更严格的限制了它们使用的颜色。
  • Made up at least one notable change to make the list look longer
  • 一个显著的变化：更新列表看起来更长了。

To get snapshots, open your launcher and press the “New Profile” button. Call it “snapshots” and check the box saying “Enable experimental development snapshots” and save. To switch to the normal version, you can select it in the dropdown at the bottom left corner of the launcher. Back up your world first or run the game on in a different folder (See the “new profile” dialog).
想要下载快照，请打开您的正版启动器并且点击"New Profile"按钮，在对话框中把"Enable experimental development snapshots"选项打开，然后将"Use version"选为"Use Latest Version"，保存，然后点击"Play"开始游戏吧~您可以在版本下拉列表中选择回普通的版本。在体验快照前请记得备份地图或者在"new profile"对话框里更改游戏文件夹。

Snapshots can corrupt your world, please backup and/or run them in a different folder from your main worlds.
快照可能会吃了你的存档，千万记得备份或在与你的存档不同的文件夹里运行。

讲的通俗点就是 你看见一个人从苹果专卖店普通地走里出来
你觉得他有没有在那里买了苹果产品
如果你觉得他有在那里买了苹果产品 那他就是有在那里买了苹果产品
如果你觉得他没有在那里买了苹果产品 那他就是没有在那里买了苹果产品

∞不是一个具体的数值 不能拿它来算得有限的具体数值
∞-1等于∞ ∞+1也等于∞ ∞+∞还是等于∞
那这样的话∞+1=∞ 两边划掉∞ 1=0     _(:з」∠)_
所以说不能用无限大来算有限的具体数值
