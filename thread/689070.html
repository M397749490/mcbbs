Linux(6.6)教程：
本帖子并不是说抄袭或者再次教学，只是为了更全面的教学。
Linux是什么？
1.Linux是一种占资源少，优化程度高，使用起来也方便（对于大佬来说）
2.Linux的编码一般统一是UTF8
3.centos是Linux的可以说是远程操作，远程控制，或者指令台终端。

centos详情：

Xshell 5.0.1124，这里就不放下载链接了，大家可以自主下载软件版本，当然也可以用其他软件来操作。
FXP/FTP，有区别吗？编码推荐的话，FlashFXP，优化和上传方式都很好，软件也自带中文汉化。

首先，你购买一台机器，选择最好是使用流量计算（如果是一般的IDC的话，只能固定就认输吧）
最低配置推荐2G 2H 3M.（这个配置的话优化好带个30-40人是无压力，这就是linux）

2.准备Yum库
首先先升级机器的Yum库，如果机器本来就是新的Linux版本就不用了
/yum update（升级Yum）
/yum install screen（这个的话，一般Linux7.2+都是自带的，反正我的是自带的= =）
/yum -y install java-1.8.0-openjdk*(安装JAVA)
随后，如果你的Yum是旧版本，且机器不自带zip、unzip等功能，那么
/yum install zip/unzip

用户名默认root,如果你创建了其他用户，就改成其他用户的用户名。
(创建用户，这个如果是群组的话就创建吧，避免进错窗口。)
首先/cd ..(返回目录)
/cd X(进入X文件夹，一般硬盘都在home，所以/cd home，进入HOME文件夹。)
如果你不想用FTP，也可以通过/mkdir 文件夹名字 来创建一个文件夹。如果你时间多的话······
随后，用于实验，我们输入
/cd ..


/cd home
/mkdir Spigot(创建一个spigot的文件夹)
进入这个文件夹，输入vi /home/start.sh（创建一个start.sh的文件）
然后编辑这个文件，编辑为java -Xmx1024M -jar spigot.jar nogui(java为命令，Xmx是最大内存，为1024M，spigot.jar是核心名字，nogui是取消GUI界面（初中翻= =）)


好的，创建完这个文件之后，把你的服务端核心上传上去吧！
上传上去之后，进入你的后台，输入/cd .. /cd home /cd Spigot
然后在FTP里把核心及start.sh右键并设置权限777.（启动服务器无权限的解决方案）
就算是ROOT，也必须设置权限。
设置之后，再输入./start.sh，就开服成功了。


什么？关闭界面后服务器也会随着关闭？
screen -S spigot（创建一个新界面，界面名字为spigot，切记要在开服前输入）
下次在进你的CENTOS的时候只要输入screen -rx spigot即可


（关闭网络防火墙） 永久性生效，重启后不会复原
开启： chkconfig iptables on
关闭： chkconfig iptables off

Windows详情教程：

哈喽，欢迎回到正常的世界，如果你不会centos的话。
首先，你需要购买一台windows系统的机器
这里推荐Windows2012/2008，这两种系统都十分适合开服。
配置就不多说了，那么我就说正题了。

操作方式我就不多说了，首先先安装 java
1.8以下版本用java7，以上版本用java8（推荐）
www.java.com （这里就放官方链接了，不放外链了）
准备好JAR核心，新建一个文本：

@echo off

:MAIN
cls
java -Xms1024M -Xmx1024M -jar 核心文件名字.jar
if exist "plugins\RestartEvolution\restart.mcs" goto MAIN
if not exist "plugins\RestartEvolution\restart.mcs" goto END
:END
echo.
pause>nul


然后保存，最好是N++软件保存，防止乱码
根据个人情况改动即可
然后开服吧！

什么？》开不了服务器？啥EULA，直接开啊？
如果出现
[17:50:40 INFO]: Generating new properties file
[17:50:40 WARN]: Failed to load eula.txt
[17:50:40 INFO]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.

这种情况需要打开EULA.TXT，然后把false改动true，因为这是腐竹的EULA协议，这里也希望各位准守。盗版不要紧，不要做出出格的事就行。

成功开服后，按照个人情况优化。
打开网络设置，关闭windows防火墙。
如果是家庭电脑，请使用某蛤蟆吃、某域名等固定IP的软件，如果是WIFI，可以去192.168.1.1端口映射25565即可。
百度搜索IP两个字母，即可看到个人的IP情况。如果是WIFI，请打开网络，属性即可查看。

惊喜：
windows优化DNS后，可以使用VPN来挂北京等防御一些攻击。或者做域名解析防ping，以防一些普通的攻击。
