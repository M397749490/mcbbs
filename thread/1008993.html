tick.json 里的函数不能停止运行（除非用 datapack disable 把整个数据包停掉），不过你可以给其中的命令加一些条件，例如：
  1. execute if score #enable value matches 1 run say 233
复制代码
只有在 #enable 的 value 分数为 1 时才运行 say 233.
延时可以用高频给记分板加分然后检测记分板的分数达到指定值后执行指定命令。
或者可以用 schedule 命令，例如：
  1. schedule function foo:example 10s
复制代码
10 秒后运行函数 foo:example.
