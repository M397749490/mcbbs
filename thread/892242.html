原本需要钱的操作不要钱就能做到, 原因无外乎三点:

1. 设置问题, 你认为要钱, 其实是不要钱的

2. 插件逻辑, 作者认为要钱, 实际上是不要钱的

3. 插件调用 vault api 进行查询/扣钱时发生了异常, 这种情况下一般可以在后台看到报错信息.
