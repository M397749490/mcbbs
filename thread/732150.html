标题: 关于从物品栏删除的物品的获取，如下界反应核
如题目，在现版本被删除的物品如何通过命令获取。已解包，证明部分已删除物品并未从游戏内删除，只是隐藏了，例如发光的黑曜石和下界反应核，对应的材质仍然存在。那么要如何获取当前版本的已删除物品呢？例如说，反光的黑曜石物品ID是glowing_obsidian，但是直接输入/give @p glowing_obsidian并不能直接获取，会提示命令错误。
作者: fsxitutu    时间: 2017-10-15 11:20
没办法，这是minecraft本身的限制。因为不知道你这么做是为什么(是在CB中给玩家还是自己用，如果自己用的话用修改器就好了)，不过你真的非要用命令刷的话只能用修改器(例如pocketlnvEditor)先获取后放入箱子，再clone箱子去刷。比如(假设箱子坐标为0,0,0)先/clone 0 0 0 0 0 0 ~ ~2 ~再/setblock ~ ~2 ~ air。如果控制得好别人是很难看出破绽的。
