木牌传送建议用
http://www.mcbbs.net/forum.php?mod=viewthread&tid=76134&highlight=script

直接GroupManager上面改下找到GroupManager的配置文件config.yml
groups:
  Default:
    default: true   （这个改成false）
    permissions:
    - essentials.help
    -essentials.help.*
    --essentials.help.factions
    -essentials.helpop
    -essentials.list
    -essentials.motd
    -essentials.rules
    -essentials.spawn
    -essentials.eco
    inheritance: []
    info:
      prefix:'&e'
      build: false
      suffix: ''
  Builder:
    default: false  （这个改成true ）
    permissions:
    -essentials.home
    - essentials.me
    -essentials.msg
    -essentials.sethome
    -essentials.warp
    inheritance:
    - default
    info:
      prefix:'&2'
      build: true
      suffix: ''
这样玩家进入游戏就直接在有权限的权限组了
然后那些没有权限的玩家输入 /manuadd 玩家名字 Builder

如果玩的人不多的话

你就用这个插件立一个牌子

在/spawn的地方

加一个牌子

上面写

没有权限的玩家

请右键木牌

（这个其实可以乱打的，牌子上的字不影响指令，方块也不会影响指令,你也可以放个门...然后他开门就会触发这个指令）

然后你加了那个插件吧

直接聊天框输入

/sbinteract create [@cooldown:1][@bypass /manuadd <player> Builder]

然后右键牌子把这个指令绑定到牌子上面就行了

[@cooldown:1]这个是表示一分钟的冷却的

万一有熊孩子无脑刷这个也很烦的
