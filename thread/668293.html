Ranged Pumps——远程泵

此MOD只增加了一个物品——一种能够在更大的范围内抽取液体的泵
（把地狱抽干吧！）


MOD汉化及搬运许可
以上为搬运和汉化许可。

MOD安装方式
在安装ForgeAPI之后，直接将MOD主体文件放入mods文件夹即可

主要用途
本MOD只增加了一个物品——泵，这种泵能在一定范围内寻找液体并抽取，然后你需要使用管道把液体从机器内部引出。
这种泵可以使用RF能源，但也可以在config配置中设定不使用。（下文有详细阐述）
因此，本MOD是可以独立运行的，但是独立运行时貌似没有什么用处……液体无法从机器里导出。

主要物品及其合成方式
唯一的物品——泵↓

物品的详细工作方式及使用说明
把泵放置之后，给予其红石信号，泵就会开始工作。
在config配置文件中设置后，泵不需要能量，但泵可以配置为使用RF能量（偷懒的余地……）。
泵的内部储存空间的大小是默认的32桶（32格），可以在配置文件中增加或减少。
当泵的内部已经充满某种液体时，它将会停止运行。
右键单击泵可以显示泵此时的状态（抽取液体、容纳何种液体，等等）。
它的工作范围是泵的一格高度以下的一个矩形区域（默认为128格大小，它将在以泵为中心，64格的区域内搜索），同样也可以在配置文件中指定。
默认情况下，当泵在抽取液体时，会将液体原有位置用石头填补。
下图是泵搜索液体的方式，从左上方蜿蜒曲折（扫描）至右下方，并一直搜索至基岩。
泵在工作时不会保持区块加载，所以，你不能在很远的地方等待泵工作完成。

Config配置文件使用说明
如上图所示的配置文件（在第一次加载MOD之后生成在config文件夹中）
为了展示得更清楚，将文本放入代码行分析。
  1. <font face="微软雅黑"># Configuration file

  3. pump {
  4.     # The capacity of the energy storage [range: 0 ~ 2147483647, default: 32000]
  5.     I:energyCapacity=32000

  7.     # Energy drained when draining liquid [range: 0 ~ 2147483647, default: 100]
  8.     I:energyUsagePerDrain=100

  10.     # Energy drained when moving to the next block [range: 0 ~ 2147483647, default: 0]
  11.     I:energyUsagePerMove=0

  13.     # The range of the pump [range: 0 ~ 1024, default: 128]
  14.     I:range=128

  16.     # Replaces the liquid that is removed with stone to reduce lag [default: true]
  17.     B:replaceLiquidWithStone=true

  19.     # The interval in ticks for when to move on to the next block (higher is slower) [range: 0 ~ 1024, default: 8]
  20.     I:speed=8

  22.     # The capacity of the internal pump tank [range: 1000 ~ 2147483647, default: 32000]
  23.     I:tankCapacity=32000

  25.     # Whether the pump uses energy to work [default: true]
  26.     B:usesEnergy=true
  27. }</font>
复制代码
I:energyCapacity=32000——储存能源上限（RF）
I:energyUsagePerDrain=100——每抽取一单位（单位不明，mB或块）消耗能源（RF）
I:energyUsagePerMove=0——每扫描/移动一次小号能源（RF）
B:replaceLiquidWithStone=true——是否将抽取后的流体替换为石头
I:speed=8——扫描速度（以游戏刻（tick）计算，数值越高，速度越慢）
I:tankCapacity=32000——泵的容量（mB）
B:usesEnergy=true——是否使用RF能源
