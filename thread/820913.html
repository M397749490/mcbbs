二、原帖介绍


What does the plugin do?
When a player was kicked for the reason "Flying is not enabled on this server" it will run a command to ban this player. You can edit this command in the config.yml. Default is it /ban %name% Hacking.
该插件有什么作用？
当一名玩家因为“Flying is not enabled on this server”而被踢时，它将运行禁止此玩家的命令。您可以在config.yml中编辑此命令。默认是/ ban ％name％ Hacking。
