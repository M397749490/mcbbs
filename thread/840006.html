Jojo's Incredible Adventure - JOJO的奇妙冒险


|||    [ Map Info - 地图简介 ]
原作者更新记录：

OK,作者终于后终于完成了这个版本，它没有增加太多的未知的元素，但修复了很多BUG，并且会让你的游戏体验炒鸡顺畅。
在地下城的基础上，我们将地下城优化了，将更清晰，更容易过关。添加了一张地图，以及一个更好地GPS传送器，以及一个炒鸡容易的最终BOOS。
我还添加了一个新的支线任务，这炒鸡重要，并重写了一些比较重要的对话。
这些大量的工作是值得的，现在你们这些大佬可以在没有任何问题的情况下玩这个地图
如果你发现连官方作者都找不到的BUG，请到主题上报告。




什么是JOJO的奇妙冒险：
JOJO的奇妙冒险是一个番剧，我感觉更像是一张游戏地图了XD。它有自带的音乐、剧情、建筑场景、主线任务、支线任务、根据番剧来的各种怪物和boss、当然也有各种副本（真的用心做了qwq）、升级自身的商店、也是设计了一些会随着剧情发展而不同的对话、隐藏地点和解密项目。话说回来，也是做了偏rpg向的地图都会有的货币系统、特殊物品等了啦，玩的开心。




这是一个炒鸡像塞尔达的游戏，具有较为相同的机制和相同的进步感，即使它们根本不是同一个地图。



JOJO原本在一个小村庄开始追求生活。然后在一系列的离奇事件中，他不得不环游不同的城市，地下城，与各种人交谈，解决各种谜团，以阐明方式揭露这皇帝的大阴谋......

为毛这个神秘人向JOJO发号施令？
JOJO希望找到什么惊人的秘密？
JOJO的过去背后到底是什么？
为什么每个人都对JOJO如此的不友好？
你会发现所有这一切，如果你玩JOJO的难以置信的冒险，你会发现更多！



冒险工艺的安装:
对于那些还不了解Adventure Craft的人来说，这里有一些信息：
如果你想玩这张地图，你必须下载这MOD，因为它允许很多原版不允许的东西，比如音乐，剧本等
它是一个独立的MOD，它不会影响你的Minecraft正常运行，无论与Minecraft有什么关系。你都可以安装它，它将自动运行。



持续时间： 6个小时左右。
大致内容：你会发现许多剧情，容易碎的花盆，可以剪草，也有金钱系统，许多秘密区域和不知名的箱子。


建议：简而言之，整个世界都可以探索。我给你一个建议，就是花时间游玩其他区域而不是急于完成主线任务，也可以去完成支线任务。

|||    [ Install - 地图安装 ]
Save存档(正版用户):
1、关闭Minecraft，
2、在Windows资源管理器的路径中输入 %appdata%/.minecraft 。
3、把下载的地图存档解压缩放到. minecraft\saves 文件夹里面。


Schematics存档：
这类型需要MCEdit。
1、下载完成后解压，
2、关闭Minecraft，
3、打开MCEdit.exe，点击下方import按钮，选择你下载的文件，
     最后点import，按Ctrl+s保存，Ctrl+w关掉存档，点Quit退出。
