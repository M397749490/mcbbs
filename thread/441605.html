作者: 上白丶慧泽音    时间: 2015-5-3 21:33
有点麻烦要分限权组
禁止指令 essentials.指令 例如 essentials.back
找到
/plugins/GroupManager/
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          你所需的世界名字:
          - users
          all_unnamed_worlds:
          - users
          - groups
然后在那个世界输入 /mangaddp default -essentials.指令
如/mangaddp default -essentials.back
