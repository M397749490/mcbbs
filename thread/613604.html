  介绍
1. Native解压支持
2. 快速启动MC
3. 缺少库提示
4. 命令行支持
5. 基于Nodejs

  使用方式
安装模块:
  1. $ npm install --save minecraft-launcher
复制代码
快速启动:
  1. const mclauncher = require('minecraft-launcher')
  2. const co = require('co')
  3. co(function* () {
  4.   var core = yield mclauncher()
  5.   core.launch(yield core.load('1.10.2'))
  6. })
