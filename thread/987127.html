- 下载地址与一些注意事项
- 注意事项-可能对新人很重要-

因为我的测试环境是Linux，所以下载解压以后有两个start
start.bat-windows平台
start.sh Linux平台


启动参数
  1. java -Xms2048M -Xmx3000M -jar CatServer.jar
复制代码
因为我自己的基友小服也是基于Catserver，插件mod数量差不太多。在10人左右在线时内存占用差不多在2400MB左右
所以需要更多在线人数请调整最大内存，不建议分配最小1500MB以下内存。

运行环境
请在java8环境下运行，不支持java7环境与java9环境


默认开启正版验证，请支持正版
如有需要请在server.properties中自行调整为
  1. online-mode=false

- Ess插件的设置
1.我的ess是英文的，怎么办
请找到Essentials/config.yml 搜索locale，把locale：en前的#删去，修改为小写的zh
  1. # Set the locale for all messages.
  2. # If you don't set this, the default locale of the server will be used.
  3. # For example, to set language to English, set locale to en, to use the file "messages_en.properties".
  4. # Don't forget to remove the # in front of the line.
  5. # For more information, visit http://wiki.ess3.net/wiki/Locale
  6. #locale: en
复制代码

2.登录进去出来一大堆英语，什么welcome /help
请找到Essentials/motd.txt进行修改，同时，他的记分牌一样是支持papi变量的
示例
  1. &6Welcome！这里是mcbbs服务器, {PLAYER}&6!
  2. &6官网http://www.mcbbs.net
  3. &6当前在线:&c {ONLINE} &6名玩家
复制代码

3.如果你想更加个性化你的服务器提示语
你可以修改ess的提示语
详细教程在这里 https://www.mcbbs.net/thread-544674-1-1.html
