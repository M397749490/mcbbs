配置の解說
#前綴
prefix:
  success: '&a[WatchDog]'
  notice: '&6[WatchDog]'
#訊息
messages:
  playeradded: Player %PLAYER% has been added to the watchlist!
  playerremoved: Player %PLAYER% has been removed from the watchlist!
  playernotfound: Player %PLAYER% is not in the watchlist!
  playeronline: Player &c%PLAYER% &fhas logged in! Run &c/wd info %PLAYER% &ffor details.
#用戶
users:
  text:
    addedby: Text
    addedon: 07-28 11:01:57
    reason: text
指令の解說
/ wd add <player> <reason> - 將指定玩家添加到看門狗觀察列表
/ wd remove <player> - 從看門狗觀察列表中移除指定玩家
/ wd notify <status | on | off> - 啟用/禁用玩家通知
/ wd info <player> - 顯示指定玩家的看門狗觀看列表的信息
/ wd search <player> - 搜索指定玩家的觀察列表
/ wd count - 顯示看門狗觀察列表中的玩家數量

權限の解說

watchdog.use - 允許玩家使用WatchDog
watchdog.add - 允許有這權限的玩家將某玩家添加到看門狗觀察列表
watchdog.remove - 允許有這個權限的玩家從看門狗觀察列表中刪除某玩家
watchdog.statusupdates - 允許有這權限的玩家在觀看玩家登錄時被通知(不懂，求解!!)

安裝の方法


1放入Plugins資料夾
2.重啟伺服器

3.完成!
