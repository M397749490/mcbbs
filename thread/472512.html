4.配置工作


git init：在当前目录新建一个空的git库。

git remote add <远程名称(可以顺便填)> <git地址>：新建一个远程项目（Remote库），用于连接到相应的服务器。

git commit：定义当前的修改为一个版本。

git push：推送本地的所有版本。

git pull：更新本地版本到远程的最新版本，并与本地代码进行合并，不同处进行标示。

git clone：克隆整个远程库到本地。

git diff：对比两个版本的区别。

git fetch <远程名称>


在基本使用中，我们主要使用这些代码。下面以一些情景来说明有什么用。

1.我在本地新建了一个项目，想使用Git进行版本控制：git init

2.我对当前项目进行BUG修复，我要把它推送给我的同事：git commit；git push .

3.我完成了一个更新我想定义当前版本叫version 1.0.1：git commit ……

4.我的伙伴更新了代码，我要更新我当前的版本：(git commit) , git pull .

5.我的电脑还没有任何项目的数据，我要把它下载下来：git fetch ……

6.假如编辑到了某个版本，发现某个功能不起作用了，或者有bug了。但是自己知道之前的某个版本是好的：

      

  1. <font><font color="#000000" style="background-color: white;">git bisect start
  2.       git bisect bad      现在这个版本是坏的
  3.       git bisect good good_commit   good_commit这个版本是好的

  5.       接下来编译，测试。 如果是好的
  6.       git bisect good
  7.       如果还是不好
  8.       git bisect bad
  9.       这样git都会给你输出某个中间的版本让你继续测试。
  10.       
  11.       找到了错误，用
  12.       git bisect reset 恢复到原先的版本。</font></font>
