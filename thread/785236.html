                                                      教程
本插件不需要圈地工具，站在领地的两个对角，输入/foxguard position，然后创建领地/foxguard create worldregion 领地名 rectangular即可创建一个领地，创建完成之后，别的玩家还是可以破坏领地的，就要输入/foxguard create handler 权限组名 basic easy来创建一个权限组，然后再用/foxguard modify handler 权限组名 flags default add block change =false 修改权限组权限，最后/foxguard link 领地名 权限组名来把领和权限组联系起来即可创建一个领地。
