  1. 指令：
  2. 时间必须是两位数(年度是四位数)，如09:20:00   06.12.2013(注意符号)
  3. 以下用<时间>指代<时时:分分:秒秒>；用<日期>指代<日日.月月.年年年年>
  4. # 在每天的固定时间执行命令
  5. /tce set <时间> <执行命令>
  6. # 移除该时间的每日命令
  7. /tce remove <时间>
  8. # 显示每日命令列表
  9. /tce list
  10. ------------------------------------------------
  11. # 在指定的日期时间执行命令
  12. /tce setdate <时间> <日期> <执行命令>
  13. # 移除指定日期时间的命令
  14. /tce removedate <时间> <日期>
  15. # 显示日期命令列表
  16. /tce datelist
复制代码


例：/tce set 09:45:00 say 嗨~~~~~~
在每天的09:45:00就会say 嗨了= =

  1. 权限：
  2. tce.help
  3. tce.list
  4. tce.datelist
  5. tce.remove
  6. tce.removedate
  7. tce.setcommand
  8. tce.setdatecommand
