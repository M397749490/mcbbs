前言

站内的宝可梦徽章成就系统的插件装上后一直刷报错，bug还不少，受不了。自己写了个方便易用的出来。



功能

带GUI界面

按键检测玩家背包背徽章数量

自定义达到多少枚可执行什么操作

比如收集到25枚时给予玩家一个称号和全服通告

目前仅在1.12.2可用

反正口袋服只有1.12.2的2333



使用方法
  • 下载插件
  • 关闭服务器
  • 将插件丢进/服务端/plugins/
  • 启动服务器
  • 修改/服务端/plugins/npoke/config.yml
  • 后台输入命令/npoke reload
  • 完成

命令与权限以及配置文件

指令：
指令
 作用
/npoke open 玩家打开GUI的权限
/npoke reload 重载   

权限：
权限 作用
npoke.use 给玩家打开GUI的权限
npoke.admin 管理权限（不开放给玩家）

示例配置文件config.yml:
  1. #
  2. # button格式: - 位置|名字|标签|功能|物品ID，可以使用颜色代码
  3. # execute格式: - 数量|执行的指令
  4. # 如果是检查玩家身上勋章的，请使用check
  5. # 如果是让玩家领取奖励的按钮，请输入execute中设定的勋章数量

  10.   %player%达成了"天王训练师"的成就！
  11. - 50|manuaddp %player% deluxetags.tag.13;msg %player% 恭喜你成为成为宝可梦大师!请到称号系统查看称号;broadcast
  12.   %player%达成了"宝可梦大师"的成就！

  14. - 1|检测背包内徽章个数|让我康康!|check|5028
