Tweakeroo(Masa全家桶其二)
高级万能工具箱

简介
功能:
向游戏添加了许多不同的“功能调整”。
目前，它是为Minecraft 1.12.x上的LiteLoader，MC 1.13.2上的Rift和1.14.x上的Fabric编写的。
注意：从0.8.0及更高版本开始，Tweakeroo还需要MaLiLib库mod,http://www.curseforge.com/minecraft/mc-mods/malilib
打开游戏内配置GUI的默认热键是X + C (从Rift和Fabric,和0.10.0版本的LiteLoader开始)。

功能
当前可用的功能是：
  • 精准方块放置(Accurate Block Placement ) - 允许以指定方向将方块放置在拥有地毯Mod的服务器上
  • After Clicker后 - 启用"After Clicker"功能后，可自动右键单击刚放置的方块若干次(可在通用配置中设置)。例如放置中继器之后直接调档。
  • 天使方块(Angel Block) -（仅创造模式可用）允许将方块放置在空中(右键空气都能在面前放出方块)
  • 减少爆炸粒子(Explosion reduced particles) - 对大型爆炸使用较小且不怎么遮挡视线的爆炸粒子
  • 快速方块放置(Fast Block Placement) - 有不同的模式可以避免不必要的方块放置。在将光标移到新方块上时启用快速/快速方块放置。有不同的模式可以避免不必要的方块放置。
  • 快速左键单击(Fast Left Click) - 在按住攻击键（左键单击）的同时启用自动快速单击左键。每个tick的点击数在通用配置中设置。
  • 快速右键单击(Fast Right Click) - 在按住使用键（右键单击）的同时启用自动快速单击右键。每个tick的点击数在通用配置中设置。
  • 填充/克隆限制更改(Fill/Clone limit change ) - 允许在单人模式中更改/fill和/clone命令的方块限制
  • 灵活方块放置(Flexible Block Placement) - 可以在按住绑定热键的同时以不同的方向放置方块。例如，漏斗或原木的放置朝向与正常放置时不同。
  • Gamma重写(Gamma Override) - 用"通用配置"中的一个值覆盖默认的Gamma值。
  • 保持手中物品(Hand Restock) - 当前手中即将用完时，将新的物品自动"补货"到主手或副手。
  • 保持攻击(Hold Attack) - 模拟按下攻击按钮（通常是单击左键）
  • 保持使用(Hold Use) - 模拟按下使用按钮（通常是单击右键）
  • Hotbar Scroll- 允许将物品栏与背包中的一行交换（类似于Hotbar Swap）
  • Hotbar Slot Cycle - 使用完物品后循环选中的物品栏栏位。具有可配置的最大栏位。对于放置有固定重复模式的方块模型很有用。
  • Hotbar Swap - 可以将物品栏与三个背包行中的任何一行交换。按住热键时可以预览背包。
  • 背包预览(Inventory Preview) - 使光标停留在具有库存(栏位)的方块或具有库存(栏位)的实体上并按住热键启用库存预览。注意：不幸的是（大多数情况下）该功能仅适用于单人游戏，当前不适用于任何Forge IItemHandler库存，因为这是Liteloader mod，并不了解Forge东西。
  • 物品溢出保护(Item Unstacking Protection) - 如果启用，则在禁用列表 -> unstackingItems 中配置的物品将不被溢出。例如，这意味着要防止在装满桶时避免将岩浆桶扔进熔岩中。
  • 岩浆可见性(Lava Visibility) - 如果启用并且玩家使用了带有水下速掘/或水下呼吸的头盔，那么熔岩雾会大大减少。
  • 地图预览(Map Preview) - 当您将鼠标悬停在地图上并按住shift键时，将显示背包中的地图的预览
  • Movement Keys Last - 如果启用，则相反的移动键不会互相抵消，而是采用最后按下的键的效果。
  • 去除破坏方块粒子(No Block Breaking Particles) - 去除阻隔颗粒
  • 禁用客户端实体更新(No Client Entity Updates) - 删除客户端上的所有(非玩家)实体更新。如果当前世界上由于某种原因而存在大量实体，则可以帮助解决该问题。
  • 禁用实体渲染(No Entity Rendering) - 禁用除玩家实体之外的所有渲染。如果世界上有大量实体，可以帮助解决该问题。
  • 禁用无重力方块实体渲染(No Falling Block Entity Rendering) - 如果启用，则完全不会渲染无重力方块实体。主要用于带有大量下落方块实体的大型装置，渲染时会降低FPS。
  • 不渲染切换物品时的冷却(No Item Switch Render Cooldown) - 如果启用，则切换手持物品或使用该物品时将没有任何冷却/装备动画。
  • 禁用光照更新(No Light Updates) - 如果启用，则禁用客户端光照更新。当许多方块不断变化时（例如使用大型史莱姆飞行器），这可以帮助客户端提高性能。
  • 禁用全部光照更新(No Light Updates All) - 与其他No Light Updates调整相比更彻底。请注意，这还将阻止任何客户端区块heightmap更新或光照重计算。
  • No Portal Gui Closing - 即使站在传送中也能打开库存GUI
  • 禁用粘液方块减速(No Slime Block Slowdown ) - 移除客户端粘液方块的减慢效果和滑溜感。请注意，这也会影响单人模式中的其他实体！
  • 永久潜行(Permanent Sneak) - 无需按住潜行键即可使玩家潜行
  • 放置前拾取(Pick Before Place) - 如果启用，则在放置/使用该物品前，将要放置方块的目标方块切换到主手（如果在背包中可找到）。
  • 放置网格(Placement Grid) - 允许将方块放置限制为可配置大小的网格。注意：当前，这仅在启用快速方块放置模式(Fast Block Placement)的情况下才可用。
  • Placement Limit - 允许将每次使用/右键单击操作所能放置的方块限制为可配置的最大数目
  • Placement Restriction - 允许将方块放置限制为给定的"图案"，例如平面，线，面，列，对角线。这是快速方块放置模式在内部使用的方式，它独立于一个单独的调整即可使用，而无需快速方块放置调整。
  • Placement Restriction First - 仅允许在与一开始放置的方块相同类型上放置相同的方块
  • Placement Restriction Hand - 仅允许将方块放置在与手持物品相同类型的方块上
  • Player Inventory Peek - 当按住热键时,允许玩家peek/预览背包。
  • 药水效果警告(Potion Warning) - 当药水效果即将结束时，在actionbar中打印警告
  • 打印死亡坐标(Print Death Coordinates) - 死亡后在聊天栏中打印玩家的死亡坐标
  • 移除自己的药水效果(Remove own potion effects) - 移除玩家本身的药水效果的粒子
  • 渲染隐身实体(Render Invisible Entities) - 渲染隐身实体（于处于旁观者模式的渲染方式相同,个人测试不可渲染玩家实体）
  • 渲染限制实体(Render Limit Entitie) - 允许限制所渲染的经验球和物品实体的数量。如果世界上有很多这样的实体，可以为FPS带来很大的提升。
  • 修复模式(Repair Mode) - 交换损坏的物品并将修补后放回玩家手上，允许站在经验农场中时自动修复它们
  • 潜影盒预览(Shulker Box Display) - 当鼠标悬停在物品上方并按住Shift键时，渲染潜影盒(以及其他所有带有库存(栏位)的原版方块)的内容
  • 堆叠空潜影盒(Shulker Boxes Stack when empty) - 启用空潜影盒最多可叠加64个注：此仅在单人游戏可用！在多人游戏中，服务器必须具有其他某些Mod具有相同功能，否则在堆叠的潜影盒周围移动时，背包会不同步！
  • 交换几乎破损的工具(Swap Almost Broken Tools) - 如果启用，则手中将要使用且即将破损的任何可损坏物品将交换为还能继续使用的同类型物品。
  • Tab完整坐标(Tab Complete Coordinates) - 当您在不看向方块的情况下在命令中使用制tab补全时，请使用玩家坐标而不是输入"~"字符
