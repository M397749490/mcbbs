您好楼主，很理解您的心情。关于Decimation的使用我没有相关经验，但我查阅了Mcbbs相关帖子。本帖提供了相关的汉化配置文件。

您提出的需求时关闭Decimation的自动更新检查，请尝试在decimation_server.properties文件中，将
disableUpdates=false -> true
以禁用自动更新。

此外，您在报错文件中提供的信息，似乎有一项报错和服务器MOTO相关，如果您在试图处理这个问题，请尝试在decimation_server.properties文件中，将moTdImage= 链接 ->任意有效的图片链接
我无法确定MOTO是否可以为空，但这值得尝试。
  1. [00:33:06] [Server thread/INFO]: 没有服务器图标，从官网下载一个!
  2. [00:33:07] [Server thread/INFO]: 无法获取服务器图标！你必须自己创造!
  3. [00:33:07] [Server thread/WARN]: java.io.IOException: Server returned HTTP response code: 403 for URL: https://www.boehmod.net/serverfiles/decimation/server-icon.png
复制代码
此处的报错告诉您，您应该关注“就是那个链接我敲不出来不然会直接读....”指向的图片为空的问题。为此，您应该删去此处的链接（不确定的解决方案，因为可能此处不能为空。），或替换为一个有图片的链接。

如果您需要更多帮助，请通过回复继续追问，我会尽可能帮您解决问题。

Dec的自动更新一共有两个选项
一个是自动下载更新
一个是更新检查
=.=我也不知道它是什么机制，但是帮朋友解决过这个问题
把更新检查和自动下载都关闭还是会报错
我测试的时候打开自动更新
也就是说disableUpdates=false
然后关闭自动下载更新，就不会出现连接spigot失败的报错
