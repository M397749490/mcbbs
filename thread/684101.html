Broadcaster

介绍
这个插件可以让你轻松地播放服务器的公告
并且支持变量，你还可以自动播放自定义内容，你还可以设置间隔多少秒播放

颜色与符号
颜色
[sub]背下来都是为了你好，MC世界随时用得着[/sub]

符号/变量
[sub]背下来都是为了你好，这个插件就可以装饰的逼格漫天了[/sub]
      
[ * ]不要空格的，因为MCBBS影响，才使用空格
<3?
[ * ]★
[**]?
[p]●
[v]?
[+]?
[++]?
[x]█
[/]▌
%n分界线
%online_players%当前在线玩家的数量
%max_players%服务器能承载的最大玩家的数量


命令or权限
命令:
/brc  >查看插件的全部指令
/brc start >开启公告
/brc stop >停止公告
/brc cast [message] >把一条消息显示在服务器，可能会包括符号与变量还有颜色
/brc reload >很明显的重载有木有

权限 介绍

Config.yml的配置文件

  1. #————————————————————————————————————#
  2. #                                                                                                                     #
  3. #                          Broadcast配置文件                                                              #
  4. #                          汉化by 商萌丿芒果                                                              #
  5. #                          所属小组:PCD                                                                     #
  6. #                                                                                                                     #
  7. #————————————————————————————————————#

  9. # Broadcast的具体选项 #
  10. Cast:

  12.   # 公告显示出来的前缀 (梨子 "&b[&3公告&b] >" )
  13.   Prefix: "&b[&3公告&b] > "

  15.   # 每条公告的信息的间隔.
  16.   # 以秒为单位 [60等于1分]
  17.   Interval: 60

  19.   # 是否在服务器启动时自动开启公告
  20.   OnServerStart: true

  22.   # 玩家是否要有相应的权限才可以看到公告
  23.   # false为不用权限看到公告，true为需要权限看到公告
  24.   NeedPermissionToSee: false

  26. # 消息配置，不是公告消息 (还用说嘛)
  27. Messages:
  28.   Started: "&a公告已成功启动."
  29.   Stopped: "&a公告已停止."
  30.   AlreadyRunning: "&c正在运行该公告插件!"
  31.   AlreadyStopped: "&c该公告插件已停止运转!"
  32.   Starting: "&6试图启动公告"
  33.   ReloadStopped: "&c由于重新加载而停止该插件了!"
  34.   NoPermission: "&c你没有权限那样做!"
  35.   Arguments: "&c参数过少!"

  37. # 符号/变量.
  38. # 自定义你要的符号/变量.
  39. # 预定义的:
  40. #   %n - New Line (\n)
  41. #   %online_players% - 现在在线的玩家数
  42. #   %max_players% - 服务能容纳最大的玩家数
  43. # 下面的是符号
  44. Placeholders:
  45.   - ["<3", "?"]
  46.   - ["[*]", "★"]
  47.   - ["[**]", "?"]
