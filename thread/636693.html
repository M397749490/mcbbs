你在服务器有很多地标，一直用/warp指令看起来是不是很**！
You've a lot of warps and your /warp looks ugly?
这个插件会给/warp指令增加一个GUI！
This plugin adds an GUI for the /warp command!?

(0)说明
Essentials自带的warp功能，是一个指令，你输入warp后会显示所有的warp除了一部分人用脚本方块之类的插件操作玩家执行这个指令外，似乎用途不大，也不美观，
有的人也有BS或CC之类的菜单文件做一些传送菜单什么的。
这个插件为Essentials的warp功能增加了GUI，可以设置什么方块，lore，前缀，并且可以自定义语言文件~

①指令&权限
指令 说明 权限
/warpcfg help 查看帮助 warpgui.cfg
/warpcfg seticon <地标名称> <材质> 设置某个地标在GUI中显示的物品（物品id或英文名均可） warpgui.cfg
/warpcfg prefix <地标名称> 设置某个地标在GUI中显示的前缀 warpgui.cfg
/warpcfg lore <地标名称> 设置某个地标在GUI中显示的lore warpgui.cfg
/warpcfg list 列出地标 warpgui.cfg
/warpcfg reload 重载配置文件 warpgui.cfg


②配置文件&汉化语言文件
ps：代码可以直接复制，不是图片
配置文件,config.yml
#插件版本,别乱改
config-version: 1.5.3
#设置标题
inv-title: &3Warps
#如果此项开启，GUI中物品名称的首字母会大写
first-char-caps: false
#如果此项开启，才能在/warp中打开gui
includecmd-warps: true
语言文件,message.yml
No_Permissions: &c你没有权限这样做！
No_Prefix: &c地标 &4{warp} &c没有前缀！
No_Warps: &c没有可用的地标！
DoesntExist_Warp: &c地标 &4{warp} &c不存在！
NotA_Player: &c你不是个玩家！
NotA_Number: &4{number} &c不是一个数字！
Changed_Icon: &a图标改为了 &2{icon}
Changed_Prefix: &a地标 &2{warp} 的前缀&a修改成功
Removed_Prefix: &a地标 &2{warp}&a 的前缀&4删除成功
Added_Lore: &alore已经被添加到地标 &2{warp}
Removed_Lore: &aID为 &2{id} 的lore &a已经从地标 &2{warp} 中移除。
Unkown_Material: &c未知材质 &4{material}
Unkown_Argument: &c未知的参数 &4{arg}
Unkown_ID: &未知的ID &4{id}
Usage: &6帮助: &e{usage}
Usage_Add_Lore: &6使用 &e{usage}&6来添加一个lore
Usage_Remove_Lore: &6使用 &e{usage}&6来删除一个lore
Usage_Change_Prefix: &6使用 &e{usage}&6来修改一个前缀
Usage_Remove_Prefix: &6使用 &e{usage}&6来删除一个前缀
Reloaded_Config: &a配置文件重载成功！
Teleporting: &6正在传送到地标 &e{warp}&6...
Teleporting_Secounds: &将会在&e{secounds}&6 秒后&6传送到地标&e{warp}...
Teleporting_Stopped: &c停止传送到地标 &4{warp}
List_Warps: &6可选地标: &e{warps}
Info_MadeBy: &a作者 &2{info}
Info_Version: &a版本 &2{info}
