★ 简介
在其它游戏里（像CSGO），玩家死亡后都会注视着杀死他的那个玩家一段时间
这个插件把这个功能做出来了
推荐FPS或对战类的服务器加入
When a player dies, they will "watch" ("spectate") their killer the moment they die for a brief period of time before respawning. This is similar to most FPS games.


★ 原贴演示视频
https://www.bilibili.com/video/av64174770/

★ 指令/权限
被插件没有任何指令和权限
这个插件的配置是通过配置文件调整的

★ 特性
处于死亡状态的玩家无法移动和执行指令
部分白名单指令可执行
这个插件兼容一些处理死亡复活的插件（像PlayerDeathEvent和PlayerRespawnEven）
Players in death spectating mode will not be able to move or do anything other than spectate at their death location (duh), chat, and use a set of commands that you allow (such as /me, /msg, etc.)
Unlike some other plugins, this one attempts to maintain compatiblity with existing plugins, particularly those that handle death and respawning (PlayerDeathEvent and PlayerRespawnEvent).


★ 配置文件
QAQ原贴没有说明配置文件，这是我一点一点测试出来的结果

  1. respawnTimeInSeconds: 8
  2. # 复活时间，默认8秒
  3. usePermissionForSpectating: true
  4. # 是否启用死亡观察
  5. respawnWithServerDefaultGamemode: true
  6. # 复活时是否安装服务器设置的模式（生存模式）复活
  7. useDamageCauseBlacklist: false
  8. # 是否使用死亡方式的黑名单：默认关，若启用，该若玩家死亡的方式在黑名单内，就不会触发死亡观察
  9. damageCauseBlacklist:
  10. - SUFFOCATION
  11. # 死亡方式的黑名单：默认窒息，若想清除就填null
  12. useWorldWhitelist: true
  13. # 是否使用世界白名单，若启用，在该指定的世界内才会触发死亡观察，若禁用，所有世界都将开启死亡观察，默认开启
  14. worldWhitelist:
  15. - world
  16. - world_nether
  17. - world_the_end
  18. commandWhitelist:
  19. # 白名单指令，下列指令可以在死亡观察时使用
  20. - me
  21. - m
  22. - msg
  23. - message
  24. - t
  25. - tell
  26. - w
  27. - whisper
  28. - list
  29. - help
  30. - '?'
  31. - info
  32. - report
  33. messages:
  34.   spectating: '&c你死了! 将在 {0} 秒后复活.'
  35.   deniedCommand: '&c你不能在死亡观察时使用这个指令.'
  36. titleMessages:
  37.   titles:
  38.   - '&c你死了!'
  39.   - '&cGame over!'
  40.   subtitles:
  41.   - 距离复活还有 {0} 秒
  42.   - '分数: &e{1}'
  43.   - '分数: &e{1}&f, 距离复活还有 {0} 秒'
