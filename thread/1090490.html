插件简介


彩弹射击是一款节奏快，动作丰富的多人游戏。

在经典的团队死战模式下，两个团队互相竞争，用雪球轰炸对方。一旦玩家被击中致死，他便离开比赛场地并且退出竞技场，必须在自定义设置的大厅等待其队友完成该场比赛后开始下一场比赛。在等待大厅中，您将遇到所有的彩弹射击玩家，选择您的队伍并等待足够的队员，以及上一场比赛结束。当所有条件都满足时，倒计时开始，宣布下一场比赛。  


作者的话：我们的主要目标是使该插件轻松添加到任何标准生存服务器上，同时不会打扰普通生存模式。玩家不得通过彩弹射击来骗取物品或获得生存玩家以外的其他优势。  



功能特点


该插件功能正在在不断增加，这些功能可能与经典的彩弹射击游戏无关。但不要害怕：根据您的个人喜好，您可以在该插件文件夹中的config.yml文件中修改或禁用大多数功能。



  • 无需客户端或者服务器安装其他模组或插件

  • 可以依照您的喜好建立多个不同的竞技场

  • 竞技场形状、规格完全自由，但是需要建造隔离墙

  • 多个重生点，不同队伍专属重生点

  • 自动轮转竞技场，无需管理员在线调整

  • 无需复杂设置，仅四个指令就能添加竞技场

  • 严格区分生存和彩弹射击，防止以此作弊

  • 简单易行且可单独调节的小商店，可在比赛中获得点数来购买弹药或其他特殊道具

  • 拥有排名系统，玩家可获得积分互相竞争

  • 各种数据的统计，包括但不限于KD值、单场得分、团队进攻、准确度等待

  • 各种功能可单独配置，详情可以点击<a href="http://dev.bukkit.org/projects/paintball_pure_war/pages/documentation/configuration/" target="_blank">http://dev.bukkit.org/projects/p ... tion/configuration/</a>



安装步骤




  1. 在原帖地址下载适用于服务器的版本




  2. 将插件本体拖入服务器plugin文件夹




  3. 重启服务器以加载插件




  4. 开始配置插件相关功能





配置步骤


创建竞技场


该插件不介意您的竞技场在哪里或者看起来想什么，您只需要按照自己的意愿设置竞技场，并且确保在其周围有着某种隔离装置，以至于玩家无法进入或者离开此区域  




  1. 确定一块区域，并且确保玩家不能进出




  2. 给您的竞技场设置标识，且确保竞技场名称单一  /pb arena <name_of_your_arena>




  3. 为每个团队添加重生点，至少需要一个  /pb <name_of_your_arena>  <team_name>




  4. 为观众设置重生点 /pb arena <name_of_your_arena> spec




完成了！您成功设置了一个竞技场，可以使用/pb arena <name_of_your_arena> info检查相关信息


设置大厅


大厅是玩家等待游戏开始的地方，大厅总是允许等待一场比赛且死亡的队员将被传送回大厅，他们将在大厅等待当局比赛的结束



  1. 选择一块区域，并且确保玩家不能进出

  2. 在大厅使用指令/pb admin lobby spawn生成


翻译配置


Paintball插件会向您显示许多消息，当然您也可以对此进行更改！


在服务器文件夹中搜索名为“ / plugins / Paintball / languages /”的文件夹。默认情况下，它将包含一个名为“ enUs.txt”的文件，该文件包含约300行的格式：
THE_NAME_OF_THE_MESSAGE =“这是文本”


这些行中的每一行代表插件在某些情况下使用的特定消息。可以使用＆[颜色代码字符]格式的颜色代码。Paintball将忽略以“＃”开头的行。


现在，如果要更改插件消息，例如，将插件翻译成您的语言，请执行以下操作：




  • 不要修改默认的enUS.txt文件。该文件实际上未由插件使用，并且在每次插件启动时都会被覆盖！如果您更改了其中的任何内容，这些更改将在下一次启动插件后消失！




  • 创建默认enUS.txt文件的备份并重命名，例如：“ zhCN.txt”




  • 现在您可以开始修改此文件中的消息了！只需在引号之间更改文本。请勿更改属性值（通常以大写字母书写）或以其他方式更改文本的默认格式！另外，请尽量避免使用诸如öäüÖÄÜß等特殊字符，否则插件可能无法加载文件。




  • 提示：您可以尝试将翻译文件编码为“ utf-8（无BOM）”，以允许使用特殊字符。同时在配置文件中“ Language.File Encoding：utf-8”设置编码。您将需要自己使用特殊文本编辑器来查找操作方法。我通常建议使用Notepad++[译者注：由于开发者问题，更推荐visual studio code]。




  • 提示：记分板上使用了一些较短的语句。这些将被削减为16个字符的长度（颜色代码也算作2个字符），因为Minecraft不支持将它们设置得更长。所以，您应该尝试使其长度尽量达到16个字符。




  • 完成后，您必须告诉插件您要将此新文件用作翻译，而不是默认的enUS.txt文件。为此，请打开config.yml，然后在条目“ Language.File Name：enUS”中输入新的文件名，在我们的示例中，该文件的名称应类似于：“ Language.File Name：zhCN”




  • 做完了！现在，您必须检查插件是否可以加载您的自定义langauge文件。插件将自动检查是否可以找到所需的所有消息，以及文件是否有问题。它将尝试让您知道出了什么问题，然后它将切换回默认文件！因此，在尝试使用新的语言文件出问题之后，请务必查看控制台日志！




  • 如果显示您的自定义语言文件有问题，请执行以下操作：首先忽略警告，然后检查特殊字符。特殊字符会使信息更加混乱，因为插件无法为您显示正确的错误消息。
