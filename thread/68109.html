MinecraftSP登录器的原理及制作 讲了在windows下cmd启动mc的大概原理, 关键代码:
  1. javaw -Xms512m -Xmx1024m -cp "%APPDATA%\.minecraft\bin\*" -Djava.library.path="%APPDATA%\.minecraft\bin\natives" net.minecraft.client.Minecraft ID
复制代码
要启动非c盘下的mc, 就需要设置APPDATA变量, %-dp0代表当前路径:
  1. SET APPDATA=%~dp0
复制代码
复制下面代码保持到*.bat文件, 最简单的mc启动器就诞生了:
  1. SET APPDATA=%~dp0
  2. javaw -Xms512m -Xmx1024m -cp "%APPDATA%\.minecraft\bin\*" -Djava.library.path="%APPDATA%\.minecraft\bin\natives" net.minecraft.client.Minecraft ID
复制代码
将*.bat放在.minecraft同级目录, 这就是最原始的mc绿色版, 论坛有许多教程, 这并不新鲜了, '宇宙最快的mc启动器'也是基于此~

这里尝试使用vbs来启动mc, 用过宇宙最快启动器的同学应该有体会, 使用cmd方式启动mc时会弹出一个黑框, vbs可以很好的解决这个瑕疵, 当然还有其他方式可以解决这个问题, 这里就只展示使用vbs:
  1. set WshShell = CreateObject("Wscript.Shell")
  2. set env = WshShell.Environment("Process")
  3. env("APPDATA") = "minecraft-index"  ''定义MC配置目录
  4. WshShell.run "javaw -Xms512m -Xmx1g -cp jinput.jar;lwjgl.jar;lwjgl_util.jar;minecraft.jar -Djava.library.path=.\natives net.minecraft.client.Minecraft Je",0
复制代码

将上面代码复制保存为*.vbs放在bin目录下, 选择合适的参数, 自定义APPDATA目录, 运行*.vbs会自动创建不存在的目录, 目录下会创建一个.minecraft文件夹, .minecraft文件夹里面除了没有bin文件夹其余内容和c盘下.minecraft结构完全相同, save,mod,texture,settings都是独立存在不会产生冲突(绿色版的奥义):
