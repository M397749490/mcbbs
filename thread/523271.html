标题: 【求助】plotme地皮插件怎么点火
我用的plotme 地皮插件，开的1.7.2的服

发现，玩家在地皮都打不着火，也没有提示

怎么给玩家加可以打火的权限
作者: 鸭蛋只吃黄    时间: 2015-11-17 22:53
在ess的配置文件里有一项是禁止打火石产生火，代码如下
  1.     water-bucket-flow: true               # 阻止 水桶水的流动
  2.     fire-spread: true                      # 阻止 火的传播
  3.     lava-fire-spread: true                 # 阻止 岩浆引起的火的传播
  4.     flint-fire: false                      # 阻止 打火石产生火
  5.     lightning-fire-spread: true            # 阻止 闪电引起的火的传播
  6.     portal-creation: false                 # 阻止 传送门的创造
  7.     tnt-explosion: true                   # 阻止 TNT的爆炸
  8.     tnt-playerdamage: true                # 阻止 TNT对玩家造成伤害
复制代码

默认为禁止产生火，把这项改成“false”即可解决问题
