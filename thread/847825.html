介绍：
天空平原生成器，拥有无限世界和旧世界两种类型。
有何特性？
  • 优质天域生存体验
  • 植被矿物一应俱全
  • 大面积平原方便居住建筑
  • 更多乐趣等你探索发现

使用：
将本插件丢进服务端plugins文件夹内，重新启动服务器即可。没有命令与权限。
注意：请在使用前备份使用原始生成器生成的世界，此生成器会直接替换原始生成器。

配置：
config.yml
  1. #是否启用生物群系
  2. biome: true
  3. #是否启用旧世界生成器
  4. old: true
