  我测试过mcbbs其他的两个隐藏玩家的插件，都比较坑，报错很多并且使用起来优化很差，所以这个插件可以说是目前MCBBS已知隐藏玩家插件中最好的一个！

功能简介：
  • 隐藏玩家
  • 显示玩家
  • 修改物品（支持颜色代码）
使用说明：
  • 下载PlayerHide
  • 放至服务器plugin文件夹下
  • 重启服务端（配置文件请自己转码 windows为ANSI，面板服和linux为UTF-8）

配置文件文本：

#PlayerHide:
#  slot: 0                                      物品在快捷栏位置 0为第一格 8为最后一格
#  show:                                        显示玩家物品名
#    item:
#      material: INK_SACK                       物品英文名
#      byte: 10                                 物品子ID
#      name: '&9显示&a玩家'                     游戏中名字
#    message:                       
#      enable: true                             是否打开文本提示
#      message: '&9PlayerHide&8> &a你显示了所有玩家'                提示语
#  hide:                                        隐藏玩家物品名
#    item:                                      同上
#      material: INK_SACK                       同上
#      byte: 8                                  同上
#      name: '&9隐藏&a玩家'                     同上
#    message:                                   同上
#      enable: true                             同上
#      message: '&9PlayerHide&8> &c你隐藏了所有玩家'                提示语
#
#========================================以下为配置文件===============================================
PlayerHide:
  slot: 0
  show:
    item:
      material: INK_SACK
      byte: 10
      name: '&9显示&a玩家'

      enable: true
