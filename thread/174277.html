用远程桌面的相信是Windows...
那么去http://dl.bukkit.org/下载一只服务器端（目前最新稳定版：1.6.2

然后在与服务器端jar同一个目录新建一个run.bat然后里面输入（用记事本即可）
  1. java -Xmx1024M -jar craftbukkit.jar -o false
  2. PAUSE
复制代码
-Xmx1024M是最大内存
craftbukkit.jar改为你的那个bukkit端的jar的名称
-o flase是关闭online-mode（允许盗版

然后服务器就应该能成功启动的了
