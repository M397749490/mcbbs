原理分析:

总的来说这个游戏就是由一个外齿轮和一个内齿轮组成,为了方便以下外齿轮统称为外圆,内齿轮统称为小圆.

大齿轮固定不动,小齿轮紧贴大齿轮内轮廓作转动(可以简单理解为小齿轮绕大齿轮转动),由于是啮合形式的,在转动的过程中对于小齿轮自身是自转.
在小齿轮上任意找一个点开孔(不要圆心),在转动的过程中,这个孔形成的曲线就是繁花曲线.大概类似于下面这张图(轨迹没有画出来)

理解了游戏规则现在就想想怎么去实现:
1.首先做出最简单的一步,完成小圆绕大圆圆心的转动.因为大圆是固定不动的,大圆圆心处用一个盔甲架BigO(实体)做标记,然后让这个盔甲架每次往右(顺时针)或者往左(逆时针)旋转1°,具体顺时针还是顺时针可以通过变量控制.然后在大圆圆心处生成一个新的盔甲架(实体)并让该盔甲架获得大圆圆心的视角,这个新的盔甲架就代表小圆圆心,然后用局部坐标将小圆圆心TP到该有的位置.那么这个该有的位置是怎么去衡量的呢?我们可以通过计分板自定义大圆的半径和小圆的半径,为了让小圆和大圆紧贴,这段TP的距离就应该是R-r(即大圆半径-小圆半径).


2.现在我们已经解决了小圆绕大圆公转的问题,那么怎么解决小圆本身自转的问题?首先要知道我在实现的时候,规定了大圆圆心视角每次只转动1°,也就是说小圆每次自转要转动的弧长就是大圆这1°的弧长.

弧长计算公式l:
l = n（圆心角）× π（圆周率）× r（半径）/180
算出大圆1°的弧长之后,我们只需要把这段弧长映射到小圆上,看这段弧长在小圆上表现为多少度,那么算出来的角度就是小圆应该转动的度数.
现在把公式变式一下,我们最终要算的是小圆要旋转的度数,那么:
n(小圆圆心角)=(180×l(大圆弧长))/(π× r(小圆半径))


接着再把l带入得:
n(小圆圆心角)=(180×(n×π×R(大圆半径)/180))/(π× r(小圆半径))


约分得:
n(小圆圆心角)=n×R/r


把n=1带入得:
n(小圆圆心角)=R/r

实际上算到最后你会发现,小圆转动的角度就是大圆半径比小圆半径的值.


3.现在我们虽然得到了每次小圆转动的角度,但是还有一些细节上的问题.之前说过,小圆圆心能被TP到目标点是因为采用了局部坐标,这代表如果小圆直接旋转,小圆每次的角度都是从大圆角度继承过来的,这很不柯学!所以我这里用一个实体保存每次小圆旋转之后的视角信息,那么大致的流程就是:
最初的初始化->大圆转动1°->小圆获取大圆视角并通过局部坐标TP到应有的位置->小圆将视角修改为存储视角实体的视角->小圆转动应有的角度->视角实体存储小圆转动后的视角->...至此循环闭合


4.最后一点就是不要忘了小孔的生成!!!小圆转动之后,在小圆出生成一个药水云并同步小圆的视角,然后通过局部坐标把小孔TP到该有的位置,该药水云长期存在,不销毁!



源码:

重要的部分函数:
start.mcfunction:

  1. execute at @s run summon minecraft:armor_stand ~ ~ ~ {Tags:["BigO"],Invisible:1}
  2. execute at @s run summon minecraft:armor_stand ~ ~ ~ {Small:1,Tags:["SmallO"],Invisible:1}
  3. execute at @s run summon minecraft:armor_stand ~ ~ ~ {Tags:["Orientation"],Invisible:1}
  4. #得到小盔甲架每次应该旋转的角度
  5. #拿乘上10倍的大圆半径除以乘上10倍的小圆半径,得到的结果每次旋转R0 0.1度

  7. scoreboard players operation TempBigOR flower = BigO flower

  9. scoreboard players operation BigO flower *= Ten flower
  10. #得到小圆旋转度数
  11. scoreboard players operation BigO flower /= SmallO flower
  12. scoreboard players operation angle flower = BigO flower
  13. scoreboard players operation BigO flower = TempBigOR flower
  14. scoreboard players set TempBigOR flower 0
  15. scoreboard players set tempAngle flower 0
  16. scoreboard players set tempTargetLength flower 0
  17. tag @a add start
复制代码
main.mcfunction(tick一直执行):
  1. #不停地改变大圆的视角
  2. execute if entity @a[tag=start] as @e[tag=BigO] at @s run tp @s ~ ~ ~ ~1 0
  3. execute if entity @a[tag=start] run function flower:tpsmall
  4. execute if entity @a[tag=start] run function flower:rotate
复制代码
tpsmall.mcfunction:TP小圆圆心的函数
  1. #TP小盔甲架的函数
  2. #这个地方可以用个变量保存计算结果,没必要重复计算
  3. execute if score TempBigOR flower matches 0 run scoreboard players operation TempBigOR flower -= SmallO flower
  4. #所有关于函数初始化的内容应当放在这两个语句之间Start
  5. #让视角盔甲架保存上一步小圆的视角信息
  6. execute if score TempBigOR flower matches ..0 as @e[tag=Orientation] at @s rotated as @e[tag=SmallO] run teleport ^ ^ ^
  7. execute if score TempBigOR flower matches ..0 as @e[tag=BigO] at @s run tp @e[tag=SmallO] @s
  8. #End
  9. execute if score TempBigOR flower matches ..0 run scoreboard players operation TempBigOR flower += BigO flower

  11. scoreboard players remove TempBigOR flower 1
  12. #为了保证精度,半径都乘10,tp小圆的时候每次tp0.1
  13. execute as @e[tag=SmallO] at @s run tp @s ^ ^ ^0.1
  14. execute if score TempBigOR flower matches 1.. run function flower:tpsmall
复制代码
rotate.mcfunction:旋转小圆盔甲架的函数

  1. #旋转
  2. #然小圆视角变为视角盔甲架的视角
  3. execute if score tempAngle flower matches 0 as @e[tag=SmallO] at @s rotated as @e[tag=Orientation] run teleport ^ ^ ^
  4. execute if score tempAngle flower matches 0 run scoreboard players operation tempAngle flower = angle flower
  5. execute if score tempAngle flower matches 1.. if score clockwise flower matches 1 as @e[tag=SmallO] at @s run tp @s ~ ~ ~ ~-0.1 ~
  6. execute if score tempAngle flower matches 1.. if score clockwise flower matches 0 as @e[tag=SmallO] at @s run tp @s ~ ~ ~ ~0.1 ~
  7. execute if score tempAngle flower matches 1.. run scoreboard players remove tempAngle flower 1
  8. #当旋转完后开始生成药水云
  9. execute if score tempAngle flower matches 0 run function flower:createlongtimeace
  10. execute if score tempAngle flower matches 1.. run function flower:rotate
复制代码

createlongtimeace.mcfunction:生成持久药水云


  1. #生成药水云
  2. execute if score tempTargetLength flower matches 0 as @e[tag=SmallO] at @s run summon minecraft:area_effect_cloud ~ ~ ~ {Tags:["particle","tempTag"],Duration:32767}
  3. execute if score tempTargetLength flower matches 0 as @e[tag=SmallO] at @s run tp @e[tag=tempTag] @s
  4. execute if score tempTargetLength flower matches 0 run scoreboard players operation tempTargetLength flower = targetLength flower
  5. execute if score tempTargetLength flower matches 1.. as @e[tag=tempTag] at @s run tp @s ^ ^ ^0.1
  6. execute if score tempTargetLength flower matches 1.. run scoreboard players remove tempTargetLength flower 1
  7. execute if score tempTargetLength flower matches 0 run tag @e[tag=tempTag] remove tempTag
  8. execute if score tempTargetLength flower matches 1.. run function flower:createlongtimeace
