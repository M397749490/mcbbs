注意 & 教程
  • 必装Java8及以上
  • 如果你没有bat，不知道写什么脚本
        要么下载包端
        要么按以下步骤
        1.新建文本 xxx.text （XXX随便）
        2.重命名文本为 xxx.bat
        3.右键该bat用文本/Notepad++（推荐）方式打开
        4.输入以下（停止服务器stop后可以再自动启动，Xms最小内容-Xmx最大内存）
  1. [url=home.php?mod=space&uid=39305]@echo[/url] off
  2. title Server
  3. :start
  4. java -Xms128M -Xmx1G -jar Spigot-1.13.jar -nojline
  5. goto start
复制代码
  • 第一次启动后请关闭，并且打开当前目录的 eula.txt 将eula=true改为eula=false
  • 再次启动后，非正版服务器的请stop关闭服务器，打开 server.properties 将online-mode=true改为online-mode=false
  • 没有插件，没有插件，没有插件
