作者: 天佑酱    时间: 2020-8-18 22:26
第一个，原理就是检测盔甲架上面是否有特定标签的物品。
比如，检测tag为SMFX110的盔甲架是否有tag为SMFX110的物品：（高频）
testfor @e[type=minecraft:armor_stand,tag=SMFX110] {Inventory:[{tag:{Tags:["SMFX110"]}}]}
如果成功，后面接连锁条件命令方块或者函数内/stats即可检测到

第二个，换个思路，“拿下后”→“获得”，那我们检测玩家背包里有没有不就可以了
比如检测玩家背包是否有SMFX111的物品：（高频）
testfor @a {Inventory:[{tag:{Tags:["SMFX111"]}}]}
如果成功，后面接连锁条件命令方块或者函数内/stats即可检测到

第三个，检测空手：（高频）
scoreboard players tag @a add SMFX112 {Inventory:[{Slot:-1b}]}
检测右键村民，先创建一个检测与村民交流的计分板：
scoreboard objectives add SMFX113 stat.talkedToVillager
再检测分数是否为1，并且实时重置计分板分数:（高频）
execute @a[tag=SMFX113,score_SMFX113_min=1] ~ ~ ~ execute @e[r=5,type=villager] ~ ~ ~ xxx
scoreboard players set @a SMFX113 0
scoreboard players tag @a remove SMFX112
