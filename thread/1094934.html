空岛服务器？这应该是个插件，你的帖子好像错版了
如果是Askyblock插件，想控制岛屿间的距离可以改这边，找不到就用文本编辑器的搜索功能
:
  • ##### 岛屿相关设置 #####
  • island:
  •    #每个岛屿之间的间隔。
  •    distance: 525
  •    #岛屿保护范围，或者是可以建筑范围。
  •    protectionRange: 325
  •    #第一个岛屿出现的坐标，以后所有岛屿会围着这个坐标进行生成，形成围绕这个坐标的群岛。
  •    startx: 0
  •    startz: 0
  •    #海的高度。（海岛用）
  •    sealevel: 0
  •    #空岛的高度，最低为五。
  •    islandlevel: 120
