发现好多人都不知道最近K锅(KCauldron)的官网地址,所以用不上最新版
就是这里:https://gitlab.prok.pw/KCauldron/KCauldro
还有下载地址:https://repo.prok.pw/pw/prok/KCauldron/?C=M&O=D

官方还出了一个启动器,可以自动下载和更新服务端本体和库文件
(面板服估计不能用→_→)

这货是啥?
KBootstrap是用来控制你的Minecraft版本的JVM应用, TA可以安装和更新各种forge服务器.


干嘛用的?
KBoostrap是一个java软件, 就像Minecraft, 每次开服都会更新服务器版本,并且自动安装库文件→_→




图片介绍:
首先: 我什么都没有, 只有一个bat和一个150kb都没有的更新器

打开bat, 咦, 这腐竹没装服务端, 我给他下一个最新版→_→

成功开服

使用教程:
首先把更新器给放进服务器目录(其实放哪都可以)
同目录新建个bat,里面写上
  1. java -jar KBootstrap-<版本>-app.jar -j "-Xmx4G -XX:+UseParNewGC " -d <服务器目录> -r latest
复制代码

比如我的启动器版本是0.2.0,服务器目录就在本目录,就写./
  1. java -jar KBootstrap-0.2.0-app.jar -j "-Xmx4G -XX:+UseParNewGC " -d ./ -r latest
复制代码

然后打开就好了→_→

如果要下载指定版本号,不让他自动更新的话,就把latest给换成backport-<forge版本>
比如:
  1. java -jar KBootstrap-0.2.0-app.jar -j "-Xmx4G -XX:+UseParNewGC " -d ./ -r backport-1388
复制代码

这样我的版本就不会自动更新啦,固定在1388→_→
