作者: huwei5201314789    时间: 2016-9-4 13:03
如果你只想单单禁止右键【使用】的话，EES能做到
  1.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  2.   # 你加载了一次Essentials后,就可以在plugins/EssentialsX/items.csv中找到物品ID列表.
  3.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  4.   alert:
  5.     on-placement: 10,11,46
  6.     on-use:
  7.     on-break:

  9.   blacklist:

  11.     # 阻止玩家放置以下方块
  12.     placement: 10,11,46,4833,368,4844   ###这里输入上镭射枪的物品ID！注意！只能输入整数，后面不能带：

  14.     # 阻止玩家使用以下物品
  15.     usage: 4833,368,4844    ###这里同上

  17.     # 阻止玩家破坏以下方块
  18.     break:

  20.     # 阻止活塞推动以下方块
  21.     piston:

  23.     # 阻止发射器发射以下物品
  24.     dispenser:
复制代码
另外，可以使用banitem插件来ban掉0电0耐久的镭射枪，这样，玩家就不能自主合成镭射枪了，但你可以通过商店出售，NPC兑换方式给予玩家满耐久的镭射枪【满耐久的镭射枪ID就是4844】没有权限的玩家，是无法使用镭射枪，但是却可以持有，且只能用来合成物品！

当然，若你的ESS无法阻止MOD物品的话，那么你需要升级下你的ESS版本了！最新版是可以阻止MOD物品的！
我服务器亲身试验过！

通过NPC兑换这事，看你放什么镭射枪的ID了，如果是4844满耐久的，那么玩家兑换的就是满耐久的，懂了么？
NPCMOD装不装是无所谓的，即便没有，你依旧可以通过QS商店来解决这个问题。QS商店，你放什么，就卖什么，你唯一只需要做一点，ban掉4844:27和4844:26就行了，用banitem，至于怎么获得4844:26，用give即可
然后ESS配置文件里输上4844,【阻止使用】即可，不过，如果以商店插件出售，建议最好标明，镭射枪只能用作合成材料，谨慎购买！
