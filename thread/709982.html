介绍
InfoBoard是一款优秀的计分版插件，但因为原作者弃坑了，导致只能在1.8以下的版本看到他的身影。
现在有了InfoBoardReloaded，外国的重置版，成功支持到1.10-1.13
为了造福大家，我搬运了这款插件。


特点
  • 支持彩色代码
  • 支持placeholdapi的变量
  • 可以设置只在你想要的世界显示
  • 每个计分版显示的时间
  • 支持多个计分版
  • 配置简单易上手

    下面是原文，英语渣翻译不正确，望指出
    1. Disable in worlds you don't want it showing up in
    2. Set scoreboards per group (Show 1 group one thing and another group different things)
    3. Supports color and formatting codes
    4. Configure the scoreboard's title, and rows.
    5. Configure multiple scoreboards to rotate through (No limit of scoreboards)
    6. Set times for each scoreboard to be shown
    7. Use keywords and variables to show info

指令&权限

  2. /ib reload -  重载计分版     -权限 管理员默认拥有
  3. /ib show - 开启显示计分版    -权限 ibr.show
  4. /ib hide -关闭显示计分版    -权限 ibr.show
  5. 看到显示计分版    -权限 ibr.view   玩家默认拥有
  6. /ib set <pg> - 意义不明，应该是设置每个计分版显示的时间

教程

把插件本体和前置插件装到服务器
打开InfoBoardReborn文件夹
打开board.yml
稍微配置一下，食用成功
不会配置的服主，可以把board.yml里面的全删了，复制下面这个，粘贴进去。
修改完board.yml输入/ib reload，可以重新加载计分板

  2. InfoBoard:
  3. #  '计分板的序号，字母或者数字':
  4.    '1':
  5. #显示时间，单位秒。
  6. #如果只有一个计分板，设置多少都一样
  7.     ShowTime: 20
  8. #这行不要改动
  9.     global:
  10. #用户组名称
  11.       default:
  12. #计分板的大标题
  13.         Title: '&e&lowo，我是可爱的计分板'
  14. #计分板的内容
  15.         Rows:
  16.         - '&b&m+=+&7&m==============&b&m+=+'
  17.         - '&7&lInfoboardReborn'
  18.         - '&7是一款非常强大的插件'
  19.         - '&7欢迎大家下载'
  20.         - '&f&f&b&m+=+&7&m==============&b&m+=+'
  21.         - '&7你好呀！%player_name%'
  22.         - '&f生命值:'
  23.         - '&e%player_health_rounded%&a/&c%player_max_health_rounded%'
  24.         - '&f坐标:'
  25.         - '&a%player_x%&7, &a%player_y%&7, &a%player_z%'
  26.         - '&b本服企鹅群:********'
  27.         - '&b服主企鹅号:********'
  28.         - '&0&b&m+=+&7&m==============&b&m+=+'
