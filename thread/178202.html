如果想弄些插件啥的那么就用bukkit端

首先，
安装个java（如果PC上面开服如果你能玩Minecraft就说明你已经有java了，如果没有搜索一下就好，没啥难度
然后去http://dl.bukkit.org/下载一只服务器端（目前最新稳定版：1.6.2

然后如果是Windows就在与服务器端jar同一个目录新建一个run.bat然后里面输入（用记事本即可）
  1. java -Xmx1024M -jar craftbukkit.jar -o false
  2. PAUSE
复制代码
-Xmx1024M是最大内存
craftbukkit.jar改为你的那个bukkit端的jar的名称
-o flase是关闭online-mode（允许盗版

如果是Linux就nano run.sh
里面输入
  1. #!/bin/sh
  2. BINDIR=$(dirname "$(readlink -fn "$0")")
  3. cd "$BINDIR"
  4. java -Xmx1024M -jar craftbukkit.jar -o false
复制代码
Linux启动就在目录下输入./run.sh
而Windows就双击打开run.bat

如无意外.w.
你的bukkit服就已经启动了.w.
