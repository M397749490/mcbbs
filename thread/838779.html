我也在用楼上提到的插件，附送一个配置文件给你参考，我服务器是1.13.2，BC端是最新的构建版，这个插件放在BC插件文件夹里即可，可以正常使用：

  1. ServerName: '登录服'
  2. # This is where the player is kicked to. This is usually the lobby/hub server
  3. KickMessage: '&7&l[&6&l梦境管家&7&l] &6&l该服务器重启或维护中... 请出理由:&4&l '
  4. # Message to be sent to the player who has been kicked. This message is followed by the kick reasonShowKickMessage: True
  5. # Set this to True if you want the kicked player to be able to see the kick reason.
