RestpSign
领地牌子传送
插件特性:
  • 使用牌子进行领地传送
  • 支持子领地传送
  • 自定义配置文件
  • 支持Vault付费创建牌子
  • 自定义权限组扣费
  • 右键进行传送
  • 更好的管理领地和子领地
使用方法:
使用牌子进行创建
  1. #第一行 [restp]
  2. #第二行 领地名称
  3. #第三行 随意填写
  4. #第四行 随意填写

如果要进行修改或牌子不够写,创建完成后视角对着牌子输入指令 /restp edit <领地名称>
子领地命名为 主领地.子领地


插件指令:
/restp help - RestpSign指令帮助
/restp edit <领地名称> - 修改传送领地
/restp subzones <领地名称> - 显示该领地子领地(不输入则为当前所在领地)
/restp reload - 重载配置文件

插件权限:
restpsign.admin - 所有权限(包括创建/修改不需要花钱)
restpsign.create - 允许创建领地牌子权限(默认玩家拥有)
restpsign.edit - 允许使用 /restp edit 指令
restpsign.subzones - 允许使用 /restp subzones 指令
restpsign.reload - 允许使用 /restp reload 指令
restpsign.help - 允许使用 /restp help 指令
restpsign.bypasscooldown - 避免冷却权限
restpsign.bypassmoney - 避免扣费权限

配置文件:
  1. #版本号
  2. version: 0.1.0
  3. #启用创建牌子扣钱
  4. hookVault: true
  5. #启用该插件功能
  6. enable: true
  7. #语言文件
  8. Lang:
  9.   prefix: '&e[RestpSign] >>'
  10.   cooldown: "&c冷却中...%time%"
  11.   noMoney: "&c你没有足够的金钱,至少需要%money%."
  12.   withdrawmoney: "&a成功创建传送牌子,扣除%money%."
  13.   needText: "&c正确使用方法 &e/restp edit <领地名称>"
  14.   reloadConfig: "&a成功重载配置文件!"
  15.   noPerm: "&c你没有足够的权限!"
  16.   editDone: "&a成功编辑领地牌子!"
  17.   createDone: "&a成功创建领地牌子!"
  18.   notexists: "&c该领地不存在!"
  19.   error: "&c错误的参数!"
  20.   notenable: "&c插件功能未被启用,请联系 服主咨询!"
  21. #其他设置
  22. Settings:
  23. #冷却时间 以秒为单位
  24.   cooldown: 3
  25. #扣钱配置
  26. Vault:
  27. #默认组
  28.   default:
  29. #权限
  30.     permission: restpsign.default
  31. #创建牌子花费金钱
  32.     money: 500.0
  33. #指令编辑牌子花费金钱
  34.     editmoney: 300.0
  35. #折扣
  36.     discount: 1.0
  37. #自定义vip组
  38.   vip:
  39.     permission: restpsign.vip
  40.     money: 250.0
  41.     editmoney: 100.0
  42.     discount: 0.8
  43. #牌子设置
  44. Lines:
  45. #第一行显示
  46.   Line-1: '&9[ResTP]'
