好了 bossbar的指令接着
顺便说一下你这样子想同步还不如直接指定玩家
-----------------------------------------------------------
执行一次即可
  1. /bossbar add health "玩家血量"
复制代码

添加一个id:health 显示名称“玩家血量”的boosbar
  1. /bossbar set minecraft:health max 20
复制代码

这边bossbar最大值设置20血量 因为普通玩家都是20血
==============================高频执行
  1. /bossbar set minecraft:health players @p
复制代码

将玩家设置在boss栏上
  1. /execute if entity @a run bossbar set minecraft:health visible true
复制代码
  1. /execute unless entity @a run bossbar set minecraft:health visible false
复制代码

通过execute检测是否玩家死了 死了的话就隐藏boss栏 复活后再显示（可以不理他）
  1. /execute store result bossbar minecraft:health value run data get entity @p Health
复制代码

不断将玩家的数据:Health（血量）同步到boss栏上去
其实中间那两个 execute可要可不要
