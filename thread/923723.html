MobsDontBurn


一个可以使怪物在阳光下不会被燃烧




权利：

  • mobsdontburn.reload - 可以使用/mobsdontburn reload 重载权利
命令：

  • /mobsdontburn reload - 重载config.yml配置文件夹


配置文件：
# 插件运行禁止燃烧的世界名字
worlds:
  - 'world'

# 以下种类在阳光不被燃烧
mobs:
  zombie: true
  zombie-villager: true
  skeleton: true
  stray: true
  phantom: true
