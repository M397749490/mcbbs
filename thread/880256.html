  1. // 0 级饥饿（实际显示 1 级），持续 0 tick
  2. new PotionEffect(MobEffects.HUNGER);
  3. // 0 级饥饿，持续 1200 tick（1 分钟）
  4. new PotionEffect(MobEffects.HUNGER, 1200);
  5. // 2 级饥饿（实际显示 3 级），持续 1200 ticks
  6. new PotionEffect(MobEffects.HUNGER, 1200, 2);
  7. // 2 级饥饿，持续 1200 tick，true 代表来自周围环境效果（原版信标等），false 代表无粒子效果
  8. new PotionEffect(ModEffects.HUNGER, 1200, 2, true, false);

这个问题有点复杂。有三个和药水相关的类，它们的名字（不论是游戏内的叫法、翻译成中文后的叫法还是 MCP 名）也是混乱至极：
药水效果是 PotionEffect，药水效果的类型是 Potion，而药水物品的类型是 PotionType。

Potion 和 PotionEffect 之间的关系相当于 Item 和 ItemStack 之间的关系。
PotionType 之于原版药水这个物品（Items.POTIONITEM）相当于 Enchantment 之于原版附魔书（Items.ENCHANTMENT_BOOK）。
原版药水物品的类型是 Item。

给某个生物实体加药水效果：
  1. // srg func_70690_d
  2. entityLivingBase.addPotionEffects(new PotionEffect(MobEffects.REGENERATION, 1200, 1);
