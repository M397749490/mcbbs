为你的服务器添加更多有趣而又实用的合成配方
简介
这个插件会提供一个GUI的菜单，作为一个全新的工作台，并且这个工作台是4*4而不是3*3

物品摆放在左边，只要满足某个合成配方，合成出的物品会显示在右边

右边的GUI则是创建合成表的
就是这么简单，全GUI，你把原料放在左边4*4的空格中，成品放在右边，点击绿色按钮即可保存合成配方

你可以用它来代替ShopKeepers来进行交换
你可以用它来进行服务器主题活动的物品合成
它可以让你服务器的VIP更具诱惑力
……
特性
1.无限的合成台
2.无限的合成配方
3.合成过程全自动
4.自定义提示信息
5.完全基于权限（应该是指所有的合成配方都可以用权限来控制）
6.可在游戏内快捷编辑菜单
7.完全对物品自定义（包括名称 lore标签 甚至附魔、特效）

另有三项由于我没有使用这个插件无法翻译，有好的翻译欢迎反馈
Live Item Output
Sneak - Block Detection
Block - Break / Explode Detection
命令 ＆ 权限
/advancedcraftingtable editor  打开合成配方编辑器
/advancedcraftingtable give <玩家> <数量>  给玩家指定数量的高级合成台
/advancedcraftingtable reload   重载插件
管理权限：advancedcraftingtable.admin 允许使用/advancedcraftingtable
默认都只有OP拥有
注意事项
没有用来打开合成页面的命令，全部通过给予玩家特殊工作台来打开
建议搭配ChestCommands或者脚本方块等插件 来实现玩家的自助领取或者出售
又是一个赞助项目……

请勿随意修改config里面的语言项目的配置，修改后已经发放的工作台将会失
因此请先修改好文件再开始使用本插件，这里我已经帮大家汉化好
下载覆盖config.yml即可，Linux下报错的话请转码为ANSI
  1. WorkbenchLocations: '这是记录特殊工作台位置的，请勿删改

复制代码

所以，要新建一个配方也很简单的
首先使用命令 /advancedcraftingtable editor  打开合成配方编辑器

（请只看右边部分）
然后把你想 要求使用的原料，按照你的想法有顺序的（自己想的顺序）摆放上去
然后把成品摆放在右边
然后点击一下绿色的save按钮，即可保存

如果你希望合成出来的东西有附魔、材质等特殊项目
再按照上方的配方详解，找到这个配方的.yml文件，打开进行修改
记得/advancedcraftingtable reload重载插件
