标题: 求怎么检测计分板数据并作出反应
我创建了一个击败玩家数量的计分板，那我应该怎么才能使命令方块检测到有玩家击败10人呢，检测后又该怎么才能使他做出反应呢？比如当有玩家击杀10人时把所有玩家传送回大厅
大佬求解！

作者: 晴路卡    时间: 2020-6-27 10:17
本帖最后由 晴路卡 于 2020-6-27 10:49 编辑
  1. execute as @a if score @s <记分板名> matches 10 run say 击败了十人
复制代码

<记分板名>对应你所创建的将击杀数作为判据的记分板
将“say 击败了十人”替换成其他的命令
来达到玩家杀死10人就执行其他命令的效果
比如
  1. execute as @a if score @s <记分板名> matches 10 run teleport @a 0 0 0
  2. execute as @a if score @s <记分板名> matches 10 run scoreboard players set @a <记分板名> 0
复制代码

就可以在某玩家杀死十个玩家后把所有人传送到0 0 0
并将所有人的击杀数记分板清零
