这个插件主要是为Sponge服务器提供易于使用的api和灵活的rpg系统。
如果您想使用api并创建新技能或附魔，您需要了解java，或者能够在javascript中编写一小段代码。
轻松创建技能等自定义内容
您可以根据需要更改PVP和PVE。
  • 为每个种族定义每个项目的伤害
  • 定义一个物种或种族不能使用的项目集等等
  • 多种技能 - 被动/主动技能
  • 技能可以通过命令，对项目的绑定技能或执行点击组合游戏来执行
  • 玩家可以使用符文制作预定义的项目
灵活多变的技能树功能

|||    [Requipment- 依赖 ]
这个插件需要另外一个MOD进行支持，还需要NT-CORE mod才能工作。
（点击发布并下载最新版本） NT-CORE MOD直接添加在服务端MOD文件夹里即可
NT-CORE mod包含Hibernate，Javassist等库，以及作者为加快开发而创建的一些小型数据库。
另一个可选要求是Nashorn库。要启用javascript支持，您必须将nashorn库放入config / nt-core文件夹。转到/ jre / lib / ext并将文件Nashorn.jar复制（或者如果你有对服务器的shell访问权限创建一个符号链接）到SpongeDir / config / nt-core文件夹中。

|||    [ permission - 指令/权限 ]
玩家指令说明 权限
/char create [name] 创建一个新角色。每个玩家的角色名称是唯一的。通常是您要运行的第一个命令。 ntrpg.player.character.create
/character set race玩家可以选择特定的种族 ntrpg.player.set.race
/character set class玩家可以选择特定的类别 ntrpg.player.set.class
/char skill refund退还技能，所有技能点将被退回 ntrpg.player.skills.refund
/char skill learn学习技能 ntrpg.player.skills.learn
/char skill upgrade升级技能 ntrpg.player.skills.upgrade
/char swith [name]切换至你的另一个角色 ntrpg.player.swith
/skl {{skillname}}执行技能
/health显示当前和最大健康状况
/mp显示当前和最大法力值
/party c创建一个小集体 ntrpg.player.party.create
/party k踢出团队的玩家，只有领导者可以踢其他玩家
/party i邀请玩家参加团队，只有领导者可以邀请其他玩家
/party a受邀玩家必须接受邀请
/classes显示类别的详细信息
/races显示种族详情
/weapons或/armor显示可以使用的武器类或护甲类
/bind创建技能绑定 ntrpg.player.skillbind
/runes显示符文列表 ntrpg.runes.list

管理员命令 说明 权限
/nadmin skill {{skillName}} -l {{skill level}} 执行任何主动技能，此命令不需要任何法力/健康成本，冷却时间 ntrpg.admin
/nadmin enchant 操纵持有物品上的自定义附魔 有上面这权限管理员指令都能用
/nadmin rune {{name}} 为玩家库存添加符文
/nadmin runeword {{name}} 使你拿在手中的物品被创建一个符文
/nadmin experiences {{playername}} {{class}} {{exp amount}} 为特定的玩家或者种族增加经验
/nadmin effect {{playername}} {{effectName}} {{duration in milliseconds}} {{effect params}} 为玩家增加特定效果
/nadmin reload 重载插件
/nadmin reload skilltree 重载技能树
