简介 INFO

Welcome to Super Wipeout! This map is based off the TV show "Wipeout" in which you have to make it past obstacles to win.
In this map you also have to get through all of the obstacles, which are redstone and command block controlled.
This map also has additional features, like enabling effects.
This map is Singleplayer and Multiplayer!
I hope you enjoy my map "Super Wipeout."
