如果是改彩色的话，书与笔倒是可以做到。
举例子：先给自己 书与笔，然后写上
  1. {"text":"233","color":"red"}
复制代码
点击完成后扔出，并运行命令：
  1. execute as @e[type=minecraft:item] run data modify entity @s Item.tag.display.Name set from entity @s Item.tag.pages[]
复制代码
就会将你写的内容复制到 display.Name，书与笔的名字就会变成红色斜体的 233。当然，把写的内容复制到其他物品，复制 display.Lore，甚至玩家不丢出来，物品放在一个容器里都是可以的。如果你需要的话，请说明具体的要求以及限制。
