VIP：
mangadd vip
mangaddi vip builder
mangaddv vip build true
mangaddp vip essentials.fly

家：打开plugins\Essentials\config.yml
  1. ############################################################
  2. # +------------------------------------------------------+ #

  4. # +------------------------------------------------------+ #

  7. # 允许玩家在白天设置他床所在的位置为家.
  8. update-bed-at-daytime: true

  11. # 这个设置只适用于'/home'命令.
  12. # 对于其他传送命令,给予玩家多世界间传送的权限 essentials.world.<世界名称> 可以允许玩家跨世界传送
  13. world-home-permissions: false

  15. # 允许玩家拥有多个家.

  17. # 定义不同权限的不同家的数量例如:essentials.sethome.multiple.vip
  18. # 用有 essentials.sethome.multiple.unlimited 权限的玩家将不被此项设置所限制.

  20. sethome-multiple:
  21.   default: 3
