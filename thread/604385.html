config配置
ShowJoinMessage: true 是否显示加入信息。不显示则false。
ShowLeaveMessage: true 是否显示离开信息。不显示则false。
作者: 幻境雲達達    时间: 2016-7-16 16:43
ess管理玩家进出信息 设置为空可以实现关闭功能

plugins essentials config.yml 找到这些地方

# 你可以在这儿设置自定义加入消息, 设置为"none"则禁用此功能
# 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
custom-join-message: "&a[银白轨迹-MOD] &e玩家 {USERNAME} 连接到服务器 !"

# 你可以在这儿设置自定义退出消息, 设置为"none"则禁用此功能
# 支持颜色代码, 使用 {USERNAME} 将会代替玩家名称, 使用 {PLAYER} 将会代替玩家的显示名称(比如昵称神马的).
custom-quit-message: "&a[银白轨迹-MOD] &e玩家 {USERNAME} 离开了服务器 !"
