  • 完全自定义开箱内容!
  • 允许在游戏内编辑开箱内容!
  • 设置不同物品的出现机率!
  • 为指定箱子设置全服公告
  • 为指定箱子设置特殊烟花
  • 当玩家没有开箱钥匙时发出击退提示
  • 钥匙不可被放置
  • GUI界面操作
  • 简单的配置与使用
  • 支持多行指令奖励




  1. Config Version: 6
  2. Update Checks: true
  3. Update Branch: spigot
  4. Metrics: true
  5. Default Opener: BasicGUI
  6. Default Cooldown: 5
  7. Crate Protection: false
  8. Disable Key Swapping: false
  9. Default Hologram Text:
  10. - '%crate%'
  11. - 右键点击打开箱子!
  12. - 左键点击偷看一眼!
复制代码




  • /crate settings - 在游戏中打开箱子编辑器
  • /crate reload - 重读配置文件
  • /crate create <名称> - 创建箱子
  • /crate rename <旧名称> <新名称> - 重命名箱子
  • /crate delete <名称> - 删除箱子
  • /crate crate <名称> [玩家] - 给予玩家一个指定的箱子
  • /crate key <player/all> [名称] - 给予玩家/全服玩家 指定的箱子钥匙




  • cratesplus.admin - 允许使用管理权限. 默认为OP
  • cratesplus.updates - 允许接收更新通知. 默认为OP
