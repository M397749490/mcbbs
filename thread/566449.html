mod1.10.1-1.11
MC1.8.9-1.9.4
    Removed poisoned arrows (this feature is now vanilla)
    Removed sticks dropping from dead bushes (this feature is now vanilla)
    Removed filling up buckets from full cauldrons (this feature is now vanilla)
    Removed potatoes from additional breeding items for pigs (this feature is now vanilla)
    Removed gold ingots generation in dungeon chests (this feature is now vanilla)
    Fixed incompatibility with Forever Enough Items

    Fixed the health draining enchantment working with indirect attacks (e.g. shooting an arrow and quickly switching to the enchanted
    item)

    Slight changes in the hard versions of horse armor recipes
    The config file now allows to specify an enchantment rarity among common, uncommon, rare and very rare, instead of a numeric value
