相信大家都知道怎么玩把
就是建一个平台。要有掉落的地方。然后系统给的木剑【击退效果】把不是自己队的击打下去即可
命令如下
/sumo
/sumo help 帮助
/sumo create map   创建地图
/sumo delete map   删掉地图
【地图只是一个点。不是删掉方块】
/sumo join map 加入相扑
/sumo leave map 离开相扑
/sumo lobby map 设置大厅
/sumo addspawn1 map 设置复活点1【可以是红队】
/sumo addspawn1 map 设置复活点2【可以是蓝队】
至于就看服主怎么设置了。希望大家玩的开心
