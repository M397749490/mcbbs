这个插件可以替换默认未知指令消息，不是提醒 type /help for help

而是显示出你可能想要执行的指令



  1. #是否替换'Unknow command'(未知指令) 信息?
  2. replace: false

  4. #设置你要发送的信息 (%s是相似的指令)
  5. message: '&3[DYM] &你是指 &a%s&b?'

  7. #如果不想让指令在建议被包括(什么鬼)
  8. ignorePermission: false
复制代码

引用：
这个插件利用Hidendra的插件度量系统，这意味着下面的信息被收集并送往mcstats.org：
唯一标识符
服务器的Java版本
服务器是否处于离线或在线模式
该插件的版本
服务器的版本
操作系统版本/名称和架构
核心数量的CPU
玩家在线人数
度量标准版
选择退出这项服务可以通过editing plugins/Plugin Metrics/config.yml和改变选择退出，以真正完成。
原文:
Quote:

This plugin utilises Hidendra's plugin metrics system, which means that the following information is collected and sent to mcstats.org:

  • A unique identifier
  • The server's version of Java
  • Whether the server is in offline or online mode
  • The plugin's version
  • The server's version
  • The OS version/name and architecture
  • The core count for the CPU
  • The number of players online
  • The Metrics version

Opting out of this service can be done by editing plugins/Plugin Metrics/config.yml and changing opt-out to true
