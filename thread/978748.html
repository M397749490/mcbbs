你两个版本检查都是直接写了全字匹配（String.equals）。
原版客户端大抵是不能处理你的信道的，所以你要检查的是协议版本是不是以 `ALLOWVANILLA` 开头。
  1. public SimpleChannel INSTANCE = NetworkRegistry.newSimpleChannel(
  2.     new ResourceLocation(Totur.MODID, "keyclient"),
  3.     () -> PROTOCOL_VERSION,
  4.     PROTOCOL_VERSION::equals, // 这一个用于在客户端检查服务器声称的协议版本
  5.     clientProtocol -> PROTOCOL_VERSION.equals(clientProtocol) || clientProtocol.startsWith("ALLOWVANILLA") // 这一个用于在服务器检查客户端声称的协议版本
  6. );
