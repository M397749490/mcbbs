如果已安装领地插件Residence，打开该文件夹找到flags.yml，找到如下行
  1. Global:
  2.   Flags:
  3.     Global:
  4.       use: true
  5.       build: true
  6.       ignite: true
  7.       firespread: true
  8.       damage: true
  9.       creeper: true
  10.       tnt: true
  11.       pvp: true
复制代码
