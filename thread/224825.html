每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。
适用于正式版的MOD不兼容预览版，而且大多数MOD都不提供对每周快照的支持。
Minecraft 1.8仍未发布，14w04a为其第6个预览版。
注意！旧版启动器已经无法启动Minecraft 1.6以及之后的快照，请看下面的说明。
本版新闻除非特别说明，否则均允许转载，但转载必须注明本帖地址。




Notable additions for survival:
对生存模式进行的重要修改：

  • Item frames can give off a signal detected by Comparators.
  • 物品框现在可以通过比较器输出一个信号。
  • Lots of changes to villager AI. Some of them now actually do stuff!
  • 对村民的人工智能（AI）做了很多修改。现在很多村民会实际地做事了！
  • Fortune now gives 1% change of rare loot per level
  • “时运”附魔现在每一级会增加1%的稀有物品掉落几率
  • Iron Golems/Zombie Pigmen now drop items on normal kills
  • 铁傀儡和僵尸猪人现在只在正常被杀死（也就是非刷怪厂）的情况下才会掉落物品
  • You can now spawn Iron Golems/Snow Golems/Withers with dispensers + pumpkin/skulls respectively
  • 现在铁傀儡、雪傀儡和凋零可以用发射器来放置最后一个南瓜/头颅了
  • Bushes can now catch fire
  • 树丛现在会起火
  • Buttons can now be placed on ceiling/floors
  • 按钮现在可以被横向放置
  • Seecret Changes
  • 秘秘密更新（？！）
  • Balancing tweaks!
  • 调整了游戏机制的平衡！


Notable additions for mapmakers:
针对地图制作者的重要修改：

  • New command /particle to show particle effects in the world. It can also be relative to entities. Example: /particle lava ~ ~1 ~ 1 1 1 0.5 2 @e[type=Chicken]
  • 新命令/particle可以在世界的某一点生成粒子效果。也可以使用相对于某个实体的坐标，比如：/particle lava ~ ~1 ~ 1 1 1 0.5 2 @e[type=Chicken]
  • Added the ability to filter block types in the /fill command, but only if it’s used to fill in replace mode with “normal” blocks. It does not work when filling with block entities. Syntax: /fill replace [filterBlockName] [filterData]
  • 现在/fill命令可以指定某些特定方块，但是只对没有实体附加值的方块有效。格式：/fill replace [要替换的方块名] [过滤属性]
  • Fixed most of the remaining issues with the /clone command, for example chest orientation.
  • 修复了大多数和/clone有关的命令，比如箱子被克隆后朝向的问题。

此前与本次更新相关的快讯列表：
此前与本次更新相关的快讯列表：（在sjjklh的翻译基础上做了较大修改）

Minecraft 1.8第五个快照已经到来！本更新对游戏有很大改动，具体包括：生存模式更新、冒险模式更新、命令方块增强和皮肤增强！我们已经做了一坨针对客户端和服务端的优化工作（还有很多没公布呢），以及大量针对后台插件API的工作。

生存模式提升：
  • 3个新石头种类：花岗岩Granite、闪长岩Diorite、安山岩Andesite
  • 修理以及附魔的大幅度改变
  • 苔石砖可合成
  • 村民交易的更新
  • 门可堆叠
  • 史莱姆方块/粘液方块

冒险模式更新：
  • 冒险模式不再允许放置以及摧毁方块
  • 但上面这句话不是绝对的……可以变哦
  • 增加实体选择符@e用以将目标指向特定实体。
  • 为大多数容器加入Lock:{'string'}NBT标签，用于锁闭容器

命令、命令方块增强：
  • 加入/blockdata命令，用来更改拥有附加值的方块属性
  • 加入 /clone 命令，用来复制大面积的区域，worldedit 至此可以消失了
  • 加入 /fill 命令，用来用单一方块填充大面积的区域，同样类似worldedit和mcedit
  • 为/kill命令加入可选实体参数，可以指定所有实体
  • 为/clear加入可选数量参数，这样可以限制物品以及NBT数值的最大值
  • 为/tp 命令加入可选朝向参数，可以自定义实体传送后的朝向
  • @p, @e 等参数现在支持自定义全部三个维度

皮肤增强：
  • 皮肤格式已经更新，支持第二层皮肤
  • 添加“自定义皮肤”菜单
  • 正版用户现在可以在游戏内调整哪一部分皮肤可见
