功能1.WarpGUI

About & Setup（简介与安装）
Create your own warp panel! Decide which size and structure you warps should be sorted in. This panel is 100% customizable. As you can see above in the subtitle thumbnail you can add icons where you want.

它可以创建你自己的warpGUI！它是可以被完全自定义的（大小、图标等等）。
You can choose between Warp-, Category-, GlobalWarp- or Deco-Icons.

下面这些传送种类可选：
  • Warp: Here you create a Icon, which teleports players to the position you was standing while creating the button.（你可以创建一个GUI，让玩家通过点击传送）
  • Category（类别菜单）: This is simply a link to a new page, where you are able to create new buttons（传送界面中的“子菜单”，在子菜单中你同样可以使用以上四种元素Warp-, Category-, GlobalWarp- or Deco-Icons.）
  • GlobalWarp（全球传送）: With this type you link buttons to global warps（支持蹦极）
  • Deco（即decorations:装饰）: Deco icons can be used to describe something or beatify your gui（无实际作用，就是用来美化你的GUI的）

All buttons are able to handle commands, permissions and costs (deco icons cannot handle costs). These options can be set in the icon editor. When you add an icon, you will automaticly go through it.
除了Deco外，图标都可以与命令/权限/执行命令的花费挂钩

As if that was not enough, you can even change the background! Isn't that great?! Just hover over the nether star at the top on the left, and you will see, how you can change it.
GUI菜单的背景也可以被更改


SimpleWarps（简单的传送）
/setwarp", "/delwarp" and "/editwarp

简单设置warp点，而不用显示在传送GUI中。
/setwarp--设置传送点
/delwarp--删除传送点
/deitwarp--编辑传送点

The SimpleWarps are able to handle permissions and costs. Edit these parameters with the edit command above.

简单WARP也可以添加权限及传送花费设置。
Permissions（权限）
"WarpSystem.Use.Warps" ? 使用GUI传送菜单功能（建议给玩家）
"WarpSystem.Use.SimpleWarps" ? 使用Simple传送点（建议给玩家）
"WarpSystem.Modify.Icons" ? 修改传送GUI
"WarpSystem.Modify.SimpleWarps" ? 修改Simplewarp
"WarpSystem.ByPass.Teleport.Delay" ? 无视冷却
"WarpSystem.ByPass.Teleport.Costs" ? 无视传送花费
功能2.本地传送

About & Setup
Native Portals are the best way to design your spawn, temples and dungeons! Run "/nativeportals <create, edit, delete>" or just "/nps <create, ...>" to modify those portals. With this command you open the editor for native portals.
你可以用这个功能制作与上面提到的GlobalWarp链接的传送门。这将大大方便各位腐竹，这一个功能可以完全取代传送门插件。
  • Here you can choose one of the following materials for your portal: 传送门的材质可以是末地/地狱/水/岩浆

    • Nether portal
    • End portal
    • Water
    • Lava

  • After setting a material, you're able to set the teleport blocks. No panic, you will see how it works, if you are ingame.（插件会给你一些方块，你把这种方块放在打算做传送门的位置，完事后这些方块会变成所选传送门材质的方块）
  • Finally you have to choose a link to a warp/global warp to set a destination, when you go into the portal.（以上完毕后，选择一个全球跨服传送或本地传送）
  • When you set all options, you can save it with the save icon on the top in the middle.（点击保存）

现在你就可以享受传送门了:)

Permissions（权限）
"WarpSystem.Use.NativePortals" ? Players can use the native portal feature
"WarpSystem.Modify.NativePortals" ? Modify all native portals
功能3.粒子效果传送门

About & Setup（简介与安装）
Effect portals are the portable option to native portals. You can set them everywhere. These portals are the best way to let players teleport by walking in a hidden edge on the spawn. They are very easy to create. Try it on your own!

粒子传送门是上述Native Portal的简化版。它更加方便。
在使用时，你只需要走进粒子圈即可传送至GlobalWarp点或者Simplewarp点。
  • Run "/portals create" on two different places, which should be connected by this portal.（在两个不同的地方执行/portals create，可以选定两个点作为起点终点）
  • Go through the editable options and save the portal（在GUI菜单中编辑就可以了*已汉化*）

If you want to edit or delete them, run "/portals" and you will know how you do it.（一切编辑都在/portals菜单中）


Permissions（权限）
"WarpSystem.Use.Portals" ? 玩家可以通过传送门（建议给玩家）
"WarpSystem.Modify.Portals" ? 创建传送门



功能4.临时传送点
About & Setup（简介与安装）
TempWarps are player created Warps, which can be public or just private. As the name says for itself: These warps are temporary warps, which will be activated with money (You need Vault or Essentials). You can create one with "/twarps create [name]".
At the Create-GUI you can configure the name, the teleport message, the active time and the teleport costs.
The teleport message, will be send to every player, which is going to teleport to this warp. If the player sets teleport costs, every player (except the warp owner) have to pay the set amount of coins to the warp owner.
All extras and the active-time for the TempWarp costs a certain amount of money, which can be changed in the Config.yml.
临时传送点可以被普通文件创造，可以被设置为公用传送点或者是有传送点。正如它的名字所说，这些传送点仅仅是临时的，他们有时间限制（但是你可以在需要的时候用金钱续期）（这需要经济插件）
创建者创建WARP必须花钱。
创建者同时可以设置收取传送来的玩家一定费用。（留下买路财）
命令：
/twarps edit <id> 编辑传送点

/twarps list [player] 查看玩家的传送点

/twarps delete <id> 删除传送点

/twarps info <id> 查看传送点信息

/twarp <id> 传送到某个地方


Permissions（权限）
"WarpSystem.Use.TempWarps" ? 玩家可以自设传送点
"WarpSystem.TempWarps.2" ? 这个玩家可以有2个传送点（数字可以自己改）
"WarpSystem.ByPass.Teleport.Delay" ? 无视冷却
"WarpSystem.ByPass.Teleport.Costs" ? 无视花费

功能5.传送牌子

About & Setup（简介与安装）
With the warp signs you can create some nice signs, where you are able to teleport to different places.

用传送牌子你可以做一些美腻的，把你传送到各地的牌子。
  • 仅限创造模式，放下一个木牌，在第一行写上 “[warps]”
  • 在 Warp-Icon, SimpleWarp or GlobalWarp各类下选择你需要传送到的地方
  • 支持彩色字体"&"

如果你要更改牌子内容，请在创造模式下用另一个牌子点击它进入修改模式。
移除牌子：创造模式直接打碎。

Permissions（权限）
"WarpSystem.Use.WarpSigns" ? 玩家可以点木牌（建议给玩家）
"WarpSystem.Modify.WarpSigns" ? 创建木牌
"WarpSystem.ByPass.Teleport.Delay" ? 无视冷却

Commands&Permissions(in-all)（插件总命令及其权限）
  • 重载插件 ("/ws reload" -权限: "WarpSystem.Modify")
  • 导入传送点 你可以把ess中传送点导入本插件。 ("/ws import" - 权限: "WarpSystem.Modify")
  • 更新新闻 ("/ws news" - 权限: "WarpSystem.Modify")
  • BUG报告 遇到了问题？输入这个指令 ("/ws report" - 权限: "WarpSystem.Modify")



Supported plugins（支持的其他插件）


    • Multiverse-Core (for locations at other worlds)
    • MultiWorld (see Multiverse-Core)

    • Vault (see Essentials)
