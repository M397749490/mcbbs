关于评审等级“原创”及“优秀”顺序调整
目前服务端整合包版块的评审等级顺序为：加粗 < 绿色 < 良好 < 优秀 < 原创 < 精华I < 精华II
  • 由于“服务端整合包”版块建设初期的评审等级“原创”及“优秀” 一直饱受争议且为了统一“多人联机”大区内其他版块评审等级中“原创”及“优秀”的顺序，经讨论，现对评审等级中“优秀”及“原创”顺序做出调整。
调整后的评审等级顺序为：加粗 < 绿色 < 良好 < 原创 < 优秀 < 精华I < 精华II

  • “原创”及“优秀”图章不受影响，拥有“原创”评审等级的帖子将会调整为“优秀”，拥有“优秀”评审等级的帖子将会调整为“原创”，评审等级的性质不变。
  • 由于版块内“原创”及“优秀”的帖子较多，将在本公告发出后进行版块内的“原创”及“优秀”帖子进行统计，在统计完毕之后，将会对现有帖子的高亮及图章进行调整。
  • 统计完毕后未及时调整的可私信服务端整合包版块的版主进行修改。
  • MCBBS多人联机大区及MCBBS服务端整合包版块拥有本贴的最终解释权。

目前“原创”及“优秀”贴均已调整完毕，公示请查看：https://www.mcbbs.net/thread-925797-1-1.html
