撤销管理员权限:deop 玩家名
设置出生点:setspawn
封禁玩家:ban 玩家名
当前世界死亡不掉落:gamerule keepInventory true
全图(多世界)死亡不掉落:gamerule keepAllInventory true
给单个玩家设置称号:manuaddv ID prefix 称号
给所有普通玩家组设置称号:mangaddv Default prefix 称号
给玩家组添加权限:mangaddp 组名 权限
给玩家添加权限:manuaddp 组名 权限
查看玩家IP与登录信息:seen ID
查看玩家背包内物品:invsee ID
玩家禁言:mute ID 时间
添加玩家白名单:whitelist add 玩家名
创建普通世界:mv create 世界名 normal
创建地皮世界:mv create plotworld normal -g PlotMe
领取地皮权限:mangaddp Default plotme.use
传送指定世界:mv tp 世界名
给玩家金钱:eco give 玩家名 数量
