========*介绍*========
    是不是老是在为关闭了服务器的死亡掉落玩家们就大死特死感到不爽呢    是不是装了playerheads看到玩家们互相刷头很想clearinventory呢
这个插件可以帮助你：
       自定义死亡扣除金钱数量、自定义死亡负面状态buff持续时间
     支持权限设置，有权限的将不会受到死亡惩罚
========*配置*========
我加的注释好像有问题了，都是很简单的英文，还不懂的看这吧
  1. TakeMoney: true  
  2. #是否开启死亡扣钱
  3. # 开启死亡扣钱时每次扣除的数量
  4. Money: 50
  5. #开启死亡扣钱时没钱可扣的话是否死亡掉落
  6. toggle: true
  7. #是否开启死亡按百分比扣钱(不建议与死亡扣钱同时开启)
  8. TakeMoneyPercentage: false
  9. #开启百分比扣钱时扣的百分数(0-100之间的数)
  10. Percentage: 0.5
  11. # 是否开启死亡负面状态
  12. Buff:
  13.   Enable: true
  14.   SLOW:
  15.     time: 120  #迟缓状态持续时间
  16.   BLINDNESS:
  17.     time: 30   #失明状态持续时间
  18.   CONFUSION:
  19.     time: 60   #反胃状态持续时间
  20. #在上述世界启用,更改请按格式填写
  21. Worlds:
复制代码



========*权限*=========
  1. DP.Money            #拥有此权限的将不受到死亡金钱惩罚
  2. DP.Buff                  #拥有此权限的将不受到死亡BUFF惩罚
复制代码
