一.开服之前的准备
1.开服方式的选择以及其优缺点

开服通常有三种选择：1.用自己家电脑开2.租用服务器开3.购买服务器开服
一般基友服否是第一种，想开20+的一般都是第二种，第三种是很少数大服才在用的
优点:(1)不需要花钱，使用插件地图等方便，省去了上传下载的麻烦。
        (2)服务器可以24小时开启，网速不卡，即使腐竹有别的事也可以开着服。
        (3)设置更加自由，也可以更合理的分配服务器资源，防止资源浪费.
缺点:(1)必须腐竹的电脑一直打开，关闭电脑无法开服，
            而且对硬盘等硬件损伤较大，且网速一般，会经常卡顿
        (2)需要每月交租金，上传地图插件等速度很慢，
        (3)价格不菲，需要每月大量的网络费用，管理费用




2.个人对开服方式的一些建议

建议：如果是朋友一起玩，玩的时间也一致的话，建议使用第一种
          如果是想招人一起玩，或者为了赚点零花钱
            最好还是租用一个服务器，小服不是很贵，相比性价比很高
          不推荐初开服使用第三种选择，毕竟资金投入是很多的





二.服务端的选择

——该章节主要用于VPS以及个人计算机开服，
面板服可以直接在面板选择或者让服务商更换
1.服务端简介以及分类


什么是服务端：服务端是为客户端服务的，服务的内容向客户端提供资源，保存客户端数据。
只有开启MC的服务端，玩家才能进入你的服务器玩minecraft。
MC游戏只有那么些版本，但是服务端却有不同的几种，下面我说明一下。
1.Bukkit：纯净插件服
2.spigot：纯净插件服，bukkit优化版。
3.cauldron(mcpc+):可以加插件的mod服
4.官服：可加forge成为mod服，不能加插件




2.推荐使用服务端：


推荐：如果是基友服的话，使用官服是不错的选择，对mod的兼容比mcpc+更好。
缺点是没有插件不能密码登录，会导致有玩家登陆其他账号偷窃。
如果是开多人服的话，建议使用spigot或者是mcpc+。
spigot是插件服，进行了很多项优化，不装过多插件是不会卡的，也自带防作弊的功能
mcpc+可以加mod，也可以加插件。通常的mod服都是这一种，但不推荐新手使用。
因为mod之间会有不兼容的问题而且本服务端与插件兼容度也不是很好，经常出问题，
如果不会看报错，不能处理bug的话会非常麻烦，可能三天两头回档，数据丢失导致流失大量玩家
而且mod是可以加却不能删不然无法启动服务器，除非删档换周目，这样做也会导致玩家流失

三.租用服务器开服简述

1.服务器的租用选择及面板服简述




租用服务器一般有三种选择：面板服，VPS和独立主机

面板服租用后会给你面板登陆方式，及FTP传输信息

面板服通常为multicraft面板，均为中文管理，具体功能不再赘述，自己看就可以。

FTP为文件传输协议，是你将本机的地图，插件等传输到服务器的方式。

通常FTP数据你租服时会发给你，也有部分服务商会写在面板后台里，自己查看即可。

推荐使用flashftp来传输数据，下载地址：点击

下载后安装，点击flashFTP启动本程序

点击会话——快速连接，然后输入你的用户名，密码，服务器地址，端口，就可以查看了。








服务器中文件夹简介：


1.world——主世界文件夹

如果是spigot会有world_nether，是地狱文件夹

还会有world_the_end，即末地文件夹，里边保存的就是地图存档

如果是mcpc+的，其他世界都会储存在world文件夹里的子文件夹

2.logs，后台数据，记录使用的指令，插件的报错，启动时读取等

3.plugins，插件文件夹，保存插件及插件配置文件夹

4.banned-ips——封禁的ip列表

5.banned-players——封禁的玩家列表

6.版本号.jar——服务端核心文件

7.whitelist——白名单，开启白名单模式没有白名单无法进入

8.mods——mod列表，没有对应mod无法进入服务器



如何安装插件和mod：


插件直接传输到plugins就可使用，通常要重启服务器才可使用

或者使用这个插件进行载入：点我 其他版本在此下载：插件原帖

mods则需要客户端有对应mod，不然无法进入游戏

注：无论是mod还是插件都要对应版本，有一些是其他版本也能使用，

但是跨版本使用bug会很多，甚至崩服数据丢失，注明全版本的除外。




四.进入游戏进行必备的设置

1.插件编辑



插件下载后装入了服务器，但是有很多功能都是可以自定义的。
那么如何自定义实现自己满意的插件配置呢？要通过配置文件夹.
通常配置文件夹在插件载入后自动生成。以插件名字的文件夹形式存在。
这时要通过传输文件夹到自己电脑进行修改，一般新人都会使用记事本修改。
但是记事本看起来很乱，而且很容易出现问题导致插件无法读取。
我推荐使用notepad++进行编码，修改插件配置。下载地址自行百度。
编辑时注意选用格式，win系统的服务器使用ANSI编码，linux系统使用UTF-8编码。
至于你的服务器是什么系统？臣妾也不知道啊(笑)。这个要问你的服务商了。

5.1.1——如何创建、将存档加入多世界

1.插件自带可用指令：
/mv create 世界名 normal                   ——生成一个普通世界
/mv create 世界名 normal -t largebiomes    ——生成大型群落世界
/mv create 世界名 normal -t flat          ——生成超平坦世界
2.常用扩展插件功能:
/mv create plotworld normal -g PlotMe      ——创建一个地皮世界 (plotme地皮插件)
一个自定义超平坦的世界，也可以制作虚空世界：点我
3.读取存档方式
将存档导入服务端中，输入/mv import 世界名 类型(无特殊要求输入normal)

在此以地皮世界举例

6.客户端制作

6.1——选用基础整合包



基础制作建议使用整合包，在此推荐一个系列：点击
这个整合包很好用，但需要注意最好删除R键整理mod。
即——Inventory Tweaks.jar
为什么要这么做呢？这个mod本身没有问题。
但是在有些服务器上摁R键会导致清空背包。
具体哪些会清空目前我也不是很清楚。
但是如果你不想玩家天天找你赔偿东西最好还是删除了吧


6.2——游戏界面小黄字修改

你还可以游戏界面的小黄字，有时会有意想不到的效果~
方式：解压 .minecraft\versions 里边的 版本名称.jar
然后点击 版本名\assets\minecraft\texts 里边的 splashes.txt
再压缩会原来的jar文件启动游戏就可以看到了

6.3——游戏内置材质修改
就是默认材质，在此不是很推荐，只是教给方法~
方式：解压 .minecraft\versions 里边的 版本名称.jar
然后打开 版本名\assets\minecraft\textures 里边的 文件夹
分别是不同的材质。GUI界面等。希望替换使用材质包中的替换
也可以用不同材质包中的进行组合(必须材质包作者允许)
再压缩回原来的jar文件启动游戏就可以看到了。


6.4——制作安装包

推荐使用电脑自带的winrar软件。

首先右键创建一个新建压缩文件
将它打开，左上角选择添加。
将你的客户端文件夹加入进去。
这时有一个界面让你选择如何压缩
点选上最佳压缩，自解压压缩，固实压缩
就做好一个最基本的安装包了
点击你的新压缩好的exe文件，就自动开始安装了
