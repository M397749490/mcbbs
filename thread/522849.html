我想问问楼主是用的是什么称号插件，或者是ESS自带的前缀后缀？
如果是前缀后缀的话，建议在ESS插件的配置文件里这样配置（这里借用地板楼的代码...）
  1. # 如果你想用其他的插件来设置玩家名字,将其改为"false".
  2. change-displayname: true

  4. # 当这个选项开启时,在玩家显示的名字上添加的前缀或尾缀,会被显示在在线列表(TAB)中.
  5. # 上面的"change-displayname"必须是true才有效.
  6. change-playerlist: true
复制代码

第二行代码保持原样，将第4行的布尔值改成false，这样可以禁止称号显示在TAB列表里。这样还能防止称号太长导致在列表里显示ID不全的问题。
