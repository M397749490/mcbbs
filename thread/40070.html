0. ESS 而不是 EES

1. 打开服务器目录\plugins\Essentials\

2. 用记事本以外的其他文本编辑器，打开config.yml

3. 找到以下，并添加你想禁用的物品或方块的ID

  1. # For which block types would you like to be alerted?
  2.   # You can find a list of IDs in plugins/Essentials/items.csv after loading Essentials for the first time.
  3.   # 10 = lava :: 11 = still lava :: 46 = TNT :: 327 = lava bucket
  4.   alert:
  5.     on-placement: 10,11,46,327
  6.     on-use: 327
  7.     on-break:

  9.   blacklist:

  11.     # Which blocks should people be prevented from placing
  12.     placement: 10,11,46,327                                 按格式加个英文逗号，然后加入一个想禁用的方块ID

  14.     # Which items should people be prevented from using
  15.     usage: 327                                                   加个英文逗号，然后加入一个想禁用的物品ID

  17.     # Which blocks should people be prevented from breaking
  18.     break:                                                         无法被破坏的方块ID

  20.     # Which blocks should not be pushed by pistons
  21.     piston:                                                         无法被活塞推动的方块ID
