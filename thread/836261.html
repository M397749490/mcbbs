武器的配置文件与载具本体无关，具体位置是：mcheli\assets\mcheli\weapons，以m134为例：

  2. DisplayName = M134 Minigun
  3. Type = MachineGun1
  4. [color=#ff0000]Power = 8[/color]
  5. Acceleration = 8.0
  6. Explosion = 0
  7. Flaming = false
  8. Sight = MoveSight
  9. Delay = 0
  10. ReloadTime = 80
  11. Round = 100
  12. SoundDelay = 3
  13. Accuracy = 4.0
  14. ; SetCartridge = model_name, Acceleration, Yaw, Pitch, ModelScale, Gravity, Bound
  15. SetCartridge = cartridge, 0.0, 0, 0, 2.00, -0.04, 0.40
  16. Sound = gun_l2_snd

  18. MaxAmmo = 1600
  19. SuppliedNum = 200
  20. Item =  3, iron_ingot
