Thicc Entities——实体自定义
这个MOD提供了一个配置，可以让你修改游戏里的所有实体的属性。
这个MOD默认会生成一个配置文件，配置文件不会修改任何东西，除非你更改配置。
例子↓
  1. minecraft {
  2.     player { //玩家
  3.         D:armor=0.0  //护甲值
  4.         D:damage=0.0625 //攻击上限
  5.         D:health=0.5 //生命值
  6.         D:jump=0.5 //跳跃高度
  7.         D:reach=0.0625 //近战距离，攻击距离
  8.         D:scale=0.0625 //比例，大小
  9.         D:speed=0.25 //速度
  10.         D:toughness=0.0 //韧性
  11.     }
  12. }
复制代码
这个例子修改了玩家的体型（也就是大小），跳跃高度和速度。
