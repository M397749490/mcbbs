InventoryKeeper 介绍

你是否觉得原版死亡掉落过于困难，而开启死亡不掉落又过于简单而失去平衡？
那么这款插件很适合你。

这款插件可以通过消耗物品或者给予权限的方式让玩家死亡后不再掉落物品并且支持在死亡、复活时执行指令。
同时也可以自定义经验值是否会掉落或丢失。

支持自定义死亡保护生效的死亡类型！

可以自定义被哪些生物或者具有某个名字的生物杀死才会激活保护。

只有当玩家拥有物品或权限才会死亡不掉落，没有物品的玩家死亡后会像原版一样全部掉落
掉落的同时也设置执行指令！

插件仅在死亡不掉落游戏规则关闭的世界起作用！

支持死亡后、重生后执行指令和随机指令组！

支持虚拟物品/真实物品/权限！（类似网游的复活币）
玩家死亡后将优先扣除背包中物品，最后再扣除玩家账户中的虚拟物品。

对于拥有权限的玩家，则玩家死亡不会掉落的同时也不会消耗复活币（虚拟、真实物品）。

所设置的物品支持自定义头颅、自定义模型id（1.13+）

现已支持星系（Galacticraft）模组的物品栏死亡不掉落（1.7.10/1.12.2）

经过测试，插件在1.7.10的服务器上可以正常使用。





指令&权限

指令支持TAB自动补全
管理员指令
/invkeep get <v/p> [数量]   -   获取设置的物品

/invkeep give <v/p> <玩家> [数量]  -  给予指定玩家物品

这里的v指虚拟物品 p指真实的物品，会直接给到玩家背包
例如/invkeep get v 2 - 获得2个虚拟物品


/invkeep set <玩家> <数量>  -  设定某个玩家的虚拟物品数量

/invkeep take <玩家> [数量]  -  扣掉某个玩家的虚拟物品

/invkeep check [玩家]  -  查询某个玩家虚拟物品的数量

/invkeep reload      -    重新加载配置文件

以上指令只有一个权限：inventorykeeper.admin
默认 OP 可以使用这些指令



玩家可用指令：
/invkeep check - 查询自己拥有虚拟物品的数量  - 权限：inventorykeeper.check（默认玩家拥有）

/invkeep check [玩家] - 查询其他玩家拥有的数量 - 权限：inventorykeeper.check.others


特别权限：
inventorykeeper.keep   -   拥有该权限的玩家在死亡不掉落的同时也不会扣除身上的复活币（相当于拥有无限数量的物品）。（该权限默认OP拥有）
可以配合其他插件做限时的不掉落功能(如vip的特权)
  


使用方法

安装：
1.下载插件，放进plugins，启动服务器
2.编辑配置文件，设置死亡不掉落需要的物品
  如果服务器装有星系模组，可在配置文件中将galacticraft-mod-support设置为true.
3.重载插件
玩家使用：
只要玩家的背包中存在所设置的物品，玩家死亡时将会消耗一个物品并保留背包。

  1.   run-commands-on-death:
  2.     - '[OP]fly off'
  3.     - 'tell %player% 你死亡了，因此你收到这一条信息'
  4.     - '100|1000|eco take %player% %random%'
复制代码
在固定指令组中，所设置的所有指令都会被执行

需要生成随机数的话，如以下格式设置： 最小值|最大值|指令

指令中用%random%替换即可，如上面例子的第三条。

如果想要做类似原地复活的功能的话，可以在复活时以OP权限执行back指令:
  run-commands-on-respawn:
    - '[OP]back'







另一个则是随机指令组

随机指令组中设置的指令，插件将会随机选择一组执行，可用于做随机的惩罚系统。

随机指令组中每一组都可以设置一个或多个指令，每个指令用分号";"隔开，分号后不要添加空格
则该组中所有指令都会被执行

需要生成随机数的话，如以下格式设置： 最小值|最大值|指令1;指令2;...

不需要随机数则直接填写指令即可。


栗子🌰：

  1.   run-random-commands-on-death:
  2.     - '[OP]fly on'
  3.     - 'xp 10L %player%;tell %player% 你复活了，但你因此获得了10等级的经验！'
  4.     - '100|1000|eco give %player% %random%;tell %player% 你因祸得福，收到了%random%游戏币！'
复制代码

%player% 替换玩家名
%random% 替换随机数
