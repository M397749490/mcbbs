这个可以锁MOD的方块

在plugins\LWC\core.yml
里面有一个protections 然后下面有一个block 在最下面按照它给的格式添加物品即可
例如我这个代码添加了一个暮色森林原木
  1. protections:
  2.     denyRedstone: false
  3.     denyHoppers: true
  4.     autoRegister: false
  5.     ignoreBlockDestruction: false
  6.     ignoreLeftClick: false
  7.     ignoreRightClick: false
  8.     ignoreExplosions: false
  9.     allowEntityBreakDoor: false
  10.     allowEntityInteract: false
  11.     quiet: false
  12.     readonly-modify: false
  13.     readonly-remove: false
  14.     blocks:
  15.         chest:
  16.             enabled: true
  17.             autoRegister: private
  18.         ...
  19.         twilightforest_twilight_log:
  20.             autoRegister: private
  21.             enabled: true
