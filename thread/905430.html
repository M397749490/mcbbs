The Tier 1 Time Machine is the most basic Time Machine of the mod. It allows players to travel to the Old West.

第一阶段的时间机器是mod中第一款时间机器

玩家可以使用它前往到旧西部世界



材料

This Time Machine is built with 30 Basic Time Machine Blocks, 1 Time Machine Core and 1 Time Machine Control Panel.

这款时间机器需要30个时间机器基础方块，1个时间机器核心和1个时间机器控制面板


用途

To access the Time Machine GUI enter inside it and right-click the Time Machine Control Panel in front of you. From the GUI you can choose where to travel.

你需要右键时间机器控制面板来打开时间旅行GUI，接下来选择穿越的时间线



冷却时间

When the Time Machine is used the Time Machine Core needs to be cooled down. This means the Time Machine will be disabled for the next 20 seconds.

当时间机器被使用以后，它将进入20秒的冷却时间，在冷却时间内，你不能使用它






The Time Crystal Ore is a very uncommon ore that drops one Time Crystal. It is found in the more deeper layers of the Overworld.
时间水晶矿石是一种很罕见的矿物，挖掘它可以掉落时间水晶，它会生成在5-20的高度
