本帖最后由 爱国民主 于 2018-6-7 16:32 编辑

  • 介绍
       KeepChunk允许你自行选择方块，让它加载到服务器内存中
       即时没有玩家在线，它依然处于加载状态
       不懂？
       简单说，防止重复加载影响游戏体验
       另外，它对大型红石电路、矿车铁路、命令方块以及传送都很有用

  • 特征
       加载更多块（这需要取决你的服务器配置）

       服务器启动时，所选的块也会加载
       不同方式加载块
       适用于1.8-1.12（注意要：Java8）

  • 命令
       /kc help - 查看帮助
       /kc reload - 重载插件
       /kc chunkinfo (coords | current | worldedit) - 关于载块信息
       /kc keepchunk (coords | current) - 保持加载单个块
       /kc keepregion (coords | worldedit) - 保持加载多个块
       /kc releaseall - 释放所有载块
       /kc releasechunk (coords | current) - 释放单个载块
       /kc releaseregion (coords | worldedit) - 释放多个载块
       当手动加载指定块时，记住是用块的坐标，而不是你站的坐标

  • 权限
       keepchunks.help - /kc help
       keepchunks.reload - /kc reload
       keepchunks.chunkinfo - /kc chunkinfo
       keepchunks.keepchunk - /kc keepchunk
       keepchunks.keepregion - /kc keepregion
       keepchunks.releaseall - /kc releaseall
       keepchunks.releasechunk - /kc releasechunk
       keepchunks.releaseregion - /kc releaseregion
       keepchunks.* - 所有命令

  • 配置
  1. # KeepChunks v1.4.1. Copyright ? 2018 TouchBar. All rights reserved.
  2. # Info & Support: https://www.spigotmc.org/resources/23307
  3. #
  4. # general:
  5. # debug: 设置true时，会在控制台显示调试信息
  6. # exposeos: 想让玩家看见你的操作系统吗
  7. # releaseallprotection: 是否仅限在控制台可以使用命令 releaseall
  8. # chunkload:
  9. # dynamic: 启用后，块会由KeepChunks将立即加载一次
  10. # onstartup: 是否在服务器启动时加载所有块
  11. # onworldload: 是否在加载时自动加载世界所有块（不是加入游戏时，而是走着走着就加载，懂了吧？）
  12. # 如果上面上个都禁止，那么块会在玩家进服时加载
  13. general:
  14. debug: false
  15. exposeos: true
  16. releaseallprotection: true
  17. chunkload:
  18. dynamic: true
  19. onstartup: true
  20. onworldload: true
