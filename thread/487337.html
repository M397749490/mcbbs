作者: lzs1234    时间: 2015-8-15 14:32
补上指令：
  1. /summon ArmorStand ~ ~ ~ {CustomName:"名字",Invulnerable:1b,Invisible:1b}
复制代码

名字换成类似1、2、3、4、5、6之类的，这样刷出几个名字不同的盔甲架。
然后创建计分板
  1. /scoreboard objectives add a dummy
复制代码
  1. /scoreboard players set @e[type=ArmorStand] a 0
复制代码

之后执行这个命令：
/scoreboard players set @r[type=ArmorStand] a 1
↑只需要执行一次

然后用几个testfor指令（有多少盔甲架用多少testfor）探测a分数为1的盔甲架
  1. /testfor @e[type=ArmorStand,score_a_min=1,score_a=1]
复制代码

后面接比较器连指令。

或者直接用execute指令/execute @e[type=ArmorStand,score_a_min=1,score_a=1] ~ ~ ~ 指令

最后执行/scoreboard players set @e[type=ArmorStand,score_a_min=1,score_a=1] a 0
