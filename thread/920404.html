Auto Tool —— 自动为你选择合适的工具并使用

简介
当你挖石头的时候他会为你自动选择稿子，以此类推

授权证明
正在沟通

特点
  • 方便懒人 A.A

效果图

命令&权限
命令:
  • /autotool - 就一个开启和关闭的指令
权限:
  • autotool.use - 使用权限

配置文件
config.yml——根据自己喜好修改
KeepPlayerDataDays: 30
UseJoinMessage: true
OnlyCheckToolBar: true
Messages:
    Prefix: "§6[§eAutoTool§6] "
    JoinMessage:
        Enabled: "§fAutomatic tool selection is §aENABLED"
        Disabled: "§fAutomatic tool selection is §cDISABLED"
    SwitchMessage:
        Enabled: "§fYou §aENABLED §fautomatic tool selection."
        Disabled: "§fYou §cDISABLED §fautomatic tool selection."

前置
点击插件名前往站内帖
  • (必选) PhoenixAPI
