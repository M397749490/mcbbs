/summon falling_block <x> <y> <z> {BlockState:{Name:"方块ID"}}
这个是使用召唤指令召唤一个 正在下落的方块，后面的xyz是指生成的坐标（也就是在哪生成）
最后那个方块名就是你要生成的方块，例如生成一个正在下落的泥土方块就在方块名那里输入minecraft:dirt（双引号不用去）
最后一个例子：在x=0 y=5 z=0处生成一个正在下落的基岩方块
/summon falling_block 0 5 0 {BlockState:{Name:"minecraft:bedrock"}}

关于那个斜抛运动的就会麻烦一点...
{ }←这个括号里需要添加新的值，刚刚的例子里只有添加Block值，如果要改变运动轨迹则需要添加一个Motion值，例如：
/summon falling_block 0 5 0 {BlockState:{Name:"minecraft:bedrock"},Motion:[0.5d,0.5d,0.0d]}
Motion值里面的三个值分别表示x轴分速度，y轴分速度，z轴分速度，通过这个可以改变运动轨迹

/summon minecraft:falling_block <x> <y> <z> {BlockState:{Name:"minecraft:grass_block"},Motion:[0.0d,0.5d,-1.0d],Time:1s}
在<x> <y> <z>填上你需要生成这个falling_block实体的坐标


解释一下三个NBT：BlockState表示掉落中的方块（falling_block）所代表的方块
                            Motion代表生成的掉落中的方块的速度 分别对应x y z三个方向
                            Time记录的是掉落中的方块存在的刻数，每秒增加20刻
参考页面：区块格式
