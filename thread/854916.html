标题: 114DNS 挂了，全国大范围无法连接
相信经常接触网络的人多少都听说过 114DNS 吧，这是一个国内比较有名的 DNS 服务商了。
他们家的两个 DNS 服务器：114.114.114.114 / 114.114.114.115 今天都挂了，全国大部分地区无法访问。
同一时间挂掉的还有谷歌的 DNS 服务器 8.8.8.8，目前也是无法访问的状态。
如果你正在使用 114DNS，建议切换回运营商的默认 DNS，或者使用阿里 DNS：223.5.5.5 / 223.6.6.6

什么是 DNS 服务器？
当你访问一个网站时，你只有他们的域名，例如 www.baidu.com，而只有一个域名是无法访问网站的，你的电脑需要将域名解析为计算机可连接的 IP 地址后才能访问网站，而这个解析的过程就需要由 DNS 服务器来完成，你可以把 DNS 服务器理解为是一个互联网的地址簿，它记录了每个域名对应的 IP 地址，而一旦 DNS 服务器挂了，你的电脑就会无法解析出域名的 IP 地址，导致无法访问网站。

个人常用的 DNS 服务器
  • 阿里 DNS：223.5.5.5 / 223.6.6.6（目前楼主使用的 DNS）
  • CloudFlare DNS：1.1.1.1（国外较快）
  • SDNS：1.2.4.8（国内较快，但是不要用于浏览违法网站）
  • IBM DNS：9.9.9.9
  • OpenDNS：208.67.222.222 / 208.67.222.220
  • 中科大 DNS：202.38.64.1 / 202.112.20.131 / 202.141.160.95 / 202.141.160.99 / 202.141.176.95 / 202.141.176.99（国内较快，纯净，安全）

Windows 更换 DNS 服务器的方法
  • 打开：控制面板\网络和 Internet\网络和共享中心
  • 找到你的连接并点击打开，例如 以太网 4
  • 点击 属性
  • 选中 Internet 协议版本 4 (TCP/IPv4)
  • 点击 属性
  • 在 首选 DNS 服务器 和 备用 DNS 服务器 输入框中输入你想使用的 DNS 服务器地址
  • 点击 确定 保存
