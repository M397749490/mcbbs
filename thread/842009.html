BedBlock
禁床使用插件



搬运感言
      因为MC一直以来都有个所谓的BUG,就是在末地或者地狱使用床的时候会引起爆炸,这给熊孩子增加了一个熊人的方式，曾经在1.8服务器的时候被人用这个方法熊过,深有体会,自己建服之后一直在杜绝这个问题,以前有个低版本的禁床插件,但那个是禁止放置床,后遗症是连管理员都没权限放,间接还导致无法在基岩上放置末影水晶进行末影龙召唤操作...
      前段时间偶然看到这个支持高版本的插件，就一路进行着测试，前几个版本都有问题，一直在跟作者反馈，然后作者也十分认真热情的进行修复工作，目前已经达到了理想状态，本来只是自用，然后看到作者那么认真负责，而且插件其实也挺不错的，但是下载量却很低，也就是很多人都不知道这个插件，经过几番考虑就行了授权搬运...这个插件支持命令重载，不需要重启服务器，支持多世界的使用，对生存服和某些特殊的服务器有很大的帮助.

作者原文介绍
BedBlock is a simple and lightweight plugin with multi-world support that allows you to prevent users from using beds on your server.
BedBlock是一个简单轻巧的插件，具有多世界支持，允许您阻止用户在您的服务器上使用床

Important Note: This plugin only prevents the use of beds, not the placement.
重要提醒: 这个插件只是禁止右键使用床(睡觉)，而不是禁止放置床.

命令权限 (不建议给玩家权限)

权限
  • 'bedblock.reload' - 重新加载配置
  • 'bedblock.modify' - 在游戏中修改被阻挡的世界


命令

    /bbadmin reload - 重新加载 config.yml 配置文件内容

    /bbadmin addworld <world> - 添加禁止使用(床)的世界

    /bbadmin removeworld <world> - 移除被禁止使用(床)的世界

安装

①.下载BedBlock插件
②.将插件放到插件目录plugins里
③.重启服务器
④.配置插件数据


配置worlds.yml

重要提醒:配置默认生成的禁止世界为主世界world，请自行手动修改配置，然后使用重载命令(/bbadmin reload)修改即可.

一般生存服建议配置(禁末地和地狱使用床):

  2.   - world_nether
