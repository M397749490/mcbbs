    NoMelt

这是一个不能让冰块融化的插件，适合做冰屋，冰城，冰碉堡，冰宫殿等等。
可以修改他的Config条件，包括部分功能，如不用精准采集 就可以挖到冰。
如下:
  1. 插件的Config里面  (用压缩打开)


  4. general:        注意这是原帖上的默认设置。
  5.     no Melting: true
  6.     ice Drop: true
  7.     no Freeze: true
  8.     ice Water: false

  10. 一般：
  11.     无融化冰块：是         不会融化的冰！
  12.     是否敲碎冰掉落：是     无需精准采集,打冰块即掉落
  13.     没有冻结：是           不会冻结的水
  14.     冰水：否               表示打破冰是否出现水



  18. 本网盘设置:

  20.     no Melting: true
  21.     ice Drop: false    注意是关闭的，需要精准采集可采集冰
  22.     no Freeze: true
  23.     ice Water: false



复制代码
如果无需精准采集就可采到冰的话，就请去原帖下载。如果用精准采集就可以采集冰请去网盘下载。


无任何命令和权限。{:10_497:}
