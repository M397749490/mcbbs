标题: ClearLagg如何设置移除地面特定怪物
这个清理插件，有个定时移除特定怪物的功能，但是，末地和地狱有大量的猪人和末影人，我在自动移除里面加上了，他们出生之后5秒内被移除，但是这个发生的前提是，定时移除发生，所以时间还是有点慢，怎么单独设置每隔一段时间移除猪人和末影人？
作者: 寂华    时间: 2020-6-30 09:48
本帖最后由 寂华 于 2020-6-30 12:17 编辑

在配置文件（config.yml文件）中找到auto-removal这一行
拿我服务器里的配置文件举例吧
auto-removal:
  enabled: true
  broadcast-message: '&8[&7收垃圾的苟寂华&8] &6在地上捡到了&a +RemoveAmount &6个辣鸡!'
  broadcast-removal: true
  autoremoval-interval: 300
  world-filter:

  boat: true
  falling-block: true
  experience-orb: true
  painting: false
  projectile: true
  item: true
  itemframe: false
  minecart: false
  primed-tnt: true
  item-filter:

  remove-entities:
    - zombie
    - skeleton
    - Zombie_Pigman
    - creeper
    - wither_skeleton
    - spider
    - CaveSpider
    - Blaze
    - Wither
    - Enderman
  warnings:
        - 'time:270 msg:&8[&7收垃圾的苟寂华&8]&6将在 &a+remaining &6秒后到达战场!'
        - 'time:290 msg:&8[&7收垃圾的苟寂华&8]&6将在 &4+remaining &6秒后到达战场!'

  autoremoval-interval: 300
这一行就是定时清除的时间设置
单位是秒
我这里设置为300就是5分钟一次

remove-entities:
这一行下面填写要清除的怪物的种类名称
例如
- zombie   就是清除僵尸
