虚无服插件介绍
1.自由PVP插件,可以越战Yo~~~
绿色代表开启PVP的玩家,红色代表关闭

2.砍树插件，砍掉树干一节就啪嗒啪嗒的砍好了
注意：只有(原版斧头才生效)

3.称号系统
/tgui open


4.商店系统
拿好要出售的物品左键单击
以聊天的形式输入价格
用指令更改商店类型
对着商店/see
可以看到商店内的物品
5.@系统
以聊天的形式
@玩家id
@全体玩家
6.锁箱系统
摆上箱子后自动上锁
7.领地系统
圈地工具为 纸
选取两个点后
/res select size 查看价格
/res create 领地名 创建领地
更多见群
8.被熊报告
在被熊地点
/rep sub [发给管理的内容]
耐心等待管理上线处理
更多教程在第九个菜单皆可看到

问题汇总
1.客户端在哪里下载?
群文件，群公告的关于客户端栏皆有下载

2.我家被熊了怎么办?
打开菜单查看第五格并单击

3.怎么进不了单人游戏
删除根目录下的.minecraft/mods文件夹中的[必须]反作弊.jar(进服务器时装回来)

4.卖op吗?
本服不卖op、创造等规格外的物品

5.客户端闪退或者out of memory
请将内存手动调为512M再试试(还不行的话就找管理员)

6.客户端怎么卡在加载页面未响应?
技术有限，优化做的不够好，耐心等等就好了

7.有地皮吗?
