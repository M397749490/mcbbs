VDTnT-Thrower —— 手持TNT左键投掷

简介
这个只有3.2KB的轻量级插件可以实现手持TNT左键投掷~熊孩子利器 PVP更好玩了
It allows you to launch the TnT with the right click, this plugin was dubbed for Skywars as a type Addon, there are many plugins like this but I will implement many things of my own.
