引言:
在使用学习Vault之前我们得了解三点：
  • Vault是什么？  Vault是一款Bukkit插件，它集合了经济、权限、聊天三个功能的接口
  • Vault能做什么？  Vault可以一次适配，兼容使用
  • Vault能给我们带来什么好处？ 使用Vault可以使我们的开发更加便利，如果现在有5个热门的权限系统，Vault的好处就是不需要对每一个权限系统进行适配，开发者只需要关注Vault提供接口

使用Vault进行开发时我们需要注意什么？
  • 有个权限插件、有个经济插件（需要支持Vault）。
  • softdepend和depend的声明，避免NPE
  • 例如使用经济相关的API时我们获取到Economy必须判断是否为空（处理没有安装经济插件或者权限插件的情况）

如何获取Vault：
MCBBS、BukkitDev、Github、Maven

如何添加Vault库：在plugin.yml中添加：
  1. softdepend: [Vault] 或 depend: [Vault]
复制代码
Maven：
在你的pom.xml文件中的repository中添加一下代码，然后同步：
  1. <repository>
  2.         <id>vault-repo</id>
  3.         <url>http://nexus.theyeticave.net/content/repositories/pub_releases</url>
  4. </repository>
复制代码

Eclipse：
右键项目 → Build Path → Add External Archives → 你下载好的Vault jar文件

IDEA:

方法一：
File → Project Structure → Modules → 你的插件Modules名 → Dependencies → 左下角＋号 → JARs or directories… → 你下载好的Vault jar文件

方法二：
File → Libraries → 左上 角＋号 → 你下载好的Vault jar文件 → 你的插件Modules名


使用Vault时我们会主要用到的类：
Permission：权限系统相关
Economy：货币/经济系统相关（注意：不同的经济插件往往有着不同的货币精度。有的插件是整数而有的是小数）
Chat：聊天相关，前缀等等相关

如何获取上述的三个类：
首先我们可以先定义以上类的变量：
  1. private Permission permission = null;
  2. private Economy economy = null;
  3. private Chat chat = null;
复制代码
然后我们在onEnable方法中初始化相应的变量：
  1.     /**
  2.      * 初始化Vault
  3.      * @return 是否成功
  4.      */
  5.     private boolean initVault(){
  6.         boolean hasNull = false;
  7.         //获取权限系统实例
  8.         RegisteredServiceProvider<Permission> permissionProvider = getServer().getServicesManager().getRegistration(net.milkbowl.vault.permission.Permission.class);
  9.         if (permissionProvider != null) {
  10.             if ((permission = permissionProvider.getProvider()) == null) hasNull = true;
  11.         }
  12.         //初始化聊天系统实例
  13.         RegisteredServiceProvider<Chat> chatProvider = getServer().getServicesManager().getRegistration(net.milkbowl.vault.chat.Chat.class);
  14.         if (chatProvider != null) {
  15.             if ((chat = chatProvider.getProvider()) == null) hasNull = true;
  16.         }
  17.         //初始化经济系统实例
  18.         RegisteredServiceProvider<Economy> economyProvider = getServer().getServicesManager().getRegistration(net.milkbowl.vault.economy.Economy.class);
  19.         if (economyProvider != null) {
  20.             if ((economy = economyProvider.getProvider()) == null) hasNull = true;
  21.         }
  22.         return !hasNull;
  23.     }
复制代码
以上例子中，我使用了ServicesManager来获取各系统Service的实例，然后我们使用getProvider方法获取对应实例。然后我们给类中变量赋值，并且同时判断是否为空，然后作为方法的返回值。之所以要这样做，是因为有的服主可能会安装了Vault以为不需要经济插件、权限插件，所以当我们在主类的onEnable中调用方法的时候，我们得对返回值做出处理，如下：
  1. if (!initVault()){
  2.        getLogger().severe("初始化Vault支持失败,请检测是否已经安装Vault插件和权限插件、经济插件");
  3.        return;
  4. }
复制代码
上面例子中，如果我们判断到初始化Vault实例失败，就在log中写入错误内容，并且停止插件的继续加载。

JavaDoc：
我们可以直接在Github中查看API，或者在官方链接中查看，里面有三个类对应方法的详细内容。
经济系统使用说明：
在获取了经济系统的实例后，我们可以调用以下方法获取我们需要的信息：
以下大部分可以传入玩家名代替Playe(不推荐)
economy.hasAccount(player) 判断玩家是否有经济账号信息。
economy.has(player, 50.0) 判断玩家player是否有50元。
economy.getBalance(player) 获取玩家player的“余额”。
economy.withdrawPlayer(player, 50.0) 拿走玩家50元。
economy.depositPlayer(player, 50.0) 给玩家50元。//Bank系统可以自己查看方法，方法名基本是前面加bank，可以使用economy.hasBankSupport()判断是否支持
权限系统使用说明：
在获取了权限系统的实例后，我们可以调用以下方法获取我们需要的信息：
以下大部分可以传入玩家名代替Playe(不推荐)
permission.playerHas(player, "UnknownDomain") 判断玩家是否有"UnknownDomain"权限。
permission.groupHas(world, "ud", "mccraft.cn") 判断权限组"ud"是否在world这个世界有"mccraft.cn"的权限。
permission.getPrimaryGroup(player) 获取玩家player的主要权限组。
permission.playerAdd(player,"ci.mccraft.cn") 给玩家添加"ci.mccraft.cn"权限。
permission.groupAdd(world, "ud","maven.mccraft.cn") 给权限组"ud"在world世界添加"maven.mccraft.cn"权限。
Remove：同理把Add改成Remove。

聊天管理系统使用说明：
这个不再列出了，方法基本是xxxPlayerPrefix之类的。Prefix是前缀，Suffix是后缀。
