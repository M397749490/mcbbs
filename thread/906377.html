哈啰~我4阿执~
今天要来教大家：
如何快速制作音阶盒演奏装置


--------------------------------------
【事前准备】
1.安装MCEdit  https://github.com/Podshot/MCEdit-Unified/releases2.准备好一个MID档
3.拥有Minecraft JAVA版帐号
转档MP3~MID
准备完就开始吧~GOGO
--------------------------------------
【下载Minecraft Note Block Studio 】

官网： https://www.stuffbydavid.com/mcnbs

蓝色：下载EXE档(直接下载)
红色：下载ZIP档(需解压缩)

蓝色：选择下载资料夹

蓝色：开始选单资料夹名称
红色：不要创建开始选单资料夹

蓝色：创建桌面捷径
--------------------------------------
【开始使用】
刚打开会出现这个：

1.自己做
2.读取NBS档(他自己的档)
3.读取MID档(如果不想花时间慢慢用，就转档吧~建议钢琴演奏版)
4.看英文教学影片
若选择3会出现：

上面不用管~
看下面
我们只需要注意右边的两个：
最右边~音量高低
倒数第二~音色

做完后点击左上方
「File」->「Export as Schematic」


点击后会出现这个：

红色：版本(选项1：1.11以上
                    选项2：1.11以下)
蓝色：改完点这个
--------------------------------------
【汇入地图】
开启「MCEdit」
点击「Create New World」


接着将「World Type」中的【Default】改为【Superflat】
「Generator」中的【Minecraft Server】改为【Fltaland 】\
(下图写错)
再点击「Create」

点击「Import」
接着选择你刚刚使用Minecraft Note Block Studio 汇出的档案

点击左键放置

放置好后点「Import」

再点击「Menu」-> 【Save】

这样就大功告成啦~~~
--------------------------------------
【汇入Minecraft 】
将储存好的地图丢入
AppData\Roaming\.minecraft\saves
就可以打开Minecraft开始听歌6
(建议使用1.12)
