首先你有abcd四个计分板，用来统计各个玩家的各种分数对吧？（我们假设abcd计分板上的玩家叫做maps_of_china）
/scoreboard objectives add game dummy
//创建一个叫做game的总计分板
/scoreboard players set a game 0
//把虚拟玩家a的game总计分板分数设为0
......bcd略
高频连接以下指令：
/scoreboard players operation a game = maps_of_china a
//将虚拟玩家a在game计分板上的分数同步为maps_of_china这个玩家在a计分板上的分数
......bcd同理略

其实是这样的：创建一个总计分板，然后我假设你有abcd四个计分板
然后在总计分板上创建abcd四个虚拟玩家产量，然后高频将四个计分板上的分数赋值给总计分板上的四个玩家。最后设置总计分板侧边栏显示。
