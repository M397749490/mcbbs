我还需要一些基本的东西
1，素材，我有6个这样命名的为png图片：
newblock_a ; newblock_b ; newblock_c ; newblock_d ; newblock_e ; newblock_f
2，在我的newblock类中，我声明了IIcon数组。
IIcon[] icon  ;
准备好之后，开始。

第一步，整理逻辑关系。
要为一个方块的每一面画上素材，首先要用方法registerBlockIcons(IIconRegister)读取图片文件。然后用方法getIcon(int, int)确定方块上素材的位置。
当然，这只是我在Block类中读取的逻辑关系。事实上是如何操作云云~~~我没有进一步探究。

第二步，读取全部素材。
在newblock类中添加
public void registerBlockIcons(IIconRegister IIR)
    {
        this.icon = new IIcon[6];
        this.icon[0]=IIR.registerIcon("newblock_a");
        this.icon[1]=IIR.registerIcon("newblock_b");
        this.icon[2]=IIR.registerIcon("newblock_c");
        this.icon[3]=IIR.registerIcon("newblock_d");
        this.icon[4]=IIR.registerIcon("newblock_e");   
        this.icon[5]=IIR.registerIcon("newblock_f");
    }

第三步，画上素材。
在newblock类中添加
public IIcon getIcon(int p1, int p2)
{
   if(p1==0)return this.icon[0];
   else if(p1==1)return this.icon[1];
   else if(p1==2)return this.icon[2];
   else if(p1==3)return this.icon[3];
   else if(p1==4)return this.icon[4];
   else if(p1==5)return this.icon[5];
}
这样就搞定了。

不过为了方便，我对getIcon这段东西还有个东西需要注意的。
public IIcon getIcon(int p1, int p2)
{
   if(p1==0)return this.icon[0];//这个对应的是底面的素材
   else if(p1==1)return this.icon[1];//这是顶面
   else if(p1==2)return this.icon[2];//侧面2，与3相对
   else if(p1==3)return this.icon[3];//侧面3，与2相对
   else if(p1==4)return this.icon[4];//与5相对
   else if(p1==5)return this.icon[5];//与4相对
}

public IIcon getIcon(int p1, int p2)
