功能

基于1.7.10开发并且向上兼容
替换服务器原本的帮助列表
支持PlaceholderAPI
支持自定义的子指令帮助
* 更多新功能等待你发觉...


指令

用法
简介
需要的权限
/hm
插件帮助
helpme.use
/hm reload
重载配置文件
helpme.reload
/hm append [内容]
向帮助列表最后一行添加[内容]
helpme.append
/hm append [内容] [行数]
向帮助列表[行数]的前一行添加[内容]
helpme.append
/hm delete [行数]
从帮助列表中删除第[行数]的内容
helpme.delete
/hm sub
子帮助列表
helpme.sub.use
/hm sub create [名称]
创建一个通过"/help [名称]"触发的子帮助列表
helpme.sub.create
/hm sub append [名称] [内容]
向名为[名称]的子帮助列表的最后一行添加内容
helpme.sub.append
/hm sub append [名称] [内容] [行数]
向名为[名称]的子帮助列表的[行数]的前一行添加[内容]
helpme.sub.append
/hm sub delete [名称] [行数]删除名为[名称]的子帮助列表的第[行数]
helpme.sub.delete
/hm sub remove [名称]删除名为[名称]的子帮助列表
helpme.sub.remove


配置文件

  2. # 是否开启控制台true为不屏蔽且控制台不支持papi变量
