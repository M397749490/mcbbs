介绍 · Introduction
这款插件可以只让在白名单内的玩家才能加入或传送到某个世界
特点
  • 返回选项,当你在一个有白名单保护的世界登录时你会传送到指定的世界. 如果没有可返回的世界, 你会被踢出服务器.
  • 支持所有传送插件
  • 可自定义
  • 轻量


指令 & 权限
/perworldwhitelist (/pww /ww /worldwhitelist) - perworldwhitelist.admin
  • <世界名>
    • enable - 启用或关闭世界白名单
      • true - 启用
      • false - 关闭
    • fallback - 设置返回世界
      • true - 设置为可返回的世界
      • false - 设置为不可返回的世界
    • info - 显示世界白名单信息
    • add - 添加玩家到该世界白名单内
      • <playername> - 玩家名
    • remove - 从白名单中移除
      • <playername> - 玩家名
    • setmessage - 设置白名单消息
      • <message> - 白名单消息.

  • reload - 重载插件
    • config - 重载插件配置
