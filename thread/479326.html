===== 服务器介绍 =====

梦幻之都是一个致力于制度的创新，并努力培育服务器文化及玩家游戏氛围的Minecraft服务器。我们的理念是：高素质与创新。 目前，我们已经建立起了一个比较完善的世界观并作了很多相关的优化处理和完善，相信一定能使您眼前一亮。我们致力于更加和谐、有爱、有趣的游戏环境，抵制不良风气，抵制低素质玩家。用心为您，呈现出色彩缤纷的梦幻之都世界。
原版纯净 加入即玩
现已加入最热门的游戏[起床战争]
== 客户端 ==
点击下载（只要是1.8.*的客户端都可以登录）GTA战争服和小游戏服请下载1.8

== 起床战争 ==

游戏简介:通过搜集钱币（铁币,金币,钻石）,跟村民兑换物资或武器来守护自己的床或进攻敌人的床,如果床遭到敌人的摧毁,死亡后将不能重生,存活到最后的那一队将获得胜利。
本服有两种模式,一种是红队对抗蓝队,另一种是红绿蓝黄四组相互对抗。
游戏地图已经完成了二十多张(由本服建筑师建筑),目前已经开放七张游戏地图,其它地图后续将会在测试调整完成后,陆续开启。

== GTA战争服 ==

无需任何前期积累，加入游戏即可开始玩
= 游戏流程 =
加入游戏 → 选择帮派 → 进入战区 → 搜刮补给箱 → 寻找帮派成员 → 追杀敌人 → 购买枪械 → 挑战生化战场 → 统治战场
达到一定的实力后挑战生化战场能获取更多的资源
= 枪械介绍 =
枪械类型：手枪、霰弹枪、冲锋枪、狙击枪、步枪、机枪。每种枪都有各自的子弹。
获得方法：枪械和子弹可以在战区的补给箱内找到，而且刷出几率很高，地图内共有三百多个补给箱，平均两个就有一个能刷出子弹和枪械，完全不用担心被其它玩家虐待。
除了枪械外，还有附加的爆弹和闪光弹，扔一个能造成成片的伤害。
= 载具介绍 =
载具其实就是汽车，需要先在主城购买汽车，才能使用车钥匙开车(车钥匙可以补给箱内找到)
汽车是很好的交通工具，可以顺利的逃脱战场或追捕玩家，也是找补给箱的好帮手。
= 生化战场 =
生化地区内会生成很多强大的生化病毒感染者，而且还有一定几率出现特殊的BOSS，拥有技能和丰富的掉落物
需要有一定的实力才能进入挑战，否则会死得很惨(目前已经配置十几种不同类型的生化怪物，以后还会增加更多)
= 副本末日战场 =
玩家不仅可以接受每日任务获得奖励，还可以在末日战场上收集资源兑换各种高级枪械
平民玩家也能拥有高级的武器
(每日任务会奖励任务点数，使用点数可以兑换高级枪械制作图)
= 帮派系统 =
游戏内分为四个帮派，每个帮派有各自的技能，相同帮派的成员不能互相伤害
进入游戏后建议第一时间就加入帮派
在战场内，寻找同帮派的玩家，一起组队杀敌将可更快的成长。
= 随身背包 =
可以随时随地的打开，存放贵重物品，而且死亡不会掉出来，初始背包空间只有九格，可以在主城升级背包空间。
= 频道喇叭 =
使用喇叭可以世界发送信息，能让所有玩家都看到
以后将会添加更多功能，敬请期待

== 众多小游戏 ==
= 空岛战争 =
好玩又刺激的PVP小游戏！
规则简单易上手！
进入游戏后，你会出生在一个小空岛上面，空岛上面会有补给箱，打开箱子可以获得许多物资，你的目标只有一个，就是存活到最后，并击杀其它玩家，活到最后的玩家，将获得胜利！
= 职业战争 =

游戏内拥有各种不同技能和属性的职业，选择你喜欢的职业并进入战场跟玩家PVP，通过击败对手来获得金币，金币可以在游戏内购买其它职业，你也可以在游戏内和其它玩家合作，利用每个职业不同的技能来组合击败对手。
= 新版躲猫猫 =

在原有的躲猫猫基础上，增加了更多的道具和游戏内容，玩家可以购买道具，并在游戏内使用。
开场后从随机一名玩家中抽选一名玩家成为寻找者，寻找者的任务当然是找到躲藏者并且将它们统统杀光，当寻找者杀死一个躲藏者，躲藏者的使命并没有结束，躲藏者会变成寻找者，继续寻找剩下的躲藏者！躲藏者会随机成为一种方块，只要呆在一个地方原地不动停留五秒，即可变成方块隐藏！（目前已有六张躲猫猫地图，以后还会陆续增加！）
= 饥饿游戏 =

这是一项残酷而可怕的生与死的竞赛，所有的玩家必须战斗到死，最后的幸存者就是胜者。 竞技场是经过人工布置的森林、荒原等特殊地型。这是一场，猎杀、追踪、饥饿、伪装、智斗等生死存亡的生存游戏。
= 建筑大师 =

建筑大师又叫速建比赛，考验玩家的记忆力和建筑能力，通过快速记忆建筑的结构和位置，然后在自己的平台上建筑出完美的建筑!
即使手残，也不用担心，建筑都是非常小型却很简单的建筑，可以在几分钟内完成的，在游戏内你还可以欣赏失败者被炸掉的建筑。
= 彩蛋射击 =

彩蛋射击是一个简单好玩的射击型PVP游戏！与雷神之锤类似，玩家开始游戏后会有很多彩蛋，扔出这些彩蛋击中敌人五次即可杀敌，并且可以在商店里购买其它道具来提高战斗力。
= 怪物竞技场 =

怪物竞技场是一个惊险刺激的PVE游戏，选择职业后进入竞技场挑战所有怪物和BOSS，BOSS带有特殊技能，不同的职业有不同的能力，挑战者们通过配合可以更有效的在竞技场内生存下来，直到杀光所有怪物才能获得胜利。
= 战墙 =

战墙是一款需要极高配合能力的团队才能获胜，每位玩家具有4个不同的职业用于互补互利，每个团队有15分钟的准备时间，在这15分钟内，你需要制作出你的工具、装备、武器，以确保在墙体落下的时候能有办法击杀其它敌人，当墙体落下的一瞬间，决战就开始了！
== 空岛-海岛●极限生存服 ==

独特的极限生存，与传统的生存相比，增加了更多生存的难度和内容，不仅让生存变得更加有趣，还能挑战更多的成就，与你的好友一起来创造属于你们的世界吧！

=== 关于我们 ===
2013年10月2日：梦幻之都服务器正式开服，并和一些基友们开始愉快的玩泥吧！
初次开服时，本服还是最单纯的工业服，当时的玩家也没有现在这么多，还是一个温馨的小服，都是一些认识的朋友一起在玩耍，服主时不时还加一些有趣的插件来提高一些乐趣。
第四周目时，本服决定全面改革成纯净插件服，不再重复之前因MOD更新或服务器不稳定而频繁换周目，避免因换周目造成的玩家损失，目前梦幻之都第四周目主要以特色插件为核心，服主还会不断添加更多有意思的插件，希望能有更多玩家喜欢玩。
经历三次更换周目······
经历多次因BUG的回档、崩服···
经历一次又一次的调整和更新···
如今梦想之都服务器正式开启四周目——多模式集成服！
经验不断的积累，我们也开始制作属于自己的插件，创造更多不同的新花样！
每天都在更新插件的配置，保证玩家在游戏内不会乏味，不断体验新的乐趣！
多模式集成服务器时代正式开启：登录服-生存服-游戏服-创造服-空岛服-躲猫猫服
如果你不喜欢玩纯净服，不要紧，本服还开创了空岛MOD服，从无到有的生存模式，不仅好玩，而且玩家的发展空间也很大，目前已有不少玩家想出了不同的自动化空岛设备，使空岛增加更多可能。
我们已经从以前那种普通的生存服成长为如今的多模式集成服！
一切只为让你玩得更开心~~
