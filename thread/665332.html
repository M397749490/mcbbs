4.支持的变量

  • '' (Just empty! Nothing inside!) = Free line 空行
  • %player% = Playername 玩家名字
  • %money% = Money amount (Only enabled if Vault is installed!) 玩家的金币
  • %rank% = Rank name (Only enabled if Vault is installed!) Rank(求大神翻译此项)
  • %world% = World name 所在世界名字
  • %now% = Amount of now players 现在的人数
  • %max% = Amount of max players 最大的人数
