                                        MobSpawnerLimit区块刷怪限制                                         

搬运证明


介绍

本插件能够限制每个区块里的刷怪数量（包括自然生成以及刷怪蛋）

使用方法

         如果玩家在他所站的区块内放刷怪蛋，区块内怪物达到了配置文件config.yml中设置的数量后，将会给你消息提醒,并且限制刷怪。   
                              




命令
●/msl reload  重载配置文件

                          ●/msl set [limited|enabled] <value>  设置单个区块内刷怪数限制/启用插件                                                   


                                          




权限

   无，默认OP拥有





                                                                         配置文件     

  1. chunk:
  2.   enabled: true     #是否启用
  3.   limit: 2               #单个区块刷怪数限制
  4.   messages:
  5.     - "&8[&aMobSpawnerLimit&8]&7: &6Chunk spawners limit reached!" #区块刷怪数限制提醒
