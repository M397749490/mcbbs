标题: 怎么设置领地无伤
我服有NPCMOD，里面的绿宝石手枪可以无视领地造成伤害，这个怎么关？
作者: 迷途的村庄    时间: 2015-7-24 13:17
/res set <领地名> [权限] [true/false/remove] - 设置某领地的权限
权限↓
damage
pvp
设置成false
/res set <领地名> damage false
/res set <领地名> pvp false

你可以试试
