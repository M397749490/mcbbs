TitleBoardcaster——字幕广播v1.2.0

简介 Description
这个插件允许使用指令"/tb"来发送字幕广播。插件基于SponeAPI7.1.0制作,低版本的请自行测试。


特性 Features
  • 可以在游戏中或控制台使用该插件的指令
  • 可以设置广播字幕的副标题[现在暂时只有玩家和控制台两种]
  • 插件已汉化


使用方法 Method of use
  • 下载插件并丢入服务端/sever/mods文件夹
  • 重启服务器



配置文件 config
  • Duration{   #不用管
  • fadein=10   #设置渐显时间
  • fadeout=10   #设置渐隐时间
  • stay=60   #设置停留时间
  • }
  • Subtitle{   #不用管
  • player="&9&l -来自{player_name}"   #玩家发送时的副标题，可以使用占位符，例如{player_name}或{player_displayname}
  • server="&4&l -系统消息"   #控制台发送时的副标题，同理↑
  • permissioncheck=你没有权限使用此命令



命令和权限 Command
命令
/tb 内容   #发送广播字幕
/tb reload   #重载插件
权限
titleboardcaster.use   #可以使用命令/tb发送字幕广播的权限
titleboardcaster.reload   #重新加载配置文件的权限
