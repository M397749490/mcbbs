TpLogin是一个简单,实用的插件，它用给定的权限将玩家传送到给定的位置。

最初的想法来自于: http://dev.bukkit.org/bukkit-plugins/tplogin/

本Tplogin作者
Tplogin完全支持1.8-1.14版本的Bukkit/Spigot服务器
注：使用此插件请删去Essentials-spawn会与之冲突(3.2以下版本不需要，因为3.2才有/spawn指令)
作者授权(有点假)



特点
1.当前最新版本内存仍然小于20kb
2.支持管理玩家权限
3.支持自定义

食用说明
1.下载这个插件
2.把插件丢掉Plugins文件中
3.重启服务器或者yum等插件加载
4.开心的使用这个插件吧

命令
- /tplogin - 展示这个插件信息
- /tplogin help - 列出插件的帮助
- /tplogin set [坐标名] - 设置传送点坐标(如果只输入/tplogin set那么就是设置默认点)
- /tplogin tp [坐标名] - 传送到传送点
- /tplogin reload - 重载这个插件
- /spawn - 传送到默认传送点(3.2以上版本输入/tplogin set设置默认点后可使用)

权限
- tplogin.use - 允许使用/tplogin
- tplogin.use.spawn - 允许使用 /spawn
- tplogin.use.set - 允许使用 /tplogin set
- tplogin.use.set.extra - 允许使用 /tplogin set [坐标名]
- tplogin.use.tp - 允许传送到默认坐标点
- tplogin.use.tp.extra - 允许传送到坐标点
- tplogin.use.reload - 允许使用 /tplogin reload
- tplogin.location.<坐标名> - 传送到坐标点
- tplogin.bypass - 越过强制传送 (前提:在settings.yml中启动)

玩家能拥有的权限
- tplogin.use.spawn - 允许使用 /spawn
- tplogin.use.tp - 允许传送到默认坐标点
#这一条和上面效果一样就是指令不一样，都是传送到默认点,上面指令/spawn 这里/tplogin tp

- tplogin.use.tp.extra - 允许传送到坐标点
- tplogin.location.<坐标名> - 传送到坐标点
#这里首先需要上面的权限下面的权限才有用！！！！
#有了上面的权限那就有/tplogin tp <坐标点>的权限
#但是还需要下面的权限才有传送到指定坐标点的权限

- tplogin.bypass - 越过强制传送 (前提:在settings.yml中启动)
#settings.yml开启且有这个权限的可以不用强制传送到默认点

  2. In-Game-Only: '&cThis command can only be run by in-game players!'
  3. No-Permission: '&cYou do not have permission to use this command.'
  4. Invalid-SubCommand: '&cInvalid Sub-Command! Use /tplogin help for help!'
  5. Command-Set-Usage: '&cUsage: /tplogin set [location-name]'
  6. Reloaded-Configs: '&aYou have reloaded the plugins configs!'
  7. Set-Default-Location: '&aYou have set the default spawn location!'
  8. Set-Named-Location: '&aYou have set a named spawn location!'
  9. TpTo-Default-Location: '&aYou have teleported to the default location!'
  10. TpTo-Named-Location: '&aYou have teleported to a named location!'
  11. Location-Does-Not-Exist: '&cThis location does not exist!'

Settings.yml

  1. General:
  2.   Use-Bypass-Permssion: true
  3.   Quit-Timer-Bypass:
  4.     Enabled: true
  5.     Time-In-Seconds: 300
复制代码
Settings.yml讲解(message.yml就不讲解了=-=)

  1. General:
  2.   Use-Bypass-Permssion: true  #这是为了使用tplogin.bypass权限，开启则有这个权限的人无视强制传送到默认点
  3.   Quit-Timer-Bypass:             #开启则强制传送到默认点有CD比如我现在进入服务器被强制传送
  4.     Enabled: true                   #那么300s后再次进入服务器才会被强制传送到默认点
  5.                                         #如果是为了让玩家每次进入都强制传送到默认点建议关闭这个功能
