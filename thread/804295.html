TabooScript 教程


0#0 认识脚本

TabooScript 使用的语言为 Groovy，他与 Java 大同小异。但如果你是从 Java 来到 Groovy，那么你可能需要注意以下几点:

1. Groovy 不需要 ";" 符号结尾。
2. Groovy 没有 Lambda 表达式，但它支持闭包。（Runnable run = { println 'run' }）
3. Groovy 可以使用 def 来定义无类型变量。（def number = 0）

关于其他区别可以自行百度搜索 "Groovy 与 Java 的区别"


0#1 Hello, World!

将 TabooScript 与 TabooLib（4.10+）一起放入 /plugins 文件内重启服务器。
在 plugins/TabooScript 文件夹内你可以看到以下文件

plugins/TabooScript/lang语言文件夹
plugins/TabooScript/scripts脚本文件夹
plugins/TabooScript/config.yml配置文件

在 脚本文件夹 中创建一个文件并命名为 "test.groovy" 后打开，写入以下内容：

  1. println "Hello, World!"
复制代码

之后在控制台输入指令：

  1. /tabooscript load test
复制代码

我们可以看到脚本正常载入并且后台提示 "Hello, World!"



随后输入 /plugins 便可以看到你的脚本在插件列表中出现了。



0#2 变成插件！

TabooScript 的脚本会被视为插件加载，你可以添加以下内容来为你的jio本润色。

  1. plugin.description {
  2.     name 'Example'
  3. }
复制代码

这样你的jio本就会以 "#Example" 的名字出现在插件列表中，当然你可以在配置文件更改这个前缀 "#"。
当然你还可以添加其他内容：

  1. plugin.description {
  2.         // 插件名称
  3.         name 'Example'
  4.         // 插件描述
  5.         description '一个脚本'
  6.         // 插件作者
  7.         author '坏黑'
  8.         // 插件版本
  9.         version '1.0-SNAPSHOT'
  10.         // 插件网站
  11.         website 'www.mcbbs.net'
  12.         // 插件依赖
  13.         depend 'TabooLib'
  14.         // 插件软依赖
  15.         softdepend 'Vault'
  16. }
复制代码


0#3 基本触发器

TabooScript 与 Java 插件不同，在这里我们将以下几种方法称作 "基本触发器"。这些触发器在每个脚本中只能出现一次。

  1. plugin.onLoad {
  2.     // 当脚本载入，你可以用来初始化变量。
  3. }
  4. plugin.onEnable {
  5.     // 当脚本启动，你可以用来注册指令或是监听器
  6. }
  7. plugin.onDisable {
  8.     // 当脚本卸载，你可以用来注销数据
  9. }
复制代码

示范：

  1. plugin.onEnable {
  2.     println '插件已载入，感谢您使用 TabooScript！'
  3. }
  4. plugin.description {
  5.     name 'Example'
  6. }
复制代码
