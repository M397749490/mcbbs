  • 可以自定义开启/关闭飞行世界
  • 可以自定义飞行速度
  • 可以自定义提示消息
  • 可以在进入游戏时自动飞行
  • 可以开启/关闭粒子效果
  • 所有消息支持颜色代码！



使用教程
  • 前往原帖下载插件
  • 将插件放入服务端plugins文件夹中
  • 重启服务器
  • 替换汉化config
  • 享受插件~


插件指令&权限
指令
  • /ufp fly - 开启/关闭飞行
  • /ufp <player> - 开启/关闭 玩家的飞行
  • /ufp speed <0-10> - 设置飞行速度
  • /ufp help - 显示插件所有指令
  • /ufp perms - 显示插件所有权限
  • /ufp particles - 开启/关闭 粒子效果
  • /ufp reload - &7重载插件

权限
  • ultimateflyplus.fly - 使用 "/ufp fly" 权限
  • ultimateflyplus.fly.other - 使用 "/ufp <player>" 权限
  • ultimateflyplus.speed - 使用 "/ufp speed <0-10>" 权限
  • ultimateflyplus.status - 使用 "/ufp status <player>" 权限
  • ultimateflyplus.help - 使用 "/ufp help" 权限
  • ultimateflyplus.perms.list - 使用 "/ufp perms" 权限
  • ultimateflyplus.particles - 使用 "/ufp particles" 权限
  • ultimateflyplus.reload - 使用 "/ufp reload" 权限


配置文件
config.yml
  1. PARTICLE-FLY-TYPE: HEART
  2. PARTICLE-SPAWN-TIME: 5
  3. PARTICLE-POSITION: -0.5
  4. AUTOMATIC-FLY-ONJOIN: true
  5. BLACKLIST-WORLDS:
  6. - example
  7. prefix: '&c&lUFP &8&l>> &7'
  8. fly-enabled: 飞行已 &a开启&7.
  9. fly-disable: 飞行已 &c关闭&7.
  10. fly-status-enable: 玩家 %player% &a开启了 &7飞行.
  11. fly-status-disable: 玩家 %player% &c关闭了 &7飞行.
  12. fly-other-enable: '&7你对玩家 &c%player%& &a开启 &7了飞行'
  13. fly-other-disable: '&7你对玩家 &c%player% &c关闭 &7了飞行.'
  14. fly-speed: 飞行速度设置为 &c%flyspeed%&7.
  15. fly-warning: 请使用此命令格式 &c/ufp speed <value>&7.
  16. noperms: 你没有权限执行这个指令!
  17. help-fly: 请使用此命令格式 &c/ufp fly&7.
  18. help-status: 请使用此命令格式 &c/ufp status <player>&7.
  19. player-offline: 该玩家不在线

  23. particles-disabled: 粒子效果已 &c关闭&7.
