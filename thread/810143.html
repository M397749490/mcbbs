CustomDeathMessage

自定义死亡讯息



插件信息:


插件作者：vk2gpz
搬运：枫林1
此插件允许您为每个世界设置单独的死亡消息。



感谢作者制作的这么一款插件



命令：
/ cdm
/ customdeathmessage
/ customdm
/ deathmessage
/ cdm help 显示帮助菜单
/ cdm reload 重新加载配置

  7. #讯息
  8. Messages:
  9.   ErrorMsg : "&c[死亡讯息] : 发生了一些错误。"
  10. #帮助信息
  11. HelpMessages:
  12.   banner:
  13.     msg: "=== &e[&a死亡讯息 命令列表 (%version%)&e] &r==="

  15.     msg: "&a/cdm help : 帮助菜单。"

  18.     permission: "customdeathmessage.reload"
  19.   debug:
  20.     msg: "&a/cdm debug <true|false> : 打开/关闭调试模式。"
  21.     permission: "customdeathmessage.debug"


  24. PlayerDeathEvent_Priority: NORMAL
  25. Broadcast: true
  26. UnknownKiller: "未知生物致死"
  27. UnknownTool: "未知工具致死"

  29. #允许您定义每个世界的死亡消息格式。
  30. #使用世界名称作为关键
  31. #如果你不想使用标题，子标题，消息，只需输入一个空字符串
  32. #格式翻译：玩家被生物用工具（手中的物品，比如：剑，弓）杀死在world世界（世界别名字）
  33. Format:
  34.   default:  #如果未找到任何特定于世界的格式，则将使用此格式
