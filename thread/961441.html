作者: 迁冥DeeChael    时间: 2020-2-16 21:32
1.12.x：
testfor @e[标签]
1.13.x以上：
execute if entity @e[标签] run 指令
或execute if entity @e[标签] at @e[标签] run 指令 （在此生物位置执行指令）
标签：
就列举常用的
type类型，输入实体的英文id，比如苦力怕就填type=creeper
name名称，输入实体名称，中文要带双引号，比如我的名字就是name="迁冥大大"
tag标签，输入已经给某个实体设定好的标签，比如我给一直猪设定了标签sb，就是tag=sb
c数量，这个testfor没有大用处，主要用于execute的run。
1.13x以上例子：比如要检测三只tag为b，名字为sm的猪，并将将三只猪tp到他们原本位置的上方10格就是：
execute if entity @e[type=pig,tag=sb,name=sm] at @e[type=pig,tag=sb,name=sm] run tp @e[type=pig,tag=sb,name=sm] ~ ~10 ~
