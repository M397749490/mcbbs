【MOD原帖】点我
---------------------------------------------------------
你是否已经厌倦了走路探索世界，是时候翱翔天空了！


---------------------------------------------------------
V7 changes
Update to Beta 1.4_01       升级到1.4_01
New 5x3 plane crafting grid    新的5*3合成框
New components       新零件
Interchangeable Engines     可更换引擎
Improved Planes API     改进程序应用界面
Two Seater Planes (Only use at the moment is to carry wolves)
Two Seater Biplane (Mainly an example plane)      双座飞机
Support for double propellers       支持双螺旋桨
Planes always break into component parts
New Spitfire Skin
Old planes somewhat tidied up, old items are obsolete, craft for a new one     淘汰了一些旧飞机和零件

默认控制键位：
W – 加速
S -
减速
A – 向左
D – 向右
Space – 向上看
Left Shift – 向下看
E – 离开
R – 库存
Left Control – 射击
C – 空投炸弹
以上你可以在planes.properties中修改。

安装：
客户端
1. 下载安装 Risugami's ModLoader 网盘
2. 下载安装 GaryCXJk's Turbo Model Thingy v2.2 Preview 网盘
3. (可选)下载安装 Risugami's AudioMod 网盘
4. 下载mod本体Planes v7（修复材质）网盘
5. 阅读介绍说明
6. 玩吧
7. 合成公式下载，参考 MOD翻译电子书v0.2

安装新飞机
当某人使用API制作了新的飞机，你可以下载他们的飞机，然后放进你的minecraft.jar里面，如果有需要，有些文件请放到resources里面。然后打开你的.minecraft\planes.txt，
在里面添加飞机的名字，你也可以通过改变或删除飞机名字来卸载新飞机。
但是服务器还不能。

Planes API Stuff下载安装（新手跳过）
1. 下载安装MCP 2.11 for 1.4_01 所有MCP版本  MPC2.11原帖下载  115网盘
2. 下载安装modloader然后放到minecraft.jar，根据之前提供的说明把它放到MCP里。
3. 在MCP中反编译，然后重编译检查它是否工作。
4. 下载Planes API Stuff - 原帖下载  115网盘
5. 阅读readme然后制作你的飞机
如果你需要帮助到esper.net的#risucraft里面来找我。
