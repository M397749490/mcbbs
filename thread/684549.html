自定义你的命令

功能:
  • 可以自定义你的命令
  • 简化你的繁琐的命令
  • 将多个命令集合在一起
  • 给玩家输出信息
  • 花费金钱使用
  • 播放特殊的声音


命令介绍:
/ccmd   查看帮助菜单
/ccmd create <需要花费的金钱[0则不需]>  <命令> 创建一个自定义命令(在Config.yml修改)

/ccmd reload    重载插件


权限：
ccmd.admin    允许使用set/reload [最最最好不要给普通玩家!]


配置文件说明：
  1. # 多命令例子:
  2. # huoqu:
  3. #    money: '50'
  4. #    command:
  5. #    - 'give_[player]_1'      // [player]代表发送指令者的ID
  6. #    - 'say: §6你获得了64个原石'  // say: 代表向发送指令者发送信息
  7. #    - 'voice: NOTE_PLING'  // 播放NOTE_PLING的声音
  8. # 单命令直接 command: give_[player]_1 即可
