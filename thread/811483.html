核心：循环

循环的原理是两个函数的互相调用，类似于：
a=>b=>a=>b=>......
那么，怎么让循环产生次数呢？要用到记分板
在上面，我先刷出了一只盔甲架，积分版上的分数设置为1
然后在互相调用时加了这样的一个execute串
execute if entity @e[tag=bow_lie,scores={bow_main=..8}] run function bow:bow/startblock
和这样一段命令
scoreboard players add @e[tag=bow_lie] bow_main 1

这样调用一次循环就增加一次分数，直到分数达到9，if条件不成立，就跳出了循环
其他想说的

tp指令中的坐标（指下面的），如果是相对坐标的话，那么是要以命令执行处的坐标开始计算的，所以有时不要忘记加execute at
tp 实体 坐标
