插件介绍

这款插件十分简单，可以让NPC与玩家对话.
不同于Citizens的文本编辑器，这款插件可以让NPC的对话更加自然

  • 可以自定义对话格式

  1. npcTexts: "§6[{2}/{3}] §e§l{0} :§r§e {1}" # 消息 + ID显示
  2. npcTexts: "§e§l{0} :§r§e {1}" # 只限消息
复制代码

  • 所有操作都可在游戏内通过指令实现 !
  • 输入 /text 指令,你可以添加、移除、导入、列出文本!
  • Tab自动补全指令
  • 你可以给一条消息添加指令 ! (点击消息、 控制台选项、自动dispatchment)
  • 你可以给每条消息添加音效.
  • NPC可以从他的对话列表中随机说出其中一条.
  • 你可以从Citizens默认的文本编辑器中导入文本.
  • 可以显示下一条消息出现的间隔 (在配置文件内修改).你也可以修改显示所需距离玩家的距离.

前置


Citizens





指令
  • /text help 帮助指令
  • /text insert <id> 插入一条对话
  • /text add <内容> 添加一条对话
  • /text remove 移除一条消息
  • /text cmd <add/remove/auto> 给文本添加指令
  • /text convert 从Citizens的文本编辑器中导入文本
  • /text random 随机显示一条消息
  • /text list 对话列表
  • /text clear 删除所有消息
  • /text reload 重载插件
权限

  • citizenstext.command : /text command 的权限
  • citizenstext.add : 添加对话
  • citizenstext.remove : 移除对话
  • citizenstext.cmd : 给对话添加指令
  • citizenstext.list : 列出所有对话
  • citizenstext.clear : 清除所有对话
  • citizenstext.sound : 设置对话结束时的音效
  • citizenstext.convert : 从默认编辑器中转换文字
  • citizenstext.random : 开关随机模式
  • citizenstext.reload : 重载插件配置
  • citizenstext.save : 保存配置

截图


使用方法
  • 先用/npc select <ID> 选中一个NPC
  • 然后输入/text add <消息> 即可添加一句对话，其余对话以此类推
  • 如果输入的消息有错,输入/text remove <消息ID> 来移除，可以用/text insert 在一句话后插入一条消息
  • /text cmd add <指令> 来给某一句话添加指令,比如给最后一句话添加其他任务插件的完成任务指令
  • 右键NPC测试成果

配置
  1. #文本格式
  2. npcTexts: "§6[{2}/{3}] §e§l{0} :§r§e {1}"
  3. #点击消息显示的文字
  4. clickableMessage : '§e可以点击消息 !'
  5. #自动对话间隔，默认-1关闭
  6. continueAfter: -1
  7. #自动对话距离
  8. continueDistance: 10
  9. #多少秒后重播对话
  10. playbackSeconds: 5
  11. #关闭点击对话
  12. disableClick: false
