疑似是tick函数中包含了一个检测npc是否在特定位置的指令而这个位置没有被加载，引起的报错。
我在这条代码前加上了forceload之后就不再出现标题的报错了
出事代码：
  1. execute unless entity @e[type=villager,x=-611,y=99,z=452,dx=42,dy=7,dz=5,nbt={CustomName:'{"translate":"pl.npc.name.te33"}'}] positioned -589 104 454 run function pld:npcs/qiansi/te33
复制代码

修复方式：强加载这个指令所使用的区块就不再报错
