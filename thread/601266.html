标题: [1.7.10][Bow Overhaul——弓箭改革]爆头与更多弓！（汉化)
本帖最后由 世界边境 于 2018-1-11 10:06 编辑
现在，弓箭可以爆头啦！
这个mod对弓箭进行了很多修改，使其比以前更有用。

爆头
现在弓箭可以通过爆头来产生更高的伤害。
任何怪物和玩家都会具有一个“爆头判定区”，使用弓箭击中该区域可以产生高倍伤害。
同时爆头伤害可以自定义，并且这种爆头伤害判定对每一种弓箭都起作用
（可以在其他mod的弓上产生效果，比如与更多武器的枪配合可以打出巨量伤害）。
该判定默认对所有原版生物及mod添加的类人怪物起作用。
可以通过F3+B进入调试模式来查看怪物的判定区域，爆头判定区会被红色框体框住
（但楼主测试的时候斌没有看到红色区域，可能是BUG）


箭头伤害过渡
当你距敌人太近时，箭头伤害会变低。
默认情况下，弓箭需要飞行至少十格才能达到最大伤害，
在此之前，弓箭飞行的距离越近伤害越低。
这一特性将会配置给每一种弓箭
（即对mod添加的弓箭也起作用）。


装甲重量影响
当你穿着重型装甲时，你的拉弓速度会变慢。
只有皮甲、链甲与该mod提供的装甲会被认定是“轻甲”，
除此之外的装甲都会被认定为“重甲”。
（与蜥蜴人改革一起用的话会很变得很可怕）


更多弓
新增五种弓。
新增了五种对应五种合成材料的弓（木弓，石弓，铁弓，金弓，当然还有钻石弓）。
这五种具有如下改变：
*箭的速度、伤害、射程略有不同
*箭的下坠速度与制造该弓的材质有关——下坠速度取决于制造弓所用材料的挖掘速度
*弓的耐久与其材质有关
*当弓具有“无限”附魔时，在箭袋和物品栏中不需要有箭存在
*能够射出箭袋外的弓箭


箭袋
箭袋中可以存放三种弓箭。
你还可以制造一些带有箭袋的装甲，这样你就可以不必牺牲你的装甲


更多箭
新增六种箭。
新增了六种对应六种合成材料的箭。
*箭的伤害基于箭的材质
*插在地面上的箭需要五分钟的时间才会消失


更多装甲
新增了一些轻甲。

可堆叠的雪球与药瓶弹
新增各种雪球与药剂弹可以堆叠

*雪球可以堆叠64个
*药剂弹可以堆叠16个


更新日志
0.0.0
- 测试原始版本.


已知BUG
*与截肢mod不兼容，可能导致坏档(感谢@liubiaocg的测试）
*与更多附魔mod 一起用会自带补缀附魔。。打怪给怪加血（感谢@冥界弃少的测试）
解决方法：
把更多附魔配置文件[MoreEnchants.cfg]这一行B：MendingEnable=true
true改成false。
*与打包药水mod 一起用会箭矢发生爆炸（感谢@冥界弃少的测试）
解决方法：
在本mod的配置文件[BowOverHaul.cfg]中找到这一行：
# If this is true, potion ammo will be enabled (splash potions that stack, but can only be used as bow ammo). Default is true.
    B:potion_ammo=true
true改成false。
（感谢@Dumpling_dada提供的解决方法）

关于BUG的解决方法：
1.和更多附魔的冲突：
把更多附魔配置文件[MoreEnchants.cfg]这一行B：MendingEnable=true
true改成false。
2.和打包药水（和药水工艺也有）冲突：
在本mod的配置文件[BowOverHaul.cfg]中找到这一行：
# If this is true, potion ammo will be enabled (splash potions that stack, but can only be used as bow ammo). Default is true.
    B:potion_ammo=true
true改成false。
至于另一个冲突....不知道....
以上均为本人自己尝试~
