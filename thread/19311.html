基本Mod






！这个Mod修改以下！
1. 红石火把和火把亮等级一样
2. 萤石总是掉5个萤石粉
3. 挖红石方块总是掉5个红石
4. 铁镐可以挖走黑曜石
5. 瞬间破坏树叶
6. 打苹果%提高
7.黑曜石有點容易破坏
8. 雪球最大装袋16提升到64

安装
1. 装Modloader
2. 下载.zip然后打开
4. 把里面东西全部扔到Minecraft.jar里
4. HAVE FUN
