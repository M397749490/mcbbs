常见问题

1.空岛不能点火

空岛配置config.yml里的 FIRE: false  改成 FIRE: true
之后在游戏中输入指令 /asadmin settingsreset all  就能点火了
如果还不能点火以Ess插件为例
在Essentials这个文件夹里，用Notepad++编辑软件打开config.yml配置文件
找到flint-fire这一项这个默认是false如果是true 改为 false
再用管理员账号在游戏中输入指令/ess reload


2.玩家可以用活塞把方块推到岛外

插件默认允许，如果你不想这样做，打开config文件把allowpistonpush设为false，然后输入/asadmin reload即可

3.还没创建空岛前领取新手礼包 之后创建空岛 新手礼包物品都没了

打开config文件把resetinventory: true
改成resetinventory: false
这样就是领取礼包之后再创建空岛 礼包也不会没了

4.完成任务给的奖励不完整

更新  [前置]Vault  插件
5.空岛指令是英文
目前有两种方法
第一种
汉化方法在游戏输入: /is lang <数字>
数字可输入此指令查看: /is lang
第二种
先右键插件用压缩包打开
再打开locale文件夹
双击点击 你选的.yml 用Notepad++打开语言文件查看你需要的语言
比如我选的 zh-CN.yml 语言文件 我选的是中文
找到了自己要的语言文件后
在打开配置config文件
在config文件里找到
defaultlanguage: en-US
改成 defaultlanguage: zh-CN
上面我选的是中文    改好后保存
之后开服即可
如果是已经开服后要修改语言文件则是
在生成的文件配置里修改onfig文件
在config文件里找到
defaultlanguage: en-US
改成 defaultlanguage: zh-CN
上面我选的是中文    改好后保存
之后在重启服务器或者输入/asadmin reload重载下配置就完成了

空岛自带刷石机机制
magiccobblegenonlyatspawn: false
如果设置为true，原石生成器将只在spawn中工作
   当心！产卵必须与岛屿在同一个世界工作。
   magiccobblegenonlyatspawn: false
一般都是设置成 false 关闭状态
在配置config中的[675]行有一项
usemagiccobblegen: false  
默认值为false，因为它会极大地改变游戏性
改成 usemagiccobblegen: true
如果设置为true，原石生成器将不仅生成原石，也可以指定块
设置 usemagiccobblegen: true 之后
就开启了刷石的功能 刷出的块也可自定义设置
比如:
magiccobblegenchances:
     #这些概率在默认情况下适用

       STONE: 20.0
