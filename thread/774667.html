标题: 怎么设置某个区域死亡不掉落
我服务器除了主城和地皮都是死亡掉落的，想弄个pvp场地，设置单独的死亡不掉落，怎么设置某区域死亡不掉落
作者: gouj511    时间: 2018-1-9 19:53
用领地插件即可，将该区域圈地，然后用管理权限的/resadmin设置这两个权限
/resadmin set [领地名] keepinv true #设置死亡不掉落
/resadmin set [领地名] keepexp true #设置死亡不损失经验
作者: 爱浪    时间: 2018-1-9 20:41
