标题: 今天闲着无聊~~给各位大大腐竹说下服务器BUG和防范
大家都应该知道Minecraft这款单机游戏开放服务器以来，BUG就一直不少。。。今天呢给腐竹大大们简单说下服务器一些需要防范的BUG

       ①-    lwc锁箱子刷东西！  lwc这款锁箱子插件大家都应该是非常知道的吧，但是这款锁箱子插件里有一个比较严重的刷物品BUG！（前提服务器必须要开启死亡掉落）  原理：/lwc mode droptransfer 他这个是一个和拾荒者差不多的功能吧、就是当你开启这个功能之后，在你死后它会自动把你身上的物品转移到一个箱子，从而保护你的物品！但是如果服务器开启死亡掉落的话，当你死亡之后默认你的装备会掉落在原地！但是你回去之后会发现你地上有一分物品！你箱子还有一份！可以无限重复刷，，解决方法:打开lwc的core.yml配置文件，按照我这下面修改 ,就是把这个功能关掉了，然后重启服务器~~就ko了
  1. modes:
  2.     droptransfer:
  3.         enabled: false
  4.         crossWorld: false
  5.     persist:
  6.         enabled: false
复制代码
   






      ②-  这个是关于NPCMOD的问题！NPCMOD呢有几个核心物品就是NPC魔杖！但是这几个物品（可能对这个MOD非常熟悉的腐竹都知道这个了）是可以在生存模式下制作出来的！配方我暂时就不透露了。。当一个玩家制作出魔杖之后他会设置一个用一个泥土换一组钻石块的商人NPC！还有 设置NPC攻击数据设置栏里有一个弹射物！里面有个爆炸效果设置！记住 这个爆炸效果如果真的运行起来是可以无视任何东西的！甚至可以毁了你的主城，而且NPC还有修改合成配方功能！具体我这也不提了。。。解决方法：先用banitem或者ati插件ban掉这几个魔杖！然后右键制作出一个NPC点击全局设置里的NPC合成表选项,里面还有一个全局设置点进去，你就会发现这个NPC魔杖的合成配方了。。只要你把合成配方删掉就OK了！如果这样你还不放心的话呢你就打开NPCMOD的config按照我下面的修改
  1. #Only ops can create and edit npcs
  2. OpsOnly=false
复制代码
就OK了~~~默认是只有OP才可以用的哦~~~~
