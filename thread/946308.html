快速、可靠的公益 Minecraft 皮肤站，随时响应你的查询请求。
LittleSkin 是一个 Minecraft 皮肤站，基于 Blessing Skin Server，支持 Yggdrasil 鉴权验证（即俗称的“外置登录”）。现在，我们大概是国内第二大的第三方 Minecraft 皮肤站（*）。

你是否遇到过以下问题：
  • 皮肤站速度太慢，等待好久都加载不出皮肤？
  • 别的玩家和你用的不是同一个皮肤站，互相看不到对方的皮肤？
  • 无法加载皮肤，自己不知道怎么做，皮肤站管理员也帮不了你？
  • 皮肤站商业化运营，不氪金就没人权？
  • 其他皮肤站的好多特性在你的皮肤站都用不了？

不用担心！在 LittleSkin，这些问题统统不存在的！
现在，隆重介绍 —— LittleSkin!
虽然 LittleSkin 看起来和其他使用 Blessing Skin Server 搭建的皮肤站只是有那么一点不太一样，但是在你看不见的地方，却有着大不一样的风景：

快，更快，比快还快！
加载快！“滴答”一秒，乖♂乖♂站♂好
（**）
32 核 CPU + 64GiB 内存，这是我们的服务器配置。对皮肤站来说，这会不会给人一种...杀鸡用牛刀的感觉？但是，为了速度，这么做值得。
此外，在源站服务器之前，LittleSkin 还加了一层腾讯云 CDN。通过遍布全国的高质量缓存节点，用户可以直接就近获取资源，跑得比香港记者还快（逃

安装快！LittleSkin 现已加入 CustomSkinLoader 默认加载列表豪华午餐
早在三年前，LittleSkin 就被加入了 CustomSkinLoader 默认加载列表，加载顺序仅次于 Mojang 官方。无需任何繁琐的配置（***），你要做的只是把 CustomSkinLoader 放进 mods 文件夹，打开游戏，你已经成为了你。

更新快！只要我更新地够快，Bug 就追不上我
LittleSkin 使用 Blessing Skin Server 开发版，更新速度比其他使用 Blessing Skin Server 稳定版搭建的皮肤站要快得多。并且，LittleSkin 运营组内部设有与 Blessing Skin Server 核心开发者直接沟通的快速反馈渠道。这意味着你可以在 LittleSkin 体验到很多其他皮肤站没有的特性，大部分的 Bug 也都会在第一时间得到修复。

用户体验，我们是认真的
贴心的用户使用手册 哪里不会点哪里，So easy！
LittleSkin 提供了精心准备的用户使用手册，供所有用户查阅。啥都不会的萌新可以阅读用户使用手册来学习如何使用 LittleSkin，大多数问题都在「常见问题解答」中有相关记录，进阶用户也可以在其中了解到 LittleSkin 的一些高级功能的用法。更令人惊喜的是，右上角的搜索框集成了 Algolia DocSearch 文档搜索，支持文档全文搜索，真正实现“哪里不会点哪里”（****）。

用心的运营团队 Blessing Skin Team 官方推荐皮肤站
不论何时，LittleSkin 的工作的出发点始终是用户体验。自 Blessing Skin Server v2 开始，LittleSkin 给 Blessing Skin Server 提供了无数的建议和意见，新版本 Blessing Skin Server 中的很多特性都来自 LittleSkin。LittleSkin 运营组成员的 1/3 都是 Blessing Skin Team 成员，其中更有 Blessing Skin Server 核心开发者 @gplane 和 CustomSkinLoader 作者 @gooding300 两位重量级巨佬坐镇。我们或许不是最专业的皮肤站运营团队，但是我们一定是最用心的，没有之一。

公益免费不氪金 用爱发电坚持到最后一刻
自建站起，LittleSkin 就采用公益运营模式，承诺基础服务永不收费。我们的收入来源只有独立运营的云计算业务和付费的一对一远程技术支持服务，以及用户自发进行的捐助，连广告都没有。当然，我们会给捐助者发送捐助回报，其中甚至包含站点创始人手写的定制明信片（*****）。

建站四年，历史悠久
国内第二大的皮肤站 小伙伴们都在用
自 2016 年 3 月建站起，LittleSkin 已经走过了四个年头。在这四年里，有 100K+ 用户选择我们提供的服务，高峰期每月处理超过一亿次查询请求，更是有多个服务器使用 LittleSkin 的 Yggdrasil 鉴权验证系统作为玩家帐户管理系统。现在，LittleSkin 已成为国内第二大的 Minecraft 皮肤站，你不必再担心你的小伙伴和你使用的不是同一个皮肤站导致互相看不到对方的皮肤。

超硬核的用户交流群 你甚至可以在群内讨论 LittleSkin
我们的官方用户交流群内聚集了各路大佬，从普通玩家到大型服务器的服主再到声名显赫的开发者，从初中生到见得多了的大学生再到供职于互联网巨头的社会人，你见过和没见过的都有。围观群内讨论时你可能不知道我们到底在说些什么，但是在群内你一定能学到些什么。（******）

立志成为国内最好 我们一直在努力
LittleSkin 的目标是在维持公益运营的模式下做国内最好的第三方 Minecraft 皮肤站，这绝不止是说说而已。这听起来或许是个可笑的梦想，但我们一直在朝着这个目标努力。随着一个个里程碑的突破，我们相信我们能做到的。

唔，看了一下，内置的头像 API 在 BS v5 开发版 092eedf 这个 commit 中有更改，但是 changelog 没写。
相关路由定义在 routes/static.php L9~L13，方法定义在 app/Http/Controllers/TexturesController.php L101~L157，感兴趣的话可以参考一下，这里给出用法：
  1. # 通过 UID 获取用户头像
  2. GET https://littleskin.cn/avatar/user/{uid}
  3. # 通过角色名获取角色头像
  4. GET https://littleskin.cn/avatar/player/{playername}
  5. # 通过 TID 获取材质头像
  6. GET https://littleskin.cn/avatar/{tid}
  7. 以上 API 均可在 URL 后加上 3d 参数（无需赋值）来获取 3D 头像，加上 size 参数（值为所需的尺寸）可获取指定尺寸的头像
