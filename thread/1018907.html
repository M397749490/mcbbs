BanEffect v1.0

这个插件可以让你在Spigot端 控制(限制)你不想要的Effect
（如：药水效果、夜视、debuff、Mod效果）

20200415073216.png (56.25 KB, 下载次数: 0)

由于 spigot 核心在 1.15 版前 未提供玩家获得 Buff 时的监控事件
就只能从 ProtocolLib 中获取服务器的 Buff 发包来拦截了

举个例子
玩家在发展 神秘时代Mod 时扭曲值过高，导致随时可能出现上述的 BUG 效果
那么 BanEffect 会在玩家 收到 BUG 效果前 拦截服务器发送 Effect 的数据包

当然了。这只是 ProtocolLib 最简单的一个应用


使用方法

安装前置插件 ProtocolLib 4.4.0 (不建议 4.5.0 )
(按理来说，绝大多数服务器自带这个插件)
https://www.spigotmc.org/resources/protocollib.1997/

安装 BanEffect 插件到 plugins
https://github.com/i493052739/BanEffect/releases/
启动服务器

调试 plugins/BanEffect/config.yml
输入 /baneffect reload 重载配置文件（或用yum，重启，均可）

Config配置文件
