插件功能简单实用


每次玩家登录都弹出一个书本

这个书本可以编辑自定义
默认OP登录不弹出
如果服务器安装了登录插件，请把本插件里面延时0设置长一些


作用很多，比如通知玩家服务器有哪些更新，服务器活动通知等等

  1. Prefix: '&7[&c书本通知&7] '       *应该是显示标题的名称
  2. JoinDelaySeconds: 50               *加入之后几秒后显示，有登陆插件必须改变数值
  3. Cooldown: 5000                        *冷却时间,应该是显示之后,几秒之内重新登陆不在显示
  4. PermissionsEnabled: false           *权限?
  5. JoinNotificationEnabled: true       *是否开启 加入后通知
  6. JoinNotificationByPassEnabled: true          *是否能免去通知
  7. JoinNotificationByPassPermission: booknotification.bypass       *免去通知的节点            
复制代码
默认OP拥有 booknotification.bypass  
如果不想部分组或者玩家需要自行给予booknotification.bypass。
我还没有测试权限节点能否改变，可以自行尝试一下。(记得备份)
