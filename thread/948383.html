[ EconomyAPI - 经济前置插件 ]

EconomyAPI 是由 OneBone 开发的一款属于PocketMine的经济插件
大部分插件都需要这个作为前置

授权搬运
申请中...

插件功能

  • EconomyAPI 自定义信息支持
  • 高效简便的命令信息
  • 大众化的储存方式
  • 经济API支持

插件命令

/mymoney
 显示资金余额
 权限: economyapi.command.mymoney

/topmoney
 列出资金排行榜
 权限: economyapi.command.topmoney

 /setmoney <player> <amount>
 设置玩家资金
 权限: economyapi.command.setmoney

 /seemoney <player>
 查看玩家资金
 权限: economyapi.command.seemoney

 /givemoney <player> <amount>
 给予玩家资金
 权限: economyapi.command.givemoney

 /takemoney <player> <amount>
 取走玩家资金
 权限: economyapi.command.takemoney

 /pay <player> <amount>
 支付玩家资金
 权限: economyapi.command.pay

 /setlang <language>
 设置语言
 权限: economyapi.command.setlang

 /mystatus
显示经济状态
权限: economyapi.command.mystatus

插件配置

CONFIG.YML (参考用...)
monetary-unit: "$"

  2. # monetary-unit: 设置使用的货币单位
  3. monetary-unit: "论坛无法显示这个符号..."
  4. # add-op-at-rank: 设置是否在排行榜显示OP
  5. add-op-at-rank: false
  6. # default-money: 设置新玩家的默认资金
  7. default-money: 1000
  8. # max-money: 设置玩家的资金上线
  9. max-money: 9999999999
  10. # 设置玩家不在线时是否允许付款
  11. allow-pay-offline: true

  13. # default-lang: 设置默认语言
  14. default-lang: ch
  15. # auto-save-interval: 设置自动保存间隔
  16. auto-save-interval: 10

  18. # provider: 设置数据库提供方式 (可用: yaml, mysql)
  19. provider: yaml

  21. # check-update: 设置是否检查服务器更新
  22. check-update: true
  23. # update-host: Set host where to check update
  24. update-host: onebone.me/plugins/economys/api

  26. # provider-settings: 设置数据库信息
  27. provider-settings:
  28.   host: 127.0.0.1
  29.   port: 3306
  30.   user: onebone
  31.   password: hello_world
  32.   db: economyapi
