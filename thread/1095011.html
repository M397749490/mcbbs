预发布版是 Minecraft Java 版的测试机制，如果该版本作为正式版发布，那么预发布版的游戏文件将与启动器推送的正式版完全相同。

然而，预发布版主要用于服主和 Mod 制作者的预先体验，如果发现重大漏洞，该预发布版会被新的预发布版代替。因此建议普通玩家持观望态度。

Minecraft 1.16.2 仍未发布，1.16.2-pre2 为其第 2 个预览版。

NEWS
Minecraft 1.16.2 Pre-Release 2
Minecraft 1.16.2-pre2



We have now brought out the second pre-release for Minecraft 1.16.2, in which another round of bugs has been squished!
我们现在推出了 1.16.2 的第二个预发布版，又一轮漏洞修复来啦！

Changes in 1.16.2 Pre-release 2
1.16.2-pre2 的更改


  • Crimson and Warped Roots no longer require shears when mined
  • 绯红菌索和诡异菌索不需要剪刀也会掉落了

Technical Changes in 1.16.2 Pre-release 2
1.16.2-pre2的技术性更改


Execute Command
/execute 命令


  • execute in now respects dimension scaling
  • execute in 现在会遵循维度的坐标缩放
  • 举个例子，在主世界(16,64,16)处执行
    1. /execute in minecraft:the_nether run tp ~ ~ ~
    复制代码
    现在会传送到下界(2,64,2)处（也就是自动除以8），反之亦然（也就是自动乘8），且适用于自定义维度。
  • 上述命令的波浪号替换为准确的数字则没有该效果。

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。Java版的启动器下载地址在上文已经提供。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。

关于 execute in 的倍率缩放变动，假设执行命令时的所在维度为1倍，那么


#这将和以前一样，会被传送到目标维度的指定坐标，(绝对坐标)不受缩放影响
execute in <目标维度> run tp <x> <y> <z>

#这会把你当前坐标按目标维度的倍率缩放后传送到目标维度
execute in <目标维度> run tp ~ ~ ~

#会传送到目标维度而坐标将使用受缩放影响前所在维度的坐标。
#结果将和此次快照变动前的右边这条命令一样。 execute in <目标维度> run tp ~ ~ ~
execute in <目标维度> positioned as @s run tp ~ ~ ~


另外，数据包的dimension_type里的自定义维度json可以定义coordinate_scale，用于指定该维度的缩放值
这里有一个由slicedslime提供的原版世界生成的参考文件
https://twitter.com/slicedlime/status/1288490213241688070


*in 仅改变执行维度，这次变动多了个坐标倍率转换
*positioned 仅改变执行坐标
