<====CarryOn====>

                                                ----搬箱



---前言---

你是否曾想过为什么史蒂夫能在口袋中一次搬运一组64个箱子，却不能空手移动移动一个装满东西的箱子？
你是否还在考虑用其他模组的工具来搬运箱子呢？

不用再想了，这个模组能帮你实现空手搬箱（当然，小动物也是可以的）。

对熔炉等有一定作用

---动态GIF图---


---图集---

原版箱


多模组支持


神奇的动物搬运



---使用方法---

Shift+右键 拿起箱子（拿起动物）

右键 放下箱子（放下动物）

---杂项---


1.该模组对其他模组的箱子有一定兼容

2.箱子拿起时不会被偷（废话！）

3.可以修改配置文件来ban箱子

4.一次只能搬运一个箱子且其他动作无效

5.搬箱时会减慢移速，（箱子）东西越多越慢

6.[亲测]在开启死亡掉落时，死亡时箱会被放置于死亡地头顶位置

不开启时，会当做一个方块放置于物品栏中（好像是个bug）


---已知bug---

1.
Rendering while carrying is a bit 'janky' on multiplayer server
多人游戏渲染有点小问题（偏小,移动时箱子会颤抖）

2.
Armor still animates when carrying a Tile Entity
护甲问题（？？？）

3.
On a server, in first person, the right hand of a players disappears when another player is carrying a Tile Entity
服务器中第一人称视角下，当其他玩家搬运箱子时，右手会消失

4.
[亲测]部分玩家无法搬运MOB，暂时无解，已上报作者，正等回复


---强大的配置文件---
该模型覆盖配置可用于手动覆盖某方块模型。

格式
[backcolor=rgba(27, 31, 35, 0.05)]modid:block;meta{NBT}->(type)modid:item;meta{nbt}
模组名：方块名；数据{NBT标签}->（种类）模组名：物品；数据{NBT标签}
Meta, NBT and the type are optional.
The type defaults to "item".
数据，NBT标签，种类可选。种类默认为物品

基础例子
minecraft:furnace->minecraft:dirt
minecraft:furnace->minecraft:dirt;1
minecraft:log;1->minecraft:stone;2
minecraft:hopper->(block)minecraft:hopper
minecraft:flower->(item)minecraft:flower

高级例子
energymod:generator{energy:300}->energymod:battery;1
buildingmod:bricks;1{type="red"}->buildingmod:brick{type="orange"}

原贴地址（需科学上网）：https://github.com/Tschipp/CarryOn/wiki/Model-Override-Config
