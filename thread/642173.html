       本帖不是教程帖，是为了记录一下我接触Minecraft的过程。前两帖的内容和Oeasy老师的网课内容是重复的，但是后面会有个人的内容。

       JDK安装以后，我们就可以运行我们本地的服务器了。

       使用前面下载的“craftbukkit-1.7.2-R0.3-20140211.200058-44.jar”文件。

       首先，在这个文件所在的目录下新建一个“开始.txt”，然后复制粘贴以下内容：

  1. @echo off
  2. :MAIN
  3. cls
  4. java -Xms1024M -Xmx1024M -jar craftbukkit-1.7.2-R0.3-20140211.200058-44.jar
  5. if exist "plugins\RestartEvolution\restart.mcs" goto MAIN
  6. if not exist "plugins\RestartEvolution\restart.mcs" goto END
  7. :END
  8. echo
  9. pause>nul
复制代码

       其中Xmx是用来设置你的应用程序能够使用的最大内存数,如果程序要花很大内存的话，那就需要修改增加此数的值。

       Xms是用它来设置程序初始化的时候内存栈的大小，增加这个值的话你的程序的启动性能会得到提高。

       接着对“开始.txt”重命名，改成“开始.bat”。如果系统隐藏了文件后缀名，设置一下显示文件后缀名就可以了。

       服务器弄好了，接下来就是去下载客户端了。

       Oeasy老师的视频中并没有讲解怎么下载客户端。我本着“从官网下载、避免病毒、体验原汁原味Minecraft”的信念，去官网下载了Minecraft的安装程序。安装完以后，又等老半天更新资源，最后发现如果不花钱买正版，只能玩Demo。本想支持一下，但是觉得有点贵。就想着先自己折腾，等熟练了再充值信仰。

       尝试了几个办法，最后发现视频中Oeasy老师用的是Hello Minecraft Launcher——你好我的世界启动器（HMCL）。

       搜索一下，第二条就是官网：


       打开官网，看了一下，更新日期还挺近，看来是受众颇广、经常维护的。直接点击网页上的“立即下载”就可以得到HMCL-2.5.3.88.exe了。

       我想着越新的客户端越好吧，就去下载了1.10版本，后来发现我的服务器的jar包是“craftbukkit-1.7.2-R0.3-20140211.200058-44.jar”，版本不兼容。

       我就又下载了1.7.2版本，里面有“.minecraft”这个文件夹，把这个文件夹里面的东西复制到先前的HMCL启动器生成的.minecraft里面就行了，至于压缩包里其他的文件，我们暂时（也可能以后都）用不到。
