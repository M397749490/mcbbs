新建一个TXT文件，里面输入
@ECHO OFF
SET BINDIR=%~dp0
CD /D "%BINDIR%"
java -Xmx1024M -Xms1024M -jar craftbukkit.jar
PAUSE
另存为run.bat
然后运行run.bat
这个文件要和你下载的服务器文件放在同一目录下。
