恩....登出前的话建议是存到Yml中
  1. @EventHandler
  2. public void onJoin(PlayerJoinEvent e) {
  3.   e.getPlayer().getLocation();//登陆后的坐标
  4. }

  6. @EventHandler
  7. public void onQuit(PlayerQuitEvent e) {
  8.    e.getPlayer().getLocation(); //玩家登出前的坐标(建议是保存在Yml中,到时候可以拿来读取啥的)
  9. }
