我想批量删除玩家的帐号，因为有些人创小号或者很久没玩
有什么插件或者要修改什么配置吗？
作者: 梓    时间: 2016-5-8 14:52
authme自带清理
  1. Purge:
  2.     # 如果启用，AuthMe将自动清理掉旧的，未使用的账户
  3.     useAutoPurge: false
  4.     # 多少天后变为未使用的账户
  5.     daysBeforeRemovePlayer: 60
  6.     # 是否在清理中顺便清理player.dat文件？
  7.     removePlayerDat: false
  8.     # 是否在清理中顺便清理 Essentials/users/player.yml 文件？
  9.     removeEssentialsFile: false
  10.     # 哪个世界存放了 players.dat
  11.     defaultWorld: 'world'
  12.     # 是否在清理中顺便清理 LimitedCreative/inventories/player.yml, player_creative.yml 文件？
  13.     removeLimitedCreativesInventories: false
  14.     # 是否在清理中顺便清理 AntiXRayData/PlayerData/player 文件？
  15.     removeAntiXRayFile: false
  16.     # 是否顺便清理权限？
  17.     removePermissions: false
