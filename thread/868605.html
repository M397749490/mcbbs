执行一次
scoreboard objectives add x dummy
scoreboard objectives add y dummy
scoreboard objectives add z dummy
scoreboard objectives add death deathCount

高频执行
execute as @a[scores={death=1..}] store result score @s x run data get entity @s Pos[0]
execute as @a[scores={death=1..}] store result score @s y run data get entity @s Pos[1]
execute as @a[scores={death=1..}] store result score @s z run data get entity @s Pos[2]
scoreboard players reset * death

让玩家返回死亡地点：
summon minecraft:armor_stand ~ ~ ~ {Invisible:1b,Invulnerable:1b,Marker:1b,Tags:["death_point"]}
execute store result entity @e[tag=death_point,limit=1] Pos[0] double 1 run scoreboard players get @p x
execute store result entity @e[tag=death_point,limit=1] Pos[1] double 1 run scoreboard players get @p y
execute store result entity @e[tag=death_point,limit=1] Pos[2] double 1 run scoreboard players get @p z
teleport @p @e[tag=death_point,limit=1]
kill @e[tag=death_point]
