Obsidian-黑曜石

一款nk空岛辅助插件

插件功能：

  • 空桶点击黑曜石还原岩浆
  • 可设置仅潜行有效
  • 允许错误的刷石机
  • 禁止高空流水/岩浆
  • 禁止高空流水自定义判断格数
  • 树苗掉落保底（最少一个）
  • 玩家掉入虚空拉回




功能演示：

黑曜石还原岩浆：
用空桶点击黑曜石即可还原为岩浆


允许错误的刷石机：
将阻止黑曜石生成，并正常生成石头


禁止高空流水：
如果水/岩浆下X（可设置）格无方块，则禁止水/岩浆流动


树苗掉落保底：
启用后会对树叶附近进行判断，如果附近一定范围内无树叶，则一定掉落树苗
玩家放置的树叶不会触发上述事件
（记录功能代码参考若水的插件 已授权）


虚空保护：
玩家掉入虚空拉回，如果安装了空岛插件，并且在空岛地图，则拉回到空岛
如果没有安装空岛插件，就直接拉回到主世界
如果使用模式1拉回，请关闭空岛的传送冷却功能





配置文件：


config.yml:

  1. #启用后将回收黑曜石与空桶，并给予玩家岩浆桶
  2. 空桶点击黑曜石还原岩浆: true
  3. #针对上述操作是否仅潜行有效
  4. 仅潜行时有效: true
  5. #如果水/岩浆下多少格无方块，则水/岩浆不留动
  6. 禁止高空流水: true
  7. 高空流水判断格数: 3
  8. #最后一个树叶必掉树苗
  9. 树苗掉落保底: true
  10. #玩家掉入虚空拉回
  11. #安装空岛插件则拉回空岛，否则拉回主世界
  12. 虚空保护: true
  13. # 1 - 直接拉回主空岛(请将空岛传送延迟设置为0)
  14. # 2 - 扫描附近方块，拉回到最近空岛
  15. # 没有空岛插件或不在空岛世界就拉回到主世界
  16. 虚空保护模式: 2
  17. #以下功能处在开发状态，可能工作异常
  18. #将阻止黑曜石生成，并正常生成圆石
  19. #bug较多，请谨慎使用
  20. 允许错误的刷石机: false
