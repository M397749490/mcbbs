正方体材质，如石头只要一张图片就行。如果改名的话需要修改json文件（又称解析文件）。
只有一面说明你做的是熔炉的材质或者别的什么的。想六面都一样这也需要修改json文件。
石头（一张贴图）
  1. {
  2.     "parent": "block/cube_all",
  3.     "textures": {
  4.         "all": "blocks/stone"
  5.     }
  6. }
复制代码

熔炉（三张贴图）
  1. {
  2.     "parent": "block/orientable",
  3.     "textures": {
  4.         "top": "blocks/furnace_top",
  5.         "front": "blocks/furnace_front_off",
  6.         "side": "blocks/furnace_side"
  7.     }
  8. }
复制代码
