Pickaxe Upgrades 介绍

插Pickaxe Upgrades 插件可以让你的稿子有一个可视化升级的效果，可以获得升级的效果并且还可以获得特殊效果或者
在升级的过程中获得一个全新的附魔效果

工具自定义描述
稿子自定义等级
可自定义的开采方块
稿子升级的进度条/百分比
TokenEnchant 插件支持
CrazyEnchantments 插件支持
可自定义的奖励/经验值/进度条大小/消息提示

该插件为付费插件价格为 2.5USD 请到原贴购买

Pickaxe Upgrades 指令权限
插件指令
/pickaxeupgrades reload  - 重新加载配置文件
/pickaxeupgrades version  - 查看插件当前版本
/pickaxeupgrades dev - 查看插件开发人员名单
插件权限
pickaxeupgrades.* - 重新加载配置文件的权限
pickaxeupgrades.update - 升级插件的权限
Pickaxe Upgrades 安装教程
1.从正确的渠道获取插件
2.将获取到的插件放进服务端的 plugins 文件夹
2.重启服务器
Pickaxe Upgrades 配置
config.yml
  1. #是否开启自动更新?
  2. update checker: true
  3. #工具的配置文件
  4. item:
  5.   # '%level%' - 此工具的等级变量
  6.   # '%progressbar% - 此工具的进度条变量 (如果是进度条开启状态下)
  7.   # '%percentage%' - 此工具的百分比变量
  8.   # '%current%' - 此工具的当前经验值变量
  9.   # '%needed%' - 此工具的经验值变量
  10.   lore:
  11.   - '&7方块数: &b%blocksbroken%'
  12.   - '&7等级: &b%level% &7(&b%percentage%&7%)'
  13.   - '&7经验: &b%current%&7/&b%needed%'
  14.   - '&8[&f%progressbar%&8]'
  15.   options:
  16.   # 是否开启无法被破坏？
  17.     unbreakable: true
  18. blocks:
  19.   STONE: 1
  20. # 附魔是应该加载等级功能前面还是后面？ (设置为: True - 前面 False - 后面)
  21. Enchant Placement: True
  22. # 你可以在下面添加附魔类型，当稿子升级的时候会更新lore描述。
  23. # 附魔类型配置项 Mc附魔大全 https://hub.spigotmc.org/javadocs/spigot/org/bukkit/enchantments/Enchantment.html
  24. enchants:
  25. - "&r&7FORTUNE"
  26. - EFFICIENCY
  27. - EXPLOSIVE
  28. - UNBREAKING
  29. - "&r&7LUCKY KEYS"
  30. #进度条配置文件
  31. progress-bar:
  32.   settings:
  33.     #进度条数量
  34.     amount of bars: 10
  35.     symbol: "|"
  36.     #进度条颜色
  37.   colors:
  38.     #已有进度颜色
  39.     completed: "&a"
  40.     #未有进度颜色
  41.     incompleted: "&c"
  42. #等级配置文件
  43. levels:
  44.   settings:
  45.   #是否开启自定义消耗
  46.     custom-costs: false
  47.   #最大等级 (你的最大可达到的等级)
  48.     max-level: 5
  49.     cost: 500
  50.   #消耗配置  
  51.   costs:
  52.     1: 200
  53.     2: 300
  54.     3: 400
  55.     4: 500
  56.     5: 600
  57.     6: 700
  58.   #奖励配置
  59.   rewards:
  60.     '1':
  61.       commands:
  62.       # '[console] command' - 从控制台执行指令
  63.       # '[player] command' - 从玩家执行指令 如果玩家没权限 那么这个指令就不会生效
  64.       # '[message] message' - 发送一个消息给玩家
  65.       # '%player%' - 执行的玩家名字变量
  66.       - '[console] give %player% stone 1'
  67.       - '[message] &7Your pickaxe is now level &a1&7, well done!'
  68.       #附魔效果
  69.       enchants:
  70.         vanilla:
  71.           LOOT_BONUS_BLOCKS: 10
  72.           DIG_SPEED: 10
  73.           DURABILITY: 1
  74.     '2':
  75.       commands:
  76.       - '[console] give %player% stone 2'
  77.       - '[message] &7Your pickaxe is now level &a2&7, well done!'
