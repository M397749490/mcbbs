我的工厂是需要关联buildcraft的 我的工厂1.52需要buildcraft2.2.14

嗯，这是一个很好的MOD的一直都没人搬，我就把它搬过来吧~


注意！该MOD的默认能源是红石脉冲，要修改成buildcraft能源请到config文件夹下修改我的工厂的配置文件！
方法：
打开config文件夹，里面有个MineFactoryReloaded.cfg文件（你要先把MOD加载一遍才会有）然后用记事本打开
在general一项里面有个“# Set whether MFR will run off classic alternating redstone of BuildCraft's power system. Values other than "redstone" or "buildcraft" will cause the system to revert to redstone mode
PowerSystem=redstone”这句话，把这句话末尾的PowerSystem=redstone里的redstone改成buildcraft就行了改回去的话把buildcraft改成redstone就行了

介绍

合成及介绍：

MF钢锭
这个不用说太多吧，制作机器的必要素材


钢锤
又来改变机器方向的


播种机
这个机器是用来播种的，播种范围为3X3


收割机
可以收割3X3以内范围的，正面是有动画的那面


金坷垃机器
顾名思义，你要给他提供骨粉才会工作，正面是有动画的那面


传送带
把物品丢到上面他会传送到另一边，给他红石信号会停止工作，可以用钢锤改变方向


收集机
原帖没给名字我就给他起了个，这个并不是可以收集所有的东西，这个是用来收集传送带传送过来的东西的
注意在这个收集器附近放个箱子


放牧机
这个东西可以收集鸡、牛、羊、猪、鱿鱼和史莱姆身上的东西，范围是5X5，能收集到什么自己去研究吧，正面是有动画的那面
但是要注意，它每收集一次被收集的动物就会伤次血


宠物医院
可以治疗动物，但是你要提供它面包


自动钓鱼机
顾名思义可以帮你钓鱼，范围是3X3X3的水池


集水机
这个东西在下雨时可以收集雨水，可以用放水管运输，下雪时是收集雪球


粉碎机
这个东西可以粉碎它面前一格的任何东西
