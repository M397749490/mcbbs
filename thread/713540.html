                                                                  JoinHealth
1.8 - 1.12



特色/用途:
  • 可以让你设置玩家的血量上限
  • 可以让你设置VIP专属血量上限
  • 可以让你设置玩家的饥饿值上限
  • 可以让你设置VIP专属血量上限
  • 可以让你设置VIP永不损失血量/饥饿度




权限/指令:
本插件是在配置文件中配置
所以指令只有一条
指令 权限 介绍
/jh reload joinhealth.reload 重载插件
无 joinhealth.user
 玩家权限
无 joinhealth.vip vip权限
无 joinhealth.notify会被通告升级插件




配置文件:
请展开观看
  1. ##################################
  2. #       JoinHealth plugin        #
  3. #               by               #
  4. #          SpaicyGaming          #
  5. ##################################

  7. # Users = 普通玩家，添加权限 joinhealth.user
  8. # Vips = VIP,添加权限 joinhealth.vip

  10. #下面是修改血量和饱食度上限
  11. Join:
  12.   WelcomeMessage: true
  13.   SetFoodLevel:
  14.     active: true
  15.     UsersFoodLevel: 20
  16.     VipsFoodLevel: 20
  17.   SetHealth:
  18.     active: true
  19.     UsersHealthLevel: 20.0
  20.     VipsHealthLevel: 20.0

  22. #设置:第一行是设置VIP可以永远不掉饥饿(建议开启),第二行是可以不掉血(喜欢变态就开2333~)
  23. Utils:
  24.   DisableHungerLoss: true
  25.   DisableLifeLoss: true

  27. Messages:
  28.   prefix: '&6[&bJoinHealth&6]'
  29.   noPerms: '&c对不起，你没有足够的权限.'
  30.   
  31. ## 不要修改 ##
  32. ConfigVersion: 1.2
  33. CheckForUpdates: true
