MMCRules
跟玩家签订契约成为魔法少女
让第一次加入的玩家同意协议


简介
强制玩家阅读服务器协议
并在玩家接受协议后可进行游玩
可以减少处理玩家时产生的纠纷
授权搬运：

只是就像你注册时勾选的xxx协议
真的有这么难懂吗
不勾选无法进行游戏这样


命令
/rules 基础指令
/acceptrules 接受协议
/mmcrules settp 设置传送点
/mmcrules reset (player)重置某个玩家接受数据
（暂时不建议使用 可能报错）
/mmcrules resetall重置所有玩家接受数据
/mmcrules acceptfor (player)替某一玩家接受


权限
无须给玩家权限 默认可以直接使用
mmcrules.commands.settp - 设定玩家接受协议时的传送点
mmcrules.commands.reset - 强制玩家再一次阅读并接受
mmcrules.commands.resetall - 强制所有玩家阅读并再一次接受
mmcrules.commands.acceptfor - 为一个玩家接受协议

配置
已完整汉化
直接复制有可能导致格式问题
  1. messages {
  2.     accepted="&c你已成功接受协议。玩的开心！"
  3.     acceptedAlready="&c你已经接受过了协议"
  4.     cantBuild="&c你必须接受协议才能建造。输入&b/rules 并且电机&b/acceptrules&c!"
  5.     inform="&c你必须接受规则! 输入&b/rules 然后点击 &b/acceptrules&c!"
  6.     mustReadRules="&c你必须阅读规则然后接受它们。输入&b/rules!"
  7. }
  8. restrictions {
  9.     # 在阅读规则之前，是否阻止玩家放置和破坏？
  10.     blockBuildBeforeAccept=false
  11.     # 在阅读规则之前，是否阻止玩家发送命令?
  12.     blockCommandsBeforeAccept=false
  13.     # 在阅读规则之前，是否阻止玩家移动？?
  14.     blockMovementBeforeAccept=false
  15. }
  16. rules {
  17.     # 您想让玩家在登录后收到上述“通知”消息吗？
  18.     informOnLogin=true
  19.     # 下面的是需要接受列表
  20.     list=[
  21. “尊重他人。”，
  22. “合乎道德。”，
  23. “使用常识。”
  24. ]
  25.     onAccept {
  26.         # 要在玩家接受规则后运行的命令，这些命令由控制台发送。使用{player}代替玩家的ID
  27.         consoleCommands=[]
  28.         # 在玩家接受规则后运行的命令，这些命令由玩家发送
  29.         playerCommands=[]
  30.     }
  31.     # /rules页的标题
  32.     title=Rules
  33. }
  34. teleport {
  35.     # 是否希望在玩家接受规则后将其传送到指定位置？（使用/mmcrules settp设置）
  36.     afterAccept=false
  37.     coordinates {
  38.         pitch=0
  39.         posx=0
  40.         posy=0
  41.         posz=0
  42.         world=World
  43.         yaw=0
  44.     }
  45. }
