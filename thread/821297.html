教程1：创建一个队列

本教程中介绍如何创建一个简单的队列。
1.指令队列（通常用在菜单点击或NPC右键来匹配到一个队列）
  • 首先，需要给玩家一个小小的权限：bts.joinserver  ；（如果没有安装权限组插件，请安装权限组插件）
  • 传送门：
  • LuckPerms（推荐）
  • PermissionsEx
  • GroupManager


  • MCBBS还有很多相关帖子，只列举三个。
  • 然后，在菜单（这里以DeluxeMenus为例子）：
  • 看到left_click_commands或right_click_commands这里，往下写：
  - '[player] bts joinserver 你的队列名称'

  • 然后，玩家点击菜单或者右键NPC以后，就可以匹配到子服了

2.木牌队列（右键传送）
  • 首先，在你的服务器地图里的任意地方放置一个普通的木牌，然后在木牌里输入：
第一行：BTSigns
第二行：<你的队列名称>

  • 提示：木牌显示的 文字可以在messages.yml修改哦，下面有汉化。
  • 点击完成，你会发现，放置的木牌马上就变成了队列木牌。玩家只需要右键就可以加入设定的队列。
  • 具体配置如下：
  1. <font size="1"># 队列设置
  2. signs:

  4. # 标题(对于1.8服务端,建议使用英文作为标题）
  5.   第一个队列:

  7. # 名称
  8.     tag: 第一个队列

  10. # 类型（不建议修改）
  11.     type: filler

  13. # 性质
  14.     properties:

  16. # 随机匹配的子服
  17.       servers:
  18.       - queue1_server1
  19.       - queue1_server2
  20.   第二个队列:
  21.     tag: 第一个队列
  22.     type: filler
  23.     properties:
  24.       servers:
  25.       - queue2_server1
  26.       - queue2_server2</font>

教程2：设置禁止加入的MOTD

本教程中介绍如何设置禁止加入MOTD。
1.禁止加入子服的MOTD
  • 首先，你需要打开config.yml，看到以下代码：
  1. # 这里指MOTD设置
  2.   signs:
  3.   
  4. # 滚动标志（具体作用本人未测试）
  5.     scrollingSign: true
  6.    
  7. # 显示GUI左键点击（具体作用本人未测试）
  8.     showPlayersGUIonLeftClick: false
  9.    
  10. # 禁止加入的MOTD，其作用是让显示以下MOTD的子服来对BTS表示禁止加入。
  11.     offlineMotds:
  12.     - 满人
  13.     - 游戏中
  14.     - 停止
复制代码
  • 然后再offlineMotds下面写上禁止加入的MOTD（如果看懂了这里的操作，可以直接跳过下面内容）

2.在相应子服的MOTD设置（这里以BedwarsRel插件为例子）
  • 首先，打开子服目录的plugins/BedwarsRel（这里为BedwarsRel为例子，如有装该插件，那么根据提示来进行操作）
  • 打开插件根目录下的config.yml
  • 找到配置文件中的（如下所示，直接拿原插件的config，要汉化请到点我查看）：
  1. bungeecord:
  2.   enabled: false
  3.   hubserver: hub
  4.   endgame-in-lobby: false
  5.   full-restart: false
  6.   spigot-restart: false
  7.   motds:
  8.     lobby: "等待中"
  9.     running: "游戏中"
  10.     stopped: "停止"
  11.     full: "满人"
复制代码

  • 在启用MOTD的同时，你必须要开启enabled，将false改为true即可
  • 然后看到motds部分（我怕小白服主看不懂，所以，我就讲的更加通俗易懂些）：
  • lobby，指的是游戏没开始之前的等待阶段；顾名思义，去掉 | 下面的两行，改成lobby: "等待中..."
  • running，指的是，游戏已经开始运行，建议在BTS的禁止加入motd，格式要跟规定子服的一致；去 | 包括下面内容，改成running: "游戏中"
  • stopped，看这意思，就是指的是游戏停止，在BWR里面理解为地图加载出现错误，这时候，需要去排查加载出错的问题，改成stopped: "停止"
  • full，指的是满人的意思，这情况都出现在人数已经达到这个房间的MAX，因此，也建议设置为无法加入，改成full: "满人"

  1. # Layouts configuration file
  2. default:
  3.   - "&6木牌显示的第一行"
  4.   - "&6木牌显示的第二行"

  • 第二个:
  1. - "&f[&3&l我的标题&f]"

提示：可以用以下变量
  • {tag} - 队列名称
  • {current_server_filled_player_count} - 正在队列中的玩家（房间开始游戏，队列人数将自动初始化至0）
  • {total_player_count} - 正在队列中的玩家（使用这个变量会让木牌的这一行滚动起来，从而增加逼格）
