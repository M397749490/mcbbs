sponge里的经济插件往往比较简洁（也就是功能少类似于linux哲学，只做一个功能但是留下了接口可以供其他插件调用）
那么我们就需要一款插件对玩家的行为做出反馈。

背景：当XRAY模组变的越来越强大，我们想针对xray模组进行一定的限制。如果挖一个石头可以获得1元，挖一个铁矿会扣掉50-100，那么玩家就会决定去卖掉这些铁矿或正常挖矿去获得石头。这就是一个让大家普通挖矿而不去使用矿透模组的一个好机制。如果你的玩家继续使用矿透模组那么他们将不会得到任何好处。
还有就是如果你设置了一个强力的怪物，那么玩家杀死他就会得到金钱，这将有助于游戏内的经济平衡。




功能特色

你可以设置 实体（杀死）或者方块（破坏） 的价格 （并且支持价格区间扣钱加钱均可）

如果玩家没有足够的钱，他们就不可以破坏/杀死 方块/实体
你可以针对不同的方块或者实体设置不同的价格
还可以针对插件进行汉化（config/espaymoney/lang）

安装
直接拖入mods文件夹后重启服务器
然后打开config文件夹就可以看到一个espaymoney文件夹
可在里面配置



指令&权限

admin
  • espaymoney.reload
player  none
配置文本：
  • # en_US, zh_CN
  • lang=en_US
  • modules {
  • #是否启用挖矿经济功能
  • pay_mining = true,
  • #是否启用杀怪经济功能
  • pay_killing = true,
  • }
  • pay_mining {
  • #挖矿最少需要的钱数目
  • remind_money = 1000,
  • other_blocks = 30~40,
  • blocks {
  • #会产生影响的矿物注意前面的减号
  • "minecraft:sand" = -10~15,
  • "minecraft:wool" = -10~10,
  • "minecraft:wool" = -1,
  • "minecraft:stone" = 1,
  • "minecraft:stone[variant=granite]" = 2,
  • # fuzzy match
  • "@blue"=233
  • "@yellow"=-233
  • # auto added by fastedit mode
  • "minecraft:wool"="-1~1"
  • }
  • }

  • pay_killing {
  • remind_money = 500,
  • other_entity = 10~20,
  • entities {
  • #会产生影响的生物注意前面的减号，第一个是杀鸡减20，第二个是杀牛减5-15
  • "minecraft:chicken" = -20,
  • "minecraft:cow" = -5~15,
  • }
  • }
