Nemisys跨服

什么是Nemisys？他是类似于BungeeCord的一款核心，但是跨服方式不太类似。

准备工作
  • 下载主体核心 Nemisys
  • 下载子服核心 Nukkit
  • 下载互通插件 Synapse

Nemisys搭建
首先，创建一个新的文件夹，将已下载的 Nemisys 导入，创建一个.txt文件，输入
  1. @echo off
  2. java -jar Nemisys.jar
  3. pause
复制代码
Nemisys.jar 是你的核心名称 可能有不同
然后保存将尾缀修改为 .bat 启动服务器
成功开服后就是这样了


现在要做的是打开 server.properties
编辑 synapse-ip 和 synapse-port password （可以不编辑） 使用原版
若不编辑则复制端口和密码


子服搭建
在创建一个新的文件夹，导入已下载的 Nukkit
同样制作一个 .bat 启动文件
将 synapse 导入 plugins 是 plugins文件夹 不是核心
导入后启动服务器，服务器应该会自动关闭，因为配置没有调整好
我们启动服务器后 打开 plugins/SynapseAPI/config.yml 开始配置
修改 server-port 为 Nemisys/server.properties 中的 synapse-port 端口
例如我这里是 10305 所以修改为 10305
然后修改密码 要与 server.properties 的 password 对应


搭建成功


游戏截图


教程结语
  • 如果觉得有点单调可以加些插件，在 NukkitX 官网
  • 标语可以在 server.properties 中修改
  • 配置文件有部分不懂的可以查阅 NukkitX/Nemisys Wiki
