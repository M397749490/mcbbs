空岛的话可以自己创建
创建世界的时候选超平坦，然后把所有层都删掉，记得要开作弊模式
然后用 setblock 设置方块
1.13 以前：
  1. /setblock 0 64 0 1
复制代码

1.13 以后：
  1. /setblock 0 64 0 minecraft:stone
复制代码


之后传送到你创建的方块上面
  1. /tp 0 66 0
复制代码


然后就可以自己做空岛地图了。

做完之后可以用 MCEdit 之类的软件修改世界的游戏模式、作弊模式等属性，之后就成为了独立的成品地图。

别忘了玩的时候注意备份。
