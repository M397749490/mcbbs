AutoHub

大厅插件

AutoHub is a small but useful plugin. It can be used to send players to a location when they join the server, add a /hub command that either teleports the user to the hub or connects them to a different server (BungeeCord required) depending on how you configure the plugin, and it can send a player a message when they join the server.
   这个大厅插件，是一个小而有用的插件
他可以用在BC服务端里····························





Config.yml:
  1. #这个是大厅的地址
  2. hub:
  3.   x: 0
  4.   y: 64
  5.   z: 0
  6.   world: world
  7.   
  8. #如果是BungeeCord你就打开这一项，如果不是，请关闭
  9. #如果设置错误，插件就无法正常运行
  10. bungeecord: false

  12. #如果你的服务器是bungeecord，请设置大厅服的名字
  13. #示例：bungeeserver: 子服名
  14. bungeeserver:

  16. #是否开启/hub命令
  17. hubcommand: true

  19. #如果传送了给玩家发送的消息
  20. hubmessage: You have been teleported to the lobby!

  22. #是否让玩家传送到，设置的大厅位置
  23. tponjoin: true

  25. #加入消息
  26. joinmessage: Welcome!




复制代码




                                            权限:
         autohub.set  ——设置权限——默认：OP
         autohub.tphub ——传送权限——默认所有人   
         autohub.bypass ——（不知道）——默认：OP
                                       
                                          命令:
         /sethub <x> <y> <z> <world> ——设置大厅
        /sethub <x> <y> <z> ——设置大厅(在你当前所处的世界)
       /sethub ——设置大厅（在你当前所处的位置）
      /hub ——传送大厅
