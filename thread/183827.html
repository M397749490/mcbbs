标题: Minecraft 13w41b 发布

每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。
适用于正式版的MOD不兼容预览版，而且大多数MOD都不提供对每周快照的支持。
Minecraft 1.7（世界生成器更新）仍未发布，13w41b为其第11个预览版。
注意！旧版启动器已经无法启动Minecraft 1.6以及1.7快照，请看下面的说明。
本版新闻除非特别说明，否则均允许转载，但转载必须注明本帖地址。

快照13w41b发布，修复如下漏洞：

  • Bug [MC-14865] – 地毯不燃
  • Bug [MC-29588] –  Hopper: java.lang.NullPointerException – 无效的生物群系id
  • Bug [MC-30811] – TellRaw – Tab Complete
  • Bug [MC-32880] – 掉落方块为技术性或无效方块时崩溃
  • Bug [MC-34641] – 游戏暂停功能不正常
  • Bug [MC-34642] – 方块名称"White Stained Glass Pane Pane（白色染色玻璃板板）"
  • Bug [MC-34645] – 最大渲染距离为8区块
  • Bug [MC-34647] – Hopper: java.lang.NullPointerException / 选择资源包时崩溃
  • Bug [MC-34650] – Hopper: java.lang.NullPointerException / 实体碰撞
  • Bug [MC-34676] – 铁栅栏渲染错误
  • Bug [MC-34679] – 染色玻璃板合成只能得到6个
  • Bug [MC-34705] – 服务器登录的NullPointerException

PS: 服主在最新快照的服务器文件夹下建立文件名为server-icon.png的64x64图片，可以作为服务器图标显示在玩家客户端的服务器列表中。

官方新版（正版）启动器下载地址：
Windows: https://s3.amazonaws.com/Minecra ... ncher/Minecraft.exe
Mac OS: https://s3.amazonaws.com/Minecra ... ncher/Minecraft.dmg
全平台: https://s3.amazonaws.com/Minecra ... ncher/Minecraft.jar

自Minecraft 1.7快照开始，Minecraft中文论坛不再提供快照客户端的下载。请各位玩家使用启动器自行下载体验。
对于正版用户，可以直接接收到新版官方启动器的快照推送。前提是：
  • Profile中的Version Selection勾选Enable experimental development versions ("snapshots")一项
  • Use version选择“Snapshot 版本号”或“Use latest version”
对于非正版用户，前提是：
  • 你使用的启动器能够在线读取官方的版本列表，并具备下载功能。具体细节请询问你的启动器作者。

服务端：
  • jar: https://s3.amazonaws.com/Minecraft.Download/versions/13w41b/minecraft_server.13w41b.jar
  • Windows EXE: https://s3.amazonaws.com/Minecraft.Download/versions/13w41b/minecraft_server.13w41b.exe
