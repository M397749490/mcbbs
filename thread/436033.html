第一个问题是没有修改build为true,新建组都是默认关闭build权限的;
输入mangaddv vip build true
一般都会继承builder组的权限: mangaddi vip builder
第二个问题因为back是继承过来的,没有直接的权限节点,需要使用负权限节点;
输入manuaddp default -essentials.back
