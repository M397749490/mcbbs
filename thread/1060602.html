想搞一把能挖基岩的稿子，只用命令方块的话，要怎么实现呢
游戏版本 1.15.2 java 版
作者: WYL0zhu    时间: 2020-6-12 20:15
本帖最后由 WYL0zhu 于 2020-6-12 21:31 编辑

建议先了解命令的基础知识：
https://minecraft-zh.gamepedia.com/命令
https://minecraft-zh.gamepedia.com/命令方块

先在聊天栏里输入命令：
  1. /scoreboard objectives add used_carrot minecraft.used:minecraft.carrot_on_a_stick
复制代码
然后摆一个循环命令方块（需要保持开启，不受制约），里面写：
  1. execute as @a[scores={used_carrot=1..}] run scoreboard players reset @s used_carrot
复制代码
循环命令方块输出端接出一个连锁命令方块（需要条件制约，保持开启），里面写：
  1. execute as @a[nbt={SelectedItem:{tag:{你自定义镐子的nbt}}}] at @s run fill ~-4 ~-4 ~-4 ~4 ~4 ~4 minecraft:air replace minecraft:bedrock
复制代码

其中的 你自定义镐子的nbt 应替换为对应的 你自定义镐子的nbt。
然后就好了。进入游戏测试，发现使用带对应nbt的胡萝卜钓竿右键会将玩家周围9*9*9范围内的基岩替换为空气。
