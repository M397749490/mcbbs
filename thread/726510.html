BossShop
强大的GUI菜单/商店插件




简 介
O V E R V I E W


BossShop是一款支持自定义GUI菜单/商店的万用插件，你可以制作自己的服务器
菜单，让玩家通过点击界面图标来触发各种各样的效果。告别复杂的指令，省去其他
插件冗余的环节，使用便捷、一步到位，只要你能想到，BossShop就做得到！

本贴作为本插件免费版BossShop和付费版BossShopPro的官方授权搬运帖，
关于两款插件的主体、附加插件和使用教程都将于此进行更新，如有需要也可在本贴
下方留言向我咨询相关问题，也可移步官方发布贴反馈插件漏洞和难以解决的问题。

功 能
F E A T U R E S


　　注：红色字体为本插件付费版BossShopPro的功能。

  • 玩家可使用木牌、指令或手持特定物品左/右键来打开菜单
  • 支持多种点击图标触发的效果：
    • 给予物品
    • 给予金钱（需要前置插件Vault，点击此处直接下载最新版）
    • 给予经验
    • 给予权限（需要前置插件Vault，点击此处直接下载最新版）
    • 给予点券（支持PlayerPoints、CommandPoints、Enjin Points、PointsAPI、TokenEnchant、Jobs、VotingPlugin、Kingdoms）
    • 给予最大数量某物品（填充玩家背包）
    • 触发延时指令（需要前置插件ScheduledCommands，点击此处直接下载最新版）
    • 使控制台运行命令（支持多个命令）
    • 使玩家运行命令（支持多个命令）
    • 使玩家以管理员身份运行命令（支持多个命令）
    • 使BungeeCord服务端运行命令（支持多个命令）
    • 使玩家手持物品附魔
    • 跳转到另一个菜单
    • 将玩家传送到其他服务器（BungeeCord和Lilypad服务器专用）
    • 跳转到玩家商店的其他页
    • 不触发任何效果
  • 支持多种触发条件：
    • 支付物品
    • 支付经验
    • 支付金钱
    • 支付点数
    • 支付背包内全部某物品
    • 无条件
  • 自定义菜单图标属性：
    • ID
    • 名称（支持多种变量，点击此处查看BossShop变量，点击此处查看BossShopPro变量）
    • 描述（支持多种变量，点击此处查看BossShop变量，点击此处查看BossShopPro变量，如果过长可自动换行）
    • 数量
    • 数据值
    • 附魔效果
    • 药水效果（药水专用）
    • 颜色（皮革装专用）
    • 头颅材质（头颅专用，支持自定义材质和玩家头颅材质）
    • 书的标题、作者及内容（成书专用）
    • 怪物种类（刷怪笼及刷怪蛋专用）
  • 自定义界面属性：
    • 标题（支持多种变量）
    • 行数（原则上支持无限行，但出于美观原因建议在6行以内）
    • 图标位置
    • 刷新延时
  • 图标连点保护系统，防止玩家通过恶意连续点击图标卡服（可自定义多少秒内最多点击图标多少次）
  • 无延时加载，服务器启动后就可以开始使用菜单
  • 针对不同玩家设置不同的价格（折扣或加价，例如对赞助者折扣，对普通玩家加价）
  • 服务器ping信息展示（BungeeCord服务器专用，点击此处查看使用教程）：
    • 某个服务器的玩家数量
    • 某个服务器的MOTD
    • 玩家总数
    • 延迟
  • 提示信息，例如玩家金钱不足时出现在聊天区的提示
  • 定时记录玩家操作行为（可选）
  • 自动更新插件（可选）
  • 支持PlaceHolderAPI
  • 当商店物品超出时，自动增加页数（点击此处查看使用教程）
  • 支持多种音效（例如打开菜单的音效、点击图标的音效、金钱不足时的音效）
  • 支持鼠标左键、鼠标右键、鼠标中键、shift+鼠标左键、shift+鼠标右键点击同一图标触发不同的效果（点击此处查看使用教程）
  • 显示数字缩略形式（如将『14027』显示为『14k』）
  • 自动使售出物品显示在商店下一空位
  • 为不同菜单绑定不同指令，使玩家通过不同指令打开不同菜单（支持为统一菜单绑定多条指令）
  • 针对不同情况改变菜单图标（例如金钱足够时显示『可购买』图标，不够时显示『不可购买』图标，点击此处查看使用教程）：
    • 金钱
    • 点券
    • 生命值
    • 饥饿值
    • 物品数量
    • 权限
    • 权限组
    • 玩家坐标
    • 世界时间
    • 玩家数量
    • 真实年、月、日、小时、分钟、秒、毫秒


指 令
C O M M A N D S


　　注：红色字体为本插件付费版BossShopPro的指令。

  • /bs - 打开主菜单
  • /bs <shop> - 打开指定菜单
  • /bs open <shop> <playername> - 为某玩家打开指定菜单
  • /bs close <playername> - 为某玩家关闭菜单
  • /bs reload - 重载插件全部内容
  • /bs check - 检视插件
  • /shop read - 查看主手物品信息
  • 命令别名（可替换/bs部分）：
    • /shop
    • /BossShop
  • 你可以自行增加或删除命令别名


教 程
T U T O R I A L


　BossShop篇：

　　　BossShop的组成如下，其中黄色代表文件夹，蓝色代表可编辑的.yml文件，且shops文件夹下的菜单
　　　有两种分布方式：

第一种：所有菜单直接存放于shops文件夹下

第二种：在shops文件夹下建立子文件夹，并将菜单存放于其中，适合为大量菜单分类，
使用该种分布方式前必须将config.yml中的SearchSubfoldersForShops项设置为true

　　　　·  BossShop的组成：
　　　　　　·  config.yml - 总体设置文件
　　　　　　·  messages.yml - 插件提示语文件
　　　　　　·  shops - 存放菜单的文件夹

　　　　一、config.yml配置教程

简体中文版
# BossShop
# 作者：Felix Neubauer
# 请移步右侧网站查看更多相关信息：http://dev.bukkit.org/bukkit-plugins/bossshop/pages/configuration/
#
# 帮助链接：
#
# BossShop插件发布页面（旧版）：
# http://dev.bukkit.org/bukkit-plugins/bossshop/
#
# 所有版本下载链接：
# http://dev.bukkit.org/bukkit-plugins/bossshop/files/
#
# 嘿！
# 你开始使用BossShop了吗？太棒了。
# 相信我：配置起来很容易。
#
# 你可以通过最经典（无聊且不方便）的方式来编辑config文件，
# 或者通过"老板"的方式来进行配置：使用"BossShopConfigure"（一个可以让你点几下鼠标就能轻轻松松配置插件的小工具）。
# 你可以在这里下载到BossShopConfigure：http://dev.bukkit.org/bukkit-plugins/bossshop/
#
#
#
#
#
# EnableSigns:
# 如果设置为'false'，本插件将停用。
EnableSigns: true
#
#
# MainShop:
# 这里填写主菜单名称。当有人使用指令'/bossshop'是，这个菜单就会被打开。其他菜单可以供过指令'/bossshop <菜单名>'打开。
# 并且，所有菜单都可以通过木牌打开（前提是该功能已开启），或者通过点击特定物品打开（如果你安装了'GuiShopManager'）。
MainShop: Menu
#
#
# AdvancedSecurity:
# 当这项被开启时，在打开菜单的情况下玩家无法移动背包内的物品。这个功能可以100%保证菜单安全。
# 其实在一般情况下都不会刷物品，但在Cauldron-1.7服务器中存在这个bug，开启这个选项可以修复这个问题。
AdvancedSecurity: false
#
#
# HideItemsPlayersDoNotHavePermissionsFor:
# 当启用该项时，没有权限的玩家将看不到图标。你可以凭此做一些很酷的功能，比如升级系统。
# 你可以把多个图标放在同一槽，并隐藏不想启用的图标。比如制作升级系统时，你可以隐藏旧的升级图标，只显示下一个升级图标。
HideItemsPlayersDoNotHavePermissionsFor: false
#
#
# CanPlayersSellItemsWithGreaterEnchants:
# 当启用该项功能时，玩家可以向商店出售附魔等级更高的道具。这样可以帮助玩家处理附魔废品。
# 但这也可能导致玩家手误，得不偿失。
CanPlayersSellItemsWithGreaterEnchants: false
#
#
# EnableTransactionLog:
# 当启用该项时，所有进程都会被记录在文档中。
EnableTransactionLog: false
#
#
# SearchSubfoldersForShops:
# 当启用该项时，插件将从'shops'目录下的子文件夹中读取菜单文件。开启这个功能可以很方便地为大量菜单分类。
SearchSubfoldersForShops: false
#
#
# ServerPingingDelay:
# 服务器Ping延时，以游戏刻为单位（20游戏刻=1秒）。
ServerPingingDelay: 20
#
#
# AllowUnsafeEnchantments:
# 当启用该项时，插件将允许等级超常的附魔。
AllowUnsafeEnchantments: false
#
#
# DisableUpdateNotifications:
# 当关闭该项时，你不会再收到任何更新提示。
DisableUpdateNotifications: false
#
#
# MultiplierGroups:
# 你可以在此设置价格倍率。
# 当启用该项时，拥有相关权限的玩家将受到相应的加价或折扣。
# 格式如右侧所示：<权限>:<种类>:<倍率>。
# <权限>：该项完全自定义。如果你想让整个权限组的玩家都受到加价或折扣，给予权限组该权限即可。
# <种类>：此处填写加价种类。此处选填：Money、Points,、Exp。
# <倍率>：实际价格=原价×倍率。
# 玩家可同时拥有不同的"MultiplierGroups"。
MultiplierGroups:
  Enabled: false
  List:
  - BossShop.PriceMultiplier.Points:points:0.75
  - BossShop.PriceMultiplier.Money:money:0.5
  - BossShop.PriceMultiplier.MoneyNegative:money:2.0
  - BossShop.PriceMultiplier.Exp:exp:0.8
#
#
# PointsPlugin:
# 该项只在服务器安装有点券插件的情况下有用。
# 这里填写点券插件种类。BossShop将和指定的点券插件相关联。
# 当你安装有多款点券插件时，只能在下面填写一个点券插件的名字，BossShop将选择它们作为自己的点券系统。
# 此处选填：'PlayerPoints', 'CommandPoints', 'EnjinMinecraftPlugin'/'Enjin', 'PointsAPI', 'Kingdoms', 'Jobs', 'TokenEnchant'、'VotingPlugin'。
#
PointsPlugin: auto-detect

　　　　三、菜单配置教程

格式说明
此处以制作一个简易菜单为例进行讲解，不如先来看看做好的样子吧：
ShopName: menu  #  这里填写菜单名，请注意菜单名和文件名无关。
DisplayName: '&2&l简易菜单'  #  这里填写GUI菜单标题，它将显示于菜单顶部。
signs:
  text: '[menu]'  #  这里填写木牌菜单标题，在木牌首行填写相同文字后，拥有相关权限的玩家通过木牌就能打开菜单。
  NeedPermissionToCreateSign: true  #  玩家是否需要权限才能使用木牌。
shop:
  icon1:  #  图标名称，可任意填写，但必须保证独一无二。
    RewardType: PlayerCommands  #  点击图标后触发的内容种类，可选填：Items、Money、Permissions、Commands、PlayerCommands、Points、Enchantments、Shop、BungeeCordServer、LilypadServer、Nothing。各项的意义请见本贴下方Wiki解释。
    Reward:  #  该项目下填写触发的具体内容，具体情况请按具体格式填写，详情请参照本贴下方Wiki解释。
    - spawn

常见问题集锦
　　插件重载时出现错误是怎么回事？
  • 请检查插件版本与自己的服务器版本是否符合；
  • 请检查菜单图标名称、描述中是否出现英文冒号:，请使用变量[colon]来代替冒号，否则会出现错误；
