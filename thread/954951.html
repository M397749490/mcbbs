AdBlockPlus

简简单单阻挡广告网站的好帮手







插件介绍

Plugin Introduction



这个插件通过识别聊天栏中一些带域名的关键词进行广告屏蔽

作者将会在未来提供语言文件便于汉化！







插件指令与权限

Plugin Command and Permission


这个插件本身没有重载指令，但他有绕过广告拦截的一个权限

adblock.bypass - 允许你发送网站而不被屏蔽

AdblockPlus:
  Enabled: true
  # 是否启用本插件
  Bypass: true
  # 启用adblock.bypass权限
  LockPlayer: true
  # 是否惩罚广告的玩家
  LockForMinutes: 1
  # 禁言玩家的时长，单位是分钟
  InformTeam: true
  # 当某玩家尝试打广告时发出公告
  Block:
    # 触发本插件的关键词
    - http
    - https
    - www
    - www.
    - .de
    - .com
