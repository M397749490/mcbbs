McSign 插件是一个简单便捷的签到插件
支持Mysql及PlaceholderAPI变量
关于 McSign 未来计划
1.Mysql支持 √ 已实现
2.如果有其他想法可以私信与我反馈
McSign 图示 与 视频

McSign 指令 与 变量
/ms reload -重载插件配置
/ms sign -签到

%ms_size% 签到天数
%ms_time% 上次签到时间
McSign 配置
  1. SQL:
  2.   Enabled: false
  3.   DataBaseName: 'null'
  4.   Host: 127.0.0.1
  5.   Port: 3306
  6.   User: root
  7.   Password: password
  8. TimeFormat: "20yy年MM月dd日"
  9. SignCommand:
  10. - '[CONSOLE]give %player% 264 5' #以CONSOLE的身份给玩家发送该命令
  11. - "[MESSAGE]&7[&d签到&7] &e恭喜你成功领取了今日签到奖励!" #签到成功后提示
