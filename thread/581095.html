- -essentials.build.craft.

这条兼添加进去权限组即可禁止合成

直接添加这个指令没用的
/mangaddv builder build false  
/mangaddp builder essentials.build.*  
上面两个指令之后
  1.     essentials.build.destroy.*     破坏
  2.     essentials.build.drop.*         丢弃
  3.     essentials.build.craft.*     交互
  4.     essentials.build.pickup.*       捡拾
  5.     essentials.build.place.*         放置
  6.     essentials.build.use.*           使用
复制代码

还有一个问题
假如你服务器是MOD服 有其他合成台
那么MOD中的其他合成台将不能限制
