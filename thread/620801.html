比如玩家执行指令pershout后，临时给予玩家 essentials.chat.shout
然后把sender转为player 控制玩家喊话。
（不要暂时设置op，那样聊天会红名，虽然也可以修改opid颜色 不过不是个好法）
具体代码如下
  1. if (cmd.getName().equalsIgnoreCase("pershout"))
  2. {
  3. if (!(sender instanceof Player)) {
  4. sender.sendMessage(ChatColor.RED + "后台禁止使用此指令！");
  5. return true;
  6. }
  7. Player p = (Player)sender;
  8. p.chat('!' + ChatColor.translateAlternateColorCodes('&', arrayToString(args, 0, false)));
  9. return true;
  10. }
