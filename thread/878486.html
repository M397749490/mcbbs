点进去..输入以下代码：
  1. java -Xms1024M -Xmx1024M -jar 核心名称.jar
复制代码
java 指的是Java的位置，你也可以替换成自己Java的路径..
默认是
C:\Program Files\Java\jre1.8.0_211\bin\javaw.exe

-Xms 指的是初始内存 | 后面的数字可以随意更改，一般看内存情况而定..
譬如，2G的家用电脑，那你就搞个-Xms1024M 1024M = 1G
-Xmx 指的是最大内存 | 后面的数字也可以更改，一般也是跟Xms相同..
