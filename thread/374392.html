大家有没有因为扩展而困扰过呀，今天，我要教大家一些比较常用的扩展名

txt
文档扩展名，可在里面写字。


bat
启动扩展名，一般用来搞服务器。

exe
启动扩展名，通常启动游戏，软件之类的。

png
图片文件，有时候windows不能处理。

wav
声音文件，可以更换成其他播放器。

dll
不名

class
java的一种扩展名

java
java的一种扩展名。

zip
压缩包

rar
压缩包

jar
java的一种扩展名，一般用于做mod

bs2
basic stamp的文档

html
浏览器的扩展名
注意
win8需要放进压缩包，别的版本不清楚
