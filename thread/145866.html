FAQ:
Q:什么是MCPC+服务端?
A:MCPC+服务端简单的说就是安装了Forge的水桶服务端 可安装Mod和插件!
Q:我可以装任何Mod到MCPC+服务端吗?
A:理论上是可以的!

MCPC+服务端启动Bat设置:(服务端是Jar文件 所以你需要JAVA去启动它 腐竹普遍都采用这种新建一个这种Bat文件来启动服务端)
  1. @ECHO OFF
  2. java -Xmx1024M -Xms1024M -jar mcpc-plus.jar
  3. PAUSE
复制代码
  • 其中"mcpc-plus.jar"是下载到的服务端文件名 要根据你下载到的服务端文件名更改
  • 其中-Xmx1024M和-Xms1024M是服务端调用的内存大小 1G=1024M 如果你的是32位JAVA 那么最大只能设置1024M
运行所需Libraries(数据库)文件下载地址:
Libraries(数据库)文件是Forge运行的必备文件
第一次启动MCPC+会自动下载它(*注) 而部分地区的网络把这个下载链接给墙了 所以这是给下载速度慢或无法下载的人下载的
用法:下载后将zip文件内的文件夹解压到与服务端jar文件同一目录下

*注:1.7.2的MCPC+服务端不会再自动下载Libraries文件 具体查看http://www.mcbbs.net/thread-217712-1-1.html

Mod安装教程:
1:打开你的服务端文件夹
2:找到mods文件夹
3.将你下载的Mod的zip或jar文件放入mods文件夹内（如果是只需要安装在客户端的mod就不用了）
