image.png (126.4 KB, 下载次数: 0)

下载附件

2019-8-31 12:09 上传
执行stop
打开config.yml
找到
# 这是基岩版连接的地址(可不改动)
udp_bind_ip: '0.0.0.0'
# 连接端口
udp_bind_port: 19132





# (Java Minecraft 服务器地址)
# Notice: 不要用TAB
remote_server_addr: 'mc.hypixel.net'
remote_server_port: 25565



# 是否pingPC服务器的人数并在PE服务器上显示
ping_passthrough: false



# 最大玩家
max_players: -1


设置完后保存
开启dragonproxy即可连接
