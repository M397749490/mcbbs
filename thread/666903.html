授权搬运





介绍

这个插件可以做到在基础的全息Holographic上拓展成为动态全息！
可以做到滚动，闪烁，闪亮滑动等动画功能
好消息是它还支持PlaceholderAPI！

你只要装好前置，并且把这个插件装进plugins文件，可在文件配置编写动画，重载使用

特色

√ 轻量级(30KB)
√ 简单配置
√ 多个可自定义动画
√ 支持全彩闪烁动态
√ 支持特殊符号
√ 支持PlaceholderAPI变量符
√ 更多特色...

图片







命令

/hde reload #重新加载
/hde list      #列出可用的动态标题

如何使用

使用之前请先看下面下载的文件配置

创建一个动态全息示范（注意文件配置\plugins\HolographicExtension\animations.yml里面的字，你就会看懂）
/hd create test {ext:example}
/hd create testa {ext:b}

当然也可以这样用（在已创建的全息添加动态标题）
/hd addline test {ext:a}
