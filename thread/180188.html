今天第一次发布一个整合包，MOD比较少，一共7个MOD。

MOD包含：
Minecraft语言输入修复补丁
小地图
TMI内置修改器
内置合成表
R键整理
id修复
枪械Mod


枪械Mod安的包有：
1、简单零件包
2、怀旧时光包
3、第二次世界大战包
4、现代武器包
5、彩弹枪包
6、黑色行动2包
7、战地3包第二代



没有安的枪械Mod的包有：
1、现代战争3包
2、现代攻击武器包
3、多重战争扩展
4、荷兰武器包
5、科幻包
6、二战+包
7、现代武器+包
8、Dayz包
9、旧美国西部包
10、汉克勒&寇奇内容包
因为找不到这些包的1.6.2版本所以就不安了



Flan's MOD操作：（操作说明：摘自原帖！）
团队控制
G : 打开团队选择菜单
H : 打开团队得分菜单飞机或载具控制
（这些设置可以在游戏选项里更改）
E : 离开飞机或载具
R : 飞机或载具的加载物品栏
飞机（简单控制模式）与载具
W : 加速
S : 减速/后退
A : 左转
D : 右转
左Ctrl : 机枪射击
V : 扔炸弹l
空格：爬升（仅限飞机）
左Shift : 下降（仅限飞机）
C : 切换控制模式（仅限飞机）
飞机（鼠标控制方法）
其它控制与上面相同，除了爬升与下降：
鼠标上/下：
爬升/下降
鼠标左/右：
左转/右转 左键：
机枪 右键：炸弹
