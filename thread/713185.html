作者: 白羊羊    时间: 2017-7-30 17:48
目录plugins\GroupManager\worlds\world
找到groups.yml编辑并修改为
groups:
  Default:
    default: true
    permissions:
    - -bukkit.command.kill
    inheritance:
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    info:
      prefix: '&e'
      build: true
      suffix: ''
即可
