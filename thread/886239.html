AutoCommands
由 NLBLacky 提供支持

它可以做什么？
你需要在服务器启动后执行指定的命令吗？或者你想在启动xx分钟后执行一个命令？或者你想让他每隔几分钟就执行一个命令？这款插件可以做到这一些！

我该如何使用它？
  • 将插件放置于 mods 文件夹或 mods\plugins 文件夹
  • 启动服务器即可

配置文件：
默认情况下所有功能模块都是关闭状态，你需要自行开启
配置文件位置：根目录/config/autocommands/autocommands.conf
  1. delay {
  2.     # 该模块用于在开服后延迟指定时间（分钟）再执行命令
  3.     enabled=false
  4.     # 指定时间，在执行命令前需要等多少分钟
  5.     delay-in-minutes=2
  6.     # 以下命令将在延迟后执行
  7.     delayed-commands=[
  8.       "",
  9.       ""
  10.     ]
  11. }
  12. interval {
  13.     # 该模块用于每隔一段时间（分钟）后执行命令
  14.     enabled=false
  15.     # 以下命令将在间隔后执行
  16.     interval-commands=[
  17.       "",
  18.       ""
  19.     ]
  20.     # 指定时间，自动执行命令的频率
  21.     interval-in-minutes=1
  22. }
  23. startup {
  24.     # 该模块将在服务器启动完成时执行命令
  25.     enabled=false
  26.     # 以下命令将在服务器启动完成后执行
  27.     startup-commands=[
  28.       "",
  29.       ""
  30.     ]
  31. }
复制代码
可以在配置文件里任意加减要执行的命令。配置文件格式为 hocon ，若格式错误插件会报错并无法运行。
