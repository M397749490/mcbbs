允许玩家创建一些地牢以进行探险
生成/删除速度非常快
结构很复杂，路痴带好火把
丰富的配置文件，地牢结构/怪物/物品包括一切行为都可自行配置
地牢结构是不可破坏的。
地牢中具有很多机关和秘密的门，当你没走到终点，你肯定是眼力不好= =
进入地牢时会有恐怖的音乐

命令：

cat = catacombs
"[]"中为选填内容，"<>"是必填项目
/cat 命令列表
/cat plan <名称> <深度> [半径] 查看是否能够建立地牢并进行规划
/cat unplan <名称>
/cat build <名称> 开始构建一个规划完毕的地牢
/cat scatter <名称> <深度> <半径> <距离你的格数> 用于移动一个已经规划完毕的地牢并进行构建。
/cat time [名称] <时间> 设置每过多久重置地牢，时间用D表示日，H表示小时，M表示分钟，S表示秒，例如/cat time dungeon1 5h30m表示每过5小时30分重置地牢。时间中允许随机范围，例如/cat time dungeon1 5h30m
/cat when [名称] 让你知道什么时候会重置地牢，返回的时间格式同/cat time命令
/cat delete <名称> 删除地牢。将地牢用普通石头填充并取消保护。其中的玩家将会被传送走。
/cat reset [名称] 重置地牢。传送走其中玩家，移除怪物和火把，重新装填箱子。
/cat resetall 重置所有世界的所有地牢
/cat unprot <名称> 取消地牢的保护并忘记这个地牢
/cat suspend [名称] 暂停地牢的保护和怪物诞生并打开灯光，以便你对它进行更改
/cat enable [名称] 使地牢恢复正常，和暂停指令/cat suspend相对
/cat recall 传送到地牢顶部
/cat goto [名称] 传送到地牢顶部
/cat end [名称] 传送到地牢最终箱子
/cat which 告诉你当前所在或所看到的地牢的名称
/cat ? 告诉你当前所在或所看到的地牢的名称
/cat style 查看当前地牢的风格(在config.yml文件中可以增减或删改风格)
/cat style <风格> 更改当前地牢的风格(重置或重启生效)
/cat list 地牢列表
/cat gold 查看金钱
/cat iron [名称] 将地牢中所有木门更换为铁门
/cat ironall 将所有地牢中的木门更换为铁门

配置-全局：
  1. Admin.emptyChestonDelete - 地牢清除时清除其中所有箱子。为False时保留小屋物品。
  2. Admin.SecretDoorOnlyInDungeon - 秘密门只会出现在地牢而不是全地图
  3. Admin.GoldOff - 为True时玩家猎杀怪物不会有奖励
  4. Admin.ProtectSpawners - 为False时玩家可以破坏刷怪箱
  5. Admin.RespawnInHut - 为True时玩家在地牢中死去后会重生在地牢顶部的小屋
  6. Admin.NoPvPInDungeon - 为True时地牢中禁止PvP
  7. Admin.NoArmourInDungeon - 设置为True将禁止玩家穿着盔甲进入地牢
  8. Admin.MobsSpawnOnlyUnderground - 禁止怪物在世界表面(没有遮挡的区域)生成
  9. Admin.MobsSpawnOnlyInDungeons - 怪物只在地牢中生成
  10. Admin.Economy - 使用什么经济插件
  11. Admin.ClickIronDoor - 玩家可以通过右击或左击打开铁门
  12. Admin.Death.GearCost - 玩家死亡需要支付多少钱来重生。如果金钱不足物品会掉落在地上。
  13. Admin.Death.KeepGear - 玩家死亡不掉落装备
  14. Admin.Death.ExpKept - 玩家死亡后会剩下百分之几的经验值。最大1.0
  15. Admin.BannedCommands - 玩家在地牢中不允许使用什么命令
  16. Admin.Breakable - 玩家在地牢中允许打破什么东西
  17. Admin.Placeable - 玩家在地牢中允许放置什么东西
  18. Admin.Patches.DoorFixDone - 设置为False来强制修复所有门
  19. Admin.Patches.SecretDoorFixDone - 设置为False来强制修复所有秘密门
  20. Admin.MobDropReductionPct - 怪物掉落物品的几率
  21. Admin.NoTeleportIn - 不能使用传送命令进入地牢
  22. Admin.NoTeleportOut - 不能使用传送命令离开地牢

配置-风格：

自带的风格只有catacomb，仿照catacomb:撰写并更改个名称，就是新风格了
torch:20:1-10表示有20%的几率获得1-10支火把
/3表示数据偏移，比如potion/3是火焰保护药水
  1. Room.Max - 最大房间尺寸
  2. Room.Min - 最小房间尺寸
  3. Room.Clutter.TrapPct - 房间里出现陷阱的几率
  4. Room.Clutter.SandPct - 房间被灵魂沙覆盖的几率
  5. Room.Clutter.ChestPct - 房间里出现小箱子的几率
  6. Room.Clutter.SpawnerPct - 房间里出现刷怪箱的几率
  7. Room.Clutter.ShroomPct - 房间里出现红色或棕色蘑菇的几率
  8. Room.Clutter.BenchPct - 房间里出现工作台的几率
  9. Room.Clutter.AnvilPct - 房间里出现铁块的几率
  10. Room.Clutter.EnchantPct - 房间里有附魔台的几率
  11. Room.Clutter.OvenPct - 房间里有熔炉的几率
  12. Room.Clutter.Pool.PoolPct - 房间里有水池的几率
  13. Room.Clutter.Pool.FullPoolPct - 房间里被水池(岩浆池)覆盖的几率
  14. Room.Clutter.Pool.LavaPct - 水池被岩浆填满的几率
  15. SpecialPct - 生成一个人工制造的房间(从内置建筑列表)的几率
  16. CorridorPct - 生成走廊而不是房间的几率
  17. Corridor.Max - 走廊最大长度
  18. Corridor.Min - 走廊最小长度
  19. Corridor.Width2Pct - 走廊是两格宽的几率
  20. Corridor.Width3Pct - 走廊是三格宽的几率
  21. Archway.Type.HiddenPct - 拱门出现隐藏门的几率
  22. Archway.Type.WebDoorPct - 拱门缠绕蜘蛛网的几率
  23. Archway.DoubleWidthPct - 拱门或门有两格宽的几率
  24. Archway.IronDoorPct - 木门变成铁门的几率。如果选择0-100之外的数，则可能出现半铁半木的双开门
  25. RadiusMax - 最大半径
  26. UnderFill - 楼层底部是否被方块填充
  27. OverFill - 楼层顶部是否被方块填充
  28. ResetButton - 地牢底部是否生成重置按钮
  29. RecallButton - 地牢底部是否生成传送按钮
  30. Hut.Type - 地牢上建立小屋的类型
  31. Block.Major - 构筑墙的材料。可以使用
  32. bukkit命名规则，比如
  33. cobblestone，或者数字ID。使用":"来指定字节码，比如smooth_brick:1
  34. Block.Minor - 随机分散在墙上的建筑材料。类型同上。
  35. Block.Floor - 地板材料类型。
  36. Block.Roof - 天花板材料类型
  37. Block.MossyPct - "Minor"配置的几率。参数越大则隐藏门更难被找到
  38. Block.AirWebPct - 地牢空气被蜘蛛网填充的几率
  39. Block.Natural - 地牢建筑材料列表。plan命令将使用这些材料来规划地牢。
  40. Depth.floor - 每一层地牢地板的深度
  41. Depth.room - 所有房间的高度
  42. Depth.roof - 每一层地牢天花板的深度
  43. Depth.firstLevel - 楼梯向下到第一层的深度
  44. Trap.Ammo - 陷阱发射器中使用的物品
  45. Mob.Type.SpiderPct - 刷怪笼产出蜘蛛的几率
  46. Mob.Type.SkeletonPct - 刷怪笼产出骷髅的几率
  47. Mob.Type.WolfPct - 刷怪笼产出狼的几率
  48. Mob.Type.PigmanPct - 刷怪笼产出僵尸猪人的几率
  49. Mob.Type.CaveSpiderPct - 刷怪笼产出洞穴蜘蛛的几率
  50. Mob.Type.BlazePct - 刷怪笼产出烈焰人的几率
  51. Mob.Type.CreeperPct - 刷怪笼产出苦力怕的几率
  52. Mob.Gold.Min - 杀死怪物最少获利
  53. Mob.Gold.Max - 杀死怪物最大获利
  54. Loot.Small.LeatherEquipPct - 箱子里出现皮革装备的几率
  55. Loot.Small.List - 物品列表。这些会被随机放置在箱子中
  56. Loot.Medium.EquipPct - 在最后一层的双人箱子中出现铁质或金质装备的几率
  57. Loot.Medium.SmallPct - 中型箱子中包括小箱子中物品的几率
  58. Loot.Medium.HalfEmpty - 设置为True时，最后一层有一半的箱子都是空的(而不是会包括小箱子的物品)
  59. Loot.Medium.List - 物品列表。这些会被放置在最后一层的双人箱子中
  60. Loot.Medium.SweepOre - 地牢重置时不改变最后一层双人箱子的物品
  61. Loot.Big.EquipPct - 在最后一层单人箱子中出现钻石装备的几率
  62. Loot.Big.SmallPct - 在最后一层大箱子中包含小箱子物品的几率
  63. Loot.Big.List - 物品列表。这些会被放置在最后一层单人箱子中。

求详细的构建过程,嗯

可以自己动手，在配置里面添加或更改风格

自动构建得先使用命令/cat plan <地牢名称> <地牢深度> [地牢最大半径] - 半径可以不填

比如/cat plan name 30，等待一会，会提示完成。

这条命令的作用是测量这里的地形能不能生成地牢，并计算结构，也就是生成一个规划图(当然，你是看不到的)

之后可以使用命令/cat build <地牢名称>来构建一个已经规划完毕的地牢

比如：/cat build name

地牢必须先规划再建立，这也是为了防止建筑出错或不满意
