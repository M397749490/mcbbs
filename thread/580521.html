作者: 330032662    时间: 2016-5-2 17:20
(a+b)的值为14，这个值默认被视为int类型，而变量c的类型被声明为byte类型，向下转型可能会有数据丢失。要解决这个问题需要显式转换:
  1. byte a = 9;
  2. byte b = 5;
  3. byte c = (byte)(a + b);
