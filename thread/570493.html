建议修改config文件
  1. forceSaveLogin: false ← 改成true 打开强行传送至指定坐标
  2. # custom saveLogin locations for each world
  3. saveLoginLocations: {} ← 把{}删除
  4. ##  world: ← 将##即可生效 需要为每个时间都设置，默认是world，你可以自行复制
  5. ##    x: 1500
  6. ##    y: -300
  7. ##    z: 0.1
  8. ### this parameters are optional ← 额外设置，用不到可以不用
  9. ##    world: world
  10. ##    yaw: 0
  11. ##    pitch: 0
