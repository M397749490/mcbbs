至于我所推荐的，使用右键物品加入队伍的方法：
首先建立一个判据为使用胡萝卜钓竿的记分项click_count
然后：
scoreboard players tag @a[score_click_count_min=1] add red {SelectedItem:{tag:{display:{Name:"加入红队"}}}}
scoreboard team join red @a[tag=red]
tell @a[tag=red] 已加入红队
scoreboard players tag @a remove red
scoreboard players set @a[score_click_count_min=1] 0
你只需要右键一个名称为“加入红队”的胡萝卜钓竿即可。5条命令！多么简便！想加新的队伍也毫无难度！

无版本，1.12为例。思路有很大很多的问题
比如沙发的1，2俩点，从你想要达成的目的出发就没法避免，所以检测格子能不用就别用。
按照你的思路，做了一个这个系统。
首先保证你又一个叫red的team和有一个叫redtime的记分板

均为不受制约>保持开启
在循环命令方块的旁边接一个比较器，比较器接一个方块，方块上放一个红石火把，红石火把上方接一个不受制约>红石控制
：/scoreboard players reset @a[tag=!redready] redtime
从左往右：
1./scoreboard players tag @a add redready {SelectedItemSlot:5}
为在5号快键栏的玩家增加tag
2.tellraw @a[tag=redready,score_redtime=!1] {"text":"是否选中红队？如确认请保持选中3秒。","color":"red"}
提示信息
3./scoreboard players add @a[tag=redready] redtime 1
为有该tag的玩家加分
4./scoreboard teams join red @a[score_redtime_min=60,score_redtime=60,tag=redready]
分值达到60的玩家加入red队伍
5./tellraw @a[team=red,score_redtime_min=60] {"text":"加入红队成功","color":"red"}
提示消息
6./scoreboard players reset @a[team=red] redtime
重置已经加入red队伍玩家的记分板
7./scoreboard players tag @a remove redready
删除已经加入red队伍玩家的tag完成

*注：沙发的1，2俩个问题并没有在该系统中解决。

至于新思路，我推F键加入队伍。
在保证你有一个叫red的队伍时：

均为不受制约>保持开启
从左往右：
1./scoreboard players tag @a[team=!red] add red {Inventory:[{Slot:-106b,id:"minecraft:wool",Count:1b,Damage:14s}]}
为副手为红色羊毛的玩家添加tag
2./scoreboard teams join red @a[tag=red]
将该tag玩家加入队伍
3./tellraw @a[tag=red] {"text":"已加入红队","color":"red"}
提示信息
4./scoreboard players tag @a remove red
删除tag
↑拿着红色羊毛按下F键加入队伍↑
