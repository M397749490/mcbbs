我的朋友，这一切由你决定。


仅限单人游戏！

不建议多人。如果硬要多人，请做以下设置：
-enable-command-block: true
-Adventure mode (gamemode 2) for every player.
-Difficulty: 2 / Normal
-commandBlockOutput: false
-doMobSpawning: false
-keepInventory: true
-spawn-protection=1


- 请用“普通”难度进行游戏！
