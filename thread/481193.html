插件介绍 Brief Introduction(En&Zh)——
作者的(一句话)介绍:
AdminShop, as the title implies is an AdminShop plugin. It requires TotalEconomy to be installed, and without it will not work.

译：(短什么的我就不说了...)
AdminShop,字面意思，是个商店插件。他需要前置插件TotalEconomy才能正常工作
用法介绍——
系统卖给玩家：
放个牌子：
第一行:[AdminShop]
第二行:系统一次出售多少
第三行:玩家买一次要花多少钱
第四行:出售的东西的ID/名字(推荐ID)
示例图：
玩家卖给系统：
放个牌子
第一行:[AdminShopSell]
第二行:系统一次收购多少
第三行:一次收购给玩家多少钱
第四行:收购的物品ID/名字(推荐ID)
示例图：
指令 Commands(En&Zh)——
本插件(目前)只有一个指令：
  1. /setitem (item name/id) - If you right click an AdminShop sign after doing this,
  2. you can set the specified ID to the ID your specified - intended for item's with ID's
  3. too long for one sign line.
复制代码
/setitem (物品名称/ID)如果你输入该指令后右键一块创建好了的AdminShop买卖牌，那么买卖牌所交易的东西就会变成你指令中做设定的。
权限 Permissions——


adminshop.create - 创造AdminShop的权限Gives player permission to create an AdminShop.
adminshop.remove - 删除/破坏AdminShop的权限Gives player permission to break/delete an AdminShop
adminshop.setitem - 使用/setitem的权限Gives player permission to do /setitem
