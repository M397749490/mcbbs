[anchor=1]注意事项[/anchor]


运行环境 JRE (Java Runtime Environment)：
由于 客户端&服务端 是 Java 程序，所以您需要先配置好Java运行环境。我在这里推荐从官网下载的完整安装的版本，而不是什么精简绿色的版本。精简绿色版虽然去除了很多不常用的组织，但是如果服务端、MOD或插件需要这个组织，那么你就杯具了， 而且很可能绑了病毒。这里我提供了一个Java中文官网，大家可以点击进入然后从官网无忧无虑的下载最安全最完整最新的Java。(如果您的服务器或家用电脑上装的是 Java6 ，那么我推荐您也去官网下载一个最新的Java7，很多MOD或插件是在JDK7的环境下编译的必须用Java7才能运行)
个人能力：
  • 如果您的英语能力或不了解Java，那么我推荐您先去学习一些简单的英语，能读通一些简单的句子，了解一些Java报错的内容与工作原理，再接着往下看，否则…… (后面我就不说 /w\)
  • 没玩过游戏？吾操，赶快去游戏里找到HIM再来看这个教程！

[anchor=3]运行服务端[/anchor]

好了，您现在应该有了 服务端程序了。
那么接下来就是开服了！
(如果没有就给我丢回二楼 啪♂啪♂啪)

具体流程：
Windows (By:FanHua)：
  • 将您下载到的 服务端程序 放到一个独立的目录中 (桌面自重……)
  • 然后在您的独立文件中 右键 -> 新建 -> 新建文本文档 -> 双击打开
  • 向里面填入如下内容。
    1. @ECHO OFF
    2. java -Xms<默认分配内存> -Xmx<最大内存> -jar <服务端程序名>.jar
    3. pause
    复制代码
    例：
    1. @ECHO OFF
    2. java -Xms512M -Xmx1G -jar CraftBukkit.jar
    3. pause
    复制代码
  • 修改 新建文本文档 这个文件的文件名为 Start.bat
  • 然后确定，双击即可启动服务端！
Linux (By:FanHua)：
  • 将下载到的文件保存到一个目录中
  • 新建一个 Start.sh 脚本
  • 然后更换内容为：
    1. #!/bin/sh
    2. java -Xms<默认分配内存> -Xmx<最大内存> -jar <服务端程序名>.jar
    复制代码
    例：
    1. #!/bin/sh
    2. java -Xms512M -Xmx1G -jar CraftBukkit.jar
    复制代码
  • 最后运行这个脚本文件即可启动服务端！

(具体操作命令行没有写，您需要一定的 Linux 操作基础)
Mac (By:Zhuogu)：
  • 将您下载到的 服务端程序 放到一个独立的目录中 (桌面自重……)
  • 使用 文本编辑器 (如系统的 TextEdit.app) 创建一个新的文本文件
  • 然后更换内容为：
    1. #!/bin/bash
    2. cd "$( dirname "$0" )"
    3. java -Xms<默认分配内存> -Xmx<最大内存> -jar <服务端程序名>.jar
    复制代码
    例：
    1. #!/bin/bash
    2. cd "$( dirname "$0" )"
    3. java -Xms512M -Xmx1G -jar CraftBukkit.jar
    复制代码
  • 保存该文件为 Start.command 与 craftbukkit.jar 放置在同一目录下，注意选择保存格式为纯文本 (Plain Text)。
  • 然后进入 终端(Terminal.app) 并输入：
    1. chmod a+x
    复制代码
    然后将刚刚保存的 Start.command 拖动到终端窗口中。
  • 然后按回车键！
  • 最后双击 Start.command 即可启动服务端！

服务端配置文件：
  1. 打开服务器目录下的server.properties文件（用记事本打开即可），并对其进行修改：
  2. （注意：必须将 online-mode=true 改为 false，否则盗版将出现 Bad Login）

  4. #Minecraft 服务器设置文件 此类型文件不支持中文，本内容仅供作为说明
  5. #true 为开启，false 为关闭。
  6. # 是否开启地狱，不开启话地狱门将无效
  7. allow-nether=true
  8. # 地图文件夹名称，下界与末路之地将会自动以nether,ender加上并用下划线隔开
  9. level-name=world
  10. # 是否允许飞行
  11. allow-flight=false
  12. # 服务器端口（25565为默认端口，联机时无需输入）
  13. server-port=25565
  14. # 地图类型，DEFAULT=默认，FLAT=超平坦，LARGEBIOMES=巨型生物群系
  15. level-type=DEFAULT
  16. # 地图种子，在生成地图文件夹之前填入此项，可生成特定的地图
  17. level-seed=
  18. # 服务器IP，不输入则为默认IP，内网用户的话请填内网IP
  19. server-ip=
  20. # 最大建筑高度，上限是256，因为Chunk的高度最大值是256
  21. max-build-height=256
  22. # 是否生成NPC
  23. spawn-npcs=true
  24. # 是否开启白名单，没有白名单的玩家尝试进入服务器会被自动拒绝
  25. white-list=false
  26. # 是否生成动物
  27. spawn-animals=true
  28. # 此处填写服务器默认材质下载链接，链接必须以.zip结尾
  29. texture-pack=
  30. # 是否开启极限模式，玩家死亡将自动被ban
  31. hardcore=false
  32. # 是否开启联网模式（正版专用，盗版需改为 false）
  33. online-mode=false
  34. # 是否开启PVP，不是战争服就不要开了
  35. pvp=false
  36. # 游戏难度，与单机相同
  37. difficulty=1
  38. # 玩家第一次进入游戏时的游戏模式
  39. gamemode=0
  40. # 同时在线的最大玩家数
  41. max-players=20
  42. # 是否生成怪物
  43. spawn-monsters=true
  44. # 是否生成建筑物（包括村庄和地牢）
  45. generate-structures=true
  46. # 可见距离，最大值为10
  47. view-distance=10
  48. # 服务器欢迎信息
  49. motd=A Minecraft Server

[anchor=5]插件&模组[/anchor]

好吧，配置完后那么就来看看这一步吧。
如果你还没有成功的运行服务端，那么就丢回 四楼 M♂L

插件：
在 http://dev.bukkit.org/ 中下载后，
将其放到plugins文件夹中，
然后运行一次服务端，
然后对插件进行配置 (如果需要的话)，
最后重新载入或重启服务端

模组：
在 http://mcportcentral.co.za/wiki/index.php?title=CraftBukkit_Ported_Mods 中下载指定的移植后的模组，
然后将其放到 mods 文件夹中，
然后运行一次服务端，
然后对模组进行配置 (道具ID、方块ID以及其他的东西)
(注意：配置需与客户端一样，否则客户端将会混乱)
保存后重启服务端 (重新载入后模组中新加的物品无法合成)
