作者: qq1149872105    时间: 2015-9-3 00:42
这个插件自动生成的配置文件前面有误，你把配置文件前面跟着我给的对照输入，不要少，可以更改触发菜单的物品ID
#   MENU SETTINGS    #
#+                  +#
######################
menu-settings:
  #名称-作为标题出现
  name: '黎明服务器菜单'
  #行-胸部的行数
  rows: 6
  #命令-可选(您可以删除这或将其设置为”)
  #绑定多个命令使用;(命令:“菜单;m;我”)
  command: 'cd'
  #自动刷新-可选
  #菜单将刷新的频率,以秒为单位。
  #有用如果你有变量项的描述。
  auto-refresh: 3
  #时将执行该命令的命令菜单打开。
  #支持所有命令类型的图标。
  open-action: 'sound: note pling; tell: &e欢迎使用黎明服务器菜单功能.'
  # open-with-item -可选
  #菜单将只有右击打开橙色羊毛[35:1]
  open-with-item:
    id: 347
    left-click: false
    right-click: true
