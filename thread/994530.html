而需要的数据从所谓的“extended blockstates”提供，每当模型需要更新时——可以使用world.markBlockRangeForRenderUpdate更新模型——
这个模型绑定的方块类中的
public IExtendedBlockState getExtendedState(IBlockState state, IBlockAccess world, BlockPos pos)
就会被调用，你返回的extended blockstates会传入IBakedModel中供渲染使用。Forge文档关于extended blockstates是这样说的：
“Extended blockstates provide a way for blocks to pass arbitrary data to their models. Ordinary blockstates and properties occupy only a fixed set of possible states, while extended states can form infinite sets. ”
也就是说extended blockstates可以储存的数据是任意的。
那么我能否在getExtendedState中利用IBlockAccess world, BlockPos pos获得——在我这个例子中是BlockPos上方那个方块的——BlockState然后
