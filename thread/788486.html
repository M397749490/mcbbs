官服死亡不掉落设置了是针对所有人，出现你说的玄学情况我不能解释。
  1. [
  2.   {
  3.     "uuid": "6FFE79BD-40ED-49B8-5693-4F443790D0DD",
  4.     "name": "players",
  5.     "level": 4,
  6.     "bypassesPlayerLimit": false
  7.   }
  8. ]
复制代码

这个就是ops.json文件里json的格式。
uuid就是这个玩家的唯一id
name就是玩家名字
level就是op等级，默认是4级也就是最高级，等级的区分就是能用的指令不一样具体看这个https://minecraft-zh.gamepedia.c ... 4.E6.A6.82.E8.BF.B0
bypassesPlayerLimit就是允不允许突破服务器人数限制（服务器人满的时候能不能进）true就是允许
你也不需要自己编辑，你在后台或者op账号用/op 玩家名字 给op就行了。
