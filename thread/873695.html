请问Bukkit的YamlConfiguration读取和保存都是Unicode，怎么改为UTF-8呢？有没有大佬能帮忙重写一下，谢谢了
作者: lgou2w    时间: 2019-6-16 00:32
使用 InputStreamReader 和 OutputStreamWriter 来读取和保存自定义编码文本。
  1. // 用 UTF-8 编码保存
  2. YamlConfiguration yaml = new YamlConfiguration();
  3. yaml.setString("test", "UTF-8编码例子");
  4. String data = yaml.saveToString(); // 将 yaml 保存为字符串
  5. FileOutputStream fos = new FileOutputStream(new File("D:/test.yaml")); // 输出文件流
  6. OutputStreamWriter writer = new OutputStreamWriter(fos, Charset.forName("UTF-8")); // 用 UTF-8 编码包装输出流写
  7. writer.write(data); // 写入数据
  8. writer.flush(); // 提交缓冲区内容
  9. writer.close(); // 关闭写流
复制代码
  1. // 用 UTF-8 编码读取
  2. FileInputStream fis = new FileInputStream(new File("D:/test.yaml")); // 输入文件流
  3. InputStreamReader reader = new InputStreamReader(fis, Charset.forName("UTF-8")); // 用 UTF-8 编码包装输入流读
  4. YamlConfiguration yaml = YamlConfiguration.loadConfiguration(reader); // 从输入流读加载 Yaml 配置
  5. yaml.getString("test"); // ->> UTF-8编码例子
  6. reader.close(); // 关闭读流
复制代码
