标题: [经济]MysqlEconomyBridge——经济跨服同步丨可同步ESS经济丨支持UUID[1.6.4-1.8.9]
本帖最后由 1582952890 于 2017-9-16 20:59 编辑


简介


一个小插件，使用Vault在Mysql上创建一个跨服的经济系统


特性


支持UUID

支持任何兼容Vault的经济插件

Mysql数据库


前置


Vault

Mysql

任何兼容Vault的经济插件


安装说明


放入plugins文件夹，确保服务器装有经济插件及Vault

开启服务器生成配置文件，关闭服务器

打开配置文件设置数据库连接细节，在Mysql创建库，插件会自动生成表

开启服务器，至此结束


命令及权限:无


config:


#Mysql连接地址
host: 127.0.0.1

#MySQL 端口 (默认 3306)

port: 3306

#库的名字 (没有的话! 你需要创建一个库.)

databaseName: 'money'

#表的名字 (插件在库中自动创建)

dataTableName: 'eco_accounts'

#用户名字

user: 'root'

#用户密码

password: 'password'

#This maintenance task runs async with a 2 min delay after the server starts.

removeOldAccounts:

#启用或禁止不活跃账户清理

enabled: false

#清理周期，单位天.

inactivity: 60



#其他设置

General:

#登陆后账户同步延迟(默认1000毫秒=1秒)

#bungeecord 必须设置延迟，因为你换服时，退出和登录几乎是同时进行的

loginSyncDelay: 1000

#在线玩家保存数据，禁用后则是在玩家下线后保存数据.

dataSaveTask:

enabled: true

#保存数据时间

interval: 3





注意

此插件不是一个经济插件，不能创建一个经济系统，他只能将现有的经济体制用Mysql实现同步
