材质包基底为1.12.2不过好像其他版本也能用，改改文件就行了
================================================

使用方式：材质包置顶（因为只有图标文件所以置顶后其他材质包也能正常使用）

     ps1：警告：json文件如果没有目标图片文件，请不要加入材质包中，有多少材质加多少个json文件，否则你将收获一堆错误报告，虽然没啥影响只是开游戏的时候卡点……
     ps2：本材质包提供了各类武器，图标的材质，但都需要特殊方式调用，适合各类RPG服务器，插件服。
     ps3：本材质包为未完成品，想使用的需要自行设置，毕竟你想调用也得自己设置……
     ps4: 材质包内图标都使用了彩虹岛内的素材，仅供学习使用，请勿商用。
     psp: 发帖用的这个编辑器是真的难用，我打了半天字直接没了，而且没了三次……
     psv: 本材质本来是给lalameow的RPG服务器做的，奈何某天才一直咕咕咕咕咕咕，一直没法做，便想着把rpg服的副产物也就是这材质包发布出来。

&0y4'表示了一个黑色的y4，
物品调用方式
  1. type=item
  2. matchItems=260
  3. texture=y4
  4. nbt.display.Lore.*=\u00A7y4
复制代码

\u00A7y4为转U码后的&0y4





想要批量设置damage值，表格非常好用。
批量命名图片的话 名字后面的数字会有括号，这个时候就需要一个神器

Untitled-1.bat
  1. [url=home.php?mod=space&uid=39305]@echo[/url] Off&SetLocal ENABLEDELAYEDEXPANSION
  2. FOR %%a in (*) do (
  3. set "name=%%a"
  4. set "name=!name: (=!"
  5. set "name=!name:)=!"
  6. ren "%%a" "!name!"
  7. )
  8. exit
复制代码
这个bat文件就可以把此文件根目录的所有文件名字里的括号全删掉。
