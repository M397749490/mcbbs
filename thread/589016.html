应该有两个文件，一个是贴图，这个你已经做好了，另外一个名字你注意一下，应该是【贴图名.png.mcmeta】
然后这个文件可以用记事本打开。
  1. {
  2.   "animation": {
  3.     "interpolate": true,
  4.     "frametime": 10
  5.   }
  6. }
复制代码

一般这么写就够了，如果需要的话可以再加上关键帧的要求。
