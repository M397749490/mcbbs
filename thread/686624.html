◆ 安装方法 ◆
本插件可以安装WorldEdit创世神，WorldGuard区域保护前置，不安装也行
下载jar文件，扔进plugins文件夹，重启服务器

◆ 指令教学（必看必看） ◆
==创建指令==
/wm set biome:<群系名称> radius:<半径>  - 改变你周围任意半径的生物群系
/wm set biome:<群系名称> - 改变WorldEdit创世神已经选择好的区域生物群系
/wm set biome:<群系名称> region:<WG区域名> - 改变WorldGuard某个区域的生物群系
/wm populate biome:<群系名称> - 重新渲染生物群系，如果你的生物群系显示不正常，使用这个
/wm replace biome:<群系名称> fill:true - 改变你现在站的位置的生物群系为其它群系
/wm give [biome | depopulator | forester |woodcutter] - 获得一个魔棒工具，它的用途可以是更改群系|重新渲染群系|生成树木|删除树木（四选一）
/wm wand biome:<群系名称> radius:<半径> tree:<树的种类> - 编辑魔棒工具参数，这条指令对四种魔棒都有效
如果想变回最初的生物群系，请将生物群系更改为original

==基础指令==
/wm help - 显示帮助
/wm check - 显示你现在在哪个生物群系
/wm info - 开启/关闭进出生物群系的提示消息
/wm list [tree | biome] - 列出可用的树的名字/生物群系的名字（二选一）

==天气指令==
/wth player <玩家> <rain|clear|remove> - 设置某特定玩家看到特定的下雨/晴天/移除效果
/wth region <WG区域> <rain|clear|remove> - 设置WorldGuard某特定区域内的下雨/晴天/移除效果
/wth biome <群系名称> <rain|clear|remove> - 设置某特定群系发生特定的下雨/晴天/移除效果
/wth world <世界名> <rain|clear|remove> - 设置某特定世界发生特定的下雨/晴天/移除效果
/wth <player|region|biome|world> - 列出已经更改过的玩家/区域/群系/世界

==日夜指令==
/wtm player [<玩家名> <时时:分分|day|night|remove>] — 设置某特定玩家的时间/白天/夜晚/移除效果
/wtm region [<WG区域名> <时时:分分|day|night|remove>] — 设置WorldGuard某特定区域内的时间/白天/夜晚/移除效果
/wtm biome [<群系名称> <时时:分分|day|night|remove>] — 设置某特定群系的时间/白天/夜晚/移除效果
/wtm world [<世界名> <时时:分分|day|night|remove>] — 设置某特定世界的时间/白天/夜晚/移除效果

◆ 权限（别看别看） ◆
毕竟是对服务器伤筋动骨的事情，默认OP使用就好
  • weatherman.basic - 允许使用 /wm help, /wm check, /wm list
  • weatherman.cmdbiome - 允许使用 /wm set 和 /wm fill
  • weatherman.sign - 允许创建能改变生物群系的牌子 [biome]
  • weatherman.wandbiome - 允许使用魔棒工具，并使用 /wm wand, /wm radius, /wm biome
  • weatherman.config - 允许使用 /wm cfg 设置插件相关参数
  • weatherman.weather - 允许使用改变天气 /wth
  • weatherman.time - 允许使用改变日夜 /wtm

◆ 一些小问题（必看必看） ◆
1，某些生物群系带有特殊的效果，比如hell和sky地狱和末地生物群系，在这两个群系里睡觉会爆炸！还有某些生物群系可能会刷出特别的怪物，请注意这点
2，频繁更改，或者大面积更改生物群系会导致服务器卡顿，可能会出现无法更改的情况
3，修改天气/日夜只能修改看到的效果，并不是真的修改了系统的天气/日夜（僵尸不自燃？）
4，即便修改天气，沙漠生物群系还是不会下雨
