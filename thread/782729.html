命令权限

  1. /skill 打开帮助
  2. /skill select 选择一个职业类型 只能选择 一次 skills.select
  3. /skill level 显示你的技能状态
  4. /skill improve 打开技能GUI skills.improve
  5. skill.level.bypass 绕过等级限制
  6. skills.select.不明类型
  7. skills.select.访问所有 /skill selects)
  8. /skill change 允许用户改变他的技能，但是这个命令在配置中有一个冷却时间。 skills.change
  9. /skill mastery 允许用户管理技能 skills.mastery
  10. /skill partycreate (允许用户创建一个队伍) skills.partycreate
  11. /skill partyinvite (允许有队伍的用户邀请其他人。) skills.partyinvite
  12. /skill partyshow (允许用户查看关于他的队伍的信息) skills.partyshow
  13. /skill partyaccept (允许用户接受派对邀请) skills.partyaccept
  14. /skill partyleave (允许用户离开当前的宴会) skills.partyleave
  15. /skill setsouls [player] [amount] (增加指定数量技能点。可用+ 或 -) skills.setsouls
  16. /skill setstatpoints [player] [amount] (添加到玩家的统计点数。 在数字前面可用+ 或 -) skills.setstatpoints
  17. /skill setlevel [player] [amount] (添加级别。 等级不能低于0.在要扣除的数字前加可用+ 或 -) skills.setlevel
  18. /skill setxp [player] amount] (添加到玩家的经验中。 经验可以低于0.在数字前加可用+ 或 -) skills.setxp
  19. /skill stat (玩家可以在其中添加stats到他的STR，DEX，INT或DEF) skills.stat
  20. /skill startxpboost [time in min] [multiplier] (在服务器范围内启动一个经验提升事件) skills.startxpboost
  21. /skill startsoulboost [timeinmin] [multiplier] (在整个服务器范围内启动灵魂提升事件) skills.startsoulboost
  22. /skill setskill [player] [skillty-pe] (改变玩家的技能) skills.setskill
复制代码
  1. 不太推荐使用 记分板之类的 倒是MV可以用用
复制代码
  1. {skill} Returns a player's skilltype in text
  2. {level} Returns a player's level
  3. {souls} Returns a player's soulcount
  4. {xp} Returns a player's current xp
  5. {maxxp} Returns a player's xp to level up
  6. {isxpboost} Returns if there is an xp boost on
  7. {issoulboost} Returns if there is a soul boost on
  8. {soulboostmultiplier} Returns the multiplier of the current soul boost
  9. {xpboostmultiplier} Returns the multiplier of the current xp boost
  10. {hp} Returns the player's Skills hp
  11. {blood} Returns the player's blood count
  12. {mana} Returns the player's mana count
  13. {energy} Returns the player's energy count
  14. {imbalance} Returns the player's imbalance count
  15. {energytype} Returns energy,mana or blood depending on the player's skilltype
