喵喵给大家发表MC的生物介绍
——————————————————————————————————————————————————————————
名称图片掉落物食物声音其他
猪猪君肉萝卜【无图】 壳壳肉可食用，可考来吃，可生小猪
小鸡君鸡肉羽毛[feather]种子哦。嘎嘎和猪一样，会生蛋，可砸出小鸡【像鸭子】
咩咩君[white_wool]毛毛草小麦咩可以用剪刀剪羊毛，吃草会长毛，小羊吃草会变成大羊
牛牛君肉[leather]皮麦子么……和猪一样，可以挤奶，牛奶有用。
猫猫君无图无鱼喵！会吓走苦力怕，
汪汪君 无 骨头[bone] 汪汪 可以驯服，驯服后会帮助主人打怪
村民君 无图 无 无 不知道 可以交易换东西
铁傀儡 无图 铁[iron_ingot]花 无 不知道 可以做，可以保护村民和史蒂夫，超拽
苦力怕 火药[gunpowder] 无 SSS 会爆炸哦，SSSSSSSSSSS.....PO！
骷髅君 骨头[bone] 无 不知道 会射箭
僵尸君 腐肉 无 不知道 会拿东西，会撞门
内牛满面 什么泪的[grid_ghast_tear] 无 啊！！！！ 会扔弹
手酸呢，给粒粒嘛给人气。
