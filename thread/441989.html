北极星插件是一款类似于Ess插件中地标（warp）的一个插件，可以绑定一个任意的物品去传送到任意一个地点！
注意：不是只能绑定一个物品，可以绑定无限个物品去无限个地点！
适用于需要快速传送的服务器，例如战争服中的阵营战斗。
特色功能：
1.可以配置冷却时间、传送时间。
2.支持颜色代码和改名类插件。
3.支持多世界。
4.可配置传送物品的损耗。
5.基本同第4条，可设置传送物品为一次性物品。
6.可以随时配置传送物品所对应的坐标，也可以随时删除物品的传送功能。
注意：传送物品默认为“下界之星”。
配置权限：
权限 功能 默认拥有者
lodestar.use 使拥有人可以使用传送物品 所有人
lodestar.list 显示传送物品对应的坐标 所有人
lodestar.admin 北极星插件的管理权限 OP
lodestar.set 使拥有者创建一个传送坐标点 OP
lodestar.set.overwrite 使拥有者可以改变传送物品对应的传送地点坐标 OP
lodestar.delete 使拥有者可以删除一个传送坐标点 OP
lodestar.bind 使拥有者可以创建一个传送物品及其对应的传送坐标点 OP
lodestar.give 使拥有者可以给别人一个传送物品 OP
lodestar.destroy 使拥有者可以销毁一个传送物品 OP
lodestar.reload 使拥有者可以重新加载北极星插件 OP
lodestar.status 使拥有者可以查看北极星插件配置文本 OP
插件命令：
命令 功能
/lodestar reload 重新加载北极星插件
/lodestar status 查看北极星插件配置文本
/lodestar set 创建一个传送坐标点
/lodestar list 显示传送坐标点列表
/lodestar delete 删除传送坐标点
/lodestar give 给别人一个传送物品
/lodestar bind 绑定一个物品及其对应的坐标点
/lodestar destroy 销毁手中的传送物品
注意：该插件所创建的坐标点与Ess插件中的坐标（warp）用法相同，且互不干涉，创建坐标点之后才可以创建一个传送物品指向这个传送坐标点。
