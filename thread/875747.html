这个插件允许玩家使用装置传送怪物和动物,这个项目可以由玩家制作。
你只需要右击任何一个怪物，它就会把怪物存放在装置里面。然后左键点击释放。
同时还允许玩家使用shift+右键对这个装置充能次数,默认消耗绿宝石



特点
制作配方可配置
使用装置时的酷炫效果和声音
制作可配置的充能物品数量
装置的充能方式可自定义。
添加世界禁止使用装置
每个 怪物/动物 的捕捉权限
支持领地插件Residence 和公民插件 Citizens.

可自定义



命令
/at get — 获取一个传送装置
/at reload — 重载插件



权限
mobtransporter.admincommand - 使用at的权限.

mobtransporter.admincommand.get - 使用get权限.

mobtransporter.admincommand.reload - 使用reload权限.

mobtransporter.admincommand.* - 完全访问at权限,也就是get和reload.

mobtransporter.blacklist-bypass - 允许在禁止的世界中使用装置.

mobtransporter.capture - 允许玩家使用装置捕捉.

mobtransporter.place - 允许玩家放置怪物.

mobtransporter.mob.<怪物类型> - 允许玩家捕捉特定类型怪物

mobtransporter.mob.* - 允许玩家捕捉任何怪物



配置文件
config:
  1. # Settings for MobTransporter - v1.2
  2. # capture.citizens: 如果是 true, 玩家可以从 Citizens这个插件捕捉怪物.
  3. capture:
  4.   citizens: false
  5. recipe:
  6. # recipe.enabled: 如果是true，玩家可以用指定的制作配方来制作传送装置.
  7.   enabled: true
  8.   top: ssa
  9.   middle: sea
  10.   bottom: aas
  11. transporter:
  12. # 装置在制作出来时默认的最大使用次数
  13.   max-usages: 2
  14. charge:
  15. # charge.item: 玩家在给装置充能时使用的物品.
  16.   item: EMERALD
  17. # charge.item-amount: 充能时消耗多少个充能物品
  18.   item-amount: 1
  19. # charge.usage-amount: 一个充能物品能充能多少次数.
  20.   usages-amount: 1
  21. # use-permissions: 如果是true, 玩家需要 'mobtransporter.capture' 和 'mobtransporter.place'权限才能使用装置.
  22. # use-permissions-per-mob: 如果是 true, 玩家需要 'mobtransporter.mob.怪物名称' 和 'mobtransporter.mob.*' 去捕捉怪物
  23. use-permissions: false
  24. use-permissions-per-mob: false
  25. # materials: 配方中使用的材料.
  26. materials:
  27. - s:STRING
  28. - e:ENDER_PEARL
  29. - a:AIR
  30. worlds:
  31. # worlds.blacklist: 世界黑名单,关闭使用传送装置的世界.
  32.   blacklist:
  33.   - myworld
  34.   - myworld_nether
  35.   - myworld_the_end
