                                                                 领地飞行插件（Residence Fly ）  它可以做什么？:
这个插件增加了飞行标记在resadmin插件里, 你可以将标记添加到领地里. 如果玩家有飞行标记的权限, 他就可以在领地里飞, 如果他离开他就会掉下.
注意！装了插件就要修改下领地插件的配置文件，添加进领地标记fly: ture 才可以用.
命令:
        /resfly 切换控制台调试
       /res set  [领地名] fly true   开启领地飞行
     / res set [领地名] fly false    关闭领地飞行
权限:
        resfly.ignore拥有此权限的时候玩家将不会失去飞行权限，跟其他插件使用时.
        refly.toggledebug 有访问/resfly指令的权限 .
        really.dontfall - 得到此权限将不会在某人领地中禁用飞行.

配置文件：
  1. # 在控制台显示调试消息
  2.    debug: false
  3. # 无损伤飞行高度（好像是)
  4. nodamageticks: 100
  5. # 领地飞区继承飞行
  6. inheritfly: false
