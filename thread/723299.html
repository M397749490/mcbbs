请用记事本打开你的命令提示符脚本文件，查看启动服务端jar包部分的命令。
比如：
  1. java -jar spigot.jar
复制代码
增加"-Dfile.encoding=UTF-8"参数：
  1. java -Dfile.encoding=UTF-8 -jar spigot.jar
复制代码
修改服务端的编码为UTF-8
控制台出现中文乱码一般由于服务端核心编译环境与生产环境的编码不一致导致，
如果以上参数仍然不能正常显示中文，请检查修改前是否已有相关参数，将其删除。
