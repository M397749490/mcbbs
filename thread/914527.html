前言说明
我知道，在站内也有一个类似于此功能的同名插件Chat Guard
但为什么还要搬运这款呢？
首先我看了一下旧帖时间....2016年，且似乎并不支持高版本

该插件的作者也是2016年的最后更新，故搬运了这款ChatGuard插件。
支持高版本，同时，也具有一些其他的有趣的设定。


功能介绍

  • 1. 定时的聊天清理
  • 2.一些关键词的屏蔽
  • 3.用游戏币担保来发送关键词，同时也可以加以关键词惩罚游戏币
  • 4.可设置聊天打字的冷却时间，更好地阻止聊天刷屏
  • 5.可设置输入命令的冷却时间，更好地阻止命令刷屏
  • 6.防止玩家在游戏中发送其他服的IP以及域名
  • 7.可自定义化插件的提示



权限节点


  2. chatguardian.chat.swearbypass - 绕过关键词检测以及惩罚
  3. chatguardian.chat.spambypass - 绕过聊天发言刷屏检测
  4. chatguardian.chat.commandspambypass - 绕过指令刷屏检测
  5. chatguardian.chat.adbypass - 绕过发送IP的检测
  6. chatguardian.chat.capsbypass - 绕过大小写 发言检测
  7. chatguardian.commands.chatguardian - 获取该插件信息的权限(默认·玩家拥有)
  8. chatguardian.commands.clearchat - 清屏 清理玩家个人的聊天频道(默认·玩家拥有)
复制代码




插件命令

  • /chatguardian - 查看插件信息
  • /cc 或 /st - 清屏(与菜单chestcommands的cc冲突)

/cc命令冲突解决方法：
用zip压缩包的方式打开插件java。
然后用notepads+打开plugins.yml
修改底部的aliases: [cc,st,clearchats] 把cc删掉即可。

最后改成aliases: [st,clearchats]

commands:
    chatguardian:
        description: Main command.
        aliases: cg
    clearchat:
        description: Clears chat.
        aliases: [cc,st,clearchats]



配置文件


words.yml
在这个文件中加入你需要屏蔽的关键词！

config.yml

  2. # 因为搬运授权问题，所以就不另出配置文件了，大部分都只是功能的提示，这里只是单独标一下都是哪些功能
  3. # 这个antichar是
  4. antichar: true
  5. # 大小写检测开关
  6. capslock-protection-enabled: true
  7. # 聊天发言开关
  8. spam-protection-enabled: true
  9. # 聊天发言间隔
  10. spam-delay: 3
  11. spam-msg: '&b[&fChat Guardian&b] &c你需要等一会儿才能发言!'
  12. command-spam-msg: '&b[&fChat Guardian&b] &c命令输入过快!'
  13. command-delay: 3
  14. #触发关键词
  15. replace-blacklisted-messages:
  16.   enabled: true
  17. swear-message: '&b[&fChatGuardian&b] &cSwearing is not allowed in this server.'
  18. # 自动清屏
  19. automated-clear-chat:
  20.   enabled: true
  21.   delay: 300
  22.   msg: '&b[&fChatGuardian&b] &a聊天已清理.'
  23. no-advertising-msg: '&b[&fChatGuardian&b] &cYou can not advertise in this server!'
  24. punishments:
  25. # 这个是触发word.yml里的关键词时，就会惩罚以及提示
  26.   swear:
  27.     enabled: true
  28.     command: 'money take %player% 100'
  29.     msg: '&b[&fChat Guardian&b] &c你因为触发关键词失去了 &f100 &c游戏币.'
  30. # 这个是发送了IP或者域名时，就会惩罚以及提示
  31.   advertising:
  32.     enabled: true
  33.     command: 'money take %player% 100'
  34.     msg: '&b[&fChat Guardian&b] &c你因为发送了疑似广告的信息失去了 &f100 &c游戏币.'
