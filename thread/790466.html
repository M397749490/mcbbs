描述

这是一个简单的物品封禁插件，支持简单的物品管理和每个物品独立权限管理。
支持
API 5-6: https://ore.spongepowered.org/le ... versions/1.4.1-API5
API 7: https://ore.spongepowered.org/le ... rict/versions/1.4.1
特性
  • 从你的手里或者某个箱子中添加物品
  • 可以使用权限让玩家无视某个封禁
  • 可选的异步世界扫描 —— 每五分钟扫描已加载的区块，清除ban的方块
  • 扫描全部加载区块方块的扫描命令
  • 可以转移的banneditems.conf文件，可以在任意服务器使用

从一个箱子中添加封禁物品
  • 把想要ban的物品添加到一个原版箱子中。
  • 主手持一个燧石然后shift+右键点击。
  • 使用/banneditems命令确认物品已经被添加。
  • 没有其它需要的话 可以移除箱子了。

注意:
已经被添加的物品，会在检测中跳过。所以你可以使用在安全地方的箱子表示ban列表。
大箱子需要你在两边都Shift右键。
权限

命令
  • /Restrict add - 将你手中的物品添加到封禁列表中
  • /Restrict remove (itemID)
  • /Restrict edit (itemID) (option) (value)
  • /Restrict search (itemID)
  • /Restrict whatsthis - 告诉你，你手中的物品的ItemID是什么
  • /Banneditems - 列出ban列表中所有的物品，拥有编辑权限的玩家可以使用这个编辑
  • /Restrict sendtochest (itemID) - 搜索所有已经加载的区块，查找指定物品id，并且在方块所在的位置放置一个箱子，并把物品放置其中？

BStats

这个插件使用bStats来收集使用信息。
你可以在配置文件config/bstats/config.conf中关闭它。
所有收集的信息可以在这里查看: https://bstats.org/plugin/sponge/MMCRestrict
