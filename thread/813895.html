JSON 是一个广泛适用的格式，NBT 是 Notch 造的轮子。

事实上，NBT 是一种二进制格式（英文 Named Binary Tag），命令中使用的只是它的字符串形式，而 JSON 存成文件的时候就是字符串形式，如果硬要说什么本质区别大概就是这样了…

所以，为什么要有这么两个格式呢…Notch：我自己造了个格式，坑了一个游戏十年，我真厉害


标准JSON格式为"名称":值，和NBT一样都是用来详细描述某个实体/方块的啊。
稍有偏差，只有 NBT 是 MC 用来详细描述实体/方块实体的，JSON 只是某些 NBT 键要用到（比如 1.13 的 CustomName、书的 page[n] 之类的）

需要用到的格式变成JSON格式而不是原来的XX:XX格式呗
需要的格式仍然是 键:值，只是值（字符串）要求是个 JSON，比如 {CustomName:"{\"text\":\"foobar\"}"}。

tellraw命令不是必须按照JSON格式么
/tellraw 要求 JSON Token，数字、布尔型、字符串、列表、对象都是合格的 Token，因此以下命令都是合法的：
数字：/tellraw @a 123456
布尔型：/tellraw @a true
字符串：/tellraw @a "foobar"
列表：/tellraw @a ["foobar",123456,true,{"text":"foobar"}]
对象：/tellraw @a {"text":"foobar"}
