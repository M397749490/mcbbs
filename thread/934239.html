PlayerBirthday
玩家生日
下载
自定义生日,自定义信息

生日时播放歌曲
发射烟火,给玩家一个蛋糕
年龄系统

==命令==

主命令
/bth
帮助
/bth help
显示所有玩家生日(?)
/bth public
/ bth setbd-[日-月份]
示例：/bth setbd 01/12；这将把你的生日设置为12月1日
PS： 玩家的命令没有权限限制

==管理员命令==
主命令
/bths
帮助
/bths help
检查更新
/bths checkupdate
更新
/bths update
更新日志
/bths changelog
重置玩家生日
/bths resetbd 玩家名称


==权限==
Birthday.staff.<命令>
允许使用管理员命令
Birthday.staff .*
可以选择全部指令
playerbth.receiveupdate
使用命令时显示更新信息的权限

==控制台命令==

bths testbirthday 玩家名字 public/private
如果使用public，则生日信息将显示给服务器上的所有人；
如果使用 private，则将仅显示该玩家的
bths bthsong bthsong player/online
如果是online，则生日歌曲播放给服务器上的每个人
bths update
如果有可用更新，它将更新插件
bths getlatest
获取该插件的最新版本并将其与你的实际插件版本进行比较


==配置文件==
  1. #生日(插件?)标题
  2. birthdaytitle: true
  3. #检查更新日志
  4. UpdateChangeLog: true
  5. #自动更新
  6. AutoUpdate: true
  7. #检查更新
  8. CheckUpdates: true
  9. #bStats统计
  10. Metrics:
  11.   bStats: true
  12. #播放歌曲
  13. BirthdaySong: Birthday
  14. #是否发射烟火
  15. Firework:
  16.   enabled: true
  17.   #力量(飞的高度)
  18.   power: 2
  19.   #数量
  20.   amount: 3
  21. #给予蛋糕
  22. Cake:
  23.   enabled: true
  24.   name: "&b{name} &f- &8年龄: &7{age}"
复制代码
