标题: [1.13] 如何正确地使用 Brigadier
本教程基于 Minecraft 18w16a，假设读者有一定的 Java 基础
1.13 采用了新的命令解析系统——Brigadier
它是一个独立的库，没有被混淆，并可以在 ./libraries/com/mojang/brigadier/version/ 下找到
命令系统基础可以看 @ustc_zzzz （没蓝？！）dalao 的稀里糊涂的commands.json全解析
So，如何正确地使用 Brigadier 呢？
首先看看它的目录结构：

com.mojang.brigadier.arguments 下面有一些参数类型；com.mojang.brigadier.builder 下面是几个 builder，一会儿会讲到；com.mojang.brigadier.tree 下面是命令的节点；com.mojang.brigadier 下面的 CommandDispatcher 就是整个命令系统的核心，所以 new 一个 CommandDispatcher 实例是很关键的（什么神逻辑）
  1. CommandDispatcher<Object> dispatcher = new CommandDispatcher<>();
复制代码
看起来那个类型参数是表示执行者的类，这里就用 Object 代替了
首先明确一下目标：
return <result>：返回参数 result，但只接受 -32768 到 32767 之间的整数
sum <a> <b>：返回参数 a，b 之和，溢出时抛异常
当然如果要添加其他命令的话，自己发挥吧
接着看 CommandDispatcher 的结构：

有个 register(LiteralArgumentBuilder<S>) 很显眼（Really？），用于加入新的命令，而 LiteralArgumentBuilder 就是这个命令了，可见其实命令是作为第一个参数处理的
LiteralArgumentBuilder 是 ArgumentBuilder 的子类，有一个 public static 的方法 literal(String)，用它获取一个实例；ArgumentBuilder 提供了很多方法构造一条命令，比如 then(ArgumentBuilder<S, ?>) 添加参数，executes(Command<S>) 指定命令执行的内容等
说到 Command，不得不提一下这个 interface 里面唯一的方法 public int run(CommandContext<S> var1) throws CommandSyntaxException;，它接受一个 CommandContext<S> 参数，返回 int，可抛 CommandSyntaxException（真是绝妙的设计）
所以经过一番摸索之后，我们得到了这样的代码：
  1. public static final SimpleCommandExceptionType ERROR_INTEGER_OVERFLOW = new SimpleCommandExceptionType("command.int.overflow", "Integer overflow");
复制代码
  1. dispatcher.register(LiteralArgumentBuilder.literal("return").then(RequiredArgumentBuilder.argument("result", IntegerArgumentType.integer(-32768, 32767)).executes(context -> context.getArgument("result", Integer.class))));
  2. dispatcher.register(LiteralArgumentBuilder.literal("sum").then(RequiredArgumentBuilder.argument("a", IntegerArgumentType.integer()).then(RequiredArgumentBuilder.argument("b", IntegerArgumentType.integer()).executes(context -> {
  3.     int a = context.getArgument("a", Integer.class);
  4.     int b = context.getArgument("b", Integer.class);
  5.     int r = a + b;
  6.     if (((a ^ r) & (b ^ r)) < 0) throw ERROR_INTEGER_OVERFLOW.create();
  7.     return r;
  8. }))));
复制代码

  2. testCommand(dispatcher, "return 2147483647", null);
  3. testCommand(dispatcher, "sum 233 1", null);
  4. testCommand(dispatcher, "sum 2147483647 1", null);
