PremiumHub —— 大厅系统



插件介绍
Description — 简介

PremiumHub这款插件是多功能，专业，完全可配置与物超所值的一款Hub插件
我（作者）花了许多时间在这款插件，很高兴与各位分享
这插件与其他Hub不同，我（作者）保证购买本插件绝对物超所值！
Features — 功能

  • 自定义加入物品
  • 自定义背包
  • 传送门与二段跳！
  • 玩家设置GUI
  • 道具（粒子效果和小道具）
  • 教学模式（类似Hypixels与Mineplexs）
  • 高級弹跳板（每个弹跳板有不同的配置）（不清楚）
  • 定时公告
  • 清除聊天
  • 飞行
  • 服务器选单
  • 大厅选单
  • 传送系统
  • 隐身
  • 掉落虚空传送
  • 彩色告示牌
  • 传送功能的弓
  • 抓取钩/拉钩
  • 防告示牌崩溃
  • 防世界下载
  • 支持PlaceholderAPI
  • 还有很多......

  • PremiumHub.Join.Firework - 加入烟火特效!
  • PremiumHub.ColorSigns - 创建告示牌使用颜色!

  • PremiumHub.PlayerOption.HidePlayer - 允许启用/关闭隐藏玩家!
  • PremiumHub.PlayerOption.Chat - 允许启用/关闭聊天栏!
  • PremiumHub.PlayerOption.DoubleJump - 允许启用/关闭二段跳!
  • PremiumHub.Vanish.Exempt - 允许看见隐身的玩家! (命令)
  • PremiumHub.HidePlayer.Exempt - 允许看见隐藏玩家的玩家! (设置GUI)
  • All Particles & Gadgets - 作者正在配置中!
