功能简介

改变玩家血量

  •        设置初始血量√
  •         每升一级增加多少血量√
  •         限制玩家最大血量√
  •         自定义改变级别提示消息√
  •         自定义达到满血提示消息√
  •         支持提示消息彩色代码√
  •         无指令√
  •         级别下降时血量也会下降√
[redstone_torch] 配置文件说明
  1. [b]############################################################
  2. # +------------------------------------------------------+ #
  3. # |                 萌萌哒血量更改插件哟                 | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7. # 要给玩家HealthChange 权限 否则以下功能全部无效并没什么卵用
  8. # 设置玩家的初始血量 这里是0级的时候他的血量为多少

  10. Initial-Health: 20

  12. # 每升一级增加多少血量

  14. Level-Up: 1

  16. # 限制玩家的最大血量 最大不能超过多少

  18. Max-HP: 100

  20. # 下面这两个是级别改变时的提示消息 啦啦啦

  22. Level-Up-Messages: "&b[&6&l血量提升&b]&a您的级别已变化,您现在的最大血量为:&c %Level-Up%"

  24. Max-HP-Messages: "&b[&6&l血量提升&b]&a恭喜你已经达到最大血量上限,您现在的最大血量为:&c %Max-HP%"
