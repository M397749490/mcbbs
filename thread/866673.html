Jehkoba's Fantsy - 仙境幻想

作者原文：
  This is a personal project by Zack Simon (a.k.a. Jehkoba), influenced heavily by classic SNES JRPG's, tabletop roleplay, and low-res adventure games. It offers an illustrated, painterly style that brings more vibrancy of colour and warmer tones than the original textures.
This resoucepack complete with new vanilla-ready 3D models and variable textures for a number of blocks and items!Enjoy!

译文：
  这是Zack Simon（即 Jehkoba)的个人项目，灵感源于经典的SNES JRPG类游戏，桌游型角色扮演游戏和像素型冒险游戏，材质的整体风格可以带给使用者一种比原始材质更温暖，更多彩的游戏体验。
  本材质包对一些方块/物品有新的3D模型及可变化的材质纹理！享受它带给你的乐趣吧！

Install-材质安装

对正版用户:
1、关闭Minecraft，
2、在Windows资源管理器的路径中输入 %appdata%/.minecraft 。
3、把下载的材质包直接放到. minecraft\resourcepacks 文件夹里面。

对非正版用户：
1、打开游戏文件夹中的.minecraft，
2、把下载的材质包直接放到. minecraft\resourcepacks 文件夹里面。
