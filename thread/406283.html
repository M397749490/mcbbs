标题: Bungeecode跨服的切服登录问题。
按照大神的方法：
    如果你不会给登陆插件关联mysql，或者关联之后要重复输入登陆命令的话，请按照下面方法去做【这个方法不会用到Mysql】
　　　　　　　　１，给一台服务器安装上用户验证插件
　　　　　　　　２，给BungeeCord登录时强行连接到默认服务器的选项打开
　　　　　　　　３，好了，把这台服务器给设置成默认服务器就好了
依旧出现的问题：
    按照以上设置，应该是只用登一次就行了，可是返回大厅服的时候，总让再次输入登录，很烦。
    我当前有一个大厅，一个子服。大厅服安装有authme登录验证插件，子服叫s，没有安装验证插件。
    当登入后，在大厅服，传送到子服，正常，传送回大厅服，又需要输入登录密码。
    希望效果只登录一次，之后切服不要再不断输入密码了，如何实现呢。
    然后我的BC的配置如下：
groups:
  md_5:
  - admin
disabled_commands:
- disabledcommandhere
player_limit: -1
stats: 65b018ef-e467-4fc5-aa3b-df3521f8c834
permissions:
  default:
  - bungeecord.command.server
  - bungeecord.command.list
  admin:
  - bungeecord.command.alert
  - bungeecord.command.end
  - bungeecord.command.ip
  - bungeecord.command.reload
listeners:
- max_players: 1
  fallback_server: lobby
  host: 0.0.0.0:25565
  bind_local_address: true
  ping_passthrough: false
  tab_list: GLOBAL_PING
  default_server: lobby
  forced_hosts:
    pvp.md-5.net: pvp
  tab_size: 60
  force_default_server: true
  motd: '&1Another Bungee server'
  query_enabled: false
  query_port: 25577
timeout: 30000
connection_throttle: 4000
servers:
  lobby:
    address: localhost:25566
    restricted: false
    motd: '&1Just another BungeeCord - Forced Host'
  s:
    address: localhost:25567
    restricted: false
    motd: '&1survival'
ip_forward: false
online_mode: false
