作者: strawmaine    时间: 2012-5-30 07:24
“%ProgramFiles%\Java\jre6\bin\java.exe”   包括引号         （首先要保证C:\Program Files\Java\jre6\bin\java.exe这个路径是正确存在的）

整个BAT基本如下：
  1. @ECHO OFF
  2. SET BINDIR=%~dp0
  3. CD /D "%BINDIR%"
  4. "%ProgramFiles%\Java\jre6\bin\java.exe" -Xincgc -Xmx1G -jar minecraft_server.jar nogui
  5. PAUSE
