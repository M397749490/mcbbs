1 介绍数据类型

1.1 数据类型
操作系统根据变量的[ruby=data type]数据类型[/ruby]为其分配内存并决定存储什么样的数据。
数据类型规定了如何正确使用标识符、能存储什么样的数据、能进行什么操作。

C++内置许多数据类型。

你可以通过重载操作符来实现原本非法的表达式。关于这个我们之后会学。

1.4 字符串 & 字符
[ruby=string]字符串[/ruby]是由数字、字符、符号组成的。字符串的内容放在双引号中，例如"Hello"，"我叫David"等。
[ruby=Characters]字符[/ruby]是单个的字母或符号，必须放在单引号中，例如'a'、'b'等。

C++中，单引号标记字符，双引号标记字符串。'a'是一个字符，但"a"是一个字符串。

2 int，float，double

整型类型存储整数，可以是正数或负数。举例，42，-42等。

整型的大小取决于程序运行的系统架构，在现代系统上应该是4字节。

2.2 整型（二）
用int关键字定义整型数据。

包括整型在内的几种基础数据类型都可以使用下面的一个或多个属性[ruby=modifiers]修饰符[/ruby]：

2.3 浮点数
浮点类型可以存储实数，例如420.0，-3.33，0.03325。
“浮点”一词表示在小数点前后都可以出现数字。你可以说小数点有“飘浮”的能力。

有三种不同的浮点数据类型：[ruby=单精度浮点]float[/ruby]，[ruby=双精度浮点]double[/ruby]，和[ruby=长双精度浮点]long double[/ruby]。

在绝大多数现代计算机架构中，float占4字节，double占8字节，long double可能是double（8字节），也可能是16字节。
举例：

浮点数都是有符号的，意味着它们能存储非负数和负数。

4 变量命名规则

4.1 变量命名规则（一）
当给变量命名的时候，要遵循下面的规则：

  • 变量名必须以字母或下划线（ _ ）开头
  • 开头的字母后可以包含其他字母或数字。空格和特殊字符不允许作为变量名。

（Ps. 可以使用汉字作为变量名，但不可使用全角标点符号）

有两种约定俗成的命名方法：
[ruby=Pascal Case]帕斯卡拼写法[/ruby]：组成标识符的单词首字母全部大写，例如BackColor。
[ruby=Camel Case]骆驼拼写法[/ruby]：标识符首字母小写，组成标识符的其他单词首字母大写，例如backColor。

4.2 大小写敏感性
C++是[ruby=case-sensitive]大小写敏感[/ruby]的，意味着大写的标识符与同名的小写标识符不等同。
举例，myvariable，MYVARIABLE和MyVariable都不相同，它们是三个不同的变量。

起名时应该使其用途明了，例如firstName，lastName。

4.3 变量命名规则（二）
C++关键字（保留字）不能用作标识符。
举例，int、float、double、cout不能用作变量名。

事实上对变量名的长度没有限制（视不同系统而言），但是尽量确保变量名有实际意义。

5 数组

5.1 数组
[ruby=array]数组[/ruby]用来存储一系列数据，也可以将数组想象成相同类型的变量集合。
相比声明多个单独的变量存储单独的值，你同样可以可以用一个数组存储所有值。
当声明数组时，要规定其元素类型，还有其存储的元素数量。
举例：

int a[5];

上面的例子中，变量a被声明为能存储5个整型值的数组 [在方括号中规定] 。
可以在声明时给数组赋初值。

int b[5] = {11, 45, 62, 70, 88};

初值包含在{花括号}中，是一个由逗号分隔的列表。

花括号 { } 中值的个数必须不能超过方括号 [ ] 中定义的数组长度。

如果省略数组大小，那么会创建一个大小刚好能容纳全部初值的数组。
举例：

这创建一个与之前例子中相同的数组。

数组中的每个元素，或成员，都有其[ruby=index]索引[/ruby]，标注了元素的特定位置。
数组的第一个成员索引为0，第二个成员索引为1。
所以，这是我们之前定义的数组b：

9 初识指针

9.1 指针（一）
每个变量都是一块内存位置，有自己的[ruby=address]地址[/ruby]。
这个地址可以用[ruby=ampersand]and号[/ruby] (&)运算符（也叫[ruby=address-of]取地址[/ruby]运算符），它表示内存中的地址。
举例：
int score = 5;

cout << &score << endl;



//输出 "0x29fee8"

这会输出存储着变量score的内存地址。

9.2 指针（二）
[ruby=Pointer]指针[/ruby]是以其他变量的地址为值的变量。
在C++中，指针能使某些任务更容易执行。其他任务，例如动态内存分配，不能不用指针来完成。
所有的指针都是一样的数据类型——一个十六进制long，表示内存地址。
不同指针的区别只有指针所指向变量的数据类型。

10 再谈指针

10.1 指针运算

对于指针，有两种运算符：
[ruby=Address-of]取地址[/ruby]运算符 (&)：返回其操作数的地址。
[ruby=Contents-of]取内容[/ruby]（或[ruby=dereference]间接引用/间接访问[/ruby]）运算符 (*)：返回其操作数包含的地址存储的值。
举例：
int var = 50;

int  *p;

p = &var;



cout << var << endl;

// 输出 50（var的值）



cout << p << endl;

// 输出 0x29fee8 （var的内存地址）



cout << *p << endl;

// 输出 50 （指针p指向的变量的值）

星号(*)在声明中只是简单地表示这个变量是个指针（星号是声明类型的一部分）。不要将它与间接引用运算符混淆了，后者是用来获取某个地址中所存放的值。它们只是两种同类型操作的不同运算。

Part题：
填空声明变量x=25，指针p=x的地址。向屏幕输出指针包含的地址。
int x = 25;

int * p = _x;

cout << _ << endl;



10.2 间接引用

间接引用运算符(*) 基本就是指针所指值的别名。
话不多说，上例子：
int x = 5;

int *p = &x;



x = x + 4;

x = *p + 4;

*p = *p + 4;

上面三条语句效果相同，结果相同。我们可以通过间接引用变量的指针来访问变量的值。
由于p指向变量x，所以间接引用指针 (*p)与直接使用变量x完全一样。

Part题：
填空声明两个变量a，b；和两个指针pa，pb，分别指向a和b。通过指针pa改变a的值，通过指针pb将值加到b里。
int a = 12; int b = 13;

int * pa = &a;

int * pb = _b;

*pa += _pb; // 与a += b一样




11 动态内存

11.1 静态和动态内存

要成为一个成功的C++程序员，就不能不充分了解[ruby=dynamic memory]动态内存[/ruby]的原理。
在C++程序中，内存分两部分：
[ruby=stack]栈[/ruby]：你所有的[ruby=local variable]局部变量[/ruby]占用栈内存。
[ruby=heap]堆[/ruby]：未用到的内存，当程序运行时需要动态分配内存时使用这里的内存。
很多时候，你都不会察觉在用变量存储信息时所用内存大小，有时需要的内存大小可以在运行时再决定。
你可以用new运算符在堆中给变量分配一块内存，这个运算符返回所分配内存的地址。
new int;

这会在堆中分配一块足以存储一个整型大小数据的内存，并返回这个地址。

Part题：
填空来分配一个int变量大小的内存（用"new"关键字）：
_______;



11.2 动态内存（一）

分配的地址可以存在指针里，之后可以间接引用来访问其变量。
例子：
int *p = new int;

*p = 5;

我们给一个整型动态分配了内存，并给其赋值5。
指针p作为局部变量存储在栈中，它自身存储了堆中分配的地址。值5存储在堆中那个地址的位置。

Part题：
填空声明一个指向int的指针ptr，包含用new int;表达式返回的地址。
int _ ptr = new int;



11.3 动态内存（二）
对于栈中的局部变量，内存管理是自动进行的。
在堆中，就必须手动管理分配的内存，当不再需要它的时候用delete运算符释放这块内存。
delete pointer;

这条语句释放pointer指向的内存。
举例：
int *p = new int; // 申请内存

*p = 5; // 存值



cout << *p << endl; // 用值



delete p; // 释放内存

忘记释放用new关键字分配的地址会导致内存泄漏，因为那块内存在程序结束运行前会一直存在。

Part题：

11.4 悬垂指针
delete运算符释放给变量分配的内存，但并不删除指针本身，因为指针存储在栈上。
指向不存在的内存地址的指针叫做[ruby=dangling pointers]悬垂指针[/ruby]。
举例：
int *p = new int; // 申请内存

*p = 5; // 存值



delete p; // 释放内存

// 现在p是悬垂指针了



p = new int; // 重新申请新地址

NULL指针是有着值0的常量，在不少标准库中都有定义，包括iostream。
在声明变量时给其赋NULL是很好的习惯，以防你没有能分配给它的合适的地址。有值NULL的指针叫做空指针，举例：int *ptr = NULL;

11.5 动态内存（三）
动态内存也可以分配给数组。
举例：
int *p = NULL; // 用空值初始化的指针

p = new int[20]; // 申请内存

delete [] p; // 删除p指向的数组

注意语法中的方括号。
动态内存分配在很多情况下都很有用，例如当你的程序要依靠输入的时候。举个例子，当你的程序需要读取一个图像文件，它无法提前知道图像的大小，和存储这个图像所需的内存为多少。

12 sizeof() 运算符

12.1 sizeof
虽然对于不同的数据类型，所分配的内存大小由你的计算机架构决定，但C++对每种数据类型的大小都有一个最小限制：


分类
类型
最小内存大小
布尔bool1字节
字符char1字节
整数short2字节
int2字节
long4字节
long long8字节
浮点float4字节
double8字节
long double8字节


sizeof运算符可以用来获取变量或数据类型占用内存的大小，以字节为单位。
语法：
sizeof(数据类型)

sizeof运算符以字节为单位返回一个类型或一个变量的大小。
举例：
cout << "char: " << sizeof(char) << endl;

cout << "int: " << sizeof(int) << endl;

cout << "float: " << sizeof(float) << endl;

cout << "double: " << sizeof(double) << endl;

int var = 50;

cout << "var: " << sizeof(var) << endl;



/* 输出

char: 1

int: 4

float: 4

double: 8

var: 4

*/

输出在不同计算机和不同编译器上可能不同。

Part题：

12.2 数组大小
C++ sizeof运算符也能用来计算数组的大小。
还是举例：
double myArr[10];

cout << sizeof(myArr) << endl; 



//输出 80

在我们的电脑上，double占8字节。由于数组存储10个double，所以整个数组占80 (8*10) 字节内存。
另外，用整个数组占用的内存大小除以数组中单个元素的大小就能得到数组中元素个数。
例例例：
int numbers[100];

cout << sizeof(numbers) / sizeof(numbers[0]);



// 输出 100
