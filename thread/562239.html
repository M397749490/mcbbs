Tree Generator
Tree Generator有什么用？
Tree Generator是一款让你生成不同的树的插件，它可以一键生成Minecraft中所有的树，包括大型的、小型的、蘑菇树等。
Tree Generator最大的便捷之处是支持GUI。

Tree Generator的特性
  • 可生成Minecraft中所有的树木，包括蘑菇树。
  • 权限系统。
  • 可用GUI来更改要生成的树的类型。
  • 可自定义打开GUI的物品。
  • 容易使用。

Tree Generator如何使用？
Tree Generator的权限：TreeGenerator.gui。（默认OP拥有）
  • 点击一个粘液球选择你所需要生成的树。（点击你所需要生成的树即可；下方的绿色染料为当前要生成的树）
  • 在GUI中领取一个魔杖。（点击右下角的木棍）
  • 点击任一一个你想生成树的地方。
在cofing中可以设置打开GUI的物品。
