BookMOT
它是一个简单的插件，用于在图书图形用户界面中向Sponge服务器玩家显示“每日消息”
聊天中可用的任何类型的文本也可以在书中显示
包括可点击文本等...
权限
无
指令
无
配置文件
我稍微解释了一下 仅供参考
  1. motd {
  2.     # 目前的插件版本，使用此版本会向没有看到过它的玩家显示消息 也就是和第一次进服差不多
  3.     version=1
  4.     # 书GUI界面的自定义内容
  5.     book {
  6.         # 这本书的署名
  7.         author {
  8.             color=green
  9.             text=windy
  10.         }
  11.         # 页面列表
  12.                 #可以用此格式来增加页面数量 记住要和上面所列举出的格式一样
  13.         pages=[
  14.             {
  15.                 color=gold
  16.                 text="欢迎来到此服务器"
  17.             },
  18.             {
  19.                 clickEvent {
  20.                                  #动作=打开链接
  21.                     action="open_url"
  22.                                  # 内容
  23.                     value="https://spongepowered.org可替换链接"
  24.                 }
  25.                                  #颜色
  26.                 color=blue
  27.                                  #文本
  28.                 text="Click me!"
  29.                                  #下划线是否开启
  30.                 underlined=true
  31.             },
  32.             {
  33.                 color=red
  34.                 hoverEvent {
  35.                                  #动作=显示文本
  36.                     action="show_text"
  37.                                  #内容
  38.                     value="boo!"
  39.                 }
  40.                 italic=true
  41.                 text="Hover me!"
  42.             }
  43.         ]
  44.         # 书的标题
  45.         title {
  46.             color=aqua
  47.             text="每日信息
  48.         }
  49.     }
  50. }
