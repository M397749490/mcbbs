指令

  1. 命令
  2.         #命令语法
  3.         mv [FILTER] [PAGE #]
  4.         #发送版本信息至控制台
  5.         mv version -[pbg]
  6.         #列出所有世界名称
  7.         mv list
  8.         #列出综合信息
  9.         mv info [WORLD] [PAGE]
  10.         */mv info [世界名称] [页码]
  11.         #创建世界
  12.         mv create {名字} {环境} -s [种子] -g [生成器[:ID]] -t [生成器] [-n] -a [true|false]
  13.         #复制某个世界
  14.         mv clone {目标} {名字} -g [生成器[:ID]]
  15.         #转换某个世界的类型
  16.         mv import {名字} {环境} -g [生成器[:ID]] [-n]
  17.         #重新加载配置文件
  18.         mv reload
  19.         #重置当前世界的默认出生点为脚下
  20.         mv setspawn
  21.         #显示当前位置信息
  22.         mv coord
  23.         #将完价传送至某世界 出生点请参考 Setspawn 命令
  24.         mv tp [PLAYER] {世界}
  25.         #查看指定世界有哪些玩家
  26.         mv who [WORLD|--all]
  27.         #将玩家传送至某世界 出生点请参考 setspawn 命令
  28.         mv spawn [PLAYER]
  29.         #卸载某个世界 这个指令不会删除该世界文件夹。也不会删除config配置文件内的时杰信息；
  30.         mv unload {世界}
  31.         #加载某个世界
  32.         mv load {世界}
  33.         #卸载某个世界并移除World.yml 内的世界信息，这个命令不删除该世界文件夹
  34.         mv remove {世界}
  35.         #删除服务器内的某个世界
  36.         mv delete {世界}
  37.         #重新生成某个世界，将会清空世界内所有方块；
  38.         mv regen {世界} [-s [SEED]]
  39.         */mv regen [世界名称] -s [种子]
  40.         *不带-s 使用原有种子重置世界
  41.         #等待系统提示使用此命令时候，输入此命令；如系统不提示该命令无任何效果；
  42.         mv confirm
  43.         #修改世界的参数设置；
  44.         mv modify {set设置|add添加|remove移除|clear清除} ...
  45.         mv modify add {值} {设置} [WORLD]
  46.         mv modify set {设置} {值} [WORLD]
  47.         mv modify remove {设置} {值} [WORLD]
  48.         mv modify clear {设置} [WORLD]
  49.         #清除某世界的生物
  50.         mv purge [WORLD|all] {all全部|animals动物|monsters敌对怪物|生物名}
  51.         #修改全局设置 建议手动修改配置文件后重新加载配置文件
  52.         mv config {项目} {变量}
  53.         #列出世界上的锚点
  54.         mv anchor {名字} [-d]
  55.         #列出可用的世界类型和环境类型
  56.         mv env
  57.         #在控制台显示调试信息，需要开启调试模式
  58.         mv debug [1|2|3|off|silent]
  59.         #打开或关闭服务器启动时加载信息；
  60.         mv silent [true|false|on|off]
  61.         #列出生成器插件 默认无插件
  62.         mv generators
  63.         #检查玩家权限是否允许去某地
  64.         mv check {玩家} {目的地}
  65.         #运行一个脚本
  66.         mv script {脚本} [目标]
  67.         mv gamerule {RULE} {VALUE} [WORLD]
  68.         mv gamerules [WORLD]
