你是要判断传送的类型吧

使用PlayerTeleportEvent事件
if (event.getCause() == TeleportCause.END_PORTAL) {
}
以下内容来自中文doc
CHORUS_FRUIT
由紫影果进行传送.
COMMAND
由命令进行传送.
END_GATEWAY
由末地折跃门进行传送.
END_PORTAL
由末地传送门进行传送.
ENDER_PEARL
玩家抛出末影珍珠传送
NETHER_PORTAL
由地狱传送门进行传送.
PLUGIN
由插件进行传送.
SPECTATE
由旁观者菜单传送到一个实体/玩家.
UNKNOWN
由除已知枚举外的其他情况进行了传送.
