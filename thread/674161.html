Reporting1058 Version 0.1.3
黑科技举报系统

一、简介 Description
论坛内最完美的插件，各种黑科技，举报系统完善，大型服务器使用的插件！作者是天空巨人SkyGiant的作者！      新版本重新排了模板&加了快速传送到指定服务器

二、功能 Features
·举报提醒
·大标题&物品栏上方提醒
·可查看列表
·完整信息
·举报排行
·可反馈玩家举报
·显示所在服务器

四、指令&权限 Command&Permission
/report <玩家> <原因>
[举报玩家]

/reports <页码>
[查看举报列表] 权限: reporting.list

/areports <页码>
[查看待处理列表] 权限: reporting.list

/reports <玩家> <页码>
[查看指定玩家举报列表] 权限: reporting.list

/delreport <id>
[删除举报] 权限: reporting.delete

/reportinfo <id>
[查看详细举报信息] 权限: reporting.info

/closereport <id> <原因>
[将id调为已处理 并反馈举报] 权限: reporting.close

/mostreported <页码>
[举报排行] 权限: reporting.list

/closereports
[将所有所有举报调成已处理] 权限: reporting.closeall

/rreload
[刷新Config文件]reporting.antirepory

/rhelp, /reporting, /reporting1058 - 主指令&查看所有指令

友情提醒:
你的管理员必须要有reporting.receive权限才能收到举报提醒
