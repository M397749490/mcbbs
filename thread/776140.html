重点到了
使用方法
/gr zm 召唤僵尸
/gr cp  召唤爬行者
/gr sl 召唤小白
/gr sd 召唤蜘蛛
/gr vg 召唤村民
/gr reload 重载插件
/gr help 插件帮助




配置文件的使用教程
ZM:
  damage: 1   伤害设置
  name: §4僵尸  怪物名字设置
  MaxHealth: 20  怪物的最高血量设置
