  14.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  15.   # 你加载了一次Essentials后,就可以在plugins/Essentials/items.csv中找到物品ID列表.
  16.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶

  27.     # 阻止玩家使用以下物品
  28.     usage: 327

  30.     # 阻止玩家破坏以下方块
