今日知识

  • 八种基本数据类型的取值范围
类型              取值范围
-------------------------------
byte            [-128~127]
short           [-32768~32767]
int             [-2147483648~2147483647]
long
float
double
boolean         [true,false]
char            [0~65535]

注意：short和char所表示的种类总数是一样的，只不过char可以表示更大的正整数
因为char没有负数

  • 八种基本数据类型的默认值
数据类型                    默认值
----------------------------------
byte,short,int,long         0
float,double                0.0
boolean                     false 【在c语言中，true是1，false是0】
char                        \u0000

八中数据基本类型的默认值是一切向0看齐
