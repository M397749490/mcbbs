作者: antecer    时间: 2014-8-30 18:39
在config文件夹里面找到IC2.ini文件，打开，找到如下这段：
  1. [protection]
  2. ; Enable logging of players when they remove a machine using a wrench.
  3. wrenchLogging = true
  4. ; Maximum Explosion power of a nuke, where TNT is 4.
  5. nukeExplosionPowerLimit = 60
  6. ; Maximum explosion power of a nuclear reactor, where TNT is 4.
  7. reactorExplosionPowerLimit = 45
  8. ; Enable the nuke
  9. enableNuke = true
复制代码

nukeExplosionPowerLimit 就是核弹的最大爆炸威力，普通TNT的爆炸威力是4；
reactorExplosionPowerLimit 是核反应堆的最大爆炸威力。
