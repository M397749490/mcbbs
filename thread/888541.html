PixelGenocide

它可以做什么？
这个插件通过定时清理各个世界的野生宝可梦来减少服务器资源消耗。

当然不仅仅是普通的宝可梦，这里有个列表，它们都是可以配置的
  • 闪光
  • 神兽
  • BOSS
  • 宝可梦和宝可梦病毒！
  • 黑名单中的宝可梦！ 例如我们不想要超音蝠，即使它是异色的！
  • 白名单中的宝可梦，可填写稀有的宝可梦，例如伊布。
  • 拥有权限的玩家附近的宝可梦将不会被清除。
  • 带有粒子特效的宝可梦不会被清除。

如何使用？
/pixelgenocide clean  清除所有世界
/pixelgenocide clean <world> 清除指定世界
权限分别为：
pixelgenocide.command.cleanpixelmon
pixelgenocide.command.cleanpixelmon.<world_name>

配置文件：
  1. # 是否应该保留这些宝可梦。
  2. keep {
  3.     # 不管它们的大小属性如何，删除这些宝可梦。
  4.     blacklist=[
  5.         Zubat,
  6.         Geodude,
  7.         Caterpie
  8.     ]
  9.     bosses=true
  10.     legendaries=true
  11.     shinies=true
  12.     # 保持这些宝可梦，不管他们的大小属性。
  13.     whitelist=[
  14.         Pikachu,
  15.         Eevee,
  16.         Ditto
  17.     ]
  18.     # 这将需要实体粒子才能工作。
  19.     withParticles=false
  20.     withPokerus=true
  21.     # 开启后不会清除拥有权限 picelgencide.Specialplayer 的玩家附近的宝可梦。警告：可能会影响性能。
  22.     withinSpecialPlayer=false
  23. }
  24. miscellaneous {
  25.     # 下面配置多久清除一次宝可梦。有关详细信息，请参阅keep.withinSpecialPlayer。
  26.     maxSpecialPlayerBlocks=100
  27.     message {
  28.         # 你可以用 %quantity%.
  29.         cleaned="&7%quantity% 个宝可梦已经被清理了"
  30.         # 你可以用 %timer%.
  31.         timer="&4所有宝可梦将在 &c%timer% 秒后清除&4."
  32.     }
  33.     timer="10=MINUTES"
  34. }
