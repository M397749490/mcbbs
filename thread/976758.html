指令：


/insights
  • help - 插件帮助
  • block - 返回手中物品的名字 便于腐竹查找
  • hooks - 查看挂钩插件列表
  • reload - 重载插件
/check
[size=14.6667px]- 在你所在的区块进行一次快速查找


/checkworlds
[size=14.6667px] - 对整个服务器进行一次快速查找


/autoscan
  • enable [block|entity] - 开启自动查找（对你所在的区块）
  • disable - 关闭自动查找
/scan
  • custom [block|entity] ... - 查找当前区块中的自定义内容 [方块名/实体名]
  • entity - 查找当前区块内的实体
  • tile - 查找当前区块内的容器
  • all - 查找当前区块中的一切目标
/scanradius <区块范围>
  • custom [block|entity] ... - 对半径内的目标进行一次自定义查找 [方块名/实体名]
  • entity - 查找半径内的实体
  • tile - 查找半径内的容器
  • all - 查找半径内的所有目标
/scanworld <世界名>
  • custom [block|entity] ... - 对世界进行一次自定义查找 [方块名/实体名]
  • entity - 查找世界中的实体
  • tile - 查找世界中的容器
  • all - 查找世界已加载区块中的所有目标
/cancelscan
[size=14.6667px] - 结束查找


/togglecheck
[size=14.6667px] - 切换实时更新状态

赶紧补上（误）

  • insights.* - 插件一切权限
  • insights.check.realtime - 实时更新权限
  • insights.notification.update - 拥有这个权限会收到更新提示
  • insights.regions.bypass.<物品> - 无视方块限制权限
/insights

/autoscan
  • insights.autoscan.<block|entity> - 自动查找的权限
/scan
  • insights.scan.* - 下面的所有权限
  • insights.scan.entity - 查找当前区块内实体权限
  • insights.scan.tile - 查找当前区块内容器权限
  • insights.scan.custom.<block/entity/'ALL'> - 查找当前区块内自定义目标的权限
/scanradius
  • insights.scanradius.* - 下面的所有权限
  • insights.scanradius.entity - 查找当前半径内实体权限
  • insights.scanradius.tile - 查找当前半径内容器权限
  • insights.scanradius.custom.<block/entity/'ALL'> - 查找当前半径内自定义目标的权限
/scanworld
  • insights.scanworld.* - 下面的所有权限
  • insights.scanworld.entity - 查找世界范围内实体权限
  • insights.scanworld.tile - 查找世界范围内容器权限
  • insights.scanworld.custom.<block/entity/'ALL'> - 查找世界范围内自定义目标的权限
/cancelscan
[size=14.6667px]- 无须权限


/togglecheck
