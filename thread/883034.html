用System.nanoTime()，
比如：
public class timer{
  public static void main(String[] args){
  while(true)
  {
  long start=System.nanoTime();
  try{
  Thread.sleep(1000);
  }catch(Throwable e){}
  System.out.println(System.nanoTime()-start);
  }
  }
}
这样正常情况下输出的值应该在900000000到1010000000之间，如果加速500倍就会输出500000000000左右的值
