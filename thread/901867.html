前言：
这是一个历史悠久的商城插件，最开始只在宝可梦附属mod发布，后面改到了sponge的官方网页发布。

说明：
其他前置任意经济插件、Nucleus插件，此处不提供链接

本插件由三个部分构成，有两个为必须插件，其余为自行选择。

前置插件——Impactor API
下载地址：https://ore.spongepowered.org/NickImpact/Impactor-API/versions
插件本体——GTS
下载地址：https://ore.spongepowered.org/NickImpact/GTS/versions
重铸宝可梦附属——GTS Reforged Bridge
下载地址：https://ore.spongepowered.org/Ni ... ged-Bridge/versions
世代宝可梦附属——GTS Generations Bridge
下载地址：https://ore.spongepowered.org/Ni ... ons-Bridge/versions

前置和本体为必须插件，而重铸和世代附属二选一，或者可以不安装。

若只安装前置和本体，那么插件和其他的全球商城并无不同，添加宝可梦附属后即可出售宝可梦。

拍卖功能已经被作者阉割

权限&指令：

玩家指令
/gts——打开商城——gts.command.gts
/gts sell——出售——gts.command.sell
/gts sell item——出售物品——gts.command.sell.item
/gts sell pokemon——出售宝可梦——gts.command.sell.pokemon
/gts ignore——忽略广播——gts.command.ignore
管理员指令
/gts admin clear——清理商城物品——gts.command.admin.clear
