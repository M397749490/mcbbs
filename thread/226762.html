【插件的使用方法】

【给玩家的使用说明】（版本0.1.1）
1.你要先设置一个传送点，参照下面的命令
   - 如果你是在控制台，你必须写明白坐标和世界
   例子：/st c 123 150 60 150 world
              /st c ------- 命令名字
               123 ------- 传送点名字
    150 60 150 ------- 所在xyz坐标，可选
           world  ------- 所在世界名字

2.然后你放一个牌子，要确认牌子周围有至少两米高的位置让人站（卡死不负责）
   牌子的内容下面是一个例子：
[第一行] >            [SignTp]             < 注意大小写别写错
[第二行] >               123                 < 这个是传送点名字
[第三行] >    要搞基的来这边！！    < 这一行随便写，空着也没事
[第四行] >      嗷呜！！！！！         < 同上 【吐槽：这两行字内容= =】
3.然后敲一下牌子即可传送 【吐槽：飞喽~】
4.要删除传送点，请使用 /st d <传送点名字>，删除后对应传送牌将不起作用
上面的东西忘了，可以用 /st help 和 /st signhelp 来查看。【给管理员的使用说明】
1.想要列出所有的传送点，请使用 /st l ；想要查看某个传送点信息，请使用 /st i <传送点名字> 。
2.如果想要批量修改传送点，你可以先修改 /plugins/SignTp/point.yml ，然后使用 /st reconfig 来重载传送点文件。
3. /st tp <传送点名字> [玩家名字] 可以让某个人飞到传送点，调试的时候较为方便。
4. /st checkupd 可以查看更新，仅控制台有效。

 【测试版使用说明】（版本0.2.0）

【给玩家的使用说明】
- 创建一个飞到世界出生点的牌子
1.放置一个牌子，内容如下：
[第一行] >            [SignTp]             < 注意大小写别写错
[第二行] >            w:world            < world是目标世界名字
[第三行] >        飞到world世界        < 这一行随便写，空着也没事
[第四行] >      呵呵，敲一下我         < 同上

- 创建一个飞到warp点的牌子
1.使用SimpleWarp创建一个warp点
2.放置一个牌子，内容如下：
[第一行] >            [SignTp]             < 注意大小写别写错
[第二行] >               123                 < 这个是warp点名字
[第三行] >    要搞基的来这边！！    < 这一行随便写，空着也没事
[第四行] >      嗷呜！！！！！         < 同上
3.然后敲一下牌子即可传送
【给管理员的使用说明】
1.如果想要批量修改传送点，你可以先修改 /plugins/SimpleWarp/warps.yml ，然后使用 /st reconfig 来重载传送点文件。
2. /st checkupd 可以查看更新，仅控制台有效。
