这个是格式
  1. list顯示名字:
  2.     Item_Information:
  3.           Item_Name: 拿在手的名字
  4.           Item_Type: 物品ID 有附加值的要用 ~ 代替 :
  5.           Item_Lore: 介紹 用 | 來分行                    Inventory_Control: <group>,(...)  (新功能 不知怎用 功能是可以限制放在快捷欄的槍械數目)
  6.           Melee_Mode: <true/false> (近戰模式 設置為 true 則用此物品攻擊可以有與此物品發射的子彈的效果 作者提醒要小心使用, 需要過濾一些無關的設定) (當近戰模式開啟 就代表此武器不能再發射子彈, 亦可以作為一個近戰附件(填在下面的 Melee_Attachment: <武器顯示名字>), 本武器支持彈藥及裝填的設定 但不理會 Firearm_Action: 這一設定[彈藥用量將以每擊計算], Delay_Between_Shots: 將變為代表每次武器可攻擊別人之間的間隔, 爆頭判定亦會被忽略 因無法檢測,  Damage_Based_OnFlight_Time 此設定也會被忽略 因無飛行時間)          Melee_Attachment: <weapon title> (只能填一些 Melee_Mode: true 的武器)
  7.                //關於近戰模式 可以參考預設武器 Python 及 Tactical Knife (melee attachment)  後者是戰術刀(肉搏強件)
  8.           Attachments: (有配件才要這一項)
  9.                 Type: <main> OR <accessory> (是主武器或是配件 卡實便是有一把main一把accessory (M320))
  10.                 Info: <weapon title> (配件槍的名字)
  11.                 Toggle_Delay: <ticks> (轉換間隔 以刻做單位 20刻=1秒)
  12.                 Sounds_Toggle: <sound>,(...) (轉換聲音)
  13.                  //關於主武器與配件 可參考預設槍械 卡賓 及 M320
  14.          Enchantment_To_Check: <ENCHANTMENT-LEVEL> (此行代表有某物品同時符合 Item_Type 及 Enchantment_To_Check 所指的ID及附魔屬性 即會變成此槍)
  15.          Skip_Name_Check: <true/false>   (無視名稱是否一樣 即會做成PVPGun+ 一樣的同ID就變槍的情況)         
  16.          Sounds_Acquired: <sound>,(...)         (當一名玩家使用/shot get 或 從牌子商店買入此槍時 使聽到的聲音)
  17.          Remove_Unused_Tag: <true/false>   (設為true時任何有 ?×? 會從武器名字刪除 當該武器有使用 Firearm_Action 設定則此行不會生效)
  18.          Hidden_From_List: <true/false>   (估計是 是否從 /cs list all 指令中隱藏)
  19.     Shooting:
  20.          Disable: <true/false> 是否關閉 true 即是該不能發射子彈 false或沒有此行即可發射 (戰術盾牌便有設置為 true)
  21.          Dual_Wield: <true/false> 是否雙持 true=是 false或沒有此行 = 不是
  22.          Right_Click_To_Shoot: <true/false>  true 即是右按開槍
  23.          Cancel_Left_Click_Block_Damage: <true/false> 是否刪去左按功能(即持續左按可以破壞方塊) 有瞄準的槍要使用
  24.          Cancel_Right_Click_Interactions: <true/false> 同上 只是這個是右按功能(例如手持此行為true的槍便不能按按鈕)
  25.          Delay_Between_Shots: <ticks(number)> 每發多少刻延遲
  26.          Recoil_Amount: <amount> 後座力大小(作者建議設置為1-10) 0即是沒後座力
  27.          Projectile_Amount: <amount> 每槍的子彈的數目(例如散彈便要設大於1)
  28.          Projectile_Type: <snowball/arrow/egg/grenade/flare/fireball/witherskull/energy/splash>   (子彈類別 雪球/弓箭/蛋/榴彈/轟擊信標/火球/凋零頭/能量/投擲藥水)
  29.          Projectile_Subtype: <itemID> OR <itemID~data> OR <energy info> OR <true/false> (適用於 grenade, flare, fireball, splash)
  30.             (grenade 及 flare : 投擲的物品ID(必要!!!)    splash(可選): 投擲的藥水ID(只改變顏色 並不帶效果的)   fireball(可選) : <true/false> 如果是true 則火球不能被打回)
  31.           (以能量為子彈 格式為 Projectile_Subtype: RANGE-RADIUS-WALLS-VICTIMS   分別是 大小-射程-穿牆(取消輸入none 全部輸入 all 其他就輸入數字)-穿人(0為不穿過所有擊中             的生物)
  32.          Remove_Arrows_On_Impact: <true/false> (Projectile_Type: arrow 時可使用 true代表當射出來的箭碰地即消失)
  33.          Remove_Bullet_Drop: <true/false> (只有 Projectile_Type 是 雪球 蛋 箭 此行才有效 true代表此3類子彈經此槍發射不會受到重力所影響 即會以一條直線移動)
  34.          Removal_Or_Drag_Delay: <delay-removal>  (當過了一定刻數此子彈會被移除或被大幅減速 用法 <刻數-true/false>  true代表移除 false代表被減速 此行可不填)
  35.          Projectile_Speed: <amount>  投射物速度 (不建議大於40)
  36.          Projectile_Damage: <amount>  被投射物擊中的傷害
  37.          Projectile_Flames: <true/false>  (true 代表投射物在射出時會帶有火 只對雪球 蛋 箭 藥水 有影響)
  38.          Projectile_Incendiary:  (燃燒彈設定)
  39.                Enable: <true/false>  (是否開啟  開了即代表所有子彈都會令目標著火)
  40.                Duration: <ticks>      (著火持續時間)
  41.          Bullet_Spread: <amount> (這並非是準確度而是擴散 一般來說這設定是給散彈槍用)(愈接近0代表愈精確 建議0-10 因高於10有可能令子彈向後飛)(此設定支持小數位即可以                                                      2.354,0.2256 等)
  42.          Reset_Fall_Distance: <true/false>  (設置為 true 代表使用此槍不會做成跌落傷害)
  43.          Sounds_Projectile: <sound>,(...)  (投射物的聲音 可以用來作手榴彈爆炸聲音或蜂鳴器
  44.          Sounds_Shoot: <sound>,(...)   (射擊時的聲音)
  45.     Sneak:   (蹲時的特別加成)
  46.          Enable: <true/false>  (是否開啟)
  47.          No_Recoil: <true/false> (蹲下時取消後座力  true 代表開)
  48.          Bullet_Spread: <amount> (蹲下時子彈的準確度 支持小數位)
  49.          Sneak_Before_Shooting: <true/false> (true 代表玩家只能在地上蹲著才有以上效果 在空中蹲不會有此效果)
  50.     Burstfire:  (連射)
  51.          Enable: <true/false>  (是否開啟 單次連射(即按一下連射幾顆子彈 建議用在一些 高射速槍械 例如AK-47)
  52.          Shots_Per_Burst: <amount> (每次連射子彈數量)
  53.          Delay_Between_Shots_In_Burst: <ticks> (連射時每顆子彈之間的間隔)

  55.     Ammo:  (子彈相關)
  56.          Enable: <true/false>  (是否開啟)
  57.          Ammo_Item_ID: <itemID> OR <itemID~data>  (子彈的ID)
  58.          Take_Ammo_Per_Shot: <true/false>  (每發射擊都扣除子彈物品)
  59.          Sounds_Out_Of_Ammo: <sound>,(...)  (當背包中可用作裝填此槍的子彈用完的聲音)
  60.          Sounds_Shoot_With_No_Ammo: <sound>,(...)  (無子彈時射擊的聲音)

  62.    Reload:  (裝填相關)
  63.          Enable: <true/false>  (是否開啟)
  64.          Reload_With_Mouse: <true/false>  (當設置為 true就只能用左右鍵裝填 Q或丟東西的按鍵則不再有裝填武器的功用 會恢復回丟東西/武器的功能)
  65.          Starting_Amount: <amount>   (當第一次獲得時的彈藥數量)
  66.          Reload_Amount: <amount>    (裝填後的子彈數量)
  67.          Reload_Bullets_Individually: <true/false> (當設置為true時 代表此槍是一發接著一發裝填 而不是直接換彈匣 類似獵槍 左輪手槍)
  68.          Take_Ammo_On_Reload: <true/false> (當設置為 true代表裝填時才會拿走彈藥ammo)
  69.          Take_Ammo_As_Magazine: <true/false> (設置為true代表ammo的ID是一個彈匣而不是一粒子彈 所以設置為true時 雙槍裝填一次會扣2個 而其悖
  70.          Reload_Duration: <ticks>  (完整裝填需要的時間)
  71.          Destroy_When_Empty: <true/false> (當所有彈藥用光, 包括可裝填的 就會自我毀滅)
  72.          Sounds_Out_Of_Ammo: <sound>,(...)  (當彈匣中子彈用光的聲音 (與在ammo中的不同 這是指槍械自身 不是指背包)
  73.         Sounds_Reloading: <sound>,(...)  (裝填時的聲音)
  74.     Dual_Wield:  (用於當一把雙持武器只有一邊的子彈用光時裝填的特例)
  75.         Single_Reload_Duration:  <ticks> (單一把槍裝填的時間)
  76.         Sounds_Single_Reload: <sound>,(...)  (單一把槍裝填時的聲音)
  77.         Sounds_Shoot_With_No_Ammo: <sound>,(...) (單一把槍彈匣內子彈用光的聲音)

  79.    Firearm_Action:  (槍支發射時的方式)(此設定需要一些與槍械有關的知識)
  80.        Type: <slide/bolt/lever/pump/break/revolver>  分別是 滑動 / 螺栓 或 槓桿 / 泵動 / Break沒找到接近解釋 / 左輪

  82. 滑動: 指槍械具有滑動機關 或 充電手柄 狀態分為不鎖定 (■) 和鎖定 (□) (譯者: 類似安全扣的那東西 要先解開鎖定才能發射子彈) 當武器彈匣的子彈用光 螺栓會鎖定並由■退到□ 如果想重新繼續射擊 除了裝填外 亦要將 螺栓由 □推回 ■


  85. 螺栓 或 槓桿: 指有螺栓行動或槓桿作用的槍械 分為3種狀態 子彈在彈膛內(■) 彈殼在燃燒室中 (□) 空彈膛 ( _ )   每次子彈發射後 螺栓或槓桿都需要打開再關閉 籍此裝填新一顆子彈進入  同時子彈裝填只能在 空彈膛 的狀態下進行

  87. 泵動: 與螺栓或槓桿一樣 分別只在於不需要在空彈膛下裝填 類似獵槍的結構

  89. Break及左輪: 當裝填時 需要將武器打開(□) 然後裝填完後再關上 (■)


  92. (當使用 泵 螺栓 槓桿 將侯用 Open_Duration Close_Duration 及 Close_Shoot_Delat 來確定連射速度 而不是之前的 Delay_Between_Shots)
  93.        Open_Duration: <ticks>  (除了滑動外都需要此設定 代表打開的所需時間)
  94.        Close_Duration: <ticks>  (全都需要此行 代表關上的所需時間)
  95.        Close_Shoot_Delay: <ticks>  (關上後與第一發子彈可發射的間隔時間 包括重新舉槍那些時間0.0)
  96.        Sound_Open: <sound>,(...)  (打開時的聲音)
  97.        Sound_Close: <sound>,(...)  (關上時的聲音)
