作者: CR_019    时间: 2020-7-21 09:04

例：一个木棍和一个凋零骷髅头在铁块上合成木剑：
高频命令方块：
  1. execute as @e[type=item,nbt={Item:{id:"minecraft:stick",Count:1b},OnGround:1b},limit=1] at @s if block ~ ~-1 ~ minecraft:iron_block if entity @e[type=item,nbt={Item:{id:"minecraft:wither_skeleton_skull",Count:1b},OnGround:1b},distance=..2] run tag @s add 1
复制代码
后面连锁：
第一个：
  1. kill @e[type=item,,distance=..2,nbt={Item:{id:"minecraft:wither_skeleton_skull",Count:1b},OnGround:1b},limit=1]
复制代码
第二个：
  1. execute as @e[tag=1] at @s run summon minecraft:item ~ ~ ~ {Item:{id:"minecraft:wooden_sword",Count:1b}}
复制代码
第三个：
  1. execute as @e[tag=1] at @s run kill @s
复制代码

另外实在搞不懂为什么不用数据包这种性能又高操作还方便的东西，这种合成用两个函数就完事了。。。
