标题: 关于物品的Lore问题
新建一个物品,想让他的Lore可以在config中写并且可以自定义行数

                            ItemStack i = new ItemStack(351);
                            ItemMeta id = i.getItemMeta();
                            id.setDisplayName(getConfig().getString("cs1N"));
                            ArrayList lore = new ArrayList();
                            lore.add(getConfig().getList("cs1Lore"));
                            id.setLore(lore);
                            id.addEnchant(Enchantment.OXYGEN, 1, true);
                            i.setItemMeta(id);

奉劝一句：想开发插件，就得先学好java！
这个其实很简单(看来楼主的java基础不扎实)：正解了就吱一声哈。
  1. String lore; //创建一个字符串,创建行lore需要用使用for循环
  2. for (Iterator iterator = getConfig().getStringList("Lore").iterator(); iterator.hasNext(); lore.add(lore.replace("&", "§")))
  3.                         lore = (String)iterator.next();   //lore是你的变量Lore名
