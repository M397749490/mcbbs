你好，在创建potionEffect后，需要将此药水效果发回给玩家才能使用
如：
  1. import org.spongepowered.api.data.manipulator.mutable.PotionEffectData;
  2. import org.spongepowered.api.entity.living.player.Player;

  4. PotionEffectData effects = player.getOrCreate(PotionEffectData.class).get();
  5. effects.addElement(potion);
  6. player.offer(effects);
