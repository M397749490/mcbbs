标题: 新手服主开服教程
前言
开一个MC服务器很简单，只是将核心与插件的互相整合，但你以为就这样结束了？不，开一个服务器，讲究的不是它是否开启，而实是否用心。只有用心的服务器，才能够在茫茫服务器中，成为最优秀，最值得玩家喜爱的服务器。但，是否开的好，这就是个难点了


第一章
服务端的选择
服务端的选择要考虑以下几个问题：
    版本？
    所需配置？
    玩家的喜爱程度？
    特性？
这几个问题需要着重考虑
版本一旦对不上
那么不但玩家不喜欢，插件也可能不支持（支持高版本的辅助性插件太少了）
版本越高，配置要求越高


在这里推荐大家使用spigot1.12.2
不但支持插件多，并且配置要求低，对玩家的配置要求也低
下载也方便
这里附上下载地址：https://getbukkit.org/download/spigot
可以前往去下载
（下载来一个后缀名为.jar的文件，不要解压！）



第二章
服务端的使用
注意：本章节分为两部分，第一部分适用于Windows，第二部分适用于linux系统，两系统不同，千万不可混用
必须有网络知识基础，比如理解什么是内外网，什么是IPv4

Windows篇：
    首先，你得确保你的配置充足：
    系统：Windows2000以上版本
    内存：大于1024MB
    处理器：一核心以上，并且主频在1.5Ghz以上
    前置环境：Java8及以上（下载地址：https://www.java.com/）
准备以上之后，确定你的服务端的位置，比如D:\xxx\xxx\spigot.jar（路径随意，但不可以在桌面直接运行；文件名称可能不同，但后缀不能删）


    随后我们新建一个文档，命名为runserver.txt
    打开文档，输入以下内容：
    Java -Xmx1G -Xms256MB -jar D:\xxx\xxx.jar（文件路径）
    Pause
其中“-Xmx”后面所跟的为你设置的最大内存
“-Xms”后面跟的为你设置的最小内存


   随后另存为，将其后缀更改为.bat（Windows可执行脚本）
   然后双击运行，会发现他让你同意一个叫eula的东西
   我们关闭命令提示符，来到脚本所在文件夹，会发现有个名为“eula.txt”的文件。打开，将第三行的“false”改为“true”


   再次运行脚本，会发现服务器开始正常运行了，并且生成了三个世界


就这样，最基础的服务端就制作完成了（关于内外网通信，我后面一个章节会讲）
Linux篇：
首先，确定你的系统。Linux系统主要分为centos，ubuntu，debian这三个系统，每个系统的命令都不相同。在这里，我们推荐使用debian，原因：
1，命令简单易懂
2，有可选的图形化界面
3，大部分系统安装了JDK以及编辑器，无需再次安装
4，系统配置占用小
      （当然，你也可以用树莓派安装debian，来运行mc服务器）
      所需配置：
              大于512MB的内存
              1核心以上的处理器，主频1.2Ghz以上
              拥有java
              有英语基础（这个很重要！）
      你需要这几个工具：
      Putty或者Xshell（用于连接你的linux服务器）
      Filezilla（用于主机和服务器之间的文件传输）
      
      首先，你需要知道你的服务器的IP地址，比如：178.61.43.116(编出来的，实际是否存在未知)
      如果是内网，请查看您的路由器获取IP
      随后打开连接工具，一般的话，远程端口都是22，除非某些运营商设置了安全组，开放了特定端口
      
      输入密码和账号，来到命令行
      再打开filezilla，填入远程端口，IP，账号，密码，如果一切顺利，你会看到服务器的文件夹
     若以上顺利，输入java –version来检查你的java是否存在
若果报错，则你的java根本没有预装，前往：https://www.linuxidc.com/Linux/2019-08/159870.htm
如果以上顺利，那么输入 mkdir minecraftserver（创建一个名为mine craftserver的文件夹）
然后输入 cd minecraftserver   进入该文件夹

然后用ftp上传spigot到你的minecrfatserver文件夹中


随后输入 nano  如果报错，那么执行sudo apt-get install nano
如果正常，那么输入nano runserver.sh

然后会弹出一个新的窗口，这个是linux下的文件编辑器。我们在里面输入：

while true
do
sudo java -Xmx1G -Xms512MB-jar /文件目录/[刚刚使用FTP上传的服务端文件名].jar nogui
done
   
然后根据下面的提示，按下crtl+o   写入（保存）文件
    然后按下按下crtl+x退出界面，这个时候，系统会回到命令行状态


然后我们输入bash runserver.sh
这个时候服务端就会运行
同样，我们也需要同意Eula，等spigot提示结束时，按下crtl+c退出服务器运行（这个时候，服务器就关闭了），随机输入nano eula.txt    将第三行的eula=false 改为 eula=true      保存并退出（方法上面讲过了）
随后再次运行runserver.sh   你就会发现，服务端开始运行，并生成文件。这个时候，服务器就运行完成了
