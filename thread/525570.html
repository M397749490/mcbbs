本帖最后由 cn_暗夜幽灵 于 2015-11-26 15:46 编辑

首先,小白退散
其次,该工具是为Linux设计的,最开始开发的目的于在树莓派上开服
该工具遵守GPL v3协议
Github 地址:https://github.com/darknightghost/mcserverd

需要libssh和readline库
安装方式和大多数Linux软件一样

该工具以守护进程的形式运行,minecraft作为其子进程脱离终端,并可通过ssh远程登录对其进行管理
该工具资源开销很小,可用于任何版本的服务端.
比较适合在低配置的服务器上使用

如果登录后不出提示符,请敲回车
安装后sudo mcserverd启动服务
sudo killall mcserverd退出
如果你能玩明白linux的话应该能明白怎么添加启动项

日志在/var/log/mcserverd下
minecraft server会以其所有者的身份运行而不是root

目前为测试版


安装教程:
该教程是直接在设备上编译安装的教程,如果你想交叉编译的话请自己解决
1.编译前的准备
首先要确保你要安装的设备上安装了以下的东西:
libssh,readline(依赖库)
gnu工具链,autotools(编译所需的工具)
git(可选,用来下载源代码,如果你通过其他方式下载也行)

2.下载源代码
首先用ssh远程登录你的设备,当然如果有键盘显示器啥的直接在上面弄更好
如果安装了git,直接在设备的终端上执行如下命令:
  1. sudo git clone https://github.com/darknightghost/mcserverd.git
复制代码
源代码就会被下载到当前目录下

3.生成Makefile
接着上一步执行以下命令:
  1. cd mcserverd
  2. ./configure
  3. make
  4. sudo make install
复制代码
如果成功了,直接跳到第五步,否则进行第四步

4.重新生成编译模板
如果到了这一步,说明设备上的autotools和我开发的时候用的版本不一致,执行以下命令:
  1. vi ./src/Makefile.am
复制代码

将-Werror删掉,然后执行以下命令:
  1. aclocal
  2. autoconf
  3. automake --add-missing
  4. make
  5. sudo make install
复制代码
这回应该能成功了
5.修改配置文件
执行以下命令:
  1. sudo vi /etc/mcserverd.conf
复制代码

配置文件格式如下:

  2. [minecraft]
  3. ;Minecraft Server所在路径
  4. workdir=/
  5. ;启动Minecraft Server所需要的命令
  6. command=java -Xms1024M -Xmx1024M -jar minecraft_server.jar nogui

  8. [ssh]
  9. ;ssh端口号
  10. port=2048
  11. ;ssh用户名
  12. username=admin
  13. ;ssh密码
  14. password=admin
  15. ;最大连接数
  16. max_connection=5

  18. [log]
  19. ;每个日志文件体积上限
  20. log-file-size=2MB
  21. ;日志文件个数上限
  22. log-file-num=10
复制代码
