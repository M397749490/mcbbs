二战坦克mod 坦克世界迷必备

Finally, after lots of work here we go, the final Version of the WW2 package for 1.6.4 and the parts package is ready for using.

Note: Due to lots of changes i strongly recommend to delete all older models from your maps before using this new package to avoid errors.

If you find any error please report them asap on the forum.

Both Packages are build for MC 1.6.4 with Forge 886 and Flan's Mod 3.1.2. To install move both Zip files to the flan folder. Don't unpack them!

Minecraft-SMP Parts Package
Changelog:
- Updated to 1.6.4
- Deleted many now useless parts, made the package much smaller
- Add better icons for all parts
