Memory Checker
服务器内存清理插件

    就是可以清理服务器多余内存的插件，释放不需要的内存，对内存不够用的服务器很有用
不过清理的内存是已分配内存，就是你在启动脚本里设置的。java本身占用的内存不会减少。

命令：
  • /mem 或者 /memory
清理服务器内存
  • /mem check 或者 /memory check
显示内存占用情况
  • /mem restart 或者 /memory restart
重启服务器

权限：

  • memory.* - 全部权限
  • memory.check - 检查权限
  • memory.free - 清理权限
  • memory.restart - 重启权限

配置文件：
  1. Memory:
  2.   time:
  3.     restart: 120 -重启时间
  4.     freeup: 600 -清理时间
  5.   debug: false -调试模式
  6.   auto-update: true -自动升级
  7.   auto-restart: true -自动重启
  8.   min-ram: 250 -最小内存
