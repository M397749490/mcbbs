如果你是按正常的一路下一步的安装方式，java的路径已经写入了环境变量了，直接用java -jar xxx就行（上面的最大最小内存不填的话，默认会是1个G)  并且注意你的批处理文件的后缀，在确保你文件管理器的后缀已开的情况下，为.bat，如果你后缀没开，并且用的是默认的文本编辑器，很有可能后缀是.bat.txt，而那个txt是默认隐藏的，所以要确保你开了显示后缀。最后最简单的判断你有没有开后缀的方法是，在你已经有一个xxx.bat的情况下，在用你创建bat文件的方法（这里的方法是指：右键新建文本文档，然后右键重命名为bat的方法），创建一个新文件，但不改名，如果你那个创建的文件后面没有.txt，而你前面创建的bat文件，有.bat，那么就是你的后缀显示没开，你必须开启，再重命名bat文件的后缀，不然系统还是默认识别为文本文档，而不是批处理（bat)文件(PS:那个 -XX:+AggressiveOpts是啥？从来没用过？）

我把我的bat文件给你看一下吧没有特殊说明的字，可以直接写入bat中



模组服：
  1. java -server -XX:+AggressiveOpts -Xms4G -Xmx4G -jar forge-1.12.2-14.23.5.2768-universal.jar
复制代码
-Xms 表示最小内存，比如我写的是-Xms4G，意思即为最小内存为4G。根据你的实际内存修改你的最小内存数值。另外一提，如果写成-Xms4000M，也是可以的，效果等同-Xms4G

-Xmx 表示最大内存，填写同最小内存

****.jar 表示你的核心文件名字。
如果是插件服，你应该有两个核心文件，官服核心和forge版核心。填写forge版核心名称。



插件服：
  1. java -XX:+AggressiveOpts -Xms4G -Xmx4G -jar paperspigot1.13-160.jar
复制代码

-Xms 表示最小内存，填写规则同前面

-Xmx 表示最大内存，填写规则同前面

****.jar 表示你的核心文件名字。
如果是插件服，你应该只有一个核心文件，也就是官服核心。填写官服核心名称。





关于bat文件：
在核心文件所在的文件夹里，创建一个txt文档，然后重命名，把txt格式更改为bat格式。
之后把我前面写的那一行代码写进入，记得保存。
然后，双击你的bat就好了。
