教程
机器：
给料机：用于喂食恐龙
给料机使用方法：左边的九宫格放肉类，右边放素类（注:需要红石信号激活，还有别的模组的食物也可以）

培养机：用来复活腔棘鱼（根据JEI显示的配方，这玩意现在似乎只能干这事）
培养机使用方法：倒入两桶水，再放任意食物，再放入DNA，如果你想控制雌雄的话那么找到水旁边的一条线，拖动上面的滑块（高温雄性，低温雌性），养分足够的话，就会开始培育，培育好了就会获得蛋，将蛋放到水里就OK了。注意：此法培育出来的腔棘鱼不属于你。

臭虫养殖箱：顾名思义，用来养一些邪恶生物的（蟑螂这类，似乎是拿来给恐龙当食物的。）
臭虫养殖箱使用方法：首先你要获得一只任意虫类（目前只知道蟋蟀获得方法，这些臭虫获得方法应该是对应现实世界的），此处以蟋蟀为例。首先制作捕虫网，然后拿捕虫网打草（其实空手也行，概率问题而已），就有几率获得蟋蟀。
然后将蟋蟀放入臭虫箱，放入对应的食物（蟋蟀是小麦，蟑螂是肉，其他未知，这些应该是对应现实世界的），然后臭虫箱就会不断培养臭虫，当臭虫箱内满了后，再培养出来的臭虫就会爆出来。

胚胎机：合成胚胎注射器
胚胎机使用方法：将含有DNA的试管、空的注射器以及培养皿放入其中，就会获得该生物的胚胎注射器。

DNA合成器：制作含有DNA的试管
DNA合成器使用方法：将非空白光盘（质量必须满）、空试管以及DNA核苷酸放入其中，就会获得一个含有DNA的试管。

骨架装配台：制作展品骨架（博物馆那种）
骨架装配台使用方法：按配方将同一种类骨骼摆放即可。

胚胎转化仪：制作史前生物的蛋
胚胎转化仪使用方法：将胚胎注射器以及一个鸡蛋放入，就会获得该品种的蛋。

DNA提取器：获得含有随机质量植物/动物DNA的光盘
DNA提取器使用方法：将蚜虫/蚊子琥珀和空白光盘一并放入其中，等待一会就会获得含有随机质量植物/动物DNA的光盘。

恒温箱：孵蛋
恒温箱使用方法：将蛋与泥煤苔（详见方块↓）放入其中，等待几分钟。你可以调整温度来影响蛋的性别。（高温雄，低温雌）。待进度完成后，手持蛋右键地面，就会生成该种类的史前生物，在多数情况下，你将是它的主人。

DNA测序器：获得含DNA的光盘。
DNA测序器使用方法：将软组织以及空白光盘放入其中，就会获得DNA。

清洗站：获得骨骼等
清洗站使用方法：将包裹着的化石与水桶放入其中，有概率获得生物骨骼或化石。一桶水最多洗出8个化石

化石磨床：获得软组织
化石磨床使用方法：将骨骼放入其中，概率获得骨粉、燧石，以及对应生物的软组织。
                           *也可以放入植物化石——by 417#@多行不义必自毙

DNA提升混合器：合并DNA
DNA提升混合器使用方法：将两个DNA质量都不满100%的光盘放入其中，会将两个DNA合并。（合并后的DNA质量为合并前两个光盘的和，当然不会超过100%）

复活动物
1.你需要合成一个“石膏绷带”，然后对化石右键，将它变成包裹着的化石，然后拿[ruby=@多行不义必自毙 改]石镐[/ruby]及以上的稿挖掘。
2.制造一个清洗站，将包裹着的化石与水桶放入其中，会获得生物骨骼。
3.制作化石磨床，将骨头放入其中，会获得骨粉、燧石，以及对应生物的软组织。
4.制造DAN测序器，并将软组织以及空白光盘放入其中，会获得DNA。
5.制作DAN提升混合器，并将两个DNA质量都不满100%的光盘放入其中，会将两个DNA合并。（合并后的DNA质量为合并前两个光盘的和，但不会超过100%）
6.制作DNA合成器，将存储光盘（就是含DNA的光盘，必须100%）、空试管以及DNA核苷酸放入其中，会获得一个含有DNA的试管。
7.制作胚胎机，然后将含有DNA的试管、空的注射器以及培养皿放入其中，就会获得该生物的胚胎注射器。
8.制作胚胎转化仪，并将胚胎注射器以及一个鸡蛋放入，会获得该品种的蛋。
9.制作恒温箱，将蛋与泥煤苔放入其中，等待几分钟。你可以调整温度来影响蛋的性别。（高温雄，低温雌）
10.获得可孵化的蛋后直接放到地上，恭喜你获得了一只史前生物！在大部分情况下，你将是它的主人。
复活植物
1.你需要一个植物软组织：可以通过挖掘植物化石（生成于煤矿附近）（不需要包石膏）并放入化石磨床获得。也可以将琥珀放入DNA提取器提取获得。
2.你需要获得一个琼脂培养皿：你可以通过去海底采集江篱，并放入熔炉熔炼，获得琼脂。然后将琼脂与培养皿合成即可得到琼脂培养皿。可以将江篱种在至少2格深水的沙子、沙砾上，阳光充足的情况下江篱会大量繁殖。
3.你需要一个植物细胞培养皿：手持注射器右键植物（树、农作物皆可）即可获得植物细胞注射器，然后与琼脂培养皿合成即可得到植物细胞培养皿 。
4.你需要一个质量满的植物DNA，获取方法：将琥珀放入DAN提取器中使用，获得植物DNA后，你需要将两个植物DNA质量都不满100%的光盘进行融合提升，获得质量100%的DNA后，再重复复活动物篇步骤6即可。
5.然后制作一个胚胎机：在其中放入满质量植物DNA（试管）.空的注射器.植物培养皿后，制作出植物愈伤组织，之后种植在地上即可。（部分需要种在耕地上）
方块
苔藓：
苔藓生成在森林和沼泽里，生成几率较低。可以将苔藓种在泥炭上，这样就可以大量获得苔藓。
泥炭：
泥炭生成在沼泽，和耕地一样需要水。该方块放置在沼泽以外的生态群系中会变成泥土，除非周围有水。主要用来种苔藓
泥煤苔：9个苔藓合成1个，用于在恒温箱中培养史前生物蛋，一颗蛋一块泥煤苔。

作者原文
Welcome to JurassiCraft!
JurassiCraft is a mod based on Jurassic Park on Jurassic World franchises, but is not only limited to it. This mod allows you to create dinosaurs by extracting DNA from fossils and amber, and putting that through a process until you get a baby dinosaur! Not only does this mod add dinosaurs, it also adds many prehistoric plants!
Confused how to use this mod? Visit our wiki! It contains all the information you will need to create your very own dinosaurs!
Currently, this mod contains only 10 dinosaurs, but more will be added in the future!

If you would like to join our Discord, where you can talk about the mod with us, see update progress, and even get some sneak peaks to features coming in later updates, you can join here!
Come Join our 24/7 Official Server @ mc.jurassicraftmod.com !

This project is sponsored by Nodecraft. Use code JurassiCraftfor a 30% discount off your first month of service!

If you enjoy JurassiCraft and want to support the development of the mod, you can click here to be taken to our patreon! Thanks for the support.
If you have any bugs to report please report them here:
https://github.com/JurassiCraftTeam/JurassiCraft2/issues
Content:
This mod contains many things, but here are some of the main things it includes:
  • Dinosaurs! This mod contains many dinosaurs, as that is the main focus of this mod.
  • Plants! If your dinosaur pen is empty, why not add some beautiful prehistoric plants to fill it up?
  • Machinery! In order to create dinosaurs, you will need machinery. This mod contains many machines that will be useful in your journey to bring dinosaurs back!
  • Decorations! Want to create a Jurassic Park? We've got you covered! This mod contains many decorations you can use to decorate your very own Jurassic Park.
  • Vehicles! Need to get around your park? Sure, we've got them!
  • Fossils! To create dinosaurs, you'll need DNA, fossils are a perfect way to get DNA!
  • Skeletons! Create your very own museum with skeletons, constructed with the fossils you find!

Q: Will you downport to 1.7.10?
A: No, we do not support 1.7.10.

A: We already have all the dinosaurs we want to add in future updates planned, and will likely not be changing those plans, but X may be in one of these planned updates.
Q: When will the next update come out?
A: We do not know, all we know is that we will release it once it is ready.
Q: Where did all the dinosaurs from the 2.0 pre-release go?
A: We removed them, we decided to rather focus on quality than quantity.
Q: I am getting an OutOfMemoryError when I try to use JC! What do I do?
A: You need to allocate more RAM to MC. This can be done by enabling advanced launch settings in your launcher, and changing your VM Arguments.

所以希望能够优先加载汉化文件，再加载模组的汉化资源包

多谢反馈，但是解决问题的方法不是加载优先级问题。
我先简单解释下 Minecraft 的语言文件加载机制，通过将每个模组的语言文件读取一遍，然后依据等号拆分成键值对，然后存入一个 Hashmap 中。
因为资源部分加载优先级非常高，所以实际情况是在 construction 阶段对已经加载的资源部分进行了重载，然后让其重新读取语言文件，装载到 Hashmap 中。
简而言之，本来就是按照你所推荐的方式加载的。

换行逻辑是在读取了存储在 hashmap 中的语言词条后，在渲染时进行分行逻辑判定的，也就是说管控换行是属于渲染部分，与语言加载顺序毫无关系
