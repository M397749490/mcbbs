如果你说的是替换方块
fill <x1 y1 z1> <x2 y2 z2> minecraft:iron_door[half=lower] replace minecraft:oak_door[half=lower]
fill <x1 y1 z1> <x2 y2 z2> minecraft:iron_door[half=upper] replace minecraft:oak_door[half=upper]

如果你说的是替换背包里的物品
很麻烦，最简单但效果最差的做法是
# foo:bar
clear @s minecraft:oak_door 1
give @s minecraft:iron_door 1
execute if entity @s[nbt={Inventory:[{id:"minecraft:oak_door"}]}] run function foo:bar

我进游戏测试了一下，大概猜测了一下原因…
铁门因为有两部分，所以需要分成两部分放。但是木门它也有两部分，所以在铁门只替换了一半木门的时候触发的方块更新会让游戏发现不对劲：「怎么有两个一半的门」，然后这俩门就都给清掉了…

话说木门的位置是固定的吗，如果是的话可以直接把那两个位置放成 air，然后再放成 iron_door
