# 灵工艺全新未转变者开服器已上线
[!] 已支持最新版本

已有主要功能

  • 服务端创建
  • 多服务端管理
  • 服务器IP获取
  • 服务端模组管理
  • 服务器配置文件设置

计划开发功能

  • 地图文件管理
  • 工具箱系列功能
  • 本体设置系列功能

功能可参考灵工艺姊妹我的世界开服器，界面设计使用统一风格。

# 使用方法
本软件使用C#开发所以需要由.NET进行前置 .NET4.0 或 更高版本即可正常使用

  • 下载软件
  • 将软件放置到游戏目录内(支持 Unturned Dedicated Server)
  • 启动软件
  • 配置服务端
