·序言·
[ 什么是MythicMobs? ]
MythicMobs可以通过更改配置的方式创造出各种各样的怪物，他可以更改怪物的任何属性，比如名称、生命、攻击力，甚至技能。
·第一章·
[ 创建你的第一个怪物！ ]
下载适应版本的插件并塞入"plugins"文件夹
且运行正常后找到目录
打开“ExampleMobs.yml”
里面就是配置了
UTF-8编码！
按照以下表格输入
不需要的属性可以不用添加
即删去

[ 怪物的基础属性 ]

  2. pikaqiu:     #代码，并非实际显示名，仅用作调用与配置!必须是英文!
  3.   Mobtype: ZOMBIE    # 显示的生物类型
  4.   Display: '&2&l皮卡丘'     #显示名，支持颜色代码

  19.   AIGoalSelectors:     #全局AI

  21.   AITargetSelectors:     #目标AI

  23.   Conditions:     #自动生成条件
  24.   - offgcd true
  25.   DamageModifiers:     #伤害减免
  26.   - FIRE 0.5     #意为火焰伤害减免50%，例如造成100点的火焰伤害，怪物只受到50点
  27.   Skills:     #技能
  28.   - lightning @Target ~onTimer:120     #每隔6秒释放雷霆点击怪物目前目标玩家

·掉落物·
[ 击杀怪物后掉落的物品 ]
例子:
pikaqiu:
  Drops:
  - exp 1 1-3 1     #杀死怪物后100%掉落经验1~3点
  1. Drops:
  2. - exp 1-3 1     #100%掉落经验1~3个
  3. - money 1 0.4     #40%掉落1块钱，需Vault前置!
  4. - 137 1 0.01     #1%掉落命令方块1个
  5. 格式:
  6. - 名字 最小掉落数量-最大掉落数量 几率
  7. - 名字 掉落数量 几率

复制代码
·全局AI·
例子:
pikaqiu:
  AIGoalSelectors:
  - 0 clear     #清除所有全局AI，注: 前面的数字要按顺序来，下一个就是1，再下一个就是2，以此类推
  1. Clear     #清除AI
  2. BreakDoors     #破门
  3. EatGrass     #吃草
  4. Float     #浮在水面
  5. GoToLocation:x,y,z     #移动到指定坐标，注意:半径必须在怪物32格内
  6. LookAtPlayers     #看向附近玩家
  7. OpenDoors     #开门并且关门
  8. RandomLookAround     #游走
  9. AvoidArrows     #躲避箭
  10. AvoidCreepers     #躲避苦力怕
  11. AvoidPlayers     #躲避玩家
  12. AvoidSkeletons     #躲避骷髅
  13. AvoidZombies     #躲避僵尸
  14. FleeSun     #躲避太阳
  15. MeleeAttack     #只攻击近战玩家
  16. MoveTowardsTarget     #走向目标
  17. RandomStroll     #游走
  18. Tempt:item_name     #当你手持某个物品，怪物将跟随你,类似萝卜喂猪
复制代码

例子:
pikaqiu:
  AITargetSelectors:
  - 0 clear     #清除所有目标AI，注: 前面的数字要按顺序来，下一个就是1，再下一个就是2，以此类推
  1. Clear     #清除AI
  2. Attacker     #攻击目标锁定
  3. Monsters      #怪物
  4. Players     #玩家
  5. Villagers     #村民
  6. OtherFaction     #不在自己派系的生物
  7. OtherFactionMonsters     #不在自己派系的怪物
  8. OtherFactionVillagers     #不在自己派系的村民
  9. <font face="黑体">SpecificFaction</font>:[faction_name]     #指定派系
  10. SpecificFactionMonsters:[faction_name]     #指定派系
  11. ThreatHolder     #怪物攻击伤害最高的
  12. OwnerAttacker     #攻击主人的目标
  13. OwnerTarget     #主人的攻击目标

·第二章·
[ 怪物的特殊属性! ]
例子:
pikaqiu:
  Options:
  - PreventOtherDrops: true     #防止怪物掉落自身物品
  - PreventLeashing: true     #怪物可以被缰绳牵走

  2. Makrket: true/false     #盔甲架是否可见
  3. Pose:      #盔甲架各部位的设定
  4.   Head: 0,0,0     #头
  5.   Body: 0,0,0     #身体
  6.   LeftArm: 0,0,0     #左臂
  7.   RightArm: 0,0,0     #右臂
  8.   LeftLeg: 0,0,0     #左腿
  9.   RightLeg: 0,0,0     #右腿
  10. AttackSpeed: 数值     #攻击速度
  11. Collidable: true/false     #是否拥有碰撞箱
  12. Glowing: true.false     #发光
  13. NoAI: true/false     #是否拥有AI
  14. Jockey: true/false     #鸡是否能被骑(可能会生成鸡骑士)
  15. Saddled: true/false     #是否能用鞍骑
  16. Incendiary: true/false     #TNT爆炸是否着火
  17. SuperCharged: true/false     #是否是高压苦力怕(适用于苦力怕)
  18. PreventSuicide: true/false     #是否防止苦力怕爆炸后死亡，设为true即为爆炸后不死
  19. Block: 方块类型     #方块类型(适用于方块)
  20. BlockData: 数值     #方块附加值
  21. Age: 数值     #年龄，-1是幼体，1是成年
  22. AegLock: true/false     #年龄是否锁定，防止长大
  23. Angry: true/false     #是否主动攻击(适用于狼和猪人)
  24. AlwayShowName: true/false     #是否一直显示名字
  25. Color: 颜色代码     #狼项圈和羊毛的颜色(颜色代码white,orange,magenta,lightBlue,yellow,lime,pink,gray,silver,cyan,purple,blue,brown,green,red,black)
  26. Despawn: true/false     #没有玩家在附近怪物是否消失
  27. Disguise: 生物类型     #伪装，需伪装插件
  28. ExplosionRadius: 数值     #苦力怕爆炸的半径
  29. FollowRange: 数值     #怪物最大仇恨距离
  30. FuseTicks: 数值     #苦力怕爆炸延迟
  31. HasArms: true/false     #盔甲架是否持有武器
  32. HasGravity: true/false     #盔甲架是否受重力影响
  33. HorseArmor: 类型     #马盔甲的类型(IRON,GOLD,DIAMOND)
  34. HorseCarryingChest: true/fals     #马是否穿戴盔甲
  35. HorseColor: 颜色代码     #马的颜色(颜色代码BLACK,BROWN,CHESTNUT,CREAMY,DARK_BROWN,GRAY,WHITE)
  36. HorseSaddled: true/false     #马是否可以骑
  37. HorseType: 生物类型     #马的种类(BLACK_DOTS,WHITE,WHITE_DOTS,WHITEFIELD)
  38. HorseTamed: true/false     #马是否可以被驯服
  39. Invisible: true/false     #盔甲架是否隐身
  40. ItemHead: 装备代码     #盔甲架头部装备(以下各项的装备必须是在“ExampleItems”设置的)
  41. ItemBody: 装备代码     #盔甲架胸部装备
  42. ItemLegs: 装备代码     #盔甲架腿部装备
  43. ItemFeed: 装备代码     #盔甲架脚部装备
  44. ItemHand: 装备代码     #盔甲架手持装备
  45. KnockbackResistance: 数值     #防击退值，默认为0.2
  46. MaxCombatDistance: 数值    #怪物攻击距离
  47. MovementSpeed: 数值      #移动速度
  48. Ocelot: 颜色代码     #猫的颜色(颜色代码BLACK_CAT, RED_CAT, SIAMESE_CAT, WILD_OCELOT)
  49. PreventBlockInfection: true/false     #蠹虫能否钻进方块
  50. PreventSnowFormation: true/false     #雪人脚下是否能生成雪
  51. PreventItemPickup: true/false     #是否能拾取物品(适用于僵尸)
  52. PreventLeashing: true/false     #能否被缰绳牵走
  53. PreventMobKillDrops: true/false     #是否阻止生物死亡掉落插件设置物品
  54. PreventOtherDrops: true/false     #是否阻止生物死亡掉落原版设置物品
  55. PreventRenaming: true/false     #是否阻止命名牌重命名
  56. PreventSlimeSplit: true/false      #是否阻止史莱姆分裂
  57. PreventTeleporting: true/false     #是否阻止末影人传送
  58. ReinforcementsChance: 数值(0-1)     #僵尸呼叫增援的几率
  59. RabbitType: 生物类型     #兔子种类(生物类型BLACK,BLACK_AND_WHITE,BROWN,GOLD,SALT_AND_PEPPER,THE_KILLER_BUNNY,WHITE)
  60. RepeatAllSkills: true/false     #过量治疗是否重置生命
  61. Small: true/false     #盔甲架是否是小型的
  62. ShowHealth: true/false     #是否通告附近玩家自身血量
  63. Size: 数值     #史莱姆的大小
  64. ThreatTable: true/false      #是否开启仇恨表
