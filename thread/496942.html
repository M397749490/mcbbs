插件介绍
没有教程，这是我（作者）做的第一个插件，插件添加了许多可以自定义的东西和指令，
如果你想添加可以改变他，把插件拖入plugins文件夹，重启服务器
插件自带许多自定义物品，如“假TNT”，“绿宝石稿”等等
这个插件每天更新很多次，不知道要不要上传，插件现在的版本是1.8

指令、权限和参数指令： /stickmansitems
指令权限：stickmansitems.admin
节点命令：give <1 or 2>, help, minesweep, reset, updateconfig, reload（具体的使用方式就是和指令组合）

如何配置config.yml文件
注意：默认情况下请把所有的配置都设为true
（其实说白了就是能不能合成）
version-DO-NOT-CHANGE - Don't change it. It's the plugin version.
auto-updater-enabled - Toggles the auto updater.
stickmans-snooper-enabled - Toggles weather I can collect data to help improve the plugin. NOTE: Please disable for now, as it is broken.
give-command-enabled - Toggle if people can use /stickmansitems give
help-command-enabled - Toggle if people can use /stickmansitems help
landmines-enabled - Toggle if land mines can hide and explode.
plastic-explosives-enabled - Toggle if plastic explosives can be detonated.
nukes-enabled - Toggle if nuclear weapons can explode.
incendiaries-enabled - Toggle if incendiaries can explode.
water-bombs-enabled - Toggle if water bombs can explode.
fall-through-block-enabled - Toggle if the fall through block drops people.
blasting-caps-enabled - Toggle if blasting caps dig.
dirtsword - Toggle if the dirt sword can be crafted.
slayer - Toggle if the slayer can be crafted.
cheater-tnt - Toggle if cheater tnt can be crafted.
saddle - Toggle if saddles can be crafted.
name-tag - Toggle if name tags can be crafted.
deathstrike - Toggle if the death strike can be crafted.
emerald-pick - Toggle if the emerald pickaxe can be crafted.
slapstick - Toggle if the slap stick can be crafted.
cane - Toggle if the can can be crafted.
diamond-encrusted-cane - Toggle if the diamond encrusted cane can be crafted.
wither-skull-gun - Toggle if the wither skull gun can be crafted.
boltslinger - Toggle if the bolt slinger can be crafted.
spambow - Toggle if the spammy bow can be crafted.
smoke-wand - Toggle if the smoke wand can be crafted.
herobrine-hat - Toggle if the herobrine hat can be crafted.
herobrine-shirt - Toggle if the herobrine shirt can be crafted.
herobrine-pants - Toggle if the herobrine pants can be crafted.
herobrine-shoes - Toggle if the herobrine shoes can be crafted.
airslicer - Toggle if the air slicer can be crafted.
healing-wand - Toggle if the healing wand can be crafted.
book-of-dedication - Toggle if the book of dedication can be crafted.
baseball-bat - Toggle if the baseball bat can be crafted.
gun - Toggle if guns can be crafted.
camo-mines - Toggle if camouflaged land mines can be crafted.
mooshroom-budder - Toggle if mooshroom spawning budder can be crafted.
bomb-defuser - Toggle if bomb defusers can be crafted. (RECOMMENDED ON IF CUSTOM BOMBS ARE ENABLED!!!)
plastic-explosives - Toggle if plastic explosives can be crafted.
detonator - Toggle if detonators can be crafted. (Must be on to detonate custom bombs!)
ultimate-emerald - Toggle if the ultimate punch emerald can be crafted.
ultimate-melon-slice - Toggle if the ultimate(villager spawning) melon slice can be crafted.
grenade-launcher - Toggle if grenade launchers can be crafted.
nuke - Toggle if nukes can be crafted. (WILL EVEN DESTROY BEDROCK!!!)
incendiaries - Toggle if incendiaries(fire bombs) can be crafted.
water-bombs - Toggle if water bombs can be crafted. (Only affects dirt and grass blocks.)
x-ray - Toggle if the X-Ray can be crafted.
fall-through-blocks - Toggle if fall through blocks can be crafted.
blasting-caps - Toggle if blasting caps can be crafted.
laser-rifle - Toggle if laser rifles can be crafted.
force-bomb - Toggle if force bombs can be crafted.
