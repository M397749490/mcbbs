如果你正在找一个Spigot和Bungeecord「双平台」而且「无需依赖」的登录插件，那么你找对啦！




大家都知道有很多与AuthMe类似的登录插件
但...它们大多数都不支持BungeeCord，即使支持，也是通过MySQL或者在BungeeCord和Spigot上安装插件本体和“附属插件“
LockLogin不需要任何附属or前置，到目前为止，还没有已知的bug来绕过登录，插件也提供很多可配置的选项，比如玩家ID检查(检查非法ID)，2FA(使用Google Authenticator)和其他与帐户有关的功能。

此处贴一个原文
We all know plugins like AuthMe, but... they are relative exploitable, and most of them don't support BungeeCord, if they do, it's with MySQL or using a "co-plugin" that creates a bridge between BungeeCord and Spigot, well, LockLogin don't need any co-plugin, and until today, there's no exploit available to bypass his security, with a lot of secure options, like name-checker (Checks for illegal names), 2FA ( Using Google Authenticator ) and other account related features.







基础功能/优点：

- 支持BungeeCord
- 支持1.8-1.16的所有版本
- 轻量&高效且无需依赖&前置
- 使用BungeeCord时，可无需MySQL
- 快速上手（配置可能少许复杂）
- 支持 MySQL
- 可限制单IP最多链接
- 非法ID检查
- 自动迁移 （YAML 到 MySQL）
- 实时获取登录用户信息
- 防止同名玩家加入
- 可从其他登录插件迁移
- 免费（It's free）


使用方式
下载好的插件放入plugins文件夹中，启动服务器就可以了！

  • 玩家命令及其相应权限
    / register-注册一个新帐户

    • args：[密码] [密码]
    • 权限：[无]
    • 需要：[密码必须相同]
    • 别名：[/ r- / reg]

    / login-登录到您的帐户
    • args：[密码]
    • 权限：[无]
    • 需要：[注册帐户]
    • 别名：[/ l]

    / unlog-退出当前登录
    • args：[无]
    • 权限：[无]
    • 需要：[登录并注册]
    • 别名：[无]

    / change-更改密码
    • args：[密码] [新密码]
    • 权限：[无]
    • 需要：[新密码不能与旧密码相同]
    • 别名：[/ cpass]

    / delaccount-删除您的帐户
    • args：[密码] [密码]
    • 权限：[无]
    • 需要：

    [需要是注册或者登陆过的玩家] [密码必须一致]
    • 别名：[/ delacc，delcc]

    / 2fa-2fa选项的主要命令
    • args：

    [password]（启动2fa）[code]（如果开启了2FA，要完全登录）[password] [code]（要替代2FA，请执行此操作）
    • 权限：[无]
    • 需要：[登录并注册]
    • 别名：[无]

    / resetfa-生成新的2fa代码/令牌
    • args：[密码] [代码]
    • 权限：[无]
    • 需要：[使用2fa登录，注册并验证]
    • 别名：[无]

    管理命令
    / unlog-关闭玩家的会话
    • args：[玩家]
    • 权限：[locklogin.forceunlog]
    • 需要：[一个已经登录或注册的玩家]
    • 别名：[无]


    / delaccount-删除玩家帐户
    • args：[玩家]
    • 权限：[locklogin.forcedel]
    • 需要：[一个已经登录或注册的玩家]
    • 别名：[/ delacc，/ delcc]


    / migrate-将MySQL帐户迁移到Yaml
    • args：[无]
    • 权限：[locklogin.migrate]
    • 需要：[有效的MySQL连接]
    • 别名：[无]
