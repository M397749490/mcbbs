标题: 【shell脚本】防蹦服 自动启动服务器
最近在用阿里云测试搭建个我的世界服务器
因为免费的只有1G内存，总出现蹦服，还要手动启动
所以写了个shell脚本，分享给大家，希望有用处

  1. #!/bin/sh
  2. echo "Start"
  3. while :       #循环，为了让脚本一直运行监控
  4. do
  5. DTTERM=`pgrep java`       #java java
  6. if [ -n "$DTTERM" ]
  7. then
  8.     echo "sleep 10s Run MC Server"
  9.     sleep 10s   # 等待10秒继续运行服务器

  11. else
  12.     echo "Run MC Server"
  13.     cd /home/mc
  14.     java -Xms128M -Xmx700M -jar spigot.jar
  15. fi
  16. echo "End"
  17. done

  19. #在if中直接写if [ -n "`pgrep nfsd`" ] 是不能达到期望的结果的！
复制代码

linux 运行脚本方法
授运行权限
chmod 777 run.sh
运行脚本
./run.sh

作用如果服务器崩溃 10S自动重新启动服务器
