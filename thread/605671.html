[第十届擂台赛作品]
Command Block Logic
随机地牢探险游戏

— 地心之路 —
- the Road to the Core -

= 背景介绍 =

  • 数年前政府地质勘探发现这一带地下有异常波动，曾经派军队来处理，却消失的无影无踪
  • 政府进一步勘探发现每3个月地下地质活动会有波动，结合进一步证据发现了存在着的第二文明，于是封锁了整个区域
  • 于是政府每3个月派一个集合工程/医疗/研究的精英队伍，前往人为勘测，以减少人员损失，同时也能快速反应灵活应对突发情况
  • 执行任务前小队会被带往营地，然后运送一台钻机协助勘探。但是钻机电力有限，需要结合周围资源发电运行。小队必须继续深入，直到找到第二文明重要线索或者走到地壳尽头为止。
  • 在此次行动前已经有很多小队葬命，因此有很多掉落补给可以在中途拾取，当然也有可能是第二文明的产物。能够活着回来的精英成为下一个队伍的向导继续前往勘测，而工程师负责维修管理大型设备，医疗团队能够进行医疗救援，研究专家则能跟进队伍进行实时勘测。
  • 在曾经几次行动中得到的消息是这个文明有类人智慧的生物，并且可能这个文明拥有超自然空间技术。



= 游戏介绍 =
- 关于地图 -
游戏的每关地图均为随机生成
地牢走向、箱子内的宝物、隐藏房间的出现
每次生成地图时均会重置
因此游戏后期需要强大的识路能力
隐藏门需要使用雷管或者粗制炸药才能炸开!

- 关于生命 -
由四人组队进行游戏
每名玩家有3条生命
阵亡后会倒下，需由队友用急救包对其腿部按住左键救起
三条生命结束后，可使用急救带丢向尸体腿部复活玩家
队友的阵亡位置不便于救助时(如岩浆里) 可右键尸体腿部搬运尸体.

- 关于怪物 -
游戏中的蜘蛛和岩浆怪
能使玩家视角受限并无法移动或受伤
请尽快救助被控制的队友

- 关于资源 -
游戏中获得的资源
可用游戏内自带的合成桌合成武器和补给

地图生成时会产生卡顿, 请耐心等待.
