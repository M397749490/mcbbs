首先，最中心白叉上方的数字代表你所打出的伤害（不是造成的伤害哦）
其次，在受伤标记附近最外侧的数值代表你与上一次伤害来源的距离
最后，受伤标记最内侧的数值代表这次伤害来源打出的伤害= =
当然啦，最中间的 红黑十字 是神马鬼？
那是个 无敌标志 ，一般人搞不出来的，不要担心。
感谢贴友的建议




服务端与客户端配置文件

该模组在服务端和客户端运行时会生成截然不同的配置文件：

客户端配置文件：
# Configuration file
client {
    # In Client,allow you play sound when you hit some entity,default:true.
    B:per_playsound=true//是否在命中目标时播放命中提示音。
    # In Client,allow you show the mark in HUD when you hit entity,default:true.
    B:per_showhitmark=true//当你命中目标时是否会显示屏幕中央的白叉。
     # In Client,show damage amount when you hit someone,"showhitmark" must be true,default:true.
    B:pre_showDamageAmount=true//当你命中敌人时，是否需要显示你所打出的伤害数值（并非造成的伤害），其中命中目标显示白叉的选项必须开启（5月23日更新配置）。
    # In Client,show hurt amount and hurt source distance,"showhurtdirection" must be true,default:true.
    B:pre_showHurtAmount=true//当你被敌人伤害时是否在伤害标记附近显示敌人打出的伤害（并非造成的伤害）以及伤害源与你的距离，其中显示伤害来源位置的标识必须开启（5月23日更新配置）。
    # In Client,show instant treatment mark when you have this effect,default:true.
    B:pre_showTreatment=true//这个是为额以后要搞的解谜地图做的一个配置选项。当你拥有 瞬间治疗 效果超过 0.5 秒的时间时，会显示一个十字形“无敌”标志。一般情况下是没办法搞出这个标志的，如果该标志与其他能够给予你有时限的 瞬间治疗 效果的模组搭配不佳，请关闭该配置。
    # In Client,allow you show the direction mark in HUD when you are hurt,default:true.
    B:pre_showhurtdirection=true//当受到伤害时是否显示本次伤害来源的位置。
}

服务端配置文件：

# Configuration file
server{
# In server,allow all players play sound when they hit entity,default:true.
B:all_playsound=true//在服务器中，是否允许玩家播放命中目标后的声音。
# In server,allow all players show the damage amount they hit,"showhitmark" must be true,default:true.
B:all_showDamageAmount=true//在服务器中，是否允许玩家在命中目标时显示自己所打出的伤害数值，其中允许玩家命中后显示白叉的选项必须开启。
# In server,allow all players show the hurt amount and hurt source distance,"showhurtdirection" must be true,default:true.
B:all_showHurtAmount=true//在服务器中，是否允许玩家在被伤害时显示敌人打出的伤害数值以及伤害源的距离，其中允许玩家显示伤害标记的选项必须开启。
# In server,allow all players show the mark in HUD when player hit entity,default:true.
B:all_showhitmark=true//在服务器中，是否允许玩家显示命中后的白叉。
# In server,allow all players show the direction mark in HUD when player is hurt,default:true.
B:all_showhurtdirection=true//在服务器中，是否允许受到伤害的玩家是否显示本次伤害来源的方向。
}



服务端配置文件与客户端配置文件的关系
在客户端内会生成客户端配置文件，服务端会生成服务端配置文件。
服务端配置文件决定着服务器内玩家是否允许使用该模组的某项功能，客户端的文件决定着在此基础上是否想要开启这个功能……
就酱紫。


服务端与其他模组兼容性及bug测试

……偶尔，图标和文字同时显示时可能会相互影响对方的渲染效果，目前楼楼正在设法解决这个问题。
尚未发现与其他模组存在不兼容的地方，从理论上来讲……emmm应该不会不兼容的
在 服务器 中，需要客户端与服务端同时拥有该模组，该模组方可生效
（对的你没看错这个专为客户端设计的模组在服务器中服务端也必须要有）
不过呢，在服务器中客户端有什么权限还是服务端说的算。
当然啦，如果发现什么 bug 或者 兼容方面 的问题请及时反馈联络作者哦。
