StackableItems
（最新版本V1.5.2）
简介   
你是否厌烦了一瓶药水占一个格子、鸡蛋只能存在十六个？
这个插件帮你设置物品可叠加的数量——在某世界全部玩家或某玩家身上可以携带的最大数量。
同时也是一个比较高级的插件，新手建议不用修改配置文件，而是使用指令完成。
插件同时附带了自定义煅烧经验的功能。
本插件提供源码。



作者原文介绍
StackableItems allows you to raise or lower the default stack amounts for any item. Items can also be disabled (disallows pickup and crafting). Items can be set in three different ways: individual players, permission groups (requires Vault), and universally.

Example use cases:

Carrying 16 snowballs while carrying 64 cubic meters of dirt is ridiculous.
Carry a stack of water buckets or mushroom soup with you so you never run out
Make potions stack
Limit stacks of food for a hardcore survival server
Allow only privileged users to craft/pickup TNT
Allow individual players to craft custom items

这个插件将允许你调整物品的叠加数量，也可以禁用某个物品的叠加数量，三种不同方式：个人、权限组、默认组
举个例子：
只能拿16个雪球，却能拿64个泥土，不是很荒唐？
带着一堆水桶和蘑菇煲。
让药水叠加
在生存服务器，限制食物的堆叠数量
只能让特殊玩家使用TNT
让玩家自己定制物品数量



指令
/si reload- 重新载入插件
/si <世界名> default <物品ID> <数量> - 设置某世界默认可重叠物品的数量
/si <世界名> player <玩家名> <物品ID> <数量> - 设置某玩家可重叠物品的数量
/si <世界名> <权限组名> <物品ID> <数量> - 设置某权限组可重叠的物品的数量
(注:世界名内若为allWorlds则是全部世界)


权限
stackableitems.admin - 使用所有指令的权限



设置教程
①如何设置全部世界 所有物品的重叠数量？
打开item.yml
在default下找到MIN
修改后面的数字
保存，重载配置，完成
②如何设置某世界 所有物品的默认重叠数量？
见指令处。
③如何设置某世界/全部世界 某玩家的重叠数量？
见指令处。
④如何设置某世界/全部世界 某权限组的重叠数量？
见指令处。
