自动翻译插件



这插件有什么用处呢？



就是你的客户端的语言不管是什么，如果服务器是英文

你输入中文 在别的玩家的聊天框会是英文的，如果另外一名玩家的语言是中文 那么依然会显示中文【超好的插件啦】

接下来就是指令了

这没有权限【只能op使用】


  1. /language               开启语言gui，选着语言
  2. /language reset         重新设置语言
  3. /language set <lang>设置语言【比如：/language set cn 这就是中文了
