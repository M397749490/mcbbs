插件的诞生 and 简介：

不少朋友和我说，他们服务器开了很久，几乎所有的玩家都变成了土豪，动辄几组钻石块，钻石更是随便扔。

我想，不少朋友都会有这种问题吧。

服务器开的久了，玩家一直玩，各种资源不断的收集，渐渐地，大家也都丧失了游戏的乐趣，这种情况，几乎所有生存服的腐竹都遇到过。

那么问题来了，怎么样回收玩家的物资呢？

于是，Lottery彩票插件，诞生了！

此插件，可以让玩家在娱乐中回收玩家的物资。

玩家的放入的物品，可以由你指定，无论是钻石块、绿宝石等游戏本有物品，还是红枫钻石、核弹等mod物品，只要物品是有id的，你就可以指定！


插件介绍：

插件中，你可以设置开启和关闭、间隔时间、开奖时间，配置文件下面会放出，此处先介绍插件功能。

首先，插件的命令是lottery，缩写是lot，无需前置插件。

输入/lot help可以查看帮助，目前暂时有下面四条命令：

/lot 进行投注

/lot help 查看帮助

/lot rule 查看规则

/lot reload 重载插件

权限列表：

lottery.help 可以查询命令帮助

lottery.use 是否可以下注

lottery.rule 是否可以查看规则

lottery.reload 重载插件


配置文件(Version-1.0.1)：
  1. #Lottery 配置文件(作者：mahua)
  2. # 是否开启彩票系统
  3. open: true
  4. # 彩票开奖间隔时间(秒)
  5. interval: 180
  6. # 发出开奖公告后多久开始摇奖(秒)
  7. open-time: 180
  8. # 猜大小赔率(正整数)
  9. scale_size: 3
  10. # 猜单双赔率(正整数)
  11. scale_s_d: 2
  12. # 猜单个赔率(正整数)
  13. scale_number: 9
  14. # 彩票的标题
  15. title: '&a[彩票中心]'
  16. # 允许进行投彩的物品
  17. item:
  18.   # 复制多份，修改信息，格式：id(小数点等于id里面的':'):名称
  19.   - '56.0:钻石矿'
  20.   - '14.0:金矿'
复制代码

注释说的已经够清楚了吧？

唯一值得一提的就是item中，一定要严格按照格式来，id的.代表:，而后面的文字就是对前面id物品的说明，一般填写物品原名就可以了。
