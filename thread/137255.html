在安裝這個插件前, 我是假設您已經安裝好支援PHP及mySQL的web服務器環境, 否則請前往以下圖文教學安裝.
--

事前需要下載的東西:
whitelist.jar 這是autowhitelist的插件jar, 在這裡下載.
mysql-connector-java-bin.jar 這是java連結mySQL需要用的檔案, 在這裡下載, 然後改為此檔名稱一樣.
whitelist.sql 這是為您準備好的數據庫匯入檔, 點帖子的附件下載.
addwhitelist [資料夾] 這是為您準備好的網頁表格, 點帖子的附件下載.
--

步驟一:
將whitelist.jar放入您服務器的plugin資料夾運行一次再輸入stop關閉服務器, 然後將您的白名單開啟設定為true.


步驟二:
將mysql-connector-java-bin.jar放您的安裝java的目錄內的lib資料夾內.

步驟三:
將whitelist.sql匯入數據庫, 得到資料庫whitelistdb及資料表whitelist




步驟四:
將addwhitelist的資料夾放進您的www網頁資料夾內, 預設的網頁服務器檔案位置是 C:\wamp\www

步驟五:
修改網頁對應您的資料庫連結內容, 在www內打開addwhitelist > Connections > comm.php
  1. <?php
  2. $hostname_comm = "localhost";
  3. $database_comm = "whitelistdb";
  4. $username_comm = "whitelistdb"; //輸入您mysql的帳號, 例如root, 非使用root的用戶請自行付予該帳戶可存取whitelistdb數據庫的權限
  5. $password_comm = "pw"; //輸入root的密碼, 非root帳戶請輸入您該mysql戶口的對應密碼
  6. $comm = mysql_pconnect($hostname_comm, $username_comm, $password_comm) or trigger_error(mysql_error(),E_USER_ERROR);
  7. ?>
复制代码

完成後save

步驟六:
開啟whitelist插件的設定檔, 在服務器檔案位置 > plugin > whitelist > config.yml



  2. # Interval, in milliseconds, for checking if whitelist.txt needs to be reloaded.
  3. FileCheckInterval: 1000
  4. KickMessage: '&bSorry! you are not on the &fwhitelist!'
  5. # 開啟sql功能 改為 true, 預設是 false
  6. SqlEnable: true
  7. SqlDriver: com.mysql.jdbc.Driver
  8. # 輸入我們的資料庫名稱為 whitelistdb, 預設是DATABASENAME
  9. SqlDriverConnection: jdbc:mysql://localhost/whitelistdb
  10. # 數據庫密碼對應之前修改comm.php的資料
  11. SqlPass: pw
  12. # 數據庫帳戶對應之前修改comm.php的資料
  13. SqlUser: whitelistdb
  14. # 將tbl_names改為whitelist
  15. SqlQuery: SELECT name FROM whitelist WHERE name='<%USERNAME%>'
  16. # 將tbl_names改為whitelist
  17. SqlQueryList: SELECT name FROM whitelist
  18. # 將tbl_users改為whitelist
  19. SqlQueryAdd: INSERT INTO whitelist (name) VALUES ('<%USERNAME%>')
  20. # 將tbl_users改為whitelist
  21. SqlQueryRemove: DELETE FROM whitelist WHERE Name='<%USERNAME%>'
  22. SqlDriverJar: lib/mysql-connector-java-bin.jar
  23. DebugMode: false
复制代码

--
以上步驟已完成此插件的安裝及設定, 您現在可前往您的網站新增白名單
網址是 http://您的publicIP/addwhitelist/addwhitelist.php

示範: http://sfplace.com/addwhitelist/

如遇上網頁不能開啟或新增失敗, 請確認您的網頁伺服器是開啟的包括(apache & mysql).
