  Default:
    default: false
    permissions:
    - -bukkit.command.kill
    inheritance:
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    info:
      prefix: '&e'
      build: false
      suffix: ''
权限继承可以在权限文件下找到每个组 的 inheritance:这个在下面填入你需要继承的权限组比如说你想让default组继承builder组的权限就要这么写、
  Default:
    default: false
    permissions:
    - -bukkit.command.kill
    inheritance:
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    - builder
    info:
      prefix: '&e'
      build: false
      suffix: ''
