为每个玩家分配uid
uid从1开始计数，同时#sch233..serverID存储当前创立uid的总玩家数，关于先后细节看下面的"函数标签的用法"
为下一个作基础
为每个玩家添加专属nbt存储空间(脱离实体)
采用storage来进行存储，玩家的信息以{uid:<uid>,xx:xx,xxx:xx,...}的形式存储在列表sch233 -.player.storage[]中
默认存在{uid:0}作为标记
为表达方便
设sch233 -.player.storage[0]为列表最前，对应的[-1]为列表最后
以下x指执行者的uid，需要执行者有uid才能执行
        提供操作的函数有
后滚，仅改变顺序，把列表最前移动至列表最后 - sch233:func/player/storage/roll
前滚，仅改变顺序，把列表最后移动至列表最前 - sch233:func/player/storage/roll_back

  1. data modify storage sch233 -.player.storage append from storage sch233 -.player.storage[0]
  2. data remove storage sch233 -.player.storage[0]

  15.     #列表总长为#sch233_stemp.len temp,玩家的uid为@s uid,当前uid为#sch233_stemp.uid temp
  16.     #分别设为n, x, i

  32.             # say 向前滚结束

player调用了state，作用是把玩家的状态存入临时存储再存入到玩家的专属nbt存储中(sch233 -.player.storage[0].temp.item和-.player.storage[0].temp.location)以及从玩家专属存储中读取到临时存储再读取给玩家，注意这是以列表的形式存储的，所以读取的时候还可以附带一个#sch233_stemp.location.sort或#sch233_stemp.item.sort来指定读取第几位

  2. ### 输入    sch233_stemp -.player.storage[0].temp.location[i](storage)

  6. # ;
  7. # 清掉
  8.     data remove storage sch233_stemp -.state.location
  9. # 存入临时变量
  10.     data remove storage sch233_stemp list
  11.     data modify storage sch233_stemp list set from storage sch233 -.player.storage[0].temp.location

  13. # 如果没有输入则设为默认值
  14.     execute unless score #sch233_stemp.location.sort temp matches -2147483648..2147483647 run scoreboard players set #sch233_stemp.location.sort temp 0

  16. # 如果sort大于等于1则从前面开始清除，i等于几就清除几位
  17.     #   for(;i>=1;i--)remove sch233_stemp list[0]
  18.         execute if score #sch233_stemp.location.sort temp matches 1.. run function sch233:func/player/player_load/load_location/func/0_
  19.     #   ;
  20.     #递归后如果还存在列表则读取当前第一位，这覆盖了i>=0的状态
  21.         execute if score #sch233_stemp.location.sort temp matches 0 if data storage sch233_stemp list[0] run data modify storage sch233_stemp -.state.location set from storage sch233_stemp list[0]

  23. # 如果sort小于等于-2则从后面开始清除，i每比-1小1就多清除一位

  26.     #   ;

  36.     #@e[type=area_effect_cloud,name=temp_tp,tag=temp] temp(tag)
  37.     function sch233:func/player/state_load/load_location/run
  38. #   输出    传送执行者

function sch233:func/sys/new_dimension
  1. #强加载区块
  2.     forceload add 0 0
  3. #召唤marker，以及改数据
  4.     summon area_effect_cloud ~ ~ ~ {CustomName:'{"text": "dimension_marker"}',Duration:2147483647}
  5.     data modify entity @e[type=area_effect_cloud,name=dimension_marker,distance=..0.5,limit=1] Tags prepend from entity @s Dimension
  6. #发出信息
  7.     tellraw @a ["",{"selector": "@s","color": "green"},{"text": "发现了新的维度","italic": true,"color": "gray"},{"entity": "@s","nbt": "Dimension","color": "aqua"}]
