MineCraft Signal：处理操作系统信号并运行指令
为了更方便地从外部控制MineCraft服务器！
利用信号，结合MineCraft强大的内部指令，实现无限可能
1.9以上版本未测试

这是什么
当你发送一个"信号"给Minecraft服务器进程时，它会运行你定义好的指令
例如，你可以定义SIGUSR1信号为/stop指令，当MC服务器接收到这个信号时，他将运行这个指令来安全地停止服务器
（众所周知，MineCraft服务器无法从外部安全地停止）

图中，我向MineCraft服务器进程发送SIGINT（即按CTRL+C时发出的信号），MineCraft Signal按照我的配置文件，自动执行了以下指令：

/killall Guys, Server will shutdown now       说：基佬们我要关机了
/stop       安全停服


注意事项
1. 信号受操作系统影响。
2. 指令执行者是控制台，指令不需要以 / 开头

附：如何发信号
Linux
方法1：给所有Java进程发信号（不推荐）
eg: 发USR2信号
  1. pkill -SIGUSR2 java

eg: 发INT信号
  1. pkill -SIGINT java

方法1：给指定Java进程发信号（推荐）
eg: 发USR2信号
