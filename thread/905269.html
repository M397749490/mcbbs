MXBukkitLib
便捷,轻量,高效


功能
本插件集合了多许扩展API, 并提供了喜闻乐见的 data: url, 并提供了十分显眼的Logger

配置
  1. # 出错: 不建议使用
  2. jvm:
  3.     enable: false
  4.     clib: ./plugins/MXBukkitLib/attach.dll
  5. update:
  6.     #启动更新检测
  7.     enable: true
  8.     #启动自动更新
  9.     autoupdate: true
  10. events:
  11.     # 开启网络监听(和YUM冲突, 如果加载了 YUM 就不要用reload了)
  12.     NetEvent: true
  13.     # 启动日志监听
  14.     LogEvent: true
  15.     # 出错....
  16.     InstrumentationEvent: true
  17. system:
  18.     # 启动自带的网络监听
  19.     # 将输出执行的网络连接
  20.     # 需要启动 events.NetEvent
  21.     OPEN_NETWORK_SHOW:
  22.         enable: true
  23.         #输出连接失败错误
  24.         log_failed: false
  25.         #需要隐藏的插件名字列表
  26.         hiddens:
  27.             - McPay
  28.             #- "<unknown>"
  29.         logger:
  30.             prefix: ""
  31.             errPrefix: ""
  32.             CoreName: "&5NetWork"
  33.     #MCON 系统
  34.     mcon:
  35.         enable: false
  36.         passwd: "MCON"
  37.         port: 5741
  38. commands:
  39.     # 启动devtools命令
  40.     enable: true
  41. logging:
  42.     #删除系统错误日志输出
  43.     removeSystemErrorLogging: false
  44.     #使用MXLib的日志系统
  45.     useLibsLogger: true
  46.     SystemNoLogging:
  47.         # java.util.Level, Level's name
  48.         - DEBUG
  49.         #- OFF
  50.         #- SEVERE
  51.         - WARNING
  52.         #- INFO
  53.         - CONFIG
  54.         #- FINE
  55.         #- FINER
  56.         #- FINEST
  57.         - ALL
复制代码

本插件所用所有代码均为原创,不存在借用/抄袭等行为

适用版本是已测试版本. 并非只有这些版本的服务器才能用

请尽量不要使用OpenJ9, 目前因为OpenJ9会砍掉很多功能
