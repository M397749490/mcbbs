然后每次进linux
输入screen -dmS main
如果已经创建
则使用
screen -r main
恢复到那个screen
然后在java -jar...启动服务器
退出screen使用
ctrl+a 然后按d

你screen装载了吗  装了的话直接用
screen -S 名字创建一个新的屏幕
然后用cd指令到.jar核心所在的文件夹
然后输入java -Xmx最大内存 -jar 核心名称.jar 开启服务器
screen -r 名字 回到设置的屏幕
不这样的话服务器会在关掉终端时关闭
