指令&权限
  • 以下权限皆可配置
  • /parkour reset - 回到跑酷起点 并重置跑酷时间
  • /parkour checkpoint - 回到检查点
  • /parkour leave - 离开当前正在进行的跑酷
  • /parkour leaderboard <parkour> - 查看某个跑酷的排行榜

  • 以下权限皆为:parkour.admin
  • /parkour add <name> - 添加一个跑酷
  • /parkour remove <name> - 移除一个跑酷
  • /parkour list - 列出所有的跑酷
  • /parkour setreset <name> - 重置一个跑酷

[tr][td]
第一,确保你设置的 开始/结束 压力板均为金质压力板

第二,确保你设置的 检查点 压力板均为铁质压力板

第三,创建一个游戏(原帖竟然没有提到),输入指令
/parkour add <name> 这时的<name>就是下文需要用到的

第四,开始设置 开始/结束 的压力板

开始压力板:鼠标指针指向金质压力板,输入指令
/parkour setstart <name> 这时候的<name>就是你添加的跑酷名字

结束压力板:鼠标指针指向金质压力板,输入指令
/parkour setend <name> 这时候的<name>就是你添加的跑酷名字

第五,这时候就可以设置每个检查点的位置了
看着每一个铁质压力板,分别输入/parkour addcheckpoint <name>

第六,设置玩家输入/parkour reset时 重置时间 的位置,输入指令
/parkour setreset <name>这时候的<name>就是你添加的跑酷名字
(由于没有测试过,位置估计就是在输入指令的脚下方)

第七,加油,就差最后一步.输入指令
/parkour reload来重载所有的跑酷,也是为了让你新建的跑酷生效

当你完成以上步骤就大功告成了
