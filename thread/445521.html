直接把world的权限复制到sc的就行

那在GroupManager里把sc权限继承World权限即可
具体设置在GroupManager/Config
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
修改成
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
          sc:
          - users
          - groups

在让玩家进权限组时加一个world
例如让玩家进入vip1权限组
/manuadd 玩家名 vip1 world
这样在所有世界都会有权限而且配置文件也只会有一个世界
