JavaShell
在游戏和控制台中运行Java程序



介绍
一款适用于程序猿的插件，短小精悍，简单易用
它能让你在游戏和控制台中运行Java程序，以调试/测试代码
还可以从网络下载并运行Java程序
例如：http://net.voxela.com/javashell/run.html <-可点
  1. for (org.bukkit.entity.Player player : Bukkit.getOnlinePlayers()) { String prefix = ChatColor.DARK_GRAY + "[" + ChatColor.GOLD + "JavaShell" + ChatColor.DARK_GRAY + "] "; String serverName = Bukkit.getServer().getServerName(); player.sendMessage(prefix + ChatColor.GREEN + "I love " + serverName + "!"); player.playSound(player.getLocation(), org.bukkit.Sound.LEVEL_UP, Float.MAX_VALUE, 0.5F); }
复制代码

食用方法
下载插件
将文件扔进服务器的plugins文件夹，重启，测试

指令
/run 网址
如：/run http://net.voxela.com/javashell/run.html
/run 代码
如：/run Bukkit.getServer().getPlayer("your-name").sendMessage("Hey!");
/run Bukkit.getServer().getPlayer("your-name").teleport(new Location(Bukkit.getWorld("world"), 0, 100, 0));
