作者: 葉子の    时间: 2017-2-8 01:23
1.首先，你需要创造一个VIP用户组
方法：/mangadd VIP 这样就创建了一个名叫VIP的用户组
因为这个用户组是新建的，所以没有命令权限，只有基本的破坏等权限。
2.给它基本的命令权限
方法：/mangaddi VIP builder VIP用户组继承builder用户组的权限
因为builder在许多GroupManager插件中都已经配置好了，拥有基本的设置家，/BACK,/SPAWN/TPA等权限，所以让VIP用户组继承也是蛮好的。
VIP权限可以给出以下权限
essentials.fly 飞行权限
essentials.nick 修改昵称权限
essentials.god 无敌模式
essentials.hat  使物品戴至脑上
若是楼主满意还请设为最佳，谢谢。

1.首先，创建一个名为VIP的用户组
方法：：/mangadd VIP
注：此时该权限组不具备任何权限！
2.继承builder的权限
方法：/mangaddi VIP builder VIP
3.接下来如果玩家被放入VIP组，打什么就显示你无权与什么交互，因此下一步就是允许破坏
方法：在plugin/GroupManager/worlds/world里面找到groups.yml
此时你可以找到：（如果找不到就/manload重载一下插件）
  1. VIP:
  2.     default: false
  3.     permissions:[]
  4.     info:
  5.       build: false '将这里修改为true
  6.       prefix: ''
  7.       suffix: ''
复制代码

4.最后一步，添加前缀、后缀（可以省略）
直接在上方的prefix或者suffix的后面引号内添加就好，彩色代码：http://wiki.ess3.net/mc/

基本命令：manuadd 123 XXX 将玩家123添加到XXX用户组;manudel 123 将玩家123变为默认组;manuaddsub 123 XXX 将XXX用户组添加到玩家123的子用户组列表中;manudelsub 123 XXX 将XXX用户组从玩家123的子列表中剔除;manuaddp 123 essentials.* 为玩家123单独增加essentials.*权限(由于大部分权限都由Essentials基础插件提供，所以这是一般形式);manudelp 123 essentials.* 删除玩家123拥有的essentials.*权限;manulistp 123 列出玩家123所拥有的权限;manucheckp 123 essentials.* 检查玩家123是否拥有essentials.*权限，并寻找出处(用户组);manuaddv 123 prefix &1 设置玩家123的prefix变量为&1(变量目前有prefix(前缀)、suffix(尾缀)、build(破坏方块)三种，已有效);manudelv 123 prefix 删除玩家123的prefix变量;manulistv 123 列出玩家123所拥有的变量(虽然无效，但看还是能看的);manucheckv 123 prefix 查看玩家123的prefix变量属性(这里看的是用户组里的);mangadd XXX 添加名为XXX的用户组;mangdel XXX 删除名为XXX的用户组;mangaddp XXX essentials.* 为用户组XXX增加essentials.*权限;mangdelp XXX essentials.* 删除用户组XXX拥有的essentials.*权限;manglistp XXX 列出用户组XXX所拥有的权限;mangcheckp XXX essentials.* 检查用户组XXX是否拥有essentials.*权限，并寻找出处;mangaddv XXX prefix &1 设置用户组XXX的prefix变量为&1;mangdelv XXX prefix 删除用户组XXX的prefix变量;manglistv XXX 列出用户组XXX所拥有的变量;mangcheckv XXX prefix 查看用户组XXX的prefix变量属性;mangaddi XXX1 XXX2 使用户组XXX1继承用户组XXX2的权限;mangdeli XXX1 XXX2 将用户组XXX2从用户组XXX1的继承列表中删除(这个命令经测试发现有问题，删除不了);manpromote 123 XXX 将玩家123升级到XXX用户组;mandemote 123 XXX 将玩家123降级到XXX用户组listgroups 列出目前所存在的用户组。用途①创造VIP用户组1.首先，你需要创造一个VIP用户组方法：/mangadd VIP 这样就创建了一个名叫VIP的用户组因为这个用户组是新建的，所以没有命令权限，只有基本的破坏等权限。2.给它基本的命令权限方法：/mangaddi VIP builder VIP用户组继承builder用户组的权限因为builder在许多GroupManager插件中都已经配置好了，拥有基本的设置家，/BACK,/SPAWN/TPA等权限，所以让VIP用户组继承也是蛮好的3.给它特殊的命令权限(比如飞行)方法：/mangaddp VIP essentials.fly 输入这个命令你就给予了VIP用户组fly的权限(前提你有这个命令的权限) 按照这个格式，你※可以※像这样给予任何一个用户组、或一个人nike的权限，权限名如下/mangaddp 权限组名称 essentials.nike /manuaddp 玩家ID essentials.nike现在，一个基本的VIP用户组已经完工了，我们再加以修饰①特殊的前缀/mangaddv VIP prefix &4VIP给VIP用户组红色的VIP前缀，可以更改prefix为suffix设置尾缀特定用户组不掉落scavenger.scavenge - 允许恢复物品scavenger.level - 允许恢复等级scavenger.exp - 允许恢复经验值/mangaddp VIP scavenger.scavenge 给予VIP用户组恢复物品的权限 /mangaddp VIP scavenger.level 给予VIP用户组恢复等级的权限 /mangaddp VIP scavenger.exp 给予VIP用户组恢复经验的权限
