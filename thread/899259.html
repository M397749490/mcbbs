插件介绍

本插件可以转载，但是需要注明地址

这是一款加大生存难度的插件,杀得越多,带来的效应越严重

特点:
  • 杀得越多,死的越惨
  • 杀怪不在判断范围之内
  • 及时死亡也无法摆脱你的罪业
  • 被附加Karma时无敌事件只有 2tick(0.1s)
  • 显示需要PAPI
  • 罪业流过了你的血管





效果图 & GIF












使用方法


下载此插件然后放到plugins文件夹然后重启您的服务器

Q: 我要怎么看我的KillCount(杀生指数)
A: 使用 /kr show 查看
Q: 我要怎么清楚这个KR效果
A: 问服务器管理拿清楚道具
Q: 我要怎么拿这个道具
A: /kr rm <数值>



PAPI变量


  • %kr_killcount%  -- 玩家的 KillCount 指数
  • %kr_karma%  -- 玩家目前的 Karma 数目
  • %kr_nav_<length>_<flags>%  -- 生成一个 <length> 长的血条
  • 请使用 此工具 编辑
  • %kr_showifkarma_<v1>_<v2>% -- 当玩家拥有 karma 值的时候返回 <v1> 的内容, 反之返回 <v2> 的内容
  • %kr_showifkr_<v1>_<v2>%  -- 当玩家已经进入 KR 惩罚阶段的时候返回 <v1> 的内容, 反之返回 <v2> 的内容


  2. # Action bar 标准内容
  3. # 复制 text 的内容到支持 Action Bar 的插件里面获取更好的效果

  10.   enchants:

  16.   display: "\u00a7bKarmicRetribution\u00a76 reset"
  17.   #注释
  18.   lore:
  19.     - "\u00a7b右键使用, 使用后可以减少KR点"
  20.   #判断行
  21.   remove_line: "\u00a77KarmicRetribution REMOVEX #"
  22. check:
  23.   #检查显示名
  24.   display: true
  25.   #检查材质
  26.   material: true
  27.   #检查附魔
  28.   enchants: true
  29.   #严格检查附魔
  30.   enchants_strict: false
  31.   #检查注释
  32.   lores: false
  33.   #允许出现负数的kills
  34.   allow_negative_kills: false

权限列表


  • kr.command            -- 允许使用 /kr 主命令
  • kr.command.set.me     -- 允许设置自己的 killcount 数值(OP)
  • kr.command.take.me    -- 允许为自己移除指定数值的 kc (OP)
  • kr.command.add.me     -- 允许为自己添加 kc (OP)
  • kr.command.show.me    -- 允许显示自己的 kc
  • kr.command.set.other  -- 允许设置其他人的 kc (OP)
  • kr.command.take.other -- 允许为其他人移除指定数值的 kc (OP)
  • kr.command.add.other  -- 允许为别人添加 kc (OP)
  • kr.command.show.other -- 允许查看其他人的 kc (OP)
  • kr.command.rm         -- 允许使用 /kr rm <value> 命令 (OP)
