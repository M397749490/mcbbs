啥玩意？你的算法和chyx不一样还是什么意思？没学过C艹……

初始朝向是(0,0,1)，假设指定一个切向（1,0,0）
然后分别绕轴旋转thx,thy,thz(顺时针还是逆时针不太清楚，可能差负号)
然后线性变换，将矩阵
[cos thx  -sin thx 0]
[sin thx   cos thx 0]
[0   0            1]

[cos thy  0 -sin thy]
[0          1  0]
[sin thx  0   cos thx]

[1  0           0]
[0  cos thx  -sin thx]
[0  sin thx   cos thx]
相乘，然后作用在(0,0,1)和(1,0,0)得到
目标方向(x,y,z)和切向(-y cost +x sint,x cost + y sint,0)
这里的向量弄成长度为1的。
如果xy全为0，就换一个切向，例如(0, -z cost +y sint, y cost+z sint)
最后反解出thx, thy, thz
