Go

 一：效果部分

Attribute 属性强化
该属性必须为你在Attr文件所创建的Skapi属性
若找不到Attr文件 请进入Config文件开启。
触发获得一段时间属性加成


Attribute /填属性名称
复读：该属性必须为你在Attr文件所创建的Skapi属性
若找不到Attr文件 请进入Config文件开启。

Amount /填属性值，也就是加多少属性
Second /属性增长持续的时间

适用技能：被动BUFF系列。

Block 生成方块

在目标周围生成立体几何(？方块
起到阻碍目标行动 或抵挡技能及攻击的效果。
使用后生成方块

Shape /形状 Sphere是球形，cuboid是长方形
Type /替换种类 Air是空气，any是所有，solid是实体方块
  所谓替换种类 则是所生成的方块将会以哪一种方式出现
 例如：Air空气，则生成的方块不会替换原有方块，仅出现在空气中
Block /方块 意思是生成哪种方块
Block date /是方块附加值 用于控制颜色等
Seconds /持续时间
Forward offset /向前多少格生成
 offset的意思是 以自己为中心的生成坐标的位移
 下同
Upward offset /向上多少格
Right offset /向右多少格
Radius /方块半径

适用技能：风墙(阻挡目标技能)，牢笼(使对方暂时困在方块墙内)




Cancel 中断吟唱
将自身的前摇打断
同时取消这一次的技能释放..(稳亏不赚
与吟唱配合使用 使用后直接取消当前吟唱

适用技能：基础技能




Channel 吟唱
吟唱一段时间后释放接下来的技能
可被打断
这是很不错的前摇方式
使用期间玩家不能移动，攻击或使用其他的什么什么东西
吟唱结束后 释放接下来的效果

Seconds /持续时间适用技能：法师的前摇吟唱


Cleanse 净化
猝不及防的净化让对方的DEBUFF失效
达到以完美状态迎接战斗的效果。
类似于牛奶

Potion /清除的DEBUFF的类型
Status /清楚的状态的类型

适用技能：净化，圣洁之光(雾



Cooldown 冷却缩减
减少自己技能的CD
连招技能必备效果。
为自己的技能减少冷却时间

Skill /填减少冷却的技能名字，ALL则是所有技能
Type /类型 Seconds是减少秒数，另一个是按照技能冷却的百分比减少冷却
Value /减少的值

适用技能：续航及收割型被动技能




Damage 造成伤害
很基础的一个属性
伤害高才是王道。、
对敌人造成伤害

Type /类型 Damage是伤害，Mu~的是倍数算法，后不解释 自己琢磨(用得比较少
若使用了倍数算法 则以敌人最大血量的百分比造成伤害(切肉效果)
以此推论 之后的两个选项是以敌人当前血量的百分比(收割效果)、敌人已损血量的百分比(斩杀效果)
Value /伤害值 若是Mu~则是倍数
True Damage /是否造成真实伤害 无法被防御力抵消的那种

适用技能：所有能造成伤害的技能




Damage Buff 攻击BUFF
给自己一个强有力的攻击BUFF
造成一段时间的巨额伤害打击。
获得一段时间的攻击加成

Type /类型 Flat是数值运算，Mu~是倍数运算
数值运算就是简单的为你增加一个伤害值，倍数运算则是取你所能造成的伤害的百分比进行乘法运算后，再造成伤害
Skill Damage /是否为技能伤害
若选择了true，则只加强技能所造成的伤害。若选择了false，则只加强平A造成的伤害。若想两个都加强，请写两个不同的效果。
Value /攻击加成的值或倍数
Seconds /持续时间

适用技能：被动BUFF，狂暴(雾




Damage Lore 攻击标签 ！！！
若你想让技能与你的武器伤害联动
就可以使用这个效果了。
自行设置一个正则表达式(lore) 后取拥有该正则表达式的lore进行运算
乘上倍数 最后造成伤害

Hand /主副手 Main是主手，Offhand是副手，他只取你所选定的主副手的lore
Regex /正则表达式
当你的正则表达式为    攻击: {value}   时，并且你希望你的武器攻击力为100
你的武器上必须有一条lore为   攻击: 100   此时该效果并生效了
Multiplier /获取玩家武器攻击进行乘法运算造成技能伤害
当武器的lore为  攻击: 100   ，multiplier为2时，释放该技能，最终伤害则为100x2 =200 点技能伤害
True Damage /是否造成真实伤害 (前面提到了)

适用技能：任何造成伤害的技能




Defence Buff 防御BUFF与攻击加成类似的防御加成。
和攻击BUFF类似，只不过换成了防御
不做详解 动动脑子

适用技能：被动BUFF技能




Delay 延迟
真正的逼格技能从延迟开始
你可以使你的技能有一段时间的间期。
让你的技能变得动态起来

让技能延迟释放，怎么用就不详解了
