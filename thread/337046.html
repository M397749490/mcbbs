FAQ（懒得翻译）

~~~~~~~~~~~~~ Common FAQ: ~~~~~~~~~~~~~

Q: When I right-click my screen it says "You need Java 32 bits" or "Installation failed; please read FAQ."
A: Usually this happens because you don't use the default Minecraft launcher, or because you didn't select the Forge profile, or because you used the manual installation and it failed (then please use the installer). Else, please read what is in the next spoiler:
（Start the Minecraft launcher. Check that the selected Profile is Forge and click on "Edit Profile".
In the "Java Settings" category, check "Executable" and in the text field put the path to your javaw.exe from your 32 bits Java ! Click Save profile and enjoy

To find your java 32bits path:
Usually it's C:\Program Files (x86)\Java\jre7\bin\javaw.exe if this file can't be found, then open C:\Program Files (x86) if this directory doesn't exist, then you have a 32bit windows, just start the game. Go to the Java directory. If it doesn't exist or if there is no folders inside it, then please Install java 32 bits.
Now open the jreX folder or jdk1.X.Y_Z where X is at least 7 (can be higher but NOT lower. If it's lower, install java 7 32 bits). Open the bin folder. You have found you java 32 bits path. Copy it and past it in the "Executable" field, don't forget to add \javaw.exe after it.

Java 32bits download:
Go here: http://www.java.com/...load/manual.jsp and select "Windows offline (32-bit)".）
Q: Where can I find my logs?
A: Minecraft logs can be found in the ForgeModLoader-client-0.log file that you can find in your %appdata%/.minecraft folder. You need to shut down minecraft to find this file!
Installer logs are generated in the WDI_x.y_Log.log file which is the same folder as the installer executable!

Q: MagicLauncher?
A: Magic Launcher is not supported. Please use the default original Minecraft launcher.

Q: It's says I need flash, or that Flash is not up-to-date.
A: Please download "Flash Player for other browser" from here. Select your operating system in Step 1, then select "Flash Player xx for Other Browser" (where xx can be any number) in Step 2, and then click "Download now" on the right. As well don't forget to install it.


~~~~~~~~~~~~~ Other FAQ: ~~~~~~~~~~~~~

Q: Why is your mod only available on Windows?
A: Well, the library I'm using to provide internet rendering, called Awesomium, is only available on Windows & Linux

Q: Now that I installed your mod, Minecraft says that I need a 64 bit Java Installation to set my render distance to "Far".
A: Yes, because my installer forces your Minecraft to run in 32 bits mode, because there are no 64 bits version of Awesomium.

Q: When I right click on the screen, nothing happens.
A: Check in the config file that the "create" option is set to false, or that the server you are playing on enables you to create web screens even if you are not OP. Else, there were a problem during the installation of the mod. Please send me your Minecraft log.

Q: I LAAAAAAAAG with your mod
A: Try a lower ppp (real Pixels Per minecraft Pixels) in your config file and check that anisotropicLevel is set to 0. You can increment update & render rates in your config file too.

Q: How can I change the home page / the language of the the browser:
A: You can do all that stuff in your config file in the misc category.

Q: I don't want to be allowed to craft screens / that you have to be OP to use screen:
A: Check your config file.

Q: Your installer tells me something about 32 bits / 64 bits java and bring me to the java download page
A: Yes. You need a 32 bit version of Java to run my mod. Simply follow the instructions given by my installer. I'm sorry about that.

Q: I want to put your mod in my mod pack:
A: Well, if it's a private server mod pack, be free. Else, please ask by sending me a PM.

Q: Now that I installed your mod, I can't allow more than 1 giga of ram to Minecraft.
A: Yes. This is because you need java 32 bits for my mod. This is horrible I know, but I have no way to fix that.

Q: MAC?
A: Maybe.

Q: Linux?
A: Coming very very soon.

Q: Fullscreen YouTube videos doesn't work
A: Yes. I'm not sure that I can fix this bug.
