这款插件 可以让你自定义玩家 加入游戏,退出游戏时候的 消息

最新版本的
插件的命令 如下所示：


/setjoin [msg]     设置玩家加入游戏时显示的消息，所有玩家都看的见
/setquit [msg]     设置玩家离开游戏时显示的消息，所有玩家都看得见
/setkick [msg]     设置玩家被T的时候的消息， 我没发现什么情况会触发这个
/setplayerjoin <player> [msg]    设置一个玩家加入服务器的时候消息，所有玩家可以看见
/setplayerquit <player> [msg]    设置一个玩家退出服务器的时候消息，所有玩家可以看见
/setmyjoin [msg]             设置我加入服务器时候的消息，需要权限
/setmyquit [msg]             设置我退出服务器时候的消息，需要权限



插件的权限如下所示：




customjoin.*          可以使用所有插件的命令
customjoin.set        可以使用所有的set命令，默认OP拥有
customjoin.set.own    可以设置自己的加入/退出消息， 默认OP拥有
customjoin.colors       允许在消息中使用颜色代码，默认OP拥有
customjoin.formats    允许在消息中使用格式化代码(变量) ， 默认OP拥有


1.4.1 版本插件的命令：


/setmsg <join|quit|kick> [message]      设置 <加入|退出|被T>  的消息
/setplayermsg <player> <join|quit|kick> [message]   设置 玩家 <加入|退出|被T>  的消息
/customjoin     重新加载配置


额外说明：

变量的话， 有:  %player      这个表示玩家的DisplayName (就是有前缀和玩家ID的那个）  
和  ： %reason    这个表示被T 的理由
所有的[msg] , [message]    都是可选的，就是可以不填写， 如果不填的话， 就会重置消息。


配置文件：
  1. #config.yml 文件
  2. # Always put your messages in single-quotes! Otherwise the
  3. # YAML parser will not be able to parse the messages correctly!
  4. # Also, if you want to use special characters, remember to save
  5. # the file with the UTF-8 encoding.

  7. # This will force the plugin to use the actual player name instead of the
  8. # display name. Set this to true if you are getting problems with changing
  9. # names in login- and logout-messages.
  10. #如果把下面的选项设置成true， 就会用玩家真实的名字 代替 DisplayName(带前缀的)
  11. force-real-name: false

  13. # Limit the length of custom message formats. Set to 0 to disable.
  14. # 自定义消息的长度，设置为0 可以禁用这个选项
  15. message-limit: 70

  17. # Require %player to be in the format for the specified commands.
  18. # 这是啥意思， 我怎么看不懂。。。
  19. require-player-name:
  20.   # For /setjoin, /setquit and /setkick
  21.   # /setjoin, /setquit 和 /setkick 命令
  22.   set: false
  23.   
  24.   # For /setmyjoin and /setmyquit
  25.   # /setmyjoin 和 /setmyquit  命令
  26.   setmy: false
  27.   
  28.   # For /setplayerjoin and /setplayerquit
  29.   # /setplayerjoin 和 /setplayerquit 命令
  30.   setplayer: false
复制代码


  1. #formats.yml文件
  2. # To disable a message, set the format to 'none'.
  3. # 禁用某个消息， 把它设置成 'none' 就可以了
  4. default:
  5.   join: '&e%player joined the game'
  6.   quit: '&e%player left the game'
  7.   kick: '&e%player was kicked: %reason'
