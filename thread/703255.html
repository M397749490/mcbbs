1.无法生成怪物
/mw setflag [世界名] SpawnMonster false
注意：该方法将禁止生成全部怪物，使用多世界插件无法只禁止生成原版怪物。
2.改变默认模式
同样的，使用多世界插件无法改变默认模式。
3.改变权限组
这个和多世界无关，应当是GroupManager的问题

首先，尝试镜像主世界

您首先打开GroupManager的Config文件

找到settings-mirrors-world
将下面的内容替换为如下：
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           all_unnamed_worlds:
  9.           - users
  10.           - groups
复制代码

这样子将让末地镜像主世界的权限

其次，如果要单独世界权限，则

打开GroupManager的Config文件

找到settings-mirrors-world
将下面的内容替换为如下：
        world:
  1.           world_nether:
  2.           - users
  3.           - groups
  4.           all_unnamed_worlds:
  5.           - users
  6.           - groups
复制代码
