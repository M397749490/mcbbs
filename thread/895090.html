介绍
还在对Minecraft时时出现在右上角的消息框感到困扰吗？这个mod可以允许你控制哪些消息框会显示。默认情况下，MC原版会显示所有消息框，包括配方解锁、进度、复述功能和新手教学。
这个mod在默认情况下，禁用了配方解锁和进度。它也可以通过配置，禁用进度和复述功能。
添加一个键位（默认为J键）可以直接关闭所有消息框。
配置文件

  1. # If advancement toasts are blocked. Enabling will block ALL advancements.
  2. # 是否禁用进度消息框。启用后将会禁用所有进度消息框。
  3. B:"Disable Advancements"=true



  7. # If all toasts are blocked.
  8. # 是否禁用所有消息框
  9. B:"Disable All"=false



  13. # If all non-vanilla toasts are blocked. Blocks all toasts that do not extend vanilla classes.
  14. # 是否禁用所有非原版消息框。禁用所有不是继承原版类的消息框。
  15. B:"Disable All Non-Vanilla"=false



  19. # If all vanilla toasts are blocked. Includes advancements, recipes, system, and tutorials.
  20. # 是否禁用所有原版消息框。包括配方解锁、进度、复述功能和新手教学。
  21. B:"Disable All Vanilla"=false



  25. # If recipe unlock toasts are blocked. Blocks "you have unlocked a new recipe" toasts.
  26. # 是否禁用配方书解锁消息框。即“你解锁了一个新的合成”消息框。
  27. B:"Disable Recipes"=true



  31. # If system toasts are blocked. This is used only for the narrator toggle notification right now.
  32. # 是否禁用系统消息框。目前只用来针对复述功能。
  33. B:"Disable System Toasts"=false



  37. # If tutorial toasts are blocked. Blocks useless things like use WASD to move.
  38. # 是否禁用新手教学消息框。即创建新实例创建第一个存档后叫你用WASD来移动之类的消息框。
  39. B:"Disable Tutorials"=true



  43. # How long (in ticks) to force a toast to show for. Higher is longer.
  44. # 消息框将为显示多少时间（单位为 tick），这个数字越大即更长
  45. I:"Forced Display Time"=0



  49. # If toasts are slightly translucent.
  50. # 消息框是否设置为半透明。
  51. B:"Translucent Toasts"=true



  55. # If toasts do not draw a background.
  56. # 消息框是否设置为全透明
  57. B:"Transparent Toasts"=false
