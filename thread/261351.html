此插件和Spoutcraft客户端配合，即可在服内不通过mod而使用各种特效功能

示例截图：






包括功能：

自定义皮肤、披风和全部文字
自定义物品材质
自定义物品名称
自定义材质包
自定义天空、云、星星、能见度、太阳、月亮、天气渲染、生物群落、迷雾等等
自定义粒子效果
自定义GUI
自定义声音（可以向客户端点歌神马的）
自定义成就提示
自定义HUD
自定义背景音乐
能够和mod一样检测按键事件
自定义跳跃高度
自定义重力强度
自定义移动速度（走路、游泳）
服务器自动重连
编辑剪切板内容
自定义路标&死亡坐标
···

很多插件都能够通过Spoutcraft来使用自定义的GUI界面，例如DragonTravel、AuthMe-Reloaded、Heroes、Quickshop等等等等
一些经典插件：
http://dev.bukkit.org/bukkit-plugins/spout-guide/
http://dev.bukkit.org/bukkit-plugins/morematerials/
http://dev.bukkit.org/bukkit-plugins/spoutessentials/
（论坛内也有转载相关插件，例如http://www.mcbbs.net/thread-241716-1-1.html）

配置详解：

  1. # 非Spoutcraft客户端登陆后的踢出信息
  2. ForceClientKickMessage: This server requires Spoutcraft! http://get.spout.org
  3. # MC版本检查
  4. MinecraftVersionCheck: true
  5. # 客户端检查延时
  6. ClientCheckTicks: 200
  7. # 区块数据缓存
  8. ChunkDataCache: true
  9. # 允许客户端缓存
  10. AllowClientCache: true
复制代码
