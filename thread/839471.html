找到
  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |         Essentials 出生设置 / 新玩家设置             | #
  4. # +------------------------------------------------------+ #

  7. newbies:
  8.   # 是否显示某玩家第一次进服时的欢迎信息
  9.   # 若开启,编辑内容,{DISPLAYNAME}将自动转换为玩家名字.
  10.   # 若取消,改为''
  11.   #announce-format: ''
  12.   announce-format: '&d欢迎新玩家{DISPLAYNAME}&d来到服务器!'

  14.   # 当我们第一次出生时,出现在哪个出生点？
  15.   # 如果你想要使用世界自带的出生点,则设置为"none".
  16.   spawnpoint: default

  18.   # 是否想要玩家第一次进入服务器时赠送新手礼物? 设置为 ''禁用此功能.
  19.   # 这个赠送不会花费金钱,也可以给予权限.
  20.   #kit: ''
  21.   kit: tools
复制代码
将kit: tools 改为你想赠送的礼包名字即可
