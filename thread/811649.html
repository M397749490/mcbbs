下面以1.12版本的函数为例
1.前提
一个循环函数内的所有命令会在1tick内同时运行
(如果中间有引用其他函数先执行这个函数再执行下面的命令)
mc中的一个循环周期为1tick
一秒有20tick，也就是说
一个循环函数一秒运行20次
所以：
  1. scoreboard objectives add tick dummy 创建tick
复制代码
一秒20tick：
  1. scoreboard objectives add sec dummy 创建sec
  2. scoreboard players add @a tick 1 循环tick加1
  3. scoreboard players add @a[score_tick_min=20] sec 1 当tick满20时sec加1，相当于加一秒
  4. scoreboard players set @a[score_tick_min=20] tick 0 重置tick
复制代码
这样，记分版sec的数值就会1秒加1
二.计时
假设需要30秒逃离一个地方，时间一到就会死亡
那么：
  1. execute @a[score_sec_min=30] ~ ~ ~ kill @s 时间一到杀死玩家
  2. execute @a[score_sec_min=30] ~ ~ ~ scoreboard players set @s sec 0 重置时间
复制代码
三.倒计时
有些地图我们会看到倒计时
那么：
  1. scoreboard objectives add tick dummy 创建tick
  2. scoreboard objectives add sec dummy 创建sec
  3. scoreboard players add @a tick 1 循环tick加1
  4. scoreboard players set @a sec 30 倒计时30秒
  5. scoreboard players remove @a[score_tick_min=20] sec 1 当tick满20时sec减1，相当于减1秒
  6. scoreboard players set @a[score_tick_min=20] tick 0 重置tick

  8. execute @a[score_sec=0] ~ ~ ~ kill @s 时间一到杀死玩家
  9. execute @a[score_sec=0] ~ ~ ~ scoreboard players set @s sec 30 重置时间
复制代码
四.定时
比如挂机五分钟提醒自己时间到了
那么：
  1. scoreboard objectives add tick dummy 创建tick
  2. scoreboard objectives add sec dummy 创建sec

  4. scoreboard objectives add min dummy 创建min
  5. scoreboard players set @a min <数值>  计时<数值>分钟

  7. scoreboard players add @a tick 1 循环tick加1
  8. scoreboard players add @a[score_tick_min=20] sec 1 当tick满20时sec加1，相当于加一秒
  9. scoreboard players set @a[score_tick_min=20] tick 0 重置tick
  10. scoreboard players remove @a[score_sec_min=60] min 1 当sec满60时min减1，相当于减1分钟
  11. scoreboard players set @a[score_sec_min=60] sec 0 重置sec

  13. execute @a[score_min=0] ~ ~ ~ playsound entity.arrow.hit_player master @a ~ ~ ~ 10 1 提醒玩家
  14. execute @a[score_min=0] ~ ~ ~ scoreboard objectives remove min 清除计时
