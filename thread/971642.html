Config
  1. # 玩家进入服务器的声音 需给权限vjm.joinsound.声音名 "false"关闭
  2. # 声音名见https://github.com/Deewkz/VIPJoinMessage/wiki/VIP-JOIN-MESSAGE---SOUND-LIST

  4. JoinSound: "false"

  6. # 管理员进入服务器的声音名 "false"或""关闭
  7. # 声音名见https://github.com/Deewkz/VIPJoinMessage/wiki/VIP-JOIN-MESSAGE---SOUND-LIST

  9. OpPlayer_JoinSound: "false"

  11. # 默认玩家进出服务器的信息

  13. DefaultJoinMsg: "true"
  14. DefaultLeaveMsg: "true"
  15. DefaultJoinMessage: "&7玩家 &a%player% &7进入了游戏！"
  16. DefaultLeaveMessage: "&7玩家 &c%player% &7离开了游戏！"

  18. # 管理员进出服务器的信息

  20. OpPlayerJoinMsg: "true"
  21. OpPlayerLeaveMsg: "true"
  22. OpPlayerJoinMessage: "&b\n&6&l管理员 &a&l%player% &6&l来查水表啦~\n&b "
  23. OpPlayerLeaveMessage: "&b\n&6&l管理员 &c&l%player% &6&l查完水表啦~\n&b "

  25. # 拥有 VJM.JoinRank.数字 权限的玩家进入服务器的信息
  26. # 可添加数字 但不要超过30个

  28. JoinMessages:
  29.   1: "&b&lVIP玩家 &a&l%player% &b&l进入了游戏！"
  30.   2: "&d&lSVIP玩家 &a&l%player% &d&l进入了游戏！"
  31.   
  32. # 拥有 VJM.LeaveRank.数字 权限的玩家离开服务器的信息
  33. # 可添加数字 但不要超过30个

  35. LeaveMessages:
  36.   1: "&b&lVIP玩家 &c&l%player% &b&l离开了游戏！"
  37.   2: "&d&lSVIP玩家 &a&l%player% &d&l进入了游戏！"
复制代码

权限

权限 用途
VJM.default 默认玩家进出信息
VJM.JoinRank.数字 指定数字玩家的进入信息
VJM.LeaveRank.数字 指定数字玩家的离开信息
VJM.AdminCMDS 管理员权限 *

命令

命令 用途
/vjm help 获取插件帮助
/vjm version (/vjm ver) 查看插件版本
/vjm reload (/vjm rl) 重载插件 *
