每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。
Minecraft 1.14 仍未发布，19w09a为其第24个预览版。
转载本贴时须要注明原作者以及本帖地址。
MINECRAFT SNAPSHOT 19W09A
A Village & Pillage Java Snapshot
Java版1.14快照19w09a

We got a fever and the only prescription is more cowbell.
我们发烧了，唯一的的处方是更多的牛铃。

CHANGES IN 19W09A
19W09A变更列表
  • Added new Note block sounds
  • 添加了更多的音符盒音效
  • Fixed bugs
  • bug修复
  • Sprites for particles can now be configured in resource packs (though particle still controls how they will be used)
  • 粒子效果的图像现在可以被资源包修改（即使粒子效果依旧决定了它们自己如何被使用）

NOTE BLOCK
音符盒
  • 5 new Note block sounds have been added: Iron Xylophone, Cow Bell, Didgeridoo, Bit, and Banjo
  • 五种新的音符盒音效被添加：铁木琴，牛铃，迪吉里杜管，Bit风格音效和班卓琴
  • 1 previously existing, but unused, sound effect has now been made available: Pling
  • 一种以前就已经存在但未被使用的音色现在也有效了：Pling（这是啥）
  • The new Note block sounds can be heard by using Iron Blocks, Soul Sand, Pumpkins, Emerald Blocks, Hay Blocks, or Glowstone
  • 将音符盒放置在铁块，灵魂沙，南瓜，绿宝石块，干草块和荧石块上，你将会听到新的音符盒音效

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要魔法上网。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验预览版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。

狐狸有一个装备槽的，跟僵尸一样
PS.
狐狸生成的时候就有几率携带一个东西，这些东西会在一个战利品表中选取（包括绿宝石）。
被杀死的时候，天然携带的东西只是有几率掉。
狐狸生成的时候如果没带东西，会寻找掉落物（可以是任何东西）然后叼在嘴里，但它们更偏好浆果。
如果它发现浆果的话，会把嘴里的东西放下（跟僵尸发现更好武器时的行为一样），然后叼浆果。
狐狸会捕杀鸡、兔子等小动物。
狐狸嘴里的东西的特性依然生效，带火附魔的武器攻击会着火，带不死图腾的话被杀死会复活……
