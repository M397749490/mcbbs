标题: ToolBox制作Flan盔甲模型
做了一个盔甲模型，预计全部都是胸甲，所以在Model Part里全选了body，Model Type选了Armor。编译后配置文件如下
//---Standard Armor Config for Flans Mod----------
//Created by Minecraft-SMP Toolbox 2.2.2.2


//---Standard-------------------------------------
// Naming
Name R_V1
ShortName R_V1


// Visuals
Colour 255 255 255
Icon R_V1


// Recipe


//Misc

//------------------------------------------------

//---Armor----------------------------------------
//Type
Type Body


//Visuals
ArmourTexture R_V1

//Armor Settings
Defence 0.1


//Helmet Settings

//------------------------------------------------

但是进入游戏以后装备以后模型加载不出来。
