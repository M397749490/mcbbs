作者: _E_S_    时间: 2016-8-6 15:46
EssentialsX默认玩家没有建筑权限
如果出现玩家无法破坏方块，请输入指令
/mangaddp default essentials.build

在config中
玩家是否可以使用物品(当玩家没有build权限的时候):
设置为 true 可以禁用那些没有权限玩家的使用物品
设置为 false 将使 EssentialsAntiBuild 从不阻止玩家使用物品
use: true
