使用方法

下载插件，丢进plugins，重启，没了


配置文件[必看]
  1. # 不支持&，请使用§达到彩色字目的！
  2. Menu:
  3.   Title: "&1&l音乐菜单"   # 音乐菜单的标题
  4.   OpenMessage: "&a你打开了音乐菜单！选择一首喜欢的播放吧！"   # 打开菜单后的提示语
  5. Messages:
  6.   NoPermissions: "&c你没有权限执行这个指令"   # 无权限提示
  7.   SenderIsConsole: "&c只有玩家能够使用这个指令"   # 控制台执行/pmgui指令提示
  8.   Playing: "&6正在播放: %music%"   # 开始播放的提示，变量：%music%为歌曲名(菜单图标的展示名)
  9.   StoppedRecord: "&c你关闭了唱片的播放"   # 关闭唱片播放提示
  10.   StoppedBackgroundMusic: "&c你关闭了背景音乐"   # 关闭背景音乐提示
  11.   Reloaded: "&a重载完毕"   # /pmreload重载配置文件后提示
  12. #——————————
  13. StopPlayingRecord:   # 图标：停止唱片播放
  14.   ID: 351   # 图标ID
  15.   SubID: 2   # 图标子ID，应该不支持
  16.   Amount: 1   # 图标显示的数量
  17.   DisplayName: "&c&l停止播放唱片"   # 图标展示名
  18.   Lore:   # 图标描述
  19.     - "§b如果你播放了唱片"
  20.     - "§b你可以通过此选项来关闭"
  21. StopPlayingBackgroundMusic:   # 图标：停止背景音乐
  22.   ID: 351   #同上，暂时不支持子ID
  23.   Amount: 2   # 同上
  24.   DisplayName: "&c&l停止播放背景音乐"   # 同上
  25.   Lore:    # 同上
  26.     - "§b使用此选项，你可以快速"
  27.     - "§b关闭游戏背景音乐，包括"
  28.     - "§b上面已经开始播放的游戏"
  29.     - "§b背景音乐。"
  30. #——————————
  31. Music1:   # 图标：第一首音乐
  32.   ID: 35
  33.   SubID: 15   # Music1的子ID不支持，Music2-18都支持
  34.   Amount: 1
  35.   DisplayName: "&e唱片：13"
  36.   Lore:
  37.     - "§bMinecraft原版音乐"
  38.     - "§a点击播放"
