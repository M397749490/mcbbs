如何设置每个世界的不同权限？
比如：你在生存世界有tpa的指令 换个地狱就没有tpa的权限 怎么做到？{:10_492:}
作者: lichi2050    时间: 2015-2-19 15:17
*  \plugins\GroupManager\worlds\世界名\groups.yml
*
  1.   mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds: #删除这一级
  16.           - users
  17.           - groupsall_unnamed_worlds
复制代码

*删除
          all_unnamed_worlds:
          - users
          - groupsall_unnamed_worlds
* 然后每一个世界都有他们的权限组
