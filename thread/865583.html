终极自动重启
插件介绍
：服务器重启
重启后...
：赔我东西
：我说过了重启
：说30秒的，只过20秒，我正在合成东西都没了，赔出来
：.......
还在担心服务器内总有一些玩家看不见重启而丢了东西吗，这个插件完美解决了你的问题
只需要一个指令就可以设定重启的时间，再也不担心某些玩家说自己没看见说重启，要求索赔了
设定定时重启还可以帮助各位一些服务器的服主清理服务器的缓存哦

插件特色
1.可以设定每段时间进行自动重启，但只能以秒为单位
2.自行调整该插件的指令
3.重启时强制保存世界
4.可以手动设定下次重启时间
5.PAPI变量支持
6.支持BOSS血条，title，聊天信息的自定义
7.配置简单

指令和权限
/autorestart now [秒]     -在多少秒后重启服务器      uar.now
/autorestart stop     -停止本次重启      uar.stop
/autorestart reload     -重载配置文件      uar.reload
所有权限 uar.commands

PAPI变量
%ultimateautorestart_seconds%
%ultimateautorestart_formatte%

说明
本插件只负责关服务器，不负责开启，若要自动开启服务器，请在bat文件后加入代码
window系统格式
  1. @ECHO OFF
  2. :start
  3. java -Xmx1024M -Xms1024M -jar 服务器核心.jar -o false
  4. goto start
复制代码
Linux系统格式
  1. #!/bin/sh
  2. screen -s server -X stuff "stop"
  3. screen -s server -X eval "stuff \015"
  4. sleep 15
  5. cd <path to the folder your startup script is stored in>
  6. ./start.sh
