啥是CustomSpawners?
CustomSpawners让你能让任何方块变成一个刷怪器![刷怪笼呢?双倍刷怪!] 这些刷怪器可以是任何类型的, 有很多可配置的特性, 并且能变成隐藏的因为像石头,草方块,甚至是空气的材料都能变成一个刷怪器!你创建它之后, 你可以用MCedit来做同样的刷怪方块[也就是说直接复制]!
生物的类型也可以自定义.创造像是只有半颗心的巨大史莱姆,不同颜色的羊的属于你的生物的生怪器！如果你想要无限的BOSS,你可以试试有攻击削弱和回复药水效果的巨人或是JJ怪！
一些关于CustomSpawners的创意:
  • 使多人游戏的生物地牢只在你接近的时候出现![省服务器资源]
  • 制作有强力怪物关卡的竞技场!
  • 创造直到解决前不会关闭的生怪笼!
  • 创造只可以被物品或物体毁坏的实体!
  • 制作超动态的根据在里面的玩家数量而改变的地牢![这个绕来绕去翻死我了]
  • 在游戏中做自定义的刷怪器! (不要求用MCEdit!)

Getting Started

Tutorial video coming soon! If you make a video about CustomSpawners, let me know and I could post it here!

To get started using CustomSpawners, load it into your server and configure it appropriately. Make sure no other copies of CustomSpawners are in the plugin directory.

Next, go in game and type in "/entities create <type of entity>". This creates a default entity of the type you specify. Many properties can be set to the entity from here on out. To make it easier, you should select the entity so you don't have to type in the ID of the entity every time. Use "/entities select <id>" for this, where <id> is the ID number the plugin printed out when you created it. Now you don't have to type in the ID number for entity commands! You can always type in a specific ID even if you don't have it selected to modify it. After that, you can set properties of the entity. Refer to the commands below for all the properties or pages 5 through 8 of the in-game help menu ("/customspawners help") for usage.

Now the fun part: spawner creation. To create a spawner, look at the block you want to be a spawner. It doesn't matter which type, it can be grass, obsidian, wool, even another spawner! Next, type in "/spawners create <ID number of entity you've created>". This creates a default spawner. You can select a spawner by using "/spawners select <id>" where ID is the id of the spawner you created. Properties can also be applied to spawners. Refer to the commands below or pages 1 through 4 of the in-game help menu for usage.

Lastly, set the spawner you created to be active using "/spawners setactive <id of spawner>". You should now have a working spawner!

Some other useful commands:

  • "/customspawners" - displays the plugin info, and provides links to the main page for CustomSpawners and thebiologist13's BukkitDev profile.
  • "/spawners listall" - list all the existing spawners and locations.
  • "/entities listall" - list all the existing entities and their names if they have one.
  • "/spawners setname [id]" - gives a spawner a name so it is easier to find.
  • "/entities setname [id]" - gives an entity a name so you can identify it easier.
