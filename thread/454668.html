咳咳，这次我来发个抢先的更新翻译帖好啦鬼畜的预览图



3.10.8.0更新内容~
公告-Nelson Sexton

哈喽【标准开头XD】

如果你对正在测试的Unturned感兴趣，你可以打开你的Steam游戏库右键点击Unturned，选择属性，找到“测试”栏，输入代码“OPERATIONMAPLELEAF”体验测试版的Unturned哟~

狩猎：
你现在可以在爱德华王子岛上看见许多小动物正在天真的散步哟~但是小动物们很害怕陌生人（翻译卖萌：尤其是怪叔叔）
所以最好带上望远镜用它来从远处观看动物们哟~（翻译卖萌：偷窥狂）

更新内容：
添加：
  • 狩猎系统
  • 满月时的警告+单人游戏中改进了满月时僵尸生成的机制
  • 主菜单里面有了全球的统计数据哟
  • 创意工坊的地图编辑器里面加入了动物生成器
  • ID号为1的小鹿
  • ID号为514的生鹿肉
  • ID号为515的煮熟的鹿肉
  • ID号为516的动物皮
  • ID号为517的皮质上衣
  • ID号为518的皮质裤子


调整：
  • 可爱的民用步枪和木弓的攻击力被削弱了（翻译卖萌：你们太强了，咱们削弱刀妹吧）
  • 让音效的音调更加准确，防止其产生变化，给效果加上了静态的标记（然而我并没有看懂作者想表达什么）


修复：
  • 修复了爆炸物伤害会减弱的问题
  • 修复了调整阳光效果时会先调整灰度分析的问题
  • 修复了服务器中死亡僵尸的对撞体不会消失的问题
  • 修复了服务器读取角色服装的问题
  • 修复了实验室无线电台的树木的问题
  • 修复了货仓的车库门会消失的问题
  • 修复了松木桩
  • 修复了僵尸刷新的偏移量
  • 修复了需要火源才能修理物品的问题
  • 微调了僵尸的性能表现
  • 修复了物品/车辆会跑进自然物品资源点的问题


作者的话：
  • 这次更新拖延的时间太久了，深感抱歉。不过下一次的更新我可能会加入更多类型的动物并且作出一些其他方面的AI改进。


注意：
  • 任何自定义武器对动物的伤害值都需要被更新（大概就是自制武器不可以杀动物？）


感谢阅读！


原文如下

Hello!
If you're interested in testing out this upcoming update head on over to the Preview branch! You can gain access by right clicking on Unturned in your Steam library, selecting properties, navigating to the Betas tab and entering the secret passcode "OPERATIONMAPLELEAF".
Hunting:    You'll now start to see some wildlife roaming the fields of Prince Edward Island! They're easily spooked, so bring some binoculars to observe from a distance.
Update Notes:
Additions:
Added hunting.
Added full moon alerts and zombie respawning in singleplayer when full moon.
Added global stats to the main menu.
Added animal spawns to the level editor.
Added deer. [ID 1]
Added raw vension. [ID 514]
Added cooked venison. [ID 515]
Added leather. [ID 516]
Added leather top. [ID 517]
Added leather bottom. [ID 518]
Tweaks:
Tweaked civilian rifle and crafted bow damage a bit lower.
Tweaked effects to have "Static" flag which prevents audio pitch change.
Fixes:
Fixed explosion damage dropoff.
Fixed grayscale applying before sun shafts.
Fixed server not turning off zombie collider on death.
Fixed server loading clothing.
Fixed tree in radio tower.
Fixed missing gate on warehouse.
Fixed pine post.
Fixed zombie spawn offset.
Fixed needing fire to repair items.
Fixed minor zombie performance issue.
Fixed item/vehicle enter exploit.
Sorry about the massive delay between the last update and this!  Most likely the next update will add a few more animals and AI improvements.
Note: Any custom weapons will need to be updated with animal damage values.   Thanks for reading!
