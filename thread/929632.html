SlimefunRecipeEditor
你是否为部分粘液科技物品合成不够肝或过于肝而烦恼？
你是否向往能够将自定义粘液科技物品的合成表自定义化？

功能
  • 你能够通过修改配置文件来修改一个或多个粘液科技物品的合成
  • 支持加载多个配置文件中的合成
  • [敬请期待...]

配置方法
config.yml

  2. debug: false
  3. # [boolean] 是否开启调试模式 (可能会刷屏控制台)

  5. enable: false
  6. # [boolean] 开启此项后此插件才会工作

  8. recipes:
  9. # [string] 合成表配置文件名
  10. - 'recipes.yml'
复制代码
recipes这一项填需要加载的配置文件的文件名
这个设计主要是为了方便管理

recipes.yml (默认配置文件，内含示例)
  1. #
  2. # example:
  3. # 标题随意, 用于辨别, 不要重复
  4. # - 'STEEL_INGOT'
  5. # 第一行为要修改的粘液科技物品的ID
  6. # - 'MC{IRON_INGOT}|MC{IRON_INGOT}|MC{IRON_INGOT}'
  7. # - 'null|null|null'
  8. # - 'null|null|null'
  9. # 第二、三、四行写新合成表
  10. # - 'RT{OVEN}'
  11. # 第五行写新的合成方式
  12. #
  13. # 物品表达式:
  14. #   'MC{<ITEM_ID>}' 表示一个原版物品, 必须是一个被包含在enum中的ID
  15. #   'SF{<ITEM_ID>}' 表示一个粘液科技物品, 其中 'ITEM_ID' 是一个物品ID
  16. #
  17. # 可用的合成方式有:
  18. #   MULTIBLOCK (多方块需要外接其他插件)
  19. #   ARMOR_FORGE 盔甲锻造台
  20. #   GRIND_STONE 磨石
  21. #   MOB_DROP (生物掉落需要外接其他插件)
  22. # SMELTERY 冶炼厂
  23. #   ORE_CRUSHER 碎矿机
  24. #   COMPRESSOR 压缩机
  25. #   PRESSURE_CHAMBER 压力室
  26. #   HEATED_PRESSURE_CHAMBER 热压力室
  27. #   OVEN 烤箱 (这个似乎没有实际作用，但是出现在作者的源码里= =)
  28. #   MAGIC_WORKBENCH 魔法工作台
  29. #   ORE_WASHER 洗矿机
  30. #   ENHANCED_CRAFTING_TABLE 强化工作台
  31. #   JUICER 榨汁机
  32. #   ANCIENT_ALTAR 远古祭坛(使用祭坛时第五个物品不能为空！否则无法合成！)
  33. #   SHAPED_RECIPE 原版有序合成
  34. #   SHAPELESS_RECIPE 原版无序合成
  35. #   FURNACE 熔炉烧制
  36. #   NULL 无
  37. #

  39. example:
  40.   - 'POWER_CRYSTAL'
  41.   - 'MC{DIAMOND}|MC{REDSTONE}|MC{DIAMOND}'
  42.   - 'MC{REDSTONE}|MC{DIAMOND}|MC{REDSTONE}'
  43.   - 'MC{DIAMOND}|MC{REDSTONE}|MC{DIAMOND}'
  44.   - 'RT{ENHANCED_CRAFTING_TABLE}'
复制代码
其中，"  MULTIBLOCK"(多方块)和"MOB_DROP"(生物掉落)直接编辑无法生效
需要配合其他插件
例如"MOB_DROP"可以配合MythicMob插件实现

注意事项
每次写完配置文件需要重启服务器才能生效
