* TabooSK *
禁忌系列 (六)，脚本扩展
我没想到我竟是 MCBBS 第一位发布脚本扩展的菜鸡开发者

本插件为 Skript 扩展插件，不可独立使用

功能 & 介绍
具体有啥功能看下面介绍吧

  • 获取 PlaceholderAPI 变量
  • 获取系统时间（Millils）
  • 获取 Skript 时间的 年，月，日，时，分，秒，毫秒
  • 将 系统时间 -> 转换为 Skript 时间
  • 将 Skript 时间 -> 转换为系统时间
  • 将 Skript 时间 -> 格式化为任意形式（yyyy-MM-dd HH-mm-ss）
  • 获取玩家的物品点击类型（InventoryClickEvent）


用法 & 代码

[taboosk ]system (date|time|millils)
[taboosk ]system[ date] format %date%
[taboosk ]skript[ date] format %number%
[taboosk ]string[ date] format %date% with %string%
[taboosk ]time[ number] %string% in %date%
[taboosk ]placeholder[ format] %string% with %player%
[taboosk ]click[ type] with %player%


教学 & 帮助
相信很多已经会使用 Yaml 存储数据的服主
应该体会过无法将日期数据存到文件里的痛苦

这个插件会帮助你们干掉这些困扰
只要给我一个评分，我就带你们升天

——————————————————————————————————————
在此之前，首先你需要学会读懂脚本格式，例如

[taboosk ]placeholder[ format] %string% with %player%

[] 符号中的内容 可写入
意思是可写可不写，用于避免与其他扩展的语法冲突

() 符号中的内容为 必须写入
一般不单独出现，常和 | 符号共同使用

| 符号左右的内容为 选择写入
例如 (date|time)，你可以选择 date、time 中的任意一个

%% 符号中的内容为变量类型
这里只举简单的例子，Skript 基本知识

%string% 文本变量
%number% 数字变量
%player% 玩家变量

——————————————————————————————————————

[taboosk ]system (date|time|millils)
返回值：数字

获取当前系统的时间（单位：毫秒）
这个语法获取到的时间为纯数字格式，便于储存
具体作用自己理解

获取时间差只需 相减 即可得出毫秒差

set {_time} to system date


——————————————————————————————————————

[taboosk ]system[ date] format %date%
返回值：数字

将 skript 时间变量，转换为系统时间（单位：毫秒）
具体作用自己理解

set {_millils} to system format now

set {_millils} to system format {_date}


——————————————————————————————————————

[taboosk ]skript[ date] format %number%
返回值：日期

将系统毫秒转换为 Skript 时间变量
具体作用自己理解

set {_date} to skript format {_number}

set {_date} to skript format 1496841736356


——————————————————————————————————————

[taboosk ]string[ date] format %date% with %string%
返回值：文本

将 Skript 时间变量转换为一段任意格式的文本
第二个变量为时间格式具体帮助访问网站
具体作用自己理解

set {_s} to string format now with "yyyy年MM月dd日"

set {_s} to string format {_d} with "HH时mm分ss秒"


——————————————————————————————————————

[taboosk ]time[ number] %string% in %date%
返回值：数字

获取 Skript 时间变量中的时间单位
聪明点的服主其实可以用上面的语法完成这个功能
但是为了考虑到部分服主

set {_时} to time "HH" in now

set {_年} to time "yyyy" in now


yyyy年 MM月 dd日 HH时 mm分 ss秒 SSS毫秒
注意大小写

——————————————————————————————————————

[taboosk ]placeholder[ format] %string% with %player%
返回值：文本

获取 PlaceholderAPI 的变量
功能介绍就这一句话

set  {_n} to placeholder "taboocode_power" with player


变量不需要加引号
变量不需要加引号
变量不需要加引号

本帖原 PapiFormat，因代码**导致很多问题
这次重写优化了这个语法

返回值从 数组变量 改为 单变量

——————————————————————————————————————

[taboosk ]click[ type] with %player%
返回值：文本

获取玩家的背包点击方式
任何背包点击事件，且不限于
on inventory click
on mor.inventory click

click type with player
