BWKits

简介：

此插件专门为起床战争服务器设置的职业系统，可以让你在起床战争（BedWars）中选择职业，内容操作简单，明了，可以修改配置文件！





作者的话：

这是我的第一个插件！感谢你使用这个插件，大家可以在帖子下方做评论
P.S. My first plugin. So, will be really grateful if you will rate plugin and leave a review.



此插件完全可配置!

你可以修改配置文件，还可以将它翻译成不同的语言！但只有一件事情不能修改——职业

插件版本从1.7便可以开始使用 ！（Wow 好6）















指令 Command 权限

/bws - 打开职业商店用于购买职业

/bwk - 打开职业选择GUI界面，用于选择已经购买的 职业

/bwc - 清除自己所有的职业

/bwr -  重新加载这个插件


bw.kit.<职业> -  拥有选择职业的权限

bw.buykit.<职业> - 拥有购买XXX职业的权限

bw.buykit.d_<职业> - 拥有购买职业的权限




如何使用？

1.下载插件

2.放进Plugins文件夹

3.重启服务器

4.配置文件生成

5.打开服务器一起嗨！
