打开rpgitem的config配置文件，最下面，把residence：那里改成true就行啦，如下

# 是否启用对以下插件的支持
support:
  worldguard: false
  residence: true  
  plotme: false
  pvparena: false
  mobarena: false
  towny: false
  minigames: false
  ultimatearena: false
