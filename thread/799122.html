功能&玩法
本插件主要的玩法就是
开局后随机选择一个玩家，手持土豆
手持土豆的玩家需要快速的将土豆传给另外的玩家
当土豆在手里的时间超过30秒后，就会爆炸结束游戏
在游戏中可以拾取 加时/冻结/眩晕/高跳/无敌/传送等道具buff
当游戏到达白热化阶段的时候，将会传送所有场上所有玩家到一个区域进行死亡竞技

插件指令&游戏创建
需要权限：potatoes.admin
/pyr rl potatoes 重载插件
/potatoes setmainlobby 设置主大厅
/potatoes arena 列出领域
/potatoes arena 名字 create 创建游戏
/potatoes arena 名字 delete 删除游戏
/potatoes arena 名字 setmin 数量 设置最小玩家人数
/potatoes arena 名字 setmax 数量 设置最大玩家人数
/potatoes arena 名字 setlobby 设置等待大厅
/potatoes arena 名字 setdeathmatch 设置死亡竞技位置
/potatoes arena 名字 spawn 列出复活点
/potatoes arena 名字 spawn ID set 设置玩家复活点（复活点可以多个ID表示复活点必须为数字名字如：/potatoes arena 名字 spawn 1 set  设置名字竞技场 玩家复活点 1 你还可以设置/potatoes arena 名字 spawn 2 set：/potatoes arena 名字 spawn 3 set ）
/potatoes arena 名字 bonus 补给箱列表
/potatoes arena 名字 bonus ID set 设置补给箱位置（ID如上解释）
/potatoes arena 名字 bonus ID del 删除补给箱位置

创建游戏方法（顺序）：
1.首先在一个区域设置主大厅 /potatoes setmainlobby
2.然后创建一个游戏（游戏名字可以中文） /potatoes arena 名字 create 创建游戏
3.设置这个游戏的最小人数 /potatoes arena 名字 setmin 数量
4.设置这个游戏的最大人数 /potatoes arena 名字 setmax 数量
5.然后在游戏地图里合适的地方设置等待大厅 potatoes arena 名字 setlobby
6.接着在地图里合适的区域设置死亡竞技场（越小越好）/potatoes arena 名字 setdeathmatch
7.然后在地图的中心位置设置玩家的复活点 至少两个
/potatoes arena 名字 spawn ID set （ID必须为数字）
8.最后在地图中 设置补给箱的位置 /potatoes arena 名字 bonus ID set

游戏牌子的创建
推荐把牌子就放在主大厅的墙上
1.放置一个木牌
2.在第一行写上 [Potatoes]  注意P必须大写
3.在第二行写上你刚刚创建的游戏的名字
完成
