这是我的配置文件

解读一下

我开启了MYSQL这个不用管

看最下面的vip_groups

这里一定要写上vip1

然后default_gourp是你vip到时间之后，自动移动到哪个组

我服务器玩家都在Builder组

根据服务器设置，有的服务器可能是default组


这里设置好之后 重启服务器或/vipzero reload


然后我们移至权限组插件

这里我用的是 GroupManager
你可以直接复制我这里写的VIP1
以及Builder组
Builder:
    default: true
    permissions:
    - EasyKits.bypass.limit
    - EasyKits.bypass.price
    - EasyKits.kits.cooldown
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      build: true
      prefix: '&a[玩家]'
      suffix: ''
  vip1:
    default: false
    permissions:
    - EasyKits.kits.vip1
    inheritance:
    - builder
    - g:essentials_builder
    - g:towny_builder
    info:
      build: true
      prefix: '&f白银VIP'
      suffix: ''

这里是已经设置了vip1有权限使用
/kit vip1 这个指令领取这个礼包
Builder组给了加冷却，限制等权限
请一定要给默认组加那三个权限
不然会导致礼包无限领取
这里用的礼包插件是EasyKit

如果觉着对你有用，请设置最佳~
