作者: 晴路卡    时间: 2020-7-13 10:01
你应该要填的是power
  1. /summon minecraft:fireball ~ ~ ~ {power:[0.0d,0.0d,1.0d]}
复制代码

用雪球丢出火球：
  1. execute as @e[type=minecraft:snowball] at @s run summon minecraft:fireball ~ ~ ~ {power:[0.0d,0.0d,0.0d],Tags:["init"]}
  2. execute as @e[type=minecraft:snowball] at @s run data modify entity @e[tag=init,limit=1,sort=nearest] power set from entity @s Motion
  3. tag @e[tag=init] remove init
  4. kill @e[type=minecraft:snowball]
