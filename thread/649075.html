作者: Alendill    时间: 2016-11-18 10:03
ESS插件支持你所说的功能
在ess的config里找到如下信息，并修改
  # 当以下方块被放置或破坏,或物品被使用时会出现警告
  # 你加载了一次Essentials后,就可以在plugins/EssentialsX/items.csv中找到物品ID列表.
  # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  alert:
    on-placement: 46
    on-use:
    on-break:

  blacklist:

    # 阻止玩家放置以下方块
    placement: 46

    # 阻止玩家使用以下物品
    usage:

    # 阻止玩家破坏以下方块
    break:

    # 阻止活塞推动以下方块
    piston:

    # 阻止发射器发射以下物品
    dispenser:
