一
scriptblock插件，绑定一个指令到方块上。
/sbinteract create [$cost:金币数量][@bypass /ca add <player> 点券数量]
这样玩家右键绑定了命令的方块扣除金币获得点券。
二
chestcommand插件 配置花费制定金币 执行op: ca add <player> 点券数量
作者: a2605393469    时间: 2016-1-1 06:37
使用rpgitem插件
http://www.mcbbs.net/thread-203851-1-1.html

输入如下指令
/rpgitem 物品代码 power command 0 right 右键使用 `xxx add {player} 100` *
右键后就能获得100点卷
/rpgitem 物品代码 power consume
添加这条指令，使用后就会消失掉
-当你完成了以上步骤，你就可以把做出来的道具丢快捷商店出售啦
PS: 由于不知道你使用的什么点卷插件 所以我就用xxx代表,0是冷却时间，100是点卷数量， {player}是玩家变量
