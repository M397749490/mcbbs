Bei Fen
简介:

Bei Fen可以定时备份与多个时间开启备份，让熊孩子无法进行大规模的毁存档行为!你是否烦恼熊孩子的熊存档行为。对此是否没有办法解决熊孩子留下的烂摊子。Bei Fen可以在短暂时间内快速备份，而且可以自定义多个时间段开启备份服务器，使卡区块不存在（支持数据库储存）。
特点:
①,简单配置，且实用的一款备份插件
②,可自定义备份指定文件与不备份指定文件
③,支持数据库与FTP数据库的传输

指令:
<> = 必要指令
/beifen - 指令大全
/beifen <create> - 创建新的备份文件
/beifen <cancel> - 取消正在进行的备份文件
/beifen <ftp> - 上传最新的备份文件
/beifen <clean> - 删除旧的备份日志
/beifen <info> - 查看备份文件的信息
/beifen <disk> - 查看磁盘的储存情况
/beifen <reload> - 重新加载文件

配置config:
#备份时间设置
#星期 时间(这里的时间是24小时制的)
#时间 AM/PM(这里的时间是12小时制的)
#下面有例子
#Mon Tue Wed Fri Thu Sat Sun 10:00   说明固定在星期一-星期天的早上10点钟开始备份
#10:00 AM 说明固定在早上10点钟开启备份
#10:00 PM 说明固定在晚上10点钟开启备份
backupSchedule:
- Mon Tue Wed Fri Thu Sat Sun 10:00
- 10:00 AM
- 10:00 PM
#备份最多文件，如果备份的文件超过设置的数量，就会删除最早已备份的文件
maxBackupsBeforeErase: 4
#压缩等级，数字越大，压缩包容量越小，且时间越长
compressionLevel_1-10: 5
#是否随着服务器的tps来决定备份的速度
slowdownWhenServerLags: true
#是否显示备份进程
showSlowdownMessage: true
#是否开启安全模式，服务器滞后后，备份停止
safeties: true
#是否开启开发者模式，不要开启！！！
debug: false
#压缩包文件名称
name: BeiFen_%time%
#压缩包格式支持zip等等
extension: rar
#不加入下列文件到备份文件中。
exemptFolders:
- logs
- resource_packs
- nukkit.jar
#压缩包放入到服务端哪个文件夹
saveFolder: plugins/BeiFen/备份
#设置主文件夹，可不用设置
masterFolder: .
#是否可以在游戏中开启备份
allowInGameCommands: false
#备份开启时，是否通知管理员
notifyAdmins: true
#压缩包密码"%c1%*FC*kpz,DYWw&&!n15TtA=="说明为不设置
backupPassword: '%c1%*FC*kpz,DYWw&&!n15TtA=='
#时间格式，不用理会
timeFormat: 1
#下列为传输数据库，不做翻译，都是填写用户名和开启的
ftp:
#是否开启ftp数据库
  enable: false
  hostname: ftp.example.com
  port: 21
  protocol: sftp
  username: user
  password: '%c1%*FC*=X[r[\K3:<U4udw/]6~=='
  sshKey: ''
  saveLocation: .
  deleteAfterSuccess: false
  maxBackupsBeforeErase: 4
sql:
#是否开启sql数据库
  enable: false
  db1:
    host: localhost
    port: 3306
    username: root
    password: '%c1%*FC*''Ax](ud]h\''''YkU_622[(Dzt=='
    database: database
    exemptTables:
    - table
#是否清理旧的备份文件
cleaner:
  cleanBeforeBackup: true
#清理超过4天的logs文件
  logs:
    enable: true
    daysOld: 4
#在worlds以下的世界中，清理超过365天的玩家数据
  playerdata:
    enable: false
    daysOld: 365
    worlds:
    - world
    - world_nether
    - world_end
#清理超过90天的stats文件
  stats:
    enable: false
    daysOld: 90
    worlds:
    - world
    - world_nether
    - world_end
#接收更新的邮箱
email:
#是否开启
  enable: false
#邮箱地址
  email: 123456789@163.com
  name: 您的名字
  server: 服务器名字
  diskSpace: true
  failures: true
  onbackupcreate: false

设置问题解析:

: 如何设置压缩包密码呢？

: config中backupPassword: '%c1%*FC*kpz,DYWw&&!n15TtA=='

修改为backupPassword: '所要的密码'



: 如何设置备份时间呢？
: 列子:
第一种情况(指定星期时间备份):
backupSchedule:
- Mon Wed Fri Sun 10:00
解释:分别在星期一,星期三,星期五,星期日,星期日中的早上十点开启备份
具体设置星期时间按照星期英文的前三个字母
第二种情况(每一天备份):
backupSchedule:
- 10:00 AM
解释:AM:只要在早上十点的时候就进行备份
backupSchedule:
- 10:00 PM
解释:PM:只要在晚上十点的时候就进行备份
ps：数据库储存的配置就不需要进行解读了
