Mojang API
注意:
[size=10.5000pt]1. 当前全部公开API的处理速度都是受到限制的(当前是10分钟600个, 但是有可能会修改).
[size=10.5000pt]2. API中的某些部分不一定是否包含测试账户.
API Status (服务器状态)
使用这个API可以查看Mojang服务器的状态. 你可以根据它的返回值来判断服务器是否还活着:
1. Green: 完全没有问题
2. Yellow: 存在一些问题(在这个状态下就不建议使用了)
3. Red: 服务器已经废了
请求: GET https://status.mojang.com/check
返回: 我实在不知道怎么用wps编辑json, 自己用浏览器访问上面那个网址就有了.
UUID > 查询玩家的UUID
这个api有什么用我真没弄明白, 总之就是根据玩家名字查询他的UUID.
请求: GET https://api.mojang.com/users/profiles/minecraft/<username>?at=<timestamp>
我建议这么用: GET https://api.mojang.com/users/profiles/minecraft/<username>
返回: {“id”: ”这里就是uuid”,”name”: ”名字”}
UUID > 查询玩家的历史昵称
这个api能查找这个玩家使用的历史昵称. 话不多说看请求吧
请求: GET https://api.mojang.com/user/profiles/<uuid>/names
返回: [{"name":"用过的昵称"},{"name":"现在的昵称","changedToAt":现在这个昵称改的时间
Playernames > UUIDs

UUID > Profile + Skin/Cape
这个是重头戏, 讲的是怎么获取玩家的皮肤和披风.
请求: https://sessionserver.mojang.com/session/minecraft/profile/<uuid>
这个请求返回什么呢? 它返回一个玩家的属性列表. 您可别小看这几个字, 这个玩家的uuid啊, 昵称啊, 乃至皮肤披风, 全都在这儿.
