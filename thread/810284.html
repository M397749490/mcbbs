作者: moshan    时间: 2018-7-30 15:06
[color=rgba(0, 0, 0, 0.7)]1. 点击桌面左下角的"win"图标
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]2. 选择"设置"
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]3. 选择"更新和安全"
[color=rgba(0, 0, 0, 0.7)]
[color=rgba(0, 0, 0, 0.7)]4. 选择左侧的"恢复"选项
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]5. 在右侧就可以看到"回退到win10上一个版本"的选项，选择开始
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]6. 选择需要回退的原因后点击"下一步"
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]7. 在提示更新补丁修复计算机现在有问题上的情况下点击"不，谢谢"
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]8. 在确认可能的风险并接受的情况下点击 "下一步"
[color=rgba(0, 0, 0, 0.7)]
[color=rgba(0, 0, 0, 0.7)]9. 确认密码未遗忘的情况下直接点击"下一步"
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]10. 之后直接点击"回退到早期版本"
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]11. 选择后电脑直接重启进入回退系统等待界面
[color=rgba(0, 0, 0, 0.7)]

[color=rgba(0, 0, 0, 0.7)]12.无需进行其他操作，耐心等待系统回退完成就能直接进入原系统。
