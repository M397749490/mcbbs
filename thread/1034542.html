插件特点
* 这是一款单人单词听写插件
1.(仅)支持MySQL数据库
2.播放单词语音（跟着读效果更佳）
3.自定义单词频率
4.自定义单词(从百词斩导入)
5.随机物品、药水效果奖励/惩罚

效果展示

【视频展示】

指令说明
主指令：WordChallenge(简写wc)
输入wc查看指令帮助
/wc depack  解包zpks文件导入单词到数据库
(详见下面[食用方法])
/wc start  开始单词训练
/wc pause  暂停单词训练

食用方法
一、手动创建数据库WordChallenge
sql语句如下：
  1. CREATE DATABASE WordChallenge;
复制代码
二、启动一次插件并修改配置文件中的数据库信息（见下文【配置文件】）
三、导入单词
1.想要自定义单词的看这里

【图片教程】
1.选择单词词书并点击【↓单词数据】
2.用一款有压缩功能的文件管理器(如ES)打开目录：
Android/data/com.jiongji.andriod.card/files/baicizhan/zpack
里面有唯一一个以数字为名字的文件夹，压缩发到电脑
3.解压放到plugins/wordchallenge/zpks
4.启动服务器，输入指令wc depack，等待完成
【视频演示】
链接:https://pan.baidu.com/s/1pbJtIjczMVwBAYsXUIRFaw提取码:19e5

2.不想这么麻烦的看这里
网盘链接:https://pan.baidu.com/s/1M-vZ1EIzk_z3iKTMYpXvIw提取码:9iqn
1.找到网盘里的WordChallenge压缩包，解压得到WordChallenge文件夹
2.拷贝到plugins文件夹中-自带四级高频词汇，共738词(资源来自百词斩)

配置文件
  1. #数据库Ip地址
  2. Ip:127.0.0.1
  3. #数据库端口
  4. Port:3306
  5. #数据库用户名
  6. UserName:'root'
  7. #数据库密码
  8. Password:'123'
  9. #两个单词间隔时间
  10. Time:10
复制代码
