  1. # The default layouts are in the Message.yml file!

  3. # Message-Layouts can not only be used for bans but also for mutes and warns
  4. # Currently available variables:
  5. #   %OPERATOR% - The user who dealt the punishment.
  6. #   %REASON% - Reason for punishment.
  7. #   %PREFIX% - Prefix set in Message.yml.
  8. #   %DURATION% - Amount of time left before a punishment expires (will be -1 for permanent punishments).
  9. #   %DATE% - Date punishment was issued on.
  10. #   %ID% - Displays the punishment ID (i.e. first punishment = 0, second punishment = 1, third punishment = 2, etc.)
  11. #   %HEXID% - Displays the punishment ID in base 16.
  12. # For warns you have also the variable %COUNT% which will be
  13. # replaced with the current amount of warns the player already received
