大家好，我是Endman233，今天带来的是4个神奇的RPG道具：雷神斧[打谁谁遭天谴]看过Sao_N的OOC雷神斧，虽然我不认识用版主的OOC破解器看出来了- -好吧也表示抱歉。。。还是打脸这招有效……
传送剑[打谁谁就传送到那个生物身边]、磁铁模式[拿起燧石激活磁铁模式，周围10格的物品会被吸过来，拿起线解除磁铁模式]、末影人模拟雪球[扔出雪球的玩家将会随机传送]效果：








2333就是这么一个效果，下面是教程时间：
1.雷神斧
首先要创造一个判断玩家使用钻石斧叫raytheon的计分板，钻石斧也就是所谓的雷神斧啦

/scoreboard objectives add raytheon stat.useItem.minecraft.diamond_axe





[magenta_wool]:

  1. /scoreboard players set @a[score_raytheon_min=1] raytheon 0
复制代码
[lightblue_wool]:

  1. /execute @a[score_raytheon_min=1] ~ ~ ~ /execute @e[r=8,type=!Player] ~ ~ ~ summon LightningBolt ~ ~ ~
复制代码
对了，我还忘了，带上这个指令高频喂养口味更佳：
  1. /execute @e[type=LightningBolt] ~ ~ ~ /scoreboard players set @a[score_raytheon_min=1] raytheon 0
复制代码
意思呢，就是说，当玩家用雷神斧攻击生物时，可以肯定的是：生物在他附近，因此在攻击生物的玩家附近寻找不是人类的目标，然后一道雷劈下来。。。然后清零分数
2.传送剑
首先创造一个判断玩家使用金剑叫tp的计分板
  1. /scoreboard objectives add tp stat.useItem.minecraft.golden_sword
复制代码


[lime_wool]：

  1. /execute @a[score_tp_min=1] ~ ~ ~ tp @a[score_tp_min=1]<span id="kM0.3088911254890263">@e[r=8]</span>
复制代码
[yellow_wool]:

  1. /scoreboard players set @a[score_tp_min=1] tp 0
复制代码
意思呢，就是说当有人拿金剑去打生物或人的时候，那个使用了金剑的玩家tp到被打的生物然后清零分数

3.磁铁
首先要创造一个叫magnet的计分板
  1. /scoreboard objectives add magnet dummy
复制代码


你没看错，就三条指令高频就可以了
[orange_wool]:

  1. /scoreboard players set @a magnet 1 {SelectedItem:{id:minecraft:flint}}
复制代码
[grey_wool]:

  1. /scoreboard players set @a magnet 0 {SelectedItem:{id:minecraft:string}}
复制代码

[pink_wool]:
  1. /execute @a[score_magnet_min=1] ~ ~ ~ tp @e[type=Item,r=10] @a[score_magnet_min=1]
复制代码
最后，是末影人模拟雪球咯
首先创造一个探测玩家丢雪球叫snowball的计分板
意思就是说，你拿起了燧石，就为你的磁石分数设置为1，拿起线就把你的磁石分数设置为0，周围10格的物品实体tp到分数为1的玩家
  1. /scoreboard objectives add snowball stat.useItem.minecraft.snowball
复制代码



[lightgrey_wool]:
  1. /scoreboard players set @a[score_snowball_min=1] snowball 0
复制代码
[cyan_wool]:
  1. /execute @a[score_snowball_min=1] ~ ~ ~ /spreadplayers ~ ~ 5 25 false @a[score_snowball_min=1]
复制代码
原理同1、2，使用雪球的人就会随机瞬移

第一，没问过作者(saon)就"破解"了他的作品并拿来当教程是不对的
第二，雷神斧的第三条指令，也就是/execute @e[type=LightningBolt] ~ ~ ~ /scoreboard players set @a[score_raytheon_min=1] raytheon 0
我根本没看到任何作用，这个execute根本不可能有效，因为LightningBolt根本就不会出现为实体，还说破解了saon的作品，呵呵，连基本原理都不懂你说什么破解了
第三，你那个传送剑单人能用，然而到了多人就会bug，不信可以试试，根本就不是用@a的，那样子会全部使用了剑的玩家都tp过去某一个实体那里。而且最重要的是你未必能tp到，只要那个玩家r=8的范围内有多于一只怪物就会bug，而且也不一定是攻击了的怪物
第四，和第三类似，当magnet=1的玩家多于一个的时候你根本就无法tp，因为要tp到多个玩家
第五，我在你的指令那里看到一大堆execute，然而根本就没必要使用execute，用了execute反而会额外执行几次

结论就是:
你弄多人的系统能不能先在多人的环境里测试一下？而且能不能学好一点再发布作品？
最重要的是，拆开别人的系统那不叫破解，那叫学习而已，而且学习能不能学好一点？这样子改得不伦不类的
