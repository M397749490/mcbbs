原帖介绍：
This plugin is very easy to use. It's best for all types of server! This plugin is great for fast events. You can one command give items to all players on the server! We want add in future new commands. You must download Essentials plugin to use this plugin.

个人编辑介绍：
这是一款非常简便的插件，你能用它来给予在线玩家指定物品与数量，RPG服与礼包必备！
这件插件一定会帮到你！而且这款插件非常小！大小：1.7KB

特色：
命令,
安装后可以使用,
没有权限(只OP可以使用命令),
没有配置,
容易使用,

前置插件：
Essentials

指令：
/giveall 物品id 数量
权限：
无
BUG：
V1不工作（我也不懂这是什么）
