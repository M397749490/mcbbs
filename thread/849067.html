插件配置

tabmanager:
注：表格排版有点炸了，请勿直接复制！若需要可以下载下方的备份
  1. TabManager {
  2.     #这将把服务器上的玩家添加到记分板中的团队，这将覆盖tab菜单，如Pixelmon GUI，允许在此范围内自定义前缀/后缀。但是，在游戏中聊天时，这也会给玩家一个前缀和/或后缀，因此，如果你想让聊天看起来与这里的选项不同，还必须使用一个类似nucleus的插件来处理聊天。
  3.     #意思就是会让计分板中的团队覆盖tab菜单（慎用）
  4.         "Add Players to Teams"=false
  5.     #这将编辑TAB列表（不会影响Pixelmon定制的TAB列表，最好在Pixelmon.hocon中启用Pixelmon后禁用此选项。
  6.         #注：并不会影响，可以启用
  7.         "Edit Vanilla Tab List"=true
  8.     #这将尝试使用玩家的nick名称，而不是他们的实际的名称
  9.     "Use Player Nicknames"=false
  10.     #玩家组重新检查更新的间隔（以秒为单位）
  11.         #[这是关系到插件性能，因此不要将其设置得太低。默认值为60，建议值不小于60]。
  12.         #设置为-1以禁用更新。
  13.     group-update-interval=60
  14.     #以秒为单位更新TAB菜单文本的间隔。只有在使用PlaceholderAPI时才需要此选项。
  15.         #设置为-1以禁用更新。
  16.     update-interval=5
  17. }

首先找到usercache（在根目录里），里面会有进服过玩家的UUID

然后在插件配置里找到players这个文件名的文件

  1. {
  2.   "playerList": {
  3.     "shixueSAMA": {                                                         #名字
  4.       "uuid": "6c64cd3a-748a-3019-98fa-c25bf03518c8",      #（此为UUID，上文提到过在哪里可以找到）
  5.       "prefix": "[&e测试&r]",                                              #前缀
  6.       "suffix": ""                                                               #后缀
  7.     }
  8.   }
  9. }
