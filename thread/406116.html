标题: /scoreboard应用
我们可以用scoreboard objectives add 来创建一个每杀死一个生物则加一分的计分板
但是如何做到，每加一分则奖励一个物品呢？

作者: 小白勇者    时间: 2015-2-10 13:20
您好,您可以先输入命令/scoreboard objectives add 英文名 totalKillCount与命令/scoreboard players set @a 英文名 0,这两条命令将添加一个计算杀死生物数的变量并设置所有玩家该分数为零。接下去使用高频红石信号不断激活输入了命令give @a[score_英文名_min=1] 物品名 1,的命令方块,使用红石比较器连接于该命令方块上,并指向一个输入了命令scoreboard players set @a 英文名 0的命令方块即可在有玩家杀死生物时奖励一个物品,物品名可以在游戏中按下F3+H并在背包中将光标移至相应物品上查看,上文提及的英文名必须为同一串英文字母串。若您对此系统有任何不满请向我发送消息告知,我会为您修改直到您满意为止。
