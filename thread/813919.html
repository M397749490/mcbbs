##7.制作模板教程
下载模板的模板（好像有点问题）
点我下载（可能有短链）
打开main.json，在json->loop中加入项目！
#如type字段填写text
         font:填写目录中的字体文件
         text:填写添加的文字(可用 我的世界颜色代码 和 text变量 )
         nobuild:可选，如值为true(文本)则不会转换变量
         x:文字左上角的x坐标
         y:文字左上角的y坐标
         size:文字的大小
         angle:文字的旋转角度

#如type字段填写img
         text:填写添加的文字(可用 我的世界颜色代码 和 text变量 )
         x:图片左上角的x坐标
         y:图片左上角的y坐标
         tx:图片转换到的宽度
         ty:图片转换到的高度

#如type字段填写motd (如非需要超过两行的motd建议不使用此类型，可使用%motd1%,%motd2%变量)
         font:填写目录中的字体文件
         nobuild:可选，如值为true(文本)则不会转换变量
         x:motd左上角的x坐标
         y:motd左上角的y坐标
         size:文字的大小
         angle:文字的旋转角度
         liney:一行的宽度（自动换行使用）

#text所有可用变量
详见 ##text代码

#img text所有可用类型
delay : 延迟，延迟如小于100则加载g.png，小于200则m.pmg，否则b.png，无法获取则为define_delay.png
icon : 服务器图标，无法获取则为define_icon.png

#define下的内容：如无法成功获取则使用的默认值

color.json内为各个颜色代码对应的rpba
       r : 红色,0-255
       g : 绿色,0-255
       b : 蓝色,0-255
       a : 透明度,0-255
