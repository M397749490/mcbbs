ChatColorGUI
让玩家彩字聊天更方便~    作者:UrBae/Andrew

插件简介

一个小插件，能够通过指令调出GUI来点击选择聊天所要用的颜色，这样就可以不用背颜色代码啦。

可以通过修改配置文件进行一定程度的自定义，也可以设置不同组的颜色权限。

注：1.13，1.14与1.15版本是否完全适用有待验证

插件命令

  • /chatcolor - 打开聊天颜色菜单
  • /chatcolor help - 显示插件帮助
  • /chatcolor reset <玩家名> - 重置指定玩家的聊天颜色
  • /chatcolor set <玩家名> <颜色代码> - 设置指定玩家的聊天颜色
  • /chatcolor reload - 重新加载配置文件

权限节点

基础权限
  • chatcolorgui.use - 允许使用彩字聊天功能
  • chatcolorgui.help - 允许查看插件帮助
  • chatcolorgui.reset - 允许重置指定玩家的聊天颜色
  • chatcolorgui.set - 允许设置指定玩家的聊天颜色
  • chatcolorgui.reload - 允许重新加载配置文件
颜色权限
  • chatcolorgui.color.white - 允许使用白色
  • chatcolorgui.color.gray - 允许使用灰色
  • chatcolorgui.color.darkblue - 允许使用深蓝色
  • chatcolorgui.color.lightblue - 允许使用浅蓝色
  • chatcolorgui.color.darkgreen - 允许使用深绿色
  • chatcolorgui.color.lightgreen - 允许使用浅绿色
  • chatcolorgui.color.darkturquoise - 允许使用青色
  • chatcolorgui.color.lightturquoise - 允许使用暗青色
  • chatcolorgui.color.darkred - 允许使用暗红色
  • chatcolorgui.color.lightred - 允许使用亮红色
  • chatcolorgui.color.purple - 允许使用紫色
  • chatcolorgui.color.magenta - 允许使用紫红色
  • chatcolorgui.color.darkyellow - 允许使用暗黄色
  • chatcolorgui.color.lightyellow - 允许使用亮黄色
  • chatcolorgui.color.* - 允许使用所有颜色
