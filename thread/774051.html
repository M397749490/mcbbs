插件描述

VIP专属插件，可以让玩家的身边产生各种粒子特效，不必多说，这款粒子特效插件最大的优势在于各版本通吃，最最最重要的是，这个插件能在固定的地方产生粒子特效，直接成地标有没有？

插件指令

  1. /pp effects - 显示你拥有的粒子特效
  2. /pp effect <args> - 设置粒子特效
  3. /pp styles - 显示粒子特效的style
  4. /pp style <args> - 设置粒子特效的效果
  5. /pp data <args> - 设置数据？应该用不到
  6. /pp reset - 重置粒子特效
  7. /pp reset <playerName> - 重置其他玩家的粒子特效
  8. /pp fixed - 固定粒子特效
  9. /pp fixed create <x> <y> <z> <effect> <style> [data] - 在某个位置产生固定的粒子特效
  10. /pp fixed remove <id> - 移除固定在某处粒子特效，根据id
  11. /pp fixed list - 显示所有的固定的粒子特效
  12. /pp fixed info <id> - 获得固定的粒子特效的信息
  13. /pp fixed clear <radius> - 清除一定范围内所有固定的粒子特效
  14. /pp version - 显示版本
  15. /pp worlds - 显示禁用粒子特效的世界
  16. /pp help - 显示帮助

插件权限

和指令对应着看，我就不翻译了

  1. playerparticles.* - Allows full access to effects, styles, and fixed effects
  2. playerparticles.forcereset - Allows a player to force clear another player's effect, style, and data
  3. Note: playerparticles.* does not grant permission to the following:

  5. playerparticles.forcereset
  6. playerparticles.fixed.unlimited
  7. playerparticles.fixed.clear
  8. Particle Permissions:
  9. playerparticles.effect.* - Gives access to all particle types
  10. playerparticles.effect.<effectName> - Effect names are listed in /pp list
  11. Ex. playerparticles.effect.driplava Will give the player permission to use /pp effect driplava
  12. Style Permissions:
  13. playerparticles.style.* - Gives access to all style types
  14. playerparticles.style.<styleName> - Style names are listed in /pp styles
  15. Ex. playerparticles.style.orbit Will give the player permission to use /pp style orbit
  16. Fixed Effect Permissions:

  18. playerparticles.fixed - Gives access to all regular fixed effect commands, except the following:
  19. playerparticles.fixed.unlimited - Allows a player to exceed the maximum set fixed effect limit
  20. playerparticles.fixed.clear - Allows a player to remove ALL fixed effects within a given radius
