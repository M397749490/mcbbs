软件介绍
Minecraft Command Editor 全面发布！使用 c# 并以 Microsoft .Net Framework 为框架，全面重写所有功能代码。简洁的 ui 页面，高效的指令操作，将 MCE 的能力最大化的发挥出来。
MCE 可以对 Minecraft 指令进行高级操作，包括自定义物品附魔、属性等。用户可以高效的在 MCE 上进行一系列指令操作。完全支持 Minecraft 1.13.2 及以下版本。

为了更好的使用 MCE ，请尽可能在 Windows 10 x64 系统，并搭载 .Net Framework 4.6.1 或更高版本运行 MCE 。


特色功能
  • 完全支持 Minecraft 1.13.2 及以下版本
  • 支持多语言切换
  • 清晰简洁的可视化 UI
  • 完全按照原版 Minecraft 对物品类别进行分类
  • 物品 id 及 data 可视化（Minecraft 1.13 及以上版本无 data）
  • 拥有检索功能，可二次编辑生成的指令
  • 拥有生成指令的历史记录（\history 下的.log文件）
  • 拥有离线 Minecraft Command Editor Wiki（2.0.1 新添加）
  • 使用 Microsoft Office Access 进行数据管理
  • 离线化软件，无需联网即可食(使)用
  • ..........

使用指南（必看！）
MCE 上手手册 - 2019.2.14 更新
  • 下载 MCE 相关版本的压缩文件（.rar格式）
  • 解压到你的想要放置的地方
  • 打开解压后的文件夹
  • MCE 1.3.7.1013_beta 及以下版本请跳转至 7~8，MCE 2.0.0 及以上版本请跳转至 5~6
  • 打开 'Install .NET Framework 4.7.2.bat' 批处理文件，会自动运行 Microsoft .NET Framework 4.7.2 安装文件，若安装过 Microsoft .NET Framework 4.7.2 也务必打开批处理，系统会自动检测是否安装成功。
  • 打开 'Minecraft Command Editor.exe' ，第一次运行会自动检测是否安装 Microsoft.ACE.OLEDB.12.0 ，若已安装则点击 '取消' ；若没有弹出提示，请务必在 '设置 - 支持库' 中选择 '安装 AccessDatabaseEngine' ！
  • 打开 MCE 本体 .exe 文件，即可开始使用
  • 如遇到数据损坏的错误，在 MCE 1.3.0.802_beta 到 MCE 1.3.7.1013_beta 之间的版本可使用 'MCELib.exe' 来修复数据（2.0.0 及以上版本不适用）
  • 阅读完使用手册，就请开始你的指令之旅吧~
