当前插件作者：RapDoodle

1.4（NewAPI）版本的已经处于开发阶段，由于现在pm自身加入了gamerule命令，下一个版本将会多出很多东西
插件介绍：
- 这个插件的1.0版本名字为RespawnWithoutDropping，只是一个纯属的事件处理。但后来很多人提议关于插件的修改，便演变成了今天的SpawningControl，不仅仅是监控事件的处理，同时加入了很多人性化的控制。
- 这是一个很简单但是却对你服务器有帮助的插件来保证你的用户死亡的时候不会掉落任何物品。
- 服务器使用他之后将不会出现死亡的画面，而是进行传送
- 使用前请先删除RespawningWithOutDroping也就是这个插件的上一个版本，由于class改变了;
- 如果不设定，玩家在那个地图中死亡后默认回到服务器出生地；
- 每个地图的“是否回到出生点”都要进行用/sc add设置，如果需要全部打开，请直接使用/sc all；
- 如果你感觉这个插件好，请给予5星评价，任何建议都会欢迎，也欢迎大家关注我的Twitter:@RapDoodle

插件的使用：

命令作用 备注
/wspawn用户会回到当前世界的出生点 无
/sc add <地图名称>把一张地图加入到玩家死亡后重生到当前世界的列表中 不加入死亡后默认回到出生点
/sc remove <地图名称>把一张地图从到重生到当前的世界的列表中移除 无
/sc all开启玩家死亡后回到当前世界出生点模式 插件会自动取反

插件介绍原文（旧版）：
This is a very simple but helpful plugin for your server to make sure your players wont lose any item when they died.
IMPORTANT TEXT:
- Theres two plugins inside this packet. The first one: "RespawnWithoutDrop(Back to spawn).php" can let your players back to the spawn when they died.
The other one can let your players back to the spawnpoint in the target world when they died. You can only use ONE at the same time.
- If you have any map like sky block, please dont use it, Im now trying to fix this bug.

感谢：Marcus+中政委菌（MCBBS：raysuperman） 帮忙测试插件。
