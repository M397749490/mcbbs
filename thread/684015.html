" 一款简易便捷的全面盔甲架编辑插件. "


Author - brainsynder
本帖来自: PluginsCDTribe


| 特点 |
- Features -

*本插件适用于Spigot/PaperSpigot/Bukkit类型端
*本插件适用于Minecraft1.8/1.9/1.10/1.11等版本

可记录玩家放置盔甲架地方的UUID
可限制盔甲架的放置
可对盔甲架(ArmorStand)进行快捷编辑
重量级大小的插件 —— 82.4KB
插件内可自定义部分高达95%
盔甲架的命名支持彩色代码
支持 PlotSquared 地皮插件
可完全自定义盔甲架的动作
玩家可以对盔甲架进行编辑/修改


| 权限 |
- Permissions -

*只对重要权限进行注释,详情见该插件WiKi翻译

SimpleArmorStandEdit.modify
── 允许修改盔甲架

SimpleArmorStandEdit.modify.others
── 允许其他玩家修改盔甲架

SimpleArmorStandEdit.overrideLimit
── 允许修改盔甲架放置的上限

SimpleArmorStandEdit.remove.others
── 允许删除其他玩家放置的盔甲架


| 指令 |
- Commands -

/sase count [玩家]
── 显示该玩家拥有盔甲架的数量

/sase wand
── 给予自己一个盔甲架操作棒子

| 使用与安装 |
- Install and Use -

*具体使用介绍.如若有误.及时提醒我
*为了您与您服务器的安全.请规范安装插件(滑)

在任意处放置盔甲架.

右键盔甲架来编辑盔甲架的穿着等.

Shift+右键盔甲架来打开编辑菜单

① 准备好从官网/搬运帖下载好的插件本体
② 前往官网/搬运帖查看您所要使用的插件是否需要前置
③ 将插件本体与插件前置共同移动到服务端目录下的plugins文件夹
④ 重启服务器或者使用PluginsMan载入插件
