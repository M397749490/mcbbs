第一次搬运插件,如若哪里不好请见谅
————————————————————————————————————

简介


这个插件非常强大、耐用。它允许你编辑Items.yml来设置玩家进入服务器时给的物品。
该物品可设置死亡后自动重发、禁止丢弃等
并且物品可以绑定指令,配合菜单(如chestcommands、bossshop、DeluxeMenu)什么的最好了-v-
因此，很多服务器都有用到这个插件。


安装

把下载下来的jar文件放进\plugins文件夹内，重启服务器。



指令和权限

/cji reload - 重置此插件
/cji update - 更新此插件
以上两个指令权限
customjoinitems.admin



配置


找到此插件产生的文件夹里的items.yml：
————————————————————————————————————
# 这里是一个内部名称,不可重复.
first-item:

    id: 352
    # 给予的物品ID,默认是352.


    name: '&aTest item'
    # 给予物品的名称,如：'&6萌萌哒菜单'.


    data-value: 0
    # 数据值,比如说蓝色羊毛,ID是35:3,那么此处就填3.


    cooldown-seconds: 5
    # 这可以防止指令的刷屏.单位(秒)

    command: 'say Hello world'
    # 这里是物品绑定的指令,右键物品就会输入这些指令
    # 设置指令不需要添加斜杠! (/) 如若是创世神指令则需要加一个斜杠

    # 一些前缀是特殊的,可以提供额外的功能
    # commands:
    #
    # 'console: '(以后台来执行命令)
    # '如commands:'console:bc 这是公告'
    #
    # 'op: ' (以OP来执行命令) 同上所用
    # 'server: ' (跨服,前提条件是你得搭建好BC....)
    # 'tell: ' (发送一条消息给玩家. commands:'tell:玩家名称 消息')
    #
    # 另外你可以使用 %player% 和 %world%的变量.
    # %player%指输入这个指令的玩家,%world%指玩家所在的世界
    #
    # 当然,你也可使用多个指令: 'command; command2; command3'

    lore:
      - 'Line 1'
      - 'Line 2'
      - '...'
    # 物品的标识,可多个.

    block-movement: false
    # 是否禁止物品移动.

    slot: 9
    # 设置物品所在物品栏位置(1~9)
    # 如果省略这个,物品将被放在第一个物品栏里.
    # 如果设置了,物品出现在你设置的位置.


    permission: 'customjoinitems.test'
    # 获得此物品所需要的权限,若无设置,
    # 所有人都会获得这个物品(建议不设置).
    # permission: ''

    first-join-only: false
    # 默认不开启
    # 如果设置成true,玩家只有在第一次加入服务器时才能获得

    # 注意:如果first-join-only设置成true
    # give-at-respawn(死亡后给予物品) 将自动设置成false


    give-at-respawn: true
    # 默认开启
    # 设置成true,玩家将在死亡后再获得物品
    # 咳咳,并且重生.


    allow-drop: false
    # 默认不开启
    # 是否允许玩家丢弃此物品(推荐不能丢弃!).


    give-on-world-change: false
    # 默认不开启
    # 是否在世界改变时再给予玩家物品


    disabled-worlds: world_nether, world_the_end
    # 禁止在某个世界不给予物品
    # 如果你不想禁止请设置成.
    # disabled-worlds: ''
