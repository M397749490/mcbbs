MCBBS WARNING
这是一个FabricApi开发的mod，目前被yarn开发者订阅了的项目
(我当时震惊了)
本模组开发之初的想法是和化学mod类似，后来算是超出了化学的界限。这个脑洞的发起时间是2020/3/16
这也算是搁置了好久的mod了，当初是为了做forge版本后来选择了fabric，因为fabric目前开发的前途比较高，相比forge来说跨版本的兼容性好，适合这个mod的1.16的进一步更新。
源码与授权许可
源码遵循CC0协议，目前找不到好的协议就和Fabric的协议相当。
开发者可以借鉴此mod的源码，源码贴在下方(目前是没什么可以借鉴的)
开发作者&他的开发团队
baka4n && SquidcraftTeam(Github)
贡献准则
你可以clone github地址来进行对源码的优化，对本mod进行二次构建，也可以为mod做一个美美的贴图，我们会对其采纳，进行鸣谢，只要你愿意，也可以加入这个项目的开发。
如果遇到bug或者不可描述的东西，请去下方链接的issue进行推送，我们将看得到你的消息。注意不要答非所问，请看:提问的智慧
下载版本
游玩版本 给开发者的版本
不带DEV版本，正常游玩 DEV版本提供给开发者开发拓展mod

其它
前置
Fabric Loader 0.8.2版本以上
Fabric Api 0.10.1+build.336-1.16
模组版本1.0.0还在持续开发中
缺少任意一个都会导致mod崩溃！！ 在游玩mod时如果崩溃了，请务必报告给我们！
目前的下载地址只有github你们可以clone构建版本里面的release里面复制，开发者去to-dev文件夹复制。
对于开发者你可以直接使用我们的源码进行构建和引用，并在援建者名单上加上我的名字或者我的团队即可，制作不易。
鸣谢
squidcraftTeam团队 && 队长:@squid233
