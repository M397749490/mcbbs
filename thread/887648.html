标题: 如何自定义禁用应用能源的伪装板？
因为模组加的多，伪装板足足超过了8页...占用了一部分资源，想把它关掉
但是伪装板还是有人要用，只是想分模组禁用(比如说只想启用原版和AE中方块的伪装板)
如何配置?
.minecraft\config\AppliedEnergistics2\Facades.cfg 貌似是这个文件
版本:1.12.2
(我的意思不是隐藏 像让大部分伪装板不要自动生成)
作者: mine新时代xs    时间: 2019-7-18 10:25
首先，Facades.cfg是应用能源提供的关于实体方块制作线缆伪装板的配置文件，它提供了一个启用实体方块(如玻璃、橡木楼梯等)伪装板白名单的选项，还提供了一个白名单，白名单内的实体方块都会在游戏中添加对应的伪装板
所以，不能通过修改Facades.cfg的方法修改AE2的伪装板
然后，是关于如何修改线缆伪装版
虽然很遗憾但应用能源的配置文件只提供了禁用所有伪装板的选项
在config文件夹下的AppliedEnergistics2文件夹中找到AppliedEnergistics2.cfg
用记事本或notepad++编辑
找到
  1. facades {
  2. B:Facades=true
  3. }
复制代码

将true改为false即可禁用所有伪装板
或者找到
  1. crafting {
  2. B:EnableDisassemblyCrafting=true
  3. B:EnableFacadeCrafting=true
  4. B:InWorldFluix=true
  5. B:InWorldPurification=true
  6. B:InWorldSingularity=true
  7. B:InterfaceTerminal=true
  8. }
复制代码

将EnableFacadeCrafting改为false即可禁用所有伪装版的合成
没有其他选择的余地(禁用部分模组？不存在的)
