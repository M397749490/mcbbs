标题: 关于苦力怕和tnt爆炸声音修改的问题
1.16版本，我想做一个材质包，其中一项的内容是把苦力怕爆炸之前的声音改为扣扣哒哟，然后改完之后我发现苦力怕播放这个音频的时候会慢放，后来我想起tnt也会播放这个音频，试了以后发现tnt不会慢放
现在我想知道怎么在不影响tnt正常把这个音频播放的情况下让苦力怕播放这个音频的时候不会自动慢放
有大佬可以帮我解决一下吗
（注：正常播放也包括游戏内正常的音频使用）
作者: ⊙u⊙    时间: 2020-7-10 22:13
虽然苦力怕和tnt都是使用同一个音频，由于硬编码定义了播放速度的不同。可以在材质包里创建sounds.json定义苦力怕爆炸时使用独立音效。


assets/minecraft/sounds.json
  1. {
  2.     "entity.creeper.primed": {
  3.         "replace": "true",
  4.         "sounds": [
  5.             {
  6.                 "name": "custom/boom"
  7.             }
  8.         ]
  9.     }
  10. }
复制代码



/assets/minecraft/sounds/custom/boom.ogg
