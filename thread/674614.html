EasyBackup | 介绍
  • EasyBackup可以备份服务器的所有文件，包括世界文件，日志文件，插件文件，服务器的核心文件以及其他的所有数据!
  • 备份数据将默认打包成RAR压缩文件。你也可以改成其他压缩扩展，比如  zip 和 tar.gz 。
  • 除了服务器备份文件夹备份的文件以及插件不能访问的数据，插件都可以将其打包备份。

EasyBackup | 特性
  • 可备份所有文件
  • 压缩率可配置，最高压缩达率高达250%
  • 抗滞后特性，自动调整备份速度，不影响服务器运行
  • 可配置自动备份
  • 简单易用-放入插件文件夹后运行服务器
  • 完全可配置
  • 语言可配置
  • 备份最大数量限制，超过限制自动删除旧备份

EasyBackup | 压缩
  • 压缩率可以设置在1和10之间。最佳压缩级别为10。你设置的压缩越高，备份的时间越长，但由于文件会变小，下载或重新上传备份文件的速度会更快。10级压缩进行了测试，服务器1300mb数据压缩成一个550mb文件。
  • 本人测试 7G左右的服务端 1级压缩后7G 10级压缩后3G 建议设置为最高等级

EasyBackup | 恢复
  • Restoring a backup is also possible. Before restoring, EasyBackup will automatically create a restore point backup. When restoring a backup note that ALL exempt files or unsaved files will be erased, but they will still be in the restore point backup. While restoring, do not start your server because files that are not restored yet can not be restored because bukkit/spigot will be using those files.
  • Restoring takes about 60 seconds to start after you run the command. It will automatically shut down your server to run a background task. Once the server is shutdown to restore, it will take about the same amount of time as backing up your server.
  • You will know the restore process has completed when the file " restore_log.txt " appears in your main server folder.
  • 这里的内容摘自原贴，本人不推荐使用恢复功能，自己手动恢复就好了嘛......

EasyBackup | 命令
  • 权限: EasyBackup.backup >>
  • /backup create - 创建一个备份
  • /backup cancel - 取消正在进行的备份
  • /backup info - 关于备份的信息
  • /backup reload - 重载配置
  • 权限: EasyBackup.restore >>
  • /backup restore [备份名字] - 恢复备份

EasyBackup | 配置
  1. #是否开启自动备份
  2. autoBackup: false

  4. #自动备份时间间隔
  5. backupDelayInHours: 72

  7. #最大备份文件保存数量，超过此数量将删除旧的备份文件
  8. maxBackupsBeforeErase: 4

  10. #上次服务器备份时间
  11. lastBackup: 0

  13. #压缩等级[1-10之间] - 10 属于最高级
  14. compressionLevel_1-10: 3

  16. #防滞状态 (服务器延迟高推荐开启)
  17. slowdownWhenServerLags: true

  19. #当开启防滞功能后，是否提示信息
  20. showSlowdownMessage: true

  22. #输入信息到控制台
  23. debug: false

  25. #备份文件名字 %time%替换备份时间 必须添加
  26. name: 服务器备份_%time%

  28. #备份文件的扩展名.支持 rar zip tar.gz
  29. extension: rar

  31. #不备份以下文件夹和文件
  32. exemptFolders:
  33. - example/this/folder/wont/backup
  34. - example/folder
  35. - example/file.yml

  37. #备份文件保存路径
  38. saveFolder: plugins/EasyBackup/Backups

  40. #是否限制游戏内使用备份命令
  41. allowInGameCommands: true
