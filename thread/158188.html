怎么给default设置商店的使用权限啊
作者: aresidsz    时间: 2013-8-11 23:09
需要用到这三个权限 这样输入三次命令就可以了
/mangaddp default ItemFrameShops.use.*
/mangaddp default ItemFrameShops.buy
/mangaddp default ItemFrameShops.sell
