命令:
/nbs add <Wolrd Name> —— 添加世界到不生效的名单
/nbs remove <World Name> —— 移除世界在不生效名单里
/nbs reload —— 重载配置


配置文件

  1. #############################
  2. # NoBlackSky by gamerover98 #
  3. #############################

  5. #
  6. # Set to true if you use ParadiseLand plugin, the worlds generated with ParadiseLand won't be menaged by Blacklist
  7. #
  8. # https://www.spigotmc.org/resources/paradise-land-1-8-1-11-2-skyworld-generator.28056/
  9. #如果你在使用ParadiseLand插件，如果你设置成true，ParadiseLand插件生存的世界黑名单将不会生效。
  10. paradise_land: false

  12. # 若果你不想它在某个世界生效的话，请把世界名加入下面。
  13. blacklist:
  14.   - noVoidWorld

权限
nbs.* —— 本插件所有权限许可
nbs.add —— 是否允许使用/nbs add
nbs.remove —— 是否允许使用/nbs remove
nbs.reload —— 是否允许使用/nbs reload
