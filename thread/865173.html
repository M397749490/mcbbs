ClickToQuote - 聊天框复制

（上面的下载地址是英文版的，汉化版在末尾）







效果截图







你们都以为MC的聊天框不装MOD是没法复制内容的。所以有时候要复制别人说的话（比如复读）会不太方便。

所以我做了款插件，方便自己快速复制聊天框内容。

玩家只要点一下别人说的话，就能自动复制到聊天框了。







插件需要 ProtocolLib 前置
和 Java 8 以上的版本

(因为我写插件的时候用了 Java 8 的新语法 Lambda)







插件特点


  • 轻量 (8kb大) 不占资源
  • 插件原理是直接修改数据包，所以不会改变别的插件设置好的聊天格式
  • 插件自带一个过滤器，用来"过滤"一遍复制的文本。
  • 过滤器解释：比如，有个玩家说了一句话"我喜欢里约 :)"，大家看到的是"<玩家名> 我喜欢里约 :)"。
  • 如果没有过滤器，默认整句话会被复制，所以玩家会复制"<玩家名> 我喜欢里约 :)"。如果增加了一个过滤器，过滤掉“<玩家名> ”，玩家就会复制"我喜欢里约 :)"。
  • 过滤器基于正则表达式，所以简单易于配置，也能匹配很复杂的内容。比如你的服务器的聊天格式是“[空岛世界][尊贵VIP][玩家名]: 高价收黑曜石”，过滤器也能过滤掉“[空岛世界][尊贵VIP][玩家名]: ”这个前缀。
  • 可以配置很多个过滤器。
  • 鼠标悬浮在文字上时可以出现提示“点击复制到聊天框”。这个提示内容可以改，也可以禁用。

插件配置


# 通用外观设置
appearance:
  # 鼠标悬浮在聊天文字上时是否显示提示框
  show-hovering-prompt: true
  # 提示框的内容(上项设置为true才有用)
  hovering-prompt: "&a点击复制到聊天框"

# 正则表达式设置
# 插件会根据下面设置的正则表达式，在复制聊天文字时自动去掉一些东西(比如玩家的名字)
# 例子: 有个玩家说了一句话，大家都看到的是这样："<Unity41> 我喜欢里约 :)"
#     > 如果没有设置正则表达式，默认整行会被复制，包括名字，即玩家会复制 "<Unity41> 我喜欢里约 :)"
#     > 如果设置了正则表达式 "<.+> " (不带引号), 正则表达式会匹配到 "<Unity41>" 并且自动排除
#     > 所以玩家最后复制到 "我喜欢里约 :)"
# 请注意单独的 \ 号在 YAML 格式的配置文件中必须写成 \\
excluder-settings:
  regexes:
    - "<.+> "
