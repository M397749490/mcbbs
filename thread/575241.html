作者: 梓    时间: 2016-4-13 22:36
g981070922 发表于 2016-4-13 22:27
那要怎么写啊，除了eco权限其他都要，一个一加？

新建一个管理组
假设设定管理组名为op
指令mangadd op
建立一个叫op的权限组
mangaddv op build true
给予基本建筑权限
mangaddi op builder
op组所有权限继承builder （即拥有builder所有权限）
上面步骤完成之后op组就和普通玩家组权限一样了
然后你再加上要给的一些管理权限  
例如ban coi gamemode
等等  各种权限 不想让op使用的指令就不给权限
最后效果就能达到了  
而且不同于/op ID
让op有权限给自己加权限
