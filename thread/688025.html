作者: sss1    时间: 2017-4-23 00:36
打开  academy-craft-data.con

cp_consume_speed: 1.0,
overload_consume_speed: 1.0,            


这俩是CP槽和过载槽的消耗速度
改成0。然后把上面这两串复制黏贴到黑色背景的位置（每符合这样格式的位置都需要黏贴）
skills{
XXXX{          }
XXXXX{        }
}
技能就不会有消耗了

文件没有提供关于【技能的冷却】这样的配置
所以，冷却是不能更改的（至少现在不能）
