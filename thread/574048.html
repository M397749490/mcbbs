介绍：
本插件可以自定义一些核心玩法。如：禁止物品掉落、禁止产生伤害、禁止掉入虚空、禁止破坏与放置方块、进服自动传送到重生点。

使用：
将本插件丢进服务端plugins文件夹内，重新启动服务器即可。

配置：
  1. #true- 是, false- 否
  2. #是否对OP有效
  3. OP: false
  4. #是否禁止物品掉落
  5. NoDrop: false
  6. #是否禁止产生伤害
  7. NoDamage: false
  8. #是否禁止掉入虚空
  9. NoVoid: false
  10. #是否禁止破坏与放置方块
  11. NoBreak&Place: false
  12. #进服是否自动传送到重生点
  13. AlwaysSpawn: false
