不是我吹牛逼。2楼这个根本没有效果。莫名奇妙的又会变成hard（困难）模式。估计你这个是面板服，然后设定的模式就是困难或者普通模式。MV的配置是跟着你服务器的配置的。

要么你就给地皮传送点，加个脚本，用脚本插件，每次玩家传送到地皮，就触发这个脚本：/mv modify set difficulty 0  就设置了

作者: 草原能跳绳    时间: 2016-7-30 21:06
我建议你去修改MV插件的配置文件来更改某世界设置

下面我用适用1.9.4的MV插件给你做例子，配置文件内容估计比你那版本多一些内容罢了
我给你划出一些有用的

world:
    ==: MVWorld
    hidden: 'false'
    alias:                               ←此处填写你希望该世界显示的昵称
    color: WHITE
    style: NORMAL
    pvp: 'true'                        ←该世界是否可以PVP
    scale: '1.0'
    respawnWorld: ''
    allowWeather: 'true'
    difficulty: HARD                ←该世界游戏难度，现在为困难，注意大写
    spawning:
      ==: MVSpawnSettings
      animals:
        ==: MVSpawnSubSettings
        spawn: 'true'                ←该世界是否可以生成动物
        spawnrate: '-1'
        exceptions: []
      monsters:
        ==: MVSpawnSubSettings
        spawn: 'true'                ←该世界是否可以生成怪物
        spawnrate: '-1'
        exceptions: []
    entryfee:
      ==: MVEntryFee
      amount: '0.0'
      currency: '-1'
    hunger: 'true'
    autoHeal: 'true'
    adjustSpawn: 'true'
    portalForm: ALL
    gameMode: SURVIVAL      ←游戏模式，注意大写（如果不想玩家破坏该世界，设为冒险模式即可）
    keepSpawnInMemory: 'true'
    spawnLocation:
      ==: MVSpawnLocation
      x: 0.5                            ←
      y: 64.0                          ←该世界出生点
      z: 0.5                            ←
      pitch: 0.0
      yaw: 0.0
    autoLoad: 'true'
    bedRespawn: 'true'
    worldBlacklist: []
    environment: NORMAL
    seed: '381219855606680962'
    generator: 'null'
    playerLimit: '-1'
    allowFlight: 'true'
