食用方法~


命令权限

/mf help —— 打开MoreShop插件帮助

/mf begin [时间(秒)] —— 手动开启一个钓鱼竞赛【管理员指令】

/mf suspend —— 暂停钓鱼竞赛，价格和宣布排名将被跳过【管理员指令】

/mf end —— 结束钓鱼比赛，并颁发奖品和向玩家宣布排名【管理员指令】

/mf rewards —— 打开可设置钓鱼奖励（物品和货币）【管理员指令】
（需要前置Ess和Vault）

/mf clear —— 清除比赛的排名【管理员指令】

/mf reload —— 重新加载配置文件【管理员指令】

/mf shop [ID] —— 为一个玩家打开贩鱼商店【管理员指令】

/mf shop —— 打开贩鱼商店【morefish.shop】

/mf top —— 展示钓鱼竞赛的记录【morefish.top】

如何自定义鱼类
在fish_zh_cn文件中按以下格式新增

                                       - # []: 空格，<Num>: 数值，"**": 字符

                                       - [][]<级别/默认已给出, 可找到后在下方添加鱼>:

                                       - [][][][]<鱼/使用英文>:
                                       - [][][][][][]display-name: "显示名称/支持彩色代码"
                                       - # 鱼的随机长度 - 最小值
                                       - [][][][][][]length-min: <Num>
                                       - # 鱼的随机长度 - 最大值
                                       - [][][][][][]length-max: <Num>
                                       - # 鱼的实际物品相关内容
                                       - [][][][][][]icon:
                                       - # 鱼显示的物品, 需与Minecraft官方Wiki一致
                                       - [][][][][][][][]id: "minecraft: "
                                       - # 鱼显示的物品的数量
                                       - [][][][][][][][]amount: <Num>
                                       - # 鱼显示的物品的耐久
                                       - [][][][][][][][]durability: <Num>
                                       - # 鱼显示的物品Lore相关项
                                       - [][][][][][][][]lore:
                                       - [][][][][][][][][][]- "Lore内容/可多行"
                                       - # 鱼显示的物品附魔相关项
                                       - [][][][][][][][]enchantments:
                                       - # 附魔类型需与Minecraft官方Wiki一致，等级为数值，可添加多行
                                       - [][][][][][][][][][]- "minecraft:附魔类型|附魔等级"
                                       - # 跳过物品的格式设置，显示名称等都将无效，不推荐开启
                                       - [][][][][][]skip-item-format: <true/false>
                                       - # 钓上鱼后执行的命令
                                       - [][][][][][]commands:
                                       - # 例：- "whisper @p hello world!"
                                       - [][][][][][][][]- "命令内容/玩家的变量只允许为@p/可添加多个"
