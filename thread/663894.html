咳咳，由于第一次发帖自我介绍一下我叫灵飞 Mc龄6岁 职业技术，某个服腐竹，指令方块大师
那么告诉大家一下灵感来源，我自己的服务器
纯天热，半自动烧物机
以上都是废话，进入正题吧！
单机玩，推荐别使用。
此东西是给予服务器的

材料:发射器×1，漏洞×3，熔炉×1，压力板×1，箱子×2
制作教程:
第一排:[size=35.2528px]漏斗(漏洞小的方向朝着下面)
第二排:箱子
第三排:漏斗(漏洞小的方向朝着下面)
第四排:熔炉(肯定需要玩家手动加煤)
第五排:漏斗(漏洞小的方向朝着下面)
第六排:发射器(发射孔面对前面)
第六排前面:压力板
压力板旁边在放个箱子装燃料
好得还有一步就是圈地咯。
指令:/res create 领地名字
圈好地还有一指令
/res set 领地名字 use t
让玩家使用压力板

建筑完成就开始实验了
玩家爬到最上面，把要烧的物品扔进最上面的漏斗里
就大公告成
