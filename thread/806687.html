mcpkg 文档

1. 总则

mcpkg 是一个基于 TOML(Tom's Obvious, Minimal Language) 的 Minecraft 整合包配置文件。

Minecraft 是一款沙盒类独立视频游戏，凭借着社区的发展，其扩展（下称 mod）数量已经达到了空前的程度。凭借扩展的集合来创造特定的游戏体验的，被称为整合包（modpack）。

然而当今 Minecraft 整合包的格式仍然没有规定，使用各种启动器导出的整合格式不尽相同。并且至今，在中国最大的 Minecraft 社区 MCBBS 中，仍然有大量的是直接将 .minecraft 文件夹打包发布。这种整合包包含 Minecraft 游戏文件，是严重违反 Minecraft EULA 的。

mcpkg 的目标是成为 Minecraft 整合包的通用配置文件。借助于 mcpkg，整合包打包者可以用一种读写轻松的方式创建整合包，往里面添加资源包、mods 和配置，并且将它发布。它不会带有 Minecraft 游戏文件和 mods，而是让启动器从官方服务器和 CurseForge 等下载文件。这样做，最小化了整个整合包的体积，并且避免了由于违反 EULA 而产生的纠纷。

2. 关键文件

要开始使用 mcpkg，你需要在游戏根目录（.minecraft 的上一层）先创建一个 mcpkg.toml 文件。

还有一个 mcpkg.lock.toml，需要启动器自动创建。

目录结构像这样：

  1. .
  2. ├─mcpkg.toml
  3. ├─mcpkg.lock.toml
  4. └─.minecraft
  5.    ├─config
  6.    ├─logs
  7.    └─...

3. 定义一个包

在 mcpkg.toml 里面加上如下字样（仅供示例参考）：

  1. [package]
  2. name = "sevtech-ages"
  3. displayName = "SevTech: Ages"
  4. version = "3.0.8"
  5. authors = ["Darkosto"]
  6. website = "https://minecraft.curseforge.com/projects/sevtech-ages"
  7. cfid = 268208
复制代码

重要：如有侵权，请联系 zeroaurora233@outlook.com。

解释一下各项目。

  • name：字符串，可以被程序引用而不会出错的整合包名。必须是小写字母、数字和连接符的组合。如果发布到了 CurseForge，则使用 CurseForge 项目名（全部小写）
  • displayName：字符串，显示给玩家的整合包名。可以任意使用大小写字母、数字、符号和空格，无特殊情况不使用 TOML 中的字面量字符串。
  • version：字符串，整合包版本号。
  • authors：包含着字符串的数组。
  • website：字符串。指向整合包发布网页。
  • cfid：（可选）整数。表示 CurseForge 中的 Project ID。

现在继续在 [package] 字段下添加更多的内容：

  1. gameVersion = "1.12.2"
  2. javaVersion = "~1.8.0"
  3. forgeVersion = "14.23.4.2707"
