标题: 怎么在某地一个地方弄怪物不出生
如题，不过不是把这个世界弄怪物不出生，只是某一个区域弄怪物不出生，求助
作者: LS_jie    时间: 2015-6-25 20:03
先用领地插件圈一块地，然后输入
禁止刷新怪物
/res set <领地名> monsters false   
禁止刷新动物
/res set <领地名> animals false
