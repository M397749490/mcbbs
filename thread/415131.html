我们为了制作Mod，需要下载一些东西。第一个是http://www.oracle.com/technetwor ... ownload-432154.html，不过我们在上一篇博客完成，在此不再敖述。然后呢，下载一个http://mcp.ocean-labs.de/releases/（PS：根据你想编写的MC版本下载哟），接下来，在你的workspace（这个不清楚的，请自行百度eclipse workspace）中创建一个文件夹来编写你的mod（以后都在这哟，我的叫MC_MODS），把下好的MCP压缩文件放在里面，接着，再创建一个文件夹(我的叫mod_0)，用来放你的第一个mod。现在回到MC_MODS目录下，打开压缩文件，你能看到很多.bat和.sh文件，全选，把它们放在mod_0目录下。做完这个后，不要忙着删除MCP，你以后想编其他的Mod的时候，要用到的。


接下来，你需要一个纯净版的minecraft，从http://minecraft.gamepedia.com/Minecraft.jar下载，还是要注意版本啊ヽ(≧Д≦)ノ。下在那个目录下，你随意，我们只需要其中的bin文件夹和resource文件夹，找到他们，放在mod_0的jar目录下。然后你需要一个MODLOADER API，可以在http://files.minecraftforge.net/下载，记得下载src（latest版本的），当然你需要安装API（在JAR目录的MC核心文件）。

<h2>1.7.10版本配置</h2>
对于新版本的，技术更新啦，自然比较简单，但是同样的，我们需要JAVA和eclipse。不同的就是下面啦，听我慢慢道来(和windows有毛线区别，就是.bat是windows下的，linux用sh脚本运行，用chmod增加执行权限就能./运行了，所以windows把./去掉即可)
1.下载http://files.minecraftforge.net/，注意直接的版本，请直接下载src。
2.在workspace里创建“forge_mods”文件夹，这将放置我们的mod代码和forge。
3.将下载好的forge src解压缩到forge_mods目录下。
4.打开命令窗口，cd到forge_mods目录下，输入以下代码：
./gradlew setupDecompWorkspace
5.然后输入以下代码：
./gradlew eclipse
6.完成之后，若提示缺少LWJGL文件，请按照如下步骤：
./gradlew setupDecompWorkspace
./gradlew cleanCache
./gradlew install setupDecompWorkspace eclipse –refresh-dependencies
我家网速太慢，鉴于此，网速慢的可以去玩点别的，大约一个小时候，回来看看T_T
7.然后就是导入项目，如果有看台湾教程的同学，“專案”=“项目”=“project”，我用的是英文版，但是还是会给大家说明的。首先，打开eclipse，如果是第一次打开，会让你选择workspace，这里注意了，一定要选择forge_mods下的eclipse目录，这样，打开eclipse的时候就可以在项目浏览器里看到minecraft了，然后在上面有的绿色的类似播放按钮的东西，有下拉菜单，可以看到Run Client（运行客户端）和Run Server（运行服务端），你可以试试~\(≧▽≦)/~啦啦啦（额，其实这里是forge的自动配置，你要是不喜欢，可以手动设置，参考这里吧http://www.hakugyokurou.net/wordpress/?p=134</a>
