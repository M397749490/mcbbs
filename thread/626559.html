AI-Core是一个库，使用JMegaHAL生成类似聊天机器人的插件。AI也可以使用其他网站上的句子，这给了AI更广泛的学习空间，同时AI也会尝试学习玩家在服务器上所说的话。


目前支持的网站：
4chan.org


未来的计划：
  • 可以创建多个AI，而且可以自定义（目前只有一个“主要”的AI）。
  • 支持更多的网站如Reddit和推特。



使用AI-Core作为核心的插件：
TalkingMobs

配置选项

  1. #if true, the 4chan board scraper will be enabled which will
  2. #load the AI with content from 4chan. Support for other websites
  3. #like reddit coming later.
  4. boardscraper: true

  6. #boards from 4chan the bot with gather posts from
  7. boards:
  8.   - b
  9. #how many pages worth of threads which will be loaded into the brain
  10. #each value corresponds to the boards in the list above
  11. #do not go over 10. the larger the number the longer it takes to load
  12. boarddepths:
  13.   - 10
  14. #how often (in hours) the chatbots brain will be updated with new content
  15. update-frequency: 12

  17. #If set the true, the AI will learn from players when they chat in game
  18. LearnFromChat: true

  20. debug: false

API方法

  1. //Generates a sentence based on the sentence given. If no sentence is specified the returned String will be generated at random
  2. AICore.GenerateSentence(sentence);

  4. //adds a sentence to the AI's brain file
  5. AICore.addSentence(sentence);
