java.lang.IllegalArgumentException: Duplicate enchantment id! class electroblob.wizardry.enchantment.EnchantmentMagicSword and class tb.common.enchantment.EnchantmentMagicTouch Enchantment ID:100

ID为100的附魔效果已被注册，后来的WizardryMod当然注册不上啊。尝试：在打开config文件夹里的wizardry.cfg，找到：
    # The ID of the magic sword enchantment. Change if this conflicts with another mod.
    I:magicSwordEnchantmentID=100

把100改成大于零但是不太大的正整数，保存。
如果后续发生相同类型错误，按照这个思路修改配置文件就行了。
