作者: Ph-苯    时间: 2020-2-25 15:31
data modify 目标路径 set from 源路径
这条命令可以比较目标路径和源路径的nbt是否相同，如果相同，这条命令就会执行失败；如果不相同，就会执行成功，把目标路径的nbt设置为源路径的nbt。
你可以用这个来一一比较箭的owner和各个实体的uuid，然后给匹配成功的实体加tag。
比如：
最外层内容：
tag @e remove a
execute as @e[type=arrow,tag=!already] run function 函数1
tag @e remove already
最外层结束
函数1内容：
tag @s add detecting
execute as @e run function 函数2
tag @s remove detecting
tag @s add already
execute if entity @e[type=player,tag=owner] run tag @s add a
tag @e remove owner
函数1结束
函数2内容：
data modify 临时路径1 set from entity @e[type=arrow,tag=detecting,limit=1] owner.M
data modify 临时路径2 set from entity @e[type=arrow,tag=detecting,limit=1] owner.L
execute store success score 记分板路径1 run data modify 临时路径1 set from entity @s UUIDMost
execute store success score 记分板路径2 run data modify 临时路径2 set from entity @s UUIDLeast
execute if score 记分板路径1 matches 1 if score 记分板路径2 matches 1 run tag @s add owner
函数2结束
