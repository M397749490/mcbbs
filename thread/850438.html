MonsterPVE-刷怪插件
[此排版来自PCD小组]

插件介绍:
                  一款自定义刷怪点的刷怪插件
插件功能:
  • 支持原版全生物
  • 可自定义怪物穿戴装备
  • 自定义怪物攻击药水效果
  • 支持nbt物品掉落(目前只支持RSWeapon的物品,觉醒插件的物品) "兼容性，如果不用可以不用添加这几个插件"
  • 击杀怪物执行命令
  • 可开启超出范围清除怪物
  • 自定义范围刷怪(在自定义的正方体范围内刷怪)
  • 自定义怪物骑乘
  • 全GUI操作.
  • 自定义怪物大小
  • 自定义怪物攻击力范围
  • 支持设置地图怪物数量限制
  • 自带nbt物品掉落显示名字
配置文件:  
  1. #id:
  2. # 攻击力:  1-2   //攻击力范围
  3. # 药水效果:
  4. #  - 药水ID:等级:时间:触发几率
  5. # 掉落物品:
  6. #  - id:damage:概率
  7. # 装备类: //id:damage
  8. # 骑乘怪物: pig //怪物类型
  9. # 范围刷怪: true/false //是否开启范围刷怪
  10. # 刷怪范围:   //以刷怪点为正方体中心点，长宽高为 刷怪范围*2的正方体区域类刷怪
  11. # 刷怪数量:   //每一次刷怪的数量
  12. # 刷怪距离:   //距离刷怪点多远开始刷怪
  13. # 击杀执行命令:
  14. #  - cmd:概率  //@p代表击杀玩家名字
  15. #  - kill @p:100
  16. # 怪物数量上限:  //每个地图该刷怪点的怪物上限数量
  17. # 是否开启清除:  //超过刷怪点多远清除 0表示不开启
  18. # nbt物品掉落:     //所属插件编号 1:RSWeapon武器 2:RsWeapon防具 3:RSWeapon宝石 4:LevelAwakenSystem物品
  19. #  - id:数量:所属插件:概率
  20. #  - weapon_name:1:1:100
