前言


前几天兴致勃♂勃去某国内最大小游戏服玩起床，结果那铺路的，不潜行直接就。。。。铺路过去了
其实这种作弊我很早就知道了，不过个人不喜欢作弊
今天顶着作业多，花了一下午写了这个插件。

注意，此插件判断存在严重问题，要想获得更好的反自动铺路,私聊获取,没空发= =



功能

功能: 禁止非法放置方块

何为非法？就是你放这个方块头却朝着其他地方

这是我根据V端的自动铺路观察出的

而且这插件尽量减少了误判。

插件会记录一个玩家非法放置方块的次数，如果超过阈值就踢出该玩家。

可以自定义踢出阈值，自定义提示信息和踢出信息

---此插件只检测生存模式的玩家是否作弊---




命令与权限以及配置文件

命令:
无
权限:   
还是无
配置文件

[iron_ingot]
kickzbcs就是阈值，当玩家非法放置次数超过这个阈值就会踢出服务器
mp就是当玩家被检测到非法放置方块，服务器发送给玩家的提示，支持颜色代码
kick就是踢出时显示的信息，不支持颜色代码

默认UTF-8格式，乱码自行转码

  17. public class apc extends JavaPlugin implements Listener{
  18.         private HashMap<String,Integer> log;

  22.         public void onEnable(){

  29.                 Bukkit.getServer().getPluginManager().registerEvents(this, this);
  30.         }
  31.         void add(String p){

  34.                         log.remove(p);
  35.                         log.put(p, cs+1);
  36.                 }else{
  37.                         log.put(p, 1);
  38.                 }
  39.                 if(log.get(p)>this.cs){
  40.                         Bukkit.getPlayer(p).kickPlayer(kick);
  41.                 }
  42.         }
  43.         public void onDisable(){

  45.         }
  46.         @EventHandler

  48.                 if(log.containsKey(e.getPlayer().getName())){
  49.                         log.remove(e.getPlayer().getName());
  50.                 }
  51.         }
  52.         @EventHandler
  53.         public void onBlockPlace(BlockPlaceEvent e){
  54.                 if(!e.isCancelled()){
  55.                         if(e.getPlayer().getGameMode().equals(GameMode.SURVIVAL)){
  56.                                         //不是飞行
  57.                                         Set<Material> s=new HashSet<Material>();
  58.                                         Block tar=null;
  59.                                         for (Material ma : Material.values()){
  60.                                                 s.add(ma);
  61.                                         }
  62.                                         for(Block b:e.getPlayer().getLineOfSight(s, 6)){
  63.                                                 if ((b != null) && (b.getType() != Material.AIR)){
  64.                                                         if(b.getType().toString().contains("WATER")){
  65.                                                                 break;
  66.                                                         }
  67.                                                         if(b.getType().toString().contains("LAVA")){
  68.                                                                 break;
  69.                                                         }
  70.                                                         if(b.getType().toString().contains("GRASS")){
  71.                                                                 break;
  72.                                                         }
  73.                                                         tar=b;
  74.                                                     break;
  75.                                                 }
  76.                                         }
  77.                                         if(tar==null){
  78.                                                 
  79.                                                 return;
  80.                                         }
  81.                                         if(!e.getBlock().getLocation().equals(tar.getLocation())){
  82.                                                 if(e.getPlayer().isSneaking()){return;}
  83.                                                 this.add(e.getPlayer().getName());
  84.                                                 e.getPlayer().sendMessage(mp.replaceAll("&", "§"));
  85.                                                 e.setCancelled(true);
  86.                                         }
  87.                                 }
  88.                         
  89.                 }
  90.         }
  91. }
