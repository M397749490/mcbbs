◆介绍◆
RandomSpawnPlus is a lightweight and configurable random spawn plugin. It has enough features to make your server the way you want it, and it's great for Survival and Factions servers alike.  You can find the addons bundled within the .zip file.

RandomSpawnPlus是一个轻量级、可配置的随机生成插件。
它有丰富的功能使你的服务器达到你想要的效果，对生存服和Factions服都很好，你可以在.zip文件中找到相关的插件。


Random Spawning
Players can be given a spawn on their first join, whenever they die, both, or neither. All of this is controllable by permissions.
随机生成
玩家可以在他们第一次加入时获得一个新的生成点，无论怎样，他们都可以或者不可以获得。这些都是由权限控制的。


/wild
Using the same efficient random spawning system, players can get a new location whenever they run /wild. There's also a configurable cooldown.
/wild
使用相同、有效的随机生成系统，玩家可以得到新的出生点无论何时他们使用/wild。有可配置的冷却时间哦。


Developer API & Addons
An easy to use API means that addons can be quickly created to add support for more plugins. Addons for Factions and WorldGuard is bundled within the provided .zip.
开发者API&附属
一个很简单易用的API意味着可以快速创建对更多插件的支持。Factions和WorldGuard的附属已经包含在作者整理的zip里。


Built-in Essentials Integration
The Essentials integration allows you to give players a /home on their first spawn - effectively giving them a permanent random spawn. (Must be enabled in config)
内置Essentials整合
Essentials整合允许你给予玩家/home 在第一次出生时 - 永久有效的随机出生(必须在配置文件中启用)


Spawn Caching
Personally, my favourite feature - While most RTP plugins look for a spawn when it needs to (i.e. on death or /wild), RandomSpawnPlus loads up a bunch of spawns before the server boots. This means that there is NO lag or delay when finding a location, because all that work has been done already. You can change the amount of cached spawns in the config.

出生点缓存
对我来说，这是我最喜欢的特点-大多数RTP插件在需要时候才寻找新的出生点（在死亡或者/wild时候）
但是RandomSpawnPlus早就在服务器启动前加载好了一堆“出生点”，这样子就可以降低在寻找新出生点时候的延迟。
因为他早就把活儿干完了（这叫未雨绸缪），可以在配置文件中修改出生点缓存的数量。
命令/权限
命令：
/rsp reload - 重载配置文件 & 语言文件
/wild - 传送你到一个随机出生点
/wild <player> - 传送某人到随机出生点

权限：
randomspawnplus.randomspawn:
  启用随机出生点
  默认: op
randomspawnplus.wild:
  传送到随机出生点
  默认: op
randomspawnplus.wild.others:
  传送别人到随机出生点
  默认: op
randomspawnplus.wild.bypasscooldown:
  绕过传送冷却时间
  默认: op
randomspawnplus.manage:
  允许使用/rsp (和/rsp reload) 命令
  默认: op
