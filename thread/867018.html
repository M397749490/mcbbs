介绍 · Introduction
来自Quests插件作者:
导入这个库你就可以使你开发的插件发送的信息自动转译成目标客户端所用语言,如物品材料名、实体名和附魔名.

兼容bukkit1.7.2+
入门
首先添加LocaleLib的jar到你的Java build path或使用Maven将其添加为前置：
  1. <repositories>
  2.     <repository>
  3.         <id>jitpack.io</id>
  4.         <url>https://jitpack.io</url>
  5.     </repository>
  6. </repositories>
复制代码
  1. <dependency>
  2.     <groupId>com.github.PikaMug</groupId>
  3.     <artifactId>LocaleLib</artifactId>
  4.     <version>1.1</version>
  5. </dependency>
复制代码
然后在plugin.yml内添加为前置：

  1. depend: [LocaleLib]
复制代码
现在你需要为LocaleManager添加reference，示例如下：
  1. private LocaleManager localeManager;

  3. @Override
  4. public void onEnable() {
  5.    LocaleLib localeLib = (LocaleLib) getServer().getPluginManager().getPlugin("LocaleLib");
  6.    localeManager = LocaleLib.getLocaleManager();
  7. }
复制代码
最后决定使用的消息和指令，但你先要获取玩家：
  1. org.bukkit.entity.Player p = Bukkit.getPlayer("PikaMug");
复制代码
翻译物品
  1. localeManager.sendMessage(p, "I make "
  2.         + ChatColor.GREEN + "<item>" + ChatColor.RESET
  3.         +" look good", Material.DIRT, (short) 0, null);
复制代码
使用英语Enligsh (US),这会显示为



但如果玩家使用 Espa?ol (México), 这会显示为



如果你想要显示为 Podzod 而不是 Dirt，在 Minecraft 1.13+，你可以这样做:
  1. if (localeManager.isBelow113()) {
  2.     localeManager.sendMessage(p, "I make <item> look good", Material.DIRT, (short) 1, null);
  3. } else {
  4.     localeManager.sendMessage(p, "I make <item> look good", Material.PODZOL, (short) 0, null);
  5. }
复制代码
请注意数值 '1' 代表旧版本的Minecraft.

对于附魔物品, 你可以这样:

  1. Map<Enchantment, Integer> ench = new LinkedHashMap<Enchantment, Integer>();
  2.         ench.put(Enchantment.IMPALING, 5);
  3.         localeManager.sendMessage(p, "A <item> with <enchantment> V", Material.DIAMOND_SWORD, (short) 0, ench);

发送消息"Enchant Silk Touch I and Luck III"

  3.         enchs.put(Enchantment.LUCK, 3);
  4.         localeManager.sendMessage(p, "Enchant <enchantment> I and <enchantment> III", enchs);
