1、在plugin.yml里添加代码

在plugin.yml里添加：
  1. commands:
  2.   主命令名:           #不加斜杠
  3.     description: Error
  4.     usage: /主命令名         #有斜杠
复制代码

填完之后像这样：（注意主命令名不需要带斜杠）
  1. name: MySpigotPlugin
  2. main: com.abc.MySpigotPlugin
  3. version: 1.1
  4. commands:
  5.    command:
  6.      description: 这是一个命令
  7.      usage: /command
复制代码



2、在主类里写代码

我们再看到主类：
添加这样一段方法：（这里以命令/test为例子）
  1. @Override
  2.     public boolean onCommand(CommandSender sender, Command cmd, String label, String[] args){
  3.         if(cmd.getName().equalsIgnoreCase("test")){ //如果输入"/test"则返回true
  4.                 return true;
  5.         }
  6.         // 如果不是test，则返回false，如果你没有添加这个命令，系统就会显示：“没有这个命令”
  7.         return false;
  8.     }
复制代码

重要部分：

3、填写命令执行器：


很简单，加入一句：
  1. sender.sendMessage("你好！");
复制代码

以下是全部的命令：
