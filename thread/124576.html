[基本命令篇]
此篇推荐新手观看，熟悉的玩家就可以跳过
/login [密码] 登录命令，输入你注册的密码，缩写是 /l 另外除了本命令不推荐缩写
/register [密码] 注册命令，部分服务器要求空格后再次输入密码
/spawn 回到出生点
/sethome 在你当前的位置设置家，多次使用会覆盖
/home 回到设置的家
/tpa [玩家ID] 传送至某玩家身边，需要被允许
/tpaccept 允许别人的传送
/back 返回上一个传送点，不论任何方式的传送
/w [玩家ID] [私聊语句] 向任意玩家私聊，不会被其它人看见
/hat 将你手中的物品戴在头上
/me [语句] 以紫色字强调体发送你的话
/warp [地标] 传送至OP建立好的地标
/money 查看你的金币数
/pay [玩家] [金额] 给玩家汇款
/help [页数] 查看某一页的服务器帮助
/helpop [语句] 给所有OP留言
/baltop 查看财富排行

[玩家进阶篇]
本篇推荐有一定联机经验的普通玩家浏览
[private] 经典的锁箱子，这个准确说不是命令，在箱子或门的上一格放置一个木牌，第一行输入这段文字，第二行默认为输入者姓名，三四行输入共享权限的玩家，门一定要在关闭情况下锁，否则…
/co i' /he tool' /him tool 三条命令来自不同插件，但效果相同，输入一次开启查询，再次输入关闭，都是左键一个方块查询一个已放置方块的变更记录，右键则是查询被你放置（右键）的方块位置，输入时不要同时输入三条命令，也不要带上 ' 不同服务器的插件不同，所以都试试吧
/powertool [命令] 绑定任意命令到你当前手上的物品，左键使用/res select size 查看选定区域的方块个数，选取区域：预先定好一个区域，必须是正方体，分别左击、右击两个不共享边的预定选区内的方块
/res create [领地名] 选取区域后创建领地
/res area [add/remove/replace] [领地名] [区域id] 向叫做[领地名]的领地增加(add)、从其中去除(remove)或是替换 (replace) 区域。可与同一领地内的区域重合
/res removeall 把你的所有领地移除
/res subzone [领地名] [子区域名] 在你拥有的一个领地内创建一个子区域，可以使用不同的权限，方便管理

[管理命令篇]
此篇是给服主和OPS看的，包括很多常用管理MOD的命令，由于此篇量较大，所以拆分发布，在服务器里没有OP权限的同学可以止步了…
<World Edit 创世神>
大部分命令需要指定区域，具体过程如选定领地，一般服务器需手持木斧选定区域
//set [物品ID] 在选定区域中填充一种方块，假如该物品不可以放置，物品就会以纸片状掉落，情况不绝对，视版本而定
//copy 复制选区，方块的材质、朝向以及红石电路都会保留，牌子锁也是哦，但是画除外
//paste 粘贴选区，朝向不变而且你和建筑物相对的位置不变
//replace [物品ID] [新物品ID] 替换
//wall [物品ID] 墙？围墙？选区变成围墙？
//undo 撤消上次的WE命令，命令本身不受影响
//redo 还原上次撤消造成的效果
//move [距离] 向你正对的方向移动选定区块
//move [距离] down 向上移动选区
//move [距离] up 向下移动选区
/xp [玩家ID] [经验值] 给予玩家经验值
/bind [键位] [命令] [命令参数] 将一个命令绑定到一个按键上，以后按下绑定的按键即可执行命令
/unbind [键位] 把按键上的绑定命令解除
/cannon [射程] 向前发射一个TNT，射程不解释
/dropstore 在你附近生成一个箱子并把你背包内的物品全部装入
/jump 跳跃到准心所指的方块上，绑定到快捷键上很实用
/kill 貌似和Ess重叠了，这个是自杀，带上某人ID那就是谋杀了…
/killnpc 谋杀附近的生物，可以根据类型进行区分 如all monster animol
/reach [深度] 钻探挖掘机…
/tele [XYZ坐标] 坐标传送
