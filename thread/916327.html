★》指令/权限/变量《★

常规命令
  • /mmocore - 插件主命令
  • /mmocore reload - 重载插件
  • /player 或 /p - 打开个人信息界面
  • /class (玩家名) - 打开职业选择界面
  • /waypoints - 打开传送点界面
  • /deposit (玩家名) - 打开存款界面
  • /withdraw - 取款
  • /party - 组队命令
  • /friends - 好友命令
  • /skills - 打开技能界面
  • /quests - 打开任务界面
  • /guilds - 打开公会界面
经济命令
  • /mmocore note <玩家名> <钱数> - 给予指定玩家指定钱数的纸币
  • /mmocore coins <玩家名> <钱数> - 给予指定玩家指定数量的金币
传送点命令
  • /mmocore waypoints unlock <传送点ID> <玩家名> - 解锁指定玩家的传送点
  • /mmocore waypoints open <玩家名> - 给指定玩家打开传送点GUI界面
管理员命令
  • /mmocore admin class <玩家名> <职业> - 设置指定玩家的职业
  • /mmocore admin exp <玩家名> <副职业/主经验> <数量> - 给予玩家指定副职业或者主等级经验值
  • /mmocore admin level <玩家名> <副职业/主等级> <数量> - 设置玩家指定副职业或主等级
  • /mmocore admin class-points <玩家名> <数量> - 给予指定玩家职业点数
  • /mmocore admin skill-points <玩家名> <数量> - 给予指定玩家技能点数
  • /mmocore admin reset <玩家名> - 重置指定玩家的职业、等级、经验值
  • /mmocore admin nocd <玩家名> - 管理员测试技能时使用,可无视冷却和法力消耗
  • /mmocore admin info <玩家名> - 查看指定在线玩家的数据
经验加成命令
  • /mmocore booster create <副职业名/主等级> <加成强度> <持续时间> (玩家名)
  • /mmocore booster list - 显示正在生效的经验加成效果
  • /mmocore booster remove <uuid> - 删除指定ID的经验加成


  • mmocore.admin - 可使用管理员命令
  • mmocore.waypoints - 可使用/waypoints命令
  • mmocore.currency - 可使用 /deposit 和 /withdraw 命令
  • mmocore.class-select - 可使用 /class 命令


  • %mmocore_combat% - 判断玩家是否处于战斗状态
  • %mmocore_attribute_<属性类型>% - 玩家某属性的数值
  • %mmocore_<health/mana/stamina/stellium>% - 玩家当前的基础数值
  • %mmocore_max_health% - 玩家的最大生命值
  • %mmocore_stat_<职业属性类型>% - 显示玩家某职业属性的数值
  • %mmocore_skill_points% - 玩家技能点数
  • %mmocore_class_points% - 玩家职业点数
  • %mmocore_attribute_points% - 玩家属性点数
  • %mmocore_attribute_reallocation_points% - 玩家剩余的属性重置点数
  • %mmocore_level% - 玩家等级
  • %mmocore_level_percent% - 玩家当前等级经验占的百分比
  • %mmocore_experience% - 玩家当前经验值
  • %mmocore_next_level% - 升到下一级所需要的经验
  • %mmocore_profession_<副职业ID>% - 玩家副职业等级
  • %mmocore_profession_percent_<副职业ID>% - 玩家当前某副职业等级经验占的百分比
  • %mmocore_class% - 玩家职业名
  • %mmocore_quest% - 正在进行中的任务
  • %mmocore_quest_progress% - 当前任务进度,如果为0则是没有任务
  • %mmocore_quest_objective% - 正在进行中的任务的目标
  • %mmocore_guild_name% - 公会名称
  • %mmocore_guild_tag% - 公会标签
  • %mmocore_guild_leader% - 公会会长名称
  • %mmocore_guild_members% - 公会成员数
  • %mmocore_guild_online_members% - 公会在线成员数
