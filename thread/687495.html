CommandBlocker
自定义信息的命令禁止
功能
·禁止指定命令的使用,防止玩家使用
·自定义禁止指令后玩家输入指令显示的信息
·可用权限控制是否可用指令
·不同世界的支持
安装
1.[下载安装]下载插件本体后放入服务器plugins文件夹后重启即可
命令
/cb reload - 重载配置文件
/cb add - 添加一个指令禁止
/cb remove - 删除一个指令禁止
权限
cb.add - 添加指令的权限
cb.remove - 删除指令的权限
cb.reload - 重载配置的权限
配置

  1. # ---------------------------------------- #
  2. # +--------------------------------------+
  3. # |           Command Blocker!           |
  4. # | Blocks players from seeing commands! |
  5. # |            (c): TreyRuffy            |
  6. # +--------------------------------------+
  7. # ---------------------------------------- #

  9. # -------------------------------------------------------------------------------- #
  10. # +------------------------------------------------------------------------------+
  11. # | Add blocked commands and set permissions in:                                 |
  12. # | disabled.yml                                                                 |
  13. # |                                                                              |
  14. # | Main permissions are:                                                        |
  15. # | cb.add    -> /cb add                                                         |
  16. # | cb.remove -> /cb remove                                                      |
  17. # | cb.reload -> /cb reload                                                      |
  18. # +------------------------------------------------------------------------------+
  19. # -------------------------------------------------------------------------------- #

  21. Default:
  22.     # This is the default message to show.
  23.     Message: '&cSorry, the owner has disabled that command.' #默认输出信息
  24.     # This is the default permission. Placeholders are %command% -> Command sent.
  25.     ## %command% does not include any colons ##
  26.     Permission: cb.allow.%command% #默认权限
  27. Messages:
  28.     # This message will be sent to players without permission to do /cb
  29.     NoPermission: '&cYou do not have the required permissions to execute this command.' #默认无权限信息
复制代码
禁止命令文件

  1. DisabledCommands:
  2.     Help: #需要禁止的指令
  3.         Message: '&cSorry, I can''t help you with this. :/' #玩家无权限输入该指令显示的信息
  4.         Permission: cb.allow.help #拥有此权限的玩家无视禁止
