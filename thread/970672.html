以编辑掉落物的附魔为例，现有一个附魔钻石剑掉落物，其nbt如下
{Item:{id:"minnecraft:diamond_sword",Count:1b,tag:{Enchantments:[{id:"minecraft:shapness",lvl:5s},{id:"minecraft:unbreaking",lvl:3s}]}}}
即拥有锋利5和耐久3附魔
现在只将锋利附魔的等级修改为10级，命令是
/data modify entity @e[type=item,limit=1,nbt={Item:{id:"minnecraft:diamond_sword"}}] Item.tag.Enchantments[0].lvl set value 10s
