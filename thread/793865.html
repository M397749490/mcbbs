sounds.json里面这样写
  1. {
  2.   "music.game.creative": {
  3.     "category": "music",
  4.     "replace": "true",
  5.     "sounds": [
  6.       {
  7.         "name": "custom/null",
  8.         "volume": "1.0",
  9.         "weight": "1",
  10.         "stream": true
  11.       }
  12.     ]
  13.   },
  14.   "custom.s1": {
  15.     "category": "music",
  16.     "replace": "false",
  17.     "sounds": [
  18.       {
  19.         "name": "custom/ctm_s1",
  20.         "volume": "1.0",
  21.         "weight": "1",
  22.         "stream": true
  23.       }
  24.     ]
  25.   }
  26. }
复制代码
然后...在资源包\assets\minecraft\sounds\custom下放入null.ogg和ctm_s1.ogg
null.ogg须为一个无声音的音频...
而ctm_s1.ogg则为你自定义的音频

最后，游戏内用命令播放自定义音频ctm_s1
  1. /playsound custom.s1 @p
复制代码


=============后来想了下，不一定要修改music.game.creative的ogg，只要把这个播放事件的volume值改为0
应该也可以...你可以去试一下
就像这样
  1. {
  2.   "music.game.creative": {
  3.     "category": "music",
  4.     "replace": "true",
  5.     "sounds": [
  6.       {
  7.         "name": "music/game/hal1",
  8.         "volume": "0.0",

  11.     ]
  12.   },
  13.   "custom.s1": {
  14.     "category": "music",
  15.     "replace": "false",
  16.     "sounds": [
  17.       {
  18.         "name": "custom/ctm_s1",
  19.         "volume": "1.0",
  20.         "stream": true
  21.       }
  22.     ]
  23.   }
  24. }
复制代码
之后放入ctm_s1.ogg就好
