问题出在编码, 不要使用 latin1 转而使用支持中文的 utf8mb4
请用 root 用户进入 mysql 命令模式, 然后一行一行地输入下面的指令来切换编码:

use mcmmo数据库名称;
alter table mcmmo数据表名称 convert to character set utf8mb4 collate utf8mb4_general_ci;

或者对于 phpmyadmin 的用户你可以直接点击你的 mcmmo 数据库, 进去之后点击查询选项卡输入上面第二个指令即可。
