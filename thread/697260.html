HyEssentials - 小桂基础前置
- 简介 -
这是一个基础的, 想要达到全方面的API
理论上支持全版本!
- 功能详细介绍 -
Logger (包含Debug)
这个Logger是一个很简单使用的Logger.
使用它只需要首先Import这个类
然后新建一个Logger对象
  1. <b>Logger logger = new Logger("插件名", true)
  2. //字符串是你想让log里显示的插件名
  3. //布尔值表示是否Debug</b>
复制代码
然后直接<对象名>.log(<要发送的字符串>)
或者<对象名>.Debug([变量], <要发送的字符串>)
就可以了! 是不是很方便使用!
例子:
  1. Logger logger = new Logger("HyEssentials", true);
  2. logger.log("Test");
  3. logger.Debug("TestDebug");
  4. logger.Debug(new ArrayList<String>(), "TestDebugObj");
