首先我为玩家添加了能储存金币数量的能力系统。然后想在打开玩家背包栏的时候在界面上绘制一段文字显示玩家的金币。我的实现思路是这样子的：@SideOnly(Side.CLIENT)
@SubscribeEvent
public static void onRenderGuiScreen(GuiOpenEvent event)
{
    if(event.getGui() instanceof GuiInventory)

        Minecraft.getMinecraft().fontRenderer.drawString("当前金币:",0,0,0xFFFFFFFF);
    }
}首先我在客户端监听玩家打开背包的事件，if里面前两句代码是我截断了游戏自带的背包界面然后自己重绘了一个，可以别管它。然后第三句我向服务器发送了一个new GetMoneyRequest()，这个GetMoneyRequest的实现代码是这样子的：
public class GetMoneyRequest implements IMessage
{
    public GetMoneyRequest(){}
    @Override
    public void fromBytes(ByteBuf buf)
    {
    }
    @Override
    public void toBytes(ByteBuf buf)
    {
    }
}
它是空的，因为我只是用来提醒服务器要返回玩家金币，所以发送了一个空包。
之后便是服务器处理这个包的类：
public class ServerMessageHandler implements IMessageHandler<GetMoneyRequest,MoneyInfo>
{
    @Override
    public MoneyInfo onMessage(GetMoneyRequest message, MessageContext ctx)
    {
        EntityPlayerMP player=ctx.getServerHandler().player;
        IMoneyStorage capability=player.getCapability(CapabilitiesLoader.moneyStorage,null);
        return new MoneyInfo(capability.getCoin(),capability.getTicket());
    }
}
代码很简单，前两句是为了获取服务端玩家的金钱储存能力系统
然后第三句利用能力系统里面getCoin(),getTicket()两个接口返回的数据（分别代表金币，点券）new一个新的Message然后Return给客户端
这里的MoneyInfo具体实现是这样的（因为图片数量受限我就直接发文字代码了）：
public class MoneyInfo implements IMessage
{
    public MoneyInfo(){}
    public int coin;
    public int ticket;
    public MoneyInfo(int coin, int ticket)
    {
        this.coin=coin;
        this.ticket=ticket;
    }
    @Override
    public void fromBytes(ByteBuf buf)
    {
        buf.writeInt(coin);
        buf.writeInt(ticket);
    }

    @Override
    public void toBytes(ByteBuf buf)
    {
        coin=buf.readInt();
        ticket=buf.readInt();
    }
}

这个类也很简单，就是存了金币和点券的数据
之后我在客户端又写了一个处理这个返回的数据包的类，具体的实现是这样的：
public class ClientMessageHandler implements IMessageHandler<MoneyInfo, IMessage>
{
    public ClientMessageHandler(){}
    @Override
    public IMessage onMessage(MoneyInfo message, MessageContext ctx)
    {
        int coin=message.coin;
        int ticket=message.ticket;
        Minecraft.getMinecraft().addScheduledTask(()->{
            EntityPlayerSP player= Minecraft.getMinecraft().player;
            IMoneyStorage capability=player.getCapability(CapabilitiesLoader.moneyStorage,null);
            capability.setCoin(coin);
            capability.setTicket(ticket);});
        return null;
    }
}
也很简单，就是先获取客户端玩家的能力系统，然后把返回过来的数据利用能力系统setCoin()和setTicket()两个接口填写到能力系统里面。
最后就是回到这里：

因为刚才已经把数据加载到本地了，所以if里面第四第五句代码就是把本地能力系统里面的数据绘制到游戏界面上。最后就是我注册SimpleNetworkWrapper的代码：
public class SimpleNetworkWrapperLoader
{
    int ID=0;
    public static final SimpleNetworkWrapper simpleNetworkWrapper = NetworkRegistry.INSTANCE.newSimpleChannel(FantasyValley.MODID);
    public SimpleNetworkWrapperLoader()
    {
        simpleNetworkWrapper.registerMessage(ClientMessageHandler.class, MoneyInfo.class,ID++, Side.CLIENT);
        simpleNetworkWrapper.registerMessage(ServerMessageHandler.class,GetMoneyRequest.class,ID++,Side.SERVER);
    }
}以上就是我的实现思路，但是我进入游戏后打开背包后游戏就崩溃了，然后弹出那个背景是泥土的画面，上面写着这么一句话（因为图片上传数量受限，就直接码字了）：
