根据LZ私聊的要求，先用
  1. scoreboard objectives add 目标名称 stat.useItem.minecraft.wooden_shovel
复制代码
创造一个目标，再用
  1. scoreboard players set 玩家名称 目标名称 0
复制代码
之后再用高频
  1. testfor @p[score_目标名称_min=1]
复制代码
比较器连接tp指令（我想这个你应该会233）或者
  1. effect @a blindness 20 1 true
复制代码
（20是20秒，1是等级）即可。也可以在testfor后再连接一个比较器,里面指令为上述的players即可。

  1. scoreboard objectives add 1 dummy
复制代码
（名称可以LZ自己改）创造一个目标，再用
  1. scoreboard players set 假玩家名称 1 0

以及
  1. scoreboard players set 玩家名称 1 0
复制代码

再高频
  1. scoreboard players operation 玩家名称 1 = 假玩家名称 1
复制代码
即可。效果:当假玩家名称加了一分，真玩家也会变成一分
