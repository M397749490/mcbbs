-=RegWeilcomes=-
关于插件 | About Plugins
作者: Xlv
搬运: LingXin233
作者原话
plugin for different messages when player moves between regions.
JukeBox >> 使玩家进入某区域播放歌曲的前置

如有BUG请在
置顶楼层
以回复形式反馈！



特点 | Feature

  • 进入设置的区域可以自动播放 标题/声音/歌曲
  • 离开设置的区域可以自动播放 标题/声音/歌曲
  • 全自定义配置
  • 轻量级插件



指令&权限 | Cmd And Permissions


重载配置 >> /rw reload

重载权限 >> regwelcomes.reload




截图 | Screenshots

使用方法 | Instructions
1.首先,你需要会使用WorldGuard<如果不会也没关系我来教QWQ>
2.WorldGuard和WorlDedit是一个作者 所以都用小木斧选择区域
3.选择完区域后,输入/rg define <区域名> 即可创建WG区域
4.最后,去Regdate.yml配置消息即可~
