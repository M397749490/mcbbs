√ 插件简介 √
DreamShop是一款新型的商店插件，他可以实现很多GUI商店没有实现的功能，如商品限购，商品冷却，随机商品等，是腐竹们更新服务器商店和提升服务器逼格的不二选择！



√ 主要功能 √
商店：
自定义商店名称
自定义商店行数
自定义打开权限
自定义商品

商品：
自定义打开权限
自定义商品显示材质
自定义消费方式（点卷和金币，可同时消费）
自定义商品名字
自定义商品显示数量
自定义数量限购
自定义玩家限购数量
自定义购买冷却
自定义随机指令发送
自定义随机指令几率
自定义玩家折扣
自定义收购
自定义物品兑换

其他：（指令类）
自定义指令跳转多个指令
自定义指令跳转商店
自定义指令跳转商店中的商品（可以联合VV原版制作VV原版商店）

其他：（PAPI变量）
自定义PAPI变量名
自定义PAPI变量内容（支持检测商品冷却时间，限购次数等）

以及更多的让玩家方便操作的功能
下次更新（列举）：
自定义支付方式选择
自定义商品限时停售

√ 插件命令 √
/ds open [玩家名] [商店文件名]      打开该GUI菜单（文件名不要.yml后缀！）
/ds reload            重载配置文件
/dsDIY [自定义命令]         执行你自定义命令的操作

√ 配置文件 √
DIYCmd.yml
  1. #是否开启自定义二级命令的功能
  2. Switch: true
  3. #你要注册的命令列表
  4. CmdList:
  5.   - menu
  6.   
  7. #命令设置
  8. Setting:
  9.   #必须和CmdList里面的一样
  10.   menu:
  11.     #是否开启指令跳转
  12.     TiaozhuanSwitch: true
  13.     #要跳转的指令（以控制台的形式）
  14.     tiaozhuan:
  15.       - m %player% 指令跳转成功！
  16.     #是否开启指令打开商店
  17.     ShopSwitch: true
  18.     #打开的商店名字
  19.     ShopName: "example"
  20.     #是否开启商品跳转
  21.     ItemSwitch: false
  22.     #商品属于的商店
  23.     ItemShop: "example"
  24.     #商品在该商店中的格数
  25.     ItemNumber: 1

  21.   items2:

复制代码



example.yml
  1. #商店名字
  2. Name: '&a&l梦の商城'
  3. #商店的行数，一行九个商品
  4. Size: 3
  5. #打开商店需要的权限
  6. Permission: DShop.example
  7. #点击菜单周围的空白处是否关闭菜单
  8. GUIclose: true
  9. #你要创建的商品格数，如第一格就写1
  10. Items:
  11. - 1
  12. - 2
  13. ItemInfo:
  14.   #在ItemInfo里面写在Items里面注册好了的格数的数字
  15.   #如Items里面你写了1，那么就照如下填写
  16.   '1':
  17.     #点击了商品之后是否关闭菜单
  18.     close: true
  19.     #购买商品是否需要权限
  20.     Permission: Item1.Buy
  21.     #商品材质
  22.     ID: 276
  23.     #商品附加值，如黄色羊毛是35:4，则ID填写35，附加值填4，若没有附加值则写0
  24.     More: 0
  25.     #显示的数量
  26.     Num: 1
  27.     #购买需要花费的金钱
  28.     Money: 1000
  29.     #购买需要花费的点卷
  30.     #Money和Points可同时消费
  31.     Points: 100
复制代码
1.2版本后example有更多内容

在1.3版本后，Lore和执行的命令中支持的变量：
%player%获取玩家名

%Finishing% 获取商品剩余数量

%PlayerCishu% 获取玩家还剩余的数量

%Time% 获取购买冷却时间

%UUID% 获取玩家UUID

%World% 获取玩家所在世界名称

%Level% 获取玩家等级




√ PAPI变量 √
%DreamShop_[自定义PAPI后缀]%   可自定义检测商品数量，商品冷却时间等等
