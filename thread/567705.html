用强制饥饿插件
Hunger Keeper —— 强制饥饿。让生存充满困难[1.6.4-1.2.5]
http://www.mcbbs.net/thread-186160-1-13.html

什么是强制饥饿？
我来简单的介绍一下：

在游戏里很多玩家会因为饱食度不够而死亡。
而在他们重生后，他们饱食度有重新满了。

这个插件的作用就是当你食物不够时，
你不能因为死亡而重新填满饱食度.
所以在重生后饱食度是不满的，你必须自己来寻找食物.

特点：
无命令
可以适合与多个世界

安装：
安装到服务器的plugins文件夹
重新服务器。
安装完成

Config：

Per-World-Hunger: true 是否开启强制饥饿
Per-World-Hunger-in:    对于任意世界的设置强制饥饿开启或关闭.
  world: true
  world_nether: true
  world_the_end: true
