矿物生成进阶教程

其实有个更好的方法,以一个Chunk的基岩层到地面层为范围进行随机,如果随机到的位置是石块,就将其替换为你要的矿物,这样可以保证绝对没问题而且非常Easy!

以上这句话出自szszss的基础教程（5）。其实World类有一个getBlockID方法，他可以获得方块的ID。以下为新的生成矿物的方法
  1. public void generateSurface(World world, Random random, int chunkX, int chunkZ)
  2. {
  3. for(int i = 0; i < 20; i++)
  4. {
  5. int randPosX = chunkX + random.nextInt(16);
  6. int randPosY = random.nextInt(128);
  7. int randPosZ = chunkZ + random.nextInt(16);
  8. int check = world.getBlockId(randPosX, randPosY, randPosZ);

  10. if (check == Block.stone.blockID)
  11. {
  12.     world.setBlock(randPosX, randPosY, randPosZ, mod_Block.OreTi.blockID);
  13. }

  15. }

  17. }
复制代码
             check变量检测要替换的方块ID。下边的If函数的意思是当check检测到的ID是石头的ID的时候就替换成钛矿（这是我的mod里的新矿物{:10_535:}）。这样做就避免了矿物浮空与在超平坦模式中生成大量矿物的bug出现。

复制代码

  1. /**
  2.      * The level of material this tool can harvest (3 = DIAMOND, 2 = IRON, 1 = STONE, 0 = IRON/GOLD)

复制代码
getHarvestLevel=3=钻石稿，getHarvestLevel=2=铁镐，getHarvestLevel=1=石镐，getHarvestLevel=0=石镐和木稿（注释应该错了）
我们只需要添加一个if函数
