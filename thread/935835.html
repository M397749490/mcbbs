前言：我转载这个插件，是因为ColorMotd需要的前置不知道怎么在我的服务器用不了，我在bukkit搜到了这个插件，于是就把它转载了过来以前有人把这个插件转载了过来，但是他们都不更新了，现在最新版本已经更新到了1.14，其实1.15也支持...



介绍:这是一个轻量级的Motd插件，可以实现自定义Motd,自定义玩家加入的消息



权限：motd.*     所有权限（包括以下权限）
              motd.check 允许在游戏里查看MOTD
              motd.set   允许在游戏里设置MOTD
              motd.reload 允许重新加载配置文件
              motd.reset 允许重置配置文件
              motd.showmsg 允许在游戏里查看玩家加入或退出时说的话
              motd.setshowmsg 允许在游戏里设置玩家加入或退出时说的话
              motd.enableshowmsg 允许开启/关闭是否在玩家加入或退出时说话


命令： /motd 查看当前的MOTD
               /setingamemotd 修改当前的MOTD
               /rmotd 重新加载配置
               /resetmotd 重置配置文件
               /showmsg 查看玩家加入或退出时说的信息
               /setshowmsg 设置玩家加入或退出时说的信息
               /enableshowmsg 开启/关闭是否在玩家加入或退出时的信息

config.yml:
  1. # Variables for ingame-text: %name%,%world-name%,%players%,%gamemode%,%ip-address%,%item-in-hand% !
  2. # Variables for system-motds: Special characters like: hearts,check,star,bar,arrow,pencil: http://dev.bukkit.org/bukkit-plugins/ingamemotd/pages/special-characters/
  3. # If random: true, the system-motds will be shown randomly !
  4. # If joinANDquitMSG: true, the "JoinMSG" & "QuitMSG" will work, if "false" will not work.
  5. # Here are the 2 of the MOTDS, ingame and system !
  6. InGameMotdActive: true
  7. SystemMotdActive: true
  8. motd:
  9. ingame-text: '&9Welcome to the -newline-&4server&f! '
  10. system-motds:
  11. - '&5DEFAULT&f-&cMOTD -newline-&9EXAMPLE:&21'
  12. - '&5DEFAULT&f-&cMOTD -newline-&9EXAMPLE:&22'
  13. - '&5DEFAULT&f-&cMOTD -newline-&9EXAMPLE:&23'
  14. - '&5DEFAULT&f-&cMOTD -newline-&9EXAMPLE:&24'
  15. - '&5DEFAULT&f-&cMOTD -newline-&9EXAMPLE:&25'
  16. random: false
  17. messages:
  18. Prefix: '&e[&2&lMOTD&e]&f '
  19. NoPermission: '&4You dont have permission to do this!'
  20. SpecifyMessage: '&7Please specify a message!'
  21. ReloadConfig: '&bConfig has been reloaded!'
  22. ConfigReset: '&bConfig has been reset!'
  23. IngameSET: '&dIN-GAME MOTD set to: '
  24. joinANDquitMSG: false
  25. JoinMSG: '&e-name- has joined the game.'
  26. QuitMSG: '&e-name- has quit the game.'
  27. Version: 1
