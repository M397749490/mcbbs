LZ，我也有一样的问题，我想问一下这一段是什么意思？


用任意一款文本编辑器（但不建议用记事本实在不行的话，用写字板打开也行！）编辑的build.gradle你会看到两部分：
  1. <pre class="brush: plain; title: ; notranslate" title="" style="color: rgb(0, 0, 0); background-color: rgb(230, 230, 231);">buildscript {
  2.     repositories {
  3.         jcenter()
  4.         maven {
  5.             name = "forge"
  6.             url = "http://files.minecraftforge.net/maven"
  7.         }
  8.     }
  9.     dependencies {
  10.         classpath 'net.minecraftforge.gradle:ForgeGradle:2.0-SNAPSHOT'
  11.     }
  12. }
  13. apply plugin: 'net.minecraftforge.gradle.forge'
  14. </pre><pre class="brush: plain; title: ; notranslate" title="" style="color: rgb(0, 0, 0); background-color: rgb(230, 230, 231);">plugins {
  15.     id "net.minecraftforge.gradle.forge" version "2.0.1"
  16. }</pre>
复制代码

根据你使用的版本，其中一部分是被注释掉的，而另一部分则没有。无论你现在看到的是什么样，你需要确保第一部分（也就是很长的那一段）没有注释，然而删掉/注释掉第二部分（只有3行的那段），说白了，就是留下长的，删掉短的，确保长的没有注释。
