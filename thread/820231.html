插件用途

众所周知 Minecraft中的叶子如果不通过其他叶子连接到原木上，就会慢慢开始腐烂。游戏中的树叶实际上是龟速腐烂啦XD。

这就是FASTLYFASH这个插件出现的原因。只要树叶与附近的原木互相分开，在保证是自然生成的树叶的情况下，

插件就会开始工作，让树叶瞬间腐烂。





腐竹们不需要添加任何权限或修改配置，插件本身就提供了配置，请参见后文

  • 树干切断后叶子会迅速腐烂。
  • 本身就会自然腐烂的叶子（例如用we球形笔刷 刷普通的树叶球体）也会快速腐烂。
  • 自然生成的树叶仍然会掉落树苗和苹果，几率不受影响，只是加速时间。
  • 玩家放置的叶子（带有永久的NBT）将不受插件影响。
  • 腐竹可以在配置中设置启用/禁止树叶快速腐烂的世界。
  • 可以在树叶腐烂时播放声音和动画，玩家可能可以获得更好的体验。可以在配置里面设置/关闭。
  • （不会翻了 嘻嘻）开发者：这个插件在采取行动之前调用LeavesDecayEvent并尊重其取消状态。










兼容性

FastLeafDecay插件 使用了 Spigot's 中最新的 BlockData 和 Tag 框架，因此仅适用于Spigot 1.13或更高版本

作者正在制作兼容1.8-1.13的版本


本帖可以当作是前瞻版下载





配置

FastLeafDecay的大多数功能都能在config.yml里配置。要应用您做出的修改，重启启动服务器或手动重新加载插件（疯狂暗示yum）。

要恢复到插件最初状态，请删除config，下次加载插件时将自动创建一个新config。





config.yml汉化文件

# 将该栏留空=在全部世界启用 填入世界名=只在你输入的世界里启用 快速腐烂
OnlyInWorlds: []
# 在该栏填入世界名=在你输入的世界中禁用 快速腐烂
ExcludeWorlds: []
# 在多少秒后使树叶腐烂.
# 该栏至少需要填入5以上的数字来使插件正常工作.
BreakDelay: 5
# 在多少秒后检测可被 快速腐烂 选中的叶子.
DecayDelay: 2
# 播放效果（粒子+声音）
SpawnParticles: true
PlaySound: true
