  1. "enchantment: extinction" {
  2.     I:"Enchantment ID for Extinction"=149
  3.     B:"Should the Extinction Enchantment be available?"=true
  4.     B:"Should this effect be available in vanilla?"=false
  5. }
复制代码

将true改为false就可以了。
