标题: 地皮插件花钱购买地皮
因plotme插件 关于金钱设置项太多 机翻又不准确 = =本人又不太懂英文  所以来请教一下 plotme插件的设置里哪个是调整领取地皮花费金钱的。
作者: Raymond_Min    时间: 2015-5-25 17:17
服务器的地皮插件的配置文件里的config.yml里的

UseEconomy: false
是否使用经济
      CanPutOnSale: false
是否可以出售地皮
      CanSellToBank: false（推荐禁止，不然玩家可以领取了地皮就卖来刷钱！）
是否可以卖给服务器
      RefundClaimPriceOnReset: false
不知道什么意思
      RefundClaimPriceOnSetOwner: false
领取地皮是否要钱
      ClaimPrice: 0.0
领取地皮需要的钱
      ClearPrice: 0.0
清理需要的钱（就是/p clear指令）
      AddPlayerPrice: 0.0
给权限需要的钱（/p add 指令）
      DenyPlayerPrice: 0.0
禁止玩家进入需要的钱（/p deny 指令）
      RemovePlayerPrice: 0.0
删除权限需要的钱（/p remove 指令）
      UndenyPlayerPrice: 0.0
/p undeny 指令需要的钱
      PlotHomePrice: 0.0
/p h 指令需要的钱
