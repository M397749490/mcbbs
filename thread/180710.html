GeneralHave you ever sat in front of a modded client and marvelled at its variety? Sadly, that comes at a price: Everyone needs to have the same mods installed before they can join a server. This plugin attempts to bring a bit of that variety into bukkit-servers by creatively using the available options to create authentic machines.ConfigurationClick me!FeaturesMachines
  • Each machine has its own graphical Interface
  • It is created through first placing a basic machine block (default: Emerald), and right-clicking on it with an activation Item (default: BlazeRod)
  • You then have to craft a special Machine-Item in a designated crafting-screen, which afterwards can be inserted in the Basic Machine Block.
  • The BMB will automatically turn into the machine that you chose it to be
  • Every machine will support custom upgrades which allow you to trade resources for speed (Planned)
Electricity
  • Machines do support electricity.
  • They need to be connected through cable-blocks(default: Not yet chosen) to a power-storage-unit.
Customisation
  • Almost everything in the plugin is fully configurable, such as crafting recipes, machine types, ...
  • Multilang
Community Involvement
  • Everyone is able to create his own Machines and share them with the community.
  • Each machine is a JAR-File which simply has to be placed into a special folder in order to be activated
Integrated MacinesWhat this obviously cannot do for youThere is no way to acutally add any new blocks or items to the game without mods. Also, machines will look like normal blocks because texturepacks cannot be dynamically changed either.Permissions
PermissionFunction
machines.createCan a player place Machines?
machines.craftingmenuCan a player open the craftingmenu in order to assemble machine-parts?
machines.create.MachinenameCan a player place a machine of the type Machinename
machines.ignoreCreateRestrictionsCan a player place any machine?
