标题: 【高悬赏】两个命令方块指令问题


（提问版本均为1.12版本）





1、怎样使水和岩浆放置后无法流动？

2、怎样测试多个玩家的物品栏里是否有铁锭，并将其ID和铁锭数量显示在右侧记分板里？


作者: gouj511    时间: 2017-12-29 12:34
1、直接放一个静止的水就不会流动了2333
  1. /setblock ~ ~ ~ minecraft:water
复制代码

同理，熔岩
  1. /setblock ~ ~ ~ minecraft:lava
复制代码


2、先设置一个变量来记录铁块数
  1. /scoreboard objectives add iron_ingot_count dummy 铁块数量
复制代码

让变量在侧边栏显示
  1. /scoreboard objectives setdisplay sidebar iron_ingot_count
复制代码

然后像这样放置三个命令方块
第一个（从左往右）
  1. /scoreboard players add @a iron_ingot_count 0
复制代码

第二个
  1. /stats entity @a set AffectedItems @a[c=1] iron_ingot_count
复制代码

第三个
  1. /execute @a ~ ~ ~ clear @a[c=1] iron_ingot 0 0
复制代码
作者: pca006132    时间: 2017-12-29 13:58
1. 直接setblock/fill/clone etc.。但确保旁边方块不会出现方块更新的情况。（所以游戏里就没办法放置大量水方块而保持不流动，因为那会造成方块更新。需要使用第三方软件修改）。
2. 使用clear和stats。
stats entity @a set SuccesCount @s iron
execute @a ~ ~ ~ clear @s minecraft:iron_ingot 0 0
