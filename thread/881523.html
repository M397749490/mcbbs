本插件可以给您的物品增加使用期限
若当前时间超过使用期限,物品会被自动删除!

特点:
插件信息全部可自定义
物品拥有破坏音效[可在配置文件关闭]
多项事件监测,玩家穿戴拥有时间限制的盔甲
被攻击时到期同样移除!

指令&权限
插件默认所有指令只有管理员能执行
权限节点: timeditems.admin
/ti reload 重新载入配置文件
手持物品输入/ti set 数字 时间单位 即可设置使用时长
s : 秒 m: 分钟 h: 小时 d : 天
例如/ti set 1 d 设置物品使用时长为一天
物品会在使用时开始计数

注意!本插件会忽视创造模式的玩家,测试本插件功能请切换生存模式!

物品被玩家使用时会自动设定到期时间
物品到期再使用则会移除
指令/ti set 时间也可重新设置物品的使用期限


配置文件

  1. DateFormat:
  2.   expires_at: "&7&l[&c&l到期时间&7&l]&c&l "
  3.   useful_life: "&7&l[&a&l使用时长&7&l]&c&l "
  4.   s: " &a&l秒"
  5.   m: " &a&l分"
  6.   h: " &a&l小时"
  7.   d: " &a&l天"
  8. Settings:
  9.   #是否在点击物品时开始运算到期时间
  10.   #设置为false 将只会在物品左键/右键时开始运算,盔甲将会在被攻击后运算
  11.   start_date_calculate_on_click: true
  12.   #是否开启物品到期破坏音效
  13.   Sounds: true
  14. Messages:
  15.   prefix: "&7[&b物品期限&7] &r"
  16.   expire: "&c你的物品到期了!"
  17.   config_reload: "&a配置文件已经重新载入!"
  18.   invalid_usage: "&c错误的指令用法! /ti set [数字] [日期格式] s:秒 m:分钟 h:小时 d:天"
  19.   time_set: "&a设置物品使用时长成功!"
  20.   no_item: "&c你手里没东西啊!"
