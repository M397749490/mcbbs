二. 配置文件

Config:
  Chat: true
  Title: true
  Message: true
Chat:
  Format: "%Health%&c&l%Love%"
Title:
  Killed:
    Title: "&c&l你击倒了玩家 &a%player%"
    SubTitle: "&e最后一击&f：&e%Damage%&c&l%Love%"
  Normal:  
    Title: "&e%Damage%&c&l%Love%"
    SubTitle: "&e玩家 &a%player% &c血量&l：&e%Health%&f/&c%MaxHealth%&c&l%Love%"
Message:
  Message:
    - "&6&L&m======================================"
    - "              &c&l你造成了&6%Damage%&c&l伤害"
    - "&e玩家 &a%player% &c血量&l：&e%Health%&f/&c%MaxHealth%&c&l%Love%"
    - "&6&L&m======================================"
  Reload: "%prefix% &c&l插件重载成功~~"






三. 插件命令&变量
ShowHealth -- ShowHealth.admin
重置插件用
[sh,sr]
附属指令
变量
Title和Message通用变量
%Health%
显示被攻击的玩家血量
%player%
显示被攻击的玩家名字
%Damage%
显示你攻击玩家的伤害
%MaxHealth%
显示被攻击玩家的最大血量
%Love%
显示?的图标

ChatFormat的变量
%Health%
显示被攻击的玩家血量
%MaxHealth%
显示玩家的最大血量
%Love%
显示?的图标
