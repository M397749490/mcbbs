FancyWorld is a growing plugin to allow you to modify almost anything in your world! Currently with the plugin you can change the biome (auto updating biome), weather, gamerules, time, and generate void worlds.

插件作用：修改生物系、天气、游戏规则、时间、创建空世界




功能特色
自动更新配置文件
全面布局和容易使用命令
易于使用的库存编辑天气，时间，和游戏规则
  • 权限简单
  • 高效的代码Commands 指令
/fancyw edit - 修改天气 游戏规则 时间 (ess自带 并没什么用)
/fancyw biome - 查看生物系
/fancyw biomes - 列出所有生物系
/fancyw setbiome <b生物系> [范围] - 在一个范围内设置生物系.默认范围: 32
/fancyw gc - 腾出内存空间
/fancyw brush <biome> <size> - NEW biome brush to easily modify and make biomes look nice
利用 'VoidGen' 创建一个空的世界  (没试过，看不懂)   

Permissions 权限
- fancy.world.command.biome -使用 /fancyw biome
- fancy.world.command.biomes - 使用 /fancyw biomes
- fancy.world.command.setbiome - 使用/fancyw setbiome
- fancy.world.command.setbiome.radius - 使用/fancyw setbiome with radius
- fancy.world.command.edit - 使用 /fancyw edit
- fancy.world.command.gc - 使用 /fancyw gc
- fancy.world.command.brush - 使用 /fancyw brush
- fancy.world.items.brush - 使用 brushes
