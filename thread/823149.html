作者: TRCRedstoner    时间: 2018-10-8 22:30
和banitem插件无关，最有可能的事情就是你在装完banitem插件后想重启服务器，结果这个时候多世界插件储存出了问题，导致整个worlds.yml文件清空，解决方法可以删掉mv的文件夹然后重新生成，再用/mv import 普通世界名字 normal来导入，记得地皮世界、地狱、末地就要和用mv生成世界的格式一样导入，仅仅是mv create改为mv import
作者: cixuefeimang    时间: 2018-10-11 11:52
世界未加载，从mvlist看得出在mv配置中这些世界是存在的
首先检查一下你的worlds文件夹看这些世界是否在还
如果在，进游戏后输入  mv load xxx(世界名）
如果不在，删掉mv配置文件中的worlds.yml   然后进游戏有重新生成世界
