需要配合启动bat使用

配置文件
  1. Enable: true #是否开启自动重启功能
  2. Times:
  3.    - "11:0:0" #时间点 不需要写两个0
  4.    - "22:12:30"
  5.    - "23:26:0"
  6. reloadMessage: "服务器即将重启: %time%" #重启时提示语句 %time% 代表当前剩余重启时间
  7. reloadStartMessage: "服务器将在30秒后重新启动" #倒计时开始前提示语句
复制代码

启动bat
  1. @echo off
  2. :start
  3. java -jar nukkit-1.0-SNAPSHOT.jar
  4. goto start
