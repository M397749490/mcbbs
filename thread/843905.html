PokeTeams
此款插件可以让玩家创建完全可定制的团队,可以邀请你的朋友一起加入。每个级别都可在配置文件中完全自定义
玩家可以设置和使用基地,使用随机排队系统与其他团队战斗,在私人团队聊天频道中聊天,并记录有关的战斗，野生精灵战斗，精灵抓捕等等信息。

指令&权限&作用
一般指令权限(主权限poketeams.command.base) 作用
/teams create (team) poketeams.command.create 创建一个战队
/teams delete poketeams.command.delete 删除一个战队
/teams info poketeams.command.info 查看信息
/teams invite (player) poketeams.command.invite 邀请玩家
/teams kick (player) poketeams.command.kick 踢出玩家
/teams chatpoketeams.command.chat进入聊天模式
/teams chat <message> 上同
/teams base poketeams.command.bases回战队基地
/teams tag (list)poketeams.command.tag列出标签
/teams listpoketeams.command.list列出战队
/teams queue poketeams.command.queue.base列出队列信息
/teams adminpoketeams.command.admin.base管理员模式

队列命令权限(主权限poketeams.command.queue.base) 作用
/teams queue join poketeams.command.queue.join 加入队列
/teams queue leave poketeams.command.queue.leave离开队列
/teams queue list poketeams.command.queue.list所有队列

银行命令权限(主权限poketeams.command.bank.base) 作用
/teams bank bal poketeams.command.bank.add战队银行
/teams bank add poketeams.command.bank.balance添加金钱

管理员命令(主权限poketeams.command.admin.base) 作用
/teams admin delete (team) poketeams.command.queue.join强制删除战队
/teams admin kick (team) (player) poketeams.command.queue.leave强制踢出战队玩家
/teams admin rename (team) poketeams.command.queue.list强制修改战队名字
/teams admin tag (team) (tag)poketeams.command.admin.tag强制修改战队标签
/teams admin reset (team)poketeams.command.admin.reset强制重置战队
/teams admin set (player) (team)poketeams.command.admin.set 强制设置玩家战队

%teamname%  -  玩家战队的名称
%teamtag% - 战队的自定义标签
%teamwins% - 战队的胜利次数
%teamlosses% - 战队的损失金额
%teamratio% - 战队的赢/输比率
%teamkills% - 战队击杀的精灵的数量
%teamcaught% - 战队捕获的野生精灵的数量
%teamcaughtlegend% - 捕获的精灵数
%teambal% - 玩家的当前余额
