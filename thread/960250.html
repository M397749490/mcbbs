教程
首先，你需要安装一个浏览器插件：TamperMonkey
之后，打开这个页面，安装由大佬 @xmdhs 开发的备注脚本


进入管理面板，找到备注脚本的编辑按钮，点击


我们将脚本原来的代码魔改一下，成为下面这样：
  1. (function() {
  2.     var setid = ["1970274",
  3.                  "3038",
  4.                  "2704361"
  5.                 ];
  6.     var note = ["Mr_Fang",
  7.                 "管理员",
  8.                  "高度警戒"
  9.                ];
  10.     var names = document.getElementsByClassName("avtm");
  11.     for(var a=0; a<names.length; a++) {
  12.        for(var n=0; n<setid.length; n++) {
  13.         if (names[a].href == location.origin+"/home.php?mod=space&uid="+setid[n])
  14.          {
  15.             names[a].innerHTML += '<div style="margin:5px; background-color:#FFFFFF; border-width:2px; border-color:#D0D0D0; border-style:solid; font-size:12pt; font-weight:bold; text-align:center; color:#242424">'+note[n]+'</div>';
  16.          }
  17.        }
  18.     }
  19. }
  20. )();
复制代码

修改div标签的style属性即可修改备注样式
margin：外边距
background-color：背景颜色border-width：边框厚度
border-color：边框颜色
border-style：边框样式
font-size：文字大小
font-weight：文字粗细
text-align：文字对齐方式
color：文字颜色

想要一个脚本显示多种标签样式？
没问题，将这段代码多粘贴几段即可
