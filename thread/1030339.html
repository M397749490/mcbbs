自定义铁砧配方
Custom Anvil Recipe


本插件所用所有代码均为原创,不存在借用/抄袭等行为。

介绍
允许用户自定义原版中不存在的铁砧配方。NBT数据保留。


指令
  1. /anvil          --打开插件菜单
  2. /anvil menu     --打开插件菜单
  3. /anvil create   --打开配方创建界面
  4. /anvil list     --打开配方列表
  5. /anvil help     --显示插件指令提示信息
  6. /anvil ?        --显示插件指令提示信息
复制代码



使用方法





插件规则
1. 材料与成品三项皆不可缺省


2. 不同的配方，材料不可重复


3. 材料的左右顺序交换后视为不同配方


4. 自定义配方将覆盖原版配方


5. Beta2.0新增 调整配方所需要的经验等级（同时按住shift键可一次调整5级）


6. Release1.0新增 删除配方
