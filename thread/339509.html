服务器server.properties文件修改（原帖stool版主的服务端核心文件帖）：
大家在服务端找到server.properties，打开这个文本
level-name [ 服务器地图的名称]
allow-nether [ 开启地狱世界 true为开启，false关闭]
view-distance [ 可视距离]
spawn-monsters [ 刷怪物 true为开启，false关闭]
online-mode [ 只有在线玩家可以进游戏 true为开启，false关闭]
gamemode [ 游戏模式 0=生存、1=创造]
spawn-animals [ 刷动物 true为开启，false关闭]
difficulty [ 难度等级 0=和平、1=简单、2=中等、3=困难]
server-name [ 服务器名字]
pvp [ 玩家伤害玩家 true为开启，false关闭]
server-ip [ 服务器IP地址]
max-players [ 最大玩家数]
level-seed[生成地图的时候使用的种子]
server-port [ 服务器端口，默认25565]
allow-flight [ 允许玩家飞行]
white-list [ 白名单]

关于服务端出现找不到指定路径原因：此端默认java路径为"%ProgramFiles%\Java\jre6\bin\java.exe
即java6路径，因此导致java7用户无法使用此端。修改方法①：
用txt格式打开服务端内bat启动器，找到"%ProgramFiles%\Java\jre6\bin\java.exe"
把jre6改为jre7，修改之后启动bat即可


修改方法②：
或许是你在安装java的时候修改了它的默认路径，使服务端无法连接到你的java路径。最简单方法，重新安装java，不要修改它的默认路径，按此端默认设置来看，最好安装java6，安装java7的话请看修改方法①。


对此骷髅表示抱歉。
服务端将在下次更新中添加java7的bat。
