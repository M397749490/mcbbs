1.0版本指令与之前的有所变化

左侧为指令，右侧为权限


/realmap create file <地图名（随意）> <文件名> 》》》 realmap.create.file
从本地图片创建，需要把图片文件放在config/realmap/images这个文件夹下面
示例：/realmap create file test test.png


/realmap create url <地图名（随意）> <URL> 》》》 realmap.create.url
示例：/realmap create url https://test/test.png


/realmap give <player> <name> 》》》 realmap.give
示例：/realmap give Eric12324 test


/realmap del <name> 》》》 realmap.del
示例：/realmap del test
