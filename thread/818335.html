求指令QwQ

tp ~ ~ ~ ~ ~
前三个是 x y z 坐标
第四个是 y 旋转角度，正北方为-180.0，正东为-90.0，正南为0.0，正西为90.0
第五个是 x 旋转角度，竖直上方为-90.0，至竖直下方90.0

具体可以看 wiki：https://minecraft-zh.gamepedia.com/命令#tp

完了完了，没看到你标题写着1.12.2...不过思路差不多都是这样的，只是格式要改一改

干嘛那么纠结...强制TP药水云不就行了？格式如下
（注：XXX为计分板名称，600，601等数字均为单位，一秒对应20个单位，紫色的备注表示循环命令方块，绿色的备注表示连锁命令方块）

总体结构分为俩层，先说下层：
1:tp @e[scores={XXX=0}] X Y Z 0 0
让XXX为0的所有实体TP到X Y Z 0 0（通常用来固定视角）

2:scoreboard players add @e[scores={XXX=0..601}] XXX 1
让XXX为0到601的所有实体持续上升1个单位

3:execute as @a at @s run tp @e[scores={XXX=1..200}] ~ ~ ~0.05 ~ ~
让XXX为1到200的所有实体持续向上TP~ ~ ~0.05 ~ ~

4:execute as @a at @s run tp @e[scores={XXX=201..400}] ~-0.05 ~0.05 ~0.05 ~0.2 ~
让XXX为201到400的所有实体持续TP~-0.05 ~0.05 ~0.05 ~0.2 ~

5:execute as @a at @s run tp @e[scores={XXX=401..600}] ~-0.05 ~ ~0.05 ~ ~
让XXX为401到600的所有实体持续TP~-0.05 ~ ~0.05 ~ ~

6:execute as @a at @s run tp @a[scores={XXX=601}] X Y Z
让XXX为601的所有玩家TP到终点位置（通常用来精确最后TP位置）

然后是上层：
1:scoreboard players set @a[scores={XXX=602}] XXX -1
将XXX为602的所有玩家分数设置为-1

2:gamemode spectator @a[scores={XXX=0}]
将XXX为0的玩家设置为观察者模式

3:gamemode creative @a[scores={XXX=601}]
将XXX为601的玩家设置为冒险模式

4:tp @a[scores={XXX=0..600}] @e[type=minecraft:area_effect_cloud,scores={XXX=0..600},limit=1]
将XXX为0-600的所有玩家持续TP到XXX为0-600的药水云上

5:execute at @p[scores={XXX=0}] run summon minecraft:area_effect_cloud ~ ~ ~ {Duration:602,Tags:["cam"]}
在XXX为0的玩家基础上召唤一个时间为602，Tags为cam的药水云

6:scoreboard players add @e[type=minecraft:area_effect_cloud,tag=cam] XXX 0
持续让tag为cam的药水云的XXX上升0个单位（通常用来给予刚刚刷出来的药水云添加积分）
