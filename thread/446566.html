EasyKitsRel

2015-5-17 22:21 上传

时隔几年，重回旧坑，原版EasyKits，BUG多的一批。
很多坛友向我反馈，我也使用的难受，特此发布此版本。
理论spigot全版本，如有某版本报错，请反馈报错完整记录和服务端类型加版本

  • 一.指令

  1. /kit [礼包名称] - 领取一个礼包
  2. /kit create [礼包名称] - 创建一个礼包(当前背包的物品)
  3. /kit remove [礼包名称] - 删除一个礼包
  4. /kit price [礼包名称] [价格] - 设置领取这个礼包的价格（前置Vault）
  5. /kit view [礼包名称] - 展示一个礼包
  6. /kit cooldown [礼包名称] [时间]- 设置礼包领取时间的间隔例如：1s/1m/1h/1d
  7. /kit limit [礼包名称] [次数]- 设置礼包每个玩家最高领取次数
  8. /kit reset cooldown [礼包名称] [玩家]- 重置玩家的领取冷却时间
  9. /kit reset limit [礼包名称] [玩家]- 重置玩家的最大领取次数
  10. /kit give [玩家] [礼包名称] - 给予玩家一个指定礼包
  11. /kit book - 给所有有权限的人一本书，查看可领取的礼包
  12. /kit list - 列出礼包的列表
  13. /kit reload - 重载配置文件
复制代码


  • 二.权限
EasyKits.* - 全部权限
EasyKits.cmd.* - 指令全部权限
EasyKits.kits.* - 允许领取所有礼包[会受到最大次数，价钱，冷却的限制]
EasyKits.kits.[kitname] - 允许领取某个礼包[会受到最大次数，价钱，冷却的限制]
EasyKits.cmd.reload - 略
EasyKits.cmd.create - 略
EasyKits.cmd.remove - 略
EasyKits.cmd.cooldown - 略
EasyKits.cmd.limit - 略
EasyKits.cmd.price - 略
EasyKits.cmd.give - 略
EasyKits.cmd.list - 略
EasyKits.cmd.view - 略
EasyKits.cmd.help - 略
EasyKits.cmd.reset - 略
EasyKits.bypass.cooldown - 不受冷却限制
EasyKits.bypass.limit - 不受最大领取次数限制
EasyKits.bypass.price - 不受价格限制
EasyKits.sign.create - 创建礼包牌子
EasyKits.sign.remove - 允许删除牌子
EasyKits.sign.use - 允许使用牌子

Default-Cooldown: 0 默认冷却  
Default-Kit-Limit: 0 默认最大领取次数
Default-Price: 0 默认价格
New-Player-Kit: xs 新人礼包名称 玩家第一次服务器直接放入玩家背包  Sign-Action: view 玩家点击牌子后的效果 分为obtain和view分别是 领取和查看 默认为查看

  • 六.老版本怎么更换为新版本
关闭服务器，删除EasyKits插件，放入EasyKitsRel，更改原文件夹名为EasyKitsRel，删除文件夹内config.yml，开服即可
