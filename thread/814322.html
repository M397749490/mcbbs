使用教程




如何安装？

  1、确保服务器安装了前置插件BedwarsRel 1.3.6, ProtocolLib, Citizens
  2、将下载的插件(Jar文件)放入服务器目录下的plugins文件夹内
  3、重启(启动)服务器


乱码怎么办？

  1、安装软件Notepad++
  2、右键服务器目录下'plugins/BedwarsScoreBoardAddon/'内config.yml或teamshop.yml
  3、选择使用Notepad++打开
  4、在Notepad++内点击上方"编码"按键，选择编码格式
  5、指令'/bwsba reload'重载插件




设置商店

  1、进入游戏地图区域
  2、站在要设置商店的位置
  3、执行指令'/bwsba shop set <item/team> <游戏>'
      '<item/team>'代表商店类型，item为物品商店，team为队伍商店
      '<游戏>'代表游戏名称
      示例:
           创建"吃豆豆"的物品商店'/bwsba shop set item 吃豆豆'
           创建"吃豆豆"的队伍商店'/bwsba shop set team 吃豆豆'
  4、游戏开始后，将在你设置时所站的位置生成一个商店NPC




移除商店

  1、指令'/bwsba shop list <游戏>'查看已设置的商店列表



  2、指令'/bwsba shop remove <ID>'移除一个商店
       '<ID>'为已设置的商店列表种所示ID


实现"永久的护甲"


  自动穿装备:

       商店文件 'BedwarsRel/shop.yml' 内给物品添加特殊Lore"§a§r§m§o§r§0§0§1"
            "§a§r§m§o§r§0§0§1"为锁链护甲
            "§a§r§m§o§r§0§0§2"为铁护甲
            "§a§r§m§o§r§0§0§3"为钻石护甲




  禁止脱下装备:

      1、打开服务器目录下'plugins/BedwarsScoreBoardAddon/config.yml'配置文件
      2、将 'giveitem.armor.helmet.move'
              'giveitem.armor.chestplate.move'
              'giveitem.armor.leggings.move'
              'giveitem.armor.boots.move'
           设置为false




  死亡后保存原有装备:

      1、打开服务器目录下'plugins/BedwarsScoreBoardAddon/config.yml'配置文件
      2、将 'giveitem.keeparmor' 设为true




木剑替换

  商店文件 'BedwarsRel/shop.yml' 内给物品添加特殊Lore"§s§w§o§r§d"
