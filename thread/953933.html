标题: [1.13+]使用命令行快捷安装新版Forge
本帖最后由 gooding300 于 2020-2-7 13:02 编辑

简介
许多启动器都实现了Forge的自动安装，然而Forge在1.13修改了安装方法，使得原有的安装方法彻底失效，且新的安装方法相对而言难以实现，部分启动器放慢了这一功能的支持。
那么有什么在启动器中方便快捷加入安装Forge功能的方法呢？答案是有的，我制作了一个简单的“补丁”使得Forge安装器可以直接在命令行中执行，甚至可以输出进度让启动器来显示。
使用方式
普通安装
  1. java -cp "forge-installer-headless.jar;forge-installer.jar" me.xfl03.HeadlessInstaller -installClient 路径
复制代码

以使用“forge-installer-headless-1.0.1.jar”将“forge-1.15.2-31.1.0”安装到“%appdata%/.minecraft”为例：
  1. java -cp "forge-installer-headless-1.0.1.jar;forge-1.15.2-31.1.0-installer.jar" me.xfl03.HeadlessInstaller -installClient %appdata%/.minecraft
复制代码

进度显示
在普通安装的基础上再加上“-progress”参数即可在命令行中只显示进度。
以使用“forge-installer-headless-1.0.1”将“forge-1.15.2-31.1.0”安装到“%appdata%/.minecraft”并显示进度为例：
  1. java -cp "forge-installer-headless-1.0.1.jar;forge-1.15.2-31.1.0-installer.jar" me.xfl03.HeadlessInstaller -installClient %appdata%/.minecraft -progress
复制代码

进度显示有三种类型，“STAGE”指的是目前安装器到达的阶段，“START”指的是目前安装器正在执行的工作，“数字”指的是正在执行的工作的进度。
注意事项
1.安装前请检测Java是否存在，尽量使用用户指定的Java执行安装器
2.仅用于1.13以上的版本，不支持老版本安装方法
