圈地的大小限制怎么该，还有这个-545128448是什么情况
作者: 972299721    时间: 2019-1-29 16:45
-545128448 是超过了圈地的最大限制
一般这个限制我都懒得去调 （我记得好像是100*100*100）
以玩家的角度来看这都足够大了（如果是我记错了你就要去res插件贴内下的教程改了 他那里写的很清楚）

如果你想以OP的身份圈地 那就要resadmin OP专用圈地
举个例子 res create 1 是创建一个名字为1的领地
那么你就要resadmin create 1 以OP的身份圈地 以此类推 OP的都要在res后加admin
OP身份圈地无视任何限制 如金钱和距离

如有帮助请采纳
作者: Abraham511    时间: 2019-1-29 17:15
圈地的大小限制怎么该

  1.                 # 玩家可以拥有的领地数量最大值
  2.                 MaxResidences: 3
  3.                 # 领地可包含的最大物理区域
  4.                 MaxAreasPerResidence: 2
  5.                 # 领地最大格数（东西方向）
  6.                 MaxEastWest: 16
  7.                 # 领地最小格数（东西方向）
  8.                 MinEastWest: 3
  9.                 # 领地最大格数（南北方向）
  10.                 MaxNorthSouth: 16
  11.                 # 领地最小格数（南北方向）
  12.                 MinNorthSouth: 3
  13.                 # 领地最大格数（高度）
  14.                 MaxUpDown: 256
  15.                 # 领地最小格数（高度）
  16.                 MinUpDown: 3
复制代码
