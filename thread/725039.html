function小教程前言

1.12的function的功能算是比较强大，而且比Command Block(命令方块，以下简称CB)要方便很多，有很多人自从1.12更新之后就再也没用过CB(比如我)，因为function系统在大体上可以代替CB(虽然Mojang说function只是用来补充CB而不是代替CB的)，利用function可以做出一些CB难以实现的东西，比如数以百计甚至千计的大量穷举，在1gt内重复执行某条命令x次(x为未知数)等。


但是论坛各版里的帖子标题出现function的字样，就可能会出现0查看惨案，已经不是0评分或0回复了，是0查看!也就是说很多人只要看见funtion字样，连点都不想点进来。出现这种情况，可能是因为大家对function认知程度很低，而且觉得是个很麻烦的东西，而实际上只要你知道命令是什么，function就是个很容易学会怎么使用的东西，目前我还没有发现适合萌新的function教程，所以我写了这个function从入门到入土精通来提高萌新对function的认知程度。
function是什么
wiki:函数（Function）是一个允许玩家利用扩展名为.mcfunction的文本文档编写和运行多行命令的功能。
这句话的意思:简单来说，就是创建一个xxx.mcfunction文件，然后在游戏里可以调用这个文件执行命令。
function本是为了方便玩家完成进度后对玩家执行多条命令用的，结果变成了一个在游戏外即可编辑的CB。
function的基本用法
mcfunction文件需要用UTF-8无BOM格式编码（我也不知道什么是UTF-8无BOM，反正就是一种格式），所以最好不要使用记事本之类的附件编辑，如果使用记事本，可能会导致mc无法识别这个文件而出错。建议使用Notepad++来编辑mcfunction文件，所以在使用function之前先下载安装一个Notepad++，直接百度Notepad++即可，安装好之后记住它的目录位置。
字符编码，你保存的时候文本编码要保证是UTF-8，且文本文件不能有BOM（notepad.exe是做不到的，不光每次都会给你默认ANSI你要记得每次调，还无法控制地会加入 UTF-8 BOM头导致游戏无法识别），故而需要有更好的文本编辑器来调整文件保存时的选项。当然如果你自己保证不使用ASCII以外的字符且从空文件开始写作，notepad.exe应该是可以用的（此时它会认为你需要保存ASCII文本然后就一切安好了）。当然还是强烈推荐使用更好的文本编辑器。

来自30楼Xtricman的补充

打开1.12的mc随意创建一个地图，然后打开.minecraft\saves\创建的地图的名字\data\functions，这里就是放function的地方。但是不能直接在这里创建mcfunction文件，因为mcfunction文件必须储存在.minecraft\saves\创建的地图的名字\data\functions\另一个文件夹下，所以必须在functions内先创建一个文件夹，名字任意。


我创建的地图名字叫"测试图"，我在functions下创建的文件夹是"test"，在"test"这个文件夹内新建一个记事本，命名并把".txt"后缀改成".mcfunction"，这里我把这个文件命名为"abc.mcfunction"，所以我这个文件的位置应该是这样的.minecraft\saves\测试图\data\functions\test\abc.mcfunction。


创建完文件之后，就需要之前的Notepad++了，右键这个abc.mcfunction打开方式-->选择程序-->浏览-->找到notepad++.exe设置为默认打开方式，之后就可以打开abc.mcfunction开始编辑了，编辑的方法很简单，一行一条命令，一行的最前面加上#的话就说明这行是注释，注释是不会执行的，比如我在abc.mcfunction里这样写:
  1. say 1
  2. #say 2
  3. #这什么都不是

  5. say 4
  6. say 3
复制代码
在游戏里输入/function test:abc就会在聊天框里显示:

[玩家] 1
[玩家] 4
[玩家] 3

以上例子的意思就是function会按顺序执行里面的指令，前面加上#的命令不会执行，空行会被无视。

总结一下:在地图的functions文件夹下新建文件夹x，在文件夹x下新建记事本命名y并把后缀改成.mcfunction，然后在y.mcfunction内一行一条命令（可以加#注释），在游戏里输入/function x:y即可依次执行该地图下data/functions内的x文件夹里的y.mcfunction内的每条命令。

为了方便使用高频的function，添加了gameLoopFunction这个gamerule，比如输入/gamerule gameLoopFunction x:y后游戏就会每gt一次执行一次y.mcfunction，但是与循环型CB执行的时间不同，比如CB可以检测HurtTime:10s而function只能检测HurtTime:9s。注意:一个地图内只允许同时在gameLoopFunction内设置一个function来高频，所以在大型的模块中，可以先创建一个main\main.mcfunction作为主模块，各个分支模块需要高频执行的部分可以通过main\main.mcfunction调用，main里面的命令为执行其他的function，只需要高频main:main，就可以实现同时高频执行多个function。另外，gameLoopFunction执行命令所在的位置为（0,0,0）

在地图正在运行的时候修改了其中的function，需要重进该地图或者直接输入/reload来重新载入函数列表。

如果你再functions内建了一个文件夹x，x文件夹里又建了一个文件夹y，在y文件夹内建z.mcfunction，输入/function x:y/z即可执行z.mcfunction.
function实现制约模式
命令方块是可以直接使用条件制约模式的，但是function不能直接与游戏互动。比如你想function中的say 1执行成功后执行say 2，自然是不能用比较器什么的了，function想要与游戏内交互，大多需要execute实体来执行，所以可以利用stats和execute来代替制约模式。大概就需要这样写:
  1. #召唤一个用来执行命令的实体
  2. summon area_effect_cloud ~ ~ ~ {Tags:["cond"]}
  3. #添加一个虚拟变量记分板
  4. scoreboard objectives add cond dummy
  5. #将实体的分数初始化（即设置为0）
  6. scoreboard players add @e[tag=cond] cond 0
  7. #将实体的执行命令成功次数统计到记分板的分数上
  8. stats entity @e[tag=cond] set SuccessCount @e[tag=cond] cond
  9. #此时让这个实体say 1
  10. execute @e[tag=cond] ~ ~ ~ say 1
  11. #say 1成功则输出2
  12. execute @e[score_cond_min=1] ~ ~ ~ say 2
  13. #清除实体并还原系统
  14. kill @e[tag=cond]
复制代码
function的递归
递归即自己调用自己，比如在a\b.mcfunction里写function a:b和say 1就会在1gt内执行无数次say 1，因为function受到/gamerulemax CommandChainLength的限制，只会执行32767次（默认情况下），但是一般情况下mc都会扛不住而崩溃，所以一定要加上一定的条件，即可实现1gt内执行不定量条命令，比如

执行function a:b
a\b.mcfunction
  1. #召唤tag为if的实体
  2. summon area_effect_cloud ~ ~ ~ {Tags:["if"]}
  3. #添加一个虚拟变量记分板
  4. scoreboard objectives add if dummy
  5. #执行a:c
  6. function a:c
复制代码
a\c.mcfunction
  1. #给实体在记分板if增加一分
  2. scoreboard players add @e[tag=if] if 1
  3. #如果实体在记分板分数是4分及以下，就再执行一次，否则不执行，也就是会执行五次say 1
  4. function a:c if @e[score_if=4]
复制代码
给实体初始分数设置为不同的值就可以执行不同次数，另外如果在funtion a:c if @e[score_if=4] 下面再写say 2，像这样

a\b.mcfunction
  1. summon area_effect_cloud ~ ~ ~ {Tags:["if"]}
  2. scoreboard objectives add if dummy
  3. function a:c
复制代码

a\c.mcfunction
  1. say 1
  2. scoreboard players add @e[tag=if] if 1
  3. function a:c if @e[score_if=4]
  4. say 2
复制代码

执行a:b就会输出5个1和5个2，为什么呢，fuction内执行的function会立即在下一条命令执行前执行，不论多少命令，所以，执行顺序看起来就是这样的:
say1
-say 1
--say 1
---say 1
----say 1
----say 2
---say 2
--say 2
-say 2
say 2

say前面减号(-)数相同，就代表的同一个function里的命令，不仅是递归，任何funtion中执行的function里的命令都会在下条命令之前执行。
