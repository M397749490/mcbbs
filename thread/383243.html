能做什么：

利用它你可以不用在客户端安装mod即可播放指定的音乐，让您的服务器更加独特

如何安装：

1.下载NoteBlockAPI：http://dev.bukkit.org/bukkit-plugins/noteblockapi/

2.安装NoteBlockAPI

3.下载MusicPlayer

4.安装

5.去这里下载.nbs格式的音乐并放到plugins/MusicPlayer/songs/

命令和权限：

Player Commands:
  • /play <SongName/SongID>
  • /stopsong
  • /listsongs
Admin Commands:
  • /musicplayer reloadsongs
  • /musicplayer listsongs
  • /musicplayer disablemusic
  • /musicplayer enablemusic
  • /musicplayer stopall
  • /musicplayer playingsongs
  • /musicplayer playall <SongName/SongID>
Permissions
  • music.reloadsongs: default: op
  • music.listsongs: default: op
  • music.disablemusic: default: op
  • music.enablemusic: default: op
  • music.stopall: default: op
  • music.playall: default: op
  • music.play: default: op
  • music.listsongs: default: op
  • music.adminhelp: default: op
  • music.userhelp: default: op
  • music.playingsongs: default: op
  • music.playall: default: op
