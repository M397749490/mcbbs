作者: MineCommander    时间: 2020-2-28 01:14
tick标签和复读循环型命令方块的运行频率都是20/s，所以你可以利用这个特性来做计时器。
大致思路就是给一个计分板timer里的工具人#tick不断加分，当#tick的timer分数为20时说明已经过了1秒，就给目标计分板+1并复位。这里假设目标计分板是#sec的timer。
start.mcfunction（初始化）
  1. scoreboard objectives add timer dummy
复制代码

timer.mcfunction（高频循环执行）
  1. scoreboard players add #tick timer 1
  2. #打点计时
  3. execute if score #tick timer matches 20 run scoreboard players add #sec timer 1
  4. #给目标计分板+1
  5. execute if score #tick timer matches 20 run scoreboard players set #tick timer 0
  6. #复位
复制代码

它的原理和高中物理的打点计时器差不多，以一定频率打点（这里是计分），根据点的数量（分值）确定时间。但是他有一个缺点，那就是TPS过低（也就是游戏负载过高太卡）时间会变得不稳定。
