搜索327
  1.   # 10 = lava :: 11 = still lava :: 46 = TNT :: 327 = lava bucket
  2.   alert:
  3.     on-placement: 10,11,46,327
  4.     on-use: 327
  5.     on-break:

  7.   blacklist:

  9.     # Which blocks should people be prevented from placing?
  10.     placement: 10,11,46,327

  12.     # Which items should people be prevented from using?
  13.     usage: 327

  15.     # Which blocks should people be prevented from breaking?
  16.     break:

  18.     # Which blocks should not be pushed by pistons?
  19.     piston:

  21.     # Which blocks should not be dispensed by dispensers
  22.     dispenser:
复制代码
然后把placement 和 usage里的327删掉即可
