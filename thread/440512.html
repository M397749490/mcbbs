CoreProtect = 查破坏纪录(查不到盗箱纪录) Essentials = 服务器基本插件 EssentialsSpawn = 服务器设置重生点、出生点 GlobalMarket = 全球市场，使玩家可以公平的进行买卖、交易 GroupManager = 权限组设置，设置玩家可以干嘛或不能干嘛。 MYthicMobs = 自定义怪物属性插件 NoCheatPlugin = 防外挂飞行、快挖。  PluginMan = 当服务器开着时可以马上禁止这个插件或重新载人 RandomLocation = 随机传送插件 Residence = 领地插件(玩家可以用指定物品自行设置及购买) Vault = 很多关于钱的插件等前置插件 WorldEdit = 世界编辑器，可以设置你这边药方多少方块，那边要什么方块，复制或贴上或转向或剪下(必须使用小木斧进行编辑) WorldGuard = 世界保护，可以设置只有op可以破坏的保护区。
