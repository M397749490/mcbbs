作者原话
This is my first free plugin, I am still learning but I want to try bring as much fun to the Minecraft community by adding fun plugins that change base game mechanics. I originally made this as a Skript, however I am deciding to convert this over to Java and make it as customisation as possible for server owners to make it unique to their server!
Do you agree that fishing is boring? Then this is the plugin for you!

作者第一个免费插件


特点

自定义鱼 （配置文件自定义）
配置文件方便添加自定义鱼
5种不同类型的自定义鱼（不同类型不同价格）
钓鱼菜单（指令：/fishing menu）
任务奖励规则，分别是铜，银和金
一个容易使用的鱼贩卖店，玩家可以把鱼卖给贩卖店！（不同鱼价格可以配置）
亮点》》不同生物群系可以钓不同鱼（可配置）
日常任务（可配置奖励）
