Land 圈地系统
插件交流群: 点我加入插件交流群
GitHub开源: https://github.com/SmallasWater/Land
当前插件版本: v1.5.7



功能:
  - 自定义圈地提示
  - 自定义玩家领地上限
  - 自定义禁止圈地世界
  - 自定义购买领地价格
  - 领地成员独立权限
  - 立体领地
  - GUI 操作
  - 领地套娃?(主领地内可设置数个子领地(配置可更改))
  - 领地粒子区域显示
  - 领地出售
  - 领地赠送
  - 领地寄售
  - 自定义经济核心
  - 领地GUI查找
  - 使用工具圈地

领地权限:
   - 禁止破坏
   - 禁止放置
   - 禁止传送
   - 禁止进入
   - 禁止丢弃物品
   - 禁止使用箱子 熔炉
   - 禁止PVP
   - 禁止伤害生物
   - 使用桶
   - 使用打火石
   - 创建子领地
   - 使用展示框


使用方法:
  安装前置 经济核心
  插件指令: /la help
    ① 玩家输指令/la pos <1/2> 确定两点
    ② 玩家手持圈地工具(默认木锄) 点击方块进行圈地

之后执行 /la create 名称 即可创建领地 (领地范围为长方体)

管理员(OP)指令:

/lad money 金钱  强制设置脚底领地出售金钱
/lad del  强制删除脚底领地
/lad reload  重新读取配置文件

配置文件:
config.yml

  1. ---
  2. # 标题

  4. title: "[领地系统]"

  6. #圈地工具
  7. landTool: "290:0"

  9. # 圈地时每个方块的价格
  10. landMoney: 10.0

  12. # 子领地每个方块价格
  13. subLandMoney: 5.0

  15. # 出售领地时 减少的价格百分比
  16. # 这里的 50 是减少原价格的 50%
  17. sellMoney: 50

  19. # 黑名单世界
  20. # 在此名单的世界无法圈地 OP 除外
  21. # 示例: blackList: ["世界1","世界2"]
  22. blackList: ["世界1","世界2"]

  24. # 保护世界
  25. # 在此名单的世界无法破坏放置 需要圈地
  26. # 示例: protectList: ["世界1","世界2"]
  27. protectList: ["世界1","世界2"]

  29. # 限制玩家拥有的领地上限
  30. # 注: 只拥有成员权限也计算在内
  31. max: 5

  33. # 限制子领地上限
  34. subMax: 3

  36. # 设置领地显示范围时间
  37. time: 5

  39. #公示期(天)
  40. 售卖领地显示时间: 7

  42. # 加载的经济核心
  43. #当前支持 EconomyAPI,Money,PlayerPoint
  44. # default 为自动识别
  45. loadEconomy: default

  47. ...
