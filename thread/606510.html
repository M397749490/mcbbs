前言：

此插件为本人进行的二搬插件，点我进入原搬运贴

二搬理由：

①原搬运贴和我搬运的其实不是完全相同一个插件，这里搬运的是spigot专用版的

②此插件已支持1.10.2服务端，原帖已长期未更，更了也只是CB版的插件

③虽然是spigot版，但理论支持CB端，只不过是针对spigot编译的，比原搬运贴的兼容性更强

④原搬运贴没有讲解如何更换登录插件【Authme】



介绍：
此插件主要特征是安全
说到轻量，其实指的不是插件大小，而是插件的指令
指令仅仅只有6条！（其中2条是OP的）（插件大只是因为插件的加密系统很强大）
该密码会储存在服务器的配置文件中，只有腐竹才能查看/修改
作者的原话：LoginSecurity is a lightweight password authorization plugin. You can optionally set a password each time you enter the server, adding a double layer of security to your account. The password is stored inside the configuration file, nobody else except the server owner can access or modify it.


楼主已测试的服务端：
paperspigot1.8.8
paperspigot1.9
paperspigot1.10.2
测试结果 均可使用

特征：

  • 注册账号的要求可在配置文件中更改
  • 5个有用的指令来管理你的密码
  • 先进的管理系统
  • 先进的文件放在wiki
  • 5个可选的加密方式：BCrypt, SCrypt, PBKDF2, Whirlpool and SHA3_256
  • 安全的保存用户输入的信息
  • 可自定义登录超时时间
  • 根据登录会进行地图验证
  • 支持从Authme或XAuth中导出密码到LoginSecurity（更换登录插件）
  • 支持自动登录
  • 可以自动更新并保存日志
  • 可过滤掉不合要求的用户名（支持长度和标点符号）
  • 非常详细的配置
  • 自动更新用户的翻译（自动提交）
  • 可以阻止其他人用相同的用户名把你踢下线
  • 聊天栏输入密码登录后若登出了，再次登录无需密码（1分钟内且IP不变）

  • Register your account optional or required (change in config)
  • 5 Useful commands to mangage your password
  • Advanced administrative control
  • Advanced documentation via wiki
  • 5 Secure password algorithms: BCrypt, SCrypt, PBKDF2, Whirlpool and SHA3_256
  • Secure sessions storing to improve user experiance
  • Customizable time-out
  • Map captcha upon registration (user friendly)
  • Conversion from AuthMe and xAuth (check wiki for more info)
  • Premium support through AutoIn
  • Automatic update with changelog overview
  • Username filtering (length and characters)
  • Highly detailed configuration
  • Automatically updated translation manager (user-submitted)
  • Prevents being kicked by orther players loging in with your name
  • Session login allows the user to log in right after they logged out and not have to type in their password again. (1 minute time limit of being logged out, stores IP during that time to keep everything safe)



指令&权限：
玩家指令
指令参数权限用处
/register密码注册账号
/login密码登录账号
/changepass旧密码 新密码更改账号密码
/logout登出
管理员指令
指令参数权限用处
/lac helploginsecurity.admin查看指令帮助
/lac dbimportsource [params]loginsecurity.admin从另一个登录插件导入数据
/lac rmpassplayerloginsecurity.admin删除玩家的密码
/lac updateloginsecurity.admin更新插件

更换登陆插件：
更换登陆插件支持Authme以及XAuth
Authme：
【默认】SQLite:
  • 打开Authme文件夹
  • 找到并复制authme.db文件
  • 粘贴至LoginSecurity文件夹
  • 在控制台或游戏中输入/lac dbimport authme sqlite
  • 等待
  • 转换完成后删除LoginSecurity文件夹内的authme.db文件
  • 完成

MYSQL：
  • 去控制台中输入lac dbimport authme mysql <host> <user> <password> <database>
  • 等待
  • 完成

XAuth：
【默认】SQLite:
  • 打开xauth文件夹
  • 找到并复制xauth.h2.db文件
  • 粘贴至LoginSecurity文件夹
  • 在控制台或游戏中输入/lac dbimport xauth h2
  • 等待
  • 转换完成后删除LoginSecurity文件夹内的xauth.h2.db文件
  • 完成

MYSQL：
  • 去控制台中输入lac dbimport xauth mysql <host> <user> <password> <database>
  • 等待
  • 完成
