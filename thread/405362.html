这是个非常棒的服务器Motd插件!支持双行!支持随机标语!支持多种数据显示!支持彩色!


配置文件:


#使用 %n% 来换行
uniquePlayers: 0
# uniquePlayers: 0 把0改成1来开启
# 功能:能够记录从这个插件被添加并启用的那一刻开始,进入服务器的玩家数量(这个玩家数量不会记录入同一ID的玩家的多次登陆记录)
lastLogin: ''
# 功能:记录最后一个进入服务器的玩家
lastLoginDisplay: ''
# 功能:一个Lastlogin的格式化的版本( 不明,不影响插件使用,希望大神解释  owo )
enableMOTD: true
# enableMOTD: true 把true改成false来关闭
# 功能:开关服务器标语
randomMOTD: true
# randomMOTD: true 把true改成false来关闭
# 功能:使服务器标语变为随机播放的(前提要让 enableMOTD: [这里是true] ) (如果这里是false的话,那会按照第一条→第二条 ... 的顺序播放下去)
MOTD:
# 标语列表:
- '&41%n%233'
# 第一条
- '&42'
# 第二条
- '&b3'
# 第三条
- '&44'
# 第四条
enableLoginMOTD: true
# enableLoginMOTD: true 把true改成false来关闭
# 功能:开关玩家登陆标语
randomLoginMOTD: true
# randomLoginMOTD: true 把true改成false来关闭
# 功能:使服务器标语变为随机播放的(前提要让 enableLoginMOTD: [这里是true] ) (如果这里是false的话,那会按照第一条→第二条 ... 的顺序播放下去)
delayLoginMOTD: 0
# delayLoginMOTD: 0 这里的[0]可以改为任何数字
# 功能:玩家进入服务器后多少秒时才会看到这条标语
loginMOTD:
- '&45'
# 第一条
- '&46'
# 第二条
- '&b7'
# 第三条
- '&48'
# 第四条

命令与权限

命令权限作用
/multimotd无查看所有的插件命令
/multimotd motd无查看所有的服务器标语
/multimotd motd enabledmultimotd.motd.enabled.check查看服务器标语是否开启
/multimotd motd enabled [true/false]multimotd.motd.enabled.change[开/关]服务器标语
/multimotd motd randommultimotd.motd.random.check查看服务器标语是否随机
/multimotd motd random [true/false]multimotd.motd.random.change[开/关]服务器标语随机模式
/multimotd loginmotd无查看所有的玩家登陆标语
/multimotd loginmotd enabledmultimotd.loginmotd.enabled.check查看玩家登陆标语是否开启
/multimotd loginmotd enabled [true/false]multimotd.loginmotd.enabled.change[开/关]玩家登陆标语
/multimotd loginmotd randommultimotd.loginmotd.random.check查看玩家登陆标语是否随机
/multimotd loginmotd random [true/false]multimotd.loginmotd.random.change[开/关]玩家登陆标语随机模式
/multimotd reloadmultimotd.reload重新读取插件的配置文件
/multimotd resetmultimotd.reset重置插件的配置文件



服务器标语常用数据显示代码


%n% - 开始新的一行
%default_gm% - 服务器的基础游戏模式
%ip% - 服务器的IP地址
%port% - 服务器的端口地址
%players% - 在线的玩家数
%lastlogin% - 最后一个登入服务器的玩家(在你登入服务器的前一个玩家)
%maxplayers% - 服务器的最大在线玩家数
%unique% - 已经进入过服务器的不同玩家的数量
%motd% - 服务端配置文件里的motd
%bannedplayercount% - 已经ban出的玩家数量
%hardcore% - 检测服务器是不是极限模式
%worlds% - 展示服务器的所有世界(不推荐)
%plugins% - 展示服务器的所有插件(不推荐)
例子:
MOTD:
# 标语列表:
- '&4&l已经进入过服务器的玩家数量:%unique%,期待您的加入'
# 第一条
- '&3&l已经有%bannedplayercount%个熊孩子给ban了哦'
# 第二条
- '&b&l服务器在线人数:%players%/%maxplayers%'
# 第三条
- '&6服务器IP:%ip%'
# 第四条
还有一些没什么大用的可以自己去dev官网查看哦  owo




玩家登陆标语常用数据显示代码


%player_name% - 玩家的名字
%player_ip% - 玩家的ip
%player_loc% - 玩家所处的X,Y,Z轴坐标
%player_fly% - 玩家是否允许飞行
%player_exp_total% - 玩家的所有经验(应该是从插件添加到现在所有得到的)
%player_exp% - 玩家的经验
%player_level% - 玩家的等级
%player_exptolevel% - 玩家升到下一级要的经验
%player_food% - 玩家的饥饿值(1=半个饥饿图标)
%player_health% - 玩家的生命值(1=半颗心)
%player_gm% - 玩家的游戏模式
%player_op% - 检查玩家是不是op
%world% - 玩家所在的世界名
%time% - 当前所在世界的时间(游戏时间)
%rain% - 当前世界是否在下雨(其实只用看一眼周围 owo)
%thunder% - 当前世界是否正在进行一场雷雨交加的暴风雨
%seed% - 当前世界的地图种子
%animals% - 检查该世界是否会刷怪
%monsters% - 检查该世界是否会生成动物
%difficulty% - 当前世界的生存难度 ( 0 = 和平 | 1 = 简单 | 2 = 普通 | 3 = 困难 )
%pvp% - 当前世界可否pvp
%whitelisted% - 在白名单列表里的玩家
%banned% - 被ban的玩家列表

例子:
loginMOTD:# 标语列表:
- '&4&l您的游戏名:%player_name%'
# 第一条
- '&3&l您的登陆Ip:%player_ip%'
# 第二条
- '&b&l您的游戏模式:%player_gm%'
# 第三条
- '&6您现在在世界:%'
# 第四条
