5L的评论不知道如何评价...但sendActionbar()这个方法是Paper自己偷偷塞进核心的,你可以去查询最新的BukkitAPI,里面并无该方法

但是你要知道要使用nms的话就差不多找对方向了...

首先我们看 Minecraft协议里的Chat http://wiki.vg/Protocol#Chat_Message_.28clientbound.29
对应过来的就是nms下的PacketPlayOutChat这个封包

那么我们从协议里面得知  封包内的
private IChatBaseComponent a; ---> 就是 JSON Data
private byte b; ---> 就是Position [0: chat (chat box), 1: system message (chat box), 2: game info (above hotbar)]

所以我们就可以这么做,我们要用actionbar,那无非就是 Position 设置为2咯
所以我们可以写出以下代码


  3. PacketPlayOutChat packetPlayOutChat = new PacketPlayOutChat(IChatBaseComponent.ChatSerializer.a("test"), (byte) 2);
  4. EntityPlayer entityPlayer = ((CraftPlayer) player).getHandle();
  5. entityPlayer.playerConnection.sendPacket(packetPlayOutChat);</p><p>
  6. // 注:以上的代码使用 spigot1.10.2 编写,不同版本代码会有所改变!
  7. // 比如以下为1.12的
  8. IChatBaseComponent iChatBaseComponent = IChatBaseComponent.ChatSerializer.a("test");
  9.         
  10. PacketPlayOutChat packetPlayOutChat = new PacketPlayOutChat(iChatBaseComponent, ChatMessageType.GAME_INFO);
  11. EntityPlayer entityPlayer = ((CraftPlayer) player).getHandle();
  12. entityPlayer.playerConnection.sendPacket(packetPlayOutChat);
  13. // 可以看到不同的就是nms下把 byte 封装成了ChatMessageType
