关于MM的小问题
------------------------------------------------------------------------------


#如何添加一个刷怪点
-
#刷怪点 不能重复 建议这样格式 F1-1 F1-2 F1-3 以此类推




第一步 对准脚下 输入 /mm s create 刷怪点 怪物名字 即可生成刷怪点


------------------------------------------------------------------------------


#如何给BOSS 刷怪点 添加 刷新时间
-
#时间按秒计算 60秒为一分钟 120秒为两分钟 以此类推


第一步 输入 /mm s set 刷怪点 cooldown  时间  即可完成刷新时间添加


------------------------------------------------------------------------------


#如何删除 某个刷怪点


第一步 输入 /mm s delete 刷怪点


#不知该位置 刷怪点 是什么


第一步 输入 /mm s listnear <范围> 范围为方块距离 即可查看附件的刷怪点


------------------------------------------------------------------------------

                                                               关于如何设置NPC传送
------------------------------------------------------------------------------


第一步再想要传送的终点设置 设置时 请将对准脚下 /setwarp 地标名 >>设置坐标


------------------------------------------------------------------------------


第二步 用木棍 选定 想右键可进行传送的 NPC


------------------------------------------------------------------------------


第三步 输入 /npcmd add noPerms warp 地标名


------------------------------------------------------------------------------


第三步 到此你右键 NPC 即可传送到 第一步设置的 地标位置了


------------------------------------------------------------------------------


注：/warp 地标名 也可以进行传送 手动输入


------------------------------------------------------------------------------
