Crackshot-奶妈枪教程



相信不少RPG服务器都会有奶妈这种职业
奶妈枪顾名思义是给队友回复血量的枪械
这个帖子讲会教大家如何用Crackshot制作奶妈枪


以下教程


  1. Explosions:
  2.       Enable: true
  3.       是否开启
  4.       Damage_Multiplier: 0
  5.       爆炸伤害 不用管
  6.       Enable_Friendly_Fire: true
  7.       友军伤害 开不开无所谓都会有效果的
  8.       Explosion_No_Damage: true
  9.       无伤害 奶妈枪所以开启
  10.       Explosion_Potion_Effect: HEAL-1-1
  11.       药水效果 HEAL代表瞬间恢复 后面依次是 药水等级 持续时间
  12.       Knockback: 1
  13.       击退距离
  14.       Explosion_Radius: 5
  15.       范围（半径）
  16.       On_Impact_With_Anything: true
  17.      撞到物体才爆炸 推荐开启
复制代码

以上是奶妈枪需要用到的一点东西现在我放上来一把奶妈枪以用于大家学习。
