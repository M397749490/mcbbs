插件简介：COD-Warfare是一基于一款热门游戏“使命召唤”的插件，在你的bukkit服务器里增加了新的PVP模式。COD-Warfare绝对不需要mods。你可以把它作为一个小游戏，或者用在整个服务器。COD-Warfare是任何服务器的完美插件。制造枪支，建立地图和你的朋友玩，让Minecraft更有趣。
这个插件是一个很火的插件，下载量已过30000！！

作者的原话：COD-Warfare is a plugin based on the popular game "Call of Duty" that adds new PvP modes to your Bukkit server. COD-Warfare requires absolutely no mods. Whether you choose to use COD-Warfare as a mini game, or base your whole server on it, COD-Warfare is the perfect plugin for any server. Create guns, build maps and play with your friends game modes that make Minecraft way more fun.

插件的命令和权限：
/cod        查看插件的信息
/cod authors        显示玩家COD-Warfare作者的列表
/cod join        加入 COD-Warfare        cod.join
/cod join <玩家>        让其他玩家加入 COD-Warfare        cod.joinother
/cod leave        离开 COD-Warfare        cod.leave
/cod leave <玩家>        让其他玩家离开 COD-Warfare        cod.leaveother
/cod profile        显示你的分数        cod.profile
/cod profile <玩家>        显示其他玩家的分数        cod.profileother
/cod lobby tp        传送到游戏大厅        cod.lobbytp
/cod lobby set        设置大厅        cod.lobbyset
/cod create <竞技场名称> <Arena Type>        创建一个竞技场（地图）        cod.createarena        Arena types can be found below
/cod delete <竞技场名称>        删除一个竞技场（地图）        cod.deletearena
/cod arena <竞技场名称>        显示这个竞技场的领域信息        cod.infoarena
/cod set <竞技场名称> [参数]        编辑这个竞技场        cod.set
/cod info        显示插件的信息（跟/cod一样）
/cod menu        打开商店        cod.openshop        this permission does not work with the gun menu item
/cod creategun        创建一个用于游戏的枪        cod.creategun
/cod creategggun        创建一个游戏用的枪        cod.creategungamegun
/cod guns        显示可用的枪        cod.gunlist
/cod pack        这个指令告诉你服务器COD-Warfare的资源包        cod.rpack        default resource pack can be found bellow
/cod give <玩家> <枪支名称>        解锁指定玩家的枪        cod.givegun
/cod xp        显示你的经验值（XP）        cod.xp
/cod clan create        创建一个家族        cod.clanCreate
/cod clan invite        邀请玩家加入你的家族        cod.clanInvite
/cod clan leave        退出家族        cod.clanLeave
/cod clan join        加入家族        cod.clanJoin
/cod clan delete        解散你的家族        cod.clanDelete
/cod clan invites        显示家族的邀请        cod.clanInvites
/cod clan addadmin        在你的家族添加一个管理员        cod.clanAddAdmin
/cod clan removeadmin        删除你家族的管理员        cod.clanRemoveAdmin
/cod list        列出可用的竞技场（地图）        cod.arenasList
/cod credits set        设置玩家的分数        cod.creditsSet
/cod credits add        增加玩家的分数        cod.creditsAdd
/cod credits take        取走玩家的分数        cod.creditsTake
/cod update        更新 COD-Warfare        cod.update
/cod arenacreator        Leaves Arena Creator Mode（不懂，谁能告诉我）        cod.arenacreator
/cod guncreator        进入创造枪的模式（编辑枪）        cod.guncreator
/cod nextarena        等待下一场游戏        cod.setNextArena
/cod start        开始比赛        cod.forceStart
给你一个挂式套装可以让你跳得更高一些        cod.exojump
Allow spam / swearing（不懂）        cod.allowedSpam地形编辑        cod.terrainedit
允许拾取物品        cod.pickupitem
