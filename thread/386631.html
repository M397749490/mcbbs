①简介

这个插件可以让你在一些地方添加自定义声音（来自于Minecraft内置的声音），比如：玩家登入退出、被箭射中、聊天提示音等等。你可以自行配制什么情况下发出什么声音，当然这些声音必须是Minecraft内置的。当你安装本插件后，在插件配置目录会生成一个 list-of-sounds.yml文件，此文件包含Minecraft可用的内置声音列表，你可以通过指令试听这些声音。

在我的服务器玩过的服主应该体验过该插件了。没错，因为你们需要，所以我转载来了。

②支持的事件

  • join    玩家登陆
  • leave     玩家退出
  • chat    新聊天消息
  • teleport    传送音效
  • command    指令执行音效
  • hit    击中
  • hit with iron or diamond sword    被铁剑或钻石剑击中
  • hit with bow    被弓箭击中
  • death    死亡音效
  • Scroll in the hotbar    滚动鼠标滚轮（切换工具栏的音效）
  • Inventory clicks      背包内点击音效

③指令和权限

指令
权限
描述
-moresounds.hear可以听见音效 (默认所有玩家可以听见). 如果添加该权限的负权限, 玩家默认不能听见音
/sounds on<code>|</code>offmoresounds.toggle切换是否可以听见音效
/sounds helpmoresounds.help列出插件可用指令
/sounds reloadmoresounds.reload重新加载配置文件
/sounds listmoresounds.list列出所有可用的声音
/sounds play <声音名> [玩家ID 或者 *] [pitch] [volume]moresounds.play试听在列表中的声音
/sounds updatemoresounds.update使用 /sounds update 指令升级插件并且如果有更新会在控制台提

④配置文件
  1. 要使某个情况不发出声音你可以将其值设置为 'none' 或者 ''. 声音的格式为 '声音名, [音高], [声音大小]' 其中音高和声音大小可以不填. 例如: note-pling, 2.0, 0.5.
  2. 配置文件 config.yml 很简单:

  4. sounds:

  6.     join: note-pling
  7.     # 有玩家登陆的音效，所有玩家可以听见

  9.     leave: note-bass
  10.     # 玩家退出时的音效，所有玩家可以听见

  12.     chat: item-pickup
  13.     # 新聊天信息，所有玩家可以听见

  15.     command: item-pickup
  16.     # 执行了一条指令，仅该玩家能听见

  18.     hit: hurt-flesh, 1.2
  19.     # 怪物或者玩家被击中 - 附近所有的玩家可听见

  21.     hit-sword: zombie-metal, 1.5
  22.     # 怪物或者玩家被铁剑后者钻石剑击中 - 附近所有的玩家可听见

  24.     hit-arrow: orb-pickup, 0.8
  25.     # 当成功射中一只怪物或者一名玩家时 - 仅该玩家能听见

  27.     teleport: portal-travel, 2.0
  28.     # 当通过指令传送时 - 仅该玩家能听见

  30.     hotbar-scroll: note-sticks, 1.8, 0.8
  31.     # 当转动鼠标滚轮选择物品栏时

  33.     inventory-click: none
  34.     # 当玩家在背包中点击物品时

  36.     on-death: wither-spawn
  37.     # 玩家死亡时 - 仅该玩家能听见

  39. update-notifications: true
  40. # 是否在服务器启动时检查更新

  42. teleport-particles: true
  43. # 在玩家传送点创建一些粒子效果 - 所有附近玩家都可看见
