wget http://www.java.net/download/jdk7u10/archive/b18/binaries/jdk-7u10-fcs-bin-b18-linux-i586-28_nov_2012.tar.gz


cd到usr目录，mkdir建立java文件夹
tar解压进去
然后
vi /etc/profile 或者 vim /etc/profile
·在profile文件末尾加入：
export JAVA_HOME=/usr/java/jdk1.7.0_10 ←你的JAVA目录
export PATH=$JAVA_HOME/bin:$PATH
export CLASSPATH=.:$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar

最后输入java或者javac测试下，列出参数列表表示环境配置成功

不过环境是否配置成功都无所谓，每次开启服务器时输入/usr/java/jdk1.7.0_10/bin/java 来代替输入 java 也行，之后就和windows一样了，配置properties什么的
