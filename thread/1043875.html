说是尝试提升打击感，其实就是搬了些万物鼻祖OW的东西过来
根据个人理解，简单的把狭义的打击感分为以下几点：
  • 攻击命中时视角变动（镜头晃动，视野缩放等）
  • 攻击命中时音效的反馈
  • 攻击命中时GUI上的反馈
  • 对象受到伤害时的动画，特效
  • ...
试了下在1，2，3点上面做了一点点文章，用到了两个新东西：
/attribute 和JSON文本中的font

1.视角变动
众所周知，（通过effect，修改属性）改变玩家的速度会对玩家的视野进行缩放
原本在attribute刚出的时候发现输入
  1. /attribute @s minecraft:generic.movement_speed base set 1
复制代码
有时会对玩家的镜头进行一瞬间的拉伸，想在这方面做东西结果发现这玩意通过其他方式执行和在聊天栏输入的效果不一样，只有后者才会出现这个效果。（这也太mojang了）
没法，只能老老实实给玩家加速属性。
首先用进度检测玩家攻击：
  1. {
  2.         "criteria": {
  3.               "damage": {
  4.                     "trigger": "minecraft:player_hurt_entity",
  5.              "conditions": {
  6.                           "damage":{
  7.                                 "type":{
  8.                          "is_projectile":false,
  9.                                        "is_magic":false,
  10.                                        "is_fire":false
  11.                                  }
  12.                            }
  13.                      }
  14.                  }
  15.             },
  16.         "rewards":{
  17.               "function":"fox_hurt:fov"
  18.         }
  19.   }
复制代码
fox_hurt:fov函数中的内容：
  1. attribute @s minecraft:generic.movement_speed modifier add 0-0-0-0-0 test 0.02 add
  2. scoreboard players set @s timer 3
  3. title @s times 0 1 4
  4. execute unless entity @s[advancements={fox_hurt:kill=true}] run title @s title {"text":"\ue005","font":"mark:test"}
  5. execute at @s run playsound minecraft:mz1 player @s ~ ~ ~ 0.5 1 0.5
复制代码
配合高频执行的fox_hurt:tick中的相关内容：
  1. execute as @a[scores={timer=0}] run attribute @s minecraft:generic.movement_speed modifier remove 0-0-0-0-0
  2. scoreboard players remove @a[scores={timer=1..}] timer 1
  3. advancement revoke @a[advancements={fox_hurt:damage=true}] from fox_hurt:damage
复制代码
可以注意到视野的缩放要经过3tick才会回到原来的状态，因为发现只给1tick有时压根就不会放。
“但是玩家的速度同时被改变了呀”
是。但是差值不是很大，我是认为为了提供反馈牺牲一下给玩家3tick的20%提速是可以接受的


2.音效反馈
相关的函数同样在上面，老东西就不提了。
元素对抗这方面就做得很完善，尊尊尊。

3.GUI反馈
就是指准心周围的"X"字啦。
用titie显示自定义字体（也在fox_hurt:fov中）。
