请教各位大佬
我的代码想要实现当玩家捡起一个物品时更改被捡起的物品
为何getItem().setItemStack(item)无效
而getItem().getItemStack.setItemMeta(meta)就有效呢

例如我想要将玩家捡起的[泥土]加上nbt标签更名为[泥土样本]
我像这样写是没有效果的 捡起来的东西依旧是泥土
public void onPickup(PlayerPickupItemEvent event){
        if(event.getItem().getItemStack().equals(new ItemStack(Material.DIRT))){
            ItemMeta meta = plugin.getServer().getItemFactory().getItemMeta(Material.DIRT);
            meta.setDisplayName("§2DirtClumps");
            ItemStack item = event.getItem().getItemStack().clone();
            item.setItemMeta(meta);
            event.getItem().setItemStack(item);
        }
    }

而我如果这样写就有效果 捡起的[泥土]确实被改名为了[泥土样本] 这是为什么呢？


public void onPickup(PlayerPickupItemEvent event){
        if(event.getItem().getItemStack().equals(new ItemStack(Material.DIRT))){
            ItemMeta meta = plugin.getServer().getItemFactory().getItemMeta(Material.DIRT);
            meta.setDisplayName("§2DirtClumps");
            event.getItem().getItemStack().setItemMeta(meta);
        }
    }

在我取消事件之后我发现即使使用setItemStack靠近一个我要修改的物品之后它也的确被修改了
但若我不取消事件 进入我的背包的仍然是原来的物品而不是修改后的物品


我原以为修改物品只是修改你快要捡起的时候的物品
而这个事件当中物品你已经获得了 是不会修改的
但setItemMeta就不会出现这样的情况 于是我就很奇怪了

实在是不明白为什么，希望各位赐教
