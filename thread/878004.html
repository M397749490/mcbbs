新人第一次写数据包。打算弄一个签到系统，就先写了一个时间系统了，整体很简单的。
时间是一直显示的，手动开启数据包后校准一下时间
用英文显示是因为放在服务器里中文是乱码，大家可以转码替换文字改成中文。
  1. /function test:time
复制代码
接下来就是废话了。
day是天数，min是分钟，h是小时，s是秒。
用scoreboard players set @a xx xx 来校准一下当前时间。
bug还是有的，大家可以把@s改成其他的，不然可能会服务器没人的时候时间就停止了吧。。
具体内容就是这样啦~
  1. scoreboard objectives add s dummy "s"
  2. scoreboard objectives add min dummy "min"
  3. scoreboard objectives add h dummy "h"
  4. scoreboard objectives add day dummy "day"
  5. function test:time/s
复制代码
  1. scoreboard players add @a s 1
  2. execute as @a as @s[scores={s=60}] run scoreboard players add @a min 1
  3. execute as @a as @s[scores={s=60}] run scoreboard players set @a s 0
  4. execute as @a as @s[scores={min=60}] run scoreboard players add @a h 1
  5. execute as @a as @s[scores={min=60}] run scoreboard players set @a min 0
  6. execute as @a as @s[scores={h=24}] run scoreboard players add @a day 1
