简介

afkTerminator 能够防止你服务器里的熊孩子使用挂机池等设备。它可以检测到这些种挂机方式：

矿车、流水、连跳、活塞、飞行、钓鱼、骑乘、弓箭、方块交互

你可以指定自动检测这些挂机方式，对疑似挂机的熊孩子自动惩罚。管理员将会在控制台收到警告信息，而且还会记录到一个日志文件里。日志会记录挂机的位置和玩家

支持的惩罚方式：不处理（发出警报）、岩浆、TNT（慎用）、杀死、踢出、生成怪物、自定义命令（支持多条命令）

可以通过权限配置哪些人免除检测。

支持禁止自动登录，防止挂机被踢的玩家立刻登录服务器。开启该功能后，玩家离开服务器后必须等待一段时间才能重新登录，如果重试失败达到你设置的最大重试次数，将会对这名玩家执行你设定好的动作（例如 ban 掉）

命令

  1. /afkt reload all # 重载插件
  2. /afkt reload config # 重载配置文件
复制代码


权限

如果你使用权限功能，必须安装 Vault。

  1. afkTerminator.excluded 拥有此权限的玩家不会被惩罚（但仍然会被记录到日志）
  2. afkTerminator.loginDelayExculded 拥有此权限的玩家不会受到登录限制
  3. afkTerminator.admin 使用 /afkt reload 的权限
  4. afkTerminator.notify 拥有此权限的玩家会在游戏中收到警告信息

配置

以下是以插件 2.1.0 的配置文件为例， 1.9.0 版本的配置文件与下面的略有差别，下面会提到


  1. # 配置文件版本，不能更改！！！v2.1.0 版本该值为 9，v1.9.0 版本该值为 8
  2. configVersion: 9
  3. # 是否启用afkTerminator
  4. afkMachineDetectEnable: true
  5. #
  6. # 自动检查的间隔（该选项已移除）
  7. # afkTime:
  8. #
  9. # 惩罚方式，下面的英文分别对应：不处理、岩浆、TNT、踢出、杀死、命令、生成怪物
  10. # NONE, LAVA, TNT, KICK, KILL, COMMAND, SPAWNMOB
  11. punishment: NONE
  12. #
  13. # 当惩罚方式为 COMMAND 时，在这里设置自定义命令
  14. #  "[player]" 将会被替换为实际的玩家名字
  15. # 多条命令之间用一个 " /n " 分割
  16. commandPenalty: 'ban [player]'
  17. #
  18. # 当惩罚方式为 SPAWNMOB时，这里设置生成哪一种怪物
  19. mobToSpawn: ZOMBIE

  21. # LAVA, TNT, SPAWNMOB & COMMAND 通常会自动尝试多次直到有效
  22. # 但是你可以在这里指定一个大于 0 的数字来限制次数，如果数字小于等于 0，将不会限制次数
  23. # 设置为 KILL 或者 KICK 时，将会自动默认该数为 1
  24. punishmentLimit: -1

  26. # 是否记录日志
  27. logEnable: true
  28. #
  29. # 日志级别 (3 = 最少细节，1 = 最多细节)
  30. logLevel: 3
  31. #
  32. # 控制台信息级别 (3 = 最少细节，1 = 最多细节)
  33. # 设置为 2 会在控制台查看挂机事件的警告
  34. consoleLevel: 2
  35. #
  36. # 开关不同种类的 AFK 机器检测，true 为检测
  37. detectWater: true # 流水
  38. detectMineCart: true # 矿车
  39. detectHorse: true # 骑马
  40. detectPig: true # 骑猪
  41. detectJump: true # 连跳
  42. detectPiston: true # 活塞
  43. detectFishing: true # 钓鱼
  44. detectProjectile: true # 抛射
  45. detectInteraction: true # 方块交互

  47. # 自动检查更新
  48. updateCheckEnable: true
  49. #
  50. #
  51. # 设置检测的速度（频率）级别，范围为 1-10，数字越大，频率越快
  52. # 较高的频率有可能会造成错误，例如将正常游戏的玩家判定为挂机
  53. # 而且较高频率也会更耗费服务器资源
  54. #
  55. # 1 = 低速.  平均每超过 4 分钟检测一轮，资源消耗低，较低的错误率
  56. # 5 = 中速.  每 1 - 3 分钟检测一轮，建议配置
  57. # 10 = 高速.  每低于 30 秒就检测一轮，资源消耗高，较高的错误率
  58. #
  59. afkSensitivity: 5
  60. #
  61. # 设置启用该插件的世界（"- all" 则在所有世界启用）
  62. #
  63. worlds:
  64.    - all
  65. #
  66. # 以下几个设置是防止自动登录的设置
  67. #
  68. # 是否启用
  69. blockAutoLoginEnable: true
  70. #
  71. # 玩家必须等待多少秒才能重新登录
  72. autoLoginMinTime: 5
  73. #
  74. # 每次重试失败后，等待秒数乘的倍数（需要等待的时间越来越长，1.0 则不增加，支持小数）
  75. minTimeMultiplier: 1.0
  76. #
  77. # 最大重试次数
  78. autoLoginMaxAttempts: 5
  79. #
  80. # 超出重试次数后执行的命令，"[player]" 将会替换成实际的玩家名字
  81. maxAttemptsCommand: 'ban [player]'
  82. #
  83. # 禁止登录时给玩家的消息，"[player]" 将会替换成实际的玩家名字，"[cooldown]" 将会替换成实际的等待秒数
  84. autoLoginBlockMsg: '玩家 [player] 请等待 [cooldown] 秒再重新登录'
