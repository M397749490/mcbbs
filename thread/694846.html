使用方法&指令&权限

购买本插件，扔进plugins文件夹，重启服务器


本插件管理员指令只有一个/ads4vip
使用后可打开管理员菜单，设置插件的启用/禁用，重载插件


权限就一个

ads.bypass
把这个权限给买了VIP的玩家，他们就再也不会被广告骚扰啦

配置文件
可设置广告内容，聊天广告显示频率，以及打开哪些GUI会显示广告，以及广告时长
配置文件对应版本2.0

  2. # 广告是否只显示一次
  3. showOnce: false
  4. # 玩家进服时强制打开一个广告GUI界面，不推荐
  5. forceOnJoin:
  6.   enabled: false
  7.   time: 5
  8. # 出现在聊天栏的广告  
  9. ChatAds:
  10.   enabled: true
  11.   # 每多少次聊天会显示一次
  12.   show: 60
  13.   lores:
  14.   - '&a——&b——&c——&d——&e——&7——&f——&a——&b——&c——&d——&e——&7——&f——&a——&b——&c——&d——&e——&7——&f——'

  20. menu:

  22.   size: 45
