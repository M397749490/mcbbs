指令
  • /smileychat 查看信息.
  • /smileychat reload 重载配置.
  • /smileychat smileys 查看所有表情.

权限
  • smileychat.* 拥有该插件的所有权限.
  • smileychat.update 玩家登入时的更新提示
  • smileychat.info 允许使用 /smileychat
  • smileychat.reload 允许使用 /smileychat reload
  • smileychat.list 允许使用 /smileychat list
  • smileychat.chat.*
    • smileychat.chat.smileys 允许玩家在聊天栏里使用表情符号.
    • smileychat.chat.custom 允许使用自定义符号
    • smileychat.chat.art 允许使用 ascii-art
  • smileychat.sign.*
    • smileychat.sign.smileys 允许玩家在牌子里使用表情符号.
    • smileychat.sign.custom 允许使用自定义符号
    • smileychat.sign.art 允许使用 ascii-art
  • smileychat.command.*
    • smileychat.command.smileys 允许玩家在命令里使用表情符号.
    • smileychat.command.custom 允许使用自定义符号
    • smileychat.command.art 允许使用 ascii-art

配置文件
  1. Update-check: true 检查更新
  2. chat: true 聊天框使用启用
  3. Use-signs: true 牌子使用启用
  4. Use-commands: true 指令内使用启用

  6. smileys:
  7.     misc:  每个表情/符号都有对应的keyword，可自定义
  8.         happy: ':)'
  9.         checkmark: '*check'


  12. ascii-art:  同上
  13.      tableflip: '*tbf'

  15.             
  16. custom:  自定义表情如下，输入*troubled 显示 (>_<)
  17.     smiley1:
  18.          input1: '*troubled'
  19.          output1: '(>_<)'
