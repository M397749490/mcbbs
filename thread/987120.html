【插件简介】
WorldPluginManager提供了一个轻量级的解决方案，用于在不同的世界中加载，卸载和配置不同的插件。
它支持Multiverse-Core和其他Multi-World插件。
它还包括一个在服务器上重新加载插件的新系统，称为Clean Reload
这种动态重载是尽可能安全地重新加载而不会损坏插件

【插件特点】
直观方便的命令和命令反馈
每个世界不同的插件设置
插件被禁用之后，可以设置不被禁用的插件指令
插件重新加载器
自动启用新插件并加载它们，无需中断或重新启动服务器
自动禁用旧插件并卸载它们而不会中断服务器
可以动态配置插件

【插件教程】
  1. worlds:
  2.   world:
  3.     plugins:
  4.       BetterParty: false
  5.       ProtocolLib: true
  6.     overrides:
  7.       BetterParty:
  8.                - bp
  9.       ProtocolLib: []
  10.   world1:
  11.     plugins:
  12.       BetterParty: true
  13.       ProtocolLib: true
  14.     overrides:
  15.       BetterParty: []
  16.       ProtocolLib: []
复制代码
以上为示例文件
有两个世界"world"和"world1"，安装了2个插件“BetterParty”和“ProtocolLib”

插件“BetterParty”在世界“world”被禁用，而在世界“world1”可以正常使用
但是可以在世界“world”使用插件“BetterParty”的/bp指令，而此插件其他的指令如:"/bparty"就不能使用

插件第一次载入时，会自动在config.yml里生成现有的插件和世界
插件全部默认为启用（true）
按照自己需求在参考上面的示例文件
禁用/启用插件在指定世界，添加不被禁用的指令
