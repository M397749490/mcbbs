插件命令:

/vipsys 查看帮助

/vipsys viptime 查询自己的VIP情况 (玩家命令)

/vipsys key <激活码> 使用激活码 (玩家命令)

/vipsys list 显示所有的VIP (OP命令)

/vipsys look <玩家名> 查看指定玩家的VIP情况 (OP命令)

/vipsys remove <玩家名> 删除指定玩家的VIP (OP命令)

/vipsys give <玩家名> <VIP组> <时间> 给指定玩家指定时间的VIP(时间写-1为永久)(OP命令)

/vipsys createkey <数量> <VIP组> <时间> 创建激活码(OP命令)

/vipsys export <VIP组> 导出该组的激活码(OP命令)

/vipsys save 立即保存缓存数据（没特殊用处可以不要用）（OP命令）

/vipsys reload 重载部分配置文件 （OP命令）

注: 时间为XdXhXmXs 例如1d为1天 2h为2小时 10m为10分钟 5s为5秒 1d10m5s为1天10分钟5秒


PlaceholderAPI变量
VipSystem_leftdays    -> 玩家剩余的VIP天数

                                                        VipSystem_group       -> 玩家的VIP组名

                                                        VipSystem_lastgroup  -> 玩家开通VIP之前的组名
