前几天在看vexview教学的时候，发现居然支持滚屏功能

那可要好好利用起来！！

于是 - SnowkDanmaku 诞生了
通过它，你可以让你的MC服务器摇身一变
变成.....变成....bilibili   (雾)


SnowkDanmaku 使用方法

=======#前置#=======
下载前置 VexView
https://www.vexview.net/

=======#本体安装#=======
方法1： 将jar文件放入plugins文件夹，启动服务器
方法2： 将jar文件放入plugins文件夹，使用yum实现热加载

=======#使用#=======
输入 /fadanmu   /fadm   /fdm 皆可
即可进入发弹幕状态，在聊天框输入弹幕内容，即可在公屏上看到你自己
也可以中途输入 cancel 取消发送

=======#额外内容#=======
SnowkDanmaku 支持 DFA 敏感词过滤算法
详情见我的另一个帖子
https://www.mcbbs.net/thread-1007749-1-1.html
让熊孩子无权发送弹幕
同时还支持冷却系统，让熊孩子无法刷屏

=======#服主进阶#=======
-1-
你可以配合 VexKeyBoardHealper 插件实现
发弹幕快捷按键
https://www.vexview.net/resources/vexkeyboardhelper-vexview.9/updates
-2-
你可以配合 ChestCommands / TabooMenu 等菜单插件
实现钟表菜单中点击发送弹幕功能
https://www.mcbbs.net/forum.php?mod=viewthread&tid=482226&highlight=Chestcommands
https://www.mcbbs.net/thread-798904-1-1.html

=======#权限#=======
snowk.danmaku.admin - 使用 /fdm reload 重载插件权限
snowk.danmaku.help - 使用 /fdm help 查看帮助的权限


配置文件

# 你可自定义新的敏感词列表
add:
  - '阿伟死了'

# 你也可从默认的列表中删除你不需要的敏感词
remove:
  - 'fxx'

# 是否开启弹幕冷却系统
cooldown: true

# 冷却秒数
cd_timeSec: 25
