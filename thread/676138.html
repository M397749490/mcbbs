# 口袋部落回归

口袋部落始建于 2013 年，尝试过工业、口袋妖怪等各种 Mod 服。2015 年左右关闭服务器，因为腐竹本人感觉管理服务会花费大量的精力和时间，很难投入到游戏，享受游戏本身的乐趣。

那么为什么又重新运营 Minecraft 服务器了呢，因为最近在很多 Minecraft 服务器中玩过，但是玩了一段时间，服务器就删档了，自己在服务器付出的努力忽然就没有了，就会感到很沮丧，所以打算开一个不删档的 Minecraft 服务器，只对资源区进行定期更新。同时为了自己也能享受游戏，所有本服也不会又 OP 等管理人员。同时为了游戏玩家的质量（此处并没有贬低盗版玩家的意思），会开启正版验证。希望大家能一起享受游戏。


# 服务器硬件优势


        1. 本服是独立服务器，意味着一台服务器上只有我们一个服运行，保障资源较为充足。

        2. 目前只有 4 GB RAM。

        3. SSD 固态硬盘。

        4. 每小时服务器都会自动备份，异地多活。

        5. 对 TCP 连接做了大量优化（等待更多玩家加入测试）




     # 服务器特色

        1. 声望系统：声望越高，权限越多，攻击力体力也会增强呢。

        2. 粘液科技：增加纯净服务器的可玩性（也有人称之为插件版工业）

        3. 宠物插件，乐趣无穷

        4. EggCatcher：用鸡蛋捕捉各种生物

        5. 地皮世界：地皮世界永远不会删除，这就是你温暖的港湾。

        6. 更多内容，等待你的发掘。
