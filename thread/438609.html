原文

Description  This plugin allows a player to set bounties on others! When a player with a bounty is killed, the killer will collect the reward from it.  Permissions  br.* - allows a user to use all commands  br.setbounty - allows a user to setbounties  br.list - allows a user to see all current bounties  br.help - allows a user to see the commands  br.reload - allows a player to reload the config  Commands  /br help - The help menu  /br reload - Reloads the config  /br <player> (amount) - Sets the bounty on a player  /br list - Shows all current bounties  Dependencies  You need Vault for this to work!  Additional Information  If there are any bugs you'd like to report, leave a comment and I will work on it asap. If you have a suggestion for me, leave a comment as well!
