标题: [1.11-]Mineways 5.0.5 —— Minecraft地图渲染与3D打印模型导出
本帖最后由 LocusAzzurro 于 2016-12-7 23:27 编辑



Mineways可以把你的Minecraft作品输出为模型文件，以用来制作图片，视频或进行3D打印。这也是个免费，开源的软件，使你可以轻松输出你的作品并3D打印出来，你可以使用自己的打印机，也可以通过Shapeways或Sculpteo等服务来打印，同时也可以在Sketchfab等网站中查看它们，以及使用Blender, 3DS MAX, Maya, Cinema 4D 或者其它渲染系统制作渲染图片。

Windows平台的目前最新版本为5.05，Mac最新版本为5.04，仅限32位，且不能在Sierra中运行。Linux系统需要WINE来模拟Windows系统。

Minecraft建筑Mineways输出
Blender渲染Shapeways打印


一般情况下Minecraft地图需要储存在电脑上（除非使用World Downloader）并可以通过Windows/Mac/Linux原版Minecraft读取（或是经过转换的PE版地图）。在程序中你可以从地图上选择一个模型，并创建一个3D打印或渲染用文件。具体操作可以参考下方的详细指南。另外可以通过一个3D文件浏览器来查看导出的文件，推荐使用G3D来查看OBJ文件，使用MeshLab来查看STL和VRML文件。此时你可以选择上传并分享这个模型，或使用渲染工具制作图片，或把它3D打印出来。对于最后一项，你可以使用自己的3D打印机，或者将它上传到Mineways的打印服务平台上。3D打印的价格根据大小从$5到$500不等。

如何安装并运行Mineways：

  • 解压mineways.zip到一个目录中。在Windows里可以直接从压缩文件中运行mineways.exe文件。
  • 双击Mineways.exe程序来运行（如果失败就尝试Mineways32.exe）如果不能成功运行，参考下面的指南。
  • 使用"File | Open World"来打开一个地图，使用 "File | Open..."来打开schematic文件。
  • 使用左键来拖动地图，使用滚轮来缩放，F3可以到达玩家位置。
  • 使用右键拖动来选择地图上的一个区域以及控制选择区域。
  • 可以使用鼠标中键或"Lower Depth"滑条来设定深度。
  • 通过"File | Export for Rendering"来导出渲染用模型，通过"File | Export for 3D Printing"来导出打印用模型，之后直接点击OK即可。如果需要上传，操作比较复杂。
  • 非必须：如果需要查看结果可以使用G3D, MeshLab或者其它模型预览程序来查看.OBJ或.WRL文件（如果模型有颜色不要使用Microsoft的3D Builder，对于STL没关系）。



Mineways界面



鼠标与键盘操作

  • 左键点击与拖动 - 在地图中移动
  • 右键点击与拖动 - 选择输出区域或改变其大小，左键+Ctrl也能达到同样效果
  • 中键点击 - 修改选择区域的最低高度
  • 滚轮 - 缩放
  • Shift键不会影响大多数快捷键操作
  • [ 和 ] - 将最低高度向上/向下移动一格，控制模型底部
  • 空格 - 将最低高度移动到选区内最下方的方块位置
  • E/Q | PageUp/PageDn | +/- -向内/向外缩放一级
  • Home/End 最大/最小缩放


Mineways菜单选项

  • File 菜单
    • Open World - (打开地图)从地区列表选择地区，地图名显示在左侧，文件夹名在右侧。
    • Open... (Ctrl-O) - (打开...)选择需要打开的地图的level.dat文件。
    • Reload World (R) - (重载地图)重新打开当前加载的地图。在修改地图本身后需要重新加载时很有用。
    • Set Terrain File (Ctrl-T) - (设置材质文件)选择一个Mineways提供的或自己使用TileMaker制作的terrainExt*.png文件。
    • Import File (Ctrl-I) - (导入文件)导入一个输出过的模型(OBJ, WRL, STL's TXT文件)以继续操作。或运行一个命令脚本。
    • Export for Rendering (Ctrl-R) - (渲染输出)将选择区域输出为一个渲染用文件。提示：使用G3D可以预览。
    • Export for 3D Printing (Ctrl-P) - (3D打印输出)输出3D打印模型，检查坚固性并简化模型。
    • Publish to Sketchfab (Ctrl-F) - (发布至Sketchfab)将你的模型放在Sketchfab，一个免费服务平台上，进行展示。
    • Export Schematic (Ctrl-S) - (输出schematic)输出模型以供WorldEdit或MCEdit使用。
    • Repeat Export (Ctrl-X)- (再次输出)使用相同输出参数再次输出。可以进行输出，查看结果，并且再次输出，以按照需求修改选择区域。
    • Close (Ctrl-Q) - (关闭)退出程序。
  • View 菜单
    • Jump to Spawn (F2) - (至出生点)查看出生点位置。
    • Jump to Player (F3) - (至玩家位置)查看玩家位置。
    • Jump to Model (F4) - (至模型)当创建选区之后，可移动视角至这个位置。
    • View Nether (F5) - (查看下界)如果存在，切换至对应的下界地图。
    • View The End (F6) - (查看末地)如果存在，切换至末地地图。
    • Show all objects (F7) - (显示所有物体)默认情况下，例如牌子和梯子等小型物体不会在地图上显示。
    • Show biomes (F8) - (显示生物群系)显示地图的生物群系的颜色。
    • Elevation shading (F) - (高度光照系统)较高的位置会以更亮的颜色显示。
    • Lighting (L) - (光照)显示地图的夜晚效果。
    • Cave mode (C) - (洞穴模式)显示地下洞穴的存在。shows the presence of underground caves.
    • Hide obscured (H) - (隐藏遮挡)在下界最有用，会显示在顶层之下的物体。
  • Colors 菜单
    • Color Schemes... - (颜色方案)通过设置这些可以修改要导出的方块种类，以及显示的方块颜色。
  • Help 菜单
    • About ... - (关于)显示版本号。
    • Give more export memory! - (更多的输出内存！)如果你收到了内存溢出的错误，使用这个可以最大限度减少内存使用。



Mineways 导出选项

一般情况下你可以直接无视这个可怕的对话框直接点击OK或按一下回车跳过它。


Mineways导出选项


渲染相关：

  • World coordinates selection: (地图坐标选择)导出范围的最高与最低对角顶点坐标。
  • Create a ZIP file: (创建ZIP文件)这个是需要上传到3D打印服务的文件。也可以用来打包所有输出的文件。
  • Export no materials, etc.: (不输出材料,等等)控制模型为单一颜色，每个方块单一颜色或带有材质。
  • OBJ file export options: (OBJ输出选项)使数据更加容易修改的专业设置。
    • Export separate types: 每种方块生成一个物体
    • Export individua blocks: 每个方块生成一个物体
    • Separate material/blocks: 分离材质与方块
    • Split materials into subtypes: 每种方块附加值生成一个物体
  • Make Z up: (将Z设为高度轴)一些系统会使用Y作为高度轴，另一些使用Z。
  • Create composite overlay faces: (创建复合叠加层)梯子，藤蔓等会被输出为单独悬空的多边形。
  • Center model around the origin: (将模型中心点定为原点)如果关闭将使用Minecraft坐标。
  • Use biome: (使用生物群系)使用生物群系属性来为方块上色。目前仅能使用导出范围中心的生物群系值。
  • Create block faces: (创建方块面)如果你不打算看到导出模型的侧面，可以不选择这一项来使文件更小。
  • Tree leaves solid: (固体树叶)为互动性使用设计（如VR），会大幅降低导出的多边形量。
  • Rotate model clockwise: (顺时针旋转模型)主要为了选择在Shapeways的平台上展示时方向。


3D打印相关：

  • 缩放选项：
    • Make the model x cm in height: (使模型x cm高)设置模型的物理高度。
    • Minimize size based on wall thickness...: (根据墙厚度最小化大小)使墙在可打印的范围内达到最低厚度。
    • Make each block x mm: (使每个方块边长为x mm)这里会显示默认的可安全打印的墙壁厚度，可以修改。
    • Aim for a cost of $x: (以消费$x作为目标)确定打印费用的大概值，会使模型被缩放。
  • Fill air bubbles: (填充气孔)模型中的空洞会被转换为固体。一般是个明智的选择，也可以减少渲染时创建的多边形数量。
    • Seal off entrances: (封闭入口)使用火把封闭入口，这样内部可以被填满（并被挖空）。
    • Fill in isolated tunnels: (填充孤立隧道)如果一个隧道通向侧面但不通至表面，就会被堵死。
  • Connect parts sharing an edge: (连接共边部分)如果一个部分漂浮在空中，会添加一个方块来把它连接到附近的部分上。
    • Connect corner tips: (连接共点部分)如果一个部分与另一个部分仅通过一点连接，会添加方块将它们连接。
    • Weld all shared edges: (焊接所有共边)在任何仅以一条边连接的方块位置添加方块来连接。一般有些过度，但对于斜屋顶比较有用。
  • Hollow out bottom of model...: (挖空模型)挖掉不可见方块使制作Shapeways与Sculpteo模型更加省钱。
    • Superhollow: (超级挖空)大量挖空方块，挖进所有边角。
    • Melt snow blocks: (融化雪块)比较迷的功能，在其他处理之后让“漏孔”更大。
  • Export lesser, detailed blocks: (输出较小，有细节的方块)一般所有方块会被打印为整个方块，或不被打印。这个选项可以使很多“部分性”方块被打印。
    • Fatten lesser blocks: (加厚较小方块)一些有细节的方块比较薄，打印效果不理想，这个选项会使它们变厚。
  • Debug: show floating parts...: (显示悬浮部分)任何不与主要结构连接的部分会被标注出来。
  • Debug: show weld blocks...: (显示焊接方块)任何由Mineways添加以使模型能够打印的方块会以粉色羊毛和岩浆显示。


Mineways文件

  • Mineways.exe - 主要的64位可执行文件。
  • Mineways32.exe - 32位版本，如果64位不能运行可以使用这个。
  • terrainExt.png - Mineways使用的默认的Minecraft材质文件
  • terrainExt_*.png - 其他高人气资源包的材质文件。
  • docs/index.html - 文档链接，与mineways.com页面相同。
  • mineways.bat - 运行Mineways，并首先运行scripting/startup.mwscript（默认为空）中的命令。
  • mineways_debug_log.bat - 运行Mineways并生成一个mineways_exec.log诊断文件。
  • mineways_without_worlds.bat - 一个“如果不能正常打开”的运行方式；会避免从默认位置读取地图。
  • register-Mineways-run-as-administrator.bat - 运行一次可以将*.mwscript文件关联至Mineways.exe。
  • README.txt - 一些小提示，大部分会指引到帮助文档。
  • scripting/*.mwscript - 控制Mineways各个部分的脚本。可以直接打开来查看其功能。
  • BlenderScripts/* - 导出至Blender时有用的脚本。
  • TileMaker/TileMaker.exe 和 TileMaker32.exe - 一个可以从资源包制作一个新的方块材质文件(terrainExt*.png)的程序。
  • TileMaker/terrainBase.png - 材质的基础模板。与terrainExt.png相同，只是为了保险起见。
  • TileMaker/blocks - TileMaker进行操作时将会使用的方块材质，需要自己提供需要修改的方块材质。



各平台相关问题与修复

Windows

如果运行Mineways时收到了“Windoes保护了你的PC”之类的消息，点击“更多信息”，然后“继续运行”。
如果Mineways在启动时出现了错误，尝试使用Mineways32。如果没有任何程序运行，可以尝试运行“mineways_without_worlds.bat”文件（双击它）。这样可以在不查看你的Minecraft地图文件夹的情况下启动Mineways。有时错误或不完整的地图数据会引起问题。如果Mineways仍然不能运行，请运行“mineways_debug_log.bat”并将输出的mineways_exec.log文件发给作者以帮助他修复问题。

如果你收到了一条关于缺少MSVCR120.DLL的错误信息，请为你的系统安装Microsoft Visual C++ 2013 Redistributable Package。你可能需要使用IE或Edge浏览器来打开链接。如果你是64位系统，选择vcredist_x64.exe，如果是32位则选择vcredist_x86.exe。
Mineways32.exe应该可以在所有系统运行，但输出大小有一些限制（一般对于3D打印来说没大问题）；
Mineways.exe是64位的，只能在64位系统运行。这个问题比较麻烦抱歉了，但是这是微软的锅【

Minecraft的Windows 10版本基本就是携带版，目前Mineways不能读取这个版本的存档。需要将其转换为PC或Mac版Minecraft存档才能在Mineways中使用。如果需要，可以使用MCEdit来进行转换。

如果Mineways被杀毒软件阻止：首先，确认你是从Mineways官网进行的下载（首页上方的链接）。如果下载文件被自动删除。则需要暂时关闭杀毒软件。除此以外也可以直接忽略警告继续运行。你可以相信作者的人品，此外，Mineways是开源的，若不确认可自行查看源码。


Mac

下载Mac版本的Mineways并双击zip文件。Mineways应该会解压并运行。如果下载文件无法解压，可能是因没有下载整个文件导致，下载的zip文件大小应为86MB左右。

目前Mineways无法在Sierra中运行；它只能在WineBottler支持的系统上运行。

当安装完成后，运行Mineways，首次运行需要比较长的时间，并且会收到一条关于Wine的消息，所以耐心等待吧。使用“File | Open World”可以加载地图。如果你的地图没有显示出来，你会收到一条警告消息，且需要使用“File | Open...”来找到/users/<用户名>/Library/Application Support/minecraft/saves/<地图名>并选择其中的level.dat文件。

如果Mineways在Mac启动时出现错误，可能是因为5.x版本无法运行（请告诉作者为何，如果你知道的话）：可以尝试使用4.16版本。

默认情况下，Mineways会使用储存在程序内部的材质，当然也可以使用其他的“terrainExt.png”文件，程序也自带了一些，使用“File | Set Terrain File”并在/users/<your name>/Downloads/MinewaysMac路径（或者其他储存Mineways的路径）选择需要的“terrainExt.png”。你可能需要自己去找这些文件，用Spotlight查找“terrainExt.png”即可。其他的terrainExt*.png文件也会在相同的路径里。

当保存的时候，打开directory /Users/<your name>/Documents路径来保存。Mac版本只有32位，所以不能像PC版一样导出很大的区域。一般来说对于3D打印来说问题不大，因为需要比较小的模型。如果你的内存溢出了，尝试使用Help菜单下的“Give more export memory!”指令，可以在导出选择区域前清理地图缓存。

除这些之外，Mac版本和PC版本是相同的，Mac用户也可以使用MeshLab或GLC Player来查看导出的3D模型。查看主要帮助文档可以获取更多信息。

Mac相关问题

如果收到“无法打开Mineways，因为不能确认开发者”之类的警告，确认执行程序即可。

如果在打开地图时提示文件名不能含有“/ : < > 或 |”字符，修改你的地图文件夹名使其不含有这些字符即可。Mineways是一个戴着Mac程序面具的Windows程序，Windows是不会允许文件名含有这些字符的。

如果收到无法找到Minecraft地图路径的消息，你需要指引Mineways来找到你的地图文件夹位置。如果你使用的Mac系统不是英文的，Mineways可能依旧会找不到你的文件路径。一个方法是将地图文件复制到一个USB盘上，这个会避开路径的问题。另一个方法是暂时把系统语言改成英语。

如果不能找到Application Support/minecraft文件夹，简单的方法是在Spotlight搜索“terminal”并运行以下命令：

  1. defaults write com.apple.Finder AppleShowAllFiles TRUE
复制代码


然后是这条：

  1. killall Finder

以重新启动查找器。你可以通过Finder -> Go -> Go To Folder -> 输入 ~/Library/Application Support/minecraft/saves来找到存档文件夹。为之后需要，可以直接在桌面上创建一个快捷方式。

通过右键可以选择选区；如果你用的是触摸板，或者你的鼠标没有右键，按住Control并左键点击即可。


Linux

对于Linux来说，下载Windows版本并使用WINE来模拟Windows环境即可。此外在Mac上也可以使用同样的方法；因为Mac版本就是经过WINE程序包装的Windows版本。即便如此，一些Ubuntu Linux用户使用5.00版本及以上时依旧会遇到问题（尚无解决方案），尝试4.17版本试试。
