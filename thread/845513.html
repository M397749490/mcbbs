插件介绍
插件主要功能
本插件可以对指定的防具或武器进行淬炼
淬炼等级可无限设置，无上限
属性也非常简单，只有伤害属性和血量属性
每一级的几率与增加的属性都可自定义
每一个掉星几率均可设置
配置简单实用



淬炼插件图片介绍
[attach]2845[/attach]



安装与使用
前置插件：TabooLib
将淬炼石文件保存在 TabooLib的item里面，通过Tlib调用即可。
Item文件保存内容：
淬炼1:
  material: COAL
  name: '&c&L武器淬炼石'
  lore:
  - '§e用法：§a将武器和淬炼石放进熔炉使用'
  - '§e作用：§a淬炼武器,激活武器隐藏属性'
  - '§e说明：'
  - '§7  -§a获得后请在熔炉内进行淬炼'
  - '§7  -§a为避免装备被抢，'
  - '§7  -§a请确保无人,再放到熔炉使用.'
  - '§7  -§c有10%的几率淬炼失败后掉级'
  nbt:
    quenching-fuel: 'ptcls'

指令与权限
  • 本插件无指令

本插件没有任何权限需要给玩家

配置文件
config
[spoiler]
Settings:
  # 允许淬炼的材质
  QuenchingItems:
  - 'DIAMOND_SWORD'
  - 'GOLD_SWORD'
  - 'BOW'
  - 'DIAMOND_AXE'
  - 'DIAMOND_PICKAXE'
  - 'DIAMOND_SPADE'
  - 'DIAMOND_HOE'
  - 'DIAMOND_ROD'
  - 'STONE_HOE'
  - 'STONE_SWORD'
  - 'STONE_AXE'
  - 'STONE_PICKAXE'
  # 淬炼描述
  QuenchingLore:
    Head: '§f-------------- [§e淬炼§f] --------------'
    Lore: '§f  淬炼等级: §e$level §6?'
    # 检查关键字
    CheckLore: '淬炼等级'

# 淬炼几率表
# 可无限扩展
QuenchingFormula:
  # 0-1 级几率
  # 1 级淬炼不要出现失败的几率，否则插件会出错
  1:
    # 名称为 "ptcls" 的淬炼石几率
    # 可无限扩展
    ptcls: 1
  2:
    ptcls: 0.95
  3:
    ptcls: 0.9
  4:
    ptcls: 0.8
  5:
    ptcls: 0.8
  6:
    ptcls: 0.7
  7:
    ptcls: 0.7
  8:
    ptcls: 0.6
# 失败掉星几率
QuenchingFall:
# 10% 的几率掉1星
- '0.10 1'
# 20% 的几率再掉1星
- '0.2 1'
# 10% 的几率再掉1星
- '0.1 1'

# 淬炼设置
# 可无限扩展
QuenchingLevel:
  # 1 级属性
  1:
    # 淬炼属性
    # 格式与 TabooLib 物品格式的 Attribute 配置相同
    all:
      health: 0  #血量  每次升级均为下一级代替上一级属性 (避免有服主认为是叠加的。。)
