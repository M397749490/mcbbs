ResGui - 领地GUI列表

    和某些拥有房间的社交游戏一样拥有GUI房间列表，可以推进玩家之间的交流，以及推广可以让玩家更好的推广自己的建筑；本插件需要Residence作为前置。

命令

命令 权限
/resgui op / resgui.use / resgui.admin
/resgui reload op / resgui.reload
/resgui load op / resgui.load
/resgui open op / resgui.use / resgui.admin
/resgui open my op / resgui.use / resgui.admin
/resgui seek <玩家名> op / resgui.use / resgui.admin
/resgui <领地名称> addlore <lore> op / resgui.use / resgui.admin
/resgui <领地名称> setlore <行数> <lore> op / resgui.use / resgui.admin
/resgui <领地名称> removelore <行数> op / resgui.use / resgui.admin

权限
    resgui.use    基础权限（给玩家这个权限才可以使用本插件的命令）
    resgui.lore.x 自定义Lore行数 （例如给玩家resgui.lore.1 那么玩家就能定义一行lore，0就是不能定义，但是这个数不能超过配置文件中的maxcustomlore）
    resgui.reload 可以使用/resgui reload
    resgui.load    可以使用/resgui load

配置文件

  1. # 插件配置 #
  2. Puginconfig:
  3.   # 领地是否以头颅为图标
  4.   resiconhead: false
  5.   # 如果上面那一项为false，将以下面的物品为图标
  6.   id: 2
  7.   data: 0
  8.   # 是否开启领地lore的上部分的内容 #
  9.   isuplore: true
  10.   # 领地上部分lore
  11.   uplore:
  12.    - '&a所有者：%ResOwner% %ResOwneronline%'
  13.    - '&a领地玩家数量：%PlayerAmount%'
  14.   # 如果是玩家自己的领地，则显示以下lore
  15.   myuplore:
  16.   - '&a这是你的领地'
  17.   - '&a领地玩家数量：%PlayerAmount%'

  19.   # 是否开启领地lore的下部分的内容 #
  20.   isdownlore: true
  21.   # 下面部分的Lore
  22.   downlore:
  23.    - '&e>> 点击传送至该领地 <<'
  24.   mydownlore:
  25.    - '&e>> 点击传送至该领地 <<'

  27.   # 是否允许玩家自定义lore
  28.   iscustomlore: true
  29.   # 玩家自定义Lore行数
  30.   # 这项对权限 resgui.lore.x 起限制作用
  31.   # 若为5 ; resgui.lore.x ; x>5=无效
  32.   maxcustomlore: 1
  33.   
  34.   # 设置玩家自定义Lore禁止使用的字符，多个使用英文“,”隔开
  35.   notallowlore: ''

  37.   # %ResOwneronline% 变量的显示文本，如果改变了字体lore这个变量后面的字体会被覆盖 #
  38.   resOwnerOnline: '&f在线'
  39.   resOwnerOffline: '&8离线'

  41.   # 数据自动保存时间 单位：Tick  1秒 = 20Tick 1分钟 = 1200
  42.   AutoSaveTime: 12000

  44. # 插件文本 #
  45. Language:
  46.     help:
  47.      - '&6------ &e领地帮助 - &6/resgui &e - 页面  &6------'
  48.      - '&2resgui open &6-&e 打开领地列表'
  49.      - '&2resgui open my &6-&e 打开我的领地列表'
  50.      - '&2resgui seek <玩家名> &6-&e 打开一个玩家的领地列表'
  51.      - '&2resgui &2<&a领地名&2> addlore &2<&alore&2> &6-&e 为该领地添加一行lore'
  52.      - '&2resgui &2<&a领地名&2> setlore &2<&a行数&2> &2<&alore&2> &6-&e 修改该领地该行的lore内容'
  53.      - '&2resgui &2<&a领地名&2> removelore &2<&a行数&2> &2<&alore&2> &6-&e 删除该领地该行lore'
  54.      - '&6------------------------------------------------'
  55.     noCommand: '&c命令错误，使用 /resgui 查看指令'
  56.     noPermission: '&c你没有权限执行这个命令'
  57.     noResName: '&c该领地不存在'
  58.     noLineNumber: '&c行数只能为数字'
  59.     noResOwner: '&c您不是该领地的拥有者'
  60.     addLoreSucceed: '&a新增lore成功！'
  61.     addLoreCome: '&clore已到达上限，无法添加'
  62.     setLoreSucceed: '&a设置lore成功'
  63.     setLoreCome: '&c该行lore不存在'
  64.     removeLoreSucceed: '&a删除lore成功'
  65.     removeLoreCome: '&c该行lore不存在'
  66.     reload: '&a配置已重载'
  67.     load: '&a数据已保存'
  68.     notallowlore: '&c您设置的Lore中包含不允许使用的非法字符！'
  69.     noPlayer: '&c该玩家不存在！'
复制代码


Lore 的上下部分是配置文件设置的；中间部分是玩家设置的，保存在data.yml。

Lore可用的变量（玩家自定义也可以使用）：

  # %ResName% =  领地名字
  # %ResOwner% = 领地所有者
  # %ResOwneronline% = 领地所有者在线状态
  # %PlayerAmount% = 领地玩家数量
  # %ResSize% = 领地总大小
  # %ResCreate% = 领地创建时间
  # %ResHighX%  = 领地起始点X坐标
  # %ResHighY%  = 领地起始点Y坐标
  # %ResHighZ%  = 领地起始点Z坐标
  # %ResLowX%  = 领地结束点X坐标
  # %ResLowY%  = 领地结束点Y坐标
  # %ResLowX%  = 领地结束点Z坐标

这个延迟是因为头颅数据是需要向mc官方请求的，因为是国外所以有延迟甚至无法访问，而这个延迟或无法访问 ...

这个加载玩家头颅皮肤会和leaderheads，viaversion插件冲突 会造成瞬间TPS卡到1以下，
修改建议：
1，可配置领地ICON图标，比如纸张，工作台，腐竹自己配置，当配置为非头颅时，则不加载头像皮肤节省资源。
     （我单区有几千个领地，10个玩家同时加载这个菜单并执行翻页时候，服务器直接卡死）
2，在deluxe菜单中执行[player] resgui seek %player_name%时，会在打开的菜单下面出现全部领地按钮，而手动输入则不会出现全部领地按钮，建议档使用resgui seek 无论从菜单 还是手动输入都不显示其他按钮，只有自己的领地，方便作为领地列表使用。
3，当玩家输入/resgui open my 如果玩家没有领地也是可以查看所有领地的 建议档玩家输入/resgui open my时候只可以看自己的领地，当玩家拥有权限时才可以看所有玩家领地，不然总是加载很多领地数量，玩家头颅，特别是调用MYSQL数据库保存领地的服务器会很卡。
4，当玩家左键点击领地图标时是传送，希望可以配置当右键领地图标时候出现领地管理菜单，例如 权限管理/res set 领地名字，添加成员/res padd 领地名 玩家名，删除成员，领地改名，设置领地欢迎语，设置领地tp点等操作。总体来说，将插件的功能发展方向定义为两种功能用途，1作为领地列表，串门用，2作为领地管理的gui菜单提升用户体验。
