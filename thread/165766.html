现在的纹理注册的机制是重写registerIcons方法（在不同版本的forge中方法名可能不大一致，）
（可以在conf 文件夹下的methods.csv文件里找该版本对应的方法名 其中Block的是func_94581_a
Item的是func_94332_a）
默认的材质属性分别是blockIcon和ItemIcon   
比如一般格式为

  2.   @SideOnly(Side.CLIENT)
  3.   @Override
  4.     public void registerIcons(IconRegister par1IconRegister)
  5.     {
  6.         this.itemIcon = par1IconRegister.registerIcon(“文件夹名：文件名”);
  7.     }
复制代码
如果是1.5.×的话需要在mod文件根目录建立
mods/文件夹名/textures/blocks/文件名
mods/文件夹名/textures/items/文件名

如果是1.6.×的话需要在mod文件根目录建立
assets/文件夹名/textures/blocks/文件名
assets/文件夹名/textures/items/文件名
这样对于的材质文件就可以被读取
