标题: 求一款跟指令有关的插件
有没有一款插件是这样的，比如说：玩家有权限使用home指令，但是在聊天框输入/home是无效的，只能通过指令牌子，命令方块，RPGITEM的插入指令功能等来执行，也就是说聊天框限制不能输入什么指令，但是有权限执行，急求[qq]450064700[/qq]
作者: RaycusMX    时间: 2015-2-22 21:57
你要这个功能的话，可以用用 variable triggers 写一个命令trigger叫 home ，命令内容自由发挥，可以设成提示玩家不能从聊天框输入，然后设置 /vtcmdo home true 覆盖原指令内容，这样玩家在聊天框输入的 home 都只会执行你自己添加的内容，而牌子之类不受影响。

作者: TrojanHacker    时间: 2015-2-23 11:58
用脚本方块插件 scriptblock
玩家如果有权限输入home不可能无效，所以把玩家的home权限删除
然后创建牌子或者方块来 触碰或踩踏触发指令
例如/sbinteract create @bypass /home
这个指令绑定在牌子上就可以无视权限执行指令这样
正常情况有权限是不能不执行指令的
