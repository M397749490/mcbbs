ajTNTRun


插件简介

这是一款TNT Run小游戏插件，无需前置插件，使用简单，可进行高度的自定义。

截图




教程

获取更多信息请前往插件Wiki[↗]

  • 创建主大厅
使用命令 /tntrun setlobby 即可，一局游戏结束后玩家们会被传送到此处。

  • 创建游戏场地
首先，你需要有一块符合以下标准的场地：
  • 玩家只能通过传送到达
  • 有由自上到下分别为“任意压力板”“任意方块”“TNT”三层方块组成的地面（见下图）

输入命令： /tntrun createarena <场地名> 。之后选取两个点，站在上面分别使用命令 /tntrun arena <场地名> pos1 和 /tntrun arena <场地名> pos2 ，使用 /tntrun arena <场地名> startloc 设置游戏开始时玩家被传送到的点。
建造一个用于等待游戏开始的空间，输入 /tntrun arena <场地名> lobby ，玩家在加入游戏后将被传送到这里等待游戏开始。
输入 /tntrun arena <场地名> save 保存设置。

  • 加入一局游戏
使用命令 /tntrun join <场地名> 即可加入游戏

  • 创建告示牌
步骤如下：
  • 放置一个告示牌
  • 面向告示牌
  • 使用命令 /tntrun signs add <场地名>


配置文件

config.yml 汉化版
获取更多信息请前往插件Wiki[↗]

  1. # 请不要修改这个
  2. # 注意：这是配置文件版本，而不是插件版本
  3. config-version: 7

  5. # 开始游戏需要的最低玩家数量
  6. #  默认为 2
  7. min-players: 2

  9. # 当玩家数达到最低要求后的倒计时等待时间
  10. #  默认为 30
  11. lobby-countdown: 30

  13. # 玩家被传送到游戏场地后游戏开始前的倒计时时间
  14. #  默认为 10
  15. plate-countdown: 10

  17. # 游戏结束后，将玩家传送回大厅前倒计时的时间
  18. #  默认为 10
  19. end-duration: 10

  21. # 是否允许玩家互相攻击
  22. #  默认为 true
  23. block-pvp: true

  25. # Bungee模式（服务器上必须有一个游戏场地）
  26. #  默认为 false
  27. enable-bungee: false
  28. # 当游戏结束或玩家离开时将玩家传送到的服务器
  29. bungee-remove-to: lobby


  32. # 在游戏开始后禁止玩家使用命令
  33. # 如果要允许玩家使用命令，需要把block-commands设置为false
  34. #  默认为 true
  35. block-commands: true
  36. allowed-commands:
  37. - atr
  38. - tntrun
  39. - tr
  40. - msg
  41. - r
  42. - w
  43. - whisper
  44. - tell

  46. # 是否开启自动更新
  47. #  默认为 true
  48. enable-updater: true

  50. # 是否通知管理员有新更新
  51. #  默认为 true
  52. notify-update: true

  54. # 使用什么速度回滚游戏场地
  55. # 数字越大 = 回滚速度越快 = 对服务器造成的压力越大
  56. #  默认为 20
  57. rollback-speed: 20

  59. # 倒计时提示音
  60. # 需要是Minecraft中的声音
  61. # 分号后的数字是音高
  62. #  默认为 block.note_block.pling;2
  63. pregame-countdown-sound: block.note_block.pling;2

  65. # 游戏开始提示音
  66. # 需要是Minecraft中的声音
  67. # 分号后的数字是音高
  68. #  默认为 entity.ender_dragon.growl;1
  69. game-start-sound: entity.ender_dragon.growl;1


  72. # 是否允许玩家在游戏场地重置时加入等待大厅
  73. # （需要设置对应的等待大厅）
  74. #  默认为 true
  75. allow-join-while-resetting: true

  77. # 方块消失的时间
  78. # 单位是ticks，所以20 = 1秒.
  79. # 不建议更改此选项
  80. #  默认为 10
  81. block-fall-delay: 10

  83. # 玩家在空中多久后将其判为失败
  84. #  默认为10
  85. air-eliminate-time: 10


  88. # 是否开启调试模式
  89. # 将输出额外的调试信息，这可能对开发人员寻找错误有所帮助
  90. #  默认为 false
  91. debug: false

命令&权限

命令描述权限
/tntrun join 加入一局游戏
/tntrun leave 退出一局游戏
/tntrun stats 查看自己或其他玩家的统计数据
/tntrun list 查看所有可用的游戏场地
/tntrun createarena 创建一个游戏场地并将它添加到编辑队列中 ajtr.setup
/tntrun editing 列出编辑队列中的游戏场地 ajtr.setup
/tntrun edit 将游戏场地加入到编辑队列中来 ajtr.setup
/tntrun reload 重载插件 ajtr.reload
/tntrun signs 告示牌管理命令 ajtr.setup
/tntrun start 强制开始一局游戏 ajtr.forcestart
允许使用游戏进行中禁止使用的命令 ajtr.bypasscommands

可以使用以下命令代替/tntrun
  • /ajtntrun
  • /atr
  • /tr
