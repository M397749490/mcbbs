简介
PrisonRanksX is a plugin that adds prison ranks with many features. also, It can be used in a non-prison server. you can have both ranks the vault rank aka permissions rank [pex, lp, gm, etc...] and the prison rank [a,b,c,d] It doesn't mess with them it typically has its own system. and the best thing that it works from 1.5 to 1.15.
PrisonRanksX是一个插件，它在监狱等级的基础上增加了许多的功能。此外，它还可以用于非监狱风云的服务器。这个插件可以让你可以同时拥有不同的金库等级，也可以是不同的权限等级[pex，lp，gm…]以及监狱等级[a，b，c，d]。从1.5到1.15，这款插件始终是更好的（论坛不能用最好的，就把这个更好的替换成最好的看，别骂我机翻了！！！）。

- MySQL Player Data Reader

- Rankup firework
- Animated actionbar upon rankup
- Custom formatted balance
- Support from 1.5 to 1.15

聊天插件变量（支持大多数聊天插件）
{rank} => shows rank display name/prefix
{prestige} => shows prestige display name/prefix
{rebirth} => showws rebirth display name/prefix
{rank} => 展示当前等级的显示名称/prefix
{prestige} => 展示当前声望等级的显示名称/prefix
{rebirth} => 展示当前重生等级的显示名称/prefix
依赖
- Vault [Required]
- Economy plugin such as Essentials, IConomy, MWEconomy [Required]
- PlaceholderAPI [Optional] [to use papi placeholders in plugin messages or use prisonranksx papi placeholders in other plugins]
- HolographicDisplays [Optional] [to spawn a hologram above your head when you rankup]
- MVdWPlaceholderAPI [Optional] [to use prisonranksx placeholders in MVdW Plugins]
- ActionUtil [Optional] [to use several actions provided from the plugin when you rankup or prestige up]
- Vault [必须]
