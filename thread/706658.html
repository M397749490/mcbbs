这个插件呢
作用是把2个或以上的箱子连接在一起
一个母箱子和一堆子箱子
当你对子箱点右键时
显示的会是母箱的内容


教学：

首先你需要一个母箱子

输入指令“/ sc main 1”拿到母箱

记录下它的ID

然后输入指令“/ sc link {子箱ID} {母箱ID}”就完成啦！


指令:

获得母箱：/sc main [数量]
获得子箱：/sc related [数量]
获得资料棒：/sc tool
连接箱子：/sc link [子箱ID] [母箱ID]
取消連接:/sc unlink [子箱ID] [母箱ID]


  权限:

/sc help   展示帮助列表  sc.help

/sc main [数量] 获得母箱  sc.chests

/sc related [数量]  获得子箱  sc.chests

/sc tool 获得资料棒  sc.tool

-使用这些连接的箱子  sc.use

-连接箱子  sc.link
