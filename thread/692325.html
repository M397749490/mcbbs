作者: LRual    时间: 2017-5-14 20:48
找到工业2配置文档（\.minecraft\config\IC2.ini）
打开,并找到以下这一列：


  2. [balance / energy / generator]
  3. generator = 1.0
  4. geothermal = 1.0
  5. ; Deprecated, because of Kinetic Watermill
  6. water = 1.0
  7. solar = 1.0
  8. ; Deprecated, because of Kinetic Windmill
  9. wind = 1.0
  10. nuclear = 1.0
  11. semiFluidOil = 1.0
  12. semiFluidFuel = 1.0
  13. semiFluidBiomass = 1.0
  14. semiFluidBioethanol = 1.0
  15. semiFluidBiogas = 1.0
  16. Stirling = 1.0
  17. Kinetic = 1.0
  18. radioisotope = 1.0
复制代码


把
  1. wind = 1.0
复制代码

修改为
  1. wind = 0.5
复制代码

关闭并保存重启MC（服务端/客户端）
从而达到发电量减半的效果
