以背包上的物品决定重量，以重量决定移动速度。
作者貌似已经停止更新



亲测1.7.10 MCPC 有用

特性:
★自定义物品重量
★在经验栏显示重量百分比（可能会导致无法正常获取经验的bug，建议关闭）
★降低移动速度按重量百分比
★显示状态变化的信息(可关闭)

指令:
/pw reload - 重载配置文件

/pw debug

/pw - 显示当前体重
权限:
PlayerWeight.bypass - 拥有所有权限。
PlayerWeight.reload - 允许使用/pw reload
PlayerWeight.debug - 允许使用/pw debug
配置:

#定义最大重量，这将决定您所能携带的物品重量!
Max Weight: 180
#使用经验栏显示背包重量!请关闭该功能，否则将导致玩家无法通过正常途径获取经验
Enable XP Bar: true
WeightCommand: '&6[&7系统提示&6] &2您目前的体重是 &6<weight>&2/&6<maxweight> &2(&6<weightpercent>%&2)'

#禁用消息, false 为开启!
Disable Messages: false

Less And Equal To:
#当重量达到 24 %,系统将提示玩家!
  Percentage: 24
#当达到以上重量,则移动速度为 105% .
  SpeedPercent: 105
  Message: '&6[&7系统提示&6]&a 您的背包还很轻!'
Between:
  Percentage: 25,49
  SpeedPercent: 95
  Message: '&6[&7系统提示&6]&2 变得越来越重，要小心!'
Between1:
  Percentage: 50,100  
  SpeedPercent: 70
  Message: '&6[&7系统提示&6]&7你是沉重的，试着减肥!'
Bigger Than:
  Percentage: 100
  SpeedPercent: 50
  Message: '&6[&7系统提示&6]&4 哦，不！你做了什么!'
