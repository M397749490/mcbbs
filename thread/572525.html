FaceChat
让你发送的聊天信息更高大上!
插件简介
一个聊天信息就可以占满聊天框
自定义人脸显示以及字显示
独特的玩家加入服务器信息
发多了可能会比较占用服务器资源
权限节点
/facechat reload - 重载插件 - facechat.reload
/facechat [player:<PlayerName>] <message> - 使用指定玩家的脸发送消息 - facechat.command.player
/facechat <message> - 使用自己的连来发送消息 - facechat.command
- facechat.chat - 拥有此权限的玩家输入消息时强制变为使用自己的脸发送消息
- facechat.join - 拥有此权限的玩家，加入服务器时会有特殊的消息
插件截图
配置文件（已汉）
#不要修改
general:
#开启/关闭自动更新【true=开启,false=关闭】
  check-updates: true
#不要修改
face:
# 玩家皮肤大全
  skin-url: http://s3.amazonaws.com/MinecraftSkins/
#每一条信息中间的间隔信息
  separator: '&8++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++'
#皮肤缓存时间【建议不修改】
  cache-lifetime-(minutes): 30
#默认字体颜色
  default-color: '&e'
#不要修改
  chat:
#是否开启所有的信息都为人脸信息【建议关闭，否则消息过多会卡服】
    enable-for-chat-messages: false
#玩家输入的消息从第x行开始显示【0-7】
    message-start-line: 3
#不要修改
    message:
#以下为消息的排版，消息前会显示一个人脸【排版最多可以设置8行】
    - '&6&l%player%'
    - +--------------------------------------------------+
    - ''
    - ''
    - ''
    - ''
    - +--------------------------------------------------+
    - '&6&lFaceChat plugin by fromgate'
#不要修改
  join:
#是否显示加入信息【提前必须拥有facechat.join权限】
    show-join-message: true
#是否删除原版加入信息【推荐删除】
    remove-default-join-message: true
#不要修改
    message:
#以下为消息的排版，消息前会显示一个人脸.
    - ''
    - +--------------------------------------------------+
    - ''
    - '&6&l%player%&ejoined the game!'
    - ''
    - ''
    - +--------------------------------------------------+
    - '&6&lFaceChat plugin by fromgate'
