  • 所有提示消息可自定义
  • 通过一个gui来管理你的好友
  • 可以与你的朋友进行聊天 (可以关闭)
  • 好友加入/退出提示
  • 可使用指令传送至你的好友
  • UUID-支持
  • 可查看玩家是否在线？-支持
  • 你可以屏蔽玩家的好友请求
  • 多个好友请求从不同的玩家
  • MySQL or Flat-File
  • 你可以看到你的好友最后下线的时间
  • 100% 可配置
  • 无限的朋友？
  • 支持版本:1.7.X - 1.9.X
  • 可点击的消息 (只有1.8.3或者更高的版本拥有)
  • 你可以启用 "删除验证" 后面会介绍
唯一权限:

  • - Friends.Use
指令:

  • /friends add <Player>   向该玩家发送好友请求
  • /friends remove <Player>   将该玩家移出你的好友列表
  • /friends accept <Player>   同意该玩家的好友请求
  • /friends deny <Player>    拒绝该玩家的好友请求
  • /friends block <Player>   屏蔽该玩家的好友请求
  • /friends unblock <Player>   解除对该玩家的屏蔽
  • /friends jump <player>   传送至该玩家(似乎想要添加了好友才可以)
  • /friends list    查看好友列表




配置讲解:




  •   Prefix:  就是插件名
  • CheckForUpdates: true 检查插件是否想要更新
  • EnableJumping: false  是否开启 /friends jump 指令
  •   FriendChat:
  •       Enable: true  是否开启好友聊天
  •       Code: "@好友聊天"  这个就是 在聊天框前面 加上 @好友聊天  你想说的话 这样你的话就会发送给全部好友看了
  •   Options: 选项
  •       FriendCanPvP: true   好友是否可以互相伤害
  •       HitToRequest: false  如果这是启用的,玩家可以打别人好友物品发送一个人请求 机翻
  •       CanDropItem: false  如果这是启用的,玩家可以丢弃好友物品 机翻
  •       CanPlaceItem: false  如果这是启用的,玩家可以放置好友物品 机翻
  •       CanMoveItem: false  如果这是启用的,玩家可以移动好友物品 机翻
  • LastOnline: 最后在线时间设置
  •       Enable: true    是否开启
  •       Format: "&c最后在线时间: &3%days% 天, %hours% 时 %minutes% 分"   %days% 为天%hours%为时 %minutes%为分 %seconds%为秒
  • RemoveVerification: false   这就是删除好友验证  就是删除好友的时候会提醒你是不是还要删除这个好友(应该把qaq)
  • FriendItem:   好友系统物品
  •     Name: "&3好友系统 &7(右键)"   物品名字
  •     ItemID: "397:3" 物品ID
  •     Lore: "&7右键打开好友系统菜单" 物品lore
  •     PlayersHead: true  如果你启用这个选项,头颅将会是玩家的头颅
  •     GiveOnJoin: false  是否在玩家加入游戏的时候给予这个物品
  •     InventorySlot: 9  给予的时候放置在快捷栏第几格
  • GUI:
  •     Enable: true 是否开启gui
  •     PlaySoundOnOpen: false   玩家打开音效？
  •     PlaySoundsOnInteract: true
  •     Title: "&a好友列表:"     这个可以自定义的  这个是显示在/friend 打开gui菜单后的菜单名字
  •     InventorySize: 54    菜单格数
  •   后面都是菜单的自定义  会一并发出来
