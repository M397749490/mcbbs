玩家指令：
/pet help   查看帮助界面
权限：echopet.pet

/pet (宠物类型）   召唤宠物
权限：echopet.pet.type.(pet)

/pet remove   取消宠物
权限：remove        echopet.pet.remove

/pet list    查看宠物种类
权限：echopet.pet.list

/pet info   查看目前宠物消息
权限：echopet.pet.info

/pet ride    坐骑模式可以骑乘你的宠物
权限：echopet.pet.ride.(pet)

/pet hat    宠物出现在你的头上
权限：echopet.pet.hat.(pet)

/pet name (名称)    修改宠物名称
权限：echopet.pet.name

/pet mount (类型):[数据]     换宠物坐骑类型
权限：echopet.pet.type.(mount)

/pet name mount (名称)     换宠物坐骑名称
权限：echopet.pet.name

/pet mount    取消你目前的坐骑类型
权限：remove        echopet.pet.remove

/pet default set (类型)    设置默认宠物类型
权限：echopet.pet.default.set.type.(pet)

/pet default set current     设置默认宠物坐骑类型
权限：echopet.pet.default.pet.set.current

/pet default remove     取消默认宠物类型
权限：echopet.pet.default.remove

op指令：
/petadmin help      查看OP宠物指令
权限：echopet.petadmin.help

/petadmin (玩家) (宠物类型)     给予玩家宠物
权限：echopet.petadmin.type.(type)

/petadmin remove (玩家)      取消玩家宠物
权限：echopet.petadmin.remove

/petadmin list     宠物表列
权限：echopet.petadmin.list

/petadmin info (玩家)     查看玩家信息
权限：echopet.petadmin.info

/petadmin ride (玩家)     强行让玩家骑上宠物
权限：echopet.petadmin.ride.(pet)

/petadmin hat (玩家)     强行将宠物放到玩家头上
权限：echopet.petadmin.hat.(pet)

/petadmin name (玩家) (宠物名称)     强行修改玩家宠物名称
权限：echopet.petadmin.name

/petadmin mount (玩家) (类型)     设定玩家坐骑类型
权限：echopet.petadmin.type.(mount)

/petadmin name (玩家) mount (名称)     设定玩家坐骑名称
权限：echopet.petadmin.name

/petadmin mount （玩家) remove     取消玩家坐骑
权限：echopet.petadmin.remove

/petadmin default (玩家) set (类型)     设定默认玩家宠物类型
权限：echopet.petadmin.default.set.type.(pet)

/petadmin default (玩家) set current    设定默认玩家...
权限：echopet.petadmin.default.pet.set.current

/petadmin default (玩家) remove      取消默认设定
权限：echopet.petadmin.default.remove

blaze:
#烈焰人
    enable: true#是否激活召唤该动物
    tagVisible: true#昵称可见
    defaultName: Blaze Pet#召唤出来的宠物名字
    interactMenu: true#是否激活主界面
    startFollowDistance: 12#开始更随的距离
    stopFollowDistance: 8#停止更随的距离
    teleportDistance: 50#最大传送距离
    attack:#伤害配置
      canDamagePlayers: false#是否可以攻击玩家
      lockRange: 10#同步范围
      ticksBetweenAttacks: 20#攻击间隔时间
      damage: 6.0#伤害
      loseHealth: false#是否拥有宠物血量
      health: 20.0#宠物的最大血量
    rideSpeed: 0.25#骑乘的速度
    jumpHeight: 0.6#跳跃的高度
    canFly: true#是否可以飞行
    allow:#允许事件
      mounts: true#骑行
      fire: true#着火

      fire: false#着火

怎么分配举一个例子
作者: 极光先生    时间: 2017-1-23 18:27

怎么分配举一个例子

嗯，举例子：
安装完宠物插件后，你需要给玩家分配允许捕捉宠物的权限：
（假设当前玩家都是builder权限组），则输入如下指令：
/mangaddp builder MyPet.leash.生物英文名
假设给玩家可以捕捉牛的权限，则输入：
/mangaddp builder MyPet.leash.Cow
这样处于builder权限组的玩家就能够使用栓绳捕捉牛作为自己的宠物了
如果你想要给玩家能够捕捉全部生物的权限，
就把MyPet.leash.Cow替换成MyPet.leash.* 。这个是允许捕捉所有生物的权限。
关于宠物插件的大部分权限可以在我提供的网址里面查看，自行添加给玩家
