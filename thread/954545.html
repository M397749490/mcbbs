第二节
首先 先讲下本文以后出现的名词 生活化的解释
属性、方法、对象、返回值

属性: 如你的名字、性别、年龄这些就是你的属性
如 你的名字叫张三 性别为男 年龄为10岁

方法: 也叫做函数 可以理解为一个动作的执行
如 你问你朋友名字 或 你给你朋友取一个外号 这就是一个方法

对象: 理解为一个 人  这个人有 他有许多的属性 和 方法 我们可以通过这个人来获得他的一些属性 和 方法
如 你的一位朋友 你的一位同学

返回值: 就是执行一个方法 返回给你的东西
如 你问你朋友名字 他回复张三  则 张三就是返回值

理解了上面这几点 就可以看接下来的搭建框架部分了

我们想一下 获取的为true就是可飞行 然后我们设置为他相反就是关闭飞行 所以我们要用到

e.getPlayer().setAllowFlight(!e.getPlayer().getAllowFlight());

如果你的版本>=1.13报错了并且有以下
java.lang.IllegalStateException: Asynchronous player tracker update!
那么只需要将

e.getPlayer().setAllowFlight(!e.getPlayer().getAllowFlight());

改成
Bukkit.getScheduler().runTask(this, new Runnable() {
@Override
public void run() {
       e.getPlayer().setAllowFlight(!e.getPlayer().getAllowFlight());
}
});
作用是将此代码同步在主线程运行 涉及到玩家某些操作如果异步将会产生某些错误 所以高版本将会抛出
Asynchronous player tracker update!
