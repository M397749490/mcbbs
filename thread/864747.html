那就先把 Slot 删掉【

data merge block <临时箱子> {Items:[{id:"minecraft:stone",Count:1b,tag:{Items:[]}}]}
data modify block <临时箱子> Items[0].tag.Items set from entity @p Inventory
data remove block <临时箱子> Items[0].tag.Items[].Slot

然后再
data modify block <第一个箱子> Items append from block <临时箱子> Items[0].tag.Items[0]
...
这样的【
