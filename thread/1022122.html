下载
    游戏版本1.9.x-1.12.x
        插件本体：建议使用远古工艺重置版v4.1.15 请自行到原帖下载
        前置：CS-CoreLibv1.5.18 (看好版本下啊！)
    游戏版本1.13以及更高
        插件本体：可使用远古工艺重置版或粘液科技v4.2版 前者请使用v4.1.17 后者请使用v4.2或更高
        前置：前者使用CS-CoreLibv1.6 后者我没用过待补充，也许可以用最新版？
安装
    一套不解释连招将插件本体以及前置拖入服务端目录内/plugins/文件夹中，重启后即可
配置文件篇
    config.yml(只选取部分讲解，别问问就是懒)(该配置文件摘自远古工艺v4.1.15版本，其它版本应该也适用...吧)
        auto-update:true 自动更新，远古工艺版本请关闭，其它版本自行斟酌
        give-guide-on-first-join: true 是否在给予新玩家粘液科技书，某些情况需要关闭(见各种常见及不常见问题以及变头问题解决篇)
        prefix: '&a&l远古工艺 &7>' 插件前缀，可自行更改 如 xx服务器远古工艺
        auto-save-delay-in-minutes: 10 自动保存间隔
        research-unlock-fireworks: true 解锁物品后是否放个烟花庆祝
        items:
            talismans: true 是否启用护身符
            coolers: true 雾
            backpacks: true 是否启用背包
    其它配置文件会在插件自定义篇里说明
物品禁用篇
    1.查询物品id
        远古工艺重置版：
            拥有op权限的玩家打开远古工艺书，点入需要禁用的物品，左下角可看到物品id
        其它情况
            1.使用插件查询(我没试过，扩展不确定能不能查询)
            2.根据中文字面意思翻译猜物品id
            3.使用已有id对照表查询(扩展物品id不全)
    2.禁用物品
        1.打开服务端目录/plugins/Slimefun/Items.yml (建议使用Notepad++打开，实在不行记事本)
        2.Ctrl+F 搜索步骤1中找到的物品id
        3.这时你看到的应该是这样的:
        将 enable:true 改为 enable:false 即可
    3.自行检验啦
Bug修复篇
     部分bug新版本可能已修复，请自行斟酌
    1.必备插件修复:
        修复插件两件套:1 2
    2.自动附魔台刷头颅bug修复
        原理：在附魔台内放入绑定附魔或诅咒附魔附魔书和要刷的头颅
        解决方案：
            1.ban掉附魔台
            2.ban掉绑定、诅咒附魔附魔书 使用Banitem with NBT
            3.在item.yml中将所有头颅设定为不可附魔(详见插件自定义篇)
            4.定制修复插件
     3.物品放置机bug
         原理：利用物品放置机各种奇怪的特性加上红石刷物品(具体方法很多)
         解决方案：
             1.ban掉物品放置机(修复十分麻烦)
             2.定制修复插件
    4.插件向导书刷物品bug
        原理：背包里放个向导书内有的物品，打开向导书，双击背包内的物品便可拿出向导书内物品
        解决方案：
             1.安装修复插件(见Bug修复篇1)
             2.安装禁用客户端快捷键插件(尚未实测，不过这玩意能修些别的bug)
    5.向导书卡服
        原理：部分服务器蹲下右键向导书后出现的界面设置菜单中，点击版本信息可能会导致卡服重启
        解决方案：
            1.禁用向新玩家给予向导书并禁止玩家使用/sf guide指令(详见配置文件篇)，使用/sf open_guide打开插件向导书(权限节点为slimefun.command.open_guide)
            2.魔法上网
    6.部分版本自动铁毡以及多功能工具刷物品bug
        原理：不解释
        解决方案：
            1.ban自动铁毡多功能工具
            2.定制修复插件
    7.连点器＋采矿机/高级采矿机刷矿
        原理：连点器刷就对了
        解决方案：
            1.ban采矿机/高级采矿机
            2.将采矿机/高级采矿机设置为需使用权限
            3.安装放连点器插件(至少我是没成功过，原版物品连点是防止了，粘液机器的没能防住)
    8.推荐ban的物品汇总也就是我懒得写原理(部分版本部分物品可不ban，自行斟酌)
        精准之镐 爆炸镐 地震斧 矿脉镐 方块放置机 维度卷 知识共享巨著 自动铁毡 自动附魔机 彩虹玻璃方块等 所有背包 多功能工具 经验收集器 全息显示器 猎人护身符 魔法师护身符 远古基座
    x.想起来会补的，还有很多
插件自定义篇
    服务端目录/plugins/Slimefun/items.yml
        以斩首剑为例子：
        
        enabled: true 是否能用这个物品
        can-be-used-in-workbenches: false 是否能参与合成(指原版合成，比如把24K金块的改为true，那么24K金块将可以参与原版合成，即可以分解为9个金锭等)
        hide-in-guide: false 是否在向导书内隐藏
        allow-enchanting: true 是否允许附魔
        allow-disenchanting: true 是否允许扣去附魔
        required-permission: '' 使用需要权限(比如 '' 中填example1，则拥有example1权限的玩家才能合成或使用斩首剑，该项未详细测试)
        上面是大部分的物品都有的，可更改的参数，但部分物品如斩首剑、部分护身符、淘洗盘、炼制厂等还拥有特定参数，以斩首剑为例子：
        chance:
            PLAYER: 70
            SKELETON: 40
            WITHER_SKELETON: 10 凋零骷髅额外掉头几率
            ZOMBIE: 40
            CREEPER: 40
        这些便是自定义掉头几率，可自行修改为0-100的数值
        其他特殊物品特殊参数自行理解会慢慢补充
    服务端目录/plugins/Slimefun/Researches.yml
        name：exampleid 该物品的id，请不要随意修改
        cost：1 开启该物品需要等级
        enable：true 是否可以花费经验开启该物品
    服务端目录/plugins/Slimefun/whitelist.yml
        exampleworld：在example世界的设置
            enable：true 是否在该世界启用粘液科技
            enable-items：
                exampleitem：false 物品id为 exampleitem 在世界 exampleworld 不可用
    服务端目录/plugins/Slimefun/generators/下界玄冰.cfg|原油.cfg
        存储了各个生物群系的原油|下界玄冰的储量
        可使用Notepad++打开
        游戏内F3可查看当前区块生物群系名称
    服务端目录/data-storage/Slimefun内各种文件夹(真干货)
        至少我没搜到过讲这些东西的教程
        1.Players文件夹
             存储了玩家解锁了的物品以及玩家制造的背包、冰箱等容器内存储的物品
             以玩家UUID为文件名
             下面是一个例子
            
            researches:
              '30': true 30对应的粘液物品id可在 服务端目录/plugins/Slimefun/Researches.yml 内找到 这里是玩家解锁了 30 所对应的粘液物品
             backpacks:
              '0':
                size: 27 背包/冰箱容量大小，请使用9的倍数，避免出现奇怪的现象
                contents:
                  '0'：下面便是背包/冰箱内存储的物品，请不要随意更改，避免***
        2.stored-blocks文件夹
            存储了各个世界的粘液物品，请不要随意更改，删除会导致粘液头颅失效
        3.stored-chunks文件夹
            存储各个区块内的原油/下界玄冰被开采的情况
            可删除该文件来重置呃 也就是玩家们把资源肝完时(也不太可能)可以删除这个文件
        4.stored-inventories文件夹
            存储各个世界内粘液机器内物品(玩家肝起来了这里面便大部分都是运输机器)
            还是那句话别随意更改
        5.waypoints文件夹
            存储玩家的GPS传送点
            以玩家UUID为文件名

各种常见及不常见问题以及变头问题解决篇
    1.Residence领地权限问题
        1.玩家可以打开别的玩家的领地内的粘液机器，需玩家将领地flag中的sf-machines节点设置为false或在默认节点中将该节点设置为false(Residence中默认的true，导致玩家可以打开别的领地内的粘液机器)
        2.经测试，远古工艺v4.1.15版本中粘液机器人无法无权限进入他人领地破坏，其他版本有待测试 懒
    2.与Quickshop兼容问题
        测试服务器中同时安装quickshop与远古工艺以及各修复插件后，可能会导致后台报错、熔炉刷物品
    3.插件向导书内头颅不显示头颅皮肤 全是骷髅头
        1.检查插件本体、前置版本是否正确
        2.在客户端安装CustomSkinLoader皮肤补丁mod
    4.玩家背包丢失
        1.让玩家再做一个背包出来
        2.找出玩家UUID，可通过让玩家重新进入服务器获得或其他途径
        2.然后将原丢失的背包内物品复制到新背包内(详见插件自定义篇)
    5.变头问题解决
        1.每次启动服务器前删除 服务端目录/data-storage/Slimefun/stored-blocks 内以服务器内世界为名字的文件夹内的 null.sfb 文件(可解决一部分变头现象)
        2.定制修复插件(可解决绝大部分变头现象)
    6.An internal error occurred while attempting to perform this command报错
        1.检查插件本体、前置版本是否正确
    7.出现隐形盔甲架，无法放置方块
        1.安装修复插件(谨慎使用，尽量少使用清除世界指令)
