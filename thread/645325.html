FlexPipe
稳定 - 安全 - 高速


FlexPipe是什么？ | （What is it?）
FlexPipe是基于BungeeCord制作的一个服务器代理系统,可以让玩家多Minecraft服务器之间进行传送, 能够更好的兼容Spigot服务器(和其衍生端如PaperSpigot TacoSpigot等).它可以使客户端进行服务器传送时如同世界传送一样迅速[sup]1[/sup]

注[sup]1[/sup]: 根据原文所述应该是指玩家在跳转服务器时看起来就像是在同一个服务器上进行世界传送
原文地址: https://github.com/minotopiame/FlexPipe




特性 | （Features）
  • 尽早加入可调节应用[sup]1[/sup]
  • 调节在一些插件中Tab补全可能会出现过载的问题
  • > Differentiate between pings ad joins in logging, possibility to turn off ping logging
  • > Allow modification of the module source url
  • 增加相关选项可关闭模块的下载或更新
  • 调整Netty的值至最优[sup]2[/sup]
  • 可以调整BungeeCord的提示信息并且不需要内核修改
  • 解决可能出现的假死问题
  • 对核心进行部分优化
  • 控制台输出较少的无效数据包信息
  • 没有半秒延迟的关闭与客户端的连接
  • 兼容较老的Ping工具 如1.8版本
  • 验证压缩数据包的压缩阈值[sup]3[/sup]
  • 聊天时进行更严谨的验证
  • 异常行为检测API
  • 通过动态加载类来加速事件的处理（比反射更快）
  • 不会复制内存在可能的地方> Don't copy memory where possible
  • 大量减少在使用记分板插件时所创建的许多团队的内存占用
  • 允许控制台进行Tab补全

注[sup]1[/sup]: 原文为“Join throttle applied as early as possible”,意思应该是新增一些可自定义的配置文件
注[sup]2[/sup]: Netty 是一个基于NIO的客户、服务器端编程框架，是Mojang使用的客户端与服务器传送的框架
注[sup]3[/sup]: 根据原文所述应该是指对客户端发送的数据包进行数据包大小的验证
