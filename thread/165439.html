游戏未响应有以下几种情况
I·
ava未安装，MC启动器无法启动MC
II·
安装MOD出现错误，MC启动黑屏
III·
安装MOD数量较多，加载时间较长。



解决方案
I·
去下面之后链接下载并且安装与你系统版本兼容的java
然后重新启动MC
java.com: Java 与您
http://www.java.com/zh_CN/
II·
①下载纯净包重新安装各类API与MODs
然后重新启动MC
②更换一个新的懒人包
可以去下面这个链接下载
懒人包发布&#160;-&#160;Minecraft中文论坛 - Minecraft资讯|MOD|联机|皮肤|材质|作品 http://www.mcbbs.net/forum-modpack-1.html
III·
删减一些不会用到的MOD
然后重新启动MC


在下曾经用过苍燚的懒人包
从启动MC到进入主菜单界面需要20分钟


另外·
如果是新建世界未响应·
很多懒人包有个错误
在新建超平坦世界的时候MC会进入未响应状态
发生这种情况时
只要等待5分钟（为了确保世界已经生成，当然你也可以在.minecraft\saves文件夹下面看是否有你创建世界的文件夹来确认），然后结束MC的进程（关掉MC）
然后再次进入MC即可

当然你也可以选择 非超平坦地形的世界
比如默认，或者巨型生物体系


码字用时15+分钟
如果问题解决了设为最佳
未解决继续提问
