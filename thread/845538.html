K_bai's Block Brush



这个数据包是为了满足RookieXhand的要求专门写的一个建筑用数据包，主要功能是提供一个可变的笔刷和橡皮，用于绘制小型地形。

它主要的功能就是在玩家面前创建一个画笔，可以以画笔为中心改变方块。画笔与玩家距离可通过计分板命令调整，且可将画笔锁定在某一平面移动，方便绘制。


用法很简单：
  • 在你的地图里新建填充笔刷和橡皮笔刷
    • 这两个笔刷都是5*5*5的
    • 填充笔刷就是一坨方块，其余部分是空气
    • 橡皮笔刷就是一坨空气，其余部分是任意其他方块
  • 打开数据包中的 draw:brush/place 和 draw:brush/eraser，分别把填充笔刷和橡皮擦笔刷的坐标填进去
  • 在游戏中执行 function draw:init，对数据包初始化
  • 高频执行 function draw:tick
  • 想使用画笔的玩家执行 function draw:join，需要OP权限
  • 小心使用，无撤销功能
