介绍
GadgetsMenus是一个娱乐性趣味道具
是每个小游戏服务器大厅的推荐的插件，它不仅仅是用来玩耍
还能激起玩家的收集道具乐趣，大大拓展趣味性
互赠礼物，抽奖礼盒等


特色
|- 寻找礼盒
|- 动画效果
|- 礼物系统
|- 轻松配置
|- 购买系统
|- 套装技能
|- 自定义道具
|- 神秘的礼盒
|- 可自定义消息
|- 加入给予菜单
|- 可命名宠物名字
|- 支持Vault & PlayerPoints
|- 支持占位符（Placeholders）
|- 支持数据库MySQL
|- 更新检查 / 经常更新
|- 还有更多...


命令权限

  • 推荐权限
  • gadgetsmenu.menuselector   #玩家进服自动获得趣味道具菜单
  • gadgetsmenu.mysteryboxes.open.*   #允许玩家使用不同品质礼盒
  • gadgetsmenu.animations.*   #允许玩家自行开启/关闭动画效果（开箱子动画）

  • 命令参数（必看）

- [道具]
    请填 Hat/Particle/Suit/SuitHelmet/SuitChestplate/SuitLeggings/SuitBoots/Gadget/Pet/Morph/Banner/Emote/Cloack
- [类型]
    请填 （在 plugins\GadgetsMenu\categories\道具.yml 可以找到）
    例子 打开 hats.yml 可以看到 Hamburger（这就是类型）
- [重置道具选填]
     请填 all/道具 （all为所有道具，道具请看上面[道具]）
- [重置玩家选填]
     请填 all/玩家 （all为所以玩家，玩家为指定玩家）
- [品质]
    描述 礼盒品质（一般的，数字越大礼包内容越好）
    请填 数字 （1至5）
- [日期]
    描述 保质期（过了就过期）
    请填 ex=7h/d/m/false （ex=时/天/分/永久）

  • 主命令

命令 权限 描述 后台可用
/gmenu about gadgetsmenu.commands.about 插件信息 是
/gmenu checkupdate gadgetsmenu.commands.checkupdate 检查插件更新 是
/gmenu equip <道具> <类型> [玩家]
 gadgetsmenu.commands.equip 给玩家装备指定道具 否
/gmenu help gadgetsmenu.commands.help 插件帮助 是
/gmenu main 打开主菜单 否
/gmenu menu <道具> 打开某菜单 否
/gmenu namepet <名字> gadgetsmenu.commands.namepet 重命名宠物名 否
/gmenu permission <道具, 命令> gadgetsmenu.commands.permission 列出权限列表 是
/gmenu reload gadgetsmenu.commands.reload 重载插件 是
/gmenu reset <重置道具选填> <重置玩家选填> gadgetsmenu.commands.reset 重置道具 是

  • 趣味的碎片命令

命令 权限 描述 后台可用
/mysterydust add <玩家> <数量> gadgetsmenu.mysterydust.add 添加玩家碎片 是
/mysterydust check <玩家> gadgetsmenu.mysterydust.check 查看玩家碎片 是
/mysterydust pay <玩家> <数量> gadgetsmenu.mysterydust.pay 支付玩家碎片 否
/mysterydust remove <玩家> <数量> gadgetsmenu.mysterydust.remove 扣除玩家碎片 是
/mysterydust set <玩家> <数量> gadgetsmenu.mysterydust.set 设置玩家碎片 是

  • 神秘的礼盒命令

命令 权限 描述 后台可用
/gmysteryboxes check [玩家] gadgetsmenu.mysteryboxes.check 查看玩家礼盒数量 是
/gmysteryboxes gift <玩家> <包数> gadgetsmenu.mysteryboxes.gift 给玩家礼盒礼物包 是
/gmysteryboxes give <玩家> <数量> [品质] [日期]
 gadgetsmenu.mysteryboxes.give 给玩家礼盒 是
/gmysteryboxes giveall <数量> [品质] [日期] gadgetsmenu.mysteryboxes.giveall 给所有在线玩家礼盒 是
/gmysteryboxes mode gadgetsmenu.mysteryboxes.mode 显示礼盒操作命令 否

注意事项 & 常见问题
  1  给予权限的配置
      请在 GadgetsMenu/config.yml 和 GadgetsMenu/mystery boxes/mystery boxes.yml
      的 Execute-Command
      改成你的权限插件的命令
      如：
      PermissionsEx插件: pex user {PLAYER} add {PERMISSION}
      GroupManager插件: manuaddp {PLAYER} {PERMISSION}
      PowerfulPerms插件: pp user {PLAYER} add {PERMISSION}
      LuckPerms插件: lp user {PLAYER} permission set {PERMISSION}
      CloudNet permission插件: cperms user <user> add permission <permission>
  2  为什么没有变形Morphs
      请前往https://github.com/OnlyNoobDied/GadgetsMenu/wiki/Morphs安装插件（注意对应版本）
  3  如果烦菜单点击又关闭的麻烦
      可以用命令+菜单插件（如DeluxeMenus ChestCommands等）搭配使用
  4  有占位符？
      请安装 PlaceholderAPI 插件
      点击查看
  5  你必须在Spigot或PaperSpigot服务端使用
  6  为什么给了权限仍然打不开抽奖盒子？
      请打开服务端主目录的 server.properties 中 spawn-protection 后面的值改为 0
  7  加载插件显示错误：Unsupported major.minor version 52.0
      你可能使用了低版本JAVA
      请安装 JAVA8
  8  关于4.1.10的同时打开多个礼盒问题
      目前有三个选项，这三个选项权限分别为
  • gadgetsmenu.multipleboxes.20
  • gadgetsmenu.multipleboxes.50
  • gadgetsmenu.multipleboxes.250
      意思分别是
  • 同时打开20个神秘的礼盒
  • 同时打开50个神秘的礼盒
  • 同时打开250个神秘的礼盒
      如果想给全部选项，可以给予权限
  • gadgetsmenu.multipleboxes.*
  9  为什么有些没汉化？
      因为没有实际用处，所以禁用并且不汉化
  10 如何设置在线自动获得礼盒？
  • 在 mysteryboxes.yml 中的 mystery-box-reward 设置时间
