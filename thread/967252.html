视线追踪

  • 寻找鼠标指针所对的方块或实体。

函数 foo:tick，拥有 minecraft:tick 标签。

  1. # 使用胡萝卜钓竿
  2. execute as @a[scores={foo-use=1..}] run function foo:use
复制代码

函数 foo:use，使用胡萝卜钓竿。

  1. # 重置分数
  2. scoreboard players remove @s foo-use 1
  3. # 手持物品, 视线追踪, 寻找方块
  4. execute at @s[nbt={SelectedItem:{tag:{foo:"block"}}}] anchored eyes positioned ^ ^ ^ anchored feet run function foo:block/ray
  5. # 标记自身
  6. tag @s add foo-self
  7. # 手持物品, 视线追踪, 寻找实体
  8. execute at @s[nbt={SelectedItem:{tag:{foo:"entity"}}}] anchored eyes positioned ^ ^ ^ anchored feet run function foo:entity/ray
  9. # 移除 找到 标签
  10. tag @s remove foo-find
  11. # 移除 自身 标签
  12. tag @s remove foo-self

函数 foo:block/ray，视线追踪，寻找方块。

  1. execute unless block ~ ~ ~ #foo:through run function foo:block/find
  2. execute if entity @s[distance=..5,tag=!foo-find] positioned ^ ^ ^0.3 run function foo:block/ray
复制代码

函数 foo:block/find，找到方块。

  1. tag @s add foo-find
  2. # 其他操作
复制代码

方块标签 foo:through，可穿过方块。

  1. {
  2.   "replace": false,
  3.   "values": [
  4.     "minecraft:air",
  5.     "minecraft:cave_air",
  6.     "minecraft:void_air",
  7.     "minecraft:water",
  8.     "minecraft:bubble_column",
  9.     "minecraft:lava",
  10.     "minecraft:fire"
  11.   ]
  12. }
复制代码


  • 注
    • ^0.3 为递归步长，distance=..5 为限制玩家与目标方块的距离。
    • 标签 foo-find 用于判断是否已找到方块。
    • 如果函数 foo:block/find 不会使已找到的方块拥有 foo:through 标签，则可以将函数 foo:block/ray 第 2 行的命令改成 execute if entity @s[distance=..5] if block ~ ~ ~ #foo:through positioned ^ ^ ^0.3 run function foo:block/ray。

    • 节省资源
  • 缺点
    • 不够精确

函数 foo:entity/ray，视线追踪，寻找实体。

  1. # 标记找到的实体
  2. execute as @e[tag=!foo-self,dx=1,dy=1,dz=1] positioned ~-1 ~-1 ~-1 run tag @s[dx=1,dy=1,dz=1] add foo-target
  3. # 找到实体
  4. execute if entity @e[tag=foo-target] run function foo:entity/find
  5. # 未找到实体, 方块可穿过
  6. execute if entity @s[distance=..5,tag=!foo-find] unless entity @e[tag=foo-target] if block ~ ~ ~ #foo:through positioned ^ ^ ^0.3 run function foo:entity/ray
复制代码

函数 foo:entity/find，找到实体。

  1. tag @s add foo-find
  2. # 其他操作

    • 节省资源
  • 缺点

修改玩家背包物品

  • 仅修改单个指定物品。

主函数

  1. # 召唤 Marker
  2. summon minecraft:zombie ~ -65 ~ {Tags:["foo-marker"],DeathLootTable:"foo:replace"}
  3. # 将手上物品存入 Marker
  4. data modify entity @e[tag=foo-marker,limit=1] ArmorItems[0] set from entity @s SelectedItem
  5. # 使用 data 命令进行修改
  6. data modify entity @e[tag=foo-marker,limit=1] ArmorItems[0].tag ...
  7. # 将 Marker 上物品存入手上
  8. loot replace entity @s weapon.mainhand 1 kill @e[tag=foo-marker,limit=1]
  9. # 移除 Marker
  10. kill @e[tag=foo-marker]

数据表

  • 使每个玩家拥有自己的数据，可用于帮助一些仅支持单人的原版模组支持多人。
  • 例如，将每位玩家的坐标存储到自己的记录中。

初始化

  1. # 加载记分板
  2. ## 临时记分板
  3. scoreboard objectives add foo-value dummy
  4. # 加载 storage
  5. ## 存储玩家的数据
  6. data merge storage foo:data {Player:[]}
  7. ## 临时 storage
  8. data merge storage foo:temp {Player:[]}
复制代码
  1. execute as @a at @s run function foo:data/search
复制代码

函数 foo:data/search，搜索数据。

  1. ## 重置临时 storage
  2. data remove storage foo:temp Player[]
  3. ## 搜索记录
  4. function foo:data/loop
  5. ## 移除 找到记录 标签
  6. tag @s remove foo-find
复制代码

函数 foo:data/loop，逐条比对。

  1. ## 尝试存储玩家的 UUID
  2. execute store success score #foo-temp foo-value run data modify storage foo:data Player[-1].UUIDLeast set from entity @s UUIDLeast
  3. execute store success score #foo-temp2 foo-value run data modify storage foo:data Player[-1].UUIDMost set from entity @s UUIDMost
  4. ## 若存储失败则意味着找到
  5. execute if score #foo-temp foo-value matches 0 if score #foo-temp2 foo-value matches 0 run function foo:data/find
  6. ## 如果未找到
  7. ### 将本条记录移到临时 storage
  8. execute if entity @s[tag=!foo-find] run data modify storage foo:temp Player prepend from storage foo:data Player[-1]
  9. execute if entity @s[tag=!foo-find] run data remove storage foo:data Player[-1]
  10. ### 下一条
  11. execute if entity @s[tag=!foo-find] run function foo:data/loop
复制代码

函数 foo:data/find，找到数据。

  1. tag @s add foo-find
  2. ## 如果此时 Player 内元素的个数为 0, 则新建记录
  3. execute if data storage foo:data {Player:[]} run function foo:data/new
  4. ## 存储坐标
  5. data modify storage foo:data Player[-1].Pos append from entity @s Pos
  6. ## 将临时 storage 移回
  7. data modify storage foo:data Player append from storage foo:temp Player[]
复制代码

函数 foo:data/new，新建记录。

  1. data modify storage foo:data Player append value {}
  2. data modify storage foo:data Player[-1].UUIDLeast set from entity @s UUIDLeast
  3. data modify storage foo:data Player[-1].UUIDMost set from entity @s UUIDMost
  4. data modify storage foo:data Player[-1].Pos set value []
复制代码


  • 缺点
    • 搜索记录时直接比对 UUIDMost 和 UUIDLeast 在记录较多时会占用较多的资源。  在 1.16，UUID 将以整型数组的形式存储，将数组中各个元素存储到记分板，直接比对分数会节约不少资源。当然也可以选择用记分板给每个玩家编一个号，直接比对编号。


根据朝向放置方块

  • 放置与玩家朝向相反的木桶。

  1. # 放置木桶, 穷举方向
  2. execute if entity @s[y_rotation=-180..-135.01] run setblock ~ ~ ~ minecraft:barrel[facing=south]
  3. execute if entity @s[y_rotation=-135.01..-45.01] run setblock ~ ~ ~ minecraft:barrel[facing=west]
  4. execute if entity @s[y_rotation=-45.01..45.01] run setblock ~ ~ ~ minecraft:barrel[facing=north]
  5. execute if entity @s[y_rotation=45.01..135.01] run setblock ~ ~ ~ minecraft:barrel[facing=east]
  6. execute if entity @s[y_rotation=135.01..180] run setblock ~ ~ ~ minecraft:barrel[facing=south]
  7. execute if entity @s[x_rotation=45.01..90] run setblock ~ ~ ~ minecraft:barrel[facing=up]
  8. execute if entity @s[x_rotation=-90..-45.01] run setblock ~ ~ ~ minecraft:barrel[facing=down]
复制代码


  • 优点
    • 节省资源
  • 缺点
    • 不够精确，但基本够用


吸引仇恨

  • 使一个拥有标签 foo-attacker 的实体拥有来自 foo-target 的仇恨。

  1. # 召唤雪球
  2. execute at @e[tag=foo-attacker,limit=1] anchored eyes positioned ^ ^ ^ run summon minecraft:snowball ~ ~1.59 ~ {Motion:[0.0d,-10.0d,0.0d],Tags:["foo-snowball"]}
  3. # 修改 UUIDLeast
  4. data modify entity @e[tag=foo-snowball,limit=1] owner.L set from entity @e[tag=foo-target,limit=1] UUIDLeast
  5. # 修改 UUIDMost
  6. data modify entity @e[tag=foo-snowball,limit=1] owner.M set from entity @e[tag=foo-target,limit=1] UUIDMost
复制代码

  • 注
    • 1.59 的高度可以兼容大部分实体
  • 缺点
    • 攻击者头顶上有方块阻挡时无效
    • 攻击者为末影龙、凋灵、末影人（会瞬移）时无效
