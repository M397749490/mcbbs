究竟是什么意思？给个详细的指令吧！

先在存档文件夹内的data文件夹创建一个文件夹loot_tables，再在里面创建一个文件夹user，再在里面创建一个文件horsezombie.json，用文本编辑器打开并输入
  1. {"pools":[

  3. {"rolls":1,"entries":[
  4.         {
  5.                 "type":"item","name":"minecraft:leather","weight":1,"quality":0,
  6.                 "functions":[
  7.                         {
  8.                                 "function":"minecraft:set_count",
  9.                                 "count":{"min":1,"max":1}
  10.                         },
  11.                         {
  12.                                 "function": "minecraft:set_nbt",
  13.                                 "tag": "{drop:hz}"
  14.                         }
  15.                 ]
  16.         }
  17. ]}

  19. ]}
复制代码
进入游戏，
  1. give @p minecraft:spawn_egg 1 0 {EntityTag:{id:minecraft:horse,display:{Name:["生成 僵尸陷阱马"]},DeathLootTable:"user:horsezombie"}}
复制代码
给自己一个马刷怪蛋。如果不是1.11，将horse换成EntityHorse

在地上依次放置循环型命令方块(激活),连锁型(条件、激活),连锁型(条件、激活),连锁型(条件、激活),连锁型(条件、激活),连锁型(条件、激活)
依次输入
  1. scoreboard players tag @e[type=item] add horsezombie {Item:{tag:{drop:"hz"}}}
  2. execute @e[tag=horsezombie] ~ ~ ~ summon zombie ~ ~ ~
  3. execute @e[tag=horsezombie] ~ ~ ~ summon zombie ~ ~ ~
  4. execute @e[tag=horsezombie] ~ ~ ~ summon zombie ~ ~ ~
  5. execute @e[tag=horsezombie] ~ ~ ~ summon zombie ~ ~ ~
  6. kill @e[tag=horsezombie]
复制代码

这样马死后会掉落user:horsezombie中定义的一个带 drop:hz的皮革，然后命令方块给这个掉落物加一个标签 horsezombie,然后在具有这个标签的物品处依次召唤4个僵尸，最后杀掉这个物品（或者移除标签也可）
