将/plugins/GroupManager/worlds/world文件夹下的groups.yml文件中
  1.   builder:
  2.     default: true←这里改为true是确保新来的玩家都进入到builder权限组
  3.     info:
  4.       build: true←这里的true是确保玩家可以放置物品 捡东西

作者: Kbi_MC    时间: 2016-2-6 00:25
在权限组文件夹内的worlds >> 相应世界文件夹 >> group.yml
修改builder组下的default为true;
并设置该文件下原default为true的组的default选项为false;
例如:
权限组1:
....
  default: true
....
builder:(权限组)
.....
  default: false
....
修改后:
权限组1:
....
  default: false
....
builder:(权限组)
.....
  default: true
....
