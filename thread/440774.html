Winter Slash   
简介:
这是一个小游戏插件..大致就是类似葵花点穴手...
游戏规则:
当一个玩家被杀时会自动重生,而他死亡的地点上有一块冰块,不能移动,他将一直保持冰冻状态直到另一个队友帮他解冻,但是帮他人解冻需要特定工具,当一个玩家被解冻时,他可以继续游戏.
描述与胜利目标:
游戏分成两队,红队和绿队,游戏开始时会给予它们一些东西,不过最终目标还是将对面玩家全部冻结...
主要功能:
回合制-游戏采用2-4回合 具体取决于玩家数量..
连杀奖励-医疗包 随机药水 以及狗(???啥意思...原帖写的是dogs)
自动加入-自动加入还未开始游戏的房间
制作竞技场十分简单..
以及金钱奖励!
指令:
/ws help
列出所有命令
----
/ws list
列出所有的竞技场
----
/ws join
随机加入一个竞技场
----
/ws join <arenaname>
加入某个竞技场
----
/ws leave
退出竞技场
----
/ws setred
设置红队的出生点
----
/ws setgreen
设置绿队的出生点
----
/ws setlobby
设置大厅
----
/ws create <arenaname> <minplayers>
设置出生点完毕后使用这个命令来创建游戏..
----
/ws award <number>
设置胜利的队伍的奖励金币(该功能需要Vault)
----
/ws remove <arenaname>
删除竞技场

权限:
给予玩家:
winterslashusers.*
给予Master:
winterslash.*
