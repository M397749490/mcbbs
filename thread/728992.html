插件の简介

Introduction — 简介

BungeeParty是BungeeCord服务器的一個功能(系统)!
邀请玩家加入队伍是很简单的。
每个队长可以通过踢出玩家或邀请玩家来管理队伍。
想要与朋友一起在服务器内游玩:只需要创建一个队伍!
对于运行，不需要复杂的安装!


Create Party — 创建队伍

应该是邀请玩家就可以了(必须要玩家同意！)


Installation — 安装

购买并下载插件在将插件丢入插件文件夹内!
重新启动BungeeCord

指令の解说

  1. >> /party - 打开帮助中心
  2. >> /party list - 查看队伍玩家列表
  3. >> /party invite [User] - 邀请玩家加入队伍
  4. >> /party accept [User] - 接受邀请
  5. >> /party deny [User] - 拒绝邀请
  6. >> /party leave - 离开队伍
  7. >> /party kick [User] - 从你的队伍里踢出玩家
  8. >> /party destroy - 解散队伍
  9. >> /party move [User] - 队长身份转移
  10. #队伍聊天方法
  11. >> @party [Message] - 队伍聊天
