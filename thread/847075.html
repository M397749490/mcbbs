介绍 · Introduction
这款插件可以让你用可合成的钥匙来锁门.你也可以使用万·能·钥·匙（居然被屏蔽了）来开门

测试1.12.2 暂时无法使用 等待插件作者修复
特点
  • 给你的门、箱子、活版门等上锁
  • 可合成的钥匙、万·能·钥·匙、复制钥匙、钥匙串，甚至是搜锁器!
  • 每个合成配方拥有独立的权限.
  • 每个物品拥有独立的权限.
  • 自动更新插件.
  • 兼容新版本的门 (1.8).

指令&权限
/serialkey getkey - 详情查看权限. - 可以让你获取你所看方块的钥匙.
  • serialkey.craft.key - 允许合成钥匙. - 默认 : 所有人拥有.
  • serialkey.craft.masterkey - 允许合成万·能·钥·匙. - 默认 : 管理员.
  • serialkey.craft.keyclone - 允许复制钥匙. - 默认 : 所有人拥有.
  • serialkey.craft.bunchofkeys - 允许合成钥匙串. - 默认 : 所有人拥有.
  • serialkey.craft.padlockfinder - 允许合成搜锁器. - 默认 : 所有人拥有.
  • serialkey.use.key - 允许使用钥匙. - 默认 : 所有人拥有.
  • serialkey.use.masterkey - 允许使用万·能·钥·匙. - 默认 : 管理员.
  • serialkey.use.bunchofkeys - 允许使用钥匙串. - 默认 : 所有人拥有.
  • serialkey.use.padlockfinder - 允许使用搜锁器. - 默认 : 所有人拥有.
  • serialkey.command.getkey - 允许使用 /serialkey getkey 获得钥匙. - 默认 : 管理员.
