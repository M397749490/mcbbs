插件の簡介

Features — 功能


  • 多个arena(场地)（无限的）
  • 屏幕画板
  • 所有场地都是单独的（每个场地都可以有不同的题目与设置）
  • 场地独特的题目
  • title标题和action-bar支持
  • 支持1.7-1.11
  • 原帖持续更新
  • 支持BossBarAPI
  • 排名玩家（无限）
  • 颜色选择GUI（NEW）
  • Chat-type, PRIVATE or PUBLIC for non dedicated servers, (!) might not work with other chat plugins (NEW)
  • 工具包（NEW,用法:/ dmt kit <kit>）
  • Editable fill-tool (either like Paint, or so it fills the entire screen)
  • Colordata，你可以选择颜色块(羊毛)，例如像Mineplex
  • 支持Multi-world
  • Configure points for drawer, first guess, and other guesses.
  • Configure time once someone guessed word.
  • 支持告示牌
  • 投票踢出
  • 自订义讯息（除了帮助消息）
  • 自订义记分板
  • BungeeCord支持（不是一个BungeeCord插件，但插件具有Bukkit的功能，使其在设置时更加BungeeCord）(不清楚)
  • 没有记分板闪烁
  • 时间锁定（设定世界时间，无日夜循环）
  • 声音（猜题，加入，退出，开始，绘画，清除屏幕，填充屏幕等）可编辑声音
  • 不断更新插件(原帖)
  • Action-bar提示并绘画消息（100％完全可配置）
  • Shows new character in hint message every so often. Not predefined, it will show more often for longer words
  • 细与粗体刷和填充屏幕和清晰屏幕工具
  • 时间留在经验栏和计分版佔位符
  • 轮数，总轮数等佔位符
  • 区域工具（选择位置），用于设置绘画区域和colordata
  • 完全可修改的权限（config.yml）
  • 强制开始场地 （用法:/dmt forcestart）
  • MySQL support ready IF implementing a points system




Setup — 游戏设置


  • 创建场地 - 使用: "/dmt arena create <name>"
  • 设置大厅和旁观者(不清楚)的位置 - 使用:"/dmt arena set<lobby/spectator> <name>"
  • 增加加入游戏的玩家位置 - 使用: "/dmt arena addspawn <name>"
  • 设置绘画区域 - 使用: "/dmt wand" 来拿出区域工具，点对角线的位置点，点1按左键点2按右键，输入 "/dmt arena setcanvas <name>"
  • 在用一次区域工具来选择颜色方块, 点击颜色方块区域 选择区域按照上个步骤一样 - 使用: "/dmt colordata <wool/stained>" wool/stained 是屏幕类型, 如果是羊毛屏幕则选wool ; 如果是染色黏土则选stained
  • 设置画家的位置 - 使用: "/dmt arena setdrawer <name>"
  • 完成~
