特性：
  • 无限的菜单。
  • 自定义你菜单名字。
  • 使用一个物品来打开你的菜单。
  • 使用一条指令来打开你的菜单。
  • 动态物品描述。
  • 自定义每个动态的延迟。
  • 自定义每个菜单的行数。
  • 每一个动画无限帧。
  • 每一个物品无限描述。
  • 自定义每一个项目的ID+破损值。
  • 自定义每一个物品的名字。
  • 禁言菜单中的移动效果。
  • 运行（无限）命令在某个物品中执行。
  • 可以在菜单内放置物品。
  • 可以设置打开的声音+可以调节音量的大小等。
  • 可以设置权限+单独物品权限。
  • 设置物品执行价格+不足够钱的点击消息。（需要Vault或其他经济类插件支持）
  • 设置物品执行的点(点卷)+不足够点击消息。（需要PlayerPoints或其他点卷类插件支持）
  • 更改菜单每一帧的物品。
  • 获取一个服务器（最大）玩家的数目。
  • 单独文件(XX.yml)为一个菜单。
  • 支持 Unicode 字符。
  • 精确的报错记录。（程序猿的天堂）
  • 支持 BungeeCord 。
  • 支持 Tab 。
  • 超多变量支持

命令：
  • /animatedmenu - 显示插件帮助消息
  • /animatedmenu open [name] - 列出菜单列表或打开一个菜单
  • /animatedmenu item [name] - 给予一个对应菜单的打开物品
  • /animatedmenu edit [name] - 在游戏中编辑菜单
  • /animatedmenu reload - 重载插件

权限：
(/am 本为此插件的指令简称,但后来貌似不能用了)
  • animatedmenu.command.help - 使用 /am 权限
  • animatedmenu.command.reload - 使用 /am reload 权限
  • animatedmenu.command.open - 使用 /am open [菜单] 权限
  • animatedmenu.open - 使用物品打开一个菜单
  • animatedmenu.economy.bypass - 无视扣钱
  • animatedmenu.points.bypass - 无视点的价格

一些在菜单中可以使用的变量：
玩家变量(需要ProtocolLi前置插件!):
  • %name%
- * 显示玩家的名字
  • %uuid%
- * 显示玩家的 uuid (对于你来说就是一群乱码)

  • %ping%
- * 显示玩家的ping(延迟)值

  • %money%
- * 显示玩家的金钱(需要Vault前置插件)

  • %points%
- *显示玩家的点(点卷)(需要PlayerPoint前置插件)
其他:
  • %unicode:<unicodeid>%
- * 显示一个 Unicode 字符属于 Unicode 的 ID

  • %ping-online/<serverip>:<serverport>%
- * 显示一个服务器玩家在线的情况(需要BungeeCord支持)

  • %ping-max/<serverip>:<serverport>%
- * 显示一个服务器的最大玩家数(需要BungeeCord支持)

  • %bungee-online/<servername>%
- * 显示一个服务器的在线情况(需要BungeeCord支持)[这个与%ping-online/<serverip>:<serverport>%略有不同]

  • %mv-online/<worldname>%
- * 显示一个世界的在线人数情况(需要Multiverse-Core或其他多世界插件支持,其实也可以不用的)

  • %mv-max/<worldname>%
- * 显示一个世界的最大在线人数情况(需要Multiverse-Core或其他多世界插件支持,其实也可以不用的)

  • %region/<worldname>,<regionname>%
- * Gets the amount of players in a WorldGuard region in the world specified with <worldname>. Requires WorldGuard
