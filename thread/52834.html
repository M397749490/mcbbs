  2. --[[
  3. place this file under .minecraft/mods/ComputerCraft/lua/rom/programs

  5. to make a game with this api, make a new file and type shell.run('gameapi') at the top, the functions will then be available for you to use.

  7. Breif Explanation of Functions:

  9. actor:new(x, y, char[, bounded])
  10. returns a new actor at the x and y positions on the terminal
  11. bounded is a boolean which will determine whether or not your actor's movement is limited to the console window, true by default.

  13. actor.x
  14. the actor's x position

  16. actor.y
  17. the actor's y position

  19. actor.char
  20. the character representing the actor on screen

  22. actor.bounded
  23. whether or not the actor can go outside the screen

  25. actor:setPos(x,y)
  26. sets the actor's position
  27. **this method and other positioning methods must be used in order for the actor's position to be updated onscreen

  29. actor:addPos(x,y)
  30. adds to the actor's position

  32. actor:setX(n)
  33. sets the actor's x position to n

  35. actor:setY(n)
  36. sets the actor's y position to n

  38. actor:addX(n)
  39. adds n to the actor's x position

  41. actor:addY(n)
  42. adds n to the actor's y position

  44. actor:setChar(char)
  45. change the actor's character to char

  47. game.key(k)
  48. user defined, triggered when a key is pressed

  50. game.update()
  51. user defined, triggered when a new frame is drawn

  53. game.start()
  54. required for the game to start, obviously
  55. **any code after this function will not be ran until the game has stopped

  57. game.stop()
  58. quit the program

  60. Example at http://pastebin.com/D78fft65

  62. /*---*/

  64. Changelog:

  66. r1:
  67. Released API

  69. r4:
  70. Added 'game:setChar()' to change an actor's characters
  71. Added a 'bounded' attribute if you wanted an actor to be able to go outside the screen.
  72. Added 'screen.width' and 'screen.height' as editable attributes to allow for custom widths and heights

  74. r5:
  75. Changed instructions for usage.
  76. ]]
