如何让另一个世界的权限与主世界权限一样？我在主世界添加权限后到了另一个世界就又没权限了。
作者: 幻想112    时间: 2016-5-7 15:08
按照下面的步骤来做就可以了：
plugins\GroupManager\config.yml
用notepad++ 这个软件编辑config.yml
然后找到    mirrors：   这行
1.下面的配置如下：
  mirrors:
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
          你的世界名字(你要权限的世界名字)
          - users
          - groups
