介绍
该整合包涵盖了与建筑相关的插件
主要功能有：
  • 关闭一些方块的物理效果
  • 各种笔刷
  • 各种地形
  • 创世神选区可视化
  • 更多音效
  • 无落叶
  • 无爆炸破坏
  • 无天气变更
  • 预置世界固定时间 可手动用/time set 更改
  • 无农田践踏
  • 方块重力效果可在Builder's Utilities内关闭
  • 编辑旗帜、盔甲架
该服务端主要用于无需联机的本地开服.  如果你要用于服务器，你只需复制这些插件到其他服务端使用
该整合包由qsefthuopq在MCBBS首发，最终解释权归qsefthuopq所有
转载请注明原帖

使用方法
  • 下载并解压压缩包
  • 点击开服bat文件开服
  • 打开游戏，输入本地服务器IP：127.0.0.1:25565 并进入服务器
  • 在后台输入op [用户名] 给予自己管理员权限
  • 自由发挥，创造属于你的世界
  • 输入/stop 来保存地图并关服 地图位于服务端根目录，可随时导入到单机
