您好,请使用正式版1.8或之后的版本进行下列操作。
侧边栏仅能同时显示一个变量。您应该利用假玩家来完成您的目的。
添加变量的命令为/scoreboard objectives add 变量名a dummy 变量列表
显示侧边栏的命令为/scoreboard objectives setdisplay sidebar 变量名a
添加假玩家的命令为/scoreboard players set Z 变量名a Y
假玩家间变量的加减可用命令/scoreboard players operation Z1 Y1 += Z2 Y2与命令/scoreboard players operation Z1 Y1 -= Z2 Y2完成,判断可用scoreboard players test Z 变量名a 最小值完成。使用脉冲红石信号激活输入了命令testfor @e[目标选择器参数]的命令方块来探测指定怪物是否存在,再使用红石比较器连接非门连接至输入了命令/scoreboard players add Z 变量名a Y的命令方块即可,请将您指定怪物的特殊之处告诉我,我会为您选择合适的目标选择器参数。
使用命令/scoreboard players operation Z1 Y1 *= Z2 Y2来将Y1设为Y1*Y2,使用命令/scoreboard players operation Z1 Y1 /= Z2 Y2来将Y1设为Y1/Y2,使用命令/scoreboard players operation Z1 Y1 %= Z2 Y2来进行取余,使用命令/scoreboard players operation Z1 Y1 = Z2 Y2来进行"复制",使用命令/scoreboard players set Z 变量名 Y来进行"等于"。
使用命令/scoreboard objectives add 变量名b dummy和命令/scoreboard objectives add 变量名c dummy添加两个变量,使用命令/scoreboard players set Z 变量名c 0将变量c设为0,使用命令/scoreboard players set @e[x,y,z,dx=DX,dy=DY,dz=DZ] 变量名b 0将以xyz为区域中坐标最小顶点,各方向上长度分别为DX、DY,与DZ的区域中实体变量设为0,使用脉冲红石信号激活输入了命令testfor @e[x,y,z,dx=DX,dy=DY,dz=DZ,score_变量名b=0,c=1]的命令方块,用红石比较器连接至分别输入了命令/scoreboard players set @e[x,y,z,dx=DX,dy=DY,dz=DZ,c=1] 变量名b 1与命令/scoreboard players add Z 变量名c 1的命令方块,变量名c的值即实体数。
命令/testfor @e[x,y,z,dx=DX,dy=DY,dz=DZ,type=Player]与命令/testfor @e[x,y,z,dx=DX,dy=DY,dz=DZ,type=!Player]能分别探测指定区域内的玩家与非玩家实体。
使用命令/summon 怪物名 x y z {NoAI:1}在坐标xyz生成没有AI的怪物,使用高频红石信号激活分别输入了命令execute @e[type=怪物名] ~ ~ ~ detect ~ ~-10 ~ stone_brick_stairs 1 tp @e[type=怪物名,c=1] ~0.2 ~ ~ -90 0、命令execute @e[type=怪物名] ~ ~ ~ detect ~ ~-10 ~ stone_brick_stairs 2 tp @e[type=怪物名,c=1] ~ ~ ~-0.2 180 0、命令execute @e[type=怪物名] ~ ~ ~ detect ~ ~-10 ~ stone_brick_stairs 0 tp @e[type=怪物名,c=1] ~-0.2 ~ ~ 90 0,与命令/execute @e[type=怪物名] ~ ~ ~ detect ~ ~-10 ~ stone_brick_stairs 3 tp @e[type=怪物名,c=1] ~ ~ ~0.2 0 0的命令方块使在石砖台阶上方10米处的怪物按照石砖台阶的方向移动。速度与用作判断的方块种类及距离均可改变。
使用高频红石信号激活分别输入了命令execute @e[type=怪物名] ~ ~1 ~ kill @e[type=Item,c=1]与execute @e[type=怪物名] ~ ~1 ~ summon Item ~ ~ ~ {PickupDelay:2s,Item:{id:物品ID,Damage:损伤值,Count:数量,tag:{数据标签}}}的命令方块或使用命令/entitydata @e[type=怪物名] {Equipment:[{id:物品ID,Damage:损伤值,Count:数量,tag:{数据标签}},{id:物品ID,Damage:损伤值,Count:数量,tag:{数据标签}},{id:物品ID,Damage:损伤值,Count:数量,tag:{数据标签}},{id:物品ID,Damage:损伤值,Count:数量,tag:{数据标签}},{id:物品ID,Damage:损伤值,Count:数量,tag:{数据标签}}],DropChances:[1.0F,1.0F,1.0F,1.0F,1.0F]}来替换现存所有怪物的装备并自定义掉落率,1.0相当于100%。
