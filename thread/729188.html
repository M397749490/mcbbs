插件の简介

Introduction — 简介

ServerAdmin 是一款与手机应用程式的插件，可以以应用程式来监控自己服务器的一举一动。
ServerAdmin 拥有许多功能，未来将会有许多功能将添加。


Features — 功能

  • 无限制添加服务器
  • 账号/密码保护
  • 权限功能，可以限制用户有权使用哪些功能
  • 查看服务器是否开启或关闭
  • 查看各个服务器当前状态
  • 当前服务器资讯
  • 随时随地执行命令
  • 当前玩家监控:查看玩家位置, 更改玩家游戏模式等！
  • 插件监控:启用/禁用各个插件
  • 世界:查看服务器内的世界列表与分享地图种子码！
  • 当前与玩家聊天
  • 更多功能正在推出
待推出：FTP系统来设置插件配置


Use — 使用

  • 购买并下载 ServerAdmin 插件，在将插件丢入插件文件夹内，再开起服务器。
  • 这时，服务器就可以使用 ServerAdmin 手机应用程式监控
  • 应用程式可以在 Google Play商店 或 Apple App 商店 免费下载并安装。

演示服务器
  • IP: server.serveradminapp.com
  • Port: 8001
  • user: demo
  • pass: demo

Installation — 安装

  • 购买并下载插件在将插件丢入插件文件夹内!
  • 重新启动或重载服务器
  • 打开配置文件并更改预设帐户
  • (非必须)更改 ServerAdmin 运行端口
  • 在config内配置端口
  • 更改配置后储存，重载或重启服务器
  • 查看服务器后台，如果出现"ServerAdmin started on port XXXX"代表完成
  • 下载并安装应用程式
  • 开启应用程式
  • 点击右上角的+
  • 填写服务器资讯。IP请与加入的服务器IP相同，Port请与在插件配置中设置的相同。用户名与密码是在配置文件中的用户名与密码相同。设置完成后，按下"Add Server"
  • 之后，会转到服务器列表的页面中，如果图标变绿色，代表成功设置，可以监控服务器了。如果变红色，代表设置有误，请修复错误地方
