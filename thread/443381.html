本项目已不再开发

如果你是个玩家，下载某地图后发现全是繁体字，看的眼睛都瞎了。
如果你是个地图作者，在地图里用了繁体字，想把批量转换成简体。

那么你来对地方了。

直接读取NBT进行批量繁简转换，一行命令，全部搞定！
并发执行，效率翻倍！

使用说明
  1. java -jar <下载的jar> <要转换的存档的路径>...
复制代码
建议给程序分配至少512M的内存，防止转换过程中内存不足
  1. java -Xmx512M -jar <下载的jar> <要转换的存档的路径>...
复制代码
程序会把转换的过程提示输出到stderr，转换前后的繁简对比输出到stdout。如果你想把繁简对比存起来，可以使用重定向符。
  1. java -jar <下载的jar> <要转换的存档的路径>... > <输出文件>
复制代码
如果你不想看到繁简对比，Windows用户可以重定向到NUL，Linux/Unix/Mac用户可以重定向到/dev/null
