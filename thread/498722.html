Minecraft的mod就是多！
现在连1.9都有mod了！

Meddle是一个基于LaunchWrapper系统的Mod API，主要拥有一个从游戏文件夹(.minecraft)之下的Meddle文件夹里面读取Tweaker的功能。
当然Minecraft的源码是混淆过的，所以跟Meddle同时出现的另一个Tweaker是DynamicMappings，可以一定地反编译minecraft源码。

客户端使用：
原版启动器——下载Json：
  1. {
  2.   "id": "15w36c-meddle-1.2.2",
  3.   "time": "2015-08-19T00:00:00-04:00",
  4.   "releaseTime": "2015-08-19T00:00:00-04:00",
  5.   "type": "snapshot",
  6.   "minecraftArguments": "--username ${auth_player_name} --version ${version_name} --gameDir ${game_directory} --assetsDir ${assets_root} --assetIndex ${assets_index_name} --uuid ${auth_uuid} --accessToken ${auth_access_token} --userType ${user_type} --tweakClass net.fybertech.meddle.Meddle",
  7.   "libraries": [
  8.     {
  9.       "name": "net.minecraft:launchwrapper:1.11"
  10.     },
  11.     {
  12.       "name": "org.ow2.asm:asm-all:5.0.3"
  13.     },
  14.     {
  15.       "name": "net.fybertech:meddle:1.2.2",
  16.       "url": "http://www.fybertech.net/maven/"
  17.     }
  18.   ],
  19.   "mainClass": "net.minecraft.launchwrapper.Launch",
  20.   "minimumLauncherVersion": 14,
  21.   "assets": "1.8",
  22.   "inheritsFrom": "15w36c",
  23.   "jar": "15w36c"
  24. }
复制代码
你可以把id一项改成别的东西，就是你的游戏版本的名字(versions里面的文件夹的名字)。例如这个你就需要先安装15w36c才能安装meddle。
服务器安装器下载链接:http://www.fybertech.net/minecra ... generator-1.0.1.jar
使用方法：命令提示行里面输入
  1. java -jar servergenerator-1.0.1.jar <mc版本> <meddle版本> <服务器文件夹>
复制代码
meddle使用时最好开vpn，因为它要联网下载meddle的文件。

Meddle是开源的——https://github.com/FyberOptic/Meddle
