作者: RINNDA    时间: 2017-7-20 17:47
在ESS里的config.yml找到chat这行
  1. chat:

  3. # 设置聊天半径,如果安装了EssentialsChat,这将设置玩家喊话的可见范围,以格为单位.设置为0则允许全图聊天.
  4. # 注意开启了间谍模式(权限:essentials.chat.spy)的玩家将看到所有聊天内容,无视该设置.
  5. # 拥有"essentials.chat.shout"权限的玩家可以忽视该设置,只要在聊天内容前面加上"!"符号即可(小写感叹号)；
  6. # 或者拥有"essentials.chat.question"权限的玩家可以忽视该设置,只要在聊天内容前面加上"?"符号即可(小写问号)；
  7. # 你可以添加使用上两行方法的花销,在上经济设置中的"command-costs"下添加"chat-shout"和"chat-question"的设置即可.
  8.   radius: 0

  10.   # 聊天格式,可以有两种,你可以定义所有聊天为标准格式.
  11.   # 或者你可以给一个用户组特定的聊天格式,提供一些额外的变化.
  12.   # 是否设置为默认聊天格式,需要与ichat插件兼容.
  13.   # 想了解更多的默认聊天格式的信息,请查看wiki: http://wiki.ess3.net/wiki/Chat_Formatting

  15.   format: '&a{DISPLAYNAME} 》 {MESSAGE}'
  16.   #format: '&7[{GROUP}]&r {DISPLAYNAME}&7:&r {MESSAGE}'

  18.   group-formats:
  19.   #  Default: '{WORLDNAME} {DISPLAYNAME}&7:&r {MESSAGE}'
  20.   #  Admins: '{WORLDNAME} &c[{GROUP}]&r {DISPLAYNAME}&7:&c {MESSAGE}'

  22.   # 你也可以设置特定组别的聊天格式,删除前面的"#"号来启用.
复制代码
