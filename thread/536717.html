基本废话:自己服务器是1.7.10 1.8的 又想有极限附魔,虽然有老的eex  但是 那插件 完全没有新的附魔 比如什么钓饵 什么的 所以做了个 本来想自己用 还是公开了
介绍(来自):

上面的图 好像是白搭
因为 附魔名字我已经汉化了   下面的<附魔名称>  请使用中文名称  
命令：

# 列出附魔列表
/eex list
# 附魔别名列表
/eex alias
# 帮助菜单
/eex help
# 给指定玩家一个附魔物品.
/eex give <玩家> <物品ID> <附魔名称> <附魔等级>
# 给指定玩家一个自命名的附魔物品.
/eex give <玩家> <物品ID> <附魔名称> <附魔等级> <新名称>
# 添加一个附魔物品到你背包中.
/eex <物品ID> <附魔名称> <附魔等级>
# 添加一个自命名的附魔物品到你背包中.
/eex <物品ID> <附魔名称> <附魔等级> <新名称>
# 为手中物品增加附魔.
/eex hand <附魔名称> <附魔等级>
# 为手中物品增加附魔并重命名.
/eex hand <附魔名称> <附魔等级> <新名称>
# 为手中物品重命名.
/setname <新名称>
# 为手中物品写入描述文字
/setlore <描述文字>
# 查看手中物品ID.
/itemid
