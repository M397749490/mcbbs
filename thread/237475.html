[fly]==========介绍==========[/fly]
一个非常强大的魔法插件，有着近100种魔法，花费经验来使用魔法，而且还提供了模板，可以自己制作魔法。作者提供的演示服务器：mine.elmakers.com（需要正版，去玩了下感觉还是不错的）
而且还支持Dymap和WorldGuar

[fly]==========指令==========[/fly]
魔杖指令：
  • /wand :  创建一个新的空的魔杖
  • /wand 名字 : 从wands.yml中读取一个预置的魔杖
  • /wand list : 列出可用的魔杖列表
  • /wand add 法术名称 : 给你手中的魔杖添加一个法术
  • /wand fill：添加给你手中的魔杖所有可以添加的法术
  • /wand remove 法术名 : 删除你手中魔杖的一个法术
  • /wand configure 属性 值 : 配置法杖的属性（见下面）
  • /wand upgrade 属性 值 : 增加这个属性的值（见下面）
  • /wand combine 魔杖名 : 给一个魔杖添加模板魔杖的属性
  • /wand add material 材料 : 给当前魔杖添加一个新的材料
  • /wand remove material 材料 : 删除当前魔杖的某个材料
  • /wand name 名字 : 重命名魔杖（还可以用铁砧）
  • /wand describe : 列出魔杖的所有属性
  • /wandp 玩家名 命令 : 给一个玩家使用魔杖命令
工具指令
  • /magic load : 重载配置文件
  • /magic save : 保存数据
  • /magic populate 世界名 高度 : 用魔杖填充某个世界位于低于多少格的箱子（就是可以把魔杖藏到地牢这种地下箱子里）
  • /magic list 玩家 : 列出所有丢失的魔杖，或者某个玩家的
  • /magic clean 玩家 : 清除所有的魔杖，或者某个玩家的
  • /spells : 列出所有的法术（这个命令可以给玩家，是安全的）
/cast命令是非常强大的，他允许你使用任何魔法。具体的使用方法待填坑，等不及的可以去看http://dev.bukkit.org/bukkit-plugins/magic/pages/admin-instructions/

[fly]==========权限==========[/fly]

推荐给普通玩家的权限
  • Magic.wand.use : 魔杖是使用权限
  • Magic.commands.spells :/spells命令的使用权限
  • Magic.commands.wand :/wand命令的使用权限
  • Magic.commands.wand.wand.魔杖名 : 玩家可以使用/wand命令获得某个魔杖，如果不给这个权限。默认是所有魔杖都可用的
  • Magic.commands.wand.add : 玩家可以使用 /wand add
  • Magic.commands.wand.add.spell.法术名: 玩家可以添加一个特定的法术
  • Magic.commands.wand.add.material : 玩家可以添加材料
  • Magic.commands.wand.remove : 玩家可以使用 /wand remove
  • Magic.commands.wand.name : 玩家可以使用 /wand name
  • Magic.commands.wand.list : 玩家可以使用 /wand list
  • Magic.commands.wand.fill : 玩家可以使用 /wand fill
  • Magic.commands.wand.configure : 玩家可以使用 /wand configure
  • Magic.commands.wandp : 玩家可以使用 /wandp
  • Magic.commands.wandp.wand.魔杖名 :玩家可以使用 /wandp 给一个特定的魔杖，如果不给这个权限。默认是全部可用的
  • Magic.commands.wandp.add : 玩家可以使用 /wandp add
  • Magic.commands.wandp.add.spell.法术名 :玩家可以添加一个特定的法术给特定的魔杖，如果不给还是全部可用
  • Magic.commands.wandp.add.material : 玩家可以添加一个特定的材料给特定的魔杖，同上
  • Magic.commands.wandp.remove : 玩家可以使用 /wand remove
  • Magic.commands.wandp.name : Player can use /wand name
  • Magic.commands.wandp.list : 玩家可以使用 /wand list
  • Magic.commands.wandp.fill : 玩家可以使用 /wand fill
  • Magic.commands.wandp.configure : 玩家可以使用 /wand configure
  • Magic.commands.cast : 玩家可以使用 /cast
  • Magic.cast.法术名 :玩家可以使用特定的法术
管理员权限：
  • Magic.commands.magic.load : 重载配置文件
  • Magic.commands.magic.populate : 填充箱子
  • Magic.commands.magic.[save|clean|search|list|等……] :所有的命令，格式相同\
还有Dynmap集成和WorldGuard集成就先不说了，待填坑
