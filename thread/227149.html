本帖最后由 songfeitong 于 2014-3-12 21:32 编辑

今天SOFT在经过3、4个小时的不懈努力之后，终于研制出了用Tellraw命令打造的纯原版修改器 Too Many Softs。这个“修改器”拥有TMI、NEI的功能（不含附魔、自定义药水、装备、获取物品）。同时SOFT还结合了一些最近的研究成果，为这个修改器加入了[Pro]版，其中新增加了瞬间回家，无敌模式、夜视模式，银行系统，获取补给箱等进阶功能。

-----------------------------------------------------------------------------------------------------------------------------
图片预览[Standard]基础版

如图就是TMS基础版的操作界面，每一个字母/按钮都代表一个功能。

S-surival mode-调成生存模式
C-creative mode-调成创造模式
A-adventure mode-调成冒险模式
■-On/off rain/snow-开/关 雨雪■-time set sunrise-将时间设为日出
■-time set noon-将时间设为正午
■-time set sunset-将时间设为日落
■-time set midnight-将时间设为日落
■-difficultly-游戏难度调整
心形-fill health and food-恢复生命和饥饿值

把光标移到图标上会显示该按键的功能。


TMS的基础版功能完全来自TMI的功能，使用方法也全部相同，只需要点击按钮即可进行操作。■按钮在无雨雪时会开始下雨雪，有雨雪时按下会清除雨雪。
■按钮每按下一次就会提升一次难度，和平-简单-普通-困难，困难之后接下来是和平。
其余按钮按下后会执行一次上面所说的修改。

最后一句话：[Standard]版本与TMI操作完全一毛一样。

下页：[Standard]原理讲解。
如果您不想看完，看到这里后请点一下顶吧。

原理讲解[Standard]基础版
整个修改器都是基于/tellraw指令的。
其实想学写tellraw指令十分的简单，完全不用看syl的教程。只需一个网站：点我！一下是每个按钮的背后的原理：
S：执行命令/gamemode 0
C：执行命令/gamemode 1
A：执行命令/gamemode 2
■:执行命令/toggledownfall
■：执行命令/time set 0
■:执行命令/time set 6000
■:执行命令/time set 12000
■:执行命令/time set 16000

-----------------------------------------------------------------------------------------------------------------------------
以下内容较有难度：
■按钮运用了Counter（计数器）也就是每次输入一个讯号就会+1，每按一次按钮就会把难度重新设置，到最后一个Hard的时候，Counter就会把整个机器重置。


下面附上鱼干大大的Counter教程：（视频）
http://player.youku.com/player.php/sid/XNDc0MTUzNzUy/v.swf

心形按钮按下后会给玩家瞬间恢复255，饱和255。这能以瞬间回满玩家的饥饿和血值。

图片预览[Pro]专业版

如图就是专业版TMS的操作界面，好花哨啊……


每一个按钮的功能简介：
Home：
√-set home-设置家的位置
X-cannel-取消设置
●-go home-瞬间传送回家
Effect：
N-night vision-开启/关闭夜视
I-invincible-无敌模式
J-Jump Boost-跳跃提升
C-Clear-清除全部效果
$-Bank System-银行系统
！-Bonus Chest-召唤补给箱

Home3个按钮图文演示
首先在要设置家的位置上按√按钮。

然后你可以走到任何地方，想回家时点击●按钮。


点击之后就会即可回到刚刚存档的地方，不需死亡。

而X按钮点击以后就会取消当前的家，你可以在别的地方存档。


Effect演示：
以“无敌”做演示，点击这个按钮获得效果。

然后按“E”，可以看到获得无限时长的抗性提升。

跳进岩浆里都不损血了！



再点击一次“I”,就会取消无敌效果。


银行系统按钮，按下就会触发另一条tellraw。

详见：http://www.mcbbs.net/thread-221659-1-1.html

奖励箱，按下就会出现一个箱子。

里面有许多物资。
