你要记住一点
只要是BukkitScheduler，BukkitRunnable等等任务调度
全都有返回值的
也就是BukkitTask
BukkitTask类有一个cancel方法
可以取消任务

所以你得这个就很简单了
直接存起来你的俩BukkitTask
在合适的时机cancel掉
比如说
BukkitTask task =

new BukkitRunnable(){

@Override
public void run(){



xxx


}


}.runTask(xxx);


然后task.cancel();
