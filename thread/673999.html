在MC服务器中，

总有那么一群人，

喜欢轻视生命，

为了恢复饥饿值而自杀。

为此我特地在MCBBS上找了几天，

然而并没有1.7.10及以上版本可以用的插件！

特此我联系了作者，更新了此插件！

这个插件十分轻量，

只有4.44KB大小。



作用：
使玩家复活时，
不再恢复饥饿值，
而是掉为0，
迫使玩家吃食物！



指令：

无



权限：

无



配置文件:

Per-World-Hunger: true 是否启用插件
Per-World-Hunger-in: 启用的世界
  world: true 启用为true，不启用为false
  DIM1: true  KC端和C端好像没法加载世界名称
  BMSC: true  需要手动添加！
  NMSC: true
  YZSC: true
  FZSC: true
  plotworld: true



截图：

实在没什么好截的……



版本：1.4

修复了KC端和C端多世界无法使用的BUG



后记：

本插件已改版，

理论上全版本通用。

S端还没测试，

欢迎大家测试！

1.6.4以下可能会没法加载出来，

更新一下JAVA到J8就可以了！
