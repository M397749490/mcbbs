  1. 命令：

  3. # 列出附魔列表
  4. /eex list
  5. # 附魔别名列表
  6. /eex alias
  7. # 帮助菜单
  8. /eex help
  9. # 给指定玩家一个附魔物品.
  10. /eex give <玩家> <物品ID> <附魔名称> <附魔等级>
  11. # 给指定玩家一个自命名的附魔物品.
  12. /eex give <玩家> <物品ID> <附魔名称> <附魔等级> <新名称>
  13. # 添加一个附魔物品到你背包中.
  14. /eex <物品ID> <附魔名称> <附魔等级>
  15. # 添加一个自命名的附魔物品到你背包中.
  16. /eex <物品ID> <附魔名称> <附魔等级> <新名称>
  17. # 为手中物品增加附魔.
  18. /eex hand <附魔名称> <附魔等级>
  19. # 为手中物品增加附魔并重命名.
  20. /eex hand <附魔名称> <附魔等级> <新名称>
  21. # 为手中物品重命名.
  22. /setname <新名称>
  23. # 为手中物品写入描述文字
  24. /setlore <描述文字>
  25. # 查看手中物品ID.
  26. /itemid
复制代码

  1. 权限：

  3. enchantextreme.eex
  4. enchantextreme.setname
  5. enchantextreme.setlore
  6. enchantextreme.itemid
