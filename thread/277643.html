我又一个更好的办法，但是要使用服务器。先创造一个超平坦世界，预设为全空气（空气ID:0），然后使用该地图开启服务器（服务器内包含WE插件）然后你会发现自己正在掉落，飞起来吧，随后，你使用WE，输入//sphere 1 1，创造出一个石头的球体，这样一来，你就有方块可以在空中建设了，保存地图后，复制刚刚客服端里的地图，粘贴到服务端.minecraft saves这里面就可以进行单人游戏了

作者: ChallengerX    时间: 2014-5-22 23:33
OAO直接烧肯定不行的

你可以使用超平坦预设代码（PS：1是用来展位的）
2;1x0;1
1.8以上版本由于超平坦代码转变，改为
3;1xminecraft:air;1
之后使用setblock指令生成第一个方块，位置是x=0,y=64,z=0

/setblock 0 64 0 7
同样的，1.8版本下需要修改一下
/setblock 0 64 0 minecraft:bedrock
之后，你可以通过第一个方块放置更多的方块


也可以生成一张地图，之后使用ME或WE清除一定的范围内的所有方块（你还得保留一个……），一般设置10万左右就可以了。

你也可以直接上网下载一个单方块之类的地图，然后修改
