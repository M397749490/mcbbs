GUI Commands

图片

描述
GUI Commands是一个便于开发人员制作在GUI中点击物品便执行命令的插件。这个插件可以高度自定义他们的GUI（将来会有更多的功能自定义名称，lore，GUI开启物品（例如指南针）和权限！

功能
  • GUI设置
  • 自定义GUI名称（显示在顶部）
  • 自定义GUI打开的命令
  • 自定义GUI关闭的命令
  • 自定义GUI的行数
  • 设置玩家点击某个物品后GUI是否保持打开
  • GUI物品/登录物品
  • 玩家登陆后是否拥有自定义物品
  • 更改自定义物品类型
  • 给自定义物品添加lore
  • 为自定义物品添加名称
  • 设置此物品在GUI所处的位置
  • 设置玩家是否可以移动物品
  • 设置玩家是否可以丢弃物品
  • 自定义GUI
  • 允许玩家在他们可以自定义的GUI中创建物品
  • 设置物品的ID
  • 设置物品的数量
  • 设置物品的名称
  • 添加物品的lore
  • 给GUI中的物品添加可执行命令
  • 让玩家也可以创建自定义GUI
  • 自定义玩家是否可以看到GUI中物品的权限
  • 自定义玩家是否可以点击GUI中物品的权限
  • 自定义玩家无权限点击某个物品时的消息

命令与权限
命令
  • /guicommands
  • /guicommands reload
权限
  • guicommands.reload
  • (config.yml)view-permission; ''
  • (config.yml)click-permission; ''
  • 这些权限可以根据你的需要自行设置，也可以留空，无需任何权限！
