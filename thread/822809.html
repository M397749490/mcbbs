前言：以前我记得见到过这个模组，不过现在似乎找不到了，所以搬运一下。

介绍：这个模组允许你在主世界中只有一种生态群系，例如：平原生物群系世界，冰雪生物群系世界，甚至是其它模组的生物群系世界。

配置文件:
  1. # Configuration file

  3. general {
  4.     # Logs helpful debug messages to the console.
  5.     #  [default: false]
  6.     B:"Enable Debugging"=false  （调试部分可以不管）

  8.     # If you enter a biome ID here, the whole world will consist of only that biome.
  9.     # Set to -1 to generate the world normally.
  10.     # Vanilla biome IDs can be found here: http://goo.gl/WqlAfV
  11.     #  [range: -1 ~ 255, default: -1]
  12.     I:"Lonely Biome ID"=-1 （在这里输入生物群系的ID，主世界就默认只有该生物群系）
  13. }
复制代码
注意：生物群系的ID不是一尘不变的，如果较多可能会有改变，请根据实际情况改变。
