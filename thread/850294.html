函数效果塔 | 1.13.X
Minecraft 效果塔原版数据包 by 小超_酱@bilibili  mango2017@mcbbs


§1  简介
函数数据包效果塔主要作用为，将盔甲架放置在不同的方块上可产生药水效果，以此用来对人物/生物产生相应的效果，以此达到药水的效果。
ps：效果可重复使用（效果塔也可以放置在水下），也可以完全埋在方块中使用。

§3  函数编辑
函数编辑文件路径：.minecraft\datapacks



§3.1  tick.json编辑
tick.json文件路径：.minecraft\datapacks\data\minecraft\tags\functions
  1. {
  2. "values":[
  3. "xiaoguota:ta"
  4. ]}
复制代码

§3.2  ta.mcfunction 效果编辑
ta.mcfunction文件路径：.minecraft\datapacks\data\xiaoguota\functions

示例讲解：
  1. execute as @e[type=armor_stand,tag=!xgt] at @s if block ~ ~-0.1 ~ gold_block run data merge entity @s {CustomName:""§e§lshanghaixishou"",CustomNameVisible:1}
  2. execute as @e[type=armor_stand,tag=!xgt] at @s if block ~ ~-0.1 ~ gold_block run tag @s add xgt
  3. execute at @e[type=armor_stand,name="§e§lshanghaixishou",tag=xgt] run effect give @a[distance=..25] absorption 1 0 true
复制代码

友情链接：wiki百科[中国版]

§3.3  ta.mcfunction 衣架旋转编辑
ta.mcfunction文件路径：.minecraft\datapacks\data\xiaoguota\functions

#旋转塔
  1. execute as @e[type=armor_stand,tag=xgt] at @s run tp @s ~ ~ ~ ~10 ~
复制代码
§3.4  ta.mcfunction 敲掉方块效果失效编辑
ta.mcfunction文件路径：.minecraft\datapacks\data\xiaoguota\functions

#清除标签
  1. execute as @e[type=armor_stand,tag=!xgt] run data merge entity @s {CustomName:"",CustomNameVisible:0}
  2. execute as @e[type=armor_stand,tag=xgt] run tag @s remove xgt
复制代码

§5  原理介绍
通过检测特定标签盔甲架是否在指定方块上，从而引发相应设定的效果给予玩家or生物，如果检测当前的盔甲架与本条不一致，将切换下一条继续检测，从而使得更多的效果运用到效果塔中，并保持各个效果不发生冲突，这也是我的世界更新到1.13.X之后一次重大的突破吧[不代表官方说明，仅本人感言]，也感谢mojang提供我的世界。
