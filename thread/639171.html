前言
   Flanmod是众所周知的一个枪械类mod，它由外国人开发完成，并且国外的FLAN扩展包在质量完全超过国内大部分FLan扩展包，在数量上更是没得比，因此本人写出该帖子，是为了让大家更好地了解这个软件，并制作出好的扩展包！本人写出这个帖子，不是给你们骂，不是给你们泼污水的！有人骂我骗子，我只能说我从没卖过教程，如果是这样，我不介意再进行技术封锁。好心有好报，希望大家能够支持！
================教程开始！================
注意：有些电脑可能需要下载net framework 4.0才能运行flantoolbox
请各位先检查电脑中是否安装了net framework 4.0
否则出现了一系列千奇百怪的问题楼主也很难解释
点击下载Flan Toolbox
密码是：lymk
================华丽分割线================
==========安装Toolbox以及下载forge=========
楼主的FLAN讨论群有FlanToolbox工具合集下载
下载好之后他会提示你是否要购买付费版的Toolbox，假如你是专业人员你可以考虑购买
若不是的话那就选择No Thanks 进入后会看见一堆英文对不对？好心的楼主给大家翻译了一下  
打开上方的Package 里的Forge Gradel 点击上方的Setup里的Setup Forge Gradel with Flan’s Mod
开始下载forge，下载完forge后 打开上方的File 里的 Options 第一个路径选择 我的文\Toolbox 2.0\Forge\src\main\java\com\flansmod\client\model\
第二个路径选择 我的文档\Toolbox 2.0\Forge\eclipse\Flan\ 注意:选择路径的时候要用右边的Browser选择
==========安装JDK7以及完成环境配置==========
嘛，这个JDK7主要是帮助你把做好的模型转成Flanmod可以读取的文件 JDK7下载链接：http://www.oracle.com/technetwor ... nloads-1880260.html
讲道理，安装完JDK7之后我们还需要对系统环境进行配置
WIN7系统的JDK环境配置：点我查看
WINXP系统的JDK环境配置：点我查看
==========制作前的设置==========
这个时候默认的模型是plane（飞机），我们先打开上方的Model选项，看到里面会有个Model Setting。 先填写必要的信息！ModelName填写你这个模型的名字，至于ModelID一般可以不用填写！
点开model type然后选择gun，这样你就可以开始制作flan枪械了！！
记住，每次创建新的模型的时候都要先切换模型类型！默认是飞机模型！ Model scale 可以对整体模型进行缩小或者放大！
Texture Size X和Texture Size Y是修改贴图大小！
接下来你可以选择steve这个选项，把show steve和shooting steve打勾！
X,Y,Z坐标是调整史蒂夫的坐标
=========楼主的建模方法==========
1.先找一幅图片，把它分解成一些你可以理解的立体图形！
2.尽量用手把这个枪械在纸上画出来，便于更好地理解这个模型
3.新手可以用普通的box模块和shapebox模块来进行建模
4.你可以把你的模型上传到群文件的作业中，群主每个星期都能帮你们进行修改
==========★模型导出以及载入游戏★==========
（本人的教程可能需要软件eclipse来辅助进行模型导出！）
首先先确保你能够下载好上面所说的Flanmod Gradle build这是一个构建扩展包环境的文件
确定没有问题之后先设置把枪模导入你自己的包里面
