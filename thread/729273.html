插件介绍
本插件并非CrackShot的加强版，两个插件的作者也不是同一人

CrackShot自带枪械升级 | 更多属性显示
“击杀记录”代表死在这把枪下的玩家数量


搭配材质包 | 更真实的枪械效果


夜视瞄准镜 | 体验真实狙击


装弹进度条 | 更真实的换弹体验
可在visualreload文件夹里设置相关内容


真实方块裂纹 | 击碎方块自动复原
方块种类，复原时间均可以配置


枪械附属组件 | 自由拆卸 | 添加更多效果
可在attachments文件夹里设置相关内容



枪械皮肤 | 同一种枪 | 不同颜色皮肤
可在skins文件夹里设置相关内容


枪械合成配方 | 有序合成 | 无序合成
可在weaponrecipes文件夹里设置相关内容


枪械粒子效果 | 100%可配置
可在trails文件夹里设置相关内容


安装与使用
  • 本插件适合版本1.8起步，但是对于1.8版本来说，很多机制无法使用，材质包也不能使用，所以建议服务端版本1.9以上
  • 使用本插件之前必须先安装CrackShot，这里提供一份0.98.7的版本
（CrackShot的作者终于想起了自己BukkitDev的密码……）
CrackShot.jar (149.82 KB, 下载次数: 916)
2017-10-27 12:52 上传
点击文件名下载附件

  • 如果你还没有使用过CrackShot，请参阅这个站内搬运帖或者这个Bukkit原帖
  • 你还可以安装这个附属插件Zoom++，这是一款适合CSP的枪械放大镜插件，非必须


  • 两个插件都安装好了以后，输入/shot list即可发现在CS自带的枪械里多出了一些以“_CSP”结尾的枪械，输入/shot get <枪械名>即可获得相应枪械

  • 如果想要重载插件，最好把两个插件一起重载，以避免出现问题
  • 枪械的适配材质包会在安装后自动生成在CrackShotPlus插件文件夹中，不在帖内放出


关于组件、皮肤、粒子，甚至装弹进度条，都可以以物品的形式添加到枪械上
管理员手持枪械输入以下指令可以查看并获得适合该枪械的各种组件
  1. # 查看可用附属组件
  2. /attachment all
  3. # 查看可用皮肤
  4. /skin all
  5. # 查看可用粒子
  6. /trail all
  7. # 查看可用装弹进度条
  8. /vis all

指令&权限

CrackShot指令
  • /shot list - 列出所有CrackShot枪械
  • /shot get <枪械名称> - 获得枪械
  • /shot give <枪械名称> <玩家名> - 让玩家获得枪械
  • /cs config reload - 重载CrackShot

CrackShotPlus指令
  • /csp item list - 列出所有CrackShotPlus物品
  • /csp item get <物品名称> - 获得物品
  • /csp item give <物品名称> <玩家名> - 让玩家获得物品
  • /csp reload - 重载CrackShotPlus

  • /attachment all - 手持枪械查看适合安装的附属组件
  • /skin all - 手持枪械查看适合安装的皮肤
  • /vis all - 手持枪械查看适合使用的装弹提示语
  • /trail all - 手持枪械查看适合使用的粒子效果

  • /attackment - 手持枪械安装附属组件
  • /skin - 手持枪械安装皮肤
  • /vis - 手持枪械使用装弹提示语
  • /trail - 手持枪械使用粒子效果
  • /detach - 手持枪械拆卸附属组件


权限
本插件默认权限已经配置好，不需要再修改
玩家默认拥有的权限
  • csp.use.all - 使用所有枪械
  • csp.attachment.all - 使用所有附属组件
  • csp.ammo.all - 使用所有子弹
  • csp.visualreload.all - 使用所有装弹提示语
  • csp.trail.all - 使用所有种类粒子效果
  • csp.skin.all - 使用所有种类皮肤
  • csp.see.killfeed - 看到击杀提示
