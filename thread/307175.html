简介：
  曾经想拥有可以用命令或者物品来隐藏全部玩家的插件？那么接下来的东西就可以满足你！你可以通过配置或者简单的命令/hideallplayers来更改任何物品用来隐藏玩家。
（这个插件用于大型服务器是最好不过的了）

安装方法：
  把插件扔进Plugins文件夹里    重启服务器即可

指令：
  /hideallplayers - 开关之间的切换 （same as using the specified item 这句不是很懂，好像是使用指定的物品）
  /showall - 显示全部玩家
  /hideall - 隐藏全部玩家
右键使用指定的物品（免的输入命令）可以直接隐藏/显示玩家（默认物品为：Nether star 下届之星）

权限：
  hideallplayers.use ：可使用显示隐藏命令，和用指定物品隐藏/显示玩家
  hideallplayers.exempt ：拥有此权限者无法被隐藏

Config 配置文件：
  1. #Plugin created by arnofrutos
  2. #Use ~ to change the color of the messages
  3. toggleon: ~6All players have been vanished. - 所有玩家被隐藏了
  4. toggleoff: ~6All players have been revealed. - 所有玩家被显示了
  5. defaultpermission: false - 默认权限
  6. exempt: true - 免除
  7. item_id: 399 - 指定物品ID
  8. item_on_join: true - 这个应该是开启或关闭物品的使用 隐藏/显示
  9. item_name: ~6HideAllPlayers - 物品名字?
  10. item_lore: ~4Right Click to activate - 不懂
  11. antispam: ~cYou are not allowed to spam this item!
  12. antispam_delay: 3
  13. IncludedWorlds: - 所需世界
  14. - world
复制代码
