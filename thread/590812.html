----------原理----------

OOC全部指令↓
  1. /scoreboard players tag @e[type=Arrow] add Arrow2 {pickup:0b,CustomPotionEffects:[0:{Amplifier:0b,Ambient:0b,Duration:600,Id:2b,ShowParticles:1b}]}
  2. execute @e[tag=Sk2] ~ ~ ~ execute @e[tag=Arrow2,r=3] ~ ~ ~ entitydata @e[tag=Arrow2,r=0] {pickup:0b,CustomPotionEffects:[0:{Amplifier:0b,Ambient:0b,Duration:100,Id:25b,ShowParticles:1b}],Potion:"minecraft:water"}
  3. execute @e[tag=Sk2] ~ ~ ~ execute @a[r=3,score_dT_min=1] ~ ~ ~ effect @p 25 5 0
  4. scoreboard players set @a dT 0
复制代码
第一条指令是判断流浪者射的箭（

 这种箭不会被检测到的，因为玩家射的箭可以捡起，流浪者的不行）

第二条指令可以让指定标签的流浪者射出我们想要的药箭——失重
点击告示牌获得的射失重箭的流浪者有标签"Sk2"


这个OOC需要dT计分板——拥有玩家受伤则自加的准则
因为流浪者射的箭如果在半径3以内的话不会立刻改变NBT，即射的箭是原本的箭，所以第三条指令是为了弥补这个问题的


第四条是让dT清零，必须在第三条指令后


----------信息----------


做了这个OOC我发现，流浪者射的箭，即使被改变了NBT，射到生物时，还是会有缓慢效果(第二条指令如果是我NBT用错请告诉我)
