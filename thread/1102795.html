命令，我是switch，不能装外来物品

初始化:
/gamerule commandblockoutput false
/scoreboard objectives add deathCount dummy

tag @a add death.0
tag @e[type=player] remove death.0
scoreboard players add @a[tag=death.0,tag=!death.1] deathCount 1
tag @a[tag=death.0] add death.1
tag @e[type=player,tag=death.1] remove death.1
原理很简单 @a可以选中死亡玩家 @e不能选中死亡实体
如果@a能选中而@e选不中说明玩家死了
玩家死后deathCount+1再加上标记 防止重复加分
标记复活后移除
