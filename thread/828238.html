雷劫系统介绍:

神灵对人类开采资源的行为及其不满 于是降下了十八重天劫,既是惩罚又是馈赠!
玩家首先 需要觉醒仙根 这决定接下来雷劫的强度 以及修炼速度
接下来玩家需要通过战斗 击杀指定的怪物 获得历练经验 然后转化为自己的修为
修为一旦满后 玩家先面临第一重涅槃劫 度过后就能获得属性加成
并且获得学习更高战技的机会

配置过程介绍:

详细教程:https://SealFan.coding.net/s/33ce1246-ccd7-43aa-84c6-1b456e874ee8
我们为腐竹提供了基础配置, 如果不需要考虑属性平衡 装上立马就能修炼渡劫
每次雷劫的强度、数量、伤害、境界的修为限制都是自定义的
主要需要修改的就是属性值平衡问题

插件指令
/Xian
  • /xian dz 开始打坐! 权限:xian.use
  • /xian open 打开个人修仙界面 权限:xian.use
  • /xian join 觉醒 权限:xian.use
  • 以下为op指令,以上为玩家指令
  • /xian join [玩家名] 让玩家开始觉醒,并随机品质
  • /xian open [玩家名] 为玩家打开个人修仙界面
  • /xian kill 取消所有玩家打坐状态
  • /xian pvp [玩家]  改变玩家pvp状态
  • /xian gas [玩家] 数值 设置玩家的真气
  • /xian state [玩家] 数值 设置玩家的境界
  • /xian level [玩家] 数值 设置玩家的小境界
指令介绍
/Cobs
  • /cobs self 打开自己的战技背包
  • /cobs use [战技名称] 释放战技
  • /cobs remove  从战技背包移除所有战技
    以下为op指令,以上为玩家指令
  • /cobs create [战技名称] [战技学习需求进度] [战技消耗真气] 创建一个战技
  • /cobs trigger [战技名称] [战技等级] 技能 为战技添加技能
  • /cobs clear [战技名称] [战技等级] 技能行数 删除某行的技能
  • /cobs consume [战技名称] 真气数值 设置战技释放消耗真气
  • /cobs delete [战技] 删除战技
  • /cobs list 查看已创建的战技
  • /cobs view [战技名称] [战技等级]查看该战技信息
  • /cobs give skill [玩家] [战技名称] 给予玩家一个战技
  • /cobs cd [战技名称] 冷却时间 设置战技冷却时间
