★使用方法&指令&权限★
首先安装Vault前置，下载本插件，扔进plugins文件夹，重启服务器即可
如果想使用获得礼包执行指令等功能，请务必安装PlaceholderAPI前置，不安装也可以

本插件默认指令/kit可能和ess自带的kit冲突，若发生冲突请改为/akit

/akit view 查看礼包列表GUI菜单 advancedkits.view
/akit reload 重载插件 advancedkits.reload
/akit delete <礼包名> 删除礼包 advancedkits.delete
和ESS的冲突问题已修复



↓↓↓和玩家有关的权限↓↓↓
advancedkits.player
advancedkits.use.礼包名
有了这两个权限可使用以下两个指令
/akit view <礼包名> 查看该礼包内容
/akit use <礼包名> 获得该礼包

创建礼包教程与礼包配置，请接着往下看↓↓↓

★礼包制作教程★

————【创建礼包】————

输入/akit create <礼包名>，弹出菜单，你可以在菜单里放入想要放进礼包的物品，下面5个盔甲架分别代表头盔 胸甲 护腿 靴子 副手，左下角蓝色玻璃代表暂时保存，点击后可暂时关闭菜单，右下角绿色玻璃代表创建，点击即可创建礼包

请注意，必须把礼包属性autoequiparmor设置成true，礼包内穿戴才能真正在获得的时候穿在身上
请注意，你可以使用中文作为礼包名，但是中文礼包名在给权限的时候可能会出故障，所以还是推荐使用英文作为礼包名（只要不涉及权限的，可以用中文）

————【编辑礼包】————

输入指令/akit edit <礼包名> 即可进入礼包编辑界面，此时你便可以在自己的背包内给礼包增加/修改/删除物品，想要保存更改，请再输入一遍刚才的指令


————【使用礼包】————

给予玩家相应权限advancedkits.use.<礼包名> 玩家使用相应指令即可获得礼包

————【礼包属性】————
可以通过指令编辑礼包各项属性，达到不同的功能

基础指令（生效世界缺省默认是所有世界）
/akit flag <礼包名> <属性名> <属性修改值> [生效世界]
举个例子，我想让玩家每获得一次礼包就支付100金币，那么我可以
/akit flag <礼包名> perusecost 100
再举个例子，我想让玩家第一次进服就获得某礼包，那么我可以
/akit flag <礼包名> firstjoin true
现已证实firstjoin属性存在bug 请不要使用

————【属性列表】————
↓↓↓以下内容高能↓↓↓
加粗的属性值为默认属性

  • visible 当玩家使用/akit view时能不能在列表里看见这个礼包 可选[true/false]
  • firstjoin 玩家第一次进服是否获得这个礼包 可选[true/false]现已证实该属性存在bug 请不要使用
  • autoequiparmor 礼包内的盔甲玩家获得时是否直接穿在身上 可选[true/false]
  • clearinventory 当玩家获得这个礼包的时候是否清空背包内其他物品[谨慎使用] 可选[true/false]
  • spewitems 当玩家背包格子没有多余空间容纳礼包时，设置为true礼包物品会扔在玩家脚下，设置为false会无法获得礼包 可选[true/false]
  • displayname 礼包在/akit view列表里显示的名字 可加彩色代码
  • perusecost 玩家每次使用礼包需要支付的金钱 默认0不需要支付
  • maxuses 玩家最多能获得几次这个礼包？默认0是无限制
  • delay 两次使用同一礼包的时间冷却 单位是秒 默认0无冷却[想让某玩家无视冷却时间，给玩家加权限advancedkits.skipdelay.<礼包名>]
  • icon 礼包在/akit view列表里显示的图标 请把要改成的物品拿在手上，输入/akit flag <礼包名> icon hand
  • firework 请先制作一个漂亮的烟花并拿在手上，输入指令/akit flag <礼包名> firework hand 这样每当获得了一个礼包，都会产生这个烟花的特效
  • customdescription 礼包在/akit view列表里显示的lore，多行lore请用英文逗号隔开 举例/akit flag <礼包名> customdescription &6第一行lore~,&a&l第二行lore~
  • commands 玩家获得礼包时执行的控制台指令，多条指令请用英文逗号隔开，玩家变量请使用PlaceholderAPI变量 举例/akit flag <礼包名> commands kill %player_name%
  • messages 玩家获得礼包时显示聊天栏消息 物品栏消息 主Title消息 副Title消息 举例/akit flag <礼包名> messages 什么前缀都没有的是聊天栏消息 actionbar:这是物品栏消息 title:这是主Title消息 subtitle:这是副Title消息
  • disabledworlds 这个礼包禁止在哪些世界被领取 多个世界用英文逗号隔开
  • potioneffects 领取这个礼包获得的药水效果,多个效果用英文逗号隔开 指令/akit flag <礼包名> potioneffects <效果名>;<持续tick>;<效果等级> 举例：获得持续500tick的幸运II效果/akit flag <礼包名> potioneffects LUCK;500;1
  • particleeffects 领取这个礼包产生的粒子特效,多个特效用英文逗号隔开 举例/akit flag <礼包名> particleeffects EXPLOSION_LARGE,FIREWORKS_SPARK
  • soundeffects 领取这个礼包产生的声音，多个声音用英文逗号隔开 举例/akit flag <礼包名> soundeffects UI_BUTTON_CLICK,BLOCK_WOOD_BREAK
