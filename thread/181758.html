八月的第一天更新
鉴于现在 PocketMine-MP 1.4 的 新 API，本帖OldAPI插件已不能在 PM1.4 上使用本次更新说明：由于最近没有太多 NewAPI 插件发布，并且考虑到还有许多腐竹正在使用 PM1.3，所以这次更新主要更新了一些 OldAPI 但却非常流行的插件。
插件目录
OldAPI
  • UPVP 娱乐插件
  • ServerGuar 专业服务器管理系统
  • SmartSign 多功能智能牌子
  • ServerChatPro 模拟PC的聊天格式
  • Quitmsg 下线提示
  • TouchIt 楼主原创的多功能牌子传送插件
NewAPI
  • PocketMoney 口袋钱包
  • SimpleAuth Dev 用户登陆验证插件
  • AwaysSpawn 登陆出生在出生点
  • ChatBubbles 在头顶标签上显示聊天信息
  • HTTPServer 在 PocketMine-MP 里搭建一个简易地 HTTP 服务器
  • SimpleHome 允许你的玩家拥有一个自己的家
  • TimeCupsule 地图备份插件
  • DevTools 开发者必备插件
  • PaintMyLawn 给草染色
  • Portal 传送门插件
  • Economy 金钱插件
  • SpawnWithItems 第一次来到的玩家带着物品出生
  • EssentialsTP 各种先进传送功能
  • DisguiseMe 马上变成僵尸
  • PVPWorld 规定一个世界能进行PVP
  • BackDeath 输入命令，马上回到死亡地点
  • WorldMonitor 能显示世界人数的牌子传送插件
  • xPermsMgr 强大的权限管理系统
  • MoreHealth 允许你的玩家拥有更多的生命值

Old API (PocketMine-MP 1.3 及以下)
1. UPVP
作者：苦力怕辅助
来源：mcbbs.net
简介：这个插件可以对PVP进行积分并且有等级，积分可以在PVP商店中买东西，而且无需pocketmoney
链接：http://www.mcbbs.net/thread-223138-1-1.html
注：由于该插件已经提供了下载地址，故不再提供
2. ServerGuard
作者：RapDoodle
来源：mcbbs.net
简介：很多实用的管理方案整理到了一起
链接：http://www.mcbbs.net/thread-246526-1-1.html
注：由于该插件已经提供了下载地址，故不再提供
3. SmartSign
作者：RapDoodle
来源：mcbbs.net
简介：能帮您做很多事的牌子插件，如传送
链接：http://www.mcbbs.net/thread-231870-1-1.html
注：由于该插件已经提供了下载地址，故不再提供
4. ServerChatPro
作者：RapDoodle
来源：mcbbs.net
简介：这个简单的插件能够模拟出PC聊天的格式
链接：http://www.mcbbs.net/thread-196051-1-1.html
注：由于该插件已经提供了下载地址，故不再提供
5. Quitmsg
作者：张政中
来源：mcbbs.net
简介：这个插件解决了 PocketMine-MP 玩家下线时没有提示的问题
链接：http://www.mcbbs.net/thread-304508-1-1.html
注：由于该插件已经提供了下载地址，故不再提供
6. TouchIt
作者：Marcus
来源：mcbbs.net
简介：这是一个牌子传送插件，具有许多强大的功能，比如动态更新牌子，显示目标世界在线人数等
链接：http://www.mcbbs.net/thread-294550-1-2.html
注：由于该插件已经提供了下载地址，故不再提供
New API (PocketMine-MP 1.4 dev)
1. PocketMoney
作者：MinecrafterJPN
来源：pocketmine.net
简介：许多PocketMine-MP插件都会使用到这个插件的API。这是一个小巧的金钱插件。
链接：http://forums.pocketmine.net/plugins/pocketmoney.63/
注：由于该插件已经提供了下载地址，故不再提供
2. SimpleAuth Dev
作者：PocketMine Team
来源：github.com
简介：适用于新的API的用户验证插件。
链接：https://github.com/PocketMine/SimpleAuth
注：需要将其打包为 .phar 或者使用 DevTools 加载该插件。由于该插件已经提供了下载地址，故不再提供。
3. AwaysSpawn
作者：Comedyman937
来源：pocketmine.net
简介：每次用户登陆到服务器便会出生在服务器默认出生点，而并不会出生在最后一次离线的位置
链接：http://forums.pocketmine.net/plugins/alwaysspawn.284/
注：由于该插件已经提供了下载地址，故不再提供
4. ChatBubbles
作者：Comedyman937
来源：pocketmine.net
简介：将玩家的聊天信息显示在玩家头顶的标签上
链接：http://forums.pocketmine.net/plugins/chatbubbles.671/
注：由于该插件已经提供了下载地址，故不再提供
5. HTTPServer
作者：Falk
来源：pocketmine.net
简介：这个插件能在 PocketMine-MP 上搭建一个 HTTP 服务器，需要使用端口映射。默认使用端口 8080
链接：http://forums.pocketmine.net/plugins/httpserver.568/
注：由于该插件已经提供了下载地址，故不再提供
6. SimpleHome
作者：Dutok
来源：pocketmine.net
简介：这个插件允许你的玩家使用指令设置自己的家，然后在任意时间、任意地点输入指令传送回家
链接：http://forums.pocketmine.net/plugins/simplehome.658/
