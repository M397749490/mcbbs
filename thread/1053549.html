emm这两个组完全不是一个概念..
lp是全局权限组,VipSystem是通过独立的分组来操作权限组.

有两个解决方案:
① 修改vipsystem配置
  1. customCommands:
  2.   vip:
  3.     activate:
  4.       - 'lp user {0} parent add vip'
  5.     expire:
  6.       - 'lp user {0} parent remove vip'
复制代码
② 直接使用lp自带的临时权限组
  1. /lp user %player_name% parent addtemp vip 30day
