SkinChanger
本插件是Sponge版的更换皮肤插件,安装后玩家可以自由的更换自己的皮肤。


命令/权限

/sc - 获取命令列表.   [skinchanger.commands.help]
/sc version - 获取插件版本
/sc github - 获取插件 github.
/sc permissions - 显示自己拥有的本插件权限.
/skin <正版账号名称> - 设置你自己的皮肤.  [skinchanger.commands.skin]
/setskin <玩家名称> <正版账号名称>- 设置其他玩家的皮肤. [skinchanger.commands.setskin]
