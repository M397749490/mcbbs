介绍
GUI指南针是一个小型Mod，是TheVanillaExperience整合包的附属产物，可以简单显示坐标，这才是指南针嘛。
只需要将指南针放在身上(背包也可以)，就可以在游戏中显示坐标，默认情况下在左上角，你可以自行修改，具体的设置可以参考下面的配置方法的折叠，你或许还对[GUI时钟]感兴趣，可以点击这里赞助作者。

关于配置
以下内容未1.15.2下config/guicompass-common.toml的默认设置

[General]
        #启用后需要身上(包括背包)有携带才会显示坐标
        mustHaveCompassInInventory = true
        #将坐标显示置于在右边
        compassPositionIsRight = false
        #将坐标显示置于在中间
        compassPositionIsCenter = false
        #将坐标显示置于在左边
        compassPositionIsLeft = true
        #将时间显示的位置移动到垂直位置(Y轴)，即上下移动，可以一定程度上避免和其他显示重叠的问题。
        #范围: 0 ~ 3000
        compassHeightOffset = 5
        #修改坐标显示文字的RGB颜色
        #修改RGB颜色的R值(Red)
        #范围: 0 ~ 255
        RGB_R = 255
        #修改RGB颜色的G值(Green)
        #范围: 0 ~ 255
        RGB_G = 255
        #修改RGB颜色的B值(Blue)
        #范围: 0 ~ 255
        RGB_B = 255
