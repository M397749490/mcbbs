标题: 1.14.4PVP地图的一些命令问题
怎么让获胜者的名字显示在标题
如果地图有2人以上（不包括2人）
要怎么把被击杀的玩家变为旁观者模式，并且清空物品
当有一人获胜时，又要怎么把全部玩家传回主大厅并且把所有玩家的物品都清空
（总之就是PVP地图该有的一些东西吧）

作者: Chelover_C60    时间: 2019-10-4 13:09

1、
假设获胜者拥有winner标签
  1. /title @a title [{"text":"获胜者是："},{"selector":"@a[tag=winner]"}]
复制代码

2、需要借助计分板
①建立计分板
  1. /scoreboard objectives add death deathCount
复制代码
②游戏进行时，高频执行以下命令
  1. /gamemode spectator @a[scores={death=1},tag=!death]
  2. /clear @a[scores={death=1},tag=!death]
  3. /tag @a[scores={death=1},tag=!death] add death
复制代码

3、游戏结束时，直接tp所有人至大厅，并clear @a即可。
如果采用了我上面说的思路，记得重置计分板分数并移除death标签

winner标签要怎么给予呢？

这个要看你的游戏形式。
我通过你的后续问题判断，应该是存活到最后的玩家获胜吧。那就要检测玩家数量，或者简单排除玩家数量为1的情况。这里采用第一种思路。
首先，建立计分板（其实如果没有强迫症，直接用death计分板也可以）
  1. /scoreboard objectives add info dummy
复制代码
然后高频获取存活玩家数量并存入计分板，后检测分数
  1. execute store result score #playercount info if entity @a[gamemode=adventure]
  2. execute if score #playercount info matches 1 run tag @a[gamemode=adventure] add winner
复制代码
