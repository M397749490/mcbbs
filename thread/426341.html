1VS1小游戏插件

——创造你的决斗竞技场——



之前用过别的大大搬运的x1vs1，感觉蛮好的，就是功能少了点，今天偶然看到了这个插件0 0~！！虽然只有几十kb，但是自定义工具、创建房间、木牌显示、排行榜功能一应俱全，所以就搬运过来啦~~希望大家喜欢！~~



1vs1 Minigame Plugin




插件特性：
*        自定义多人竞技场
*        随机加入游戏
*        禁止飞行
*        可在游戏中禁用某些指令
*        移除药水效果
*        屏蔽死亡信息
*        胜利后会有公告提示
*        支持木牌显示加入/离开/排行榜
*        自动更新木牌内容
*        游戏不会影响到随身物品、武器和等级
*        游戏中禁用扔下、拾取物品
*        可配置玩家在游戏中是否能放置/破坏方块
*        可配置玩家在游戏中是否受到坠落伤害
*        一个指令就可以简单设置
*        可以使用附魔装备
*        TOP 5 排行榜
*        玩家统计数据
*        信息全部可以自定义
*        可自定的木牌状态

指令：
*        /1vs1 rjoin 加入随机游戏队列
*        /1vs1 join <Map> 加入一个已存在的竞技场
*        /1vs1 leave 离开队列/游戏
*        /1vs1 stats [player] 显示目标玩家的数据
*        /1vs1 top 显示TOP5排行榜
*        /1vs1 addmap <Mapname> 添加一个竞技场
*        /1vs1 setfirstspawn <Mapname> 设置竞技场的第一个出生地
*        /1vs1 setsecondspawn <Mapname> 设置竞技场的第二个出生地
*        /1vs1 setlobby 设置游戏结束后玩家被传送的地方

权限：
*        1vs1.admin -> 全部的管理权限（慎用）。


木牌写法：
加入木牌:
第一行: 1vs1j
第二行: <Mapname>
离开木牌:
第一行: 1vs1l
TOP5 排行榜:
第一行: 1vs1t
资料木牌:
第一行: 1vs1s
写完后请右键木牌来激活它！

自定义竞技场武器：
  • 要想使用自定义武器，在 kit.yml 中将kit 设置为true. 在服务器中装备好武器后使用指令： /1vs1 savekit
  • 重启插件

重要的设置：
*        如果 falldmg : false ，玩家将不会受到坠落伤害。
*        如果 place: true 玩家在竞技场可以放置方块。
*        如果 break: true 玩家在竞技场可以破坏方块。

插件测试服务器：
*        如果想测试插件效果可以连接这个服务器： IP: novablocks.net

自定义Messages：
*        在 messages.yml 中修改. （暂时不支持颜色代码，后续版本中会添加这项功能）

安装方法：
原作者说要确定你使用的是最新的SPIGOT客户端： SPIGOT VERSION (MIN: 1.8.3)，
我在1.7.10上面测试的时候暂时没有发现问题（并不是没有问题！！）
