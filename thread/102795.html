新版其实很早就做好了，可是编辑帖子很多次都没成功，因为主题分类没办法选择，刚发现是因为论坛不支持Chrome，悲剧。
新版本的配置文件格式已经更改，建议删除config\MoreOres.cfg（不删除影响不大，只是妨碍手动配置）
新版特征：
默认矿石倍率下调至3倍（从5倍下调）
支持平坦基岩生成（需更改配置文件中flatbase的值为true）
支持其它矿石mod（内置支持IC2、ThermalExpansion、Railcraft、Forestry，其它可自己按格式添加）

希望喜欢这个mod的人都能留言支持，这是mod维护唯一的动力。

旧版本：

以前custom ore generation的mod一直没更新，就自己做了一个，所以这个MOD的作用就是根据minecraft的生成规则生成更多的矿石，没有custom ore generation中仿射和矿脉的生成规则，好处是不破坏地貌，不乱生成该生态没有的矿石（custom ore generation会在所有生态中生成绿宝石，原版仅会在山岭生态的地下1～32层中生成）
采用Forge 7.7.0.608编译，未测试其他版本的兼容性，欢迎反馈。
安装方法：先参照论坛其它帖子安装Forge 7.7.0.608，然后把下载的zip文件放到.minecraft\mods文件夹下

想体验更多矿石，需要新开存档（不开新存档时跑出已生成的区块也可以体验，但是否跑出去了自己要弄清楚）
前面说了MOD的开发原因，所以本MOD不准备支持1.4.7及之前版本，需要1.4.6或1.4.7版本的，请下载Custom Ore Generation，地址是http://www.minecraftforum.net/topic/1107057-

可以生成的矿石包括：
主世界的煤矿、铁矿、金矿、红石矿、青金石矿、钻石矿以及只在山脉生态生成的绿宝石矿
下界的萤石矿以及石英矿

默认生成倍率全部为5倍，安装mod运行一次会在config文件夹下生成MoreOres.cfg，用记事本打开可以看到以下内容


  1. # Configuration file

  3. ####################
  4. # rate
  5. ####################

  7. rate {
  8.     D:coal=5.0
  9.     D:diamond=5.0
  10.     D:emerald=5.0
  11.     D:glowStone=5.0
  12.     D:gold=5.0
  13.     D:iron=5.0
  14.     D:lapis=5.0
  15.     D:netherQuartz=5.0
  16.     D:redstone=5.0
  17. }


  20. ####################
  21. # size
  22. ####################

  24. size {
  25.     I:coal=16
  26.     I:diamond=7
  27.     I:emerald=9
  28.     I:glowStone=11
  29.     I:gold=8
  30.     I:iron=8
  31.     I:lapis=6
  32.     I:netherQuartz=13
  33.     I:redstone=7
  34. }
复制代码

rate的部分就是生成的倍率，越高矿石越多，但生成也耗时越多，不要太大，size的部分是每个矿脉生成的最多矿石数目，建议不要更改。
