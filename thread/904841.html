BetterTitle —— 更好的称号

简介
因支持属性插件的称号插件比较少，所以写出来造福广大服主。

欢迎加入作者的讨论小群: 613869152 作者[qq]2191746730[/qq]


PAPI变量:
  • 前缀: %bt_prefix%
  • 后缀: %bt_suffix%

已兼容:
  • SX-Attribute (3.x版本未兼容）


特点
  • 全新的前缀后缀
  • 支持MYSQL数据库
  • 称号仓库 chat(聊天框) inventory(GUI容器)
  • 支持属性插件 插件: SX-Attribute2.x
  • 支持TAB显示PAPI变量
  • 限时称号

[skelecton]命令&权限
命令&权限:
OP:
  • /bt add <player> <title> 给予玩家称号 - besttitle.command.add
  • /bt remove <player> <title> 删除玩家称号 - besttitle.command.remove
  • /bt reload 重载插件配置 - besttitle.command.reload

Player:
  • /bt list <page> 查看称号仓库(不输入page默认第一页) - besttitle.command.list
  • /bt set <prefix/suffix> <title> 设置玩家的称号 0 besttitle.command.set
