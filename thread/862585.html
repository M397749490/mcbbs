BlockRegen
自定义的方块刷新

前置
  • DustCore


命令
None

权限
None

配置
  1. # 不同世界配置
  2. worlds {
  3.     world {
  4.         # 刷新方块类型
  5.         "minecraft:emerald_ore" {
  6.             # 刷新类型权重
  7.             blockWeights {
  8.                 "minecraft:air"=60
  9.                 "minecraft:coal_ore"=30
  10.                 "minecraft:diamond_ore"=2
  11.                 "minecraft:emerald_ore"=1
  12.                 "minecraft:gold_ore"=5
  13.                 "minecraft:iron_ore"=10
  14.                 "minecraft:lapis_ore"=2
  15.                 "minecraft:redstone_ore"=5
  16.                 "minecraft:stone"=40
  17.             }
  18.             # 方块刷新时间(秒)
  19.             regenTime=3000
  20.             # 破坏后占位方块
  21.             replaceWith="minecraft:air"
  22.         }
  23.     }
  24. }
复制代码


特性
  • 自定义方块刷新类型
  • 方块刷新间隔
  • 自定义占位方块
  • 保存数据到文件
