指令：
  1.     /ga gen                                 generate a Secret-Key 生成一个密钥
  2.     /ga login <One-Time-password>           login server  登录服务器
  3.     /ga logout                              logout server 登出服务器
  4.     /ga mycode [One-Time-password]          show my secret-Key 显示我的密钥
  5.     /ga <on|off>                            turn on/off my login authentication 启用或停用自己的登录验证
  6.     /ga regen <One-Time-password>           regen the Secret-Key 重新生成一个密钥 （not finish yet）
  7.     /ga show <PlayerName>                   show Player's Secret-Key 显示某个玩家的密钥 （admin only）
  8.    
  9.     --setting--
  10.     /ga <enable|disable>                    enable or disable this plugin 停用或启用插件
  11.     /ga forceauth                           
  12.     force auth player when login (players who didn generate keys will be kicked)
  13.     登录时强制验证玩家（未生成过密钥的玩家将会被踢出）

配置文件：

展开查看


autoLoginCoolingTime=3000  
如果玩家登出超过这个时间，将不会自动登录
enablePlugin=true
启用或停用自动登录
forceAuthAllPlayer=false
登录时强制验证玩家（未生成过密钥的玩家将会被踢出）
languageFile=en_us.lang

语言文件名，可以从git仓库下载（码云）
loginTimeout=30000 (not finish yet)(功能未完成)
如果玩家进入服务器超过这个时间未登录，将会被自动踢出。
passwordIncorrectKickTime=3
如果玩家登录密码错误超过此次数将会被踢出服务器。
settingVersion=1.0.0
配置文本版本号，不要修改！
showTipsForUnregisterPlayer=true
在玩家登录时推荐用户启用google验证码验证
usingAutoLogin=true
允许玩家短时间内无密码登录(配置项：autoLoginCoolingTime)
windowSize=10
谷歌验证器的窗口时间
如果太低将导致玩家很容易验证失败（如果玩家时间和服务器相差过多）
如果太高将会导致密码容易被随机猜出
默认设置10，允许设置1~17之间的数字
