接下来讲解设置价格。
上一篇教程中提到过计算总价时使用数量*单价(废话)
所以直接修改单价即可，我们这里读取记分板上(购买数量)的数字并赋值到价格分数上：
  1. /scoreboard players operation @e[type=armor_stand] j = @e[type=armor_stand] count
复制代码
之后清空分数：
/scoreboard players set @e[type=armor_stand] count 0

即可。
