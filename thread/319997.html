首先介绍useItem函数的作用

useItem函数属于钩子（hook）函数，作用就是捕捉发生的事件

useItem的作用就是当进行一次点击时(如使用物品或放置方块，食用食物不包括在内)会触发这个函数，并返回数据。

格式如下

  1. function useItem(x,y,z,itemId,blockId,side,itemDamage,blockDamage){}
复制代码

看到这个，你肯定会问：怎么用呢？

很简单，首先弄懂“返回数据”这句话

你可以理解“返回数据”其实就是当你触发这个useItem函数时，它把有关的数据返回并储存起来了

那你肯定会问它返回什么数据呢？

很简单，小括号里的就是返回数据

我来列个表


x代表被点击方块的x坐标

y代表被点击方块的y坐标

z代表被点击方块的z坐标

itemId代表点击时手里拿的物品id(空手为0)

blockId代表被点击方块的ID

side代表方块被从哪个方向点击

itemDamage代表点击时手里拿的物品附加值(也就是伤害值)

blockDamage代表被点击方块的附加值(也就是伤害值)

（最后两项其实一般初学者不太会用到）


然后，怎样使用这些数据呢？

我不讲，请仔细阅读http://www.mcbbs.net/thread-204040-1-1.html

接下来是实例（由于http://www.mcbbs.net/thread-204040-1-1.html讲得比较详细就不多讲）

  1. function useItem(x,y,z,itemId,blockId)
  2. {//一开头的函数部分，后面紧跟if语句
  3. if(itemId == 267&&blockId == 89)
  4. {//如果用id为267的物品即铁剑点击id为89的方块
  5. setTile(x,y,z,0);//在点击地点的坐标放置id为0的方块即空气
  6. preventDefault();//阻止原来的动作
  7. }
复制代码

后面的setTile，与preventDefault等都是实体设置函数

也就是对某个实体设置某种事件，并将其触发，这个在这里不多讲，以后会讲。
