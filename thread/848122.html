标题: DynmapExport —— 导出dynmap为一整个大图
本帖最后由 hoshizorayuki 于 2019-3-1 05:01 编辑

本工具支持从dynmap的mysql表中提取渲染结果，整合成一个大图。
注意：仅支持mysql存储方式

使用方法：
Option
Description
--db-password
--db-url
like jdbc:mysql://localhost/mc
--db-user
--map-id
usually was "flat"
--table-prefix
such as "dynmap_build_"
--threads
working threads, should be integer, default to 10, must > 0 (default: 10)
--world
world name
--zoom
zoom, should be integer, starting from 0


示例：
  1. java -jar DynmapExport-1.0-SNAPSHOT.jar --db-url=jdbc:mysql://localhost/mc --db-user=mc --db-password=123123 --map-id=flat --table-prefix=dynmap_ --world=world --zoom=0
复制代码

编译好的jar的下载地址: https://github.com/theTd/DynmapExport/releases
源码(GPLv3): https://github.com/theTd/DynmapExport
