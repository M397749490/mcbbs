如果是1.13+的版本,可以用
  1. /execute as @a at @s if entity @e[type=minecraft:experience_orb,distance=..10] run tp @e[type=minecraft:experience_orb,distance=..10] @s
复制代码
和
  1. /execute as @a at @s if entity @e[type=minecraft:item,distance=..10] run tp @e[type=minecraft:item,distance=..10] @s
复制代码
两个指令实现一定范围内物品和经验传送到身边从而达到加大拾取范围的目的(数据包)
