授权


功能
· 让玩家自由设置地标点
· 可配置每个玩家最大建立地标的数量
· 可配置地标名最大长度
· 延迟传送
· 危险传送保护（玩家仍可传送，但传送前会发送警告，若玩家确认传送再执行传送）
· 建立/传送至地标点扣除游戏币（需Value）
· 可列出所有地标点
· 可启用GUI以显示所有地标点
· 玩家可自定义地标点的名称，描述等
· 高度自定义
· 支持 Plotsquared（使玩家只能在自己的地皮中设置地标点）
· 支持 Worldguard（禁止玩家在Worldguard保护的地方设置地标点）
· 支持 ASkyBlock（使玩家只能在自己的空岛中设置地标点）
· 支持 GriefPrevention（使玩家只能在自己的区域内设置地标点？？？）
· 支持在某些世界禁用地标点
· 支持从MyWarp直接继承数据至Player Warp
· 作者非常勤奋！（我发帖前五分钟它才发布了V4.2.5！）
· 作者会自动从你的服务器收集信息以改进插件（可关闭但不推荐）
· 作者对插件功能的描述
A Plugin that allows players to set their own warps. This also supports loads of other plugins!

Features:
  • Plotsquared Support
  • Worldguard Support
  • ASkyBlock Support
  • GriefPrevention Support
  • Set warps per player
  • Multiple warps per player
  • Ability to list all warps
  • Ability to remove warps
  • Highly customizable
  • Easy to setup
  • All automatic!
  • A GUI to list all of the warps
  • Manage your Warps in a GUI
  • Purge warps
  • Detect unsafe warps
  • Delay to teleport to a warp
  • Economy Support
  • World Support

命令
/pwarp - 打开帮助菜单，或者切换打开GUI菜单
/pwarp <warp> - 传送至一个地标
/pwarp set <warp> - 在你的位置设置一个地标
/pwarp remove - 删除地标
/pwarp list - 列出所有地标
/pwarp open - 打开GUI菜单
/pwarp reload - 重新加载插件
/pwarp addwarps <player> <amount> - 给予他人额外的地标上限'
权限
pw.limit.X - 玩家能拥有几个地标
pw.limit.* - 玩家可拥有∞个地标
pw.delay.bypass - 可以绕过延迟直接传送
pw.admin.bypass - 可以在任何地方设置地标点
pw.admin.delete - 可以删除自己和他人的地标点
pw.admin.reload - 可以用指令重载插件
pw.admin.update - 可以在加入的时候看到插件更新的信息
pw.admin.addwarps - 给予他人地标的权限
