dynos01，你好。

1.你可以尝试在淘宝购买DDos刷流量，指定目标为自己的服务器，以此确定压测能力和服务器硬防。
2.(转自http://mcbbs.tvt.im/thread-196018-1-1.html)
可以按照以下步骤估算性能：
1.确定基数
如果 真核数 <= 6 则 基数 = CPU 真核数 x 最高睿频（核心少时通常能全核心最高频率运行）
如果 真核数 > 6 则 基数 = CPU 真核数 x 默认主频（核心多时往往默认主频更能反映 CPU 通常运行的频率）
如果手动超频则 基数 = CPU 真核数 x 全核心最高同步主频（手动设置的频率自然不用说了）
2.Buff/Debuff
如果为 Intel CPU 则 基数 x 1.8（根据 FX6300 ≈ i5-6400 计算）
如果支持并开启超线程则 基数 x 1.6（根据 Cinebench、Fritz Chess Benchmark、FPU Julia、FPU Mandel 等跑分结果归纳出的数值）
如果默认主频 < 2GHz 则 基数 x 0.8（默认主频低会影响一些服务端核心线程的运行速度，也可能可以侧面反映出你使用的是低性能电脑）
基数 x 1.05^n，n 为 (CPU 发布年 - 2015)，n 可为负数（根据个人经验优化版的摩尔定律）

3.测试网络速度，因为有时候其实并不是你的服务器在卡，而是网络带宽资源狭窄。可以在http://www.speedtest.net/测试。
(4.这是附加的。如果你想防御攻击，可以试试http://mcbbs.tvt.im/thread-654195-1-1.html。)

理论上来讲，一般在外租的Linux系统的VPS最起码能撑20人同时游戏，因客户端而异。
随着你增加插件、Mod的增多，服务器也会因为负载资源越来越多而缓慢运行。
