命令
/repl help 查看所有命令

使用
  • 安装前置插件 UDPLib、ProtocolLib 等
  • 启动 Bukkit 服务器
  • 添加你的游戏名到 config.yml 中
  • 重新启动服务器
  • 输入 /repl start 打开终端
  • 开始输入代码
  • 输入 :shut 关闭终端

特性

支持远程执行代码
支持添加默认变量和指令
支持 Java 8 Lambda

下载
你可以在我们官网获取最新版本

WIKI
你可以在我们官网查看更多帮助信息

已知 Bug
暂时发现，但已发现 UDPLib 1.1.1 存在以下 Bug：
1. SLang 未正常 trim() 导致国际化支持错误
2. 命令的 Tab 完成提示无视权限
建议你使用 1.1.2 或以上版本的 UDPLib（如果更新了的话）
