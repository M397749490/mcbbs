————前言————这款插件可以用任何的东西来实现传送
比如用踏板 按钮 牌子等
非常方便 解决了 那种地狱门的嘈杂声
并且自动执行传送命令 方便！
(以上是我自己说的)
————作者的前言————
英文版:
Color Portals relies on only physical items in the game, (wool, pressure plates, buttons, and signs), to create portals. Also, you do not need to run back and forth between portals setting locations as Color Portals does this automatically. And above all, there are no commands necessary so you don't have to take time away from building to type things!



————作者提供的源码————
https://github.com/snowgears/Color-Portals



————这个插件好处是啥————
1,不用命令来建立传送门
2,传送门 自动连接起来 不用来回跑来跑去 设置
3,与MV和MW多世界兼容，实现多世界传送
4,无需权限 (但是还是有权限的)
5,不用配置 (但是想要更多的好处 需要配置)
6,装进plugin文件夹 就可以用 不用前置插件


————自选命令————
/portal list 或者 /cp list — 显示服务器有多少个传送门
/portal info 或者 /cp info — 寻找一个传送门


————权限————
colorportals.use —— 使用传送门权限
colorportals.create —— 创造传送门权限
colorportals.destroy —— 破坏传送门权限


————下载地址————
http://dev.bukkit.org/bukkit-plugins/color-portals/files/

这个插件有前途 估计2015.4.5 汉化完毕
