简介
同样是看标题就知道MOD的用途的MOD类型。
这个非常简单的MOD能让Minecraft里面的一些动物以动物宝宝的形态生成。默认情况下，生成动物宝宝的概率大约为50%。
动物宝宝的年龄是随机的，所以动物宝宝会花更多或者更少的时间长大。

本MOD的描述也适用于1.1.0！

看看这个MOD的配置文件吧！（当然可以修改配置文件哦）
# Configuration file
general {
    # Chance for an animal to become a baby animal (default: 50.0)
    D:chance=50.0
生成动物宝宝的概率（默认：50.0（50%））

    I:max_age_ticks=24000
    # Maximum random value to set the baby animals age (default: 24000)
动物宝宝随机出现的最大年龄（默认：24000）

    I:min_age_ticks=6000
    # Minium random value to set the baby animals age (default: 6000)
}
动物宝宝随机出现的最小年龄（默认：6000）

  # List of mobs that can spawn as baby (default: [minecraft:chicken, minecraft:pig, minecraft:cow, minecraft:sheep, minecraft:mooshroom])    S:mobs_affected <        minecraft:chicken        
minecraft:pig        
minecraft:cow        
minecraft:sheep        
minecraft:mooshroom     >}
能以宝宝形态生成的生物名单（默认：鸡、猪、牛、羊、哞菇）

mod_support {    # Whenever the Zombie Chicken should be made baby in the Baby Mobs mod (default: false)   
B:baby_mobs=false
支持生物宝宝MOD
无论何时，生物宝宝MOD中的僵尸鸡以宝宝形态生成（默认：关闭）

更新日志
1.0.4
增加每种动物生成动物宝宝的几率设置。
村民在默认设置下有15%的几率生成村民宝宝。

1.0.3
增加了 能增加更多以宝宝形态生成的生物的配置。

1.0.2
支持生物宝宝MOD。
你可以在配置文件中设置是否以宝宝形态生成僵尸鸡。默认关闭。

1.0.1
发布第一个版本。
