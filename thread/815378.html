settings:
    sessions:
        # Do you want to enable the session feature?
        # If enabled, when a player authenticates successfully,
        # his IP and his nickname is saved.
        # The next time the player joins the server, if his IP
        # is the same as last time and the timeout hasn't
        # expired, he will not need to authenticate.
        enabled: true
        # After how many minutes should a session expire?
        # A player's session ends after the timeout or if his IP has changed
        timeout: 720    开启这个功能AUTHME  这样一段时间内 可以不用再次输入密码 除非此账号更换IP

作者: robbit    时间: 2018-8-18 18:16
楼上说的正解

Authme 可以设置同IP登录某账号后在规定时间内重新使用此IP登录账号不需要输入密码

目前我的服务器设定的是十分钟内重新登录不需输入密码，你可以根据自己的需求适当修改时限，比如将时间延长至数小时，在这个情况下一般玩家进行游戏的时间从登陆至下线都没必要重新输入密码
——————————————
或者换一种方式解决问题:
    例子: 禁止玩家输入指令返回大厅 + 子服内使用菜单跨服

    这样可以解决玩家会重新进入大厅的问题，同时也能保证跨服的便利性，当然具体还是要视情况而定

——————
PS: 如果要开启 Authme 的IP验证功能，建议先检查 BC 与子服之间的 BC 选项是否开启
