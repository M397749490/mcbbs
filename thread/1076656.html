本帖最后由 wjwrh 于 2020-7-12 10:21 编辑

装一个权限插件
例如luckperms https://www.mcbbs.net/thread-676818-1-1.html
然后给基础权限就行了
具体是什么权限要看你装的什么基础插件

如果安装luckperms的话
使用指令
/lp group default permission set 权限名
即可为默认组添加权限

一般服务器里面基础插件都是ess
给权限
essentials.build
essentials.tpa
essentials.tpaccept
这些之类的
