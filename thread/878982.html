ChopTree2
说明
ChopTree2回归，目前新版最低支持1.14版本，已测试1.14.X
，1.15.X，1.16.X均受支持，若有什么问题可以先检查一下报错内容。这是服务端插件，不是mod。论坛的其他砍树插件暂时还未发现支持1.14版本以上的，因此转载过来，希望各位支持下。
指令
基本用不到的指令如下
/choptree 可在游戏内看到插件配置，（如截图）可用短指令 /ct
/togglechop on/off 一键砍树开关，可用短指令 /tc
/choptree reload 重载插件
权限
choptree.*   所有权限
choptree.chop    一键砍树权限
choptree.commands.choptree.info   查看配置文件权限
choptree.commands.choptree.reload   重载插件权限
choptree.commands.togglechop   一键砍树开关权限

下面是用不到的OP权限，没什么卵用，就不翻译了
choptree.commands.choptree.*: Access to all admin commands
choptree.commands.choptree.toggle.*: Can toggle all choptree settings
choptree.commands.choptree.toggle.activebydefault: Can toggle this setting
choptree.commands.choptree.toggle.useanything: Can toggle this setting
choptree.commands.choptree.toggle.moredamagetotools: Can toggle this setting
choptree.commands.choptree.toggle.interruptiftoolbreaks: Can toggle this setting
choptree.commands.choptree.toggle.logsmovedown: Can toggle this setting
choptree.commands.choptree.toggle.onlytrees: Can toggle this setting
choptree.commands.choptree.toggle.leaves: Can toggle this setting

配置文件

# 此处中文仅用于对照设置配置文件，复制无效
ActiveByDefault: true
#新加入玩家是否获取一键砍树权限
UseAnything: false
#使用任何物品触发一键砍树功能
AllowedTools: WOODEN_AXE,STONE_AXE,IRON_AXE,GOLDEN_AXE,DIAMOND_AXE,
WOODEN_AXE,STONE_AXE,IRON_AXE,GOLDEN_AXE,DIAMOND_AXE
#指定物品触发一键砍树功能：木斧，石斧，铁斧，金斧，钻石斧
MoreDamageToTools: false
#是否消耗工具更多耐久值
InterruptIfToolBreaks: false
#耐久值不够时，是否砍掉整棵树
LogsMoveDown: false
#是否启用坎一段，下落一段
OnlyTrees: true
#玩家放置的一堆原木，砍掉时是否触发一键砍树，true为不触发
PopLeaves: false
#叶子是否直接全部掉落
MatchLogType: false
# 不清楚实际意义
LeafRadius: 3
#叶子掉落半径
