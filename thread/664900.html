BungeeCord跨服群组搭建教程
一、需要
1.租用VPS或者有一台自己电脑
2.下载BungeeCord.jar(无需翻墙与挂VPN)
新版本可以支持1.8-1.11了
#1119 = 1.7.10
#701 = 1.6.4
#666 = 1.6.2
#548 = 1.5.2
#386 = 1.5.0
#251 = 1.4.7
创建完毕后新建一个文件夹把BungeeCord.jar放入新建文件夹后
再创建一个bat文件打开
  1. @echo off
  2. "java路径" -Xmx256M -Xin1024M -jar BungeeCord.jar
  3. pause
复制代码
就会生成
modules文件夹
内有都可以在(http://ci.md-5.net/job/BungeeCord/)下载
cmd_alert
cmd_find
cmd_list
cmd_send
cmd_server
reconnect_yaml
plugins文件夹(插件文件夹里啥也没有)
需要自己可以加

二、config配置汉化
player_limit: -1
ip_forward: false
permissions:
  default:
  - bungeecord.command.server
  - bungeecord.command.list
  admin:
  - bungeecord.command.alert
  - bungeecord.command.end
  - bungeecord.command.ip
  - bungeecord.command.reload
#权限不用修改
timeout: 30000
log_commands: false
online_mode: true
#改为false否则为正版服
servers:
  lobby:
#子服名字
    motd: '&1Just another BungeeCord - Forced Host'
#服MOTD
    address: localhost:25565
#子服IP
    restricted: false
listeners:
- query_port: 25577
  motd: '&1Another Bungee server'
  tab_list: GLOBAL_PING
  query_enabled: false
  forced_hosts:
    pvp.md-5.net: pvp
  ping_passthrough: false
  default_server: lobby
#玩家上线的第一个服务器
  bind_local_address: true
  fallback_server: lobby
#玩家上线的第一个服务器
  host: 0.0.0.0:25577
  max_players: 1
#玩家上限
  tab_size: 60
  force_default_server: false
disabled_commands:
- disabledcommandhere
network_compression_threshold: 256
groups:
  md_5:
  - admin
#作者md_5有admin权限
connection_throttle: 4000
stats: e1b4a3a9-762d-4d9b-9075-510e1be14618
#不可修改


三、指令和相关权限
/alert 信息
权限点：bungeecord.command.alert
作用：显示一个让全服人都看的到信息
默认权限组：群组管理员

/alertraw  json格式的信息
权限点：bungeecord.command.alert
作用：显示一个让全服都看的到json格式信息
默认权限组：群组管理员

/perms
权限点：无
作用：显示你所在的权限组及拥有的权限
默认权限组：全体玩家

/send <玩家名/current/all> <目标子服务器名>
#all全体玩家传送到xxx服务器
权限点：bungeecord.command.send
作用：把xxx强制传送到xxx服务器
默认权限组：群组管理员

/bungee
权限点：无
作用：显示当前BungeeCord的版本信息
默认权限组：全体玩家

/end
权限点：bungeecord.command.end
作用：关闭BungeeCord服务端
默认权限组：群组管理员

/find <玩家名>
权限点：bungeecord.command.find
作用： 查询玩家在哪一个服并且在不在线
默认权限组：群组管理员

/glist
权限点：bungeecord.command.list
作用：显示各子服在线人数
默认权限组：全体玩家

/greload
权限点：bungeecord.command.reload
作用：重载BungeeCord服务端的配置文件，不重载插件
默认权限组：群组管理员

/ip <玩家名>
权限点：bungeecord.command.ip
作用：查找玩家IP
默认使用者：群组管理员

/server [子服务器名]
权限点：bungeecord.command.server
作用：跳转到一个子服务器
默认使用者：全体玩家


四、BungeeCord的BUG及修复办法
1.使用127.0.0.1来绕过登录
解决方法:
将每个子服务器的server.properties文件中的“server-ip=”填为“server-ip=127.0.0.1”

2.使用IP:md_5进入拥有群组的所有指令的权限
解决方法:
A.  ban md_5封了他
B.  把config的groups:改成groups: {}

3.受到压测
解决方法:
安装

六、如何创建登录服
1.找到BC中的config的
servers:
  lobby:
#可以改为登录服也可以自定义(服务器名)
    motd: '&1Just another BungeeCord - Forced Host'
#&1Just another BungeeCord - Forced Host可以修改(MOTD)
    address: localhost:25565
#25565可以修改
    restricted: false
再找到下面这两个
    default_server: lobby
#lobby可以改为登录服也可以自定义
    fallback_server: lobby
#lobby可以改为登录服也可以自定义
