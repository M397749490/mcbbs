COVID-19


插件介绍

Covid-19是一种病毒，它将随机出现在实体上，并可以传播给玩家、污染方块。
插件作者标记1.12-1.15均可使用，但本人仅在1.15成功加载了插件
玩法

感染
如果靠近被感染的实体、玩家，被感染者攻击或吃被污染的食物都有很大可能会感染Covid-19。

起初没有任何现象，但经过4分钟后会玩家会收到被感染的提示，并警告其他玩家，感染者将获得越来越多的负面buff最后会死亡（创造模式也会死）。

玩家可以使用一些物品降低感染风险、使用药物治疗。

污染
感染者可能会污染走过的地面，被污染的地面有概率扩散，甚至感染健康的玩家。
方块被污染一分钟后将会改变材质并产生粒子效果，最后将消失。

可能被污染的食物：
烤马铃薯、蜘蛛眼、腐肉、生牛肉、生羊肉、生兔肉、生猪排、生鸡肉

合成配方
  • 口罩
右键佩戴，减少被感染风险

  • 手套
左键使用，减少被感染风险

  • 药品
右键使用，治疗自己的病

  • NBC防护服
减少被感染风险

命令与权限

命令描述
covid add world设置该插件在什么世界生效
covid set infected {player}感染一个玩家
covid cure {player}治愈一个玩家
covid reload重载插件

权限节点描述
Covid19.*该插件的所有权限
Covid19.alert被感染的玩家离开服务器时向玩家显示提示
Covid19.cmd_add允许玩家使用covid add world命令
Covid19.cmd_cure允许玩家使用covid cure命令
Covid19.cmd_set允许玩家使用covid set infected命令
Covid19.cmd_reload允许玩家使用covid reload命令
