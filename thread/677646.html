管理指令
  • /ccsetup - 基础安装指令 - craftconomy.setup
  • /craftconomy - 显示帮助彩蛋
  • /craftconomy bankprice - 改变银行开户初始价格 - craftconomy.config.bankprice
  • /craftconomy holdings - 改变玩家默认进服余额 - craftconomy.config.holdings
  • /craftconomy format - 设置显示格式 - craftconomy.config.longmode


玩家经济指令
  • /money help - 显示帮助菜单
  • /money - 显示当前世界的余额 - craftconomy.money.balance
  • /money all - 显示全世界的余额 - craftconomy.money.balance
  • /money balance - 显示指定玩家的余额 - craftconomy.money.balance.others
  • /money pay - 给指定玩家转账 - craftconomy.money.pay
  • /money top - 显示指定世界的排名 - craftconomy.money.top
  • /money log [玩家名称] - 显示玩家日志信息 - craftconomy.money.log
    [玩家名称] - 显示指定玩家日志信息 - craftconomy.money.log.others
  • /money exchange - 交换指定玩家的余额


管理经济指令
  • /money give [货币] [世界] - 给指定玩家添加余额 - craftconomy.money.give
  • /money take [货币] [世界] - 从指定玩家余额取出 - craftconomy.money.take
  • /money set [货币] [世界] - 设置指定玩家余额 - craftconomy.money.set
  • /money create - 创建指定名称的余额账户 - craftconomy.account.create
  • /money delete - 删除指定名称的余额账户 - craftconomy.account.delete
  • /money infinite - 指定玩家为无限余额 - craftconomy.money.infinite


玩家银行指令
  • /bank - 显示银行帮助
  • /bank create - 创建银行账户 - craftconomy.bank.create
  • /bank balance - 查看银行账户余额 - craftconomy.account.delete
  • /bank deposit [货币]         - 存入指定货币到银行 - craftconomy.bank.deposit
  • /bank withdraw [货币] - 从银行取出指定货币 - craftconomy.bank.withdraw
  • /bank perm - 设置玩家的权限 - craftconomy.bank.perm
  • /bank list        - 列出所有被许可的银行账户 - craftconomy.bank.list


管理银行指令
  • /bank list - 设置其他玩家的账户许可 - craftconomy.bank.perm.others
  • /bank give [货币] [世界] - 给一个银行账户增加余额 - craftconomy.bank.give
  • /bank take [货币] [世界] - 从一个银行账户取出余额 - craftconomy.bank.take
  • /bank set [货币] [世界] - 设置一个银行账户的余额 - craftconomy.bank.set


货币设置（不推荐，影响性能）
  • /currency add        (Admin Command) Add a currency in the system.        craftconomy.currency.add
  • /currency edit        (Admin Command) Edit a currency.        craftconomy.currency.edit
  • /currency delete        (Admin Command) Delete a currency from the system.        craftconomy.currency.delete
  • /currency info        (Admin Command) Shows information about a currency.        craftconomy.currency.info
  • /currency exchange        (Admin Command) Set a currency exchange rate.        Unknown
  • /ccgroup create        (Admin Command) Create a world group.        craftconomy.group.create
  • /ccgroup addworld        (Admin Command) Add a world to the world group.        craftconomy.group.addworld
  • /ccgroup delworld        (Admin Command) Remove a world from a world group. This will revert the world to the default balance.        craftconomy.group.delworld
