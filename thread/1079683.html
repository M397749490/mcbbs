以下是一些建议:
  1. @EventHandler
  2.     public void PlayerMoveEvent(final PlayerMoveEvent event) {
  3.         final Player player = event.getPlayer();
  4.         final int level = SXLevel.getApi().getPlayerData(player).getLevel();
  5.         final int level2 = SXLevel.getApi().getPlayerData(player).getExp();
  6.         this.getConfig().set(player.getName(), (Object)level);
  7.         this.getConfig().set(player.getName() + "data", (Object)level2);
  8.         this.saveConfig();
  9.     }
复制代码

1.不建议在高频事件调用io处理 数据小还不明显 实际上对服务器性能有损耗
2.建议删去或者使用map存储最后再存进yml
3.正常考虑玩家数据存储只需要 加入、离开事件 加上 插件关闭全员的保存数据 即可
此举可以防止除了腐竹强行差掉服务器以外大部分数据丢失.
