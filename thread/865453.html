Stew Effects
插件介绍
steweffects是一款适合pvp或rpg服的插件
该插件的功能很强大，玩过pvp的大佬都知道，pvp自带几个蘑菇汤
吃了蘑菇汤就会恢复血量，而这个比它更加强大。至于强大的地方在哪请看下面

插件特性
1.可自定义音效，可自定义消息，可自定义物品（默认蘑菇汤）
2.可自定义药水效果
3.可自定义治疗多少
4.吃完物品可以触发指令（可多行）
5.可设置左键食用还是右键食用

插件命令与权限
[size=14.6667px] /steweffects reload——重载配置文件
权限
se.use——玩家基本权限
se.admin——管理员权限

插件配置


  • messages:
  •   config-reloaded: '&a配置文件重载成功!'
  •   no-permission: '&c你没有使用这个命令的权限.'
  •   invalid-usage: '&c有效使用命令:/steweffects reload'
  •   non-player-sender: '&c你必须是个玩家才能使用该命令!'
  •   error-reloading: '&c重载配置文件出错'
  • options:
  •   heal-amount: 4 #治疗量
  •   feed-amount: 6
  •   feed-after-heal: false
  •   click:
  •    left: true #左键
  •     right: true #右键
  •   item:
  •     type: apple #食物，默认是蘑菇汤
  •     change-to: air #吃完后变成什么，默认是碗
  •     change-to-amount: 1
  •   sound:
  •     enabled: true
  •     type: BLOCK_ANVIL_BREAK #音效，默认是打嗝需要音效可以在（https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Sound.html)这里找
  •     volume: 1
  •     pitch: 2
  •   potion:
  •     enabled: true #是否开启
  •     type: REGENERATION #药水效果默认是恢复
  •     duration: 3 #持续时间
  •     amplifier: 0
  •   commands:
  •     - 'give %player% diamond 1' #给予吃完物品的玩家一颗钻石
