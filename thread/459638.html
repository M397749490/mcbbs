第二个主要是不会检测手上拿烈焰棍的玩家啊

{SelectedItem:物品格式}物品格式例子：{id:"minecraft:blaze_rod",Damage:0s}
至于那个检测背包里有没有某个物品啊
我觉得{Inventory:[{id:"minecraft:feather"}]}就可以了
命令：
（检测背包有没有羽毛）
scoreboard players set @a 某个计分板 1 {Inventory:[{id:"minecraft:feather"}]}
（检测玩家手上是不是烈焰棍）
scoreboard players set @a 某个计分板 2 {SelectedItem:{id:"minecraft:blaze_rod",Damage:0s}}
