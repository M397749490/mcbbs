还在为自己服务端的插件是否最新而烦恼么？还在频繁跑水桶官网下载更新插件而蛋疼么？现在，这个插件就是你的更新助手，时刻保持服务端所有（支持的插件）插件的最新状态.
插件特性：1.自动备份要更新的插件                      2.在服务器开启状态就可以自动安装。
                  3.可以通过配置文件编辑例外              4.可以终止目标插件自动更新程序
                  5.支持大多数水桶端插件

指令以及权限：
指令：权限说明
/upuupu.upu显示所有可更新的插件
/upu checkupu.upu立即给所有插件检查更新
/upu update <Plugin>upu.upu设置下次更新的插件（不确定）
/upu unregister <Plugin>upu.upu取消[Plugin]插件的支持
/upu register <Plugin>upu.upu求高手翻译 原文：Will then ask for fileName and bukkit-page-name then register all with the updater
/upu install <Plugin>upu.upu在你离开服务器的时候更新插件
