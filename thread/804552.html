在上方dalao的基础上这边丢一个Wiki推荐的工具
https://www.minecraftjson.com/
无论是对萌新还是dalao都很友好的json制作器，
打开网页后在这里P1那里选择 Tellraw 不要选sign(/give)！ 否则无法添加Click Events
点击P2的add text之后，在左下角的Click Events 选择 Run command，
在同行输入栏中写上你想加的指令，类似P3,记得在右上角改变文字属性
然后重复，添加四行文字。最后回到一开始的界面
比如我得到这样的指令(四个同一行的1，第一个1点击会/tell) 换行的问题我写在下一个回复里了。
/tellraw @p ["",{"text":"1","clickEvent":{"action":"run_command","value":"/tell @p 1"}},{"text":"1"},{"text":"1"},{"text":"1"}]
把P1尚的标签改成 sign(/give) 得到
/give @p sign 1 0 {BlockEntityTag:{Text1:"[\"\",{\"text\":\"1\",\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/tell @p 1\"}},{\"text\":\"1\"},{\"text\":\"1\"},{\"text\":\"1\"}]",id:"Sign"}}
绕过网站的分流系统，大功告成。
