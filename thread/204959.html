这个整合包的初衷是尽量提高生存难度……（以至于你不能一个人玩下去）
这个本来是用在服务器上的，但是服务器暂时没人加上腐竹神坑，我就先发到懒人包区吧
由于这些mod最初是为了让玩家不能一个人正常生存而组合起来的，
所以这个懒人包的难度略大……你们谁对自己的生存能力超很有信心可以尝试来挑战一下……
注：本懒人包不是新手向，而且对电脑配置要求比较苛刻……


优点：
  • 真实环境，游戏体验我已经尽力做到最好了……
  • 游戏性平衡，这个我也花了一些精力来调整


缺点：
  • 吃内存……对CPU和显卡有一定的要求
  • 有些东西的材质不匹配……(逼死强迫症)

核心功能性mod：（可能有几个mod你们大概没见过，国内没人搬过似乎……）

灵活动作Smartmoving让你能攀爬高坡，或者趴下穿过小洞升级这是一个让你能够选择自己职业，并且加点的mod，非常不错
家具MrCrayfish的家具mod，添加了几种功能性家具世界树Yggdrasill让你能种植超级大的树(似乎也随机生成)
木匠方块Carpenter's Blocks让你做一些可以自定义材质的门、床等，既有功能又美观我的环境EnviroMine增加了水分量，体温，神智和空气质量等变量，让生存变得更科学。同时增加了一定的物理计算
更好的世界生成BWG4可以让你自定义世界生成，并提供一种更科学的生成方式巨大的树BigTrees改变了树的生成方式，树会变得大一些而且看上去更科学，种类更多(并无添加新木头)
战斗高塔 BattleTowers会在地图上随机生成刷怪塔可以挑战，有boss，有箱子作为奖励(未完成)更好的弓箭BetterArchery添加了几种几种不同性能的弓，同时增加了不同性质的箭(火焰，爆炸，buff)，该mod增加了箭袋
蒸汽船PChan3增加了以煤为燃料的飞艇和汽艇蜥蜴人的更改iguanatweaks让mc有负重、走在不同的方块上也有不同的移动速度(比如雪地沙地上走的慢)，同时更改了不同物品的叠加数量(受伤有负面影响，如减速)
饥饿hungeroverhaul使得你饿的更快，而且饥饿归零的时候你会直接死亡。这个mod同时减少了食物回复的饥饿值。(和潘马斯关联,饥饿有负面影响)天才小狗doggy talent增加了狗的各种技能，使得狗用途更加广泛
精英怪物InfernalMobs增加了一些带属性的怪物，打死他们会掉落不错的附魔的装备。(当然这很有风险)潘马斯HarvestCraft增加了很多食物(地上随便都能找到吃的)，配合HGmod你必须学会制作高级的料理来有效率地回复饥饿
爬墙红石RedstonePasteMod让你能够制作会爬墙的红石(很方便)工具怪物UtilityMobs增加了一些有用的工具怪物来帮助你攻击或者携带东西(长腿的箱子，炮塔，石头兵之类的)
天气Weather增加了风和浪，你会看到叶子在飘落，同时会自然生成危险的龙卷风！(这个mod开光影看超级壮观，简直就是人生绝景……)僵尸意志Zombie Awareness加强了怪物的AI，他们能够凭借声音，血迹，光亮来抓你……而且是成群结对的
塞尔达的剑技 这个mod加入了各种剑技，使得mc变得像动作游戏

辅助功能性mod和API/lib：

Forge API 所有mod的基础APIOptifine 高清修复作用，内置skinme和光影兼容补丁
GLSL shader 光影mod，搭载了MrMeep,SEUE,Sildurs三种shader，平时默认关闭，可任选其一 autoutils automatic的mod的库
Better Grass增加草和树叶的视觉效果 Better Sign 使得牌子上的字更清晰，同时让牌子更科学
Dynamiclight 动态光源mod inventorytweak r键整包
Player API Smartmoving必要的API Render Player API 提升Smartmoving和更好弓箭mod的视觉效果
Status 雕塑mod，让你能做雕塑，纯娱乐mod DamageIndicator 显示血条mod
Animation API 变异生物的API Config ModWeather和僵尸意志的dependence
CoroAI Weather和僵尸意志的dependence CraftGuide G键合成表
ExtendedRender Weather的dependence Inputfix 中文输入补丁

对于闪退的原因和解决办法：
如果游戏启动有问题，需要在mods文件夹里把BetterSignsMod[v1.6.4.B].jar删掉，如果还不行把BetterGrassAndLeavesMod[v1.6.4.D]也删了。对于渣机，把光影和之前提到的bettersign和bettergrass删了，同时把材质包关掉把动态光源删了……还嫌卡就删掉ExtendedRender和WeatherMod，这样并不影响游戏难度。
