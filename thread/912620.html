  • ★插件特点
-你厌烦了原版的PVP模式与生存机制？想来点刺激的？
-想要某种可以远程操纵物品的机制？但又为领地越权操纵的风险而担忧？
-这里就是你想要的——魔法纪元
-为你的服务器增添超级好的附加玩法！
  • 插件功能
  • 各种魔咒（下面会逐一介绍）
  • 自定义魔咒属性（延续速度、粒子效果、粒子效果数量、冷却时间、范围）
  • 魔咒传递机制——引力透镜、魔咒反弹和液体减缓（可设置效果强度）
  • 为开发者做了API，用JAVA添加你自己想要的魔咒吧！
  • 自定义语言文件和魔咒物品样式
  • 认识魔咒
通过魔杖，发送一段魔法，在世界中延续，碰到方块/实体进行操作
每种魔咒固有属性：
冷却-同一玩家发射同一种魔咒两次最少的间隔时间
最大距离-一个抽象的数字代表着魔咒最多可以延续的距离（单位不是MC中的格）
魔咒延续速度-一个抽象的数字代表着魔咒向前的速度
粒子效果-魔咒延续时周围的粒子效果
粒子效果数量-魔咒延续时周围的粒子效果的数量
禁用的世界-在这些直接不能使用该魔咒


  • 插件指令
/wand 获取魔咒
  • 插件权限
hp.wand 获取魔咒/wand指令的权限
hp.use.魔咒中文名 释放魔咒的权限 例如阿瓦达索命的权限：hp.use.阿瓦达索命
hp.cd.minus  魔咒冷却减半
hp.admin 无视冷却

  • 魔咒机制
引力透镜
魔咒经过玻璃制造的物品（染色玻璃、玻璃板等）时会发生小小的偏转，并且速度和范围会变大。利于腐竹们准备特殊的PVP场——有玻璃作为掩体

液体减缓
魔咒经过水中会减慢速度（可以设置）

实体判定
魔咒周围实体检测范围（即魔咒生效范围，妈妈再也不用担心我打不准啦！）

魔咒碰撞
该功能还在研发中。。。

  • 插件编程API

注册一个魔咒：
ICurse curse=new ICurse(int id,ItemStack item,String permission);
int id-魔咒独一无二的ID
ItemStack item-魔咒在Gui里显示的物品
String permission-魔咒释放需要的权限

把魔咒添加进GUI里：
CurseLoader.addCurse(curse);
InventoryProvider.addCurse(curse);

监听魔咒事件：
MeetBlockEvent(Curse curse,Block block); 碰到方块
MeetEntityEvent(Curse curse,Entity entity); 碰到实体
MeetLivingEntityEvent(Curse curse,LivingEntity entity); 碰到生物
MeetPlayerEvent(Curse curse,Player); 碰到玩家

运行的魔咒类：
  1.         public double dist;      //已经经过的路程

复制代码

以阿瓦达索命为例：
  1. public class 阿瓦达索命 implements Listener{
  2.         public 阿瓦达索命() {
  3.                 ItemStack item=new ItemStack(Material.DIAMOND_SWORD);
  4.                 ItemMeta meta=item.getItemMeta();
  5.                 meta.setDisplayName("§9阿瓦达索命");
  6.                 item.setItemMeta(meta);
  7.                 ICurse curse=ExampleCurseLoader.loadStats(0,item,"阿瓦达索命","hp.use.阿瓦达索命");    //添加魔咒
  8.                 CurseLoader.addCurse(curse);
  9.                 InventoryProvider.addCurse(curse);
  10.         }
  11.         @EventHandler public void onMeetLivingEntity(MeetLivingEntityEvent event) {
  12.                 if(!(event.curse.curse.id==0)) return;             //如果不是id为0的魔咒，直接跳过
  13.                 if(event.entity==event.curse.sender) return;          //如果碰到了发射者自己，直接跳过
  14.                 if(盔甲护身1.protect.contains(event.entity.getName())) {          //如果碰到的生物被盔甲护身魔咒保护，则反弹并且不生效
  15.                         event.curse.vec=event.curse.vec.multiply(event.curse.vec);         //向量自乘（反弹）
  16.                         event.curse.dist=0.0;         //重制已经经过的路程（延长范围）
  17.                         盔甲护身1.protect.remove(event.entity.getName());        //生物的盔甲护身失效
  18.                         return;
  19.                 }
  20.                 event.curse.stop();        //魔咒停下来
  21.                 LivingEntity entity=event.entity;
  22.                 EntityDamageByEntityEvent cevent=new EntityDamageByEntityEvent(event.curse.sender,event.entity,DamageCause.ENTITY_ATTACK,entity.getHealth()*0.4+3.0);
  23.                 Bukkit.getServer().getPluginManager().callEvent(cevent);
  24.                 if(cevent.isCancelled()) return;
  25.                 entity.setHealth(entity.getHealth()*0.6);
  26.                 entity.damage(3.0);
  27.         }
  28.         @EventHandler public void onMeetBlock(MeetBlockEvent event) {
  29.                 if(event.curse.curse.id!=0) return;                    //如果不是id为0的魔咒，直接跳过
  30.                 if(event.block.getType()!=Material.AIR) {                //如果碰到了非空气方块，则停止运行
  31.                         event.curse.stop();
  32.                 }
  33.         }
  34. }
