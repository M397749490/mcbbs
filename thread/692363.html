标题: 正经下来做地图 黄石系统
前段时间担心立刻修复抓紧时间高频reload了
现在那个做完了 自然就要正经地做小地图了~  [正经脸]
不用高频reload 只有正常的function~

今天做的是黄石系统（仿照红石线做的~）
放置在羊毛上面的有最大信号强度4最低不会低于0
     
  

写了两个function
loop.txt
  1. execute @e[type=Armor_Stand,tag=m] ~ ~ ~ summon area_effect_cloud ~ ~ ~ {Age:-1000000,Particle:take,Tags:["n","yellow"]}
  2. //将新放置的盔甲架上生成一个药水云
  3. scoreboard players set @e[tag=n] dq 0
  4. scoreboard players tag @e[tag=n] add needupdate
  5. scoreboard players tag @e[tag=n] remove n
  6. scoreboard players tag @e[tag=m] remove m
  7. //初始化新放置的盔甲架和对应药水云
  8. scoreboard players tag @e[tag=yellow] add del
  9. execute @e[type=Armor_Stand,tag=as] ~ ~ ~ scoreboard players tag @e[tag=yellow,dx=0] remove del
  10. execute @e[tag=del] ~ ~ ~ scoreboard players tag @e[rm=0,r=1,tag=yellow] add needupdate
  11. kill @e[tag=del]
  12. //把打掉盔甲架的药水云去除并引起周围更新
  13. scoreboard players tag @e[tag=wool] remove wool
  14. execute @e[tag=yellow] ~ ~ ~ detect ~ ~-1 ~ wool * scoreboard players tag @s add wool
  15. scoreboard players tag @e[tag=wool,score_dq=3] add needupdate
  16. scoreboard players tag @e[tag=!wool,score_dq_min=4] add needupdate
  17. //处理下方是否有放置羊毛
  18. execute @e[tag=needupdate] ~ ~ ~ function yellow:update
  19. scoreboard players tag @e[tag=needupdate] remove needupdate
  20. //统一更新
  21. execute @e[score_dq=4] ~ ~ ~ replaceitem entity @e[dx=0,tag=as] slot.armor.head wool 1 14
  22. execute @e[score_dq=3] ~ ~ ~ replaceitem entity @e[dx=0,tag=as] slot.armor.head wool 1 2
  23. execute @e[score_dq=2] ~ ~ ~ replaceitem entity @e[dx=0,tag=as] slot.armor.head wool 1 6
  24. execute @e[score_dq=1] ~ ~ ~ replaceitem entity @e[dx=0,tag=as] slot.armor.head wool 1 0
  25. execute @e[score_dq=0] ~ ~ ~ replaceitem entity @e[dx=0,tag=as] slot.armor.head wool 1 15
复制代码

update.txt
       记分板变量解释
当前分数 dq
计算中分数 js
临时分数 temp

  1. scoreboard players set #var js 0
  2. execute @e[type=area_effect_cloud,rm=0,r=1,tag=yellow] ~ ~ ~ scoreboard players operation #var js > @s dq
  3. scoreboard players operation @s js = #var js
  4. //取周围的信号强度的最大值
  5. scoreboard players remove @s[score_js_min=1] js 1
  6. //减一（信号衰减）
  7. execute @s ~ ~ ~ detect ~ ~-1 ~ wool * scoreboard players set @s js 4
  8. scoreboard players operation @s temp = @s js
  9. scoreboard players operation @s temp -= @s dq
  10. scoreboard players operation @s temp *= @s temp
  11. scoreboard players operation @s dq = @s js
  12. execute @s[score_temp_min=1] ~ ~ ~ execute @e[type=area_effect_cloud,rm=0,r=1,tag=yellow] ~ ~ ~ function yellow:update
  13. //一旦强度变化 就让周围的也更新
