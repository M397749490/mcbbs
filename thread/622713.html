前言
影音制作是一款微软出品的视频编辑软件，没有复杂的破解过程，这款软件完全免费；没有复杂的操作界面，非常适合新手实况主操作。我翻译视频几年来一直用的这款软件，一些实况主苦于视频编辑的繁琐性，我希望帮助他们。之前我在网上也找了找，但是没发现一篇能全部介绍这款软件的教程，所以特此来写这篇教程。（“影音制作”指“Windows 影音制作 2012”，并非为较早版本的“Windows 影音制作 2011”）
下载
由于微软将“影音制作”和其他Windows附属软件集成到了Windows软件包中，所以“影音制作”无法单独下载。下载影音制作首先需要下载Windows软件包（下载地址：https://support.microsoft.com/zh-cn/help/17779）。
Windows 软件包 2012已于2017年1月10日终止支持，Windows 软件包 2012 在微软官网已不再提供下载。
故楼主从电脑废墟里找了一个当年下载的Windows 软件包 2012，分给大家好了← ←，
下载地址：http://pan.baidu.com/s/1kUPaOR1
电脑配置要求：
  • 操作系统：Windows 7（32 位或 64 位版本）、Windows 8（32 位或 64 位版本）、 Windows 8.1（32 位或 64 位版本）、Windows 10（32 位或 64 位版本），不支持Windows XP及Mac。
  • 处理器：1.6 GHz 、 2.4 GHz（单处理器）或更高频率（在编辑高清视频时，建议使用双核处理器或更高频率的处理器），支持 SSE2。Pentium 4 或更新处理器以及 AMD K8 或更新处理器都支持 SSE2。
  • 内存：1 GB RAM 或更高。（在编辑高清视频时，建议使用 2 GB 或更大 RAM）
  • 分辨率： 最低 1024 × 576。
  • Internet 浏览器：Internet Explorer 7（或更高版本）、Mozilla Firefox 3.0.1（或更高版本）或者 Safari 3.1（或更高版本）。
  • Internet 连接：联机服务需要具有拨号连接或高速 Internet 访问（单独提供，可能按本地或长途费率来收费）。对于某些功能，建议使用高速 Internet 访问。
  • 图形卡：Windows 影音制作需要使用支持 DirectX 9.0c 或更高版本以及 Shader Model 2 或更高版本的图形卡。
  • 其他必须程序：照片库、 Windows Media Player和Windows DVD Maker。
斜体为非必要内容。
——选自微软官网


下载完毕后打开安装包，可以选择“安装所有 Windows 软件包”或“选择要安装的程序”，如果你希望选择安装的话，务必要安装照片库和 Windows Media Player，否则影音制作将无法正常启动。



界面
安装完毕后随便打开一个视频，这里以Minecraft官网宣传片为例，

打开一个新视频软件需要对这个视频进行准备，等待一会就好。完毕后便可以对视频进行编辑。如果不想等待可在设置里取消准备（不推荐）。


主界面：
我们可以将主界面分为“工具区”、“预览区”和“工作区”。“工具区”有处理视频所需的工具；“预览区”为视频导出后效果的实时预览；“工作区”可以对视频进度条、音乐进度条和旁白进度条（后者需要添加音乐与旁白）进行移动等。
有三种方法可以控制当前所在帧：

①常用于视频的微调中，②为正常播放视频，③为自定义调整（需按住所在帧指示向前或后拉动）。
菜单栏及工作区一览：
“开始”是菜单栏的默认区，这足以显示它的重要性。在“开始”中可以添加新内容或导出视频（详见第二章：导入与导出和第三章：音乐与旁白）以及设置视频主题（详见第四章：拆分与主题）。
“动画”顾名思义就是设置视频动画，动画包括过渡特技以及平移和缩放（详见第六章：动画与其他）。
“视觉效果”通俗讲就是滤镜的意思，在这里可以设置共26种滤镜效果（详见第五章：字幕与滤镜）。
“项目”里为强调视频声音、音乐和旁白（详见第三章：音乐与旁白）。
“查看”里为一些零散的其他设置。

“视频工具”为四大小工具之首，可以编辑视频及视频音乐。
“音乐工具”（需添加音乐后才能显示）可以控制音乐。
“旁白工具”（需添加旁白后才能显示）可以控制旁白。
“文本工具”（需添加描述后才能显示）可以修改字幕。
第一章完
