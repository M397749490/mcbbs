如果想要在执行第一条命令成功5秒后，激活第二条命令，不用比较器，中继器，时钟电路等等“物理延迟”，应该怎样编写？

计分板，让紫CB循环给玩家#count的dummy加分。
  1. #创建
  2. scoreboard objectives add clock dummy

  4. #紫色
  5. scoreboard players add #count clock 1
复制代码



然后第一个条件约束的绿CB加上
  1. execute if score #count clock matches 100.. run scoreboard players reset #count clock
复制代码

之后的绿CB补上你后续要做的事情
