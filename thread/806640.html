+——bAnnouncer——+

简单|高效|自动|自定义

公告插件





简介

bAnnouncer是一个简易而高效的公告插件





特点

  • 自动公告
  • 公告自带声效
  • 自定义公告格式
  • 支持多行公告
  • 世界独立公告
  • 还是公告……



指令和权限
  • /ba —— 查看指令帮助
  • /ba setrandom —— 开启公告随机模式
  • /ba setinvertal <秒数> —— 设置公告间隔
  • /ba delmessage <公告ID> —— 删除一个指定的公告
  • /ba addsound <Id> <声效ID> —— 为一个公告设置发出时的声效
  • 声效查询：https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Sound.html
  • /ba reload —— 重启插件
  • /ba broadcast <消息> —— 使用CONFIG.YML中的格式发送一条消息
  • /ba view <iD> —— 查看指定的ID公告
  • /ba list —— 列出所有公告
  • bannouncer.ba —— 允许使用以上指令



配置文件
论坛代码又崩了。。
# B 公告插件 汉化BY PumpkinServer
# 管理员指令 -> /ba
# 权限 -> 'bannouncer.ba'
# 每一条公告的间隔 (单位：秒).
Interval: 30
# 是否开启随机公告挑选
Random: false
# 想要一个集中的公告吗？马上把ID添加到这里来吧！（shemogui）
# 填写公告ID（必须是Messages当中有的）
Centered-messages:
- "message1"
- "message2"
- "message3"

# 想在一个公告被广播时出现声音吗？填写ID吧！
# 这里是一些可用的声音列表
# https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Sound.html
Sounds:
message1:
- "BLOCK_NOTE_PLING" #《-在这里填写声音
# ============[间隔]============ #
# 下面是公告填写，格式为：
# [ID]:
#   - "公告行1"
#   - "公告行2"
Messages:
message1:
- "&8&m------------------------------------------"
- ""
- "&ebAnnouncer &6v1.2 &eby &6Coltify."
- ""
- "&8&m------------------------------------------"
message2:
- "&8&m------------------------------------------"
- ""
- "&ebAnnouncer has &6PlaceholderAPI&e support!"
- ""
- "&8&m------------------------------------------"
message3:
- "&8&m------------------------------------------"
- ""
- "&ebAnnouncer now has a &6Message centering&e feature!"
- ""
- "&8&m------------------------------------------"

# 这是你的公告格式，当你使用/ba broadcast时将使用这里的格式来公告，文字变量：%text%
Broadcast:
format:
- "&8&m------------------------------------------"
- ""
- "&e%text%"
- ""
- "&8&m------------------------------------------"
centered: true
# 在这里添加ID到指定世界下面，来规定某些公告只能发送至哪一个世界。
World-messaging:
world:
- "message1"
- "message3"
nether:
- "message2"
