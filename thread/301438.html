因为这个插件太简单了，还有点小实用，于是我就搬运了过来
官方介绍：
这是一个非常简单的插件，你可以创建一个账户并加钱取钱。
其实用处不大但是有些服务器可能需要。（主要是我的服务器需要一个……）
所以不喜勿喷啊……[storage_minecart]
作者正在开发新版本（这个插件才新出炉），所以敬请期待更多功能！！！


指令：
/econ set <player>创建<玩家>的账户
/econ add <player> <amount>往<玩家>的账户里添加<amount>数量的钱
/econ remove <player> <amount>

第三个命令是减少相应的钱（别问我为什么这个出格了）


权限：
smalleconomy.set允许使用/econ set
smalleconomy.add允许使用/econ add
smalleconomy.remove允许使用/econ remove
