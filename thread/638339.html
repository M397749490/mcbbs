汉化方法：(适用于1.6.2及更高版本支持语言文件汉化的模组)
Step1：
       用压缩软件打开模组，语言文件一般位于“\assets\模组名\Lang”内，但是IC(工业时代)位于“\ic2\Lang”内
Step2：
       找一下有没有“zh_CN.lang”，没有的话在桌面上新建一个。
       然后找一下待翻译的源语言文件，大部分是英语，那就打开“en_US.lang”或“en_UK.lang”(对于日本的模组，如果看得懂日语推荐使用“ja_JP.lang”，不过上面两个也行)

Step3：
用比较好用的文本编辑器一条条比对过去(推荐Notepad++以及它的compare(比较插件))

附录-Lang文件解析：
       ——通用条目开头解释
       Chat 代表这句话很可能出现在聊天框中
       Command 代表输入命令的时候显示
Achievement 在【成就】里显示
Item、Tile 大部分是物品或方块名称                     
GUI 显示在交互界面上(比如工作台)
Stat 显示在【统计信息】中
Config 点【Mods】按钮进入那个编辑模组设置的界面中显示(不会在游戏中显示，可以不汉化)
Tooltip、Tip 物品提示信息
Options 在【控置】中显示
Generator 在“世界类型”中显示
Entity 实体名字
Fluid 流体名称
ItemGroup 创造模式物品栏标签名
Inventory 物品栏中显示
Key 在【控制中显示】
Direction、Dir 方位
Color 颜色
Recipe 合成
——模组特有条目开头解释：
Gate BC门控系统中出现
Waila 在Waila上显示
Crop 作物(IC)
Generic (IC)
Nei 在Nei中显示
Warp 获得扭曲值的时候显示(TC)
Focus 在魔导手册中显示(TC)
