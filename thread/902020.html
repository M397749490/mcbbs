VoteUp 2

VoteUp 是一个简单的，易于使用的投票管理系统，通过可视化的 Gui 界面来创建，浏览投票。

若您在使用时遇到问题，请于本贴回复或私信我，在 Github 项目 下创建一个 Issue 也是可以的。


出于稳定性考虑，请更新到 VoteUp v2.0.4-Beta 及其以上版本。


特性

  • 深度可自定义化，全面插件设置，提示音，提示信息，包括 Gui 中的任意内容。
  • 匿名投票
  • 查阅所有投票参与者
  • 投票权重
  • 多项投票设置
  • 多种投票类型
  • 三种投票立场
  • 收集投票理由
  • 投票通过后自动执行指令
  • 自定义投票持续时间
  • 开发活跃，积极采纳建议 :3

投票设置

  • 投票标题：帮助玩家快速了解投票内容
  • 投票简述：介绍投票目的
  • 投票类型
    • 普通投票：投票结束时同意人数大于反对人数
    • 多数同意投票：投票结束前同意人数达到指定数量
    • 否决投票：投票结束前反对人数不超过指定数量
    • 更多投票类型等你来提议鸭！
  • 目标人数
    • 于配置文件内可设置投票通过的最低参与人数，低于此人数即便满足通过条件，也无法判定投票通过，感谢 @roughanddai 于 Issue #2 提出此逻辑建议。
  • 持续时间：支持天(d)，小时(H)，分钟(m)
  • 投票选项：同意，中立，反对，各项的内容可具体设置
  • 投票结果：通过，驳回，平票，被取消，各项的内容可具体设置
  • 自动执行
    • 在投票通过后按照顺序执行指令
    • 三种执行模式：黑名单模式(屏蔽指定指令)，白名单模式(仅允许执行指定指令)，玩家权限模式(以玩家身份执行指令)
    • 在玩家权限模式时，若投票发起人不在线将挂起直至对方上线后以他身份权限执行指令
  • 允许匿名投票：允许玩家以随机的匿名身份投票，其**在未拥有查看权限的情况下不会显示。
  • 公开投票进度：普通玩家也可查阅投票参与者列表，而非仅投票发起者与 VoteUp 管理员。
  • 可编辑所投票：参与者可在投票结束前任意编辑其所投票内容，包括投票选项，投票原因。

指令与权限

指令

插件主命令: /voteup

命令缩写: /votes

命令介绍所需权限
/votes create (back)开始创建投票(带上 back 即返回先前的投票草稿)VoteUp.create
/votes view <投票ID>/latest查看指定投票/最新投票的详细信息VoteUp.view
/votes search <检索条件>/me/open检索符合条件/自己发起/当前进行中的投票VoteUp.search
/votes reload重载插件数据VoteUp.admin 或 VoteUp.*

其他权限

权限节点介绍
VoteUp.vote.reason允许在投票后发表投票原因
VoteUp.vote.<投票选项> 或 VoteUp.vote.*允许投指定选项的票
VoteUp.edit.<投票设置> 或 VoteUp.edit.*允许编辑指定的投票设置
VoteUp.notice在任意进行中投票收到新的一票或投票结束时发送通知
VoteUp.view.anonymous允许查阅匿名投票者**
VoteUp.admin 或 VoteUp.*总权限

  • 本插件于 Github 开源，主要更新进度也将发布于其上。
  • VoteUp 2 刚完成重写工作(voteup2 分支)，尚于 Beta 测试版，其他相对于 v1.4 版本的新特性将于后续更新中推送，开发计划可于 Issue #3 查看，欢迎提出建议。
  • 本插件基于 Spigot 1.14.4 编译，在 Spigot 1.15.2 下除出 Bug 情况下能正常运行，应该没有用到版本特有的 API 或 nms，理论上向上或向下兼容(最多到 1.13 吧)。
