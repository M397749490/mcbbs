作者: kcm1329623049    时间: 2014-9-28 18:05
先设置配置文件plugins\GroupManager\config.yml
  1.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  2.         # 第一个世界 'world' 是主世界名称
  3.         # 子世界 'world_nether' 和 'world_the_end' 将会
  4.         # 与父世界使用相同的玩家/用户组文件.
  5.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  6.         # all_unnamed_worlds将会使用所有未定义的世界
  7.         world:
  8.           world_nether:
  9.           - users
  10.           - groups
  11.           world_the_end:
  12.           - users
  13.           - groups
  14.           fuben:
  15.           - users
  16.           - groups
  17.         xiaoqu:
  18.         spawn:
  19.     #  world2:      (World2 将会拥有自己的独立设置)
  20.     #    world3:
  21.     #    - users    (World3 使用 world2 的 users.yml,但是使用自己独立的 groups.yml)
  22.     #    world4:
  23.     #    - groups   (World4 使用 world2 的 groups.yml,但是使用自己独立的 users.yml)
  24.     #  world5:
  25.     #    - world6   (这个世界使用从world5镜像过来的设置文件)
复制代码

然后再打开plugins\GroupManager\worlds里面设置各个世界的权限组
