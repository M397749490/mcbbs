想必许多腐竹还在为论坛与服务器连接而头痛吧~因为论坛上仅有discuz连接教程而欲罢不能？看不惯discuz臃肿的功能？就是想要phpwind那样简洁快速的论坛？教你phpwind与discuz连接！
免去游戏内登陆注册的繁琐套路，让你的服务器更加富有个性吧~


搭建需求
  • 一个phpwind站点
  • phpwind数据库支持从外部连接
  • Authme登陆插件
  • 一个动手能力强的人

教程开始
我这里以AuthMe-5.2版本为例，其他版本同样适用，只不过config排序设置项目略有不同罢了
打开Authme的config文件进行如下修改
  1. DataSource:
  2.   backend: mysql  #储存数据方式，修改成mysql
  3.   caching: true
  4.   mySQLHost: 127.0.0.1  #修改为phpwind数据库的连接地址
  5.   mySQLPort: '3306'  #phpwind数据库的连接端口，一般为3306
  6.   mySQLMaxConections: 8
  7.   mySQLUsername: root  #修改为phpwind数据库的连接用户名
  8.   mySQLPassword: '584334420'  #修改为phpwind数据库的连接用户名密码
  9.   mySQLDatabase: phpwind  #修改为phpwind的数据库的名字
  10.   mySQLTablename: pw_windid_user   #填写phpwind用户储存表单，改成pw_windid_user
  11.   mySQLColumnId: id  #不做修改
  12.   mySQLColumnName: username  #不做修改
  13.   mySQLColumnPassword: password  #不做修改
  14.   mySQLColumnEmail: email  #不做修改
  15.   mySQLColumnLogged: isLogged
  16.   mySQLColumnIp: regip  #修改为regip
  17.   mySQLColumnLastLogin: lastlogin
  18.   mySQLlastlocX: x
  19.   mySQLlastlocY: y
  20.   mySQLlastlocZ: z
  21.   mySQLlastlocWorld: world
  22.   mySQLRealName: realname
  23.   mySQLWebsite: false
  24. 开始部分设置完成后 我们找到
  25.   security:
  26.     minPasswordLength: 6  #最小密码长度 因为phpwind为6，所以修改为6
  27.     unLoggedinGroup: unLoggedinGroup  #不修改
  28.     passwordHash: SALTED2MD5   #密码存储方式,修改为SALTED2MD5
  29.     doubleMD5SaltLength: 6  #SALT随机码长度 填6  
  30.     supportOldPasswordHash: false  #不修改
  31. unsafePasswords: []    #不修改
  32. 然后找到
  33. mySQLColumnSalt:
  34. 修改为
  35. mySQLColumnSalt: salt
复制代码
修改配置完毕
现在大可以进入论坛注册再来游戏试验成果了！
