首先需要准备准备软件（请自行下载）：
flashfxp    FTP上传 吧服务端上传到服务器

putty       控制台程序，远程访问服务器执行命令


前言

应该有不少同学想拥有自己的服务吧，我来给大家说下怎么用最便宜的方法来架设我的世界服务器，并且可以邀请基友一起来玩。

本教程是基于阿里云服务器的，目前有优惠0元免费试用6个月，但是需要购买外网带宽，大概是1M每天0.5元。

首先在 【 http://www.aliyun.com 】 申请免费的云服务器 0元/6个月，我是2天申请成功的，最长可能要5个工作日。

申请成功后，选择一个镜像，就是给你预先安装的操作系统，这里我选择的是linux，因为免费的只有单核1G内存，如果跑windows肯定不行，所以这里选择使用linux，系统安装完成之后大概占用300M左右内存，程序还可以使用700M。

我这里使用的镜像环境是【Java运行环境（Ubuntu 64位 | JDK1.7） V1.1】

安装完成之后设置root密码以及WEB终端管理的密码

这里推荐使用【putty】来进行服务器的前期设置，因为他可以直接复制粘贴命令，而web的需要都手打命令才行，如何使用网上教程很多。

注意
这个时候你需要购买至少1M 1天的带宽 就是几毛钱就可以使用【putty】和【flashfxp】来上传文件，如果你不买的话是没有办法上传文件的。


使用 【putty】 登录服务器，安装基本的ftp服务，为了上传服务端文件

  1. sudo apt-get instal vsftpd
复制代码



一直按回车，如果提示Y就按Y直到安装完成
使用【flashfxp】用root用户登录服务器上传文件，推荐上传到/home/mc/文件夹方便管理
因为免费服务器，会出现内存不够服务器自动关闭程序问题，参考【 http://www.mcbbs.net/forum.php?mod=viewthread&tid=388584 】的脚本
  1. #!/bin/bash
  2. DIR=$HOME/mc # Minecraft Directory. Plz Modify this line before running. 先在这里修改你的MC目录，然后运行此脚本
  3. M_OLDPWD=$OLDPWD
  4. M_PWD=$PWD
  5. LOGDIR=$DIR/srvlog
  6. LOG=$LOGDIR/launcher.log
  7. [[ -d "$LOGDIR" ]] || ( mkdir "$LOGDIR" ; echo "$(date)[Info]Created log directory.">>$LOG )
  8. cd "$DIR"
  9. echo "$(date)[Info]Launching.">>$LOG
  10. MCSTAT=0
  11. false
  12. while [[ "$?" != "0" || -f "$DIR/restart.lck" ]]; do
  13.     if [[ "$MCSTAT" == "0" ]]; then
  14.         echo "$(date)[Info]Start server.">>$LOG
  15.         MCSTAT=1
  16.     elif [[ -f "$DIR/restart.lck" ]]; then
  17.         echo "$(date)[Info]Restart server.">>$LOG
  18.         sleep 2
  19.     else
  20.         echo "$(date)[Warn]Crashed. Restart server.">>$LOG
  21.         sleep 10
  22.     fi
  23.     if [[ -f "$DIR/restart.lck" ]]; then
  24.         rm "$DIR/restart.lck"
  25.     fi
  26.     # Commands here will execute before launch
  27.     java -server -Xms128M -Xmx700M -Djava.awt.headless=true -jar $DIR/spigot.jar #这里看你的情况来改
  28. done
  29. echo "$(date)[Info]Exit.">>$LOG
  30. cd "$M_PWD"
  31. OLDPWD=$M_OLDPWD
复制代码

  6. vi  server.properties
