AutoSaveWorld
多功能插件，可以保存，备份，清除，重新启动Minecraft服务器，重新加载插件等等。
支持ftp、脚本、

功能
自动保存世界和玩家数据
执行世界备份（保存在:"服务器文件夹\backups\"下）
自动清除一些插件的数据
在制定的时间自动重启
服务器崩溃时重新启动
自动执行在config中定义的命令

config.yml

1、自动保存(和save-all差不多)
  1. save:
  2.   enabled: true #是否启用自动保存世界
  3.   disablestructuresaving: true #禁用结构保存（保存执行速度要快得多，但是当worldegn(?)改变时，你的地图结构将停止工作）
  4.   forceregioncachedump: true #强制区域缓存转储（确保将文件写入磁盘）
  5.   broadcast: true #在保存之前和之后全服广播一条消息（true - 启用，false - 关闭）
  6.   interval: 900 #每次保存的时间间隔（以秒为单位）
  7.   onplugindisable: true #当AutoSaveWorld禁用时执行保存(意思差不多吧)
复制代码

2、自动备份 - 备份世界
注意：默认情况下AutoBackup被禁用！
AutoBackup默认情况下，备份位于服务器文件夹\backups 内。
世界的备份使用WorldEdit快照文件存储在文件夹 backups\worlds 内
插件的备份存储在 backups\plugins 内
  1. backup:
  2.   enabled: false #启用或禁用自动备份
  3.   interval: 21600 #自动备份之间的秒数，以秒为单位
  4.   savebefore: true #强制替换原来的备份
  5.   broadcast: true #备份前后是否在全服广播信息
  6.   rateLimit: -1 #限制读取速率（kb/s，-1表示无限制）
  7.   localfs:
  8.     enabled: true #启用备份到本地
  9.     worlds: #要备份世界的列表，“*” - 备份所有的世界
  10.     - '*'
  11.     MaxNumberOfWorldsBackups: 30 #世界备份的最大数量，达到这个数量后，插件将删除最旧的一个，然后备份一个新的
  12.     pluginsfolder: false #备份插件
  13.     MaxNumberOfPluginsBackups: 30 #和上面世界的一样
  14.     excludefolders: [] #不备份列表内路径的数据，下面有示例
  15.     destinationfolders: [] #要备份的文件夹列表，下面有示例……
  16.     zip: false #zip备份文件夹，应该是自动压缩的意思
  17.   ftp:
  18.     enabled: false #启用备份到FTP
  19.     sftp: true #是否使用sftp
  20.     hostname: 127.0.0.1 #ftp ip
  21.     port: 21 #ftp 端口
  22.     login: user #ftp 用户名
  23.     password: password #ftp 密码
  24.     path: asw #ftp服务器上备份将被存储的路径
  25.     zip: false #同上
  26.     worlds: #同上
  27.     - '*'
  28.     pluginsfolder: false #同上
  29.     otherfolders: [] #要备份的其他文件夹的列表，不知道怎么写的看下面
  30.     excludefolders: [] #同上
  31.     maxNumberOfBackups: 2 #同上
  32.   script:
  33.     enabled: true #启用脚本备份
  34.     scriptpaths: [] '' #指向要执行的脚本的路径
  35.   dropbox:
  36.     enabled: false #启用备份到dropbox
  37.     token: #自己的令牌（在https://www.dropbox.com/developers/apps上通过创建您自己的应用程序来获得一个令牌）
  38.     path: asw #保存备份的Dropbox路径
  39.     worlds: #同上
  40.     - '*'
  41.     pluginsfolder: false #同上
  42.     otherfolders: [] #同上
  43.     excludefolders: [] #同上
  44.     maxNumberOfBackups: 2 #同上
  45.     zip: true #同上

destinationfolders示例
  1. purge:
  2.   enabled: false #启用或禁用AutoPurge
  3.   interval: 86400 #每次数据清理的间隔
  4.   awaytime: 2592000 #如果玩家 x(秒)没有在服务器上玩，他的信息将在所设定的时间后删除。
  5.   broadcast: true #清理之前和之后的广播消息
  6.   ignorednicks: [] #始终认为是活跃的，不会被清除的昵称列表（将uuid转换为uuids）
  7.   ignoreduuids: [] #总是被认为是活跃的，不会被清除的uuid列表
  8.   wg:
  9.     enabled: true #enable or disable WorldGuard regoins purge
  10.     regenpurgedregion: false #regenerate purged worldguard regions
  11.     noregenoverlapregion: true #do not regen overlapping regions
  12.   lwc:
  13.     enabled: true #enable or disable LWC purge
  14.     deletepurgedblocks: false #delete blocks of purged protections
  15.   residence:
  16.     enabled: true #enable or disable Residence purge
  17.     regenpurgedresidence: false #regenerate purged Residence (requeres WorldEdit)
  18.   permissions:
  19.     enabled: true #enable permissions purge (needs Vault, or GroupManager)
  20.     savecmd: mansave #command to save changes to permissions after purge is done
  21.   mywarp:
  22.     enabled: true #enable mywarp purge
  23.   dat:
  24.     enabled: true #enable or disable player .dat file purge

指令和权限


/asw save手动执行保存，对应权限: autosaveworld.save
/asw backup手动执行备份，对应权限: autosaveworld.backup
/asw purge手动执行清除，对应权限:autosaveworld.purge

/asw help #显示帮助 对应权限:autosaveworld.help
/asw reload #重新加载 config.yml 和 configmsg.yml 对应权限:autosaveworld.reload
/asw reloadconfig #重新加载 config.yml 对应权限:autosaveworld.reloadconfig
/asw reloadmsg #重新加载 configmsg.yml 对应权限:autosaveworld.reloadmsg
/asw version #显示AutoSaveWorld版本 对应权限:autosaveworld.version
/asw info #显示AutoSaveWorld信息 对应权限:autosaveworld.info


注意:
除自动保存以外的所有功能默认都是禁用的。
