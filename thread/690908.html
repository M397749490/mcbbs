 插件介绍

由于我想做一个低仿泰拉瑞亚的修闲服，这个插件就这么出来了。
由于本人能力有限，有BUG的话我会尽力修复。但。。
本插件可以让你在挖掘某方块时有几率掉落生命水晶
生命水晶可以提升最大生命值
插件只会在你使用水晶之后修改最大生命值，所以....
你懂我的意思吧

 特性
◎ 挖掘某方块时有几率掉落生命水晶
◎ 达到钦定生命上限之后将无法再继续提升
◎ 每次提升多少生命可设定
◎ 生命水晶的材质，名字，LORE可设定
◎ 可以在右键&食用两种模式切换
◎ 自定义提示消息

 指令&权限
/pph help 查看帮助
/pph set 设置某人生命最大值
/pph give 给某人生命水晶
/pph check 检查某人生命信息
暂时只有OP能做check以外的事

 配置文件





  1. #插件前缀
  2. prefix: '&a[没想到吧]'
  3. #可以找到水晶的方块列表
  4. #精准采集无法挖出水晶
  5. block:
  6.   - LAPIS_ORE
  7.   - DIAMOND_ORE
  8. #获得几率 0~100
  9. chance: 20
  10. #玩家的最大生命值
  11. maxhp: 400.0
  12. #每次服用后提升多少生命
  13. hpadd: 20.0
  14. #是否回复提升部分的生命
  15. recover: true
  16. #使用食物模式？生命水晶为食物时请开启
  17. useeatmode: true
  18. #目前只会在后台提示你音效是否正确
  19. debug: false
  20. #================
  21. #信息的各种设定||
  22. #================
  23. message:
  24. #生命最大时使用水晶后的提示信息
  25. maxhpmessage: '&e生命已达上限.'
  26. #生命提升时的提示信息
  27. hpupmessage: '&e生命上限增加,输入/pph check查看自己的血量'
  28. #检查生命时的信息
  29. checkmessage: '&e目标的生命为 &2%hp%&e/&a%maxhp%,&e全服生命上限为 &c%limithp%'
  30. #获得水晶提示信息
  31. getmessage: '&e你找到了一个生命水晶.'
  32. #====================
  33. #生命水晶的各种设定||
  34. #====================
  35. heart:
  36. #生命水晶的材质
  37. itemid: GOLDEN_APPLE
  38. #生命水晶的damage值
  39. data: 1
  40. #生命水晶的名字
  41. customname: '&a&l生命水晶'
  42. #生命水晶的LORE
  43. customlore:
  44.   - '§e食用后增加20生命上限'
  45.   - '§4[最大生命上限为400]'
  46. #是否开启获得水晶提示信息
  47. sendmessage: true
  48. #============
  49. #音效的设定||
  50. #============
  51. #1.8以上版本的音效与1.8以及之前的版本名字不同
  52. sound:
  53. #发现时的音效(留空或者none则为没有音效)
  54. getsound: VILLAGER_DEATH
  55. #使用的音效
  56. usesound: VILLAGER_HIT
  57. #最大生命时的音效
  58. maxsound: VILLAGER_NO
