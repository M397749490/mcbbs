作者: Saint_Fall    时间: 2017-1-19 23:18
这个不能算是报错，只是未关闭 ProtocolLib插件自动更新所引起的。
将插件文件夹中的配置改为如下
  1. global:
  2.   # Settings for the automatic version updater
  3.   auto updater:
  4.     notify: false
  5.     download: false
