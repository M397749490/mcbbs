使用 API
  • Forge Mod Loader
  • LiteLoader

包含 Mod
  • VoxelMap
  • WorldEdit CU
  • ArmorStatus HU
  • StatusEffect HUD
  • Damage Indicators
  • Dynamic Lights
  • InventoryTweaks
  • Optifine
  • Shaders Mod
  • TooManyItems

包含材质
  • R3D SR 128x
  • Sphax PureBDCraft 128x
  • ChromaHills 128x (推荐与 SEUS 光影包协同使用)

包含光影包
  • Sonic Ether's Unbelievable Shaders (SEUS)
  • Sildur's Vibrant Shaders basic/medium/extreme


适用平台：OS X
其他平台需要下载原生库... 所以第一次启动大概会卡一会。挂个代理吧亲。

使用方法
下载(废话)
解包(还是废话)
OS X 下，把里面的 minecraft 目录丢进 ~/Library/Application Support 下即可。如果之前有这个目录建议移动到其他地方以免冲突。然后记得安装 Oracle 的 Java 以及 Minecraft 官方启动程序。然后执行包里 osx-start.command。
Linux 下，把包里的 minecraft 目录丢到 ~/.minecraft 即可。避免冲突同上。启动命令自己写。
Windows 下，打开资源管理器定位到 %APPDATA%\.minecraft，然后把所有文件移动到其他位置，再把包里 minecraft 目录下的所有文件丢进去
