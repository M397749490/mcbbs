简介
首先感谢你能看到这篇帖子
插件作者为你提供了80+附魔(包)，你也可以自己自定义附魔(包)
作者原话:
  Welcome to the Crazy Enchantments Plugin Page. This plugin has a bunch of enchantments that your players can have fun with. This plugin has over 80+ enchantments. You can now also make your own enchantments.
    欢迎来到 疯狂附魔 发布页，这款插件有很多新附魔能提供给你的玩家很多乐趣，这个插件超过80种附魔属性，你也可以自己制作属于自己的附魔属性。
关键：该插件完全免费,而且可以自定义附魔

插件特色
超过80+附魔属性
制作属于自己服务器的附魔属性
高度自定义[GUI以及提示信息等都可以修改任意语言]
附魔等级限制功能
牌子商店/箱子(GUI)商店
支持经验/金币(Vault)
... ...等

本插件支持以下插件

- World Guard
- Silk Spawners
- Feudal
- Kingdoms+
- Factions by Massive Ctaft
- FactionsUUID
- ASkyBlock
- MegaSkills
- Towny
- Legacy Factions

命令/权限
命令
权限
描述
/Tinker crazyenchantments.tinker交易GUI
/BlackSmith crazyenchantments.blacksmith 铁砧特性的GUI
/GKitz crazyenchantments.access 附魔包GUI
/GKitz [Kit] [Player] crazyenchantments.gkitz.<gkit> 给予给[player]一个附魔包
/GKitz Reset <Kit> [Player] crazyenchantments.reset 重置[player]的冷却时间
/CE crazyenchantments.access 打开GUI
/CE Help crazyenchantments.access 查看帮助
/CE Info [Enchantment] crazyenchantments.info 查看附魔(包)信息
/CE Reload crazyenchantments.reload 重载插件
/CE Remove <Enchantment> crazyenchantments.remove 移除你手上物品的某个附魔属性
/CE Add <Enchantment> [LvL] crazyenchantments.add 添加你手上物品的附魔属性
/CE Spawn <Enchantment> [Level:#/World:<World>/X:#/Y:#/Z:#] crazyenchantments.spawn 在你当前位置放下一本附魔书
/CE Scroll <Black/White/Transmog> [Amount] [Player] crazyenchantments.scroll 给予玩家卷轴
/CE Crystal [Amount] [Player] crazyenchantments.crystal 给予玩家保护卷轴
/CE Scrambler [Amount] [Player] crazyenchantments.scrambler Gives a player Scramblers.
/CE Dust <Success/Destroy/Mystery> [Amount] [Player] [Percent] crazyenchantments.dust 给予玩家魔法粉尘(+成功率/-失败率/随机获取+-)
/CE Book <Enchantment> [Lvl] [Amount] [Player] crazyenchantments.book 给予玩家一个多少等级的附魔书
/CE LostBook <Category> [Amount] [Player] crazyenchantments.lostbook 给予玩家随机附魔书
crazyenchantments.sign                    制作木牌商店的权限
crazyenchantments.limit.#  “#”修改为任意数字，限制最高附魔数量
crazyenchantments.bypass                  跳过冷却Gkits时间

注：'<>'为必填内容,'[]'为选填内容

插件更新记录[中-英]
翻译可能有误，望指出修正
v1.7.9.3.8 Update[New!]
Bug Fixes:
- A blank line from Crazy Enchantments would appear randomly in Console due to old MCUpdate class.
- Telepathy enchantment would not give the user's cocoa beans when breaking a cocoa bean plant.
Trello: https://trello.com/c/uPuuvy11
- Telepathy would sometimes give broken texture blocks for slabs and leaves.
Trello: https://trello.com/c/hrhmIB8h
- Telepath + Silk Touch would sometimes give duplicate blocks for Sea Lanterns.
Trello: https://trello.com/c/ktWWUQoN

Changes:
- Switched from my old Settings Manager to my new FileManager class to control all the config files.

v1.7.9.3.7 Update
Fixes:修复

- Vanilla enchantments are hidden in Gkit items. 普通(原版)附魔在Gkit中隐藏

- Small Spelling error for the FeedMe description.小的拼写错误

- GKitz was hiding vanilla enchantments when custom enchantments were added to the item. This affected 1.10 down.

  当自定义附魔添加到Gkit后会隐藏普通附魔，这影响到1.10版本

Added:添加

- /ce add now supports the real name of the enchantment instead of only the custom name.

   /ce add 现在支持该附魔的真实名字，而不仅仅是自定义附魔的名字

Changes:

- Some code clean up to make it look nicer.去掉多余代码,

v1.7.9.3.6 Update
Fixes: 修复
- 1.7 servers would get an error from ItemFlags since 1.7 does not have ItemFlags.
  1.7服务器会从ItemFlags那里得到一个错误，因为1.7没有ItemFlags。
- BlackSmith not giving 1.11+ servers glowing books when combining books.
  铁匠(疯狂铁砧)在合并附魔书时不会给1.11多个发光的书?
- Left clicking an enchantment book would show the enchantment description. This should have been right click only.
  左键单击附魔书将显示附魔描述。这应该是右键单击。
- Some servers kept getting errors about the Unbreaking option because I was using a Spigot only method which seemed to break even on different Spigot versions. I switched to NBT tags to stop these errors.
  一些服务器不断地收到关于Unbreaking选项的错误，因为我使用的只是Spigot，它似乎在不同的Spiget版本上达到了平衡。我切换到NBT标签来阻止这些错误??(机翻)



Added:  添加

- A newly integrated plugin called NBT API by @tr7zw.

  一个新的NBT API 由tr7zw制作

- GKitz now supports Spawn Eggs better.

  Gkitz现在支持更好的产卵?（或生成蛋?）





Code Changes: 代码修改
- All the NMS classes were removed in favor of the new NBT API that is integrated into CE.
所有NMS classes都被删除，集成到CE中的新的NBT API中
v1.7.9.3.4 Update
Added: 添加
- Crazy Enchantments is now in maven.


Bug Fixes:  BUG修复
- Error with the Bow enchantments that happens rarely on some servers.
  弓附魔错误,此情况很少出现
- AAC giving null player causing an error.  
  AAC给予无效玩家发生错误
- Missing code for 1.12 support for spawn eggs.  
1.12版本缺少代码
- Recoded the Glowing system and Items system so now everything that should glow will glow in 1.11+ except for the items that get enchanted as adding a glowing effect would hide the vanilla enchantments on the item.
   对发光系统和物品系统进行重新编码，所以现在所有应该发光的东西都会在1.11+中发光，除了被附魔的物品外，因为增加一个发光效果将隐藏该物品上的普通附魔(发光就是附魔后的那个光,应该懂吧？233)
- Bug in the customenchantments.yml where it would shoot errors if using Slow_Digging potion effect for some stuff.
如果使用一些缓慢_挖掘药水效果，则会在customenchantments.yml中出现错误
- Telepathy was not giving multiple items for blocks that drop multiple of the same item.
  Telepathy并没有给同一个项目的多个块提供多个项目

其他版本更新请去原贴查看
