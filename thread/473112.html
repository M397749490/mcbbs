里面的代码如下
  1. package 包名:

  3. import org.bukkit.plugin.java.JavaPlugin;

  5. public class 类名 extends JavaPlugin{

  7.   @Override
  8.   public void onEnable(){

  10.     getLogger().info("插件已加载");

  12.   }

  14.   @Override
  15.   public void onDisable(){

  17.     getLoggin().info("插件退出");

  19.   }

  21. }
复制代码



如果要写指令，那么再新建一个类，建在刚刚建的包里，或者其他包(名字自己取)，类的名字自己取（里面最好加个Commands）
然后，基础代码如下
  1. package 包名;
复制代码
然后在主类的onEnable方法里面加点东西

  1. getCommand("你的指令").setExecutor(new 指令类类名());
复制代码
有多少指令就写多少次，就可以注册指令了



当然，如果你还想在你的插件里面加事件监听的话，那么
再新建一个类，建在刚刚建的包里，或者其他包(名字自己取)，类的名字自己取（里面最好加个Listener）
然后，基础代码如下
  1. package 包名;
复制代码
然后也同样的，在主类里加点东西
  1. getServer().getPluginManager().registerEvents(new 事件侦测类名(), this);
复制代码
