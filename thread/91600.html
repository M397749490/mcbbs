打开plugins/essential下的config，找到
  1. prevent:                                 # 阻止以下现象(译注:true就是阻止,false是允许,这里需要注意一下)
  2.     lava-flow: false                       # 阻止 岩浆的流动
  3.     water-flow: false                      # 阻止 水的流动
  4.     water-bucket-flow: false               # 阻止 水桶水的流动
  5.     fire-spread: true                      # 阻止 火的传播
  6.     lava-fire-spread: true                 # 阻止 岩浆引起的火的传播
  7.     flint-fire: false                      # 阻止 打火石产生火
  8.     lightning-fire-spread: true            # 阻止 闪电引起的火的传播
  9.     portal-creation: false                 # 阻止 传送门的创造
  10.     tnt-explosion: false                   # 阻止 TNT的爆炸
  11.     tnt-playerdamage: false                # 阻止 TNT对玩家造成伤害
  12.     fireball-explosion: true               # 阻止 火球的爆炸(译注:恶魂发射的火球)
  13.     fireball-fire: false                   # 阻止 火球的燃烧
  14.     fireball-playerdamage: false           # 阻止 火球对玩家造成伤害
  15.     witherskull-explosion: true            # 阻止 凋零攻击的爆炸
  16.     witherskull-playerdamage: false        # 阻止 凋零攻击对玩家照成伤害
  17.     wither-spawnexplosion: true            # 阻止 凋零出生时的爆炸
  18.     wither-blockreplace: true              # 阻止 凋零破坏方块
  19.     creeper-explosion: false               # 阻止 爬行者的爆炸
  20.     creeper-playerdamage: false            # 阻止 爬行者对玩家造成伤害
  21.     creeper-blockdamage: true              # 阻止 爬行者炸毁方块
  22.     enderdragon-blockdamage: true          # 阻止 末影龙破坏方块
  23.     enderman-pickup: false                 # 阻止 末影人拾取方块
  24.     villager-death: false                  # 阻止 村民被杀死
复制代码
修改对应项重启即可

注意，这是个全局设置，所有的世界都生效
