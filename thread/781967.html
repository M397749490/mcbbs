每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。

然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。

Minecraft 1.13 仍未发布，18w07a为其第18个预览版。


MINECRAFT SNAPSHOT 18W07A
A Minecraft Java Edition snapshot
Java版1.13快照 18W07A

Today is Valentines Day! We couldn't think of any better way to show our love for you than to give you a snapshot full of new things. <3
今天是情人节！除了一个充满新东西的新快照，我们想不出用什么来表达我们对你的爱啦！<3


CHANGES IN 18W07A
18W07A变更列表
  • Added Phantoms (MineCon voted mob!)
  • 新增 Phantoms （Minecon投票生物/生物B）
  • Added Turtles
  • 新增 海龟
  • Added new swimming ability (sprint underwater!)
  • 新增 新的水下能力（水下游泳）
  • Added bubble columns
  • 新增 气泡柱
  • Added ability to strip logs
  • 新增了剥皮的原木
  • Added new trident weapon
  • 新增武器 三叉戟
  • Squids now shoot ink to defend themselves
  • 鱿鱼现在用墨汁来保护自己（一个基岩版3年前加入的东西233）
  • Added new kelp and sea grass blocks
  • 新增 海带和海草方块
  • Items in water now float to the top
  • 水中掉落的物品现在会浮到上面
  • Added new prismarine stairs and slabs
  • 新增了海晶石台阶与半砖

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要vpn。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验快照版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
