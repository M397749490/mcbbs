作者: 酷车手BB弹    时间: 2016-7-25 20:30
打开ess的文件夹，打开config
用记事本打开，找到下面的
  1.   # 禁止各种物理现象和行为
  2.   # 查看更多信息,请访问 http://wiki.ess3.net/wiki/AntiBuild

  4.     # 玩家是否可以建造:
  5.     # 设置为 true 可以禁用那些没有权限玩家的建造
  6.     # 设置为 false 将使 EssentialsXAntiBuild 从不阻止玩家建造
  7.     build: false

  9.     # 玩家是否可以使用物品(当玩家没有build权限的时候):
  10.     # 设置为 true 可以禁用那些没有权限玩家的使用物品
  11.     # 设置为 false 将使 EssentialsAntiBuild 从不阻止玩家使用物品
  12.     use: false

  14.     # 玩家无法建造时是否提示玩家
  15.     warn-on-build-disallow: true
复制代码

如果是true的
将Build和use都改为false即可
