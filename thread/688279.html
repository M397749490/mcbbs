插件介绍
它可以和
WorldGuard
GriefPrevention
ASkyBlock
连用
可以让你服的玩家发现玩法的有趣！
使用这款插件，你服务器必须支持java8！


插件使用效果图


插件权限
很简单:
meloncrack.use
是否让玩家使用


插件命令
/meloncrack reload
重载配置文件


配置文件
  1. #设置
  2. Settings:
  3.   #边界支持
  4.   WorldGuard: false
  5.   #区域保护支持
  6.   GriefPrevention: false
  7.   #空岛支持
  8.   ASkyBlock: false
  9.   #是否掉落西瓜？
  10.   DropMelon: true
  11.   #是否允许发射器
  12.   AllowDispensers: true
  13.   #是否允许小白射爆西瓜
  14.   AllowSkeletons: true
  15.   #爆炸时是否给玩家提示
  16.   MessagePlayers: true
  17.   #爆炸时给予的提示
  18.   Message: BOOM!
  19.   #粒子的多少，建议设置少，不然造成卡服
  20.   ParticleAmount: 1000
  21.   #音乐声音
  22.   Sound: Entity Zombie Step
