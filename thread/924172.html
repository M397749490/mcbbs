修订并翻译自英文Minecraft Wiki https://minecraft.gamepedia.com/Bedrock_Edition_1.13.0
与中文Minecraft Wiki同步 https://minecraft-zh.gamepedia.com/基岩版1.13.0

感谢诸多热心玩家的付出。

1.13.0是基岩版的重大更新，发布于2019年10月29日。它加入了狐狸、棕色哞菇、迷之炖菜、凋零玫瑰、结构方块的功能和一些其他特性，以及对地图制作和命令进行进一步完善。

新内容
方块
失活的珊瑚
  • 珊瑚放置在地面或没有水时形成的一种失活的珊瑚变体。
  • 可以放置在方块顶部。
花
  • 加入了凋零玫瑰。
    • 由凋灵杀死的非亡灵生物掉落或种植。
    • 可对周围的玩家和生物造成1秒的凋零效果。
    • 可用于合成黑色染料。
光源方块
  • 可以通过/give、/fill和/setblock获得。
  • 支持0-15级光照等级的辅助数据。
音符盒
  • 加入了11种新的音效：
    • 骨块 = 木琴
    • 金块 = 铃铛（钟琴）
    • 粘土 = 长笛
    • 浮冰 = 管钟
    • 羊毛 = 吉他
    • 铁块 = 铁片琴（颤音琴）
    • 灵魂沙 = 牛铃
    • 南瓜 = 迪吉里杜管
    • 绿宝石块 = “芯片”（方波）
    • 干草块 = 班卓琴
    • 荧石 = “扣弦”（电钢琴）
结构空位
  • 它是一种透明的方块，用于结构方块显示空气。
    • 曾用于替换屏障方块（早期开发期间），所以此方块也可以成为结构的一部分。
  • 该方块是隐形的，并且拥有一个小碰撞箱。
    • 只有在结构方块中启用"显示隐形方块"时才会显示。
    • 此外，玩家手持结构空位时，所有放置的结构空位都将可见，类似于屏障。
  • 用于显示结构中的空位。
    • 不同于空气，不会在加载时覆盖方块。
    • 例子：如果玩家将2格高结构顶部的空气和底部的结构空位加载到一个2格高的石头方块中，则顶部的方块将转变为空气，但底部仍保持为石头。
  • 版本独有：有一个和Java版不同的材质。

物品
迷之炖菜
  • 可以在沉船遗迹里的箱子中找到。
  • 消耗此物品时，给予的状态效果取决于用什么花合成的。沉船里找到的迷之炖菜则会给予随机效果。
刷怪蛋
  • 加入了狐狸刷怪蛋。

生物
棕色哞菇
  • 生成于红色哞菇被雷击时。
  • 可以喂不同的花来生产迷之炖菜。
狐狸
  • 在降雪的生物群系生成白色变种。
  • 北极熊会主动攻击它们。
  • 信任玩家的狐狸会保护玩家。
  • 能够捡起并用嘴携带物品。
    • 会吃掉嘴里的食物。
  • 自然生成的狐狸有几率嘴里叼着东西。
    • 版本独有：狐狸死亡时，嘴里叼着的物品100%掉落，即使是它生成时叼着的物品。
    • 版本独有：自然生成时叼着的部分物品的几率与Java版不同。
  • 版本独有：狐狸有几率生成在针叶林村庄中。

世界生成
村庄
  • 重新加入了僵尸村庄。

游戏内容
成就
  • 版本独有：加入了新的成就：
    • 炖肉时间到 - 给某人一份迷之炖菜。

命令格式
  • 使用命令时坐标可以用tab自动补全了。
  • 为生物持久性加入了PersistComponent组件。
  • 改进了许多制作地图存档用的命令。

常规
辅助功能
  • 辅助功能选项现在可在游戏内聊天栏访问，且进行了修补。
  • 在无障碍设置中添加了允许用户不自动启用“聊天文本转语音”的选项。
角色创建者
  • 允许玩家以多种方式个性化定制自己的游戏角色，包括身体的大小和形状，及四肢、眼睛、嘴巴、发型发色、面部毛发和肤色的调整。
    • 包含100余种可免费调整的项目，另有一系列自定义饰品可供选购。
  • 之前的自定义皮肤仍然可以在Windows 10和移动平台上导入。
聊天
  • 加入了进入世界后禁用聊天提示的功能。
制作人员名单
  • 加入了游戏制作人员名单。
    • 可以在击败末影龙后查看，也可以通过设置菜单下的新按钮查看。
字体
  • 更改了菜单的字体。
常规
  • 加入了与PlayStation相关的信息，并将相关的内容存储在游戏文件中。

更改
方块
珊瑚
  • 现在能放置在地面上了，但是没有水将会转化为失活的珊瑚。
草径
  • 现在可以在创造模式物品栏里找到了。
物品展示框
  • 现在能放置在方块顶部和底部了。
结构方块
  • 现在可以被使用了，就像Java版中那样。
  • 保存和加载功能需要开启exg后才可用。

物品
盔甲
  • 损坏的盔甲现在当玩家或生物受伤时不再变成红色。
相机
  • 不再能通过give命令获得。
  • 加入了功能。拍摄的照片现在会储存在screenshots文件夹里。
海龟蛋
  • 在物品栏中拥有2D材质了。
地图
  • 锁定的地图现在有一个独特的物品栏图标。

生物和实体
盔甲架
  • 现在更改姿势时的动画更平滑了。
鱼
  • 现在被杀死时会掉落经验值了。
袭击队长
  • 玩家在杀死袭击队长后现在会正确获得不祥之兆效果。
玩家
  • 现在身高是1.8个方块了。（{MCPE-31710）
  • 现在会眨眼了。
鱿鱼
  • 现在可以生成于河流中。
村民
  • 如果村民的物品栏当中有面包，它们会恢复生命值。
  • 大师级别的农民现在会出售迷之炖菜了。（MCPE-51215）
  • 制图师村民的交易现在需要11个玻璃板而不是10个。
  • 村民的交易等级现在和Java版的一致，有5个等级徽章而不是3个。（MCPE-43206）

常规
  • 现在玩家试图在被村民占据的床上睡觉时会成功，并将村民赶下床。
  • 性能改进。
  • 加入了一条消息，用来通知玩家商城的资源包是否与其Minecraft版本兼容。（即若它包含了一个新版本的方块的话）
  • iOS版Minecraft将不再显示“是否关闭Minecraft”的弹框，因为iOS不支持这种操作。
地图制作和附加包改进
  • 新的数据驱动的对象：
    • 酿造台药水配方。
    • 实体产生的环境破坏。
    • 海龟被闪电击中。
    • 河豚膨胀状态。
    • 钓鱼鱼钩动画。
    • 马的模型与动画。
    • 雪傀儡移动并产雪。
    • 龙息粒子。
    • 守卫者/远古守卫者的动画和渲染
    • 远古守卫者攻击动画。
    • 烟花粒子（教育版）。
    • 气球摆动（教育版）。
  • 更改了Breathable、RideTick和Transformation系统，让它们使用ViewedEntityContext。
  • 加入了push组件以判定实体是否可以被推动。
  • 加入了persistent组件以判定实体是否会持久地存在于世界中。
  • 大幅增加了spawnRadius的距离上限。
  • 拉杆现在拥有独立的方块状态。
  • 紫珀块和石英块现在拥有独立的方块状态，而不是使用方块方向状态的值。
  • Actor Definition Events现在可以被脚本触发。
  • 现在可以在游戏运行中查看脚本日志。
  • 加入新的Actor脚本标签。
  • 为方块添加了container脚本组件。
  • 加入了新的脚本行为：projectile_hit、entity_hurt、entity_sneak、entity_attack和block_exploded。
游戏指南
  • 改进了“游戏指南”。
  • 在“游戏指南”当中加入了结构方块的相关章节。
  • 更新了装甲部分，以指明应使用雕刻南瓜作为头盔来防止末影人的攻击。
  • 更新了有关修复鞘翅的部分，该部分现在介绍了应使用幻翼膜代替皮革修复鞘翅。 (MCPE-41608)
  • 更新了有关袭击的部分。
  • 更新了有关主控者和玩家的部分。 (MCPE-28976)
  • 更新了有关驯服猫的部分。(MCPE-43490)
菜单界面
  • 将菜单中的“衣架图标”替换成了“个人资料”按钮
  • 将“成就”按钮移至“个人资料”中。
灾厄巡逻队
  • 灾厄巡逻队现在会在除蘑菇岛及其变种外的所有生物群系中生成。
  • 灾厄巡逻队的生成延迟时间从5-6分钟增加到10-11分钟。
  • 灾厄巡逻队中的成员现在会一同攻击对它们进行攻击的生物。
袭击
  • 战胜袭击后，村民会欢呼。
  • 袭击摧毁村庄后，灾厄村民会欢呼。
Render Dragon
  • Xbox One现在使用新的渲染引擎Render Dragon。
屏幕大小
  • 加入了一条新的提示，告知玩家在必要的时候调整屏幕安全区大小。

修复
