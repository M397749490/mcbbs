DesoxBans
封禁插件[BungeeCord]


一、简介 Description
DesoxBans是MySQL支持bungeecord简单的封禁插件！



二、图片 Pictur




三、指令 Command
/ban <ID> <原因> -永久封禁一个玩家
/tempban <Player> <Value> <Unit> <Reason> -暂时封禁玩家
/check list -显示封禁玩家名单
/check <Player> -检查玩家是否被封禁
/unban <Player> - 解封玩家


四、权限 Permission
desoxbans.admin ->使用所有的desoxbans权限（需在bungeecord的config.yml添加）
