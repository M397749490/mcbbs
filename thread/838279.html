标题: Minecraft 主机版 3DS 1.9 发布
主机版即Xbox 360，Xbox One版，PlayStation 3/4/Vita版，WiiU版，Switch版，由4J Studios为Mojang开发。

迎接新的正式版吧！

转载本贴时须要注明原作者以及本帖地址。


https://feedback.minecraft.net/hc/en-us/articles/360022028351-Minecraft-New-Nintendo-3DS-Edition-1-9

Welcome to Version 1.9! This will be the last update for Minecraft: New Nintendo 3DS Edition.

欢迎来到1.9版本！这将是Minecraft 3DS的最后更新。

New features
新内容

  • Woodland Mansions
  • 林地府邸
  • Explorer maps
  • 探险家地图
  • Iron & gold nugget smelting
  • 铁粒/金粒烧制

New blocks / items
新方块/物品

  • Concrete
  • 混凝土
  • Concrete powder
  • 混凝土粉末
  • Glazed Terracotta
  • 带釉陶瓦
  • Shulker box
  • 潜影盒
  • Frosted ice
  • 霜冰
  • Totem of Undying
  • 不死图腾
  • Iron nuggets
  • 铁粒
  • Magma block
  • 岩浆块
  • Bone block
  • 骨块
  • Nether wart block
  • 地狱疣块
  • Red Nether brick
  • 红色地狱砖块
  • Spawn eggs (llama, Vindicator, Evoker, Vex)
  • 怪物蛋（羊驼，卫道士，唤魔者，恼鬼）

New entities
新实体

  • Llamas
  • 羊驼
  • Vindicators
  • 卫道士
  • Evoker
  • 唤魔者
  • Vexes
  • 恼鬼
  • Cartographer Villagers
  • 制图村民

World generation
世界迭代

  • Underground fossils
  • 地底化石
  • Natural magma block generation in the Nether
  • 岩浆块自然产生在地狱

  • New enchantments
  • 新附魔
    • Frost Walker
    • 冰霜行者
    • Mending
    • 经验修补

  • New achievements
  • 新成就

  • Numerous bug fixes from previous builds
  • 修复了前几个测试版的漏洞
