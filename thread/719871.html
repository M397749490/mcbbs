特点

配置简单

指令
/ servernpc create（子服名字）（NPC皮肤）（NPC名字） -  创建一个NPC
/ servernpc delete（NPC的id） -  删除一个NPC
/ servernpc list  -  查看NPC列表
/ servernpc reload  -  重载插件

配置

  1. Hologram:                 //设置NPC头上计分板的内容
  2.     Lines:
  3.       - "&b%NPCName%"
  4.       - "&e{online: %server%} players"
  5. Messages:               //自定义提示
  6.     rightClick: "&aSending you to the &7%server% &aserver."
  7.     cmdNoPerm: "&c&lERROR: &7You don't have permission to use this command."
  8.     npcNoPerm: "&c&lERROR: &7You don't have permission to use the &e%server% &7NPC."
  9.     onlyPlayers: "&c&lERROR: &7This command is only available for players."
  10. Permissions:                  //自定义权限
  11.     create: servernpc.admin
  12.     delete: servernpc.delete
  13.     list: servernpc.list
  14.     reload: servernpc.reload
  15.     allTheAbove: servernpc.admin
  16. NPCS: []                      //创建的npc
