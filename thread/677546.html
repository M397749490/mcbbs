标题: 龙族崛起生化系列2丨生化大逃杀






本存档是1.7.2存档，存档地址:http://pan.baidu.com/s/1o7QLHF0
玩法很简单，一开始游戏的前10秒，人类是在包围圈里，不能出来，10秒后打开牢笼并随机一人变成母体(母体无敌)，传送到上面的牢笼，给予人类6秒的时间跑路，6秒后放出母体。
被母体杀死的人类原地复活并变成丧尸，丧尸血量有限
被人类杀死的丧尸复活在母体的传送点，要重新追逐
人类胜利条件:到达指定地点，才下压力板，坚持20秒等待，20秒后直接逃亡胜利
丧尸胜利条件:歼灭所有人类，或者夜幕降临人类无法逃脱
人类胜利，每个人类阵营+5分
丧尸胜利,每个丧尸阵营+2分
分数可以在主城兑换指定武器，武器不删除
中途回合结束条件:丧尸退出游戏，回合停止

开始游戏规则:需要满5人后30秒自动开始，右边会显示Time表示倒计时
开创造规则:/scoreboard players set @p qx 1,在输入/gamemode 1即可,但是无法加入游戏和玩家一起玩，/scoreboard players set @p qx 0，会自动把你跳转到生存，并无法改成创造，但可以和玩家们一起玩
