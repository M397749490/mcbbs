今天带来的是如何用好的.bat文件开服
仅供参考，加了[]的地方请自行更改
本文本只试了1.8开服，其他版本请将其中
  1. -XX:+AggressiveOpts -XX:+UseCompressedOops
复制代码
删除，或加上后没有问题可不用删除
直接上文本
  1. @echo off
  2. title [服务器]
  3. :start
  4. color 7
  5. "[C:\Program Files\Java\jre1.8.0_91\bin\java.exe]" -Xincgc -Xmx2048M -XX:+AggressiveOpts -XX:+UseCompressedOops -jar [PaperSpigot-1.8.8-R0.1-SNAPSHOT-latest.jar]
  6. cls
  7. :menu
  8. echo.
  9. echo.　　　 菜 单 选 项
  10. echo.
  11. echo.     开服 → 请输入 1
  12. echo.
  13. echo.     退出 → 请输入 0
  14. echo.
  15. set /p xj= 输入数字后按回车：
  16. if /i "%xj%"=="1" Goto Start
  17. if /i "%xj%"=="0" Goto End
  18. cls
  19. echo 输入错误，请重新输入...
  20. ping -n 2 127.0.0.1 >nul
  21. cls
  22. goto menu
  23. :end
复制代码
