方法一：安装这个运行库Microsoft Visual C++ 2008 SP1 Redistributable，注意这里的版本需要和你的JAVA版本一致，32位JAVA就用32位的运行库，64位JAVA就用64位的运行库
附上官方下载地址：
【32位】Microsoft Visual C++ 2008 SP1 Redistributable
【64位】Microsoft Visual C++ 2008 SP1 Redistributable
方法二：直接禁用这个，在服务器的运行脚本后面添加--nojline
