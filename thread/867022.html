介绍 · Introduction

特点 · Features
  • 使用菜单建立和管理商店
  • 3 种商店: '出售', '购买' 和 '有限'
  • 2 种物品类型: 'static' and '可交易'
  • 1 个强大的商人类型: "trader" (/trait trader) 将 dtlTraders 商店绑定到NPC身上
  • 支持原版和 NBT/DataTags 物品
  • NBT/DataTags 可以兼容第三方插件的自定义物品
  • 高级用户可以自定义配置.
  • 可出售堆叠物品
  • 支持任何经济插件
  • 自动转换低版本的dtlTraders商店
  • 兼容 spigot/bukkit 1.8 - 1.14.x
5.0.4版本的新特性:
  • 设置 "default shop" 默认商店
  • 使用 "toggle shops" 关闭商店
  • 带有权限的自定义商店
  • 可调节商店的交互方式
  • 使用 "Trade Shop" 进行交易! 推迟到下个版本更新
  • 更多菜单按钮

想要更多功能的用户可以尝试这款付费插件: dtlTradersPlus

dtlTradersPlus特性:
  • 多页商店
  • 可设置打开商店的指令而无需与NPC交互
  • 更强大的商店功能
  • 2 种物品指令类型: '购买并运行指令' 和 '购买并保留指令 (可稍后运行指令)'
  • 菜单编辑
  • 所有 dtlTraders 的功能

使用方法
  • 创建NPC并给NPC加上trait  /dtltraders trait
  • 使用 /dtl create "商店名"  来创建商店
  • 把你想要出售的物品 添加物品到你的背包内
  • 使用 /dtledit 或/dtl trait  编辑你的商店
  • 点击更改内容，把要出售的物品放进菜单内，然后返回
  • 点击更改内容功能》点击物品》更改物品作用》可交易物品》保存并返回》更改交易价
  • 最后, 右击 NPC并选择与NPC关联的商店.
