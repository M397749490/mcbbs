Introduction

Creatio 是一个高版本 Minecraft 服务器，游戏玩法以原版生存为主，并以创造和小游戏为辅。

服务器会紧跟 Mojang 官方更新的步伐，将版本提升至最新的稳定版，让玩家能即使体验到高版本MC的乐趣！

Creatio成立于2020年3月18日，并在此之后不断地进行更新改进，致力于带给玩家更好的游戏体验。

玩家们的支持就是服务器发展的动力！

服务器运行维护、购买插件都需要花钱，如果有玩家愿意赞助支持这个服务器，我们将感激不尽！

Features

这里列举七点你会选择Creatio的原因

①高素质、热情、友善的玩家群体。

②几乎不修改原版玩法，不Ban任何红石机器，实现肝帝的愿望。

③主城地皮开启，让玩家在主城中建筑不再是梦。

④详细的新手教程，让没玩过服务器/MC的玩家也能轻松上手。

⑤i9-9900K强劲CPU，使得高版本渣优化也能达到20TPS。

⑥时刻保持Mojang发布的最新稳定版，让玩家能立即体验到最新版。

⑦宏伟、高质量建筑云集的主城，让想学习建筑的玩家能够有所借鉴。

Server Rules

玩家们需要知道的四条

Creatio不同于一般服务器，对于玩家没有严格的限制

服务器里没有很多的规则，最重要的是让玩家能玩的开心

这是玩家们需要遵守的底线：

①不要触犯国家法律法规。

②不去损害玩家游戏体验。

③不涉及现实中的金钱交易。

④不广告刷屏引战带节奏等。

规则经过简化，完整版可查看 Creatio Wiki 上对应章节开头标明的连接

一般玩家只需要记住这四条并有遵守规则的意识，就没有任何问题

但也请记住虽然只有四句话，但其分量很重，细品。

** 服务器中允许建造红石机器，鼓励建筑、创立小镇、发展交通

但是如果任何形式的东西影响了玩家体验（例如卡服机器）

我们会进行处理

如果你对你将要做的事情没有把握请直接在交流群中问，或者私信管理

How to Join

这里向你介绍如何加入服务器

为了保证玩家的质量和游戏体验，服务器启用了正版验证

1.加入 Creatio交流群1029029522

2.你需要在Minecraft.net上购买一份￥165的Minecraft Java Edition

3.下载1.15.2客户端和游戏本体，并登录你的正版账号

4.在主界面多人游戏中添加服务器，在服务器地址一栏写入Creatio的地址

5.保存 & 双击进入！

玩家加入服务器需要进入Creatio的QQ群，以方便交流管理

服务器地址在群公告中

如果是刚刚入坑Minecraft不知道如何操作的可以查看 Creatio Wiki ，里面有非常详细的介绍

**提示：这里正版指在Minecraft.net上购买的正版，不是离线登录的盗版也不是网易版，更不是TB花几十一百买的黑卡或迁移号。
