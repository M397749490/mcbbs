MarkItem
前言：
这个插件的确是有人搬运过，但是原搬运贴的有缺陷与错误（插件权限处与配置文件处）。
并且只提供了汉化文本下载。
介绍：
RPG服务器的轻型插件.
这个插件将打记号添加到你的服务器，当你死亡将保存打记号的物品.
锁定方块需要将该物品与Mark（打记号用的物品）放在工作台.
特性：
1.轻量
2.支持版本1.8.X-1.5.2.
3.允许记号物品与禁止记号列表
4.容易配置的Config.
5.兼容RPGInventory与许多其他RPG插件
（原帖中“RPG”写为“RP”，应该是作者打漏）
指令：
markitem-给一个MarkItem
权限：
markitem.commands-所有指令
Config：

#启用
enabled: true
#记号设置
mark:
  #打记号材料
  texture: INK_SACK:1
  #是否开启闪光（大概是打记号后会有附魔光+A+）
  glow: false
  #显示名
  name: "&9Mark"
  #介绍
  lore: "&e&o你可以给你的物品打记号，当你死亡该物品不会掉落。"
  #标记
  text: "&9- 已打记号"
##
# 允许与禁止给方块打记号
# ------------------------------------------
# 你可以指定一个范围,例如:1-100
# 你也可以使用方块赋值(耐久值),例如P:351#14
##
#允许
allowed:
  - 256-258
  - 267-279
  - 283-286
  - 290-294
  - 298-317
  - 346
#禁止
denied:
  - 268-271
  - 290
