前言
众所周知的是，工业时代2这一个老牌科技模组
分为经典的IF版本(仅1.7以前)与实验Exp版本(仅1.7以后)
两个版本的区别极大，许多人依然喜爱旧版的IF
但苦于If版在1.7以后便不再更新
许多人便转战了Exp版本
但是在坚守If版的这些勇士之中

模组特性
1.自带附属mod
1.高级机械
增加了使用高级机械方块合成的各种机械
这些机械与初级的破碎机，压缩机等功能相同
但不同之处是，这些机械增加了类似工业炉的
"热量"系统，并且带有两格容量。

2.压缩发电机阵列
(似乎叫这个？)

增加了低，中，高压三种的太阳能发电机和水力发电机
可以看做是廉价的高级水利/高级太阳能
也就是将多个水力发电机/太阳能发电机的效率叠加在一个方块上
需要注意的是，压缩太阳能仅白天发电。

3.能源桥

添加了两类方块，可以将Eu与Rf互转。
分低/中/高压。

2.充电板系统

重置版mod添加了充电板内容

你可以把他理解为是exp版本中的“充电座”

其分为四个等级

从左至右等级由低至高。分别为基础充电板，能量水晶充电板，兰波顿充电板以及量子充电板

他们的GUI为（此处以兰波顿充电板作为例子）

蓝色：能量储存区域
紫色：放入电池后为充电板充电
红色：升级插槽区域（升级待会讲）
黄色：特殊升级插槽
绿色：领域升级插槽
其余的充电板GUI分别为：


要注意的是，其中充能水晶与基础充电板的插槽是不完整的。
上锁的插槽无法解锁，无法装入升级。
那么，到这里，你要问了
既然低等级的插槽无法装入升级，然而充电板又不能通过合成升级
那我不用的充电板岂不是浪费了？
别担心，作者为我们准备了升级包。
自上由下分别为
能量水晶升级组件（用于将基础充电板升级为能量水晶充电板）
兰波顿升级组件（用于将能量水晶充电板升级为兰波顿充电板）
量子升级组件（用于将兰波顿充电板升级为量子充电板）

但是！（严肃）升级组件是必须右键充电板下方升级的！
如果你想让充电板的所有面都可以升级的话

打开.minecraft/config/IC2.cfg
在文件的第7，8行你将看到
  1. # If this config is true then you can use the ChargePad UpgradeKit on any side
  2.     B:"ChargePads AnySide Upgrade"=false
复制代码
将其改为
  1. # If this config is true then you can use the ChargePad UpgradeKit on any side
  2.     B:"ChargePads AnySide Upgrade"=true
复制代码
即可。


下面是令我翻译时吐血的升级插件板块……

1.放电效率组件
实际上是我翻译时的错误。
这个组件实际上的作用是可以同时给多个你的物品栏内的物品充能
而不是按照从第一个到第n个的顺序充能。
但要注意的是，这会使充能效率降低，被充能物品将会平分你的充能速度
放置区域：领域升级插槽

2.充能领域组件
将会在充能时在你的周围释放一个领域，领域内的所有玩家都将能为自己身上的物品充能。
分为三个等级——基础，进阶，绝对
其能够释放的电领域分别为1x1（仅在充电板正上方），3x3，5x5
放置区域：领域升级插槽

3.高护甲优先级组件
该插件使充电板首先为你的护甲充电，而不是首先充能物品栏。
放置区域：特殊升级插槽

4.生物毒性组件
该插件使充电板消耗电力以伤害其上的生物
加装该组件后，仅能在充电板的下方打开其GUI。
放置区域：特殊升级插槽

5.反向充能组件
该插件是一个恶作剧性质的插件。
它使得充电板消耗自身电力的同时消耗站在其上的玩家身上的电力——无论是护甲还是物品栏
然而这些电力并不会被储存至充电板中，而是会消失。
加装该组件后，仅能在充电板下方打开其GUI。
放置区域：特殊升级插槽

其余适用于机器的组件，大部分也都适用于充电板，
如： 高压升级，储能升级等，这些插件须被放置在一般升级插槽中。
