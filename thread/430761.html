如果楼主说的是控制。E : 离开飞机或载具
R : 飞机或载具的加载物品栏

飞机（简单控制模式）与载具
W : 加速
S : 减速/后退
A : 左转
D : 右转
左Ctrl : 机枪射击
V : 扔炸弹l
空格：爬升（仅限飞机）
左Shift : 下降（仅限飞机）
C : 切换控制模式（仅限飞机）

飞机（鼠标控制方法）
其它控制与上面相同，除了爬升与下降：
鼠标上/下：爬升/下降
鼠标左/右：左转/右转
左键：机枪
右键：炸弹
请开ESC按键设置自行设置。有可能冲突了。
