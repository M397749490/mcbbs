/give @p minecraft:stone 16 0 {CanPlaceOn:["minecraft:diamond_block"]}
那么你得到的这16个石头是可以放置在钻石块上的，当然双引号里面的是可以修改的，不过要用英文id，如果要多个的话/give @p minecraft:stone 16 0 {CanPlaceOn:["minecraft:diamond_block","物品"]}可以弄无数个。。。
，/give @p minecraft:diamond_shovel 1 0 {CanDestroy:["minecraft:sand"]}
那么这把锹可以破坏沙子，多个的话。。/give @p minecraft:diamond_shovel 1 0 {CanDestroy:["minecraft:sand","minecraft:grass"]}
那么这把锹可以破坏沙子和草方块

http://www.mcbbs.net/thread-463290-1-1.html 这里有一个办法

scoreboard objectives add GM3 dummy

/give @p minecraft:stone 16 0 {GM3:1b,CanPlaceOn:["minecraft:diamond_block"]}

scoreboard players set @a GM3 0
scoreboard players set @a GM3 1 {SelectedItem:{tag:{GM3:1b}}}
gamemode 2 @a[score_GM3_min=1]
gamemode 0 @a[score_GM3=0]


这个样子 第一条是创建计分板 然后是获得石头 接下来的是检测加使用 注意 下面的指令要高频 而且必须按顺序执行
