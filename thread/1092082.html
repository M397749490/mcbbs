给个建议，直接改成登录时判断世界。
目前的实现方式，如果是服务器突然炸了……下次进入玩家会仍然在里面。然后初始化其实不需要：
public class WorldDead extends JavaPlugin implements Listener{
        String deadMessage;
        List<String> enabledWorld;

        @Override
        public void onEnable() {
                getLogger().info("断连死亡插件启用");
                Bukkit.getPluginManager().registerEvents(this, this);

                saveDefaultConfig();
                FileConfiguration config = getConfig();

                deadMessage = config.getString("DeadMessage","12345678");
                enableWorld = config.getStringList("EnableWorld", new ArrayList<String>());
        }
        @Override
        public void onDisable() {
                getLogger().info("断连死亡插件卸载");
                HandlerList.unregisterAll();
        }

        @EventHandler
        public void playerJoin(PlayerJoinEvent evt)
        {
                Player player = evt.getPlayer();
                World tempWorld = player.getWorld();

                if(enableWorld.contains(tempWorld.getName()))
                {
                        player.setHealth(0);
                        player.sendMessage(deadMessage);               
                }
        }
}
（话说这不是应该叫断连嘛……第一眼看成整个世界的玩家链式死亡）
