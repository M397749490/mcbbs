标题: 话说插件如何在文件中创建文件
很多插件都是加载之后出现config之类的文件，这些基本都是从jar里出来的，还有些插件会游戏中生成一些玩家的文件之类的，他们创建文件时用的是java流的方式吗？



作者: 1139365029    时间: 2019-5-7 13:21
文件中不能创建文件，

使用Bukkit自带的API：
  1. File file = new File("plugins/插件名/文件名.yml");
  2. FileConfiguration config = YamlConfiguration.loadConfiguration(file);
复制代码
然后就可以向普通的配置文件一样操作了，
具体可参考这个插件：http://www.mcbbs.net/thread-614310-1-1.html

使用文件流的方法也可以，
完全脱离Bukkit，使用自己的方法操作文件、解析yml，
可以参考这个插件(只有最新版才有)：http://www.mcbbs.net/thread-824439-1-1.html
