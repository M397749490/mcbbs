安装简介
------------------------------------------
我电脑是ubuntu的其他版本请自测,教程并不太准确,请大家包含,如果不会请百度
1.首先我是介绍的是自由版(daoban)的启动方法
2.首先你得有个java的运行环境(喂,你这是废话)
    1> java 下载地址(unbuntu 系统可能会用不到,系统好像自带):
         [url=https://java.com/zh_CN/download/manual.jsp]java下载地址[/url]
    2> java -version 查看是否安装了 java
    3> 像我的unbuntu(任选其一)  
  1. 1)使用sudo apt-get install default-jre 来安装jre文件
  2. 2)使用sudo apt-get install default-jdk 来安装OpenJDK(推荐)
复制代码
   4> 下面就是主文件方法了
        1)[解压文件及其放置]
        首先 打开[终端]
            [1] 找到终端启动程序
            [2] 使用ctrl+shift+t      
  1. 然后在终端里面输入: ls -A ~/</font> (普及 ls 为查看文件列表 -A 为查看目下所有除".和.."的文件选项(可以看见隐藏文件哦) ~/ 当然就是目录了)在这个列表能看见一个叫".minecraft"的文件夹,如果没有就好办了.直接把我的压缩文件里面的".mincraft"文件夹拷贝过去就好了,当然如果有直接拷贝压缩文件.mincraft文件里面的东西就好了.
复制代码
            *解压方法:我准备了两个文件请自行选择后缀名
                   gz版和zip版(如果不明白这两个是什么请自行百度)        
                [1] 使用unbuntu里面的'归档管理器'
                [2] 使用(此处看自己下的什么压缩版本)                    
  1.                   unzip 懒人包之linux版1.7.10.zip ~
  2.                      jar -zcvf mine1.7.10.tar.gz ~/
