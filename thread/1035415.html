其他版本的操作方法大同小异，只是GUI换了下


使用相应版本的客户端输入服务器ip进入
负责善后的权限指令(一律在后台输入)：

原版：

关闭死亡掉落
  1. <div class="blockcode"><blockquote>mangaddp default essentials.<权限节点>
复制代码
常用节点：<tpa/tp/tpaccept/warp/setwarp/home/sethome/back>
小集合：
  1. mangaddp default essentials.tpa essentials.tpaccept essentials.warp essentials.sethome essentials.delhome  essentials.homeessentials.back essentials.back.ondeath
复制代码
附：ess基础权限详细介绍 https://www.mcbbs.net/thread-523520-1-1.html
LuckPerms插件:
  指令：
  1. lp group default pemission set <权限节点>
复制代码
常用节点：
tpa
                                                        nucleus.teleport.tpa.base
接受tpa
                                                             nucleus.teleport.tpaccept.base
设置家
                                                         nucleus.homeset.base
回家
                                                          nucleus.home.base                              
回到上一位置
                                                           nucleus.back.base

允许back回上一个死亡地点（这样back就不会永远都是出生点了）
                                                       nucleus.back.targets.death

附：Nucleus权限节点大全https://www.mcbbs.net/thread-727722-1-1.html
