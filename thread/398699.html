标题: Multiverse多世界插件，如何让全部世界统一出生点，或者在其他世界复活？
安装了Multiverse后
我发现ESS原先的setspawn不能让玩家在spawn复活了，而是每一个世界必须单独的mv setsapwn
导致地狱和末地必须单独设置出生点非常的蛋疼
求什么办法能让所有世界死亡后都复活到指定出生点？
作者: 庐州月    时间: 2015-1-30 02:45
打开plugins\Essentials\config.yml,移动到最下面
  1. # 设置为 lowest, 如果你想使用 Multiverse 处理重生.
  2. # 设置为 high, 如果你想使用 EssentialsSpawn插件 处理重生.
  3. # 设置为 highest, 如果你想强制使用 EssentialsSpawn插件 处理重生.
  4. respawn-listener-priority: lowest

  6. # 如果设置为true,玩家死后会重生在自己家,而不是出生点.
  7. respawn-at-home: true
复制代码

这里可以根据需要配置，根据LZ的意思，设置highest即可
