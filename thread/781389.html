插件介绍
你有没有想过拥有一个完美可以阻止下雨的插件? 你有多少次在spigot和bukkit上搜索了所有的插件资源，能找到一个完美工作无bug的插件?
No Rain Reloaded，可以满足你的这个愿望.以高质量的代码去制作一个不用付费购买的插件,NRR将停止你在服务器中的雨，没有任何控制台错误，或者是其他插件之间产生的冲突。
  作者：我自己，也是开过服务器的人，尝试了十几个同类的禁雨插件，并且几乎所有这些插件版本都已经过时了，在后台中基本是不工作或者是有大量的bug！
那么当你启动该插件时，默认情况下，它将禁用所有世界中的雨。 然后你可以通过命令去改变它，插件不会再改变它。 如果你创造了一个新的世界，那么雨水也将被禁用，所以要恢复它你只需输入 /worldrain <世界名>即可,非常简单轻量化。


特点
√可以禁用或启用雨
√雨可以通过世界禁用/启用,所以如果你想让世界下雨,你也可以做到
√一切都可以通过命令完成,所以你实际上不需要配置任何东西
√可以使用命令重新加载config.yml配置文件
√如果有需求,也可以在config.yml中编辑
√可以更改消息的颜色

√支持1.12版本!适用于Java 8或+

安装&指令&权限&其他
  • 本插件无需前置插件

指令
/rainreloaded(管理员使用)- 显示您的帮助页面
/nrr(管理员使用)- 显示您的帮助页面
/nrr(管理员使用)- 重新加载重新加载config.yml文件
/nrr info(管理员使用)- 获取关于该插件的一些信息
/worldrain <世界名> [on | off](管理员使用)- 启用或禁用世界上的降雨
/wr <世界名>(管理员使用)- 检查是否在世界中启用或禁用了雨水
/nr(管理员使用)- 检查您所在的世界是否启用或禁用雨水
/nr <世界名>(管理员使用)- 检查是否在世界中启用或禁用雨水

权限
本插件没有任何权限建议给玩家
  • norainreloaded.* ; 查看本插件所有的命令.
  • norainreloaded.norain* ; 允许使用/norain和/worldrain命令
  • norainreloaded.norain ; 允许使用/norain和/worldrain命令.默认:管理员可以使用.
  • norainreloaded.reload ; 允许使用/nrr reload命令.默认:管理员可以使用.
  • norainreloaded.update ; 允许使用/nrr update command.默认:管理员可以使用.
  • norainreloaded.updatenotify ; 允许使用/nrr update命令和侦听器.默认:管理员可以使用.
  • 在所有的命令默认其设置为管理员,所以你不需要使用权限插件
