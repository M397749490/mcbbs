最近家里的宽带突然有了ipv6地址起先以为又是个内网地址，但当好奇的ping了一下





居然不是连接超时？！

我又在网站上ping了一下





成功！就这样有了一个公网ipv6
那么问题就来了：


众所周知，这个ip是动态的，而一般的ddns服务并不支持ipv4
因此,需要编写一个支持ipv6的ddns服务









使用本教程，你需要准备什么

1.一个公网ipv6地址 (现在一般的运营商都会提供,可以通过ipconfig查看是否有非fe80开头的ip地址即可)

2.一个在Cloudflare解析的域名 (可以通过其它域名服务商转移)

3.Git(必须)以及Python(可选) Git用于执行curl








正文

前期准备:

1.获取 ZoneID 与 API Key

  首先，在域名的 Overview 页的右下角可以看到 ZoneID

  在 ZoneID 的下方可以看到 Get your API token

  之后点击 Global API Key 右侧的 View 即可查看 API Key


2.添加DNS解析

  在DNS解析页，为你需要实现DDNS添加AAAA的解析

  AAAA解析设置为::1

  不需要开启 Proxy status




3.获取域名ID

  在桌面创建记事本，重命名为test.sh

  在里面输入



  1. curl -s -X GET "https://api.cloudflare.com/client/v4/zones/[你的ZoneID]/dns_records?type=AAAA&name=[需要进行解析的域名]&content=127.0.0.1&page=1&per_page=100&order=type&direction=desc&match=any"\
  2.     -H "X-Auth-Email: [你cloudflare帐号的邮箱]"\
  3.     -H "X-Auth-Key: [API Key]"\
  4.     -H "Content-Type: application/json"\
  5.     | python -m json.tool
  6.         
  7. read -n 1
复制代码





执行test.sh

编写DDNS服务


  本人熟悉C语言，所以使用C进行编写

  (编译环境: gcc version 8.1.0 (x86_64-posix-sjlj-rev0, Built by MinGW-W64 project)，

  在 DEV-C++ 下编译时需要在 编译选项->编译时加入以下命令 加入 -std=c++11 -lwsock32 -lWs2_32 )
