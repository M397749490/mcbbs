作者: xmdhs    时间: 2019-12-29 12:27
不要替换，那个 config 做参考而不是直接替换。

要汉化 ess 的各种提醒的语言，只需在 /plugins/essentialse/config.yml 中，

设置
  1. # 设置所有消息的语言文件.
  2. # 如果没有设置,将使用默认语言文件.
  3. # 例如,使用中文语言文件,设置locale为zh,即可使用语言文件"messages_zh.properties"
  4. # 不要忘记去除"#"
  5. # 查看更多信息,请访问 [url=http://wiki.ess3.net/wiki/Locale]http://wiki.ess3.net/wiki/Locale[/url]
  6. locale: zh
