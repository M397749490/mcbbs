下面是函数 test:loop
  1. execute unless block ~ ~ ~ air run function test:store
  2. execute if block ~ ~ ~ air positioned ^ ^ ^1 run function test:loop
复制代码

其中，某 dalao 说：^ ^ ^1 中的 1 应该改成比 1 小的一个数，否则有可能跳方块（有方块检测不到），请问：
1、这是为什么？
2、改成什么数可以使得：
(1) 递归次数尽可能地少，
(2) 每个方块都检测得到。
作者: ⊙v⊙    时间: 2019-2-8 12:22
次数与精度成反比。改小能更精确，却也会使执行次数增加。
其实改为0.1或0.05已经很精确了。0.005的话怕是会让某些低配玩家体验ppt。
另外最好给个限制...
