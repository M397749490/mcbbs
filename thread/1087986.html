详细教程
最基础的材质包创建-大佬可跳过
创建一个最基础的材质包文件夹，名叫 aa，这里用文件名aa举例
aa文件夹里创建assets文件夹，assets文件夹里创建minecraft文件夹
在assets里创建一个txt文件后输入
{
  "pack": {
    "pack_format": 4,
    "description": "材质包的简介:1.14.X 发光材质"
  }
}
pack_format
你应该根据你的Minecraft版本替换“pack_format”后面的X。
“pack_format”需为：
  • Java版1.6.1-1.8.9为1
  • Java版1.9.1-10.2为2
  • Java版1.11-1.12为3
  • Java版1.13至1.14为4
  • Java版1.15-1.16为5
  • Java版1.16.2及更高为6

详细参考https://minecraft-zh.gamepedia.c ... 4%E6%BA%90%E5%8C%85


重命名为 pack.mcmeta
注："pack.mcmeta"文件告诉游戏这是一个材质包，重命名需注意扩展名，重命名后不再是txt文本文件

随便找张正方形图片放进assets里重命名为 pack.png
注："pack.png"文件告诉游戏这是一个材质包的预览图

在 aa\assets\minecraft 路径下
一.创建一个optifine文件夹
optifine文件夹内创建一个txt文本文件
打开txt文本文件并输入
suffix.emissive=_e
保存后关闭并
重命名为 emissive.properties
注："suffix.emissive=_e"意思应该是告诉optifine模组材质包里以 _e结尾的材质都要发光,如"apple_e.png"，
重命名需注意扩展名，重命名后不再是txt文本文件

这里拿金块举例，到原版材质里复制一张金块的贴图，可直接搜索 gold_block.png
复制后粘贴到 aa\assets\minecraft\textures\block 里
二.重命名为 gold_block_e.png
没错只是在结尾加了个 "_e"...

三.将材质包文件夹里的
assets文件夹，pack.mcmeta，pack.png文件
放进压缩包内
压缩完成后重命名成你喜欢的名字，这就是一个材质包了
放进游戏目录下的resourcepacks文件夹里
注：\.minecraft\resourcepacks
运行游戏就可以在游戏设置的资源包选项里看到材质包啦 \(AvA)/

运用建议
材质高亮部分会以最大亮度显示(目前还无法调整亮度)，在部分光影下通常会非常刺眼，因此造成不良的视觉效果
建议尽量避免对常见的物品或方块大面积的使用
