作者: zero28    时间: 2014-2-23 14:48
||和&&是布尔与布尔之间的运算，两边只能是true 或者 false
|,&,^,~都是数与数之间的运算，两边可以是数字，也（可能，忘了）可以是布尔，布尔的话true是1，false是0。并且由于是数与数之间的运算，是不会被“中断的运算”。最后一句可以忽略。
如果只是开发脚本，只需要会用||和&&就行了，剩下的都是在一些比较要求效率的东西上面用，插件甚少能用上

作者: 1303851661    时间: 2014-2-25 14:17
||和&&是用在用在判定语句的时候的，如果你有很多的条件，比如你要求a不仅要大于2，还要是个奇数的话，就可以用&&来表示“和”，“并且”的意思。
if(a>2&&a%2==1)
{
    //这里打符合条件的话要执行的命令
}

如果你要表示“或者”这个意思，就用||。
比如说，你要a的值是大于2的数字，或者小于20的时候执行某个命令，就用||。 这个是逻辑运算中的“或”
if(a>2||a<20)
{
    //这里打你要执行的命令
}

如果你是刚学习java的，只要知道这两个符号就行了
