作者: 天辉胡萝卜    时间: 2020-7-4 11:04
用反射获取note值

  1. import java.lang.reflect.Field;
  2. import org.bukkit.Note;

  4. public class NoteHelper {
  5.     public static int getNoteInt(Note note) {
  6.         try {
  7.             Class clazz = Note.class;
  8.             Field field = clazz.getDeclaredField("note");
  9.             field.setAccessible(true);
  10.             
  11.             int res = field.getByte(note);
  12.             return res;
  13.         } catch(IllegalAccessException | IllegalArgumentException | NoSuchFieldException | SecurityException ex) {
  14.             return -1;
  15.         }
  16.     }
  17. }
复制代码


调用：NoteHelper.getNoteInt(note)
