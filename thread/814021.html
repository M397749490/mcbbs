如图1，在世界内分别有任意两个盔甲架：
盔甲架1：无重力，坐标：（x1,y1,z1），tag=armor_stand_1
盔甲架2：无重力，坐标：（x2,y2,z2），tag=armor_stand_2
x1,y1,z1,x2,y2,z2 之间无任何数量关系。
要求：制作一个数据包，使得玩家运行数据包内的函数后，以这两个盔甲架为两个顶点用盔甲架（无重力，tag=armor_stand_3）绘制一个长方体（如图2，类似于用 /fill 指令根据两个坐标填充一个长方体），并简要说明原理。
版本：1.13.1 的快照版本 18w32a

刚好还没人答，之前组里 dalao 提到过，“点动成线，线动成面，面动成体”（把这三步分别称为 step_1 step_2 step_3，点-point，线-line，面-square）。

初始化
  1. scoreboard objectives add tmp dummy "临时"
复制代码


在玩家执行的函数里，获取两个盔甲架 X 坐标之差：$xd
  1. execute store result score $x1 tmp run data get entity @e[limit=1,tag=armor_stand_1] Pos[0] 1
  2. execute store result score $x2 tmp run data get entity @e[limit=1,tag=armor_stand_2] Pos[0] 1
  3. scoreboard players operation $xd tmp = $x1 tmp
  4. scoreboard players operation $xd tmp -= $x2 tmp
复制代码


然后在 tag=armor_stand_1 处生成“点”盔甲架
  1. execute at @e[tag=armor_stand_1] run summon minecraft:armor_stand ~ ~ ~ {Tags:["armor_stand_3","point","line","square"],NoGravity:1b}
复制代码


让 tag=point 执行 step_1
  1. execute as @e[tag=point] run scoreboard players operation @s tmp = $xd tmp
  2. execute as @e[tag=point] at @s run function foobar:step_1
复制代码


大致内容就是根据上面得到的 $xd 来不断移动“点”，并在原先位置放置新的盔甲架，使得点动成线。
  1. # foobar:step_1
  2. execute unless score @s tmp matches 0 run summon minecraft:armor_stand ~ ~ ~ {Tags:["armor_stand_3","line","square"],NoGravity:1b}
  3. execute if score @s tmp matches 1.. run teleport @s ~1 ~ ~
  4. execute if score @s tmp matches 1.. run scoreboard players remove @s tmp 1
  5. execute if score @s tmp matches ..-1 run teleport @s ~-1 ~ ~
  6. execute if score @s tmp matches ..-1 run scoreboard players add @s tmp 1
  7. execute unless score $xd tmp matches 0 run function foobar:step_1
复制代码



在玩家执行的函数里，接着获取两个盔甲架 Y 坐标之差：$yd
  1. execute store result score @s tmp run data get entity @e[limit=1,tag=armor_stand_1] Pos[1] 1
  2. execute store result score $yd tmp run data get entity @e[limit=1,tag=armor_stand_2] Pos[1] 1
  3. scoreboard players operation $yd tmp = $y1 tmp
  4. scoreboard players operation $yd tmp -= $y2 tmp
复制代码


让 tag=line 执行 step_2
  1. execute as @e[tag=line] run scoreboard players operation @s tmp = $yd tmp
  2. execute as @e[tag=line] at @s run function foobar:step_2
复制代码


大致内容就是让刚刚生成出来的“线”根据 $yd 运动为“面”
  1. # foobar:step_2
  2. execute unless score @s tmp matches 0 run summon minecraft:armor_stand ~ ~ ~ {Tags:["armor_stand_3","square"],NoGravity:1b}
  3. execute if score @s tmp matches 1.. run teleport @s ~ ~1 ~
  4. execute if score @s tmp matches 1.. run scoreboard players remove @s tmp 1
  5. execute if score @s tmp matches ..-1 run teleport @s ~ ~-1 ~
  6. execute if score @s tmp matches ..-1 run scoreboard players add @s tmp 1
  7. execute unless score @s tmp matches 0 run function foobar:step_2
复制代码



在玩家执行的函数里，接着获取两个盔甲架 Z 坐标之差：$zd
  1. execute store result score $z1 tmp run data get entity @e[limit=1,tag=armor_stand_1] Pos[2] 1
  2. execute store result score $z2 tmp run data get entity @e[limit=1,tag=armor_stand_2] Pos[2] 1
  3. scoreboard players operation $zd tmp = $z1 tmp
  4. scoreboard players operation $zd tmp -= $z2 tmp
复制代码


让 tag=square 执行 step_3
  1. execute as @e[tag=square] run scoreboard players operation @s tmp = $zd tmp
  2. execute as @e[tag=square] at @s run function foobar:step_3
复制代码


大致内容就是让刚刚生成出来的“面”根据 $zd 运动为“体”
  1. # foobar:step_3
  2. execute unless score @s tmp matches 0 run summon minecraft:armor_stand ~ ~ ~ {Tags:["armor_stand_3"],NoGravity:1b}
  3. execute if score @s tmp matches 1.. run teleport @s ~ ~ ~1
  4. execute if score @s tmp matches 1.. run scoreboard players remove @s tmp 1
  5. execute if score @s tmp matches ..-1 run teleport @s ~ ~ ~-1
  6. execute if score @s tmp matches ..-1 run scoreboard players add @s tmp 1
  7. execute unless score @s tmp matches 0 run function foobar:step_3
复制代码



最后，移除中间步骤用到的 tag
  1. tag @e remove point
  2. tag @e remove line
  3. tag @e remove square
