Chat Manager  聊天管理[重置]
-------------------------------------------------------------------

[gold_ingot] 这是什么？
- [wood_sword]这个简单的插件会让你清除你的聊天，服务器聊天，并锁定服务器聊天！
- [stone_sword]这个插件可以让玩家清除自己的聊天，并为工作人员清理整个聊天或锁定它！
- [gold_sword]想让我补充点什么吗？给点建议 TAT！

[diamond_gem] 指令列表！
/cc - 将清除整个服务器的聊天记录
/cp - 将清除你的聊天记录
/cchelp - 如果你忘记了指令，输入这个~
/cclock - 锁定聊天功能
/ccunlock - 解锁聊天功能
/ccperms - 查看这个插件的所有权限

[redstone_dust] 权限列表！
chat.public - 权限对应指令    /cc command
chat.private - 权限对应指令    /pc command
chat.help - 权限对应指令    /cchelp command
chat.lock - 权限对应指令    /cclock command
chat.unlock - 权限对应指令    /ccunlock command
chat.perm - 权限对应指令    /ccperm command
