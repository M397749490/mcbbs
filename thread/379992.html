介绍
正如图片上看到的一样，这个星门可以做成任何样子..







星门网络像贪吃蛇一样，例如在主世界有5座星门，渐进去往这些地方，穿过1号抵达2号，穿过2号就会抵达3号。只需要使用同一个名称命名。例如“主世界”，假如你看不懂这里,请继续往下看。


使用时钟来创建星门；命名时钟（使用铁砧修改时钟的名字）来创建星门网络，例如：主世界到平坦世界，我命名为"flatland"，

权限

Multiverse Conf/全局配置
multiverse conf 在 /mstore/creativegates_mconf/instance.json. 当服务器运行时你可以改变这个文件，修改会在几分钟后生效，你不需要重启和输入指令。
这是服务器全局设置,任何世界和地方.

  1. {
  2.   "aliasesCg": ["cg", "creativegates", "creativegate"],
  3.   "permissionDefaultCreate": "TRUE",
  4.   "permissionDefaultUse": "TRUE"
  5. }
复制代码


选项:
  • aliasesCg: 在这里你可以决定你想要的基本命令别名
  • permissionDefaultCreate: 如果玩家获得许可，默认创建门? 选项值 “TRUE”, “FALSE”, “OP” and “NOT_OP”.
  • permissionDefaultUse: 玩家是否应该默认使用大门？ 选项值 “TRUE”, “FALSE”, “OP” and “NOT_OP”.

Universe Conf/世界配置  
universe conf在 /mstore/creativegates_uconf@universe/instance.json 每个世界都有一个。 您可以在服务器运行时对此文件进行更改。 修改将在几秒钟后自动检测并加载到服务器中。 您不需要运行任何命令或重新启动服务器，以实现此目的。这是服务器针对每个世界的设置
  1. {
  2.   "enabled": true,
  3.   "usingWater": false,
  4.   "maxarea": 200,
  5.   "blocksrequired": {
  6.     "EMERALD_BLOCK": 2
  7.   },
  8.   "removingCreateToolName": true,
  9.   "removingCreateToolItem": false,
  10.   "materialCreate": "WATCH",
  11.   "materialInspect": "BLAZE_POWDER",
  12.   "materialSecret": "MAGMA_CREAM",
  13.   "materialMode": "BLAZE_ROD"
  14. }
复制代码

选项:
  • enabled: 如果将此项设置为false，则此世界中的插件将被禁用。
  • usingWater: CreativeGates 使用星门块作为默认模. 但是有些人喜欢用水啊！！！！.
  • maxarea: 这定义了最大门内容大小。 如果在内容达到此大小时未找到帧，洪水填充算法将停止运行.
  • blocksrequired: 门框中必须含有指定模块,默认是绿宝石2块.
  • removingCreateToolName: 创建门时，名称是否从创建工具中删除？
  • removingCreateToolItem: 创建门时是否删除整个创建工具项？
  • materialCreate: 用于门创建工具的材料。
  • materialInspect: 用于门检查工具的材料。
  • materialSecret: 用于网络保密工具的材料。
  • materialMode: 用于门进入/退出模式工具的材料。
