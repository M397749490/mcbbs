这款交友组队插件功能丰富并且拥有许多的拓展插件，在spigotmc页面上也是以高评分排在前面。
由于我汉化的时候将party翻译成小队，所以帖内有关都以小队说明
  • 菜单页面可以完全配置（比如添加物品并且自定义指令，如图）
  • 列出你的朋友，显示他们的在线状态，查看他们在哪个子服上，并可以查看他们上次上线时间
  • 和你的好友互动（传送到他们身边，拉他们进小队）
  • 背包页面中可以管理好友请求
  • 有个人设置（相关隐私设置）
  • 显示或隐藏周围玩家
  • 自定义指令
  • 支持RedisBungee
  • 支持Tab补全
  • /r 回复以及离线留言
  • 设置禁用的子服

附属插件
  • Interact all extension: 添加指令 /friend acceptall 接受所有请求 和 /friend denyall 拒绝所有请求
  • Friend toggle MSG Command extension: 添加指令 /friend toggle
  • Party toggle Command extension: 添加指令 /party toggle
  • Mute All: 添加指令 /friend muteall
  • MultiLobby server connector: 添加与 MultiLobby的支持
  • PlayerBalancer 服务器链接: 添加与 PlayerBalancer 的支持
  • Gson for 1.7.10:让插件支持1.7 (不支持1.8+) 以下

插件开发计划 (按顺序一个个添加):
  • 添加公会功能 (进度90 90% (已确认好所有的特色) (测试版本)
  • 添加网站操作以下的功能！！！！ (将在 1.2.0 上实现):
    • 添加删除朋友 (也能被op控制)
    • 发送悄悄话
    • 通过此插件验证是否正版玩家 (此功能还未生成, 将开发源码并提供与其他插件的api接口), 认证他们的正版皮肤, 通过管理员认证或者某人认证或者自动认证 (不推荐开启这个选项)
    • 网站将作为第三方支持
  • 优先修复bug次要添加功能
