作者: MXZGHaoting    时间: 2017-2-19 20:04
1.添加游戏 /bw addgame {地图名称} {最少玩家数}
2.设置等待大厅 /bw setlobby {地图名称}
3.设置游戏时间 /bw gametime {地图名称} {时间} | 时间注解[建议时间1000]
4.设置区域 /bw setregion {地图名称} {区域名称} | 区域名称注解[区域一=loc1  区域二=loc2]
5.设置队伍 /bw addteam {地图名称} {团队名称} {颜色} {最大玩家数}
颜色注解
RED=红
YELLOW=黄
BLUE=蓝
GREEN=绿
AQUA=青
BLACK=黑
GOLD=金
DARK_BLUE=深蓝
DARK_GREEN=深绿
DARK_RED=深红
DARK_PURPLE=紫
GRAY=灰
DARK_GRAY=深灰
LIGHT_PURPLE=亮紫
WHITE=白

6.设置队伍重生点 /bw setspawn {地图名称} {团队名称}
7.设置重生方块[床] /bw setbed {游戏名称} {团队名称} 或 /bw settarget {游戏名称} {团队名称}
8.设置资源重生点 /bw setspawner {地图名称} {类型}
类型注解
bronze=铜
iron=铁
gold=金

9.保存配置 /bw save {地图名称}

使用MV多世界插件或MW多时间插件啊

[创世|管理|传送]Multiverse-Core —— 多世界管理插件[1.9-1.4.5]
http://www.mcbbs.net/thread-101532-1-1.html

  • 吧地图放到与服务器核心同一个文件夹
  • /mv import [地图名字] [环境{normal(普通) nether(地狱) end(末地)}]

[管理|创世|传送]MultiWorld——多世界插件[1.5.2~1.8X]
http://www.mcbbs.net/thread-380159-1-1.html

  • 吧地图放到与服务器核心同一个文件夹
  • 输入 /mw create [地图名字]
  • 输入 /mw load [地图名字]
