是否厌烦了playersql?这款插件是你的另一个选择！
EnderSync插件使得跨多个服务器共享（玩家）数据变得十分简单。
它可以同步各种数据，如玩家生命值，背包，末影箱，金钱等等（见下文）。
作为开发人员，您还可以使用它简单的API来同步自定义数据，如统计数据，优质/特殊功能的计数器，自定义“效果”...
授权搬运
为什么要使用它？
在许多情况下它将会非常有用。例如，在CityBuild服务器，它可以在多个CB服务器之间共享玩家背包，以便玩家可以在任何地方建造/耕种。在Minigame / PvP服务器上，它可用于在服务器之间存储玩家游戏统计数据。
此外，因为它将所有内容存储在数据库中，所以可以查看和操纵玩家背包，金钱......即使没有任何玩家在服务器上在线。
  • 玩家背包
  • 玩家装备（将在下一个功能版本中得到支持）
  • 玩家末影箱
  • 玩家生命值
  • 玩家食物
  • 玩家空气(不明所以)
  • 玩家游戏模式
  • 玩家药水效果
  • 玩家飞行
  • 玩家钱（Vault）
  • 玩家上次游戏时间
  • 通过API的任何自定义数据

为何选择“BETA”？
即使插件的核心功能（通常）完美地工作（同步背包，末影箱 ......），但插件仍然存在一些小问题，如AutoUpdater可能导致某些服务器上的错误。如果可以的话请在测试服务器运行BETA,或者至少在安装插件前备份服务器数据！

它是如何工作的？
每当玩家加入服务器时，它会将玩家数据与来自数据库的数据（生命值，食物，背包......）同步。当玩家离开服务器时，它会将当前玩家数据保存到数据库中，使其保持最新状态。（还有一个autoSave功能，它会定期保存玩家数据，使数据库中的数据“实时”更新）

对于不同版本的服务器：如果玩家具有仅在1.13中可用的效果或物品，则这些物品，效果...在加入时不会同步，例如1.8服务器。在同步不同版本时请记住这一点！（同步不同版本也可能导致意外行为）

安装

注意：您需要在要保持数据同步的所有服务器上安装此插件，并将它们配置为使用相同的数据库。

  • 考虑备份您的服务器。
  • 从此页面下载JAR。（重要提示：如果您想使用AutoUpdate功能，请不要重命名该文件，我建议这样做！）
  • 下载所有依赖项。
  • 将您下载的内容放到要保持同步的所有服务器的“plugins”文件夹中。
  • 启动服务器以生成“config.yml”文件。
  • 打开“config.yml”并输入数据库连接详细信息。您需要创建数据库，插件将为您完成剩下的工作。
  • 通过将“enabled：false”设置为“enabled：true”来启用您喜欢的任何功能
  • 重新启动服务器并享受插件

命令& 权限

注意：您可以使用/ endersync或/ es

/ endersync或/ es显示基本信息。
/ es help显示帮助信息。
/ es update将插件更新到最新版本。
/ es reload重新加载配置文件。
/ es delete <name>从数据库中删除玩家的数据。
/ es saveAndKick保存所有玩家数据并踢出所有人。
/ es inv <name>允许您查看和操作玩家背包（即使他们处于离线状态）。
/ es end <name>允许您查看和操纵玩家末影箱（即使他们处于离线状态）。
/ es ecoBal <name>
/ es ecoSet <name>允许你设置玩家钱（需要Vault）。
/ sync [name]手动同步您或其他玩家。
/ save [name]手动保存您或其他玩家。

-

endersync.*授予对所有命令的访问权限。
endersync.update允许使用/ es update命令。
endersync.reload允许使用/ es reload命令。
endersync.delete允许使用/ es delete命令。
endersync.saveAndKick允许使用/ es saveAndKick命令。
endersync.inv允许使用/ es inv命令。
endersync.end允许使用/ es end命令。
endersync.ecoBal允许使用/ es ecoBal命令。
endersync.ecoSet允许使用/ es ecoSet命令。
endersync.sync.self允许自己使用/ sync。
endersync.sync.other允许对其他玩家使用/ sync。
endersync.save.self允许自己使用/保存。
endersync.save.other允许使用/保存给其他玩家。
