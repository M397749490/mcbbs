如果是获取玩家的手中物品的话：
定义的 Player 变量为 p
  1. p.getItemInHand().getItemMeta.getLore();
  2. p.getItemInHand()此方法返回的类型为ItemStack也就是物品栈。
  3. 即:
  4. int id = /*物品id写这里*/1;
  5. int amount = /*物品数量写这里*/1;
  6. short duriability = /*物品损伤值写这里*/;
  7. //List<String> lores = Arrays.asList(new String[] {lore写这里，注意用“,”来分割});
  8. /*例子：*/ List<String> lores = Arrays.asList(new String[] {"§a我是lore！","§b我也是lore！"});
  9. ItemStack item = new ItemStack(Material.getMaterial(id),amount,duriability);
  10. ItemMata meta = item.getItemMeta();
  11. meta.setLore(lores);
复制代码

获取lore的方法： 先获取ItemStack再获取ItemMeta然后就getLore();
