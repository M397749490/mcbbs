首先：原版服可以直接下载craftbukkit或其他服务端jar，然后新建文本文档，粘贴
  1. @echo off
  2. java -Xincgc -Xms1g -Xmx1g -jar 服务端文件名.jar
  3. pause
复制代码

再重命名为 开始.bat
双击 开始.bat
就可以了（刚才说的两个文件要在一个文件夹）
