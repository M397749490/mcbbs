  1. [url=home.php?mod=space&uid=39305]@echo[/url] OFF
  2. :restart
  3. title 服务器后台控制台
  4. echo ****************************************
  5. echo             正在开启服务端...
  6. echo ****************************************
  7. JAVA -Xincgc -Xmx3G -Xms1G -jar 换成你的核心名字.jar
  8. echo 玩家和地图数据已经储存，请按任意键退出本程序
  9. goto restart
