是不是在你编辑颜色，打字半天弄好一个牌子时
发现措了一个字QAQ(对于强迫症真不能忍)
然后又得把牌子打掉重来TAT

然而 当你有了这个插件
不论何时何地 谁家牌子出错了
只需对着牌子 Shift +右击！
Duang的一下 就可以直接修改当前牌子内容了！
=========================
需要前置插件：ProtocolLib 点击空降
=========================

食用方法：
  • Shift +右击一个牌子来编辑它，就是这么简单！
  • 颜色代码的支持! 把“&”,后跟一个数字0 - 9、或字母。 http://ess.khhq.net/mc/
  • 兼容保护插件，玩家只能编辑自己的牌子
  • 权限支持

权限
  • clickedit.edit ——允许使用编辑器
  • clickedit.color ——允许添加颜色标志

命令
  • /clickedit edit ——编辑你指着的牌子
  • /clickedit edit [行] [文本] ——直接编辑你指着的牌子的某行

安装
  • 需要前置插件 ProtocolLib 点击空降
  • 把 ClickEdit 和 ProtocolLib 拖拽到你的Plugins文件夹
  • 强烈建议生成配置文件后将 enable-updater: true (自动更新) 改为 enable-updater: false
  • 因为此插件的自动更新可能导致插件无效
