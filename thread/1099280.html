简介
使用此插件，玩家可以快速地将他们的药水堆叠。最大可到64个一组。
这对于 PVP 很有帮助，你不用再担心药水会占用过多的背包空间，也不用在连续使用药水时频繁切换位置。
这个插件对饮用、喷溅药水，以及插件自定义的药水（如mcmmo）都适用。

指令与权限
  • /pot - 将你的药水堆叠（权限：potionstacker.use）
  • /potreload - 重载 config.yml （权限：potionstacker.reload）

配置文件
prefix: "&f&l[&3&lPotionStacker&f&l]&a" # 前缀
allowSplash: true # 适用喷溅药水
stackSize: # 一组的最大数量
  AWKWARD: 16 # 粗制的药水
  FIRE_RESISTANCE: 16 # 抗火
  INSTANT_DAMAGE: 16 # 伤害
  INSTANT_HEAL: 16 # 治疗
  INVISIBILITY: 16 # 隐身
  JUMP: 16 # 跳跃
  LUCK: 16 # 幸运
  MUNDANE: 16 # 平凡的药水
  NIGHT_VISION: 16 # 夜视
  POISON: 16 # 中毒
  REGEN: 16 # 再生
  SLOW_FALLING: 16 # 缓降
  SLOWNESS: 16 # 缓慢
  SPEED: 16 # 迅捷
  STRENGTH: 16 # 力量
  THICK: 16 # 浑浊的药水
  TURTLE_MASTER: 16 # 神龟药水
  UNCRAFTABLE: 16 # 不可合成的药水
  WATER: 16 # 水瓶
  WATER_BREATHING: 16 # 水肺
  WEAKNESS: 16 # 虚弱


开源
https://github.com/z1haze/PotionStacker

其他说明
插件最后一次更新是在2018年8月，作者在 spigot.org 的最后一次活跃是2018年9月。
因此原帖只记录了1.13可用，1.15版的可用性是我自己测试。
同时插件如果出现问题，找原作者估计不会有回应了，我可能考虑重制（或者写个新的），所以可以在此反馈（包括下文已知问题中的——我只是列出这些问题，但由于没人提出需要修正，因此我并没有进行重制）。

已知问题和注意事项
  • 不支持中文消息
  • 部分功能自由度低或设置不符合常理（如允许设置“禁用喷溅药水”，但不能“禁用饮用药水”）
  • 如果同时使用了禁用插件，如 Dupe Fixes / Illegal Stack Remover 等，会导致药水消失
  • 如果设置的数量不到64，玩家也有办法堆叠到64（如A格有16个，B格有16个，点击B格拿起它，再点A格，A格将会只保留一个，其余全部加到手中）
  • 不能合并滞留药水
