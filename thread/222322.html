首先推荐一下jespertheend的the Code系列解谜地图，特别是the Code III非常令人震撼！地图原帖地址
这篇教程是从作者的Youtube频道上摘抄整理加翻译过来的……本帖稍微可能或许有一丁点剧透成分……


这里有一堆箱子~

其中的大箱子都很正常

但是中间的小箱子的碰撞箱是巨大的……

而且你打也打不掉！

打开它……

教程：
核心内容：
  • 36号方块
    • 无法通过一般方式破坏
    • 右键点击即可移除
  • 矿车
    • CustomDisplayTile: 1来显示箱子
    • 设置DisplayOffset来让箱子浮在方块上
  • 红石
    • 漏斗脉冲（随便用哪种脉冲，只是我喜欢用漏斗的……
  • 指令
    • /testforblock判定目标是否为空气
    • /setblock将36号方块放回去
    • /tellraw显示文字（用/say会显示一个[@]，很不科学……

其实你把这个看完基本就明白了……
