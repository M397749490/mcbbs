介绍 · Introduction
WhatIsThis这款轻量级的插件可以让你的玩家使用木棍点击方块来查看方块名称及其掉落物.这对于萌新玩家很有用

只需使用木棍右键方块即可看到方块信息，也可以输入/wt 获取你看着的方块的信息.

插件只兼容 Minecraft/Spigot 1.13+
指令 & 权限
  • /wt - 查看方块信息
  • /wt info - 插件信息
  • /wt reload - 重载插件 (需要 whatisthis.admin 权限)


  • whatisthis.use - 默认所有玩家拥有
  • whatisthis.admin - 默认管理员拥有
使用插件
输入 /wt 你就可以看到方块信息. 默认范围为10格 - 插件作者将在未来更新可配置范围.

右键用物品查看方块信息可在配置内关闭,但这没有必要.

用于查看的物品也可以配置. 默认物品为木棍. 可设置为任何物品.

物品的名称和数量从Block#getDrops()中获取. 在有变量的掉落物 (比如小麦掉落的种子数) 时会显示掉落物品数量的范围( 如 0 -> 3) .



如果掉落数有错请私聊插件作者或在Github反馈.
特点
多语言选项
从2.0版本起, 支持所有Minecraft支持的语言. 玩家的语言 (一般在Minecraft登录器内设置) 会用于显示方块和物品名.  "Drops" 可以手动在 config.yml 内翻译

由于记分板的上限为40格字符, 太长的物品名可能无法正常显示.

如果插件找不到本地语言,则会使用默认的英语.




Minecraft 1.14
这款插件将在未来的1.14版本更有用，可以让你更快地认识新版本的方块

  2. # WhatIsThis 配置文件 #
  3. # 注释会被覆盖#

  6. # Author: steve4744                            #
  7. check_for_update: true
  8. use_right_click:

  10.   item: STICK
