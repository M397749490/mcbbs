本合辑共收录有2019年7月到2020年2月的一些没有发布或者撤销发布的杂作。

近期基本上把精力全部砸在逻辑电路设计上面了，一开始是弄了点RAM，后来直接弄ALU去了，因为这个领域人生地不熟，走了不少弯路，直到刚刚才把32位串行除法器整出来。
后面一长段时间估计都会把绝大多数课余精力投入到逻辑电路上面，保守估计半年内不会制作其他什么作品，红石元件除外。

原定于2月的雅思考试被肺炎疫情宕没了，考不了就算了，大不了，还有电子科学竞赛。

此后基本上接近冬眠了，或许不会受理任何商业用途批准。目前暂定：

  1. public boolean allowForCommercialUsage(Player player)
  2. {
  3.         player.sendMessage("NEVER!");
  4.         return false;
  5. }
复制代码



全部自动授权，具体看每一个帖子的协议。遵守协议情况下的一切活动我默认自动授权了。

活动不参加了，懒了。想去森林公园放松也去不了了。

才想起来上学期人文讲座基本没去，学年内又有数量下限。下学期麻烦了。

最后很重要一点，如果东方刚欲异闻正式版上线Steam了，赶紧通知我一下，我可能会高ping回复。更大的可能性是，没看到



以下皮肤展示顺序按照创建时间排列。

只有了无光影预览，带光影效果的没做。图片简单处理过。


2019.7.15
第14届擂台赛上被自己撤销发布的一个皮肤，取而代之的是一个蓝白相间的护甲。
人设是半导体研究者，人物形象参考了牙膏厂流水线内部照片。
那个蓝白长啥样的？https://www.mcbbs.net/thread-886357-1-1.html


2019.11.16
原本是给学院制作的拟人化形象，由于征集活动大致方案拖延到两个星期前才定下来，所以……泡汤
（倒是很想吐槽，一整个活动说着学生会几十个人好好策划，结果大致方案过分潦草，活动细则之类的几乎全变成我一个人在写）


2019.11.23
同上一批的，另一个候选设定。


2019.11.29
中文译名是“晶圆”，这是和上面同一批的候选设定。


2019.12.1
“光刻工艺”。感觉画毁了。


2019.12.7
“量子化”，当时听说谷歌弄了个量子芯片（并且新闻有点讽刺其他企业的味）时肺都要气炸了。


2019.12.15
四级台风利奇马。纪念这次风灾。
同时还有一个是海贝思的，没做完，就算了。


2019.12.21
接头霸王臭鼬“凯露”，梗不必我多解释。


2019.12.27
C5是萨菲尔辛普森分级的最高级，表示热带气旋中心附近最大风速不小于137节。
当时预测北冕将是个65m/s以上的王（但JTWC一开始给的好像只有95kts来着），后来实际表明没有那么强（但是比JTWC一开始预报的强）。
就这点神操作给了点灵感吧。
现役正版皮肤，取代了擂台赛的那个蓝白机。


2019.1.1
mango……
（拉狗的用另一个号发了）


2019.1.16
去年暑假时无意中捉了几条尺蠖幼虫（Looper），由于找不到它们的天然食物，就给了点白菜，结果都不吃，全军覆没……
动车上画的，但因为晕车只做了一半。一个小时前补完。
（当时因为下大雪限速160，结果只坚持了一个小时就受不了了，趴在电脑上就是睡）
