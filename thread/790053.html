既然要矩形，那我就令你为正方形吧。。


首先我们假想有个单位圆，之后呢我们在上图找到四个黑点，这四个黑点的连线就是一个正方形，所以我们可以先从这四个黑点入手，那我这里就直接取45°就好了

  1. Location location = player.getLocation();
  2.         final int[] degrees = {45, 135, 225, 315}; // 因为我们这里只是需要四个点，所以我们就用数组保存下就行了
  3.         for (int degree : degrees) { // 对其遍历
  4.             double radians = Math.toRadians(degree);
  5.             double x = Math.cos(radians);
  6.             double y = Math.sin(radians);
  7.             location.add(x, 1.2D, y); // 那么经过相加之后，我们得到的这个location就是其中一个点的位置了
  8.             // 然后你可以将其clone然后保存在一个数组里或Cache里
  9.             // 这里做添加的操作
  10.             location.subtract(x, 1.2D, y);

  12.         }
  13.         // 剩下的便是利用点做连线的操作了, 简单得不能再简单的操作了, 代码我就不写了..
