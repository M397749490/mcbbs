  1. /tag @e[type=armor_stand, ...] add target
  2. /execute positioned as @r run summon armor_stand ~ ~ ~ {Tags:["mark"]}
  3. /tp @r @e[tag=target,limit=1]
  4. /tp @e[tag=target] @e[tag=mark,limit=1]
复制代码
注1：第一行 ... 需要指定目标位置的盔甲架。
注2：只考虑一个玩家（@r）。
