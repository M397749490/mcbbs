标题: 拾起丢失的显示问题
捡起某物用title显示+ xx
丢掉某物用title显示- xx
1.12.2
作者: MC深坑不回头    时间: 2019-10-12 19:33
本帖最后由 MC深坑不回头 于 2019-10-14 01:00 编辑



首先设置记分板统计要记的方块，这里举例金矿
/scoreboard objectives add pickgoldo stat.pickup.minecraft.gold_ore 捡金矿


当捡到金矿时计分板自动加一，高频侦测到数字为一时执行下面:
显示标题时长title @p[score_pickgoldo=1,score_pickgoldo_min=1] times 0 10 0
标题字title @p[score_pickgoldo=1,score_pickgoldo_min=1] title ["",{"text":"+ ","color":"red"},{"text":"金矿","color" :"aqua"},{"text":" x 1","color":"gold"}]
将该计分板归零/scoreboard players set @p[score_pickgoldo=1,score_pickgoldo_min=1] pickgoldo 0


丢弃也是相同作法，把变数改成
stat.drop.minecraft.gold_ore
标题字改改即可。如果要计全部物品，最好放function内执行
