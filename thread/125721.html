什么是SimpleAlias?

     SimpleAlias(命令别名)插件是一个能够为服务器命令设置别名的插件，它可以让你将冗长的命令简单化，更加简便也更加节省时间。


命令:


命令+用途
权限
/aladd <命令> <别名> = 为一个命令创建别名
SimpleAlias.add
/alremove <别名> = 移除存在的别名
SimpleAlias.remove
/alchange <旧别名> <新别名> = 更改一个别名
SimpleAlias.change
/allist = 显示别名列表
SimpleAlias.list
/alreload = 重载配置
SimpleAlias.reload
/argadd <别名> <参数> = 为别名添加参数
SimpleAlias.argadd
/argremove <别名> = 移除一个别名的所有参数
SimpleAlias.argremove
/alset <alias> <-a/-aa/-c/-p/-do/-dm> <true/false/text> = 改变一个别名的值 ("text"只在 "-dm"状态可用)
SimpleAlias.set
/alinfo <别名> = 显示别名的详细信息
SimpleAlias.info
使用从控制台被执行的别名
SimpleAlias.console
使用启用权限的别名
SimpleAlias.command.ALIAS

参数
含义
-a
使用参数(UseArgs)
-aa
一直使用参数(AlwaysUseArgs)
-c
控制台执行(ExecuteAsConsole)
-p
需要权限(Permissions)
-do
禁用来源(DisableOrigin)

-dm
禁用信息(DisableMessage)


配置文件:
  1. Aliases:
  2.   /rd:
  3.     Command: /region
  4.     Arguments: define
  5.     UseArgs: false
  6.     AlwaysUseArgs: true
  7.     ExecuteAsConsole: false
  8.     Permissions: true
  9.     DisableOrigin: true
  10.     DisableMessage: '&cPlease use %alias%.'
复制代码

名称
说明
Command:
这是原始命令，将会在输入别名时执行
Arguments:
如果你添加了参数，将会在这里显示
UseArgs:
如果这个为"true"，它会在你输入别名时使用参数 (Eg."/w"是"/weather"的别名，参数为 "sun",执行"/w"就等于执行"/weather sun")
AlwaysUseArgs:
如果这个为"true",，它会一直使用键入的参数 (在例子中，"/rd test"作为"/region define test"执行) 注意: 你必须先用/argadd添加参数，之后当你在命令后加入任何参数时会像这样： "/alias ARGS YOURARGS"
ExecuteAsConsole:
如果这个为"true"，这个命令将会在控制台被执行
Permissions:
如果这个为"true"，它会要求玩家拥有权限 (权限: SimpleAlias.command.ALIAS)
DisableOrigin:
如果这个为"true"，它会禁用原始的命令和显示禁用信息
DisableMessage:
这个信息将会在DisableOrigin为"true"时玩家访问原始命令时显示 (支持带有'&'的颜色代码)
