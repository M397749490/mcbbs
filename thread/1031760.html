功能：
  • 交互式GUI商店
  • 分类商店
  • 自定义项目的显示名称和知识
  • 出售物品或自定义命令（/time set day, /give %p% item 等）
  • 使用Minecraft内置的任何计分板分数(deathCount, playerKillCount, xp, item used/broken/crafted count,等)作为货币

教程：

首先，你需要使用Minecraft的/scoreboard命令创建一个计分板目标。 例如，我们要记录玩家杀死了多少僵尸:
  1. /scoreboard objectives add zombieKills minecraft.killed:minecraft.zombie
复制代码

我们可以通过以下方式将显示设置为侧边栏:
  1. /scoreboard objectives setdisplay sidebar zombieKills
复制代码

然后，将变量与SBS链接起来，并将其命名为KillerGold:
  1. /sbs link zombieKills KillerGold
复制代码

我们还需要一个类别来展示商品:
  1. /sbs category create cateA KillerGoldShop zombie_head
复制代码

之后，我们可以将商品添加到类别中。 货物可以是您手中的物品，也可以是任何命令。
e.g
从手中以100zombieKills分数出售:
  1. /sbs item create cateA zombieKills 100 Display_name Lore HAND 1
复制代码

以500 zombieKills分数出售改变天气的命令:
  1. /sbs item create cateA zombieKills 500 Display_name Lore COMMAND sunflower /weather clear
复制代码

最后，键入以打开商店:
  1. /sbs shop
复制代码



指令：

/sbs link  [scoreboard变量名] [显示名称]
  使Minecraft scoreboard与scoreboard shop变量连接，并赋予显示名称

/sbs unlink  [scoreboard变量名]
  使Minecraft scoreboard与scoreboard shop变量取消连接

/sbs link list
显示已建立的连接

/sbs category create  [类别] [显示名称] [显示物品]
  创建商店中的类别，通过指定的显示名称与显示物品

/sbs category remove  [类别]
  移除商店中的类别，类别下的物品也会被移除

/sbs category list
显示所有类别，包括其类别名称、显示名称

/sbs item create  [类别] [已连接的scoreboard变量] [价格] [显示名称] [物品描述] [额外属性]
  在类别下创建商品，使用下划线来代替显示名称和介绍中的空格。
[物品类型] [额外属性]:
1. HAND [数量] 从手中创建指定数量的物品
2. Command [显示物品] [指令] 任意指令需斜杠，使用%p%代表玩家名
/sbs item list  [类别]
  列出指定类别下的所有物品

/sbs item remove  [类别] [item id]
  移除指定类别下的物品

/sbs reload
重载插件

/sbs shop
显示scoreboardshop商店
