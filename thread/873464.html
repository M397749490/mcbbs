插件介绍


使用QQ号码绑定 双向验证 需要用户主动向机器人发送验证请求(私聊发送 关键词 支持自定义)获取验证码

确保了QQ号是玩家本人使用 并且不会造成骚扰(骚扰指"无聊玩家"不断获取验证码 主动推送会造成"消息轰炸"效果)

并限制 [申请次数，验证码验证错误次数] 超过4次 24小时后再试(无法更改)

插件安装&配置

下载插件将 verForQQ.jar 放置到/plugins目录下
(下载地址帖子底部)
安装CoolQ 下载CoolQ Java
CoolQ Java SDK By 南荒喵
将com.rligry.verforqq.jar与com.rligry.verforqq.json 放置到 coolq目录/data/app/com.sobte.cqp.jcq/app/ 目录下 重启CoolQ
准备就绪后申请通信密钥

访问网址申请通信密钥(仅有一次申请机会 白屏自行解决)

注意: 申请时请输入正确的QQ号码

将申请到的三个值对应填写到MC插件配置文件

以及CoolQ插件配置文件对应(coolq目录/data/app/com.sobte.cqp.jcq/app/com.rligry.verforqq/Config.ini)处

重启CoolQ 重启CoolQ 重启CoolQ

用刚刚申请密钥的QQ号码向机器人私聊发送"激活"二字 返回"欢迎使用"即代表激活完成
若激活已成功 再次输入会返回 e0 错误码

返回 error-p7 请检查申请的三个参数是否按照要求填写
返回 TCC-02 请先在游戏内申请验证码

MC插件配置文件内的 "msg_s" 只是提示信息 (见效果图图一) 需要自己手动设置
机器人的触发词需要在CoolQ配置文件 "msg_key" 内单独设置!
机器人获取验证码的默认的触发词是 "嘤"

更多错误码 请参阅[错误代码]

如果使用遇到问题 欢迎留言



插件配置文件描述


CCTID - 填写申请到的

key - 填写申请到的

secret - 填写申请到的

groupID - 详见插件效果图1 加群提示信息中显示的群号

verID - 机器人QQ号码 - 详见插件效果图1 设置向哪个QQ号发送私聊 获取验证码

msg_s - 设置机器人触发词 - 详见插件效果图1  Coolq配置文件也需要设置

ver - (MC插件 v1.0.2版本支持此功能) 强制绑定 默认值 true 若要关闭强制绑定填写 false



Coolq插件配置文件描述


CCTID - 填写申请到的

key - 填写申请到的

secret - 填写申请到的

msg_key - 触发词(例: 验证 禁止设置关键词为激活)


插件指令


/verqq [QQ] - 权限 默认 - 获取验证码

/verqq2 [验证码] - 权限 默认 - 绑定验证

/verfindusername [player name] - 权限 OP - 获取该玩家绑定的QQ号码 (有BUG请在评论区反馈)
/verfinduserqq [qq] - 权限 OP - 获取绑定该QQ号码玩家的名称
/verdeleteuserinfo [player name] - 权限 OP - 清除玩家绑定数据



错误代码


(*)由中转服务器返回的错误代码

error-0606 / error1 - 请检查游戏所在操作系统的时间是否滞后*

error3-1 - CCTID没有被注册*

e0717 - 通信密钥没有被激活*

error3 - 提供的密钥验证失败*
