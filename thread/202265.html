整合了自己认为开服比较需要的插件，大部分都是亲手汉化+优化过的
插件列表：
  • AuthPro（登录插件）
  • Coordinates（查看坐标插件 饥饿游戏服推荐使用）
  • ChestLocker（锁箱插件）
  • FurnaceLocker（锁熔炉插件）
  • KillBearBoys（方块记录查询 已优化）
  • PocketHungerGames（饥饿游戏）
  • PocketJobs（职业插件）
  • Portal（传送插件）
  • PrivateAreaProtector（区域保护）
  • SimpleWarp（地标插件）
  • Trust（信任插件）
  • WorldEdit（WE地图编辑）
  • TpMultiWorlds（多世界）
下面是各个插件的使用说明
  • AuthPro

国内大婶编写的登陆插件，和SimpleLogin用法一样，但是比SimpleLogin更节省资源，反应更快！
用法：
/login 密码（登录）
/register 密码（注册）
还有反注册什么的没研究过就不说了=-=
  • Coordinates

用于管理员查询当前的坐标
用法：
/coord
输入后坐标会通过消息的方式显示出来
  • ChestLocker/FurnaceLocker

国内初二大神Rapdoodle编写的插件！快来膜拜...
用于锁箱子和锁熔炉
用法：
/chestlock
/furnacelock
然后点击要上锁的箱子或熔炉 就是这么简单
  • KillBearBoys

国内大神ljyloo的作品，可查询方块放置或破坏的记录
用法：
/co（开启 关闭查询模式）
不过此插件有点吃资源，定时记得删记录
  • PocketHungerGames

让服务器变成一个饥饿游戏服！
a847371462汉化 插件板块有他自己的帖子哦~
用法：
略长...自己去看吧...
  • Portal

很不错的传送门插件，国内ljyloo大神的作品
用法：
1.站在目的地，输入/por target2.站在传送门1点，输入命令/por pos1
3.站在传送门2点，输入命令/por pos2
4.输入命令/por create 传送门名字 <可选参数>(可选参数若填t，则传送门为一次性)
删除传送门：
输入命令 /por delete 传送门名字
  • PrivateAreaProtector
区域保护插件，非常遗憾的是一个世界只能保护一个区域
用法：
1.站在保护区x点，输入/protect pos1
2.站在保护区z点，输入/protect pos2
3.输入/protect 这个区域就被保护了，只有你可以放置或破坏区域内的方块~
如果想删除保护区域的话，就另外创一个区域，原先的保护区域就自动被删除了
  • Trust
信任插件，没有信任名单的玩家不能破坏方块、放置方块
用法：
/trust ID
已知Bug：取消信任时服务器会挂掉= =
  • TpMultiWorlds
更好的多世界插件
用法：
/lw （查看服务器世界列表）
/w 世界名 （传送到世界）
以后还会有更新的哦~用了半个多小时写了这个帖子= =金币人气啥的砸上来
