船的话怎么实现平移？

(甚至可以用龟龟...) 以一个marker为参照物，随marker移动而移动（当然你喜欢的话marker的移动可以用motion代替tp）

execute as @e[tag=marker] at @s run tp @s ~0.1 ~ ~
execute as @e[tag=boat1] at @e[tag=marker] run tp @s ~1 ~1 ~
execute as @e[tag=boat2] at @e[tag=marker] run tp @s ~- ~1 ~
execute as @e[tag=boat3] at @e[tag=marker] run tp @s ~-1 ~1 ~
...
