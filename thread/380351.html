【小白必读】

众所周知，纯净的MINECRAFT PC是不支持中文输入的。

这就在世界名字、告示牌等非常蛋疼。

造成了N多的爱国人士的不满。

虽然有免费的中文输入补丁

但

大部分小白不会用....
下面 我来介绍

如何在没有中文补丁的情况下
输入中文
（在MC中使用复制粘贴）
——————————————————
这里就拿一个古老的1.4.7纯净包举例。

可以看到，无论使用任何输入法都无法输入中文···



这时，打开你电脑里自带的记事本


输入你想要输入的文本信息。

然后，将目光转向键盘。


在键盘上，有3个常用的快捷键。
他们是
Ctrl + X
Ctrl + C
Ctrl + V

Ctrl + X    剪切

Ctrl + C    复制

Ctrl + V    粘贴

将你在记事本上写的文字选中
然后同时按下


回到mc,在没有任何输入法的前提下，同时按下



看那！输入了中文！


附：Ctrl组合快捷键大全作用大全：

  1. Ctrl+A 全选(字体、文件或文件夹)
  2. Ctrl+B 整理收藏夹
  3. Ctrl+C 复制(字体、文件或文件夹)
  4. Ctrl+D 将当前Web页添加到收藏夹
  5. Ctrl+E 打开系统或Internet搜索
  6. Ctrl+F 查找
  7. Ctrl+I 收藏夹
  8. Ctrl+L 打开键入的文档或文件夹的Internet地址
  9. Ctrl+N 新建文件或在新窗口打开当前Web页
  10. Ctrl+O 打开键入的文档或文件夹的Internet地址
  11. Ctrl+P 打印
  12. Ctrl+R 刷新
  13. Ctrl+V 粘贴(字体、文件或文件夹)
  14. Ctrl+X 剪切(字体、文件或文件夹)
  15. Ctrl+Z 撤消(字体、文件或文件夹)
  16. Ctrl+Shift 转换输入法
  17. Ctrl+B 加粗
  18. Ctrl+U 下划线
