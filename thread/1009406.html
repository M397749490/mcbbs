地图简介 Description

基本信息：
  • 游戏人数 1 ~ 无限
  • 游戏版本：Minecraft Java Edtion 1.15.2 或以后
  • 材质包：可选


游戏模式：
  • 竞速模式：用最快的速度冲向终点！
  • 对抗模式：收集道具，在有限的时间内尽可能击杀其他玩家！
  • 特殊模式：淘汰赛，基于以上两种模式，看谁能撑到最后！


赛道：
  • 内置26张竞速地图和7张对抗地图
  • 可高度自定义的地图
  • 在非领域版本中还包含有一个游戏内关卡编辑器


道具：
  • 多达20种道具
  • 4种不同的道具容器
  • 每个道具都有自己的强化版本！


AI：
  • 你可以和由系统控制的僵尸竞速或对抗。他们能够像玩家一样移动，拾取并使用物品，甚至是抄捷径（仅AI难度为高时）。如果你的电脑能处理的过来的话，最多可以设置9个AI！确保在游戏过程中服务器的mstp不超过50ms（TPS保持在20），否则游戏将开始减速并产生异常！
  • 支持根据玩家数量和性能自动调整AI数量！


性能选项:
  • 性能不够强大？在大厅中更改性能设置,启用 [流畅] 性能模式，将主时钟放慢一倍，只会稍微牺牲一些响应速度和视觉效果。减缓服务器压力，获得更好的游戏体验！
  • 关闭AI也可以显著提升流畅性！
  • 智能模式可帮助你完成自动切换时钟速度，完成优化！！（AI需单独设置）



翻译支持
  • 99%的游戏内文本都包含在sprint_racer_language数据包，不需要懂得复杂的指令机制，就可以为游戏创建新的本地化！
  • translate code：6n8f


原文
  • Map supports any number of players (1 to infinity)
  • Played on Minecraft: Java Edition 1.15.2 or later
  • Resource pack is recommended but not necessary (included with world download)
GAMEMODES
Race Mode: Race to the finish on a linear track
Battle Mode: Fight in an open arena for the highest KO count
(both gamemodes also have an "elimination" variant)

TRACKS
26 race tracks, 7 battle arenas.
Map contains an easy-to-use track editor, allowing you to create as many custom race and battle tracks as you like!
(note: track editor is only available in the downloadable version, not in the Minecraft Realms release!)

ITEMS
20 unique items. Every item also has an upgraded "enchanted" variant.

BOTS
You can race or battle against computer-controlled zombies. They move, pick up and use items, take shortcuts, and compete just like a human player can. You can have up to 9 of them... if your computer can handle that! Make sure the server's tick length doesn't exceed 50ms during gameplay, or else the bots will start slowing down.

PERFORMANCE OPTIONS
Computer having trouble keeping up? Visit the sandstone building in the lobby and you can enable [?FASTER] performance mode, which nearly doubles server performance at a slight cost of responsiveness. You can also reduce the number of bots you play against or disable them entirely, also improving performance.

SUPPORT FOR TRANSLATION
Sprint Racer's datapack is organized in such a way that all in-game text elements are in a separate folder, meaning you won't have to dig through mountains of extra code to translate everything. You can easily pop a new "sprint_racer_language" folder into the datapack to change language!
