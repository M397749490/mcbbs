必要前置


一个MySQL数据库即可
如果你没得MySQL数据库的话，这里也许可以给你免费提供

功能&特性
特点：
1.无需任何指令，全自动操作（Fully automatic. (Without any commands)）
2.不可能存在作弊/卡bug（No cheating possible.）
3.不会存在卡崩服的情况（Tolerates server crashes.）
4.同步快速（Asyncronous. (Which means that the server won't lag while loading the invenory)）
5.更新的时候会通知（Update notification.）
6.完全可配置（Full configurable.）
它能同步以下内容：
背包
末影箱
血量
饥饿值
经验值和等级
药水效果
水下剩余空气
剩余燃烧时间
（你可以根据需要在配置文件中关闭/开启某项）
