简短的不能再简短的介绍：
写这个插件的初衷是因为，新周目安装了用于建筑的地形地图，而地图里矿物资源极度丰富……
为了防止地图里的矿物导致服务器经济失衡，写了这个小插件。

功能：
禁止在指定的世界，挖掘指定方块。
可设置，不掉落物品，不掉落经验。或禁止破坏指定方块。


备注：
使用 WorldGuard 可以很好的实现禁止破坏指定方块的设置，但是我在配置时没有发现破坏方块不掉落物品的相关设置。
这个插件可以补充这一点。


配置文件：
  1. # 是否不破坏这个方块，true 是不可破坏，false 是可以破坏
  2. AntiBreak: false
  3. # 是否不掉落物品，true 是掉落物品，false 是不掉落物品
  4. DropItem: false
  5. # 掉落多少经验(使用整数)
  6. DropEXP: 0
  7. # 发送给玩家的信息
  8. AntiMessage: '&6不好意思, 在这个世界挖矿将不会掉落任何物品. '
  9. # 生效的世界，参照自己的世界名
  10. Worlds:
  11. - world
  12. # 生效的方块，可以添加更多的值，然后使用指令更新配置文件
  13. Blocks:
  14. - DIAMOND_ORE
  15. - EMERALD_ORE
  16. - GOLD_ORE
  17. - IRON_ORE
  18. - COAL_ORE
  19. - DIAMOND_BLOCK
  20. - EMERALD_BLOCK
  21. - GOLD_BLOCK
  22. - IRON_BLOCK
  23. - COAL_BLOCK
复制代码
相关权限与指令：
重载插件：/abb reload

使用这条指令需要有权限：antibreakblock.reload
允许在这个世界挖掘指定方块的权限：antibreakblock.allow

这两条权限默认 OP 拥有。
