  1. execute as @a at @s anchored eyes run summon minecraft:evoker_fangs ^ ^ ^1
  2. execute as @a at @s anchored eyes rotated ~ 0 run summon minecraft:evoker_fangs ^ ^ ^1
  3. execute at @a run summon minecraft:evoker_fangs ^ ^ ^1
  4. execute as @a at @s rotated ~ 0 run summon minecraft:evoker_fangs ^ ^ ^1

execute as @p at @s positioned ~ ~1.62 ~ run summon minecraft:evoker_fangs ^ ^ ^1
execute as @e[type=minecraft:evoker_fangs] at @s rotated as @p run tp @s ~ ~ ~（尖牙 rotated 不能用……）
execute as @e[type=minecraft:evoker_fangs] run data modify entity @s Rotation set from entity @p Rotation（ data 可以）
按顺序执行：上面两条：
第一条：召唤一个尖牙
第二条：定尖牙的朝向
