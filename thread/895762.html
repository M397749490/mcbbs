有人可能会说：“不怕，作者不是还写了令一份插件用于高版本的么（这里也许是指BskyBlock）”

对于这种人，我们先跳过，因为我无言以对，不是说ta说得不对，而是我真的觉得无言以对，好，那么接下来我就介绍一下我正在制作的数据包吧






首先，这个数据包里将会有一个添加好友功能（原插件虽然没有，但我觉得有必要做一下）

那么看表面截图之后，就知道这个加好友功能目前是只有添加好友功能的

但是你别看外表光鲜亮丽，可你们实际看一下命令

  1. tag @s add find.success
  2. tellraw @s {"translate":"island.system.function.api.conf","with":[{"entity":"@e[type=armor_stand,limit=1,sort=nearest,tag=test.uid]","nbt":"ArmorItems[0].tag.UIDnew.name","interpret":true},{"translate":"island.system.function.add_friend","clickEvent":{"action":"run_command","value":"/trigger action set 10000"}},{"translate":"island.system.function.cancel","clickEvent":{"action":"run_command","value":"/trigger action set 10001"}}]}
  3. execute at @s as @e[tag=player_store] if score @s UID = @p find_uid run data modify entity @s ArmorItems[0].tag.store_info.store_message[{type:0}].send_message prepend value {type:request,By_uid:0,By_name:""\\u00a7csomeone\\u00a7r"",message:"{"translate":"island.system.message.friend_application","with":[{"selector":"@p"}]}"}
  4. execute at @s as @e[tag=player_store] if score @s UID = @p find_uid store result entity @s ArmorItems[0].tag.store_info.store_message[{type:0}].send_message.By_uid int 1 run scoreboard players get @s UID
  5. execute as @e[type=armor_stand,tag=player_store] if score @s UID = @s UID run tag @s add tem.uid
  6. execute at @s as @e[tag=player_store] if score @s UID = @p find_uid run data modify entity @s ArmorItems[0].tag.store_info.store_message[{type:0}].send_message.By_name set from entity @e[tag=tem.uid,limit=1] ArmorItems[0].tag.store_info.master_info.Name
  7. tag @e remove tem.uid
  8. scoreboard players operation @s store_uid = @s find_uid
