1.配置里有
  1.   # Whether or not to use the action bar
  2.   use-action-bar: 'ture'

  4.   # The text to display on the action bar.
  5.   # Available filters:
  6.   #   {combo}       - the player's current click combo
  7.   #   {class}       - the player's main class name
  8.   #   {level}       - the player's main class level
  9.   #   {exp}         - the player's main class exp
  10.   #   {expReq}      - the player's main class required experience
  11.   #   {expLeft}     - the player's main class experience until the next level
  12.   #   {health}      - the player's current health
  13.   #   {maxHealth}   - the player's max health
  14.   #   {mana}        - the player's current mana
  15.   #   {maxMana}     - the player's max mana
  16.   #   {name}        - the name of the player
  17.   #   {attr}        - the player's attribute points
  18.   #   {sp}          - the player's main class skill points
  19.   #   {value:<key>} - a skill value
  20.   action-bar-text: '{class}/{level} '
复制代码

2.配置里有
  1. Skill Bar:

  3.   # Whether or not to use skill bars
  4.   enabled: 'true'

  6.   # Whether or not to show skill cooldowns in the skill bar
  7.   show-cooldown: 'true'

  9.   # The item to use as a placeholder in the skill bar
  10.   empty-icon:
  11.     material: 'PUMPKIN_SEEDS'
复制代码

3.手持武器用技能槽施法，或者技能绑定在武器上都能继承除了NBT武器攻击力的其他伤害属性，也就是说技能伤害是=技能基础伤害+武器除原版伤害以外的其他伤害。
当然你可以用skillapi的读取武器lore的技能来设置技能伤害与武器伤害成比例，非凡的lore可能特殊一些，有点麻烦的。
