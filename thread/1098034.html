如题，做一个技能+冷却
最好能详细讲解每一步，版本1.12.2
冷却要求那种是物品数量，例如我1号物品栏是个技能，我按了F切换到副手触发技能然后删除，再在1号物品栏放30个屏障，直到刷新
作者: 天佑酱    时间: 2020-8-10 08:33
本帖最后由 天佑酱 于 2020-8-10 15:36 编辑

首先你的技能物品最好要有个标签
比如
give @s web 1 0 {Tags:["SMFX051"]}

再循环高频执行：
scoreboard players tag @a add SMFX050 {Inventory:[{Slot:-106b,id:"minecraft:web",tag:{Tags:["SMFX051"]}}]}这条命令是说如果玩家副手有标签为“SMFX051”的蜘蛛网，则给玩家添加一个“SMFX050”的tag

execute @a[tag=SMFX050] ~ ~ ~ execute @e[r=16,tag=!SMFX050] ~ ~ ~ setblock ~ ~ ~ minecraft:web
这条命令是说如果有玩家标签为SMFX050，则在玩家半径16格内的除那个玩家以外的实体脚下生成一个蜘蛛网

replaceitem entity @a[tag=SMFX050] slot.weapon.offhand air

这条命令是把玩家副手的蜘蛛网清掉

replaceitem entiry @a[tag=SMFX050] slot.hotbar.0 minecraft:barrier 30 0

这条命令是把玩家快捷栏1号位替换为30个屏障

scoreboard players set @a[tag=SMFX050] SMFX052 0
这命令是后面记分用的

scoreboard players tag @a[tag=SMFX050] add SMFX053
这条命令是给玩家一个特殊的tag，方便后续冷却用

scoreboard players tag @a remove SMFX050
这条命令是实时移除玩家的tag，以免技能重复执行



以上是技能主题，接下来说怎么做屏障减少
先创建俩计分板
scoreboard objectives add SMFX052 dummy
scoreboard objectives add SMFX054 dummy

再1gt循环执行以下：
scoreboard players add @a[tag=SMFX053] SMFX052 1
这条命令是一直给计分板加分

execute @a[tag=SMFX053,score_SMFX052_min=20] ~ ~ ~ clear @s barrier -1 1
这条命令是当计分板值到达20(1s)，则清除玩家的一个屏障

scoreboard players add @a[tag=SMFX053,score_SMFX052_min=20] SMFX054 1
这条命令是当计分板数值到达20，则给另一个计分板加一分

scoreboard players set @a[tag=SMFX053,score_SMFX052_min=20] SMFX054 0
这条命令是当计分板数值到达20，则把该计分板清0，以便循环

replaceitem entity @a[tag=SMFX053,score_SMFX054_min=30] slot.hotbar.0 web 1 0 {Tags:["SMFX051"]}
当二号计分板数值达到30（屏障都清没了），则把玩家1号物品栏替换成有技能的蜘蛛网

scoreboard players tag @a[tag=SMFX053,score_SMFX054_min=30] remove SMFX053
scoreboard players reset @a[tag=SMFX053,score_SMFX054_min=30] SMFX054
这两条命令是打杂用的，重置一些东西以便再用
