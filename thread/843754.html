那估计是你这地狱世界没有加入到gm的权限管理里面。我默认你用的是gm。
  1.   mirrors:
  2.         # 多世界设置,世界列表中子世界将参照父世界的设置.
  3.         # 第一个世界 'world' 是主世界名称
  4.         # 子世界 'world_nether' 和 'world_the_end' 将会
  5.         # 与父世界使用相同的玩家/用户组文件.
  6.         # 每个子世界可以设置镜像的 'groups', 'users' 或者与父世界使用一样的设置.
  7.         # all_unnamed_worlds将会使用所有未定义的世界
  8.         world:
  9.           world_nether:
  10.           - users
  11.           - groups
  12.           world_the_end:
  13.           - users
  14.           - groups
  15.           all_unnamed_worlds:
  16.           - users
  17.           - groups
复制代码

主要是最后面的那个，未定义的世界都会继承这个权限方案。
你要不找到地狱世界名字加进去，要不就按照上面这个写，未定义的或被默认继承主世界的。
