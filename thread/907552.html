参照我上一次回复的帖子
plot setup
/plot setup PlotSquared
/plot setup default
/plot setup 地皮高度 设置为64就好了
/plot setup 地皮大小
/plot setup 地皮下面的方块的ID 一般都是泥土 ID为3 如有需求可自定义   [这里指的就是地皮里的第二层往下]
/plot setup 地皮表面方块ID 一般是草方块 ID为2[这里就是第一层也叫表面]
/plot setup 没认领前围墙的ID 默认是44
/plot setup 认领后围墙的ID 默认是44:1 两个应该可以设置相同方块
/plot setup 路面宽
/plot setup 路面高 设置64就可以了
/plot setup 路面的方块 默认是石英块 ID155
/plot setup 墙下面的方块 默认是石头 ID1
/plot setup 墙的高度 一般是64
/plot setup true/false 是否开启基岩
/plot setup dipi   [这里的话随便搞反正不能中文就对了]

我的方法是直接改地皮配置文件,路径是:
\plugins\PlotSquared\config\worlds.yml
打开后:
修改完后,用多世界创建的地皮世界就是你想要的材料了
  1. worlds:
  2.   plotworld:
  3.     plot:
  4.       height: 64
  5.       size: 52#这个是地皮大小
  6.       filling:
  7.       - '3:0'#这个是表面以下的材料ID
  8.       floor:
  9.       - '2:0'#这个就是地皮表面的材料
  10.       bedrock: true
  11.       biome: FOREST
  12.       auto_merge: false
  13.       create_signs: true
  14.     wall:
  15.       block: '44:0'
  16.       block_claimed: '44:0'
  17.       filling: '1:0'
  18.       height: 64
复制代码
