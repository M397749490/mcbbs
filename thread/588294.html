● 米饭 Mod / 飯 Mod（1.14.4）

简单介绍
本帖主要介绍的是对应MC1.7.10/1.8.9的竹/竹和风（下称竹）。竹是一个农业系Mod，之所以称为农业系，我想主要还是因为它是以竹和樱花以及其他农作物为中心展开的Mod。不过竹更倾向为一个综合性质的Mod，内容繁多，包含了建筑装饰、武器工具、家具、多种特殊道具、农作物和多种饮食。
竹是一个非常细致的Mod，里面大部分的道具和方块都有多种多样的特性，猜想也许正是因为如此，MC1.8以上版本对应的竹只有寥寥几种物品，至今未能完全移植（不排除作者没空偷懒等←_←），总之推荐对应MC1.7.10版本的竹才能玩到全部内容。
另有和风（并不是同一个Mod）。与豆腐、枫树、拔刀剑、苹果奶茶2等Mod均有联动。

配置文件（1.7.10）
配置文件位置：\.minecraft\config\BambooConfig.cfg
游戏内亦可直接通过主页Mod菜单进行配置文件的修改，修改重启游戏后生效
  1. # Configuration file

  3. bamboosettings {
  4.     # Add magatama to DunsionChests 地牢箱子是否生成勾玉（勾玉是有各种强力特效的道具）
  5.     B:AddMagatama=false

  7.     # Delude right click max reference （模仿方块相关？）
  8.     I:DeludeMaxRightClickReference=2

  10.     # Delude texture max reference （模仿方块相关？）
  11.     I:DeludeMaxTexReference=2

  13.     # Possible level firecracker explosion 0~3 爆竹的爆炸等级（竹Mod的爆竹很厉害，有必要一定要关闭）
  14.     I:MaxExplosionLv=0

  16.     # Multi-block add block restriction 0:None 1:Creative 2:Creative or OP 3:OP 4:ALLUser
  17.     I:MultiblockRestriction=0

  19.     # The use of UTF-8 encoding if using a 2byte character
  20.     # Used to change only the name of overhead
  21.     # S:Nickname <
  22.     # "name:nickname"
  23.     # "name2:nickname2">
  24.     #  Nickname has none ("name:") to not display name
  25.     S:Nickname <
  26.      >

  28.     # Weed to drop a Sakura and Takenoko(Disabled requires a reboot) 打草掉樱花树苗和竹笋（关闭该效果需要重启游戏）
  29.     B:ReliefItem=false

  31.     # Acceleration time by huton 让Mod里的被褥和原版的床一样可以跳过夜晚
  32.     B:TimeAccel=true

  34.     # Update notification 更新通知（建议关掉，貌似会影响游戏启动速度）
  35.     B:UpdateNotify=false

  37.     # Not melt ice with light 使Mod中的光源不融化冰
  38.     B:UpdateStopIce=false

  40.     # Not melt snow with light 使Mod中的光源不融化雪
  41.     B:UpdateStopSnow=false

  43.     # !!!This item is to erode the terrain greatly!!! 这一项选true的话会更大的侵蚀地形（某勾玉的特殊效果？）
  44.     B:UseMagatama=false

  46.     # EntityWind knock back for EntityPlayer 设置实体风对实体的玩家有效（某勾玉的特殊效果？）
  47.     B:WindPushPlayer=true
