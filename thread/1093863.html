Respawn
重生触发事件

简介
这个插件可以在你死亡的时候触发一些其他的事件

特色
自动重生功能
  • 可以取消掉重生页面
重生后在一定范围内随机传送

权限
权限:
  • respawn.autorespawn.true 开启/关闭自动重生功能的权限
  • respawn.randomspawn.true 开启/关闭随机出生点功能的权限
  • respawn.color 改变提示信息的权限
  • respawn.reload 重载插件的权限


命令
命令：
  • /respawn reload 重载插件
  • /respawn autorespawn 开启/关闭自动重生功能
  • /respawn randomspawn 开启/关闭随机出生点功能
  • /respawn color 改变提示信息颜色



配置文件
  1. config:
  2.   autorespawn:
  3.     open: true
  4.     # 是否开启自动重生功能
  5.   randomspawn:
  6.     open: true
  7.     # 是否开启随机出生点的功能
  8.     range: 100
  9.     # 改变随机出生点的范围
  10.     mode: true
  11.     #true模式是在玩家死亡所在坐标一定范围内传送 false模式是玩家在主世界一定范围内传送
  12.   color: a
  13.   # 改变提示信息的颜色
