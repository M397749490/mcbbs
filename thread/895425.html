如果只要勾住那一下有伤害，这样做
绿色命令方块都是保持开启，中间那个需要条件制约，紫色命令方块保持开启就行

从右到左的指令是
  1. /execute at @e[type=minecraft:fishing_bobber] if entity @e[type=!minecraft:fishing_bobber,type=!minecraft:item,type=!minecraft:arrow,distance=..1.6,tag=!A] run summon minecraft:arrow ~ ~0.7 ~ {Motion:[0d,-0.5d,0d],life: 1198s,Color:-1}
复制代码
  1. /execute at @e[type=minecraft:fishing_bobber] run tag @e[type=!minecraft:fishing_bobber,type=!minecraft:item,type=!minecraft:arrow,distance=..1.6] add A
复制代码
  1. /execute at @e[type=minecraft:fishing_bobber] run tag @e[type=!minecraft:fishing_bobber,type=!minecraft:item,type=!minecraft:arrow,distance=1.6..] remove A
