mod部分截图








筛网分为：筛网，硬化筛网，铁质筛网，钻石筛网，本mod的筛子没有耐久，不会像1.10.2站内搬运的无中生有筛子有耐久，并且本mod的筛子可以附魔

mod使用教程
在安装，启动一次游戏后，mod生成.cfg文件
  1.         B:enableBarrelTransformLighting=true

  3.         # Enable this to to load the JSON files.
  4.         # Keeping this on false will only load recipes registered in code
  5.         # This is recommended to enable for Packmakers
  6.         # For players just playing with this without wanting to configure something this is recommended to keep disabled
  7.         B:enableJSONLoading=false
  8.         B:oredictExNihiloSeeds=true
  9.         B:oredictVanillaItems=true
  10.     }
复制代码
在.minecraft/config/exnihilocreatio/exnihilocreatio.cfg内找到上面的一段把enableJSONLoading=false改为“true”
在默认情况下，它只生成cfg文本，所以需要把它改为“true”
总之在mod的config内的json文本几乎都可以进行修改
