FirstJoinPlus——当玩家第一次加入时

FirstJoinPlus介绍：
FirstJoinPlus能够让你控制玩家加入服务器时的任何一个环节，比如说：给他们一个起始工具包，特殊重生点，经验，或者运行什么指令！但是存在的玩家是不会被告知他们第一次加入这个服务器的！
FirstJoinPlus功能：
  • 新玩家进入服务器时宣布（也可以有总共多少个玩家加入了）
  • 给他们一个起始的资产（可设置）
  • 给玩家们展示起始的提示信息
  • 强制玩家/控制台运行命令
  • 给他们预先设置好的经验值
  • 设置玩家为无敌模式（一段时间内 就像新手保护）
  • 播放一个很酷的特效
  • 播放一个已经设置好的声音，会播放给有"firstjoinplus.notify"权限的玩家
  • 给一个玩家以预先写好的书（支持颜色代码）
  • 以上的所有功能可以被更改或设置！
FirstJoinPlus命令：
指令描述所需权限
/firstjoinplus reload重载插件的设置firstjoinplus.reload
/firstjoinplus setspawn为新玩家设置重生点（可能与其他插件冲突）firstjoinplus.setspawn
/firstjoinplus spawn传送新玩家的重生点（测试用）firstjoinplus.spawn
/firstjoinplus motd显示为新玩家显示设定的信息（测试用）firstjoinplus.motd
/firstjoinplus items给你自己给新玩家的物品（测试用）firstjoinplus.items

命令"/fjp"可以替代"/firstjoinplus"，所有指令权限默认为仅OP拥有

FirstJoinPlus设置：

config.yml

  1. # FirstJoinPlus v1.8 Configuration -- Please see [url]https://github.com/chaseoes/FirstJoinPlus/wiki/Configuration[/url] #

  17.     enabled: true

  19.     - WOOD_PICKAXE

用法解释：
  • first-join-message：设置玩家第一次加入的时候显示的信息，这个插件在任何信息都支持颜色代码
  • teleport-delay：传送玩家到设置好的重生点的延迟（以tick计算）（如果有插件冲突，请将此值设置高一点）
  • notify-sound：向有"firstjoinplus.notify"权限的玩家播放的声音，以下链接为声音列表：http://jd.bukkit.org/rb/apidocs/org/bukkit/Sound.html
  • update-checking：是否检查更新
  • debug：开启此项将会把所有的加入认为是第一次加入（测试用）
  • show-first-join-message：开启或关闭首次加入的信息（true为开启，false为关闭）
  • teleport：是否将玩家传送到firstjoinplus设置的重生点（如果你设置了重生点，将会开启这项）
  • show-smoke：是否在新加入的玩家身上显示烟雾效果
  • play-notify-sound：是否播放提示音
  • launch-firework：在玩家加入服务器时，是否发射艳华？
  • %player-name：可以用在信息内，用来表示玩家名
  • %player-display-name：可以用在信息内，用来表示玩家昵称
  • &unique-players：显示加入服务器玩家的总数
  • &0-9/a-f：所有标准的颜色代码是支持的：http://media-mcw.cursecdn.com/4/4c/Colors.png
FirstJoinPlus权限：
  • firstjoinplus.reload: 使用/firstjoinplus reload的权限
  • firstjoinplus.motd: 使用 /firstjoinplus motd的权限
  • firstjoinplus.setspawn: 使用 /firstjoinplus setspawn 的权限.
  • firstjoinplus.items: 使用 /firstjoinplus items 的权限.
  • firstjoinplus.spawn: 使用 /firstjoinplus spawn 的权限.
  • firstjoinplus.notify: 收到提示音的权限
  • firstjoinplus.notify-update: 收到更新信息的玩家
