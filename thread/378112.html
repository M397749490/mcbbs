箱子锁是LWC还是lockette
是lockette的，打开plugins\Lockette\config.yml
  1. allow-admin-snoop: true
  2. allow-admin-bypass: true    这三个都改true
  3. allow-admin-break: true
复制代码

是LWC的话，同上打开core.yml
  1. opIsLWCAdmin: true    这个改true
复制代码

关于领地的话，打开领地的config.yml
  1. # Setting this to true makes server OPs admins.
  2.     AdminOPs: true    改为true
复制代码
