可能bat自身存在问题
用这个吧：
  1. [url=home.php?mod=space&uid=39305]@echo[/url] off&setlocal enabledelayedexpansion
  2. set a=-1
  3. :ok
  4. set /a a+=1
  5. title [xx服] 重启次数:%a%
  6. color A
  7. set /a s=3+1
  8. for /l %%i in (1,1,!s!) do (
  9. set /a s-=1
  10. ping -n %s% 127.1>nul
  11. echo 倒计时开始！ !s!)
  12. echo 服务器开始运行！
  13. JAVA -Xmx1g -Xms1g -Xmn500M -jar spigot-1.8.8.jar
  14. goto ok
  15. pause
复制代码
把spigot-1.8.8.jar换成你的核心全名（包含.jar）
