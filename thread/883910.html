  1. useWelcomeMessage: true
复制代码

改为
  1. useWelcomeMessage: false
复制代码

如果你是想改变消息的内容，在welcome.txt中修改
一些特殊的提示代码：

  2.     # {PLAYER}: 玩家名称, {ONLINE}: 在线玩家
  3.     # {MAXPLAYERS}: 最大在线玩家, {IP}: 玩家的IP, {LOGINS}: 已登录的玩家
  4.     # {WORLD}: 每个世界的玩家, {SERVER}: 服务器名称
  5.     # {VERSION}: 获取bukkit的版本, {COUNTRY}: 玩家IP所属的国家
