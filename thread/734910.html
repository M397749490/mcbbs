对于json是什么，大家应该也有所理解
mc中的很多地方都使用了json来储存数据

在插件开发过程中，使用json来储存数据也会方便很多
yml有时候可能很好用，但是到了像数据库之类的地方，那就基本上没什么用了

通过反编译mc服务器核心，我们可以发现里面有一个com.google.gson包，里面就有各种关于json的类


JsonObject类就是一个json对象，可以直接调用构造方法进行创建
  1. JsonObject json = new JsonObject();
复制代码
往里面添加数据：
  1. json.add("key", new JsonPrimitive(数据));  //第二个参数需要JsonElement对象，基本数据类型需要使用JsonPrimitive来包装
  2. json.addProperty("key2", "value");  //也可以使用addProperty方法直接添加【跟上面等价】
复制代码

获取数据：
  1. JsonElement value = json.get("key");  //调用get方法就行
  2. System.out.println(value.getAsString());  //可以通过方法转成各种数据类型
  3. System.out.println(value.getAsInt());
  4. System.out.println(value.getAsJsonArray());
复制代码
json数组：
  1. JsonArray jsonArray = new JsonArray();  //也是直接创建
  2. jsonArray.add(new JsonPrimitive("test"));  //添加方法跟JsonObject类似
  3. jsonArray.add(new JsonPrimitive(1));
复制代码

不管是JsonObject、JsonArray还是JsonPrimitive都继承自JsonElement，所以可以像下面这样组合
  1. JsonObject json = new JsonObject();
  2. json.add("key", new JsonPrimitive("测试"));
  3. JsonArray jsonArray = new JsonArray();
  4. jsonArray.add(new JsonPrimitive(1));
  5. json.add("array", jsonArray);
  6. System.out.println(json.toString());
复制代码


然后就是解析json文本：
  1. JsonParser parse = new JsonParser();  //需要JsonParser来解析
  2. JsonObject json = (JsonObject)parse.parse("{"test":"success","list":[1,2,3]}");  //返回一个JsonElement对象
复制代码

另外nbt和json没什么关系，只是实现方法类似
