While循环
从2.0版本开始你就可以使用While循环，只要满足条件，将只保持重复的循环。While的循环格式是这样的:
while <condition>:
        <code>

请注意这种类型的循环，如果条件满足将会一直执行。

第一个问题，不会退出是因为 while 的条件一直成立，对于一个一直 +1s 的数字，用 is set 判断时永远成立，且后面的 stop 只有第一个 if 后面存在有效的 stop ，后面 else 接的 stop 和 while 的缩进在同一个等级，只有前面的 while 执行结束后才会执行，另外， lore's 这个语法直接用的时候，貌似会被解析器转义掉，所以上面的例子里咱稍微改了一下
第二个问题，也许只是 if 末尾没加冒号？
彩蛋发现不管 line 后面填的是多少，获取到的字串永远是全部的 lore，可能这是 v2.1.2 旧版遗留的 bug 吧……
