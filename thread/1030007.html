1、操作计分板      计分板操作计分板基本操作可以参考MaySpeed教程如果有对每个玩家显示特定内容的需求可以对服内每个玩家使用getNewScoreboard()创建专属计分板，并使用player.setScoreboard(刚创建的计分板)，这样每个玩家所看到的计分板内容就不一样了
假设我需要记录玩家的破坏圆石数或击杀僵尸数，并在该数字达到10时将其清零

      以破坏圆石数量为例子，以每个玩家独立计分板、计分板侧边栏Objective名字为name、记录破坏圆石数条目(Entry)名为"已破坏圆石数量"为前提。
流程：监听BlockBreakEvent，判断破坏方块是否为圆石，是则取出事件玩家的计分板，从该计分板中获取名为name的Objective，从该Objective中取出条目名为"已破坏圆石数量"的分数（此处分数是Score对象，而不是数字），给他加一，判断分数是否≥10，是则清零
代码：
  1.         public void onEnable(){
  2.                 // 同样监听PlayerJoinEvent
  3.                 // 以确保对玩家使用getScoreboard非空
  4.                 for(Player p : Bukkit.getOnlinePlayers()) {
  5.                         // 为每个玩家创建新的计分板
  6.                         Scoreboard sb = Bukkit.getScoreboardManager().getNewScoreboard();
  7.                         // 为这个新的计分板创建Objective
  8.                         Objective objective = sb.registerNewObjective("name", "dummy", "侧边栏标题");
  9.                         // 让Objective显示在右侧
  10.                         objective.setDisplaySlot(DisplaySlot.SIDEBAR);
  11.                         // 初始化(非必须)
  12.                         // spigot已经处理过了，objective.getScore(String)所得分数不会是null
  13.                         // 若条目原先不存在于Objective
  14.                         // 使用getScore()所得分数将为0
  15.                         objective.getScore("已破坏圆石数量").setScore(0);
  16.                         // 向玩家展示计分板
  17.                         p.setScoreboard(sb);
  18.                         info(sb);
  19.                 }
  20.                 getServer().getPluginManager().registerEvents(this, this);
  21.         }
  22.         
  23.         @EventHandler
  24.         public void onBlockBreak(BlockBreakEvent e) {
  25.                 // 判断破坏方块是否为圆石
  26.                 if(e.getBlock().getType().equals(Material.COBBLESTONE)) {
  27.                         // 获取玩家独有计分板
  28.                         Scoreboard sb = e.getPlayer().getScoreboard();
  29.                         // 获取名为name的Objective
  30.                         Objective objective = sb.getObjective("name");
  31.                         // 获取名为"已破坏圆石数量"的分数
  32.                         Score score_stone = objective.getScore("已破坏圆石数量");
  33.                         // 设置分数为原有分数+1
  34.                         score_stone.setScore(score_stone.getScore() + 1);
  35.                         // 分数是否达到了10
  36.                         if(score_stone.getScore() >= 10) {
  37.                                 // 清零
  38.                                 score_stone.setScore(0);
  39.                                 // Do sth
  40.                         }
  41.                 }
  42.         }

3、处理死亡掉落物品
      可以关闭原生掉落，自己新建掉落体系
也可以对getDrops()进行操作，把不应该掉落的物品移出getDrops()，并存起来，1tick后重新给予玩家
  1.         @EventHandler
  2.         public void onPlayerDeath(PlayerDeathEvent e) {
  3.                 List<ItemStack> toSave = new ArrayList();
  4.                 for(ItemStack item : e.getDrops()) {
  5.                         if(保存条件) {
  6.                                 toSave.add(item);
  7.                         }
  8.                 }
  9.                 for(ItemStack item : toSave) {
  10.                         e.getDrops().remove(item);
  11.                 }
  12.                 new BukkitRunnable() {
  13.                         public void run() {
  14.                                 for(ItemStack item : toSave) {
  15.                                         e.getEntity().getInventory().addItem(item);
  16.                                 }
  17.                         }
  18.                 }.runTaskLater(this, 1);
  19.         }

4、控制玩家的复活      要控制玩家的复活，一种是直接在玩家死亡事件中调用player.spigot().respawn()，然后设置玩家的游戏模式，这种方法无需调用NMS，但如果要限制玩家的行动会比较麻烦。
      另一种是让玩家无法点击死亡界面的重生。由于死亡界面是由客户端控制的，因此我们需要使用到NMS发包，并用一点trick：玩家死亡后，重生按钮有1秒时长是无法按下的，在这期间，向玩家发送复活包+死亡包，此时玩家的重生按钮将一直是灰的。
代码示例(使用spigot-1.14.4):
  1.         // 多少tick后使玩家重生
  2.         private static final int RESPAWN_AFTER = 100;
  3.         // 多少tick重新发一次包
  4.         private static final int PACKET_SEND_PERIOD = 10;
  5.         
  6.         @EventHandler
  7.         public void onPlayerDeath(PlayerDeathEvent e) {
  8.                 new BukkitRunnable() {
  9.                         int i = 0;
  10.                         public void run() {
  11.                                 if(i++ > RESPAWN_AFTER / PACKET_SEND_PERIOD) {
  12.                                         e.getEntity().spigot().respawn();
  13.                                         this.cancel();
  14.                                 }else {
  15.                                         sendRespawnPacket(e.getEntity());
  16.                                         sendDeadPacket(e.getEntity());
  17.                                 }
  18.                         }
  19.                 }.runTaskTimer(this, PACKET_SEND_PERIOD, PACKET_SEND_PERIOD);
  20.         }

  22.         private void sendPacket(Player p, Packet packet){
  23.                 ((CraftPlayer) p).getHandle().playerConnection.sendPacket(packet);
  24.         }
  25.         
  26.         private EntityPlayer getHandle(Player player) {
  27.                 return ((CraftPlayer)player).getHandle();
  28.         }
  29.         
  30.         public void sendDeadPacket(Player p) {
  31.                 sendPacket(p, new PacketPlayOutCombatEvent(getHandle(p).getCombatTracker(), EnumCombatEventType.ENTITY_DIED));
  32.         }
  33.         
  34.         public void sendRespawnPacket(Player p) {
  35.                 sendPacket(p, new PacketPlayOutRespawn(getHandle(p).dimension, getHandle(p).getWorld().getWorldData().getType(), EnumGamemode.SURVIVAL));
  36.         }
