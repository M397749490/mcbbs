Features/特點

  • Arena vote function with GUI/投票選場地！
  • Own chests blocks/獨自的箱子！不用再和別人搶一個QAQ
  • Deathmatch function/決戰競技場！省的到處亂跑
  • Spectator Mode/旁觀者模式
  • Configurable Scoreboard/自定義計分板
  • Configurable Messages/自定義信息
  • Automaticly start and map-reset/自動開始、重置地圖
  • Unlimited game lobbys with unlimited arenas/自動使用沒有在遊戲中的場地！
  • Multiverse support/支持跨服插件！
  • Seperate chat (in-game and global)/旁觀者私聊！防止熊孩子告訴情報！
Commands
指令介紹權限
/sg                                                      列出全部指令/
/sg start開始一個遊戲sg.start
/sg join <LOBBYNAME>加入一個遊戲sg.join
/sg leave退出一個遊戲sg.join
/sg vote <ARENAID>為場地投票sg.join
/sg list列出所有可以使用的場地sg.list
/sg lobby顯示大廳幫助sg.lobby
/sg lobby create <NAME>創建一個遊戲sg.lobby
/sg lobby setspawn <NAME>為遊戲設置出生點sg.lobby
/sg lobby unload <NAME>禁用場地sg.lobby
/sg lobby load <NAME>恢復場地sg.lobby
/sg lobby reload <NAME>重載某場地sg.lobby
/sg lobby list <NAME>列出所有可用場地sg.lobby
/sg lobby delete <NAME>刪除一個場地sg.lobby
/sg arena create <LOBBYNAME> <ARENA NAME>將大廳和遊戲連接在一起sg.arena
/sg arena tools給你一個區域選擇工具sg.arena
/sg arena select <LOBBYNAME> <ARENA NAME>選擇大廳和遊戲連接在一起的地點sg.arena
/sg arena check檢查是否完成場地建設sg.arena
/sg arena addspawn在場地內添加出生點sg.arena
/sg arena removespawn <ID>在場地內移除出生點sg.arena
/sg arena deathmatch開始/結束一個場地內的最終決鬥！sg.arena
/sg arena deathmatch add為最終決鬥添加一個出生點sg.arena
/sg arena deathmatch remove <ID>將最終決鬥的出生點移除sg.arena
/sg arena finish強制結束遊戲sg.arena




Plugin update checking、Plugin Statistics/插件更新、數據統計
  • The plugin connects automaticly to curse (while enabling) , to inform you when a new update is available. If you don't want this, set the option "enable-update-check" in the config.yml of the SurvivalGames folder to false.
  • 如果要更新到最新版本，直接把舊版本的插件刪除，裝上新的便可
  • The plugins sends automaticly statistic informations like current player amount, java version, etc. to http://mcstats.org/! If you don't want this, set the option "opt-out" in the config.yml of the PluginMetrics folder to true.
  • 可在插件配置文件中獲取玩家遊戲信息
