强化插件的属性过于单一？
强化等级的上限不能够按附魔类型分别设置？
那么也许使用这款插件来代替是一个更好的选择！
（将会在后续的版本添加更具特色的强化能力！）
（包括成功率在内，许多参数可自由调节~！）

【傻瓜式强化】是的，就是这么简单！
打开背包，右击强化物品，你会发现它消耗了一个
然后，只要再右击你需要强化的物品，就可以将强化物品上的附魔和强化附加到物品上啦

【一键融合】我发动这张魔法卡！
手持着强化物品右键，当你数量足够，你就可以获得一个更高等级的强化物品！例如原本是锋利I的强化物品，就可以升级到锋利II~
*注：本插件理论上可以应用于大多数大于1.6.4且支持bukkit插件的服务端，但是只在1.7.10的thermos端和1.12.2的spigot上进行过测试
*如果遇到bug，请反馈至wby27_2006@126.com
命令

/readyupgrade 与 /rup等价
/rup give [玩家] 给予玩家（省略时为自己）1个未附加任何强化的强化物品
/rup enchant [玩家] <附魔> <等级> 给玩家（省略时为自己）手中物品附魔（建议使用其他方式附魔而不是本插件的附魔，这里仅仅提供一个备用指令，无视原版附魔等级上限）
/rup help 查看指令帮助
/rup version 查看插件版本信息
/rup reload 重载插件（配置和语言文件）


权限节点

readyupgrade.apply 使用强化物品进行强化的权限（建议给予玩家）
readyupgrade.merge 融合强化物品的权限（建议给予玩家）
readyupgrade.give 获取未附加任何强化的强化物品的权限
readyupgrade.enchant 使用附魔指令的权限
readyupgrade.admin 管理员权限，进行重载以及查看版本需要此权限


配置文件
开始你的配置~（重载后生效）
config.yml

#不要动，配置自动保存默认为关闭，且没有开启的必要
auto-save: 0
#语言文件（默认为zh_CN，此时语言文件为zh_CN.yml），你可以在该文件内更改显示的信息
lang: zh_CN
#融合所需的强化物品个数
merge:
  amount: 3
#强化物品的显示样式
item:
  default:
    ==: org.bukkit.inventory.ItemStack
    type: EMERALD
    meta:
      ==: ItemMeta
      meta-type: UNSPECIFIC
      display-name: §r§a升级石
      lore:
      - §r§e在背包中右击该物品，然后右击目标物品以附魔
      - §r§e手持时右键将消耗一定数量融合成更高级的升级
#附魔类强化的相关设置
ench:
#设置为true关闭原版所不允许的附魔类型（例如在玻璃上附魔保护）（这个设置只与附魔类型有关，与附魔等级无关）
  vanilla-only: false
#默认设置（当某个附魔没有进行特殊设置时将使用默认设置）
  default:
#允许的最高附魔等级（0为不限制，-1为使用原版限制）
    max-level: 0
    chance:
#融合时的成功率=(base-factor*(附魔等级-1))*1%，每个附魔分别计算成功率，融合失败时，融合所得的附魔物品的对应附魔等级将不会增加
#默认为必定成功
      merge:
        base: 100
        factor: 0
#强化时的成功率=(base-factor*(附魔等级-1))*1%，每个附魔分别计算成功率，强化失败时，对应附魔将会尝试降低一级的强化
#再次失败重复此步，直至成功或0级强化，默认为必定成功
#附魔的强化会覆盖原有的强化
      apply:
        base: 100
        factor: 0
#这个位置往下将会是自动生成的附魔的个别设置项，格式与默认项完全一致
#其中最高等级将以默认设置和个别设置中的最小值为准，成功率将以个别设置为准
