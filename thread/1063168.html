想自己通过这个设置一个材质，但是怎么写都没法成功，也遇到了物品完全不显示的问题。所以想寻找一个普通的拓展材质包来自行研究一下，并且想照着模板刻印几份= =...。


希望一个懂材质的大佬能使用这张图片，制作一个物品，CustomModelData值为1001，代替的原版物品是碗 bowl
只需要直接通过这个图片制作只有这一个物品的材质包就行。
完成后zip格式直接上传到帖子里...

bowl的json文件
assets/minecraft/models/item/bowl.json
  1. {
  2.     "parent": "item/generated",
  3.     "textures": {
  4.         "layer0": "item/bowl"
  5.     },
  6.         "overrides": [
  7.                 { "predicate": { "custom_model_data": 1001 }, "model": "minecraft:custom/boow"}
  8.         ]
  9. }
复制代码


然后boow.json，assets/minecraft/models/custom/boow.json，内容如下
  1. {
  2.     "parent": "item/generated",
  3.     "textures": {
  4.         "layer0": "custom/boooow"
  5.     }
  6. }
复制代码



最后boooow.png的贴图文件，assets/minecraft/textures/custom/boooow.png
