第二篇：重要！如何使用BPS补丁
IMPORTANT: HOW TO APPLY BPS PATCHES
                                                                        
In order to install a Cauldron bps patch you will require the following :

  • Maeyanie's Cauldron 1.7.10 198 server installer or 1.6.4 204 server installer.
  • SpigotPatcher or any other tool that supports bps patching.
  • A cauldron bps patch

To Apply a BPS patch do the following :

  • Launch your bps patcher.
  • Choose "cauldron-1.7.10-1.1207.01.198-installer.jar" for original input
  • Choose the bps patch you downloaded above for patch
  • Output as any filename you wish

Enjoy!

Note: you will receive an odd FML error as shown here
https://github.com/MinecraftForge/FML/issues/519

This is not a Cauldron issue and will be fixed soon in FML so just ignore it

重要！如何使用BPS补丁
安装一个Cauldron的BPS补丁，你需要准备如下的东西：
  • Maeyanie的Cauldron 1.7.10 198 服务端安装器 或 1.6.4 204 服务器安装器
  • SpigotPatcher 或其他任何支持BPS的工具
  • 一个Cauldron的BPS补丁


应用一个BPS补丁需要你完成如下步骤：
  • 打开你的BPS工具
  • 选择"cauldron-1.7.10-1.1207.01.198-installer.jar" 作为 original input
  • 选择你上面已经下载的BPS补丁
  • 你可以自己设定输出的文件名


享受吧！
注：你会收到一个如下的奇怪的FML错误 （GITHUB）
这不是一个Cauldron的问题并且将会在今后被修复，所以你可以无视这个错误。
