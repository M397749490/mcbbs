简介
这个插件可以控制建造下界和末地传送门的权限

  • 支持多世界
  • 支持权限管理
  • 自动监测、删除传送门
  • 可以禁用末影之眼以禁用末地传送门
  • OP或者有权限的玩家可以创建传送门


指令

无

权限

权限节点必须是小写

  1. noportals.<worldname>.allow  允许在某世界创建传送门
复制代码


配置

  1. watchdog: false #是否开启自动监测
  2. destroyer: false #检测到传送门是否自动破坏，这个功能必须打开Watchdog才可用
  3. stopEnder: false #是否禁用末地传送门
  4. toggleCustomMessage: false #是否显示自定义消息
  5. customMessage: 你没有开启传送门的权限 #自定义无法创建传送门时的消息
复制代码


已有传送门的服务器请在打开WatchDog之前重新创建所有允许的传送门，使插件将它们添加到可信列表中。
