         Auction是一款Sponge的拍卖插件,一次只允许1个用户拍卖一个物品，它不会导致聊天栏被它刷屏，而是以另一种形式显示出来。

指令与权限
  • /auc start  <价钱>开始拍卖与在手的项目（权限：auction.start）
  • /auc cancel 取消拍卖（权限：auction.cancel）
  • /auc show   显示在拍卖的物品（权限：auction.show）
  • /bid [price]对正在拍卖的物品出价（权限：auction.bid）


使用方法
拿着要拍卖的物品输入/auc start 价钱即可
