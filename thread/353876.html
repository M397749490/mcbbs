你装了几个经济插件？
作者: Smaoll    时间: 2014-10-17 23:07
请楼主找到Ess插件配置目录中的config.yml文件打开
然后改动，找到一行currency-symbol: 改成你想要的货币名，以下为汉化配置供参考
  1. ############################################################
  2. # +------------------------------------------------------+ #
  3. # |               Essentials 经济设置                    | #
  4. # +------------------------------------------------------+ #
  5. ############################################################

  7. # 查看更多信息,请访问 http://wiki.ess3.net/wiki/Essentials_Economy

  9. # 设置玩家第一次登录服务器时拥有的金钱,默认为0.
  10. starting-balance: 400

  12. # worth-# 定义物品的价格,用来使玩家输入"/sell"后,以这种价格将物品卖给服务器.
  13. # 现在该项设置的文件是worth.yml

  15. # 定义玩家每次使用命令时所要花的钱,空格由"-"代替,带有"example"的是例子.
  16. # 一些命令例如/repair拥有独立的花费,可以在essentials wiki查看更多信息
  17. command-costs:
  18.   # /example costs $1000 PER USE
  19.   #example: 1000
  20.   # /kit tools costs $1500 PER USE
  21.   #kit-tools: 1500

  23. # 设置该项为一个你想使用的货币符号(译注:货币符号(双字节)有"￥"、"＄"、"￠"和"￡"等).
  24. currency-symbol: '金'

  26. # 设置一个玩家所允许拥有的最大钱数.
  27. # 这个数量最大为10万亿(1个1,13个0),这是由于JAVA的限制.
  28. max-money: 100000000000

  30. # 设置一个玩家所允许拥有的最小钱数 (必须大于最大金额的负数).
  31. # 设置为0,将完全禁用透支/贷款.用户需要'essentials.eco.loan"权限,钱数才能低于0.
  32. min-money: 0

  34. # 设置为true来记录所有玩家的交易记录(译注,仅记录Essentials所支持的交易命令和功能).
  35. economy-log-enabled: false
