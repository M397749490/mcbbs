插件名：植物大战僵尸

插件英文名：Plants Vs.Zombies

-------------------------------------------------------------------------------------------------------

这个插件的简介：

“来自作者”，mcdarc翻译

介绍到这个插件

[size=107.7%]Plants vs. Zombies is the minecraft version of the popular iOS and Android (and pc, xbox, everything.....) game. This version of PvZ strives to resemble the original game while still having the fun of minecraft! This means that some modifications had to be made. The plugin is simple for both admins and players. It is fully customizable through custom messages and an extensive, but easy-to-use configuration. Perhaps the best part is that Plants vs. Zombies is fun with almost any number of players. If you want the game to start after only 2 players join, you can do that, and if you would like a different plants to zombies ratio, that's also configurable!
[size=107.7%]本插件是一个MC版本的“植物大战僵尸”。我们可以利用这个来在MC中弄许多小游戏。这代表了他可以被高度自定义。这个插件对于每一个管理员都十分简单。他可以高度地被自定义通过自定义消息和伤害。但是它很容易配置。你可以随便配置成什么样。

-------------------------------------------------------------------------------------------------------

如何使用这个插件

这个插件件使用很简单！

首先是安装的教程：

1.下载这个的jar文件

2.用ftp上传工具进入你的服务器ftp空间

3.找到plugins这个文件夹

4.把这个文件扔进去

5.重启服务器/重载本插件

6.没了

然后是这个插件怎么使用！

1.玩家使用 /pvz join 指令进入竞技场

2.要不同的植物或僵尸类型，可以使用 /pvz type 指令

3.游戏一开始他们就会被传送到 植物/僵尸 出生地（这取决于他们的队伍）

4.植物队伍尽力阻止僵尸的攻击（180秒后若僵尸未攻入植物最后一行则植物胜）

5.没了

插件特点

1.允许改变许多配置（我看了下，够你头晕的了）

2.允许多个竞技场

3.内置范围选取工具（无需创世神）

4.轻松设置场地

5.有不同种类的植物与僵尸（他们都有不同的使用限权与技能）——VIP服务器的福星

6.胜利有烟花---

7.好看的计分牌（让你知道还需支持多少时间/还有多少植物）

8.没了

关于bug反馈

我还是折叠下吧
“作者欢迎各位去原帖反馈bug”


-------------------------------------------------------------------------------------------------------

最重要的——命令！

玩家命令

命令 作用
/pvz join 让玩家加入一个竞技场
/pvz leave 让玩家离开一个竞技场
/pvz type让玩家选择一个类型（队伍）
管理员（op）命令

命令作用
/pvz wand 选择你的竞技场范围
/pvz create 竞技场名字 创建一个竞技场，范围为你用wand命令选择的范围
/pvz add 农场名创建一个植物养殖场（原帖是这样说的···）
/pvz setspawn 农场名 行序 zombie或plant 设置出生地
/pvz endpoint <farm> <row>设置一个终点（僵尸攻入哪才会赢）

最最重要的限权设置

  • pvz.wand - 给予使用 /pvz wand 的限权
  • pvz.create - 给予使用 /pvz create 的限权
  • pvz.add - 给予使用 /pvz add 的限权
  • pvz.setspawn - 给予使用 /pvz setspawn 的限权
  • pvz.endpoint - 给予使用 /pvz endpoint 的限权
  • pvz.join - 给予使用 /pvz join 的限权
  • pvz.leave -给予使用 /pvz leave 的限权
  • pvz.type - 给予使用 /pvz type 的限权
队伍设置限权

  • pvz.peashooter - 成为一个豌豆射手
  • pvz.repeater - 成为一个火炬树？
  • pvz.basic - 成为一个普通僵尸
  • pvz.conehead - 成为一个雪糕筒僵尸
  • pvz.gargantuar - 成为僵尸博士
