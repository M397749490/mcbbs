炮塔
这里是Kingdoms中现有炮塔的信息。
箭头塔楼

以适中速度发射的炮塔。射出正常的箭，造成中度伤害。对中等装甲单个目标强大
火焰炮塔
一座快速发射的炮塔。射出设定目标的箭头，但造成较小的伤害。对轻度装甲和中等的目标伤害效果。

治疗站
周期性地治疗周围的王国成员。可堆叠效果

灵能图腾
用强大的灵能打击对周围的非盟友玩家造成伤害。严重减缓目标，同时造成3点无视护甲伤害。

地狱火炮塔
一个强大的快速火力炮塔，可以在远距离发射双箭头。箭塔的高度改进版本，具有两倍的伤害和攻击速度，以及更远的射程。对于中等数量的重型装甲目标有强大作用

僵尸士兵
一个塔楼，可以召唤不死族保卫你的领土。定期召唤僵尸士兵的目标。可以通过墙壁召唤。不瞄准非玩家。非常强大的武器可怜的目标。

TNT
一击就可以击中多个敌人，但一次只能瞄准一个敌人。对范围内的目标造成持续伤害。对中度装甲的玩家和暴徒强大，如果目标在伤害范围内，对钻石甲可以造成高额伤害

征服
征服是一个基本上允许玩家在虚拟土地上战斗的王国“迷你游戏”。 玩家可以为他们的虚拟土地购买防御，这些土地每小时提供资源点。

指令
  1. / k（显示所有命令）
  2. / k nexus（允许你放置地面上的国王核心GUI 核心！！。）
  3. / k info（显示Kingdoms如何工作）
  4. / k join[王国]（用于加入另一个王国，必须被邀请。）
  5. / k create[王国]（用于创建一个名称与王国。）kingdoms.create
  6. / k claim（用于声明你所站在的土地，成本5个资源点，奖励5可能）
  7. / k unclaim（用于取消你的一块土地，退还5个资源点，但扣除5个可能）
  8. / k invade（当你站在不属于你的王国的土地上时使用，花费10点资源来挑战他们的王国，如果你赢了，你获得土地，5个可能）
  9. / k show[王国]（显示特定王国的审查信息，不显示他们的盟友和敌人）
  10. / k show（显示你自己的信息，显示盟友和敌人）
  11. / k king [player]（将王国的领导权传递给另一位，将你变成一个国防部，并将该玩家变为国王）
  12. / k mod [player]（Mods一个在你王国中的玩家）
  13. / k demote[玩家]（在你的王国Unmods模组）
  14. / k kick [player]（强行从你的王国中移除一名玩家）
  15. / k invint[玩家]（邀请玩家到你的王国）
  16. / k accept（接受邀请）
  17. / k decline（拒绝邀请）
  18. / k sethome（设置王国家）
  19. / k home（如果王国仍然有效，则不会被索赔等）
  20. / k leave（离开你现在的王国）
  21. / k ally add/remove[王国/玩家名称]（盟军另一个王国）
  22. / k enemy add/remove[王国/玩家名称]（敌人另一个王国）
  23. / k map[开/关]（显示周边地区）权限：kingdoms.map
  24. / k donate[王国] [金额]（捐赠给另一个王国）
  25. / k chat[k，a，p]（更改聊天设置）
  26. / k tradable（显示可以和不可以交易资源点的项目）
  27. / k top（根据资源点显示前10位最富有的王国）
  28. / k admmin（显示管理员命令）
  29. / k admin toggle切换管理模式，允许你摧毁，放置和攻击任何领地
  30. / k admin safezone（声明safezone补丁）
  31. / k  admin warzone（声称一个warzone补丁）
  32. / k  admin safezone（如果有土地，强行解除非联系部分）
  33. / k admin rp [kingdom] [amount]（从王国增加/减去金额，减去负数，加上正数）。
  34. / k admin masswar [时间（分钟）]（在指定的时间内开始一场群体大战。）
  35. / k admin forcestopmasswar（迫使正在进行的群众大战停止）
  36. / k admin seenexus [王国]（打开指定王国的GUI）
  37. / k admin backup（创建当前kingdoms数据库文件的备份）
  38. / k admin import<mysql / file> SQL导入
