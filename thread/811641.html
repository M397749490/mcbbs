（我这方法大概是 data driven，很不 MC

创建一个记分项
/scoreboard objectives add choice dummy

高频以下命令(把 X Y Z 都换成你的牌子的绝对坐标)
/execute positioned X Y Z if score $X_Y_Z choice matches 1 unless block ~ ~ ~ minecraft:sign{Text1:"{\"text\":\"> 第一行 <\"}"} run setblock ~ ~ ~ minecraft:sign{Text1:"{\"text\":\"> 第一行 <}",Text2:"{\"text\":\"第二行,\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/scoreboard players set $X_Y_Z choice 2\"}}",Text3:"{\"text\":\"第三行}",Text4:"{\"text\":\"第四行}"}

/execute positioned X Y Z if score $X_Y_Z choice matches 2 unless block ~ ~ ~ minecraft:sign{Text2:"{\"text\":\"> 第二行 <\"}"} run setblock ~ ~ ~ minecraft:sign{Text1:"{\"text\":\"第一行,\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/scoreboard players set $X_Y_Z choice 3\"}}",Text2:"{\"text\":\"> 第二行 <}",Text3:"{\"text\":\"第三行}",Text4:"{\"text\":\"第四行}"}

/execute positioned X Y Z if score $X_Y_Z choice matches 3 unless block ~ ~ ~ minecraft:sign{Text3:"{\"text\":\"> 第三行 <\"}"} run setblock ~ ~ ~ minecraft:sign{Text1:"{\"text\":\"第一行,\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/scoreboard players set $X_Y_Z choice 4\"}}",Text2:"{\"text\":\"第二行}",Text3:"{\"text\":\"> 第三行 <}",Text4:"{\"text\":\"第四行}"}

/execute positioned X Y Z if score $X_Y_Z choice matches 4 unless block ~ ~ ~ minecraft:sign{Text4:"{\"text\":\"> 第四行 <\"}"} run setblock ~ ~ ~ minecraft:sign{Text1:"{\"text\":\"第一行,\"clickEvent\":{\"action\":\"run_command\",\"value\":\"/scoreboard players set $X_Y_Z choice 1\"}}",Text2:"{\"text\":\"第二行}",Text3:"{\"text\":\"第三行}",Text4:"{\"text\":\"> 第四行 <}"}

$X_Y_Z 的 choice 分数，就是当前选择的行数。根据这个分数，决定使用哪个地图。
