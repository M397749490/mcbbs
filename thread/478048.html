标题: bufftool 属性工具 的自定义属性制作方法
简而言之，打开buffedtools.cfg
然后你会看到

# Configuration file

"BT:Effect:Durable" {
    S:color=a
    S:dataArray=||durability:0.25
    S:name=耐用的
}

#################…………

而你要做的
就是复制
"BT:Effect:Durable" {
    S:color=a
    S:dataArray=||durability:0.25
    S:name=耐用的
}
然后粘贴，再改个名字
比如：

"BT:Effect:Durable" {
    S:color=a
    S:dataArray=||durability:0.25
    S:name=耐用的
}


"BT:Effect:Durable2" {
    S:color=9
    S:dataArray=||durability:0.35
    S:name=强固的
}

这样就增加了一个名字“强固的”耐久+35%的新属性

然后关于属性的颜色

8, 灰色
f, 白色
a, 绿色
2, 深绿
9, 蓝色
d, 紫色
e, 黄色
6, 橙色
b, 淡青色
3, 青色
c, 红色
4, 深红

← ←天生不善分辨颜色，反正就是这么个稀有度排行
一共有5个属性可以加
damage 伤害
speed 速度
durability 耐久
crit 致命
invulTime ????

但是invulTime这个属性我在原版里没看到，也不知道是什么效果，于是决定忽略

那么对于单个属性多个效果的写法

"BT:Effect:007" {
    S:color=e
    S:dataArray=||damage:0.40||crit:0.25||durability:0.15||speed:0.05
    S:name=传奇的
}

就是这样
↓_↑另外似乎，颜色决定出现的概率
我感觉a到9这个范围是出的最多的，8比较少，其他的更少
