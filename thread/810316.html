介绍：
本插件可以展示自定义信息栏内容。由PetteriM1制作

使用：
将本插件丢进服务端plugins文件夹内，重新启动服务器即可。没有任何命令与权限

配置：
config.yml
  1. #自定义显示信息
  2. Message: XHud
  3. #支持的变量:
  4. # <NAME> 玩家名
  5. # <WORLD> 世界名称
  6. # <X> X坐标
  7. # <Y> Y坐标
  8. # <Z> Z坐标
  9. # <N> 换行
  10. # <PLAYERS> 在线玩家数
  11. # <MAXPLAYERS> 最大玩家数
  12. # <PING> 玩家的延迟
  13. # <TPS> 服务器TPS
  14. # <FNAME> 玩家的公会名
  15. # <MONEY> 玩家钱数 （需要经济前置）
