指令&权限

以下所有report都可替换rpt
/report  打开GUI举报菜单 - report.basic.report
/report <玩家> <原因>  使用指令举报玩家 - report.basic.report
/reportadmin 查看所有玩家举报的信息 - report.admin.preview
/reportadmin reload 重载插件 - report.admin.reload
/reportadmin [页码] 打开指定页数的举报信息菜单 - report.admin.preview
/reportadmin ban <玩家> 封禁玩家 - report.admin.ban
/reportadmin mute <玩家> 禁言玩家 - report.admin.mute
/reportadmin tp <玩家> 封禁玩家 - report.admin.tp
/reportadmin kick <玩家> 踢出玩家 - report.admin.kick
/reportadmin ignore <玩家> 忽略该玩家的被举报信息 - report.admin.ignore

配置文件

  1. MySQL:
  2.   switch: false
  3.   #mysql的开关(false则使用yml文件存储)
  4.   host: localhost
  5.   #mysql的ip
  6.   port: 3306
  7.   #mysql的端口
  8.   user: minecraft
  9.   #mysql的用户名
  10.   password: root
  11.   #mysql的密码
  12.   database: minecraft
  13.   #mysql的数据库名称
  14.   SSL: false
  15.   #是否启用SSl连接mysql
  16. debug: true
  17. #往控制台输出更多信息
  18. mute: []
  19. #禁言列表
  20. mutecommand:
  21. - /m
  22. - /msg
  23. #禁言时禁止使用的命令，必须添加"/"
  24. times: 10
  25. #Matrix被检测多少次会被踢出,小于0则不会踢出
  26. Matrix: false
  27. #是否启用Matrix反作弊
