Debian 8[Linux]开服教程
您的回复是我最大的动力

为什么选择Linux
占用资源低，安全性高，系统稳定（主要是省钱...）

需要准备什么
一台装有Debian 8的Linux服务器
一个服务端（教程使用的是PaperSpigot）
一个SSH终端软件（用来管理服务器，比如Putty，或者Xshell）
一个传输文件的SFTP软件（我使用的是WinSCP）
以及一个搜索引擎!!

教程开始
给你的服务器安装Java 8
在以下两个版本里选择一个安装即可
Oracle JDK
安装Oracle JDK
  1. sudo apt-get install software-properties-common
复制代码
系统将提示你确认安装，请输入 y 并回车，然后输入以下命令
  1. sudo add-apt-repository "deb http://ppa.launchpad.net/webupd8team/java/ubuntu xenial main"
复制代码
然后更新
  1. sudo apt-get update
复制代码
更新完成后，输入以下命令安装 Oracle JDK 8
  1. sudo apt-get install oracle-java8-installer
复制代码
系统将提示你确认安装，输入 y 并回车
您还需要接受Oracle二进制代码许可条款。 使用箭头键选择“是”，然后按“Enter”接受许可证。

Open JDK
安装Open JDK并没有Oracle JDK复杂，只需要两行代码就能搞定
首先更新
  1. sudo apt-get update
复制代码
然后使用以下命令安装Open JDK
  1. sudo apt-get install default-jdk
复制代码
如果你想安装JRE而不安装JDK的话，请使用以下命令
  1. sudo apt-get install default-jre
复制代码

JDK包含了JRE，安装JDK 除了体积比JRE大之外，并没有其他缺点。

下载服务端
先给你的服务器建一个文件夹，然后下载服务端在文件夹里
输入以下命令创建一个名为mc的文件夹
  1. mkdir mc
复制代码
然后进入这个文件夹
  1. cd mc
复制代码
下载PaperSpigot 1.12纯净端
  1. https://ci.destroystokyo.com/job/PaperSpigot/1169/artifact/paperclip-1169.jar
复制代码
建一个启动文件
  1. vi start.sh
复制代码
输入这条命令后，终端会变成一个空的文本，这里使用的是vim文本编辑器
按下 i 进入文本编辑模式，并且把以下内容 输入到里面
  1. java -Xms512M -Xmx1024M -jar paperclip*.jar
复制代码
这里Xms指的是最小内存 Xmx指的是最大内存
paperclip*.jar指的是服务端文件（在Windows里它需要输入全称才能识别）
输入完内容后，按下ESC退出编辑模式，然后输入 :wq 保存并关闭文件
一定要先按 ESC 退出编辑模式，再输入 :wq 保存并关闭

接下来，输入以下命令启动服务器
  1. sh start.sh
复制代码

可能会遇到的问题
初次启动启动的过程中，无法启动
PaperSpigot初次启动，会有一个Download original jar的过程，国内的服务器可能会卡在这一步
这里我准备了一个处理好的PaperSpigot服务端，下载后将他传输到服务器里（通过WinSCP，或者是导出直链wget）
下载地址：https://pan.baidu.com/s/1hr9ILeO
这是一个tar.gz压缩包，下载完成后需要输入以下命令解压
  1. tar zxvf PaperSpigot.tar.gz
复制代码
他将解压出一个PaperSpigot的文件夹，进入文件夹并执行start.sh文件即可
这个端我并没有将更改eula.txt所以再下载后还需要自行把eula.txt

提示：java not found
这个的意思是指你没有安装Java，请回到上方安装Java

关闭终端后，服务器停止


这里需要使用screen，再Debian里他是默认安装了的，其他Linux如CentOS是需要自行安装
新建一个名为mc的screen
  1. screen -S mc
复制代码
然后在进入的窗口里运行服务器
如果你想离开screen，请将Ctrl+A+D三个键一起按下
想重新进入已创建的screen，输入以下命令
  1. screen -r mc
复制代码
这样，你关闭中断后服务器也不会停止

一些其他的设置
改eula.txt
打开eula.txt
  1. vi eula.txt
复制代码
将eula=false改为eula=true
保存退出文件即可

关闭正版登陆
打开server.properties
  1. vi server.properties
复制代码
找到这一行
  1. online-mode=true
复制代码
将true改为false，保存并退出即可

启用命令方块
打开server.properties
  1. vi server.properties
复制代码
找到这一行
  1. enable-command-block=false
复制代码
将false改为true，保存并退出即可

关于serever.properties的文件里的几个参数
  1. #下界传送门是否生效
  2. allow-nether=true
  3. #游戏难度
  4. difficulty=1
  5. #是否生成怪物
  6. spawn-monsters=true
  7. #OP权限等级，推荐设置3
  8. op-permission-level=4
  9. #大概设置为false就不能互相伤♂害了吧
  10. pvp=true
  11. #是否开启命令方块
  12. enable-command-block=false
  13. #服务器人数上限
  14. max-players=20
  15. #服务器端口
  16. server-port=25565
  17. #是否生成村民
  18. spawn-npcs=true
  19. #服务器视距，数值范围3-15
  20. view-distance=10
  21. #是否生成动物
  22. spawn-animals=true
  23. #白名单
  24. white-list=false
  25. #正版验证
  26. online-mode=true
  27. #最高建筑高度
  28. max-build-height=256
复制代码
