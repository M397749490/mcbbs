以上是我遇到的，然后在MCBBS上搜了一下，的确发现有服主遇到了这类问题，但是回答均是“请删除存档”，之后我在多次测试后发现解决办法

当你看到以下提示：
Run the command /fml confirm or or /fml cancel to proceed.
Alternatively start the server with -Dfml.queryResult=confirm or -Dfml.queryResult=cancel to preselect the answer.
请直接输入/fml confirm，之后回车
然后服务端会删除你这一个区块文件内的缺少的物品，并备份你的存档，然后读取下一个区块
之后你会再次遇到这个提示，同理
直到你的区块都修改完成为止

也就是说如果你有10个区块文件，你就要输入10次

对于已经开了一段时间的服务器（区块会非常多）来说，是一个噩梦，但是如果想保住存档，这是唯一的办法

（如果是win客户端开服的话可以善用上箭头来显示出你的上一条命令，然后回车就好，linux的话善用鼠标右键的粘贴功能吧）
