功能介绍

这个插件让守卫者长老成为像凋零和末影龙那样的BOSS。只能在水下的海底神殿中找到长老守卫者。
他们有更多的血量和像凋零、末影龙一样的BOSSBAR血量条，他们会掉落随机附魔的剑或装备，你可以改变掉落的自定义战利品。
他们也可以召唤普通守卫者。他们的攻击还会附带药水效果，默认是剧毒和反胃。
药水效果、掉落物、血量、显示名称都是可配置的。



命令

/ egb reload < - 重新加载Config

/ egb spawn < - 生成一个长老守卫Boss

/ egb loot< - 获取一个战利品。




权限

使用reload和spawn命令的权限：egb.cmds




安装使用方式

1.将插件放入插件文件夹中重启服务器。


2.编辑配置内容。


3. 使用 /egb reload 重新加载插件
