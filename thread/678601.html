大家好

我是章鱼
我是一位来自香港程式设计师。今天来介绍一下广播插件
我们常看到网站的广告，用户可以点击广告进入连结等
Minecraft里的广播就和现实一样，用于提醒玩家和其他类似信息

网站总是可以互动但minecraft为什么不行？

众所周知，Ｍinecraft有一个插件叫Announcement。
但它的广播字句不能与玩家互动。例如伺服主主持一个活动
并需要进行宣传。玩家可以很容易地透过点击字句进入活动埸地。

现时的公告插件便不能这样做。


TouchNotice有什么不同？

TouchNotice可以使您的广播与玩家互动。
玩家可以使用鼠标指向字句知道更多的细节或点击运行命令

容易!!

一种写广播的新方法: XML
明显的对比度！

鼠标指向字句了解命令详细信息


也可以在後台上运行


Command
/Notice list - 获取广播列表
/Notice add {Text} - 添加.
/Notice remove <Index> - 删除广播列表中指定位置的元素
/Notice delay <秒> - 设置发出广播的秒数。
/Notice broadcast <索引> - 手动广播消息。
/Notice say {Text} - 手动广播一次性消息。
/Notice reload - 重新加载插件。

用法



正常
以下有同样的效果

使用命令: /Notice add <p>&eHi &a{player}&e, how are you?</p>


使用命令: /Notice add <p>&eHi &a{player}</p><p>&e, how are you?</p>

连结网站
打开URL网站链接，接受“http”和“https”协议。

标签：
  • open_url
  • openurl
  • url

示例: <p url="http://google.com">点击我去Google</p>
运行指令
以点击者身份自动运行指令。

标签：
  • run_command
  • runcommand
  • rc

示例: <p rc="/stop">单击我停止伺服器</p>
替换输入栏
将玩家的当前输入栏替换为值中的文本。

标签：
  • suggest_command
  • suggestcommand
  • sc

示例: <p sc="/kick {player}">点击我踢随自己</p>
更改页面(少用)
与书籍一起使用，切换到值中指定的页面。 如果页码不存在，则不会发生。

标签：
  • change_page
  • changepage
  • cp

提示文字
使用鼠标指向字句显示文本提示。

标签：
  • show_text
  • showtext
  • st


示例: <p st="我是 {player}">我的名字是什么？</p>
显示成就(少用)
使用鼠标指向字句显示成并名称

标签：
  • show_achievement
  • showachievement
  • sa

显示物品(高阶)
使用鼠标指向字句显示一个物品的资讯表
需输入物品JSON值，启用工具（F3 + H）显示物品NBT有助你制作资讯。

标签：
  • show_Item
  • showItem
  • si

显示实体(高阶)
使用鼠标指向字句显示实体名称，需输入实体UUID。
启用工具（F3 + H）。才能查看实体UUID

标签：
  • show_entity
  • showentity
  • se
