授权搬运




插件介绍

玩家可以通过聊天栏点击接受/拒绝传送





插件指令&权限

插件指令

/tpa <player> - 传送指令
/tpaccept - 同意传送
/tpadeny - 拒绝传送
/tpo <player> - 强制传送至玩家
/tpohere <player> - 强制传送玩家至你这里

插件权限

clicktpa.tpdeny - 使用 '/tpadeny' 指令
clicktpa.tpaccept - 使用 '/tpaccept' 指令
clicktpa.tpa - 使用 '/tpa' 指令
clicktpa.tpo - 使用 '/tpo' 指令
clicktpa.tpohere - 使用 '/tpohere' 指令
