标题: 1.15.2execute检测区域玩家脚下方块
直接上指令，玩家在半径25的区域内踩到barrier(屏障方块)，就会把触发事件的玩家tp到~ ~ ~，我要做多人地图，1.15.2
作者: ⊙u⊙    时间: 2020-4-1 20:33
execute positioned 0.5 0.5 0.5 as @a[distance=..25] at @s if block ~ ~-0.1 ~ minecraft:barrier run tp @s ~ ~ ~

作者: Y制杖杖    时间: 2020-4-2 06:54
/execute as @a[distance=..25] at @s if block ~ ~-1 ~ minecraft:barrier run tp @s <x> <y> <z>
在球心放置循环命令方块并执行以上命令（<x>，<y>，<z>为命令方块坐标）
如果使用函数，则可以：
/execute positioned <x> <y> <z> align xyz as @a[distance=..25] at @s if block ~ ~-1 ~ minecraft:barrier run tp @s <x> <y> <z>
