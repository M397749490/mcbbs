好久没来插件版做客咯。




这是shenmegui嘞？

这是一款能够让你右键下界之星就可以回到你之前设置家的地方的插件。

作者制作初衷只是因为玩家觉得输入/home很麻烦。*不想吐槽什么了
**右键等于/home的下界之星下文中我简略成H星！



神奇的地方：
这个插件可以配置材质(默认下界之星)，冷却时间，显示名称和描述
等很多神奇的配置。*有兴趣的朋友可以去原帖看，很多东西都可以配置哟~



指令&权限：
/homestar reload重载插件
/homestar status显示配置设置
/homestar give <玩家ID> [数量]给玩家H星

权限说明默认拥有
homestar.use使用权限.都有
homestar.admin使用插件指令的权限:op
homestar.give给H星的权限.op
homestar.reload重载权限.op
homestar.status显示配置设置权限.op
实在太懒，就直接bukkit页面复制过来。



配置文件
  1. # This is the config file for HomeStar plugin v1.0别管

  3. # localized language support语言文件
  4. language: en-US

  6. # Note: use only one enabled/disabled list, and comment out or remove the other启用世界
  7. # enabled worlds list (use this list for a default-deny world policy)
  8. #enabled-worlds:
  9. #  - enabled_world1
  10. #  - enabled_world2

  12. # disabled worlds list (use this list for a default-allow world policy)禁用世界
  13. disabled-worlds:
  14.   - disabled_world1
  15.   - disabled_world2

  17. # material to be used as homestar item. Set item data using a colon, example: WOOL:5材质
  18. # invalid item data may be reset, so use only valid item data values for a given material
  19. item-material: NETHER_STAR

  21. # minimum distance from destination目的地最小距离
  22. minimum-distance: 10

  24. # cooldown time in seconds冷却时间(秒)
  25. teleport-cooldown: 60

  27. # warmup time in seconds传送时间（秒）
  28. teleport-warmup: 5

  30. # particle effects during warmup粒子效果
  31. particle-effects: true

  33. # allow left-click to use左键使用(true开启)
  34. left-click: false

  36. # require shift-click to use homestar item(是否需要按shift键才能使用)
  37. shift-click: true

  39. # remove item from inventory ( on-use使用后 | on-success使用成功后 | never从不 )使用后是否删除
  40. remove-from-inventory: on-use

  42. # allow homestar items to be used in crafting recipes能否合成出来
  43. allow-in-recipes: false

  45. # cancel teleport if player takes damage如果玩家受到伤害取消传送
  46. cancel-on-damage: false

  48. # cancel teleport if player moves如果玩家移动取消传送
  49. cancel-on-movement: false

  51. # cancel teleport if player interacts with another block如果玩家与方块互动。取消传送
  52. cancel-on-interaction: false

  54. # maximum number of homestar items that can be given at once (-1 for no limit)一次最多能给几个H星（默认无限制）
  55. max-give-amount: -1

  57. # lightning strike at destination on use在目的地雷击。。什么鬼
  58. lightning: true

  60. # write log entry on use使用时写入log
  61. log-use: true
