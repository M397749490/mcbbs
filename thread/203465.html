标题: 禁止主城有怪
怎么设置主城保护地区没有怪出现？如果不能设置 请问怎么弄才能是主城保护区没有怪呢？
作者: wjwrh    时间: 2013-12-8 11:23
你可以使用领地插件  把主城圈地  并且输入 用 /resadmin create spawn来圈地
然后输入 /resadmin set spawn monster false
就可以防止怪物生成了
