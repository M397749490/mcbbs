你听说过sunAPI包吗？你知道怎么使用吗？今天我就来讲讲，部分关于sunAPI的内容的使用。
首先，sunAPI是仅限甲骨文提供的JDK及JRE才会有的，而且据说会在jre9移除部分功能(?)，但可以确认的是,sun.misc.Unsafe这个类在将来会加入正式API
使用sunAPI前请确定你自己有一定的编程及信息学知识基础，有一些东西可能会造成不安全的后果，sun.misc.Unsafe是个典型的栗子
我刚刚就讲到sunAPI是只有甲骨文提供的JVM才有的，所以还是有一定的平台限制的，在插件开发中这一缺点体现的并不显著


在使用sunAPI包之前，请确认你的IDE设置完善，否则可能会出现编译错误，我们使用的是eclipse
那么我就来讲讲eclipse需要先设置的东西
首先右击你的工程，打开首选项(一般情况下在菜单的最低端，如果你看不懂英文的话)


接下来:
1.展开Java Compiler选项
2.点击Errors/Warnings
3.找到Deprecated and restricted API菜单并展开
4.将Forbidden reference和Discouraged reference设置成Ignored或Warning，这里建议使用Warning

设置完成！

看起来眼花缭乱，但是真的有用的其实没有几个。
他们两个的区别就在于Player只可以一次播放一个数据流，而Device可以播放多个。
注意啦！这个播放器对音乐文件格式是有要求的，目前已知的一定可以播放的是WAVE格式，即.wav后缀的媒体文件
这个InputStream不是你随便扔个Stream进去就可以播放的
我们需要上面的AudioStream

AudioStream的使用非常方便，就像我们平时使用的IOStream一样，只要把你的InputStream作为构造函数的参数传入就可以啦。
just like this:
  1. AudioStream stream = new AudioStream(yourInputStream);
复制代码
然后关于AudioData，这个也是用来播放音乐的媒体介质，与Stream不同，他是直接将媒体数据存储在这个对象中的
获取它有两种途径
1.就是直接构造，把你的媒体数据直接作为构造参数传入，类型是byte[] 字节数组
2.通过stream获取，AudioStream中有一个方法是getData，就像这样:
  1. AudioData data = audioStream.getData();
复制代码
但是……但是播放只能用InputStream呀！QAQ
不要担心，还有AudioDataStream这个类呢，相同地，直接把AudioData对象直接作为构造参数传入就可以创建这个对象了。
关于ContinuousAudioDataStream的解释很简单，而且用这个类就可以做到循环洗脑辣！（雾：循环播放才对嘛233）


不过要注意的是，如果你是文件数据流，或者是很大的媒体数据，使用getData一定会抛出IOException的，
这里的getData的前提是数据大小不大于1024*1024，即1MB


接下来就是一个实例：
  1. import java.io.*;
  2. import sun.audio.*;

  4. public class Player {
  5.   public static void main(String[] args) throws IOException
  6.   {
  7.     Player player = new Player(args[0], true); // 开启循环洗脑！
  8.     player.play();
  9.   }
  10.   
  11.   Player(String filename, boolean cycle) throws IOException
  12.   {
  13.     AudioStream as = this.as = new AudioStream(new FileInputStream(new File(filename)));
  14.     if(as.getLength() > 1048576) //太大啦不行啦qwq,不能洗脑啦
  15.       ads = as;
  16.     else
  17.       ads = cycle ? new ContinuousAudioDataStream(as.getData()) : new AudioDataStream(as.getData());
  18.   }

  20.   public void play()
  21.   {
  22.   AudioPlayer.player.start(ads);
  23.   //AudioDevice.device.openChannel(ads);也可以喔
  24.   }

  26.   public void close() throws IOException
  27.   {
  28.   as.close();
  29.   }

  31.   AudioStream as;

  33.   InputStream ads;
  34. }
