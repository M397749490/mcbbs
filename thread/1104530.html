作者: IhaveBB    时间: 2020-8-18 13:27
Residence领地插件
res create设置一个区域。
然后设置权限，
res set 【领地名】move f  
res set 【领地名】tp f
如果想单独给玩家进入权限输入指令
/res pset 【领地名】【玩家名】move t
/res pset 【领地名】【玩家名】tp t
