Climatic Biomes 2——气候生物群系2

这是一个添加了更多生物群系的模组，

但它不只是添加了生物群系，

也不只是添加了地形，

更是充足了你的世界。






介绍

本mod完全取代了原本的辣鸡地图生成器
使用了一个十分真实的地图生成系统
避免了原本地图生成生物群系的单调与重复
让你的世界更加具有多样性



特点

1·添加了长河生物群系
2·添加了松叶等方块
3·添加了新型树木:松树
松树林
4·添加了灌木丛



如何启用mod？
将世界类型调为:气候

Changed marsh colors.

A few minor tweak.

修改了沼泽的颜色和一些BUG

2.13.2
Fixed config typo that (for some reason) caused Montane Forest to generate as the Void biome.

2019-08-06
2.13.3
Climate Variations for most biome types can now be turned off in the config.

Clay (x8) blocks can now be crafted from 4 dirt, 4 volcanic ash, and a bucket of water. (Because, why not? It should have some use.)

Tweaks to basalt: Basalt is now more resistant to explosions, and polished basalt is slighltly lighter.

现在可以在配置文件中选择启用哪些生物群系
黏土块(x8)可以由4个泥土，4个volcanic ash方块(个人认为应该译为火山泥块)，和一桶水制造

2019-08-07
2.13.4
Mountain variants now have there own config to enable / disble.

Volcanoes can now be turned off.

More correct handling of tropical forests areas without forest variants (now mixes in jungles).

山脉生物群系现在有了独特的配置文件来启用/关闭
火山可以变成死火山了
更好的处理了热带森林群系与原版群系的关系（现在可以在丛林生物群系中生成）

2019-08-12
2.13.6
Fixes a major bug where negative continent coords were read as one more than they should be; this cause duplicates of the spawn continent to appear immediately to the north, west, and northwest.

(Warning: This moves northern / western land by a full continent.  Installing this on an existing world will cause ugly cliffs / walls to appears in northern / western continents that are partially explored.)

2019-08-23
2.14.1
The Very GUI Update:


There is now a GUI where several key settings can be assigned when creating a world

There include biome size, map scale, generation mode, forcing whole biome, adding extra islands, adding extra beach.

This is available for all new worlds.

When re-creating a world from an old save, these setting still start as default for now, and can be modified fro there.

The more important settings are now saved per world; most notable size info

These can come from the GUI, but for existing worlds they will come from the config;

Existing worlds must be loaded once with the correct values in the config to get their permanent settings.

重大的GUI更新
现在生成世界时有多个选项来选择，生物群系尺寸大小，生成方式，地图大小，添加额外岛屿与沙滩
这些对新存档生效

旧存档可以在配置文件中修改

修复了2.14.2/2.14.3版本使存档保存失效的恶性bug，如果你是2.14.2/2.14.3版本，务必更新到这个版本！
