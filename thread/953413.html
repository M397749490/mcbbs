安装了 res 的话，设置 config.yml 中

    Flow:
      # 这是限制水和岩浆流动时高度的设置
      # 这个选项不会限制领地内水和岩浆的高度
      Level: 63
      # 如果设置为true, 则会限制岩浆流动的高度
      NoLavaFlow: true
      # 如果设置为true, 则会限制水流动的高度
      NoWaterFlow: true
