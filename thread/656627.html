------------------------------------------------





  • 支持自定义加入/退出/踢出信息
  • 支持加入命令
  • 支持加入后进行聊天栏清屏
  • 支持标题显示
  • 支持登录效果、音效
  • 支持插件重载
  • 支持加入Motd
  • 支持多种变量
  • 支持设置一切信息



/bmj - 显示插件帮助
/bmjmotd - 显示Motd
/bmjreload - 重载插件配置



BMJoin.use - 可发送闪电/音效
BMJoin.admin - 管理员权限



  1. #============#
  2. #   BMJoin   #
  3. # 作者:Yuhiy #
  4. #  版本v1.5  #
  5. #============#
  6. #%player_name% 变量显示玩家真实名字
  7. #%player_displayname% 变量显示玩家名字
  8. #%server_version% 变量显示服务器的版本
  9. #%server_bukkitversion% 变量显示服务器的Bukkit版本
  10. #%players% 变量显示玩家在线人数
  11. #%reason% 变量显示被踢出服务器原因
  12. #=============
  13. #BMJoin.use 权限为登录可出现闪电和音效
  14. #=============
  15. #/bmj 为查看插件帮助信息
  16. #/bmjreload 为重载指令
  17. #=============
  18. #基础信息 设置
  19. #=============
  20. #加入信息
  21. JoinMessage: "&8[&b&lBMJoin&8] &6玩家 &f&l%player_name% &6进入了服务器"
  22. #退出信息
  23. QuitMessage: "&8[&b&lBMJoin&8] &6玩家 &f&l%player_name% &6离开了服务器"
  24. #踢出信息
  25. KickMessage: "&8[&b&lBMJoin&8] &6玩家 &f&l%player_name% &6踢出了服务器"
  26. #=============
  27. #加入Motd 设置
  28. #=============
  29. Motd:
  30.   #是否开启Motd
  31.   enable: true
  32.   #Motd信息
  33.   Message:
  34.   - '&a&l欢迎进入本服务器'
  35.   - '&a&l这个是本服务器的Motd'
  36.   - '&6&l玩家名字：&f&l%player_name%'
  37.   - '&6&l服务器版本：&f&l%server_version%'
  38. #=============
  39. #标题显示 设置
  40. #=============
  41. Title:
  42.   #是否开启加入信息标题显示
  43.   enable: true
  44.   #主标题
  45.   Message: '欢迎来到本服务器'
  46.   #副标题
  47.   SubMessage: '&a&l玩家：%player_name%'
  48. #=============
  49. #加入命令 设置
  50. #=============
  51. JoinCommands:
  52.   #是否开启加入输入命令
  53.   enable: true
  54.   #命令
  55.   Commands: me 我加入了游戏
  56. #=============
  57. #插件重载 设置
  58. #=============
  59. #插件重载后聊天栏信息
  60. ReloadMessage: '&8[&b&lBMJoin&8] &a&l插件重载成功'
  61. #插件重载后标题信息
  62. ReloadTitle: '&a&l插件重载成功'
  63. #=============
  64. #登录音效 设置
  65. #=============
  66. #音效名字
  67. #必须为音效名字
  68. #音效可以在 https://docs.windit.net/Chinese_BukkitAPI/org/bukkit/Sound.html 找到
  69. Sound: ENTITY_SHEEP_AMBIENT
复制代码



%player_name% - 显示玩家真实名字
%player_displayname% - 显示玩家名字
%server_version% - 显示服务器的版本
%server_bukkitversion%  - 显示服务器的Bukkit版本
%players% - 显示玩家在线人数
%reason - 显示被踢出服务器原因
