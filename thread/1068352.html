作者: 落星雨    时间: 2020-6-26 22:21
先说问题，这些在 javadoc 中你都能找到答案
Vault http://milkbowl.github.io/VaultA ... conomy/Economy.html
通过方法名你就知道哪个是获取了
net.milkbowl.vault.economy#getBalance(org.bukkit.OfflinePlayer player)

YamlConfiguration https://bukkit.windit.net/javado ... lConfiguration.html
它继承了 FileConfiguration 所以你可以先调用 set(java.lang.String path, java.lang.Object value)
这是用来设置配置文件内容的
然后你可以调用 save(java.io.File file) 将其保存到你指定的 File 对象中。

其实很多东西没必要问，学会看文档可以解决你大部分 "how to" 的问题
就比如 Java 里有 javadoc 这个神奇的玩意，基本上你能做到的都在 javadoc，比如对一个 Player 进行操作，那么你可以到侧栏展开所有类，在所有类中 ctrl+F 搜 Player, 然后你就知道在 Player 身上你能干嘛了, 配置文件也同理。
甚至如果你啥都不知道，点击最上方的索引，你能看到所有方法和类的描述和用法，在那里 ctrl+F 搜索你想要的操作的描述或者方法名。比如想知道配置文件，在汉化版的 javadoc 里，直接搜索 "配置文件"，就出来了 XD
