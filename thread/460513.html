作者: z272191619    时间: 2015-6-28 00:40
服务端文件夹/plugins/Multiverse-Core/worlds.yml
#世界名
  tangguoxingqiu:
    spawning:
      ==: MVSpawnSettings
#动物
      animals:
        ==: MVSpawnSubSettings
        spawn: 'false'
        spawnrate: '1'
        exceptions: []
#怪物
      monsters:
        ==: MVSpawnSubSettings
        spawn: 'false'
        spawnrate: '-1'
        exceptions: []

作者: 拉普达    时间: 2015-6-28 01:01
去所在世界输入指令：
/gamerule doMobSpawning false 这个是关闭刷友好生物
/mv modify set difficulty 0 这个是设置和平模式（这样怪物就不会出现了）
清理所有生物指令
/ mv purge all
