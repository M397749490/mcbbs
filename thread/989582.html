在MinecraftForge.ORE_GEN_BUS注册OreGenEvent.GenerateMinable事件
然后会传入World Random和说是BlockPos其实是ChunkPos的pos然后可以直接使用net.minecraft.world.gen.feature.WorldGenMinable也可以自己处理
不过为了防止bug
x和z最好按这样写:

                int posX = pos.getX() + rand.nextInt(16);
                int posZ = pos.getZ() + rand.nextInt(16);

也可以在放置方块时传入18的flag(不清楚,翻源码看到的)
