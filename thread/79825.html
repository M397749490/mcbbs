配置文件
配置文件是.minecraft/config文件夹下的mod_crystalWing.cfg文件，用记事本打开。
  • #MLProperties: name (type:default) min:max -- information（翻译：mod读取特性：名称（类型：默认）最小：最大——信息）
  • #MLProp : idBurningWing (int:3101)（翻译：mod读取特性：燃烧之翼的物品id（整数：3101））
  • #MLProp : teleDistance (int:500) -- Maximum distance for the Burned Wing teleportation.（翻译：mod读取特性：远程距离（整数：500）——瞬移之翼传送的最大距离。）
  • #**ONLY EDIT WHAT IS BELOW THIS**（翻译：只有编辑什么是下面这个）
  • #MLProp : uses (int:8) -- Number of Crystal Wing uses. Set to 0 for infinite.（翻译：mod读取特性：使用（整数：8）——水晶之翼使用次数。无限集0。）
  • #MLProp : idCrystalWing (int:3100)（翻译：mod读取特性：水晶之翼的物品id（整数：3101））
  • #MLProp : idBurnedWing (int:3102)（翻译：mod读取特性：瞬移之翼的物品id（整数：3101））
  • #MLProp : allowUpdateCheck (boolean:true) -- Set to true to allow checking for mod updates, false to disable（翻译：mod读取特性：允许更新检查（是否：true）——设置为true允许检查模型更新，false禁用）
