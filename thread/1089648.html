Custom Ore Generator 『1.8 - 1.16.1』 自定义矿石生成器
经过测试的Minecraft版本：1.16


插件介绍

     Custom Ore Generator 插件可以帮助你在我的世界存档中生成每一个在Minecraft中可以想象到的方块
（除了这类方块，比如水和熔岩）作为你的Minecraft世界中的矿石。

       这个插件不仅可以自定义矿物的种类，还可以自定义矿脉形状，比如说，你可以自定义一条从地表
延伸至基岩的根状矿脉。通过数值的调整，你可以做出各种不同样子的矿脉。

特点
不同类型的方块生成器和区块生成限制

• 一般矿石生成器 Vanilla minablegenerator
VANILLA_MINABLE_GENERATOR是Minecraft的默认矿石生成器。像煤一样，各种各样的铁矿石。。。
生成的形状是一个椭球体，它绕着它的轴随机旋转。
它只有一个设置：
VEIN_SIZE: 控制产生的矿石量，也就是单个矿脉的大小。默认值为0
注：它也可以产生较小的矿脉。如果将矿脉大小设置为1或2这样的小数值，
则根本不会生成矿石。在这种情况下，使用SINGLE_ORE_GENERATOR

• 类萤石生成器     Glow stone generator
GLOW_STONE_GENERATOR（萤石生成器）可以在下届产生类似萤石一样的矿物。
有6个设置：
POSITIVE_VERTICAL_SCOPE：从第一个选定的方块开始向上生成的高度。默认值为0
NEGATIVE_VERTICAL_SCOPE：只在负方向与正垂直范围相同。默认值为12
HORIZONTAL_SCOPE：从中心方块开始，它应该在x和z轴上分布多少方块。默认值为8
POSITIVE_TRIES：它应该多长时间在正的垂直范围内生成一个方块。默认值为0
NEGATIVE_TRIES：与正面相同，只适用于负纵向范围。默认值为1500

• 根状矿脉生成器   Root generator
ROOT_GENERATOR
可以生成多个向下延伸的根状矿脉。(指的是根茎状矿脉）
他有十个设置：
ROOT_LENGTH: 单个根的长度。默认值为0
CONTINUE_CHANGE：创建新根茎时的做出的改变。默认值为0
CONTINUE_TRIES：每个方块尝试更新的频率。默认值为0
MINIMUM_LENGTH_SUBTRACTION：从ROOT_LENGTH减去最小值。默认值为0
LENGTH_SUBTRACTION_RANGE：ROOT_LENGTH额外缩短的范围。默认值为0
MINIMUM_CHANGE_SUBTRACTION: 从CONTINUE_CHANGE中减去的最小值。。默认值为0
CHANGE_SUBTRACTION_RANGE：CONTINUE_CHANGE的范围进一步缩短。默认值为0
MINIMUM_TRIES_SUBTRACTION：从CONTINUE_TRIES中减去的最小值。默认值为0
TRIES_SUBTRACTION_RANGE：CONTINUE_TRIES的范围将额外缩短。默认值为0
DOWN_CHANGE：根茎向下的变化。默认值为0 。

配置方法

1.15以上版本输入/oregen create 可以打开创建新建矿石规则Gui
（GUI步骤详细，目前英文，我会尽快进行汉化）

1.15以下版本

步骤1：创建一个新的OreConfig
要创建自定义矿石，您必须首先创建一个新的OreConfig，可以使用命令oregen create <name> <material> [<ore-generator>] [<block-selector>]
Variables：
name：：Ore配置的名称，该名称只能包含以下字符az，AZ，0-9，-和_。该名称用作种子参数。
material：应生成的方块
ore-generator：应使用哪个生成器（默认vanilla minable generator）。
block-selector：应该使用哪个区块限制器，默认count range区块限制器。

第2步：设置替换材料
创建新的矿石配置后，必须设置要在其上生成矿石的材料。这是替换的典型材料（Overworld：石头，End：末地石，Nether：地狱岩）。要设置替换材料，请使用以下命令：/oregen set replace-material <ore-config> <material> ...

步骤3：设定值
现在，你必须设置矿石配置的设置，此设置取决于您选择的矿石生成器和区块限制器。您可以在此处找到设置列表。
要设置此设置，可以使用以下命令 /oregen set value <ore-config> <setting> <value>

第4步：将矿石配置添加到世界在最后一步，您必须将创建的ore-config添加到世界。您可以使用以下命令执行此操作：/oregen add ore-config <world> <ore-config> [<position>]

自定义数据
Customdata
使用自定义数据功能，您可以在生方块时为其设置额外的数据。可以通过以下命令设置自定义数据值：
/oregen setcustomdata<ore config><customdata><value>。并非每个自定义数据都与矿石配置的材料兼容。
您可以在自定义数据的wiki页面上找到自定义数据所需的材料。自定义数据需要依赖于自定义数据的值类型。
您还可以在自定义数据的wiki页面上找到此信息。

  • 头颅贴图

    Skull Texture

    使用此自定义参数可以设置头颅的贴图
    在版本1.8 - 1.12.2方块必须是 SKULL. 在版本1.12或更高 版本方块必须是 PLAYER_HEAD 或
    PLAYER_WALL_HEAD.自定义数据的值是纹理属性的值。你可以找到这个值，例如在minecraft-heads的头颅底部的上。
  • 朝向

    Facing

    此参数可以设置方块的朝向, 此方块必须是有方向的，例如箱子的朝向。
    它的值可以被设置为 UP, DOWN, WEST, SOUTH, EAST 和 NORTH。
  • 方向

    Direction

    方块朝向可以被设置，它的参数是: UP, DOWN, WEST, SOUTH, EAST 和 NORTH.
    就比如像是蘑菇块有不同的朝向。
  • 命令方块

    command

    使用此自定义数据，可以将命令设置在命令方块里。
    对于Minecraft版本1.8-1.12.2，材料必须是COMMAND, COMMAND_REPEATING（从MC 1.9开始）
    或COMMAND_CHAIN（从MC 1.9开始）。从Minecraft版本1.13到1.14.4，
    它必须是COMMAND_BLOCK, CHAIN_COMMAND_BLOCK or REPEATING_COMMAND_BLOCK。
    命令不会在生成世界期间自动激活，它需要一个红石信号。可以使用自动自定义数据自动激活它。
  • Auto（使用Minecraft 1.9及更高版本）

    Auto

    使用此自定义数据，您可以设置生成区块时命令是否自动激活。此自定义数据仅在Minecraft 1.9
    版及更高版本之后才起作用。对于Minecraft版本1.9-1.12.2，材料必须是命令方块、循环型命令方块或连锁型命令方块。
    从Minecraft版本1.13到1.14.4，它必须是命令方块, 连锁型命令方块 or 循环型命令方块。值可以是true或false。
    在Minecraft 1.13及更高版本中，还必须将TICK_BLOCK自定义数据设置为true。
  • Tick Block（带有Minecraft 1.13和更高版本）

    Tick block

    使用这些自定义数据，您可以设置生成的矿石是否应进行方块更新。（通常他们不会得到一个）
    值可以是true或false。
    此自定义数据仅适用于Minecraft 1.13及更高版本。
  • ItemMods（具有Minecraft 1.13版和ItemMods插件1.3.1版或更高版本）

    ItemMods

    使用这些自定义数据，您可以从Plugin ItemMods设置自定义方块。
    为了设置自定义数据，ore-config(矿物配置文件)的材质必须与自定义方块的材质相同。值是自定义方块的名称。
    此自定义数据仅适用于Minecraft版本1.13及更高版本，并且安装了ItemMods 1.1.6或更高版本时。
    使用此自定义数据，可以将自定义NBT值设置为实体附加值
    (方块实体（与实体无关），被游戏用来存储不能储存在方块状态中的信息。1.8之前的版本称为tile entity)。
    格式必须是有效的Json。
  • Variant（适用于Minecraft 1.8-1.12.2版）

    Variant

    有了这些自定义数据，您可以设置不同类型的方块块，如从石头中挖出闪长岩。
    此自定义数据仅存在于Minecraft 1.8-1.12.2版本中。
    因为在Minecraft版本1.13及更高版本中，方块的子id被删除。
  • NBT标签
  • Block State（使用Minecraft 1.10及更高版本）

    Block State(是进一步定义一个方块所需的附加数据)

    使用此自定义数据，可以将附加值设置到方块上。
    自定义数据值必须与Minecraft用于/give命令的语法相同。
    此自定义数据适用于Minecraft 1.10及更高版本。
