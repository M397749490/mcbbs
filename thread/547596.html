标题: JAVA虚拟机异常无法开服

@echo off
title 1.7.10服务器
java -Xmx2g -jar "%cd%\cirnocraft\KCauldron.jar"
pause

大致意思：
Java虚拟机初始化发生错误

无法创建Java虚拟机
发生了一个致命的错误：程序即将结束

作者: 1363848914    时间: 2016-1-28 15:29
这种问题大部分是由于内存设置错误造成的，你可以尝试修改内存设置，将bat文件内容修改为
@echo off
title 1.7.10服务器
java -Xincgc -Xmx1g -jar "%cd%\cirnocraft\KCauldron.jar"
pause
重新运行
