情况如下:我在一个炼药锅的位置设置了一个隐形盔甲架，如果我检测这个炼药锅:当此锅等级为3或2级时给盔甲架加can的标签，当此锅等级不等于3或2级时给盔甲架除去can标签，这样一级时则不能拥有can标签


加can标签的很简单
  1. execute as @e[type=arrmor_stand] at @s if block ~ ~ ~ minecraft:cauldron[level=3] run tag @s add can
复制代码
  1. execute as @e[type=arrmor_stand] at @s if block ~ ~ ~ minecraft:cauldron[level=2] run tag @s add can
复制代码


现在的问题是:
  1. ① execute as @e[type=arrmor_stand] at @s unless block ~ ~ ~ minecraft:cauldron[level=3] run tag @s remove can
复制代码
  1. ② execute as @e[type=arrmor_stand] at @s unless block ~ ~ ~ minecraft:cauldron[level=2] run tag @s remove can
复制代码
锅为1级，①②都通过，可以去掉can标签
但如果锅为2级，那么①通过，如果锅为3级，那么②就通过，这样无论锅是多少级，都不能拥有can标签
所以   求解

作者: Ruainbow_    时间: 2020-4-26 10:33
将remove的unless条件合并即可，此时有任意条件不通过（等于2或3）时都不会remove这个标签。
execute as @e[type=arrmor_stand] at @s unless block ~ ~ ~ minecraft:cauldron[level=3] unless block ~ ~ ~ minecraft:cauldron[level=2] run tag @s remove can
