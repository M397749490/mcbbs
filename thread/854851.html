配置文件已全为默认

问题1.非OP玩家无法使用类似tpa,sethome等Ess基础指令(补充:You do not have access to that command)
问题2.kits物品是否可添加药水效果？如果可以如何编辑(格式)？(补充：装备在装备栏生效)

总回答 : (1)装权限组插件;不支持   (2)直接改plugin.yml(简单粗暴);不支持[已最佳]

经过LZ仔细翻阅config.yml，找到了问题所在
# In this example someone with 'essentials.sethome.multiple' and 'essentials.sethome.multiple.vip' will have 5 homes.
# Remember, they MUST have both permission nodes in order to be able to set multiple homes.
# Controls whether players need the permission "essentials.home.compass" in order to point
# the player's compass at their first home.
# Leaving this as false will retain Essentials' original behaviour, which is to always
# change the compass' direction to point towards their first home.
compass-towards-home-perm: false

ess自带的有权限组 插件文件夹搜索GroupManager就是权限组插件

使用方法如下：
  1. manuadd 123 XXX 将玩家123添加到XXX用户组;

  3. 　　manudel 123 将玩家123变为默认组;

  5. 　　manuaddsub 123 XXX 将XXX用户组添加到玩家123的子用户组列表中;

  7. 　　manudelsub 123 XXX 将XXX用户组从玩家123的子列表中剔除;

  9. 　　manuaddp 123 essentials.* 为玩家123单独增加essentials.*权限(由于大部分权限都由Essentials基础插件提供，所以这是一般形式);

  11. 　　manudelp 123 essentials.* 删除玩家123拥有的essentials.*权限;

  13. 　　manulistp 123 列出玩家123所拥有的权限;

  15. 　　manucheckp 123 essentials.* 检查玩家123是否拥有essentials.*权限，并寻找出处(用户组);

  17. 　　manuaddv 123 prefix &1 设置玩家123的prefix变量为&1(变量目前有prefix(前缀)、suffix(尾缀)、build(破坏方块)三种，已有效);

  19. 　　manudelv 123 prefix 删除玩家123的prefix变量;

  21. 　　manulistv 123 列出玩家123所拥有的变量(虽然无效，但看还是能看的);

  23. 　　manucheckv 123 prefix 查看玩家123的prefix变量属性(这里看的是用户组里的);

  25. 　　mangadd XXX 添加名为XXX的用户组;

  27. 　　mangdel XXX 删除名为XXX的用户组;

  29. 　　mangaddp XXX essentials.* 为用户组XXX增加essentials.*权限;

  31. 　　mangdelp XXX essentials.* 删除用户组XXX拥有的essentials.*权限;

  33. 　　manglistp XXX 列出用户组XXX所拥有的权限;

  35. 　　mangcheckp XXX essentials.* 检查用户组XXX是否拥有essentials.*权限，并寻找出处;

  37. 　　mangaddv XXX prefix &1 设置用户组XXX的prefix变量为&1;

  39. 　　mangdelv XXX prefix 删除用户组XXX的prefix变量;

  41. 　　manglistv XXX 列出用户组XXX所拥有的变量;

  43. 　　mangcheckv XXX prefix 查看用户组XXX的prefix变量属性;

  45. 　　mangaddi XXX1 XXX2 使用户组XXX1继承用户组XXX2的权限;

  47. 　　mangdeli XXX1 XXX2 将用户组XXX2从用户组XXX1的继承列表中删除(这个命令经测试发现有问题，删除不了);

  49. 　　manpromote 123 XXX 将玩家123升级到XXX用户组;

  51. 　　mandemote 123 XXX 将玩家123降级到XXX用户组

  53. 　　listgroups 列出目前所存在的用户组。
