如题
求助下大佬
我写了个树苗，继承的是BlockBush类
而且blockstate和model的block都是照着原版的蘑菇材质去写的
可进入游戏手上有这Item材质但是放下去就变成了紫黑块
这是model下Block的json:
{
    "parent": "block/cross",
  "textures": {
    "cross": "sakura:blocks/sakurasapling"
  }
}

这是blockstate的json:
{
  "variants": {
    "normal": { "model": "sakura:sakurasapling" }
  }
}

谢谢各位大佬了

我刚刚自己解决了
我就很奇怪就是放下的紫黑块顶上没有蓝色那个字
然后我就翻了一下我的block注册类
发现貌似上次删除另一个不需要的方块时候
误删了这个树苗的block
导致没有注册这个方块从而也就不会有报错了
