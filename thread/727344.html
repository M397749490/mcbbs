Help -- by what_name


介绍
这个插件可以在玩家在输入/help指令，发送指定文字的时候给玩家发送帮助信息（可自定义）。
截图:




用法
命令:
  玩家命令:
    /help —— 获得帮助
  管理员命令:
    /helpadmin reload —— 重载配置
    /helpadmin help    —— 获得管理员帮助
  管理员命令简写:
    /ha reload —— 重载配置
    /ha help    —— 获得管理员帮助

配置文件:

  1. help:
  2. - '&7------------- &eHelp v1.0 &cby what_name&7 -------------'
  3. - '&7此处省略一万字'
  4. # 帮助内容

  6. ChatHelp: true
  7. #是否启用聊天检测
  8. ChatWords:
  9. - 'help'
  10. #触发词语

  12. AdminHelp:
  13. - '&7------------- &eHelp v1.0 &cby what_name&7 -------------'
  14. - "&f&l/helpadmin reload &7---- &a重载插件"
  15. - "&f&l/helpadmin help &7---- &a获得管理员帮助"
  16. #管理员帮助内容

  18. #玩家获得帮助时运行事项
  19. OnGetHelp:
  20. # 发送帮助内容
  21. - 'sendHelp'
  22. # 播放声音
  23. - 'playsound pling'
  24. # 所有用法 ↓
  25. #-------------------------------------------
  26. # - 'tell &ehello_world'
  27. # 向玩家发送文字
  28. #-------------------------------------------
  29. # - 'playsound pling'
  30. # - 'playsound orb'
  31. # - 'playsound levelup'
  32. # 播放声音，目前仅支持这三种
  33. #-------------------------------------------
  34. # - 'runcommand player me_hello'
  35. # - 'runcommand op give_@p_command#block'
  36. # 执行命令
  37. # 第二项填写"player"代表以玩家身份，权限运行
  38. # 第二项填写"op"代表以玩家身份，op权限运行
  39. #-------------------------------------------

  41. sendHelpOnJoin: true
  42. #进入游戏时发送帮助
复制代码



举个例子：
将
  1. help:
  2. - '&7------------- &eHelp v1.0 &cby what_name&7 -------------'
复制代码
添加一行:
  1. help:
  2. - '&7------------- &eHelp v1.0 &cby what_name&7 -------------'
  3. - '&7emmmmm'
复制代码

同理，管理员帮助内容也可以这么修改

onGetHelp是个很有用的配置，可以通过不填写"sendHelp"的方式实现许多功能
例如配合sendHelpOnJoin来实现加入游戏获得物品，进入游戏执行命令等
