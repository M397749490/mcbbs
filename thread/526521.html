作者: TSStudio    时间: 2015-11-29 08:18
先用启动器下载资源文件！！
找到assets文件夹 打开indexes文件夹 打开1.8.json(记事本神马的)看到的如下
  1. {
  2.   "objects": {
  3.     "realms/lang/de_DE.lang": {
  4.       "hash": "10a54fc66c8f479bb65c8d39c3b62265ac82e742",
  5.       "size": 8112
  6.     },
复制代码
基本是这样重复(重复的是这个文件所呆的位置) 看到第三行 是一个lang(语言)文件的真实文件名字 音乐一样的 看到hash了吗 10a54fc66c8f479bb65c8d39c3b62265ac82e742 前两个字是10 返回assets文件夹 打开objects文件夹 找到前两个字(那个lang文件的hash的前两个是10)10这个文件夹 看到一大堆没有后缀的文件了吗 找到10a54fc66c8f479bb65c8d39c3b62265ac82e742 这个文件 就是de_DE.lang这个源文件了 (音乐改完了不能放原位置！) 用压缩软件计算MD5有一行SHA1    ：10A54FC66C8F479BB65C8D39C3B62265AC82E742 就是应该放的位置 然后把1.8.json里的改掉 注意size是大小 不是占用空间！！

在.minecraft/assets/indexes用写字板打开json文件 搜索 minecraft/sounds/music/game/creative 有很多的 把size上一行的代码（冒号后面的）复制

然后在 文件夹的右上角（关闭窗口底下的）的查找搜索 就在assets那个位置找 找到了挪到桌面来 重命名在末尾写.ogg 用QQ音乐之类的载入即可
