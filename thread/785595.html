Stats ScoreBoard——能够显示你的击杀数/死亡数的计分板
原贴地址(The original address)：点我|Click me
原作者(The original author): Zohreh
介绍|Introduction
这是一款可以用计分板的形式显示玩家的击杀数/死亡数，
不仅如此，它还能显示玩家的KD，最高击杀数的玩家排名和玩家的连杀数！
适用版本为Bukkit/Spigot 1.8-1.12
如果你有任何建议麻烦在下方回复
我看到以后会反馈给作者（同时也是作者对我的要求）
截图|Pictures
配置文件（已汉化）|Config
  1. MainOptions:
  2.   PerWorldStats: true   #是否每个世界都启用计分板
  3.   EnabledWorlds:        #能够启用计分板的世界
  4.   - world
  5.   - pvp
  6.   KillStreaks:          #是否开启连杀统计
  7.     enabled: true
  8. Scoreboard:             #是否开启计分板
  9.   enabled: true
  10.   scoreboardlinescolor: '&8'    #计分板标题的颜色
  11.   title: '&2StatsSB'            #计分板标题名称
  12.   dateTimeZone: PST             #当前时间
  13.   Kills-Prefix: '&f击杀数:'     #击杀数
  14.   Deaths-Prefix: '&f死亡数:'    #死亡数
  15.   KD-Prefix: '&fKD:'            #KD
  16.   Streak-Prefix: '&f连杀数:'    #连杀数
  17.   Kills: '&6'   #击杀数的颜色
  18.   Deaths: '&6'  #死亡数的颜色
  19.   KD: '&6'      #KD的颜色
  20.   Streak: '&6'  #连杀的颜色
  21. StatsCommand:
  22.   enabled: true         #是否开启指令
  23.   enable-permission: false      #是否开启指令权限
  24.   no-permission-message: '&c你没有权限使用这个指令!'   #若没有权限提示的信息
  25. MySQL:      #MySQL的相关配置，这里不多做注释
  26.   Enabled: false
  27.   Host: 127.0.0.1
  28.   Port: 3306
  29.   dbName: minecraft
  30.   Username: StatsSBSQL
  31.   Password: password12345
  32. Leaderboard:    #计分板统计
  33.   number-of-players-to-show: 10     #展示多少个玩家的排名
  34.   color-of-number: '&e'             #排名数的颜色
  35.   color-of-player-name: '&6'        #玩家名颜色
  36.   color-of-arrow: '&7'              #>>这个符号的颜色
  37.   color-of-kill-value: '&6'         #击杀数的颜色
  38.   color-of-top-border: '&8'         #全榜第一的颜色
  39.   borders: _______________________  #分割线
  40.   color-of-title: '&6&l'            #标题的颜色
  41.   title: 最高击杀                   #标题文字

如果有解释错误的麻烦回帖提出
指令|Command
/stats [玩家名] => 查看该玩家的计分板信息
/sbreload => 重启插件
需要权限: statssb.reload
/leaderboard => 查看玩家计分板排名榜 (便捷指令 - /lb)
