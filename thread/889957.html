这个非常简单，第一次加入的时候在 默认 权限设置死亡不掉落为 true
然后使用 AdvancedAchievements 插件，AdvancedAchievements是一个成就插件
可以记录很多数据，包括死亡
然后在死亡一次的时候触发命令，将个人权限设置为 false，因为个人权限优先级高于全局权限，所以
死亡一次后就没权限了

  1. Deaths:
  2.   '1':
  3.     Message: §f［§3信息§f］§r §f累计死亡 １ 次。§r
  4.     Name: Deaths1
  5.     Reward:
  6.       Command:
  7.         Execute: title PLAYER title ["",{"text":"§f［§5成就达成§f］§r"}]; title PLAYER subtitle
  8.           ["",{"text":"§f结束了罪恶的一生§r"}]; luckperms user PLAYER permission set 权限.死亡不掉落
  9.           false

作者: Worf丶Horo    时间: 2019-7-23 08:39
如果是1.7.10可以试试用VT http://www.mcbbs.net/thread-331579-1-1.html
VT有玩家死亡事件
一开是给玩家死亡掉落插件的权限，和另外一个新手判定权限
如果玩家死亡 玩家拥有新手判定权限 就执行命令删除玩家的掉落权限，并且删除新手判定权限，就可以了。

这样第二次玩家死亡，因为没有新手判定权限，所以也不会删除后续的死亡掉落权限
