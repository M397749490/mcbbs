领地插件有没有
打开领地插件config.yml,找到这样一段
    Flags:
        Global: #these are default for all worlds unless specified below, they can be overridden per group
            use: true
            build: true
            ignite: true
            firespread: true
            damage: true
            creeper: true
            tnt: true
            pvp: true

把pvp设置为true

再往下找到这样一段
# These groups correspond to the Permissions groups defined in your '<worldname>.yml'
Groups:
    Default: #group name

把Default改成你要关闭pvp的用户组名

再往下找到
       Flags:
          # Specifically allow or deny this group from changing certain flags.
          Permission:
               #build: true
改成
       Flags:
          # Specifically allow or deny this group from changing certain flags.
          Permission:
               pvp: false

The group doesn't have direct access to that permission

那么你是全服默认开启pvp的咯

\plugins\Essentials\config.yml
  1. # Users with the essentials.protect.pvp permission will still be able to attack each other if this is set to true.
  2.     # They will be unable to attack users without that same permission node.
  3.     pvp: true
复制代码
然后给所有需要开启pvp的用户组（除了需要关闭pvp的那组）添加essentials.protect.pvp权限
mangaddp 用户组名 essentials.protect.pvp
