标题: Minecraft 1.10.1 发布
本帖最后由 广药 于 2020-6-13 18:19 编辑
正式版是Minecraft经过一段时间的预览版测试之后得到的稳定版本，也是众多材质、Mod与服务器插件会逐渐跟进的版本。官方正版登陆器也会第一时间进行推送。

建议玩家与开服的朋友关注其相关服务端、Mod、插件、与API的更新，迎接新的正式版吧！
专注于单人原版游戏的玩家可立即更新，多人玩家请关注您所在的服务器的通知。

转载本贴时须要注明原作者以及本帖地址。





This is a smaller update taking care of some of the most annoying reported bugs. We are also planning to release another update for 1.10.x in a few weeks that takes care of some less critical but still annoying issues.
现在有一个关注于一些最令人烦恼的Bug的小更新。我们也准备在接下来的几周内发布1.10.x来解决一些不那么关键但也挺烦的问题。

Issues fixed in this version:
修复的Bug：
  • [Bug MC-85162] - Slight player/mob offset when on Farmland Block
  • [Bug MC-85162] - 在耕地上玩家/实体有轻微偏移
  • [Bug MC-99914] - DataWatcher / EntityMetadata ID is based on the class load order
  • [Bug MC-99914] - DataWatcher / EntityMetadata的ID是基于类加载顺序的
  • [Bug MC-100333] - Entities from old (<= 1.5.2) worlds are killed when loaded in current versions due to a typo in the health data fixer
  • [Bug MC-100333] - 旧版（<= 1.5.2）的世界的实体在当前版本中加载时因为生命值标签拼写错误被杀死
  • [Bug MC-102072] - Structure Block: Unable to navigate in the “structure name” field of structure blocks, using the arrow-keys, pos1, end or the delete key
  • [Bug MC-102072] - 结构方块：不能在“结构名称”栏中用方向键、位置1、End键或Delete键进行导航
  • [Bug MC-102867] - chat key bound to unicode char causes crash in creative inventory
  • [Bug MC-102867] - 创造模式中聊天按键绑定为Unicode字符会导致崩溃
  • [Bug MC-103177] - Missing subtitles for polar bears, strays, husks, and wither skeletons
  • [Bug MC-103177] - 北极熊、流髑、尸壳和凋零骷髅没有字幕
  • [Bug MC-103497] - End Dragon Does not respawn
  • [Bug MC-103497] - 末影龙不重生

If you experience crashes during multiplayer sessions, we need to know if you were playing on a vanilla server or a modified server. We still get crash reports in our backend systems that we can’t reproduce and we need more information to analyze that problem. It seems to be a rare but annoying problem for some players.
如果你在多人游戏中崩溃，你们我们需要知道你在玩的是原版还是MOD服务器。我们在后台依然会得到不能重现的报告并且我们需要更多信息来分析问题。这看起来很罕见但是让某些玩家非常烦恼。

正式版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要魔法上网。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户也请使用启动器下载游戏，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如仍有疑惑请到原版问答板块提问。
