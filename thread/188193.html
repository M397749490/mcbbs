简单几句介绍下这个插件。



这个插件可以让其他方块如【土】拥有【沙砾】的效果【增加重力的效果】这样这样增加许多的乐趣然后还得看你们的想象力.



安装插件。



这个插件和其他插件一样，下载后再把.jar 拖进plugins文件夹里面.


权限。

默认OP已经全部有了....


landslide.admin这个插件的全部指令op
landslide.commands.delete可以使用消除方块的指令op
landslide.commands.getcfg可以在游戏里面查看configop
landslide.commands.info可以查看插件状态op
landslide.commands.kaboom可以创造爆炸【使方块滑动】op
landslide.commands.reload还原插件op
landslide.commands.setcfg可以在游戏里面设定configop
landslide.commands.wand可以使用指令获得滑动之棒【下面介绍...】op
landslide.use.wand可以使用滑动之棒【下面介绍】...op



指令。


    /lsl set worlds.【世界名字】.enabled 【true=启动】

-  /lsl set worlds.world.enabled true           在world世界启动这个插件  

    /lsl set worlds.【世界名字】.enabled 【false=关闭】

-  /lsl set worlds.world.enabled false           在world世界不启动这个插件


还有需要指令是设定方块滑动的几率【我就不写了，一大堆呢】，大家到config里面设定比较快.
