作者: tamashii    时间: 2019-7-2 17:27
是这样的，
Java 的垃圾回收机制做的不好
从而导致内存泄露
然而Java 并不知道自己泄露了，所以你在Java中看到的内存占用实际上是Java能支配的内存空间
而任务管理器中看到的内存占用是 Java 实际上向操作系统申请了但是没有释放的内存空间
