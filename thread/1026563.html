使用方法：

装载JSRunner，装载本插件

开服后在BDS根目录找到npc.json



JSON&创建NPC：

在npc.json内我们可以看到：
  1. {
  2.     "admin": {                        //这是可以管理op的玩家列表
  3.         "playername": "playername"
  4.     },
  5.     "npcs": [ "npcname" ],            //这是NPC列表

  7.     "npcname": {                      //这是NPC名字，不能修改
  8.         "title": "我是总标题",        //这是点击NPC后弹出表单的标题
  9.         "xyz": "0 0 0",               //这是这个NPC的坐标
  10.         "buttons": [                  //这是按钮列表
  11.             {
  12.                 "title": "我也是按钮",             //按钮标题
  13.                 "image": "textures/items/gold_sword.png",         //按钮图片路径(BDS文件夹内)
  14.                 "cmd": "tell {执行者} 我是点击这个按钮后执行的命令"  //点击后执行的指令{执行者}为玩家
  15.             },
  16.             {
  17.                 "title": "我是按钮",              //按钮标题
  18.                 "content": "我是一个弹窗内容哦"              //此元素为点击按钮后弹出内容
  19.             }
  20.         ]
  21.     }
  22. }
复制代码
增加管理员：
通过修改json内admin元素增加管理员
示例：
  1. "admin": {
  2.         "playername": "playername",
  3.         "siyue": "siyue"
  4. }
复制代码

创建一个NPC：
输入：/npc creat npc名字
