AutoUnloadChunk
自动卸载区块
  • 插件作用：
简单配置多长时间自动卸载一次区块，查看各个世界的加载区块数量，or 手动卸载区块
小 妹:https://www.mcbbs.net/thread-723356-1-1.html

  • 插件配置：
  1. # 卸载区块的间隔时间(秒)
  2. AutoUnloadChunkSecondTime: 180
复制代码
  • 指令：
/auc chunk  查看区块数量
/auc unload  手动卸载区块
/auc reload  重载插件配置

  • 权限：
  1. permissions:
  2.     autounloadchunk.*:
  3.         description: Auto unload chunk.
  4.         default: op
  5.         children:
  6.             autounloadchunk.help: true
  7.             autounloadchunk.chunk: true
  8.             autounloadchunk.unload: true
  9.             autounloadchunk.reload: true
  10.     autounloadchunk.help:
  11.         description: Auto unload chunk help.
  12.         default: false
  13.     autounloadchunk.chunk:
  14.         description: View chunk amount.
  15.         default: false
  16.     autounloadchunk.unload:
  17.         description: Manual unload chunk.
  18.         default: false
  19.     autounloadchunk.reload:
  20.         description: Reload the plugin configuration.
  21.         default: false
