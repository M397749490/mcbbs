前言

这是一个支持将命令限制使用次数的插件，比如你想让某个玩家只能使用3次的飞行命令，那么这款插件对于你来说在合适不过。
已测试服务端 1.6.2 ，1.7.10 ，1.12.2
同时支持Forge版本服务端。

命令/变量名
OP/后台命令
/MKC create 玩家名字 权限 命令 次数     创建一条命令
/MKC remove 玩家名字 命令              删除玩家的某个命令
/MKC query 玩家名字                    查看某个玩家的命令

玩家命令

/MKC use 命令                         使用一个命令
/MKC cmdList                          查看拥有的命令

没有权限……
变量名
^ 等于空格
%pn%等于玩家名字
@你定义的名字等于快捷赋值

注意事项

1. 如果你创建了一条这样的命令 /MKC create mark5 essentials.fly fly 4 为什么需要是4次呢？因为包含了 玩家关闭 飞行模式，所以这个只能算做两次命令，但由于这种命令涉及到 开启/关闭 所以命令数量 * 2 当然，如果不是这种包含 开启/关闭 的命令，则不用管。
2. 既然用到命令次数，那么这个玩家肯定是不能拥有这个命令权限的，因为本插件会在给予玩家的权限的时候 立刻 删除。
教程

/MKC create Mark5 essentials.gamemode gamemode^0^%pn% 1 执行变生存模式
(如果不知道^和%pn%是什么意思往上翻……一定要看注意事项的第一条)
执行这个命令后会给一个名为 Mark5 的玩家一次执行/gamemode 0 Mark5 的权限
