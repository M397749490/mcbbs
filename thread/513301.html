原文
Bingo is a plugin inspired by lorgon111. This plugin allows you to simulate the game of Bingo in Minecraft! Bingo items may be customized and will be randomly picked from your list of items. Once you pick up an item that is on your Bingo Board, that item is cleared and you can move on to other items that you have not been cleared. If you can get 5 in a row either in a row, column, or diagonal, you win! This plugin is suppose to be used as a speed-run type of Fun Plugin, please enjoy your time and don't gamble!
--------------------
bingo是一个插件，作者lorgon111。这个插件允许您在Minecraft模拟
bingo
游戏项目可以定制,它会随机选择模式，从你的项目列表(config.yml)。一旦你挑选一个项目,游戏里,获得的物品会自动消失。如果你可以得到5个连续的行的,列的,或斜得物品,那你就赢了!
请享受吧!

It should be pretty simple, download, drag, and drop into the plugins folder of your bukkit server. If something goes wrong, your console should show you a stacktrace (a long scary [SEVERE] error) or just a friendly reminder. I have not implemented all the error handling yet, so brace yourselves for some errors.
----------
它很简单，如何下载？直接拖放bukkit服务器的插件文件夹。如果出现错误,您的控制台会出现报错。我还没有完成所有的BUG处理,所以承认自己的一些错误。
This plugin is meant to a fun plugin, and serve as an event on a busy server.  When an administrator starts the game, all players are notified so they can choose if they want to join the game and gamble their wealth for victory! It's advised player do not have anything to start out with, so everyone have a fair chance.  This plugin supports color, just use your basic color symbol (&) and the code followed by it!
------------
　　这是一个有趣的插件,是忙碌的生存服务器的一个娱乐。
　　当管理员开始游戏时,所有玩家都会被通知，他们可以选择是否游戏。如果他们想参加游戏，那么必须有进场费。它保证每个玩家都是公平的。
　　这个插件支持颜色,使用颜色符号(&)就行了!



指令
/bingo - 全部指令
  /bingo start - 创建一个游戏(需要权限)
/bingo join - 加入一个游戏
/bingo leave - 退出一个游戏



权限
bingo.admin - 创建游戏的权限


配置文件config
Welcomemessage:(进入一个游戏时的提示信息)
items:(随机物品的ID)
announce_new_item:(当玩家发新东西时是否公告)
itemlore:(未发现物品的lore)
bingolore:(用来记录物品状态的地图的lore)
starlore:(已发现物品的lore)
economy:
(是否启用经济插件)
economy-entry-fee-enabled:
(是否开启报名费)
economy-entry-fee:
(报名花费)
economy-reward:
(奖励数量)

no-economy-entry-fee-enabled:
(是否开启物品报名费,需要"ecnomy-entry-free-enabled: false")
no-economy-entry-fee:
(报名物品)
no-economy-entry-fee-quantity:
(报名物品数量)
no-economy-reward:
(奖励物品)
no-economy-reward-quantity:
(奖励物品数量)



进入方法
OP输入/bingo start
玩家输入/bingo join
