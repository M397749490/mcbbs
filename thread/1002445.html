概述

为BDS WIN提供了一个开发模组的基础框架

其兼容BDSJsRunner 也有自研的Lua API

可以让开发者既能使用JSRunner Api/Lua Api快速开发简单且跨版本无需重复编译的小型插件

也能通过其内建的各类方法更简单更快速的开发复杂的C++ 模组

同时也尽量兼容其他开发框架 并且使安装流程更加简化 使得普通用户更易于使用。


目前已实现的功能:

- 可以方便的监听常用事件
- 注册原生指令
- 使用调度器
- 使用json语言包和json配置文件
- 通过Key-Value DB和工具类来保存和读取自定义数据
- 自定义GUI
- LUA API（快速开发小型插件）
- 经济API

同时为常用操作（比如执行指令）做了简单封装

选择BedrockX的理由？

对于服务器运营者：

BDL运行在BDS Linux平台上，与Win平台相比有至少一倍的性能损失

BDL的一些mod已经过时并且停止维护，最近的一个严重安全问题就是land权限绕过问题

BDL的功能没有BDX丰富，同时自定义性弱

Bedrock X提供了大量官方基础插件 并且与JSRunner合作 可以直接使用JSRunner插件



对开发者：

BDL使用的API过于陈旧，开发者甚至无法改变事件监听器次序，同时其他API如指令注册等也很复杂

BDL Base API设计混乱，耦合性过大

Bedrock X将尽量保持与其他API的兼容 确保用户拥有最大选择权


为什么要使用BDX提供的经济和领地API:


对开发者：

经济API使用sqlite存储，支持流水查询和多服同步
领地API经过了特殊优化，可以做到一秒百万级别查询（连续坐标查询，基准测试情况下），
因此可以作为其他mod的辅助工具，例如允许区域爆炸，只允许和最近领地半径大于10的坐标爆炸。

对服主用户：


经济GUI,领地GUI
与bdl相似的命令格式，操作简便
无需记忆新的指令格式。
