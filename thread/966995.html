我有一个办法：
我们先生成一个带标签的 pillager：
  1. /summon minecraft:pillager ~ ~ ~ {Tags:["leader"]}
复制代码
然后再写一个进度：
kill_leader:root
  1. {
  2.   "rewards": {
  3.     "function": "kill_leader:rewards"
  4.   },
  5.   "criteria": {
  6.     "requirement": {
  7.       "trigger": "minecraft:player_killed_entity",
  8.       "conditions": {
  9.         "entity": {
  10.           "nbt": "{Tags:["leader"]}"
  11.         }
  12.       }
  13.     }
  14.   }
  15. }
复制代码
意思是击杀 Tags:["leader"] 的实体后运行函数 kill_leader:rewards。
再写一个函数：
kill_leader:rewards
  1. advancement grant @s only adventure/voluntary_exile
  2. effect give @s minecraft:bad_omen 6000 0
  3. advancement revoke @s only kill_leader:root
复制代码
意思是赋予玩家 自我放逐 进度，给予玩家 不祥之兆 效果。
