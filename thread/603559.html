作者: 火星使者    时间: 2016-7-15 01:24
这个其实不用命令方块，用中继器就可以
中继器有四档，延迟分别是0.1秒，0.2秒，0.3秒，0.4秒，
比如，要记十秒，就把25个四档的中继器加上开关连在一起（0.4*25=10），开始计时就打开开关，中继器最后可以接个命令方块打指令/say hi，效果就是打开开关后过10秒就会说hi
作者: lzs1234    时间: 2016-7-15 08:13
/scoreboard objectives add time dummy
创建一个名为Time的计分板

/scoreboard players set remaintime XXXXXX
XXXXXX处填写秒数X20的数值（因为在MC中，命令系统都是用gt计时的，1s=20gt）

循环/高频命令方块：/scoreboard players remove remaintime time 1
给time记分板上的remaintime每个gt减去1

/scoreboard players test remaintime time 0 0
检测remaintime的值是否为0，后接一个Chain模式的CB（1.9+）或比较器（1.8）并输出

不过命令方块可以调漏斗的延迟，这个应该可以，也不会看到积分板
漏斗的延迟NTB是{TransferCooldown:10}，默认是10，这个单位大概是红石刻（1红石刻=1/20秒）
比如要计10秒，可以先放一个漏斗
  1. /setblock <XYZ> minecraft:hopper 0 replace {TransferCooldown:200}
