6  怎么不把所有菜单都挤进config.yml?

接上面,当你启动完毕服务器后 (看到 Done! )

应该可以在plugins/DeluxeMenus中找到config.yml

打开后,发现了clip大鸽送给你的一个模板菜单

但是把所有的菜单都挤到一个config.yml里既不美观,也没有秩序

那么你可以参照下面修改下config.yml

  1. debug: false
  2. check_updates: true
  3. gui_menus:
  4.   example:
  5.   #注册的名字,可以通过/dm open 注册的名字 打开菜单
  6.     file: example.yml
  7.     #该菜单在gui_menus文件夹中的名字

9  教你写一个条件

为了更符合正常的学习流程,我先在这里讲如何写一个条件

注意 这里也许需要一定的Java基础,不过没有也无妨

你下面所看到的

  • open_requirement:
  • left_click_requirement:
  • right_click_requirement:
  • view_requirement:
  • 等结尾是 requirement 的选项
    即为条件选项

条件选项配合多个物品的优先级

可以做到一些譬如

在同一个物品位置上,如果玩家有100点券就可以看到钻石,没有则看到泥土

的一类操作

接下来由我讲解一下如何写一个条件(requirement)

下面是两个例子,用来解释到底条件写在哪里

  4.     one:
  5.     #条件1
  6.       ......
  7.     cps:
  8.     #条件2
  9.       ......

复制代码
  1. type: javascript
  2. expression: 'JS'

  4. 用过老版DM或者在用TrMenu的服主应该会比较明白
  5. 就是填写一些JS表达式,使用&&表并列,使用||表其一,使用!表(如果)不
  6. 其实上面的所有简化条件都是由这个转来的

  8. 下面是一些格式

  10. * (String[A]).equals(String[B])
  11. * 输入A与输出B是否完全一致
  12. * (例) (%player_name%).equals.("AzureHanChen")
  13. * 玩家的名字是否是AzureHanChen

  15. * (String[A]).equalsIgoneCase(String[B])
  16. * 输入A与输入B除大小写外是否完全一致
  17. * (例) (%player_name%).equalsIgoneCase.("AzureHanChen")
  18. * 玩家的名字在忽略的大小写的情况下是否是AzureHanChen

  20. * A (符号) B
  21. * A 是否 (符号) B
  22. * 只能用于A和B都是Int的场景中

  24. * 符号列表
  25. * == 等于
  26. * > 大于
  27. * >= 大于或等于
  28. * <= 小于或等于
  29. * < 小于

  31. * (错例) %player_name% == AzureHanChen
  32. * (错例) "%playerpoints_points" >= 233
  33. * 那肯定有人要问了,为什么这个不对呢
  34. * 首先,如果按照上面写,那么写出来是这样的
  35. * expression: '"%playerpoints_points%" >= 233'
  36. * 首先'里面可以套"是对的,但是结合前面的内容
  37. * 这样%playerpoints_points%就成了一个个体,而且还存在一个"
  38. * 那么无疑就成了String了,拿String和Int作比较,这个结果可想而知
  39. * 另外也肯定有人问: 那我将错就错,我把233也套上"不就行了吗?
  40. * 首先,我敢肯定这是个迷惑行为,拿String和String作比较,这样不就违反了
  41. * 我一开始讲到的 "只能是Int和Int做对比" 原则了吗

  43. * 说了一大堆,总结: Int外面莫套壳,Int就和Int比

  45. * 那么怎么表达一个反向条件呢
  46. * 例如一开始讲到的 "如果玩家的名字是AzureHanChen,那么此条件通过"
  47. * 那么怎么实现如果 "如果玩家的名字不是AzureHanChen,那么此条件通过"呢?

  49. * !+一个JS格式
  50. * 例如expression: '!(%player_name%).equals("AzureHanChen")'
  51. * 就可以实现"如果玩家的名字不是AzureHanChen,那么此条件通过"

  53. * 那么如何实现两个JS都通过此javascript条件才通过呢
  54. * JS1 && JS2
  55. * 例如
  56. * expression: '(%player_name%).equals("AzureHanChen") && %playerpoints_points% >= 1'
  57. * 玩家的名字必须是AzureHanChen*且*玩家的%playerpoints_points%≥1

  59. * 那如何实现二者其一通过,此条件就通过呢
  60. * JS1 || JS2
  61. * 例如
  62. * expression: ' %vault_eco_balance% >=233 && %playerpoints_points% >= 1'
  63. * 玩家的Vault经济系统金额必须≥233*也或者*玩家的%playerpoints_points%≥1

  65. (*) 憋说我啰嗦,不同的货币在不同的服务器有不同的命名,因此我用代名词来指认
  66. (*) 如果在你服的PlayerPoints是金币,我说点券你会明白?

15  听说你想加点声音?

哪个男孩不想给自己的菜单加点声音呢?
首先得找到一段声音

在原版MC中,你可以使用"/playsound"
来寻找一段符合菜单/物品设定的声音

比如我想在礼包冷却时给玩家放一段末影人传送的声音
先分析一下
末影人属于生物 entity
而末影人则是 endermen
传送则是 teleport  

  1. /playsound minecraft:entity.endermen.teleport ambient @a
复制代码

但是在菜单中可不能直接这样写
要全大写并且将.改为_   也就是
ENTITY_ENDERMEN_MEN

  1. - '[sound] ENTITY_ENDERMEN_MEN'
