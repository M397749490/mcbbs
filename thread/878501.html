标题: ItemloreStats插件怎么设置原伤害百分比
自从加了ItemloreStats插件，服务器里所有伤害都变了，摔落造成伤害变高，玩家到稍微那么高点点地方跳下来就死了。还有，比如火焰，爆炸，中毒等等，造成伤害好像是按10%原生命值来算的，比如10000血的NPC被火烧了，每次减1000血

跪求问，怎么修改原伤害百分比，不按10%来算？？



作者: 破晓大辣鸡    时间: 2019-6-29 08:33
打开ils的config
搜索:
environmentalDamage:
  block_explosion:
    damage: 0
    durabilityLost: 0
  cactus:
    damage: 0
    durabilityLost: 0
  drowning:
    damage: 0
    durabilityLost: 0
  entity_explosion:
    damage: 0
    durabilityLost: 0
  fall:
    damage: 0
    durabilityLost: 0
  fire:
    damage: 1
    durabilityLost: 0
  fire_tick:
    damage: 1
    durabilityLost: 0
  lava:
    damage: 0
    durabilityLost: 0
  lightning:
    damage: 0
    durabilityLost: 0
  magic:
    damage: 0
    durabilityLost: 0
  poison:
    damage: 2
    durabilityLost: 0
  starvation:
    damage: 10
    durabilityLost: 0
  suffocation:
    damage: 0
    durabilityLost: 0
  thorns:
    damage: 0
    durabilityLost: 0
  damage:
    durabilityLost: 1
