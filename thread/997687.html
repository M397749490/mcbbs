感谢诸多热心玩家的付出。

1.16.0是基岩版以下界更新为主题的重大更新，发布于2020年6月23日。此次更新对下界进行了重大更改，加入了新的生物、生物群系和方块等内容，同时加入了一些原本Java版独有的特性，以及重新添加了一些原本教育版独有的特性。

新内容
方块
允许方块和拒绝方块
  • 能再次通过give获得。
远古残骸
  • 可以在下界的任何高度处生成，而高度较低处的生成率更高。
  • 可放入熔炉或高炉中熔炼获得下界合金碎片。
  • 爆炸抗性和黑曜石相同，但能够被活塞推动。
  • 掉落物形式能够在熔岩中漂浮。
  • 不会被熔岩或火烧毁。
  • 需要钻石质或更好的镐来进行开采。
  • 生成时总会被熔岩或其他方块完全掩盖。
玄武岩
  • 组成玄武岩柱的方块。
  • 自然生成于灵魂沙峡谷以及玄武岩三角洲生物群系。
  • 与原木相似，可沿不同方向摆放。
  • 会在灵魂土上的熔岩接触蓝冰时形成。
黑石
  • 会自然生成于堡垒遗迹里。
  • 大片生成于玄武岩三角洲生物群系中，小片生成于任何下界生物群系的35层及以下。
  • 类似于圆石，可用于合成熔炉和石质工具。
黑石台阶、黑石楼梯和黑石墙
  • 由黑石合成或在切石机制成的装饰性方块。
下界合金块
  • 可由9个下界合金锭合成获得。
  • 不会被熔岩和火烧毁。
  • 与黑曜石有着相同的爆炸抗性，但可被活塞推动。
  • 可用于搭建信标金字塔。
边界
  • 能再次通过give获得。
锁链
  • 生成于堡垒遗迹中。
  • 可用1个铁锭和2个铁粒合成。
錾制下界砖块
  • 下界砖块的錾制变种。
  • 由2个下界砖台阶合成或在切石机制成。
裂纹下界砖块
  • 下界砖块的裂制变种。
  • 由下界砖块在熔炉中熔炼而成。
绯红菌和诡异菌
  • 分别生成于绯红森林和诡异森林生物群系。
  • 可放置在泥土、花盆、砂土、耕地、灰化土、草方块、菌岩和灵魂土上。
  • 对种在对应变种菌岩上的菌类使用骨粉可使之生长为对应的巨型菌类。
  • 与蘑菇不同，菌类不能蔓延。
  • 可用于堆肥。
绯红菌岩和诡异菌岩
  • 与草方块相似。
  • 对与菌岩相邻的下界岩使用骨粉可使其蔓延。
绯红木板和诡异木板
  • 不可燃尽。
  • 可由对应的菌柄方块合成获得。
  • 可用于合成对应的台阶、楼梯、栅栏、栅栏门、压力板、按钮、告示牌、门和活板门。
绯红菌索和诡异菌索
  • 装饰性植物，生成于绯红森林、灵魂沙峡谷和诡异森林生物群系。
  • 可种植在花盆中。
  • 可用于堆肥。
绯红菌柄和诡异菌柄
  • 一类组成巨型菌枝干的方块。
  • 拥有动态的材质。
  • 顶面的材质和其他原木相似，呈年轮状。
  • 与原木相似，可沿不同方向摆放。
  • 不可燃尽。
  • 具有对应的去皮变种。
绯红菌核和诡异菌核
  • 菌柄的六面覆皮变种。
    • 由菌柄合成，合成方式类似原木合成木头。
  • 具有对应的去皮变种。
哭泣的黑曜石
  • 可通过与猪灵以物易物获得。
  • 会发出亮度等级为10的光。
  • 会散发紫色颗粒。
  • 爆炸抗性与黑曜石相同，且不能够被活塞移动。
  • 是重生锚的合成材料。
  • 会出现在废弃传送门和堡垒遗迹的战利品箱中。
  • 会作为废弃传送门的一部分生成。
镶金黑石
  • 黑石的镶金变种。
  • 挖掘后目前大几率掉落该方块本体，小几率掉落2-5颗金粒。
    • 掉落金粒的概率受时运魔咒影响。
  • 会自然生成于堡垒遗迹中。
  • 不属于矿石，因此无法通过熔炉烧炼。
磁石
  • 由8个錾制石砖和1个下界合金锭合成。
  • 对磁石使用指南针可使指南针指向点置为该磁石的位置，同时该指南针会转化为磁石指针。
  • 可在所有维度中使用。
下界金矿石
  • 生成于下界的金矿石变种。
  • 和普通金矿石一样，烧炼可获得金锭。
  • 用镐直接挖掘会掉落2-6金粒与经验。
    • 掉落物品数量上限受时运魔咒影响。
    • 可以使用任意镐进行开采。

下界苗
  • 一种生成于诡异森林生物群系的、类似草丛的植物。
  • 可用于堆肥。
磨制玄武岩
  • 装饰性方块。
  • 可由4个玄武岩合成或使用切石机获得。
磨制黑石
  • 黑石的磨制变种。
  • 由4个黑石合成或在切石机制成。
  • 有錾制、台阶、楼梯和墙变种。
  • 可用于合成压力板和按钮。
磨制黑石砖
  • 由4个磨制黑石合成或在切石机制成。
  • 有裂制、台阶、楼梯和墙变种。
磨制黑石按钮和磨制黑石压力板
  • 由磨制黑石合成的红石元件。
  • 性质与普通石质按钮和压力板相同。
磨制黑石台阶、磨制黑石楼梯和磨制黑石墙
  • 由磨制黑石合成或在切石机制成的装饰性方块。
錾制磨制黑石
  • 磨制黑石的錾制变种。
  • 由磨制黑石合成或在切石机制成的装饰性方块。
裂纹磨制黑石砖
  • 磨制黑石砖的裂制变种。
  • 由磨制黑石砖在熔炉中熔炼而成。
石英砖
  • 石英块的变种，可用4个石英块合成。
重生锚
  • 由哭泣的黑曜石和荧石合成。
  • 通过消耗荧石充能，这一操作也可由发射器执行。
    • 版本独有：使用附上精准采集的镐采集有能量的重生锚会保存重生锚的能量。
  • 充能后用于在下界设置重生点。
  • 每次重生消耗1点充能点数。
  • 在主世界和末地使用会发生爆炸。
菌光体
  • 与荧石相似，会发出亮度等级为15的光。
  • 可使用任意工具采集，但锄和斧是最快的。
  • 会作为巨型菌的一部分生成。
灵魂营火
  • 营火的蓝色变种。
  • 会发出亮度等级为10的光。
  • 合成配方与普通的营火相似，但需使用灵魂土或灵魂沙而非煤炭或木炭。
  • 其他性质与普通营火相同。
  • 可用于驱赶猪灵。
灵魂火
  • 火的蓝色变种。
  • 会发出亮度等级为10的光。
  • 在任何维度下，在灵魂土和灵魂沙上燃烧的火焰都会呈蓝色。
    • 与下界岩上的火焰相似，会永久燃烧，也不会被雨淋熄。
  • 自然生成于下界的灵魂沙峡谷生物群系。
  • 版本独有：每秒会造成1伤害。
灵魂灯笼
  • 会发出亮度等级为10的光，且不能够融化冰和雪。
  • 合成配方与普通的灯笼相似，但需使用灵魂火把而非普通火把。
  • 拥有动态的材质。
灵魂火把
  • 会发出亮度等级为10的光，且不能够融化冰和雪。
  • 合成配方与普通的火把相似，但木棍下方还需放置灵魂土或灵魂沙。
灵魂土
  • 和灵魂沙一同生成于灵魂沙峡谷生物群系。
  • 在其上点燃的火焰为灵魂火。
  • 玩家在其上行走时既不会“下陷”，也不会受到减速影响。
标靶
  • 新的红石元件，被弹射物击中后会发出红石信号。
    • 弹射物击中的位置越接近靶心，其发出的红石信号越强，最高强度可达15。
  • 可使用4个红石粉和1个干草块合成。
缠怨藤
  • 生成于诡异森林生物群系的藤蔓变种。
  • 与垂泪藤不同，缠怨藤会自下而上生长。
  • 可以攀爬。
  • 可用于堆肥。
诡异疣块
  • 下界疣块的变种。
  • 会作为诡异巨型菌的一部分生成。
  • 在诡异森林生物群系中有时取代诡异菌岩在地面上自然生成。
  • 可用于堆肥。
垂泪藤
  • 生成于绯红森林生物群系的藤蔓变种。
  • 只能放置在方块底部，可竖直向下生长。
  • 可以攀爬。
  • 可用于堆肥。

物品
迟缓药水 IV
  • 可以通过在普通迟缓药水中添加荧石粉来酿造。
喷溅型迟缓药水 IV
  • 可以通过在普通喷溅型迟缓药水中添加荧石粉来酿造。
滞留型迟缓药水 IV
  • 可以通过在普通滞留型迟缓药水中添加荧石粉来酿造。
迟缓之箭 IV
  • 可以用装有迟缓药水的炼药锅与箭矢制作。
磁石指针
  • 可由指南针绑定磁石后转化而来。
    • 指针会指向其绑定的磁石。
    • 如果玩家传送到其他维度或绑定的磁石被破坏，则该磁石指针会随机旋转。
  • 版本独有：拥有与Java版不同的材质。
  • 版本独有：无法附魔消失诅咒。
音乐唱片
  • 加入了音乐唱片“Pigstep”。
    • 与其他的音乐唱片不同，这是由Lena Raine制作的而不是C418。
    • 只能在堡垒遗迹的战利品箱中发现。

下界合金盔甲
  • 不会烧毁，且会在熔岩中漂浮。
  • 具有比钻石盔甲更高的韧性。
  • 拥有比钻石盔甲更高的耐久度和更强的附魔能力。
下界合金斧、锄、镐、锹和剑
  • 拥有比钻石工具更高的耐久度和挖掘效率，也有更强的附魔能力。
  • 不会被熔岩烧毁，且会在熔岩中漂浮。
下界合金锭
  • 可由4个金锭和4个下界合金碎片合成获得。
  • 可用于升级钻石工具和盔甲。
  • 不会被熔岩烧毁，且会在熔岩中漂浮。
下界合金碎片
  • 可通过在熔炉中烧炼远古残骸获得。
  • 可用于合成下界合金锭。
  • 不会被熔岩烧毁，且会在熔岩中漂浮。
刷怪蛋
  • 加入了疣猪兽、猪灵、炽足兽以及僵尸疣猪兽的刷怪蛋。
猪鼻旗帜图案
  • 可以在织布机中将猪鼻图案添加到旗帜上。
  • 可在堡垒遗迹中发现。
诡异菌钓竿
  • 可由钓鱼竿和诡异菌合成。
  • 能够用于控制炽足兽，使用方法和使用胡萝卜钓竿控制猪的方法相似。
    • 骑乘炽足兽时手持诡异菌钓竿并使用（点击并长按）可以暂时提高移动速度，每次提速消耗其1点耐久度。
      • 拥有100点耐久。



生物
疣猪兽
  • 生成于绯红森林生物群系。
  • 与玩家敌对。
  • 版本独有：死亡后掉落2-4生猪排，有50%的概率掉落1皮革。
  • 有成年和幼年两种变种。
  • 可通过喂食绯红菌来繁殖。
  • 会主动远离诡异菌和僵尸疣猪兽。
猪灵
  • 生成于绯红森林和下界荒地生物群系。
  • 成年猪灵生成时会随机装备金剑或弩，偶尔还会装备金质盔甲。
  • 成年猪灵默认与玩家敌对，幼年猪灵呈被动状态。
    • 成年猪灵不会攻击穿着金制盔甲的玩家。
      • 如果玩家对猪灵发起攻击，或者当着它们的面挖掘金块、金矿石、下界金矿石或镶金黑石，打开或破坏箱子、陷阱箱、木桶、潜影盒或末影箱（无论其中装有何种物品），它们仍会被激怒。

  • 玩家可以使用金锭右键它们或把金锭扔在地上来和它们进行以物易物。
  • 在某些时候会攻击疣猪兽。
    • 幼年猪灵不会攻击疣猪兽，成年猪灵不会攻击幼年疣猪兽。
  • 幼年猪灵会骑在幼年疣猪兽的背上。
  • 成年猪灵会主动攻击凋灵骷髅。
  • 会远离灵魂火、灵魂火把、灵魂灯笼、灵魂营火、僵尸疣猪兽和僵尸猪灵。
  • 在主世界或末路之地中滞留一段时间后会转化为僵尸猪灵。
炽足兽
  • 生成于下界的熔岩海中。
    • 熔岩上方存在两格以上的空气才会生成。
    • 在熔岩外会打寒颤并变成暗紫色，面部表情稍微改变且移动速度减缓。[1]
  • 属于被动型生物。
  • 死亡后掉落0-5根线。
  • 可以装备鞍，需要使用诡异菌钓竿控制。
    • 在熔岩上乘骑的速度与在海上乘船的速度相似。
  • 接触水和雨时会受到伤害。
  • 具有幼年变种。
  • 可以通过喂食诡异菌繁殖。
  • 僵尸猪灵和幼年炽足兽有时会随之一同生成并骑在其身上。
    • 当生成僵尸猪灵炽足兽骑士时，炽足兽会携带鞍。
  • 幼年炽足兽有时会骑在成年炽足兽上。
僵尸疣猪兽
  • 疣猪兽的僵尸化变种。
  • 由在主世界或末路之地中滞留一定时间后的疣猪兽转化而来。
  • 与疣猪兽的特征不同，僵尸疣猪兽无法繁殖，也不会躲避诡异菌。
  • 攻击视野中的大多数生物，苦力怕和其他僵尸疣猪兽除外。
  • 死亡后掉落1-3腐肉。
  • 能够免疫火焰伤害。

世界生成
生物群系
  • 玄武岩三角洲
    • 下界的火山生物群系，像是火山爆发后的废墟，其中充斥着大面积的黑石和玄武岩柱，以及大片的熔岩和岩浆块。迷雾和颗粒呈灰色。
    • 岩浆怪、恶魂和炽足兽会在此生成。
    • 下界要塞会在此自然生成。
  • 绯红森林
    • 一种茂密的森林生物群系，绯红巨型菌会成片地在此生成。地面上有各种植物、菌类及其他方块，巨型菌类的树冠上还会生成垂泪藤。迷雾和颗粒呈红色。
    • 僵尸猪人、猪灵和疣猪兽会在此生成。
    • 版本独有：下界要塞会在此自然生成。
    • 堡垒遗迹会在此自然生成。
  • 灵魂沙峡谷
    • 一种空间开阔的洞穴生物群系，由大型玄武岩柱、下界化石、灵魂沙和灵魂土组成，灵魂火随处燃烧。迷雾和颗粒呈蓝色。
    • 骷髅、恶魂和末影人会在此自然生成。
    • 下界要塞和堡垒遗迹会在此自然生成。
  • 诡异森林
    • 绯红森林的异色变种，植被、颗粒和迷雾效果都与之略有不同。迷雾和颗粒呈紫色。
    • 只有末影人会在此生成。
    • 版本独有：下界要塞会在此自然生成。
    • 堡垒遗迹会在此自然生成。

结构
  • 玄武岩柱
    • 一种由玄武岩构成的、生成于灵魂沙峡谷生物群系的石柱结构，延连地面与天花板。
  • 堡垒遗迹
    • 生成在除了玄武岩三角洲以外的下界生物群系中。
    • 生成四种类型的结构：
      • 桥
      • 疣猪兽棚
      • 居住区
      • 藏宝室
    • 这是音乐唱片“Pigstep”的唯一来源。
    • 这是唯一可以自然生成含有远古残骸、下界合金碎片和下界合金锭的战利品箱的地方。
    • 猪灵和疣猪兽会在此生成。
  • 绯红巨型菌和诡异巨型菌
    • 新型树木结构，分别生成于绯红森林和诡异森林生物群系。
    • 枝干由绯红菌柄或诡异菌柄组成，树冠由下界疣块或诡异疣块组成，其上可能会生成几个菌光体。
    • 可由在菌类使用骨粉使之长成对应的巨型菌。
  • 下界化石
    • 一种灵魂沙峡谷生物群系特有的新型化石结构。
    • 与主世界中的化石结构不同，这类化石当中不会夹杂煤矿石。
  • 废弃传送门
    • 下界传送门的破碎残骸。
    • 在主世界和下界的任意生物群系中生成。
      • 生成时可能会在地下、水中或裸露在地面上。
    • 传送门框架附近会生成战利品箱，传送门框架上方会生成金块。
