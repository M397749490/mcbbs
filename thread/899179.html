标题: 更改游戏ID后怎么给已训服的狼换主人？
本帖最后由 22009988y 于 2019-8-8 21:19 编辑

我用别的id玩游戏（单人），结果狼（已训服）他不认主人了。于是我试着用：
  1. /execute as @e[type=minecraft:wolf] run data merge entity @s {Owner:Ecabc}
复制代码
↑这条指令进行修改，但是游戏显示修改成功，却没反应（狼坐着你点他他也不起来）
（指令什么的我也不会，我找遍了论坛也没有什么方法。）（游戏版本1.14.4）


作者: ⊙u⊙    时间: 2019-8-8 20:59
.minecraft\saves\<存档名>\playerdata

到达以上路径，能见到里面有玩家的UUID，复制那个值


回到游戏，执行
  1. execute as @e[type=wolf] run data merge entity @s {OwnerUUID:"刚才复制的值"}
复制代码


这是我的例子...
  1. execute as @e[type=wolf] run data merge entity @s {OwnerUUID:"42c66abc-a86d-4a80-af17-5563c805d4db"}
复制代码
作者: Chelover_C60    时间: 2019-8-8 21:13
随便说一句话，然后把鼠标放到你的名字上，可以在最下面一行看到你的UUID，然后输入以下命令即可
  1. /execute as @e[type=minecraft:wolf] run data merge entity @s {OwnerUUID:"<UUID>"}
复制代码

用你的UUID置换掉命令中的<UUID>即可
