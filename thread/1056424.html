作者: MC深坑不回头    时间: 2020-6-6 13:34
在1.14.4.jar\assets\minecraft\particles 里面将要套用的粒子图片改成一个自订图片:
更改ambient_entity_effect.json、effect.json内容
(假设你要放的粒子图档名叫做aaa)

{
  "textures": [
    "minecraft:effect_7",
    "minecraft:effect_6",
    "minecraft:effect_5",
    "minecraft:effect_4",
    "minecraft:effect_3",
    "minecraft:effect_2",
    "minecraft:effect_1",
    "minecraft:effect_0"
  ]
}

改为
{
  "textures": [
    "minecraft:aaa"
  ]
}


后将图片aaa放到textures\particle文件夹内即可。
