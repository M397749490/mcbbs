                                                                      ——sponge端的Vip插件


PixelVip是一个简单的插件，简单的配置方式和功能让你很好的管理Vip特点：
  • 与所有Sponge的API兼容，不需要寻找苦苦对照版本！（Sponge-Api:5/6/7/8)
  • 生成密匙，更加高效的自动化管理。
  • 允许多个Vip同时激活，玩家可以选择他需要先用什么Vip!
  • 时间计算是从激活的那一刻开始，而不是一天的开始！
  • 玩家激活密匙，还能自动输入指令！
  • 所有内容都是可翻译的！
  • 自由操控玩家的Vip，随时都能检查玩家的Vip
  • 兼容超多的权限插件，只要修改指令即可！
  • Tab一键输出全组的名称，不需要每次都打完权限组名称
  • 功能与Spigot/Bukkit同步！

指令和权限(Command) or (Permission)

提醒: []为必须选择，{}为可选项目
  • 指令：/usekey [密匙] —— 使用已经生成的key密匙
  • 指令别名：/usarkey
  • 权限【pixelvip.cmd.player】


  • 指令：/viptime {玩家} —— 查看Vip到期时间
  • 指令别名：/tempovip
  • 权限【pixelvip.cmd.player】
  •       【pixelvip.cmd.player.others】（查看其他人的Vip到期时间）


  • 指令：/changevip [权限组] —— 更改目前的Vip等级(提前是已经激活了多个Vip)
  • 指令别名：/changevip，/trocarvip
  • 权限【pixelvip.cmd.player】

  • 指令：/newkey [权限组] [时间] {个数} —— 生成新的密匙
  • 指令别名：/gerarkey
  • 权限【pixelvip.cmd.newkey】

  • 指令：/newitemkey [cmd1，cmd2，...] —— 创建一个新密匙并给密匙添加新的指令
  • 指令别名：/newikey, /gerarikey
  • 权限【pixelvip.cmd.newitemkey】

  • 指令：/additemkey [key] [cmd1, cmd2, …] —— 给现有的密匙添加新的指令
  • 指令别名：/addikey
  • 权限【pixelvip.cmd.additemkey】

  • 指令：/delkey [密匙] —— 删除密匙
  • 指令别名：无
  • 权限【pixelvip.cmd.delkey】

  • 指令：/listkeys —— 列出所有可用的密匙
  • 指令别名：无
  • 权限【pixelvip.cmd.listkeys】

  • 指令：/removevip [Vip玩家] {权限组} —— 删除玩家的Vip（如权限组不填，则删除最新激活的Vip）
  • 指令别名：/delvip
  • 权限【pixelvip.cmd.removevip】

  • 指令：/addvip [玩家] [权限组] [天数] —— 给玩家添加一个Vip
  • 指令别名：/givevip，/darvip
  • 权限【pixelvip.cmd.addvip】

  • 指令：/setvip [玩家] [权限组] [天数] —— 设置玩家的Vip情况
  • 指令别名：无
  • 权限【pixelvip.cmd.setvip】

  • 指令：/pixelvip reload —— 重载插件
  • 权限【pixelvip.cmd.pixelvip】

论如何使用其他的权限插件（必点）

由于Sponge开始之初，权限插件非常多
就导致了现在Sponge的权限插件是割据天下，每个服务器的权限插件都不一定相同
再加上本插件的设置问题，所以造一个：如何使用其他的权限插件

在pixelVip.conf中，下面这段就是设置的方法
  1. configs {
  2.     # 取消玩家Vip时运行的指令.
  3.     cmdOnRemoveVip="pex user {p} parent delete group {vip}"
  4.     # 权限插件的重载指令.
  5.     cmdToReloadPermPlugin="pex reload"
  6.     # 玩家使用指令更换他的Vip组时权限插件触发的指令.
  7.     # Variables: {p} 玩家名称, {newvip} 新选择的权限组, {oldvip} 原来的权限组.
  8.     commandsToRunOnChangeVip=[
  9.         "pex user {p} parent add group {newvip}",
  10.         "pex user {p} parent delete group {oldvip}"
  11.     ]
  12.     # 玩家Vip过期时运行的指令.
  13.     # Variables: {p} 玩家名称, {newvip} 新选择的权限组, {playergroup} 玩家的默认权限组
  14.     commandsToRunOnVipFinish=[
  15.         "pex user {p} parent delete group {vip}",
  16.         "pex user {p} parent add group {playergroup}"
  17.     ]
  18.     # Vip密匙的长度.
  19.     key-size=10
复制代码
一个一个讲：
首先你需要了解你的权限插件中的指令，然后再来这里
①cmdOnRemoveVip这个是使用指令[/delvip]删除该玩家Vip的选项
在这里，你需要填的是如何删除玩家的Vip组
②cmdToReloadPermPlugin插件的重载指令
你需要把插件的重载指令填上去，因为本插件会经常需要重载插件，为了安全，也需要重载权限插件
③commandsToRunOnChangeVip更换权限组
如果你的服务器有土豪玩家，一次性开通了几个Vip，那么他就需要更换Vip了
在什么时候选择什么Vip，第一行填上的是新的Vip设置，就是让玩家添加到新的权限组，第二行填上删除Vip，就是将玩家从旧的用户组中删除
④commandsToRunOnVipFinishVip过期
这里是设置Vip过期的方法
第一行就是将玩家从现有的Vip组给删除
第二行就是让玩家还原到默认的权限组中

请记住，第一行和第二行尽量不要互换，你是可以添加第三行一类的。
