安装以后打开配置文件
dungeonChest.json
找到这段
  1. {
  2.       "item": "IC2:itemOreIridium",
  3.       "damage": 0,
  4.       "weight": 20,
  5.       "count_min": 1,
  6.       "count_max": 2
  7.     },
  8.     {
  9.       "item": "IC2:itemShardIridium",
  10.       "damage": 0,
  11.       "weight": 100,
  12.       "count_min": 6,
  13.       "count_max": 14
  14.     },
复制代码


修改里面的count_min和count_max到想要的数值
都改成0就是彻底不生成

理论来讲改掉地牢箱子就好
如果你想要彻底改的话
可以选择把
strongholdCorridor.json
strongholdCrossing.json
这两个文件里面的相同代码进行同样的修改

然后保存重启游戏就好
