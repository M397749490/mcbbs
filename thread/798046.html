761070659 发表于 2018-6-7 23:42
不同耐久不同材质，然后是替换穿身上的装备 而不是拿在手上的

拿在手上和穿身上实现方式没差别……

在资源包中建立文件 assets\minecraft\models\item\diamond_chestplate.json
  1. {
  2.     "parent": "item/generated",
  3.     "textures": {
  4.         "layer0": "items/diamond_chestplate"
  5.     },
  6.     "overrides": [
  7.         { "predicate": { "damage": 0.000000000 }, "model": "item/diamond_chestplate"},
  8.         { "predicate": { "damage": 0.038461538 }, "model": "item/chestplate1"},
  9.         { "predicate": { "damage": 0.076923077 }, "model": "item/chestplate2"},
  10.         { "predicate": { "damage": 0.115384615 }, "model": "item/chestplate3"},
  11.         { "predicate": { "damage": 0.153846154 }, "model": "item/chestplate4"}
  12.     ]
  13. }
复制代码
然后在同一文件夹下建立文件chestplate1.json, chestplate2.json 等等
  1. {
  2.     "parent": "item/generated",
  3.     "textures": {
  4.         "layer0": "custom/chestplate1"
  5.     }
  6. }
复制代码
然后在 assets\minecraft\textures\custom文件夹中放入chestplate1.png等材质文件即可。
使用时
  1. give @s diamond_chestplate 1 1 {Unbreakable:1b}
复制代码
即可
