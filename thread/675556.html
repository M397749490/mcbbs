Minecraft 模组下载器
这是一个模组下载器，有搜索、安装功能（由于下载链接过于复杂，有的是网盘，有的又是直接下载，因此这一部分任务交给了用户）。
功能
  • 自动搜索（使用Bing的site语法）
  • 自动获取下载链接（BeautifulSoup解析）
  • 自动安装

安装

注：安装操作为新手编写；老司机请直接安装 Python 3 、从 pip 安装 Colorama 包、下载本程序然后查看本帖的“用法”部分
  • 安装 Python 3 环境（开发时使用 Python 3.6.0）

    • 打开 Python for Windows 官方下载页，进入最新 Python 3 下载页
    • 拖到页面底部，根据系统版本选择相应文件下载
    • 运行下载到的文件（应该是“python-3.*.*.exe”或“python-3.*.*-amd64.exe”这样的，取决于你的操作系统版本；目前主流为64-bit，即amd64）
    • 在界面中先勾选“Add Python 3.6 to PATH”，然后单击“Customize install”
    • 出现第二个界面时， Next 过去；然后这么做：
    • 等待安装完成，然后 Close 窗口
  • 下载本程序
    到GitHub （更新最快）或者度盘（更新可能有延迟）下载，并解压到你想要的目录
  • 安装支持库

    • 按 Win+R ，启动“运行”对话框
    • 输入 cmd 并回车
    • 输入以下命令：
      1. python -m pip install colorama
      复制代码


用法
  • 运行“setup.py”，输入游戏路径以及下载路径，生成配置文件
  • 运行“main.py”，依照程序提示进行操作
