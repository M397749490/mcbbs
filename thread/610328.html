本地图只能在1.10版本下游玩。
史蒂夫被暗杀了，你的任务是打败暗杀史蒂夫的人，但是他逃到了一个拥有邪恶怪兽，极其危险的地方...
这是我的第一张冒险地图。你的旅途从这里开始。
游戏规则 Game Rules
在视频设置中，你必须将视野距离调为9 Chunks或以上，我推荐把亮度调为最亮。不要安装能够影响游戏游玩的mod，如果需要向局域网开放，把所有人都设为冒险模式并取消作弊。在服务器游玩请确定打开命令方块。

玩家数量：1~4
游戏时间：6~8小时
游戏版本：1.10
游戏特性 Features
值得注意的特性：

  • 大量的自定义生物和战利品
  • 难以置信的挑战和解密
  • 紧张的BOSS战斗和剧情
  • 经验商店
  • 史诗般的剧情
在1.10：

  • 难度设置
  • 难度随玩家数量变化
  • 自定义掉落物
