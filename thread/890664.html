你大概是看了我的某个回复才这么问的吧。
首先：那个 AT 只是去掉了某个方法的 final 允许你覆写那个方法。
你既然说“是原版实体”，那你就应该意识到不能生搬硬套了——因为你并不控制原版的实体的代码。

控制最大生命值的 SharedMonsterAttributes.MAX_HEALTH 在原版中是个 RangedAttribute，1024.0D 的上限也源于此。那么：
  1. public-f net.minecraft.entity.ai.attributes.RangedAttribute field_111118_b #maximumValue
复制代码

然后
  1. IAttribute maxHealth = SharedMonsterAttributes.MAX_HEALTH;
  2. if (maxHealth instanceof RangedAttribute) {
  3.   ((RangedAttribute)maxHealth).maximumValue = Double.POSITIVE_INFINITY;
  4. }
复制代码
