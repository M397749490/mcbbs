安装方法：（必看）

1、放置命令方块
2、在命令方块内输入指令（Ctrl+C 复制，Ctrl+V粘贴）
3、激活此命令方块

1.在较低位置摆放这样一个东西（玻璃上方需放置方块，任意方块即可）

注意事项


千万不要在一般的铁块上跳跃，否则导致的失控，概不负责




常见问题



1.Q：上升过程中失控了怎么办？
   A： 聊天栏中输入
  1. /scoreboard players set @a up 0
复制代码

2.Q:   下降过程中失控了怎么办？
   A:    聊天栏中输入
  1. /scoreboard players set @a down 0
复制代码
3.Q：不想用这个mod了，该怎么删除？
   A： 换成创造模式，拆除所有命令方块
  PS：如果想要删除本mod所添加的记分版，请依次输入以下4条指令
  1. /scoreboard objectives remove A
  2. /scoreboard objectives remove B
  3. /scoreboard objectives remove up
  4. /scoreboard objectives remove down
复制代码





已知BUG


1.在一般铁块上跳跃作死，导致失控后输入/scoreboard players set @a up 0后在石英上跳跃仍会上升失控
解决方法：输入

  1. /scoreboard players set @a A 0
