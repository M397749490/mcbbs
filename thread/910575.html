>>如何食用它呢?

"通过任意权限插件赋予权限节点,使玩家具有属性"

>>详尽一点..?
<第一步>
在配置中加入对应权限所对应的的属性，然后通过/sx-talent 重载配置(记得保存)
<第二步>
用你所使用的权限管理插件，给予对应玩家相对应的权限节点，
<第三步>
玩家重进服务器，或者/sx-talent refresh ID 刷新属性，玩家即可拥有对应的属性(天赋)
>>命令列表，以及权限...?
  1. 基础命令列表:
  2.   /sx-talent reload : 重载插件
  3.   /sx-talent refresh ID : 刷新某玩家的属性
  4. 呐呐呐,,,权限呢..?
  5.   指令默认op可以执行
复制代码
>>配置文件:
  1. test_sx:
  2. - '攻击力: 10000'
  3. - '闪避几率: 100%'
  4. #对应权限节点: test.sx
