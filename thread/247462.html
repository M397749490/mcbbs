那从等级开始写好了

等级的话...
其实就是很简单的计分板
【话说之前在论坛很少见过有人用计分板- -】

先来一个记录杀敌数量的变量 就叫exp好了
  1. /scoreboard objectives add exp totalKillCount 经验值
复制代码
再来记录等级的 这个用dummy就好
  1. /scoreboard objectives add lvl dummy 等级
复制代码
其实这两个就够用了
比如到5经验就到一级,再来8经验到2级
  1. /scoreboard players set @a[score_exp=4] lvl 0
  2. /scoreboard players set @a[score_exp_min=5,score_exp=12] lvl 1
  3. /scoreboard players set @a[score_exp_min=13] lvl 2
复制代码
再弄个脉冲不断激活三个命令方块
像这样



经验与等级需要显示~
  1. /scoreboard objectives setdisplay list exp
  2. /scoreboard objectives setdisplay sidebar lvl
复制代码
这里把经验放在tab列表
等级放在侧边栏【侧边栏最多显示16玩家，不然会消失】【可以弄成只显示在线玩家~各位少年可以想想如何做到~】

然后等级高了还得有效果吧？
  1. /effect @a[score_lvl_min=1] 11 1 0
  2. /effect @a[score_lvl_min=2] 5 1 0
复制代码
像这样【一级获得抗性提升1】【二级获得力量一】



黄色的是上面的三个命令
蓝色的是增加效果的两个命令

基础的等级功能就建好了！

下面是扩展的等级功能
比如杀玩家增加经验数量多？
先建一个以杀玩家为判据的变量
  1. /scoreboard objectives add playerkill playerKillCount
复制代码
然后 命令方块
  1. /scoreboard players add @a[score_playerkill_min=1] exp 4
  2. /scoreboard players set @a[score_playerkill_min=1] playerkill 0
复制代码
这样的话杀死一个玩家会增加5点经验[4+1]

这样



然后死亡减经验？
先建一个以死亡为判据的变量
  1. /scoreboard objectives add death deathCount
复制代码
然后 命令方块
  1. /scoreboard players remove @a[score_death_min=1] exp 1[黄]
  2. /scoreboard players set @a[score_death_min=1] death 0[蓝]
复制代码
这样死一次减1经验

和上面的差不多
