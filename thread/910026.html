标题: [管理|安全]TnTRegen——让被炸掉的方块重生[1.13-1.14.x]



这款插件可以使被实体(tnt 苦力怕 凋零头 火焰弹)爆炸破坏的方块重生，可自定义重生方块、重生种类、重生时间。官方仅测试支持1.13-1.14.x，其他版本有待确认。


效果图: (3.5M sm.ms图床):


  1. The TnTRegen plugin will allow blocks that were destroyed from any entities that can explode such as TnTs, Creepers, Withers, Wither Skulls, & Fireballs from Ghasts to be able to regenerate. Easy to configure & no need to reload after doing a value change (With the exception of the "enablePlugin" value). Designed on 1.13, supports 1.14.
复制代码


配置文件英-中对照:

1.blocks.yml:(仅截取一部分，剩余部分同理)

  1. acacia_button:       #方块
  2.   doPreventDamage: false       #是否防爆
  3.   regen: true        #爆炸破坏后是否重生
  4.   replace:     
  5.     doReplace: false        #是否重生替换，如果为true，则重生replaceWith所选择的方块。
  6.     replaceWith: acacia_button     #doReplace的子项，选择重生为什么方块。

  1. The "enable-Regen", "delay-", & "period-" values are not to be confused with block regen in general. These values are used for if a new MC update were to introduce a new entity type that can explode were to explode, the plugin will recognize & save that entity type to the config file to be able to configure that new explosion type's delay value, period value, and either to enable or disable the regen option for that explosion.

  3. Changes made to a value will automatically take into affect. No need to reload. The exception to this is "enablePlugin" which will require a plugin reload.
  4. enablePlugin (Value = boolean, Default: true)
  5. If set to false, the plugin will be set to be disabled on plugin load.
