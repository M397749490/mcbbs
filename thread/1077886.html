仔细想了下是有解决方案的
你需要的全部记分板：记录效果等级的buff，buff_0~buff_7 和 temp

  1. scoreboard players set #2 temp 2
  2. execute as @a run scoreboard players operation @s temp = @s buff
  3. execute as @a run scoreboard players operation @s buff_0 = @s temp
  4. execute as @a run scoreboard players operation @s buff_0 %= #2 temp
  5. execute as @a run scoreboard players operation @s temp /= #2 temp
  6. execute as @a run scoreboard players operation @s buff_1 = @s temp
  7. execute as @a run scoreboard players operation @s buff_1 %= #2 temp
  8. execute as @a run scoreboard players operation @s temp /= #2 temp

  14. execute as @a run scoreboard players operation @s temp /= #2 temp
  15. execute as @a run scoreboard players operation @s buff_4 = @s temp
  16. execute as @a run scoreboard players operation @s buff_4 %= #2 temp
  17. execute as @a run scoreboard players operation @s temp /= #2 temp
  18. execute as @a run scoreboard players operation @s buff_5 = @s temp
  19. execute as @a run scoreboard players operation @s buff_5 %= #2 temp
  20. execute as @a run scoreboard players operation @s temp /= #2 temp
  21. execute as @a run scoreboard players operation @s buff_6 = @s temp
  22. execute as @a run scoreboard players operation @s buff_6 %= #2 temp
  23. execute as @a run scoreboard players operation @s temp /= #2 temp
  24. execute as @a run scoreboard players operation @s buff_7 = @s temp
  25. execute as @a run scoreboard players operation @s buff_7 %= #2 temp
  26. execute as @a if score @s buff_0 matches 0 run attribute @s generic.attack_damage modifier remove 0-0-0-0-0
  27. execute as @a if score @s buff_1 matches 0 run attribute @s generic.attack_damage modifier remove 0-0-0-0-1

  34. execute as @a if score @s buff_0 matches 1 run attribute @s generic.attack_damage modifier add 0-0-0-0-0 loy 3 add
  35. execute as @a if score @s buff_1 matches 0 run attribute @s generic.attack_damage modifier add 0-0-0-0-1 loy 6 add
  36. execute as @a if score @s buff_2 matches 0 run attribute @s generic.attack_damage modifier add 0-0-0-0-2 loy 12 add
  37. execute as @a if score @s buff_3 matches 0 run attribute @s generic.attack_damage modifier add 0-0-0-0-3 loy 24 add
