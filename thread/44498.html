透视mod也更新到1.3.2了作者们都好快
嗯 简单介绍一下
主要的功能当然是透视地层啦
视图开关介绍
X = 开启透视（让你透过泥土和石头）
R = 与上一个不同的是它看见的矿物只有红石矿
B = 让视野保持明亮
C = 透视寻找洞穴
P = 可以像蜘蛛那样爬墙（垂直的哦）
N = 消除掉落伤害，在灵魂沙上行走不减速

2.将压缩包内文件丢入minecraft.jar内
3.开始游戏
