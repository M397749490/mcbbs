震惊！一个未成年人竟然用“U盘”玩Minecraft
1. 开头说两句
这里的U盘，并不是指储存的那种USB设备，而是一种开发板叫做Arduino，这种东西能和Minecraft擦出什么火花（基情）呢？

前期准备：
  • 一个arduino开发板（我的是327大洋的arduino leonardo）
  • arduino开发IDE
  • Minecraft

而这篇文章呢，就是教大家如何用开发板来玩Minecraft

2. 开始搞事！
首先，我们得打开我们的Minecraft


再打开我们的
IDE

经过我的发现，这个开发的IDE也是用Java开发的，果然Java大法无处不在！

看到这里，肯定有很多大佬会问？

“你这些有什么用呢，我该如何去玩！”

那我这次呢，就写一个可以自动打开聊天框输出“2333”（弱鸡）



3. 开始写代码！

那我先普及一下Arduino的基本语法

默认生成的Setup类是第一次插♂入时运行的代码

而loop则是重复运行的代码！

那我们让他执行一些操作，就像这样！

  1. #include <Keyboard.h>
  2. void setup() {
  3.   //第一次加载时做
  4.   Keyboard.begin();//开始键盘通信
  5.   delay(1000);
  6.   Keyboard.press(KEY_RETURN);  //按下回车键
  7.   Keyboard.release(KEY_RETURN); //释放回车键
  8.   delay(1000);//延时1000毫秒，不要太短，因为每天电脑的运行速度都不一样
  9.   Keyboard.println("2333");//模拟键盘输出2333
  10.   delay(1000);
  11.   Keyboard.press(KEY_RETURN);  //按下回车键
  12.   Keyboard.release(KEY_RETURN); //释放回车键
  13. }

  15. void loop() {
  16.   //重复做

  18. }
复制代码

这段代码会模拟键盘输出2333，但是却不能在MC里说出来。

为什么呢？

因为你还要模拟按键啊！

在我们arduino的扩展库里，模拟按键大概是这样的

  1. Keyboard.press('t');//按下t键
