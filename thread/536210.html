①介绍:

需要一个简单快捷的组队插件吗?
让这个插件成就你的梦想~


②特性

组队聊天
队伍在线玩家GUI面板
和更多的特性...

③指令
/party - 指令帮助
/party create <name> - 创建一个队伍
/party info - 关于队伍的信息
/party status - 队伍在线玩家信息
/party invite <player> -邀请其他人来你的队伍
/party leave - 离开你的队伍
/party chat - 切换队伍聊天
/party kick <player> - 从你的队伍中将人踢出
/party promote <player> - 提升玩家在队伍内的等级
/party demote <player> - 降低玩家在队伍内的等级
/party rename <name> - 为你的队伍改名
/party disband - 解散你的队伍
/party version - 插件版本

④没有配置文件和权限

⑤使用这个插件需要用到作者的前置插件
地址

⑥等级
等级 (特殊权限) :
Leader : 可以做任何事情
Manager : 可以踢人
Member : 无
