今日知识

题目要求：
计算1~100所有奇数的和
    1 + 3 + 5 + 7 + 9....+ 99

运算符 += 就是专门完成追加的

编写代码
  1.         //定义一个变量【盒子】，初始值为0
  2.         int sum = 0;

  4.         for(int i = 1;i <= 100;i += 2) {
  5.             //i一定是奇数
  6.             //累加求和
  7.             //System.out.println("i --> " + i);

  9.             //sum存储的是最终求和的结果
  10.             //不能每一次执行到这里，都把求和结果归零
  11.             //定义sum变量不能放到这里，因为这里是循环体。
  12.             //int sum = 0;

  14.             sum += i;
  15.         }

  17.         //以上的for循环结束之后，最终输出求和的结果
  18.         System.out.println("sum = " + sum);
复制代码
第二种
  1.         //归零
  2.         sum = 0;

  4.         for(int i = 1;i <= 100;i++) {
  5.             if(i % 2 != 0) { //是奇数
  6.                 sum += i; //则积累加求和
  7.             }

  9.         }
  10.         System.out.println(sum);
