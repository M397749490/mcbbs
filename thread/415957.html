配置文件编辑插件(ConfigEdit)是一个轻量级的水桶插件，它提供了一个简单的指令来编辑其他插件的配置文件(config.yml)。如果你疲于用NotePad(有的还得用FTP一遍遍下载上传)来修改插件的配置文件，这个插件就是为你而生的。

Comand|指令
ConfigEdit只有一个简单的，方便的语法来编辑其他配置文件：

  • /edit theplugin the.key:value otherconfig

其中:

  • "theplugin" 需要修改的配置文件所在的文件夹名字(通常就是插件的名字)，在这个例子中该文件夹路径是：plugins/theplugin.
  • "the.key:value" 是配置文件中的关键字以及将要被编辑的内容(值)，所以在配置文件中，它看起来像是这样：
    1. the:
    2.   key: value
    复制代码
  • "otherconfig" 是被修改配置文件的名字。如果这个字段你没有指定，那么ConfigEdit会将它默认为"config"


你也可以设置配置文件中的列表，举个例子：

  • /edit theplugin the.key:value1,value2,value3 otherconfig
  • 在配置文件中它看起来是这样的：
    1. the:
    2.   key:
    3.   - value1
    4.   - value2
    5.   - value3
    复制代码



如果你想要在已经存在的配置中添加变量，可以使用如下语句：

  • /edit theplugin the.key:+value4,value5,value6 otherconfig



  • 它看起来应该是这样的：
    1. the:
    2.   key:
    3.   - value1
    4.   - value2
    5.   - value3
    6.   - value4
    7.   - value5
    8.   - value6
    复制代码



如果你想移除变量1、2、3，你可以：

  • /edit theplugin the.key:-value1,value2,value3 otherconfig
  • 之后配置文件中会是这样的：
    1. the:
    2.   key:
    3.   - value4
    4.   - value5
    5.   - value6
    复制代码



如果你想把the.key全删了，只要输入null：

  • /edit theplugin the.key:null otherconfig

Permissions|权限
ConfigEdit 只有一个权限
  • configedit.command

Metrics
这个插件采用了 Hidendra's plugin metrics system，它意味着以下信息将被收集并发送至mcstats.org
  • 一个独有的编号
  • 服务器的JAVA版本
  • 服务器是否Online模式(即只有正版玩家才能登录的模式)
  • 插件的版本
  • 服务器的版本
  • 操作系统的相关信息
  • CPU的相关信息
  • 在线的玩家数量
  • Metrics的版本

你可以通过将 plugins/Plugin Metrics/config.yml 中的 opt-out 设置为 true 来阻止该动作的发生。


备注：
作者注明游戏版本只有CB 1.7.9-R0.1/R0.2，但据我实测1.7.x均可使用，暂未发现任何bug.
