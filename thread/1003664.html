Paintings ++
为mc添加更多的画

简介
欢迎使用Paintings ++！
7.0.0.0已发布，虽然1.14.4版本以后Minecraft支持将单个图像添加至游戏但是Paintings ++直接抓住了机会，使添加大量的画变成可能，并且对于普通人来说比较简单！

Paintings ++能做什么
添加任何你想添加的画
  • Paintings ++是基于已经停更了很久的 MorePaintings mod进行接坑并重新编译的
  • Paintings ++一直追求着在游戏多添加尽可能多的图像
  • 虽然1.14.4原版仅仅就只能这样做了
选择你想要的画
本模组除了可以在游戏中添加大量绘画，您还可以通过单击按钮选择你想要的图片

图片


搬运授权


如何在游戏中添加你想要的图片？
该教程适用于1.14及更高版本,你可以访问作者的代码库获取绘画模板
在添加时你将需要这两个东西：
  • 你需要一个装满你想添加的图片的资源包
  • 在模组新生成的文件夹中的json文件
第一步：至少启动一次游戏以生成一个名为“paintings”的文件夹,文件夹中包含着一个控制绘画图片的基础的json文件
Making your ResourcePack-制作你的材质包
第二步：阅读有关如何制作一个材质包的教程
  • 你的resourcepack文件夹结构将如下所示：
     * asset / paintings / textures / painting
  • 在绘画文件夹中放置你想要png图片
（注：确保图片的像素点个数是16的倍数！不要忘记编辑你的pack.mcmeta文件！为了让材质包更好看一些,也不要忘记编辑你的pack.png文件！）
Making your JSON painting register-使用json文件注册你的画像图片
在模组生成的“paintings”文件夹中的json文件必须有以下格式：
{ "paintings" : [{ "name" : "texture_name_here", "x" : 16, "y" : 32 }, { "name" : "texture_name_here_for_other_painting", "square" : 64 }] }
你可以用json解析器来分析你的json文件有没有错误
  • 每一项都代表着一张画
  • name项应该填写图像文件的名称，在我们示例的resourcepack文件中就有一张名为lagune.png图片
  • 你可以改变“x”和“y”的值以定义画的形状
  • 或者你可以写入"square"使用正方形作为画的形状

   {"name" : "abstract_rainbow","square" : 16}
完成：
  • 将你的资源包文件放入resourcepack文件夹
  • 将你的json文件另存入paintings文件夹中（就是resourcepack文件夹旁边那个）

点击启动游戏，如果你至今为止做的一切完全正确，那么你的画就在那儿！


绘画资源包
你制作了一个资源包？并想把它分享出来？你可以在curseforge中上传你的资源包
并向本模组的评论区评论，本模组的作者将会把你的资源包贴在模组贴中
Oliver Remund Painting Pack
由Subaraki（本模组作者）与艺术家Oliver Remund达成协议制作的绘画包
https://www.curseforge.com/minecraft/texture-packs/oliver-remund-painting-pack
你可以在Remund的网站上查看图片的原始画作
