圈地指令~~~~~~~
作者: 恋    时间: 2019-1-13 21:44
RES
  1. /res ? —— 查看帮助
  2. /resadmin —— 管理员专用指令，当指令用/resadmin代替/res时，指令不考虑权限问题。
  3. select - 选取命令，选择以你为中心的一部分地方【使用方法：/res select [x] [y] [z]】
  4. create - 创建领地，创建一个属于你自己的领地【使用方法：/res create [领地名]】
  5. remove - 删除领地，删除一个你已经有了的领地【使用方法：/res remove <领地名>】
  6. rename - 修改名称，修改一个领地的名称【使用方法：/res rename [旧领地名] [新领地名]】
  7.               - 【注意：如果你需要重命名子领地，必须使用全名称(主领地.子领地),而新名称不用使用全名称。】
  8. padd - 给一个玩家基本的权限，【使用方法：/res padd <领地名> [玩家ID]】
  9. pdel - 删除一个玩家的基本权限，【使用方法：/res pdel <领地名> [玩家ID]】
  10. info - 查看一个领地的信息，【使用方法：/res info <领地名>】
  11. set - 为领地设置默认权限，【使用方法：/res set <领地名>】
  12. pset - 为某玩家设置该领地的权限，【使用方法：/res pset <领地名> [玩家] [权限] [true/false/remove]】
  13. tpset - 设置领地的传送点【使用方法：/res tpset】
  14. tp - 传送到一个领地【使用方法：/res tp [领地名]】
  15. rt - 随机传送到当前世界的位置【使用方法：/res rt】
  16. rc - 加入当前领地的聊天频道【使用方法：/res rc [领地]】
  17. expand - 向你当前位置扩展多少领地范围【使用方法：面对扩展面输入/res expand <领地名> [扩展格数]】
  18. contract - 向你当前位置缩减领地范围【使用方法：/res contract <领地名> [缩减格数]】
  19. subzone - 在领地内创建一个子领地【使用方法：领地内选择区域，输入/res subzone <领地名> [子领地名]】
  20. message - 设置当前领地 进入/退出 的信息【使用方法：/res message [enter/leave] [信息]】
  21. lease - 管理领地Zu约【使用方法：/res lease [renew/cost] <领地名>】
  22. bank - 创建领地商店【使用方法：暂无（如有精通者，可教我否?)】
  23. list - 显示某个玩家的领地【使用方法：/res list <玩家ID>】
  24. kick - 将一个玩家飞出你的领地【使用方法：/res kick [玩家ID]】
