概览
这个插件可以让玩家使用经验来获取技能点. 然后他们可以将这些技能点分配给他们的技能. 现在可用的技能有: 力量, 暴击, 抗性, 箭术, 生命.
上述每个技能的百分比属性都是可以自定义的.


技能
Strength(力量) - 增强玩家的攻击力
Criticals(暴击) - 增强玩家的暴击伤害
Resistance(抗性) - 抵御/减少 即将到来的伤害
Archery(箭术) - 影响弓箭的伤害与击退效果
Health(生命) - 提高玩家生命值

命令
/skills 或 /skill - 打开技能菜单
/skillsadmin 或 /skilladmin - 查看管理员帮助

API
注意: 可能会有BUG
  1. import me.fatpigsarefat.skills.PlayerSkills;
  2. import me.fatpigsarefat.skills.utils.Skill;
  3. import me.fatpigsarefat.skills.utils.SkillManager;

  5. public void method (Player player) {
  6.       SkillManager sm = PlayerSkills.getSkillManager(); // getter
  7.       sm.setSkillPoints(player, sm.getSkillPoints(player) + 1); // 设置玩家技能点
  8.       int archeryLevel = sm.getSkillLevel(player, Skill.ARCHERY); // 获取玩家箭术等级  Skill为枚举类型
  9. }
