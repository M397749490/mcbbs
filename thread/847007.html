一款简单便捷的登陆提示插件
当前版本：1.9.3  作者：zarotli


授权搬运


插件特色

  • 占位符和emojis
  • 登入服务器提示和退出服务器提示
  • 首次登陆提示
  • 首次登陆提示标题和副标题
  • 首次登陆MOTD＆登陆MOTD（多行）
  • 登陆信息显示排名和音乐
  • 重载命令＆BJ重新加载
  • PlaceHolderAPI支持
  • 登陆音乐
  • 可完全自行配置
  • 游戏内可编辑

PlaceHolderAPI


%total% = the number of total new playersthat was in the server


%player% = name of the player

权限

BJ.RANK1  -  12 =登入＆退出信息排行

BJ.ADMIN = / BJ reload＆/ BJ Command

/ bj - 显示所有命令

[size=14.6667px]/ bj reload - 重新加载config

[size=14.6667px]/ bj motdmessage - 显示motd消息
[size=14.6667px]
/ bj firstmotdmessage - 显示第一个motd消息
