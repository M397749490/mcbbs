标题: 怎么生成有主人的末影珍珠
版本：1.14.4
如题
生成的末影珍珠没有传送功能
想让生成的末影珍珠能传送人

作者: Chelover_C60    时间: 2019-11-16 21:35
先生成末影珍珠，然后借助data modify来修改其nbt来指定其主人（假设其主人拥有owner标签）
  1. summon minecraft:ender_pearl ~ ~1 ~ {Tags:["mark"]}
  2. data modify entity @e[type=minecraft:ender_pearl,tag=mark,limit=1] owner.L set from entity @a[tag=owner,limit=1] UUIDLeast
  3. data modify entity @e[type=minecraft:ender_pearl,tag=mark,limit=1] owner.M set from entity @a[tag=owner,limit=1] UUIDMost
