简介：
XiaoEnchant是一款可通过指令/UI对任意物品强制附魔的插件
并且支持自定义附魔强化

功能  ：
   命令/UI 强制附魔
   UI提供自定义附魔等级
   提供了更便捷的物品设置功能
   UI自定义强化附魔 (目前只支持nk1 nk2前置暂时没有兼容nk2)
   支持强化爆炸/强化保护/强化掉级 （有点内味了~）

常见问题:

1.nukkit2.0 无法使用强化功能和强化相关的任何指令:
- 由于前置插件EconomyAPI 暂时未支持2.0版本 所以强化所需api无法使用 暂时//了强化内容的代码
2.由于nk2各个版本改动较大 所以推出了Lite版本 去除了Window与其他强化类功能
- 若您的Nk2服务器无法使用正式版1.1.0 请尝试使用lite版本

部分问题解决方法与强化系统帮助


1.从旧版本1.0.x升级至1.1.0


由于老版本未考虑到config lang等配置文件的更新问题,导致更新插件版本后无法自动补全

请手动删除配置文件重新生成

另外,请勿私自修改配置文件中的version 否则会出现白给现象



2.如何增加其他附魔强化和增加附魔强化物品


增加其他附魔强化

  1.   Ench-0:
  2.     #成功率 50% (1-100)% 小于等于0认为成功率为0 大于100将认为是100%成功
  3.     Probability: 50
  4.     #强化需要金额
  5.     Money: 666
  6.     #强化最大等级
  7.     Max: 32767
  8.     #强化爆炸 Boom！！！
  9.     Explosion:
  10.       #是否启用爆炸
  11.       Enable: true
  12.       #爆炸等级 （当强化该附魔 大于设定值时 失败概率爆炸） [举个栗子:卢某某 手中附魔等级为10 当他再次强化时就有可能爆炸]
  13.       level: 10
  14.       #爆炸概率(1-100)%
  15.       Probability: 20
  16.       #爆炸是否普天同庆~（玩家内心MMP）
  17.       Announcement: true
  18.     #强化成功后触发公告
  19.     Announcement:
  20.       #是否启用公告
  21.       Enable: true
  22.       #当强化值 大于等于该设定时 触发
  23.       level: 10
  24.     Fail:
  25.       #是否启用失败掉级
  26.       Enable: true
  27.       #当大于等于该设定时 失败将掉级/不变
  28.       Level: 5
  29.       #掉级概率(1-100)%
  30.       Probability: 50
  31.       #随机掉0-2级
  32.       Drop:
  33.         Min: 0
  34.         Max: 2
  35.     #可强化的物品/武器/装备 ID
  36.     List:
  37.       - 276
