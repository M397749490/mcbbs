作者: ZKILLA    时间: 2014-1-6 16:16
不太清楚具体原因，不过你可以试着做下面的处理
1：确定你的JAVA版本，如果64位电脑要用64位JAVA
2：更新电脑所有驱动，排除是不是驱动版本太低的原因（因为你电脑提示的是驱动程序停止相应，所以驱动方面还是要更新下）
3：散热方面考虑一下，驱动停止响应的原因也有可能是电脑过热，并且你是开始可以玩儿，过一会就会弹出来，所以我觉得电脑发热的原因比较大
4：驱动停止响应也可能是内存不足，考虑到你电脑是i3并且只有2g内存，玩儿游戏的时候尽量关闭其他软件，腾出内存，或者加装内存条
实在不行只能重装系统了···只能帮你到这儿了，祝好运

操作系统（Windows、Mac OS、GNU/Linux）的发行版本和适用的硬件架构（32位或64位）。
CPU品牌（AMD或Intel），型号，时钟频率（GHz）。
RAM容量（GB），类型（DDR、DDR2、DDR3）、时钟频率（MHz）。
显卡品牌（AMD/ATI、Nvidia或英特尔），型号、核心/显存频率（MHz）、显存大小。
显卡驱动，请确认你的显卡驱动是否最新的，过时的驱动可能是无法进行游戏的原因。
屏幕分辨率和颜色深度(位数)，例如：1280*768*32。
游戏运行帧率（FPS），可以在游戏中使用F3键调出调试页面来获得。
安装Java的计算机，请确认你正在使用的Java版本（OpenJDK或Sun/Oracle）。
此外，在1.5版本中渲染引擎被重写，所以对应的游戏要求也被提高，不再支援过时的Java。而在未来的1.7版本将会再完善渲染引擎，需求更高级版本的OpenGL并且不支持旧显卡驱动。届时帧率会上升，游戏更流畅，渲染更高效。
[编辑]由于Minecraft使用Java架构编写，因此硬件需求较高

任何拥有下列硬件及软件的电脑都能够运行游戏，然而，要体验更好的游戏体验，我们建议使用推荐配置或更好的电脑。
在1.7版本后要求会更高，所以已改善所需的硬件要求。

最低配置：
CPU（中央处理器）：Intel Pentium/Celeron/Core（奔腾/赛扬/酷睿）系列单核/双核处理器或更好、AMD Sempron/Athlon 64/Phenom（闪龙/速龙64/羿龙）系列单核/双核处理器或更好。
CPU频率（MHz/GHz）：由于现时处理器构架繁多，而不同的构架在同频率下的性能也不同，这里取自Intel与AMD构架的平均。单核心2.4-3.0GHz或更好、双核心1.8-2.4GHz或更好。
RAM容量（内存）：Windows XP最少2GB、Vista/7/8最少2GB、Mac OS/GNU/Linux最少2GB。
RAM类型、频率：SDRAM-200或更好、DDR2-400或更好。
GPU（显卡）：Intel GMA X3100 系列集成显示芯片【不能直接运行minecraft，需要禁用direct3D才能运行，否则无法运行】、ATi Radeon 9xxx 系列显示芯片、Nvidia GeForce 6xxx 系列显示芯片或以上。
OS（操作系统）：Windows /XP/Vista/7/8/8.1、Mac OS/GNU/Linux 的32位或64位操作系统。
HDD（硬盘）：FAT32文件系统的机械硬盘（HDD）以及至少有150MB硬盘剩余空间（存档可能占用超过100MB甚至1GB）。

推荐配置：
CPU（中央处理器）：Intel Pentium/Celeron/Core i3/i5/i7（奔腾/赛扬/酷睿 i3/i5/i7）系列双核/四核处理器或更好、AMD Athlon II/Phenom II/FX/A4/A6/A8/A10（速龙2/羿龙2/FX/APU）系列双核/四核处理器或更好。
CPU频率（MHz/GHz）：由于现时处理器构架繁多，而不同的构架在同频率下的性能也不同，这里取自Intel与AMD构架的平均。双核心2.6-3.4GHz或更好、四核心2.4-3.0Ghz或更好。高性能需要i5 i7处理器
RAM容量（内存）：Windows XP要有2GB或以上（64位4GB以上）、Vista/7/8/8.1要有4GB或以上（64位8GB以上）、Mac OS/GNU/Linux要有2GB或以上。(想玩高性能光影mod的话推荐WIN7以上系统 8GB+ RAM)
RAM类型、频率：DDR2-667MHZ或更好、DDR3-1600MHZ或更好。
GPU（显卡）：Intel HD Graphics 4600/Iris Graphics 5100 或更好、AMD Readon HD 6750/HD 7750 或更好、Nvidia Geforce GTS 450/GTX 650 或更好。(如果有更好的需求，比如光影mod，维持FPS100+ 需要Nvidia GTX 670(M)/765(M)+)
OS（操作系统）：Windows xp/7/8/8.1、Mac OS/GNU/Linux 的64位操作系统。
HDD（硬盘）：NTFS文件系统的固态硬盘（SSD）以及1GB硬盘剩余空间。

此外，必需拥有以下软件才能进行游戏：
Java：最低要Java Runtime(JRE)5以上，推荐Java SE 6 Update 32 或 Java SE 7 Update 25以上版本。
显卡驱动：确保显卡驱动是最新的，过时的驱动可能是无法进行游戏的原因。

正在使用旧构架单核心CPU、旧式集成显卡【独显也一样】、物理内存少于1GB 或 Windows 95/98/2000或之前的操作系统请注意。
使用旧构架单核心CPU 或 旧式集成显卡几乎无法畅顺地进行游戏（CPU例如奔腾4单核、闪龙单核等，显卡例如Intel GMA 900），物理内存少于1GB会导致游戏时电脑卡顿严重，Windows 95/98/2000或之前的操作系统则因兼容性太低无法游戏
以上部分只是在进行游戏时帧数太低或过低，或者游戏经常崩溃，但并不代表不能玩。

硬盘空间里的150MB仅仅是估算值，如果保留一些存档或安装Mod就需要更多空间（特别是大型地图存档）。

[edit]Software requirements
  • Windows XP or later, OS X, GNU/Linux with latest software updates
    • Windows users: Run Windows Update to install the latest updates from Microsoft
    • OS X users: Run Software Update from System Preferences to install the latest updates from Apple.
    • GNU/Linux users: Use the respective Package manager for your distribution to install the latest updates.
      • Alternatively (for distributions to which it applies): Open a Terminal and type in the command "sudo apt-get update; sudo apt-get upgrade".

  • Java SE 7
    • Using the most up-to-date version of Java 7 is preferred. (Update 45 as of Oct 15, 2013)
    • If you are using a 64-bit OS, it is highly recommend that you install the 64-bit version of Java. (Both the 32-bit and 64-bit versions are compatible with each other.)
  • Latest graphics drivers

[edit]Singleplayer
  • Create New World
    • World Name: "Hardware Performance Test" (Without quotes)
    • Game Mode: Survival, Creative if you don't want hostile mobs to bother you (Please don't use commands or fly if you choose Creative).
    • More World Options
      • Seed for the World Generator: "Hardware Performance Test" (Without quotes)
      • Generate Structures: ON
      • World Type: Default
      • Allow Cheats: OFF
      • Bonus Chest: OFF


  • Once in the Test world...
    • Press F3 to bring up the debug screen. Your FPS will be on the first line on the top left next to the game version.
    • (Optional, but recommended) For the most accurate frame rate results:
      • Allow all chunks to load until the chunk updates value drops to a low, consistent value (This may take a while depending on the performance of your machine.)
      • Use Fraps benchmarking feature to collect FPS results. (Using the debug screen lowers in-game FPS, therefore making results less accurate.)

  • To gather FPS results:
    • Stand at coordinates (x:276), (z:180).
      • (Coordinates can be found on the mid-left position on the debug screen.)
      • This is a central location for players to start. Players retrieving frame rates closer to the lake will have higher FPS results as opposed to those who are by or inside the tree line, creating unfair results.
    • Look around in all horizontal directions. Do not look straight up or down while obtaining the framerate.
      • Looking down causes any underground entities to hurt your average FPS while looking up inflates it, ruining a standard test either way.
    • When retrieving your average frame rate, walk around in a small circle (about 20 blocks in all directions - counting from the center of a circle).
    • Get an average frame rate for the default window and in fullscreen. To change to fullscreen, press F11 (Mac OS X FN + F11).
