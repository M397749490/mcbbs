前置安装的意义在于，这个前置可以让有昵称的人前面显示昵称二字，与Ess中的某条功能相同

指令
/nicky help - 查看插件指令帮助
/nicky reload - 重载插件
/nick <名字> <昵称> - 让我们为自己创建一个昵称（Essentials插件中有此功能）
/delnick <名字> - 让我们删除一个昵称
/realname <昵称> - 检查谁拥有这个昵称（这个插件最大特点在此）

权限
权限名 作用
nicky.help 查看插件帮助
nicky.reload 使用指令/nicky reload的权限
nicky.set 让使用者设置一个昵称
nicky.set.other 让使用者为你设置一个别名
nicky.del 允许用户删除一个昵称
nicky.del.other 允许用户删除其他玩家的昵称
nicky.color 让用户能使用颜色代码
nicky.color.normal 让一个昵称只能使用一种颜色
nicky.color.extra 让用户能有额外格式（&i 等）

配置

  1. # Nicky 配置 - www.okicore.com

  3. # 存储类型 "sqlite" 或 "mysql"
  4. type: 'sqlite'

  6. # MySQL 连接设置.
  7. host: 'localhost'
  8. port: '3306'
  9. user: 'root'
  10. password: 'password'
  11. database: 'nicky'

  13. # 如果安装 TagAPI 的话更改名称标签吗?
  14. tagapi: true

  16. # 名称应在标签列表更新吗?
  17. tab: true

  19. # 你的昵称是所有昵称里唯一的吗?
  20. unique: true

  22. # 在昵称前面加上前辍吗? (设置为 '' 来禁用)
  23. prefix: '&e~'

  25. # 名字昵称的最大位数, 包括颜色代码.
  26. length: 20

  28. # RegEx 中昵称不允许的字符, 设置为 '' 允许任何, 或者保留默认值只有数字和字母.
  29. characters: '[^a-zA-Z0-9§]'

  31. # 不能出现在昵称的任何话.
  32. blacklist:
  33.   - Melonking
  34.   - Admin
