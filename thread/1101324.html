JEI Integration
JEI扩展

前言
  本模组遵循MIT协议.

功能
  JEI Integration 是 Tonius 的 NEI Integration 在高版本的重置,是Minecraft 1.10及更高版本的JEI的附属模组,该模组提供了一些物品显示功能,如下:
  注意:默认以下信息均不显示,请自行在配置(.minecraft\config\jeiintegration-client.toml)中开启或在游戏模组菜单中开启.
  Tips:不知道是我的问题还是Forge的问题,1.16.2无法打开配置界面,只能前往jeiintegration-client.toml...
1.15及以上
燃烧时间:显示可燃烧物品的燃烧时间,单位为Tick(20Ticks=1s).
  耐久值:显示某些物品的耐久值,例如钻石剑,显示物品总耐久与剩余耐久.
  饥饿值:显示某些食物可恢复的饥饿值.
  元数据:显示部分物品共用同一ID的数据值,例如不同颜色的羊毛.
  最大堆叠数量:显示某些物品的最大堆叠数量,通常大部分物品为64个,但也有例外,例如末影珍珠为16个.
  NBT数据:显示在物品上保存的NBT数据.
  物品ID:显示物品的英文ID,例如minecraft:apple是苹果虽然通过游戏自带的F3+H可以看出,但是JEI扩展提供了额外的ID显示,例如云杉木板会显示三个,分别为木板,云杉木板(还有一个忘了).
  物品本地化名:显示特定方块的本地化名称,例如石头为block.minecraft.stone.
1.14
  燃烧时间:显示可燃烧物品的燃烧时间,单位为Tick(20Ticks=1s).
  耐久值:显示某些物品的耐久值,例如钻石剑,显示物品总耐久与剩余耐久.
  最大堆叠数量:显示某些物品的最大堆叠数量,通常大部分物品为64个,但也有例外,例如末影珍珠为16个.
  NBT数据:显示在物品上保存的NBT数据.
  物品ID:显示物品的英文ID,例如minecraft:apple是苹果虽然通过游戏自带的F3+H可以看出,但是JEI扩展提供了额外的ID显示,例如云杉木板会显示三个,分别为木板,云杉木板(还有一个忘了).
  物品本地化名:显示特定方块的本地化名称,例如石头为block.minecraft.stone.
1.12及以下

  燃烧时间:显示可燃烧物品的燃烧时间,单位为Tick(20Ticks=1s).
  耐久值:显示某些物品的耐久值,例如钻石剑,显示物品总耐久与剩余耐久.
  元数据:显示部分物品共用同一ID的数据值,例如不同颜色的羊毛.
  最大堆叠数量:显示某些物品的最大堆叠数量,通常大部分物品为64个,但也有例外,例如末影珍珠为16个.
  NBT数据:显示在物品上保存的NBT数据.
  矿物辞典:显示物品的矿物辞典名,例如木头的矿物辞典为logWood.
  物品ID:显示物品的英文ID,例如minecraft:apple是苹果虽然通过游戏自带的F3+H可以看出,但是JEI扩展提供了额外的ID显示,例如云杉木板会显示三个,分别为木板,云杉木板(还有一个忘了).
  物品本地化名:显示特定方块的本地化名称,例如石头为block.minecraft.stone.

Q:能不能兼容Fabric API?

Q:我能在整合包中使用它吗?
A:可以.
