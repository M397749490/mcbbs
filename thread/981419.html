/points => 打开GUI界面
/points me => 查询剩余点券

/points take => 拿走玩家点券
/points set => 设置玩家点券

API介绍
  1. PlayerPoint mp1 = new PlayerPoint(sender.getName());
  2. mp1.has(1000); #该玩家是否有1000点券
  3. mp1.set(1000); #设置玩家点券为1000点券
  4. mp1.give(1000); #给玩家1000点券
  5. mp1.take(1000); #拿走玩家1000点券
