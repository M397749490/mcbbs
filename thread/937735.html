这个帖子的内容如题，那有什么用呢？
举个例子：你想你的服务器的玩家一进来就回到主城，就有用了
指令（按顺序放到循环、连锁命令方块里就能用了）：
  1. execute @e[tag=test_IG] ~ ~-50 ~ tag @p add in_game
  2. execute @a[tag=!in_game] ~ ~ ~ function back
  3. tag @a remove in_game
  4. kill @e[tag=test_IG]
  5. execute @a ~ ~50 ~ summon armor_stand
  6. execute @a ~ ~50 ~ tag @e[c=1,type=armor_stand] add test_IG
复制代码


其中第2条指令的“function back”就是自定义的指令，改成其他的指令就行了
经过作者亲自测试，这些指令有用
