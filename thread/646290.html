可以通过改LWC的配置文件来达成这个效果
先找到配置文件
然后ctrl+F搜索
“protections”
往下拉找到这段：
  1. blocks:
  2.         chest:
  3.             enabled: true
  4.             autoRegister: private
  5.         furnace:
  6.             enabled: true
  7.             autoRegister: private
  8.         dispenser:
  9.             enabled: true
  10.             autoRegister: private
  11.         sign:
  12.             enabled: true
  13.             autoRegister: private
  14.         wooden_door:
  15.             enabled: true
  16.         iron_door:
  17.             enabled: true
  18.         trap_door:
  19.             enabled: true
  20.         fence_gate:
  21.             enabled: true
  22.         trapped_chest:
  23.             autoRegister: private
  24.             enabled: true
复制代码

之后按照上面的这种格式
继续添加上工业机器的ID就行
附加值可以直接用 “:*” 代替

用35*为例(应该是羊毛，也可能记错了)：
  1. 35:*:
  2.    enabled: true
复制代码
当然除了数字，添加英文ID也行
