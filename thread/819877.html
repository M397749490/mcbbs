功能
1.配置容器ID 限制 容器 位置 上方 下方 放置漏斗

2.容器无法同时被两个或者两个以上玩家打开(测试兼容原版箱子 和 时装模组容器)



配置文件:

注意 默认 时装容器 上下方无法放置漏斗 无法更改
  1. # 容器 管理类
  2. # 服务器内需要限制的容器的数字ID
  3. # 默认 箱子
  4. ContainerId_list:
  5.   - 54

  7. # 是否禁止容器位置的 上面 或者 下面 放下漏斗
  8. Container_Ban_HOPPER: true
  9. # 是否开启 容器只允许 一个人打开
  10. # 测试兼容 原版箱子 时装容器
  11. # 测试不兼容 神秘的饕餮箱子
  12. chestopen_only: true
