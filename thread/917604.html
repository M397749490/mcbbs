例子：假设我们可以通过以下命令获得 1 个列表，例如 ["a","b","c"]
  1. data get block 0 0 0 Items[0].tag.foo
复制代码
可以通过以下命令来移除这个列表里的第 1 个元素，例如 "a"，使得列表变成 ["b","c"]
  1. data remove block 0 0 0 Items[0].tag.foo[0]
复制代码
那么，假设这个列表里的元素的类型和个数是任意的，那么如何移除这个列表里的：
1、最后 1 个元素；
2、倒数第 n 个元素 。
