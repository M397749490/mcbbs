Mob Properties Extra
无限制的生物DIYmod~
基础介绍
这是个啥？
  Mob Properties Extra mod 是一个功能非常强大的mod，它可以修改你整合包内近乎所有的生物属性且几乎通过NBT操作，所以兼容性非常的高。
  注意，此版本非官方版本[Mob Properties]，而是原创移植版本，原作者已经消失2年多且无法联系，在于后续接任者协商后，故在此发布支持1.12.2的Extra版本（原mod只支持到1.10.2）
可以做到哪些效果？
  那可真是太多了，当你基本了解了这个mod的操作之后，你可以给生物们穿上你所想的任意装备
不管是僵尸还是绵羊（虽然它不会显示但是通过一些辅助类mod你可以看到绵羊已经有护甲了）
  或者是生物死亡后，再召唤出另一种生物，召唤的生物也可以做到有属性，也可以在在死亡后召唤出其他生物。
你甚至还可以给生物添加药水效果，例如让僵尸获得防火效果，让其白天或者在岩浆中不受火焰伤害。
  除此之外还有非常多的创意值得你们尝试，例如让一只僵尸骑着一只猪然后猪在骑着一个附带隐身效果的蝙蝠（迫真），然后一个飞猪骑士就出来了！
  本MOD还有很多高级的功能，可以让同一种生物在不同的情况下出现不同的效果，例如僵尸在主世界20血，到了地狱却是40血。
  更有甚者配合NBT实现一个生物生成的时候随机外形（json模型，需要材质包），如果你不知道该调整哪一个NBT的话，这个mod还给所有生物增加了一个额外的无意义的nbt数据，可以由你来操作，以DIY你想要的东西。
  如果你是一个冒险整合包的作者或者服务器作者，你还可以设置距离出生点多少距离的生物有什么样的名字，血量以及攻击力加成如何等等等等。。。太多太多了，好了，闲话不多说。

但是对于本1.12.2版本，需要注意以下事项（这里也是一些问题的修改和更新）。
1、一些 json 的格式识别
2、怪物装备槽位修正，不能使用数字
可用槽位
[mainhand,offhand,head,chest,legs,feet]
3、新增配置文件读取流程，读取一次后自动false掉
4、药水效果写法
potion.fireResistance以及数字ID可用，但是会弹警告
正确的写法是minecraft:fire_resistance["minecraft:"可加可不加]
5、附魔效果写法
enchantment.damage.all以及数字ID可用，但是会弹警告
正确的写法是minecraft:sharpness["minecraft:"可加可不加]
6、物品ID的nbt写法 不能使用 item_id 要使用 string
如果加了cnpcmod，那么道具id前的tag需要添加

"name": "ForgeCaps",
"function": "compound",
"tags": [
{
"name": "customnpcs:itemscripteddata",
"function": "compound",
"tags": []
}
7、command的函数器value值不能加"/"符号
8、发送信息的"tellraw"指令其value中的json内容使用引号的需要转义
如/tellraw @a[r=8] {"text":"你获得了一枚钻石！","color":"aqua"}
需要转义为
/tellraw @a[r=8] {\"text\":\"你获得了一枚钻石！\",\"color\":\"aqua\"}
下载&安装
愉快的安装环节
1.首先度盘的提取码为：spee
2.下载mod后，放入mods文件夹
3.开启客户端或者服务器，等待加载完成
4.开始DIY你自己的魔鬼生物吧！
