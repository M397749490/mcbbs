在18w15a可以利用facing命令实现实体围绕实体或坐标点作向心/离心运动。

↓下面是命令↓
  1. execute at @e[type=chicken] run execute as @e[type=chicken] run execute facing entity @e[type=armor_stand] eyes run tp ^1 ^ ^0.15

代码说明：

  1. execute at @e[type=绕圈实体名称] run execute as @e[type=绕圈实体名称(理论要和前面一致)] run execute facing entity @e[type=被绕圈实体名称] eyes/feet run tp ^线速度 ^ ^向心速度(大于一定数值时做离心运动)

【作死改为@a的恕不负责】
作者: SPGoding    时间: 2018-4-14 15:31
命令execute是一种类似chain的结构…就是说你可以写
execute as foo at bar run **
而不必拆开为多个execute foo run bar
以及如果把as at顺序调一下就可以让at那里直接@s。另外，at @e后再as @e实际上你的命令执行了(实体个数)^2次，实体一多堪比4exe
修改后的命令：execute as @e[type=绕圈实体名称] at @s facing entity @e[type=圆心实体名称] feet run tp ^线速度 ^ ^向心速度
