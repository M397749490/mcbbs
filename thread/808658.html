神奇宝贝常用指令：        /pokespawn (神奇宝贝名称)lvl[精灵等级1-100] [参数] [参数] - 这是召唤出神奇 ...

/nbtedit用法
修改闪光：IsShiny


说明：0是普通，1是闪光。


--------------------------------------------------
修改成蛋：isEgg


说明：0是精灵，2是蛋。


注意：修改成蛋之后，就不可恢复。


--------------------------------------------------
修改性别：Gender


说明：0是雄，1的雌，3是无性别。


--------------------------------------------------


修改体型：Growth


说明：0-7之间的数字。


注意：修改体型的时候，数字不要超过7，否则会出现严重后果。


--------------------------------------------------
修改性格：Nature


说明：1-24之间的数字。


注意：修改性格的时候，不要胡乱修改，否则会出现严重后果。


1：无加无减
2：无加无减
3：无加无减
4：无加无减


5：加攻击减防御
6：加攻击减速度
7：加攻击减特攻
8：加攻击减特防


9：加防御减攻击
10：加防御减速度
11：加防御减特攻
12：加防御减特防


13：加速度减攻击
14：加速度减防御
15：加速度减特攻
16：加速度减特防


17：加特攻减攻击
18：加特攻减防御
19：加特攻减速度
20：加特攻减特防


21：加特防减攻击
22：加特防减防御
23：加特防减速度
24：加特防减特防


--------------------------------------------------
修改努力值：EVAttack攻击 EVDefence防御 EVHP血量 EVSpecialAttack特攻 EVSpecialDefence特防 EVSpeed速度


说明：按照对应的值修改。


注意：修改努力值的时候，数字不要过大，否则会出现严重后果。


--------------------------------------------------
修改个体值：IVAttack攻击 IVDefence防御 IVHP血量 IVSpAtt特攻 IVSpDef特防 IVSpeed速度



说明：按照对应的值修改。


注意：修改个体值的时候，数字不要过大，否则会出现严重后果。


--------------------------------------------------
修改等级：Level


说明：修改数字即可。


注意：修改等级的时候，数字不要过大，否则会出现严重后果。


--------------------------------------------------
修改精灵特性：Ability


说明：修改成特性的英文即可


--------------------------------------------------
修改精灵：Name


说明：修改精灵英文即可。


注意：修改成本版本无的精灵可能会导致无模型。


--------------------------------------------------
重命名精灵名字：Nickname


说明：修改成你喜欢的名字

神奇宝贝常用指令：        /pokespawn (神奇宝贝名称)lvl[精灵等级1-100] [参数] [参数] - 这是召唤出神奇宝贝。        /pokegive (玩家) (神奇宝贝名称)[精灵等级1-100] [参数] [参数] - 某玩家直接获得一只神奇宝贝。        /pokeheal (玩家) - 治疗某玩家的所有神奇宝贝。        /pokebattle (玩家1) (玩家2) - 让两个玩家进行战斗。        /pokebattle2 (玩家) [玩家]/[神奇宝贝名称] [玩家]/[神奇宝贝名称] [玩家]/[神奇宝贝名称]让多个玩家进行战斗，但是是一起战斗。        /pokestats (玩家) - 查看某玩家的对战记录。        /resetpokestats (玩家) - 清除某玩家的战斗纪录。        /freeze - 让整个世界的神奇宝贝都不动。(但还可战斗)        /struc - 建**奇宝贝中心。(不可重迭，要相隔很远才能放)       /nbtedit 改精灵            /teach 玩家名 （1-6） 技能英文名 - 给精灵改技能        /unlock  玩家名 解锁某个玩家的牧场精灵

刷新率.minecraft/config/pixelmon, 打开这个
# 设置神兽生成的几率（X分之1的几率生成），X的值越高，神兽生成频率越小.
    I:"Legendary Spawn Rate"=5000

    # 飞行精灵最大数量
    I:"Max number of Air Pokemon (at one time)"=2

    # 陆上精灵最大数量.
    I:"Max number of Land Pokemon (at one time)"=20

    # 地底精灵最大数量.
    I:"Max number of Underground Pokemon (at one time)"=0

    # 水中精灵最大数量.
    I:"Max number of Water Pokemon (at one time)"=5

    # 闪光精灵生成率.
    I:"Shiny spawn rate"=1000

你可以根据个人需求改
