2.宠物插件的指令补充
其实有些东西在宠物[指令]这里面是不完整的
比如admin的指令
/petadmin <选项> [参数…]
只有拥有 MyPet.admin 权限的玩家可使用
选项:
name
为指定玩家的 宠物 设置新名字
参数:
<拥有者>
<新名字>
exp
为指定玩家的 宠物 设置经验值
参数:
<拥有者>
<数值>
[add/set/remove]
注：add为增加 set为设置指定数值 remove为扣除

respawn
为指定玩家的 宠物 设置重生时间
只能改变死亡中的 宠物 使用
参数:
<拥有者>
[新的重生时间] 或 [show]
reload
重载配置文件 (config.yml)
build
显示 MyPet 版本

这个就是一个不完整这里面没有把指令写完全
下面我把完整的但是没有翻译的admin宠物指令放出来给大家看看
create
creates a new MyPet for a specific player
Only usable when player has no active MyPet
Use -f to create a new pet even if the player has a pet already
parameters:
[-f]
<ownername>
<pettype>
[parameter]
Use the TAB-key to see all possible paramerters for the selected pettype
clone
clones a MyPet from a player and gives it to another player
parameters:
<pet ownername>
<new pet ownername>
remove
deletes a new MyPet for a specific player
parameters:
<ownername>
cleanup
deletes unused pets older than a certain amount of days
if the days parameter is set to -1 all pets which aren't used after the upgrade to MyPet 1.1.3
parameters:
<-1> or <days>

由于本人大概是版主里面英语最菜的了，我也不误导大家给大家乱翻译了
我就给你们说一下我知道的指令吧
这些是在宠物插件中文没有提到的指令
下面我会一个个的讲作用的

create
给予玩家某个宠物的指令
比如你们服务器并不能捕捉凋零，那么你想要怎么给予你的VIP凋零呢？
使用方法
/petadmin create  <玩家名字> Wither

如果这个玩家已经有宠物了，这样这个指令是给不了的，那么我们可以加上-f
/petadmin create -f <玩家名字> Wither

create进阶
/petadmin create -f <玩家名字> Enderman block:7

这个指令的意思就是，给予玩家一个手上拿着基岩的小黑
block这个参数是小黑的特殊参数，别的宠物是没有的
不过别的宠物有别的参数OP们可以在输入完了实体名字在加空格
在按键盘上的Tab就会出现可以输入的参数了

（注意：小黑抱着的装备可以被剪刀剪下来，请不要给命令方块之类的，其他奇怪的方块也会造成游戏的崩溃）


clone
克隆宠物
/petadmin clone <你的ID> <被克隆的ID>

remove
删除宠物，这个很好理解，直接删除某个玩家的名字
/petadmin remove <玩家ID>

cleanup
/petadmin cleanup <清理天数>

输入清理天数那里输入：60的话就是清理60天以前的所有不活跃宠物
请注意
不要输入过少的天数，易照成误伤30天已经很少了



3.奇怪的作用
宠物背包
宠物背包无视多世界背包
这个插件可以把已经分开背包的世界的物品带进去另一个世界
所以各位腐竹要小心了

宠物改名
宠物改名大家都会，但是怎么修改彩色名字却少有人知道
明明写了更新了宠物支持彩色名字却不知道怎么修改
下面我来告诉大家
并不是&1-9，或者§1-9，也不是十进制什么的
其实是  < >
没错就是
<1>一只有<2>理想的鸡
一只有理想的鸡就是这么简单

宠物的名字
如果设置为Dinnerbone，宠物就会倒过来

乘骑宠物
骑上宠物就会像骑上马一样，可以无视领地的移动权限，就算是设置了禁止移动还是可以在上面移动
蝙蝠和鸡都自带滑翔，骑着他们从天上摔下来并不会去血
如果你装了乘骑插件
那么有/ride的玩家，不需要宠物学习这个技能就可以骑着跑了

RPGitem
注：并不确定
比如你设置了一个物品是僵尸掉落，那么你抓了僵尸宠物
然后你叫朋友打死你的宠物，掉落物品，过了5秒复活在打死，这样可以刷东西吗
虽然没有试验过，但是在理论上是成立的
所以请各位腐竹谨慎，如果可以的话，最好在下面反馈一下

其他的暂时没有想到什么
如果有请补充

那么就要开始噩梦一般的调试技能了
为了你们看着方便，我就一个技能折叠一下好了


先添加一个等级1级
必须要在1级给予宠物攻击力，不然宠物是不会攻击怪物的
而宠物不攻击怪物就不能升级，所以必须要加1级

如果想要在十级获得两点攻击力就
点那个添加等级，出来的框里面写10
这样宠物攻击就会在10级的时候增加一点了
其他的技能也是同样的道理
需要各位自己的搭配，本人就不再这里误导大家了

其他没什么好说的，进入技能讲解
Beacon（信标技能）

信标技能宠物的一大亮点
包涵很多技能
分单体/群体
如单体

建议不要在宠物等级太低的时候给予信标效果，容易导致游戏难度大幅度降低

Behavior（行为模式）
友好（friendly） → 不会攻击，即使自己被攻击
friend
普通(normal) → 像普通狼一样
好战（aggressive） → 攻击玩家15格范围内所有的生物
aggro
打野（farm） → 攻击玩家15格范围内所有的怪物
突击（raid） → 如同普通模式，但宠物 不会攻击玩家和其他宠物

不建议给宠物好战以及打野
那样会导致挂机刷怪，如果是那种非战斗的宠物可以考虑打野技能，让升级更容易一些
Control（支配）
你可以支配你的 宠物 向哪移动， 攻击什么。
手持 捕捉宠物的物品右键一个地方， 宠物会走到那。
Damage（攻击力）
最好选择add 攻击力
这个是在原来的攻击力上面叠加的
而set是设置攻击力，比如你原来有500点攻击
用了set 1.0 那么就会变成1点攻击力了
Fire（点燃）
没啥好说的大家看着加就行了
HP（血量）
这个需要好好说一下，这个初始血量是在插件生成的配置文件里面的
没有修改的话，默认都是20滴血初始血量
这个血千万不能设置成set 1.0
你要设置成set 21.0这个没问题
Health Regeneration（血量恢复速度）
这个如果是纯净服不建议回血效率调的太夸张
那样一秒回复5滴血根本打不死
Inventory（宠物背包）
这个不是叠加的，如果想要升级增加背包就在高等级的地方重新添加技能
一般不是特别变态的服不要去点底下的Drop Content 勾上了这个会导致你自己死亡，宠物背包里面的物品全部消失
Knockback（击退）
击退几率也没什么好说了
用添加比较好
Lightning（闪电）
如上
Pickup（自动拾取）
这个技能算是比较逆天的了，丢了装备
别人的宠物开启范围拾取，然后你连装备到哪里去都不知道
（其实在别人的宠物背包）
Poison（中毒）
如上
Ranged（远程攻击）



注意：攻击间隔使用下面的set：35设置攻速，如果用add：35会导致越到后面攻速越慢！！！
经过测试35的攻速就是普通骷髅弓箭手的攻速

Ride（乘骑）

第一个增加速度不建议调的太大，不然跑图太厉害了
第二个方块最多设置3格高

5.简单的配置


在宠物插件生成的配置文件里面

主要是配置下面这些



一个好的服务器
宠物插件必须要自己重新配置过
比如一只鸡初始血量怎么能有20呢，改成10就很科学
后期可以用技能树来提升这个鸡的血量
宠物的食物应该变得更科学一点
重要的是捕捉宠物的工具
原来的是统一拴绳，但是我为了让服务器的玩家更加认真的去玩
我把全部的捕捉条件都改了，都是与捕捉的宠物有关的
比如村民用绿宝石打残就可以捕捉之类的
不建议你们修改可以捕捉凋零，恶魂
恶魂鬼叫太吵，凋零的也是。可以用第二页的指令给予玩家就行了
下面是我很早以前给自己服务器的配置文件
没有什么其他的东西，就是把捕捉怪物的工具改了一下，和部分的食物改的更科学了一点
补充一下：食物可以设置多个食物，格式如下

Food: 353;296;260
