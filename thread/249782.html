插件介绍：
任何人都可以直观编辑权限！Permissions GUI是一个图形用户界面，你可以用一些简单的按钮配置权限。你将再也得不到一堆权限错误信息。你可以添加你自己的权限或自己的权限插件。他可以自动更新你的权限

版本更新：
rc2 - 如果在"config.yml"里面将两项都设置为false的话，不会更新下面的"rc5"版本
rc5 - 如果在"config.yml"里面将两项都设置为true的话，会更新这个版本
"config.yml"文件会在下面的“禁用更新和数据库的下载”提及

支持的权限插件列表：
  • PermissionsEx
  • GroupManager
  • bPermissions
  • PermissionsBukkit
估计会不断更新，更新列表变动详情请移步：这里

权限：
此插件为管理权限的插件，没有权限。
这个插件是服务器管理员用的，在服务器里的其他用户没有权限访问和编辑这个插件

安装：
下载好压缩包（帖子顶部有原下载地址），双击打开文件"Permissions GUI.exe"。
如果过了几秒没有反应的话，执行“Permissions GUI.jar"，这样你就可以设置你所有的偏好设置了

禁用更新和数据库的下载：
要是取消该功能，请设置里面的"config.yml"：（下面的设置应该能看得懂吧）
  1. enable_updater: false
  2. enable_database_download: false
复制代码
如果"config.yml"不存在，就手动创建一个

已经完成的功能：
  • Auto Updater - 自动更新
  • Add, edit, delete groups - 创建，编辑和删除分组
  • Add, edit, delete permissions - 创建，编辑和删除权限
  • Options Screen - 设置屏幕
  • Custom permission plugins - 自定义权限插件
  • Localization - 本土语言化


以后的版本更新计划：（就是以后会更新的内容）
  • FTP & MySQL - 这个就不解释了
  • Code improvements - 代码改进
  • Open source - 开源
  • Drag 'n' Drop system - 没明白，貌似是拖拽功能
  • More supported plugins - 更多支持插件
  • API which helps plugin authors to register their permissions - 可以帮助插件作者来注册自己的权限的API
