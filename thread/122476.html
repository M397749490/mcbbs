AutoSaveWorld - 自动地图更新/备份插件


简单介绍

玩多人MC的过程中常会出现“蹦服”的现象。蹦服后重启长会发现地图还原到了几分钟甚至几个小时之前的样子。这个插件解决了这个问题：他会定时更新并且备份服务器文档中的地图文件。这样，每次蹦服只会还原到蹦服前插件保存地图时的地图状态。建议各位把自动保存地图的时间隔设为每15秒。

注：所谓的定时更新(/asw save)是定时“更新”地图文件；不是备份。所谓的保存(/asw backup)是指备份：做出完整的存档文件。
注：如需汉化，请拷贝一下下面【Configmsg.yml文件】的内容到你自己的Configmsg.yml文件里。


功能列表

定时地图更新/备份, 自动备存/更新插件和地图文件, 新推出的PURGE功能，更新别的插件的编制 (建议别使用此功能), 自动定时重启服务器, 蹦服现象后自动重启服务器


指令和权限介绍

主要指令

/asw save -地图保存，注意：不是地图备存（也可以/save替代）
/asw backup -全程备存（也可以/backup替代）
/asw purge - 全程清除（建议不要用此指令，很不稳定！）
/asw restart -服务器整体重启

额外指令

/asw help -列出插件帮助 (权限NODE是autosaveworld.help)
/asw reload -插件重新载入，刷新config.yml和configmsg.yml文件 (权限NODE是autosaveworld.reload)
/asw reloadconfig -刷新config.yml文件 (权限NODE是autosaveworld.reloadconfig)
/asw reloadmsg -刷新configmsg.yml文件 (权限NODE是autosaveworld.reloadmsg)
/asw selfrestart -自动重启Autosaveworld (权限NODE是autosaveworld.selfrestart)
/asw version -列出Autosaveworld插件版本 (权限NODE是autosaveworld.version)
/asw info -列出Autosaveworld的内容介绍 (权限NODE是autosaveworld.info)

友谊提醒：所有的指令对OP，后台，和有权限的人都好用


文件编辑

Config.yml文件

var:
  debug: false (不用管)
  crdebug: false (不用管)
save:
  enabled: true (是否自动地图保存)
  interval: 900 (多久(秒)进行地图保存)
  broadcast: true (是否广播保存地图的过程)
  warn: false (时候实现提醒你以下)
  warntime:
  - 0 (提前提醒时间)
backup:
  enabled: false (是否自动备存)
  interval: 21600 (多久(秒)备存一次)
  worlds: (世界列表)
  - '*' (全部地图)
  MaxNumberOfWorldsBackups: 30 (最多数世界备存)
  pluginsfolder: false (是否备存插件文件夹)
  MaxNumberOfPluginsBackups: 30 (最多插件备存数量)
  excludefolders: []
  broadcast: true (是否广播)
  toextfolders: false
  disableintfolder: true
  extfolders: []
  zip: false (是否compress备存成一个.zip文件)
  slowbackup: true (是否选择惊醒慢型备存)
  warn: false (是否警告)
  warntime:
  - 0 (警告时间)
purge:
  enabled: false (Purge是否启用)
  interval: 86400 (多久Purge一次)
  awaytime: 2592000 (如果玩家不在线，多久(秒)不在线清空和Purge)
  broadcast: true (是否广播)
  slowpurge: true (是否使用慢行Purge系统)
  wg: (WorldGuard插件)
    enabled: true (启用Purge?)
    regenpurgedregion: false (重新载入Purge完的地形)
  lwc: (LWC插件)
    enabled: true (启用Purge?)
    deletepurgedblocks: false (是否删除Purge完的方块)
  essentials: (Essentials插件)
    enabled: true (启用Purge?)
  dat:
    enabled: true (启用Purge?)
crashrestart: (蹦服情况是否自动重启)
  enabled: false (是否启用蹦服情况下的自动重启)
  scriptpath: start.sh (不必修改)
  timeout: 15 (如果服务器停止运行XXX秒，就会自动进行重启)
  juststop: false (如果是true，你的服务器就会在崩塌的情况下自动关闭)
autorestart: (自动重启)
  enabled: false (是否启用自动重启)
  broadcast: true (是否广播)
  time: (时间)
    hour: 0 (小时)
    minute: 0 (分钟)
  countdown: (倒数)
    enabled: true (是否启用倒数提醒系统)
    seconds: 20 (重启前，多少秒的倒数时间?)
  scriptpath: start.sh (不必更改)
  juststop: false (如果是True，服务器在自动重启的情况下会自动关闭)
locale:
  switchtolangfile: false
  langfilesuffix: ru

  post: '&9自动备存完毕'
broadcastpurge:
  pre: '&9Purge功能刷新中'
  post: '&9Purge功能刷新完毕'
warning:
  save: '&9请注意，自动地图保存即将进行'
  backup: '&9请注意，自动备存即将进行'
insufficentpermissions: '&c你没有权限使用此指令.'

  restarting: '&9服务器重启中'
  countdown: '&9服务器会在{SECONDS}秒后重启'
