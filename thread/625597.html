这是什么插件
                                                                                                                                                                             
Beaconz是一个团队的PvP生存游戏,玩家在2000×2000区域游戏。 Beaconz是自然生成的无法破坏的灯塔(信标)玩家可以找到并占领为自己的队伍。 Beaconz可以彼此连接，如果连接成一个三角形将获得分数于覆盖的区域。如果一支球队获得300万点，他们将赢得比赛。三角形也赋予正面的效果给队友和负面效给敌方玩家。重叠的三角形给予越来越多的效果。通过这种方式，团队可以“声称”土地和保护它。 Beaconz可配备主动和被动防御技能，防止敌方玩家的占领它们。(就等于自动攻击的炮台)

警告！ Beaconz是一个团队的PvP游戏，敌方玩家可以杀死你！准备好为自己防卫或者逃跑。如果你不喜欢战斗，创建安全区与三角形并留在里面。(好像集合了推塔和据点攻占的元素)
              
安装
下载Beaconz,下载插件并安装在服务器的插件文件夹。 在重新启动服务器之后,插件将生成一个新的世界,一个大厅区域,第一场比赛。登录并输入/ beaconz。 在大厅里,输入命令,你就会开始游戏。
游戏的目的
这个游戏的目的是为你的团队赢得比赛得分。 管理员可以干涉(不好啦...)。 默认是300万块2000 x 2000块三角形的游戏区域。 其他选项都找到beaconz或创建连接。 游戏可以结束时得分,或者一直运行下去。

Game Play
玩家加入Beaconz世界和会被分配到人数最少的队伍。 玩家通常会开始装备和生成在随机位置附近的团队自己的灯塔,或只是一个随机的位。 玩家通过寻找发现信标,连接在一起,使三角形为团队的领域,给团队一个覆盖区域分数。
寻找灯塔与占领野外(无主)灯塔(信标,也可以叫Beaconz)
寻找灯塔:灯塔被随机放置在世界各地。 它们可以被雪覆盖,隐藏在树下或蘑菇。 他们从来没有发现在深海,但会在河流。 有时候,灯塔可能损坏,但当玩家进行交互时会自我修复。
野外灯塔占领:野外beaconz(灯塔)上有一个黑曜石。 要占,上面所有钻石块和黑曜石必须清除。 这包括树叶和任何突出根据地灯塔。 液体(水或熔岩)计数,可以占领之前,必须清理信标附近。 一旦明确信标区域,玩家可以打破黑曜石,它将成为队伍的彩色玻璃的颜色。 然后获得灯塔地图可以用来连接到另一个灯塔。
灯塔连接
玩家使用灯塔地图和经验灯塔指向连接。 从一个灯塔获取地图,灯塔后玩家将映射到另一个有关灯塔。 如果玩家有足够的经验值和范围内的信标,灯塔地图和经验值消耗有关。 每个信标可以有6连接。 玩家会得到连接灯塔的奖励——绿宝石。 beaconz(灯塔)之间的连接形式在天空中。 建议你关掉云不然你看不它们!Beaconz无法连接的情况:距离超过500格。如何解决:除非范围扩展块添加到灯塔否则灯塔无法连接。黄金块增加50格范围，钻石块加200格,但一旦放置范围扩展块就不被破坏不能被删除，因此将它们小心放置！
做一个三角形
当玩家将3个灯塔连接在一起成一个三角形，队伍获得点覆盖的新领域和三角形提供的正面药水效果的区域。重叠区域不计入评分但增加了效果。在多个重叠的区域，有更强大的效果。对于队友，这意味着正面的药水效果，比如速度，跳跃提升，再生和夜视功能，而对于敌方玩家，其影响是负面的，比如缓慢，饥饿，夜视和凋零。对于高层次重叠，一个团队可以完全防止敌方玩家进攻，可怕的瞬间伤害使敌方无法进入。
保卫灯塔与主动防御系统

防御块(被动防御系统):团队已占领的灯塔可以进行自我保护。 防御块大部分是被动防御,但发射器提供了一个auto-turret主动防御!
防御块可以放置的高度在灯塔8块的高度。 购买不耗费经验,但玩家必须在正确的水平放置一个防御块。 例如,放置一块8上方的灯塔,一个队友必须30级。 同样的,敌人必须30级才能删除8高防御。
它不需要有块高度。 举例来说,一个团队可以将周围一圈黑曜石环在信标8块基础之上, 防御块可以是任何块,被动和主动防御。您只能从你的团队拥有一个灯塔删除自己的防御块(防御块应该是放在钻石块上面)
主动防御系统:炮塔只会在队友范围内发射器上可以看到。 攻击范围是360度。 弹药放在发射器上不会用完,是无限的。 弹药不能被敌人捡起。 相反,发射器必须被打破。
                                                                                                                                                       占领敌人的灯塔与扩展信标
占领敌人的灯塔:清理掉防御模块,然后打破玻璃,挖走黑曜石进行占领
扩展信标:还记得连接灯塔奖励的绿宝石吗? 最初的灯塔是一个坚不可摧的组3 x3钻石块,但是它可以用绿宝石块像任意方向延伸。 一旦放置,将成为永久性灯塔的一部分,不能被删除。 防御块可以放在上面。 PS:绿宝石可以通过连接灯塔,挖矿,交易进行获取。
玩家指令
  • /beaconz - 进入游戏大厅，有传送延迟
  • /beaconz score - 详细的游戏分数
  • /beaconz sb - Hides or reveals the game scoreboard (我也不知道,好像是显示或隐藏计分版)
  • /beaconz leave - (需要权限) - 退出游戏
  • /beaconz help - 命令列表
管理员指令

  • /badmin delete <gamename> - 删除游戏
  • /badmin games - 现有游戏列表
  • /badmin regenerate <gamename> - 重新生成游戏区块并重置游戏
  • /badmin force_end <gamename> - 强制游戏立即结束
  • /badmin list [all |<gamename>] [team] - 列出游戏中所有已知的信标|由团队拥有的所有比赛
  • /badmin listparms <gamename> - 列出游戏参数
  • /badmin newgame <gamename> [<parm1:value> <parm2:value>...] - 创建一个空地区的新游戏;参数是可选的; parameters are optional - do /badmin newgame for a list of the possible parameters  (好像是参数。。。不知道啊）
  • /badmin reload - 重新加载插件，保留现有的游戏
  • /badmin switch <online playername> - 开关团队在一个游戏
  • /badmin teams [all | <gamename>] - 显示一个游戏团队和团队成员

                                                                                                                                                                  权限

beaconz.map.unclaimed:    description: Can see all unclaimed beacons on a map    default: op   (OP权限:在地图上可以看到所有野外的灯塔)
beaconz.admin:    description: Can use admin commands    default: false (OP权限:能使用管理员命令)
beaconz.player:    description: Can player beaconz    default: true(玩家能进行游戏,系统默认已给权限)
beaconz.player.leave:    description: Player can leave a beaconz game before it finishes    default: false(玩家能自由退出游戏,默认无权限)
