简洁大厅1.1
这是一款用于登录大厅的简洁管理插件
最新更新内容
1.加入自定义配置
2.加入指令设置**注意**以前使用1.0版本的需要删除配置文件更新!


功能
掉落免受伤害、登录切换冒险模式、固定上线地点、掉落虚空传送、禁止破坏、禁止放置、禁止丢弃、禁止移动物品、无饥饿、禁止攻击、禁止聊天、禁止天气变化、禁止爆炸、自定义加入退出消息

指令

/lobby setspawn 设置出生点
/lobby spawn 传送至出生点
/lobby reload 重载配置文件
配置
  1. #大厅地点坐标,用于登录传送与虚空传送,可在游戏中输入/lobby setspawn设置
  2. location:
  3.   world: 'world'
  4.   X: 0
  5.   Y: 0
  6.   Z: 0
  7.   Yaw: 0.0
  8.   Pitch: 0.0
  9. #是否开启登录服务器传送到固定地点
  10. LoginTeleport: false
  11. #是否开启掉入虚空传送到固定地点
  12. VoidTeleport: false
  13. #登录后是否切换为冒险模式
  14. LoginAdventure: false
  15. #是否允许聊天
  16. Chat: true
  17. #是否允许建筑与破坏
  18. Build: false
  19. #是否允许拾取物品
  20. PickupItem: false
  21. #是否允许丢弃物品
  22. DropItem: false
  23. #是否扣饱食度
  24. Hunger: false
  25. #是否允许PVP
  26. Pvp: false
  27. #是否受到生物造成的伤害
  28. Damage: false
  29. #是否受到跌落造成的伤害
  30. FallDamage: false
  31. #是否允许移动背包中的物品
  32. ItemMove: false
  33. #是否允许天气变化
  34. Weather: false
  35. #是否允许爆炸
  36. Explosion: false
  37. #加入服务器提示消息,填none将没有提示,玩家变量%player%
  38. JoinMessage: '&a%player% join the server!'
  39. #退出服务器提示消息,填none将没有提示,玩家变量%player%
  40. QuitMessage: '&c%player% leave the server!'
