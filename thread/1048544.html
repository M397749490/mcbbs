[15:04:39] [Server thread/WARN]: Can't keep up! Is the server overloaded? Running 6514ms or 130 ticks behind

只是告诉你服务器卡了。通常是 cpu 主频过低

设置内存的话，创建一个文本，其中的内容写 java -Xmx2048M -Xms2048M -jar minecraft_server.jar

然后后缀改为 .bat ，然后双击就是设置了 2g 的内存了
