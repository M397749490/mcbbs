插件介绍


作者已明确表示不支持CraftBukkit
支持的服务器核心类型:Spigot/PaperSpigot及其Fork版本(CatServer/Mohist等有希望了)
此插件不推荐使用 Yum/Plugman/EazyPluginManager等插件管理插件热加载/重载, 若因此出现数据丢失/回档等问题, 概不负责

来自原帖: # 经过部分删改及润色
插件概述


此插件向服务器带入了一套全新的, RPG风格的技能系统(类似于MCMMO), 玩家能通过做各种各样的事情获得对应的技能经验, 并且也能从其中获得强大的能力。每一种能力都能以特别的方式提升玩家游戏的趣味程度以及一定程度上的难度。本插件是因为受到了 MCMMO 和 Hypixel SkyBlock 的启发而制作的, 并且高度可自定义, 可以个性化, 能够最大程度地成为服务器一大特色, 同时提升玩家体验而不至于损失原有趣味。随着版本的更新, 更多特色化的技能以及选项/特性等会被加入。我们也希望在各位用户的帮助下，能让 Aurelium Skills 变得更好。

插件特点

- 15 种独特的技能 (耕作Farming, 锻造Foraging, 挖矿Mining, 钓鱼Fishing, 采掘(旧版本翻译为掘土)Excavation, 箭术Archery, 防御Defense, 战斗Fighting, 耐力Endurance, 敏捷Agility, 炼金Alchemy, 附魔Enchanting, 巫术Sorcery, 治愈Healing, 以及锻造Forging)
- 6 种玩家属性 (生命Health, 力量Strength, 再生Regeneration, 幸运Luck, 智慧Wisdom, 以及韧性Toughness)
- 简洁明了, 能显示详细信息的 GUI
- 能够自定义物品和盔甲上的特殊属性
- 自定义打怪, 采集和钓鱼获得的特殊物品(掉落表/道具池, 原文为 Loot Table)
- 经验值来源及大小均可修改,支持 MythicMobs 自定义怪物作为经验来源
- 多语言支持(目前支持波兰语/简体中文/繁体中文(未翻译完)/俄语(未翻译完)/越南语(未翻译完)/英语/法语/德语(未翻译完)/土耳其语/西班牙语/葡萄牙巴西文/立陶宛语/印度尼西亚语等) # 默认只携带10种包括简体中文在内的部分语言
- ActionBar 与 BossBar 位置显示
- 可供开发者使用的 API
- 支持MySQL

插件配置文本&各大技能介绍

技能
每一个技能都会为玩家增加两种属性，这两种属性分别为主副属性
主属性增幅相对较大，而副属性增幅相对较小
方括号内的为增加的主副属性, 顺序为[主属性,副属性]
- Farming 耕作 (收获作物) [生命, 力量]
- Foraging 伐木 (伐木) [力量, 韧性]
- Mining 挖矿 (挖矿) [韧性, 幸运]
- Fishing 渔技 (钓鱼) [幸运, 生命]
- Excavation 采集 (掘土) [自愈, 幸运]
- Archery 箭术 (使用弓射杀生物) [幸运, 力量]
- Defense 防御 (减少伤害) [韧性, 生命]
- Fighting 搏斗/近卫 (使用近战武器杀死生物) [力量, 自愈] # 暂时不清楚此项对于CrackShot枪械子弹杀死生物的判定
- Endurance 探索 (行走、跳跃) [自愈, 韧性]
- Agility 杂技 (受到摔落伤害) [智慧, 自愈]
- Alchemy 炼药 (制作药水) [生命, 智慧]
- Enchanting 附魔 (附魔物品) [智慧, 幸运]
- Sorcery 魔法 (使用消耗魔法的技能) [力量, 智慧]
- Healing 自愈 (使用药水，包括喷溅与滞留药水) [自愈, 生命]
- Forging 锻造 (使用铁砧合成相同物品) [韧性, 智慧]

属性
- Strength 力量 (提升近战伤害)
- Health 生命 (提升最大生命)
- Regeneration 自愈 (提高生命与魔法恢复速度)
- Luck 幸运 (提升幸运值并有机率掉落双份战利品)
- Wisdom 智慧 (提高经验值获取倍率，提升魔法上限，降低铁砧经验消耗)
- Toughness 韧性 (减少正受到的伤害)

钓鱼技能/采集技能能够爆出配置文本(loot)里面的稀有掉落物和史诗掉落物

插件指令&权限

此插件指令似乎和Skript冲突
无括号权限表示所有玩家均可打开
从属关系: Ability Xp(能力经验) -升级> Ability(即/sk界面图标显示的总等级数) -随等级提升，解锁> Skill(特定的技能或属性加成)

[] 为可选参数 | <>为必填参数

- /skills 或 /skill 或 /sk - 打开技能菜单
- /stats - 打开属性菜单(注意，不会载入AP、SX为玩家添加的属性点，那种添加的属性点会只显示在总生命值而不是附加值)
- /sk ability setlevel <玩家名> <能力名> <等级数> - 设置特定玩家的能力等级 (aureliumskills.ability.setlevel)
- /sk skill setlevel <玩家名> <技能名> <等级数> - 设置技能等级 (aureliumskills.skill.setlevel)
- /sk xp add <玩家名> <技能名> <数量> - 添加能力经验至某玩家 (aureliumskills.xp.add)
- /sk xp set <玩家名> <技能名> <数量> - 设置玩家的能力经验为定值
- /sk xp remove <玩家名> <技能名> <数量> - 删除特定数量玩家的能力经验
- /sk skill setlevel <玩家名> <技能名> <数量> - 设置技能等级
- /sk skill setall <玩家名> <等级> - 设置玩家所有的技能至同一个指定的等级
- /sk skill reset <玩家名> [技能名] - 将玩家的技能等级重置为1，若不填则默认为全部
- /sk top [技能名] - 显示排行榜 (aureliumskills.top)
- /sk lang <语言> - 改变语言 (aureliumskills.lang)
# 中文语言为 zh-CN
- /sk reload - 重载配置文档 (aureliumskill.reload)
- /sk modifier add <玩家> <属性名> <属性名称> <值> [是否静默] - 给玩家添加一个属性
- /sk modifier remove <玩家> <属性名> [是否静默] - 删除玩家的一个属性
- /sk modifier list [玩家名] [属性] - 列出玩家身上所有的属性改变
- /sk modifier removeall [玩家名] [属性] [是否静默] - 删除玩家所有的属性改变
- /sk item modifier add <属性名> <值> [lore] - 为你的物品增加属性,默认有Lore
- /sk item modifier remove <属性名> [lore] - 删除你的物品增加属性,默认也会删除Lore
- /sk item modifier list - 列出手上物品的所有属性
- /sk item modifier removeall - 删除手上物品所有属性
- /sk armor modifier add <属性名> <值> [lore] - 为你的防具增加属性,默认有Lore
- /sk armor modifier remove <属性名> [lore] - 删除你的防具增加属性,默认有Lore
- /sk armor modifier list - 列出手上防具的所有属性
- /sk armor modifier removeall - 删除手上防具所有属性
- /sk multiplier [玩家名] - 显示玩家当前经验翻倍数量(取决于玩家拥有的权限)
- /sk help - 显示帮助菜单

完整权限列表请在这里查阅

目前可用变量:
%aureliumskills_power% - 类似于MCMMO的战力显示，也就是技能综合评价值
%aureliumskills_[技能]% - 特定技能的等级 (ex: %aureliumskills_farming%)
%aureliumskills_[属性]% - 特定技能的属性 (ex: %aureliumskills_health%)
%aureliumskills_hp% - 整数的血量
%aureliumskills_hp_1% - 带一位小数的血量
%aureliumskills_hp_2% - 带两位小数的血量
%aureliumskills_mana% - 玩家当前魔力值
%aureliumskills_<技能名称>_roman% - 玩家特定技能的等级，以罗马数字显示
%aureliumskills_rank% - 玩家的战力排名
%aureliumskills_rank_<技能名称>% - 特定技能的玩家排名

Config详解

单独开在一楼有些不方便，特此再在这一楼详细解释Config的文本配置
部分内容取自作者的插件Github Wiki

语言部分

default-language - 插件对玩家使用的默认语言，必须有对应的文档与之相连
# 中文文档名称为 cn,对应文件为messages_cn.yml

try-detect-client-language - 若设置为 true 则插件会尝试使用客户端使用的语言, 并且这个语言在Aurelium Skills上有对应的语言文件. 此选项仅适用于没有使用指令选择语言的玩家,或者在服务器突然重启后丢失已选择语言设置的玩家. 若客户端使用了Aurelium Skills没有的语言文件，则默认使用 default-language 设置的语言.若设置为 false ,则全部玩家都使用 default-language 设置的语言

languages - 可供玩家使用指令 /skills lang <语言> 切换的语言文件列表; 必须有对应的语言文档与之对应,语言本土化可以从这里设置.

Actionbar设置部分

enabled - 是否启用此功能

idle - 控制除了经验获取部分的其余所有静态部分如血量和魔法值的显示，设置为 false 可以关闭血量和魔法值的显示

xp - 控制经验获取的提示

maxed - 控制满级时经验获取的提示

update-period - Actionbar刷新时间，设置为更大值意味着越频繁的更新和卡顿，不推荐改动此项。

round-xp - 若启用则会将获得的经验值简化为一位小数

placeholder-api - 是否替换来自于其他插件的变量符，取决于你是否安装了 PlaceholderAPI

Bossbar部分

enabled - 是否启用此功能
# Bossbar的功能是和MCMMO类似的经验值收集进度条

mode - 可以设置为 single 或 multi. multi 允许多个 Bossbar (在获得不同技能的经验值)同时显示, 设置为 single 则每次只显示一个.

stay-time - 若经验值没有新变动，持续的时间

update-every - 控制连续增加经验值时 Bossbar 的更新间隔，如果出现卡顿问题那么试着调大数值

round-xp - 若启用则会将获得的经验值简化为一位小数

format - 不同技能的Bossbar颜色样式:
# 格式参考: '[技能名称] [颜色] [分割样式]'
# 可用颜色: BLUE, GREEN, PINK, PURPLE, WHITE, RED, YELLOW
# 可用分割样式: SOLID, SEGMENTED_6, SEGMENTED_10, SEGMENTED_12, SEGMENTED_20

base-mana - 不知道为什么要把这个选项放在 Bossbar 部分。玩家初始 (智慧为0时) 的魔法值

enable-roman-numerals - 决定技能等级是否使用罗马数字

Damage Hologram部分
# 相当于是一个小小的攻击力显示器。不过很遗憾，目前为止暂时无法修改其中的文本

damage-holograms - 是否启用此功能
# 需要以 HologramDisplays 用作前置

damage-holograms-scaling - 以之前配置文本内设置的 health.hp-indicator-scaling 属性为放缩比例，对攻击显示内的数值进行放缩

damage-holograms-decimal:
    - display-when-less-than: 指的是当造成伤害小于多少时才显示伤害悬浮字
    - decimal-max-amount: 指的是最多显示几位小数

damage-holograms-offset:: 指的是XYZ坐标上伤害值显示悬浮字的固定偏移距离
    - x - X 坐标轴偏移
    - y - Y 坐标轴偏移
    - z - Z 坐标轴偏移
    random: # 悬浮字基于以上固定偏移的随机偏移
      enabled - 是否启用此功能
       x-min - X轴最小偏移
       x-max - X轴最大偏移
       y-min - Y轴最小偏移
       y-max - Y轴最大偏移
       z-min - Z轴最小偏移
       z-max - Z轴最大偏移

Leaderboards部分
    leaderboards:
      update-period - 排行榜全息字刷新间隔，单位为刻(tick)

      update-delay - 插件自动备份过后刷新全息字数据的延迟时间(不包括开启服务器时的备份)

Gameplay设置部分

skill-level-requirements-multiplier - 更改技能升级经验值需求的倍数。计算公式为
( 要求经验数 = 此处倍数 x (技能等级 - 2)² + 100 )

enable-skill-commands - 决定 /farming 或 /mining 诸如此类的指令是否有效。需要重启服务器以应用更改。

check-block-replace - 检查方块复位。顾名思义就是为了防止玩家通过重复放置方块达到刷经验的目的，默认为开。

Worlds and Regions:

blocked-check-block-replace-worlds - 禁用检查方块复位的世界

blocked-check-block-replace-regions - 禁用检查方块复位的 WorldGuard 区域 (1.13+)

blocked-worlds - 禁用经验获得的世界列表 (仅限通过正常途径获得的经验, 指令添加的不算)

blocked-regions - 禁用经验获得的 WorldGuard 区域列表 (同上,需要 1.13+)

disabled-worlds - 禁用插件功能以及显示的世界, 但菜单指令仍然可用

disable-in-creative-mode - 决定玩家是否能在创造模式下获得经验

Economy:

skill-money-rewards - 决定技能升级是否奖励金钱
    enabled - 开关
    base - 玩家在第二级获得金钱奖励的数量, 参与下方计算公式
    multiplier - 获得奖励的倍数 ( 计算公式: 奖励金钱数 = 第二级奖励基数 + 获得奖励倍数 x 等级² )

Leveler:

leveler:
  title: 升级提示标题
    enabled - 是否启用此功能
    fade-in - 标题淡入持续时间
    stay - 标题停留时间
    fade-out - 标题淡出持续时间
  sound: 升级提示声音
    enabled - 是否启用此功能
    type - 声音种类，需为有效声音
    category - 声音种类子类, 例如猫愤怒或猫受伤，后两者动词/形容词属于这个地方
    volume - 决定音量大小
    pitch - 决定音调大小
double-check-delay - 二次检查时间，适用于一次性获得大量经验时显示上述内容的时候的时间间隔

常见问题解答

方便一些摸不着头脑特别是第一次用这个插件的腐竹们快速解决他们遇到的问题
部分内容取自作者的 Github Wiki

Q: 后台显示的文字不管切换到什么语言总是没办法显示中文，怎么办？
A: 有部分作者写死在代码里面的内容，我没法翻译，抱歉。但是你可以通过修改配置文本内的语言文档选择或使用/sk lang zh-CN来汉化大部分内容，游戏里面的所有技能(菜单里的)已经全部汉化完毕并可以直接使用。

Q: 输入sk打开的菜单里的物品可以随意扔出而且没有办法正常操作，怎么办？
A: 确保你的插件本体或者 SmartInvs 是最新版，然后重新试试看。

Q: 重启服务器后会导致已设置好的语言变成默认语言，怎么办？
A: 其实这个问题也在困扰着我，我会和作者取得联系让他解答相关问题
    尝试修改服务器默认语言为中文，这样插件可能会默认使用中文

Q: 我有很多很多脑洞想让这个插件更新，去哪里反应？
A: 除了 SpigotMC 的评论区域以外，你还可以到 Discord 的 suggestion 也就是建议板块去和作者反馈
    (并且还能时不时看到我活跃的身影)

Q: 安装插件以后执行 /sk 出现报错并且后台刷的报错是 unknownDependency 相关的，怎么办？
A: 请安装 SmartInvs 作为前置插件再试试重启服务器。
