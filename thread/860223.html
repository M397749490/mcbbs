2019/4/25 算法周报第一期 图与MC
引语
大家都知道生物AI吧，一些生物会自动跟踪玩家。
不知道MC是怎么控制这个机制的。
我认为，这其实是一种不带边权的最短路，每个坐标是一个图中的点。
若某个坐标有实体方块，则它周围的点不能与这个点相连（即需要绕路）
图是什么？MC怎么转化成图？
如图，假设同一平面内相邻的四个方块（第一步）
生物可以从某一方块走到相邻的方块（第二步）
于是把每个方块剥离开，连接路径依然不变（第三步）
接着把各个方块抽象化，分别变成点1、2、3、4，它们之间连有线段，这就是图了（第四步）
图（Graph）通常用字母g表示，一般来说g=[V,E]，V表示图中的所有点（例如点(-1,1)）的集合，E表示图中的所有边（例如边(1,-1—-1,-1)）的集合。
怎么实现图的存储？
我们可以用一个二维动态数组（叫做邻接表）存图。
已知：ArrayList[] g=new ArrayList[100];
数组的一维表示各个点，例如g[1]表示了点1的信息。
那g[1]对应的ArrayList中存放什么呢？当然是存放与1互相连接的那些点啊！
我们可以从上图中知道点1与点2相邻，那么我们在g[1]对应的ArrayList中添加点2：
g[1].add(2);
当然，因为从点2也能到达点1，所以也要在g[2]对应的ArrayList中添加点1：
g[2].add(1);
这样，我们就能存储点和点之间的边了
我们已经存好了图，该怎么读取呢？

我们实现了图，该怎么搜索呢？
注：搜索就是从某点出发递推，把整个图按某种顺序扫描完。
这就引入了DFS:
DFS:深度优先搜索：就是从某点出发，扫描该点连接的所有点，在递归扫描下去（就是从扫到的点开始接着扫）
如何实现：
boolean vis[100]=new boolean[100];  //存储点有没有扫描过，防止重复扫描
void dfs(int A){ //DFS方法，A表示目前从那个点开始扫描
    vis[A]=true;  //表示该点已经扫描过了
    for(int B=0;B<g[A].size();B++)
        if(vis[g[A].get(B)]) continue;  //若已经扫描过，则跳过
        else dfs(g[A].get(B)); //递归深层遍历
}
好了，回到开头，图中怎么求最短路？
先介绍BFS(广度优先搜索)：
首先访问起始点A
然后由A出发，依次访问A的各个未被访问过的连接点B[sub]1[/sub],B[sub]2[/sub],B[sub]3[/sub]...B[sub]n[/sub]
然后再依次访问B[sub]1[/sub],B[sub]2[/sub],B[sub]3[/sub]...B[sub]n[/sub]的所有未被访问过的连接点
以此类推，直到途中所有的顶点都被访问过为止
BFS怎么实现呢？
怎么求最短路？
void bfs(int A){  //从点A开始搜索
    int[] vis=new int[100];  //存储每个点是否扫描过，避免重复扫描
    Queue<int> queue = new LinkedList<int>();  //用于BFS搜索的数据结构：队列，不懂得小伙伴可以百度
    queue.offer(A);  //先把点A加入搜索顺序列表中
    while(!queue.empty()){  //是要搜索顺序列表中还有点，就继续搜
        int B=queue.poll();  //从搜索顺序列表中弹出最近的任务并删除它
        vis[B]=1;  //表示B点已经搜索过了
        for(int i=0;i<g[B].size();i++)  //循环搜索B点连接的其他点
            if(v[g[B].get(i)]==1) continue;  //若搜过了，跳过
            else queue.offer(g[B].get(i));  //若没搜过，把新的点加入搜索计划
    }
}
使用BFS，我们可以求解一个满足上述定义的图的单源最短路径问题
这是由BFS总是按照距离由近到远来遍历图中每个顶点的性质决定的
于是我们就可以求出A点到B点最短路啦！
