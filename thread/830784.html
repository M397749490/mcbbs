ChestPreview 1.3.2
此插件允许服务器管理员添加展示用箱子


简介:

相信很多伺服器都会需要展示箱这类的物品,
玩家需要有权限才能编辑箱子内的物品(可以打开)

插件指令&权限

/ChestPreview help : 显示所有指令
/ChestPreview create : 下一个放置的箱子将会是展示箱
/ChestPreview : 显示所有展示箱
/ChestPreviewt reload : 重载插件
  •                             ChestPreview.admin：允许管理员创建展示箱
  • ChestPreview。*：给予op


如何使用ChestPreview：
获得OP或获取ChestPreview.admin权限。要创建展示箱，请使用 /chestpreview create，然后放置箱子或右键单击手中箱子在已存在的箱子旁。您还可以通过修改config.yml来使某世界上所有的箱子都是展示用箱子。只要您拥有ChestPreview.admin权限，您就可以添加，移除或移动箱子的任何物品。否则，您虽能打开箱子，但您将无法从中取出任何东西。
