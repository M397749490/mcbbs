  • 标志符的命名规则是什么？
  1. * 一个合法的标识符只能由数字、字母、下划线_、美元符号$ 组成，不能含有其他符号
  2. * 不能数字开头
  3. * 严格区分大小写
  4. * 关键字不能做标志符 public class static void 之类的蓝色字体都是关键词，不能做标志符
  5. * 理论上无长度限制，最好别太长
