入门
使用本插件并不困难，只需要简单几步配置即可做出一个完整的派系系统，让玩家常驻服务器。
你可以在这里查看所有的入门简介。

在开始之前，有一些问题需要考虑，我建议拿起一张纸，写下你想到的：
游戏模式：和平，半战争，战争，还是混合？
经济系统！你的服务器是否有经济系统？玩家应该花费多少钱？
你使用地标吗？地标附带密码吗？
您是否想为RPG服务器创建多个永久派系？
你想让玩家使用什么命令？
准备好了，那就让我们开始吧！

重要文件和目录：
  • LegacyFacts / database / - 这个地方禁止修改，这里是数据库，为了避免数据损坏，请勿修改这些文件。
  • LegacyFacts / commandAliases.json - 要修改命令如何显示给玩家，您可以在此处更改其别名。
  • LegacyFacts / conf.json - 这是主要的配置文件，您可以在此处修改插件的所有配置，修改后，输入/f reload即可重载插件配置！
  • LegacyFactions / tags.json - 这是标签文件， 您可以在此处更改聊天消息中使用的标签的颜色。 （例如<b>设置为<rose>（红色），<i>设置为<黄色>（黄金）
  • LegacyFacts / lang.yml - 这是语言文件， 您可以在这里修改LegacyFacts中使用的语言。
修改json文件时，请注意一定要遵循格式，你可以在这里验证格式是否正确，格式设置错误可能会导致插件无法正常运行。

第一步：查看插件命令帮助
LegacyFactions插件有很多命令，玩家可以输入/f help来查看这些命令。
这是调用JSON的帮助菜单，因为它使用Minecrafts JSON菜单来创建按钮。

[<] 和 [>] 图标是用于换页的按钮。 或者，你可以键入/f help 2，/f help 3等。它非常灵活！
该菜单根据玩家的权限自动生成，所以他们只看到允许使用的命令！
有些服务器可能不希望这样 - 这样可以！ 您可以通过将conf.json文件中的useOldHelp转换为true来切换到较旧的1.6样式的帮助菜单。
但也许一些服务器想要自己写一些帮助，或者只是改变它来将用户链接到wiki！

基础：
使用命令所需的权限，为了简化，插件已经自动创建了一些权限工具包。
  • factions.kit.halfplayer：可以做所有的事情，除了创建派系。
  • factions.kit.fullplayer：可以做所有事情，包括创建派系。
  • factions.kit.halfmod：可以使用Zones, bypassing, kicking, and chatspy
  • factions.kit.mod：所有派系权限，除了配置和永久性。
  • factions.kit.admin：所有派系权限。
如果您是服务器OP并希望能够绕过权限，可以使用/f bypass命令，这将启用最高权限模式。
有关命令的完整介绍，请阅读权限和命令页面的帮助信息。

多语言脚本支持
如果插件不支持中文输入，你可以在这里开启支持中文字符输入。
这一部分讲解如何让插件支持一些非英文字符。

只要是Java Unicode支持的字符，LegacyFaction都可以支持，你可以在这个网站找到一个完整的值列表：
https://docs.oracle.com/javase/8/docs/api/java/lang/Character.UnicodeScript.html
打开你的config.json文件,找到enabledScriptSupport这一段，LegacyFactions默认设置了一些值：
  1. "enabledScriptSupport": {   
  2. "BALINESE": false,   
  3. "KHMER": false,   
  4. "ARABIC": false,   
  5. "HAN": false  
  6. },
复制代码
再举个例子，如果想使用中文字符就需要把默认HAN的值从false改为true，就像这样：
  1. "enabledScriptSupport": {   
  2. "BALINESE": false,   
  3. "KHMER": false,   
  4. "ARABIC": false,   
  5. "HAN": true
  6. },
复制代码
如果你想要的脚本类型没有列出来，很简单，只要把”BALINESE”换成你想要的脚本类型。例如，如果你想用希腊语：
  1. "enabledScriptSupport": {
  2.     "GREEK": true,
  3.    "KHMER": false,
  4.     "ARABIC": false,
  5.     "HAN": false
  6.   },

扩展: 派系聊天频道
聊天格式
这里有一个派系聊天频道专属的占位符 {fc_message} 来显示玩家发送的消息内容。
你也可以使用其他的占位符。

配置
你可以参照下文调整派系聊天频道的配置文件：

enable
默认: true
如果开启，玩家就可以使用派系聊天频道了。

enableAllianceChat
默认: true
如果开启，玩家除了可以使用派系聊天之外，还可以使用盟友之间的聊天 (/f chat a)

enableTruceChat
默认: true
如果开启，玩家除了可以使用派系聊天之外，还可以使用停战聊天 (/f chat t)

enableFormatPublicChat
默认: false
如果开启，聊天格式将用于普通聊天，如果你希望所有聊天格式都是派系提供的，可以开启此功能。

chatFormatPublic
默认: {factions_player_role_prefix}%s:§f%s
这个是公共聊天格式配置，第一个 % 是玩家名字，第二个 % 是消息内容，可以直接省略 {factions_player_name} 和 {fc_message}

chatFormatFaction
默认: §a{factions_player_role_prefix}%s:§f %s
这个是派系内聊天格式配置，第一个 % 是玩家名字，第二个 % 是消息内容，可以直接省略 {factions_player_name} 和 {fc_message}

chatFormatAlliance
默认: §d{factions_player_role_prefix}%s:§f %s
这个是盟友聊天格式配置，第一个 % 是玩家名字，第二个 % 是消息内容，可以直接省略 {factions_player_name} 和 {fc_message}

chatFormatTruce
默认: §5{factions_player_role_prefix}%s:§f %s
这个是停战聊天格式配置，第一个 % 是玩家名字，第二个 % 是消息内容，可以直接省略 {factions_player_name} 和 {fc_message}

chatFormatSpy
默认: §7(spy) {factions_player_role_prefix}%s:§7 %s
这个是管理员监视聊天格式配置，第一个 % 是玩家名字，第二个 % 是消息内容，可以直接省略 {factions_player_name} 和 {fc_message}

chatPluginChannelUse
Default: true
如果开启，派系聊天记录会被同步到一个指定频道，目前仅支持 VentureChat 插件，所有消息将会自动同步到该频道，例如 /f chat a 就会加入聊天频道。

chatPluginChannelGlobal
默认:
如果你开启了上面的功能，请在这里填写频道名称。

chatTagEnabled
默认: true
如果启用，自动替换占位符为玩家名称。

chatTagRelationalOverride
默认: false
如果占位符不工作，请开启此选项。

chatTagPlaceholder
默认: {factions_chat_tag}
自定义占位符。

配置
注意：如果你修改了conf.json里面的内容 - 你可以使用 /f reload 来重载配置文件，但是绝对不要使用 plugman 或是 /reload 命令!

enabled (默认值: false)
开启派系飞行功能。

disableEnderpearlWhileFlying (默认值: true)
如果开启，在飞行时禁止使用末影珍珠。

disableChorusFruitWhileFlying (默认值: true)
如果开启，在飞行时禁止使用紫颂果。

maxY (默认值: -1)
限制玩家飞行高度，设置为-1则不限制。

onDisableNoFallDamage (默认值: true)
如果开启，玩家将不会受到跌落伤害。

onDisableTeleportToFloor (默认值: false)
如果开启，当玩家飞到禁止飞行的区域内，将会取消飞行状态并传送到地面。

LegacyFactions 自带对 PlayerVaults 的支持。

  • PlayerVaults 下载点 Bukkit Projects

功能
这个支持会将PlayerVaults带入LegacyFactions中！

命令
/f vault [数字]
权限: factions.vault

/f setmaxvaults [派系] [数字]
权限: factions.setmaxvaults

配置文件设置
vaultPrefix
Default: faction-%s
这是数值的前缀设置，但是默认的配置应该也不错。

WorldGuard支持：
LegacyFactions 自带对 WorldGuard 的支持。
WorldGuard 并没有在 SpigotMC
WorldGuard 下载点 Bukkit Projects

功能
此功能可以让派系无法领取WorldGuard划定的区域作为领地。

命令
没有任何可以用此功能的命令。

配置文件设置：
worldGuardChecking
Default: false
开启后，将无法领取已经被WorldGurad划定的区域。

worldGuardBuildPriority
Default: false
开启后，将给予worldGuard建造优先级，如果玩家在他们有权限的地方建造, 那么他们将绕过 wildernessDenyBuild, worldsNoWildernessProtection, safeZoneDenyBuild,以及 warZoneDenyBuild的权限限制。

请使用可用的方法：
你不能存储或修改 FactionColl.all() 的结果，如果你需要获取派系，请使用 FactionColl.get(faction name/id)

不要使用被弃用的方法：
