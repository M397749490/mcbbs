关于节拍：
一个四分音符是一分钟60/76=0.789，一个中续器一档是0.1秒，那么一个四分音符约=两个中续器下面是对照表
节拍中续器个数档位
0---八个中续器满档
0-四个中续器满档
0两个中续器满档
0一个中续器满档
0
=		一个中续器两档位
0
=
=  		一个中续器一档
