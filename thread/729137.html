安装与使用
购买本插件，放进plugins文件夹，重启服务器

如果想使用金钱购买技能升级功能，你需要安装Vault或者PlayerPoints
如果想添加区域或者派系限制，你可以安装WorldGuard或者Factions

两种技能升级系统只能选择一种，你可以在settings.yml中修改
  1. # 这个插件用什么升级系统？
  2. # 可选: rpg, money
  3. # rpg代表RPG经验计费，money代表金钱购买
  4. system: rpg
复制代码



指令&权限

  • /abilities menu - 打开技能菜单
  • /abilities open <玩家名> - 为玩家打开技能菜单
  • /abilities stats - 查看自己的RPG经验状态
  • /abilities reset - 重置玩家的数据
  • /abilities menu page <页> - 打开技能菜单的一页
  • /abilities help - 插件帮助
  • /abilities stats <玩家名> - 查看玩家的RPG经验状态
  • /abilities hologram create - 在你所站位置创建一个显示玩家技能状态的悬浮字
  • /abilities hologram list - 列出悬浮字列表
  • /abilities hologram remove - 移除悬浮字


本插件没有任何权限需要给玩家
