一、MOD介绍

你是否曾经建造了一些很牛X的防御型建筑，准备了很多工具，武器，锁上了你的箱子，但是这些东西似乎就是个摆设品呢？很少有怪物光顾。
那么你得好好看看这个MOD了，你觉得定期的怪物对你构不成猥亵，你想要测试下你的防御能力，那么试试这个MOD吧，当然这个MOD也添加了一些有用的合成物品。
Invasion Mod能够在你指定的地点召唤怪物攻击，难度随着次数的增加稳步上升。怪物种类不会改变，但是所以入侵的怪物的行为被更改了。许多怪物有了新的能力，他们集合在一起，打算和你大战一场。
当然你成功防御住了，也是有奖励的。

二、MOD玩法
入侵方块是整个MOD的核心部分.合成一份catalyst （入侵催化药剂）然后将它放入 nexus（入侵方块）的物品槽，强的催化剂和稳定的催化剂可以增强效率，以此激活入侵方块。当全部激活的时候，它会产生rift flux（裂变溢出物）,一种有用的资源，使用Minecraft的空间，类似地狱门，但是它无法被关闭，无法被破坏然后怪物会同个这个通道来到当前区域攻击玩家建议装前先备份你的地图本MOD使用方法：将 放入到左边红色指示条的方格中，等待MOD激活，当如上图显示时，怪物将会一波接一波来临。

五、配置文件
  • 配置文件是.minecraft文件夹下的invasion_config.txt文件，用记事本打开。
  • true为真，false为假。

  • # Invasion Mod config
  • # Delete this file to restore defaults
  • # General settings and IDs
  • sounds-enabled=true（翻译：是否开起声音）
  • blockID-Nexus=null（翻译：入侵方块的id，null=默认值，默认值=216）
  • guiID-Nexus=76（翻译：入侵方块的窗口id）
  • craft-items-enabled=true（翻译：合成物品是否开启）
  • itemID-PhaseCrystal=null（翻译：相位水晶的物品id，null=默认值，默认值=24656）
  • itemID-RiftFlux=null（翻译：微微发光的残留物的物品id，null=默认值，默认值=24657）
  • itemID-Remnants=null（翻译：残余的物品id，null=默认值，默认值=24658）
  • itemID-NexusCatalyst=null（翻译：催化剂的物品id，null=默认值，默认值=24659）
  • itemID-InfusedSword=null（翻译：磨=魔炼之剑的物品id，null=默认值，默认值=24660）
  • itemID-IMTrap=null（翻译：陷阱的物品id，null=默认值，默认值=24661）
  • itemID-IMBow=null（翻译：灼烧之弓的物品id，null=默认值，默认值=24662）
  • itemID-CataMixture=null（翻译：催化剂混合物的物品id，null=默认值，默认值=24663）
  • itemID-StableCataMixture=null（翻译：稳定的催化剂混合物的物品id，null=默认值，默认值=24664）
  • itemID-StableNexusCatalyst=null（翻译：稳定的催化剂的物品id，null=默认值，默认值=24665）
  • itemID-DampingAgent=null（翻译：阻尼剂的物品id，null=默认值，默认值=24666）
  • itemID-StrongDampingAgent=null（翻译：强的阻尼剂的物品id，null=默认值，默认值=24667）
  • itemID-StrangeBone=null（翻译：奇怪的骨头的物品id，null=默认值，默认值=24668）
  • itemID-Probe=null（翻译：入侵范围调整器+方块强度查看器的物品id，null=默认值，默认值=24669）
  • itemID-StrongCatalyst=null（翻译：强的催化剂的物品id，null=默认值，默认值=24670）
  • itemID-EngyHammer=null（翻译：目测无用）
  • # Nexus Continuous Mode（翻译：入侵方块连续方式）
  • min-days-to-attack=2（翻译：最小攻击天数）
  • max-days-to-attack=3（翻译：最大攻击天数）
  • # Block strengths（翻译：方块强度）
  • # Add entries here for other mods' blocks（翻译：添加条目，在这里的其他MOD的块）
  • # Reference values: dirt=3.125, gravel=2.5, obsidian=7.7, stone=5.5 (plus up to 50% from special)（翻译：参考值：泥土= 3.125，沙砾= 2.5，黑曜石= 7.7，石头= 5.5（加上从特殊到50%））
