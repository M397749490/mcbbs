用这个自定义矿石生成器，您可以为每个玩家/权限组配置任意块的生成率。这个插件只适用于Skyblock、AcidIsland或旧的插件uSkyBlock。


注意:这个插件支持最新的spigot版本(1.12.2)和更老的版本，如1.11，1.10、1.9、1.8.8、1.7.10，等等。



(本插件需要一个Sky Block插件，AcidIsland或uSkyBlock)!


  • 下载并将插件放入plugins文件夹
  • 重载/重启你的服务器
  • 编辑配置（看下面）




下面是一个配置文件的梨子例子
  1. # You can create generators as much as you want.
  2. # Important: All generators should be named "generator1", "generator2", etc.
  3. # You can define the spawnrates of any block in the blocks-section.
  4. # The spawnrates are in percent, for example 57.3 are 57,3%.
  5. # All values together should be 100%. If all values together are higher or lower as 100, the plugin would'nt work correctly.
  6. # The permissions are custom, so you can make a generator for VIPS, and give them the permission "oregen.vip".
  7. # Are you finish with configuring? Just type /customoregen to reload the plugin!

  9. # Note: If the Island's owner is offline, the cobblestone generator would be choose the first Generator-Config.

  11. generators:
  12.   generator1:
  13.     # default generator
  14.     blocks:
  15.     # Please use Bukkit-Blocknames. List: https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html
  16.     - STONE:50.0
  17.     - SANDSTONE:40.0
  18.     - IRON_ORE:10.0
  19.     permission: ''
  20.     # You can also define from what level the generator should be activated. Example: Leave all permissions empty and
  21.     # only work with the island Level. The plugin would only consider the islandLevel then.
  22.     unlock_islandLevel: 0
  23.   generator2:
  24.     # vip generator, VIPS need generators.vip permission
  25.     blocks:
  26.     - IRON_ORE:90.0
  27.     - STONE:5.0
  28.     - SANDSTONE:5.0
  29.     permission: 'oregen.vip'
  30.     unlock_islandLevel: 0
  31. # Here you can define worlds where the generator should not work
  32. disabled-worlds:
  33. - "world_nether"
复制代码


您可以创建无限多的生成设定。
重要提示:所有的生成设定都应该被命名为“generator1”，“generator2”，等等这种名字。你可以定义任何岛屿的生成设定的生成率。
生成率应该为百分数,不是的话会被转化，如57.3，就是57，3%。
所有的值加起来应该是100%的。
如果所有的值的合在100以上，插件就不会正常工作。
权限是自定义的，因此您可以为VIP单独设置生成器，并授予他们“oregen.vip”权限。
您完成配置了吗?
只需输入/customoregen重载插件！


注意:如果这个岛屿的所有者是离线的，那么生成器将会选择第一个设定。


源码:https://github.com/mastercake10/CustomOreGen



你可以在config.yml中定义所有权限！
