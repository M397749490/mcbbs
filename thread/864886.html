TalexLoginOutSide

一款轻量级的外置登录

这款插件你可以使用以下语言
Java，C++，C#，php，E.....
可以说是支持80%的语言





这款插件的诞生

因为我的服务器的需要，然后因为我已经写好了启动器和服务器的socket，但是用的E，所以不想再用Java重写，于是我开创了一种新玩法，好像当时犯了一堆白痴的问题，一堆人跟我说dalao自己造轮子 [丢人]






插件的原理

这款插件的原理非常简单，就是运用E或者其他程序，在玩家需要的时候写到插件的配置文件，玩家加入的时候检查配置，也就是Player.Can里面，如果为true那么通过，通过后还原，所以你需要我提供的E模板，如果你是大佬，你甚至可以自己写[反正很简单] 当然也可以让我帮忙或者定制

配置文件[有点长]
我*，一改成靠左边就乱码，就这样吧复制到NP++自己慢慢看
  1. #常用变量
  2. # %player% 玩家名字                     %web% 官网
  3. # %displayer% 玩家的自定义名字          %rmbweb% 赞助地址
  4. # %uuid% 玩家的uuid
  5. # %money% 玩家的金币 暂未启用
  6. # %points% 玩家的点券 暂未启用
  7. #所有消息都可以输入 & 进行代替 §

  9. PluginInformation:
  10.     #版本请勿修改
  11.     PluginVersion: 1.2.0
  12.     #插件前缀可使用&
  13.     PluginPrefix: "§6Talex§cLogin§fOut"
  14.     #插件是否开启
  15.     PluginIsOpen: true
  16.     #玩家是否可以加入服务器
  17.     PlayersCanJoinServer: true
  18.     #插件一卸载就关服
  19.     PluginCloseServer: true
  20.     #当服务器不可以加入时踢出玩家消息
  21.     PluginCloseKickPlayerMessage: "§c抱歉，服务器维护中..."
  22.     #玩家不允许加入，则提示（不支持变量)
  23.     PlayerCannotJoinError: "§c您的账号未通过外置验证！"
  24.     #玩家登陆成功消息[全服]
  25.     PlayerLoginSuceess: "§7[§b+§7]§3%player%"
  26.     #玩家被封禁提示（不支持变量)
  27.     PlayeBanMsg: "§c此账号已被服务器封禁！"

  29. #服务器配置
  30. ServerConfig:
  31.     ServerName: "§fExample" #可以输入& 请不要太长
  32.     Web: "www.mcbbs.net"    #官网
  33.     RmbWeb: "www.rmb.com"   #赞助链接
  34.     ServerJoinTimeOut: 5000 #加入超时时间

  36. #玩家例子 请照着这样写入json
  37. Example: #这里的Example是玩家名字
  38.     #默认请为空，插件会自动填充，为空则代表未注册
  39.     UUID:
  40.     #第一次请为空，否则登录IP不一致将进行验证
  41.     Ip:
  42.     #玩家的密码，可以自由设置，为空则表示未注册 注意新玩家请全部为空 此项仅在内置登录时有用 外置登录将不做记录
  43.     PassWord:
  44.     #无需管
  45.     Time:
  46.     #金币，无需管，需要Vault进行前置
  47.     SoulMoney:
  48.     #点券，无需管，需要PlayerPoints进行前置
  49.     SoulPoint:
  50.     #验证码，必须填入，请不一致，每一次插件会重新生成，第一次请手动输入 必须6字符
  51.     Cord: "123456"
  52.     #输入true就是被BAN了 默认为空即可   
  53.     ban: false
  54.     #凭证，每次填表都把这个改成true即可
  55.     Can: true

如何使用
①下载 > 丢服务器 > 运行一次 > 打开config.yml > 设置参数[编码为ANSI]
②下载易语言模板，可以自行更改，CSS程序请自行运用
注意，易语言模板需要用到 精易模块 请自行下载[百度一堆好不]
