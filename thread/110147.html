标题: [截至1.6pre]Minecraft 1.6的已发布的各快照特性汇总（来自中文MinecraftWiki）
每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。
然而，每周快照主要是用于新特性展示，存在大量的漏洞。因此对于普通玩家建议仅做测试尝鲜用。

1.6快照的下载地址（正版没有必要手动下载）以及运行说明：
新的启动器更改了启动方式，原来的所有启动器已经没办法使用新版本了。

对于正版用户：
鉴于启动器还处于开发初期，建议每次新快照出现都重新下载一遍启动器。启动器适用于全PC平台。
Windows: http://s3.amazonaws.com/Minecraf ... er/MinecraftDev.exe
Mac/OSX: http://s3.amazonaws.com/Minecraf ... er/MinecraftDev.dmg
Linux/其它: http://s3.amazonaws.com/Minecraf ... er/MinecraftDev.jar

对于非正版用户：
请详细阅读Minecraft 1.6的每周快照&离线模式启动脚本下载一文，遵循里面的说明文件的指示，完成快照核心文件、库文件以及运行脚本的下载、放置以及运行操作。仅适用于Windows。

关注最新版本资讯，请关注mcbbs新闻版Minecraft官方版本信息索引（自正式版1.0.0至今）与版规

16pre(2013-6-25)
仅漏洞修复

13w26a(2013-6-24)
仅漏洞修复

13w25b(2013-6-18)
仅漏洞修复

13w25a(2013-6-17)
仅漏洞修复

13w24b(2013-6-15)

  • 地毯现在能够放置在任何方块的上方
    • 这些方块包括水源方块，树苗，火把，箱子，其他地毯，等
    • 这是用于解决无法在铁栏杆上放置地毯的方法 — 使它们哪里都能被放置
  • 添加了吸收效果
    • 两种金苹果都会给予1分30秒的效果


13w24a(2013-6-14)

  • 移除了材质包支持，添加了资源包
  • 添加了控制日夜交替的游戏规则 - doDaylightCycle
    • 将停止在当前的时间，使天空暂停移动
  • 蜘蛛现在有几率带着药水效果生成
  • 刷怪蛋现在可在水上使用


13w23b(2013-6-7)

  • 添加生命加速效果
    • 图标与药水效果均显示为红心
    • 金苹果也能有此效果


13w23a(2013-6-7)

  • 添加了/spreadplayers指令
    • 从一个点上散布一些玩家
    • 可设定玩家间最小和最大距离
    • 可用于将队伍放到一起
  • 添加了游戏规则天然生命再生naturalRegeneration
  • 药水平衡更改
    • 治疗药水从恢复6点生命值将至4点
    • 治疗药水从恢复12点生命值将至8点
    • 再生药水再生间隔加长
  • 金苹果的配方从使用8个金粒更改成了使用8块金锭
  • 闪烁的西瓜配方从使用1块金粒增加至8个
  • 添加了闪烁标语"HURNERJSGER?"和"What's up Doc?"


13w22a(2013-5-30)

  • 马、驴、骡、僵尸马、骷髅马具有新音效
  • 村民具有新的音效
  • 增加拴绳的强度，使其能耐拉扯


13w21b(2013-5-27)
纯漏洞修复

13w21a(2013-5-23)

  • 添加了马和驴的用户界面来调整鞍/盔甲/物品栏
    • 通过shift-右击开启，或在乘骑时按物品栏键开启
    • 界面内的内容会根据品种而改变：
      • 马，驴，和骡都有鞍的槽
      • 马拥有盔甲槽
      • 驴和骡没有盔甲，但在装备箱子时有15个槽的物品栏
  • 猪现在会和马一样显示它们的生命值
  • 开始将多个内容转移至新的属性系统：
    • 物品的属性会使用NBT标签：
      • 属性可使用固定的数值相加，相减和相乘
      • 一些物品拥有默认修改符来代替之前硬编码设定的属性
    • 实体属性
      • 这些特性能和其他NBT属性一样简单地修改
      • 实体速度，基础生命，基础攻击
    • 其他像武器伤害/箭连射速度/挥剑速度将随后加入
  • 给一些工具，武器，和药水添加了效果标签
  • 正在开发新的资源包系统。目前仍和材质包兼容。
  • 新的内部聊天系统：解决了之前信息没有被翻译的问题
    • 信息被更好地模块化
    • 服务器信息将发送它们的代码名，并由客户端根据它们正在使用的语言设定来翻译
    • 颜色现在可以特别设定来避免更多的信息泄露
  • 马铠不能堆叠了



13w19a(2013-5-10)

  • 添加了与羊毛颜色相同的彩色硬化粘土
  • 拥有箱子的驴和骡现在可以在潜行时开启
    • 驴和骡的名字将会像重命名过的容器出现在箱子GUI内
  • 木炭，煤炭块，和青金石块获得了新的材质
  • 生物又会成群生成了


13w18c(2013-5-3)
纯漏洞修复

13w18b(2013-5-2)
纯漏洞修复

13w18a(2013-5-2)

  • 添加了煤炭块
    • 使用3x3煤炭合成
    • 只能用煤炭合成，不能使用木炭
    • 能作为熔炉燃料使用，一块能烧炼72个物品，相当于9个煤炭
    • 可用于储存大量煤炭
  • 开始使用新的材质加载系统
    • "也许会爆炸"
    • 新的 "缺失材质" 材质
  • 为拴绳和干草块添加了合成配方
    • 干草块能通过3x3的小麦合成
    • 干草块不能还原为小麦
  • 调整了马装备的可获取性
    • 玩家无法合成马铠了
    • 你现在能在大多数的世界生成箱子内找到鞍
    • 马不再使用特殊的马鞍
    • 在地牢箱子内添加了马铠
  • 在下界内添加了世界生成箱子
    • 箱子现在会在下界堡垒内生成，一般出现在内部的角落内
  • 红石比较器现在能够根据炼药锅和末地传送门框架的状态输出信号
  • 菜单内的泥土背景使用了新的模糊渲染
  • 攻击性生物不再会攻击在创造模式内的玩家
  • 僵尸不再会生成从天而降的僵尸
  • 地毯现在能被放置在萤石和其他透明方块上了


13w17a(2013-4-25)

  • 添加了硬化粘土
    • 通过烧炼粘土块获得
  • 为创造模式物品栏的搜索标签添加了提示
  • 湖不再会在沙漠中生成，但岩浆湖仍会生成
    • 湖只会在沙漠的边缘生成
  • 僵尸在受到伤害时有几率生成更多的僵尸


13w16b(2013-4-23)

  • 添加了命名牌
  • 为干草块和拴绳添加了标签
  • 降低了马的速度和滑行距离


13w16a(2013-4-19)

  • 添加了马
    • 右键可骑乘，持续按下跳跃键蓄力，放开后可跳跃，用通常的移动键控制前进方向。最大速度与弹跳高度与马的品种相关
    • 最大生命值各不相同，可以用小麦回复
    • 死后掉落皮革
    • 可用小麦喂养。小马可以用苹果、金苹果与小麦使其成长
    • 在Mo' Creatures作者DrZhark的协助下完成
  • 添加了驴。
    • 驴与马共享同样的生成代码
    • 驴戴着鞍时也能驮着箱子，但目前并没有物品栏
    • 游戏文件中也存在着不死，骷髅，和骡子版本的驴材质文件
  • 添加了马铠（铁制，金制，钻石）
    • 合成配方为6个铁锭/金锭/钻石和一个羊毛
  • 添加了马鞍
    • 合成配方为5个皮革和3个铁锭
  • 添加了干草捆
  • 添加了拴绳
  • 添加了地毯
    • 地毯可以通过两个同样颜色的羊毛横放来合成
  • “水下呼吸”魔咒现在能提升水下视觉
  • 改变生物难度的概念
    • 区域难度：在一个地方呆的越久，难度越高
    • 随难度调整：物品，附魔与人工智能会随着难度提高而增强
