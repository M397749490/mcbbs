这插件有什么用的？就是让你多余合成的物品变回原样



先看看效果图吧



怎样？很不错吧，纯净服又不能用mod来还原，所以就用这插件吧！！


指令


  1. /uncraft:
  2. 说明: 这个指令是直接让你手上的物品还原!
  3. 指令：/uc
  4. 缩写: [uc,untrade, ut]
  5. /unsmelt:
  6. 说明: 这个指令是直接让你手上被烧过的物品还原!
  7. 指令：/us
  8. 缩写: us
  9. /unenchant:
  10. 说明: 这个指令是直接让你手上附魔的物品还原!
  11. 指令：/ue
  12. 缩写: ue
  13. /unbrew:
  14. 说明: 这个指令是直接让你手上酿造的物品还原!
  15. 指令：/ub
  16. 缩写: ub
复制代码



权限


  1.         uncrafter.crafting:
  2.         默认: true
  3.         说明: 给与权限来进行和成果的物品
  4.     uncrafter.smelting:
  5.         默认: true
  6.         说明: 给与权限来进行用熔炉烧过的物品
  7.     uncrafter.brewing:
  8.         默认: true
  9.         说明: 给与权限来进行酿造的物品
  10.     uncrafter.enchanting:
  11.         默认: true
  12.         说明: 给与权限来进行附魔的物品
  13.     uncrafter.trading:
  14.         默认: true
  15.         说明: 给与权限来进行交易前的物品【npc交易】
  16.     uncrafter.command:
  17.         默认: true
  18.         说明: 给与权限来进行所有指令
  19.     uncrafter.update.notify:
  20.         默认: op
  21.         说明: 提醒更新
复制代码

  1. #文本版本
  2. config_version: 1.9
  3. #讯息语言
  4. language: EN
  5. #允许还原被合成掉的物品
  6. allow_uncrafting: true
  7. #允许还原被烧掉的物品
  8. allow_unsmelting: true
  9. #允许还原被附魔掉的物品
  10. allow_unenchanting: true
  11. #允许还原被酿造掉的物品
  12. allow_unbrewing: true
  13. #使用权限吗
  14. use_permissions: false
  15. #更新提醒
  16. notify_update_available: true
  17. #还原所用的资金
  18. recycle_chance: 0.9
  19. #还原黑名单【可用id】
  20. recycle_blacklist:
  21. - coal_ore
  22. - quartz_ore
  23. - redstone_ore
  24. - lapis_ore
  25. #不明==不用去管
  26. In_Or_Ex_clude_List_For_Worlds: none
  27. #允许使用的世界【不再加过的话，默认全世界】
  28. worlds_include_list:
  29. - world
  30. - world_nether
  31. - world_the_end
  32. #禁止的世界【如果要禁止那个世界用这插件的话 就填写】
  33. worlds_exclude_list:
  34. - pvp
  35. - noUncrafting
