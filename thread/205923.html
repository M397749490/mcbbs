                                    IslandWorld
众所周知的空岛插件自带任务系统
这个插件代替了从前的 SkyBlock 插件，并可以自定义空岛
就像下面那样:

还可以自定义箱子中的物品哦。 注：缺少正确版本的WE可能会导致箱子内的物品丢失
可以组团空岛生存，一起完成任务ect.
主要命令：
/is create创建你的空岛
/is delete删除你的空岛
/is cha list/is c c [ID]显示任务列表 完成任务
/is calc计算空岛点数
/is sethome /is home设置空岛的出生点 传送回空岛

命令列表:http://dev.bukkit.org/bukkit-plugins/islandworld/pages/installation/
谢谢 Sansi丶XL 的提醒，本插件必须要多世界插件multiverse 也就是MV多世界插件


生成命令为：

  2. /mv create IslandWorld empty
复制代码
这个IslandWorld是世界名字，建议不用修改
如果要空岛世界中有水或岩浆就像上面的图那样需要在生成世界时的命令如下:
  1. /mv create IslandWorld NORMAL -g CleanroomGenerator:100,water
复制代码
这里的数字必须为100，后面跟的是方块ID

如果已经使用了别的多世界插件或不想安装的按如下操作（注：操作前请备份 bukkit.yml 文件)
首先，关闭服务器,
然后打开 bukkit.yml 文件,
在文件的最后加入
  1. worlds:
  2.   IslandWorld:
  3.     generator: CleanroomGenerator:
复制代码
最后依旧可以像上面一样添加水
我个人建议使用MW多世界插件
生成命令为：
  1. /mw create IslandWorld empty
复制代码
如果你不想让空岛世界的名字叫IslandWorld，可以修改
在生成世界之后，关闭服务器，在插件的配置文件中写入你的世界名字
如果是IslandWorld则不用修改重启服务器即可'

如果生成的箱子是空的，说明你的WE插件版本不是最新的
需要使用开发版本
http://builds.enginehub.org/job/worldedit/

记住，必须使用UTF-8编码
现在开始讲解
我们拿第一个挑战来解析
<challenge id='1'>
<descr val='建造一个刷石场,然后收集1组鹅卵石' />
<required itemId='4' count='64' take='true' />
</challenge>

中间的中文是我写进去的
另外作者在默认挑战列表中是没有奖励设置的这需要我们自己添加
<reward itemId='5' count='64'/>

像这个就是完成后奖励1组木板的
下面是整合在一起后

<challenge id='1'>
<descr val='建造一个刷石场,然后收集1组鹅卵石' />
<required itemId='4' count='64' take='true' />
<reward itemId='5' count='64'/>
</challenge>


那么整句就是
缴纳1组的圆石
给你1组的木板
其中challenge id为挑战ID，这个不需要去变动



descr val为返回玩家的信息
required这行为需求物品

  2. <P>itemId=''<必须在""中填写数字><此为物品ID></P>
  3. <P>count=''<必须在""中填写数字><此为数量></P>
  4. <P>take='true'<这个只有true和false><true为完成后删除玩家物品,false为不删除></P>
复制代码
reward为奖励物品
代码同上
以此类推就可以自定义自己的挑战了










如果你想自定义箱子？
请先学会MCedit
然后把你的箱子通过复制保存的方法保存为schematic格式
然后放到本插件的配置文件夹里
然后就行了
记得重命名然后覆盖
