MySkills

技能



★介绍★
MySkills插件是一款技能(氪金)插件，绚丽的技能吸引玩家的眼球(赞助)，让你的服务器更有可玩性。

★特性★
性能：内置服务器优化：心跳包、区块清理。流畅使用，不用担心放技能造成的卡顿！
信息：信息清晰明了，报错信息中文提示，支持多语言，根据玩家客户端语言切换发送消息的语言，语言可设置，后台语言可以更改。启动、报错信息双语言显示，让您无忧配置管理插件！
提醒：更新提醒！不用每天来翻帖子了！有更新时，插件将会自动提醒您更新！
氪金：炫酷的技能，强大的属性，各种效果吸引着玩家，让更多的玩家来赞助你的服务器吧！

技能冷却冷却时间实时ActionBar显示。

设置实体掉落物教程：
首先，输入/ms select true 开启选择实体模式
拿着要添加的掉落物 输入/ms setdrop add
如果添加错了，拿着要删除的掉落物 输入/ms setdrop remove
设置完毕 输入/ms select false

NBT设置教程：
/ms setnbt <等级> <位置> <属性> —— 设置手中物品的NBT
<等级>：数字，即属性等级
<位置>：mainhand / offhand / feet / legs/chest / head，即属性有效位置
分别为：主手 / 副手 / 腿 / 脚 / 胸 / 头 部，1.9以下没有副手
<属性>：attackDamage / attackSpeed / maxHealth / movementSpeed / armor / luck
分别为：攻击伤害 / 攻击速度 / 最大血量 / 移动速度 / 护甲 / 幸运

附魔设置教程：
/ms setench add <附魔> <等级> —— 给手中物品添加附魔
/ms setench remove <附魔> —— 给手中物品删除附魔
/ms setench setlevel <附魔> <等级> —— 设置手中物品某个附魔的等级
