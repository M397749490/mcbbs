地皮插件(PlotMe)相关问题:


修改地皮大小和道路方块:

打开服务器的plugins文件,找到Plotme的文件,打开config.yml,找到：
  1.   plotworld:
  2.     PlotAutoLimit: 1000
  3.     PathWidth: 7
  4.     PlotSize: 48
  5.     BottomBlockId: '7'
  6.     WallBlockId: '44:7'
  7.     PlotFloorBlockId: '2'
  8.     PlotFillingBlockId: '3'
  9.     RoadMainBlockId: '155'
  10.     RoadStripeBlockId: '89'

PlotSize就是地皮的大小(32代表32X32的地皮)

RoadMailBlockId就是道路中间的方块ID

RoadStripeBlockId就是道路两旁的方块ID

WallBlock就是围绕地皮的方块

玩家领取地皮显示无权限:

输入指令:/mangaddp 默认权限组(builder或default) plotme.use

/mangaddp 默认权限组(builder或default) plotme.use.add

/mangaddp 默认权限组(builder或default) plotme.use.remove

地皮世界世界生怪或动物:

输入指令:/mv modify set monsters flase (关闭刷怪的指令)

/mv modify set animals false (关闭刷动物的指令)

想让玩家花钱购买地皮:

  1. 服务器插件文件Plotme里的config.yml里:
  2. UseEconomy: false
  3. 是否使用经济
  4.       CanPutOnSale: false
  5. 是否可以出售地皮
  6.       CanSellToBank: false（推荐禁止，不然玩家可以领取了地皮就卖来刷钱！）
  7. 是否可以卖给服务器
  8.       RefundClaimPriceOnReset: false
  9. 不知道什么意思
  10.       RefundClaimPriceOnSetOwner: false
  11. 领取地皮是否要钱
  12.       ClaimPrice: 0.0
  13. 领取地皮需要的钱
  14.       ClearPrice: 0.0
  15. 清理需要的钱（就是/p clear指令）
  16.       AddPlayerPrice: 0.0
  17. 给权限需要的钱（/p add 指令）
  18.       DenyPlayerPrice: 0.0
  19. 禁止玩家进入需要的钱（/p deny 指令）
  20.       RemovePlayerPrice: 0.0
  21. 删除权限需要的钱（/p remove 指令）
  22.       UndenyPlayerPrice: 0.0
  23. /p undeny 指令需要的钱
  24.       PlotHomePrice: 0.0
  25. /p h 指令需要的钱

创世神插件(WorldEdit)插件:
如何将建筑保存为schematic的格式:
用创世神的默认工具选择要保存的建筑,然后输入//copy,在输入//schem save 名字,保存的schematic的文件会在创世神插件的配置文件的schematics文件里
如何将schematic格式的建筑复制到服务器:
首先将schematic文件放入创世神插件的配置文件里的schematics文件里(如果没有这个文件,请手动创建),然后在游戏里输入//schem load 名字 就可以了
基础插件(Essentials)插件:
设置不生成末影龙,凋零的生物:
打开服务器插件文件的Essentials里的config.yml文件,找到:

  1.   prevent:                                                        # 阻止以下现象(译注:true就是阻止,false是允许,这里需要注意一下)
  2.     lava-flow: true                                              # 阻止 岩浆的流动
  3.     water-flow: false                                          # 阻止 水的流动
  4.     water-bucket-flow: false                             # 阻止 水桶水的流动
  5.     fire-spread: true                                          # 阻止 火的传播
  6.     lava-fire-spread: true                                  # 阻止 岩浆引起的火的传播
  7.     flint-fire: false                                              # 阻止 打火石产生火
  8.     lightning-fire-spread: true                           # 阻止 闪电引起的火的传播
  9.     portal-creation: false                                  # 阻止 传送门的创造
  10.     tnt-explosion: true                                      # 阻止 TNT的爆炸
  11.     tnt-playerdamage: false                             # 阻止 TNT对玩家造成伤害
  12.     tnt-minecart-explosion: true                      # 阻止 TNT矿车 爆炸
  13.     tnt-minecart-playerdamage: false             # 阻止 TNT矿车 对玩家造成伤害
  14.     fireball-explosion: true                               # 阻止 火球的爆炸(译注:恶魂发射的火球)
  15.     fireball-fire: false                                        # 阻止 火球的燃烧
  16.     fireball-playerdamage: false                      # 阻止 火球对玩家造成伤害
  17.     witherskull-explosion: true                        # 阻止 凋零攻击的爆炸
  18.     witherskull-playerdamage: false               # 阻止 凋零攻击对玩家照成伤害

  20.     wither-blockreplace: true                          # 阻止 凋零破坏方块
  21.     creeper-explosion: false                            # 阻止 爬行者的爆炸

  25.     enderman-pickup: false                            # 阻止 末影人拾取方块
