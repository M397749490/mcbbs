介绍：
本插件是使用Kotlin语言编写的反作弊安全插件。
可以抵御以下类型的作弊：
  • 飞行
  • 加速
  • 自瞄
  • 水面轻功
  • 高跳
  • 不死
  • 灵魂出窍
  • 秒挖
  • 传送
  • 穿墙
  • 瞬移
  • 爬墙
  • 快速爬梯
  • 快速跳跃
目前暂时不支持杀戮光环与hitbox，未来会加入的。
检测到玩家作弊后可以踢出玩家或执行其它自定义操作。
以下情况不会检测玩家：
  • 被蜘蛛网黏住
  • 使用鞘翅滑翔
  • 乘坐　交通工具
  • 处于创造模式
  • 允许飞行与穿墙
  • 在冰上疾跑与跳跃(有时)
过快的传送(如每秒好几次传送)可能会出现某些未知的奇怪问题，所以你要设置传送冷却时间。

使用：
将前置插件与本插件一起扔进服务端plugins文件夹里，重新启动服务器即可。

配置（汉化）：
config.yml
  1. #配置文件版本，不得擅自修改
  2. version: 1 #do not modify this

  4. #whether GAC will be active in all levels (if not changed below) or not
  5. #是否检测所有世界（如果不，需要在下面配置排除的世界）
  6. default_active: true

  8. #add all worlds where AC should be in the opposite state than #default_active property
  9. #不检测的世界
  10. excluded_levels: [""]
  11. #例子：
  12. #excluded_levels: ["world1", "test", "survival world"]

  14. #if true, plugin will kick the player if detects cheats
  15. #是否检测到玩家作弊时踢出
  16. kick_players: true

  18. #if true, anticheat will checks even OP players
  19. #是否检测OP
  20. check_ops: false

  22. #manage all available checks (enable/disable)
  23. #检测项目
  24. checks:
  25.   #加速（包括垂直移动与水平移动）
  26.   speed: true #vertical and horizontal speed
  27.   #飞行（包括无效移动）
  28.   fly: true #fly and other invalid movement checks
  29.   #秒挖
  30.   speedmine: true
  31.   #出窍（CPU占用高）
  32.   nuker: false #checks if player can see the block (this check takes a bit more CPU than other checks)
  33.   #轻功
  34.   glide: true
  35.   #传送
  36.   teleport: true
  37.   #穿墙
  38.   noclip: true
  39.   #刷屏
  40.   spam: true
  41.   #瞬移
  42.   reach: true
  43.   #自瞄
  44.   aimbot: true
  45. settings:
  46.   #刷屏延迟
  47.   spam_delay: 8 #delay between messages #currently not implemented
  48.   #最大攻击范围
  49.   hit_range: 4 #max hit range
