简介
RedeemCodes is a plugin that enables server owners to generate virtual codes which users can be redeemed using the"/redeem < code >". All while never touching a single configuration file. Any commands that you have configured for the virtual code will be executed for the player through the console upon redeeming it. This plugin can be useful for giveaways (for example,instead of waiting for a player to come online to collect their prizes, you can generate a virtual code for them and redeem it when they want).

RedeemCodes是使服务器所有者能够生成虚拟兑换码的插件，玩家可以使用“ / redeem <code>”来兑换。可以不用触摸单个配置文件。兑换后 ，将通过控制台为玩家执行您为虚拟兑换码配置的所有命令。该插件对于奖励很有用（例如，您可以等待他们在线生成并兑换虚拟兑换码，而不是等待玩家在线上来给予他们奖品）


特点
  • 轻松生成兑换码
  • 向代码中添加无限数量的命令和操作
  • 查看兑换码详细信息
  • 可以在兑换码中使用变量
  • 基于权限的兑换码激活
  • 设置限制使用
  • 支持1.8.8至1.15.2
  • 支持Spigot 和 Paper
  • 不久将会更新

权限和命令
  1. /redeem [VCODE] - rc.user.redeem - 兑换兑换码
  2. /rc create [VCODE] - rc.admin.create - 创建兑换码
  3. /rc remove [VCODE] - rc.admin.edit - 删除兑换码
  4. /rc addcmd [VCODE] [COMMAND] - rc.admin.edit - 给兑换码增加命令
  5. /rc delcmd [VCODE] [COMMAND INDEX] - rc.admin.edit - 给兑换码删除命令
  6. /rc show [VCODE] - rc.admin.show - 查看兑换码详细信息
  7. /rc setusage [VCODE] [USES] - rc.admin.edit - 设置兑换码用法
  8. /rc setperm [VCODE] [PERMISSION] - rc.admin.edit - 设置权限组
  9. /rc clearperm [VCODE] - rc.admin.edit - 清除权限组
  10. /rc list - rc.admin.list - 兑换码列表
  11. /rc help - rc.admin.help or rc.user.help - 帮助
