首先, Mojang的登录操作是使用json数据传输的, 所以我们需要发送json数据,
最好不要直接拼接字符串, 虽然直接拼接也没啥事
使用类库: Gson (Google的JSON工具), 我自己写的库(用来发送HTTPS的

username -> 这是用户名字, 实际上需要的是需要验证的邮箱
password  -> **
requestUser = true -> 定义需要返回User
clientToken -> 客户端(启动器)token, 理论上可为任何字符串

agent -> 代理, 最好不要修改
    name -> 代理名字, 正版启动器为 Minecraft
    version -> 代理版本, 正版启动器为 1

好, 我们已经定义好我们的数据了, 让我们把它发送到 Mojang 服务器

WebHelper.post(auth) // 创建一个链接, 这里需要自行实现了啊233, 你直接用 new URL(auth).openConnection() 也行的233
    .write((OutputStream output) ->{
           Gson g = new Gson(); // Gson库
           String post = g.toJson(data); // 格式化我们需要发送的数据, JSON格式

           System.out.println(...); // 显示我们需要发送的是什么东西 (过滤隐私版本)

           byte[] bytes = post.getBytes(StandardCharsets.UTF_8);
           output.write(bytes);

    .response(...) // 数据回调
    .connect();
