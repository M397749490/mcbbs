作者: 3TUSK    时间: 2020-6-19 02:47
这个错误简单来说就是你用的 Java 看上去不信任Let's Encrypt X3 所用的中间证书或者 DST Root CA X3 根证书。
但是对 DST Root CA X3 的信任早就在 JDK 8u101 里就有了，而你用的是 8u252。你的情况理应不可能出现。

考虑过重装 JDK 吗？
