标题: first position set to（x,y,z）怎么回事？
用木质斧头破坏方块时会在左下角显示“first position set to（x,y,z）”x,y,z是该方块坐标，一直破坏方块的话，能刷出一屏这玩意，这是怎么回事？
作者: well    时间: 2011-8-28 09:34
The mod Single Player Commands + World Edit use the WoodenAxe as an editing tool with Leftclick for "First Position" and Rightclick for "Second Position" you can then type something like //set 1 (or //set stone) to change the whole area you selected with the wooden axe into stone (1 = stone, 2 = grass etc.)
