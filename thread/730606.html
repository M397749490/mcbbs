SimplePing —— 延迟



插件介绍
Features — 功能

  • 简单轻松配置
  • 自定义消息
  • 显示自己的ping
  • 显示其他人的ping
  • 重新加载配置
  • 简易命令
  • 标题与子标题（新添加！！）
  • Action Bar消息 - 就是在屏幕中间稍下方（未来版本将会推出）

配置说明
  1. # SimplePing by CrispyBow
  2. # SimplePing 汉化 by Moyu默雨（Miku狂三）

  4. # 变量:
  5. # {player} - 使用指令的玩家
  6. # {target} - 被指令点到的玩家
  7. # {ping_p} - 使用指令的玩家Ping
  8. # {ping_t} - 被指令点到的玩家Ping
  9. Messages:
  10.   Prefix: '&8[&bSimplePing&8] &r'
  11.   #前缀
  12.   NotPermission: '&cYou don''t have permission for this command!'
  13.   #没权益
  14.   ReloadConfig: '&aThe config has been reloaded.'
  15.   #重载配置
  16.   PlayerPingMessage: '&fYour current ping is &e&l{ping_p}&fms&8.'
  17.   #玩家延迟消息
  18.   TargetPingMessage: '&9{target}&f''s ping is &e&l{ping_t}&fms&8.'
  19.   #其他玩家延迟消息
  20.   PlayerNotOnline: '&cThe player is not online!'
  21.   #玩家未在线
  22.   InvalidArguments: '&cInvalid arguments. Use /ping <player> or reload'
  23.   #未知参数
  24.   
  25. # 新功能！！！ 标题 & 子标题
  26. # 变量:
  27. # {player} - 玩家
  28. # {ping} - 延迟
  29. Titles:
  30.   enabled: true
  31.   #开关
  32.   TitlePing: '&c'
  33.   #主标题
  34.   SubtitlePing: '&fYour current ping is &6{ping}&ems&8'  
  35.   #子标题

命令与权限说明
Commands — 命令

  1. /ping - 显示自己的延迟
  2. /ping <player> - 显示其他玩家的延迟
  3. /ping reload - 重载配置
