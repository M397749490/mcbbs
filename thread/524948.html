插件特点：
可以让你的种子自动补上，比如小麦、萝卜、西瓜（没测试）..所有农作物，懒人必背。前提是物品栏要有种子。
这个插件可以设置权限，打掉自动补种、成熟后打掉自动补种。可以设置可使用的世界或所有世界。
你是否会想，假如我同时带多个种子，它是否会随机补种？
回答： NO，它会根据你之前种下的种子来判断补种什么种子，比如你收获萝卜就补种萝卜。


作者相关：
和TreeAssist（便利砍树插件）是一个作作者。
插件的用法：
经过小黑测试，本插件可以用于1.7.2版本，并且经过各种测试，并没有发现能刷种子的BUG。


不足的地方：
如果手速太慢的话可能漏补种子..
指令：
/FarmAssist Toggle - 切换自动补种开关（前提要有权限，默认关闭权限功能。）
/FarmAssist Global  - 开启或关闭该插件 （如果权限系统开了，可以用这个切换开关）
/FarmAssist Reload - 重新读取配置文件
权限：
farmassist.wheat - 允许用户自动种植小麦
farmassist.reeds - 允许用户自动种植甘蔗
farmassist.wart - 允许用户自动种植地狱疣
farmassist.cocoa - 允许用户自动种植可可豆
farmassist.carrots - 允许用户自动种植胡萝卜
farmassist.melon - 允许用户自动种植西瓜
farmassist.pumpkin - 允许用户自动种植南瓜
farmassist.potatoes - 允许用户自动种植土豆

farmassist.till - 允许用户耕地时有种子来自动种植
（--如果权限功能开启，单独给这个权限就能自动补种全部农作物--）

farmassist.reload - 允许使用 '/farmassist reload' 指令（重载插件）
farmassist.toggle - 允许使用 '/farmassist toggle' 指令（自动补种开关）
farmassist.toggle.global - 允许使用 '/farmassist global' 指令（插件开关）
配置文件:
Main:
  Use Permissions: true    #是否开启权限功能
Wheat:    #物品种类: 小麦
  Enabled: true     #是否开启自动补种
  Only Replant When Fully Grown: true   #是否开启成熟收获后自动补种（建议开启，否则你想破坏都被强制种植了）
  Plant on till: true          #是否在耕地上种植（意义不明- -，难道小麦还可以在其他地方种植吗）
Reeds:    #甘蔗
  Enabled: true
Netherwart:  #地狱疣
  Enabled: true
  Only Replant When Fully Grown: true
Cocoa Beans:  #可可豆
  Enabled: true
  Only Replant When Fully Grown: true
Carrots:  #胡萝卜
  Enabled: true
  Only Replant When Fully Grown: true
Potatoes:  #土豆
  Enabled: true
  Only Replant When Fully Grown: true
Pumpkin:  #南瓜
  Enabled: true
  Only Replant When Fully Grown: true
Melon:  #西瓜
  Enabled: true
  Only Replant When Fully Grown: true
Worlds:
  Enable Per World: false  #是否开启世界限制补种   true=开启限制  false=关闭限制
  Enabled Worlds:
  - ExampleWorld  #自动补种的世界，需要开启上面的。
