插件介绍
Timed Rewards is a plugin much alike Hypixel's Delivery Man or Mineplex's Carl the Creeper. Timed Rewards allows players to claim rewards over set periods of time which can be completely configured. Rewards are claimed from a GUI which can be opened from a command or by interacting with another plugin NPC.
Timed Rewards是一个类似于Hypixel服务器的Delivery Man 以及 Mineplex服务器的Carl the Creeper的插件，可以让玩家在设定的时间内领取奖励，并且可以右键NPC打开GUI来领取


功能
-可自定义的GUI界面
-倒计时、占位符
-可自定义的消息
-可自定义权限奖励
-可自定义奖励
-NPC支持
-多版本支持:1.8-1.11
-非常小，易于使用

  14. # When right-clicking on an NPC this will open the rewards menu.(Works well with plugins such as Citizens).

  16. npc-names:
  17.   - '&a&lCarl the Creeper'
  18.   - '&bThe Delivery Man'

  24. # If true when a player attempts to claim (clicks) a reward the inventory will close, otherwise it will remain open.
  25. close-inventory-on-claim: true

  27. menus:
  28.   rewards:
  29.     # Size of the menu (inventory)

  34.     # The name of the rewards menu.
  35.     title: '&a&l奖励菜单'

  37.     # This will replace all other items in the menu with the below id, 0 being air (nothing).
  38.     # Note: If the item id has data make sure to put it as a string by surrounding it with quotes.
  39.     #       Example: other-items: '160:15'
  40.     other-items: 0

  50.         # 数量
  51.         name: '&c每日奖励'
  52.         # Time in seconds until they can claim it again.
  53.         # 物品名字
  54.         time: 86400
  55.         # The lore of the item, a description if you like. Note put "lore: []", without quotation, if you don't want a lore.
  56.         # Note: Using {time} will change to the 'claim-message' in messages.yml if there are 0s remaining. (recommended).
  57.         # {time} - Example: 5d 01:01:42 (Same as: {days}d {hours}:{minutes}:{seconds})
  58.         # {days}
  59.         # {hours}
  60.         # {minutes}
  61.         # {seconds}
  62.         #时间
  63.         lore:
  64.           - '&f你可以每天领取一次这个奖励'

  69.         # {player} - The player's name.
  70.         # {uuid}   - The player's uuid.

  72.           - 'eco give {player} 1000'
  73.           - 'tr msg {player} &7[&6TimedRewards&7] 你领取了每日奖励!'
