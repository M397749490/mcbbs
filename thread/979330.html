C -> S: Handshake (next: status)
C -> S: Status Request
S -> C: Status Response
C -> S: Ping
S -> C: Pong

Connnection close.


C -> S: Handshake (next: login)
C -> S: Login Start (包含一个username)
S- > C: Encryption Start (一个Server hash, 一个 RSA Public Key, 一个目前并不需要用到的token)
    hash: Long.toString(random.nextLong(), 16);
C -> S: Encryption Response (一个secret和一个token)
Netty Channel Pipeline 添加加密. 见LoginHandler.java
Server 开始连接验证登录状态 String authURL = "https://sessionserver.mojang.com/session/minecraft/hasJoined?username=" + username + "&serverId=" + encodedHash; // 见LoginHandler.java #199
S -> C: Disconnect, 并显示自定义信息, 通过生成临时验证码配合web验证系统可以实现自动化正版登记.
