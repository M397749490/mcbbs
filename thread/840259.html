首先，你可以自己领一个空岛，然后随意DIY，注!空岛必须有一个基岩！
然后，用创世神插件，选择这个空岛，然后//copy
然后//schematic save xxx

在服务器的文件夹里/plugins/worldedit/schematics/
找到文件xxx.schematic
复制到/plugins/askyblock/schematics/
然后打开配置文件/plugins/askyblock/config.yml
注！配置文件可能给我有点不同！

找到差不多最底下，大概九百多行的地方，有一个“schematicsection:”（你可以使用查找功能）
找到这一段

（我把一部分注释省略了！）
复制
schematicsection:
    schematics:
        default:
下的内容，即下文 第7行至最后一行！
  1. schematicsection:
  2.   useschematicspanel: true
  3.   chooseislandrandomly: false
  4.   hackskeletonspawners: false
  5.   schematics:
  6.     # default heading is required
  7.     default:
  8.       # Icon - if this is missing or wrong, it will be a MAP
  9.       icon: DIRT
  10.       # Order of preference in listing
  11.       order: 1
  12.       # Short name - color codes with & okay
  13.       name: "The Original"
  14.       # Longer description. Use | for new lines. Color codes okay.
  15.       description: "Challenging|starter|island!"
  16.       # Filename of the schematic in the schematic folder
  17.       filename: island.schematic
  18.       # Use default chest if true, or use schematic chest contents if false
  19.       useDefaultChest: true
  20.       # Which schematic will be used in the opposite world if newnether:true
  21.       # If there is no partner, this island will be used
  22.       partnerSchematic: nether
  23.       #Level handicap zeros the initial island level.
  24.       levelHandicap: 3
复制代码

然后粘贴到配置文件
schematicsection:
    schematics:
的里面


小白做法：
把鼠标编辑光标移至
  1. schematicsection:
  2.   useschematicspanel: true
  3.   chooseislandrandomly: false
  4.   hackskeletonspawners: false
  5.   schematics:
复制代码
这里最后一行的冒号后，换行，然后粘贴上述要你复制的内容！

然后在default里找到filename: island.schematic 改为  filename: xxx.schematic
然后，把default改你喜欢的名字，一定要英文！
然后保存！

然后进服务器,重载配置文件（重启服务器），你输入/island reset,然后/is confirm,弹出的菜单就会多了一项啦！
