死亡解牌子锁UnlockifDie死亡删除领地RemoveResidenceifDie
死亡掉落DropItemsAndExps

UnlockifDie：指令无
权限：只有一个
unlock.vip.nounlock                     有这个权限的人可以死后不被破坏牌子锁
工作原理：
当玩家放置牌子的时候保存位置下来，当玩家死的时候再销毁这个位置的牌子。因为检查不到门上的牌子所以对门无效，也不能检查在安装插件之前的牌子锁……

RemoveResidenceifDie：
指令无
权限：还是只有一个
rrd.vip.nonerrd                            有这个权限的人可以死后不被移除领地
工作原理：
检测玩家死亡之后，就用领地自带的删除系统删了这个玩家的所有领地
这个插件没什么好介绍就不介绍了。
DropItemsAndExps：
指令：
/die reload ------------- 重载插件
/die xp [玩家] --------- 查看玩家经验
/die check [世界] ----- 查看目标世界的插件配置
权限：
ifdead.drops.ignore:不用掉落经验或者物品  ifdead.drops.ignore.exps:不用掉落经验
  ifdead.drops.ignore.items:不用掉落物品
ifdead.commands.die:使用指令
  ifdead.commands.die.debug: debug命令(xp和check)的权限
  ifdead.commands.die.reload:  reload命令权限
介绍
设置死亡之后掉落物品和经验你可以给每个世界分别设置，或者使用默认配置"default"
掉落是采用随机掉落，说不定你挖你一组石头都还在，但是你挖的钻石却不见了[%笑%]
配置文件说明
  1. default:
  2.   #是否启用，为true则用下面的配置，为false则...你自己看着办，自己设置世界规则
  3.   enable: true
  4.   #物品掉落率(%)
  5.   dropitem: 80
  6.   #经验消失率(%)
  7.   dropexp: 80
  8.   #掉落经验在消失的经验中的比例(%)
  9.   #例如你有100经验，因为死亡你扣了80经验，扣的80经验中只有20%的即16经验会掉出来
  10.   dropexpodd: 20
  11.   #是否用钱保留一定的物品(false的话不用钱也能保留部分物品)
  12.   keepwithmoney: true
  13.   #若上面一个为true，设置要多少钱才能部分保留(钱不够就全部掉落)
  14.   moneytokeep: 30
  15.   #是否用钱保留所有物品(false的话就不保留所有物品。)
  16.   keepallwithmoney: true
  17.   #若上面一个为true，钱够的话就扣钱保留所有物品。不够的话看一下保留一定物品。
  18.   moneytokeepall: 50
  19.   #低配模式，会使掉落比例偏差变大一点，同时换取得一点性能。不建议开，反正也快不了多少
  20.   low: false
  21. pvpworld:
  22.   enable: true
  23.   dropitem: 100
  24.   dropexp: 100
  25.   dropexpodd: 80
  26.   keepwithmoney: false
  27.   moneytokeep: 30
  28.   keepallwithmoney: false
  29.   moneytokeepall: 50
  30.   low: false
