scoreboard objectives add (你要的名字#1) totalKillCount (你要的名字#1)

scoreboard objectives add (你要的名字#2) dummy (你要的名字#2)

scoreboard players set @a[score_(你要的名字#1)_min=1] (你要的名字#1) 0
scoreboard players operation @p[score_(你要的名字#1)_min=1] (你要的名字#2) += @p[score_(你要的名字#1) (你要的名字#1)

scoreboard players test @p[score_(你要的名字#1)_min=1]

(除了第1,2條指令之外,都要使用脈衝紅石信號激活命令方塊來反復執行其中的命令)
