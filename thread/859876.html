就是

至于第一个 我好像不太清楚        
作者: kuikui851    时间: 2019-4-23 20:04
这个问题很简单，如果你装了cofh模组的话。 这个模组很蛋疼，如果是带名字的怪物死亡的话，就会发送死亡消息。 不知道这个是什么你可以百度下，在服务端config文件夹里面。 有个cofh文件夹，里面还有个core文件夹，里面还有个common.cfg文件，打开。     # Set to TRUE to display death messages for any named entity.     B:EnableGenericDeathMessage=true 复制代码 找到这一条，把true改成false就可以了，这样任何带名字实体死亡就不会刷消息了。 而且不影响其他死亡消息。
