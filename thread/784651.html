Pixel Auto Message
效果图
前言
       Sponge可用的公告插件并非仅此一款，但是用过多个公告插件之后，米二认为这个插件是最简洁，上手最方便，功能最强大的一款插件，此插件支持对每一个公告进行多种功能的定义，是一个十分简洁可靠的公告插件。
插件特色
------------------
1.可自定义点击事件
2.可现实悬停信息   
3.可使用名字占位符
4.可自定义播报周期
5.可定义接收者权限
6.   全版本兼容      

------------------
安装方法

将此插件移动到Sponge服务端的mods文件夹下

（请确保你是用的版本号是正确对应于SpongeAPI开发的）

指令
/pam reload —— 重载配置文件
对应权限：pam.cmd.reload
配置文件
  1. configs {
  2. # 译者注：公告发布的周期
  3.     interval=60
  4. # 译者注：公告前缀
  5.     prefix="&7[&a卡洛兰小喇叭&7]&r "
  6. # 译者注：十分开启随机轮播模式
  7.     random=false
  8. }

  10. # 请在这里修改公告内容!请按照“0”结构体添加新的公告条目，序号递增，例如"1"{}
  11. # 所有的内容都支持占位符 (除了权限) 请使用{player}代表玩家ID。
  12. # 译者注：占位符功能不完善，可能出现错误的用户ID。
  13. # 提示: 每个条目只可以使用一个'click-cmd', 'click-url'或者'suggest-cmd'。（译者注：其余项留空）
  14. messages {
  15.     "0" {
  16.         # 可以使用"&"格式化公告文本
  17.         a-message="&a这是一条默认公告。 &6你可以在配置文件中修改他!"

  19.         # 在线玩家数阈值（译者注：小于此数量的玩家数则不会发布此公告）。设置为0代表永远发布。
  20.         b-players-online=0

  22.         # 接收此条公告需要的权限。
  23.         c-permission=""

  25.         # 鼠标悬停时候显示的信息（译者注：可以使用"&"格式化公告文本）
  26.         d-on-hover="&7你好啊 {player}！本插件由&6Tollainmear&7搬运~！!"

  28.         # 点击功能：将指定的内容打印在玩家聊天栏。
  29.         e-suggest-cmd="今天过得怎么样？"

  31.         # 点击功能：点击执行相关指令
  32.         f-click-cmd="say 大家好啊！"

  34.         # 打开一个网页链接
  35.         g-click-url="http://www.mcbbs.net/thread-784651-1-1.html"
  36.     }
  37. }
