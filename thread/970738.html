插件介绍及特色
这是一款基于SpongeAPI以及NucleusAPI开发的签到插件，本插件主要有一下特性：

  • 基于nucelus礼包系统，完美支持Mod物品
  • 支持指令（通过nucleus的礼包实现，非本插件内容）
  • 使用SQLite储存签到数据
  • 支持补签
  • 支持多种货币购买补签卡（也就是可以自行选择购买补签卡的货币）
  • 支持菜单查看签到奖励

指令及权限

指令
权限
说明
/checkin view <玩家名称>
checkin.view
显示该玩家签到数据 ，该玩家在线时可用
/checkin  set <玩家名称> <补签卡数量>
checkin.set
设置一个玩家的补签卡数量
/checkin
checkin.base
打开签到面板， 也可以用/qiandao或者/qd

使用说明
文字版
  • 先使用nucleus创建所需的礼包，不需要给玩家礼包权限
  • 在配置文件里添加礼包，设置interval，确保KitName与nucleus的礼包名称完全对应
  • 给予玩家"checkin.base"权限
  • 设置补签卡价格，使用的货币以及显示名称
  • done (可能需要重启)
