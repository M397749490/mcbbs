|||   [ Map Info - 地图简介 ]

我是随着西伯利亚的寒风，被吹到这里来的
风雪中，我和战友们失去了联系
被北冰洋冰冷的海水浸泡着，或许……我就会在海洋的怀抱下死去罢
但是，我没有看到死神的镰刀——
当我醒来的时候，阳光照亮远方了漆黑的海水
浅蓝色的苍穹上是一轮银色的月亮和东方白色的地平线
我挣扎着游到那里，希望看到的是辽阔的西伯利亚平原
但是，我错了……
这里是平原，但是这里是一望无际的绿色平原，天空中是规则的紫色环状晶体
地面上是一柱柱直插天空的紫色晶体
这是那个在爱斯基摩人口中所谓的失落的大陆
这是那个我一生所追求的梦幻，就像桃源那样，如梦如幻
是我枯竭的油灯里最后一簇火花，我跪在这个世界中央的火树面前
泪水早已在脸颊上肆意横行，轻轻说道：
父亲……我终于找到您了！
四十年了，您还记得我吗？
我终于找到了！
或许你已经被世人遗忘
但是……
我也要随你而去了……
在这个北国的秘境
远处，是消失的地平线
是纷争和充满欺骗的世界


文案来自@Kelix
晶体柱在120年前郭老师的皮炎临世后从地底升起，不久后就凝聚出了一个巨大的魔法阵,你凑近听——
那里有一阵阵奇怪的叫声
猕hotel—— 不合适吧，您坐下吧—— 亲我嘴——
在这时你对着魔法阵大喊:
你婆婆不喜欢你，你老公在外面做0
魔法阵会从四周传来惨叫，之后30分钟都没有什么叫声
但别放松！不久后会传来巨大的响声——对不起我放个屁啊对不起，轰————啊！不好意思！不好意思姐妹.......

|||    [ Install - 地图安装 ]
Save存档(正版用户):
1、关闭Minecraft，
2、在Windows资源管理器的路径中输入 %appdata%/.minecraft 。
3、把下载的地图存档解压缩放到. minecraft\saves 文件夹里面。

Schematics存档：
这类型需要MCEdit。
1、下载完成后解压，
2、关闭Minecraft，
3、打开MCEdit.exe，点击下方import按钮，选择你下载的文件，
     最后点import，按Ctrl+s保存，Ctrl+w关掉存档，点Quit退出。
- 本地图请使用第一种方法安装使用 -
