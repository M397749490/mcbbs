  3. CMD [/A | /U] [/Q] [/D] [/E:ON | /E:OFF] [/F:ON | /F:OFF] [/V:ON | /V:OFF]
  4.     [[/S] [/C | /K] string]

  6. /C      执行字符串指定的命令然后终止
  7. /K      执行字符串指定的命令但保留
  8. /S      修改 /C 或 /K 之后的字符串处理(见下)
  9. /Q      关闭回显
  10. /D      禁止从注册表执行 AutoRun 命令(见下)
  11. /A      使向管道或文件的内部命令输出成为 ANSI
  12. /U      使向管道或文件的内部命令输出成为
  13.         Unicode
  14. /T:fg   设置前台/背景颜色(详细信息见 COLOR /?)
  15. /E:ON   启用命令扩展(见下)
  16. /E:OFF  禁用命令扩展(见下)
  17. /F:ON   启用文件和目录名完成字符(见下)
  18. /F:OFF  禁用文件和目录名完成字符(见下)
  19. /V:ON   使用 ! 作为分隔符启用延迟的环境变量
  20.         扩展。例如，/V:ON 会允许 !var! 在执行时
  21.         扩展变量 var。var 语法会在输入时
  22.         扩展变量，这与在一个 FOR
  23.         循环内不同。
  24. /V:OFF  禁用延迟的环境扩展。

  26. 注意，如果字符串加有引号，可以接受用命令分隔符 "&&"
  27. 分隔多个命令。另外，由于兼容性
  28. 原因，/X 与 /E:ON 相同，/Y 与 /E:OFF 相同，且 /R 与
  29. /C 相同。任何其他开关都将被忽略。

  31. 如果指定了 /C 或 /K，则会将该开关之后的
  32. 命令行的剩余部分作为一个命令行处理，其中，会使用下列逻辑
  33. 处理引号(")字符:

  35.     1.  如果符合下列所有条件，则会保留
  36.         命令行上的引号字符:

  38.         - 不带 /S 开关
  39.         - 正好两个引号字符
  40.         - 在两个引号字符之间无任何特殊字符，
  41.           特殊字符指下列字符: &<>()@^|
  42.         - 在两个引号字符之间至少有
  43.           一个空格字符
  44.         - 在两个引号字符之间的字符串是某个
  45.           可执行文件的名称。

  47.     2.  否则，老办法是看第一个字符
  48.         是否是引号字符，如果是，则去掉首字符并
  49.         删除命令行上最后一个引号，保留
  50.         最后一个引号之后的所有文本。

  52. 如果 /D 未在命令行上被指定，当 CMD.EXE 开始时，它会寻找
  53. 以下 REG_SZ/REG_EXPAND_SZ 注册表变量。如果其中一个或
  54. 两个都存在，这两个变量会先被执行。

  56.     HKEY_LOCAL_MACHINE\Software\Microsoft\Command Processor\AutoRun

  58.         和/或

  60.     HKEY_CURRENT_USER\Software\Microsoft\Command Processor\AutoRun

  62. 命令扩展是按默认值启用的。你也可以使用 /E:OFF ，为某一
  63. 特定调用而停用扩展。你
  64. 可以在机器上和/或用户登录会话上
  65. 启用或停用 CMD.EXE 所有调用的扩展，这要通过设置使用
  66. REGEDIT.EXE 的注册表中的一个或两个 REG_DWORD 值:

  68.     HKEY_LOCAL_MACHINE\Software\Microsoft\Command Processor\EnableExtensions

  70.         和/或

  72.     HKEY_CURRENT_USER\Software\Microsoft\Command Processor\EnableExtensions

  74. 到 0x1 或 0x0。用户特定设置
  75. 比机器设置有优先权。命令行
  76. 开关比注册表设置有优先权。

  78. 在批处理文件中，SETLOCAL ENABLEEXTENSIONS 或 DISABLEEXTENSIONS 参数
  79. 比 /E:ON 或 /E:OFF 开关有优先权。请参阅 SETLOCAL /? 获取详细信息。

  81. 命令扩展包括对下列命令所做的
  82. 更改和/或添加:

  84.     DEL or ERASE
  85.     COLOR
  86.     CD or CHDIR
  87.     MD or MKDIR
  88.     PROMPT
  89.     PUSHD
  90.     POPD
  91.     SET
  92.     SETLOCAL
  93.     ENDLOCAL
  94.     IF
  95.     FOR
  96.     CALL
  97.     SHIFT
  98.     GOTO
  99.     START (同时包括对外部命令调用所做的更改)
  100.     ASSOC
  101.     FTYPE

  103. 有关特定详细信息，请键入 commandname /? 查看。

  105. 延迟环境变量扩展不按默认值启用。你
  106. 可以用/V:ON 或 /V:OFF 开关，为 CMD.EXE 的某个调用而
  107. 启用或停用延迟环境变量扩展。你
  108. 可以在机器上和/或用户登录会话上启用或停用 CMD.EXE 所有
  109. 调用的延迟扩展，这要通过设置使用 REGEDIT.EXE 的注册表中的
  110. 一个或两个 REG_DWORD 值:

  112.     HKEY_LOCAL_MACHINE\Software\Microsoft\Command Processor\DelayedExpansion

  114.         和/或

  116.     HKEY_CURRENT_USER\Software\Microsoft\Command Processor\DelayedExpansion

  118. 到 0x1 或 0x0。用户特定设置
  119. 比机器设置有优先权。命令行开关
  120. 比注册表设置有优先权。

  122. 在批处理文件中，SETLOCAL ENABLEDELAYEDEXPANSION 或 DISABLEDELAYEDEXPANSION
  123. 参数比 /V:ON 或 /V:OFF 开关有优先权。请参阅 SETLOCAL /?
  124. 获取详细信息。

  126. 如果延迟环境变量扩展被启用，
  127. 惊叹号字符可在执行时间被用来
  128. 代替一个环境变量的数值。

  130. 你可以用 /F:ON 或 /F:OFF 开关为 CMD.EXE 的某个
  131. 调用而启用或禁用文件名完成。你可以在计算上和/或
  132. 用户登录会话上启用或禁用 CMD.EXE 所有调用的完成，
  133. 这可以通过使用 REGEDIT.EXE 设置注册表中的下列
  134. REG_DWORD 的全部或其中之一:

  136.     HKEY_LOCAL_MACHINE\Software\Microsoft\Command Processor\CompletionChar
  137.     HKEY_LOCAL_MACHINE\Software\Microsoft\Command Processor\PathCompletionChar

  139.         和/或

  141.     HKEY_CURRENT_USER\Software\Microsoft\Command Processor\CompletionChar
  142.     HKEY_CURRENT_USER\Software\Microsoft\Command Processor\PathCompletionChar

  144. 由一个控制字符的十六进制值作为一个特定参数(例如，0x4
  145. 是Ctrl-D，0x6 是 Ctrl-F)。用户特定设置优先于机器设置。
  146. 命令行开关优先于注册表设置。

  148. 如果完成是用 /F:ON 开关启用的，两个要使用的控制符是:
  149. 目录名完成用 Ctrl-D，文件名完成用 Ctrl-F。要停用
  150. 注册表中的某个字符，请用空格(0x20)的数值，因为此字符
  151. 不是控制字符。

  153. 如果键入两个控制字符中的一个，完成会被调用。完成功能将
  154. 路径字符串带到光标的左边，如果没有通配符，将通配符附加
  155. 到左边，并建立相符的路径列表。然后，显示第一个相符的路
  156. 径。如果没有相符的路径，则发出嘟嘟声，不影响显示。之后，
  157. 重复按同一个控制字符会循环显示相符路径的列表。将 Shift
  158. 键跟控制字符同时按下，会倒着显示列表。如果对该行进行了
  159. 任何编辑，并再次按下控制字符，保存的相符路径的列表会被
  160. 丢弃，新的会被生成。如果在文件和目录名完成之间切换，会
  161. 发生同样现象。两个控制字符之间的唯一区别是文件完成字符
  162. 符合文件和目录名，而目录完成字符只符合目录名。如果文件
  163. 完成被用于内置式目录命令(CD、MD 或 RD)，就会使用目录
  164. 完成。
  165. 用引号将相符路径括起来，完成代码可以正确处理含有空格
  166. 或其他特殊字符的文件名。同时，如果备份，然后从行内调用
  167. 文件完成，完成被调用时位于光标右方的文字会被调用。

  169. 需要引号的特殊字符是:
  170.      <space>
  171.      ()[]{}^=;!'+,`~(&()

PowerShell[.exe] -Help | -? | /?

-PSConsoleFile
    加载指定的 Windows PowerShell 控制台文件。
    要创建控制台文件，请在 Windows PowerShell 中使用 Export-Console。

-Version
    启动指定版本的 Windows PowerShell。
    通过此参数输入版本号，如 "-version 2.0"。

-NoLogo
    启动时隐藏版权标志。

-NoExit
    运行启动命令后不退出。

-Sta
    使用单线程单元启动 Shell。
    默认值为单线程单元(STA)。

-Mta
    使用多线程单元启动 Shell。

-NoProfile
    不加载 Windows PowerShell 配置文件。

-NonInteractive
    不向用户显示交互式提示。

-InputFormat
    描述发送到 Windows PowerShell 的数据的格式。
    有效值为 "Text" (文本字符串)或 "XML" (序列化的 CLIXML 格式)。

-OutputFormat
    确定如何设置 Windows PowerShell 输出内容的格式。
    有效值为 "Text" (文本字符串)或 "XML" (序列化的 CLIXML 格式)。

-WindowStyle
    将窗口样式设置为 Normal、Minimized、Maximized 或 Hidden。

-EncodedCommand
    接受 Base 64 编码字符串版本的命令。
    使用此参数向 Windows PowerShell 提交需要复杂引号
    或大括号的命令。

-File
    在本地作用域("dot-sourced")中运行指定的脚本，
    以便脚本创建的函数和变量可以在当前会话中使用。
    输入脚本文件路径和任何参数。
    File 必须是命令中的最后一个参数，
    因为在 File 参数名称后面的所有字符都将解释为
    后面带有脚本参数的脚本文件路径。

-ExecutionPolicy
    设置当前会话的默认执行策略，
    并将其保存在 $env:PSExecutionPolicyPreference 环境变量中。
    该参数不会更改在注册表中
    设置的 Windows PowerShell 执行策略。

-Command
    执行指定的命令(和任何参数)，
    就好像它们是在 Windows PowerShell 命令提示符下键入的一样，然后退出，
    除非指定了 NoExit。Command 值可以为 "-"、字符串或
    脚本块。

    如果 Command 值为 "-"，则从标准输入中读取
    命令文本。

    如果 Command 值为脚本块，则脚本块必须
    用大括号({})括起来。只有在 Windows PowerShell 中运行 PowerShell.exe 时，
    才能指定脚本块。脚本块结果将作为反序列化的 XML 对象
    (而非活动对象)返回到父 Shell。

    如果 Command 值为字符串，则 Command 必须是命令中的最后一个参数，
    因为在命令后面键入的所有字符
    都将解释为命令参数。

    要编写运行 Windows PowerShell 命令的字符串，请使用以下格式:
        "& {<命令>}"
    其中，引号表示一个字符串，
    调用运算符(&)使得命令会被执行。

-Help, -?, /?
    显示此消息。如果在 Windows PowerShell 中键入 PowerShell.exe 命令，
    请在命令参数前面添加连字符(-)，
    而不是添加正斜杠(/)。你可以在 Cmd.exe 中使用连字符或正斜杠。
