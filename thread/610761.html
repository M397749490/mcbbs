1、前言

这篇教程到底适用于哪些人？↓

1、需要使用网页控制台；

2、在同一局域网下有多台机器供运行MC服；

3、采用MultiCraft网页控制台；

4、有足够的耐心的（因为本文篇幅超长）。

如果以上条件都符合您的话，那么您看对文章了。本篇文章也许将非常适合您。



为什么我要写这篇文章？↓

今天上午在multicraft官网偶然看到似乎这奇妙的网页控制台还支持多机器关联，而且正好我也有多个服务器，想平均一下负载，因此开始探究多机器关联的方法。但是在他们官网一阵查找后似乎并没有找到有关这方面的资料，而且在mcbbs也搜索了一下，找到了一个帖子。这个帖子看他的计划似乎包括了多机器关联，但可惜等了好久都没有更新，似乎成坟了吧。我只好自己开始试验。经过一下午的各种尝试，终于弄明白了这奇妙的货到底怎么多机器关联。

不太理解我说的“Multicraft多机器关联”？

某特idc知道吧，当你玩MC的时候连接的服务器地址都是**.[省略]eidc.com，但是控制台却是**.34[省略].com，经过我的域名解析查询这两个域名所指向的IP不同，但是控制台却真真实实地控制了另一个IP上的服务器。这是怎么做到的呢？（噗根本不是转发器，转发器那就没必要再开个IP了）

本篇文章就是写如何只通过一个http服务器（Multicraft网页端），来掌控多个Daemon的方法。

——————————————————————————————————————————————————————

2、搭建环境

正所谓“工欲善其事，必先利其器”。要玩Multicraft多机器关联，那么您必须满足以下条件：

1、拥有一个Dynamic版的Multicraft的key

2、至少两台正常运行的电脑（虚拟机亦可；当然也可以不在同一内网下，只要这两台电脑能正常通讯即可，但建议在同一内网）

3、一个正常运行的mysql（而不可以是SQLite）+http+php的环境（Windows-standalone版的Multicraft已经自带http+支持mysql的php的nginx网页环境）

本帖以两个Windows10——1x实体机+1x虚拟机作为基本电脑环境。

Linux电脑可以参考本帖的思路进行多机器关联。

我说到这里可能有人会问我为什么不直接在multicraft.conf中把database项改成mysql，这是因为如果你的MySQL还是处于比较空的状态，没有Multicraft需要用的数据表，因此如果你直接更改multicraft.conf的话再启动会直接报错。

4、后记
首先声明一点，破解的Dynamic版Multicraft仅供研究学习之用，请勿用于商业用途！否则请支持正版，购买Dynamic Key！
对于这些问题，我们需要的都是足够的好奇心与大胆的尝试，当然还有更多的查找资料！
一个大教程帖子下来了，倒也没用到什么特殊的东西，那就送给大家一个我做的BungeeCord.jar.conf吧，放在multicraft\jar目录下的那种。
  1. [config]
  2. name = [1.8]BungeeCord
  3. #source = http://ci.md-5.net/job/BungeeCord/lastSuccessfulBuild/artifact/bootstrap/target/BungeeCord.jar

  5. [encoding]
  6. encode = utf-8
  7. decode = gb2312
  8. fileEncoding = latin-1
  9. #decode这里如果是Windows就原封不动，如果是Linux就改成utf-8。但是encode不要动，因为MC服务器这货就是utf-8的。。。


  12. [commands]
  13. list = glist
  14. stop = end
  15. version = bungee
  16. say = alert

  18. [startup]
  19. command="{JAVA}" -Xmx{MAX_MEMORY}M -Djline.terminal=jline.UnsupportedTerminal -XX:+AggressiveOpts -XX:+UseCompressedOops -jar "{JAR}" nogui --nojline --log-strip-color true

  21. [parse_players]
  22. start=Total players online: (?P<v_maxDataLines>\d+)

  24. [parse_startup]
