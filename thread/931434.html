用进度什么的也许要好一点。

指令的话，简单的可以创建几个实体，再给个标签。再每个实体给不同的一个分数

然后就 /tag @r[tag=a] add b

execute as @e[tag=b,scores={a=1}] run say 1号
execute as @e[tag=b,scores={a=2}] run say 2号

或者直接使用这个 https://www.mcbbs.net/forum.php?mod=viewthread&tid=706030

干脆伪随机好了
初始化：scoreboard objectives add time dummy
scoreboard players set #max time <maxnum+1>
随机：
execute store score # time run time query gametime
scoreboard players operation # time %= #max time
