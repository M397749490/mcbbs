玩家 facing=east，运行以下这个由 5 条命令组成的函数，为什么 setblock 出来的是 facing=south 的箱子？
  1. execute if entity @s[y_rotation=..-135.01] run setblock ~ ~ ~ minecraft:chest[facing=south] replace
  2. execute if entity @s[y_rotation=-135.01..-45.01] run setblock ~ ~ ~ minecraft:chest[facing=west] replace
  3. execute if entity @s[y_rotation=-45.01..45.01] run setblock ~ ~ ~ minecraft:chest[facing=north] replace
  4. execute if entity @s[y_rotation=45.01..135.01] run setblock ~ ~ ~ minecraft:chest[facing=east] replace
  5. execute if entity @s[y_rotation=135.01..] run setblock ~ ~ ~ minecraft:chest[facing=south] replace
复制代码

初步研究，得知玩家 facing=east 会使第 5 条命令执行成功，这是为什么啊？

第五条改成
execute if entity @s[y_rotation=135.01..180] run setblock ~ ~ ~ minecraft:chest[facing=south] replace
不然MC怎么知道上限多少

比如我写上限360，也是可以激活的
/execute if entity @s[y_rotation=135.01..360] run setblock ~ ~ ~ minecraft:chest[facing=south] replace
你看tp里输入的数值是可以大于180的
