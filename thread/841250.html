介绍 · Introduction

这个插件前置库可以使同插件作者的ChatControl Pro的跨服聊天功能兼容低版本.这只是个前置所以单独使用没有任何功能.
这个插件用于使ChatControl 和 Confiscate 兼容低版本.

背景 · Background
从1.7.10, Spigot 开始自带跨服聊天API库, 并轻易地可以发送JSON消息. 但是插件如果在旧版本使用这个库则不会生效. 所以插件作者创建了这个前置库.


安装 · Installation

  • 关闭服务器
  • 拖拽 .jar 文件到Bukkit服务器内.
  • 如果无效则: 打开不兼容的插件的 .JAR文件. 然后打开 'plugin.yml'并植入BungeeChatAPI为 'softdepend' (如果没有则自行创建).在这整个过程中服务器必须关闭.

前置 · Requirements

Java 8
Minecraft 1.2.5, 1.3.2, 1.4.7, 1.5.2, 1.6.4, 1.7.10之间的版本的Craftbukkit 或 Spigot服务端.
