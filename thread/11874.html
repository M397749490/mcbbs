标题: [懒人方便工具2]Minecraft Mod制作大师(工具篇)，不懂制作Mod进！！[1.8.1]
Minecraft Mod制作大师
作者:AlexM

你希望制作一款自己原创的Mod?不懂JAVA?我们先从简单开始

这工具给什么人用:
1.第一次制作Mod的人
2.一个懒的开发者，这工具就像Visual Basic一样，帮你制作好介面，你可以自己去java文件添加代码

下载地址:



http://115.com/file/dnml5asq#


注意:
如果在第7步因为网络问题不能下载MC，你是可以自己在论坛下载一个新的mc，然后把bin放到.minecraft/ModMakerBins/newbin/
整个路径是.minecraft/ModMakerBins/newbin/bin
没有这些文件夹就自己建立

使用教程:

1.先去下载个Modloader
2.下载个mcp mcp wiki
﹂我也给大家搬运过来了，这是支持1.8.1的mcp,http://115.com/file/aqu9fkhb#
3.解压缩mcp,然后将 Mod Maker放进mcp的文件夹
4.打开Mod Maker后，切换到MCP setup
5.点击get clean bin会生成一个mod maker的bin
6.弹出提示后不要关闭，然后打开mc
7.等待下载完成
8.下载完成了，关闭mc并点击continue，再点击yes
9.程序为你自动打开bin了，去把minecraft.jar里面的META-INF删除，再将预先下载好的Modloader放进去，再点ok
10.然后点Auto setup MCP
11.然后你会看到mcp正在反编译mc中
12.中间会有一些错误，但不用去理它(没错误代表你的步骤错误)

13.最后完成时任意键离开
14.然后我们回到Mod Maker，切换到Tool
15.按照图中的数字填写

1的位置填你Mod的名字
2的位置填你的工具/武器名称
3的位置选你工具的类型(pickaxe=镐hatchet=斧头spade=铲hoe=锄sword=剑)
4的位置选你工具的威力(wood=木stone=石iron=铁gold=金diamond=钻石)
5的位置输入你工具的ID(建议1000以上，这样不容易有冲突)
6的位置选择你工具的图片
    这是我的图片例子
7的位置是制作合成表，先点左边方格，然后右边选择物品(都只是单字，自己查字典去吧)

16.然后点Add new item，如果有物品要制作就继续，不然请点Finish(中间的数字是你己经做了多少个工具)

17.切换到MCP setup
18.点recompile编译
19.点start client自动开测试版mc测试一下你的mod

   看到工具了吧，没任何问题
20.因为我的画图很差，所以用了镐改了点色测试下，看到了吧，很正常
21.最后点reobfuscate汇出class文件
20.完成后点Obfuscated Classes(Final Output)取出你的文件

21.然后就像平常装mod一样，先装modloader，再将你的mod跟图档放进minecraft.jar
22.己经完成了，剩下来的创意就交给你了
23.注意画图必须要找支援透明背景的软件去改，不然到时候你自己就会知道情况了，我就是用Paint.net
