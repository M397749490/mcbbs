启动服务端Bat文件设置:
  1. @ECHO OFF
  2. color 2
  3. title Dark的生存整合包 - 服务端
  4. SET BINDIR=%~dp0
  5. CD /D "%BINDIR%"
  6. "%ProgramFiles%\Java\jre7\bin\java.exe" -Xmx1024M -Xms1024M -jar mcpc-plus-1.6.2-R1.1-forge871-B97.jar
  7. PAUSE
复制代码
·其中"%ProgramFiles%\Java\jre7\bin\java.exe"是你的JAVA安装目录,如果你的JAVA安装在别的地方 请在""内填写地址
·其中-Xmx1024M和-Xms1024M是服务端调用的内存大小 1G=1024M 如果你的是32位JAVA 那么最大只能设置1024M
开服建议电脑配置&网络环境:
·10人服建议分配768M或以上的内存 以及6M及以上的网络带宽
·50人服建议分配3G或以上的内存 以及30M及以上的网络带宽
注意:
·请注意观察服务端压缩包名称 如:"Server v2.0 For Client v2.0"说明此v2.0版本服务端是对应v2.0版本客户端制作的
·游戏ID太短会出现加入服务端显示"数据流终止"的情况 请将游戏ID加长
·游戏ID不能使用中文 否则加入服务端还是会显示"数据流终止"
