**市武清区2018-2019学年度第二学期Minecraft综合第一次模拟考试
注意：本试卷除特殊标注版本均为1.13
第一部分 选择（45分）
一，单项选择题（36分）
1.小红在游玩Minecraft的时候，发现有一些方块会受到重力作用的影响，下列选项中，受重力影响的方块是（ ）
A.水方块
B.熔岩方块
C.混凝土粉末方块
D.陶瓷方块
2.小明在游戏中饮用了一瓶瞬间恢复药水，他想知道一些关于药水的信息，下列关于瞬间恢复的说法正确的是（ ）
A.瞬间恢复倍率最高的为255，在255倍率的时候可恢复2^255血的血量。
B.瞬间恢复等级最高为255，在255等级的时候可恢复2^255心的血量。
C.瞬间恢复倍率最高为256，在256倍率的时候可恢复2^256血的血量。
D.瞬间恢复等级最高为256，在256等级的时候可以恢复2^256心的血量。
3.下列关于村庄的说法，错误的是（ ）
A.如果你在村庄的受欢迎程度＜-15时，该村庄的铁傀儡会主动攻击你。
B.我们在可能会在沙漠或针叶林中发现一种全是村民僵尸的村庄，这种村庄十分罕见，只有2%的几率生成。
C.如果村民被怪物杀死或在玩家的16格范围内时死于非生物、非玩家来源，该村庄的村民在大概三分钟内不会交配。
D.一个村庄的最少人口是有效门的数量乘0.35，如果人口下跌到低于这数字（因死亡或绑架），但还有最少两个能相遇的村民，他们会交配并繁殖直至人口比最少人口高。
4.如果我们要在地图内使用熔炉烧制物品，可使用时间最长的燃料物是（ ）
A.1个熔岩桶
B.20个阳光传感器
C.4个干海带块
D.8个烈焰棒
5.下列关于烧炼的说法，错误的是（ ）
A.熔岩桶是燃料效率最高的燃料，可一次烧炼100个物品
B.弓在mc1.12中是不可被燃烧的
C.阳光传感器是可以被燃烧的，一次可以被熔炼20秒
D.烧炼任何物品一次都只需要30秒
6.下列四个选项中，可执行的是（ ）
A.execute as @e at @s run data merge entity @e {NoAI:true}
B.execute as @e at @s facing 0 64 0 in neither run tp @s ^1 ^ ^
C.execute as @e at @s run tp @s ^ ^10 ^ ~10 ~
D.execute as @a store success score @s holding_rod run enchant luck_of_the_sea
7.下列准则中，非只读准则的是（ ）
A.health
B.food
C.totalKillCount
D.xp
8.下列效果中，有图标的是（ ）
A.饱和
B.海洋的恩惠
C.瞬间治疗
D.瞬间伤害
9.丛林中生成丛林神庙的几率为（ ）
A.0.1
B.0.25
C.0.5
D.0.75
10.如果你以旁观者模式附身到生物上，哪个不会有特殊效果（ ）
A.末影人
B.蜘蛛
C.爬行者
D.末影龙
11.tnt爆炸后，掉落方块几率为（ ）
A.0.1
B.0.2
C.0.3
D.0.4
12.在一次爆炸中，爆炸共破坏了n个方块（爆炸涉及到的方块都可以生成掉落物），但只掉落了n-9个掉落物，则本次爆炸可伤害实体的理论最小范围体积与理论最大范围体积之比为（ ）
A.n^2-9
B.3/4兀[1.854n/(n-9)^3]
C.3/4兀[1.854n/(n+9)^3]
D.n^(n-9)
二，多项选择题（9分）
13.下列关于着色器及着色器的描述，正确的是（ ）
A.苦力怕 绿色视角
B.末影人 反色视角
C.蜘蛛 五倍视觉，轻微的模糊，高FOV（视场）
D.洞穴蜘蛛 和蜘蛛一样，但是略带红色
14.下列说法正确的是（ ）
A.旁观模式的玩家的飞行速度可以达到每秒43.556方块，在按住Ctrl键时的速度甚至可以达到每秒87.111方块。
B.如果启用了作弊，玩家可以用命令gamemode survival来切换到生存模式。
C.在创造模式中，将物品放在物品展示框里或盔甲架上，不会导致它从你手中消失，而会将物品复制一份。当你单击右键来穿上盔甲时，你的盔甲也会复制一份。
D.极限模式是一种游戏模式，它与生存的区别在于极限模式的玩家不能重生（取而代之的是以旁观模式重生）和难度锁定在困难。
15.下列的命令所需要op等级为2 3都可以使用的是（ ）
A.tp
B.whitelist
C.publish
D.kill
