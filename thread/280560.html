我看到有个教程,但是那貌似要安装桌面的`     
注意:空格一个不许少

第一步:安装java
      TIP:某些自带的JAVA可能工作起来性能不好,建议自己上传(直接在ssh界面    wget 你的下载链接   就好了).
我介绍直接安装 apt-get install openjdk-7-jre    安装java
第二步: 下载核心文件啦(我用我自己的核心文件,那是bukkit 1.7.2R0.3的,要其他的自己去找去)
命令:    wget sftp://z250967086@42.159.200.184/ ... 140316.221310-4.jar   (我不确定能上载`````毕竟这是sftp)
不行的话 就是   wget 你找的下载链接 (不能是分享链接,不能有防盗链(坑逼的百度网盘))
第三步:开服!
命令:java -jar -Xms最大内存 ./你上载到服务器的文件.jarXms是初始化内存用量，Xmx是最大堆内存用量   解释:如果初始化的时候内存很高，操作系统不会分配新的内存，也就是事实上变成了最大内存
这说明,把Xms改成Xmx才是比较严格的代码
解释下 -Xms后面加你想分配给他的最大内存 (超过1G需要64位JAVA支持)

你们在自己家随便开下服,把配置文件传上去,把正版验证关了
(你关了ssh在开,不会看见熟悉的后台界面,要用screen -r)我忘记-后面接的是c还是r了,太晚了,睡了

我来凑个热闹

Ubuntu/Debian 系仓库里只有 openjdk 但是已经明确被 mojang 声明不支持，所以建议用 oracle jdk
在 ppa 上有现成的包。不过下载速度什么的... 嗯...

接下来是 java 参数问题。
1. 一般来说 -Xmx 和 -Xms 设置差不多大就行了，差太多会有性能问题。
2. 加上 -server 会有一定的性能提升
3. 加上 -Djava.awt.headless=true 可以减少一些内存占用
4. 遇到 reload 的时候 MaxPermSize 出错的可以试试看加 -XX:MaxPermSize=128M，默认是64M，如果你插件比较多就容易出错

更高级的用法等你去 Google 咯。

Arch 的话可以添加我们社区仓库，jdk包是我打的。

用Arch Linux的可以比較懶
用指令

  1. yaourt spigot
复制代码
可以安裝Spigot

  1. yaourt craftbukkit
复制代码
可以安裝craftbukkit

  1. yaourt minecraft-server
复制代码
可以安裝官方minecraft server
前者2種安裝後都放在/srv/ 裹面
官方的我還沒有試過所以不清楚

然後用
  1. sudo systemctl start craftbukkit
复制代码
或用spigot 的話
  1. sudo systemctl start spigot
复制代码

就可以打開服務器的daemon 了
又或者直接用
  1. sudo /srv/craftbukkit/spigot.sh start
复制代码
都可以打開服務器
