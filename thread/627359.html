[stone]第三节：制作一个方块[stone]

记得上一节我做了一个冰锭，mc里什么锭啊什么锭啊都可以合成，没错，今天我们来制作一个和冰锭有关的方块，不是冰矿。。。

做一个极冰块吧，矿物后面讲


仔细看其实不是全蓝的

这就是了，我画的，伸手党拿走，不用谢[snowball]

首先需要导入这个材质

1.首先打开Resources里的create block/item texture[创建一个方块/物品材质]
2.关于材质，可以自己在画图里自己画，大小是16×16，然后点load image[加载图像]来加载图像，然而我已经做好了

这是在第二节里的
导入完成，点击new mod，如图，选择block，名字自己填随便，方便日后区分
然后点击next

这在下一个界面中是设置方块怎样的这是对方块方向的解析：
上
左 前 右 后
下
点击每个面中间空白的按钮，选择材质

选择好了，就点select

还有接下来的页面，右边许多英文大家也有可能不懂，所以也一一翻译：
名称 翻译 介绍
block render type 方块渲染类型 先别动
custom texture of the model
 自定义材质模型 也别动
click to select 点击选择 选择模型的，别管他
Y offset of model 不明 不懂就别乱调啦
大小[不要调整，现在还不需要]：
名称 翻译 介绍
mX 最小X坐标 调整方块的大小
mY 最小Y坐标 调整方块的大小
mZ 最小Z坐标 调整方块的大小
MX 最大X坐标 调整方块的大小
MY 最大Y坐标 调整方块的大小
MZ 最大Z坐标 调整方块的大小
下面还有俩
Don’t render as normal block 不渲染为正常块？
Has alpha？ 具有α[度娘翻译，我也不懂]
点击next，进入下一步
然后分成了四个工作区
