★RPG斩首系统★

你是否想过在服务器中添加一个好玩的野♂兽（原mob，翻译成野兽是某群的建议，不禁想到某些前辈）系统？
那么，今天将是你的幸运日，本插件拥有一个神奇的RPG游戏体验，你要杀死野♂兽们，并出售它们的头颅，带上它们的强大的面具，成为一个斩首大师。

★功能和特性★

  • 野♂兽RPG系统
  • 奇特的出售界面
  • 野♂兽头颅作为面具戴在头上有特效
  • 多种出售方式：界面，牌子，右键
  • Spawner商店
  • 末影珍珠冷却时间系统
  • 高速的头颅渲染系统
  • 能够使用方块打开出售菜单
  • 友好的用户指令和JSON系统
  • 完全可自定义
  • 在升级时可执行自定义命令
  • SilkSpawner和EpicSpawner插件支持
  • PlaceholderAPI和MVdWPlaceholderAPI 插件支持
  • LeaderHeads插件支持
  • MassiveFactions＆FactionUUID插件支持
  • WorldGuard插件支持
  • 与1.7.x服务器不兼容


★使用方法及玩法★

主要目标是从一级开始，斩首野♂兽，然后出售头颅获得经验和钱，然后升级
每个等级都是一个新的野♂兽类型，所以你可以在每次升级的时候解锁新的野♂兽类型。但在默认设置种，你不能斩首野♂兽，放置和取消生成位置都是未解锁的（你可以自行设置，但是不建议这么做）

每个头颅都值一定的金钱和经验。当你卖掉一个头时，你会得到这个头颅的全部金钱和经验。经验用于升级。当你输入/headhunter rankup时，你需要有一定数量的经验和金钱。获得金钱和经验的多少的量可以在Ranks.yml文件自行修改。


当然，你也可以杀死玩家并卖掉他们的头，这取决于你如何配置插件，当你卖掉玩家的一个头时，你也可以偷走这位头颅的主人（玩家）的余额的百分之一。如果你不想这样，你可以为玩家的头颅设置默认值。

"Cauldron 方块"（像Saico服务器一样）（表示没听说过，需要有人能解释一下）

你可以创作出一个自定义的方块，打开本插件的菜单

通过使用/hh block create指令并看着一个方块来设置，指令/hh block remove是来删除这个方块作为商店入口

但是你也可以通过配置文件设置一个方块

  1. "RIGHT_CLICK_ON_BLOCK_OPEN_GUI": true,                                            //设置为true是允许通过右键一个方块打开商店
  2. "BLOCK_TO_OPEN_GUI": "CAULDRON",                                                  //此处的CAULDRON是方块名字，可以打开商店的方块

可用的占位符：

如果您正在使用PlaceHolderAPI，占位符用法为：％占位符％，但如果您使用MVdWPlaceholderAPI，用法为：{占位符}

  1. HeadHunter_Level             //等级
  2. HeadHunter_XP                //经验
  3. HeadHunter_PlayerSkulls                //玩家头颅
  4. HeadHunter_MobHead_{野兽类型}             //野兽头颅类型，意义同上

★前置及拓展★
红色为必须加的，绿色为可选的：

  • Vault
  • Helix （下载地址：https://www.spigotmc.org/resources/helix.58373/）
  • SilkSpawners
  • EpicSpawners
  • PlaceHolderAPI：如果要将此插件的统计信息添加到附加的占位符API（如记分板等）的任何插件中，请使用此选项。
  • LeaderHeads：用于创建带有NPC，标志，全息图或横幅的排行榜。

★指令和权限★

  1. /HeadHunter rankup >> Headhunter.use         //查询等级，给玩家
  2. /HeadHunter stats >> Headhunter.use            //统计信息，给玩家  
  3. /HeadHunter reload >> Headhunter.admin        //重新加载插件，管理员权限
  4. /HeadHunter version >> Headhunter.admin       //查看版本，管理员权限
  5. /HeadHunter block >> Headhunter.admin         //创建商店方块，管理员权限
  6. /HeadHunter mask >> Headhunter.admin          //面具设置，管理员权限

  8. Sell Signs >> Headhunter.sell-sign                //商店牌子设置，给不给玩家看情况
  9. Spawner Shop Signs >> Headhunter.shop-sign            //牌子购买面具商店，看情况给，不建议给

  11. Spawners（按需要给）:
  12. 破坏: Headhunter.spawner_break
  13. 放置: Headhunter.spawner_place
  14. 改变: Headhunter.spawner_change
