作者: pineapple_    时间: 2018-2-7 22:55
[/s]正着反着横着竖着反过来调过去都行得通[/s]
首先你需要一个记分板和两个假名，一个记录秒数，一个记录bossbar的分数
a为dummy型记分板，让bossbar表示a记分板上一个假名的分数即可，该分数每秒+1
scoreboard players add gt a 1
execute if score gt a match 20.. run scoreboard players add s a 1
execute if score gt a match 20.. run scoreboard players set gt a 0
execute store result bossbar foo:bar value run scoreboard players get s a

反过来就是把第二条的add改成remove
