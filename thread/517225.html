标题: 一次mod物品导致服务器区块崩溃的修复经验
本帖最后由 zlzchuyue 于 2016-8-24 02:01 编辑

    许多腐竹服务器都遇到过mod的某个方块、物品导致一进入某个区域，客户端就崩溃，用创世神插件即可解决
某个地方，一去就闪退，任何人都一样，这时查看客户端崩溃报告。
精简了崩溃报告，可以很明了的看出来是哪个东西出了问题，下面是崩溃报告中的一部分：
-- Block Entity Details -- Details:         Name: cfmBlender // com.mrcrayfish.furniture.tileentity.TileEntityBlender         Block type: ID #524 (tile.blender // com.mrcrayfish.furniture.blocks.BlockBlender)         Block data value: 0 / 0x0 / 0b0000         Block location: World: (-1246,76,845), Chunk: (at 2,4,13 in -78,52; contains blocks -1248,0,832 to -1233,255,847), Region: (-3,1; contains chunks -96,32 to -65,63, blocks -1536,0,512 to -1025,255,1023)         Actual block type: ID #524 (tile.blender // com.mrcrayfish.furniture.blocks.BlockBlender)         Actual block data value: 0 / 0x0 / 0b0000




    可以很明确的看出是id为524的东西导致的崩溃，坐标为World: (-1246,76,845),于是就想办法干掉这个东西。


使用创世神
  
//pos1
  
坐标1
远程选取坐标

  
//pos2
  
坐标2
远程选取坐标


输入
//pos1 -1246,76,845
//pos2 -1246,76,845
最后，使用//replace 524 0  显示有一个方块被替换，说明成功了，这时再过去那个地方，就没事了
