隐藏的意思是不然玩家发现你服务器的插件吗？

具体能看插件的方法 /？和 /help
禁止玩家输入这两个命令就可以了

/help禁止方法：
essentials内设置，详情如下


  1. # 是否设置输入"/help"时,显示其它插件的命令.
  2. non-ess-in-help: false

  4. # 隐藏没给出权限的插件.
  5. # 你可以添加权限到对应玩家或用户组,使之对其显示.
  6. # 个人权限设置是:essentials.help.<plugin>,任何人有essentials.*或'*'将能看到所有帮助.
  7. # 如果下面的设置开启,你可以使用否定命令来移除权限,之后该插件的帮助将不会被看到.
  8. hide-permissionless-help: true
