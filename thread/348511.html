本帖最后由 1582952890 于 2017-9-17 08:58 编辑
这个插件是金色时光服务器的其中一个插件
插件没有指令
设置在config，也很简单


#在线时间 单位是分钟 (可以继续添加5:,6:,7:,等等)
online:
  1: 30 (这个是分钟,可以自己设置)
  2: 40
  3: 60
  4: 120
#完成上面的时间就给下面对应的钱 (根据你上面设置的项目时间送金钱上面添加了5:,这里也要添加)
money:
  1: 300
  2: 400
  3: 800
  4: 1500
#经验双倍
#是否开启
levelEnable: true
#开启的日期，0为星期天 ,true为开启
date:
  0: true
  1: false
  2: false
  3: false
  4: false
  5: false
  6: true
#开始结束的时间，示例为下午2点到4点
time:
  start: 14
  end: 16
