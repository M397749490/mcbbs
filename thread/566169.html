这是一个表格在一个表格以内的效果。
首先，我们需要做出一个表格在一个表格以内的效果，见下代码所示。
  1. [table=50%]
  2. [tr][td][table=50%]
  3. [tr][td]示范文字[/td][/tr]
  4. [/table][/td][/tr]
  5. [/table]
复制代码

其实际效果：
示范文字


       做出两个重叠的表格之后，调整表格宽度，使其分别为560和550，相差10像素的宽度看起来正好吻合（代码第一、第二行）。
  1. [table=560]
  2. [tr][td][table=560]
  3. [tr][td]示范文字[/td][/tr]
  4. [/table][/td][/tr]
  5. [/table]
复制代码

其实际效果：
示范文字


       继续下去，把表格行的背景颜色改为你想要的颜色。例子使用的是外部：#ECE3B8、内部：#99876C两种表格颜色。表格颜色的解释是加到{table=560}的后面，以{table=560,#ECE3B8}的方式表达（代码第一、第二行）。当然LZ也可以附在{tr}之后，以{tr=#ECE3B8}的方法表达。详细见《[论坛食用技巧76]论坛代码拓展教程1：表格长度、合并单元格》。
  1. [table=560,#ECE3B8]
  2. [tr][td][table=550,#99876C]
  3. [tr][td]示范文字[/td][/tr]
  4. [/table][/td][/tr]
  5. [/table]
复制代码

其实际效果：
示范文字


       最后，把表格居中（{align=center}...{/align}），调整表格内字样的居中（{align=center}...{/align}）、颜色（{color=#ffffff}...{/color}）、大小（{size=5}...{/size}）、字体（{font=宋体}...{/font}，当然这个不加也可以）。这样就完成了！
=成品效果=
  1. [align=center][table=560,#ECE3B8]
  2. [tr][td][table=550,#99876C]
  3. [tr][td][align=center][color=#ffffff][size=5][font=宋体]服务端整合包版规[/font][/size][/color][/align][/td][/tr]
  4. [/table][/td][/tr]
  5. [/table][/align]
复制代码

其实际效果：
服务端整合包版规
