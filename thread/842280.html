用途:

方便Denizen使用者便捷的存储或调用一些文件

优点:

Data文件独立文件夹保存

Data采用热加载方式,不会导致读取文件卡磁盘等情况

使用方式:

1.命令修改

/set [A] [B] [C] [D]

[A]:主类 [B]:项目

[C]:玩家 [D]:数值

2.其他脚本调用

  1. - yaml id:database set 你的脚本.项目类型.<player.name>:<player.location>
  2. - yaml savefile:/Data/database.yml id:database
复制代码
ID: database

路径:/Data/database.yml

BUG易发点:

设置完没有存储

在设置一些数值的时候下面一行必须是 savefile 不然会导致不存储数据的情况
