然后，关于怪物的生成限制，除了原版指令修改游戏规则，多世界，worldguqrd以及Plotme地皮都可以对这件事进行管制。plotme甚至还可以管制打火石是否禁用，所以，如果你在一个已被管制的世界，生成怪物那是显然矛盾的。

闲话，即便是怪物生成的监管，worldguard就比其他做得好，其他插件采取的是允许你生成，生成了就立马给你吃了就是了，简单粗暴。
worldguard不会，他管制时，会检查你是否具备OP权限，如果是，在禁止生成的区域，你照样可以生成怪物。

重要一点，除了这个总设置文件内，你需要改成你正确的世界地图名字，你还要在plugins\MythicMobs文件夹内的随机生成和自定义生成规则上
做出正确的配置。

默认，随机生成里，仅有如此简单几行
plugins\MythicMobs\RandomSpawns
ExampleRandomSpawns.yml
  1. #
  2. # These example files show you how to inject Mythic Mobs
  3. # you've created into your world. The name of each block
  4. # can be whatever you'd like but must be unique.
  5. RandomSkeletonKing:
  6.   MobType: SkeletonKing
  7.   Worlds: world
  8.   Chance: 0.001
  9.   Priority: 1
  10.   Action: replace
  11.   Conditions:
  12.   - outside true
  13. RandomSkeletalKnight:
  14.   MobType: SkeletalKnight
  15.   Worlds: world
  16.   Chance: 0.008
  17.   Priority: 1
  18.   Action: add
复制代码

意思是只有骷髅王和骷髅骑士会随机生成，生成规则里还有细则，是替换原版怪物，还是添加……

那么plugins\MythicMobs\Spawners文件夹内，记录的就是你人为设置的刷怪点，默认是空白的。
自定义生成和随机生成，在总配置文件内有选项的
  Components:
    CustomSpawners: true 自定义生成，开启
    RandomSpawning: true 随机生成，开启
