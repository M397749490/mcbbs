# 内容
通过指令来给玩家配置文件中的皮肤卡，玩家点击皮肤卡打开同行列表的GUI，点击对应精灵的皮肤来完成换肤。
基于 Pixelmon Wiki 自定义材质教程：https://pixelmonmod.com/wiki/index.php?title=Custom_textures

简易的自定义材质教程如下：
  • 在材质包的 assets/pixelmon/textures/pokemon/ 目录下，创建 custom-%value% 的文件夹 %value% 可以自定义任何好记的名称
  • 然后在复制pokemon目录下 你想修改的精灵的贴图文件，到你创建的文件夹下，自由修改配色
  • 游戏中应用该材质包，用 NBT编辑器 来编辑 对应的精灵，加入类型为 TEXT ，标题为CustomTexture，内容为 %value% 的值，并保存
  • 即可对这个精灵更换材质皮肤


而这个插件做的就是简化了 NBT编辑器 的步骤，直接应用到对应精灵与对应的 %value% 值，更利于玩家操作。

# 介绍
  • 能够完整显示队伍中精灵信息 和 所选的精灵信息，防止玩家更换错精灵的皮肤
  • 高度自定义的 GUI 页面和语言文件，你可以自由的更改你想更改的内容
  • 支持精灵的普通样子以及阿罗拉的样子，使用这一功能只需在精灵后加入 _alolan 后缀即可标记皮肤为阿罗拉的样子
  • 玩家的操作日志，精确到时分秒以及更换皮肤的玩家以及更换的精灵和皮肤名称

# 指令
pokeskin give <player> <poke> <skin> [amount]
pokeskin reload

# 权限
PocketmonSkin.use - 默认
PocketmonSkin.admin - OP
没有什么权限需要给的
