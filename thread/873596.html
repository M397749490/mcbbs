介绍 · Introduction
城主可以发起选举并让居民成为候选人或为其他人投票. 得票最多的居民将成为下一届城主，而上一届的城主会获得其他城镇职位.

如果你不想花钱的话，Civs城镇文明插件也有相同的功能
特点 · Features
  • 发起限时选举
  • 成为候选人
  • 为你喜欢的城主候选人投票
  • 投票匿名!
  • 可随时停止选举新城主
  • 一些指令和事件会有标题和音效
  • 所有数据有序保存
  • 插件兼容 UUID
  • 玩家无法看到选举数据
前置 · Requirement
  • Spigot 1.10 +
  • Java 8 +
  • Towny (推荐使用最新版)
指令和权限

  • /telect - 显示帮助 (townyelections.use)
  • /telect info - 查看插件信息 (townyelections.use)
  • /telect vote [候选人] - 为候选人投票 (townyelections.vote)
  • /telect unvote - 删除投票 (townyelections.unvote)
  • /telect convoke [持续时间] - 发出选举并提醒在线居民 (townyelections.convoke)
  • /telect run - 竞选城主的时间 (townyelections.run)
  • /telect list - 候选人名单 (townyelections.list)
  • /telect stop - 停止投票并选出候选人 (townyelections.stop)
汉化配置
config.yml
  1. language: en-US #语言文件名 (en_US.yml)
  2. max-duration: 604800000 #最大选举时间，单位为毫秒 (604800000ms = 7天)
