  2. # YggdrasilOfficialProxy

  4. YggdrasilOfficialProxy 采用了代理服务器的方式建立Yggdrasil服务器和
  5. official服务器的人同时登录的支持nya. 并且提供了2种加载方式nya!

  7. # 下载使用
  8. 如果你能熟练使用命令行启动java程序的话, 或者你想把 YggdrasilOfficialProxy
  9. 当做Java库使用. 下载 `dist\YggdrasilOfficialProxy-core.jar` nya.

  11. 如果你是懒得打命令, 匹配代码的话. 下载 `dist\YggdrasilOfficialProxy.jar` nya.
  12. 这个版本还包含了YOP使用的库nya.

  14. # 使用的库

  16. - [Netty](http://netty.io) - HTTP Server.
  17. - [Gson](https://github.com/google/gson) - JSON parsing.
  18. - [SnakeYaml](http://www.snakeyaml.org/) - YAML Parsing
  19. - [JetBrains Annotations](https://www.jetbrains.com/help/idea/annotating-source-code.html) - Source Annotations

  21. # 使用
  22. ## JavaAgent启动
  23. 你只需要把服务器的启动参数的
  24. `-javagent:injector.jar=...` 替换成 `-javaagent:YggdrasilOfficialProxy.jar` 就好

  26. ```shell script
  27. java -javaagent:YggdrasilOfficialProxy.jar -jar spigot-1.15.2.jar nogui
  28. ```

  30. ## 独立服务器启动
  31. 启动命令
  32. ```shell script
  33. java -jar YggdrasilOfficialProxy.jar
  34. ```

  36. # 配置
  37. YggdrasilOfficialProxy 需要配置好才能使用.
  38. 我们的配置文件专门存在一个文件里面, 并不是从opt里面读取.
  39. 下面是我们的配置文件, 默认他叫做 `YggdrasilOfficialProxy.yml`.

  41. 如果有需要的话你还可以自定义配置路径

  43. ```shell script
  44. java ... -javaagent:YggdrasilOffcialProxy.jar={path} ...
  45. java -jar YggdrasilOffcialProxy.jar {path}
  46. ```
  47. 下面是我们的配置
  48. ```yaml
  49. # Yggdrasil API 根地址
  50. # 对于某 "统一"通行证,
  51. # 他的地址是 https://auth2.nide8.com:233/{id}/
  52. yggdrasil: "https://yggdrasil.example.com/"
  53. # 检测玩家登录状态的时候先访问官方源
  54. official-first: false
  55. # 代理服务器端口
  56. # 填 0 以自动分配
  57. # 填 50000~51000
  58. # 自动从 50000~51000中选择一个端口
  59. port: 4321

  61. # 代理读取超时时间(毫秒)
  62. timed-out:
  63.   reading: 60000
  64.   connecting: 60000
  65. # 链接代理
  66. proxy:
  67.   official:
  68.     # direct 直接链接
  69.     # socks  Socks代理
  70.     # http   HTTP 代理
  71.     type: "direct"
  72.     host: "localhost"
  73.     port: 1080
  74.   yggdrasil:
  75.     type: "direct"
  76. extension:
  77.   # 是否为MySkin之类的插件提供缺省地址修复
  78.   yggdrasil-fix: true
  79.   opts:
  80.     injector:
  81.       # 请替换成你自己的injector所在位置
  82.       path: "G:/Java/authlib-injector-1.1.26-41a7a47.jar"
  83.       # 没有需要的话不用改
  84.       arg: "{proxy}"
  85. ```
