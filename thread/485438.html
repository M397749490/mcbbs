盗版额外步骤：


1.下载以后，去度娘找一些Midi格式音乐，点击"Create a New Song"
2.点击"Files"，然后点击"Import from MIDI"，选择一个音乐。
3.就可以导入了。
4.点击"Export as Schematic"导出MCEdit区块包。
5.打开MCEdit，创建一个超平坦世界，点击Import，导入后按"Enter"。
6.按"Ctrl+s"{
                              保存到：你的文件夹/.minecraft/saves/
                             }。
7.打开Minecraft 1.5+版本（正版盗版皆可）
8.打开你的地图。
9.听音乐吧！

服务器额外步骤(我的服务器里有哦)：

插件原帖：http://www.mcbbs.net/thread-383243-1-1.html   GTH2000
服务端插件
英文名称:MusicPlayer
中文名称:音乐播放器
来源:转载
类型:|CraftBukkit插件|  
前置模组|插件:NoteBlockAPI（下载见下面）
下载地址:http://dev.bukkit.org/bukkit-plugins/musicplayer/files/
原帖地址:http://dev.bukkit.org/bukkit-plugins/musicplayer/
最后更新:2015-01-09
能做什么：

利用它你可以不用在客户端安装mod即可播放指定的音乐，让您的服务器更加独特

如何安装：

1.下载NoteBlockAPI：http://dev.bukkit.org/bukkit-plugins/noteblockapi/

2.安装NoteBlockAPI

3.下载MusicPlayer

4.安装

5.去这里下载.nbs格式的音乐并放到plugins/MusicPlayer/songs/

命令和权限：

Player Commands:
  • /play <SongName/SongID>
  • /stopsong
  • /listsongs
Admin Commands:
  • /musicplayer reloadsongs
  • /musicplayer listsongs
  • /musicplayer disablemusic
  • /musicplayer enablemusic
  • /musicplayer stopall
  • /musicplayer playingsongs
  • /musicplayer playall <SongName/SongID>
Permissions
  • music.reloadsongs: default: op
  • music.listsongs: default: op
  • music.disablemusic: default: op
  • music.enablemusic: default: op
  • music.stopall: default: op
  • music.playall: default: op
  • music.play: default: op
  • music.listsongs: default: op
  • music.adminhelp: default: op
  • music.userhelp: default: op
  • music.playingsongs: default: op
  • music.playall: default: op
