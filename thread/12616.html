你先去es插件或者权限里看看有没有给自己权限 再来设置

Command = ChopTree, ct
Toggle = ToggleChop, tc

# Here you can change the options (can also be done in-game).

ActiveByDefault = true  默认触发
UseAnything = true 用啥都行（用手砸树树也倒塌）
MoreDamageToTools = true 对工具伤害更大
InterruptIfToolBreaks = false 让工具损坏（就是普通的你砸多少树干工具减多少耐久）
SupportMcmmoIfAvailable = false 若有mcmmo插件 是否支持
TreeFellerNeeded = false feller是伐木工的意思 不懂这句
LogsMoveDown = false 树干下落 （会卡的）
OnlyTrees = true 只局限于树
EnableOverride = false  也不懂

# -Material List-  这就是可以用来秒杀树的工具表 输入 mat = 工具ID或者名字即可
# If the "UseAnything" option is false, the plugin will take the items you can use to chop trees with from here.
# You can either put in the material's name or its ID.

mat = WOOD_AXE
mat = STONE_AXE
mat = IRON_AXE
mat = GOLD_AXE
mat = DIAMOND_AXE
