单位是毫秒
作者: a8105    时间: 2018-7-31 19:00
Bukkit.getServer().getScheduler().runTaskTimer(this, new Runnable() {
    @Override
    public void run() {
        //你的代码
    }
},(5*60)*20L,(5*60)*20L);

第一个(5*60)*20L为第一次运行的间隔
第二个(5*60)*20L为每次运行的间隔
时间单位是刻
20刻=1秒
不是3楼所说的时间单位是毫秒

Edit:
this参数为JavaPlugin类型
