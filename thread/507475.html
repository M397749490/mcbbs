功能
个人清屏、全体清屏
全体禁言



指令
/cc - 全部指令
/cc all - 清除所有人的屏幕
/cc clear - 清除自己的屏幕
     /cc clear <--> - 清除某玩家的屏幕
（以下需要插件版本为1.6或更高版本)
/cc lock - 全员禁言
/cc prefix <--> -设置信息前缀




权限
cc.* - 全部权限
cc.use - 使用/cc的权限
cc.me - 清除自己聊天的权限
cc.other - 清除别人聊天的权限
cc.all - 清除所有人聊天的权限
cc.lock - 使用/cc lock的权限
cc.lock.bypass - 不受禁言影响的权限
cc.prefix - 使用/cc prefix的权限
不会给默认组权限?
/mangaddp default [权限]




配置文件
##设置插件消息前缀##
##支持颜色代码##
##设置为''则取消前缀##
prefix:'&a[CC]'
