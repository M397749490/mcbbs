Sojourn 逗留
我不清楚我为什么要搬运这个MOD，也许有些整合包或者地图作者也许会需要这个MOD：D
这个神奇的MOD使你的世界只留下了一个生物群系
例如全世界都是蘑菇岛啊，都是沼泽啊，都是地狱啊，都是末地之类的玩意
这个生物群系可以根据配置文件进行改变：D
嘛我该介绍的都介绍了
那就说一下使用方法
首先找到你的.minecraft文件
直接进入.minecraft\config\sojourn
里面会有个sojourn.cfg文件
用记事本或者Notepad++打开，随便你选哪个
  1. <p>
  2. # Configuration file</p><p>client {
  3.     # When true, users will not be able to make non-sojourn worlds 当为true时，玩家将无法使用除"Sojourn"以外的世界
  4.     B:forceSojurnWorlds=true
  5. }</p><p>
  6. general {
  7.     # The registry name for the biome Sojourn uses for worlds. [Example: traverse:autumnal_woods] 这个为生物群系的注册名称，示例：autumnal_woods
  8.     S:sojournBiome=minecraft:forest
  9. }</p><p>
  10. </p><p align="center"> </p>
复制代码
可能有些玩家不清楚生物群系是啥玩意，那我就举个例子.
在游戏里按下F3
你会发现在左上角出现了一堆文字
找到biome，你会看到我所处的生物群系为Savanna
这是我所在的沙漠生物群系，如果你想让这个生物群系存在于你的世界之中
则把minecraft:forest改成minecraft:Savanna即可
