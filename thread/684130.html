经过我测试，在discuz任何版本(包括最新版X3.3)都可以通过<img />HTML标签间接接受任务
--例如
接受任务：http://mcbbs.tvt.im/home.php?mod=task&do=apply&id=24
退出：http://mcbbs.tvt.im/member.php?m ... t&formhash=xxxxxxxx
收藏：http://mcbbs.tvt.im/home.php?mod ... 0&formhash=xxxxxxxx
勋章(验证来源)：http://mcbbs.tvt.im/home.php?mod ... ply&medalsubmit=yes

通常这些链接验证formhash或验证来源进行验证，然而任务系统却不验证formhash，也不验证来源


初步解决方案：
discuz根目录\source\function\function_discuzcode.php
搜索"function bbcodeurl"，该函数的作用是过滤Discuz代码
  1. function bbcodeurl($url, $tags) {
  2.         if(!preg_match("/<.+?>/s", $url)) {
  3.                 if(!in_array(strtolower(substr($url, 0, 6)), array('http:/', 'https:', 'ftp://', 'rtsp:/', 'mms://')) && !preg_match('/^static\//', $url) && !preg_match('/^data\//', $url)) {
  4.                         $url = 'http://'.$url;
  5.                 }
  6.                 return str_replace(array('submit', 'member.php?mod=logging', 'home.php?mod=task'), array('', '', ''), str_replace('{url}', addslashes($url), $tags));
  7.         } else {
  8.                 return '&nbsp;'.$url;
  9.         }
  10. }
复制代码

可见"submit"和"member.php?mod=logging"已经被过滤为空，如上添加"home.php?mod=task"即可过滤
效果：出现以上关键字保存时自动替换为""
