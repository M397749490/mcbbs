我发现搬运贴中没有讲到关于配置文件设置的问题，因为bukkit上面的原帖只有1.2.2的配置文件教程，所以我在这里发一下1.3.0的配置文件教程



  储存设置

storage:
  type: sqlite     #储存类型
  mysql_user: root                #关于mysql数据库的设置我不太懂..可以参照其他插件的数据库设置方法来设置,但是储存名称不能一样！！！
  mysql_pass: password
  mysql_database: market
  mysql_address: localhost
  mysql_port: 3306
配置教程：储存类型：目前只有mysql和sqlite 选择其一填写即可


多世界设置

  enable: false    #是否启用 如果启用则填写为true  反之则为false
  links:
    world:
    - world_nether
    - world_the_end
配置教程：这个插件提供了一个多世界市场的功能，如果启用,市场将分为各个世界,在每个世界交易每个市场的东西，邮箱也是分开的,如果开启这个功能，输入/market mail打开邮箱的时候则会有一个切换各个世界的邮箱的功能




限制设置


limits:

  default:

    cut: 0.05      #玩家每次上架物品时服务器收取的税金,可以是百分比,也可以是固定费用  固定费用：如“100” 百分比费用：如“5%”或“0.05”小数点百分比不能超过1,超过1就是固定费用~

    max_price: 10000  #上架的物品的出售价格限制,0为无价格限制

    max_item_prices: #允许你自定义一个物品的价格限制

      stone:   #物品ID,我没测试,不知道数字ID可不可以

        dmg: 0    #这个就是物品的冒号后面的数值 例如黑色羊毛35:35 那么dmg这里就要填写35

        price: 50.0   #限制的价格

    creation_fee: 5  原文：

can either be a flat fee (like 100) or a percentage (like 0.05, which is 5%) that is charged when a player creates a listing. Set to 0 to disable.



    max_listings: 15 #玩家可以上架多少货物到全球市场,设置为0则禁用

    expire_time: 168 #物品上架多久没被购买会自动下架,设置0则禁用

    queue_trade_time: 5  #设置0即可

    queue_mail_time: 5 #设置0即可

    allow_creative: false #如果设置为false，会阻止创建列表、发送邮件、查看邮件和在创造模式时查看列表。

  admin:

    cut: 0.0

    max_price: 0.0

    creation_fee: 0

    max_listings: 0

    expire_time: 0

    queue_trade_time: 0

    queue_mail_time: 0

    allow_creative: true

配置教程：自定义每个用户的限制。配置文件中的每个个组的权限为:globalmarket.limits.<组的名称>   可以分配给玩家，如果没有分配任何权限给玩家,则会使用默认配置。




队列设置


queue:

  queue_mail_on_buy: true #当玩家购买物品后是否发送到邮箱内,如果为false,则直接发送到背包

  queue_on_cancel: true #当玩家取消上架商品时，是否取消队列





黑名单设置

blacklist:

  custom_names: false  #是否允许上架铁砧修改过名字的物品

  item_name:  #以下名称的商品不允许上架

  - Transaction Log

  - Market History

  item_id:   #以下的物品ID不允许上架

    '0': 0

  enchant_id:  #以下附魔效果的物品不允许上架   附魔ID查看：<<<传送门>>>

  - 5

  lore:        #物品中有以下lore的不允许上架

  - 'Billy Bob's Sword'


  use_with_mail: false  #如果启用，那么玩家在使用/market send指令时检查黑名单(就是将这个指令也进行黑名单限制)

关于Item_id项我也不太懂,大家可以看这个原文

item IDs and damage values to blacklist. A damage value of -1 will blacklist all damage values for that item. Wood's item ID is 5: 5: 0 will blacklist normal wood planks, 5: 1 will blacklist spruce planks, and 5: -1 will blacklist all wood types.





无限商品设置



infinite:  #无限商品设置

  seller: Server     #这个账号所出售的商品都是无限商品,可以修改Server为腐竹或管理员的游戏名字,不然就禁用这个用户,否则后果自负哦~


  account: '' #这个不用管





杂项设置


automatic_payments: false #是否禁止购买物品后发送交易记录到邮箱 建议设置为ture

enable_history: true  #是否开启交易历史记录，历史记录查询方式：/market history

stall_radius: 0

mailbox_radius: 0

announce_new_listings: false #是否在聊天窗中公布新创建的市场

enable_metrics: true 是否开启metrics 建议开启，方便作者统计

notify_on_update: true #是否开启更新通知

有些地方写的可能不完整或者不对，这是原帖地址，如果你找到了什么错误，欢迎指正
