  1. ChatPrefixEnable: true
  2. ChatPrefix: ''

  4. ChatCoolTime: 0
  5. AutoUse: false
  6. AutoCost: false

指令及权限:

指令
描述权限默认
/sc setitem将手上拿着的物品设置为喇叭ServerChat.Adminop
/sc give [玩家] [数量]给予玩家喇叭,留空则给自己ServerChat.Adminop
/sc reload重载插件配置ServerChat.Adminop
/sc ignore无视所有跨服消息ServerChat.Ignoreop
/sc buy [数量]
购买跨服喇叭ServerChat.Buy所有玩家

跨服喇叭的颜色使用ServerChat.Colorop
/sc send
发送跨服喇叭无所有玩家
/sc update
检查插件更新ServerChat.Adminopop
变量:

%player% : 玩家名字
%server% : 玩家所在服务器
%message% : 消息内容
%cooltime%：喇叭冷却时间

支持所有PlaceholderAPI变量
