前几天在写弹幕系统（没错就是下一个坑）的时候
想起了一个致命问题

对
那就是
玩家公屏发敏感词要怎么过滤？？？

查了查mcbbs和百度，国内貌似只转载过一个 BungeeCord跨服端 的敏感词过滤插件
但由于自己并未涉及BC的领域
于是就着手开发了一个属于 Bukkit/Spigot 全版本的高可用/高拓展性的过滤器
算法原理很简单，运用的最基本的敏感词过滤规则

那就是 -
有穷自动机 (Deterministic Finite Automaton) 算法

更新：（关于重名）也是后来检索BadWordKiller发现在Nukkit核心有作者写过，但和本BadWordKiller不是一个插件
功能和实现原理也不同，在此声明下

有穷自动机 (Deterministic Finite Automaton) - DFA 算法

以简要为主，就直接说用它到底好在哪里：
它几乎可以让你在 0.1s 内匹配超过 上万个敏感词

v1.0.0
BadWordKiller 1.0.0 默认包含了 2500+ 种中英文敏感词汇
（DFA建树后约为 610 个最小匹配节点）
其中包括了你所有可能想象的过滤类别
（限制了zz相关，sq相关，广告营销，民生不良词汇等）
并且可在config实现
手动添加 / 删除 你想过滤的新词

v1.1.0 - 1.1.5  [记得更新config文件]

※① 可自定义掩码※
输入案例：【FXXK!!! FXXX!】
输出值1：【我爱你呀!!! 我爱你呀!】
输出值2：【我饿了!!! 我饿了!】

※② 可跨越任意 符号，数字及大小写 - 强行识别敏感词※
【2┡┮┭3^测 ！@#！@￥试%!#→↓◆★★←〓¤^#%字 --$!%!@12--符h┣┟Aha┮$^】
可识别出：【“测试字符haha”】

※③ 弥补了DFA算法的局限性 - 增加 单字符匹配 功能※
输入案例：【橄！】
输出值：【我爱你呀！】

※杜绝了 中文中间夹杂英文 的干扰※
    输入案例："^#!3^测 2┡┮┭lo◆★★←ve〓¤试%!@^"
    可识别出 1： "测试"   -->  输入算法 排查中文
    可识别出 2： "测love试" -->  输入算法 排查中英混淆、单英文

※其他更新※
加密了字符库
优化了整体匹配逻辑
增加了对中性词是否可能为敏感词的判断逻辑
增添了近两年内的祖安词汇监测功能
删除了一些不至于限制的敏感词

v1.2.0

※管上了 /tell 指令※
不多说了，就是香

※可以 在线管控config 中的内容※
/bwk mask <word> - 替换掩码
/bwk add ban <word> - 添加限制词
/bwk add unban <word> - 添加忽略词
/bwk remove ban <word> - 删除限制词
/bwk remove unban <word> - 删除忽略词

※添加了 debug功能※
输入/bwk debug 即可在线测试语句和词库
输入 cancel 退出debug

使用方法

方法2： 将jar文件放入plugins文件夹，使用yum实现热加载


配置文件

# 监测到敏感词后删除消息还是替换成符号？[默认替换]
replace: true

# 若开启替换，则把敏感词替换为如下掩码
mask: '爱你'

# 你可自定义新的敏感词列表
add:
  - '阿伟死了'

# 你也可从默认的列表中删除你不需要的敏感词
remove:
  - 'fxxx'

# Messages 消息
# 若在上面开启了replace功能而非直接删除消息，那么下方的拒绝消息将不会提示给玩家
Msg_Reject: "&b[BWK]&c莫生气！莫生气！有什么事都好解决的，不要发晦气的话哦"
Msg_Reload: "&b[BWK]&a配置文件已重载"
Msg_NoPerm: "&b[BWK]&c执行失败，尚未找到相关权限"
