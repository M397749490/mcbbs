作者: 89009332    时间: 2015-2-14 21:21
那要先看你是用的什么权限插件了，ess的权限组在config.yml文件了修改
  mirrors:
        world:#这个是主世界，下面的是子世界。如果某个世界不再这里面。那么这个世界的权限组独立。
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          zc:
          - users
          - groups
          plotme:
          - users
          - groups
          plotworld:
          - users
          - groups
          newworld:
          - users
          - groups
在找到对应世界的group.yml文件管理权限即可
