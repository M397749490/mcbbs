简介

本插件允许你下载图片和gif，并且通过本插件在游戏中建造出图片和gif。

特性

－ 允许op或者拥有相应权限的玩家下载，截取，并且在游戏中自动建造图片。
－ 支持 jpeg，png， gif 格式。
－ 所有版本通用（未经测试）


指令


pixelprinter均可使用pp代替 如：/pixelprinter = /pp
指令描述
/pixelprinter 列出所有指令和描述
/pixelprinter download <地址> <文件名>或/pixelprinter d从<地址>下载图片以<文件名>命名
/pixelprinter downloadimage <地址> <文件名>或/pixelprinter di <地址> <文件名>从<地址>下载图片以png jpg gif形式和<文件名>命名
/pixelprinter create <方向> <文件名> <高度>在游戏中以<方向>方向将<文件名><高度>为高度（图片底部到顶部的距离）生成 图片的宽度（图片左端到右端的距离）将会根据游戏内高度和实际高度比例进行自动生成
/pixelprinter help或/pixelprinter ?显示所有指令和描述
/pixelprinter delete <filename>删除名为<文件名>的文件
/pixelprinter stopGif <ID> 停止id为<ID>的gif
/pixelprinter stopAllGifs停止服务器内所有gif
/pixelprinter listGifs 显示服务器内所有活动的gif
/pixelprinter preview为你即将创造的图片创造一个框架，这个指令只会显示图片的框架（最外层的一圈方块），所以你可以通过这个指令知道哪些已存在的方块将会被替换
/pixelprinter specs显示图片的规格
/pixelprinter list显示已经下载到服务器的所有图片


权限


权限描述
pixelprinter.*所有权限
pixelprinter.stop停止gif的权限
pixelprinter.delete删除图片文件的权限
pixelprinter.create在游戏中创造图片的权限
pixelprinter.download从一个地址下载图片的权限
如果不想下载，可以直接将图片放到p夹/PixelPrinter/images file
