安装与使用
使用本插件前，需安装最新版Residence
装载插件后填写plugin/TuziFight配置文件信息
输入/tzf reload重载config.yml就已经完成了你的配置，接下来按照config.yml中的提示进行自定义修改即可
然后直接拿起你的rpg武器输入/tzf see 即可统计自身战力(战力统计建议使用牌子、npc、捆绑指令)


指令与权限
  • /tzf see -tzf.see  评测个人战力及排名
  • /tzf ph - tzf.ph 查看战斗力排行榜
  • /tzf set - tzf.set 设置领地战斗力最低限制
  • /tzf remoive - tzf.remove 移除领地战力限制
  • /tzf reload - tzf.reload 重载配置文件
建议给予玩家/tzf see和/tzf ph权限或使用脚本方块进行祭坛测评
数据库进行的是长连接，/tzf reload会关闭重置连接
