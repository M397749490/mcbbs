  1. net.berry64.asdf.main

  1. package com.github.berry64;

  3. //下面是导入的包
  4. import org.bukkit.command.CommandSender;
  5. import org.bukkit.event.Listener;
  6. import org.bukkit.command.Command;
  7. import org.bukkit.plugin.java.JavaPlugin;

  9. //主代码
  10. public class MyFirstPlugin extends JavaPlugin implements Listener{
  11.         public boolean onCommand(CommandSender sender, Command cmd, String label, String[] args){
  12.                 if (cmd.getName().equalsIgnoreCase("HAYO")){         
  13. //记得这里的指令不需要带上 "/" , 比如说游戏里输入"/HAYO" 这里就是 "HAYO"
  14.                         sender.sendMessage("HAYO!");                          
  15. //向指令发送者发送 HAYO! ,这里可以用§输入彩色代码
  16.                         return true;                                                      
  17. //返回 "真" 说明这个指令顺利通过了， 如果返回 "假"(false) 那么服务器就会提示
  18. //在plugin.yml里面写的 usage 的文字提醒玩家如何使用
  19.                 }
  20.                return false;
  21.         }
  22. }
复制代码

这样，java里面的指令已经创好了，记得把[指令]换成你要的英文指令
现在我们打开plugin.yml来注册这个指令
在下面我们输入:
  1. commands:
  2.   HAYO:
  3.     description: HAYO
  4.     usage: /<command>

@Override 就是重写父类方法的一个语句，这个嘛，不好解释
就是说extends JavaPlugin这里命名JavaPlugin这个class为父类，然后这个class里面自己已经有了onEnable(){
但是这里子类的又要写一个自己的onEnable()，为了不产生矛盾所以@Override告诉java这里重写而不要使用父类自带的方法。。。
