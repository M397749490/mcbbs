不要直接用ChatColor.xx+str的方式，那样会造成客户端换行时重置颜色，应构建自己的Component

显性构建：
TextComponent message = new TextComponent( "tttttttttttttttttttttttttttttttttttttttttttttttttttttttt" );
message.setColor( net.md_5.bungee.api.ChatColor.RED );
player.sendMessage(message);
