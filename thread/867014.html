介绍 · Introduction
玩家每次死亡后血量上限都会减少。玩家死亡后会从噩梦中苏醒。当血量上限将为0时玩家将永久死亡，无法再复活。


特点 · Features

  1. healthLossText: 你的生命值已永久减少.
  2. bedRespawnText: 你充满迷惑地从梦中醒来
  3. noBedRespawnText: 由于没有栖息之地,你从梦中醒来了.
  4. permaDeathServerText: 彻底死亡了!
  5. permaDeathPlayerText: 你彻底死亡了.
  6. dragonKillText: 梦结束了. 你的头脑清醒了,传送门也打开了.
  7. maxHpRestoreText: 你的血量上限已恢复.

  9. bloodEffectEnabled: true
  10. trippyEffectEnabled: true
  11. trippySoundEnabled: true
  12. weaknessOnRespawn: true

  14. restoreHpOnDragonKill: true
  15. enforceHardcoreMode: true
复制代码


指令 & 权限
  • hardcoreplus.admin - 管理员权限


  • /hardcoreplus setmax <玩家> <数值> - 设置玩家血量上限.
  • /hardcoreplus reload - 重载配置
