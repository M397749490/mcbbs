标题: 1.13复活币系统！支持多人！麻麻再也不用担心我被打死啦
大佬们好！

1.13指令的更新可以说是真的很好了，做很多东西上方便了很多
这次要给大家分享的是1.13版本，指令制作的复活币系统！


效用：死后使用复活币原地复活
实际原理：获取玩家死前x，y，z坐标并储存，使用复活币使玩家tp到死前的坐标

那么教程就此开始吧

首先，用到了以下五个计分板：
获取坐标的计分板：
  1. /scoreboard objectives add positionx dummy
  2. /scoreboard objectives add positiony dummy
  3. /scoreboard objectives add positionz dummy
复制代码
记录死亡次数的计分板：
  1. /scoreboard objectives add death deathCount
复制代码
使用复活币的计分板（在这里是雪球）：
  1. /scoreboard objectives add fuhuobi minecraft.used:minecraft.snowball
复制代码


然后用三个repeat命令方块分别获取并储存活着的玩家（death=0）的x，y，z坐标
  1. /execute as @a[scores={death=0}] at @s store result score @s positionx run data get entity @s Pos[0]
  2. /execute as @a[scores={death=0}] at @s store result score @s positiony run data get entity @s Pos[1]
  3. /execute as @a[scores={death=0}] at @s store result score @s positionz run data get entity @s Pos[2]
复制代码


用repeat命令方块初始化活着的玩家的复活币（雪球）使用值：
  1. /scoreboard players set @a[scores={death=0}] fuhuobi 0
复制代码


之后是以下命令链：
repeat命令方块（检测死后重生的玩家是否使用雪球）：
  1. /execute as @a if score @s[scores={death=1..}] fuhuobi matches 1..
复制代码
+比较器（当时做的时候没想那么多，就做成还有比较器这样的了）

+pulse命令方块（检测使用了复活币（雪球）的玩家并召唤一个名为spawn的盔甲架）：
  1. /execute as @a[scores={fuhuobi=1},limit=1] run summon minecraft:armor_stand ~ ~1 ~ {CustomName:""spawn"",CustomNameVisible:1b}
复制代码

+以下都为chain命令方块（按顺序输入）：
  1. /execute as @e[name="spawn",type=minecraft:armor_stand] at @s store result entity @s Pos[0] double 1 run scoreboard players get @a[limit=1,scores={death=1..,fuhuobi=1..}] positionx
  2. /execute as @e[name="spawn",type=minecraft:armor_stand] at @s store result entity @s Pos[1] double 1 run scoreboard players get @a[limit=1,scores={death=1..,fuhuobi=1..}] positiony
  3. /execute as @e[name="spawn",type=minecraft:armor_stand] at @s store result entity @s Pos[2] double 1 run scoreboard players get @a[limit=1,scores={death=1..,fuhuobi=1..}] positionz
  4. /execute as @a[scores={death=1..,fuhuobi=1}] run tp @a[scores={fuhuobi=1}] @e[limit=1,name="spawn"]
  5. /kill @e[name=spawn]
  6. /execute as @a[scores={fuhuobi=1}] at @s run scoreboard players set @s death 0
  7. /execute as @a[scores={fuhuobi=1}] at @s run scoreboard players set @s fuhuobi 0
复制代码


作用机理为：分别将玩家positionx，positiony，positionz计分板储存的值（也就是玩家死之前的坐标）赋予盔甲架的坐标,Pos[x,y,z]，再将玩家tp到被赋值之后的spawn盔甲架，然后做好后续处理，比如初始化计分板，清除盔甲架。（测试过两人联机使用，理论上支持多人）


可以看出来，这个有个很明显的瑕疵，就是如果玩家死了一次没有使用复活币呢？下次再死亡，使用复活币不是复活到上上次死亡的坐标了吗？
在这里我给出的回答是，你可以再做一个死亡后检测一定时间内玩家是否使用复活币，若没有使用则死亡次数清零，这样就避免了上述问题。
