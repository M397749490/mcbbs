==================基础指令==================

/spawn 返回这个世界的出生点
/home set 设置你的第一个家 /home set -o home1设置名为home1的家
/warp sc 这是出生点坐标
/warp sc1 /sc2/sc3/sc4
这些都是生存世界 你可以作家圈地 跟你的好朋友玩耍
/warp kw /kw1/kw2/kw3/kw4
这些是矿物世界的坐标 可以作为挖矿地点
