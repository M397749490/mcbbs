WebLoginV2.0：现已加入联锁封号（封号通知服务器）！

这是什么

当玩家尝试连接到服务器时，插件会自动向你填写的服务器POST数据

当服务器返回特定消息的时候，允许或者拒绝玩家登录（默认消息为<[AccessOK]>，其他消息将作为踢出玩家所显示的信息）

当玩家尝试连接到服务器时，插件会自动向你填写的服务器POST数据

当服务器返回特定消息的时候，允许或者拒绝玩家登录（默认消息为<[AccessOK]>，其他消息将作为踢出玩家所显示的信息）

该插件也支持/ban和/unban指令，当你输入这些命令时，插件会自动提交一些数据到你指定的服务器 1.7.10以下版本未测试，如果能用的话请告知

灵感来源于Beelogin，向其作者致谢


它有什么优势

1.更安全

比起传统的CrazyLogin之类的进游戏后再登录的插件，他更安全

众所周知，CL无法拦截MOD发送的数据包，比如NEI（没登录也能修改世界时间之类的）

2.更开放

WebLogin只是个服务端，一切验证行为都由目标网页端完成，WebLogin几乎不参与交互

比如MoeCraft设计的“按一下按钮登录”

3.功能强大
  • 它会向服务端提交 玩家名称，IP，UUID，时间 信息
  • 支持密码验证
  • 支持自定义消息（支持显示网页端给出的消息）
  • 当网页端服务器宕机时，可以设置是否允许玩家直接登录（此时可以使用Crazylogin等传统插件）
用法
1.命令
  • /weblogin 显示插件帮助
  • /weblogin reload 重载插件设置
  • /wban 使用weblogin封禁玩家
  • /wunban 使用weblogin解除封禁玩家
  • /ban 使用weblogin封禁玩家. 选项 rewriteBanCommand 为 true 时可用
  • /unban 使用weblogin解除封禁玩家. 选项 rewriteBanCommand 为 true 时可用

2.权限

moecraft.weblogin.command.reload
允许重载插件，OP默认拥有

4.插件配置文件说明

  2. # 登录成功/封号成功时服务器给出的消息。当服务器给出这个消息的时候允许玩家登录
  3. successMsg: '<[AccessOK]>'

  5. # 服务器密码（POST的pwd项）
  6. pwd: 'helloworld'

  8. ###########################外部网页登录设置#####################################
  9. # 目标服务器地址
  10. url: 'http://localhost/weblogin.php'

  12. # 是否启用外部网页登录
  13. enableWebLogin: true



  17. # 自定义踢出消息？ true表示显示服务器发出的消息。警告：服务器给出空消息表示服务器宕机！
  18. customKickMsg: true

  20. # 踢出玩家所显示的消息，当开启自定义踢出消息时不可用
  21. kickMsg: 'Access denied.'

  23. # 是否要在服务器宕机时重试？输入重试次数
  24. retryIfServerOffline: 5

  26. # 如果服务器宕机，是否不要踢出玩家？
  27. noKickIfServerOffline: false

  29. # 是否在发生致命错误时踢出玩家？
  30. kickIfWebloginError: true
  31. # 发生致命错误时踢出玩家的消息
  32. kickIfWebloginErrorMessage: 'SERVER ERROR'
  33. ########################################################################################

  35. ############################# 网页连锁封号的设置 #####################################
  36. # 网页连锁封号的目标服务器地址
  37. banUrl: 'http://localhost/wenban.php'

  39. # 启用网页连锁封号？
  40. enableWebBan: true

  42. # 是否在成功时（给出<[AccessOK]>）踢出玩家？
  43. banKickIfSuccess: true

  45. # 封号成功时踢出玩家的消息
  46. banKickMessage: 'You are banned!'

  48. # 重写 /ban /unban 指令? 可能不工作
  49. rewriteBanCommand: true

  51. # Continue(allow other plugin to process ban command) if some fatal error happened? Unavaiable if "rewriteBanCommand" is "false"
  52. banContinueIfFailed: false
