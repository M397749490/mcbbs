如果你想要录制一个MC的小短片又找不到合适的录像者的话这个mod肯定适合你
首先，下载地址（我是说正话的）

由于我也没用多久这个mod,有问题可以说出来
这个mod里面没有增加一个方块，但是增加了很多指令
由于本人英语“好的”不行
所以去贴吧里找了些教程
---------------------------------------------------------
/rec第一人称摄影·

/rec shortcut
第一人称摄影 快捷键
Video FPS
好像是录像FPS限制……？
Video speed
拍摄速度,和14楼的一样但是 那个调的是第三人称，这个调的玩家【第一人称】

Codec
编解码器[感谢google]
H264
高压缩，高系统使用，更低FPS,能存为mp4
下面两个不支持微软自带的播放器
FFV1
全部中等……
FFVHUFF
CAUTION!!!大容量！20秒1GB 但是压缩小，比起其他的顺畅
简单使用教程

先吧设置 设置好← ←

然后就是设置点了
在一个地方按 P 就可以设置点
在一些地方设置点过后， 按 /cam 快速拍摄看是不是你要的路径
【记得要开Cam third person ← ← 】
然后 /cam start Xm Xm 是录制的持续时间 X 是你要改的设置，比如说要录一分钟 就是
/cam start 1m

如果不满意的话 就/cam clear
/cam clear 会中断摄影所以要注意

/cam pause 暂停~
/cam resume继续~
先暂时这样← ←
现在在上传点的视频，在贴吧服拍的叻

指令
[ ] 为可以更改的数值
·点设置
直接按P设置
/cam p 设置玩家站的地方为点

/cam p[数字] 设置玩家站的地方为[数字]点，

比如说
我输入/cam p123456789 我站的地方会变p123456789

这个也可以用来取代 已经存在的点

我设置了 p1 p2 p3 但是对P2的位置 不满意
我换另一个地方站着 输入 /cam p2
我现在站的地方会取代旧的 p2

/cam undo p[数字]
undo 还原刚才的设置
我觉得新的p2没有旧的好，输入 /cam undo p2 就可以回复了

/cam goto p[数字]
马上移动到 p[数字]点上，
注意是移动不是传送！
玩家在的位置和点之间不能有方块【← ←防作弊】

/cam target
设置玩家所在的位置为中心点
额，意思是录像的时候全程看着这个 所谓的中心点
不管你设 点的时候 看哪里都一样

/cam target undo
……

/cam orient [on|off|target]
……这是录像的时候看的方向的设置
/cam orient on 的话
是用在设 P 点 的时候看的方向
/cam orient off
自由移动视角
/cam orient target
和/cam target 同一个功能
/cam l [pａ][pｂ]
/cam l 是在两点之间会直线移动，不会自动转圈的

/cam l p1 p2
开始录制的时候就会走直线了

然后还有一个自定义转向的……很多生词我翻不到

·日夜时间设置
/et
查看这个设置的状态

/et on
打开日夜时间控制
/et off
关闭日夜时间控制

/et [时间][时间]
如果说想 早上 30分钟 晚上1分钟就这样设置
/et 30m 1m
记得 /et on 这个才能用！
这个设置在服务器上也能用，但是只有你能看到时间变化，即不会影响服务器的时间

设置的 点，路径，时间什么的
/cam load [被你随便填的存档名]
读取你所设置的 点，路径，时间什么的

/cam list
saves列表

/cam default
把所有 O哦 的设置 还原
