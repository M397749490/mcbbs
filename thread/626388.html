当怪物出生或者被攻击时就会说话，因为是使用AI生成的句子，所以你永远也不知道它会说什么！

要求
这个插件需要安装AI-Core才能正常工作！
描述
这个插件使你在攻击怪物时，他们会产生互动！（想想貌似也是挺奇葩的啊哈这）而且在一个怪物出生时有一定几率示好。。。（什么鬼系列），句子是随机生成的，或者随机抽取text.txt文件里的一句话。
插件可以高度的自定义，如果你想改变AI说出的句子，你可以通过修改AI-Core插件的配置来自定义

如果使用的是AI产生的句子，AI会学习玩家在服务器上所说的话，也可以将AI设置为学习指定支持的网站，这些都可以在AI-Core的配置文件就行配置。

目前AI支持学习的网站：
4chan.org

配置选项

  1. #怪物出生时会说话的几率
  2. something
  3. chance_of_text: 75
  4. #如果设置为true，则是AI来自动选配句子，如果是false，则只会从texts.txt中抽取。
  5. enable_ai_response: true
  6. #AI产生响应的几率，而不是从text文件里
  7. chance_of_ai_response: 75
  8. #怪物是否会在下一次受到攻击时说一些新的句子。
  9. change_response_on_attack: true
  10. #当受到攻击时怪物会说话的几率，而不是从text文件抽取一个
  11. chance_of_ai_response_attacked: 90
  12. #是否只有受到攻击时才会说话
  13. talk_only_when_attacked: false
  14. #怪物说话的最大的字母长度，设置为-1为取消限制
  15. lenght_of_response: 60
  16. #是否将调试信息发送到命令台
  17. debug: false
复制代码
一些官方的图片吧




安装




1.
把插件扔到plugins文件夹里。

2.

开启服务器，让它生成配置文件。

3.

关闭服务器

4.

按照自己的需求更改配置文件，同时也要修改AI-Core的配置文件。

5.

如果你不想要AI-Core生成句子，那么你就要给text.txt添加你想要怪说的句子。

6.

现在可以把服务器开了，你就会发现怪物会说话了！




未来的计划

  • 文字过滤。
  • 可以自定义哪些怪物可以说话，哪些不可以。
  • 支持1.8/1.9的服务器。
  • 在选项中可以选用holograms

权限/命令

talkingmobs.admin - 给予使用以下命令的权限

      /talkingmobs reload - 重载配置文件
