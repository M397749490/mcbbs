四、GroupMangerX设置
Q这个插件想必大家都不陌生，接下来我只做一个简单的介绍
0.把它扔进\plugins文件夹，重启/开启服务器
OP（不要在服务器后台输入这些指令）输的指令：
1.创建一个vip组/mangadd  <VIP组名>
2.让这个组继承普通玩家的权限/mangaddi <VIP组名> Builder
3给vip组添加vip特有权限./mangaddp <VIP组名> <权限名>

六、ChestCommands设置
0.把它扔进\plugins文件夹，重启/开启服务器
1.打开\plugins\ChestCommands\menu里的yml文件
2.看我下面的代码吧，跟着设置
######################
#+                  +#
#    VIP菜单设置     #
#+                  +#
######################

menu-settings:

  #菜单的名字（在左上角的）
  name: '&1vip购买菜单'
  # GUI的行数
  rows: 3
  # 打开菜单所要执行的命令
  command: 'vip'
  # 没什么用
  auto-refresh: 5
  # 没什么用，下面这是设置了打开的声音
  open-action: 'sound: note pling'
  # 打开菜单所需的物品
  open-with-item:
    id: '347'      
    right-click: true
    # false是不启用左/右键，true是启用
    left-click: false
   
   
######################
#+                  +#
#        物品        #
#+                  +#
######################

#{player}是变量玩家名称,中括号里的内容是要删去
vip:
#没什么用，随便写，就是一个名称
  COMMAND: 'broadcast:购买vip后发的公告;console[控制台发出的指令]: manuadd {player} <VIP组名>[将购买vip的玩家移动到先前设置的VIP组];console: mansave[保存权限组];give[给予物品]:1[物品ID，英文数字都可]:1[附加值],1[数量];give-money[给予的钱数]: 1'
  NAME: 'VIP'
  #在gui里显示的物品名称
  LORE:
  - '在gui里显示的物品简介'
  ID: 1
  #显示的物品的ID，英文数字都可
  POINTS: 100
  #需要花费的点券数
  POSITION-X: 1
  #X（左右）位置，最大9
  POSITION-Y: 1
  #Y（上下）位置，最大是上面设置的rows
  #我就不用代码了，容易乱码
