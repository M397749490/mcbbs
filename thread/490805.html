前言部分

  一、什么是only one command？

  only one command，顾名思义，只使用一个命令方块和几秒钟的时间就可以创造出一个大型的机械，因为它的性质像在原版上安装模组，所以也叫做“原版模组”。并且这种科技十分方便，广受国外命令爱好者的好评。



  二、如何使用only one command？

  第一步、按T键打开聊天栏，输入/give @p minecraft:command_block来获得命令方块。

  第二步、把命令方块右键放置在一个空旷的地方

  第三步、在游戏外把你准备安装的only one command指令复制好，在游戏内右键命令方块打开，然后按ctrl+v(mac用户按command+v)把命令复制到命令方块里，最后，按下确定按钮，在命令方块的旁边放一个可以输出红石信号的物品（如红石块、红石火把）来激活这个命令方块，安装成功。

    二、高级设置

1.结构(形状)设置



这个工具也有很多实用的设置，我们先从左边的Structure Shape设置看起




设置中提供了三种生成的结构，第一种Boxed会把所有命令方块都塞在一个玻璃盒子里，第二种Horizontal为水平的一条直线，第三种Vertical则为垂直的一条直线。



(以下使用同一个only one command机械进行测试)
第一种，长8格，宽5格，高12格，体积480格，命令长度28357字节

第二种，长57格，宽3格，高1格，体积171格，命令长度28188字节


第三种，长3格，宽1格，高57格，体积171格，命令长度28067字节



相对Y轴设置

就是生成出的机械距离地面的距离有多少格，如果填的是负数，那么机械就会陷在地下，这个很好理解，就不上图了


2.Boxed模式封箱外观选项



这个选项只会在形状设置中选择为Boxed时出现。


Enable casing，如果这个选项不打勾，那么这个机械就不会有外面的箱子，下面的Case main block和Case top/bottom blocks两个选项也会不见。


Enable casing打勾和不打勾的区别



Case main block选项，可以更改机械四周的蓝色玻璃处的方块

Case top/bottom blocks选项，可以更改机械上方和底部蓝色硬化粘土处的方块

更改格式(重要):上图中，stained_glass为这个方块的主要ID，后面的3为数据值，注意两者之间要有一个空格。

如何获取这些值？:在游戏中按下F3+H可以打开(再按一次关闭)显示方块的数据，这时你按E键，把鼠标移动到某一个方块上就可以看到这个方块的主要ID和数据值了。
这个图中，stained_glass为这个方块的主要ID，后面的14为数据值

3.Boxed模式封箱选项

这个选项同样只会在Boxed模式中出现

Limit per row为机械的长度限制，如果调短了，高度自然就会变高，如果调长了，高度就会变低


左边设置为2格，右边为10格


Smart mode,聪明模式，开启后会自动尝试生成最短的命令，如果把这里的勾去掉，上面的Use /blockdata选项就会解锁，如果把Use /blockdata的勾去掉的话，那么就会在生成过程中使用/setblock命令(推荐开启Smart mode)

    三、告示牌设置

点击Add sign可以添加一个告示牌，可以添加无数个(如果你确定你的机械上可以放得下的话)。

1.点击事件(右键这个告示牌后会执行的命令)

由于告示牌上每一行文字只能附加一个点击事件，所以说一个告示牌只能添加4个。里面的命令只要按正常方式输入就可以了，你想要加什么就加什么，你平时怎么用命令就怎么写。

2.文字编辑

    Line 1 2 3 4分别是这个告示牌的第1、2、3、4行，后面的Black为这一行文字的颜色。
Italics,Bold,Underline分别是斜体、粗体、下划线三种效果，可以多选。
3.移除机械和移除告示牌

    勾选左边的Destroy Machine会在这一个告示牌的第四行上附加一个点击事件(把这个机械删除)，所以勾选后这个告示牌的点击事件上限就变成3个了。
    右边的Remove Sign就是把这个告示牌移除。
    四、方块标记(Block Markers)

在一个命令前输入$方块ID$可以让这个命令方块旁边有一个特殊的方块来进行标记。

比如这样，就可以在这个/say I'm different命令方块旁边标记一个青金石块。

   

(大部分键盘输入$都是shift+4)

五、自定义合成

  在框内输入%customcrafting; 原材料1; 原材料2; 合成后的物品; 数量; {物品NBT(可以不填)}  

  举个例子:%customcrafting; grass; stone; diamond_sword; 1; {display:{Name:"Magic Sword"}}  

  把草方块和石头按Q键丢在同一个位置后会出来一个钻石剑，名叫“Magic Sword”。  

  注意，这里的自定义合成不是用工作台合成的，而是把物品丢在同一个位置来合成。并且这个自定义合成只支持2个原材料。


    六、mcedit滤镜(滤镜安装教程点击这里进入冰块菌的帖子)
    已经在游戏内建好了装置，但是不想一个个把命令复制粘贴进去然后再编辑？你可以试一试工具自带的mcedit滤镜。
    下载地址点这里(需要翻墙)在游戏中建好完整的机械，把命令方块分成两类，第一类是只用在安装完成后激活一次的命令(例如计分板创建、tellraw指令等)，第二类是需要高频激活的命令。把第一类的命令方块放在旁边，不用激活。而第二类的命令方块，你就要把它们放在同一个超频上，如果分开的话，可能导致生成后的命令不按照顺序执行。准备工作做完之后，打开mcedit，选中所有命令方块之后点击生成，就会在装置旁边生成一个命令方块。现在关闭mcedit，进入地图存档，把这个命令方块里面的代码复制出来(ctrl+a全选，然后ctrl+c复制)，粘贴到网站里面，并且点击MCEdit Filter按钮，勾选Import via MCEdit，最后点击Generate，完成。现在进入游戏看看你的成果吧
   
    七、only one command分享网页(点我进入)
    在这个网页中，你可以浏览其他玩家分享的机械，也可以自己上传分享给其他人。点击上方recent可以显示最新上传的，点击top可以显示最多好评的。如果你想要使用某个作品，可以点击右边的get the command。如果你想学习某个作品的原理，可以点击“Show source commands”，显示出的就在生成器网页中白框里的命令。
