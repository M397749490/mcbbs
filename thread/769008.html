额。。。那么如何判断末影龙死亡(不用Functuon和非门)

scoreboard objectives add A
高频scoreboard players set B A 1
execute @e[type=EnderDragon] ~ ~ ~ scoreboard players set B A 0
当末影龙死了，就不能把B的分数变成0了
B换成一个实体marker的tag的话execute  @e[tag=B] ~ ~ ~ say 1
输出1的时候说明末影龙死了
(但是这样弄得末影龙所在区块不能被卸载)
