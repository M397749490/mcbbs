v1.5_02(服务端)更新说明
Bugs修复:
  • 游戏不再因为进入1.5_01版本的客户端出现的"internal server error"而崩溃
  • 游戏不再因为从工作台拿东西出来而出现"有灰尘的屏幕"
新的Bugs:
  • 当有雪在工作台上的时, 能放方块上去.

v1.5_01更新说明
Bugs修复:
  • 方块现在可以放在雪或者水上.
  • 雨水不再穿过透明的方块.
  • 南瓜材质修复.  之前是反了过来.
新的Bugs:
  • 许多不同的动作能触发"internal server error"而崩溃. 所以现在联机几乎什么都不可以做.
  • 在某些服务器上, 如果方块放在雪上会立即消失而放下的方块会回到自己的背包里. (可能只会发生在雪天)
  • 单机中台阶被雷电击中会烂掉而且变成黑色(需刚放下的).
  • 雨水现在穿透流水.

v1.5更新说明
  • 新增天气系统
  • 新增统计和成就
  • 新物品 (触碰铁轨(跟触碰开关一个道理, 只不过是铁轨的), 动力铁轨, 树木种子, 蜘蛛网).
  • 按下SHIFT+左键 立即从储物箱拿出物品.
  • 新增的树木会掉相应的种子.
  • 游戏优化
  • 梯子制作现在会得到两个梯子而不是原来的一个
  • 如果雷电击中猪, 它会变成僵尸猪
  • 如果雷电击中Creeper(JJ怪), 它会带电而且有更强大的爆炸力.
  • 在选项中的新设置:
    • 能更换界面大小 (小, 普通, 大, 自动).
    • 高级OpenGL.
  • 新* 动力盔甲(像被雷电击中那样).
  • 种子也能给熔炉使用, 燃烧时间跟棍子一样.
  • 物品在水流中流得更快.
  • 如果把猪烧死, 会掉熟了的猪肉.
  • 红石粉现在能放在雪上了.
  • 野狼现在更常见了, 甚至在非森林/森林气候区域.
  • 小麦被水碰到现在会掉落种子和麦子而不是原本的麦子.
  • 空手伤害从半心增加到一心.
Bugs修复:
  • 梯子必须是完整的才能往上爬(以前是梯子,空,梯子可以的), 往下爬还是可以的.
  • 方块边的草符合了当时的气候坏境.
  • 现在你能以以前的速度穿过水流.
  • 狼们更能懂怎么进门. 如果他们卡在门口会退后再试一次.
  • 当使用Smooth Lighting, 雷电击中传送门或者冰块已经修复(之前是有个小三角在方块上).
  • 在联机中, 狼的血量已经与服务器同步. 这样使狼血量低时会低鸣, 而不是一直都会.
  • 红石关闭状态再一次是红色的.
新的Bugs:
  • Creepers可以发出其他怪物的声音.
  • 有时候在雪地气候会下雨.
  • 重复放入可烧熔物品进去熔炉, 这样会算进制作统计.
  • 如果你在单机中完成了第一个成就,成就只会在联机中生效.
  • 如果你关了再开游戏, 成就会有时候会消失. 或许关了再开游戏可以解决这个问题.
  • 一般在生成新的Chunks时, 帧数表显示的是Chunks刷新而不是帧数.
  • 游戏可能会崩溃, 如果触碰铁轨在普通铁轨旁边.
    • 普通铁轨如果放在连接着其他铁轨的触碰铁轨会造成游戏崩溃.
  • 方块不能放在雪地上.
  • 如果你设置了高级OpenGL又设置回去原本的设置, 一个大洞会出现而且能看穿它.
  • 如果在联机中从围栏上跳下会触动"防作弊-飞行", 把你踢了.
  • 雨水能穿过透明的方块和台阶.
  • 当画面设置调到fancy, 破坏带草的泥土方块, 旁边的草会显得比顶上的草暗些.
  • 水流不再会把空矿车推走.
  • 游戏界面: 在小或者普通的界面设置中, 新建世界的输入框不对齐.
  • 有时候你可能无法得到相应的成就, 就算你已经完成了. 到别的世界可以修复此问题.
  • 上锁的箱子再一次能在联机中/存档修改器中得到. 它能放下也能破坏但是不再是愚人节的菜单. 右键箱子过一段时间就会消失.(联机专有?不确定)
  • 在单机中, 当按下成就会回到游戏而不是暂停游戏.
  • 坐着矿车从南进入转弯再从北到西(连接到现在的铁轨)会使游戏崩溃. 可能其他方向也会这样, 不过如果你一样的方向进入转弯但是是从东而来就不会崩溃.(我蘿卜是搞不懂, 估计是实际测试了)
  • 熔炉的燃烧效果可能会过一段时间才会消失.
  • 在使用fast的画质设置, 天气的音效会停止播放.
  • 破坏特别的树种会出现普通的树种, 而不是特别的.
  • 游戏关闭再开游戏会重置你的游戏设置.
