简介：
你有没有想创建一个与您的朋友的家族？好吧，让我告诉你这个惊人的插件。
这个插件，您可以创建和用鼠标点击管理自己的家族。
它是如此的简单。


特点：
工会人员之间不能PVP（默认是不能的，但是会长输入/clan pvp就可以开启）
可以设置工会基地
有工会商店
可以跟工会的所有人说悄悄话（便利了会长啊，比如会长发任务什么的时候可以用用，工会成员也是可以用滴）

指令：

命令 可以使用此命令的人 描述
/clan disband 工会会长踢工会的人
/clan demote 工会会长把一个工会管理员炒鱿鱼
/clan promote 工会会长设置一个工会管理员
/clan sethome 工会会长设置工会的基地=-=
/clan setmotd 工会会长设置工会的描述
/clan pvp <on/off> 工会会长 开启/关闭工会人员的PVP伤害
/clan kick 工会会长/工会管理 踢一个工会人员
/clan invite 工会会长/工会管理 邀请一个玩家加入工会
/clan shop 工会会长/工会管理 打开工会商店
/clan 所有人 显示指令
/clan create [名字]所有人 创建工会
/clan info 所有人 显示一个工会的信息
/clan home 所有人 回到你的工会基地
/clan list 所有人 显示所有玩家的工会
/clan motd 所有人 显示工会的公告
/clan chat [消息] 所有人 跟工会成员说话
/clan leave 所有人 离开当前工会


权限：

无

  1. http://wiki.ess3.net/wiki/Essentials_Economy

  3. # 设置玩家第一次登录服务器时拥有的金钱,默认为0.
  4. starting-balance: 0

  6. # worth-# 定义物品的价格,用来使玩家输入"/sell"后,以这种价格将物品卖给服务器.
  7. # 现在该项设置的文件是worth.yml

  9. # 定义玩家每次使用命令时所要花的钱,空格由"-"代替,带有"example"的是例子.
  10. #一些命令例如/repair拥有独立的花费,可以在essentials wiki查看更多信息
  11. command-costs:
  12.   # /example costs $1000 PER USE
  13.   #example: 1000
  14.   # /kit tools costs $1500 PER USE
  15.   #kit-tools: 1500

  17. # 设置该项为一个你想使用的货币符号(译注:货币符号(双字节)有"￥"、"＄"、"￠"和"￡"等).
  18. currency-symbol: '
