好久不见大家,上次发布原创插件到现在的时间有...8个月多了![时间真是把杀猪刀] 不过,你也许会想,为何我现在才发新插件.
其实,这插件是用来纪念我入坑Minecraft游戏二周年..[论坛账号注册时间就是我入Minecraft的时间,2年我还是个minecraft小白] 它真的给我带来了很多有趣的东西, 而我也要回报它~回报论坛!
- -于是 特意花了点时间写了这款插件——FightPower 战斗力系统,希望你能喜欢~
至于为啥写这个,因为我看论坛貌似没啥这类的插件...所以才这样写的~

此插件可以做到:

通过击杀玩家增加战斗力,通过lore增加玩家的战斗力,通过吃战斗力果实提高玩家的战斗力,通过杀怪提高玩家的战斗力,战斗力可以每日签到拿到相应       的金钱奖励~,还可以查询自己/他人的战斗力~ 还可以进出服显示玩家的战斗力排名!   最后！还有战斗力提高玩家的伤害力和防御力！
至于这些功能搭配,就看你服啦~我已经给了你们很大的自定义空间~编辑的时候记得用Notepad噢!

命令:

    可以选择的命令的开头/fp  /fight  /fightpower  /zdl  /fpzdl (下面以fp为例 其实可以把fp换成我左边说的命令开头,一样可以用到命令!)
    /fp         -        召唤下面的命令的菜单!   权限: 默认给玩家使用 如果不想这样 就打开插件的jar,找到FightPower.use 的default:  true 改为 default: false
    /fp view       -       查询个人战斗力          权限:    FightPower.view
    /fp reward   -       领取每日战斗力奖励   权限:    FightPower.reward
    /fp count    -       战斗力计算方法           权限:    无
    /fp  listtop   -       列出全服战斗力排名         权限:    FightPower.listtop
    /fp mege     -       获取自己战斗力查询棒     权限:    FightPower.meget
    /fp otherget   -    获取他人战斗力查询棒     权限:    FightPower.otherget
    /fp about      -     关于作者                          权限:     无
    /fp reload      -     重载战斗力插件配置        权限:     FightPower.reload
                               吃战斗力果实                  权限:      FightPower.EatFpFruit
插件配置:

  1. # 颜色代码请使用§ true == 开 false == 关

  3. #是否开启击杀玩家增减战斗力
  4. KillPlayerControl: true
  5. #击杀玩家后杀人者的提示信息
  6. increase: "您的战斗力增加"
  7. #击杀玩家后死亡者的提示信息
  8. decrease: "您的战斗力减少"
  9. # 杀人增加战斗力数值多少
  10. increaseAmount: 1
  11. # 被人杀减少战斗力数值多少
  12. decreaseAmount: 1
  13. # 是否开关战斗力称号系统[开了的话,会自动给玩家上称号,不开的话只能用view来看他的称号~]
  14. Prefix: false
  15. #是否开启Fp果
  16. FpFruitControl: true
  17. #Fp果[战斗力果实]吃下去后增加战斗力的几率
  18. FpFruit: 50
  19. #Fp果[战斗力果实]的增加战斗力数值
  20. FpFruitMath: 1
  21. #是否开启击杀怪物增加战斗力
  22. MonsterControl: true
  23. #击杀怪物增加战斗力数值多少
  24. AddMonsterAmount: 2
  25. #击杀怪物是否提示增加战斗力信息
  26. Monster: true
  27. #ListTop命令的排名列的数值
  28. ListTopAmount: 10
  29. #进服公告玩家与他的排名
  30. JoinMessage: true
  31. #退服公告玩家与他的排名
  32. QuitMessage: true

  34. #战斗力增强伤害
  35. #[方法:战斗力/数值 就是要增加的伤害,现在是10,若个人战斗力是50,那么就是50/10=5 增加个人输出5伤害!]
  36. FpAddDamage: 10
  37. #战斗力增强伤害开关
  38. FpAddDamageControl: true

  40. #战斗力增强防御力[受到攻击的伤害]
  41. #[方法:战斗力/数值 就是要增加的防御力,现在是10,若个人战斗力是50,那么就是50/10=5 增加个人防御5点伤害!]
  42. #当怪物打你10血的时候,你只扣5血!
  43. FpAddDefense: 10
  44. #战斗力增强防御力开关
  45. FpAddDefenseControl: true
  46. #你可以按下面的顺序与格式来增加你的战斗力多少可以兑换的称号
  47. score:
  48.     # 需要战斗力
  49.     '200':
  50.         称号: "§b狂热之神"
  51.         每日奖励金钱: 118.35
  52.     '5000':
  53.         称号: "§b战斗之王"
  54.         每日奖励金钱: 2006.74

  56.         称号: "§b[神]战斗之王"

插件的用法:

1.首先,下载了本插件,你还需要有[Vault]此插件~
没有的话请去此贴下载:http://www.mcbbs.net/thread-78310-1-1.html

2.很好,之后把此插件与Vault都丢进服务器里的Plugins文件夹,之后重启服务器!
3.若你想使用lore增加战斗力,那么请用Rpgitem,或则别的Lore增加插件给装备增加条lore—— 战斗力: 你要增加的数值 [注意冒号后面有空格!到时候也要输,要增加的数值随便你,例如我要增加10000点战斗力,那么我以rpgitem为例]
