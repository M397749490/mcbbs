作者: a2605393469    时间: 2016-2-5 01:34

有一种办法就是圈地之后PVP权限是直接开启的不是关闭的，打开领地配置文件config。
找到下面
    ResidenceDefault:
        build: false
        use: false
        container: false
        pvp: false         #<<<一一此处改成true
        tnt: false
        creeper: false
        flow: false
        piston: false
        ignite: false
        firespread: false
以后你服务器所有人圈地之后，领地就是默认开启PVP权限，想关系就需要手动关闭
作者: Q撒啥玩    时间: 2016-2-5 09:39
在领地输入 /res set pvp t

如果你的领地开了无视伤害的话 先取消无视伤害/resadmin set damage t
然后再输入/res set pvp t
