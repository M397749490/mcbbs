你的红石创作感到无聊吗？或者你只是想知道它在你的Minecraft世界中有什么神奇的作用？
Sensor Craft 为您解决了这些问题！
Sensor Craft  将一大堆传感器添加到您的Minecraft世界中......
传感器正在等着你...
这个mod应该是兼容多人的......如果没有，请发表评论。
注意：你需要Minecraft Forge！


  • 基础核心

    • 该  基础核心  用于各种传感器。



  • 末影核心

    • 在  末影核心  用于各种传感器。



  • 钻石核心

    • 该  钻石核心  用于各种传感器。



  • 风扇

    • 该  风扇  用于各种传感器。



  • 焦点

    • 使用  焦点  来确定传感器激活端。
    • 插槽中的焦点数量会影响传感器的性能。



  • 负面的焦点

    • 使用  负对焦 来确定负的传感器坐标。
    • 插槽中的负面焦点量会影响传感器的性能。



  • 过滤器焦点

    • 使用  滤波器焦点 来确定传感器过滤。
    • 插槽中过滤器焦点的数量会影响传感器的性能。

方块（传感器）

  • 方块接触传感器

    • 如果 方块接触传感器的至少一个对焦有方块，则方块传感器发出信号。



  • 方块块过滤器接触传感器

    • 该 方块过滤器接触式传感器发出信号，可以过滤出不能激活此机器的方块。

   


  • 雨量传感器

    • 雨量传感器 发出信号需要你的Minecraft世界正在下雨。
    • 传感器需要露天才能正常工作。



  • 天气传感器

    • 天气传感器 发出信号需要设置相对应的天气。
    • 传感器需要露天才能正常工作。



  • 无线方块块传感器

    • 如果  传感器的聚焦点存在块，无线方块块传感器将 发出信号。
    • 一个插槽最多可容纳16个核心。



  • 无线方块过滤器传感器

    • 同上，只不过可以过滤
    • 一个插槽最多可容纳16个核心。



  • 无线功率传感器

    • 可以间接传感。
    • 一个插槽最多可容纳16个核心。



  • 无线电源滤波传感器

    • 同上，可以过滤。
    • 一个插槽最多可容纳16个核心。



  • 协调方块块传感器

    • 该  协调封闭传感器  发出信号需要在焦点坐标有方块。
    • 一个插槽最多可容纳16个核心。
    • 一个插槽最多可容纳16个负焦点。



  • 协调式块状滤波器传感器

    • 同上。可过滤。
    • 一个插槽最多可容纳16个核心。
    • 一个插槽最多可容纳16个负焦点。

集成电路方块，本质上是将红石电路隐藏在一个看不到的地方执行，将输入输出远程传输。
1x1x1，每一个面都可以放焦点，放焦点是输入，放负焦点输出。
多个集成电路方块摆放在一起即视为同一大型集成电路，大型集成电路共用电路和输入输出。只有空的集成电路方块（没有电路）可以组成大型集成电路，大型集成电路其中任意方块移动将导致整个大型集成电路擦除电路（变为空的集成电路方块）。
单独集成电路可移动并不改变电路。
放焦点的面可以更改颜色（放入不同羊毛和粘土？），对应不同输入及输出（输入羊毛，输出粘土），羊毛和粘土有多少颜色输入输出就可以有多少颜色，输入和输出颜色独立。
通过合成“电路建模器”（玻璃+焦点+玻璃 焦点+红石块+焦点 铁锭+负焦点+铁锭）来点击电路的x1y1z1,x2y2z2两个点定位整个电路（电路中不同颜色的羊毛和粘土对应集成电路的输入输出）（定位后可以取消定位或刻录，定位时电路所处空间锁定不可做任何更改），定位电路后可刻录到集成电路方块，原电路的材料将永久“刻入”集成电路方块不可撤回（表现为定位为电路的方块全部消失），除非集成电路方块被擦除电路，否则将永远保持。

集成电路擦除器，顾名思义，被红石激活后擦除指向方的集成电路。可移动。
