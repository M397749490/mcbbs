注:此mod根据BBC电视剧"Doctor Who"(神秘博士 1963年-至今)制作 了解更多剧情后再使用此mod效果更佳


基础剧情
此mod中的故事是围绕一个名为“博士”（Doctor）的时间领主展开,他用他伪装成50年代英国警亭的时间机器Tardis（Time And Relative Dimension(s) In Space，时间和空间相对维度的缩写）在时间、空间中旅行的冒险。他与其搭档（companion）在时间、空间中探索悠游、惩恶扬善、拯救文明、帮助弱小。{以上是从百度百科复制的}
现在回到Dalek,这是最强大的反派种族之一,总之就是在游戏中会攻击你。{可能有一些不会}

生物
现在开始正式介绍模组
此mod包含23种生物 帖内只介绍在主世界常见的 生物攻击时会发出音效
1.Ice Warrior(冰の战士)不会主动攻击 攻击力:0.5~1.5颗心
     2.Snowman(雪人)貌似无攻击性                              
3.80s Dalek一开始只会威胁性的歪着攻击(射) 然后才会攻击你{猜测} 攻击力巨大没事别惹他

物品

贴内只介绍比较常用的 此部分1~2在创造模式Godgets分页下 其余的在交通工具(放矿车)标签下
1.Nitro -9类似于TNT的物品 需要放在地上后再右击才会爆炸
2.Time Vortex Manipulator 这个可以把你传送到另一种风格的世界
这个世界是一望无际的平原 会正常生产动物 还有人(请注意看图的远处)
3.Tardis Command Block A 顾名思义 伪装成50年代英国警亭的命令方块 与下面的相同 但是没有控制室
4.Tardis - 9/10th 这就是基础剧情中提到的伪装成50年代英国警亭的时间机器
右击它 就可以进入控制室(?)了 为了增加神秘感 Mod作者设定它有时会闪烁并会发出音效
5.Tardis 与Tardis - 9/10th外表大致相同 但控制室不相同(这是根据电视剧设计的)
6.The Tardis 与上面两个一样 就是不会闪烁 控制室同样不相同
7.Spawn Bessie 汽车

穿越时空
你需要先进入任意一个时空机器的控制室 然后找到一个上面会显示时间的控制台
接着右击它 接着在游戏窗口左下方会出现 Tardis set for (Skaro/Trenzalore/Gallifrey/Overworld)
表明你选择了哪个传送目的地(Overworld指原来的世界)
决定目的地后 在控制室内找到
然后右击任意一处 接着你就会被传送到指定时空了
