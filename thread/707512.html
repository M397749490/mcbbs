插件介绍
本插件允许让玩家使用多种方式表达自己的感情！例如头顶出现表情头颅，粒子效果，声音效果，头顶全息字效果，聊天消息，Actionbar消息，你可以让玩家使用GUI来选择属于自己的表情，玩家既可以自己使用也可以对其他玩家使用表情，且必须拥有相应权限才可以使用每个表情！你甚至可以制作专属于你的表情！



安装与使用
下载本插件，扔进plugins文件夹，重启服务器
如果想在使用表情时显示Actionbar消息，请安装ActionBarAPI 不安装也行

指令&权限&玩家使用方法
基础指令

/emotes 插件帮助
/em  打开玩家表情选择GUI菜单
/emotes ignore  让自己无视（看不到）其他玩家的表情
/emotes list  列出自己可用的表情
/emotes reload  插件重载

权限

仅列出建议给玩家的权限

emotes.hear   可以看到其他玩家做表情的权限
emotes.ignore   无视其他玩家表情的权限
emotes.menu   打开表情GUI菜单的权限
emotes.list   列出自己可用表情的权限

emotes.use.<表情名>  使用每个表情的权限

默认自带的<表情名>即上列快捷指令的指令名，例如applaud
想让玩家使用全部表情，则给权限emotes.use.*

编辑表情&配置文件[已过时]
注意：该教程仅适合1.x版本插件

你可以自由地为插件自带的表情修改面部头颅显示，粒子特效等


【给表情添加/修改面部头颅】

本插件自带了十余种表情，但默认不是每种表情都有面部头颅变化，你可以在faces.yml给表情加面部头颅
面部头颅名称参上方效果图中“各种面部表情”和“动态面部表情”的英文名称，格式如下
表情: 头颅名称

  1. default: none
  2. smile: smile
  3. wink: anim_wink
  4. laugh: scared
  5. dance: dragon
  6. flirt: anim_heart
复制代码


【给表情添加/修改粒子效果】

你可以在配置文件的particles.yml中给表情添加粒子效果，格式如下
  1. bow:
  2.   style: halo
复制代码
style部分即粒子效果名称 更多粒子效果名称请参帖子上方效果图中的“粒子特效”

【把表情添加进GUI菜单】


前文说过玩家可以使用/em打开表情选择GUI菜单，你可以在配置文件的GUI.yml中增删表情
  1.   poke:
  2.     name: "&a戳!"
  3.     lore: ## 物品的lore
  4.       - "&e点我"
  5.       - "&e戳一下别人!"
  6.     ## 按钮的物品种类，请不要添加子ID
  7.     item-id: "stick"
  8.     ## 子ID应该添加到这里
  9.     data: 0
  10.     ## GUI 里物品的数量 (1-64)
  11.     amount: 1
  12.     ## 这个表情是系统自带的表情吗，如果是请设置为false
  13.     custom: false
复制代码

【自己创建表情】
插件自带的那几个表情太没劲？想自己创建表情，你可以在custom.yml中自己创建表情，自己创建的表情也是可以添加头颅、粒子、悬浮字、声音的！还可以加入GUI菜单！

  1.   billy:
  2.     # 使用此表情需要的权限
  3.     permission: "emote.custom.billy"
  4.     # 自己使用此表情出现的提示语
  5.     self: "&3%player% &3正在哲学摔跤!"
  6.     # 对他人使用此表情出现的提示语
  7.     other: "&3%player% &3和 %target%&3 正在哲学摔跤!"   
复制代码
