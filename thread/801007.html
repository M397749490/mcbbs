  1.    #创建地狱世界，如果这个选项为false，那么这个地狱世界将不会被创建和访问。
  2.    #注意！如果没有地狱世界，一些挑战是不可能完成的。
  3.    #玩家们通过地狱门出现在地狱世界的模板上，返回地狱门也出现在他们各自的岛屿上
  4.    createnether: true

  6.    #设置为true空岛地狱将会有空岛风格 如果是false的话将生成默认风格的地狱
  7.    newnether: true
  8.    #是否让地狱里长出的树将会是地狱风格（沙砾和萤石）
  9.    nethertrees: true  
  10.    #是否让船在地狱里也将会是地狱风格，如果会卡等问题的话就设置true
  11.    netherroof: true
  12.    #空岛刷怪处的保护半径，只适用于标准的地狱
  13.    #最小值为零。（不推荐），最大值为100，默认值为25。
  14.    netherspawnradius: 25
