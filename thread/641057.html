tl;dr你需要在自定义模型里把这个 element 的 shade 设置成 false

Detailed
首先我强烈建议你去看一下那个模型教程，如果看了很好我们继续，如果没看，god bless you。

首先，我们先在 assets\minecraft\models\block 里创建一个文件叫做 no-shade.json。文件内容如下：

  1. {  
  2.   "parent":"block/block",
  3.   "textures": {
  4.     "particle": "#particle"
  5.   },
  6.   "elements":[  
  7.     {  
  8.       "from":[  
  9.         0,
  10.         0,
  11.         0
  12.       ],
  13.       "to":[  
  14.         16,
  15.         16,
  16.         16
  17.       ],
  18.       "shade":false,
  19.       "faces":{  
  20.         "up":{  
  21.           "texture":"#up",
  22.           "cullface":"up"
  23.         },
  24.         "down":{  
  25.           "texture":"#down",
  26.           "cullface":"down"
  27.         },
  28.         "west":{  
  29.           "texture":"#west",
  30.           "cullface":"west"
  31.         },
  32.         "east":{  
  33.           "texture":"#east",
  34.           "cullface":"east"
  35.         },
  36.         "north":{  
  37.           "texture":"#north",
  38.           "cullface":"north"
  39.         },
  40.         "south":{  
  41.           "texture":"#south",
  42.           "cullface":"south"
  43.         }
  44.       }
  45.     }
  46.   ]
  47. }
复制代码


大致意思就是说创建了一个继承自 block 的模型，使用 #particle 作为粒子，使用 #up - #south 作为各个面的材质，然后最重要的，禁用了 shade。

这个写完了是第一步，这个相当于是一个前置，本身不实现任何功能，但是你会需要他。然后你需要给每一个你不希望有阴影的方块设置一个模型，具体设置方式就是在 assets\minecraft\models\block 里创建名字是 方块名 + .json 的文件。比如 cobblestone.json。对于每一个创建的文件，打开，填写以下信息。

  1. {
  2.   "parent": "block/no-shade",
  3.   "textures": {
  4.     "particle": "<通往粒子效果的路径>"
  5.     "up": "<通往顶部材质的路径>",
  6.     "down": "<通往底部材质的路径>",
  7.     "west": "<通往西部材质的路径>",
  8.     "east": "<通往东部材质的路径>",
  9.     "north": "<通往北部材质的路径>",
  10.     "south": "<通往南部材质的路径>"
  11.   }
  12. }
复制代码


这一步的大概意思就是说调用了刚刚创建的那个 no-shade.json，然后把7个参数（粒子 + 6个面）传递进那个 no-shade.json 模型。因为这个方块没有任何附加元素，所以所有的元素都来自 no-shade.json 的那个没有 shade 的方块，因此你为这个方块创建的模型也会没有纹理。

如果实在无法理解，你可以下载我的一张叫做 Black and White 的地图，里面的 red_wool 和 yellow_wool 就用到了这个技巧。

补充一下，粒子效果就是一张图片（比如石头的粒子效果就是他本身的材质）。也就是说提供的7个参数都应该指向图片。这个路径是根据 assets\minecraft 开始算的。也就是说一个材质如果位于 assets\minecraft\block\666cyq.png，那么你在模型里面就需要填写 block/666cyq。
（我不确定是否强制正斜杠，但是我是用正斜杠而且有效，linux 也是正斜杠，但是 windows 默认复制出来的地址是反斜杠，这个需要注意。）
