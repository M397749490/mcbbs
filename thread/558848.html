# ColorMOTD Config
# -----------------------
# OnlineMsg即为个性化的在线人数显示。不支持换行。此项在showDelay打开后失效
OnlineMsg: "      &6&l时光总是让人触摸不到      &a&l在线人数: &6&l[&b%ONLINE%&b/&b%MAXPLAYER%&6&l]"

# Motd即为服务器显示的MOTD信息。\n来换行，只支持2行。
Motd:
- "           &6&l[&a&l欢&e&l迎&d&l来&6&l到&b&lXXX&4&l服&2&l务&c&l器&l]\n&6&l[&b&l新服开荒神秘拔刀RPG配置中&6&l]&6&l[&b&lQQ群：XXXXXXX&d&6&l]"

# Players为上图中，鼠标移动到OnlineMsg上显示的信息。列表中每项为1行，注意格式
Players:
- '&2============================='
- '&a  欢&e迎&d来&6到&bXXXX&4服&2务&c器'
- '&d  服务器公告: &e新服开荒中~~'
- '&b  在线人数: &6%ONLINE%'
- '&2============================='
- '&4/\  &6新  &4/\'
- '&4/\  &6年  &4/\'
- '&4/\  &6快  &4/\'
- '&4/\  &6乐  &4/\'
- '&2============================='

# 这个是开启维护模式时的MOTD
ServiceModeMOTD: '&c服务器维护中,请等待维护完成...'
# 这个是开启维护模式后，普通玩家进服被阻止的提示信息
