插件名
BeeHivesTrees

作者
esmorall

兼容版本
1.15

介绍 · Introduction
如果你正在开1.15的服务器并且你想要你的玩家与蜜蜂亲“蜜”接触,那么这款插件就很适合你！
这款插件可以让玩家种的树有几率长出蜂巢。

配置 · Configuration
  1. #几率范围为 0.0 - 1.0， 1 = 100%
  2. chance-to-have-a-bee-nest: 0.05

  4. #每个蜂巢里有几只蜜蜂
  5. bees-per-nest: 2

  7. #是否会在所有生物群系内生成蜂巢？
  8. allow-all-biomes: false

  10. #生物群系名称请查看： https://hub.spigotmc.org/javadocs/spigot/org/bukkit/block/Biome.html
  11. allowed-biomes:
  12.   - FOREST
  13.   - PLAINS
  14.   - FLOWER_FOREST
  15.   - SUNFLOWER_PLAINS
  16.   - BIRCH_FOREST
  17.   - BIRCH_FOREST_HILLS
  18.   - TALL_BIRCH_FOREST
  19.   - TALL_BIRCH_HILLS

  21. #是否所有类型的树都能种出蜂巢？
  22. allow-all-tree-types: false

  24. #树名请查看 https://hub.spigotmc.org/javadocs/spigot/org/bukkit/TreeType.html
  25. allowed-tree-types:
  26.   - TREE
  27.   - BIG_TREE
  28.   - BIRCH
  29.   - TALL_BIRCH
