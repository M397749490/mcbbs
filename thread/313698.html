随时随地的食物

这个插件能让玩家随时随地用一个指令

得到一个红红的苹果

是不是很贴心啊

你是我的~小丫~小苹果~

指令:
  • /apple - 给你苹果
以下的指令都需要apple.admin的权限才能执行
  • /apple set <#> - 改变获得苹果的冷却时间
  • /apple set <player> <#> - 改变指定玩家的获得苹果的冷却时间
  • /apple remove <player> - 删除对指定玩家获得苹果的冷却时间的限制
  • /apple warn <on/off> - 开启或关闭玩家第二次获得苹果时的警告
