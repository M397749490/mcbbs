插件介绍
这个插件可以驯服任何怪物
不管是中立、敌对、友好的生物都能驯服
是一个轻量级的插件~


这个插件能干什么？
能配置用于驯服的物品
兼容mcMMO的驯服XP
可以用鞍骑宠物
可以命名你的宠物
可用随机名称
支持彩色标签
完全权限的支持
Optional ops override permissions.（不懂求大神翻译）
宠物跟随
改变羊的颜色
改变狼项圈的颜色

宠物模式
友好（friendly） → 不会攻击，即使自己被攻击
普通(normal) → 像普通狼一样
好战（aggressive） → 攻击玩家15格范围内所有的生物
打野（farm） → 攻击玩家15格范围内所有的怪物
突击（raid） → 如同普通模式，但宠物 不会攻击玩家和其他宠物

如何安装
将插件丢进你的plugins文件再重启服务器
如果你不想使用权限请修改“OpsBypassPerms: true”和“DisablePermissions: true”

指令列表
当你要召唤宠物的时候只要输入/pet 1宠物就会瞬移到你身边
/petlist - 查看你的宠物列表
/pet [id|all] - 瞬移你的宠物
/petcolor [id] [ color ] - 给你的狼/羊换上颜色
/petfree [id|all] -取消跟随
/petname [id] [name|random] - 给宠物取名字
/petgive [id] [player] - 把[id]送给[player]
/petkill [id|all] - 放生宠物
/petmode [id] [a|d|p] - 改变宠物模式
/petage [id] [baby|adult|lock|unlock] - 改变宠物的大小
/petreload - 重载插件
/petspawn [ pet type ] [count]
