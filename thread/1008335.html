今日知识

  • 八种数据类型当中除布尔类型之外剩下的七种类型之间都可以互相转换

  • 小容量向大容量转换，称为自动类型转换，容量从小到大排序：
    byte < short < int < long < float < double
           char  <
    注：
    任何浮点类型不管占用多少个字节，都比整数型容量大
    char和short可表示的种类数量相同，但是char可以取更大的正整数

  • 大容量转换成小容量，叫做强制类型转换，需要加强值类型转换符，程序才能编译通过
但是在运行阶段可能会损失精度，所以谨慎使用。

  • 当整数字面值没有超出byte,short,char的取值范围，可以直接赋值给byte,short,char
类型的变量。
  • byte,short,char混合运算的时候，各自先转换成int类型再做运算。

  • 多种数据类型混合运算，先转换成容量最大的那种类型再做运算。
    注意：

    byte b = 3; 可以编译通过，3没有超出byte类型取值范围

    int i = 10;
     byte b = i / 3; 编译报错，编译器只检查语法，不会"运算" i / 3

例题（较长/谨慎打开）
  1. //出现错误，1000超出了byte的范围
  2. //byte a = 1000;
  3. //正确，因为20没有超出byte范围
  4. //所以赋值
  5. byte a = 20;
  6. //变量不能重名
  7. //short a = 1000;
  8. //正确,因为数值1000没有超出short类型的范围
  9. //所以赋值正确
  10. short b = 1000;
  11. //正确，因为默认就是int，并且没有超出int范围
  12. int c = 1000;
  13. //正确，可以自动转换
  14. long d = c;
  15. //错误，出现精度丢失问题，大类型-->>小类型会出现问题
  16. //int e = d;
  17. //将long强制转换成int类型
  18. //因为值1000，没有哦超出int范围，所以转换是正确的
  19. int e = (int)d;
  20. //因为java中的运算会转成最大类型
  21. //而10和3默认为int，所以运算后的最大类型也是int
  22. //所以是正确的
  23. int f = 10/3; //3
  24. //声明10位long类型
  25. long g = 10;
  26. //出现错误，多个数值在运算过程中，会转换成容量最大的类型
  27. //以下示例最大的类型为double,而h为int,所以就会出现大类型（long）到小类型（int）
  28. //的转换，将会出现精度丢失的问题
  29. //int h = g/3;
  30. //可以强制转换，因为运算结果没有超出int范围
  31. //int h = (int)g/3;
  32. //可以蚕蛹long类型来接收运算结果
  33. //long h = g/3;
  34. //出现精度损失问题，以下问题主要是优先级的问题
  35. //将g转换成int，然后又将int类型的g转换成byte，最后byte类型的g和3运算，那么
  36. //它的运算结果类型就是int，所以int赋值给byte就出现了精度损失问题
  37. //byte h = (byte)(int)g/3;
  38. //正确
  39. //byte h = (byte)(int)(g/3);
  40. //不能转换，因为运算结果没有超出byte范围
  41. //byte h = (byte)(g/3);
  42. //可以转换，因为运算结果没有超出short范围
  43. //short h = (short)(g/3);
  44. short i = 10;
  45. byte j = 5;
  46. //错误，short和byte运算，首先会转换成int再运算
  47. //所以运算结果为int，int赋值给short就会出现精度丢失问题
  48. //short k = i + j;
  49. //可以将运算结果强制转换成short
  50. //short k = (short)(i + j);
  51. //因为运算结果为int,所以可以采用int类型接收
  52. int k = i + j;
  53. char l = 'a';
  54. System.out.println(l); //a
  55. //输出结果为97,也就是a的ascii值
  56. System.out.println((byte)l); //97
  57. int m = l + 100;
  58. //输出结果为197,取得a的ascii码值，然后与100进行相加运算
  59. System.out.println(m); //197

  61. double dd = 10 / 3;
  62. System.out.println(dd); //3.0

  64. dd = 10.0 / 3;
  65. System.out.println(dd); //3.3333333333333335
