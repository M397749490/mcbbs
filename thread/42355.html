这个插件提供与红石电路的游戏中的时间同步。它可以用于照明，城市或您的店铺。
设置：

permissions, make the usage of permissions true or false.

refresh, how often the server will update the redblock. (In ticks)

save, how often the server will save the redblocks. (In ticks)

updatechecker, activate the update checker. (true or false)

copyitem, the id of the item that is used for copying. (Default 294, Gold hoe)
inative, feature to deactivate the copying if you're afk for a selected time, useful if you're using a block for copying.


权限：

redclock.use -允许玩家使用红石时钟
redclock.admin -玩家可以摧毁别人的红石时钟
redclock.copy -玩家可以复制红石时钟。

指令：

/redclock : 显示插件版本.
/redclock copy : 复制一个红石时钟
/redclock stop : 停止复制.
/redblock, 同/redclock.

如何创建一个红石时钟（英文，自己翻译吧，要不然被说误导）：

How to use : (For version 1.0.8 and higher)
Creating a RedBlock


  • Put a sign on the wall and on the first line, write "redblock", you can write it with caps or not, the plugin don't check the case.
  • On the second line, write the mode of the redblock. (Exemples : "ON", "OFF", "PULSE")
  • On the third line, write the start hour. (Exemples : "1200"ticks,"10AM","11PM","18:20")
  • On the fourth line, write the stop hour. (Exemples : "1200"ticks,"10AM","11PM","18:20")
  • Save the sign and if you correctly did everything, the text will change to something more explicit.
  • The plugin will make a check every two seconds to make sure that the torch is there.
Copying a RedBlock (Video shortly)


  • Write the command "/redclock copy".
  • Take the copying item, default is a Gold Hoe.
  • Right Click on the RedBlock you want to copy with the copying item.
  • Right Click on the block where you want to place a copy of the RedBlock, it should appear as soon the server update RedBlocks.
  • To stop, simply write the command "/redclock stop".
