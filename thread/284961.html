废话
欢迎来到终极怪物地狱。
(??ω`? )呐，你们不觉得原版的游戏难度已经满足不了自己了吗。
把难度开到HARD，怪物再多也是渣，一撸就挂的怪物很无聊的说。
自从有了这个插件之后，我可爱的玩家们就再也不会觉得无聊了。

不说太多废话了，虽然我们每天说的话超过七八成都是废话。
这个插件可以完全控制游戏怪物力量强度、血量、爆炸和特定伤害类型免疫等，甚至是生成率。
很久之前有其他同学转载过这个插件，原转载贴在这里，但这位同学已经弃坑，于是我就来补上吧。把防火防爆关掉口味更佳= =

特点
  • 完美支持worldguard插件
  • 多世界的支持 - 将只在你想的世界上运行！
  • 控制怪物的刷新点
  • 全新的怪物生成系统，彻底改变你的世
  • 可以使天空永远都只会是夜晚，让世界永远堕入黑夜的阴暗之中，永远看不见明天的太阳
  • 使怪物有超强的能力和更厚的HP，极高的速度，更高的AI
  • 更好的事件系统。你说你害怕黑夜，只想躲在你家里面过日子？
  • 每次到了特定的时间都会有一大波僵尸来主动进攻你的家(进攻事件)
  • 你以为你把门口换成铁门就能防得住了吗？僵尸特有的方块破坏者能力，可以破坏你的方块，直接打穿你的墙壁而入，黑夜里进攻你家的僵尸一波接着一波，你能防住几波？
  • 可设定僵尸可破坏的方块类型和需要的时间
  • 骷髅特有的超级射手能力，超远的射程，变身狙击手，将在你看不见的遥远地方准确打击你，甚至能快速连射及射出爆炸箭。你还没看见它，你就已经被击飞。
  • 被僵尸咬了可以使玩家带上减速、中毒等状态，由你来设定
  • 怪物会拆掉你插的火把，它会拆掉它身边3x3x4范围内的所有火把，如果你在黑暗的洞穴里面看见怪物，你就死定了。
  • mega-aggro大型仇恨系统，怪物可以从大老远就发现到你，部分怪物更可以使用冲刺以超快的速度冲向你
  • 动作RPG模式 - 战斗更加激烈、精彩！
  • 甚至可以设定一些怪物无视玩家护甲效果打击玩家
  • 不敢回家，躲在树上？让僵尸们够不着？一些怪物比如僵尸在发现玩家在站很高的地方而它们无法上去时，它们会通过互相攻击致死而变成方块的方式最终搭起人梯来进攻玩家。
  • 还不够过瘾？噩梦模式(Nightmare Mode)最终将迎来越来越大的挑战！

命令与权限

命令
/ma addspawnpoint <name> <creaturetype> <period> <count> <lightmin> <lightmax> <chance>创建一刷新点
/ma removespawnpoint <name>
删除一个刷新点
/ma set<property> <name> <value>
更改刷新点的配置
/ma properties <name>
查看某刷新点的属性
/ma get<property> <name>
查看某刷新点的某项配置属性
/ma listspawnpoints
列出你的所有刷新点

关于噩梦模式

楼主未能理解噩梦模式，但那貌似是一个拥有一定周期的事件，应该叫噩梦事件
据作者原文的介绍提到的服务端重启后噩梦模式生成的Bonus会丢失，那噩梦模式或许是类似怪物攻城那样事件，并且有发生的周期
config中有三项与噩梦模式相关
Nightmare mode multiplier: 1.0              #噩梦模式发生周期的递进倍数(倍)
Nightmare mode period: 1200000        #初次噩梦模式发生周期(毫秒)。
Nightmare mode exponential?: true      #噩梦模式的发生周期是否以倍数递增

Exponential为true，period为15，multiplier为1.1时

数列15, 17, 18, 20, 22
Exponential为false，period为20，multiplier为2.0时
数列20, 40, 60, 80, 100, 120, 140
数列可能是指噩梦模式的发生时间
