介绍
MyWorlds是用于管理多世界的插件。
它允许管理员创造、加载、删除新的世界，以及对新的世界进行设定。
它也可以建立世界之间的传送门，使得玩家可以传送到另一个世界而不用输入传送指令

指令
(1)创造世界
①/world create [worldname]:[generator]:[arguments]
②/world create [worldname]
③/world create world1:BananaSpace:12,grass,wood,dirt -1856378464
④/world create world2 -527332672
⑤/world create world2_nether
⑥/world create world3_skylands
⑦/world create skylandsworld
创造一个世界，你可以建立一个方块生成器[generator]，在冒号后面设定它的参数[arguments]。参数是可选择的，如果不设定的话就会使用随机地图生成器。（如①②③④所示）
如果想创造一个特定环境的世界，你可以添加特定的环境名称在创造的世界名字中。例如：如果名字中有nether，就会出现地狱的环境；同样如果出现the_end字样，就会创造出黑基佬的世界。（如⑤⑥⑦所示）

(2)载入与卸载世界
/world load [worldname]
/world unload [worldname]
使用载入世界指令后，这个世界将在每次服务器重启时被载入。
使用卸载指令后，这个世界在重启后将不会被载入。
加载新世界基本不会增加服务器内存的使用，但是会增加CPU的使用率，因为新的世界有刷新额外的小怪数量。

(3)保存世界
/world save [worldname]
/world save
/world save World1
/world save *
/world save all
上述指令可在自动保存被禁用的情况下手动保存一个世界。或者确保你想永久性地保存对一个世界的变化。
当将[worldname]改为*或者all时，可以保存所有的世界。

(4)自动保存世界
/world saving [state] [worldname]
/world saving [state]
/world saving on World1
/world saving false
/world saving yes
设定是否自动保存世界。如果设定false则玩家对于世界的改变将不会被保存直到手动输入了保存指令。

(5)世界复制和删除
/world delete [worldname]
/world copy [worldname] [newworldname]
永久删除一个未被载入的世界以及复制世界。
这两条指令默认在游戏中禁止使用除非被给予了权限。

(6)修复世界
/world repair [worldname]
尝试修复一个损坏的世界，重新生成level.dat并移除损坏的方块
注意：损坏的方块不能被恢复，而是会由服务器重新生成。

(7)世界信息
/world info [worldname]
/world info
/world info world1
显示一个世界的信息，如种子，时间，天气和属性。

(8)世界列表
/world list
列出所有的世界，包括未载入及损坏的世界。不同世界会以不同颜色显示。

(9)传送门列表
/world portals [worldname]
/world portals
列出一个世界里面所有的传送门。以不同颜色显示，你可以看到不同传送门之间的距离。

(10)方块生成器列表
/world listgenerators


列出所有你可以用来创造世界的方块生成器插件。只有那些会覆盖默认生成器的插件会被显示

(11)设置世界管理员
/world op [playername] [worldname]
/world deop [playername] [worldname]
/world op [playername]
/world deop [playername]
/world op * World1
/world op player1 *
/world deop * *
/world op
设置一个世界的管理员。*可以代表所有玩家或者所有世界。
只有当这项功能在配置文件中被启用时才会生效。

(12)驱逐世界中的玩家
/world evacuate [worldname] [message...]
/world evacuate [worldname]
/world evacuate World1 Your world has been closed!
如果你想关闭一个世界，你可以使用这个指令将这个世界中的玩家驱逐出去。
如果有传送门，玩家将通过传送门传送出去
如果玩家有世界传送及进入指令的权限，他将被随机传送到一个可进入的世界。
如果上述都不符合，玩家将被踢出服务器。
并不受驱逐影响的其他世界中的玩家也会收到这条提示信息



(13)设置重生点
/world setspawn [worldname]
/world setspawn
    设置一个世界的重生点到你的脚下。可以将一个世界的重生点设置到另一个世界。从而使得玩家可以按照一定的方向在不同世界之间轮换

(14)设置默认传送门
/world setdefaultportal [portal] [worldname from]
/world setdefaultportal [worldname to] [worldname from]
/world setdefaultportal World1_nether World1
/world setdefaultportal "" World1
设置一个世界里未被特殊设定的默认传送门的传送方向。
这个可以使玩家传送到一个特定的世界如果未获权限的玩家自己搭建了一个传送门。
也可以使用该指令建立一个指向新的世界的传送门，在新的世界里还没有建立对应的传送门之前。
将目标世界的传送门替换为""可以使得默认传送门无效。

(15)允许和禁止怪物刷新
/world allowspawn [mobname] [worldname]
/world allowspawn [mobname]
/world denyspawn [mobname] [worldname]
/world denyspawn [mobname]
/world denyspawn creeper
/world denyspawn animal world1
允许(allow)和禁止(deny)某种怪物在某个世界的刷新，但是管理员手动刷怪并不被影响。
可以指定任何特定的怪物，也可以使用animal，monster，all，mob等控制指定种类的怪物刷新

(16)时间
/world time [time] [worldname]
/world time [time]
/world time always 12:00
/world time day
/world time night world1
/world time 24:00 locked
设置一个世界的时间
可以使用lock，always，forever锁定一个世界的时间。
可以使用day, night, dawn, morning来设定一个特定的时间。
也可以使用具体的[小时:分钟]来设置具体时间

(17)天气
/world weather [weather] [worldname]
/world weather [weather]
/world weather always rain
/world weather rainy
/world weather endless storm
/world weather always sunny World1
设置一个世界的天气
可以使用lock，always，endless，forever来锁定一个世界的天气。
使用sun可以移除其他天气，rain可以下雨，在rain时输入storm可以下雷雨。

(18)游戏模式
/world gamemode [mode] [worldname]
/world gamemode [mode]
/world gamemode survival
/world gamemode creative world1
/world gamemode none
设定一个世界的游戏模式(survival生存，creative创造)，这个世界里面的所有玩家都将以这个模式进行游戏。
如果使用一个非生存或创造的模式名称，游戏模式将被清除，玩家将以设定前的模式进行游戏。

(19)游戏难度
/world difficulty [difficulty] [worldname]
/world difficulty [difficulty]
/world difficulty peaceful
设定一个世界的难度，难度将影响怪物的刷新速度以及对玩家的伤害。
有效的设定量为： easy, norma', hard and peaceful.

(20)PVP
/world togglepvp [worldname]
/world togglepvp
开启或者关闭一个世界玩家之间的伤害。

(21)重生点传送
/world spawn [worldname]
/world spawn
传送到一个世界的重生点。
也可以使用此命令设置一个世界中的特定传送地名，以及世界之间的传送

(22)保存及载入世界设定
/world config load
/world config save
加载或保存世界配置，从文件worlds.yml中。

(22)传送到一个传送门或者重生点
/tpp [worldname]
/tpp [portalname]
/tpp bergerkiller max mogers World2
/tpp alfa beta Home
/tpp [player1] [player2] [player3] [world/portalname]
/world teleport [worldname]/world tp [worldname]
传送自己以及某一玩家到指定的传送门或者世界重生点。

聊天权限：
下面的指令设置了不同世界中的玩家是否可以与别的世界的玩家交谈。该权限需要先在设定档中激活才会生效。

描述  
权限语句
世界1的玩家是否可以对世界2的玩家说话
myworlds.world.chat.world1.world2   
世界1的玩家可以对任何世界的玩家说话
myworlds.world.chat.world1.*  
任何世界的玩家都可以对世界2的玩家说话
myworlds.world.chat.*.world2  
任何世界的玩家都可以自由的互相说话(默认OP)
myworlds.world.chat.*.*  
玩家在任何世界都可以说话(默认开启)
myworlds.world.chat.*  
玩家可以在世界1说话
myworlds.world.chat.world1  
重要： 上述权限都在玩家拥有在该世界说话权限的基础上才生效。


例如：
myworlds.world.chat.world1.world2
这个权限依然需要在世界1和任何世界说话的以下两个基本权限。
myworlds.world.chat.world1
myworlds.world.chat.*
  • 默认不同世界不能互相聊天。

传送门使用方法：
除了传送指令外，插件自带了穿越世界的最简单的方式：传送门。玩家可以通过(地狱)传送门以及水传送门进入另一个世界。所需要做的事情是在传送门旁边放一个木牌。
建立一个传送门：
  • 可以使用黑曜石建立一个标准的传送门，然后点火激活它。
  • 可以用创造模式放置传送门方块。这个方式也可以建立普通的传送门。
  • 摧毁一个传送门，只需要摧毁最下面的传送门方块。
  • 也可以制作一个水塘，作为传送的水传送门。

制作一个传送木牌：
  • 放一个木牌在传送门旁边
  • 在第一行写上：[portal]
  • 在第二行写上这个传送门的名字：例如：portal1
  • 在第三行写上你想传送到的传送门名字或者世界名字：portal2
  • 在第四行写上你想显示的目的地的名称(可以写第三行的传送门或者世界的名字，至是个说明作用，没有实际功能)




  • 如果使用传送指令到某一传送门，传送门的名字就是第二行所输入的名字
  • 以上紫色的两步可以调换先后顺序
  • 建立两个世界之间的传送门，即需要将两个世界的传送门都以上述方式设定并连接在一起。
  • 也可以用这个方法建立同一世界两地的快速传送门。


担心服务器装了多世界插件会卡，那就看看这个吧

NoSpawnChunks（減少未使用Chunk）插件
NoSpawnChunks有什么用途?
你有发现你的服务器的"The End"和"Nether"或者更多的地图中根本没有玩家或者玩家数量少,而却于服务器中载入大量Chunk造成服务器TPS过低的情况吗?

现今解决办法非常简单: 安装这个插件！这个插件只有一个功能,就是防止Chunk于所有世界都载入到内存中,增加您的服务器流畅

实际上能增加多少效能?
例如当你使用这个插件,你可以运行一个32Mb内存的两人服务器(包括8-10个轻量级插件),并允许同时存在10个以上的世界

插件安装
没有任何需要设置,只需要下载这个插件,拖放到服务器Plugin文件夹,重启服务器。现在插件已经启用,你可以看到内存使用量大量下降。

插件冲突
暂时没发现有冲突，但小心某些插件(Nolagg......)会强制载入Chunk,这样可能会造成互相影响
下载：http://dev.bukkit.org/server-mods/nospawnchunks
