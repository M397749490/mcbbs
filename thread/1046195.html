需要玩家离开才将方块替换掉的话
可以按顺序高频执行这些命令
  1. execute as @a at @s unless block ~ ~-1 ~ minecraft:air positioned ~-0.5 ~-1 ~-0.5 unless entity @e[type=minecraft:area_effect_cloud,tag=air,dx=0,dy=0,dz=0] run summon minecraft:area_effect_cloud ~0.5 ~ ~0.5 {Duration:9999999,Tags:["air"]}
  2. execute as @e[tag=air] at @s positioned ~-0.5 ~1 ~-0.5 unless entity @a[dx=0,dy=0,dz=0] run setblock ~0.5 ~-1 ~0.5 lava destroy
  3. execute as @e[tag=air] at @s positioned ~-0.5 ~1 ~-0.5 unless entity @a[dx=0,dy=0,dz=0] run kill @s
