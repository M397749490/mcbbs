Loot Chest

一款可以制作类似空投或奖励箱的插件



为什么选择Loot Chest?

  • 每个箱子支持自定义特殊效果(全息字体 粒子效果 公告提示 空降特效等等)
  • 可自定义物品在箱子里面生成的几率
  • 游戏内GUI配置
  • 支持范围随机刷新,自定义刷新时间
  • 可直接像kit一样发送给玩家
  • 搬运(汉化)者不会跑路(突然字体莫名其妙的变小了)

插件指令

/lc create <name> 创建宝箱并打开编辑GUI
/lc edit <name>编辑某个宝箱
/lc respawn <name>立刻生成某个宝箱
/lc respawnall 立刻刷新所有的宝箱
/lc remove <name> 移除一个宝箱
/lc setholo <name> <text>设定宝箱上方的浮空字体
/lc setpos 设置宝箱的刷新点(你的位置)
/lc give <player> <name>给玩家某个箱子
/lc settime <name>设置空投(宝箱)刷新时间
/lc randomspawn <name> <radius>设置空投随机刷新范围
/lc tp <name>直接传送到某个宝箱
/lc togglefall <name>开启/关闭宝箱的掉落特效
/lc list 列出宝箱名字
/lc help你觉得这是啥
/lc reload重载所有配置

插件权限
lootchest.<命令名字> - /lc <命令名字>

config.yml

  1. #检查更新
  2. CheckForUpdates: true
  3. #粒子效果设置
  4. Particles:
  5.   #禁用后可无视以下到speed的配置
  6.   enable: true
  7.   default_particle: FLAME
  8.   #同时生成的粒子数量
  9.   number: 10
  10.   #生成后持续的时间
  11.   respawn_ticks: 5
  12.   #生成粒子的范围
  13.   radius: 0.3
  14.   #粒子的散播速度，越低效果越平滑，推荐1以下
  15.   speed: 0.05
  16. #默认重生时间
  17. default_reset_time: 10
  18. #默认物品生成几率
  19. default_item_chance: 100
  20. #是否启用全息字体
  21. UseHologram: true
  22. #玩家拿完东西后是否删除
  23. RemoveEmptyChests: true
  24. #玩家就算没拿完东西 打开箱子后是否删除
  25. RemoveChestAfterFirstOpenning: false
  26. #部分版本不支持全息字体，需手动设置浮空字高度
  27. #支持负数
  28. Hologram_distance_to_chest: 1
  29. #漏斗会导致刷物品 是否禁用漏斗放在空投箱子下方 强烈推荐开启
  30. PreventHopperPlacingUnderLootChest: true
  31. #作者恶搞的行数 无视即可
  32. Enable_fall_effect: true #开启掉落特效
  33. Fall_Effect_Height: 50
  34. Fall_Effect_Block: "NOTE_BLOCK"
  35. Minimum_Number_Of_Players_For_Natural_Spawning: 0
  36. #你可以自定义默认的消息提示
  37. respawn_notify:
  38.   #是否只在空投生成的世界发消息
  39.   per_world_message: false
  40.   #玩家拿走奖励之后是否有提示
  41.   message_on_chest_take: true #默认配置 你可以单独设置每个箱子
  42.   natural_respawn:
  43.     enabled: true #默认配置 你可以开启或关闭每个箱子的配置
