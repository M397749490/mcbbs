首先就是机器的问题了，机器我个人推荐各位选择阿里云-轻量应用服务器-香港-34元套餐

为什么选择阿里云的这个服务器呢

而且linux系统占用资源少鸭，对于经常破费的服主很是友好[至少能省资源]

登录好后干什么？

登录好后很简单，直接输入指令


升级所有能升级的东西


  1. sudo apt-get update -y
复制代码


安装java


  1. sudo apt-get install -y openjdk-你想要的java版本-jre
复制代码



安装screen【用来防止你退出的时候服务器进程关闭的】


  1. sudo apt-get install -y screen
复制代码




然后我们要开始放上我们在本地做好的服务端了--打开xftp

百度xftp，然后安装，安装好跟xsell前面一样配置
但是，协议选择sftp，然后就跟前面一样配置【端口22】


开始传服务端~

左边找到你服务端的目录【记住，服务端最好是文件夹形式，不要是压缩形式最好】
右边打开home/你的用户/

然后把左边的文件夹拖到右边

等待完成-----





准备开服~

返回到xshell
然后输入

  1. screen -s 你要的进程名
复制代码

然后cd /home/你的用户/服务端核心目录下

然后就是见证奇迹的时候到了

  1. java -Xincgc -Xmx你需要的内存大小【单位G】G -jar 你服务端核心的文件名.jar
复制代码
然后就等待它启动吧




ps：很多人可能会问我为什么不用sh xxx.sh或者./xxx.sh，因为有些小白不懂设置啊




注意：

服务器插件如果有中文则此插件不会被加载

若编码不对会产生乱码

退出后想重新进入管理界面输入
  1. screen -r 前面输入的进程名
复制代码
