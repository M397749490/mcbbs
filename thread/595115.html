本帖最后由 1582952890 于 2017-9-16 20:05 编辑


一个轻量级插件，让你的服务器怪物掉钱方式更具RPG特色~.

前置:

Java 7+
Spigot 1.8+
Vault
MythicMobs（可以不加到服务器上，后期会增加配置教程）

  • 指令:
  • /pickupmoney, /pmoney, /pum
  • /pickupmoney reload -重载配置
  • /pickupmoney drop 数量 -掉落指定数量的金币
  • 权限:
  • PickupMoney.pickup   - 必须给玩家这个权限玩家才能捡起金币
    PickupMoney.multiply.drop.* -允许玩家掉落金币
    PickupMoney.multiply.pickup.* -允许玩家捡起其他玩家掉落的金币
  • 游戏截图
