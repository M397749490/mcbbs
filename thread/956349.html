一、简介
此插件为BungeeCord插件（未来可能兼容Bukkit），为国内已某跑录服务器2017年为了解决玩家疑(xian)难(zhe)杂(dan)症(teng)所开发的

它可以监测玩家发出的词汇并加以判断后进行处理（取消/发送消息）
同时支持包含监测、全词匹配、正则匹配，基本满足所有要求
可以作为脏话屏蔽、聊天帮助、乃至娱乐的聊天机器人
高效自定义、亲测聊天规则匹配5000余条，在同时6000人在线的BC群组服不会有性能问题

二、安装/使用

  • 下载插件
  • 拖进BungeeCord下的plugins文件夹

  • 重启服务器或者热加载
  • 进入plugins/ChatBot文件夹，打开配置文件进行配置
  • console输入chatbotreload
  • 完成！



三、指令

玩家：
/bot —— 开启或者关闭机器人

管理员：
/chatbotreload ——  重载配置文件


四、配置文件
本插件共有4个配置文件
其中config.yml是主配置文件，其余为规则配置文件

config.yml
  1. #设置不启用的服务器列表（前缀即可）
  2. blackServer:
  3.   - 'lobby-'
  4. #开启或者关闭机器人的命令
  5. switchCommand: 'bot'
  6. #开启机器人的提示
  7. switchOn: '§c已开启机器人'
  8. #关闭机器人的提示
  9. switchOff: '§c已关闭机器人'
复制代码


对于全部规则
如果匹配到相同的，将会随机抽选一条执行
{player}参数是通用的，$cancel$可取消聊天事件，$next$继续匹配接下来的规则
取消规则一般用于脏话屏蔽


包含.txt
  1. // 关键字规则
  2. // $next$代表继续判断接下来的规则
  3. // $cancel$代表取消聊天事件
  4. // {player} 代表玩家
  5. **:::不要骂人哦！$next$cancel$
  6. SB:::不要骂人哦！$next$cancel$
复制代码

全词.txt
  1. // 全词规则
  2. // $next$代表继续判断接下来的规则
  3. // $cancel$代表取消聊天事件
  4. // {player} 代表玩家
  5. 哈哈哈:::**?$next$
  6. 哈哈::hhhhh$next$
  7. 你好::你好{player}!
复制代码

正则.txt
  1. // 正则表达式规则
  2. // $next$代表继续判断接下来的规则
  3. // $cancel$代表取消聊天事件
  4. // {player} 代表玩家
  5. (?=^.{3,255}$)(http(s)?:\/\/)?(www\.)?[a-zA-Z0-9][-a-zA-Z0-9]{0,62}(\.[a-zA-Z0-9][-a-zA-Z0-9]{0,62})+(:\d+)*(\/\w+\.\w+)*:::禁止发网址$cancel$next$
