介绍
这是一款简单轻便且支持1.16的交易插件
[应该1.14也支持吧]
保障了玩家之间交易的安全
同意交易时需要玩家按两次确认方块
并且只要确认后物品有所替换插件会自动取消确认保护了玩家不被骗

官方展示图片



个人图片展示[图片没了]



指令+权限
指令;

- /trade <玩家> --> 像某个玩家发起交易请求

- /trade accept <玩家> --> 同意
某个玩家发来的交易请求

- /trade deny <玩家> --> 拒绝某个玩家发来的交易请求

- /trade cancel --> 取消一个你已发送的交易请求

- /trade reload --> 重载插件，配置文件，语言文件


权限;

- trade_ui.trade --> 玩家必须要有此权限才能进行交易

- trade_ui.reload --> 能重载插件的权限

# 插件的信息显示量
# DEBUG -> INFO -> WARN -> SEVERE
# DEBUG -> 只要是插件消息，就会显示在后台
# INFO  ->全显示
# WARN  ->只显示报错
# SEVERE->显示的少就对了
# 你选啥后台就能看到啥
logger-priority: INFO
#设置 false 来阻止玩家使用指令交易
allow-commands: true
#设置 false 来阻止玩家shift+右键交易
allow-shifting: true
#设置 true 来允许拥有权限的玩家进行交易
require-trade-permission: true
#设置成 -1 取消交易范围(就是俩玩家相距距离超过多少就自动取消交易)
max-trade-distance: 15
#交易持续的时间
trade-request-timeout: 20
#设置为 false，当玩家跑远时不会自动取消请求
cancel-request-on-walk-away: true
#设置为 true 允来许玩家进行交易
#注意:这是一个纯粹用于测试的功能
#如果设置为true，插件将会出现故障
#(要你何用)
allow-self-trading: false
