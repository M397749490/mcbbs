作者: 565585    时间: 2020-2-28 19:13
开机启动bat，然后在bat文件里面加个自动重启就好了
@echo off
title CatServer-1.12.2
:start
java -Xmx4G -Xms1G -XX:+UseG1GC -XX:+AggressiveOpts -XX:+UseCompressedOops -jar CatServer-1.12.2-2019-11-27-server.jar
echo 10秒后重启服务器,如需关闭服务器请直接关闭该窗口
@ping 127.0.0.1 -n 10 >nul
goto start
pause
