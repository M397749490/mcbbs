作者: ProperSAMA    时间: 2015-6-2 00:34
应该是MV多世界插件的前缀，MultiWorld默认是没有前缀的打开plugin/Multiverse-Core/worlds.yml，找到需要修改前缀的世界，比如
  1.   ServerSpawn:
  2.     ==: MVWorld
  3.     hidden: 'false'
  4.     alias: 主城
  5.     color: AQUA
  6.     style: NORMAL
  7.     pvp: 'false'
  8.     scale: '1.0'
  9.     respawnWorld: ''
  10.     allowWeather: 'false'
  11.     difficulty: EASY
复制代码

hidden项设置为true即可隐藏前缀
当然你也可以选择将前缀修改为其他文字，修改alias后面的文字即可
如果前缀要设置为中文的话，要使用用ANSI格式编码修改，不然会显示乱码
修改过配置后，输入/mv reload指令重载插件即可使配置生效

隐藏：在ESS中找到聊天控制

变量WORLDNAME就是世界名字
  1. chat:

  3. # 设置聊天半径,如果安装了EssentialsChat,这将设置玩家喊话的可见范围,以格为单位.设置为0则允许全图聊天.
  4. # 注意开启了间谍模式(权限:essentials.chat.spy)的玩家将看到所有聊天内容,无视该设置.
  5. # 拥有"essentials.chat.shout"权限的玩家可以忽视该设置,只要在聊天内容前面加上"!"符号即可(小写感叹号)；
  6. # 或者拥有"essentials.chat.question"权限的玩家可以忽视该设置,只要在聊天内容前面加上"?"符号即可(小写问号)；
  7. # 你可以添加使用上两行方法的花销,在上经济设置中的"command-costs"下添加"chat-shout"和"chat-question"的设置即可.
  8.   radius: 0

  10.   # 聊天格式,可以有两种,你可以定义所有聊天为标准格式.
  11.   # 或者你可以给一个用户组特定的聊天格式,提供一些额外的变化.
  12.   # 是否设置为默认聊天格式,需要与ichat插件兼容.
  13.   # 想了解更多的默认聊天格式的信息,请查看wiki: http://wiki.ess3.net/wiki/Chat_Formatting

  15.   format: '<{DISPLAYNAME}> {MESSAGE}'
  16.   #format: '&7[{GROUP}]&r {DISPLAYNAME}&7:&r {MESSAGE}'

  18.   group-formats:
  19.   Default: '{WORLDNAME} {DISPLAYNAME}&7:&r {MESSAGE}'
  20.   #  Admins: '{WORLDNAME} &c[{GROUP}]&r {DISPLAYNAME}&7:&c {MESSAGE}'

  22.   # 你也可以设置特定组别的聊天格式,删除前面的"#"号来启用.

作者: xv1470928    时间: 2015-6-2 08:59
这是多世界的问题
打开多世界配置文件 config.yml
  1. multiverse-configuration:
  2.   ==: com.onarandombox.MultiverseCore.MultiverseCoreConfiguration
  3.   enforceaccess: 'false'
  4.   prefixchat: 'false' 把该项设置成FALSE即可隐藏
  5.   prefixchatformat: '[%world%]%chat%'
  6.   useasyncchat: 'true'
  7.   teleportintercept: 'true'
  8.   firstspawnoverride: 'true'
  9.   displaypermerrors: 'true'
  10.   globaldebug: '0'
  11.   silentstart: 'false'
  12.   messagecooldown: '5000'
  13.   version: '2.9'
  14.   firstspawnworld: world
  15.   teleportcooldown: '1000'
  16.   defaultportalsearch: 'false'
  17.   portalsearchradius: '128'
