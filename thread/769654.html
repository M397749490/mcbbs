简介
此插件可以骑着猪自由控制飞行



特点
此插件允许你骑着猪飞行 你需要一个鞍 胡萝卜钓竿来控制它
猪会朝着你看的方向行走或飞行



指令
/pigflying reload 重新加载插件配置


权限
pigflying.reload 允许重新加载插件配置

pigflying.use 允许骑猪飞行


配置文件

Config.yml

  1. # Developer FatCrab
  2. # This plugins my new enhancements
  3. Boolean: true
  4. Prefix: '&c[PigFlying]'
  5. SpeedPigFlying: 0.5
  6. Messages:
  7.   RidePig: '&aUse the carrot stick to control the flying pig'
  8.   Reload: '&areload configuration successfully!'
  9.   Permission: '&cYou don''t have permission!'
  10.   Command: '&cUsed: </pigflying reload> reload configuration'
  11.   Console: '&aCannot use this command on the console!'
复制代码



使用方法
你需要准备的: 鞍 胡萝卜钓竿 (权限)

拿着鞍找到一只猪并且右键 然后右键猪骑上去

拿出胡萝卜钓竿"猪霸天下"吧！233
