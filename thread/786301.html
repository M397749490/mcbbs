你是服务器的本地端开发者吗？你想在同学面前装逼吗？你想屌丝逆袭吗？那就和我来学基于Mod coder pack (一说Minecraft coder pack)的客户端开发之旅吧！今天我来带大家做一个属于自己的客户端，后续也可能有续集【由于本人也是编程新手，不足请多多指教】

0×01)工具&原料


1）Mod coder pack[http://www.modcoderpack.com/website/releases]
2）Eclipse(本例使用 Mars版): http://www.eclipse.org/downloads/
3）Minecraft正版启动器 https://minecraft.net/购买成功后即可以下载启动器
4） WinRar: http://www.rarlab.com/download.htm , 或 7zip: http://www.7-zip.org/
5）Java JDK (本例使用 1.8.0_161 版本): http://www.oracle.com/technetwor ... ownloads/index.html

注意！！！必须正版启动器下载的客户端才可以逆向工程minecraft，不能使用如HMCL下载的第三方正版


0×02)配置你的工作环境
1）安装 JDK 并设定 JRE 与 JDK 环境变数路径，可参考product.pconline.com.cn/itbk/software/dnwt/1408/5260596.html#ad=7094
2）下载MCP      http://www.modcoderpack.com/website/releases  本案例使用mcp内部版本918版
3）下载下来的mcp解压到Desktop
4）使用Minecraft Launcher（正版启动器）下载并启动Minecraft
5）Mcp对于Libraries的依赖十分严重，所以请下载完整版minecraft
6）对于没有正版的小朋友，请使用本教程中携带的正版（本人私人使用，请勿登录任何服务器！请勿登录任何服务器！请勿登录任何服务器！）
7）【私人信息已隐藏】（如果第二天我发现正版不能登录了，我会记着你们的）
8）找到%DeskTop%中你解压的文件夹中的decompile.bat（Linux玩家请点击decompile.sh）
9）耐心等待，本配置使用了接近两分钟时间，当看到请按任意键退出并且没有任何的抛出错误的时候，即可关闭提示符
X）到了这一步，你就可以把eclipse打开，找到File_Swith Workspace_Other到你的mcp/eclipse路径了



0×03）对世界说"Helloworld"
1）找到这个类
2）Ctrl+F转入查看框查找"Copyright Mojang AB. Do not distribute!"字符串（本教程是第549行）
3）_1在下面键入这段代码
  1. String %你想要的变量名% = "HelloWorld";
  2.         this.drawString(this.fontRendererObj, %你想要的变量名%, this.width - this.fontRendererObj.getStringWidth(%你想要的变量名%) - 2, this.height -%你想要的的高度%, -1);
复制代码
3）_2 其中%你想要的的高度%在原版中，此句话的高度为-10
本作者发现添加-10相当于汉语一行字的高度
3）_3§0黑色
　　§1深蓝
　　§2深绿
　　§3天蓝
　　§4 红色
　　§5深紫
　　§6金黄
　　§7浅灰
　　§8深灰
　　§9淡紫
　　§a浅绿
　　§b淡蓝
　　§c淡红
　　§d淡紫
　　§e淡黄
　　§f白色
　　除了改变字体颜色以外，我们还可以加粗、斜体、下划线，而且可以和字体颜色重叠：
　　§l 字体加粗
　　§m删除线
　　§n下划线



3）_4结果效果

当然，你也可以添加点色彩效果
代码效果

  1. String democode = "§6§lHelloWorld";
  2.         this.drawString(this.fontRendererObj, democode, this.width - this.fontRendererObj.getStringWidth(democode) - 2, this.height -20, -1);
复制代码
