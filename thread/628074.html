什么是 SheepPainting?
SheepPainting 允许你不用点击便改变指定半径羊的颜色。( /sheeppainting radius <范围> )
如果玩家有权限，这个指令就可以使用
(简单来说就是AOE式的改羊的颜色，如果在羊群中玩一定很爽)



插件特点
  • 每种颜色都可以用
  • 粒子特效的颜色使用RGB的颜色代码
  • 如果你飞起来，那么你脚底下的羊也会改变颜色(如果你手持一些染料的话)
  • 95%的配置文件是可以自定义的 ( 粒子特效颜色无法自定义 )
  • 如果很多人在旁边一起用着不同的颜色，那么羊的粒子特效将会是每种颜色杂乱交错
  • 支持WorldGuard = 只有区块的所有者才能更改羊的颜色




指令和权限
指令 权限
/SheepPainting SheepPainting.help 或是 Sheeppainting.Admin
/SheepPainting reload SheepPainting.Reload 或是 SheepPainting.Admin
/SheepPainting debug SheepPainting.Debug 或是 SheepPainting.Admin
/SheepPainting radius <范围> SheepPainting.radius 或是 SheepPainting.Admin
/SheepPainting toggleparticle [size=14.6667px]SheepPainting.Particle 或是 SheepPainting.User
*你可以自定义每种颜色不同权限，在下面会说明
