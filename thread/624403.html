作者: Stupidbanana666    时间: 2016-8-21 10:39
这个不用插件就比较麻烦了，比如你主世界是world，其他世界world1,world2...
打开GroupManager
打开config
添加你要弄的世界,如下

        world:
           world_nether:
           - users
           - groups
           world_the_end:
           - users
           - groups
           plotworld:
           - users
           all_unnamed_worlds:
           - users
           - groups
           world1:
           - users (红色的就是要添加的,world1可以变换成你想要的世界名，注意下面只要- user~~)
然后游戏里输入/manload
你会发现,worlds里面多了一个文件夹
复制一份原来就有的世界文件夹里的group拷贝过去
进入修改即可

按你的要求，只要在下面添加

- residence.create
就是给这个世界加领地权限
然后打开GM/worlds/world
在builder组添加
- -residence.create
其它世界跟world1一样
纯手打
求最佳
