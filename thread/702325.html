NoCmds


介绍
一个轻量级插件用于禁止使用某指令！

权限
nocmds.bypass  - 允许使用禁止的指令。
nocmds.admin  - 访问“nocmds”指令。

用法
将需要禁止的指令添加到Config里面。
如果添加的指令没有带斜杠，则与指令有相同的指令都禁止使用！
如果添加了带斜杠的指令，则只有你的输入的指令会被禁止使用！



例：
blockedCommands：
- ver
- / plugins
此配置将禁止使用以下指令:
/ ver
/ bukkit：ver
/ minecraft：ver
/ <any_prefix>：ver
和
/ plugins
