权限

  • superjoin.admin - 管理员权限（重载插件、显示插件信息）
  • superjoin.use - 插件功能的使用权限（玩家权限，包括以下所有权限）
         ┣superjoin.use.sound  （进服提示音权限）
         ┣superjoin.use.command   （进服执行命令权限）
         ┣superjoin.use.lightning   （进服触发闪电权限）
         ┣superjoin.use.particle   （进服粒子特效权限）
         ┣superjoin.use.joinmsg   （VIP进服信息|自定义信息框权限）
         ┣superjoin.use.title   （全服Title提示）
         ┣superjoin.use.actionbar   （全服ActionBar提示）
         ┣superjoin.use.potion   （进服药水效果权限）
         ┣superjoin.use.motd   （VIP进服专属MOTD消息权限）
         ┣superjoin.use.menu   （VIP玩家自定义菜单）
         ┗superjoin.use.leavemsg   （VIP退出游戏消息权限）
你可以利用这些子权限来分出好多个VIP等级，当然，你也可以不把它当做VIP插件，给全服玩家权限，每一个人都可以有特效也是可以的。
使用方法
/sreload - 重载插件配置文件（需要superjoin.admin权限）
/smenu - 打开自定义功能菜单（需要superjoin.use或superjoin..use.menu权限）
命令和权限真是非常的简单呢，更方便服主配置和管理了！

SuperJoin插件Wiki

入门：
其实使用SuperJoin插件并不难，虽然插件的功能繁多而丰富，但是各位服主可曾知道插件最初的样子？插件在最初的时候，仅仅是玩家上线发出闪电，而现在已经发展到多功能、多版本的登录特效插件。现在，就让我们从头开始来认识这一款插件吧！
基础功能：
SuperJoin利用对玩家登录事件的监听，在玩家进服时能够使用多项功能。
1.如何提高插件的执行效率

2.进服闪电功能
玩家在进服时可以触发一道闪电从天空中劈下（不会造成伤害什么的，只是个特效），因为是闪电，所以说在那个世界的所有玩家都会听得到打雷的声音和天空中的闪烁。
如何启用或关闭这个功能呢？打开config.yml文件，找到：

  2. lightning: true
复制代码
我们默认设置的是true（开启），如果你想关闭此功能，请设置为false。
使用闪电功能，你需要给玩家以下权限：
  • superjoin.use.lightning
如果你使用的是GroupManager插件，请输入/mangaddp <VIP组名称> superjoin.use.lightning即可完成权限添加

3.PlaceholderAPI插件变量使用
如果你觉得光是%player%变量过于单调，你可以使用PlaceholderAPI为你提供的所有变量，首先，就是让插件与PlaceholderAPI挂钩，首先你需要下载PlaceholderAPI插件，并将其拖入plugins文件夹，然后回到SuperJoin文件夹，打开config.yml文件夹，找到：
  1. #是否开启对PlaceholderAPI的支持（请安装之后再开启，否则插件会报错！）
  2. PlaceholderAPI: false</font>
复制代码
将false设置为true，重启服务器，插件即可完成与PlaceholderAPI插件的挂钩。
注意：挂钩成功后，原有的%Player%变量会失效，请重新检查并配置各个文本内容，并将%Player%修改为%player_name%变量，你现在可以任意使用PlaceholderAPI为你提供的所有变量，重载插件或重启服务器，修改完成，成功使用PlaceholderAPI变量。
问题：为什么我设置了%player_name%还是显示不出来呢？如果你是第一次使用PlaceholderAPI插件，你需要下载PlaceholderAPI的变量包，玩家变量的话就输入（其他同理）：/papi ecloud download player，下载完成后，即可正常显示变量。


4.AuthMe登录插件支持

如何开启对AuthMe插件的支持呢？打开config.yml文件，找到：
  1. 是否开启对Authme登录插件的支持（请使用最新版Authme插件！）
  2. #开启后，玩家必须在登录之后才能触发进服特效
  3. #如果玩家没有登录，则不显示进入退出消息
  4. AuthmeHook: false
复制代码
将false修改为true即可，重启服务器，玩家必须成功登录服务器才能展示特效，否则不会提示任何登录退出消息。

  8. fadein: 3

  10. fade: 5
  11. #title消息的淡出时间

  2. #是否开启全服Title消息功能
  3. use: true

12.Spigot服务端特殊扩展
我们在2.1版本更新之后，特别为Spigot服务端增加了扩展功能，当玩家的鼠标移动到玩家进服消息处时，会显示自定义的玩家信息或是其他内容。（效果图在上文）
如何自定义这些内容？打开config.yml文件，找到（仅限Spigot服务端）：
  1. #———————VIP进服消息专属面板——————————
  2. #开启后，当玩家的鼠标移动到玩家上线消息处时
  3. #会显示自定义信息，支持PlaceholderAPI变量。
  4. BetterShow: false
  5. #这就是显示的内容，自行配置。
  6. BetterShowText:
  7. - '这是给VIP玩家§b%player_name%§r的专属信息显示§r'
复制代码
你可以自定义任何内容，当然，所有的内容都支持PAPI变量，并且此功能只能在启用PAPI的情况下使用！
当玩家拥有自定义进服消息的权限时，同时也拥有了此功能的权限。


13.VIP玩家自定义选项菜单
VIP玩家现在可以自定义开启或关闭superjoin插件的某些功能了，当然，前提是config.yml内的功能得开启。
要使用以上功能，你需要给玩家以下权限：
  • superjoin.use.menu
如果你使用的是GroupManager插件，请输入/mangaddp <VIP组名称> superjoin.use.menu即可完成权限添加
