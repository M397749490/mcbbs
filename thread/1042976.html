data modify entity XXX merge 是合并。

比如玩家的 nbt 中，有一个 Inventory[] ，你使用这个命令，即可把 {id:"minecraft:stone",...} 合并，或者说增加进去。（虽然实际不能修改玩家的 nbt

[{id:"minecraft:stone",...}] 使用后 [{id:"minecraft:stone",...},{id:"minecraft:stone",...}]

data modify entity XXX set 是设置，还是玩家的 Inventory[]  ，set 会设置指定路径中的值设置成你 set 的 nbt

data modify entity @s Inventory[0] set value {id:"minecraft:stone",...}

[{id:"minecraft:stone",...}] 使用后 [{id:"minecraft:stone",...}]

抑或是
data modify entity @s Inventory set value {id:"minecraft:stone",...}

[{id:"minecraft:stone",...},{id:"minecraft:stone",...}] 使用后  {id:"minecraft:stone",...}

作者: Chelover_C60    时间: 2020-5-10 21:34
区别在对Compound型键值（大括号）的处理上。
set直接将目标键值替换为指定值，未指定的键舍去。
merge将目标值用指定值覆盖，未指定的键保留。
例：某nbt目录如下
{a:{b:1,c:2}}
如执行
data modify <目标> a set value {b:2,d:3}
执行后结果为 {a:{b:2,d:3}}
如执行
data modify <目标> a merge value {b:2,d:3}
执行后结果为 {a:{b:2,c:2,d:3}}

data modify entity XXX merge是合并，例如有一个标签A，用这个指令输入标签B的话得到的结果是A、B
data modify entity XXX set是设置，同上有一个标签A，输入标签B，得到的结果是B
