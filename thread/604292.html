唔。先说段废话
本人喜欢全自动化，所以BuildCraft几乎是我每个整合包内必备的Mod，但BuildCraft内的唯一能量来源——各种引擎，的燃料全部无法有稳定的自动获取来源（红石引擎功率太低，斯特林引擎需要煤，燃油引擎需要石油，创造引擎。。。不解释）。所以这就需要人工定期补充燃料，很不能忍呢。

此插件的功能
可以让任何流体——无论是原版还是任何Mod的流体（甚至水）作为BuildCraft | Energy模块内燃油引擎（Combustion Engine）的燃料，并可以自定义能产生的输出与燃烧时间，支持一次设置N种燃料。举个梨子：UU物质众所周知的很难获得，并且似乎除了复制物品就没啥功能了。。。。

数据（默认配置情况下）
所属MOD内部名名称1mB燃烧时间1tick输出功率1mB总输出功率
BuildCraft | Energyoil原油5000=5tick=0.25s30RF/t150RF
BuildCraft | Energyfuel燃油25000=25tick=1.25s60RF/t1500RF
IndustrialCraft2ic2uumatterUU物质500000=500tick=25s160RF/t80000RF
其中UU物质为本插件默认增加的燃料。这个燃烧时间与输出功率是我想了半天才决定的，因为发现UU机在充足的电力供应并没加废料的情况下，产生1mb差不多是24s，于是我就搞了个25s。。。如果觉得不合适，自己改吧，别吐槽了XD


配置文件
  1. # Configuration file

  3. #配置文件版本请勿修改
  4. ~CONFIG_VERSION: 1.0

  6. fuels {
  7.     # 添加的自定义燃料列表
  8.     S:"Custom Fuels" <
  9.         ic2uumatter    # UU物质的内部名
  10.         # 在此处可继续添加，例如原版的水
  11.         # water
  12.      >
  13. }

  15. # ic2uumatter 燃料的设定
  16. ic2uumatter {
  17.     # 每tick，这种燃料可产生多少RF？
  18.     I:powerPerCycle=160

  20.     # 1mB的燃料可以烧多久？
  21.     # 单位为 GameTick * 1000   20 GameTick = 1s = 20000
  22.     # 此处默认为 500tick = 25s
  23.     I:totalBurningTime=500000
  24. }

  26. # 下面可继续添加设定，例如水的设定
  27. # water {

  29. #
  30. #    # 20000 = 20tick = 1s
  31. #    I:totalBurningTime=20000
  32. #}

如何查看流体内部名
最直接的方法大概是去反编译了，不过如果不会/不想这么做，可以利用IC2的通用流体单元。
在创造模式/NEI的搜索界面输入"通用流体单元"，然后会发现出来一堆结果。每种游戏中可用的流体（即使不是IC2的流体），都分别对应了一个通用流体单元。
例如你看到了UU物质的通用流体单元，上面是这么写的
通用流体单元
<ic2uumater, 1000mB>
那个"ic2uumater"即为内部名

如何往引擎里装燃料
1、使用IC2的通用流体单元：拿着单元，按Shift+右击引擎即可。
2、使用IC2的各种液体单元（例如蒸馏水单元etc）：打开引擎的界面，把液体单元放进去。不会返还空单元的，空单元是一次性消耗品。
3、如果没IC2，可以使用各种桶啊之类的，例如星系3提供了“菌泥桶”之类的玩意。如果那种液体根本没法用任何容器盛起来。。那么自然就没办法了。
