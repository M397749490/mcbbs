世界的湿度...？
世界的 TickEvent（WorldTickEvent）和玩家的（PlayerTickEvent）不一样。但概念是差不多的，每一个 tick 触发一次。
理想状态的 Minecraft 服务器中，一秒有 20 个 tick。那么 10 秒就应该有 200 个 tick。
  1. private int tickCounter = 0;
  2. @SubscribeEvent
  3. public void onWorldTick(WorldTickEvent.Post event) {
  4.     if (++tickCounter > 200) {
  5.         // 搞事情
  6.         tickCounter = 0;
  7.     }
  8. }
