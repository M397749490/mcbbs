插件配置

按照配置格式增加附魔商店的选项即可颜色符号为 "§" 价格为0则为免费附魔
SHOP.YML (已做汉化 可供参考用...)
  1. ---
  2. # 不要修改
  3. version: "0.5"

  5. # 是否启用当玩家右键附魔台时,自动打开EnchantUI 若否 则可用命令 /enchantui 打开
  6. enchanting-table: true

  8. #EnchantUI version 0.5
  9. Title: "§r[ §c附 魔 商 城 §r]"
  10. Button: "§3{NAME} §a{PRICE}[        DISCUZ_CODE_24        ]quot;
  11. slider-title: "§5附 魔 等 级"
  12. messages:
  13.   thanks: "§a感谢使用 EnchantUI"
  14.   label: "§e你需要支付 {PRICE}$ 来附魔"
  15.   not-enough-money: "§c你没有足够的钱!"
  16.   paid-success: "§a你花费 {PRICE}$ 购买了 {LEVEL} 级 {NAME}"
  17.   hold-item: "§c请手持一件物品进行附魔."
  18.   no-perm: "§c你没有权限使用."
  19.   incompatible-enchantment:
  20.   
  21. #WARNING: Use only Enchantment ID at incompatible-enchantments example [1,10,13]
  22. shop:
  23. - name: "§0类型: §c火 焰 保 护" # 选项名称
  24.   enchantment: fire_protection # 附魔类型
  25.   price: 100 # 价格
  26.   max-level: 2 # 最高等级
  27.   incompatible-enchantments: []
  28. - name: "§0类型: §2保 护"
  29.   enchantment: 1
  30.   price: 100
  31.   max-level: 3
  32.   incompatible-enchantments: []
  33. ...
