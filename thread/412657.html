大家好,

因为MCPE的服务端更新了,导致第一次用Linux开服的腐竹,使用以前得教程无法开服!

那么我给大家带来一次完美的更新教程.

仅仅只需要3条命令,就可以做到开服!

先说说用Linux的好处,随着MCPE的更新,已经不支持WINDOWSERVER2003系统的运行了.(准确的说是PHP不能运行了,大家可以百度下.)

Linux 无图形界面,更好的利用内存,如果你现在要开服,一台WINDOWS2008系统的服务器,有1GB的RAM运行内存.

但是光一个系统就要200M-400M左右(因为虚拟机构架不同,用的也不一样,效果也不同)

你也就只剩下600MB左右的内存来运行服务器.

但是Linux呢?

普通版本的话,只要30MB左右.如果是精简版的系统,我的服务器只需要14MB内存就可以让服务器运行.

但是Linux鉴定与全是命令,有些人无法接受,但是他的价格,以及性能,都是毋庸置疑的,大家自己考虑.

说说开服务器吧.

首先你要有一台服务器,我这里准备的Centos 6 X86 也就是32位的.

服务器的获取,我个人推荐是国内的云主机,但是鉴定与国内GFW无法访问国外,(不知道GFW是什么可以去百度下.)

大家选择香港的服务器,如果经济不允许,可以考虑美国洛杉矶的服务器,价格便宜,延迟还可以接受.



然后我们用PUTTY登录服务器.

(HOST NAME OR IP ADDRESS) 这里是你购买的服务器的地址

PORT 连接端口 (一般默认都是22,部分商家为了安全修改了其他端口,具体询问服务器提供商.)

输入好以后我们点击下方的OPEN.

先是会看到一个白色的对话框,让你确定RAC指纹信息,我们确定就可以.

再接着.你会看到一个黑色框的界面.

上面写着 login as : (这里是让你输入帐号,我们购买到的帐号必须是root)

输入root,他提示我们输入密码,我们输入购买到的密码.(这时候你输入密码是没有任何提示的.)

可以复制内容,然后在窗口内按鼠标右键,就可以自动粘贴内容.

输入完成,我们进入界面.我们输入我们的第一条命令.

yum -y install perl gcc make automake libtool autoconf m4 screen && adduser mcpe && passwd mcpe && exit

这时候我们一直等,一直等到提示 NEW passwoord :

这是让你输入一个帐号密码,你必须要自己定义一个.我暂且设置为123456789(不建议这么简单,因为容易被猜解.)

Retype Nwe password: 这是让你重复一边密码,在输入一遍你刚才设置的密码就可以了.

如果出现sorry,说明出现错误,需要你重新填写.

如果窗口自动关闭,那么你的密码设置好了.窗口关闭后会创建一个账户,账户为mcpe密码是你自己刚才设定的密码.

OK,我们在打开PUTTY,输入IP,端口,然后点击OPEN,我们登录帐号,这一次登录的是我们重新建立好的 mcpe 这个帐号.

登录完成,我们执行我们的第二条命令!

screen -S mcpe

然后输入

wget -q -O - http://get.pocketmine.net/ | bash

然后一直等到
Everything done! Run ./start.sh to start PocketMine-MP

我们输入./start.sh 就可以开服啦.

第一次出现的选项输入Y(这是问你是否同意条款)
第二次出现的选项输入Y(是否跳过新手引导,如果你需要的话可以输入n)
然后选择语言界面,个人推荐使用默认的英语界面(en)因为这个界面不会出现乱码.

当出现done(3.2s) 这类文字的时候,就是代表开服成功了.(括号内的数据是代表运行开服程序用了多久.不是很重要.)
引用其他帖子的几句话,复制过来,免得我打了 原帖地址(http://www.mcbbs.net/thread-240751-1-1.html)

如果我们要添加插件,等等等等,我们要用到FlashFXP
首先打开Flashfxp
然后点击“快速连接 F8”
然后，修改连接类型为“SFTP over SSH”
地址或URL输入服务器IP。注意，这后面的端口写的是21，这里要和在Putty里填写的相同，一般为22
用户名称为“mcpe” (如果你只是游戏不需要完整权限的话)
密码还是在Putty里登入时填写的那个。
其他的不用修改。
注：如果成功登入了一次后，在“历史”那一栏里会有保存，就不用次次填写了。

里面的文件夹plugins是插件worlds是地图,player是玩家.如果需要更新文件,请直接替换文件夹内文件.

在Pocketmine目录下的“server.properties”就是设置你服务器的数据。
其中几项重要的：motd为进入你服务器的欢迎词。
server-port为服务器端口
max-players为服务器最高支持多少人在线
memory-limit为PHP最高内存（不是设的越高越好，一般不超过256，加入max-player小于20，那么设置128足够了）
level-name为你服务器主地图。（就是一进去看到的,因为现在是无限地图,一般不需要）
注意：所有“server.properties”的设置都不能出现中文、空格、点（例如1.5）等等否则服务器可能会使用默认选项或无法启动

PS：本文中的FlashFXP、Putty在手机上都有类似功能软件。分别推荐一个比较好的：FlashFXP=ES文件浏览器；Putty=ConnectBot这两个软件就不再介绍了。好处就是，你可以用流量随时随地开服、装插件什么的。


这里有两个必用的命令，记好了就行

1、screen -S（注意大小写，包括以下的也要注意）

2、screen -x

screen -S

这个命令就是让你指定一个会话名称。

它可以让你更方便的在关闭Putty后，打开原先的会话。如果自动创建一个screen会话的话，再恢复的时候会很麻烦（因为恢复需要输入会话名称，而自动创建名称，都是很长的，很不好输）

比如，我的服务器现在叫STNO

我想创建一个叫st的会话

当你们进入服务器后台，输完密码后
你们就需要输入"screen -S st"

那么我们退出后，怎么恢复呢？别急，下面就来介绍。
②screen -x

这个命令可以让我们恢复以前的会话，重新回到Pocketmine管理界面，就可以输whitelist啊op啊或者ban之类的命令了。

具体用法

我们不是创建了一个叫st的会话吗？

刚才我已经关掉Putty了，现在又想控制Pocketmine了

让我们打开Putty，登陆以后输入"screen -x st"

就可以恢复之前的会话了。

(使用我的命令默认会自动使用Screen添加一个名为 mcpe 的窗口.如果需要恢复窗口可以输入screen -x mcpe)
