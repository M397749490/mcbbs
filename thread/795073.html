（下半部分的汉字请先忽略= =）
可以清晰地看到这个模组主要有三个命令：
/setMusic [player] 音乐ID（-1到10) [最短时间间隔（tick）] [最长时间间隔（tick）]设置一位玩家客户端的背景音乐ID，并设置该玩家客户端背景音乐播放的最端与最长时间间隔。
/setAllMusic 音乐ID（-1到10） [最短时间间隔（tick）] [最长时间间隔（tick）]设置一个服务器或者局域网内所有玩家客户端的背景音乐ID，并设置所有玩家客户端背景音乐播放的最端与最长时间间隔。
/getMusic [player] 获取一位玩家客户端内正在播放的背景音乐ID、背景音乐播放的最短与最长时间间隔。
（看到这些指令是不是有种熟悉的赶脚？）
注：在最新版本中，/setMusic 指令有四种写法：
/setMusic 音乐ID
/setMusic 音乐ID time(short) time(long)
/setMusic player 音乐ID
/setMusic player 音乐ID time(short) time(long)
/setAllMusic 也有类似的写法，大家自己探究下吧= =
其中 玩家名称 属于可选填写项，不写的话目标就是自己。
音乐ID为 -1 将不会播放任何背景音乐，ID为 0 将会播放原版音乐。

附：关于在服务器内的配置文件对客户端的影响
首先，服务器的配置文件优于客户端，因此在服务器内，只有服务端配置文件可以影响客户端，客户端内的本身是无效的
比如：客户端内修改唱片的配置为 false ，服务器内为 true ，那么在服务器内唱片音乐仍然会被修改。
如果服务器内没有该模组，则在客户端内关于修改唱片的配置将会无效

    # Default music ID when you are on the game interface,this only effects on client.(-1 to 10,-1 is none,0 is original,default:2)
    I:defaultMusicOnTitle=2//5月15日新增的配置，决定客户端登录界面所启用的背景音乐音乐包ID，其中 -1 为无音乐，0为原版音乐，该配置不受已启用的音乐包数量的影响，请勿填写低于 -1 或者高于 10 的参数。如果不希望修改界面背景音乐的话请将改配置设置为0。该配置在服务端没有意义。注：最新版本已可以启用30个音乐包！

首先是"category"选项，music1 中对应的结果是 "music" ，即告诉系统文件这是一个“音乐”文件，系统会根据提示自动调整该音乐文件的音量、音调
如果是用作唱片文件的话可以考虑将这个选项变为"record"，以获得与唱片声音文件相同的调试方法（不过楼楼赶脚没啥区别）。

"name"选项，指认音乐文件的调取路径，例如  "musicsetting:music1/music1_1"  这个路径翻译过来就是“assets/musicsetting/music1/music1_1.ogg”，当然聪明的吧友应该很快就想到魔改这个模组的方法啦吧= =。
切记不论如何修改文件与文件夹名称，请勿使用除了英文以外的语言，比如中文日语啥的，模组读不出来这种奇怪的编码的= =。
最后，无论怎样魔改，请勿修改最外层的 musicsetting 和 record.musicsetting 文件夹的名字以及这个文件内的 music1 music2 这样的题头！

"stream"标明是否加载整个音乐文件用以播放，由于这些原文件都属于音乐或者唱片文件且该项默认为 false ，请在编写的时候不要落下该项并将该项设置为 true （布尔变量，不需要引号）

最后，万众瞩目的音量设置参数："volume" ，这是一个浮点数因此也不需要引号，范围为 0.0 到 1.0（不得等于 0.0） ，表示在游戏内该音乐文件的音量 × 这个值，但不可以设置为 0 否则会报错。

最后，请记得自己使用了多少个 逗号（英文的半角逗号！），当然你可以注意到每个选项的结尾除了最后一个外都有一个逗号= =。

解谜地图制作者的朋友们
emmmm……首先，我需要在不同的环境中播放不同的背景音乐，而这个模组的命令可以在命令方块内执行的特性决定了它可以很好地调节解谜地图的氛围。同样配置文件可以关掉玩家使用命令的权限，这样玩家也不可以随意修改背景音乐= =。
更有趣的一点是，这个模组可以控制背景音乐的播放频率，也就是说你可以让玩家好好滴沉浸在背景音乐的氛围中啦= =。
注：使用命令方块执行命令时请标明玩家

服务器
没错这就是今天额要说的重点。
由于这个模组以前是一个服务器专用模组，所以这个模组严格意义上来讲是服务于服务器的。
首先，可以通过配置文件设置玩家使用命令的权限，这样玩家客户端内播放什么背景音乐完全由服务器说得算。
其次，客户端背景音乐的播放频率也是可以由服务端控制的。
最后，很多服务器可能拥有多个子服，如果每个子服都安装该模组的话其生成的配置文件也都不尽相同，因此可以通过改写不同服务器的不同配置文件来达到不同服务器播放不同初始背景音乐的效果= =，这样可以很好地区分不同世界所播放的背景音乐。
请记得在服务端与客户端同时安装该模组哦
