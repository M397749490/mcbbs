DeathCrystal
死亡水晶

伺服器玩家抱怨死亡後物品噴光?
直接開防噴好像又對大家太好了?
本插件將是你的最佳選擇!
插件名稱：DeathCrystal 死亡水晶

插件版本：1.5
適用版本：Spigot / Bukkit 1.13.X  (1.12.2以下未測試)
前置插件：無，可直接使用
插件下載：點此下載
安裝方法：將DeathCrystalV1.5.jar下載下來後放入伺服器plugins資料夾即可
指令：(deathcrystal可簡寫為dc)
/deathcrystal help - 查看指令教學
/deathcrystal give <玩家> <數量> - 給予指定玩家指定數量的死亡水晶，默認為自己、1顆
/deathcrystal reload - 重新載入插件設定檔
權限：
dc.admin - 擁有此權限的玩家可使用以上三個指令(預設OP)
  • 本插件讓玩家死亡時自動偵測背包中是否有死亡水晶，若有該道具則該次死亡不會掉落物品、裝備、經驗。
  • 可讓死亡水晶透過破壞方塊取得，並且可自行設定方塊、機率、數量等等。
  • 可讓死亡水晶透過擊殺生物取得，並且可自行設定生物、機率、數量等等。
  • 死亡水晶可自行更改道具名稱以及說明。
  • 插件所有訊息99.99%可從lang.yml做修改。

↑死亡水晶預設文字，全數可自行修改
config插件設定檔
#死亡水晶的外型
item: Diamond
#是否使用附魔光澤特效
enchantEFX: true
#每次死亡消耗水晶數量，不想消耗則設定0
amount: 1
#從方塊掉落
drop-from-block:
  #方塊種類
  Diamond_Ore:
    #是否啟用此方塊
    enable: false
    #掉落機率(%)
    chance: 50
    #最少掉落數量
    min-amount: 1
    #最多掉落數量
    max-amount: 4
    #掉落時觸發音效(若不想觸發音效請直接用兩個單引號''，中間不留空白)
    sound: ENTITY_PLAYER_LEVELUP
    #是否只有生存模式下會掉落
    survival-only: true
    #是否允許使用絲綢之觸時也會掉落
    allow-silk-touch: false
#從生物掉落
drop-from-mob:
  #生物種類
  Zombie:
    #是否啟用此生物
    enable: false
    #掉落機率(%)
    chance: 50
    #最少掉落數量
    min-amount: 1
    #最多掉落數量
    max-amount: 4
    #掉落時觸發音效(若不想觸發音效請直接用兩個單引號''，中間不留空白)
    sound: ENTITY_PLAYER_LEVELUP
    #是否只有在玩家擊殺該生物時會掉落(設定false的話不論哪種死因都會掉落)
    player-only: true
方塊、道具、音效、生物的編號請參照官方設定
若想要有很多方塊或生物都會掉落水晶，只要用同樣的格式複製下去即可
