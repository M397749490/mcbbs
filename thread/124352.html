= -因为昨天发的一个Spleef不支持我的服务器版本[Spout]所以我就再发一个~
安装方法~
安装最新版WE和SueprSpleef放进Plugins

上图【官网的图】

权限&指令：
指令：
  • /spleef leave - 离开游戏
  • /ss join <场地名字> - 进游戏
Admin Commands:
  • /spleef createarena -用WE创造新场地
  • /spleef addfloor <Arena#> -增加地板。。。？
  • /spleef setspawn <Arena#> - 设置游戏出生点
  • /spleef setlose <Arena#> - 玩家死了之后传送点的设置
  • /spleef setwin <Arena#> - 设置胜利者的让 an arena
  • /spleef disable - 马上停止所有Spleef游戏
  • /spleef enable <Arena#> - 重新允许开启游戏。。？
  • /spleef enable - 开启所有场地
  • 权限：：
  • spleef.join.<arena#> - 让玩家可以用牌子进入游戏
  • spleef.start - 让玩家可以开始游戏
    • spleef.arena.disable - Allows the user to disable an arena允许关闭场地
    • spleef.arena.enable - Allows the user to enable an aren允许这个玩家开启场地
    • spleef.arena.nocmdblock - 翻译不出来。。

关于牌子进入游戏的方法，请看2L
