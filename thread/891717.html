功能介绍
  • 消息完全自定义！
  • 查询玩家在服务器的游戏时间！（支持离线玩家
  • 记录玩家加入游戏的次数
  • 查询服务器的运行时间!
  • 支持变量
  • 使用JSON文本易于编辑
  • 在线时间排行榜Top10
  • 设置指令的冷却时间
  • API

插件指令
  • /playtime-获取自己的在线信息
  • /playtime <player>-获取其他玩家的在线信息
  • /uptime-获取服务器的运行时间
  • /playtime reload-重载插件
  • /topplaytime-在线世界排行榜

权限列表
  • pt.use-允许使用/playtime查询自己的在线时间
  • pt.others-允许查询其他玩家在线时间
  • pt.uptime-允许查询服务器运行时间
  • pt.admin-重载插件
  • pt.top-查询服务器在线排行榜
  • pt.block-cooldown-使用/toppt不受冷却的限制
