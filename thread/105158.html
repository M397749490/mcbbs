引入了城市模式，让玩家能够以城市划分群体进行生活

城市中土地是可以购买的，未购买土地不能进行任何破坏建造等等

城市引入了税收模式，只对城市银行征收，银行收入来自于土地的出售

税收征收时间和款项可自定义

市长可以随时取钱，玩家可以为城市捐款

助理可协同市长处理事务，比如接受请求

城市设为私有后玩家将不能通过主动申请的方式加入城市，必须城市进行邀请

区域从大到小分为：世界——城市——领土(不属于城市但属于世界的地方叫荒野)

领土和公路尺寸可自定义

只有先建立一个世界(/citycraft worlds add命令)，才能继而建立城市，世界范围很大，足够囊括N个城市了(整张地图可以有多个世界和多个城市)

城市可任意更改区域范围

城市附近不会生成怪物(可配置)

世界/城市/领土中可以自定义pvp、爆炸、火焰、建造、物品使用、物品交互(即红石、踏板等功能是否起作用)等

城市间可以任意进行传送(/city warp指令)

clean/mark/fill指令能够很方便的对每块领土进行规划，当然，是收费的

具备丰富的配置文件(我眼睛都花了。。。)

message.yml是消息文本，可自行配置

不具备重载指令，请自备重载插件。


最好在使用/plot claim占有领土后，再使用/city plot mark 或 /city plot fill对领土进行标记，否则你根本分不清自己的领土范围，不能一步一步走过去丈量吧。。。部分命令是区分玩家名称大小写的，比如/city resident kick 和 /city attributes等

指令：
  1. /citycraft worlds add [名称] - 添加名称。默认当前世界名
  2. /citycraft worlds remove [名称] - 移除名称。默认当前世界名
  3. /citycraft set - 查看可用属性列表
  4. /citycraft set [规则名] <on/off> - 设置属性。
  5. /citycraft info - 显示当前属性

  7. /city - 你的城市状态
  8. /city list - 全部城市列表
  9. /city [城市名称] - 指定城市信息
  10. /city join [城市名称] - 加入城市
  11. /city leave - 离开城市
  12. /city warp [城市名称] - 传送到指定城市
  13. /city map - 城市地图
  14. /city new [城市名称] - 创建城市
  15. /city mayor ? - 显示市长命令列表
  16. /city delete - 删除城市
  17. /city resident <add/kick> <玩家名称> - 邀请/剔除某个市民
  18. /city claim - 扩张城市。必须是相邻的土地，也就是说扩张地区不能离城市太远
  19. /city unclaim - 解除当前土地的扩张
  20. /city bank - 城市银行命令列表
  21. /city bank deposit - 存钱
  22. /city bank withdraw - 取钱
  23. /city bank balance - 查看城市银行
  24. /city plot <clean/mark/fill> - 清除围栏/创建围栏/填充土地。仅仅是为了方便标记

  26. /city attributes - 查看可用属性
  27. /city attributes <add/remove> <城市名称> build - 建造权限
  28. /city attributes <add/remove> <城市名称> witch - 物品互动权限
  29. /city attributes <add/remove> <城市名称> use_items - 物品使用权限
  30. /city attributes <add/remove> <城市名称> assistants - 列表显示

  32. /city set - 查看城市可设置的标志值
  33. /city set mayor <市长名称> - 设置新市长
  34. /city set spawn - 设置城市出生点
  35. /city set all <on/off> - 开启/关闭全部
  36. /city set pvp <on/off> - 开启/关闭pvp
  37. /city set fire <on/off> - 开启/关闭火焰
  38. /city set mob <on/off> - 开启/关闭怪物生成
  39. /city set explosions <on/off> - 开启/关闭爆炸
  40. /city set public <on/off> - 开启/关闭城市公有化


  43. /plot claim - 占有领土
  44. /plot unclaim - 取消占有
  45. /plot forsale [售价] - 出售领土
  46. /plot noforsale - 取消出售
  47. /plot [info] - 查看领土信息
  48. /plot help - 查看领土帮助
  49. /plot set all <on/off> - 开启/关闭全部
  50. /plot set pvp <on/off> - 开启/关闭pvp
  51. /plot set fire <on/off> - 开启/关闭火焰
  52. /plot set mob <on/off> - 开启/关闭怪物生成
  53. /plot set type residential - 允许占有无主土地。别名res
  54. /plot set type comercial - 设为商业
  55. /plot set type public - 公有
  56. /plot attributes - 查看可用属性列表
  57. /plot attributes clear <属性名称> - 清除属性
  58. /plot attributes <add/remove> <城市名称> build - 添加/移除建造权限
  59. /plot attributes <add/remove> <城市名称> switch - 添加/移除物品互动权限
  60. /plot attributes <add/remove> <城市名称> use_items - 添加/移除物品使用权限


  63. /resident - 查看自己信息
  64. /resident help - 帮助
  65. /resident info [市民名称] - 查看指定市民信息
  66. /resident friends <add/remove> [市民名称] - 添加/移除朋友
  67. /resident list - 市民列表


  70. /request accept [ID] - 接受指定请求。默认是最后一个
  71. /request decline [ID] - 拒绝指定请求。默认是最后一个
  72. /request clear - 清空请求
  73. /request list - 查看请求列表
  74. /request help - 查看帮助列表
