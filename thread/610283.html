                                ForceResourcePack - 强制材质包
       重要:本插件前置为ResourcePackAPI，
且需要服主自备一个.zip结尾的储存下载地址（不可为所谓的网盘）

     警告：当玩家使用某种特定的客户端时，使用该插件会造成玩家客户端崩溃
                      具体原因不明，推测和中文补丁以及Froge有关


[diamond_sword]插件介绍

· 大家都知道服务器材质包吧~但如果有人点了不下载材质包呢？

·这款插件可以让玩家强制下载服务器材质包，如果不下载，则可以规范他的行为（如kick ; ban ; 禁止移动 ； 禁止输入命令等）


[diamond_gem] 安装方法
将前置和本体
扔进 Spigot/PaperSpigot/Bukkit的Plugins里
然后重启服务器



[powered_minecart]配置文件及注释
  1. #设置材质包的地址(必须为.zip或.rar结尾,推荐使用腾讯云的免费服务;)
  2. link: 'http://test1-10054566.cos.myqcloud.com/JehkobaFantasy.zip'
  3. #信息
  4. message:
  5.   send: '&a您正在下载必备的材质包...&7&o(该功能仍在测试,如有问题请联系技术)'
  6.   loaded: '&a材质包已成功加载,请享受!&7&o(该功能仍在测试,如有问题请联系技术)'
  7.   accepted: '&a加载材质包中&7&o(该功能仍在测试,如有问题请联系技术)'
  8.   failed_load: '&c加载材质包失败'
  9.   declined: '&c请在客户端设置中打开服务器资源包选项!'
  10. #下载资源包失败时是否启用deny设置里的选项
  11. deny_on_fail: true
  12. #如果他们拒绝打开服务器材质包设置是否将其踢出服务器(如果选择了true则下面deny的配置无效)
  13. kick_on_deny: false
  14. #如果玩家拒绝打开服务器材质包设置，是否执行下面的命令
  15. command_on_deny:
  16.   enabled: false
  17.   command: "/ban %player%"
  18. #记录材质包的下载情况
  19. console_log: true
  20. #如果玩家不接受材质包，则拒绝其做出以下动作
  21. deny:
  22.   message: '&c你并未允许或成功加载服务器材质包!所以你不可以做那个!'
  23.   interact: false
  24.   interact_entity: false
  25.   damage: false
  26.   change_world: false
  27.   chat: true
  28.   build: false
  29.   move: false
  30. #是否当玩家登陆时检查设置其材质包情况
  31. set_on:
  32.   join: true
复制代码



下载地址（已汉化）
http://pan.baidu.com/s/1c5L5D0



指令,权限
/forcerp reload - 重载配置文件
/forcerp set <玩家ID> - 设置一个玩家的材质包为当前服务器材质
/forcerp setall - 设置所有在线玩家均为当前服务器材质
forcerp.deny.bypass  可让服务器不检查 某一玩家/组 的材质情况

兼容版本：仅测试了1.8.7，作者称支持1.7-1.9

最后：
如果玩家不使用服务器材质不太大影响服务器特色或游戏性
建议不要使用该插件！
该插件会大大影响并降低玩家对服务器的评价！
