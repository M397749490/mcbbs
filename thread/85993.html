现在开始传送门部分
在服务器1控制台上输入
  1. trp network set key server1Key                                                  #设置当前服务器的key值
  2. trp network set listenAddress *:25601                                       #设置trp 插件端口代理（bungeeCord）模式必须
复制代码
在服务器2控制台上 输入
  1. trp network set listenAddress *:25602                                        #设置服务器2 的trp端口
  2. trp network set key server2Key                                                    #服务器2的key
  3. trp network set clusterName cluster                                             #设置群集名
复制代码
登陆游戏按
t输入
/server lobby
代理上设置的server名字
跳到lobby的服务器上
然后输入
  1. /trp design build lobby
复制代码
这样就会出现一你开始在配置文件那里设定的门 lobby.ynl文件
先把牌子拆下来挂上一个新牌子
第一行 是门的名字我的取名叫lygate
完成后切换到tianyou
  1. /server tianyou
复制代码
  然后输入
  1. /trp design build tianyou
复制代码
创造一个门一样刚刚在配置文件里做的
再回到lobby
/server lobby
然后输入
  1. /trp gate list                        查看门列表 如果你跟对面服务器连接上了就可以看见对面的门
  2. /trp gate link add lygate tianyou.tianyou.tygate rev
复制代码
  记得切换到生存模式 然后左键下牌子就可以开启门了 还等什么 跨服战开始了
