2个....1个是事件的，一个是player

传参都通过new XXXEvent(参数)来进行，而不是在invoke你的@EventHandler注释下方法的时候传入

例子：
  猜的你的代码：
   
  1.     @EventHandler
  2.     private void onXXX(XXXEvent e, Player p){
  3.         
  4.     }
复制代码

  
  应该改成:
   
  1.     @EventHandler
  2.     private void onXXX(XXXEvent e){
  3.       Player p = e.getPlayer();
  4.     }
