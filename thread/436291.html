标题: 有谁知道怎么修改附魔台的权限组么
最近我开了一个服务器，但是服务器里的玩家都不能使用附魔台和铁占，不是在领地里的，普通放着也不能使用，这是为什么
作者: moline    时间: 2015-4-20 20:20
/mangaddp default essentials.build.*
给玩家使用交互权限，如果是单独的使用权
/mangaddp default essentials.build.use
只能使用，不能破坏
作者: qq307198081    时间: 2015-4-20 22:07
如果你是OP，那么输入
/mangaddp default essentials.build.*
给玩家使用交互权限，单独的使用权
/mangaddp default essentials.build.use
只能使用，不能破坏
如果你是玩家，在你的领地内只要给他USE使用权就可以了。
