标题: 关于服务器插件的一些问题
我的服务器里的地皮插件（PlotMe），普通玩家领取不了地皮，还有宠物插件（MyPet）怎样设置才能普通玩家也可以扑捉宠物，帖子我都看过了，看了，并不是非常懂。详情再下方回复
作者: 幻境雲達達    时间: 2015-10-17 19:49
依次输入以下指令

/mangaddp default plotme.use

允许玩家领取地皮

/mangaddp default plotme.use.add

添加权限

/mangaddp default plotme.use.remove删除权限

宠物插件的话。。

/mangaddp default *

这个*替换成下面的代码 依次输入

    - MyPet.custom.skilltree.ppp
    - MyPet.user.command.release
    - MyPet.user.command.respawn
    - MyPet.user.leash.*
