上面都错啦！SelectedItem 是主手呐。
  1. /execute as @a[nbt={Inventory:[{Slot:-106b,id:"<物品id>"}]}] run function ...
复制代码
玩家物品栏的 -106 号位（Slot:-106b）就是副手位。
这个命令是指，对每个副手上有任意数个 <物品id> 的玩家，以他们为执行者执行函数。所以追加描述中的例子：
  1. /execute as @a[nbt={Inventory:[{Slot:-106b,id:"minecraft:stone"}]}] run function ...
