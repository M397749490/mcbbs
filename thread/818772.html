标题: MythicMobs插件问题如何创建固定的刷怪点
MythicMobs怎么设置固定刷怪点以及设置刷怪点时间？
作者: 二白丶    时间: 2018-9-1 19:05
设置好怪物后，输入/mm s create 刷怪点名称 怪物名称[指的是怪物代码]<--创建刷怪点
然后/mm s set 刷怪点名称[需要先创建刷怪点] 秒数<--设置冷却
