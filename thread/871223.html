认识插件
CrateReloaded是某种的一个插件呢？
想必玩过勇者赞歌的都知道那个抽奖箱子就是用这个插件完成的
但你绝对不知道英文的还有更多的功能！
如果贴内介绍有不全面的，您还可以翻阅官方wiki
               
即日起该教程不再更新，有问题请Q我

与其搭配的插件
是的，您并没有看错，这个插件可以和其他插件搭配混合使用
Essentials
Vault

Citizens

配置：config.yml
# ======================================================= #
#                                                         #
#                   CONFIG.YML                            #
#                   FOR 2.0                               #
#                                                         #
# ======================================================= #

#  NOTE:                                                  #
#  您没有配置奖励，请到 plugins/CrateReloaded/crate.yml   #
#  进行配置。                                             #
# ======================================================= #
#
# 消息的显示前缀
prefix: '&8[&b抽奖箱&8]&e'

# 选择您的语言文件.
locale: zhs

# 是否开启记录
logger: false

# Decimal format that determines the number of decimals
# i.e. 3.14 = #.##, 2.5 = #.#
# 抱歉翻译能力有限
decimal-format: '#'

# 玩家等待抽奖箱的冷却是多久
cooldown: 1.0

# 创造模式限制
# 防止玩家使用创造模式复制抽奖箱钥匙.
creative-control: true

# 好像是储存多余奖品的地方
claim:
  # 指令前缀，建议不要修改此项
  # 除非指令与其他插件的指令冲突时再做修改
  command: 'cr'
  # 库存名称
  menu: '抽奖仓库'
  # 如果背包满了的话，让这个仓库来储存它？
  # 否则的话，多余的奖品会掉在地上！
  handle-full-inventory: true
  # 提醒玩家有奖励在这个仓库里
  reminder:
    # 在玩家加入服务器时发送这条消息
    join: true
    # 在一段时间后向该玩家发送这条消息
    timer: true
    # 发送这条消息的时间
    period: 900

# 抽奖箱设置
crate:

  # Comparison Level
  # Compares two items and determines if it is a crate
  # 0 - Basic (Name, Type, Lore)
  # 1 - Normal (Setting 0 + Enchants, Flags)
  # 2 - Strict (Setting 1 + Custom NBT) . . . Note: Old keys will not work if this option is selected.
  # 抱歉翻译能力有限
  compare: 0

  # 在抽奖的过程中显示的物品名称
  display: ''

  # 默认菜单名称
  menu: 'Menu'

  # 是否允许玩家把抽奖箱放入容器里
  craft: false

  # 是否允许玩家在还没有抽完奖的时候退出界面
  peri-exit: false

  # CSGP 抽奖方式的长度
  csgo: 6

  # roulette 抽奖方式的长度
  roulette: 5

  # wheel 抽奖方式的长度
  wheel: 8

  # 菜单部分功能
  buttons:
    enabled: true

    # 下一个
    next: 'ARROW 1 name:&a下一页 lore:&e进入下一页。'

    # 关闭
    close: 'MUSIC_DISC_11 1 name:&4关闭！ flag:隐藏界面'

    # 上一个
    back: 'RED_BED 1 name:&4&l上一页 lore:&e回到上一页。'

    # 确认菜单
    # 每个抽奖箱在 crate.yml 都有个性化的设定
    # 如果没有自定义，那将采用下面的默认设定
    accept: 'GREEN_STAINED_GLASS_PANE 1 name:&a确定 lore:&f点击打开 {crate}!'
    decline: 'RED_STAINED_GLASS_PANE 1 name:&4否定'

    # CSGO 显示
    # 仅仅用于显示，并不会有任何效果
    csgo-top: 'REDSTONE_TORCH 1 name:&6奖品!'
    csgo-bot: 'REDSTONE_TORCH 1 name:&6奖品!'

  # Pushback 设置
  # 抱歉翻译能力有限
  pushback:
    enabled: true

    # 效果项
    x: 1.0
    y: 1.0
    z: 1.0

  # 全息字体设置
  hologram:

    # 修改项
    # 全息字体处于居中位置，在距离一个方块远的上方位置（不知道怎么翻译好..）
    x: 0.0
    y: 0.0
    z: 0.0

第③篇：高级篇——为你的配置加上更多参数
这些更多的内容可以自行摸索，因为有部分讲起来可能会让人难以理解
所有开箱动画：roulette、csgo、none、reverse_csgo、wheel、reverse_wheel
wheel和reverse_wheel的可用性未知，最好用前四项
        
结束动画：blank、bandom
结束动画一般很少用到，最好还是不用
        
物品参数：
  • name —— 物品的名称，例子：name:&7我只是一块石头
  • lore —— 物品的标签，例子：lore:&7很常见的方块
  • player —— 玩家头颅，例子：player:notch
  • skull —— 也是头颅，但是这个却不实用，很抱歉这个例子举不出来
  • color —— 颜色效果需要使用RGB而不是颜色的英文，例如：color:255,255,255
  • effect —— 药水效果（需要物品材质为药水时），例子：effect:haste
  • power —— 药水等级，例子：power:2
  • duration —— 药水持续的时间，单位刻，每20刻为1秒，例如：duration:200
  • splash —— 这个类似是属性？，例子：knockback:1
  • unbreakable —— 无法破坏，例子：unbreakable:true
  • glow —— 附魔效果，仅仅是附魔时发光的那个效果，例子：glow:true
  • enchant —— 附魔效果，真正的附魔，例子：DURABILITY:3
  • hide —— 隐藏物品属性，比如附魔等级，属性数值等，例子：flag:HIDE_UNBREAKABLE
flags：
  • HIDE_ENCHANTS —— 隐藏附魔
  • HIDE_ATTRIBUTES —— 隐藏属性
  • HIDE_UNBREAKABLE —— 隐藏无法破坏
  • HIDE_DESTOYS —— 隐藏能够破坏的方块
  • HIDE_PLACED_ON —— 隐藏能够放置的方块
  • HIDE_POTION_EFFECTS —— 隐藏药水效果
奖励参数：
  • item —— 物品类型的奖励，例子：item:(stone 1) #这里你可以用物品参数的例子，glow似乎不支持
  • cmd —— 指令类型的奖励，例子：cmd:(/heal {player}) #斜杠 / 号可有可无
  • chance —— 抽中的几率，例子：chance:(10) #算法：<某项数值>/<所有数值总和>
  • display —— 适用于和cmd搭配，例子：display:(stone 1) #这里你可以用物品参数的例子
  • unique —— 似乎是当奖励有多项时添加的，例子：unique:()
  • always —— 总是，总是会获得这个奖励，不要和chance共用在同一项奖励里，例子：always:()
  • broadcast —— 当抽到这项奖励时播放一条公告，例子：boradcast:(玩家 {player} 在 {crate} 中抽到了XXXX)
  • msg —— 当抽到这项奖励时对抽奖的人发送一条消息，例如：msg:(恭喜您抽到了XXXX)
  • append —— 似乎是给broadcast附加一条消息（不确定），很抱歉这个举不出例子，作者没有过多的解释
  • permission —— 特权，给这项奖励添加一个只有某项权限的人才能获得，例子：permission:(user.vip)
  • 这些参数需要用英文的逗号 , 来隔开，切勿使用中文的逗号
