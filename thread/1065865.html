# LuckPerm权限自动导入插件使用方法：
1. 将插件放入plugins目录
2. 启动服务器
3. 将写好的权限节点文件放入插件文件夹
4. 在控制台中执行
includeperm

5. 权限添加完成!

其它说明:


文件名为权限组名称,文件后缀不限


例如：


player.txt

player.text

player.perm

...

权限文件放置目录


plugins\IncludePermission\permissions
