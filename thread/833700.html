　前言　
本来想在生存服弄个战斗信息的
但是要不就是只支持玩家PVP
或者变量太少
或者就是一些大型RPG插件的附属
于是就写了这个插件2333


　插件简介　
一个战斗信息插件
其实我也不知道适配什么版本
不过1.8水龙头有效
毕竟我是看1.12BukkitDoc用1.8Spigot包写的
代码也没什么特殊


　插件功能　
  • 配置简单，一目了然
  • 变量多达6个
  • 信息全部自定义
  • 支持俩个特殊符号
  • 完美弓箭判断
  • 击杀射杀信息
  • 三种信息显示方式
  • ActionAnnouncer/Title/Message
  • 自带小数修复，你绝对不会看见比如2.333333之类的东西
  • 区分玩家PVP与PVE,你可以设置不同的信息!
    ......
  • 目前的变量:
  • 攻击伤害
  • 真实攻击伤害
  • 攻击者昵称
  • 攻击者血量
  • 被攻击者昵称
  • 被攻击者血量
  • (Player)攻击者等级
  • (Player)攻击者显示名
  • (Player)被攻击者等级
  • (Player)被攻击者显示名
  • 以及有一个小问题的[exp]变量:击杀掉落得经验


　命令/权限　
无
以后也不会有的


　Config/配置文件　
仅供参考(话说上色真麻烦)
Config.yml
  • #
  • #注意:颜色代码请使用§
  • #
  • #变量: (注意，请小写。)
  • #  [s0] 攻击伤害值
  • #  [s1] 真实攻击伤害
  • #  [s2] 攻击者的Name
  • #  [s3] 被攻击者的Name
  • #  [s2hp] 攻击者的hp
  • #  [s3hp] 被攻击者的hp
  • #近战攻击提示的信息
  • 近战攻击信息: "§f<§e战斗信息§f> §7您攻击§f[s3]§8§o(§c[xin]§8§o[s3hp])§7,造成了§c[s1]§8§o([s0])§7伤害."
  • #被近战伤害提示的信息
  • 被近战伤害信息: "§f<§e战斗信息§f> §7您被§f[s2]§8§o(§c[xin]§8§o[s2hp])§7攻击,受到了§c[s1]§8§o([s0])§7伤害."
  • #弓箭攻击命中的信息
  • 弓箭命中信息: "§f<§e战斗信息§f> §7您射中了§f[s3]§8§o(§c[xin]§8§o[s3hp])§7,造成了§c[s1]§8§o([s0])§7伤害."
  • #被箭射中的信息
  • 被箭射中信息: "§f<§e战斗信息§f> §7您被§f[s3]§8§o(§c[xin]§8§o[s3hp])§7射中,受到了§c[s1]§8§o([s0])§7伤害."
  • #如果对方被砍死(近战)的信息
  • 砍死对方信息: "§c击杀!最后一刀伤害:§l[s1]"
  • #如果对方被射死（远程）的信息
  • 射死对方信息: "§c射杀!最后一箭伤害:§l[s1]"
  • #提示信息: (Action就是状态栏上面的信息要前置插件) (0是关闭 1是开启) (可多个)
  • 提示到聊天栏: 1
  • 提示到Action: 1
  • 提示到subtitle: 1
  • # 提示到subtitle的信息:
  • #PS:都是小标题! 都是不同的,参照上面
  • #加空格可以适当的移动title的位置防止遮挡视线
  • 攻击st提示: "§a[s3hp]               "
  • 被攻击st提示: "§c!                  "
  • 击杀st提示: "§e击杀!                         "
  • 射杀st提示: "§e射杀!                         "

远程射箭(emm截不到射箭的图)
