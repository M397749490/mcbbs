This plugin is no longer supported.

I have not updated this plugin in over a year, I barely even play Minecraft anymore, I've gotten a full-time job, and nobody else on the team is interested in developing it either. It's time to put it to rest. With the release of name changing in Minecraft 1.8, this plugin is no longer functional. Please do not use it anymore. The code is mediocre at best, and was written by a college student with no real-world programming experience. You really shouldn't want the source code. If somebody comes up with a script to convert BOSEconomy files to work with a different economy plugin, let me know via PM and I can include it on this page.

Thanks for the support I got while it lasted, and sorry for going silent and letting everyone down.


（注意，此插件不再更新！以上是作者原文。推荐使用FeatherEconomy插件）
相信有很多人都熟悉iConomy，iConomy一向以好用，简便著称。但是自从2012年愚人节过后iConomy就停止了更新，虽然插件还是可以继续使用的，但是一些问题也暴露出来，比如说：iConomy会丢失玩家所有的金钱数据 之类的，Lz我是亲身经历过这种情况的，所以我为大家带来了一款新的经济插件，也就是BOSEconomy。

注：此插件为原版，未经汉化。
适用版本：1.4.5~1.6.2 （可用在MCPC+上）（1.6.4,1.7.2可用。经 @gdfszzj 测试支持1.8spigot服务端 ， Bug未知，请谨慎使用！）

特点（机翻+手翻）：

简单：安装和设置非常简单。将与您服务器对应版本的插件放在你的plugins文件夹并启动一次服务器。

灵活：强大的系统能够容纳的最简单经济的设置与最复杂的经济设置。

可靠：我们的插件可以兼容几乎全部的Bukkit。（在新版的Bukkit里无需长时间等待插件更新）

标准：插件的API，如Vault和Register支持。使用Vault和Register为核心，任何插件都可以与此插件兼容且不需要改变任何的代码。

可扩展：控制服务器的经济，根据服务器的大小。随着游戏的命令来修改插件，几乎每一个方面你都能控制。

别出心裁：制定程序，给予服主与“天空才是极限”的心态。随着选项和控制，几乎插件的每一个方面都有数以百计处理方法，形成经济体系。

可靠：这个插件不断测试与维护。其中最恼人的因素，服务器所有者是当一个插件丢失，因为在的Minecraft业主漠不关心的支持。这不会发生这个作为我的社区服务器是很受欢迎，被证明是对我们的游戏需求的基石。

安装：
将与服务器对应版本的插件拖入服务端“plugins”文件夹即可（注意：请先打开下载的zip文件，再把当中的jar文件拖入“plugins”文件夹）


指令（我省略了一部分不常用的XD 机翻+手翻）：
  1. /econ help [页数]
  2. 权限: BOSEconomy.common.help
  3. #列出的插件命令，并简要介绍它们。

  5. /econ
  6. 简化指令: /wallet, /money
  7. 权限: BOSEconomy.common.wallet
  8. #显示你有多少钱

  10. /econ income [页数]
  11. 权限: BOSEconomy.common.income
  12. #列出你的收入和支付率。

  14. /econ pay <玩家> <钱数>
  15. 简化指令: /pay <玩家> <钱数>
  16. 权限: BOSEconomy.common.pay
  17. #付钱给其他用户或银行帐户。只允许支付给在线玩家。支付银行账户，请在前面加上一个“$”符号，以它的名字（例如：$ Bank01）。

  19. /econ info <玩家> [页数]
  20. 权限: BOSEconomy.admin.money.info
  21. #列出一个玩家或银行账户的收入。

  23. /econ mastery [页数]
  24. 权限: BOSEconomy.common.mastery
  25. #列出括号。

  27. /econ viewmastery <玩家> [页数]
  28. 权限: BOSEconomy.admin.viewmastery
  29. #列出一个玩家或银行帐户的主人。

  31. /econ add <玩家/银行> <钱数>
  32. 权限: BOSEconomy.admin.money.add
  33. #给予玩家或银行帐户钱。

  35. /econ sub <玩家/银行> <钱数>
  36. 权限: BOSEconomy.admin.money.sub
  37. #减去一个玩家或银行帐户钱。

  39. /econ set <玩家/银行> <钱数>
  40. 权限: BOSEconomy.admin.money.set
  41. #设置一个玩家或银行帐户的钱。

  43. /econ clear <玩家/银行>
  44. 权限: BOSEconomy.admin.money.clear
  45. #将一个玩家或银行帐户的钱清零。

  47. /econ stats
  48. 权限: BOSEconomy.common.stats
  49. #显示服务器玩家总金钱数，平均货币和平均收入。（不包含银行账户）

  51. /econ top5
  52. 权限: BOSEconomy.common.top5
  53. #列出服务器金钱排名前五名的玩家

  55. /econ bank create <银行> [业主] [成员]
  56. 权限: BOSEconomy.admin.bank.create
  57. #创建一个具有指定所有者和成员一个新的银行帐户。如果你只是想添加成员，用“@none”帐户组标记。（例如：“ /econ bank create Bank01 @none Member,AnotherMember ”）

  59. /econ bank remove <银行>
  60. 权限: BOSEconomy.admin.bank.remove
  61. #删除一个银行帐户。

  63. /econ bank rename <银行> <名称>
  64. 权限: BOSEconomy.common.bank.rename BOSEconomy.admin.bank.rename
  65. #重命名一个银行帐户。普通权限允许银行所有者重命名他们的银行帐户。

  67. /econ bank list [页数]
  68. 权限: BOSEconomy.common.bank.list
  69. #列出所有银行账户

  71. /econ bank info <银行> [页数]
  72. 权限: BOSEconomy.common.bank.info BOSEconomy.admin.bank.info
  73. #列出收入阶层的一个银行账户，其总收入。普通权限允许玩家查看自己的银行账户信息。

  75. /econ bank mastery <银行> [页数]
  76. 权限: BOSEconomy.common.bank.mastery BOSEconomy.admin.bank.mastery
  77. #列出的银行账户的主人。普通权限允许所有者查看其银行账户的掌握。

  79. /econ bank listmembers <银行> [页数]
  80. 权限: BOSEconomy.common.bank.listmembers BOSEconomy.admin.bank.listmembers
  81. #列出的银行账户的玩家。普通权限允许所有者查看其银行帐户的成员列表。

  83. /econ bank withdraw <银行> <钱数>
  84. 权限: BOSEconomy.common.bank.withdraw BOSEconomy.admin.bank.withdraw
  85. #从银行账户提取资金。普通权限允许银行成员，从他们的银行账户中提取资金。

  87. /econ bank deposit <银行> <钱数>
  88. 权限: BOSEconomy.common.bank.deposit
  89. #将钱存入到一个银行账户。这是提供给所有玩家的，不仅仅是银行帐户的成员。

  91. /econ bank addowner <银行> <玩家>
  92. 权限: BOSEconomy.common.bank.addowner BOSEconomy.admin.bank.addowner
  93. #增加一个玩家的银行账户。如果玩家已经是成员，它??们将被更改为所有者。普通权限允许所有者添加其它玩家到他们的银行账户。

  95. /econ bank addmember <银行> <玩家>
  96. 权限: BOSEconomy.common.bank.addmember BOSEconomy.admin.bank.addmember
  97. #增加一个玩家的银行账户。如果玩家已经是所有者，他们都更改为成员。普通权限允许所有者将成员添加到自己的银行账户。

  99. /econ bank removemember <银行> <玩家>
  100. 权限: BOSEconomy.common.bank.removemember BOSEconomy.admin.bank.removemember
  101. #移除一个银行帐户的成员或所有者。普通权限允许一名业主从他们的银行帐户中删除的业主或成员。

  103. /econ request list [页数]
  104. 权限: BOSEconomy.common.request.list
  105. #列出您发送与接收的请求。

  107. /econ request do <请求> <行为>
  108. 权限: BOSEconomy.common.request.do
  109. #执行请求的操作。有效的行为是“cancel（取消）”的发送请求，“accept（接受）”或“reject（拒绝）”收到的请求。

  111. /econ payday reset
  112. 权限: BOSEconomy.admin.payday.reset
  113. #重置工资计时器。这将初始化在任何时间命令发送的工资的时间间隔。从这个时间点，时间间隔继续正常进行。这不提示即时工资发生，它设置它的命令是用来后出现一次工资的间隔。

  115. /econ about
  116. 权限: BOSEconomy.common.about
  117. #显示插件的版本号。
