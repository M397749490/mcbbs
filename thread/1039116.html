介绍
本插件可通过指令记录你手上物品的信息到插件里
然后根据单独的编号，可通过指令快速给予玩家物品
指令的用途非常广，甚至可以当kit使用

新版本支持NBT查看储存的物品，并且能通过ID来进行储存（后台也能存物品了）
更重要的是，支持指定玩家使用和限时使用
比如发放无尽剑，锁定后主人可以随意用，其他人捡到了无法使用（但可拾取，防止扫地大妈）
或者是让某个人在10分钟内免费使用无尽剑，过期使用则自动清理


特点
本插件记录的物品完全支持NBT
对模组服/RPG服极其友好
兼容性高，大多数版本都支持
支持列表显示物品属性、锁定玩家使用和使用时限


指令、配置文件和权限组
指令
  1. /ic help  使用说明
  2. /ic list  显示所有编号的物品信息
  3. /ic del 编号  删除这个编号下的物品
  4. /ic save 编号 [物品ID] 以编号为...保存手上/此ID下的物品
  5. /ic give 编号 [玩家] [数量]  给予玩家这个编号的物品
  6. /ic lock 编号 [玩家] [数量]  给予锁定后的物品（只能此玩家使用）
  7. /ic time 编号 时间 [玩家] [数量]  设置此物品使用时限（分钟）
  8. /ic all 编号 时间 [玩家] [数量]  既设置时限也锁定使用
  9. /ic reload  重载
复制代码


配置文件
  1. #给予成功时，是否向发送者发送提示
  2. GivedMessage: true

  4. #是否提醒被给予物品的玩家
  5. GiveMessage: true
  6. #提醒的信息
  7. #[item]物品的名称
  8. Message: "&a收到&f[item]&a物品成功"


  11. #设置锁定物品时显示的lore前缀
  12. LockLore: '&a此物品&4已锁定&a，持有者： &6'
  13. #锁定后被别人使用的提示（禁止使用）
  14. LockMessage: '&c你不是此物品的主人！无法使用！'

  16. #设置拥有时限时显示的lore前缀
  17. TimeLore: '&a此物品&4到期&a时间： &6'
  18. #超出时限后再次使用的提示（清除后）
  19. TimeMessage: '&c此物品已到期'
