作者: 凯文丶    时间: 2015-12-5 20:53
首先，连接VPS（废话），安装JAVA7/8
新建个文件夹，文件夹内放一个核心文件和一个bat后缀的文件，
bat文件内容为
  1. [url=home.php?mod=space&uid=39305]@echo[/url] OFF
  2. title 你想要的标题
  3. pause
  4. :MAIN
  5. cls
  6. java -Xms512M -Xmx512M -jar spigot-1.7.2-R0.4-SNAPSHOT.jar
  7. if exist "plugins\RestartEvolution\restart.mcs" goto MAIN
  8. if not exist "plugins\RestartEvolution\restart.mcs" goto END
  9. :END
  10. echo.
  11. pause
复制代码

其中Xms512M -Xmx512M是分配的内存。
jar spigot-1.7.2-R0.4-SNAPSHOT.jar是核心文件的名字
bat文件编辑好后，双击打开，服务器就可以开了。
