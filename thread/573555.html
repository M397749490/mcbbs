他的意思就是说：
用户组最低级别的是Default组，Builder组继承Default组。如果楼主设定的VIP组和Builder组是并列关系，那么是继承Default组；如果是继承关系，VIP组是继承Builder组，Builder组又继承Default组。
综上所言，Default组就是最底层的组，你往Default里加权限，其他上层的组都会获得权限。
所以在Default组加这条领地权限：residence.create
在Default组加这三条地皮权限：plotme.use，plotme.use.add和plotme.use.remove

作者: SO2    时间: 2016-4-8 13:13
地皮问题……具体还是要看你用哪个地皮插件和哪个权限组管理插件！需要把builder组设置为默认,我只列举一些基本权限设置
Groupmanager+plotme(红色部分为必须设置）：
                                       /mangaddp builder plotme.add
                                      /mangaddp builder plotme.use
                                      /mangaddp builder plotme.remove
                                     /mangaddp builder plotme.limit.1 （必须添加,这个玩家能领取的地皮数量)
(具体权限节点见http://www.mcbbs.net/forum.php?m ... 21&highlight=plotme）
Groupmanager+Plotsquared:
                                       /mangaddp builder plots.claim
                                      /mangaddp builder plots.unclaim
                                     /mangaddp builder plots.auto
                                     /mangaddp builder plots.plot.1
(具体权限节点见http://www.mcbbs.net/forum.php?m ... ghlight=plotsquared）
PEX部分
PermissionsEX+Plotme:
                                    /pex group builder add plotme.use
                                   /pex group builder add plotme.add
                                  /pex group builder add plotme.remove
                                 /pex group builder add plotme.limit.1

PermissionsEX+Plotsquared:
                                /pex group builder add plots.claim
                               /pex group builder add plots.unclaim
                              /pex group builder add plots.auto
                             /pex group builder add plots.plot.1
