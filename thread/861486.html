DungeonLife 地牢生活

努力的猎手也想变成考古家 球评分辽！


可为每个副本设置单独的世界在其中自动复制副本，并在一定时间后自动清理。

该版本为Free版本，只支持持续式副本，作为控制单个区域中玩家数量而起作用。

Premium版本尚在开发，将提供独立式副本，每个队伍一个副本，并有副本目标。


言归正传。

注: 副本世界请自行设定，如不可破坏，关闭怪物和动物的自动生成等,插件并不对其进行操作。

前置: MythicMobs(必须) PlaceholderAPI(非必须)


命令列表:


主命令/dungeon 简称/dun
/dungeon create <dungeonName> 创建一个副本。
/dungeon select <dungeonName> 选中一个副本。/dungeon delete 删除一个副本。
/dungeon set 设置副本相关。

  set部分有子命令 输入/dungeon set help查看
/dungeon join <dungeonName> 加入一个副本。

/dungeon exit 退出一个副本。
/dungeon list 列出所有副本并查看信息。
/dungeon help 帮助信息。

/dungeon reload 重载所有设定。

权限列表:

  • dungeonlife.dungeon
  • dungeonlife.dungeon.set
  • dungeonlife.dungeon.spawner



配置文件:
prefix: '&a[DungeonLife]'
Tool: 'GOLD_HOE'
#无人时持续多少秒清除区域
LastTime: "60*60"
Dungeons: {}


插件变量: %dungeonlife_current% 显示玩家当前所在区域

推荐设定
display (副本展示名，在变量中显示，支持颜色符号)
