Biomes O' Plenty (BOP) 模组介绍


（大概这个介绍一时半会更不完）


Biomes O' Plenty 是一个由 Glitchfiend 团队开发的环境类模组，添加了新生物群系并优化了原有生物群系，与绝大部分模组兼容性优良。其目前涵盖 1.6.4 至 1.16.4 版本，其中包含大量新物品、新方块、新生物群系、新植物、新矿物等等。

本次以 1.12.2-7.0.1.2444、1.16.4-13.0.0.422 版本、各个维基与 943 的视频上的资料信息给大家介绍。

零、基础设置

0.1   生成设置
    该模组运行需要 Forge 环境，将文件放入 /mods 文件夹安装。
   
    客户端中：
    默认需要选择“超多生物群系”来生成世界，才能生成新生物群系。
    服务端中：
    （1.12.2 及以下）需把 level-type=DEFAULT 改为 level-type=BIOMESOP，才能生成新生物群系。
    （1.12.2 以上）需把 level-type=DEFAULT 改为 level-type=biomesoplenty，才能生成新生物群系。

    若想要在旧存档中生成新生物群系：
    对于原本以“超多生物群系”方式生成的世界，可以选择删除已加载的区块让其重新生成；
    对于原本以其他世界类型方式生成的世界，则需使用 NBT 编辑器更改世界生成选项再使其重新生成。

    自定义：
    （1.12.2 及以下）超多生物群系下的“自定义”按钮提供更为细致的调整。

0.2   杂项设置
    模组游戏内杂项设置（1.12.2）如下：
游戏内设置
便捷设置 > Flower Drops Need Shears    默认 false
                 决定是否用剪刀才能剪下花朵。
GUI设置 > Default to BoP World Type    默认 false
                  决定是否默认世界生成就生成模组新特性。
                  该设置调整后服务端也可不调整 level-type 的值。
材质设置 > Enable Biomes O' Plenty Main Menu Panorama    默认 true
                  决定是否在首页使用BOP全景图。
材质设置 > Enable Fog Colouration    默认 true
                  决定是否对不同生物群系中迷雾颜色进行修改。（貌似是为了Dynamic Surroundings）
                  该设置可能会使部分带有迷雾颜色的生物群系光影效果错误。

0.3   Config 文件
    1.12.2 及以下：
       该模组的 config 文件位于 .../.minecraft/config/biomesoplenty 目录下。
       该目录下含 /biomes、biomes_ids.json（生物群系ID）、gameplay.cfg（便捷设置）、misc.cfg（GUI设置与材质设置）
       /biomes 目录下含 /defaults 与名为 "Put biome config files here" 的无后缀文件
       /defaults 目录下含 /biomesoplenty 与 /vanilla 目录，分别储存对应生物群系生成用代码（.json 格式）
       （config嵌套不嫌多）
    1.12.2 以上，待测试：
       该模组无 config 文件，也无法从游戏内访问配置页面。
       在 .../.minecraft/config/biomesoplenty 目录下含 server.toml 。

一、生物群系（1.12.2）

生物群系是这个模组最为重要的组成部分。

在目前的版本（1.12.2-7.0.1.2444）中，该模组新添了 73 个生物群系，同时也调整了原版生物群系的生成内容，介绍时原版生物群系的修改内容不包含在内。
所有图片出自 Fandom 维基、GitHub 维基、FTB 维基、官方生物群系相册或是由玩家贡献。（多图警告）
生物群系名称使用自己的翻译。（然而翻译的并不好，实在不好就用 943 的啦）

为不影响游戏内探索体验及探索乐趣，各个生物群系不会过于详尽的介绍。（同时也是因为懒）

权重实际为“生成权重”，使得生物群系会在对应气候位置生成。
后方注释可能会有不符合新版本源码的地方。（部分类似柯本气候分类法中的名称，感谢维基百科）

三、植被

植被是一个生物群系的基础，也是初次访问者对那个生物群系留下的第一层印象。（大部分情况下也是最后一层）
这里的植被是指其他一切不属于树木的植物、菌类等（有点不对），是生成在每一个生物群系里的各种植物（草方块什么的就不列在这里了）。

不过在现实中树木应当归入植被中，在 Fandom 维基上也有体现，但是因为容易出现分类问题所以作罢。
