★功能★
给某条指令加上一个此插件的使用权限，玩家需要拥有该插件给出的权限或者处在白名单中的世界才能使用此命令。
插件本意是为了防止服务器插件被偷窃。

★独道之处★
1、禁止的指令都有一条子权限，只要给予该权限，依然可以使用此命令。

2、可以给每条所禁止的命令添加一条无权限提示，注意：是每条命令。

3、世界白名单：添加到白名单中的世界将不受此插件的影响。

4、很多命令都带有参数，这是很多插件没有解决的一个问题，但是我解决了~


★指令与权限★
指令
/nps 查看此插件的信息
/nps help 插件帮助
/nps add <命令> 给这条命令加上一个使用权限 给带有参数的命令添加权限请在主命令后加*号 例: /nps add gamemode*
/nps remove <命令> 移除这个命令
/nps whitelist add <世界名> 将此世界添加到白名单中 (加入白名单中的世界不受此插件影响)
/nps whitelist remove <世界名> 将此世界从白名单中移除
/nps reload 重载配置文件 插件help中没有reload项.请记住这个参数。
重载指令只能在游戏中输入，控制台输入无效。

权限

NoPluginStealers.bypass.指令      指令的使用权限   例:NoPluginStealers.bypass.?
NoPluginStealers.reload      重载配置权限
NoPluginStealers.admin    使用add/remove权限
