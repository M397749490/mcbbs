2019年8月25日魔改重制版已更新



介绍
简而言之ExoticGarden是Slimefun插件的一个扩展，它新增了大量的新植物、新食物，可以极大地丰富玩家的生存体验。而重制版则在汉化ExoticGarden了的基础上，更是加入了全新内容和对玩法内容进行了平衡。可以说是一个安装了Slimefun的服务器必备的一个扩展。
关于这个重置版ExoticGarden的提示
这个重置版基于最新的ExoticGarden 1.6.3进行了重制，所有物品名称均已汉化，不会出现物品不可用的情况，大家可以放心使用。
新的物品，这里我就不翻译了，插件里面的我都是翻译好的。
重制版新增的物品请看下方。
这个重置版有什么变化的内容？
  • 新增：酒曲，用于酿酒
  • 新增：酒类食物，含数十种酒，有独特的效果
  • 新增：金坷垃，专门用于催化ExoticGarden的作物
  • 新增：新植物，潜影壳异化植物
  • 新增：新植物，仙馐果
  • 新增：新植物，酒香果
  • 新增：机器，种子分析机
  • 新增：机器，酒曲培养机
  • 新增：机器，电力酿造机
  • 异化植物配方重制，现在变得比较平衡了
  • 修复了刷锄头的问题   
  • 修改了异化植物粉末的材质

感谢@XJue_DaDa提交的问题
如果你的服务器开放了爆炸镐(Slimefun的内容)的使用，
请将爆炸镐的配置文件(位于/plugins/slimefun/items.yml)添加上三个禁止破坏方块，以免出现问题，如下:
  1. EXPLOSIVE_PICKAXE:
  2.   enabled: true
  3.   can-be-used-in-workbenches: false
  4.   allow-enchanting: true
  5.   allow-disenchanting: true
  6.   required-permission: ''
  7.   unbreakable-blocks:
  8.   - BEDROCK
  9.   - SKULL
  10.   - LEAVES
  11.   - SPALING
  12.   wiki: https://github.com/TheBusyBiscuit/Slimefun4/wiki/Explosive-Pickaxe
  13.   hide-in-guide: false
