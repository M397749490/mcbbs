作者: Jecvay    时间: 2016-3-2 11:08
1. 你的CoreProtect使用的是SQLite数据库, 就是用一个 .db 文件作为数据库存放, 可以在 CoreProtect 目录下面吧这个文件删除或者剪切掉, 重启服务器让其重新生成, 排除DB文件错误或者磁盘权限问题;

2. Java连接数据库需要使用JDBC, 尝试重新安装 Java 或者更新(或者降低) Java 版本;

3. 重新下载 CoreProtect 插件, 地址 http://dev.bukkit.org/bukkit-plugins/coreprotect/files/
