如果你为了服务器管理插件太多导致想进行配置时苦恼，那么你就需要此插件——SOUP



简介

此插件集经济、聊天、传送、邮件、登录等等为一身，让大家不用花很多时间去找插件。（真的好"简"）



SOUP的特色
1.密码：玩家注册系统。 玩家必须设置一个密码来保护他们在服务器上的帐户。这是任何“离线”服务器必须具备的功能，也是“在线”服务器必须具备的附加功能。
2.经济：一个简单的经济插 件，支持银行！ 基于金库的经济性，所有非弃用的方法都已实现。 老实说，任何经济都足够好。你不必用数十亿不同的硬币来复杂化你的生活。支持银行，如果你还用的话。
3.传送请求：玩家可以使用/tpask和/tphere来回传送 生存服务器中的必备组件。允许玩家直接互动。 指定您接受的请求！你不会再接受不需要的请求了！如果有多个请求，则需要指定请求发件人。 黑名单功能！世界可以被列入传送黑名单。玩家将无法从这些世界传送或传送到这些世界。
4.Warps和Spawn：创建称为Warps的传送坐标以及服务器出生点（基本上是服务器大厅）。 任何受人尊敬的服务器都必须有。 黑名单功能！世界可以被列入传送黑名单。玩家将无法传送这些世界的。
5.其他必需的命令：/heal, /feed, /invsee等。
6.完全可翻译。（麻麻再也不用担心我看不懂英文了） 每条信息都可以更改 标签有助于翻译过程。它们看起来像{这个}。 想要颜色吗？如果您使用Windows，请按Alt+2+1将此符号放在lang.yml中
7.高度可配置。 可以配置许多功能。 所有命令都有权限检查。 您可以请求配置此插件的任何方面。
所以本插件是一款居家旅行必备插件



食用方法
1.你需要前置插件：Vault
和 TickTime  ；还要一款你喜欢的权限插件（作者推荐LuckPerms）
（去 https://www.spigotmc.org/resources/ 这里搜以下就有了）
2.把此插件和刚才提到的那些插件放进plugins文件夹，运行服务器。




电子邮件
如何创建电子邮件
1.在服务器里注册
2.输入指令： /email set <你的邮箱账号>
3.很好，如果你想要你的密码，输入：/email send

消息会自动发送到您的电子邮件中，可以通过修改安装此插件时创建的email.txt文件来切换此消息。注意，该文件包含一个{password-holder-block}标记，它应该是html格式的。你可以使用this editor 来制作你自己的邮件。

要恢复电子邮件系统，请执行以下操作：

1.安装插件，如上所述。

2.打开credentials.yml文件。在config.email里，配置主机、用户、密码和标题。

3.重新启动服务器，就完成了！

    • 权限：soup.admin.cmd.adventure

    • 权限：soup.admin.cmd.suicide

  • /thunder
    • 权限：soup.admin.cmd.thunder

  • /invsee
    • 权限：soup.admin.cmd.invsee

  • /feed [player]
    • 权限：soup.admin.cmd.feed
    • 注释：既可自用也可对他人使用。

  • /heal [player]
    • 权限：soup.admin.cmd.heal
    • 注释：既可自用也可对他人使用。

    • 权限：soup.admin.cmd.setspawn

  • /soup reload
    • 权限：soup.admin.cmd.reload

  • /soup exportlang
    • 权限：soup.admin.cmd.exportlang

  • /tpask <player>
    • 权限：soup.user.cmd.tpask

  • /tphere <player>
    • 权限：soup.user.cmd.tphere

  • /tpok [player]
    • [权限：soup.user.cmd.tpok

  • /tpno [player]

    • 权限：soup.user.cmd.tpno

  • /tpcancel
    • 权限：soup.user.cmd.tpcancel

  • /warp
    • 权限：soup.user.cmd.warp

  • /warp <name>
    • 权限：soup.user.cmd.warp

  • /warp <name> set
    • 权限：soup.admin.cmd.warp

  • /warp <name> del
    • 权限：soup.admin.cmd.warp

  • /eco set <player> <amount>
    • 权限：soup.admin.cmd.eco

  • /eco deposit <player> <amount>
    • 权限：soup.admin.cmd.eco

  • /eco withdraw <player> <amount>
    • 权限：soup.admin.cmd.eco

  • /money [player]
    • 权限：soup.user.cmd.money (Self)
    • 权限：soup.admin.cmd.money (Others)

  • /pay <player> <amount>
    • 权限：soup.user.cmd.pay

  • /email
    • 权限：soup.user.cmd.email
    • 注释：显示您当前的电子邮件（如果有）。

  • /email set <your e-mail>
    • 权限：soup.user.cmd.email

  • /email send
    • 权限：soup.user.cmd.email
  • /password
    • 权限：soup.user.cmd.password
    • 注释：显示如何加密密码。

  • /password <old password> <new password> <new password>
    • 权限：soup.user.cmd.password
    • 注释：允许玩家更改密码。

  • /register <password> <password>
    • 权限：soup.user.cmd.register

  • /login <password>
    • 权限：soup.user.cmd.login
  • /logout
    • 权限：soup.user.cmd.logout
    • 注释：删除玩家的身份验证。当玩家进入服务器时，会触发相同的效果。

  • /unregister <password> <password>
    • 权限：soup.user.cmd.unregister 注释：删除玩家的帐户。如果在离线服务器上游玩，任何其他用户都可以使用此帐户。
