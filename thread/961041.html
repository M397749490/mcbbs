Gravy
永不丢失您的物品
Spigot Mc:https://www.spigotmc.org/resources/gravy.45288/
简介
这是一个死后保存物品到墓碑的插件,玩家死亡后在玩家的位置生成坟墓，破坏墓碑即可获得物品,生成的坟墓防爆以及活塞的推动,可以用命令来显示坟墓位置并传送。

配置文件
  1. debug_mode: false #debug模式
  2. enable_chat_prefix: true #前缀
  3. chat_line_color: '&2' #前缀颜色
  4. do_safe_grave_spawn: true #是否在安全的地方生成墓碑
  5. save_timer: 60 #保存时间
  6. grave_timer: 1200 #墓碑存在时间 以秒计算
  7. enable_timer: true #墓碑是否会消失
  8. grave_block: DIRT #墓碑下的方块 默认是泥土
  9. spawn_zombie_on_not_owner_break: true #在破坏他人墓碑时是否生成僵尸
  10. spawn_zombie_on_owner_break: false #破坏墓碑时生成僵尸
  11. zombie_hp: 20 #僵尸血量
  12. can_zombie_pickup_items: true #僵尸是否可以拾取物品
  13. execute_command_on_respawn: false #复活时执行命令
  14. execute_command_on_grave_break: false #破坏墓碑时执行命令
  15. command_: ''
  16. command_on_grave_break: ''
  17. drop_items_on_player_kill: false #被玩家击杀时是否掉落物品
  18. enable_token_use: true #是否开启令牌的使用
  19. enable_token_craft: true #令牌的制造
  20. enable_token_drop: true #是否可以丢出
  21. token_drop_mob: GHAST #怪物可以掉落令牌
  22. token_drop_amount: 1 #数量
  23. token_drop_chance: 0.05 #机率 0.05=百分之五
  24. token_item: MAGMA_CREAM #令牌的模型 下面是合成配置
  25. token_craft_recipe: GOLD_INGOT:GOLD_INGOT:GOLD_INGOT-GOLD_INGOT:DIAMOND:GOLD_INGOT-GOLD_INGOT:CHEST:GOLD_INGOT
  26. use_vault: false #是否开启花费金钱生成墓碑
  27. grave_cost: 500 #花费数量
  28. enable_worldguard_support: true #是否开启worldguard支持 下面是世界的启用

复制代码

注意事项
只有玩家身上有物品时才会生成墓碑,有Gravy.break权限的人可以破坏任意墓碑但不能破坏有Gravy.protected权限的玩家墓碑。
如果需要破坏墓碑时生成僵尸在配置文件中将spawn_zombie_on_owner_break 设置为true,死于熔岩或水中墓碑将在死亡位置上方生成。
有gravy.info权限的玩家可以右键墓碑查看信息,可以在配置中设置是否开启令牌,开启以后玩家需要身上带有令牌才会生成墓碑,合成配方可以自行更改。
注意：如果不开启死亡掉落可能会导致刷物品,墓碑一份身上一份
