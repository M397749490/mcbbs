§m        删除线

要得到彩色告示牌，或者格式化文本，你需要输入\u00a7代替§。例如，§5会变成\ u00a75。下面列出全部列表。

Code        Official Name
MOTD code

§1        深蓝色        \u00A71

§3        湖蓝色        \u00A73
§4        深红色        \u00A74
§5        紫色        \u00A75
§6        金色        \u00A76
§7        灰色        \u00A77
§8        深灰色        \u00A78

§a        绿色        \u00A7a

§l        粗体        \u00A7l
