这是一个创建NPC银行用以保管物品的插件，每个玩家都可以最多拥有54个仓库

可以创建N家银行

具备物品分类功能

每个玩家在银行中都只能看到自己的东西，不存在偷窃~~~

你唯一需要担心的就是管理员把你的数据库给删除了= =

嗯，箱子插件什么的可以去死了

可选前置插件：vault(只是为了配合仓库购买使用的，如果想免费买仓库，可以不用)

命令：
  1. /gb create [名称] - 创建一家银行
  2. /gb delete - 删除一家银行
  3. /gb face - 改变一家银行的朝向
  4. /gb help - 查看帮助
  5. /gb info - 显示插件信息
复制代码

权限：
  1. # 创建银行
  2. gb.create
  3. # 删除银行
  4. gb.delete
  5. # 使用face指令
  6. gb.face
  7. # 使用help指令
  8. gb.help
  9. # 能够使用银行
  10. gb.use
  11. 最多能够购买多少仓库，数字只能是：9、18、27、36、45、54
  12. 比如：mangaddp default gb.slots.9
  13. gb.slots.数字
复制代码

配置：
  1. Economy:
  2. # 每格仓库递增价格
  3.   CostPerSlot: 20
  4. # 启用经济
  5.   UseEconomy: true
  6. # 仓库递增乘数. 6号仓库是40元，7号仓库就是40+20*2=80元
  7.   ProgressiveSlotMultiplier: 2
  8. Slot:
  9. # 哪格仓库开始需要购买
  10.   BeginWith: 5
复制代码
