发射火球,以僵尸为例子,你得给僵尸加上一个boss的nbt
  1. execute at @e[type=zombie,tag=boss] positioned 0.0 0.0 0.0 run summon minecraft:armor_stand ^ ^ ^2 {NoGravity:1b,Tags:["marker"]}
复制代码
  1. execute at @e[type=zombie,tag=boss] anchored eyes positioned ^ ^ ^1 run summon minecraft:fireball ~ ~2 ~ {direction:[0.0d,0.0d,0.0d],power:[0.0d,0.0d,0.0d],Tags:["fire_ball"]}
复制代码
  1. execute as @e[type=minecraft:fireball,tag=fire_ball] run data modify entity @s direction set from entity @e[limit=1,type=minecraft:armor_stand,tag=marker] Pos
复制代码
  1. kill @e[type=minecraft:armor_stand,tag=marker]
复制代码
  1. tag @e[type=minecraft:fireball] remove fire_ball

/summon minecraft:zombie_horse ~ ~1 ~ {Passengers:[{HandItems:[{id:"minecraft:iron_sword",Count:1b},{}],ArmorItems:[{id:"minecraft:diamond_boots",Count:1b},{},{id:"minecraft:iron_chestplate",Count:1b},{}],id:"minecraft:zombie"}]}比如这里,生成一只骑着僵尸马的僵尸，僵尸穿着铁胸甲，钻石鞋，手里拿着铁剑
HandItems:手里的物品
后面的[{id:"minecraft:iron_sword",Count:1b},{}],第一个{}里为主手武器,第二个为副手武器
ArmorItems:身上的装备
后面的[{id:"minecraft:diamond_boots",Count:1b},{},{id:"minecraft:iron_chestplate",Count:1b},{}],id:"minecraft:zombie"}]
有4个{},顺序依次为从该生物的脚到头
