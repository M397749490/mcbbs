作者: xiaodidi1985    时间: 2018-9-14 13:34
需要提前设置临时数据从世界数据读取
@Override
    public Object getClientGuiElement(int ID, EntityPlayer player, World world, int x, int y, int z){
        switch (ID){
                case ZiDingYiSuiDaoZhaDan:
                        rtTileEntityRepairTable c = (rtTileEntityRepairTable)H4acda_mod.world.getTileEntity(x, y, z);
                        player.worldObj.setTileEntity(x, y, z, c);
                        rtTileEntityRepairTable a = (rtTileEntityRepairTable)player.worldObj.getTileEntity(x, y, z);
                        int[] b = {x,y,z};
                        return new rtGuiRepairTable(player.inventory, a, b);
                default:
                    return null;
        }
    }
这样运行快很多
