Preface | 前言（English | 英语版）：

Have you ever thought about leaving the planet Earth and running away to the moon? No? Me neither. Good! Although you've never thought about it, this plugin is for you! With a simple command you will create the moon, and with another simple command you can go there! CAREFUL! There is no gravity in the moon, so be careful not to get out of the orbit! (Despite being a stupid jump effect). An idiot has decided to genetically modify the mobs of the moon, so they will be upgraded, especially the skeletons! In this planet the mineral spawn is wider (if the idiot who set the server has set the percentages well).


Preface | 前言（Chinese | 中文版）：

你有没有想过离开地球去月球呢？没有过？我也是一样。虽然你没有想过去月球，但是这个插件可以让你在mc去月球！用多世界插件创建一个月球（世界），并使用多世界传送指令去月球（世界）！月球上的重力只有地球的六分之一，小心一点哦！（尽管是一个愚蠢的跳跃+缓慢效果）。  一个人决定对月球的怪物进行基因改造，所以他们会升级变得更厉害，尤其是骷髅！在月球，矿物生成的更多（可以设置矿物生成比率）。

Plugins features | 插件特征


● Ability to set the spawning of the ores.
● Enhanced mob.
● Ability to set the gravity level.
● It is possible to connect the featherboard plugin by putting {oxygen} in the setting.
● The plugin needs Featherboard and mvdw placeholders to work.
● It is possible to change the crafting of the cans.
● The plugin is completely custom.



● 可以自定义矿物在月球的生成
● 月球有更强的怪物
● 可以设置在月球的重力
● 可以在 featherboard 插件内使用 {oxygen} 变量查看氧气值
● 插件可以使用Featherboard 和 mvdw 占位符工作（楼主：但是没有2个插件会报错，不影响使用）
● 可以改变药水的制作配方
● 插件完全自定义

Use | 使用方法

Ability to create the world with multiverse, by doing "/mv create MoonWorld normal -g ToTheMoon".
Of course, you can also replace the MoonWorld with other names.

使用指令/mv create MoonWorld normal -g ToTheMoon来创造一个月球世界
你也可以不使用MoonWorld这个名字来创建月球
