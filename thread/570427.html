前言：动物坐骑Mod是一个能让你轻易召唤出可骑乘的动物或者其它生物的Mod，所有的坐骑都有着各自的属性/能力，在你制作这些坐骑之前你会需要一个马鞍，它们可以在地牢的箱子里找到或者通过下面的配方获得，该Mod单人多人均可

马鞍可以堆叠至8个
马鞍的合成需要三张生皮，一根线以及一块铁锭

生皮的合成

你还可以通过烧制腐肉获得更多的皮革


关于.minecraft/config/AnimalBikes.cfg
  • 使用文本编辑器来打开它，我推荐notepad++
  • 只能修改前面没有#的条目
  • 你可以禁用所有的坐骑
  • 你可以禁用马鞍的合成


就1.9版本而言，所有的坐骑如下：
末影龙坐骑



末影龙坐骑让你能够驾驭末影龙飞行，它的合成需要末地石，当你用打火石右键它时它会喷出火焰，默认情况下火焰是不会破坏地形的

  • 可染色
  • 按住空格向上飞
  • 会自动往下飞
  • 用打火石右键喷出火焰
  • 让地形受火焰破坏可使用命令/gamerule animalbikesTerrainDamage true
  • 禁止其飞行可使用命令/gamerule animalbikesFlying false




中国龙坐骑



中国龙坐骑让你能够驾驭中国龙飞行

  • 生成时有四种随机颜色
  • 按住空格向上飞
  • 按住键盘左边的Shift向下飞
  • 用火药右键可让它射出烟火
  • 禁止其飞行可使用命令/gamerule animalbikesFlying false




铁傀儡坐骑



铁傀儡坐骑让你能够驾驭铁傀儡，当你按空格时它会甩出手臂并攻击到周围的生物

  • 可染色
  • 当你按空格时可攻击到周围的生物
  • 像马一样自动上坡
  • 140点血量
  • 当攻击时会造成8-14点伤害




麋鹿坐骑



麋鹿坐骑让你能够驾驭麋鹿飞行，它是由云杉树苗合成的，在空中划过时会留下一道雪痕

  • 鼻子可以染成不同的颜色
  • 禁止其飞行可使用命令/gamerule animalbikesFlying false




雪傀儡坐骑



雪傀儡坐骑让你能够驾驭雪傀儡，当你试图跳跃时它会射出雪球，同样的，它也会在行走过程中留下雪片
  • 留下一道雪痕
  • 像马一样自动上坡
  • 可染色
  • 按下空格发射雪球




Notch坐骑



Notch坐骑让你能够驾驭一个巨大的Notch头颅，如果你尝试跳跃时它会吐出苹果。为什么会是苹果呢？如果你在服务器里杀了Notch的话他会掉落苹果，所以我觉得让它吐出苹果是比较合适的
  • 当你按下空格会吐出苹果
  • 像马一样自动上坡
  • 并不喜欢给予太多的苹果
  • 会尝试吃了你




牛坐骑



牛坐骑让你能够驾驭牛，牛可以跳得更高（两格），如果你给你的牛坐骑一个红蘑菇它会变成一只哞菇
  • 两格高的跳跃高度
  • 20%的几率召唤出一只小牛坐骑，它的行走速度也会减缓30%
  • 喂食红蘑菇可变为哞菇
  • 可染色




末影人坐骑



末影人坐骑让你能够驾驭末影人，当你试图跳跃时你和你的末影人坐骑都将随机传送至前方的某个位置
  • 空格随机传送
  • 像马一样自动上坡
  • 每一次传送需要5秒冷却
  • 同样会受到水的伤害并且它将不会传送进水里




猪坐骑



猪坐骑让你能够驾驭猪，一旦猪坐骑开始跑起来它将无法停下并且达到可怕的速度
  • 20%的几率召唤出一只小猪坐骑，它的行走速度也会减缓30%
  • 可染色



羊坐骑



羊坐骑能让你驾驭羊，羊坐骑真的非常普通，没什么特别的
  • 比其他坐骑稍快些
  • 20%的几率召唤出一只小羊坐骑，它的行走速度也会减缓30%
  • 可染色



蜘蛛坐骑



蜘蛛坐骑让你能够驾驭蜘蛛，只需对着墙走就可以爬墙了
  • 可爬墙
  • 比其它坐骑稍慢
  • 可染色



鸡坐骑



鸡坐骑让你能够驾驭鸡，鸡不会摔落，但在下降时会非常慢
  • 比其它坐骑行走得稍快些
  • 缓慢下降并不会受到摔落伤害

  • 20%的几率召唤出一只小鸡坐骑，它的行走速度也会减缓30%
  • 可染色



乌贼坐骑



乌贼坐骑让你能够驾驭乌贼，当它脱离水时它会站起来并且移动的十分缓慢，但在水里移动的是十分快的
  • 陆地移动慢
  • 水中移动快
  • 在水中通过空格上浮通过Shift下沉
  • 可染色



狼坐骑



狼坐骑让你能够驾驭狼，狼会攻击任何一个正在攻击你的人，如果你想让它停止攻击，只需在手上拿着一根骨头
  • 攻击每一位攻击你或者他的人
  • 攻击以十个方块为半径内的敌对生物
  • 随机攻击周围的羊
  • 如果你手持骨头它将不会攻击任何生物
  • 可染色




苦力怕坐骑



苦力怕坐骑让你能够驾驭苦力怕，喂食胡萝卜可以让它跑得更快
  • 受到攻击时20%几率爆炸
  • 20%几率召唤出高压苦力怕，爆炸时拥有更大的威力
  • 地形破坏可使用命令/gamerule animalbikesTerrainDamage true
  • 可染色




小马坐骑



小马坐骑让你能够驾驭小马，它包括4种类型：
大地小马：在走过时使泥土长草并随机生成花朵
独角兽小马：有着彩虹光辉粒子
飞翔小马：能飞
Alicorn小马：拥有所有小马的能力

同样，小马坐骑也能染色，以下貌似出自某动漫...所以不翻译了...
Black : Princess Luna
White: Princess Celestia
Red : Big Mac
Lapis : Rainbow Dash
Purple : Rarity
Light Gray: Derpy Hooves
Pink : Pinkie Pie
Yellow : Fluttershy
Light blue : DJ Pony
Magenta : Twilight Sparkle
Orange : Applejack

  • 包含54种小马
  • 可染色
  • 禁用飞行可使用命令/gamerule animalbikesFlying false




恶魂坐骑



恶魂坐骑让你能够驾驭恶魂，默认情况下你不能在主世界召唤它，这是为了防止玩家们的恶意破坏，当你手持火药右键它时会发射火球
  • 可染色
  • 手持火药右键可发射火球
  • 只能在下界和末地生成
  • 要想在主世界生成可以使用命令/gamerule animalbikesGhastNetherOnly false
  • 禁用飞行可以使用命令/gamerule animalbikesFlying false




恐龙坐骑



恐龙坐骑让你能够驾驭恐龙，当你跑向一个动物时它会将其举起来，在那一刻按下Shift它会把动物放下
  • 有四种不同的恐龙
  • 像马一样自动上坡
  • 跑向动物时会将动物举起来
  • 按下Shift可放下动物






兔子坐骑




兔子坐骑让你能够驾驭一只（复活节）兔子，它将会掉落蛋，有时它还会掉落一份“特别”的礼物
  • 掉落礼物
  • 可染色




陆行鸟坐骑



陆行鸟坐骑能让你驾驭陆行鸟，喂食胡萝卜可提高移动速度
  • 喂食胡萝卜可提高移动速度
  • 像马一样自动上坡
  • 可染色
  • 在你骑着它的时候会播放一首歌：Chocarena—by Draggor，你可以在Overcloack ReMix上找到这首歌




蠹虫坐骑



蠹虫坐骑让你能够驾驭蠹虫，如果当你驾驭蠹虫时你手持着一把镐子，蠹虫会往前“啃食”石头，如果你按住Shift它会往下挖，它“啃食”的石头会扔在地上让你能捡起来
  • 手持镐子时可挖矿
  • 可染色




蝙蝠坐骑


蝙蝠坐骑让你能够驾驭蝙蝠，在你驾驭它时你会得到一个夜视效果
  • 当骑着它时有夜视加成
  • 可染色
  • 禁用飞行可以使用命令/gamerule animalbikesFlying false



已知Bug：
你无法使用从创造模式物品栏中的夜视药水来制作，你只能自行酿造

史莱姆坐骑


史莱姆坐骑让你能够驾驭史莱姆，它不能像正常的坐骑一样行走，要向前移动你只能跳，运用某些神奇的跳跃技巧可让你跳的非常非常高
  • 可染色
  • 只能通过跳跃移动
  • 20%几率召唤出岩浆史莱姆坐骑




豹猫坐骑


豹猫坐骑让你能够驾驭豹猫，每当你召唤出豹猫坐骑时总会有额外的三只豹猫在周围生成，因为该坐骑是用鱼做的，它获得的方式相当简单所以并没有过多的能力
  • 可染色
  • 背后总有三只猫跟着
