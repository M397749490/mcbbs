主要内容如题


为了和小伙伴远程联机玩暮色森林才开的服务器

一开始用的原版服务端核心+forge的模式

在发现开不了传送门之后加进了官网的纯净sponge核心, 并没有加上sponge的插件

但是仍然开不了传送门

求解啊.
在发帖一天之后,通过度娘搜索搜到了另一个mcbbs的帖子看到了指导安装原版服务器端＋forge的安装教程
于是保留地图文件后直接删掉了整个服务器文件,再去重新安装服务器
解决方式
1.下载原版1.12.2服务端的jar
2.新建文本文档,重命名位"启动",并将文件后缀改为bat
3.右键编辑该文件,输入"@echo off
java -Xms256M -Xmx1024M -jar [minecraft_server.1.12.2.jar]
pause"ctrl+s保存
4.双击运行一次该bat文件
5.当命令行显示done后关闭窗口
6.打开eula.txt修改false为true
7.再运行一次"启动.bat"
8.前往forge官网下载服务端1.12.2的forge的jar文件
9.双击运行forge的jar文件
10.选择第二项install server,点击"...",定位到服务器根目录,等待安装完成
11.在服务器根目录新建文件夹"mods"
12.右键编辑"启动.bat",删除全部,再输入"@ECHO OFF
java -Xms1g -Xmx2g -jar forge-1.12.2-14.23.5.2768-universal.jar
pause"ctrl+s保存
13.运行"启动.bat"
14.当命令行显示done后关闭窗口
15.将暮色森林mod放入mods文件夹中
16.运行"启动.bat"
17.运行客户端加入服务器
18.在命令行给予自己op权限,测试暮色森林传送门
19.一道闪电劈下,暮色森林传送门开启成功
