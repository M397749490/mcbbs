作者: Ir.Nep    时间: 2020-4-16 10:23
通过API知道Furnace继承了InventoryHolder接口，意味着我们可以通过Inventory类的getHolder()方法获取Furnace
因此物品栏事件可行：
  1. @EventHandler
  2. public void onInvClick(InventoryClickEvent e) {
  3.         if(e.getClickedInventory()!=null && e.getClickedInventory().getType() == InventoryType.FURNACE) {
  4.                 Furnace furnace = (Furnace)e.getClickedInventory().getHolder();
  5.                 furnace.setBurnTime((short) 100);
  6.         }
  7. }
