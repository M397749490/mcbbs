这里是狼三，今天搬运一个可以支持Citizens（公民）插件的开箱抽奖插件！
首先是上一个搬运许可





该插件的作者是QRPG（非凡/量子RPG）以及Sunlight基础插件的原作者，
因为我发现这是一个对RPG服非常有用的插件，
所以我特地到论坛内看了一下，还没有搬运记录，
现已向作者申请授权搬运该开箱插件并获得了允许！
OK，话不多说，直接开始切入主题吧！


插件特点


高度自定义
你可以修改任何插件设置。
您可以更改任何插件消息，并以不同的方式打开它们（如在config.yml中修改插件指令别称等）
轻量级
这个插件非常的轻量级，且做过高度优化，
完全不会导致延迟和内存泄漏。
SQL数据存储
提供MySQL和SQLite数据存储。
自动清除不活跃用户和旧插件数据

游戏内GUI编辑器：
创建和管理抽奖箱的简单方法，
你可以用指令
/GoldenCrates editor
或
/宝箱系统 editor
在GUI界面中更改所有抽奖箱的设置。

箱子奖励：
你可以自定义每个箱子里的奖励
支持任何NBT标签的自定义奖励
玩家赢得奖励时，还可以执行命令
甚至可以设置最少奖励和最多奖励。

奖励预览：
允许玩家在打开前预览一下内容，
预览功能可以在配置文件里禁用

箱子类型：
物品箱：附加到指定的物品上，拿在手上右键可以抽奖
方块抽奖箱：输入指令set连接到你指针所指定的方块上
菜单箱：附加到指定的自定义GUI上。

钥匙宝箱：
你可以设置打开抽奖箱时必须要有一个钥匙，
并且钥匙可以自定义名称让插件来进行识别，
（建议使用带有颜色代码的名称）
钥匙的item数值还可以自定义为任何东西，比如一个地狱疣等乱七八糟的玩意……
你也可以使用虚拟密匙来打开宝箱，虚拟密钥存储在数据库中

抽奖箱冷却：
定义玩家在再次打开抽奖箱之前必须等待的每个抽奖箱的持续时间。
支持：秒数, 分钟, 小时, 天, 月份,年

抽奖箱特效：
为抽奖箱播放不同的效果和声音
当玩家打开时会播放不同的效果和声音
当玩家收到奖励时，会播放不同的效果和声音

抽奖箱动画模板：
默认情况下包括4个原作者做的CSGO等模板参考
你也可以头脑风暴一下创建自己的动画奖励GUI
它还可以自定义动画的滚动速度、声音和效果。

无限制：
你可以创建不限数量的抽奖箱（不用特地办完一个活动就删除一个，可以留着下一次活动用）
无限的奖励（只要把你的奖励放进去，就算是一个方块，无论多少玩家抽奖，它都会无限的发放给中奖玩家，而不需要经常进行补货23333）
无限数量的模板（你可以自己头脑风暴创建更多的抽奖动画模板，它是没有限制数量的哦。）
无限数量的菜单（它也是没有限制数量的哦。）

兼容的插件：
你可以在GUI编辑器里将抽奖箱附加到公民NPC身上！玩家可以通过单击NPC预览抽奖箱和进行抽奖~

可以添加自定义全息消息
抽奖箱需要一定数量的金币才能打开它（可以在GUI界面关闭）（必须要Vault前置哦！）

PlaceholderAPI支持：
%goldencrates_keys_<宝箱名字>%-显示指定宝箱的钥匙数量。
%goldencrates_cooldown_<宝箱名字>%-显示指定宝箱重新打开之前的时间。




插件指令：

/GoldenCrates help - 打开插件帮助
/GoldenCrates editor - 打开宝箱编辑器
/GoldenCrates give <player|*> <crate> [amount] - 给予玩家某个宝箱
/GoldenCrates givekey <player|*> <crate> [amount] - 给予玩家某个宝箱的钥匙
/GoldenCrates menu - 打开宝箱菜单
/GoldenCrates checkkey <player> <crate> - 显示某玩家对应宝箱特定钥匙的数量
/GoldenCrates reload - 重载插件

插件权限：

goldencrates.user - 玩家默认权限(使用权限)
goldencrates.admin - 管理员权限(谨慎，给了这个权限玩家可以自由操控和创建抽奖箱!)
goldencrates.bypass.cooldown - 无视抽奖箱冷却
goldencrates.bypass.cost - 抽奖无须成本(即金钱)

配置文件注释:



这里只讲重要的设置文件，因为创建宝箱完全可以依赖GUI界面操作！
我们从最基础的Config开始吧:
core:
command-aliases: 宝箱系统
#命令别称，你可以将其修改为中文或英文，便可以使用你设置的打开，例子:上方我设置了命令别称为"宝箱系统"，那么我保存这个config替换到服务器内之后，使用命令/GoldenCrates reload重载之后，输入/宝箱系统 即可使用指令！（免去了学渣秒忘英语单词的烦恼233333）#
lang: en
#插件语言文件#
prefix: 宝箱系统
#插件前缀，即使用插件命令后弹出提示的前缀设置#
crates:
block:
disable-visual-drop: false
#禁止视觉掉落，处于开启状态的时候，玩家开启方块宝箱将不会以掉出物品的形式来获得奖品，这样可以防止在主城等公共特殊开箱场所一些心怀不轨的玩家趁其他玩家开箱后上前捡走的恶劣行为#
preview:
enabled: true
#玩家可否预览已经设置好的宝箱#
menu:
#菜单的界面设置#
lore:
- '%crate_lore%'
- '&7'
- '&b你有 &a%keys% &b个钥匙!'
- '&b打开宝箱将花费: &c%cost%$'
