Marauders Map
什么是Marauders Map?
可以在地图上看见附近的玩家

展示图
图一

图二(GIF图)

插件指令
[size=14.6667px]/mm - 给自己一个地图
[size=14.6667px]/mm [player] - 给指定玩家一个地图
[size=14.6667px]/mm <player_name> [CLOSEST|CLOSE|NORMAL|FAR|FARTHEST] - 给指定玩家一个自定义的地图

权限
  • marauders.use - 使用指令 "/mm"的权限
  • marauders.activate - 允许玩家使用地图的权限

配置
#Default Config.yml
#Scale can range from CLOSEST, CLOSE, NORMAL, FAR, FARTHEST
faceSize: 4 #地图尺寸的配置
scale: CLOSEST #范围的配置
map-display-name: '&eMarauders Map' #这个地图的名字
individual-scales: true #允许后即使你改变 的地图范围,但原先生成的地图不会高边
show-update-message: true #允许插件更新是后台出现提醒
show-players-when-invisible: true #允许玩家使用隐身药水是出现在地图上
show-players-when-spectating: false #是否显示游戏模式为3的玩家
