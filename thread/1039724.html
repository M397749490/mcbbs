标题: jvav教程
首先，如何下载jvav？
请去www.jvav.top网站下载
下载以后，还需要一个ide（集成开发环境）
我们选择
zhyIDE（张浩杨IDE）
下载？
不存在的，自己开发。


1，语法
jvav是基于我的世界游戏的，所以它的职责就是使我的世界插件可以被zhy服务器核心加载
先看一个最简单的栗子
  1. @override
  2. class pluginmian extend zhy.pluginserver{
  3.     if playerlogin = ture (e){
  4.         sendmsg(e, hello);
  5.     }
  6. }
复制代码
这个栗子可以在玩家登录的时候发送消息“hello”给登录的玩家
其中if playerlogin = ture (e){是指假如玩家登录事件发送，则把登录玩家命名为“e“
并在sendmsg方法中给e输出消息
