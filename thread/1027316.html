作者: QiuJay    时间: 2020-4-25 15:06
看了下粘液淘金盘的源码，最好的方式是注册两个 PlayerInteractEvent 事件方法，一个高，一个低，在高的地方将此玩家破坏方块的权限禁止掉，然后在到低的方法中将玩家破坏方块的权限打开。

下面是 淘金盘 右键时的代码，判断了右键的方块是否 Material.GRAVEL(沙砾) 并且 玩家有没有破坏方块的权限，如果有才随机取一个物品替换
  1. public ItemUseHandler getItemHandler() {
  2.                 return e -> {
  3.                         Optional<Block> block = e.getClickedBlock();
  4.                        
  5.                         if (block.isPresent()) {
  6.                                 Block b = block.get();
  7.                                
  8.                                 if (b.getType() == Material.GRAVEL && SlimefunPlugin.getProtectionManager().hasPermission(e.getPlayer(), b.getLocation(), ProtectableAction.BREAK_BLOCK)) {
  9.                                         ItemStack output = randomizer.getRandom();
  10.                                        
  11.                                         b.getWorld().playEffect(b.getLocation(), Effect.STEP_SOUND, b.getType());
  12.                                         b.setType(Material.AIR);

  14.                                         if (output.getType() != Material.AIR) {
  15.                                                 b.getWorld().dropItemNaturally(b.getLocation(), output.clone());
  16.                                         }
  17.                                 }
  18.                         }
  19.                        
  20.                         e.cancel();
  21.                 };
  22.         }
