数据包原理:



玩家编号模块:

玩家编号模块的文件在数据包的 hjrpg/functions/player 中。

实现原理:
1. 在每个玩家首次登入时，即当玩家的计分板 id 为 0 时，运行一次。如果有多个玩家同时登入且都是首次登入，则每tick运行一次，直到所有玩家都有自己唯一的 id 。

2. 运行时，先将 $hjrpg_maxid 的计分板 maxid 加 1，再将运行的玩家的计分板 id 等于 $hjrpg_maxid 的计分板 maxid。这样就能让每个玩家都拥有自己唯一的 id 。

3. 运行时，也初始化HP值和MP值。


技能模块：

技能模块的文件在数据包的 hjrpg/functions/skill 资源包的 hjrpg/textures/skill、hjrpg/lang、hjrpg/models/skill、miecraft/models/item/carrot_on_a_stick.json中。

1. 当玩家右键技能，即胡萝卜钓竿时，检测技能释放所需等级、技能CD和技能释放所需MP值是否达到要求。达到则扣除相应的MP值并生成盔甲架记录玩家释放的技能、技能CD等，再寻找对应的技能函数并释放。

2. 在检测技能CD时，先获取技能id，记录在玩家的计分板 sid 中，再通过execute套娃寻找计分板 aid 与玩家的计分板 id 相等且计分板 said 与玩家的计分板 sid 相等的盔甲架。如果找到则技能还在冷却，运行 fail 函数；如果没找到，这技能以经冷却，继续检测技能释放所需MP值。这样做就减少了非常多需要用于技能CD检测的计分板，少了很多不必要的麻烦。(我消耗了几个晚上的头发才想出这个方法)


HP值模块:

玩家编号模块的文件在数据包的 hjrpg/functions/hp 中。

1. 为减少开销，当运行前的HP值和当前HP值不相等时，更新HP值并显示。


MP值模块:

玩家编号模块的文件在数据包的 hjrpg/functions/mp 中。

1. 在每个玩家首次登入时，即当玩家的计分板 maxm 为 0 时，初始化MP值。

2. 计算计分板 maxm 和计分板 nowm 的差。小于0则说明MP值溢出了，重置MP值；大于0则说明MP值需要增加，判断并增加MP值。

3. 为减少开销，当运行前的MP值和当前MP值不相等时，更新MP值并显示。


显示模块：
显示模块的文件在数据包的 hjrpg/functions/display 和资源包的 hjrpg/textures/display、minecraft/font/default.json 中。

实现原理:
1. 为减小开销，通过计分板 dpt 来判断是否需要显示。

2. 通过当前HP值和最大HP值的比算出HP值的百分比

3. 通过百分比判断需要显示的HP条

4. 通过title @s actionbar ... 指令在游戏中以负长度的字体显示。

MP值同上。




技能自定义教程:


1. 创建一个新技能物品，用于技能释放
这里推荐使用战利品表来制作技能物品。

1. 在数据包的 hjrpg/loot_tables/item/skill 中新建一个 json 文件，文件的名字推荐为技能的 id。下面以技能0为例。

2. 在文件内输入:
  1. {
  2.   "pools":[
  3.     {
  4.       "rolls": 1,
  5.       "entries":[
  6.         {
  7.           "type": "item",
  8.           "name": "minecraft:carrot_on_a_stick",
  9.           "functions":[
  10.             {
  11.               "function": "set_name",
  12.               "name": {"translate":"item.hjrpg.1000","italic":false}
  13.             },{
  14.               "function": "set_lore",
  15.               "lore":[
  16.                 {"text":"一一一一一一一一一一一一","color":"gold","italic":false},
  17.                 {"text":"简介","color":"white","italic":false},
  18.                 {"text":"一一一一一一一一一一一一","color":"gold","italic":false},
  19.                 {"text":"消耗魔力: 0点","color":"white","italic":false}
  20.               ]
  21.             },{
  22.               "function": "set_nbt",
  23.               "tag":"{
  24.                 hjrpg:{
  25.                   skill:{id:0,cd:0,mp:0,lv:0},
  26.                   id:1000
  27.                 },
  28.                 Unbreakable:1,
  29.                 HideFlags:4,
  30.                 CustomModelData:14800000
  31.               }"
  32.             }
  33.           ]
  34.         }
  35.       ]
  36.     }
  37.   ]
  38. }
复制代码
其中：

第12行 "name": {"translate":"item.hjrpg.1000","italic":false} 中 "translate" 的值为 item.hjrpg.[数字]，一般与第26行 id:1000 中 id 的值 [数字] 相等。这是在hjrpg中物品的ID。技能的物品ID一般为1开头的4位数字。

第25行 skill:{id:0,cd:0,mp:0,lv:0},  id 为技能id，用于技能的释放，这里的id可以填任何数字，但最好按顺序写；cd 为技能的冷却时间，以tick为单位(1s=20tick)；mp 为技能释放需要消耗的MP值；lv 为技能释放所需的等级。

第17行是物品的简介，可以随意修改。

第32行是物品的材质。技能物品材质的范围推荐是以14800开头的8位数字。

其他的代码就不需要修改了。

3. 点击保存，进入游戏输入 /reload 重新加载数据包，再输入/loot give @s loot hjrpg:item/skill/[json文件名]，就会得到一个空白的技能物品。


2. 写技能

1. 在数据包的 hjrpg/function/skill/id 中新建一个文件夹，文件夹的名字为技能的 id。

2. 在新建的文件夹内新建一个 run.mcfunction 文件，技能的释放从这个文件开始。

3. 在 run.mcfunction 中输入指令作为技能。
例：
  1. execute anchored eyes run summon arrow ^ ^ ^0.1 {Tags:["hjrpg_st","hjrpg_smotion"]}
  2. function hjrpg:skill/model/motion/3
  3. function hjrpg:skill/model/timer/100
复制代码
其中：

第一行中箭的tag hjrpg_st 用于函数 hjrpg:skill/model/timer/100，hjrpg_smotion 用于函数 hjrpg:skill/model/motion/3。

第二行和第三行都为技能模型，为了方便技能的制作。

4. 点击保存，进入游戏输入 /reload 重新加载数据包，右键第1步创建的技能。如果有箭发射出去，则技能制作成功。


3. 技能物品包装:

1. 写技能的名字: 在资源包的 hjrpg/lang/en_us.json 中输入 "item.hjrpg.1000":"[ 技能 ] 名字"，其中 "item.hjrpg.[数字]" 与第1步中第12行的 [数字] 对应。

2. 写技能数据: 在数据包的 hjrpg/loot_tables/item/skill/[新建的json文件名] 的第19行输入 消耗魔力 、冷却时间、所需等级，分别对应第27行的 mp、cd、lv 的数值，用于显示技能的数据。

3. 画技能材质: 先在资源包的 miecraft/models/item/carrot_on_a_stick.json 中添加:
  1. {"predicate": {"custom_model_data": 14800000}, "model": "hjrpg:skill/0"}
复制代码
其中 :

"custom_model_data" 的值与数据包 hjrpg/loot_tables/item/skill/[新建的json文件名] 的第32行 CustomModelData 的值相等。

"model" 的值一般为 "hjrpg:skill/[数字]"，与新技能的技能id对应。

4. 点击保存，进入游戏输入 /reload 重新加载数据包，再输入 /loot give @s loot hjrpg:item/skill/[新建的json文件名] 获取技能。如果显示正确，则新建好一个新技能。
