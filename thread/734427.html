UDPLib——一切为了爽的插件类库[1.1.1]
插件简介：
这是一款专门为开发者而设计的重量级插件类库，拥有十多个插件API，一切为了方便开发者，并且持续更新中。
本插件可以在1.9及以上版本的Spigot服务端及其派生服务端上使用，1.9以下版本的仅部分功能可以使用。

特性列表：
  • 注解指令API
  • 国际化API
  • 区域管理API
  • 界面API
  • 自动识别配置文件编码
  • NMSAPI
  • Title帮助类
  • ActionBar帮助类
  • 计分板API
  • 聊天帮助类
  • 牌子帮助类
  • 书本帮助类
  • BungeeCord帮助类
  • 缓存帮助类
  • 交流API
  • 序列化帮助类
  • 还有很多很多的帮助类和工具类

开发者使用教程：
GithubWiki

源码地址：
Github

指令列表：
/udpl info - 查看UDPL信息
/udpl debug - 切换UDPL Debug模式
/pm plugins - 查看服务器载入的插件
/pm enable <插件文件名> - 载入并启用插件
/pm disable <插件名> - 禁用插件

配置文件：
#UDPL 测试
enableTest: false
#UDPL Debug
debug: false
#UDPL 默认语言，目前仅支持en-US（English）和zh-CN（简体中文）
language: en-US
