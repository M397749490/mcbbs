其实制作这个东西很简


检测所有没有'Get成就'标签的人脚下是不是草方块，是的话给他添加'成就'标签
然后检测所有有'成就'标签的人，tell他们
再然后把所有成就标签的人加上'Get成就'标签，保证只tell一次


代码:

  2. execute @a[tag=!Getachievement1] ~ ~ ~ detect ~ ~-1 ~ minecraft:grass 0 /scoreboard players tag @a[tag=!achievement1] add achievement1
  3. execute @a[tag=!Getachievement1] ~ ~ ~ /tellraw @a[tag=achievement1] ["",{"selector":"@p[r=1]"},{"text":"刚刚获得了"},{"text":"[系统已安装]","color":"green","hoverEvent":{"action":"show_text","value":"\u00a7a系统已安装\n\u00a7f\u00a7o成就\n\u00a7f你走在草地上"}},{"text":"成就!"}]
  4. execute @a[tag=achievement1] ~ ~ ~ /scoreboard players tag @a[tag=!Getachievement1] add Getachievement1
复制代码

上面这几段命令按照从上到下的顺序写入命令方块
循环
连锁
连锁

就可以在你走过草方块的时候tell你

（“\u00a7” 就是那个万恶的小节号）





//重置时使用

  2. /scoreboard players tag @a remove Getachievement1
  3. /scoreboard players tag @a remove achievement1
