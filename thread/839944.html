ItemJoin

插 件 简 介
ItemJoin是一款基于Nukkit的类似于Bukkit的 CustomJoinItems 类的插件，它是小游戏服的必备插件，很简单的自定义加入物品!
本插件原本是一款Bukkit,此版本为作者转制的Nukkit版.
注意：
  修改了配置文件需要重启才会生效
  配合海螺的菜单插件食用更加有味
  由于是转制的,可能使用会有些问题

配 置 文 件
  1. # 版本号 禁修改
  2. version: 1.8
  3. # 这是第一个物品的ID
  4. id: 347
  5. # 物品子ID
  6. meta: 0
  7. # 物品数量
  8. quantity: 1
  9. # 物品所处的格子 0-8
  10. slot: 0
  11. # 物品名
  12. name: "&a游戏菜单"
  13. # 点击执行的指令
  14. command: "menu"
  15. # 离开游戏是否清空
  16. clearleave: false
  17. # 这是第二个物品的ID
  18. id: 347
  19. meta: 0
  20. quantity: 1
  21. slot: 0
  22. name: "&e商店菜单"
  23. command: "shop"
  24. clearleave: false
