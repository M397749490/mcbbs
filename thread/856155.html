方块重力

让方块拥有重力



谨慎安装，装了这个插件天空中的方块会掉下来，可能会毁地图

这个插件理论支持1.8~1.13但是作者只在1.13测试过，所以有可能不兼容

方块有粘性，建房子需要柱子和地基，和真实一样




  OP指令

  • /gravity reload - 重载配置
  • /gravity stop - 停止重力系统


配置
gravity:

  #How much ticks can this plugin take from the server to do its calculation

  #(这个插件可以从服务器获取多少tickss来进行计算?不懂qwq)
  #50 = 20 ticks
  #(这个数值=50就等于20ticks也就是1秒)

  Check speed: 20

  #The interval (in ticks) for each check

  #(每次计算的间隔ticks,就是说上面那个数算重力算完了,等待一段时间再开始下一次计算)

  Check each ticks: 5

  #开启重力系统的世界

  enabled worlds:

  - world

#方块配置
block config:

#空气

  AIR:

#粘性半径

    sticky radius: 5

#是否会受到重力影响而掉落

    can fall: false

#是否在计算时无视此方块,节省性能

    is ignored: true
