根据Sponge 7.1.0 文档 —— 依赖注入，为Config类型的字段设置@Inject是无用的，若要获取默认的配置文件，请使用@DefaultConfig注解，例子如下：
  1. @DefaultConfig
  2. ConfigurationLoader<ConfigurationNode> configLoader;

  4. void method() {
  5.     ConfigurationNode root = configLoader.load();
  6. }
