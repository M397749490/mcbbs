插件特点
  • 适用于出售/回收两种交易类型
  • 随意地新增/删除物品
  • 设定一次交易的物品数量
  • 支持箱子UI
  • 支持表格UI
  • 多语言支持

权限
/*
*
* 指令 /shop 可以被所有人使用。
*
*/
shop.command.info:
  default: op
shop.command.category:
  default: false //Not necessary
  children:
    shop.command.category.create:
      default: op
    shop.command.category.remove:
      default: op
    shop.command.category.additem:
      default: op
    shop.command.category.removeitem:
      default: op
    shop.command.category.icon:
      default: op
    shop.command.category.changename:
      default: op
    shop.command.category.list:
      default: op

指令
  • /shop : 打开商店页面
  • /shop category create <分类配置名|给服主自己看> <分类显示名|写给玩家看> <物品ID> <物品特殊值>: 创建一个分类
  • /shop category remove <分类配置名>: 删除一个分类
  • /shop category additem <分类配置名>  <每件出售价格> <每件回收价格> <物品ID> <物品特殊值>: 添加一个物品到指定分类中
  • /shop category removeitem <分类配置名> <物品ID> <物品特殊值>:删除一个物品在指定分类中
  • /shop category icon <分类配置名> <物品ID> <物品特殊值>: 更换一个分类的图标
  • /shop category changename : 修改一个分类的名称
  • /shop category list : 显示所有商店物品分类
