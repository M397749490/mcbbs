ess插件里 一般只需要考虑禁止下面这些物品。不在内的都可以考虑删去
# 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶：152 = 红石块

修改路径
\plugins\Essentials\config.yml


我的配置信息

blacklist:

    # 阻止玩家放置以下方块?
    placement: 10,46,327

    # 阻止玩家使用以下物品?
    usage: 327

    # 阻止玩家破坏以下方块?
    break: 426

    # 阻止活塞推动以下方块?
    piston:

    # 阻止发射器发射以下物品
    dispenser:
