Flans Panel
Flan面板
Developed by SaraLab

简介
Flan面板是一个可以把 Flan's Mod 的载具信息显示到玩家计分板上的插件。

功能特点：
※ 支持语言文件，可翻译载具名称、弹药名称等
※ 高度自由的自定义信息板
※ 对服务器主线程的占用小，保证TPS

效果图：
默认效果。
中文是已被汉化的条目。
燃料和耐久可根据不同大小显示不同颜色。
主驾驶位武器也可根据不同武器类型显示不同样式。

配置文件
配置文件是本插件的核心部分。
介绍内容较多，配置过程可能比较复杂，建议仔细阅读！

主要配置文件：
config.yml
绿字为注释说明
长文字警告
# Flans Panel Configuration

#设定语言文件，不写.yml后缀。语言文件放在lang文件夹中
Language: zh_CN
#载具信息板
VehiclePanel:
  #自动激活设置。被激活的玩家才可显示信息板
  Activate:
    #是否需要权限。若开启，则拥有flanspanel.display权限的玩家才可被激活
    NeedPermission: true
    #启用的世界。玩家位于指定世界中时才可被激活，星号*表示对所有世界启用
    Worlds:
    - '*'
  #语言相关设置
  Language:
    #信息板每行文字长度上限。服务端默认16，请勿轻易更改
    MaxLineLength: 16
    #是否按照武器类型EnumWeaponType变换文字样式。目前只对主驾驶位的武器有效
    EnableTypeFormats: true
    #是否自动保存未翻译的名称。若开启，则会自动将语言文件中尚未翻译的载具、武器等的名称保存到originalnames.yml文件，以便于进一步完善语言文件
    SaveOriginalNames: false
  #信息板刷新设置
  Refresh:
    #最短刷新周期，单位ticks。间隔小信息板刷新快，间隔大运算压力小，设为0会导致信息板不刷新
    MinInterval: 2
    #是否仅当数据改变时才刷新信息板。推荐开启，提高效率。若关闭，则每次必刷新
    OnlyIfDataChange: true
  #信息板启用设置。关闭某项后，相应的变量也将失效
  Enable:
    #通用
    General:
      #是否允许显示剩余燃料
      Fuel: true
      #是否允许显示核心耐久
      HealthCore: true
    #主驾驶位
    Driver:
      #是否允许显示主武器
      PrimaryWeapon: true
      #是否允许显示副武器
      SecondaryWeapon: true
    #乘客位
    Passenger:
      #是否允许显示乘客武器
      Weapon: true
    #机甲

      #是否允许显示左臂信息
      LeftArm: true
      #是否允许显示右臂信息
      RightArm: true
  #显示设置
  Display:
    #通用
    General:
      #设定燃料中水平。当燃料比例低于此值时显示中水平文字样式
      Fuel-Mid-Level: 0.1
      #设定燃料低水平。当燃料比例低于此值时显示低水平文字样式
      Fuel-Low-Level: 0.05

  EnginePeriod: 5
  EngineDrive:

    VPanelActivation: true

配置要点：
※ 计分板限制条目不能多于15条，因此信息板正文不要超过15行
※ 每行不能超过16个字符，否则文字会被压缩
※ 计分板的条目不能重复，可以在可能重复的行尾增加一些字符（如颜色代码）
※ 功能变量<remline"">可以删除某些变量不可用时留下的空行，保证视觉效果

配置要点：
※ 所有包含“&”之类字符的字符串必须用单引号围起来，否则会导致读取错误（如果搞不清楚，可以一律围起）
※ 原名称中包含英文句号的必须改成<d>，翻译名称则不用
※ 载具名称的翻译请列在 VehiclePanel.Vehicle.Name 条目中，其他任何弹药名称、物品名称等请列在 VehiclePanel.Weapon.Name 条目中

讲解一下信息板变量的运作流程：
最好别看
1.先检查变量的可用性。若变量可用，则从语言文件中获得相应的翻译名
2.若能获取到武器类型，则把翻译名替换到武器类型样式中的<data>处
3.从语言文件中获取相应的变量样式，如果是Valid样式，则把以上内容替换到<data>处
4.最后将以上内容替换信息板中的变量

未翻译名称存储文件：
originalnames.yml
是方便服主编写语言文件用的。
在 config.yml 中开启 SaveOriginalNames 或在服务端中输入命令 /fpnl saveorigin，开启自动保存原名功能后，当插件发现未翻译的载具、武器、物品等的名称时，就会自动保存到 originalnames.yml 中。
然后就可以手动把原名复制到语言文件中进行翻译。

命令与权限
命令：
/fpnl 或 /flanspanel
/fpnl <help| ?> - 显示帮助页
/fpnl saveorigin - 启用/关闭自动保存原名功能
/fpnl vehicle [player] - 查看玩家所乘坐载具的信息
/fpnl reload - 重载所有配置文件
/fpnl info - 查看插件运行信息

权限：
flanspanel.* - 全部权限。OP默认拥有
flanspanel.display - 信息板激活权限
flanspanel.command.* - 全部命令权限
flanspanel.command.help - help命令权限
flanspanel.command.saveorigin - saveorigin命令权限
flanspanel.command.vehicle - vehicle命令权限
flanspanel.command.reload - reload命令权限
flanspanel.command.info - info命令权限
