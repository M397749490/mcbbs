1.(非必要)
请注册一个账号(http://mcstats.org/admin/register.php)
注册完成后
如图所示


2.
下载一个Metrics.java
https://github.com/Hidendra/Plugin-Metrics/tree/master/mods/bukkit/metrics
把他从GitHub上下载下来
放入你自己的插件包里面
当然为了防止冲突 最好把Metrics放到自己的包里面


3
打开你的插件 往插件主类中添加以下代码
  1. try {
  2.     Metrics metrics = new Metrics(this);
  3.     metrics.start();
  4. } catch (IOException e) {
  5.     // Failed to submit the stats :-(
  6. }
复制代码
请确保这些代码最少被加载1次，并且PluginMetrics内opt-out: false


4.（非必要）
既然使用了统计插件 你必然需要一个用以管理你插件统计数据的网站
这个时候第一步所注册到的账号就有用了
点击Add Plugin
按照所需要求提供信息
如果被通过会通过你所提供的Email信息来联系你


Metrics适用于Standalone/Spout/Bukkit/Forge/Canary/Bungee
