这里我解释下部分东西：
none表示否定
false表示否定
true表示允许
PVP：玩家互相攻击
invincible：暂时未知
fall-dmg：摔落是否会扣血
effects：药水伤害是否开启
blocked-cmds：这个区域禁用的命令哪些（留空表示不禁用）
allowed-cmds：这个区块允许使用哪些命令（留空表示所有）
use：使用权限（例如熔炉，箱子啥的）
item-drop：丢掉物品
explosion：爬行者是否能在区域爆炸使玩家受到伤害
notify-enter：进入该区域是否提醒本区域名称
notify-leave：离开该区域是否提醒本
potions：喷溅型药水是否会伤害玩家
allowed-enter：是否能进入该区域
allowed-leave：是否能离开这区域？？？
game-mode：是否更改游戏模式
sleep：是否可以在这区域设置床
send-chat：暂时未知
receive-chat：暂时未知
enderpearl：是否能在这区域使用末影珍珠传送
fly-mode：区域飞行
eat：是否可以吃东西
allow-damage-animals：是否能伤害生物
allow-damage-monsters：是否能伤害怪物
allow-leaves-decay：树叶能否腐烂
allow-plant-growth：农作物能否生长
allow-spreading：未知
allow-block-burn：方块是否会被燃烧
若你想允许玩家在区域干嘛输入/rg flags set <区域名称> 权限 true/false
比如我想在区域内使用工作台方块输入/rg flags set admin use true

权限介绍：


  1. worldguard.create：创建一个受保护的区域
  2. worldguard.modify：更改某个区域保护大小
  3. worldguard.delete：删除某个保护区域
  4. worldguard.enter.<区域名称>：无视权限进入某区域
  5. worldguard.leave.<区域名称>：无视权限离开某个区域
  6. worldguard.build.<区域名称>：允许在某个区域放置物品权限
  7. worldguard.break.<区域名称> ：允许在某个区域破坏方块权限
  8. worldguard.edit.<区域名称> : 编辑某个区域
  9. worldguard.eat：无视所有区域eat的flag权限设置
  10. worldguard.drop：无视所有区域drop的flag权限设置
  11. worldguard.usechest.<区域名称>：允许在某一个区域使用原版箱子
  12. worldguard.usechestender.<区域名称>：允许在某个区域使用末影箱
  13. worldguard.enchantingtable.<区域名称>：允许某个区域使用附魔台
  14. worldguard.usedoors.<区域名称>：允许某个区域中使用门
  15. worldguard.usegates.<区域名称>：允许某个区域使用地狱传送门权限？？？
  16. worldguard.usetrapdoors.<区域名称>：允许某个区域中使用活板门
  17. worldguard.usefurnaces.<区域名称>：允许某个区域使用熔炉
  18. worldguard.useanvil.<区域名称>:允许某个区域使用铁砧

命令介绍：


/rg : 插件帮助
/rg create <区域名称> : 创建某个区域【你必须先输入命令然后使用木斧头圈地一样创建】
/rg list : 列出所有已创建的区域名称
/rg flags get <区域名称> : 查看某个区域权限设置情况
/rg flags reset  <区域名称> <flag权限> : 将某个区域某个flag权限恢复到默认值
/rg flags set <区域名称> <flag权限> <需要更改的值> : 将某个区域某个flag权限设置为....
