作者: 晴路卡    时间: 2020-4-7 12:41

整个长得不太一样的答案吧（上面几个单命令的会在玩家距离小于0.1的时候失效，当然一般不可能遇见就是了
高频执行这条命令：

/execute as @a at @s at @a[distance=..5] unless entity @s[distance=0] run effect give @p minecraft:invisibility 1 1 true

红色的是你所说的“靠近”这个范围的最大值

复制代码


函数 xxx
  1. tag @s add self
  2. execute if entity @a[tag=!self,distance=..5] run effect give @s minecraft:invisibility 1 0 true
  3. execute unless entity @a[tag=!self,distance=..5] run effect clear @s minecraft:invisibility
  4. tag @s remove self
