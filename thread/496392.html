还在担心玩家掉进虚空死亡么

使用Anti_Void_Death吧！

玩家：
使用前： 服主我的东西掉虚空了 赔偿！
使用后：呼~ 我在掉进去的一瞬间被上帝救了  真幸福！

也就是说这个插件会把玩家从掉进虚空的时候传送到安全点


使用方法：

1.去原帖下载插件（尊重作者）

2.放入服务器plugins文件夹

3.重启服务器


指令&权限

1./avd spawn set 世界名 | 权限: avd.setspawn 描述：为这个世界设置掉入虚空之后的安全传送点
2./avd spawn remove <WorldName> | 权限: avd.removespawn 描述: 移除这个世界的安全传送点
3./avd spawn goto | 权限: avd.gotospawn描述: 把玩家传送到他们目前的世界的安全传送点
4. /avd config reload [CONFIG/PROTECTEDWORLDS] | 权限: avd.config 描述:重载插件配置和世界保护点信息
5./avd config loadworlds | 权限: avd.config 描述: 载入所有世界的保护信息（同第四？）

只要给玩家 avd.alwayssavedfromfall 权限即可！
配置文件说明：
  1. #这里填写当玩家被保护时显示的信息
  2. Saved_From_Fall_Message: '&d感谢上帝把你从火星救回来！'
  3. #在控制台显示彩色的信息（服主福利）
  4. Use_Colour_In_Console: true
  5. #这里填写true会检测玩家的权限
  6. Use_Permissions_For_Save_From_Fall: false
  7. #没权限被救的信息（6666好悲惨）
  8. Not_Saved_From_Fall_Message:
  9.   No_Permission: '&d上帝表示没有权限从火星获救！'
  10. #更新检测
  11. Update:
  12. #设置为true会启动更新检测
  13.   Update_Check_Enabled: true
  14. #是否通知在线的OP要更新本插件
  15.   Announce_Update_Available_To_Online_OPs: true
  16. #汉化、搬运 By Busy_gains QQ781482205
