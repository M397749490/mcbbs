一、前言
本插件灵感来自于@名副其实
以前在PVPIN（https://www.mcbbs.net/thread-1034477-1-1.html，我写了关于PVPIN的一小段介绍）
有过一个“Grenade手雷”插件，作者把他叫做“向量高级应用”
不过由于历史原因，PVPIN曾经删除过大量旧插件的源代码，包括这一插件，导致当年无法查看其实现方法
但这是一个优秀插件，因此在PVPIN的代码箱还是可以看到他的身影
我曾经试着用过，当时限于自己数学水平，无法写出类似的插件
这次正好想写一个好写的小插件，就尝试写了一个类似的向量应用


二、插件介绍
本插件是一个可以让腐竹自定义药水的插件
不过这里的自定义仅限于原版的效果
即使用PotionMeta（或者是操作原版的Potion数据键对应的NBT混合数据包）就可以做到的
呼应“向量应用”，我写了两个额外的功能
第一是多重投掷，可以让一瓶药水分裂为多个
第二是药水反弹，可以让药水碰到方块时反弹




三、使用方法
先把插件丢进Spigot服务端的plugins文件夹
会自动生成MinerTribeSplashPotion这一数据文件夹
初次使用，会自动生成
/plugins/MinerTribeSplashPotion/demo1
/plugins/MinerTribeSplashPotion/demo2以及config.yml
然后在游戏内使用/mtsp指令，即可拿出自定义的药水




四、config.yml
整个config.yml只有两个参数
SplitRadians，调整药水多重投掷时分裂的药水之间的夹角
比如说设置为30，且split为2
那么就会在玩家正中央靠左30度、靠右30度各生成一瓶药水
比如说设置为30，且split为4
那么就会在玩家正中央靠左15度、靠左30度、靠右15度、靠右30度各生成一瓶药水
HitVelocity，调整反弹的力度
值越大，反弹的力度越大，如果设为大于1那么就会变成扔弹力球的感觉（注：想玩弹力球可以试试看把bounce调到几百，保证弹到停不下来）




五、自定义药水系统
任何json语法问题，我不予解答，请自行百度搜索json解析，校正自己的语法问题！
  1. {    "name": "demo",    "material":"SPLASH_POTION",    "bounce":10,    "split":3,    "color":"#D4AF37" ,    "potioneffect":[        {        "type":"DOLPHINS_GRACE",        "duration":20,        "amplifier":3,        "ambient":false,        "has-particles":true,        "has-icon":true        },        {        "type":"CONDUIT_POWER",        "duration":20,        "amplifier":3,        "ambient":false,        "has-particles":true,        "has-icon":true        },        {        "type":"LUCK",        "duration":200,        "amplifier":1,        "ambient":false,        "has-particles":true,        "has-icon":true        }    ]}
复制代码


这是示例代码，如果看不懂json结构，请直接对着他改
name代表物品名字
material是物品材质，包括SPLASH_POTION和LINGERING_POTION，大小写敏感
bounce代表反弹次数
split代表多重投掷几个
color是药水颜色，物品栏的颜色和扔出去的药水AEC粒子颜色都是他
请以#开头，16进制数字表示，RGB
potioneffect是，[]，也就是json里的列表
列表的每一项以逗号隔开，每一项都应当是{}包裹，表示对象即：[{xxx},{yyy},{zzz}]或者[{xxxx}]
请注意英文标点！
potioneffect对象当中：
type代表药水效果类型，枚举在https://bukkit.windit.net/javado ... tionEffectType.html
比如说ABSORPTION，SPEED，LUCK等，也就是PotionEffectType的枚举常量
大小写敏感，请注意全部大写，单词之间下划线隔开
duration代表药效持续时间，如果太短，则不会显示药水效果的图标
这玩意本质上是Long计量的tick，但是不需要你打L，会自动转换，20tick为1秒
比如说你想要1秒药效，就输入20
比如说你想要5秒药效，就输入100
amplifier代表药效等级
ambient代表药水是不是信标效果（粒子减少）
has-particles代表有没有粒子
has-icon代表会不会在客户端右上角显示药水效果的图标




六、文件处理
/MinerTribeSplashPotion文件夹下的每一个目录都会被读取
比如说demo1、demo2目录
你也可以自建文件夹，我不太确定含有中文字符的路径会不会产生什么问题，所以尽量全英文名
在文件夹里面新建item.json，你就可以自己自定义自己的药水了
这里之所以多做一层目录，是因为日后可能有更多功能
在游戏内输入/mtsp，就可以看到所有的自定义药水




七、权限
minertribesplashpotion.get节点
代表了/mtsp指令的使用权限
默认为OP拥有，请不要随便给予玩家！




八、给那些开发者的话
我没有封装API，所有的方法没有静态方法，没有做API类
如果你想要以此插件为前置，请自行查看自定义药水的NBT
（不是display数据键的混合数据包，我没把属性写进lore里面，请直接查看最外层的NBT混合数据包）
日后我会做好自定义事件，届时就可以直接监听了
日后我会做好NBT的修改API，方便直接调用
现在理论上反编译也能看懂，我是全程反射，没用ProtocolLib

如果您发现药水反弹时触发了粒子效果，请不要担心
我写了相应算法，保证所有的药水效果全部被清除
所以药水的效果仅会被应用一次，而且是在最后一次落地点

插件所用代码部分来自其他开源或闭源(已授权)作品
包括PVPIN的抛物线向量库，PVPIN是什么，可在帖子最上方查看
简单来说，是一个图形化mc编程网站
其抛物线向量代码就在其编辑器内，明显属于开源
同时由于PVPIN早已倒闭，因此此代码也无从考证其是否存在bug
（我的插件实际并未使用这段代码，原因是实际操作存在大量NaN报错，checkFinite就会导致问题）
