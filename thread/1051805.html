前言

这是一款投票重启插件。编写这款插件主要是看到许多服务器在较卡的时候，拥有后台权限的人都不在，导致玩家游戏体验极差（我自己亲身经历过）
功能介绍
1.防挂机
某些服务器挂机人数较多，导致投票没人投。本插件提供了防挂机来进行避免。
2.防同IP
为了防止有熊孩子开小号进行投票，本插件提供了防同IP投票。
3.版本BUG避免
若插件出现重大BUG（如刷物品、踢人BUG等），会自动禁用并提醒服主更新【需要设置配置文件中checkupdate为true】

如何使用

1.下载本插件，并将插件放在服务器内plugins目录内

2.重启服务器或/reload（不推荐）
指令
/votereboot 插件菜单
/vote 发起一次投票
/voteaccept 同意本次重启
/votecancel 取消本次投票/重启
/votereboot reload 重载插件
权限
votereboot.vote 发起投票权限
votereboot.accept 同意投票权限
votereboot.cancel 取消投票/重启权限

配置文件

默认在plugins/VoteReboot目录下
  1. #请勿随意修改配置文件，否则会导致插件出现各种奇怪的BUG
  2. #当出现缺少路径时，配置文件将会重置

  4. #此内容请勿修改！！！
  5. ConfigVersion: 1.1

  7. #自动检查更新功能 强烈建议开启！！！
  8. #自动检查更新，若发现此版本存在重大BUG（如刷物品、卡服之类的）会自动停用本插件，并提醒升级至最新版
  9. #同时提醒你更新插件
  10. checkupdate: true

  12. #插件聊天栏前缀
  13. prefix: §b[VoteRebbot]

  15. #是否启用VoteReboot。若为false,插件将会自动关闭。
  16. EnablePlugin: true

  18. #设置当投票玩家的频率（四舍五入）为rate时，服务器重启。比如，当rate为0.6，在线玩家为10时，只需要6名玩家投“是”票即可重启。
  19. #rate默认为0.6
  20. rate: 0.6

  22. #重启方式 1:在控制台发送指定命令  2.在终端(cmd)发送指定命令
  23. #默认为1
  24. way: 1
  25. #在控制台发送的命令 当way=1时该配置项有效
  26. cc: stop
  27. #在终端(cmd)发送的命令 当way=2时该配置项有效
  28. ccwl: sh restart.sh
  29. #重启前是否保存游戏
  30. save: true
  31. #保存命令 默认save-all
  32. savec: save-all

  34. #是否禁止一个IP不同ID的玩家投多次票
  35. #如果你的服务器没有使用FRP，建议开启此功能
  36. IPCheck: false

  38. #重启等待时间 默认为10秒
  39. rs: 10

  41. #是否启用挂机检测 启用后可以防止挂机玩家影响投票
  42. #虽然检测不会占用主线程 但目前仍然不确定该功能是否会对服务器的性能造成影响
  43. #若该功能影响了服务器性能 请将其关闭 并报告给插件作者 插件作者会进行改进
  44. checkplayer: true
  45. #未操作多少秒后判定为挂机 默认为300 当checkplayer为false时该配置项没有用处
  46. s: 300
  47. #检测到挂机玩家后是否通知所有玩家 当checkplayer为false时该配置项没有用处
  48. notice: true
