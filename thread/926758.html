教程 - “创建一个最简单的任务”
---------------------------
装上汉化
(由  @Yaths 提供)
---------------------------

输入指令创建一个任务
/quest create <任务ID>
---------------------------

选择任务类型
(这里没法汉化,付费内核汉化没法发出来)
任务类型列表
BREAK_QUEST - 破坏方块BREED_QUEST - 喂养/繁殖动物
BUCKET_FILL_QUEST - 填满桶(例：装水/装岩浆)
CHAT_QUEST - 玩家需要发送指定的消息
CLICK_QUEST - 点击一个特定的方块
COMMAND_QUEST - 执行特定的命令
COMPLETION_QUEST - 需要完成一定数量的任务
CONSUME_QUEST - 需要吃一定量的食物
DEATHS_QUEST - 需要一定数量的死亡
DELIVERY_QUEST - 需要向NPC交付特定的物品
ENCHANT_QUEST - 需要一定数量的附魔
ENDED_QUEST - 需要完成一定数量的任务
FISH_QUEST - 钓鱼时获得一定数量的物品
INTERACTION_QUEST - 需要与特定实体交互
KILL_QUEST - 需要杀死一定数量的玩家
LEVEL_QUEST - 需要达到一定的附魔等级
LOCATION_QUEST - 需要到达一个位置
MOB_QUEST - 需要杀死一定数量的怪物(如果是Mythicmobs怪物不要用这个,当你装上MM插件会自动提供一个Mythicmobs选项)
OBTAIN_QUEST - 需要获得一些特定的物品
PERMISSION_QUEST - 需要权限完成任务
PLACEHOLDER_QUEST - 需要PAPI变量达到任务要求的数量
PLACE_QUEST - 需要放置一定数量的块
SHEAR_QUEST - 需要剪一定数量的羊毛
STAGE_QUEST - 需要完成特定的任务
START_QUEST - 需要开始一定数量的任务
TAME_QUEST - 需要驯服一定数量的动物
TOTAL_QUEST - 需要达到总数 Requires a set total to be reached (Incremented via API or commands)
(兼容的插件当安装之后会有相关任务类型出现,所以这里只是基础的类型;)
---------------------------
填好要求，保存任务 并在菜单中编辑任务
/quest menu create new
点下界之星 点一个黑色玻璃板 将你做好的任务ID填到菜单中，保存
---------------------------
/quest menu new
打开菜单，开始你的任务吧
---------------------------
多人任务的组队类型
SOLO - 单人任务
GROUP - 组队
FACTION - FACTION插件 整个派系(https://www.spigotmc.org/resources/factions.1900/)
FACTION_UUID - 整个玩家阵营 (HCFactions或FactionsUUID[https://www.spigotmc.org/resources/factionsuuid.1035/])
GANG - 帮派插件整个帮派 (https://www.spigotmc.org/resources/gangs-1-7-1-14.2604/)
TOWN - Towny插件整个城镇 (https://github.com/TownyAdvanced ... -developed-by-llmdl)
NATION - Towny插件整个国家
ASKYBLOCK - ASkyblock插件整个空岛(https://www.spigotmc.org/resources/askyblock.1220/)
USKYBLOCK - USKYBLOCK插件整个空岛(https://www.spigotmc.org/resources/uskyblock.2280/)
---------------------------
任务奖励类型
[Chance={percentage}] [{action}] - 有{percentage}%的概率执行此操作
[Delay={time}] [{action}] - 延迟（秒）后要执行的操作
[SyncTask][{action}] - 与服务器当前tick同步执行的操作(Performs the action in sync with the server tick)
[PlayerCommand] {command} - 由玩家发出一条指令
[ConsoleCommand] {command} - 由控制台发出一条指令
[OperatorCommand] {command} - 由OP发出一条指令
[Broadcast] {message} - 发出一条公告
[Message] {message} - 给玩家发送一条消息
[JSONBroadcast] {message} - 将JSON消息发送到服务器
[JSONMessage] {message} - 将JSON消息发送到玩家
[Sound] {sound value} - 给玩家播放声音
[VaultGive] {amount} - 给玩家金钱
[VaultTake] {amount} - 扣除玩家金钱
[Teleport] {world name};{x};{y};{z} - 将玩家传送到指定的坐标
[Teleport] {world name};{x};{y};{z};{yaw};{pitch} - 将玩家传送到指定的坐标(yaw与pitch是视角,可以在ess中设置个warp看看)
[GiveItem] {material};{amount} - 给玩家指定的物品
[GiveItem] {material};{amount};{data} - 给玩家指定的物品
[GiveItem] {material};{amount};{data};{name} - 给玩家指定的物品
[TitleBroadcast] {title} - 在服务器里发送一条Title公告
[TitleBroadcast] {title};{subtitle} - 在服务器里发送一条Title公告,带有副标题
[Title] {title} - 给玩家发送一条Title消息
[Title] {title};{subtitle} - 给玩家发送一条Title消息,带有副标题
[ActionBarBroadcast] {message} - 在服务器里发送一条ActionBar公告
[ActionBar] {message} - 给玩家发送一条ActionBar消息
[StartQuest] {quest identifier} - 让玩家开始指定的任务
[CancelQuest] {quest identifier} - 取消玩家指定的任务
[Bungee] {server} - 将玩家传送到指定的BC服务器
[AddPoints] {amount} - 给予玩家指定的任务点数
[SubtractPoints] {amount} - 扣除玩家指定的任务点数
示例
给玩家5000金币
[VaultGive] {amount} = '[VaultGive] 5000'

向玩家发送标题“完成” 带有红色的“恭喜”字幕
[Title] {title};{subtitle} = '[Title] &4完成!;&4恭喜'

有25%概率奖励玩家64颗钻石
[Chance=<percentage>][GiveItem] {material};{amount} = '[Chance=25][GiveItem] DIAMOND;64'

使用ActionBar显示玩家当前任务的进度 (All current placeholders)
[ActionBar] {message} = '[ActionBar] &bCurrent progress: &7(%quest_progress_formatted%/%quest_total_formatted%)'
JavaScript Actions:

您还可以在操作中使用JavaScript，以进一步增强您的奖励和插件其他部分的功能。
Objects:
BukkitPlayer - The player who the action is being executed for
ProQuests - The instance of the plugin
Quest - The quest object the action is being executed for
示例
[ConsoleCommand] eco give %player% [JavaScript=%quest_remaining_duration% * 20]

---------------------------
排行榜的配置

settings:#排行榜中显示玩家的总数量(设置10就是显示前十名)
  total: 10
#更新时间(以秒为单位)
  update_delay: 600
#在新的月,周时刷新(false就是7天,30天刷)
  reset_on_month: true
#是否使用菜单进行显示,找不到菜单会默认在聊天框中显示
  use_menu: true
#当月结束后，是否要奖励特定排名的玩家。这些奖励可以在后面定义。
  use_monthly_rewards: true
#一周结束后是否要奖励特定排名的玩家。这些奖励可以在后面定义。
  use_weekly_rewards: true
#每周奖励
weekly_rewards:
#first_place为ID，不可重复。
  first_place:
#排行前几的人能领取到这个奖励
    positions:
    - 1
#奖励的指令
    actions:
    - '[GiveItem] DIAMOND;64'
    - '[Message] &e[&e&lQUESTS&e] &7You finished &a&l1st Place &7with the most weekly
      points! &7(&b%weekly_points% points&7)'
#前十名的奖励
  top_ten:
    positions:
    - 2
    - 3
    - 4
    - 5
    - 6
    - 7
    - 8
    - 9
    - 10
    actions:
    - '[GiveItem] GOLD_INGOT;16'
    - '[Message] &e[&e&lQUESTS&e] &7You finished in the top ten this week! &7(&a#%place%&7)
      &7(&b%weekly_points% points&7)'
