更多熔炉 | More Furnaces

  • 懒得画资源包，新熔炉材质与普通熔炉一致，通过熔炉内的名称辨别不同熔炉即可.jpg
  • 此模组添加了四个新熔炉：铁制熔炉、金制熔炉、钻石熔炉 和 下界熔炉。

获得方式

  • 使用 8 块铁锭和 1 个普通熔炉投掷合成 铁制熔炉。
  • 使用 8 块金锭和 1 个普通熔炉投掷合成 金制熔炉。
  • 使用 8 颗钻石和 1 个普通熔炉投掷合成 钻石熔炉。
  • 使用 8 个地狱岩和 1 个普通熔炉投掷合成 下界熔炉。

使用方式

  • 使用方式同普通熔炉。
  • 铁制熔炉的熔炼速度和燃料消耗速度为普通熔炉的 4 倍。
  • 金制熔炉的熔炼速度和燃料消耗速度为普通熔炉的 8 倍。
  • 钻石熔炉的熔炼速度和燃料消耗速度为普通熔炉的 16 倍。
  • 下界熔炉的熔炼速度为普通熔炉的 1/3，但该熔炉在使用燃料点燃后，可以一直燃烧。

已知 BUG

  • 粗糙的视线追踪方法导致的所有 BUG。

更多熔炉 | More Furnaces

  • 命名空间：furnaces
  • CustomModelData：暂无

使用命令

  • 运行命令 /loot give @s loot furnaces:iron 来获得铁制熔炉。
  • 运行命令 /loot give @s loot furnaces:golden 来获得金制熔炉。
  • 运行命令 /loot give @s loot furnaces:diamond 来获得钻石熔炉。
  • 运行命令 /loot give @s loot furnaces:nether 来获得下界熔炉。
  • 运行命令 /function furnaces:remove 来移除模组加载时建立的记分板。

修改文件

  • 打开 More Furnaces Datapack 1.0\data\furnaces\functions\work\iron\burn.mcfunction 看到第 2 行：
    1. execute store result block ~ ~ ~ BurnTime short 0.25 run data get block ~ ~ ~ BurnTime
    复制代码
    其中的数字 0.25 = 普通熔炉燃料消耗速度 / 铁制熔炉燃料消耗速度。
  • 打开与 burn.json 同文件夹下的 cook.mcfunction 看到第 2 行：
    1. execute store result block ~ ~ ~ CookTimeTotal short 0.25 run data get block ~ ~ ~ CookTimeTotal
    复制代码
    其中的数字 0.25 = 普通熔炉熔炼速度 / 铁制熔炉熔炼速度。
  • 铁制熔炉的 burn.mcfunction 和 cook.mcfunction 放在 iron 文件夹下，而金制、钻石和下界熔炉的 burn.mcfunction 和 cook.mcfunction 依次放在 golden、diamond 和 nether 文件夹下，通过修改其中的数字可以修改相应的速度（下界熔炉的 burn.mcfunction 除外）。
