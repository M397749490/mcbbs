介绍：
本插件可以根据玩家的IP显示玩家的地理位置。

使用：
将本插件扔进服务端plugins文件夹里，重新启动服务器即可。

命令：
命令
权限
说明
默认
/geoip <玩家>geoip.show显示某玩家的地理位置OP
/geoip <玩家>geoip.show.fullip显示某玩家的地理位置与完整的IP地址false
geoip.hide隐藏一个玩家的地理位置false

配置：
  1. database:
  2.   # 是否显示城市
  3.   show-cities: false
  4.   # 是否自动下载
  5.   download-if-missing: true
  6.   # 国家数据的链接
  7.   download-url: "https://geolite.maxmind.com/download/geoip/database/GeoLite2-Country.tar.gz"
  8.   # 城市数据的链接
  9.   download-url-city: "https://geolite.maxmind.com/download/geoip/database/GeoLite2-City.tar.gz"
  10.   update:
  11.     # 是否自动更新
  12.     enable: true
  13.     # 自动更新周期（单位：天）
  14.     by-every-x-days: 30
  15. # 是否在玩家进入游戏时广播
  16. show-on-login: true
  17. # 是否用指定语言显示位置，见下文
  18. enable-locale: true
  19. # 显示位置的语言，可用值见 https://dev.maxmind.com/geoip/geoip2/web-services/#Languages
  20. locale: zh-CN

API：
示例
  1. import cn.nukkit.Player;
  2. import cn.nukkit.Server;
  3. import cn.wode490390.nukkit.geoip.GeoIP;

  5. class Example {
  6.     Example() {
  7.         Player player = Server.getInstance().getPlayer("wode490390");
  8.         if (player != null) {
  9.             String geoLocation = GeoIP.query(player); //Our API :)
  10.             player.sendMessage("Your location: " + geoLocation);
  11.         }
  12.     }
  13. }
