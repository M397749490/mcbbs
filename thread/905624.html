版本号？不说版本默认1.12？然后去枪毙如果你既想看到人物，又想移动生物，我这里有一个比较麻烦的办法这里举例猪
召唤一个tag为move且无AI的猪 /summon minecraft:pig ~ ~1 ~ {Tags:["move"],NoAI:1b,Invulnerable:1b}
固定这只猪的视角 保持开启/tp @e[tag=move] ~ ~ ~ 90 0 之后它所朝的方向便为前方


保持开启 scoreboard players tag @a add up {Inventory:[{Slot:-106b,id:"minecraft:lever",tag:{display:{Name:"up"}}}]}
保持开启 execute @a[tag=up] ~ ~ ~ /tp @e[tag=move] ~-0.1 ~ ~
scoreboard players tag @a remove up


保持开启 scoreboard players tag @a add up {Inventory:[{Slot:-106b,id:"minecraft:lever",tag:{display:{Name:"down"}}}]}
保持开启 execute @a[tag=down] ~ ~ ~ /tp @e[tag=move] ~0.1 ~ ~
scoreboard players tag @a remove down


保持开启 scoreboard players tag @a add up {Inventory:[{Slot:-106b,id:"minecraft:lever",tag:{display:{Name:"left"}}}]}
保持开启 execute @a[tag=left] ~ ~ ~ /tp @e[tag=move] ~ ~ ~0.1
scoreboard players tag @a remove left



保持开启 scoreboard players tag @a add up {Inventory:[{Slot:-106b,id:"minecraft:lever",tag:{display:{Name:"right"}}}]}
保持开启 execute @a[tag=right] ~ ~ ~ /tp @e[tag=move] ~ ~ ~-0.1
scoreboard players tag @a remove right



0.1为走路速度 0.2为奔跑速度 建议不要太快
这里用的是拉杆 名字需要命名为up down right left来控制前后左右
唯一的bug：无法跳跃和下降
下降解决办法：将猪的无AI属性去掉，添加无限缓慢药水效果
