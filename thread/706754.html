相信大家已经对这个插件有所了解了，接下来就是来说说怎么用了，用法与ScriptBlock十分相似，但是有几个和scriptblock不同的细节，需要当心和注意一下
指令:
/smkill create [怪物名字] [脚本] ——添加当怪物被玩家杀死的脚本，具体脚本填写什么，下面再说
/smkill remove [怪物名字] ——移除一个脚本
/smdamage create [怪物名字] [脚本] ——添加当玩家对怪物造成伤害的时候的脚本，具体脚本填写什么，下面再说
/smkill remove [怪物名字] ——移除一个脚本

权限:
上面的指令都只有OP才能使用

配置文件:
scripts: #这个是存储一些数据的，不要管他

脚本教程:
脚本是由[到]构成的，格式要求严格
可用的脚本标签有以下几个:
@random
@bypass
@cmd
@console
@money

我们一个一个来讲:

1.@bypass ——执行OP指令
示范(玩家对名字为S的怪物造成伤害时发送一条信息):
/smdamage create S [@bypass /say %player%对S怪物造成了伤害!]

2.@cmd —— 执行玩家指令
示范(杀死名字为S的怪物自动回城，并说"我率先杀死Boss")
/smkill create S [@bypass /say 我率先杀死Boss][@cmd /spawn]

3.@console —— 执行控制台指令
示范(杀死名字为S的怪物自动给玩家一个钻石)
/smkill create S [@console /give %player% 264 1]

4.@random —— 随机值
用法:
@random (一个值) ——这个值必须在100以内，整数，如果这个随机值没有通过后面的脚本都不会执行
示范(杀死名字为S的怪物必定说"我杀死了Boss"，并有50%的几率给玩家一个钻石)
/smkill create S [@bypass /say 我杀死了Boss][@random 50][@console /give %player% 264 1]

5.@money ——金钱判断值(楼主没有试过，如果不行的话说一下)
用法:
@money (一个值) ——如果玩家的金币不大于这个值后面的脚本都不会执行
示范(当玩家的金币大于10000的时候杀死名字为S的怪物有50%给玩家一个钻石)
/smkill create S [@money 10000][@random 50][@console /give %player% 264 1]
