广告盈利器
　　本 Spigot 插件支持 Minecraft 1.8-1.15 的版本。它可以让您通过在服务器中向玩家播放广告的形式获取在 PayPal 上的一部分盈利（真钱）。
　　这些事儿都可以通过一个交互性的菜单来完成！
功能
> 自定义显示广告链接的文字 <
> 简单的管理菜单 <
> 所赚到的钱可在 PayPal 中提现 <
> 可控制显示广告的频率 <
> 在没有广告显示延迟的情况下测试系统 <
图片



权限
"monetizer.help" : 使用 "/monetizer help" 指令
"monetizer.manage" : 使用 "/monetizer manage" 指令
"monetizer.manage.test" : 测试广告推送系统
"monetizer.manage.owner" : 成为当前带有广告系统的服务器的所有者
"monetizer.update" : 当插件有更新时接收更新提醒
指令
"/monetizer help" : 查看所有自己有权限执行的指令
"/monetizer manage" : 打开管理菜单
"/ad" : 获取一个广告链接
[custom command] : 获取一个广告链接 ( like "/ad" )​
配置
config.yml
  1. # Additional command to watch an advertisement ( other than /ad )
  2. AdCommand: "/reward"

  4. # Commands to execute when the player has seen the advertisement
  5. # Use "%player%" for player name   Use "," for multiple commands
  6. ConsoleCommand: "give %player% minecraft:diamond,say Thanks to %player% for the support !"

  8. # This option increases the gains by adding an a***y page but this may displease some users
  9. Increase: true

  11. # Display a menu when loading (very fast)
  12. LoadingMenu: true
  13. # Send a message when connecting if the player can see an advertisement
  14. JoinMessage: true
  15. # Time in seconds between automatic messages (set to 0 to deactivate)
  16. AutoMessage: 600
