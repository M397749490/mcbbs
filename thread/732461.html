特点 | Feature



指令&权限 | Cmd And Permissions

管理命令描述
/f13 setup [游戏名称]创建并开始设置一个游戏场地
/f13 add [游戏名称] (spawn/chest:item/chest:weapon/phone)为指定游戏设置重生点/箱子/物品/武器/电话
/f13 delete [游戏名称]删除一个游戏场地
/f13 arena [游戏名称]显示游戏场地的信息
/f13 arenas列出所有游戏场地
/f13 end [游戏名称]结束某个游戏场地
/f13 kick [玩家名称]踢出一个游戏中的玩家
/f13 set [游戏名称] tpc [值]设置每场游戏的时间？？
<Sets number of minutes per counselor in the arena.>
/f13 set [游戏名称] wait [值]设置游戏人数到最小人数的时候,倒计时的秒数
/f13 memoryView the number of items currently stored in F13 memory.


玩家命令
描述
/f13 play [arenaName]Play game in supplied arena.
/f13 join自动加入一个游戏场地.
/f13 join [arenaName]加入指定的游戏场地
/f13 quit退出游戏或等待大厅
/f13 leave退出游戏
/f13 stats [playerName]玩家统计信息
/f13 spectate [arenaName]观战游戏
/f13 tutorial jason查看 Jason 的游玩文本帮助
/f13 tutorial counselor查看文本帮助

权限

FridayThe13th.admin - 管理员权限
FridayThe13th.user - 玩家权限
FridayThe13th.Build - 放置/破坏 无视游戏边界
