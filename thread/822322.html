EnvironmentalAwareness



介绍
这款插件的创意是由 @Espinete87 提出的. 当你种树时你会获得金钱,破坏树苗会扣钱.
注意:插件可能存在bug 插件作者不打算修复
由于插件是开源的 如果你是插件开发者你可以重制这款插件

权限
  • sapling.place.reward
拥有的权限玩家种树得钱.
如果你只给玩家这个权限的话玩家就可以用树苗刷钱

  • sapling.break.penalty
拥有权限的玩家破坏树苗扣钱




汉化配置
  1. #
  2. # 插件配置文件.
  3. # 插件作者:TheBlockBender  July 6th 2018 (在 spigot 1.12上测试,理论上兼容1.8-1.12)
  4. #

  6. # 玩家植树获得的钱.
  7. reward-money: 2.50
  8. # 玩家破坏树苗的罚款. (防止刷钱)
  9. penalty-money: 2.50

  11. # 是否在玩家获得奖励时显示消息.
  12. should-reward-message: true
  13. # 玩家植树时显示的消息, 变量 {player} 用来表示玩家名
  14. reward-message: "&8[&2\u2618&8] &a你的环保行为使你获得了 &6$ &e2.50&a."

  16. # 是否在玩家破坏树苗时显示消息.
  17. should-penalty-message: true
  18. # 玩家破坏树苗时显示的消息, 变量 {player} 用来表示玩家名
  19. penalty-message: "&8[&4\u2618&8] &c你这是在践踏自然! 你被罚款 &6$ &e2.50&c."
