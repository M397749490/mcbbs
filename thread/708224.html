WorldBanCommand


插件介绍
**~本插件是面向懒癌(小白)腐竹的,帮助不会/不想用权限组的腐竹来禁止使用某个指令
插件权限
worldBanCommand.*  可无视并使用所有被禁止的指令（op默认拥有）
插件命令
/worldBanCommand 重新加载配置
插件配置
#WorldBanCommand插件
#变量%command%代表禁止的指令
#所有世界都禁止使用的指令
AllWorldBan:
#完全匹配禁止命令
  FullMatchCommand:
    - ''
#模糊匹配禁止命令
  FuzzyMatchCommand:
    - ''
#前缀匹配禁止命令
  PrefixMatchCommand:
    - ''
#  - '命令|禁止时提示消息'
world:
  1:
    Command: "/test"
    msg: "该命令被禁止"
    #完全匹配禁止
    FullMatch: false
    #模糊匹配禁止
    FuzzyMatch: false
    #前缀匹配禁止
    PrefixMatch: true
    #无视该禁止命令的权限
    CanUsePermission: "test"

每个世界最多添加100条禁止命令,按照上面规则写
注意事项
插件可能会乱码，记得把配置转码为UTF-8
