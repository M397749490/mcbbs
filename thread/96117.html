说明：
随机传送玩家
支持两种方式：命令或按钮触发
命令：
    /randomtp <昵称/玩家名>
按钮：
    放置一个按钮
    鼠标对着它
    输入：/rlb create [传送最大半径] [传送最小半径] [世界]
    右键这个按钮进行传送

可以广泛应用于PVP、生存之类的地图


当然，惩罚性措施也是不错的


http://www.tudou.com/v/fueqjvSv2bw/&rpid=41821350&resourceId=41821350_04_05_99/v.swf


  1. 命令：
  2. # [字符串/整数] 都是可以的
  3. # 创建随机传送按钮
  4. /rlb create [最大半径] [最小半径] [世界]
  5. # 移除按钮
  6. /rlb remove
  7. # 随机传送玩家
  8. /randomtp <昵称/玩家名>
复制代码

  1. 权限：
  2. RLB.create:
  3. description: 允许玩家创建传送按钮.
  4. default: op
  5. RLB.remove:
  6. description: 允许玩家移除传送按钮.
  7. default: op
  8. RLB.teleport:
  9. description: 允许玩家使用randomtp传送.
  10. default: op
  11. RLB.teleport.other:
  12. description: 允许玩家使用randomtp传送别人
复制代码

  1. 配置：
  2. # 最小随机值
  3. min-range: 2000
  4. # 最大随机值
  5. max-range: 5000
  6. # 传送按钮ID（可以任意方块，不仅仅是按钮）
  7. BLOCKS-IDS:
  8. - 143
  9. - 77
  10. # 第一次进入游戏时随机传送
  11. RANDOM-TELEPORT-ON-FIRST-JOIN: false
复制代码
