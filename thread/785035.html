这层楼主要介绍各个物品的使用方式部分内容借鉴于MC中文百科与游戏自带的指导手册
有些物品在MOD里的指导手册，MC中文百科与这里的使用方式不同，具体使用方式请自行测试
关于合成部分
1.8以上请使用Just Enough Item (JEI)查询合成
1.6.4-1.7.10请使用Not Enough Item (NEI)查询合成
该内容排序为指导手册中的物品排序

方块:
大型按钮 (Big Button)：
  • 大型按钮正如其名，它是更大的按钮，增加了一些功能。该按钮与一个压力盘的大小大致相同，可以被放置任何可以放置普通按钮的表面。在新版本中还加了木制的大型按钮
  • 与普通按钮不同的是，它会发出一个很短的红石脉冲直到弹起。通过空手时蹲伏(shift)并用鼠标右键单击大型按钮，可以打开gui，里面有一个插槽，可以放置物品。随着越来越多的物品被放置在该插槽中，脉冲的持续时间的将延长。

建筑指导仪 (Builder Guide)：
  • 给它红石信号，建筑指导仪便会投影出方块轮廓，你可以通过Shift+右键它来改变形状，或者右键它的不同面来增大或减小轮廓
  • 创造模式下将黑曜石放在建筑指导仪上，再拿着任何方块右键它，则会自动完成搭建
  • 提供了这些形状：球，圆柱，立方，圆锥，三角形，五角形，六边形，八角形

强化建筑指导仪 (Enhanced Building Guide)：
  • 主要特点与建筑指导仪相似
  • 使用任意方块右键它，可以快速的放置方块

捕兽夹 (Bear Trap)：
  • 放在地上，右键打开，路过它的生物将夹住动弹不得，但是不会造成伤害

方块放置器 (Block Placer)：
  • 可以在里面放置9组可放置的实体或非实体方块，当接收到红石信号时，会将储存的物品放置在有洞的一面正前方一格，选择储存的物品的顺序是从上到下从左到右。当前方不能放置方块或者红石信号消失时，停止放置。

方块采掘器 (Block Breaker)：
  • 当它接收到红石信号时，会将有齿的一面前方一格内的方块打碎（没有精准采集或时运效果），然后从后方有小洞的一面排出，如果在后方放置了能储存物品的方块，会自动将物品放入。可以打碎除了基岩以外的所有实体和非实体方块。红石信号消失后停止工作

村庄高亮仪 (Village Highlighter)：
  • 放置在村庄里，接入红石信号，会显示出一个染色方框，标记村庄中心地带，和一个球体区域，标示村庄的有效范围，可能并不包含全部的村庄建筑。
  • 关于村庄的概念可以参考Minecraft Wiki上的说明，可以利用这个特性建造铁傀儡农场

梯子活板门 (Jaded Ladder)：
  • 集合了活板门与梯子的功能，打开时可以作为梯子攀爬，解决了爬梯子遇上活板门时必须跳出去的麻烦事

洒水器 (Sprinkler)：
  • 将它放置在装有水的蓄水槽上，它会向周围喷水（粒子效果）范围是以它为中心9X9的正方形。它有9个插槽，可以放入骨粉以便加速作物生长。不需要红石信号激活，一直处于开启状态。

海绵 (Sponge)：
  • 它是原版海绵的重置版，会吸收以它为中心，7x7范围内的液体。如果吸收掉了液体的源头，在吸收范围外会产生一个新的源头（但不能用空桶收集），用方块填上新的源头后剩余流动的的液体消失。当吸收岩浆时，会把周围的岩浆吸收掉同时被烧毁。可以隔着方块吸收。
  • 在吸收一大片液体的时候请务必小心，它会让液体的流动变得相当混乱

物品投掷器 (Item Dropper)：
  • 在GUI里面放物品后，每被红石信号激活一次就会有口的一面射♂出掉落状态的物品,，你可以调整速度与范围

电梯 (Elevator)：
  • 使用电梯至少需要两个电梯方块，且两个电梯方块必须垂直放置，传送有效距离为19格，电梯传送距离可在配置文件中修改，电梯中间间隔4个方块以上时无法传送。
  • 站在电梯方块上，按空格（跳跃）上升一层楼，按shift（蹲）下降一层楼
  • 最新版本中电梯可以用染料染色，只有同种颜色的电梯之间才能互相传送
  • 默认每次使用消耗17点经验，不足不能使用。可以在配置文件中修改是否消耗经验

画布 (Canvas)：
  • 可以被颜料刷染色，具体使用方法请看颜料刷

经验地漏 (XP Drain)：
  • 放在本mod的蓄水槽上面（或其他mod中能从顶部输入液体的容器），玩家站着上面就会快速的失去经验流进蓄水槽。落在上面的经验球也会被吸进去。

经验莲蓬头 (XP Shower)：
  • 安装在装有经验的蓄水槽侧面，经验球会以一定的速度从淋浴头流出来。
  • 只有在蓄水槽里的经验液面高于淋浴头才会流出。这一些被排出的经验球可以被经验地漏或者MFR的排污机吸收。

经验装瓶器 (XP Bottler)：
  • 用来制造附魔之瓶，需要在里面放空瓶。
  • 在周围放上装有经验的蓄水槽，然后打开GUI设置经验输入面和物品输出面，在物品输出面放置箱子会自动将制造好的附魔之瓶放入。在gui里按住鼠标右键拖动调整视角，左键单击选择面，选中的面会变成红色。

绘图桌 (Drawing Table)：
  • 将空白模具放入绘图桌中，选择自己喜欢的图案后在右侧取出即可（一旦绘制无法重复利用）

绳梯 (Rope Ladder)：
  • 使用时像原版梯子那样贴在其他方块侧面
  • 旧版设置：一旦贴上第一个绳梯，绳梯会立刻向下延伸，直到绳梯已经到达地面无法再延伸 或因背包中的绳梯耗尽无法延伸为止
  • 新版设置：贴上第一个绳梯后，需要一定数量的绳梯才会立即向下延伸。（可以在配置文件中修改相应配置开启或者关闭旧版功能）
  • 这些向下延伸的部分不需要依附方块，碰撞体积与梯子相同，即可沿着绳梯爬下
  • 拆除时只需拆除最高的一个，全部绳梯就会掉落

脚手架 (Scaffolding)：
  • 放下后在一段时间后会自动变成掉落物，有些类似没有原木支撑的树叶
  • 没有像沉浸工程一样的攀爬功能

自动铁砧 (Auto Anvil)：
  • 自动附魔/修复物品，并且无耐久
  • 不能直接用自身经验，需要定义经验输入口后输入经验

自动附魔台 (Auto Enchantment Table)：
  • 自动附魔物品
  • 不能直接用自身经验，需要定义经验输入口后输入经验
  • 周围也是要跟原版附魔台一样，需要书架才能提升附魔等级的

蓄水槽 (Tank)：
  • 一种液体容器，单个容量16000mb（16桶），可摆成任意形状的液体储罐；液体会从高水位流向低水位，并伴随有液面波动的效果。每一块可单独拆掉，掉落物能保持里面的液体。
  • 把经验地漏放在蓄水槽上的话，站在地漏上，自己的经验就会快速的流进蓄水槽。假如里面装的是液态经验的话，空手右键蓄水槽可以吸取一级的经验。这个蓄水槽也能装其他mod中的部分液体

虚空漏斗 (Vacuum Hopper)：
  • 放置后会自动将距离自身3格内的掉落状态的物品吸入自己的储存空间或者相邻的储存设备和管道(也会将经验球自动吸收并转化为液体经验)，吸力很强。可以在刷怪塔上使用

调色器 (Paint Mixer)：
  • 在机器内放置4种染料，在上方放一个牛奶桶，可以用鼠标拖动左上方的红点粗略选择颜色，也可以在代码区输入颜色的RGB代码，左边中间的条是调整颜色的灰度的，左下角是颜色预览。最后点击 mix 开始生成该颜色的颜料罐。
  • 把生成好的颜料罐放在地上，然后手拿颜料刷右键蘸颜料，一桶颜料可以蘸30次，蘸完后变成空桶掉落。颜料刷可以在方块表面刷颜色。

铺路石 (Path)：
  • 没有额外的效果，可以用来铺路，会随机生成样式。

电风扇 (Fan)：
  • 收到红石信号时启动，可吹走实体（玩家、生物、物品等），可以用于建造刷怪场或农场。

物品：
/dev/null：
  • 一个能储存1组物品的容器，超过1组的物品将会被销毁。

刮刀(Squeegee)：
  • 拿在手里右键被颜料刷刷过的方块表面可以刮掉颜料。通过shift+右键可以刮掉一整面的颜料

史莱姆区块探测器(Slimalyzer)：
  • 放在背包中，当玩家走进史莱姆区块的时候会“嘟~”一声，并变成绿色，可以用它来做史莱姆农场

史诗橡皮擦(Epic Eraser)：
  • 擦除某个物品的的使用记录？具体使用方式不明

大金属棒(Big Metal Bar)：
  • 可以旋转某个方块的方向，类似扳手

海绵棒(Sponge)：
  • 作用跟海绵一样可以用来清除液体，但是容易坏掉

游标(Cursor)：
  • 手持游标shift+右键绑定某个方块后，在一定范围内可以使用它右键打开某个物品的GUI，超过这个范围后需要消耗经验

滑翔翼 (Hang Glider)：
  • 右键它即可穿在身上（并非装备在装备栏），在高处掉落时会滑翔，按住Shift滑翔速度加快。

睡袋(Sleeping Bag)：
  • 在晚上时右键它即可睡觉，而且不会重置出生点

空白模板(Unprepared Stencil)：
  • 将它放到绘图桌中即可弄到自己想要图案。然后放到某个可被颜料刷绘制的方块上面，用颜料刷即可涂出图案

行李箱(Luggage)：
  • 它是一个可以一直陪伴在你身边的移动箱子，被雷劈中后即可增加一倍的容量。

起重机控制器(Crane Control)：
  • 它可以控制起重机背包，手持它左键释放/拾取，右键升起，shift+右键下降

起重机背包(Crane Backpack)：
  • 他需要装备在装备栏里，通过配合起重机控制器，可以拾取玩家/实体/方块，在服务器中可以破坏领地

音波眼镜(Sonic Glasses)：
  • 带上后眼前仿佛蒙上一层黑纱，白天勉强可以看到东西，但是对声音变得灵敏。会在屏幕上显示出走过的路线和怪物之类有声音的东西。

颜料刷(Paint Brush)：
  • 拿在手里从颜料罐蘸颜料后可以把颜料涂在方块表面，假如方块上覆盖了模子便可涂出那个模子的图案。可以刷24次。
  • 如果不是原版的16种颜色，颜料刷无法涂在羊毛等一些物品

其他物品:（指导手册未加进去的）
计步器(Pedometer)：
  • 它可以用来计算：起始位置(X Y Z),当前移动速度(m/tick)，平均移动速度(m/tick)，距离起始位置(m)，直线距离(m)，直线移速(m/tick)，上次移速(m/tick)，距离上次记步点(m)，距离上次记步时间间隔(tick)，记步总耗时(tick)。
  • 具体使用方法：右键开始记步，shift+右键重新记步

制图机器人(Cartographer)：
  • 用于绘制高度图，右键地面放置，手持空白地图shift+右键机器人为机器人装载地图。用准星指向绘图机器人可以查看进度，当整张地图全变成亮绿色时绘制完成。

高度图投影仪(Height Map Projector):
  • 在里面放置绘制完成的高度图后，会在上方投影出3D的地图。
  • 具体使用方式请自行测试或者看视频

高度图/空白地图(Empty Map)：
  • 空白地图有1:1,1:2,1:4,1:8,4种型号，按着shift右键制图机器人放入，然后机器人会自动绘制以你此时所在点为中心的3D地图。
  • 当机器人绘制地图完成后按着shift右键绘图机器人取下。放入高度图投影仪可投影出3D地图

方块放置器 (Block Placer)：
  • 可以在里面放置9组可放置的实体或非实体方块，当接收到红石信号时，会将储存的物品放置在有洞的一面正前方一格，选择储存的物品的顺序是从上到下从左到右。当前方不能放置方块或者红石信号消失时，停止放置

魔法蜡笔(Magic Crayon)：
  • 魔法蜡笔有很多种颜色，右键可以放置蜡笔方块
  • 蜡笔方块默认无碰撞体积，带上特定眼镜后有碰撞体积，不会使人窒息
  • 玩法推荐：可以做一些密室（玩监禁play）之类的地方，放附魔台之类的东西，当然如果你是op的话，你可以用这个策划出各种各样好玩的游戏

蜡笔眼镜(Crayon Glasses)：
  • 用纸和魔法蜡笔合成与魔法蜡笔相同颜色的蜡笔眼镜,只有带着同样颜色的蜡笔眼镜才能看到绘制的蜡笔方块并且看到的绘制的蜡笔方块会变成实体。摘下眼镜后慢慢变淡消失，同时失去实体

魔法铅笔(Magic Pencil)：
  • 玩家可以使用右键单击创建不可见的铅笔绘制的块。铅笔所绘制的块不能被看见，但是是有形的，玩家无法穿过它们，与魔法蜡笔创建的块不同。用铅笔绘制的块也可以通过装备铅笔眼镜，惊艳科幻色调眼镜或恶棍眼镜看见。
  • 使用魔法铅笔，玩家可以创建一共有八种不同类型的块。默认设置创建一个方块。拿着铅笔时通过蹲伏（shift）并单击鼠标右键，可以改变模式。

铅笔眼镜(Pencil Glasses)：
  • 用于查看魔法铅笔绘制的块，必须在装备在头盔插槽时才能生效。

惊艳科幻色调眼镜(Amazing Technicolor Glasses)：
  • 装备眼镜后玩家可以看到魔术蜡笔或魔术铅笔创造的所有方块，类似恶棍眼镜。但又有些不同，玩家带着惊艳科幻色调眼镜可以穿过所有魔法蜡笔创造的块，只有神奇铅笔创造的块是实体存在。这个工具只能在地牢或者在创造模式下获得，因为它是一个非常强大的工具。

恶棍眼镜(Badass Glasses):
  • 装备在头盔位置时可以看到魔法铅笔和魔法蜡笔绘制的方块。
  • 与惊艳科幻色调眼镜不同的是，可以选中绘制的方块并打破它。因为功能强大，所以只能从创造模式获得。

投掷加农炮(Item Cannon)：
  • 用于将周围容器中存储的物品打出至指定地点。
  • 使用方法：拿着本mod的指针，按住shift右键大炮，然后按住shift右键目标方块。定位成功后会有条抛物线出现。然后用红石信号激活大炮，大炮会持续不断的将周围储存的物品沿着抛物线射出，以掉落状态掉到地上。红石信号终止时大炮终止发射。
  • 适用于原版的箱子，熔炉（会把燃料，要熔炼的物品也一并扔出所以不能做输出设备），投掷器，发射器等容器，不能用于末影箱。

指针(Pointer)：
  • 用于定位传物加农炮的目标地点，方法是先右键传物加农炮再右键目标地点。然后会从传物加农炮炮口产生一条抛物线到目标地点。

捐助站(Donation Station)：
  • 鼠标右键打开一个界面，里面有一个格子，可以将物品放入，它会确定这是什么mod的物品，假如储存有捐献这个mod的作者的网页链接，下方的按钮会亮起，点击可以打开捐款页面。

旗子(Flag)：
  • 制作旗子的地毯颜色不影响旗子的颜色，它第一次做出来时总是绿色的，拿在手里时按住shift+右键切换颜色，插在地上时右键可以改变尖头指向的方向，插在墙上时则不能改变方向。

天空方块(Sky Block)：
  • 反转天空方块放置后会变成具有天空视觉纹理的方块（四面），但里面没有云，只有天空、太阳、月亮和星星。经过红石信号激活后，它会变成灰色的天空方块。
  • 在某些版本中，可能会导致客户端闪退，推荐直接禁用它，如果服务器里不幸的发生了这件事情，只能采用WorldEdit大法了

靶子(Target)：
  • 放置在地面上用红石信号激活后立起，被弓箭射中后会向周围输出瞬间的红石信号。可以用于解谜游戏。

黄金之眼(Golden eye)：
  • 合成后需要用10个末影珍珠通过合成充满耐久，然后可以使用100次。
  • 它与末影之眼用于类似。寻找世界中自然生成的建筑，如村庄，要塞等。先拿着黄金之眼潜行右击一次才能正常使用！然后每次扔出都会在空中向建筑方向移动一小段距离再落地。

治愈方块(Healer)：
  • 当玩家站在上面时会以较快的速度恢复生命值，但不会治愈除玩家的所有生物。
  • 治愈方块不能合成，只能通过创造模式获取。

美味粘土(Tasty Clay)：
  • 美味的粘土，食用后回复半格饥饿度。大概是作者的恶趣味，也许很好吃。

金蛋(Golden Egg)：
  • 放置在地上一段时间后，会旋转着离开地面并发光，同时使其周围一定范围内的方块飞起来（表面一层，注意这也可能会发生在你所站立的方块上，让你掉到方块下面去，可能会有风险），金蛋飞到一定高度后会爆炸，造成破坏的同时，之前飞起来的方块一般来说也会落回原位（也有可能不会）。基于该特性，建议在服务器的配置中关闭金蛋的爆炸功能，或者禁用该方块合成和使用。避免带来不必要的损失
  • 此过程完成后会生成一个名为“迷你替身”的小型玩家生物，具有10点生命，不会帮你做任何事，只会时不时的把你抓起来骑在它的头上，这时玩家除非按Lshift（脱离坐骑）下来，否则无法移动，这也许会对工作或者战斗时的玩家造成不利后果。（在新版中貌似除了采花和走来走去就啥都不会做了）

附魔书-尔虞我诈 (flim flam)：
可用此附魔书在防具上附魔，总共四个等级，附魔等级越高可以在更多的防具上附魔。当受到来自怪物或玩家的伤害时，可以使他们的幸运值(Luck)降低。

  • Advent of Ascension
  • CombatLog plugin
  • RotaryCraft (when player is killed by grinder)
  • ???

3.Code that spawns graves works after all other mods had chance to add their drops. During that time, any mod can modify list of already added items or even cancel drops at all.
Graves should always contain items that would be dropped normally - so if item isn't in grave, it would probably not drop even if graves were disabled.
First step is to make sure this isn't the case.
Please recreate this death in following conditions:

  • in flatworld
  • with the same mods
  • with inventory reproduced as close as possibly (may be restored with ob_inventory restore)
  • after switch to survival If grave didn't spawn, then it's possible that some other mod captures all drops before our code.


4.To fully verify it, use /gamerule openblocks:spawn_graves false command to disable graves in this world and re-test again. If nothing drops on the ground, try to identify mod that causes that.

Advanced debug methods
If you want to see, what other mods can interfere with grave spawning, please use either debug:gravesDebug config option or EventLog (available here). You can change value of this option without restart with following command:
  1. <font face="微软雅黑"><font face="微软雅黑">/om_config_s set openblocks debug gravesdebug true</font></font>

If command is used, your logs should contain information about drops handlers. Note: This information will be visible only in log file, not in console. If EventLog is used, you have to print it with /list_events_s after at least one death.

If grave is spawned, contents will be stored in appropriate file (see next question). OpenBlocks will also store pre-death inventory in separate file. This usually is done before other mods have change to modify it, so it may be more reliable.

2.How do I restore my inventory with command?
As you may have noticed from previous question, OpenBlocks has command that allows to restore inventory from before death or examine grave contents, even if grave was already destroyed or not spawned at all.
It can be used in two ways:
  • /ob_inventory restore - replaces contents of player's inventory with stored items
  • /ob_inventory spawn - drops whole inventory or just single item in world

If you are confused by syntax, almost all parameters have tab-completion.

To use it, you need to enable commands in single-player or be op in multi-player.

Before you can restore, you need to know which file contains items you want to restore. Path usually looks like this:
  1. <font face="微软雅黑">saves/<world name>/data/inventory-<player name>-2015-04-04_21.48.30-death-0.dat</font>
复制代码
You can just start typing player name and then press tab key, it should already fill rest with suggestion. ** specifies what event triggered file creation. Currently it may be one of following strings:
  • death - contents of player's inventory from moment before player death
  • grave - contents of grave
  • command - snapshot of inventory, created with /ob_inventory store command


3.How do I disable graves?
You can disable graves via configuration file, like any other block and item in OpenBlocks. Just make following change to configuration:
  1. <font face="微软雅黑">blocks {
  2.     B:grave=false
  3. }</font>
复制代码
Note that this will also remove all existing graves in save.
You can also disable graves per world (just creation, not block), by using gamerule command, i.e./gamerule openblocks:spawn_graves false. This method won't remove existing graves.

4.I disabled graves, but they still spawn?
Are you sure those are our (i.e. OpenBlocks') graves? This seems like silly question, but this is most common solution to this problem.  Easiest way to verify that is to look for logs mentioned in one of previous questions.

5.How do I break graves in adventure mode? Can I empty grave without breaking it?
If you can't (or don't want to) break grave, you can just right-click it with shovel. Unfortunately, we can't control list of block that can be destroyed in adventure mode with specific tool.Also, please remember, that digging graves may get you into trouble.

6.What happened to radio?
We removed it.Between Minecraft 1.6 and 1.7 sound engine changed. When trying to port radio, code started to look more and more like very limited and buggy external player with on/off switch in Minecraft. So it become kind of pointless.

7.Why does elevator not work?
There are usually few possible causes:
  • Not enough XP. Since few versions elevators drain experience in survival mode. This option can be disabled in configuration.
  • Too many blocks between elevators. This limitation is also configurable.
  • Badly implemented air-like blocks. Most mods implemented various fake air, light and tracking blocks right, but there is still room for misbehaving implementation.
  • Different elevator colors. Elevators will only teleport to other elevators with same color.


Interactions with Better Sprinting and similar mods.
In some cases switching to alternative method of getting information about player movement may help (especially when it's cased by interaction with other mod).

To do it, open OpenModsLibCore.json in config folder on client, find activate_movement_callback and change line below it from "value": "true" to "value": "false".

8.Does /ob_inventory restore work on non-vanilla inventories?
This depends on other mods.Currently OpenBlocks contains code that allows storing such inventories and events to signal loading and storing inventory (openblocks.api.InventoryEvent.*).
Though it's recent addition and as far as we know, no mod uses that.
We may add integration directly in OpenBlocks, if mod has proper API.

9.Why doesn't building guide show any markers?
Since version 1.3 this block needs redstone power to work. This behavior can be configured with guide.redstoneSensitivity configuration option.

10.How can I add information about my mod to donation station?
Send string IMC with key donateUrl and URL as value.

11.How can I disable flim-flam enchantment?
For new worlds: just set enchantment id to -1
For existing worlds: removing any enchantment from game may break world. But in case of flim-flam enchantment, you can just disable all effects with blacklist/whitelist stored in flimFlamBlacklist+reverseBlacklist config option or just disable potentially harmful ones with safeOnly.

You can get list of all flim-flam effects by using tab-expansion on /flimflam command.
