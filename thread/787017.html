★高级传送门★
自定义传送门形状 | 跨服传送 | 进入传送门执行指令


插件介绍
Author: sekwah
本插件的功能类似另一款名字以A开头以Gates结尾的传送门插件，可用于制作传送门并使用它传送至设置好的坐标，还拥有跨群组服传送，传送冷却，传送后执行指令等多种功能。

玩家走进哪种方块会被传送？
理论上你可以设置所有来自MC的方块，但是实际上只有“你能走的进去”的方块可以设置，推荐的方块有空气air，水water，岩浆lava，地狱传送门portal，末地传送门ender_portal，末地折跃门end_gateway

传送门的形状？
方形的传送门已经过时了！你现在可以设置任意形状的传送门！（传送门只与“玩家走的进去”的传送方块有关，与传送门框架无关，不设框架都可以）

跨服传送
可在创建传送门时设置通过传送门跨服传送至某子服

进入传送门执行指令
可在创建传送门时设置玩家进入传送门后执行控制台指令，或玩家以管理员身份执行指令




创建传送门
创建目的地
  • 与其它插件不同的是，本插件的“传送门”与“目的地”不是配套的，多个传送门可以传送到同一个目的地
  • 使用指令/desti create <目的地名> 将你所站的位置设置为目的地

创建传送门
  • 使用指令/portal selector 获得创建传送门需要的铁斧
  • 建一个传送门，形状任意，框架有没有都可以，但是必须包含“玩家走的进去”的传送区方块，比如水，空气，地狱传送门等等（关于某些难以放置的方块，如传送门，折跃门等，插件提供了指令可获得相应方块，详参下方指令）
  • 使用铁斧分别左键右键出传送门的区域，选择区域时务必把“玩家走的进去”的传送区方块全部圈起来
  • 使用指令创建传送门/portal create name:<传送门名> desti:<目的地名> triggerblock:<传送区方块种类> 其中传送区方块的标准方块名称可以在这里找到，如果不指定传送区方块，将默认是地狱传送门
常用传送区方块名称：空气air，水water，岩浆lava，地狱传送门portal，末地传送门ender_portal，末地折跃门end_gateway
  • 至此你便完成了一个传送门的创建，你可以在创建指令里添加更多变量，可添加的变量如下，红色标注的变量是必须的：
- name:<传送门名>  传送门的名字
- desti:<目的地名>  传送门的目的地
- triggerblock:<传送门方块种类>  玩家走进哪种方块会被传送
- bungee:<子服名>  跨服传送到的子服名称
- permission:<所需权限>  玩家需要相应权限才能使用传送门
- command:"#指令名"  玩家进入传送门后执行的指令，若指令以#开头，代表由控制台执行指令，若指令以!开头，代表让玩家以管理员身份执行指令，可在指令中添加变量@player指代玩家名称

注意事项
  • 穿过岩浆传送门还是会让你着火
  • “地狱传送门portal”这个方块相当特殊，两个方块并排放会自动消失，这个问题你问我我也不知道怎么解决



指令与权限
  • /portal help - 插件帮助
  • /portal selector - 获得选择传送门区域的铁斧
  • /portal select - 输入此指令后点击一下某传送门内部的方块，将选中此传送门
  • /portal unselect - 取消选中此传送门
  • /portal remove - 移除选中的传送门
  • /portal list - 列出传送门
  • /desti create <目的地名> - 创建目的地

以下指令用于建造传送门
  • /portal portalblock - 获得一块羊毛，放置此羊毛即可在放置位置生成一个地狱传送门方块
  • /portal endportalblock - 获得一块羊毛，放置此羊毛即可在放置位置生成一个末地传送门方块
  • /portal gatewayblock - 获得一块羊毛，放置此羊毛即可在放置位置生成一个末地折跃门方块


本插件没有任何权限需要给玩家
