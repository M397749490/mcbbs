插件介绍：
随机显服务器图标
显示全部玩家皮肤头
查看未读邮件
在Motd里可自定义/多项随机显示文字或信息（ 例：{ESSENTIALS_MONEY} 为金币显示 ）
设置一个无限大的虚拟玩家数目
排除ping高的玩家搜索/加入不了服务器
截图(不明)


插件图介：



兼容插件：
======Static======
======Dynamic======
以及
======Player related======
具体信息点我

插件指令：
/smartping timer
设置motd为当时时间
/smartping timer <Minutes>
延长在Motd时间
/smartping timer -<Minutes>
减少在Motd时间
/smartping test
显示玩家在Motd
/smartping test <Player>
显示指定玩家到Motd
/smartping test #default
显示取消查看的玩家
/smartping test #banned
查看ban
/smartping test #forbidden
显示指定的喜欢的玩家列表显示
/smartping test #multiple
显示同一个IP下的玩家 (unless allow_multiple 设置 true)
/smartping reload
重载config.yml文件
/smartping vars
帮助界面
/smartping vars <Page>
切换帮助界面的页面
/smartping addbg <Url>
从外链下载图片到服务器

插件权限：
smartping.*
可以使用此插件的所有指令
smartping.timer
可以使用后缀为Timeer的指令
smartping.stick
可以使用后缀为Stick的指令
smartping.specialcolor
可以使用后缀为Specialcolor的指令
smartping.reload
可以重载插件
smartping.vars
可以查看帮助
smartping.addbg
可以使用后缀为Addbg的指令
