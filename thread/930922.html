作者: 轻光233    时间: 2019-12-7 07:30
在你的监听器里加上以上代码
  1. Map<String,String> lastest_cmds = new HashMap<>(); //记录玩家指令

  3. @EventHandler
  4. public void respawn(PlayerRespawnEvent event){ //监听玩家重生
  5.     String uid = event.getPlayer().getUniqueId().toString(); //获取玩家uid
  6.     String cmd = null;
  7.     if((cmd = lastest_cmds.get(uid)) != null){ //判断玩家是否输入过指令
  8.         Bukkit.dispatchCommand(player,cmd); //执行指令
  9.     }
  10. }

  12. @EventHandler
  13. public void death(PlayerCommandPreprocessEvent event){ //监听玩家输入指令
  14.     String uid = event.getPlayer().getUniqueId().toString(); //同上
  15.     lastest_cmds.put(uid,event.getMessage().substring(1)); //更新玩家指令记录,由于没有滤掉'/'号所以加一个substring(1)
  16. }
