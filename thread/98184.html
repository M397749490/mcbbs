&#8226;Fixed ability/skill files autoloading on reload or startup. 0.6.2 created any ability file that was corrupt or missing which result in server owners having to use every skill whereas they may only want some or one.
修复了技能和能力的自动重读。在0.6.2创建了所有能力文件，管理员可以修改你想要的一些或者一个。
&#8226;Ability fix now allows you to configure which abilities are enabled for your players to use as a rank line. Just set the respective skills "enabled" setting to "true" or "false" in the config.yml.
你要什么技能就在config。yml里面改为true或者false就行
&#8226;Added in-game editing of most configuration settings, including enabling and disabling abilities/files.
在游戏中可以修改很多的设置
&#8226;Improved Coloring system a little more. getting close to 100% color scheme selectable launch.
改进颜色系统
&#8226;Added 2 new nodes (mru.admin, mru.show) - see permission in the main section for details.
加了2个新文件 (mru.admin, mru.show) 在主选单有细节可以查看
BACKUP YOUR EXISTING ABILITY FILES AND CONFIG.YML
&#8226;Stop your server

&#8226;Delete config.yml from " /plugins/Mcmmorankup " - 异常重要!!

&#8226;Delete your ability files from " /plugins/Mcmmorankup " - (version prior to 0.6.2)
&#8226;Start your server
&#8226;Check the server.log for any issues with McMmoRankup. You should see that every ability file was missing, but was created during the install of this release. You can just copy your existing ability files (from step 3 above) into the new skills folder: " /plugins/Mcmmorankup/skills "
&#8226;Edit the new config.yml file to adjust your settings again. The old config.yml file has been changed and any existing config.yml files left in the Mcmmorankup folder will create version confusion for you and the mcmmoRankUp plugin.
&#8226;Transfer over any edited files to their respective folders
&#8226;Either re-start your server or Issue, in-game, the /mru reload command. If in-game reload does not reload properly (sometimes happens), re-start your server.
