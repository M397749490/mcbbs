实用的网络API
大概吧。。。
0.规范

    <> 代表变量     " " 代表字符串

1.原理与实现
    这个插件将连接到另一个外部的socket服务器,然后在mc中的事件触发时向服务器发出特定格式的字符串,然后经过外部的socket服务器处理后返回特定格式的字符串,经过本插件计算最后作出反应。

2.主要功能
    可以将mc与web连接起来其他功能等待你们的发现
     （本插件同时内带了命令创建容器gui后面讲解）


3.举点例子
    ①登录拦截(难道你甘心用别人的通行证，用别人的启动器吗，为什么不用你自己的服务器呢，这个就可以帮你实现!)
        通过玩家登录返回的事件判断是否在可登录表内不可则kick出去awa,不影响登陆插件的实用。
         
          后台为证
    ②一键举报
          通过自带的信息发送装置,发送请求头与内容,可在socket服务器判断请求头,然后处理请求信息最后做出响应
         
         
          直接在聊天框输入tx,holyds就是这个效果了无需 /
          输入后将向socket服务器发送 "player|holyds|holyds#tx#ask" 第一个holyds是发送者id第二个是输入的内容第三个是请求头第四个表示为请求
          后续计算就看socket服务器的了 （请忽略这不整齐的背包）
        
        当然可实现的功能可不止这么点比如网站上的mc装备拍卖awa可以通过php让网站执行程序连接到socket服务器然后发送数据awa然后断开连接。这可以将网站与socket连接起来。进一步可实现网站上的种种操作。

4.config解析  


5.事件一览   
发送内容触发条件
this_is_server当插件启动时
log|<内容>
发送日志的格式
onlines|<num>num为当前在线人数 每60s发送
player|<id>#loginid登录时发送
player|<id>|<请求内容>#<请求头>#ask
当使用internalc操作台发起请求时
player|<id>|<内容>#chat玩家说话时发送
player|<id>|<容器标题>#<格数>#click玩家点击容器时发送

6.命令一览
命令作用权限
inter open打开internall操作界面internall.open
inter cas <str> <id>给id打开一个str编码的容器界面internall.cas
inter page <url> <id>给id打开一个url(http://...)上面的编码的容器界面 internall.page
inter send <str>向socket服务器发送strinternall.send
   
7.指令容器

    inter cas <str> <id> : 首先将str按照格式解析然后经过计算给id打开对应容器
    举个栗子: 54,mc主站,第一格<x>5:0<x>lore1<x>lore2%第二格<x>2:0<x>lore2%§b第三格<x>3:0<x>lore2%第四格<x>4:0<x>lore2%第五格<x>5:0<x>lore2%第六格<x>6:0<x>lore2%第七格<x>7:0<x>lore2%第八格<x>15:0<x>lore2%第九格<x>16:0<x>lore2（请注意并没有拐行，这是超过了页面的长度（支持§）
   

    inter page <url> <id> : 首先读取url上面的数据然后以cas同样的方式给玩家打开容器

    然后就是事件当玩家点击格子时会返回player|<id>|<容器标题>#<格数>#click
    一定不要让容器标题和其他插件的操作界面一样！！！
