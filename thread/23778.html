 哦，昨天时间仓促，
没说完就下线了，我只是想拿论坛做个测试，在之前拿网易测试还算是成功，就是拿qq测试就失败了，昨天发上来只是想做个验证，如果想自己试试的话，代码：
  1. @echo off
  2. ping www.mcbbs.net /n 4&&goto checkurl||goto oldip
  3. :checkurl
  4. for /f "tokens=2 delims=[]" %%i in ('ping www.mcbbs.net /n 4 /w 0') do echo %%i %date%%time%>>测试结果.txt
  5. echo [InternetShortcut]
  6. echo URL= http://www.mcbbs.net
  7. )
  8. start "" "www.mcbbs.net"
  9. goto :eof
  10. :oldip
  11. for /f "tokens=1 delims= " %%a in (log.txt) do set urlis=%%a
  12. start "" "http://%urlis%"
  13. goto :eof

  15. ::********************
复制代码

只要把上面的www.mcbbs.net改成要测试的网站就行了，测试结果会在文件同级目录下新建一个叫测试结果.txt的文件。测试完成后会自动打开测试网页。我不是想黑了论坛，只是做个测试，在此声明一下。谢谢！
