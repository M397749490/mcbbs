介绍：
本插件是一款基于Economy经济API的收购插件，与EconomyShop对应。

使用：
将前置插件与本插件一起扔到服务端plugins文件夹里，重新启动服务器即可。

命令：
命令
权限
说明
/sell create [物品id[:附加数据值]] [数量] [价格] [方向]economysell.command.sell.create创建收购实体
/sell removeeconomysell.command.sell.remove移除收购实体
/vend [数量]economysell.command.vend**物品

权限：
权限
说明
economysell.*包括EconomySell的所有权限
economysell.break允许玩家破坏收购实体
economysell.command.*允许玩家使用EconomySell的所有命令
economysell.command.sell.*允许玩家使用/sell命令
economysell.command.sell.create允许玩家使用/sell create命令
economysell.command.sell.remove允许玩家使用/sell remove命令
economysell.command.vend允许玩家使用/vend命令
economysell.create允许玩家创建收购实体
economysell.sell允许玩家**物品

配置：
config.yml
  1. data:
  2.   save-on-change: true
  3. #自动保存
  4. language: zh
  5. #语言
  6. #内置en(英语)、jp(日语)、ko(韩语)、ru(俄语)
  7. #zh(中语)为汉化
  8. sell:
  9.   tap-twice: true
  10. #是否启用双击确认
  11.   enable-vend: true
  12. #是否启用收购命令
  13. destroy:
  14.   block: true
  15. #是否允许破坏方块
