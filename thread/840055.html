作者: SPGoding    时间: 2019-1-26 22:00
假设这个盔甲架有个 tag 叫 xxx

execute as @e[tag=xxx] at @s run teleport @s ~ ~ ~ facing entity @e[type=!player,type=!item,tag=!xxx,limit=1,sort=nearest]

移动：
execute as @e[tag=xxx] at @s run teleport @s ^ ^ ^0.1

不能在execute as @e[tag=xxx] at @s后面接facing吗

execute facing 的意思是，以该朝向执行命令，实体的朝向实际上并未被改变

如果使用
execute as @e[tag=xxx] at @s facing entity @e[type=!player,type=!item,tag=!xxx,limit=1,sort=nearest] run teleport @s ^ ^ ^0.1
那么是可以的
