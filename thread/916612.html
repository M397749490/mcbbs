功能
· 让你的潜影盒可以拿着右键打开
· 让你的潜影盒可以在背包中右击打开
· 可以自定义右键打开潜影盒的小标题如“可爱迷人的小箱箱”
· 可以自定义打开/关闭潜影盒听到的声音
· 采用metadada储存数据，即使您卸载插件，您的数据也不会丢失一丝一毫
· 作者自己的介绍
Features:
100% Customizable:
You can customize open and close messages and sounds, inventory name, cooldown.

Right-click shulkerbox in inventory to open it:
You can open a shulkerbox by right-clicking it inside the your inventory.

Custom inventory names:
You can choose the inventory name for shulkerboxes, you can also use %itemname% to use the shulkerbox's name in the inventory name.

Sounds:
Ability to enable/disable and config the sound that is played when a player opens/closes a shulkerbox.

Items saved as metadata:
Better Shulker Boxes doesn't storage the container inventory in a file, as some plugins do (for example, playervaults). Instead, items are stored as MetaData of the shulker box, so if you uninstall the plugin no items will be lost.

命令
/bsb - 输出插件版本
/bsb reload - 重载配置文件
权限
bettershulkerboxes.* - 授予所有权限(建议管理员)
bettershulkerboxes.use.* - 授予所有玩家权限
bettershulkerboxes.use - 允许玩家通过两种方式打开潜影盒(必须在config中开启另一种方式)
bettershulkerboxes.use.rightclick - 允许玩家在背包中右击打开潜影盒
bettershulkerboxes.bypasscooldown - 允许玩家绕过冷却时间
bettershulkerboxes.updatenotify - 允许玩家收到来自新版本的通知
bettershulkerboxes.reload - 允许玩家重载插件
配置
  1. # Better Shulker Boxes - By Rektb
  2. # PLEASE SEE https://github.com/lMartin3/BetterShulkerBoxes/blob/master/src/main/resources/config.yml for an example config.yml
  3. # PERMISSIONS:
  4. # bettershulkerboxes.*: Grants all permissions (Recommended for admins)
  5. # bettershulkerboxes.use.*; Grants all permissions (Recommended for users)
  6. # bettershulkerboxes.use: Allows players to open shulkerboxes in both ways UNLESS rightclick_requires_permission is set to true
  7. # bettershulkerboxes.use.rightclick: Allows players to open shulkerboxes by rightclicking them in the inventory (rightclick_requires_permission doesn't matter)
  8. # bettershulkerboxes.bypasscooldown: Allows players to bypass the cooldown (Recommended for exclusive ranks)
  9. # bettershulkerboxes.updatenotify: Allows players to receive notification about new versions. (Recommended for admins)
  10. # bettershulkerboxes.reload: Allows players to reload the config. (Recommended for admins)

  12. version: 2.6.0
  13. prefix: '&8[&3BSB&8] '
  14. inventory_name: '&7潜影小箱箱'
  15. open_msg: '&e你打开了潜影小箱箱...' # 设置为'none'以禁用 (带引号)
  16. close_msg: '&e你关掉了潜影小箱箱...'  # 设置为'none'以禁用 (带引号)
  17. no_permission_msg: '&c你没有权限这样做' # 玩家没有权限时收到的提示
  18. cooldown_msg: '&c潜影盒还没有准备好哟' # 玩家试图打开潜影盒但冷却未结束时发送的提示
  19. config_reload_msg: '&b插件配置成功重载' # 插件重载时的提示
  20. config_reload_error_msg: '&c插件的配置出了一点问题,查看后台以排查' # 同上,但这是出现问题发送的提示
  21. cooldown: 5 # [必须输入整数] 玩家打开潜影盒的冷却(单位: 毫秒)
  22. open_sound: 'BLOCK_SHULKER_BOX_OPEN' # [声音类型] 玩家打开潜影盒听到的声音,设置为'none'以禁用 (带引号)
  23. close_sound: 'BLOCK_SHULKER_BOX_CLOSE' # [声音类型] 玩家关闭潜影盒听到的声音,设置为'none'以禁用 (带引号)
  24. cooldown_enabled: true # [Boolean] 是否启用冷却时间
  25. requires_permission: true # [Boolean] 玩家打开潜影盒是否需要权限
  26. enable_rightclick_open: true # [Boolean] 是否能通过在背包中右键单击打开潜影盒
  27. rightclick_requires_permission: false # 右键单击打开潜影盒是否需要权限<font size="4">
