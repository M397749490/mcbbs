管理类

  1. /op [ID]

ess的用户组权限管理插件


  1. /mangadd [名字]   
  2. 创立一个用户组
  3. /mangaddp [名字] [权限]     
  4. 给组添加某某权限
  5. /manglistp [名字]   
  6. 列出某个组的权限
  7. /mangdelp [名字] 权限   
  8. 删除某组的某权限
  9. /mangaddv [名字]  prefix [数值]（比如&f是一种颜色）   
  10. 给组添加值的前缀
  11. 举例/mangaddv LBWORD prefix &f 熊族
  12. 给LBWORD用户组添加了[熊族]的前缀，并且这个前缀是带[&f]这个数值的颜色的
  13. /mangaddi [名字1]  [名字2]      让组1担当租2的权限，能够为权限设置剩下不少费事
  14. /manuadd [玩家ID] [名字]      
  15. 将用户添加到组
  16. /manuaddp    [玩家ID]   [名字]      
  17. 给用户权限
  18. /manudelp [玩家ID]   [名字]      
  19. 删除用户权限
  20. /manuaddp 玩家 prefix [参数]给玩家添加XXX的前缀
  21. /manuaddv 用户名 prefix &[]  
  22. 给玩家添加XXXX的称号/manreload
  23. 重新读取配置文件

  25. 以下摘抄自http://www.mcbbs.net/thread-5531-1-1.html#4楼

  27. 文件组设置一般格式：
  28. groups: （这个要保持在文件最上处）
  29.   XXX: （XXX的含义是你可以自行增减用户组，名称任意，只要保持各设置格式相同即可）
  30.     default: false （该项设置玩家第一次进入游戏时，是否自动归入改组，true是，false否，下同）
  31.     permissions: （该项设置玩家的权限，在下一行之后添加，该项请看完后面的设置再更改）
  32.     - essentials.* （*代表ESS插件某一权限，例如“sethome”为设置家等，如果保持*，该组则拥有Essentials插件的所有权限）
  33.     - '*' （仅仅为'*'（注意引号）则是指该组拥有所有的权限（包括上面的））
  34.     - XXX.XXX （这是其他插件的权限格式，长短，点数量不定，作者应该在帖子中作说明）
  35.     inheritance: （意为继承，在下一行之后添加其它某一组（级别相邻或相同即可），之后XXX组就拥有所添加的组的所有权限，没有则改为“    inheritance: []”，下方组也不添加）
  36.     - default （例如该项设置了默认组，则XXX组就拥有默认组所有权限（你不用再在“permissions”中添加命令了））
  37.     info: （用户组属性）
  38.       prefix: '&e' （前缀，若将引号中的内容改为“&c[VIP]&2”，该组所有玩家名则会显示为：[VIP]绿名，输入“/list”查看在线人数时就可以看到。颜色设置在这里看）
  39.       build: true （该组是否能修改地形（注：刚安装插件时，默认组此项为false））
  40.       suffix: '' （尾缀，好吧，这项我没用过，应该和“prefix”一样功能，不过在昵称尾部）

[基本命令]
/spawn                            回重生点
/t spawn                          回自己的城镇
/back                               回到死亡地点
/warp xxx                        传送到某坐标
/sethome x                     设置家（/sethome a /sethome b /sethome c）
/home x                           回到家-（/home a     /home b      /home c）
/delhome x                       删除某个家
/money                            查看个人的金钱(别名/bal)
/baltop                            查看全服金钱排行(别名/balancetop)
/bal <玩家名>                  查看指定玩家的金钱
/tpa <玩家名>                 给某玩家发送请求，传送他身边
/tpahere <玩家名>          给某玩家发送请求，将他传送到你身边


/tpaccept                  接受请求(别名/tpyes)  
/tpdeny                    拒绝请求(别名/tpno)
/m <玩家> <内容>        向玩家发送一条密语(别名/tell <xxx> /msg <xxx>)
/r   <内容>                      如果玩家私聊过你，你可以进行快捷回复(密语)
/pay <玩家> <钱数>     向某玩家打入一笔钱
/afk                                 切换自己在服 离开/回来 状态
/book                             将手中的书进行编辑/锁定
/compass                       查看自己的方向(East东 West西 South南 North北)
/depth                            查看自己的所在海拔
/exp                                查看自己的经验信息
/getpos                          查看自己的坐标xyz位置
/hat                                 将你手中的物品戴到自己头上
/ignore <玩家名>             屏蔽某玩家
/itemdb                          查看手中的物品信息数据
/mail                               给某玩家发送邮件(/mail send <玩家名> <内容> )


send                            ---发送邮件
read                             ---查看邮件
clear                            ---清空邮箱
/recipe <ID> <附加ID>   查看该物品的合成方法
/seen                                 查看该玩家的在线/下线状态
/suicide                             自杀
/time                                 查看游戏内时间
