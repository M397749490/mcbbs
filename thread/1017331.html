使用方法·命令·权限
默认使用萤石调整光照等级,右键方块+1,左键减1
生存模式增加光亮会减少一个光源工具,创造模式不减少
命令:
/varlight save: 存储自定义光源
/varlight autosave: 设置为自动保存模式
/varlight perm: 管理插件功能的权限,此插件默认无权限
/varlight whitelist: 列出白名单世界或增减白名单
/varlight blacklist: 列出黑名单世界或增减白名单
/varlight update: 在一个设定的点安装光源
/varlight fill: 用光源填充大区域,此指令类似于原版的/fill
/varlight stepsize: 设置光源的单位等级,有1-15可以设置
/varlight debug: 测试模式,请勿打开
/varlight item: 更改你的光源工具 (默认: glowstone_dust萤石)
/varlight reload: 重载配置
权限:
插件默认无使用权限,如果玩家拥有光源工具,就可以改变方块的光照
如果你要追加权限,请使用/varlight perm set 自定义权限||以实现权限控制
比如/varlight perm set vl.use,之后给管理员组此权限即可实现管理员可改变光照
权限树(luckperm生成)
├── varlight
│  ├── varlight.stepsize: 允许使用 /varlight stepsize
│  ├── varlight.admin: 允许使用 all varlight admin commands
│  │  ├── varlight.admin.debug: 允许使用 /varlight debug
│  │  ├── varlight.admin.fill: 允许使用 /varlight fill和/varlight update
│  │  ├── varlight.admin.perm: 允许使用 /varlight perm
│  │  ├── varlight.admin.reload: 允许使用 /varlight reload
│  │  ├── varlight.admin.save: 允许使用 /varlight save和/varlight autosave
│  │  ├── varlight.admin.update: 允许使用 /varlight update
│  │  ├── varlight.admin.item: 允许使用 /varlight item
│  │  ├── varlight.admin.world: 允许使用 /varlight whitelist和/varlight blacklist
配置文件
  1. # VARLIGHT 插件配置,汉化/释义者:碎心者炫宙
  2. # -------------------------------------------------------------------------------------------
  3. # "autosave" 控制插件如何自动保存自定义光源
  4. # 自定义光源存储在世界名/varlight/下,存到地图文件里而非插件
  5. # 设置自动保存时间大于0将会在每 N 分钟内保存一次
  6. # 设置位0将会完全关闭插件的自动保存功能,此时
  7. # 必须使用内置命令手动保存所有自定义光源
  8. # 小于0将会在世界被服务器保存时自动保存光源
  9. # -------------------------------------------------------------------------------------------
  10. # "requiredPermission" 表示此插件的使用权限
  11. # -------------------------------------------------------------------------------------------
  12. # "whitelist" 控制世界白名单
  13. # -------------------------------------------------------------------------------------------
  14. # "blacklist" 控制世界黑名单
  15. # -------------------------------------------------------------------------------------------
  16. # "nls-deflated" 表示存储光源信息文件是否使用GZIP压缩
  17. # -------------------------------------------------------------------------------------------
  18. # "stepsize-gamemode" 用以控制管理模式
  19. # 模式分别为:
  20. #  1) Creative: 只有创造模式才采用光照等级设置(默认)
  21. #  2) SURVIVAL: 创造模式和生存模式才采用光照等级设置
  22. #  3) ADVENTURE: 除了观察者模式以外全部模式都可以采用
  23. # 观察者无法更改光照,所以列表里没有它
  24. # -------------------------------------------------------------------------------------------
  25. # 当 "varlight-reclaim" 设置为, 玩家使用精准采集附魔破坏
  26. # 方块将会得到一个名为"Glowing ..."的方块(比如: Glowing Block of Iron)
  27. # 之后你放置此方块就会直接还原光照
  28. # 破坏光照方块时会掉落一个光源工具(萤石粉)
  29. # 当它设置为false,挖掘光源总是会破坏光源
  30. # 并保留完全正常的掉落物
  31. # -------------------------------------------------------------------------------------------
  32. # "log-debug" 开启后将会输出更多信息.
  33. #如果遇到一些麻烦了,恁可以开启
  34. # -------------------------------------------------------------------------------------------
  35. # "check-update" 设置为true,插件将会在开服时自动检查更新
  36. # -------------------------------------------------------------------------------------------

  38. experimental-blocks: false
  39. item: minecraft:glowstone_dust
  40. autosave: -1
  41. requiredPermission: ''
  42. whitelist: []
  43. blacklist: []
  44. nls-deflated: true
  45. stepsize-gamemode: CREATIVE
  46. varlight-reclaim: true
  47. log-debug: false
  48. check-update: false
