使用虚拟玩家，借助operation找到分数的最大值，再寻找分数相等的玩家即可
  1. execute at <目标玩家> run tag @a[distance=..10] add mark
  2. scoreboard players operation #max 计分板id > @a[tag=mark] 计分板id
  3. execute as @a[tag=mark] if score @s <计分板id> = #max <计分板id> run say 分数最高
  4. tag @a[tag=mark] remove mark
