在指令设置完毕之后会给武器增加限时的标签

食用指南
/tli 调出指令帮助列表
/tli set yyyy-mm-dd hh:mm 设置具体过期时间
正确示范：时间格式如2017-05-04 05:05
错误示范：时间格式如2017-5-4 16：34
1.月份、日期及时间必须为两位数
2.时间冒号必须为英文标点
/tli set 1d 设置一天后过期
1.该指令仅有“d”天可用
/tli remove 移除过期时间

权限节点
/tli （所有玩家）
无
/tli set（仅op）
tlitems.set
/tli remove（仅op）
tlitems.remove

配置文件
暂无
