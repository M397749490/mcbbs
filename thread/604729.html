[diamond_gem]前言：

本插件为二搬插件，点我进入原帖

因为原搬运贴的版本只有到1.7.2，而现在的已经到1.8.1了，

实测1.9完美运行，理论支持到1.9.4（作者说了1.8+）

在配置文件上和原来的有些不同，不过先前的版本配置方法还会在新版上的

对配置文件进行了简单的汉化，下方会贴出






介绍|使用方法|指令|权限原帖均完整，这里就不做复制粘贴这种无耻的事了，请去原帖查看



[paper]配置文件：

  1. # This config controls what plugins work on certain worlds.
  2. # 这个配置文本可控制插件在某个世界进行工作
  3. # Example
  4. # 举个例子
  5. # limit:
  6. #   WorldEdit:
  7. #     - world
  8. #     - world_nether
  9. #   Essentials: []
  10. # This will make it so worldedit will only work in world & world_nether, meaning in the end it is not usable.
  11. # 这样写就可以了，现在世界编辑将仅仅工作在世界和地狱，这就意味着在末地是无法使用的。
  12. # When there is no worlds in the list it will allow it for any worlds, in this example allowing all worlds.
  13. # 当没有任何世界在列表中，他将允许所有世界使用（不同世界不同插件），在下面的配置中就是允许了所有的世界
  14. # Whenever a plugin is added, this config will automatically add it!
  15. # 每当增加了新的插件，该配置也将自动添加它！
  16. # exempt-login-events is for excluding login events when true, this means if a plugin uses PlayerLogin it will allow it for any world. We advise this to be enabled!
  17. # exempt-login-events 当该选项为true时，是将登陆系统排除在外，这意味着如果插件中有PlayerLogin，他将允许他在所有世界，我们建议开启该选项！
  18. # blocked-msg is the string displayed to a client when a command is blocked
  19. # blocked-msg 当某个插件不可用时，会在该选项显示出对应的提示（可自行编辑）
  20. exempt-login-events: true
  21. check-for-updates: true
  22. blocked-msg: '&c[错误] 该指令不可在这个世界执行.'
  23. limit:
  24.   Vault: []
  25.   GroupManager: []
  26.   ProtocolLib: []
  27.   Essentials: []
  28.   EssentialsProtect: []
  29.   EssentialsSpawn: []
  30.   EssentialsChat: []
  31.   EssentialsAntiBuild: []
