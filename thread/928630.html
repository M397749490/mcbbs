  1. Tahoma,"Microsoft Yahei","Simsun"

其中 Tahoma 是英文字体，而 Microsoft Yahei 和 Simsun 是中英混合字体。

对于 Windows 系统来说，这样的设置是毫无问题的，但问题的关键就在于全世界只有约 35% 的 Web 终端设备使用 Windows 系统（以下数据来自 wiki）：



我们可以注意到，Apple 公司的设备和使用 Linux 系统的设备共同占据了超过 60% 的市场份额，但是它们都没有上面的列表中的任何一款字体。更恶劣的是，这一字体列表压根没有指定基本字体族，因此这些设备在找不到这些字体的时候，便只能使用浏览器的默认字体，而浏览器一旦使用衬线字体作为默认字体，那便会显示得很难看。

如果说论坛界面相当于一个人的脸面，那字体毫无疑问可以视为一个人的五官。虽然这件事和论坛大大小小的 BUG 来说可能只能处于优先级较低的位置，但是只通过修改几行 CSS 便可确保所有现代浏览器字体显示的正确性，那是十分值得的。

以下从显示字体和代码字体两个角度分析问题。

显示字体

考虑到论坛倾向于使用无衬线字体作为显示字体，因此可能需要：

  • 在字体最后添加 sans-serif 字体族
  • 把带衬线的字体 Simsun 去掉

考虑 Apple 公司的设备，可能需要：

  • 添加 -apple-system 和 BlinkMacSystemFont 从而使 Webkit 浏览器自动调用默认字体
  • 添加 Hiragino Sans GB（冬青黑体）作为中文字体
  • 添加 Helvetica Neue 作为英文字体

考虑 Linux 设备，可能需要：

  • 添加 WenQuanYi Micro Hei（文泉驿微米黑）作为字体

最后总结可以得到列表：

  1. -apple-system,BlinkMacSystemFont,"Helvetica Neue",Tahoma,"Hiragino Sans GB","Microsoft Yahei","WenQuanYi Micro Hei",sans-serif

代码字体

现在论坛的代码字体是：

  1. Monaco,Consolas,"Lucida Console","Courier New",serif
复制代码

问题如下：

  • serif 写错了，应该写成 monospace
  • 对于现代 Apple 设备而言 Monaco 过于陈旧
  • 通常的 Linux 桌面发行版会预装 Liberation Mono 这一代码字体
  • Courier New 是衬线字体，和论坛整体的无衬线字体风格是格格不入的
  • 装了 Courier New 的设备通常都装了 Consolas 和 Lucida Console，因此该声明毫无必要

最后总结可以得到列表：

  1. SFMono-Regular,Menlo,Monaco,Consolas,"Lucida Console","Liberation Mono",monospace
