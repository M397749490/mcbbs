[ Ding - 界面进入提醒 ]

这是一个由国外著名模组作者 iChun 制作的非常简单的模组，
功能是在游戏启动完毕进入主菜单时 / 单机存档加载完毕时 / 进入服务器时，
发出一个游戏加入的音效，默认为拾起经验球的音效“叮”，故而得名。
这个模组是高度可配置的，包括可以选择发出声音提示的时机，发出的音效种类，以及发出音效的声调。

虽然作者是 iChun，但这个模组并不需要 iChun's Util 作为前置。

模组的配置文件非常简短。
原配置文件中 # 号后的说明内容是英文，我将其做了翻译。
以下的例子使用的是我自己的整合包中的配置文件，可以看到是做了修改的。
直接从这里拿走使用也没问题。效果是，在游戏加载完成和进入存档的时候，
都会发出一声“喵呜”，用来萌化整合包，和屏幕前的你的少女心。

  1. # Configuration file

  3. ding {
  4.     # 当 Minecraft 游戏加载完毕时播放的音效种类，写出其 **游戏内的音效名称**。
  5.     # 例如："ui.button.click"，或 "entity.experience_orb.pickup"。
  6.     #
  7.     # 也可以是某个模组添加的音效，只要这个模组安装了并正常运行。
  8.     # 格式是这样：modname:modsound.boing 。
  9.     # 默认的音效“叮”，是 entity.experience_orb.pickup
  10.     S:name=entity.cat.ambient
  11.     # 这是豹猫发出的“喵呜”声。

  13.     # 当游戏世界（单人或联机）载入完成时播放的音效种类，写出其 **游戏内的音效名称**。
  14.     # 例如："ui.button.click" or "entity.experience_orb.pickup"
  15.     #
  16.     # 也可以是某个模组添加的音效，只要这个模组安装了并正常运行。
  17.     # 格式是这样：modname:modsound.boing 。
  18.     # 默认的音效“叮”，是 entity.experience_orb.pickup
  19.     S:nameWorld=entity.cat.ambient

  21.     # 游戏加载完毕时播放音效的音调 [范围：0.0 ~ 10.0, 默认为 1.0]
  22.     S:pitch=1.0

  24.     # 游戏世界载入完成时播放音效的音调 [范围：0.0 ~ 10.0, 默认为 1.0]
  25.     S:pitchWorld=1.0

  27.     # 在以下时刻播放音效...
  28.     # 0 = 不播放（那还装这个模组干嘛？）
  29.     # 1 = 游戏加载完成
  30.     # 2 = 游戏世界载入完成
  31.     # 3 = 以上两个时候都播放 [范围：0 ~ 3, 默认：1]
  32.     I:playOn=3
  33. }
