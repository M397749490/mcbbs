下面我们来看看元素（划重点）

HTML元素，决定了网页所拥有的基础功能。你可以不写元素直接在body中写文本，但是那样的话会导致绝大多数你要的功能、样式无法实现。

一般推荐是在body下写一个div元素，有必要的话，你可以写多个div，多次嵌套多个div。

比如，如果我想要实现内部样式表（就是直接写在页面内，不引用外部css文件的样式），需要借助style元素。

例如style元素、script元素都需要卸载head元素中间的。（script写body中间也行，但会在加载网页内容后在执行。）

如果想要插入一张图片需要用img元素，想要让内容在一行（包括文本、图片）则需要用p元素。


下面我们来看列表：
无序列表
无序列表是一个项目的列表，此列项目使用粗体圆点（典型的小黑圆圈）进行标记。
无序列表始于 <ul> 标签。每个列表项始于 <li>。
<ul>
<li>Coffee</li>
<li>Milk</li>
</ul>
浏览器显示如下：
Coffee
Milk
列表项内部可以使用段落、换行符、图片、链接以及其他列表等等。

有序列表
同样，有序列表也是一列项目，列表项目使用数字进行标记。
有序列表始于 <ol> 标签。每个列表项始于 <li> 标签。
<ol>
<li>Coffee</li>
<li>Milk</li>
</ol>
浏览器显示如下：
Coffee
Milk
列表项内部可以使用段落、换行符、图片、链接以及其他列表等等。

自定义列表
自定义列表不仅仅是一列项目，而是项目及其注释的组合。
自定义列表以 <dl> 标签开始。每个自定义列表项以 <dt> 开始。每个自定义列表项的定义以 <dd> 开始。
<dl>
<dt>Coffee</dt>
<dd>Black hot drink</dd>
<dt>Milk</dt>
<dd>White cold drink</dd>
</dl>
浏览器显示如下：
Coffee
Black hot drink
Milk
White cold drink
定义列表的列表项内部可以使用段落、换行符、图片、链接以及其他列表等等

CSS属于比较简单的语言，基本就是死格式，往里套就可以了。如果有不会的可以www.baidu.com

CSS分为内联样式表和外部样式表
CSS全程是层叠样式表
内联样式表直接写在html文件中的Style元素中，外部样式表则在html文件中用link元素引用。

首先我们来看元素选择器：
代码格式：
  1. 元素{
  2.    样式:值;
  3. }
复制代码
元素选择器用于规定整个页面中所有这种元素的样式。
比如：
div{
color:white;
}
那么整个页面中div元素里面的所有元素的文本和文字的颜色都会是白色。

下面我们来看类选择器：
代码格式
  1. .类{
  2. 样式:值;
  3. }
复制代码
类选择器用于规定页面中所有有这个类的属性的元素的样式。
比如在<div class="abc">Hi</div>中，类就是abc。一个元素可以有多个类，中间用空格隔开
内联样式表中这样写才有效：
.abc{
color:red;
}
如果这么写的话，那么“Hi”就会是红色的
如果我们再写一个类：
.haa{
background-color:blue;
}
然后div元素我们这样写：<div class="abc haa">POO</div>
那么“POO”的颜色是红色，背景颜色是蓝色

最后我们来看ID选择器。
在HTML中我们会因为某些原因给一些元素规定ID，ID是不能重复的，相当于每个人的**号码。
我们来看基本格式：
  1. #ID{
  2. 样式:值;
  3. }
复制代码
注意：一个HTML只能有一个且不重复的ID！
如果我们在内联样式表里面写：
#OOI{
color:green;
}
然后div元素这样写：
<div id="OOI">APO</div>
那么“APO”的颜色就是绿色。

以此类推。如果想实现更多样式功能的话可以百度或者询问我，我们下期JavaScript再见！
