第二步什么是BungeeCord？怎么获得BungeeCord？：[可在此段结尾获取BungeeGord下载地址,以下内容来自于spigotmc请自行翻译]
·        About BungeeCord

For a long time, Minecraft server owners have had a dream that encompasses afree, easy, and reliable way to connect multiple Minecraft servers together.BungeeCord is the answer to said dream. Whether you are a small server wishingto string multiple game-modes together, or the owner of the ShotBow Network,BungeeCord is the ideal solution for you. With the help of BungeeCord, you willbe able to unlock your community's full potential.
What is it? [ BungeeCord这是什么？]
BungeeCord is a useful software written in-house by the team at SpigotMC. Itacts as a proxy between the player's client and the connected Minecraftservers. End-users of BungeeCord see no difference between it and a normalMinecraft server.
How does it work? [它是怎么进行工作的？]
When the player connects to BungeeCord, it bridges the connection seamlessly tothe Minecraft server and allows the player to connect. From there, the playercan use integratedcommands and/or plugin-operated portals to movethemselves to different servers. This system allows for a single server to becomea network of seamlessly integrating servers. The possibilities are endless!
Features [特征]
Written from the ground up using all new development practices and principles,this project aims to be the most efficient, reliable and feature-packed systemaround. It's already dominating similar systems that are costing end-usershundreds of dollars per month.

BungeeCord comes with the ability to load plugins that are written against itsexpansive API. The BungeeCord system can not only seamlessly integrate withexisting set-ups, but can also be limitlessly expanded to create anything. Fromglobal ban integration to your very own M.M.O. multi-verse, BungeeCord cansurely handle it.
·        BungeeCord can spread out theload of a population spanning multiple servers, taking full advantage ofmulti-core CPUs.
·        BungeeCord can separate yourserver's activities (e.x. creative, survival, minigames,...)

简单来说BungeeCord可以把不同的服务端连接在一起来，不同服务端这样就可以互相进行传送！

第二步分安装Java：[如打不开可在文章结尾获取Java下载地址]
确保你的电脑/服务器安装Java如没安装可打开页面 http://www.java.com/zh_CN/download/manual.jsp
分32位64位，推荐下载64位的！！！
因本版部分整合包不支持Linux与Mac OS X因此在后文不再介绍，只需下载对应版本即可。
第三步创建BungeeCord服务端：[废话不多说直接开始！]
1.  新建一个文件夹[文件夹名随意]
2.  将刚才下载的BungeeCord.jar核心单独放在你所创建的文件夹里面
3.  在新建的文件夹内新建一个文本文档[.TXT文件]用来运行BungeeCord.jar
4.  新建完文本文档并打开在文档里输入以下命令
@echo OFF
title BC-控制端 title命令后的内容可修改为你想要的名字/内容
Java -jar BungeeCord.jar nogui /* 注意：更改了BungeeCord.jar文件名如123.jar这里也必须相同,JAVA是你所安装的JAVA路径位置不懂可不更改 */
不懂可直接复制以下命令到文本文档内并保存关闭
@echo OFF
title BC-控制端
Jva -jar BungeeCord.jar nogui

第四步BungeeCord服务端Config.yml配置篇：
server_connect_timeout: 5000
remote_ping_cache: -1
forge_support: false
player_limit: -1 /* 群组最大人数上限，设置-1即为不限制，这里设置的数值是真实上限数值，而不是显示数值 */
permissions: /* 权限列表一般不管 */
  default:
  -bungeecord.command.server
  -bungeecord.command.list
  admin:
  -bungeecord.command.alert
  -bungeecord.command.end
  -bungeecord.command.ip
  -bungeecord.command.reload

log_commands: false
network_compression_threshold: 256
online_mode: true /* 是否开启正版验证，设置为true后，只允许正版玩家登陆服务器 */

- disabledcommandhere

  Lobby: /* 子服名字，你要把lobby设置为新玩家入服的第一个服务器（大厅），就要修改下面的priorities:- lobby */
    motd:'&1Just another BungeeCord - Forced Host' /* 子服的标语，可用中文 */
    address: 127.0.0.1:25565/* 子服IP和端口，建议127.0.0.1:25566不能与开放端口一致 */
    restricted:false
listeners:
- query_port: 25577
  motd:'&1Another Bungee server' /* 服务器的标语，可用中文 */
  tab_list:GLOBAL_PING
  query_enabled:false
  proxy_protocol:false
  forced_hosts:
    pvp.md-5.net:pvp
ping_passthrough: false
  priorities:
  - Lobby
bind_local_address: true
  host: 0.0.0.0:25565/*  设置服务器的IP和端口（即玩家在客户端输入的端口号）这个端口是公开的，用于给玩家进入服务器
                         端口建议设置成25565（看你服务商所开放的端口是什么）
                          0.0.0.0表示接受从所有IP地址发来的数据，例如服务器是双线双IP的，那么请填0.0.0.0 */
  max_players: 1  /* 这是BC所显示的最大人数上限，并不是真实值（真实值在player_limit一项中设置）即使玩家在线人数超过这里的数字，也可以进入服务器*/
  tab_size: 60
force_default_server: false /* 如果设置为true，玩家每次登陆到BC群组时，默认服务器，改为true

prevent_proxy_connections: false

  - admin
connection_throttle: 4000
stats: 702ac574-ef2c-466e-ae01-61a1b9a33dbb /* 不要修改 */
connection_throttle_limit: 3 /* 客户端每隔多少毫秒才可以重新连接一次服务器*/
log_pings: true

Servers：/* 子服设置，跨服列表 */
  Lobby: /* 子服名 */
   address: 127.0.0.1:25566 /* 子服IP和端口,必须与子服server.properties文件中的IP端口一样，不能与BC开放端口一致，建议使用127.0.0.1：XXXXX来设置IP和端口[XXXXX代表端口号] */
   restricted: false
   motd: '&1Just another BungeeCord - Forced Host' /* 服务器标语,支持中文 */
  Lobby2: /* 子服名,注意这里名字与第一个子服一样但多加了一个2 */

   restricted: false

第五步选择子服的服务端：[以下服务器核心信息来自于http://**/thread-1778626.html]
minecraft_server（即官服）
为官方的服务端，每有一个新版MC出来，官服都会跟着出
不能加插件，不能加MOD，仅能使用原版的指令
可自定义功能少

官服+Forge（即MOD官服）
在官服的基础上加入了Forge，稳定性较好
仍无法加插件，可以通过MOD添加非原版的指令
可自定义功能少

Cauldron（即MCPC+，KCauldron，MOD服）
MCPC+为先前的名字，KCauldron为最后几个1.7.10版的名字
优点：既能加MOD又能加bukkit插件
缺点：
①bukkit插件并非完全兼容，仍有一些无法正常运行
②由于MOD和插件并在一起，经常会出现不可避免的BUG，例如核弹炸领地
③较吃配置，稳定性良
可自定义功能较多

Thermos
Cauldron的优化版
优点：
既能加MOD又能加bukkit插件
相较于Cauldron更安全，稳定性更好对插件的兼容性比Cauldron更好
缺点：
①bukkit插件并非完全兼容，偶有一些无法正常运行
②由于MOD和插件并在一起，经常会出现不可避免的BUG，例如核弹炸领地
可自定义功能较多

Craftbukkit（即水桶服）
Spigot的前身，可以加入bukkit插件
优点：稳定性较Cauldron相比较好，能够兼容绝大部分的bukkit插件
缺点：部分方面优化较差，一些专为spigot制作的插件无法运行
可自定义功能较多

Spigot（即水龙头）
Craftbukkit的优化版，可加入bukkit插件
优点：
稳定性较Craftbukkit相比更好，在Craftbukkit一些卡服的问题上做出了优化
服务端自带反作弊
缺点：暂未发现
可自定义功能多

PaperSpigot【目前使用数最多】
Spigot的优化版，可加入bukkit插件
优点：
稳定性和Spigot一样，但是Spigot上一些仍可造成卡服的问题在这基本没有了
内存占用量更少，并且多出了一些涉及到服务器性能的设置
1.9之前内置反作弊
缺点：暂未发现
可自定义功能非常多

TorchSpigot【国人制作！】
Spigot的优化版，可加入bukkit插件
优点：
在各方面性能相较于Paper更加好，稳定性十分强，可自定义方面比Paper更多
支持多核心运算，并内置反作弊
缺点：少量插件无法使用，目前最高版本只有到1.9.4
可自定义功能非常多

Sponge（即海绵端）
有人称为Cauldron的后续版本，可加入Sponge插件
优点：
支持Sponge插件，同时可以加入MOD
MOD与插件之间的兼容性相较于Cauldron加强了不少
Sponge插件可在客户端中安装
未来可实现高版本的（MOD服）
缺点：
①即使加了pore也难以让bukkit插件正常运行
②性能优化较差，较吃配置
③Sponge插件比bukkit要少很多
④插件配置比bukkit插件难，汉化更难
⑤启动慢
可自定义功能较多

SpongeVanilla
Sponge端的纯净版
优点：
支持Sponge插件
Sponge插件可在客户端中安装
占用内存少，配置需求低
缺点：
①即使加了pore也难以让大部分bukkit插件正常运行
②Sponge插件比bukkit要少很多
③插件配置比bukkit插件难，汉化更难
④无法加入MOD
可自定义功能较多

Glowstone（荧石端）
优点：开源的bukkit服务端，开发者可通过这个制作属于自己的服务端
内置对sponge插件所支持的插件
缺点：未知
[推荐使用：Spigot核心[个人最喜欢的一款核心]
[Spigot下载地址：https://getbukkit.org/download/spigot]
第六步子服的创建：
1.     在你放BungeeCord服务端的文件夹里新建一个文件夹取名为你上面设置的子服名[如：Lobby和Lobby2两个文件夹]来放置两个子服。
2.     将你按第五步所下载好的服务器核心分别放人两个子服文件夹内并分别在两个文件夹里创建一个文本文档文件，步骤与设置BC服的一样创建文本文档输入命令改名为.bat命令如下：
@echo OFF
title Lobby /* title命令后的内容可修改为你想要的名字/内容 */
Java -jar spigot-1.8.8-R0.1-SNAPSHOT-latest.jar nogui /*注意：更改了spigot-1.8.8-R0.1-SNAPSHOT-latest.jar文件名如123.jar这里也必须相同,JAVA是你所安装的JAVA路径位置不懂可不更改 */
不懂可直接复制以下命令到文本文档内并保存关闭
@echo OFF
title Lobby
Java -jar spigot-1.8.8-R0.1-SNAPSHOT-latest.jar nogui

3.   双击XX.bat运行命令将会在此文件夹里生成一堆文件/文件夹,找到eula.txt打开它并将eula=false这行的false修改成true保存关闭，再此双击XX.bat运行命令会生成更多的文件
4.   找到以下文件即可
plugins [生成的文件夹，放插件的]               server.properties [生成的文件，配置文件]
5.   打开server.properties文件进行配置修改，修改完成保存关闭
#Minecraft server properties
#Thu Jul 23 20:42:20 CST 2020
spawn-protection=16 /* 服务器保护范围默认16格 */
server-name=Unknown Server /* 服务器名字 */
generator-settings=
force-gamemode=false
allow-nether=false
gamemode=2 /* 服务器游戏模式0是生存模式、1是创造模式、2是冒险模式、3是观察者模式 */
broadcast-console-to-ops=true
enable-query=false
player-idle-timeout=0
difficulty=0 /* 服务器游戏难度0和平、1简单、2普通、3困难 */
spawn-monsters=false
op-permission-level=4
resource-pack-hash=
announce-player-achievements=true
pvp=true /* 服务器是否开启PVP,开了玩家就有伤害，默认开启 */
snooper-enabled=true
level-type=DEFAULT
hardcore=false
enable-command-block=false /* 是否可以使用命令方块 */
max-players=2020 /* 服务器玩家人数 */
network-compression-threshold=256
max-world-size=29999984 /* 世界大小 */
server-port=25566  /* 服务器端口，与BC的配置文件里的一样如这是Lobby子服就设置成Lobby的端口，Lobby2子服就设置成Lobby2子服的端口 */
debug=false
server-ip=127.0.0.1 /* 服务器IP地址，与BC的配置文件里的一样 */
spawn-npcs=true /* 服务器是否使用NPC */
allow-flight=false
level-name=world /* 主世界名 */
view-distance=10
resource-pack=
spawn-animals=false
white-list=false
generate-structures=true
online-mode=true /* 否开启正版验证，设置为true后，只允许正版玩家登陆服务器，默认是true */
max-build-height=256 /* 服务器建筑高度，没啥用 */
level-seed= /* 服务器地图种子 */
enable-rcon=false
motd=A Minecraft Server /* 服务器标语，中文需改变编码格式 */
第八步开启BungeeCord服务器：
1.    BC与子服都配置完成后分别在子服的Plugin插件文件夹里放入Stp跨服传送插件
2.    运行Bc、子服的.bat文件，打开游戏客户端输入BC的IP地址进入服务器即可
3.    加入了Stp插件，输入在游戏中 /stp [子服名如：Lobby] 即可实现跨服传送
4.    将子服进行修改加入一些插件什么的
