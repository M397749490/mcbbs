    全局的自定义物品冷却系统(仿末影珍珠，支持nbt判断)。
    子界面(SubScreen)嵌套式重叠界面，多重UI。
    gui背包式(WInventoryScreen)附加原版背包槽位，
    有相对安全的物品处理办法，降低或杜绝了刷物品的情况。
    单/多节点式动画(放大缩小/淡入淡出/旋转/坐标移动)，
    可应用于 GUI/按钮/图片/勾选框 ，花样更多。
有何特点？
   1.基于pangu开发框架，高效，稳定，bug易修复。
   2.所有元素可动态更新。
   3.拥有相对较全面的UI元素，应用到游戏内部方方面面。
   3.插件完全开源，不做混淆，
      提供学习和大佬改进(大佬不要看，真的很辣眼)(出于私心，模组保留)。
   4.可对图片加密，保护自己辛辛苦苦做的图不被窃取利用。
   5.数据包智能分包发送，对超过32767字节的数据包进行分段发送。
      不管多少内容的GUI都能被成功创建，创意不缩水，尽情发挥。

     更新记录     
2020.07.07  ----  1.0
1.第一版本插件产生
2020/9/12  ----  1.1
1.新增[子界面(WSubScreen)]组件，
子界面和主界面一样，拥有打开动画(ScreenAnimation)，可以在实例中设定。
和主界面一样，可以自由添加组件，支持嵌套组件，严禁套娃。
子界面自带一个setClickCloseComponent(String id) 方法，
用以设定一个该子界面直系容器中的组件一个点击关闭子界面的功能。
并且自带了Close和Open方法，可以开发调用。
2. 槽位(WSlot)组件新增
   (1.空物品预设背景，和装备栏一样，放上物品后背景消失。
   (2.空物品预设鼠标悬停文本(tooltips)
3.新增网络图片预加载数据包(MessageDownloadImage)，
玩家进服后，会发送一个数据包给玩家客户端，包含一个图片链接数组，
客户端收到后，会异步将链接中的图片缓存到客户端。
2020/9/14 ---- 1.2
1.新增组件 - [冷却条 - WCoolingTag]
由背景图和缩减条两张图组成，
构成函数包含两个图片链接(String)，开始时间(单位: long)，和结束时间(单位: long)
支持横竖显示以及慢慢缩减或者逐渐增加的显示！
2.新增组件 - [占比示意条 - WWProportionTag]
由冷却条部分代码衍生
由背景图和缩减条两张图组成，
构成函数包含两个图片链接(String)，和一个基于0-1之间的数构成
支持横竖显示，相当于不会动的冷却条
3.槽位(WSlot)组件新增
    可调整的槽位大小！可以不再固定 16*16
    基于槽位实例内 scale 字段，
   1.0为正常大小，比1.0小则缩小，反之放大。
4.新增界面类型 - [背包界面 - WInventoryScreen]
继承于WxScreen，拥有WxScreen所有功能，相比下
比WxScreen多了原版背包的槽位(完全同步背包)
支持修改原版背包任意槽位(从id 0到40)的坐标以及背景和空槽位tooltip提示，
以及大小。
5.由WInventoryScreen衍生的修改槽位的类(ResetInventorySlot)
ResetInventorySlot实例所有字段为public，即直接修改
x和y设为 -999 为保持原坐标的意思
id从0-35为针对原版背包容器槽位的修改
id从36-40为装备栏的修改，默认WInventoryScreen没有原版装备栏
需要通过ResetInventorySlot实例为WInventoryScreen添加对应的装备栏槽位
从36-40分别为 靴子，裤腿 ，护甲 ，头盔 ，副手。
使用方法为往WInventoryScreen实例内的resetSlots列表中添加ResetInventorySlot实例
然后打开gui，就能看到对应的槽变化
6.由WInventoryScreen衍生的针对原版槽位点击的事件(PlayerPreClickInventorySlotEvent)
2020/10/12 --- 1.3
1. 新增GUI组件 血条 (由一个生物实例和WProportionTag组件的部分构建参数构成)
2.新的界面元素 HUD (HudComponent)。
3.复刻了大部分该插件的GUI组件用来提供HUD显示与交互
4.拥有复刻GUI组件的除动画外的全部属性字段和功能
5.基础(HudComponent)由 ID X Y Z W H 组成。
ID为文本ID 不能重复
W H 宽 高
其中 X Y 为坐标位置 -1为中间坐标
正数 X 为从左往右数，负数 X (小于-1)为从右往左数
正数 Y 为从上往下数，负数 Y (小于-1)为从下往上数
Z 值为组件的显示优先级，越大越靠前
衍生的组件有，如上图示意
- WHudImage ------- HUD图片组件
- WHudButtton ------- HUD按钮组件
- WHudSlot ------- HUD槽位组件，可与容器类gui交互(物品移动交换)
- WHudCheckBox ------- HUD勾选框组件
- WHudHealth ------- HUD生物血条显示组件
- WHudTextList ------- HUD文本组件
- WHudLivingEntity ------- HUD生物立绘组件
- WHudPlayerDraw ------- HUD玩家立绘组件
- WHudProportionTag ------- HUD比例示意图组件
- WHudCooldownTag ------- HUD冷却示意图组件
5.新的事件监听器 HUD组件点击事件(PlayerClickHudComponentEvent)
监听所有hud组件的点击事件
2020/10/19 --- 1.4
1.新增全局物品冷却显示(类似末影珍珠，可指定某一物品)
2.物品冷却管理器，提供api直接调用
3.新增组件 WDropField - 丢弃域(垃圾桶)，
  由2张图构成，鼠标悬浮改变状态
  可为需要丢弃物品的gui提供便利，
  玩家在gui内拖动物品点击丢弃域，可以将物品抛出
4.添加了按键监听器(WKeyInputEvent)，实时监控玩家按下和弹起的按键
5.现在事件的监听触发将会更合理，部分事件改动为发生前事件(可取消)，
和发生后事件，修正了部分错误的逻辑
2020/10/26 --- 1.5.5-1.5.6
一、WakeShow-1.5.5更新记录:
1. 修复与高清修复(OptiFine_1.12.2)的兼容问题
2. 修复与高清修复(OptiFine_1.12.2)的字体冲突问题
3. 修复与VexView同时使用时的通信问题
4. 增加了心跳包校对事件(WClientProofreadingEvent),
(玩家进服后会触发一次)在此事件下为玩家添加HUD和其它组件，将会正常添加
二、 WakeShow-1.5.6更新记录:
- 优化了数据传输，对槽位内物品的数据进行了分包发送与更新
- 现在可以增加更多的槽位，而不用担心数据包过大异常了。
2021/1/29 --- 1.7.2
一、自去年2020年10月26至今，横跨了多个版本(1.5.6--1.7.2)，修复了大大小小的许多问题。
二、新增重载客户端图片文件命令，主要针对服主调试图片适配效果时使用。
三、新增坐标查看功能，客户端根目录Config文件夹wakeshow.cfg
       内开启showMousePosition选项后可以在鼠标处查看鼠标指向的全局坐标和GUI相对坐标
       大大降低了配置GUI的难度。
四、删除了心跳包校对(主要针对bc服务器跳转后校对)相对低效的办法，
       采用bc服务器发送 - 服务器切换(MessageServerChange) - 的消息进行校对，更高效安全。
       校对的原因: 群组服中或许有其它版本的服务器或者不需要wakeshow插件的服务器
       在进行校对后，会初始化客户端或进而显示跳转后服务器的UI版面，
       也可提供其它与wakeshow联动的插件监听校对事件来正确为玩家提供需要的界面效果。
五、创作安全向 - 添加自定义密码的图片加密(服务器) <---> 解密(客户端)功能，
      可以防止其它服主在未经授权的情况下直接cv自己辛苦创作的UI资源到自己服务器盈利。
      使用方法: config.yml内设定一个只有自己知道的密码，然后
                     将 图片或图片文件夹，拖入插件配置文件images文件夹
                     然后使用命令/wakeshow encrypt 即可加密图片
                     之后加密的图片会出现在插件配置文件encryptImages文件夹内
                     然后替换客户端未加密的图片即可。
                     (指向对应加密图片时，路径末尾需要补充 .wsi ，即加密文件全名)
六、创意尽兴向 - 突破发包限制，由于原版发包限制最大32767字节
       内容过于丰富的gui将会出现超过字节限制报错的情况，
       现在这个插件采用智能的分包方式进行多段发送(即 超过32767字节的数据包将会分段发送)，
       突破了原版限制，使创意不缩水，创作更尽兴!gui内容更加丰富。
七、从当前版本开始，开放插件的源代码。源码
