1.获取MySQL软件，从官方地址http://www.mysql.com/downloads
或者我为你准备的http://pan.baidu.com/s/1jHl5BSE
从软件名字上可以看出mysql_5.6.24_winx64这是Windows64位系统使用的，其他还有Unix和Linux，还分企业版各种版，访问官方一试，初次造访，直接头晕……我就默认当你的服务器主机是Windows64位操作系统了。
的

[/spoiler]
2.解压mysql_5.6.24_winx64.zip之后，放在你的硬盘，注意文件夹名字最好不要有中文，以免发生奇葩的问题。
3.因为这是压缩版，不是安装版，安装版在安装过程中，会在操作系统中加入系统变量，以及询问你，选定一些基础设置，那么要让解压版正常运作，就需要手动在操作系统里添加变量，这个动作的目的，是以后使用命令，操作系统接收到命令后，就知道去哪个文件夹找Mysql然后执行……
4.附上百度安装过程详解，那攻略是正确的http://www.xp85.com/html/article-98-1290.html
5.楼主手上的Navicat for MySQL仅仅是使用MySQL的一个图形化工具，而不是MySQL必须的，
本身MySQL是纯DOS窗口下运行的，有了楼主的工具，会便利一些。

6.当你的MySQL安装完毕，测试有效后，现在使用你的Navicat for MySQL登录你的MySQL数据库。
7.右击root选择新建一个数据库，名字假设写nice数据格式你就选ascii -- US ASCII
8.至此一个常规的数据库我们已经建立了，我们到Authme配置文件内瞅瞅。

  2. DataSource:
  3.   mySQLColumnName: username
  4. #Authme在数据库应用中，他在保存数据的时候那些列表需要目录，就会用上面这个词语来表示玩家名字。
  5.   mySQLTablename: authme
  6. #当Authme成功登录你的数据库之后，他会新建一个列表，就用所设的名字作为列表名字
  7.   mySQLUsername: root
  8. #Authme登录数据时，需要数据库帐号，我们给他个最牛叉帐号
  9.   backend: mysql
  10. #Authme文件存储类型，已被我们设置为启用mysql
  11.   mySQLColumnLastLogin: lastlogin
  12. #数据库连接地址，这里是本机，当然也可以是某IP，把数据库做在很远的地方，只不过考验网速。
  13.   mySQLDatabase: modauthme
  14. #这个modauthme是我的设置，意思是MOD服的Authme数据，因为我还有纯净服，楼主应该改成我们预设的nice
  15.   mySQLPort: '3306'
  16. #Authme登录数据库时，从哪个端口进去，一般都用3306默认值，我改过，就鸡鸡思密达了，嘿嘿估计是需要防火墙配合数据库打开需要的端口……
  17.   mySQLColumnIp: ip
  18.   mySQLHost: 127.0.0.1
  19. #这两个就照着这样写就是了，说多了显得啰嗦
  20.   mySQLColumnPassword: password
  21. #这个的意思是Authme新建的列表，存储数据时，会以这个单词拿来作为玩家密码的目录名
  22.   mySQLPassword: dsadasdsadsa
  23. #好吧，这就是数据库超级管理员root的密码，安全起见，我就给写个乱七八糟的内容来代替之。
  24. #后面的都不必改，保持默认值就好，也没啥好说的。
  25.   caching: true
  26.   mySQLlastlocX: x
  27.   mySQLlastlocY: y
  28.   mySQLlastlocZ: z
  29.   mySQLlastlocWorld: world
  30.   mySQLColumnEmail: email
  31.   mySQLColumnId: id
  32.   mySQLColumnLogged: isLogged
  33. GroupOptions:
  34.   UnregisteredPlayerGroup: ''
  35.   RegisteredPlayerGroup: ''
  36.   Permissions:

  38.     PermissionsOnJoin: []
