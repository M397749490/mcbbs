高级礼品
插件特色
1.远程送礼物，无需tp
2.玩家可以把手中或者任何数量发送!(只要他们有足够多)
3.玩家可以在送礼物的时候发一句话
4.玩家可以阻止特定玩家向他们发送礼物
5.管理员可以监视礼物交换
6.自行设置送礼物的冷却时间
7.管理员可以查看他人邮箱
8.自行设置哪个世界可以和哪个世界换礼物，而哪个不行
9.礼物的交换记录于控制台中

指令
/gift [玩家ID] <amount|hand|all> [发送的消息]  
- amount发送手上物品的数量;hand发送手上全部物品;all发送背包中所有与手上物品相同的物品
/togglegift <on/enable|off/disable> -设置自己的接收礼物  
- enable/on允许别人向自己发送礼物;disable/off禁止别人向自己发送礼物
/giftblock          - 让你禁止特定玩家向您发送礼物
/giftunblock      - 取消禁止特定玩家
/giftblocklist     - 列出你禁止向你发送礼物的玩家,在命令后添加"clear"将清除禁止列表
/giftspy             - 让你监视礼物的交换,以防止不适当的礼物,支持on/off和enable/disable
/agreload          - 重载插件

权限
advancedgift.gift.send：允许玩家发送礼物,如果目标没有获得礼物的权限,则会失败
advancedgift.gift.receive：允许玩家获得礼物
advancedgift.gift.message：允许玩家发送消息及其礼物
advancedgift.gift.spy：允许玩家监视礼物的交易
advancedgift.bypass.cooldown：允许玩家忽略送礼物的冷却时间
advancedgift.bypass.world.restriction：允许玩家绕过世界间的送礼限制
advancedgift.bypass.world.blacklist：允许玩家在黑名单世界发送自己的礼物
advancedgift.bypass.vanish：允许玩家向隐身的玩家发送礼物
advancedgift.reload：允许玩家重新加载插件配置

配置文件
                                                                           

prefix: '&6[AdvancedGift]'
#不需要在前缀的末尾添加空格,该插件会自动添加(不用理)

enable-cooldown: false

cooldown-time: 10
#玩家每次赠送礼物的时间间隔（以秒为单位）

allow-gift-message: true
#如果设置为false，则所有玩家都无法使用消息发送功能

message-censorship: false
#如果为true，将检查带有违禁词的消息，即查找下面“黑名单”列表中的文字

send-censored-message: BLOCK
#确定插件怎么处理包含敏感词的消息
#允许填写的:WITH,WITHOUT,BLOCK
# WITH: 发送礼物和带有违禁词的插件
# WITHOUT: 取消发送消息，但是发送礼物
# BLOCK: 阻止玩家发送礼物

word-filter:
#礼物信息中被过滤的单词,支持占位符“*”
#占位符的使用和防止将影响单词的比较方式
# Please refer to AdvancedGift resource page for information on how to use wildcards.
  - ***
  - shit*
  - ass
  - dumbass
  - bitch
  - bastard

restrict-interworld-gift: false
#将此设置为true以限制世界或世界之间的礼物交换

world-group-list:
#礼品交换不会在下面设置的不在同一行中的世界之间进行
#任何未列出的世界都将被视为被列入黑名单,所有礼物都将在这些世界中禁止
  - test1
  - 'test2, test3'
  - 'world, world_nether, world_the_end'
