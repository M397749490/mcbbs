作者: 最萌九小月    时间: 2017-3-5 13:53
Mithey 发表于 2017-3-5 13:43
装ess插件，然后在config.yml禁止玩家放置，使用，交互，合成此物品

   # 阻止玩家放置以下方块
    placement:

    # 阻止玩家使用以下物品
    usage: 4571,4725,4578,4890,4325

    # 阻止玩家破坏以下方块
    break:

    # 阻止活塞推动以下方块
    piston:

    # 阻止发射器发射以下物品
    dispenser:
