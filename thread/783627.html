每周快照是Minecraft的测试机制，主要用于下一个正式版的特性预览。

然而，每周快照主要用于新特性展示，通常存在大量漏洞。因此对于普通玩家建议仅做测试尝鲜用。使用测试版打开存档前请务必备份。 适用于正式版的Mod不兼容快照，且大多数Mod都不对每周快照提供支持。

Minecraft 1.13 仍未发布，18w08a为其第21个预览版。


MINECRAFT SNAPSHOT 18W08A
A Minecraft Java Edition snapshot
Java版1.13快照 18W08A

This weeks snapshot is mostly to help prepare for a really cool snapshot coming your way soon. That's right - it's a snapshot snapshot!
本周的快照主要是为了帮你把下一个非常酷的快照准备好，没错 - 这是一个快照的快照！


CHANGES IN 18W08A
18W08A变更列表
  • The game shouldn't crash when joining multiplayer!
  • 加入多人游戏时游戏不会崩溃啦！
  • Split the ocean into 10 different biomes!
  • 将海洋分成了10个不同的群系！
  • Added underwater caves & ravines
  • 添加了水下洞穴和沟壑
  • Added a clickable link to the /locate command output
  • 给/locate的输出添加了点击事件

OCEAN BIOMES
海洋群系
We didn't want to stop at seven seas.
我们并不想在7个群系就停下来
  • Oceans are now split into 5 temperatures: frozen, cold, normal, lukewarm, warm
  • 现在海洋被分成5个温度：冰冷，寒冷，正常，温和，温暖
  • In addition to the deep vs shallow oceans we had before
  • 还有之前的深海和浅海
  • World generation should stay the same, but old chunks will only have normal oceans
  • 世界结构应该没有变化，但旧的区块仅会有正常的海洋
  • We'll be using these for something real soon!
  • 我们将尽快使用这些东西！


UNDERWATER CAVES & RAVINES
水下洞穴和沟壑
They look so cool. Sea for yourself!
他们看起来超棒！自己去看看吧！
  • Caves under the ocean are 50% more humid
  • 海底洞穴潮湿度高出50％
  • Ravines will appear in all oceans
  • 峡谷将出现在所有海洋中
  • Some ocean ravines cut deep, exposing lava to the seas
  • 一些海沟被深深的切开，露出岩浆块


FIXED BUGS IN 18W08A
18W08A的BUG修复
  • MC-122000 - Items get deleted when the inventory is overflowed by using the recipe book to return items from a crafting table.
  • MC-122000 - 通过使用配方书在工作台合成物品返回时，由于物品栏已满掉落的话，物品将被删除
  • MC-124299 - /give command: Items on ground for a long time not able to pick up
  • MC-124299 - /give命令：长时间在地面上的物品无法被拾取
  • MC-124948 - /enchant can be used by non-ops
  • MC-124948 -  /enchant 可以被非管理员使用
  • MC-125451 - Crash when logging into multiplayer without logging into singleplayer first
  • MC-125451 - 未先登录单人游戏的话登录多人游戏会崩溃

预览版的下载方式以及运行说明
对于正版用户
官方启动器是跟进最及时、运行最稳定的启动器，每次启动均会自动检查并下载启动器最新版本。但由于亚马逊服务器https连接在国内时常不稳定，官方启动器下载游戏可能需要vpn。启动器在上文已经提供。适用于全平台。
对于非正版用户
非正版用户完全可以体验快照版本，请于推荐启动器列表寻找合适的启动器。目前绝大多数主流启动器都带有游戏下载功能。如有仍疑惑请到原版问答板块提问。
