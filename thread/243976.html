标题: 怎么给别人领地权限
place                放置权限
::        destroy                破坏权限
::        build                建筑权限（将覆盖前两个权限）
::        waterflow        水流动权限
::        lavaflow        岩浆流动权限
::        flow                液体流动权限（将覆盖前两个权限）
::        piston                活塞运动权限
::        use                使用物品（门 按钮 拉杆）权限
::        container        使用容器（箱子 附魔台 发射器 酿造台）
::        monsters         刷怪权限
::        move                行动权限
::        pvp                PK权限        tp               tp 权限



这些权限用/res pset [领地] [玩家] [flag] [true/false] 这个指令一个一个的给太麻烦，我要给10个人的领地权限，没有办法把这些权限一次性全给了? 求那个指令!!!!
