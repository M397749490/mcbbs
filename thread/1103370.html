怎么获取某个原版属性的值
比如generic.armor（盔甲值）和generic.armorToughness（盔甲韧性）的值
给一句完整的声明变量代码参考下就行......


作者: 凉鱼    时间: 2020-8-16 17:15

function interact(event) {
  var item = event.player.mainhandItem;
  var armor = item.getAttribute("generic.armor");
}

如果物品本身没有这些属性，就获取不到
