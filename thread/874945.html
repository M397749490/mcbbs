领地的 config.yml 文件中
  1. # 这个是领地插件默认的世界. 默认的世界是 'World'. 这个选项最好与 essential 的设置相匹配
  2.     DefaultWorld: world
  3.     DisabledWorlds:
  4.       # 禁用插件的世界列表
  5.       List: []
  6.       # 在禁用的世界中,是否禁用世界的监听器(监听器:插件运行需要的东西，禁用后在此世界无法使用领地)  
  7.       DisableListeners: true
  8.       # 在禁用的世界中,是否禁用所有的领地指令
  9.       DisableCommands: true
