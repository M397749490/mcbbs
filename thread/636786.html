　　与Jeb的聊天总结：
  • 建议命名为“探索更新”
  • 想做探索地图已经有很长一段时间了
  • 从1.10版本开始就制作“林中鬼屋”，但是直到1.11版本才完成
  • “林中鬼屋”使用的是结构方块的预设结构模版制作的
  • 在此基础添加部件是很简单的，Jeb等待制作更多的林中鬼屋
  • 羊驼的点子是作为驮畜的一种，但是可以使用毛毯作为装饰的帷幕
  • 潜影贝箱子被添加，是因为很多人抱怨箱子放新物品太拥挤
  • 背包感觉有些落后了，所以我们把他和潜影贝相结合，最终的结果就是制作了潜影贝箱子
  • 每一个方块都有一个在被活塞推动时候的独立规则，所以这让潜影贝箱子像数据一样被传输成为了可能
  • 决定下一个更新内容，他们试图寻找一个主题，然后尝试找到合适的东西添加进这个主题里



　　来自网络的一些问答　　

　　在发布一个大更新前需要多久的时间
　　他们希望有一些有趣的东西呈现给Minecon，所以最新的更新都是在秘密的情况下开发的，通常我们想要一些社区的反馈，有时候，我们喜欢说我们正在开发一个新特性，而不是马上发布，我们看看人们猜测它是如何工作的，应该如何实现它们，并参考这些反馈，例如：一个动物需要一天去制作外观和基本的行为，然后花费一周的时间让它具有独特的个性。


　　你玩过哪些游戏
　　魔兽争霸3，战争黎明，战争黎明2，沙丘
　　期待玩到明年上市的一些即时战略游戏


　　自从你开始在Mojang工作后，Minecraft社区有哪些改变？
　　总有一些新加入的玩家觉得很兴奋，但是新玩家和老玩家是不同的，制作一个新的版本，老玩家总是希望有所不同，但是对于新玩家来说这是他的第一次，目前感觉社区已经很成熟了，已经成为了一个独立的产业。　　


　　你是故意删除了一些旧的PVP机制吗？
  • 我曾经思考过要恢复这些机制
  • 我感觉在我玩过新的PVP机制以后，我很难再恢复这些被删除的机制
  • 然而，玩家会去理解这些机制是怎么工作的么？
  • 可以快速连点，但是变得更困难
  • 我们讨论过制作一个真正的竞技环境，然后不去改变它
  • 如果你想完善你的PVP技巧，三个月改变一次PVP机制没有任何帮助
  • 对于MC来说最佳的机制，应该是1.8版本，当然我们会搞定它



　　新的启动器进度如何了？
　　它很好，也接近完工了。


　　将会添加乌龟这个生物？
　　问题在于我犹豫于乌龟的掉落物品，龟壳，和可以用它们做什么，乌龟可能最终会被加入进来。


　　为什么没有蛇、鸟或者其他的生物？
  • 蛇会导致怪异的体积碰撞箱
  • Jeb想要添加鸟，“这很久都没实现”



　　我们可以把村民的抱怨声变得更兴高采烈么？
　　并不能，呵呵。


　　你们能增加星相学吗？
  • 星星的位置由固定的随即种子产生
  • 我们可以预测星星的位置和星座
  • 这个计划已经在“TO-DO”列表里有一年多了，但是还没有开始任何有关的工作



　　我们会看到更多的周边游戏么？（例如故事模式）
　　我们希望可以看到更多。


　　使用Tab还是空格缩进（程序员向）
　　Tab


　　更新日志


  • 逃离末地岛屿的传送门
    • 随机在末地生成返回主岛的传送门
  • 林中鬼屋

    • 新的大型地牢
    • 林中鬼屋将会在深色橡木林生态中生成
    • 可以在村民处兑换藏宝图并且定位林中鬼屋的位置
    • End game type challenge（我不太明白什么意思）



　　物品


  • 藏宝图 (也就是探索地图)
    • 像地图一样，引导玩家到宝藏（地牢等等）
    • 如最初的地图一样，并不显示地形
    • 一旦找到宝藏，就会像普通地图一样了
    • 宝藏的图标标注在地图上





  • 被诅咒的附魔
    • 绑定的诅咒
      • 无法被取下
      • 只有耐久耗尽的时候才可以拿下
    • 消失的诅咒
      • 有诅咒附魔的时候，你死亡的时候物品会消失
      • KeepInventory 可以防止物品消失
    • 在地牢中获得（罕见）
    • 最佳用途是制作地图
  • 潜影贝壳
    • 由潜影贝掉落
  • 不死图腾
    • 在玩家濒死的时候使得玩家免除死亡一次
    • 激活的时候带来生命恢复和伤害吸收的效果
    • 激活的时候有特殊的粒子效果



　　方块




  • 观察者方块

    • 移植自MCPE
    • 可以发现方块的更新并且输出红石信号
    • 普通的BUD依然保留
    • 行为特性和MCPE不太一样




  • 潜影箱子
    • 使用箱子和两个潜影贝壳合成
    • 放置和使用和普通箱子一样
    • 可以拿在手里，如同背包一样
    • 被破坏的时候依然保留内部物品
    • 可以以任何角度放置，包括放在墙上
    • 鼠标悬浮在上面可以显示前5个物品名字和一共有多少物品
    • 活塞推动可以破坏
    • 可以被漏斗传输
    • 可以被发射器放置在地上
    • 不能储存潜影箱子

　　生物





  • 制图村民
    • 可以交易到藏宝图
    • 穿着白色衣服
  • 召唤师
    • 被驱逐的村民类型
    • 召唤师
      • 在林中鬼屋中生成
      • 召唤小鬼
      • 死亡掉落不死图腾
      • 施法的时候会举起手臂
      • 主动远离玩家
    • 护林人（唤魔者）
      • 在林中鬼屋中生成
      • 敌对生物并且持有武器
      • 使用斧头攻击
      • 死亡掉落斧头和绿宝石





  • 小鬼
    • 在林中鬼屋中生成
    • 被召唤师召唤
    • 如果小鬼一样，可以穿越墙壁
    • 即将攻击的时候实体的材质会显示出红色的印记
    • 使用剑攻击





  • 羊驼
    • 使用毛毯可以驮运物品
    • 可以被驯服（反复乘骑）
    • 可以使用小麦喂养
    • 背包有6格空间
    • 可以被拴绳牵着
    • 皮革有不同的材质
    • 狼会主动远离它
    • 攻击方式是吐口水
    • 一个领头的羊驼可以让附近的羊驼跟随其后

　　命令
  • /locat
    • 可以定位遗迹、地牢、特殊生态
    • 例如: /locate EndCity
    • 返回最近的遗迹等的坐标
    • 可以指定定位开始的位置，例如某个实体坐标（返回离这个实体最近的遗迹等的坐标）
    • 返回的信息: "Located [Structure] at [x] [y] [z]"
