撤销/模糊模式（默认按键为U）：
建筑小帮手为撤销模式（撤销上一步）
更替小帮手模糊模式开则将范围内所有方块替换为目标方块
模糊模式关则指针所指方块替换为目标方块

更改范围（默认按键为R）：增加建造/替换范围（Shift+R减小范围）
模式切换（默认按键为G）：切换建造/替换模式

锚定（默认按键为H）：
将选区固定下来，这样你就可以在构建它前自由观察它。
当选区被固定时，右键单击就开始工作，再次按下则取消固定



建筑小帮手：
建筑小帮手允许你在一定范围内快速建筑。
你只需要Shift+右键选中方块，调整好模式和范围后，右键即可建造

建筑小帮手模式：

Build to Me——以你为标准（你的高度或距离）开始建造
（这是唯一一种不用调整范围的模式，因为一切以你为标准）
Vertical Column——建造一个高度等于范围设定的垂直柱子
Horizontal Column——建造一个长度等于设定范围的水平行/列
Vertical Wall——建造一个面积等于设定范围x设定范围的竖直墙
Horizontal Wall——建造一个面积等于设定范围x设定范围的水平墙
Stairs——建造一个长度等于设定范围的楼梯
Checker board——建造一个面积等于设定范围x设定范围的跳棋棋盘


更替小帮手：
当你Shift+右键选中一个方块后，你就可以开始替换别的方块了~

1.3.0

Dank/Null and other inventory containers
NOTE
   The undo function and exchanger tool will insert into the dank/null (if appropriate) but only up to a max stacksize inside the dank/null of 64. The Dank/Null mod needs to implement a change to fix this. For now, it'll insert up to 64, and the rest will go into your inventory. Extracting from the dank null works fine.
1.4.0
Added an Energy Cost to the tools (Configs to change the cost/max storage).
Significant refactor of a lot of code, please let me know if I introduced any bugs :). Flagged as Alpha due to refactor and new energy stuff.
1.5.1
Added radial menu for Mode Select.
Can no longer exchange air/liquids using fuzzy mode.
1.6.1
Added a config option to allow the tools to take item durability damage (Like vanilla tools) instead of using Forge Energy.
Tools will never break.
Can be fully repaired with a single diamond in an anvil.
Can accept the normal suite of tool enchants (Unbreaking/Mending/etc).
1.6.2
Exchanger and Builder(During Undo) now properly fire BlockBreakEvents for modders to cancel if need be.
2.0.0
This is an ALPHA release of Building Gadgets v2.0 -- Please report any bugs you find :). Note that textures are temporary. Added Construction Paste: -Make construction powder, and place it in world next to water, over 4 seconds it will harden into a construction block. -Break the construction block to receive Construction Paste -Construction paste can be used to build any block (Non-Tile Entity) instead of the real block. -Some attributes like light opacity and bounding box are copied to the construction paste block -Some are not - Like light / redstone output Added Construction Paste Container -Can store 512 Construction paste -If a container (with space) exists in your inventory, paste will automatically go into it when picked up -Alternatively place construction paste in your hand and right click to put it into an available container in your inventory. Misc bug fixes.
2.1.0
Added a config option to disable paste all together.
修复了一两个崩溃错误
3.3.5
Fixed
  • Fixed a crashing issue with some mods. (our registry was broken, whoops)
  • Fixed overlapping issue with JEI
  • Fixed exchanging gadgets being able to select the effect block.
