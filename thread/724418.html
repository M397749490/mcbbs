插件の简介

Features — 功能

  • JAVA8
  • 不支持在一個服務器上運行的多個Arena(場地)
  • 支持PermissionEx
  • 完全可配置
  • 多達8支隊伍
  • 每隊無限隊員
  • 顏色隊伍和前綴
  • 隊伍聊天（全球聊天請使用 "!" or "@"）
  • 鑽石和綠寶石產卵
  • 村民商店、升級商店與更多
  • 旁觀系統
  • 隊伍選擇GUI
  • 玩家自己組隊
  • 記分板遊戲狀態
  • 每一個地圖配置
  • 設置場地無需任何命令
  • 支持BungeeCord（一個服務器只能一個場地）
  • 指南針團隊追蹤器
  • 可配置獎勵命令、殺死敵人獎勵與獲勝獎勵
  • 可配置聊天格式
  • 快速聊天指南針
  • 以及更多....

Setup — 游戏设置

  • 在单人游戏中打开地图
  • 执行以下命令（将<idteam>替换为1到8之间的数字）
  • 去到要放置床的地方並執行此命令：/ summon ArmorStand ~~~ {CustomName：Spawn：<idteam>}
  • 去团队产卵地方並執行此命令：/ summon ArmorStand ~~~ {CustomName：SpawnItems：<idteam>}
  • 去商店村民将被产生的地方並執行此命令：/ summon ArmorStand ~~~ {CustomName：SpawnShop：<idteam>}
  • 去升级村民将被产生的地方並執行此命令：/ summon ArmorStand ~~~ {CustomName：SpawnUpgrade：<idteam>}
  • 去钻石生成的地方並執行此命令：/ summon ArmorStand ~~~ {CustomName：diamondgenerator}
  • 去翡翠生成的地方並執行此命令：/ summon ArmorStand ~~~ {CustomName：emeraldgenerator}
  • 保存并退出地图
  • 创建一个config.yml文件并丟到刚在单人设置的地图文件夹中
  • 复制下方的Map Config.yml配置并根据你想要的进行修改
  • 完成

场地 设置 命令

  • 请到上方 地图设置 查看


Game 游戏 命令

  • /game start - 开始游戏
  • /game forcestart - 强制开始游戏


Team 團隊 命令

  • /team invite <player> - 发送团队邀请
  • /team accept <player> - 接受邀请
  • /team leave - 离开你目前的团队
  • /team list - 查看你所在队伍的玩家
