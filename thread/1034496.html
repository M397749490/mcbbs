现有功能介绍/教程

1. 可以创建任意一种生物
2. 自定义交易配方多达16种/个商店
3. 该插件可自定义程度在95%+
4. 支持设置生物的移动速度/飞行速度
5. 支持临时开启/关闭交易
6. 可以玩家与商店相互传送
教程：wiki



权限


权限
注释
animaltrade.create
允许玩家使用/at create指令创建商店
animaltrade.edit
允许玩家Shift+右键编辑商店
animaltrade.setname
允许玩家使用/at setname/delname
animaltrade.reload
允许玩家使用/at reload
animaltrade.select
允许玩家使用/at select
animaltrade.tp
允许玩家使用/at tp [name]
animaltrade.tphere
允许玩家使用/at tphere
animaltrade.fool
允许玩家使用/at fool




指令


指令
作用
备注
/animaltrade
显示帮助
可以缩写成/at
/animaltrade type
查看当前服务器版本所支持的所有实体类型
插件并不支持当前版本的所有实体
/animaltrade create <type>
在当前位置生成一个<type>类型的生物商店

/animaltrade select
选择生物
理论上适用于游戏中所有实体
/animaltrade tphere
将刚才选择的生物传送到当前位置

/animaltrade tp [name]
传送到第一个名为<name>的生物
不填name时将传送到最近实体
/animaltrade setname <name>
设置选中的生物的显示名称
理论上适用于游戏中所有实体
/animaltrade delname
删除选中生物的显示名称
/animaltrade fool
删除选中生物的AI
该操作不可逆！(so far)
/animaltrade reload
重新加载配置文件

已知BUG



v1.6
1.有些生物即便删除了AI还是会移动，例如末影人还是会瞬移走

v1.4
1.重启服务器后需要使用指令reload后商店才能生效（已修复）
2.只输入/at时不会弹出帮助信息（已修复）

v1.3
1.右键新创建的动物商店时会报错 （已修复）
2.每次使用指令之后都会弹出帮助信息 （已修复）
3.选中未命名的实体时后台会刷报错信息 （已修复）

v1.1
1. 1.15.2中如果设置交易物品时第一格放空，有几率导致服务器崩溃（已修复）
2. 偶发性翻译节点缺失（已修复）

v1.0
1. 即便开启了无敌状态也会受伤（已修复）
2. 如果你生成了一只熊猫 即便把移动速度设为0 他还是会自己滚走
3. 暂不支持设置彩色名字标签（已修复）
