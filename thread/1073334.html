WorldManager
世界管理 · 自带备份功能的世界管理系统

功能
·自动备份世界
·直接重置世界
·自带虚空,超平坛世界模板
缺点
无法使用其他世界生成器 例如VoidGen
指令及权限列表
/world help 显示帮助
WorldManager.commond.help
/world list  显示所有加载的世界
WorldManager.commond.list
/world listContainer  显示所有世界
WorldManager.commond.listcontainer
/world info  查看你所在的世界
WorldManager.commond.info
/world tp <世界名>  传送到一个世界
WorldManager.commond.tp
/world import <世界名>  载入一个世界
WorldManager.commond.import
/world create <世界名>  创建一个新世界
WorldManager.commond.create
/world delete 世界名  删除一个世界
WorldManager.commond.delete
/world unload <世界名>  卸载一个世界
WorldManager.commond.unload
/world reset <世界名>  重置世界到备份过的世界
指令错误,无法辨别真实功能
WorldManager.commond.reser
已知BUG
可强制加载其他不是世界的世界,例如:Libs文件夹
/world reset 显示指令错误
