我今天在翻一个魔塔端时看到了一个操作，就是用mm怪的技能来播放背景音乐，请问这是如何做到的，我想给主城添加音乐

https://www.mcbbs.net/thread-832205-1-1.html

下载这个插件，然后

配置怪物:
背景音乐:
  Type: ZOMBIE
  Display: '背景音乐播放'
  Health: 30000000
  Damage: 0
  Options:
    MovementSpeed: 0
    PreventItemPickup: true
    KnockbackResistance: 1
  Skills:
  - skill{s=背景音乐播放} ~onSpawn  

配置mm技能
背景音乐播放:
  Skills:
  - command{c="abf playinworld <mob.l.w> 音效名字"}
