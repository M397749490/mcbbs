今天在逛spigot论坛时无意发现的这个插件，觉得还蛮有趣的，于是顺手搬运一下。

作者的介绍：
雨寂是一个简单独特的插件。当一位玩家死亡后将会下雷雨，但是这个简单的插件也有一些不错的配置选项。

  1. #是否被启用?
  2. Enabled: true
  3. #玩家死亡后是否在玩家死亡的位置雷击?
  4. Lightning-OnDeath: true
  5. #是否公告玩家死亡的信息?
  6. AnnounceDeath: true
  7. #是否在X ticks（对应下面的stop-time）后设置天气为晴天?
  8. Stop-Weather-After-Certain-Ticks: true
  9. #{Player}用来获取是谁死了
  10. Death-Message: "&a{Player} &6Has died"
  11. #ticks的量值, 20 tick = 1 秒.
  12. #在多少tick后停止工作，且只有“Stop-Weather-After-Certain-Ticks”设置为:“true”时才会工作。

1.必须是java 8
