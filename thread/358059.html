据我推理，大家可能对rpgitem看的眼花缭乱吧，接下来就来看这个教程吧

武器制作篇
rpgitem最主要的就是编号
没了编号是不能继续制作的
/rpgitem 查看所有命令
/rpgitem 物品的编号 create
然后打/rpgitem list
可以查看自己刚刚创造的武器编号
如何获得物品？
/rpgitem 物品编号 give [玩家]
[玩家]什么都不写时默认为自己
武器在你手中了，有人说
为什么要木剑，我要制作的可是食物！
接下来
变更材质的命令为/rpgitem 物品的编号 item [材质的id]
它就变某物啦!

1.如果你觉得你做完武器后，那些op删你的武器
该怎么办呢？？
你可以/rpgitem 困难的编号 create
困难的编号是什么？
例如：％】%%&&￥&￥&￥&ぁう人家只能从rpgitem文件夹里面删除
武器美化篇
对于美化，命令是更上一步的，可以慢慢来

上篇回顾
我创造了一个叫我爱罗的武器
可是，我拿到武器后，名字是Wood_Sword
这个时候该怎么办呢？
/rpgitem 我爱罗 display [名字]
[名字]默认为Wood sword
支持彩色文字
已经省去了品质这个命令了
/rpgitem 我爱罗 hand [文本]
/rpgitem 我爱罗 type [文本]
这些改不改都是没有用的
都是美观的
然后，如果改攻击和防御
/rpgitem 我爱罗 damage [攻击]:[最大攻击MAX]最高1000000000
简化
/rpgitem 我爱罗 damage  1 2
他的攻击就是1-2
最小是1攻击，最大是2攻击
防御
/rpgitem 我爱罗 armour [吸收伤害%]最高100

物品描述
/rpgitem 我爱罗 lore [文本]
记得如果不想要‘’这个符号的
可以试试这个命令
/rpgitem 我爱罗 description add [文本]
删除为/rpgitem 我爱罗 description remove [行数]
武器技能篇
许多篷油在这里懵了，让我来说说吧

/rpgitem 我爱罗 power
查看所有技能
其他技能参考wolski的帖子
[fly]http://www.mcbbs.net/thread-98386-1-1.html[/fly]
注意，大家会发现
权限技能玩家没有权限
/rpgitem XX power command [冷却]|[左手(left)|右手(right) [文本] [命令，记得加/]|[权限]
命令如太长
例如/rpgitem xx power command 0 right 我爱罗 `/mob zombie`
玩家没权限时
`/mob zombie` * 记得空格
*为无视改命令的权限
我已知的权限有essential.hat essential.back 等 差不多
有些插件是没用权限的
你可以用“*”
