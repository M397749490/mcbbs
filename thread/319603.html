在对应1.8的forge出来之前，就先按照新的fml修改了部分代码，想等着1.8的forge一出就马上更新，结果forge一直没出，我就给忘了，等我发现的时候forge已经出了快半个月了{:10_527:}
花了1小时做了新版本，简单测试了下先扔上来

本MOD与之前的MyHome MOD功能类似，不同之处在于可以设置多个家，并且可以自定义命令
本人是由于对MyHome只支持设定一个家的怨念长期累积，最终决定起义（造反）推荐安装versioncheck mod，新版本提示和下载依赖versioncheck mod
versioncheck相关介绍和下载
发现BUG请留言


指令表

/sethome <数字1-8>
设置你的家，支持无参数和参数1-8，一共可以设置⑨个家

/home <数字1-8>
回到你的家，与/sethome对应

/goto [玩家名]||[坐标X] [坐标Y] [坐标Z]

/goto [玩家名]传送到指定玩家身边
/goto x y z传送到坐标X,Y,Z处

/spawn
返回出生点

/b2d
返回死亡地点

/back
返回传送之前的位置

/update (已经移除)
检测到新版后可以使用这个命令下载新版本

游戏内可以用原版的/help指令查看命令如何使用
旧版介绍

1.7.10版使用的forge版本为1200和1202（两台电脑配置的forge版本不同），1.7.2和1.6.4的forge都是推荐版（记不清版本号了）
0.4版添加了back命令对tp命令的支持，不过目前只支持/tp 玩家名   和/tp x y z 这两种使用方式0.5版加入/homelist指令，使用后打开GUI

命令表（默认）

/bsethome
时候后可以将当前地点设定为家
可以不带参数，如/bsethome
也可以带上一个参数，如/bsethome 1
参数支持1-8，也就是说目前最多能设定9个家


/bhome
回到之前设定的家
与之前使用/bsethome指令对应

如果觉得9个家还不够用的，可以自行用RAR之类的软件打开MOD，找出lang文件
把homelimit改成更大的数字，并且在后面补上对应的基佬吐槽

吐槽要把bsethome=和bhome=成对的补上
具体方法打开lang文件后一眼就能看出来
不过目前homelist功能还在规划中，太多家自己也记不清哪是哪了吧{:10_518:}

/bspawn
回到出生点

/bback
回到传送之前的地点

/b2d
回到死亡地点

/homelist0.5版加入，可打开设置和返回home的GUI，方便在几个家之间快速传送寻找自己要去的那个家
/btp
0.5a版加入，用法同原版/TP，不需要开启作弊就可以使用，避免为了LAN游戏中能TP导致基友随意使用其他指令

配置文件说明

# Configuration file

general {
    S:b2d=b2d
    S:bback=bback
    S:bhome=bhome
    S:bsethome=bsethome
    S:bspawn=bspawn
    S:nogay=true
    S:usingdefaultname=true
}


第一次运行后在config文件夹下可以得到一个配置文件，文件名BrainHole_8morehome.cfg打开后就像上面那样
想看基佬宣传内容的把nogay=true改成nogay=false


想使用自定义命令的，先将usingdefaultname=true改成usingdefaultname=false，再修改命令
例如将bsethome=bsethome改成bsethome=kfc
那么/bsethome命令就变成了/kfc
以后别再吐槽命令太长记不住了
