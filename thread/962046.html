作者: MC深坑不回头    时间: 2020-2-18 22:51
1.14版本
地图档文件夹\datapacks\资料包名\data\minecraft\tags\entity_types內
这文件夹里面加个档案，举例命名为em.json
在里面输入你要加的敌对生物:
  1. {
  2.   "replace": false,
  3.   "values": [
  4.     "minecraft:evoker",
  5.     "minecraft:skeleton",
  6.     "minecraft:bat",
  7.     "minecraft:zombie",
  8.     "minecraft:creeper",
  9.     "minecraft:witch"
  10.   ]
  11. }
复制代码

存档后即可，要使用在选取器时:
/execute as @e[type=#minecraft:em]
就能选取所有在该类别里的生物了
(#表示自定义的标签群)
