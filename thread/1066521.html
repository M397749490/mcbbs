Frozen Join 是一款可以完全自定义权限来提供加入/退出消息

允许对不同组提供不同的随机加入/退出json格式消息(所有格式)

Frozen Join还提供了PlaceholderAPI支持

就比如Admin权限组上线可以激活

某某op上线了

某某op进水坑了

某某op进服务器了

随机选择其中一个输出

以此类推还有消失格式(我没理解透请进原帖查看详情233)

随机模式在spigot核心的1.15.2有些问题 其他版本没测试

========================================

指令

/join reload 重载插件

/join info 查看插件信息

/join help 查看插件帮助

/join motd 查看MOTD消息

/join motd 有独立指令为 /motd

========================================

权限

无

需自己在Config.yml配置文件设置

2020.6.10 版本:1.2.1

NOTE: The hex colors are only available for servers running 1.16+, as it was only introduced in this version.

Action Changes:

An old action has been reintroduced

- EQUP Action: The equip item action has been readded and changed to properly support both old and new material styles:

> 1.13+ = [EQUIP] item;display;lore;amount;slot

> 1.13- = [EQUIP] item,data;display;lore;amount;slot

(Lore seperator is currently ~ and may be changed in the future if it...

2020.6.10 版本:1.2.0

NOTE: Due to the changes to a new Actions library, all previous actions have been changed/adjusted, some removed, some added.

If there was an action that was removed, which you were using, please contact me on discord and it will be added back!

Action Changes: New actions have been introduced, as well as the old ones reworked.

- Delayed Actions: You are now able to execute delayed actions, these are presented as modifiers to the regular actions. Inputs for this action...

2020.4.26 版本:1.1.1

Added a new action:

- [rangebroadcast]

(More explained in the config).

Removed particles action as it wasn't working all the time.

Added more documentation inside the config.yml for the actions.

Cleaned some code

2020.4.19 版本:1.1.0

Added format priorites:

They range from lowest to highest, heighest being the first to be applied if you have multiple format permissions.

Moved to objects instead of accessing config every join.

Preparations for adding multiple motds as well.

The action system has been switched out, but will work as before. If you encounter an issue with an action, please contact me on discord (Frosty#3308) and report it!

2020.4.15 版本:1.0.2

Added format types:

Format types are the ability to specify the current format, either being a normal format, or being random format.

- NORMAL: the standard format which executes all listed actions

- RANDOM: a random action selected from the listed actions

(example for both format types can be seen in the default config)

新增的格式类型：

格式类型可以指定当前格式，可以是NORMAL格式，也可以是RANDOM格式。

NORMAL：按照顺序输出动作

RANDOM：在你填写的动作中随机输出动作
