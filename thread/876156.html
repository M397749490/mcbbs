我是1.7.10空岛服  穿上时装如果死了时装会掉落  为什么  只有时装掉落     
作者: skyliye    时间: 2019-6-23 01:22
在时装mod配置文件中修改以下设置：

    # Should skins be dropped on player death.
    # 0 = use keep inventory rule
    # 1 = never drop
    # 2 = always drop
    I:dropSkinsOnDeath=1

1就是死亡不掉落时装
