作者: chenppqq    时间: 2015-1-10 19:55
理论上，应该只需要单独禁用这个世界的飞行就行了，可以不用设置用户权限，除了开创造模式，所有人都不能在这个图上面使用飞行。。。。

输入/mv modify set allowFlight false <世界名>
或者直接你进入这个世界 ，单独输入/mv modify set allowFlight false 也可以

可以使用Groupmanager插件，一般服务器都会有
进入Groupmanager文件夹——————worlds————复制world文件夹粘贴（把他命名成其他世界的名字
然后从world也就是你要取消VIP飞行的世界的groups.yml 取消VIP组的飞行权限{:10_512:}
