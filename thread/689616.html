想想马上就要到劳动节了，于是我就做了这样一个插件。这是我的第四个插件，欢迎下载使用。

Labour插件可以让玩家在收获成熟的农作物时掉落更多，并且可以设置随机掉落数量的最大值和最小值
一分耕耘一分收获，丰富的回报只献给辛勤的人，让玩家们体验辛苦劳作后丰收的快乐吧。




插件特点
● 轻量级插件
● 收获粒子出现时有效果
● 可设置随机掉落数（最小值、最大值）

● 可设置收获时提示的消息
● 收获时有粒子效果出现

● 大多数内容可通过配置文件随意开关

指令&配置
指令：
/lbreload 重载配置文件
*需要权限lb.admin
配置文件（大多数内容可自由配置）：

  1. ##################################################
  2. # Labour v1.0                                    #
  3. # 提示：配置中的 XM=小麦 HLB=胡萝卜 MLS=马铃薯   #
  4. # 一分耕耘一分收获~好好享受这个插件吧            #
  5. ##################################################
  6. XM-enable: true
  7. #是否启用所有相关于小麦的功能
  8. XMEffect-enable: true
  9. #是否启用收获时出现粒子特效
  10. XMMessage-enable: true
  11. #是否开启收获时提示消息
  12. XMMessage: '&d幸运之神祝福了热爱劳动的你'
  13. #设置提示的消息,支持"&"颜色代码
  14. XMMax: 10
  15. #收获小麦的最大数量
  16. XMMin: 1
  17. #收获小麦的最小数量
  18. #以下配置以此类推
  19. HLB-enable: true
  20. HLBEffect-enable: true
  21. HLBMessage-enable: true
  22. HLBMessage: '&d幸运之神祝福了热爱劳动的你'
  23. HLBMax: 10
  24. HLBMin: 1
  25. MLS-enable: true
  26. MLSEffect-enable: true
  27. MLSMessage-enable: true
  28. MLSMessage: '&d幸运之神祝福了热爱劳动的你'
  29. MLSMax: 10
  30. MLSMin: 1

要这插件有何用？
既然是专门为节日才诞生的这个插件，所以腐竹们应该有许多想法，可以利用本插件配合其他插件做一些活动之类的（比如说凑足一定数量的小麦可以换取奖励什么的）
