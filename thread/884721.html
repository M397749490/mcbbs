①回答如下
请使用管理员账户站在领地使用如下命令
1.允许使用按钮/resadmin setall button true
2.允许使用门及活版门/resadmin setall door true
3.允许使用压力板/resadmin setall pressure true
4.讲台的权限目前应该是没有
②回答如下
请打开 服务器根目录 - plugins - Residence 文件夹下的 groups.yml文件
在文件中里找到如下所示配置项 自行修改
           # 玩家是否可以创建领地.这个设置可被 'residence.create' 权限覆盖.
           CanCreate: true
           # 玩家允许拥有最大领地数.
           MaxResidences: 5
           # 一个领地的最大物理区域数目.
           MaxAreasPerResidence: 3
           # 一个领地在东西方向最大距离 (X坐标).
           MaxEastWest: 64
           # 一个领地在东西方向最小距离 (X坐标).
           MinEastWest: 3
           # 一个领地在南北方向最大距离 (Z坐标).
           MaxNorthSouth: 64
           # 一个领地在南北方向最小距离 (Z坐标).
           MinNorthSouth: 3
           # 一个领地在上下方向最大高度 (Y坐标).
           MaxUpDown: 256
           # 一个领地在上下方向最小高度 (Y坐标).
           MinUpDown: 3
           # 允许创建领地的最低高度.
           MinHeight: 0
           # 允许创建领地的最高高度.
           MaxHeight: 255
③回答如下
检查经济/创世神/权限插件是否为较新版本
将destroy权限给设置为false无法破坏方块
设置指令:/resadmin setall destroy false
或者查看一下玩家是否拥有如下权限
residence.bypass.destroy
由于我不知道你的权限插件是什么所以我无法给出准确指令
