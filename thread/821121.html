  •            MaxResidences: 5(可设置多少)
  •            # 一个领地的最大物理区域数目.
  •            MaxAreasPerResidence: 3(可调大)
  •            # 一个领地在东西方向最大距离 (X坐标).
  •            MaxEastWest: 64（可调大）
  •            # 一个领地在东西方向最小距离 (X坐标).
  •            MinEastWest: 0
  •            # 一个领地在南北方向最大距离 (Z坐标).
  •            MaxNorthSouth: 64(可调大)
  •            # 一个领地在南北方向最小距离 (Z坐标).
  •            MinNorthSouth: 0
  •            # 一个领地在上下方向最大高度 (Y坐标).
  •            MaxUpDown: 256(可调大)
  •            # 一个领地在上下方向最小高度 (Y坐标).
  •            MinUpDown: 0
  •            # 允许创建领地的最低高度.
  •            MinHeight: 0
  •            # 允许创建领地的最高高度.
  •            MaxHeight: 255(可调大)
  •             # 子区域领地最大深度.
  •             # 当一个领地子区域包含另一个子区域时,最大为2.
  •             # 设置为0将禁用领地子区域.
