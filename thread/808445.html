判断满足暴击的条件是最科学的，还能防止作弊
假如发起攻击的玩家是Player p，那么满足下面的条件即可产生暴击伤害
!p.isOnGround() && p.getFallDistance() > 0 && !p.hasPotionEffect(PotionEffectType.BLINDNESS) && !p.isInsideVehicle() && !p.isSprinting()
也就是玩家要悬空+没有致盲药水状态+没有乘骑任何实体+没有加速跑
出于反作弊的考虑，还可以判断玩家脚下方块是不是水、岩浆等方块，玩家有没有处于蜘蛛网、梯子上等
