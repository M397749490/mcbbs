游戏规则
-Gensokyo(幻想乡)-
  • DoFireTick False
  • RandomTickSpeed 0
  • MobGriefing False
*注释: 如果你想要让草能够蔓延、冰能够融化、或者其他的什么东西，就请把RandomTickSpeed改为1(如果设置成1，靠近可能性空间移动船旁的冰方块将会融化)

-NetherWorld(冥界)-
  • DoFireTick False
  • RandomTickSpeed 0
  • MobGriefing False

-DreamWorld(梦境世界)-
  • DoFireTick False
  • MobGriefing False
  • DoMobSpawning False
  • RandomTickSpeed 0
*注释: 末影龙或许会生成并破坏东西。我不能完全地确定"DoMobSpawning False"是否会禁止末影龙的生成。

-Gap(邪眼)-
  • DoFireTick False
  • MobGriefing False
  • DoMobSpawning False
  • RandomTickSpeed 0
*注释: 末影龙或许会生成并破坏东西。我不能完全地确定"DoMobSpawning False"是否会禁止末影龙的生成。

-Lunar Capital(月之都)-
  • DoFireTick False
  • MobGriefing False
  • DoMobSpawning False
*注释: 末影龙或许会生成并破坏东西。我不能完全地确定"DoMobSpawning False"是否会禁止末影龙的生成。
