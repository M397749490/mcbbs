标题: Q键、F键，制作技能触发的神器
一、Q键侦测
原理试探测玩家的drop记分板(丢出)，再来侦测被丢出的物品是否为指定物品
教程开始：

一：先创立一个记分板以便计算玩家是否丢出物品：
/scoreboard objectives add Drop stat.drop

二：接着是从丢出物品的玩家身上判定附近是否有指定的物品，如果有就把指定物品加入标签：
/execute @a[score_Drop_min=1] ~ ~ ~ /scoreboard players tag @e add Qtest {Item:{id:(物品ID),tag:{display:{Name:(自订义名称)}}}}


三：重复执行的指令方块后面就可以接你想要在侦测Q键后执行的指令，
而在后面再放置指令方块让物品还原到玩家身上(让可捡取时间归0)：
/entitydata @e[tag=Qtest] {PickupDelay:0}



四：最后让玩家的丢出分数归0：
/scoreboard players set @a[score_Drop_min=1] Drop 0


简单的Q键侦测机关就完成了：



二、F键侦测
原理：试探测玩家左手是否持著指定物品
教程：
一：将玩家左手手持指定物品的玩家加入标签：
/scoreboard players tag @a add Ftest {Inventory:[{id:minecraft:(物品ID),Slot:-106b,tag:{display:{Name:(自订义名称)}}}]}

二：重复执行的指令方块后面就可以接你想要在侦测F键后执行的指令，
而在后面将玩家的指定物品清除：
/clear @a[tag=Test] (物品ID) (物品附加值) (数量) {display:{Name:(自订义名称)}

三：再来还给玩家指定的物品：
/give @a[tag=Test] (物品ID) (数量) (物品附加值) {display:{Name:(自订义名称)}}}

四：最后清除玩家的标签：
/scoreboard players tag @a[tag=Ftest] remove Ftest

简单的F键侦测机关就完成了：
