介绍 · Introduction
使用Towny3D你可以在一个区块不同高度处声明多块土地! 你只需在声明土地时输入最低点和最高点.
插件拥有 Towny的所有特性! (由于插件还在测试阶段所以只有部分特性)

插件仍处于测试阶段，暂不推荐使用

列表
点击查看Towny插件百科

指令列表:
  • /town
    • help
    • create <townName>
    • mayor
      • help
      • getClaimerStick (或) gcs  获得设置土地最低和最高点的物品
      • addAssistant <玩家名>
      • removeAssistant <玩家名>
    • claim [区块]
    • unclaim
    • invite (or) add <玩家名>
    • deposit <amount>
    • withdraw <amount>
    • setHome
    • online 显示在线的城镇居民
    • here 显示你所在的城镇信息
    • spawn
    • kick <玩家名>
    • disband
    • <城镇名> 查看指定城镇的信息
  • /plot
    • help
    • set
      • embassy
      • perm <权限名>
      • reset
    • toggle <flag>
    • forsale (或) fs <价格>
    • notforsale (或) nfs
    • claim
    • unclaim
    • name 设置土地名
    • info 显示土地信息
  • /townchat (或) tc
  • /townyadmin
    • chat
      • spy

  • /accept
  • /decline
标志列表:
  • fire
  • explosion
  • friendly_mobs_spawn
  • hostile_mobs_spawn
如 /plot set flag fire true

权限列表:
  • res/ally/gen

    • inventory
    • interact

    • destroy
    • drop
    • pick
    • move
