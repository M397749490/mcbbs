作者: Ir.Nep    时间: 2015-10-19 18:50
找到目录下文件plugins\Residence
按CTRL+F搜索Default:
Groups:
   Default: #你的VIP组名
       # 这是你规定玩家[Default组]所可以圈的地的规定
       #Uncomment the lines below to mirror this config to other groups.
       #Mirror:
         #- 'group1'
         #- 'group2'
       Residence:
           # Determins if this group can create residences or not.  This option can be overriden with the permissions node 'residence.create'
           CanCreate: true
           # 最大圈地数量
           MaxResidences: 3

找到最大圈地数量之后，将整个    Default: 里面的内容复制下来
并在Groups:里面粘贴上去，将    Default:改为  VIP:   
将           MaxResidences: 3改为           MaxResidences: 10【最大数量】
示例：
Groups:
   VIP: #你的VIP组名
       # 这是你规定玩家[Default组]所可以圈的地的规定
       #Uncomment the lines below to mirror this config to other groups.
       #Mirror:
         #- 'group1'
         #- 'group2'
       Residence:
           # Determins if this group can create residences or not.  This option can be overriden with the permissions node 'residence.create'
           CanCreate: true
           # 最大圈地数量
           MaxResidences: 10
