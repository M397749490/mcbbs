自动工具套装
作者:infinitiesloop
介绍
这个Mod是很多懒人都必须的，玩生存模式，但是挖矿挖到手都累了吗?这工具能自动跳,长按潜行,自动向前走(还能设置走多少格),一键放火炬,自动挖矿，Mod除了在单人模式中可以用之外，在服务器里面都可以用。如果服务器的建筑工程分配你是提供材料的，有这Mod就不用怕累了吧。

预设按键:
ALT+C -打开菜单
V -放火炬
J -自动跳
M -自动挖
R -自动向前走
=(删除键左边那个) -自动向前走多少格
B -灯光增强
鼠标中键 -看背后
F5三次+鼠标中键 -360度旋转
Caps Lock -自动潜行
还有更多小功能就让你自己发现了.....

功能:
  • Auto Tool Selection -自动选择工具
  • Auto Sword Selection -自动选择剑
  • Auto Block Selection -自动选择方块
  • Stack Preservation -自动把相类物品堆起来
  • Place Torch -放火炬
  • Tap to Sprint -短跑
  • Disable Void Fog -禁用地底的雾
  • Automatic Window Restoration -自动窗口恢复
  • Better 3rd Person View w/ Camera Control -更好的第三人称视觉/镜头控制
  • Auto Run -自动跑
  • Toggle Sneak -切换潜行
  • Toggle Jump -切换跳
  • Swap Left -选择左边物品
  • Swap Right -选择右边物品
  • Toggle Mining -切换挖
  • Toggle Use Item -切换使用物品
  • Run Distance -自动向前跑指定距离
  • Look Behind -看背后
  • Smart Furnace Drops -智能使用熔炉
  • Render Less Rain -更少雨水(低配置可以用)
  • Toggle Full Brightness -切换更强光线
  • Individual SFX Volume Control -个别声音控制
  • Coordinates Overlay -坐标
  • Set Waypoint -设置航点
  • Say your location -说出你的位置

安装方法:
1.到置顶帖下载并安装Modloader
2.把"CLASSES"里面的东西拖进.minecraft/bin/minecraft.jar
3.安装完成
