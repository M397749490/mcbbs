MC从alpha版开始就有了红石电路，可以说红石电路是MC自由度的最佳体现。你甚至理论上可以在MC里再造一台电脑然后在MC内玩MC（虽然工程难度和需要的时间是天文数字，输入输出受限于各种游戏内的功能性方块，最后游戏平均帧率(2^-inf)fps 就是了www），其原因是因为红石电路所能构造出的logic gates是turing complete的，其对应的boolean algebra是functional complete。

那么如果MC一开始并不是加入的红石电路，而是加入其他与其等价的东西，可能是什么呢？其中一种可能性叫做lambda演算。lambda演算是所有函数式编程语言的基础，甚至在非函数式的语言里也会出现，比如java中的lambda表达式，粗略来说就是一种typed lambda calculus。

lambda演算由3个syntax（variable、abstraction、application）和3个reduction rule组成（α-conversion、β-reduction、η-conversion），α-conversion是变量重命名，β-reduction是函数应用，η-conversion是函数的外延相等性。

举个几个简单的例子：

  1. id := λx.x
  2. const := λx.λy.x
  3. fix := λf.(λx.f (x x)) (λx.f (x x))
复制代码

当然，在lambda calculus里也可以玩boolean algebra：

  1. false := λt.λf.f
  2. true := λt.λf.t
  3. and := λp.λq.p q p
  4. or := λp.λq.p p q
  5. not := λb.λt.λf.b f t
  6. if := λb.λt.λf.b t f
复制代码

在使用函数式编程语言，例如scala开发mod、插件的过程中，会经常使用各种复杂的函数式的技巧，例如higher order function、currying、closure等。因此，了解其背后的基础理论就会有很大的帮助。

然而大多数的编程语言中的lambda表达式要么是typed的（例如haskell），要么是call by value的（例如lisp）。有时候，我们需要一个纯净的、能使用normal order进行reduction、untyped的编程语言来实验新的想法（当作玩具）。那么，本着作为一名programmer的造轮子（复读）本质，自己从头写一个吧！

这里安利一波我写的一个实现，支持设定最大步数、自定义evaluation strategy（head only、evaluation only）、支持free variables、自带编译器、pretty printer、使用scala编写、以及各种附加工具为一体的lamcalcj和对应的gui程序lambdacore：
