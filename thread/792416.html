    MOD介绍
  • 作战模式[新]
    •   技能色标
      红色=冷却时间
      蓝色=被动
      黄色=充电
  • 新武器[新]
    •   5吨、10吨和100吨锤子
      警棍
      米霍克的小刀
      和道一文字
      秋水
      三代鬼彻
  • 半机械人[新]
    •   有5种新能力(需获得)
      机器人能力每次使用时都会消耗可乐
      新的可乐表显示用户目前有多少可乐值
  • 可乐&超级可乐[新]
    •   可以被所有种族使用，但如果被一个半机器人使用，它将补充可乐量
      每喝一次超级可乐，就能提高一个半机器人所能容纳的最大可乐量
  • 鱼人水下视觉[新]
    •   鱼人现在可以看到水下了
  • 遥测[新]
    •   这个新系统会在你的游戏过程中收集一些数据并把它发送回我们的服务器
      不包括个人信息，如ip，密码，用户名等被收集
    身份还是海贼，海军，赏金猎人 3个选择
    种族选择 普通人 鱼人 半机器人
    专业选择剑客 狙击手 医生
    选择好了在点击CREATE
    0.2.6版本是按F查看自己的属性,但0.3.0版本是按R查看自己的属性
    点击能力把要带的技能选择出来,可选择八个技能
    点一下你要放的位置,在点一下你要放入的技能(鼠标左键即可)
    放技能需要打开技能表,按ALT打开技能表，在按一下ALT关闭技能表
    恶魔果实宝箱可以在船上找到
    .minecraft\config\mineminenomi.cfg配置文件
    # Configuration file

    general {
        B:"Allow Devil Fruits to drop from leaves"=true
        B:"Allow Ships to Spawn"=true
        D:"Rate at which Devil Fruits drop from leaves"=0.1
    }


    "mine mine no mi config" {
        B:"Allow 3D Rendering"=false  允许/关闭3D渲染
        B:"Allow Debug Mode"=false    允许/关闭调试模式
        B:"Allow Griefing"=true       允许/关闭恶意破坏
        B:"Allow Particles"=true      允许/关闭粒子
        B:"Allow Quests"=true         允许/关闭任务
        B:"Allow Race/Faction"=true   允许/关闭种族/阵营
        B:"Allow Ships Spawn"=true    允许/关闭世界生产船
        B:"Allow Sounds"=false        允许/关闭声音
        B:"Reset Stats After Death"=true  允许/关闭死后重置统计
    }
