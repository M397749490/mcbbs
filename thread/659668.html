本插件之前有人搬运过,地址是这里,但是由于版本更新且年久失修,本人决定重新搬运

——]-特性-[——
·-·本插件高度仿真神庙逃亡,请看以下
·踩到特定方块将会执行某种特效
·停止奔跑2秒[可自定义]自动算游戏失败
·支持Vault,奖励跑过终点玩家自定义的钱数
·某玩家到达终点将全服通告[支持彩色字]
·拥有BungeeCord模式[详情请自己研究]


——]-方块作用-[——
= 金币
= 超级跳
沙子/砂砾= 减速
= 加速
青金石块 = 反胃
煤 = 失明
黑曜石 = 完全失明
= 带南瓜在头上，会出现视野内有个南瓜头的效果
= 冻结玩家
海绵 = 将玩家往回弹射
红石块 = 终点
= 失败
= 存档点


——]-指令&权限-[——

/irun -查看帮助
/irun join [id] -加入一个游戏(insanityrun.join)  
/irun leave [id] -离开一个游戏(insanityrun.leave)
PS:insanityrun.play 拥有上面两个权限
/irun create [id] -创建一个游戏
/irun delete [id] -删除一个游戏
/irun setspawn [id] -给一个游戏设置出生点
/irun setpay [id] -设置一个游戏过关后可以获得的钱数[需要Vault支持]  
/irun adjoin [玩家] [id] -让某个玩家强制加入一个游戏
/irun adleave [玩家] [id] -强制从一个游戏踢出某个个玩家
/irun list -显示所有游戏      
/irun linkarenas [id1] [id2] -从id1游戏成功后，把玩家传送到id2继续闯关
/irun setcharge [id] [钱数] -设置进入一个游戏的钱数[需要Vault支持]
PS:       insanityrun.sign: 允许建立快捷加入牌子
            insanityrun.create: 允许建立一个场地
            insanityrun.delete: 允许删除一个场地
            insanityrun.setspawn: 允许设置一个场地的重生点
            insanityrun.admin:给予所有权限
