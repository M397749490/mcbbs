基本使用:
首先放个牌子
第一行内容:
  • #wiki 对应wiki
  • #wikiimage 对应wiki图片
  • #txtfile 对应文本文件

第二行内容:
  • 如果wiki则是页名,未测试是否支持中文内容
  • 如果是txtfile则是文本名,不用输入.txt

第三行内容:
  • 宽x高,例如2x3就是 宽2格 高3格
  • 最小2x2 最大16x16

第四行内容:
  • hide 隐藏牌子
  • glow 半透明牌子
  • wire 线框牌子
  • 空白 无变化

左键打开网页
右键刷新内容
注意不要打到牌子...

web修改版
将其对应位置修改为 网址+wiki/
例如你在插件中设置 wikiapiurl: http://123.org/w/ 则对应 http://123.org/w/wiki/
wikiapiurl: http://123.org/w 则对应 http://123.org/wwiki/

文件名可以随意,只要内容符合就可以读取,如下图

mods\VoxelMods\voxelboards.properties
此文件可以設定面板透明度還有顯示文字和邊框顏色
裡面的顏色代碼0~9 a~f 使用MC預設

搬运内容:

支持格式
这不是一个浏览器因为你只能得到Wiki链接和粗体文本渲染.
页面名称支持空格如果你使用下划线(_),并且最大字符数限制为15个字符.
因此建议特殊 VoxelBoard 页中使用在代替具有过量的HTML格式的页面. (例如: VB:短页)
使用
你在牌子中输入每一行参数如下:
行1: #wiki
行2: 页名 (例如 "VoxelJobs")
行3: {宽}x{高} 1x1 到 16x16 之间 (例如 "5x3)
行4: {显示选项} (Hide, glow, {无})
Hide - 设置牌子隐形.
Glow - 设置牌子半透明.
空行 - 留下牌子.
例如
  1. #wiki
  2. User:Ciscog33k
  3. 5x3
  4. hide

编写您的VoxelBoard文本,但隐藏在Wiki
如果你想这样,请按以下步骤:
转录你想要出现在VoxelBoard牌子的信息到相应的wiki页面,但在页面底部,之前全部其他的都格式化.
在你的VoxelBoard文本上一行,放置以下内容然后保存该wiki页面并且刷新游戏中的面板:
  1. <div style="display:none;">
  2. <div id="begincontent"></div>
  3. 内容放在这里.

链接面板到一个MediaWiki站点
VoxelBoards可以链接到任何 wiki 支持的 MediaWiki 软件,并且这是由服务器指定通过使用 VoxelModPackPlugin .要启用 VoxelBoards 功能在你的服务器,只需安装插件并运行服务器一次创建默认的 config.yml 文件.

接下来修改 config.yml 的设定并设置 voxelboards.enabled 设定为 true ,并指定你的 wiki 网址(这是用来在单击一个面板时)和 wiki API 的基础网址
  1. voxelboards:
  2.   enabled: true
  3.   wikiurl: http://en.wikipedia.org/wiki/
  4.   wikiapiurl: http://en.wikipedia.org/w/api.php
复制代码
注释: MediaWiki 安装必须具有该 API 启用以便 VoxelBoards 工作. API 是默认启用但是如果禁用,你可以启用它通过编辑 LocalSettings.php 加入 $wgEnableAPI = TRUE; 在配置的最后一行.

链接面板到纯文本文件 (例如 单人冒险地图)
VoxelBoards也可以读取本地存储的纯文本文件内容,这可以用于例如如果你希望包含面板在一个单一玩家冒险地图或在你自己的单人游戏世界.

读取纯文本文件面板创建完全按照wiki面板,但是替代 #wiki 指令用 #txtfile 并指定一个文本文件的名称,而不是一篇文章的名称.你不必包含 .txt 扩展名,mod将附加到您指定的名字.mod将会读取在两个位置的纯文本文件:
在单人游戏,mod会首先读取
.minecraft/saves/WorldName/VoxelBoards/boardname.txt

并且如果文件没有找到,它会读取在
.minecraft/mods/VoxelMods/VoxelBoards/boardname.txt

左键单击一个文本文件(txtfile)面板无效果,而右键单击刷新文件内容从磁盘中.
