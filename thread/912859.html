标题: 获取一个圆形区域内的所有区块
现在需要获取一个圆心和半径已知的圆形内的所有区块
（用于通过坐标快速获取这个圆形）
目前我是用正方形近似，下面是代码
  1.                 val index = new HashSet<Index>();
  2. double centreX;
  3.                 double centreZ;
  4.                 double radius;
  5.                 int x1 = (int) Math.floor(centreX - radius) >> 4;
  6.                 int x2 = (int) Math.ceil(centreX + radius) >> 4;
  7.                 int z1 = (int) Math.floor(centreZ - radius) >> 4;
  8.                 int z2 = (int) Math.ceil(centreZ + radius) >> 4;
  9.                   for (int x = x1; x <= x2; x++) {
  10.                             for (int z = z1; z <= z2; z++) {
  11.                                       index.add(new Index(x, z));
  12.                             }
  13.                   }
  14. return index;

上面那个实现在radius效果不错，但当radius较大的时候，会有较大误差
请问各位还有什么更好的算法吗?
