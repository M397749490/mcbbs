前置插件：Multiverse-Core

无需Multiverse的版本(1.2.5)：下载地址 | 但是/dota restart命令必须配合Simple_Restart使用

地图说明原帖













推荐使用Multiverse-Inventories来管理仓库

玩家必须使用命令来传送到DOTA世界，例如：/mv tp Minecraft_dota

当塔旁有玩家时，怪物每10秒会生成

如果不再出怪，请确定config.yml中ForceMobSpawn为True

交易货币为任意物品

进入世界后在箱子中拿出矿车，然后站在任意踏板前，满6人则开启通道

倒塔需要两个玩家站在踏板上

选择好队伍后，拉下拉杆，30秒后打开大门(地面红石灯会进行倒计时)

因为没有使用任何其它插件/mod，完全红石操作，所以投放货币最好有间隔(作者建议2秒，好像有点长= =)
以后的版本会用插件/mod来代替红石进行物品贩卖(作者原话)


特点：
无法伤害队友(队伤滚粗=。=)
团队自动分配(黑店什么的去死吧= =)
出生点保护(擅闯死)
物品偷窃保护(70格半径)
自动重生点
方块保护
加入服务器并加入团队后背包会清除
给怪物最后一击以掉落物品
在加入游戏后玩家会得到一把石剑、一块生鸡肉以及一张地图(重复加入无效)
无法打开敌人的箱子
玩家加入、倒塔、团队胜利时进行世界广播

安装说明：
1.下载地图文件，解压到服务器文件夹下(默认文件名是Minecraft_dota)

2.下载DOTA插件和Multiverse-Core并放到Plugins文件夹下
3.运行一次服务器然后在Multiverse-Core的配置文件中增加Minecraft_dota世界
    Multiverse-Core/worlds.yml配置范例：

# 这行是DOTA地图文件名

    seed: -215693617893672367
    environment: NORMAL
    type: FLAT
    hidden: false
    alias:
      name: ''
      color: WHITE
    pvp: true
    scale: 1.0
    respawnworld: ''
    allowweather: false
    difficulty: EASY
    animals:
      spawn: false
    monsters:
      spawn: false
    entryfee:
      currency: -1
      price: 0.0
    hunger: true
    autoheal: true
    adjustspawn: true
    portalform: ALL
    gamemode: SURVIVAL
    keepspawninmemory: true
    spawn:
      x: -1257.5
      y: 66.0
      z: 118.5
      pitch: 0.0
      yaw: 0.0
      world: Minecraft_dota
    autoload: true
    bedrespawn: true

命令：
/dota join - 加入游戏
/t 聊天内容 - 团队聊天。例如：/t 为了部落！
/dota score - 查看分数
/dota restart - 重置游戏世界
    需要dota.restart权限(仅当游戏结束时)，如果在游戏未结束时想使用命令，则必须有dota.forcerestart权限
    地图不会被保存，如果保存，则是因为其它插件的缘故
/dota recall - 传送回基地
    和DOTA一样，这是延迟传送。
    可以在配置文件中禁用。
    如果移动，传送会取消

权限：
dota.chooseteam - 自由选择团队。即在 join 后加red或blue
dota.restart - 游戏结束后使用restart命令
dota.forcerestart - (2.12新增)任何时间使用restart命令

配置：
  1. # 启用插件
  2. Enabled: true
  3. # 地图名称
  4. WorldName: Minecraft_dota
  5. # 根据阵营改变名字标签
  6. colorNameTag: true
  7. # 玩家死亡保留物品
  8. PlayersKeepItems: true
  9. # 玩家死亡保留等级
  10. PlayersKeepLevel: true
  11. # 强制怪物生成(从2.2版本开始被移除)
  12. ForceMobSpawn: true
  13. # 启用回城指令
  14. RecallEnabled: true
  15. # 回城等待时间
  16. RecallDelay: 6
  17. # 移除怪物盔甲
  18. removeMobArmor: false
  19. # 给怪物皮革头盔
  20. giveMobsHelmet: true
复制代码

  1. pvp=true
  2. difficulty=1
  3. gamemode=0
  4. max-players=11
  5. spawn-monsters=false
  6. view-distance=15
  7. spawn-animals=false
