Tablist


Actionbar || Tablist || Titlebar
这个作者一共有三个插件，我都搬过来了，点击名字跳转，表示三个搬运帖的排版都没变过233
三个插件可以一起使用
百度网盘下载地址 链接：https://pan.baidu.com/s/1DUoIxvGHum7ExPtFJTwJCg
提取码：r2sg



功能

这个插件允许你自定义Tab列表，支持彩色字体和动态字体！
效果图:


安(fei)装(hua)
需要1.8以上服务端
1.下载插件
2.丢进plugins文件夹内
3.启动服务器

指令
        
/tablist(/tlist)(/tl)                打开帮助菜单
/tl        reload        重载插件

权限

/titlebar reload        tablist.reload

变量
玩家变量

%gamemode%                显示玩家的游戏模式
%money%                       显示玩家的金币余额
%player%                        显示玩家的名字
%level%                           显示玩家的等级
%health%                        显示玩家的生命值
%foodlevel%                    显示玩家的饱食度
%maxhealth%                  显示玩家的最大生命值
%iteminhandtype%          显示玩家手持物品的类型
%iteminhandamount%     显示玩家手持物品的数量
%iteminhandid%               显示玩家手持物品的ID
%group%                         显示玩家所在权限组的名字
%prefix%                          显示玩家所在权限组的前缀
%suffix%                           显示玩家所在权限组的后缀
%ping%                            显示玩家的延迟

世界变量

%difficulty%                        显示世界的难度
%world%                            显示世界的名字
%blockx%                           显示玩家所在的X坐标
%blocky%                           显示玩家所在的Y坐标
%blockz%                            显示玩家所在的Z坐标
%direction%                        显示玩家面朝方向的名字
%directionLetter%                显示玩家面朝方向的首字母
%directionNumber%             显示玩家面朝方向的数字
服务端变量
%vanishedplayer%                显示隐身玩家的数量
%onlineplayers%                   显示在线玩家的数量
%maxonlineplayers%             显示最大在线玩家的数量
%servermotd%                      显示服务器的MOTD
%servername%                     显示服务器的名字
%serverid%                          显示服务器的ID
%serverip%                          显示服务器的IP地址
%serverport%                       显示服务器的端口
%staffs%                              显示在线的拥有权限的玩家的数量(可以在config里编辑用于使用此变量的权限)

真实世界变量

%time%                               显示真实世界的时间
%date%                               显示真实世界的日期

配置文件

  1. # Tablist v1.2.3.7 by sn1cko
  2. # Time is set in milliseconds which means every 20 = 1 second
  3. # for example: 6000 = 5 minuntes OR 300 = 15 seconds
  4. #
  5. # The announcer will never stop if the time is set to 0
  6. # Else it will stop after the amount of milliseconds you wish
  7. #
  8. # There are currently 15 variables available which can be built in
  9. # for example %player% - will display the playername or %health% - will give out the health
  10. # all other variables can be found on the website
  11. # http://dev.bukkit.org/bukkit-plugins/tablist/pages/variables
  12. Tablist:
  13.   Settings:
  14.   #能被%staffs%变量检测到所需权限
  15.     Staff:
  16.       Permission: tablist.staff
  17.   #是否启用
  18.     Toggle: true
  19.   #变化时间
  20.     Time: 20
  21.     Messages:
  22.   #顶部
  23.   #   - |-
  24.   #
  25.   #
  26.   #这里编辑显示的内容
  27.   #
  28.   #
  29.   #   - |-
  30.       Header:
  31.       - |-
  32.         &5&lSERVERNAME.dot
  33.         &7&lPlayer: &3&l%player%
  34.         &7&lHealth: &a&l%health% &7&l/ &2&l%maxhealth%
  35.         &7&lFood: &a&l%foodlevel% &7&l/ &2&l10.0

  37.             &7&m===================
  38.       - |-
  39.         &6&lSERVERNAME.dot
  40.         &8&lPlayer: &b&l%player%
  41.         &8&lHealth: &c&l%health% &8&l/ &4&l%maxhealth%
  42.         &8&lFood: &c&l%foodlevel% &8&l/ &4&l10.0

  44.             &7&m===================
  45.   #底部
  46.       Footer:
  47.       - |-
  48.         &7&m===================

  50.         &7&oOnline: &d&o%onlineplayers%&7&o/&5&o%maxonlineplayers%
  51.       - |-
  52.         &7&m===================

  54.         &8&oOnline: &e&o%onlineplayers%&8&o/&6&o%maxonlineplayers%
