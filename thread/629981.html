ItemGoCmd

让指令需要特殊物品执行

----------------------------------------------------------------------------------------------

介绍

让你的指令需要指定物品执行

配置文件

config.yml
主配置文件
  1. lang:
  2.   NotReloadPerm: '&c&l你没有权限重置插件'
  3.   ReloadOK: '&a&l重置成功'
  4.   ReloadError: '&a&l重置失败'
  5.   NotGivePerm: '&c&l你没有权限给予物品'
  6.   GiveOK: '&a&l成功获得了一个物品'
  7.   GiveSB: '&e&lItemGoCmd'
  8.   textNotItemHand: '&e%cmd%指令需要物品&a[%item%&a]&b来执行&c&l(你必须手持这个物品)'
  9. settings:
  10.   fb:
  11.     DisplayName: '&e&l萤火之石'
  12.     Lore: '&a&l开启失落大陆的钥匙'
  13.     onLore: true
  14.     Cmd:
  15.     - warp fb
  16.     - warp fb1
  17.     ItemId: 370
  18.   tpa:
  19.     DisplayName: '&e&l传送宝石'
  20.     Lore: '&a&l传送宝石'
  21.     onLore: true
  22.     Cmd:
  23.     - 'tpa '
  24.     ItemId: 280
复制代码


指令和权限


  1. /igcgive <物品>------获得指定物品 权限 igc.give
  2. /igclist -----------------查看物品列表 权限 igc.list
  3. /igcreload-------------重置插件 权限 igc.reload
  4. 无视物品限制 权限 igc.noigc
  5. OP拥有所有权限
