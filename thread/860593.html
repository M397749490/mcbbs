  1. ### 0x14 并查集

  3. 并查集可以让我们比较方便的维护集合的信息

  5. [并查集](<https://www.luogu.org/problemnew/show/P3367>)

  7. 给出n个元素和m次操作 每次操作可以

  9. - 将两个元素所在的集合合并
  10. - 查询两个元素是否在一个集合内

  12. $n\le10^4,M\le2\times10^5$



  16. 不妨写出来一个暴力

  18. ```cpp
  19. int col[maxn];
  20. int main(){
  21.     int n,m;cin>>n>>m;
  22.     for(int i=1;i<=n;i++)col[i]=i;
  23.     while(m--){
  24.         int op,x,y;cin>>op>>x>>y;
  25.         if(op == 1){
  26.             if(col[x] == col[y])continue;
  27.             int tmp = col[x];
  28.             for(int i=1;i<=n;i++)
  29.                 if(col[i] == tmp)col[i] = col[y];
  30.         }else{
  31.             cout<<(col[x] == col[y]?"Y":"N")<<endl;
  32.         }
  33.     }
  34. }
  35. ```

  37. 大概思路就是选出一个元素作为集合的代表元素 并用这个元素给这个集合中的所有元素染色

  39. 查询的时候直接去考虑颜色是否相同就可以了

  41. 但是这么做的复杂度高达$O(nm)$ 所以我们需要一个比较优秀的做法



  45. 我们实际上可以直接对每个集合建出来一棵树 这个树中所有节点就是属于这个集合的元素

  47. 于是我们的代表元素就是树的根

  49. 合并的时候找到一棵树的根 然后直接扔到另一棵树上作为它的儿子就好了



  53. 但是这么做的复杂度不对 **情况下这棵树会退化成链 查询代表元素的根的复杂度就会达到$O(n)$

  55. 所以我们有两种优化：

  57. - 路径压缩

  59. 我们发现实际上这棵树的形态对我们要维护的信息没有任何影响

  61. 那么我们可以直接把一个集合中的所有元素的父亲设为代表元素 这样在查询的时候就可以十分快速的得到根节点

  63. 如果某个节点的父亲不是代表元素 那么我们可以直接把这个节点到代表元素的链上的所有节点的父亲设为代表节点

  65. ```cpp
  66. int fa[maxn];//节点的父亲
  67. int findfa(int x){//虽然说写着是找父亲 但是找的实际上是代表元素
  68.     if(x == fa[x])return x;//当x=fa[x]时 说明x是代表元素
  69.     int tmpfa = findfa(fa[x]);
  70.     fa[x] = tmpfa;
  71.     return tmpfa;
  72. }
  73. int findfa(int x){
  74.     return x==fa[x]?x:fa[x]=findfa(fa[x]);//或者你使用一些技巧写成这样的一行
  75. }
  76. ```

  78. - 按秩合并

  80. 秩可以有很多种定义方式 在这里比较通用的定义是子树的大小 当然你也可以定义为树的深度

  82. 我们发现实际上只需要在合并的时候将秩比较小树合并到秩比较小的树上就行了

  84. ```cpp
  85. int siz[maxn];//秩
  86. void merge(int a,int b){
  87.     a = findfa(a),b = findfa(b);
  88.     if(siz[a] < siz[b]){
  89.         fa[a] = b;siz[b] += siz[a];
  90.     }else{
  91.         fa[b] = a;siz[a] += siz[b];
  92.     }
  93. }
  94. ```



  98. 这两种优化任何一种都可以让并查集的复杂度降低到$O(logn)$

  100. 但如果你将两个一起使用可以把复杂度降低到$O(\alpha n)$ 这里的$\alpha$是反阿克曼函数 增长极慢

  102. ### 0x14 简单平衡树

  104. 平衡树是一种比较优雅的树

  106. 前置知识：堆 线段树

  108. [【模板】普通平衡树](<https://www.luogu.org/problemnew/show/P3369>)

  110. 题目大意：

  112. 你需要支持六种操作

  114. 1. 向可重集中插入一个元素x
  115. 2. 删除集合中的一个元素x（如果有多个x 只删除一个）
  116. 3. 查询元素x在集合中的排名
  117. 4. 查询排名为x的数
  118. 5. 求在集合中小于x并且最大的数
  119. 6. 求在集合中大于x并且最小的数



  123. 接下来我们会分几种不同的做法来讲

  125. #### 0x15 BST

  127. BST的中文名叫做二叉查找树（Binary Search Tree）

  129. 它满足对于任意一个节点 其左儿子的权值大于本身 本身的权值大于右儿子

  131. 很显然假如我们按先序遍历输出树的权值 得到的数组是从小到大有序的

  133. BST的实现在这里不再讲解 因为BST在最劣情况下（插入的数有序）构造出来的树会退化为链
  134. (也即每个节点只有一个儿子，构成一条链，失去树的存在意义)

  136. 在链上的时间复杂度可以达到$O(n)?$ 是一种不太优美的算法

  138. 当然 也不能通过本题

  140. #### 0x16 Treap

  142. Treap是所有平衡树实现中最简单 常数也比较小的一种做法

  144. 我们发现BST很容易不平衡（左右儿子大小相差较大） 但是BST具有很多优美的性质

  146. 所以Treap给每个节点一个随机权值$rnd$

  148. 对于每个点的权值 它们构成一颗BST

  150. 对于每个点的随机权值 它们构成一个**堆**（这里默认为小根堆）

  152. 同时$rnd$ 是随机生成的 于是这棵树的深度会近似于$logn$ 可以说是很平衡的

  154. 之后需要进行操作的时候就可以直接按照bst来操作



  158. 且慢 我们怎么把随机权值维护成一个堆？

  160. 我们首先定义旋转操作

  162. 旋转分为两种 左旋与右旋

  164. 左旋可以把一个节点变到它右儿子的位置

  166. 右旋可以把一个节点变到它左儿子的位置

  168. 同时左右旋都不会改变BST的性质

  170. 在插入一个节点的时候 我们先把他放到某个叶子结点的后面 然后再把他不断通过旋转操作放到合适的位置

  172. 删除时

  174. 如果这个节点是叶子节点 直接删除

  176. 如果这个节点不是叶子结点 选择其左右儿子中随机权值比较小的旋转上来

  178. 直到这个节点是叶子结点为止

  180. ~~剩下的所有操作乱搞一下就好了x~~剩下的操作还是要说一下的

  182. - 查找排名

  184. 这个就比较简单了 从根开始递归左儿子或者右儿子寻找这个值

  186. 递归左儿子还是递归右儿子由当前节点的权值与查找的数的大小有关

  188. 然后统计一下答案就可以了

  190. - 查找排名为k的数

  192. 这个把查找排名倒过来就行了x

  194. 假如左儿子的大小大于等于k 那就去左儿子找 不然去右儿子找

  196. - 前驱后继

  198. 仅以找前驱为例 后继是相似的

  200. 对于当前节点 假如它的权值小于我们要找前驱的数的权值 那么我们就可以考虑到答案应该在当前节点和它的右儿子当中

  202. 假如它的权值大于要找前驱的数的权值 那么就说明答案在当前节点的左儿子中

  204. 递归寻找并处理即可



  208. 由于这棵树的**随机**权值满足堆的性质 其深度在$logn$左右 而绝大多数操作都与树的深度有关

  210. 于是Treap维护这道题的复杂度是$O(nlogn)$

  212. #### 0x17 FHQ-Treap

  214. FHQ是范浩强的缩写

  216. 这种平衡树有很多种叫法

  218. 非选treap 可持久化treap之类的 不过本质上是一样的



  222. 我们同样还是考虑一颗treap

  224. 我们发现旋转实际上是一个十分麻烦的操作

  226. 但是假如我们可以支持把一棵树拆开以及合并两棵树这两种操作

  228. 支持那六种操作的难度就会低很多

  230. 所以我们可以考虑fhq-treap 以下简称fhq



  234. fhq支持两种操作 split以及merge

  236. split又分为两种 按值分裂以及按排名分裂 这里只讲第二种

  238. 按排名分裂的split可以将一颗树分成两棵树 并保证第一棵树的大小为k 还保证分裂后的两棵树都是Treap

  250. 我们来简单yy一个分裂的过程

  252. 这里我们定义分裂后的两颗树分别叫做树1和树2

  254. 同时定义每个节点的大小为以这个节点为根的数的节点数

  256. - 对于当前节点 假如它是叶子 那么此时k只能为0或1 按照规则把当前节点分入树1或树2
  257. - 对于当前节点 如果它不是叶子结点 那么此时考虑它的左儿子的大小
  258.   - 假如它的左儿子的大小大于等于k 那么就说明当前节点在树2中 于是我们把左儿子按照排名为k分裂 之后将当前节点的左儿子设置为树2的根 再令当前节点作为树2的根节点
  259.   - 假如它的左儿子的大小小于k 那么就说明当前节点在树1中 于是我们把右儿子按照排名为$k-leftSize()-1$(令leftsize()表示当前节点的左儿子大小)分裂 之后将当前节点的右儿子设为树1的根 再令当前节点为树1的根
  260.     - 仔细想想 为什么是$k-leftsize()-1$？
  261. - 我们发现实际上并不需要单独讨论叶子结点 因为假如我们在分裂空节点时返回两颗空的树 那么按照上面这个过程叶子结点也会被划分到正确的树中

  263. 于是按照Treap的定义和fhq的分裂过程 我们先写出节点的定义

  265. ```cpp
  266. struct Node;         
  267. typedef Node* ptr_t;//ptr_t是一个类型 这个类型是Node的指针
  268. struct Node{
  269.     ptr_t lson;
  270.     ptr_t rson;
  271.     int size,val,rnd;
  272.     Node(int w){
  273.         val = w;rnd = rand();size = 1;
  274.         lson = rson = nullptr;//nullptr表示空指针
  275.     }
  276.     int leftSize(){
  277.         if(lson != nullptr)
  278.             return lson -> size;//-> 可以访问一个指针对应的元素中的变量
  279.         return 0;//这里需要先判断一下左儿子是不是空 不然会访问空指针
  280.     }
  281.     void maintain(){//在lson和rson变动后 我们需要更新当前节点的大小
  282.         size = 1;
  283.         if(lson != nullptr)size += lson -> size;
  284.         if(rson != nullptr)size += rson -> size;
  285.     }
  286. };//现在我们需要假设读者能看懂一部分C++代码了。
  287. ```

  289. 之后我们可以十分简单的写出分裂的代码

  291. ```cpp
  292. typedef pair<ptr_t,ptr_t> pair_t;
  293. //pair_t中包含了两个元素first second 类型都为ptr_t
  294. //在这里first表示树1 second表示树2
  295. pair_t split(ptr_t rt,int k){//将当前节点(rt) 按排名(k)分裂
  296.     if(rt == nullptr)return pair_t(nullptr,nullptr);//假如当前节点为空
  297.     if(rt -> leftSize() >= k){//-> 也可以访问指针对应的元素的函数
  298.         pair_t tmpAns = split(rt -> lson,k);
  299.         rt -> lson = tmpAns.second;
  300.         rt -> maintain();
  301.         return pair_t(tmpAns.first,rt);
  302.     }else{
  303.         pair_t tmpAns = split(rt -> rson,k - rt -> leftSize() - 1);
  304.         rt -> rson = tmpAns.first;
  305.         rt -> maintain();
  306.         return pair_t(rt,tmpAns.second);
  307.     }
  308. }
  309. ```



  313. 那么 现在我们写完了分裂 只剩合并需要我们去考虑了

  315. 我们发现合并的时候要同时满足BST和堆这两个性质

  317. 那么我们首先删掉一个需要维护的性质

  319. 经过深思熟虑 你决定不在合并的时候维护BST

  321. 这就导致我们在合并的时候需要满足树1的所有节点的权值都需要小于树2任何一个节点的权值

  323. 我们从一个简单的情况入手

  325. 假如需要合并的两颗树是树1和树2 其中有一棵是空的

  327. 那么 很显然的 答案就是非空的那棵树

  329. 之后我们可以讨论讨论比较复杂的情况

  331. 比如对于这张图

  333. ![img](http://luogu-ipic.oss-cn-shanghai.aliyuncs.com/isd5z.bmp)

  335. 对于正在合并的两棵树

  337. 我们判断一下两棵树的根的随机权值大小 然后分情况讨论

  339. - 树1的根的随机权值 小于 树2的根的随机权值

  341. 这时候为了满足堆的性质 我们应当让树2作为树1的儿子

  343. 然后为了满足BST的性质 我们要让树2作为树1的右儿子

  345. 。。 那么树1原本的右儿子怎么办呢？

  347. 这好办 把树1的右儿子和树2合并以后的新树作为树1的右儿子就好了

  349. - 树2的根的随机权值 大于等于 树2的根的随机权值

  351. 和上面那种情况类似 但是这里需要让树1作为树2的儿子

  353. 合并的是树1和树2的左儿子



  357. 当你想要写这个函数的时候 你一定要特别注意树1和树2需要满足**树1的所有节点的权值都需要小于树2任何一个节点的权值**

  359. ```cpp
  360. ptr_t merge(ptr_t a,ptr_t b){//a b是两棵要合并的子树
  361.     if(a -> rnd < b -> rnd){
  362.         a -> rson = merge(a -> rson,b);
  363.         a -> maintain();
  364.         return a;
  365.     }else{
  366.         b -> lson = merge(a,b -> lson);
  367.         b -> maintain();
  368.         return b;
  369.     }
  370. }
  371. ```



  375. 之后我们来考虑怎么用split和merge来维护这道题的六种操作

  377. - 插入一个数

  379. 在平衡树中找到当前数的排名k 之后将树分成两棵子树 第一棵的大小为k-1

  381. 之后合并树1与当前插入的数的节点 再把这棵合并出来的树与树2合并

  383. ```cpp
  384. void insert(int w){
  385.     int k = getRnk(root,w);//getRnk即查找排名的函数 这里返回的是排名-1
  386.     pair_t tmp = split(root,k);//root是整颗树的根
  387.     root = merge(tmp.first,merge(new Node(w),tmp.second));
  388. }
  389. ```

  391. - 删除一个数

  393. 在平衡树中找到当前数的排名k 之后将树分成三棵子树 前两棵的大小分别为k-1和1

  395. 之后直接合并树1和树3就好了 如果你愿意 也可以把树2的内存释放掉

  397. ```cpp
  398. void del(int w){
  399.     int k = getRnk(root,w);
  400.     pair_t tmp = split(root,k);
  401.     pair_t ttp = split(tmp.second,1);
  402.     root = merge(tmp.first,ttp.second);
  403. }
  404. ```

  406. - 查找一个数的排名

  408. 从根开始向左右儿子递归 顺便计算答案

  410. ```cpp
  411. int_t getRnk(ptr_t rt,int w){
  412.     if(!rt)return 0;//当前节点为空时不再递归
  413.     if(rt -> w >= w)return getRnk(rt->lson,w);
  414.     return getRnk(rt->rson,w) + rt -> leftSize() + 1;
  415.     //当查询节点在当前节点的右儿子时 这个节点的在树中的排名还要加上当前节点的左儿子大小以及当前节点
  416. }
  417. ```

  419. - 查找排名为k的数

  421. 直接把树拆成k-1 1 xxx三棵树就好了 答案就是第二棵树的值

  423. 当然你也可以像我一样把树拆成大小为k和xxx的两棵树 然后在树1中找最大值

  425. ```cpp
  426. int getVal(int k){
  427.     pair_t tmp = split(root,k);
  428.     int ans = findMax(tmp.first);
  429.     root = merge(tmp.first,tmp.second);
  430.     return ans;
  431. }
  432. ```

  434. - 找前驱后继

  436. 仅以前驱举例

  438. 首先拿到这个数的排名k 然后把树拆成两棵树k-1和xxx

  440. 那么很明显的 树1中的最大值就是前驱

  442. ```cpp
  443. int getPre(int x){
  444.     pair_t tmp = split(root,getRnk(root,x));
  445.     int ans = findMax(tmp.first);
  446.     root = merge(tmp.first,tmp.second);
  447.     return ans;
  448. }
  449. ```

  451. - 最大最小值

  453. 你可能会想着把整棵树都遍历一遍

  455. 但是并不需要这么麻烦

  457. 查询最大值只需要一直顺着右儿子走就行了

  459. 最小值同理

  461. ```cpp
  462. int findMax(ptr_t rt){
  463.     while(rt -> rson)rt = rt -> rson;
  464.     return rt -> w;
  465. }
  466. ```



  470. 它的复杂度和treap的复杂度的分析方式是一样的 于是它的复杂度也是$O(nlogn)$

  472. 但你需要特别注意的是 它的常数会比treap大那么一丢丢

  474. 不过它比treap好写好用

  476. 而且 fhq是唯一一个支持可持久化的平衡树

  478. #### 0x18 Splay

  480. 是不是不想维护堆的性质了？

  482. 那么splay可以满足你的需要

  484. 我们发现bst不平衡的时候整棵树与链十分的像

  486. 那么我们是不是可以在旋转的时候破坏掉链 把链变成树？

  488. 于是就有了splay

  490. splay的主要操作依然是旋转

  492. splay的旋转不同于treap的只有两种方式

  494. 它的旋转一共有四种情况 这被称为**双旋**

  496. 在这里需要说一句 **单旋**splay是一个**假**算法 其复杂度不对



  500. 我们先举一个例子       

  502. ![img](https://inf.tiger0132.tk/2018/07/19/splay-notes/src.svg)

  504. 假设现在我们要把2这个节点向上旋转 那么我们发现

  506. 首先让6的左儿子变成2

  508. 然后令4作为2的右儿子

  516. 然后根据父节点对于爷爷节点的位置以及当前节点对于父节点的位置 一共可以搞出来四种旋转

  518. 于是你用手模拟了一遍这个过程 发现旋转有以下规律：

  520. - 令k表示当前节点是父节点的左儿子还是右儿子 左儿子则$k=0$ 否则为1
  521. - 爷爷节点连向父节点的边会删掉 然后连向当前节点
  522. - 父节点将作为该节点的$(k\text^1)$这个儿子（$k=0$时即右儿子 反之则是左儿子）
  523. - 该节点原本的$(k\text^1)$这个儿子会作为父节点的k这个儿子（$k=0$则是左儿子）

  525. 你发现这并不是很容易看懂 于是你可以看这段代码

  527. ```cpp
  528. void rotate(int x){//这里不再写指针 而是用节点的标号来表示这个节点
  529.     int y = fa[x],z = fa[y],k = check(x),w = son[x][k^1];
  530.     //y是父节点 z是爷爷节点 k即上文的k w即x的k^1这个儿子
  531.     //fa数组表示节点的父亲
  532.     son[z][check(y)] = x; fa[x] = z;
  533.     son[x][k^1] = y;fa[y] = x;
  534.     son[y][k] = w;fa[w] = y;
  535. }
  536. ```

  538. 之后我们需要考虑一个问题 假如我们要把一个节点旋转到它的某个祖先 我们该怎么旋转？

  542. 你需要在旋转的过程中考虑到一个“它 它父亲 它爷爷”三点一线的问题

  544. 也就是说$check(x)=check(fa[x])$

  546. 这时候你要先旋转它的父亲



  550. 这个操作被称为伸展 英文即$splay$

  552. 事实上这个操作是splay最重要的操作

  554. 具体来说 它可以把一个节点旋转到另一个节点的儿子的位置

  556. 代码如下

  558. ```cpp
  559. void splay(int rt,int goal=0){//goal为目标节点
  560.     while(fa[rt] != goal){//当前节点的父亲不是目标节点
  561.         int y = fa[rt],z = fa[y];
  562.         if(z != goal){// 如果爷爷节点是目标节点 旋转两次后rt就到了目标节点的位置 所以要判断一下
  563.                        if(check(rt)==check(y))rotate(y);//处理三点一线
  564.             else rotate(rt);
  565.         }
  566.         rotate(rt);
  567.     }
  568.     if(!goal)root=rt;//如果goal是0 则说明把rt旋转到根
  569. }
  570. ```

  820. 假如对于一个数列中的每个数$A_i$ 我在$i$这个版本把位置为$A_i$的值加上1

  822. 那么当我需要知道前$k$个数中$x$出现了几次时 就可以直接去查询$k$这个版本的$x$的值

  830. 因为这个性质是某个叫做hjt（重名）的竞赛选手提出的 所以这种算法就有了一个叫**树的名字
