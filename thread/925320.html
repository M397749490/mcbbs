监听鼠标左键发射的一个实体未能正常造成伤害

经过排查，发现实体的onImpact方法
protected void onImpact(RayTraceResult result){
        if ((result.entityHit != null)&&(result.entityHit!=this.getThrower()))
        {
            result.entityHit.attackEntityFrom(DamageSource.causeThrownDamage(this, this.getThrower()), this.byHand? 23.F:25.F);
        }

        if (!this.world.isRemote)
        {
            this.world.setEntityState(this, (byte) 3);
            this.setDead();
        }
}
第二个if没有走进去。
不过我虽然猜到了是和服务端客户端有关的问题，但我并不知道怎么改比较好。。有大佬吗
