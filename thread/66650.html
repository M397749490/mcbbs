什么是HerobrineAI?

HerobrineAI是可以于你的服务器创建一只Herobrine(Him),并拥有自身AI和皮肤。Herobrine(Him)可以于世界中随机出现和会攻击或惊吓你的玩家。如果你没耐性等待Herobrine(Him)随机生成出来，有使用本插件的权限者可以手动生成并指定目标玩家。

Herobrine(Him)可以做点什么?
攻击或惊吓你的玩家
创建小洞穴、写书、放置牌子
可以攻击生物和掉下东西
他会在目标附近发出可怕的的声音
可以利用图腾召唤他
于世界中随机走动
发送信息
于玩家附近放置附有可怕句子的牌子
把书本放置于玩家的背包里

本插件最新稳定版本是 v1.3.2
  • 完全支持1.4.2


插件指令
  • 所有命令前需先输入/hb-ai
  • /hb-ai help - 显示本插件所有指令
  • /hb-ai attack <玩家名字> - 设置该玩家为Herobrine(Him)的攻击目标
  • /hb-ai haunt <玩家名字> - 设置该玩家为Herobrine(Him)的惊吓目标
  • /hb-ai cancel - 取消Herobrine(Him)指定的目标
  • /hb-ai reload - 重新载入本插件配置
  • /hb-ai position - 查询Herobrine(Him)的位置
*"<>"不用输入

插件权限
  • /hb-ai help : hb-ai.help
  • /hb-ai attack : hb-ai.attack
  • /hb-ai haunt : hb-ai.haunt
  • /hb-ai cancel : hb-ai.cancel
  • /hb-ai reload : hb-ai.reload
  • /hb-ai position : hb-ai.position


插件配置
  • ShowInterval - 设置Herobrine(Him)寻找目标的时间间隔,但是主要取决ShowRate的值
  • ShowRate - 设置Herobrine(Him)寻找目标的级别,1 = 低, 2 = 一般, 3 = 高(设置为高时,他将会经常寻找受害目标)
  • HitPlayer - Herobrine(Him)会不会攻击玩家
  • SendMessages - 设置Herobrine(Him)攻击玩家时会发送信息
  • Lighting - Herobrine(Him)向世界发出雷电
  • DestroyTorches - Herobrine(Him)攻击玩家时会不会破坏半径内所有的火炬
  • DestroyTorchesRadius - Herobrine(Him)攻击玩家时破坏所有火炬的半径范围
  • Worlds - 设置Herobrine(Him)的活动世界
  • TotemExplodes - Herobrine(Him)于图腾生成出来的时候图腾会不会爆炸
  • OnlyWalkingMode - Herobrine(Him)只会在世界上到处走动而不会做其他动作
  • BuildStuff - Herobrine(Him)可以创建洞穴和放置红石火炬
  • PlaceSigns - Herobrine(Him)可以放置牌子
  • UseTotem - Herobrine(Him)可以从图腾中生成出来
  • Killable - 可以杀死Herobrine(Him)
  • Messages - 设置Herobrine(Him)攻击玩家时发送的信息
  • SignMessages - 设置Herobrine(Him)放置的牌子里的内容
  • BookMessages - 设置Herobrine(Him)所写书本的内容
  • Drops - 设置Herobrine(Him)被杀死时所掉下的物品
默认配置文件:
config:
  ShowInterval: 7000
  ShowRate: 2
  HitPlayer: true
  SendMessages: true
  Lighting: false
  DestroyTorches: true
  DestroyTorchesRadius: 5
  Worlds:
  - world
  TotemExplodes: true
  OnlyWalkingMode: false
  BuildStuff: true
  PlaceSigns: true
  UseTotem: true
  WriteBooks: true
  Killable: false
  Messages:
  - Even Notch can′t save you now!
  - Fear me!
  - Welcome to my world!
  - I am your death!
  - Grave awaits you!
  SignMessages:
  - I′m watching.
  - Death...
  - Eyes in dark...
  BookMessages:
  - White eyes in dark...
  - '... was last what I saw ...'
  - '... before i was dead.'
# For drops
# 264 is id for item
# count is count of dropped item
# chance of drop (0-100)%
  Drops:
    '264':
      count: 1
      chance: 20
!如果你认为生成太多Herobrine(Him),可以调高ShowInterval
