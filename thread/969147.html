写的挺好看的

getCurrentItem()获取的是玩家所点击的槽位上的物品
getCursor()才是获取玩家光标上拿着的物品

写方法长链遇到NPE时就把的每一节都输出一遍，哪里是null就一清二楚了
比如event.getCurrentItem().getItemMeta().getLore()
  1. System.out.println(e.getCurrentItem().toString());
  2. System.out.println(e.getCurrentItem().getItemMeta().toString());
  3. System.out.println(e.getCurrentItem().getItemMeta().getLore());
复制代码
根据null出现的情况我们可以写成

  1. @EventHandler
  2. public void onItemClick(InventoryClickEvent e) {
  3.         ItemStack cursorItem = e.getCursor();  // 玩家光标上拿着的物品
  4.         if(cursorItem.hasItemMeta()) {  // 判断物品是否有ItemMeta
  5.                 ItemMeta im = cursorItem.getItemMeta();
  6.                 if(im.hasLore()) {  // 判断物品ItemMeta是否有Lore
  7.                         if(im.getLore().contains("戒指")) {
  8.                                 return;
  9.                         }
  10.                 }
  11.         }
  12.         e.setCancelled(true);
  13. }
复制代码
另外物品栏点击事件还要注意判断getAction()和getClick()，防止玩家手持指定物品同时用数字键或shift键移动非指定物品
