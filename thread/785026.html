你需要在配置文件中自行写，下面是ChestCommands插件的例子：
menu-settings:
  name: '&1&lxxoo菜单'
  rows: 2
  command: 'cd'
  open-action: 'sound: note pling; tell: &eYou opened the example menu.'
  open-with-item:
    id: 1 用石头[1]打开菜单
    left-click: false 是否可以左键打开
    right-click: true 是否可以右键打开

    item-id: 347 另一种打开菜单的途径:手持该物品(左键/右键)能打开该菜单. 可以使用附加值.可以使用物品名称/物品ID
    left-click: true 如果你想左键(上面设置的)物品来打开菜单,请设置为true(左右两者可以同时为true)
    right-click: true 如果你想右键(上面设置的)物品来打开菜单,请设置为true
