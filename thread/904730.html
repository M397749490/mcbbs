DeathMessagesPrime

自定义和修改所有死亡消息

~让你的服务器多姿多彩吧~


作者前言

DeathMessagesPrime is a simple-to-use but still versatile death message plugin. It allows to freely format and modify all death messages in Minecraft to date.

提示：不支持CraftBukkit。请改用Spigot

.....为一个被炸毁的人改变死亡信息？

     ...有多种不同的死亡信息选择，取决于人们是死于短期还是长期跌倒？

...只为一个VIP玩家添加自定义消息，以便在被推入虚空之后死亡？
没关系~这个插件可以处理所有这些情况。

通用功能示例
允许区分死亡消息中的非命名和命名的怪物，并在死亡消息中显示它们。将普通玩家和管理员分开。
支持CrackShot（种类）
允许在特定世界中禁用PVP和非PVP消息
一个世界组功能，仅在其组中的特定世界中显示死亡消息
每种原因都有多条死亡信息
生物群落中的死亡信息
区分短距离和长距离击落（如Minecraft的消息，比较“击中地面太硬”和“从高处跌落”）
允许在击杀者或玩家“推”时指定死亡消息
允许更改闪电/enderpearl死亡信息（在Minecraft中也可以作为火烧/坠落信息）
支持消息中的玩家显示名称
每个正则表达式具有特定名称的怪物的自定义消息（因此支持自定义）
支持武器显示在消息中的工具提示
对于PVP死亡，半径范围内的死亡消息（仅杀手和受害者接收消息）
用于插件的heart-compat-mode，可以将健康栏显示为mob名称


指令和权限

/dmsg允许重新加载配置
权限节点deathmessagesprime.reload
控制执行此操作的能力
                                        /toggledeathmsg允许玩家使用deathmessagesprime.toggle权限
切换显示死亡消息给自己
请注意，此权限最初仅默认于OP，建议给普通玩家。
该插件还具有调试模式
可以从配置启用该模式以帮助解决冲突。

#死亡消息配置文件
#用UTF-8保存这个文件！
#您的文本编辑可能可以它（但是Windows记事本可能不行）

# 配置 版本
# 不要更改.
config-version: 47

# 世界组死亡消息
# 如果一个世界是在一个群体中，而死亡发生在那里，那么死亡信息也将显示在同一组中的其他世界中。
# 如果为false，则禁用此功能。相反，死亡信息出现在全部世界组中
# 启用后每个世界组内死亡消息可以看到但是世界组外的看不到
world-groups:
  _enabled: true
  world:
    - world
    - world_nether
    - world_the_end

# 以下玩家永远不会有死亡信息。
# 在此列表下输入UUID。 要获得在线的玩家ID，请输入
# 指令/dmsg uuid player_name<玩家名>.  
# 默认: (空)
player-blacklist:
# - '00000000-0000-0000-0000-000000000000'

# 列出的世界，禁用PVP死亡消息。
# 默认：(空)
worlds-no-pvp-death-messages:
# - world2

# 列出的世界，其中禁用除了PvP之外的其他任何内容的死亡消息
# 记录在这里.
# 默认: (空)
worlds-no-natural-death-messages:
# - world2

# 列出的世界，死亡信息只显示给杀手和受害者
# 默认: (空)
worlds-private-pvp-death-messages:
# - world3

# 列出的世界，死亡信息仅显示给在此死亡的玩家
# 默认: (空)
worlds-private-natural-death-messages:
# - world3

# 死亡消息的半径
# 如果当前世界有死亡消息半径，则死亡消息不会对其他世界的玩家显示
worlds-death-message-radius:
    #world: 10

# 控制PVP消息（不是自然死亡消息)
# 如果两者都设置了，则上面的worlds-death-message-radius会影响自然消息，这个会影响PVP消息。
# 为了只有PVP消息半径，仅在此处添加世界。上方不用加
worlds-pvp-death-message-radius:
    #world: 10

# 如果玩家在死亡间隔时间内死亡超过死亡次数
# 那么该玩家的死亡消息将被隐藏在死亡冷却时间内。
# 死亡数：3
cooldown-death-count: 3
# 死亡间隔时间: 10
cooldown-death-interval: 10
# 信息冷却时间: 10
cooldown-death-cooldown: 10
# 如果death-reset为true，那么每个隐藏的死亡消息都会重置冷却时间。: false
cooldown-death-reset: false

# 显示插件死机时的调试信息，对确定插件冲突很有用，
# 等等.[正常时候不要作死开起来玩！]
# 默认: false
debug: false

# 在所有世界中显示死亡消息，如果false.需要是true的才能在worldgroups正常运行
# 默认: true
per-world-messages: true

# 死亡消息兼容性：
# 如果出现任何冲突，请使用此选项
# 默认: true
death-message-compat-mode: true

# 如果设置了自定义死亡消息，是否使用DMP广播
# 另一个插件.
# 默认: false
death-message-conflict-broadcast: false

# 是否启用namedmob消息。 如果禁用，则namedmob消息将不会显示，将被替换.
# 默认: true
death-message-enable-namedmob: true

# 显示％weapon_name％和％weapon％标签中名称。
# (这会影响死亡消息的文本颜色和格式)
# Default: true
death-message-show-rarity: true

# 允许对死亡消息中出现的项目应用标志.
# 请注意，此功能仅适用于Minecraft 1.8及更高版本。
# 可以用的标志记录在https://hub.spigotmc.org/javadoc ... ntory/ItemFlag.html下
death-message-item-flags:
# - HIDE_ATTRIBUTES
# - HIDE_ENCHANTS

# Heart兼容模式：当mob名称时使用mob而不是namedmob
# 包含心脏字符.
# 专为Healthy插件设计，等等。
# 如果死亡消息中人的名称是一行代表的心脏，则启用此功能
# health.
# Default: false
heart-compat-mode: false

# 如果mob名称包含以下任何字符而且
# 启用了heart-compat-mode，则会显示默认的mob名称。
# 如果健康栏仍然可见，则可以你添加字符
#（从死亡消息日志中复制的字符）或删除它们。
heart-characters: "???■"

# 将死亡消息广播到控制台
# none: 不要在控制台中打印死亡消息。
# normal: 在控制台中打印死亡消息。
# verbose: 打印详细消息，包括坐标和其他信息。
# Verbose对调试很有用
# 默认: normal
console-death-message: normal

# 清理控制台中打印的消息的前缀/后缀，
# 如果console-death-message设置为normal，则可以省略
# 默认: false
console-death-message-strip-prefix: false

# 清理控制台中打印的消息中的颜色代码，
# 如果console-death-message设置为normal，则可以省略
# 默认: false
console-death-message-strip-colors: false

# 即使世界已禁用死亡消息，也会在控制台中显示死亡消息
# 默认: true
console-death-message-even-if-disabled: true

# 侦听器的优先级。 如果存在任何冲突，请设置为较低的值
# 从高到低依次为：HIGHEST，HIGH，NORMAL，LOW，LOWEST
# MONITOR是不支持的 - 不要使用它，因为它会导致冲突并且可能会发生冲突
# 默认: HIGH
death-listener-priority: HIGH

# 是否显示自定义武器死亡消息（例如ZombieCustom）
# 所有武器 (true), 自定义名称的武器 (false).
# 默认: false
show-custom-death-msg-on-all-weapons: false

# 这个功能现在没有实现，因为API不支持
# 是否显示驯服和命名宠物的死亡信息。
# 默认: true
show-named-pet-death-messages: true

# 使用/toggledeathmsg启用和禁用死亡消息的消息
death-messages-hidden: "&a[DMP] &a其他人的死亡信息现在将被隐藏"
death-messages-shown: "&a[DMP] &a其他人的死亡信息现在将显示"

# 这是死亡信息的变量，因此您可以添加很多你想要的，
# 插件可以使用这些变量。格式为＆0-＆f的颜色代码
# 和&k-&r也可以使用.
#
# %player% 代表玩家的名字.
# %name% 表示玩家的显示名称.[带有前缀和后缀]
# %killer% 代表杀手.
# %killer2% 仅代表杀手显示的名称.
# %plrtag% 表示被击杀/死亡的玩家名称
# %victim% 表示被击杀/死亡的玩家显示名称.[带有前缀和后缀]
# %entity% 表示击杀者显示的名称.[带有前缀和后缀]
# %weapon_name% 表示武器名称.
# %weapon% 表示武器名称（包括内容提示）.
# %world% 代表死亡的世界名称.
# %biome% 代表发生死亡的生物群系.
# %x%, %y% and %z% 表示玩家死亡坐标.

#            方块 (如果启用)

常见问题/问题和解决方案

1.血条出现在死亡消息中而不是杀手的名称
从配置文件中启用heart-compat-mode（从false改成true）
2.添加多个死亡消息以便随机
选择一个消息只需在特定原因下添加多个死亡消息（使用相同的连字符优先语法添加更多消息）。该插件将在死亡时随机选择其中一条消息。

无效字符，不可接受的代码点，不允许使用特殊字符问题...
使用支持UTF-8的文本编辑器。大多数现代编辑甚至一些旧编辑都应该支持它
（请注意，记事本并不完全支持它，除非你在2019年5月或之前的Windows 10上）
如果您的编辑器支持它，请确保将文件保存为UTF-8
（具体步骤取决于您的文本编辑器）。不要用文本（字节顺序标记）保存
