插件介绍

这个插件是什么呢？我想我不用说大家也知道他有什么用处了吧...‘死亡扣钱’
这个插件有什么用呢？减轻服务器金钱压力，解决一些玩家有巨大的金钱差距.
这个插件好用么？我觉得挺好用的，只需要修改一下下config. 我想弄过插件的都应该会一点吧.

如何安装

MonetaryDeathPenalty不需要任何的前置模组|(当然任意经济插件还是要的)，安装方法与其他插件一样放到plugins文件夹即可.

指令


/mdp 查看插件版本
/mdp reload 重载插件
/mdp set prefix <数据> 设定插件前端
/mdp set pvppay <数据> 设定杀人赚取金钱数量
/mdp set usepercentage <数据> 是否启动被杀后掉落金钱
/mdp set flatpercentage <数据>设定被杀后掉落的金钱数量（百分比）
/mdp set flatamount <数据>设定被杀后掉落的金钱数量（数量）
/mdp set vipflatpercentage <数据>设定VIP被杀后掉落的金钱数量（百分比）
/mdp set vipflatamount <数据>设定VIP被杀后掉落的金钱数量（数量）
/mdp set minamountforpenalty <数据> 设定金钱底限（到这个数就不扣了）
/mdp set flatamountbelowminamount <数据> 如果玩家低于金钱底限那么他将获得这个金钱数量
/mdp set maxpercentagecap <数据> 设定百分比能扣的最大数量
/mdp set currencysymbol <符号> 设定金钱符号

  3. prefix - <span style="line-height: 1.5;">MonetaryDeathPenalty信息的前端</span><span style="line-height: 1.5;">. 想要取消设定成这样 prefix: 0</span>
复制代码





权限

- monetarydeathpenalty.reload
介绍: 可以重载插件
默认: op

- monetarydeathpenalty.ignore
介绍: 死亡不扣钱
默认: op

- mdp.vip
介绍: 享受monetarydeathpenalty的VIP功能（就是少扣点）.
默认：OP
- mdp.admin
介绍: 可以使用修改指令，适合给予管理员（op了就算了）.
默认：OP
