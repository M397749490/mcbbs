主要内容：多维数组
虽然用一维数组可以处理一般简单的数据，但是在实际应用中仍显不足，所以java也提供有二维数组以及多维数组供程序设计人员使用。
二维数组的使用：
二维数组的声明的方式与一维数组类似，一样用到 new 关键字。声明方式如下
  1. 数据类型 数组名[][] ;
  2. 数组名 = new 数据类型[行的个数][列的个数]
复制代码
如果想在声明时直接给数组赋值，可以利用大括号完成。只要在数组的声明格式后面再加上所赋的初值即可，如下格式
  1. int num[][] = {{12,45,21,45}{45,23,46,23}};
复制代码
语句中声明了一个整形数组num，数组有2行4列共8个元素，大括号里的几组初值会分别依序指定给各行里的元素存放，num[0][0]为23，
num[0][1]为45,···,num[1][3]为23 。
值得一提的是，java允许二维数组中每行的元素个数均不相同，这点与一般的程序语音不同。例如，下面的语句是声明整形数组num并赋初值，而初值的赋值指明了num具有三行元素，其中第1行有4个元素，第2行有3个元素，第3行则有5个元素
  1. int num[][] = {
  2. {42,54,34,49}
  3. {33,34,37}
  4. {12,34,56,99,74}
  5. };
复制代码


如何取得二维数组的行数与特定行的元素的个数？
若想取得整个数组的行数，或者是某行元素的个数，则可利用".length"来获取。其语法如下
  1. 数组名.length  //取得数组的行数
  2. 数组名[0].length  //取得数组特定行元素的个数
  3. 数组名[0][0].length //取得数组特定行元素的值

二维说完拉，之后就是多维拉，其实也没什么区别只要在声明数组的时候将索引与中括号再加一组即可，所以三维数组的声明为int a[][][],而四围数组为
int b[][][][],依此类推.
下面放一个三维数组的范例:

  1. public class Hduowei
  2.       {
  3.            public static void main(String args[])
  4.            {
  5.                   int i,j,k,sum=0;
  6.                   int A[][][]={{{5,1},{6,7}},{{9,4},{8,3}}};      //声明数组并赋初值
  7.                          //三维数组的输出需要采用三层for循环方式输出
  8.                    for(i=0;i<A.length;i++)
  9.                       for(j=0;j<A[i].length;j++)
  10.                          for(k=0;k<A[j].length;k++)
  11.                            {
  12.                                 System.out.print("A["+i+"]["+j+"]["+k+"]=");
  13.                                 System.out.println(A[i][j][k]);
  14.                     sum+=A[i][j][k];
  15.                   }
  16.           System.out.println("sum="+sum);
  17.        }
  18. }
