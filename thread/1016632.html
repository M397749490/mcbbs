如何编写一个可以保留注释的配置类

前言

  • 在开发过程中 配置文件是最常用的一个东西 大部分插件都需要配置文件
  • 但是很多新手开发会遇到一个问题
  • 编写好的默认配置文件 保存之后 配置文件的注释全部消失了
  • 那是因为yaml在保存的时候是不会保留注释的(除了头部的一个参数)

思路

深入研究

  • 我们既然要修改配置文件的保存 那么就得熟悉 Bukkit 使用的配置类
  • 我们先看一下 org.bukkit.configuration.file.YamlConfiguration
    public class YamlConfiguration extends FileConfiguration {
    
  // 省略代码
    
  @Override
    
  public void loadFromString(String contents) throws InvalidConfigurationException {
    
      // 省略代码
    
  }
    
  @Override
    
  public String saveToString() {
    
      // 省略代码
    
  }
    
}
  • 这里最核心的两个方法 loadFromString 和 saveToString
  • 顾名思义 这就是保存和读取的方法

处理逻辑

  • 既然要保留配置的注释 那么必然需要把注释保留到运行阶段
  • 如何将注释保留到运行阶段呐
  • 那就是把注释也变成配置项(清奇的思路来自神奇的白鲨七)
  • 比如下列配置文件(摘选自MiaoBind)
    #配置文件版本 请勿修改
    
Version: 1.2
    

    
#绑定标签处理
    
#检查操作 检索所有标签
    
#绑定操作 使用第一个标签
    
Tag:
    
  Bind:
    
  - '§6喵式绑定'
    
  - '§6灵魂绑定'
    
  - '§6SoulBound'
    
  # 时间绑定的标签
    
  TimeBind:
    
  - '§6到期时间'


读取配置的处理

置顶注释处理

  • 我们先处理简单的单行单节点置顶注释
    #配置文件版本 请勿修改
    
Version: 1.2
  • 处理成配置项之后
    '注释 #配置文件版本 请勿修改': 注释
    
Version: 1.2
  • 这样 Yaml 在处理的时候就会把注释当作节点处理 保存到配置存数上
  • 在 org.bukkit.configuration.MemorySection 的 protected final Map<String, Object> map = new LinkedHashMap<String, Object>();

非置顶注释处理

  • 接下来处理多行注释(忽略了无关内容)
    Tag:
    
# 时间绑定的标签
    
TimeBind:
    
- '§6到期时间'
  • 如果按照上面的逻辑 那么这个注释会变成
    Tag:
    
  Bind:
    
  - '§6喵式绑定'
    
'注释   # 时间绑定的标签': 注释
    
  TimeBind:
    
  - '§6到期时间'
  • 很明显 这样子会打乱配置文件的层级和内容
  • 所以这种注释需要特殊处理成
    Tag:
    
  Bind:
    
  - '§6喵式绑定'
    
  '注释   # 时间绑定的标签': 注释
    
  TimeBind:
    
  - '§6到期时间'


特殊字符处理

  • 假设有下列配置文件
    # 这是一个'神奇的.注释:
    
MagicConfig: 1.2
  • 如果按照原来的逻辑处理
    '注释 # 这是一个'神奇的.注释:': 注释
    
MagicConfig: 1.2
  • 很明显 他就不能解析了
  • 所以还要对特殊字符替换(一般来讲 只需要替换 '.: 这三个字符)
    • . 替换成 ．
    • ' 替换成 ＇
    • : 替换成 ：
  • 因为注释在运行时是看不到的 所以没啥关系
    '注释 # 这是一个＇神奇的．注释：': 注释
    
MagicConfig: 1.2


保存配置的处理

  • 保存配置之前 需要把配置节点 还原成注释
  • 这里我们简单讲一下 如何还原
  • 正则一把梭 ( *)(- )*('注释 )(#.*)(': 注释) 然后获取第四组的内容就好了
  • 嗯 没了
