Death Penalty
效果图
前言
       开启保留背包gamerule之后，玩家对死亡从不畏惧？是不是有玩家饿了干脆/suicide？死亡缺少惩罚？这款插件帮你解决玩家不在乎死亡的问题！
       开过Bukkit/Spigot/Cauldron端的腐竹一定都非常习惯了拾荒者插件，但是遗憾的是，在Sponge端并没有拾荒者死亡保护的移植版，而且类似的插件也似乎并不好用，于是我选择了这款死亡惩罚插件，虽然这款插件不能让玩家死后留有物品，但是，通过和/Gamerule KeepInventory True指令的配合，这款插件也能实现同拾荒者插件类似的功能，甚至这款插件允许你自定义玩家重生后的Buff效果。
插件特色
------------------
1.自定义惩罚类型   
2.扣除固定金币      
3.按百分比扣除金币
4.按百分比扣除经验
5.扣除固定经验      
------------------
安装方法

注：安装本插件前你需要一款经济管理相关的插件（例如这个或者这个）

将此插件移动到Sponge服务端的mods文件夹下

（请确保你是用的版本号是正确对应于SpongeAPI开发的）

指令
无

                text="0"
            }
            optional=true
        }
    }

        color=aqua

            {
                text=" 你失去了 "

                text="{moneyLoss}"

                text="经验值，死神对你施加了"

            {
                text="{potionEffects}"
            },
            {
                text="效果！"
            }

    }
    options {
        closeArg="}"
        openArg="{"
    }
}
# 以下方式的死亡将不会受到死亡惩罚。
