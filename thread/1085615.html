第一个物品

首先在你的mod包里面新建一个包（文件夹），就像这样：
src/main/java/com/XXX/XXX/XXX/item
然后在这个item文件夹里面新建一个类（你刚才右键没看到？），就像这样：
ItemTestItem
这个写法没有规定，只是我们一般都是用开头Item来表示这是个物品，后面的每个单词的首字母大写。（这样写着看得比较舒服，其他的写法有个拼写错误你就不觉得很难受吗）
ItemTestItem↑
然后我们要继承Item类，然后就可以开始写物品了
  1. public class ItemTestItem extends Item
  2. {
  3.     public ItemTestItem()

  5.     {
  6.         super();
  7.         this.setUnlocalizedName("testItem");
  8.     }
  9. }
复制代码

setUnlocalizedName是设置非本地化名称，这个是物品没有设置语言文本之前的名称（在游戏里面显示item.testItem.name，我们一般用驼峰式写法）
非本地化名称尽量使用小写驼峰式写法，即第一个词以小写字母开始，第二个词开始首字母大写，中间不使用任何符号分隔。——ustc_zzzz

然后你仔细观察会发现，这个ItemTestItem是灰色的，这表明它并没有生效，所以我们接下来要去注册它
在item包里面新建一个ItemLoader类
  1. public class ItemLoader
  2. {
  3.    public static Item testItem = new ItemTestItem();

  5.    public ItemLoader(FMLPreInitializationEvent event)
  6.    {
  7.        register(testItem, "test_item");
  8.    }

  10.    private static void register(Item item, String name)
  11.    {
  12.        GameRegistry.registerItem(item，name);
  13.    }
  14. }
复制代码

public static Item testItem = new ItemTestItem();是将一个物品实例化
register(testItem, "test_item");是将这个物品注册到FMLPreInitializationEvent中去，也就是在你加载mc的时候加载这个物品
GameRegistry.registerItem(item，name);这是注册物品的方法
实际上原本的写法是 GameRegistry.registerItem(item，item.getUnlocalizedName());偷懒它不香吗

如果你认真观察的话你会发现你的ItemLoader也是灰色的，这是因为你的ItemLoader也没有生效，所以我们应该在CommonProxy里面加上一句话
  1. public void preInit(FMLPreInitializationEvent event)
  2. {
  3.    new ItemLoader(event);
  4. }
复制代码

注意是在FMLPreInitializationEvent里面写
