重要的话写在前面

这个插件已经在mcbbs转过了，
这是原贴：http://www.mcbbs.net/forum.php?mod=viewthread&tid=428632&highlight=Color%2BPortals

但是它没有注明怎么使用这个传送门，

我在我的服务器上使用了一下，

发现比上古传送门好用很多，

于是我决定把这个插件的基本教程写给大家，

供各位小白和dalao使用。


作者原话:


Color Portals lets users create portals in game with little effort and no commands to type!
Using wool, a sign, a pressure plate, and a button, players can create their own portals!
Features:
  • No commands necessary to set up portals.
  • Portals link automatically. No running back and forth setting locations.
  • MultiVerse/MultiWorld compatible. Teleport between worlds with ease.
  • No permissions required. (But are supported)
  • No configuration required. (But many options are supported)
  • Plug and Play.

插件使用



这个插件只有四个[准确说是两个]指令


分别是：


/portal info 或 /cp info 看看你对面的这个传送门什么名字


/portal list 或 /cp list 查看有多少传送门在你的服务器


他怎么建造呢？




看见了吗？？？

它是由羊毛【必须是羊毛】木质按钮，石制踏板，木牌组合而成。


在木牌上写什么？？？


第一行：自定义名称【可以是传送的地方，比如我要去生存世界，我就写"生存世界"】

第二行：你的传送门编号【比如我没创建过传送门，我写"1"，然后相对的传送门我也要写"1"】

第三行【可以空着，也可以随便写，反正不显示】

第四行：相对的传送门编号【你要传送到的传送门编号，在相对的传送门编号不能和这个重复】

[编号都是数字！]



怎么传送？

踩在你设置的踏板上，然后点木质按钮，就"嗖~"



最后，下载地址

https://www.spigotmc.org/resources/color-portals.5546/
