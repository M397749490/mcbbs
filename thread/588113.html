你的隐私



英文君

This plugin contacts curse.com and checks for newer versions by using the Curse ServerMOD API. Opting out of this service can be done by editing config.yml and changing DisplayUpdateNotifications to false.

This plugin utilises Hidendra's plugin metrics system, which means that the following information is collected and sent to mcstats.org:

- A unique identifier
- The server's version of Java
- Whether the server is in offline or online mode
- The plugin's version
- The server's version
- The OS version/name and architecture
- The core count for the CPU
- The number of players online
- The Metrics version

Opting out of this service can be done by editing config.yml and changing MetricsOptOut to true.

中文君

这个插件使用Hidendra's管理系统，所以插件需要发送信息到Mcstats.org.....

  - 一个独一无二的标识符。

- 在正版模式还是在离线模式？

不想再让插件获取你的隐私了？这个可以。在 Config.yml 中的 MetricsOptPut，你可以调整这个功能。


我为什么要安装它？

- 它可以为你服务器上的玩家的马设定一个响亮的名字
- 也可以保护你服务器上VIP玩家那珍贵的、独一无二的马不被熊孩子Over
- 让马不会被其他人伤害
- 保护它不会被熊孩子释放
- 在你不需要/嫌弃它的时候，把它转让
- 把马出售
- 看看你有多少马
- 传送到你的马身旁，给它喂点好吃的
- 让它传送到你身边
- 在它身上放一个箱子

怎么玩？

开始你的MyHorse生活！
只需骑上您的马即可。
起个响亮的名字～
如果你要命名，请确保你有这权限后，输入 /myhorse name [名字] 即可。
这可是我的马！！
在默认情况下，只要您完成了“开始你的MyHorse生活”这一步，您的马就已经开启锁模式了。这时只有马的主人才能与马交互。
除非你想把你的马开放，这时使用命令 /myhorse unlock 解锁，当要上锁时，输入 /myhorse lock 。
过来，我的马～
如果你想让你的马传送到你那里，输入 /myhorse comehere 。
这匹马怎么了？
输入 /myhorse info 命令看看你的马的各项参数。
新的主人：xxxx
你不想要你的马了？嘿嘿，让你的基友变成它的主人！输入 /myhorse sepowner [新主人的名字] 即可！
走开，你这个没人要的家伙！！
如果你想让你的一匹马滚开或者你讨厌它了，就输入 /myhorse goaway 让它变成没人认领的孤马。
熊OP的救星！
如果你是OP或管理员，你可以通过 /myhorse spawn [normal（普通）/mule（驴）/undead（僵尸/亡灵马）/skeleton（骷髅马）] [baby] 来生成任何形式的马。

什么命令？

/myhorse 普通命令。
/myhorse name 给你的马一个名称。
/myhorse comehere 让你的马传送到你那里。
/myhorse goaway 快走开！
/myhorse list 展开马匹列表。
/myhorse goto 去你的马那里。
/myhorse setowner 设定马匹的主人。
/myhorse addfriend 设定马的朋友。
/myhorse removefriend 移除一个马的朋友。
/myhorse kill 杀死马。
/myhorse reload 重置插件。
/myhorse sell 出售马匹。
/myhorse claim跟别人装逼说我登上了我的马。*
/myhorse select选择你列表中的马。参见/myhorse list。
/myhorse spawn生成各种各样的马。
*标星号的部分是由于我看不懂此解释，只是勉强翻译了一下，有可能不是准确的～



权限

myhorse.*玩家可以做所有下面的事情。
myhorse.list玩家可以看到他拥有的马匹名单。
myhorse.goto 玩家可以传送到他的马匹上。
myhorse.comehere 玩家可以传送他自己的马到他身边。
myhorse.lock玩家可以上锁他的马。
myhorse.unlock玩家可以解锁他的马。
myhorse.name玩家可以给他的马一个名字。
myhorse.setowner玩家可以为他的马设定一个新主人。
myhorse.addfriend玩家可以添加一个自己马的朋友。
myhorse.removefriend玩家可以移除他的马的朋友。
myhorse.info玩家可以看到他的马的信息。
myhorse.buy玩家可以购买马。
myhorse.sell玩家可以卖他的马。
myhorse.goaway 玩家可以放弃他的马，也就是遗弃。
myhorse.kill玩家可以杀死他的马。
myhorse.claim 玩家可以在服务器中说“我已将我的马遗弃”
myhorse.select玩家可以选择一个他的马。
myhorse.help玩家将可以看到帮助页面(/myhorse help)
myhorse.bypass.mount玩家可以登上任意一个人的马，即使他不是主人。
myhorse.bypass.leash 玩家可以拆除一匹马的栓绳。
myhorse.bypass.inventory玩家可以看到任意一个人所拥有的马的名单 。
myhorse.admin玩家有所有Myhorse的权限。
myhorse.updates玩家可以得到插件更新通知。
myhorse.spawn玩家可以声称任意一个种类的马。
