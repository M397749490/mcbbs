教程：

  假设我们在多人模式下，多个玩家拿着各自的武器对其他生物进行攻击，我们需要分别探测每一个被攻击的实体，首先应该为各自的玩家准备不同的武器。
给不同的玩家贴上不同的标签：
玩家A
  1. /scoreboard players tag @p add a
复制代码
玩家B
  1. /scoreboard players tag @p add b
复制代码

再给a,b玩家不同的武器，武器对于探测被攻击的目标有决定性的作用
玩家A
  1. /give @p minecraft:stone_sword 1 0 {ench:[{id:20,lvl:2}]}
复制代码
玩家B
  1. /give @p minecraft:stone_sword 1 0 {ench:[{id:20,lvl:1}]}
复制代码

大家可以从上面的指令中发现：两把武器的火焰附加的等级不同，因为火焰附加的等级不同，所以对被攻击者的着火时间各不同，又因为着火时间不同，因此我们凭此可以判断出不同的被攻击者。
但是仍需要游戏指令辅助，减小误差。

创建积分榜“sword"用于探测玩家A使用石剑（以下玩家B的指令省略，与玩家A的同理）
  1. /scoreboard objectives add sword stat.useItem.minecraft.stone_sword
复制代码
创建积分榜“scope"用于探测玩家A攻击范围内的生物
  1. /scoreboard objectives add scope dummy
复制代码
创建积分榜“attacked"用于给”bytheattacker"积分榜加分并且处理一些还原工作
  1. /scoreboard objectives add attacked dummy
复制代码
创建积分榜“bytheattacker""用于显示被攻击的实体
  1. /scoreboard objectives add bytheattacker dummy
复制代码



给玩家攻击范围的生物加分：
  1. /execute @a[tag=a] ~ ~ ~ /scoreboard players set @e[tag=!a,r=4] scope 1
复制代码

探测被玩家用石剑攻击的实体:
  1. /execute @a[score_sword_min=1] ~ ~ ~ /scoreboard players set @e[score_scope_min=1] attacked 1 {Fire:160s}
复制代码
{Fire:160s}是被2级火焰附加的剑击中的着火时间

把被攻击的实体列上积分榜：
  1. /execute @e[score_attacked_min=1] ~ ~ ~ /scoreboard players set @e[score_attacked_min=1] bytheattacker 1
复制代码
  1. /scoreboard objectives setdisplay sidebar bytheattacker
复制代码

给被攻击的实体灭火：
  1. /execute @e[score_attacked_min=1] ~ ~ ~ /entitydata @e[score_attacked_min=1] {Fire:0s,Tags:["attacked"]}
复制代码
基本的还原工作，重复探测：
  1. /scoreboard players set @e[score_attacked_min=1] attacked 0 {Fire:0s}
复制代码
  1. /scoreboard players set @a sword 0
复制代码
