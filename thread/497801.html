标题: [修正][机械]NoFlyPvp——飞行管制防止不公平的PVP[1.7.10-1.8.X]
本帖最后由 1582952890 于 2017-9-17 06:57 编辑

这个插件能让飞行的时候不能PVP、破坏方块，禁止药水，倒水倒岩浆等等
对于一些开放VIP飞行的服来说可能有用，可以防止不公平的PVP
除非他们关掉飞行，或者和一样能飞行的玩家才能PVP
不知道会不会向下兼容，希望有能力的朋友测试一下1.1.4版兼容1.7.10

命令只有一个
/noflypvp reload 重载插件
权限


noflypvp.*                       给OP的，让OP可以使用所有指令不受插件影响
noflypvp.admin                   授予重新加载和更新通知
noflypvp.exempt.*                允许不受插件管理
noflypvp.exempt.blockbreak       允许飞行时打破方块
noflypvp.exempt.blockplace       允许飞行时放置方块
noflypvp.exempt.bowdamagemob    Grants Exemption For Shooting Mobs With A Bow While Flying)
noflypvp.exempt.bowdamageplayer Grants Exemption For Shooting Players With A Bow While Flying）
noflypvp.exempt.bowfire          Grants Exemption For Shooting A Bow While Flying
noflypvp.exempt.bucketempty      允许飞行时放桶(水、岩浆)
noflypvp.exempt.bucketfill       允许飞行时装桶(水、岩浆)
noflypvp.exempt.divebomb         Grants Exemption For Dropping When Damaged While Flying
noflypvp.exempt.pickupitem       允许在飞行时捡东西
noflypvp.exempt.potions          允许在飞行中使用药剂
noflypvp.exempt.pvp              允许飞行时攻击玩家



配置



settings:
    # Seconds To Wait Before The Same Message Is Sent To A Player
    msgtimeout: 5
    # 新版本通知是否启用
    updatecheck: true
    # 有新版本通知管理员
    notifyadmins: true
    block:
        # 阻止飞行中PVP
        pvp: true
        # 阻止飞行中使用药水
        potions: true
        # 阻止飞行中弓箭(这条启用时下面两条才会生效)
        bowfire: true
        # 阻止在飞行中射击玩家
        bowdamageplayer: false
        # 阻止在飞行中射击怪物
        bowdamagemob: false
        # 阻止飞行时打破方块
        blockbreak: true
        # 阻止飞行时放置方块
        blockplace: true
        # 阻止飞行时放桶
        bucketempty: true
        # 阻止飞行时装桶
        bucketfill: true
        # 阻止飞行时捡东西
        pickupitem: true
    pvp:
        # 打开关闭飞行时被人击中(不知道正不正确原文Turn Off Fly When Hit By A Player (Aka DiveBomb))
        disableflyonhit: false
        # Minimum Health To Leave A Player Whose Fly Was Turned Off
        fallminhealth: 1
        # 怪物对玩家造成伤害时，会关掉他们的飞翔
        mobdisablefly: false
    messages:
        # Messages Sent To Player
        # Warning Messages Are An Alert Of What They Are Not Allowed To Do
        # Disable Messages Are To Tell The Player They Must Disable Flying
        # To Continue What They Want To Do
        # If A Message Is Set To '' That Message Will Be Ignored And Not Sent
   pvp:

            warning: '&cYou Are Not Allowed To PVP While Fly Is Enabled'
            disable: '&cYou Must Disable Flying Or Your Opponent Must Enable Flying To Continue'
        potion:
            warning: '&cYou Are Not Allowed To Use Potions While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Use Potions Again'
        bowfire:
            warning: '&cYou Are Not Allowed To Shoot Bows While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Shoot Bows Again'
        bowdamageplayer:
            warning: '&cYou Are Not Allowed To Shoot Bows At Players While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Attack With Bows Again'
        bowdamagemob:
            warning: '&cYou Are Not Allowed To Shoot Bows At Mobs While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Attack With Bows Again'
        blockbreak:
            warning: '&cYou Are Not Allowed To Break Blocks While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Break Blocks Again'
        blockplace:
            warning: '&cYou Are Not Allowed To Place Blocks While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Place Blocks Again'
        bucketempty:
            warning: '&cYou Are Not Allowed To Empty Buckets While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Empty Buckets Again'
        bucketfill:
            warning: '&cYou Are Not Allowed To Fill Buckets While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Fill Buckets Again'
        pickupitem:
            warning: '&cYou Are Not Allowed To Pick Up Items While Flying Is Enabled'
            disable: '&cYou Must Disable Flying To Pick Up Items Again'

            warning: '&4MAYDAY. MAYDAY. MAYDAY. You Are Going Down!!!!
