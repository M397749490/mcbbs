怎么设置、
  1. # 自动AFK(Away From Keyboard,离开状态)
  2. # 以秒为单位,保持静止状态达到该时间,玩家将被自动设置为离开状态.
  3. # 需要玩家拥有 essentials.afk.auto 权限.
  4. # 设置为 -1 取消该功能.
  5. auto-afk: -1

  7. # 自动T出AFK状态下的玩家
  8. # 以秒为单位,AFK状态达到该时间,玩家将自动被服务器T出.
  9. # 拥有essentials.afk.kickexempt权限的玩家无视此设置.
  10. # 设置为 -1 取消该功能.
  11. auto-afk-kick: -1

  13. # 设置为true,如果你想要冻结AFK状态下的玩家.
  14. # 其他玩家和怪物将无法推动或攻击他.
  15. # 这将会使AFK的玩家进入无敌模式.
  16. # 玩家需要使用"/afk"命令来退出AFK状态.
  17. freeze-afk-players: false

  19. # 当玩家AFK状态时,是否允许玩家捡取物品?
  20. # 启用这个功能,当你不希望有人在刷怪塔挂机刷物品.
  21. disable-item-pickup-while-afk: true

  23. # 这个设置控制当一个玩家交互时解除afk状态
  24. # 如果设为false,将只能使用/afk来取消离开状态
  25. cancel-afk-on-interact: true

  27. # 当玩家移动时是否解除他的AFK状态?
  28. # 当玩家聊天或使用命令时,玩家将自动解除AFK状态,无视这个设置
  29. # 禁用这个选项可以减少服务器延迟
  30. cancel-afk-on-move: false
