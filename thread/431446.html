反熊小技巧

创建一个领地 用木锄头点击两个点，注意这两个点是立体的。
输入/res create 名字 (如：/res create yuyu 请注意你的钱数)
然后在领地内输入 /res set 领地名字 move false
然后你就可以给你基友加权限了 命令：/res pset [你基友的id] trusted t

LWC锁使用教程
对锁上的东西左键
然后输入/cprivate [你基友的id]
好了 现在他有权限了。
