你可能需要这个插件ScriptBlock
新玩家进入游客权限组的路径为/plugins/GroupManager/worlds/world/groups.ym
groups:
  default:
    default: false     ←这里设置为true，其他权限组设置false，这样新玩家进入就是在default组

使用命令方块的方法

你可以给default组一个**方块的交互权限，命令 /mangaddp default essentials.build.interact.** (**指方块ID)
最后在命令方块里输入 manuadd @p builder   ( 命令方块可以不输入''/' ) ( builder为你想要给通过的玩家所在的权限组 )
使用插件的方法
你也可以用ScriptBlock来代替考题的方块的交互，只要给这两个权限就可以了，命令 /mangaddp default ***

  2. <p><font color="#8b0000">scriptblock.interact.use <font color="#006400">- 授予玩家使用点击触发方块的权限(不包括建立) - 给玩家授予这两条就可以</font>
  3. <font color="#8b0000">scriptblock.walk.use </font><font color="#006400">- 踩踏 同上</font><font color="#006400"></font></font></p>
  4. <font color="darkred">最后设置一个通过的方块指令为：</font>
复制代码
/sbinteract create [@group:default][@bypass /manuadd <player> builder]    ( builder为你想要给通过的玩家所在的权限组 )
