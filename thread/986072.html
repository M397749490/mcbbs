二：服务端配置文件简单教程
这里是简单配置教程！
折叠在此


sever文件配置
---------------------------------------------
#Minecraft server properties
#Fri Mar 20 19:28:33 CST 2020
......
server-port=25565#服务端口
......
level-seed=#地图种子
......
server-ip=#服务端指向IP
.....
max-build-height=256#最大建筑高度
spawn-npcs=true#是否生成NPC
white-list=false#是否开启白名单
spawn-animals=true#是否生成生物
......
online-mode=true#是否开启正版验证
（开启正版验证后无法使用盗版登录）
......
pvp=true#是否可以PVP
......
difficulty=1#游戏难度
......
gamemode=0#游戏模式
max-players=20#最多玩家人数
spawn-monsters=true#生成怪物
......
-------------------------------------------
（因为篇幅有限，在这里不一一列举）
需要使用地图种子的把“world”“world_nether”“world_the_end”三个文件夹删去。然后在level-seed=里面填上种子即可。

四：核心文件使用教程
我们这里用1.12.2举例：
把你下载的核心文件（.jar）放在一个文件夹内，
然后新建一个文本文档，在里面写：
--------------------------------------------------
@echo off
java -Xms2g -Xmx2g -jar Paper-1.12.2-b1618.jar
pause
----------------------------------------
（绿字部分改成你自己的核心文件名）
然后另存为.bat文件，
双击启动；

第一次它会暂停一次
