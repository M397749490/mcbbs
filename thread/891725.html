标题: rpgitem类：怎样做到跨世界传送
怎么样用rpgitem做跨世界传送.
详细点就是用rpgitem做出传送卷 右键可以跨越到其他世界{多世界插件创造的世界}
作者: GodLion    时间: 2019-7-26 05:09
powers:
      '0':
        powerName: command
        cooldown: 100  #冷却时间，20tick一秒
        command: mv tp {player} 世界名字
        display: ''   #描述
        isRight: true
        permission: '*'
        consumption: 0
添加以上技能到物品即可右键使用
作者: 南京扛把子    时间: 2019-7-26 06:53
