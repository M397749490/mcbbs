第四篇，我们来说一下在1.12.2原版做到检测右键的几种方法。

一.萝卜钓竿
这种方法是最广为人知的，即使用计分板配合特殊Tag，来做到检测右键特定萝卜钓竿。上命令：

#1.give @s minecraft:carrot_on_a_stick 1 0 {Tags:["SMFX001"]}
这条命令是给玩家一个特定的钓鱼竿，“SMFX001”可替换为其他文本。

#2.scoreboard objectives add SMFX001 stat.useItem.minecraft.carrot_on_a_stick
创建一个使用萝卜钓竿的计分板，若玩家右键萝卜钓竿，这个计分板就会增加1分

#3.scoreboard players tag @a add SMFX001 {SelectedItem:{tag:{Tags:["SMFX001"]}}}
此命令需要高频执行。这条命令是给手持特定标签的玩家一个tag，用来标记玩家。

#4.execute @a[tag=SMFX001,score_SMFX001_min=1] ~ ~ ~ xxxxx
此命令需要高频执行。这条命令是当玩家右键特定钓竿，则....，后面可以输入你想输的命令

#5.scoreboard players tag @a remove SMFX001
此命令需要高频执行。这条命令是清除玩家的tag，即防止玩家右键其他钓竿而触发命令。

#6.scoreboard players set @a SMFX001 0
此命令需要高频执行。这条命令是清0玩家的使用钓竿计分板，使右键可以不止一次检测。

注意：4、5、6命令需在3命令后方，若为命令方块，则设置为保持开启、不受限制、连锁，若为function，则请按顺序输入。


以上就是通过钓竿来检测右键。还有一种比较方便的方法是通过隐身村民。


二.隐身村民
这种方法不需要玩家持有特定的物品，但缺点是两个右键之间不能隔太近。上命令：

#1.summon minecraft:villager ~ ~ ~ {ActiveEffects:[{Id:14,Amplifier:0,Duration:20000000,ShowParticles:0b}],PersistenceRequired:1b,Tags:["SMFX002"],Offers:{Recipes:[]}}
这条命令是在特定位置召唤一只隐身村民，隐身村民甚至连旁观者模式都看不见，所以不用担心不美观；并且该村民没有兑换，所以不会弹出GUI界面。

#2.scoreboard objectives add SMFX002 stat.talkedToVillager
这条命令是创建一个与村民互动的计分板，当玩家右键村民就会加一分。

#3.execute @a[score_SMFX002_min=1,r=5] ~ ~ ~ execute @e[tag=SMFX002] ~ ~ ~ xxxxx
此命令需要高频执行。这条命令是当玩家右键某特定区域内的村民，则xxxx

#4.scoreboard players set @a SMFX002 0
此命令需要高频执行。这条命令是清0玩家的计分板，使右键可以不止一次检测。

注意：3、4命令需在2命令后，若为命令方块，则设置为保持开启、不受限制、连锁，若为function，则请按顺序输入。

以上就是两种常见的检测右键的方法，当然还有像弹射物、燃料、右键使用的物品等等等等，这里就不多介绍，基本思路还是计分板。

方法：计分板（应该是最简单的一种方法）
思路：生成一个Marker，创建一个计分板，以所有实体的名义给他加分
操作：
#1.创建一个计分板。
scoreboard objectives add SMFX050 dummy

#2.在一个始终能加载的地方生成一个Marker，此处我试着药水云不好，可能会消失（也可能是我玩的时间太长了..）
summon minecraft:armor_stand ~ ~ ~ {PersistenceRequired:1b,Invisible:1b,Tags:["SMFX050"]}

#3.以所有实体的名义给它加分（此处为了精准，可以用多个execute不同type选择指定类型）。此命令需要高频执行。
execute @e[type=!item,tag=!SMFX050] ~ ~ ~ scoreboard players add @e[c=1,type=armor_stand,tag=SMFX050] SMFX050 1

#4.若大于某分数，比如256，则清除实体。此命令需要高频执行。
execute @e[c=1,type=armor_stand,tag=SMFX050,score_SMFX050_min=256] ~ ~ ~ kill @e[type=!player,tag=!SMFX050]

#5.设置计分板为0分。方便实时监测。此命令需要高频执行。
scoreboard players set @e[c=1,type=armor_stand,tag=SMFX050] SMFX050 0


就是以上。
这个东西对于很多RPG地图很有帮助，可以优化地图，使玩家游玩更为流畅。
