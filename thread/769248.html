所以你的版本去哪了，默认1.12了
首先你并不需要像1楼那样弄得那么复杂，

表示楼上辛苦了，

实际上每种矿石只需要两条命令(见下面)

mc里一共只有两种挖了会掉矿石的矿(吧)，金矿和铁矿，

铁矿比较常见，拿铁矿为例

像这样摆一串命令方块，全部为保持开启



从左到右的命令为

  1. scoreboard players tag @e[tag=!iron] add iron {Item:{id:"minecraft:iron_ore"}}
复制代码

给铁矿掉落物添加自定义标签:iron

  1. entitydata @e[tag=iron] {Item:{id:"minecraft:iron_ingot"},Tags:[]}
复制代码


把有iron标签的物品变成铁锭，并把标签清掉

完事
解释一下:
你不需要检测附近有没有玩家挖掉了矿石，因为正常的生存能见到矿石的情况只有玩家把矿石挖下来，
不需要新生成再kill，一条命令可以同时做到把矿石变锭和清除标签，
你不要那用个比较器，因为那样不支持多人还有延迟
下面是挖金子掉锭的命令

  1. scoreboard players tag @e[tag=!iron] add iron {Item:{id:"minecraft:gold_ore"}}
复制代码
  1. entitydata @e[tag=iron] {Item:{id:"minecraft:gold_ingot"},Tags:[]}
复制代码

本回答只支持铁,金矿,请酌情添加其他矿
首先给能挖矿掉锭的人一个tag

  1. scoreboard players tag 挖矿直接掉锭的人 add tag名字
复制代码
然后计分板
  1. scoreboard objectives add mine_iron_ore stat.mineBlock.minecraft.iron_ore
复制代码
  1. scoreboard objectives add mine_gold_ore stat.mineBlock.minecraft.gold_ore
复制代码

函数版(1.12+可用),函数教程请看这里:
高频(glf)函数:
  1. scoreboard players tag @e[type=item] add iron_ore {Item:{id:"minecraft:iron_ore"}}
  2. scoreboard players tag @e[type=item] add gold_ore {Item:{id:"minecraft:gold_ore"}}
  3. execute @e[tag=iron_ore] ~ ~ ~ execute @a[tag=tag名字,r=5,score_mine_iron_ore_min=1] ~ ~ ~ function 命名空间:iron_ore
  4. execute @e[tag=gold_ore] ~ ~ ~ execute @a[tag=tag名字,r=5,score_mine_gold_ore_min=1] ~ ~ ~ function 命名空间:gold_ore
复制代码
在同一命名空间新建一个名字为iron_ore的函数:
  1. execute @e[tag=iron_ore] ~ ~ ~ summon item ~ ~ ~ {Item:{Count:1,id:iron_ingot}}
  2. kill @e[tag=iron_ore]
  3. scoreboard players set @e[tag=iron_ore] mine_iron_ore 0
复制代码
类似的,建一个名字为gold_ore的函数:
  1. execute @e[tag=gold_ore] ~ ~ ~ summon item ~ ~ ~ {Item:{Count:1,id:gold_ingot}}
  2. kill @e[tag=gold_ore]
  3. scoreboard players set @e[tag=gold_ore] mine_gold_ore 0
复制代码
