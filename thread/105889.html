这插件的用途嘛... 就是把“XXX join/left the game. ”改成自己想要的信息。当然不止这些，往下看介绍吧。

简介

  • 自定义加入消息
  • 自定义离开消息
  • 自定义组加入消息
  • 自定义组离开消息
  • 自定义单独玩家加入消息
  • 自定义单独玩家离开消息
  • 游戏中编辑消息，修改即生效
  • 支持组/玩家的前后缀
  • 可无声无息的加入和离开
  • 支持字体和颜色
    * 需要 Vault ！


指令
指令描述
/jm ? <页>显示帮助
/jm help <页>显示帮助
/jm set [join/quit] [消息]设置全局加入/离开消息
/jm group [组] set [join/quit] [消息]设置组加入/离开消息
/jm group [组] prefix [前缀内容]设置组前缀
/jm group [组] suffix [后缀内容]设置组后缀
/jm player [玩家] set [join/quit] [消息]设置玩家加入/离开消息
/jm player [玩家] prefix [前缀内容]设置玩家前缀
/jm player [玩家] suffix [后缀内容]设置玩家后缀
/jm info显示插件信息
/jm reload重载配置
[] = 必填 | <> = 选填


权限
权限默认使用者描述
jm.helpOp允许使用 "/jm help" and "/jm ?".
jm.setOp允许使用 所有 "/jm set" commands.
jm.set.groupOp允许使用 所有 "/jm group" commands.
jm.set.playerOp允许使用 所有 "/jm player" commands.
jm.infoOp允许使用 "/jm info".
jm.reloadOp允许使用 /jm reload.
jm.silent没人能用给予 jm.silentjoin 和 jm.silentquit 权限
jm.silentjoin没人能用允许玩家悄无声息的加入
jm.silentquit没人能用允许玩家悄无声息的离开
注：所谓没人能用是指有该权限的玩家才能这样
