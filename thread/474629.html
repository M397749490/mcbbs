所以说，这个插件在某些意义上可以共享一些数据。这个插件属于工具类型的。不需要什么图也没有指令，会自动删除（一些无用数据）
最重要的前缀（前置）插件：ProtocolLib


一个轻量级插件，可以帮助你清理许多的MYSQL的一些别的插件的信息。

清除游戏账号干什么呢？游戏账号会占用一定服务器的空间，可能会对一下低配的服务器造成一些影响。比如卡顿什么的。所以这个效果还是有一定优化服务端的效果的，各位服主可以考虑下载安装到自己服务器区使用

  12. databaseName: 'mydatabase'
  13. #Tables name (the plugin will auto create it)
  14. tableName: 'meb_inventory'

  20. maintenance:
  21. #Enable or disable database maintenance. | (true or false)
  22. enabled: false
