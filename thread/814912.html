这是不全面的，你提到的内容会影响核弹和核反应堆的爆炸威力，实际上，在1.12.2所有机械在电压过载的情况下都会爆炸，如果想防止工业的机械因为电压问题爆炸，应该改这里：
  1. ; If you really really really don't want to have your machines explode if you don't pay attention to voltage, you can disable that here.
  2. enableEnetExplosions = true
  3. ; Same for cable meltdown
  4. enableEnetCableMeltdown = true
复制代码

其中“enableEnetExplosions”的值改为“false”可以防止电压爆炸；
“enableEnetCableMeltdown”的值设置为“false”可以防止电流过大烧毁导线

补：如果想禁用核弹的话，请将“enableNuke”设置为false（这可以让服务器在启动时不注册核弹方块）
