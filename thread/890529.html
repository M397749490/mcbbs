McLottery 是一款自定义性比较强的插件
支持创建多个宝箱；自定义概率；抽奖TITLE显示；MESSAGE显示；自定义钥匙；且支持Mysql；PlaceholderAPI变量
关于 McLottery 未来计划
1.Mysql支持 √ 已实现
2.支持变量 √ 已实现
3.抽奖TITLE显示 √ 已实现
4.抽奖粒子动画
5.如果有其他想法可以私信与我反馈
McLottery 图示 与 视频

McLottery 指令 与 变量
/ml reload -重载插件配置
/ml edit <give/set/take> <playername> <lotteryname> <value> -修改玩家钥匙数量
/ml clear <lotteryname> -清除宝箱的位置
/ml set <lotteryname> -设置宝箱位置
/ml info -查询自己拥有的钥匙数量
/ml list -查看所有宝箱

%ml_宝箱名字% 显示该宝箱钥匙的数量

创建宝箱教程：
1.在Config文件夹配置宝箱的相关配置，假设我们的宝箱命名为"地阶宝箱"
2.放置一个方块，输入命令：/ml set 地阶宝箱，开生存模式左键该方块，宝箱设置成功！
可以参考下方的Config配置，但是不要直接复制到服务器内使用！
