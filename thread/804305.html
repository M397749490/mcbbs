作者: 游侠崔斯特    时间: 2018-7-9 08:36
配置文件木牌存档里可以这样改，也有指令可以添加，你要给添加对应的权限
commands:
  '0':
    command: /give <player> XXX
    type: PLAYER_COMMAND
    delay: 0
    grantPerms: []
    alwaysPersisted: false
    interactValue: 0
grantPermissions:
- XXX.*
这里的XXX.*权限就是执行某个指令需要的权限  你移除玩家权限让玩家点牌子。那这个牌子的权限自然要添加权限组相关权限
