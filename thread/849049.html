标题: [安全]ServerRestorer——轻松备份和恢复服务器支持FTP[1.7-1.15]
本帖最后由 白可乐 于 2021-2-8 13:55 编辑



特征：
  • 备份完整的服务器目录，包括插件，世界和配置/属性文件。
  • 压缩备份。可以将文件减小到1/4的大小。
  • 包括自动计划的备份。备份时间可以配置
  • 备份时，服务器将不会关闭
  • 快速备份：保存服务器可能需要不到一分钟的时间。
  • 支持FTP：将备份上传到家用电脑
  • 备份限制：如果空间有限，则可以配置对存储备份数量的限制。
  • 此插件将不断更新
  • 支持面板服，目前只在IC家的服务器测试过，完全兼容，其他面板请咨询面板商


删除无用的文件：
ServerRestorer内置了过滤器，以确保您没有保存无用的文件。如日志文件（其大小可以是控制台垃圾邮件的大小）以及无法更改的server.jar文件等文件不包含在备份中。如果由于某种原因希望将这些文件存储在备份中，则始终可以在配置中启用serverjar备份。

FTP：
ServerRestorer支持FTP！您现在可以将备份直接从服务器传输到您的家庭计算机或另一台服务器。

恢复：
服务端根目录下的Backup文件夹中就是保存备份的文件，在恢复之前，只需要将服务器关闭，并且将Backup文件夹中的ZIP包中所有文件复制到服务器目录中即可恢复服务器。

命令：
  • /sr save - 强制保存
  • /sr enableAutoSaver [时间] - 更改自动保存的时间（时间1S为1秒，1H为1小时，1D为1天，测试1S无效）
  • /sr disableAutoSaver - 禁用自动备份服务器，改为手动备份。

权限：
  • serverrestorer.*  - 包含下面的所有权限
  • serverrestorer.save  - 允许用户访问/sr save - 强制保存命令

本插件使用bStats进行信息收集

配置文件：
  1. # 保存路径
  2. getBackupFileDirectory: 'e:\Backup\PokeBC\3-shengcun'
  3. # 是否保存服务器jar
  4. saveServerJar: true
  5. # 是否保存插件jar
  6. savePluginJars: true
  7. # 自动保存时间
  8. AutosaveDelay: 3D
  9. # 最后保存时间
  10. LastAutosave: 1612366278246
  11. # 开启自动保存
  12. enableautoSaving: true
  13. # 保存的格式名称
  14. FileNameFormat: Backup-%date%
  15. # 插件前缀
  16. prefix: '&6[&3ServerRestorer&6]&8'
  17. # 被提出提示
  18. kickMessage: '&6[&3ServerRestorer&6]&8 服务器还原到以前的版本，请稍后重新加入'
  19. # 是否开启ftp保存
  20. EnableFTP: false
  21. # 是否开启ftps
  22. EnableFTPS: false
  23. # 是否开启sftp
  24. EnableSFTP: false
  25. # ftp地址
  26. FTPAdress: www.example.com
  27. # ftp端口
  28. FTPPort: 80
  29. # ftp用户名
  30. FTPUsername: User
  31. # ftp密码
  32. FTPPassword: password
  33. # 压缩等级
  34. CompressionLevel_Max_9: 9
  35. # ftp保存路径
  36. FTP_Directory: ''
  37. # 不保存内容
  38. exceptions:
  39. - logs
  40. - crash-reports
  41. - backups
  42. - dynmap
  43. - pixelprinter
  44. - backups
  45. # 最大压缩包
  46. MaxSaveSize: 10G
  47. # 最大文件储存数量
  48. MaxFileSaved: 1000
  49. # 删除ftp上的备份文件
  50. DeleteZipOnFTPTransfer: false
  51. # 删除本地保存的备份
  52. DeleteZipIfFailed: false
