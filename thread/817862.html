一次性执行
scoreboard objectives add time dummy

计时开始执行
scoreboard players set $timer time 0

计时中执行（用循环型命令方块，每秒执行 20 次的那种）
scoreboard players add $timer time 1

计时结束只需要停止上面那个循环型命令方块就行了。$timer 的 time 分数就是计时以后经过的游戏刻数，除以 20 就大致是秒数了（受游戏卡顿影响）。

这么做是有上限的，最多能计 3.4 年多，所以就当它没有上限就好啦。
