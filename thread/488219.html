Fifth 配置文件:

（为什么作者要如此狗血用心呢？）
  1. # PingTab v1.3.1
  2. # AutoUpdate: 启用/禁止更新检查
  3. AutoUpdate: true
  4. # AutoDownloadUpdate: 启用/禁止自动更新，启用后会通知你更新新版本（如果不想被吵的话就禁止）
  5. AutoDownloadUpdate: false
  6. # Interval: 设置刷新Ping（延迟）的频率，时间单位:秒
  7. Interval: 3
  8. # DisableTab: 禁用插件标签部分
  9. DisableTab: false
  10. # ShowPluginNameOnMessages: 在聊天框和控制台展示插件的名字（作者的宣传~）
  11. ShowPluginNameOnMessages: false
  12. # ColoredPingParameter: Make the %ping parameter on messages to be automatically
  13. #                       colored based on it's value.  
  14. ColoredPingParameter: true
  15. # GoodPing: Pings below this number will be printed as green in the /ping command.
  16. GoodPing: 200
  17. # MediumPing: Pings below this number will be printed as gold in the /ping command.
  18. #             If the ping gets over this number, it will be printed in red .
  19. MediumPing: 500
  20. # OwnPingMessage: Message that is sent to the player when he check it's own
  21. #                 ping with /ping. Color codes are supported using & character.
  22. #                 Parameters: %ping - Ping Measured
  23. OwnPingMessage: "Your ping is %ping ms"
  24. # PingMessage: Message that is sent to player when he check anothe player's
  25. #              ping with /ping. Color codes are supported using & character.
  26. #              Parameters: %playername - Player Name
  27. #                          %ping - Ping Measured
  28. PingMessage: "%playername's ping is %ping ms"
  29. # AlertPlayers: Ping值高的玩家系统会警报 (默认: true)
  30. AlertPlayers: true
  31. # AlertThreshold:Ping一样的玩家将会被提醒
  32. AlertThreshold: 1000
  33. # AlertInterval: 设置发送警告的频率，时间单位:分
  34. AlertInterval: 5
  35. # AlertMessage: 发送这条警告消息给玩家
  36. #              支持使用&1-F，就是颜色代码
  37. #               Parameters: %playername - 玩家名字
  38. #                           %ping - 延迟
  39. #                           %threshold - Threshold Set
  40. AlertMessage: "%playername,你的 %ping 延迟太高了！"
