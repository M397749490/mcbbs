额，，我要开启喷口水模式了{:10_512:}
假设你的VIP世界为VIP
打开/plugins/GroupManager/config.yml
看到 mirrors:       下面
改成
        world:
          world_nether:
          - users
          - groups
          world_the_end:
          - users
          - groups
          all_unnamed_worlds:
          - users
          - groups
        VIP:
          VIP:
          - users
          - groups
保存，然后打开worlds文件夹，新建一个VIP的文件夹，把world的groups.yml复制进去，修改一下，重启
P.S  最好将VIP世界的除了你要弄成的权限组，其他的权限组都删掉，防止玩家把自己加入到admin权限组
P.P.S 一定要对齐，不然会报错
