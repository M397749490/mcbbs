推荐人海绵端推荐插件命令：

[td]
命令
用法
例
别名
/referrals主命令，显示帮助菜单/referrals没有
/referrals top [#]用于列出服务器上的玩家邀请玩家数量排行，如果未提供数字，则默认为前10名/referrals top 10/referrals top/t
/referrals check [name]用于列出指定玩家所邀请的玩家数量，如果未列出名称，则默认为查询自身邀请玩家数量。/referrals check BranFlakes/referrals check/chk
/referrals thanks [name]感谢某位玩家邀请你加入某服务器/referrals thanks BranFlakes/referrals thanks/thank
/referrals help显示所有命令用法的基本帮助命令/referrals help/referrals help/h
权限：[td]
允许
描述
referrals.check允许用户使用check命令
referrals.check.self允许用户对自己使用check命令
referrals.check.other允许用户对其他人使用check命令
referrals.top允许用户查看服务器上的邀请人数排行

配置：
#设置命令以发放奖励
  rewardActions {  
  # 设置命令需要在邀请成功的基础上完成\  
  # 在命令中不要使用'/'  
  # %p = player name  
  # 例如下
  referrerRewardCommand = "msg %p Thanks for using Referrals!"  
  referredRewardCommand = "msg %p Thanks for using Referrals!"
}
  # 设置邀请人或被邀请人是否获得邀请奖励
  rewardPlayers {
    # 如果是true, 玩家将获得相应的邀请奖励  
    # referrer为邀请人 referred为被邀请人  (如果二者均为true，邀请人和被邀请人均获得奖励)  
    referrer = true  
    referred = true
}
