【简介】
Heroes是一款集技能、职业、组队等功能为一体的强大RPG插件。超高的自由度，完整强大的功能曾让他风靡一时
MCBBS中此插件的配置与教程已经过于古老，所以我这次撸一篇教程粗来，希望更多人学会这款强大的插件
【安装方法/下载地址】
  • Heroes 1.5.5.7 （1.8.1）
  • 1.5.5.5 （1.8.1）
  • Heroes 1.5.5.4 with skills （1.7.9含技能包）
  • Heroes 1.5.5.4 （1.7.9）
  • Heroes 1.5.5.3 for 1.7.9 only （1.7.9）
前置：Vault
直接将此文件放入:plugins文件夹







【指令】

一般指令：
/hero   - 查询插件所有指令
/bind <技能名>  - 将技能绑定在当前持有的物品上，然后可以右键使用技能

/level 或者/hero level或者/lvl   - 查看当前等级信息

/mana   - 查看自己当前的魔力

/cooldowns或者/cd   - 查看当前技能的冷却时间

/health或是/hp   - 查看当前血量

/hero leaderboard   - 查看玩家等级排行

查询技能：
/skills或者/skilllist   - 查询可用技能
/skill <skill><args>   - 查看技能参数
队伍指令：
/party invite <player>   - 邀请玩家进入队伍

/party accpt <player>   - 准许玩家加入队伍

/party leave   - 离开队伍

/p <message> 或是 /party <message>   - 队伍私聊

/party mode [pvp:exp]   - 队伍PVP经验共享

/party ui  -团队GUI图？

/party who   - 查看队伍里有什么人

职业设定：
/hero admin class <玩家> <职业>   - 设定玩家职业
/hero admin prof <玩家> <职业>   - 设定玩家副职业

/hero admin exp <玩家> <职业> <经验值>   - 给与玩家某职业经验值

/hero admin level <玩家> <职业> <等级>   - 设定玩家某职业的等级

/hero admin heal <玩家>   - 治疗玩家

/hero admin hp <玩家> <治疗量>   - 给予玩家血量

/hero admin reload  - 重新读取heroes插件

/hero admin saveall   - 存储heroes插件

/hero debug dump   - 将heroes插件的debug文件清空

转职指令：
/hero chooes [现在的主职业] [要转职成的主职业]
/hero chooes [现在的副职业] [要转职成的副职业]
【配置文件】


注意：1、当你在一个选项后的数据是个数字时，记得要打一个空格。2、每一行不要有多余的空格。3、当你配置出错的时候，配置文件会还原
我们先来简单的了解一下各个配置文件是干什么用的，其中比较复杂的技能制作和职业制作的教程将会在后面教给大
当你打开heroes的配置文件夹时会有如下几个文件
[skills（文件夹）]
此文件夹是用以 储存技能的文件，一般为.jar文件，这些文件是游戏中的技能执行文件，然而我并不是很会。这里一般不需要编辑
[classes（文件夹）]
此文件夹是用以储存职业配置文件的，点开之后会有如下文件：
Admin.yml couge.yml mage.yml
这几个文件是各自的职业配置，我们在后面会仔细讲
[player(文件夹)]
用于储存玩家数据
[storage(文件夹)]
迷
[skils.yml]
这个配置文件是用于设置使用技能和技能结束时的提示语。先看个技能：
One:
  use-text: "\xa77[\xa72\u6280\u80fd\xa77] %hero% \u4f7f\u7528\u4e86 %skill% \u6280\
    \u80fd!"
  speed-multiplier: 2
  duration: 15000
  apply-text: "%hero% \u7684\u901f\u5ea6\u53d8\u5feb\u4e86!"
  expire-text: "%hero% \u6062\u590d\u4e86\u666e\u901a\u901f\u5ea6!"
其中，one 是指一个叫做“one”的技能，后面就是具体的提示语设置。
"use-text:"之后就是指当你使用这个叫做“one”的技能后，就会出现后面双印号之中的提示语
“apply-text:”是指当此技能开始生效时的提示语，同样是在双印号内
“ expire-text: ” 这个是指技能结束的提示语，其他同上
%hero% 是一个变量，指使用这个技能的玩家名。%skill% 是指玩家使用的技能名
其他的技能提示语同理
[damages.yml]
这个配置文件是用于设怪物血量，怪物血量，物品或者剑的伤害等的设置。
creature-health:  ←生物血量设置
    Chicken: 4    ←鸡：4滴血
    Cow: 10  ←牛：10滴血

    Creeper: 20  ←苦力帕： 20滴血
    ·······
creature-damage:  ←生物伤害
    Creeper: 49  ←苦力帕：49
    PigZombie: 5  ←僵尸猪人：5
    Zombie: 4  ←僵尸： 4
    ·····
item-damage:  ←手中持有物品的伤害

    Air: 2  ←空气:2(空手撸别人)
enchantment-damage:  ←魔法伤害（好像没用···）
    THORNS: 1
    DAMAGE_ALL: 1
    DAMAGE_UNDEAD: 1
   ····
[recipes.yml]
用于各类物品的等级限制
如：
swords:   ←物品限制的类别
  level: 5  ←使用等级要求
  items:
    - '276','267'   ←到达指定等级后可用物品
这是什么意思呢？指的就是当你的等级到达了5级之后才可以使用物品Id为“276”和‘267’的物品。
其他的类别同理
[config.yml]
插件总设置：
leveling:
  exp-curve: 1.0  ←经验曲线
  max-exp: 100000  ←升级最大经验值
  max-level: 50  ←最大等级
  pad-max-level: true  ←迷
  exp-loss: 0.1  ←经验丢失率
  pvp-exp-loss: 1.0  ←与玩家战斗经验丢失率
  max-party-size: 6  ←最大组队成员数
  party-exp-bonus: 1.0  ←组队经验加成
  level-loss: false  ←等级下降
  mastery-loss: false  ←熟练度丢失？
  spawner-checks: false  ←咸鱼检查？
  spawner-exp-mult: 0.5  ←咸鱼····？
  reset-on-death: false  ←
  pvp-range: 50  ←战斗范围
  min-pvp-level: 1  ←最小PVP等级
  pvp-exp-range: 10  ←PVP经验范围
  pvp-max-exp-range: 40  ←PVP最大经验值范围
  dump-exp-file: false  
其他的最好是自行百度翻译，因为如果都翻译好了，那么对你们的学习能力的提升是没多大好处的（LZZZ不会翻译）

heroes自带有四个职业，这里面的每一个XXX.yml文件都是一个职业的配置文件
我们要设置职业的是此职业的技能，各种物品的伤害，血量等
先来看一个，mage.yml
这是一个叫做mage的职业，我们看看它的配置文件：
[spoiler]

name: Mage   ←职业名字
default: false  ←默认（这个千万别设置成true）
parents:  默认
    strong: []
    weak: []
primary: true  默认
secondary: false  默认
description: Ranged Disable with LeatherArmor and Icebolt 默认
permitted-armor:  ←可以使用的远程物品
- ALL    ←所有（我设置过，推荐设置成所有）
permitted-weapon:  ←可以使用的武器
- ALL  ←所有（我设置过，推荐设置成所有）
item-damage:  ←物品伤害
item-damage-level:  物品伤害等级
projectile-damage:  远程物品伤害
projectile-damage-level:  远程物品伤害等级
permitted-skills:  可以使用的技能
    Enchant:  （技能名，以下的类似）
        level: 1  
        mana: 50
    Mark:
        level: 5
        mana: 5
        reagent: BED
        reagent-cost: 1
···中间省下一截····
    Web:
        level: 5
        mana: 25
        duration: 10000
experience-sources: 经验来源
- KILLING  击杀
- PVP  与玩家战斗
- QUESTING  探索
expmodifier: 1.0  默认
base-max-health: 21.0 最大基础血量
max-health-per-level: 0.25 每等级提示最大的血量
base-max-mana: 125  最大基础魔法值
max-mana-per-level: 1  每级提升的魔法值
mana-regen: 2  魔法值回复
mana-regen-per-level: .1  魔法值回复提升等级
expLoss: 0.007  经验损失
wildcard-permission: true 默认
tier: 1  默认
recipes: [ default ] 默认
这里需要着重讲一下技能的设置。如果你想让某种职业能够使用某种技能，那么就要想如下这样设置。先找到“permitted-skills:  “这个选项
然后这是技能配置的格式：
permitted-skills:
       [技能名]:
        [各项属性]
以雪球这个技能为例：
    Icebolt:
        level: 1 【使用需求等级】
        damage: 4 【技能伤害】
        cooldown: 2000  【冷却时间没，1s=1000】
        slow-duration: 2000  【减速时间】
        mana: 0  【耗蓝】
各个技能的设置都是和雪球这个技能差不多的，你可以调整各个技能的各个属性。如果你想添加技能，那么就直接按照这样的相同格式在“permitted-skills:  “这个选项后添加就可以了。
Heroes中的技能其实是一个技能库，在”skills.yml“中就有所有技能的名字。而我们的各个职业只是挑选了一部分让这个职业可以使用而已，所以，如果你想添加某个职业的技能，那么就可以从技能库中寻找技能。
