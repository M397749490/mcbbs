简介：signshop允许你设置实体店铺和你的命令。你想卖东西放进箱子里，箱子上面面放一个实体，然后在那方块上放一个木牌子（手上得拿着红石，可根据下图实例制作）。设置简单，甚至更容易定制！

特点：
可以右键就快速执行某个命令to kill bear children
更多特点看：http://dev.bukkit.org/bukkit-plugins/signshop/pages/expanded-features/
权限、可写:
"Admin" signs require OP or SignShop.Admin.* to create  翻译：admin一栏下面是yes的需要有SignShop.Admin.*权限去创建，即OP身份。可写的（暂时未翻译）：
SignAdminDescription
[Buy]NoBuy an item from the shop chest for the price specified on the 4th line
[Sell]NoSell an item to the shop chest for the price specified on the 4th line
[Trade]NoTrades one set of items for another, 2 chests required
[Share]NoLink to another SignShop to split profits, lines 2 and 3 are for the other players, line 4 is for % amounts (e.g. "25/50" for 75% to others)
[Bank]NoLink to another SignShop to make the shop take/give money to a bank account, The bank account is specified on line 2 of the sign (Note: you must own the bank account for this to work)
[Donate]NoGives an item to the shop chest
[DonateHand]NoDonates the item in your hand to the shop chest
[Dispose]NoTakes the item in your hand and safely decomposes the material
[Slot]NoGives a random item from the selected chest items (not the entire inventory) to the player
[DeviceOn]NoTurns a lever on
[DeviceOff]NoTurns a lever off
[Toggle]NoToggles a lever
[Device]NoTemporarily turns on a lever
[DeviceItem]NoTemporarily turns on a lever using items as payment
[Jukebox]NoAllows players create jukeboxes by placing music discs in a chest
[Restricted]NoMakes it so only certain permission groups can use the linked SignShop (listed on lines 2, 3, and 4)
[gBuy]YesBuy an item from the shop chest, but the owner receives no money
[gSell]YesSell an item to the shop chest, and the player receives money, but not from the owner
[iBuy]YesBuy an item from the "shop", money goes to noone, infinite items
[iSell]YesSell an item to the "shop", infinite money, item disappears
[iTrade]YesTrades one set of items for another, infinite stock
[Class]YesTakes the user's inventory and replaces it with items from a chest, infinite stock
[Kit]YesGives the buyer a set of items once (infinite stock), must be reset using ResetKit sign before they can use it again
[ResetKit]YesAllows a player to use a Kit sign again
[iBuyXP]YesBuy the number of XP levels on the third line of the sign
[iSellXP]YesSell the number of XP levels on the third line of the sign
[iXPBuy]YesBuy an item using raw XP points on the third line of the sign
[iXPSell]YesSell an item using raw XP points on the third line of the sign
[iSlot]YesGives a random item from the selected chest items with infinite stock
[Day]YesTurns the time to day
[Night]YesTurns the time to night
[Rain]YesTurns on rain + thunder
[ClearSkies]YesTurns off rain + thunder
[Repair]YesRepairs the current item
[Heal]YesFully heals the player
[Enchant]YesSells the enchantments from the item in the chest
[Disenchant]YesRemoves enchantments from an item
[TpToOwner]YesAn example of a custom sign for running commands
[Command]YesAllows players to run commands on the 2nd and 3rd lines of the sign
[UserCommand]YesAllows players to run commands on the 2nd and 3rd lines of the sign as if they typed it themselves
[Promote]YesPromotes players to the permission group listed on the 2nd line of the sign

原文：
  • Uses Vault (站内)API, so it works with all standard economies (EssentialsEco, iConomy, BOSEconomy, Gringotts, and more) and permission plugins (Permissions 3(站内), bPermissions, PEX,GroupManager(站内), PermissionsBukkit, zPermission (and defaults to OP permissions, if you don't want to use a permission system).
  • Supports LWC (站内), Lockette (站内,懒得再找下面的了。。。自己搜索吧), Deadbolt, WorldGuard , Grief Prevention, PlotMe, PreciousStones,LoreLocks, and Residence for chest / sign protection, but SignShop also has built-in sign protection.
  • Use with SignShopGuardian to save your inventory when you die.
  • Use with SignShopHotel to allow players to rent rooms for a period of time.
  • Supports dynmap to show shop locations.
  • Buy and sell custom made guns and weapons using Crackshot. (P.S. Crackshot is awesome!)
  • Supports alternate worlds using Multiverse.
  • Supports the Notifications plugin. SignShop will give a notification whenever a sign is created. This message can be customized in the config.
  • Display the items SignShop is selling by clicking half slabs and using ShowCaseStandalone.
  • Support for custom sign colors using SignColours.
  • Make SignShop run commands for all players online using WildcardCommands.
  • Charge a fee to use, and remotely operate Machinas with MachinaCraft.
  • Can use Towny banks to fund your shops using custom Blocks (Thanks ryvix!).
  • Can restrict shops to WorldGuard regions with the "allow-shop" flag, or Towny shop plots
  • Can convert ChestShop signs to SignShop format by just punching them with redstone
