看了眼 CrT 源码
PlayerInteractBlockEvent::block 返回的是 MCSpecificBlock 类，而这个类的 getTileData 方法只会返回 null ，需要获得 MCWorldBlock 类才有能返回正常值的 IData ，目前我看见这个类的实例可以用 IWorld::getBlock(int x, int y, int z) 获取

所以
var head as IData = BLock.data; 等号后面的改成 event.world.getBlock(event.x, event.y, event.z).data
