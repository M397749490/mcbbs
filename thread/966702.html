分数储存在marker的scb里

scoreboard players set marker scb -2147483648
execute 所有要比较分数的实体 ~ ~ ~ scoreboard players operation marker scb > @e[c=1] scb

建立计分板c，让所有玩家在计分板c上的分数设为最高分数，然后减去原分数，再选择分数为0的玩家即可

/scoreboard objecrives add c dummy
然后
/execute @a ~ ~ ~ scoreboard players operation @s c = @s a
/execute @a ~ ~ ~ scoreboard players operation @s c > @a a
/execute @a ~ ~ ~ scoreboard players operation @s c - @s a
/scoreboard players add @a[score_c=0] b 1

参考自：https://www.mcbbs.net/forum.php? ... 703721&pid=11978257
