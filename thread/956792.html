标题: 无法使用雪球吸引仇恨
玩家运行如下函数，无法使两只僵尸互相发起攻击。
版本：1.15.2
  1. summon minecraft:zombie ~ ~ ~ {Tags:["A"]}
  2. summon minecraft:zombie ~ ~ ~ {Tags:["B"]}
  3. execute as @e[tag=A] at @s run summon minecraft:snowball ~ ~2 ~ {Tags:["snow_ball"]}
  4. execute as @e[tag=snow_ball] run data modify entity @s owner.L set from entity @e[limit=1,tag=B] UUIDLeast
  5. execute as @e[tag=snow_ball] run data modify entity @s owner.M set from entity @e[limit=1,tag=B] UUIDMost
  6. execute as @e[tag=B] at @s run summon minecraft:snowball ~ ~2 ~ {Tags:["snow_ball"]}
  7. execute as @e[tag=snow_ball] run data modify entity @s owner.L set from entity @e[limit=1,tag=A] UUIDLeast
  8. execute as @e[tag=snow_ball] run data modify entity @s owner.M set from entity @e[limit=1,tag=A] UUIDMost
