声明：首先，这个插件和MCBBS中另一款名为Anti-Xray的插件没有冲突，它是一款以CoreProtect为基础的附属插件，功能是用来汇报玩家挖矿比例.而我这一款插件的功能是用来操纵玩家的挖矿数目.当然还有很多很有趣的功能，下面我来简单介绍.二楼是英文Anti-Xray的翻译，你们也可以看，但是很多专业术语感觉看了我这个的话，你们也就没必要看了.

ANTI-XRAY

========================

01.介绍：

  首先，Anti-Xray它不是用来防Xray的……没错，就是说你装了这个插件，玩家照样可以作弊.那么它是如何猥琐熊孩子的呢？其内部程序大概可以概括成：


·1.首先，生成一种叫“挖矿金币”的货币（当然不是货币，我这里只是形象地说，其实就是一个数据，是无形的）

·2.每个玩家一上线，TA就会获得规定数目的“挖矿金币”

·3.然后，每当TA挖一种矿石时（矿石可以自定义），例如说钻石，他就要损耗一定数目的“挖矿金币”（例如说 我定钻石消耗100点“挖矿金币”，那么TA挖取钻石之后就会扣除100点）

·4.如果TA的“挖矿金币”用完了，TA就不能再挖取矿石了

·5.这种金币既可以通过每小时服务器自动给予，也可以通过挖取一些特定方块获得


怎样？简单明了吧？所以这款插件非常轻量，和Orebfuscator相比简直是既保证了服务器性能，又能够有效地防御作弊.唯一需要注意的地方就是：你的“挖矿金币设置”必须要非常合理（当然你不可能再顾及附魔效果，其实我认为也没什么关系，毕竟已经在防作弊的同时也保护了服务器的性能，没钱挖矿了休息一下建建房子更好）Anti-Xray甚至可以为你的服务器建设良好的经济效应.

全局设置：
·EnableMeticsTracking：开启/关闭与MeticsTracking的连接，就是一个统计网站，统计有多少人用Anti-Xray，你不想让作者知道你用他的插件你就设置为false
·Nplayers starting points：设置新玩家的“挖矿金币”，这里我说一下，新玩家就是刚刚进服务器的玩家，Anti-Xray里面有个套路：就是老玩家（在你装了Anti-Xray之前已经在服务器的）他的“挖矿金币”就会比普通玩家（MaxPoint）多一些，后面会慢慢降低到平均水平，让这个变化变得相对于更平缓，或者就说是察觉不到吧；而新玩家，他们的“挖矿金币”会比普通的低，尤其是如果你把新玩家的挖矿金币设置得比挖一块钻石消费的金币还要低的话，对劝退熊孩子有非常大的成效.我觉得这个创意可以
·Points earn per hour played：每小时获得的金币数目
·Maxinum point：最大金币数，注意，只有在玩家停止挖矿之后，金币才会进行补充
·Custom block definition：自定义矿物.这个很迷，因为我在上面的配置中没有发现这个功能.可能是MOD服专用的，据介绍，它的功能就是要你把一些MineCraft以外的方块名称及ID添加进去，Anti-Xray就会对它们进行识别和运算；
·Protect Block values：你可以在这里设定矿物的相关数据了.Value就是挖掉这个矿物，需要消耗的“挖矿金币”数目，MaxHight表示低于这个高度，挖掉这个矿物才需要消耗金币（高于是不需要的，毕竟有些人喜欢用钻石矿建房子==）
·Default Max Height：默认MaxHight，如果你在上面没有定义某种矿物的MaxHight，那么就会应用这个设置

分世界设置:
·Daultmaxheight：该世界默认MaxHight
·ProtectedBlocks：需要消耗金币的方块
PS:或许你已经注意到了，那就是末地和地狱的MaxHight都设置为256,（因为那个啥…象牙岩啊就是上天入地都有的）.但是是不是有些玩家**放了一块钻石矿，TA再挖的时候就要消耗金币呢？——不是，因为在钻石的设置中MaxHight为20，所以在所有世界中，钻石矿必须放置在20高度以下，挖掉它才需要消耗金币

04.控制挖矿比例：
这也算是一种高阶玩法了，其过程就是：让玩家通过挖普通方块（石头、砂石甚至低级矿物）来凑出“挖矿金币”，然后再拿来进行挖取钻石的消费.过程很简单，就三步：

01.将perhourpoint（每小时获得的金币数）设置为0（你要设置一些也不是不可以）
02.自定义矿物（例如stone），把它的value值设定为负数
03.这样，玩家就需要通过破坏这些低级别方块，才能够赚取金币，有足够的金币之后才能破坏高级别矿物

通过这个过程就实现了对矿物比例的控制，例如：
·points per hour: 0
·starting points: 0
·DIAMOND_ORE: 100
·STONE: -1
这样设置之后（这当然不是设置文件），玩家就需要通过挖取100颗石头，才能够有资格破坏钻石


05.命令：
  1. 01./antixray help --> 显示帮助信息
  2. 02./antixray reload --> 重载插件
  3. 03./antixray check [player] --> 检查玩家的“挖矿金币”数值，不建议你将这个权限交给玩家，具体看后面
  4. 04./antixray set <player> <points|counter> <value> --> 设置玩家的“挖矿金币”数目（point设置后，玩家就会拥有多少金币；counter设置后，玩家就会减少多少金币），这个指令一般用于做不同的矿物测试

07.抓熊孩子
01.AntiXray汇报功能：
把这条命令添加给管理员 antixray.op ，然后一旦有玩家的“挖矿金币”用完，就会发一条信息给管理员.然后管理员tp过去做个判断就行，判断是作弊就BAN就这么简单粗暴，所以之前我说不要把能够看自己有多少金币的权限给玩家，不然他们就能够时刻注意自己有没有超支，然后你就发现不了作弊者了

02.熊孩子判断方程：
不得不承认，要真正确定一个玩家作弊是一件非常困难的事情，所以下面列举出一些我的经验，来供大家参考：
1.通道都是直达矿物的，或者在挖矿过程中他们总是毫无畏惧地挖直线.因为作弊者可以看出哪里有岩浆，哪里有岩洞.
2.挖矿连火把都不用插，就肯定是作弊的了，Xray玩家根本不需要火把——他们能在黑暗中看到矿物.
3.通道非常的短，或者说是特别.和“挖矿专家”们不一样，专家们的通道往往是直线的，直达基岩，但是作弊者的通道可能转向的非常坚决，同时，专家的通道大部分汇聚得比较紧凑，但是作弊者的通道分布广泛，因为他们能看到哪里有矿物，哪里有挖的价值.
4.在挖矿前甚至没有一个农场，或者一个庇护所.作弊玩家可以看到哪里有岩洞，哪里有怪物，他们无需庇护都能躲开怪物.
5.挖矿时只携带非常少量的食物，弹药.因为他们能看到怪物在哪，所以连交战的必要都没有.
6.在加入服务器后很短的时间内就找到了钻石，因为Xray玩家根本不需要寻找钻石，他们只需要挖出一条小通道抵达钻石处就行.
7.也可以通过其他玩家的行为判断，如果其他玩家老是抱怨“怎么我老是找不到钻石啊？”，那么你就需要带上/co i到附近矿物区去逮捕作弊者了.
8.有一个非常高的矿物比例.Anti-Xray的确不支持这方面的查询，但是你可以通过上面我提到的“保护核心Anti-Xray”进行查询，往往，作弊玩家挖到的原石是非常非常少的.

Anti-Xray
---------------------------------------------------------------------------------------
01.它是如何工作的？
（自行翻墙）YouTube
基本上就是,玩家的挖矿数目被限制了.在限制的时间内他们只能允许挖一定数目的矿.在实践过程中,不作弊的玩家几乎感觉不到它的存在（他们也挖不出超过规定数目的矿）,但是作弊玩家就会心急气躁了.虽然不得不承认,这款名为Anti-Xray的插件确实不能禁止玩家使用Xray,但是,作弊玩家在挖到一定数目的矿后会禁止挖矿,一定程度上维护游戏平衡,以及起到劝导改邪归正的作用.当然,你使用这款插件来建立良好的经济效益也不是不可以.
----------------------------------------------------------------------------------------
02.和Orebfuscator相比，有什么区别？
在这里不得不吐槽的是，虽然Orebfucator效果非常显著，但与此同时，运行它必须付出很大的代价.Orebfucator运行时需要消耗非常多的CPU，来进行信息的封装、发送、分析.同时，对RAM的消耗也非常严重，因为它需要检阅和记录许多方块的信息.小服基本上就别指望用的上它了，大服必须通过削减最大玩家数，来保证Orebfuscator高效运行.就为了区区几个作弊玩家，损害了所有玩家的游戏体验，我认为这样并非最佳选项.
相比之下，Anti-Xray非常轻量化，它不需要非常高的服务器配置，也不需要占用很大内存（甚至可以说不会占用）来做信息记录.当然不得不承认的是，科技熊依然可以使用X-ray并获得成效（Mojang在防御作弊方面确实也没下多少工夫），但是他们的获益和普通玩家几乎是一致的（如果你设置合理的话），所以一句话说的就是：使用这款插件，可以彰显你对作弊玩家的绅士风度，同时减少CPU和RAM方面的压力.
----------------------------------------------------------------------------------------
03.和矿物信息类插件以及矿物比例报道插件相比，有什么优势？
首先，这种什么信息报道插件根本就没有办法自动防御X-ray，你要用它们来检查作弊，需要消耗很大的人力物力.同时，等你发现的时候，作弊玩家已经对游戏平衡造成了很大伤害.把作弊玩家BAN掉，你也解决不了世界钻石损耗的问题.同时，长江后浪推前浪，装这些插件没法解决根本问题.
但是，Anti-Xray就能够将矿石原封不动地保存在地面上，就算只作弊玩家也无可奈何.玩家矿物的采集数和他在服务器里呆的时间是对应的.虽然作弊玩家还是能得到一点蝇头小利，但是对普通玩家而言就不会造成太大伤害.事实上，如果你使用这款插件，那么一定能把熊孩子逼成正常，或者让其他服务器背锅，不就解决了根本问题了嘛~
使用矿物检查插件，你需要手动解决问题，使用Orebufscator，你需要付出很大代价.

05.细节
当玩家在线时，有一个无形的数据会飙升（直到达到最大阀值），当然这对不在线的玩家是没有影响的.当玩家开始破坏矿物时，他们的这个数值就会开始下降，如果他们没有足够的数值，去破坏对应方块的话，他们就会收到一条信息显示“你挖的太快了！”（当然不可能是这一句，大概意思），然后，就需要等待X分钟以后，他们才能继续挖矿.
如果玩家在你安装Anti-Xray之前就在你的服务器上游玩，那么这个阀值可能会比其他新玩家大一些，以此让这种限制变得柔和和不易察觉.
而新玩家，这个阀值在前几次游玩时可能会稍稍降低，以此劝导他们不要使用作弊Mod，维护服务器和谐的氛围.
当然，这对正常玩家来说，可能有点不公平（尤其是附魔的），但是，为了团体牺牲自我，难道不是传统的美德吗？
下面列举出一些常见状况：
1.有些玩家，他们老是在服务器里抱怨，或者私聊你.不用管他们，因为他们一定是作弊的（如果你数值设置的合理的话）.他们就是想你关掉这个插件来获取利益.
2.当然也有些玩家是合作挖矿，一个人挖石头一个人挖钻石，你只需要告诉他：要收获肯定要自己付出，守株待兔是绝对不行的. 就OK了.
3.也可能一些玩家相当幸运，那么你就劝他们去买彩票吧.毕竟，你还要考虑到那些不幸运的玩家，他们是有可能会作弊的.
4.有些玩家简直是职业挖矿玩家，他们很喜欢挖直线啊、垂线啊，抵达基岩然后获得非常爆炸多的钻石.我在这只能说，他们对钻石的痴迷非常病态，如果你顺应他们的抱怨并给他们通过检查的Node，那么，对于那些心态正常的玩家，他们找矿物可能会非常艰难.
PS：上面全是对作者原话的翻译，你们别吐槽我.

06.逮住作弊者
这款插件确实能够有效的防止作弊，但是如果你想要真正的抓住作弊者并BAN他们，Anti-Xray确实有一个记录挖矿情况以及通知管理的设置.（相关的Node：antixray.monitorxrayers 或者 op 前面那个是发送给创造玩家，后面是发送给管理），当玩家达到了挖矿阀值时，Anti-Xray就会把这个玩家的坐标发送给你（切记：达到阀值并不一定意味着作弊！），自从MC1.3.0版本以后，/tp的指令也支持坐标传送了，所以即使玩家突然下线，你也可以去相关地点进行调查.

09.调整每小时的挖矿限制
请不要随意更改钻石的数目，除非你已经亲身做过相关实验.否则，要么你可能会损害到普通玩家的权益，或者你会让作弊者得到更多利益！相关代码如下
  1. AntiXRay:
  2.   EnableMetricsTracking: true
  3.   NewPlayerStartingPoints: -400
  4.   PointsEarnedPerHourPlayed: 800
  5.   MaximumPoints: 1600
  6.   IgnoreMaxPointsForBlockRatio: true
  7.   ExemptCreativeModePlayers: true
  8.   NotifyOnMiningLimitReached: false
  9.   DefaultMaxHeight: 63
  10.   ProtectedBlockValues:
  11.     EMERALD_ORE:
  12.       Value: 50
  13.       MaxHeight: 35
  14.     DIAMOND_ORE:
  15.       Value: 100
  16.       MaxHeight: 20
  17.   Worlds:
  18.     world: ''
  19.     world_nether:
  20.       DefaultMaxHeight: 256
  21.     world_the_end:
  22.       DefaultMaxHeight: 256
复制代码
全局设置：
EnableMeticsTracking：开启/关闭数目追踪，更多信息请往下看
New players starting points：设置新玩家的数值，这个数值是用来破坏方块的，例如我想要破坏一个钻石矿，就需要损耗100点数值；
Points earn per hour played：每小时，在线玩家可以获得的数值数
Maxinum point：数值最大阀值，请注意，数值必须在玩家停止挖矿之后，才会进行恢复
在上面这个例子中，由于新玩家的数值远远小于挖一个钻石矿所要花费的数值，这样就能很好地抵制Xray作弊者的出现.（然后你也能逮捕他们
）
你也可以在下面添加其他矿物损耗的数值，但是我认为，Xray作弊者一般只对钻石感兴趣.增加新矿物只会增加服务器的压力.
Custom block definition：允许你通过方块的ID以及子ID来定义新矿物的限制，如果你使用了什么工业服之类的话.
Protect Block values：在这里设置你想要保护的矿物相关数值，这是对所有世界的限制.当然你也可以为每个世界设定不同的限制数值，具体看下面
Default Max Height：这个选项设置所有矿物的默认允许免费挖矿高度，当高于这个高度时，玩家挖矿就不会损耗数值，但低于这个高度，他们就会损耗数值了.这个选项还是很有实用价值的，例如有些玩家喜欢用钻石矿建房子……如果你这个设置能够设置好的话，既能防止作弊，又能满足玩家的这种癖好（一般情况下MineCraft的钻石矿在16以下的方块中生成）

下面，是每个世界的单独设置：
       你可以在下面设置哪些世界需要接受Anti-Xray的检查，设置的值将覆盖全局值并应用于那个世界之中
Daultmaxheight：设置这个世界的默认允许免费挖矿高度，只应用于对应世界
ProtectedBlocks：设置需要消费数值的方块：
在这一块 你可以看到，地狱和末地的MaxHeight设置为256，但这并不意味着玩家放了钻石矿之后，敲碎它就需要损耗数值，因为在全局设置之中，钻石块的Maxheight设置为20，所以只有在20高度以下敲碎钻石块，才会损耗数值（我就想问谁会那么无聊在地狱和末地放钻石矿）
你可以通过下面的这个比较进一步了解数据覆盖等级：
default max height < default protected ore max height
< world specific default max height < world specific ore max height

查看MineCraft各种矿物默认高度地址链接：
http://minecraft.gamepedia.com/Ore
如果你想添加一个自定义世界，应用Anti-Xray全局设置而非自定义设置，你只需要按格式写上世界名并加上“”号就行，例如我添加一个叫mining_world的世界，设置如下：
  1. Worlds:
  2.   mining_world: ""
  3.   world:
  4.     ProtectedBlocks:
  5.       DIAMOND_ORE:
  6.         Value: 75
  7.         MaxHeight: 63
  8.   world_nether:
  9.     DefaultMaxHeight: 256
  10.   world_the_end:
  11.     DefaultMaxHeight: 256
复制代码
当你克隆了相关设置以后，需要重启2次服务器，Anti-Xray才会应用这个设置.

10.对于自定义方块的更多细节：
你完全可以自定义需要保护的特殊方块，这在你加入了mod之后非常有效：
但是需要注意的是，由于mod属于外部程序，Anti-Xray并不能完全保证对这些特殊的方块限制时时有效，因为Anti-Xray可能会找不到相关的数据库
同时，Anti-Xray也可能会擅自更改id，如果它没找到你定义的id但找到了一个相似的话.
当然，你也可以通过~来进一步定位相关方块的信息（在名字和ID之间用~隔开
）如果你没有设置Value，默认为-1，表示这个方块被忽视.
  1. ProtectedBlockValues:
  2.   999~12: # 这是一些mod上的方块id
  3.     Value: 50
  4.     MaxHeight: 35
  5.   WOOL~14: # 红木
  6.     Value: 100

11.数据库的设置在哪？
在默认设置中，Anti-Xray不需要使用数据库.因为我认为，使用数据库弊大于利，甚至还会加大插件对服务器性能的损耗.对于Anti-Xray来说，每一个玩家只有两个设置变量，所以，Anti-Xray完全可以只用一个文档来读取数据，并且把数据再带出来.因此根本没有数据库的必要，并且添加数据库之后，你还需要浪费一些时间来读取它.
当然，我曾经也使用过数据库，但是很多时候，和数据库的连接总是莫名其妙地断开.因此从今往后，我再也不会使用数据库了，这只会加大插件信息的读取量和服务器的压力.

12.设置挖矿比例
如果你希望让玩家通过挖取更多的石头和低级别矿石之后才能得到钻石这类高级矿物，下面有三件事需要你做.一：将每小时获取的数值设置为0；二：将石头、低级矿物损耗的数值设置为负数，这样当玩家破坏这些石头的时候，他们就会获得一些数值，然后再用这些数值来挖矿；三：修改message.yml来告知大家这个政策
例如下面这个设置，玩家就需要在敲碎一个钻石矿的时候，挖掉100个石头：
  • points per hour: 0
  • starting points: 0
  • DIAMOND_ORE: 100
  • STONE: -1
然后你的message.yml可以设置为：“你需要破坏一些石头才能挖取钻石！”
