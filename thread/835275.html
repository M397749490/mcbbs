给你几个现成的：

  1. 蓝色：/give @p minecraft:leather_helmet 1 0 {display:{color:1310975}}
  2. 绿色：/give @p minecraft:leather_helmet 1 0 {display:{color:7601920}}
  3. 黄、色：/give @p minecraft:leather_helmet 1 0 {display:{color:16777006}}
  4. 橙色：/give @p minecraft:leather_helmet 1 0 {display:{color:16748032}}
  5. 红色：/give @p minecraft:leather_helmet 1 0 {display:{color:16725504}}
  6. 青色：/give @p minecraft:leather_helmet 1 0 {display:{color:262058}}
  7. 天蓝：/give @p minecraft:leather_helmet 1 0 {display:{color:262143}}
  8. 深蓝：/give @p minecraft:leather_helmet 1 0 {display:{color:44031}}
  9. 玫瑰红：/give @p minecraft:leather_helmet 1 0 {display:{color:16712309}}
  10. 紫色：/give @p minecraft:leather_helmet 1 0 {display:{color:10158709}}
  11. 粉色：/give @p minecraft:leather_helmet 1 0 {display:{color:16104954}}
复制代码


color后面直接写数字，但这个数字是10进制的，因此需要把你需要的颜色的RBG信息转换成16进制的数字再转换成10进制的数字后再填写。
