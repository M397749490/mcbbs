一键启动服务器

基于容器技术，在任何装有 Docker 环境的操作系统下，只需一个命令就可以启动基岩版官方服务器：

  1. docker run -d --restart=always --name=mc-bedrock-server --net=host nswebfrog/mc-bedrock-server:1.10.0.7

补充一下，你的这些命令是可以提前执行好，封装成一个 Docker 镜像。然后就可以一个命令直接执行了。

提供一下我的 Dockerfile 文件：

  1. FROM ubuntu:18.04

  3. ARG BEDROCK_VER=1.12.1.1

  5. EXPOSE 19132
  6. VOLUME /opt/server/mc-bedrock/world

  8. ENV TZ=Asia/Shanghai
  9. RUN apt-get update \
  10.   && apt-get install -y wget unzip curl \
  11.   && mkdir -p /opt/server/mc-bedrock && cd /opt/server/mc-bedrock \
  12.   && wget https://minecraft.azureedge.net/bin-linux/bedrock-server-${BEDROCK_VER}.zip \
  13.       -O /opt/server/mc-bedrock/server.zip \
  14.   && unzip server.zip && rm server.zip \
  15.   && apt-get clean && rm -rf /var/lib/apt/lists/* /tmp/* /var/tmp/*

  17. WORKDIR /opt/server/mc-bedrock
  18. ENV LD_LIBRARY_PATH=/opt/server/mc-bedrock
  19. CMD ["./bedrock_server"]
复制代码


打包镜像的命令：

  1. docker build -t mc-bedrock-server .
复制代码


运行镜像的命令：

  1. docker run -d --restart=always --name=mc-bedrock-server --net=host mc-bedrock-server
复制代码


如果要更新官方的镜像，只需要修改 Dockerfile 里的 BEDROCK_VER 参数就好。

备注： Dockerfile 里的官方 server 文件地址由于服务器在国外无法直接下载到。
