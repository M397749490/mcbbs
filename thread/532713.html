2、作者的话
Hello guys!

InfinityCraft is a Forge mod for minecraft 1.8. It is going to add a wide variety of blocks, items, tools, trees, crops and so on..

UPDATES

Im working every day on this mod so you guys can expect regular updates. "Oh no! I need to check this post every day!" Well no.. I've made an build-in version checker so when there is a newer version available then the version that you have. There will be a link in the chat that takes you directly to the downloads page to download the latest version.

VIDEOS

Currently, there are no mod spotlights for this mod yet. If you want to make one, please PM me.

MODPACK

You MAY add this mod in a modpack, ONLY if i am credited.
You MAY NOT make any money of your modpack, no matter what.

INSTALLATION
1. Install Forge 11.14.3.1425 or higher (or the mod won't work).
2. Drop the InfinityCraft 1.0-a.xxx.jar into your mods folder.
3. Enjoy the mod!

BUGS

Currently, there are no bugs that i'm aware of. If you found one, send a e-mail to: support@rowanmods.3eeweb.com
