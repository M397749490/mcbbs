简介（注：本人能力有限，所以插件的简介并未完全照搬原文）


作为一名腐竹，在通常情况下，你的服务商不会把你的IP地址进行更换，然而如果你开的是家用服或者是服务器的域名很长，那么你就需要

这款插件

ps：这不是CS:GO的MC版

这款插件可以检测你的服务器IP地址的改变（具体啥方法我也不知道），然后更新你在MCGO.IO上定制的ip（目测可以热重载）



食用方法：下载插件后放进plugins文件夹。（是的就怎么简单）


接下就是插件的配置过程
（不然插件咋知道你家的IP地址）

（以下为图文教程，懒得看的后面有视频教程）

  
1.打开mcgo.io
2.点右上角的Register
3.来到注册界面，填写个人信息
如果当你按下注册后，弹出来这个
别紧张，不是作者码代码是码错了，而是作者采用了谷歌验证
所以https://www.mcbbs.net/thread-778175-1-1.html请
或者科学的力量

4.当你注册好后，点My server，再点
create a new server

你照着填就是了

5.启动服务器，打开MC，享受你的游戏吧


现在来解决刚才直接填写端口映射后的域名或服务器的域名会报错的问题
1.按WIN+r键，输入cmd
2.输入命令
ping  (端口映射的服务器域名）我这里以路 油 侠为例
把输出的内容划红线的那部分给填到

3.打开mc，在原本的xxx.mcgo.io后加上你的端口映射的服务器端口
（如test1.mcgo.io:2556）


这是作者说的原话





命令and权限
/mcgo ip —获取服务器的基础地址
权限：mcgo.ip.get

/mcgo reload —
重新加载mcgo插件
权限：mcgo.reload

                        
/mcgo silence—
   禁止mcgo发出IP更改警告                    
权限：mcgo.silence



搬运授权





注意

由于作者给出的答复是在xxx.mcgo.io后添加端口号，但由于端口号是有限的，所以遇到这种情况请使用别的端口号
