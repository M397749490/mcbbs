@EventHandler
public void shoot(org.bukkit.event.player.PlayerInteractEvent e) {
    e.getPlayer().playSound();//播放声音
    e.getPlayer().sendMessage();//发送消息
}
如何用物品破坏自己翻javadoc，反正有监听器，然后判断破坏方块是否拿的是你需要的物品
中文文档：https://bukkit.windit.net/javadoc/
