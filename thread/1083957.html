可能是residence插件的限制
你(如果装了residence的话，当然看你的描述大概率是residence的限制)
打开plugins/residence/config.yml
找到这一段
  1.     Place:
  2.       # Level from which one to start block lava and water place
  3.       # This don't have effect in residence area
  4.       Level: 63
  5.       # With this set to true, playrs cant place lava outside residence
  6.       NoLavaPlace: false
  7.       # With this set to true, playrs cant place water outside residence
  8.       NoWaterPlace: false
  9.       Worlds:
  10.       - world
复制代码


把上面那个nolavaplace和nowaterplace都设为false

水的流动在同一个配置文件中
修改plugins\residence\config.yml
找到这一段
  1.     Flow:
  2.       # Level from which one to start lava and water flow blocking
  3.       # This dont have effect in residence area
  4.       Level: 120
  5.       # With this set to true, lava flow outside residence is blocked
  6.       NoLavaFlow: false
  7.       # With this set to true, water flow outside residence is blocked
  8.       NoWaterFlow: false
  9.       Worlds:
  10.       - world
复制代码


把NoLavaFlow和NoWaterFlow都设置成false
