-= Ragecraft III: The Prophecy=-

大型CTM地图：预言

By Heliceo





你是否正在寻找一场无极限的CTM挑战？

那你来对地方了！

Ragecraft系列提供了3个巨大，充满挑战的地图。

它们会挑战你PVE技术的极限，甚至使你的理智。

准备好来挑战了吗？

【本次搬运Ragecraft系列第三作--预言】

你的目标是，搜集物品，提高自己能力，了解黑暗的真相，

最终打败妄想夺取黑色水晶的Aris！






预言作为失眠的续作，在游玩性上全面提升。


任务，升级，特殊道具，华丽的BOSS战，令人震惊的各种系统...


更加适合各位挑战！





MC版本1.8.8，游玩时间30~60小时
地图版本V1.4

允许多人游玩




目标：

收集全部16色的染色玻璃【水晶】【成就物品】

额外：收集全部12个绿宝石方块【绿宝石可在副本中找到】【4个多余绿宝石防止漏掉】




地图难度【作者自己评价】：7.5★




部分规则：

1.永远不要开启和平

2.生存模式游玩

3.不要开启防爆指令

4.不要翻越地图

5.不要自行制作成就物品

6.允许使用生存模式大部分游玩方法

7.不要前往地狱/末地




评语：非常适合喜欢CTM地图的玩家，

游玩时间绝对让您满意，充满挑战的一张地图

锻炼PVE能力，生存能力，寻路能力【雾】
内容细则：
预言是一张大型CTM地图，何为CTM？
CTM的全称是Complete the Monument，即收集作者所设定的成就物品为最终目标
在本张地图中，你需要收集16种颜色的染色玻璃[水晶]，在战斗中，你能提升自己的能力
你还能收集箱子中的绿宝石来获得强大的奖励箱，奖励箱中全部含有神秘基岩！
这些基岩能大幅提升玩家的某一特殊能力！[例子：杀怪回血]
言归正传，你的终极目标，是收集16色的染色玻璃[水晶]，并击败邪恶竞技场的大BOSS Aris！
然而，你的初始能力并不足以击败它......
一开始，你会出生在无法离开的海边[雾]
在这个海边区域里，你靠自己的双脚，跑出来，进入第一个区域： 血之谷
你可以运用所有你所了解的生存能力，获取箱子，杀死怪物，制作装备，收集物品！
[除了规则不允许的！]
当然，作者会在箱子里提供一些设定好的物品，这些物品都有独特的名字和分级！
分级如下：
Common Item
Uncommon Item
Rare Item
Epic Item
Legendary Item
Set Item
Special Item
Secret Item
Bonus Item
当然，在这个完全自定义的世界中，没有挖矿这一说法！
所有你能看到的矿石，都是作者想提供给你的！
同时，如同绝大多数CTM一样，本张地图非常昏暗，你需要足够的亮度看清四周并
阻止怪物的生成！
这个时候，火把------最好用的道具就派上用途了！
地图中经常能看到树木和煤炭，用它们制作火把吧！
在一定时间的战斗后，你还会来到神秘的地方——Nexus【玩家基地！】
在这里，不仅永远不会刷怪，你还能提升自己的能力，解锁传送点，
放置成就物品，放置绿宝石方块来获取奖励箱！
附魔台在本张地图中也有至关重要的作用，有时作者提供的装备不一定有你附魔的好！
附魔台会在二号岔路口获得.......
说到岔路口......本地图有5个岔路口，分别包含了各个副本。
岔路口是休养生息的另一个地方，也是你可以选择挑战之地的好去处！
我来介绍下本地图的全部副本吧！每个都非常大！
如下：
血之谷
法老之沙
Xin的遗产
堕落泥沼
小型矿山
最后的巫师
火山之城
幽灵废墟
召唤师的巢穴
嗜血神庙
终末之冬
诡异实验室
恶臭之河
Vhisarion之堡
流放
Aris的宫殿
另外，本地图有许许多多特色的BOSS！
如下：
法老王——赞埃弗拉
最后的巫师
Yaaros
Alyria
Vhisarion
Aris
所有副本包含1个染色玻璃[水晶]！每个副本有非常独特的特色、怪物、道具、地形、建筑、场景！
绝对值得一玩的地图！
游玩时间高达30~60小时，支持多人，跟基友一起开黑组团虐怪物吧！
另外说一句：国外这个系列火到不能再火了！
92万查看量！比肩mcbbs的冒险者传说！
同时，CTM这个题材在国外远比国内深入人心！
