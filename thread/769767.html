作者: 746671016    时间: 2017-11-23 08:30
如果是在GroupManage的权限组给的称号不显示可能就是语法错误缺少双引号或者格式错误所导致。

如果是称号插件添加的称号，可能就是编译和转码错误导致文件重置成原始状态。

如果是在Ess修改的话，那样是不行的，那只能修改聊天框的玩家聊天格式，不可以添加称号的。
作者: fyxrim    时间: 2017-11-24 01:01
hi hello
这个ess改config 用我的复制就行了
  1. # OP名字的颜色代码,填写0~9或a~f其中的一个数字或字母,填写'none'来冻结该功能.(译注:可到http://ess.khhq.net/mc/查看颜色代码)
  2. ops-name-color: ''

  4. # 昵称的前缀符号,这样你能知道这不是他们真正的用户名.
  5. nickname-prefix: '昵称:'

  7. # 设置最大昵称长度, 昵称前缀也包括在内.
  8. max-nick-length: 15

  10. # 如果你想用其他的插件来设置玩家名字,将其改为"false".
  11. change-displayname: true

  13. # 当这个选项开启时,在玩家显示的名字上添加的前缀或尾缀,会被显示在在线列表(TAB)中.
  14. # 上面的"change-displayname"必须是true才有效.
  15. change-playerlist: true

  17. # 添加前缀后缀(上面的"change-displayname"必须是true才有效)
  18. # 如果你不设置该项,且essentialschat被安装了,其将会被默认为"true".
  19. add-prefix-suffix: true
复制代码
