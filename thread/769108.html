唔，我还是给你讲过程吧，手机不方便。
圆的方程是 (x-a)^2+(y-b)^2=r^2
其中 x，y为坐标变量，a，b为圆心坐标，r 为半径
那么思路就是

循环区域内的点，计算到圆心距离，如果小于某个阈值（因为double不可能精确计算），则在圆上
来一波伪代码

for each double x from A-r to A+r step 0.01
  for each double y from B-r to B+r step 0.01
    if (x-A)^2 + (y-B)^2 - r^2 <=0.01
      // 这里的 x y 就是一个合格的圆上的点

不过有一点，这样取的点是不均匀的，其他的方法比如导数方程也是可以的，而且那个是均匀的点

Set<Location> sendParticleCircle(Location loc, double radius) {

    for (double degree = 0; degree < 360; degree +=15) {
        double offsetX = Math.sin(degree/180D * Math.PI) * radius;
        double offsetZ = Math.cos(degree/180D * Math.PI) * radius;
        Location result1 = loc.clone();
        result1.add(offsetX, 0D, offsetZ);

}
