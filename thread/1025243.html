┃ 须知·特点
须知:
此插件分为两个发布版本:Command Panels和Command Panels Classic
前者适用于1.7-1.12
后者适用于1.9-1.15
另外还有一个作者制作的菜单编辑器,适用于1.13-1.15
特点:
  • 超轻量级,仅仅95KB
  • 可在线编辑GUI界面
  • 使用任意物品并根据需要分配任意多个命令
  • 快速填满所有空栏位
  • 使用PlaceHolderAPI高度自定义
  • 给物品加任何Lore和名字
  • 尽你所想地制作不同的菜单
  • 完整格式控制
  • 支持记录玩家输入的命令并"加油添醋"
  • 可使用快捷物品开启菜单
  • 给指令加金钱限制
  • 为玩家的热键创建菜单
  • 自定义命令打开菜单
  • 使用自定义头颅支持
  • 内置一些方便的变量
  • 为菜单设置权限
  • 为菜单开启设置音效
  • 为菜单物品设置附魔
  • 设置物品堆叠数
  • 设置点击音效
  • 设置玩家传送
  • 可以以后台身份执行指令
  • 多种点击方式
  • 支持选择BC跨服
  • 列出你服务器已有的菜单
  • 从后台让玩家打开菜单
  • 智能刷新在面板,在插件打开时刷新变量
  • 当菜单打开时执行指令
  • 使用独立编辑器轻松制作菜单
  • 支持在Discord社区讨论

┃ 命令
图表整理
命令 权限 描述
/cp无列出游戏里的可用指令
/cp [菜单名]commandpanel.panel.菜单权限 打开菜单
/cp [菜单名] [玩家ID]commandpanel.other让其他人打开菜单
/cp [菜单名] item [玩家ID]commandpanel.item.菜单名给予玩家打开菜单的道具
/cplcommandpanel.list列出成功载入的菜单
/cpccommandpanel.close关闭当前打开的菜单。
放入菜单配置文件里很有用
当使用者点击时它将关闭菜单
/cpgcommandpanel.generate开启/关闭通过箱子生成GUI
/cpr
commandpanel.reload
重载插件配置
/cpvcommandpanel.version查看插件版本
/cpdcommandpanel.database查看菜单数据库，
从中可以共享预制菜单
commandpanel.move.菜单权限允许移动菜单的热键
（如果菜单是固定的）
commandpanel.* 允许使用全部权限
我使用的版本中/cpd指令是开启Debug模式而没有database这一项,不知道是WIKI没更新还是怎么回事

┃ 变量
  • %cp-player-displayname% 玩家的显示名
  • %cp-player-name% 玩家实际ID
  • %cp-player-x% 玩家X坐标
  • %cp-player-y% 玩家Y坐标
  • %cp-player-z% 玩家Z坐标
  • %cp-player-input% "命令输入"模式下的变量,玩家在聊天框里输入指令后,可以在玩家指令基础上编辑并发出指令,设置多个可重复执行某一指令
  • %cp-player-world% 玩家所在的世界
  • %cp-player-balance% 玩家的金钱(需要经济系统+Vault)
  • %cp-tokenmanager-balance% 玩家的金钱(需要TokenManager插件)搬运帖
  • %cp-online-players% 在线玩家数
  • %cp-clicked% 玩家所点击的菜单中的物品(你可以用这个方法设置点击可以获得菜单显示的那个物品)经测试,
如果没有基础插件或者注入扁平化之前物品ID的插件则这个可能会出错
  • %cp-votingplugin-points% 玩家拥有的投票点数(需要GUI投票插件VotingPlugin) 搬运帖
  • %cp-player-online-1-find% 寻找某一栏位的玩家,可以把1改成任何数。如果只有一个人在线,那么1模式就会显示在线的那个人,如果设置2模式,将会显示离线的玩家

使用目前最新版本(2.8)

  10.   input-cancel: cancel #当使用%cp-player-input%变量时,玩家取消输入模式的验证字符,默认是 %cp-player-input%
  11.   input-cancelled: '&c已取消输入!' #当输入模式取消时的提示消息
  12.   input-message: #当玩家开启输入模式时出现的提示消息.使用变量%cp-tag%(我觉得可以称之为常量)

命令标签
你可以在添加命令时加入一些条件以控制,请注意前缀如"op= "必须加上
标签类型(请在后面加上=和一个空格)描述
op 以OP身份强行执行指令
server 在BC下允许把玩家传送到其他字服
console 以控制台身份执行(需要加上玩家ID否则一般指令不生效)
msg 私聊玩家
buy 购买某物品,请使用'buy= 价格 物品 数量 子ID'的格式书写,需要Vault前置
sell 出售某物品,请使用'sell= 价格 物品 数量 子ID'的格式书写,需要Vault前置
buycommand 花费游戏币使用指令,请使用'buycommand= 价格 命令'以控制台身份
sound 点击时使用的音效
stopsound 停止某音效,请使用'stop= 音效名'
teleport 传送玩家,请使用'teleport= X Y Z [玩家名]'或'teleport= X Y Z [视角] [偏向]'
sudo 强迫玩家使用指令
paywall 如果不支付规定的游戏币,这条标签以下的所有命令都不能使用
xp-paywall 如果不支付规定的经验,这条标签以下的所有命令都不能使用
tokenbuy 与buy类似,但是是针对TokenManager插件的功能
tokensell 与sell类似,但是是针对TokenManager插件的功能
tokenbuycommand 与buycommand类似,但是是针对TokenManager插件的功能
tokenpaywall 与paywall类似,但是是针对TokenManager插件的功能

┃ 支持的插件
并非必须,但是可以给插件提供一些扩展
Placeholder API>>提供更多变量,让菜单更加灵活
Vault>>出售或购买标签所需要的必备前置,当然你还得准备一个经济系统(如Ess|Economy|Iconomy等)
Bungeecord>>支持使用'server= '标签跨服传送
Head Database>>支持使用'hdb= '标签载入材质
TokenManager>>有关Token的功能
VotingPlugin>>使用任何与投票相关的变量或功能
┃ 生成菜单
  • 在一个箱子或一个大箱子里用自行修改的物品装好菜单里所对应的位置,空白区域将会自动填充
  • 键入指令/cpg 进入生成模式
  • 打开箱子,此时配置就会产生,自动命名为Panel-X
  • 打开配置文件为你的菜单添加命令一类的东西吧
┃ 牌子菜单
  • 在牌子第一行输入你设置的标识符(默认是 [CommandPanel] )
  • 在第二行写上菜单名,使用默认菜单则会在第二行生成'example'
  • 允许使用彩色，例如，“&1[CommandPanel]”仍然有效。
┃ FAQ
一、当玩家点击菜单时如何让他关闭?
给菜单加指令:cpc或commandpanelclose

二、为什么玩家可以把菜单里的东西拿出来且菜单不工作?
CommandPanels不支持Minecraft 1.8.X或更低版本。你需要升级你的Minecraft版本，
或者将CommandPanels降到1.8.3版本或者使用Classic版
三、为什么我已经是最新版本却还有提示更新?
当我发布新的更新时会发生这种情况。Bukkit需要审核的更新。如果在48小时后还没有修复，你可以在Discord上反馈
四、打开菜单时出错但是我不知道怎么修复
使用/cpd将启用调试模式。下次尝试打开时会把详细的错误信息将载入服务器控制台。
如果您不确定错误代码的含义，请咨询Discord成员或者开发者
