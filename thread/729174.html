标题: mypet2.3.1玩家能无限切换技能树
普通玩家输入/pcst能无限切换技能树，每次切换只是宠物掉一级，怎么才能让玩家一只宠物只能选择一次技能树   1.8.8的服务器
作者: Saukiya    时间: 2017-9-21 10:39
在Mypet/config.yml 中

  2.   Skilltree:
  3.     AutomaticAssignment: false
  4.     RandomAssignment: false
  5.     InheritAlreadyInheritedSkills: false
  6.     ChooseOnce: false
  7.     PreventLevellingWithout: true
  8.     SwitchPenalty:
  9.       Fixed: 0.0
  10.       Percent: 20.0
  11.       Admin: false
复制代码

将ChooseOnce 这一行改为true 就可以只选择一次了。
你也可以选择下面的 SwitchPenalty ，Fixed为每次扣取固定的等级，Percent为扣取百分比等级(20%)
