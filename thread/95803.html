命令：
  1. # 帮助
  2. /chguser help [指令]
  3. # 重置玩家数量到正常值
  4. /chguser reset
  5. # 重载配置
  6. /chguser reload
  7. # 自动增加或减少玩家数量(减用"-"号)(服务器列表)
  8. /chguser autoadd [数量]
  9. # 设置永久在线玩家数(服务器列表)
  10. /chguser setplayers [数量]
  11. # 从服务器隐藏一个玩家
  12. /chguser hide [玩家名称]
  13. # 显示一个隐藏的玩家
  14. /chguser show [玩家名称]
  15. # 创建一个虚假玩家
  16. /chguser fake [玩家名称]
  17. # 移除一个虚假玩家
  18. /chguser remfake [玩家名称]
复制代码

解释一下autoadd和setplayers命令
这两个命令更改的都是服务器列表上显示的玩家数量
假设服务器目前有2个人，服务器列表显示的就是2
通过setplayers命令可以设置为300，这个300是固定的也就是绝对数量，无论后来加入或者离开多少人，这个数字都不会变化
而autoadd命令则是在当前玩家数量基础上，对玩家数量进行增减，比如chguser autoadd 100，服务器人数便会变成102，无论后来加入/离开多少人，人数都会在这个值上增加100。
当然，无论你怎么设置，服务器上都不会显示负数


权限：
  1. chguser.setplayers
  2. chguser.reset
  3. chguser.autoadd
  4. chguser.reload
  5. chguser.hide
  6. chguser.fake
复制代码

配置：

  1. # 玩家数量
  2. users: 0
  3. # 是否自动增加
  4. autoadd: true
