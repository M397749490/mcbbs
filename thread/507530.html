These days I'm doing a lot of UI design, the Win10 UI (and something in MCPE) isn't good and we want to fix it :D
这几天我在做一些UI的设计，Win10版的UI（和PE的一些）不怎么好，我们要修复它。 :D

Doing a UI that will work on touch, PC and controllers and well enough for everyone is a big bet, but maybe we can pull it off :D
为所有人做一个可以在触屏、电脑和手柄上都可以用的、足够好的UI是一个很大的赌注（挑战），但也许我们可以做到。 :D

Now I'm experimenting with drag&drop of items in PE, so you can rearrange them and choose the slot. And move them straight to the toolbar!
现在我正在尝试在PE版上拖拽物品，所以你可以重新排列它们并选择它们的位置，将他们直接移动到工具栏！
（意思是可以在背包或箱子里 拖拽物品来移动其位置 win10版已经支持）
