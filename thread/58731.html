规则

1. 请勿破坏任何东西
2. 请勿放置任何东西(除了按钮)
3. 使用和平模式
4. 切勿使用钻石以外的物品解锁提示
5. 请勿使用模组作弊或者使用第三方程式
6.回报漏洞丶翻译错漏，留下建议以及你的分数
7.请使用指定的材质包

多人游戏注意

你可能会在沙滩附近出生，游到附近，找找水底的萤光石，游上去会有入口。
攻略

注意: 解锁了全部的提示，才阅读攻略！


大宅 #1
请跳进火山并启动能源控制杆，
此举会开启岛上的所有门。

你可以透过休息室离开这个秘密实验室，

顺便看看火山里面的房间，里面埋藏了很重要的剧情。

回到大宅，铁门後的告示牌会给你对应符号的谜题的提示。

金字塔
正确组合为: 黑曜石，钻石，青金石，黄金

西洋棋
正确步法为：
1. h6 - c1
2. d8 - d2
2. d2 - d4

灯塔
正确组合为：
最右，最左，左中，右中

地下室
答案为： F-I-S-H

树林
正确路线为：
B-A-A-B-A-B-C-C

火把
说真的，你解不了这个？
每个按钮会转变两支红石火把，
你只需在一开始按下最左和最右的按钮。

遗迹
原文我也不知道什麽意思，
站在潜艇上面，把你所看到的东西画在纸上，
自己慢慢参详……


无穷
走过全部的传送门，
在最後的走廊里面，按下会推动矿车的按钮并快速地按掉馀下的按钮，
如果成功的话，门就会开启。


潜艇
解法是: 1350 + 1500 + 2300 + 2650 /2


洞穴
顺着以下的次序启动门前的按钮:- 第二高音
- 最低音
- 最高音
- 第二低音


大宅 #2
扳动你在五个谜题所看见的五个字母，
烧掉大宅的羊毛地图，进入隐藏通道。


结局
输入 Carter 的 身份证号码 (14682)
在车程後跳进天堂岛
进入瀑布後的洞穴，阅读最後的记录(地图)，决定你要做的东西
有秘密结局/坏结局
你需要自己寻找秘密结局，或许你找到的最後一次音效会给你提示……

*按钮可以放在绿色的方块上*
