标题: TreasureChest宝藏箱问题
小白在这里请教一下大神，不知道为什么我服务器的宝藏箱我设置一个，然后我把东西再拿走，玩家就打开是空的了，还有我设置宝藏箱每日奖励也是会这样。请教一下设置每人一次奖励的步骤和每日奖励的步骤是什么（指令）
作者: 枫卍梦话    时间: 2016-2-1 14:50
我回答你，正好这个插件我用几个月了。
首先你要给玩家权限：
treasurechest.access
允许玩家打开任何类型的宝藏箱
treasurechest.access.treasure
允许玩家开启宝藏箱
之后设置宝箱，放好东西后输入：/tchest set  设置宝箱   然后输入/tchest setforget 1 0 0 0 设置为每天可以刷新一次宝箱。
ok ！就这么简单。自己开小号测试吧，如果这样不行，说明你的配置改为了一个宝箱仅能一个人使用。改改配置就好
