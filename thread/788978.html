安装方法
在两个jar文件都放入plugins文件夹里之后，用Notepad打开你的运行.bat。就是那个启动服务器的东东(.bat)，找到这一行:
java xxxxx.jar
有的服务器可能是
java -Xmx1G -jar xxx.jar
无所谓，然后在java后面加一句:
-javaagent:plugins/MethodCall.jar
比如说
java -javaagent:plugins/MethodCall.jar xxxxx.jar
或者是
java -javaagent:plugins/MethodCall.jar -Xmx1G -jar xxxxxx.jar
然后启动服务器，安装完成

开发者部分
在ide中导入前置 "MethodCallPlugin"
首先，先在Plugin.yml里 depend: [MethodCall] 然后随便创建一个类，让他继承CallTask类，并实现public static Object onBeforeCall(Object instance)  方法，其中传入的instance变量是被调用方法的实例对象
import org.bukkit.craftbukkit.v1_11_R1.entity.CraftPlayer;

import com.locydragon.mc.api.CallTask;

public class MethodListener extends CallTask {
    public static Object onBeforeCall(Object instance) {
       return null;
    }
}

然后在onEnable调用MethodCallManager的静态方法addCallTask方法，监听一个方法:
MethodCallManager.addCallTask(Method 你监听的方法, CallTask 执行类); 这个方法不能是static方法
比如我们监听一个op方法
MethodCallManager.addCallTask(Class.forName("org.bukkit.craftbukkit.v1_11_R1.entity.CraftPlayer").getMethod("setOp", boolean.class), new MethodListener());

ok了，这样子当setOp方法执行的时候就会调用MethodListener的onBeforeCall方法，但是并不会拦截，怎么拦截呢？
注意:当 onBeforeCall 的返回值不是null时，监听的方法就会被拦截，否则将不会拦截，并且拦截的方法的返回值必须是void，不然会导致服务端逻辑混乱
所以我们只要
import org.bukkit.craftbukkit.v1_11_R1.entity.CraftPlayer;

import com.locydragon.mc.api.CallTask;

public class MethodListener extends CallTask {
    public static Object onBeforeCall(Object instance) {
       CraftPlayer who = (CraftPlayer)instance;
       System.out.println(who.getName()+"尝试修改op记录，已经拦截.");
       return new Object();
    }
}

即可。
