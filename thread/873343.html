标题: GroupManager问题
每当玩家重新进入服务器后，聊天框会显示you were moved to the group Default in all_unnamed_worlds 或者 world. 显示你的权限组被移动到了default组，而default组不可以使用money 那些普通指令，用/manuadd 玩家名 player all 重新进入服务器后还是这样，怎么办，想要固定玩家组都是player
作者: skyliye    时间: 2019-6-14 22:27
本帖最后由 skyliye 于 2019-6-14 22:43 编辑

修改Permissionstime插件中的配置文件：
# 默认权限组.
# Default permission group.
defaultGroup: Default

default改成player
不过你如果手动将玩家移到其他组还是会变回来，比如给了vip马上掉
建议参考插件发布贴来分配权限http://www.mcbbs.net/thread-707273-1-1.html
