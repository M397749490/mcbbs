梦开始的地方
要开始，你需要在.minecraft/mods目录下创建一个新的文件夹（注：建议此文件夹名称为你mod的名字，不可为中文）。在该文件夹中创建一个文件名为cs4mod.json并输入以下内容：
{

"id": "<你mod的名称，不可为中文>",

"name": "<你mod的名称，不可为中文>",

"version": "<你mod的版本>"

}

启动游戏，即可看到该文件夹下多出多个文件夹

添加mod简介
1.在该文件夹下创建一个【mcmod.info】文件

2.   然后用Notepad++（以后不说了,默认就用这个打开）

点击编码中的使用UTF-8编码（如果本来就是那就不用了）

（以后都用UTF-8编码，因为物品什么的中文是在lang文件里写【以后会讲】）

（只有cs4mod.json是用ANSI编码）

3.写上（前面的双引号内容不能改,后面的双引号("x")是需要自己填的,双引号一律不能删除）


[
         {
          "modid": "<cs4mod.json中的id>",
          "name": "<你mod的名字，可为中文>",
          "description": "<mod简介>",
          "version": "<mod版本>",
          "mcversion": "<构建此mod的Minecraft版本>",
          "url": "<mod主页，可为服务器官网>",
          "updateUrl": ""<更新网址>,
          "authorList": ["<作者>","<作者>"],
          "logoFile": "<mod的logo>",
          "screenshots": [],
          "dependencies": []
         }
]


到此，你的mod以初步成型了
创造物品栏？
创建一个物品，可以丢到mc自带的创造物品栏，
但，那样方便嘛？不方便，所以现在就来创建一个创造物品栏
1.   在你的mod文件夹下创建一个叫【main.json】的文件
2.   粘贴以下内容
{
  "content": [
    {
      "type":"creativeTab",
      "entries": [
        {
          "id": "creation",
          "icon": "minecraft:diamond_axe"
        }
      ]
    }
  ]
}
注释：
【"id"】此创造物品栏的内部ID，不可为中文、
【"icon"】此物品栏的图标，需为英文ID

而后，某种时候会出现你创建新的创造物品栏，但你所创建的物品不在这个物品栏里的情况
具体原因我也不知道，可能是某些设置的原因，也可能是cubex编写本体时所出现的共有bug
