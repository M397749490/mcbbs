标题: [娱乐]Kaboom——玩转地雷压力板[1.5.2]
今日插件搬运第四弹，压力板地雷来袭。

这个插件故名思议，就是用压力板做地雷，可用于PVP竞技。

直接上介绍


使用方法

1.拥有压力板，木质石质铁质金质各不同。
2.输入指令/kb toggle-开启防雷模式，再次输入关闭。
3.放置压力板。
4.踩上去。
5.Kaboom！！！



指令和权限

/kb help-显示Kaboom帮助
/kb toggle-开启/关闭放雷模式


kaboom.enable-允许使用Kaboom插件的功能



配置文件
  1. LandMine:
  2.   WOOD_PLATE:
  3.     Damage: 3.0  
  4. # 爆炸能量，TNT为4.0
  5.     SetFire: false
  6. #是否产生火焰
  7.     BreakBlock: false
  8. #是否破坏方块
  9.   STONE_PLATE:
  10.     Damage: 5.0
  11.     SetFire: true
  12.     BreakBlock: true
  13.   IRON_PLATE:
  14.     Damage: 7.0
  15.     SetFire: false
  16.     BreakBlock: false
  17.   GOLD_PLATE:
  18.     Damage: 10.0
  19.     SetFire: true
  20.     BreakBlock: true
