生存服
空岛服

空岛玩法：
空岛主要围绕 <物资少> <死亡掉落> <PVP> 为主题
1.新玩家可以在自己的岛屿发展
2.新玩家的岛屿1天内无法被传送
3.新玩家在这1天中在出生点需要做好保护措施
4.通过击杀其他岛屿玩家或者钓鱼来获得发展物资
友情提示：
输入is warp ID 可以传送到别人岛屿
输入is expel ID 可以赶走入侵你岛上的玩家
击杀对方可以斩获对方头颅，右键头颅可以传送至对方身边
生成怪物要求亮度为0 大小最低50*50
生成动物要求亮度为15 大小最低60*60
