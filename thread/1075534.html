作者: 22856139    时间: 2020-7-10 16:35
如果你用LuckPerms使用MYSQL报这个错误。应该修改配置文件config里面的这一部分
data:
  pool-settings:
    # This setting allows you to define extra properties for connections.
    properties:
      useUnicode: true
      characterEncoding: utf8
      useSSL: false
      verifyServerCertificate: false
