安装方法

Chrome请打开扩展程序页面（菜单——更多工具——扩展程序），开启开发者模式，再把插件文件拖进该页面即可。

Chrome 停用的扩展程序
以下信息仅面向 Windows 用户和 Mac 用户。
如果您看到“扩展程序已停用”这一消息，则表明系统已停用您的一个或多个扩展程序，以确保您在浏览互联网时的数据安全。
Chrome 停用的扩展程序要么并非来自 Chrome 网上应用店，要么是未经您许可就擅自安装的。
您可在 Chrome 中使用的扩展程序
为了安全起见，当您浏览网页时，Chrome 将仅允许您使用 Chrome 网上应用店中发布的扩展程序。
查看您的扩展程序列表
  • 在计算机上打开 Chrome。
  • 点击右上角的“更多”图标 。
  • 依次选择更多工具 扩展程序。
尚未在 Chrome 网上应用店中发布的扩展程序均以灰色显示，而且您无法重新启用它们。
使用已停用的扩展程序
如果需要使用某个已停用的扩展程序，您可以联系该扩展程序的开发者，让他们将该扩展程序上传到 Chrome 网上应用店。这样，您和其他 Chrome 用户便可通过 Chrome 网上应用店来安装该扩展程序；或者，如果您已经安装了该扩展程序，则可手动从您的扩展程序列表中重新启用它。
安全浏览互联网
详细了解 Chrome 如何保护您免受可能有害的扩展程序的威胁。
