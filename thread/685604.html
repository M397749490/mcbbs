插件特点Features
不一定是镐子！可以设置任何物品！
刷怪笼之锄刷怪笼之斧刷怪笼之皂

可自定义镐子耐久，能挖几个刷怪笼？
“腐竹！我买的刷怪笼镐挖了一下就爆了！”

权限限制，没有权限用不了！
“听说你的稿子能挖刷怪笼？借我用用！”“怎么用不了？”

自定义木牌购买，方便快捷！
需Vault插件作为前置

1.7.10-1.11全部种类刷怪笼支持！
有个毛用！野生的刷怪笼不还是那几种吗！

[新1.3版本]刷怪笼商店！自由选定耐久

指令Commands
  • /pspawner <玩家> <耐久次数> : 获得一把刷怪笼之镐，<玩家>缺省默认是你自己，<耐久次数>缺省默认是1
  • /spawner <怪物名称> <玩家> : 直接给某玩家一个某种类刷怪笼
  • /spawner list : 列出所有种类刷怪笼
  • /pspawner reload : 重载插件
  • /pspawner help : 指令帮助
  • [新1.3版本]/pspawner shop : 打开刷怪笼镐商店

权限Permissions
  • spawnerpickaxe.use : 使用刷怪笼之镐
  • -------------------------------后面的不用看了--------------------------------
  • spawnerpickaxe.give : 允许给玩家一把刷怪笼之镐
  • spawnerpickaxe.spawner : 允许给玩家刷怪笼
  • spawnerpickaxe.sign : 允许创建木牌商店
  • spawnerpickaxe.reload : 重载插件
  • spawnerpickaxe.help : 显示帮助

安装方法Setup
本插件需要Vault经济插件作为前置（不过我猜是个服务器都安装了吧……）
下载jar文件，扔进plugins文件夹，启动服务器，关闭服务器，把帖内汉化好的配置文件放进plugins/SpawnerPickaxe文件夹内，重启服务器

如何设置木牌购买？How to buy
创建一个木牌，第一行写[PSPAWNER]大小写不限
第二行写价格，即可创建一个木牌购买商店
[新添加]第三行可写刷怪笼镐耐久(缺省默认是1)

还有疑问？Any question?
问：刷怪笼之镐能附魔吗？能不能通过铁砧修理回复耐久？
答：刷怪笼之镐的“耐久”指的是次数，不是物品耐久，用的次数多了再修也修不回来，可以附魔，但是附魔毫无意义
问：为什么我放置不了刷怪笼？
答：检查Essentials的config.yml，看看是不是把刷怪笼放置禁止了，或者刷怪笼被banitem禁止了
问：使用/pspawner指令时根本无法获得，而且后台报错？
答：音效配置问题，默认音效只适合1.8及以前版本服务器，如果你开的是1.9+服务器，请立刻至config中修改，或者直接禁止音效（帖内的config默认就是关闭音效的）
问：我想上报BUG或者提建议？
答：欢迎大家上报BUG或者提建议，我将第一时间反馈给作者
