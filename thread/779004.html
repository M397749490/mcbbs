材质包这个位置assets\minecraft\models\item
新建名为diamond_axe文本，修改后缀为json，打开并输入以下，保存
  1. {
  2.   "parent": "item/handheld",
  3.   "textures": {
  4.     "layer0": "items/diamond_axe"
  5.   },
  6.   "overrides": [
  7.     { "predicate": {"damaged": 0, "damage": 0}, "model": "item/diamond_axe"},
  8.     { "predicate": {"damaged": 0, "damage": 0.0006402048655569782}, "model": "block/custom/a"},
  9.         { "predicate": {"damaged": 0, "damage": 0.0012804097311139564}, "model": "block/custom/b"},
  10.     { "predicate": {"damaged": 0, "damage": 0.0019206145966709346}, "model": "block/custom/c"},
  11.     { "predicate": {"damaged": 1, "damage": 0}, "model": "item/diamond_axe"}
  12.   ]
  13. }
复制代码

然后材质包assets\minecraft\models\block\custom位置下，新建a.json，b.json，c.json

a.json输入如下，保存。b.json和c.json同理
  1. {
  2.     "parent": "item/handheld",
  3.     "textures": {
  4.         "layer0": "items/custom/a"
  5.     }
  6. }
复制代码

最后，游戏里获取a
  1. /give @p minecraft:diamond_axe 1 1 {Unbreakable:1b}

把那个json进行修改，例子
  1. {
  2.     "parent": "builtin/generated",
  3.     "textures": {
  4.         "layer0": "custom/cb/cbico"
  5.     },
  6.     "display": {
  7.         "thirdperson_righthand": {
  8.             "rotation": [ -90, 0, 0 ],
  9.             "translation": [ 0, 1, -3 ],
  10.             "scale": [ 0.55, 0.55, 0.55 ]
  11.         },
  12.         "firstperson": {
  13.             "rotation": [ 0, -135, 25 ],
  14.             "translation": [ 0, 4, 2 ],
  15.             "scale": [ 1.7, 1.7, 1.7 ]
  16.         }
  17.     }
  18. }
复制代码
display下定义thirdperson_righthand(第三人称右手), thirdperson_lefthand(第三人称左手), firstperson_righthand(...), firstperson_lefthand, gui, head, ground, 或fixed

rotation为旋转，translation为位移，scale为各轴大小
https://minecraft-zh.gamepedia.com/%E6%A8%A1%E5%9E%8B

scale变大完后，修改rotation和tralslation的数值进行显示调整，游戏内F3+T重新加载材质。
或者你可以用blockbench软件，进行可视化修改。
