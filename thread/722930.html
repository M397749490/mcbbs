插件指令：
/medals 打开称号菜单
/medals list 列出可用称号
/medals create 创建一个称号
/medals delete 删除一格称号


插件权限：
只有2个
mmedal.admin
管理员权限
mmedal.<ID>给予玩家使用这个ID的悬浮称号

如何使用：
2种方法：
一使用指令/medals create id 自定义称号内容 物品英文ID
二编辑后台medals.yml
  1. medals:
  2.   example:
  3.     display: '&b&l测试测试'
  4.     icon: STONE
  5.     data: 0 </div>
复制代码
这个就是范例中的悬浮称号设置
其中，icon必须是英文id
example仅仅是一个id，就像rpgitem中的id
推荐使用第二种，因为第一种不能使用彩色字体
