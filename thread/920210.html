首先 你得设置刷怪点
  1. /mm s create [刷怪点名称] [怪物代码]
  2. 指着的方块输入指令，指着的方块就会变成刷怪点

  4. /mm s copy [A刷怪点名称] [B刷怪点名称]
  5. 复制之前设置的刷怪点，可以省下很多时间。

  7. /mm s delete [刷怪点名称]
  8. 刪除指定的刷怪点。


  11. /mm s info [刷怪点名称]
  12. 查看指定的刷怪点的资料。


  15. /mm s listnear <范围>
  16. 查看在范围内有多少MyThicMob的自定义刷怪点。


  19. /mm s set [刷怪点名称] [属性] [变量]
  20. 设定指定的刷怪点的属性，比如说刷怪点的刷怪时间，下面我会详细介绍。

  22. /mm s addcondition [刷怪点名称] [生成的条件] [变量]
  23. 设定刷怪点的生成条件，下面我会说。


  26. /mm s removecondition [刷怪点名称] [生成的条件]
  27. 删除刷怪点的生成条件。


  30. 我们在上面提到的刷怪点的属性
  31. /mm s set [刷怪点的名称] [属性] [变量]
  32. 什么是刷怪点的属性呢？这些属性又有什么用？
  33. 其實說特殊設定也可以，因為它真的很像特殊設定

  35. cooldown:
  36. 刷怪点的冷却时间，就是怪物死了后多久会再次刷怪，以秒为计。


  39. leashrange:
  40. 刷怪点的怪物可以离自己的生成点多远，设0的话为无限距离。

  42. maxmobs:
  43. 这个刷怪点"最多（最大值）"可以生成多少个怪物？


  46. warmup:
  47. 刷怪点每隔几秒会生成一个怪物，和cooldown不一样，你们自己探索一下。

  49. mobsperspawn:
  50. 刷怪点"一次生成"多少怪物？
  51. 例：设定为5的话就是一次生成5个怪物，而不是一个一个的生成。
