需求

旧版
然后手机登入 https://play.google.com/store/ap ... id.remotecontroller 下载应用！
注意，你需要注册一个Gmail才能下载！

搬运 by tknw2012

http://pan.baidu.com/s/1l9oJ6

1

指令&权限
指令简写描述
- /remotecontroller-user add <用户名> <密码>/rcu add添加控制账户
- /remotecontroller-user remove <用户名>/rcu remove移除控制账户
- /remotecontroller-user list/rcu list列出控制账户
- /remotecontroller-reload/rcr重载
- /remotecontroller-summon/rcs向服务器管理发送请求

权限描述
- remotecontroller.user允许使用 "/remotecontroller-user"
- remotecontroller.reload允许使用 "/remotecontroller-reload"
- remotecontroller.summon允许使用 "/remotecontroller-summon"

旧

指令简写描述
- /remotecontroller-user add <用户名> <密码>/rcu add创建一个控制用户
- /remotecontroller-user remove <用户名>/rcu remove移除用户
- /remotecontroller-user list/rcu list列出所有控制用户.
- /remotecontroller-reload/rcr重载配置

配置文件
项目默认描述
Languagedetect使用的语言.(如 en, ja, 等...) 如果设置"detect", 插件会根据电脑语言进行自动选择
Port25570手机端连接端口
MaxLog100手机端接受最多日志信息
MaxChat100手机端接受最多聊天信息
EditableExtension-yml -txt远程可编辑文件类型.
EnableDynmaptrue是否开启卫星地图（不建议使用）. ("true"开启, "false"关闭)
DynmapAddress""卫星地图地址. 以下情况会发生错误：无法获取卫星地图端口, 或地址没有包含端口 (如 "http://dynmap.yourminecraftserver.net"). 必须以 "http://"开头
ConsoleOnlytruetrue: 只能在控制台使用 "/rcu add"  "/rcu remove" 这种指令.
false: 任何游戏内的OP都能用.
FileAccess
标记文件可以/不可以读取或写入. 查看 here
NotificationMax100手机端保存的最大提示信息
NotificationIncludeWarnLogLevelfalsetrue: 当 "WARN"日志出现, 将会发送到手机端
false: 不发送任何 "WARN"日志
Icon
在窗口显示服务器图标
SummonCommandAlias
当前不可用.

  1. Port
  2. Using port to connect client.

  4. MaxLog
  5. Max size of saved log that send cilent.

  7. MaxChat
  8. Max size of saved chat that send cilent.

  10. Language
  11. Using language.(en, ja, etc...)

  13. EditableExtension
  14. Editable extension of file from remote.

  16. ChatPrefix
  17. Prefix of chat from remote client.(Can use colorcode.)
