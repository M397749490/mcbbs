首先给指定僵尸加一个tag，便于选中，此处以boss为例

建立一个boss栏，设定其id为zombie
/bossbar add zombie "zombie"

然后设定其最大值为僵尸血量
/bossbar set zombie max 20

当需要显示boss栏时，设置boss栏所有玩家可见，并循环获取僵尸血量
#以下命令执行一次
/bossbar set zombie players @a
#以下命令循环执行
/execute store result bossbar zombie value run data get entity @e[type=zombie,tag=boss] Health
