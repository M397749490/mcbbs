MonthlyCard 月卡插件灵感来自于某公司网游
可以根据玩家充值点券的数量来升级月卡，月卡不同奖励不同，支持每日领取奖励，支持Mysql及PlaceholderAPI变量
关于 MonthlyCard 未来计划
1.Mysql支持 √ 已实现
2.每日月卡奖励 √ 已实现
3.如果有其他想法可以私信与我反馈
MonthlyCard 图示 与 视频

MonthlyCard 指令 与 变量
/emc edit <give/set/take> <playername> <cardname> <value> -修改玩家月卡点数
/emc remove <playername> <cardname> -删除玩家月卡
/emc info <playername> -查询玩当前家月卡状态
/emc reload -重载插件配置
/emc activation <playername> <cardname> -激活玩家月卡

 %emc_月卡昵称% 月卡状态
%emc_月卡昵称_kit% 礼包状态
MonthlyCard 配置
  1. SQL:
  2.   Enabled: false
  3.   DataBaseName: 'null'
  4.   Host: 127.0.0.1
  5.   Port: 3306
  6.   User: root
  7.   Password: password
  8. TimeFormat: "yy年MM月dd日 HH:mm"
  9. Placeholder:
  10.   Activation:
  11.     'On': "&6到期时间: &d{0}"
  12.     'Off': "&c未激活: &6{0}/&d{1}"
  13.   Kit:
  14.     'On': "&6已领取"
  15.     'Off': "&c未领取"
  16. Card:
  17.   Silver:
  18.     Value: 3000 #当玩家充值的点券达到这个数值时激活这个月卡
  19.     Command:
  20.     - '[CONSOLE]give %player% 264 5'
