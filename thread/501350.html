介绍
在Minecraft中使用标题命令老是遇到麻烦吗?
或者你只是懒得使用JSON slighty复杂语法向玩家展示一个简单的文本的屏幕吗?
所以TitleSender只为你在这里!只为你!
这个插件提供了由两个简单的命令来显示一个文本,即使颜色或下划线,加粗,无论你想要什么,都能呈现在玩家的屏幕上!
您甚至可以设置一个欢迎消息,当玩家进入你的服务器时发送!(修改config.yml文件)
如果你想给文字赋予颜色/效果，可以使用颜色代码的“语法”。
像&a&1&2等等
如,急症室等（等等，什么鬼？）
命令
/ts -使用方法:/ts <玩家> <文本>…(您可以使用空间的文本框和颜色代码)——在玩家的屏幕中心显示文本
/sts -使用方法:/sts <玩家> <文本>…(您可以使用空间的文本框和颜色代码)——设置一个副标题连同/ts发送命令
权限
titlesender：
发送权限：
只有拥有此权限的玩家(或OP玩家)才可以使用上面的命令。

欢迎信息的配置
配置文件即为config.yml，
请使用文本的方式打开它，
我们将看到以下文字

默认信息：
on-join: false
title: Welcome
subtitle: In Minecraft

解释：
on-join ：是否开启
title ：发送文本的标题
subtitle ：发送文本的内容

PS：
只要玩家进入服务器就会显示这些东西，
你可以随便修改，
如果使用默认也可以。

原文
Always had troubles with the /title command from Minecraft Vanilla?Or you just aren't cool using slighty complex JSON syntax just to show a simple text to a player's screen?Then TitleSender is here for you! Made by a person like you, only for you!
This plugin offers you just two simple commands to show a text, even colored or underlined, bold, whatever you want, to a player's screen! You can even set a Welcome message, when the player enters in your server! (Modify the config.yml file)
To set colors / effects you can use the Essentials "syntax" for color codes. Such as &a, &e etc. (Google for more colors typing Minecraft Essentials colors)
Commands
/ts - Usage: /ts <player> <text>... (You can use spaces in the text field and color codes) - Displays that text in player's center screen
/sts - Usage: /sts <player> <text>... (You can use spaces in the text field and color codes) - Sets a subtitle to be sent along with the /ts command
Permissions
titlesender.send - Only players with this permission (or OP players) can use the above commands.
