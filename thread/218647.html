用Minecraft Query获取服务器信息

        大家好，我是某个犯过大错的人~从此不断将功补过中 QwQ
        教程适用于有一点php基础或有一些其他编程语言基础的人，请注意！看不懂的话请先补一下基础！
        今天我为大家带来了Minecraft php Query 教程，主要是用php语言获取Minecraft服务器信息！php语言不用多说了，这个多么常见多用途的服务器端编程语言（剩下请自行百度知道）。。。闲话少说，进入正题。
        简单的说，获取Minecraft服务器信息有2个方法。第一个方法是直接获取服务器信息，这种方式的原理和Minecraft客户端读取服务器列表信息相同，此方式的优点是代码简单易懂，暴力好用，缺点是只能获取服务器名称，Motd以及玩家数量。第二种方式是使用DinnerBone提供的MinecraftQuery方式，此种方式需要在服务器配置文件server.properties中enable-query设为true。此种方式优点是可以获得更全面的服务器信息，比如玩家列表，地图名称等，缺点是这个可以得知服务器内插件，服务器具体版本！这些信息可能为重要并且需要保密的信息，enable-query之前需要务必考虑清楚。
        本教程分为2个部分，暂时更新到第一部分。
第一部分：直接获取服务器信息。
        首先请大家看一下这个QueryMinecraft的API，来自这里。
  1.         function QueryMinecraft( $IP, $Port = 25565, $Timeout = 2 )
  2.         {

  4.                 $Socket = Socket_Create( AF_INET, SOCK_STREAM, SOL_TCP );
  5.                 Socket_Set_Option( $Socket, SOL_SOCKET, SO_SNDTIMEO, array( 'sec' => (int)$Timeout, 'usec' => 0 ) );
  6.                 Socket_Set_Option( $Socket, SOL_SOCKET, SO_RCVTIMEO, array( 'sec' => (int)$Timeout, 'usec' => 0 ) );
  7.                 if( $Socket === FALSE || @Socket_Connect( $Socket, $IP, (int)$Port ) === FALSE )
  8.                 {
  9.                         return FALSE;
  10.                 }
  11.                 Socket_Send( $Socket, "\xFE\x01", 2, 0 );
  12.                 $Len = Socket_Recv( $Socket, $Data, 512, 0 );
  13.                 Socket_Close( $Socket );
  14.                 if( $Len < 4 || $Data[ 0 ] !== "\xFF" )
  15.                 {
  16.                         return FALSE;
  17.                 }
  18.                 $Data = SubStr( $Data, 3 );
  19.                 $Data = iconv( 'UTF-16BE', 'UTF-8', $Data );
  20.                 if( $Data[ 1 ] === "\xA7" && $Data[ 2 ] === "\x31" )
  21.                 {
  22.                         $Data = Explode( "\x00", $Data );
  23.                         return Array(
  24.                                 'HostName'   => $Data[ 3 ],
  25.                                 'Players'    => IntVal( $Data[ 4 ] ),
  26.                                 'MaxPlayers' => IntVal( $Data[ 5 ] ),
  27.                                 'Protocol'   => IntVal( $Data[ 1 ] ),
  28.                                 'Version'    => $Data[ 2 ],
  29.                         );
  30.                 }
  31.                 $Data = Explode( "\xA7", $Data );
  32.                 return Array(
  33.                         'HostName'   => SubStr( $Data[ 0 ], 0, -1 ),
  34.                         'Players'    => isset( $Data[ 1 ] ) ? IntVal( $Data[ 1 ] ) : 0,
  35.                         'MaxPlayers' => isset( $Data[ 2 ] ) ? IntVal( $Data[ 2 ] ) : 0,
  36.                         'Protocol'   => 0,
  37.                         'Version'    => '1.3',
  38.                 );
  39.         }
复制代码

        看过之后我们可以看出来，这个东西吃三个参数：$IP，$Port，$Timeout分别代表IP（域名，localhost也可使用），端口（默认25565）和超时时间（默认2秒）。返回一个Array，里面带有HostName（服务器名称），Players（玩家数量，是数量！），MaxPlayers（最大玩家数量），Protocol（无视，没用）和Version（服务器版本）。
好的，既然这样我们做一个实验，利用这个代码写一个小php程序。
  1. $mcserverip = server.example.com //服务器地址！
  2. $mcserverport = 25565 //好习惯，好习惯而已。。。
  3. $array = QueryMinecraft($mcserverip ,$mcserverport); //调用API
  4. $servername = $array['HostName']; //服务器名称
  5. $maxplayers = $array['MaxPlayers']; //最大玩家数量
  6. $onlineplayers = $array['Players']; //当前玩家数量
  7. $serverversion = $array['Version']; //服务器版本
  8. echo "服务器名称：" . $servername
  9. echo "服务器玩家：" . $onlineplayers . '/' . $maxplayers
  10. echo "服务器版本：" . $serverversion
复制代码

        这样的结果就是大概这个样子的（输出举例）：
        服务器名称：我的狂拽服务器
        服务器玩家：32/998
        服务器版本：1.6.4
