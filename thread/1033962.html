# 设置宝可梦生成多少。

    # 改变一个神兽生成的几率 (0-1)。
    legendarySpawnChance=0.500000011920929
    # 神兽的平均生成时间(随生成率改动)。
    legendarySpawnTicks=1900

楼上已经说的很清楚了，那我就再提示（真滴不是水贴）一下，生成几率是百分比的，比如你设置0.6就是60%，1就是100%，然后生成时间是按照tick计算的，1s=20tick，望注意，最佳答案给楼上就行了
