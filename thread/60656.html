又到了发整合包的时候了冶金2mod
1.基础金属

新增：
铜，锡，锰，青铜，幽魂结晶，神圣之金，大马士革钢，钢。
（图中左三是天然矿，右五是合成矿。）

说明：
这些矿物是介于石头和钻石工具之间的矿物。
钢的效率和钻石一样，但是耐久度稍微低一点。

合成：
铜 + 锡 = 青铜
青铜 + 金 = 幽魂结晶
铁 + 金 = 神圣之金
铁 + 青铜 =大马士革钢
铁 + 锰 = 钢


2.贵重金属

新增：
锌，黄铜，银，琥珀金，铂金
（图中左三天然矿，右二合成矿，接下来都是如此。）

说明：
贵金属与黄金类似。
优势在于附魔强度较强，但是耐久度偏低。
贵金属另外一个用处就是用于造币。
钱币可以用于和村民交易（绿宝石......）

合成：
铜 + 锌 = 黄铜 （需要基础金属）
金 + 银 = 琥珀金


3.地狱金属

新增：
伊格内休斯, 暗影铁, 利莫利亚, 暗影钢, 溶火金, 幽冥剧毒结晶, 暗影秘银, 神秘蓝金, 自然女神的眷恋, 幽冥魂石, 魔力之石, 熔岩结晶, 狱炎石

说明：
只有地狱才能挖得到的矿物，所做出来的工具的强度范围很大。
从中等强度到比钻石还要强的强度。
有些矿物有其他用途，比如伊格内休斯和熔岩结晶矿可以当做燃料。

合成：
暗影铁 + 利莫利亚 = 暗影钢
暗影秘银 + 神秘蓝金 = 自然女神的眷恋
幽冥魂石 + 铂金 = 魔力之石 （需要贵金属）
暗影铁粉 + 伊格内休斯粉 = 铁粉


4.幻想金属

新增：
秘银, 深铁, 精金, 黑钢, 大地结晶, 希尔金, 星辰银, 闪耀金, 幻之金, 褐铜, 水银, 幻之铜, 自然之石, 幽冥毒结晶, 血石, 深金, 熔火之石。

说明：
幻金属的强度层出不穷，低至仅有石器程度的强度，高至媲美末地矿做出来的工具的强度。
附魔效率比默认要高，但比同阶金属比起来更为稀有。
幻金属还用于萃取，下面会讲。

合成：
深铁 + 精金 = 黑钢
幻之金 + 银 = 水银 （需要贵金属）
幻之金 + 褐铜 = 幻之铜
自然之石 + 铂金 = 幽冥毒结晶 （需要贵金属）
血石 + 深金 = 熔火之石
秘银粉末 + 深铁粉末 = 铁粉


5.末地金属

新增：
虚空石, 龙之魂石, 虚空之魂石

说明：
只能在末地挖到。
虚空石的强度与钢相当。
龙之魂石是催化金属，和虚空石合成虚空之魂石，灰常强大的金属。
