今天的第三篇插件搬运帖子，累死洒家了~
刚刚买了个正版，填ID的时候发现我的名字被人（还是被我自己？）给用了，万分桑心QAQ


好吧进入正题，这又是一个轻量的插件，刚刚看了wolski发的帖子，这特么多久没更新了？于是我果断的，妥妥的，就搬了最新的3.6.1版并且汉化了，呵呵呵= =




作用：当球员【雾，是Player（雾，是玩家）】说脏话后，可选：直接T掉，把屏蔽字替换成其他的字符（如CF里的**，CSOL里的※※），或整句话替换成指定文字（如ER服的“我是个爱说脏话的小学生，大家不要学我！”）




配置文件config：
  1. ###########################################################
  2. ##     脏话屏蔽  V3.6.1    配置文件汉化BY Legend_Kun      ##
  3. ###########################################################

  5. #        选项中， false=不会或不是   true=会或是

  7. # 玩家说脏话时会不会被Kick
  8. KICK_ON_SWEAR: false

  10. # Kick的理由.如果不开启Kick，就是玩家说脏话时发给玩家的信息。 可以为中文字符
  11. KICK_MESSAGE: '&4脏话在这个服务器是禁止的!'

  13. # 玩家说脏话时是否以玩家为源头生成一个无伤害的爆炸
  14. EXPLOSION_ON_SWEAR: true

  16. # 当一句话中出现屏蔽词的时候，是否用<NEW_MESSAGE>替换掉玩家说的那一整段话
  17. REPLACE_MESSAGE: false

  19. # 句子中的屏蔽词是否用<NEW_MESSAGE>替换，其余部分依然显示。上面的选项为false了这个设置才有效
  20. BEEP_WORD: true

  22. # 玩家说脏话时在控制台上显示的信息，<player>为玩家名称
  23. COMMAND_ON_SWEAR: warn <player>

  25. # 用来替换脏话/句子的词/句
  26. NEW_MESSAGE: ※※

  28. # 默认屏蔽词列表，可修改
  29. list:
  30.   - ass
  31.   - fuck
  32.   - shit
  33.
