怎么把设置领地插件圈地大小？
作者: Littlebear    时间: 2013-6-15 20:42
本帖最后由 Littlebear 于 2013-6-15 21:30 编辑
  1. Residence:
  2.            # 玩家是否可以创建领地.这个设置可被 'residence.create' 权限覆盖.
  3.            CanCreate: true
  4.            # 玩家允许拥有最大领地数.
  5.            MaxResidences: 8
  6.            # 一个领地的最大物理区域数目.
  7.            MaxAreasPerResidence: 2
  8.            # 一个领地在东西方向最大距离 (X坐标).
  9.            MaxEastWest: 3000
  10.            # 一个领地在南北方向最大距离 (Z坐标).
  11.            MaxNorthSouth: 3000
  12.            # 一个领地在上下方向最大高度 (Y坐标).
  13.            MaxUpDown: 3000
  14.            # 允许创建领地的最低高度.
  15.            MinHeight: 0
  16.            # 允许创建领地的最高高度.
  17.            MaxHeight: 255
  18.             # 子区域领地最大深度.
  19.             # 当一个领地子区域包含另一个子区域时,最大深度为2.
  20.             # 设置为0将禁用领地子区域.
  21.            SubzoneDepth: 3
  22.            # 是否允许传送到领地.
  23.            CanTeleport: true
  24.            # 是否允许使用'/res unstuck'命令, 当你卡在领地内时可以传送出去
  25.            Unstuck: true
  26.            # 是否允许使用'/res select '命令, 如果禁用,那么只能使用工具选取领地.
  27.            SelectCommandAccess: true
  28.            # 领地主人是否允许使用 黑名单/屏蔽列表 .
  29.            ItemListAccess: true
  30.        # 进入和离开领地时的消息设置.
