TeleportTitle


该插件已停止维护

这是一个轻量的插件，理论上兼容任何传送插件。op可以通过命令设置“传送标题 "，当玩家通过任何传送命令（如Essentials的spawn、warp等）到达这个标题所绑定的位置后，就会在屏幕正中央显示设定好的标题（如图）。

命令
命令 说明
/telet add <标题文本> [x y z] [世界] 在指定位置添加指定的传送标题，缺省项将以玩家所在位置为准，<标题文本>支持颜色符号&（与安装Essentials后的彩色聊天一致）
/telet del [x y z] [世界] 删除指定位置上的所有传送标题，缺省项将以玩家所在位置为准
/telet confirm 确认, 仅在使用了命令 /telet del 后可用
/telet list [世界] [x y z] 列出指定位置上的所有传送标题，缺省后将输出全服信息
/telet reload 重新读取配置文件，未保存的更改会丢失
/telet save 保存到配置文件（关服时会自动保存）

权限
节点 说明 默认拥有者
teleporttitle.command 使用上述所有命令 op
teleporttitle.showtitle 能够看到传送标题 所有人

配置文件
请注意文件编码，若中文显示乱码请更换编码为UTF-8
基本上不需要修改配置文件
就先放这里了
  1. # 格式
  2. #  - <世界名>,<x坐标>,<y坐标>,<z坐标>|<title原Json内容>
  3. # 常用符号
  4. # %player% - 在显示时会替换为玩家ID
  5. # \u00A7 - 样式代码，用于显示彩色文字。在配置文件中使用\u00A7或§，在命令中使用&

  7. messages:
  8.   - world,0,100,0|"\u00A7b你好啊 \u00A76%player%"
