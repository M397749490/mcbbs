#1./scoreboard objectives add SMFX minecraft.custom:minecraft.damage_dealt
创建一个造成伤害的计分板，这条在聊天栏输入即可

#2./scoreboard objectives add Aezning minecraft.custom:minecraft.damage_taken
创建一个承受伤害的计分板，这条在聊天栏输入即可

#3.give @p minecraft:diamond_sword{Tags:["SMFX"]} 1
给玩家一把特殊的剑，可编辑其特殊NBT，如果过长请在命令方块或者function内输入

#4.tag @a[nbt={SelectedItem:{tag:{Tags:["SMFX"]}}}] add SMFX
给持有特殊剑的玩家一个tag，此命令需要参照上图高频执行

#5.execute as @a[tag=SMFX,scores={SMFX=1..}] at @s run execute as @a[distance=..6,tag=!SMFX,limit=1,scores={Aezning=1..}] at @s run summon minecraft:lightning_bolt
当持有特殊剑的玩家造成伤害，并且周围半径6格内有玩家受到伤害，就在他的位置召唤一个闪电，此命令需要参照上图高频执行

#6.scoreboard players set @a SMFX 0
将SMFX计分板设置为0，此命令需要参照上图高频执行

#7.scoreboard players set @a Aezning 0
将Aezning计分板设置为0，此命令需要参照上图高频执行

#8.tag @a remove SMFX
移除SMFX的tag，此命令需要参照上图高频执行

需要三个命令方块在那里持续召唤闪电,下面放指令第一个：/execute @e[type=Arrow] ~ ~ ~ summon LightningBolt ~ ~ ~第二个：testfor @e[type=Arrow,c=1] {inGround:1b}第三个：/kill @e[type=Arrow]探测刚刚射出去的弓箭有没有着地，要连上高频电路，后面再连一个比较，两个中继的输出，连到/kill 弓箭，就会把持续召唤闪电的弓箭清除掉  作者：某龙 链接：https://www.zhihu.com/question/312305528/answer/598620169 来源：知乎 著作权归作者所有。商业转载请联系作者获得授权，非商业转载请注明出处。
