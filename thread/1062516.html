安装好这个前置后
再自己开个mcfunction
内容如下
  1. execute at @s positioned ^ ^ ^5 run summon area_effect_cloud ~ ~ ~ {Tags:["mrcd_mark","mrcd_block"],Duration:100}
  2. execute as @e[tag=mrcd_mark] store result score @s mrcd_x0 run data get entity @s Pos[0] 1000
  3. execute as @e[tag=mrcd_mark] store result score @s mrcd_y0 run data get entity @s Pos[1] 1000
  4. execute as @e[tag=mrcd_mark] store result score @s mrcd_z0 run data get entity @s Pos[2] 1000
  5. execute store result score #var0 mrcd_system run data get entity @s Pos[0] 1000
  6. execute store result score #var1 mrcd_system run data get entity @s Pos[1] 1000
  7. execute store result score #var2 mrcd_system run data get entity @s Pos[2] 1000
  8. scoreboard players operation @e[tag=mrcd_mark,limit=1] mrcd_x0 -= #var0 mrcd_system
  9. scoreboard players operation @e[tag=mrcd_mark,limit=1] mrcd_y0 -= #var1 mrcd_system
  10. scoreboard players operation @e[tag=mrcd_mark,limit=1] mrcd_z0 -= #var2 mrcd_system
  11. execute at @s anchored eyes positioned ^ ^ ^ run tp @e[tag=mrcd_mark,limit=1] ~ ~ ~ ~ ~

  13. execute as @e[tag=mrcd_mark,limit=1] at @s run function mrcd:generic/start
  14. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=0] run title @a title "小麦：状态1"
  15. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=1] run title @a title "小麦：状态2"
  16. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=2] run title @a title "小麦：状态3"
  17. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=3] run title @a title "小麦：状态4"
  18. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=4] run title @a title "小麦：状态5"
  19. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=5] run title @a title "小麦：状态6"
  20. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=6] run title @a title "小麦：状态7"
  21. execute as @e[tag=mrcd_mark,tag=mrcd_touch_edge] at @s if block ~ ~ ~ wheat[age=7] run title @a title "小麦：状态8"
  22. tag @e[tag=mrcd_mark] remove mrcd_mark
复制代码
然后再execute as @a高频执行你写的function就欧克了
当然，显示效果可以改那一长坨title命令来达到你要的效果
