介绍：
本插件是一款基于Economy经济API的贩卖插件，与EconomySell对应。

使用：
将前置插件与本插件一起扔到服务端plugins文件夹里，重新启动服务器即可。

命令：
命令
权限
说明
/shop create [物品id[:附加数据值]] [数量] [价格] [方向]economyshop.command.shop.create创建贩卖实体
/shop removeeconomyshop.command.shop.remove移除贩卖实体
/buy [数量]economyshop.command.buy购买物品

权限：
权限
说明
economyshop.*包括EconomyShop的所有权限
economyshop.break允许玩家破坏贩卖实体
economyshop.command.*允许玩家使用EconomyShop的所有命令
economyshop.command.shop.*允许玩家使用/shop命令
economyshop.command.shop.create允许玩家使用/shop create命令
economyshop.command.shop.remove允许玩家使用/shop remove命令
economyshop.command.buy允许玩家使用/buy命令
economyshop.create允许玩家创建贩卖实体
economyshop.purchase允许玩家购买物品

配置：
config.yml
  1. data:
  2.   save-on-change: true
  3. #自动保存
  4. language: zh
  5. #语言
  6. #内置en(英语)、jp(日语)、ko(韩语)、ru(俄语)
  7. #zh(中语)为汉化
  8. purchase:
  9.   tap-twice: true
  10. #是否启用双击确认
  11.   enable-buy: true
  12. #是否启用贩卖命令
  13. destroy:
  14.   block: true
  15. #是否允许破坏方块
