     插件介绍

  KitPvP 是一款 PvP大乱斗 类型小游戏, 玩家需要选择自己的职业在场地中进行战斗,
  来提升自己的职业等级和段位, 这是一场争夺职业战争排行榜榜位的战争.
  插件想法及排版提供者 @归尘. 插件开发者 @白

  当前版本为初版, 可能会有些 Bug, 可前往 Github 提交 issue 或者在帖子下方回复.

  KitPvP 特点

  • 支持服主自行增加多种职业
  • 各类职业支持自定义物品及介绍
  • Gui 菜单, 让你释放双手
  • 高度自定义的提示文本
  • 支持多地图列表 (玩家可选/随机)
  • 自定义道具恢复血量
  • 自定义击杀获得的奖励
  • 默认金币及默认礼盒数
  • Gui 按钮/标题/提示 完全自定义
  • 独立玩家游戏信息面板
  • 自定义击杀 / 死亡提示


     基础帮助

  如何使用
  下载插件, 将下载后的 jar 文件装入服务器 plugins 目录, 重启服务器
  输入 /kp setend 设置结束点, 在 config.yml 内设定地图 (不用担心不会, config. yml 有注释)
  输入 /kp menu 打开菜单, 开始你的职业战争之旅

  玩家命令 / 管理命令
  # 玩家命令 ( [] 内为可选参数 )
  /kp menu - 打开职业战争菜单
  /kp join [地图] - 加入职业战争 (指定地图 / 随机)
  /kp info - 查看个人职业战争信息
  /kp shop - 打开职业战争商店
  /kp leave - 离开职业战争
  # 管理命令 ( 权限: kitpvp.admin )
  /kp setEnd - 设置战争结束点
  /kp pay <玩家> <数量> - 给予玩家金币
  /kp give <玩家> <数量> - 给予玩家礼盒
  /kp reload - 重载插件配置
