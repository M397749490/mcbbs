插件介绍
CustomPets是任何类型的服务器的完美宠物插件！ 你可以摆脱你的老平原，无聊的宠物，并用你创建的宠物来代替它们。 创建自己的宠物是非常简单和容易做的。 这个插件充分利用了实体拥有的众多NBT标签，并允许服务器主人将它们用于自己的宠物。 使用这个插件，您的服务器一定会感觉到更独特的自己的一套定制宠物。

Spigo/Bukkit 1.8，1.9，1.10，1.11和1.12兼容性
- 支持所有生物类型
- 多世界的支持
- 无限量的宠物
- 可定制的宠物菜单
- 可骑你的宠物
- 支持PVP
- 宠爱你的宠物
- 命名你的宠物
- 宠物帽
- 宠物路径
- 每个宠物的自定义权限
- 可配置的消息和默认值
- 轻松配置和创建宠物
- 会一直持续更新非常酷的新功能
- 惊人的支持


插件截图&使用方法&指令&权限
1.原帖购买/下载CustomPets.jar插件。
2.将其拖动到服务器根目录的plugins文件夹中。
3.运行/重新加载服务器。
4.用pets.yml文件创建自己的宠物
5.（可选）配置config.yml和messages.yml文件
6. 完成安装

玩家指令
/pet - 列出您拥有的所有宠物
/pet help -显示宠物命令列表
/pet [pet] - 产生你的
宠物 (需要[宠物]的权限许可)
/pet remove -删除你产卵的宠物
/pet menu -打开宠物菜单
/pet name [name] -将宠物的名称更改为[姓名]
/pet ride -骑在你所产生的宠物上
/pet hat -将宠物放在头顶上
/cp - 列出“cp”命令.
/cp reload -重新加载插件
/cp list -列出所有创建的宠物

玩家权限
cp.pet.command - /pet, /pet [pet], /pet remove

cp.pet.help - /pet help

cp.pet.menu - /pet menu

cp.pet.name - /pet name

cp.pet.ride - /pet ride

cp.pet.hat - /pet hat

cp.command - /cp

cp.reload - /cp reload

cp.list - /cp list
