拍卖箱！
类似于WOW拍卖行的邮箱。
注：描述/命令/权限和功能代表最新版本的插件，非常推荐新版本。
这个插件的特点：
·可以用箱子作为拍卖行，还可自定义拍卖行名称。
·拍卖行里出售/购买物品的权限。
·有人买你拍卖的东西时会得到消息。（貌似如果你觉得烦可以用这个指令关闭/auctionchest）
·东西拍卖时，可以显示自定义文本。
如何使用!：
对于玩家：
鼠标左键,买/卖/删除1个物品。
鼠标右键,购买/出售/删除8个物品（可以在conifg.yml更改默认配置。）
Shift+点击,购买/出售/删除所有物品
原文：
[]
For players
  • Left mouse button buy/sell/remove 1 item.
  • Right mouse button buy/sell/remove 8 default items (configurable in config.yml)
  • Shift+click buy/sell/remove all items

[]
对于管理员：
/auctionchest get <name>来设置拍卖箱的名字（貌似还有显示箱子的库存）。
你想在哪拍卖就把箱子放在哪。
然后你就成功创建了一个拍卖箱，很简单对不？
还有，如果你想删除些没luan用的拍卖品只需要/auctionchest clean然后点击来删除。
原文：
[]
  • Type /auctionchest get <name>. name - the name of the chest (shows up when viewing the chest inventory)
  • Place the chest where you want the auction chest to be.
  • You're made an auction chest! It's that simple! Really.
  • If you want to delete unwanted auctioned items just type /auctionchest clean and click on the items.

[]
所需的前置插件：Vault！
这里可以找到：http://www.mcbbs.net/forum.php?mod=viewthread&tid=78310&highlight=vault



插件的指令和权限：
[]
CommandPermissionDescription
/auctionchest-Shows the user other commands that he has permission to use.
/auctionchest help-Shows the user other commands that he has permission to use.
/auctionchest get <name>auctionchest.getGives an auction chest item with the specified name (name shows up when viewing the auction inventory)
/auctionchest silentauctionchest.silentToggles silence for the messages get when users auctioned items is bought.
/auctionchest cleanauctionchest.cleanToggles the feature to delete items from auction chest when clicked on them.
/auctionchest countauctionchest.countCounts the auction chests on the server.
/auctionchest reloadauctionchest.reloadReloads the plugin config.
-auctionchest.sellAllow user to auction items.
-auctionchest.buyAllow user to buy auctioned items.
