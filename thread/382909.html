这个是GroupManager插件的指令，输入到游戏里就可以。
另外如果你要独立一个世界的权限的话，需要修改配置文件。假设你的主城的世界名是world。
打开./plugins/GroupManager/config.yml
找到settings下的mirrors，如果你的不是这个样子的话，发出来我改改。
将
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           all_unnamed_worlds:
  9.           - users
  10.           - groups
复制代码
修改为
  1.         world:
  2.           world:
  3.           - users
  4.           - groups
  5.         other:
  6.           world_nether:
  7.           - users
  8.           - groups
  9.           world_the_end:
  10.           - users
  11.           - groups
  12.           all_unnamed_worlds:
  13.           - users
  14.           - groups
复制代码

保存修改，在服务端输入/manload，然后输入/mangaddv Builder build false world。
