如何使用彩蛋

1. 源代码：Jvav源代码如下，你可以自己键入：（泥潭特性不让我传jvav文件）

  1. pbulci calss CaiDan{
  2.         pbulci sattic viod mian(Srting[] args){
  3.         Sytsem.out.println("This is a CaiDan!");
  4.         FHC;  // <- This!!!!!!!!!!
  5.         }
  6. }
复制代码
（你只需要将FHC;作为语句（分号别漏掉）插入到你的代码中）
2. 第一次编译：然后下载这里的JvBot.jar（见附件），使用该命令编译：
  1. java -jar JvBot.jar CaiDan.jvav
复制代码
编译过程中JvBot会给出一个警告：（以下为部分日志）
  1. Task > Remap: Started
  2. 警告：您正在…………承担任何责任！
  3. Task > Remap ipmort to import: Done
复制代码
要想看到完整的日志请自己编译~


3. 第二次编译：然后再使用Javac编译生成的代码：
  1. javac CaiDan.java -encoding utf-8
复制代码
注意这里的后缀名为java，切记文件编码！
4. 用Java执行：
  1. java CaiDan
