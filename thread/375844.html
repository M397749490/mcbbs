UniqueMOTD能让玩家在进入“多人玩家“的时候
看到你所设定的MOTD，例如：欢迎加入我们的服务器！现在在线玩家:50/100
也可以显示：嘿你好！新玩家！欢迎你来到本服！

TIP:本插件虽然是1.7.9的，但经过测试1.7.2等版本完全可用
ProtocolLib下载地址：http://dev.bukkit.org/bukkit-plugins/protocollib/files/

下面是使用方法：
首先 我们需要安装前置插件:Protocolib 否则将无法正常运行
请删除其他MOTD插件 例如:yulemotd等等

下载我的汉化版  放到服务器的plugins里 重启服务器
然后找到"UniqueMOTD"这个藏在plugins文件夹里的文件夹
ip.yml:无需修改 储存玩家信息
config.yml :你可以修改里面的我已经汉化了的信息 请用notepad++,editplus等软件打开
否则插件可能乱码。

config.yml详解：
##############################################

#------------------SETTINGS------------------#

# 错误报告模式？开启该模式后台会显示反馈信息 #
debug-mode: false

# 是否让插件检测并自动升级？#
auto-updater: true

# 是否开启服务器图标显示玩家头颅？ #
player-heads: true
############################################################################################
default-motds:
  随机显示的MOTD-第一个:
    line-1: '&8&l---[&3&l欢迎来到本服务器&8&l]---'
    line-2: '&6&o哈喽你好! 来加入我们的服务器吧!'
  随机显示的MOTD-第二个: 可显示目前玩家人数/最高玩家人数
    line-1: '&8&l---[&3&l欢迎来到本服务器&8&l]---'
    line-2: '&6&o现在在线玩家: &b&l%ONLINE%/%MAX%&6&o.'
  随机显示的MOTD-第三个: 可显示服务器服务端目前版本
    line-1: '&8&l---[&3&l欢迎来到本服务器&8&l]---'
    line-2: '&6&o目前版本: &a&l%VERSION%&6&o!'
############################################################################################
可显示玩家名的MOTD:
  examplemotd:
    line-1: '&8&l---[&3&l欢迎来到本服务器&8&l]---'
    line-2: '&6&o嘿, &b&l%PLAYER%&6&o! 欢迎你来到本服!'
  嗯。。不解释:
    line-1: '&8&l---[&3&l欢迎来到本服务器&8&l]---'
    line-2: '&6&o嘿, &b&l%PLAYER%&6&o! 这里有 %ONLINE% 个玩家在线!'

#--------------------END---------------------#
