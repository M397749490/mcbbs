夜晚5人惊心动魄的派对！
2016/5/21更新了1.9啦！



这是一款游戏游戏插件
首先是由5个团队：
分别是：

player     普通玩家
freddy   弗莱迪【这尼玛原来是熊-- 】
bonnie   邦尼
chica     奇卡
foxy     狐狸



这款游戏的玩家技能介绍：
游戏的一开始：插件会随机的选择四名玩家。这些玩家将是弗莱迪，邦妮，奇卡，和狐狸，其他的是玩家。

玩家的获胜办法：生存过6晚上点
费莱迪的获胜办法：让全部人变成费莱迪
玩家：
可以移动
侦查：你可以检查你周围的人。
雷达：你可以检查是否有弗莱迪的成员或不。
快门：你是隐形的，弗莱迪的团队成员不能赶上你，但是你的电池更快地减少。

你的能量越少，就越有可能被其他4个费莱迪攻击

1:铁锭：闪光灯
2：红石：雷达
3：铁门：快门


积分榜：
夜晚几：几点
剩余玩家:
你的职业：

费莱迪大队：
弗莱迪：
在夜里弗莱迪不能移动，但弗莱迪可以传送和攻击到能量空的玩家中。
从晚弗莱迪可以正常运行。
邦妮：
他在第一晚的速度很慢，但他在那之后会更快。
奇卡：
与邦妮几乎相同，但她可以发出声音恐吓玩家。
狐狸：
狐狸不能移动，但他可以用他可以在固定的时间非常快速的移动。

===============================================
如何创建游戏？

/fn set lobby - lobby - 设置游戏结束后的出生点
/fn set player - 设置玩家的出生点
/fn set specrate - 设置观众的出生点
/fn set freddy - 设置费莱迪的出生点
/fn set chica - 设置邦尼的出生点
/fn set bonnie 设置奇卡的出生点
/fn set foxy - 设置狐狸的出出生点



/fn join - 加入游戏
/fn leave - 离开游戏[在游戏玩家中途不能离开，观众可以离开]
/fn spectate - 加入观众席[可以离开]
/fn info - 显示游戏消息

管理员的指令：
/fn open - 打开一场游戏，并参与其中[玩家加入]
/fn close -  取消游戏
/fn start - 开始游戏
/fn start night6 - 开始游戏6
/fn start night7 - 开始游戏7
/fn cancel - 取消开始游戏
/fn reserve (玩家) - 指定这个玩家参与游戏
/fn set lobby - 重新设置大堂出生点
/fn set player - 重新设置玩家的出生点
/fn set spectate - 重新设置观众的出生点
/fn set freddy - 重新设置费莱迪的出生点
/fn set chica - 重新设置奇卡的出生点
/fn set bonnie - 重新设置邦尼的出生点
/fn set foxy - 重新设置狐狸的出生点
/fn reload - 重新加载插件
