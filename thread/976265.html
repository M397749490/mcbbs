MagicItem
自定义魔法物品



简介

       这是一个超强的自定义物品插件，你可以用它去自定义目前配置文件有的所有功能。比如物品的lore显示，附魔特效，使用获得药水等等等。具体的参看配置文件。

       新更新的内容
           1. /mi show 像全服玩家展示手持物品  支持所有nbt物品
           2. /mi sell 一键回收背包所有可回收的魔法物品  每个物品的回收价格配置文件自定义
           3. 新增自定义锻造 即概率合成物品  具体参考配置文件
           
         


用法


1. 把插件丢进服务器plugins文件夹

2. 重启服务器

3. 使用/mi add 名称 id  去创建你的魔法物品


4. 去/plugins/MagicItem/items 里面找到你的物品 开始配置他吧！

5. 使用/mi give 玩家 名称 数量  去给一个玩家指定的魔法物品

6. 右键去使用他吧...

配置文件

物品配置文件：

         
  1. 物品ID: '351:1'
  2. 名字: 测试的名字
  3. 获得药水: ""
  4. 群体药水: ""
  5. 药水范围: 5
  6. 群体药水作用对象: 1
  7. 使用雷击: true
  8. OP指令: ""
  9. 以玩家身份执行: "me test@me sss"
  10. 附魔: 0:1@2:5
  11. 显示: 第一行{换行}第二行
  12. 使用消耗: true
  13. 职业限制: 无
  14. 回收价格: 10
  15. 冷却时间: 10
  16. 获得提示: 恭喜获得魔法物品
  17. 全服提示: 恭喜{player}获得魔法物品
复制代码
            注：不需要的功能留空即可 留空用 ""

指令

总帮助 /mi help
创建物品 /mi add 名称 ID
给玩家物品 /mi give 玩家 名称  数量
创建合成文件 /mi syn create 名称
使用合成文件 /mi syn use 名称
创建锻造文件 /mi for  create 名称
使用锻造文件 /mi for  use 名称
保存手持物品NBT信息 /mi save 名称
展示手持物品 /mi show
一键回收背包可回收物品 /mi sell

说明

我可以用它干什么？
  1. 去自定义你需要的物品
  2. 去实现血瓶，群回血瓶等道具
  3. 配合RSRPG系列打造出用材料合成装备的效果
  4. 配合锻造插件使用可以做出自定义材料锻造的效果
  5. 配合RSRPG系列打造装备+材料合成更高级的装备
