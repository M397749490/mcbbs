作者: xmdhs    时间: 2018-8-12 09:20
你首先开启smtp功能 http://service.mail.qq.com/cgi-b ... =28&&no=166
然后按下面配置，自行替换
  1. # SMTP服务器IP
  2.     mailSMTP: 'smtp.qq.com'
  3.     # SMTP服务端口
  4.     mailPort: 465
  5.     # 仅适用于25端口,是否启用 TLS/STARTTLS 功能
  6.     useTls: true
  7.     # 发信邮箱账号例如 abc
  8.     mailAccount: '你的qq'
  9.     # 发信邮箱密码
  10.     mailPassword: '授权码'
  11.     # 发信邮箱账户,例如 abc@abc.cn
  12.     mailAddress: '你的qq邮箱'
  13.     # 自定义发信名称
  14.     mailSenderName: '服务器'
  15.     # 账户恢复验证码长度
  16.     RecoveryPasswordLength: 8
  17.     # 右键标题
  18.     mailSubject: '你的新密码'
  19.     # 每个邮箱最多绑定多少个账户
  20.     maxRegPerEmail: 1
  21.     # 是否要求玩家绑定邮箱
  22.     recallPlayers: true
  23.     # 要求玩家绑定邮箱消息的延后时间
  24.     delayRecall: 5

作者: 游侠崔斯特    时间: 2018-8-12 09:39
开通邮箱验证后    登录服输入/changepassword 老密码 新密码  就会给你绑定邮箱发验证
请在10分钟内在游戏里操作这个验证码否则会失效 10 分钟!
请在登陆服输入 /verification 123456 然后再输入/changepassword 老密码 新密码.
这样密码就成功改了
