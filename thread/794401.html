前言

是不是觉得Steve徒手拿岩浆桶很不可思议?
这个Mod能让游戏更加科学
使液体达到某个数值就会让玩家自燃~

使用教程

放到mods文件夹中就可以了
↓配置文件↓
  1. # Configuration file

  3. general {
  4.     # How hot a fluid should be to start burning the player
  5.         # 大于等于这个值就会让玩家燃烧
  6.     I:HOT=1300

  8.     # If true, the items that contain hot fluid will have a tooltip that will show that they are too hot
  9.         # 是否开启达到燃烧数值的物品提示
  10.     B:TOOLTIP=true
  11. }
