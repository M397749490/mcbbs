插件介绍
本插件可以给玩家提供一个选择与更换聊天称号的GUI菜单，玩家可输入指令打开菜单，只有拥有相应权限才能看到并更换相应聊天称号，与其它同类插件不同的是，本插件与ess自带的前缀后缀并不冲突，而是直接再给玩家加个称号

使用方法
下载本插件，扔进plugins文件夹，重启服务器，把帖内汉化好的配置文件放入相应文件夹，重启服务器

本插件既可以和DeluxeChat/MiaoChat搭配使用也可以和ess自带的聊天搭配使用

↓↓↓使用EssentialsChat请看↓↓↓
打开ess的config，找到format这一行，添加{deluxetags_tag}这个变量，你可以添加成前缀称号也可以添加成后缀称号
  • 前缀称号
  1.   format: '{deluxetags_tag}<{DISPLAYNAME}> {MESSAGE}'
复制代码
  • 后缀称号
  1.   format: '<{DISPLAYNAME}>{deluxetags_tag} {MESSAGE}'
复制代码
然后重启服务器，之后就可用使用了，原帖很多人都在问为什么安装以后什么称号都不显示，就是因为这一步没做

↓↓↓使用DeluxeChat/MiaoChat请看↓↓↓
使用DeluxeChat必须先安装PlaceholderAPI前置，然后下载DeluxeTags拓展包
指令如下
  1. /papi ecloud download deluxetags
  2. /papi reload
复制代码
然后在DeluxeChat的配置中使用%deluxetags_tag%变量即可，MiaoChat同理
如果你使用DeluxeChat的话请不要下载本帖内的config，请使用默认生成的config

指令&权限

/tags   打开更换称号GUI    deluxetags.gui
使用称号的权限    deluxetags.tag.<称号ID>
玩家只有拥有相应权限才能在GUI内看到称号，并点击更换

↑↑↑以上就是和玩家有关的指令&权限↑↑↑
↓↓↓以下是管理员需要用到的指令↓↓↓


/tags list all    查看所有称号
/tags list <玩家名>   查看玩家拥有的所有称号
/tags set <玩家名> <称号ID>   给玩家设置称号
/tags clear <玩家名>   抹去玩家当前所用称号
/tags create <称号ID> <称号>   创建一个称号
/tags delete <称号ID>   删除一个称号
/tags setdesc <称号ID> <称号的lore>   在GUI里给称号添加lore
/tags reload   重载插件

<称号ID>代表称号的序号，真正在聊天里显示的是<称号>，<称号>可加彩色代码
请注意：<称号ID>可以是中文，但是在给权限的时候可能会出偏差，所以还是推荐使用英文

配置文件
  • 如果你使用的是EssentialsChat，推荐下载本帖内的config.yml
  • 如果您没有使用本帖内的config而是使用了默认生成的config，您需要修改：

  • 找到deluxe_chat属性并设置为false
  1. deluxe_chat: false
复制代码
  • 将默认生成的所有带%%的变量改为带{}的变量，例如%deluxetags_tag%改为{deluxetags_tag}
  • 之所以要改这么多是因为它默认是和DeluxeChat挂钩，不想这样麻烦的话，推荐您从帖内下载config
