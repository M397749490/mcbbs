嗯，这里是作者的解说：
Finite Water Control is successor in function to Regional Water. Water (and other fluids, if specified in the config) does not form into new source blocks when outside of specified dimensions, biomes, or y-levels.     FWC is intended to allow pack-makers and players to make obtaining large amounts of water more challenging than it is in vanilla Minecraft. Players can pipe water in from oceans or rivers, but can't set up infinite water sources of their own.



翻译：
有限的水控制是区域水功能的后续。水（如果在配置中指定了其他的流体）在指定的维度、生物或y指标之外不会形成新的源块（大水伤身）。FWC的目的是让整合包制作者和玩家能够获得比在原版世界中更大的挑战。玩家可以从海洋或河流中输送水，但不能建立自己的无限水源。

（4）.还有，怎么添加其他流体呢？
          找到/.minecraft/config文件夹，找到Finite Water Control，里面有关于控制水有限的代码，然后你就依葫芦画瓢就行了  

config中的内容：
# Configuration file  general {     # Block IDs for fluids that should be made finite [default: [minecraft:water][流体]]     S:finiteFluids <         minecraft:water      > # Biomes in which these fluids should be infinite [default: [ocean], [beach], [river]，[其他地形]]     S:infiniteBiomes <         ocean         beach         river      >
# Dimensions in which these fluids should be infinite     I:infiniteDimensions <      >
# Maximum y-level in which these fluids can form new source blocks. [range: 0 ~ 255, default: 255]     I:maxHeight=255
# Minimum y-level in which these fluids can form new source blocks. [range: 0 ~ 255, default: 0]     I:minHeight=0 }


此外，你还可以添加岩浆，使在地狱中的岩浆海变成无限的
