我用的是MCedit 0.1.1（64bit）
主界面（就是刚打开的时候）：
   create new world－创建一个新的世界
   load world－读取世界
   open a level－打开一个世界
我们一般只用open a level（存档的位置我不用说了吧...）
   打开之后（从左往右一共有9个图表）：
         1. select 选择
             right click for option 右键点击来打开设置界面
              点击选择之后     
                （鼠标拖拽来选择）
                deselect 取消选择
                select chunks 选择区块
                delete blocks 删除选择的方块
                analyze 统计选择的方块
                cut 剪切选择的方块
                copy 复制选择的方块
                paste 粘贴复制或剪切的方块
                export 导出选择的方块为 .schematic文件
         2. brush 刷子
             right click for option 同上
             点击刷子后：
                 mode 模式 需要在意的模式有 fill（填充）
                                                           replace（替换）
                                 （其他的我也不会用...）
                 brush 刷子的形状 有 round（球体）
                                              square（长方体）［吐槽：square明明是正方形］                     
                                              diamond（钻石形）
                 L 长度
                 W 宽度
                 H 高度
                                  （剩下的不会用...）
         3. Clone 克隆
             点击克隆后（选了东西后才能点）
                 Rotate 旋转
                 Roll 水平旋转
                 Flip 翻转
                 Mirror 镜像翻转
             下面的3个0是可以改的，分别是：
                 X轴位移
                 Y轴位移
                 Z轴位移
                 Repeat 重复次数
                 Scale factor 改变比例
                 copy air 是否复制空气
                 copy water 是否复制水源
       4. Fill and replace 填充和替换（选了东西后才能点）
             很简单，点了之后会出现一个选物品的界面，看图片就行了
             选完之后按OK 再按Fill
       5. Filter 过滤器 （选了东西后才能点）
             ［吐槽：AI很傻很天真，与其用过滤器不如手刨］
               要跟详细的说明消息我（实在太多了）
       6. Import 导入
               可以导入 .schematic文件
       7. Move player 移动玩家
               play name 玩家名字
                    （选中之后可以对该玩家操作）
               goto player 移动到该玩家的附近
               goto player‘s view 移动到该玩家的第一人称视野
               move player 移动该玩家
               Align player to Camera 将该玩家移动到摄像机所在的位置
         8.move spawn point 移动玩家的重生点
         9.区块控制［吐槽：很鸡肋的功能］
                     要详细的说明消息我
