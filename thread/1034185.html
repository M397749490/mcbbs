你需要指定你插件的Main类，如果你这个runTaskTimer 写在其它类，你需要这样：

在 插件的Main 类加入以下代码
  1. public static 你的Main类名称 instance;

  3. @Override
  4. public void onEnable() {
  5.     // 这个丢在你的onEnable即可
  6.     instance = this;
  7. }
复制代码


然后，在其它类这样使用：

  1. runTaskTimer(你的Main类名称.instance , 0L, 1L);
