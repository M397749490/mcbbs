喷气背包插件
前言
这是我第一次搬运插件，有什么不对的地方还请各位大佬能说出来，让我改正。
插件说明
Jetpack是一款简单的娱乐插件，是用飞行与佩戴物品相结合的插件。让玩家可以感受飞行的乐趣。（我说的，不是作者说的qwq）
插件特性
1.可以自定义燃料在飞行时多少秒扣除一个，相当于燃烧煤炭
2.可以自定义燃料和喷气背包，支持lore和name
3.可以自定义飞行时喷气背包后面喷出的粒子效果
插件指令
/jetpack help ——插件帮助/jetpack set [fuel/jetpack]——设置手中物品为燃料/喷气背包（喷气背包目前只能用胸甲）
/jetpack give [fuel/jetpack] [玩家ID] [数量]——给予玩家指定数量的燃料/喷气背包
/jetpack get [fuel/jetpack] ——获取燃料/喷气背包/jetpack reload ——重载插件
插件权限
JetPack.use——基础权限
JetPack.set——设置燃料/喷气背包权限
jetpack.get.fuel——获取燃料权限
jetpack.get.jetpack——获取喷气背包权限
jetpack.give.jetpack——给予喷气背包权限
jetpack.give.fuel——给予燃料权限
jetpack.reload——重载插件权限
