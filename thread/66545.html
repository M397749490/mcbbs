输入 //wand 获得选择工具。
　左击一个方块设置点1。
　右击另外一个方块设置点2。
　输入 //set X替换所有方块为方块X。
　输入 //expand <数量> [方向] 扩大选择区域。
　输入 //shift <数量> [方向] 移动选择区域。
　输入 //set 0 移除所有的方块。
　输入 //undo 撤销。
　输入 //redo 重做。
