比如刷怪时间是10分钟 打怪中人物死亡  怪会消失  进入冷却

首先哪个despawn参数不要丢，一定要加上
设置固定刷怪点，然后修改：
cooldown设置为0，然后warmup设置为600（10分钟）（warmup就是前一批怪物死完之后多久生成下一批），mobsperspawn设置为1（只刷一个）
  1. /mm s create [刷怪点] [怪物的MM名字]
  2. /mm s set [刷怪点] cooldown 0
  3. /mm s set [刷怪点] warmup 600
  4. /mm s set [刷怪点] mobsperspawn 1
