此插件是 https://dev.bukkit.org/projects/notify 的更新版本

介绍：
Notify 是一个给在其自己计算机上运行服务器的腐竹使用的插件。在某些事件触发时，插件会播放声音来提醒腐竹。再也不会有玩家在你服务器玩耍而你不知道的事情发生了。

功能
检测聊天、加入、退出事件
所有声音都可以自定义
在检测到关键字及玩家加入/退出时播放指定独特的声音
支持 WAVE、AU、MP3 和 MIDI 格式
支持游戏内声音。设置 use-ingame-sounds 为 true 即可。游戏内声音请在 sounds 设置，每个拥有 notify.hear 权限的玩家都能听到。
动态启用或禁用声音播放
通过指令播放声音
音量控制

指令
notifyreload - notify.reload - 重载配置
notifysound <enable/disable> - notify.sound - 启用或禁用声音播放
notifytestsound <soundtype> - notify.testsound - 向控制台播放声音

我的结尾
配置文件翻译
#音频文件必须为 .wav、.au 或 .mid 格式。
#请将要使用的音频文件转换为上述文件格式之一。

#选择需要播放声音的事件。
events:
  player-chat: true #聊天
  player-join: true #进入游戏
  player-quit: true #离开游戏

#是否启用游戏内声音？
use-ingame-sounds: false

#是否在触发事件时记录日志到文件？
should-log-to-file: false

#在使用游戏内声音时，会使用此列表代替 sound-files
sounds:
default: "ENTITY_EXPERIENCE_ORB_PICKUP" #默认
chat: "ENTITY_EXPERIENCE_ORB_PICKUP" #聊天
join: "ENTITY_EXPERIENCE_ORB_PICKUP" #进入游戏
quit: "ENTITY_EXPERIENCE_ORB_PICKUP" #离开游戏
special-chat: "ENTITY_EXPERIENCE_ORB_PICKUP" #聊天（特殊）
special-join: "ENTITY_EXPERIENCE_ORB_PICKUP" #进入游戏（特殊）
special-quit: "ENTITY_EXPERIENCE_ORB_PICKUP" #离开游戏（特殊）

#指定声音文件的路径。包括文件名和扩展名。
#使用 % 包围，以使用 ./plugins/Notify/Sounds 中的声音。
sound-files:
  default: '%default.wav%' #默认
  chat: '%chat.wav%' #聊天
  join: '%join.wav%' #进入游戏
  quit: '%quit.wav%' #离开游戏
  special-chat: '%specialchat.wav%' #聊天（特殊）
  special-join: '%specialjoin.wav%' #进入游戏（特殊）
  special-quit: '%specialquit.wav%' #离开游戏（特殊）

#如果在聊天中发现了这些词，播放一个特别的声音。
#使用逗号分割：[这是, 一个, 示例]
special-chat: []

#在下列玩家进入或退出游戏时，播放一个特别的声音。
special-join: [] #进入游戏
special-quit: [] #离开游戏

#设置音量，值为 0 到 100 间的整数。
volume: 100

#插件将在成功启用后立即播放一段默认声音。
#如果设置为 true 但没有播放声音，请确认是否发生错误。
play-sound-on-startup: true
#消息内容的前缀
prefix: "&7[&9Notify&7]"
#在玩家没有正确权限时发送的消息
no-permission: "你没有权限执行此命令"
#在配置重载后发送的消息
config-reload: 配置已重载
