1.监听生物死亡事件可以做到
创建一个新类，名字随便你
  1. public static class LFBEventHandler {
  2.             @SubscribeEvent
  3.             public void playerEvent(LivingDeathEvent event) { //监听的是所有生物摔落事件
  4.                 //判断event.entity是哪种生物
  5.                 if(!(event.entity instanceof EntityMob)) { //如果event.entity是怪物
  6.                     return;
  7.                 }
  8.                 event.entity.dropItem(XXX, 数量); //掉的东西和数量
  9.                     }
  10.                 }
复制代码

然后主类Init里注册这个监听器
  1. MinecraftForge.EVENT_BUS.register(new XXX.LFBEventHandler());
