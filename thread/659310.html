> SymortalMotd<

= 简介=
这个插件可以设置玩家加入服务器时候的宣传语，乘机宣传服务器~
如果你想修改加入的信息请打开SymortalMotd的配置文件 config.yml
进行修改！
=权限=
此插件没有任何的权限。
所有的玩家都可以进行宣传。
=特点=
此插件支持颜色代码!
下面这是各种颜色的代码

=配置=
下面这是config.yml的配置（英文）
  1. #########################
  2. # Symortal MOTD #
  3. # Made By: Peyton ! #
  4. # Spigot: peytonfultz #
  5. #########################
  6. #
  7. HEADER: 'Default Message' #Example Message Welcome to the <Server>
  8. #
  9. WEBSITE: '&c&lWebsite: &7www.yourwebsite.com' #Your Servers Website
  10. #
  11. TEAMSPEAK: '&c&lTeamSpeak: &7ts.yourteamspeak.com' #Your Servers Teamspeak
  12. #
  13. SHOP: '&c&lShop: &7ts.yourshop.com' #Your Servers Shop / Store
  14. #
  15. FOOTER: 'Default Message'
