Akashic Tome——阿卡什宝典
注意：本模组需要前置模组AutoRegLib
模组介绍
阿卡什宝典是一个基于变形工具（Morph-o-Tool）的模组。它唯一增加的物品便是阿卡什宝典，由一本书和一个书架所制作。它们基本的概念（及代码）是相同的，但在功能上却是不同的。


阿卡什宝典能够与其他模组的手册相结合，并且它能存储所有你放进去的手册。

·如果想要添加一本手册到阿卡什宝典，只需要简单的在工作台中结合它们。你想要添加多少本手册都没问题，哪怕是完全一样的手册。
·你从阿卡什宝典中所得到的都是真实的物品（手册），而非这个物品或容器的仿制品。这确保了与物品所具有的功能100%的兼容（详见配置模组）
·你所添加的物品会获得一些依附于它的NBT标签，以此改变它的名字并确保游戏知道如何正确的改回它。
·由于你得到的是真实的物品，你可以把它用于合成，但你最好不要这么做，因为这样你会失去其他你所添加的物品。
·想要切换宝典到其他模组你所添加的手册，你只需要简单的右键点击它并选择你想要的手册。
·按住Shift键再右击一个模组的方块会使宝典变成已添加的相应模组的手册。如果你添加了一个模组的多本手册，它会选择你首先添加的手册。
·左键点击空气使宝典恢复原状。
·当你拿着阿卡什宝典（没有转变为其他手册），你可以按住Shift键再右键单击一个宝典中没有该模组手册的方块，这样你会被带到它的wiki页面（这使用了Botania Wiki API，并且默认为FTB wiki）。
如果想要移除你所添加的手册，请切换到你想要移除的手册，按住Shift键再点击Q键来移除手册。

作者原文：
Akashic Tome is a mod based on Morph-o-Tool. The only item it adds is the Akashic Tome, crafted with a Book and a Bookshelf. The basic concept (and code) is the same, but they are functionally different. Check out the images tab for some pics.     The Akashic Tome can be combined with mods' documentation books, and can store as many as you can fit in there.  To add a book to it, simply combine them in the crafting table. You can have as many as you want, including duplicates. You get the actual item from the mod, not an emulation of the item or a container. This ensures 100% compatibility with that item's functionality. The item gets some NBT data tacked on to it to change its name and ensure the game knows to change it back properly. Since you get the actual item, you can use it for crafting but you probably shouldn't, as you'll lose all other attached items. To morph the tome into another mod's documentation book that is added to it, simply right click and pick ** you want. Shift-right clicking a block from a mod that has a book added to the tome will morph the tome into that book. If you have multiple from the same mod, it'll take the first added. To unmorph back into the tome, left click the air. While in the standard "Akashic Tome" item, you can right click a block that does not have a documentation book to be taken to its wiki (this uses the Botania Wiki API, and will default to the FTB wiki) To remove items attached to it, drop the item using Q while shifting and it's morphed into the item you want to remove.
配置模组
模组的配置文件包含以下内容：
一个允许每一个单独的物品被添加进宝典的选项。默认为禁用（开启后你可以把背包模组的大背包塞进书里，但原版物品不行）
一个不允许添加的模组物品的黑名单
一个特定关键词的白名单，包含这类关键词的物品都能够被添加（如book、tome、lexicon...）
一个特定物品的白名单，可以使不包含以前设置的关键词的物品也能够被添加
一个映射列表。这允许你将一个模组重定向到另一个模组。例如，RFTools模组中含有智能扳手这一工具，如果映射列表中包含“rftoolsdim=rftools”，那么在你看着一个RFTools Dimensions（RF工具|维度）的方块，并且在变形工具中添加了智能扳手，它便也能转换成智能扳手。热动力学映射到热力膨胀也是一个例子（这段作者偷懒直接照抄了他另一个模组变形工具的原文，原理是相同的）
