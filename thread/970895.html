ZSociety

2020.4.12日 更新 1.0.8alpha 版本
当前插件还属于测试版本,如发现BUG请及时反馈
前置插件EconomyAPI
交流群号:615313559
简介:
  • 还在为没有公会插件而烦恼吗?
  • 本作者在最近几天发现圈内没有免费的公会插件,所以觉得想给大家带来一款功能全面的公会插件
  • 希望大家多多提出合理的功能后面会加快实现
  • Github

功能:
1.公会系统
  • 公会商店
  • 公会等级排行榜
  • 公会经济排行榜
  • 公会贡献
  • 会长管理界面
  • 公会商店


2.称号系统
  • 称号商店
  • 称号管理界面
  • 称号设置界面

3.结婚系统
  • 求婚
  • 情侣之间TP
  • 情侣公共资产排行榜



4.特权系统
  • SVIP功能界面
  • VIP功能界面
  • 特权管理界面
后期将会实现功能(无期限):
  • 公会战
插件指令说明:
  /公会 ->公会主命令
  /称号 ->设置称号
  /结婚 -> 结婚功能GUI
  /特权 -> VIP/SViP功能界面
  /管理 [称号| 特权] -> OP管理界面
