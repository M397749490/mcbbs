搬运说明

这是一款老牌死亡信息插件，拥有高度可自定义。



使用

QQ图片20180726223937.png (548 Bytes, 下载次数: 1)

下载附件

2018-7-26 22:48 上传
1.准备spigot端
2.去原帖下载插件
3.放进plugins文件夹里面
4.重启服务器生成 DeathMessagesPrime 文件夹
5.游戏里面输入/kill id （不对，不对 是/dmsg） ok



功能

  • 支持 CrackShot 的死亡信息
  • 在特定的世界允许禁用PVP死亡信息和非PVP死亡信息
  • 多世界/单独世界禁用死亡信息
  • 可配置每个死亡原因
  • 在生物群落死亡的消息
  • 区分跌落高度死亡信息 (如低处摔落信息为：“撞到地面太硬”     高处掉落信息为：“从高处摔下”)
  • 允许指定死亡消息可见（全部 或 n格以内）
  • 允许VIP不同死亡信息和不同PVP信息
  • 支持玩家显示前后缀
  • 支持MythicMobs或其他的自定义怪物名称的怪打死玩家的特殊死亡提示
  • 支持当武器项目工具提示中显示一条消息
  • [size=14.6667px]可配置死亡信息间隔时间，防死亡信息刷屏
  • 更新中。。。（其他没列出来的在原帖看，有些功能已经写到汉化配置里面了）
