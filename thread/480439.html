功能介绍：

TimeTracker 是一个用于记录玩家每次登陆和退出服务器的时间的插件，这个插件会储存这些用户记录。查看用户总在线时长方便快捷。
这个插件可以用于给资深玩家发放奖励，甚至是VIP等等
比如说一个玩家游戏在线时长1小时就能申请XXX奖励，当他游戏在线时长达到24小时就能申请XXXX奖励
一个很不错的管理插件，本人亲测{:10_512:}

指令：
Commands
  • /seen - Provides all the stored data about a player.
  • /playtime - Provides information about the issuing player.
指令
  • /seen - 提供某个玩家所有的已储存的记录
  • /playtime - 提供执行此命令的玩家自己的记录

权限：

Permissions
  • timetracker.seen - Gives access to /seen. Defaults to OP only.
  • timetracker.playtime - Gives access to /playtime. Defaults to true.
指令
  • timetracker.seen - 给用户使用 /seen 的权限。初始只有OP有权该限
  • timetrackter.playtime - 给用户使用 /playtime 的权限。初始每个人都有该权限

未来更新：
Upcoming Features

  • Multiple languages
未来更新目标

  • 多种语言
