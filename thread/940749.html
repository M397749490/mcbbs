你是否在因为想要设置一个死亡掉落生存，却因为掉落物品不好整理而困扰吗？

那么今天我给大家带来一款适用于spigot的轻量级,开源，免费的插件

Graves

使用方法：直接扔到plugins文件夹就行啦



效果：玩家死后身上的物品会跑进一个箱子头颅里，右键打开回收物品


配置文件：


configVersion: 1


settings:

# 如果要禁用选项就把显示设置改为 ""


  graveTime: 10800 # (秒) 死亡箱的留存时间，超时删除。

  #graveBlock: CHEST # https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html

  graveBlock: PLAYER_HEAD # If player head.

  #当下面的选项设置为"$entity"时，死亡箱字会使用玩家皮肤。

  graveHeadSkin: MHF_Chest # “MHF_Chest”是一个箱子的皮肤ID

  graveTitle: "$entity 的坟" # 死亡箱的标题，“$entity“代表坟墓主人

  graveBreak: true # 死亡箱是否能被打坏

  graveExplode: true # 死亡箱是否能被炸毁

  graveProtected: false # 坟墓保护，如果是false别人也可以打开

  graveProtectedMessage: "&8[&6坟墓&8] &f这个坟墓被保护了!" #坟墓保护显示文本

  graveProtectedSound: BLOCK_CHEST_LOCKED  #坟墓被保护时其他玩家的右键音效

  killerOpen: true # 杀死玩家的玩家是否能打开此箱子此项设置高于坟墓保护


  graveFailure: "&8[&6坟墓&8] &f完啦！坟墓不能被放置，物品将掉落一地." # 如果坟墓不能放置显示的消息


  graveOpenSound: BLOCK_CHEST_OPEN # https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Sound.html 箱子打开音效

  graveCloseSound: BLOCK_CHEST_CLOSE # https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Sound.html 箱子关闭音效


  deathMessage: "&8[&6坟墓&8] &f你的坟在 &fx=&6$x, &fy=&6$y, &fz=&6$z 生成了。你只有&6$time&f的时间去回收它!" #死亡提示，创建坟墓成功后显示给玩家的文本


  lootMessage: "&8[&6坟墓&8] &f完啦，你坟被别人刨了!" #玩家坟墓被别人刨了的提示

  lootSound: ENTITY_DONKEY_CHEST # https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Sound.html

  lootEffect: MOBSPAWNER_FLAMES # https://hub.spigotmc.org/javadocs/spigot/org/bukkit/Effect.html


  expStore: true # 是否储存经验

  expMessage: "&8[&6坟墓&8] &f你从坟墓里回收了 &6$xpxp &f经验!" #经验回收提示


  permissionDenied: "&8[&6坟墓&8] &f你没权限这样做!"  #提示没有权限的提示


  graveEntities: # 死后能创建坟墓的实体

    - PLAYER

    #- ZOMBIE

    #- ALL


  timeSecond: "$s 秒"

  timeMinute: "$m 分钟"

  timeHour: "$h 小时"

  timeDay: "$d 天"

指令：



/ graves- 插件信息

/ graves reload- 重新加载命令（需要OP权限）



权限组：


graves.place（默认，坟墓放置权限）

graves.open（默认，坟墓使用权限）

graves.break（默认，坟墓破坏权限）

graves.bypass（OP，坟墓操作绕过权限）

graves.reload（OP，插件重载）
