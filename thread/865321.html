UTF8Encoder Java Edition
UTF8转码器 Java版

是的，又是我，这次又双叒是UTF8转码器，又是相同的服务商的委托，定制了此软件。
经过允许又现将此软件公开发布，以此希望帮助更多人。
特性：
  • 与Win32版不同，此版本可使用与Minecraft相同的启动参数作为服务器核心JAR启动，这对于面板服来说，只需要将其添加到核心列表即可实现自助转码
  • 转码备份功能，转码的文件将会以相同的路径结构存储在独立文件夹
  • 面板服兼容（如MultiCraft），发送list等命令时，Encoder会输出避免循环重启
  • 云服务支持，将会从云端服务器获取应转码与不应转码的文件后缀格式，进行有针对性的转码，热更新支持
  • 由于编写语言使用Java，因此要求至少应分配512M的RAM。（经测试400M可承载2-3w文件信息，更高还未测试，但也应适当提高分配）

如何使用：
  • java -jar UTF8Encode.jar (是的，服务器核心怎么启动就怎么启动就成
  • 等待从云服务器拉取数据后，运行指令confirm即可开始转码

命令列表：
  • confirm 执行转码操作
  • kill 强停转码线程
  • printwhitelist 打印云端服务器支持转码的后缀名列表
  • printblacklist 打印云端服务器指定不转码的后缀名列表 (当不存在与两个列表中的将会上报服务器，公开版默认关闭此功能)
