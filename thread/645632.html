标题: 因为服里存在不同的附魔武器，比如附魔X的镐和附魔IV的镐，有什么办法可以区分维修？
比如我要维修X的需要花费更多的金币之类的，有办法实现吗？
作者: Airl    时间: 2016-10-30 20:02
你好楼主！你可以使用到ESS插件里面的功能！最后效果每个玩家都可以修理物品并扣除费用.
注意(只能维修原版物品)
打开ESS的config进行操作
[前]
command-costs:
  # /example costs $1000 PER USE
  #example: 1000
  # /kit tools costs $1500 PER USE
  #kit-tools: 1500

[后]
[解释： 当玩家使用 /repair 指令并扣除1000游戏币]
command-costs:
   repair: 1000
  # /example costs $1000 PER USE
  #example: 1000
  # /kit tools costs $1500 PER USE
  #kit-tools: 1500
[修改保存之后重载ESS插件或重启服务器]
[然后在游戏里面添加权限组的使用权限 /mangaddp Builder essentials.repair ]
[在游戏里面手握要维修的物品输入 /repair 即可]
[结束 最后 望采纳！]
