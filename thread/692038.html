EpicWorldGenerator -- Intermediate
EWG 对象 (EWG Object)
在 EpicWorldGenerator 里, 所有的结构都是使用 "EWG 对象"生成的. 这个对象的配置文件使用json格式, 其中最重要的设置是对象所属的文件. 所有 EpicWorldGenerator 里的结构需要保存在.EWG格式的文件里. 这个文件是用来优化速度, 存储对象的标记点的.
任何一个 EWG 对象都可以在 "customTrees" 和 "customStructures" 中使用, 作为生成结构单元.
创建一个新的结构文件
1. 使用World Edit选择一片区域
2. 如果要包含空气 (房屋, 金字塔, 等.) 你必须用海绵代替空气.
    替换指令: //re 0 sponge:1
3. 之后, 站在区域中央(中心)输入命令(和坐标), 防止以后用于生成的结构的位置错误(比如生成在空中).
    例子: /ewg create <center X> <center Y> <center Z> <name> 只输入整数, 不要输入小数!
4. 结构保存在 EpicWorldsGenerator 的文件夹下的 "EWGFiles" 文件夹内
生成文件
每个配置都必须含有结构的文件名.
1. 打开生物群系文件, 位于世界文件夹 > Settings 文件夹 > Biomes 文件夹 > [生物群系名称]
2. 找到 "customTrees" 或 "customStructures" 条目, 这取决于你是想生成树还是结构
3. 将下面的内容加入配置文件
4. 将 "CUSTOM_jungle_tower" 改为 "CUSTOM<name>" , 注意 "" 或者下划线代表一个空格.
5. 其他的条目都在Biome Wiki. 但是提供的大部分信息都不需要去碰它, 而且在大多数情况下并不需要.
  1. {
  2.   "name":  "CUSTOM_<name>", //所属的文件
  3.   "density": 0.002, //密度, 在每个X和Y坐标生成的几率
  4.   "size": "MEDIUM", //常常忽略, 有时用于树的设置
  5.   "type": "DECO", //树或者结构的种类
  6.   "blocksRequiredUnderneath": [ //这个对象底部需要生成的方块
  7.     "GRASS"
  8.   ],
  9.   "blacklistedDecoBlocks": [], //黑名单方块
  10.   "spawnOnGround": true, //这个结构是否必须生成在地上
  11.   "overrideExsistingBlocks": false, //这个结构是否需要替换原有地形的方块
  12.   "allowRotation": false, //是否需要随机翻转
  13.   "applyPhysics": true, //是否需要物理效果, 比如方块更新
  14.   "replaceAir": false, //是否只替换空气
  15.   "minY": 50, //最低的Y坐标
  16.   "maxY": 90, //最高的Y坐标
  17.   "maxSlope": 0.0, //最大的坡度, 地形边界
  18.   "minSlope": 0.0 //最小坡度
  19.   "snapToXGrid": 150, //如果你希望对象在网格中生成, 那么X轴的对象之间有150个方块相隔. 你可以设置为-1来禁用他. 如果启用, 请记住增加密度(density)选项.
  20.   "snapToYGrid": 150,//Z轴, 同上
  21.   "gridXOffset": 0, //中心的偏移量, 防止多个对象生成在同一地点(如果你配置了多个对象, 你可以适当偏移, 防止坐标重合)
  22.   "gridYOffset": 0, //同上
  23.   "anchorYOffset": 0 // Y轴的偏移量, 设置为正数会将对象抬高.
  24. }

EpicWorldGenerator -- Intermediate
自定义生物群系 (CustomBiomes)
创建一个新的生物群系
自定义的生物群系可以很轻松的从默认的生物群系复制而来, 你只需要做这些;
1. 进入你的世界的文件夹, 接着加入设置, 接着是生物群系, 接着是默认.
2. 找到你想要的生物群系.
3. 复制 <biome>.json 文件 (推荐 FileZilla), 接着上传或者粘贴进在同一个文件夹下的自定义文件夹.
4. 将名字改为你想要改的名字. (不要改 .JSON)
5. 清空世界文件夹, 除了设置文件夹.
6. 启动你的服务器, 然后确认你的自定义生物群系被加载了.使用 /ewg tp <name> 或检查列表.

  1. "biomeType": "<type>"

EpicWorldGenerator -- Advanced
方块几率与条件 (Block conditions and probability)
所有方块的放置都基于配置. 我们使用了更多的高级设置来实现这个.
这些设置看起来可能很简单, 但是他们提供了很多高级的功能. 它支持独立或依赖的概率和基于条件的方块选择.
条件
一个方块的放置可以有多个条件. 你可以把这些条件结合起来. "或"条件可以将一个方块放置多次.
这里是可以使用的条件;
* 高度条件
* 倾角条件
* 相对高度条件

EpicWorldGenerator -- Advanced
用噪波自定义你的地形 (Custom terrain using noise)
大部分 EpicWorldGenerator 生成的地形都使用梯度噪波算法. 这是维基百科对梯度噪波算法的描述;
Gradient noise is a type of noise commonly used as a procedural texture primitive in computer graphics. It is conceptually different, and often confused with value noise. This method consists of a creation of a lattice of random (or typically pseudorandom) gradients, which are then interpolated to obtain values in between the lattices. An artifact of some implementations of this noise is that the returned value at the lattice points is 0. Unlike the value noise, gradient noise has more energy in the high frequencies.
谷歌机翻
梯度噪声是计算机图形中通常用作程序纹理原语的一种噪声。 它在概念上是不同的，经常与价值噪音混淆。 该方法包括随机（或典型的伪随机）梯度的格子的创建，然后将它们内插以获得晶格之间的值。 这种噪声的一些实现的假象是格子点处的返回值为0.与值噪声不同，梯度噪声在高频中具有更多的能量。

最常用的梯度噪波算法是 Perlin算法(https://en.wikipedia.org/wiki/Perlin_noise) 和 open simplex 噪波算法(https://en.wikipedia.org/wiki/OpenSimplex_noise). 插件使用的噪波类型取决于 world-settings.json 里的设置. 当你打开 world-settings.json 文件, 你就会发现这样一行:
  1. "useOpenSimplexNoise": false,
复制代码
如果 "useOpenSimplexNoise" 设置为 false, 插件就会使用 Perlin 算法来生成地形. 阅读以下文章了解这两个概念.
Perlin 是给有更多内存的服务器使用的, 并且会使用更多的 CPU. 尽管这两个算法都很相似, Open Simplex 更推荐那些没有内存和CPU的服务器使用. 并且 Perlin 并不会创造更好的地形, 还会使用更多资源.

使用噪波创建地形
为了简化这个过程, 我们先来学习1维的噪波.
我们先从一层开始. 我们创建了更多频率更高的噪波层. 我们还下降了下一个层的幅度. 这让我们能够生成一个很酷的地形.
如果我们把所有的层堆在一起, 取最顶端, 就会看到这样一个地形;
这个噪波会表现在地形的顶端. 如果没有噪波, 插件就会使用 "baseheight" 属性来生成Biome. 这是一幅 EWG 如何工作的插图;
绿线代表基础高度. 蓝线代表海平面. 黑线代表噪波图形. 灰线是另一个层, 使用更高的频率和更小的幅度. 地形的高度是这样计算的;
基础高度+ 主层+ 第二噪波层 = 地形高度
基础高度属性在下方有更详细的解释.
请务必看看 "Frequency" 和 "Octaves" 于 http://www.redblobgames.com/maps/terrain-from-noise/
在弄清楚地图是如何通过噪波产生和它们使用的不同变化之后, 我们可以根据这些来制作自己的独特地形.
首先, 让我们在配置它们之前先搞清楚地形的数据.
打开你的 <biome>.json 文件, 位于 world > settings > biomes > (custom 或 default).
你可以根据 json 语法粘贴下以下内容. 下面已经提供了一份配置好的文件, 这样你在实际操作时就不会急的头皮发麻.
如果您正在使用以下指南,请不要使用自定义地形以外的其他内容,因为其他的内容(以及自定义地形，但我们正在编辑)只是默认配置.
在biome.json文件中找到地形设置. 将生成器名称(引号内的文本)更改为“CUSTOM_EWG”, 名称必须为大写字母(不需要引号, 它们已经在.json文件中了).
你做完了这些, 接着让我们自定义吧.
