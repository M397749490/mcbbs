正文
   本教程词语和缩写以英文字母顺序排列
  • AAC：一个知名的反作弊插件，付费 站内帖 原帖
  • API：全称Application Programming Interface，应用程序编程接口。在Minecraft中可以理解为两个不同事物交互的接口。比如有两个箱子，你想将箱子A的物品移动到箱子B，你可以用漏斗连接，那么这个漏斗就是API。在Minecraft中有很多API，如Mojang API(原版)，Placeholder API(插件)，Forge API(Mod)
  • BC | Bungeecord：一种服务器核心，通过代理使玩家可以在多个服务器内切换，相比于一个服务器，多个服务器的Bungeecord可以使服务器的TPS更高(CPU和内存够用的情况下)，但Bungeecord配置较难，小白配置和开服时容易出现很多错误
  • CC：包含多个含义
                ①全称ChestCommands，一个图形Gui插件 站内帖 原帖
                ②全称CrazyCrates，一个抽奖插件 站内帖 原帖







  • Chunk：区块，每个区块长16格，宽16格，高256格。区块中还有强加载(所有事物都会运行)，弱加载(除实体和区块刻，其他都会运行)之分，它们的特性也不同
  • CO：全称CoreProtect，方块记录插件 站内帖 原帖
  • Config：全称configuration，指配置文件，通常指插件内的config.yml或客户端Config文件夹内的文件，玩家可以修改配置文件来更改一些游戏功能
  • CMI：全称ChangeMyInventory，一个优秀的基础插件，付费 站内帖 原帖
  • DIM：全称dimension，译名维度，一个维度代表着一个独立的世界，主世界的维度为1(DIM1)
  • ESS：全称Essentials，一个基础插件，大部分服务器正在使用 站内帖 原帖
  • GM：全称GroupManager，一个权限管理插件 站内帖 原帖
  • HD：Holographic Displays，全息图显示插件 站内帖 原帖
  • ILS：Item Lore Stats，一个RPG插件，低版本比较流行 站内帖 原帖
  • JDK：全称Java SE Development kit，即java标准版开发包，是Oracle提供的一套用于开发java应用程序的开发包，它提供编译，运行java程序所需要的各种工具和资源，包括java编译器，java运行时环境，以及常用的java类库等。
  • JRE：Java运行环境，它的全称Java Runtime Environment，因此也被称为JRE，它是运行java的必需条件。如果启动服务器的时候出现Java Runtime Environment一类提示，很可能是Java环境错误，需要重装Java
  • Json：全称JavaScript Object Notation，是一种数据存储格式，无法添加注释，如需了解语法请查看Json语法
  • JVM：Java Virtual Machine ，Java虚拟机，JRE包含JVM。JVM是运行java程序的核心虚拟机，还需要其他的类加载器，字节码校验器，以及大量的基础类库。JRM除了包含JVM之外，还包含运行java程序的其它环境支持。如果启动服务器时候提示Java Virtual Machine一类的提示，可能是服务器核心问题或者内存不足
  • KC：全称Kcauldron，是一种服务器核心，支持安装Mod和插件，目前只支持到1.7.10
  • LP：全称Luckperms，也是一个权限组插件，比GM更复杂但功能更丰富 站内帖 原帖
  • MM：全称MythicMobs，一个自定义生物插件 站内帖 原帖
  • MV：全称Multiverse-Core，多世界插件 站内帖 原帖
  • Mysql：是一种数据库管理系统，在全球非常流行，很多插件都支持Mysql储存，Bungeecord服务器也需要Mysql作为桥梁，关于如何搭建，您可以查看这里
  • PAPI：全称PlaceholderAPI，一个变量前置插件 站内帖 原帖
  • Ping：Packet Internet Groper，网络发包探索器，用于确定两台主机是否能进行数据交换，和两台主机间延迟，有时提示cant ping xxx，就是两台主机间无法进行数据交换，通常是因为连接超时或者某台主机根本就没有开启。但不要将ms混为一谈
  • Playerdata：一个储存玩家数据的文件夹，文件夹目录在世界名下，该文件夹下文件名都为玩家的uuid
  • PP：全称PlayerPoints，一个点券插件 站内帖 原帖
  • Res：全称Residence，一款领地插件 站内帖 原帖
  • SQLite：也是一种数据库管理系统，相比Mysql，它更轻便小巧，适用于仅为了储存小型数据的情况下，不建议用在Bungeecord上，有一部分插件默认使用或者支持SQLite，如CoreProtect
  • SX：全称SX-attribute，一款RPG装备插件 原帖
  • Tick：循环程序的一个周期被称之为一刻。刻分为游戏刻，区块刻，计划刻，红石刻，它们的间隔时间通常不同。  
       游戏刻即TPS，每秒20刻
       区块刻在绝大部分地方都会执行。同时还有随机刻，会在可以执行区块刻的区块中执行，这也是
       作物生长的机制
       计划刻通常指一些方块的更新，如红石和水流更新
       红石刻会在红石机器内被提及，1红石刻=2游戏刻
  • Timings：Spigot中内置的功能，可以查看服务器内Tick的情况，从而判断服务器卡服的原因，这个功能在builds 1261被加入。如果你需要关于Timings生成报告的帮助，请阅读Timings分析教程
  • TPS：Ticks Per Second，每秒游戏刻，该数值最大为20，数值越低，服务器运行越缓慢，通常TPS大于16为良好，小于16即需要优化
  • UUID：Universally Unique IDentifier，通用唯一识别码，用来储存和区分对象。分为字符串，字符串(无连字符)，高低位，整数型组。很多实体都有UUID数据，每个玩家也对应着一个UUID
  • VV：全称VexView 一个Gui插件/Mod 原帖
  • YML：全称YAML Ain't a Markup Language，又称YAML，是一种特殊的配置文件格式，Minecraft的大部分插件配置文件格式都为yml，yml的语法很简单，如需了解请查看YML(YAML)语法
