★RPG战利品★
杀怪后掉落含有掉落物的箱子


插件介绍
Author: NightExpress
本插件的作者是NightExpress，他写过热门插件非凡RPG为很多人所熟悉
本插件的功能是：当玩家杀死怪物，其掉落物会以战利品箱子（头颅）的形式生成，当玩家拿走战利品后箱子即消失

搭配悬浮字插件 | 显示击杀者和过期时间
可安装HolographicDisplays前置，会在战利品箱子上显示怪物的击杀者和即将消失的时间

安装与使用
想要在战利品箱子上显示悬浮字，需安装HolographicDisplays前置，不安装也行

指令与权限
  • /rpgloot help - 插件帮助
  • /rpgloot reload - 重载插件
  • /rpgloot info - 插件信息

本插件没有任何权限需要给玩家

配置文件
config
该config已过时，仅为注释示例，请勿直接复制
  1. cfg_version: 1.1
  2. General:
  3.   # 如果你发现战利品箱的悬浮字和粒子效果位置异常，请开启此项
  4.   FixCenterLocation: false
  5.   # 只有击杀者可以拿战利品
  6.   ProtectDrop: true
  7.   # 战利品箱子（头颅）是否不可被挖掉
  8.   AllowBreak: false
  9.   # 战利品箱子消失的时间秒
  10.   TimeToLoot: 360
  11.   # 该插件掉落机制对普通怪物生效
  12.   ApplyToRegularMobs: true
  13.   # 该插件掉落机制对MM怪物生效
  14.   ApplyToMythicMobs: true
  15.   # 哪种实体不会受本插件影响
  16.   EntityBlackList:
  17.   - ARMOR_STAND
  18.   # 哪种MM怪物不会受本插件影响
  19.   MythicMobsBlackList:
  20.   - SkeletonKing123
  21. Item:
  22.   # 战利品头颅的材质
  23.   SkullHash: 'eyJ'
  24.   SkullHashAir: 'eyJ'
  25.   # 战利品箱子旁边显示的粒子效果
  26.   Particles:
  27.     Enabled: true
  28.     Type: 'SPELL_WITCH'
  29.   # 战利品箱子上方显示的悬浮字  
  30.   Holograms:
  31.     Enabled: true
  32.     List:
  33.     - '&7[&e战利品 &c%e%&7]'
  34.     - '&6> &e时间: &f%time%'
  35.     - '&6> &e拥有者: &f%owner%'
