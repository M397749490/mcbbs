那点击了这个纯文本之后呢会发现，所有编辑过的内容都变成了一堆代码..
这种代码就叫BBCode




比如说，在纯文本显示模式下，暗夜绿就会显示成这样：
  1. [color=#2e8b57]暗夜绿[/color]
复制代码
可以看到在color=的后面有一个#2e8b57，这个#2e8b57就是HEX颜色。
中文叫16进制颜色代码表。




所以HEX是什么？
大多数玩家估计都知道RGB是什么，毕竟这玩意可以帮助电脑提升30%性能
HEX其实和RGB都是颜色的表达方式，只是他们不相同而已

稍微翻译一下：

  • Your Message ：想要制作渐变文字的内容
  • # of Colors ：渐变过程颜色数量（数量越多效果越好，但是工程越大）
  • Color Presets ：这里可以选测渐变规则，有很多种可以选，制作炫彩渐变的话我们这里选Rainbow（彩虹）
  • Colors ：颜色，这里是你可以自己设定渐变的主颜色。一般设定过颜色数量后，这里会自动生成
  • Fade Type ：渐变方法，可以选垂直渐变、横向渐变等等，我们这里选择Horizontal（普通横向）
  • Output Code ：输出代码，这里填Hex Code + Text（16进制颜色代码+文字）
  • Result Display ：输出方式，这里选择是要在同标签页上打开还是新标签页打开
