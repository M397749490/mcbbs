指令：[minecart]
Standard Player CommandsAny player may use these commands. (Unless explicitly denied via permissions).
CommandReq. Arg.Opt. Arg.Permission NodeDescriptions
/mm infominecartmania.commands.infoShows a list of detailed minecart information for the server显示信息
/mm speed or /mm momentumminecartmania.commands.momentumshows the speed of the minecart the player is in.显示速度
/trucompass or /mm trucompassminecartmania.commands.trucompassShows the direction the player is facing.
/st or /mm stany word-sminecartmania.commands.stSets the station value for the player. It must be followed by any string, with numbers and letters. The -s flag saves the value so that it is not reset after 1 station.时间。
/throttle or /mm throttlepercentminecartmania.commands.throttleSets the speed of the minecart to either the indicated percent or the max speed of the cart, whichever is lower.
OP CommandsOnly players with OP privileges (or given specific permission, if using a permission plugin) can use these commands.
CommandReq. Arg.Opt. Arg.Permission NodeDescriptions
/mm helpNoneShows all available commands.
/mm reloadminecartmania.commands.reloadreloads the MCM config.yml
/mm ejectplayer nameminecartmania.commands.ejectEjects the given player from a minecart, if they are in one.
/mm permejectplayer nameminecartmania.commands.permejectEjects the given player from a minecart, and prevents them from re-entering any minecart. This resets if the command is used again for the given player, or if the server is restarted.
/mm clearemptycarts-d, rangeminecartmania.commands.clearemptycartsRemoves all empty minecarts from the server. If -d (destroy) is set, they will not be returned to their owners. If the range is set, only carts inside the range will be cleared.
/mm clearpoweredcarts-d, rangeminecartmania.commands.clearpoweredcartsRemoves all powered minecarts from the server. If -d (destroy) is set, they will not be returned to their owners. If the range is set, only carts inside the range will be cleared.
/mm clearstoragecarts-d, rangeminecartmania.commands.clearstoragecartsRemoves all storage minecarts from the server. If -d (destroy) is set, they will not be returned to their owners. If the range is set, only carts inside the range will be cleared.
/mm clearoccupiedcarts-d, rangeminecartmania.commands.clearoccupiedcartsRemoves all occupied minecarts from the server, dropping players where they stand. If -d (destroy) is set, they will not be returned to their owners. If the range is set, only carts inside the range will be cleared.
/mm clearallcarts-d, rangeminecartmania.commands.clearallcartsRemoves all minecarts from the server. If -d (destroy) is set, they will not be returned to their owners. If the range is set, only carts inside the range will be cleared.
/mm clearstalledcarts-d, rangeminecartmania.commands.clearstalledcartsRemoves any unmoving minecarts from the server. If -d (destroy) is set, they will not be returned to their owners. If the range is set, only carts inside the range will be cleared.
/mm clearmovingcarts-d, rangeminecartmania.commands.clearmovingcartsRemoves any moving minecarts from the server. If -d (destroy) is set, they will not be returned to their owners. If the range is set, only carts inside the range will be cleared.
/mm redrawminecartmania.commands.redrawSends updates to all connected players to force all clients to redraw minecarts. Causes 1 second of lag.
/mm hideminecartmania.commands.hideHides all minecarts from view. They will continue moving, but will drop any passengers, and can not be seen unless someone re-logins or /mm redraw is used
