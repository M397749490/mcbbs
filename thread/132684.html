ThermalExpansion附带的万能扳手的小MOD，此mod很小，主要用来转换各种科技类MOD（BuildCraft, IndustrialCraft, MFFS, RailCraft, Forestry, MineFactory Reloaded, Universal Electricity, Thermal Expansion）的金属锭和一个能调节物品朝向的万能扳手。

随着TE更新到2.4.6.0版，此MOD也更新到了3.1.6.0，但是没人汉化，我作为BBS菜鸟，就挑简单的来练练手。

PS：至于为何我要翻译成泛型工具。我看到高级程序设计中有泛型这个概念。百度解释 感觉很高贵的样子，于是就拿来用了。

更新信息

3.1.6.0:
-Bugfix: Fixed an intermittent crash on high latency servers.

3.1.5.0:
-Added: OmniWrench will now work with Trapped Chests (Thanks Greg!)
-Changed: OmniWrench will now work with Greg's new awesome wrench system. (Thanks Greg!)
-Known Issue: Wrenching GT machines is not always consistent; this is actually on Greg's end as GT wrenches behave the same way.

3.1.4.0:
-Updated new to CoFHCore framework and supporting APIs.

3.1.3.0:
-Bugfix: OmniWrench will properly fix disabled TE engines again.

3.1.2.0:
-Added: OmniWrench will now rotate entities it strikes. (Combat hilarity.)
-Bugfix: OmniWrench will no longer rotate levers improperly.

3.1.1.0:
-Added: Update Notification Option.
-Changed: Updated to IC2 API version 304.

3.1.0.0:
-IMPORTANT: Port to 1.5.1. This mod now requires CoFHCore.
-Bugfix: Lexicon no longer eats ingots.
