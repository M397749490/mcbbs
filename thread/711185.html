标题: 1.7.10mod服 COFH 与 Residence 4.x 取流体权限问题
COFH是热力膨胀的前置。
Residence 4.x是重制的领地插件，现在保持更新


这个问题困扰我好久了，配置文件也全改了，游戏内COFH的指令也打遍了，COFH与Res4的Github也反馈了，但一无所获。
出错环境：
Thermos 1.7.10 Forge 1614(K锅端也不行) + CoFHCore-3.1.4-329(最新版) + Residence 4.x(任意版本)


大致是这样的：
A = OP B = 普通玩家
A圈了地，然后放一桶水(任意流体)在领地内，set build destroy ...所有权限都设为False(bucket权限在4.x某版被移除了，destroy和build包括bucket权限，但是有bucket权限的旧版也是不行的)。此时，B可以用任何容器包括可以取流体的武器(比如TE中的移液器)可以无视权限取水(无任何提示)。
如果说权限不包含bucket，也不可能。我删除COFH发现测试正常，无权限取任意液体。
由于COFH有对玩家权限的一些调整，我怀疑是不是COFH与Res在权限上冲突所致

另一款领地保护插件RedProtect测试正常，与COFH兼容完美（我也不知道什么鬼 但那个也有bug 装了要不出错要不生成不了凋零）
