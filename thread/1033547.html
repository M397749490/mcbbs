单个fill不能突破上限
但是多个可以啊
以1.15.2为例

比如说我在一tick内依次执行了下面这些命令：
  1. summon armor_stand ~ ~ ~ {Tags:["fill"]}
  2. execute as @e[type=minecraft:armor_stand,tag=fill] at @s run fill ~ ~8 ~ ~31 ~39 ~31 minecraft:bedrock replace
  3. execute as @e[type=minecraft:armor_stand,tag=fill] at @s run teleport @s ~ ~ ~32
  4. execute as @e[type=minecraft:armor_stand,tag=fill] at @s run fill ~ ~8 ~ ~31 ~39 ~31 minecraft:bedrock replace
  5. kill @e[type=minecraft:armor_stand]
复制代码

就可以填充一个32x32x64的区域了
你所要做的就是让这个带有特定tag的盔甲架以每32x32x32的空间为单位遍历一遍你要填充的区域就OK了
放张填充草方块为地狱岩的效果
