(开服Bat文件设置帮助)

  1. 默认的Bat可以启动服务端根据自身需要修改
  2. <a href="home.php?mod=space&uid=39305" target="_blank">@echo</a> OFF
  3. title [椰汁整合 CB 1.7.2]
  4. java -Xincgc -Xms1g -Xmx1g -jar spigot-1.7.2-R0.4.jar
  5. pause
  6. ::512M代表给服务端分配多少内存
  7. ::一般1024M以及130KB的上传带宽可以开一个20人的服务器
  8. ::如果你要修改 请把两个512M都改了
  9. java -Xms512M -Xmx512M -jar spigot-1.7.2-R0.4.jar
  10. pause

整合包的表层
云服最少12M网速
添加子服务器需要打开config内找到servers: 照这样的格式复制粘贴

  登陆服务器:
    motd: '&1Just another BungeeCord - Forced Host' [这里是子服务器IP]
    address: localhost:25564 [这里是子服务器端口 localhost代表本机]
    restricted: false

不需要把
ip_forward: true
online_mode: false
也复制粘贴
