Hi大家好，我是末影矿工，开学后好久不给大家做教程了。今天给大家做的是第三个智（keng）能（die）化生物---骷髅。部分内容转自Youtuber Dragnoz大大。来张截图（镇楼五大神）：

-----------------------------------------------<分界线>-----------------------------------------------
一号技能：吃鸡进化（上次吃猪这次吃鸡。。。）
当骷髅吃鸡后就会变成凋灵骷髅，凋零骷髅有更强的攻击方式加上自带火焰箭。首先我们要创建变量ST：
  1. /scoreboard objectives add ST dummy
复制代码
然后再用高频红石连上5个命令方块：
  1. execute @e[type=Skeleton] ~ ~ ~ effect @e[type=Chicken,r=5] <a href="tel:20 1000000 1">20 1000000 1</a>
复制代码
  1. scoreboard players set @e[type=Skeleton] ST 1 {SkeletonType:1b}
复制代码
  1. scoreboard players set @e[type=Skeleton] ST 0 {SkeletonType:0b}
复制代码

  1. execute @e[type=Chicken] ~ ~ ~ entitydata @e[type=Skeleton,r=5] {SkeletonType:1b}
复制代码
  1. execute @e[type=Skeleton,score_ST_min=1] ~ ~ ~ effect @a[r=1] 7 1 1
复制代码
第一个指令就是当骷髅发现周围有鸡时将鸡弄上凋灵效果，第四个是让所有鸡给周围更改周围骷髅标签变成凋零骷髅。这两个命令方块是给骷髅变异用的，第二个是给所有凋灵骷髅ST弄成1,第三个是让所有普通骷髅ST设为0。这两个是用来给分辨普通骷髅和凋灵骷髅的，在后头会用到很多。最后一个是让所有ST大于等于1（凋零骷髅）的骷髅让靠近自己的玩家收到瞬间伤害2的攻击。所以凋零骷髅是十分强的。
-----------------------------------------------<分界线>-----------------------------------------------
二号技能：自动切换武器
这个是Dragnoz大大的作品，被我稍微改了一下。首先创造变量Pumpkin：
  1. /scoreboard objectives add Pumpkin dummy
复制代码

这个部分指令虽然很多，但是很容易理解（所有命令方块都要用高频连上。。。）：
  1. execute @a ~ ~ ~ replaceitem entity @e[type=Skeleton,r=5] slot.weapon minecraft:iron_sword 1 0
复制代码
  1. execute @a ~ ~ ~ replaceitem entity @e[type=Skeleton,r=5] slot.armor.head minecraft:lit_pumpkin 1 0
复制代码
  1. execute @a ~ ~ ~ scoreboard players set @e[type=Skeleton,r=5] Pumpkin 1
复制代码
  1. execute @a ~ ~ ~ effect @e[type=Skeleton,r=5] 1 1 5
复制代码
第一、二、四个指令分别是让玩家给周围的骷髅戴上南瓜灯、手持铁剑、速度大幅提升，第三个是让那个骷髅Pumpkin变量为5（这个有啥用？呆会你就知道了）。
下面是如何恢复，当你跑远那只骷髅后，骷髅就会切换回去，首先创建变量tamer
  1. /scoreboard objectives add tamer dummy
复制代码

然后用高频红石连上下面几个命令方块：
  1. scoreboard players add @e[type=Skeleton] tamer 1
复制代码
  1. replaceitem entity @e[type=Skeleton,score_tamer_min=60] slot.weapon minecraft:bow 1 0
复制代码
  1. scoreboard players set @e[type=Skeleton,score_tamer_min=60] Pumpkin 0
复制代码
  1. scoreboard players set @e[type=Skeleton,score_tamer_min=61] tamer 0
复制代码
第一条指令是给所有骷髅一直加上1点tamer变量，第二个指令时给所有tamer大于60的骷髅手上再次拿上弓箭，第三个是给tamer大于60的骷髅设置变量Pumpkin为0，最后一个是当骷髅tamer到61时再次把tamer设为0，所以你离开骷髅后一会他就会切换回弓。
-----------------------------------------------<分界线>-----------------------------------------------
三号技能：骑蜘蛛
这个也是Dragnoz大大的发明。。。首先创建变量SJ
  1. /scoreboard objectives add SJ dummy
复制代码
然后再用高频连上四个命令方块：
  1. execute @e[type=Skeleton,name=!Skelly] ~ ~ ~ scoreboard players set @e[type=Spider,r=5,name=!Spidey] SJ 1
复制代码
  1. execute @e[type=Spider,name=!Spidey] ~ ~ ~ scoreboard players set @e[type=Skeleton,r=5,name=!Skelly] SJ 1
复制代码

  1. execute @e[type=Skeleton,score_SJ_min=1,name=!Skelly] ~ ~ ~ execute @e[type=Spider,r=5,name=!Spidey] ~ ~ ~ summon Skeleton ~ ~ ~ {CustomName:Skelly,Riding:{id:Spider,CustomName:Spidey}}
复制代码
  1. tp @e[score_SJ_min=1] ~ ~-600 ~
复制代码
这几条指令比较繁琐，新人可能会理解不了。前两条意义是分别是让名字不是Skelly的Skeleton和名字不是Spidey的蜘蛛将周围的名字不是Spidey的蜘蛛和名字不是Skelly的骷髅的变量SJ设为1，第三个指令时让变量为1的名字不叫Spidey的蜘蛛生成一只骷髅骑士，骷髅骑士中骷髅的名字为Skelly然后蜘蛛的名字为Spidey，最后一条指令是让所有SJ为1的生物tp到虚空。连起来差不多就是当骷髅遇到蜘蛛后蜘蛛生成骷髅骑士然后原骷髅和原蜘蛛一起tp到虚空，就像骑上去了一样。为了防止游戏难度的增加，我让凋灵骷髅骑上蜘蛛骑士后变回普通骷髅。再加上我上次弄得增强智能化蜘蛛的教程，蜘蛛骑士会变得十分难对付。
-----------------------------------------------<分界线>-----------------------------------------------
四号技能：防晒
有人可能会问为何把防晒放到最后？因为这次的防晒不想上次增强智能化僵尸那篇教程那么简单，有凋灵骷髅，还有变成近战模式后的骷髅会戴上南瓜灯，所以我放到了最后。下面的几个命令方块同样要连上高频红石：
  1. replaceitem entity @e[score_Pumpkin=0,type=Skeleton,score_ST=0] slot.armor.head minecraft:skull 1 0
复制代码
  1. replaceitem entity @e[type=Skeleton,score_Pumpkin=0,score_ST_min=1] slot.armor.head minecraft:skull 1 1
复制代码
第一个指令是让所有Pumpkin为0的骷髅、凋灵骷髅戴上各自的头颅，判断方式为ST。刚才在上面自动切换模式那部分中讲到了每过60秒就会切换回远程模式并把Pumpkin清零就是为了做这个，如果像上次僵尸那篇干脆一直给他们戴上僵尸头的话就会代替掉近战的南瓜灯。

对抗攻略：
这次的骷髅远程进程都有了加强，甚至会和蜘蛛联手合力攻击。对骷髅的最佳武器还是弓，应为升级后的骷髅近战比远程更强了，所以你就让他没有换剑之前干掉他，而且和增强凋灵骷髅对抗简直就是想自寻死路，一靠近你就把你瞬间秒杀了。不过用弓也不是说就会十分安全，因为凋灵骷髅的弓会射出火焰，千万不能被打中。
