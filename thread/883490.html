标题: Minecraft 基岩版 1.12.0 发布
本帖最后由 WuGuangYao2012 于 2019-7-10 10:08 编辑

Minecraft 基岩版是指包括Minecraft 手机版（Android、IOS）、Win10版（VR）、主机版（XboxOne、NS）在内，使用“基岩引擎”（C++语言）开发的Minecraft统一版本。

正式版是Minecraft 基岩版经过一段时间的测试版测试之后得到的稳定版本，也是众多材质、Addon和官方领域服会逐渐跟进的版本。与此同时Google Play、Win10 Store等官方软件商店也会推送此次更新。



该版本的GooglePlay平台更新将推迟数天


Changes:
更改：
  • Increased the frequency and volume of the ambient mob sounds made during raids, to make them easier to locate
  • 增加了袭击事件期间的周边环境声音的频率和音量，使其更容易被确定位置
  • Added new Wandering Trader sounds (MCPE-41191)
  • 添加了新的流浪商人的声音 (MCPE-41191)
  • Updated the main menu splash text
  • 更新了主菜单的闪烁标语
  • Updated the default main menu panorama from Aquatic to Village & Pillage
  • 更新了水域更新到村庄掠夺更新的主菜单背景图
  • The "Store" button on the main menu has been renamed to "Marketplace"
  • 主菜单上的“商店”按钮已重命名为“市场”
  • Realm owners can now set relevant permissions for players invited to their Realm
  • 领域的拥有者现在可以为被邀请到其领域的玩家设置相关的权限
The owner can set permissions for an invited player to either visitor, member or operator
When resetting a world, or uploading a new world, already set permissions stay in place
可以为进入领域的所有新成员设置默认的权限
拥有者可以将受邀玩家的权限设置为访客，成员或管理员
重置世界或上传新世界时，已设置的权限保持不变

bug修复
修复了155个bug

For Map Makers and Add-On Creators:
给地图和附加包制作者：
  • 更新了1.12.0的资源包、行为包、文档和示范包的模板，可以在aka.ms/MinecraftAddons下载
  • 添加了一个屏幕来查看内容日志错误
  • 日志屏幕可以使用Ctrl+H打开，或者进入设置→配置文件
  • 为基岩版专用服务器上的制作者启用内容日志记录调试包错误
  • 生物事件可以使用新的/mobevent命令切换了
  • 粒子发射器现在可以触发斜杠命令，actor事件和MoLang表达式
  • 增加了一次性动画支持，允许在实体上执行单个动画
  • 动画和粒子无需链接实体即可加入
  • 现在可以由动画事件触发声音效果
  • 加入命令方块的自动完成功能
  • 加入命令方块的延迟选项功能
  • 可以使用新字符给命令方块添加延迟函数，延迟多少由红石的延迟刻决定
数据驱动的合成配方（实验性）
  • 允许使用行为包定制合成配方，用于有序合成，无序合成和熔炉的配方
  • JSON文件已添加到行为包模板中
添加新的简易物品（实验性）
  • 可以使用行为包将新的“简易”物品添加到游戏中
  • 目前只使用了部分组件，会在未来的更新中添加了更多组件以允许更复杂的行为
  • 某些物品（比如食物）现在是数据驱动的，它们的JSON文件已添加到了行为包模板中
添加新的简易方块（实验性）
可以使用行为包将新的“简易”方块添加到游戏中
目前只使用了部分组件，会在未来的更新中添加了更多组件以允许更复杂的行为
增加了新的数据驱动粒子：
  • 羊驼吐口水
  • 大爆炸
  • 彩色火焰
  • 红石灰烬
  • 掉落的沙子
  • 岩浆
  • 附魔台
  • 潮涌核心
增加了新的数据驱动动画：
  • 狼
  • 唤魔者的尖牙攻击
  • 箭
  • 潜影贝导弹
  • 弓
  • 水


Script Engine Updates:
脚本引擎更新：
（目前可在Windows 10版启用实验性游戏）

  • 针对方块的API V0
    • 新的针对方块的事件，和新的两个API已经包含方块查询功能，包括以下部分：
    • APIs
    • getBlock(Ticking Area, x, y, z)
    • getBlock(Ticking Area, PositionObject)
    • getBlocks(Ticking Area, x min, y min, z min, x max, y max, z max)
    • getBlocks(Ticking Area, Minimum PositionObject, Maximum PositionObject)
    • Events
    • block_destruction_started
    • block_destruction_stopped
    • piston_moved_block
    • player_destroyed_block
    • player_placed_block

  • 针对物品的API V0
    • 基本物品相关事件项已经可公开用至脚本API。包括以下：
    • actor_acquired_item
    • actor_carried_item_changed
    • actor_dropped_item
    • actor_use_item
    • actor_equipped_armor

  • 针对物品栏的API V0
    • 基本物品栏事件项已经可公开用至脚本API。包括以下：
    • inventory_container
    • armor_container
    • hand_container (note that the hand container will get you both the main hand and offhand)
    • （注意会同时应用到左右手）
    • hotbar_container

executeCommand APIexecute指令API
  • 允许脚本API获取斜杠命令的使用结果

Event Data API数据事件API
  • 允许创建和注册事件数据，并将其传递给事件函数。
