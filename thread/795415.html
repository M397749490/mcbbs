Q&A:
Q1:我的软件打开后显示Not found the kernel library or the kernel library is invalid?
A1:请下载最新版本的修复版。
Q2:为什么我无法填写物品名称等东西？
A2:请将标题栏点亮，这代表启用这项，之后才可以填写这一栏的内容。
Q3:在游戏中输入指令后显示错误的命令参数
A3:你是否使用了1.13及以上版本？本软件暂时不支持1.13，如果你想，你可以尝试修复，比如 /give @p a b c {d} 改为 /give @p a{d} b 来修复(不保证能修复成功)
Q4:但是他还是用不了怎么办
A4:作者建议：建议别用 用指令生成器 他不香吗
