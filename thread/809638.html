  1. ShopName: example-shop
  2. DisplayName: '&aExample Shop'
  3. Command: example:ex
  4. signs:
  5.   text: '[example-shop]'
  6.   NeedPermissionToCreateSign: true
复制代码

你可以在一个商店文件的开头自行决定。需要注意的是，在主配置文件中你必须启用这项设置：
  1. # EnableSigns:
  2. # If set EnableSigns to 'false' BossShop signs will be disabled.
  3. EnableSigns: true
复制代码
否则将不会启用牌子。
