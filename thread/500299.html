1、此贴是国内第一帖塞尔达的正式教程。国内对于塞尔达mod无任何资料可查，MC百科只有40余物品介绍，无任何怪物等介绍。因此很难做到百分百准确无误。
2、以下所有数据均为LZ亲测。mod版本为2.2.6。
3、物品获得方法里只写已确定的途径。譬如：隐藏房里没爆过面具，但不代表面具一定不会出现在隐藏房中。可能是我人品差没爆过。

2、怪物副本
所有副本在未进去前，墙壁都是无法被破坏的。开启副本后副本密闭，进副本前在该副本内放置的所有方块全部消失。但是墙壁可被凿开。
因为主世界隐藏房非常难找，而各种副本钥匙主要来源于主世界隐藏房的宝箱。因此钥匙极其难找。
然而这并不能难倒充满着智♂慧的我们。
进入方法：末影珍珠立大功啦！

位置：低矮树林地形中
特征：从门缝里望去，中间插着一把剑。
难度：开启副本后墙壁四周会刷出3格高度的一层蜘蛛网。在四个角落刷出四只洞穴蜘蛛（副本精英怪）。
————————————————————————————
不得不承认，我真是个天才！锋利IV钻石剑打蜘蛛一下3血，怎么可能硬碰硬？但是只要按照我的方法，只要操作熟练，几乎可以不用受到任何来自怪物的伤害就可通关。
准备：N桶岩浆、N组末影珍珠、一组垫脚物，可以带几瓶抗火药剂。
最重要的：临危不乱的内心。
方法：开启副本后迅速扔一颗末影珍珠到周围的墙壁上，你会掉入蜘蛛网里。这样蜘蛛就无法攻击到你。（有时还是会打到）。此时：（二选一）
————————————————————————————
1、迅速挖开墙壁，出去再填上。上到副本顶部，向底部灌入岩浆，注意放置岩浆后要堵住岩浆源上方，防止蜘蛛顺着岩浆上到顶层。找到副本内宝箱位置，下到底部从外面试探着挖开墙壁取走箱子里的物品。越快取走越好。
2、迅速在上方放置方块，然后扔末影珍珠使你下落时正好掉在刚放置的方块上。如图。砖块代表你踩着的方块；海绵代表你用来阻挡蜘蛛上爬的方块；砂石代表岩浆源。时刻盯着箱子有没有被破坏。毕竟刷副本就为了这个箱子。

    // rarity may be 1 or 0, with 1 being more rare
            @Override
            protected void dropRareDrop(int rarity) {
                    if (getType() == KeeseType.CURSED) {
                            switch(rarity) {
                            case 1: entityDropItem(new ItemStack(ZSSItems.treasure,1,Treasures.EVIL_CRYSTAL.ordinal()), 0.0F); break;

                            default: entityDropItem(new ItemStack(rand.nextInt(8) == 0 ? ZSSItems.smallHeart : ZSSItems.heartPiece), 0.0F);
                            }
                    } else {
                            switch(rarity) {
                            case 1: entityDropItem(new ItemStack(ZSSItems.treasure,1,Treasures.MONSTER_CLAW.ordinal()), 0.0F); break;
                            default: entityDropItem(new ItemStack(rand.nextInt(3) == 1 ? Items.emerald : ZSSItems.smallHeart), 0.0F);
                            }
                    }
