标题: 破坏农作物方块时如何获得掉落的实体列表？
block.getDrops()拿到的Collection<ItemStack>的好像不行,我明明掉了两个，可是itemstack.getAmount()输出的是 1，不知道是不是我用法错误，代码如下：
@EventHandler
public void harvestCrop(BlockBreakEvent event){
    Block block = event.getBlock();
    Player player = event.getPlayer();
    if(block.getType().getData() == Material.CROPS.getData()){
        Collection<ItemStack> drops = block.getDrops();
        List<ItemStack> itemList = new ArrayList(drops);
        player.sendMessage("§2CropExpert §总共获得："+itemList.toString());
        player.sendMessage("获得的物品:");
        for(ItemStack i :itemList){
            player.sendMessage("=========>§a"+i.getData()+"§f:§a"+i.getAmount()+"§f个");
            CropDataUtil.save(player,i,i.getAmount());
        }
    }
}






作者: 吕易天    时间: 2019-11-16 16:36
block.getDrops只是获取一般情况下它会掉的物品，而不是实际掉的物品，如果要获取实际掉落的物品你需要用ItemSpawnEvent
作者: 我的锅    时间: 2019-11-16 17:44
e.getBlock()是玩家在服务端破坏方块这一动作发生之前就确定的，故其无法获得服务端还未计算的的掉落物品信息。
