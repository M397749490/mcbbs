Features|插件特性


⑴更快地创建Spawners of MythicMobs

Descriptions|插件描述


㈠使用简单的点击创建Spawner

㈡本插件基于Spigot 1.12.2开发,理论支持全版本



Commands|插件命令


/DarkSpnrCrtr 别名:/darksc, /dsc

/dsc set <Spawner名称> <生物内部名> [Spawner配置] - 设置使用者的Spawner创建器

在Spawner名称中使用[c]代表Spawner序号

在Spawner配置中使用“配置名:值”的形式表示一条配置，使用“|”分割各条配置

与group配置搭配以充分发挥本插件功能

例: /dsc set test[c] Shwz group:testgroup|maxmobs:1

即可将创建器设置为'生成"Shwz"生物的名称为"test序号"的隶属于"testgroup"组的最大生物数为1的一系列Spawner'

在此后的配置中可使用"g:testgroup"同时操作所有隶属于"testgroup"组的Spawner

/dsc start - 将使用者的Spawner创建器设为开启状态，此时在创造模式下的管理员左键点击方块即可创建Spawner

/dsc end - 将使用者的Spawner创建器设为关闭状态

/dsc cset <数字> - 将使用者的下一个序号设置为指定值

所有命令均仅有管理员可执行
