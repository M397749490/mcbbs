请打开RPGitem文件夹中的config，把下面的defaults里面的内容照我这样改即可，属性的汉化只有RPGitem3可以做到哦~，如果我解答了您的问题，请最佳
pluginVersion:
localeDownload: true
autoupdate: true
defaults:
  hand: 手持
  sword: 介绍
  damage: 伤害
  armour: 防御
support:
  worldguard: false
  residence: true
