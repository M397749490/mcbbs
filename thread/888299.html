匿名函数

在FP范式的编程语言中，函数是[ruby=First-class Object]一等对象[/ruby]，也就是说函数不光能绑定到作用域内的一个标识符上被调用，还能作为一个拥有[ruby=Function Type]函数类型[/ruby]的值存在。我们通常将其称作[ruby=Anonymous Function]匿名函数[/ruby]。匿名函数可以有0个或多个参数，其语法如下例所示：
  1. val f0: () => String = () => "bar"
  2. val f1: String => String = s => s ++ " bar"
  3. val f2: (String, String) => String = (s0, s1) => s0 ++ " " ++ s1
复制代码
可以使用[ruby=Placeholder Syntax]占位符语法[/ruby]来定义匿名函数：
  1. val f1: String => String = _ ++ " bar"
  2. val f2: (String, String) => String = _ ++ " " ++ _
复制代码
匿名函数可以指定其从参数的数据类型：
  1. () => "bar"
  2. (s: String) => s ++ " bar"
  3. (s0: String, s1: String) => s0 ++ " " ++ s1

高阶函数

既然函数可以作为一个值存在，那么就可以将函数本身作为其他函数的参数或返回值，这类计算其他函数的函数叫做[ruby=Higher-order Function]高阶函数[/ruby]。高阶函数本身是一个很简单的概念，但其却是FP范式最重要的思想之一，高阶函数赋予了FP强大的表达能力。理论上只需要高阶函数就能实现一个图灵完备的编程语言，甚至数据类型、控制结构本身都可以靠高阶函数来实现。可以很方便的在Scala中使用高阶函数，其语法如下例所示：
  1. def checkString(s: String, p: String => Boolean): String = if (p(s)) s else ""
  2. val checkString: (String, String => Boolean) => String = (s, p) => if (p(s)) s else ""

柯里化

[ruby=Currying]柯里化[/ruby]是指将有多个参数的函数变换为只有1个参数，返回值为函数的高阶函数，例如：
  1. val concat: (String, String) => String = (s0, s1) => s0 ++ s1
复制代码
可以被变换为：
  1. val concate: String => (String => String) = s0 => (s1 => s0 ++ s1)
复制代码
由于括号的结合性，可以省略掉最右边的括号，简写为：
  1. val concate: String => String => String = s0 => s1 => s0 ++ s1
