作者: MC_tingfeng    时间: 2019-5-28 07:32
在你的服务器根目录下找到spigot.yml 文件，用记事本或者notepad打开
往下翻，找到下面这些
  1. merge-radius:
  2.       exp: 3.0
  3.       item: 2.5
  4.     chunks-per-tick: 350
  5.     clear-tick-list: false
  6.     enable-zombie-pigmen-portal-spawns: true
  7.     zombie-aggressive-towards-villager: true
  8.     use-async-lighting: true
  9.     item-despawn-rate: 6000
复制代码


这里有一个item-despawn-rate   你看下这个数值，如果是是0或者1之类的，就会出现你说的东西扔地上就消失的情况
