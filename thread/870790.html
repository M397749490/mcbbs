标题: 如何做一个类似燃烧弹的效果？
有一个盔甲架名字叫“oil”只要在它范围内5格的玩家和僵尸都会燃烧，要怎么做？在1.14.2版本。
作者: 底层咸鱼    时间: 2019-6-2 22:18
本帖最后由 897412176 于 2019-6-8 09:42 编辑

玩家的话，可以找一些代替的方法……
例如在玩家上方召唤着火的箭，来让玩家达到着火的效果。
或者你可以干脆改成放置火方块：
execute at @e[type=armor_stand,name=oil] as @e[type=zombie,distance=..5] at @s if block ~ ~ ~ minecraft:air run setblock ~ ~ ~ minecraft:fire
execute at @e[type=armor_stand,name=oil] as @a[distance=..5] at @s if block ~ ~ ~ minecraft:air run setblock ~ ~ ~ minecraft:fire

作者: Chelover_C60    时间: 2019-6-6 10:20
  1. /execute at @e[type=armor_stand,name=oil] as @e[type=zombie,distance=..5] run data merge entity @s {Fire:20}
复制代码
这个命令可以让名为oil的盔甲架周围5格以内的僵尸着火20个游戏刻。可以放到循环命令方块里激活
