Easy Island Miner


前言
制作这个插件的原因，是因为有人在联机问答版问我要能够在空岛服使用的让玩家能从刷石机获得矿物的插件。而站内找到的插件很多都要不然不能自定义矿物掉落率，要不然装上后所有世界都能使用，要不然就没有权限设置。于是就想着做个更加完善的空岛刷石机出矿插件发出来——就是这个Easy Island Miner。



特性

本插件的特性有：
◇支持插件在指定的世界才能生效，让别的世界的玩家无法使用刷石机刷矿
◇支持设置多个掉落组，并为不同的掉落组设置不同的权限，只有拥有相应权限的玩家才能按照相应组挖出掉落物
◇支持手持物品创建掉落项目，项目的物品可以为任何物品，支持NBT，概率也可以自行设置
◇只有水和岩浆生成的圆石才会被判断为刷石机产物，并且每分钟清理一次判断的方块，防止刷矿和卡服

配置

无



权限
easyislandminer.admin
查看帮助，使用所有指令




指令

管理

/eim
显示插件信息
/eim help
显示总指令帮助
/eim world <world>
设置插件生效的世界
掉落组
/eim group
 显示掉落组指令帮助
/eim group create <组名>
 创建一个掉落组
/eim group delete <组名>
 删除一个掉落组
/eim group rename <组名>
 重命名一个掉落组
/eim group list [页码]
 列出掉落组列表
/eim group perm <组名>
 设置本组的权限，可以随意自定义，可以与别的组叠加
/eim group add <组名> <项名>
 向一个组添加一个项，项可重复
/eim group remove <组名> <序号>
 从一个组中移除一个项
/eim group listdrop <组名> <页码>
 列出一个组拥有的所有项



掉落项
/eim drop
 显示掉落项指令帮助
/eim drop create <项名> <概率>
 创建一个掉落物为手上物品的项
/eim drop delete <项名>
 删除一个掉落项
/eim drop list <页码>
 列出所有的掉落项
/eim drop rename <旧项名> <新项名>
 重命名一个掉落项
/eim drop change <项名>
 用手中物品替换一个项目中的掉落物
/eim drop rate <项名>
 更改该项目的掉落概率






前置插件

Skript


使用说明


此插件用Skript编写，需要先安装Skript插件

安装前置
1.下载skript
2.将.jar文件放入plugins文件夹
3.运行服务器

安装本体
1.下载压缩文件
2.解压获得easyIslandMiner.sk
3.扔进plugins/skript/scripts
4.使用“/sk reload all”指令
