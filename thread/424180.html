介绍
就是能够让你箱子里的物品一个个蹦出来~



Command/Permission

一般情况下不用给权限



教程

1.创建一个drop party：/dp create <party>
2.设置一个drop party的使用箱：/dp set chest <party>
3.给箱子添加物品：/dp set itempoint <party>
(可以手动打开箱子添加也可以通过这个指令添加)
4.设置烟花：/dp set fireworkpoint <party>
(可以不用设置)
5.开始一个drop party：/dp start <party>.




配合

这个插件可以配合'ScriptBlock'在制作副本的宝箱奖励,这会非常有趣！
这个插件还需要一个带恢复区块的插件来恢复这个箱子,例如CoreProtect
如果你想用这个插件来设置这个有趣的奖励方式,请保证以下几点!
1.就算默认没有也得上 -dropparty.teleport 这个权限
2.使用'ScriptBlock',需要设置好无视用户的权限来使用任何命令,详细方法不提供!
(因为我只有那个想法,可能行得通也可能行不通,没有去实际去测试)
3.必须打其他插件或者禁止所有传送方式来防止玩家轮回到奖励处
