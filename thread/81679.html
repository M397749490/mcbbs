THX的直升飞机MOD
鄙人已汉化
一、MOD介绍
欢迎您来到我们官（ban）方（yun）群组的直升飞机MOD！
这个mod增加了一个物品——直升飞机，操作简单，合成方法也简单，可以让您和您的基友漫游天际。
有很多在原始话题讨论的好主意：
http://www.minecraftforum.net/index.php?showtopic=246531
这是一个开放源代码的mod，任何人不参与。看下面的开发部分，并在GitHub拜访我们：
https://github.com/theoxylo/minecraft_mod_thx
快乐的飞翔吧！

二、制作
目前的合成配方是非常便宜和简单的——先造一条船，再添加一个屋顶（转子）！

四、选择和设置

  • #这些存储在.Minecraft/mods/mod_thx_options.txt文件里。
  • #请重新启动游戏应用更改。

  • #默认的控制是利用现有的Minecraft默认。
  • #请自定义您喜欢的控制。
  • #以下是默认配置
  • #直升机移动（基本是WASD移动按键）。
  • 键_前进 = W
  • 键_左移 = A
  • 键_后退 = S
  • 键_右移 = D

  • #直升机集体（减速，上/下，跳/潜行）
  • 键_上升 = space
  • 键_下降 = x

  • #音高模式切换。使用时，沥青更随玩家查看和W/A制控制减速
  • #简要显示世界坐标和高度（方块）
  • 键_看_沥青 = L

  • #离开直升机1.9块左右的谨慎使用而飞！
  • 键_离开 = y

  • #迅速返回沥青零有用全减速以避免碰撞
  • #当看沥青使用（见上图），重置零距当前视图
  • 键_乘_水平 = K

  • #允许直升机自然归零间距自动
  • 启动_乘_水平 =true

  • #返回到零减速时不积极上升或下降#如果禁用，您的转子速度将显示当前油门（非常容易动气的时刻）
  • 启动_乘_减速_零 =true

  • #包括与模型运动的转子#转子速度随减速-视觉效果高度
  • #依赖的帧率，所以实验找到一个愉快的结果
  • #或禁用如果一切都失败了
  • 启动_轮子=true

  • #定转子相对速度
  • 轮子_速度_百分比 = 70

  • #持有的后视图
  • 键_看_后退 = U

  • #创建当前区域地图
  • 键_创建_地图 = O

  • #保持直升机在当前的高度，再按下进行解锁
  • 键_锁_保持 = P

  • #开关平视显示器/相机模式下，模型隐藏
  • 键_平视显示器_模型 = C

六、安装教程
  • 1.如果你没有安装Forge，那么请在这里下载并安装Forge，Forge安装方法：打开Forge压缩包把里面的内容全部拖入.minecraft/bin文件夹下的minecraft.jar文件里，注意安装前先备份一个minecraft.jar文件，防止安装失败后无法打开游戏。
  • 2.下载THX的直升飞机MOD压缩包。
  • 3.把下载到的压缩包文件剪切到.minecraft/mods文件夹下。
  • 4.打开游戏享受吧！
