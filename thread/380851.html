首先这个功能直接就开启了的
其次你要改最好也只改value后面的数据
24小时会自动重启

restart:
  # 自动重启服务器功能
  # value 为“小时”
  # 如果服务器5分钟内没有人 将会自动重启服务器
  # 注意: 你需要在启动脚步中写死循环
  # 如果你不需要开启自动重启，那么true改为false即可
  use: true
  value: 24
  limit: 0
