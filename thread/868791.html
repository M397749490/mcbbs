标题: [前置|BCS] Bukkit Commons —— 基于BukkitAPI的Bukkit插件开发框架 [1.9+]
Bukkit Commons


与BCS同名的基于Bukkit API的超赞开发框架


简介:
Bukkit Commons 是一个基于 Bukkit API 的开发框架，使您的插件做到曾经无法做到的骚操作，节省开发时间，使用更优雅的方式构建插件代码。

包含:
  • 方块相关实用工具（取大箱子的另外一半、获取依附方块等）
  • 区块相关实用工具（目标区块是否已加载【快速】等）
  • 多彩文本实用工具（随机颜色上色、指定颜色上色、顺序指定颜色上色等）
  • Ticks工具（获取服务器当前tick和tps）
  • 自定义计时器实用工具（使用UUID为标识符的无性能占用计时器【精确到纳秒】）
  • 数据库（SQLite 与 MySQL）
  • 物品栏实用工具（链式创建InvGUI，取走物品等）
  • ItemStack转Json实用工具（调用NMS保存ItemStack为Json等）
  • 物品相关实用工具与链式物品编辑器（链式创建ItemMeta，获取物品耐久度百分比，YAML序列化ItemStack等）
  • 位置与位置判定实用工具（通过偏航获取玩家所看方块的BlockFace，平面/立体区域范围判定，平面/立体区域相等判定）
  • 友好的文本样式格式化工具（更人性化的物品名格式化【DIAMOND_SWORD到Diamond Sword】等）
  • 监听器注册管理器（批量注册/反注册插件监听器等）
  • Tellraw Json链式创建器（链式创建TellrawJson且可灵活合并多个TellrawJson对象）
  • 离线玩家使用相关工具（获取离线玩家的背包、末影箱等等数据进行操作）
  • ...更多绝赞功能正在路上！
