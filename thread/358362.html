首先，请看帖子 http://www.mcbbs.net/thread-273672-1-1.html
了解原理后自行修改。或是直接找到路径 /plugins/groupmanager/config.yml
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           all_unnamed_worlds:
  9.           - users
  10.           - groups
复制代码
替换为
  1.         world:
  2.           world_nether:
  3.           - users
  4.           - groups
  5.           world_the_end:
  6.           - users
  7.           - groups
  8.           此处替换为刷怪世界的名字:
  9.           - users       //只继承主世界的users.yml权限表，不继承groups.yml
  10.           all_unnamed_worlds:
  11.           - users
  12.           - groups
复制代码
修改后重启服务器或者重新加载权限插件/manload

之后复制主世界的groups.yml（在/plugins/groupmanager/worlds/world目录）到新生成的目录，即在/plugins/groupmanager/worlds/刷怪世界名/中，并使用notepad++（或类似文本编辑器）打开该文件作如下编辑：
1、修改相应组build:true为build:false            这样就移除了该组玩家的建筑权限（放置破坏等）
2、添加如下权限：
  1.     - essentials.build.drop.*         //丢弃
  2.     - essentials.build.interact.*     //交互
  3.     - essentials.build.pickup.*      //捡拾
  4.     - essentials.build.use.*          //使用
复制代码
以上代码中的*代指所有物品。
如果将*替换为物品id则代表只允许该物品的以上权限。
