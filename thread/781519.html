ForgeModBlocker —— 禁止玩家使用某Mod



介绍:

本插件可配置玩家允许或禁止使用的Mod，这是一款完全自定义可配置的插件。

此插件需要在Java 8环境下运行!

命令与权限:

/fmb 显示插件的版本
/fmb reload 重载插件
/mods <玩家名> 列出一个玩家的Mod列表

其他权限:

fmb.*
[size=14.6667px]此插件的全部权限

fmb.update_notification
玩家将收到可用插件更新通知。

fmb.bypass
拥有该权限的玩家将可以无视白名单/黑名单


配置文件:

  1. # ForgeModBlocker 配置文件汉化 by qq1737333652
  2. # 这是插件的前缀
  3. # 支持颜色代码
  4. prefix: "&c[&6FMB&c]&e"

  6. # 这个选项将禁止任何使用Forge的玩家的连接
  7. block-forge: false

  9. # 选择插件运行在哪个模式 有白名单和黑名单模式
  10. # whitelist: 白名单模式，只有安装有白名单上的Mod的玩家才能加入
  11. # blacklist: 黑名单模式，禁止安装有黑名单上的Mod的玩家加入
  12. mode: blacklist

  14. # 白名单或黑名单的Mod列表
  15. # 你必须在这里使用Mod ID
  16. # 如果要查找该Mod的 Mod ID 请安装此Mod在你的客户端再点击主界面的Mods按钮在里面寻找该Mod的ID
  17. mod-list:
  18. - examplemod

  20. # 这是是不被允许进入游戏的玩家执行的命令
  21. # 你可以设置踢出命令，这在玩家加入服务器时执行
  22. # 支持颜色代码
  23. # 变量:
  24. # %player% - 不被允许的玩家名
  25. # %mods% - 此玩家的所有Mod
  26. # %disallowed_mods% - 此玩家安装的不被允许的Mod
  27. # 如果要从BungeeCord中踢出玩家，请使用[bungeekick]而无需使用%player%变量
  28. # 例子: - "[bungeekick] &cIllegal Mods - %disallowed_mods%"
  29. disallowed-mods-commands:
  30. - "kick %player% &cIllegal Mods - %disallowed_mods%"

  32. # 插件的更新检查时间 以分钟为单位
  33. # 默认: 20
  34. update-check-interval: 20

  36. # 插件消息
  37. messages:
  38.   no_permission: "&c你没有权限"
  39.   mods_command_usage: "&c用法: /mods <玩家名>"
  40.   player_offline: "&c此玩家不在线"
  41.   player_not_using_forge: "&e%s 没有使用Forge" # 变量: 玩家名
  42.   player_mods: "&a%s 使用了Mod:" # Placeholders: 玩家名
  43.   mods_format: "&e%s &7- &a版本: &e%s" # Placeholders: Mod名, Mod版本
复制代码

获取Mod ID教程:

1.先把Mod放入游戏Mods文件夹内，启动游戏，在游戏主界面点击Mods按钮


2.在左侧选择Mod，右侧的第三行文字Mod ID:'XXX' XXX就是该Mod的Mod ID


3.最后把Mod ID填入配置文件，然后重载插件即可
