{简介}

·关于这款插件的功能.我想我一句话带过就行了:
输入指令/help，打开一个便携GUI.但不是点击执行，而是显示命令.

也就是说它把/help的显示方式GUI化了.能够限制哪些help显示给玩家，哪些不显示.

·所以这个插件非常轻量.搬运难度比以往相比几乎可以说是毫无挑战==
·但它非常实用，所以我就搬了~\(≧▽≦)/~

{配置}
  1. # 菜单上方显示的名字.请注意，不要使用颜色代码！
  2. name: help
  3. # 用来代替页码的物品.
  4. folderItem: CHEST
  5. # 用来代替命令的物品.
  6. itemItem: PAPER
  7. # 构建页码.自定义它们的名字.
  8. folders:
  9. - test1
  10. - test2
  11. - test3

  13. # 自定义命令
  14. # 例子：
  15. # items:
  16. # 名称:（请使用英文）
  17. # 显示名称: (输入命令)
  18. # 描述: (请输入描述，如需多行使用-)

  20. items:
  21.   fly:
  22.     displayName: "/fly"
  23.     lore:
  24.     - "gives the ability to fly"
  25.   spawn:
  26.      displayName:"/spawn"
  27.      lore:
  28.      - "Back to where you born"
  29.      - "whether you like or not."

  31. #自定义页码
  32. # 页码名称必须与上方构建页码相对应.
  33. # 例子：

  35. # pages:
  36. #   {页码名称}:
  37. #     items:
  38. #     {添加命令 (这里的名称是上方自定义命令的名称，而非显示名称)}

  40. pages:
  41.   test1:
  42.     items:
  43.     - fly
  44.   test2:
  45.     items:
  46.     - fly
  47.   test3:
  48.     items:
  49.     - fly
复制代码
{命令}

·/help - 打开GUI
·/helpgui - 打开helpgui帮助，即显示下面这条命令（需要权限help.admin）
·/helpgui help - 打开helpgui相关帮助（当然也需要权限）
·/helpgui reload - 重置配置文件
·/helpgui createiem <命令> <描述> - 创建命令，不过我建议你直接更改config
·/helpgui createfolder <页码名> <命令名> - 创建页码，不过我建议你直接更改config

{权限}
·help.admin - 赋予编译权限.
