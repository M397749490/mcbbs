事件监听器没有注册。
事件监听器有两种注册方式。

1. MinecraftForge.EVENT_BUS.register。需要在事件发布之前注册。
  1. MinecraftForge.EVENT_BUS.register(new ItemLoader());
复制代码


2. @Mod.EventBusSubscriber，需要写在类上，且监听事件的方法必须有 static 修饰。用这个方式不用担心注册监听器的时候错过注册事件的发布。
  1. @Mod.EventBusSubscriber(modid = "my_mod_id")
  2. public class ItemLoader {
  3.   // ...
  4. }
复制代码
