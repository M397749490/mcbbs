Dropt

——被认为是前置mod的魔改重器
     



     首先，本mod是火种科技MOD的前置MOD，但是其本身带有科技树点满的掉落物、掉落概率、掉落优先级，甚至是掉落逻辑修改的功能。且官方文档内容完备，完全可以依葫芦画瓢定制你的个性化世界！
     官方帮助文档



注：本mod可热重载，指令为/dropt reload


想要撸树只掉落木棍？

想要让铁块只有用锄头才能挖掘掉落？

在这里全部实现（明人明言+1）



通过Dropt，许多奇思妙想得以实现

如：配合cot，可以实现类似群峦传说的开局体验

又如：配合crt，实现不一样的无中生有

你，心动了吗



图文教程


首先，本mod的前置mod为：雅典娜Athenaeum（真是套娃啊）

可自行在mcmod百科界面找到，在此不再赘述。
注：Dropt可使用JSON、ZS、DroptAPI三种方式进行自定义
在此处重点讲JSON格式的脚本（其实是最简洁的）
ZS和DroptAPI压根没讲好吗KORA！！！

装载Dropt后，启动游戏（不是废话吗）

JSON脚本篇：

在（你的mc目录）/config/dropt内进行脚本编写
具体语法请查看官方文档
案例：将石头的掉落物替换为线
  1. {
  2.   "rules": [
  3.     {
  4.       "match": {
  5.         "blocks": {
  6.           "blocks": [
  7.             "minecraft:stone:0"
  8.           ]
  9.         }
  10.       },
  11.       "drops": [
  12.         {
  13.           "item": {
  14.             "items" : [
  15.               "minecraft:string"
  16.             ]
  17.           }
  18.         }
  19.       ]
  20.     }
  21.   ]
  22. }
复制代码

案例：设置高草被打掉时，添加一个85%几率触发的什么都不掉落的的项目，和一个15%几率掉落一个线的项目
  1. {
  2.   "rules": [
  3.     {
  4.       "match": {
  5.         "blocks": {
  6.           "blocks": [
  7.             "minecraft:tallgrass:*"
  8.           ]
  9.         }
  10.       },
  11.       "replaceStrategy": "ADD",
  12.       "drops": [
  13.         {
  14.           "selector": {
  15.             "weight": {
  16.               "value": 85
  17.             }
  18.           }
  19.         },
  20.         {
