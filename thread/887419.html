FastRespawn
此插件作者为PetteriM1

此插件直接跳过了重生画面，让玩家快速的重生.

可以通过配置文件来决定改变某些选项

  1. #重置生命
  2. resetHealth: true
  3. #重置饥饿
  4. resetFood: true
  5. #重置物品栏
  6. resetInventory: false
  7. #重置经验
  8. resetXp: false
  9. #掉落物品
  10. dropInventory: true
  11. #掉落经验
  12. dropXp: true
  13. #启用死亡消息
  14. deathMessages: true
