这里是杰帕斯，我又来搬有趣(无聊)的插件了！
Statues
这个插件可以让你预览你的新皮肤，或者让展示你自己的皮肤，看看多帅气(可爱)啊！雕像当然不会受到任何伤害，debuff,移动或者互动，他只是一个可爱的雕像，永远为你的玩家们服务！

A.特征：·创建玩家雕像·创建动物雕像·让雕像对着你看·动作雕像（目前仍在制作）

B.前置插件：
  • BKCommonLib- 必须安装！[已搬运]
  • ProtocalLib - 选装
C.效果图：



D.指令列表：

  • /statue create mob <mob name> - 创建一个动物雕像
  • /statue create player <player name> -创建一个玩家雕像
  • /statue select - 选中离自己最近的雕像
  • /stature remove - 移除选中的雕像
  • /statue edit - 可以更换名字，手持武器，以及盔甲 (即将更新)



D.动画类型：
动画在2.0更新时暂时删除！ 当前的动画类型有：
打孔 - 打造雕像
伤害 - 将雕像变成红色，受伤的动画
蹲伏 - 使雕像蹲下
旋转 - 慢慢地旋转雕像
停止 - 停止雕像动画（Bugged，目前停止所有雕像动画）


E.权限：


  • statues.create.mob - 创建动物雕像的权限
  • statues.create.player - 创建玩家雕像的权限
  • statues.select - 选中雕像的权限
  • statues.animate - 给雕像添加动画的权限[暂时没用]
  • statues.deleteall - 删除全部雕像的权限 注意！当你给予这个权限的时候，很危险！[暂时没用]
