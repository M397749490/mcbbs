覆盖上去以后就能达到你要的效果，体温不再影响玩家。我担心你不会改配置文件，所以直接给了你一个 config.

原理是这样：意志坚定模组的配置文件都包含在 config/toughasnails 文件夹，
里面有一个 gameplay.cfg ，包含了所有机制的开关。
  1. # Configuration file

  3. "main settings" {
  4.     # Players are affected by temperature [default: true]
  5.     B:"Enable Body Temperature"=false

  7.     # The effects of the mod will work on Peaceful difficulty. [default: false]
  8.     B:"Enable Peaceful"=false

  10.     # Players are affected by thirst. [default: true]
  11.     B:"Enable Thirst"=true

  13.     # Allows drinking from rain by sneak-rightclick and empty main hand if looking up at raining sky. [default: false]
  14.     B:"Enable drinking from rain"=false

  16.     # Allows drinking directly from water-source blocks with sneak-rightclick and empty main hand [default: true]
  17.     B:"Enable drinking from water blocks"=true
  18. }


  21. "tweak settings" {
  22.     # Ice Blocks drop Ice Cubes. [default: true]
  23.     B:"Ice Cube Drops"=true

  25.     # Loot tables are tweaked for balance. [default: true]
  26.     B:"Loot Table Tweaks"=true

  28.     # Magma Blocks drop Magma Shards. [default: true]
  29.     B:"Magma Shard Drops"=true
  30. }


复制代码
这就是配置文件全文，第一项配置就是体温是否启用，我把 true 改成了 false 之后，把配置打包放在了附件。

你也可以自己动手改。
