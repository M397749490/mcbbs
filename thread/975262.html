简介

此插件可以绑定服务器玩家的QQ，并且进行验证。太空人再也不用担心熊孩子瞎写QQ号码了
*未绑定禁止移动功能已经可以自行控制啦*

插件配置简便，使用简单，以后可能会发布CoolQ插件[无需Web服务器]）
无固定端口，无需设置字符编码。插件使用Mysql储存数据，您可以直接在您的网站上使用本插件数据表数据
本插件还可以与AuthMe联动，忘记密码时使用绑定账号获取验证码修改密码

本插件依赖
CoolQ
CoolQ HTTP (cqhttp.cc)
Mysql
PHP
Nginx/Apache (用于接收CoolQ HTTP插件请求)

更新信息




本次更新为不兼容 v0.2.0 以下版本的更新
[Pre-release] Beta v0.2.0 （测试版）
添加/修改了新功能:
  • 修改：/bindq 验证码信息更改为变量形式（自定义信息更灵活/配置文件内修改）
  • 新增：未绑定玩家是否可移动开关（配置文件内修改 true/false 默认关闭需手动启用）
  • 新增：控制玩家是否可以更改绑定信息（配置文件内修改 true/false 默认关闭需手动启用）
  • 新增：AuthMe插件密码更改（忘记密码自助获取验证码验证修改 默认关闭需手动启用）
启用新功能需要在 服务端配置+插件配置文件 中两者对应配置全部修改为true 默认为关闭

Bug/功能建议 请提交Github Issues



命令&所需权限




命令 描述 所需权限
/bindq 获取绑定码 需要的权限:默认
/bindQueryAdmin <player name> 查询玩家绑定的QQ号码 需要的权限:OP
/deleteBindAdmin <player name> 删除玩家的绑定信息 需要的权限:OP

新增
changepassword_authme修改AuthMe密码默认
bindinfochange修改绑定信息 默认


插件配置文件

插件配置文件内容
新增功能默认不启用 请手动开启 / http.php和插件两者都要配置，否则会出错
数据库地址 mysqlAddress: 127.0.0.1
数据库端口 mysql_port: 3306
用  户  名 mysql_user: root
密       码 mysql_password: root
自定义信息 group_info: '加群xxx,绑定xxx %code%'
未绑定可以移动 not_bind_can_move: false
玩家可以更改绑定信息 player_can_change_bindinfo: false
更改AuthMe密码 changepassword_authme_func: false

qv_http.php 配置
$mysqlAddr 连接地址
$mysqlPort 连接端口
$mysqlUser 用户名称
$mysqlPass 用户密码
$changeBindInfo 是否允许更改绑定信息
$changepassword_authme 是否允许更改AuthMe密码
