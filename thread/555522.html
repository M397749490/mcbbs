首先这是我之前发的帖子：戳我:D  我在这里在理顺一下。


  • 创建一个组
    1. /pex group <组名> def true/false
    复制代码
    设置为true表示具有所有权限，设置为false表示没有任何权限
  • 创建/移除一个继承权限的组(设置默认组的指令是/pex group <新建组名> parent add default user)
    1. /pex group <新建组名> parent add/remove group <被继承组名>
    复制代码

  • 向组添加/移除成员
    1. /pex user <玩家名> parent add/remove group <组名>
    复制代码

  • 向某玩家添加/禁用/移除某个权限
    1. /pex user <玩家名> perm {权限} true/false/0
    复制代码
  • 向某个组添加/禁用/移除某权限
    1. /pex group <组名> perm {权限} true/false/0
    复制代码
  • 使一个组升级
    1. /pex rank default add group <组名>
    复制代码


之前升降级的部分请参考官方原教程……我也不是很清楚是什么逻辑

    复制代码
  • 限制玩家家的数量
