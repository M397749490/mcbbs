插件功能

  • 礼包可配置文件自定义编辑
  • 自带玩家变量
  • 拥有GUI领取
  • 可自定义名称
  • 高度自定义物品

插件命令

/kit
打开礼包菜单
权限: kit.command

/无命令
创建礼包木牌权限
权限: kit.sign

/无命令
无礼包冷却权限
权限: kit.freepass

插件配置

CONFIG.YML (已做汉化 可供参考用...)
  1. ---
  2. # 玩家死后获得礼包
  3. one-kit-per-life: true
  4. # 重新登陆可在领取(only if one-kit-per-life 是否为 true)
  5. reset-on-logout: true
  6. start-from-first: false
  7. # 添加礼包前是否清空玩家背包
  8. clear-inventory: false
  9. # 添加礼包前是否清除玩家状态
  10. clear-effect: false
  11. # 木牌上填写内容 (不区分大小写)
  12. text-on-sign: "[KitUI]"
  13. ...

KITS.YML (配置教学 详细)
  1. ---
  2. first:
  3.   # 格式: "物品ID:子ID:数量:名称:附魔名称:附魔等级"

  5.   # 自定义物品名称 (屋敷膜): "物品ID:子ID:数量:名称"

  7.   # 取消附魔和自定义名称: "物品ID:子ID:数量"

  9.   # 如果只有附魔 (无自定义名称): "物品ID:子ID:数量:DEFAULT:附魔名称:ench_level" -- 在name位置输入DEFAULT

  11.   # 如果需要更多附魔: "id:子ID:数量:名称:附魔名称1:附魔等级1:附魔名称2:附魔等级2"
  12.   # 或者 "物品ID:子ID:数量:DEFAULT:附魔名称1:附魔等级1:附魔名称2:附魔等级2"

  14.   items:
  15.   - ""
  16.   - "364:0:64:&3新手牛排"
  17.   helmet: "298:0:1:&6带有附魔的混乱帽:protection:1"
  18.   chestplate: "299:0:1:&6带有附魔的混乱胸甲:protection:1"
  19.   leggings: "300:0:1:&6带有附魔的混乱护腿:protection:1"
  20.   boots: "301:0:1:&6带有附魔的混乱靴子:protection:1"

  22.   commands: # 支持变量 {player}(执行玩家)
  23.   - "tell {player} 礼包领取成功!"

  25.   cooldown:
  26.     hours: 24
  27.     minutes: 30

  29.   # 格式: "药水名称:持续时间:效果"
  30.   # 时间单位 秒
  31.   effects:
  32.   - "speed:120:2"
  33.   
  34.   # 在礼包菜单显示名称 可用颜色符号 '§'
  35.   kit-name: "§6新手礼包"

  37.   # 设置礼包价格 需要前置 EconomyAPI
  38.   # 输入 0 即为免费
  39.   money: 50
  40.   
  41.   # 显示图标 (链接模式)
  42.   image-url: "https://mc.res.**/pc/qt/20170209162048/data/big/pic20.png?v=4"

  44.   # 信息界面显示信息
  45.   info: "新手可免费领取"

  47.   # 需要权限
  48.   permission: "kit.testkit"
