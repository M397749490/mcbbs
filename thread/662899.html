1.特性：
  • Automatic Arena Reset 竞技场自动复位
  • Does not use Redstone! - Create your own maps! 不用红石了! - 创建您自己的地图
  • Automatic Chest Reset 自动箱子重置
  • Auto game start with voting & more. 投票游戏地图
  • Spectators 旁观者模式
  • Signs 木牌
  • Kits 工具包
  • In game lobby with real-time player and arena status.
  • Unlimited Arenas 无限的领域
  • Unlimited Spawns per Arena 每个领域有无限的出生点
  • Simultaneous games 同时游戏[什么玩意儿]
  • Multiworld support 支持mw插件
  • Web based stats 基于Web的数据
2.未来的计划
支持
  • BungeeCord Support
3.已知的bug
无 None

4.兼容的插件
  • MySQL Database (optional) - If you wish to use stats, you must have a SQL database. It is no longer required for logging.
  • MySQL数据库(可选) 如果你希望使用统计数据,您必须有一个SQL数据库。是不再需要的日志记录。
  • WorldEdit - Needed to create arenas
  • WE (必需) 使用这个去创建区域
5.安装方法
把插件放在plugins文件然后输入/reload或者重启服务器
6.命令
- - - - -玩家命令Players Commands
  • /sg vote - Vote to start the game 投票去开始游戏
  • /sg leave - Leave the game 离开游戏
  • /sg join - Teleports you to the lobby spawn point 传送您到等待大厅
  • /sg join <id> - Joins the game <id> 加入<ID>游戏
  • /list - Shows a list of players dead and alive players (only ingame) 显示死亡的玩家和活着的玩家(只能在游戏中)
  • /sg spectate <id> - spectate a game 观察者模式进入<ID>游戏
  • /sg lq or /sg leavequeue - Leave the queue your in. 你在离开队列[这不懂]


- - - - -管理员命令Admin Commands
  • /sg createarena - Creates a new arena in your region selected with world edit 用WE创建一个区域(这个大家都知道吧)
  • /sg setlobbyspawn - Set the spawn point for dead tributes 设置死亡后的重生点
  • /sg addwall <arena> - Sets the signs you have selected with worldedit as a lobbywall. 用WE选择点设置lobbywall[大厅的墙？]
  • /sg disable <gameid> - Disable a game and force reset it (forces the arena rollback to run, useful if a crash or server shutdown occurs while a game is running. Also allows you to make changes the the arena. 禁用一个游戏，迫使它重置(后面括号里的大意是:允许更换竞技场)
  • /sg disable - Disabled every arena at once 禁用所以领域(慎用)
  • /sg enable <gameid> - renable a disabled game 启用一个游戏
  • /sg enable - enable all games 启用所有游戏
  • /sg start - Force Start the game your in 强制开始你进入的游戏
  • /sg start <arenaid> <Time> - Force a game to start <arenaid> is the arena # and the <time> is how long the countdown is 强制开始一场游戏<arenaid>是竞技场名字,<Time>是倒计时
  • /sg setspawn next - Set the next spawn point for the arena you are located in 设置下一个重生点
  • /sg setspawn <spawnid> - set a specific spawn for the arena you are in 设置一个特殊的重生点(不懂咧)
  • /sg delarena <id> - Deletes an arena 删除一个区域
  • /sg resetspawns <id> - resets all spawns for an arena 重置所有重生点
  • /sg refill - Refills the chest stock. 重置所有箱子
  • /sg reload <games | settings | all> - reloads part or all of the plugin. 重载插件<games>是游戏<settings>是设置<all>是全部(慎用)
    • Note: /sg can be interchanged with /survivalgames, /hg and /hungergames
    • 小提示:/sg可以写成/survivalgames, /hg 或者/hungergames
7.权限
  • sg.arena.join.# - Allows the user to join a certain arena 允许玩家加入一个特定的区域
  • sg.arena.join.* - Allows the user to join all arenas 允许玩家加入所有区域
  • sg.arena.vote - Allows the user to vote to start (/sg vote) 允许玩家投票(/sg vote)
  • sg.arena.spectate - Allows a user to spectate a game 允许玩家以旁观者模式观察游戏
  • sg.lobby.join - Allows the use of /sg join to join the lobby 允许使用/sg join命令加入游戏
    • Staff Permissions:
    工作人员权限：
  • sg.arena.forcestart - Allows the user to Start Sg (/sg start) 允许工作人员强制开始(/sg start)
  • sg.arena.disable - Allows the user to disable an arena 允许工作人员禁用一个竞技场
  • sg.arena.enable - Allows the user to enable an arena 允许工作人员启用一个竞技场
  • sg.arena.nocmdblock - Allows user to bypass ingame cmd block 允许工作人员绕过(ingame command block)（不懂）
    • Admin Permissions:
    管理员权限
  • sg.arena.create - Allows the user to create an arena 允许管理员创建一个竞技场
  • sg.arena.setspawn - Allows user to set spawns 允许管理员设置重生点
  • sg.arena.resetspawns - Allows the user to reset all spawnpoints 允许管理员重置重生点
  • sg.arena.delete - Allows a user to delete an arena 允许管理员删除一个竞技场
  • sg.lobby.set - Allows the user to set the lobby spawn and wall 允许管理员设置大厅,出生点和墙
