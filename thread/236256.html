如果是Clear lagg的话，mods里有个Clearlag的文件夹，里面有两个文件，用notepad++之类的高级记事本打开config.yaml后找到
这段代码

  2. #Auto-removal options
  3. auto-removal:
  4.   broadcast-message: '&6[ClearLag] &aRemoved +RemoveAmount Entities!'
  5.   enable-scheduler: true # THIS IS NO LONGER IN USE!
  6.   enable-limit: true  #Should clearlag limit be enabled?
  7.   autoremoval-interval: 400  #The seconds it takes for auto-removal to run
  8.   
  9. #The warning delay that runs AFTER auto-removal fires: This actually clears the items when it fires!
  10. warning:
  11.   autoremoval-warning: true #Should there be a warning?
  12.   autoremoval-warningdelay: 60  #How long until the removal starts (after delay)
  13.   broadcast-warning: true  #Should this be broadcasted?
  14.   autoremoval-warningmessage: '&4[ClearLag] &cWarning Ground items will be removed in one minute!'
复制代码
