它的特性：
1、拥有5种不同种类的锁
①公共锁 —— 任何人都能打开，只适用于保护
②私有锁 —— 只有自己或者认可的人能够打开
③常闭密码锁 —— 用户每次都要输入密码才能打开
④一次性密码锁 —— 用户只需输入一次即可开启
⑤公益锁 —— 只有主人才能取走，其他人只能放入
2、可防止盗窃、活塞、爆炸、红石
3、可配置每个玩家每个锁的共享量
4、可配置可锁方块
5、以h2数据的方式保存 latch.mv.db
6、可使用bstats进行统计

将来要加入的功能：
添加管理功能来管理锁
添加公会锁来支持公会插件

配置文件：
配置文件在/config/latch里面
add_default_permissions  自动添加 latch.normal 默认权限
lockable_blocks  玩家可以使用这个插件来锁方块
protect_from_explosives  上锁的东西可防止爆炸物
protect_below_block  上锁后同时保护下面的方块
lock_limit  设置每个玩家能使用每一种类的锁的数量
protect_from_redstone  上锁的东西可防止红石
allow_opening_locked_iron  是否能直接用手开关铁门

指令：

/latch or /lock - 显示基本的命令以及该插件的信息
/latch help - 显示命令帮助
/latch private - 在下一次点击时给方块上锁 放置/点击
/latch password [password] - 使用指定密码创建一个密码锁 (可添加以下标志使用不同种类)
-a - 每次使用时都需要密码 (默认)
-o - 仅需输入一次密码即可使用
/latch change - 如果你是主人的话可以更改锁的属性 (可添加以下属性，多个属性可一起添加)
--type=[PRIVATE, PASSWORD_ALWAYS, PASSWORD_ONCE] - 改变锁的类型
--password=[password] - 更改锁的密码 (会重置访问列表)
--add=[player] - 在锁的访问列表中添加玩家 (可以在单个命令里包含多个)
--remove=[player] - 在锁的访问列表中移除玩家 (可以在单个命令里包含多个)
--owner=[player] - 把锁转移给另一位玩家
--redstone=[true/false] - 设定该锁是否阻止被红石交互
/latch remove - 如果你是主人的话可以移除该锁
/latch persist - 开启复制 -p 标志的功能 (将最后一个命令持久化)
再次使用该命令可关闭, 或者使用 /latch clear
/latch info 或 /latch display - 显示锁的名字, 主人, 目标 以及 可访问的玩家
/latch list - 显示你所有的锁
/latch list [player] - 显示某玩家的所有锁 (需要权限 latch.admin.list)
/latch open [password] 或 /unlock [password] - 使用密码打开某个锁
/latch add [user] or '/latch remove [user]` - 添加锁的允许访问列表
/latch lockable add (block id)  - 为手中的方块添加到可锁物列表
/latch lockable remove (block id)  - 在可锁物列表里移除手中的方块
/latch lockable list  - 查看可锁物列表
/latch bypass  - 无视箱子锁

权限：
latch.normal 允许使用非管理功能的命令
其他节点：
latch.normal.info
latch.normal.create
latch.normal.create.password.always
latch.normal.create.password.once
latch.normal.create.private
latch.normal.create.public
latch.normal.create.donation
管理权限：
latch.admin
latch.admin.list
