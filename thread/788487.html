插件介绍
对于一个大型服务器，让玩家找到某个坐标，某个传送门，某个NPC可能非常困难，来试试这个插件！当玩家不知道自己想去的地方在哪时，可以召唤出一个动态的箭头，指引玩家到达目的地！
插件原帖提供了非常生动形象的动图，本帖内将会引用来自原帖的图片


箭头的样子、大小、长短任意选择
用于导航的“箭头”由盔甲架上的方块拼接而成，可自由设置方块的种类，以及箭头的大小



自由调整箭头的位置|最舒服的姿势
使用指令/gps move可进入调整模式调整箭头相对于玩家的位置，鼠标滚轮可前后移动箭头，Shift+鼠标滚轮可上下移动


导航点与路径|是什么让你我连接？
使用指令/gpsc editor可进入编辑模式，可在此模式下创建“导航点”，并可使用指令将两个导航点连接起来组成一条路径，可将多个导航点连接起来组成长而弯曲的路径，甚至组成一张路径网




开始导航|一緒にいく！
玩家输入/gps start <目标点名>即可开始导航，首先，箭头将玩家指引到最近的“导航点”，随后将按照路径通过一个一个导航点，最终到达目的地，如果路径网非常复杂，箭头会按照两点间直线最短原则选出最短的路径



自定义箭头材质
国外材质大佬NullBlox为本插件制作了自定义材质的箭头，你可以在这里查看各种箭头的效果
你可以去这里下载需要的材质包（国内需魔法上网）或者在本帖下方下载

安装与使用教程
  • 本插件可以在1.8使用，但是实体箭头将完全不可用，只有粒子效果箭头可用，所以完全不推荐1.8服务端使用，强烈建议使用1.9+服务端
  • 本插件有个特性，可让导航箭头只对相应玩家显现，如果需启用此特性，需要安装ProtocolLib前置并在config中启用

使用教程
  • 输入指令/gpsc editor进入编辑模式（再输入一次可退出）
  • 输入指令/gpsc show 现在所有导航点的位置均会以红色粒子效果标出
  • 站到相应位置输入/gpsc create <导航点名>创建一个导航点
  • 至此，玩家如果输入指令/gps start <导航点名> 出现的箭头会直接将玩家以直线导向至该导航点，这种导航会无视障碍物的存在
  • 如果想设置弯曲的路径来让玩家避开障碍物，你需要在其它关键位置创建更多导航点
  • 多个导航点创建完成后，开始创建路径，使用指令/gpss select <导航点名> 选中一个导航点，被选中的导航点将会变成绿色
  • 到达另一个导航点旁边，直到这个导航点的粒子效果变成黄色，输入指令/gpsc connect即可将两点以蓝色粒子效果连接，一条路径即创建完成
  • 重复此步骤，在其它两点之间创建路径
  • 至此路径创建完成，输入/gpsc editor退出编辑模式
  • 玩家输入/gps start <目标导航点名>即可进入导航模式，出现箭头将玩家按照路径指引至目标
  • 方便起见，可以使用一些菜单类插件让玩家点击按钮开始导航，也可以使用脚本类插件让玩家点击木牌开始导航

指令与权限
  • /gps help - 插件帮助
  • /gps start <目的地名> [玩家名] - 开始导航
  • /gps stop [玩家名 ]- 停止导航
  • /gps move - 调整箭头相对于玩家的位置
  • /gps reload - 重载插件
  • /gps list [页] - 列出所有导航点

  • /gpsc editor - 进入/退出编辑模式
  • /gpsc create <导航点名> - 创建导航点
  • /gpsc select <导航点名> - 选中导航点
  • /gpsc delete - 删除选中的导航点
  • /gpsc connect [双向？] - 连接两点并生成路径
[双向？]可选true/false 如果是true那么这条路径将是双向的，如果是false那么这条路径将是单向的（距离最近的黄点 -> 选中的绿点）缺省默认为true双向
  • /gpsc disconnect - 解除两点连接
  • /gpsc show - 所有导航点和路径将以彩色粒子效果标注
  • /gpsc move - 将选中的点的位置移动到你所站的位置
  • /gpsc teleport <导航点名> - 直接传送至导航点
  • /gpsc stick 获得导航点编辑棒

建议给玩家的权限
  • gps.commands - 使用指令的基础权限
  • gps.commands.start - 使用指令开始导航
  • gps.commands.stop - 使用指令停止导航

酌情给玩家的权限
  • gps.commands.move - 使用指令调整箭头相对于玩家的位置
