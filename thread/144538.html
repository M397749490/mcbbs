Java注重类型。他不会让你做出变量随意乱用（比如把int变量赋值给short），也不会让你把浮点数变量放进整数变量中，除非你愿意强制转换（会损失精度）。在这方面，编译器会指出大部分问题。
一。主数据类型
变量名 占用内存 大小限制
字符型char 16字节 0-65535
字符串String
布尔型boolean java虚拟机决定 true/false
byte 8字节 -128 - +127
short 16字节 -32768 - 32767
int（最常用） 32字节 -2147483648 - 2147483647
long 64字节 -2的63次方 - 2的63次方-1
float 32字节
double（浮点数） 64字节

三。实例变量标签
public 公共 允许任意调用
projected 允许同一个jar中调用
default 默认 允许同一个包（文件夹）内调用（不包括子文件夹）
private 私有 只允许在这个类中调用，标签只要加在变量类型前面

  2. //例如
  3. private String a="aaa";//声明私有变量
