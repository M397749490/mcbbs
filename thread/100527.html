YouYou-绿宝石经济系统V1.0

------------------------------------------------------

厌倦了服务器iConomy等复杂的经济插件了吗?

想要简单的能拿在手里的代币吗?

没有空间时，存在ATM里？OK！

简单的可买可卖商店？OK！

YouYou绿宝石经济系统满足你的需求!



插件列表：

Essentials[基础插件]

GroupManager[权限/用户组]

EmeraldMarket[绿宝石交易系统(主要!)]

ShopKeepers[村民商店]

SignEdit[告示牌修改]

OtherDrops[掉落奖励系统(重要!)]



此懒人包是1.4.7-R1.0水桶服务端的绿宝石经济系统。

可以自行添加更多插件。

主要插件为EmeraldMarket.

特性：
1.使用绿宝石代币 自由度很高!
由于绿宝石是物品：
-可以拿在手上直接使用
-可以由发射器/命令方块 发射/给予
-可以扔出 激活红石信号等，如制作门票系统
-代币存入 再也不头痛背包空间/小偷问题
2.打怪/挖矿有几率获得掉落绿宝石奖励
3.自由开张自己的商店，同时卖出/买进，收入可以直接到ATM账户
4.OP可创造无限商店（卖出数量无限）和自定义村民
5.支持木牌颜色/修改，创造自己的完美木牌

EmeraldMarket插件教程
Item-物品
Price-卖出价格
Sale Value-买进价格
功能:
  • 用绿宝石买/卖物品
  • 每个玩家的银行账户系统
  • 买/卖特殊物品（像编辑过的书和礼花）
  • 创建无限商店（不用续货）
  • 玩家可以创造私人商店
  • 创建取款机（ATM）

ATM:特性
  • 存入绿宝石（所有ATM中的账户信息同步）
  • 买/卖东西时，你的账户里会被直接扣除/添加宝石
制作ATM：
  • 输入 /em create atm
  • 对钻石块点右键
注意
  • 账户绿宝石最大容量- 82944
  • 你可以超出82944个，但是数量不会被显示
SHOP商店:特性
  • 买/卖东西
  • 无限卖出物品（不用续货）
  • 9个物品栏
创建
  • 输入/em create shop
  • 右击绿宝石块
为商店添加物品
  • 手里拿着添加商品
  • /em add <卖给玩家价钱> <从玩家那买入价钱>
  • 右击超市的绿宝石块
注意
  • 如果你不想让一个东西被买/卖，设<>数值为0
移除商品
  • 输入/em remove <第几个商品栏(1-9)>
  • 右击超市的绿宝石块
注意
  • 如果你的账户里绿宝石不够，你不能买任何东西
  • 你必须有1个背包空格
  • 卖出物品时，手里必须持有它

权限列表
权限指令描述
emeraldMarket.lang/em setlang更换语言（目前没有汉化）.
emeraldMarket.reload/em reload重新启动插件.
emeraldMarket.setowner/setowner重置商店主人.
emeraldMarket.ignoreGMnone可以用任何游戏模式访问商店(普通仅支持生存).
emeraldMarket.balance/em balance查看存款的绿宝石数目
emeraldMarket.balance.other/em balance <player>查看某玩家的绿宝石存款数目.
emeraldMarket.open.*
emeraldMarket.open.shopnone访问一个商店.
emeraldMarket.open.atmnone访问一个ATM.
emeraldMarket.create.*
emeraldMarket.create.shop/em create shop创造无限商店.
emeraldMarket.create.private/em create private创造私人商店.
emeraldMarket.create.atm/em create atm创造ATM.
emeraldMarket.add/em add为你自己的商店添加商品.
emeraldMarket.add/em remove为你的商店取出商品.
emeraldMarket.add.other/em add为任何商店添加商品.
emeraldMarket.add.other/em remove为任何商店取出商品.
emeraldMarket.destroy.*
emeraldMarket.destroy.shopnone关闭(破坏)你自己的无限商店.
emeraldMarket.destroy.shop.othernone关闭(破坏)任何人的无限商店.
emeraldMarket.destroy.privatenone关闭(破坏)你自己的私人商店.
emeraldMarket.destroy.private.othernone关闭(破坏)任何人的私人商店.
emeraldMarket.destroy.atmnone关闭(破坏)任何ATM.
