监狱风云2 - Prison2

这个插件虽然在去年10月已经有搬运帖了
但是他从发帖到现在从未编辑过（有些错误也没纠正- -）
作者也声明在近期内发布 Prison3 版本，我就顺手带过来了
                                                                 

命令&权限列表
其中，<>为参数，[]为该命令的用处
核心命令
权限节点：prison.manage
/prison [总命令]
/prison help [查看帮助]
/prison version [查看运行插件的版本号]
等级相关命令
/ranks [列出所有等级]
/rankup [提升等级]

等级相关-高级命令
权限节点：prison.ranks.manage
/prisonranks [查看关于等级的命令]
/prisonranks add <等级> <花费金额> <彩色名字> [创建一个等级组]
/prisonranks remove <等级> [删除一个等级组]
/prisonranks promote <玩家> [强制提升某玩家等级]
/prisonranks demote <玩家> [强制降低某玩家等级]
矿场相关-高级命令
权限节点：prison.mines.manage
/mines create <名称> [创建一个矿场]
/mines addblock <矿场名> <方块ID> <几率> [设置方块在矿场刷新比率]
/mines reset [刷新该矿场]
/mines info <矿场名> [查看该矿场的信息]
/mines list [查看所有矿场]
/mines removeblock <矿场名> <方块ID> [删除方块在矿场刷成]
/mines delete <矿场名> [删除一个矿场]
/mines redefine <矿场名> [重新划定矿场的区域（需要先用创世神选取两个点）]
