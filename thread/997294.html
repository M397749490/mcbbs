NcRules
快速管理所有世界规则，周目服刷新世界开服自动应用上次设置的规则



下载地址:Github Releases | 开源地址:Github



插件简介:

本来是给自己服务器找个这样的插件，奈何木有，只好自己写一个了，感谢论坛内制作插件开发教程的PONG友√

命令:
  • 使用命令 NcRules & Ncrs
  • /ncrs help 获取帮助
  • /ncrs reload 重载配置文件并立即应用规则到已启用世界
  • /ncrs list 列出已启用世界
  • /ncrs add [World] 添加世界并立即应用目前配置规则

权限:
默认全部OP所有
  • ncrules.help
  • ncrules.reload
  • ncrules.list
  • ncrules.add

额外功能:
死亡标题画面 (推荐配合自动复活规则使用 doImmediateRespawn)

添加规则:
打开配置文件:config.yml
默认添加了3个(没有修改设置处于默认世界状态需要手动添加或修改)
  • doImmediateRespawn: false
  • keepInventory: false
  • doFireTick: true
如果需要额外添加 直接在
  • doFireTick: true
回车 填写游戏的规则 一定要和游戏内的大小写完全一致 建议使用 /gamerule TAB补全然后手动复制添加到配置文件内
如果不会，请点开下面的隐藏内容查看图片
默认的三条 在最后一条回车 主要对齐留空不能少空格也不能多
