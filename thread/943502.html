前置类原版模组（datapack）：自定义耐久损耗系统

适用版本：1.14.x及以上
适用范围：自定义耐久扣除，适用于设计中应当扣除耐久却不被游戏判定为物品损耗的情况，如弓的近战
接口：给需要应用此功能的物品加上一个nbt标签："CustomDamage:1b"，在需要消耗耐久时在计分板 Customdamage上增加所需点数即可注意：此前置不提供消耗耐久的判断，使用时，判断完后请依照你的想法把相关判断数据（如另一个计分板）关联到Customdamage计分板上。
                          特色功能：1、生存模式玩家若主手持有带有上述nbt的物品，且该玩家的CustomDamage计分板分数大于1，其耐                                            久将会扣除<其计分板上的分数>点
                                          2、若该武器带有耐久附魔，可以按照游戏中的耐久计算，有概率不掉耐久，此功能最高支持等级为                              65536（2^16）

  2. scoreboard objectives add Duriable dummy
  3. scoreboard objectives add Unbreaking dummy

复制代码
共4个计分板，均为虚拟型。
分别将储存的信息：
Customdamage：要消耗的耐久；

Duriable：损害值；

Unbreaking：耐久等级；
DamageMax：该物品耐久的最大值。


超频执行函数：customdamage v1.2\data\customdamage\functions\tick:
  1.      #对造成伤害的玩家执行“function”
  2. execute as @a[scores={Customdamage=1..},nbt={SelectedItem:{tag:{CustomDamage:1b}}},gamemode= !creative] run function customdamage:function
复制代码
检测有相应计分板数据，手上拿有对应物品，且不处于创造模式的玩家执行损耗命令。

执行函数：customdamage v1.2\data\customdamage\functions\function:
  1.    #初始化数据
  2. scoreboard players set @s Unbreaking 0
  3. #放置潜影盒并获取玩家手中物品信息
  4. setblock ~ 255 ~ shulker_box{Items:[{Slot:0b,id:"minecraft:stone",Count:1b}]}
  5. data modify block ~ 255 ~ Items[0].id set from entity @s SelectedItem.id
  6. data modify block ~ 255 ~ Items[0].tag set from entity @s SelectedItem.tag
  7. function customdamage:max
  8. #耐久附魔模块
  9. execute as @s store result score @s Unbreaking run data get entity @s SelectedItem.tag.Enchantments.[{id:"minecraft:unbreaking"}].lvl
  10. scoreboard players add @s Unbreaking 1
  11. scoreboard players set #random_min random 1
  12. scoreboard players set #random_max random 65536
  13. function random:random
  14. scoreboard players operation @s random = #result random
  15. scoreboard players operation @s random *= @s Unbreaking
  16. #在潜影盒内扣除耐久
  17. execute as @s store result score @s Duriable run data get entity @s SelectedItem.tag.Damage 1
  18. scoreboard players add @s[scores={random=1..65536}] Duriable 1
  19. execute store result block ~ 255 ~ Items[0].tag.Damage short 1 run scoreboard players get @s Duriable
  20. #将潜影盒内物品调包到玩家手上并清除潜影盒
  21. replaceitem entity @s weapon.mainhand air
  22. execute if score @s Duriable > @s DamageMax run data remove block ~ 255 ~ Items
  23. loot replace entity @s weapon.mainhand 1 mine ~ 255 ~ minecraft:diamond_pickaxe{isShulkerMarker:1b}
  24. setblock ~ 255 ~ air
  25. #检测是否需要更多次消耗耐久
  26. scoreboard players remove @s Customdamage 1
  27. execute if entity @s[scores={Customdamage=1..}] run function cam:magic/weapon/customdamage/function

#耐久附魔模块：

原版耐久附魔计算机制如下：
对于多数物品，每次使用时消耗耐久度的概率将降至(100/(等级+1))%。物品的期望寿命为原来的(等级+1)倍。

对于盔甲，每次使用时消耗耐久度的概率将降至(60+(40/(等级+1)))%（即耐久度每次都有20%/27%/30%的概率不会减少）。盔甲的期望寿命为原来的125%/136%/143%。

当物品单次承受的耐久度损耗超过1点时（例如使用钓鱼竿拉扯生物，或带有荆棘魔咒的盔甲造成反伤时），每1点损耗都将应用以上规则进行减免。

这里不涉及盔甲。
计算原理：
1、获取耐久附魔等级并加1，便于计算；
2、设置一个1到65536的随机数值，将这个数乘以耐久等级，若这个数还在1到65536的范围内，则扣除耐久。
（在一个范围内取任意值，将其乘以一个数n，数据还在原范围的概率为1/n）
因为计分板只支持整型（int，-2147483648~2147483647），所以要达到乘的效果只能在65536（2147483647开方）内计算，因此最多支持到耐久65536级。

#在潜影盒内扣除耐久：

获取一下物品损耗值，若满足上述条件，扣除1耐久。计算完后，储存到潜影盒里，再在下面返还给玩家。
