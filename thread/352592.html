许多战争服是不是都很困扰，同阵营的能可以互相打，这样就失去了阵营战争服的意义。
这款插件可以阻止拥有相同权限的人PVP
在config里设置一下你自定义的权限后缀

以下是config文件

  1. PvpMessageEnabled: true   #这里写是否开启信息提示（就是我是阵营A，打我的也是阵营A，然后打我的人会提示信息）
  2. PvpMessage: '这里写提示的信息'
  3. Groups:
  4. - A  #这个A组，这个A可以改成任何英文
  5. - B #组B
  6. - C #组C（当然你想添加几个组就能添加几个组）
复制代码



然后假设你的阵营为Group1和Group2
就把A改成Group1
B改成Group2
然后利用权限插件添加 pvpperms.Group1给Group1组，pvpperms.Group2给Group2组
然后Group1能打除了拥有pvppers.Group1权限以外的所有人，Gourp2能打除了拥有pvpperms.Group2权限以外的所有人

如果你想添加更多组也是可以的




此插件1.7.10以后无影响
