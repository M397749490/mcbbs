1.warp权限：
  1. 基础权限: nucleus.warp.base
  2. 全部权限：
  3. nucleus.warp.others - 默认权限组: ADMIN
  4. 允许玩家对其他玩家执行 "warp".
  5. nucleus.warp.exempt.cooldown - 默认权限组: ADMIN
  6. 允许玩家无视 /warp 的冷却时间
  7. nucleus.warp.exempt.warmup - 默认权限组: ADMIN
  8. 允许玩家无视 /warp 的预热时间
  9. nucleus.warps - Default Role: ADMIN
  10. 当 per-warp 开启时候，允许玩家传送所有地标。
  11. nucleus.warp.base - 默认权限组: USER
  12. 允许玩家执行 /warp
复制代码
