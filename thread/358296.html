我想让我服务器的玩家都去矿界去挖，主世界不掉落矿石怎么设置啊。我已经安装了multiwirod插件了。但是不知道怎么设置的！
作者: Lucky777777    时间: 2014-10-27 06:43
  首先，请看帖子 http://www.mcbbs.net/thread-273672-1-1.html
  了解原理后自行修改。或是直接找到路径 /plugins/groupmanager/config.yml
world:
world_nether:
- users
- groups
world_the_end:
- users
- groups
all_unnamed_worlds:
- users
- groups

替换为
world_nether:
world_the_end:
- users
- groups
all_unnamed_worlds:
- users
- groups


  然后你需要有一个essentials和groupmanager
  在主世界输入/mangaddp builder -essentials.pick.id
  id修改为矿物id，每次输入时可以修改一个id的物品
  修改后，在主世界破坏的矿物无法拾取（因为矿物和精准采集的原矿id相同，所以可能会影响原矿在主世界破坏后也无法拾取），其他世界不受影响
