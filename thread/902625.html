标题: 1.14关于选中拥有状态效果的玩家的问题
①如何选中拥有某状态效果的玩家（没有时间、等级的限制）
②如何选中拥有某状态效果的玩家（有时间、等级的限制，要求为某一个区间）

作者: SPGoding    时间: 2019-8-15 00:43
本帖最后由 SPGoding 于 2019-8-15 01:30 编辑

①
@a[nbt={ActiveEffects:[{Id:1b}]}]

②
scoreboard objectives add amplifier dummy
scoreboard objectives add duration dummy

execute as @a store result score @s amplifier run data get entity @s ActiveEffects[{Id:1b}].Amplifier
execute as @a store result score @s duration run data get entity @s ActiveEffects[{Id:1b}].Duration
execute as @a if score @s amplifier matches 0..1 run say 速度Ⅰ 到 速度Ⅱ
execute as @a if score @s duration matches 20..40 run say 速度持续时间还剩 1 秒至 2 秒
scoreboard players reset * amplifier
scoreboard players reset * duration

需要注意的是，Amplifier 从 0 开始；Duration 并非一成不变的，而是在不断减小的。

状态效果的数字 ID 可在 中文 Wiki 查看。
生物的 NBT 结构可在 中文 Wiki 查看。
