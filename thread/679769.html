官方图


作者的话

RankPrefix+ is a powerful Chat/Rank/Scoreboard Manager which
allows you to make your Chat a bit more fancy and also apply the
Prefix and Suffix of the Ranks on your Server to your Player's
TAB-List and NameTag.
But since the Plugin is that big and advanced, its Config may seem
a bit complicated, but dont worry!


作者的话
翻译版

  1. RankPrefix +是一个功能强大的聊天/等级/记分牌经理
  2. 可以让你聊天更花哨,也适用
  3. 前缀和后缀的服务器上你的玩家的TAB-List和NameTag。
  4. 但由于大和先进的插件,它的配置似乎有点复杂,但别担心!
复制代码



配置文件

  1. #——————————————————————#
  2. #———汉化by商萌丿芒果———#
  3. #—感谢酷车手BB弹的指导—#
  4. #———感谢 Feng 的指导———#
  5. #———感谢 雪尼 的指导———#
  6. #——————————————————————#
  7. options:
  8. #是否开启自动更新
  9.   auto-update: true
  10. #开启这项让玩家名的前缀出现在TAB列表里
  11.   use-scoreboard-teams: true
  12. #计分板刷新频率
  13.   update-delay-in-ticks: 100
  14. notifications:
  15.   name-in-chat:
  16. #是否被高亮提到的玩家，例如[Moewe1]
  17.     highlight: true
  18.     sound:
  19. #是否为高亮提到的玩家播放音乐
  20.       enabled: true
  21. #选择要播放的音效
  22.       sound: BLOCK_NOTE_PLING
  23. variables:
  24.   afk:
  25. #如果玩家输入了/afk，那么他的前缀将会变成&e[&a&l离开了&e]
  26.     afk: '&e[&a&l离开了&e]'
  27. #如果他不输入/afk，那么将会显示以下称号
  28.     not-afk: ''
  29. chat:
  30. #在聊天中的布局，这是所有您可以使用变量部分。
  31.   layout: '&7{PREFIX}{PLAYER}{SUFFIX}: {MESSAGE}'
  32. #是否指定将使用行列的个别玩家的布局
  33.   per-rank-layout: false
  34. #是否应该使用这种布局。
  35.   use-layout: true
  36. #是否应该强制要用小写的消息 （防止冒充）
  37.   force-lower-case: false
  38.   world-specific-layout:
  39. #是否根据您在的世界使用不同种类的聊天布局。
  40.     enabled: false
  41. #在主世界的聊天布局
  42.     world: '&7{PREFIX}{PLAYER}{SUFFIX}: {MESSAGE}'
  43. #在地狱的聊天布局
  44.     world_nether: '&7{PREFIX}{PLAYER}{SUFFIX}: {MESSAGE}'
  45. #在末地的聊天布局
  46. #若要添加更多世界的聊天布局，请在格式写，梨子：plotworld:'{PREFIX}{PLAYER}{SUFFIX}:{MESSAGE}'
  47.     world_the_end: '&7{PREFIX}{PLAYER}{SUFFIX}: {MESSAGE}'
  48.   sound:
  49. #是否给发送这条消息的人播放声音
  50.     enabled: true
  51. #选择哪个声音
  52.     sound: UI_BUTTON_CLICK
  53.   local:
  54. #是否启用本地聊天
  55.     enabled: false
  56. #是否每个世界有它自己的聊天
  57.     per-world: false
  58. #你可以说的区域的半径。无限的半径将它设置为-1
  59.     radius: -1
  60.     per-world: false
  61.     radius: -1
  62. ranks:
  63. #哪个组
  64.   builder:
  65. #这个组的聊天前缀
  66.     prefix: '&7[&e玩家&7] '
  67. #这个组的聊天后缀
  68.     suffix: ''
  69. #这个组显示的计分板设置
  70.     scoreboard:
  71. #是否启用
  72.       enabled: true
  73. #计分板前缀
  74.       prefix: '&7'
  75. #计分板后缀
  76.       suffix: ''
  77. #这种等级选项卡列表中的优先级。(1-52) 较低的优先级
  78.       tab-priority: 1
  79. #这个计分板所需的权限，如果没有，则不填
  80.     required-permission: ''
  81. #这个计分板显示的颜色
  82.     message-color: '&7'
  83. #别开启，否则会搞坏服务器，因为他直接绕过权限来使用全部命令
  84.     bypass-OP: false
  85. #消息布局
  86.     chat-layout: '&7{PREFIX}{PLAYER}{SUFFIX}: {MESSAGE}'
  87. #哪个组
  88.   admin:
  89. #这个组的聊天前缀
  90.     prefix: '&7[&c管理&7] '
  91. #这个组的聊天后缀
  92.     suffix: ''
  93. #这个组显示的计分板设置
  94.     scoreboard:
  95. #是否开启这个计分板
  96.       enabled: true
  97. #计分板前缀
  98.       prefix: '&c'
  99. #计分板后缀
  100.       suffix: ''
  101. #这种等级选项卡列表中的优先级。(1-52) 较低的优先级
  102.       tab-priority: 10
  103. #这个计分板所需的权限，如果没有，则不填
  104.     required-permission: 'RankPrefixPlus.admin'
  105. #这个计分板所显示的颜色
  106.     message-color: '&7'
  107. #绕过所有权限来使用全部指令
  108.     bypass-OP: true
  109. #消息布局
  110.     chat-layout: '&7{PREFIX}&4{PLAYER}{SUFFIX}: &c{MESSAGE}'
  111.   order:
  112. #管理组的第一顺序
  113.   - admin
  114. #玩家组的第二顺序
  115.   - builder
