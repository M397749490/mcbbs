一、背景：
大部分人类由于一个致命性的病毒的爆发从而变成了僵尸，只有一小部分的人类存活了，而你，就是一个需要与混乱与僵尸搏斗的勇士！
但是！僵尸并不是你的大问题：大部分玩家并非友善，因为他们想获得你的东西，在这里存活的守则是：不要相信任何人！

二、CraftZ功能：

红色代表暂未加入 | 黄色代表这个功能并未按照预期执行 | 绿色代表这个功能已经加入并且正常运作
（所有功能是可以自定义的，如果你不想要某个功能，你可以禁止它）
进展：30/39 = 77%
  • 僵尸的重生点，使用木牌标记（详情请继续往下阅读）
  • 自动生成僵尸（可选）
  • 僵尸不在白天燃烧
  • 没有其他任何的怪物可以生成
  • 僵尸掉落其他物品（弓箭或者腐肉）
  • 只在你所设定的世界运行Craftz，不需要担心Craftz修改你的整个服务器
  • 吃糖 = 注射肾上腺素。可以让你跑得更快
  • 可以刷新的箱子（物品自订）（详情请继续往下阅读）
  • 玩家有随机重生点（详情请继续往下阅读）
  • 对于玩家加入游戏，有另外的提示信息
  • 玩家会感到渴（使用经验条表示）
  • 你的生命值不会回复，除非你吃了东西
  • 世界保护——玩家无法破坏
  • 你可能被僵尸感染（毒药效果 在Dayz本体里这个效果是流血），可以被抗生素治愈
  • 绷带，和流血的设定。
  • 血包可以恢复生命值
  • 可以弄一个游戏大厅
  • 物品名称与MINECRAFT原版不同（比如说 纸=绷带）
  • 增强僵尸的速度与伤害
  • 蜘蛛网可以当做障碍物（可以用剪刀移除）
  • 世界的边界（如果玩家呆太久，将会直接死亡，就跟战地3的边界差不多，用于限制地图大小）
  • 手榴弹（会爆炸的末影珍珠）
  • 用铁斧右键可以砍树
  • 让服务器不生成新区块的选项
  • 每个玩家都有一个分数版来显示状态（如：杀死僵尸数量，存活时间）
  • 真实世界中的时间
  • 从高处跳下会骨折
  • 如果你死亡了，一个村民僵尸将会生成并且捡起你的物品（坑爹）
  • 显示僵尸发现你的程度（头上的进度条），当数值达到一定程度时，僵尸会攻击你
  • 篝火（用砍下来的树制作），可以在晚上照亮周围的环境也可以烤肉
  • 可以开的车辆
  • 温度设定，如果你太冷的话，你会生病
  • 背包的设定（在Dayz本体中，有默认背包，小背包，中背包，大背包）
  • 生成动物以让玩家获得食物（极其稀有）
  • 工具包，可能你可以做一个VIP专用工具包
  • 制作刷新箱子的简单的方法
  • 可以组队，同一个队伍的人可以重生在同一点
  • 增加对文件，MySQL的支持（目前仅支持文件）

三、不兼容的插件：

CraftZ与以下插件不兼容
  • 如果你的玩家重生点有问题，你需要卸载Essentials（可以用AdminCmd代替）（临时解决方式：将Essentials的设置文件中的“spawn priority”改为LOWEST）
  • 如果你的僵尸生成有问题，请卸载WorldGuard或者设置“block-plugin-spawning"为"false”

四、插件详解：

1、安装：

这个插件的安装与其他插件相同：
  • 下载最新版本的Craftbukkit（推荐版本）
  • 下载本插件的最新版本
  • 把下载的.jar文件放入/plugins文件夹内
  • 重启服务器
  • 关闭服务器并配置插件

2、配置：
配置文件可以在/plugins/CraftZ中找到
在config.yml中，你可以找到最重要的选项，这个教程将会引领你设置

message.yml
这里你可以找到几乎本插件使用的所有信息（对玩家爱展示的）你可以使用在message.yml中已经出现的变量，颜色代码无法生效。
loot.yml
这个文件十分重要，你会在这里找到三个选项
选项名默认可能值描述
Loot.settings.time-before-refill120所有数字这是箱子刷新的时间（以秒计算）
Loot.settings.min-stacks-filled1所有数字箱子刷新物品的最小数量
Loot.settings.max-stacks-filled3所有数字箱子刷新物品的最大数量

Loot列表：

如果你创建了一个可以刷新的箱子，这些列表是十分重要的，你可以增加自己的列表或者更改其中的一个

在列表中的物品是由物品的ID和刷新物品的几率构成的。可以通过查询Minecraft Wiki来了解物品ID，例如：铁剑的ID为267

现在我们想要添加灰色染料，我们怎么做呢？

我们可以知道，灰色染料的ID为351，数据值为6。所以最终需要填写的为351:6，而这些早已经写进默认的列表中了。

但是如果我们想要增加出现的几率（比如说是别的物品的四倍），如果要达成这个效果的话，我们需要在物品ID前面添加：“4x”

最终看上去就是 "4x351:6"

B14
  • Changed: No longer requires Java 7, went back to Java 6 so you should be able to play CraftZ on any device now.
  • Changed: CraftZ now uses UUIDs to prepare for the Mojang name changes. Also, CraftZ player data is a lot smaller. Converter is built-in.
  • Added/Changed: The zombie visibility checker now actually does something! You only attract zombies in the range expressed by the EXP bar.
  • Changed: Only natural mob spawning is blocked now, plugins can spawn anything they want.
  • Changed: "Kick on death" is now disabled by default. Also, a kick bypass permission was added.
  • Added: You can get pre-written signs with "/craftz sign <line2> <line3> <line4>". Plunk them down, click OK, and the text appears.
  • Added: Put a %c% in the third line of a lootchest sign to automatically let CraftZ detect a chest above or below the sign, so you don't have to investigate the y-coord if chest is already there.
  • Added: You can modify the front-end prefix.
  • Added: Mini zombies as well as grenades can be disabled.
  • Changed: When your legs are broken, you can't sprint.
  • Fixed: Server reloading doesn't break CraftZ.
  • Fixed: Block checking algorithm was improved -> auto zombie spawning now works correctly.

  • Fixed: World border not working at all.
  • Fixed: Loot chests can't be created. If you somehow manage to, they are empty.
