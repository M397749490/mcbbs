能不能做到 怪物在未发现玩家 之前不会乱跑，呆在原地不动。
作者: Mixne    时间: 2020-4-5 17:12
本帖最后由 Mixne 于 2020-4-5 17:18 编辑

简单，举个例子，注意AIGoalSelectors，这个是行动选择，数字是优先级，最高是0，然后clear是清除怪物的默认行动
wslz:
  Type: SKELETON
  Display: '&8&l我是例子'
  Health: 20
  Damage: 1
  AIGoalSelectors:
  - 0 clear
  - 1 meleeattack
  - 2 lookatplayer
  AITargetSelectors:
  - 0 clear
  - 1 players
  Equipment:
  - leather_helmet:4
  Drops:
  - cjsj 1 0.2
  Options:
    AlwaysShowName: true
    FollowRange: 15
    MovementSpeed: 0.2
    KnockbackResistance: 1
    Collidable: true
    PreventRandomEquipment: true
    PreventItemPickup: true
    PreventOtherDrops: true
    Silent: true
