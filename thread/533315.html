作者: 格林    时间: 2015-12-21 21:10
1 你要有GroupManager插件。
2 打开GroupManager文件夹。
3 找到GroupManager文件夹打开worlds文件夹。
4 例如：我想禁止 world 世界禁止破坏，那么你就打开 world文件夹，或是你想禁止 plotmeworld 那么你就打开
   plotmeworld文件夹。
5 打开groups.yml文件(用记事本打开)
6 找到这一段，注意红字部分！！！
Default:
    default: true <--把这里从 false 改为 true
    permissions:
    - -bukkit.command.kill
    - coreprotect.inspect
    - killermoney.earnmoney
    - killermoney.getcash
    - serversigns.use
    - serversigns.use.*
    inheritance:
    - g:groupmanager_default
    - g:bukkit_default
    - g:essentials_default
    - g:towny_default
    info:
      prefix: '&e'
      build: false
      suffix: ''
      perfix: '[Default]'

然后
Builder:
    default: true <--把这里从 true 改为 false
    permissions:
    - coreprotect.inspect
    - killermoney.earnmoney
    - killermoney.getcash
    - serversigns.use
    - serversigns.use.*
    - serversigns.use.promote
    inheritance:
    - default
    - g:essentials_builder
    - g:towny_builder
    info:
      prefix: '&2[Player]'
      build: true
      suffix: ''
      perfix: '[Builder]'

保存即可.

作者: 格林    时间: 2015-12-22 19:22
你好楼主，你问的 “禁用世界TP”，请输入以下指令试试：

Multiverse-Core多世界插件:
/mangdelp Builder mv.tp
/mangdelp Builder multiverse.tp

MultiWorld多世界插件：
/mangdelp Builder multiworld.command.goto
/mangdelp Builder multiworld.command.move

输入的时候注意大小写！
