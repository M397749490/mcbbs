看起来你的服务端分配的内存过大了。

请适当调小。
另外移除启动脚本上其他的启动参数。

像是这样：

@ECHO OFF
color 0A
title 服务器后台
SET BINDIR=%~dp0
java -Xmx4096M -Xms1024M -jar 服务端核心名.jar
PAUSE

还有报错的意思是无法在虚拟内存页面文件上分配足够空间。

建议调大你电脑的虚拟内存设置，内存如果是4G的话就分8192的虚拟内存，8G以上给16384M虚拟内存，或者由系统自动接管，设置方法可以自行百度

可尝试重装64位java8，目前最新版本是212
