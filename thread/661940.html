于是，我无意中碰到强大的DeluxeMenus杜蕾斯菜单
它跟等级系统有什么关系？
你要发现它的特点>优先级

于是我灵光一感，花了一个下午想出了等级系统的思路：0级（0>10经验）>满级
在位想出来了吗？想不出来的话继续看教程吧

图片展示









工作原理Principle

利用DeluxeMenus杜蕾斯菜单的优先级
判断不同权限不同等级/经验
但是，升级方面我暂时只能用游戏币兑换经验或升级


准备工作Work

准备好以下东西
DeluxeMenus杜蕾斯菜单[作为优先级判断]
ChestCommands[作为游戏币兑换经验等级]
Permission跨服推荐使用的权限插件
单端可使用GroupManage等权限插件
Vault作为经济前置以及Ess或其它经济插件

一个升级系统（运用游戏币兑换权限的原理）
  up00-0:
    material: 384
    data: 0
    slot: 21
    update: true
    priority: 1
    display_name: '&a&n升级系统'
    view_requirement: 'BukkitPlayer.hasPermission("level.0.0")' #这是0级0经验显示的，足够游戏币后可以点击这个开始升级变成0级1经验等
    update: true
    lore:
    - '&7&m-------------------&a&m-----&7&m-------------------'
    - ' '
    - '&f&l如何兑换经验'
    - '&a知道游币吗？它的作用还可以兑换经验哦'
    - ' '
    - '&f&l如何获取游币'
    - '&a通过&e小游戏娱乐&7/&e挂机娱乐&7/&a活动&a等方式获得'
    - ' '
    - '&f&l当前兑换需求'
    - '&650游币'
    - '&c兑换后会扣除50游币'
    - ' '
    - '&7&l[&a&l点击兑换经验&7&l]'
    - ' '
    - '&7&m-------------------&a&m-----&7&m-------------------'
    left_click_commands:
    - '[console] cc open levelup1 %player_name%'
#这时候开始运用强大的CC菜单作为交易吧，游戏币兑换获得新等级权限并且删除旧等级（不懂的话，给我分QAQ，我会放附件给大家）
    right_click_commands:
    - '[console] cc open levelup1 %player_name%'
