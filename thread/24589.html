你真是多此一举。。。
打开方式---Java（TM）Platform SE Binary
或者
  1. @ECHO OFF
  2. SET BINDIR=%~dp0
  3. CD /D "%BINDIR%"
  4. "%ProgramFiles%\Java\jre7\bin\java.exe" -Xincgc -Xmx1G -jar minecraft_server.jar nogui
  5. PAUSE
复制代码
（如果你装的是Java6，请将jre7改为jre6）
复制以上代码，新建一个txt文本文件粘贴进去，保存文本文件关闭，改名（包括后缀名）为Launch.bat ,放到服务器目录， 双击启动谢谢。。。
