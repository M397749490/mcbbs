PunchEffects

打人的时候给受害者一些效果



--一[插件介绍]一--

Plugin Introduction



这款插件唯一的特点，也是最大的特点，就是能够附加效果(当玩家击打别的生物时)

这款插件有一个缺陷就是不能在游戏内添加击打效果。

原帖更新！

+ Added WorldGuard Support (Option in the configs.yml)
[+]增加WorldGuard支持(点击插件名可直达搬运帖)
+ Fixed the effects level where the level was increased by one.
[+]修正了药水效果比配置文件设置等级高1级的问题
+ Cleaned up some code to make it more scalable in future.
[+]未来将会优化代码使其能够更个性化
+ Added Per Item Effects. You can configure if the player has to hold a certain item, with a display name and a lore or not (Type "ANY" in the "material" section to make it works with any item and none items, type "NONE" in the "display_name" section to check for an item without custom name, type [] in the "lore" section to check for an item without custom lore).

[+]加入了对于物品的手持效果(所持物品需要有对应Lore和名称)。material项填ANY则可以让其不生效或是在任何物品上都生效。取消检测Lore则在lore项输入[]即可。取消检测名称则在diaplay_name项中输入NONE即可
+ Added new effect "SMITE" which remove all the entity effects from the entity

[+]加入"SMITE"效果方便清除生物上的所有效果

最近更新

[+]加入吸血鬼(VAMPIRE)效果,该效果根据玩家造成的实际伤害按比例回复生命

[fix]修复WorldGuard支持中关于__Global__的问题

[fix]修复吸血鬼和清除效果的BUG

[+]加入了每个效果的冷却时间和触发条件并修复了一些小BUG

[+]加入了HAND使效果仅能触发于空手攻击别人

[add]添加了一个对旧版(1.12及以下)WorldGuard的支持

[fix]修复无法识别损坏物品的小问题

[fix]修复项目检查器优化问题

[+]加入PROJECTILE标签以识别弹射物造成的伤害

[+]对于弹射物的标签添加only_arrow过滤标签

[+]加入了config中可选的无权限选项

[fix]修复了一个无法在旧版运行的小问题

过时的旧配置:


# 每一个自定义击打效果都能有一个权限，这里是一个样本
# 所有效果名称可以在这里找到 https://hub.spigotmc.org/javadoc ... tionEffectType.html
# 只要将效果名称用双引号括起并放在effect:项后面即可使用
#=---------------------------------=#
# punch_effects:                    #
#   effectname1:                    #
#     permission: permission1       #
#     effect: "SMITE"               #
#     holding_item:                 #
#       material: "DIAMOND_SWORD"   #
#       display_name: "NONE"        #
#       lore:                       #
#         - "A LORE LINE 1"         #
#         - "A LORE LINE 2"         #
#     mob_effect: true              #
#     damager_effect: true          #
#     player_effect: true           #
#     worldguard_check: true        #
#     duration: 99999 (seconds)     #
#     level: 3                      #
#=---------------------------------=#

punch_effects:
  # 效果
  smite:
  # 效果名称
    permission: peffects.smite
    # 对应权限
    effect: "SMITE"
    # 效果名
    holding_item:
    # 手持物品的探测
      material: "DIAMOND_SWORD"
      # 物品名，大小写宽松
      display_name: "Smite Sword"
      # 检测名字
      lore: []
      # 检测lore
    mob_effect: true
    # 作用于生物
    damager_effect: true
    # 作用于持有者
    player_effect: true
    # 作用于别的受攻击玩家
    worldguard_check: true
    # 启用WorldGuard检查
    duration: 5
    # 持续时长
    level: 1
    # 等级
  heal:
    permission: peffects.heal
    effect: "REGENERATION"
    holding_item:
      material: "DIAMOND_SWORD"
      display_name: "Heal Sword"
      lore: []
    mob_effect: true
    damager_effect: true
    player_effect: true
    worldguard_check: true
    duration: 60
    level: 1

新版config

# Here is an example of how you set up a new effect per permission
# You can find all the available effects on the plugin page under the spoiler "Available Effects"
# You can find all the available item material here https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html (1.15.2 for other version please refer to the proper documentation!)
# Simply add the name of the material under the column "Enum Constant" in the documentation
#=---------------------------------=#
# punch_effects:                    #
#   effectname1:                    #
#     use_permission: true          #
#     permission: permission1       #
#     effect: "SMITE"               #
#     holding_item:                 #
#       material: "ANY"             #
#       only_arrow: false           #
#       display_name: "NONE"        #
#       lore:                       #
#         - "A LORE LINE 1"         #
#         - "A LORE LINE 2"         #
#     mob_effect: true              #
#     damager_effect: true          #
#     victim_effect: true           #
#     worldguard_check: true        #
#     duration: 99999 (seconds)     #
#     level: 3                      #
#     cooldown: 15 (seconds)        #
#     trigger_chances: 100 (%)      #
#=---------------------------------=#

punch_effects:
  smite:
    use_permission: true
    #是否使用权限
    permission: peffects.smite
    #若使用权限则此处需要填写
    effect: "SMITE"
    #效果名
    holding_item:
    #触发条件:手持物品
      material: "DIAMOND_SWORD"
      #物品名
      # "only_arrow" option Will only be read if the material is set to "PROJECTILE"
      only_arrow: false
      #当材料名设定为弹射物时此选项可用
      #大致效果为箭矢命中时触发效果
      display_name: "Smite Sword"
      #物品判定名称与lore
      lore: []
    mob_effect: true
    #此处注释与上一版本相同
    damager_effect: true
    victim_effect: true
    worldguard_check: true
    duration: 5
    level: 1
    cooldown: 15
    #冷却时长
    trigger_chances: 100
    #触发几率

    effect: "REGENERATION"

      material: "DIAMOND_SWORD"
