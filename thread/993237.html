命令/权限 Commands/Permissions

HungerGames 插件的所有命令，详细内容也可查看Commands-Wiki.

命令权限描述
/hg join <竞技场>hg.command.join加入游戏
/hg leavehg.command.leave退出游戏
/hg spectate <竞技场>hg.command.spectate观看游戏
/hg tphg.command.tp打开传送菜单(处于观察模式)
/hg listhg.command.list列出游戏内玩家列表
/hg listgameshg.command.listgames列出所有可用游戏

管理员命令 AdminCommands

命令权限描述
/hga forcestop <竞技场/所有>hg.stop强制停止游戏
/hga wandhg.admin.command.wand获取区域选择工具
/hga create <名称> <最少玩家数> <最多玩家数> <时间(秒)>hg.admin.command.create创建竞技场(时间必须为30倍数)
/hga delete <竞技场>hg.admin.command.delete删除竞技场
/hga teleportworld <世界名>hg.admin.command.teleportworld传送至不同世界
/hga addspawnhg.admin.command.addspawn设置玩家出生点
/hga randomchests <竞技场> <最少箱子数> <最多箱子数> <概率>hg.admin.command.randomchests创建随机资源箱
/hga addchesthg.admin.command.addchest设置资源箱点
/hga convertchests <竞技场>hg.admin.command.convertchests将宝箱点转换为出生点
/hga chestrefill <竞技场> <时间(秒)>hg.admin.command.chestrefill设置箱子填充时间(若取消则为0，必须为30倍数)
/hga setsign <竞技场>hg.admin.command.setsign设置竞技场加入木牌(瞄准木牌输入)
/hga setexithg.setexit设置竞技场退出点
/hga forcestart <竞技场>hg.admin.command.forcestart强制开始游戏
/hga toggle <竞技场>hg.admin.command.toggle切换竞技场状态(锁定/解锁)
/hga reloadhg.admin.command.reload重载插件

配置 Configuration

CONFIG.YML
lang: "zh_CN"



#如果为true，则仅列出主要命令

#如果为false，将会列出重载命令

only-main-commands: true



#游戏设定

settings:

  # 游戏开始的时间,保护时间 (以秒为单位)

  free-roam: 25

  # 资源箱内最多可产生物品

  max-chestcontent: 5

  # 资源箱内最少可产生物品

  min-chestcontent: 1

  # 奖励箱内最多可产生物品

  max-bonus-chestcontent: 5

  # 奖励箱内最少可产生物品

  min-bonus-chestcontent: 1

  globalexit:

    enable: false

    level: world

    x: 0

    y: 0

    z: 0



#刷新设置

rollback:

  # 让玩家可以破坏竞技场,游戏结束后刷新

  allow-block-break: false

  # 启用后，将不允许玩家在冷却时间内破坏方块

  protect-during-cooldown: true

  # 庄稼保护,防止践踏庄稼

  prevent-trampling: true

  # 玩家可以破坏的方块列表(所有方块则为EMPTY)

  editable-blocks:

    - TALLGRASS

    - LEAVES

    - LEAVES2



#结束设置

final:

  # 游戏剩下x秒后,将玩家传送回起点

  enabled: false

  # 公告提醒时间(以秒为单位)

  # 将玩家传送至起点

  # (注意: 必须为30的倍数, 例如: 30, 60, 90, 120, 等)

  countdown-start: 60

  # 停止公告提醒时间(以秒为单位)

  # 将玩家传送至起点

  countdown-end: 50

  # 在最终对决开始之前,冻结玩家时间(以秒为单位)

  countdown-freeze: 5

  # 你设置的第一个出生点的最终边界大小

  radius: 60



#观看设置

# 启用后,允许玩家观看游戏且不会影响比赛

spectate:

  # 默认禁用

  enabled: false

  # 当玩家被击杀后,自动切换为观看模式

  on-death: true

  # 观看时是否能聊天

  chat: false



#区域工具

wand:

  id: "blaze_rod"

  # 名称

  name: "&3饥饿游戏&f(&a区域工具&f)"

  # 描述

  lore:

    - "&7左键点击设置第一点"

    - "&7右键点击设置第二点"```
