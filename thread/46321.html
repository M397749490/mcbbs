简介：
Tested and works with  CB 1.3.1-R1.0

HatMe is a simple "hat" plugin with a little more functionality than most. Just like any common hat plugin '/hat' puts the block in your hand on, and '/unhat' takes it off. What this plugin adds is the ablity to restrict blocks and items from the config file. HatMe uses Bukkit permissions but will use OP permissions if Bukkit permissions is not found.



命令与权限：

  • '/hat' - 将你手中的物品带在头上- 'hatme.hat'
  • '/hat <item id>' - 将此ID物品带在你的头上 （注意：这个方块可以放回背包） - 'hatme.hat.give'
  • '/hat -a' - Puts entire stack on your head - 'hatme.hat.all'（这个.... 似乎跟/hat没啥区别，有待考察）
  • '/unhat' - 把头上的东西放回背包 （鼠标操作也行） - 'hatme.hat'
  • "hatme.*" - 给予玩家HatMe插件的所有权限
  • "hatme.hat" - 允许玩家使用/hat
  • "hatme.hat.all" - 允许玩家使用 /hat -a
  • "hatme.hat.give" - 允许玩家使用 /hat <item id>
  • "hatme.norestrict" - 给予玩家无限制使用/hat （针对".<item id>"而言）
  • ".<item id>" 只允许玩家使用特定的方块. 例如： "hatme.hat.5" 或 "hatme.hat.give.5"
