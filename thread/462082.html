工具使用Node.JS编写, 使用之前请确定您的服务器已经安装Node.js,Npm


使用步骤:

1. 进入带app.js的目录下

2. 执行 sudo npm install 和 chmod -R 777 .

3. node ./bin/www

4. 如需使用进程守护工具 请确保您的目录位置 以免无法读取到SQLite数据库


基于Node.JS制作的一个批量管理Minecraft服务端小工具 适用于BC大型群组服 不用在多个Screen里切换服务端 操作十几个服务端更得心应手

同时手机横屏也能达到非常好的显示效果，避免了没有电脑情况下烧流量连接至远程桌面/SSH。

如果您有更好的建议 欢迎把您的建议发送至我的邮箱: 1020938070@QQ.com

由于涉及多个服务端操作所以更新速度较为缓慢，目前仅有基本功能(启动 关闭 强制关闭 控制台 API(没文档) ) 将来将提供市面上大部分启动器的常用功能 以及 性能报表


浏览器请使用 Chrome Firefox IE11 ++++ 的版本 否则可能无法连接至控制台。
