请大家先了解一下Flan里面各各文件夹的用处：http://www.mcbbs.net/thread-526954-1-1.html
枪械文件夹，就是guns文件夹！
一个AK47的枪械设置：



//【§——颜色符号】后面加数字，就和服务器里面说话的颜色一样
Name §3[LT]Ak47

//这是在枪械制作盒里面添加是打的名字
ShortName ak47

//这个枪械使用的弹药名字
Ammo ak47Ammo
//这个枪械的图标名字
Icon AK47
//这个并没有什么乱用，全部填 255
Colour 255 255 255
//这个是枪械的物品代码 我服务器会自动分配代码的 不知道你们的一样不
ItemID 23813
//换弹时间，每20大约为1秒
ReloadTime 40
//枪械的后坐力，1点大约为1.5个方块大小
Recoil 2
//枪械的威力
Damage 5
//枪械的精准，当为1的时间 就和开了无后座力挂一样厉害
Accuracy 5
//枪械的射击速度
ShootDelay 2
//枪械的射击声音文件
ShootSound AK47Shoot
//枪械的射击换弹
ReloadSound MP44Reload
//这个并没有什么用处的
Mode FullAuto
//子弹的飞行速度
BulletSpeed 10.0
//枪械的射击距离，这个最好不要改动
Scope None
ZoomLevel 1.0
FOVZoomLevel 1.25
//这个没什么用，建议不要动
Deployable False
DeployedModel None
//枪械的模 就是在 com中的子文件-flansmod中的文件client 中的model 新建的名字是mw文件夹  没有那个符号【.】
Model mw.AK47
//枪械的染色
Texture AK47
//这个我也不太清楚什么意思
AllowAllAttachments false
//能安装上这把武器的配件
AllowAttachments flanMWSilencer flanMWRedDot flanMWACOG flanMW4xScope flanMWSingleFire flanMWBurstFire flanMWAutoFire
//枪械【前】面能安装的配件 true 开启 false 关闭
AllowBarrelAttachments true
//枪械【上】面能安装的配件 true 开启 false 关闭
AllowScopeAttachments true
//枪械【后】面能安装的配件 true 开启 false 关闭
AllowStockAttachments false
//枪械【下】面能安装的配件 true 开启 false 关闭
AllowGripAttachments false
//这个不用管
NumGenericAttachmentSlots 1




一个AK47弹药的设置：


//【§——颜色符号】后面加数字，就和服务器里面说话的颜色一样
Name §3[LT]§fAk47 §f弹药
//这是在枪械制作盒里面添加是打的名字
ShortName ak47Ammo
//子弹的模型 暂时只有一个 Bullet
Model Bullet
//这个并没有什么乱用，全部填 255
Colour 255 255 255
//这个是枪械的物品代码 我服务器会自动分配代码的 不知道你们的一样不
ItemID 23812
//这个枪械的图标名字
Icon AK47Ammo
//重力对子弹下降速度的影响 一般步枪 0.25就可以了的 火箭筒 1就可以了的
FallSpeed 0.25
//弹夹的最大堆积数目
MaxStackSize 4
//子弹的数量，最大上限为32000
RoundsPerItem 30
//特殊子弹的伤害提成
Damage 1
/ /散弹枪 的设置 如果不是散弹枪 就可以不用这个东西
numbullets 3

//枪械的爆炸 1 是大约为2*2的范围 2大约为 5*5的范围
Explosion 0
//爆炸是否会对地形造成破坏
ExplodeOnImpact False
Fuse 0
FlakParticles 0
//火焰的燃烧，即1会烧一个3x3，2会烧一个5x5平方
Fire 0
//火焰是否是真实的
BreaksGlass True
//Size of box to check for entities to hit / detonate
HitBoxSize 0.1
HitSound bullet
//子弹可以穿过一个实体，击中它，这个不是破甲的意思，每把枪械 必须开启 否则打人不掉血
Penetrates True
//这个是否飞出的子弹带烟雾效果
SmokeTrail False

弹药的特殊能力

实例：
PotionEffect 19 80 2
意思就是 毒药 4秒 二级的毒
每20为1秒



防具的设置：



//【§——颜色符号】后面加数字，就和服务器里面说话的颜色一样
Name G§3[LT]§8幽灵之盔
//这是他在汉化文件对应的名字
ShortName gilliehat
//这个是防具的物品代码 我服务器会自动分配代码的 不知道你们的一样不
ItemID 27236
//这个枪械的图标名字
Icon GillieHat
//这个并没有什么乱用，全部填 255
Colour 255 255 255
//戴在身体哪个部位 Helmet 头部 Body 胸部 Pants 腿部 Boots 靴部
Type Helmet
//他的防御力 0.2为一格的护甲
Defence 0.2
///护甲的染色
ArmourTexture gillie
其他部位和这个差不多，唯一改变的只是这个
//戴在身体哪个部位 Helmet 头部 Body 胸部 Pants 腿部 Boots 靴部
Type Helmet

//  击退抗性

KnockbackModifier 0.1
// 让头盔具有夜视药水的能力 ture 开启 false 关闭
NightVision True
//让这件装备拥有回血加快的能力
SmokeProtection True

这是从源码中找到的，半根单词据原意半翻源码大概翻译一下
DamageReduction  Defence  增加防御，具体多少因为对MC的API不熟系所以不敢确定
MoveSpeedModifier  Slowness  增加速度，具体多少因为对MC的API不熟系所以不敢确定
JumpModifier 增加跳跃，具体多少因为对MC的API不熟系所以不敢确定
KnockbackReduction   KnockbackModifier 增加击退抗性，具体多少因为对MC的API不熟系所以不敢确定
NightVision 是否夜视
NegateFallDamage 是否免除摔落伤害(确定是免除而不是减少，因为源码中是布尔型)
Overlay 这个不懂，单词原意是覆盖，具体什么作用我没试
SmokeProtection 是否不受枪械烟雾效果的影响(确定是免除而不是减少，因为源码中也是布尔型)
ArmourTexture   ArmorTexture 这个就是材质了
