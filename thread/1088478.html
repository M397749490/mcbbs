使用方法
使用  /coords  命令打开/关闭坐标显示

插件命令
/coords 打开/关闭坐标显示

/coords reload
重新加载配置文件
（请使用此命令重载插件而不是/reload或重启服务器）
/coords author 显示作者信息
插件权限
coords.use 允许使用/coords
coords.reload 允许使用/coords reload

配置文件

  1. # Coordinates
  2. # Version: 2.5
  3. # Made by: johntheskeleton | Plugin_Developer

  5. # If set to true, players will have coords enabled when they join the server. (Does not need the coords.use permission).
  6. #设置为true，则玩家进入服务器自动显示坐标（不需要use权限）
  7. Enable On Join: true

  9. # Set these true to where you want the information to be displayed!
  10. #设置坐标显示在action bar还是boss bar。
  11. ActionBar: false
  12. BossBar: true

  14. # If set to true, the ActionBar will fade away when not moving. If set to false, the ActionBar will stay visible.
  15. #如果设置为true，action bar位置的坐标信息在玩家静止将消失，否则会一直可见。
  16. ActionBar Fade: true

  18. # Messages when they execute the command "/coords"
  19. #使用/coords命令开启坐标显示时的消息提示
  20. Enabled Message:
  21.   - '&r'
  22.   - '&aYou have &2&nenabled&r &athe coords!'
  23.   - '&r'
  24.   
  25. #使用/coords命令关闭坐标显示时的消息提示
  26. Disabled Message:
  27.   - '&r'
  28.   - '&cYou have &4&ndisabled&r &cthe coords!'
  29.   - '&r'

  31. #无权限时的消息提示
  32. No Permission:
  33.   - '&cYou do not have permission!'

  35. # This is the message that will appear above the hotbar and/or bossbar.
  36. # NOTE: These will have to be set to true in order to see them.
  37. # Avaliable place holders: %X%, %Y%, %Z%, %UPPER_CASE_FACING%, %LOWER_CASE_FACING%, %FACING%, %FACING_ABBREVIATION%, %YAW%, %PITCH%, %BIOME% %UPPER_CASE_BIOME%, %LOWER_CASE_BIOME%, %SERVER_TIME%, %SLIME_CHUNK%, %UPPER_CASE_SLIME_CHUNK%, %LOWER_CASE_SLIME_CHUNK%  
  38. BossBar Format: '&3X&7: %X%     &3Y&7: %Y%     &3Z&7: %Z%     &3Facing&7: %UPPER_CASE_FACING%'
  39. ActionBar Format: '&3X&7: %X%     &3Y&7: %Y%     &3Z&7: %Z%     &3Facing&7: %UPPER_CASE_FACING%'
  40. #坐标样式设置
