Command iConomy 是一个可以让玩家使用命令花money的插件


问：为什么使用命令要花钱呢？
答：因为假设你的服务器有副本，死亡后无限back，那还有什么意思？
    假设你服装有环境，那么缺水了，回家，再回来，装个MOD还有什么意思？
装了这个插件，秒杀无限back


概述：
Command iConomy是一个能够让玩家使用命令从iConomy账户中扣除一定资金的插件。扣除资金的命令需要java正则表达式。如果玩家输入相对命令，即从玩家iConomy账户中扣除指定资金，插件需要Vault
机翻加手工润色
Overview
Command iConomy is a plugin that allows a server admin to assign a cost to server commands that is deducted from a player's iConomy account whenever a player uses that command. Commands are matched using java regular expressions. If text entered by a player matches a configured rule, Command iConomy will attempt to bill the player. Command iConomy requires Vault!




权限
CommandIConomy.Free  有了这个权限的人，使用命令将不花钱

Internationalization  这个是配置？
可以在配置三个附加的设置。 yml文件本地化命令iConomy的文本。 创建config.yml。
它们是:
NoAccountMessage
InsuficientFundsMessage
AccountDeductedMessage
Substitute (cost) for cost


使用方法：
设置一个命令的价格,prices.yml添加一行。 命令iConomy匹配正则表达式对用户输入。 正则表达式允许你单独收取个人sub-commands甚至特定的命令参数。
一个经典的例子：^/tp$: 10
命令表达式匹配从上到下。 如果找到匹配项,命令iConomy停止寻找一个匹配和收费玩家配置数量。 如果命令配置一个零成本,处理将会停止,但球员将不会被起诉。 这些特性允许开放结束命令一起单独起诉。这句话我想应该是，自上而下的匹配命令，你可以在收费命令行上面，增加一个免费的命令，为的是玩家输入错误的命

^/warp help$: 0
^/warp \S+$: 10
下面每一句英文原文下面都是机翻加手工润色或者纯机翻
