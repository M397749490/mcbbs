GameTime
能帮助腐竹管理玩家在线时间和点卡
效果与魔兽世界的相似，收费准入向
自认为是目前RPG服务器美化吃相的利器

如何使用
  • 将插件本体放在服务端根目录下的plugins文件夹中。
  • 运行服务端。
  • 在./plugins/Gametime/config.yml文件中配置你所需要设定的内容。
  • 重启服务端（或使用/gt reload重载GameTime配置文件）。

指令权限
  1. #输出GameTime插件版本、作者。
  2. /gt
  3. gametime.gt 默认OP拥有

  5. #输出GameTime插件帮助内容，即有权限使用的指令介绍。
  6. /gt help
  7. gametime.help 默认All拥有

  9. #使用一个[key]的Key。
  10. /gt use [key]
  11. gametime.use 默认All拥有

  13. #检查本人拥有的游戏时间
  14. /gt check
  15. gametime.check 默认All拥有

  17. #检查[name]玩家拥有的游戏时间
  18. /gt check [name]
  19. gametime.checkother 默认OP拥有

  21. #检查[Key]的状态，返回'create_time'、'vaule'，
  22. #如果被使用还需返回'user'、'use_time'。
  23. /gt key [Key]
  24. gametime.checkkey 默认OP拥有

  26. #为[name]玩家增加[time]分钟的游戏时间
  27. /gt add [name] [time]
  28. 仅Console(依据配置项op_can_use_add决定)

  30. #生成[amount]个，[time]秒长的点卡Key。
  31. /gt create [time] [amount]
  32. 仅Console

  34. #导出所有未使用的Key，填{time}时只导出该vaule的Key
  35. /gt export {time}
  36. 仅Console

  38. #重载插件
  39. /gt reload
  40. 仅Console

  42. #不计费
  43. gametime.bypass
  44. 默认OP拥有

配置文件
  1. #%time%替换符，可使用%day%,%hour%,%minute%,%second%
  2. time_format: '%day%天%hour%小时%minute%分钟'

  4. #玩家第一次进入游戏得到的游戏时间
  5. original_time: 0

  7. #插件是否计费(登录服等建议按需选false)
  8. cost_time: true

  10. #OP是否可以使用/gt add命令,此项可以防止熊OP
  11. op_can_use_add: false

  13. #是否与登陆插件互联,使用后玩家默认在插件登陆以后才扣费
  14. #目前支持: AuthMe, CrazyLogin, XsignIn, LoginSystemPro
  15. use_login_hook: true

  17. #玩家进入游戏，数据初始化未完成时,使用命令出现
  18. waiting_message: '&e[GameTime]&b正在加载您的数据,请稍等'
  19. #查询游戏时间时出现
  20. check_message: '&e[GameTime]&b%name%的游戏时间还剩下%time%'
  21. #被查询玩家不存在时出现
  22. check_missing_message: '&e[GameTime]&b该玩家不存在！'
  23. #充值成功时出现
  24. success_message: '&e[GameTime]&b兑换成功！'
  25. #充值错误时出现
  26. fail_message: '&e[GameTime]&b您的Cdkey有误'

  28. #玩家剩余游戏时间到达阈值时是否提示
  29. inform: true
  30. #阈值，以分钟为单位
  31. inform_time: 30
  32. #剩余游戏时间达到阈值时提示消息
  33. inform_message: '你的游戏时间还剩下%time%'
  34. #是否使用Title来显示
  35. inform_use_title: true
  36. #是否使用mysql数据库（填false则使用本地SQLite）
  37. use_mysql: false
  38. #Mysql数据库名
  39. database: 'GameTime'
  40. #Mysql地址
  41. address: '127.0.0.1'
  42. #Mysql端口
  43. port: 3306
  44. #Mysql用户名
  45. user: 'your account'
  46. #Mysql密码
  47. password:'your password'

数据库结构
  1. #玩家数据表，运行GameTime后上线过的玩家均记录
  2. TIME:
  3.         user(String)
  4.         #玩家ID
  5.         time(long)
  6.         #玩家拥有的时间,单位为秒

  8. #Key主表,已生成未使用的Key记录
  9. MAP:
  10.        account(String)
  11.        #Key值,UUID标准生成
  12.        create_time(date)
  13.        #Key生成时间,以格林尼治时间存储
  14.        value(long)
  15.        #Key所携带的价值,即兑换后可获得的游戏时间,单位为秒

  17. #Key副表,已生成且使用的Key记录
  18. LOG:
  19.        user(String)
  20.        #玩家ID
  21.        account(String)
  22.        #Key值,UUID标准生成
  23.        time(date)
  24.        #Key被使用的时间,以格林尼治时间存储
  25.        value(long)
  26.        #Key所携带的价值,即兑换后可获得的游戏时间,单位为秒
