+ Description +
Players with the "nofall.use" permission will not take fall damage



+ Commands +
There are no commands for this plugin.  
这个插件没有命令


+ Permissions +
nofall.use (A player with that permission will not take fall damage)
拥有该权限的人在Config配置的世界列表中可以有效防止摔伤


+ Configuration +
插件有效世界的列表
可以往下继续添加,但需要注意世界名大小写

# make sure you use the exact capital letters as spelled in your worlds #
worlds:
  - world
  - world_nether
  - world_the_end
  - 注意世界名大小写
