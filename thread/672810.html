风车工作室 作品

你的服务器在招募管理吗？你的服务器有op吗？
你信任他们吗？要是他们是熊op怎么办呢？
这个插件帮助你限制熊op破坏你的服务器！
即使有了op权限也不能为所欲为！
命令：
/limper reload 重载配置文件
/lnop 什么都不做..我实在没想到什么更好的写法..
权限：
所有限制以op为标准，所以没有权限
配置文件：
config.yml
  1. CanPlayerPickupItemDroppedByOp: false
  2. CanOpDamagePlayer: false
  3. CanOpInteractBlockPlayerPlaced: false
  4. CanPlayerInteractBlockOpPlaced: false
  5. CanPlayerBreakTheBlockOpPlaced: false
  6. CanOpBreakTheBlockPlayerPlaced: false
  7. MessageActionStoppedByPlugin: 'You are not allowed to do this!'
  8. PermissionMessage: 'You have no permission to do this!'
  9. CommandMessage: 'Please use /limper reload to reload the plugin!'
  10. ReloadCompletedMessage: 'Reload Completed!'
  11. NoInteractBlocks: [61, 54]
  12. WhiteList: ['zbww']
  13. ForbiddenRule:
  14.   - '/give <CommonPlayer> <AnyThing>'
  15.   - '/eco give <CommonPlayer> <AnyThing>'
  16.   - '/eco set <CommonPlayer> <AnyThing>'
  17.   - '/pay <CommonPlayer> <AnyThing>'
  18.   - '/op <CommonPlayer>'
  19.   - '/kill <CommonPlayer>'
  20.   - '/heal <CommonPlayer>'
  21.   - '/sudo <CommonPlayer>'
  22.   - '/lightning <CommonPlayer>'
  23.   - '/tp <CommonPlayer> <AnyThing>'
  24.   - '/tpall'
  25.   - '/tphere <CommonPlayer>'
  26.   - '/deop <OpPlayer>'
复制代码


以上是默认的配置文件，下面解释一下配置的每一项的用途

以下都是说是否能.....而不是禁止.....请特别注意！
CanPlayerPickupItemDroppedByOp 设置玩家是否可以捡起op扔出的物品，如果为true，op扔出的物品玩家无法捡起，这是为了预防op给玩家物品用的
CanOpDamagePlayer 设置玩家是否可以伤害玩家，如果为true，则op攻击玩家无伤害，这是为了预防熊op杀玩家
下面两个选项所说的一部分、特殊方块详见下文关于NoInteractBlocks的描述
CanOpInteractBlockPlayerPlaced 开启后，op将无法与一部分玩家放置的特殊方块互动，如果你不想让熊op打开玩家的箱子给物品的话，开启这个再好不过了
CanPlayerInteractBlockOpPlaced 正好倒过来，玩家将无法与一部分op放置的特殊方块互动。
CanPlayerBreakTheBlockOpPlaced 玩家不能破坏op放的方块，如果有熊op放钻石块让玩家敲碎，也会失败
CanOpBreakTheBlockPlayerPlaced op不能破坏玩家放的方块，主要为了防熊，不建议开启
MessageActionStoppedByPlugin 当有人的行为被插件制止，就会发送这个信息
ReloadCompletedMessage 插件配置重载后，这个消息自动发送到使用重载指令的op
CommandMessage 提示重载指令用法的信息
NoInteractBlocks 后面是一个用, 隔开的数组，每一个数字是指一个方块id，即上文中的特殊方块
ForbiddenRule 这一部分是op被限制使用的指令
WhiteList 新版本新增功能，一个字符串数组，用, 隔开，表示白名单，白名单内玩家不受限制
ForbiddenRule
- 后面接一个字符串，表示符合的条件
除了正常的字符串匹配之外，还有以下特殊参数
<CommonPlayer> 能匹配普通玩家
<AnyThing> 任何内容
<OpPlayer> 能匹配op玩家
如果与某个规则与玩家的指令匹配，玩家的指令会被阻止。
如果玩家输入的指令参数比设置好的规则还要多，那么仅仅会比较规则中有的靠前的一部分参数。
特殊和一般匹配规则严格区分大小写，请特别注意！
插件的配置大致就是这样，
