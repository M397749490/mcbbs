十一、skriptAPI简述
什么是函数:
    通俗讲，函数就是封装了一些功能方法的集合，你只需向里面传递参数就行，最后就会得到你想要的结果。在skript里面，函数分为两类：有返回值函数，和无返回值函数。
函数类型：
有返回值函数：
  1. function myFunction(i: number) :: number:
  2.     set {_i} to {_i} + 1
  3.     return {_i}
复制代码
  1. function 函数名(参数名: 参数类型) :: 返回值类型:
  2.     set {_i} to {_i} + 1
  3.     return {_i
复制代码
无返回值函数：
  1. function leathSet(p: player):
  2.     set helmet of {_p} to leather helmet
  3.     set chestplate of {_p} to leather chestplate
  4.     set leggings of {_p} to leather leggings
  5.     set boots of {_p} to leather boots
复制代码
  1. function 函数名(参数名: 参数类型):
  2.     set helmet of {_p} to leather helmet
  3.     set chestplate of {_p} to leather chestplate
  4.     set leggings of {_p} to leather leggings
  5.     set boots of {_p} to leather boots
复制代码

调用函数：
在代码中直接使用： 函数名字(参数) 就可以。例如：
  1. set {this.number} to 1
  2. #{this.number} 现在是1
  3. set {this.number} to myFunction({this.number})
  4. #{this.number} 现在将会是2
复制代码
注意事项：
1、所有函数必须写在被调用之前，否则将会产生错误。
2、所有传递的参数在函数里面使用局部变量表示。比如参数是p，那么在函数代码里面使用{_p}表示。
3、传递的参数必须和函数的参数类型一样，否则将会产生错误。
