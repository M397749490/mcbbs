你看，又一个提问不说版本的。
我的想法是，以武器本身的伤害为基础伤害，然后通过在受伤的实体上面生成随机伤害的箭来达到随机伤害的效果。
以单人模式为例。
其实要做的事情很简单，就是在玩家拿着特定武器时，在受到伤害的实体上生成随机伤害的箭
第一步，给拿着特定武器（这里以钻石剑，即 minecraft:diamond_sword 为例）的玩家加 tag。
1.12
  1. /scoreboard players tag @p add chosen_by_sky {SelectedItem:{id:"minecraft:diamond_sword"}}
复制代码
1.13
  1. /tag @p[nbt={SelectedItem:{id:"minecraft:diamond_sword"}}] add chosen_by_sky
复制代码

第二步，找受到伤害的实体，加tag。
1.12
  1. /scoreboard players tag @e add hurted {HurtTime:9s}
复制代码
1.13
  1. /tag @e[nbt={HurtTime:9s}] add hurted
复制代码

第三步，在满足上面两个条件时，生成随机伤害的箭。
我这里用一个诡异的随机数生成的方式。
  1. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","1"]}
  2. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","2"]}
  3. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","3"]}
  4. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","4"]}
  5. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","5"]}
  6. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","6"]}
  7. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","7"]}
  8. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","8"]}
  9. /summon armor_stand ~ ~ ~ {Invisible:1b,Tags:["random","9"]}
复制代码
从它们里随机抽一个加tag
1.12
  1. /scoreboard players tag @r[type=armor_stand,tag=random] add selected
复制代码
1.13
  1. /tag @e[sort=random,tag=random,type=armor_stand,limit=1] add selected
复制代码
然后穷举被选中盔甲架的 tag。
1.12
  1. /execute @e[tag=selected,tag=1] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:1d}
  2. /execute @e[tag=selected,tag=2] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:2d}
  3. /execute @e[tag=selected,tag=3] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:3d}
  4. /execute @e[tag=selected,tag=4] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:4d}
  5. /execute @e[tag=selected,tag=5] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:5d}
  6. /execute @e[tag=selected,tag=6] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:6d}
  7. /execute @e[tag=selected,tag=7] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:7d}
  8. /execute @e[tag=selected,tag=8] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:8d}
  9. /execute @e[tag=selected,tag=9] ~ ~ ~ execute @p[tag=chosen_by_sky] ~ ~ ~ execute @e[tag=hurted] ~ ~ ~ summon arrow ~ ~2 ~ {damage:9d}
复制代码
1.13
  1. /execute as @e[tag=selected,tag=1] at @s run execute as @p[tag=chosen_by_sky] at @s run execute as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:1d}
  2. /execute if entity @e[tag=selected,tag=2] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:2d}
  3. /execute if entity @e[tag=selected,tag=3] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:3d}
  4. /execute if entity @e[tag=selected,tag=4] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:4d}
  5. /execute if entity @e[tag=selected,tag=5] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:5d}
  6. /execute if entity @e[tag=selected,tag=6] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:6d}
  7. /execute if entity @e[tag=selected,tag=7] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:7d}
  8. /execute if entity @e[tag=selected,tag=8] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:8d}
  9. /execute if entity @e[tag=selected,tag=9] if entity @p[tag=chosen_by_sky] as @e[tag=hurted] at @s run summon arrow ~ ~2 ~ {damage:9d}
复制代码
最后清楚用来生成随机伤害的这些盔甲架
  1. /kill @e[tag=random]
复制代码

清楚用到的tag
1.12
  1. /scoreboard players tag @a remove chosen_by_sky
  2. /scoreboard players tag @e remove hurted
复制代码
1.13
  1. /tag @a remove chosen_by_sky
  2. /tag @e remove hurted
复制代码

至此，你就可以在钻石剑的基础伤害上，对生物造成多于 1 至 9 点的伤害。
