CommandIterator



介绍

我本来是给某个鸽子服务器打工的

某天腐竹说要找一个用物品触发命令的插件

我就顺手写了一个(免费 我很卑微)

前几天在论坛找了一下发现这样的插件好像没有Bukkit版本的(如果是我没找到，欢迎指出)

但是当时这个插件很粗糙

命令只有一个reload

必须通过yaml文件编辑

而且必须依赖MythicMobs插件

花了一天时间来重写这个插件

存储物品采用物品json化并且序列化到文件

编辑采用了在游戏内命令编辑

现在它不需要任何依赖插件即可运行在你的服务器上



为什么选择我

优点

可以执行多条命令

可以设置触发需要点击的方块

可以设置触发的键位

自由编辑

采用序列化方式储存



缺点

编辑不方便







欢迎指出插件缺点，我会尽量改正



命令

PS:带“...”的参数为可变长参数，可以填1至无限个同类参数

/icmd help 插件插件命令帮助
/icmd reload 重载插件
/icmd list 列出所有命令物品编号
/icmd list <编号...> 列出指定编号的命令物品的所有命令
/icmd create <编号> <命令> 创建一个命令物品
/icmd delete <编号...> 删除指定编号的命令物品
/icmd edit <编号> add <命令> 给指定的命令物品添加一条命令
/icmd edit <编号> set <序号> <命令> 设置一个命令物品的指定序号的命令
/icmd edit <编号> delete <序号...> 删除命令物品指定序号的命令
/icmd edit <编号> type <类型> 设置一个命令物品的使用类型(永久有效 Everlasting/一次性 OneTime)
/icmd edit <编号> click <键位> 设置一个命令物品的触发方式(鼠标左键Left/鼠标右键Right)
/icmd edit <编号> block <true/false> 设置一个命令物品触发是否需要点击方块
/icmd get <编号...> 获取编号的命令物品
/icmd save <编号> <json/yaml> 把命令物品保存到文件
/icmd read <文件名> <json/yaml> 从文件中读取命令物品(之前的命令物品会被覆盖)
