怎么样能修改打粉机的输入和输出物品？版本是1.10.2
作者: Deing    时间: 2018-2-6 11:12
Crafttweaker已经不再支持ic2了，因为1.10.2的ic2已经内置了自己的配方修改方法

诚然，在crafttweaker的源代码里还有关于ic2的部分，并且我测试了一下，你确实可以用
mods.ic2.Macerator.addRecipe(<output>,<input>);  
来添加新的配方
但是你并不能修改原有的配方，也不能移除（也许可以覆盖？我没试），
并并且，即使你添加了新配方，jei也是不会显示的（也许再加几条jei的代码就能显示了？我没研究过）

不过，既然ic2本身都支持修改配方了，何不一用呢？
我试了一下，很方便也很简单的，简直比照猫画虎还简单

你需要做的，是用压缩软件打开你的industrialcraft-?-?-???-ex???.jar这个mod文件，打开assets/ic2/config,
把macerator.ini解压出来，然后在你的游戏配置文件夹（config）里新建一个ic2文件夹，把macerator.ini丢进去，然后修改这个macerator.ini就好啦！

具体怎么改呢？建议用notepad++打开不然很乱很乱都没有换行的，往下翻你会看到所有ic2内置的配方都在这里，你就照着这个格式添加新的，或者直接修改原来的配方，然后保存就好啦！非常简单啊真的！我没有骗你的！

复制一段过来让你看看
可以看到左边是输入物，右边是输出，输入物支持矿典，有数据值/损伤值/metadata的就用@表示
比如minecraft:stone@2   
有数量的，直接在最后加个*3    *8这样的就好了
至于id的话，，，，游戏内开了F3+H来看吧

; Lead Ingot
OreDict:ingotLead = ic2:dust#lead
; Copper Ingot
OreDict:ingotCopper = ic2:dust#copper
; Tin Ore
OreDict:oreTin = ic2:crushed#tin*2
; OreDict:ingotRefinedIron
OreDict:ingotSteel = ic2:dust#iron
; Bio Chaff
ic2:crafting#bio_chaff = minecraft:dirt
; Oak Leaves
OreDict:treeLeaves*8 = ic2:crafting#bio_chaff
; Coal
minecraft:stick = ic2:dust#coal
; Stone
minecraft:stone = minecraft:cobblestone
