为什么一点开就闪退

右键新建文本文档，重命名为XXX.bat，那个XXX可以改成别的名字
确认你的服务端核心的名字（这里假设叫核心名.jar）（不推荐核心名出现中文、俄文、日文等字符，最好是英文/数字）
右键刚刚新建的XXX.bat --> 编辑 --> 然后你就用记事本打开了
  1. java -jar 核心名.jar
复制代码

如果你要配置使用内存1GB-4GB的话可以这么写
  1. java -Xms1G -Xmx4G -jar 核心名.jar
复制代码

加上一个全版本通用的JVM优化参数可以这么写
  1. java -Xms1G -Xmx4G -Xss512K -XX:+AlwaysPreTouch -XX:+AggressiveOpts -jar 核心名.jar
复制代码


第一次打开之后闪退很正常，你需要同意Eula协议

服务端根目录下文件eula.txt里的eula=false改为eula=true

然后就可以正常启动了

新建一个文本.txt
打开复制粘贴进去把服务端核心ID改成你服务端核心的名字
调内存然后保存关闭并且把文本.txt 后缀名改成 .bat
@echo off
@set a=0
:Menu
color 0f
title XXX服务器正在运行... 重启次数[%a%]
@echo==================================
@echo== XXX服务端                =
@echo== 服务端版本: XXX                =
@echo==================================
java -Xms1G -Xmx1G -jar 服务端核心ID.jar
@echo 服务器已经关闭将会在10秒后自动重启...
@ping -n 10 0.0.0.1>nul
@set /a a=%a%+1
@goto Menu
pause
