0. 如何安装MOD0.1 首先安装Forge
想要装MOD，必须先让自己的电脑支持安装MOD，目前大多MOD支持Forge安装器，所以欲装MOD，先装Forge。
首先，请各位至少运行过一次你要安装MOD的那个版本的游戏，比如要安装152就必须先选择152，运行一次才行，如果要安装的是164的MOD，要运行过一次164才可以。
然后从
http://files.minecraftforge.net/（162以上）
http://files.minecraftforge.net/minecraftforge/index_legacy.html（1.6.2以下版本）
网站中找到符合自己版本的forge注意forge对应的版本和安装包，选择推荐版为名字前缀为Recommand版本，点击右边圈中的Installer来下载安装包，将安装包打开
                              
打开方式：
1.   有些Java可以自动识别，直接打开即可，不是下图就看打开方式2
2.    如果无法自动识别，可以右键，打开方式，选择默认程序
在跳出的窗口中选择浏览，找到JAVA安装路径，一般是C:\Program Files\Java\jre7\bin文件夹中的javaw
Forge会直接默认你的正版路径，点确定即可~
3.都无法打开，可以使用第三种方式，创建一个新建文本文档
然后输入
java -jar minecraftforgeinstaller.jar
注意，红色字体部分必须修改为forge的文件名！
然后讲文本文档的名字改为新建文本文档.bat
双击运行即可。
注意，一定要是这个窗口才是正确打开方式！
Forge安装好以后还没好哟，打开登录器，登录后选择Edit Profile，选择相应的forge版本，然后点saveprofile
最后点Play，运行一下，游戏，forge就安装好拉~~
0.2 安装MOD
下载MOD方面建议大家去两个网站
http://www.mcbbs.net/forum-mod-1.html
http://www.minecraftforum.net/forum/51-minecraft-mods/
前者是国内网站，看不懂英文可以去第一个网站里下载MOD，后者是国外网站，目前国内还没有很强力的MOD建设组，一般都是从国外搬运的，所以建议英语水平不错的童鞋去第二个网站里下载MOD。
但是MOD下载下来放到哪里去呢？
首先运行至少一次forge版本的游戏，然后打开MC正版的地方（如果不知道怎么打开就点这个链接：3.5正版文件装在哪里？）打开.minecraft文件夹后，你会看到多了一个mods文件夹
打开mods文件夹，然后愉快地把你下载好的MOD放进去吧~MOD也是有对应版本的，所以下载的时候要注意咯，不要用162的版本使用152的MOD了，升级版本之后也记得把原来的MOD备份一下，如果无法打开游戏，就表明是多个MOD互相冲突或者是有MOD不符合版本，试着删除几个MOD再开
