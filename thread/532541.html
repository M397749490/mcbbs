那我就说说我的看法吧，首先要装灵活动作，Render Player API 和Player API两个都是必要的前置
它们的说明只是关于安装方法的。
1.6.1以前安装Render Player API和Player API不能采用直接拖入mod文件夹的方法，目测是要采用拖入coremod文件夹的方法（只是猜想），但1.7.2之后加入coremod这种形式已经消失，所有mod都只需加入mod文件夹就可以了。
所以没必要顾虑那么多，把Render Player API 和Player API两个对应1.7.10的版本拖到mod文件夹下就可以了。
