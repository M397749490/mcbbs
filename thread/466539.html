先创建一个名字为 （方块英文名）_lantern.png   大小为32x？的文件（？=32的任何一个倍数）
然后再用几个不同的32x32的图像填满它。
就像原版动态材质那样。

最后，在创建名字为（方块英文名）_lantern.png.mcmeta  的记事本文件，里面写上：
{
    "animation": {
        "frametime": 5
    }
}


就ok了。
