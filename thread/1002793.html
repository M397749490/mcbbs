原理：
首先，探测到玩家使用特定标签的胡萝卜钓竿后，利用局部坐标在玩家面前生成一个火球
然后将该火球的坐标分别与玩家的坐标相减，利用高中数学知识很容易知道，相减之后的x，y，z组成的向量的方向即为玩家面对的方向
代码：
  1. execute positioned ~ ~0.15 ~ run summon fireball ^ ^ ^1 {Tags:["fireball","fireball_1"],ExplosionPower:4,direction:[0.0,0.0,0.0]}


  4. execute store result score @s x0 run data get entity @s Pos[0] 4000000
  5. execute store result score @s y0 run data get entity @s Pos[1] 4000000
  6. execute store result score @s z0 run data get entity @s Pos[2] 4000000

  8. execute store result score @s x run data get entity @e[limit=1,sort=nearest,tag=fireball] Pos[0] 4000000
  9. execute store result score @s y run data get entity @e[limit=1,sort=nearest,tag=fireball] Pos[1] 4000000
  10. execute store result score @s z run data get entity @e[limit=1,sort=nearest,tag=fireball] Pos[2] 4000000


  13. scoreboard players operation @s x -= @s x0
  14. scoreboard players operation @s y -= @s y0
  15. scoreboard players operation @s z -= @s z0

  17. execute store result entity @e[limit=1,sort=nearest,tag=fireball] direction[0] double 0.000001 run scoreboard players get @s x
  18. execute store result entity @e[limit=1,sort=nearest,tag=fireball] direction[1] double 0.000001 run scoreboard players get @s y
  19. execute store result entity @e[limit=1,sort=nearest,tag=fireball] direction[2] double 0.000001 run scoreboard players get @s z

  21. tag @e[limit=1,sort=nearest,tag=fireball] remove fireball
