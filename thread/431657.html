PerWorldMotds

不同的世界不同的提示公告



这是一个轻量级的插件，它能给你带来

一个玩家进入不同世界的公告，并且有player和world的变量。作者还添加了加入声音！

所有的玩家都能知道某个玩家进出了某个世界。

而且这个插件兼容所有的公告插件。不会和其他公告插件冲突。提示的内容可以在配置文件中修改。


Config说明

##PerWorldMOTD v1.4 by CGA1123#
#ConfigurationFile#
#FORMAT:
# motds:
#  WORLDNAME:     #世界的名字
#    motd: "MESSAGE"   #进服的提示信息
#    sound: "SOUNDNAME"     #提示声音
#    joinmsg: "MESSAGE"     加入信息
#    leavemsg: "MESSAGE"离开信息#  WORLDNAME2:    #其他的世界
#    motd: "MESSAGE2"
#    joinmsg: "MESSAGE"
#    leavemsg: "MESSAGE"  同上
##usecustomjoinleave: true    #是否开启进出世界的提示
###你可以在这里找到所有的声音代码  http://jd.bukkit.org/rb/apidocs/org/bukkit/Sound.html  
#你可以使用'&'颜色代码  
#你也可以使用'\nl'跳转下一行
#当然也可以使用 '%Player' 获取玩家名字的变量  "
motds:
  world:
    motd: "&f嘿, &3%Player&r 欢迎来到基♂佬的 &6主世界&f."
    sound: "SPLASH"
    joinmsg: "&a%Player &r欢快的射进了主世界"                leavemsg: "&a%Player &r 赛高了！蹦出了主世界！"
  creative:
   motd: "&f嘿！, &3%Player&r, 你来到了 &1C&2r&3e&4a&5t&6i&7v&8e&f."
