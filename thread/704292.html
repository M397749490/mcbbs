Deathmoney

竹萌技术团队出品——Huangwang


                                                         一个十分轻量的玩家死亡掉钱插件，插件灵感来源于Scavanger插件


更新：

V0.4.7(2019-05-28)
  • 常规升级

V0.4(2018-10-21)
  • 升级至1.13可用

V0.3.3(2018-06-16)
  • 修复了开启死亡经验不掉落，可通过掉落经验球刷经验的bug

V0.3(2018-03-05):
  • 增加reload指令，/deathmoney reload 更新配置
  • 增加死亡消失诅咒开关，打开死亡时背包中拥有该附魔的物品会消失
  • 增加经验不掉落开关
  • 增加插件开关

V0.2(2017-08-21):
  • 添加了死亡掉落开关
  • 添加了自定义货币名称功能

功能：
  • 自定义掉落开启世界
  • 自定义掉落金钱百分比
  • 自定义最大／最小金钱掉落值
  • 自定义掉落消息

依赖：
  • Vault


源码：
  • https://github.com/ImyvmCircle/Deathmoney

配置文件：
  1. # 启用该插件
  2. Enabled: true
  3. # 最小掉落钱数
  4. minloss: 30.0
  5. # 最大掉落钱数
  6. maxloss: 10000.0
  7. # 掉落百分比, 总掉落数= {player'balance}*{percent}/100+{minloss}
  8. losspercent: 8.0
  9. chargemessage: 'You Charged '
  10. Curname: ' dollars'
  11. disablemessage: Keepinventory is disabled in this world
  12. nomoneymessage: You can't afford it
  13. # 启用的地图
  14. EnabledWorld:
  15. - world
  16. - fun
  17. # 掉钱时是否开启死亡不掉落
  18. KeepInventory: true
  19. # 掉钱时是否开启经验不掉落
  20. KeepExp: false
  21. # 掉钱时消失诅咒是否消失
  22. ANISHING_CURSE: true
复制代码
