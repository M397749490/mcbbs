步骤一：添加源仓库  
选择一：使用官方源
打开pom.xml ，在 <repositories> ... </repositories> 代码块中加入：

  2. <repository>
  3.     <id>papermc</id>
  4.     <url>https://papermc.io/repo/repository/maven-public/</url>
  5. </repository>

复制代码

选择二：使用Lss233's.OSS();
本人搭建的Lss233's.OSS();也镜像了PaperSpigot的官方源镜像，针对国内开发者有下载速度提升。
详情链接：http://www.mcbbs.net/thread-800729-1-1.html
代码：

  2. <repository>
  3.   <id> lss233-minecraft </id>
  4.   <name> Lss233's Minecraft Repository </name>
  5.   <url>http://crystal.lss233.com.aslf.top/repositories/minecraft</url>
  6. </repository>

复制代码


步骤二：添加依赖
在 <dependencies> ... </dependencies> 代码块中加入：

  2. <dependency>
  3.     <groupId>com.destroystokyo.paper</groupId>
  4.     <artifactId>paper-api</artifactId>
  5.     <version>1.13.2-R0.1-SNAPSHOT</version>
  6.     <scope>provided</scope>
  7. </dependency>
复制代码


把代码中的1.13.2-R0.1-SNAPSHOT换成你想要的版本即可。
