特性:
推荐给以下服务器使用：
→ 生存
→ 真实生存
→ 派系
→ RPG


→ Tracking - 追踪功能，可以指定一个玩家或坐标
→ Support JSON - 支持全部类型的 JSON 显示
→ Full Configuration - 完全可配置的文件
→ Full Sound - 每个动作都有声音可配置
→ Full Effect - 全效果显示
→ Full Tab Completer - 支持tab指令补全

需求:
前置插件 AgarthaLib
java 8
Bukkit,Spigot,和Paperspigot服务端 1.8-1.12


指令/权限：

/ LiveCompass help [<page>] - 显示全部命令
/ LiveCompass about - 显示插件的版本信息
/ LiveCompass reload - 重置配置
/ LiveCompass track player <player|location|stand> - 追踪玩家位置
/ LiveCompass track location <x> <y> <z> - 指定的坐标位置
/ LiveCompass track stand - 您当前位置的追踪点
/ LiveCompass toggle on/off - 打开/关闭指南

- "livecompass.admin"
- "livecompass.command.reload"
- "livecompass.command.track.player"
- "livecompass.command.track.location"
- "livecompass.command.track.stand"
