{VarLight}
对服务器特定方块的亮度进行设置
手持萤石粉右键方块使其亮度+1
手持萤石粉左键方块使其亮度-1
(也就是说 你可以让玩家也能玩到这个机制)
(当然你也可以通过下掉玩家权限 来达到只有做服务器的时候用)

开源地址 https://github.com/flori-schwa/VarLight

指令&帮助

  • /varlight save: 保存你所在世界的所有光源
  • /varlight save <world>: 保存特定世界的所有光源
  • /varlight save all: 保存所有世界的光源
  • /varlight autosave <interval>: 设置自动保存间隔
  • ————————————————————————————————
  • /varlight getperm: 查看权限节点
  • /varlight setperm <perm>: 设置权限节点
  • /varlight unsetperm: 取消权限节点
  • ————————————————————————————————
  • /varlight whitelist add <world>: [需重启服务器]将某一世界加入白名单(可以对方块亮度进行修改)
  • /varlight whitelist remove <world>: [需重启服务器]将某一世界移出白名单
  • /varlight whitelist list: 列出所有在白名单内的世界
  • ————————————————————————————————
  • /varlight blacklist add <world>: [需重启服务器]将指定的世界加入黑名单
  • /varlight blacklist remove <world>: [需重启服务器]将某一世界移出黑名单
  • /varlight blacklist list: 显示所有在黑名单里的世界
输入 /varlight book 打开一本便捷设置书(类似于gui)


*权限节点
varlight.admin - 允许使用管理命令(保存，设置权限)
varlight.admin.save - 允许使用保存命令
varlight.admin.perm - 允许使用权限相关的命令
varlight.admin.world - 允许使用/ varlight whitelist/blacklist 指令

注: 插件旧版支持1.7-1.14，新版仅支持1.14-1.15，故本帖不便更新
