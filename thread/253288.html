嘛=w=过了机械三王下一步就是丛林了，丛林在这个时期是很恐怖的QAQ！
首先其中有三个变态的新怪QAQ，一个叫巨大乌龟，一个叫常春藤峰，还有一个叫巨骨蛇鱼(后期没威胁）
巨大乌龟就算是后期也是要见到保持距离的怪,不知道从哪里突然出现砸你，攻防超高QAQ
常春藤其实一个不恐怖，就怕成群= =，真-弹幕射击
巨骨蛇鱼一开始下水经常被这东西群殴，后期随便砍死就可以了
本教程不讨论BUG打法= =！


为什么要下丛林？

1：因为丛林是后期必走的一步，其中一个Boss相当与肉山一样重要

是虐与被虐的分水岭

2:丛林有叶绿矿，神圣镐可以挖掉，没有叶绿矿虽然说不影响后来的进程= =

但是如果你要强力装备的话必须要挖叶绿矿，后期几乎所有装备都需要叶绿锭

比如蘑菇套，乌龟套，甲虫套，幽灵套

3:丛林有神庙

丛林有那三个Boss？

1：蜂后

2：世纪之花

3：魔像傀儡

简单介绍丛林

打完机械三王，身穿神圣装，手握神圣镐，如果你觉得你现在很厉害
那么你错了，神圣装在以前可能是名震天下最厉害的套装
但现在来说，只相当与过渡用的暂时装备= =
所以拿出镐子去丛林地下挖矿吧！
叶绿矿，这种矿物其实是生长的，它会在淤泥中蔓延，所以打完机械三王不要着急去挖矿
因为这时的叶绿矿可能才一两个的分布，很少的
等以后蔓延开了再去挖



介绍丛林三Boss

比起机械三王这些Boss会掉落更多不同的掉落物，而且几率不一，所以有理由反复去挑战他们

蜂后

这只Boss其实肉山前就可以打了= =
其难度和骷髅王差不多吧= =反正我觉得和克鲁苏之眼一样容易打



攻击方式：在你那个高度左右冲刺，停在你上面释放很多小蜜蜂辅助攻击，在你上面到处摇晃发射毒刺
攻击力：30
血量：3400
防御：8

鉴于这Boss一般都是后期打的，前期打了也没啥意义= =
肉山前打一点用的没有，肉山后杀掉还有个巫师NPC卖的树叶翅膀
所以一般都是肉山后再去找蜜蜂杀
因为都肉山后了，一身熔岩套装都可以抗住它的攻击= =
所以算很简单的Boss了

=====掉落物=====
魔法武器
蜜蜂炮
发射追踪敌人的小蜜蜂，掉落率：33.33%，前期可以当暗炮使，后期没用
近战武器
蜜蜂守护者
砍到敌人的时候释放小蜜蜂辅助攻击，掉落率：33.33%，同上，前期有用后期垃圾
饰品
蜂巢
装备后用近战武器攻击就会释放小蜜蜂辅助攻击，掉落率：33.33%，压箱底的饰品之一
宠物
花蜜，召唤一直小蜜蜂宠物，掉落率：5%，没啥用= =
道具
蜂巢法杖
让你放置蜂巢块，掉落率：33.33%，建筑党这样你就不用到处去挖蜂巢块了= =
时装
蜜蜂全套衣服
每件掉率均为11.11%，收藏用= =
消耗品
蜜蜂手雷
一次掉落10-29个不等，爆炸后释放蜜蜂，掉落率75%，同理，前期炸着玩= =
时装
蜂王面具
掉落率：14.29%，收藏用= =
荣誉勋章
蜂王荣誉勋章
掉落率：10%，收集用= =
血瓶
蜂蜜瓶
一次掉落5-15不等，掉落率：100%，比血瓶好用一点= =


世纪之花

最重要的Boss!!!
必须打完机械三王才能打的Boss！
难度和机械骷髅王差不多，你把他想象成四只手都是激光手的骷髅王即可QAQ！
和眼珠一样有两种形态
第一阶段
攻击方式：发射种子（随着血量减少射速加快）发射孢子球，像玩家扔的针刺球，弹来弹去并照成持续伤害
攻击力：50
无防御
血量：30000

当血掉到一半进入暴走形态
攻击方式：停止远程攻击，并释放很多夹子触手（像肉山的那些触手）追着玩家咬
攻击力：50
防御：14
第一次打完这个Boss会出现一个提示，地牢传来回响
然后你的地牢就升级了QAQ里面各种恐怖了！
注意不要把花引到丛林外面！要不它会暴怒，加攻击加防御=A=

=====掉落物=====
钥匙
神庙钥匙
打开丛林地下的神庙大门，掉落率：100%，很有用的道具！不管是用来开门还是和钥匙模具合成
武器
榴弹发射器
发射火箭弹，第一次击败世纪之花：100%掉落，以后再次击败掉落率为：16.67%
获得这把武器，NPC人造人就会入住，会出售火箭弹这些的东西
宠物
苗
召唤一个树苗宠物，掉率：5%，同所有宠物一样= =没用的收藏品
工具
电音吉他
可以当斧头和锤子用，最厉害的斧锤，掉落率：0.5%，终极工具之一
召唤杖
矮人召唤杖
召唤一个矮人出来帮你打怪= =，掉落率：25%，无聊的时候叫个矮人出来帮做输出也不错
弹药
一号火箭弹
榴弹发射器的弹药，一次掉落20-49，掉落率：当掉落榴弹发射器的时候才会掉落：100%
等人造人NPC来了就可以买二号三号火箭弹了，这些都不会破坏地形
四号火箭弹就是作死，炸地图用的= =
武器
金星马格南
不要吐槽名字了= =就是这样我也不知道为什么，掉落率：16.67%
理论上比大鲨鱼厉害，但是它不能连发= =所以要狂点鼠标，不推荐= =
魔法武器
突击法杖
邪恶荆棘的升级版，更长更高伤，穿墙攻击，掉落率：16.67%
嘛= =戴在身上必要的时候躲在墙里虐怪也好
魔法武器
飞叶枪
发射速度很快的树叶，掉落率：16.67%，也没啥用= =肉山掉的激光枪都这个好用
流星锤
锦绣链锤
丢出去还会像敌人发射致命花瓣，掉落率：16.67%
魔法武器
黄蜂枪
蜜蜂枪的升级版，发射跟踪敌人的黄蜂，掉落率：16.67%
到处射着玩的=w=
时装
世纪之花面具
戴着玩的，掉落率：14.29
荣誉勋章
世纪之花荣誉勋章，掉落率：10%，收集品= =
魔像傀儡
神庙中的Boss，因为主体不会穿墙，被各种玩家各种虐= =
而且还可以定点召唤= =
所以还有人做专门虐魔像的机器= =

一样有两种形态
第一阶段是头上戴着石像头

攻击方式：发射火流星（会反弹，不能穿墙）
发射拳头（可以穿墙，但是如果拳头中途被攻击就会缩回）
石像头血量：16000，防御：20，攻击：64
傀儡有两个拳头
单独记血，不杀死不影响Boss击杀
当拳头被打爆石像变不能发射拳头攻击了
每个拳头血量：7000，攻击59，防御：28
当石像头血掉了一半便会开始射激光，石像头血越少攻击速度越快
第二形态

石像头会脱离主体并变成浮游炮进行攻击，这时到处飞的石像头是无敌的
不能被击杀，傀儡身体将继续用拳头攻击（如果他拳头没被你打爆的话）
傀儡身体有9000血，攻击：72，防御26
当扣到一半的时候（4500）到处飞的石像头就会开始发射激光，速度巨快
傀儡血扣的越多激光射的越快
注意这个Boss必须要在打败世纪之花的世界才能打！
所以不能拿着神庙钥匙新开个世界找神庙打这个Boss！
不能穿墙攻击所以你只需要卡好位注意血量就好了，如果你之前打出了血地钥匙模具
去地牢拿上吸血飞刀= =你可以站着不动虐杀这个Boss，前提是防御要高！
