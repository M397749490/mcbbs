竟然这么无语...hoverEvent不限长度，而clickEvent却有限制...
原因是当玩家触发clickEvent时，clickEvent上面的命令会(转)到玩家聊天栏发送，
而聊天栏有字数限制...所以clickEvent上的指令就被阉割了，之后框框括号不对等，导致无法正常运行。

反正你也几乎是全局增伤了，动物又没有那么多血给你打，顺便把锋利级别调高了...

好处，单条指令保证能在服内使用
缺点，武器tag被阉了(火焰，亡灵，节支)。

作者: hqqaazz    时间: 2016-4-7 18:50
所谓的执行指令其实就是在聊天栏发送指令，而聊天栏发送信息是有字数限制的，一条不完整的指令当然会报错。

解决办法就是把执行的指令改成setblock红石块，在相应的地方设置好指令方块就行了。
作者: 作案哥    时间: 2016-4-7 19:26
原因是run_command的value项过长导致
解决方法如下：
tellraw @a {"text":"点我","hoverEvent":{"action":"show_item","value":"{id:diamond_sword,tag:{
ench:[{id:16,lvl:5},{id:70,lvl:1},{id:21,lvl:3},{id:20,lvl:2},{id:19,lvl:2},{id:17,lvl:5},{id:18,lvl:5}]}}"},"clickEvent":{"action":"run_command","value":"/setblock 0 64 0 redstone_block 0 replace"}}
然后在0,63,0位置放置一个命令方块，里面输入: give @p diamond_sword 1 0 {ench:[{id:16,lvl:5},{id:70,lvl:1},{id:21,lvl:3},{id:20,lvl:2},{id:19,lvl:2},{id:17,lvl:5},{id:18,lvl:5}]}
具体就看楼主自己情况了，比如具体给玩家钻石剑的这个命令方块要放在比较靠近玩家的地方，则/setblock里的坐标也要相应改变

我是问setblock放了命令方块后，我不知道怎么在用命令放置红石块。。。

/setblock x y z redstone_block 0 replace
xyz坐标设在命令方块相邻的地方

可以这样，clickevent里用setblock放置一个红石块在一个地方，激活两个命令方块，一个执行给玩家钻石剑那个命令，另一个可以执行其他的，比如setblock把红石替换成空气之类的
