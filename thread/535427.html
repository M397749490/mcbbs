材质包是否符合规范？材质包的pack.mcmeta文件是否存在？
作者: lrf8643    时间: 2015-12-29 13:50
  • 看一看材质包的models文件夹里有没有写json代码时打草稿用的txt文件，如有则删除并重新压缩。否则无法被加载*。
  • 看一看材质包的models文件夹里的json格式是否规范，如不规范则修改并重新压缩。否则黑紫。
  • 如果models文件夹里的json未按照【版本.jar】里models文件夹里的json命名，那么新建blockstates文件夹被修改的方块必须按照【版本.jar】blockstates文件夹里的命名来命名json。否则无用。
    例子：我要修改石头（stone）的材质。我把石头的model命名为abc.json。那么blockstates文件夹里的stone.json的model必须写成abc。
    1. {
    2.     "variants": {
    3.         "normal": [
    4.             { "model": "abc" },
    5.         ]
    6.     }
    7. }
    复制代码

  • 材质包可以没有assets和pack.png，但pack.mcmeta必须有。否则无法被读取*。
  • 如果需要六面贴图不同的，可以参考：http://www.mcbbs.net/thread-535354-1-1.html
我目前能想到就这些了。希望对你有帮助吧。


注释1：无法被加载：MC可以读取，点击完成之后材质包还是回到【可用的资源包】那一栏。
注释2：无法被读取：MC无法读取，材质包不会出现在【可用的资源包】那一栏。
