生成随机数也可以不用这么玄学
#init首次加载
  1. /scoreboard objectives add random dummy
  2. /scoreboard objectives add getRandom dummy
  3. /scoreboard objectives add MAX_RANDOM dummy
  4. /summon armor_stand 1 1 1 {NoGravity:1b,Invisible:1b,Tags:["random"],Invulnerable:1b,Marker:1b}
  5. /scoreboard players set @e[tag=random] MAX_RANDOM 100
复制代码


#rcb高频循环
  1. /scoreboard players add @e[tag=random,limit=1] random 1
复制代码


#获取随机数
  1. /scoreboard players operation @e[tag=random] getRandom = @e[tag=random] random
  2. /scoreboard players operation @e[tag=random] getRandom %= @e[tag=random] MAX_RANDOM
复制代码


使用方法：第一段加载一次就够了，MAX_RANDOM的值是最大范围+1，示例中为100，则随机数范围为0~99
第二段函数高频循环（每tick增加random的值）
第三段用于获取随机数，保存在@e[tag=random]的getRandom计分板里

优点：简单省事，适用于随机数范围较小且触发时点随机的例子
缺点：不是很严谨，当触发间隔时间相同时可能得到的值就不“随机”了

如果获取随机数的时间点是随机的话（比如玩家点一下按钮获得一个随机数），那么此方法非常适用
