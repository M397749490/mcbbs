注意事项 （新人必看！）


1.mod版本请匹配，否则可能会有什么意料之外的结果。

2. 如果你不清楚 server.properties  里设置代表什么意思，修改后会有什么影响，不要乱改动。

    关于 server.properties 经常会碰到的选项，这里捎带提一点 （true 为开启， false为关闭）
  1. evel-seed=  输入种子码后，首次启动服务端会生成该种子地图
  2. white-list=false 白名单
  3. hardcore=false 极限模式，死后被T出服务器并ban掉
  4. pvp=true PVP模式
  5. difficulty=1 难度，数字可填0~3，分别代表和平/简单/中等/困难
  6. max-players=20 最大玩家数
  7. spawn-protection=16 出生点保护范围
  8. motd=A Minecraft Server 服务器介绍，中文需要转码
复制代码
3. 服务端路径不要包含中文，可能会造成服务端无法启动。
4. 关闭服务器时，要在控制台（开服的黑框里）输入stop指令来关闭，直接X掉99%地图会回档！
5. 如遇以下状况不能开服，请安装Visual C++ 2008 redistributable 先， 或在%ProgramFiles%\Java\jre7\bin\java.exe" -Xincgc -Xmx1G -jar "%BINDIR%\mcpc-plus-1.5.2-R1.1-forge738-B653.jar -nojline 添加红字部分试试。6.请将server.properties删掉再尝试一下。
