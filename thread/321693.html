现代电视 GUI

2019-8-6 16:42 上传
鉴于有许多人不知道电视的使用方法，我就稍微研究了一下。
* Channel #1,2,3 频道，可以轮流显示三张 GIF 图
（此处请填写 GIF 链接，且 GIF 大小需小于 2MB，GIF 无效的建议换专门存放 GIF 的网站再试试）
* Stretch to Screen 的意思是 GIF 延伸到全屏幕
（即原本 GIF 不足以填充满屏幕，开启后强行将其拉伸以填满黑边）
* Powered 为当前电视的开关状态

在电视填好 GIF 之后，
* 手持电视遥控器潜行（Shift）右击电视为开关电视
* 在电视开启的情况下，手持电视遥控器右击电视为切换频道

>> 语言文件
由于强迫症，我对简中文本进行了些许修正以符合 Minecraft 原版规范。
  • 又又又完善了某些名词。（2020/04/18）
  • 给 GitHub 发语言文件 PR 了，或许未来某一天 Mod 自带简中（2020/08/01）
  • MC 1.16.3 - v7.0.0-pre19 自带语言文件啦（2020/10/14）

* 修正语言文件食用方法
想使用修正语言文件，用压缩软件（如 7z, Bandizip）打开 jar 文件，找到 assets/cfm/lang 文件夹，用相应文件进行替换。

主流版本的语言文件名：
  • Minecraft 1.15.2+ 为 zh_cn.json
  • Minecraft 1.12.2 为 zh_cn.lang
  • Minecraft 1.7.10 为 zh_CN.lang

* 关于测试版本
1.14.x/1.15.x/1.16.x 测试版本出现了，由于正在重写 Mod，所以测试版本 Mod 内容可能会很少。

CurseForge 界面里找到并进入 Files，再然后找到并点击“View All”就能看到所有版本了。

* 关于 Minecraft 1.7.10 v3.4.8 的说明
CurseForge 上用于 Minecraft 1.7.10 的 Mod 最新版本为 v3.4.7，而 v3.4.8 当时是在作者网站下载的，如今已经找不到了。
