全部插件搜mcbbs的搜索内容即可
* 基础插件送 Essentials
* 多世界 建议 multiverse
* 星门 stargate
* 指令木牌 server sign
* 闹钟 - 菜单 是 chest command
* 地皮是 plotme
* 点卷系统是 playerpoints 【可以配合boss商店插件】
* 权限需要权限组插件 建议 groupmanager
* 权限需要加入相应的权限组即可
* pvp设定可以使用 多世界来禁止 /mv modify set pvp false 世界名称
* 工会插件 推荐 guilds
* 教程每一个搬运贴内基本都有介绍
* 然后就不加QQ了 40金怜太少了
