指令及权限列表
/ acid：管理员命令
/ acid version：显示BentoBox本质组件的版本
/ acid tp <player>：传送到玩家的岛屿
/ acid tpnether <player>：传送到玩家的岛屿
/ acid tpend <玩家>：传送到玩家的岛屿
/ acid getrank <玩家>：获取玩家在他们的岛屿上的头衔
/ acid setrank <玩家> <排名>：设置玩家在他们岛屿上的头衔
/ acid info <玩家>：获得您当前所在或指定玩家的岛屿信息
/ acid add <所有者> <玩家>：将玩家添加到队长的队伍中
/ acid kick <团队球员>：从全体中踢走玩家
/ acid disband <所有者>：解散队长的队伍
/ acid setowner <玩家>：将岛屿转交给玩家
/ acid unregistere<所有者>：剥夺岛主的所有权，但保留岛屿方块
/ acid ：管理员岛范围命令
/ acid resets：修改玩家的重置次数
/ acid delete <玩家>：删除玩家的岛屿
/ acid why<player>：切换控制台保护调试报告
/ acid deaths：编辑玩家的死亡次数
/ acid reload：重载本插件
/ acid resetflags [flag]：将所有岛屿重设至config.yml中的预设标志设置
/ acid trash [玩家]：显示回收站中的无主岛屿或玩家岛屿
/ acid emptytrash [玩家]：清除玩家在回收站中的岛屿，或清除回收站中的无主岛屿
/ acid switchto <玩家> <数字>：将玩家的岛屿切换至回收中的某一个
/ acid level <玩家>：计算某玩家的岛屿等级
/ acid top：显示前十名

安装教程
AcidIsland是Bentobox的附属插件，如果您需要使用AcidIsland，您需要首先安装Bentobox并在\ plugins \ BentoBox \ addons加入本插件
安装推荐您一键安装所有适用的Bentobox插件
例如：等级，任务，菜单等
Bentobox官方海岛打包下载
1.将Bentobox加入插件文件夹中，重新加载服务器
2.打开Bentobox文件夹中的config.yml，查找默认语言并更改为zh-CN
3.将AcidIsland加入plugins \ BentoBox \ addons文件夹中，重启
4.生成配置文件后使用我提供的配置文件覆盖并进行更改
5.删除位于服务端根目录下的[AcidIsland_world] [AcidIsland_nether] [AcidIsland_the_end]重启
自定义初始牌子教程：打开\ plugins \ BentoBox \ locales \ AcidIsland文件夹：zh-CN.yml文件，修改Line0-Line3
