我想禁止玩家放置信标 想让玩家通过金币[游戏币]购买 如何可以做到 求解
作者: Living98    时间: 2015-8-23 21:02
1.你可以在Essentials文件夹内的配置文件config.yml中找到以下代码（在结尾处）

  2.   # 当以下方块被放置或破坏,或物品被使用时会出现警告
  3.   # 你加载了一次Essentials后,就可以在plugins/Essentials/items.csv中找到物品ID列表.
  4.   # 10 = 动态岩浆 :: 11 = 静态岩浆 :: 46 = TNT :: 327 = 岩浆桶
  5.   alert:
  6.     on-placement: 10,11,46,327
  7.     on-use: 327
  8.     on-break:

  10.   blacklist:

  12.     # 阻止玩家放置以下方块
  13.     placement: 10,11,46,327,138

  15.     # 阻止玩家使用以下物品
  16.     usage: 327

  18.     # 阻止玩家破坏以下方块
  19.     break:

  21.     # 阻止活塞推动以下方块
  22.     piston:

  24.     # 阻止发射器发射以下物品
  25.     dispenser:
复制代码
如上面代码所写在阻止放置以下方块中填入138即可，或者将这条代码复制。

2.你可以使用Essentials自带的权限分配 指令如下
/mangdelp Builder -essentials.build.place.138
可将其复制到输入框进行删除此项权限

作者: lichi2050    时间: 2015-8-24 00:06
放置物品的权限是 essentials.build.place.<物品id>
信标的ID是138

禁止的话加个 - 就行 ：-essentials.build.place.138

然后可以通过chestcomands 或者 bossshop 或者其他可以出售权限的商店卖这个权限。
