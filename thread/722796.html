Authme如何修改指令？
将/login或者/reg之类的改成
.l 或者.reg

作者: jin7568866    时间: 2017-8-19 22:22
用压缩软件打开你的authme登陆插件jar文件（虽然不知道你是哪个版本的 但无所谓）
压缩软件打开后你会看到plugins.yml文件
打开
然后找到
  1.   login:
  2.     description: Login command
  3.     usage: /login <password>
  4.     aliases:
  5.     - l
  6.     - log
复制代码
这边就是login的指令了
如要修改为log
你会看到aliases:下面有- log
意思就是login指令有其他缩略指令/l   /log
【举例】如果你要添加的或者修改 直接在下面那行加一个就行 或者修改
例如你要加一个缩略指令为/lg
那就这样加
  1.   login:
  2.     description: Login command
  3.     usage: /login <password>
  4.     aliases:
  5.     - l
  6.     - log
  7.     - lg
复制代码
register也是一样的
  1.   register:
  2.     description: Register an account
  3.     usage: /register [password] [verifyPassword]
  4.     aliases:
  5.     - reg
复制代码
直接在aliases:下面加或者修改
