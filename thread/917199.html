标题: (bukkit)如何获取范围内最近的玩家？
我使用loc.distance(player.getLocation())的方法判定玩家处于范围内并存入集合中，但集合内的玩家是按照字符串大小来排序的。请问一下该如何像原版命令的@p一样获取距离最近的玩家呢？或者请给我提供一个思路吧。
作者: 粘兽    时间: 2019-10-2 18:10
首先用getNearbyEntities得到范围内的实体
随后new 一个map用来做排序
然后用loc.distance得到两者的距离 为map的key 实体为map的value
最后整一个冒泡排序就完事了

  11.         for (Entity entity : player.getNearbyEntities(range, range, range)){
  12.             if (!(entity instanceof Player)){
  13.                 continue;

  16.             if (d <= range){
