所有命令：            http://www.mcbbs.net/thread-18529-1-1.html
  1. 总命令
  2. /res ? [页数] - 显示帮助，不写页数则显示第一页.
  3. /resadmin - 在使用管理命令时使用


  6. 选择命令
  7. /res select [x] [y] [z] - 选择领地的长方体区域，X Y 和Z 都是从你当前位置为中心的距离，你也可以用一个工具（默认是木斧）来选择地块。
  8. /res select chunk - 选取一整个chunk。
  9. /res select expand [格数] - 向你的前方延伸选区。
  10. /res select size - 显示已选择区域的尺寸。
  11. /res select shift [格数] - 向你的前方移动选区。
  12. /res select vert - 把选区延伸到从天顶到地底。

  14. 创建命令
  15. /res area [add/remove/replace] <领地名> [区域id] - 向叫做[领地名]的领地增加(add)、从其中去除(remove)或是替换 (replace) 区域。可与同一领地内的区域重合。
  16. /res create [领地名] - 选择好区域后创建一个叫做[领地名]的领地
  17. /res remove [领地名] - 移除一个叫[领地名]的领地
  18. /res removeall - 移除所有领地
  19. /res subzone <领地名> [子区域名] - 在领地内创建一块子区域，你必须是所有者才行。

  21. 信息命令
  22. /res area list [领地名] - 列出某领地的所有区域
  23. /res area listall [领地名] - 列出某领地的所有区域以及他们的坐标
  24. /res current - 显示你所在的领地
  25. /res info <领地名> - 得到某领地的信息
  26. /res list - 显示你拥有的领地
  27. /res listall - 显示所有领地
  28. /res limits - 显示重要的权限
  29. /res sublist - 显示你所在领地的所有子区域
  30. /res version - 显示插件版本

  32. 权限命令
  33. /res gset <领地名> [群组名] [权限] [true/false/remove] - 设置某领地对于某群组的权限
  34. /res lset <领地名> [黑名单/忽略名单] [材质] - 从某领地的黑名单/忽略名单中增加/移除某材质
  35. /res lset <领地名> info - 显示某领地的黑名单/忽略名单设置
  36. /res pset <领地名> [玩家名] [权限] [true/false/remove] - 设置某领地对于某玩家的权限
  37. /res set <领地名> [权限] [true/false/remove] - 设置某领地的权限



  41. 其他命令
  42. /res default [领地名] - 重置某领地的权限设置
  43. /res give [领地名] [玩家名] - 将某领地赠与某玩家，你必须是领主且被赠予玩家在线
  44. /res lists - 预定领地许可清单的详细信息
  45. /res message [领地名] [enter/leave] [信息] - 设置进入/退出某领地时候显示的信息
  46. /res message [领地名] remove [enter/leave] - 移除进入/退出某领地时候的信息
  47. /res mirror [源领地名] [目标领地名] - 复制源领地的权限设置至目标领地
  48. /res rename - [旧名称] [新名称] 重命名领地.对于子空间旧名称必须全名，新名称可以只写子空间名
  49. /res renamearea [领地名] [旧名称] [新名称] - 重命名某领地中某区域的名称
  50. /res tp [领地名] - 传送至某领地
  51. /res tpset - 设置当前领地的传送点为你站立的地方
  52. /res unstuck - 将你从当前领地移出


  55. 交易命令
  56. /res lease [renew/cost] [领地名] - 更新/显示 更新一个领地的费用（？意义不明）
  57. /res market list - 显示在售的所有领地
  58. /res market info [领地名] - 显示在售的某领地的信息
  59. /res market sell [领地名] [价格] - 将某领地出售
  60. /res market unsell [领地名] - 将某领地下架
  61. /res market buy [领地名] 购买某领地
  62. /res market rentable [领地名] [价格] [天数] <repeat:t/f> - 将某领地以[价格]/[天数]出租并设置可否自动续期
  63. /res market rent [领地名] <repeat:t/f> - 设置某领地出租手否可自动续期
  64. /res market release [领地名] - 解除某领地的出租

  66. 管理命令
  67. /resadmin lease set [领地名] [#天数/infinite] - 设置领地的时间限制或不限时
  68. /resadmin removeall [玩家名] - 移除某玩家的所有领地
  69. /resadmin setowner [领地名] [玩家名] - 将某领地以交给某玩家
  70. /resadmin server [领地名] - 将某领地设置为服务器领地
  71. /resload - 载入领地插件. *注* 在res.yml的任何改变都不会被还原. 你可以再更改过res.yml后想立即将新设置生效的时候使用此命令
  72. /rereload - 重载领地插件. *注* 将会还原res.yml为初始状态. 如果你在res.yml更改过设置请不要使用此命令
