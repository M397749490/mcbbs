LegendQuest RPG



插件特色：

插件最好运行在SG端，插件开发于1.8.7版本的SG端，所有其他端有可能会不兼容

[diamond_sword]含种族 职业 技能
[diamond_sword]初始属性多样化，多达六种
[diamond_sword]初始属性随机分配
[diamond_sword]技能特效
[diamond_sword]种族特殊的能力
[diamond_sword]种族的职业限制
[diamond_sword]职业限制
[diamond_sword]技能购买解锁，经验升级技能
[diamond_sword]其他插件的兼容性
[diamond_sword]魔法值 集中值 冷却 材料消耗 等等
[diamond_sword]角色善恶判定
[diamond_sword]设定简单容易

前置插件：
SQLibrary  下载地址：点我

支持版本：
bukkit-1.8，spigot-1.8.1-1.8.7 当然1.7.9也支持
下载地址：删除（作者更换为收费，不再提供下载）
LegendQuest.zip压缩包包含插件主jar和技能skill各种jar
先把主jar放进服务器插件文件夹，重启，生成目录后，把压缩包内skill文件夹里的jar复制到服务器生成的skill文件夹里


插件结构：

config.yml
服务器设定，如经验，掉落，战斗机制等
lang.yml
语言文件
skills.yml
技能设定
LegendQuest.log
错误报告
legendquest.db
服务器玩家种族 职业 技能 等存档文件，请注意备份
/skills/
技能文件夹，把压缩包内skill文件夹里的jar辅助到这里
/race/
种族文件设置，即使不打算用种族，也不要删除这个文件夹
/classes/
职业设定文件夹,里面有各种插件预设职业



插件指令：


/stats 玩家状态
/stats [playername] 其他玩家状态
/stats full  更多状态信息
/race list (或 /races) 查看可以选择的种族
/race [racename] 选择种族，racename就是种族名字
/classes 或 /class list 查看可以选择的职业(可以使用/classes full 来查看所有职业)
/class [class name] 选择职业
/skill list or /skills 查看可以选择的技能
/skill info <skillname>  技能介绍
/skill buy [skillname] 购买技能
/skill [skillname] 使用技能
/link 绑定技能，手拿物品输入指令即可，绑定后，物品右键施放
/binds 和/link一样
/unlink | unbind 解除绑定
/hp 显示你的血量状况
/karma 显示你的善恶值状况 /karma <playername>  查看其它玩家的善恶值状况
/roll 随机属性点  用法：/roll <player> <str|dex|con|int|wis|chr> <integer|very_easy|easy|average|tough|challenging>  说明：<str|dex|con|int|wis|chr>为属性点，下面会介绍 。<integer|very_easy|easy|average|tough|challenging>为随机分配时获取属性大小程度
/party 组队 用法：/party create <partyname>创建队伍
                          /party join <partyname> 加入队伍
                          /party approve <playername> 批准玩家加入
                         /party tp <playername>或者 /party teleport  <playername>传送队伍玩家到身边

/admin 管理员指令，用法：
                        /admin class <playername> <classname>  强制更改玩家职业
                        /admin race <playername> <racename>   强制更改玩家种族
                        /admin xp <playername> <amount>         强制更改玩家经验值数值
                        /admin karma <playername> <amount>    强制更改玩家善恶值数值
                        /admin level <playername> <level>           强制更改玩家等级
                        /admin reset <playername>                      重置玩家，职业，技能全部变为默认，等级0，经验0，魔法值0，慎用
                        /admin effect <effect> [duration] [radius]   指向地方生成特效，装逼用的，[duration]持续时间，[radius]半径
                       /admin effect <effect> <world> <x> <y> <z> [duration] [radius]   指定世界指定坐标生成特效 <world>世界名字
/flag 设定玩家flag，用法：
                       /flag <key> <value> [playername]

name
种族名字
description
种族简短介绍
longdescription
种族具体介绍
chattag
聊天前缀，不添加则聊天时直接显示种族名字
plural
复数
frequency
种族的稀有程度
size
种族身高尺寸大小，玩家为1.8，调整请已0.5为基础上下调整，如1.3，1.8，2.3，注意：有的技能是有种族大小要求的
perm
选择这个种族需要的权限
default
是否是玩家一开始的默认种族，如是想让玩家选择的种族，请一定用false
groups
种族隶属于个部落
basehealth
基础生命值.
basespeed
基础速度
baseMana
基础魔法值
manaPerSecond
基础魔法恢复速度
statmods
基础属性点：str=力量，dex=敏捷，int=智力，wis=精神，con=体力，chr=魅力。说明：力量影响伤害，敏捷影响被伤害，智力影响魔法值，精神影响魔法恢复速度，体力影响血量，魅力暂时没实装，作者说是影响和NPC交易
allowCrafting
能否使用合成台
allowSmelting
能否使用熔炉
allowBrewing
能否酿造药水
allowEnchanting
能否使用附魔
allowRepairing
能否使用修理
allowTaming
能否驯服动物
disallow[Crafting|Smelting|Brewing|Enchanting|Repairing|Taming]
以上设定为true，为能使用，false为不可使用
allowedWeapons
allowedTools
allowedArmour
dissallowedWeapons
dissallowedTools
dissallowedArmour
特殊设定
skillPoints
种族基础技能点
skillPointsPerLevel
每个等级加多少技能点
skills
技能，更多技能下面会详细介绍
xpAdjustKill
技能杀死怪物获取经验数值
xpAdjustMine
挖矿获取的经验数值
xpAdjustSmelt
熔炉烧制获取的经验值

复制代码
Description
技能描述信息，可以使用/skill 技能名 info 来查看
level
技能多少级解锁，设定0为初始即可用
cost
购买这个技能需要多少技能点，设定为0免费获取
requires
如果设置了，必须拥有设置的技能列表才会解锁
requiresOne
如果设置了，必须拥有设置的技能才会解锁
type
技能类型:包括主动，被动，触发三种，分别为：ACTIVE主动技能，PASSIVE被动技能，TRIGGERED触发技能
manaCost
施放这个技能消耗的魔法值
consumes
施放这个技能需要的材料
consumesqty
施放这个技能需要的材料数量
pay
购买这个技能需要花费多少钱
xp
使用这个技能需要的经验值
karmaCost
使用这个技能消耗多少善恶值
karmaReward
施放这个技能奖励多少善恶值
karmaRequired
使用技能之前需要多少善恶值.，如果善恶值不足，技能施放失败
needPerm
施放技能需要的权限节点
buildup
施放技能为站立不动，移动会打断技能，站立不动多久可以施放技能
delay
技能触发需要多久
duration
技能持续时间
cooldown
冷却时间
perm
技能施放添加给玩家的权限
perms
技能施放添加给玩家的权限节点
command/startcommand
技能所需命令，开始命令
endcommand
技能所需命令，结束命令

如果問的 1.7.10 mod端 是插件、模組並存的 cauldron-1.7.10 伺服器
那可以明確的跟你說，可以使用。
種族、人物屬性、職業、技能(部分)都可正常使用。

但技能的效果設定上，有不少無法正常使用(造成刷訊息)
例如 : SLOW 、 STUNNED 、 DAMAGE_RESISTANCE、INCREASE_DAMAGE 、 WITHER
以上這幾個效果，拿去放在技能的設定上，一使用技能打中怪物，就會造成伺服器刷屏
不是指遊戲內的刷屏，而是伺服端的小黑窗內，會不斷刷訊息，
因不斷的刷訊息，一段時間後，還會造成伺服器開始延遲{:10_493:}
但去除那些會刷屏的效果，還是能設計出不少實用的技能{:10_509:}
