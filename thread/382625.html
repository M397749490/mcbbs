Chat
插件现已更新！添加了玩家的权限和OP指令等功能！

    介绍
       还在为熊孩子刷屏而恼火吗？
         还在为熊孩子说脏话而急躁吗？
         还在为找不到合适的插件而烦恼吗？
         快试试只有5KB的Chat！
    功能
        限制玩家聊天间隔时间
         和(屏)谐(蔽)玩家的聊天内容
         对刷屏和说脏话的玩家自动进行惩罚
         自定义惩罚内容
         自定义警告样式
         自定义处罚惩罚的条件
    权限
         chat.admin   拥有此权限的玩家将不会受到惩罚和限制
    指令
         /chat add <脏话关键字>       添加需要屏蔽的内容
       /chat reload               重载插件
        （所有指令只有OP才可以使用）
    配置

  2. <P><FONT size=1><FONT color=black size=4>interval: 5000                                  #聊天信息发送间隔 单位/毫秒
  3. admin_permission: "chat.admin"     #管理员权限 可以无视重复消息 聊天间隔 和脏话限制
  4. ban_msgs:
  5.   show: true                                     #脏话显示
  6.   replace: "*"                                    #替换脏话的字符 需开启脏话显示
  7.   num: 3                                           #脏话禁止次数
  8.   msgs:
  9.     - "fuck"                                        #此处为脏话列表
  10.   commands:                                    #帐号超过禁止次数执行命令
  11.     - "mute <player> 1h"</FONT></FONT></P>
