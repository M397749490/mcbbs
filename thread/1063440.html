手里拿着npc脚本魔杖对着NPC右键 在弹出来的窗口点击右边的启用按钮 改为是然后点击窗口最上方的加号在新的窗口里输入如下代码
  1. function died(event) {
  2.      event.npc.executeCommand("class exp "+event.source+" 100");
  3. }
复制代码
上面这个代码会让这个NPC在死掉的时候给击杀者 100skillapi的经验

  1. class exp @dp 100
复制代码

上面这个操作会让玩家完成任务后增加 100 点 skillapi的经验
