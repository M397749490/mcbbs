标题: 怎么测定mc的时间

也就是，如何让开玩mc的第三天会发生一些事件，第四天晚上发生什么事件。

作者: ruhuasiyu    时间: 2017-1-18 16:36
创建计分板
  1. scoreboard objectives add timequery dummy
复制代码
放置一个rcb查询当前时间
  1. time query gametime
复制代码
再在北面接一个ccb,并将查询结果存储在你的计分板
  1. stats block ~ ~ ~-1 set QueryResult @p time query
复制代码
然后rcb检测计分板是否达到某个数值(两天=2400秒=48000tick)
  1. scoreboard players test @p timequery 48000
复制代码
后面接ccb执行事件

不过这样会比较卡，不如直接用漏斗时钟电路定个时，
http://www.mcbbs.net/thread-102270-1-1.html
然后再把时间归零
  1. time set 0
复制代码
