标题: 1.13无命令方块实现睡下起床提醒功能
本帖最后由 qaz1-qaz1- 于 2018-8-7 15:33 编辑

引言

本来想做一个盖被子的插件的，毕竟床上没有被子挺可惜的，但是，后来一想，万恶的Mojang取消了数据值。导致要一坨的execute if才能选上正确的颜色，还是算了的说，于是水了一下，做了这个
函数实现
初始化
  1. scoreboard objectives add sleep_is dummy
  2. scoreboard objectives add sleep_change dummy
复制代码
每tick执行
  1. execute as @a run scoreboard players operation @s sleep_change = @s sleep_is
  2. execute as @a if entity @s[nbt={Sleeping:1b}] run scoreboard players set @s sleep_is 1
  3. execute as @a if entity @s[nbt={Sleeping:0b}] run scoreboard players set @s sleep_is 0
  4. execute as @a run scoreboard players operation @s sleep_change -= @s sleep_is
  5. # -1 睡下 1 离开
  6. execute if entity @a[scores={sleep_change=-1}] run tellraw @a [{"selector":"@a[scores={sleep_change=-1}]"},"已经在床上睡觉了"]
  7. execute if entity @a[scores={sleep_change=1}] run tellraw @a [{"selector":"@a[scores={sleep_change=1}]"},"已经醒来了"]
复制代码
思路
创建2个记分板
sleep_is 玩家是否在睡觉
sleep_change 临时记分板，玩家的状态是否改变
先将玩家上一刻的睡觉状态储存在记分板sleep_change中
然后，我通过了Sleeping这个nbt判定玩家是否在睡觉，1为睡了，0为没睡
接下来，做差，将玩家的sleep_change - sleep_is（的数据）,并记录在该玩家的sleep_change上，会有一下几种结果：
sleep_change 前 1 00 1
sleep_is 0 0 1 1
做差后 1
起床		 0
不变		-1
睡下		 0
不变


最后，在将状态改变的玩家打印到屏幕上，就好了
标签
在这里，我给命令贴上了minecraft:tick与minecraft:load这个标签，这样可以不用命令方块，达到自执行的效果。做法相信大家也讲过了。所以就不细说了，注意一定不要将标签的replace改成true，防止乱覆盖引起错误
其他想说的
如果用data提取json中的字符串，那么怎么写回字符串呢？这就很绝望了。
另外。发现了一个bug，minecraft里的床没有#minecraft:beds标签的。
其实还可以在后面加一段睡觉的有。。。
