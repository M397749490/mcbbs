  1. 这些是命令
  2. Release Details
  3. Compatible with Minecraft Beta 1.2
  4. Added fly and no clip commands...
  5. /fly - Allows you to fly
  6. /noclip - Allows you to go through walls
  7. Note: Minecraft Beta V1.2 breaks the repair command.
  8. Please read the readme for detailed information about the mod.
  9. Use /help <COMMANDNAME> to find out information about normal commands. For example - /help grow
  10. Use //help <COMMANDNAME> to find out information about World edit commands. For example - //help fill

  12. ascend - Moves you to the next platform above your position
  13. clear - Clears the console
  14. damage - Turns player damage on/off
  15. defuse [all] - Defuses any TNT nearby which has been hit, drops 1 tnt in its place
  16. descend - Moves you to the next platform below your position
  17. destroy [all] - Destroys the current item
  18. difficulty <LEVEL> - Sets the difficulty to the specified level (0-3)
  19. dropstore - This command transfers everything in your inventory into a chest that it creates next to you.
  20. duplicate [all] - Duplicates and drops the currently selected item stack
  21. explode [SIZE] - Sets off an explosion in your current location.
  22. extinguish|ext [all] - Puts out all nearby fire (or all fire)
  23. falldamage - Turns fall damage on/off
  24. firedamage - Turns fire damage on/off
  25. goto <NAME> - Goto a waypoint
  26. grow [all] - Grows all saplings/wheat on the map.
  27. heal <HEALTH> - Heals a player the specified number of points
  28. health <min|max|infinite> - Sets the health of a player to pre-defined figures
  29. help [COMMAND] - Gives general help when COMMAND isn't specified, gives specific help when COMMAND is specified. Same as /h
  30. home – Teleport to spawn point
  31. instantmine - Turns instant mining on/off
  32. item <ITEMCODE|ITEMNAME> [QUANTITY] – Gives player item, if quantity isn’t specified maximum amount of that item. Same as /give and /i
  33. itemname - Use this command to discover the itemname and ID of your currently selected item.
  34. itemstack <ITEMID> [QUANTITY] - Gives the player the specified quantity of maximum item stacks of the item.
  35. jump - Moves you from where you are to where your mouse is pointing. Note: This command is buggy and may put you in the block you move to.
  36. kill – Kills the current player
  37. killnpc [all] - Kills all living creatures nearby.
  38. listwaypoints - Lists all waypoints. Same as /l
  39. msg <MESSAGE> - This commands adds a message to the console.
  40. music [VOLUME] - Requests a music track to be played, there is a limitation of at MAX 2 tracks per day. Set the volume by specifying VOLUME.
  41. pos – Gives current player position. Same as /p
  42. rem <NAME> - Removes the specified waypoint
  43. removedrops [all] - This command removes item drops from the world.
  44. repair [all] - Repairs the currently selected item to full health
  45. replenish [all] - Re-stocks your items in your inventory to the maximum ammount
  46. return - Moves the player to the last position before teleport
  47. search <SEARCHTERM> - Allows you to search for items using a name
  48. set <NAME> - Mark a waypoint on the world
  49. setjump [JUMP|reset] - Sets the height that you jump. Note: Turns fall damage off if the jump is configured to move than 1.
  50. setspawn [<X> <Y> <Z>] – Set the current position as the spawn point, if X Y Z are specified sets that position as spawn point
  51. setspeed [SPEED|reset] - Sets the speed that the player moves
  52. spawn <NAME|ID|random|list> [QTY] - Allows you to spawn an individual creature.
  53. spawnstack <NAME|ID|list|random> - Spawns the specified creature a few blocks away from your current position (use "/spawn list" to get a list of creature names and codes).
  54. tele <X> <Y> <Z> - Teleport to X Y Z coordinates. Same as /t
  55. time [set|get|day|night [minute|hour|day [TIME]]] - Set and get the time within minecraft.
  56. timeschedule <reset | <TIME1> <TIME2>> - Sets a period of time (HH:MM format), this will make minecraft always within this time.
  57. useportal - Instantly transfers you to the nether, use it again to go back.
  58. waterdamage - Turns water damage on/off
  59. World Edit Commands
  60. //box <BLOCKID> - Creates a box between the two specified points
  61. //contract <n|s|e|w|u|d> [DISTANCE] - Reduces the selected area in the direction specified
  62. //copy - Copies the selected area
  63. //expand <n|s|e|w|u|d> [DISTANCE] - Expands the selected area in the direction specified
  64. //fill <BLOCKID> - Fills the selected area
  65. //help [COMMAND] - Specific world-edit help
  66. //load <FILENAME> - Loads a saved config file so that it can be pasted
  67. //paste - "Pastes" the copied (or loaded) region to the south-west of you
  68. //remove - Removes the selected region
  69. //reset - Resets the selected region
  70. //save [FILENAME] - Saves the selected region to file
  71. //set1 - Sets one corner of the region
  72. //set2 - Sets one corner of the region
  73. //walls <BLOCKID> - Puts walls around the selected region
