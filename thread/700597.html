标题: 水桶服1.11.2开的时候提示这个
cannot run server in directory with ! or ? in the pathname. please rename the affected folders and try again                求解
作者: nsisogf    时间: 2017-6-25 17:44
这个提示是指
您服务端的路径中含有“?”,"!"这两个特殊符号
比如：C:\minecraft\mc?\start.bat这里面的路径就存在特殊符号"!"和"?"

请将您的服务端更换一个没用特殊符号的路径即可
