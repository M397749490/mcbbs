 一个轻量级的经济插件稳定高效！
支持 MYSQL 平面文件储存方式，与Vault完全契合！

用于替代iconomy的一个年轻的经济插件！

插件安装：
1.将jar放入plugin文件夹
2.重启服务器
3.配置config文件如果使用mysql请改变设置到mysql
4.重启服务器

命令、权限：
玩家命令:   fe.member
  • /fe (name) - 显示一个玩家的金钱数量           fe.balance     fe.balance.other（可查看其他玩家的金钱）
  • /fe send [name] [amount] - 付款                  fe.send
  • /fe top - 显示金钱数排行前五的玩家              fe.top
  • /fe help - 显示命令帮助                                fe.?
管理员命令:  fe.admin
  • /fe grant [name] [amount] - 增加玩家金钱               fe.grant
  • /fe deduct [name] [amount] - 抠除玩家金钱             fe.deduct
  • /fe set [name] [amount] - 设置玩家金钱数量             fe.set
  • /fe create [name] - 创建一个玩家账户                       fe.create
  • /fe remove [name] - 删除一个玩家账户                     fe.remove
  • /fe clean - 删除所有金钱数量为默认值的账户              fe.reload
  • /fe convert (plugin) (flatfile|mysql) - 从原来的经济插件转换数据          fe.convert
  • /fe reload - 重载配置
