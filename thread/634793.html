输出功率可以改的

打开.minecraft/config/ic2.ini，找到如下内容

[balance / energy / generator]
generator = 1.0 火力发电机
geothermal = 1.0 地热发电机
; Deprecated, because of Kinetic Watermill
water = 1.0 水力发电机(不可用)
solar = 1.0 太阳能发电机
; Deprecated, because of Kinetic Windmill
wind = 1.0 风力发电机(不可用)
nuclear = 1.0 核电站输出
semiFluidOil = 1.0 下面几行好像与流体发电机有关，应该是不同燃料燃烧发电的倍率
semiFluidFuel = 1.0
semiFluidBiomass = 1.0
semiFluidBioethanol = 1.0
semiFluidBiogas = 1.0
Stirling = 1.0 斯特林发电机
Kinetic = 1.0
radioisotope = 1.0

其中1.0是倍率，改成2.0即为输出功率*2，如果是太阳能的话就是从1eu/t变为2eu/t，不过有的发电机改大会超过输出最大功率，没什么问题就是会开开停停比较吵。

其他的诸如 hu、ku 的同理

[balance / energy / heatgenerator]
semiFluidOil = 1.0 流体加热器
semiFluidFuel = 1.0
semiFluidBiomass = 1.0
semiFluidBioethanol = 1.0
semiFluidBiogas = 1.0
solid = 1.0 太阳能加热器
radioisotope = 1.0 放射性同位素温差加热器
electric = 1.0 电力加热器

; Base kinetic generation factors - increase for higher kinetic energy yield.
[balance / energy / kineticgenerator]
water = 1.0 水力动能发生器
wind = 1.0 风力动能发生器
manual = 1.0 手摇动能发生器
steam = 1.0 蒸汽动能发生器
electric = 1.0 电动动能发生器

附上丧病mox的方法：把reactorExplosionPowerLimit = 45 ，45改成 0，反应堆就不会炸了
