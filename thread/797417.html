插件介绍
Author:CyberDrain
Find more information here

本插件可以让你通过击杀生物/玩家获得其头颅，可自定义掉头几率（可受“抢夺”附魔影响），另外本插件附带了一套原版的进度系统（Advancement）,可以让玩家通过不断获得头颅来完成进度

全生物种类支持
支持MC1.12全部生物，且同一种生物可以按照花色，种类，村民的职业等进一步细分

设置自定义进度
  • 请下载下面这个mobheads文件夹，并放入/<世界文件夹>/data/advancements文件夹里
  • 请务必在所有世界文件夹里都放入这个mobheads文件夹！
  • 然后玩家便可在原版游戏中的“进度”里看到多出来的头颅进度（如果没看到，一定是因为你没有在全部世界文件夹里放入进度）
  • 注意事项：某些头颅（比如：僵尸马头颅）无法通过生存模式获得，所以部分进度仅凭生存模式无法达成，这给氪金购买头颅留下了空间

仅提供汉化过的进度包，如果想获得英文进度包，请参这里
This is NOT a jar file, just an advancement pack which is translated.

指令与权限
  • /mobhead give <玩家名> <头颅名> - 获得头颅，头颅标准名称请参config
  • /mobhead reload - 重载插件

建议给玩家的权限
com.cyber.mobheads.behead.mobs - 击杀生物掉落头颅
com.cyber.mobheads.behead.players - 击杀玩家掉落头颅
com.cyber.mobheads.behead.fish - 钓鱼钓到鱼的头颅

配置文件
config生物头颅设置
  1. ListOfMobs:
  2.     Bat:
  3.         # 生物掉头几率
  4.         dropChance: 0.1%
  5.         # 杀.生物的武器每包含一等级“抢夺”附魔，掉头几率增加多少
  6.         lootingBonus: 0.04%
  7.         # 爆到该种头颅是否全服公告
  8.         broadcastMessage: true
  9.         # 当该种生物被高压苦力怕炸.死时是否爆出头颅
  10.         # 请注意这个设置可能会影响到原版四种生物的掉头
  11.         dropOnChargedCreeperDeath: false
  12.         displayName: "蝙蝠的头"
  13.         random_uuid: e4c5dfef-bbcc-4012-9f74-879d28fff431
  14.         textureCode: []
  15.         advancements:
  16.             - "mobheads:firstmobhead first_mob_head"
