详细说明

  • 支持CraftBukkit / Spigot 1.7 - 1.16
  • 支持物品名称和lore的动画
  • 在加入游戏时给予物品
  • 在重生时给予物品
  • 在不同的世界拥有不同的物品
  • 对WorldGuard区域的特殊物品设置
  • 使用ItemJoin物品执行命令
  • 设置每次或每第一次加入时给出的特殊物品，甚至可以将特殊物品制定给玩家的ip
  • 允许每个物品拥有各自固定的格子
  • 允许或拒绝覆盖背包中的已有的物品
  • 如果玩家已拥有这个物品，就不会重复给予
  • 会显示给予失败的物品数量
  • 可在所有类型的药水瓶子上自定义药水效果
  • 自定义药水效果和对食用金苹果的效果，包括附魔金苹果和普通金苹果
  • 防止重新给予已经拥有的物品
  • 物品绑定的命令可以在背包中单击它们来执行，也可以直接通过左键单击或右键单击与它们进行交互或执行命令
  • 每个物品都支持不同的命令
  • 可以为每个命令设置冷却时间
  • 可以为每个命令设置自定义冷却消息
  • 可以为每个物品设置执行命令时所需要的费用
  • 左键单击和右键单击以执行不同的命令
  • 用不同的身份执行命令，可用的身份：

  • 执行命令时播放声音

  • 为物品进行附魔

指令

您可以使用/ IJ 代替 /ItemJoin

指令 说明 权限
/itemjoin 出现一个菜单，上面有着版本信息，制作者和帮助命令 - itemjoin.use
/itemjoin help [页码] 查看帮助 - itemjoin.use
/itemjoin reload 重载配置文件 - itemjoin.reload
/itemjoin info 查看手上物品的信息 - itemjoin.use
/itemjoin updates 检查升级 - itemjoin.updates
/itemjoin permissions [页码] 查看拥有的ItemJoin权限 - itemjoin.permissions
/itemjoin save <物品名> 保存物品到item.yml中 - itemjoin.save
/itemjoin get <物品> 给你一个指定的物品 - itemjoin.get
/itemjoin get <物品> <玩家> 给予指定玩家指定物品 - itemjoin.get.others   
/itemjoin remove <物品> 从你的背包中移除指定物品 - itemjoin.remove
/itemjoin remove <物品> <玩家>      从指定玩家的背包中移除指定物品 - itemjoin.remove.others  
/itemjoin enable 为所有玩家启用所有物品 - itemjoin.enable
/itemjoin enable <玩家> 为指定玩家启用指定物品 - itemjoin.enable.others
/itemjoin disable 禁用所有玩家的所有物品 - itemjoin.disable
/itemjoin disable <玩家> 禁用指定玩家的所有物品 - itemjoin.disable.others
/itemjoin removeall 从你的背包中移除所有ItemJoin物品 - itemjoin.remove
/itemjoin removeall <玩家> 移除指定玩家背包中的所有ItemJoin物品 - itemjoin.remove.others
/itemjoin list 检查每个可用世界中可以获得的物品 - itemjoin.list
/itemjoin autoupdate 强制更新ItemJoin，如有更新，则需要重启服务器 - itemjoin.autoupdate
/itemjoin purge 清除数据库 - itemjoin.purge
/itemjoin purge first-join 从数据库中清除指定玩家第一次加入的数据 - itemjoin.purge
/itemjoin purge ip-limits 从数据库文件中清除指定玩家所有的ip限制数据 - itemjoin.purge
/itemjoin get <物品> 给你所有ItemJoin物品 - itemjoin.get
/itemjoin get <物品> <玩家> 给指定玩家所有ItemJoin物品 - itemjoin.get.others
/itemjoin world 检查您所处的世界，方便调试 - itemjoin.use

ItemJoin支持多世界吗?
  • 是的，ItemJoin可以为items.yml中的每个指定世界提供项目。 items.yml中未定义的任何世界的话就不会获得任何物品。
  • 你还可以将ItemJoin挂钩到 Multiverse-Core 或 Multiverse-Inventories 中，这样你就可以在每个世界中拥有不同的物品，而无需在切换世界时清除玩家的背包。只需在config.yml中将
  1. Multiverse-Core: false
  2. Multiverse-Inventories: false

  1. Multiverse-Core: true
  2. Multiverse-Inventories: true

我可以只在首次加入时获得物品吗？
  • 是的，ItemJoin的物品可以开启首次加入模式。您只要将first-join添加到items.yml中的想要首次加入得到的物品的itemflags:中，以便仅在第一次加入时获取这些物品。之后，只有一些物品在首次加入时给出，而其他物品每次都给出，或者只是简单地将它们设置为首次加入给予的所有物品。如果您想在每次重新加入时收到该物品，只需在items.yml中删除想要每次加入都能得到的物品的itemflags中的first-join即可。

ItemJoin是否有自己的 Custom API?
  • 是的，如果需要，ItemJoin实际上允许其他插件挂钩。  所有的API选项都位于 me.RockinChaos.itemjoin.ItemJoinAPI 下. 目前只有一种方法; me.RockinChaos.itemjoin.ItemJoinAPI.getAllItems(player). 您可以作为插件开发者把插件挂钩到ItemJoin上并使用新的API将所有ItemJoin物品给予玩家。

ItemJoin是否具有任何依赖性?
  • ItemJoin 不依靠任何插件，但使用它们会得到更棒的游戏体验
  • 您可以通过点击这里的链接了解更多关于这些API / 挂钩的信息; https://www.spigotmc.org/wiki/api-hooks/
    • Vault- 您可以使用ItemJoin的命令挂钩到Vault以使用经济！
    • PlaceholderAPI- 您可以在ItemJoin的任何地方使用所有这些占位符! 比如 命令，名称, lore, 头颅皮肤, 书本lore, 作者，等等！ 将ItemJoin的所有部分都挂钩到PlaceholderAPI中。
    • Multiverse-Core - 仅是为了支持Multiverse-Inventories，因为ItemJoin已经拥有多世界支持而没有这个（指Multiverse-Inventories）。
    • MyWorlds- 允许简单的多世界支持
    • Multiverse-Inventories- 这使ItemJoin轻松地设置世界背包。你可以选择启用他，这样就可以在不清除玩家背包的情况下获得加入世界和世界变化的物品！ 非常有助于ItemJoin背包管理。
    • xInventories- 这使ItemJoin轻松地设置世界背包。你可以选择启用他，这样就可以在不清除玩家背包的情况下获得加入世界和世界变化的物品！ 非常有助于ItemJoin背包管理。
    • PerWorldInventory- 这使ItemJoin轻松地设置世界背包。你可以选择启用他，这样就可以在不清除玩家背包的情况下获得加入世界和世界变化的物品！ 非常有助于ItemJoin背包管理。我最近看到许多人用它来代替 Multiverse-Inventories.
    • PerWorldPlugins- 在这个插件中ItemJoin默认是禁用的，你要在PerWorldPlugins中启用这插件，并且在ItemJoin中启用，有点儿麻烦，所以我不推荐使用它，但是ItemJoin的确支持PerWorldPlugins，如果您的服务器上有这个插件，请在你想要的世界中中启用ItemJoin。
    • AuthMe- 登录或注册 AuthMe 后再给予ItemJoin物品.
    • WorldGuard- 使你在特定区域拥有特殊的物品，离开特定区域再还给你进入前的物品。
    • TokenEnchant - 获得一些特殊附魔的物品。
    • BetterNick- 如果由于某种原因导致的无法支持获得物品，请使用这个插件，并在配置文件中则将此设置为true可以解决无法正常获得物品问题。 如果您使用了BetterNick昵称，这样ItemJoin就可以轻松地找到您的原始玩家名称和UUID（正版服）。
    • HeadDatabase - 使用并在ItemJoin配置文件中启用HeadDatabase这样你就可以使用<hdb-head id>获取玩家头颅.
