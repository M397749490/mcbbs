简介：
这是一款简单的插件，它能使玩家随机地方重生
由于bbs转载链接还停留在17年，所以我重新转载更新一遍

功能特色:
玩家随机重生
可以限制随机的范围坐标
可以配置是否启用随机重生
设置床后可以不用随机重生
随机重生只在第一次进服
指令:
/uxspawn-config——查看配置文件
/uxspawn-reload——重载插件

权限:
UnexpectedSpawn——能使用所有指令(OP默认拥有)

配置:
# ####################
# 坐标设置 #
# ####################
#值必须是整数，例如：
# x-max: 9500
# x-min: -9500
# z-max: 9500
# z-min: -9500

# ###################
# 条件设置 #
# ###################
# 使用床出生的点?
bedrespawn: true
#新玩家加入时随机传送?
firstjoin: true
# 玩家每次加入时都随机传送?
onjoin: falst
