OffHandActions


     插件介绍
  让玩家在主副手之间切换时添加动作（按F键即可）
  给玩家发送信息，运行控制台的命令，让玩家执行命令等

     插件功能

  • [ConsoleCommand]-让控制台运行指令，玩家变量％player％
  • [PlayerCommand]-以玩家的身份执行指令，玩家变量％player％
  • [Message]-给玩家发送信息（支持颜色代码&），玩家变量％player％每个奖励都有自定义的冷却时间
      例如：'[Message] &6你好 &e%player%！'

  
     配置文件

  1. # ---------------------------------------------
  2. #    OffHandActions 作者： N3kas  汉化：天铄
  3. # ---------------------------------------------
  4. # 帮助:
  5. #   disable-offhand: [true/false] - 是否禁用副手
  6. #   actions: 执行任务列表:
  7. #     [ConsoleCommand]-让控制台运行指令，玩家变量％player％
  8. #     [PlayerCommand]-以玩家的身份执行指令，玩家变量％player％
  9. #     [Message]-给玩家发送信息（支持颜色代码&），玩家变量％player％
  10. #    注意: 这些你都可以添加到列表 (以我这你可以一次运行多个命令或一次发送多个信息）
  11. # ---------------------------------------------
  12. # 祝你好运 /作者： N3kas  汉化：天铄
  13. # ---------------------------------------------
  14. disable-offhand: true
  15. actions:
  16.   - '[ConsoleCommand] tell %player% 这个服务器使用的是 OffHandActions!'
  17.   - '[PlayerCommand] /me 你好呀！ :)'
  18.   - '[Message] &7这个服务器使用的是 &eOffHandActions&7!'
