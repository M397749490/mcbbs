  create $cost:钱数
这个自定义选项可以让你为一个脚本添加执行所需要花费的金钱, 如果玩家不具备相应金钱则取消执行之后的脚本内容.

  示例
  1. /sbinteract create [$cost:1][@bypass give <player> 草的ID 草的数量] #作用是出售给玩家草方块，钱数不足则取消命令
复制代码

根据需要，在所需的指令前添加
  1. /sbinteract create [$cost:1][] #在后面按命令执行顺序添加[]并书写内容，/sbinteract create [$cost:钱数]在前面说明先检测钱数并扣除
复制代码
