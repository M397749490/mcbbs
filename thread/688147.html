这个东西是我写的第一个小游戏，希望大家能够喜欢
有服主肯定认为小游戏装起来麻烦，但这个插件绝对简单，可以看一下最下面的安装教程
玩过CF的服主相信都了解cf里的爆破模式的游戏规则是怎么玩的
还有服主会认为自己的服务器装不上这个插件，可能觉得不兼容，那么这个小游戏适合你，兼容性比较强！
如果不知道的话，我来说一下:
分两队，保卫者和潜伏者，潜伏者负责埋炸弹，保卫者负责拆炸弹，炸弹过一会儿就会爆炸，如果炸弹爆炸算潜伏者赢，如果保卫者拆除炸弹算保卫者赢，如果一方队员全部阵亡，则算另一方胜利!

由于考虑到版本兼容，这里没用title

安装炸弹/拆除炸弹:
安装炸弹:手拿炸弹右击或者左击红石块/绿宝石块，静立5秒不动安装c4
拆除炸弹:右键/左键c4所在的红石块或者绿宝石块，静立5秒不动拆除c4

指令:
/bpm join [游戏号] ——加入一个爆破游戏(这个指令没有权限也就是玩家可以任意入)
/bpm create [游戏号] ——创建一个爆破游戏区
/bpm lobby [游戏号] ——为一个爆破游戏区设置大厅为脚下方块
/bpm baowei [游戏号] ——为一个爆破游戏区设置保卫者出生点为脚下方块
/bpm qianfu [游戏号] ——为一个爆破游戏区设置潜伏者出生点为脚下方块

权限:
BPMode.use ——创建游戏的权限

安装方法：
首先把插件丢入服务器加载
然后在服务器内输入
/bpm create [游戏号] ——游戏号随意输入，举一个例子吧/bpm create 1
这样就创建了名字叫1的爆破游戏区
然后/bpm lobby [游戏号] ——设置大厅，举上面的例子吧:/bpm lobby 1(设置爆破游戏区1的大厅为脚下方块)
然后/bpm baowei [游戏号] ——设置爆破游戏区保卫者出生点
接着/bpm qianfu [游戏号] ——设置爆破游戏区潜伏者出生点
接着在游戏场地分别放置一个绿宝石块和红石块，模拟cf的a点和b点，如果你只需要一个点也可以放置他们的其中之一
最后/bpm join [游戏号] ——就可以和基友(必须两个或以上)一起玩爆破游戏了!
