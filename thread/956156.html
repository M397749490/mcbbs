RPG Death

特性
物品概率掉落，可配置的掉落装备，黑名单白名单
经验比率掉落，上下限
经验比率丢失（丢失掉落经验百分比，不是全部经验百分比）
经济比率掉落，上下限
下线后保留假人，会被周围怪物攻击，如果在时长内死亡，则上线后玩家死亡
所有模块可开关，可配置消息发送


权限
rpgdeath.disable.item         不掉落物品
rpgdeath.disable.exp          不掉落经验
rpgdeath.disable.ecnomy       不掉落经济
rpgdeath.disable.fakeplayer   不生成假人（创造下线后可以被杀）


配置

  2. economy {
  3.     # 最大掉落
  4.     maxDrop=100
  5.     # 最小掉落
  6.     minDrop=10
  7.     # 掉落比率 (< 1)
  8.     ratio=0.2
  9.     sendMessage=true
  10. }
  11. exp {
  12.     # 丢失比率（掉落部分）
  13.     loseRatio=0.4
  14.     # 最大掉落
  15.     maxDrop=0
  16.     # 最小掉落
  17.     minDrop=64
  18.     # 掉落比率 (< 1)
  19.     ratio=0.2
  20.     sendMessage=true
  21. }
  22. fakePlayer {
  23.     playerData=[]
  24.     sendMessage=true
  25.     # 假人持续时间（秒）
  26.     timeToLive=5
  27. }
  28. item {
  29.     # 必掉物品
  30.     blacklist=[]
  31.     # 掉落装备
  32.     dropEquipments=true
  33.     # 最小掉落
  34.     minDrop=4
  35.     # 掉落概率 (< 1)
  36.     ratio=0.15
  37.     sendMessage=true
  38.     # 保护装备
  39.     whitelist=[]
  40. }
  41. modules {
  42.     economy=true
  43.     exp=true
  44.     fakePlayer=true
  45.     item=true
  46. }
