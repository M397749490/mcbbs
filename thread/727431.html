RplPlaceholder


让 RPG Player Leveling 支持 PlaceholderAPI 占位符

站内 RPL 教程

该插件即将向多个插件创建占位符
如有别的插件需求占位符，请在贴内回复
格式

  1. 插件名: XxxXxx
  2. 插件链接: http://www.mcbbs.net/xxx.php
  3. 需要变量: %等级?% / %法力值?% / %抽奖钥匙?%
复制代码

停止更新中



使用方法

把 RplPlaceholder 放入 /plugins 文件夹

启动你的服务端，确保启动成功后

向你的插件提供 PAPI 占位符



注意事项

确认你的 RPG Player Leveling 及 PlaceholderAPI 在 /plugins 文件夹

否则本插件会自动关闭



支持占位符

  1. %rpl_random数字1-数字2% -> 获取数字1到数字2的随机值
  2. (例:%rpl_random50-100% 随机获取 50-100 的随机值)

  4. %rpl_level% -> 获取玩家RPL等级
  5. %rpl_stat_points% -> 获取玩家RPL天赋点
  6. %rpl_exp% -> 获取玩家RPL经验值
  7. %rpl_max_exp% -> 获取玩家RPL最大经验值
  8. %rpl_mana% -> 获取玩家RPL法力值
  9. %rpl_max_mana% -> 获取玩家RPL最大法力值
  10. %rpl_power% -> 获取玩家RPL耐力值
  11. %rpl_max_power% -> 获取玩家RPL最大耐力值
  12. %rpl_str% -> 力量
  13. %rpl_sta% -> 健康
  14. %rpl_dex% -> 灵巧
  15. %rpl_int% -> 智力
  16. %rpl_melee_d% -> 近战伤害
  17. %rpl_arrow_d% -> 远程伤害
  18. %rpl_mage_d% -> 魔法伤害
  19. %rpl_health% -> 血量
  20. %rpl_def% -> 防御
  21. %rpl_regen% -> 生命恢复
  22. %rpl_crit_c% -> 暴击几率
  23. %rpl_crit_p% -> 暴击伤害
  24. %rpl_block% -> 格挡几率
  25. %rpl_dodge% -> 闪避几率
