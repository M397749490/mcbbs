  • 前言:
最近逛bukkit,发现一款挺好的插件,不过看下载量不高,而且论坛也没人转载,纳闷之余那就我来转载吧~

CompassModes, 我姑且翻译成更好的指南针,这款插件在利用指南针指向的原理下,增加了多种指向目标.
-   默认(指南针原始的指向方向)
-   自己目前X,Y坐标位置方向
-   指定的X,Y坐标方向
-   离自己最近玩家的方向
-   随机一个坐标方向
-  上个死亡方向
-  放置的床的方向
-  指定一个家的方向
并且还提供多种可配置方案.
  • 命令&使用方法
-  /compass help
#显示帮助
-  /compass list
#显示可使用的指向方向.
具体支持
NEAR         - 离自己最近的一位玩家
RANDOM    - 指南针每隔一秒随机指向
CURRENT   - 当前坐标
LOCATION  - 指定坐标,使用方法为/compass X,Z  (逗号需要是英文半角符号)
PLAYER       - 某个玩家
DEFAULT     - 指南针默认指向
BED             - 床的方向
DEATH         - 上次死亡方向
NORTH        - 指向北方
SOUTH        - 指向南方
EAST           - 指向东方
WEST         - 指向西方
HOME         - 家的方向,使用方法为/compass home:<home名>
- /compass reload
#重载插件
-  /compass <mode>
#修改指南针指向模式,具体模式参考compass list
-  /compass <mode> <player>
#修改其他玩家的指南针模式
