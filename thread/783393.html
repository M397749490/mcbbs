RandomDrop

死亡时物品都没了肯定会让玩家很苦恼，但是什么都不掉落的话游戏就没意思了。这个插件能让玩家掉落随机数量的物品。
我特别做了Vehicles支持。插件会自动检测Vehicles插件是否存在。存在的话会与Vehicles挂钩。Vehicles载具不会掉落，以防止载具掉落造成巨大损失。

  1. preservedItems: [] # 100%不掉落的物品
  2. lostItems: [] # 100%掉落的物品
  3. disabledWorlds: [] # 禁用的世界
  4. preserveVehicles: true # 启用防载具掉落
复制代码

安装方法

将插件拖入plugins文件夹，更改设置即可。监测到Vehicles插件会自动提示。


还要一张效果图

这能有什么效果。。好吧，原来有64个原木。死亡以后背包里剩50个，掉落14个。
