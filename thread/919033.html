NametagEdit
名称标签编辑



插件介绍


NametagEdit是一个容易配置的插件，允许用户更改名称标签和TAB名称。
使用NametagEdit，用户可以在名称之前和之后添加其他字符。
此外，插件兼容多个服务端核心版本（当前兼容1.7.x-1.14.x）。

权限信息



权限                                           描述
          nametagedit.use                  允许玩家使用NametagEdit插件
        nametagedit.reload              允许玩家重新加载插件的数据
        nametagedit.priority             允许玩家查看排序优先级信息
            nametagedit.clear.others      允许玩家清除任何人的前缀/后缀
         nametagedit.clear.self          允许玩家清除自己的前缀/后缀
             nametagedit.edit.others        允许玩家编辑任何人的前缀/后缀
          nametagedit.edit.self            允许玩家编辑自己的前缀/后缀
                        nametagedit.groups             允许使用所有组命令(创建、编辑、删除)



命令信息


/nte —— 显示所有的命令
/nte debug —— 显示调试信息
/nte reload —— 重新加载插件
/nte longtags —— 切换TAB标签显示长短名称
/nte priority —— 列出名称标签的排序优先级
/nte teams <clear> —— 清除空团队的调试特性
/nte player [player] clear —— 清除玩家的前缀和后缀
/nte player [player] <prefix/suffix> <text> —— 设置玩家的前缀或后缀
/nte player [player] priority <#> —— 设置名称标签优先级


编辑用户组命令



/nte group list —— 列出所有加载的组
/nte group order <groups> —— 排序组的优先级。
/nte group add [group] —— 创建一个新组
/nte group remove [group] —— 删除组
/nte group [group] perm <value> —— 设置组的默认权限
/nte group [group] prefix <value> —— 设置组的前缀
/nte group [group] suffix <value> —— 设置组的后缀
/nte group [group] priority <value> —— 设置名称标签优先级
/nte group [group] clear <prefix/suffix> —— 清除组的前后缀


配置文件


config.yml
选项值描述
ClearEmptyTeamsInterval整数此功能检测清除其他插件遗留下来的空团队（可能会有用！）。此设置为以秒为单位。
DatabaseVersion整数请勿更改此设置！
Debugtrue/false如果为true，NametagEdit将显示调试信息到控制台。
DisablePushtrue/falseIf 'true', NametagEdit will prevent player pushing. This only works if both players have NametagEdit nametags.不明白啥意思
MetricsEnabledtrue/false如果为true, 将发送少量信息到MCstats.org，方便作者知道插件使用量。
MySQLtrue/false如果为true, NametagEdit将使用MySQL数据库存储数据。
RefreshTagOnWorldChangetrue/false如果为true, 当玩家改变世界时，NametagEdit会刷新他们的名字。
RefreshInterval整数此功能将每隔一定的秒数刷新所有玩家的名字，此设置为以秒为单位。
Tablist.Enabledtrue/false如果为true, NametagEdit将更改TAB列表中的名字.
Tablist.LongTagstrue/false如果为true，NametagEdit将格式化用户的TAB列表名字以显示更长的名字。

groups.yml
Groups:
  fuzhu: # 这是组名，根据喜好设置。
     Permission: nte.fuzhu # 这是这个组的权限，需要配合权限插件使用。
     Prefix: '&2' # 这是前缀
     Suffix: '&f' # 这是后缀
     SortPriority: 1 # 这是优先级，此数越小越优先显示。
  op:
     Permission: nte.op # 这是这个组的权限，需要配合权限插件使用。
     Prefix: '&2' # 这是前缀
     Suffix: '&f' # 这是后缀
     SortPriority: 2 # 这是优先级，此数越小越优先显示。


palyers.yml
Players:
  b5ccebaa-0623-4370-af73-0ec985dfa3b0: # 这是玩家的uuid
     Name: sgtcazeyt # 这是玩家的名字
     Prefix: '&b' # 这是玩家的前缀
     Suffix: '&c' # 这是玩家的后缀
     SortPriority: 1 # 这是显示优先级，同一个玩家可以设置多个前后缀，优先级设置同组。
