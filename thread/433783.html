第一章-    配置Java编程环境及简单认识Java
  在制作Mod之前，你先要了解Java，Java是一种可以撰写跨平台应用软件的面向对象的程序设计语言。是全世界闻名的编程语言之一,我建议没有任何编程经历的人先阅读一些Java教程再来学习.
  首先，你需要Jre1.7(java runtime environment, Java运行环境)
下载地址: http://www.java.com/zh_CN/download/manual_java7.jsp
JDK1.7(Java Development Kit)
下载地址:http://www.oracle.com/technetwor ... nloads-1880260.html
根据自己的操作系统来选择版本, 64位Window请用x64版, 32位请用Window x86版.
  Jre下载完后, 按照步骤安装, Jdk同理. 现在,要开始配置环境变量,下面的链接能帮到你~
http://zhidao.baidu.com/question/351018707.html
配置完,在cmd窗口输入javac与java都没有出现找不到命令,那就Ok了~这时, 我们需要一个Ide(Integrated Development Environment, 集成开发环境), 我这里推荐Eclipse, 因为Eclipse配置Forge比较友好, 并且教程后面使用的都是它, 不过, 你也可以选择其他, 但是后文我就不会讲解其他的Forge配置方法.
Eclipse下载地址:
http://www.eclipse.org/downloads/
等一切都安装完毕后, 就来开始你的第一个Java程序吧!(虽然你可能已经不是第一个了)

复制代码


  现在,双击HelloWorld.java,你会看到以下代码:
第一行 packagesrc;  为 声明包, 假如说, 类就是鸡蛋， 包就是箱子，声明鸡蛋在盒子里
第二行 public classHelloWorld {    为定义类 public指此类可被所有类访问,class为 一个关键字, { 为一个块的开头.
第三行 }    为一个块的结尾
我们把代码更改为这样:

  1. package src;
  2. public class HelloWorld {
  3.      public static void main(String srg[]){
  4.          System.out.println("HelloWorld");
  5.      }
  6. }
复制代码


好了,你可能现在已经一头雾水.现在我来解释一下这些是什么意思.
第一句, 依然为声明类
第二句, 依然为之前的说明
第三句, 为定义一个方法,这个方法是Java启动程序的一个标志,如果没有这个,Java将不会运行你的程序,就好比说这是一个合格标签贴在箱子上,Java检测箱子上有没有这个标签,如果有,就执行,反之则出错，此方法一个程序只需要一个，你所有要执行的代码都要放在这里. public表示指此方法可被所有类访问, static 表示该方法为静态 ,void表示该类无返回值, main是方法名(这个不能更改),String是一个值类型, srg[]是一个定义的参数(可随意更改名字,如 a[]),{为块的开始
第四句,System.out.println是Java提供的一个方法,用于在控制台打印消息.(println为打印后换行)
  现在,你可以尝试点击左上角的”运行”按钮开始测试.
