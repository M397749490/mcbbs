Mojang服务检查器
专为启动器作者设计的动态连结库


引言
有没有尝试过无法登入Minecraft？有没有尝试过无法进入Minecraft.net？有没有尝试过无法进入正版伺服器？想知道Mojang的服务是否正常？这个程式能够帮助你！


简介
这是一个简单易用的动态连结库；只要引用这个动态连结库，并且输入一行代码，就可以轻易得知Mojang服务的状态；而且这个动态连结库支援多个程式语言，可算得上简单易用！

教程
以下是本动态连结库的呼叫及回传的教程
状态伺服器
状态伺服器是用于检查各服务的状态
呼叫：
  1. // 呼叫指令
  2. ServiceChecker.MojangStatusServer()  // 用于检查状态伺服器的运作，无需任何参数
复制代码
回传：
  1. // 正常回传
  2. True  // 状态伺服器运作正常
  3. False  // 状态伺服器出现异常

  5. //错误回传
  6. Error  // 连接时出现异常，可能是网络问题
复制代码
服务状态
服务状态就是Mojang支援网站顶部那個「Service Statuses」
呼叫：
  1. // 呼叫指令
  2. ServiceChecker.ServiceStatusChecker(%Mojang服务%)  // 用于检查Mojang服务状态，「%Mojang服务%」就是需要的参数

  4. // 呼叫参数
  5. %Mojang服务% = Mojang服务网址  // 可以在「help.mojang.com」的原始码，大约第1755行找到
复制代码
回传：
  1. // 正常回传
  2. True  // 服务运作正常
  3. Limited  // 服务运作受限
  4. False  // 服务出现异常

  6. //错误回传
  7. NetworkError  // 连接时出现异常，可能是网络问题
  8. ServerError  // 状态伺服器出现异常
  9. LinkError  // 连接时出现异常，可能是服务网址错误
  10. DllLostError  // 遗失了「Newtonsoft.Json.dll」
  11. ProgramError  // 遇上了程式错误，这是我的问题
