Fx全球商店






简介
▔▔▔▔


本插件为基于vexview的全球商店，自带两种商店类型（玩家商店与系统商店）



          √  自定义商店界面      

          √  支持金币点券         

          √  无限出售物品         

          √  支持商品打折   

          √  支持MySQL            

          √  内置快捷键打开商店

          √  自定义上架物品名

          √  商品预览 防止与描述不符

          √  禁止上架含有指定Lore的物品


若使用过程中遇到bug请直接在帖子下反馈

权限
▔▔▔▔


基础权限


fzmxer.admin.vexfxshop.use 允许玩家使用命令              

fzmxer.admin.vexfxshop.sell 允许玩家上架商品到玩家商店

fzmxer.admin.vexfxshop.buy 允许玩家购买                     



打折权限(仅限系统商店，防止刷钱)

VexFxShop.v1 打折 95%

VexFxShop.v2 打折 90%

VexFxShop.v3 打折 85%

VexFxShop.v4 打折 80%

VexFxShop.v5 打折 75%

打折越低，判定优先级越高(例同时有打折90%与80%权限，将判定打折80%)








指令
▔▔▔▔



/fxs open [类型]            ——  打开商店(ss(系统),ps(玩家))  例: /fxs open ss 打开系统商店
/fxs keys                       —— 开启关闭  按键调试(类似VexKey，按下按键后反馈按键ID)   
/fxs add [物品名]           —— 将手上的物品名改为指定名称(仅适用于本插件)                    
/fxs del                         —— 删除手上物品的物品名                                                      
/fxs reload                     —— 重载插件                                                                                            








配置
▔▔▔▔


config.yml
  1. # ******************** #
  2. # Make: FzmXer         #
  3. # ******************** #
  4. VexFxShop:
  5.   #目前仅支持 mysql 与 sqlite，默认sqlite
  6.   DataSaveType: sqlite
  7.   #数据库地址
  8.   MySQL:
  9.     IP: 127.0.0.1
  10.     UserName: fzmxer
  11.     PassWord: 123456
  12.     DatabaseName: fzmxer
  13.     Port: 3306
  14.   #打开系统商店的快捷键id，默认I键
  15.   SystemShop: 23
  16.   #打开玩家商店的快捷键id，默认O键
  17.   PlayerShop: 24
复制代码

banlore.yml
  1. VexFxShop:
  2. #如果物品的Lore中含有这个Lore，则禁止上架,中文请使用 '' 括起来，颜色符请使用§
  3.   BanLore:
  4.     - '灵魂绑定'
