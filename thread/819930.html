介绍：
本插件可以按指定周期自动重置自定义的世界，支持选择是否保留世界游戏规则与种子。当然，您也可以使用命令手动重置世界。

使用：
将本插件扔进服务端plugins文件夹里，重新启动服务器即可。

命令&权限：
命令
别名
权限
说明
默认
/worldreset <世界名> [是否保留种子] [是否保留游戏规则]/wrworldreset.command用于手动重置世界OP

配置：
config.yml
  1. # 需要重置的世界列表，每个世界都可以有自己的设置
  2. worlds:
  3.   # 世界名称
  4.   example_world1:
  5.     # 多久重置一次（以分钟为单位）。默认的 10080 即 1 周
  6.     period: 10080
  7.     # 是否保留种子
  8.     keep-seed: false
  9.     # 游戏规则种子
  10.     keep-gamerule: true
  11.   example_world2:
  12.     period: 10080
  13.     keep-seed: false
  14.     keep-gamerule: true
