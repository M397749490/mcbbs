TabooLib-BungeeSuite

用于 BungeeCord 与 Bukkit 之间的快速交流工具


插件介绍

本插件为 BungeeCord 插件，也可以安装于 Bukkit 内。
相比原版 BC 交流方式有所不同的是, 这个工具可以在单个方法内实现交流信息的发送与接收。
每条交流信息都有独立的识别序号, 不会因为同时发送多条信息就导致无法准确的送达返回内容。
我觉得比手动写 PluginMessageListener 简单多了，一个方法解决所有操作，无需注册任何通道。


插件示范

Bukkit 向 BungeeCord 发送数据：
  1. // Bukkit 部分:
  2. TBukkitChannel channel = TabooLibBukkit.getInst().getBukkitChannel();
  3. TBukkitChannelTask.createTask()
  4.     .channel(channel)
  5.     .sender(Bukkit.getOnlinePlayer().iteraotr().next())
  6.     .command("Hello World!")
  7.     .result(result -> Bukkit.broadcastMessage("Hello: " + result[0]))
  8.     .run();
复制代码
  1. // BungeeCord 部分
  2. @EventHandler
  3. public void onCommand(BungeeCommandEvent e) {
  4.     if (e.getString(0).equalsIgnoreCase("Hello World!)) {
  5.         // 返回信息
  6.         e.response(e.getSender().getName());
  7.     }
  8. }
复制代码
BungeeCord 向 Bukkit 发送数据
  1. //BungeeCord 部分:
  2. TBungeeChannel channel = TabooLibBungee.getInstace().getBungeeChannel();
  3. TBungeeChannelTask.createTask()
  4.     .channel(channel)
  5.     .sender(BungeeCord.getInstace().getPlayer("BlackSKY"))
  6.     .command("Hello BlackSKY!")
  7.     .result(result -> BungeeCord.getInstace().getProxy().getLogger().info("Hello: " + result[0]))
  8.     .run();
复制代码
  1. // Bukkit 部分:
  2. @EventHandler
  3. public void onCommand(BungeeCommandEvent e) {
  4.     if (e.getString(0, "null").equalsIgnoreCase("Hello BlackSKY!)) {
  5.         // 返回信息
  6.         e.response("BungeeCord");
  7.     }
  8. }
