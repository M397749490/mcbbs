Skinner 2.8.0-SNAPSHOT
改变几乎所有的怪物，NPC皮肤！你甚至可以改变你的皮肤！


【必备前置】Lib'sDisguises (伪装插件)，Holographic Displays(全息图)
                      【可选前置】MythicMobs , Citizens(NPC插件)      
                                 

一 、插件特色

    1. 不必担心套用伪装的对象更换皮肤

     2. 允许使用玩家 自行下载/直接链结 的skin档改变皮肤


二 、插件指令 (/sk 或 /skinner)
   
    /sk help or ? : 展示插件指令

    /sk reload : 重新载入config档 (config.yml)

    /sk upload <皮肤档名.png> <removeFileAfterUpload（boolean）：
    上传一个新皮肤并在 plugins / LibsDisguises / disguises.yml 中创建伪装档

    /sk upload <直接链结> <伪装名称>  :
    使用直接链结上传一个新皮肤并在 plugins / LibsDisguises / disguises.yml 中创建伪装档

    /sk changeSkin <伪装名称>：改变你的皮肤,你仍可以看到你的旧皮肤,但其他玩家会看到你伪装的皮肤


三、权限节点 Perimission




       skinner.admin：  允许使用所有指令
       skinner.upload：  允许使用 上传皮肤 指令
       skinner.changeSkin：允许使用 更换皮肤 指令

创建步骤 Setup

分类-前置步骤
1. 下载皮肤档并放进skinner资料夹中的skins资料夹
2. 使用指令 /sk upload <皮肤档名.png> <removeFileAfterUpload（boolean）>
       或 /sk upload <Url(直接链结)> <*伪装名称>
*伪装名称 正常情况下为识别字词 (支持特殊符号,但不建议)
3. 你将在 plugins/LibsDisguises/disguises.yml 找到你新增的伪装

3. 你将在 plugins/LibsDisguises/disguises.yml 找到你新增的伪装


分类-MythicMobs   


1. 找出你创建的伪装档 (plugins/LibsDisguises/disguises.yml)
2. 编辑插件配置（plugins / Skinner / config.yml）
并将MythicMobs: false 改成 true
3. 将 MM-Mobs: 中的
  mobInternalName 改成 怪物辨识ID
       displayName 为 怪物显示名称 (更改后方英文)
       disguise是伪装档辨识，将disguiseName更改成伪装档名称

分类-Citizens (NPC)

#作者提及Citizens插件skin功能的已经超越的伪装插件所能做到的 (他正在想办法解决)
1. 找出你创建的伪装档 (plugins/LibsDisguises/disguises.yml,图有了不重上)
2. 编辑插件配置（plugins / Skinner / config.yml）
    并将Citizens: false 更改为 Citizens: true
3. 将 NPC: 中的
  npc name改成您的NPC名称
      displayName 为 NPC显示名称 (更改后方英文)
      disguise是伪装档辨识，将disguiseName更改成伪装档名称
分类-原版怪物
跟上面一样的方法
1.找出伪装挡
2.编辑
MOBTYPE是怪物类型
(见此:https://hub.spigotmc.org/javadoc ... ity/EntityType.html)
       displayName 为 怪物显示名称 (更改后方英文)
       disguise是伪装档辨识，将disguiseName更改成伪装档名称
