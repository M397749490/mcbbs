数组
数组是一种数据结构，其中包含许多通过计算索引访问的变量。 数组中的变量（亦称为数组的元素）均为同一种类型，我们将这种类型称为数组的元素类型。       ——docs.microsoft.com

一维数组的 声明语法 如下
<元素类型>[] <数组名称>;

初始化语法 如下
<数组名称> = new <元素类型>[数组的长度;

初始化并赋值语法 如下
<数组名称> = new <元素类型>[数组的长度] { 数组长度个数的变量 };

我们可以用 <数组名称>[变量的位置索引  来访问数组中的变量

这里要注意
1. 数组的长度就是数组中的变量个数
2. 长度一旦声明就无法更改，也就是说变量的个数无法改变
3. 数组中没有进行赋值的变量的默认值是 0 或者 false
4. 在访问数组时，数组第一个变量的索引是0
5. 访问超出数组长度的索引位置会报错
