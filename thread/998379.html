███████████████████  ？？？ ███████████████████
每当进入一个服务器，服务器里总是充斥着各种低素质语言
似乎大家也习以为常了，但是这真的是一种好现象吗？
反脏话插件出了又出，脏话却仍然以加符号等方式遍布
在这种条件下，NoFxxkMsg诞生了！


███████████████████  Why？ ███████████████████
论坛内已经有很多优秀的反脏话插件，为啥还要用这个？
铛铛！NoFxxkMsg支持多种模式检测脏话
不仅支持是否包含脏话的匹配，还支持正则表达式等多种模式
总有一种可以简洁又强力地消除脏话！

███████████████  Command&Permission ███████████████
目前只有一个命令:
/nfmreload - 重载配置
权限暂时没有，上面这条指令仅允许有op权限的人使用

███████████████  Configuration ███████████████
在默认生成的配置文件内有详细的注释
你可能已经发现了，这个插件不止于反脏话，还能反宣传

  1. # NoFxxkMsg 配置文件

  3. # 反脏话设置
  4. antiSwear:
  5.   # 是否取消脏话发送?
  6.   reject: true
  7.   # 如果不取消,应把脏话替换成什么字符?
  8.   replacement: "[屏蔽]"

  10. # 惩罚
  11. punish:
  12.   # 类型
  13.   # KICK: 踢出
  14.   # BAN: 封禁
  15.   # CMD: 执行一条指令,指令中可以有玩家名变量%player%
  16.   type: "CMD"
  17.   # 多少次讲脏话会触发惩罚
  18.   # 0即禁用惩罚
  19.   count: 0
  20.   # 惩罚内容
  21.   # 如果是CMD类型惩罚,就是惩罚的指令
  22.   # KICK或BAN类型,就是惩罚的理由
  23.   value: "tell %player% §4不要讲脏话!"

  25. # 屏蔽规则
  26. rules:
  27.   # 一条示例规则
  28.   -
  29.     # 脏话文本
  30.     text: "sb"
  31.     # 检测类型
  32.     # FULL: 消息完全等于该文本才认为是脏话
  33.     # FUZZY: 消息包含该文本就认为是脏话
  34.     # REGEX: 消息包含匹配该正则的文本就认为是脏话
  35.     # ENHANCED: 加强的FUZZY,可以匹配q;q'1@2$3##45-这种
  36.     # 除了FULL均大小写敏感..到时候加强
  37.     type: FULL
  38.   -
  39.     text: "q群"
  40.     type: FUZZY
  41.   -
  42.     # qwq表示很无奈
  43.     text: "[Qq][^w]{0,3}[Qq].*"
  44.     type: REGEX
