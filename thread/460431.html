因为问题一样我就copy一下啦。
刚刚回答的那个的网址：http://www.mcbbs.net/thread-460461-1-1.html


default      新玩家
builder      正式玩家
moderator 低级管理
admin        OP
owner       腐竹
这是一开始就设定好的的5个组别，一进来都是default组别的

再扔上指令
/mangadd [名字]   
创立一个用户组
/mangdel [名字]  
删除xxx用户组
/mangaddp [名字] [权限]     
给组添加某某权限
/manglistp [名字]   
列出某个组的权限
/mangdelp [名字] [权限]   
删除某组的某权限
/mangaddv [名字]  prefix [数值]（比如&f是一种颜色）   
给组添加值的前缀
举例/mangaddv LBWORD prefix &f 市民
给LBWORD用户组添加了[市民]的前缀，并且这个前缀是带[&f]这个数值的颜色的
/mangaddi [名字1]  [名字2]      
让组1担当租2的权限，能够为权限设置剩下不少费事
/manuadd [玩家ID] [名字]      
将用户添加到组
/manuaddp    [玩家ID]   [名字]      
给用户权限
/manudelp [玩家ID]   [名字]      
删除用户权限
/manuaddp 玩家 prefix [参数]
给玩家添加XXX的前缀
/manuaddv 用户名 prefix &[]  
给玩家添加XXXX的称号

举个栗子，初始称号的话，人们一进来就在default组别，你可以给这个组别弄个新人称号，
/mangaddv default  prefix 新人           
这样子进来的人就是有称号 新人 了

给自己添称号的指令就是最后一个，我再来举Gdo_7的栗子
/manuaddv Gdo_7 prefix 副逗比
给玩家Gdo_7添加 副逗比 的称号
