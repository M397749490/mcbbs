由于这是示例项目 所以我们的[项目名称]填写 example
下方的[创建主类]改为自己想要的路径
比如我是隶属于 冰山工作室 的开发人员
我们工作室的域名是 bergst.cn 这个属于插件(plugin)
那么我的主类就写成 cn.bergst.plugins.example.Example
也就是采用 域名反转+项目类型+项目名 这样的形式
然后点击[完成]

这时我们的项目就已经创建完毕了
接着右方会变成代码编辑框
我们删去
  1. <font face="宋体">/**
  2. * @param args the command line arguments
  3. */
  4. public static void main(String[] args) {
  5.     // TODO code application logic here
  6. }</font>
复制代码

点击 工具 -> 库 -> 新建库 -> 库名称填写[Spigot-api-版本] -> 添加jar文件 -> [你的api文件]

此时当左下角出现 example.jar(clean) 构建成功时
