JulyGuild

本贴使用 MCBBS Markdown To BBCode Converter 生成

为什么使用 JulyGuild

  • 超过 200个 服务器（1400+个玩家）正在使用本插件
  • 使用 GNU 协议开源
  • 高度自定义
  • 功能齐全
  • 全局 GUI 支持
  • 多版本支持
  • 多服务端支持
  • 长期更新

功能



创建公会

插件支持使用点券和金币来创建公会。



加入公会

玩家只需要点几下鼠标就可以申请加入他人的公会。

公会信息

个人信息

公会排行榜

你可以自定义权重来指定排行榜。

入会审批

玩家可在 GUI 内申请加入公会，管理员只需要点下鼠标就可以处理请求。

成员管理

你可以踢出玩家，给予玩家各种权限，只需要点下鼠标。



捐赠

玩家可以为公会捐赠公会币，公会币是公会商店的交易货币。



公会商店

玩家可以在公会商店购买图标，全员集结令，升级公会……

公会主城

玩家可以为公会设置一个主城来供成员传送。

公会升级

玩家可以使用公会币来升级公会的最大人数。

公会图标

玩家可以使用公会币来为公会购买图标，图标会显示在主界面上。

你可以自己配置供销售的图标。



全员集结令



成员免伤

玩家可以开关成员免伤，开启后免疫成员伤害。

图标仓库

玩家可以在图标仓库自由设置购买到的图标。

每日签到

玩家可以每日签到获取奖励。

高度自定义

配置自定义

你可以自定义插件里的许多参数：

  • 创建公会的价格
  • 最大成员数
  • 排行榜计算公式
  • ...

语言自定义

你可以自定义插件中的每条消息。

GUI自定义

你可以自定义界面的标题，行数。

你也可以自定义物品的：

  • 位置
  • 材质
  • 子ID
  • 展示名
  • skulTexture
  • lore
  • flag
  • ...

指令与权限（部分）

/jguild gui main

打开主界面。

(需要权限：JulyGuild.use)

/jguild plugin reload

重载插件配置。

(需要权限：JulyGuild.admin)

/jguild plugin version

显示插件信息。

PlaceholderAPI 变量（部分）

变量名返回
%guild_name%公会名
%guild_member_position%职位：成员，主人
%guild_member_donated_gmoney%成员已赞助的公会币数量
%guild_member_join_time%成员加入时间
%guild_ranking%公会排名
%guild_owner%公会主人
%guild_member_count%公会成员数量
%guild_max_member_count%公会最大成员数量
%guild_creation_time%公会创建时间
%guild_bank_gmoney%公会币储备
%guild_online_member_count%公会在线成员数

作者: xx578975893    时间: 2019-7-12 04:05
提几个建议哈
设置公会的领地（就是公会传送点）
公会银行（升级用公会银行的钱,玩家可以贡献的钱到银行,每1金币=1贡献）
公会仓库（可以放东西,其他成员可以从里面拿出来,最好加个记录）
公会buff（用公会银行的钱购买药水buff,持续时间5分钟 每次可以设置多少钱,如果可以希望加上公会升级减少钱）
公会签到（每次玩家上线可以在公会签到,获得腐竹设置的物品,越高的公会等级,获得物品越多,这样可以让RPG服或者其他服增加一些玩法）
