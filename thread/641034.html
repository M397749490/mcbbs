教程优化的大体内容（具体操作看视频）：
1.下载驱动精灵
  升级显卡驱动
  安装各种组件
2.在系统属性减少视觉效果，减轻电脑压力
3.碎片整理
  减少硬盘的碎片可以有效的提高流畅度
  关闭整理计划，请定期手整理
  避免流畅度下降
4.进行相关显卡设置
5.运行 services.msc
优化服务项
Cryptographic Services
Desktop Window Manager Session Manager（爱透明效果的谨慎选择）
DHCP Client（不建议，需要联机的请不要选择）
DNS Client（不建议，需要联机的请不要选择）
Windows Event Log（自行选择）
HomeGroup Listener
HomeGroup Provider
Windows Firewall
Print Spooler
6.禁用启动项
msconfig > 启动选项卡
7.精简网卡功能
控制面板 > 网络与共享中心 > 更改适配器设置 > 选择你正在使用的网卡，右键属性
8.使用简单壁纸，注意，比较花哨的壁纸也会占用资源哦
9.玩我的世界时尽量关掉没用的软件
10.内存设置调小点
11.取消应用使用记录
*重启电脑
*重启游戏
