这插件很旧了，12年的，现在的人基本都不认识
http://dev.bukkit.org/bukkit-plugins/residence-limits/
下载地址 当时出的时候Bukkit才CB 1.0.1
不过今天我配合ResidenceV2.6.6.6在 1.7.10服务器上测试过，有效
你只需要配置一下文件
  1. Global:
  2.   res_x_limit: 16 ← 这是X值的最低限制
  3.   use_x_limit: true ← 是否启动检测X值
  4.   res_y_limit: 5 ← 其余的我想你也明白了
  5.   use_y_limit: true
  6.   res_z_limit: 16
  7.   use_z_limit: true
  8.   res_xz_limit: 50
  9.   use_xz_limit: false
  10.   res_xy_limit: 1
  11.   use_xy_limit: false
  12.   res_yz_limit: 1
  13.   use_yz_limit: false
  14.   res_total_size: 25
  15.   use_total_size: false
复制代码
如果没有达到最低限制系统会提示玩家在哪个值还缺多少个方块，由于这插件比较旧，当时作者也没考虑语言文件，你可以自行修改class来汉化，反正就一个文件，很短...
