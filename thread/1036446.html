没遇到过这个问题，只能给你提供一下思路，不一定对。猜测可能是启用了UUID验证，而恰好离线服务器或者是因为服务端的原因，造成玩家UUID跟地皮插件的数据不一致，所以无法回去。UUID必须跟玩家ID对应一致才能用。你也可以试试换一下cat核心能不能解决。

看看配置文件里的UUID模式是否关闭了   settings.yml
  1. uuid:
  2.   # Force using offline UUIDs (it usually detects the right mode)
  3.   offline: false
  4.   # Force using lowercase UUIDs
  5.   force-lowercase: false
  6.   # Use a database to store UUID/name info
  7.   use-sqluuidhandler: false
