简介
skript可以理解为一个高级的脚本插件。他可以编辑出类似插件功能的高端插件，而且理解简单，适合没有java开发经验的各位服主。
前言
  • 本人只是一个skript初学者，也没有什么开发经验，本教程仅限于像我一样没有开发经验，又想自己写一个功能的服主。
  • 大神请路过~！

正文:
实例讲解1：初识skript
  1. on join:
  2.     message "欢迎来到服务器"
  3.     broadcast "%player% 加入了服务器"
复制代码
这是一个，当玩家进入服务器时，自动发送给玩家一条消息和一条系统消息。
"on join: "是一个事件，当玩家进入游戏时。也就是说，当玩家进入游戏的时候，会触发下面的指令。

message "欢迎来到服务器"  这里的“message”是发送给玩家一条消息，后面的引号里是发送的内容。

broadcast "%player% 加入了服务器"  这里的broadcast是“公告”就是发送给每一位玩家。

通过此段脚本，可以设计出，当VIP玩家进入游戏时，获得不一样的进入消息。



实例讲解2：变量和if语句
  1. on join:
  2.     if {%player%join} is not set:
  3.         set {%player%join} to 1
  4.     else:
  5.         add 1 to {%player%join}
  6.         message "您已经来过服务器%{%player%join}%次了"
复制代码
if {%player%join} is not set:      
这里的{%player%join}是一个变量，IF 可以理解为“如果”的意思， 如果 {%player%join} 没有设置。

set {%player%join} to 1
设置{%player%join}这个变量值为1

else:
否则 “这里的否则，值得是对应格式的if，也就是对应如果{%player%join} 变量没有设置，否则。”

add 1 to {%player%join}
+1到{%player%join} 这个变量里。

这时，当玩家登录时，会得到一条消息，“你已经进入服务器%{%player%join}%次了”


注意：
        if和下一排挨着的语句，要多间隔4个空格，
onjoin：
空空空空 if
空空空空空空空空add
也可以用tab键空出一个空位。
