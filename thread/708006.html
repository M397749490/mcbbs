插件介绍
想让你的服务器更加国际化？想让来自不同国家的玩家在服务器里看到不同语言的同一个提示语？那么快来试试这个插件！
这个插件可以把所有插件*里能被玩家看到的文字显示为适合每个玩家的翻译过的语言**！包括聊天栏消息，Title消息，Actionbar消息，GUI菜单标题，计分板文字，Hologram悬浮字/NPC名字，踢出理由，Bossbar血条消息，TAB顶部底部消息，物品名称以及物品的lore，木牌消息……等等！

*   “所有插件”不排除可能存在，但目前尚未发现的不兼容的插件
** 本插件不是自动翻译机，所有翻译内容均需自己翻译才行

本插件需要Java8 且只能在1.8及以上服务器运行

——【② config】——

打开config.yml创建新的语言项，找到languages部分，如下
  1. languages:
  2.     # 语言的名字 和languages文件夹里各个文件息息相关
  3.     # 比如你在这里创建了一个en_UK的语言项，对应的语言修改文件就应该储存在 languages/en_UK.language文件里
  4.     # 请不要在服务器里有玩家的时候修改这些，因为语言是跟着玩家一起修改的
  5.     en_GB:
  6.         # 这个是能显示旗帜的代码
  7.         # 想获得这个代码的话请访问 http://www.needcoolshoes.com/banner 并创建一个旗帜
  8.         # 创建完成了以后注意看一下网址的变化，比如：
  9.         # 网址变成了 http://www.needcoolshoes.com/banner?=eapwplpnpmbzbj 那么这个代码就是 eapwplpnpmbzbj
  10.         flag: eapwplpnpmbzbj
  11.         # Minecraft里的语言代码 想查询这个代码请访问：
  12.         # http://minecraft.gamepedia.com/Language
  13.         # 简体中文是zh_CN 繁体中文是zh_TW
  14.         minecraft-code: en_GB
  15.         # 语言在GUI内显示的名称 可以添加彩色代码
  16.         # 请注意这里是不可以用[lang]翻译成别的语言的！！
  17.         display-name: '&aEnglish (UK)'
  18.     pt_PT:
  19.         flag: bacLlt
  20.         minecraft-code: pt_PT
  21.         display-name: '&aPortuguese (Portugal)'
  22.     zh_CN:
  23.         flag: balDbBbcbe
  24.         minecraft-code: zh_CN
  25.         display-name: '&aSimplified Chinese (China)'
复制代码
插件默认自带了英语en_UK和葡萄牙语pt_PT两种语言，你可以新建一个简体中文zh_CN（上方已经新建好了一个）

插件自带了一个更换语言的GUI，各个语言会在GUI内以一面旗帜的形式展示以供选择，关于这面旗帜的图案有一个专门的代码，请访问这里来创建一面旗帜，创建完成后请注意网址的变化，网址中banner?=后面的内容即旗帜代码（中国 国 旗的代码是balDbBbcbe）

——【④ languages.json】——
语言变量有什么用？当然是利用它们显示出不同的语言，打开插件文件夹中的languages.json文件，按照如下格式开始写你的第一个翻译变量
  1. {
  2.   "type": "text",
  3.   "key": "teletitle",
  4.   "languages": {
  5.     "en_GB": "RandomTeleport",
  6.     "zh_CN": "随机传送"
  7.   }
  8. }
