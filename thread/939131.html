插件介绍
  • 自定义属性标签(攻击力,防御力,火攻,火防等等能想到的)
  • 自带职业系统,自定义配置职业造成的伤害公式
  • 装备生成属性可随机可固定,可带孔,可带强化,可随机附加额外的属性
  • 可装备54件不同类型的装备,自定装备类型,如:卡牌,戒指,项链,手镯,勋章,宝物等等..
  • 自带宝石系统,可打孔,镶嵌,取出.宝石属性可多条,可随机属性
  • 自带强化系统,无上限强化,创建强化石配置文件并设置强化成功率,失败掉级率,失败消失率
  • 自带洗练系统,可随机获得/减少额外的属性,<-可配置
  • 自带绑定系统,可配置绑定装备可放入什么标题的箱子
  • 自带回收窗口,装备价值可根据属性点来计算,可回收点券|游戏币|插件升级需要的经验值
  • 自带右键执行指令列表并消耗指定数量的系统,做回血药,一次性药,持续药,经验券,点券券,权限券等等...
  • 自带套装系统X件触发Y效果
  • 自带道具大全,快速浏览编辑好的物品/装备/宝石/强化石
  • 自带加点功能,每级给予X点属性点供玩家分配
  • 指令添加临时属性,buff属性,永久属性
  • 兼容skillapi技能插件,修改skillapi伤害公式,做百分比伤害
  • 兼容mythicmobs怪物插件,给怪物添加插件属性
  • 插件只支持MySql保存格式,不支持其他保存格式

PAPI变量

#属性点point数据
#all = 所有数据的总和
#equip = 装备加成的数量
#other = 其他属性的加成,例如称号,药水,道具加成
#basic = 职业基本属性
#add   = 属性id所投放的点数

#total = value*(1+sign)的数量
#value = 实际点数量,不加百分比
#sign  = 百分比数据
%pxrpg_point_[all|equip|other|basic|add]_[total|value|sign]:(属性id)% = 玩家的属性点ID总数


#属性attribute数据
#all = 所有数据的总和
#equip = 装备加成的数量
#other = 其他属性的加成,例如称号,药水,道具加成
#basic = 职业基本属性

#min   = 最小值
#max   = 最大值
#random= 随机值,每次访问都不一样

#total = value*(1+sign)的数量
#value = 实际点数量,不加百分比
#sign  = 百分比数据
%pxrpg_attribute_[all|equip|other|basic]_[min|max|random]_[total|value|sign]:(属性id)% = 玩家的属性数据



#display = 显示名字,例如:"战士"
#level   = 当前职业等级
#exp     = 当前职业经验值
#levelexp= 当前等级升级所需的经验值
#id      = 职业id
#maxlevel= 职业最大等级
#mana    = 当前蓝量
#maxmane = 最大蓝量
#surplus|surpluspoint = 剩余可分配的属性点数量
#skillpoint= 剩余可分配的技能点数
%pxrpg_class_main_[display|level|exp|levelexp|id|maxlevel|surplus|maxmana|mana|surpluspoint|skillpoint]% = 玩家的主职业数据



#point = 属性点类型
#att   = 属性类型
%pxrpg_class_main:[point|att].(属性id).display% = 玩家的主职业的基本数据#不建议使用



#equip = 装备
#item  = 物品类型
#streng= 强化石
#gem   = 宝石

#name  = 物品显示名
#type  = 物品类型
#damage= 物品耐久值
%pxrpg_item_[equip|item|streng|gem]:(物品ID|物品文件名).display.[name|type|damage]% = 物品信息#不建议使用


%pxrpg_class:(职业ID).display% = 职业ID的显示名

#point = 属性点point
#att   = 属性数值
%pxrpg_class:(职业ID).[point|att].(属性id).display% = 职业ID的基础属性值
