前言
这是一个世界生成器插件，扔进plugins里即可。单独使用没有任何效果。一些多世界插件如Multiverse、Multiworld生成特殊世界用到它才能发挥作用。
如无特殊说明，生成器没有权限和指令。

简介
  • 宇宙空间世界可自定义行星和小天体生成（见配置文件）
  • 太空帽和太空服可启用或关闭（见配置文件）
  • 支持多世界管理插件
  • 可呼吸区域 (无需太空帽和太空服)
  • Spout 端还有额外功能比如重力影响和黑洞
  • （补充）本世界默认24小时黑夜状态~

生成器用法
Multiverse 用法:
/mv create 世界名 normal -g bSpace

PS：我擦，还区分大小写！

Multiworld 用法
/mw create 世界名 plugin:bSpace

如果想要利用这个生成器生成主世界，修改bukkit.yml
  1. worlds:
  2.   world:
  3.     generator: bSpace
