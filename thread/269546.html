标题: 怎么给予别人领地权限
我的基友来了，可是我设置了领地，而基友就没有地方住了，我想问：怎么给他领地的使用权？
把指令发给我
作者: naruro2010    时间: 2014-4-27 18:36
本帖最后由 naruro2010 于 2014-4-27 18:46 编辑

输入/res pset 玩家  权利 t
在你的领地里输入
基本权利：
build ：建筑
use ：开启门等
container ：开启箱子等
作者: rams    时间: 2014-4-27 18:42
/res pcst [你的领地名字} Build t

/res pcst [你的领地名字} use t

/res pcst [你的领地名字} container t

全部输入就什么权限都有了，给我最佳
