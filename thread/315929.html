DiscoSheep 小羊舞会
@aaronusa

这是一个有趣旧插件的重制版本，它可以生成羊和其他生物并让它们开始一场迪斯科舞会!不可思议吧~
特性：


  • 绝妙的迪斯科舞步
  • 支持权限
  • 可以自由设置生物数量、持续时间以及节奏
  • 小羊们可以发射烟花
  • 羊处在无敌状态下，并且不可被剪羊毛、不可繁殖
  • 可以生成其他生物加入舞会
  • 在以后增加新功能



安装：
将插件拖入plugins文件夹，重启服务器后将自动生成配置文件。


配置：
如果不进行配置将使用默认值，注意period（节奏）以游戏刻为单位(1游戏刻=1/20秒)，数字越小代表节奏越快。舞会持续时间以秒为单位，minimum（最小值）的设置是为了防止过快的频率可能拖慢服务器。同样，maximums（最大值）是指每个舞会（最慢节奏？）的限制，也可以防止插件拖慢服务器。


命令与参数：

只有玩家可以使用的命令
/ds me [参数]
开始自己的舞会
/ds stop
停止自己的舞会

玩家和控制台都可以使用的命令
/ds all
开始整个服务器的舞会
/ds stopall
停止整个服务器的舞会
/ds other <玩家> [参数
start parties for the given space-delimited list of players, eg. /ds other Gibstick Rangermauve -n 20
/ds defaults [参数
设置之后舞会的默认阵容(不保存至文件)比如：ds defaults -n 20 -r 5 -g COW 5
/ds save 或 /ds saveconfig
保存默认配置文件的改变
/ds reload
重载 config.yml 文件
/ds help
帮助
/ds togglejoin
在全局范围内禁用或启用加入舞会的功能(只限于处于discosheep.party.onjoin 权限节点的玩家

参数：
-n <羊的数量>
羊的数量
-f (原名 -fw)
启用烟花效果
-t <持续时间>
以秒为单位
-p <节奏快慢>
以游戏刻为单位，指定每个迪斯科节奏之间的持续游戏刻. 数字越低节奏越快. 不推荐把设定的默认值低于5游戏刻。
-r <半径>
玩家周围将会生成羊。
设定半径为 "dense"（密集）将会将你的舞会变成“小羊狂舞区” (比如： /ds me - r dense)
-g <生物> <数量>
设置额外生成的生物数量。参考config.yml 中生物的名称和数量限制。
比如. /ds me -g COW 5 CREEPER 2 CHICKEN 3
将参数设为 "none" 将不生成额外的生物，比如： /ds defaults -g none
默认情况下，config.yml 中的数量限制都为0
-l
启用闪电效果
权限：
超级权限节点
discosheep.*
授予访问所有DiscoSheep权限
discosheep.party.*
授予访问所有与舞会有关命令的权限
discosheep.admin.*
授予访问所有管理命令权限

舞会
discosheep.party.me
允许玩家使用/ds me创建一个单人的舞会
discosheep.party.all
允许玩家使用服务器范围的聚会
discosheep.party.other
允许玩家使用 /ds other 命令
discosheep.party.fireworks
允许玩家使用 -f 烟火开关
discosheep.party.spawnguests
允许玩家使用 -g 开关生成其他生物
discosheep.party.lightning
允许玩家使用 -l 开关开启闪电效果
discosheep.party.onjoin
允许玩家加入舞会
discosheep.party.changeperiod
允许玩家改变 -p 节奏快慢开关

管理
discosheep.admin.stopall
允许玩家使用 /ds stopall 停止所有的舞会
discosheep.admin.reload
允许玩家使用 /ds reload 命令重载配置文件
discosheep.admin.changedefaults
允许玩家使用 /ds defaults 命令回复默认设置
discosheep.admin.saveconfig
允许玩家使用 /ds saveconfig 命令保存默认配置文件的改变
discosheep.admin.toggleonjoin
允许玩家在全局范围内禁用或启用加入舞会的功能
