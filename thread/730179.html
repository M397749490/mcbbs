作者: ⊙v⊙    时间: 2017-9-29 11:49
....没看懂你是想做什么
设立
scoreboard objectives add mark dummy


然后高频
scoreboard players set @a mark 3 {Inventory:[{id:"minecraft:apple"}]}
scoreboard players remove @a[score_mark_min=0] mark 1


有苹果的玩家会被设置为3分
在没有苹果时，会被渐渐减1分，直到分数等于-1
因此可以选择器选择所有mark分数为0的玩家背包没有苹果



之后你要解决一个问题，就是什么时候玩家没有指定物品，或者说因为什么而没有物品，以区分并保证
始终都没有此物品的玩家不执行后续操作
曾经有过之后没有此物品的玩家执行操作

比如
可以是把获得苹果后的玩家加上tag  ihaveit
高频的第一条变为@a[tag=ihaveit]
高频的第二条变为@a[tag=ihaveit,score_mark_min=0]
在高频一条score players tag @a[score_mark=-1] remove ihaveit


最后又要根据你自己的情况考虑其他可能发生的事情
比如若是玩家获得苹果后，放入箱子或丢出去再拿回来你想怎么算...
