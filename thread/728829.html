萌新第一次写插件，喷请轻喷！

本插件使用Bukkit1.7.5API写成，实测在Spigot1.7.2和PaperSpigot1.8.4的环境下可用，其他环境因为我没有所以也没试。


相信很多腐竹朋友们都在自己的服务器上开了一个DiscuzX论坛吧，DiscuzX因为其方便易用而功能强大的特性受到了腐竹朋友们的青睐。很多腐竹朋友也希望利用DiscuzX的充 值接口来实现自己服务器的商业运营，亦或是用游戏币来激励玩家在论坛发帖。但是目前，DiscuzX的积分兑换成为游戏中的虚拟货币可谓难于登天。本人数年前曾经进入过一个服务器，该服务器就采用了DiscuzX作为充 值接口，但是因为缺乏一种方便的兑换为游戏币的手段，该服腐竹被迫使用“待兑换游戏币”的extcredit和几小时执行一次、**低效的计划任务来实现兑换操作。针对这种情况，本人独立开发了DX2iConomy插件，方便玩家将DiscuzX论坛的积分兑换为游戏币。该插件每分钟自动兑换一次。


使用该插件，请确保你已经启用iConomy经济插件，并把iConomy的config.yml中：
Database--Type改为'mysql'；
Database--URL改为你服务器的数据库地址，默认为mysql://localhost:3306/ultrax；（建议视你的论坛装在哪个数据库，最后一个单词为你数据库实际名称，DiscuzX的默认为ultrax）
Database--Username和Password改为你数据库的管理员用户名密 码。

config.yml解析：

##你数据库的地址，URLDiscuz--论坛数据库，URLiconomy--游戏数据库，格式为："jdbc:mysql://"+你数据库的IP地址+":"+端口号+"/"+数据库名称；
##默认IP为localhost（本机），端口号3306，数据库名称ultrax。
URLDiscuz: jdbc:mysql://localhost:3306/ultrax
URLiconomy: jdbc:mysql://localhost:3306/ultrax
##你Discuz的数据表名称前缀，一般为pre，如果同一个数据库中运行了多个论坛，请修改
prefix: pre
##你iconomy插件的表名称，默认是iconomy，参见iconomy的config.yml
icotab: iconomy
##你Discuz的MySQL数据库的用户名和密码
unmDiscuz: root
passwordDiscuz: root
##你游戏MySQL数据库的用户名和密码
unmiconomy: root
passwordiconomy: root
##你discuz对应游戏币的积分编号，默认为2，extcredit几就是几
extcredit: 2
##你discuz对应待兑换游戏币（即充 值之后作为奖励的积分）的积分编号，默认为3，extcredit几就是几
extcreditwaiting: 3
##你服务器设置金钱的初始值，默认为10000
initialbalance: 10000.00
##是否是第一次使用该插件
first_used: 1

指令：
/initialization 初始化命令，把游戏币导入论坛积分，以免游戏币信息丢失。本插件人性化设置了“first_used”，你需要修改config符合你的论坛后使用这个命令来初始化，以免张冠李戴。
/alltrans 全服转换，就是每分钟进行一次的那个操作。
/dxireload 重置插件。
/xu 彩蛋指令，我有两句诗，不知当念不当念（滑稽）

权限：
permissions:
    dxic.xu:
        description: Allow Xuming//允许使用彩蛋
    dxic.dxico:
        description: Allow use /dxico //允许个人转换
    dxic.initialization:
        description: Allow use /initialization //允许全服初始化
        default: op
    dxic.reload:
        description: Allow use /dxireload //允许重置插件
        default: op
