先建立一个记分板 foo
  1. scoreboard objectives add foo dummy
复制代码
  1. execute store result score #count foo if entity @e[type=zombie]
复制代码
if entity @e[type=zombie] 用于统计僵尸的数量，store result score #count foo 用于将结果存储为一个名为 #count 的玩家的 foo 记分板的分数。
