配置文件
  1. filters {
  2.     ljyys {
  3.         cancel-condition=""
  4.         cancelMessage=""
  5.         enable-replacement=true
  6.         pattern="l.*j.*yys"
  7.         replacement=ljyys
  8.         weight=0
  9.     }
  10.     black {
  11.         cancel-condition="entire"
  12.         cancelMessage="Fire"
  13.         enable-replacement=true
  14.         pattern="pa"
  15.         replacement=""
  16.         weight=1
  17.     }
  18. }
  19. settings {
  20.     showRawMsg=true
  21. }
复制代码
拥有chatfilter.bypss.<key>可以不判定某个匹配
cancel-condtion可以为
  • entire   ->完全匹配正则则取消发送消息
  • any      ->部分匹配正则则取消发送消息
  • 其他     ->不取消消息发送

weight越大则越先匹配其他基本为英文单词字面意思
