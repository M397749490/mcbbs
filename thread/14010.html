唔..这里的教程蛮多蛮乱的，我建服的时候看了几个小时话说..
几个点可以留意一下：
1.bat文件和.jar放一起
2.jar文件的名称下载的时候是什么就是什么，最好不要改变
3.Java地址可以改用固定地址看看，用%XXX%的方法一般都是要设环境变量的，如果环境变量不对的话这个地址是没意义的。（非计算机专业，讲错勿喷）
4.下面是我的.bat文件，LZ如果是XP的话可以COPY试用一下。%BINDIR%就是当前文件夹，所以只有.jar和.bat放在一起才能生效。
  1. @ECHO OFF
  2. SET BINDIR=%~dp0
  3. "C:\Program Files\Java\jre6\bin\java.exe" -Xincgc -Xmx1G -jar "%BINDIR%\craftbukkit-1.0.0-snapshot.jar"
  4. PAUSE
复制代码
