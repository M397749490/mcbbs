  × 简介

               ……增加玩家的最大生命上限！当你升级的时候可以获得不同的生命值！
               ……方便快捷的命令！                可以使用命令（命令方块）来执行命令！
               ……可随心配置！                        你可以通过配置文件来配置你所需要的！
               ……不配置任何权限文件！          你不必配置权限文件因为他不需要任何权限！
               ……使用十分灵活方便！                因为他能够通过你配置的配置文件进行自动更新和检查！（建议关闭）

  2.   version: 1.2.0
  3.   autoUpdate: true     #是否自动更新

  5. metricsEnabled: true

  7. updateCheck:#更新检查
  8.   enabled: true
  9.   informOperators: true

  15.   reset:
  16.     login: false#登录时是否初始化最大生命值

  18.   restoreHealth: true#是否允许初始化生命值
  19.   particleEffect:#粒子效果
  20.     increase: heart#生命增加
  21.     decrease: none#生命减少

  23. chat:
  24.   language: enUS

  26. commands:
  27.   maxHealthEnabled: true
  28.   healthEnabled: true
  29.   infoEnabled: true

  31. permissions:
