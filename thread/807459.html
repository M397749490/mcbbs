+——BookStats——+

让你的信息显示在书本上


简介




还在为简陋的聊天框信息显示而烦恼吗？

这款插件完美解决！

该插件极其轻量

但功能完全

下拉了解更多：


特点

  • 让玩家获取一个书本，查看获取时的玩家信息
  • 8个插件基变量
  • 支持PlaceHolderAPI
  • SQL存储（搞不懂为啥这么简单的插件还要用SQL……）



指令和权限

  • /bookstats-获取一本写有状态的书本|bookstats.getbook
  • /bookstats reload-重启|bookstats.reload



Config配置
同理，又崩了


  1. # MYSQL设置，如果要打开请打开Use MySQL选项
  2. MySQL:
  3.     Use MySQL: false
  4.     IP Address: localhost
  5.     Port: 3306
  6.     User: notroot
  7.     Pass: notmypassword
  8.     Database: BookStats
  9.     Table: BookStats

  11. # 间隔多少秒更新数据（应该是SQL）
  12. Save Interval: 2

  14. # 书本自定义，变量同下
  15. Book:
  16. - "&b&l{Player}'s Stats!"
  17. - " "
  18. - "&1Balance: &4{Balance}"
  19. - " "
  20. - "&1Kills: &4{Kills}"
  21. - " "
  22. - "&1Deaths: &4{Deaths}"
  23. - " "
  24. - "&1Kill Streak: &4{Killstreak}"
  25. - " "
  26. - "&1Mob Kills: &4{Mobkills}"
  27. - " "
  28. - "&1Block Placed: &4{Blocksplaced}"
  29. - " "
  30. - "&1Block Broken: &4{Blocksbroken}"

  32. Book Title: "&6{Player}'s Stats" #书物品的标题
  33. Book Author: "&aBookStats" #书物品的作者

  35. On Join:
  36.     # 是否在加入时给予玩家书本
  37.     Give Book: false
  38.     # 是否只给一次书本（shemogui）
  39.     Give Limit: true
  40.     # 设置get书本后放置到的快捷栏槽位，设置为0将会寻找背包里空缺的位置
  41.     Slot: 0
  42.     # 如果你想防止玩家丢掉书本，请打开
  43.     Prevent Drop: false
  44.     # 如果你想防止玩家移动书本的位置，请打开
  45.     Prevent Drag: false

  47. # 是否让插件每时每刻更新你的书本内容和变量（shemogui）
  48. Update Book: true
复制代码





关于变量

  • {Player}-玩家名字
  • {Balance}-玩家金钱（需要VAULT支持）
  • {Kills}-玩家累计杀人数
  • {Deaths}-玩家累计死亡数
  • {KillStreak}-gets the amount of kills the player has in a row.（啥意思……）
  • {mobKills}-杀死的怪物数量
  • {BlocksPlaced}-玩家累计放置方块的数量
  • {BlocksBroken}-玩家累计破坏方块的数量
