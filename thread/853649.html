前言：这是一个很有趣的插件，生存服可以当趣味来添加

其他玩法，服主可以自行脑洞





配置文件
  1. # UseBypassPermission: 'se.bypass'
  2. # DecaySpeed(In game hour): Default value is 12
  3. # Penalty: Penalty threshold
  4. # Warning: Warning threshold
  5. UseBypassPermission: false
  6. DecaySpeed: 12
  7. IgnoreList:
  8. - POTION
  9. - MILK_BUCKET
  10. Penalty:
  11. Food_level_-1: 2
  12. HP_-1: 4
  13. Potion_effect_1: 6
  14. Potion_effect_2: 7
  15. Potion_effect_3: 8
  16. Potion_effect_group1:
  17. - SLOW
  18. - UNLUCK
  19. Potion_effect_group2:
  20. - WEAKNESS
  21. - SLOW_DIGGING
  22. Potion_effect_group3:
  23. - CONFUSION
  24. Warning:
  25. weak: 2
  26. strong: 5
  27. Message:
  28. Intake: '{food} intake: {number}'

复制代码


命令：

- /se hungry (用于测试时使用)
- /se reload 重载插件




权限：

- se.admin

- se.bypass



对于有人无法理解这个插件的意思，我只能再这里解释一下
每天吃的东西可以设置不一样，如果吃别的就有惩罚
