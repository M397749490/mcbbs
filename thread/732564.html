Nukkit-AntiCheat
AntiCheat - 防作弊插件
简介
  • AntiCheat是一款运行在Nukkit上的反作弊插件.
  • 它可以帮助你更好的检测作弊玩家并阻止.
  • 包括(快速聊天,敏感词检测,自动瞄准, 速度, 碰撞箱检测)等.
  • 如果可以，你可以让它变得更好.
如何使用?
  • 安装插件
    • 下载 'AntiCheat' 插件.
    • 放入Nukkit根目录下的plugins文件夹.
    • 重启(或重载)你的服务器.

配置:true开启false关闭
  1. antiSpeed: true
  2. antiSpeedPingCheck: true
  3. pingNoCheckValue: 25
  4. maxMoveSpeed: 6.0
  5. checkBB: true
  6. antiFly: true
  7. inAirTimeCheck: 5
  8. checkChat: true
  9. chatSec: 2
  10. checkChatWord: true
  11. SensitiveWords:
  12. - f**k
  13. - shit
  14. antiKillAura: true
  15. antiAutoAim: true
  16. checkKillAuraCPS: 3
