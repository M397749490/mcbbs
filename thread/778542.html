Ultimate Chat | 更简单使用的Json聊天·标记·等级

(使用PlaceHolderAPI具有50多个变量)

介绍:
Ultimate Chat让你（服务器所有者）显示玩家姓名，部落标记，结婚标签和你选择创建的任何标签的附加信息，全部使用原我的世界JSON。 当你悬停在这个玩家的聊天上时,就将会显示玩家的信息。





预览效果:


在服务器中的玩家可以@你











插件特色:

               
在使用PlaceHolderAPI时可以完全支持此插件的所有变量，例如在服务器自动发送的公告上面可以使用自定义的json （例如:命令 跳转的网站）,在使用Redis在同一个Redis服务器上的任意bukkit或Sponge服务器之间发送私人消息等（下面是作者剩下的原文,就是和各类插件的交互） /ubroadcasts and channel message between any server in bukkit or Sponge conected on same Redis server.?Can show tags of plugin tags made for LegendChat;?Use channels as command aliases;?Bungee bridge to chat messages between Bungee Network using as many channels you want.?Hook into vault to get prefixes, suffixes, money, group, and all info the Vault provides;?Hook with all chat plugin that uses "setFormat()" in his codes;?Show marry status, marry partner and marry name if using marry plugin;?Channel costs to chat;?Mention players. When a player write other player name on chat this player will be notified with a sound;?Show Clan info, KDR, name, tag, rank, etc;?Easy channel creation and personalization, by distance, world or all;?Show the item the player is on hand useing @Hand (default) on chat message;?Easy TAG creation and 100% customization of a tag;?Complete API to add tag, change the messages or cancel chat,allviaplugin.With javadocs too;?


使用方法:官方百科
命令:(未翻译大概能看懂 命令 权限节点 功能)
  1. /tell {player} [message] - uchat.cmd.tell
  2. To lock private messages with a player or send a message direct to player.
  3. /r {message} - uchat.cmd.tell
  4. To respond the last private message received.
  5. /umsg {player} {message} - uchat.cmd.umsg
  6. To send a message directo player without formats. Goot to use with other plugins to send clean system messages to players.
  7. /ubroad {message} [hover:{message}] [click:{cmd}] [suggest:{msg or cmd}] - uchat.cmd.broadcast Send broadcast messages with optional hover message, click and suggest actions. You can change or add more aliases like /all on config file. On click: and suggest: you can use {clicked} to put the player name who clicked on command.
  8. /chat clear - uchat.cmd.clear
  9. To clear own chat messages (not for all players);
  10. /chat clear-all - uchat.cmd.clear-all
  11. To clear all players chat messages;
  12. /chat spy - uchat.cmd.spy
  13. To enable/Disable spy chat. This will spy the non global chats and all private messages.
  14. /chat mute {player} [channel] - uchat.cmd.mute
  15. To mute/unmute a player in all channels, or in a specific channel.
  16. /chat ignore {channel/player} - uchat.cmd.ignore.player or uchat.cmd.ignore.channel
  17. To ignore a channel or player and dont receive the channel/player messages.
  18. /chat chconfig {channel} {key} {value} - uchat.cmd.chconfig
  19. Edit a channel config. Use TAB to see available keys to edit.
  20. /chat newchannel {channel-name} {alias} {color} - uchat.cmd.newchannel
  21. Creates a new Channel.
  22. /chat delchannel {channel-name} - uchat.cmd.delchannel
  23. Deletes a Channel.
  24. /chat reload - uchat.cmd.reload, uchat.admin_, OP or from console
  25. Reload the config and language files.

Bungee安装:(机翻能看懂所以我也就没人翻)
您的玩家可以使用BungeeCord聊天消息作为正常频道。
把插件jar放到你的BungeeCord插件目录下;
现在你可以创建一个新的频道或使用一些现有的频道，并在频道文件上启用Bungee选项;
所有的信息将只发送到蹦极频道，而不是正常的聊天;
使用蹦极频道的权限与其他正常频道相同。 不需要特别的许可;
